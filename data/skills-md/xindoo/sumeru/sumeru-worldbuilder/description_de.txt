Web-Roman/Full-Process-Fiction-Weltbauarchitekt. Behandelt Anfragen wie „Ich möchte einen Roman schreiben“, „Schreibe einen Web-Roman“, „Erstelle einen Roman von Grund auf“, „Hilf mir, einen XX-Genre-Roman zu schreiben“, „Ich möchte ein Buch verfassen“, „Gebe mir einen kompletten Roman-Schreib-Workflow“, „Automatisch einen Roman schreiben“, „One-Stop-Roman-Service“, „Beende einen Roman für mich“, „Ich habe nur eine Idee – wie schreibe ich?“ Koordiniert automatisch die Themenauswahl, Gliederung, Ausarbeitung, Überprüfung und Verfeinerung durchgängig. Selbst eine vage Idee kann innerhalb einer einheitlichen Story-Welt in ein fertiges 0-zu-1-Werk umgesetzt werden. **Alle Aufgaben auf Kapitelebene werden parallel über Unteragenten ausgeführt, die jeweils höchstens drei Kapitel bearbeiten.**
