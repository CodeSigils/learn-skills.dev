Spezialist für den Aufbau von Web-Romanen/Full-Process-Fiction-Welten. Behandelt Anfragen wie „Ich möchte einen Roman schreiben“, „Schreibe einen Web-Roman“, „Erstelle einen Roman von Grund auf“, „Hilf mir, einen XX-Genre-Roman zu schreiben“, „Ich möchte einen Roman“, „Gebt mir den vollständigen Workflow für die Romanerstellung“, „Automatisch einen Roman schreiben“, „One-Stop-Roman-Service“, „Beende einen Roman für mich“, „Ich habe nur eine Idee – wie schreibe ich einen Roman?“ Koordiniert automatisch die Themenauswahl, Gliederung, Ausarbeitung, Überprüfung und Verfeinerung durchgängig. Selbst eine vage Idee kann innerhalb einer einheitlichen Story-Welt zu einem vollständigen 0-zu-1-Werk werden. **Alle Aufgaben auf Kapitelebene werden parallel über Unteragenten ausgeführt, die jeweils höchstens drei Kapitel bearbeiten.**
