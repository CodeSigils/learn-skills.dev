Romanentwurf/Weltaufbau/Charakterdesign, geeignet für Benutzeranfragen wie „Helfen Sie mir, einen Romanentwurf zu schreiben“, „Entwerfen Sie das Profil der Hauptfigur“, „Erstellen Sie eine Weltkulisse“, „Erstellen Sie einen Handlungsrahmen für den Roman“, „Schreiben Sie detaillierte Umrisse für jeden Band“, „Entwerfen Sie Romanfiguren für mich“, „Erstellen Sie eine Fantasieweltkulisse“, „Helfen Sie mir, die Romanhandlung zu organisieren“, „Entwerfen Sie Romancharaktere“, „Schreiben Sie eine Kapitel-für-Kapitel-Gliederung für den Roman“, „Planen Sie die Platzierung befriedigender Momente.“ „Eine neuartige Charakterkarte erstellen“, „Die neuartige Welt konstruieren“ usw. Erstellt eine vollständige Weltanschauung, Charakterkarten, einen Handlungsentwurf und einen Plan für befriedigende Momente mit automatischen Compliance-Prüfungen, um das Risiko von Verstößen zu vermeiden. **Wenn Sie einen großen Stapel von Kapitelumrissen erstellen, verwenden Sie Unteragenten für die parallele Verarbeitung, wobei jeder Agent höchstens drei Kapitelumrisse verarbeiten kann.**
