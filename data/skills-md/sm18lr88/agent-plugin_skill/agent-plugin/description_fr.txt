À utiliser pour concevoir, créer, migrer, réviser, valider, empaqueter ou implémenter la prise en charge de plugins d'agent portables, y compris les manifestes plugin.json, les compétences d'agent sous skills/, les serveurs MCP dans mcp.json, les extensions client de domaine inversé, la conformité du client, les couches de compatibilité et les limites de sécurité des plugins. Ignorez les plug-ins d'application ordinaires ou les modifications de compétences isolées qui n'impliquent pas de package de plug-in d'agent.
