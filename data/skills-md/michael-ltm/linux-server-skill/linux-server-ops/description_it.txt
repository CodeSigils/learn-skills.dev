Gestisci, distribuisci e monitora i server Linux tramite SSH. Come un BaoTa/1Panel ma guidato dall'intelligenza artificiale. Copre siti Web, servizi Node.js/Java/Python/Go/PHP, database MySQL/PostgreSQL/Redis, contenitori Docker e stack Compose, certificati SSL (emissione automatica + rinnovo automatico), associazione di domini, gestione Nginx, WAF (ModSecurity+OWASP), processi cron, firewall, gestione dei registri, operazioni sui file, gestione degli utenti, monitoraggio del sistema e backup. Tutti i servizi si avviano automaticamente all'avvio. Mantiene un indice lato server e istantanee dell'area di lavoro locale per la ripresa immediata della sessione. Da utilizzare quando l'utente chiede di distribuire un sito Web o un servizio, gestire un server Linux, impostare SSL, configurare database, gestire Docker, controllare lo stato del servizio, riavviare un servizio, monitorare le risorse o riprendere il lavoro su un server precedentemente configurato.
