Управляйте, развертывайте и контролируйте серверы Linux через SSH. Как BaoTa/1Panel, но управляемый искусственным интеллектом. Охватывает веб-сайты, службы Node.js/Java/Python/Go/PHP, базы данных MySQL/PostgreSQL/Redis, контейнеры Docker и стеки Compose, сертификаты SSL (автоматический выпуск + автоматическое продление), привязку домена, управление Nginx, WAF (ModSecurity+OWASP), задания cron, брандмауэр, управление журналами, файловые операции, управление пользователями, мониторинг системы и резервное копирование. Все службы автоматически запускаются при загрузке. Поддерживает индекс на стороне сервера и снимки локальной рабочей области для мгновенного возобновления сеанса. Используйте, когда пользователь запрашивает развертывание веб-сайта или службы, управление сервером Linux, настройку SSL, настройку баз данных, управление Docker, проверку состояния службы, перезапуск службы, мониторинг ресурсов или возобновление работы на ранее настроенном сервере.
