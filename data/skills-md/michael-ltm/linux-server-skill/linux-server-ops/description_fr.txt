Gérez, déployez et surveillez les serveurs Linux via SSH. Comme un BaoTa/1Panel mais piloté par l'IA. Couvre les sites Web, les services Node.js/Java/Python/Go/PHP, les bases de données MySQL/PostgreSQL/Redis, les conteneurs Docker et les piles Compose, les certificats SSL (émission automatique + renouvellement automatique), la liaison de domaine, la gestion Nginx, WAF (ModSecurity+OWASP), les tâches cron, le pare-feu, la gestion des journaux, les opérations sur les fichiers, la gestion des utilisateurs, la surveillance du système et les sauvegardes. Tous les services démarrent automatiquement au démarrage. Conserve un index côté serveur et des instantanés de l'espace de travail local pour une reprise instantanée de la session. À utiliser lorsque l'utilisateur demande à déployer un site Web ou un service, à gérer un serveur Linux, à configurer SSL, à configurer des bases de données, à gérer Docker, à vérifier l'état d'un service, à redémarrer un service, à surveiller des ressources ou à reprendre le travail sur un serveur précédemment configuré.
