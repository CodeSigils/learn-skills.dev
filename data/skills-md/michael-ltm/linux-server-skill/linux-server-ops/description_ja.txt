SSH 経由で Linux サーバーを管理、展開、監視します。 BaoTa/1Panel に似ていますが、AI 駆動です。 Web サイト、Node.js/Java/Python/Go/PHP サービス、MySQL/PostgreSQL/Redis データベース、Docker コンテナおよび Compose スタック、SSL 証明書 (自動発行 + 自動更新)、ドメイン バインディング、Nginx 管理、WAF (ModSecurity+OWASP)、cron ジョブ、ファイアウォール、ログ管理、ファイル操作、ユーザー管理、システム監視、バックアップをカバーします。すべてのサービスは起動時に自動的に開始されます。セッションを即座に再開できるように、サーバー側のインデックスとローカル ワークスペースのスナップショットを維持します。ユーザーが Web サイトまたはサービスのデプロイ、Linux サーバーの管理、SSL のセットアップ、データベースの構成、Docker の管理、サービスのステータスの確認、サービスの再起動、リソースの監視、または以前に構成されたサーバーでの作業の再開を要求する場合に使用します。
