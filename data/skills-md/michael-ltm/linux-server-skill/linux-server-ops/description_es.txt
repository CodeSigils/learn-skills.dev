Administre, implemente y monitoree servidores Linux a través de SSH. Como un BaoTa/1Panel pero impulsado por IA. Cubre sitios web, servicios Node.js/Java/Python/Go/PHP, bases de datos MySQL/PostgreSQL/Redis, contenedores Docker y pilas de Compose, certificados SSL (emisión automática + renovación automática), enlace de dominio, administración de Nginx, WAF (ModSecurity+OWASP), trabajos cron, firewall, administración de registros, operaciones de archivos, administración de usuarios, monitoreo del sistema y copias de seguridad. Todos los servicios se inician automáticamente al arrancar. Mantiene un índice del lado del servidor e instantáneas del espacio de trabajo local para la reanudación instantánea de la sesión. Úselo cuando el usuario solicita implementar un sitio web o servicio, administrar un servidor Linux, configurar SSL, configurar bases de datos, administrar Docker, verificar el estado del servicio, reiniciar un servicio, monitorear recursos o reanudar el trabajo en un servidor previamente configurado.
