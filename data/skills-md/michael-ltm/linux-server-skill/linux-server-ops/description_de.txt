Verwalten, bereitstellen und überwachen Sie Linux-Server über SSH. Wie ein BaoTa/1Panel, aber KI-gesteuert. Deckt Websites, Node.js/Java/Python/Go/PHP-Dienste, MySQL/PostgreSQL/Redis-Datenbanken, Docker-Container und Compose-Stacks, SSL-Zertifikate (automatische Ausstellung + automatische Erneuerung), Domänenbindung, Nginx-Verwaltung, WAF (ModSecurity+OWASP), Cron-Jobs, Firewall, Protokollverwaltung, Dateivorgänge, Benutzerverwaltung, Systemüberwachung und Backups ab. Alle Dienste werden beim Booten automatisch gestartet. Verwaltet einen serverseitigen Index und lokale Workspace-Snapshots für die sofortige Wiederaufnahme der Sitzung. Verwenden Sie diese Option, wenn der Benutzer eine Website oder einen Dienst bereitstellen, einen Linux-Server verwalten, SSL einrichten, Datenbanken konfigurieren, Docker verwalten, den Dienststatus überprüfen, einen Dienst neu starten, Ressourcen überwachen oder die Arbeit auf einem zuvor konfigurierten Server fortsetzen möchte.
