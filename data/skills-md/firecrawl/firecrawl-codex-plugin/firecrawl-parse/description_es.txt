Extraiga y convierta de manera eficiente el contenido de cualquier archivo local, como PDF, DOCX, DOC, ODT, RTF, XLSX, XLS o HTML, en un descuento limpio y bien formateado guardado en el disco. Utilice esta habilidad siempre que el usuario solicite analizar, leer o extraer información de un archivo en su computadora, incluidas frases como "analizar este PDF", "convertir este documento", "leer este archivo", "extraer texto de" o cuando se proporcione una ruta de archivo local (no una URL). Esta habilidad ofrece opciones avanzadas como generar resúmenes basados ​​en IA y responder preguntas basadas en el contenido del archivo. Prefiera esta herramienta a "scrape" cuando maneje archivos locales para ofrecer resultados precisos y estructurados para tareas posteriores.
