يمكنك التحكم في جلسة المتصفح المباشرة والتفاعل معها على أي صفحة مسروقة - انقر على الأزرار، واملأ النماذج، وتنقل التدفقات، واستخرج البيانات باستخدام مطالبات اللغة الطبيعية أو التعليمات البرمجية. يُستخدم عندما يحتاج المستخدم إلى التفاعل مع صفحة ويب بما يتجاوز عملية الاستخراج البسيطة: تسجيل الدخول إلى موقع، أو إرسال النماذج، أو النقر خلال ترقيم الصفحات، أو التعامل مع التمرير اللانهائي، أو التنقل في عملية الدفع متعددة الخطوات أو تدفقات المعالج، أو عند فشل عملية الاستخراج العادية لأن المحتوى خلف تفاعل JavaScript. مفيد أيضًا للتجريف المصادق عليه عبر الملفات الشخصية. مشغلات عند "التفاعل"، أو "النقر"، أو "ملء النموذج"، أو "تسجيل الدخول إلى"، أو "تسجيل الدخول"، أو "إرسال"، أو "مرقّم الصفحات"، أو "الصفحة التالية"، أو "التمرير اللانهائي"، أو "التفاعل مع الصفحة"، أو "الانتقال إلى"، أو "فتح جلسة"، أو "فشل الاستخراج".
