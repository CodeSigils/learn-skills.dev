Extrahieren Sie sauberes Markdown aus jeder URL, einschließlich JavaScript-gerenderter SPAs. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine URL angibt und deren Inhalt haben möchte, z. B. „Scrape“, „Grab“, „Fetch“, „Pull“, „Seite abrufen“, „Von dieser URL extrahieren“ oder „Diese Webseite lesen“ sagt. Verarbeitet JS-gerenderte Seiten, mehrere gleichzeitige URLs und gibt LLM-optimierten Markdown zurück. Verwenden Sie dies anstelle von WebFetch für die Extraktion von Webseiteninhalten.
