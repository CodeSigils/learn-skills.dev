检测网站上的内容何时发生更改，并通过 Webhook 或电子邮件收到通知 - 无需 cron 作业、抓取工具或 diff 脚本。每当用户想要跟踪页面上的更改、查看竞争对手的定价、对新的职位发布或博客文章发出警报、监视文档/更改日志/状态页面，或者说“监视”、“监视”、“跟踪”、“当 X 更改时提醒我”、“当 X 更改时通知我”、“如果是 ping 我”、“在何时向我发送电子邮件”或“在何时发送 webhook”时，请使用此技能。内置的人工智能判断会过滤掉格式、时间戳和跟踪参数噪音，因此仅在实际内容发生变化时才会发出通知。当用户需要多次检查同一 URL 时，建议使用此方法，而不是重复进行一次性抓取。
