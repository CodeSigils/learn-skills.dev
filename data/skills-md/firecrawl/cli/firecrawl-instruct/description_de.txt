Steuern Sie eine Live-Browsersitzung auf jeder gecrackten Seite und interagieren Sie mit ihr – klicken Sie auf Schaltflächen, füllen Sie Formulare aus, navigieren Sie durch Abläufe und extrahieren Sie Daten mithilfe von Eingabeaufforderungen oder Code in natürlicher Sprache. Ersetzt den alten Befehl firecrawl-browser. Verwenden Sie diese Option, wenn der Benutzer über einfaches Scraping hinaus mit einer Webseite interagieren muss: Anmelden bei einer Website, Senden von Formularen, Klicken durch Paginierung, Behandeln von unendlichem Scrollen, Navigieren durch mehrstufige Checkout- oder Assistentenabläufe oder wenn ein reguläres Scrapen fehlschlägt, weil der Inhalt hinter der JavaScript-Interaktion liegt. Auch nützlich für authentifiziertes Scraping über Profile. Wird ausgelöst bei „Browser“, „Anweisen“, „Klicken“, „Formular ausfüllen“, „Anmelden bei“, „Anmelden“, „Senden“, „Paginieren“, „Nächste Seite“, „Unendliches Scrollen“, „Mit der Seite interagieren“, „Navigieren zu“, „Sitzung öffnen“ oder „Scrapen fehlgeschlagen“.
