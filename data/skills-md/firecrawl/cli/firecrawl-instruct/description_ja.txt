スクレイピングされたページ上のライブ ブラウザ セッションを制御および操作します。ボタンをクリックし、フォームに入力し、フローを操作し、自然言語プロンプトまたはコードを使用してデータを抽出します。古い firecrawl-browser コマンドを置き換えます。ユーザーが単純なスクレイピングを超えて Web ページを操作する必要がある場合に使用します。サイトへのログイン、フォームの送信、ページネーションのクリック、無限スクロールの処理、複数ステップのチェックアウトまたはウィザード フローの操作、またはコンテンツが JavaScript インタラクションの背後にあるために通常のスクレイピングが失敗した場合です。プロファイルを介した認証済みスクレイピングにも役立ちます。 「ブラウザー」、「指示」、「クリック」、「フォームへの記入」、「ログイン」、「サインイン」、「送信」、「ページ分割」、「次のページ」、「無限スクロール」、「ページの操作」、「ナビゲート」、「セッションを開く」、または「スクレープ失敗」でトリガーされます。
