Estrai e converti in modo efficiente il contenuto di qualsiasi file locale, come PDF, DOCX, DOC, ODT, RTF, XLSX, XLS o HTML, in markdown puliti e ben formattati salvati su disco. Utilizza questa capacità ogni volta che l'utente richiede di analizzare, leggere o estrarre informazioni da un file sul proprio computer, comprese frasi come "analizzare questo PDF", "convertire questo documento", "leggi questo file", "estrai testo da" o quando viene fornito un percorso di file locale (non un URL). Questa competenza offre opzioni avanzate come la generazione di riepiloghi basati sull'intelligenza artificiale e la risposta a domande in base al contenuto del file. Preferisci questo strumento a "scrape" quando gestisci file locali per fornire output precisi e strutturati per le attività successive.
