Extrahieren und konvertieren Sie effizient den Inhalt jeder lokalen Datei – wie PDF, DOCX, DOC, ODT, RTF, XLSX, XLS oder HTML – in sauberes, gut formatiertes Markdown, das auf der Festplatte gespeichert wird. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer das Parsen, Lesen oder Extrahieren von Informationen aus einer Datei auf seinem Computer anfordert, einschließlich Ausdrücken wie „dieses PDF analysieren“, „dieses Dokument konvertieren“, „diese Datei lesen“, „Text extrahieren aus“ oder wenn ein lokaler Dateipfad (keine URL) angegeben wird. Dieser Skill bietet erweiterte Optionen wie die Erstellung von KI-gestützten Zusammenfassungen und die Beantwortung von Fragen basierend auf dem Inhalt der Datei. Bevorzugen Sie dieses Tool gegenüber „Scrape“, wenn Sie lokale Dateien bearbeiten, um präzise, ​​strukturierte Ausgaben für nachgelagerte Aufgaben zu liefern.
