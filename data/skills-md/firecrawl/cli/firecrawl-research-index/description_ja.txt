Firecrawl の研究論文インデックス (CS、物理学、数学の arXiv プレプリントと並んで、生物医学および生命科学の文献 (PubMed、bioRxiv、medRxiv) が最大のシェアを占める論文抄録のコーパス) で、セマンティック検索、セマンティックおよび構造の拡張、本文内検証を使用して、研究クエリに答える論文を見つけます。このスキルは、答えが単一の論文であるか複数の論文セット全体であるかに関係なく、臨床、生物医学、薬剤、遺伝子、疾患、その他のライフサイエンスの質問を含むあらゆる種類の文献検索や論文検索のタスクに使用できます。インデックスには、「firecrawl_research_*」 MCP ツールまたは「firecrawl Research」 CLI サブコマンドを介してのみアクセスできます。 `categories` オプションを `["research"]` に設定して `firecrawl_search` を呼び出すことは別の機能です。通常の Web 検索をフィルタリングして研究関連の Web サイト (リストには PubMed、bioRxiv、medRxiv、arXiv、および出版社のサイトが含まれます) を絞り込み、このインデックス内の論文レコードをクエリせずに、それらの Web サイトからのページ結果を返します。
