Contrôlez et interagissez avec une session de navigateur en direct sur n'importe quelle page récupérée : cliquez sur des boutons, remplissez des formulaires, parcourez les flux et extrayez des données à l'aide d'invites ou de code en langage naturel. À utiliser lorsque l'utilisateur a besoin d'interagir avec une page Web au-delà du simple scraping : se connecter à un site, soumettre des formulaires, cliquer sur une pagination, gérer un défilement infini, naviguer dans une caisse en plusieurs étapes ou dans des flux d'assistant, ou lorsqu'un scraping régulier a échoué parce que le contenu est derrière une interaction JavaScript. Également utile pour le scraping authentifié via des profils. Déclencheurs sur « interagir », « cliquer », « remplir le formulaire », « se connecter à », « se connecter », « soumettre », « paginé », « page suivante », « défilement infini », « interagir avec la page », « naviguer vers », « ouvrir une session » ou « échec du scrape ».
