Интегрируйте Firecrawl в код приложения всякий раз, когда продукту, агенту или рабочему процессу требуются веб-данные внутри приложения — веб-поиск, результаты поиска в реальном времени, очистка страниц, структурированное извлечение или взаимодействие с браузером. Используйте при создании любой функции, которой требуются данные из Интернета в коде, даже если пользователь не упоминает Firecrawl явно и описывает только нужные веб-данные, контент веб-сайта, поиск, очистку или взаимодействие в приложении. Триггер для запросов Firecrawl, сокращения «огненная девушка» и общих потребностей в веб-данных на уровне приложения, которые должны сопоставляться с `/scrape`, `/search` или `/interact`. Не используйте этот навык для одноразовых веб-задач только для терминала во время текущего сеанса; используйте для них `firecrawl/cli`.
