每当产品、代理或工作流程需要应用程序内的 Web 数据（Web 搜索、实时搜索结果、页面抓取、结构化提取或浏览器交互）时，请将 Firecrawl 集成到应用程序代码中。在构建任何需要代码中的 Web 数据的功能时使用，即使用户没有明确提及 Firecrawl，而仅描述了需要 Web 数据、网站内容、搜索、抓取或应用程序中的交互。触发 Firecrawl 请求、“fire girls”速记以及应映射到“/scrape”、“/search”或“/interact”的通用应用程序级 Web 数据需求。在当前会话期间，不要将此技能用于一次性的仅限终端的 Web 任务；使用 `firecrawl/cli` 来实现这些。
