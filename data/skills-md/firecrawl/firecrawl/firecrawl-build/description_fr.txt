Intégrez Firecrawl dans le code de l'application chaque fois qu'un produit, un agent ou un flux de travail a besoin de données Web dans l'application : recherche sur le Web, résultats de recherche en direct, scraping de page, extraction structurée ou interaction avec le navigateur. À utiliser lors de la création de toute fonctionnalité nécessitant des données Web dans le code, même si l'utilisateur ne mentionne pas explicitement Firecrawl et décrit uniquement les données Web souhaitées, le contenu du site Web, la recherche, le scraping ou l'interaction dans une application. Déclencheur pour les requêtes Firecrawl, le raccourci « fire girl » et les besoins génériques en matière de données Web au niveau de l'application qui doivent correspondre à « /scrape », « /search » ou « /interact ». N'utilisez pas cette compétence pour des tâches Web ponctuelles uniquement sur le terminal au cours de la session en cours ; utilisez `firecrawl/cli` pour ceux-là.
