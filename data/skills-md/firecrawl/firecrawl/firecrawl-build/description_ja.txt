製品、エージェント、またはワークフローがアプリ内の Web データ (Web 検索、ライブ検索結果、ページ スクレイピング、構造化抽出、ブラウザー操作など) を必要とする場合は常に、Firecrawl をアプリケーション コードに統合します。コード内で Web からのデータを必要とする機能を構築するときに使用します。これは、ユーザーが Firecrawl について明示的に言及しておらず、Web データ、Web サイトのコンテンツ、検索、スクレイピング、またはアプリケーションでのインタラクションが必要であることのみを説明している場合でも使用します。 Firecrawl リクエスト、「fire girl」の短縮表現、および「/scrape」、「/search」、または「/interact」にマップする必要がある一般的なアプリレベルの Web データ ニーズのトリガー。現在のセッション中に、このスキルを 1 回限りのターミナルのみの Web タスクに使用しないでください。これらには「firecrawl/cli」を使用してください。
