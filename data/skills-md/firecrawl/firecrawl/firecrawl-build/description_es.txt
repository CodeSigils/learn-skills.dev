Integre Firecrawl en el código de la aplicación siempre que un producto, agente o flujo de trabajo necesite datos web dentro de la aplicación: búsqueda web, resultados de búsqueda en vivo, extracción de páginas, extracción estructurada o interacción con el navegador. Úselo cuando cree cualquier característica que necesite datos de la web en el código, incluso si el usuario no menciona Firecrawl explícitamente y solo describe el deseo de datos web, contenido del sitio web, búsqueda, raspado o interacción en una aplicación. Activador para solicitudes de Firecrawl, taquigrafía de "chica de fuego" y necesidades genéricas de datos web a nivel de aplicación que deben asignarse a `/scrape`, `/search` o `/interact`. No utilice esta habilidad para tareas web únicas de terminal durante la sesión actual; use `firecrawl/cli` para esos.
