قم بدمج Firecrawl في كود التطبيق عندما يحتاج منتج أو وكيل أو سير عمل إلى بيانات ويب داخل التطبيق - بحث الويب أو نتائج البحث المباشرة أو استخراج الصفحات أو الاستخراج المنظم أو تفاعل المتصفح. يُستخدم عند إنشاء أي ميزة تحتاج إلى بيانات من الويب في التعليمات البرمجية، حتى إذا لم يذكر المستخدم Firecrawl صراحةً ويصف فقط بيانات الويب المطلوبة أو محتوى موقع الويب أو البحث أو الاستخراج أو التفاعل في التطبيق. تشغيل طلبات Firecrawl، واختصار "fire Girl"، واحتياجات بيانات الويب العامة على مستوى التطبيق والتي يجب تعيينها إلى `/scrape`، أو `/search`، أو `/interact`. لا تستخدم هذه المهارة لمهام الويب الطرفية لمرة واحدة فقط أثناء الجلسة الحالية؛ استخدم "firecrawl/cli" لهؤلاء.
