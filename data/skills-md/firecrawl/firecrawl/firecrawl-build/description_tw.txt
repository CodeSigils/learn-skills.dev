每當產品、代理或工作流程需要應用程式內的 Web 資料（Web 搜尋、即時搜尋結果、頁面抓取、結構化擷取或瀏覽器互動）時，請將 Firecrawl 整合到應用程式程式碼中。在建立任何需要程式碼中的 Web 資料的功能時使用，即使使用者沒有明確提及 Firecrawl，而僅描述了需要 Web 資料、網站內容、搜尋、抓取或應用程式中的互動。觸發 Firecrawl 請求、「fire girls」速記以及應對應到「/scrape」、「/search」或「/interact」的通用應用程式級 Web 資料需求。在目前會話期間，不要將此技能用於一次性的僅限終端的 Web 任務；使用 `firecrawl/cli` 來實現這些。
