Integrieren Sie Firecrawl in den Anwendungscode, wann immer ein Produkt, ein Agent oder ein Workflow Webdaten innerhalb der App benötigt – Websuche, Live-Suchergebnisse, Page Scraping, strukturierte Extraktion oder Browserinteraktion. Verwenden Sie diese Funktion, wenn Sie eine Funktion erstellen, die Daten aus dem Web im Code benötigt, auch wenn der Benutzer Firecrawl nicht explizit erwähnt und nur den Wunsch nach Webdaten, Website-Inhalten, Suche, Scraping oder Interaktion in einer Anwendung beschreibt. Auslöser für Firecrawl-Anfragen, die Abkürzung „Fire Girl“ und generische Webdatenanforderungen auf App-Ebene, die „/scrape“, „/search“ oder „/interact“ zugeordnet werden sollten. Verwenden Sie diesen Skill nicht für einmalige Webaufgaben, die nur auf das Terminal beschränkt sind, während der aktuellen Sitzung. Verwenden Sie dafür „firecrawl/cli“.
