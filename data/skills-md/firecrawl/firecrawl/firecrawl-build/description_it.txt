Integra Firecrawl nel codice dell'applicazione ogni volta che un prodotto, un agente o un flusso di lavoro necessita di dati Web all'interno dell'app: ricerca Web, risultati di ricerca in tempo reale, scraping di pagine, estrazione strutturata o interazione con il browser. Da utilizzare quando si creano funzionalità che necessitano di dati dal Web nel codice, anche se l'utente non menziona esplicitamente Firecrawl e descrive solo la richiesta di dati Web, contenuto del sito Web, ricerca, scraping o interazione in un'applicazione. Trigger per richieste Firecrawl, abbreviazione di "fire girl" ed esigenze generiche di dati web a livello di app che dovrebbero essere mappate a "/scrape", "/search" o "/interact". Non utilizzare questa competenza per attività Web una tantum eseguite solo su terminale durante la sessione corrente; usa `firecrawl/cli` per quelli.
