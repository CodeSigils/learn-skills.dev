Obtenga las credenciales de Firecrawl y la configuración del SDK en un proyecto. Úselo cuando una aplicación necesite `FIRECRAWL_API_KEY`, cuando un agente deba agregar Firecrawl a `.env`, cuando el usuario quiera autenticar Firecrawl para el código de la aplicación o cuando elija el primer SDK y documentos para una nueva integración de Firecrawl. Esta habilidad incluye su propio flujo de autenticación del navegador, por lo que no depende de la habilidad de incorporación del sitio web.
