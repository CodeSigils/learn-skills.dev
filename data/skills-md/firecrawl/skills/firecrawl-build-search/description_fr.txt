Intégrez Firecrawl `/search` dans le code produit et les workflows des agents. À utiliser lorsqu'une application nécessite une découverte avant l'extraction, lorsque la fonctionnalité démarre par une requête au lieu d'une URL, ou lorsque le système doit effectuer une recherche sur le Web et éventuellement hydrater le contenu des résultats.
