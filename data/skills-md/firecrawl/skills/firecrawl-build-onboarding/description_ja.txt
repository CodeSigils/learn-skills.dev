Firecrawl 認証情報と SDK セットアップをプロジェクトに取得します。アプリケーションが `FIRECRAWL_API_KEY` を必要とする場合、エージェントが Firecrawl を `.env` に追加する必要がある場合、ユーザーがアプリ コードに対して Firecrawl を認証したい場合、または新しい Firecrawl 統合用の最初の SDK とドキュメントを選択する場合に使用します。タスクが現在のセッション中のライブ Web 作業である場合は、代わりに `firecrawl/cli` に引き渡します。このスキルには独自のブラウザ認証フローが含まれているため、Web サイトのオンボーディング スキルには依存しません。
