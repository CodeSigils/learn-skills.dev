Obtenez les informations d'identification Firecrawl et la configuration du SDK dans un projet. À utiliser lorsqu'une application a besoin de `FIRECRAWL_API_KEY`, lorsqu'un agent doit ajouter Firecrawl à `.env`, lorsque l'utilisateur souhaite authentifier Firecrawl pour le code de l'application, ou lors du choix du premier SDK et de la première documentation pour une nouvelle intégration de Firecrawl. Si la tâche consiste en un travail Web en direct pendant la session en cours, confiez-la plutôt à « firecrawl/cli ». Cette compétence inclut son propre flux d'authentification de navigateur, elle ne dépend donc pas de la compétence d'intégration du site Web.
