Integrieren Sie Firecrawl „/scrape“ in den Produktcode für die Einzelseitenextraktion. Verwenden Sie diese Option, wenn eine App bereits über eine URL verfügt und Markdown, HTML, Links, Screenshots, Metadaten oder eine strukturierte Seitenausgabe benötigt. Bevorzugen Sie diese Fähigkeit gegenüber umfassenderen Crawling-Mustern, wenn die Funktion auf Seitenebene erfolgt.
