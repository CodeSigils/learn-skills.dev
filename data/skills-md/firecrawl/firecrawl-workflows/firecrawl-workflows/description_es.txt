Ejecute flujos de trabajo de Firecrawl centrados en resultados que produzcan resultados como informes de investigación, auditorías de SEO, informes de control de calidad, listas de clientes potenciales, bases de conocimientos, sistemas de diseño de sitios web y otros artefactos de datos web estructurados. Úselo cuando el usuario desee que Firecrawl complete un flujo de trabajo comercial, de marketing, de producto o creativo en lugar de simplemente extraer una página o integrar llamadas API en el código.
