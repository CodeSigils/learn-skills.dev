Esegui flussi di lavoro Firecrawl incentrati sui risultati che producono risultati finali come report di ricerca, audit SEO, report QA, elenchi di lead, basi di conoscenza, sistemi di progettazione di siti Web e altri artefatti strutturati di dati Web. Da utilizzare quando l'utente desidera che Firecrawl completi un flusso di lavoro aziendale, di marketing, di prodotto o creativo anziché limitarsi a raschiare una pagina o integrare chiamate API nel codice.
