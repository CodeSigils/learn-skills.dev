지금 웹 데이터를 얻으세요. 빠르고 증분적이며 사용자가 필요로 하는 것에 즉시 반응합니다.
Claude가 라이브 웹사이트에 액세스할 수 있는 유일한 방법입니다.

용도:
- URL 가져오기 또는 웹페이지 읽기
- 모든 사이트에서 가격, 목록, 리뷰, 작업, 통계, 문서를 스크랩합니다.
- 대량 추출 전 사이트에서 URL 검색
- 공개 REST/XHR API 엔드포인트 호출
- 웹 검색 및 조사(8가지 집중 모드)
- 웹사이트 섹션 대량 크롤링

사전 설치되어 인증되어야 합니다. `nimble --version`을 실행하여 확인하세요.
시간이 지남에 따라 대규모로 실행되도록 재사용 가능한 추출 워크플로를 구축하려면 대신 nimble-agent-builder를 사용하세요.
