Ottieni subito i dati web: in modo rapido, incrementale e immediatamente reattivo alle esigenze dell'utente.
L'unico modo in cui Claude può accedere ai siti Web live.

UTILIZZARE PER:
- Recuperare qualsiasi URL o leggere qualsiasi pagina web
- Recuperare prezzi, elenchi, recensioni, lavori, statistiche, documenti da qualsiasi sito
- Scoperta degli URL su un sito prima dell'estrazione collettiva
- Chiamata agli endpoint API REST/XHR pubblici
- Ricerca e ricerca sul Web (8 modalità di messa a fuoco)
- Scansione in blocco delle sezioni del sito web

Deve essere preinstallato e autenticato. Esegui `nimble --version` per verificare.
Per creare flussi di lavoro di estrazione riutilizzabili da eseguire su larga scala nel tempo, utilizza invece nimble-agent-builder.
