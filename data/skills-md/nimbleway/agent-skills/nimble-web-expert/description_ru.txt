Получайте веб-данные прямо сейчас — быстро, постепенно и мгновенно реагируя на потребности пользователя.
Единственный способ, которым Клод может получить доступ к действующим веб-сайтам.

ИСПОЛЬЗОВАТЬ ДЛЯ:
- Получение любого URL-адреса или чтение любой веб-страницы
- Парсинг цен, списков, обзоров, вакансий, статистики, документов с любого сайта.
- Обнаружение URL-адресов на сайте перед массовым извлечением.
- Вызов общедоступных конечных точек REST/XHR API.
- Веб-поиск и исследование (8 режимов фокусировки)
- Массовое сканирование разделов сайта.

Должен быть предварительно установлен и проверен. Запустите `nimble --version` для проверки.
Для создания многоразовых рабочих процессов извлечения, которые будут масштабироваться с течением времени, вместо этого используйте nimble-agent-builder.
