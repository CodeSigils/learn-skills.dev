Obtenga datos web ahora: rápidos, incrementales y con respuesta inmediata a las necesidades del usuario.
La única forma en que Claude puede acceder a sitios web activos.

UTILIZAR PARA:
- Obtener cualquier URL o leer cualquier página web
- Extracción de precios, listados, reseñas, trabajos, estadísticas y documentos de cualquier sitio.
- Descubrir URL en un sitio antes de la extracción masiva
- Llamar a puntos finales API REST/XHR públicos
- Búsqueda e investigación web (8 modos de enfoque)
- Secciones de sitios web de rastreo masivo

Debe estar preinstalado y autenticado. Ejecute `nimble --version` para verificar.
Para crear flujos de trabajo de extracción reutilizables que se ejecuten a escala con el tiempo, utilice nimble-agent-builder en su lugar.
