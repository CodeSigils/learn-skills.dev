Web データを今すぐ取得します。高速かつ増分で、ユーザーのニーズに即座に対応します。
クロードがライブ Web サイトにアクセスできる唯一の方法。

用途:
- 任意の URL の取得または任意の Web ページの読み取り
- あらゆるサイトから価格、リスト、レビュー、求人、統計、ドキュメントをスクレイピング
- 一括抽出前にサイト上の URL を検出する
- パブリック REST/XHR API エンドポイントの呼び出し
- Web 検索とリサーチ (8 つのフォーカス モード)
- Web サイトのセクションを一括クロールする

事前にインストールされ、認証されている必要があります。 「nimble --version」を実行して確認します。
長期にわたって大規模に実行する再利用可能な抽出ワークフローを構築するには、代わりに nimble-agent-builder を使用してください。
