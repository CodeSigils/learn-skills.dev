RouterOS /container-Subsystem zum Ausführen von OCI-Containern auf MikroTik-Geräten. Verwendung bei: Aktivieren von Containern auf RouterOS, Einrichten von VETH/Bridge-Netzwerken für Container, Verwalten des Containerlebenszyklus über CLI oder REST API, Erstellen von OCI-Images für RouterOS, Konfigurieren von Containerumgebungsvariablen, Beheben von Containerproblemen oder wenn der Benutzer RouterOS-Container, /container, VETH, Gerätemodus-Container oder MikroTik Docker erwähnt.
