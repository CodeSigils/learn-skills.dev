النظام الفرعي RouterOS /container لتشغيل حاويات OCI على أجهزة MikroTik. يُستخدم عندما: تمكين الحاويات على RouterOS، أو إعداد شبكة VETH/bridge للحاويات، أو إدارة دورة حياة الحاوية عبر CLI أو REST API، أو إنشاء صور OCI لنظام RouterOS، أو تكوين متغيرات بيئة الحاوية، أو استكشاف مشكلات الحاوية وإصلاحها، أو عندما يذكر المستخدم حاوية RouterOS، أو /container، أو VETH، أو حاوية وضع الجهاز، أو MikroTik Docker.
