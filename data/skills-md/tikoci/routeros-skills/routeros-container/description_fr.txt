Sous-système RouterOS /container pour exécuter des conteneurs OCI sur les appareils MikroTik. À utiliser lorsque : l'activation de conteneurs sur RouterOS, la configuration d'un réseau VETH/bridge pour les conteneurs, la gestion du cycle de vie des conteneurs via CLI ou l'API REST, la création d'images OCI pour RouterOS, la configuration des variables d'environnement de conteneur, le dépannage de problèmes de conteneur ou lorsque l'utilisateur mentionne le conteneur RouterOS, /container, VETH, conteneur en mode périphérique ou MikroTik Docker.
