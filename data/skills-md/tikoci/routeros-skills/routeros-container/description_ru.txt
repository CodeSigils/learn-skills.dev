Подсистема RouterOS/container для запуска OCI-контейнеров на устройствах MikroTik. Используйте при включении контейнеров в RouterOS, настройке сети VETH/bridge для контейнеров, управлении жизненным циклом контейнера через CLI или REST API, создании образов OCI для RouterOS, настройке переменных среды контейнера, устранении проблем с контейнером или когда пользователь упоминает контейнер RouterOS, /container, VETH, контейнер режима устройства или MikroTik Docker.
