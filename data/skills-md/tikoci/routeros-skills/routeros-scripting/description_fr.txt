Langage de script RouterOS et idiomes de configuration CLI pour les fichiers .rsc et les commandes interactives. À utiliser lorsque : l'écriture ou la révision de scripts RouterOS, d'extraits de planificateur/netwatch/sur événement, de configuration CLI idempotente, de syntaxe :local/:global/:foreach/:do, de sélecteurs [find], de gestion d'impression en tant que valeur, d'autorisations de script ou lorsque l'utilisateur mentionne .rsc, un script RouterOS, des astuces de script ou une automatisation de configuration CLI.
