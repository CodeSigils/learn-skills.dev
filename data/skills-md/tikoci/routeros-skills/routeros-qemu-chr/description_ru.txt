MikroTik RouterOS CHR (облачный маршрутизатор) с QEMU. Используйте при: запуске RouterOS в QEMU, загрузке образов CHR, отладке сбоев загрузки CHR, настройке устройств VirtIO для RouterOS, выборе между загрузкой SeaBIOS и UEFI, настройке переадресации портов QEMU для REST API RouterOS или выборе ускорения QEMU (KVM/HVF/TCG).
