MikroTik RouterOS CHR (routeur hébergé dans le cloud) avec QEMU. À utiliser lorsque : l'exécution de RouterOS dans QEMU, le démarrage d'images CHR, le débogage des échecs de démarrage CHR, la configuration de périphériques VirtIO pour RouterOS, le choix entre le démarrage SeaBIOS et UEFI, la configuration de la redirection de port QEMU pour l'API REST RouterOS ou la sélection de l'accélération QEMU (KVM/HVF/TCG).
