MikroTik RouterOS CHR (enrutador alojado en la nube) con QEMU. Úselo cuando: ejecute RouterOS en QEMU, inicie imágenes de CHR, depure fallas de inicio de CHR, configure dispositivos VirtIO para RouterOS, elija entre arranque SeaBIOS y UEFI, configure el reenvío de puertos QEMU para la API REST de RouterOS o seleccione la aceleración de QEMU (KVM/HVF/TCG).
