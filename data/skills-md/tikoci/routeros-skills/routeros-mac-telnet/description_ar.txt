تنسيق سلك بروتوكول MAC-Telnet (محطة MikroTik Layer-2/exec عبر UDP 20561)، ومصافحة الجلسة، ومصادقة MD5 + MTWEI (EC-SRP). يُستخدم عندما: تنفيذ أو تصحيح أخطاء عميل/خادم MAC-Telnet، أو الوصول إلى جهاز RouterOS عن طريق عنوان MAC بدون IP، أو تحليل حزم MAC-Telnet، أو فهم محطة L2 بنمط WinBox، أو الاختيار بين MD5 الكلاسيكي ومصادقة MTWEI الحديثة، أو عندما يذكر المستخدم MAC-Telnet، أو mactelnet، أو mactelnetd، أو المنفذ 20561، أو تسجيل الدخول إلى MTWEI/EC-SRP RouterOS.
