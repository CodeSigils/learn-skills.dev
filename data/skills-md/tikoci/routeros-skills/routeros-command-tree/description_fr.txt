Introspection de l'arbre de commandes RouterOS via l'API /console/inspect. À utiliser lors de : la création d'outils qui analysent les commandes RouterOS, la génération de schémas API à partir de RouterOS, l'utilisation de /console/inspect, le mappage de commandes CLI avec des verbes REST, la traversée de la hiérarchie des commandes RouterOS ou lorsque l'utilisateur mentionne inspecter, l'arborescence de commandes, RAML ou la génération OpenAPI pour RouterOS.
