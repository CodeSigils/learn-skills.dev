Самоанализ дерева команд RouterOS через /console/inspect API. Используйте при: создании инструментов, анализирующих команды RouterOS, создании схем API из RouterOS, работе с /console/inspect, сопоставлении команд CLI с глаголами REST, обходе иерархии команд RouterOS или когда пользователь упоминает проверку, дерево команд, RAML или генерацию OpenAPI для RouterOS.
