Introspezione dell'albero dei comandi di RouterOS tramite /console/inspect API. Da utilizzare quando: si creano strumenti che analizzano i comandi RouterOS, si generano schemi API da RouterOS, si lavora con /console/inspect, si mappano comandi CLI su verbi REST, si attraversa la gerarchia dei comandi RouterOS o quando l'utente menziona inspect, command tree, RAML o generazione OpenAPI per RouterOS.
