Знание предметной области RouterOS v7 для агентов ИИ. Используйте при: работе с MikroTik RouterOS, написании команд CLI/скрипта RouterOS, вызове REST API RouterOS, отладке причин сбоя команды Linux в RouterOS или когда пользователь упоминает пути MikroTik, RouterOS, CHR или /ip /system /interface. Область применения: только RouterOS 7.x (долгосрочная версия и новее) — версия 6 НЕ покрывается, и точность решения проблем с версией 6 будет низкой.
