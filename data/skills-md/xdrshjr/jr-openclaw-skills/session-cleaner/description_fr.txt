À utiliser lorsque l'utilisateur dit « fermer toutes les sessions », « effacer le contexte », « tuer tous les agents », « nettoyer les sessions », « tout réinitialiser », « 关掉所有子agent », « 清空上下文 », « 关闭所有session » ou des demandes de nettoyage similaires.
