Анализируйте график TradingView в реальном времени с помощью интерфейса командной строки Rust `tv`. Используйте, когда пользователю нужен обзор графиков, технический анализ, контекст котировок/OHLCV, значения исследования, настройка символа/таймфрейма, проверка видимого диапазона или подтверждение графиков с помощью скриншотов.
