Connaissance approfondie du développement Azure IoT, y compris les modèles d'architecture et de conception, ainsi que les modèles d'intégration et de codage. À utiliser lors de l'utilisation de MQTT, IoT Plug and Play, DPS/IoT Hub, de l'intégration SAP ERP ou d'architectures de référence IoT industrielles, ainsi que d'autres tâches de développement liées à Azure IoT. Pas pour Azure IoT Hub (utilisez azure-iot-hub), Azure IoT Edge (utilisez azure-iot-edge), Azure IoT Central (utilisez azure-iot-central), Azure Defender For Iot (utilisez azure-defender-for-iot).
