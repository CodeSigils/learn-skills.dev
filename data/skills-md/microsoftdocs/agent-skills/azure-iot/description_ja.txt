アーキテクチャと設計パターン、統合とコーディング パターンを含む、Azure IoT 開発の専門知識。 MQTT、IoT プラグ アンド プレイ、DPS/IoT ハブ、SAP ERP 統合、または産業用 IoT リファレンス アーキテクチャ、およびその他の Azure IoT 関連の開発タスクを使用する場合に使用します。 Azure IoT Hub (azure-iot-hub を使用)、Azure IoT Edge (azure-iot-edge を使用)、Azure IoT Central (azure-iot-central を使用)、Azure Defender For Iot (azure-defender-for-iot を使用) には使用できません。
