Conoscenza approfondita dello sviluppo IoT di Azure, inclusi modelli di architettura e progettazione, integrazioni e modelli di codifica. Da usare quando si usa MQTT, IoT Plug and Play, DPS/IoT Hub, integrazione SAP ERP o architetture di riferimento IoT industriale e altre attività di sviluppo correlate a Azure IoT. Non per l'hub IoT di Azure (usare azure-iot-hub), Azure IoT Edge (usare azure-iot-edge), Azure IoT Central (usare azure-iot-central), Azure Defender For Iot (usare azure-defender-for-iot).
