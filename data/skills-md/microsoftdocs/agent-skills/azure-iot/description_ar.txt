معرفة الخبراء بتطوير Azure IoT بما في ذلك أنماط الهندسة والتصميم والتكامل وأنماط الترميز. يُستخدم عند استخدام MQTT أو IoT Plug and Play أو DPS/IoT Hub أو تكامل SAP ERP أو البنى المرجعية لإنترنت الأشياء الصناعية ومهام التطوير الأخرى ذات الصلة بـ Azure IoT. ليس لـ Azure IoT Hub (استخدم azure-iot-hub)، وAzure IoT Edge (استخدم azure-iot-edge)، وAzure IoT Central (استخدم azure-iot-central)، وAzure Defender For Iot (استخدم azure-defender-for-iot).
