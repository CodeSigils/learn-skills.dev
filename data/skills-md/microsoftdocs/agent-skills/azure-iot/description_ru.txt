Экспертные знания по разработке Azure IoT, включая шаблоны архитектуры и проектирования, а также шаблоны интеграции и кодирования. Используйте при использовании MQTT, IoT Plug and Play, DPS/IoT Hub, интеграции SAP ERP или эталонных архитектур промышленного Интернета вещей, а также других задач разработки, связанных с Azure IoT. Не для Azure IoT Hub (используйте azure-iot-hub), Azure IoT Edge (используйте azure-iot-edge), Azure IoT Central (используйте azure-iot-central), Azure Defender для Iot (используйте azure-defender-for-iot).
