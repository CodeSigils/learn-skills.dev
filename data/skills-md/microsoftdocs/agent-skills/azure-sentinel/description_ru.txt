Экспертные знания для разработки Azure Sentinel, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при управлении соединителями Sentinel, правилами аналитики KQL, сборниками сценариев Logic Apps, данными UEBA/SAP или схемами ASIM, а также другими задачами разработки, связанными с Azure Sentinel. Не для Защитника Azure для облака (используйте azure-defender-for-cloud), Безопасность Azure (используйте azure-security), Azure Monitor (используйте azure-monitor), Наблюдатель за сетями Azure (используйте azure-network-watcher).
