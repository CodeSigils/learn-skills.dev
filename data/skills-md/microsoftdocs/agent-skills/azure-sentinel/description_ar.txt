معرفة الخبراء بتطوير Azure Sentinel بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إدارة موصلات Sentinel، أو قواعد تحليلات KQL، أو أدلة تشغيل Logic Apps، أو بيانات UEBA/SAP، أو مخططات ASIM، ومهام التطوير الأخرى ذات الصلة بـ Azure Sentinel. ليس لـ Azure Defender For Cloud (استخدم azure-defender-for-cloud)، وAzure Security (استخدم azure-security)، وAzure Monitor (استخدم azure-monitor)، وAzure Network Watcher (استخدم azure-network-watcher).
