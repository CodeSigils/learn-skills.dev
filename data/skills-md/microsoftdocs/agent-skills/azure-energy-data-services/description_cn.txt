Azure 能源数据服务开发的专业知识，包括故障排除、决策、体系结构和设计模式、安全性、配置、集成和编码模式以及部署。在配置 ADME 分区/CORS、管理 ACL/法律标签、部署地理空间 CZ/管理 UI 或调试清单提取以及其他 Azure 能源数据服务相关开发任务时使用。不适用于 Azure 数据资源管理器（使用 azure-data-explorer）、Azure Synapse Analytics（使用 azure-synapse-analytics）、Azure 数据工厂（使用 azure-data-factory）、Azure Databricks（使用 azure-databricks）。
