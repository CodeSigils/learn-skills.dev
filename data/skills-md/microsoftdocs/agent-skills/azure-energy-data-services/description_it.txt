Conoscenza approfondita dello sviluppo di Azure Energy Data Services, tra cui risoluzione dei problemi, processo decisionale, architettura e modelli di progettazione, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare durante la configurazione di partizioni ADME/CORS, la gestione di ACL/tag legali, la distribuzione di Geospatial CZ/interfaccia utente di amministrazione o il debug dell'inserimento di manifest e altre attività di sviluppo correlate a Azure Energy Data Services. Non per Azure Esplora dati (usare azure-data-explorer), Azure Synapse Analytics (usare azure-synapse-analytics), Azure Data Factory (usare azure-data-factory), Azure Databricks (usare azure-databricks).
