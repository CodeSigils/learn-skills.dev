Экспертные знания для разработки Azure Energy Data Services, включая устранение неполадок, принятие решений, шаблоны архитектуры и проектирования, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке разделов ADME/CORS, управлении списками управления доступом/юридическими тегами, развертывании Geospatial CZ/UI Admin или отладке приема манифеста, а также других задачах разработки, связанных с Azure Energy Data Services. Не для Azure Data Explorer (используйте azure-data-explorer), Azure Synapse Analytics (используйте azure-synapse-analytics), Azure Data Factory (используйте azure-data-factory), Azure Databricks (используйте azure-databricks).
