معرفة الخبراء بتطوير خدمات بيانات Azure Energy بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار وأنماط الهندسة والتصميم والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين أقسام ADME/CORS، أو إدارة قوائم ACL/العلامات القانونية، أو نشر Geospatial CZ/Admin UI، أو تصحيح أخطاء استيعاب البيان، ومهام التطوير الأخرى المتعلقة بخدمات Azure Energy Data Services. ليس لـ Azure Data Explorer (استخدم azure-data-explorer)، وAzure Synapse Analytics (استخدم azure-synapse-analytics)، وAzure Data Factory (استخدم azure-data-factory)، وAzure Databricks (استخدم azure-databricks).
