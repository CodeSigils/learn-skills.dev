Expertenwissen für die Entwicklung von Azure Energy Data Services, einschließlich Fehlerbehebung, Entscheidungsfindung, Architektur- und Designmuster, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird zum Konfigurieren von ADME-Partitionen/CORS, zum Verwalten von ACLs/zulässigen Tags, zum Bereitstellen von Geospatial CZ/Admin-Benutzeroberfläche oder zum Debuggen der Manifesterfassung und anderen Entwicklungsaufgaben im Zusammenhang mit Azure Energy Data Services verwendet. Nicht für Azure Data Explorer (verwenden Sie azure-data-explorer), Azure Synapse Analytics (verwenden Sie azure-synapse-analytics), Azure Data Factory (verwenden Sie azure-data-factory), Azure Databricks (verwenden Sie azure-databricks).
