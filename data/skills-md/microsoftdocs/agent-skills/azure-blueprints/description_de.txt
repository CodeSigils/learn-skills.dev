Expertenwissen für die Azure Blueprints-Entwicklung, einschließlich Fehlerbehebung, Architektur- und Designmuster, Sicherheit, Konfiguration sowie Integrationen und Codierungsmuster. Wird zum Definieren von Azure Blueprints, zum Zuordnen integrierter Compliance-Sets, zum Automatisieren über CLI/PowerShell/REST oder zum Beheben von Zuweisungsfehlern und anderen Entwicklungsaufgaben im Zusammenhang mit Azure Blueprints verwendet. Nicht für Azure Policy (verwenden Sie azure-policy), Azure Resource Manager (verwenden Sie azure-resource-manager), Azure Managed Applications (verwenden Sie azure-managed-applications), Azure Deployment Environments (verwenden Sie azure-deployment-environments).
