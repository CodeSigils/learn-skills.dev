Экспертные знания для разработки Azure Blueprints, включая устранение неполадок, шаблоны архитектуры и проектирования, безопасность, настройку, а также шаблоны интеграции и кодирования. Используйте при определении Azure Blueprints, сопоставлении встроенных наборов соответствия, автоматизации с помощью CLI/PowerShell/REST или исправлении ошибок назначения, а также других задачах разработки, связанных с Azure Blueprints. Не для Политики Azure (используйте azure-policy), Azure Resource Manager (используйте azure-resource-manager), управляемых приложений Azure (используйте приложения, управляемые azure), сред развертывания Azure (используйте azure-deployment-environments).
