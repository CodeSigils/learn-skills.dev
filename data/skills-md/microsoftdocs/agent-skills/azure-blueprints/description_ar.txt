معرفة الخبراء بتطوير Azure Blueprints بما في ذلك استكشاف الأخطاء وإصلاحها وأنماط الهندسة المعمارية والتصميم والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند تحديد Azure Blueprints، أو تعيين مجموعات الامتثال المضمنة، أو التشغيل الآلي عبر CLI/PowerShell/REST، أو إصلاح أخطاء التعيين، ومهام التطوير الأخرى ذات الصلة بـ Azure Blueprints. ليس لسياسة Azure (استخدم سياسة azure)، وAzure Resource Manager (استخدم azure-resource-manager)، وتطبيقات Azure المُدارة (استخدم تطبيقات azure المُدارة)، وبيئات نشر Azure (استخدم بيئات النشر azure).
