Conoscenza approfondita dello sviluppo di Azure Blueprints, tra cui risoluzione dei problemi, architettura e modelli di progettazione, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare durante la definizione di Azure Blueprints, la mappatura di set di conformità incorporati, l'automazione tramite CLI/PowerShell/REST o la correzione di errori di assegnazione e altre attività di sviluppo correlate ad Azure Blueprints. Non per criteri di Azure (usare azure-policy), Azure Resource Manager (usare azure-resource-manager), applicazioni gestite di Azure (usare azure-owned-applications), ambienti di distribuzione di Azure (usare azure-deployment-environments).
