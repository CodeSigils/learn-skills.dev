Connaissance approfondie du développement d'Azure Blueprints, y compris le dépannage, les modèles d'architecture et de conception, la sécurité, la configuration, ainsi que les intégrations et les modèles de codage. À utiliser lors de la définition d'Azure Blueprints, du mappage des ensembles de conformité intégrés, de l'automatisation via CLI/PowerShell/REST ou de la correction des erreurs d'affectation, ainsi que d'autres tâches de développement liées à Azure Blueprints. Pas pour Azure Policy (utilisez azure-policy), Azure Resource Manager (utilisez azure-resource-manager), Azure Managed Applications (utilisez azure-managed-applications), Azure Deployment Environments (utilisez azure-deployment-environments).
