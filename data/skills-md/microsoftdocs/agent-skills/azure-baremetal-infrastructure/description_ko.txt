Azure 대규모 인스턴스(azure-large-instances 사용), Azure Virtual Machines(azure-virtual-machines 사용), Azure Virtual Machine Scale Set(azure-vm-scalesets 사용), Azure 대규모 인스턴스의 SAP HANA(azure-sap 사용)에는 해당되지 않습니다.
