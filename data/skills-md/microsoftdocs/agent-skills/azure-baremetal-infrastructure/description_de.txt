Expertenwissen für die Entwicklung der Azure Baremetal-Infrastruktur, einschließlich Entscheidungsfindung sowie Architektur- und Designmuster. Verwenden Sie diese Option, wenn Sie NC2-Regionen/SKUs auswählen, BareMetal-Topologien planen oder NC2 in Azure-Netzwerke/-Dienste integrieren sowie für andere Entwicklungsaufgaben im Zusammenhang mit der Azure Baremetal-Infrastruktur. Nicht für Azure Large Instances (verwenden Sie azure-large-instances), Azure Virtual Machines (verwenden Sie azure-virtual-machines), Azure Virtual Machine Scale Sets (verwenden Sie azure-vm-scalesets), SAP HANA auf Azure Large Instances (verwenden Sie azure-sap).
