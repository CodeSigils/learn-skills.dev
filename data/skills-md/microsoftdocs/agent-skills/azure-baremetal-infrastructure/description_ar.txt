معرفة الخبراء بتطوير البنية التحتية Azure Baremetal بما في ذلك اتخاذ القرار وأنماط الهندسة المعمارية والتصميم. يُستخدم عند اختيار مناطق/وحدات SKU لـ NC2، أو تخطيط طبولوجيا BareMetal، أو دمج NC2 مع شبكات/خدمات Azure، ومهام التطوير الأخرى ذات الصلة بالبنية التحتية لـ Azure Baremetal. ليس لمثيلات Azure الكبيرة (استخدم مثيلات azure-large)، وأجهزة Azure الافتراضية (استخدم أجهزة azure الافتراضية)، ومجموعات مقياس الجهاز الظاهري Azure (استخدم مجموعات مقياس azure-vm)، وSAP HANA على مثيلات Azure الكبيرة (استخدم azure-sap).
