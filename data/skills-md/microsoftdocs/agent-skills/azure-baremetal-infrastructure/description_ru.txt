Экспертные знания в области разработки базовой инфраструктуры Azure, включая принятие решений, а также шаблоны архитектуры и проектирования. Используйте при выборе регионов/SKU NC2, планировании топологий BareMetal или интеграции NC2 с сетями и службами Azure, а также при выполнении других задач разработки, связанных с инфраструктурой Azure Baremetal. Не для крупных экземпляров Azure (используйте большие экземпляры Azure), виртуальных машин Azure (используйте виртуальные машины Azure), масштабируемых наборов виртуальных машин Azure (используйте azure-vm-scalesets), SAP HANA на крупных экземплярах Azure (используйте azure-sap).
