Conoscenza approfondita dello sviluppo dell'infrastruttura baremetal di Azure, inclusi processi decisionali e modelli di architettura e progettazione. Da utilizzare quando si scelgono aree/SKU NC2, si pianificano topologie BareMetal o si integra NC2 con reti/servizi di Azure e altre attività di sviluppo correlate all'infrastruttura Baremetal di Azure. Non per istanze large di Azure (usare azure-large-instances), macchine virtuali di Azure (usare azure-virtual-machines), set di scalabilità di macchine virtuali di Azure (usare azure-vm-scalesets), SAP HANA su istanze large di Azure (usare azure-sap).
