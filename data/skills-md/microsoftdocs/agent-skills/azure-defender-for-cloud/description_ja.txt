トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、デプロイなど、Azure Defender For Cloud 開発に関する専門知識。 Defender for Cloud を使用して VM/サーバー、AKS/コンテナー、SQL/ストレージ、CI/CD/DevOps、またはマルチクラウド (AWS/GCP) を保護する場合や、その他の Azure Defender For Cloud 関連の開発タスクを行う場合に使用します。 Azure Defender For Iot (azure-defender-for-iot を使用)、Azure DDos Protection (azure-ddos-protection を使用)、Azure Firewall (azure-firewall を使用)、Azure Security (azure-security を使用) には使用できません。
