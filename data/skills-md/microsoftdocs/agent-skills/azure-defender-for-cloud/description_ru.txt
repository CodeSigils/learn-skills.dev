Экспертные знания по разработке Azure Defender для облака, включая устранение неполадок, рекомендации, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при защите виртуальных машин/серверов, AKS/контейнеров, SQL/хранилища, CI/CD/DevOps или мультиоблачной среды (AWS/GCP) с помощью Защитника для облака и других задач разработки, связанных с Защитником Azure для облака. Не для Защитника Azure для Iot (используйте azure-defender-for-iot), Azure DDos Protection (используйте azure-ddos-protection), Брандмауэра Azure (используйте azure-firewall), Azure Security (используйте azure-security).
