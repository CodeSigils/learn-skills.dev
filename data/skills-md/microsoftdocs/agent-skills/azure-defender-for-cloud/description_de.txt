Expertenwissen für die Azure Defender For Cloud-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird zum Sichern von VMs/Servern, AKS/Containern, SQL/Storage, CI/CD/DevOps oder Multi-Cloud (AWS/GCP) mit Defender for Cloud und anderen Azure Defender For Cloud-bezogenen Entwicklungsaufgaben verwendet. Nicht für Azure Defender für IoT (verwenden Sie azure-defender-for-iot), Azure DDoS Protection (verwenden Sie azure-ddos-protection), Azure Firewall (verwenden Sie azure-firewall), Azure Security (verwenden Sie azure-security).
