Conoscenza approfondita dello sviluppo di Azure Defender For Cloud, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare per proteggere VM/server, AKS/contenitori, SQL/Storage, CI/CD/DevOps o multi-cloud (AWS/GCP) con Defender for Cloud e altre attività di sviluppo correlate ad Azure Defender For Cloud. Non per Azure Defender for Iot (usare azure-defender-for-iot), Protezione DDos di Azure (usare azure-ddos-protection), Firewall di Azure (usare azure-firewall), Sicurezza di Azure (usare azure-security).
