معرفة الخبراء بتطوير Azure Defender For Cloud بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تأمين الأجهزة الافتراضية/الخوادم، أو AKS/الحاويات، أو SQL/التخزين، أو CI/CD/DevOps، أو السحابة المتعددة (AWS/GCP) مع Defender for Cloud، ومهام التطوير الأخرى ذات الصلة بـ Azure Defender For Cloud. ليس لـ Azure Defender For Iot (استخدم azure-defender-for-iot)، وحماية Azure DDos (استخدم حماية azure-ddos)، وجدار حماية Azure (استخدم جدار الحماية azure)، وAzure Security (استخدم azure-security).
