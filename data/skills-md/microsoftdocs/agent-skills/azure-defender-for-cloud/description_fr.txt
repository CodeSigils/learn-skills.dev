Connaissance approfondie du développement d'Azure Defender For Cloud, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser pour sécuriser les machines virtuelles/serveurs, AKS/conteneurs, SQL/Storage, CI/CD/DevOps ou multi-cloud (AWS/GCP) avec Defender for Cloud et d'autres tâches de développement liées à Azure Defender For Cloud. Pas pour Azure Defender For IoT (utilisez azure-defender-for-iot), Azure DDos Protection (utilisez azure-ddos-protection), Azure Firewall (utilisez azure-firewall), Azure Security (utilisez azure-security).
