Azure Defender For Cloud 開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在使用 Defender for Cloud 保護 VM/伺服器、AKS/容器、SQL/儲存、CI/CD/DevOps 或多雲 (AWS/GCP) 以及其他 Azure Defender For Cloud 相關開發任務時使用。不適用於 Azure Defender For Iot（使用 azure-defender-for-iot）、Azure DDos 保護（使用 azure-ddos-protection）、Azure 防火牆（使用 azure-firewall）、Azure 安全（使用 azure-security）。
