문제 해결, 의사 결정, 한도 및 할당량, 보안, 구성, 통합 및 코딩 패턴, 배포를 포함한 Azure Static Web Apps 개발에 대한 전문 지식입니다. SWA API를 Azure DB에 연결하고, 사용자 지정 도메인/인증, CI/CD, 미리 보기 슬롯 또는 Front Door/CDN 및 기타 Azure Static Web Apps 관련 개발 작업을 구성할 때 사용합니다. Azure App Service(azure-app-service 사용), Azure Functions(azure-functions 사용), Azure Container Apps(azure-container-apps 사용), AKS(Azure Kubernetes Service)(azure-kubernetes-service 사용)에는 해당되지 않습니다.
