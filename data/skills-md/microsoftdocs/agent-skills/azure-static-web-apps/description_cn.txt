Azure 静态 Web 应用开发的专业知识，包括故障排除、决策、限制和配额、安全性、配置、集成和编码模式以及部署。在将 SWA API 连接到 Azure DB、配置自定义域/身份验证、CI/CD、预览插槽或 Front Door/CDN 以及其他与 Azure 静态 Web 应用相关的开发任务时使用。不适用于 Azure 应用服务（使用 azure-app-service）、Azure Functions（使用 azure-functions）、Azure 容器应用（使用 azure-container-apps）、Azure Kubernetes 服务 (AKS)（使用 azure-kubernetes-service）。
