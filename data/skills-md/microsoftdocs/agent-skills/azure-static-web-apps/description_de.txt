Expertenwissen für die Entwicklung von Azure Static Web Apps, einschließlich Fehlerbehebung, Entscheidungsfindung, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird verwendet, wenn Sie SWA-APIs mit Azure DBs verbinden, benutzerdefinierte Domänen/Authentifizierung, CI/CD, Vorschauslots oder Front Door/CDN konfigurieren und andere Entwicklungsaufgaben im Zusammenhang mit Azure Static Web Apps durchführen. Nicht für Azure App Service (Azure-App-Service verwenden), Azure Functions (Azure-Funktionen verwenden), Azure Container Apps (Azure-Container-Apps verwenden), Azure Kubernetes Service (AKS) (Azure-Kubernetes-Service verwenden).
