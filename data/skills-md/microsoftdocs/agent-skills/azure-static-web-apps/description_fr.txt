Connaissance approfondie du développement d'Azure Static Web Apps, y compris le dépannage, la prise de décision, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors du câblage des API SWA aux bases de données Azure, de la configuration de domaines/authentification personnalisés, de CI/CD, d'emplacements de prévisualisation ou de Front Door/CDN, ainsi que d'autres tâches de développement liées aux applications Web statiques Azure. Pas pour Azure App Service (utilisez azure-app-service), Azure Functions (utilisez azure-functions), Azure Container Apps (utilisez azure-container-apps), Azure Kubernetes Service (AKS) (utilisez azure-kubernetes-service).
