Azure 靜態 Web 應用開發的專業知識，包括故障排除、決策、限制和配額、安全性、配置、整合和編碼模式以及部署。在將 SWA API 連接到 Azure DB、設定自訂網域/驗證、CI/CD、預覽插槽或 Front Door/CDN 以及其他與 Azure 靜態 Web 應用程式相關的開發任務時使用。不適用於 Azure 應用程式服務（使用 azure-app-service）、Azure Functions（使用 azure-functions）、Azure 容器應用程式（使用 azure-container-apps）、Azure Kubernetes 服務 (AKS)（使用 azure-kubernetes-service）。
