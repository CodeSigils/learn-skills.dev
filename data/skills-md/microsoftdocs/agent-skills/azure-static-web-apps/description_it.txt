Conoscenza approfondita dello sviluppo di app Web statiche di Azure, tra cui risoluzione dei problemi, processo decisionale, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante il collegamento di API SWA a database di Azure, la configurazione di domini/autenticazione personalizzati, CI/CD, slot di anteprima o front door/CDN e altre attività di sviluppo correlate alle app Web statiche di Azure. Non per Servizio app di Azure (usare azure-app-service), Funzioni di Azure (usare azure-functions), App contenitore di Azure (usare azure-container-apps), Servizio Azure Kubernetes (AKS) (usare azure-kubernetes-service).
