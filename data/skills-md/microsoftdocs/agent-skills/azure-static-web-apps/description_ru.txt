Экспертные знания для разработки статических веб-приложений Azure, включая устранение неполадок, принятие решений, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при подключении API SWA к базам данных Azure, настройке пользовательских доменов/аутентификации, CI/CD, слотов предварительного просмотра или Front Door/CDN, а также других задач разработки, связанных со статическими веб-приложениями Azure. Не для Службы приложений Azure (используйте azure-app-service), Функций Azure (используйте azure-functions), Контейнерных приложений Azure (используйте azure-container-apps), Службы Azure Kubernetes (AKS) (используйте azure-kubernetes-service).
