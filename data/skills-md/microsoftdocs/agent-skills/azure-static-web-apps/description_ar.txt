معرفة الخبراء بتطوير تطبيقات الويب Azure Static بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند توصيل واجهات برمجة تطبيقات SWA بقواعد بيانات Azure، أو تكوين المجالات/المصادقة المخصصة، أو CI/CD، أو فتحات المعاينة، أو Front Door/CDN، ومهام التطوير الأخرى ذات الصلة بتطبيقات Azure Static Web Apps. ليس لخدمة Azure App (استخدم azure-app-service)، ووظائف Azure (استخدم وظائف azure)، وتطبيقات Azure Container (استخدم تطبيقات azure-container)، وخدمة Azure Kubernetes (AKS) (استخدم خدمة azure-kubernetes).
