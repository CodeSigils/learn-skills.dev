トラブルシューティング、ベスト プラクティス、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、デプロイメントなど、Azure Fluid Relay 開発に関する専門知識。 AzureClient、オーディエンス API、JWT 認証トークン、コンテナーの回復、静的 Web アプリのホスティング、およびその他の Azure Fluid Relay 関連の開発タスクを使用する場合に使用します。 Azure Web PubSub (azure-web-pubsub を使用)、Azure SignalR Service (azure-signalr-service を使用)、Azure Relay (azure-relay を使用)、Azure Service Bus (azure-service-bus を使用) には使用できません。
