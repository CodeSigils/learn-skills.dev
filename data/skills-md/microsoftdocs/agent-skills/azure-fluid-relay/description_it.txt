Conoscenza approfondita dello sviluppo di Azure Fluid Relay, tra cui risoluzione dei problemi, procedure consigliate, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usa AzureClient, API di pubblico, token di autenticazione JWT, ripristino di contenitori o hosting di app Web statiche e altre attività di sviluppo correlate a Azure Fluid Relay. Non per PubSub Web di Azure (usare azure-web-pubsub), Servizio Azure SignalR (usare azure-signalr-service), Inoltro di Azure (usare azure-relay), Bus di servizio di Azure (usare azure-service-bus).
