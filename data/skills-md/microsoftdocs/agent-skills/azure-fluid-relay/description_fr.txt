Connaissance approfondie du développement d'Azure Fluid Relay, y compris le dépannage, les meilleures pratiques, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'utilisation d'AzureClient, des API d'audience, des jetons d'authentification JWT, de la récupération de conteneur ou de l'hébergement d'applications Web statiques, ainsi que d'autres tâches de développement liées à Azure Fluid Relay. Pas pour Azure Web PubSub (utilisez azure-web-pubsub), Azure SignalR Service (utilisez azure-signalr-service), Azure Relay (utilisez azure-relay), Azure Service Bus (utilisez azure-service-bus).
