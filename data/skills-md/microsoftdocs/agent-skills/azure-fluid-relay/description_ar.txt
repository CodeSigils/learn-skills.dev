معرفة الخبراء بتطوير Azure Fluid Relay بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام AzureClient، أو واجهات برمجة تطبيقات الجمهور، أو الرموز المميزة لمصادقة JWT، أو استرداد الحاوية، أو استضافة تطبيقات الويب الثابتة، ومهام التطوير الأخرى ذات الصلة بـ Azure Fluid Relay. ليس لـ Azure Web PubSub (استخدم azure-web-pubsub)، وخدمة Azure SignalR (استخدم azure-signalr-service)، وAzure Relay (استخدم azure-relay)، وناقل خدمة Azure (استخدم ناقل خدمة azure).
