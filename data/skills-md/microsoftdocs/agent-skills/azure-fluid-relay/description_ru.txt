Экспертные знания для разработки Azure Fluid Relay, включая устранение неполадок, рекомендации, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании AzureClient, API-интерфейсов аудитории, токенов аутентификации JWT, восстановления контейнера или размещения статических веб-приложений, а также других задач разработки, связанных с Azure Fluid Relay. Не для Azure Web PubSub (используйте azure-web-pubsub), службы Azure SignalR (используйте azure-signalr-service), Azure Relay (используйте azure-relay), Azure Service Bus (используйте azure-service-bus).
