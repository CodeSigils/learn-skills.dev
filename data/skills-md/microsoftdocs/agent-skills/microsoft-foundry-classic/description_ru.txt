Экспертные знания для разработки Microsoft Foundry Classic (также известной как Azure AI Foundry classic), включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, шаблоны интеграции и кодирования, а также развертывание. Используйте при создании агентов Foundry, RAG/векторном поиске, вызове функций, аудио в реальном времени или точно настроенных моделях Azure OpenAI, а также других задачах разработки, связанных с Microsoft Foundry Classic. Не для Microsoft Foundry (используйте microsoft-foundry), Microsoft Foundry Local (используйте microsoft-foundry-local), Microsoft Foundry Tools (используйте microsoft-foundry-tools).
