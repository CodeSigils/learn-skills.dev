Microsoft Foundry Classic（又稱 Azure AI Foundry classic）開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在建立 Foundry 代理程式、RAG/向量搜尋、函數呼叫、即時音訊或微調的 Azure OpenAI 模型以及其他 Microsoft Foundry Classic 相關開發任務時使用。不適用於 Microsoft Foundry（使用 microsoft-foundry）、Microsoft Foundry Local（使用 microsoft-foundry-local）、Microsoft Foundry Tools（使用 microsoft-foundry-tools）。
