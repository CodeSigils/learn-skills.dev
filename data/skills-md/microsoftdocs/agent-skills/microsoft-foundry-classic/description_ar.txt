معرفة الخبراء بتطوير Microsoft Foundry Classic (المعروف أيضًا باسم Azure AI Foundry classic) بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إنشاء وكلاء Foundry، أو بحث RAG/المتجه، أو استدعاء الوظائف، أو الصوت في الوقت الفعلي، أو نماذج Azure OpenAI المضبوطة بدقة، ومهام التطوير الأخرى ذات الصلة بـ Microsoft Foundry Classic. ليس لـ Microsoft Foundry (استخدم microsoft-foundry)، وMicrosoft Foundry Local (استخدم microsoft-foundry-local)، وMicrosoft Foundry Tools (استخدم أدوات microsoft-foundry).
