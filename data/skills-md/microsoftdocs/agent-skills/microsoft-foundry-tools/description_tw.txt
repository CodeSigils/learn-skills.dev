Microsoft Foundry Tools（又稱 Azure AI 服務、Azure 認知服務）所開發的專業知識，包括最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置以及整合和編碼模式。在使用內容審查器、內容理解分析器、REST/.NET API、配額或安全性 Foundry 設定以及其他 Microsoft Foundry Tools 相關開發任務時使用。不適用於 Microsoft Foundry（使用 microsoft-foundry）、Microsoft Foundry Classic（使用 microsoft-foundry-classic）、Microsoft Foundry Local（使用 microsoft-foundry-local）。
