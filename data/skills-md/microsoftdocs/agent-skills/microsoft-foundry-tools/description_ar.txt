معرفة الخبراء بتطوير أدوات Microsoft Foundry (المعروفة أيضًا باسم خدمات Azure AI وخدمات Azure المعرفية) بما في ذلك أفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند استخدام Content Moderator، أو محللي فهم المحتوى، أو واجهات برمجة تطبيقات REST/.NET، أو الحصص، أو إعدادات Foundry الآمنة، ومهام التطوير الأخرى ذات الصلة بـ Microsoft Foundry Tools. ليس لـ Microsoft Foundry (استخدم Microsoft Foundry)، وMicrosoft Foundry Classic (استخدم Microsoft Foundry-classic)، وMicrosoft Foundry Local (استخدم Microsoft Foundry-local).
