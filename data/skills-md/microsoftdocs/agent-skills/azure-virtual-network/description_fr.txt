Connaissance approfondie du développement de réseaux virtuels Azure, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité et la configuration. À utiliser lors de la conception de réseaux virtuels, de NSG, de points de terminaison de service, d'appairage de réseaux virtuels, de passerelles VPN ou de passerelles Azure Firewall/NAT, ainsi que d'autres tâches de développement liées au réseau virtuel Azure. Pas pour Azure Networking (utilisez azure-networking), Azure Virtual Network Manager (utilisez azure-virtual-network-manager), Azure Virtual WAN (utilisez azure-virtual-wan), Azure VPN Gateway (utilisez azure-vpn-gateway).
