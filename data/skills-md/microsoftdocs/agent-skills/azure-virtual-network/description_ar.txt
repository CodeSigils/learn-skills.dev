معرفة الخبراء بتطوير Azure Virtual Network بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين. يُستخدم عند تصميم شبكات VNets، أو NSGs، أو نقاط نهاية الخدمة، أو VNet Peering، أو بوابات VPN، أو بوابات Azure Firewall/NAT، ومهام التطوير الأخرى ذات الصلة بشبكة Azure Virtual Network. ليس لشبكة Azure (استخدم شبكة azure)، وAzure Virtual Network Manager (استخدم azure-virtual-network-manager)، وAzure Virtual WAN (استخدم azure-virtual-wan)، وبوابة Azure VPN (استخدم بوابة azure-vpn).
