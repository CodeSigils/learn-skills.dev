Conoscenza approfondita dello sviluppo della rete virtuale di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza e configurazione. Da utilizzare durante la progettazione di reti virtuali, gruppi di rete, endpoint di servizio, peering di reti virtuali, gateway VPN o gateway Firewall/NAT di Azure e altre attività di sviluppo correlate alla rete virtuale di Azure. Non per Rete di Azure (usare azure-networking), Gestione rete virtuale di Azure (usare azure-virtual-network-manager), WAN virtuale di Azure (usare azure-virtual-wan), Gateway VPN di Azure (usare azure-vpn-gateway).
