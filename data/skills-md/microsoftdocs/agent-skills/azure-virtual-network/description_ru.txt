Экспертные знания по разработке виртуальной сети Azure, включая устранение неполадок, рекомендации, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность и настройку. Используйте при проектировании виртуальных сетей, групп безопасности сети, конечных точек служб, пиринга виртуальных сетей, VPN-шлюзов или шлюзов брандмауэра Azure/NAT, а также других задач разработки, связанных с виртуальной сетью Azure. Не для сетей Azure (используйте azure-networking), Azure Virtual Network Manager (используйте azure-virtual-network-manager), Azure Virtual WAN (используйте azure-virtual-wan), Azure VPN-шлюза (используйте azure-vpn-gateway).
