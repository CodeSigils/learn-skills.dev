معرفة الخبراء بتطوير Azure Operator Service Manager بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند إعداد CNFs/VNFs، وتصميم مجموعات التكوين، باستخدام العناصر المدعومة من ACR، أو الارتباط الخاص، أو AOSM CLI، ومهام التطوير الأخرى ذات الصلة بـ Azure Operator Service Manager. ليس لـ Azure Operator Insights (استخدم azure-operator-insights)، وAzure Operator Nexus (استخدم azure-operator-nexus)، وAzure Network Function Manager (استخدم azure-network-function-manager)، وAzure Networking (استخدم شبكة azure).
