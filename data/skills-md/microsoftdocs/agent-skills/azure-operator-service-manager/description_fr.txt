Connaissance approfondie du développement d'Azure Operator Service Manager, y compris le dépannage, les meilleures pratiques, la sécurité, la configuration, les intégrations et les modèles de codage. À utiliser lors de l'intégration de CNF/VNF, de la conception de groupes de configuration, de l'utilisation d'artefacts basés sur ACR, de Private Link ou d'AOSM CLI et d'autres tâches de développement liées à Azure Operator Service Manager. Pas pour Azure Operator Insights (utilisez azure-operator-insights), Azure Operator Nexus (utilisez azure-operator-nexus), Azure Network Function Manager (utilisez azure-network-function-manager), Azure Networking (utilisez azure-networking).
