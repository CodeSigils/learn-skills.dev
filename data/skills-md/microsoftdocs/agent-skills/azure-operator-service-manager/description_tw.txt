Azure Operator Service Manager 開發的專業知識，包括故障排除、最佳實務、安全性、設定以及整合和編碼模式。在加入 CNF/VNF、設計設定群組、使用 ACR 支援的專案、專用連結或 AOSM CLI 以及其他 Azure Operator Service Manager 相關開發任務時使用。不適用於 Azure Operator Insights（使用 azure-operator-insights）、Azure Operator Nexus（使用 azure-operator-nexus）、Azure Network Function Manager（使用 azure-network-function-manager）、Azure Networking（使用 azure-networking）。
