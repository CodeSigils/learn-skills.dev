문제 해결, 모범 사례, 보안, 구성, 통합 및 코딩 패턴을 포함한 Azure Operator Service Manager 개발에 대한 전문 지식입니다. CNF/VNF 온보딩, 구성 그룹 설계, ACR 지원 아티팩트, Private Link 또는 AOSM CLI 및 기타 Azure Operator Service Manager 관련 개발 작업을 사용할 때 사용합니다. Azure Operator Insights(azure-operator-insights 사용), Azure Operator Nexus(azure-operator-nexus 사용), Azure Network Function Manager(azure-network-function-manager 사용), Azure 네트워킹(azure-networking 사용)에는 적합하지 않습니다.
