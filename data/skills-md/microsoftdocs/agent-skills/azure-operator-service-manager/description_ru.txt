Экспертные знания для разработки Azure Operations Manager, включая устранение неполадок, рекомендации, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при подключении CNF/VNF, разработке групп конфигурации, использовании артефактов на основе ACR, Private Link или AOSM CLI, а также при выполнении других задач разработки, связанных с диспетчером служб операторов Azure. Не для Azure Operation Insights (используйте azure-operator-insights), Azure Оператор Nexus (используйте azure-operator-nexus), Azure Network Function Manager (используйте azure-network-function-manager), Azure Networking (используйте azure-networking).
