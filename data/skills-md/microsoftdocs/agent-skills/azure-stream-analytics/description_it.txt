Conoscenza approfondita dello sviluppo di Analisi di flusso di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare durante la creazione di processi con Hub eventi/Kafka, output Cosmos DB/SQL, integrazione ML/AML, IoT Edge o Power BI e altre attività di sviluppo correlate ad Analisi di flusso di Azure. Non per Azure Synapse Analytics (usare azure-synapse-analytics), Azure Data Factory (usare azure-data-factory), Hub eventi di Azure (usare azure-event-hubs), Azure Data Explorer (usare azure-data-explorer).
