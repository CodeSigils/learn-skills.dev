معرفة الخبراء لتطوير Azure Stream Analytics بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إنشاء وظائف باستخدام Event Hubs/Kafka، أو مخرجات Cosmos DB/SQL، أو تكامل ML/AML، أو IoT Edge، أو Power BI، ومهام التطوير الأخرى ذات الصلة بـ Azure Stream Analytics. ليس لـ Azure Synapse Analytics (استخدم azure-synapse-analytics)، وAzure Data Factory (استخدم azure-data-factory)، وAzure Event Hubs (استخدم azure-event-hubs)، وAzure Data Explorer (استخدم azure-data-explorer).
