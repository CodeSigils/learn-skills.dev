Connaissance approfondie du développement d'Azure Stream Analytics, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la création de tâches avec Event Hubs/Kafka, les sorties Cosmos DB/SQL, l'intégration ML/AML, IoT Edge ou Power BI et d'autres tâches de développement liées à Azure Stream Analytics. Pas pour Azure Synapse Analytics (utilisez azure-synapse-analytics), Azure Data Factory (utilisez azure-data-factory), Azure Event Hubs (utilisez azure-event-hubs), Azure Data Explorer (utilisez azure-data-explorer).
