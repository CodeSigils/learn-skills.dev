Экспертные знания для разработки Azure Stream Analytics, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при создании заданий с помощью Центров событий/Kafka, выходных данных Cosmos DB/SQL, интеграции ML/AML, IoT Edge или Power BI, а также других задач разработки, связанных с Azure Stream Analytics. Не для Azure Synapse Analytics (используйте azure-synapse-analytics), Azure Data Factory (используйте azure-data-factory), Центров событий Azure (используйте azure-event-hubs), Azure Data Explorer (используйте azure-data-explorer).
