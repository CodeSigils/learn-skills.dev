معرفة الخبراء بتطوير تطبيقات Azure المُدارة بما في ذلك الحدود والحصص والأمان والتكوين والنشر. يُستخدم عند تصميم واجهات مستخدم createUiDefinition، أو الوصول إلى JIT، أو الهويات المُدارة، أو Key Vault/CMK، أو StorageAccountSelector، أو عمليات نشر الكتالوج المستندة إلى Bicep، ومهام التطوير الأخرى ذات الصلة بتطبيقات Azure المُدارة. ليس لـ Azure Lighthouse (استخدم azure-lighthouse)، وAzure Partner Solutions (استخدم azure-partner-solutions)، وAzure Resource Manager (استخدم azure-resource-manager)، وAzure Blueprints (استخدم مخططات azure).
