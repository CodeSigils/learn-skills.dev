Экспертные знания по разработке управляемых приложений Azure, включая ограничения и квоты, безопасность, настройку и развертывание. Используйте при разработке пользовательских интерфейсов createUiDefinition, JIT-доступа, управляемых удостоверений, Key Vault/CMK, StorageAccountSelector или развертываний каталога на основе Bicep, а также других задач разработки, связанных с управляемыми приложениями Azure. Не для Azure Lighthouse (используйте azure-lighthouse), решений партнеров Azure (используйте azure-partner-solutions), Azure Resource Manager (используйте azure-resource-manager), Azure Blueprints (используйте azure-blueprints).
