Connaissance approfondie du développement d'applications gérées Azure, y compris les limites et quotas, la sécurité, la configuration et le déploiement. À utiliser lors de la conception d'interfaces utilisateur createUiDefinition, d'accès JIT, d'identités managées, de déploiements de Key Vault/CMK, StorageAccountSelector ou de catalogues basés sur Bicep, ainsi que d'autres tâches de développement liées aux applications managées Azure. Pas pour Azure Lighthouse (utilisez azure-lighthouse), Azure Partner Solutions (utilisez azure-partner-solutions), Azure Resource Manager (utilisez azure-resource-manager), Azure Blueprints (utilisez azure-blueprints).
