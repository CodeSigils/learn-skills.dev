معرفة الخبراء لتطوير Azure Translator بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام واجهات برمجة تطبيقات النصوص/المستندات الخاصة بالمترجم، أو النماذج المخصصة، أو المسارد، أو حاويات Docker، أو تدفقات Power Automate، ومهام التطوير الأخرى المتعلقة بـ Azure Translator. ليس للغة Azure AI (استخدم خدمة اللغة azure)، وAzure AI Speech (استخدم الكلام azure)، وAzure AI Immersive Reader (استخدم القارئ الشامل azure)، وAzure AI Search (استخدم البحث المعرفي azure).
