Экспертные знания для разработки Azure Translator, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании API-интерфейсов Переводчика текста и документов, пользовательских моделей, глоссариев, контейнеров Docker или потоков Power Automate, а также других задач разработки, связанных с Переводчиком Azure. Не для языка Azure AI (используйте azure-language-service), речи Azure AI (используйте azure-speech), иммерсивного средства чтения Azure AI (используйте azure-immersive-reader), поиска Azure AI (используйте azure-cognitive-search).
