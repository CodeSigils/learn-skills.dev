Connaissance approfondie du développement d'Azure Digital Twins, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la modélisation avec DTDL, de l'interrogation de graphiques jumeaux, de l'intégration de hub/fonctions IoT ou de la migration des API du plan de contrôle, ainsi que d'autres tâches de développement liées à Azure Digital Twins. Pas pour Azure IoT Hub (utilisez azure-iot-hub), Azure IoT Central (utilisez azure-iot-central), Azure IoT Edge (utilisez azure-iot-edge), Azure IoT Operations (utilisez azure-iot-opérations).
