Conoscenza approfondita dello sviluppo di gemelli digitali di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la modellazione con DTDL, l'esecuzione di query su grafici gemelli, l'integrazione di funzioni/hub IoT o la migrazione delle API del piano di controllo e altre attività di sviluppo correlate a Gemelli digitali di Azure. Non per l'hub IoT di Azure (usare azure-iot-hub), Azure IoT Central (usare azure-iot-central), Azure IoT Edge (usare azure-iot-edge), Azure IoT Operations (usare azure-iot-Operations).
