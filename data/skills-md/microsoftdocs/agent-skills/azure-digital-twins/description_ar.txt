معرفة الخبراء بتطوير Azure Digital Twins بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند النمذجة باستخدام DTDL، أو الاستعلام عن الرسوم البيانية المزدوجة، أو دمج مركز/وظائف IoT، أو ترحيل واجهات برمجة تطبيقات مستوى التحكم، ومهام التطوير الأخرى ذات الصلة بـ Azure Digital Twins. ليس لـ Azure IoT Hub (استخدم azure-iot-hub)، وAzure IoT Central (استخدم azure-iot-central)، وAzure IoT Edge (استخدم azure-iot-edge)، وعمليات Azure IoT (استخدم عمليات azure-iot).
