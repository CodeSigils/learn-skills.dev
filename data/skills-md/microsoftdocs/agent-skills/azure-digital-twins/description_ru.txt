Экспертные знания для разработки Azure Digital Twins, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при моделировании с помощью DTDL, запросе двойных графов, интеграции IoT Hub/функций или переносе API плоскости управления, а также при выполнении других задач разработки, связанных с Azure Digital Twins. Не для Azure IoT Hub (используйте azure-iot-hub), Azure IoT Central (используйте azure-iot-central), Azure IoT Edge (используйте azure-iot-edge), Azure IoT Operations (используйте azure-iot-operations).
