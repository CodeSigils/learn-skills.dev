Microsoft Foundry (別名 Azure AI Foundry) 開発に関する専門知識 (トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、展開など)。 Azure OpenAI、RAG/インデックス作成、MCP/OpenAPI ツール、評価ワークフロー、または CI/CD デプロイメントを使用して Foundry エージェントを構築する場合、およびその他の Microsoft Foundry 関連の開発タスクを構築する場合に使用します。 Microsoft Foundry Classic (microsoft-foundry-classic を使用)、Microsoft Foundry Local (microsoft-foundry-local を使用)、Microsoft Foundry Tools (microsoft-foundry-tools を使用) には対応しません。
