معرفة الخبراء بتطوير Microsoft Foundry (المعروف أيضًا باسم Azure AI Foundry) بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إنشاء وكلاء Foundry باستخدام Azure OpenAI، أو RAG/indexing، أو أدوات MCP/OpenAPI، أو سير عمل التقييم، أو عمليات نشر CI/CD، ومهام التطوير الأخرى ذات الصلة بـ Microsoft Foundry. ليس لـ Microsoft Foundry Classic (استخدم Microsoft Foundry-classic)، وMicrosoft Foundry Local (استخدم Microsoft Foundry-local)، وMicrosoft Foundry Tools (استخدم أدوات Microsoft Foundry).
