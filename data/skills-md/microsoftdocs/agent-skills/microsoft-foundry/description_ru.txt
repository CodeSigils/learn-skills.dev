Экспертные знания для разработки Microsoft Foundry (также известной как Azure AI Foundry), включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при создании агентов Foundry с помощью Azure OpenAI, RAG/индексирования, инструментов MCP/OpenAPI, рабочих процессов оценки или развертываний CI/CD, а также других задач разработки, связанных с Microsoft Foundry. Не для Microsoft Foundry Classic (используйте microsoft-foundry-classic), Microsoft Foundry Local (используйте microsoft-foundry-local), Microsoft Foundry Tools (используйте microsoft-foundry-tools).
