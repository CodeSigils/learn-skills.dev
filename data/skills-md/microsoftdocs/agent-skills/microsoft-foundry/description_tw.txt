Microsoft Foundry（又稱 Azure AI Foundry）開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在使用 Azure OpenAI、RAG/索引、MCP/OpenAPI 工具、評估工作流程或 CI/CD 部署以及其他 Microsoft Foundry 相關開發任務建置 Foundry 代理程式時使用。不適用於 Microsoft Foundry Classic（使用 microsoft-foundry-classic）、Microsoft Foundry Local（使用 microsoft-foundry-local）、Microsoft Foundry Tools（使用 microsoft-foundry-tools）。
