Conoscenza approfondita dello sviluppo di istanze large di Azure, tra cui risoluzione dei problemi, limiti e quote, integrazioni e modelli di codifica. Da utilizzare durante la configurazione di SKU Epic, il dimensionamento dei gruppi di volumi, l'ottimizzazione dell'archiviazione EHR o la risoluzione di problemi di connettività/perf Epic-ALI e altre attività di sviluppo correlate alle istanze di grandi dimensioni di Azure. Non per l'infrastruttura baremetal di Azure (usare azure-baremetal-infrastructure), macchine virtuali di Azure (usare azure-virtual-machines), set di scalabilità di macchine virtuali di Azure (usare azure-vm-scalesets), cache HPC di Azure (usare azure-hpc-cache).
