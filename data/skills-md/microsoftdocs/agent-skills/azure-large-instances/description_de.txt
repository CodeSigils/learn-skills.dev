Expertenwissen für die Entwicklung großer Azure-Instanzen, einschließlich Fehlerbehebung, Grenzwerte und Kontingente sowie Integrationen und Codierungsmuster. Verwenden Sie diese Option, wenn Sie Epic-SKUs konfigurieren, Volumengruppen dimensionieren, den EHR-Speicher optimieren oder Epic-ALI-Konnektivitäts-/Leistungsprobleme sowie andere Entwicklungsaufgaben im Zusammenhang mit Azure Large Instances lösen. Nicht für Azure Baremetal Infrastructure (verwenden Sie azure-baremetal-infrastructure), Azure Virtual Machines (verwenden Sie azure-virtual-machines), Azure Virtual Machine Scale Sets (verwenden Sie azure-vm-scalesets), Azure HPC Cache (verwenden Sie azure-hpc-cache).
