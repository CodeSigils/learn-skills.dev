Connaissance approfondie du développement d'Azure Large Instances, y compris le dépannage, les limites et quotas, ainsi que les intégrations et les modèles de codage. À utiliser lors de la configuration des SKU Epic, du dimensionnement des groupes de volumes, du réglage du stockage DSE ou de la résolution des problèmes de connectivité/perf Epic-ALI et d'autres tâches de développement liées à Azure Large Instances. Pas pour Azure Baremetal Infrastructure (utilisez azure-baremetal-infrastructure), les machines virtuelles Azure (utilisez azure-virtual-machines), les groupes de machines virtuelles identiques Azure (utilisez azure-vm-scalesets), Azure HPC Cache (utilisez azure-hpc-cache).
