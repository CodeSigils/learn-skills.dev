معرفة الخبراء بتطوير مثيلات Azure الكبيرة بما في ذلك استكشاف الأخطاء وإصلاحها والحدود والحصص والتكاملات وأنماط الترميز. يُستخدم عند تكوين وحدات SKU الخاصة بـ Epic، أو تغيير حجم مجموعات الحجم، أو ضبط تخزين السجلات الصحية الإلكترونية، أو حل مشكلات اتصال/أداء Epic-ALI، ومهام التطوير الأخرى ذات الصلة بمثيلات Azure الكبيرة. ليس للبنية التحتية Azure Baremetal (استخدم البنية التحتية azure-baremetal)، وأجهزة Azure الافتراضية (استخدم الأجهزة الافتراضية azure)، ومجموعات مقياس الجهاز الظاهري Azure (استخدم مجموعات مقياس azure-vm)، وذاكرة التخزين المؤقت لـ Azure HPC (استخدم ذاكرة التخزين المؤقت azure-hpc).
