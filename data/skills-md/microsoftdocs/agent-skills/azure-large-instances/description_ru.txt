Экспертные знания для разработки крупных экземпляров Azure, включая устранение неполадок, ограничения и квоты, а также интеграцию и шаблоны кодирования. Используйте при настройке номеров SKU Epic, определении размера групп томов, настройке хранилища EHR или решении проблем с подключением/производительностью Epic–ALI, а также при выполнении других задач разработки, связанных с крупными экземплярами Azure. Не для базовой инфраструктуры Azure (используйте azure-baremetal-infrastructure), виртуальных машин Azure (используйте azure-virtual-machines), масштабируемых наборов виртуальных машин Azure (используйте azure-vm-scalesets), кэша HPC Azure (используйте azure-hpc-cache).
