Conoscenza approfondita dello sviluppo di Azure Queue Storage, incluse procedure consigliate, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica. Da usare durante la gestione dell'autenticazione della coda (ID Entra/RBAC), il monitoraggio di parametri/log, l'ottimizzazione della velocità effettiva/limiti o la codifica con SDK e altre attività di sviluppo correlate ad Archiviazione code di Azure. Non per archiviazione BLOB di Azure (usare azure-blob-storage), archiviazione tabelle di Azure (usare azure-table-storage), bus di servizio di Azure (usare azure-service-bus), Hub eventi di Azure (usare azure-event-hubs).
