Экспертные знания по разработке хранилища очередей Azure, включая лучшие практики, ограничения и квоты, безопасность, конфигурацию, а также интеграцию и шаблоны кодирования. Используйте при управлении проверкой подлинности очереди (Entra ID/RBAC), мониторинге метрик/журналов, настройке пропускной способности/ограничений или кодировании с помощью пакетов SDK, а также других задачах разработки, связанных с хранилищем очередей Azure. Не для хранилища BLOB-объектов Azure (используйте azure-blob-storage), хранилища таблиц Azure (используйте azure-table-storage), служебной шины Azure (используйте azure-service-bus), концентраторов событий Azure (используйте azure-event-hubs).
