معرفة الخبراء بتطوير Azure Queue Storage بما في ذلك أفضل الممارسات والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند إدارة مصادقة قائمة الانتظار (Entra ID/RBAC)، أو مراقبة المقاييس/السجلات، أو ضبط الإنتاجية/الحدود، أو الترميز باستخدام مجموعات SDK، ومهام التطوير الأخرى ذات الصلة بتخزين Azure Queue. ليس مخصصًا لتخزين Azure Blob (استخدم azure-blob-storage)، وAzure Table Storage (استخدم azure-table-storage)، وناقل خدمة Azure (استخدم ناقل خدمة azure)، ومراكز أحداث Azure (استخدم مراكز أحداث azure).
