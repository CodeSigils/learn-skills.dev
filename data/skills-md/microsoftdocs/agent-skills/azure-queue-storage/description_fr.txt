Connaissance approfondie du développement d'Azure Queue Storage, y compris les meilleures pratiques, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage. À utiliser lors de la gestion de l'authentification de file d'attente (Entra ID/RBAC), de la surveillance des métriques/journaux, du réglage du débit/des limites ou du codage avec des SDK et d'autres tâches de développement liées à Azure Queue Storage. Pas pour Azure Blob Storage (utilisez azure-blob-storage), Azure Table Storage (utilisez azure-table-storage), Azure Service Bus (utilisez azure-service-bus), Azure Event Hubs (utilisez azure-event-hubs).
