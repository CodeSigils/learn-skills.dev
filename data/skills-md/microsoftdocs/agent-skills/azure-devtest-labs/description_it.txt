Conoscenza approfondita dello sviluppo di Azure DevTest Labs, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare durante la gestione di VM, immagini/artefatti di DevTest Labs, automazione ARM/CLI, sicurezza RBAC/Key Vault o configurazioni di lab hub-spoke e altre attività di sviluppo correlate ad Azure DevTest Labs. Non per Azure Dev Box (usare azure-dev-box), Azure Lab Services (usare azure-lab-services), Macchine virtuali di Azure (usare azure-virtual-machines), Desktop virtuale di Azure (usare azure-virtual-desktop).
