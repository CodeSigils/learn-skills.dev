Экспертные знания для разработки в Azure DevTest Labs, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при управлении виртуальными машинами DevTest Labs, изображениями/артефактами, автоматизацией ARM/CLI, безопасностью RBAC/Key Vault или настройками хаб-лабораторий, а также другими задачами разработки, связанными с Azure DevTest Labs. Не для Azure Dev Box (используйте azure-dev-box), Azure Lab Services (используйте azure-lab-services), виртуальных машин Azure (используйте azure-virtual-machines), виртуальных рабочих столов Azure (используйте azure-virtual-desktop).
