معرفة الخبراء بتطوير Azure DevTest Labs بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إدارة الأجهزة الافتراضية لـ DevTest Labs، أو الصور/المنتجات، أو أتمتة ARM/CLI، أو أمان RBAC/Key Vault، أو إعدادات المختبرات المحورية، ومهام التطوير الأخرى ذات الصلة بـ Azure DevTest Labs. ليس لـ Azure Dev Box (استخدم azure-dev-box)، وAzure Lab Services (استخدم azure-lab-services)، وأجهزة Azure الافتراضية (استخدم azure-virtual-machines)، وAzure Virtual Desktop (استخدم azure-virtual-desktop).
