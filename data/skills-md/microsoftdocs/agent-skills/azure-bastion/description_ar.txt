معرفة الخبراء بتطوير Azure Bastion بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند تكوين Bastion لمجموعات AKS الخاصة، ومجموعات مقياس VM، ومصادقة معرف Entra، وشبكات VNet المحور/المتحدثة، أو الوصول عبر VNet القائم على IP، ومهام التطوير الأخرى ذات الصلة بـ Azure Bastion. ليس لشبكة Azure الافتراضية (استخدم شبكة azure الافتراضية)، وأجهزة Azure الافتراضية (استخدم أجهزة azure الافتراضية)، وبوابة Azure VPN (استخدم بوابة azure-vpn)، وجدار حماية Azure (استخدم جدار الحماية azure).
