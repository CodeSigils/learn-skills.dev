Expertenwissen für die Azure Bastion-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration sowie Integrationen und Codierungsmuster. Verwenden Sie diese Option, wenn Sie Bastion für private AKS-Cluster, VM-Skalierungsgruppen, Entra-ID-Authentifizierung, Hub/Spoke-VNets oder IP-basierten Cross-VNet-Zugriff und andere Azure Bastion-bezogene Entwicklungsaufgaben konfigurieren. Nicht für Azure Virtual Network (verwenden Sie azure-virtual-network), Azure Virtual Machines (verwenden Sie azure-virtual-machines), Azure VPN Gateway (verwenden Sie azure-vpn-gateway), Azure Firewall (verwenden Sie azure-firewall).
