Azure Bastion 開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置以及整合和編碼模式。在為 AKS 專用群集、VM 規模集、Entra ID 驗證、中心/輻射 VNet 或基於 IP 的跨 VNet 存取以及其他 Azure Bastion 相關開發任務配置 Bastion 時使用。不適用於 Azure 虛擬網路（使用 azure-virtual-network）、Azure 虛擬機器（使用 azure-virtual-machines）、Azure VPN 閘道（使用 azure-vpn-gateway）、Azure 防火牆（使用 azure-firewall）。
