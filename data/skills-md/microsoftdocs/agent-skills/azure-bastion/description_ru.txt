Экспертные знания для разработки Azure Bastion, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при настройке Bastion для частных кластеров AKS, масштабируемых наборов виртуальных машин, аутентификации Entra ID, распределенных виртуальных сетей концентратора или распределенного доступа или доступа к нескольким виртуальным сетям на основе IP, а также других задач разработки, связанных с Azure Bastion. Не для виртуальной сети Azure (используйте azure-virtual-network), виртуальных машин Azure (используйте azure-virtual-machines), VPN-шлюза Azure (используйте azure-vpn-gateway), брандмауэра Azure (используйте azure-firewall).
