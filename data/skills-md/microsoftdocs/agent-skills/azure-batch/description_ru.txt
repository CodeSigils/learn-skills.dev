Экспертные знания для разработки пакетной службы Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке пулов/задач пакетной службы, автомасштабирования, контейнерных заданий, рабочих процессов SDK/CLI или рабочих нагрузок рендеринга/MPI, а также других задач разработки, связанных с пакетной службой Azure. Не для Azure HDInsight (используйте azure-hdinsight), Azure Databricks (используйте azure-databricks), Azure Kubernetes Service (AKS) (используйте azure-kubernetes-service), виртуальных машин Azure (используйте azure-virtual-machines).
