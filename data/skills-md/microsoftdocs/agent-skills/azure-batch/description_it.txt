Conoscenza approfondita dello sviluppo di Azure Batch, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la configurazione di pool/attività batch, scalabilità automatica, processi in contenitori, flussi di lavoro SDK/CLI o carichi di lavoro di rendering/MPI e altre attività di sviluppo correlate ad Azure Batch. Non per Azure HDInsight (usare azure-hdinsight), Azure Databricks (usare azure-databricks), Azure Kubernetes Service (AKS) (usare azure-kubernetes-service), Macchine virtuali di Azure (usare azure-virtual-machines).
