Expertenwissen für die Azure Batch-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird zum Konfigurieren von Batch-Pools/-Aufgaben, automatischer Skalierung, Containeraufträgen, SDK-/CLI-Workflows oder Render-/MPI-Workloads und anderen Azure Batch-bezogenen Entwicklungsaufgaben verwendet. Nicht für Azure HDInsight (verwenden Sie azure-hdinsight), Azure Databricks (verwenden Sie azure-databricks), Azure Kubernetes Service (AKS) (verwenden Sie azure-kubernetes-service), Azure Virtual Machines (verwenden Sie azure-virtual-machines).
