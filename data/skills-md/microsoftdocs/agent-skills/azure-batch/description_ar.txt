معرفة الخبراء بتطوير Azure Batch بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين مجمعات/مهام الدفعية، أو القياس التلقائي، أو المهام المعبأة في حاويات، أو سير عمل SDK/CLI، أو أحمال عمل العرض/MPI، ومهام التطوير الأخرى ذات الصلة بـ Azure Batch. ليس لـ Azure HDInsight (استخدم azure-hdinsight)، وAzure Databricks (استخدم azure-databricks)، وخدمة Azure Kubernetes (AKS) (استخدم خدمة azure-kubernetes)، وأجهزة Azure الافتراضية (استخدم الأجهزة الافتراضية azure).
