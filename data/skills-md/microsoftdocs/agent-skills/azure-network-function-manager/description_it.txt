Conoscenza approfondita dello sviluppo di Azure Network Function Manager, incluse sicurezza e configurazione. Da usare durante la configurazione di prerequisiti di NF Manager, gruppi di risorse, identità gestite, assegnazioni di ruoli o accesso NF sicuro e altre attività di sviluppo correlate a Gestione funzioni di rete di Azure. Non per Gestione firewall di Azure (usare azure-firewall-manager), Gestione rete virtuale di Azure (usare azure-virtual-network-manager), Rete virtuale di Azure (usare azure-virtual-network), WAN virtuale di Azure (usare azure-virtual-wan).
