معرفة الخبراء بتطوير Azure Network Function Manager بما في ذلك الأمان والتكوين. يُستخدم عند إعداد المتطلبات الأساسية لـ NF Manager، أو مجموعات الموارد، أو الهويات المُدارة، أو تعيينات الأدوار، أو الوصول الآمن إلى NF، ومهام التطوير الأخرى ذات الصلة بـ Azure Network Function Manager. ليس لـ Azure Firewall Manager (استخدم azure-firewall-manager)، وAzure Virtual Network Manager (استخدم azure-virtual-network-manager)، وAzure Virtual Network (استخدم azure-virtual-network)، وAzure Virtual WAN (استخدم azure-virtual-wan).
