보안 및 구성을 포함한 Azure Network Function Manager 개발에 대한 전문 지식입니다. NF Manager 필수 구성 요소, 리소스 그룹, 관리 ID, 역할 할당 또는 보안 NF 액세스 및 기타 Azure Network Function Manager 관련 개발 작업을 설정할 때 사용합니다. Azure Firewall Manager(azure-firewall-manager 사용), Azure Virtual Network Manager(azure-virtual-network-manager 사용), Azure Virtual Network(azure-virtual-network 사용), Azure Virtual WAN(azure-virtual-wan 사용)에는 해당되지 않습니다.
