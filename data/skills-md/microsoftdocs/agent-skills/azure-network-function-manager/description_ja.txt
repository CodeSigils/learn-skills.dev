セキュリティや構成を含む、Azure Network Function Manager 開発に関する専門知識。 NF Manager の前提条件、リソース グループ、マネージド ID、ロールの割り当て、安全な NF アクセス、およびその他の Azure Network Function Manager 関連の開発タスクを設定するときに使用します。 Azure Firewall Manager (azure-firewall-manager を使用)、Azure Virtual Network Manager (azure-virtual-network-manager を使用)、Azure Virtual Network (azure-virtual-network を使用)、Azure Virtual WAN (azure-virtual-wan を使用) には使用できません。
