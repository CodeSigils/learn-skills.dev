Connaissance approfondie du développement d'Azure Network Function Manager, y compris la sécurité et la configuration. À utiliser lors de la configuration des prérequis de NF Manager, des groupes de ressources, des identités managées, des attributions de rôles ou de l'accès NF sécurisé, ainsi que d'autres tâches de développement liées à Azure Network Function Manager. Pas pour Azure Firewall Manager (utilisez azure-firewall-manager), Azure Virtual Network Manager (utilisez azure-virtual-network-manager), Azure Virtual Network (utilisez azure-virtual-network), Azure Virtual WAN (utilisez azure-virtual-wan).
