Экспертные знания для разработки Azure Network Function Manager, включая безопасность и настройку. Используйте при настройке предварительных требований NF Manager, групп ресурсов, управляемых удостоверений, назначений ролей или безопасного доступа NF, а также других задач разработки, связанных с Azure Network Function Manager. Не для диспетчера брандмауэра Azure (используйте azure-firewall-manager), диспетчера виртуальной сети Azure (используйте azure-virtual-network-manager), виртуальной сети Azure (используйте azure-virtual-network), виртуальной глобальной сети Azure (используйте azure-virtual-wan).
