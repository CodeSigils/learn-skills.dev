Connaissance approfondie du développement d'Azure Firewall Manager, y compris les meilleures pratiques, la prise de décision, la sécurité et la configuration. À utiliser lors de la gestion des plans DDoS, des stratégies WAF, des règles de proxy DNS/FQDN, des groupes IP ou du hub virtuel sécurisé par rapport au réseau virtuel, ainsi que d'autres tâches de développement liées à Azure Firewall Manager. Pas pour Azure Firewall (utilisez Azure-firewall), Azure Virtual Network Manager (utilisez Azure-virtual-network-manager), Azure Network Function Manager (utilisez Azure-network-function-manager), Azure Networking (utilisez Azure-networking).
