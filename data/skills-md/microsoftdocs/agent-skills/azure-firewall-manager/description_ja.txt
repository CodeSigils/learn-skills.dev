ベスト プラクティス、意思決定、セキュリティ、構成など、Azure Firewall Manager 開発に関する専門知識。 DDoS プラン、WAF ポリシー、DNS プロキシ/FQDN ルール、IP グループ、またはセキュリティで保護された仮想ハブと VNet、およびその他の Azure Firewall Manager 関連の開発タスクを管理する場合に使用します。 Azure Firewall (azure-firewall を使用)、Azure Virtual Network Manager (azure-virtual-network-manager を使用)、Azure Network Function Manager (azure-network-function-manager を使用)、Azure Networking (azure-networking) には使用できません。
