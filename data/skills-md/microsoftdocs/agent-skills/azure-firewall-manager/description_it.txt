Conoscenza approfondita dello sviluppo di Azure Firewall Manager, comprese procedure consigliate, processo decisionale, sicurezza e configurazione. Da utilizzare durante la gestione di piani DDoS, criteri WAF, regole proxy DNS/FQDN, gruppi IP o hub virtuale protetto rispetto a VNet e altre attività di sviluppo correlate a Gestione firewall di Azure. Non per Firewall di Azure (usare azure-firewall), Gestione rete virtuale di Azure (usare azure-virtual-network-manager), Gestione funzioni di rete di Azure (usare azure-network-function-manager), Rete di Azure (usare azure-networking).
