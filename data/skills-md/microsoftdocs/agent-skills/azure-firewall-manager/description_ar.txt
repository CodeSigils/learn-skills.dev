معرفة الخبراء بتطوير Azure Firewall Manager بما في ذلك أفضل الممارسات واتخاذ القرار والأمان والتكوين. يُستخدم عند إدارة خطط DDoS، أو سياسات WAF، أو قواعد وكيل DNS/FQDN، أو مجموعات IP، أو المحور الظاهري الآمن مقابل VNet، ومهام التطوير الأخرى ذات الصلة بـ Azure Firewall Manager. ليس لجدار حماية Azure (استخدم جدار الحماية azure)، وAzure Virtual Network Manager (استخدم azure-virtual-network-manager)، ومدير وظائف شبكة Azure (استخدم azure-network-function-manager)، وشبكة Azure (استخدم شبكة azure).
