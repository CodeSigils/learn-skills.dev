Экспертные знания по разработке Azure Firewall Manager, включая лучшие практики, принятие решений, безопасность и настройку. Используйте при управлении планами DDoS, политиками WAF, правилами DNS-прокси/полного доменного имени, группами IP или защищенным виртуальным концентратором вместо виртуальной сети, а также другими задачами разработки, связанными с Azure Firewall Manager. Не для брандмауэра Azure (используйте azure-firewall), Azure Virtual Network Manager (используйте azure-virtual-network-manager), Azure Network Function Manager (используйте azure-network-function-manager), Azure Networking (используйте azure-networking).
