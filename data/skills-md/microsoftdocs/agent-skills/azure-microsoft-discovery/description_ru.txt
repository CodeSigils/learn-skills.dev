Экспертные знания для разработки Azure Microsoft Discovery, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при создании рабочих областей Discovery, общих сеансов, заданий суперкомпьютера, образов инструментов ACR или запросов Log Analytics, а также других задач разработки, связанных с Azure Microsoft Discovery. Не для Azure Resource Graph (используйте azure-resource-graph), Azure Portal (используйте azure-portal), Azure Monitor (используйте azure-monitor), Политики Azure (используйте azure-policy).
