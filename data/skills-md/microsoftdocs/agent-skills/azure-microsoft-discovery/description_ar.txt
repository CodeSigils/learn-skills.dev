معرفة الخبراء بتطوير Azure Microsoft Discovery بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إنشاء مساحات عمل Discovery أو الجلسات المشتركة أو وظائف الكمبيوتر العملاق أو صور أدوات ACR أو استعلامات Log Analytics ومهام التطوير الأخرى ذات الصلة بـ Azure Microsoft Discovery. ليس لـ Azure Resource Graph (استخدم azure-resource-graph)، وAzure Portal (استخدم azure-portal)، وAzure Monitor (استخدم azure-monitor)، وسياسة Azure (استخدم سياسة azure).
