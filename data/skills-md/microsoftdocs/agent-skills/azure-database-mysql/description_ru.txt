Экспертные знания для разработки базы данных Azure для MySQL, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при планировании MySQL Flexible Server HA/BCDR, развертываний CI/CD, виртуальной сети/частного канала, реплик чтения или подключения AKS, а также других задач разработки, связанных с базой данных Azure для MySQL. Не для базы данных Azure для MariaDB (используйте azure-database-mariadb), базы данных Azure для PostgreSQL (используйте azure-database-postgresql), базы данных SQL Azure (используйте azure-sql-database), Управляемого экземпляра SQL Azure (используйте azure-sql-managed-instance).
