Azure Database for MySQL 開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在規劃 MySQL 靈活伺服器 HA/BCDR、CI/CD 部署、VNet/專用連結、唯讀副本或 AKS 連線以及其他 Azure Database for MySQL 相關開發任務時使用。不適用於 Azure Database for MariaDB（使用 azure-database-mariadb）、Azure Database for PostgreSQL（使用 azure-database-postgresql）、Azure SQL 資料庫（使用 azure-sql-database）、Azure SQL 託管實例（使用 azure-sql-managed-instance）。
