문제 해결, 모범 사례, 의사 결정, 아키텍처 및 디자인 패턴, 제한 및 할당량, 보안, 구성, 통합 및 코딩 패턴, 배포를 포함한 Azure Database for MySQL 개발에 대한 전문 지식입니다. MySQL 유연한 서버 HA/BCDR, CI/CD 배포, VNet/Private Link, 읽기 복제본 또는 AKS 연결 및 기타 Azure Database for MySQL 관련 개발 작업을 계획할 때 사용합니다. Azure Database for MariaDB(azure-database-mariadb 사용), Azure Database for PostgreSQL(azure-database-postgresql 사용), Azure SQL Database(azure-sql-database 사용), Azure SQL Managed Instance(azure-sql-managed-instance 사용)에는 해당되지 않습니다.
