Conoscenza approfondita dello sviluppo di database di Azure per MySQL, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la pianificazione di HA/BCDR del server flessibile MySQL, distribuzioni CI/CD, collegamento VNet/privato, repliche di lettura o connettività AKS e altre attività di sviluppo correlate al database di Azure per MySQL. Non per il database di Azure per MariaDB (usare azure-database-mariadb), il database di Azure per PostgreSQL (usare azure-database-postgresql), il database SQL di Azure (usare azure-sql-database), l'istanza gestita SQL di Azure (usare azure-sql-built-instance).
