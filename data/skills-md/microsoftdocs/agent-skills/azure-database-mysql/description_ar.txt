معرفة الخبراء بقاعدة بيانات Azure لتطوير MySQL بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند التخطيط لعمليات نشر MySQL Elastic Server HA/BCDR أو CI/CD أو VNet/Private Link أو قراءة النسخ المتماثلة أو اتصال AKS وقاعدة بيانات Azure الأخرى لمهام التطوير ذات الصلة بـ MySQL. ليس لقاعدة بيانات Azure لـ MariaDB (استخدم azure-database-mariadb)، وقاعدة بيانات Azure لـ PostgreSQL (استخدم azure-database-postgresql)، وقاعدة بيانات Azure SQL (استخدم قاعدة بيانات azure-sql)، ومثيل Azure SQL المُدار (استخدم مثيل azure-sql المُدار).
