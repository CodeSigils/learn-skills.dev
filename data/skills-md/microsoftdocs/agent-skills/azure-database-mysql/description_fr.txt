Connaissance approfondie du développement d'Azure Database pour MySQL, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la planification du serveur flexible MySQL HA/BCDR, des déploiements CI/CD, du réseau virtuel/lien privé, des réplicas en lecture ou de la connectivité AKS, ainsi que d'autres tâches de développement liées à Azure Database pour MySQL. Pas pour Azure Database pour MariaDB (utilisez azure-database-mariadb), Azure Database pour PostgreSQL (utilisez azure-database-postgresql), Azure SQL Database (utilisez azure-sql-database), Azure SQL Managed Instance (utilisez azure-sql-managed-instance).
