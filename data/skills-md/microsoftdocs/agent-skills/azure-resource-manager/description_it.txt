Conoscenza approfondita dello sviluppo di Azure Resource Manager, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la creazione di modelli Bicep/ARM, utilizzando specifiche del modello, stack di distribuzione, pipeline CI/CD o ARM REST/CLI e altre attività di sviluppo correlate ad Azure Resource Manager. Non per Criteri di Azure (usare azure-policy), Azure Resource Graph (usare azure-resource-graph), Portale di Azure (usare azure-portal), Azure Blueprints (usare azure-blueprints).
