Экспертные знания для разработки Azure Resource Manager, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при разработке шаблонов Bicep/ARM, использовании спецификаций шаблонов, стеков развертывания, конвейеров CI/CD или ARM REST/CLI и других задач разработки, связанных с Azure Resource Manager. Не для Политики Azure (используйте azure-policy), Azure Resource Graph (используйте azure-resource-graph), Azure Portal (используйте azure-portal), Azure Blueprints (используйте azure-blueprints).
