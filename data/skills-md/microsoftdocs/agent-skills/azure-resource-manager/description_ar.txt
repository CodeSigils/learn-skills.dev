معرفة الخبراء لتطوير Azure Resource Manager بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تأليف قوالب Bicep/ARM، باستخدام مواصفات القالب، أو مجموعات النشر، أو خطوط أنابيب CI/CD، أو ARM REST/CLI، ومهام التطوير الأخرى ذات الصلة بـ Azure Resource Manager. ليس لسياسة Azure (استخدم سياسة azure)، وAzure Resource Graph (استخدم رسم بياني لموارد azure)، وAzure Portal (استخدم بوابة azure)، ومخططات Azure (استخدم مخططات azure).
