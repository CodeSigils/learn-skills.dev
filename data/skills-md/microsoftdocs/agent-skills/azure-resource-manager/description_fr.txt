Connaissance approfondie du développement d'Azure Resource Manager, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la création de modèles Bicep/ARM, à l'aide de spécifications de modèles, de piles de déploiement, de pipelines CI/CD ou ARM REST/CLI, ainsi que d'autres tâches de développement liées à Azure Resource Manager. Pas pour Azure Policy (utilisez azure-policy), Azure Resource Graph (utilisez azure-resource-graph), Azure Portal (utilisez azure-portal), Azure Blueprints (utilisez azure-blueprints).
