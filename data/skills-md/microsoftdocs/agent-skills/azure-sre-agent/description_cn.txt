Azure Sre Agent 开发的专业知识，包括故障排除、决策、限制和配额、安全性、配置、集成和编码模式以及部署。在将 SRE 代理连接到 DevOps/Teams/ServiceNow、配置工具/挂钩、查询 KQL 遥测或部署为 Teams 机器人以及其他与 Azure Sre Agent 相关的开发任务时使用。不适用于 Azure Monitor（使用 azure-monitor）、Azure Reliability（使用 azure-reliability）、Azure Resiliency（使用 azure-resiliency）、Azure 服务运行状况（使用 azure-service-health）。
