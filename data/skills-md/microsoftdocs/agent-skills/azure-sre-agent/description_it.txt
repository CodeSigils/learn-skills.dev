Conoscenza approfondita dello sviluppo dell'agente Azure Sre, tra cui risoluzione dei problemi, processo decisionale, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare quando si collega l'agente SRE a DevOps/Teams/ServiceNow, si configurano strumenti/hook, si eseguono query sulla telemetria KQL o si distribuisce come bot di Teams e altre attività di sviluppo correlate all'agente SRE di Azure. Non per Monitoraggio di Azure (usare azure-monitor), Affidabilità di Azure (usare azure-reliability), Resilienza di Azure (usare azure-resiliency), Integrità del servizio di Azure (usare azure-service-health).
