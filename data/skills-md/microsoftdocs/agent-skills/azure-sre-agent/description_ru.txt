Экспертные знания для разработки агента Azure Sre, включая устранение неполадок, принятие решений, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при подключении агента SRE к DevOps/Teams/ServiceNow, настройке инструментов/перехватчиков, запросе телеметрии KQL или развертывании в качестве бота Teams, а также при выполнении других задач разработки, связанных с агентом Azure Sre. Не для Azure Monitor (используйте azure-monitor), надежности Azure (используйте azure-reliability), устойчивости Azure (используйте azure-resiliency), работоспособности служб Azure (используйте azure-service-health).
