معرفة الخبراء بتطوير Azure Sre Agent بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند توصيل وكيل SRE بـ DevOps/Teams/ServiceNow، أو تكوين الأدوات/الخطافات، أو الاستعلام عن قياس KQL عن بعد، أو النشر كروبوت Teams، ومهام التطوير الأخرى ذات الصلة بـ Azure Sre Agent. ليس لـ Azure Monitor (استخدم azure-monitor)، وموثوقية Azure (استخدم موثوقية azure)، ومرونة Azure (استخدم مرونة azure)، وصحة خدمة Azure (استخدم azure-service-health).
