Conoscenza approfondita dello sviluppo di istanze gestite SQL di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usa MI Link, replica geografica/HA, autenticazione Kerberos/Entra, TDE/Key Vault o eventi estesi e altre attività di sviluppo correlate a Istanza gestita SQL di Azure. Non per il database SQL di Azure (usare azure-sql-database), SQL Server in macchine virtuali di Azure (usare azure-sql-virtual-machines), il database di Azure per MySQL (usare azure-database-mysql), il database di Azure per PostgreSQL (usare azure-database-postgresql).
