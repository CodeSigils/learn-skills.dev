Экспертные знания для разработки Управляемого экземпляра Azure SQL, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании MI Link, георепликации/HA, проверки подлинности Kerberos/Entra, TDE/Key Vault или расширенных событий, а также других задач разработки, связанных с Управляемым экземпляром SQL Azure. Не для базы данных SQL Azure (используйте azure-sql-database), SQL Server на виртуальных машинах Azure (используйте azure-sql-virtual-machines), базы данных Azure для MySQL (используйте azure-database-mysql), базы данных Azure для PostgreSQL (используйте azure-database-postgresql).
