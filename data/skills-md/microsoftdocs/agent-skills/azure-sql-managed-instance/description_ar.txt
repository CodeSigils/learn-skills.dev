معرفة الخبراء بتطوير مثيلات Azure SQL المُدارة بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام MI Link أو النسخ المتماثل الجغرافي/HA أو Kerberos/Entra auth أو TDE/Key Vault أو Extended Events ومهام التطوير الأخرى المتعلقة بمثيلات Azure SQL المُدارة. ليس لقاعدة بيانات Azure SQL (استخدم قاعدة بيانات azure-sql)، وSQL Server على أجهزة Azure الافتراضية (استخدم azure-sql-virtual-machines)، وقاعدة بيانات Azure لـ MySQL (استخدم azure-database-mysql)، وقاعدة بيانات Azure لـ PostgreSQL (استخدم azure-database-postgresql).
