Azure SQL 託管執行個體開發的專業知識，包括故障排除、最佳實務、決策、架構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在使用 MI Link、異地複製/HA、Kerberos/Entra auth、TDE/Key Vault 或擴充事件以及其他 Azure SQL 託管執行個體相關開發任務時使用。不適用於 Azure SQL 資料庫（使用 azure-sql-database）、Azure 虛擬機器上的 SQL Server（使用 azure-sql-virtual-machines）、Azure Database for MySQL（使用 azure-database-mysql）、Azure Database for forgreSQL（使用 greure-databasebase-postsql）。
