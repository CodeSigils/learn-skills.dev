Expertenwissen für die Entwicklung von Azure SQL Managed Instance, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Verwendung bei Verwendung von MI Link, Georeplikation/HA, Kerberos/Entra-Authentifizierung, TDE/Key Vault oder erweiterten Ereignissen und anderen Entwicklungsaufgaben im Zusammenhang mit Azure SQL Managed Instance. Nicht für Azure SQL-Datenbank (verwenden Sie azure-sql-database), SQL Server auf Azure Virtual Machines (verwenden Sie azure-sql-virtual-machines), Azure Database for MySQL (verwenden Sie azure-database-mysql), Azure Database for PostgreSQL (verwenden Sie azure-database-postgresql).
