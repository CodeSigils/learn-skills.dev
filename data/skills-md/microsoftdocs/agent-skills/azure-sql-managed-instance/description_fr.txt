Connaissance approfondie du développement d'Azure SQL Managed Instance, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'utilisation de MI Link, de géoréplication/HA, d'authentification Kerberos/Entra, de TDE/Key Vault ou d'événements étendus, ainsi que d'autres tâches de développement liées à Azure SQL Managed Instance. Pas pour Azure SQL Database (utilisez azure-sql-database), SQL Server sur les machines virtuelles Azure (utilisez azure-sql-virtual-machines), Azure Database pour MySQL (utilisez azure-database-mysql), Azure Database pour PostgreSQL (utilisez azure-database-postgresql).
