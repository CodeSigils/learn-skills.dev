معرفة الخبراء بتطوير Azure Cloud Shell بما في ذلك استكشاف الأخطاء وإصلاحها والحدود والحصص والأمان. يُستخدم عند تصحيح أخطاء تخزين/اتصال Cloud Shell، أو حدود الجلسة، أو حسابات التخزين المطلوبة، أو الوصول إلى VNet الخاص، ومهام التطوير الأخرى ذات الصلة بـ Azure Cloud Shell. ليس لـ Azure Portal (استخدم azure-portal)، وAzure Resource Manager (استخدم azure-resource-manager).
