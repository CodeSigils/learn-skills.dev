Экспертные знания по разработке Azure Cloud Shell, включая устранение неполадок, ограничения и квоты, а также безопасность. Используйте при отладке хранилища и подключения Cloud Shell, ограничений сеансов, необходимых учетных записей хранения или доступа к частной виртуальной сети, а также других задач разработки, связанных с Azure Cloud Shell. Не для портала Azure (используйте azure-portal), Azure Resource Manager (используйте azure-resource-manager).
