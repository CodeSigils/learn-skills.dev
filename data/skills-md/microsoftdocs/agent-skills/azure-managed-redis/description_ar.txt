معرفة الخبراء بتطوير Azure Managed Redis بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام مصادقة Entra، أو النسخ المتماثل الجغرافي، أو الاستمرارية، أو الارتباط الخاص، أو عمليات نشر ARM/Bicep، أو روابط وظائف Azure، ومهام التطوير الأخرى ذات الصلة بـ Azure Managed Redis. ليس لـ Azure Cache for Redis (استخدم azure-cache-redis).
