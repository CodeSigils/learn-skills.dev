Экспертные знания для разработки Redis, управляемой Azure, включая устранение неполадок, рекомендации, принятие решений, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании аутентификации Entra, георепликации, персистентности, Private Link, развертываний ARM/Bicep или привязок функций Azure, а также других задач разработки, связанных с Azure Managed Redis. Не для кэша Azure для Redis (используйте azure-cache-redis).
