Conoscenza approfondita dello sviluppo di Azure Managed Redis, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usano l'autenticazione Entra, la replica geografica, la persistenza, il collegamento privato, le distribuzioni ARM/Bicep o le associazioni di Funzioni di Azure e altre attività di sviluppo correlate ad Azure Managed Redis. Non per Cache di Azure per Redis (usare azure-cache-redis).
