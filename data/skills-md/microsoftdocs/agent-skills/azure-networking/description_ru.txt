Экспертные знания для разработки сетей Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, безопасность, а также интеграцию и шаблоны кодирования. Используйте при разработке узловых виртуальных сетей, правил брандмауэра Azure/NSG, WAF (App GW/Front Door), запросов ускоренной сети или графика ресурсов, а также других задач разработки, связанных с сетями Azure. Не для виртуальной сети Azure (используйте azure-virtual-network), Azure Virtual Network Manager (используйте azure-virtual-network-manager), Azure Virtual WAN (используйте azure-virtual-wan), Azure Network Watcher (используйте azure-network-watcher).
