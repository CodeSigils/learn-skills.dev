Conoscenza approfondita dello sviluppo della rete di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, sicurezza, integrazioni e modelli di codifica. Da usare durante la progettazione di reti virtuali hub-spoke, regole firewall di Azure/NSG, WAF (app GW/porta anteriore), query di rete accelerata o grafico delle risorse e altre attività di sviluppo correlate alla rete di Azure. Non per la rete virtuale di Azure (usare azure-virtual-network), Gestione rete virtuale di Azure (usare azure-virtual-network-manager), WAN virtuale di Azure (usare azure-virtual-wan), Azure Network Watcher (usare azure-network-watcher).
