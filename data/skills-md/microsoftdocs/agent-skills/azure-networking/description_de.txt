Expertenwissen für die Azure-Netzwerkentwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Sicherheit sowie Integrationen und Codierungsmuster. Wird beim Entwerfen von Hub-Spoke-VNets, Azure Firewall/NSG-Regeln, WAF (App GW/Front Door), Accelerated Networking oder Resource Graph-Abfragen und anderen Entwicklungsaufgaben im Zusammenhang mit Azure Networking verwendet. Nicht für Azure Virtual Network (verwenden Sie azure-virtual-network), Azure Virtual Network Manager (verwenden Sie azure-virtual-network-manager), Azure Virtual WAN (verwenden Sie azure-virtual-wan), Azure Network Watcher (verwenden Sie azure-network-watcher).
