معرفة الخبراء بتطوير Azure Networking بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والأمان والتكامل وأنماط الترميز. يُستخدم عند تصميم شبكات VNets ذات المتحدث المحوري، أو قواعد Azure Firewall/NSG، أو WAF (App GW/Front Door)، أو Accelerated Networking، أو استعلامات رسم الموارد، ومهام التطوير الأخرى ذات الصلة بشبكة Azure. ليس لشبكة Azure الافتراضية (استخدم azure-virtual-network)، وAzure Virtual Network Manager (استخدم azure-virtual-network-manager)، وAzure Virtual WAN (استخدم azure-virtual-wan)، وAzure Network Watcher (استخدم azure-network-watcher).
