Connaissance approfondie du développement de réseaux Azure, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, la sécurité, ainsi que les modèles d'intégration et de codage. À utiliser lors de la conception de réseaux virtuels hub-spoke, de règles de pare-feu Azure/NSG, de requêtes WAF (App GW/Front Door), de mise en réseau accélérée ou de Resource Graph, ainsi que d'autres tâches de développement liées au réseau Azure. Pas pour Azure Virtual Network (utilisez azure-virtual-network), Azure Virtual Network Manager (utilisez azure-virtual-network-manager), Azure Virtual WAN (utilisez azure-virtual-wan), Azure Network Watcher (utilisez azure-network-watcher).
