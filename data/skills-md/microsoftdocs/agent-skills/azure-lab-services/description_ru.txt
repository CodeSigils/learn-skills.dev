Экспертные знания для разработки Azure Lab Services, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке планов лабораторных занятий, шаблонов/расписаний виртуальных машин, лабораторий, интегрированных в виртуальную сеть, графического процессора/вложенной виртуализации или интеграции Canvas/Teams, а также других задач разработки, связанных со службами лабораторий Azure. Не для лабораторий Azure DevTest (используйте azure-devtest-labs), виртуальных машин Azure (используйте azure-virtual-machines), виртуальных рабочих столов Azure (используйте azure-virtual-desktop).
