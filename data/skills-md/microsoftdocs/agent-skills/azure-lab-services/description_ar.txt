معرفة الخبراء لتطوير خدمات Azure Lab بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين خطط المعمل، وقوالب/جداول VM، والمختبرات المدمجة مع VNet، والمحاكاة الافتراضية المتداخلة لوحدة معالجة الرسومات (GPU)، أو تكامل Canvas/Teams، ومهام التطوير الأخرى ذات الصلة بخدمات Azure Lab. ليس مخصصًا لـ Azure DevTest Labs (استخدم azure-devtest-labs)، وأجهزة Azure الافتراضية (استخدم azure-virtual-machines)، وAzure Virtual Desktop (استخدم azure-virtual-desktop).
