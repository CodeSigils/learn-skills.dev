Expertenwissen für die Entwicklung von Azure Lab Services, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird zum Konfigurieren von Laborplänen, VM-Vorlagen/-Zeitplänen, VNet-integrierten Laboren, GPU/verschachtelter Virtualisierung oder Canvas/Teams-Integration und anderen Azure Lab Services-bezogenen Entwicklungsaufgaben verwendet. Nicht für Azure DevTest Labs (verwenden Sie azure-devtest-labs), Azure Virtual Machines (verwenden Sie azure-virtual-machines), Azure Virtual Desktop (verwenden Sie azure-virtual-desktop).
