Экспертные знания для разработки Microsoft Planetary Computer Pro, включая устранение неполадок, принятие решений, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования. Используйте при управлении коллекциями STAC, приеме GeoCatalog, токенах SAS, визуализации Explorer или интеграции QGIS/ArcGIS, а также других задачах разработки, связанных с Microsoft Planetary Computer Pro. Не для открытых наборов данных Azure (используйте azure-open-datasets), Azure Maps (используйте azure-maps), Azure Data Explorer (используйте azure-data-explorer), Azure Synapse Analytics (используйте azure-synapse-analytics).
