معرفة الخبراء بتطوير Microsoft Planetary Computer Pro بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند إدارة مجموعات STAC، أو استيعاب GeoCatalog، أو رموز SAS، أو تصور Explorer، أو تكامل QGIS/ArcGIS، ومهام التطوير الأخرى ذات الصلة بـ Microsoft Planetary Computer Pro. ليس لمجموعات البيانات المفتوحة في Azure (استخدم مجموعات البيانات المفتوحة من azure)، وخرائط Azure (استخدم خرائط azure)، وAzure Data Explorer (استخدم مستكشف بيانات azure)، وتحليلات Azure Synapse (استخدم تحليلات azure-synapse).
