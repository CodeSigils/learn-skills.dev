Экспертные знания для разработки машинного обучения Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании рабочих пространств Azure ML, AutoML, Prompt Flow, онлайн-/пакетных конечных точек или развертываний SDK/CLI v2, а также других задач разработки, связанных с машинным обучением Azure. Не для Azure Databricks (используйте azure-databricks), Azure Synapse Analytics (используйте azure-synapse-analytics), виртуальных машин Azure Data Science (используйте azure-data-science-vm), Azure HDInsight (используйте azure-hdinsight).
