معرفة الخبراء بتطوير Azure Machine Learning بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام مساحات عمل Azure ML، أو AutoML، أو Prompt Flow، أو نقاط النهاية عبر الإنترنت/الدفعة، أو عمليات نشر SDK/CLI v2، ومهام التطوير الأخرى ذات الصلة بالتعلم الآلي من Azure. ليس مخصصًا لـ Azure Databricks (استخدم azure-databricks)، وAzure Synapse Analytics (استخدم تحليلات azure-synapse)، والأجهزة الظاهرية لـ Azure Data Science (استخدم azure-data-science-vm)، وAzure HDInsight (استخدم azure-hdinsight).
