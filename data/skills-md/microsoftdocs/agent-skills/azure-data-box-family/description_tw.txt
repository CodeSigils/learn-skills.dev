Azure Data Box 開發的專業知識，包括故障排除、最佳實踐、限制和配額、安全性、配置以及整合和編碼模式。在處理 Data Box/重型/磁碟佈線和複製流、blob 分層、Key Vault CMK、REST API 或 VHD 導入以及其他 Azure Data Box 相關開發任務時使用。不適用於 Azure 匯入匯出（使用 azure-import-export）、Azure Stack Edge（使用 azure-stack-edge）、Azure 虛擬機器（使用 azure-virtual-machines）、Azure Blob 儲存（使用 azure-blob-storage）。
