Conoscenza approfondita dello sviluppo di Azure Data Box, tra cui risoluzione dei problemi, procedure consigliate, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare durante la gestione del cablaggio e dei flussi di copia di Data Box/Pesante/Disco, della suddivisione in livelli BLOB, delle CMK di Key Vault, delle API REST o delle importazioni di VHD e di altre attività di sviluppo correlate ad Azure Data Box. Non per Azure Import Export (usare azure-import-export), Azure Stack Edge (usare azure-stack-edge), Macchine virtuali di Azure (usare azure-virtual-machines), Archiviazione BLOB di Azure (usare azure-blob-storage).
