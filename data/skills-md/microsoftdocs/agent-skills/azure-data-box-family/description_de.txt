Expertenwissen für die Azure Data Box-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Grenzwerte und Kontingente, Sicherheit, Konfiguration sowie Integrationen und Codierungsmuster. Wird bei der Handhabung von Data Box-/Heavy-/Disk-Verkabelungen und Kopierflüssen, Blob-Tiering, Key Vault CMKs, REST-APIs oder VHD-Importen und anderen Azure Data Box-bezogenen Entwicklungsaufgaben verwendet. Nicht für Azure Import Export (verwenden Sie azure-import-export), Azure Stack Edge (verwenden Sie azure-stack-edge), Azure Virtual Machines (verwenden Sie azure-virtual-machines), Azure Blob Storage (verwenden Sie azure-blob-storage).
