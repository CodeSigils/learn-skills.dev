Azure Data Box 开发的专业知识，包括故障排除、最佳实践、限制和配额、安全性、配置以及集成和编码模式。在处理 Data Box/重型/磁盘布线和复制流、blob 分层、Key Vault CMK、REST API 或 VHD 导入以及其他 Azure Data Box 相关开发任务时使用。不适用于 Azure 导入导出（使用 azure-import-export）、Azure Stack Edge（使用 azure-stack-edge）、Azure 虚拟机（使用 azure-virtual-machines）、Azure Blob 存储（使用 azure-blob-storage）。
