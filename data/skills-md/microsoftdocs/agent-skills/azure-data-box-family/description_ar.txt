معرفة الخبراء بتطوير Azure Data Box بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند التعامل مع كابلات Data Box/الثقيلة/القرصية وتدفقات النسخ، أو طبقات البيانات الثنائية الكبيرة، أو Key Vault CMKs، أو REST APIs، أو عمليات استيراد VHD، ومهام التطوير الأخرى ذات الصلة بـ Azure Data Box. ليس لـ Azure Import Export (استخدم azure-import-export)، وAzure Stack Edge (استخدم azure-stack-edge)، وأجهزة Azure الافتراضية (استخدم أجهزة azure الافتراضية)، وAzure Blob Storage (استخدم تخزين azure-blob).
