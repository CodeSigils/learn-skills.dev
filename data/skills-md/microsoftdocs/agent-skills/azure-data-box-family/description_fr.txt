Connaissance experte du développement Azure Data Box, y compris le dépannage, les meilleures pratiques, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage. À utiliser lors de la gestion des flux de câblage et de copie Data Box/Heavy/Disk, de la hiérarchisation des objets blob, des clés CMK Key Vault, des API REST ou des importations VHD et d'autres tâches de développement liées à Azure Data Box. Pas pour Azure Import Export (utilisez azure-import-export), Azure Stack Edge (utilisez azure-stack-edge), les machines virtuelles Azure (utilisez azure-virtual-machines), Azure Blob Storage (utilisez azure-blob-storage).
