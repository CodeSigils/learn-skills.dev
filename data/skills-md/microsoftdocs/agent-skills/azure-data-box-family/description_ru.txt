Экспертные знания для разработки Azure Data Box, включая устранение неполадок, рекомендации, ограничения и квоты, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при обработке кабелей Data Box/Heavy/Disk и потоках копирования, многоуровневом BLOB-объектах, Key Vault CMK, REST API или импорте VHD, а также других задачах разработки, связанных с Azure Data Box. Не для импорта и экспорта Azure (используйте azure-import-export), Azure Stack Edge (используйте azure-stack-edge), виртуальных машин Azure (используйте azure-virtual-machines), хранилища BLOB-объектов Azure (используйте azure-blob-storage).
