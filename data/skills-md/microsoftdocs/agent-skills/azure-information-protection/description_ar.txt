معرفة الخبراء لتطوير حماية البيانات في Azure بما في ذلك أفضل الممارسات واتخاذ القرار والتكوين والنشر. يُستخدم عند اختيار Azure RMS مقابل AD RMS، أو ترحيل المفاتيح/السياسات، أو تكوين موصل RMS/MSIPC، أو مراقبة سجلات RMS، ومهام التطوير الأخرى ذات الصلة بحماية معلومات Azure. ليس لـ Azure Key Vault (استخدم azure-key-vault)، وAzure Security (استخدم azure-security)، وAzure Defender For Cloud (استخدم azure-defender-for-cloud)، وAzure Sentinel (استخدم azure-sentinel).
