Connaissance experte du développement d’Azure Information Protection, y compris les meilleures pratiques, la prise de décision, la configuration et le déploiement. À utiliser lors du choix d'Azure RMS par rapport à AD RMS, de la migration de clés/stratégies, de la configuration du connecteur RMS/MSIPC ou de la surveillance des journaux RMS et d'autres tâches de développement liées à Azure Information Protection. Pas pour Azure Key Vault (utilisez azure-key-vault), Azure Security (utilisez azure-security), Azure Defender For Cloud (utilisez azure-defender-for-cloud), Azure Sentinel (utilisez azure-sentinel).
