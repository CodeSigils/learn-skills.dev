Экспертные знания по разработке Azure Information Protection, включая лучшие практики, принятие решений, настройку и развертывание. Используйте при выборе Azure RMS вместо AD RMS, переносе ключей/политик, настройке соединителя RMS/MSIPC или мониторинге журналов RMS, а также при выполнении других задач разработки, связанных с Azure Information Protection. Не для Azure Key Vault (используйте azure-key-vault), Azure Security (используйте azure-security), Azure Defender для облака (используйте azure-defender-for-cloud), Azure Sentinel (используйте azure-sentinel).
