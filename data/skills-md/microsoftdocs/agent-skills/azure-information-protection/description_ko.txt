모범 사례, 의사 결정, 구성 및 배포를 포함한 Azure Information Protection 개발에 대한 전문 지식입니다. Azure RMS와 AD RMS를 선택하고, 키/정책을 마이그레이션하고, RMS 커넥터/MSIPC를 구성하거나, RMS 로그를 모니터링하고, 기타 Azure Information Protection 관련 개발 작업을 수행할 때 사용합니다. Azure Key Vault(azure-key-vault 사용), Azure Security(azure-security 사용), Azure Defender For Cloud(azure-defender-for-cloud 사용), Azure Sentinel(azure-sentinel 사용)에는 적합하지 않습니다.
