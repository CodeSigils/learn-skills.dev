Conoscenza approfondita dello sviluppo di Azure Information Protection, incluse procedure consigliate, processo decisionale, configurazione e distribuzione. Da utilizzare quando si sceglie Azure RMS rispetto ad AD RMS, si esegue la migrazione di chiavi/criteri, si configura il connettore RMS/MSIPC o si monitorano i log RMS e altre attività di sviluppo correlate ad Azure Information Protection. Non per Azure Key Vault (usare azure-key-vault), Sicurezza di Azure (usare azure-security), Azure Defender For Cloud (usare azure-defender-for-cloud), Azure Sentinel (usare azure-sentinel).
