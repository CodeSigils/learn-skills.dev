Connaissance approfondie du développement d'Azure SQL Database, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors du choix de DTU/vCore/serverless/Hyperscale, de la configuration de la géoréplication/de la synchronisation des données ou de la sécurisation avec Entra/TDE et d'autres tâches de développement liées à Azure SQL Database. Pas pour Azure SQL Managed Instance (utilisez azure-sql-managed-instance), SQL Server sur les machines virtuelles Azure (utilisez azure-sql-virtual-machines), Azure Cosmos DB (utilisez azure-cosmos-db), Azure Database pour PostgreSQL (utilisez azure-database-postgresql).
