Expert knowledge for Azure SQL Database development including troubleshooting, best practices, decision making, architecture & design patterns, limits & quotas, security, configuration, integrations & coding patterns, and deployment. Используйте при выборе DTU/vCore/less/Hyperscale, настройке георепликации/синхронизации данных или обеспечении безопасности с помощью Entra/TDE, а также при выполнении других задач разработки, связанных с базой данных SQL Azure. Не для Управляемого экземпляра SQL Azure (используйте azure-sql-managed-instance), SQL Server на виртуальных машинах Azure (используйте azure-sql-virtual-machines), Azure Cosmos DB (используйте azure-cosmos-db), Базы данных Azure для PostgreSQL (используйте azure-database-postgresql).
