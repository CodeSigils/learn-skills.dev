トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、デプロイメントなど、Azure SQL Database 開発に関する専門知識。 DTU/仮想コア/サーバーレス/ハイパースケールの選択、地理レプリケーション/データ同期の構成、Entra/TDE によるセキュリティ保護、およびその他の Azure SQL Database 関連の開発タスクを行う場合に使用します。 Azure SQL Managed Instance (azure-sql-managed-instance を使用)、Azure Virtual Machines 上の SQL Server (azure-sql-virtual-machines を使用)、Azure Cosmos DB (azure-cosmos-db を使用)、Azure Database for PostgreSQL (azure-database-postgresql を使用) には適用されません。
