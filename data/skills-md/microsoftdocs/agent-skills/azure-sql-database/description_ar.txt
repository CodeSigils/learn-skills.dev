معرفة الخبراء بتطوير قاعدة بيانات Azure SQL بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند اختيار DTU/vCore/serverless/Hyperscale، أو تكوين النسخ المتماثل الجغرافي/مزامنة البيانات، أو التأمين باستخدام Entra/TDE، ومهام التطوير الأخرى ذات الصلة بقاعدة بيانات Azure SQL. ليس لمثيل Azure SQL المُدار (استخدم مثيل azure-sql-managed)، وSQL Server على أجهزة Azure الظاهرية (استخدم azure-sql-virtual-machines)، وAzure Cosmos DB (استخدم azure-cosmos-db)، وقاعدة بيانات Azure لـ PostgreSQL (استخدم azure-database-postgresql).
