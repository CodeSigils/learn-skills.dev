Conoscenza approfondita dello sviluppo del database SQL di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare quando si sceglie DTU/vCore/serverless/Hyperscale, si configura la replica geografica/sincronizzazione dei dati o si protegge con Entra/TDE e altre attività di sviluppo correlate al database SQL di Azure. Non per Istanza gestita SQL di Azure (usare azure-sql-built-instance), SQL Server in macchine virtuali di Azure (usare azure-sql-virtual-machines), Azure Cosmos DB (usare azure-cosmos-db), Database di Azure per PostgreSQL (usare azure-database-postgresql).
