Expertenwissen für die Entwicklung der Azure SQL-Datenbank, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Verwenden Sie diese Option, wenn Sie DTU/vCore/Serverless/Hyperscale auswählen, Georeplikation/Datensynchronisierung konfigurieren oder mit Entra/TDE sichern und andere Entwicklungsaufgaben im Zusammenhang mit Azure SQL-Datenbank ausführen. Nicht für Azure SQL Managed Instance (verwenden Sie azure-sql-managed-instance), SQL Server auf Azure Virtual Machines (verwenden Sie azure-sql-virtual-machines), Azure Cosmos DB (verwenden Sie azure-cosmos-db), Azure Database for PostgreSQL (verwenden Sie azure-database-postgresql).
