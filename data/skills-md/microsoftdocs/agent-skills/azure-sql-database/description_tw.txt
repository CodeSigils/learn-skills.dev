Azure SQL 資料庫開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在選擇 DTU/vCore/無伺服器/超大規模、配置異地複製/資料同步或使用 Entra/TDE 進行保護以及其他 Azure SQL 資料庫相關開發任務時使用。不適用於 Azure SQL 託管執行個體（使用 azure-sql-託管實例）、Azure 虛擬機器上的 SQL Server（使用 azure-sql-virtual-machines）、Azure Cosmos DB（使用 azure-cosmos-db）、Azure Database for forgreSQL（使用 azure-database-postgresql）。
