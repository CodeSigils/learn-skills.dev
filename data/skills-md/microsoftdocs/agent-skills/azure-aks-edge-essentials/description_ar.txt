معرفة الخبراء بتطوير Azure Kubernetes Service Edge Essentials بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إدارة مجموعات AKS Edge/Arc، أو اتصال Arc، أو أحمال عمل IoT/OPC/ONVIF، أو TPM/Key Vault، أو Azure Local، ومهام التطوير الأخرى ذات الصلة بـ Azure Kubernetes Service Edge Essentials. ليس لخدمة Azure Kubernetes (AKS) (استخدم azure-kubernetes-service)، وAzure IoT Edge (استخدم azure-iot-edge)، وAzure Stack Edge (استخدم azure-stack-edge)، وAzure Container Apps (استخدم تطبيقات azure-container).
