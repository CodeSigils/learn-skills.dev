Conoscenza approfondita dello sviluppo di Azure Kubernetes Service Edge Essentials, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare durante la gestione di cluster AKS Edge/Arc, connettività Arc, carichi di lavoro IoT/OPC/ONVIF, TPM/Key Vault o locale di Azure e altre attività di sviluppo correlate a Azure Kubernetes Service Edge Essentials. Non per il servizio Azure Kubernetes (AKS) (usare azure-kubernetes-service), Azure IoT Edge (usare azure-iot-edge), Azure Stack Edge (usare azure-stack-edge), App contenitore di Azure (usare azure-container-apps).
