Экспертные знания для разработки Azure Kubernetes Service Edge Essentials, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при управлении кластерами AKS Edge/Arc, подключением Arc, рабочими нагрузками IoT/OPC/ONVIF, TPM/Key Vault или Azure Local, а также другими задачами разработки, связанными с Azure Kubernetes Service Edge Essentials. Не для службы Azure Kubernetes (AKS) (используйте azure-kubernetes-service), Azure IoT Edge (используйте azure-iot-edge), Azure Stack Edge (используйте azure-stack-edge), приложений-контейнеров Azure (используйте azure-container-apps).
