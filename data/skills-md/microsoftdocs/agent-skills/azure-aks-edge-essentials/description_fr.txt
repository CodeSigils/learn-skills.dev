Connaissance approfondie du développement d'Azure Kubernetes Service Edge Essentials, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la gestion des clusters AKS Edge/Arc, de la connectivité Arc, des charges de travail IoT/OPC/ONVIF, TPM/Key Vault ou Azure Local et d'autres tâches de développement liées à Azure Kubernetes Service Edge Essentials. Pas pour Azure Kubernetes Service (AKS) (utilisez azure-kubernetes-service), Azure IoT Edge (utilisez azure-iot-edge), Azure Stack Edge (utilisez azure-stack-edge), Azure Container Apps (utilisez azure-container-apps).
