Azure Kubernetes Service Edge Essentials 開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在管理 AKS Edge/Arc 叢集、Arc 連線、IoT/OPC/ONVIF 工作負載、TPM/Key Vault 或 Azure Local 以及其他 Azure Kubernetes Service Edge Essentials 相關開發任務時使用。不適用於 Azure Kubernetes 服務 (AKS)（使用 azure-kubernetes-service）、Azure IoT Edge（使用 azure-iot-edge）、Azure Stack Edge（使用 azure-stack-edge）、Azure 容器應用程式（使用 azure-container-apps）。
