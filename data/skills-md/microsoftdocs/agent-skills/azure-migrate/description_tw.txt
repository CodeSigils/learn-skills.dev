Azure Migrate 開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。使用 AppCAT/CAST、Site Recovery REST API、Azure Migrate 裝置、基於 Arc 的探索或資源移動器以及其他 Azure Migrate 相關開發任務時使用。不適用於 Azure 資料庫遷移服務（使用 azure-database-migration）、Azure Site Recovery（使用 azure-site-recovery）、Azure 虛擬機器（使用 azure-virtual-machines）、Azure 虛擬機器上的 SQL Server（使用 azure-sql-virtual-machines）。
