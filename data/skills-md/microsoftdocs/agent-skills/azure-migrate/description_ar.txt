معرفة الخبراء بتطوير Azure Migrate بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام AppCAT/CAST، أو Site Recovery REST APIs، أو جهاز Azure Migrate، أو الاكتشاف المستند إلى Arc، أو Resource Mover، ومهام التطوير الأخرى ذات الصلة بـ Azure Migrate. ليس لخدمة ترحيل قاعدة بيانات Azure (استخدم ترحيل قاعدة بيانات azure)، واسترداد موقع Azure (استخدم azure-site-recovery)، وأجهزة Azure الافتراضية (استخدم أجهزة azure الافتراضية)، وSQL Server على أجهزة Azure الظاهرية (استخدم أجهزة azure-sql الافتراضية).
