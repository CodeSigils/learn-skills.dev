Экспертные знания для разработки Azure Migrate, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании AppCAT/CAST, API REST Site Recovery, устройства Azure Migrate, обнаружения на основе Arc или Resource Mover, а также других задач разработки, связанных с Azure Migrate. Не для службы миграции базы данных Azure (используйте azure-database-migration), Azure Site Recovery (используйте azure-site-recovery), виртуальных машин Azure (используйте azure-virtual-machines), SQL Server на виртуальных машинах Azure (используйте azure-sql-virtual-machines).
