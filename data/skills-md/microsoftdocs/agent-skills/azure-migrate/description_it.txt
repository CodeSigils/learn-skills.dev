Conoscenza approfondita dello sviluppo di Azure Migrate, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usano AppCAT/CAST, API REST di Site Recovery, l'appliance di Azure Migrate, l'individuazione basata su Arc o Resource Mover e altre attività di sviluppo correlate ad Azure Migrate. Non per il servizio Migrazione del database di Azure (usare azure-database-migration), Azure Site Recovery (usare azure-site-recovery), Macchine virtuali di Azure (usare azure-virtual-machines), SQL Server in Macchine virtuali di Azure (usare azure-sql-virtual-machines).
