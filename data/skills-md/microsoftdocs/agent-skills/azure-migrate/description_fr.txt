Connaissance experte du développement Azure Migrate, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'utilisation d'AppCAT/CAST, des API REST Site Recovery, de l'appliance Azure Migrate, de la découverte basée sur Arc ou de Resource Mover et d'autres tâches de développement liées à Azure Migrate. Pas pour le service Azure Database Migration (utilisez azure-database-migration), Azure Site Recovery (utilisez azure-site-recovery), les machines virtuelles Azure (utilisez azure-virtual-machines), SQL Server sur les machines virtuelles Azure (utilisez azure-sql-virtual-machines).
