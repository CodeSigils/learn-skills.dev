Expertenwissen für die Entwicklung von SQL Server auf Azure Virtual Machines, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Entwurfsmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird verwendet, wenn Sie SQL Server auf Azure-VMs mit Always On AG/FCI, WSFC, IaaS-Agent, Blob-Sicherungen oder Entra-Authentifizierung sowie andere Entwicklungsaufgaben im Zusammenhang mit SQL Server auf Azure Virtual Machines konfigurieren. Nicht für Azure SQL-Datenbank (verwenden Sie azure-sql-database), Azure SQL Managed Instance (verwenden Sie azure-sql-managed-instance), Azure Virtual Machines (verwenden Sie azure-virtual-machines), Azure Data Science Virtual Machines (verwenden Sie azure-data-science-vm).
