Conoscenza approfondita dello sviluppo di SQL Server su macchine virtuali di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la configurazione di SQL Server su macchine virtuali di Azure con Always On AG/FCI, WSFC, agente IaaS, backup BLOB o autenticazione Entra e altre attività di sviluppo correlate a SQL Server su macchine virtuali di Azure. Non per il database SQL di Azure (usare azure-sql-database), Istanza gestita SQL di Azure (usare azure-sql-activate-instance), Macchine virtuali di Azure (usare azure-virtual-machines), Macchine virtuali di Azure Data Science (usare azure-data-science-vm).
