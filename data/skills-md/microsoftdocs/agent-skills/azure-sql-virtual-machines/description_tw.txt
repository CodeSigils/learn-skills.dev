Azure 虛擬機器上的 SQL Server 開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在使用 Always On AG/FCI、WSFC、IaaS 代理程式、Blob 備份或 Entra auth 配置 Azure VM 上的 SQL Server 以及 Azure 虛擬機器上的其他 SQL Server 相關開發任務時使用。不適用於 Azure SQL 資料庫（使用 azure-sql-database）、Azure SQL 託管執行個體（使用 azure-sql-託管執行個體）、Azure 虛擬機器（使用 azure-virtual-machines）、Azure Data Science 虛擬機器（使用 azure-data-science-vm）。
