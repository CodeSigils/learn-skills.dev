Экспертные знания по разработке виртуальных машин SQL Server на Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке SQL Server на виртуальных машинах Azure с Always On AG/FCI, WSFC, агентом IaaS, резервными копиями BLOB-объектов или аутентификацией Entra, а также другими задачами разработки, связанными с SQL Server на виртуальных машинах Azure. Не для базы данных SQL Azure (используйте azure-sql-database), Управляемого экземпляра Azure SQL (используйте azure-sql-managed-instance), виртуальных машин Azure (используйте azure-virtual-machines), виртуальных машин Azure для обработки данных (используйте azure-data-science-vm).
