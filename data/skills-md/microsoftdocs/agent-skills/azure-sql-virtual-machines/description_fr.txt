Connaissance approfondie du développement de SQL Server sur des machines virtuelles Azure, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la configuration de SQL Server sur des machines virtuelles Azure avec Always On AG/FCI, WSFC, IaaS Agent, des sauvegardes Blob ou Entra Auth et d'autres tâches de développement liées à SQL Server sur des machines virtuelles Azure. Pas pour Azure SQL Database (utilisez azure-sql-database), Azure SQL Managed Instance (utilisez azure-sql-managed-instance), les machines virtuelles Azure (utilisez azure-virtual-machines), les machines virtuelles Azure Data Science (utilisez azure-data-science-vm).
