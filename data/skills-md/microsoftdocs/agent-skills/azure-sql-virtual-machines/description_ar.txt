معرفة الخبراء بـ SQL Server على تطوير Azure Virtual Machines بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين SQL Server على أجهزة Azure VMs مع Always On AG/FCI أو WSFC أو IaaS Agent أو النسخ الاحتياطية Blob أو مصادقة Entra ومهام التطوير ذات الصلة بـ SQL Server على أجهزة Azure الظاهرية. ليس لقاعدة بيانات Azure SQL (استخدم قاعدة بيانات azure-sql)، ومثيل Azure SQL المُدار (استخدم مثيل azure-sql المُدار)، وأجهزة Azure الافتراضية (استخدم أجهزة azure-virtual)، والأجهزة الظاهرية لعلوم بيانات Azure (استخدم azure-data-science-vm).
