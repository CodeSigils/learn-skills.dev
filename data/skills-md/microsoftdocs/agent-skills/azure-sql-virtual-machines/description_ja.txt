Azure Virtual Machines 上の SQL Server 開発に関する専門知識 (トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、展開など)。 Always On AG/FCI、WSFC、IaaS エージェント、BLOB バックアップ、または Entra 認証を使用して Azure VM 上の SQL Server を構成する場合、および Azure Virtual Machines 上のその他の SQL Server 関連の開発タスクを構成する場合に使用します。 Azure SQL Database (azure-sql-database を使用)、Azure SQL Managed Instance (azure-sql-managed-instance を使用)、Azure Virtual Machines (azure-virtual-machines を使用)、Azure Data Science Virtual Machines (azure-data-science-vm を使用) には適用されません。
