문제 해결, 모범 사례, 의사 결정, 아키텍처 및 디자인 패턴, 제한 및 할당량, 보안, 구성, 통합 및 코딩 패턴, 배포를 포함한 Azure Virtual Machines 개발의 SQL Server에 대한 전문 지식입니다. Always On AG/FCI, WSFC, IaaS 에이전트, Blob 백업 또는 Entra 인증을 사용하여 Azure VM에서 SQL Server를 구성하고 Azure Virtual Machines 관련 개발 작업의 기타 SQL Server를 구성할 때 사용합니다. Azure SQL Database(azure-sql-database 사용), Azure SQL Managed Instance(azure-sql-managed-instance 사용), Azure Virtual Machines(azure-virtual-machines 사용), Azure Data Science Virtual Machines(azure-data-science-vm 사용)에는 해당되지 않습니다.
