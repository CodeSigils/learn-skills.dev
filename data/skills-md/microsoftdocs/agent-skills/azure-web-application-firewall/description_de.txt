Expertenwissen für die Entwicklung der Azure Web Application Firewall, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Verwenden Sie diese Option, wenn Sie WAF-Regeln für Front Door/App Gateway, Ratenbeschränkungen, Bot/CAPTCHA, Sentinel-Protokollierung oder IaC-Bereitstellungen sowie andere Entwicklungsaufgaben im Zusammenhang mit Azure Web Application Firewall konfigurieren. Nicht für Azure Application Gateway (verwenden Sie azure-application-gateway), Azure Front Door (verwenden Sie azure-front-door), Azure Firewall (verwenden Sie azure-firewall), Azure DDos Protection (verwenden Sie azure-ddos-protection).
