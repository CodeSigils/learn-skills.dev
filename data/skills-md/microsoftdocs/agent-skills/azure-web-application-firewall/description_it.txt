Conoscenza approfondita dello sviluppo di Azure Web Application Firewall, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare durante la configurazione di regole WAF front door/app gateway, limiti di velocità, bot/CAPTCHA, registrazione Sentinel o distribuzioni IaC e altre attività di sviluppo correlate al firewall applicazione Web di Azure. Non per il gateway applicazione di Azure (usare azure-application-gateway), la porta anteriore di Azure (usare azure-front-door), il firewall di Azure (usare azure-firewall), la protezione DDos di Azure (usare azure-ddos-protection).
