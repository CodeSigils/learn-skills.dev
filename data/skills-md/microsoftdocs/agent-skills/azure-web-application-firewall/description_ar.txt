معرفة الخبراء بتطوير جدار حماية تطبيق الويب Azure بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين قواعد WAF للباب الأمامي/بوابة التطبيق، أو حدود المعدلات، أو bot/CAPTCHA، أو تسجيل Sentinel، أو عمليات نشر IaC، ومهام التطوير الأخرى ذات الصلة بجدار حماية تطبيق Azure Web. ليس لبوابة تطبيق Azure (استخدم بوابة تطبيق azure)، والباب الأمامي لـ Azure (استخدم الباب الأمامي azure)، وجدار الحماية Azure (استخدم جدار الحماية azure)، وحماية Azure DDos (استخدم حماية azure-ddos).
