Azure Web アプリケーション ファイアウォール開発に関する専門知識 (トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、展開など)。 Front Door/App Gateway WAF ルール、レート制限、ボット/CAPTCHA、Sentinel ログ、または IaC 展開、およびその他の Azure Web アプリケーション ファイアウォール関連の開発タスクを構成するときに使用します。 Azure Application Gateway (azure-application-gateway を使用)、Azure Front Door (azure-front-door を使用)、Azure Firewall (azure-firewall を使用)、Azure DDos Protection (azure-ddos-protection を使用) には使用できません。
