Экспертные знания для разработки брандмауэра веб-приложений Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке правил WAF Front Door/App Gateway, ограничений скорости, ботов/CAPTCHA, ведения журнала Sentinel или развертываний IaC, а также других задач разработки, связанных с брандмауэром веб-приложений Azure. Не для Шлюза приложений Azure (используйте azure-application-gateway), Azure Front Door (используйте azure-front-door), Брандмауэра Azure (используйте azure-firewall), Azure DDos Protection (используйте azure-ddos-protection).
