Connaissance approfondie du développement d'Azure Web Application Firewall, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la configuration des règles WAF Front Door/App Gateway, des limites de débit, du bot/CAPTCHA, de la journalisation Sentinel ou des déploiements IaC, ainsi que d'autres tâches de développement liées au pare-feu d'application Web Azure. Pas pour Azure Application Gateway (utilisez azure-application-gateway), Azure Front Door (utilisez azure-front-door), Azure Firewall (utilisez azure-firewall), Azure DDos Protection (utilisez azure-ddos-protection).
