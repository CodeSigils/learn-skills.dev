Экспертные знания для разработки Azure AI Search, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при проектировании индексов/наборов навыков, векторного/семантического поиска, индексаторов, баз знаний RAG или безопасного доступа к данным, а также других задач разработки, связанных с поиском Azure AI. Не для Azure Cosmos DB (используйте azure-cosmos-db), Azure Data Explorer (используйте azure-data-explorer), Базы данных SQL Azure (используйте azure-sql-database), Azure Synapse Analytics (используйте azure-synapse-analytics).
