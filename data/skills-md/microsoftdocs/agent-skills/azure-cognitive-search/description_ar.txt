معرفة الخبراء بتطوير Azure AI Search بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تصميم الفهارس/مجموعات المهارات، أو البحث المتجه/الدلالي، أو الفهارس، أو قواعد معارف RAG، أو الوصول الآمن إلى البيانات، ومهام التطوير الأخرى ذات الصلة بـ Azure AI Search. ليس لـ Azure Cosmos DB (استخدم azure-cosmos-db)، وAzure Data Explorer (استخدم azure-data-explorer)، وقاعدة بيانات Azure SQL (استخدم قاعدة بيانات azure-sql)، وAzure Synapse Analytics (استخدم تحليلات azure-synapse).
