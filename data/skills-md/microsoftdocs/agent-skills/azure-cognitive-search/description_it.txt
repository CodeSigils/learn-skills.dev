Conoscenza approfondita dello sviluppo di Ricerca AI di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la progettazione di indici/set di competenze, ricerca vettoriale/semantica, indicizzatori, knowledge base RAG o accesso sicuro ai dati e altre attività di sviluppo correlate a Ricerca AI di Azure. Non per Azure Cosmos DB (usare azure-cosmos-db), Esplora dati di Azure (usare azure-data-explorer), database SQL di Azure (usare azure-sql-database), Azure Synapse Analytics (usare azure-synapse-analytics).
