Azure AI 搜尋開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在設計索引/技能集、向量/語義搜尋、索引器、RAG 知識庫或安全資料存取以及其他 Azure AI 搜尋相關開發任務時使用。不適用於 Azure Cosmos DB（使用 azure-cosmos-db）、Azure 資料資源管理器（使用 azure-data-explorer）、Azure SQL 資料庫（使用 azure-sql-database）、Azure Synapse Analytics（使用 azure-synapse-analytics）。
