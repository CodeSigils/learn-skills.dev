Connaissance approfondie du développement d'Azure AI Search, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la conception d'index/ensembles de compétences, de recherches vectorielles/sémantiques, d'indexeurs, de bases de connaissances RAG ou d'accès sécurisé aux données, ainsi que d'autres tâches de développement liées à Azure AI Search. Pas pour Azure Cosmos DB (utilisez azure-cosmos-db), Azure Data Explorer (utilisez azure-data-explorer), Azure SQL Database (utilisez azure-sql-database), Azure Synapse Analytics (utilisez azure-synapse-analytics).
