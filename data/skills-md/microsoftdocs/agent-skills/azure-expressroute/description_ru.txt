Экспертные знания для разработки Azure ExpressRoute, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при проектировании каналов/шлюзов ExpressRoute, маршрутизации BGP, сосуществования Global Reach, FastPath или S2S VPN, а также других задач разработки, связанных с Azure ExpressRoute. Не для интернет-пиринга Azure (используйте azure-internet-peering), службы пиринга Azure (используйте azure-peering-service), виртуальной глобальной сети Azure (используйте azure-virtual-wan), VPN-шлюза Azure (используйте azure-vpn-gateway).
