トラブルシューティング、ベスト プラクティス、意思決定、構成、統合とコーディング パターンを含む、Microsoft Foundry Local (別名 Azure AI Foundry Local) 開発に関する専門知識。 Foundry Local CLI、REST/SDK API、OpenAI クライアント、LangChain/Open WebUI、または Olive モデルのビルド、およびその他の Microsoft Foundry Local 関連の開発タスクを使用する場合に使用します。 Microsoft Foundry (microsoft-foundry を使用)、Microsoft Foundry Classic (microsoft-foundry-classic を使用)、Microsoft Foundry Tools (microsoft-foundry-tools を使用)、Azure Local (azure-local を使用) には使用できません。
