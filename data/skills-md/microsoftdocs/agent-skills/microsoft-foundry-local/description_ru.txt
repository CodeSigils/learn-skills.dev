Экспертные знания для разработки Microsoft Foundry Local (также известной как Azure AI Foundry Local), включая устранение неполадок, лучшие практики, принятие решений, настройку, а также интеграцию и шаблоны кодирования. Используйте при использовании Foundry Local CLI, API-интерфейсов REST/SDK, клиентов OpenAI, сборок моделей LangChain/Open WebUI или Olive, а также других задач разработки, связанных с Microsoft Foundry Local. Не для Microsoft Foundry (используйте microsoft-foundry), Microsoft Foundry Classic (используйте microsoft-foundry-classic), Microsoft Foundry Tools (используйте microsoft-foundry-tools), Azure Local (используйте azure-local).
