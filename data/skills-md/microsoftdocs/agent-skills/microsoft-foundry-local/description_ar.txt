معرفة الخبراء بتطوير Microsoft Foundry Local (المعروف أيضًا باسم Azure AI Foundry Local) بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والتكوين والتكامل وأنماط الترميز. يُستخدم عند استخدام Foundry Local CLI أو REST/SDK APIs أو عملاء OpenAI أو LangChain/Open WebUI أو إصدارات نموذج Olive ومهام التطوير الأخرى ذات الصلة بـ Microsoft Foundry Local. ليس لـ Microsoft Foundry (استخدم Microsoft Foundry)، وMicrosoft Foundry Classic (استخدم Microsoft Foundry-classic)، وMicrosoft Foundry Tools (استخدم أدوات microsoft Foundry)، وAzure Local (استخدم Azure-local).
