معرفة الخبراء بتطوير ملفات Azure NetApp بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند نشر ANF لعمليات تكامل SAP HANA/Oracle، أو AzAcSnap، أو ZRS، أو AVS، أو REST/PowerShell، أو S3/OneLake، ومهام التطوير الأخرى ذات الصلة بملفات Azure NetApp. ليس لملفات Azure (استخدم ملفات azure)، وAzure Blob Storage (استخدم azure-blob-storage)، وAzure Elastic SAN (استخدم azure-elastic-san)، وAzure Managed Luster (استخدم Lustre المُدار من azure).
