Conoscenza approfondita dello sviluppo di Azure NetApp Files, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la distribuzione di ANF per integrazioni SAP HANA/Oracle, AzAcSnap, ZRS, AVS, REST/PowerShell o S3/OneLake e altre attività di sviluppo correlate ad Azure NetApp Files. Non per File di Azure (usare azure-files), Archiviazione BLOB di Azure (usare azure-blob-storage), Azure Elastic SAN (usare azure-elastic-san), Azure Managed Lustre (usare azure-activated-lustre).
