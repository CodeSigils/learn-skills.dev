Connaissance approfondie du développement d'Azure NetApp Files, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors du déploiement d'ANF pour les intégrations SAP HANA/Oracle, AzAcSnap, ZRS, AVS, REST/PowerShell ou S3/OneLake et d'autres tâches de développement liées à Azure NetApp Files. Pas pour Azure Files (utilisez azure-files), Azure Blob Storage (utilisez azure-blob-storage), Azure Elastic SAN (utilisez azure-elastic-san), Azure Managed Lustre (utilisez azure-managed-lustre).
