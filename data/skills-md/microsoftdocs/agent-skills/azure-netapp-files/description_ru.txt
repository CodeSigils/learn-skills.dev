Экспертные знания для разработки Azure NetApp Files, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при развертывании ANF для интеграции SAP HANA/Oracle, AzAcSnap, ZRS, AVS, REST/PowerShell или S3/OneLake, а также других задач разработки, связанных с Azure NetApp Files. Не для файлов Azure (используйте azure-files), хранилища BLOB-объектов Azure (используйте azure-blob-storage), Azure Elastic SAN (используйте azure-elastic-san), Azure Managed Lustre (используйте azure-managed-lustre).
