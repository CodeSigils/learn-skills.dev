معرفة الخبراء لتطوير Azure Automation بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند أتمتة دفاتر التشغيل/DSC، أو Hybrid Runbook Workers، أو تتبع التغيير، أو عمليات تكامل Azure/AWS/365، أو عمليات الترحيل، ومهام التطوير الأخرى ذات الصلة بـ Azure Automation. ليس لوظائف Azure (استخدم وظائف azure)، وتطبيقات Azure Logic (استخدم azure-logic-apps)، وAzure Scheduler (استخدم azure-scheduler)، وAzure DevOps (استخدم azure-devops).
