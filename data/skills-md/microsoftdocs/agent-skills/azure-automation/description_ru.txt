Экспертные знания для разработки автоматизации Azure, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при автоматизации модулей Runbook/DSC, гибридных рабочих процессов Runbook, отслеживания изменений, интеграции Azure/AWS/365 или миграции, а также других задач разработки, связанных с автоматизацией Azure. Не для функций Azure (используйте azure-functions), Azure Logic Apps (используйте azure-logic-apps), планировщика Azure (используйте azure-scheduler), Azure DevOps (используйте azure-devops).
