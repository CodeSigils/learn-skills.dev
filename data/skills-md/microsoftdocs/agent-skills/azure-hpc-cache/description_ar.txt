معرفة الخبراء بتطوير Azure HPC Cache بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين مساحات أسماء HPC Cache، أو أهداف NFS/Blob، أو وصول العميل، أو البرامج النصية لاستيعاب البيانات، أو تجاوز فشل ذاكرة التخزين المؤقت، ومهام التطوير الأخرى ذات الصلة بـ Azure HPC Cache. ليس لـ Azure Managed Luster (استخدم azure-managed-lustre)، وملفات Azure NetApp (استخدم ملفات azure-netapp)، وAzure Batch (استخدم azure-batch)، وأجهزة Azure الافتراضية (استخدم الأجهزة الافتراضية azure).
