Expertenwissen für die Azure HPC Cache-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird zum Konfigurieren von HPC Cache-Namespaces, NFS-/Blob-Zielen, Clientzugriff, Datenerfassungsskripts oder Cache-Failover und anderen Azure HPC Cache-bezogenen Entwicklungsaufgaben verwendet. Nicht für Azure Managed Lustre (verwenden Sie azure-managed-lustre), Azure NetApp Files (verwenden Sie azure-netapp-files), Azure Batch (verwenden Sie azure-batch), Azure Virtual Machines (verwenden Sie azure-virtual-machines).
