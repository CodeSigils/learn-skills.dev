문제 해결, 모범 사례, 의사 결정, 아키텍처 및 디자인 패턴, 제한 및 할당량, 보안, 구성, 통합 및 코딩 패턴, 배포를 포함한 Azure HPC Cache 개발에 대한 전문 지식입니다. HPC 캐시 네임스페이스, NFS/Blob 대상, 클라이언트 액세스, 데이터 수집 스크립트 또는 캐시 장애 조치(failover) 및 기타 Azure HPC 캐시 관련 개발 작업을 구성할 때 사용합니다. Azure Managed Lustre(azure-managed-lustre 사용), Azure NetApp Files(azure-netapp-files 사용), Azure Batch(azure-batch 사용), Azure Virtual Machines(azure-virtual-machines 사용)에는 적합하지 않습니다.
