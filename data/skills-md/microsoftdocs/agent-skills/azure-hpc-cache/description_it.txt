Conoscenza approfondita dello sviluppo della cache HPC di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la configurazione di spazi dei nomi della cache HPC, destinazioni NFS/BLOB, accesso client, script di inserimento dati o failover della cache e altre attività di sviluppo correlate alla cache HPC di Azure. Non per Azure Managed Lustre (usare azure-activated-lustre), Azure NetApp Files (usare azure-netapp-files), Azure Batch (usare azure-batch), Macchine virtuali di Azure (usare azure-virtual-machines).
