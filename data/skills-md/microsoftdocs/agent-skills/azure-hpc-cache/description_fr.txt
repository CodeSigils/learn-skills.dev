Connaissance approfondie du développement d'Azure HPC Cache, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la configuration des espaces de noms HPC Cache, des cibles NFS/Blob, de l'accès client, des scripts d'ingestion de données ou du basculement du cache, ainsi que d'autres tâches de développement liées à Azure HPC Cache. Pas pour Azure Managed Lustre (utilisez azure-managed-lustre), Azure NetApp Files (utilisez azure-netapp-files), Azure Batch (utilisez azure-batch), Azure Virtual Machines (utilisez azure-virtual-machines).
