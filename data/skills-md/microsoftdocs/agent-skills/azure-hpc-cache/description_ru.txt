Экспертные знания для разработки Azure HPC Cache, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке пространств имен кэша HPC, целевых объектов NFS/Blob, клиентского доступа, сценариев приема данных или отработки отказа кэша, а также других задач разработки, связанных с кэшем HPC Azure. Не для Azure Managed Lustre (используйте azure-managed-lustre), файлов Azure NetApp (используйте azure-netapp-files), пакетной службы Azure (используйте azure-batch), виртуальных машин Azure (используйте azure-virtual-machines).
