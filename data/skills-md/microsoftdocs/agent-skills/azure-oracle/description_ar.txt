معرفة الخبراء بتطوير Azure Oracle بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند تكوين Oracle TDE باستخدام Key Vault أو طبولوجيا VNET أو نشر Exadata أو تحديد المنطقة أو سجلات Azure Monitor/Sentinel ومهام التطوير الأخرى ذات الصلة بـ Azure Oracle. ليس لقاعدة بيانات Azure SQL (استخدم قاعدة بيانات azure-sql)، ومثيل Azure SQL المُدار (استخدم مثيل azure-sql المُدار)، وSQL Server على أجهزة Azure الظاهرية (استخدم azure-sql-virtual-machines)، وSAP HANA على مثيلات Azure الكبيرة (استخدم azure-sap).
