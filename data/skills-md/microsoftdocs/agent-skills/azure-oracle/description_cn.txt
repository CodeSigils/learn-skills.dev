Azure Oracle 开发的专业知识，包括故障排除、决策、安全、配置以及集成和编码模式。在使用 Key Vault、VNET 拓扑、Exadata 部署、区域选择或 Azure Monitor/Sentinel 日志配置 Oracle TDE 以及其他 Azure Oracle 相关开发任务时使用。不适用于 Azure SQL 数据库（使用 azure-sql-database）、Azure SQL 托管实例（使用 azure-sql-托管实例）、Azure 虚拟机上的 SQL Server（使用 azure-sql-virtual-machines）、Azure 大型实例上的 SAP HANA（使用 azure-sap）。
