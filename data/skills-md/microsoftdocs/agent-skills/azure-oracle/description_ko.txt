문제 해결, 의사 결정, 보안, 구성, 통합 및 코딩 패턴을 포함한 Azure Oracle 개발에 대한 전문 지식입니다. Key Vault, VNET 토폴로지, Exadata 배포, 지역 선택 또는 Azure Monitor/Sentinel 로그 및 기타 Azure Oracle 관련 개발 작업을 사용하여 Oracle TDE를 구성할 때 사용합니다. Azure SQL Database(azure-sql-database 사용), Azure SQL Managed Instance(azure-sql-managed-instance 사용), Azure Virtual Machines의 SQL Server(azure-sql-virtual-machines 사용), Azure 대규모 인스턴스의 SAP HANA(azure-sap 사용)에는 해당되지 않습니다.
