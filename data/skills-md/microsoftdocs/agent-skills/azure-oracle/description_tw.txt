Azure Oracle 開發的專業知識，包括故障排除、決策、安全性、配置以及整合和編碼模式。在使用 Key Vault、VNET 拓樸、Exadata 部署、區域選擇或 Azure Monitor/Sentinel 日誌配置 Oracle TDE 以及其他 Azure Oracle 相關開發任務時使用。不適用於 Azure SQL 資料庫（使用 azure-sql-database）、Azure SQL 託管執行個體（使用 azure-sql-託管執行個體）、Azure 虛擬機器上的 SQL Server（使用 azure-sql-virtual-machines）、Azure 大型執行個體上的 SAP HANA（使用 azure-sap）。
