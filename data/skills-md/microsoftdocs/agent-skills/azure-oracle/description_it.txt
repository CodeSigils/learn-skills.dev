Conoscenza approfondita dello sviluppo di Azure Oracle, tra cui risoluzione dei problemi, processo decisionale, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare durante la configurazione di Oracle TDE con Key Vault, topologia VNET, distribuzione Exadata, selezione dell'area o log di monitoraggio/Sentinel di Azure e altre attività di sviluppo correlate a Oracle di Azure. Non per il database SQL di Azure (usare azure-sql-database), Istanza gestita SQL di Azure (usare azure-sql-built-instance), SQL Server su macchine virtuali di Azure (usare azure-sql-virtual-machines), SAP HANA su istanze large di Azure (usare azure-sap).
