Экспертные знания для разработки Azure Oracle, включая устранение неполадок, принятие решений, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при настройке Oracle TDE с Key Vault, топологией виртуальной сети, развертыванием Exadata, выбором региона или журналами Azure Monitor/Sentinel, а также другими задачами разработки, связанными с Azure Oracle. Не для базы данных SQL Azure (используйте azure-sql-database), Управляемого экземпляра Azure SQL (используйте azure-sql-managed-instance), SQL Server на виртуальных машинах Azure (используйте azure-sql-virtual-machines), SAP HANA на крупных экземплярах Azure (используйте azure-sap).
