トラブルシューティング、意思決定、セキュリティ、構成、統合とコーディング パターンなど、Azure Oracle 開発に関する専門知識。 Key Vault、VNET トポロジ、Exadata デプロイ、リージョンの選択、または Azure Monitor/Sentinel ログ、およびその他の Azure Oracle 関連の開発タスクを使用して Oracle TDE を構成する場合に使用します。 Azure SQL Database (azure-sql-database を使用)、Azure SQL Managed Instance (azure-sql-managed-instance を使用)、Azure Virtual Machines 上の SQL Server (azure-sql-virtual-machines を使用)、Azure Large Instances 上の SAP HANA (azure-sap を使用) には適用されません。
