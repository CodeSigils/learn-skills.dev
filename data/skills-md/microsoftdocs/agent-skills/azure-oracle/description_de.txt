Expertenwissen für die Azure Oracle-Entwicklung, einschließlich Fehlerbehebung, Entscheidungsfindung, Sicherheit, Konfiguration sowie Integrationen und Codierungsmuster. Wird verwendet, wenn Sie Oracle TDE mit Key Vault, VNET-Topologie, Exadata-Bereitstellung, Regionsauswahl oder Azure Monitor/Sentinel-Protokollen und anderen Azure Oracle-bezogenen Entwicklungsaufgaben konfigurieren. Nicht für Azure SQL-Datenbank (verwenden Sie azure-sql-database), Azure SQL Managed Instance (verwenden Sie azure-sql-managed-instance), SQL Server auf Azure Virtual Machines (verwenden Sie azure-sql-virtual-machines), SAP HANA auf Azure Large Instances (verwenden Sie azure-sap).
