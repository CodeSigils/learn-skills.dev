Connaissance experte du développement Azure Front Door, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la configuration du routage/de la mise en cache Front Door, de WAF/TLS, des origines Private Link, du moteur de règles ou des migrations classique vers Std/Prm, ainsi que d'autres tâches de développement liées à Azure Front Door. Pas pour Azure Application Gateway (utilisez azure-application-gateway), Azure Traffic Manager (utilisez azure-traffic-manager), Azure Load Balancer (utilisez azure-load-balancer), Azure Web Application Firewall (utilisez azure-web-application-firewall).
