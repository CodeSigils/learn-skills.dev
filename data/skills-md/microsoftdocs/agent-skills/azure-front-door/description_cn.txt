Azure Front Door 开发的专业知识，包括故障排除、最佳实践、决策、体系结构和设计模式、限制和配额、安全性、配置、集成和编码模式以及部署。在配置 Front Door 路由/缓存、WAF/TLS、专用链接源、规则引擎或经典到 Std/Prm 迁移以及其他 Azure Front Door 相关开发任务时使用。不适用于 Azure 应用程序网关（使用 azure-application-gateway）、Azure 流量管理器（使用 azure-traffic-manager）、Azure 负载均衡器（使用 azure-load-balancer）、Azure Web 应用程序防火墙（使用 azure-web-application-firewall）。
