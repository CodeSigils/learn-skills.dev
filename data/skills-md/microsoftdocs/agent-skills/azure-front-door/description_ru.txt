Экспертные знания для разработки Azure Front Door, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке маршрутизации и кэширования Front Door, WAF/TLS, источников частных ссылок, обработчика правил или миграции с классического на Std/Prm, а также других задач разработки, связанных с Azure Front Door. Не для шлюза приложений Azure (используйте azure-application-gateway), диспетчера трафика Azure (используйте azure-traffic-manager), Azure Load Balancer (используйте azure-load-balancer), брандмауэра веб-приложений Azure (используйте azure-web-application-firewall).
