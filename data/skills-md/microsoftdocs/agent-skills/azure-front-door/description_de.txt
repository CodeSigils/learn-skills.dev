Expertenwissen für die Azure Front Door-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird verwendet, wenn Sie Front Door-Routing/Caching, WAF/TLS, Private Link-Ursprünge, Regel-Engine oder Migrationen von klassisch auf Std/Prm sowie andere Azure Front Door-bezogene Entwicklungsaufgaben konfigurieren. Nicht für Azure Application Gateway (verwenden Sie azure-application-gateway), Azure Traffic Manager (verwenden Sie azure-traffic-manager), Azure Load Balancer (verwenden Sie azure-load-balancer), Azure Web Application Firewall (verwenden Sie azure-web-application-firewall).
