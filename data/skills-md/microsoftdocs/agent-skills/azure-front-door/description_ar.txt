معرفة الخبراء بتطوير Azure Front Door بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين توجيه/التخزين المؤقت للباب الأمامي، أو WAF/TLS، أو أصول الارتباط الخاص، أو محرك القواعد، أو عمليات الترحيل الكلاسيكية إلى Std/Prm، ومهام التطوير الأخرى ذات الصلة بـ Azure Front Door. ليس لـ Azure Application Gateway (استخدم azure-application-gateway)، وAzure Traffic Manager (استخدم azure-traffic-manager)، وAzure Load Balancer (استخدم azure-load-balancer)، وجدار حماية تطبيق الويب Azure (استخدم جدار حماية تطبيق الويب azure).
