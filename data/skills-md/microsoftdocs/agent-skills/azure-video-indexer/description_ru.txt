Экспертные знания для разработки индексатора видео Azure AI, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании API/виджетов индексатора видео, индексации камер в реальном времени, пользовательских моделей речи/брендов или интеграции Azure OpenAI, а также других задач разработки, связанных с индексатором видео Azure AI. Не для служб Azure AI (используйте инструменты Microsoft-foundry), Azure AI Vision (используйте azure-ai-vision).
