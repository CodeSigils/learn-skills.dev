Connaissance experte du développement Azure Stack Edge, y compris le dépannage, les meilleures pratiques, la prise de décision, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'exécution d'applications IoT Edge ou GPU/Kubernetes, de la configuration des machines virtuelles/du stockage/de la mise en réseau ou de la gestion des mises à jour des appareils, ainsi que d'autres tâches de développement liées à Azure Stack Edge. Pas pour Azure Data Box (utilisez azure-data-box-family), Azure IoT Edge (utilisez azure-iot-edge), Azure Kubernetes Service (AKS) (utilisez azure-kubernetes-service), Azure Virtual Machines (utilisez des machines virtuelles azure).
