Экспертные знания для разработки Azure Stack Edge, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при запуске приложений IoT Edge или GPU/Kubernetes, настройке виртуальных машин/хранилища/сети или управлении обновлениями устройств, а также при выполнении других задач разработки, связанных с Azure Stack Edge. Не для Azure Data Box (используйте azure-data-box-family), Azure IoT Edge (используйте azure-iot-edge), Azure Kubernetes Service (AKS) (используйте azure-kubernetes-service), виртуальных машин Azure (используйте azure-virtual-machines).
