معرفة الخبراء بتطوير Azure Stack Edge بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تشغيل تطبيقات IoT Edge أو GPU/Kubernetes، أو تكوين الأجهزة الافتراضية/التخزين/الشبكات، أو إدارة تحديثات الجهاز، ومهام التطوير الأخرى ذات الصلة بـ Azure Stack Edge. ليس لـ Azure Data Box (استخدم azure-data-box-family)، وAzure IoT Edge (استخدم azure-iot-edge)، وخدمة Azure Kubernetes (AKS) (استخدم خدمة azure-kubernetes)، وأجهزة Azure الافتراضية (استخدم الأجهزة الافتراضية azure).
