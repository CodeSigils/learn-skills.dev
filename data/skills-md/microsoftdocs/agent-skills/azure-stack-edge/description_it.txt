Conoscenza approfondita dello sviluppo di Azure Stack Edge, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante l'esecuzione di app IoT Edge o GPU/Kubernetes, la configurazione di VM/archiviazione/rete o la gestione degli aggiornamenti dei dispositivi e altre attività di sviluppo correlate ad Azure Stack Edge. Non per Azure Data Box (usare azure-data-box-family), Azure IoT Edge (usare azure-iot-edge), Azure Kubernetes Service (AKS) (usare azure-kubernetes-service), Macchine virtuali di Azure (usare azure-virtual-machines).
