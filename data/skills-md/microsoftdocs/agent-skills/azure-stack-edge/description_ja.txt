トラブルシューティング、ベスト プラクティス、意思決定、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、デプロイなど、Azure Stack Edge 開発に関する専門知識。 IoT Edge または GPU/Kubernetes アプリの実行、VM/ストレージ/ネットワークの構成、デバイスの更新の管理、およびその他の Azure Stack Edge 関連の開発タスクを行うときに使用します。 Azure Data Box (azure-data-box-family を使用)、Azure IoT Edge (azure-iot-edge を使用)、Azure Kubernetes Service (AKS) (azure-kubernetes-service を使用)、Azure Virtual Machines (azure-virtual-machines を使用) には適用されません。
