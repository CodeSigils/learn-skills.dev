Connaissance approfondie du développement d'Azure Virtual WAN, y compris le dépannage, la prise de décision, les modèles d'architecture et de conception, les limites et les quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la conception de hubs Virtual WAN, d'un VPN P2S, d'une connectivité ExpressRoute/SD‑WAN, de NVA/pare-feu ou d'un accès VPN Entra ID, ainsi que d'autres tâches de développement liées à Azure Virtual WAN. Pas pour Azure Virtual Network (utilisez azure-virtual-network), Azure VPN Gateway (utilisez azure-vpn-gateway), Azure ExpressRoute (utilisez azure-expressroute), Azure Traffic Manager (utilisez azure-traffic-manager).
