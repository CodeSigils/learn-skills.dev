Экспертные знания для разработки виртуальной глобальной сети Azure, включая устранение неполадок, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при проектировании концентраторов виртуальной глобальной сети, P2S VPN, подключений ExpressRoute/SD-WAN, NVA/брандмауэров или VPN-доступа по Entra ID, а также других задач разработки, связанных с виртуальной глобальной сетью Azure. Не для виртуальной сети Azure (используйте azure-virtual-network), VPN-шлюза Azure (используйте azure-vpn-gateway), Azure ExpressRoute (используйте azure-expressroute), диспетчера трафика Azure (используйте azure-traffic-manager).
