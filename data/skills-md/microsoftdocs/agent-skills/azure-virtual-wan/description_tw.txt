Azure 虛擬 WAN 開發的專業知識，包括故障排除、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在設計虛擬 WAN 中心、P2S VPN、ExpressRoute/SD‑WAN 連線、NVA/防火牆或 Entra ID VPN 存取權以及其他 Azure 虛擬 WAN 相關開發任務時使用。不適用於 Azure 虛擬網路（使用 azure-virtual-network）、Azure VPN 閘道（使用 azure-vpn-gateway）、Azure ExpressRoute（使用 azure-expressroute）、Azure 流量管理器（使用 azure-traffic-manager）。
