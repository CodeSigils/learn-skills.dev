Azure 虚拟 WAN 开发的专业知识，包括故障排除、决策、体系结构和设计模式、限制和配额、安全性、配置、集成和编码模式以及部署。在设计虚拟 WAN 中心、P2S VPN、ExpressRoute/SD‑WAN 连接、NVA/防火墙或 Entra ID VPN 访问以及其他 Azure 虚拟 WAN 相关开发任务时使用。不适用于 Azure 虚拟网络（使用 azure-virtual-network）、Azure VPN 网关（使用 azure-vpn-gateway）、Azure ExpressRoute（使用 azure-expressroute）、Azure 流量管理器（使用 azure-traffic-manager）。
