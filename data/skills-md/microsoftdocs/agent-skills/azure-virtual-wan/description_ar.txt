معرفة الخبراء بتطوير Azure Virtual WAN بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تصميم لوحات وصل شبكة WAN الافتراضية، أو P2S VPN، أو اتصال ExpressRoute/SD‑WAN، أو NVAs/جدران الحماية، أو الوصول إلى Entra ID VPN، ومهام التطوير الأخرى ذات الصلة بـ Azure Virtual WAN. ليس لشبكة Azure الافتراضية (استخدم azure-virtual-network)، وAzure VPN Gateway (استخدم azure-vpn-gateway)، وAzure ExpressRoute (استخدم azure-expressroute)، وAzure Traffic Manager (استخدم azure-traffic-manager).
