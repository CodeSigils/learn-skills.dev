Conoscenza approfondita dello sviluppo di quote di Azure, inclusi limiti e quote. Da utilizzare quando si richiedono aumenti della quota dell'account di archiviazione per regione, si controllano i limiti o si inviano richieste di supporto di Azure e altre attività di sviluppo correlate alle quote di Azure. Non per Gestione costi di Azure (usare azure-cost-management), Monitoraggio di Azure (usare azure-monitor), Criteri di Azure (usare azure-policy), Azure Resource Manager (usare azure-resource-manager).
