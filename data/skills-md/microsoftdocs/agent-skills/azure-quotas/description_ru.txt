Экспертные знания по разработке Azure Quotas, включая ограничения и квоты. Используйте при запросе увеличения квоты учетной записи хранения для каждого региона, проверке ограничений или подаче запросов на поддержку Azure, а также при выполнении других задач разработки, связанных с квотами Azure. Не для Azure Cost Management (используйте azure-cost-manager), Azure Monitor (используйте azure-monitor), Политики Azure (используйте azure-policy), Azure Resource Manager (используйте azure-resource-manager).
