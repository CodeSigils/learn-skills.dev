معرفة الخبراء لتطوير Azure Quotas بما في ذلك الحدود والحصص. يُستخدم عند طلب زيادة حصة حساب التخزين لكل منطقة، أو التحقق من الحدود، أو تقديم طلبات دعم Azure، ومهام التطوير الأخرى ذات الصلة بـ Azure Quotas. ليس لإدارة تكلفة Azure (استخدم إدارة تكلفة azure)، وAzure Monitor (استخدم azure-monitor)، وسياسة Azure (استخدم سياسة azure)، وAzure Resource Manager (استخدم azure-resource-manager).
