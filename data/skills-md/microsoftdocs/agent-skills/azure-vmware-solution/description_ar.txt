معرفة الخبراء لتطوير حلول Azure VMware بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين AVS مع HCX/NSX، أو vSAN/مجموعات ممتدة، أو Citrix/Horizon، أو Cloud Director، أو JetStream DR، ومهام التطوير الأخرى ذات الصلة بـ Azure VMware Solution. ليس لأجهزة Azure الافتراضية (استخدم الأجهزة الافتراضية azure)، ومثيلات Azure الكبيرة (استخدم المثيلات الكبيرة azure)، والبنية التحتية Azure Baremetal (استخدم البنية الأساسية azure-baremetal)، وSAP HANA على مثيلات Azure الكبيرة (استخدم azure-sap).
