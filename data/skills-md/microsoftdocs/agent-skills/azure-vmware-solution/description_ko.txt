문제 해결, 모범 사례, 의사 결정, 아키텍처 및 디자인 패턴, 제한 및 할당량, 보안, 구성, 통합 및 코딩 패턴, 배포를 포함한 Azure VMware 솔루션 개발에 대한 전문 지식입니다. HCX/NSX, vSAN/확장된 클러스터, Citrix/Horizon, Cloud Director 또는 JetStream DR 및 기타 Azure VMware Solution 관련 개발 작업으로 AVS를 구성할 때 사용합니다. Azure Virtual Machines(azure-virtual-machines 사용), Azure 대규모 인스턴스(azure-large-instances 사용), Azure Baremetal 인프라(azure-baremetal-infrastructure 사용), Azure 대규모 인스턴스의 SAP HANA(azure-sap 사용)에는 해당되지 않습니다.
