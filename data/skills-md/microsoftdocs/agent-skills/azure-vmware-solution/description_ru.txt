Экспертные знания для разработки решений Azure VMware, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке AVS с помощью HCX/NSX, vSAN/растянутых кластеров, Citrix/Horizon, Cloud Director или JetStream DR, а также других задач разработки, связанных с решением Azure VMware. Не для виртуальных машин Azure (используйте azure-virtual-machines), крупных экземпляров Azure (используйте azure-large-instances), базовой инфраструктуры Azure (используйте azure-baremetal-infrastructure), SAP HANA на крупных экземплярах Azure (используйте azure-sap).
