Conoscenza approfondita dello sviluppo di soluzioni Azure VMware, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la configurazione di AVS con HCX/NSX, vSAN/cluster estesi, Citrix/Horizon, Cloud Director o JetStream DR e altre attività di sviluppo correlate alla soluzione Azure VMware. Non per macchine virtuali di Azure (usare azure-virtual-machines), istanze grandi di Azure (usare azure-large-instances), infrastruttura baremetal di Azure (usare azure-baremetal-infrastructure), SAP HANA su istanze grandi di Azure (usare azure-sap).
