用于农业开发的 Azure Data Manager 的专业知识，包括限制和配额、安全性、配置以及集成和编码模式。在设置 BYOL 信用/专用链接、农业数据提取/物联网、AI/营养素 API、限制或事件网格日志以及其他用于农业的 Azure 数据管理器相关开发任务时使用。不适用于 Azure 数据资源管理器（使用 azure-data-explorer）、Azure 数据工厂（使用 azure-data-factory）、Azure Synapse Analytics（使用 azure-synapse-analytics）、Azure Databricks（使用 azure-databricks）。
