用于农业开发的 Azure Data Manager 的专业知识，包括限制和配额、安全性、配置以及集成和编码模式。在設定 BYOL 信用/專用連結、農業資料提取/物聯網、AI/營養素 API、限製或事件網格日誌以及其他用於農業的 Azure 資料管理器相關開發任務時使用。不適用於 Azure 資料資源管理器（使用 azure-data-explorer）、Azure 資料工廠（使用 azure-data-factory）、Azure Synapse Analytics（使用 azure-synapse-analytics）、Azure Databricks（使用 azure-databricks）。
