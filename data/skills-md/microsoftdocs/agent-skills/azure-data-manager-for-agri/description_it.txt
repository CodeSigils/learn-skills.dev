Conoscenza approfondita dello sviluppo di Azure Data Manager for Agriculture, inclusi limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare durante la configurazione di credenziali BYOL/collegamento privato, inserimento dati agricoli/IoT, API AI/nutrienti, limitazione o log della griglia di eventi e altre attività di sviluppo correlate a Azure Data Manager for Agriculture. Non per Esplora dati di Azure (usare azure-data-explorer), Azure Data Factory (usare azure-data-factory), Azure Synapse Analytics (usare azure-synapse-analytics), Azure Databricks (usare azure-databricks).
