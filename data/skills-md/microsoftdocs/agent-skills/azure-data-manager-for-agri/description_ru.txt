Экспертные знания по разработке Azure Data Manager для сельского хозяйства, включая ограничения и квоты, безопасность, конфигурацию, а также интеграцию и шаблоны кодирования. Используйте при настройке кредитов BYOL/частной ссылки, приема сельскохозяйственных данных/Интернета вещей, API ИИ/питательных веществ, регулирования или журналов сетки событий, а также других задач разработки, связанных с Azure Data Manager для сельского хозяйства. Не для Azure Data Explorer (используйте azure-data-explorer), Azure Data Factory (используйте azure-data-factory), Azure Synapse Analytics (используйте azure-synapse-analytics), Azure Databricks (используйте azure-databricks).
