Connaissance approfondie du développement d'Azure Data Manager for Agriculture, y compris les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage. À utiliser lors de la configuration des crédits BYOL/Private Link, de l'ingestion de données agricoles/IoT, des API d'IA/nutriments, de la limitation ou des journaux Event Grid et d'autres tâches de développement liées à Azure Data Manager for Agriculture. Pas pour Azure Data Explorer (utilisez azure-data-explorer), Azure Data Factory (utilisez azure-data-factory), Azure Synapse Analytics (utilisez azure-synapse-analytics), Azure Databricks (utilisez azure-databricks).
