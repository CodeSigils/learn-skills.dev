معرفة الخبراء بـ Azure Data Manager للتنمية الزراعية بما في ذلك الحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند إعداد بيانات اعتماد BYOL/الارتباط الخاص، واستيعاب البيانات الزراعية/إنترنت الأشياء، وواجهات برمجة تطبيقات الذكاء الاصطناعي/المغذيات، والتقييد، أو سجلات شبكة الأحداث، ومهام التطوير الأخرى ذات الصلة بـ Azure Data Manager للزراعة. ليس لـ Azure Data Explorer (استخدم azure-data-explorer)، وAzure Data Factory (استخدم azure-data-factory)، وAzure Synapse Analytics (استخدم تحليلات azure-synapse)، وAzure Databricks (استخدم azure-databricks).
