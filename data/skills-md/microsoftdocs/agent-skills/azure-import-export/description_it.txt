Conoscenza approfondita dello sviluppo di Import Export di Azure, inclusa risoluzione dei problemi, limiti e quote e sicurezza. Da utilizzare durante l'impostazione di CMK tramite Key Vault, la convalida del supporto di unità/sistema operativo o il debug di problemi relativi a processi e log di importazione/esportazione e altre attività di sviluppo correlate all'importazione/esportazione di Azure. Non per Azure Data Box (usare azure-data-box-family), Archiviazione BLOB di Azure (usare azure-blob-storage), File di Azure (usare azure-files).
