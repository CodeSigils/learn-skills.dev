معرفة الخبراء بتطوير Azure Import Export بما في ذلك استكشاف الأخطاء وإصلاحها والحدود والحصص والأمان. يُستخدم عند إعداد CMK عبر Key Vault، أو التحقق من دعم محرك الأقراص/نظام التشغيل، أو تصحيح أخطاء مهمة الاستيراد/التصدير ومشكلات السجل، ومهام التطوير الأخرى ذات الصلة بـ Azure Import Export. ليس لـ Azure Data Box (استخدم azure-data-box-family)، وAzure Blob Storage (استخدم azure-blob-storage)، وملفات Azure (استخدم ملفات azure).
