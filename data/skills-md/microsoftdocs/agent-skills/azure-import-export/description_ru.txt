Экспертные знания для разработки Azure Import Export, включая устранение неполадок, ограничения и квоты, а также безопасность. Используйте при настройке CMK через Key Vault, проверке поддержки диска/ОС или отладке проблем с заданиями импорта и экспорта и журнала, а также при выполнении других задач разработки, связанных с импортом и экспортом Azure. Не для Azure Data Box (используйте семейство azure-data-box), хранилища BLOB-объектов Azure (используйте azure-blob-storage), файлов Azure (используйте azure-files).
