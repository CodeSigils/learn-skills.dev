Expertenwissen für die Azure-Import-Export-Entwicklung, einschließlich Fehlerbehebung, Grenzwerte und Kontingente sowie Sicherheit. Verwenden Sie diese Option, wenn Sie CMK über Key Vault festlegen, die Laufwerks-/Betriebssystemunterstützung überprüfen oder Import-/Export-Auftrags- und Protokollprobleme sowie andere Entwicklungsaufgaben im Zusammenhang mit Azure Import/Export debuggen. Nicht für Azure Data Box (verwenden Sie azure-data-box-family), Azure Blob Storage (verwenden Sie azure-blob-storage), Azure Files (verwenden Sie azure-files).
