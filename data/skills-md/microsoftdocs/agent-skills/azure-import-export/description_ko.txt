문제 해결, 제한 및 할당량, 보안을 포함한 Azure 가져오기 내보내기 개발에 대한 전문 지식입니다. Key Vault를 통해 CMK를 설정하거나, 드라이브/OS 지원의 유효성을 검사하거나, 가져오기/내보내기 작업 및 로그 문제를 디버깅하고, 기타 Azure Import 내보내기 관련 개발 작업을 수행할 때 사용합니다.
