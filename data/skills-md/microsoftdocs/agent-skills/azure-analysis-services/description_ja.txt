トラブルシューティングを含む、Azure Analysis Services 開発に関する専門知識。サーバー接続のテスト、ゲートウェイまたはファイアウォール ブロックのデバッグ、接続文字列とポートの確認、およびその他の Azure Analysis Services 関連の開発タスクを行うときに使用します。 Azure Synapse Analytics (azure-synapse-analytics を使用)、Azure SQL Database (azure-sql-database を使用)、Azure SQL Managed Instance (azure-sql-managed-instance を使用)、Azure Virtual Machines 上の SQL Server (azure-sql-virtual-machines を使用) には適用されません。
