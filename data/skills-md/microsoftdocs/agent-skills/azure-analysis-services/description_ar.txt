معرفة الخبراء بتطوير خدمات تحليل Azure بما في ذلك استكشاف الأخطاء وإصلاحها. يُستخدم عند اختبار اتصالات الخادم، أو تصحيح أخطاء البوابة أو كتل جدار الحماية، أو التحقق من سلاسل الاتصال والمنافذ، ومهام التطوير الأخرى ذات الصلة بخدمات تحليل Azure. ليس لـ Azure Synapse Analytics (استخدم azure-synapse-analytics)، وقاعدة بيانات Azure SQL (استخدم قاعدة بيانات azure-sql)، ومثيل Azure SQL المُدار (استخدم مثيل azure-sql المُدار)، وSQL Server على أجهزة Azure الافتراضية (استخدم الأجهزة الافتراضية azure-sql).
