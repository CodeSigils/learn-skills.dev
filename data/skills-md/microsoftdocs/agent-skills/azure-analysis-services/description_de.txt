Expertenwissen für die Entwicklung von Azure Analysis Services einschließlich Fehlerbehebung. Wird zum Testen von Serververbindungen, zum Debuggen von Gateway- oder Firewall-Blöcken oder zum Überprüfen von Verbindungszeichenfolgen und Ports sowie für andere Entwicklungsaufgaben im Zusammenhang mit Azure Analysis Services verwendet. Nicht für Azure Synapse Analytics (verwenden Sie azure-synapse-analytics), Azure SQL-Datenbank (verwenden Sie azure-sql-database), Azure SQL Managed Instance (verwenden Sie azure-sql-managed-instance), SQL Server auf Azure Virtual Machines (verwenden Sie azure-sql-virtual-machines).
