Conoscenza approfondita dello sviluppo di Azure Analysis Services, inclusa la risoluzione dei problemi. Da utilizzare durante il test delle connessioni server, il debug dei blocchi del gateway o del firewall oppure il controllo delle stringhe e delle porte di connessione e altre attività di sviluppo correlate ad Azure Analysis Services. Non per Azure Synapse Analytics (usare azure-synapse-analytics), database SQL di Azure (usare azure-sql-database), Istanza gestita SQL di Azure (usare azure-sql-built-instance), SQL Server in macchine virtuali di Azure (usare azure-sql-virtual-machines).
