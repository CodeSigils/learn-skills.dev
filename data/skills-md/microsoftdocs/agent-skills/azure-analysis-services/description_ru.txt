Экспертные знания по разработке служб Azure Analysis Services, включая устранение неполадок. Используйте при тестировании подключений к серверу, отладке блоков шлюза или брандмауэра или проверке строк подключения и портов, а также при выполнении других задач разработки, связанных со службами Azure Analysis Services. Не для Azure Synapse Analytics (используйте azure-synapse-analytics), Базы данных SQL Azure (используйте azure-sql-database), Управляемого экземпляра Azure SQL (используйте azure-sql-managed-instance), SQL Server на виртуальных машинах Azure (используйте azure-sql-virtual-machines).
