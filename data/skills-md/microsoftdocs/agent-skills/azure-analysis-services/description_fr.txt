Connaissance approfondie du développement d'Azure Analysis Services, y compris le dépannage. À utiliser lors du test des connexions au serveur, du débogage des blocs de passerelle ou de pare-feu, ou de la vérification des chaînes de connexion et des ports, ainsi que d'autres tâches de développement liées à Azure Analysis Services. Pas pour Azure Synapse Analytics (utilisez azure-synapse-analytics), Azure SQL Database (utilisez azure-sql-database), Azure SQL Managed Instance (utilisez azure-sql-managed-instance), SQL Server sur les machines virtuelles Azure (utilisez azure-sql-virtual-machines).
