문제 해결을 포함한 Azure Analysis Services 개발에 대한 전문 지식. 서버 연결을 테스트하거나, 게이트웨이 또는 방화벽 블록을 디버깅하거나, 연결 문자열 및 포트를 확인하거나, 기타 Azure Analysis Services 관련 개발 작업을 수행할 때 사용합니다. Azure Synapse Analytics(azure-synapse-analytics 사용), Azure SQL Database(azure-sql-database 사용), Azure SQL Managed Instance(azure-sql-managed-instance 사용), Azure Virtual Machines의 SQL Server(azure-sql-virtual-machines 사용)에는 해당되지 않습니다.
