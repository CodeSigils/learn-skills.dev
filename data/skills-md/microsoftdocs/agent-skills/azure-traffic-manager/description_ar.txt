معرفة الخبراء بتطوير Azure Traffic Manager بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والتكوين والتكامل وأنماط الترميز. يُستخدم عند تكوين ملفات التعريف/نقاط النهاية، أو طرق التوجيه، أو RUM JS، أو التصميمات المتداخلة، أو الضبط المستند إلى طريقة عرض حركة المرور، ومهام التطوير الأخرى ذات الصلة بـ Azure Traffic Manager. ليس لـ Azure Front Door (استخدم azure-front-door)، وAzure Load Balancer (استخدم azure-load-balancer)، وAzure Virtual WAN (استخدم azure-virtual-wan)، وبوابة تطبيق Azure (استخدم بوابة تطبيق azure).
