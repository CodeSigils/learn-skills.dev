Экспертные знания для разработки Azure Traffic Manager, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, конфигурацию, а также шаблоны интеграции и кодирования. Используйте при настройке профилей/конечных точек, методов маршрутизации, RUM JS, вложенных проектов или настройки на основе представления трафика, а также других задач разработки, связанных с диспетчером трафика Azure. Не для Azure Front Door (используйте azure-front-door), Azure Load Balancer (используйте azure-load-balancer), Azure Virtual WAN (используйте azure-virtual-wan), Azure Application Gateway (используйте azure-application-gateway).
