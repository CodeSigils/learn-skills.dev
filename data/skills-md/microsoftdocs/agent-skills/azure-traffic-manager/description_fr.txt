Connaissance approfondie du développement d'Azure Traffic Manager, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, la configuration, ainsi que les modèles d'intégration et de codage. À utiliser lors de la configuration des profils/points de terminaison, des méthodes de routage, de RUM JS, des conceptions imbriquées ou du réglage basé sur Traffic View, ainsi que d'autres tâches de développement liées à Azure Traffic Manager. Pas pour Azure Front Door (utilisez azure-front-door), Azure Load Balancer (utilisez azure-load-balancer), Azure Virtual WAN (utilisez azure-virtual-wan), Azure Application Gateway (utilisez azure-application-gateway).
