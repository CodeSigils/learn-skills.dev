Expertenwissen für die Azure Traffic Manager-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Konfiguration sowie Integrationen und Codierungsmuster. Wird zum Konfigurieren von Profilen/Endpunkten, Routingmethoden, RUM JS, verschachtelten Designs oder Traffic View-basierter Optimierung sowie anderen Azure Traffic Manager-bezogenen Entwicklungsaufgaben verwendet. Nicht für Azure Front Door (verwenden Sie azure-front-door), Azure Load Balancer (verwenden Sie azure-load-balancer), Azure Virtual WAN (verwenden Sie azure-virtual-wan), Azure Application Gateway (verwenden Sie azure-application-gateway).
