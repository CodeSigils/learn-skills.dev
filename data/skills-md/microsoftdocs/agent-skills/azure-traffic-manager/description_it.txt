Conoscenza approfondita dello sviluppo di Gestione traffico di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, configurazione, integrazioni e modelli di codifica. Da utilizzare durante la configurazione di profili/endpoint, metodi di routing, RUM JS, progettazioni nidificate o ottimizzazione basata sulla visualizzazione traffico e altre attività di sviluppo correlate a Gestione traffico di Azure. Non per la porta anteriore di Azure (usare azure-front-door), il servizio di bilanciamento del carico di Azure (usare azure-load-balancer), la rete WAN virtuale di Azure (usare azure-virtual-wan), il gateway applicazione di Azure (usare azure-application-gateway).
