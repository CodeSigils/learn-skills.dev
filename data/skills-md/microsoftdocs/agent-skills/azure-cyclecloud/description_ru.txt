Экспертные знания для разработки Azure CycleCloud, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, безопасность, конфигурацию, шаблоны интеграции и кодирования, а также развертывание. Используйте при автоматизации CycleCloud через API/CLI, управлении кластерами Slurm/HPC, настройке автоматического масштабирования или обеспечении безопасности доступа/SSL, а также при выполнении других задач разработки, связанных с Azure CycleCloud. Не для пакетной службы Azure (используйте azure-batch), кэша HPC Azure (используйте azure-hpc-cache), виртуальных машин Azure (используйте azure-virtual-machines).
