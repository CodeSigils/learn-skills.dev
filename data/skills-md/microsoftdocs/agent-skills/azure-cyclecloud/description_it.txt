Conoscenza approfondita dello sviluppo di Azure CycleCloud, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare per automatizzare CycleCloud tramite API/CLI, gestire cluster Slurm/HPC, ottimizzare la scalabilità automatica o proteggere accesso/SSL e altre attività di sviluppo correlate ad Azure CycleCloud. Non per Azure Batch (usare azure-batch), Cache HPC di Azure (usare azure-hpc-cache), Macchine virtuali di Azure (usare azure-virtual-machines).
