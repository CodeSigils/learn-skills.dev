معرفة الخبراء بتطوير Azure CycleCloud بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند أتمتة CycleCloud عبر API/CLI، أو إدارة مجموعات Slurm/HPC، أو ضبط القياس التلقائي، أو تأمين الوصول/SSL، ومهام التطوير الأخرى ذات الصلة بـ Azure CycleCloud. ليس لـ Azure Batch (استخدم azure-batch)، وAzure HPC Cache (استخدم azure-hpc-cache)، وأجهزة Azure الافتراضية (استخدم الأجهزة الافتراضية azure).
