Conoscenza approfondita dello sviluppo di Azure Network Watcher, tra cui risoluzione dei problemi, processo decisionale, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare durante la configurazione di monitoraggio connessione, log di flusso NSG/VNet, acquisizione di pacchetti, analisi del traffico o integrazioni Sentinel e altre attività di sviluppo correlate a Azure Network Watcher. Non per Monitoraggio di Azure (usare azure-monitor), Rete di Azure (usare azure-networking), Rete virtuale di Azure (usare azure-virtual-network), Gestione rete virtuale di Azure (usare azure-virtual-network-manager).
