Экспертные знания для разработки Azure Network Watcher, включая устранение неполадок, принятие решений, ограничения и квоты, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при настройке монитора подключений, журналов потоков NSG/VNet, захвата пакетов, анализа трафика или интеграции Sentinel, а также других задач разработки, связанных с Azure Network Watcher. Не для Azure Monitor (используйте azure-monitor), сети Azure (используйте azure-network), виртуальной сети Azure (используйте azure-virtual-network), Azure Virtual Network Manager (используйте azure-virtual-network-manager).
