معرفة الخبراء بتطوير Azure Network Watcher بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند تكوين مراقبة الاتصال، أو سجلات تدفق NSG/VNet، أو التقاط الحزم، أو تحليلات حركة المرور، أو تكاملات Sentinel، ومهام التطوير الأخرى ذات الصلة بـ Azure Network Watcher. ليس لـ Azure Monitor (استخدم azure-monitor)، وAzure Networking (استخدم azure-networking)، وAzure Virtual Network (استخدم azure-virtual-network)، وAzure Virtual Network Manager (استخدم azure-virtual-network-manager).
