Connaissance approfondie du développement d'Azure Network Watcher, y compris le dépannage, la prise de décision, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage. À utiliser lors de la configuration du Moniteur de connexion, des journaux de flux NSG/VNet, de la capture de paquets, des intégrations Traffic Analytics ou Sentinel, ainsi que d'autres tâches de développement liées à Azure Network Watcher. Pas pour Azure Monitor (utilisez azure-monitor), Azure Networking (utilisez azure-networking), Azure Virtual Network (utilisez azure-virtual-network), Azure Virtual Network Manager (utilisez azure-virtual-network-manager).
