Expertenwissen für die Azure Network Watcher-Entwicklung, einschließlich Fehlerbehebung, Entscheidungsfindung, Grenzwerte und Kontingente, Sicherheit, Konfiguration sowie Integrationen und Codierungsmuster. Wird zum Konfigurieren von Verbindungsmonitor, NSG/VNet-Flussprotokollen, Paketerfassung, Verkehrsanalysen oder Sentinel-Integrationen und anderen Azure Network Watcher-bezogenen Entwicklungsaufgaben verwendet. Nicht für Azure Monitor (verwenden Sie azure-monitor), Azure Networking (verwenden Sie azure-networking), Azure Virtual Network (verwenden Sie azure-virtual-network), Azure Virtual Network Manager (verwenden Sie azure-virtual-network-manager).
