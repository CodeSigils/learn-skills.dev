معرفة الخبراء بتطوير Azure Data Share بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار والأمان والتكوين والنشر. يُستخدم عند تقدير تكاليف مشاركة البيانات، أو إدارة الدعوات/RBAC، أو عمليات النشر عبر المناطق، أو تعيين مجموعة البيانات، أو الأتمتة، ومهام التطوير الأخرى ذات الصلة بمشاركة بيانات Azure. ليس لـ Azure Data Box (استخدم azure-data-box-family)، وAzure Import Export (استخدم azure-import-export)، وAzure Open Datasets (استخدم مجموعات البيانات azure-open)، وAzure Data Explorer (استخدم azure-data-explorer).
