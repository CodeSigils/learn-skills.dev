Экспертные знания для разработки общих ресурсов данных Azure, включая устранение неполадок, принятие решений, безопасность, настройку и развертывание. Используйте при оценке затрат на общий доступ к данным, управлении приглашениями/RBAC, развертываниях в разных регионах, сопоставлении наборов данных или автоматизации, а также при выполнении других задач разработки, связанных с общим доступом к данным Azure. Не для Azure Data Box (используйте azure-data-box-family), Azure Import Export (используйте azure-import-export), Azure Open Datasets (используйте azure-open-datasets), Azure Data Explorer (используйте azure-data-explorer).
