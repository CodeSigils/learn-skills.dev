Connaissance experte du développement Azure Data Share, y compris le dépannage, la prise de décision, la sécurité, la configuration et le déploiement. À utiliser lors de l'estimation des coûts du partage de données, de la gestion des invitations/RBAC, des déploiements interrégionaux, du mappage ou de l'automatisation des ensembles de données, ainsi que d'autres tâches de développement liées à Azure Data Share. Pas pour Azure Data Box (utilisez azure-data-box-family), Azure Import Export (utilisez azure-import-export), Azure Open Datasets (utilisez azure-open-datasets), Azure Data Explorer (utilisez azure-data-explorer).
