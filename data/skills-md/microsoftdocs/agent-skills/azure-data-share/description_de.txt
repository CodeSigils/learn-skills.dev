Expertenwissen für die Azure Data Share-Entwicklung, einschließlich Fehlerbehebung, Entscheidungsfindung, Sicherheit, Konfiguration und Bereitstellung. Wird zum Schätzen der Data Share-Kosten, zum Verwalten von Einladungen/RBAC, zur regionsübergreifenden Bereitstellung, zur Datensatzzuordnung oder -automatisierung sowie für andere Entwicklungsaufgaben im Zusammenhang mit Azure Data Share verwendet. Nicht für Azure Data Box (verwenden Sie azure-data-box-family), Azure Import Export (verwenden Sie azure-import-export), Azure Open Datasets (verwenden Sie azure-open-datasets), Azure Data Explorer (verwenden Sie azure-data-explorer).
