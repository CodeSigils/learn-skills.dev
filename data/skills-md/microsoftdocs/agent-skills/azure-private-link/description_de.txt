Expertenwissen für die Azure Private Link-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit und Konfiguration. Verwenden Sie diese Option, wenn Sie private Endpunkte, DNS/Private Resolver, High Scale-Limits, NSP/RBAC oder Azure Firewall-Inspektion und andere Azure Private Link-bezogene Entwicklungsaufgaben konfigurieren. Nicht für Azure Virtual Network (verwenden Sie azure-virtual-network), Azure VPN Gateway (verwenden Sie azure-vpn-gateway), Azure ExpressRoute (verwenden Sie azure-expressroute), Azure Firewall (verwenden Sie azure-firewall).
