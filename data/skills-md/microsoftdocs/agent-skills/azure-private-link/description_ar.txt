معرفة الخبراء بتطوير Azure Private Link بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين. يُستخدم عند تكوين نقاط النهاية الخاصة، أو DNS/المحلل الخاص، أو حدود النطاق العالي، أو فحص NSP/RBAC، أو جدار حماية Azure، ومهام التطوير الأخرى ذات الصلة بـ Azure Private Link. ليس لشبكة Azure الافتراضية (استخدم azure-virtual-network)، وAzure VPN Gateway (استخدم azure-vpn-gateway)، وAzure ExpressRoute (استخدم azure-expressroute)، وجدار حماية Azure (استخدم جدار الحماية azure).
