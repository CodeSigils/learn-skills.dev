Экспертные знания для разработки Azure Private Link, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность и настройку. Используйте при настройке частных конечных точек, DNS/частного сопоставителя, крупномасштабных ограничений, NSP/RBAC или проверки брандмауэра Azure, а также других задач разработки, связанных с Azure Private Link. Не для виртуальной сети Azure (используйте azure-virtual-network), VPN-шлюза Azure (используйте azure-vpn-gateway), Azure ExpressRoute (используйте azure-expressroute), брандмауэра Azure (используйте azure-firewall).
