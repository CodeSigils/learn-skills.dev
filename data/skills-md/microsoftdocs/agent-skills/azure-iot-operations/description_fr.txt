Connaissance approfondie du développement d'Azure IoT Operations, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la configuration du courtier MQTT, des flux/graphiques de données, des connecteurs OPC UA/ONVIF, des transformations WASM ou Prometheus/Grafana et d'autres tâches de développement liées à Azure IoT Operations. Pas pour Azure IoT (utilisez azure-iot), Azure IoT Hub (utilisez azure-iot-hub), Azure IoT Edge (utilisez azure-iot-edge), Azure Defender For IoT (utilisez azure-defender-for-iot).
