معرفة الخبراء لتطوير عمليات Azure IoT بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين وسيط MQTT وتدفقات البيانات/الرسوم البيانية وموصلات OPC UA/ONVIF وتحويلات WASM أو Prometheus/Grafana ومهام التطوير الأخرى ذات الصلة بعمليات Azure IoT. ليس لـ Azure IoT (استخدم azure-iot)، وAzure IoT Hub (استخدم azure-iot-hub)، وAzure IoT Edge (استخدم azure-iot-edge)، وAzure Defender For Iot (استخدم azure-defender-for-iot).
