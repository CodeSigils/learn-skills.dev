Экспертные знания для разработки операций Azure IoT, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке брокера MQTT, потоков/графиков данных, соединителей OPC UA/ONVIF, преобразований WASM или Prometheus/Grafana, а также других задач разработки, связанных с операциями Azure IoT. Не для Azure IoT (используйте azure-iot), Azure IoT Hub (используйте azure-iot-hub), Azure IoT Edge (используйте azure-iot-edge), Azure Defender для Iot (используйте azure-defender-for-iot).
