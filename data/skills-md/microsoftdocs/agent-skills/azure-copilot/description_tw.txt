Azure Copilot 開發的專業知識，包括故障排除、決策、架構和設計模式、安全性、配置以及整合和編碼模式。在調整 VM 大小、產生 Bicep/Terraform、配置 Cosmos DB 儲存或偵錯應用程式服務/VM 磁碟以及其他 Azure Copilot 相關開發任務時使用。不適用於 Azure AI 服務（使用 microsoft-foundry-tools）、Azure 機器學習（使用 azure-machine-learning）、Azure AI 搜尋（使用 azure-cognitive-search）、Azure AI Bot 服務（使用 azure-bot-service）。
