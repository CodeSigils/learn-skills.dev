Экспертные знания для разработки Azure Copilot, включая устранение неполадок, принятие решений, шаблоны архитектуры и проектирования, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при определении размера виртуальных машин, создании Bicep/Terraform, настройке хранилища Cosmos DB или отладке дисков Службы приложений/ВМ, а также других задачах разработки, связанных с Azure Copilot. Не для служб искусственного интеллекта Azure (используйте инструменты Microsoft-foundry), машинного обучения Azure (используйте машинное обучение Azure), поиска Azure AI (используйте azure-cognitive-search), службы Azure AI Bot (используйте azure-bot-service).
