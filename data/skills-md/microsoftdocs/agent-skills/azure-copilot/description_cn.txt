Azure Copilot 开发的专业知识，包括故障排除、决策、体系结构和设计模式、安全性、配置以及集成和编码模式。在调整 VM 大小、生成 Bicep/Terraform、配置 Cosmos DB 存储或调试应用服务/VM 磁盘以及其他 Azure Copilot 相关开发任务时使用。不适用于 Azure AI 服务（使用 microsoft-foundry-tools）、Azure 机器学习（使用 azure-machine-learning）、Azure AI 搜索（使用 azure-cognitive-search）、Azure AI Bot 服务（使用 azure-bot-service）。
