Conoscenza approfondita dello sviluppo di Azure Copilot, tra cui risoluzione dei problemi, processo decisionale, modelli di architettura e progettazione, sicurezza, configurazione, integrazioni e modelli di codifica. Da usare per il dimensionamento di macchine virtuali, la generazione di Bicep/Terraform, la configurazione dell'archiviazione di Cosmos DB o il debug di dischi del servizio app/VM e altre attività di sviluppo correlate ad Azure Copilot. Non per i servizi AI di Azure (usare microsoft-foundry-tools), Azure Machine Learning (usare azure-machine-learning), Ricerca AI di Azure (usare azure-cognitive-search), Servizio Bot AI di Azure (usare azure-bot-service).
