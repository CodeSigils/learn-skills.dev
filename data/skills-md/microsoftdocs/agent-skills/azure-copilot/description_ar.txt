معرفة الخبراء بتطوير Azure Copilot بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار والهندسة المعمارية وأنماط التصميم والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند تغيير حجم الأجهزة الافتراضية، أو إنشاء Bicep/Terraform، أو تكوين تخزين Cosmos DB، أو تصحيح أخطاء أقراص App Service/VM، ومهام التطوير الأخرى ذات الصلة بـ Azure Copilot. ليس لخدمات Azure AI (استخدم أدوات microsoft Foundry)، والتعلم الآلي من Azure (استخدم التعلم الآلي من azure)، وAzure AI Search (استخدم البحث المعرفي azure)، وخدمة Azure AI Bot (استخدم خدمة azure-bot).
