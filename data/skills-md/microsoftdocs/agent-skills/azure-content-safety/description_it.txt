Conoscenza approfondita dello sviluppo della sicurezza dei contenuti di Azure AI, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usano API di sicurezza dei contenuti, contenitori Docker, liste di blocco, controlli di messa a terra o categorie di sicurezza personalizzate e altre attività di sviluppo correlate alla sicurezza dei contenuti di Azure AI. Non per Azure Information Protection (usare azure-information-protection), Sicurezza di Azure (usare azure-security), Azure Sentinel (usare azure-sentinel), Azure Defender For Cloud (usare azure-defender-for-cloud).
