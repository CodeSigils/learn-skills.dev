Экспертные знания для разработки безопасности контента Azure AI, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании API-интерфейсов безопасности контента, контейнеров Docker, черных списков, проверок обоснованности или пользовательских категорий безопасности, а также других задач разработки, связанных с безопасностью контента Azure AI. Не для Azure Information Protection (используйте azure-information-protection), Azure Security (используйте azure-security), Azure Sentinel (используйте azure-sentinel), Azure Defender для облака (используйте azure-defender-for-cloud).
