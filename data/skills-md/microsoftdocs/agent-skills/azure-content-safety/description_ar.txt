معرفة الخبراء بتطوير Azure AI Content Safety بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام Content Safety APIs أو حاويات Docker أو قوائم الحظر أو عمليات التحقق من التأريض أو فئات الأمان المخصصة ومهام التطوير الأخرى ذات الصلة بـ Azure AI Content Safety. ليس لحماية البيانات في Azure (استخدم حماية المعلومات azure)، وAzure Security (استخدم azure-security)، وAzure Sentinel (استخدم azure-sentinel)، وAzure Defender For Cloud (استخدم azure-defender-for-cloud).
