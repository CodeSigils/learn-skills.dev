Экспертные знания для разработки виртуальных машин Azure Data Science, включая устранение неполадок, принятие решений, шаблоны архитектуры и проектирования, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при управлении образами/инструментами DSVM, развертывании IaC (Bicep/ARM), секретах Key Vault, проблемах MLflow или GPU/Jupyter, а также других задачах разработки, связанных с виртуальными машинами Azure Data Science. Не для виртуальных машин Azure (используйте виртуальные машины Azure), Машинное обучение Azure (используйте azure-machine-learning), Azure Databricks (используйте azure-databricks), Azure HDInsight (используйте azure-hdinsight).
