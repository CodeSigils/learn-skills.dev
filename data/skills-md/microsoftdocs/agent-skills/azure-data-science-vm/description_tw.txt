Azure 資料科學虛擬機器開發的專業知識，包括故障排除、決策、架構和設計模式、安全性、配置、整合和編碼模式以及部署。在管理 DSVM 映像/工具、IaC 部署 (Bicep/ARM)、Key Vault 機密、MLflow 或 GPU/Jupyter 問題以及其他 Azure 資料科學虛擬機器相關開發任務時使用。不適用於 Azure 虛擬機器（使用 azure-virtual-machines）、Azure 機器學習（使用 azure-machine-learning）、Azure Databricks（使用 azure-databricks）、Azure HDInsight（使用 azure-hdinsight）。
