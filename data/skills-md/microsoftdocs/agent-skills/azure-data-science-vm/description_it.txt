Conoscenza approfondita dello sviluppo di macchine virtuali per data science di Azure, tra cui risoluzione dei problemi, processo decisionale, modelli di architettura e progettazione, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la gestione di immagini/strumenti di macchine virtuali DSVM, distribuzione IaC (Bicep/ARM), segreti di Key Vault, problemi di MLflow o GPU/Jupyter e altre attività di sviluppo correlate alle macchine virtuali di data science di Azure. Non per macchine virtuali di Azure (usare azure-virtual-machines), Azure Machine Learning (usare azure-machine-learning), Azure Databricks (usare azure-databricks), Azure HDInsight (usare azure-hdinsight).
