Connaissance approfondie du développement de machines virtuelles Azure Data Science, y compris le dépannage, la prise de décision, les modèles d'architecture et de conception, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la gestion des images/outils DSVM, du déploiement IaC (Bicep/ARM), des secrets Key Vault, des problèmes MLflow ou GPU/Jupyter et d'autres tâches de développement liées aux machines virtuelles Azure Data Science. Pas pour les machines virtuelles Azure (utilisez des machines virtuelles azure), Azure Machine Learning (utilisez azure-machine-learning), Azure Databricks (utilisez azure-databricks), Azure HDInsight (utilisez azure-hdinsight).
