معرفة الخبراء بتطوير الأجهزة الافتراضية لـ Azure Data Science بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار وأنماط الهندسة والتصميم والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إدارة صور/أدوات DSVM، أو نشر IaC (Bicep/ARM)، أو أسرار Key Vault، أو MLflow، أو مشكلات GPU/Jupyter، ومهام التطوير الأخرى المتعلقة بالأجهزة الافتراضية لـ Azure Data Science. ليس لأجهزة Azure الافتراضية (استخدم الأجهزة الافتراضية azure)، والتعلم الآلي من Azure (استخدم التعلم الآلي من azure)، وAzure Databricks (استخدم azure-databricks)، وAzure HDInsight (استخدم azure-hdinsight).
