Expertenwissen für die Entwicklung von Azure App Testing, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird verwendet, wenn Azure Load Testing mit VNets/privaten Endpunkten, JMeter/Locust/Playwright, CI/CD-Pipelines oder Playwright Workspaces und anderen Azure App Testing-bezogenen Entwicklungsaufgaben verwendet wird. Nicht für Azure Test Plans (verwenden Sie azure-test-plans), Playwright Workspaces (verwenden Sie azure-playwright-workspaces), Azure DevOps (verwenden Sie azure-devops), Azure App Service (verwenden Sie azure-app-service).
