Экспертные знания для разработки тестирования приложений Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании нагрузочного тестирования Azure с виртуальными сетями/частными конечными точками, JMeter/Locust/Playwright, конвейерами CI/CD или рабочими областями Playwright, а также другими задачами разработки, связанными с тестированием приложений Azure. Не для планов тестирования Azure (используйте azure-test-plans), Playwright Workspaces (используйте azure-playwright-workspaces), Azure DevOps (используйте azure-devops), Службы приложений Azure (используйте azure-app-service).
