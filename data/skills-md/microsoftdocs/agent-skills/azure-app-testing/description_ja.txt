トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、デプロイメントなど、Azure App Testing 開発に関する専門知識。 VNet/プライベート エンドポイント、JMeter/Locust/Playwright、CI/CD パイプライン、または Playwright ワークスペースで Azure Load Testing を使用する場合、およびその他の Azure App Testing 関連の開発タスクを使用する場合に使用します。 Azure テスト プラン (azure-test-plans を使用)、Playwright ワークスペース (azure-playwright-workspaces を使用)、Azure DevOps (azure-devops を使用)、Azure App Service (azure-app-service を使用) には適用されません。
