معرفة الخبراء بتطوير اختبار Azure App بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام Azure Load Testing مع VNets/نقاط النهاية الخاصة، أو JMeter/Locust/Playwright، أو خطوط أنابيب CI/CD، أو Playwright Workspaces، ومهام التطوير الأخرى ذات الصلة باختبار Azure App. ليس لخطط اختبار Azure (استخدم خطط اختبار azure)، ومساحات عمل Playwright (استخدم مساحات عمل azure-playwright)، وAzure DevOps (استخدم azure-devops)، وخدمة تطبيقات Azure (استخدم خدمة تطبيقات azure).
