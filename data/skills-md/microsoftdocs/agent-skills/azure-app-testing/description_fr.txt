Connaissance approfondie du développement d'Azure App Testing, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'utilisation d'Azure Load Testing avec des réseaux virtuels/points de terminaison privés, JMeter/Locust/Playwright, des pipelines CI/CD ou des espaces de travail Playwright, ainsi que d'autres tâches de développement liées à Azure App Testing. Pas pour les plans de test Azure (utilisez azure-test-plans), Playwright Workspaces (utilisez azure-playwright-workspaces), Azure DevOps (utilisez azure-devops), Azure App Service (utilisez azure-app-service).
