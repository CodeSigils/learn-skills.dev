Conoscenza approfondita dello sviluppo di Azure App Testing, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usa test di carico di Azure con reti virtuali/endpoint privati, JMeter/Locust/Playwright, pipeline CI/CD o aree di lavoro Playwright e altre attività di sviluppo correlate al test delle app di Azure. Non per piani di test di Azure (usare azure-test-plans), Playwright Workspaces (usare azure-playwright-workspaces), Azure DevOps (usare azure-devops), Servizio app di Azure (usare azure-app-service).
