Azure 應用程式測試開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。將 Azure 負載測試與 VNet/專用終端、JMeter/Locust/Playwright、CI/CD 管道或 Playwright 工作區以及其他 Azure 應用程式測試相關的開發任務結合使用時使用。不適用於 Azure 測試計畫（使用 azure-test-plans）、Playwright 工作區（使用 azure-playwright-workspaces）、Azure DevOps（使用 azure-devops）、Azure 應用程式服務（使用 azure-app-service）。
