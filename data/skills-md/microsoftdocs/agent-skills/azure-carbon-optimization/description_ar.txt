معرفة الخبراء بتطوير Azure Carbon Optimization بما في ذلك استكشاف الأخطاء وإصلاحها والأمان والتكامل وأنماط الترميز. يُستخدم عند استخدام Carbon Service REST API، أو صادرات Python، أو أدوار RBAC، أو جودة بيانات الانبعاثات، أو مشكلات لوحة المعلومات، ومهام التطوير الأخرى ذات الصلة بـ Azure Carbon Optimization. ليس لإدارة تكلفة Azure (استخدم إدارة تكلفة azure)، وتقرير تأثير Azure (استخدم تقرير تأثير azure)، وAzure Monitor (استخدم شاشة azure)، وسياسة Azure (استخدم سياسة azure).
