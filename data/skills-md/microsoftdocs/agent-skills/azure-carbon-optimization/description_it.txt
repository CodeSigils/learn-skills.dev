Conoscenza approfondita dello sviluppo di Azure Carbon Optimization, inclusi risoluzione dei problemi, sicurezza, integrazioni e modelli di codifica. Da usare quando si usa l'API REST di Carbon Service, le esportazioni Python, i ruoli RBAC, la qualità dei dati sulle emissioni o i problemi del dashboard e altre attività di sviluppo correlate ad Azure Carbon Optimization. Non per Gestione costi di Azure (usare azure-cost-management), Reporting sull'impatto di Azure (usare azure-impact-reporting), Monitoraggio di Azure (usare azure-monitor), Criteri di Azure (usare azure-policy).
