Экспертные знания для разработки Azure Carbon Optimization, включая устранение неполадок, безопасность, интеграцию и шаблоны кодирования. Используйте при использовании REST API Carbon Service, экспорта Python, ролей RBAC, качества данных о выбросах или проблем с информационной панелью, а также других задач разработки, связанных с оптимизацией выбросов углерода Azure. Не для Azure Cost Management (используйте azure-cost-management), Azure Impact Reporting (используйте azure-impact-reporting), Azure Monitor (используйте azure-monitor), Azure Policy (используйте azure-policy).
