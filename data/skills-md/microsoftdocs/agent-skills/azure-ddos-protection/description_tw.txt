Azure DDos 保護開發的專業知識，包括故障排除、最佳實務、決策、架構和設計模式、安全性和配置。在啟用 DDoS IP/網路保護計畫、解析 DDoS 日誌、使用快速回應或強制實施 Azure 策略以及其他 Azure DDoS 保護相關開發任務時使用。不適用於 Azure 防火牆（使用 azure-firewall）、Azure Web 應用程式防火牆（使用 azure-web-application-firewall）、Azure 虛擬網路（使用 azure-virtual-network）、Azure 虛擬網路管理員（使用 azure-virtual-network-manager）。
