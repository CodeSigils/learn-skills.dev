Azure DDos 保护开发的专业知识，包括故障排除、最佳实践、决策、体系结构和设计模式、安全性和配置。在启用 DDoS IP/网络保护计划、解析 DDoS 日志、使用快速响应或强制执行 Azure 策略以及其他 Azure DDoS 保护相关开发任务时使用。不适用于 Azure 防火墙（使用 azure-firewall）、Azure Web 应用程序防火墙（使用 azure-web-application-firewall）、Azure 虚拟网络（使用 azure-virtual-network）、Azure 虚拟网络管理器（使用 azure-virtual-network-manager）。
