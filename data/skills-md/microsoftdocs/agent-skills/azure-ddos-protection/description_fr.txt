Connaissance approfondie du développement d'Azure DDos Protection, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, la sécurité et la configuration. À utiliser lors de l’activation des plans de protection IP/réseau DDoS, de l’analyse des journaux DDoS, de l’utilisation de Rapid Response ou de l’application d’Azure Policy, ainsi que d’autres tâches de développement liées à Azure DDos Protection. Pas pour le pare-feu Azure (utilisez Azure-firewall), Azure Web Application Firewall (utilisez Azure-web-application-firewall), Azure Virtual Network (utilisez Azure-virtual-network), Azure Virtual Network Manager (utilisez Azure-virtual-network-manager).
