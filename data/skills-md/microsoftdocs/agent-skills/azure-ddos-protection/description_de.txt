Expertenwissen für die Entwicklung von Azure DDoS Protection, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Sicherheit und Konfiguration. Wird verwendet, wenn Sie DDoS-IP-/Netzwerkschutzpläne aktivieren, DDoS-Protokolle analysieren, Rapid Response verwenden oder Azure Policy und andere Entwicklungsaufgaben im Zusammenhang mit dem Azure DDoS-Schutz erzwingen. Nicht für Azure Firewall (verwenden Sie azure-firewall), Azure Web Application Firewall (verwenden Sie azure-web-application-firewall), Azure Virtual Network (verwenden Sie azure-virtual-network), Azure Virtual Network Manager (verwenden Sie azure-virtual-network-manager).
