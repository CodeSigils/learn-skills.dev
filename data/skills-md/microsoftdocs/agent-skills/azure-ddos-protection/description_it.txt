Conoscenza approfondita dello sviluppo della protezione DDos di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, sicurezza e configurazione. Da usare quando si abilitano i piani di protezione IP/rete DDoS, si analizzano i log DDoS, si usa Rapid Response o si applicano criteri di Azure e altre attività di sviluppo correlate alla protezione DDoS di Azure. Non per Firewall di Azure (usare azure-firewall), Firewall applicazione Web di Azure (usare azure-web-application-firewall), Rete virtuale di Azure (usare azure-virtual-network), Gestione rete virtuale di Azure (usare azure-virtual-network-manager).
