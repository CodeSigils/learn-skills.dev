Экспертные знания для разработки Azure DDos Protection, включая устранение неполадок, рекомендации, принятие решений, шаблоны архитектуры и проектирования, безопасность и настройку. Используйте при включении планов защиты IP/сети от DDoS, анализе журналов DDoS, использовании Rapid Response или применении политики Azure, а также при выполнении других задач разработки, связанных с защитой от DDoS. Не для брандмауэра Azure (используйте брандмауэр Azure), брандмауэра веб-приложения Azure (используйте брандмауэр веб-приложения Azure), виртуальной сети Azure (используйте виртуальную сеть Azure), диспетчера виртуальной сети Azure (используйте диспетчер виртуальной сети Azure).
