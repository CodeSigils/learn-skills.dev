문제 해결, 모범 사례, 의사 결정, 아키텍처 및 디자인 패턴, 보안 및 구성을 포함한 Azure DDos Protection 개발에 대한 전문 지식입니다. DDoS IP/네트워크 보호 계획을 활성화하고, DDoS 로그를 구문 분석하고, 신속한 응답을 사용하고, Azure Policy를 적용하고, 기타 Azure DDos Protection 관련 개발 작업을 수행할 때 사용합니다. Azure Firewall(azure-firewall 사용), Azure Web Application Firewall(azure-web-application-firewall 사용), Azure Virtual Network(azure-virtual-network 사용), Azure Virtual Network Manager(azure-virtual-network-manager 사용)에는 해당되지 않습니다.
