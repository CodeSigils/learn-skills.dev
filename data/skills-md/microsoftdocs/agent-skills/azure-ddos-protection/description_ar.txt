معرفة الخبراء بتطوير Azure DDos Protection بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والأمان والتكوين. يُستخدم عند تمكين خطط حماية DDoS IP/الشبكة، أو تحليل سجلات DDoS، أو استخدام الاستجابة السريعة، أو فرض سياسة Azure، ومهام التطوير الأخرى ذات الصلة بحماية Azure DDos. ليس لجدار حماية Azure (استخدم جدار حماية azure)، وجدار حماية تطبيق ويب Azure (استخدم جدار حماية تطبيق ويب azure)، وشبكة Azure الافتراضية (استخدم شبكة azure الافتراضية)، وAzure Virtual Network Manager (استخدم azure-virtual-network-manager).
