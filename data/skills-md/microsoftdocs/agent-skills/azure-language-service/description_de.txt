Nicht für Azure AI Search (verwenden Sie azure-cognitive-search), Azure AI Document Intelligence (verwenden Sie azure-document-intelligence), Azure AI Immersive Reader (verwenden Sie azure-immersive-reader), Azure Translator (verwenden Sie azure-translator).
