Экспертные знания для разработки языка Azure AI, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при создании намерений CLU, пользовательского NER, классификации текста, CQA/FAQ, решений по настроению или обобщению, а также других задач разработки, связанных с языком Azure AI. Не для поиска Azure AI (используйте azure-cognitive-search), Azure AI Document Intelligence (используйте azure-document-intelligence), Azure AI Immersive Reader (используйте azure-immersive-reader), Azure Translator (используйте azure-translator).
