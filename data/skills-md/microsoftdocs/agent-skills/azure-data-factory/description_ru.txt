Экспертные знания для разработки Фабрики данных Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при проектировании конвейеров ADF, сопоставлении потоков данных, развертываниях SHIR/SSIS IR, SAP CDC или CI/CD и других задачах разработки, связанных с фабрикой данных Azure. Не для Azure Synapse Analytics (используйте azure-synapse-analytics), Azure Databricks (используйте azure-databricks), Azure Stream Analytics (используйте azure-stream-analytics), Azure Data Explorer (используйте azure-data-explorer).
