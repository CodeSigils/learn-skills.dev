معرفة الخبراء بتطوير Azure Data Factory بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تصميم خطوط أنابيب ADF، وتعيين تدفقات البيانات، أو عمليات نشر SHIR/SSIS IR، أو SAP CDC، أو CI/CD، ومهام التطوير الأخرى ذات الصلة بـ Azure Data Factory. ليس لـ Azure Synapse Analytics (استخدم azure-synapse-analytics)، وAzure Databricks (استخدم azure-databricks)، وAzure Stream Analytics (استخدم تحليلات azure-stream)، وAzure Data Explorer (استخدم مستكشف بيانات azure).
