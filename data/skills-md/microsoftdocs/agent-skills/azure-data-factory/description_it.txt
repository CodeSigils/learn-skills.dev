Conoscenza approfondita dello sviluppo di Azure Data Factory, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la progettazione di pipeline ADF, la mappatura di flussi di dati, distribuzioni SHIR/SSIS IR, SAP CDC o CI/CD e altre attività di sviluppo correlate ad Azure Data Factory. Non per Analisi sinapsi di Azure (usare azure-synapse-analytics), Azure Databricks (usare azure-databricks), Analisi di flusso di Azure (usare azure-stream-analytics), Azure Esplora dati (usare azure-data-explorer).
