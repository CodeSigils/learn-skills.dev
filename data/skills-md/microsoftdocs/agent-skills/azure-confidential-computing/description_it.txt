Conoscenza approfondita dello sviluppo di Azure Confidential Computing, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Usare quando si usano VM SGX/SEV-SNP, contenitori riservati AKS, attestazione/SKR, vTPM o Fortanix/Key Vault e altre attività di sviluppo correlate al calcolo riservato di Azure. Non per enclave virtuali di Azure (usare azure-virtual-enclaves), Macchine virtuali di Azure (usare azure-virtual-machines), HSM dedicato di Azure (usare azure-dedicated-hsm), Attestazione di Azure (usare azure-attestation).
