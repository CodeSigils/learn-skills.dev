Экспертные знания для разработки конфиденциальных вычислений Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании виртуальных машин SGX/SEV-SNP, конфиденциальных контейнеров AKS, аттестации/SKR, vTPM или Fortanix/Key Vault, а также других задач разработки, связанных с конфиденциальными вычислениями Azure. Не для виртуальных анклавов Azure (используйте azure-virtual-enclaves), виртуальных машин Azure (используйте azure-virtual-machines), выделенного HSM Azure (используйте azure-dedicated-hsm), Azure Attestation (используйте azure-attestation).
