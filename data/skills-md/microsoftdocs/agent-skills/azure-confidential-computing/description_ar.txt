معرفة الخبراء بتطوير Azure Confidential Computing بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام أجهزة افتراضية SGX/SEV-SNP، أو حاويات AKS السرية، أو التصديق/SKR، أو vTPM، أو Fortanix/Key Vault، ومهام التطوير الأخرى ذات الصلة بحوسبة Azure السرية. ليس لـ Azure Virtual Enclaves (استخدم azure-virtual-enclaves)، وأجهزة Azure الافتراضية (استخدم azure-virtual-machines)، وAzure Dedicated HSM (استخدم azure-dedicated-hsm)، وAzure Attestation (استخدم شهادة azure).
