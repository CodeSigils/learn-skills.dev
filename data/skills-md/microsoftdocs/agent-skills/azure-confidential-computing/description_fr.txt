Connaissance approfondie du développement d'Azure Confidential Computing, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'utilisation de machines virtuelles SGX/SEV-SNP, de conteneurs confidentiels AKS, d'attestation/SKR, de vTPM ou Fortanix/Key Vault et d'autres tâches de développement liées à Azure Confidential Computing. Pas pour Azure Virtual Enclaves (utilisez azure-virtual-enclaves), Azure Virtual Machines (utilisez azure-virtual-machines), Azure Dedicated HSM (utilisez azure-dedicated-hsm), Azure Attestation (utilisez azure-attestation).
