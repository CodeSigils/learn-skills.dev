Экспертные знания для разработки партнерских решений Azure, включая устранение неполадок, принятие решений, шаблоны архитектуры и проектирования, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при использовании Service Connector, Confluent Cloud, MongoDB Atlas, Dynatrace APM или Palo Alto Cloud NGFW в Azure, а также других задач разработки, связанных с решениями партнеров Azure. Не для отрасли Azure (используйте azure-industry), управляемых приложений Azure (используйте приложения, управляемые azure), Azure Lighthouse (используйте azure-lighthouse), сетей Azure (используйте azure-networking).
