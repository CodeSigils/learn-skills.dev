معرفة الخبراء بتطوير Azure Partner Solutions بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار وأنماط الهندسة والتصميم والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند استخدام Service Connector، أو Confluent Cloud، أو MongoDB Atlas، أو Dynatrace APM، أو Palo Alto Cloud NGFW على Azure، ومهام التطوير الأخرى ذات الصلة بـ Azure Partner Solutions. ليس مخصصًا لصناعة Azure (استخدم صناعة azure)، وتطبيقات Azure المُدارة (استخدم تطبيقات azure المُدارة)، وAzure Lighthouse (استخدم منارة azure)، وشبكات Azure (استخدم شبكات azure).
