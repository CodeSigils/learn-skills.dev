Connaissance approfondie du développement de solutions partenaires Azure, y compris le dépannage, la prise de décision, les modèles d'architecture et de conception, la sécurité, la configuration, ainsi que les modèles d'intégration et de codage. À utiliser lors de l'utilisation de Service Connector, Confluent Cloud, MongoDB Atlas, Dynatrace APM ou Palo Alto Cloud NGFW sur Azure et d'autres tâches de développement liées aux solutions partenaires Azure. Pas pour Azure Industry (utilisez Azure-Industry), Azure Managed Applications (utilisez Azure-Managed-Applications), Azure Lighthouse (utilisez Azure-Lighthouse), Azure Networking (utilisez Azure-Networking).
