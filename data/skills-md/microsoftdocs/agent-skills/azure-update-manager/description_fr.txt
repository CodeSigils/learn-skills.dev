À utiliser lors de la gestion des correctifs VM/Arc, des profils Automanage, des planifications hotpatch/ESU, du suivi des modifications ou de l'automatisation SDK/REST et d'autres tâches de développement liées à Azure Update Manager. Pas pour Azure Automation (utilisez azure-automation), Azure Monitor (utilisez azure-monitor), Azure Osconfig (utilisez azure-osconfig), Azure Virtual Machines (utilisez azure-virtual-machines).
