Экспертные знания для разработки Azure Update Manager, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при управлении исправлениями виртуальных машин/Arc, профилях автоматического управления, расписаниях горячего исправления/ESU, отслеживании изменений или автоматизации SDK/REST, а также при выполнении других задач разработки, связанных с Azure Update Manager. Не для автоматизации Azure (используйте azure-automation), Azure Monitor (используйте azure-monitor), Azure Osconfig (используйте azure-osconfig), виртуальных машин Azure (используйте azure-virtual-machines).
