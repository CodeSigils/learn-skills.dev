معرفة الخبراء بتطوير Azure Update Manager بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إدارة تصحيح VM/Arc، أو الإدارة التلقائية لملفات التعريف، أو جداول التصحيح السريع/ESU، أو تعقب التغيير، أو أتمتة SDK/REST، ومهام التطوير الأخرى ذات الصلة بـ Azure Update Manager. ليس لـ Azure Automation (استخدم azure-automation)، وAzure Monitor (استخدم azure-monitor)، وAzure Osconfig (استخدم azure-osconfig)، وأجهزة Azure الافتراضية (استخدم الأجهزة الافتراضية azure).
