Expertenwissen für die Azure Dedicated HSM-Entwicklung, einschließlich Fehlerbehebung, Entscheidungsfindung, Architektur- und Designmuster, Sicherheit und Bereitstellung. Verwenden Sie diese Option, wenn Sie die Größe von HSM-Clustern anpassen, VNets/ExpressRoute konfigurieren, die Migration von verwaltetem HSM planen oder Probleme mit dem Anbietersupport lösen, sowie für andere Entwicklungsaufgaben im Zusammenhang mit Azure Dedicated HSM.
