Conoscenza approfondita dello sviluppo di HSM dedicati di Azure, tra cui risoluzione dei problemi, processo decisionale, architettura e modelli di progettazione, sicurezza e distribuzione. Da utilizzare per il dimensionamento dei cluster HSM, la configurazione di reti virtuali/ExpressRoute, la pianificazione della migrazione di HSM gestiti o la risoluzione di problemi di supporto del fornitore e altre attività di sviluppo correlate all'HSM dedicato di Azure. Non per Azure Cloud Hsm (usare azure-cloud-hsm), Azure Key Vault (usare azure-key-vault), Azure Payment Hsm (usare azure-payment-hsm).
