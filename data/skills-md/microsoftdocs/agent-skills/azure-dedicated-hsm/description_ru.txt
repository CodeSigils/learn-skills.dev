Экспертные знания для разработки Azure Dedicated HSM, включая устранение неполадок, принятие решений, шаблоны архитектуры и проектирования, безопасность и развертывание. Используйте при определении размера кластеров HSM, настройке виртуальных сетей/ExpressRoute, планировании управляемой миграции HSM или решении проблем с поддержкой поставщиков, а также других задачах разработки, связанных с выделенным HSM Azure. Не для Azure Cloud Hsm (используйте azure-cloud-hsm), Azure Key Vault (используйте azure-key-vault), Azure Payment Hsm (используйте azure-pay-hsm).
