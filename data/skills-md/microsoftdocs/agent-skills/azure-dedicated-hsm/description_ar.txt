معرفة الخبراء بتطوير Azure Dedicated HSM بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار والهندسة المعمارية وأنماط التصميم والأمان والنشر. يُستخدم عند تحديد حجم مجموعات HSM، أو تكوين VNets/ExpressRoute، أو التخطيط لترحيل HSM المُدار، أو حل مشكلات دعم البائعين، ومهام التطوير الأخرى ذات الصلة بـ Azure Dedicated HSM. ليس لـ Azure Cloud Hsm (استخدم azure-cloud-hsm)، وAzure Key Vault (استخدم azure-key-vault)، وAzure Payment Hsm (استخدم azure- Payment-hsm).
