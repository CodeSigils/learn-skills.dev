معرفة الخبراء لتطوير Azure Api Center بما في ذلك أفضل الممارسات والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند أتمتة عملية فحص/تسجيل واجهة برمجة التطبيقات (API)، أو تخصيص البوابة الإلكترونية، أو المزامنة مع بوابات واجهة برمجة التطبيقات (API)، أو فرض إدارة وقت التصميم، ومهام التطوير الأخرى ذات الصلة بـ Azure Api Center. ليس لإدارة Azure API (استخدم azure-api-management)، وتكوين تطبيق Azure (استخدم تكوين تطبيق azure)، وموصل خدمة Azure (استخدم موصل خدمة azure).
