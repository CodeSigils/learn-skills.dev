Conoscenza approfondita dello sviluppo di Azure Api Center, incluse procedure consigliate, sicurezza, configurazione, integrazioni, modelli di codifica e distribuzione. Da utilizzare per l'automazione dell'linting/registrazione delle API, la personalizzazione del portale, la sincronizzazione con i gateway API o l'applicazione della governance in fase di progettazione e altre attività di sviluppo correlate al Centro API di Azure. Non per Gestione API di Azure (usare azure-api-management), Configurazione app di Azure (usare azure-app-configuration), Connettore del servizio di Azure (usare azure-service-connector).
