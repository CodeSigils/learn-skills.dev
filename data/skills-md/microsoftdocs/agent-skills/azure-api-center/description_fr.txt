Connaissance approfondie du développement d'Azure Api Center, y compris les meilleures pratiques, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'automatisation du linting/enregistrement d'API, de la personnalisation du portail, de la synchronisation avec des passerelles API ou de l'application de la gouvernance au moment de la conception, ainsi que d'autres tâches de développement liées à Azure Api Center. Pas pour Azure API Management (utilisez azure-api-management), Azure App Configuration (utilisez azure-app-configuration), Azure Service Connector (utilisez azure-service-connector).
