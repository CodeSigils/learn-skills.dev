Экспертные знания для разработки Azure Api Center, включая лучшие практики, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при автоматизации проверки/регистрации API, настройке портала, синхронизации со шлюзами API или обеспечении управления во время разработки, а также при выполнении других задач разработки, связанных с Azure Api Center. Не для управления API Azure (используйте azure-api-management), конфигурации приложений Azure (используйте azure-app-configuration), Azure Service Connector (используйте azure-service-connector).
