トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、展開など、Azure IoT Hub 開発に関する専門知識。 DPS 登録、デバイス ツイン/メソッド/ジョブ、メッセージ ルーティング/エンドポイント、デバイス更新、または Cosmos DB シンク、およびその他の Azure IoT Hub 関連の開発タスクを使用する場合に使用します。 Azure IoT (azure-iot を使用)、Azure IoT Central (azure-iot-central を使用)、Azure IoT Edge (azure-iot-edge を使用)、Azure IoT Operations (azure-iot-operations を使用) には使用できません。
