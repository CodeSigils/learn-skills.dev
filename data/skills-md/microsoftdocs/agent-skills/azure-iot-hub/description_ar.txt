معرفة الخبراء بتطوير Azure IoT Hub بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام تسجيلات DPS، أو توائم/طرق/وظائف الجهاز، أو توجيه الرسائل/نقاط النهاية، أو تحديث الجهاز، أو منافذ Cosmos DB، ومهام التطوير الأخرى ذات الصلة بـ Azure IoT Hub. ليس لـ Azure IoT (استخدم azure-iot)، وAzure IoT Central (استخدم azure-iot-central)، وAzure IoT Edge (استخدم azure-iot-edge)، وعمليات Azure IoT (استخدم عمليات azure-iot).
