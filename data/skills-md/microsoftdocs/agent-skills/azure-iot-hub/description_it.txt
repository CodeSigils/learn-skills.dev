Conoscenza approfondita dello sviluppo dell'hub IoT di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usano registrazioni DPS, dispositivi gemelli/metodi/processi, routing dei messaggi/endpoint, aggiornamento dispositivi o sink Cosmos DB e altre attività di sviluppo correlate all'hub IoT di Azure. Non per Azure IoT (usare azure-iot), Azure IoT Central (usare azure-iot-central), Azure IoT Edge (usare azure-iot-edge), Azure IoT Operations (usare azure-iot-operazioni).
