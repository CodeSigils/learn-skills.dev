Экспертные знания для разработки Azure IoT Hub, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании регистрации DPS, двойников устройств/методов/заданий, маршрутизации сообщений/конечных точек, обновления устройств или приемников Cosmos DB, а также других задач разработки, связанных с Azure IoT Hub. Не для Azure IoT (используйте azure-iot), Azure IoT Central (используйте azure-iot-central), Azure IoT Edge (используйте azure-iot-edge), Azure IoT Operations (используйте azure-iot-operations).
