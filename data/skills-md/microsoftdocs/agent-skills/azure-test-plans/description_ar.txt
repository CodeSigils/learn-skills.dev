معرفة الخبراء بتطوير خطط اختبار Azure بما في ذلك الحدود والحصص والأمان والتكامل وأنماط الترميز. يُستخدم عند تكوين حقول الاختبار، أو إدارة الوصول للاختبار، أو أتمتة المجموعات وعمليات التشغيل والتكوينات عبر tcm.exe، ومهام التطوير الأخرى ذات الصلة بخطط اختبار Azure. ليس لـ Azure DevOps (استخدم azure-devops)، ولوحات Azure (استخدم لوحات azure)، وAzure Pipelines (استخدم خطوط أنابيب azure)، واختبار تطبيق Azure (استخدم اختبار تطبيق azure).
