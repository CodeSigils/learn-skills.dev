Expertenwissen für die Entwicklung von Azure-Testplänen, einschließlich Grenzwerten und Kontingenten, Sicherheit sowie Integrationen und Codierungsmustern. Verwenden Sie diese Option, wenn Sie Testfelder konfigurieren, den Testzugriff verwalten oder Suiten, Ausführungen und Konfigurationen über tcm.exe und andere Entwicklungsaufgaben im Zusammenhang mit Azure Test Plans automatisieren. Nicht für Azure DevOps (verwenden Sie azure-devops), Azure Boards (verwenden Sie azure-boards), Azure Pipelines (verwenden Sie azure-pipelines), Azure App Testing (verwenden Sie azure-app-testing).
