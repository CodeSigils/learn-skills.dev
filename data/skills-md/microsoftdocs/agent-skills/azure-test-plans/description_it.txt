Conoscenza approfondita dello sviluppo di piani di test di Azure, inclusi limiti e quote, sicurezza, integrazioni e modelli di codifica. Da utilizzare durante la configurazione dei campi di test, la gestione dell'accesso ai test o l'automazione di suite, esecuzioni e configurazioni tramite tcm.exe e altre attività di sviluppo correlate ai piani di test di Azure. Non per Azure DevOps (usare azure-devops), Azure Boards (usare azure-boards), Azure Pipelines (usare azure-pipelines), Azure App Testing (usare azure-app-testing).
