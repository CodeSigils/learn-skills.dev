Экспертные знания для разработки планов тестирования Azure, включая ограничения и квоты, безопасность, интеграцию и шаблоны кодирования. Используйте при настройке полей теста, управлении доступом к тестам или автоматизации наборов, запусков и конфигураций с помощью tcm.exe, а также других задач разработки, связанных с планами тестирования Azure. Не для Azure DevOps (используйте azure-devops), Azure Boards (используйте azure-boards), Azure Pipelines (используйте azure-pipelines), Azure App Testing (используйте azure-app-testing).
