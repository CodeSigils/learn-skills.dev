Экспертные знания для разработки иммерсивного средства чтения Azure AI, включая лучшие практики, ограничения и квоты, безопасность, конфигурацию, а также интеграцию и шаблоны кодирования. Используйте при настройке чтения вслух/переводе, сохранении пользовательских настроек, настройке аутентификации Entra, интеграции JS SDK или языковой поддержке, а также других задачах разработки, связанных с Azure AI Immersive Reader. Не для языка Azure AI (используйте azure-language-service), Azure AI Speech (используйте azure-speech), Azure Translator (используйте azure-translator), Azure AI Services (используйте Microsoft-foundry-tools).
