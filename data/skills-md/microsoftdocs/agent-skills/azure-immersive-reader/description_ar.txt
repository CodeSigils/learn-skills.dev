معرفة الخبراء بتطوير Azure AI Immersive Reader بما في ذلك أفضل الممارسات والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند ضبط القراءة بصوت عالٍ/الترجمة، أو تخزين تفضيلات المستخدم، أو إعداد مصادقة Entra، أو تكامل JS SDK، أو دعم اللغة، ومهام التطوير الأخرى ذات الصلة بـ Azure AI Immersive Reader. ليس للغة Azure AI (استخدم خدمة اللغة azure)، وAzure AI Speech (استخدم الكلام azure)، وAzure Translator (استخدم مترجم azure)، وخدمات Azure AI (استخدم أدوات microsoft Foundry).
