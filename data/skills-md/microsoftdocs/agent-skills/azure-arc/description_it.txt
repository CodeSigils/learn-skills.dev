Conoscenza approfondita dello sviluppo di Azure Arc, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la gestione di Kubernetes, server, SQL MI, Edge RAG, Resource Bridge o carichi di lavoro SCVMM/vSphere abilitati per Arc e altre attività di sviluppo correlate ad Azure Arc. Non per il servizio Azure Kubernetes (AKS) (usare azure-kubernetes-service), Macchine virtuali di Azure (usare azure-virtual-machines), Azure Stack Edge (usare azure-stack-edge), Soluzione VMware di Azure (usare azure-vmware-solution).
