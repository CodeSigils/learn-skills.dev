Экспертные знания для разработки Azure Arc, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при управлении Kubernetes с поддержкой Arc, серверами, SQL MI, Edge RAG, мостом ресурсов или рабочими нагрузками SCVMM/vSphere, а также другими задачами разработки, связанными с Azure Arc. Не для службы Azure Kubernetes (AKS) (используйте azure-kubernetes-service), виртуальных машин Azure (используйте azure-virtual-machines), Azure Stack Edge (используйте azure-stack-edge), решения Azure VMware (используйте azure-vmware-solution).
