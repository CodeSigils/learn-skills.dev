معرفة الخبراء بتطوير Azure Arc بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إدارة Kubernetes أو الخوادم أو SQL MI أو Edge RAG أو جسر الموارد أو أحمال عمل SCVMM/vSphere التي تدعم Arc، ومهام التطوير الأخرى ذات الصلة بـ Azure Arc. ليس لخدمة Azure Kubernetes (AKS) (استخدم azure-kubernetes-service)، وأجهزة Azure الافتراضية (استخدم azure-virtual-machines)، وAzure Stack Edge (استخدم azure-stack-edge)، وAzure VMware Solution (استخدم azure-vmware-solution).
