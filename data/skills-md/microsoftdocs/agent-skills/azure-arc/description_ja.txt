トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、展開など、Azure Arc 開発に関する専門知識。 Arc 対応の Kubernetes、サーバー、SQL MI、Edge RAG、リソース ブリッジ、または SCVMM/vSphere ワークロード、およびその他の Azure Arc 関連の開発タスクを管理する場合に使用します。 Azure Kubernetes Service (AKS) (azure-kubernetes-service を使用)、Azure Virtual Machines (azure-virtual-machines を使用)、Azure Stack Edge (azure-stack-edge を使用)、Azure VMware Solution (azure-vmware-solution を使用) には適用されません。
