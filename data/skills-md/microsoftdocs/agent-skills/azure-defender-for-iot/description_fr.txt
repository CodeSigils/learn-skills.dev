Connaissance approfondie du développement d'Azure Defender For IoT, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors du déploiement de capteurs OT, de la configuration de micro-agents, de la configuration de la mise en miroir du trafic ou de l'intégration avec Sentinel/SIEM et d'autres tâches de développement liées à Azure Defender For IoT. Pas pour Azure Defender For Cloud (utilisez Azure-defender-for-cloud), Azure Security (utilisez Azure-security), Azure External Attack Surface Management (utilisez Azure-external-attack-surface-management), Azure Sentinel (utilisez Azure-sentinel).
