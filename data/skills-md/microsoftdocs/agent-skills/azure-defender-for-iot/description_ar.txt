معرفة الخبراء بتطوير Azure Defender For Iot بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند نشر مستشعرات OT، أو تكوين العوامل الدقيقة، أو إعداد النسخ المتطابق لحركة المرور، أو التكامل مع Sentinel/SIEM، ومهام التطوير الأخرى ذات الصلة بـ Azure Defender For Iot. ليس لـ Azure Defender For Cloud (استخدم azure-defender-for-cloud)، وAzure Security (استخدم azure-security)، وإدارة سطح الهجوم الخارجي لـ Azure (استخدم azure-external-attack-surface-management)، وAzure Sentinel (استخدم azure-sentinel).
