Conoscenza approfondita dello sviluppo di Azure Defender per IoT, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la distribuzione di sensori OT, la configurazione di micro agenti, l'impostazione del mirroring del traffico o l'integrazione con Sentinel/SIEM e altre attività di sviluppo correlate ad Azure Defender For Iot. Non per Azure Defender for Cloud (usare azure-defender-for-cloud), Sicurezza di Azure (usare azure-security), Gestione superficie di attacco esterna di Azure (usare azure-external-attack-surface-management), Azure Sentinel (usare azure-sentinel).
