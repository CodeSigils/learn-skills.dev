Экспертные знания по разработке Azure Defender для Интернета, включая устранение неполадок, рекомендации, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при развертывании датчиков OT, настройке микроагентов, настройке зеркалирования трафика или интеграции с Sentinel/SIEM, а также при выполнении других задач разработки, связанных с Защитником Azure для Интернета. Не для Защитника Azure для облака (используйте azure-defender-for-cloud), Безопасность Azure (используйте azure-security), Управление внешней поверхностью атаки Azure (используйте azure-external-attack-surface-management), Azure Sentinel (используйте azure-sentinel).
