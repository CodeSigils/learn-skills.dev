Экспертные знания по разработке ботов Azure Health, включая лучшие практики, принятие решений, шаблоны архитектуры и проектирования, безопасность, конфигурацию, а также шаблоны интеграции и кодирования. Используйте при настройке каналов Health Bot, веб-чата или внедрения голоса, API управления, потоков оркестратора или оценки затрат, а также других задач разработки, связанных с Azure Health Bot. Не для службы Azure AI Bot (используйте azure-bot-service), Azure Communication Services (используйте azure-communication-services), Azure Health Data Services (используйте azure-health-data-services).
