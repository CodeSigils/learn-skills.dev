معرفة الخبراء بتطوير Azure Health Bot بما في ذلك أفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند تكوين قنوات Health Bot، أو الدردشة عبر الويب/التضمينات الصوتية، أو واجهات برمجة تطبيقات الإدارة، أو تدفقات المنسق، أو تقدير التكلفة، ومهام التطوير الأخرى ذات الصلة بـ Azure Health Bot. ليس لخدمة Azure AI Bot Service (استخدم azure-bot-service)، وخدمات اتصالات Azure (استخدم خدمات الاتصالات azure)، وخدمات Azure Health Data Services (استخدم خدمات البيانات الصحية azure).
