Conoscenza approfondita dello sviluppo di Azure Health Bot, tra cui best practice, processo decisionale, architettura e modelli di progettazione, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare durante la configurazione di canali di Health Bot, incorporamenti vocali/chat Web, API di gestione, flussi di orchestrazione o stima dei costi e altre attività di sviluppo correlate ad Azure Health Bot. Non per il servizio Azure AI Bot (usare azure-bot-service), Servizi di comunicazione di Azure (usare azure-communication-services), Azure Health Data Services (usare azure-health-data-services).
