Expertenwissen für die Entwicklung des Azure SignalR-Dienstes, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Verwenden Sie diese Option, wenn Sie den SignalR-Modus auswählen, Upstreams/benutzerdefinierte Domänen konfigurieren, mit Entra ID/MI sichern, Skalierung/Sharding oder Nachverfolgungsprobleme sowie andere Entwicklungsaufgaben im Zusammenhang mit Azure SignalR Service durchführen. Nicht für Azure Web PubSub (verwenden Sie azure-web-pubsub), Azure Service Bus (verwenden Sie azure-service-bus), Azure Event Hubs (verwenden Sie azure-event-hubs).
