معرفة الخبراء بتطوير خدمة Azure SignalR بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند اختيار وضع SignalR، أو تكوين المنبع/المجالات المخصصة، أو التأمين باستخدام Entra ID/MI، أو القياس/التقسيم، أو مشكلات التتبع، ومهام التطوير الأخرى ذات الصلة بخدمة Azure SignalR. ليس لـ Azure Web PubSub (استخدم azure-web-pubsub)، وناقل خدمة Azure (استخدم azure-service-bus)، ومراكز أحداث Azure (استخدم مراكز أحداث azure).
