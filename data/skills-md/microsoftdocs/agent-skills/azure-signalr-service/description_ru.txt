Экспертные знания для разработки службы Azure SignalR, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при выборе режима SignalR, настройке восходящих/пользовательских доменов, защите с помощью Entra ID/MI, масштабировании/шардинге или отслеживании проблем, а также других задачах разработки, связанных со службой Azure SignalR. Не для Azure Web PubSub (используйте azure-web-pubsub), Azure Service Bus (используйте azure-service-bus), Центров событий Azure (используйте azure-event-hubs).
