Conoscenza approfondita dello sviluppo del servizio Azure SignalR, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si sceglie la modalità SignalR, la configurazione di upstream/domini personalizzati, la protezione con Entra ID/MI, ridimensionamento/sharding o problemi di traccia e altre attività di sviluppo correlate al servizio Azure SignalR. Non per PubSub Web di Azure (usare azure-web-pubsub), Bus di servizio di Azure (usare azure-service-bus), Hub eventi di Azure (usare azure-event-hubs).
