トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、デプロイなど、Azure SignalR Service 開発に関する専門知識。 SignalR モードの選択、アップストリーム/カスタム ドメインの構成、Entra ID/MI によるセキュリティ保護、スケーリング/シャーディング、または問題のトレース、およびその他の Azure SignalR Service 関連の開発タスクを行うときに使用します。 Azure Web PubSub (azure-web-pubsub を使用)、Azure Service Bus (azure-service-bus を使用)、Azure Event Hubs (azure-event-hubs を使用) には使用できません。
