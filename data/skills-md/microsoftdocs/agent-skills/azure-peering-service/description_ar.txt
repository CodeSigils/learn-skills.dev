معرفة الخبراء لتطوير خدمة Azure Peering بما في ذلك أفضل الممارسات. يُستخدم عند تصميم بادئات خدمة Peering، أو سياسات التوجيه، أو قواعد التحقق من صحة البادئة، أو قيود الاتصال، ومهام التطوير الأخرى ذات الصلة بخدمة Azure Peering Service. ليس لـ Azure Internet Peering (استخدم azure-internet-peering)، وAzure Virtual Network (استخدم azure-virtual-network)، وAzure Virtual WAN (استخدم azure-virtual-wan)، وAzure ExpressRoute (استخدم azure-expressroute).
