ベスト プラクティスを含む、Azure Peering Service 開発に関する専門知識。ピアリング サービスのプレフィックス、ルーティング ポリシー、プレフィックス検証ルール、接続制約、およびその他の Azure Peering Service 関連の開発タスクを設計するときに使用します。 Azure インターネット ピアリング (azure-internet-peering を使用)、Azure Virtual Network (azure-virtual-network を使用)、Azure Virtual WAN (azure-virtual-wan を使用)、Azure ExpressRoute (azure-expressroute を使用) には使用できません。
