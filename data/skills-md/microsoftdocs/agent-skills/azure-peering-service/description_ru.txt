Экспертные знания по разработке служб пиринга Azure, включая лучшие практики. Используйте при разработке префиксов службы пиринга, политик маршрутизации, правил проверки префиксов или ограничений подключения, а также других задач разработки, связанных со службой пиринга Azure. Не для интернет-пиринга Azure (используйте azure-internet-peering), виртуальной сети Azure (используйте azure-virtual-network), виртуальной глобальной сети Azure (используйте azure-virtual-wan), Azure ExpressRoute (используйте azure-expressroute).
