모범 사례를 포함한 Azure Peering Service 개발에 대한 전문 지식입니다. Peering Service 접두사, 라우팅 정책, 접두사 유효성 검사 규칙 또는 연결 제약 조건 및 기타 Azure Peering Service 관련 개발 작업을 디자인할 때 사용합니다. Azure 인터넷 피어링(azure-internet-peering 사용), Azure Virtual Network(azure-virtual-network 사용), Azure Virtual WAN(azure-virtual-wan 사용), Azure ExpressRoute(azure-expressroute 사용)에는 적합하지 않습니다.
