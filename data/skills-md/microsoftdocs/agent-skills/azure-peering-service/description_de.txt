Expertenwissen für die Entwicklung des Azure Peering Service, einschließlich Best Practices. Verwenden Sie diese Option beim Entwerfen von Peering Service-Präfixen, Routing-Richtlinien, Präfixvalidierungsregeln oder Konnektivitätsbeschränkungen sowie anderen Entwicklungsaufgaben im Zusammenhang mit dem Azure Peering Service. Nicht für Azure Internet Peering (verwenden Sie azure-internet-peering), Azure Virtual Network (verwenden Sie azure-virtual-network), Azure Virtual WAN (verwenden Sie azure-virtual-wan), Azure ExpressRoute (verwenden Sie azure-expressroute).
