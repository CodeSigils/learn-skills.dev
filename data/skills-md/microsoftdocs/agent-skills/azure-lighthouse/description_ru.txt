Экспертные знания для разработки Azure Lighthouse, включая принятие решений, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при проектировании мультитенантного делегирования, доступа RBAC/AOBO/PIM, адаптации на основе политик, интеграции Arc/Sentinel или предложений Marketplace, а также других задач разработки, связанных с Azure Lighthouse. Не для Azure Arc (используйте azure-arc), управляемых приложений Azure (используйте приложения, управляемые azure), Azure Resource Manager (используйте azure-resource-manager).
