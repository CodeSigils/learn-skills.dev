معرفة الخبراء بتطوير Azure Lighthouse بما في ذلك اتخاذ القرار والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تصميم تفويضات متعددة المستأجرين، أو الوصول إلى RBAC/AOBO/PIM، أو الإعداد المستند إلى السياسة، أو عمليات تكامل Arc/Sentinel، أو عروض Marketplace، ومهام التطوير الأخرى ذات الصلة بـ Azure Lighthouse. ليس لـ Azure Arc (استخدم azure-arc)، وتطبيقات Azure Managed (استخدم تطبيقات azure Managed)، وAzure Resource Manager (استخدم azure-resource-manager).
