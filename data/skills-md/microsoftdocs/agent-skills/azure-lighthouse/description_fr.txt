Connaissance experte du développement Azure Lighthouse, y compris la prise de décision, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la conception de délégations multi-locataires, d'accès RBAC/AOBO/PIM, d'intégration basée sur des stratégies, d'intégrations Arc/Sentinel ou d'offres Marketplace, ainsi que d'autres tâches de développement liées à Azure Lighthouse. Pas pour Azure Arc (utilisez azure-arc), Azure Managed Applications (utilisez azure-managed-applications), Azure Resource Manager (utilisez azure-resource-manager).
