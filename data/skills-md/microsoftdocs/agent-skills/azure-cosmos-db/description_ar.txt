معرفة الخبراء بتطوير قاعدة بيانات Azure Cosmos بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام واجهات برمجة تطبيقات Cosmos DB (NoSQL، وMongo، وCassandra، وPostgres)، أو تغيير الموجز، أو التوزيع العالمي، أو بحث المتجهات، أو HTAP، ومهام التطوير الأخرى ذات الصلة بـ Azure Cosmos DB. ليس مخصصًا لتخزين جدول Azure (استخدم azure-table-storage)، وقاعدة بيانات Azure SQL (استخدم قاعدة بيانات azure-sql)، وقاعدة بيانات Azure لـ MySQL (استخدم azure-database-mysql)، وقاعدة بيانات Azure لـ PostgreSQL (استخدم قاعدة بيانات azure-postgresql).
