Экспертные знания для разработки Azure Cosmo DB, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании API Cosmos DB (NoSQL, Mongo, Cassandra, Postgres), канала изменений, глобального распространения, векторного поиска или HTAP, а также других задач разработки, связанных с Azure Cosmo DB. Не для хранилища таблиц Azure (используйте azure-table-storage), базы данных SQL Azure (используйте azure-sql-database), базы данных Azure для MySQL (используйте azure-database-mysql), базы данных Azure для PostgreSQL (используйте azure-database-postgresql).
