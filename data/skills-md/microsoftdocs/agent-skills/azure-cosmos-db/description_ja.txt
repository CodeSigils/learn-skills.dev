トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、デプロイなど、Azure Cosmos DB 開発に関する専門知識。 Cosmos DB API (NoSQL、Mongo、Cassandra、Postgres)、変更フィード、グローバル分散、ベクター検索、または HTAP、およびその他の Azure Cosmos DB 関連の開発タスクを使用する場合に使用します。 Azure Table Storage (azure-table-storage を使用)、Azure SQL Database (azure-sql-database を使用)、Azure Database for MySQL (azure-database-mysql を使用)、Azure Database for PostgreSQL (azure-database-postgresql を使用) には使用できません。
