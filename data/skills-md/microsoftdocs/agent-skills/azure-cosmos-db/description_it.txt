Conoscenza approfondita dello sviluppo di Azure Cosmos DB, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usano API Cosmos DB (NoSQL, Mongo, Cassandra, Postgres), feed di modifiche, distribuzione globale, ricerca vettoriale o HTAP e altre attività di sviluppo correlate ad Azure Cosmos DB. Non per archiviazione tabelle di Azure (usare azure-table-storage), database SQL di Azure (usare azure-sql-database), database di Azure per MySQL (usare azure-database-mysql), database di Azure per PostgreSQL (usare azure-database-postgresql).
