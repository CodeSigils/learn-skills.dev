Azure Cosmos DB 開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在使用 Cosmos DB API（NoSQL、Mongo、Cassandra、Postgres）、變更來源、全域分發、向量搜尋或 HTAP 以及其他 Azure Cosmos DB 相關開發任務時使用。不適用於 Azure 表格儲存體（使用 azure-table-storage）、Azure SQL 資料庫（使用 azure-sql-database）、Azure Database for MySQL（使用 azure-database-mysql）、Azure Database for PostgreSQL（使用 azure-database-postgresql）。
