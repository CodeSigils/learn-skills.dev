Connaissance experte du développement Azure Cosmos DB, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'utilisation des API Cosmos DB (NoSQL, Mongo, Cassandra, Postgres), du flux de modification, de la distribution globale, de la recherche vectorielle ou HTAP et d'autres tâches de développement liées à Azure Cosmos DB. Pas pour Azure Table Storage (utilisez azure-table-storage), Azure SQL Database (utilisez azure-sql-database), Azure Database pour MySQL (utilisez azure-database-mysql), Azure Database pour PostgreSQL (utilisez azure-database-postgresql).
