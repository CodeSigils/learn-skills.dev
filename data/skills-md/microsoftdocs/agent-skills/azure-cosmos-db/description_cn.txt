Azure Cosmos DB 开发的专业知识，包括故障排除、最佳实践、决策、体系结构和设计模式、限制和配额、安全性、配置、集成和编码模式以及部署。在使用 Cosmos DB API（NoSQL、Mongo、Cassandra、Postgres）、更改源、全局分发、矢量搜索或 HTAP 以及其他 Azure Cosmos DB 相关开发任务时使用。不适用于 Azure 表存储（使用 azure-table-storage）、Azure SQL 数据库（使用 azure-sql-database）、Azure Database for MySQL（使用 azure-database-mysql）、Azure Database for PostgreSQL（使用 azure-database-postgresql）。
