Expertenwissen für die Azure Cosmos DB-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird verwendet, wenn Sie Cosmos DB-APIs (NoSQL, Mongo, Cassandra, Postgres), Änderungsfeeds, globale Verteilung, Vektorsuche oder HTAP und andere Azure Cosmos DB-bezogene Entwicklungsaufgaben verwenden. Nicht für Azure Table Storage (verwenden Sie azure-table-storage), Azure SQL-Datenbank (verwenden Sie azure-sql-database), Azure Database for MySQL (verwenden Sie azure-database-mysql), Azure Database for PostgreSQL (verwenden Sie azure-database-postgresql).
