Экспертные знания для разработки Azure Load Balancer, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке интерфейсных и серверных интерфейсов, проверок работоспособности, SNAT/исходящих API-интерфейсов, IMDS/метрик или миграции «Базовый → Стандартный», а также других задач разработки, связанных с Azure Load Balancer. Не для шлюза приложений Azure (используйте azure-application-gateway), Azure Front Door (используйте azure-front-door), диспетчера трафика Azure (используйте azure-traffic-manager), шлюза Azure NAT (используйте azure-nat-gateway).
