معرفة الخبراء بتطوير Azure Load Balancer بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين الواجهات الأمامية/الواجهات الخلفية، أو تحقيقات السلامة، أو SNAT/الصادرة، أو واجهات برمجة تطبيقات IMDS/المقاييس، أو عمليات الترحيل Basic → Standard، ومهام التطوير الأخرى ذات الصلة بـ Azure Load Balancer. ليس لـ Azure Application Gateway (استخدم azure-application-gateway)، وAzure Front Door (استخدم azure-front-door)، وAzure Traffic Manager (استخدم azure-traffic-manager)، وبوابة Azure NAT (استخدم azure-nat-gateway).
