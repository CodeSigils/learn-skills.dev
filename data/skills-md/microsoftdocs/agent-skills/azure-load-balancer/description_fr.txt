Connaissance approfondie du développement d'Azure Load Balancer, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la configuration des interfaces/backends, des sondes d’intégrité, des API SNAT/sortantes, IMDS/métriques ou des migrations de base → Standard et d’autres tâches de développement liées à Azure Load Balancer. Pas pour Azure Application Gateway (utilisez azure-application-gateway), Azure Front Door (utilisez azure-front-door), Azure Traffic Manager (utilisez azure-traffic-manager), Azure NAT Gateway (utilisez azure-nat-gateway).
