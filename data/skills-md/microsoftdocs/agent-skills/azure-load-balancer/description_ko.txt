문제 해결, 모범 사례, 의사 결정, 아키텍처 및 디자인 패턴, 제한 및 할당량, 보안, 구성, 통합 및 코딩 패턴, 배포를 포함한 Azure Load Balancer 개발에 대한 전문 지식입니다. 프런트엔드/백엔드, 상태 프로브, SNAT/아웃바운드, IMDS/메트릭 API 또는 기본→표준 마이그레이션 및 기타 Azure Load Balancer 관련 개발 작업을 구성할 때 사용합니다. Azure Application Gateway(azure-application-gateway 사용), Azure Front Door(azure-front-door 사용), Azure Traffic Manager(azure-traffic-manager 사용), Azure NAT Gateway(azure-nat-gateway 사용)에는 해당되지 않습니다.
