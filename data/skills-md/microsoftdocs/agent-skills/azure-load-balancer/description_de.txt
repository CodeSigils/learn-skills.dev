Expertenwissen für die Azure Load Balancer-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird zum Konfigurieren von Frontends/Backends, Integritätstests, SNAT/Outbound, IMDS/Metrik-APIs oder Basic→Standard-Migrationen und anderen Azure Load Balancer-bezogenen Entwicklungsaufgaben verwendet. Nicht für Azure Application Gateway (verwenden Sie azure-application-gateway), Azure Front Door (verwenden Sie azure-front-door), Azure Traffic Manager (verwenden Sie azure-traffic-manager), Azure NAT Gateway (verwenden Sie azure-nat-gateway).
