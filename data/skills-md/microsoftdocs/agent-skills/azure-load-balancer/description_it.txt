Conoscenza approfondita dello sviluppo di Azure Load Balancer, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la configurazione di frontend/backend, sondaggi di integrità, API SNAT/in uscita, IMDS/metriche o migrazioni Basic→Standard e altre attività di sviluppo correlate al servizio di bilanciamento del carico di Azure. Non per il gateway applicazione di Azure (usare azure-application-gateway), la porta anteriore di Azure (usare azure-front-door), Gestione traffico di Azure (usare azure-traffic-manager), il gateway NAT di Azure (usare azure-nat-gateway).
