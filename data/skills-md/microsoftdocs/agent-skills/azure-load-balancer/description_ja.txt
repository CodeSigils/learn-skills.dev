トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、デプロイメントなど、Azure Load Balancer 開発に関する専門知識。フロントエンド/バックエンド、正常性プローブ、SNAT/アウトバウンド、IMDS/メトリクス API、または基本から標準への移行、およびその他の Azure Load Balancer 関連の開発タスクを構成するときに使用します。 Azure Application Gateway (azure-application-gateway を使用)、Azure Front Door (azure-front-door を使用)、Azure Traffic Manager (azure-traffic-manager を使用)、Azure NAT Gateway (azure-nat-gateway を使用) には使用できません。
