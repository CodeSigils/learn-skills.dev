Connaissance experte du développement Azure Cloud Hsm, y compris le dépannage, les meilleures pratiques, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage. À utiliser lors de la gestion des applications PKCS#11, des certificats/clés basés sur HSM, de la rotation/sauvegarde des clés, des quotas/algorithmes ou des journaux HSM et d'autres tâches de développement liées à Azure Cloud Hsm. Pas pour Azure Dedicated HSM (utilisez azure-dedicated-hsm), Azure Payment Hsm (utilisez azure-payment-hsm), Azure Key Vault (utilisez azure-key-vault), Azure Attestation (utilisez azure-attestation).
