معرفة الخبراء بتطوير Azure Cloud Hsm بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند إدارة تطبيقات PKCS#11، والشهادات/المفاتيح المدعومة بـ HSM، وتدوير/النسخ الاحتياطي للمفاتيح، والحصص النسبية/الخوارزميات، أو سجلات HSM، ومهام التطوير الأخرى ذات الصلة بـ Azure Cloud Hsm. ليس لـ Azure Dedicated HSM (استخدم azure-dedicated-hsm)، وAzure Payment Hsm (استخدم azure- Payment-hsm)، وAzure Key Vault (استخدم azure-key-vault)، وAzure Attestation (استخدم azure-attestation).
