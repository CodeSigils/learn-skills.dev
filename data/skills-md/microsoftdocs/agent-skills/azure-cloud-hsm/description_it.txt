Conoscenza approfondita dello sviluppo di Azure Cloud Hsm, tra cui risoluzione dei problemi, procedure consigliate, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare durante la gestione di app PKCS#11, certificati/chiavi supportati da HSM, rotazione/backup delle chiavi, quote/algoritmi o log HSM e altre attività di sviluppo correlate a Azure Cloud Hsm. Non per HSM dedicato di Azure (usare azure-dedicated-hsm), Hsm di pagamento di Azure (usare azure-payment-hsm), Azure Key Vault (usare azure-key-vault), Attestazione di Azure (usare azure-attestation).
