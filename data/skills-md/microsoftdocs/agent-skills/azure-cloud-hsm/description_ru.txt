Экспертные знания для разработки Azure Cloud Hsm, включая устранение неполадок, рекомендации, ограничения и квоты, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при управлении приложениями PKCS#11, сертификатами/ключами на базе HSM, ротацией/резервным копированием ключей, квотами/алгоритмами или журналами HSM, а также другими задачами разработки, связанными с Azure Cloud Hsm. Не для Azure Dedicated HSM (используйте azure-dedicated-hsm), Azure Payment Hsm (используйте azure-pay-hsm), Azure Key Vault (используйте azure-key-vault), Azure Attestation (используйте azure-attestation).
