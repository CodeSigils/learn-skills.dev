Экспертное руководство по планированию и внедрению облака с помощью Azure Cloud Adoption Framework. Охватывает стратегию, планирование, зоны готовности и высадки, модели внедрения, руководство, безопасность, операции и управление, организацию и команды, а также сценарии внедрения. Используйте при проектировании рабочих нагрузок агента ИИ, платформ AKS/AVS/AVD, SAP/Oracle в Azure, сетки данных/аналитики или целевых зон, а также других задач разработки, связанных с Azure Cloud Adoption Framework.
