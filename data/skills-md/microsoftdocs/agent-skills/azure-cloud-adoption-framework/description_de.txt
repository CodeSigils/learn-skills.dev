Fachkundige Anleitung zur Planung und Durchführung der Cloud-Einführung mithilfe des Azure Cloud Adoption Framework. Behandelt Strategie, Planung, Bereitschafts- und Zielzonen, Einführungsmuster, Governance, Sicherheit, Betrieb und Management, Organisation und Teams sowie Einführungsszenarien. Verwendung beim Entwerfen von KI-Agent-Workloads, AKS/AVS/AVD-Plattformen, SAP/Oracle auf Azure, Data Mesh/Analysen oder Landing Zones und anderen Entwicklungsaufgaben im Zusammenhang mit dem Azure Cloud Adoption Framework.
