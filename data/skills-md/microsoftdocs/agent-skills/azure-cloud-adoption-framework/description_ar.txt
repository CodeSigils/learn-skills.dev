إرشادات الخبراء لتخطيط وتنفيذ اعتماد السحابة باستخدام Azure Cloud Adoption Framework. يغطي الإستراتيجية والتخطيط ومناطق الاستعداد والهبوط وأنماط الاعتماد والحوكمة والأمن والعمليات والإدارة والتنظيم والفرق وسيناريوهات الاعتماد. يُستخدم عند تصميم أعباء عمل وكيل الذكاء الاصطناعي، أو منصات AKS/AVS/AVD، أو SAP/Oracle على Azure، أو شبكة البيانات/التحليلات، أو مناطق الهبوط، ومهام التطوير الأخرى ذات الصلة بـ Azure Cloud Adoption Framework.
