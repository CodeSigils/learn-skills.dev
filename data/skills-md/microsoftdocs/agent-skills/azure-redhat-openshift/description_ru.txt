Экспертные знания для разработки Azure Red Hat OpenShift, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при создании кластеров ARO, настройке сети/хранилища, обеспечении безопасности с помощью Entra/NSG, использовании графических процессоров/Key Vault или обновлении, а также при выполнении других задач разработки, связанных с Azure Red Hat OpenShift. Не для службы Azure Kubernetes (AKS) (используйте azure-kubernetes-service), приложений-контейнеров Azure (используйте azure-container-apps), экземпляров контейнеров Azure (используйте azure-container-instances), решения Azure VMware (используйте azure-vmware-solution).
