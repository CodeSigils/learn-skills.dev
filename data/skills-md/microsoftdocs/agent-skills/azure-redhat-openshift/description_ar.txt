معرفة الخبراء بتطوير Azure Red Hat OpenShift بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إنشاء مجموعات ARO، وتكوين الشبكة/التخزين، والتأمين باستخدام Entra/NSGs، واستخدام وحدات معالجة الرسومات/Key Vault، أو الترقية، ومهام التطوير الأخرى ذات الصلة بـ Azure Red Hat OpenShift. ليس لخدمة Azure Kubernetes (AKS) (استخدم خدمة azure-kubernetes)، وتطبيقات Azure Container (استخدم azure-container-apps)، ومثيلات حاوية Azure (استخدم مثيلات حاوية azure)، وAzure VMware Solution (استخدم حل azure-vmware).
