Conoscenza approfondita dello sviluppo di Azure Red Hat OpenShift, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la creazione di cluster ARO, la configurazione di rete/archiviazione, la protezione con Entra/NSG, l'uso di GPU/Key Vault o l'aggiornamento e altre attività di sviluppo correlate ad Azure Red Hat OpenShift. Non per il servizio Azure Kubernetes (AKS) (usare azure-kubernetes-service), app contenitore di Azure (usare azure-container-apps), istanze di contenitore di Azure (usare azure-container-instances), soluzione VMware di Azure (usare azure-vmware-solution).
