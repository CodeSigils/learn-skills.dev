معرفة الخبراء بتطوير Azure Firewall بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند اختيار وحدات SKU لجدار الحماية، أو تكوين قواعد DNAT/SNAT، أو فحص TLS، أو التوجيه المحوري، أو تسجيل Sentinel، ومهام التطوير الأخرى ذات الصلة بجدار حماية Azure. ليس لـ Azure Firewall Manager (استخدم azure-firewall-manager)، وشبكة Azure الافتراضية (استخدم شبكة azure الافتراضية)، وAzure Virtual WAN (استخدم azure-virtual-wan)، وجدار حماية تطبيق الويب Azure (استخدم جدار حماية تطبيق الويب azure).
