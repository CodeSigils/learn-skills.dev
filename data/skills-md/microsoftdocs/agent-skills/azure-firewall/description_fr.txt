Connaissance approfondie du développement du pare-feu Azure, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors du choix des SKU du pare-feu, de la configuration des règles DNAT/SNAT, de l'inspection TLS, du routage hub-spoke ou de la journalisation Sentinel, ainsi que d'autres tâches de développement liées au pare-feu Azure. Pas pour Azure Firewall Manager (utilisez azure-firewall-manager), Azure Virtual Network (utilisez azure-virtual-network), Azure Virtual WAN (utilisez azure-virtual-wan), Azure Web Application Firewall (utilisez azure-web-application-firewall).
