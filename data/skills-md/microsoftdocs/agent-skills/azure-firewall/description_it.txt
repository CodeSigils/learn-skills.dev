Conoscenza approfondita dello sviluppo di firewall di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si scelgono gli SKU del firewall, si configurano le regole DNAT/SNAT, l'ispezione TLS, il routing hub-spoke o la registrazione Sentinel e altre attività di sviluppo correlate al firewall di Azure. Non per Gestione firewall di Azure (usare azure-firewall-manager), Rete virtuale di Azure (usare azure-virtual-network), WAN virtuale di Azure (usare azure-virtual-wan), Firewall applicazione Web di Azure (usare azure-web-application-firewall).
