Экспертные знания для разработки брандмауэра Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при выборе номеров SKU брандмауэра, настройке правил DNAT/SNAT, проверке TLS, маршрутизации концентратора или ведении журналов Sentinel, а также других задачах разработки, связанных с брандмауэром Azure. Не для диспетчера брандмауэра Azure (используйте azure-firewall-manager), виртуальной сети Azure (используйте azure-virtual-network), виртуальной глобальной сети Azure (используйте azure-virtual-wan), брандмауэра веб-приложения Azure (используйте azure-web-application-firewall).
