Azure 防火墙开发的专业知识，包括故障排除、最佳实践、决策、体系结构和设计模式、限制和配额、安全性、配置、集成和编码模式以及部署。在选择防火墙 SKU、配置 DNAT/SNAT 规则、TLS 检查、中心辐射路由或 Sentinel 日志记录以及其他 Azure 防火墙相关开发任务时使用。不适用于 Azure 防火墙管理器（使用 azure-firewall-manager）、Azure 虚拟网络（使用 azure-virtual-network）、Azure 虚拟 WAN（使用 azure-virtual-wan）、Azure Web 应用程序防火墙（使用 azure-web-application-firewall）。
