Экспертные знания по разработке хранилища контейнеров Azure, включая устранение неполадок, принятие решений, ограничения и квоты, безопасность и настройку. Используйте при настройке томов Elastic SAN с шифрованием CMK, пулов ACS, избыточности LRS/ZRS, изменения размера тома или установки версии 1, а также других задач разработки, связанных с хранилищем контейнеров Azure. Не для хранилища BLOB-объектов Azure (используйте azure-blob-storage), Azure Files (используйте azure-files), Azure Elastic SAN (используйте azure-elastic-san), Azure NetApp Files (используйте azure-netapp-files).
