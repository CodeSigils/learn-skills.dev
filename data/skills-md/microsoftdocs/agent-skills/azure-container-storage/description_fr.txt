Connaissance approfondie du développement d'Azure Container Storage, y compris le dépannage, la prise de décision, les limites et quotas, la sécurité et la configuration. À utiliser lors de la configuration de volumes Elastic SAN chiffrés par CMK, de pools ACS, de redondance LRS/ZRS, de redimensionnement de volume ou d'installations v1, ainsi que d'autres tâches de développement liées à Azure Container Storage. Pas pour Azure Blob Storage (utilisez azure-blob-storage), Azure Files (utilisez azure-files), Azure Elastic SAN (utilisez azure-elastic-san), Azure NetApp Files (utilisez azure-netapp-files).
