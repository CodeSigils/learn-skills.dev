Conoscenza approfondita dello sviluppo di Archiviazione contenitori di Azure, tra cui risoluzione dei problemi, processo decisionale, limiti e quote, sicurezza e configurazione. Da utilizzare durante la configurazione di volumi SAN elastici crittografati con CMK, pool ACS, ridondanza LRS/ZRS, ridimensionamento dei volumi o installazioni v1 e altre attività di sviluppo correlate ad Archiviazione contenitori di Azure. Non per archiviazione BLOB di Azure (usare azure-blob-storage), File di Azure (usare azure-files), Azure Elastic SAN (usare azure-elastic-san), Azure NetApp Files (usare azure-netapp-files).
