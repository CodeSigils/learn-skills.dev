معرفة الخبراء بتطوير Azure Container Storage بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار والحدود والحصص والأمان والتكوين. يُستخدم عند تكوين وحدات تخزين SAN المرنة المشفرة بواسطة CMK، أو مجموعات ACS، أو تكرار LRS/ZRS، أو تغيير حجم وحدة التخزين، أو عمليات تثبيت الإصدار 1، ومهام التطوير الأخرى ذات الصلة بتخزين حاوية Azure. ليس مخصصًا لتخزين Azure Blob (استخدم azure-blob-storage)، وملفات Azure (استخدم ملفات azure)، وAzure Elastic SAN (استخدم azure-elastic-san)، وملفات Azure NetApp (استخدم ملفات azure-netapp).
