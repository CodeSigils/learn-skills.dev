Expertenwissen für die Entwicklung von Azure Container Storage, einschließlich Fehlerbehebung, Entscheidungsfindung, Grenzwerte und Kontingente, Sicherheit und Konfiguration. Verwenden Sie diese Option, wenn Sie CMK-verschlüsselte Elastic SAN-Volumes, ACS-Pools, LRS/ZRS-Redundanz, Volume-Größenänderungen oder v1-Installationen sowie andere Entwicklungsaufgaben im Zusammenhang mit Azure Container Storage konfigurieren. Nicht für Azure Blob Storage (verwenden Sie azure-blob-storage), Azure Files (verwenden Sie azure-files), Azure Elastic SAN (verwenden Sie azure-elastic-san), Azure NetApp Files (verwenden Sie azure-netapp-files).
