Connaissance approfondie du développement d'Azure Resource Graph, y compris le dépannage, les meilleures pratiques, la prise de décision, les limites et quotas, la configuration, ainsi que les modèles d'intégration et de codage. À utiliser lors d'interrogations via CLI/PowerShell/REST, à l'aide des API GET/LIST vs Query, des requêtes partagées, des alertes ou Power BI et d'autres tâches de développement liées à Azure Resource Graph. Pas pour Azure Monitor (utilisez azure-monitor), Azure Policy (utilisez azure-policy), Azure Resource Manager (utilisez azure-resource-manager), Azure Portal (utilisez azure-portal).
