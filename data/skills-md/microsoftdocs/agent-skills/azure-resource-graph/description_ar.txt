معرفة الخبراء بتطوير Azure Resource Graph بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والتكوين والتكامل وأنماط الترميز. يُستخدم عند الاستعلام عبر CLI/PowerShell/REST، باستخدام GET/LIST مقابل واجهات برمجة تطبيقات الاستعلام، أو الاستعلامات المشتركة، أو التنبيهات، أو Power BI، ومهام التطوير الأخرى ذات الصلة بـ Azure Resource Graph. ليس لـ Azure Monitor (استخدم azure-monitor)، وAzure Policy (استخدم azure-policy)، وAzure Resource Manager (استخدم azure-resource-manager)، وAzure Portal (استخدم azure-portal).
