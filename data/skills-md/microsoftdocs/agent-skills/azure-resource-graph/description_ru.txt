Экспертные знания для разработки Azure Resource Graph, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, настройку, а также интеграцию и шаблоны кодирования. Используйте при запросах через CLI/PowerShell/REST, с использованием GET/LIST и API запросов, общих запросов, оповещений или Power BI, а также других задач разработки, связанных с Azure Resource Graph. Не для Azure Monitor (используйте azure-monitor), Политики Azure (используйте azure-policy), Azure Resource Manager (используйте azure-resource-manager), Azure Portal (используйте azure-portal).
