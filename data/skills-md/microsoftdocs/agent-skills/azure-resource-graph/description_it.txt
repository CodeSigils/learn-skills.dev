Conoscenza approfondita dello sviluppo di Azure Resource Graph, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, limiti e quote, configurazione, integrazioni e modelli di codifica. Da usare durante l'esecuzione di query tramite CLI/PowerShell/REST, usando GET/LIST e API di query, query condivise, avvisi o Power BI e altre attività di sviluppo correlate a Azure Resource Graph. Non per Monitoraggio di Azure (usare azure-monitor), Criteri di Azure (usare azure-policy), Azure Resource Manager (usare azure-resource-manager), Portale di Azure (usare azure-portal).
