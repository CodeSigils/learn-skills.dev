معرفة الخبراء بتطوير Azure Boards بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند إدارة عناصر العمل، أو اللوحات/السجلات المتراكمة، أو استعلامات WIQL، أو مزامنة Excel/Office، أو عمليات تكامل GitHub/Teams، ومهام التطوير الأخرى ذات الصلة بـ Azure Boards. ليس لـ Azure DevOps (استخدم azure-devops)، وخطط اختبار Azure (استخدم خطط اختبار azure)، وخطوط أنابيب Azure (استخدم خطوط أنابيب azure)، وAzure Repos (استخدم azure-repos).
