Expertenwissen für die Azure Boards-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Grenzwerte und Kontingente, Sicherheit, Konfiguration sowie Integrationen und Codierungsmuster. Wird zum Verwalten von Arbeitselementen, Boards/Backlogs, WIQL-Abfragen, Excel/Office-Synchronisierung oder GitHub/Teams-Integrationen und anderen Azure Boards-bezogenen Entwicklungsaufgaben verwendet. Nicht für Azure DevOps (verwenden Sie azure-devops), Azure Test Plans (verwenden Sie azure-test-plans), Azure Pipelines (verwenden Sie azure-pipelines), Azure Repos (verwenden Sie azure-repos).
