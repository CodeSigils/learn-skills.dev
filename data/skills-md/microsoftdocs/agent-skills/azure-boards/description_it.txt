Conoscenza approfondita dello sviluppo di Azure Board, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare durante la gestione di elementi di lavoro, bacheche/backlog, query WIQL, sincronizzazione di Excel/Office o integrazioni GitHub/Teams e altre attività di sviluppo correlate alle bacheche di Azure. Non per Azure DevOps (usare azure-devops), Azure Test Plans (usare azure-test-plans), Azure Pipelines (usare azure-pipelines), Azure Repos (usare azure-repos).
