Экспертные знания для разработки Azure Boards, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при управлении рабочими элементами, досками/невыполненными задачами, запросами WIQL, синхронизацией Excel/Office или интеграцией GitHub/Teams и другими задачами разработки, связанными с Azure Boards. Не для Azure DevOps (используйте azure-devops), планов тестирования Azure (используйте azure-test-plans), Azure Pipelines (используйте azure-pipelines), Azure Repos (используйте azure-repos).
