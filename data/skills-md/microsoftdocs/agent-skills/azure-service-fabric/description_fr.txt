Connaissance experte du développement Azure Service Fabric, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la création de clusters Service Fabric, de services/acteurs fiables, de stratégies Cluster Resource Manager, de proxy inverse ou d'automatisation sfctl/PowerShell, ainsi que d'autres tâches de développement liées à Azure Service Fabric. Pas pour Azure App Service (utilisez azure-app-service), Azure Kubernetes Service (AKS) (utilisez azure-kubernetes-service), Azure Container Apps (utilisez azure-container-apps), Azure Cloud Services (utilisez azure-cloud-services).
