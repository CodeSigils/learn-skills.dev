Экспертные знания для разработки Azure Service Fabric, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при создании кластеров Service Fabric, Reliable Services/Actors, политик диспетчера ресурсов кластера, обратного прокси-сервера или автоматизации sfctl/PowerShell, а также других задач разработки, связанных с Azure Service Fabric. Not for Azure App Service (use azure-app-service), Azure Kubernetes Service (AKS) (use azure-kubernetes-service), Azure Container Apps (use azure-container-apps), Azure Cloud Services (use azure-cloud-services).
