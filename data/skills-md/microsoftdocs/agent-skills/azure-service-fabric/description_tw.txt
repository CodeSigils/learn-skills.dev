Azure Service Fabric 開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在建置 Service Fabric 叢集、可靠服務/參與者、叢集資源管理器策略、反向代理程式或 sfctl/PowerShell 自動化以及其他 Azure Service Fabric 相關開發任務時使用。不適用於 Azure 應用程式服務（使用 azure-app-service）、Azure Kubernetes 服務 (AKS)（使用 azure-kubernetes-service）、Azure 容器應用程式（使用 azure-container-apps）、Azure 雲端服務（使用 azure-cloud-services）。
