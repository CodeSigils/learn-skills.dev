معرفة الخبراء بتطوير Azure Service Fabric بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إنشاء مجموعات نسيج الخدمة، أو الخدمات/الممثلين الموثوقين، أو سياسات إدارة موارد المجموعة، أو الوكيل العكسي، أو أتمتة sfctl/PowerShell، ومهام التطوير الأخرى ذات الصلة بـ Azure Service Fabric. ليس لخدمة Azure App (استخدم خدمة تطبيق azure)، وخدمة Azure Kubernetes (AKS) (استخدم خدمة azure-kubernetes)، وتطبيقات Azure Container (استخدم تطبيقات حاوية azure)، وخدمات Azure Cloud (استخدم خدمات السحابة azure).
