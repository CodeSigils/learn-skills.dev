Conoscenza approfondita dello sviluppo di Azure Service Fabric, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la creazione di cluster di Service Fabric, Reliable Services/Attori, criteri di Cluster Resource Manager, proxy inverso o automazione sfctl/PowerShell e altre attività di sviluppo correlate a Azure Service Fabric. Non per Servizio app di Azure (usare azure-app-service), Servizio Azure Kubernetes (AKS) (usare azure-kubernetes-service), App contenitore di Azure (usare azure-container-apps), Servizi cloud di Azure (usare azure-cloud-services).
