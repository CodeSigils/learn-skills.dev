Azure Service Fabric 开发的专业知识，包括故障排除、最佳实践、决策、体系结构和设计模式、限制和配额、安全性、配置、集成和编码模式以及部署。在构建 Service Fabric 群集、可靠服务/参与者、群集资源管理器策略、反向代理或 sfctl/PowerShell 自动化以及其他 Azure Service Fabric 相关开发任务时使用。不适用于 Azure 应用服务（使用 azure-app-service）、Azure Kubernetes 服务 (AKS)（使用 azure-kubernetes-service）、Azure 容器应用（使用 azure-container-apps）、Azure 云服务（使用 azure-cloud-services）。
