Экспертные знания для разработки Azure Operation Nexus, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при управлении фабриками Nexus, доменами изоляции, политиками BGP/ACL/QoS, правилами TAP NPB или проектами ближайшего хранилища, а также другими задачами разработки, связанными с оператором Azure Nexus. Не для диспетчера сетевых функций Azure (используйте azure-network-function-manager), сети Azure (используйте azure-networking), диспетчера виртуальных сетей Azure (используйте azure-virtual-network-manager), виртуальной глобальной сети Azure (используйте azure-virtual-wan).
