معرفة الخبراء لتطوير Azure Operator Nexus بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إدارة بنى Nexus، أو مجالات العزل، أو سياسات BGP/ACL/QoS، أو قواعد NPB TAP، أو تصميمات التخزين القريبة، ومهام التطوير الأخرى ذات الصلة بـ Azure Operator Nexus. ليس لـ Azure Network Function Manager (استخدم azure-network-function-manager)، وAzure Networking (استخدم azure-networking)، وAzure Virtual Network Manager (استخدم azure-virtual-network-manager)، وAzure Virtual WAN (استخدم azure-virtual-wan).
