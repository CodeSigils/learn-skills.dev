Connaissance approfondie du développement d'Azure Operator Nexus, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la gestion des structures Nexus, des domaines d'isolation, des stratégies BGP/ACL/QoS, des règles NPB TAP ou des conceptions de stockage Near Edge, ainsi que d'autres tâches de développement liées à Azure Operator Nexus. Pas pour Azure Network Function Manager (utilisez azure-network-function-manager), Azure Networking (utilisez azure-networking), Azure Virtual Network Manager (utilisez azure-virtual-network-manager), Azure Virtual WAN (utilisez azure-virtual-wan).
