Conoscenza approfondita dello sviluppo di Azure Osconfig, inclusa risoluzione dei problemi, sicurezza, configurazione, integrazioni e modelli di codifica. Da usare quando si esegue OSConfig tramite l'hub IoT per comandi, comportamento SSH, integrità dell'agente, linee di base di Windows o LAPS e altre attività di sviluppo correlate a Azure Osconfig. Non per Azure Update Manager (usa azure-update-manager), Automazione di Azure (usa azure-automation), Criteri di Azure (usa azure-policy).
