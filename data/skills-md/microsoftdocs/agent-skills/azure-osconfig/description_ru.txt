Экспертные знания по разработке Azure Osconfig, включая устранение неполадок, безопасность, настройку, интеграцию и шаблоны кодирования. Используйте при запуске OSConfig через Центр Интернета вещей для команд, состояния SSH, работоспособности агента, базовых показателей Windows или LAPS, а также других задач разработки, связанных с Azure Osconfig. Не для диспетчера обновлений Azure (используйте azure-update-manager), автоматизации Azure (используйте azure-automation), политики Azure (используйте azure-policy).
