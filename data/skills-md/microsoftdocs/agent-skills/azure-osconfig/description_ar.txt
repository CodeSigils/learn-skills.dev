معرفة الخبراء بتطوير Azure Osconfig بما في ذلك استكشاف الأخطاء وإصلاحها والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند تشغيل OSConfig عبر IoT Hub للأوامر أو وضع SSH أو صحة الوكيل أو الخطوط الأساسية لـ Windows أو LAPS ومهام التطوير الأخرى ذات الصلة بـ Azure Osconfig. ليس لـ Azure Update Manager (استخدم azure-update-manager)، وAzure Automation (استخدم أتمتة azure)، وسياسة Azure (استخدم سياسة azure).
