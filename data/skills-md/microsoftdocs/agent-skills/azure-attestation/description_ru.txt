Экспертные знания по разработке аттестации Azure, включая устранение неполадок, рекомендации, безопасность, настройку и развертывание. Используйте при проверке токенов аттестации, разработке политик, обеспечении соблюдения базовых показателей SGX/TPM или настройке частных конечных точек, а также других задачах разработки, связанных с аттестацией Azure. Не для конфиденциальных вычислений Azure (используйте azure-confidential-computing), виртуальных анклавов Azure (используйте azure-virtual-enclaves), выделенного HSM Azure (используйте azure-dedicated-hsm), Azure Key Vault (используйте azure-key-vault).
