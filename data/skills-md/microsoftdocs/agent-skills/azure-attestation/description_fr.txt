Connaissance experte du développement d’Azure Attestation, y compris le dépannage, les meilleures pratiques, la sécurité, la configuration et le déploiement. À utiliser lors de la validation des jetons d'attestation, de la création de stratégies, de l'application des lignes de base SGX/TPM ou de la configuration de points de terminaison privés, ainsi que d'autres tâches de développement liées à Azure Attestation. Pas pour Azure Confidential Computing (utilisez azure-confidential-computing), Azure Virtual Enclaves (utilisez azure-virtual-enclaves), Azure Dedicated HSM (utilisez azure-dedicated-hsm), Azure Key Vault (utilisez azure-key-vault).
