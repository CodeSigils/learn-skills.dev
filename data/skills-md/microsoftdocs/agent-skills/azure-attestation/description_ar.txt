معرفة الخبراء بتطوير Azure Attestation بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات والأمان والتكوين والنشر. يُستخدم عند التحقق من صحة الرموز المميزة للتصديق، أو تأليف السياسات، أو فرض خطوط أساس SGX/TPM، أو تكوين نقاط النهاية الخاصة، ومهام التطوير الأخرى ذات الصلة بـ Azure Attestation. ليس مخصصًا للحوسبة السرية في Azure (استخدم الحوسبة السرية azure)، وAzure Virtual Enclaves (استخدم الجيوب الافتراضية azure)، وAzure Dedicated HSM (استخدم azure-dedicated-hsm)، وAzure Key Vault (استخدم azure-key-vault).
