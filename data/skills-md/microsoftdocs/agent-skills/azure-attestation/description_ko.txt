문제 해결, 모범 사례, 보안, 구성 및 배포를 포함한 Azure Attestation 개발에 대한 전문 지식입니다. 증명 토큰의 유효성을 검사하고, 정책을 작성하고, SGX/TPM 기준을 적용하거나, 프라이빗 엔드포인트를 구성하고, 기타 Azure Attestation 관련 개발 작업을 수행할 때 사용합니다. Azure 기밀 컴퓨팅(azure-confidential-computing 사용), Azure Virtual Enclaves(azure-virtual-enclaves 사용), Azure Dedicated HSM(azure-dedicated-hsm 사용), Azure Key Vault(azure-key-vault 사용)에는 적합하지 않습니다.
