Expertenwissen für die Azure Attestation-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Sicherheit, Konfiguration und Bereitstellung. Wird zum Überprüfen von Nachweistokens, zum Erstellen von Richtlinien, zum Erzwingen von SGX/TPM-Baselines oder zum Konfigurieren privater Endpunkte sowie für andere Entwicklungsaufgaben im Zusammenhang mit Azure Attestation verwendet. Nicht für Azure Confidential Computing (verwenden Sie azure-confidential-computing), Azure Virtual Enclaves (verwenden Sie azure-virtual-enclaves), Azure Dedicated HSM (verwenden Sie azure-dedicated-hsm), Azure Key Vault (verwenden Sie azure-key-vault).
