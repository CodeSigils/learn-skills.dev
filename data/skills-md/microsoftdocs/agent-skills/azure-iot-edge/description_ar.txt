معرفة الخبراء بتطوير Azure IoT Edge بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين وحدات/أجهزة IoT Edge، أو توفير DPS، أو EFLOW على Windows، أو البوابات، أو أحمال العمل المسرَّعة بواسطة GPU، ومهام التطوير الأخرى ذات الصلة بـ Azure IoT Edge. ليس لـ Azure IoT Hub (استخدم azure-iot-hub)، وAzure IoT Central (استخدم azure-iot-central)، وAzure IoT Operations (استخدم عمليات azure-iot)، وAzure Stack Edge (استخدم azure-stack-edge).
