Экспертные знания для разработки Azure IoT Edge, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке модулей/устройств IoT Edge, подготовке DPS, EFLOW в Windows, шлюзах или рабочих нагрузках с ускорением на графическом процессоре, а также других задачах разработки, связанных с Azure IoT Edge. Не для Azure IoT Hub (используйте azure-iot-hub), Azure IoT Central (используйте azure-iot-central), Azure IoT Operations (используйте azure-iot-operations), Azure Stack Edge (используйте azure-stack-edge).
