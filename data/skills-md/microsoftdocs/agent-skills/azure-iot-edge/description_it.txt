Conoscenza approfondita dello sviluppo di Azure IoT Edge, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la configurazione di moduli/dispositivi IoT Edge, provisioning DPS, EFLOW su Windows, gateway o carichi di lavoro accelerati da GPU e altre attività di sviluppo correlate ad Azure IoT Edge. Non per l'hub IoT di Azure (usare azure-iot-hub), Azure IoT Central (usare azure-iot-central), Operazioni IoT di Azure (usare azure-iot-operazioni), Azure Stack Edge (usare azure-stack-edge).
