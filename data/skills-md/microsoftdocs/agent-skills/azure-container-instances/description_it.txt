Conoscenza approfondita dello sviluppo di istanze di contenitore di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione e distribuzione. Da utilizzare durante la configurazione di reti ACI, pool di standby, distribuzioni di azioni GitHub, contenitori Spot o carichi di lavoro GPU e altre attività di sviluppo correlate alle istanze di contenitore di Azure. Non per app contenitore di Azure (usare azure-container-apps), servizio Azure Kubernetes (AKS) (usare azure-kubernetes-service), servizio app di Azure (usare azure-app-service), macchine virtuali di Azure (usare azure-virtual-machines).
