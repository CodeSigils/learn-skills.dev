トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、デプロイなど、Azure Container Instances 開発に関する専門知識。 ACI ネットワーク、スタンバイ プール、GitHub Actions デプロイ、スポット コンテナー、または GPU ワークロード、およびその他の Azure Container Instances 関連の開発タスクを構成するときに使用します。 Azure Container Apps (azure-container-apps を使用)、Azure Kubernetes Service (AKS) (azure-kubernetes-service を使用)、Azure App Service (azure-app-service を使用)、Azure Virtual Machines (azure-virtual-machines を使用) には適用されません。
