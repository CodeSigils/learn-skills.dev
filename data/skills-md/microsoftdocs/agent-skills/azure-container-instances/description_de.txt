Expertenwissen für die Entwicklung von Azure Container Instances, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration und Bereitstellung. Wird zum Konfigurieren von ACI-Netzwerken, Standby-Pools, GitHub Actions-Bereitstellungen, Spot-Containern oder GPU-Workloads und anderen Entwicklungsaufgaben im Zusammenhang mit Azure Container Instances verwendet. Nicht für Azure Container Apps (verwenden Sie azure-container-apps), Azure Kubernetes Service (AKS) (verwenden Sie azure-kubernetes-service), Azure App Service (verwenden Sie azure-app-service), Azure Virtual Machines (verwenden Sie azure-virtual-machines).
