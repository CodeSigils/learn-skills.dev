Azure 容器執行個體開發的專業知識，包括故障排除、最佳實務、決策、架構和設計模式、限制和配額、安全性、設定和部署。在設定 ACI 網路、備用池、GitHub Actions 部署、Spot 容器或 GPU 工作負載以及其他 Azure 容器執行個體相關開發任務時使用。不適用於 Azure 容器應用程式（使用 azure-container-apps）、Azure Kubernetes 服務 (AKS)（使用 azure-kubernetes-service）、Azure 應用程式服務（使用 azure-app-service）、Azure 虛擬機器（使用 azure-virtual-machines）。
