Экспертные знания для разработки экземпляров контейнеров Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку и развертывание. Используйте при настройке сети ACI, резервных пулов, развертываний действий GitHub, спотовых контейнеров или рабочих нагрузок графического процессора, а также других задач разработки, связанных с экземплярами контейнеров Azure. Не для приложений-контейнеров Azure (используйте azure-container-apps), Службы Azure Kubernetes (AKS) (используйте azure-kubernetes-service), Службы приложений Azure (используйте azure-app-service), Виртуальных машин Azure (используйте azure-virtual-machines).
