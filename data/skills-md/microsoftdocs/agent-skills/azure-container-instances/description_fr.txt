Connaissance approfondie du développement d'Azure Container Instances, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration et le déploiement. À utiliser lors de la configuration du réseau ACI, des pools de secours, des déploiements d'actions GitHub, des conteneurs Spot ou des charges de travail GPU, ainsi que d'autres tâches de développement liées à Azure Container Instances. Pas pour Azure Container Apps (utilisez azure-container-apps), Azure Kubernetes Service (AKS) (utilisez azure-kubernetes-service), Azure App Service (utilisez azure-app-service), Azure Virtual Machines (utilisez azure-virtual-machines).
