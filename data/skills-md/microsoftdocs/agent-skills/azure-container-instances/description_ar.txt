معرفة الخبراء بتطوير مثيلات حاوية Azure بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والنشر. يُستخدم عند تكوين شبكة ACI، أو التجمعات الاحتياطية، أو عمليات نشر GitHub Actions، أو حاويات Spot، أو أحمال عمل GPU، ومهام التطوير الأخرى ذات الصلة بمثيلات Azure Container. ليس مخصصًا لتطبيقات Azure Container (استخدم azure-container-apps)، وخدمة Azure Kubernetes (AKS) (استخدم خدمة azure-kubernetes)، وخدمة Azure App (استخدم خدمة تطبيق azure)، وأجهزة Azure الافتراضية (استخدم أجهزة azure الافتراضية).
