Azure Site Recovery 開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在規劃 VMware/Hyper-V 的 ASR、設定復原服務保管庫、使用 PowerShell/Terraform 編寫腳本、整合 ExpressRoute/Traffic Manager 或保護 AD/SQL/SAP 工作負載以及其他與 Azure Site Recovery 相關的開發任務時使用。不適用於 Azure 備份（使用 azure-backup）、Azure Migrate（使用 azure-migrate）、Azure 虛擬機器（使用 azure-virtual-machines）、Azure 虛擬機器規模集（使用 azure-vm-scalesets）。
