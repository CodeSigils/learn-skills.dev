Connaissance approfondie du développement d'Azure Site Recovery, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la planification d'ASR pour VMware/Hyper‑V, de la configuration des coffres Recovery Services, de la création de scripts avec PowerShell/Terraform, de l'intégration d'ExpressRoute/Traffic Manager ou de la protection des charges de travail AD/SQL/SAP et d'autres tâches de développement liées à Azure Site Recovery. Pas pour Azure Backup (utilisez azure-backup), Azure Migrate (utilisez azure-migrate), les machines virtuelles Azure (utilisez azure-virtual-machines), les groupes de machines virtuelles identiques Azure (utilisez azure-vm-scalesets).
