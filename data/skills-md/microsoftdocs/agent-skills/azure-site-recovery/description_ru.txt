Экспертные знания для разработки Azure Site Recovery, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при планировании ASR для VMware/Hyper-V, настройке хранилищ служб восстановления, написании сценариев с помощью PowerShell/Terraform, интеграции ExpressRoute/Traffic Manager или защите рабочих нагрузок AD/SQL/SAP, а также при выполнении других задач разработки, связанных с Azure Site Recovery. Не для Azure Backup (используйте azure-backup), Azure Migrate (используйте azure-migrate), виртуальных машин Azure (используйте azure-virtual-machines), масштабируемых наборов виртуальных машин Azure (используйте azure-vm-scalesets).
