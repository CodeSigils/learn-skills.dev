Expertenwissen für die Azure Site Recovery-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Verwenden Sie es bei der Planung von ASR für VMware/Hyper-V, der Konfiguration von Recovery Services-Tresoren, der Skripterstellung mit PowerShell/Terraform, der Integration von ExpressRoute/Traffic Manager oder dem Schutz von AD/SQL/SAP-Workloads und anderen Entwicklungsaufgaben im Zusammenhang mit Azure Site Recovery. Nicht für Azure Backup (verwenden Sie azure-backup), Azure Migrate (verwenden Sie azure-migrate), Azure Virtual Machines (verwenden Sie azure-virtual-machines), Azure Virtual Machine Scale Sets (verwenden Sie azure-vm-scalesets).
