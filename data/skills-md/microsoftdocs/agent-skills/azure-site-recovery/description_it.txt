Conoscenza approfondita dello sviluppo di Azure Site Recovery, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la pianificazione di ASR per VMware/Hyper‑V, la configurazione di archivi di servizi di ripristino, lo scripting con PowerShell/Terraform, l'integrazione di ExpressRoute/Traffic Manager o la protezione di carichi di lavoro AD/SQL/SAP e altre attività di sviluppo correlate ad Azure Site Recovery. Non per Backup di Azure (usare azure-backup), Azure Migrate (usare azure-migrate), Macchine virtuali di Azure (usare azure-virtual-machines), Set di scalabilità di macchine virtuali di Azure (usare azure-vm-scalesets).
