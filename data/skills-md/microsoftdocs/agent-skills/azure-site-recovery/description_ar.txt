معرفة الخبراء بتطوير Azure Site Recovery بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تخطيط ASR لـ VMware/Hyper‑V، أو تكوين خزائن خدمات الاسترداد، أو البرمجة النصية باستخدام PowerShell/Terraform، أو دمج ExpressRoute/Traffic Manager، أو حماية أحمال عمل AD/SQL/SAP، ومهام التطوير الأخرى ذات الصلة بـ Azure Site Recovery. ليس لـ Azure Backup (استخدم النسخ الاحتياطي azure)، وAzure Migrate (استخدم azure-migrate)، وأجهزة Azure الافتراضية (استخدم الأجهزة الافتراضية azure)، ومجموعات مقياس Azure Virtual Machine (استخدم مجموعات مقياس azure-vm).
