معرفة الخبراء بتطوير خدمة تطبيقات Azure بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين خطط خدمة التطبيقات/ASE، أو تكامل VNet، أو الهوية المُدارة/Key Vault، أو فتحات النشر، أو TLS/الشهادات، ومهام التطوير الأخرى ذات الصلة بخدمة Azure App Service. ليس لوظائف Azure (استخدم وظائف azure)، وتطبيقات Azure Spring (استخدم azure-spring-apps)، وتطبيقات Azure Container (استخدم تطبيقات azure-container)، وتطبيقات الويب Azure Static (استخدم تطبيقات الويب الثابتة azure).
