Экспертные знания для разработки Службы приложений Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке планов службы приложений/ASE, интеграции виртуальной сети, управляемого удостоверения/хранилища ключей, слотов развертывания или TLS/сертификатов, а также других задач разработки, связанных со службой приложений Azure. Не для функций Azure (используйте функции azure), приложений Azure Spring (используйте azure-spring-apps), контейнерных приложений Azure (используйте azure-container-apps), статических веб-приложений Azure (используйте azure-static-web-apps).
