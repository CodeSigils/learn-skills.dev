Azure 應用服務開發的專業知識，包括故障排除、最佳實務、決策、架構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在配置應用服務計劃/ASE、VNet 整合、託管識別/Key Vault、部署插槽或 TLS/憑證以及其他 Azure 應用服務相關開發任務時使用。不適用於 Azure Functions（使用 azure-functions）、Azure Spring 應用程式（使用 azure-spring-apps）、Azure 容器應用程式（使用 azure-container-apps）、Azure 靜態 Web 應用程式（使用 azure-static-web-apps）。
