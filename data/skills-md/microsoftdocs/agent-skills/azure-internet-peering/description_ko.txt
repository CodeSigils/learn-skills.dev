Azure ExpressRoute(azure-expressroute 사용), Azure Virtual Network(azure-virtual-network 사용), Azure Virtual WAN(azure-virtual-wan 사용), Azure VPN Gateway(azure-vpn-gateway 사용)에는 해당되지 않습니다.
