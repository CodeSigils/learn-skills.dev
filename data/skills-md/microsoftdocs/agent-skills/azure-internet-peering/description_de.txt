Expertenwissen für die Azure Internet Peering-Entwicklung einschließlich Fehlerbehebung. Wird zum Überprüfen von Peering-Dienstpräfixen, zum Überprüfen der Präfixregistrierung, zum Überprüfen des Routings oder zum Beheben von Erreichbarkeitsproblemen sowie für andere Entwicklungsaufgaben im Zusammenhang mit Azure Internet Peering verwendet. Nicht für Azure ExpressRoute (verwenden Sie azure-expressroute), Azure Virtual Network (verwenden Sie azure-virtual-network), Azure Virtual WAN (verwenden Sie azure-virtual-wan), Azure VPN Gateway (verwenden Sie azure-vpn-gateway).
