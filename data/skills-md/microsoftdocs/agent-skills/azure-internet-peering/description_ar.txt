معرفة الخبراء بتطوير Azure Internet Peering بما في ذلك استكشاف الأخطاء وإصلاحها. يُستخدم عند التحقق من صحة بادئات خدمة Peering، أو التحقق من تسجيل البادئة، أو التحقق من التوجيه، أو إصلاح مشكلات إمكانية الوصول، ومهام التطوير الأخرى ذات الصلة بـ Azure Internet Peering. ليس لـ Azure ExpressRoute (استخدم azure-expressroute)، وشبكة Azure الافتراضية (استخدم شبكة azure الافتراضية)، وAzure Virtual WAN (استخدم azure-virtual-wan)، وبوابة Azure VPN (استخدم بوابة azure-vpn).
