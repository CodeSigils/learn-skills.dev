トラブルシューティングを含む、Azure インターネット ピアリング開発に関する専門知識。ピアリング サービス プレフィックスの検証、プレフィックス登録の確認、ルーティングの検証、到達可能性の問題の修正、およびその他の Azure インターネット ピアリング関連の開発タスクを行うときに使用します。 Azure ExpressRoute (azure-expressroute を使用)、Azure Virtual Network (azure-virtual-network を使用)、Azure Virtual WAN (azure-virtual-wan を使用)、Azure VPN Gateway (azure-vpn-gateway を使用) には使用できません。
