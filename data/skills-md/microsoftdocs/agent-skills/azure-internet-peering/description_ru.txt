Экспертные знания по разработке интернет-пиринга Azure, включая устранение неполадок. Используйте при проверке префиксов службы пиринга, проверке регистрации префиксов, проверке маршрутизации или устранении проблем с доступностью, а также при выполнении других задач разработки, связанных с Интернет-пирингом Azure. Не для Azure ExpressRoute (используйте azure-expressroute), виртуальной сети Azure (используйте azure-virtual-network), виртуальной глобальной сети Azure (используйте azure-virtual-wan), VPN-шлюза Azure (используйте azure-vpn-gateway).
