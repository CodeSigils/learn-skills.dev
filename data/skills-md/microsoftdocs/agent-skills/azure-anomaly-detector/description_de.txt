Expertenwissen für die Entwicklung von Azure AI Anomaly Detector, einschließlich Fehlerbehebung, Best Practices, Architektur- und Entwurfsmuster, Grenzwerte und Kontingente, Konfiguration und Bereitstellung. Verwenden Sie diese Option, wenn Sie univariate/multivariate APIs, Docker/IoT-Edge-Container, vorausschauende Wartungsabläufe oder regionale Grenzwerte und andere Entwicklungsaufgaben im Zusammenhang mit dem Azure AI Anomaly Detector verwenden. Nicht für Azure AI Metrics Advisor (verwenden Sie azure-metrics-advisor), Azure Monitor (verwenden Sie azure-monitor), Azure Machine Learning (verwenden Sie azure-machine-learning).
