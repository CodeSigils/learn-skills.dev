Conoscenza approfondita dello sviluppo di Azure AI Anomaly Detector, tra cui risoluzione dei problemi, procedure consigliate, modelli di architettura e progettazione, limiti e quote, configurazione e distribuzione. Da usare quando si usano API univariate/multivariate, contenitori Docker/IoT Edge, flussi di manutenzione predittiva o limiti regionali e altre attività di sviluppo correlate a Azure AI Anomaly Detector. Non per Azure AI Metrics Advisor (usare azure-metrics-advisor), Monitoraggio di Azure (usare azure-monitor), Azure Machine Learning (usare azure-machine-learning).
