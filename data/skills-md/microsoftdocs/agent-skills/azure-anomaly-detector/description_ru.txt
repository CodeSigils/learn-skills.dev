Экспертные знания для разработки детектора аномалий Azure AI, включая устранение неполадок, рекомендации, шаблоны архитектуры и проектирования, ограничения и квоты, настройку и развертывание. Используйте при использовании одномерных и многомерных API, контейнеров Docker/IoT Edge, потоков прогнозного обслуживания или региональных ограничений, а также других задач разработки, связанных с Azure AI Anomaly Detector. Не для Azure AI Metrics Advisor (используйте azure-metrics-advisor), Azure Monitor (используйте azure-monitor), Azure Machine Learning (используйте azure-machine-learning).
