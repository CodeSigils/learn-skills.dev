معرفة الخبراء بتطوير Azure AI Anomaly Detector بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات وأنماط الهندسة والتصميم والحدود والحصص والتكوين والنشر. يُستخدم عند استخدام واجهات برمجة التطبيقات أحادية المتغير/متعددة المتغيرات، أو حاويات Docker/IoT Edge، أو تدفقات الصيانة التنبؤية، أو الحدود الإقليمية، ومهام التطوير الأخرى ذات الصلة بـ Azure AI Anomaly Detector. ليس لـ Azure AI Metrics Advisor (استخدم azure-metrics-advisor)، وAzure Monitor (استخدم azure-monitor)، وAzure Machine Learning (استخدم التعلم الآلي من azure).
