Экспертные знания для разработки Центров событий Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании клиентов/Streams Kafka, .NET SDK, Flink/Spark, гео-аварийного восстановления или блоков обработки Premium, а также других задач разработки, связанных с Центрами событий Azure. Не для служебной шины Azure (используйте azure-service-bus), Azure Event Grid (используйте azure-event-grid), Центров уведомлений Azure (используйте azure-notification-hubs), Azure Stream Analytics (используйте azure-stream-analytics).
