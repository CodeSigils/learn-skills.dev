Conoscenza approfondita dello sviluppo di Azure Quantum, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usano QDK/qdk.azure, processi ibridi, circuiti QIR/OpenQASM/Pulser, IonQ/PASQAL/Quantinuum/Rigetti o uno strumento di stima delle risorse e altre attività di sviluppo correlate ad Azure Quantum. Non per cache HPC di Azure (usare azure-hpc-cache), Azure Batch (usare azure-batch), Azure Databricks (usare azure-databricks), Azure Machine Learning (usare azure-machine-learning).
