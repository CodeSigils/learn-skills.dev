Connaissance experte du développement Azure Quantum, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'utilisation de QDK/qdk.azure, de tâches hybrides, de circuits QIR/OpenQASM/Pulser, d'IonQ/PASQAL/Quantinuum/Rigetti ou d'un estimateur de ressources et d'autres tâches de développement liées à Azure Quantum. Pas pour Azure HPC Cache (utilisez azure-hpc-cache), Azure Batch (utilisez azure-batch), Azure Databricks (utilisez azure-databricks), Azure Machine Learning (utilisez azure-machine-learning).
