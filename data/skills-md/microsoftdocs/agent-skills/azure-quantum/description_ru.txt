Экспертные знания для разработки Azure Quantum, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании QDK/qdk.azure, гибридных заданий, схем QIR/OpenQASM/Pulser, IonQ/PASQAL/Quantinuum/Rigetti или средства оценки ресурсов, а также других задач разработки, связанных с Azure Quantum. Не для кэша Azure HPC (используйте azure-hpc-cache), пакетной службы Azure (используйте azure-batch), Azure Databricks (используйте azure-databricks), машинного обучения Azure (используйте azure-machine-learning).
