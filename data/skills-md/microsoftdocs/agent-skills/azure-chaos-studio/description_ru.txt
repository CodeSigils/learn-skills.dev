Экспертные знания для разработки Chaos Studio, включая устранение неполадок, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования. Используйте при определении экспериментов ARM/Bicep, развертывании агентов Chaos, использовании CLI/REST или интеграции с Azure Monitor, а также других задачах разработки, связанных с Chaos Studio. Не для Azure Monitor (используйте azure-monitor), устойчивости Azure (используйте azure-reliability), надежности Azure (используйте azure-reliability), Azure Site Recovery (используйте azure-site-recovery).
