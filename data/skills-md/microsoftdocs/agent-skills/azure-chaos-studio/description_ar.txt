معرفة الخبراء بتطوير Chaos Studio بما في ذلك استكشاف الأخطاء وإصلاحها والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند تحديد تجارب ARM/Bicep، أو نشر Chaos Agents، أو استخدام CLI/REST، أو التكامل مع Azure Monitor، ومهام التطوير الأخرى ذات الصلة بـ Chaos Studio. ليس لـ Azure Monitor (استخدم azure-monitor)، وAzure Resiliency (استخدم azure-resiliency)، وموثوقية Azure (استخدم موثوقية azure)، وAzure Site Recovery (استخدم استرداد موقع azure).
