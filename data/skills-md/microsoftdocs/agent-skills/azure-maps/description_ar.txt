معرفة الخبراء لتطوير خرائط Azure بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند استخدام Azure Maps web SDK، أو البحث/الترميز الجغرافي، أو التوجيه/حركة المرور، أو واجهات برمجة تطبيقات الطقس، أو الترحيل من Bing/Google Maps، ومهام التطوير الأخرى ذات الصلة بـ Azure Maps.
