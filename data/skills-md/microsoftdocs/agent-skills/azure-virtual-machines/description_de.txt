Expertenwissen für die Entwicklung von Azure Virtual Machines, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Nicht für Azure Virtual Machine Scale Sets (verwenden Sie azure-vm-scalesets), SQL Server auf Azure Virtual Machines (verwenden Sie azure-sql-virtual-machines), Azure Kubernetes Service (AKS) (verwenden Sie azure-kubernetes-service), Azure App Service (verwenden Sie azure-app-service).
