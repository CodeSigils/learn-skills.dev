Conoscenza approfondita dello sviluppo di macchine virtuali di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si scelgono le dimensioni delle macchine virtuali, si configurano set di scalabilità, si usa Avvio attendibile, si crittografano i dischi o si esegue l'automazione tramite CLI/ARM e altre attività di sviluppo correlate a Macchine virtuali di Azure. Non per set di scalabilità di macchine virtuali di Azure (usare azure-vm-scalesets), SQL Server in macchine virtuali di Azure (usare azure-sql-virtual-machines), Servizio Azure Kubernetes (AKS) (usare azure-kubernetes-service), Servizio app di Azure (usare azure-app-service).
