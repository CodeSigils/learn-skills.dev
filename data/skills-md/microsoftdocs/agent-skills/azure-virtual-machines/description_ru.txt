Экспертные знания для разработки виртуальных машин Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при выборе размеров виртуальных машин, настройке масштабируемых наборов, использовании доверенного запуска, шифровании дисков или автоматизации через CLI/ARM, а также при выполнении других задач разработки, связанных с виртуальными машинами Azure. Не для масштабируемых наборов виртуальных машин Azure (используйте azure-vm-scalesets), SQL Server на виртуальных машинах Azure (используйте azure-sql-virtual-machines), Службы Azure Kubernetes (AKS) (используйте azure-kubernetes-service), Службы приложений Azure (используйте azure-app-service).
