문제 해결, 모범 사례, 의사 결정, 아키텍처 및 디자인 패턴, 제한 및 할당량, 보안, 구성, 통합 및 코딩 패턴, 배포를 포함한 Azure Virtual Machines 개발에 대한 전문 지식입니다. Azure Virtual Machine Scale Set(azure-vm-scalesets 사용), Azure Virtual Machines의 SQL Server(azure-sql-virtual-machines 사용), AKS(Azure Kubernetes Service)(azure-kubernetes-service 사용), Azure App Service(azure-app-service 사용)에는 해당되지 않습니다.
