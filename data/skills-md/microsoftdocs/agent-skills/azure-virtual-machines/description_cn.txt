Azure 虚拟机开发的专业知识，包括故障排除、最佳实践、决策、体系结构和设计模式、限制和配额、安全性、配置、集成和编码模式以及部署。在选择 VM 大小、配置规模集、使用可信启动、加密磁盘或通过 CLI/ARM 实现自动化以及其他 Azure 虚拟机相关开发任务时使用。不适用于 Azure 虚拟机规模集（使用 azure-vm-scalesets）、Azure 虚拟机上的 SQL Server（使用 azure-sql-virtual-machines）、Azure Kubernetes 服务 (AKS)（使用 azure-kubernetes-service）、Azure 应用服务（使用 azure-app-service）。
