معرفة الخبراء بتطوير Azure Virtual Machines بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند اختيار أحجام الأجهزة الافتراضية، أو تكوين مجموعات المقاييس، أو استخدام Trusted Launch، أو تشفير الأقراص، أو التشغيل الآلي عبر CLI/ARM، ومهام التطوير الأخرى ذات الصلة بأجهزة Azure الظاهرية. ليس لمجموعات مقياس Azure Virtual Machine (استخدم azure-vm-scalesets)، وSQL Server على أجهزة Azure الظاهرية (استخدم azure-sql-virtual-machines)، وخدمة Azure Kubernetes (AKS) (استخدم خدمة azure-kubernetes)، وخدمة Azure App (استخدم خدمة تطبيق azure).
