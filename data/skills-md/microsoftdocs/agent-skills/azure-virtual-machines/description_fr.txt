Connaissance approfondie du développement de machines virtuelles Azure, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors du choix des tailles de machines virtuelles, de la configuration des groupes identiques, de l'utilisation du lancement sécurisé, du chiffrement des disques ou de l'automatisation via CLI/ARM, ainsi que d'autres tâches de développement liées aux machines virtuelles Azure. Pas pour les groupes de machines virtuelles identiques Azure (utilisez azure-vm-scalesets), SQL Server sur les machines virtuelles Azure (utilisez azure-sql-virtual-machines), Azure Kubernetes Service (AKS) (utilisez azure-kubernetes-service), Azure App Service (utilisez azure-app-service).
