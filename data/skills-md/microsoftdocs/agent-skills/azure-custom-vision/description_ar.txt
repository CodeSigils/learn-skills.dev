معرفة الخبراء بتطوير Azure AI Custom Vision بما في ذلك أفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكامل وأنماط الترميز والنشر. يُستخدم عند تصدير نماذج Custom Vision، واستدعاء واجهات برمجة التطبيقات للتنبؤ، واستخدام ONNX/TensorFlow، وإدارة CMK/RBAC، أو Smart Labeler، ومهام التطوير الأخرى ذات الصلة بـ Azure AI Custom Vision. ليس لـ Azure AI Vision (استخدم azure-ai-vision)، وخدمات Azure AI (استخدم أدوات microsoft-foundry)، وAzure Machine Learning (استخدم التعلم الآلي azure)، وAzure AI Foundry Local (استخدم Microsoft Foundry-local).
