Экспертные знания для разработки Azure AI Custom Vision, включая лучшие практики, принятие решений, ограничения и квоты, безопасность, интеграцию и шаблоны кодирования, а также развертывание. Используйте при экспорте моделей Custom Vision, вызове API прогнозирования, использовании ONNX/TensorFlow, управлении CMK/RBAC или Smart Labeler и других задачах разработки, связанных с Azure AI Custom Vision. Не для Azure AI Vision (используйте azure-ai-vision), служб Azure AI (используйте microsoft-foundry-tools), машинного обучения Azure (используйте azure-machine-learning), Azure AI Foundry Local (используйте microsoft-foundry-local).
