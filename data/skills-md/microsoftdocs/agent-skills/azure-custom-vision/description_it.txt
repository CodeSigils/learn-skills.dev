Conoscenza approfondita dello sviluppo di Azure AI Custom Vision, tra cui best practice, processo decisionale, limiti e quote, sicurezza, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante l'esportazione di modelli di visione personalizzata, la chiamata di API di previsione, l'uso di ONNX/TensorFlow, la gestione di CMK/RBAC o Smart Labeler e altre attività di sviluppo correlate alla visione personalizzata di Azure AI. Non per Azure AI Vision (usare azure-ai-vision), servizi Azure AI (usare microsoft-foundry-tools), Azure Machine Learning (usare azure-machine-learning), Azure AI Foundry Local (usare microsoft-foundry-local).
