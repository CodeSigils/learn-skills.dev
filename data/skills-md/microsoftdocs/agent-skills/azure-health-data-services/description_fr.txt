Connaissance approfondie du développement d'Azure Health Data Services, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'utilisation des services FHIR/DICOM/MedTech, des API de désidentification, des opérations en masse, des pipelines Synapse ou de Private Link, ainsi que d'autres tâches de développement liées à Azure Health Data Services. Pas pour Azure Health Bot (utilisez azure-health-bot), Azure API Management (utilisez azure-api-management), Azure Data Factory (utilisez azure-data-factory), Azure Synapse Analytics (utilisez azure-synapse-analytics).
