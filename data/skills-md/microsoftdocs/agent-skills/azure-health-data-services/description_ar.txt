معرفة الخبراء بتطوير Azure Health Data Services بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام خدمات FHIR/DICOM/MedTech، أو واجهات برمجة التطبيقات لإلغاء التعريف، أو العمليات المجمعة، أو خطوط أنابيب Synapse، أو الرابط الخاص، ومهام التطوير الأخرى ذات الصلة بخدمات Azure Health Data Services. ليس لـ Azure Health Bot (استخدم azure-health-bot)، وإدارة Azure API (استخدم azure-api-management)، وAzure Data Factory (استخدم azure-data-factory)، وAzure Synapse Analytics (استخدم تحليلات azure-synapse).
