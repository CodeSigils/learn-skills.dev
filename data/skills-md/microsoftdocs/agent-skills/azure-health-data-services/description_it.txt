Conoscenza approfondita dello sviluppo di Azure Health Data Services, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usano servizi FHIR/DICOM/MedTech, API di anonimizzazione, operazioni in blocco, pipeline di sinapsi o collegamento privato e altre attività di sviluppo correlate a Servizi dati sanitari di Azure. Non per Azure Health Bot (usare azure-health-bot), Gestione API di Azure (usare azure-api-management), Azure Data Factory (usare azure-data-factory), Azure Synapse Analytics (usare azure-synapse-analytics).
