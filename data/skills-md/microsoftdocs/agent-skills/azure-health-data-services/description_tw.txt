Azure 健康資料服務開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在使用 FHIR/DICOM/MedTech 服務、去識別 API、大量操作、Synapse 管道或專用連結以及其他 Azure 健康數據服務相關開發任務時使用。不適用於 Azure Health Bot（使用 azure-health-bot）、Azure API 管理（使用 azure-api-management）、Azure 資料工廠（使用 azure-data-factory）、Azure Synapse Analytics（使用 azure-synapse-analytics）。
