Экспертные знания для разработки служб данных о состоянии здоровья Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании служб FHIR/DICOM/MedTech, API деидентификации, массовых операций, конвейеров Synapse или Private Link, а также других задач разработки, связанных с Azure Health Data Services. Не для Azure Health Bot (используйте azure-health-bot), управления API Azure (используйте azure-api-management), фабрики данных Azure (используйте azure-data-factory), Azure Synapse Analytics (используйте azure-synapse-analytics).
