Экспертные знания для разработки Конфиденциального реестра Azure, включая принятие решений, безопасность, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке Entra ID/RBAC, клиентских сертификатов, аттестации узлов, .NET SDK, пользовательских функций JavaScript или развертываний ARM/Terraform, а также других задач разработки, связанных с Azure Confidential Ledger. Не для конфиденциальных вычислений Azure (используйте azure-confidential-computing), Azure Key Vault (используйте azure-key-vault), Azure Dedicated HSM (используйте azure-dedicated-hsm), Azure Cloud Hsm (используйте azure-cloud-hsm).
