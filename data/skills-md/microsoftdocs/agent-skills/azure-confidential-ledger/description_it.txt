Conoscenza approfondita dello sviluppo di Azure Confidential Ledger, inclusi processo decisionale, sicurezza, integrazioni, modelli di codifica e distribuzione. Da usare durante la configurazione di Entra ID/RBAC, certificati client, attestazione del nodo, .NET SDK, UDF JavaScript o distribuzioni ARM/Terraform e altre attività di sviluppo correlate a Azure Confidential Ledger. Non per Azure Confidential Computing (usare azure-confidential-computing), Azure Key Vault (usare azure-key-vault), Azure Dedicated HSM (usare azure-dedicated-hsm), Azure Cloud Hsm (usare azure-cloud-hsm).
