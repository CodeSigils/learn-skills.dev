معرفة الخبراء بتطوير Azure Confidential Ledger بما في ذلك اتخاذ القرار والأمان والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين Entra ID/RBAC، أو شهادات العميل، أو شهادة العقدة، أو .NET SDK، أو JavaScript UDFs، أو عمليات نشر ARM/Terraform، ومهام التطوير الأخرى ذات الصلة بـ Azure Confidential Ledger. ليس مخصصًا للحوسبة السرية في Azure (استخدم الحوسبة السرية azure)، وAzure Key Vault (استخدم azure-key-vault)، وAzure Dedicated HSM (استخدم azure-dedicated-hsm)، وAzure Cloud Hsm (استخدم azure-cloud-hsm).
