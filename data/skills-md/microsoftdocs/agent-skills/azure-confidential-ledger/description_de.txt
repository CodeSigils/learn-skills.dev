Expertenwissen für die Azure Confidential Ledger-Entwicklung, einschließlich Entscheidungsfindung, Sicherheit, Integrationen und Codierungsmuster sowie Bereitstellung. Wird zum Konfigurieren von Entra ID/RBAC, Client-Zertifikaten, Knotenbescheinigung, .NET SDK, JavaScript-UDFs oder ARM/Terraform-Bereitstellungen und anderen Azure Confidential Ledger-bezogenen Entwicklungsaufgaben verwendet. Nicht für Azure Confidential Computing (verwenden Sie azure-confidential-computing), Azure Key Vault (verwenden Sie azure-key-vault), Azure Dedicated HSM (verwenden Sie azure-dedicated-hsm), Azure Cloud Hsm (verwenden Sie azure-cloud-hsm).
