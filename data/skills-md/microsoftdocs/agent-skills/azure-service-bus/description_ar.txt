معرفة الخبراء بتطوير Azure Service Bus بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام قوائم الانتظار/الموضوعات، أو الجلسات/FIFO، أو تكامل JMS/RabbitMQ، أو النسخ المتماثل الجغرافي، أو أحمال العمل المميزة عالية النطاق، ومهام التطوير الأخرى ذات الصلة بـ Azure Service Bus. ليس لـ Azure Event Hubs (استخدم azure-event-hubs)، وAzure Relay (استخدم azure-relay)، وAzure Notification Hubs (استخدم azure-notification-hubs)، وAzure Web PubSub (استخدم azure-web-pubsub).
