トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、デプロイメントなど、Azure Service Bus 開発に関する専門知識。キュー/トピック、セッション/FIFO、JMS/RabbitMQ 統合、geo レプリケーション、またはプレミアムの高スケール ワークロード、およびその他の Azure Service Bus 関連の開発タスクを使用する場合に使用します。 Azure Event Hubs (azure-event-hubs を使用)、Azure Relay (azure-relay を使用)、Azure Notice Hubs (azure-notification-hubs を使用)、Azure Web PubSub (azure-web-pubsub を使用) には適用されません。
