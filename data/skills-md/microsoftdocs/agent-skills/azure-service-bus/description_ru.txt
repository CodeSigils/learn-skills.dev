Экспертные знания по разработке служебной шины Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании очередей/тем, сеансов/FIFO, интеграции JMS/RabbitMQ, георепликации или крупномасштабных рабочих нагрузок Premium, а также других задач разработки, связанных с Azure Service Bus. Не для Центров событий Azure (используйте azure-event-hubs), Azure Relay (используйте azure-relay), Центров уведомлений Azure (используйте azure-notification-hubs), Azure Web PubSub (используйте azure-web-pubsub).
