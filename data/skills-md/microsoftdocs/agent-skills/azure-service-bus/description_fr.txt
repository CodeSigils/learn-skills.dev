Connaissance approfondie du développement d'Azure Service Bus, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'utilisation de files d'attente/sujets, de sessions/FIFO, d'intégration JMS/RabbitMQ, de géoréplication ou de charges de travail Premium à grande échelle, ainsi que d'autres tâches de développement liées à Azure Service Bus. Pas pour Azure Event Hubs (utilisez azure-event-hubs), Azure Relay (utilisez azure-relay), Azure Notification Hubs (utilisez azure-notification-hubs), Azure Web PubSub (utilisez azure-web-pubsub).
