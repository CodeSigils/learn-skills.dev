Экспертные знания в области разработки отслеживания бизнес-процессов Azure, включая развертывание. Используйте при создании конвейеров CI/CD, автоматизации сборок, запуске тестов и развертывании решений отслеживания с помощью инструментов DevOps, а также при выполнении других задач разработки, связанных с отслеживанием бизнес-процессов Azure. Не для Azure Monitor (используйте azure-monitor), Azure Logic Apps (используйте azure-logic-apps), Фабрики данных Azure (используйте azure-data-factory), Машинное обучение Azure (используйте azure-machine-learning).
