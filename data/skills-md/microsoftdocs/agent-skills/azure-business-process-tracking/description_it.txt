Conoscenza approfondita dello sviluppo del monitoraggio dei processi aziendali di Azure, inclusa la distribuzione. Da utilizzare durante la creazione di pipeline CI/CD, l'automazione delle build, l'esecuzione di test e la distribuzione di soluzioni di monitoraggio tramite strumenti DevOps e altre attività di sviluppo correlate al monitoraggio dei processi aziendali di Azure. Non per Monitoraggio di Azure (usare azure-monitor), App per la logica di Azure (usare azure-logic-apps), Azure Data Factory (usare azure-data-factory), Azure Machine Learning (usare azure-machine-learning).
