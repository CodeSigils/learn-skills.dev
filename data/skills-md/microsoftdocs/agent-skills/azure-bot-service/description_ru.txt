Экспертные знания для разработки службы Azure AI Bot Service, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при создании ботов Azure AI с помощью прямой линии/веб-чата, каналов Teams/SMS, OAuth/SSO, навыков или упреждающих сообщений, а также других задач разработки, связанных со службой Azure AI Bot Service. Не для Azure Health Bot (используйте azure-health-bot), Функций Azure (используйте azure-functions), Службы приложений Azure (используйте azure-app-service), Azure Logic Apps (используйте azure-logic-apps).
