معرفة الخبراء بتطوير Azure AI Bot Service بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إنشاء روبوتات Azure AI باستخدام الخط المباشر/دردشة الويب أو قنوات الفرق/الرسائل النصية القصيرة أو OAuth/SSO أو المهارات أو الرسائل الاستباقية ومهام التطوير الأخرى ذات الصلة بخدمة Azure AI Bot Service. ليس لـ Azure Health Bot (استخدم azure-health-bot)، ووظائف Azure (استخدم وظائف azure)، وخدمة تطبيقات Azure (استخدم خدمة تطبيق azure)، وتطبيقات Azure Logic (استخدم تطبيقات azure-logic).
