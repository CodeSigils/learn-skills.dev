Connaissance approfondie du développement d'Azure AI Bot Service, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la création de robots Azure AI avec ligne directe/chat Web, canaux Teams/SMS, OAuth/SSO, compétences ou messages proactifs, ainsi que d'autres tâches de développement liées à Azure AI Bot Service. Pas pour Azure Health Bot (utilisez azure-health-bot), Azure Functions (utilisez azure-functions), Azure App Service (utilisez azure-app-service), Azure Logic Apps (utilisez azure-logic-apps).
