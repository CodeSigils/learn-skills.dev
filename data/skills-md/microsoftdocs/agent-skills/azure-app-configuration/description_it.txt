Conoscenza approfondita dello sviluppo di Configurazione app di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usano flag di funzionalità, aggiornamento dinamico, snapshot, integrazione di Key Vault o API REST di Configurazione app e altre attività di sviluppo correlate a Configurazione app di Azure. Non per Servizio app di Azure (usare azure-app-service), Azure Key Vault (usare azure-key-vault), Automazione di Azure (usare azure-automation), Criteri di Azure (usare azure-policy).
