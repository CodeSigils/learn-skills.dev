Экспертные знания для разработки конфигурации приложений Azure, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании флагов функций, динамического обновления, моментальных снимков, интеграции Key Vault или API REST конфигурации приложений, а также других задач разработки, связанных с Конфигурацией приложений Azure. Не для Службы приложений Azure (используйте azure-app-service), Azure Key Vault (используйте azure-key-vault), автоматизации Azure (используйте azure-automation), Политики Azure (используйте azure-policy).
