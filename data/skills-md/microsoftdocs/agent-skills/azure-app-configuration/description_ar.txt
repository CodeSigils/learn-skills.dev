معرفة الخبراء لتطوير تكوين تطبيق Azure بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام علامات الميزات، أو التحديث الديناميكي، أو اللقطات، أو تكامل Key Vault، أو واجهات برمجة تطبيقات REST لتكوين التطبيق، ومهام التطوير الأخرى ذات الصلة بتكوين تطبيق Azure. ليس لخدمة Azure App (استخدم azure-app-service)، وAzure Key Vault (استخدم azure-key-vault)، وAzure Automation (استخدم azure-automation)، وسياسة Azure (استخدم سياسة azure).
