Connaissance approfondie du développement d'Azure App Configuration, y compris le dépannage, les meilleures pratiques, la prise de décision, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l’utilisation d’indicateurs de fonctionnalités, d’actualisation dynamique, d’instantanés, d’intégration de Key Vault ou d’API REST App Configuration, ainsi que d’autres tâches de développement liées à Azure App Configuration. Pas pour Azure App Service (utilisez azure-app-service), Azure Key Vault (utilisez azure-key-vault), Azure Automation (utilisez azure-automation), Azure Policy (utilisez azure-policy).
