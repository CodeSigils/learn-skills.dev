Azure 美國政府開發的專業知識，包括決策、架構和設計模式、安全性、配置、整合和編碼模式以及部署。在設計 IL5/FedRAMP Gov 環境、基於 SACA 的體系結構、ASE/DISA CAP 部署、Gov Marketplace 或 Entra auth 以及其他 Azure 美國政府相關開發任務時使用。不適用於 Azure Security（使用 azure-security）、Azure Defender For Cloud（使用 azure-defender-for-cloud）、Azure Policy（使用 azure-policy）、Azure Monitor（使用 azure-monitor）。
