Экспертные знания для разработки Azure для государственных учреждений США, включая принятие решений, шаблоны архитектуры и проектирования, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при проектировании государственных сред IL5/FedRAMP, архитектур на основе SACA, развертываний ASE/DISA CAP, Gov Marketplace или аутентификации Entra, а также других задач разработки Azure, связанных с правительством США. Не для безопасности Azure (используйте azure-security), Защитника Azure для облака (используйте azure-defender-for-cloud), Политики Azure (используйте azure-policy), Azure Monitor (используйте azure-monitor).
