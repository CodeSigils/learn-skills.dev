معرفة الخبراء بتطوير Azure US Government بما في ذلك اتخاذ القرار وأنماط التصميم والتصميم والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تصميم بيئات IL5/FedRAMP Gov، أو البنى المستندة إلى SACA، أو عمليات نشر ASE/DISA CAP، أو Gov Marketplace، أو مصادقة Entra، ومهام التطوير الأخرى ذات الصلة بحكومة Azure الأمريكية. ليس لـ Azure Security (استخدم azure-security)، وAzure Defender For Cloud (استخدم azure-defender-for-cloud)، وAzure Policy (استخدم azure-policy)، وAzure Monitor (استخدم azure-monitor).
