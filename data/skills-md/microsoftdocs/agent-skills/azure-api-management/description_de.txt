Expertenwissen für die Azure API Management-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird zum Verwalten von APIM-Richtlinien, selbstgehosteten Gateways, VNet-/App-Gateway-/Front-Door-Setups, Kontingenten oder OAuth-/JWT-Authentifizierung und anderen Entwicklungsaufgaben im Zusammenhang mit Azure API Management verwendet. Nicht für Azure Application Gateway (verwenden Sie azure-application-gateway), Azure Front Door (verwenden Sie azure-front-door), Azure Api Center (verwenden Sie azure-api-center), Azure Web Application Firewall (verwenden Sie azure-web-application-firewall).
