Экспертные знания для разработки управления API Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при управлении политиками APIM, автономными шлюзами, настройками виртуальной сети/шлюза приложений/передней двери, квотами или проверкой подлинности OAuth/JWT, а также другими задачами разработки, связанными с управлением API Azure. Не для шлюза приложений Azure (используйте azure-application-gateway), Azure Front Door (используйте azure-front-door), Azure Api Center (используйте azure-api-center), брандмауэра веб-приложений Azure (используйте azure-web-application-firewall).
