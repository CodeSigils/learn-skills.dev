Connaissance approfondie du développement de la gestion des API Azure, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la gestion des stratégies APIM, des passerelles auto-hébergées, des configurations de réseau virtuel/App Gateway/Front Door, des quotas ou de l'authentification OAuth/JWT et d'autres tâches de développement liées à la gestion des API Azure. Pas pour Azure Application Gateway (utilisez azure-application-gateway), Azure Front Door (utilisez azure-front-door), Azure Api Center (utilisez azure-api-center), Azure Web Application Firewall (utilisez azure-web-application-firewall).
