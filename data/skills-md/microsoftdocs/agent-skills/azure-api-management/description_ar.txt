معرفة الخبراء لتطوير Azure API Management بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إدارة سياسات APIM، أو البوابات ذاتية الاستضافة، أو إعدادات VNet/App Gateway/Front Door، أو الحصص، أو مصادقة OAuth/JWT، ومهام التطوير الأخرى ذات الصلة بإدارة Azure API. ليس لبوابة تطبيق Azure (استخدم azure-application-gateway)، وAzure Front Door (استخدم azure-front-door)، ومركز Azure Api (استخدم azure-api-center)، وجدار حماية تطبيق الويب Azure (استخدم جدار حماية تطبيق الويب azure).
