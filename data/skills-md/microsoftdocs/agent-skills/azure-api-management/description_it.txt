Conoscenza approfondita dello sviluppo della gestione API di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la gestione di criteri APIM, gateway self-hosted, configurazioni VNet/Gateway app/porta anteriore, quote o autenticazione OAuth/JWT e altre attività di sviluppo correlate a Gestione API di Azure. Non per il gateway applicazione di Azure (usare azure-application-gateway), la porta anteriore di Azure (usare azure-front-door), il centro API di Azure (usare azure-api-center), il firewall applicazione Web di Azure (usare azure-web-application-firewall).
