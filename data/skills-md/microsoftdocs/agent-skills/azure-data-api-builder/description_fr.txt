Connaissance approfondie du développement d'Azure Data Api Builder, y compris le dépannage, les meilleures pratiques, la prise de décision, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la définition d'entités DAB sur SQL/Cosmos, de l'exposition de REST/GraphQL, de la sécurisation de l'authentification/RLS ou du déploiement via Docker/Azure et d'autres tâches de développement liées à Azure Data Api Builder. Pas pour Azure API Management (utilisez azure-api-management), Azure Functions (utilisez azure-functions), Azure App Service (utilisez azure-app-service), Azure Logic Apps (utilisez azure-logic-apps).
