معرفة الخبراء بتطوير Azure Data Api Builder بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تعريف كيانات DAB عبر SQL/Cosmos، أو الكشف عن REST/GraphQL، أو تأمين المصادقة/RLS، أو النشر عبر Docker/Azure، ومهام التطوير الأخرى ذات الصلة بـ Azure Data Api Builder. ليس لإدارة Azure API (استخدم azure-api-management)، ووظائف Azure (استخدم وظائف azure)، وخدمة Azure App (استخدم خدمة تطبيق azure)، وتطبيقات Azure Logic (استخدم تطبيقات azure-logic).
