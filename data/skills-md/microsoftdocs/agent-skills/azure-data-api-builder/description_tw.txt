Azure Data Api Builder 開發的專業知識，包括故障排除、最佳實踐、決策、限制和配額、安全性、配置、整合和編碼模式以及部署。在透過 SQL/Cosmos 定義 DAB 實體、公開 REST/GraphQL、保護驗證/RLS 或透過 Docker/Azure 進行部署以及其他 Azure Data Api Builder 相關開發任務時使用。不適用於 Azure API 管理（使用 azure-api-management）、Azure Functions（使用 azure-functions）、Azure 應用程式服務（使用 azure-app-service）、Azure 邏輯應用程式（使用 azure-logic-apps）。
