Экспертные знания для разработки Azure Data Api Builder, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при определении сущностей DAB через SQL/Cosmos, предоставлении доступа к REST/GraphQL, защите аутентификации/RLS или развертывании через Docker/Azure, а также при выполнении других задач разработки, связанных с Azure Data Api Builder. Не для управления API Azure (используйте azure-api-management), Функций Azure (используйте azure-функции), Службы приложений Azure (используйте azure-app-service), Azure Logic Apps (используйте azure-logic-apps).
