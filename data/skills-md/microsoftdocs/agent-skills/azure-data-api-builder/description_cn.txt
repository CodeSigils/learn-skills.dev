Azure Data Api Builder 开发的专业知识，包括故障排除、最佳实践、决策、限制和配额、安全性、配置、集成和编码模式以及部署。在通过 SQL/Cosmos 定义 DAB 实体、公开 REST/GraphQL、保护身份验证/RLS 或通过 Docker/Azure 进行部署以及其他 Azure Data Api Builder 相关开发任务时使用。不适用于 Azure API 管理（使用 azure-api-management）、Azure Functions（使用 azure-functions）、Azure 应用服务（使用 azure-app-service）、Azure 逻辑应用（使用 azure-logic-apps）。
