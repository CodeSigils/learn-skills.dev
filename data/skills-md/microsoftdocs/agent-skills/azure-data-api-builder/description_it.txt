Conoscenza approfondita dello sviluppo di Azure Data Api Builder, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la definizione di entità DAB su SQL/Cosmos, l'esposizione di REST/GraphQL, la protezione di autenticazione/RLS o la distribuzione tramite Docker/Azure e altre attività di sviluppo correlate a Azure Data Api Builder. Non per Gestione API di Azure (usare azure-api-management), Funzioni di Azure (usare azure-functions), Servizio app di Azure (usare azure-app-service), App per la logica di Azure (usare azure-logic-apps).
