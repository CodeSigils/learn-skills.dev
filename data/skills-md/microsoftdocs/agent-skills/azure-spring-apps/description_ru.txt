Экспертные знания для разработки приложений Azure Spring, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке сети/безопасности ASA, инструментов Tanzu, наблюдаемости/APM, развертываний CI/CD или сине-зеленых выпусков, а также других задач разработки, связанных с приложениями Azure Spring. Не для Службы приложений Azure (используйте azure-app-service), Контейнерных приложений Azure (используйте azure-container-apps), Службы Azure Kubernetes (AKS) (используйте azure-kubernetes-service), Функций Azure (используйте azure-functions).
