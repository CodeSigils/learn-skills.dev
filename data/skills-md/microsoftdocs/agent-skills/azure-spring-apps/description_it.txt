Conoscenza approfondita dello sviluppo delle app Azure Spring, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la configurazione di rete/sicurezza ASA, strumenti Tanzu, osservabilità/APM, distribuzioni CI/CD o versioni blu-verdi e altre attività di sviluppo correlate alle app Azure Spring. Non per Servizio app di Azure (usare azure-app-service), App contenitore di Azure (usare azure-container-apps), Servizio Azure Kubernetes (AKS) (usare azure-kubernetes-service), Funzioni di Azure (usare azure-functions).
