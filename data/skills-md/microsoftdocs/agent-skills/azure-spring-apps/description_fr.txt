Connaissance approfondie du développement d'Azure Spring Apps, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la configuration de la mise en réseau/sécurité ASA, des outils Tanzu, de l'observabilité/APM, des déploiements CI/CD ou des versions bleu-vert, ainsi que d'autres tâches de développement liées à Azure Spring Apps. Pas pour Azure App Service (utilisez azure-app-service), Azure Container Apps (utilisez azure-container-apps), Azure Kubernetes Service (AKS) (utilisez azure-kubernetes-service), Azure Functions (utilisez azure-functions).
