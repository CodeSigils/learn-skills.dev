معرفة الخبراء بتطوير Azure Spring Apps بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين شبكة/أمان ASA، أو أدوات Tanzu، أو إمكانية المراقبة/APM، أو عمليات نشر CI/CD، أو الإصدارات ذات اللون الأزرق والأخضر، ومهام التطوير الأخرى ذات الصلة بتطبيقات Azure Spring. ليس لخدمة Azure App (استخدم azure-app-service)، وتطبيقات Azure Container (استخدم azure-container-apps)، وخدمة Azure Kubernetes (AKS) (استخدم خدمة azure-kubernetes)، ووظائف Azure (استخدم وظائف azure).
