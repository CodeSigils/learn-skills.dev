Expertenwissen für die Azure Relay-Entwicklung, einschließlich Fehlerbehebung, Sicherheit, Konfiguration sowie Integrationen und Codierungsmuster. Wird zum Konfigurieren von Hybridverbindungen, WCF-Relays, Entra ID/SAS-Authentifizierung, Private Link oder .NET/Node.js Relay-Clients und anderen Entwicklungsaufgaben im Zusammenhang mit Azure Relay verwendet. Nicht für Azure Service Bus (verwenden Sie azure-service-bus), Azure Event Hubs (verwenden Sie azure-event-hubs), Azure Web PubSub (verwenden Sie azure-web-pubsub), Azure Application Gateway (verwenden Sie azure-application-gateway).
