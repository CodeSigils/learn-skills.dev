معرفة الخبراء بتطوير Azure Relay بما في ذلك استكشاف الأخطاء وإصلاحها والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند تكوين الاتصالات المختلطة، أو مرحلات WCF، أو مصادقة Entra ID/SAS، أو الارتباط الخاص، أو عملاء Relay .NET/Node.js، ومهام التطوير الأخرى ذات الصلة بـ Azure Relay. ليس لناقل خدمة Azure (استخدم azure-service-bus)، وAzure Event Hubs (استخدم azure-event-hubs)، وAzure Web PubSub (استخدم azure-web-pubsub)، وبوابة تطبيق Azure (استخدم بوابة تطبيق azure).
