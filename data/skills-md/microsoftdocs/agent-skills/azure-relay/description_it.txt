Conoscenza approfondita dello sviluppo di Inoltro di Azure, tra cui risoluzione dei problemi, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare durante la configurazione di connessioni ibride, inoltri WCF, autenticazione Entra ID/SAS, collegamento privato o client di inoltro .NET/Node.js e altre attività di sviluppo correlate all'inoltro di Azure. Non per bus di servizio di Azure (usare azure-service-bus), Hub eventi di Azure (usare azure-event-hubs), PubSub Web di Azure (usare azure-web-pubsub), Gateway applicazione di Azure (usare azure-application-gateway).
