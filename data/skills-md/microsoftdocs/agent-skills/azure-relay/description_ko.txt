문제 해결, 보안, 구성, 통합 및 코딩 패턴을 포함한 Azure Relay 개발에 대한 전문 지식입니다. 하이브리드 연결, WCF 릴레이, Entra ID/SAS 인증, Private Link 또는 .NET/Node.js 릴레이 클라이언트 및 기타 Azure Relay 관련 개발 작업을 구성할 때 사용합니다. Azure Service Bus(azure-service-bus 사용), Azure Event Hubs(azure-event-hubs 사용), Azure Web PubSub(azure-web-pubsub 사용), Azure Application Gateway(azure-application-gateway 사용)에는 해당되지 않습니다.
