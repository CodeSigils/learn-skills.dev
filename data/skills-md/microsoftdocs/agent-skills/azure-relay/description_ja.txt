トラブルシューティング、セキュリティ、構成、統合とコーディング パターンなど、Azure Relay 開発に関する専門知識。ハイブリッド接続、WCF リレー、Entra ID/SAS 認証、プライベート リンク、または .NET/Node.js リレー クライアント、およびその他の Azure Relay 関連の開発タスクを構成するときに使用します。 Azure Service Bus (azure-service-bus を使用)、Azure Event Hubs (azure-event-hubs を使用)、Azure Web PubSub (azure-web-pubsub を使用)、Azure Application Gateway (azure-application-gateway を使用) には使用できません。
