Экспертные знания по разработке Azure Relay, включая устранение неполадок, безопасность, настройку, интеграцию и шаблоны кодирования. Используйте при настройке гибридных подключений, ретрансляторов WCF, аутентификации Entra ID/SAS, Private Link или клиентов ретрансляции .NET/Node.js, а также других задач разработки, связанных с Azure Relay. Не для служебной шины Azure (используйте azure-service-bus), Центров событий Azure (используйте azure-event-hubs), Azure Web PubSub (используйте azure-web-pubsub), Шлюза приложений Azure (используйте azure-application-gateway).
