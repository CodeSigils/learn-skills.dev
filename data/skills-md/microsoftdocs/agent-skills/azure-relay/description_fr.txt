Connaissance experte du développement Azure Relay, y compris le dépannage, la sécurité, la configuration, les intégrations et les modèles de codage. À utiliser lors de la configuration des connexions hybrides, des relais WCF, de l'authentification Entra ID/SAS, de Private Link ou des clients Relay .NET/Node.js, ainsi que d'autres tâches de développement liées à Azure Relay. Pas pour Azure Service Bus (utilisez azure-service-bus), Azure Event Hubs (utilisez azure-event-hubs), Azure Web PubSub (utilisez azure-web-pubsub), Azure Application Gateway (utilisez azure-application-gateway).
