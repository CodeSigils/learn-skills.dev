Экспертные знания для разработки управления доступом на основе ролей Azure, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при определении ролей/условий ABAC, запрете назначений, PIM, настраиваемых ролях или RBAC через CLI/PowerShell/REST и других задачах разработки, связанных с управлением доступом на основе ролей Azure. Не для Политики Azure (используйте azure-policy), Безопасности Azure (используйте azure-security), Azure Resource Manager (используйте azure-resource-manager), Портала Azure (используйте azure-portal).
