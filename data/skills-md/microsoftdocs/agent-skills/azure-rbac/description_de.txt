Expertenwissen für die Entwicklung der rollenbasierten Azure-Zugriffskontrolle, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Grenzwerte und Kontingente, Sicherheit, Konfiguration sowie Integrationen und Codierungsmuster. Wird zum Definieren von Rollen/ABAC-Bedingungen, zum Verweigern von Zuweisungen, PIM, benutzerdefinierten Rollen oder RBAC über CLI/PowerShell/REST und für andere Entwicklungsaufgaben im Zusammenhang mit der rollenbasierten Zugriffssteuerung von Azure verwendet. Nicht für Azure Policy (verwenden Sie azure-policy), Azure Security (verwenden Sie azure-security), Azure Resource Manager (verwenden Sie azure-resource-manager), Azure Portal (verwenden Sie azure-portal).
