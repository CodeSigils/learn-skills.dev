Connaissance experte du développement de contrôle d'accès basé sur les rôles Azure, y compris le dépannage, les meilleures pratiques, la prise de décision, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage. À utiliser lors de la définition de rôles/conditions ABAC, de refus d'affectations, de PIM, de rôles personnalisés ou de RBAC via CLI/PowerShell/REST, ainsi que d'autres tâches de développement liées au contrôle d'accès basé sur les rôles Azure. Pas pour Azure Policy (utilisez azure-policy), Azure Security (utilisez azure-security), Azure Resource Manager (utilisez azure-resource-manager), Azure Portal (utilisez azure-portal).
