Conoscenza approfondita dello sviluppo del controllo degli accessi in base al ruolo di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare per definire ruoli/condizioni ABAC, negare assegnazioni, PIM, ruoli personalizzati o RBAC tramite CLI/PowerShell/REST e altre attività di sviluppo correlate al controllo degli accessi in base al ruolo di Azure. Non per Criteri di Azure (usare azure-policy), Sicurezza di Azure (usare azure-security), Azure Resource Manager (usare azure-resource-manager), Portale di Azure (usare azure-portal).
