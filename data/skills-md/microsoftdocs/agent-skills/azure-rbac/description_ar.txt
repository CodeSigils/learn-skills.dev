معرفة الخبراء بتطوير التحكم في الوصول المستند إلى دور Azure بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند تحديد الأدوار/شروط ABAC، أو رفض التعيينات، أو PIM، أو الأدوار المخصصة، أو RBAC عبر CLI/PowerShell/REST، ومهام التطوير الأخرى ذات الصلة بالتحكم في الوصول المستندة إلى دور Azure. ليس لسياسة Azure (استخدم azure-policy)، وAzure Security (استخدم azure-security)، وAzure Resource Manager (استخدم azure-resource-manager)، وAzure Portal (استخدم azure-portal).
