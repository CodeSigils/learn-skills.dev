Экспертные знания для разработки облачных служб Azure, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при управлении облачными службами (расширенная поддержка), версиями гостевой ОС, сертификатами Key Vault, правилами автомасштабирования или автоматизацией PowerShell, а также другими задачами разработки, связанными с облачными службами Azure. Не для сетей Azure (используйте azure-networking), виртуальных машин Azure (используйте azure-virtual-machines), Azure Resource Manager (используйте azure-resource-manager), портала Azure (используйте azure-portal).
