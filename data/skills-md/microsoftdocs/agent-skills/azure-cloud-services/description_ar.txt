معرفة الخبراء بتطوير Azure Cloud Services بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إدارة الخدمات السحابية (الدعم الموسع)، أو إصدارات Guest OS، أو شهادات Key Vault، أو قواعد القياس التلقائي، أو أتمتة PowerShell، ومهام التطوير الأخرى ذات الصلة بـ Azure Cloud Services. ليس لشبكة Azure (استخدم شبكة azure)، وأجهزة Azure الافتراضية (استخدم أجهزة azure الافتراضية)، وAzure Resource Manager (استخدم azure-resource-manager)، وAzure Portal (استخدم azure-portal).
