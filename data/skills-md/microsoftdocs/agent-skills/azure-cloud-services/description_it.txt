Conoscenza approfondita dello sviluppo dei servizi cloud di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la gestione di servizi cloud (supporto esteso), versioni del sistema operativo guest, certificati Key Vault, regole di scalabilità automatica o automazione di PowerShell e altre attività di sviluppo correlate ai servizi cloud di Azure. Non per Rete di Azure (usare azure-networking), Macchine virtuali di Azure (usare azure-virtual-machines), Azure Resource Manager (usare azure-resource-manager), Portale di Azure (usare azure-portal).
