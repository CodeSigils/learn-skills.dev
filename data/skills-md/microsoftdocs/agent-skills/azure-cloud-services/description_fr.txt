Connaissance approfondie du développement d'Azure Cloud Services, y compris le dépannage, les meilleures pratiques, la prise de décision, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la gestion des services cloud (prise en charge étendue), des versions du système d'exploitation invité, des certificats Key Vault, des règles de mise à l'échelle automatique ou de l'automatisation PowerShell, ainsi que d'autres tâches de développement liées aux services cloud Azure. Pas pour Azure Networking (utilisez Azure-networking), les machines virtuelles Azure (utilisez des machines virtuelles Azure), Azure Resource Manager (utilisez Azure-resource-manager), Azure Portal (utilisez Azure-Portal).
