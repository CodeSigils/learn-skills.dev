Expertenwissen für die Entwicklung von Azure Cloud Services, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird zum Verwalten von Cloud-Diensten (erweiterter Support), Gastbetriebssystemversionen, Key Vault-Zertifikaten, Autoskalierungsregeln oder PowerShell-Automatisierung sowie anderen Entwicklungsaufgaben im Zusammenhang mit Azure Cloud Services verwendet. Nicht für Azure Networking (verwenden Sie azure-networking), Azure Virtual Machines (verwenden Sie azure-virtual-machines), Azure Resource Manager (verwenden Sie azure-resource-manager), Azure Portal (verwenden Sie azure-portal).
