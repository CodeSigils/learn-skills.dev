문제 해결, 모범 사례, 의사 결정, 아키텍처 및 디자인 패턴, 제한 및 할당량, 보안, 구성, 통합 및 코딩 패턴, 배포를 포함한 Azure Communication Services 개발에 대한 전문 지식입니다. ACS 통화, 채팅, SMS, 이메일, Teams 상호 운용성, 작업 라우터 또는 연락 센터 솔루션 및 기타 Azure Communication Services 관련 개발 작업을 구축할 때 사용합니다. Azure AI Bot Service(azure-bot-service 사용), Azure Notification Hubs(azure-notification-hubs 사용), Azure SignalR Service(azure-signalr-service 사용), Azure Web PubSub(azure-web-pubsub 사용)에는 해당되지 않습니다.
