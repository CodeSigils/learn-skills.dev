トラブルシューティング、ベスト プラクティス、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、展開など、Azure Communication Services 開発に関する専門知識。 ACS 通話、チャット、SMS、電子メール、Teams 相互運用、Job Router、またはコンタクト センター ソリューション、およびその他の Azure Communication Services 関連の開発タスクを構築するときに使用します。 Azure AI Bot Service (azure-bot-service を使用)、Azure Notice Hubs (azure-notification-hubs を使用)、Azure SignalR Service (azure-signalr-service を使用)、Azure Web PubSub (azure-web-pubsub を使用) には適用されません。
