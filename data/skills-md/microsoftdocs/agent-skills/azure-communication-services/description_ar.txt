معرفة الخبراء لتطوير خدمات اتصالات Azure بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إنشاء مكالمات ACS، أو الدردشة، أو الرسائل القصيرة، أو البريد الإلكتروني، أو التشغيل المتداخل لـ Teams، أو جهاز توجيه المهام، أو حلول مركز الاتصال، ومهام التطوير الأخرى ذات الصلة بخدمات Azure Communication Services. ليس لخدمة Azure AI Bot Service (استخدم azure-bot-service)، ومراكز إعلام Azure (استخدم azure-notification-hubs)، وخدمة Azure SignalR (استخدم azure-signalr-service)، وAzure Web PubSub (استخدم azure-web-pubsub).
