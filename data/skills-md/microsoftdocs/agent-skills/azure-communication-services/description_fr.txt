Connaissance approfondie du développement d'Azure Communication Services, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la création de solutions d'appel, de chat, de SMS, de courrier électronique, d'interopérabilité Teams, de routeur de tâches ou de centre de contact ACS, ainsi que d'autres tâches de développement liées à Azure Communication Services. Pas pour Azure AI Bot Service (utilisez azure-bot-service), Azure Notification Hubs (utilisez azure-notification-hubs), Azure SignalR Service (utilisez azure-signalr-service), Azure Web PubSub (utilisez azure-web-pubsub).
