Expertenwissen für die Entwicklung von Azure Communication Services, einschließlich Fehlerbehebung, Best Practices, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird zum Erstellen von ACS-Anruf-, Chat-, SMS-, E-Mail-, Teams-Interop-, Job-Router- oder Contact-Center-Lösungen und anderen Entwicklungsaufgaben im Zusammenhang mit Azure Communication Services verwendet. Nicht für Azure AI Bot Service (verwenden Sie azure-bot-service), Azure Notification Hubs (verwenden Sie azure-notification-hubs), Azure SignalR Service (verwenden Sie azure-signalr-service), Azure Web PubSub (verwenden Sie azure-web-pubsub).
