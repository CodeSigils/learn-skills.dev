Azure 通訊服務開發的專業知識，包括故障排除、最佳實務、決策、架構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在建置 ACS 呼叫、聊天、簡訊、電子郵件、Teams 互通、作業路由器或聯絡中心解決方案以及其他 Azure 通訊服務相關開發任務時使用。不適用於 Azure AI Bot 服務（使用 azure-bot-service）、Azure 通知中心（使用 azure-notification-hubs）、Azure SignalR 服務（使用 azure-signalr-service）、Azure Web PubSub（使用 azure-web-pubsub）。
