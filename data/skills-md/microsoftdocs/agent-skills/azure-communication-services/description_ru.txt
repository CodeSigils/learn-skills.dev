Экспертные знания для разработки служб связи Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при создании решений ACS для звонков, чата, SMS, электронной почты, взаимодействия с Teams, маршрутизатора заданий или контакт-центра, а также других задач разработки, связанных со службами связи Azure. Не для службы Azure AI Bot (используйте azure-bot-service), Центров уведомлений Azure (используйте azure-notification-hubs), службы Azure SignalR (используйте azure-signalr-service), Azure Web PubSub (используйте azure-web-pubsub).
