Connaissance approfondie du développement d'Azure Notification Hubs, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, ainsi que les intégrations et modèles de codage. À utiliser lors de l'intégration d'APNS/FCM/WNS, de la configuration des crédits PNS, de l'utilisation de REST/SDK, de Private Link ou de push planifiés, ainsi que d'autres tâches de développement liées à Azure Notification Hubs. Pas pour Azure Event Hubs (utilisez azure-event-hubs), Azure Service Bus (utilisez azure-service-bus), Azure Web PubSub (utilisez azure-web-pubsub), Azure SignalR Service (utilisez azure-signalr-service).
