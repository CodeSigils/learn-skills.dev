문제 해결, 모범 사례, 의사 결정, 아키텍처 및 디자인 패턴, 한도 및 할당량, 보안, 구성, 통합 및 코딩 패턴을 포함한 Azure 알림 허브 개발에 대한 전문 지식입니다. APNS/FCM/WNS를 통합하고, PNS 자격 증명을 구성하고, REST/SDK, Private Link 또는 예약된 푸시를 사용하고, 기타 Azure 알림 허브 관련 개발 작업을 수행할 때 사용합니다. Azure Event Hubs(azure-event-hubs 사용), Azure Service Bus(azure-service-bus 사용), Azure Web PubSub(azure-web-pubsub 사용), Azure SignalR Service(azure-signalr-service 사용)에는 해당되지 않습니다.
