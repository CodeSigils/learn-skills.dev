معرفة الخبراء بتطوير Azure Notification Hubs بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند دمج APNS/FCM/WNS، أو تكوين بيانات اعتماد PNS، أو استخدام REST/SDKs، أو الارتباط الخاص، أو الدفعات المجدولة، ومهام التطوير الأخرى ذات الصلة بـ Azure Notification Hubs. ليس لـ Azure Event Hubs (استخدم azure-event-hubs)، وAzure Service Bus (استخدم azure-service-bus)، وAzure Web PubSub (استخدم azure-web-pubsub)، وخدمة Azure SignalR (استخدم خدمة azure-signalr).
