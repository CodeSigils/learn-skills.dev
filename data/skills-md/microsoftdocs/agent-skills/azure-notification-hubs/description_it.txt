Conoscenza approfondita dello sviluppo di Hub di notifica di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica. Da usare durante l'integrazione di APNS/FCM/WNS, la configurazione dei crediti PNS, l'uso di REST/SDK, collegamento privato o push pianificati e altre attività di sviluppo correlate a Hub di notifica di Azure. Non per Hub eventi di Azure (usare azure-event-hubs), Bus di servizio di Azure (usare azure-service-bus), PubSub Web di Azure (usare azure-web-pubsub), Servizio Azure SignalR (usare azure-signalr-service).
