Экспертные знания для разработки Центров уведомлений Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при интеграции APNS/FCM/WNS, настройке учетных данных PNS, использовании REST/SDK, Private Link или запланированных push-уведомлений, а также других задачах разработки, связанных с Центрами уведомлений Azure. Не для концентраторов событий Azure (используйте azure-event-hubs), служебной шины Azure (используйте azure-service-bus), Azure Web PubSub (используйте azure-web-pubsub), службы Azure SignalR (используйте azure-signalr-service).
