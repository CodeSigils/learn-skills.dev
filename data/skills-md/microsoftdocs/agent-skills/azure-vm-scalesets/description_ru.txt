Экспертные знания для разработки масштабируемых наборов виртуальных машин Azure, включая устранение неполадок, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке автоматического масштабирования VMSS, режимов обновления, зон/PPG, спотовых/резервных пулов или шифрования диска с помощью Key Vault, а также других задач разработки, связанных с масштабируемыми наборами виртуальных машин Azure. Не для виртуальных машин Azure (используйте azure-virtual-machines), Службы Azure Kubernetes (AKS) (используйте azure-kubernetes-service), Службы приложений Azure (используйте azure-app-service), Azure Service Fabric (используйте azure-service-fabric).
