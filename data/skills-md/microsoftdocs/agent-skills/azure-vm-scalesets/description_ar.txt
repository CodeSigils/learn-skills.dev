معرفة الخبراء بتطوير مجموعات مقياس Azure Virtual Machine، بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين المقياس التلقائي لـ VMSS، أو أوضاع الترقية، أو المناطق/PPGs، أو تجمعات Spot/الاستعداد، أو تشفير القرص باستخدام Key Vault، ومهام التطوير الأخرى ذات الصلة بـ Azure Virtual Machine Scale Sets. ليس لأجهزة Azure الافتراضية (استخدم أجهزة azure الافتراضية)، وخدمة Azure Kubernetes (AKS) (استخدم خدمة azure-kubernetes)، وخدمة Azure App (استخدم خدمة تطبيق azure)، ونسيج خدمة Azure (استخدم نسيج خدمة azure).
