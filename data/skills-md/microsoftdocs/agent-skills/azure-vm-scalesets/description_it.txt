Conoscenza approfondita dello sviluppo di set di scalabilità di macchine virtuali di Azure, tra cui risoluzione dei problemi, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare durante la configurazione della scalabilità automatica VMSS, delle modalità di aggiornamento, delle zone/PPG, dei pool Spot/standby o della crittografia del disco con Key Vault e altre attività di sviluppo correlate ai set di scalabilità di macchine virtuali di Azure. Non per macchine virtuali di Azure (usare azure-virtual-machines), servizio Azure Kubernetes (AKS) (usare azure-kubernetes-service), Servizio app di Azure (usare azure-app-service), Azure Service Fabric (usare azure-service-fabric).
