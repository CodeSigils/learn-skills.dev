Expertenwissen für die Entwicklung von Azure Virtual Machine Scale Sets, einschließlich Fehlerbehebung, Entscheidungsfindung, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird zum Konfigurieren von VMSS-Autoskalierung, Upgrademodi, Zonen/PPGs, Spot-/Standby-Pools oder Datenträgerverschlüsselung mit Key Vault und anderen Entwicklungsaufgaben im Zusammenhang mit Azure Virtual Machine Scale Sets verwendet. Nicht für Azure Virtual Machines (verwenden Sie azure-virtual-machines), Azure Kubernetes Service (AKS) (verwenden Sie azure-kubernetes-service), Azure App Service (verwenden Sie azure-app-service), Azure Service Fabric (verwenden Sie azure-service-fabric).
