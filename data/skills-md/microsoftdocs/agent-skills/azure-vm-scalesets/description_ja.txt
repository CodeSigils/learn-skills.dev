トラブルシューティング、意思決定、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターン、デプロイなど、Azure Virtual Machine Scale Sets 開発に関する専門知識。 VMSS 自動スケール、アップグレード モード、ゾーン/PPG、スポット/スタンバイ プール、または Key Vault を使用したディスク暗号化、およびその他の Azure Virtual Machine Scale Sets 関連の開発タスクを構成するときに使用します。 Azure Virtual Machines (azure-virtual-machines を使用)、Azure Kubernetes Service (AKS) (azure-kubernetes-service を使用)、Azure App Service (azure-app-service を使用)、Azure Service Fabric (azure-service-fabric を使用) には適用されません。
