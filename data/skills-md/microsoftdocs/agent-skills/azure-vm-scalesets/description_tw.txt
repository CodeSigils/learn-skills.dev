Azure 虛擬機器規模集開發的專業知識，包括故障排除、決策、架構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在設定 VMSS 自動縮放、升級模式、區域/PPG、現貨/備用池或使用 Key Vault 進行磁碟加密以及其他 Azure 虛擬機器規模集相關開發任務時使用。不適用於 Azure 虛擬機器（使用 azure-virtual-machines）、Azure Kubernetes 服務 (AKS)（使用 azure-kubernetes-service）、Azure 應用程式服務（使用 azure-app-service）、Azure Service Fabric（使用 azure-service-fabric）。
