معرفة الخبراء بتطوير Azure Service Health بما في ذلك استكشاف الأخطاء وإصلاحها والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند دمج واجهات برمجة التطبيقات/خطافات الويب الخاصة بـ Service Health، أو تكوين التنبيهات عبر ARM/Bicep، أو الاستعلام عن الأحداث باستخدام Resource Graph، أو إدارة الوصول إلى RBAC، أو تشخيص مشكلات VM Resource Health، ومهام التطوير الأخرى ذات الصلة بـ Azure Service Health. ليس لـ Azure Monitor (استخدم azure-monitor)، وموثوقية Azure (استخدم موثوقية azure)، ومرونة Azure (استخدم مرونة azure)، وحصص Azure (استخدم حصص azure).
