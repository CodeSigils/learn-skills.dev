Экспертные знания для разработки работоспособности служб Azure, включая устранение неполадок, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при интеграции API/веб-перехватчиков Service Health, настройке оповещений через ARM/Bicep, запросе событий с помощью Resource Graph, управлении доступом RBAC или диагностике проблем работоспособности ресурсов виртуальной машины, а также других задачах разработки, связанных с работоспособностью служб Azure. Не для Azure Monitor (используйте azure-monitor), Azure Reliability (используйте azure-reliability), Azure Resiliency (используйте azure-resiliency), Azure Quotas (используйте azure-quotas).
