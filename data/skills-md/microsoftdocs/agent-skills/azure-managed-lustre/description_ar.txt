معرفة الخبراء بتطوير Azure Managed Luster بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند تثبيت AMLFS، أو التكامل مع الاستيراد/التصدير التلقائي لـ Blob، أو استخدام AKS CSI، أو إعداد CMK/root قرع، أو ضبط الأداء، ومهام التطوير الأخرى ذات الصلة بـ Azure Managed Luster. ليس لـ Azure HPC Cache (استخدم azure-hpc-cache)، وملفات Azure NetApp (استخدم ملفات azure-netapp)، وAzure Blob Storage (استخدم azure-blob-storage)، وAzure Elastic SAN (استخدم azure-elastic-san).
