Экспертные знания для разработки Azure Managed Lustre, включая устранение неполадок, лучшие практики, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, а также интеграцию и шаблоны кодирования. Используйте при подключении AMLFS, интеграции с автоматическим импортом/экспортом BLOB-объектов, использовании AKS CSI, настройке CMK/корневого сжатия или настройке производительности, а также других задачах разработки, связанных с Azure Managed Lustre. Не для кэша Azure HPC (используйте azure-hpc-cache), файлов Azure NetApp (используйте azure-netapp-files), хранилища BLOB-объектов Azure (используйте azure-blob-storage), Azure Elastic SAN (используйте azure-elastic-san).
