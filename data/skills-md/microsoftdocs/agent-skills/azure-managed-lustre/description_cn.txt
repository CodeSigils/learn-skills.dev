Azure 托管 Lustre 开发的专业知识，包括故障排除、最佳实践、体系结构和设计模式、限制和配额、安全性、配置以及集成和编码模式。在安装 AMLFS、与 Blob 自动导入/导出集成、使用 AKS CSI、设置 CMK/root 压缩或调整性能以及其他 Azure 托管 Lustre 相关开发任务时使用。不适用于 Azure HPC 缓存（使用 azure-hpc-cache）、Azure NetApp 文件（使用 azure-netapp-files）、Azure Blob 存储（使用 azure-blob-storage）、Azure Elastic SAN（使用 azure-elastic-san）。
