Conoscenza approfondita dello sviluppo di Azure Managed Lustre, tra cui risoluzione dei problemi, procedure consigliate, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica. Da usare durante il montaggio di AMLFS, l'integrazione con l'importazione/esportazione automatica dei BLOB, l'uso di AKS CSI, l'impostazione di CMK/root squash o l'ottimizzazione delle prestazioni e altre attività di sviluppo correlate ad Azure Managed Lustre. Non per cache HPC di Azure (usare azure-hpc-cache), Azure NetApp Files (usare azure-netapp-files), Archiviazione BLOB di Azure (usare azure-blob-storage), Azure Elastic SAN (usare azure-elastic-san).
