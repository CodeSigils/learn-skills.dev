トラブルシューティング、ベスト プラクティス、アーキテクチャと設計パターン、制限とクォータ、セキュリティ、構成、統合とコーディング パターンなど、Azure Managed Lustre 開発に関する専門知識。 AMLFS のマウント、Blob 自動インポート/エクスポートとの統合、AKS CSI の使用、CMK/ルート スカッシュの設定、パフォーマンスの調整、およびその他の Azure Managed Luster 関連の開発タスクを行うときに使用します。 Azure HPC Cache (azure-hpc-cache を使用)、Azure NetApp Files (azure-netapp-files を使用)、Azure Blob Storage (azure-blob-storage を使用)、Azure Elastic SAN (azure-elastic-san を使用) には適用されません。
