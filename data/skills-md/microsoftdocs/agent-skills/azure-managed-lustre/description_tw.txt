Azure 託管 Lustre 開發的專業知識，包括故障排除、最佳實踐、體系結構和設計模式、限制和配額、安全性、配置以及整合和編碼模式。在安裝 AMLFS、與 Blob 自動匯入/匯出整合、使用 AKS CSI、設定 CMK/root 壓縮或調整效能以及其他 Azure 託管 Lustre 相關開發任務時使用。不適用於 Azure HPC 快取（使用 azure-hpc-cache）、Azure NetApp 檔案（使用 azure-netapp-files）、Azure Blob 儲存（使用 azure-blob-storage）、Azure Elastic SAN（使用 azure-elastic-san）。
