Conoscenza approfondita dello sviluppo di HSM per i pagamenti di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, sicurezza e configurazione. Da utilizzare durante la configurazione di reti virtuali/FastPath HSM di pagamento, accesso a PayShield Manager, topologie HA/DR, SKU o ispezione del traffico e altre attività di sviluppo correlate a HSM di pagamento di Azure. Non per HSM dedicato di Azure (usare azure-dedicated-hsm), Azure Cloud Hsm (usare azure-cloud-hsm), Azure Key Vault (usare azure-key-vault), Azure Information Protection (usare azure-information-protection).
