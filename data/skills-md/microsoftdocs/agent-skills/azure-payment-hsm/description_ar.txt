معرفة الخبراء بتطوير Azure Payment Hsm بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والأمان والتكوين. يُستخدم عند تكوين Payment HSM VNets/FastPath، أو الوصول إلى payShield Manager، أو طبولوجيا HA/DR، أو وحدات SKU، أو فحص حركة المرور، ومهام التطوير الأخرى ذات الصلة بـ Azure Payment Hsm. ليس لـ Azure Dedicated HSM (استخدم azure-dedicated-hsm)، وAzure Cloud Hsm (استخدم azure-cloud-hsm)، وAzure Key Vault (استخدم azure-key-vault)، وحماية معلومات Azure (استخدم حماية معلومات azure).
