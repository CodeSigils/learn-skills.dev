Экспертные знания для разработки Azure Payment Hsm, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, безопасность и настройку. Используйте при настройке виртуальных сетей/FastPath Payment HSM, доступа к payShield Manager, топологий HA/DR, номеров SKU или проверки трафика, а также других задач разработки, связанных с Azure Payment Hsm. Не для Azure Dedicated HSM (используйте azure-dedicated-hsm), Azure Cloud Hsm (используйте azure-cloud-hsm), Azure Key Vault (используйте azure-key-vault), Azure Information Protection (используйте azure-information-protection).
