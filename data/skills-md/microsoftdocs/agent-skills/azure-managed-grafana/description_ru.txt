Экспертные знания для разработки Azure Managed Grafana, включая устранение неполадок, принятие решений, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при интеграции Azure Monitor/Prometheus, настройке источников данных/предупреждений, аутентификации Entra, частных конечных точек или рабочих областей высокой доступности, а также других задач разработки, связанных с управляемым Azure Grafana. Не для Azure Monitor (используйте azure-monitor), Шлюза приложений Azure (используйте azure-application-gateway), виртуальных машин Azure (используйте azure-virtual-machines), Службы Azure Kubernetes (AKS) (используйте azure-kubernetes-service).
