معرفة الخبراء بتطوير Azure Managed Grafana بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند دمج Azure Monitor/Prometheus، أو تكوين مصادر/تنبيهات البيانات، أو مصادقة Entra، أو نقاط النهاية الخاصة، أو مساحات عمل HA، ومهام التطوير الأخرى ذات الصلة بـ Azure Managed Grafana. ليس لـ Azure Monitor (استخدم azure-monitor)، وبوابة تطبيق Azure (استخدم بوابة تطبيق azure)، وأجهزة Azure الافتراضية (استخدم أجهزة azure الافتراضية)، وخدمة Azure Kubernetes (AKS) (استخدم خدمة azure-kubernetes).
