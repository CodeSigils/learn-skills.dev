Azure 托管 Grafana 开发的专业知识，包括故障排除、决策、限制和配额、安全性、配置、集成和编码模式以及部署。在集成 Azure Monitor/Prometheus、配置数据源/警报、Entra auth、专用终结点或 HA 工作区以及其他 Azure 托管 Grafana 相关开发任务时使用。不适用于 Azure Monitor（使用 azure-monitor）、Azure 应用程序网关（使用 azure-application-gateway）、Azure 虚拟机（使用 azure-virtual-machines）、Azure Kubernetes 服务 (AKS)（使用 azure-kubernetes-service）。
