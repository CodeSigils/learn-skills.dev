Connaissance experte du développement Azure Managed Grafana, y compris le dépannage, la prise de décision, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'intégration d'Azure Monitor/Prometheus, de la configuration des sources de données/alertes, de l'authentification Entra, des points de terminaison privés ou des espaces de travail HA, ainsi que d'autres tâches de développement liées à Azure Managed Grafana. Pas pour Azure Monitor (utilisez azure-monitor), Azure Application Gateway (utilisez azure-application-gateway), Azure Virtual Machines (utilisez azure-virtual-machines), Azure Kubernetes Service (AKS) (utilisez azure-kubernetes-service).
