Azure 託管 Grafana 開發的專業知識，包括故障排除、決策、限制和配額、安全性、配置、整合和編碼模式以及部署。在整合 Azure Monitor/Prometheus、設定資料來源/警報、Entra auth、專用終端或 HA 工作區以及其他 Azure 託管 Grafana 相關開發任務時使用。不適用於 Azure Monitor（使用 azure-monitor）、Azure 應用程式閘道（使用 azure-application-gateway）、Azure 虛擬機器（使用 azure-virtual-machines）、Azure Kubernetes 服務 (AKS)（使用 azure-kubernetes-service）。
