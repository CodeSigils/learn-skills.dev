Expertenwissen für die Azure Managed Grafana-Entwicklung, einschließlich Fehlerbehebung, Entscheidungsfindung, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Zur Verwendung bei der Integration von Azure Monitor/Prometheus, der Konfiguration von Datenquellen/Warnungen, der Entra-Authentifizierung, privaten Endpunkten oder HA-Arbeitsbereichen und anderen Azure Managed Grafana-bezogenen Entwicklungsaufgaben. Nicht für Azure Monitor (verwenden Sie azure-monitor), Azure Application Gateway (verwenden Sie azure-application-gateway), Azure Virtual Machines (verwenden Sie azure-virtual-machines), Azure Kubernetes Service (AKS) (verwenden Sie azure-kubernetes-service).
