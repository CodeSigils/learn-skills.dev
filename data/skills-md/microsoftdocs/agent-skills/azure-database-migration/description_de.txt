Expertenwissen für die Entwicklung von Azure Database Migration-Diensten, einschließlich Fehlerbehebung, Entscheidungsfindung, Grenzwerte und Kontingente, Sicherheit, Integrationen und Codierungsmuster sowie Bereitstellung. Verwenden Sie diese Option, wenn Sie Azure DMS-Migrationen für MySQL-, PostgreSQL-, SQL Server/SSIS-, SQL MI- oder MongoDB-Workloads und andere Entwicklungsaufgaben im Zusammenhang mit dem Azure Database Migration-Dienst planen. Nicht für Azure Migrate (verwenden Sie azure-migrate), Azure SQL-Datenbank (verwenden Sie azure-sql-database), Azure SQL Managed Instance (verwenden Sie azure-sql-managed-instance), SQL Server auf Azure Virtual Machines (verwenden Sie azure-sql-virtual-machines).
