문제 해결, 의사 결정, 한도 및 할당량, 보안, 통합 및 코딩 패턴, 배포를 포함한 Azure Database Migration 서비스 개발에 대한 전문 지식입니다. MySQL, PostgreSQL, SQL Server/SSIS, SQL MI 또는 MongoDB 워크로드 및 기타 Azure Database Migration 서비스 관련 개발 작업을 위한 Azure DMS 마이그레이션을 계획할 때 사용합니다. Azure Migrate(azure- migration 사용), Azure SQL Database(azure-sql-database 사용), Azure SQL Managed Instance(azure-sql-managed-instance 사용), Azure Virtual Machines의 SQL Server(azure-sql-virtual-machines 사용)에는 해당되지 않습니다.
