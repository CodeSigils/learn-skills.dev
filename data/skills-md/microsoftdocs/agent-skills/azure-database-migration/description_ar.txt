معرفة الخبراء بتطوير خدمة Azure Database Migration بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار والحدود والحصص والأمان والتكامل وأنماط الترميز والنشر. يُستخدم عند التخطيط لعمليات ترحيل Azure DMS لأحمال عمل MySQL أو PostgreSQL أو SQL Server/SSIS أو SQL MI أو MongoDB ومهام التطوير الأخرى المتعلقة بخدمة Azure Database Migration. ليس لـ Azure Migrate (استخدم azure-migrate)، وقاعدة بيانات Azure SQL (استخدم قاعدة بيانات azure-sql)، ومثيل Azure SQL المُدار (استخدم مثيل azure-sql-managed)، وSQL Server على أجهزة Azure الظاهرية (استخدم الأجهزة الافتراضية azure-sql).
