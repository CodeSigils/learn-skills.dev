Azure 資料庫遷移服務開發的專業知識，包括故障排除、決策、限制和配額、安全性、整合和編碼模式以及部署。在規劃 MySQL、PostgreSQL、SQL Server/SSIS、SQL MI 或 MongoDB 工作負載的 Azure DMS 遷移以及其他 Azure 資料庫遷移服務相關開發任務時使用。不適用於 Azure Migrate（使用 azure-migrate）、Azure SQL 資料庫（使用 azure-sql-database）、Azure SQL 託管執行個體（使用 azure-sql-託管執行個體）、Azure 虛擬機器上的 SQL Server（使用 azure-sql-virtual-machines）。
