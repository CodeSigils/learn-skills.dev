Экспертные знания для разработки службы миграции баз данных Azure, включая устранение неполадок, принятие решений, ограничения и квоты, безопасность, интеграцию и шаблоны кодирования, а также развертывание. Используйте при планировании миграции Azure DMS для рабочих нагрузок MySQL, PostgreSQL, SQL Server/SSIS, SQL MI или MongoDB, а также других задач разработки, связанных со службой миграции баз данных Azure. Не для Azure Migrate (используйте azure-migrate), Базы данных SQL Azure (используйте azure-sql-database), Управляемого экземпляра Azure SQL (используйте azure-sql-managed-instance), SQL Server на виртуальных машинах Azure (используйте azure-sql-virtual-machines).
