Conoscenza approfondita dello sviluppo del servizio Migrazione del database di Azure, tra cui risoluzione dei problemi, processo decisionale, limiti e quote, sicurezza, integrazioni e modelli di codifica e distribuzione. Da utilizzare quando si pianificano migrazioni di Azure DMS per carichi di lavoro MySQL, PostgreSQL, SQL Server/SSIS, SQL MI o MongoDB e altre attività di sviluppo correlate al servizio Migrazione del database di Azure. Non per Azure Migrate (usare azure-migrate), database SQL di Azure (usare azure-sql-database), Istanza gestita SQL di Azure (usare azure-sql- Managed-Instance), SQL Server in macchine virtuali di Azure (usare azure-sql-virtual-machines).
