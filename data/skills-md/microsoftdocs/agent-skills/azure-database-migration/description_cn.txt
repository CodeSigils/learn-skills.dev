Azure 数据库迁移服务开发的专业知识，包括故障排除、决策、限制和配额、安全性、集成和编码模式以及部署。在规划 MySQL、PostgreSQL、SQL Server/SSIS、SQL MI 或 MongoDB 工作负载的 Azure DMS 迁移以及其他 Azure 数据库迁移服务相关开发任务时使用。不适用于 Azure Migrate（使用 azure-migrate）、Azure SQL 数据库（使用 azure-sql-database）、Azure SQL 托管实例（使用 azure-sql-托管实例）、Azure 虚拟机上的 SQL Server（使用 azure-sql-virtual-machines）。
