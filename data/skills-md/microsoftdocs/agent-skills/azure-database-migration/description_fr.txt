Connaissance approfondie du développement du service Azure Database Migration, y compris le dépannage, la prise de décision, les limites et quotas, la sécurité, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la planification des migrations Azure DMS pour les charges de travail MySQL, PostgreSQL, SQL Server/SSIS, SQL MI ou MongoDB, ainsi que d'autres tâches de développement liées au service Azure Database Migration. Pas pour Azure Migrate (utilisez azure-migrate), Azure SQL Database (utilisez azure-sql-database), Azure SQL Managed Instance (utilisez azure-sql-managed-instance), SQL Server sur les machines virtuelles Azure (utilisez azure-sql-virtual-machines).
