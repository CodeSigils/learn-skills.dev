Экспертные знания для разработки виртуальных рабочих столов Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при работе с профилями FSLogix, MSIX/App Attach, автомасштабированием/запуском виртуальной машины при подключении, оптимизацией Teams или SSO/MFA, а также другими задачами разработки, связанными с виртуальным рабочим столом Azure. Не для виртуальных машин Azure (используйте azure-virtual-machines), Azure Dev Box (используйте azure-dev-box).
