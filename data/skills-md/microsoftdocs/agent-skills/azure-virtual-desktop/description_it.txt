Conoscenza approfondita dello sviluppo di desktop virtuali di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare quando si lavora con profili FSLogix, MSIX/App attach, scalabilità automatica/avvio VM su Connect, ottimizzazione di Teams o SSO/MFA e altre attività di sviluppo correlate al desktop virtuale di Azure. Non per macchine virtuali di Azure (usare azure-virtual-machines), Azure Dev Box (usare azure-dev-box).
