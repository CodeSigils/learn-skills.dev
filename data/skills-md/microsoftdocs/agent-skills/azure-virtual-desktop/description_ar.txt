معرفة الخبراء بتطوير Azure Virtual Desktop بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند العمل مع ملفات تعريف FSLogix، أو MSIX/App Attach، أو القياس التلقائي/بدء VM عند الاتصال، أو تحسين الفرق، أو SSO/MFA، ومهام التطوير الأخرى ذات الصلة بـ Azure Virtual Desktop. ليس لأجهزة Azure الافتراضية (استخدم الأجهزة الافتراضية azure)، وAzure Dev Box (استخدم azure-dev-box).
