Экспертные знания для разработки Azure Virtual Network Manager, включая устранение неполадок, ограничения и квоты, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при управлении пулами AVNM IPAM, сетевыми группами, межклиентскими подключениями, правилами администратора безопасности или запросами ARG, а также другими задачами разработки, связанными с Azure Virtual Network Manager. Не для виртуальной сети Azure (используйте azure-virtual-network), виртуальной глобальной сети Azure (используйте azure-virtual-wan), Azure Network Watcher (используйте azure-network-watcher), сети Azure (используйте azure-networking).
