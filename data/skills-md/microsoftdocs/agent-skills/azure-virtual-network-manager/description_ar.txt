معرفة الخبراء بتطوير Azure Virtual Network Manager بما في ذلك استكشاف الأخطاء وإصلاحها والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند إدارة مجموعات AVNM IPAM، أو مجموعات الشبكات، أو الاتصال بين المستأجرين، أو قواعد إدارة الأمان، أو استعلامات ARG، ومهام التطوير الأخرى ذات الصلة بـ Azure Virtual Network Manager. ليس لشبكة Azure الافتراضية (استخدم azure-virtual-network)، وAzure Virtual WAN (استخدم azure-virtual-wan)، وAzure Network Watcher (استخدم azure-network-watcher)، وAzure Networking (استخدم شبكة azure).
