Expertenwissen für die Entwicklung von Azure Virtual Network Manager, einschließlich Fehlerbehebung, Grenzwerte und Kontingente, Sicherheit, Konfiguration sowie Integrationen und Codierungsmuster. Wird zum Verwalten von AVNM-IPAM-Pools, Netzwerkgruppen, mandantenübergreifender Konnektivität, Sicherheitsadministratorregeln oder ARG-Abfragen und anderen Entwicklungsaufgaben im Zusammenhang mit Azure Virtual Network Manager verwendet. Nicht für Azure Virtual Network (verwenden Sie azure-virtual-network), Azure Virtual WAN (verwenden Sie azure-virtual-wan), Azure Network Watcher (verwenden Sie azure-network-watcher), Azure Networking (verwenden Sie azure-networking).
