Conoscenza approfondita dello sviluppo di Azure Virtual Network Manager, tra cui risoluzione dei problemi, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare durante la gestione di pool IPAM AVNM, gruppi di rete, connettività tra tenant, regole di amministrazione della sicurezza o query ARG e altre attività di sviluppo correlate a Gestione rete virtuale di Azure. Non per Rete virtuale di Azure (usare azure-virtual-network), WAN virtuale di Azure (usare azure-virtual-wan), Controllo rete di Azure (usare azure-network-watcher), Rete di Azure (usare azure-networking).
