トラブルシューティング、制限とクォータ、セキュリティ、構成、統合とコーディング パターンなど、Azure Virtual Network Manager 開発に関する専門知識。 AVNM IPAM プール、ネットワーク グループ、テナント間接続、セキュリティ管理ルール、ARG クエリ、およびその他の Azure Virtual Network Manager 関連の開発タスクを管理する場合に使用します。 Azure Virtual Network (azure-virtual-network を使用)、Azure Virtual WAN (azure-virtual-wan を使用)、Azure Network Watcher (azure-network-watcher を使用)、Azure Networking (azure-networking) には使用できません。
