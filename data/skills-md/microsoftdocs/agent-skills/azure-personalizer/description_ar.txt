معرفة الخبراء بتطوير Azure AI Personalizer بما في ذلك استكشاف الأخطاء وإصلاحها واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند ضبط وضع الاستكشاف/المتدرب، أو المكالمات الفردية مقابل متعددة الفتحات، أو تصدير النموذج، أو الحصص، أو SDK للاستدلال المحلي، ومهام التطوير الأخرى ذات الصلة بـ Azure AI Personalizer. ليس لخدمات Azure AI (استخدم أدوات microsoft Foundry)، وAzure AI Search (استخدم البحث المعرفي azure)، وAzure AI Metrics Advisor (استخدم azure-metrics-advisor)، وAzure AI Anomaly Detector (استخدم كاشف الشذوذ azure).
