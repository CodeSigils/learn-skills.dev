Экспертные знания для разработки Azure AI Personalizer, включая устранение неполадок, принятие решений, ограничения и квоты, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при настройке режима исследования/ученика, вызовов с одним или несколькими слотами, экспорта модели, квот или SDK локального вывода, а также других задач разработки, связанных с Azure AI Personalizer. Не для служб ИИ Azure (используйте инструменты Microsoft-foundry), Поиска ИИ Azure (используйте azure-cognitive-search), Советника по метрикам Azure AI (используйте azure-metrics-advisor), Детектора аномалий ИИ Azure (используйте azure-anomaly-detector).
