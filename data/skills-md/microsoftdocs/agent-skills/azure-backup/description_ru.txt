Экспертные знания для разработки Azure Backup, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при защите виртуальных машин Azure, SQL/SAP HANA, файлов/блобов, рабочих нагрузок MABS/DPM или написания сценариев через CLI/PowerShell/REST, а также других задач разработки, связанных с Azure Backup. Не для Azure Site Recovery (используйте azure-site-recovery).
