معرفة الخبراء لتطوير Azure Backup بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند حماية أجهزة Azure VMs، أو SQL/SAP HANA، أو الملفات/النقط الكبيرة، أو أحمال عمل MABS/DPM، أو البرمجة النصية عبر CLI/PowerShell/REST، ومهام التطوير الأخرى ذات الصلة بـ Azure Backup. ليس مخصصًا لـ Azure Site Recovery (استخدم azure-site-recovery).
