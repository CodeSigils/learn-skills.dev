Экспертные знания для разработки Azure Data Explorer, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке аутентификации/сети ADX, управлении ограничениями кластера, интеграции через SQL/ODBC/функции или проектировании аварийного восстановления/BC и других задачах разработки, связанных с Azure Data Explorer. Не для Azure Synapse Analytics (используйте azure-synapse-analytics), Azure Stream Analytics (используйте azure-stream-analytics), Azure HDInsight (используйте azure-hdinsight), Azure Databricks (используйте azure-databricks).
