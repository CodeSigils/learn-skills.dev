Conoscenza approfondita dello sviluppo di Esplora dati di Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare durante la configurazione di autenticazione/rete ADX, la gestione dei limiti del cluster, l'integrazione tramite SQL/ODBC/funzioni o la progettazione di DR/BC e altre attività di sviluppo correlate ad Esplora dati di Azure. Non per Azure Synapse Analytics (usare azure-synapse-analytics), Analisi di flusso di Azure (usare azure-stream-analytics), Azure HDInsight (usare azure-hdinsight), Azure Databricks (usare azure-databricks).
