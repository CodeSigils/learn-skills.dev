Connaissance approfondie du développement d'Azure Data Explorer, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la configuration de l'authentification/de la mise en réseau ADX, de la gestion des limites de cluster, de l'intégration via SQL/ODBC/Functions ou de la conception de DR/BC et d'autres tâches de développement liées à Azure Data Explorer. Pas pour Azure Synapse Analytics (utilisez azure-synapse-analytics), Azure Stream Analytics (utilisez azure-stream-analytics), Azure HDInsight (utilisez azure-hdinsight), Azure Databricks (utilisez azure-databricks).
