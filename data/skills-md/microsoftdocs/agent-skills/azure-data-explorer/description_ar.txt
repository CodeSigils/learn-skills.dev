معرفة الخبراء بتطوير Azure Data Explorer بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين مصادقة/شبكة ADX، أو إدارة حدود المجموعة، أو التكامل عبر SQL/ODBC/الوظائف، أو تصميم DR/BC، ومهام التطوير الأخرى ذات الصلة بـ Azure Data Explorer. ليس من أجل Azure Synapse Analytics (استخدم azure-synapse-analytics)، وAzure Stream Analytics (استخدم azure-stream-analytics)، وAzure HDInsight (استخدم azure-hdinsight)، وAzure Databricks (استخدم azure-databricks).
