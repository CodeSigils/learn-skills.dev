Экспертные знания для разработки Azure Repos, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, а также интеграцию и шаблоны кодирования. Используйте при управлении репозиториями Git/TFVC, политиками филиалов/PR, разрешениями, сканированиями CodeQL/секретов или расширенной безопасностью GitHub, а также другими задачами разработки, связанными с репозиториями Azure. Не для Azure DevOps (используйте azure-devops), Azure Pipelines (используйте azure-pipelines), планов тестирования Azure (используйте azure-test-plans), Azure Boards (используйте azure-boards).
