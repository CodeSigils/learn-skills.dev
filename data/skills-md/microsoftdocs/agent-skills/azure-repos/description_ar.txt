معرفة الخبراء لتطوير Azure Repos بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند إدارة مستودعات Git/TFVC، أو سياسات الفرع/العلاقات العامة، أو الأذونات، أو عمليات فحص CodeQL/السرية، أو GitHub Advanced Security، ومهام التطوير الأخرى ذات الصلة بـ Azure Repos. ليس لـ Azure DevOps (استخدم azure-devops)، وخطوط أنابيب Azure (استخدم خطوط أنابيب azure)، وخطط اختبار Azure (استخدم خطط اختبار azure)، ولوحات Azure (استخدم لوحات azure).
