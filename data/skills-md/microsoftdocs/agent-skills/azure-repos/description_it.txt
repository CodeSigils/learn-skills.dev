Conoscenza approfondita dello sviluppo di Azure Repos, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare durante la gestione di repository Git/TFVC, criteri di ramo/PR, autorizzazioni, scansioni CodeQL/segreti o GitHub Advanced Security e altre attività di sviluppo correlate a Azure Repos. Non per Azure DevOps (usare azure-devops), Azure Pipelines (usare azure-pipelines), Azure Test Plans (usare azure-test-plans), Azure Boards (usare azure-boards).
