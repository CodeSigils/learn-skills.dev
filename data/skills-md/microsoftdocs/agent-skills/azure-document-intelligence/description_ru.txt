Экспертные знания для разработки Azure AI Document Intelligence, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании API-интерфейсов AnalyDocument/Markdown, пользовательских моделей, контейнеров/Docker, SAS/управляемых удостоверений или виртуальных сетей, а также других задач разработки, связанных с Azure AI Document Intelligence. Не для служб ИИ Azure (используйте инструменты Microsoft-foundry), Поиска ИИ Azure (используйте azure-cognitive-search), Языка ИИ Azure (используйте azure-language-service), Иммерсивного средства чтения Azure AI (используйте azure-immersive-reader).
