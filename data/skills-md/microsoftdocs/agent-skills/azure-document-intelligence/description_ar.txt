معرفة الخبراء بتطوير Azure AI Document Intelligence بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام AnalyzeDocument/Markdown APIs أو النماذج المخصصة أو الحاويات/Docker أو SAS/الهوية المُدارة أو VNets ومهام التطوير الأخرى ذات الصلة بـ Azure AI Document Intelligence. ليس لخدمات Azure AI (استخدم أدوات microsoft Foundry)، وAzure AI Search (استخدم البحث المعرفي azure)، ولغة Azure AI (استخدم خدمة اللغة azure)، وAzure AI Immersive Reader (استخدم القارئ الشامل azure).
