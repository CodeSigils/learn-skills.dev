معرفة الخبراء لتطوير Azure Artifacts بما في ذلك أفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إدارة الموجزات، والمصادر الأولية، ونشر/استعادة الحزم، أو CI/CD لـ GitHub Actions، أو npm/NuGet config، ومهام التطوير الأخرى ذات الصلة بـ Azure Artifacts. ليس لـ Azure DevOps (استخدم azure-devops)، وAzure Pipelines (استخدم خطوط الأنابيب azure)، وAzure Repos (استخدم azure-repos)، ولوحات Azure (استخدم اللوحات اللازوردية).
