Connaissance approfondie du développement d'Azure Artifacts, y compris les meilleures pratiques, la prise de décision, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la gestion des flux, des sources en amont, de la publication/restauration de packages, de la configuration GitHub Actions CI/CD ou npm/NuGet et d'autres tâches de développement liées à Azure Artifacts. Pas pour Azure DevOps (utilisez azure-devops), Azure Pipelines (utilisez azure-pipelines), Azure Repos (utilisez azure-repos), Azure Boards (utilisez azure-boards).
