Conoscenza approfondita dello sviluppo di Azure Artifacts, tra cui best practice, processo decisionale, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la gestione di feed, origini upstream, pubblicazione/ripristino di pacchetti, CI/CD di GitHub Actions o configurazione npm/NuGet e altre attività di sviluppo correlate ad Azure Artifacts. Non per Azure DevOps (usare azure-devops), Azure Pipelines (usare azure-pipelines), Azure Repos (usare azure-repos), Azure Boards (usare azure-boards).
