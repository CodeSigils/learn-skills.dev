Экспертные знания для разработки Azure Artifacts, включая лучшие практики, принятие решений, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при управлении каналами, исходными источниками, публикации и восстановления пакетов, GitHub Actions CI/CD или конфигурации npm/NuGet, а также других задач разработки, связанных с Azure Artifacts. Не для Azure DevOps (используйте azure-devops), Azure Pipelines (используйте azure-pipelines), Azure Repos (используйте azure-repos), Azure Boards (используйте azure-boards).
