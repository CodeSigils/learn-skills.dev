Connaissance approfondie du développement d'environnements de déploiement Azure, y compris le dépannage, les meilleures pratiques, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la conception de catalogues ADE, de schémas Environment.yaml, d'images personnalisées, de pipelines RBAC/rôles ou d'images CI/CD, ainsi que d'autres tâches de développement liées aux environnements de déploiement Azure. Pas pour Azure DevTest Labs (utilisez azure-devtest-labs), Azure Dev Box (utilisez azure-dev-box), Azure Integration Environments (utilisez azure-integration-environments), Azure Managed Applications (utilisez azure-managed-applications).
