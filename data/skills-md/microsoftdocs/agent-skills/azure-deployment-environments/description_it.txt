Conoscenza approfondita dello sviluppo di ambienti di distribuzione di Azure, tra cui risoluzione dei problemi, procedure consigliate, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la progettazione di cataloghi ADE, schemi Environment.yaml, immagini personalizzate, ruoli/RBAC o pipeline di immagini CI/CD e altre attività di sviluppo correlate agli ambienti di distribuzione di Azure. Non per Azure DevTest Labs (usare azure-devtest-labs), Azure Dev Box (usare azure-dev-box), Ambienti di integrazione di Azure (usare azure-integration-environments), Applicazioni gestite di Azure (usare azure-built-applications).
