Экспертные знания по разработке сред развертывания Azure, включая устранение неполадок, рекомендации, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при проектировании каталогов ADE, схем Environment.yaml, пользовательских образов, конвейеров образов RBAC/ролей или CI/CD, а также других задач разработки, связанных со средами развертывания Azure. Не для Azure DevTest Labs (используйте azure-devtest-labs), Azure Dev Box (используйте azure-dev-box), сред интеграции Azure (используйте azure-integration-environments), управляемых приложений Azure (используйте azure-managed-applications).
