معرفة الخبراء بتطوير بيئات نشر Azure بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تصميم كتالوجات ADE، ومخططات Environment.yaml، والصور المخصصة، وأدوار RBAC، أو خطوط أنابيب صور CI/CD، ومهام التطوير الأخرى ذات الصلة ببيئات نشر Azure. ليس لـ Azure DevTest Labs (استخدم azure-devtest-labs)، وAzure Dev Box (استخدم azure-dev-box)، وبيئات تكامل Azure (استخدم بيئات تكامل azure)، والتطبيقات المُدارة من Azure (استخدم التطبيقات المُدارة من azure).
