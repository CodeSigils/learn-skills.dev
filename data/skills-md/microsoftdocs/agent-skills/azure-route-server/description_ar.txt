معرفة الخبراء بتطوير Azure Route Server بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين. يُستخدم عند تصميم طبولوجيا محورية أو متعددة المناطق، أو نظير BGP مع NVAs/on-prem، أو ضبط سياسات التوجيه، أو إصلاح مشكلات نشر المسار، ومهام التطوير الأخرى ذات الصلة بـ Azure Route Server. ليس لشبكة Azure الافتراضية (استخدم azure-virtual-network)، وAzure Virtual Network Manager (استخدم azure-virtual-network-manager)، وAzure Virtual WAN (استخدم azure-virtual-wan)، وبوابة Azure VPN (استخدم بوابة azure-vpn).
