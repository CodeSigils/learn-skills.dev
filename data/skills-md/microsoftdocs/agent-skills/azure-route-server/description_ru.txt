Экспертные знания для разработки Azure Route Server, включая устранение неполадок, лучшие практики, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность и настройку. Используйте при разработке узловых или многорегиональных топологий, пиринге BGP с NVA/локальными устройствами, настройке политик маршрутизации или устранении проблем с распространением маршрутов, а также других задачах разработки, связанных с Azure Route Server. Не для виртуальной сети Azure (используйте azure-virtual-network), диспетчера виртуальной сети Azure (используйте azure-virtual-network-manager), виртуальной глобальной сети Azure (используйте azure-virtual-wan), VPN-шлюза Azure (используйте azure-vpn-gateway).
