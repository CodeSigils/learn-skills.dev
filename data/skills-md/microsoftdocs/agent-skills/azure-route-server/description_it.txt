Conoscenza approfondita dello sviluppo di Azure Route Server, tra cui risoluzione dei problemi, procedure consigliate, modelli di architettura e progettazione, limiti e quote, sicurezza e configurazione. Da utilizzare durante la progettazione di topologie hub-spoke o multi-area, peering BGP con NVA/on-prem, ottimizzazione dei criteri di routing o risoluzione di problemi di propagazione delle route e altre attività di sviluppo correlate al server di route di Azure. Non per la rete virtuale di Azure (usare azure-virtual-network), Gestione rete virtuale di Azure (usare azure-virtual-network-manager), WAN virtuale di Azure (usare azure-virtual-wan), Gateway VPN di Azure (usare azure-vpn-gateway).
