문제 해결, 모범 사례, 아키텍처 및 디자인 패턴, 제한 및 할당량, 보안 및 구성을 포함한 Azure Route Server 개발에 대한 전문 지식입니다. 허브-스포크 또는 다중 지역 토폴로지, NVA/온-프레미스와의 BGP 피어링, 라우팅 정책 조정, 경로 전파 문제 해결 및 기타 Azure Route Server 관련 개발 작업을 설계할 때 사용합니다.
