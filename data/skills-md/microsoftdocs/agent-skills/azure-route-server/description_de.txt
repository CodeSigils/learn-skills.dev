Expertenwissen für die Azure Route Server-Entwicklung, einschließlich Fehlerbehebung, Best Practices, Architektur- und Designmuster, Grenzwerte und Kontingente, Sicherheit und Konfiguration. Verwenden Sie diese Option beim Entwerfen von Hub-Spoke- oder Mehrregionen-Topologien, beim BGP-Peering mit NVAs/lokal, beim Optimieren von Routing-Richtlinien oder beim Beheben von Problemen bei der Routenweitergabe sowie bei anderen Entwicklungsaufgaben im Zusammenhang mit Azure Route Server. Nicht für Azure Virtual Network (verwenden Sie azure-virtual-network), Azure Virtual Network Manager (verwenden Sie azure-virtual-network-manager), Azure Virtual WAN (verwenden Sie azure-virtual-wan), Azure VPN Gateway (verwenden Sie azure-vpn-gateway).
