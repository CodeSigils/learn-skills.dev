Connaissance approfondie du développement d'Azure Route Server, y compris le dépannage, les meilleures pratiques, les modèles d'architecture et de conception, les limites et quotas, la sécurité et la configuration. À utiliser lors de la conception de topologies hub-spoke ou multirégions, du peering BGP avec des NVA/sur site, du réglage des stratégies de routage ou de la résolution des problèmes de propagation d'itinéraire, ainsi que d'autres tâches de développement liées à Azure Route Server. Pas pour Azure Virtual Network (utilisez azure-virtual-network), Azure Virtual Network Manager (utilisez azure-virtual-network-manager), Azure Virtual WAN (utilisez azure-virtual-wan), Azure VPN Gateway (utilisez azure-vpn-gateway).
