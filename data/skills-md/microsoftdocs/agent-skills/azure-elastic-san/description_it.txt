Conoscenza approfondita dello sviluppo di Azure Elastic SAN, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica. Da utilizzare durante lo scripting di volumi Elastic SAN, l'ottimizzazione di archivi dati AVS, l'uso della crittografia CMK, il dimensionamento per IOPS o l'esecuzione di SQL in cluster e altre attività di sviluppo correlate ad Azure Elastic SAN. Non per archiviazione BLOB di Azure (usare azure-blob-storage), File di Azure (usare azure-files), Azure NetApp Files (usare azure-netapp-files), Azure Managed Lustre (usare azure-owned-lustre).
