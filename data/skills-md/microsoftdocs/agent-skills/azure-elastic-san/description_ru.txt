Экспертные знания для разработки Azure Elastic SAN, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, а также шаблоны интеграции и кодирования. Используйте при написании сценариев для томов Elastic SAN, настройке хранилищ данных AVS, использовании шифрования CMK, определении размера операций ввода-вывода в секунду или запуске кластерного SQL, а также при выполнении других задач разработки, связанных с Azure Elastic SAN. Не для хранилища BLOB-объектов Azure (используйте azure-blob-storage), Azure Files (используйте azure-files), Azure NetApp Files (используйте azure-netapp-files), Azure Managed Lustre (используйте azure-managed-lustre).
