문제 해결, 모범 사례, 의사 결정, 아키텍처 및 디자인 패턴, 제한 및 할당량, 보안, 구성, 통합 및 코딩 패턴을 포함한 Azure Elastic SAN 개발에 대한 전문 지식입니다. Elastic SAN 볼륨 스크립팅, AVS 데이터 저장소 조정, CMK 암호화 사용, IOPS 크기 조정, 클러스터형 SQL 실행 및 기타 Azure Elastic SAN 관련 개발 작업에 사용합니다. Azure Blob Storage(azure-blob-storage 사용), Azure Files(azure-files 사용), Azure NetApp Files(azure-netapp-files 사용), Azure Managed Lustre(azure-managed-lustre 사용)에는 해당되지 않습니다.
