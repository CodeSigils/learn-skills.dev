معرفة الخبراء بتطوير Azure Elastic SAN بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند برمجة وحدات تخزين SAN المرنة، أو ضبط مخازن بيانات AVS، أو استخدام تشفير CMK، أو تحديد حجم IOPS، أو تشغيل SQL متفاوت المسافات، ومهام التطوير الأخرى ذات الصلة بـ Azure Elastic SAN. ليس مخصصًا لتخزين Azure Blob (استخدم azure-blob-storage)، وملفات Azure (استخدم ملفات azure)، وملفات Azure NetApp (استخدم ملفات azure-netapp)، وAzure Managed Luster (استخدم Lustre المُدار بواسطة azure).
