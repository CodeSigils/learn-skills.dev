Azure Elastic SAN 開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置以及整合和編碼模式。在編寫 Elastic SAN 磁碟區腳本、調整 AVS 資料儲存、使用 CMK 加密、調整 IOPS 大小或執行叢集 SQL 以及其他 Azure Elastic SAN 相關開發任務時使用。不適用於 Azure Blob 儲存體（使用 azure-blob-storage）、Azure 檔案（使用 azure-files）、Azure NetApp 檔案（使用 azure-netapp-files）、Azure 託管 Lustre（使用 azure-management-lustre）。
