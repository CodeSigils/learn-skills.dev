Connaissance experte du développement Azure Elastic SAN, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et les quotas, la sécurité, la configuration, ainsi que les intégrations et les modèles de codage. À utiliser lors de la création de scripts sur des volumes Elastic SAN, du réglage des banques de données AVS, de l'utilisation du chiffrement CMK, du dimensionnement des IOPS ou de l'exécution de SQL en cluster, ainsi que d'autres tâches de développement liées à Azure Elastic SAN. Pas pour Azure Blob Storage (utilisez azure-blob-storage), Azure Files (utilisez azure-files), Azure NetApp Files (utilisez azure-netapp-files), Azure Managed Lustre (utilisez azure-managed-lustre).
