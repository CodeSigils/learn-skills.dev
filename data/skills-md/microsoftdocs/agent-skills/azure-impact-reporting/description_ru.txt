Экспертные знания для разработки отчетов о воздействии Azure, включая устранение неполадок, настройку, интеграцию и шаблоны кодирования. Используйте при подключении отчетов о влиянии к оповещениям мониторинга, приложениям Logic, работоспособности узла HPC, работоспособности службы или API аналитики, а также другим задачам разработки, связанным с отчетами о влиянии Azure. Не для оптимизации выбросов углерода Azure (используйте azure-carbon-optimization), управления затратами Azure (используйте azure-cost-management), Azure Monitor (используйте azure-monitor), политики Azure (используйте azure-policy).
