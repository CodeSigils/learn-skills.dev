문제 해결, 구성, 통합 및 코딩 패턴을 포함한 Azure Impact Reporting 개발에 대한 전문 지식입니다. 경고, Logic Apps, HPC 노드 상태, Service Health 또는 해당 통찰력 API 및 기타 Azure Impact Reporting 관련 개발 작업을 모니터링하기 위해 영향 보고를 연결할 때 사용합니다. Azure Carbon Optimization(azure-carbon-optimization 사용), Azure Cost Management(azure-cost-management 사용), Azure Monitor(azure-monitor 사용), Azure Policy(azure-policy 사용)에는 적합하지 않습니다.
