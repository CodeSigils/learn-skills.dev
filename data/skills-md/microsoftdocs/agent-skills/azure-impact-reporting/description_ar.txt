معرفة الخبراء بتطوير Azure Impact Reporting بما في ذلك استكشاف الأخطاء وإصلاحها والتكوين والتكامل وأنماط الترميز. يُستخدم عند توصيل تقارير التأثير لمراقبة التنبيهات أو التطبيقات المنطقية أو صحة عقدة HPC أو سلامة الخدمة أو واجهة برمجة تطبيقات الرؤى الخاصة بها، ومهام التطوير الأخرى ذات الصلة بتقارير تأثير Azure. ليس لتحسين Azure Carbon (استخدم تحسين الكربون الأزرق السماوي)، وإدارة تكلفة Azure (استخدم إدارة تكلفة azure)، وAzure Monitor (استخدم شاشة azure)، وسياسة Azure (استخدم سياسة azure).
