Экспертные знания по разработке шлюза приложений Azure, включая устранение неполадок, рекомендации, принятие решений, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при настройке прослушивателей/маршрутизации, интеграции WAF/TLS, AGIC/AKS, автомасштабирования/избыточности зон или миграции v1 → v2, а также других задач разработки, связанных со шлюзом приложений Azure. Не для Azure Front Door (используйте azure-front-door), Azure Load Balancer (используйте azure-load-balancer), Azure Traffic Manager (используйте azure-traffic-manager), брандмауэра Azure (используйте azure-firewall).
