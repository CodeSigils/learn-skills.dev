Conoscenza approfondita dello sviluppo del gateway applicazione Azure, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare durante la configurazione di listener/routing, WAF/TLS, integrazione AGIC/AKS, ridondanza di scalabilità automatica/zona o migrazione v1→v2 e altre attività di sviluppo correlate al gateway applicazione di Azure. Non per la porta anteriore di Azure (usare azure-front-door), il servizio di bilanciamento del carico di Azure (usare azure-load-balancer), Gestione traffico di Azure (usare azure-traffic-manager), Firewall di Azure (usare azure-firewall).
