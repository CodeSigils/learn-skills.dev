Connaissance approfondie du développement d'Azure Application Gateway, y compris le dépannage, les meilleures pratiques, la prise de décision, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la configuration des écouteurs/routage, de l'intégration WAF/TLS, AGIC/AKS, de la mise à l'échelle automatique/redondance de zone ou de la migration v1→v2 et d'autres tâches de développement liées à Azure Application Gateway. Pas pour Azure Front Door (utilisez azure-front-door), Azure Load Balancer (utilisez azure-load-balancer), Azure Traffic Manager (utilisez azure-traffic-manager), Azure Firewall (utilisez azure-firewall).
