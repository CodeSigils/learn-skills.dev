معرفة الخبراء بتطوير بوابة تطبيق Azure بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تكوين المستمعين/التوجيه، أو WAF/TLS، أو تكامل AGIC/AKS، أو تكرار النطاق التلقائي/المنطقة، أو ترحيل v1 → v2، ومهام التطوير الأخرى ذات الصلة بـ Azure Application Gateway. ليس لـ Azure Front Door (استخدم azure-front-door)، وAzure Load Balancer (استخدم azure-load-balancer)، وAzure Traffic Manager (استخدم azure-traffic-manager)، وجدار الحماية Azure (استخدم جدار الحماية azure).
