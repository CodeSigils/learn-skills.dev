Connaissance approfondie du développement Azure Web PubSub, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la création d'applications WebSocket/MQTT, à l'aide de Socket.IO, de la géoréplication, de points de terminaison privés ou de liaisons Functions, ainsi que d'autres tâches de développement liées à Azure Web PubSub. Pas pour Azure SignalR Service (utilisez azure-signalr-service), Azure Event Hubs (utilisez azure-event-hubs), Azure Service Bus (utilisez azure-service-bus), Azure Relay (utilisez azure-relay).
