معرفة الخبراء بتطوير Azure Web PubSub بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند إنشاء تطبيقات WebSocket/MQTT، باستخدام المقبس.IO، أو النسخ المتماثل الجغرافي، أو نقاط النهاية الخاصة، أو روابط الوظائف، ومهام التطوير الأخرى ذات الصلة بـ Azure Web PubSub. ليس لخدمة Azure SignalR (استخدم azure-signalr-service)، وAzure Event Hubs (استخدم azure-event-hubs)، وAzure Service Bus (استخدم azure-service-bus)، وAzure Relay (استخدم azure-relay).
