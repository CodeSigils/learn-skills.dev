문제 해결, 모범 사례, 의사 결정, 아키텍처 및 디자인 패턴, 제한 및 할당량, 보안, 구성, 통합 및 코딩 패턴, 배포를 포함한 Azure Web PubSub 개발에 대한 전문 지식입니다. Socket.IO, 지역 복제, 프라이빗 엔드포인트 또는 Functions 바인딩 및 기타 Azure Web PubSub 관련 개발 작업을 사용하여 WebSocket/MQTT 앱을 빌드할 때 사용합니다. Azure SignalR Service(azure-signalr-service 사용), Azure Event Hubs(azure-event-hubs 사용), Azure Service Bus(azure-service-bus 사용), Azure Relay(azure-relay 사용)에는 적합하지 않습니다.
