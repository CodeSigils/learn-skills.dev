Экспертные знания для разработки Azure Web PubSub, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при создании приложений WebSocket/MQTT, использовании Socket.IO, георепликации, частных конечных точек или привязок функций, а также других задач разработки, связанных с Azure Web PubSub. Не для службы Azure SignalR (используйте azure-signalr-service), Центров событий Azure (используйте azure-event-hubs), Azure Service Bus (используйте azure-service-bus), Azure Relay (используйте azure-relay).
