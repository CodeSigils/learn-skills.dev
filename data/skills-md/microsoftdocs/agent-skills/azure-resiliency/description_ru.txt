Экспертные знания по разработке устойчивости Azure, включая ограничения и квоты, безопасность и конфигурацию. Используйте при управлении хранилищами Backup/Site Recovery, политиками защиты, параметрами репликации, соглашениями об уровне обслуживания или состоянием безопасности, а также другими задачами разработки, связанными с устойчивостью Azure. Не для надежности Azure (используйте azure-reliability), Azure Site Recovery (используйте azure-site-recovery), Azure Backup (используйте azure-backup), Azure Monitor (используйте azure-monitor).
