معرفة الخبراء بتطوير Azure Resiliency بما في ذلك الحدود والحصص والأمان والتكوين. يُستخدم عند إدارة خزائن النسخ الاحتياطي/استرداد الموقع، أو سياسات الحماية، أو إعدادات النسخ المتماثل، أو اتفاقيات مستوى الخدمة، أو وضع أمان المرونة، ومهام التطوير الأخرى ذات الصلة بـ Azure Resiliency. ليس لموثوقية Azure (استخدم موثوقية azure)، وAzure Site Recovery (استخدم azure-site-recovery)، وAzure Backup (استخدم النسخ الاحتياطي azure)، وAzure Monitor (استخدم شاشة azure).
