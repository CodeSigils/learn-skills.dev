Экспертные знания для разработки Azure IoT Central, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при разработке шаблонов устройств, экспорте данных, шлюзах IoT Edge, автоматизации REST/CLI или конвейерах моста устройств, а также других задачах разработки, связанных с Azure IoT Central. Не для Azure IoT Hub (используйте azure-iot-hub), Azure IoT Edge (используйте azure-iot-edge), Azure IoT (используйте azure-iot), Azure Digital Twins (используйте azure-digital-twins).
