معرفة الخبراء بتطوير Azure IoT Central بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تصميم قوالب الأجهزة، أو تصدير البيانات، أو بوابات IoT Edge، أو أتمتة REST/CLI، أو خطوط أنابيب جسر الجهاز، ومهام التطوير الأخرى ذات الصلة بـ Azure IoT Central. ليس لـ Azure IoT Hub (استخدم azure-iot-hub)، وAzure IoT Edge (استخدم azure-iot-edge)، وAzure IoT (استخدم azure-iot)، وAzure Digital Twins (استخدم التوأم الرقمي اللازوردي).
