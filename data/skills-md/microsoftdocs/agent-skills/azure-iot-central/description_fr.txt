Connaissance approfondie du développement d'Azure IoT Central, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la conception de modèles d’appareils, de l’exportation de données, de passerelles IoT Edge, de l’automatisation REST/CLI ou de pipelines de pont d’appareils, ainsi que d’autres tâches de développement liées à Azure IoT Central. Pas pour Azure IoT Hub (utilisez azure-iot-hub), Azure IoT Edge (utilisez azure-iot-edge), Azure IoT (utilisez azure-iot), Azure Digital Twins (utilisez azure-digital-twins).
