Conoscenza approfondita dello sviluppo di Azure IoT Central, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la progettazione di modelli di dispositivi, esportazione di dati, gateway IoT Edge, automazione REST/CLI o pipeline di bridge di dispositivi e altre attività di sviluppo correlate ad Azure IoT Central. Non per l'hub IoT di Azure (usare azure-iot-hub), IoT Edge di Azure (usare azure-iot-edge), IoT di Azure (usare azure-iot), Gemelli digitali di Azure (usare azure-digital-twins).
