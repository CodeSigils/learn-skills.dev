Экспертные знания для разработки Azure Dev Box, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при разработке образов Dev Box, каталогов, политик, расписаний, доступа RBAC/SSO или рабочих процессов туннеля разработки VS Code, а также других задач разработки, связанных с Azure Dev Box. Не для лабораторий Azure DevTest (используйте azure-devtest-labs), виртуальных машин Azure (используйте azure-virtual-machines), виртуальных рабочих столов Azure (используйте azure-virtual-desktop).
