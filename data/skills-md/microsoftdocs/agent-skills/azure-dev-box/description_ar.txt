معرفة الخبراء بتطوير Azure Dev Box بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تصميم صور Dev Box، أو الكتالوجات، أو السياسات، أو الجداول الزمنية، أو الوصول إلى RBAC/SSO، أو سير عمل نفق تطوير VS Code، ومهام التطوير الأخرى ذات الصلة بـ Azure Dev Box. ليس مخصصًا لـ Azure DevTest Labs (استخدم azure-devtest-labs)، وأجهزة Azure الافتراضية (استخدم azure-virtual-machines)، وAzure Virtual Desktop (استخدم azure-virtual-desktop).
