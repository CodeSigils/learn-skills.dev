معرفة الخبراء بتطوير Azure AI Metrics Advisor بما في ذلك اتخاذ القرار والأمان والتكوين والتكامل وأنماط الترميز. يُستخدم عند تكوين خلاصات البيانات، أو ضبط الكشف عن الحالات الشاذة، أو إدارة خطافات التنبيه، أو دمج واجهات برمجة تطبيقات Metrics Advisor، ومهام التطوير الأخرى ذات الصلة بـ Azure AI Metrics Advisor. ليس لـ Azure AI Anomaly Detector (استخدم كاشف الشذوذ اللازوردي)، وAzure Monitor (استخدم شاشة azure)، والتعلم الآلي في Azure (استخدم التعلم الآلي اللازوردي).
