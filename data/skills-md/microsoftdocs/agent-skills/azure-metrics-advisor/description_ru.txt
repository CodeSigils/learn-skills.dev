Экспертные знания для разработки Azure AI Metrics Advisor, включая принятие решений, безопасность, настройку, интеграцию и шаблоны кодирования. Используйте при настройке каналов данных, настройке обнаружения аномалий, управлении перехватчиками оповещений или интеграции API-интерфейсов Metrics Advisor, а также других задач разработки, связанных с Azure AI Metrics Advisor. Не для Детектора аномалий Azure AI (используйте azure-anomaly-detector), Azure Monitor (используйте azure-monitor), Машинное обучение Azure (используйте azure-machine-learning).
