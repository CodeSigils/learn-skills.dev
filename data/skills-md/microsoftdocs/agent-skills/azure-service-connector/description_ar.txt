معرفة الخبراء بتطوير Azure Service Connector بما في ذلك استكشاف الأخطاء وإصلاحها والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند توصيل التطبيقات بقواعد بيانات Azure أو المراسلة أو التخزين أو الذكاء الاصطناعي أو ذاكرة التخزين المؤقت عبر أدوار موصل الخدمة وCLI وIaC ومهام التطوير الأخرى ذات الصلة بـ Azure Service Connector. ليس لإدارة Azure API (استخدم azure-api-management)، وخدمة Azure App (استخدم azure-app-service)، ووظائف Azure (استخدم وظائف azure)، وتطبيقات Azure Logic (استخدم تطبيقات azure-logic).
