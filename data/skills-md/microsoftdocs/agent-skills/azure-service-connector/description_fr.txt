Connaissance approfondie du développement d'Azure Service Connector, y compris le dépannage, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors du câblage d'applications aux bases de données Azure, à la messagerie, au stockage, à l'IA ou au cache via les rôles Service Connector, CLI et IaC, ainsi que d'autres tâches de développement liées à Azure Service Connector. Pas pour Azure API Management (utilisez azure-api-management), Azure App Service (utilisez azure-app-service), Azure Functions (utilisez azure-functions), Azure Logic Apps (utilisez azure-logic-apps).
