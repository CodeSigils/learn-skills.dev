Conoscenza approfondita dello sviluppo del connettore di servizio di Azure, tra cui risoluzione dei problemi, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare quando si collegano app a database di Azure, messaggistica, archiviazione, intelligenza artificiale o cache tramite ruoli del connettore di servizio, interfaccia della riga di comando e IaC e altre attività di sviluppo correlate al connettore di servizio di Azure. Non per Gestione API di Azure (usare azure-api-management), Servizio app di Azure (usare azure-app-service), Funzioni di Azure (usare azure-functions), App per la logica di Azure (usare azure-logic-apps).
