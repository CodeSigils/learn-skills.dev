Экспертные знания для разработки Azure Service Connector, включая устранение неполадок, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при подключении приложений к базам данных Azure, обмену сообщениями, хранилищу, искусственному интеллекту или кэшу с помощью ролей Service Connector, CLI и IaC, а также других задач разработки, связанных с Azure Service Connector. Не для управления API Azure (используйте azure-api-management), Службы приложений Azure (используйте azure-app-service), Функций Azure (используйте azure-functions), Azure Logic Apps (используйте azure-logic-apps).
