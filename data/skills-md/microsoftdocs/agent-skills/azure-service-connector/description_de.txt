Expertenwissen für die Azure Service Connector-Entwicklung, einschließlich Fehlerbehebung, Grenzwerte und Kontingente, Sicherheit, Konfiguration, Integrationen und Codierungsmuster sowie Bereitstellung. Wird verwendet, wenn Apps über Service Connector-Rollen, CLI und IaC mit Azure DBs, Messaging, Speicher, KI oder Cache verbunden werden, sowie für andere Entwicklungsaufgaben im Zusammenhang mit Azure Service Connector. Nicht für Azure API Management (verwenden Sie azure-api-management), Azure App Service (verwenden Sie azure-app-service), Azure Functions (verwenden Sie azure-functions), Azure Logic Apps (verwenden Sie azure-logic-apps).
