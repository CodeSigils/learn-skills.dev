معرفة الخبراء لتطوير Azure Active Directory B2C بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تصميم السياسات المخصصة/تدفقات المستخدم، وتسجيل الدخول إلى MFA وIdP، وتسجيل التطبيق/واجهة برمجة التطبيقات، وعمليات نشر CI/CD، أو تسجيل Sentinel، ومهام التطوير الأخرى ذات الصلة بـ Azure Active Directory B2C. ليس لحماية المعلومات في Azure (استخدم حماية المعلومات azure)، والتحكم في الوصول المستند إلى الدور في Azure (استخدم azure-rbac)، وAzure Security (استخدم azure-security)، وAzure Portal (استخدم azure-portal).
