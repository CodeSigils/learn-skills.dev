Экспертные знания для разработки Azure Active Directory B2C, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, настройку, интеграцию и шаблоны кодирования, а также развертывание. Используйте при разработке пользовательских политик/потоков пользователей, входе в систему MFA и IdP, регистрации приложений/API, развертываниях CI/CD или ведении журналов Sentinel, а также других задачах разработки, связанных с Azure Active Directory B2C. Не для Azure Information Protection (используйте azure-information-protection), управления доступом на основе ролей Azure (используйте azure-rbac), Azure Security (используйте azure-security), Azure Portal (используйте azure-portal).
