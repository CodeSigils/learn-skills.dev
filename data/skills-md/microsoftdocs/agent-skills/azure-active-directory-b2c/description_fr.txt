Connaissance approfondie du développement Azure Active Directory B2C, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la conception de stratégies/flux d'utilisateurs personnalisés, de connexion MFA et IdP, d'enregistrement d'applications/API, de déploiements CI/CD ou de journalisation Sentinel et d'autres tâches de développement liées à Azure Active Directory B2C. Pas pour Azure Information Protection (utilisez Azure-information-protection), le contrôle d'accès basé sur le rôle Azure (utilisez azure-rbac), Azure Security (utilisez azure-security), le portail Azure (utilisez azure-portal).
