Conoscenza approfondita dello sviluppo B2C di Azure Active Directory, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la progettazione di policy/flussi utente personalizzati, accesso MFA e IdP, registrazione di app/API, distribuzioni CI/CD o registrazione Sentinel e altre attività di sviluppo correlate ad Azure Active Directory B2C. Non per Azure Information Protection (usare azure-information-protection), controllo degli accessi in base al ruolo di Azure (usare azure-rbac), Sicurezza di Azure (usare azure-security), Portale di Azure (usare azure-portal).
