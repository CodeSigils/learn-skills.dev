Expertenwissen für die Entwicklung von Azure Open Datasets, einschließlich Grenzwerten und Kontingenten. Wird bei der Verarbeitung von Nicht-Spark-Dataset-Downloads, Drosselungsverhalten, Kontingentlimits, Wiederholungslogik oder Problemumgehungen für Ratenlimits und anderen Entwicklungsaufgaben im Zusammenhang mit Azure Open Datasets verwendet. Nicht für Azure Data Explorer (verwenden Sie azure-data-explorer), Azure Synapse Analytics (verwenden Sie azure-synapse-analytics), Azure Databricks (verwenden Sie azure-databricks), Azure Machine Learning (verwenden Sie azure-machine-learning).
