معرفة الخبراء بتطوير مجموعات البيانات المفتوحة في Azure بما في ذلك الحدود والحصص. يُستخدم عند التعامل مع تنزيلات مجموعات البيانات بخلاف Spark، أو سلوك التقييد، أو حدود الحصة النسبية، أو منطق إعادة المحاولة، أو الحلول البديلة للحد من المعدل، ومهام التطوير الأخرى ذات الصلة بـ Azure Open Datasets. ليس لـ Azure Data Explorer (استخدم azure-data-explorer)، وAzure Synapse Analytics (استخدم azure-synapse-analytics)، وAzure Databricks (استخدم azure-databricks)، والتعلم الآلي من Azure (استخدم التعلم الآلي من azure).
