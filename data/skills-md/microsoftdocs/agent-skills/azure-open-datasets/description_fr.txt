Connaissance approfondie du développement d'Azure Open Datasets, y compris les limites et les quotas. À utiliser lors de la gestion des téléchargements d'ensembles de données non Spark, du comportement de limitation, des limites de quota, de la logique de nouvelle tentative ou des solutions de contournement de limite de débit, ainsi que d'autres tâches de développement liées à Azure Open Datasets. Pas pour Azure Data Explorer (utilisez azure-data-explorer), Azure Synapse Analytics (utilisez azure-synapse-analytics), Azure Databricks (utilisez azure-databricks), Azure Machine Learning (utilisez azure-machine-learning).
