Экспертные знания по разработке наборов открытых данных Azure, включая ограничения и квоты. Используйте при обработке загрузок наборов данных, отличных от Spark, регулирования поведения, ограничений квот, логики повторных попыток или обходных путей ограничения скорости, а также других задач разработки, связанных с открытыми наборами данных Azure. Не для Azure Data Explorer (используйте azure-data-explorer), Azure Synapse Analytics (используйте azure-synapse-analytics), Azure Databricks (используйте azure-databricks), Машинное обучение Azure (используйте azure-machine-learning).
