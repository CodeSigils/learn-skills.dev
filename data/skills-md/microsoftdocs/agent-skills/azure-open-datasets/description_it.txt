Conoscenza approfondita dello sviluppo di set di dati aperti di Azure, inclusi limiti e quote. Da utilizzare durante la gestione dei download di set di dati non Spark, del comportamento di limitazione, dei limiti di quota, della logica dei nuovi tentativi o di soluzioni alternative relative ai limiti di velocità e altre attività di sviluppo correlate a Azure Open Dataset. Non per Azure Esplora dati (usare azure-data-explorer), Azure Synapse Analytics (usare azure-synapse-analytics), Azure Databricks (usare azure-databricks), Azure Machine Learning (usare azure-machine-learning).
