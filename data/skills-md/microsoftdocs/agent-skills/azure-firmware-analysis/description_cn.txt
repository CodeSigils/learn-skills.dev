Azure 固件分析开发的专业知识，包括故障排除、最佳实践、限制和配额、安全性、集成和编码模式以及部署。在扫描固件映像、解释 SBOM 路径、使用 UEFI 分析或通过 CLI/PowerShell/Python 自动上传以及其他 Azure 固件分析相关开发任务时使用。不适用于 Azure Defender For Iot（使用 azure-defender-for-iot）、Azure IoT Edge（使用 azure-iot-edge）、Azure IoT 中心（使用 azure-iot-hub）、Azure 机密计算（使用 azure-confidential-computing）。
