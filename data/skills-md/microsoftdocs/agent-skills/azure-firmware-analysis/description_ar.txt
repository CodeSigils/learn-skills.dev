معرفة الخبراء لتطوير تحليل البرامج الثابتة لـ Azure بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات والحدود والحصص والأمان والتكامل وأنماط الترميز والنشر. يُستخدم عند مسح صور البرامج الثابتة، أو تفسير مسارات SBOM، أو استخدام تحليل UEFI، أو أتمتة التحميلات عبر CLI/PowerShell/Python، ومهام التطوير الأخرى ذات الصلة بتحليل Azure Firmware. ليس لـ Azure Defender For Iot (استخدم azure-defender-for-iot)، وAzure IoT Edge (استخدم azure-iot-edge)، وAzure IoT Hub (استخدم azure-iot-hub)، والحوسبة السرية لـ Azure (استخدم الحوسبة السرية azure).
