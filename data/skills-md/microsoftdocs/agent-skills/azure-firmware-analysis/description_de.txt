Expertenwissen für die Entwicklung der Azure-Firmware-Analyse, einschließlich Fehlerbehebung, Best Practices, Grenzwerte und Kontingente, Sicherheit, Integrationen und Codierungsmuster sowie Bereitstellung. Wird zum Scannen von Firmware-Images, zum Interpretieren von SBOM-Pfaden, zum Verwenden der UEFI-Analyse oder zum Automatisieren von Uploads über CLI/PowerShell/Python sowie für andere Entwicklungsaufgaben im Zusammenhang mit der Azure-Firmware-Analyse verwendet. Nicht für Azure Defender für Iot (verwenden Sie azure-defender-for-iot), Azure IoT Edge (verwenden Sie azure-iot-edge), Azure IoT Hub (verwenden Sie azure-iot-hub), Azure Confidential Computing (verwenden Sie azure-confidential-computing).
