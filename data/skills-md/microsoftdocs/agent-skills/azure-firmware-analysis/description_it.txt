Conoscenza approfondita dello sviluppo dell'analisi del firmware di Azure, tra cui risoluzione dei problemi, procedure consigliate, limiti e quote, sicurezza, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la scansione di immagini firmware, l'interpretazione di percorsi SBOM, l'uso dell'analisi UEFI o l'automazione dei caricamenti tramite CLI/PowerShell/Python e altre attività di sviluppo correlate all'analisi firmware di Azure. Non per Azure Defender for Iot (usare azure-defender-for-iot), Azure IoT Edge (usare azure-iot-edge), Hub IoT di Azure (usare azure-iot-hub), Azure Confidential Computing (usare azure-confidential-computing).
