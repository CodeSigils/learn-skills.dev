Connaissance approfondie du développement d'Azure Firmware Analysis, y compris le dépannage, les meilleures pratiques, les limites et quotas, la sécurité, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'analyse des images du micrologiciel, de l'interprétation des chemins SBOM, de l'utilisation de l'analyse UEFI ou de l'automatisation des téléchargements via CLI/PowerShell/Python et d'autres tâches de développement liées à Azure Firmware Analysis. Pas pour Azure Defender For IoT (utilisez azure-defender-for-iot), Azure IoT Edge (utilisez azure-iot-edge), Azure IoT Hub (utilisez azure-iot-hub), Azure Confidential Computing (utilisez azure-confidential-computing).
