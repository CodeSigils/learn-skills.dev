Экспертные знания для разработки анализа встроенного ПО Azure, включая устранение неполадок, рекомендации, ограничения и квоты, безопасность, интеграцию и шаблоны кодирования, а также развертывание. Используйте при сканировании образов встроенного ПО, интерпретации путей SBOM, использовании анализа UEFI или автоматизации загрузки через CLI/PowerShell/Python и других задачах разработки, связанных с анализом встроенного ПО Azure. Не для Защитника Azure для Iot (используйте azure-defender-for-iot), Azure IoT Edge (используйте azure-iot-edge), Azure IoT Hub (используйте azure-iot-hub), Azure Confidential Computing (используйте azure-confidential-computing).
