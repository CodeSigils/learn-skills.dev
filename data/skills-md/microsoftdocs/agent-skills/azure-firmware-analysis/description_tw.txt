Azure 韌體分析開發的專業知識，包括故障排除、最佳實踐、限制和配額、安全性、整合和編碼模式以及部署。在掃描韌體映像、解釋 SBOM 路徑、使用 UEFI 分析或透過 CLI/PowerShell/Python 自動上傳以及其他 Azure 韌體分析相關開發任務時使用。不適用於 Azure Defender For Iot（使用 azure-defender-for-iot）、Azure IoT Edge（使用 azure-iot-edge）、Azure IoT 中心（使用 azure-iot-hub）、Azure 機密計算（使用 azure-confidential-computing）。
