Conoscenza approfondita dello sviluppo di Playwright Workspaces, tra cui risoluzione dei problemi, best practice, processo decisionale, limiti e quote, sicurezza e configurazione. Da utilizzare durante la gestione di aree di lavoro di Playwright Testing, token/RBAC, quote, monitoraggio/metriche o problemi di esecuzione/AADSTS7000112 e altre attività di sviluppo correlate a Playwright Workspace. Non per Azure App Testing (usare azure-app-testing), Azure DevOps (usare azure-devops), Azure Pipelines (usare azure-pipelines), Azure Test Plans (usare azure-test-plans).
