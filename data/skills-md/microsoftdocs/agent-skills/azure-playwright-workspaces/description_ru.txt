Экспертные знания для разработки Playwright Workspaces, включая устранение неполадок, лучшие практики, принятие решений, ограничения и квоты, безопасность и настройку. Используйте при управлении рабочими пространствами Playwright Testing, токенами/RBAC, квотами, мониторингом/метриками или проблемами запуска/AADSTS7000112, а также другими задачами разработки, связанными с Playwright Workspaces. Не для тестирования приложений Azure (используйте azure-app-testing), Azure DevOps (используйте azure-devops), Azure Pipelines (используйте azure-pipelines), планов тестирования Azure (используйте azure-test-plans).
