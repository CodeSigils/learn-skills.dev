معرفة الخبراء بتطوير مساحات عمل Playwright بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار والحدود والحصص والأمان والتكوين. يُستخدم عند إدارة مساحات عمل Playwright Testing، أو الرموز المميزة/RBAC، أو الحصص، أو المراقبة/المقاييس، أو مشكلات التشغيل/AADSTS7000112، ومهام التطوير الأخرى ذات الصلة بمساحات عمل Playwright. ليس لاختبار تطبيق Azure (استخدم اختبار تطبيق azure)، وAzure DevOps (استخدم azure-devops)، وAzure Pipelines (استخدم خطوط أنابيب azure)، وخطط اختبار Azure (استخدم خطط اختبار azure).
