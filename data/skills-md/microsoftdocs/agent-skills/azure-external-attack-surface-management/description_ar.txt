معرفة الخبراء بتطوير Azure External Attack Surface Management بما في ذلك الحدود والحصص والتكوين والتكامل وأنماط الترميز. استخدمه عند الاستعلام عن أصول EASM، أو إعداد قواعد السياسة، أو التصدير إلى Log Analytics أو Data Explorer، أو تقدير الفواتير، ومهام التطوير الأخرى ذات الصلة بإدارة سطح الهجوم الخارجي لـ Azure. ليس لـ Azure Defender For Cloud (استخدم azure-defender-for-cloud)، وAzure Security (استخدم azure-security)، وAzure Sentinel (استخدم azure-sentinel)، وAzure Firewall (استخدم جدار الحماية azure).
