Expertenwissen für die Entwicklung von Azure External Attack Surface Management, einschließlich Grenzwerten und Kontingenten, Konfiguration sowie Integrationen und Codierungsmustern. Wird zum Abfragen von EASM-Assets, zum Festlegen von Richtlinienregeln, zum Exportieren nach Log Analytics oder Data Explorer oder zum Schätzen der Abrechnung sowie für andere Entwicklungsaufgaben im Zusammenhang mit Azure External Attack Surface Management verwendet. Nicht für Azure Defender für Cloud (verwenden Sie azure-defender-for-cloud), Azure Security (verwenden Sie azure-security), Azure Sentinel (verwenden Sie azure-sentinel), Azure Firewall (verwenden Sie azure-firewall).
