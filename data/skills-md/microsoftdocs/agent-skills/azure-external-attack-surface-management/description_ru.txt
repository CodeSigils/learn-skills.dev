Экспертные знания для разработки управления поверхностью внешних атак Azure, включая ограничения и квоты, конфигурацию, а также интеграцию и шаблоны кодирования. Используйте при запросе ресурсов EASM, настройке правил политики, экспорте в Log Analytics или Data Explorer, оценке выставления счетов и других задачах разработки, связанных с управлением внешней поверхностью атаки Azure. Не для Защитника Azure для облака (используйте azure-defender-for-cloud), Безопасность Azure (используйте azure-security), Azure Sentinel (используйте azure-sentinel), Брандмауэр Azure (используйте azure-firewall).
