Connaissance approfondie du développement d'Azure Databricks, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'utilisation de Unity Catalog, Lakehouse/Lakebase, Lakeflow, Delta Sharing, Vector Search ou Model Servicing, ainsi que d'autres tâches de développement liées à Azure Databricks. Pas pour Azure Synapse Analytics (utilisez azure-synapse-analytics), Azure HDInsight (utilisez azure-hdinsight), Azure Machine Learning (utilisez azure-machine-learning), Azure Data Factory (utilisez azure-data-factory).
