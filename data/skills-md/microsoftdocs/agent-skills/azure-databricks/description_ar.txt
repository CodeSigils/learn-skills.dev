معرفة الخبراء بتطوير Azure Databricks بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام Unity Catalog أو Lakehouse/Lakebase أو Lakeflow أو Delta Sharing أو Vector Search أو خدمة النماذج ومهام التطوير الأخرى ذات الصلة بـ Azure Databricks. ليس لـ Azure Synapse Analytics (استخدم azure-synapse-analytics)، وAzure HDInsight (استخدم azure-hdinsight)، وAzure Machine Learning (استخدم التعلم الآلي من azure)، وAzure Data Factory (استخدم azure-data-factory).
