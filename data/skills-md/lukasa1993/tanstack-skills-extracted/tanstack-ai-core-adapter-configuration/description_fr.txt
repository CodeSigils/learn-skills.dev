Sélection et configuration de l'adaptateur de fournisseur : openaiText, anthropicText, geminiText, ollamaText, grokText, groqText, openRouterText, bedrockText, byteplusText, openaiCompatible. Sécurité de type par modèle avec modelOptions, configuration de raisonnement/réflexion, commutation d'adaptateur d'exécution, extendAdapter() pour les modèles personnalisés, createModel(). Fournisseurs génériques compatibles OpenAI (DeepSeek, Together, Fireworks, etc.) via openaiCompatible({ baseURL, apiKey, models }) de @tanstack/ai-openai/compatible. Vars d'environnement de clé API : OPENAI_API_KEY, ANTHROPIC_API_KEY, GOOGLE_API_KEY/GEMINI_API_KEY, XAI_API_KEY, GROQ_API_KEY, OPENROUTER_API_KEY, OLLAMA_HOST, BEDROCK_API_KEY (ou AWS_BEARER_TOKEN_BEDROCK). BytePlus a besoin de DEUX clés : ARK_API_KEY (ModelArk — chat/vidéo/image) et BYTEPLUS_VOICE_API_KEY (Seed Speech — TTS/transcription) ; ni l’un ni l’autre n’est une solution de repli pour l’autre.
