Выбор и настройка адаптера провайдера: openaiText, anthropicText, geminiText, ollamaText, grokText, groqText, openRouterText, BedrockText, byteplusText, openaiCompatible. Безопасность типов для каждой модели с помощью modelOptions, конфигурация рассуждений/мышлений, переключение адаптера во время выполнения, ExtendAdapter() для пользовательских моделей, createModel(). Общие поставщики, совместимые с OpenAI (DeepSeek, Together, Fireworks и т. д.) через openaiCompatible({ baseURL, apiKey, models }) из @tanstack/ai-openai/совместимого. Переменные среды ключа API: OPENAI_API_KEY, ANTHROPIC_API_KEY, GOOGLE_API_KEY/GEMINI_API_KEY, XAI_API_KEY, GROQ_API_KEY, OPENROUTER_API_KEY, OLLAMA_HOST, BEDROCK_API_KEY (или AWS_BEARER_TOKEN_BEDROCK). BytePlus нужны ДВА ключа: ARK_API_KEY (ModelArk — чат/видео/изображение) и BYTEPLUS_VOICE_API_KEY (начальная речь — TTS/транскрипция); ни один из них не является запасным вариантом для другого.
