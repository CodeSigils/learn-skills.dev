プロバイダー アダプターの選択と構成: openaiText、anthropicText、geminiText、ollamaText、grokText、groqText、openRouterText、bedrockText、byteplusText、openaiComprehensive。 modelOptions、推論/思考構成、実行時アダプターの切り替え、カスタム モデルの extendAdapter()、createModel() によるモデルごとのタイプ セーフティ。一般的な OpenAI 互換プロバイダー (DeepSeek、Togetter、Fireworks など) (@tanstack/ai-openai/compatibility の openaiSupport({baseURL, apiKey, models }) 経由)。 API キー環境変数: OPENAI_API_KEY、ANTHROPIC_API_KEY、GOOGLE_API_KEY/GEMINI_API_KEY、XAI_API_KEY、GROQ_API_KEY、OPENROUTER_API_KEY、OLLAMA_HOST、BEDROCK_API_KEY (または AWS_BEARER_TOKEN_BEDROCK)。 BytePlus には 2 つのキーが必要です: ARK_API_KEY (ModelArk — チャット/ビデオ/画像) と BYTEPLUS_VOICE_API_KEY (シードスピーチ — TTS/文字起こし)。どちらも他方のフォールバックではありません。
