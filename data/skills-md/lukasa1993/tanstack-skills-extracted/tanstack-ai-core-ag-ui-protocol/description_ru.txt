Реализация протокола потоковой передачи AG-UI на стороне сервера: типы событий StreamChunk (RUN_STARTED, TEXT_MESSAGE_START/CONTENT/END, Tool_CALL_START/ARGS/END, RUN_FINISHED, RUN_ERROR, STEP_STARTED/STEP_FINISHED, STATE_SNAPSHOT/DELTA, CUSTOM), toServerSentEventsStream() для формата SSE, toHttpStream() для формата NDJSON. Для серверных частей, обслуживающих события AG-UI без клиентских пакетов.
