قم بإنشاء بنية أساسية للجدول الصلب قابلة لإعادة الاستخدام باستخدام createTableHook، و createAppTable، و createAppColumnHelper، والميزات/الافتراضيات المشتركة، وسجلات المكونات، وأغلفة التطبيقات، وخطافات السياق المكتوبة. قم بالتحميل من أجل اصطلاحات التطبيق المتكررة، أو أدوات الحصول على التفاعل لكل جدول، أو حفر الدعامات.
