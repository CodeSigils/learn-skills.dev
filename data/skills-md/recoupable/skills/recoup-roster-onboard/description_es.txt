Arranque la lista de una organización vacía: cuando la cuenta aún no tiene artistas, reúna la lista del sello (nombres o una lista pegada) e incorpórelas todas distribuyendo recoup-roster-add-artist en subagentes paralelos (cada uno ejecuta la cadena completa crear → enriquecer), opcionalmente explorando talentos primero. Úselo para "configurar nuestra lista", "aún no tenemos artistas", "incorporar toda nuestra lista", "importar estos artistas" o cuando recoup-platform-build-os / recoup-platform-connect-account encuentre una lista vacía. Para un solo artista utilice recoup-roster-add-artist; para ver la lista use recoup-roster-list-artists.
