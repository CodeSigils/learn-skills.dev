Bootstrap die Liste einer leeren Organisation – wenn das Konto noch keine Künstler hat, sammeln Sie die Liste des Labels (Namen oder eine eingefügte Liste) und binden Sie sie alle ein, indem Sie „Recoup-Roster-Add-Künstler“ auf parallele Subagenten verteilen (jeder führt die vollständige Kette „Erstellen → Anreichern“ durch) und optional zuerst Talente scouten. Verwenden Sie diese Option für „unseren Kader einrichten“, „wir haben noch keine Künstler“, „unseren gesamten Kader hinzufügen“, „diese Künstler importieren“ oder wenn recoup-platform-build-os / recoup-platform-connect-account einen leeren Kader findet. Für einen einzelnen Künstler verwenden Sie recoup-roster-add-artist; Um den Kader anzuzeigen, verwenden Sie recoup-roster-list-artists.
