Comprenda una canción a partir de su audio utilizando el modelo de audio de Recoup (Music Flamingo): informe completo, metadatos del catálogo (BPM/clave/género/estado de ánimo), una hoja de letra seccionada o una crítica de mezcla. Úselo para "analizar esta canción", "qué clave/BPM/género es este", "etiquetar esta pista", "transcribir la letra" o "criticar la mezcla". Requiere una URL de audio pública. Para encontrar el momento digno de un clip, utilice recoup-song-find-hook; para los materiales de colocación utilice recuperar el tono de colocación de la canción.
