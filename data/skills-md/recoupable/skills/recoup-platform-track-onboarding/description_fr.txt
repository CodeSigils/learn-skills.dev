Vérifiez jusqu'où un compte Recoup a progressé lors de l'intégration et faites-le passer à l'étape suivante. Mesure le compte par rapport aux huit points de contrôle d'activation (artiste ajouté, réseaux sociaux connectés, premier chat, exécution d'évaluation, catalogue réclamé, première tâche planifiée, paiement) à l'aide de la propre clé API de l'appelant, puis achemine vers la compétence qui termine l'étape suivante. À utiliser pour « où en suis-je dans ma configuration Recoup », « que dois-je faire ensuite », « ai-je terminé l'intégration », « statut d'intégration », « liste de contrôle d'activation », « comment est configuré mon compte » ou après que recoup-platform-connect-account ait terminé la configuration de première exécution. Lecture seule ; n'effectue jamais les étapes lui-même - il les achemine.
