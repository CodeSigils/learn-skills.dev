Rufen Sie die Recoupable-API aus der Sandbox auf, um Künstlerdaten, soziale Netzwerke, Organisationen, Recherchen, Dokumente und andere Plattformressourcen abzurufen – und um externe Connector-Aktionen (Google Docs/Drive/Sheets-Bearbeitungen, Gmail, TikTok, Instagram usw.) über die gemeinsamen Verbindungen von Recoupable aufzurufen. Verwenden Sie es immer dann, wenn Sie nach Recoup-Daten oder einer Recoupable-Plattformressource gefragt werden oder etwas außerhalb von Recoup lesen/schreiben möchten, beispielsweise eine Google Doc-URL oder eine Tabelle. Wird bei Phrasen wie „Künstler suchen“, „Aus Recoup abrufen“, „Künstlerdaten“, „Socials für Künstler“, „Organisationen“, „Künstlerbericht“, „Recherche“, „Neuen Künstler erstellen“, „Künstler erstellen“, „Künstler an Bord“, „Künstler hinzufügen“, „Dieses Google-Dokument bearbeiten“, „Dieses Dokument lesen“, „Tabelle aktualisieren“, „E-Mail senden“, „Auf TikTok posten“, „Auf Drive speichern“ ausgelöst oder immer dann, wenn der Benutzer ein docs.google.com / einfügt URL „drive.google.com/sheets.google.com“. Laden Sie dies immer, bevor Sie Curl-Aufrufe gegen recoup-api.vercel.app schreiben.
