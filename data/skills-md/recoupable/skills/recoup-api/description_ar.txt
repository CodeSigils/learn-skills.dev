اتصل بواجهة برمجة التطبيقات Recoupable من وضع الحماية لجلب بيانات الفنان والشبكات الاجتماعية والمؤسسات والأبحاث والمستندات وأي مورد آخر للنظام الأساسي - ولاستدعاء إجراءات الموصل الخارجي (تعديلات مستندات Google / Drive / جداول البيانات، وGmail، وTikTok، وInstagram، وما إلى ذلك) عبر اتصالات Recoupable المشتركة. استخدمه عندما يُطلب منك بيانات الاسترداد، أو مورد النظام الأساسي القابل للاسترداد، أو لقراءة/كتابة شيء ما خارج Recoup مثل عنوان URL لمستند Google أو جدول بيانات. مشغلات لعبارات مثل "البحث عن فنان"، أو "جلب من الاسترداد"، أو "بيانات الفنان"، أو "التواصل الاجتماعي للفنان"، أو "المؤسسات"، أو "تقرير الفنان"، أو "بحث"، أو "إنشاء فنان جديد"، أو "إنشاء فنان"، أو "فنان على متن الطائرة"، أو "إضافة فنان"، أو "تحرير مستند Google هذا"، أو "قراءة هذا المستند"، أو "تحديث جدول البيانات"، أو "إرسال بريد إلكتروني"، أو "النشر على TikTok"، أو "الحفظ في Drive"، أو عندما يلصق المستخدم عنوان URL docs.google.com / Drive.google.com / Sheets.google.com. قم دائمًا بتحميل هذا قبل كتابة مكالمات الضفيرة مقابل recoup-api.vercel.app.
