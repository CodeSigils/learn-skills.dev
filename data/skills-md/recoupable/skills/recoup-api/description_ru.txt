Вызовите Recoupable API из песочницы, чтобы получить данные об исполнителях, социальных сетях, организациях, исследованиях, документах и ​​любых других ресурсах платформы, а также вызвать действия внешнего коннектора (редактирование Google Docs/Drive/Sheets, Gmail, TikTok, Instagram и т. д.) через общие соединения Recoupable. Используйте всякий раз, когда вас просят предоставить данные Recoup, ресурс платформы Recoupable или прочитать/записать что-то вне Recoup, например URL-адрес документа Google или электронную таблицу. Запускается по таким фразам, как «найти исполнителя», «получить из восстановления», «данные об исполнителе», «соцсети исполнителя», «организации», «отчет об исполнителе», «исследование», «создать нового исполнителя», «создать исполнителя», «подключить исполнителя», «добавить исполнителя», «отредактировать этот документ Google», «прочитать этот документ», «обновить электронную таблицу», «отправить электронное письмо», «опубликовать в TikTok», «сохранить на диске» или всякий раз, когда пользователь вставляет URL-адрес docs.google.com/drive.google.com/sheets.google.com. Всегда загружайте это перед написанием вызовов Curl для recoup-api.vercel.app.
