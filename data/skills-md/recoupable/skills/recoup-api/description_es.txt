Llame a la API de Recoupable desde el sandbox para obtener datos de artistas, redes sociales, organizaciones, investigaciones, documentos y cualquier otro recurso de la plataforma, y ​​para invocar acciones de conectores externos (ediciones de Google Docs/Drive/Ssheets, Gmail, TikTok, Instagram, etc.) a través de las conexiones compartidas de Recoupable. Úselo siempre que se le soliciten datos de Recoup, un recurso de plataforma recuperable o para leer/escribir algo fuera de Recoup, como una URL de documento de Google o una hoja de cálculo. Activadores de frases como "buscar artista", "obtener de recuperación", "datos de artista", "redes sociales de artistas", "organizaciones", "informe de artista", "investigación", "crear nuevo artista", "crear artista", "artista incorporado", "agregar artista", "editar este documento de Google", "leer este documento", "actualizar la hoja de cálculo", "enviar un correo electrónico", "publicar en TikTok", "guardar en Drive" o cada vez que el usuario pega un docs.google.com/ URL de drive.google.com/sheets.google.com. Cargue siempre esto antes de escribir llamadas curl en recoup-api.vercel.app.
