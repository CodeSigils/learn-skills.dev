Appelez l'API Recoupable depuis le bac à sable pour récupérer les données des artistes, les réseaux sociaux, les organisations, les recherches, les documents et toute autre ressource de la plate-forme - et pour invoquer des actions de connecteur externe (modifications Google Docs / Drive / Sheets, Gmail, TikTok, Instagram, etc.) via les connexions partagées de Recoupable. À utiliser chaque fois qu'on vous demande des données Recoup, une ressource de plateforme récupérable, ou pour lire/écrire quelque chose en dehors de Recoup, comme une URL de document Google ou une feuille de calcul. Se déclenche sur des expressions telles que « rechercher un artiste », « récupérer à partir de la récupération », « données sur l'artiste », « réseaux sociaux d'artistes », « organisations », « rapport sur l'artiste », « recherche », « créer un nouvel artiste », « créer un artiste », « artiste intégré », « ajouter un artiste », « modifier ce document Google », « lire ce document », « mettre à jour la feuille de calcul », « envoyer un e-mail », « publier sur TikTok », « enregistrer sur Drive » ou chaque fois que l'utilisateur colle un docs.google.com/ URL drive.google.com / sheet.google.com. Chargez-le toujours avant d'écrire des appels curl sur recoup-api.vercel.app.
