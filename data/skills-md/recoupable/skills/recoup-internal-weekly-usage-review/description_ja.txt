INTERNAL — recoup-internal キーワードによって制御されるリクープ スタッフ ツール。リクエストに明示的に「recoup-internal」が含まれている場合にのみ呼び出します (例: 「recoup-internal run the Weekly use review」)。顧客対応やアーティストからのリクエストには決して使用しないでください。 Recoup プラットフォームのフリート全体の期間を対象としたビジネス レビューを作成します。誰がログインして Web UI にアクセスしたか、Stripe で何が変更されたか (サインアップ、トライアル、請求、キャンセル、有料名簿)、クレジットを誰が何に消費したか、AI Gateway の支出はクレジット台帳と照合され、どの顧客が最も価値のあるカタログを保持しているかなどを作成します。 「週ごとの使用状況のレビュー」、「週ごとのレビュー」、「不在中に起こったこと」、「今週製品を使用した人」、「ビジネスの状況」、または休暇の近況を尋ねられたときに使用します。単一アカウントの詳細を確認するには、代わりに recoup-internal-account-health-report を使用してください。
