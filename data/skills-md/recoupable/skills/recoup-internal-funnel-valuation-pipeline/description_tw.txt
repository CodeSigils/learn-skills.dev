INTERNAL — Recoup 人員工具，由 recoup-internal 關鍵字控制。僅當請求明確包含“recoup-internal”（例如“recoup-internal work thevaluation funnel”）時才呼叫。切勿用於面向客戶或藝術家的請求。在 Attio 中處理 Recoup「估價線索」銷售漏斗 — 取得入站目錄估價線索，並將其從「估價運行」進展到「註冊 Pro」。研究領導者是誰以及他們與他們所重視的藝術家的關係，根據收入目標對目錄進行資格認證，豐富和推進 Attio CRM 記錄，並起草第一封外展電子郵件和乾淨的單頁評估 PDF。當被要求「工作評估漏斗」、「確定該潛在客戶的資格」、「誰進行了此評估」、「此目錄值得我們花時間嗎」、「更新 Attio 管道」、「推進此潛在客戶」、「起草此評估的外展活動」或「將評估潛在客戶轉變為專業註冊」時使用。需要 Attio API 金鑰和 Recoup API 金鑰。
