ВНУТРЕННИЙ — инструментарий для персонала восстановления, доступный по ключевому слову recoup-internal. Вызывайте ТОЛЬКО в том случае, если запрос явно включает «внутреннюю окупаемость» (например, «внутренняя окупаемость работы воронки оценки»). Никогда не используйте для запросов клиентов или исполнителей. Работайте над воронкой продаж «Оценка потенциальных клиентов» в Attio — возьмите входящий запрос на оценку по каталогу и проведите его от «оценка выполнена» до «подписка на Pro». Исследует, кто является руководителем, и его отношение к артисту, которого он ценит, сопоставляет каталог с целевыми показателями дохода, обогащает и совершенствует записи Attio CRM, а также готовит первое информационное электронное письмо и чистый одностраничный PDF-файл с оценкой. Используйте, когда вас просят «проработать воронку оценки», «квалифицировать этого потенциального клиента», «кто провел эту оценку», «стоит ли этот каталог нашего времени», «обновить конвейер Attio», «продвинуть этого потенциального клиента», «набросать проект охвата для этой оценки» или «превратить потенциальных потенциальных клиентов в подписки Pro». Требуется ключ API Attio и ключ API восстановления.
