INTERNAL — recoup-internal キーワードによって制御されるリクープ スタッフ ツール。リクエストに明示的に「recoup-internal」が含まれている場合にのみ呼び出します (例: 「recoup-internal work the valuation funnel」)。顧客対応やアーティストからのリクエストには決して使用しないでください。 Attio で Recoup の「評価リード」セールスファネルを操作します。受信したカタログ評価リードを取得し、「評価実行」から「プロへのサインアップ」まで進めます。リードが誰であるか、彼らと彼らが評価するアーティストとの関係を調査し、収益目標に照らしてカタログを認定し、Attio CRM 記録を充実させて前進させ、最初のアウトリーチ メールときれいな 1 ページの評価 PDF の下書きを作成します。 「評価ファネルの作業」、「この見込み客の評価」、「この評価の実行者」、「このカタログに時間をかける価値はありますか」、「Attio パイプラインの更新」、「この見込み客の前進」、「この評価のためのアウトリーチの草案」、または「評価見込み客を Pro サインアップに変える」ように求められた場合に使用します。 Attio API キーと Recoup API キーが必要です。
