Отправьте электронное письмо через Recoup API надежным способом — помощником Node, который правильно сериализует тело и громко завершает работу с ошибкой вместо отправки пустого письма. Используйте, когда задача должна отправить отчет/сводку/уведомление по электронной почте владельцу учетной записи или получателю. ВСЕГДА используйте этот сценарий для отправки электронной почты; никогда не создавайте вручную `curl … -d "{…}"` со встроенной интерполяцией `jq`/shell (которая автоматически создает пустые электронные письма «Сообщение от восстановления»), содержащие только нижний колонтитул). Сопряжено с recoup-platform-api-access (через который он отправляет).
