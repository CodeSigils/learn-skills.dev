INTERN – Personalwerkzeuge wiederherstellen. Niemals für Kunden- oder Künstleranfragen verwenden. Schreiben und pflegen Sie GitHub-Probleme mit hoher Signalstärke – insbesondere langlebige Tracking-Probleme, die Multi-PR- und Multi-Repo-Bemühungen koordinieren – im Stil des Recoup-Hauses. Wird verwendet, wenn der Benutzer sagt: „Ein Problem schreiben“, „ein Tracking-Problem erstellen“, „ein Problem für diese Arbeit öffnen“, „das Problem aktualisieren“, „einen Artikel abhaken/abschließen“, „protokollieren, was für das Problem versendet wurde“, „das Problem verwalten“ oder wenn er einen Plan, eine Umstellung, eine Migration oder eine Bereinigung erfasst, die mehr als eine PR umfasst. Behandelt die Struktur, den Open→Done-Lebenszyklus, Beweis-/Verknüpfungsregeln und Akzeptanzkriterien.
