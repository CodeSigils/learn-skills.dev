ВНУТРЕННИЕ — Окупить штатную оснастку. Никогда не используйте для запросов клиентов или исполнителей. Напишите и поддерживайте важные проблемы GitHub — особенно долгосрочные проблемы отслеживания, которые координируют усилия по множеству PR и множеству репозиториев — в стиле Recoup house. Используйте, когда пользователь говорит «написать проблему», «создать задачу отслеживания», «открыть задачу для этой работы», «обновить задачу», «отметить/закрыть элемент», «записать в журнал то, что было отправлено по проблеме», «поддерживать проблему» или при записи плана, переключения, миграции или очистки, охватывающей более одного PR. Охватывает структуру, жизненный цикл «Открыто → Готово», правила подтверждения/связывания и критерии приемки.
