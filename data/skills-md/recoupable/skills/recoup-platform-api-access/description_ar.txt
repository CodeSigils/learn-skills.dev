اتصل بـ Recoup API والموصلات الخارجية مباشرة - قم بإحضار أي مورد للنظام الأساسي (الفنانون والشبكات الاجتماعية والمؤسسات والأبحاث والمستندات) وقم بتشغيل إجراءات الموصل (تحريرات Google Docs/Sheets/Drive وGmail وTikTok وInstagram). استخدمه عندما تحتاج إلى بيانات Recoup الأولية، أو مورد النظام الأساسي، لكتابة تجعيد مقابل api.recoupable.dev، أو لقراءة/كتابة شيء ما خارج Recoup مثل عنوان URL لمستند Google أو جدول بيانات. السباكة التي تعتمد عليها كل المهارات الأخرى. لضم فنان أو تشغيله، استخدم مهارات recoup-roster-*؛ للاتصال الذي يتم تشغيله لأول مرة، استخدم حساب recoup-platform-connect-account.
