Recoup API と外部コネクタを直接呼び出します。プラットフォーム リソース (アーティスト、ソーシャル、組織、リサーチ、ドキュメント) を取得し、コネクタ アクション (Google ドキュメント/スプレッドシート/ドライブ編集、Gmail、TikTok、Instagram) を実行します。 Recoup の生のデータ (プラットフォーム リソース) が必要な場合は、api.recoupable.dev に対して Curl を書き込む場合、または Google Doc URL やスプレッドシートなど Recoup の外部にあるものを読み書きする場合に使用します。配管は他のすべてのスキルに基づいています。アーティストをオンボーディングまたは操作するには、recoup-roster-* スキルを使用します。初回接続には recoup-platform-connect-account を使用します。
