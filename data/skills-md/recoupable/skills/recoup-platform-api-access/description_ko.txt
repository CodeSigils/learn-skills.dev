Recoup API 및 외부 커넥터를 직접 호출하세요. 모든 플랫폼 리소스(아티스트, 소셜 미디어, 조직, 연구, 문서)를 가져오고 커넥터 작업(Google Docs/Sheets/Drive 편집, Gmail, TikTok, Instagram)을 실행하세요. api.recoupable.dev에 대해 컬을 작성하거나 Google 문서 URL 또는 스프레드시트와 같은 Recoup 외부 항목을 읽고 쓰기 위해 플랫폼 리소스인 원시 Recoup 데이터가 필요할 때마다 사용하세요. 다른 모든 기술에는 배관이 적용됩니다. 아티스트를 온보딩하거나 작업하려면 recoup-roster-* 기술을 사용하세요. 처음 실행 연결의 경우 recoup-platform-connect-account를 사용하세요.
