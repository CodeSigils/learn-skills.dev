直接调用 Recoup API 和外部连接器 — 获取任何平台资源（艺术家、社交、组织、研究、文档）并运行连接器操作（Google 文档/表格/云端硬盘编辑、Gmail、TikTok、Instagram）。当您需要原始 Recoup 数据（一种平台资源）时，可以使用它来针对 api.recoupable.dev 编写curl，或者在 Recoup 之外读取/写入某些内容，例如 Google 文档 URL 或电子表格。管道是所有其他技能的基础。要加入艺术家或对艺术家进行操作，请使用 recoup-roster-* 技能；对于首次运行连接，请使用 recoup-platform-connect-account。
