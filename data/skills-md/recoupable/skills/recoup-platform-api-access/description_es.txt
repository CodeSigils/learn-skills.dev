Llame directamente a la API de Recoup y a los conectores externos: obtenga cualquier recurso de la plataforma (artistas, redes sociales, organizaciones, investigaciones, documentos) y ejecute acciones del conector (Google Docs/Sheets/Drive edits, Gmail, TikTok, Instagram). Úselo siempre que necesite datos sin procesar de Recoup, un recurso de plataforma, para escribir curl en api.recoupable.dev o para leer/escribir algo fuera de Recoup, como una URL de Google Doc o una hoja de cálculo. La plomería depende de todas las demás habilidades. Para incorporar u operar a un artista, utilice las habilidades de recuperación-roster-*; para la conexión de primera ejecución, utilice recuperación-plataforma-conexión-cuenta.
