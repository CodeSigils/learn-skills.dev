Вызывайте Recoup API и внешние коннекторы напрямую — извлекайте любой ресурс платформы (художники, социальные сети, организации, исследования, документы) и выполняйте действия коннектора (редактирование в Google Docs/Sheets/Drive, Gmail, TikTok, Instagram). Используйте всякий раз, когда вам нужны необработанные данные Recoup, ресурс платформы, для записи curl на api.recoupable.dev или для чтения/записи чего-либо вне Recoup, например URL-адреса документа Google или электронной таблицы. Сантехника зависит от всех остальных навыков. Чтобы привлечь артиста или воздействовать на него, используйте навыки восстановления-реестра-*; для первого подключения используйте recoup-platform-connect-account.
