Rufen Sie die Recoup-API und externe Konnektoren direkt auf – rufen Sie alle Plattformressourcen (Künstler, soziale Netzwerke, Organisationen, Recherchen, Dokumente) ab und führen Sie Konnektoraktionen aus (Google Docs/Sheets/Drive-Bearbeitungen, Gmail, TikTok, Instagram). Verwenden Sie es immer dann, wenn Sie rohe Recoup-Daten oder eine Plattformressource benötigen, um Curl gegen api.recoupable.dev zu schreiben oder etwas außerhalb von Recoup zu lesen/schreiben, wie eine Google Doc-URL oder eine Tabelle. Die Klempnerarbeit, auf der alle anderen Fertigkeiten basieren. Um einen Künstler einzubinden oder zu betreuen, verwenden Sie die Recoup-Roster-*-Fähigkeiten; Für die erstmalige Verbindung verwenden Sie das Konto „recoup-platform-connect-account“.
