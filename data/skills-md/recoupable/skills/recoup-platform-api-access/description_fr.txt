Appelez directement l'API Recoup et les connecteurs externes : récupérez n'importe quelle ressource de la plate-forme (artistes, réseaux sociaux, organisations, recherche, documents) et exécutez des actions de connecteur (modifications Google Docs/Sheets/Drive, Gmail, TikTok, Instagram). Utilisez-le chaque fois que vous avez besoin de données brutes de Recoup, d'une ressource de plate-forme, pour écrire curl sur api.recoupable.dev, ou pour lire/écrire quelque chose en dehors de Recoup, comme une URL de document Google ou une feuille de calcul. La plomberie, toutes les autres compétences reposent sur elle. Pour intégrer ou opérer un artiste, utilisez les compétences recoup-roster-* ; pour la première connexion, utilisez recoup-platform-connect-account.
