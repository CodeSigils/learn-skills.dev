Überprüfen und zeichnen Sie einen Musikkatalogvertrag von Anfang bis Ende durch – erfassen Sie einen unübersichtlichen Lizenzdatenraum, bewerten Sie ihn (NPS/NLS, Konzentration, Szenarien), erstellen Sie das Executive Dashboard und schreiben Sie das IC-Memo. Verwenden Sie diese Option für „Diesen Katalog prüfen/unterzeichnen“, „Diese Lizenzgebührenabrechnungen bereinigen“, „Katalogbewertung“, „Deal-Dashboard erstellen“ oder „IC-Memo schreiben“. Modi: Überprüfung (Standard), Aufnahme, Wert, Dashboard, Bericht. Benötigt Verkäuferdateien; source/ ist unveränderlich und die Fertigstellung ist begrenzt. Für einen schnellen Wert ausschließlich aus öffentlichen Daten verwenden Sie recoup-catalog-estimate-value.
