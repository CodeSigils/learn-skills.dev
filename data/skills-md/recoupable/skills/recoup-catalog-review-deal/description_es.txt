Revise y suscriba un acuerdo de catálogo de música de principio a fin: absorba una sala de datos de regalías desordenada, valórela (NPS/NLS, concentración, escenarios), cree el panel ejecutivo y escriba el memorando de IC. Úselo para "revisar/suscribir este catálogo", "limpiar estas declaraciones de regalías", "valoración del catálogo", "crear el panel de ofertas" o "escribir el memorando de IC". Modos: revisión (predeterminado), ingesta, valor, panel, informe. Necesita archivos del vendedor; source/ es inmutable y la finalización está cerrada. Para obtener un valor rápido únicamente a partir de datos públicos, utilice el valor estimado del catálogo de recuperación.
