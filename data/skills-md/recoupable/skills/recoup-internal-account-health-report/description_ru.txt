ВНУТРЕННИЙ — инструментарий для персонала восстановления, доступный по ключевому слову recoup-internal. Вызывайте ТОЛЬКО тогда, когда запрос явно включает «внутреннее восстановление» (например, «внутреннее состояние восстановления для этой учетной записи»). Никогда не используйте для запросов клиентов или исполнителей. Создайте снимок состояния/здоровья учетной записи для учетной записи Recoup, используя адрес электронной почты, идентификатор учетной записи или имя исполнителя. Разрешает учетную запись, извлекает ее исполнителей, социальные сети, чаты, запланированные задачи, песочницы, кредиты и подписку, затем создает ACCOUNT.md, дерево ARTIST.md для каждого исполнителя и усовершенствованный PDF-файл со статусом. Используйте, когда вас просят «проверить эту учетную запись», «статус учетной записи», «состояние учетной записи», «как они используют продукт», «какие исполнители/чаты есть в этой учетной записи», «оценить этого пользователя/профиль» или найти адрес электронной почты для входа за исполнителем. Требуется токен Recoup API (токен администратора может проверять любую учетную запись; токен владельца — только свой).
