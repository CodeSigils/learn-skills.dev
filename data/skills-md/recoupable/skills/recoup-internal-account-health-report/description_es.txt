INTERNO: herramientas del personal de recuperación, controladas por la palabra clave interna de recuperación. Invoque SÓLO cuando la solicitud incluya explícitamente "recuperación interna" (por ejemplo, "estado de la cuenta de recuperación interna para esta cuenta"). Nunca lo use para solicitudes de artistas o de cara al cliente. Produzca una instantánea del estado de la cuenta/salud de la cuenta para una cuenta de Recoup a partir de un correo electrónico, ID de cuenta o nombre de artista. Resuelve la cuenta, extrae sus artistas, redes sociales, chats, tareas programadas, sandboxes, créditos y suscripciones, luego genera un ACCOUNT.md, un árbol ARTIST.md por artista y un PDF de estado pulido. Úselo cuando se le solicite "verificar esta cuenta", "estado de la cuenta", "salud de la cuenta", "cómo están usando el producto", "qué artistas/chats tiene esta cuenta", "evaluar este usuario/perfil" o para encontrar el correo electrónico de inicio de sesión detrás de un artista. Requiere un token de API de Recoup (un token de administrador puede inspeccionar cualquier cuenta; un token de propietario solo la suya).
