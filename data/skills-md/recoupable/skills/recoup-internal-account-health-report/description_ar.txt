داخلي - أدوات استرداد الموظفين، مسورة بالكلمة الأساسية الداخلية للاسترداد. يتم الاستدعاء فقط عندما يتضمن الطلب بشكل صريح "استرداد داخلي" (على سبيل المثال، "سلامة حساب الاسترداد الداخلي لهذا الحساب"). لا تستخدم أبدًا لمواجهة العملاء أو طلبات الفنانين. قم بإنتاج لقطة لحالة الحساب / صحة الحساب لحساب الاسترداد من البريد الإلكتروني أو معرف الحساب أو اسم الفنان. يحل الحساب، ويسحب الفنانين ووسائل التواصل الاجتماعي والمحادثات والمهام المجدولة وصناديق الحماية والأرصدة والاشتراكات، ثم ينشئ ACCOUNT.md وشجرة ARTIST.md لكل فنان وملف PDF للحالة المصقولة. استخدمه عندما يُطلب منك "التحقق من هذا الحساب"، أو "حالة الحساب"، أو "حالة الحساب"، أو "كيف يستخدمون المنتج"، أو "ما هو الفنانون / الدردشات التي يمتلكها هذا الحساب"، أو "تقييم هذا المستخدم/الملف الشخصي"، أو للعثور على البريد الإلكتروني لتسجيل الدخول خلف فنان. يتطلب رمز Recoup API المميز (يمكن للرمز المميز للمسؤول فحص أي حساب؛ والرمز المميز للمالك خاص به فقط).
