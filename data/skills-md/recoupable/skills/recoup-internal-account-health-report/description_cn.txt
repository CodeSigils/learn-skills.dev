INTERNAL — Recoup 人员工具，由 recoup-internal 关键字控制。仅当请求明确包含“recoup-internal”（例如“此帐户的recoup-internal 帐户运行状况”）时调用。切勿用于面向客户或艺术家的要求。根据电子邮件、帐户 ID 或艺术家姓名为 Recoup 帐户生成帐户状态/帐户运行状况快照。解析帐户，提取其艺术家、社交、聊天、计划任务、沙箱、积分和订阅，然后生成 ACCOUNT.md、每个艺术家的 ARTIST.md 树和完善的状态 PDF。当被要求“检查此帐户”、“帐户状态”、“帐户运行状况”、“他们如何使用该产品”、“此帐户有哪些艺术家/聊天”、“评估此用户/个人资料”或查找艺术家背后的登录电子邮件时使用。需要 Recoup API 令牌（管理员令牌可以检查任何帐户；所有者令牌只能检查自己的帐户）。
