レーベルの自己管理「音楽会社 OS」を独自の Git リポジトリ内で足場にして実行します。これは、Recoup の規約 (トップレベル) がシードされた完全なラベル インテリジェンス ワークスペース (フォルダー、AGENTS.md にミラーリングされた自己管理 CLAUDE.md、読み取り専用ドクター + 決して古くならない管理者、複合学習と自己改善ループ、インプレース プラグイン) です。 Artists/{slug}/RECOUP.md ID ファイル、releases/{slug}/RELEASE.md)、記録システムとして Recoup API によってサポートされています。 「ラベル OS のセットアップ」、「組織ワークスペースの構築」、「このリポジトリをラベル ブレインに変える」、または新しい組織/ラベル リポジトリのオンボーディングに使用します。ライブ アカウント (recoup-platform-connect-account 経由で認証) から実際の名簿を取得し、recoup-roster-add-artist 経由で API ファーストでアーティストをオンボードし、他の recoup-* スキル (リサーチ/コンテンツ/リリース/ソング/カタログ) を再発明する代わりに呼び出します。単一のワークスペース/OS ビルダー — 軽量の「名簿をフォルダーにミラーリングするだけ」のケースもカバーします。
