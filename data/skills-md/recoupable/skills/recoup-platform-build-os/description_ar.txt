دعم وتشغيل "نظام تشغيل شركة الموسيقى" الذي يُدير نفسه ذاتيًا داخل git repo الخاص به - مساحة العمل الكاملة لذكاء التسمية (المجلدات، وCLAUDE.md ذاتي الإدارة معكوس على AGENTS.md، وطبيب للقراءة فقط + بواب لا قديم أبدًا، وحلقات للتعلم المركب والتحسين الذاتي، ومكون إضافي في المكان) مُصنفة مع اتفاقيات Recoup (المستوى الأعلى) ملفات هوية الفنانين/{slug}/RECOUP.md، والإصدارات/{slug}/RELEASE.md) ومدعومة بواسطة Recoup API كنظام تسجيل. استخدمه من أجل "إعداد نظام التشغيل الخاص بنا"، أو "إنشاء مساحة عمل المؤسسة"، أو "تحويل هذا الريبو إلى عقل التسمية الخاص بنا"، أو إعداد مستودع مؤسسة/تصنيف جديد. يسحب القائمة الحقيقية من الحساب المباشر (المصادقة عبر حساب recoup-platform-connect-account)، ويدمج واجهة برمجة تطبيقات الفنانين أولاً عبر recoup-roster-add-artist، ويستدعي مهارات الاسترداد الأخرى (البحث/المحتوى/الإصدار/الأغنية/الكتالوج) بدلاً من إعادة اختراعها. يغطي أيضًا منشئ مساحة العمل/نظام التشغيل الفردي الحالة خفيفة الوزن "فقط قم بنسخ القائمة الخاصة بي في المجلدات".
