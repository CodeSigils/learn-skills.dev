Создайте и запустите самоуправляемую «ОС музыкальной компании» лейбла внутри его собственного git-репозитория — полного рабочего пространства для анализа лейбла (папки, самоуправляемый файл CLAUDE.md, зеркально отраженный в AGENTS.md, доступный только для чтения врач + никогда не устаревающий уборщик, циклы сложного обучения и самосовершенствования, плагин на месте), засеянный соглашениями Recoup (верхний уровень). Artists/{slug}/RECOUP.md файлы идентификации, Releases/{slug}/RELEASE.md) и поддерживаются Recoup API в качестве системы записи. Используйте для «настройки нашей ОС для ярлыков», «создания рабочего пространства организации», «превратите этот репозиторий в наш мозг для ярлыков» или для подключения нового репозитория организации/лейбла. Извлекает реальный состав из реальной учетной записи (аутентификация через recoup-platform-connect-account), сначала подключает API артистов через recoup-roster-add-artist и вызывает другие навыки recoup-* (исследования/контент/релиз/песня/каталог) вместо того, чтобы изобретать их заново. Единый конструктор рабочего пространства/ОС также охватывает легкий вариант «просто отразить мой список в папках».
