INTERN – Recoup-Mitarbeitertools, gesteuert durch das Schlüsselwort „recoup-internal“. NUR aufrufen, wenn die Anfrage explizit „recoup-internal“ enthält (z. B. „recoup-internal auf diesen Upwork-Job anwenden“). Niemals für Kunden- oder Künstleranfragen verwenden. Finden, gewinnen und schließen Sie Upwork-Vertragsarbeiten von Anfang bis Ende ab: Führen Sie die tägliche Pipeline durch, prüfen Sie einen Kunden, bevor Sie etwas schreiben, überprüfen Sie jeden Anspruch anhand der tatsächlichen Repositories, entwerfen Sie das Anschreiben und die Screening-Antworten, wählen Sie das richtige Arbeitsprobenpaket aus, legen Sie den Tarif fest, verfolgen Sie dann nach, bearbeiten Sie die Antwort, führen Sie den Anruf durch und wandeln Sie einen Test in laufende Arbeit um. Wird verwendet, wenn Sie gefragt werden: „Bewerben Sie sich auf diesen Upwork-Job“, „Schreiben Sie ein Upwork-Angebot“, „Soll ich darauf bieten“, „Triage diesen Kunden“, „Ist dieser Job eine Kontaktaufnahme wert“, „Finden Sie Upwork-Jobs, auf die sich eine Bewerbung lohnt“, „Laufen Sie die Upwork-Pipeline“, „Ein Kunde hat geantwortet“, „Vorbereiten Sie sich auf den Kundenanruf“, „Verfolgen Sie meine Vorschläge“, „Warum wird nichts konvertiert“ oder wenn eine Upwork-Stellenausschreibung eingefügt wird. Erfordert ein lokales Workspace-Verzeichnis und Lesezugriff darauf Repositories hinter jeglichen Ansprüchen.
