Planen und führen Sie eine Musikveröffentlichung durchgängig durch – rüsten Sie den Arbeitsbereich aus, schreiben Sie das kreative Briefing, erstellen Sie den datierten Rollout-Zeitplan, erstellen Sie das Master-RELEASE.md + DSP-Pitch + One-Sheet, Ziel-Playlists und Armüberwachung. Verwenden Sie diese Option für „Veröffentlichung starten/planen“, „[Titel] von Anfang bis Ende übernehmen“, „kreatives Briefing“, „Rollout-Zeitplan“ oder „RELEASE.md / DSP-Pitch / Einzelblatt“. Modi: Plan (Standard, vollständiger Workflow), Briefing, Kampagne, Dokument. Alles landet in releases/{artist}/{release}/. Um den Drop anschließend zu bestätigen, verwenden Sie recoup-release-track-drop.
