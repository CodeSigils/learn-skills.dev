Come lavorare nelle directory degli artisti. Da utilizzare quando si aggiunge o si aggiorna il contesto dell'artista (identità, marchio, voce, pubblico), si aggiungono brani, si organizzano file all'interno di una directory di artista o si capisce a chi appartiene qualcosa. Da utilizzare anche quando l'utente menziona un artista per nome e l'attività coinvolge i suoi file, contesto o contenuti, anche se non dice "directory dell'artista". Ciò include attività come la ricerca di un artista, la creazione di contenuti per un artista, l'aggiornamento del marchio di un artista o l'aggiunta di una guida ai volti.
