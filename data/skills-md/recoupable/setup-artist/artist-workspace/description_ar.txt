كيفية العمل في أدلة الفنانين. يُستخدم عند إضافة أو تحديث سياق الفنان (الهوية أو العلامة التجارية أو الصوت أو الجمهور)، أو إضافة الأغاني، أو تنظيم الملفات داخل دليل الفنان، أو معرفة مكان وجود شيء ما. يُستخدم أيضًا عندما يذكر المستخدم فنانًا بالاسم وتتضمن المهمة ملفاته أو سياقه أو محتواه - حتى لو لم يذكر "دليل الفنان". يتضمن ذلك مهام مثل البحث عن فنان، أو إنشاء محتوى لفنان، أو تحديث العلامة التجارية للفنان، أو إضافة دليل للوجه.
