Создайте полный пакет заголовков и миниатюр для YouTube из контента видео — извлекайте зацепки из расшифровки, записывайте комбинации заголовка/миниатюры и текста, настраивайте их на потенциальную кликабельность, а затем создавайте фотореалистичные миниатюры с помощью моделей изображений Google Nano Banana, используя реальные снимки головы и прошлые миниатюры в качестве эталонов стиля. Вызовите «Создать миниатюру», «Миниатюру для этого эпизода/видео», «Упаковку YouTube», «Идеи названия для этого видео», «Идеи названия и миниатюры», «Создать миниатюры с помощью нанобанана». Запросы только заголовков используют шаги 1–2 и пропускают генерацию. Не для аудита стратегии канала или создания имиджа общего назначения.
