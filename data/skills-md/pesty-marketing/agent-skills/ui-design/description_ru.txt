Применяйте фреймворки Master UI Design + Practice UI для создания или аудита дизайна интерфейса (компоненты, макеты, типографика, цвет, формы, кнопки, навигация, копирайтинг). Вызывается, когда пользователь говорит «использовать пользовательский интерфейс», «проверить этот пользовательский интерфейс», «проверить дизайн» или просит помочь в создании/улучшении интерфейса, компонента или экрана. Общего назначения (не специфичного для Pesty; для этого используйте навык Pesty-design).
