Appliquez les frameworks Master UI Design + Practical UI pour créer ou auditer les conceptions d'interfaces (composants, mises en page, typographie, couleur, formulaires, boutons, navigation, rédaction). Invoquer lorsque l'utilisateur dit « utiliser ui-design », « auditer cette interface utilisateur », « réviser la conception » ou demande de l'aide pour créer/améliorer une interface, un composant ou un écran. Usage général (non spécifique à Pesty ; utilisez la compétence pesty-design pour cela).
