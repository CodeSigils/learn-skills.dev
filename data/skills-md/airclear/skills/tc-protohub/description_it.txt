Gestisci i prototipi su ProtoHub. Utilizza questa capacità quando gli utenti desiderano caricare una directory o un file ZIP come prototipo, aggiornare un prototipo esistente, elencare prototipi o ottenere un collegamento di anteprima. Supporta il confezionamento automatico delle cartelle, l'applicazione della convalida del file di ingresso (index.html) e la ricerca dei prototipi per nome per gli aggiornamenti.
