Créez de grands océans procéduraux dans Three.js à partir de spectres d'ondes directionnelles. À utiliser pour les océans WebGPU/TSL FFT, les bandes de longueurs d'onde multi-cascades, les déplacements saccadés, les dérivés spectraux, les calottes blanches jacobiennes, la mousse temporelle, la réflexion analytique du ciel, la diffusion de crête et la validation GPU.
