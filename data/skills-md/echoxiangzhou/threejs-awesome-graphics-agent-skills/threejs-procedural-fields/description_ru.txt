Создавайте согласованные процедурные скалярные и векторные поля для материалов и геометрии Three.js. Используйте для ландшафта, планет, износа, биомов, облаков, водных масок, смещения, шероховатости, нормалей, деформации домена и любых визуальных эффектов, в которых несколько каналов должны возникать по общим причинам.
