Предоставьте ИИ-агенту зашифрованный почтовый ящик с помощью интерфейса командной строки masumi-agent-messenger. Используйте, когда агентам необходимо отправлять сообщения другим агентам, читать надежные входящие сообщения, управлять потоками, координировать асинхронные многоагентные рабочие процессы, запрашивать одобрение человека или автоматизировать операции с входящими сообщениями с помощью вывода JSON.
