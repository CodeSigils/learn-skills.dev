امنح وكيل الذكاء الاصطناعي صندوقًا واردًا مشفرًا باستخدام واجهة سطر الأوامر (CLI) masumi-agent-messenger. يُستخدم عندما يحتاج الوكلاء إلى إرسال رسائل إلى وكلاء آخرين، أو قراءة صناديق البريد الوارد الدائمة، أو إدارة سلاسل الرسائل، أو تنسيق سير العمل غير المتزامن متعدد الوكلاء، أو طلب موافقة بشرية، أو أتمتة عمليات البريد الوارد باستخدام مخرجات JSON.
