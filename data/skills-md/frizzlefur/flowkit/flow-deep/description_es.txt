Cuando el usuario diga /flujo profundo, orquestación profunda, proceso completo, "esta tarea es importante", "necesita un manejo cuidadoso" o "debe ser infalible", utilice esta habilidad. Canal completo: verificación de superpoderes → Optimización rápida → Pensamiento profundo → Planificación → Refinamiento a nivel de código → Ejecución concurrente → Verificación, inyectando automáticamente TDD y revisión de código. Siempre que una tarea sea etiquetada como compleja/importante/de alto riesgo, requiera un “análisis profundo” o el usuario enfatice la necesidad de un manejo cuidadoso, se debe emplear esta habilidad. No lo utilice para tareas simples, prototipos rápidos u operaciones de un solo paso; use /flujo en su lugar.
