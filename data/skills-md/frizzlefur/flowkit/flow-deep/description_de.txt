Wenn der Benutzer sagt: „/flow-deep, tiefe Orchestrierung, vollständige Pipeline“, „diese Aufgabe ist wichtig“, „bedarf einer sorgfältigen Handhabung“ oder „muss narrensicher sein“, verwenden Sie diese Fähigkeit. Vollständige Pipeline: Überprüfung der Superkräfte → Sofortige Optimierung → Tiefes Denken → Planung → Verfeinerung auf Codeebene → Gleichzeitige Ausführung → Verifizierung, automatische Einführung von TDD und Codeüberprüfung. Immer wenn eine Aufgabe als komplex/wichtig/risikoreich eingestuft wird, eine „tiefgreifende Analyse“ erfordert oder der Benutzer die Notwendigkeit einer sorgfältigen Handhabung betont, sollte diese Fähigkeit eingesetzt werden. Verwenden Sie es nicht für einfache Aufgaben, schnelle Prototypen oder Einzelschrittvorgänge; Verwenden Sie stattdessen /flow.
