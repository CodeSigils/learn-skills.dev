사용자가 /flow-deep, 심층 오케스트레이션, 전체 파이프라인, "이 작업은 중요합니다", "신중한 처리가 필요합니다" 또는 "완벽해야 합니다"라고 말할 때 이 기술을 사용하세요. 전체 파이프라인: 초능력 확인 → 신속한 최적화 → 심층적 사고 → 계획 → 코드 수준 개선 → 동시 실행 → 검증, TDD 및 코드 검토 자동 주입. 작업이 복잡/중요/고위험으로 분류되거나 "심층 분석"이 필요하거나 사용자가 신중한 처리의 필요성을 강조할 때마다 이 기술을 사용해야 합니다. 간단한 작업, 빠른 프로토타입 또는 단일 단계 작업에는 사용하지 마십시오. 대신 /flow를 사용하세요.
