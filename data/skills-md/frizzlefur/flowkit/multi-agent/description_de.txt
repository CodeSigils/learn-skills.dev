Engine zur Generierung und Ausführung von Agent Teams-Lösungen. Parallele Verteilung mehrerer Agententeams (im Hintergrund ausgeführte Subagenten) über die Agent(name)+SendMessage(to:name)-Toolchain; Erhalten Sie automatisch eine Split-Screen-Visualisierung, wenn Sie sich in tmux befinden und ein Bereich verfügbar ist, und führen Sie ein stillschweigendes Downgrade auf Nicht-Split-Screen-Parallelität durch, wenn der Bereich ausfällt oder tmux nicht vorhanden ist (keine vorausgesetzten Abhängigkeiten erforderlich). Wenn der Benutzer /MultiAgent sagt: „Unteragenten auffächern“, „auffächern“, „ein Team senden“, „Agent“, „团队协作“, „并行处理“, „Teamkollege“, „创建agent团队“, „派团队“, „扇出“, „并行深挖“, „派几个agent分头调研“, „gräbt tief“, „每个都深挖“, „别漏掉任何东西“, dieser Skill wird verwendet – bereits eine einzige Phrase wie „Fan-Out-Subagenten“ sollte den Skill auslösen (schreibgeschützte Aufgaben nutzen den Fast Path für den direkten Versand, Schreibaufgaben durchlaufen die vollständige Planbestätigung). Unterstützt Kontextbewusstsein auf Projektebene, gemeinsame Planerstellung, Shard-Coverage-Akzeptanz (nichts verpasst) und Umgebungsanpassung.
