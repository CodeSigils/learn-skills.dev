Механизм генерации и выполнения решений Agent Teams. Параллельное распределение нескольких команд агентов (субагенты работают в фоновом режиме) через цепочку инструментов Agent(name)+SendMessage(to:name); автоматически получать визуализацию с разделенным экраном, когда внутри tmux и доступна панель, автоматически переходить к параллельному использованию без разделения экрана, когда панель выходит из строя или tmux отсутствует (предварительные зависимости не требуются). Когда пользователь произносит /MultiAgent, «разветвление субагентов», «разветвление», «отправляет команду», «多agent», «团队协作», «并行处理», «товарищ по команде», «创建agent团队», «派团队», «扇出», «并行深挖», «派几个agent分头调研», «копает глубоко», «每个都深挖», «别漏掉任何东西», этот навык используется — даже одна фраза, например «разветвление субагентов», должна активировать навык (задачи только для чтения используют быстрый путь для прямого отправка, запись задач проходит полное подтверждение плана). Поддерживает понимание контекста на уровне проекта, совместное создание планов, принятие сегментного покрытия (ничего не пропущенного) и адаптацию к среде.
