Agent Teams 솔루션 생성 및 실행 엔진. Agent(name)+SendMessage(to:name) 툴체인을 통해 여러 에이전트 팀(백그라운드에서 실행되는 하위 에이전트)의 병렬 배포. tmux 내부 및 창이 사용 가능한 경우 분할 화면 시각화를 자동으로 얻고, 창이 실패하거나 tmux가 없으면(전제 조건 종속성이 필요하지 않음) 비분할 화면 동시성으로 자동으로 다운그레이드합니다. 사용자가 /MultiAgent, "하위 에이전트 팬아웃", "팬아웃", "팀 보내기", "多agent", "团队协작품", "并行处理", "teammate", "创建agent团队", "派团队", "扇ude", "并行深挖"라고 말하면, "派几个agent分头调研", "digs deep", "每个島深挖", "别漏掉任何东西", 이 기술이 사용됩니다. "하위 에이전트 팬 아웃"과 같은 단일 문구라도 기술을 트리거해야 합니다(읽기 전용 작업은 직접 파견을 위해 빠른 경로를 사용하고, 쓰기 작업은 전체 계획 확인을 거침). 프로젝트 수준 상황 인식, 협업 계획 생성, 샤드 적용 범위 수용(누락 없음) 및 환경 적응을 지원합니다.
