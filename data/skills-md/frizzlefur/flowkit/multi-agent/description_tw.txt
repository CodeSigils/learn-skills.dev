Agent 團隊解決方案生成與執行引擎。透過 Agent(name) + SendMessage(to: name) 工具鏈，平行分配多個 agent 團隊（子代理在背景執行）；當在 tmux 且有可用窗格時，自動取得分割畫面可視化，若窗格失效或缺少 tmux，則靜默降級為非分割畫面並行（無需前置依賴）。當使用者說出 /MultiAgent、「fan out subagents」、「fan out」、「sends a team」、「多agent」、「團隊協作」、「並行處理」、「teammate」、「建立 agent 團隊」、「派遣團隊」、「扇出」、「並行深挖」、「派幾個 agent 分頭調研」、「digs deep」、「每個都深挖」、「別漏掉任何東西」時，即會使用此技能——即使只有「fan out subagents」這樣的單一詞組也應觸發（只讀任務走快速路徑直接分派，寫入任務則需完整計畫確認）。支援專案層級的情境感知、協作計畫生成、分片覆蓋接受（不遺漏任何項目），以及環境適應。
