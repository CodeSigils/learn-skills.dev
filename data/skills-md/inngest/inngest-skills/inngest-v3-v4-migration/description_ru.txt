Используйте при обновлении существующей базы кода TypeScript с Inngest SDK v3 до v4 или при исправлении смешанного использования API v3/v4. Охватывает обнаружение текущего использования SDK, перемещение триггеров в параметры createFunction, замену EventSchemas на eventType/staticSchema, перемещение параметров обслуживания клиенту, обновление импорта в реальном времени, перезапись идентификаторов строк шага вызова, настройки контрольных точек/бессерверной среды выполнения, изменения параметров подключения и проверку.
