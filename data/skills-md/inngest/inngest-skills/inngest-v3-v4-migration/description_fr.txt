À utiliser lors de la mise à niveau d'une base de code TypeScript existante du SDK Inngest v3 vers la v4, ou lors de la correction d'une utilisation mixte de l'API v3/v4. Couvre la détection de l'utilisation actuelle du SDK, le déplacement des déclencheurs dans les options createFunction, le remplacement d'EventSchemas par eventType/staticSchema, le déplacement des options de service vers le client, la mise à jour des importations en temps réel, la réécriture des ID de chaîne step.invoke, les paramètres de point de contrôle/d'exécution sans serveur, les modifications des options de connexion et la vérification.
