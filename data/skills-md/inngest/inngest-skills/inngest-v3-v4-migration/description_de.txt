Verwenden Sie diese Option, wenn Sie eine vorhandene TypeScript-Codebasis von Inngest SDK v3 auf v4 aktualisieren oder wenn Sie die gemischte v3/v4-API-Nutzung beheben. Behandelt das Erkennen der aktuellen SDK-Nutzung, das Verschieben von Triggern in createFunction-Optionen, das Ersetzen von EventSchemas durch eventType/staticSchema, das Verschieben von Serve-Optionen auf den Client, das Aktualisieren von Echtzeitimporten, das Umschreiben von Step.invoke-String-IDs, Checkpointing/serverlose Laufzeiteinstellungen, Connect-Optionsänderungen und die Überprüfung.
