يُستخدم عند ترقية قاعدة بيانات TypeScript الموجودة من Inngest SDK v3 إلى v4، أو عند إصلاح استخدام v3/v4 API المختلط. يغطي الكشف عن استخدام SDK الحالي، ونقل المشغلات إلى خيارات createFunction، واستبدال EventSchemas بـ eventsType/staticSchema، ونقل خيارات الخدمة إلى العميل، وتحديث عمليات الاستيراد في الوقت الفعلي، وإعادة كتابة معرفات سلسلة step.invocation، وإعدادات وقت التشغيل / التحقق بدون خادم، وتغييرات خيار الاتصال، والتحقق.
