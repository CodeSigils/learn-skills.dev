Da utilizzare quando si aggiorna una codebase TypeScript esistente da Inngest SDK v3 a v4 o quando si corregge l'utilizzo misto dell'API v3/v4. Riguarda il rilevamento dell'utilizzo corrente dell'SDK, lo spostamento dei trigger nelle opzioni createFunction, la sostituzione di EventSchemas con eventType/staticSchema, lo spostamento delle opzioni di servizio sul client, l'aggiornamento delle importazioni in tempo reale, la riscrittura degli ID di stringa step.invoke, le impostazioni di checkpoint/runtime serverless, le modifiche alle opzioni di connessione e la verifica.
