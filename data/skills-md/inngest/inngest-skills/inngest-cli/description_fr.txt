À utiliser lors de l'installation ou de l'exécution d'Inngest CLI et de Dev Server pour le développement local, les tests locaux, le débogage des points de terminaison de service, la configuration de Docker ou Docker Compose, la configuration MCP, le « démarrage inngest » auto-hébergé ou les vérifications du flux de travail de déploiement. Couvre « inngest dev », « inngest start », la découverte automatique, les fichiers de configuration, les variables d'environnement, « @inngest/test », l'envoi d'événements locaux, les pièges de la plate-forme et les indicateurs de serveur de production/auto-hébergé.
