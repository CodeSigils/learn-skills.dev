Используйте при установке или запуске Inngest CLI и Dev Server для локальной разработки, локального тестирования, отладки конечной точки обслуживания, настройки Docker или Docker Compose, настройки MCP, самостоятельного запуска inngest или проверки рабочего процесса развертывания. Охватывает `inngest dev`, `inngest start`, автоматическое обнаружение, файлы конфигурации, переменные среды, `@inngest/test`, отправку локальных событий, ошибки платформы и флаги производственного/самостоятельного сервера.
