Da utilizzare durante l'installazione o l'esecuzione di Inngest CLI e Dev Server per lo sviluppo locale, i test locali, il debug degli endpoint, l'installazione di Docker o Docker Compose, la configurazione MCP, l'"avvio inngest" self-hosted o i controlli del flusso di lavoro di distribuzione. Copre "inngest dev", "inngest start", rilevamento automatico, file di configurazione, variabili di ambiente, "@inngest/test", invio di eventi locali, trucchi della piattaforma e flag di server di produzione/hosting autonomo.
