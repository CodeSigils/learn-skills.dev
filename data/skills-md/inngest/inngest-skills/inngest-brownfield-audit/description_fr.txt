À utiliser lors de l'analyse d'une base de code TypeScript ou JavaScript existante pour décider où et comment introduire Inngest. Couvre la découverte de référentiels, la détection de frameworks et de packages, la recherche de lacunes de durabilité dans les gestionnaires HTTP, les webhooks, les tâches cron, les files d'attente, les tâches de longue durée, les agents IA, les boucles d'interrogation et le code lourd en effets secondaires, puis la production et la mise en œuvre d'un plan d'intégration incrémentiel.
