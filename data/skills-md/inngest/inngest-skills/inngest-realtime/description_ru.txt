Используйте при потоковой передаче устойчивых обновлений рабочего процесса в пользовательский интерфейс в режиме реального времени — страницы состояния заказов в реальном времени, которые анимируются по мере выполнения шагов, потоковая передача токенов агента AI из функции в браузер, отслеживание журналов для длительно выполняющихся заданий или потоки утверждения человеком в цикле, которые публикуют приглашение и ждут ответа пользователя. Охватывает встроенный код реального времени Inngest v4: определение типизированных каналов, публикацию изнутри Step.run, создание токенов подписки с помощью действий сервера и использование потока из клиентских компонентов React/Next.js.
