استخدمه عند تشغيل موارد Inngest API من الوحدة الطرفية باستخدام `npx inngest-cli@latest api`: تصحيح أخطاء التشغيل السحابي/المحلي، والبحث عن تشغيل الحدث، وتتبعات الوظائف، واستدعاء الوظائف، ومزامنة التطبيقات، وخطافات الويب، والبيئات، والمفاتيح، وعمليات التحقق من الحساب، واستعلامات Insights. يوفر توجيه أوامر إرشادية للوكلاء: ما هو أمر CLI الذي سيتم تشغيله لمعرف التشغيل، أو معرف الحدث، أو معرف التطبيق، أو معرف الوظيفة، أو بيئة السحابة، أو مفتاح واجهة برمجة التطبيقات، أو المعرف المفقود، أو العملية المحتملة للتغيير. استخدم `inngest-cli` لإعداد خادم التطوير/سير عمل CLI العام و`inngest-api` فقط عند الحاجة إلى مستندات REST API v2 الأولية أو احتياطي OpenAPI.
