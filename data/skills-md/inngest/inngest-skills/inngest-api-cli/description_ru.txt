Используйте при работе с ресурсами Inngest API из терминала с помощью `npx inngest-cli@latest api`: отладка облачного/локального запуска, поиск при запуске событий, трассировки функций, вызов функций, синхронизация приложений, веб-перехватчики, среды, ключи, проверки учетных записей и запросы Insights. Обеспечивает предписывающую маршрутизацию команд для агентов: какую команду CLI следует выполнить для идентификатора запуска, идентификатора события, идентификатора приложения, идентификатора функции, облачной среды, ключа API, отсутствующего идентификатора или потенциально изменяющейся операции. Используйте inngest-cli для настройки сервера разработки/общих рабочих процессов CLI, а inngest-api — только тогда, когда необходимы необработанные документы REST API v2 или резервный вариант OpenAPI.
