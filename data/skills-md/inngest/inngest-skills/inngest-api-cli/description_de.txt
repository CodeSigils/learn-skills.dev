Verwendung beim Betrieb von Inngest-API-Ressourcen vom Terminal aus mit „npx inngest-cli@latest api“: Debuggen in der Cloud/lokaler Ausführung, Ereignislaufsuche, Funktionsablaufverfolgungen, Funktionsaufrufe, App-Synchronisierungen, Webhooks, Umgebungen, Schlüssel, Kontoprüfungen und Insights-Abfragen. Bietet präskriptive Befehlsweiterleitung für Agenten: Welcher CLI-Befehl soll für eine Ausführungs-ID, Ereignis-ID, App-ID, Funktions-ID, Cloud-Umgebung, API-Schlüssel, fehlende ID oder einen möglicherweise mutierenden Vorgang ausgeführt werden? Verwenden Sie „inngest-cli“ für die Einrichtung des Entwicklungsservers/allgemeine CLI-Workflows und „inngest-api“ nur, wenn unformatierte REST API v2-Dokumente oder OpenAPI-Fallback erforderlich sind.
