`npx inngest-cli@latest api` を使用してターミナルから Ingest API リソースを操作する場合に使用します: クラウド/ローカル実行デバッグ、イベント実行ルックアップ、関数トレース、関数呼び出し、アプリ同期、Webhook、環境、キー、アカウント チェック、および Insights クエリ。エージェントに規範的なコマンド ルーティングを提供します。実行 ID、イベント ID、アプリ ID、関数 ID、クラウド環境、API キー、欠落している ID、または変更される可能性のある操作に対してどの CLI コマンドを実行するかです。開発サーバーのセットアップ/一般的な CLI ワークフローには「ingest-cli」を使用し、生の REST API v2 ドキュメントまたは OpenAPI フォールバックが必要な場合にのみ「inngest-api」を使用します。
