À utiliser lors de l'utilisation des ressources de l'API Inngest à partir du terminal avec `npx inngest-cli@latest api` : débogage d'exécution cloud/local, recherche d'exécution d'événements, traces de fonction, appel de fonction, synchronisations d'applications, webhooks, environnements, clés, vérifications de compte et requêtes Insights. Fournit un routage de commandes prescriptif pour les agents : quelle commande CLI exécuter pour un ID d'exécution, un ID d'événement, un ID d'application, un ID de fonction, un environnement cloud, une clé API, un ID manquant ou une opération potentiellement en mutation. Utilisez « inngest-cli » pour la configuration du serveur de développement/les workflows CLI généraux et « inngest-api » uniquement lorsque des documents bruts de l'API REST v2 ou une solution de secours OpenAPI sont nécessaires.
