Da utilizzare quando si utilizzano le risorse API Inngest dal terminale con `npx inngest-cli@latest api`: debug di esecuzione cloud/locale, ricerca di esecuzione di eventi, tracce di funzioni, invocazione di funzioni, sincronizzazioni di app, webhook, ambienti, chiavi, controlli di account e query Insights. Fornisce l'instradamento prescrittivo dei comandi per gli agenti: quale comando CLI eseguire per un ID esecuzione, ID evento, ID app, ID funzione, ambiente cloud, chiave API, ID mancante o operazione potenzialmente mutante. Utilizza "inngest-cli" per la configurazione del server di sviluppo/flussi di lavoro generali della CLI e "inngest-api" solo quando sono necessari documenti grezzi dell'API REST v2 o fallback OpenAPI.
