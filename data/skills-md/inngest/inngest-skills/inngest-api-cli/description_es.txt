Úselo cuando opere recursos de la API de Inngest desde la terminal con `npx inngest-cli@latest api`: depuración de ejecución local/en la nube, búsqueda de ejecución de eventos, seguimientos de funciones, invocación de funciones, sincronizaciones de aplicaciones, webhooks, entornos, claves, comprobaciones de cuentas y consultas de Insights. Proporciona enrutamiento de comandos prescriptivo para los agentes: qué comando CLI ejecutar para un ID de ejecución, ID de evento, ID de aplicación, ID de función, entorno de nube, clave API, ID faltante o operación potencialmente mutante. Utilice `inngest-cli` para la configuración del servidor de desarrollo/flujos de trabajo CLI generales y `inngest-api` solo cuando se necesiten documentos sin formato de API REST v2 o respaldo de OpenAPI.
