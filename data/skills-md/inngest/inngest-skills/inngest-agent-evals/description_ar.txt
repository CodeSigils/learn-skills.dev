يُستخدم عند إنشاء Agent Evals أو ترحيله أو تصحيح أخطاء Agent Evals على Inngest: تسجيل نتائج وكيل الذكاء الاصطناعي أو نتائج سير العمل، أو المسجلين المؤجلين، أو الجلسات، أو التتبعات، أو تجارب الخطوات، أو إسناد متغيرات التجربة، أو استعلامات Insights، أو حلقات تقييم الإنتاج للمطالبات والنماذج والأدوات والموفرين وسلوك الوكيل. يغطي واجهات برمجة التطبيقات التجريبية لـ TypeScript SDK v4، و`scoreMiddleware`، و`step.score`، و`inngest.score`، و`createScorer`، و`defer`، و`group.experiment`، و`experimentRef`، و`meta.sessions`، ومتى يتم استخدام أوليات سير العمل المتينة للتقييم القائم على النتائج.
