Úselo al crear, migrar o depurar evaluaciones de agentes en Inngest: calificar resultados de flujo de trabajo o agentes de IA, calificadores diferidos, sesiones, seguimientos, experimentos de pasos, atribución de variantes de experimentos, consultas de Insights o bucles de evaluación de producción para indicaciones, modelos, herramientas, proveedores y comportamiento de los agentes. Cubre las API beta de puntuación del SDK v4 de TypeScript, `scoreMiddleware`, `step.score`, `inngest.score`, `createScorer`, `defer`, `group.experiment`, `experimentRef`, `meta.sessions` y cuándo usar primitivas de flujo de trabajo duraderas para la evaluación basada en resultados.
