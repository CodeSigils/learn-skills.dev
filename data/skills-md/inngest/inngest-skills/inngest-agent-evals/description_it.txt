Da utilizzare durante la creazione, la migrazione o il debug delle valutazioni degli agenti su Inngest: punteggio dell'agente AI o dei risultati del flusso di lavoro, marcatori differiti, sessioni, tracce, esperimenti in passaggi, attribuzione di varianti dell'esperimento, query di insight o cicli di valutazione di produzione per prompt, modelli, strumenti, provider e comportamento dell'agente. Riguarda le API beta per il punteggio di TypeScript SDK v4, `scoreMiddleware`, `step.score`, `inngest.score`, `createScorer`, `defer`, `group.experiment`, `experimentRef`, `meta.sessions` e quando utilizzare primitive del flusso di lavoro durevoli per la valutazione basata sui risultati.
