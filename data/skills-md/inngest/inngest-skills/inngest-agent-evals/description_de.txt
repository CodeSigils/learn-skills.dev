Verwendung beim Erstellen, Migrieren oder Debuggen von Agentenbewertungen auf Inngest: Bewerten von KI-Agenten- oder Workflow-Ergebnissen, verzögerten Scorern, Sitzungen, Ablaufverfolgungen, Schrittexperimenten, Zuordnung von Experimentvarianten, Insights-Abfragen oder Produktionsbewertungsschleifen für Eingabeaufforderungen, Modelle, Tools, Anbieter und Agentenverhalten. Behandelt die Scoring-Beta-APIs von TypeScript SDK v4, „scoreMiddleware“, „step.score“, „inngest.score“, „createScorer“, „defer“, „group.experiment“, „experimentRef“, „meta.sessions“ und wann dauerhafte Workflow-Grundelemente für die ergebnisbasierte Bewertung verwendet werden sollten.
