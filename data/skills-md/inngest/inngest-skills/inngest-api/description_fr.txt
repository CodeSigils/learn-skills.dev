À utiliser lorsque l'utilisateur demande explicitement l'API REST Inngest v2, le HTTP brut, l'OpenAPI, la documentation API, l'authentification API ou un point de terminaison que la CLI Inngest n'expose pas. Couvre api-docs.inngest.com, llms.txt, la spécification OpenAPI v2, l'authentification du porteur avec des clés API ou des clés de signature, les URL de production et de base locales, les requêtes curl/fetch brutes, la découverte de la forme de la requête, la pagination, la rédaction secrète et quand préférer la compétence « inngest-api-cli » à la place.
