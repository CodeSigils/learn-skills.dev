Используйте, когда пользователь явно запрашивает Inngest REST API v2, необработанный HTTP, OpenAPI, документацию API, аутентификацию API или конечную точку, которую Inngest CLI не предоставляет. Охватывает api-docs.inngest.com, llms.txt, спецификацию OpenAPI v2, аутентификацию носителя с помощью ключей API или ключей подписи, производственные и локальные базовые URL-адреса, необработанные запросы на скручивание/выборку, обнаружение формы запроса, нумерацию страниц, секретное редактирование, а также когда вместо этого следует предпочесть навык `inngest-api-cli`.
