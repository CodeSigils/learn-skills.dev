Da utilizzare quando l'utente richiede esplicitamente Inngest REST API v2, HTTP raw, OpenAPI, documenti API, autenticazione API o un endpoint che la CLI Inngest non espone. Copre api-docs.inngest.com, llms.txt, le specifiche OpenAPI v2, l'autenticazione Bearer con chiavi API o chiavi di firma, produzione e URL di base locali, richieste curl/recupero non elaborate, rilevamento della forma della richiesta, impaginazione, redazione segreta e quando preferire invece la competenza `inngest-api-cli`.
