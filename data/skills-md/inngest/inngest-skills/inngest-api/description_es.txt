Úselo cuando el usuario solicita explícitamente Inngest REST API v2, HTTP sin formato, OpenAPI, documentos API, autenticación de API o un punto final que Inngest CLI no expone. Cubre api-docs.inngest.com, llms.txt, la especificación OpenAPI v2, autenticación de portador con claves API o claves de firma, URL base local y de producción, solicitudes de curl/fetch sin formato, descubrimiento de forma de solicitud, paginación, redacción secreta y cuándo preferir la habilidad `inngest-api-cli`.
