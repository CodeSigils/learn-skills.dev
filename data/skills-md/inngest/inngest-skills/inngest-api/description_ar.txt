يُستخدم عندما يطلب المستخدم صراحةً إصدار Inngest REST API v2، أو HTTP الخام، أو OpenAPI، أو مستندات API، أو مصادقة API، أو نقطة النهاية التي لا يكشفها Inngest CLI. يغطي api-docs.inngest.com، وllms.txt، ومواصفات OpenAPI v2، ومصادقة Bearer باستخدام مفاتيح API أو مفاتيح التوقيع، وعناوين URL الأساسية للإنتاج والمحلية، وطلبات الجلب/الجلب الأولية، واكتشاف شكل الطلب، وترقيم الصفحات، والتنقيح السري، ومتى تفضل مهارة `inngest-api-cli` بدلاً من ذلك.
