Laden Sie YouTube-Videos herunter, extrahieren/Korrekturlesen/übersetzen Sie Untertitel und rendern Sie sie auf Video. Verwenden Sie es immer dann, wenn der Benutzer ein YouTube-Video mit Untertiteln herunterladen, Videountertitel ins Chinesische übersetzen, einem Video Untertitel hinzufügen/brennen möchte oder eine ASR-Transkription für Video-Audio durchführen möchte. Deckt die gesamte Pipeline ab: Video-Download → Untertitel-Extraktion → Korrekturlesen → Übersetzung → SRT-Erstellung → Untertitel-Rendering. Auch für „下载视频加字幕“, „视频翻译字幕“, „把字幕烧录到视频中“ verwenden. Für die reine Erstellung von Untertiteldateien ohne Rendering (nur SRT-Ausgabe) erledigt dieser Skill auch das – hören Sie vor Phase 5 auf.
