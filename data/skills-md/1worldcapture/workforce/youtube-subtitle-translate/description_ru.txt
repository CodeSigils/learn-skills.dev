Скачивайте видео с YouTube, извлекайте, корректируйте и переводите субтитры и преобразуйте их в видео. Используйте всякий раз, когда пользователь просит загрузить видео с YouTube с субтитрами, перевести субтитры видео на китайский язык, добавить субтитры/записать субтитры в видео или выполнить транскрипцию ASR для аудио-видео. Охватывает весь процесс: загрузка видео → извлечение субтитров → корректура → перевод → генерация SRT → рендеринг субтитров. Также используйте для «下载视频加字幕», «视频翻译字幕», «把字幕烧录到视频中». Для создания чистого файла субтитров без рендеринга (только вывод SRT) этот навык тоже подходит — остановитесь перед этапом 5.
