قم بإنشاء أوراق اختيار شخصيات أصلية ومعتمدة على مرجع مادي ومتسقة وواقعية لمفاهيم الشخصيات التجارية أو الإعلانية أو السينمائية أو النموذجية أو المهنية أو اليومية أو التاريخية أو الثقافية التقليدية أو الأدبية أو الخيالية قليلاً. يُستخدم عندما يريد المستخدم شخصًا مصممًا، أو مرجع اختيار، أو ورقة أصول الشخصية، أو بطاقة نموذج، أو صورة واحدة تحتوي على عروض أمامية وجانبية وخلفية وتفاصيل الوجه مع هوية متماسكة وخزانة ملابس ونوع الجسم وتوليف المواد المصدر وجودة التصوير الفوتوغرافي.
