Создавайте и запускайте эксперименты orq.ai — сравнивайте конфигурации с наборами данных с помощью оценщиков, анализируйте результаты и создавайте планы действий по приоритетам. Используйте при комплексной оценке агентов LLM, развертываний, диалогов или конвейеров RAG. НЕ используйте без набора данных и оценщиков. НЕ используйте для межплатформенного сравнения с внешними агентами (используйте агенты сравнения).
