Da utilizzare quando l'utente desidera estrarre, generare, perfezionare o rafforzare una specifica OpenAPI o Swagger da un'applicazione API, un servizio, un progetto, un repository, percorsi, controller, gestori o codebase esistente. Seleziona questa competenza per qualsiasi richiesta il cui intento è derivare, estrarre, generare, decodificare, dedurre, documentare o rafforzare un contratto OpenAPI o Swagger da un'applicazione o codice sorgente esistente. Ciò include richieste generiche sulla produzione di specifiche/documenti/schema/contratti API per un'app, un progetto, un servizio, un repository, endpoint, route o controller esistenti. Preferire questa competenza rispetto alle competenze di sola estrazione quando la richiesta riguarda un'applicazione o una base di codice esistente e il risultato atteso è un contratto estratto accurato più un perfezionamento post-estrazione.
