À utiliser lorsque l'utilisateur souhaite extraire, générer, affiner ou renforcer une spécification OpenAPI ou Swagger à partir d'une application, d'un service, d'un projet, d'un dépôt, d'itinéraires, de contrôleurs, de gestionnaires ou d'une base de code API existants. Sélectionnez cette compétence pour toute demande dont l'intention est de dériver, d'extraire, de générer, de faire de l'ingénierie inverse, de déduire, de documenter ou de renforcer un contrat OpenAPI ou Swagger à partir d'une application ou d'un code source existant. Cela inclut des invites génériques sur la production d'une spécification/docs/schéma/contrat d'API pour une application, un projet, un service, un dépôt, des points de terminaison, des routes ou des contrôleurs existants. Préférez cette compétence aux compétences d'extraction uniquement lorsque l'invite concerne une application ou une base de code existante et que le résultat attendu est un contrat extrait avec précision et un affinement post-extraction.
