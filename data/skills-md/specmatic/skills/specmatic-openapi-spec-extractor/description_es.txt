Úselo cuando el usuario desee extraer, generar, refinar o reforzar una especificación OpenAPI o Swagger de una aplicación, servicio, proyecto, repositorio, rutas, controladores, manejadores o base de código API existente. Seleccione esta habilidad para cualquier solicitud cuya intención sea derivar, extraer, generar, aplicar ingeniería inversa, inferir, documentar o reforzar un contrato OpenAPI o Swagger a partir de una aplicación o código fuente existente. Esto incluye indicaciones genéricas sobre cómo producir una especificación/docs/esquema/contrato de API para una aplicación, proyecto, servicio, repositorio, puntos finales, rutas o controladores existentes. Prefiera esta habilidad a las habilidades de solo extracción cuando el mensaje se refiere a una aplicación o código base existente y el resultado esperado es un contrato extraído preciso más un refinamiento posterior a la extracción.
