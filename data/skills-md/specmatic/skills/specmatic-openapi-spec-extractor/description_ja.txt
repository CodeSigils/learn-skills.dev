ユーザーが既存の API アプリケーション、サービス、プロジェクト、リポジトリ、ルート、コントローラー、ハンドラー、またはコードベースから OpenAPI または Swagger 仕様を抽出、生成、改良、または強化する場合に使用します。既存のアプリケーションまたはソース コードから OpenAPI または Swagger コントラクトを導出、抽出、生成、リバース エンジニアリング、推論、文書化、または強化することを目的としたリクエストには、このスキルを選択します。これには、既存のアプリ、プロジェクト、サービス、リポジトリ、エンドポイント、ルート、またはコントローラーの API 仕様/ドキュメント/スキーマ/コントラクトの作成に関する一般的なプロンプトが含​​まれます。プロンプトが既存のアプリケーションまたはコードベースに関するもので、期待される結果が正確に抽出されたコントラクトと抽出後の改良である場合は、抽出のみのスキルよりもこのスキルを優先します。
