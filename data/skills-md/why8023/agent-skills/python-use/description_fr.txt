Définir les spécifications obligatoires pour l’environnement Python et la gestion des dépendances. Cette compétence doit être appliquée chaque fois que l'agent doit utiliser Python, créer des environnements virtuels, installer des dépendances ou gérer des versions de Python. L'outil uv est obligatoire ; pip/conda est interdit, garantissant l'isolation de l'environnement au niveau du projet.
