Definire le specifiche obbligatorie per l'ambiente Python e la gestione delle dipendenze. Questa competenza deve essere applicata ogni volta che l'agente deve utilizzare Python, creare ambienti virtuali, installare dipendenze o gestire versioni di Python. L'utilizzo dello strumento uv è obbligatorio; pip/conda sono vietati, garantendo l'isolamento dell'ambiente a livello di progetto.
