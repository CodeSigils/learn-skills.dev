Обеспечьте соблюдение обязательных стандартов для среды Python и управления зависимостями. Когда агенту необходимо использовать Python, создавать виртуальные среды, устанавливать зависимости или управлять версиями Python, необходимо применить этот навык. Использование УФ-инструмента обязательно; pip/conda запрещены, что обеспечивает изоляцию среды на уровне проекта.
