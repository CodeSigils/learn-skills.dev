Этот навык следует использовать, когда пользователь просит «создать лимитный ордер», «разместить лимитный ордер», «установить ордер по целевой цене», «лимитную покупку», «лимитную продажу», «отменить лимитный ордер», «проверить мои ордера», «запросить лимитные ордера» или хочет торговать токенами по определенной цене. Создает, запрашивает и отменяет безгазовые лимитные ордера через API лимитных ордеров KyberSwap в 17 цепочках EVM.
