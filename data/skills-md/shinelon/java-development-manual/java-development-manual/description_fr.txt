Collection de règles du manuel de développement Java, basée sur le manuel de développement Java d'Alibaba (édition Songshan).  
Couvre 7 dimensions : règles de programmation, journalisation des exceptions, tests unitaires, règles de sécurité, base de données MySQL, structure du projet, règles de conception.  
Utilisez cette compétence lorsque l'utilisateur a besoin de : (1) écrire ou réviser du code Java, (2) vérifier les conventions de dénomination/code, (3) gérer les exceptions et les journaux, (4) écrire des tests unitaires, (5) codage sécurisé, (6) conception de base de données, (7) conception d'architecture de projet.  
Mots déclencheurs : règles Java, règles Alibaba, conventions de code, manuel de développement, règles de programmation, gestion des exceptions, tests unitaires, sécurité, MySQL, structure de projet, modèles de conception.
