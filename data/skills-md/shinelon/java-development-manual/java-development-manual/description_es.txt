Colección de reglas del manual de desarrollo de Java, basada en el manual de desarrollo de Java de Alibaba (edición Songshan).  
Cubre 7 dimensiones: reglas de programación, registro de excepciones, pruebas unitarias, reglas de seguridad, base de datos MySQL, estructura del proyecto, reglas de diseño.  
Utilice esta habilidad cuando el usuario necesite: (1) escribir o revisar código Java, (2) verificar convenciones de nomenclatura/código, (3) manejar excepciones y registros, (4) escribir pruebas unitarias, (5) codificación segura, (6) diseño de bases de datos, (7) diseño de arquitectura de proyectos.  
Palabras desencadenantes: reglas de Java, reglas de Alibaba, convenciones de código, manual de desarrollo, reglas de programación, manejo de excepciones, pruebas unitarias, seguridad, MySQL, estructura del proyecto, patrones de diseño.
