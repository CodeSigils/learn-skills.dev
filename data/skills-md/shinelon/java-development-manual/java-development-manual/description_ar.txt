مجموعة قواعد دليل تطوير Java، استنادًا إلى دليل تطوير Java على Alibaba (إصدار Songshan).  
يغطي 7 أبعاد: قواعد البرمجة، تسجيل الاستثناءات، اختبار الوحدة، قواعد الأمان، قاعدة بيانات MySQL، هيكل المشروع، قواعد التصميم.  
استخدم هذه المهارة عندما يحتاج المستخدم إلى: (1) كتابة كود Java أو مراجعته، (2) التحقق من اصطلاحات التسمية/الكود، (3) التعامل مع الاستثناءات والسجلات، (4) كتابة اختبارات الوحدة، (5) الترميز الآمن، (6) تصميم قاعدة البيانات، (7) تصميم بنية المشروع.  
الكلمات المحفزة: قواعد Java، قواعد Alibaba، اتفاقيات التعليمات البرمجية، دليل التطوير، قواعد البرمجة، معالجة الاستثناءات، اختبار الوحدة، الأمان، MySQL، هيكل المشروع، أنماط التصميم.
