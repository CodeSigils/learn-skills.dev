Java 開発マニュアル ルール コレクション。Alibaba Java 開発マニュアル (松山版) に基づいています。  
プログラミング ルール、例外ログ、単体テスト、セキュリティ ルール、MySQL データベース、プロジェクト構造、設計ルールの 7 つの側面をカバーします。  
このスキルは、ユーザーが (1) Java コードの作成またはレビュー、(2) 命名規則やコード規則の確認、(3) 例外とログの処理、(4) 単体テストの作成、(5) 安全なコーディング、(6) データベース設計、(7) プロジェクト アーキテクチャ設計を行う必要がある場合に使用します。  
トリガーワード: Java ルール、Alibaba ルール、コード規約、開発マニュアル、プログラミング ルール、例外処理、単体テスト、セキュリティ、MySQL、プロジェクト構造、デザイン パターン。
