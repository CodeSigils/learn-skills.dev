Коллекция правил Руководства по разработке Java, основанная на Руководстве по разработке Java на Alibaba (издание Songshan).  
Охватывает 7 измерений: правила программирования, ведение журнала исключений, модульное тестирование, правила безопасности, база данных MySQL, структура проекта, правила проектирования.  
Используйте этот навык, когда пользователю необходимо: (1) написать или просмотреть код Java, (2) проверить соглашения об именовании/коде, (3) обрабатывать исключения и журналы, (4) писать модульные тесты, (5) безопасное кодирование, (6) проектировать базу данных, (7) проектировать архитектуру проекта.  
Триггерные слова: правила Java, правила Alibaba, соглашения о коде, руководство по разработке, правила программирования, обработка исключений, модульное тестирование, безопасность, MySQL, структура проекта, шаблоны проектирования.
