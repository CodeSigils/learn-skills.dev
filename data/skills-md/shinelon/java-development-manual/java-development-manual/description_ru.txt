Сборник правил руководства по разработке Java, основанный на Руководстве по разработке Java на Alibaba (Songshan Edition).  
Охватывает 7 измерений: правила программирования, ведение журнала исключений, модульное тестирование, правила безопасности, база данных MySQL, структура проекта, правила проектирования.  
Используйте этот навык, когда пользователю необходимо: (1) написать или просмотреть код Java, (2) проверить стандарты именования/кода, (3) обрабатывать исключения и журналы, (4) написать модульные тесты, (5) написать безопасный код, (6) спроектировать базы данных, (7) спроектировать архитектуру проекта.  
Триггерные слова: стандарты Java, правила Alibaba, стандарты кода, руководство по разработке, правила программирования, обработка исключений, модульное тестирование, безопасность, MySQL, структура проекта, шаблоны проектирования.
