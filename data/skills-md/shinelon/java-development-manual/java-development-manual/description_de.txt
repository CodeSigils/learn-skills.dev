Regelsammlung des Java Development Manual, basierend auf dem Alibaba Java Development Manual (Songshan Edition).  
Deckt 7 Dimensionen ab: Programmierregeln, Ausnahmeprotokollierung, Komponententests, Sicherheitsregeln, MySQL-Datenbank, Projektstruktur, Designregeln.  
Verwenden Sie diese Fähigkeit, wenn der Benutzer Folgendes tun muss: (1) Java-Code schreiben oder überprüfen, (2) Namens-/Codekonventionen überprüfen, (3) Ausnahmen und Protokolle behandeln, (4) Komponententests schreiben, (5) sicheres Codieren, (6) Datenbankdesign, (7) Projektarchitekturdesign.  
Auslösewörter: Java-Regeln, Alibaba-Regeln, Codekonventionen, Entwicklungshandbuch, Programmierregeln, Ausnahmebehandlung, Unit-Tests, Sicherheit, MySQL, Projektstruktur, Entwurfsmuster.
