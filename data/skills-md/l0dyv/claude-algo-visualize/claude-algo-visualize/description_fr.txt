Générez une page d'enseignement HTML de visualisation interactive de structure de données/d'algorithme à fichier unique. Scénarios applicables : l'utilisateur fournit un PDF ou un manuel et demande des explications sur les points de connaissance ; donne un thème nécessitant une démonstration animée (par exemple, « tri rapide de démonstration », « créer une animation de file d'attente »); fournit du code ou un algorithme et souhaite que le processus d'exécution soit visualisé ; demande de comparer deux concepts ou d’expliquer un principe. Même si l’utilisateur ne mentionne pas explicitement « HTML » ou « visualisation », tout scénario impliquant un « résumé des points de connaissance », une « page d’enseignement », une « démonstration d’animation », un « processus d’exécution d’un algorithme », une « explication PDF », un « diagramme SVG », une « exécution étape par étape », etc., devrait le déclencher.
