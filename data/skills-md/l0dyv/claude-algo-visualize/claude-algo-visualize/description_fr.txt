Générez une page d'enseignement HTML de visualisation interactive de structure de données/d'algorithme à fichier unique. Scénarios applicables : l'utilisateur fournit un PDF/un manuel et demande la génération d'explications de points de connaissance, donne une demande thématique pour une démonstration animée (par exemple, « démontrer un tri rapide », « créer une animation de file d'attente »), fournit du code ou un algorithme et demande une visualisation de son processus d'exécution, ou demande une comparaison de deux concepts ou une explication d'un principe. Même si l'utilisateur ne mentionne pas explicitement « HTML » ou « visualisation », tout scénario impliquant un « résumé des points de connaissance », une « page d'enseignement », une « démonstration animée », un « processus d'exécution de l'algorithme », une « explication PDF », une « illustration SVG », une « exécution étape par étape », etc., devrait déclencher cela.
