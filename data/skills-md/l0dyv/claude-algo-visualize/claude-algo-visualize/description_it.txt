Genera una pagina didattica HTML di visualizzazione della struttura dati/algoritmo interattivo a file singolo. Casi d'uso: l'utente fornisce un PDF/libro di testo e richiede una spiegazione dei punti di conoscenza; fornisce un argomento che richiede una dimostrazione animata (ad esempio, "dimostrare Quicksort", "creare un'animazione della coda"); fornisce un codice o un algoritmo e richiede un processo di esecuzione visualizzato; richiede un confronto tra due concetti o la spiegazione di un principio. Anche se l’utente non menziona esplicitamente “HTML” o “visualizzazione”, qualsiasi scenario che coinvolga “riepilogo dei punti di conoscenza”, “pagina di insegnamento”, “dimostrazione animata”, “processo di esecuzione dell’algoritmo”, “spiegazione PDF”, “illustrazione SVG”, “esecuzione passo passo”, ecc., dovrebbe attivarlo.
