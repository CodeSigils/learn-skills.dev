Genera una pagina didattica HTML di visualizzazione della struttura dati/algoritmo interattivo a file singolo. Scenari applicabili: l'utente fornisce un PDF/libro di testo e richiede la generazione di spiegazioni sui punti di conoscenza, fornisce una richiesta tematica per una dimostrazione animata (ad esempio, "dimostrare Quicksort", "creare un'animazione di coda"), fornisce codice o algoritmo e richiede la visualizzazione del suo processo di esecuzione, o chiede un confronto di due concetti o una spiegazione di un principio. Anche se l’utente non menziona esplicitamente “HTML” o “visualizzazione”, qualsiasi scenario che coinvolga “riepilogo dei punti di conoscenza”, “pagina di insegnamento”, “dimostrazione animata”, “processo di esecuzione dell’algoritmo”, “spiegazione PDF”, “illustrazione SVG”, “esecuzione passo passo”, ecc., dovrebbe innescare questo.
