Generieren Sie eine HTML-Lehrseite zur interaktiven Datenstruktur-/Algorithmusvisualisierung in einer einzigen Datei. Anwendbare Szenarien: Der Benutzer stellt ein PDF/Lehrbuch bereit und fordert die Erstellung von Wissenspunkterklärungen an, stellt eine thematische Anfrage für eine animierte Demonstration (z. B. „Quicksort demonstrieren“, „Warteschlangenanimation erstellen“), stellt Code oder Algorithmus bereit und fordert die Visualisierung seines Ausführungsprozesses an oder bittet um einen Vergleich zweier Konzepte oder eine Erklärung eines Prinzips. Selbst wenn der Benutzer „HTML“ oder „Visualisierung“ nicht explizit erwähnt, sollte jedes Szenario, das „Zusammenfassung der Wissenspunkte“, „Lehrseite“, „animierte Demonstration“, „Algorithmusausführungsprozess“, „PDF-Erklärung“, „SVG-Illustration“, „Schritt-für-Schritt-Ausführung“ usw. beinhaltet, dies auslösen.
