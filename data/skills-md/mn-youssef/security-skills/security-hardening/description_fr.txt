À utiliser lorsque vous disposez d'un résultat de sécurité (issu d'un audit de code ou d'un pentest) et que vous devez le corriger correctement avec des modèles de codage sécurisé, puis vérifiez que le correctif le ferme réellement. Couvre les correctifs pour l'injection, le contrôle d'accès, XSS, l'authentification, les secrets et la configuration sur l'ensemble de la pile.
