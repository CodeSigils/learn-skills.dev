Auditez et réparez avec précision un catalogue Yandex KIT. À utiliser pour les demandes russes telles que « Vérifier le catalogue », « Effectuer un audit approfondi », « Vérifier le regroupement, les cartes, les médias ou les collections », « Fixer le prix à 4 990 pour le SKU‑42 », « Corriger les niveaux de stock en fonction de ce fichier » et les corrections exactes du catalogue unique ou groupé. Les audits sont en lecture seule ; les écritures nécessitent une commande explicite avec une cible, une opération et une valeur de propriétaire exactes ou une source faisant autorité nommée. Utilisez plutôt un opérateur a1‑yandex‑kit‑kit pour un signal de magasin de courant rapide.

Veuillez toujours répondre dans la langue de l'utilisateur.
