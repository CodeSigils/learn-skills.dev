Prüfen und reparieren Sie einen Yandex KIT-Katalog genau. Verwendung für russische Anfragen wie „Überprüfen Sie den Katalog“, „Führen Sie eine gründliche Prüfung durch“, „Überprüfen Sie Gruppierung, Karten, Medien oder Sammlungen“, „Setzen Sie den Preis auf 4990 für SKU-42“, „Korrigieren Sie die Salden gemäß dieser Datei“ und genaue Einzel- oder Massenkatalogkorrekturen. Audits sind schreibgeschützt; Schreibvorgänge erfordern einen expliziten Befehl mit einem genauen Ziel, Vorgang und Eigentümerwert oder einer benannten autorisierenden Quelle. Verwenden Sie stattdessen einen 1-Yandex-Kit-Operator für ein schnelles Stromspeichersignal.
