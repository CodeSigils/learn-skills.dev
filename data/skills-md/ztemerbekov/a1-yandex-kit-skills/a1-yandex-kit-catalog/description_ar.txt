قم بإدارة كتالوج متجر Yandex KIT عبر REST API الخاص به: المنتجات، والمتغيرات (وحدات SKU، والأسعار، والأسهم)، ومزامنة الأسعار/الأسهم بالجملة، والمستندات المتنوعة (المرفقات)، والفئات، والخصائص (بما في ذلك المجموعات والألوان)، ومقاطع فيديو المنتج، والمجموعات، ومجموعات السياق والشارات. يُستخدم عند إنشاء كيانات الكتالوج أو تحديثها أو أرشفتها أو الاستعلام عنها في متجر Yandex KIT.
