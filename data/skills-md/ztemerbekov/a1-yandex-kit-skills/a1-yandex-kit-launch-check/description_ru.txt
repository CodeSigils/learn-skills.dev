Для проверки готовности к запуску магазина Яндекс КИТ: «Можем ли запустить?», «Проверить готовность», «Что блокирует открытие?», «Можем ли мы обслуживать клиентов?». Вызов модели; рабочий процесс по умолчанию полностью доступен только для чтения и различает проверенные блокировщики, риски и непроверенные ссылки для оформления заказа.
