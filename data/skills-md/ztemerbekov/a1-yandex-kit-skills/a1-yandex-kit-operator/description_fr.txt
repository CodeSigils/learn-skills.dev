Utiliser pour un examen opérationnel ou un changement exact autorisé par le propriétaire dans un magasin de KITS Yandex : « Comment vont les choses dans le magasin ? », « What's urgent ? », « Confirm order 123 », « Set price 4 990 for SKU‑42 » ou une autre commande avec une cible, une action et une valeur sans ambiguïté. Traitez le court « Comment allez-vous ? » comme une demande de magasin uniquement lorsque le contexte du KIT Yandex est déjà établi.
