À utiliser pour un examen opérationnel ou une modification exacte autorisée par le propriétaire dans un magasin Yandex KIT : « Comment vont les choses dans le magasin ? », « Qu'est-ce qui est urgent ? », « Confirmer la commande 123 », « Fixer le prix à 4990 pour le SKU-42 » ou une autre commande avec un objectif, une action et une valeur sans ambiguïté. Traitez brièvement « Comment vas-tu ? » en tant que demande de magasin uniquement lorsque le contexte Yandex KIT est déjà établi.
