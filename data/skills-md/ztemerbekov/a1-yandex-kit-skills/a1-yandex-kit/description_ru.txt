Основное руководство по API электронной коммерции Яндекс КИТ (конструктор магазинов kit.yandex.ru): аутентификация, базовый URL, ограничения скорости, контракт ошибок, нумерация страниц и скрипты поиска/проверки офлайн-спецификаций. Используйте, когда задача включает API Yandex KIT и ни один предметный навык (каталог, заказы, акции, магазин, веб-хуки) явно не подходит, или когда вам нужны основы аутентификации, ограничений или обработки ошибок.
