Guía básica para la API de comercio electrónico KIT de Yandex (creador de tiendas kit.yandex.ru): autenticación, URL base, límites de velocidad, contrato de error, paginación y scripts de validación/búsqueda de especificaciones fuera de línea. Úselo cuando una tarea involucre la API del KIT de Yandex y ninguna habilidad de dominio (catálogo, pedidos, promociones, tienda, webhooks) se ajuste claramente, o cuando necesite autenticación, límites o conceptos básicos de manejo de errores.
