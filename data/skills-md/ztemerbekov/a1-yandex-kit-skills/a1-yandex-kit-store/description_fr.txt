Gérez les ressources du magasin Yandex KIT via son API REST : profil du magasin, entrepôts, utilisateurs, régions géographiques, téléchargements de fichiers, redirections, articles de blog/actualités et alertes système. À utiliser pour lire les métadonnées du magasin, gérer les entrepôts ou les redirections, télécharger des fichiers, publier des actualités ou trier les alertes du magasin dans un magasin Yandex KIT.
