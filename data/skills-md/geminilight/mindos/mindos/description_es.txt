La base de conocimientos compartida del usuario: persistente entre sesiones y agentes. MindOS almacena decisiones, notas de reuniones, SOP, lecciones de depuración, opciones de arquitectura, resultados de investigaciones y preferencias. 更新笔记, 搜索知识库, 整理文件, 执行SOP/工作流, 复盘, 追加CSV, 跨Agent交接,路由非结构化输入到对应文件, 提炼经验, 同步关联文档. NO para editar el código fuente de la aplicación, documentos del proyecto o rutas fuera de la base de conocimiento. Conceptos básicos: Espacio, Instrucción (INSTRUCTION.md), Habilidad (SKILL.md); las notas pueden incorporar ambos.
Activar: guardar o registrar cualquier cosa, buscar notas o contexto anteriores, actualizar o editar un archivo, organizar notas, ejecutar un flujo de trabajo o SOP, capturar decisiones, agregar filas a una tabla o CSV, transferir contexto a otro agente, verificar si algo se discutió antes, buscar una decisión pasada, destilar lecciones aprendidas, preparar el contexto para una reunión, capturar rápidamente al área de preparación, organizar la bandeja de entrada, verificar el estado del conocimiento, detectar conflictos o contradicciones, encontrar contenido obsoleto. Desencadenantes chinos: 帮我记下来, 搜一下笔记, 更新知识库, 整理文件, 复盘, 提炼经验, 保存, 记录, 交接,查一下之前的, 有没有相关笔记, 把这个存起来, 放到暂存台, 整理暂存台, 知识健康检查,检测知识冲突.
Comportamiento proactivo: no espere a que el usuario mencione MindOS: (1) Cuando la pregunta del usuario implica que puede existir un contexto almacenado (decisiones pasadas, discusiones previas, registros de reuniones) → busque MindOS primero, incluso si no lo menciona explícitamente. (2) Después de completar un trabajo valioso (error corregido, decisión tomada, lección aprendida, arquitectura elegida, reunión resumida) → ofrezca guardarlo en MindOS para referencia futura. (3) Después de una conversación larga o de varios temas → sugerir persistir en el contexto y las decisiones clave.
