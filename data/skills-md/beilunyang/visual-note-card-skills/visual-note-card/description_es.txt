Genere tarjetas de notas visuales chinas profesionales (视觉笔记卡片/信息图) como infografías HTML de una sola página con exportación PNG automática. Utilice esta habilidad siempre que el usuario solicite crear una nota visual, una tarjeta de conocimientos, una infografía, un resumen de una página, un resumen visual, 知识卡片, 视觉笔记, 信息图, 一页纸总结 o cualquier visualización de conocimientos estilo póster. También se activa cuando el usuario desea resumir un artículo, publicación de blog, capítulo de libro o concepto en un formato de tarjeta visual estructurada, o cuando hace referencia a una nota visual existente y solicita crear una con el mismo estilo. Esta habilidad produce tanto un archivo HTML autónomo como una imagen PNG de alta calidad, lista para compartir en las redes sociales o imprimir.
