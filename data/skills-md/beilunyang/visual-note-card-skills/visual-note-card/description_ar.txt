أنشئ بطاقات ملاحظات مرئية صينية احترافية (视觉笔记卡片/信息图) على شكل رسوم بيانية بتنسيق HTML مكونة من صفحة واحدة مع تصدير PNG تلقائيًا. استخدم هذه المهارة عندما يطلب المستخدم إنشاء ملاحظة مرئية، أو بطاقة معرفة، أو مخطط معلوماتي، أو ملخص من صفحة واحدة، أو ملخص مرئي، أو نصوص، أو نصوص، أو نصوص، أو نصوص، أو أي تصور معرفي على شكل ملصق. يتم تشغيله أيضًا عندما يريد المستخدم تلخيص مقال أو منشور مدونة أو فصل في كتاب أو مفهوم في تنسيق بطاقة مرئية منظمة، أو عندما يشير إلى ملاحظة مرئية موجودة ويطلب إنشاء واحدة بنفس النمط. تنتج هذه المهارة ملف HTML مستقلاً وصورة PNG عالية الجودة، جاهزة للمشاركة على وسائل التواصل الاجتماعي أو الطباعة.
