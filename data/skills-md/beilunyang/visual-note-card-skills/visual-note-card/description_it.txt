Genera cartoline visive cinesi professionali (视觉笔记卡片/信息图) come infografiche HTML a pagina singola con esportazione PNG automatica. Utilizza questa capacità ogni volta che l'utente chiede di creare una nota visiva, una scheda informativa, un'infografica, un riepilogo di una pagina, un riepilogo visivo, 知识卡片, 视觉笔记, 信息图, 一页纸总结 o qualsiasi visualizzazione della conoscenza in stile poster. Si attiva anche quando l'utente desidera riassumere un articolo, un post di blog, un capitolo di un libro o un concetto in un formato di scheda visiva strutturata o quando fa riferimento a una nota visiva esistente e chiede di crearne una nello stesso stile. Questa abilità produce sia un file HTML autonomo che un'immagine PNG di alta qualità, pronta per la condivisione sui social media o la stampa.
