自動 PNG エクスポートを使用して、プロフェッショナルな中国語ビジュアル ノート カード (視觉笔记卡片/情報图) を単一ページの HTML インフォグラフィックスとして生成します。ユーザーが視覚的なメモ、ナレッジ カード、インフォグラフィック、概要資料、視覚的な概要、知识卡片、視觉笔记、情報图、一页纸总结、またはポスター スタイルの知識の視覚化を作成するように要求する場合は常に、このスキルを使用します。また、ユーザーが記事、ブログ投稿、本の章、コンセプトを構造化されたビジュアル カード形式に要約したい場合、または既存のビジュアル ノートを参照し、同じスタイルで作成するよう依頼した場合にもトリガーされます。このスキルは、自己完結型の HTML ファイルと高品質の PNG 画像の両方を生成し、ソーシャル メディアで共有したり印刷したりできるようにします。
