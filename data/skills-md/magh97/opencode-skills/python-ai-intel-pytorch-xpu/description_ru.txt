PyTorch 2.7 с поддержкой встроенного XPU для графических процессоров Intel (Arc, Flex, Max). Кубические тензоры на XPU, torch.compile + TorchInductor + Triton, смешанная точность (FP16/BF16), DataLoader с привязкой к графическому процессору, миграция из IPEX, а также распространение. Активно для обучения графическим процессорам Intel или миграции с CUDA.
