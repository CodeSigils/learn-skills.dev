Guía al usuario a través a proceso esstructurato para transforma an historia de usuario in a éspecificación técnica completa. Dazu gehören Phase 0 der Stack-Klassifizierung (automatische Lieferung von Entwicklungskits), Identifizierung von Annahmen, iterative Validierung mit Erkennung von Widersprüchen, Generierung der endgültigen Spezifikationskonfiguration für das Projekt und Checkliste für Anhänger. Wenn der Benutzer eine Benutzergeschichte verwendet, muss aufgrund unklarer Anforderungen eine technische Spezifikation erstellt werden.
