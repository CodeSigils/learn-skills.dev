Guida principale di JavaScript Vanilla sul navigatore (ES6+). Selettori DOM moderni, fetch API, eventi, moduli ES nativi (type="module"), async/await, FormData, templates, localStorage, MutationObserver e API del navigatore. Attiva per qualsiasi compito JavaScript vanilla, in particolare nei progetti ASP.NET MVC + Razor senza bundler nel framework SPA. Le abilità secondarie del kit si approfondiscono in domini specifici.
