Guide principal de JavaScript vanilla sur le navigateur (ES6+). Cube sélectionne les DOM modernes, l'API de récupération, les événements, les modules ES naturels (type="module"), async/await, FormData, les modèles, localStorage, MutationObserver et les API du navigateur. Actif pour toute application JavaScript Vanilla, en particulier dans les projets ASP.NET MVC + Razor sans bundler ni framework SPA. Les sous-compétences du kit sont approfondies dans des domaines spécifiques.
