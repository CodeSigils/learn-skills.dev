Guía principal de desarrollo Node.js (24 LTS / 26 Actual). Cubre runtime, ESM vs CJS, TypeScript 7 (compilador Go), async/await, streams, eventos, API temporal, depuración, herramientas (tsx, node:test) y fundamentos del ecosistema. Actívala para cualquier tarea Node.js: nuevos proyectos, migraciones de versión, revisión de código o configuración del entorno. Las sub-habilidades del kit profundizan en dominios específicos.
