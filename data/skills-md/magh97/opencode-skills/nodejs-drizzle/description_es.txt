Llovizna ORM en Node.js (v1.0 RC, 2026). Cubre declaración de esquemas, consultas tipo SQL y relacionales, relaciones (uno a uno, uno a muchos, muchos a muchos), transacciones y savepoints, migraciones con drizzle-kit, validación Zod (createInsertSchema/createSelectSchema), declaraciones preparadas, pooling de conexiones, SQL Server + PostgreSQL, y estrategia híbrida con Prisma. Actívala cuando el proyecto utilice Drizzle como ORM, al diseñar esquemas de tipo seguro, optimizar consultas sin servidor, o decidir entre Drizzle y Prisma.
