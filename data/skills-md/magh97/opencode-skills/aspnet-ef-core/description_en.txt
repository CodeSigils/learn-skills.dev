Entity Framework Core en contexto ASP.NET. Cubre ciclo de vida del DbContext (Scoped), DbContextFactory para Blazor y workers, migraciones en aplicaciones web, connection resiliency, health checks de BD, context pooling, queries optimizadas para web (split queries, AsNoTracking, paginación), y patrones anti-N+1. Actívala al configurar EF Core en aplicaciones web, optimizar queries de endpoints, o trabajar con Blazor + EF Core.
