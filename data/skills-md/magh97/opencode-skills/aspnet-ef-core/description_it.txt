Entity Framework Core in contesto ASP.NET. Cubo ciclo di vita di DbContext (Scoped), DbContextFactory per Blazor e lavoratori, migrazioni in applicazioni web, resilienza della connessione, controlli di integrità di BD, pool di contesto, query ottimizzate per il web (query suddivise, AsNoTracking, impaginazione) e patroni anti-N+1. Attivare la configurazione di EF Core nelle applicazioni Web, ottimizzare le query sugli endpoint o lavorare con Blazor + EF Core.
