jQuery 4.0 und veraltete ASP.NET MVC-Projekte. Würfelauswahl, AJAX, Plugins, Migrate Plugin zur inkrementellen Modernisierung, Verwendung von jQuery vs. Vanilla JS, und Migrationsstrategien zu ES-Modulen. Aktiviert, wenn das Projekt jQuery verwendet (insbesondere Unternehmens-Apps mit mehr als 50.000 Razor-Zeilen + jQuery), alte Codes verwalten oder eine einfache Migration auf Vanilla JS durchführen.
