Enregistrements de décisions d'architecture : format léger pour documenter les décisions techniques avec le contexte, les alternatives considérées et les conséquences. Activez-la pour prendre une décision architecturale importante, lorsque l'utilisateur diga 'ADR', 'enregistrement de décision', 'pourquoi nous sommes élus X', 'décision documentaire', 'décision architecturale'.
