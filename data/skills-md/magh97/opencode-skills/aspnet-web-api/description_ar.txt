واجهات برمجة التطبيقات REST مع ASP.NET Core (وحدات التحكم والحد الأدنى من واجهات برمجة التطبيقات). تصميم رائع RESTful، وتفاوض المحتوى، وإصدار الإصدارات، وHATEOAS، وOpenAPI/Swagger، وCORS، وتحديد المعدل، والتخزين المؤقت للاستجابة، ومفاتيح API، وممارسات عملية جيدة لتصميم APIs HTTP. قم بتنشيط تصميم وتنفيذ واجهات برمجة التطبيقات (APIs) HTTP، ونقاط النهاية REST، أو ترحيل واجهات برمجة التطبيقات (APIs) لوحدات التحكم إلى الحد الأدنى من واجهات برمجة التطبيقات (APIs).
