API REST con ASP.NET Core (Controller e API minime). Cubo di design RESTful, negoziazione dei contenuti, controllo delle versioni, HATEOAS, OpenAPI/Swagger, CORS, limitazione della velocità, caching delle risposte, chiavi API e buone pratiche di progettazione delle API HTTP. Attiva la progettazione o l'implementazione di API HTTP, endpoint REST o la migrazione di API da controller a API minime.
