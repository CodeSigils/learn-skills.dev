Integración de PostgreSQL con .NET y aplicaciones. Cubre Npgsql, Entity Framework Core con PostgreSQL (configuración, resiliencia de conexión, pg_trgm, mapeo JSONB, vector), Dapper para consultas de alto rendimiento, pooling de conexiones (interno y PgBouncer), y mejores prácticas de conexión. Actívala al configurar la capa de datos en aplicaciones .NET, optimizar el acceso a datos, o migrar de SQL Server a PostgreSQL.
