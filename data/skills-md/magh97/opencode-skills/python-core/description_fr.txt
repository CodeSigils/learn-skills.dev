Guide principal du développement de Python (3.13/3.14). Le type de cube suggère des éléments modernes, async/await, uv (gestionnaire de paquets), stdlib, Python à thread libre (3.14), des chaînes de modèles, Pydantic v2 pour les modèles et les fondements de l'écosystème. Actif pour n'importe quelle application Python : nouvelles fonctionnalités, révision du code, migration de la version. Les sous-compétences du kit sont approfondies dans des domaines spécifiques.
