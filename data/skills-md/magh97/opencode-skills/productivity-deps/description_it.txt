Manutenzione delle dipendenze. I pacchetti Escanea sono obsoleti in Node.js (npm obsoleto), Python (pip list --outdated), .NET (dotnet list package --outdated) e Flutter (flutter pub obsoleto). Classifica aggiornamenti per riesgo (patch = seguro, minor = revisar, major = planificar), genera il changelog di ogni aggiornamento delle versioni GitHub e suggerisce di unirsi a PR separati. Usato all'inizio di ogni sprint, il lunedì della mattina, o quando l'utente dice 'attualizzare le dipendenze', 'controllo delle dipendenze', 'qué paquetes están desactualizados', 'npm obsoleto'.
