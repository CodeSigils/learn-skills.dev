Gestion des dépendances. Les paquets Escanea sont obsolètes dans Node.js (npm obsolète), Python (pip list --obsolète), .NET (package dotnet list --obsolète) et Flutter (flutter pub obsolète). Les mises à jour classiques sont simples (patch = sécurisé, mineur = réviser, majeur = planifié), génèrent le journal des modifications de chaque mise à jour à partir des versions de GitHub, et vous permettent de vous inscrire dans les PR séparés. Habituellement, au début de chaque sprint, les lunes de la mère, ou lorsque l'utilisateur parle de « actualisation des dépendances », « vérification des dépendances », « que les paquets sont désactualisés », « npm obsolète ».
