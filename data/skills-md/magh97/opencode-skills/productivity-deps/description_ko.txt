Mantenimiento de dependency. Escanea는 Node.js(npm 구식), Python(pip list --구식), .NET(dotnet list package --구식) 및 Flutter(flutter pub 구식)로 오래된 패키지를 제공합니다. Clasifica는 GitHub 릴리스의 업데이트 로그에 따라 업데이트되며(패치 = 보안, 마이너 = 개정, 메이저 = 계획), 변경 로그는 GitHub 릴리스와 별도로 PR에 따라 업데이트됩니다. 처음에는 스프린트 시작 시, 마냐나의 달에서, 사용자가 '실제 종속성', '종속성 확인', '패키지가 비활성화됨', 'npm이 오래됨'을 확인할 수 있습니다.
