Conception de système optimisée pour les agents. Compte tenu du contexte, produit des sections composables : architecture (graphe de dépendances de texte + table de module), API (table de points de terminaison), schéma de données (blocs de table + index). À utiliser lorsque l'utilisateur dit "concevoir l'architecture", "concevoir l'API", "concevoir le schéma", "concevoir le système".
