Оптимизированный для агентов дизайн системы. Учитывая контекст, создаются составные разделы: архитектура (график текстовых зависимостей + таблица модулей), API (таблица конечных точек), схема данных (блоки таблицы + индексы). Никакой теории C4, никакого руководства по соглашениям REST, никакого объяснения нормализации. Используйте, когда пользователь говорит «спроектировать архитектуру», «спроектировать API», «спроектировать схему», «спроектировать систему».
