Progettazione del sistema ottimizzata per gli agenti. Dato il contesto, produce sezioni componibili: architettura (grafico delle dipendenze del testo + tabella dei moduli), API (tabella degli endpoint), schema dei dati (blocchi di tabelle + indici). Nessuna teoria C4, nessun primer sulle convenzioni REST, nessuna spiegazione di normalizzazione. Da utilizzare quando l'utente dice "progetta l'architettura", "progetta l'API", "progetta lo schema", "progetta il sistema".
