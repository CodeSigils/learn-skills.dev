Refactores automatizados y seguros en cualquier lenguaje. Soporta renombrar símbolos en todo el proyecto, extrae funciones/métodos, mueve archivos entre módulos actualizando imports y elimina el código muerto. Compatible con AST para TypeScript (tsgo/ts-morph), Python (libcst/ast), y C# (Roslyn/dotnet-format). Úsala durante la revisión del código cuando un hallazgo requiera refactor, o cuando el usuario diga "renombra X a Y", "extrae esta función", "mueve este archivo", "elimina código muerto".
