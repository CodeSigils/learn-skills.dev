Refactors automatisés et sécurisés dans n'importe quelle langue. Permet de renommer les symboles dans tout le projet, d'ajouter des fonctions/méthodes, de déplacer les archives entre les modules actualisant les importations et d'éliminer le code muerto. Compatible AST pour TypeScript (tsgo/ts-morph), Python (libcst/ast) et C# (Roslyn/dotnet-format). Il est utilisé lors de la révision du code lorsqu'un refactor nécessite un hallazgo, ou lorsque l'utilisateur parle de "nommer X à Y", "extrae this función", "mueve este archivo", "élimina código muerto".
