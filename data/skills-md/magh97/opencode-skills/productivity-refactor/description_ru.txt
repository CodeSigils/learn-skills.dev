Рефакторинг автоматизирован и безопасен на любом языке. Можно изменить символы во всем проекте, добавить дополнительные функции/методы, переместить архивы между модулями актуализированного импорта и удалить код muerto. Поддержка AST для TypeScript (tsgo/ts-morph), Python (libcst/ast), C# (Roslyn/dotnet-format). Выполняйте проверку кода в течение всего времени, когда требуется рефакторинг, или когда пользователь использует "renombra X a Y", "extrae esta función", "mueve este archive", "elimina código muerto".
