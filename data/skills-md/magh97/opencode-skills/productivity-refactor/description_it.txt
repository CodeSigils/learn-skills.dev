Refactoring automatizzati e protetti in qualsiasi lingua. Supporta la ridenominazione dei simboli in tutto il progetto, l'aggiunta di funzioni/metodi, lo spostamento di file tra i moduli attualizzando le importazioni ed eliminando il codice morto. Compatibile con AST per TypeScript (tsgo/ts-morph), Python (libcst/ast), e C# (formato Roslyn/dotnet). Usalo durante la revisione del codice quando un hallazgo richiede il refactoring, o quando l'utente dice "renombra X a Y", "extrae esta función", "mueve este archivo", "elimina código muerto".
