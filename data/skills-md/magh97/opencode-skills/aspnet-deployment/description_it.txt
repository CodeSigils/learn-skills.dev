Pubblicazione e distribuzione delle applicazioni ASP.NET Core. Cubre IIS, Docker, Servizio app di Azure, proxy inverso (YARP, nginx), HTTPS, certificati, variabili di ambiente, CI/CD con GitHub Actions e Azure DevOps, migrazioni in produzione e rafforzamento. Attivare la preparazione di un'applicazione per la produzione, configurare CI/CD o eseguire la migrazione tra gli ambienti di hosting.
