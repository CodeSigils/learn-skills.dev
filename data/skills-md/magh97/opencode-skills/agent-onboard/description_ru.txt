Адаптация разработчиков, оптимизированная для агентов. Учитывая базу кода, создается компактный справочник по внедрению: быстрый старт, стек, ключевые команды, ключевые файлы, переменные окружения, дайджест архитектуры. Цель до 80 строк. Используйте, когда пользователь говорит: «Присоединяйтесь ко мне», «Присоединяйтесь», «Как настроить», «Начало работы», «Быстрый старт».
