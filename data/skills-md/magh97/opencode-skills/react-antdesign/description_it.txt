Componenti React con Ant Design 5.29 e ProComponents v3. Cubre ConfigProvider + token tematici, componenti core (Table, Form, Select, Modal, Drawer), ProTable e ProForm per la produttività, integrazione con React Hook Form + Zod, Vite + tree shake e Ant Design Pro v6 (Tailwind + @tanstack/react-query). Attivalo quando lo stack dell'attrezzatura utilizza Ant Design in occasione di Tailwind/shadcn, in particolare nei progetti Sputnik (React + Vite + Ant Design).
