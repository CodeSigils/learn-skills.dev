Patroni dei componenti React + TypeScript. Componenti compositi cubici, componenti polimorfici, oggetti di scena di rendering, slot, composizione sul presente, Tailwind CSS 4.3, shadcn/ui 4.11, Radix e Headless UI e accessibilità (ARIA, focus, tastiera). Attiva la progettazione di sistemi di componenti, la costruzione di sistemi di progettazione o l'implementazione di un'interfaccia utente accessibile.
