Оптимизированная для агента техническая спецификация. Учитывая пользовательскую историю или описание функции, создается структурированная спецификация: конечные точки, сущности, бизнес-правила, состояния, компоненты пользовательского интерфейса. Никаких повторяющихся вопросов — автоматически заполняйте предположения и отмечайте их для проверки. Используйте, когда пользователь говорит «опишите это», «технические характеристики», «спецификация», «определите эту функцию».
