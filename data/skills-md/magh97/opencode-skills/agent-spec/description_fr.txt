Spécification technique optimisée pour les agents. À partir d'une user story ou d'une description de fonctionnalité, produit une spécification structurée : points de terminaison, entités, règles métier, états, composants d'interface utilisateur. Pas de questionnement itératif : remplissez automatiquement les hypothèses et signalez-les pour examen. À utiliser lorsque l'utilisateur dit "spécifier ceci", "spécifications techniques", "spécifications pour", "définir cette fonctionnalité".
