Guide principal du développement .NET (C#, .NET 9/10). Convencions de base du code, fonctionnalités modernes de C# 12-14, système de projets, hébergement, DI, configuration, middleware, journalisation, sérialisation et outils de l'écosystème. Actif pour toute application .NET : nouvelles fonctionnalités, révision du code, architecture, migrations ou débogage. Les sous-compétences du kit sont approfondies dans des domaines spécifiques.
