Генерирует оптимизированную для агентов документацию на основе существующих человеческих документов. Сканирует README.md, docs/, конфигурации linter и package.json для создания папки docs/agent-docs/ с 9 файлами с эффективным использованием токенов: КОНТЕКСТ, СТЕК, ПРАВИЛА, АРХИТЕКТУРА, СХЕМА, API, ШАБЛОНЫ, ДИЗАЙН, РАБОЧИЕ ПРОЦЕССЫ. Используйте, когда пользователь говорит «документы агента», «документы для агентов», «диалект агента», «оптимизировать документы для ИИ», «создать документы агента».
