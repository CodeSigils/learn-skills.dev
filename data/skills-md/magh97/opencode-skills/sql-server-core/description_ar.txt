الدليل الأساسي لـ SQL Server (2019/2022/2025). Cubre T-SQL، بنية المحرك، أنواع البيانات، DDL/DML، الإصدارات، الأدوات (SSMS، Azure Data Studio، sqlcmd)، قواعد بيانات النظام، وأساسيات المحرك. تنشيط لأي ملف SQL Server: تطويرات جديدة، مراجعة الاستعلامات، الترحيل أو تصميم قاعدة البيانات. تتعمق هذه المهارات الفرعية في مجالات محددة.
