Guía principal de SQL Server (2019/2022/2025). Cubre T-SQL, arquitectura del motor, tipos de datos, DDL/DML, ediciones, herramientas (SSMS, Azure Data Studio, sqlcmd), bases de datos del sistema y fundamentos del motor. Actívala para cualquier tarea SQL Server: nuevos desarrollos, revisión de consultas, migraciones o diseño de base de datos. Las sub-habilidades del kit profundizan en dominios específicos.
