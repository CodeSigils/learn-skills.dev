تصميم وإدارة SQL Server. مجموعات الملفات المكعبة، والنسخ الاحتياطي/الاستعادة، وإمكانية التوفر العالية، واستعادة القدرة على العمل بعد الكوارث (التشغيل دائمًا، وشحن السجل، والنسخ المتطابق)، ومشاركة الجداول، وضغط البيانات، ومحافظ الموارد، وتكوين TempDB. قم بتنشيط تصميم البنية التحتية الأساسية للبيانات، أو مستوى HA/DR، أو تكوين عناصر إنتاجية.
