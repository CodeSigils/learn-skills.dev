Arquitectura y administración de SQL Server. Cubre grupos de archivos, copia de seguridad/restauración, alta disponibilidad y recuperación ante desastres (Always On, trasvase de registros, duplicación), particionamiento de tablas, compresión de datos, Resource Governor y configuración de TempDB. Actívala al diseñar infraestructura de base de datos, planear HA/DR, o configurar entornos productivos.
