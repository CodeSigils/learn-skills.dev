Genera la estructura inicial de un proyecto a partir de una especificación técnica (productivity-spec). Crea árbol de directorios, archivos base (entry point, config, linters), Dockerfile, CI pipeline inicial, y todo el boilerplate según la arquitectura del dev-kit del stack elegido. Úsala después de productivity-spec o cuando el usuario pida "crear proyecto", "scaffold", "inicializar el repo", o "generar boilerplate" para un stack específico.
