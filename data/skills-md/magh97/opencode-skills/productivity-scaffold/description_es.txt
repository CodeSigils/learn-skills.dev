Genera la estructura inicial de un proyecto a partir de una especificación técnica (productivity-spec). Crea árbol de directorios, archivos base (punto de entrada, configuración, linters), Dockerfile, canalización de CI inicial y todo el modelo estándar según la arquitectura del dev-kit del stack elegido. Úsala después de productividad-spec o cuando el usuario pida "crear proyecto", "scaffold", "inicializar el repo", o "generar repetitivo" para un stack específico.
