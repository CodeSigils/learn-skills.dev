Unterstützen Sie eine Tabelle zur Koordinierung des Sputnik-Equipments mit Jira wie Issues und nutzen Sie die verfügbaren Atlassian-Anschlüsse. Toma como una tabla con columnsas Capa / Nombre Proyecto / Req. / Aktivitätsname / Beschreibende Struktur / Punkte / Rechtfertigung (generiert von Sputnik-Core) und Erstellung eines Problems für jedes Zielprojekt, Problemtyp und Punktefeld (Story Points). Soporta agrupación en epicas, vinculación entre capas und Erkennung von Duplikaten. Sobald eine Schätzung mit Sputnik-Core vorliegt, sagt der Benutzer: „Senden Sie die Ausgabe an Jira“, „Erstellen Sie Tickets“, „Passen Sie die Schätzung an Jira an“ oder „Laden Sie die Kotierung an Jira an“. Pregunta Siempre Projekt Ziel und bestätigen Sie, bevor Sie es vollständig erstellen.
