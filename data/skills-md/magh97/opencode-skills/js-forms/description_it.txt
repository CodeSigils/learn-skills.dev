Formulari in JavaScript vanilla. Cubre FormData + fetch(), convalida HTML5 (required, pattern, setCustomValidity), API di convalida vincoli, convalida personalizzata, feedback visivo sugli errori, caricamento di file e formule dinamiche (aggregare/eliminare file). Attivare l'implementazione di formulari nei progetti ASP.NET MVC senza React Hook Form o sostituire la convalida jQuery con Vanilla JS.
