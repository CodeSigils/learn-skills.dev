Programmazione procedurale su PostgreSQL con PL/pgSQL. Funzioni del cubo (RETURNS TABLE, SETOF, VOID), procedure (CALL/COMMIT), trigger (BEFORE/AFTER/INSTEAD OF), viste, viste materializzate, regole, trigger di eventi, estensioni e gestione degli errori con EXCEPTION. Attiva l'implementazione della logica di negoziazione sul database, la migrazione delle funzioni da Oracle/SQL Server o la progettazione delle API dei dati con PostgreSQL.
