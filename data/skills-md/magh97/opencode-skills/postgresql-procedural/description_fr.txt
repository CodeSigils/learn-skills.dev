Programmation procédurale sur PostgreSQL avec PL/pgSQL. Fonctions générales (RETURNS TABLE, SETOF, VOID), procédures (CALL/COMMIT), déclencheurs (AVANT/APRÈS/INSTEAD OF), vues, vues matérialisées, règles, déclencheurs d'événements, extensions et gestion des erreurs avec EXCEPTION. Activez la mise en œuvre de la logique de négociation dans la base de données, migrez les fonctions depuis Oracle/SQL Server ou créez des API de données avec PostgreSQL.
