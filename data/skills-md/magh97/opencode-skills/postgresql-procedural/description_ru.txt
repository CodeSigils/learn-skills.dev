Процедурное программирование в PostgreSQL с PL/pgSQL. Кубические функции (RETURNS TABLE, SETOF, VOID), процедуры (CALL/COMMIT), триггеры (BEFORE/AFTER/INSTEAD OF), перспективы, материализованные перспективы, правила, триггеры событий, расширения и множество ошибок с ИСКЛЮЧЕНИЕМ. Активируйте логику переговоров в базе данных, перенесите функции из Oracle/SQL Server или создайте API-интерфейсы данных для PostgreSQL.
