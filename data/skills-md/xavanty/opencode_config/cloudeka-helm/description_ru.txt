Создавайте диаграммы Kubernetes Helm, адаптированные для среды Cloudeka. Используйте, когда пользователь хочет создать диаграмму Helm, создать новое развертывание Kubernetes или развернуть приложение в Cloudeka. Запускается по таким фразам, как «создать контрольную диаграмму», «подготовить развертывание», «развернуть на Cloudeka», «диаграмма Kubernetes для Cloudeka», «контрольная диаграмма для моего приложения». Обрабатывает как общие рабочие нагрузки, так и рабочие нагрузки графического процессора (выводы ML/AI/LLM).
