أنشئ تصورات تعليمية تفاعلية بتنسيق HTML خطوة بخطوة باستخدام سمة GitHub المظلمة وعناصر التحكم في التنقل والعرض المتحرك المستند إلى الحالة. يُستخدم عندما يطلب المستخدم إنشاء شرح تفاعلي، أو تصور تعليمي، أو رسوم متحركة تفصيلية، أو شرح تفصيلي للمفهوم الفني، أو أي صفحة HTML تفاعلية تعلم مفهومًا من خلال خطوات متسلسلة. تشغيل عبارات مثل "إنشاء شرح تفاعلي"، أو "إنشاء تصور لـ"، أو "إنشاء رسم متحرك خطوة بخطوة"، أو "صفحة HTML تفاعلية حول"، أو "تعليم هذا المفهوم بشكل مرئي"، أو "إنشاء جولة تعليمية".
