Créez des visualisations éducatives HTML interactives étape par étape avec le thème GitHub-dark, les commandes de navigation et le rendu animé basé sur l'état. À utiliser lorsque l'utilisateur demande à créer une explication interactive, une visualisation pédagogique, une animation pas à pas, une présentation d'un concept technique ou toute page HTML interactive qui enseigne un concept à travers des étapes séquentielles. Se déclenche sur des expressions telles que « créer une explication interactive », « créer une visualisation pour », « créer une animation étape par étape », « page HTML interactive sur », « enseigner ce concept visuellement » ou « créer une procédure pédagogique pas à pas ».
