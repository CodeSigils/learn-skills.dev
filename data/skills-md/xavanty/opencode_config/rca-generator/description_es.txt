Genere documentos de análisis de causa raíz (RCA) en formato de rebajas a partir de recursos proporcionados por el usuario. Úselo cuando los usuarios soliciten crear un RCA, un informe de incidentes, una autopsia o analizar problemas de servicio. Especializado para LLM Ops (vLLM, LiteLLM, SGLang) pero funciona para cualquier incidente de infraestructura. Acepta cualquier formato de entrada (métricas CSV, archivos de registro, PDF, documentos, capturas de pantalla, imágenes). Activadores de frases como "crear un RCA", "analizar este incidente", "por qué falló", "generar post-mortem" o "qué causó esta interrupción".
