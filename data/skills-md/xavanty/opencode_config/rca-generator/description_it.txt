Genera documenti RCA (Root Cause Analysis) in formato markdown dalle risorse fornite dall'utente. Da utilizzare quando gli utenti chiedono di creare una RCA, un rapporto sugli incidenti, un'autopsia o analizzare i problemi del servizio. Specializzato per LLM Ops (vLLM, LiteLLM, SGLang) ma funziona per qualsiasi incidente infrastrutturale. Accetta qualsiasi formato di input (metriche CSV, file di registro, PDF, documenti, screenshot, immagini). Si attiva su frasi come "crea un RCA", "analizza questo incidente", "perché non è riuscito", "genera post mortem" o "cosa ha causato questa interruzione".
