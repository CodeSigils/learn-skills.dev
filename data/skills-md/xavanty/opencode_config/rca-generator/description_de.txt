Generieren Sie Dokumente zur Ursachenanalyse (RCA) im Markdown-Format aus vom Benutzer bereitgestellten Ressourcen. Wird verwendet, wenn Benutzer eine RCA, einen Vorfallbericht, eine Obduktion oder die Analyse von Serviceproblemen erstellen möchten. Spezialisiert auf LLM-Operationen (vLLM, LiteLLM, SGLang), funktioniert aber bei jedem Infrastrukturvorfall. Akzeptiert jedes Eingabeformat (CSV-Metriken, Protokolldateien, PDFs, Dokumente, Screenshots, Bilder). Wird durch Ausdrücke wie „RCA erstellen“, „Diesen Vorfall analysieren“, „Warum ist dies fehlgeschlagen“, „Post-Mortem erstellen“ oder „Was hat diesen Ausfall verursacht“ ausgelöst.
