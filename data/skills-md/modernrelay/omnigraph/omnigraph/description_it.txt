Archivia, recupera ed esegui query su conoscenze, memoria e relazioni in un grafico Omnigraph e gestisci una distribuzione Omnigraph locale o remota. Da utilizzare quando l'utente desidera acquisire o richiamare fatti, note o entità, creare o eseguire query su un knowledge graph o sulla memoria dell'agente oppure eseguire Omnigraph e ogni volta che vengono visualizzati comandi CLI di Omnigraph (omnigraph init/query/mutate/load/schema/lint/embed/branch/commit/login/profile/cluster), file di schema .pg o query .gq, URI del grafico s3://, endpoint del grafico con autenticazione al portatore, errori 504 o a cluster.yaml / omnigraph.yaml / ~/.omnigraph/config.yaml. Copre distribuzioni in modalità cluster (cluster.yaml plan/apply, omnigraph-server --cluster), le due superfici di configurazione (cluster.yaml + ~/.omnigraph/config.yaml), evoluzione dello schema, linting delle query, scritture di dati (mutazione; esigenze di caricamento --mode/--from), rami, incorporamenti, policy Cedar e operazioni remote. Particolarmente importante prima dell'applicazione dello schema (pianificare prima), qualsiasi caricamento (--modalità richiesta), qualsiasi modifica .gq/.pg (lint dopo) o qualsiasi scrittura remota (verifica tramite elenco di commit).
