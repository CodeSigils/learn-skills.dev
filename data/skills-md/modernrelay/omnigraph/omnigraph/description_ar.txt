قم بتخزين المعرفة والذاكرة والعلاقات واستعادتها والاستعلام عنها في الرسم البياني Omnigraph، وتشغيل نشر Omnigraph محليًا أو عن بعد. يُستخدم عندما يريد المستخدم التقاط الحقائق أو الملاحظات أو الكيانات أو تذكرها، أو إنشاء رسم بياني معرفي أو ذاكرة الوكيل أو الاستعلام عنه، أو تشغيل Omnigraph - وعندما ترى أوامر Omnigraph CLI (omnigraph init/query/mutate/load/schema/lint/embed/branch/commit/login/profile/cluster)، أو مخطط .pg أو ملفات استعلام .gq، أو معرفات URI للرسم البياني s3://، أو رسم بياني مصادق عليه الحامل نقاط النهاية، أو أخطاء 504، أو block.yaml / omnigraph.yaml / ~/.omnigraph/config.yaml. يغطي عمليات نشر الوضع العنقودي (خطة/تطبيقcluster.yaml، omnigraph-server --cluster)، وسطحي التكوين (cluster.yaml + ~/.omnigraph/config.yaml)، وتطور المخطط، وفحص الاستعلام، وكتابة البيانات (تغيير؛ احتياجات التحميل --mode/--from)، والفروع، والتضمينات، وسياسة Cedar، والعمليات عن بعد. مهم بشكل خاص قبل تطبيق المخطط (الخطة أولاً)، أو أي تحميل (--الوضع مطلوب)، أو أي تحرير .gq/.pg (الوبر بعد ذلك)، أو أي كتابة عن بعد (التحقق عبر قائمة الالتزام).
