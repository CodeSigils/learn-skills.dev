LLM Wiki: Build a three-tier directory LLM knowledge base in Feishu Cloud Drive or Knowledge Base. Supports both Cloud Drive and Knowledge Base storage modes. Supports knowledge base initialization (init), material import (import), source document ingestion (ingest), knowledge query (query), and health check (lint). Use when users need to organize documents, articles, and notes into a structured knowledge base, or retrieve and synthesize answers from an existing knowledge base.
