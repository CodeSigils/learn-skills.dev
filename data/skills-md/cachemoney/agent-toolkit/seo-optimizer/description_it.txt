Ottimizzazione SEO completa per applicazioni web. Utilizzare quando richiesto per migliorare il posizionamento nelle ricerche, aggiungere meta tag, creare dati strutturati, generare mappe dei siti, ottimizzare per Core Web Vitals o analizzare problemi SEO. Funziona con Next.js, Astro, React e siti HTML statici.
