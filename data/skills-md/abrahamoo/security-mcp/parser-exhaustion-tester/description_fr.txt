Teste les analyseurs pour les attaques de complexité algorithmique : bombes XML, attaques d'objets imbriqués, JSON profondément imbriqués, bombes YAML, retour en arrière catastrophique des regex et épuisement du processeur/mémoire via des entrées spécialement conçues. Couvre le §3.6 (sécurité de l'analyseur), le §8 (disponibilité).
