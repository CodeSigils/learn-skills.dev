Evidenzbasierte Regeln zum Schreiben von Code als Wissensgraph, der die Agenten-KI ausrichtet. Verwendung beim Verfassen von neuem Code, beim Refactoring für Agenten-Handhabbarkeit, beim Entwerfen von Modulgrenzen, beim Benennen von Bezeichnern, beim Schreiben von Typen, beim Dokumentieren von Modulen, beim Auswählen von Architekturmustern (hexagonal, sauber, vertikales Slice, funktionaler Kern/Imperativ-Shell), beim Dimensionieren von Funktionen/Dateien/Klassen, beim Definieren von Architekturdeskriptoren (AGENTS.md, ADRs), beim Strukturieren von Monorepos (Nx, Turborepo, Bazel, Buck2, Pants, Arbeitsbereichsgrenzen, betroffene Diagramme, Deskriptoren pro Paket) oder das Einrichten von Validierungs-Gates, die diese Eigenschaften erzwingen. Löst Aufgaben aus, die als „Wie soll dieser Code geschrieben werden“, „durch Agenten lesbarer Code“, „Code als Wissensgraph“, „Namenskonvention“, „Ordnerstruktur“, „AGENTS.md“, „CLAUDE.md“, „ADR“, „Funktionssignatur“, „Typvertrag“, „strukturierte Ausgabe“, „Codierungsagent auf Repo-Ebene“, „Monorepo“, „Arbeitsbereich“, „Modulgrenze“, „Architekturmuster“, „hexagonal“, „saubere Architektur“, „Abhängigkeitsrichtung“ usw. eingerahmt werden „betroffener Graph“.
