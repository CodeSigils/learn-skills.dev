Создавайте звуковые эффекты для игр, используя API ElevenLabs. Используйте этот навык всякий раз, когда пользователь упоминает звуковые эффекты, SFX, генерацию звука, звуки игры или хочет создать/экспортировать аудиоресурсы для игрового проекта. Также срабатывает, когда у пользователя есть SOUND_DESIGN.md или он спрашивает о создании звуков из подсказок. Управляет всем конвейером — анализирует игровой код, пишет документы по звуковому дизайну, генерирует варианты аудио AI и позволяет пользователю выбирать избранное в пользовательском интерфейсе браузера.
