Genera efectos de sonido para juegos usando la API de ElevenLabs. Utilice esta habilidad siempre que el usuario mencione efectos de sonido, SFX, generación de audio, sonidos de juegos o quiera crear/exportar recursos de audio para un proyecto de juego. También se activa cuando el usuario tiene un SOUND_DESIGN.md o pregunta sobre la generación de sonidos a partir de indicaciones. Maneja todo el proceso: analiza el código del juego, escribe documentos de diseño de sonido, genera variantes de audio de IA y permite al usuario elegir favoritos en la interfaz de usuario de un navegador.
