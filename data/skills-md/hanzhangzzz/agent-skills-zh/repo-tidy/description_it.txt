Riordino del repository Git e base delle attività parallele: torna all'ultimo master/principale, elimina i rami uniti o andati a monte, rimuovi gli alberi di lavoro obsoleti; `--new <task>` riordina + crea un ramo di attività in un comando e crea automaticamente un albero di lavoro parallelo quando la cassa principale è occupata; un hook SessionStart inserisce lo stato del repository all'avvio di una sessione. Da utilizzare quando si avvia una nuova attività, quando [repo-status] mostra che il repository non è master o contiene elementi pulibili o quando l'utente dice 归位, 整理仓库, 清理分支, 清理 worktree, 开新任务, repo tidy, tidy repo, clean branch.
