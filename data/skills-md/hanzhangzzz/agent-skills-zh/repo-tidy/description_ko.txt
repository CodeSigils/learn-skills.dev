Git 저장소 정리 및 병렬 작업 기반: 최신 마스터/메인으로 다시 전환하고, 병합되거나 업스트림에서 사라진 분기를 삭제하고, 오래된 작업 트리를 제거합니다. `--new <task>`는 깔끔한 작업을 수행하고 하나의 명령으로 작업 분기를 생성하며 기본 체크아웃이 바쁠 때 병렬 작업 트리를 자동 생성합니다. SessionStart 후크는 세션이 시작될 때 repo 상태를 주입합니다. 새 작업을 시작할 때, [repo-status]에 저장소가 마스터에서 벗어났거나 정리 가능한 항목이 있음을 표시할 때, 또는 사용자가 归位, 整理仓库, 清理分支, 清理 worktree, 开新任务, repo tidy, tidy repo, clean Branch라고 말할 때 사용합니다.
