Git リポジトリの整理と並列タスクのベース: 最新のマスター/メインに戻し、マージされたブランチまたは上流に存在しなくなったブランチを削除し、古くなったワークツリーを削除します。 `--new <task>` は、1 つのコマンドでタスク ブランチを作成し、メイン チェックアウトがビジー状態のときに並列ワークツリーを自動作成します。 SessionStart フックは、セッションの開始時にリポジトリ ステータスを挿入します。新しいタスクを開始するとき、[repo-status] でリポジトリがマスターから外れている、またはクリーンアップ可能な項目があることが示されているとき、またはユーザーが「归位」、「整理仓库」、「清理分支」、「清理ワークツリー」、「开新任务」、「リポ整頓」、「整然としたリポ」、「クリーンブランチ」と言ったときに使用します。
