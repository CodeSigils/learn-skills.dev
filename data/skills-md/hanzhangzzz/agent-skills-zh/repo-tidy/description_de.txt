Aufräumen des Git-Repositorys und Basis paralleler Aufgaben: Wechseln Sie zurück zum neuesten Master/Main, löschen Sie zusammengeführte oder Upstream-vergangene Zweige, entfernen Sie veraltete Arbeitsbäume; `--new <task>` erledigt das Aufräumen + Erstellen eines Aufgabenzweigs in einem Befehl und erstellt automatisch einen parallelen Arbeitsbaum, wenn die Hauptkasse beschäftigt ist; Ein SessionStart-Hook fügt den Repo-Status ein, wenn eine Sitzung beginnt. Wird verwendet, wenn eine neue Aufgabe gestartet wird, wenn [Repo-Status] anzeigt, dass das Repo nicht mehr im Master ist oder über reinigungsfähige Elemente verfügt, oder wenn der Benutzer sagt: 归位, 整理仓库, 清理分支, 清理 Worktree, 开新任务, Repo aufgeräumt, Repo aufgeräumt, Zweige reinigen.
