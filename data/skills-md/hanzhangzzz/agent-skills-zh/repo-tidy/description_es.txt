Ordenación del repositorio de Git y base de tareas paralelas: volver al último maestro/principal, eliminar ramas fusionadas o ascendentes, eliminar árboles de trabajo obsoletos; `--new <tarea>` tidy + crea una rama de tarea en un comando y crea automáticamente un árbol de trabajo paralelo cuando la caja principal está ocupada; un gancho SessionStart inyecta el estado del repositorio cuando se inicia una sesión. Úselo al iniciar una nueva tarea, cuando [repo-status] muestra que el repositorio está fuera del maestro o tiene elementos que se pueden limpiar, o cuando el usuario dice 归位, 整理仓库, 清理分支, 清理 worktree, 开新任务, repo tidy, tidy repo, clean Branches.
