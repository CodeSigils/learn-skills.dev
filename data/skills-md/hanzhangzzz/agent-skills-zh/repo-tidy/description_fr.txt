Rangement du référentiel Git et base de tâches parallèles : revenez au dernier maître/principal, supprimez les branches fusionnées ou disparues en amont, supprimez les arbres de travail obsolètes ; `--new <task>` fait ranger + crée une branche de tâches en une seule commande et crée automatiquement un arbre de travail parallèle lorsque la caisse principale est occupée ; un hook SessionStart injecte le statut du dépôt lorsqu'une session démarre. À utiliser lors du démarrage d'une nouvelle tâche, lorsque [repo-status] indique que le dépôt n'est pas maître ou contient des éléments nettoyables, ou lorsque l'utilisateur dit 归位, 整理仓库, 清理分支, 清理 worktree, 开新任务, repo ranger, ranger ranger, nettoyer les branches.
