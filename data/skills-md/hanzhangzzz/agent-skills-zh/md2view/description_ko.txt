Markdown 문서를 사람이 읽을 수 있는 추적 가능한 보기로 다시 인코딩합니다. 원본이 왼쪽에 있고 모델이 설계한 시각적 재구성이 오른쪽에 있는 단일 파일 HTML입니다(아키텍처 다이어그램, 흐름 체인, 비교 행렬, 인수 맵, 주석이 달린 카드). 여기서 모든 요소는 데이터 소스 앵커를 다시 소스로 전달하고 표시되는 텍스트는 어휘 앵커를 유지하며 숫자는 그대로 복사됩니다. 사용자가 회고, 보고서, 사양, README 또는 긴 기술 문서를 더 쉽게 흡수하고 공유할 수 있는 것으로 바꾸려는 경우에 사용하거나 /md2view, md2view, 信息重组, 双栏阅读, 文档可视化, 把文档做成图라고 말합니다. 충실한 Markdown 렌더링에는 사용하지 마세요.
