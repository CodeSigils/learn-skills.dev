Vuelva a codificar un documento Markdown en una vista rastreable de lectura humana: un HTML de un solo archivo con el original a la izquierda y una reorganización visual diseñada por el modelo a la derecha (diagramas de arquitectura, cadenas de flujo, matrices de comparación, mapas de argumentos, tarjetas anotadas), donde cada elemento lleva anclajes de fuentes de datos a la fuente, el texto visible mantiene anclajes léxicos y los números se copian palabra por palabra. Úselo cuando el usuario quiera que una retrospectiva, un informe, una especificación, un LÉAME o un documento técnico extenso se convierta en algo más fácil de asimilar y compartir, o diga /md2view, md2view, 信息重组, 双栏阅读, 文档可视化, 把文档做成图. No lo utilice para una representación fiel de Markdown.
