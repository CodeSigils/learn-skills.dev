Réencodez un document Markdown dans une vue traçable en lecture humaine : un fichier HTML unique avec l'original à gauche et une réorganisation visuelle conçue par modèle à droite (diagrammes d'architecture, chaînes de flux, matrices de comparaison, cartes d'arguments, cartes annotées), où chaque élément ramène les ancres des sources de données à la source, le texte visible conserve les ancres lexicales et les nombres sont copiés textuellement. À utiliser lorsque l'utilisateur souhaite qu'une rétrospective, un rapport, une spécification, un README ou un long document technique soit transformé en quelque chose de plus facile à absorber et à partager, ou dit /md2view, md2view, 信息重组, 双栏阅读, 文档可视化, 把文档做成图. Ne pas utiliser pour un rendu Markdown simple et fidèle.
