Ricodificare un documento Markdown in una vista tracciabile di lettura umana: un file HTML a file singolo con l'originale a sinistra e una riorganizzazione visiva progettata dal modello a destra (diagrammi di architettura, catene di flusso, matrici di confronto, mappe di argomenti, schede annotate), dove ogni elemento riporta le ancore delle origini dati alla fonte, il testo visibile mantiene le ancore lessicali e i numeri vengono copiati parola per parola. Da utilizzare quando l'utente desidera che una retrospettiva, un report, una specifica, un README o un lungo documento tecnico si trasformino in qualcosa di più facile da assorbire e condividere, oppure dice /md2view, md2view, 信息重组, 双栏阅读, 文档可视化, 把文档做成图. Non utilizzare per il rendering Markdown semplice e fedele.
