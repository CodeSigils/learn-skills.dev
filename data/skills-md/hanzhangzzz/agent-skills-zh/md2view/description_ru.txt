Перекодируйте документ Markdown в отслеживаемый для чтения человеком вид: однофайловый HTML-код с оригиналом слева и визуальной реорганизацией, разработанной с помощью модели, справа (схемы архитектуры, цепочки операций, матрицы сравнения, карты аргументов, аннотированные карты), где каждый элемент переносит привязки источников данных обратно в источник, видимый текст сохраняет лексические привязки, а числа копируются дословно. Используйте, когда пользователь хочет, чтобы ретроспектива, отчет, спецификация, README или длинный технический документ превратились во что-то более легкое для восприятия и распространения, или говорит /md2view, md2view, 信息重组, 双栏阅读, 文档可视化, 把文档做成图. Не используйте для простого и точного рендеринга Markdown.
