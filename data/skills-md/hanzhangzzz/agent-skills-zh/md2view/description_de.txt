Codieren Sie ein Markdown-Dokument in eine nachverfolgbare, für den Menschen lesbare Ansicht neu: ein Einzeldatei-HTML mit dem Original auf der linken Seite und einer vom Modell entworfenen visuellen Neuorganisation auf der rechten Seite (Architekturdiagramme, Flussketten, Vergleichsmatrizen, Argumentkarten, mit Anmerkungen versehene Karten), wobei jedes Element Datenquellenanker zurück zur Quelle trägt, sichtbarer Text lexikalische Anker behält und Zahlen wörtlich kopiert werden. Verwenden Sie diese Option, wenn der Benutzer eine Retrospektive, einen Bericht, eine Spezifikation, eine README-Datei oder ein langes technisches Dokument in etwas umwandeln möchte, das sich leichter aufnehmen und teilen lässt, oder wenn er /md2view, md2view, 信息重组, 双栏阅读, 文档可视化, 把文档做成图 sagt. Nicht für einfach originalgetreues Markdown-Rendering verwenden.
