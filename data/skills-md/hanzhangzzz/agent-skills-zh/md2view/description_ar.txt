إعادة ترميز مستند Markdown إلى عرض قراءة بشرية يمكن تتبعه: ملف HTML واحد مع النص الأصلي على اليسار وإعادة تنظيم مرئي مصمم للنموذج على اليمين (المخططات المعمارية، وسلاسل التدفق، ومصفوفات المقارنة، وخرائط الوسيطات، والبطاقات المشروحة)، حيث يحمل كل عنصر نقاط ارتساء مصادر البيانات مرة أخرى إلى المصدر، ويحتفظ النص المرئي بالمثبتات المعجمية ويتم نسخ الأرقام حرفيًا. يُستخدم عندما يريد المستخدم تحويل مستند بأثر رجعي أو تقرير أو مواصفات أو ملف README أو مستند فني طويل إلى شيء يسهل استيعابه ومشاركته، أو يقول /md2view، md2view، 信息重组، 双栏阅读، 文档可视化، 把文档做成图. لا تستخدم لعرض Markdown المخلص البسيط.
