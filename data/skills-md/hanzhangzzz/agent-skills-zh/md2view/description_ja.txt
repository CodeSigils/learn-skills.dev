Markdown ドキュメントを追跡可能な人間が読めるビューに再エンコードします。左側にオリジナルの単一ファイル HTML、右側にモデル設計の視覚的再編成 (アーキテクチャ図、フロー チェーン、比較行列、引数マップ、注釈付きカード) が表示されます。すべての要素がデータ ソース アンカーをソースに戻し、表示されるテキストは語彙アンカーを保持し、数値はそのままコピーされます。ユーザーが振り返り、レポート、仕様、README、または長い技術文書を吸収し共有しやすいものにしたい場合、または /md2view、md2view、信息重组、双栏阅读、文档可视化、把文档做成图 と言う場合に使用します。単純な忠実な Markdown レンダリングには使用しないでください。
