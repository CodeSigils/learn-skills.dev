Traduci un articolo tecnico inglese (URL web) o un PDF locale in cinese accurato, sezione per sezione con una terminologia coerente, mantenendo il 100% delle immagini, e crea un'anteprima HTML locale a tre colonne (originale · traduzione · diapositive AI). Le diapositive vengono generate tramite l'imagegen integrato della CLI Codex locale, quindi non è necessaria alcuna chiave API immagine. Da utilizzare quando l'utente condivide un post di blog, un documento, una pagina di documenti o un PDF in inglese e desidera una versione cinese fedele e affiancata oppure dice /doc-reader, 翻译这篇文章, 翻译文档, 翻译博客, 翻译 PDF, traduci questo articolo. Opzioni: --no-ppt salta la generazione delle diapositive, --quick traduce solo.
