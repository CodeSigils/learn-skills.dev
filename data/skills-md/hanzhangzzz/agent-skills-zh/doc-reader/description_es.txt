Traduzca un artículo técnico en inglés (URL web) o un PDF local al chino preciso, sección por sección con terminología consistente, manteniendo el 100% de las imágenes, y cree una vista previa HTML local de tres columnas (original · traducción · diapositivas AI). Las diapositivas se generan a través del imagegen integrado de la CLI del Codex local, por lo que no se necesita ninguna clave API de imagen. Úselo cuando el usuario comparte una publicación de blog, un artículo, una página de documentos o un PDF en inglés y desea una versión china fiel y paralela, o dice /doc-reader, 翻译这篇文章, 翻译文档, 翻译博客, 翻译 PDF, traduce este artículo. Opciones: --no-ppt omite la generación de diapositivas, --quick traduce únicamente.
