Übersetzen Sie einen englischen Fachartikel (Web-URL) oder eine lokale PDF-Datei Abschnitt für Abschnitt mit einheitlicher Terminologie in genaues Chinesisch, behalten Sie dabei 100 % der Bilder bei und erstellen Sie eine lokale dreispaltige HTML-Vorschau (Original · Übersetzung · KI-Folien). Folien werden über das in der lokalen Codex-CLI integrierte Imagegen generiert, sodass kein Bild-API-Schlüssel erforderlich ist. Verwenden Sie diese Option, wenn der Benutzer einen englischen Blog-Beitrag, eine Arbeit, eine Dokumentationsseite oder eine PDF-Datei teilt und eine originalgetreue, parallele chinesische Version wünscht oder sagt: /doc-reader, 翻译这篇文章, 翻译文档, 翻译博客, 翻译 PDF, diesen Artikel übersetzen. Optionen: --no-ppt überspringt die Foliengenerierung, --quick übersetzt nur.
