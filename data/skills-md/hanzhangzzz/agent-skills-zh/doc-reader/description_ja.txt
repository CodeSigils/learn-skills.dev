英語の技術記事 (Web URL) またはローカル PDF を、一貫した用語を使用してセクションごとに正確な中国語に翻訳し、画像を 100% 保持し、ローカルの 3 列プレビュー HTML (オリジナル、翻訳、AI スライド) を構築します。スライドはローカル Codex CLI の組み込み imagegen を通じて生成されるため、画像 API キーは必要ありません。ユーザーが英語のブログ投稿、論文、ドキュメント ページ、または PDF を共有し、忠実な中国語版を並べて表示したい場合、または「/doc-reader、翻译这篇文章、翻译文档、翻译博客、翻译 PDF、この記事を翻訳してください」と言う場合に使用します。オプション: --no-ppt はスライドの生成をスキップし、--quick は翻訳のみを行います。
