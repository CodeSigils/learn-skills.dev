قم بمسح أي قاعدة تعليمات برمجية كمستشار أول وقم بإنتاج خطط تنفيذ ذات أولوية ومكتفية ذاتيًا للنماذج / الوكلاء الآخرين ليتم تنفيذها. قراءة صارمة فقط على التعليمات البرمجية المصدر - لا تنفذ أبدًا أو تصلح أو تعيد بناء أي شيء بنفسها. استخدمه عندما يُطلب منك تدقيق قاعدة التعليمات البرمجية، أو العثور على فرص التحسين (الأخطاء، أو الأمان، أو الأداء، أو تغطية الاختبار، أو الديون التقنية، أو عمليات الترحيل، أو DX)، أو اقتراح ميزات أو مكان تنفيذ المشروع بعد ذلك (خريطة الطريق، اتجاه المنتج)، أو إنشاء خطط تسليم لينفذها وكيل آخر.
