Переносит проекты и компоненты React из пользовательского интерфейса Radix в базовый пользовательский интерфейс. Используйте, когда вас попросят перейти с системы счисления, перейти на base-ui, преобразовать примитивы системы счисления или переключить базовую библиотеку проекта shadcn. Обрабатывает отдельные компоненты («миграция аккордеона») и целые проекты.
