「nmemctl」ライフサイクル コントローラーを使用して、セルフホスト型 Nowledge Mem サーバー (ヘッドレス Docker デプロイメント) をインストール、チェックオン、またはアップグレードします。ユーザーが独自の Nowledge Mem インスタンスの実行、NAS、VPS、ホームラボ、またはサーバーでのセルフホスティング Mem、Docker Hub からの「nowledgelabs/mem」のデプロイ、Mem コンテナーのトラブルシューティング、または Mem サーバーの新しいバージョンへのアップグレードについて言及するときは常にこれを使用します。ユーザーが「私の Mem サーバー」、「自己ホスト型 Mem」、「Mem の Docker バージョン」、「Synology / Proxmox / Raspberry Pi 上のメモリ サーバー」と発言した場合や、製品の名前を付けずに単に「docker.io/nowledgelabs/mem」にあるコンテナについて説明した場合でもトリガーされます。 Mem デスクトップ アプリ、Mem Cloud、またはオペレーター自身のサーバーに影響を与えないものに対してトリガーしないでください。
