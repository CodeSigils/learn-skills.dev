Installieren, überprüfen oder aktualisieren Sie einen selbst gehosteten Nowledge Mem-Server (die Headless Docker-Bereitstellung) mithilfe des „nmemctl“-Lebenszyklus-Controllers. Verwenden Sie dies immer dann, wenn der Benutzer erwähnt, dass er seine eigene Nowledge Mem-Instanz betreibt, Mem selbst auf einem NAS, VPS, Homelab oder Server hostet, „nowledgelabs/mem“ über Docker Hub bereitstellt, Fehler in seinem Mem-Container behebt oder einen Mem-Server auf eine neuere Version aktualisiert. Wird auch dann ausgelöst, wenn der Benutzer „mein Mem-Server“, „selbst gehostetes Mem“, „die Docker-Version von Mem“, „Speicherserver auf meinem Synology/Proxmox/Raspberry Pi“ sagt oder einfach einen Container beschreibt, der sich unter „docker.io/nowledgelabs/mem“ befindet, ohne das Produkt zu benennen. Lösen Sie NICHT für die Mem-Desktop-App, Mem Cloud oder alles aus, was nicht den eigenen Server des Betreibers berührt.
