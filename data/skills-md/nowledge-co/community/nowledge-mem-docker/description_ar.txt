قم بتثبيت خادم Nowledge Mem المستضاف ذاتيًا أو التحقق منه أو ترقيته (نشر Docker بدون رأس) باستخدام وحدة تحكم دورة الحياة `nmemctl`. استخدم هذا عندما يذكر المستخدم تشغيل مثيل Nowledge Mem الخاص به، أو استضافة Mem ذاتيًا على NAS، أو VPS، أو homelab، أو الخادم، أو نشر `nowledgelabs/mem` من Docker Hub، أو استكشاف أخطاء حاوية Mem الخاصة به، أو ترقية خادم Mem إلى إصدار أحدث. يتم التشغيل حتى عندما يقول المستخدم "my Mem server"، أو "Mem المستضاف ذاتيًا"، أو "إصدار عامل الإرساء من Mem"، أو "خادم الذاكرة على Synology / Proxmox / Raspberry Pi"، أو يصف فقط حاوية موجودة في docker.io/nowledgelabs/mem دون تسمية المنتج. لا تقم بتشغيل تطبيق Mem لسطح المكتب أو Mem Cloud أو أي شيء لا يمس خادم المشغل الخاص.
