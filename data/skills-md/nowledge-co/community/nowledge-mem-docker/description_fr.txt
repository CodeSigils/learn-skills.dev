Installez, vérifiez ou mettez à niveau un serveur Nowledge Mem auto-hébergé (le déploiement Docker sans tête) à l'aide du contrôleur de cycle de vie « nmemctl ». Utilisez-le chaque fois que l'utilisateur mentionne l'exécution de sa propre instance Nowledge Mem, l'auto-hébergement de Mem sur un NAS, un VPS, un homelab ou un serveur, le déploiement de « nowledgelabs/mem » à partir de Docker Hub, le dépannage de son conteneur Mem ou la mise à niveau d'un serveur Mem vers une version plus récente. Déclenchez même lorsque l'utilisateur dit « mon serveur Mem », « Mem auto-hébergé », « la version docker de Mem », « serveur de mémoire sur mon Synology / Proxmox / Raspberry Pi », ou décrit simplement un conteneur qui se trouve sur « docker.io/nowledgelabs/mem » sans nommer le produit. Ne déclenchez PAS pour l'application de bureau Mem, Mem Cloud ou tout ce qui ne touche pas le propre serveur de l'opérateur.
