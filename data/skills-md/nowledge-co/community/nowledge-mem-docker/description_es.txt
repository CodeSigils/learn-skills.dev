Instale, verifique o actualice un servidor Nowledge Mem autohospedado (la implementación sin cabeza de Docker) usando el controlador de ciclo de vida `nmemctl`. Utilice esto siempre que el usuario mencione ejecutar su propia instancia de Nowledge Mem, alojar Mem en un NAS, VPS, homelab o servidor, implementar `nowledgelabs/mem` desde Docker Hub, solucionar problemas de su contenedor Mem o actualizar un servidor Mem a una versión más nueva. Se activa incluso cuando el usuario dice "mi servidor Mem", "Mem autohospedado", "la versión acoplable de Mem", "servidor de memoria en mi Synology/Proxmox/Raspberry Pi", o simplemente describe un contenedor que está en `docker.io/nowledgelabs/mem` sin nombrar el producto. NO active la aplicación de escritorio Mem, Mem Cloud ni nada que no toque el servidor del propio operador.
