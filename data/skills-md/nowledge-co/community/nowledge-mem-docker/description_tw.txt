使用 nmemctl 生命週期控制器安裝、檢查或升級自架 Nowledge Mem 伺服器（無頭 Docker 部署）。每當使用者提到執行自己的 Nowledge Mem 實例、在 NAS、VPS、homelab 或伺服器上自託管 Mem、從 Docker Hub 部署「nowledgelabs/mem」、對 Mem 容器進行故障排除或將 Mem 伺服器升級到新版本時，請使用此選項。即使用戶說“我的 Mem 伺服器”、“自架 Mem”、“Mem 的 docker 版本”、“我的 Synology / Proxmox / Raspberry Pi 上的記憶體伺服器”，或者只是描述位於 `docker.io/nowledgelabs/mem` 的容器而不命名產品，也會觸發。請勿觸發 Mem 桌面應用程式、Mem Cloud 或任何不觸及營運商自己的伺服器的內容。
