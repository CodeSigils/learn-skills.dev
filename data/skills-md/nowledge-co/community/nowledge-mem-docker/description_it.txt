Installa, controlla o aggiorna un server Nowledge Mem self-hosted (la distribuzione Docker headless) utilizzando il controller del ciclo di vita `nmemctl`. Utilizzalo ogni volta che l'utente menziona l'esecuzione della propria istanza Nowledge Mem, l'hosting autonomo di Mem su un NAS, VPS, homelab o server, la distribuzione di `nowledgelabs/mem` da Docker Hub, la risoluzione dei problemi del contenitore Mem o l'aggiornamento di un server Mem a una versione più recente. Si attiva anche quando l'utente dice "il mio server Mem", "Mem self-hosted", "la versione docker di Mem", "server di memoria sul mio Synology/Proxmox/Raspberry Pi" o semplicemente descrive un contenitore che si trova su "docker.io/nowledgelabs/mem" senza nominare il prodotto. NON attivare l'app desktop Mem, Mem Cloud o qualsiasi cosa che non tocchi il server dell'operatore.
