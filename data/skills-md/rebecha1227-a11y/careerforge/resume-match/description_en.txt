Resume and job JD matching analysis tool. Upload a resume (PDF/DOCX/text) and the target job JD (text/image/URL), and output multi-dimensional scores, matching level (A/B/C), key gap analysis, and specific optimization recommendations. Trigger when the user mentions any of the following keywords: 简历匹配, 简历分析, 岗位匹配, JD分析, 简历评分, resume match, resume analysis, job fit, 简历诊断, 简历评估, 匹配度分析, 简历和JD对比, 岗位适配度, resume review, resume scoring. When the user provides both a resume file and a job JD, it should also be automatically triggered. Even if the user does not explicitly say “matching analysis,” as long as they provide a resume + JD and want to know “whether it’s suitable,” “whether they can apply,” or “where the gaps are,” this skill should be activated.
