Инструмент для создания и оптимизации резюме. Поддерживает два режима: создание совершенно нового резюме с нуля (сбор информации посредством структурированного диалога) или улучшение существующего резюме (чтение текущего резюме и его улучшение). Выводит форматы HTML и PDF с профессиональной версткой строго в пределах двух страниц. Поддерживает двуязычное (китайско-английское) создание резюме. Срабатывает, когда пользователь упоминает любое из следующих ключевых слов: создать резюме, написать резюме, составить резюме, создать резюме, оптимизировать резюме, отредактировать резюме, украшение резюме, создать резюме, составить резюме, оптимизировать резюме, помочь мне составить резюме, макет резюме, составить резюме, отредактировать резюме, шаблон резюме, шаблон резюме, дизайн резюме, дизайн резюме. Когда пользователь приходит из резюме-сопоставления (с уже оптимизированным резюме Markdown), этот навык также должен быть активирован для создания версий HTML+PDF. Даже если пользователь говорит только «помогите мне составить хорошее резюме» или «отформатировать резюме», оно все равно должно сработать.

Пожалуйста, всегда отвечайте на языке пользователя.
