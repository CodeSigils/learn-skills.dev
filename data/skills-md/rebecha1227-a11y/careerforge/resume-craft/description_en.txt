Resume generation and optimization tool. Supports two modes: generate a brand‑new resume from scratch (collecting information through structured dialogue), or enhance an existing resume (reading the current resume and improving it). Outputs both HTML and PDF formats, with a professional layout, strictly within two pages. Supports bilingual (Chinese–English) resume generation. Triggered when the user mentions any of the following keywords: generate resume, write resume, make resume, resume creation, optimize resume, edit resume, resume beautification, resume create, resume build, resume optimize, help me make a resume, resume layout, make a resume, edit the resume, resume template, resume template, resume design, resume design. When the user comes from resume-match (with an already‑optimized Markdown resume), this skill should also be triggered to generate HTML + PDF versions. Even if the user only says “help me make a nice resume” or “format the resume,” it should still trigger.

Please always respond in the user's language.
