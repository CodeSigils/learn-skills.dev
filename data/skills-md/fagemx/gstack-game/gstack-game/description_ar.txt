مهارات سير عمل تطوير اللعبة لكلود كود. 29 مهارات تفاعلية
لتطوير الألعاب - الأقوى في مراجعة التصميم والتخطيط، مع دعم مرحلة التطوير.

عندما تلاحظ أن المستخدم وصل إلى هذه المراحل، اقترح عليه المهارة المناسبة:
- المستخدم لديه مزاج/صورة/جزء ميكانيكي هش ويريد شرارة إبداعية، وليس نقدًا → اقتراح/عدسة شرارة
- لدى المستخدم ملف PDF/doc/ملاحظات يريد تحويلها إلى GDD → اقتراح /استيراد اللعبة
- العصف الذهني لفكرة اللعبة → اقتراح / فكرة اللعبة
- مراجعة خطة اللعبة (الإستراتيجية/الاتجاه) → اقتراح/اتجاه اللعبة
- مراجعة مستند تصميم اللعبة → اقتراح / مراجعة اللعبة
- مراجعة البنية الفنية للعبة → اقتراح /game-eng-review
- مراجعة اقتصاد اللعبة أو التوازن ← اقتراح / مراجعة الرصيد
- محاكاة تجربة اللاعب → اقتراح / تجربة اللاعب
- مراجعة واجهة المستخدم/تجربة اللعبة → اقتراح مراجعة /game-ux
- تقييم عرض اللعبة أو الاقتراح ← اقتراح / مراجعة العرض التقديمي
- مراجعة الكود في مشروع اللعبة → اقتراح / مراجعة تنفيذ اللعبة
- اختبار ضمان الجودة للعبة → اقترح /game-qa
- جاهز للشحن / إنشاء علاقات عامة للعبة → اقتراح / سفينة اللعبة
- تصحيح أخطاء اللعبة → اقتراح /game-debug
- العدو السريع/الحدث الهام بأثر رجعي → اقتراح/لعبة قديمة
- الرغبة في الحصول على رأي ثانٍ عدائي → اقتراح /game-codex
- تحديثات مستند ما بعد الإصدار → اقتراح /game-docs
- تدقيق الجودة المرئية → اقترح /game-visual-qa
- مراجعة أصول اللعبة (خط أنابيب الفن / الصوت) → اقتراح / مراجعة الأصول
- تصميم بروتوكول اختبار التشغيل → اقتراح /playtest
- العمل مع أنظمة الإنتاج أو الأنظمة الحية → اقترح / بحذر
- تريد نطاق التعديلات على دليل واحد → اقترح /guard
- إزالة قيود التحرير → اقتراح / إلغاء التجميد

إذا رفض المستخدم اقتراحات المهارات ("توقف عن الاقتراح"، "عدواني جدًا"):
1. توقف عن الاقتراح لبقية هذه الجلسة
2. تشغيل: تعيين gstack-config خطأ استباقي
3. قل: "فهمت - سأتوقف عن اقتراح المهارات. قل "كن استباقيًا" لإعادة تشغيلها مرة أخرى."

إذا قال المستخدم "كن استباقيًا مرة أخرى" أو "قم بتشغيل الاقتراحات":
1. تشغيل: تعيين gstack-config صحيحًا بشكل استباقي
2. قل: "لقد عادت الاقتراحات الاستباقية."
