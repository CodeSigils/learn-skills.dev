Claude Code의 게임 개발 워크플로 기술. 29가지 상호작용 기술
게임 개발용 — 개발 단계 지원을 통해 디자인 검토 및 계획이 가장 강력합니다.

사용자가 다음 단계에 있다는 것을 알게 되면 적절한 기술을 제안하십시오.
- 사용자는 취약한 기분/이미지/기계적 단편을 가지고 있으며 비판이 아닌 창의적인 불꽃을 원합니다 → /spark-lens 제안
- 사용자가 GDD로 전환하고 싶은 PDF/문서/노트를 가지고 있습니다 → /game-import를 제안하세요
- 게임 아이디어 브레인스토밍 → /game-ideation 제안
- 게임 기획(전략/방향) 검토 → /게임 방향 제시
- 게임 디자인 문서 검토 → /game-review 제안
- 게임의 기술적인 아키텍처 검토 → /game-eng-review 제안
- 게임 경제나 밸런스 검토 → /balance-review 제안
- 플레이어 경험 시뮬레이션 → /player-experience 제안
- 게임 UI/UX 검토 → /game-ux-review 제안
- 게임 피치나 제안서 평가 → /pitch-review 제안
- 게임 프로젝트 코드 리뷰 → /gameplay-implementation-review 제안
- 게임 QA 테스트 → /game-qa 제안
- 게임 출시 준비/홍보 생성 → /game-ship 제안
- 게임 버그 디버깅 → /game-debug 제안
- 스프린트/마일스톤 회고 → /game-retro 제안
- 적대적인 2차 의견을 원함 → /game-codex 제안
- 출시 후 문서 업데이트 → /game-docs 제안
- 시각적 품질 감사 → /game-visual-qa 제안
- 게임 자산 검토(아트/오디오 파이프라인) → /asset-review 제안
- 플레이테스트 프로토콜 설계 → /playtest 제안
- 프로덕션 또는 라이브 시스템 작업 → 제안/주의
- 편집 범위를 한 디렉터리로 지정하고 싶음 → /guard 제안
- 편집 제한 제거 → 제안/고정 해제

사용자가 기술 제안에 반발하는 경우('제안 중지', '너무 공격적'):
1. 남은 세션 동안 제안을 중지하세요.
2. 실행: gstack-config set active false
3. 다음과 같이 말합니다. "알겠습니다. 기술 제안을 중단하겠습니다. 다시 활성화하려면 '사전 대응'이라고 말하세요."

사용자가 "다시 적극적으로 대응해 주세요" 또는 "제안 기능을 켜주세요"라고 말하는 경우:
1. 실행: gstack-config set active true
2. "사전 제안이 다시 활성화되었습니다."라고 말합니다.
