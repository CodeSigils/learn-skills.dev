Навыки разработки игр для Claude Code. 29 интерактивных навыков
для разработки игр — сильнейший в области анализа и планирования дизайна, с поддержкой на этапе разработки.

Когда вы заметите, что пользователь находится на этом этапе, предложите соответствующий навык:
- У пользователя хрупкое настроение/изображение/механический фрагмент, и он хочет творческих искр, а не критики → предложить /spark-lens
- У пользователя есть PDF/документ/заметки, которые он хочет превратить в GDD → предложить /game-import
- Мозговой штурм идеи игры → предложить /game-ideation
- Обзор плана игры (стратегия/направление) → предложить /game-direction
- Рецензирование документа по дизайну игры → предложить /game-review.
- Обзор технической архитектуры игры → предложить /game-eng-review
- Пересмотр экономики или баланса игры → предложить /balance-review
- Имитация опыта игрока → предложить /player-experience
- Обзор пользовательского интерфейса/UX игры → предложить /game-ux-review
- Оценка питча или предложения игры → предложить /pitch-review
- Проверка кода игрового проекта → предложить /gameplay-implementation-review
- Тестирование игры → предложить /game-qa
- Готово отправить/создать пиар для игры → предложить /game-ship
- Отладка ошибки игры → предложить /game-debug
- Ретроспектива спринта/вехи → предложить /game-retro
- Хотите услышать состязательное второе мнение → предложить /game-codex
- Обновления документации после выпуска → предложить /game-docs
- Визуальный аудит качества → предложить /game-visual-qa
- Проверка игровых ресурсов (арт/аудиоконвейер) → предложить /asset-review
- Разработка протокола игрового тестирования → предложить /playtest
- Работа с производственными или действующими системами → советуем/осторожно.
- Хотите ограничить изменения одним каталогом → предложить /guard
- Снятие ограничений редактирования → предложить/разморозить

Если пользователь отвергает предложения по навыкам («перестаньте предлагать», «слишком агрессивно»):
1. Прекратите предлагать предложения до конца этого сеанса.
2. Запустите: gstack-config set proactive false
3. Скажите: «Понятно, я перестану предлагать навыки. Скажите «проявите инициативу», чтобы снова включить их».

Если пользователь говорит «проявите инициативу еще раз» или «включите подсказки»:
1. Запустите: gstack-config set proactive true.
2. Скажите: «Проактивные предложения снова включены».
