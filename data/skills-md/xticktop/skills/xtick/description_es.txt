API de datos bursátiles en tiempo real de XTick, que brinda acceso a datos financieros para acciones A, ETF, índices, acciones de Hong Kong, etc. de Shanghai, Shenzhen y Beijing, incluidos datos de mercado, datos financieros, indicadores técnicos, temas de actualidad, con más de 85 interfaces y admite envío de datos en tiempo real de WebSocket.
