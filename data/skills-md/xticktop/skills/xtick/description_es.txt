API de datos en tiempo real de acciones de XTick, que brinda acceso a datos financieros para acciones A, ETF, índices, acciones de Hong Kong, etc. de Shanghai, Shenzhen y Beijing, incluidos datos de mercado, datos financieros, indicadores técnicos, datos de puntos críticos y más de 85 interfaces, y admite envío de datos en tiempo real a través de WebSocket.
