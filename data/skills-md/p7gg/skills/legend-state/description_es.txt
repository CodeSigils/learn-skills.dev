Utilice Legend-State v3 para la gestión de estado local y remota en React, React Native o Vanilla JS. Active esta habilidad cada vez que el usuario mencione Legend-State, legend-state, @legendapp/state, observables, reactividad detallada, useValue, sincronizado, sincronizadoCrud, sincronizadoFetch, sincronizadoKeel, sincronizadoSupabase, sincronizadoQuery, para componentes, componentes reactivos o si desea configurar la administración del estado con persistencia/sincronización automática. Úselo también al migrar desde otras bibliotecas estatales a Legend-State, optimizar el rendimiento de Legend-State o depurar problemas de reactividad de Legend-State. Si el usuario está trabajando con cualquier gestión de estado que involucre observables, señales o reactividad detallada y Legend-State está instalado o se menciona, utilice esta habilidad.
