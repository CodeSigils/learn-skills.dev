Configura un ambiente di sviluppo Java full-stack su un nuovo Mac con un clic. Installa Java (JDK17/21), Maven, Redis, ZooKeeper, Nacos, MySQL, PostgreSQL, Kafka, Elasticsearch, RocketMQ, Go, Git, Node.js, Python e configura le variabili di ambiente della chiave API e i comandi di scelta rapida del middleware. Attivato quando l'utente richiede di inizializzare l'ambiente di sviluppo, impostare un ambiente Java, configurare una macchina di sviluppo o "setup dev env".
