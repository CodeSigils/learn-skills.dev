Configurez un environnement de développement Java full-stack sur un nouveau Mac en un seul clic. Installez Java (JDK 17/21), Maven, Redis, ZooKeeper, Nacos, MySQL, PostgreSQL, Kafka, Elasticsearch, RocketMQ, Go, Git, Node.js, Python, configurez les variables d'environnement de clé API et les commandes de raccourci pour le middleware. Déclenché lorsque l'utilisateur demande d'initialiser l'environnement de développement, de configurer un environnement Java, de configurer la machine de développement ou de configurer l'environnement de développement.
