Guía de interfaz de usuario para aplicaciones web instaladas en plataformas Apple: aplicaciones de pantalla de inicio de iOS y iPadOS primero (áreas seguras y con ajuste de ventana gráfica, barra de estado y color de tema después de iOS 26, barras y superposiciones adhesivas/fijas, imágenes de inicio, íconos y manifiesto, CSS táctil, sugerencias de instalación, errores de la versión de iOS) además de aplicaciones web "Agregar al Dock" de macOS Safari (lo que se transfiere, lo que no hace nada allí, las cookies, el alcance, los íconos, la barra de menú). Úselo al agregar o depurar el comportamiento Agregar a la pantalla de inicio o Agregar al Dock, diseño de muesca/área segura, metaetiquetas apple-mobile-web-app-*, manifiesto de la aplicación web, pantallas de presentación o cualquier cosa que solo parezca incorrecta como una aplicación web instalada en iPhone, iPad o Mac. No apto para trabajadores de servicios, almacenamiento en caché sin conexión ni inserción.
