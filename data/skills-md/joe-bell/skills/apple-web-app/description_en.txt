UI guidance for web apps installed on Apple platforms — iOS and iPadOS home-screen apps first (viewport-fit and safe areas, status bar and theme colour after iOS 26, sticky/fixed bars and overlays, startup images, icons and manifest, touch CSS, install hints, iOS-version gotchas) plus macOS Safari "Add to Dock" web apps (what carries over, what does nothing there, cookies, scope, icons, menu bar). Use when adding or debugging add-to-home-screen or Add to Dock behaviour, notch/safe-area layout, apple-mobile-web-app-* meta tags, web app manifest, splash screens, or anything that only looks wrong as an installed web app on iPhone, iPad or Mac. Not for service workers, offline caching, or push.
