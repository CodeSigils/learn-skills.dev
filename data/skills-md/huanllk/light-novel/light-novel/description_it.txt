"Sistema di creazione collaborativa di storie lunghe/medie/corte “Novel Execution Planning”. Quando gli utenti impiegano comandi come “Novel Execution Planning: Outline”, “Novel Execution Planning: Plan”, “Novel Execution Planning: Table of Contents”, “Novel Execution Planning: Short Story”, “Novel Execution Planning: Medium Story”, “Novel Execution Planning: Draft”, “Novel Execution Planning: Main Text”, “Novel Execution Planning: Health Check”, “Novel Execution Planning: Archive”, ecc., per scrivere romanzi lunghi a più volumi, romanzi di media lunghezza o racconti brevi, o quando devono garantire la coerenza della costruzione del mondo tra capitoli, il recupero di prefigurazioni, il controllo del ritmo e la stabilità stilistica, usano questa abilità.

Il sistema supporta qualsiasi finestra di contesto da 8 K a 2 M token, selezionando automaticamente una strategia di caricamento in base alle reali capacità del modello; offre tre modalità di creazione — leggera, standard e pubblicazione — e supporta il routing di comandi in linguaggio naturale e il caricamento dinamico dei vincoli.

Il sistema si basa su una base di conoscenza gerarchica: L0 Core / L1 Basic / L2 Extended / L3 Full Book.

Rispondi sempre nella lingua dell'utente.
