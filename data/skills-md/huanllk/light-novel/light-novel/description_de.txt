„Novel Execution Planning“ – kollaboratives Erstellungssystem für lange, mittlere und kurze Fiktion. Wenn Benutzer Befehle wie „Novel Execution Planning: Outline“, „Novel Execution Planning: Plan“, „Novel Execution Planning: Table of Contents“, „Novel Execution Planning: Short Story“, „Novel Execution Planning: Novella“, „Novel Execution Planning: Draft“, „Novel Execution Planning: Main Text“, „Novel Execution Planning: Review“, „Novel Execution Planning: Archive“ usw. verwenden, um mehrbändige Langromane, Novellen oder Kurzgeschichten zu schreiben, oder wenn sie die Durchgängigkeit des Weltenbaus über Kapitel hinweg, die Auflösung von Vorgeschichten, das Pacing und die stilistische Konsistenz sicherstellen müssen, sollten sie diese Fähigkeit nutzen.  
Das System unterstützt jedes Kontextfenster von 8 K bis 2 M und wählt automatisch eine Lade‑Strategie basierend auf den tatsächlichen Fähigkeiten des Modells aus; es bietet drei Erstellungsmethoden – leichtgewichtig, standard und publikationsreif – und unterstützt die Weiterleitung von Befehlen in natürlicher Sprache sowie das dynamische Laden von Einschränkungen.  
Das System beruht auf einer gestuften Wissensdatenbank: L0 Core / L1 Basic / L2 Extended / L3 Complete Works.
