「Novel Execution Planning」長篇、中篇、短篇小說的協同創作系統。當使用者使用「Novel Execution Planning: Outline」、「Novel Execution Planning: Plan」、「Novel Execution Planning: Table of Contents」、「Novel Execution Planning: Short Story」、「Novel Execution Planning: Mid-length」、「Novel Execution Planning: Draft」、「Novel Execution Planning: Main Text」、「Novel Execution Planning: Health Check」或「Novel Execution Planning: Archive」等指令來撰寫多卷長篇小說、中篇小說或短篇故事，或需要確保跨章節的世界觀一致性、鋪陳呼應、節奏控制與風格穩定時，應使用此功能。系統支援 8K 至 2M token 的任意上下文窗口，會自動依模型能力選擇載入策略；提供輕量、標準、出版三種創作模式，並支援自然語言指令路由與動態約束載入。系統依賴分層知識庫：L0 Core / L1 Basic / L2 Extended / L3 Full Book。請始終以使用者的語言回覆。
