تم تصميمه خصيصًا لمنصة Xianyu لإنشاء عناوين منتجات ونسخ أساسية عالية التحويل وواقعية وسهلة البيع، وتغطي كلاً من العناصر الخاملة المادية ومواد المنتج الافتراضية (ملاحظات الدراسة، وبنوك الأسئلة، والقوالب، والإصدارات الإلكترونية، وما إلى ذلك). يدعم أربعة أنماط: موجزة ومباشرة، وصادقة، وقيمة صائد الصفقات، واحترافية موثوقة. يقوم تلقائيًا بتضمين كلمات البحث الأساسية ويتجنب التعبيرات المحظورة. يُستخدم عندما يطلب المستخدم كتابة أو إنشاء أو تحسين نسخة منتج Xianyu، أو نسخة مواد المنتج الافتراضية، أو أوصاف المواد الإلكترونية، أو عناوين المبيعات، أو نسخة القائمة لـ Xianyu، أو يحتاج إلى نسخة نشر عامية وأصلية وفعالة من حيث التكلفة.
