Configure y sincronice @smart-cs/vitepress-course-tools para el sitio de documentación del curso de VitePress: menú de la barra lateral, directorio de portada de PDF tocManifest, detalles del producto productDetail y script de exportación npm.  
Cuando el usuario menciona vitepress-course-tools.config.ts, sincronizando el menú docs/zh, tocManifest, productDetail, PDF de detalles del producto, pdf:export:product, exportación de PDF del curso o configuración de captura de pantalla README, se debe utilizar esta habilidad, incluso si el usuario solo dice "actualizar la configuración del sitio de documentación" o "alinear la barra lateral y la configuración de PDF".
