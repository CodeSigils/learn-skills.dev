VitePress 과정 문서 사이트(사이드바 메뉴, PDF 표지 디렉토리 tocManifest, 제품 세부 정보 productDetail, npm 내보내기 스크립트)에 대해 @smart-cs/vitepress-course-tools를 구성하고 동기화합니다.  
사용자가 vitepress-course-tools.config.ts를 언급하고 docs/zh 메뉴, tocManifest, productDetail, 제품 세부 정보 PDF, pdf:export:product, 코스 PDF 내보내기 또는 README 스크린샷 구성을 동기화하는 경우 이 기술을 사용해야 합니다. 사용자가 "문서 사이트 구성 업데이트" 또는 "사이드바 및 PDF 구성 정렬"이라고만 말하더라도 여전히 트리거되어야 합니다.
