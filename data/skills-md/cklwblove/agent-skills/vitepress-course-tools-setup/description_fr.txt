Configurez et synchronisez les @smart-cs/vitepress-course-tools pour le site de documentation des cours VitePress : menu de la barre latérale, répertoire de couverture PDF tocManifest, détails du produit, script d'exportation npm.  
Lorsque l'utilisateur mentionne vitepress-course-tools.config.ts, en synchronisant le menu docs/zh, tocManifest, productDetail, détail du produit PDF, pdf:export:product, exportation PDF du cours ou configuration de capture d'écran README, cette compétence doit être utilisée, même si l'utilisateur dit seulement « mettre à jour la configuration du site » ou « aligner la barre latérale et la configuration PDF », elle doit être déclenchée.
