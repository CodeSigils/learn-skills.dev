Configurez et synchronisez les outils @smart-cs/vitepress-course-tools pour le site de documentation des cours VitePress : menu de la barre latérale, répertoire de couverture PDF tocManifest, détails du produit (productDetail) et script d'exportation npm.  
Lorsque l'utilisateur mentionne vitepress-course-tools.config.ts, synchronisant le menu docs/zh, tocManifest, productDetail, product-details PDF, pdf:export:product, cours PDF export ou README capture d'écran configuration, cette compétence doit être utilisée, même si l'utilisateur dit seulement « mettre à jour la configuration du site » ou « aligner la barre latérale et la configuration PDF ».
