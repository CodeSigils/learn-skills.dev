قم بتكوين ومزامنة أدوات @smart-cs/vitepress-course لموقع توثيق دورة VitePress: قائمة الشريط الجانبي، دليل غلاف PDF tocManifest، تفاصيل المنتج، البرنامج النصي لتصدير npm.  
عندما يذكر المستخدم vitepress-course-tools.config.ts، أو مزامنة قائمة docs/zh، أو tocManifest، أو ProductDetail، أو تفاصيل المنتج PDF، أو pdf:export:product، أو تصدير PDF للدورة، أو تكوين لقطة شاشة README، يجب استخدام هذه المهارة - حتى إذا قال المستخدم فقط "تحديث تكوين الموقع" أو "محاذاة الشريط الجانبي وتكوين PDF"، فيجب تشغيلها.
