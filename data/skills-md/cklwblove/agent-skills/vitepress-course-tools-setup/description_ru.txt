Настройте и синхронизируйте инструменты @smart-cs/vitepress-course-tools для сайта документации курса VitePress: меню боковой панели, каталог обложек PDF-файлов tocManifest, сведения о продукте, скрипт экспорта npm.  
Когда пользователь упоминает vitepress-course-tools.config.ts, синхронизацию меню docs/zh, tocManifest, ProductDetail, PDF с подробными сведениями о продукте, pdf:export:product, экспорт курса в PDF или конфигурацию скриншота README, следует использовать этот навык — даже если пользователь говорит только «обновить конфигурацию сайта» или «выровнять боковую панель и конфигурацию PDF», он должен сработать.
