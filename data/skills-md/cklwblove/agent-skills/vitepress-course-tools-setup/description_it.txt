Configura e sincronizza @smart-cs/vitepress-course-tools per il sito di documentazione del corso VitePress: menu della barra laterale, directory di copertina PDF tocManifest, dettagli del prodotto, script di esportazione npm.  
Quando l'utente menziona vitepress-course-tools.config.ts, sincronizzando il menu docs/zh, tocManifest, productDetail, PDF dettagli prodotto, pdf:export:product, esportazione PDF del corso o configurazione screenshot README, questa abilità dovrebbe essere utilizzata, anche se l'utente dice solo "aggiorna configurazione sito" o "allinea barra laterale e configurazione PDF", dovrebbe essere attivata.
