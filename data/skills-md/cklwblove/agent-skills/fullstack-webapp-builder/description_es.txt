Cree una aplicación web implementable de pila completa desde cero (modo de ejecución automatizada avanzada). Úselo cuando el usuario describa el nombre de la aplicación, el propósito, las características, el flujo de trabajo, las preferencias tecnológicas o el modelo de datos. Cubre el análisis de requisitos, la selección de la pila de tecnología, un plan y ejecución de 14 a 18 etapas, pruebas de un extremo a otro (Playwright), auditorías de seguridad y rendimiento, CI/CD e implementación. Adecuado para escenarios que necesitan una salida única de una base de código completa, README, configuración de CI y una demostración en vivo.
