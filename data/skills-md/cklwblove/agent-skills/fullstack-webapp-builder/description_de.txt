Erstellen Sie eine produktionsbereite Full-Stack-Webanwendung von Grund auf (erweiterter automatisierter Ausführungsmodus). Verwenden Sie es, wenn der Benutzer den Namen der Anwendung, den Zweck, die Funktionen, den Workflow, die Technologieeinstellungen oder das Datenmodell angibt. Es umfasst die Anforderungsanalyse, die Auswahl des Tech-Stacks, einen 14–18-stufigen Plan und die Ausführung, End-to-End-Tests (Playwright), Sicherheits- und Leistungsaudits, CI/CD und Bereitstellung. Geeignet für Szenarien, die eine einmalige Ausgabe einer vollständigen Codebasis, README, CI-Konfiguration und einer Online-Demo erfordern.
