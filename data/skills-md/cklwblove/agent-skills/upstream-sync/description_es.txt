Sincronice el contenido de un repositorio Git ascendente con el repositorio local con mapeo de rutas, detección de conflictos y verificación de integridad. Úselo cuando el usuario solicite sincronizar, fusionar o extraer cambios de un repositorio ascendente/bifurcado, o mencione palabras clave como "sincronización ascendente", "sincronización ascendente", "上游同步", "同步上游". Acepta la URL del repositorio ascendente y el SHA de confirmación inicial.
