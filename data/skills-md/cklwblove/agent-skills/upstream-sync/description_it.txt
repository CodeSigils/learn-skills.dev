Sincronizza il contenuto da un repository Git upstream nel repository locale con mappatura del percorso, rilevamento dei conflitti e verifica dell'integrità. Da utilizzare quando l'utente chiede di sincronizzare, unire o estrarre modifiche da un repository upstream/fork o menziona parole chiave come "sincronizzazione upstream", "sincronizzazione upstream", "上游同步", "同步上游". Accetta l'URL del repository upstream e avvia il commit SHA.
