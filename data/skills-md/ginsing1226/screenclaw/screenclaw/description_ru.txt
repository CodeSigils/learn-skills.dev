Управляйте ScreenClaw через HTTP API для автоматизации операций программного обеспечения на рабочем столе.
Используйте этот навык, когда:
- Пользователям необходимо использовать настольное программное обеспечение Windows без API (например, нажатие кнопок, ввод текста, прокрутка страниц).
- Скриншоты необходимы для того, чтобы ИИ мог анализировать положение элементов пользовательского интерфейса.
- Необходимо программное управление настольными приложениями
- Пользователи упоминают такие фразы, как «нажмите кнопку в какой-либо программе», «введите текст в программе XX», «помогите мне работать с программой XX» и т. д.
Для любого запроса, связанного с операциями с графическим интерфейсом программного обеспечения настольного компьютера, расставьте приоритеты в использовании этого навыка.
