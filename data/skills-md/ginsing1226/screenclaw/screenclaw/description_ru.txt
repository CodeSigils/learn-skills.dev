Используйте ScreenClaw через HTTP API для автоматизации операций настольного программного обеспечения.  
Используйте этот навык, когда:  
– Пользователю необходимо взаимодействовать с настольными приложениями Windows, у которых нет API (например, нажимать кнопки, вводить текст, прокручивать страницы).  
- Требуются снимки экрана, чтобы ИИ мог анализировать расположение элементов пользовательского интерфейса.  
- Необходимо программное управление настольными приложениями  
- Пользователь говорит такие вещи, как «нажмите кнопку в каком-нибудь приложении», «введите программу XX» или «используйте программу XX для меня».  

Для любого запроса, связанного с операциями графического интерфейса рабочего стола, отдавайте приоритет этому навыку.
