Steuern Sie ScreenClaw über die HTTP-API, um Desktop-Softwarevorgänge zu automatisieren.
Verwenden Sie diese Fähigkeit, wenn:
- Benutzer müssen Desktop-Windows-Software ohne API bedienen (z. B. Klicken auf Schaltflächen, Texteingabe, Scrollen von Seiten).
- Für die KI sind Screenshots erforderlich, um die Positionen von UI-Elementen zu analysieren
- Eine programmgesteuerte Steuerung von Desktop-Anwendungen ist erforderlich
- Benutzer erwähnen Sätze wie „Klicken Sie auf eine Schaltfläche in einer Software“, „Geben Sie Text in eine XX-Software ein“, „Helfen Sie mir, die XX-Software zu bedienen“ usw.
Bei allen Anfragen, die GUI-Operationen für Desktop-Software betreffen, sollten Sie diesem Skill Vorrang einräumen.
