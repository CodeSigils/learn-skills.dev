Verwenden Sie die HTTP-API, um ScreenClaw zur Automatisierung von Desktop-Softwarevorgängen zu steuern.  
Verwenden Sie diese Fähigkeit, wenn:  
- Der Benutzer muss eine Desktop-Windows-Anwendung bedienen, die über keine API verfügt (z. B. Klicken auf Schaltflächen, Texteingabe, Scrollen von Seiten).  
- Für die KI-Analyse der Positionen von UI-Elementen sind Screenshots erforderlich  
- Programmatische Steuerung von Desktop-Anwendungen ist erforderlich  
- Der Benutzer erwähnt „in einer Software auf eine Schaltfläche klicken“, „in XX-Software Text eingeben“, „mir bei der Bedienung von XX-Software helfen“ usw.  
Für alle Anfragen, die GUI-Operationen von Desktop-Software betreffen, sollte diese Fähigkeit die erste Wahl sein.
