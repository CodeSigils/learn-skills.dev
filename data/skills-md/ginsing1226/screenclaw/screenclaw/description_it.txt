Controlla ScreenClaw tramite API HTTP per automatizzare le operazioni del software desktop.
Usa questa abilità quando:
- Gli utenti devono utilizzare il software Windows desktop senza API (ad esempio, facendo clic sui pulsanti, inserendo testo, scorrendo le pagine)
- Gli screenshot sono necessari affinché l'intelligenza artificiale analizzi le posizioni degli elementi dell'interfaccia utente
- È necessario il controllo programmatico delle applicazioni desktop
- Gli utenti menzionano frasi come "fai clic su un pulsante in alcuni software", "inserisci testo nel software XX", "aiutami a utilizzare il software XX", ecc.
Per qualsiasi richiesta che coinvolga le operazioni della GUI del software desktop, dai la priorità all'utilizzo di questa competenza.
