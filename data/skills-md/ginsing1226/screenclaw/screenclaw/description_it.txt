Utilizza l'API HTTP per controllare ScreenClaw e automatizzare le operazioni del software desktop.
Utilizza questa competenza quando: - Gli utenti devono utilizzare il software Windows desktop senza un'API (ad esempio, facendo clic su pulsanti, inserendo testo, scorrendo pagine) - Sono necessari screenshot per consentire all'intelligenza artificiale di analizzare le posizioni degli elementi dell'interfaccia utente - È necessario il controllo programmatico delle applicazioni desktop - Gli utenti menzionano "fai clic su un pulsante in alcuni software", "inserisci testo nel software XX", "aiutami a utilizzare il software XX" ecc. Per qualsiasi richiesta che coinvolga operazioni della GUI del software desktop, dai la priorità all'utilizzo di questa competenza.
