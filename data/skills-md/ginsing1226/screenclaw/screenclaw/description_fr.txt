Utilisez l'API HTTP pour contrôler ScreenClaw et automatiser les opérations du logiciel de bureau.  
Utilisez cette compétence lorsque :  
- L'utilisateur doit utiliser une application de bureau Windows dépourvue d'API (par exemple, cliquer sur des boutons, saisir du texte, faire défiler des pages).  
- Des captures d'écran sont nécessaires pour que l'IA puisse analyser les positions des éléments de l'interface utilisateur  
- Un contrôle programmatique des applications de bureau est nécessaire  
- L'utilisateur mentionne des actions telles que "cliquez sur un bouton dans un certain programme", "saisissez du texte dans le logiciel XX" ou "aidez-moi à utiliser le logiciel XX".  

Pour toute demande impliquant des opérations d’interface graphique de logiciel de bureau, privilégiez l’utilisation de cette compétence.
