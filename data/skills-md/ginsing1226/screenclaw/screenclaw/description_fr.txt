Contrôlez ScreenClaw via l'API HTTP pour automatiser les opérations des logiciels de bureau.
Utilisez cette compétence lorsque :
- Les utilisateurs doivent utiliser un logiciel de bureau Windows sans API (par exemple, cliquer sur des boutons, saisir du texte, faire défiler des pages)
- Des captures d'écran sont nécessaires pour que l'IA puisse analyser les positions des éléments de l'interface utilisateur
- Un contrôle programmatique des applications de bureau est nécessaire
- Les utilisateurs mentionnent des expressions telles que « cliquez sur un bouton dans certains logiciels », « saisissez du texte dans le logiciel XX », « aidez-moi à utiliser le logiciel XX », etc.
Pour toute demande impliquant des opérations d’interface graphique de logiciel de bureau, privilégiez l’utilisation de cette compétence.
