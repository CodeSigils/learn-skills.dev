HTTP API 経由で ScreenClaw を制御し、デスクトップ ソフトウェアの操作を自動化します。
このスキルは次の場合に使用します。 - ユーザーが API のないデスクトップ Windows ソフトウェアを操作する必要がある (ボタンのクリック、テキストの入力、ページのスクロールなど) - AI が UI 要素の位置を分析するためにスクリーンショットが必要 - デスクトップ アプリケーションのプログラムによる制御が必要 - ユーザーが「あるソフトウェアのボタンをクリック」、「XX ソフトウェアでテキストを入力」、「XX ソフトウェアの操作を手伝って」などと言及した場合。デスクトップ ソフトウェアの GUI 操作を伴うリクエストの場合は、このスキルの使用を優先してください。
