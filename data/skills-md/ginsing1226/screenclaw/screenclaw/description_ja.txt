HTTP API 経由で ScreenClaw を制御し、デスクトップ ソフトウェアの操作を自動化します。
このスキルは次の場合に使用します。
- ユーザーは API を使用せずにデスクトップ Windows ソフトウェアを操作する必要があります (ボタンのクリック、テキストの入力、ページのスクロールなど)
- AI が UI 要素の位置を分析するにはスクリーンショットが必要です
- デスクトップ アプリケーションをプログラムで制御する必要がある
- ユーザーは、「あるソフトウェアのボタンをクリックする」、「XX ソフトウェアにテキストを入力する」、「XX ソフトウェアの操作を手伝ってください」などのフレーズに言及します。
デスクトップ ソフトウェアの GUI 操作を伴うリクエストの場合は、このスキルを優先して使用してください。
