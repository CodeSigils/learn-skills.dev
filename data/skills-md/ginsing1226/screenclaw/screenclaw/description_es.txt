Controle ScreenClaw a través de HTTP API para automatizar las operaciones del software de escritorio.
Utilice esta habilidad cuando:
- Los usuarios necesitan operar el software de escritorio de Windows sin una API (por ejemplo, hacer clic en botones, ingresar texto, desplazarse por páginas)
- Se requieren capturas de pantalla para que la IA analice las posiciones de los elementos de la interfaz de usuario.
- Se necesita control programático de las aplicaciones de escritorio.
- Los usuarios mencionan frases como "haga clic en un botón en algún software", "ingrese texto en el software XX", "ayúdeme a operar el software XX", etc.
Para cualquier solicitud que involucre operaciones de GUI de software de escritorio, priorice el uso de esta habilidad.
