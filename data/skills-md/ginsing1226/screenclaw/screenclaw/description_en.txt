Use ScreenClaw via its HTTP API to automate desktop-software operations.  
Employ this skill when:  
- The user needs to interact with Windows desktop apps that lack an API (e.g., click buttons, enter text, scroll pages)  
- Screenshots are required so AI can analyze UI element locations  
- Programmatic control of desktop applications is needed  
- The user says things like “click a button in some app,” “type in XX software,” or “operate XX software for me”  

For any request involving desktop GUI operations, prioritize this skill.
