يرشد عمليات محاكاة Ansys Lumerical FDTD الشاملة باستخدام Python API ولغة البرمجة Lumerical. يغطي المتطلبات والوحدات والهندسة والمواد والمصادر والحدود والشاشات والتحكم في التشغيل وعمليات المسح والتقارب والإخراج والتشخيص. يُستخدم عندما يُطلب منك تصميم محاكاة كهرومغناطيسية Lumerical FDTD أو إنشاؤها أو تشغيلها أو التحقق من صحتها أو استكشاف الأخطاء وإصلاحها.
