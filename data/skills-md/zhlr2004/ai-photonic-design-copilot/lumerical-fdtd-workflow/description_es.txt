Guía las simulaciones de Ansys Lumerical FDTD de un extremo a otro utilizando la API de Python y el lenguaje de script Lumerical. Cubre requisitos, unidades, geometría, materiales, fuentes, límites, monitores, control de ejecución, barridos, convergencia, salida y diagnóstico. Úselo cuando se le solicite diseñar, generar, ejecutar, validar o solucionar problemas de una simulación electromagnética Lumerical FDTD.
