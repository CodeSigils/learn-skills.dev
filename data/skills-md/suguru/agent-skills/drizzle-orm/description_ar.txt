إنشاء مشاريع Drizzle ORM وترحيلها وتصحيح أخطائها ومراجعتها في TypeScript. يُستخدم عند العمل مع مخططات drizzle-orm أو drizzle-kit، أو عمليات الترحيل، أو التكوين، أو محولات قاعدة البيانات، أو الاستعلامات المشابهة لـ SQL، أو واجهة برمجة التطبيقات للاستعلام العلائقي، أو المعاملات، أو البذور، أو مخططات التحقق من الصحة، أو قواعد البيانات بدون خادم، أو عمليات الترحيل من وإلى Drizzle.
