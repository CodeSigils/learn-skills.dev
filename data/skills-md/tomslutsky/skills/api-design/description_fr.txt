Concevez des API à fort effet de levier destinées aux développeurs, dotées d'une ergonomie, d'une composabilité et d'une maintenabilité à long terme solides. Utilisez cette compétence chaque fois que l'utilisateur demande à concevoir, reconcevoir ou réviser une API de bibliothèque/module/service, une surface de SDK, une interface de hooks/utilitaires ou un contrat de package public, en particulier lorsqu'il souhaite une « haute qualité », des « meilleures pratiques », une « qualité de production », « comme TanStack/Convex/shadcn/better-auth », ou a besoin d'une comparaison de plusieurs formes d'API avant la mise en œuvre.
