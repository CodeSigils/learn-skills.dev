قم بتصميم واجهات برمجة التطبيقات (APIs) عالية الأداء التي تواجه المطورين مع بيئة عمل قوية وقابلية للتركيب وقابلية الصيانة على المدى الطويل. استخدم هذه المهارة عندما يطلب المستخدم تصميم أو إعادة تصميم أو مراجعة واجهة برمجة تطبيقات المكتبة/الوحدة النمطية/الخدمة، أو سطح SDK، أو واجهة الخطافات/الأدوات المساعدة، أو عقد الحزمة العامة، خاصة عندما يريد "جودة عالية"، أو "أفضل ممارسة"، أو "درجة الإنتاج"، "مثل TanStack/Convex/shadcn/better-auth"، أو يحتاج إلى مقارنة أشكال واجهة برمجة التطبيقات المتعددة قبل التنفيذ.
