Progetta API ad alto rendimento rivolte agli sviluppatori con forte ergonomia, componibilità e manutenibilità a lungo termine. Utilizza questa competenza ogni volta che l'utente chiede di progettare, riprogettare o rivedere un'API di libreria/modulo/servizio, una superficie SDK, un'interfaccia di hook/utilità o un contratto di pacchetto pubblico, soprattutto quando desidera "alta qualità", "migliore pratica", "grado di produzione", "come TanStack/Convex/shadcn/better-auth" o ha bisogno del confronto di più forme API prima dell'implementazione.
