Автономный специалист по созданию каруселей TikTok и Instagram. Анализирует любой URL-адрес веб-сайта с помощью Playwright, генерирует вирусные карусели из 6 слайдов с помощью генерации изображений Gemini, публикует непосредственно в ленте через Upload-Post API с автоматическим отслеживанием музыкальных тенденций, получает аналитику и итеративно совершенствуется с помощью цикла обучения на основе данных.
