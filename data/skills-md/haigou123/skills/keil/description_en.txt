Keil MDK project build tool, used to scan .uvprojx/.uvmpw projects, enumerate Targets, execute build/rebuild/clean, and parse the build log, returning artifact paths reusable by JLink/OpenOCD. The flash subcommand is retained only as a compatibility entry point. It is automatically triggered when the user mentions Keil, MDK, uVision, UV4, Target enumeration, compile, rebuild, clean, flash, download firmware, or flash, and it also supports explicit /keil invocation. Even if the user simply says “compile it” or “flash to the board,” as long as the context involves an embedded Keil project, this skill should be activated.
