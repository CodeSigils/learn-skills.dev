أداة تنزيل J-Link وتصحيح الأخطاء عبر الإنترنت، تستخدم لفحص الأجهزة، وامض البرامج الثابتة، وذاكرة القراءة/الكتابة، وعرض السجلات، وإعادة تعيين الهدف، وقراءة سجلات RTT/SWO، وتصحيح الأخطاء عبر الإنترنت (إيقاف مؤقت/استئناف/خطوة واحدة/تنفيذ نقطة توقف/مكدس الاستدعاءات/الفحص المتغير). عندما يذكر المستخدم J‑Link، أو JLink، أو RTT، أو البرامج الثابتة الوامضة، أو كتابة الذاكرة، أو قراءة الذاكرة، أو عرض التسجيل، أو إعادة ضبط الهدف، أو التحقق من اتصال المسبار، أو تصحيح الأخطاء عبر الإنترنت، أو خطوة واحدة، أو نقطة التوقف، أو مكدس الاستدعاءات، فإنه يتم تشغيله تلقائيًا، ويدعم أيضًا استدعاء /jlink الصريح. حتى لو قال المستخدم فقط "قم بوميضه" أو "تحقق من إخراج RTT" أو "صحح الأخطاء قليلاً"، طالما أن السياق يتضمن مسبار J‑Link، فيجب تفعيل هذه المهارة.
