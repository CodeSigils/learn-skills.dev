Strumento di download e debug OpenOCD, utilizzato per rilevamento sonda, aggiornamento firmware, cancellazione flash, avvio server GDB, controllo ripristino target, debug online Telnet (arresto/riprendi/passaggio/registrazione/memoria/punto di interruzione), debugging a livello di origine GDB, nonché acquisizione di output Semihosting/ITM e query di basso livello. Quando l'utente menziona OpenOCD, ST‑Link, CMSIS‑DAP, DAPLink, FTDI, firmware flashing, cancellazione di Flash, server GDB, ripristino, configurazione di interfaccia/destinazione/scheda, openocd.cfg, debug online, stepping, punti di interruzione, visualizzazione di registri, lettura/scrittura di memoria, semihosting, la competenza dovrebbe essere attivata automaticamente e supporta anche l'invocazione esplicita tramite /openocd. Anche se l'utente dice solo "flash it", "avvia GDB Server", "cancella il chip", "controlla i registri", "step debugging" o "capture semihosting", purché il contesto coinvolga un debugger open source supportato da OpenOCD, questa abilità dovrebbe essere attivata. 

Si prega di rispondere sempre nella lingua dell'utente.
