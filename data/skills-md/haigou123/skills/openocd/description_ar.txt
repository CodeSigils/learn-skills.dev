أداة تنزيل وتصحيح أخطاء OpenOCD، تُستخدم للكشف عن المسبار، وميض البرامج الثابتة، ومسح الفلاش، وبدء تشغيل خادم GDB، والتحكم في إعادة تعيين الهدف، وتصحيح أخطاء Telnet عبر الإنترنت (الإيقاف/الاستئناف/الخطوة/التسجيل/الذاكرة/نقطة التوقف)، وتصحيح الأخطاء على مستوى مصدر GDB، بالإضافة إلى التقاط مخرجات Semihosting/ITM والاستعلامات منخفضة المستوى. عندما يذكر المستخدم OpenOCD، أو ST‑Link، أو CMSIS-DAP، أو DAPLink، أو FTDI، أو البرامج الثابتة الوامضة، أو مسح الفلاش، أو خادم GDB، أو إعادة التعيين، أو تكوين الواجهة/الهدف/اللوحة، أو openocd.cfg، أو تصحيح الأخطاء عبر الإنترنت، أو الخطوة المفردة، أو نقاط التوقف، أو عرض التسجيل، أو قراءة/كتابة الذاكرة، أو الاستضافة شبه، فإنه يجب تشغيله تلقائيًا، كما أنه يدعم مكالمات /openocd الصريحة. حتى لو قال المستخدم فقط "flash it"، أو "start GDB Server"، أو "محو الشريحة"، أو "التحقق من السجلات"، أو "تصحيح الأخطاء بخطوة واحدة"، أو "التقاط Semihosting"، طالما أن السياق يتضمن مصحح أخطاء مفتوح المصدر مدعومًا بـ OpenOCD، فيجب استدعاء هذه المهارة.
