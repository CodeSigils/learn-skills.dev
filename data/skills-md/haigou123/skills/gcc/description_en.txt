GCC embedded project build tool (CMake + arm-none-eabi-gcc), used to scan CMake‑style embedded projects, list presets, configure, compile, rebuild, clean, and analyze ELF size. It automatically triggers when the user mentions GCC, arm‑none‑eabi, CMake embedded compilation, Ninja build, ELF size analysis, arm‑gcc, cross‑compilation, cmake --build, cmake --preset, and is also compatible with explicit /gcc calls. Even if the user just says “compile it” or “check how big the firmware is,” as long as the context involves a CMake embedded GCC project, this skill should be triggered.
