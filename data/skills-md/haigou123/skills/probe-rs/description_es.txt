probe-rs es una herramienta de descarga y depuración que se utiliza para el descubrimiento de sondas, actualización de firmware, reinicio, lectura/escritura de memoria, depuración del servidor GDB y lectura de registros RTT. Se activa automáticamente cuando el usuario menciona probe-rs, cargo-embed, DAP, RTT, CMSIS-DAP, ST-Link, J‑Link, parpadeo, información del chip, conexión bajo reinicio, selector de sonda, probe-rs gdb o probe-rs adjunto, y también admite llamadas explícitas /probe-rs. Incluso si el usuario solo dice "flash con probe-rs", "verificar RTT" o "obtener un seguimiento", siempre y cuando el contexto haga referencia claramente a la funcionalidad de probe-rs, comandos CLI o términos relacionados (como cargo-embed, RTT, flash de probe-rs), esta habilidad debe activarse.
