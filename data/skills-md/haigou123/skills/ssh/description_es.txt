Asistente de operación SSH/Servidor. Se utiliza para tareas como servidores remotos, usuario@host, configuración SSH, carga/descarga, implementación, salto de host, tunelización, reenvío de puertos, ejecución de comandos del servidor, etc.; utiliza los alias de host en~/.ssh/config como inventario de servidor único, prefiere la autenticación de claves y envuelve las operaciones OpenSSH con scripts de Python proporcionados por esta habilidad.
