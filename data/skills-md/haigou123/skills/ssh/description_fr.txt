Assistant d'exploitation SSH/serveur. Utilisé pour des tâches telles que les serveurs distants, l'utilisateur @ hôte, la configuration SSH, le téléchargement/téléchargement, le déploiement, le saut d'hôte, le tunneling, la redirection de port, l'exécution de commandes de serveur, etc. ; utilise les alias d'hôte dans ~/.ssh/config comme inventaire de serveur unique, préfère l'authentification par clé et encapsule les opérations OpenSSH via les scripts Python de cette compétence.
