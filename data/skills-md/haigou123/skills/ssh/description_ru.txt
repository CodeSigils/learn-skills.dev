SSH/Помощник по эксплуатации сервера. Используется для таких задач, как удаленные серверы, пользователь@хост, настройка SSH, загрузка/выгрузка, развертывание, переход к хосту, туннелирование, переадресация портов, выполнение команд сервера и т. д.; использует псевдонимы хоста в ~/.ssh/config в качестве уникального инвентаря сервера, предпочитает аутентификацию по ключу и оборачивает операции OpenSSH с помощью сценариев Python этого навыка.
