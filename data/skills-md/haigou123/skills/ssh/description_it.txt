Assistente operativo SSH/server. Utilizzato per attività quali server remoti, utente@host, configurazione SSH, caricamento/download, distribuzione, jump host, tunneling, port forwarding, esecuzione di comandi del server, ecc.; utilizza l'alias Host in~/.ssh/config come elenco di server univoci, preferisce l'autenticazione basata su chiave e esegue il wrapper delle operazioni OpenSSH tramite gli script Python di questa competenza.
