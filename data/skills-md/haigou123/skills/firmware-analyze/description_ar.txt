أداة تحليل ثابتة للبرامج الثابتة المضمنة. يوزع ملفات ELF/Mach-O، ويصدر تخطيط الذاكرة وجداول الرموز، ويفكك الوظائف المهمة، ويستخرج السلاسل/الثوابت، ويحلل استخدام الفلاش/ذاكرة الوصول العشوائي. يستخدم سلسلة أدوات Arm-none-eabi (objdump/readelf/nm/size) والبرامج النصية Python للتحليل الآلي. يتم تشغيله تلقائيًا عندما يذكر المستخدم تحليل البرامج الثابتة، أو تحليل ELF، أو تخطيط الذاكرة، أو التفكيك، أو جدول الرموز، أو تحليل المقاطع، أو استخدام الفلاش، أو استخدام ذاكرة الوصول العشوائي، أو objdump، أو readelf، أو الحجم، أو نانومتر، أو الهندسة العكسية للبرامج الثابتة. متوافق أيضًا مع الاستدعاء الصريح عبر / تحليل البرامج الثابتة.
