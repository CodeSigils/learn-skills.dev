Strumento di analisi statica del firmware integrato. Analizza file ELF/Mach-O, esporta layout di memoria e tabelle di simboli, disassembla le funzioni chiave, estrae stringhe/costanti e analizza l'utilizzo di Flash/RAM. Utilizza la toolchain arm-none-eabi (objdump/readelf/nm/size) e gli script Python per l'analisi automatizzata. Si attiva automaticamente quando l'utente menziona l'analisi del firmware, l'analisi ELF, il layout della memoria, il disassemblaggio, le tabelle dei simboli, l'analisi dei segmenti, l'utilizzo di Flash, l'utilizzo della RAM, objdump, readelf, dimensione, nm, reverse engineering del firmware. Compatibile anche con chiamate esplicite tramite /firmware-analyze.
