Embedded firmware static analysis tool. Parses ELF/Mach-O files, exports memory layout and symbol tables, disassembles critical functions, extracts strings/constants, and analyzes Flash/RAM usage. Uses the arm-none-eabi toolchain (objdump/readelf/nm/size) and Python scripts for automated analysis. Automatically triggered when the user mentions firmware analysis, ELF parsing, memory layout, disassembly, symbol table, segment analysis, Flash usage, RAM usage, objdump, readelf, size, nm, or firmware reverse engineering. Also compatible with explicit invocation via /firmware-analyze.
