Herramienta de análisis estático de firmware integrada. Analiza archivos ELF/Mach-O, exporta diseños de memoria y tablas de símbolos, desensambla funciones clave, extrae cadenas/constantes y analiza el uso de Flash/RAM. Utiliza la cadena de herramientas arm-none-eabi (objdump/readelf/nm/size) y scripts de Python para análisis automatizados. Se activa automáticamente cuando el usuario menciona análisis de firmware, análisis ELF, diseño de memoria, desmontaje, tabla de símbolos, análisis de segmentos, uso de Flash, uso de RAM, objdump, readelf, tamaño, nm o ingeniería inversa de firmware. También es compatible con llamadas explícitas /firmware-analyze.
