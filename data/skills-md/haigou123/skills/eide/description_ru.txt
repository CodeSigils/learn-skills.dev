Инструмент сборки проектов EIDE (Embedded IDE), используемый для сканирования проектов .eide/eide.yml, перечисления конфигураций сборки (ConfigName), выполнения сборки/перестройки/очистки и анализа журналов сборки, возвращая пути артефактов, которые могут быть повторно использованы jlink/openocd. Он запускается автоматически, когда пользователь упоминает EIDE, Embedded IDE, eide.yml, unify_builder, расширение VS Code EIDE или Cl.eide, а также поддерживает явный вызов с помощью /eide. Даже если пользователь говорит только «скомпилировать с помощью EIDE» или «записать EIDE на плату», при условии, что контекст включает встроенный проект EIDE, этот навык должен быть задействован.
