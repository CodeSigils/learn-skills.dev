EIDE (IDE integrado) es una herramienta de compilación de proyectos que se utiliza para escanear proyectos .eide/eide.yml, enumerar configuraciones de compilación (ConfigName), ejecutar compilación/reconstrucción/limpieza y analizar registros de compilación, devolviendo rutas de artefactos que pueden ser reutilizadas por jlink/openocd. Se activa automáticamente cuando el usuario menciona EIDE, Embedded IDE, eide.yml, unify_builder, extensión VS Code EIDE o Cl.eide, y también admite llamadas explícitas a /eide. Incluso si el usuario simplemente dice "compilar con EIDE" o "flash EIDE en la placa", siempre que el contexto involucre un proyecto integrado EIDE, esta habilidad debe activarse.
