EIDE (Embedded IDE) project build tool, used to scan .eide/eide.yml projects, enumerate build configurations (ConfigName), execute build/rebuild/clean and parse build logs, returning artifact paths that can be reused by jlink/openocd. It is automatically triggered when the user mentions EIDE, Embedded IDE, eide.yml, unify_builder, VS Code EIDE extension, or Cl.eide, and also supports explicit invocation with /eide. Even if the user only says “compile with EIDE” or “EIDE flash to the board,” as long as the context involves an EIDE embedded project, this skill should be triggered.
