Herramienta de depuración CAN/CAN-FD integrada para escanear interfaces, monitorear mensajes, enviar marcos de prueba, registrar, decodificar archivos de bases de datos y estadísticas de bus. Se activa automáticamente cuando el usuario menciona CAN, CAN-FD, decodificación DBC, rastreo de bus, codepuración USB-CAN, envío de mensajes, estadísticas de bus, PCAN, Vector, slcan, escaneo de interfaz CAN, filtrado de ID CAN, registros ASC o archivos BLF, y también admite llamadas explícitas /can. Incluso si el usuario simplemente dice "veamos los mensajes CAN", "envíe una trama para intentarlo" o "decodificar el DBC", siempre y cuando el contexto se refiera claramente a operaciones o problemas de comunicación del bus CAN, esta habilidad debe activarse.
