Strumento di debug CAN/CAN‑FD integrato per la scansione di interfacce, il monitoraggio di messaggi, l'invio di frame di test, la registrazione, la decodifica di file di database e le statistiche del bus. Si attiva automaticamente quando l'utente menziona CAN, CAN‑FD, decodifica DBC, acquisizione bus, co‑debug USB‑CAN, trasmissione di messaggi, statistiche bus, PCAN, Vector, slcan, scansione dell'interfaccia CAN, filtraggio ID CAN, registri ASC o file BLF ed è anche compatibile con chiamate esplicite/can. Anche se l'utente dice semplicemente "guardiamo i messaggi CAN", "invia un frame come test" o "decodifica il DBC", purché il contesto si riferisca chiaramente a operazioni o problemi di comunicazione del bus CAN, questa abilità dovrebbe essere attivata.
