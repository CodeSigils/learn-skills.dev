Outil de débogage CAN/CAN‑FD intégré pour analyser les interfaces, surveiller les messages, envoyer des trames de test, enregistrer, décoder les fichiers de base de données et les statistiques de bus. Il s'active automatiquement lorsque l'utilisateur mentionne CAN, CAN‑FD, le décodage DBC, le reniflage de bus, le débogage co‑can USB‑CAN, la transmission de messages, les statistiques de bus, PCAN, Vector, slcan, la numérisation d'interface CAN, le filtrage CAN‑ID, les journaux ASC, les fichiers BLF, et il prend également en charge les appels explicites/can. Même si l'utilisateur dit seulement « regardons les messages CAN », « envoyer une trame de test » ou « décoder le DBC », tant que le contexte fait clairement référence aux opérations ou aux problèmes de communication du bus CAN, cette compétence doit être déclenchée.
