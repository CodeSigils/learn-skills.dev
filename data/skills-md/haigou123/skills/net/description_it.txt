Strumento di debug di rete integrato, utilizzato per scoprire interfacce, acquisire pacchetti, analizzare pcap/pcapng, eseguire test di connettività, scansioni di porte e statistiche sul traffico. Si attiva automaticamente quando gli utenti menzionano Wireshark, tshark, Npcap, acquisizione di pacchetti, debug di integrazione di rete, scansione delle porte, risoluzione dei problemi di connettività, analisi pcap, interfacce di rete, test ping, traceroute, statistiche sul traffico, Modbus TCP, EtherNet/IP e altri debug di protocolli di rete e supporta anche chiamate esplicite /net. Anche se l'utente dice semplicemente "prendi un pacchetto da guardare", "scansiona una porta", "la rete è raggiungibile" o "analizza questo pcap", purché il contesto includa nomi di strumenti specifici (tshark, Wireshark, Npcap), nomi di protocollo (Modbus TCP, EtherNet/IP, ICMP, ecc.), azioni di debug (acquisizione di pacchetti, scansione di porte, test di connettività, ping, traceroute, statistiche sul traffico, analisi pcap) o operazioni di interfaccia di rete, questa abilità dovrebbe essere attivato. 

Si prega di rispondere sempre nella lingua dell'utente.
