Herramienta de depuración de autobuses I2C/SPI. Escanea dispositivos de bus, lee y escribe registros y envía/recibe datos SPI utilizando adaptadores como FTDI, CH341, Aardvark, Raspberry Pi o puentes de microcontroladores. Admite Python smbus2/spidev/pyftdi y las herramientas de línea de comandos i2c. Se activa automáticamente cuando el usuario menciona I2C, SPI, escaneo de bus, i2cdetect, lectura/escritura de registros, FTDI, CH341, Aardvark, smbus, i2c-tools, dirección de dispositivo I2C o SPI Flash. También funciona con llamadas explícitas a /i2c-spi-tools.
