I2C/SPI bus debugging tool. Scans bus devices, reads/writes registers, and transmits/receives SPI data via adapters such as FTDI, CH341, Aardvark, Raspberry Pi, or microcontroller bridge. Supports Python smbus2/spidev/pyftdi as well as the command‑line i2c‑tools. Automatically triggers when the user mentions I2C, SPI, bus scanning, i2cdetect, register read/write, FTDI, CH341, Aardvark, smbus, i2c‑tools, I2C device address, or SPI Flash. Also compatible with explicit calls to /i2c‑spi‑tools.
