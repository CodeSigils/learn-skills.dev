أداة تصحيح أخطاء ناقل I2C/SPI. يقوم بمسح أجهزة الناقل، وقراءة/كتابة السجلات، ونقل/استقبال بيانات SPI عبر محولات مثل FTDI، أو CH341، أو Aardvark، أو RaspberryPi، أو جسر وحدة التحكم الدقيقة. يدعم Python smbus2/spidev/pyftdi بالإضافة إلى أدوات سطر الأوامر i2c. يتم تشغيله تلقائيًا عندما يذكر المستخدم I2C، أو SPI، أو مسح الناقل، أو i2cdetect، أو تسجيل القراءة/الكتابة، أو FTDI، أو CH341، أو Aardvark، أو smbus، أو i2c‑tools، أو عنوان جهاز I2C، أو SPI Flash. متوافق أيضًا مع المكالمات الصريحة إلى /i2c‑spi‑tools.
