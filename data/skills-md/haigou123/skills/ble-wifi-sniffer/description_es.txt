Herramienta de análisis de captura de paquetes inalámbricos Bluetooth BLE y Wi-Fi. Admite nRF Sniffer para Bluetooth LE, captura promiscua de Wi-Fi ESP32 y análisis en tiempo real con Wireshark. Se utiliza para capturar paquetes de conexión/publicidad BLE, marcos de administración de Wi-Fi, analizar interacciones de protocolos y analizar el tiempo de conexión. Se activa automáticamente cuando el usuario menciona captura BLE, captura Wi‑Fi, nRF Sniffer, captura ESP32, análisis de protocolo Bluetooth, Wireshark inalámbrico, BLE sniffer, Wi‑Fi promiscuo, dongle nRF52840. También compatible con llamadas explícitas a /ble-wifi-sniffer.
