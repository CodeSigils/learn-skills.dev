세션 제한을 3~5배까지 확장하는 Claude Code용 토큰 효율적인 영구 메모리 시스템입니다. 프로그레시브 로딩, 컴팩트 인코딩, 분기 인식 컨텍스트, 스마트 압축, 세션 비교, 충돌 감지, 세션 연속 프로토콜 및 복구 모드를 갖춘 계층형 아키텍처입니다. 세션 시작 시(MEMORY.md가 존재하는 경우) "기억", "중단한 부분부터 시작", "무엇을 하고 있었는지", "마무리", "진행 상황 저장", "잊지 마세요", "컨텍스트 전환", "핸드오프", "메모리 상태", "상태 저장", "중단한 부분에서 계속", "컨텍스트 예산", "컨텍스트가 얼마나 남았는지" 또는 기존 메모리 파일이 있는 프로젝트의 모든 세션 시작 시 활성화됩니다. 이 기술은 한 번에 두 가지 문제를 해결합니다. Claude는 세션 사이의 모든 것을 잊어버리고 세션은 컨텍스트 제한에 너무 빨리 도달합니다. 수천 개의 낭비된 재설명 토큰을 Claude에게 2,000개 미만의 토큰으로 전체 프로젝트 컨텍스트를 제공하는 구조화된 소형 메모리 로드로 대체합니다.
