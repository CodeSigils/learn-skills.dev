クロード コード用のトークン効率の高い永続メモリ システムにより、セッション制限が 3 ～ 5 倍に拡張されます。プログレッシブローディング、コンパクトエンコーディング、ブランチアウェアコンテキスト、スマート圧縮、セッション差分、競合検出、セッション継続プロトコル、リカバリモードを備えた階層型アーキテクチャ。セッションの開始時 (MEMORY.md が存在する場合)、「これを覚えておく」、「中断したところから再開する」、「何をしていたか」、「まとめ」、「進行状況を保存する」、「忘れないでください」、「コンテキストを切り替える」、「ハンドオフ」、「メモリの健全性」、「状態を保存」、「中断したところから続行する」、「コンテキスト バジェット」、「コンテキストがどれだけ残っているか」、または既存のメモリ ファイルを持つプロジェクトでのセッション開始時にアクティブになります。このスキルは 2 つの問題を同時に解決します。クロードがセッション間ですべてを忘れてしまうという問題と、セッションがコンテキスト制限に達するのが早すぎるという問題です。これにより、何千もの無駄な再説明トークンがコンパクトで構造化されたメモリ負荷に置き換えられ、2,000 トークン未満で完全なプロジェクト コンテキストがクロードに提供されます。
