适用于 Claude Code 的令牌高效持久内存系统，可将会话限制扩展 3-5 倍。分层架构，具有渐进式加载、紧凑编码、分支感知上下文、智能压缩、会话差异、冲突检测、会话延续协议和恢复模式。在会话开始时激活（如果 MEMORY.md 存在），在“记住这一点”、“从我们上次停下的地方继续”、“我们在做什么”、“总结”、“保存进度”、“不要忘记”、“切换上下文”、“切换”、“内存健康状况”、“保存状态”、“从我上次停下的地方继续”、“上下文预算”、“还剩多少上下文”或使用现有内存文件在项目上启动的任何会话中激活。这项技能可以同时解决两个问题：克劳德忘记会话之间的所有内容，以及会话太快达到上下文限制。它用紧凑的结构化内存负载取代了数千个浪费的重新解释标记，从而在 2,000 个标记内为 Claude 提供了完整的项目上下文。
