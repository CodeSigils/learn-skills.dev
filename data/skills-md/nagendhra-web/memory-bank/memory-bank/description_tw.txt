適用於 Claude Code 的令牌高效持久記憶體系統，可將會話限制擴展 3-5 倍。分層架構，具有漸進式載入、緊湊編碼、分支感知上下文、智慧壓縮、會話差異、衝突偵測、會話延續協定和復原模式。在會話開始時啟動（如果 MEMORY.md 存在），在「記住這一點」、​​「從我們上次停下的地方繼續」、「我們在做什麼」、「總結」、「儲存進度」、「不要忘記」、「切換上下文」、「切換」、「記憶體健康狀況」、「儲存進度」、「從我停下來啟動任何內容這項技能可以同時解決兩個問題：克勞德忘記會話之間的所有內容，以及會話太快達到上下文限制。它用緊湊的結構化記憶體負載取代了數千個浪費的重新解釋標記，從而在 2,000 個標記內為 Claude 提供了完整的項目上下文。
