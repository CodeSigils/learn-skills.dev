Расширьте SQLite с помощью функций, определяемых приложением, и загружаемых расширений Python. Используйте, когда вам нужна собственная логика SQL (преобразования, оценка, агрегирование) в процессе или необходимо загрузить/создать расширения C для повторно используемых плагинов SQLite. Предполагается, что Python stdlib sqlite3. Существуют эквиваленты Go (zombiezen/go-sqlite, mattn/go-sqlite3) — ищите их API во время выполнения.
