Estendi SQLite con funzioni definite dall'applicazione ed estensioni caricabili in Python. Da utilizzare quando è necessaria una logica SQL personalizzata (trasformazioni, punteggi, aggregazioni) in-process oppure è necessario caricare/creare estensioni C per plug-in SQLite riutilizzabili. Presuppone Python stdlib sqlite3. Esistono equivalenti Go (zombiezen/go-sqlite, mattn/go-sqlite3): cerca le loro API in fase di runtime.
