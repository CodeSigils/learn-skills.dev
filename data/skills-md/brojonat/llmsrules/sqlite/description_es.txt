Amplíe SQLite con funciones definidas por la aplicación y extensiones cargables en Python. Úselo cuando necesite lógica SQL personalizada (transformaciones, puntuación, agregaciones) en el proceso, o necesite cargar/construir extensiones C para complementos SQLite reutilizables. Asume Python stdlib sqlite3. Existen equivalentes de Go (zombiezen/go-sqlite, mattn/go-sqlite3): busque sus API en tiempo de ejecución.
