Étendez SQLite avec des fonctions définies par l'application et des extensions chargeables en Python. À utiliser lorsque vous avez besoin d'une logique SQL personnalisée (transformations, notation, agrégations) en cours de processus, ou lorsque vous devez charger/créer des extensions C pour des plugins SQLite réutilisables. Suppose que Python stdlib sqlite3. Des équivalents Go existent (zombiezen/go-sqlite, mattn/go-sqlite3) — recherchez leurs API au moment de l'exécution.
