Genera una pagina Web PPT (singolo file HTML) con scorrimento orizzontale con modelli come uno sfondo WebGL, pagine dei titoli dei capitoli, poster di big data, griglie di immagini e così via. Fornire tre stili:  
1. "Rivista elettronica×E-ink" (serif+sfondo fluido+colori caldi)  
2. “Internazionalismo svizzero” (sans‑serif+matrice di punti griglia+IKB / giallo limone / verde limone / riflessi arancioni di sicurezza)  
3. "Report aziendale Huawei" (sfondo bianco-grigio+rosso Huawei+riepilogo aziendale/piano/layout rapporto aziendale).  

Da utilizzare quando l'utente deve creare un PPT web per la condivisione, la presentazione o lo stile di un evento di lancio oppure menziona "PPT in stile rivista", "PPT in stile svizzero", "PPT Huawei", "modello di report aziendale", "Swiss Style" o "swipe deck orizzontale".
