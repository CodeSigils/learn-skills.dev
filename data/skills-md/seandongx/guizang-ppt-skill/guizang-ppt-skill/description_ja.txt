WebGL 背景、章タイトル ページ、ビッグデータ ポスター、画像グリッドなどのテンプレートを使用して、水平スワイプ Web ページ PPT (単一 HTML ファイル) を生成します。 3 つのスタイルを提供します。  
1.「電子雑誌×E‑ink」（セリフ+流動的な背景+暖色系）  
2.「スイス・インターナショナリズム」（サンセリフ+方眼+IKB / レモンイエロー / レモングリーン / セーフティオレンジハイライト）  
3. 「Huawei Corporate Report」（白グレーの背景 + Huawei の赤 + 企業概要 / 計画 / ビジネスレポートのレイアウト）。  

ユーザーが共有、プレゼンテーション、発表会スタイルの Web PPT を作成する必要がある場合、または「雑誌スタイル PPT」、「スイス スタイル PPT」、「Huawei PPT」、「企業レポート テンプレート」、「スイス スタイル」、または「水平スワイプ デッキ」について言及する場合に使用します。
