قم بإنشاء webPPT (ملف HTML واحد) بتمرير أفقي يتضمن قوالب مثل خلفية WebGL، وغلاف الفصل، وملصق البيانات، وشبكة الصور، والمزيد. توفير ثلاثة أنماط:  
1️⃣ “المجلة الإلكترونية × الحبر الإلكتروني” (serif+خلفية سائلة+ألوان دافئة)  
2️⃣ "الدولية السويسرية" (sans‑serif+ مصفوفة نقطية شبكية+ IKB / أصفر ليموني / أخضر ليموني / تسليط الضوء على برتقالي الأمان)  
3️⃣ "تقرير شركة هواوي" (خلفية باللون الأبيض والرمادي + أحمر هواوي + ملخص الشركة / الخطة / تخطيط تقرير العمل).  

يُستخدم عندما يحتاج المستخدم إلى إنشاء webPPT للمشاركة أو العرض التقديمي أو نمط حدث الإطلاق، أو عندما يذكر "PPT بنمط المجلة" أو "PPT بالنمط السويسري" أو "Huawei PPT" أو "قالب تقرير الشركة" أو "النمط السويسري" أو "مجموعة التمرير الأفقية".
