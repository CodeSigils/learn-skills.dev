يُستخدم عندما تتضمن المهام أتمتة المتصفح باستخدام متصفح bridgic عبر واجهة سطر الأوامر الطرفية (`متصفح bridgic ...`) أو Python SDK ('from bridgic.browser.session import Browser`، `من bridgic.browser.tools import BrowserToolSetBuilder`). مشغل للتنقل، والتجريد، وملء النماذج، ومراجع لقطة إمكانية الوصول، وعمليات فحص e2e، والتصفح الخفي، ورسم خرائط/ترحيل CLI-SDK، وإنشاء كود SDK من خطوات إجراء CLI.
