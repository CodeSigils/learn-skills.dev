Используйте, когда задачи включают автоматизацию браузера с помощью bridgic-browser через CLI терминала («bridgic-browser ...») или Python SDK («из bridgic.browser.session import Browser», «from bridgic.browser.tools import BrowserToolSetBuilder»). Триггер для навигации, очистки, заполнения форм, ссылок на снимки доступности, проверок e2e, скрытого просмотра, сопоставления/миграции CLI-SDK и генерации кода SDK на основе действий CLI.
