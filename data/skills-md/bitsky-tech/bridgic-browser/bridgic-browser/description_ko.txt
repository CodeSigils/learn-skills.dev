작업에 터미널 CLI(`bridgic-browser ...`) 또는 Python SDK(`bridgic.browser.session import Browser`, `from bridgic.browser.tools import BrowserToolSetBuilder`)를 통한 bridgic-browser를 사용한 브라우저 자동화가 포함되는 경우에 사용합니다. 탐색, 스크래핑, 양식 채우기, 접근성 스냅샷 참조, e2e 검사, 스텔스 브라우징, CLI-SDK 매핑/마이그레이션 및 CLI 작업 단계에서 SDK 코드 생성을 위한 트리거입니다.
