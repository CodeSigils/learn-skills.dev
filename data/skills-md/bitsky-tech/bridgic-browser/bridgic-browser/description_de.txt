Wird verwendet, wenn Aufgaben eine Browserautomatisierung mit bridgic-browser über Terminal-CLI („bridgic-browser ...“) oder Python SDK („from bridgic.browser.session import Browser“, „from bridgic.browser.tools import BrowserToolSetBuilder“) beinhalten. Auslöser für Navigation, Scraping, Ausfüllen von Formularen, Snapshot-Referenzen zur Barrierefreiheit, E2E-Prüfungen, Stealth-Browsing, CLI-SDK-Zuordnung/-Migration und Generieren von SDK-Code aus CLI-Aktionsschritten.
