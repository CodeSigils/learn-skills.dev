Da utilizzare quando le attività implicano l'automazione del browser con bridgic-browser tramite CLI del terminale (`bridgic-browser ...`) o SDK Python (`from bridgic.browser.session import Browser`, `from bridgic.browser.tools import BrowserToolSetBuilder`). Trigger per navigazione, scraping, compilazione di moduli, riferimenti a istantanee di accessibilità, controlli e2e, navigazione invisibile, mappatura/migrazione CLI-SDK e generazione di codice SDK dai passaggi di azione della CLI.
