タスクにターミナル CLI (「bridgic-browser ...」) または Python SDK (「from bridgic.browser.session import Browser」、「from bridgic.browser.tools import BrowserToolSetBuilder」) を介した bridgic-browser によるブラウザ自動化がタスクに含まれる場合に使用します。ナビゲーション、スクレイピング、フォーム入力、アクセシビリティ スナップショット参照、e2e チェック、ステルス ブラウジング、CLI-SDK マッピング/移行、および CLI アクション ステップからの SDK コードの生成のトリガー。
