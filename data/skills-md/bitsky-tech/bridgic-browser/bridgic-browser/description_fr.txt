À utiliser lorsque les tâches impliquent l'automatisation du navigateur avec bridgic-browser via le terminal CLI (`bridgic-browser ...`) ou le SDK Python (`from bridgic.browser.session import Browser`, `from bridgic.browser.tools import BrowserToolSetBuilder`). Déclencheur pour la navigation, le scraping, le remplissage de formulaires, les références d'instantanés d'accessibilité, les vérifications e2e, la navigation furtive, le mappage/migration CLI-SDK et la génération de code SDK à partir des étapes d'action CLI.
