ジョージア銀行 (BOG) API を統合するための専門ガイド — オープン バンキング PSD2、iPay 支払いゲートウェイ、割賦ローン、BOG SDK (BOG.Calculator、BOG.SmartButton)、OAuth2、BOG-ID (SSO)、Business Online (BOnline) コーポレート バンキング、ペイメント ゲートウェイ (請求/サービス プロバイダー)、および銀行製品。銀行側の API の使用法とマーチャント側の実装の両方をカバーします: Webhook/コールバック ハンドラー、リダイレクト URL、冪等性、環境セットアップ、登録ドキュメント、および稼働チェックリスト。また、マーチャント統合ドキュメント (技術仕様、稼働チェックリスト、サービス プロバイダーの仕様、SDK 統合の詳細) をマークダウン形式で生成します。ユーザーが BOG がマーチャントに要求するドキュメントを準備する必要がある場合に使用します。ユーザーがジョージア銀行、BOG、bog.ge、api.bog.ge、iPay、BOG 分割払い、BOG SDK、BOG-ID、BOnline、ジョージア銀行統合、コールバック処理、加盟店登録、加盟店ドキュメント、統合ドキュメント、ゴーライブ チェックリスト、または BOG 関連の開発について言及するたびに、このスキルを使用します。テクノロジー/銀行の文脈で「BOG」と言っただけでもトリガーされます。
