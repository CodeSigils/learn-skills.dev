Ejecute muchas decisiones de autorización KBAC en una sola llamada a través de la API REST de IndyKite AuthZEN (`POST /access/v1/evaluaciones`), con asunto/acción/recurso/contexto de nivel superior como valores predeterminados anulados por entrada; devuelve una "decisión" por entrada, en orden. Utilícelo al comprobar un conjunto fijo y conocido de comprobaciones a la vez: un sujeto frente a muchos recursos, una acción entre muchos sujetos o cualquier combinación de triples, p. "de estos servidores, ¿cuál puede aprovisionarse?", "para cada uno de estos usuarios, ¿pueden implementar gpu-node-7?". Para una verificación única, utilice indykite-authzen-evaluación; para enumerar TODAS las acciones/recursos/temas permitidos (abiertos, no una lista fija) utilice indykite-authzen-search-action / -search-resource / -search-subject; para crear la política, utilice indykite-authzen-kbac.
