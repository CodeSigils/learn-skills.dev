透過 IndyKite AuthZEN REST API (`POST /access/v1/evaluations`) 在一次呼叫中執行多個 KBAC 授權決策，其中頂級主題/操作/資源/上下文作為每個條目覆蓋的預設值；按順序為每個條目傳回一個「決定」。在一次檢查一組已知的固定檢查時使用 - 主題針對許多資源，跨多個主題的一個操作，或三元組的任何組合 - 例如“這些伺服器中，哪些可以寬限配置？”，“對於每個用戶，他們可以部署 gpu-node-7 嗎？”。對於單次檢查，請使用 indykite-authzen-evaluation；要列舉所有允許的操作/資源/主題（開放式，不是固定列表），請使用 indykite-authzen-search-action / -search-resource / -search-subject；使用 indykite-authzen-kbac 來編寫策略。
