Führen Sie viele KBAC-Autorisierungsentscheidungen in einem Aufruf über die IndyKite AuthZEN REST API („POST /access/v1/evaluations“) aus, wobei Betreff/Aktion/Ressource/Kontext der obersten Ebene als Standardwerte pro Eintrag überschrieben werden; Gibt eine „Entscheidung“ pro Eintrag zurück, der Reihe nach. Verwenden Sie diese Option, wenn Sie einen bekannten, festen Satz von Prüfungen gleichzeitig prüfen – ein Subjekt gegen viele Ressourcen, eine Aktion über viele Subjekte hinweg oder eine beliebige Mischung aus Tripeln – z. B. „Welche dieser Server können bereitgestellt werden?“, „Können sie für jeden dieser Benutzer gpu-node-7 bereitstellen?“. Für eine einzelne Prüfung verwenden Sie indykite-authzen-evaluation; um ALLE erlaubten Aktionen/Ressourcen/Subjekte aufzuzählen (offenes Ende, keine feste Liste), verwenden Sie indykite-authzen-search-action / -search-resource / -search-subject; Um die Richtlinie zu erstellen, verwenden Sie indykite-authzen-kbac.
