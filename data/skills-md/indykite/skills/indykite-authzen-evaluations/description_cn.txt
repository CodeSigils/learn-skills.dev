通过 IndyKite AuthZEN REST API (`POST /access/v1/evaluations`) 在一次调用中运行多个 KBAC 授权决策，其中顶级主题/操作/资源/上下文作为每个条目覆盖的默认值；按顺序为每个条目返回一个“决定”。在一次检查一组已知的固定检查时使用 - 一个主题针对许多资源，跨多个主题的一个操作，或三元组的任何组合 - 例如“这些服务器中，哪些可以宽限配置？”，“对于每个用户，他们可以部署 gpu-node-7 吗？”。对于单次检查，请使用 indykite-authzen-evaluation；要枚举所有允许的操作/资源/主题（开放式，不是固定列表），请使用 indykite-authzen-search-action / -search-resource / -search-subject；使用 indykite-authzen-kbac 来编写策略。
