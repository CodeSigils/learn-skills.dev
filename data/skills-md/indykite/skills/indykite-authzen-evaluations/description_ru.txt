Выполнение множества решений по авторизации KBAC за один вызов через IndyKite AuthZEN REST API («POST /access/v1/evaluations»), при этом субъект/действие/ресурс/контекст верхнего уровня по умолчанию переопределяется для каждой записи; возвращает одно «решение» для каждой записи по порядку. Используйте при одновременной проверке известного, фиксированного набора проверок – один предмет против многих ресурсов, одно действие по многим предметам или любое сочетание троек – например. «из этих серверов, которые могут обеспечить льготное предоставление?», «Могут ли они развернуть gpu-node-7 для каждого из этих пользователей?». Для одной проверки используйте indykite-authzen-evaluation; чтобы перечислить ВСЕ разрешенные действия/ресурсы/субъекты (открытый, а не фиксированный список), используйте indykite-authzen-search-action/-search-resource/-search-subject; для создания политики используйте indykite-authzen-kbac.
