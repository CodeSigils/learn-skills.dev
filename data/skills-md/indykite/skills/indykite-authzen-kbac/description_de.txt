Erstellen Sie eine IndyKite KBAC-Autorisierungsrichtlinie (Knowledge-Based Access Control) – Betreff, Aktionen, Ressource und eine Cypher-Bedingung über das IKG – und werten Sie sie dann über die AuthZEN-REST-API („POST /access/v1/evaluation“) aus. Verwenden Sie diese Option, wenn Sie entscheiden, ob ein Subjekt eine Aktion für eine Ressource ausführen darf, Batch-Entscheidungen ausführen oder die Aktionen suchen, die einem Subjekt für eine Ressource erlaubt sind. Nicht zum Lesen, Zurückgeben oder Ändern von Diagrammdaten – KBAC trifft nur eine Ja/Nein-Entscheidung.
