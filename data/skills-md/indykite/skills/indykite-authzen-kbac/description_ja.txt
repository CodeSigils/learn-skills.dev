IndyKite KBAC (Knowledge-Based Access Control) 認証ポリシー (サブジェクト、アクション、リソース、および IKG 上の暗号条件) を作成し、AuthZEN REST API (`POST /access/v1/evaluation`) を介してそれを評価します。サブジェクトがリソースに対してアクションを実行できるかどうかを決定する場合、バッチ決定を実行する場合、またはサブジェクトがリソースに対して許可されているアクションを検索する場合に使用します。グラフ データの読み取り、返し、または変更には使用できません。KBAC は、はい/いいえの決定のみを行います。
