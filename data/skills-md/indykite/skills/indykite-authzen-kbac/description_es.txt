Cree una política de autorización KBAC (control de acceso basado en conocimientos) de IndyKite (asunto, acciones, recursos y una condición Cypher sobre el IKG) y luego evalúela a través de la API REST de AuthZEN (`POST /access/v1/evaluación`). Úselo para decidir si un sujeto puede realizar una acción en un recurso, ejecutar decisiones por lotes o buscar las acciones que un sujeto puede realizar en un recurso. No para leer, devolver o modificar datos de gráficos: KBAC solo genera una decisión de sí o no.
