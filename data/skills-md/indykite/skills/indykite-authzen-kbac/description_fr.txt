Créez une politique d'autorisation IndyKite KBAC (Knowledge-Based Access Control) - sujet, actions, ressource et condition de chiffrement sur l'IKG - puis évaluez-la via l'API REST AuthZEN (`POST /access/v1/evaluation`). À utiliser pour décider si un sujet peut effectuer une action sur une ressource, exécuter des décisions par lots ou rechercher les actions qu'un sujet est autorisé sur une ressource. Pas pour lire, renvoyer ou modifier des données graphiques - KBAC ne rend qu'une décision oui/non.
