Erstellen Sie eine IndyKite ContX IQ (CIQ)-Richtlinie plus ihre Wissensabfrage, die eine brandneue Beziehung zwischen zwei vorhandenen Knoten im IndyKite Graph (IKG) erstellt, und führen Sie sie dann über „POST /contx-iq/v1/execute“ aus. Wird verwendet, wenn zwei vorhandene Entitäten über CIQ miteinander verbunden werden – keine neuen Knoten, keine Beziehungsaktualisierungen, keine Löschungen.
