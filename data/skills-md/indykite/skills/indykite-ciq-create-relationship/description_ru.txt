Создайте политику IndyKite ContX IQ (CIQ) и ее запрос знаний, который создает совершенно новую связь между двумя существующими узлами в IndyKite Graph (IKG), а затем запустите ее через POST /contx-iq/v1/execute. Используйте при соединении двух существующих объектов вместе через CIQ — без новых узлов, без обновлений связей и без удалений.
