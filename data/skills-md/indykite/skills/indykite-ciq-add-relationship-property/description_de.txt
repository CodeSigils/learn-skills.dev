Erstellen Sie eine IndyKite ContX IQ (CIQ)-Richtlinie und ihre Wissensabfrage, die eine oder mehrere Eigenschaften für eine bestehende Beziehung im IndyKite Graph (IKG) festlegt, und führen Sie sie dann über „POST /contx-iq/v1/execute“ aus. Verwenden Sie diese Option, wenn Sie eine brandneue Eigenschaft hinzufügen, eine vorhandene überschreiben oder Eigenschaftsmetadaten an eine Beziehung anhängen, die sich bereits im IKG befindet – keine Beziehungserstellung, keine Knotenschreibvorgänge, keine Löschvorgänge.
