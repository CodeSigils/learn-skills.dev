Erstellen Sie eine IndyKite ContX IQ (CIQ)-Richtlinie plus ihre Wissensabfrage, die einen brandneuen Knoten erstellt UND ihn über neue Beziehungen in einem einzigen „POST /contx-iq/v1/execute“-Aufruf mit einem oder mehreren vorhandenen Knoten verknüpft. Wird beim Aufnehmen einer neuen Entität verwendet, die atomar mit dem IKG verbunden werden muss – kombiniert Knotenerstellung und Beziehungserstellung in einem Vorgang.
