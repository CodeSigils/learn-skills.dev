Erstellen Sie eine IndyKite ContX IQ (CIQ)-Richtlinie plus ihre Wissensabfrage, die einen brandneuen Knoten im IndyKite Graph (IKG) erstellt, und führen Sie sie dann über „POST /contx-iq/v1/execute“ aus. Wird beim Aufnehmen einer neuen Entität über CIQ verwendet – keine Erstellung von Beziehungen, keine Aktualisierungen vorhandener Knoten, keine Löschungen.
