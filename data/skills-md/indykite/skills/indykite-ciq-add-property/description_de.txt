Erstellen Sie eine IndyKite ContX IQ (CIQ)-Richtlinie plus ihre Wissensabfrage, die eine oder mehrere Eigenschaften für einen vorhandenen Knoten im IndyKite Graph (IKG) festlegt, und führen Sie sie dann über „POST /contx-iq/v1/execute“ aus. Verwenden Sie diese Option, wenn Sie eine brandneue Eigenschaft hinzufügen, eine vorhandene überschreiben oder Eigenschaftsmetadaten anhängen – keine Knotenerstellung, keine Beziehungsschreibvorgänge, keine Löschvorgänge.
