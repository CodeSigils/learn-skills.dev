Créez, modifiez et déployez des sites Web full-stack via la CLI Higgsfield
(`site Web Higgsfield…`). Chaque site est une application React 19 + TanStack Start SSR dans
un Cloudflare Worker (D1/R2/KV/DO/Containers). La boucle : créer →
repo-access → clone → modifier → push → déployer l'aperçu. Ceci est le site Web
AGENTS.md du modèle : un pipeline de construction par étapes, FONDÉ SUR L'IMAGE (admission →
concept → cartes de référence → système d'actifs → cartes intégrées → mouvement →
passer en revue les portes), les règles strictes, l'édition de la carte, le flux de vérification/déploiement/publication, et
références par tâche. Tout est ici.
À utiliser lorsque : "créez-moi un site Web", "créez une page de destination", "créez une application Web",
"créer un tableau de bord/outil/portefeuille SaaS", "déployer ce site", "éditer mon
site", "publier", "expédier en production".
La création nécessite --type : "site Web" (pas d'intégration Higgsfield) vs "application"
(Connexion Higgsfield + SDK, Quanta + mises en page standard).
PAS pour : génération d'image/vidéo/audio unique (génération higgsfield), produit
photos (higgsfield-product-photoshoot), cartes de marché
(cartes du marché de Higgsfield).
