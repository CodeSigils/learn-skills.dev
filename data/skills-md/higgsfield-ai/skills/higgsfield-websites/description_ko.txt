Higgsfield CLI를 통해 풀스택 웹사이트 구축, 편집 및 배포
(`힉스필드 웹사이트…`). 각 사이트는 React 19 + TanStack Start SSR 앱입니다.
Cloudflare 작업자 1개(D1/R2/KV/DO/컨테이너). 루프: 생성 →
repo-access → 복제 → 편집 → 푸시 → 배포 미리보기. 이것은 웹사이트입니다
템플릿의 AGENTS.md: 이미지 기반의 단계별 빌드 파이프라인(수입 →
개념 → 참조 보드 → 자산 시스템 → 보드 제작 → 모션 →
게이트 검토), 엄격한 규칙, 지도 편집, 흐름 확인/배포/게시 등
작업별 참조. 모든 것이 여기에 있습니다.
사용 시기: "웹사이트 구축", "랜딩 페이지 만들기", "웹 앱 만들기",
"SaaS 대시보드/도구/포트폴리오 구축", "이 사이트 배포", "내 편집
사이트", "게시", "프로덕션으로 배송".
만들기에는 --type: "웹사이트"(힉스필드 통합 없음) 및 "앱"이 필요합니다.
(Higgsfield 로그인 + SDK, Quanta + 표준 레이아웃).
해당되지 않음: 단일 이미지/비디오/오디오 생성(higgsfield-generate), 제품
사진(higgsfield-product-photoshoot), 마켓플레이스 카드
(higgsfield-마켓플레이스-카드).
