Higgsfield CLI を介してフルスタック Web サイトを構築、編集、展開する
(「ヒッグスフィールドのウェブサイト …」)。各サイトは、React 19 + TanStack Start SSR アプリです。
1 つの Cloudflare ワーカー (D1/R2/KV/DO/コンテナ)。ループ: 作成 →
リポジトリへのアクセス → クローン → 編集 → プッシュ → プレビューのデプロイ。これがウェブサイトです
テンプレートの AGENTS.md: イメージベースの段階的ビルド パイプライン (インテーク →
コンセプト → リファレンスボード → アセットシステム → ボードへの構築 → モーション →
ゲートの確認）、厳密なルール、マップの編集、フローの検証/展開/公開、および
タスクごとの参照。すべてがここにあります。
次の場合に使用します: 「Web サイトを構築する」、「ランディング ページを作成する」、「Web アプリを作成する」、
「SaaS ダッシュボード / ツール / ポートフォリオを構築する」、「このサイトをデプロイする」、「私の編集
サイト」、「公開」、「運用環境への出荷」。
作成には --type が必要です: "ウェブサイト" (ヒッグスフィールド統合なし) と "アプリ"
(Higgsfield サインイン + SDK、Quanta + 標準レイアウト)。
対象外: 単一の画像/ビデオ/オーディオ生成 (higgsfield-generate)、製品
写真 (higgsfield-product-photoshoot)、マーケットプレイス カード
(higgsfield-marketplace-cards)。
