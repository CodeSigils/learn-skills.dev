通过 Higgsfield CLI 构建、编辑和部署全栈网站
（“希格斯菲尔德网站……”）。每个站点都是一个 React 19 + TanStack Start SSR 应用程序
一名 Cloudflare Worker（D1/R2/KV/DO/容器）。循环：创建 →
存储库访问→克隆→编辑→推送→部署预览。这是网站
模板的 AGENTS.md：一个基于图像的分阶段构建管道（摄入 →
概念 → 参考板 → 资产系统 → 构建到板 → 动作 →
审查门）、硬规则、编辑地图、验证/部署/发布流程，以及
每个任务的参考。一切都在这里。
在以下情况下使用：“为我构建一个网站”、“制作登陆页面”、“创建网络应用程序”、
“构建 SaaS 仪表板/工具/组合”、“部署此站点”、“编辑我的
站点”、“发布”、“交付生产”。
创建需要 --type：“网站”（无 Higgsfield 集成）与“应用程序”
（Higgsfield 登录 + SDK、Quanta + 标准布局）。
不适用于：单个图像/视频/音频生成（higgsfield-generate）、产品
照片（希格斯菲尔德产品照片）、市场卡
（希格斯菲尔德市场卡）。
