Crea, modifica e distribuisci siti Web full-stack tramite la CLI di Higgsfield
("sito web di Higgsfield..."). Ogni sito è un'app React 19 + TanStack Start SSR in
un lavoratore Cloudflare (D1/R2/KV/DO/container). Il ciclo: creare →
accesso al repository → clone → modifica → push → anteprima distribuzione. Questo è il sito web
AGENTS.md del modello: una pipeline di creazione in fasi IMMAGINE-GROUNDED (assunzione →
concetto → schede di riferimento → sistema di risorse → build-to-boards → movimento →
rivedere i cancelli), regole rigide, modifica della mappa, verifica/distribuzione/pubblicazione del flusso e
riferimenti per attività. Tutto è qui.
Da utilizzare quando: "creami un sito web", "crea una landing page", "crea un'app web",
"crea un dashboard/uno strumento/un portfolio SaaS", "distribuisci questo sito", "modifica il mio
sito", "pubblica", "spedisci in produzione".
La creazione richiede --type: "sito web" (nessuna integrazione Higgsfield) vs "app"
(Accesso a Higgsfield + SDK, Quanta + layout standard).
NON per: generazione di immagini/video/audio singole (generazione higgsfield), prodotto
foto (servizio fotografico di prodotti Higgsfield), cartoline del marketplace
(carte-marketplace-higgsfield).
