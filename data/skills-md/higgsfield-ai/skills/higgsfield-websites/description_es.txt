Cree, edite e implemente sitios web completos a través de la CLI de Higgsfield
(`sitio web de Higgsfield...`). Cada sitio es una aplicación React 19 + TanStack Start SSR en
un trabajador de Cloudflare (D1/R2/KV/DO/Contenedores). El bucle: crear →
acceso al repositorio → clonar → editar → presionar → implementar vista previa. Este es el sitio web
AGENTS.md de la plantilla: un proceso de construcción por fases BASADO EN IMAGEN (entrada →
concepto → tableros de referencia → sistema de activos → tableros de construcción → movimiento →
puertas de revisión), reglas estrictas, edición de mapas, verificar/implementar/publicar flujo y
referencias por tarea. Todo está aquí.
Úselo cuando: "constrúyame un sitio web", "cree una página de destino", "cree una aplicación web",
"crear un panel/herramienta/cartera SaaS", "implementar este sitio", "editar mi
sitio", "publicar", "enviar a producción".
Crear requiere --type: "sitio web" (sin integración de Higgsfield) frente a "aplicación"
(Inicio de sesión de Higgsfield + SDK, Quanta + diseños estándar).
NO para: generación de una sola imagen/vídeo/audio (generación de Higgsfield), producto
fotos (higgsfield-product-photoshoot), tarjetas de mercado
(tarjetas-de-mercado-de-higgsfield).
