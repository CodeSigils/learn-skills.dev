Erstellen, bearbeiten und stellen Sie Full-Stack-Websites über die Higgsfield-CLI bereit
(„Higgsfield-Website …“). Jede Site ist eine React 19 + TanStack Start SSR-App
ein Cloudflare-Worker (D1/R2/KV/DO/Container). Die Schleife: erstellen →
Repo-Zugriff → Klonen → Bearbeiten → Push → Vorschau bereitstellen. Dies ist die Website
AGENTS.md der Vorlage: eine IMAGE-GROUNDED, phasenweise Build-Pipeline (Aufnahme →
Konzept → Referenzplatinen → Asset-System → Build-to-Boards → Bewegung →
Überprüfungs-Gates), harte Regeln, Bearbeitungskarte, Verifizierungs-/Bereitstellungs-/Veröffentlichungsfluss und
Referenzen pro Aufgabe. Alles ist hier.
Verwendung bei: „Erstelle mir eine Website“, „Erstelle eine Landingpage“, „Erstelle eine Web-App“,
„Erstellen Sie ein SaaS-Dashboard/Tool/Portfolio“, „stellen Sie diese Site bereit“, „bearbeiten Sie mein
„Site“, „Veröffentlichen“, „An Produktion versenden“.
Erstellen erfordert --type: „website“ (keine Higgsfield-Integration) vs. „app“
(Higgsfield-Anmeldung + SDK, Quanta + Standardlayouts).
NICHT für: einzelne Bild-/Video-/Audio-Generierung (Higgsfield-Generierung), Produkt
Fotos (Higgsfield-Produktfotoshooting), Marktplatzkarten
(Higgsfield-Marktplatzkarten).
