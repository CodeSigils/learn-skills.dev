透過 Higgsfield CLI 建置、編輯和部署全端網站
（「希格斯菲爾德網站…」）。每個網站都是一個 React 19 + TanStack Start SSR 應用程式
一名 Cloudflare Worker（D1/R2/KV/DO/容器）。循環：建立 →
儲存庫存取→複製→編輯→推送→部署預覽。這是網站
模板的 AGENTS.md：一個基於影像的分階段建立管道（攝取 →
概念 → 參考板 → 資產系統 → 建置到板 → 動作 →
審查門）、硬規則、編輯地圖、驗證/部署/發布流程，以及
每個任務的參考。一切都在這裡。
在以下情況下使用：「為我建立一個網站」、「製作登陸頁面」、「建立網頁應用程式」、
“建立 SaaS 儀表板/工具/組合”、“部署此網站”、“編輯我的
站點」、「發布」、「交付生產」。
創建需要 --type：“網站”（無 Higgsfield 整合）與“應用程式”
（Higgsfield 登入 + SDK、Quanta + 標準版面）。
不適用於：單一影像/視訊/音訊產生（higgsfield-generate）、產品
照片（希格斯菲爾德產品照片）、市場卡
（希格斯菲爾德市場卡）。
