Создавайте, редактируйте и развертывайте полнофункциональные веб-сайты с помощью интерфейса командной строки Higgsfield.
(«сайт Хиггсфилда…»). Каждый сайт представляет собой приложение React 19 + TanStack Start SSR в
один работник Cloudflare (D1/R2/KV/DO/Containers). Цикл: создать →
репо-доступ → клонировать → редактировать → нажать → развернуть предварительный просмотр. Это сайт
AGENTS.md шаблона: ЗАЗЕМЛЕННЫЙ НА ИЗОБРАЖЕНИИ, поэтапный конвейер сборки (прием →
концепция → эталонные платы → система активов → сборка на платах → движение →
просмотр шлюзов), жесткие правила, редактирование карты, проверка/развертывание/публикация потока и
ссылки для каждой задачи. Все здесь.
Используйте, когда: «создайте мне веб-сайт», «создайте целевую страницу», «создайте веб-приложение»,
«создать панель управления/инструмент/портфолио SaaS», «развернуть этот сайт», «отредактировать мой
сайт», «опубликовать», «отправить в производство».
Для создания требуется --type: «веб-сайт» (без интеграции с Хиггсфилдом) или «приложение»
(Вход в Хиггсфилд + SDK, Quanta + стандартные раскладки).
НЕ для: генерации одного изображения/видео/аудио (генерация Хиггсфилда), продукта
фотографии (фотосессия продукта Хиггсфилда), карточки торговой площадки
(карточки рынка Хиггсфилда).
