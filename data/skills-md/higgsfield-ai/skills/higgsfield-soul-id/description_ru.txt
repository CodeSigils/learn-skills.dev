Тренируйте характер души — персонализированная модель лица человека, которая
Хиггсфилд использует для создания достоверных изображений и видео.
Используйте, когда: «создай мою душу», «тренируй мое лицо», «сделай моего цифрового двойника»,
«Создай мне аватар», «узнай мою внешность», «создай из меня персонажа»,
«Настроить личность для видео», «Я хочу, чтобы мое лицо было на сгенерированных изображениях».
Цепочка: поезд Души (однократно, возвращает reference_id) → использовать в
higgsfield-generate через `--soul-id <id>` с такими моделями, как
`text2image_soul_v2` или `soul_cinema_studio`.
НЕ для: однократной замены лиц (используйте higgsfield-generate с --image),
аватары с именами персонажей или без фотографий (используйте команду higgsfield-generate с подсказкой).
