Examinez les modifications depuis un point fixe (commit, branche, balise ou base de fusion) selon deux axes : l'axe des normes (le code est-il conforme aux normes de codage enregistrées dans ce référentiel ?) et l'axe des spécifications (le code répond-il aux exigences du problème/spécification d'origine ?). Exécutez les deux révisions dans des sous-agents parallèles et affichez-les côte à côte. Utilisé lorsque l'utilisateur souhaite réviser une branche, un PR, des modifications en cours ou dit « réviser depuis X ».
