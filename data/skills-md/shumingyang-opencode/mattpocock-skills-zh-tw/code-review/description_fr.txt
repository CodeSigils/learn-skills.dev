Examinez les modifications selon deux axes depuis un point fixe (validation, branche, balise ou base de fusion) : l'axe standard (le code adhère-t-il aux normes de codage enregistrées dans ce référentiel ?) et l'axe de spécification (le code répond-il aux exigences du problème/spécification d'origine ?). Exécutez les deux révisions dans des sous-agents parallèles et affichez-les côte à côte. Utilisez-le lorsqu'un utilisateur souhaite examiner une branche, un PR, des modifications en cours ou dit « réviser depuis X ».
