Überprüfen Sie Änderungen seit einem festen Punkt (Commit-, Branch-, Tag- oder Merge-Basis) entlang zweier Achsen – der Standardachse (entspricht der Code den in diesem Repo aufgezeichneten Codierungsstandards?) und der Spezifikationsachse (erfüllt der Code die Anforderungen der ursprünglichen Ausgabe/Spezifikation?). Führen Sie die beiden Überprüfungen in parallelen Subagenten aus und zeigen Sie sie nebeneinander an. Wird verwendet, wenn der Benutzer einen Zweig, PR oder laufende Änderungen überprüfen möchte oder „Überprüfung seit X“ sagt.
