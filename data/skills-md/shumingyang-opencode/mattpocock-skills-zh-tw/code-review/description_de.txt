Überprüfen Sie Änderungen entlang zweier Achsen seit einem festen Punkt (Commit-, Branch-, Tag- oder Merge-Basis) – der Standardachse (entspricht der Code den in diesem Repo aufgezeichneten Codierungsstandards?) und der Spezifikationsachse (erfüllt der Code die ursprünglichen Ausgabe-/Spezifikationsanforderungen?).
