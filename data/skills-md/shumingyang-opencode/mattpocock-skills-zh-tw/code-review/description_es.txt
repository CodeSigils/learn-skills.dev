Revise los cambios desde un punto fijo (confirmación, bifurcación, etiqueta o base de fusión) a lo largo de dos ejes: el eje de estándares (¿el código se ajusta a los estándares de codificación registrados en este repositorio?) y el eje de especificaciones (¿el código cumple con los requisitos de la edición/especificación original?). Ejecute las dos revisiones en subagentes paralelos y muéstrelas una al lado de la otra. Se utiliza cuando el usuario quiere revisar una rama, PR, cambios en curso o dice "revisar desde X".
