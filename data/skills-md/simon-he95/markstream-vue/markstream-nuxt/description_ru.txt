Интегрируйте markstream-vue в приложение Nuxt 3 или Nuxt 4. Используйте, когда Кодексу необходимы границы только для клиента, безопасная настройка SSR, шлюзование одноранговых узлов только для браузера, инициализация с учетом рабочих или безопасная интеграция MarkdownRender внутри страниц, компонентов или плагинов Nuxt.
