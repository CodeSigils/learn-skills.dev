Intégrez markstream-vue dans une application Nuxt 3 ou Nuxt 4. À utiliser lorsque le Codex a besoin de limites réservées au client, d'une configuration sécurisée SSR, d'un contrôle des pairs uniquement dans le navigateur, d'une initialisation prenant en compte les travailleurs ou d'une intégration sécurisée « MarkdownRender » dans les pages, les composants ou les plugins Nuxt.
