قم بتثبيت Markstream-vue، أو markstream-react، أو markstream-vue2، أو markstream-angular، وربطه في مستودع موجود. يُستخدم عندما يحتاج Codex إلى اختيار الحزمة المناسبة، أو تثبيت أصغر مجموعة تبعية نظير، أو إصلاح ترتيب CSS/إعادة التعيين، أو الاختيار بين "المحتوى" و"العقد"، أو إضافة مثال على الحد الأدنى من عارض العمل.
