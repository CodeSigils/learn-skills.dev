Интегрируйте markstream-react в приложение React 18+ или Next. Используйте, когда Codex необходимо добавить средство рендеринга React, правильно импортировать CSS, выбрать между `content` и `nodes`, обеспечить безопасность границ клиента Next, преобразовать переопределения рендеринга или подготовить репозиторий для миграции `react-markdown`.
