قم بدمج markstream-vue2 في تطبيق Vue 2 Vue CLI أو Webpack 4. يُستخدم عندما يحتاج Codex إلى إعداد متوافق مع Webpack 4، أو عمليات احتياطية لعامل CDN لـ Mermaid أو KaTeX، أو واردات `dist/index.css`، أو حشوات واجهة برمجة تطبيقات Vue 2، أو إعدادات افتراضية أكثر أمانًا لكتلة التعليمات البرمجية التي تتجنب إعدادات عامل Monaco الهشة.
