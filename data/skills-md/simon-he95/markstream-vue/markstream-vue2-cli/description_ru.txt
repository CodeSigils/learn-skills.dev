Интегрируйте markstream-vue2 в приложение Vue 2 Vue CLI или Webpack 4. Используйте, когда Кодексу требуется настройка, совместимая с Webpack 4, резервные рабочие места CDN для Mermaid или KaTeX, импорт `dist/index.css`, прокладки Composition-api Vue 2 или более безопасные настройки блоков кода по умолчанию, которые позволяют избежать хрупких рабочих настроек Monaco.
