Навыки агента экспертного уровня для всей экосистемы разработки ServiceNow. Охватывает метаданные Fluent SDK (.now.ts), устаревшие сценарии (GlideRecord, Script Enabled, Client Scripts, g_form) и настройку CLI (аутентификация now-sdk, сборка, установка). Используйте при создании, просмотре или объяснении любого кода ServiceNow.
