Standard di codifica per la scrittura, la modifica e la revisione del codice. Percorsi verso regole specifiche del linguaggio/framework (Next.js, NestJS, Laravel, vanilla JS/TS, NativeScript, React Native/Expo, C#/.NET, Node Express/Fastify, Cocos Creator, Vue/Nuxt, Spring Boot, Django, FastAPI, Flask, Go HTTP) INOLTRE regole universali di clean-code (funzioni, denominazione, oggetti/dati, formattazione, gestione degli errori, SOLID/KISS/DRY, struttura universale regole) che si applicano a ogni lingua. Consultare prima di qualsiasi modifica del codice. Da utilizzare quando l'utente dice "scrivi un componente", "aggiungi un endpoint", "refattorizza questo", "rivedi questo diff/PR" o "è pulito?". Assicurati di consultare questa competenza per QUALSIASI attività di creazione o revisione del codice, anche quando l'utente non richiede esplicitamente "standard": ogni scrittura/modifica/revisione deve essere conforme.
