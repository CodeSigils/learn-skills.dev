Стандарты кодирования для написания, редактирования и проверки кода. Маршруты к правилам, специфичным для языка/фреймворка (Next.js, NestJS, Laravel, vanilla JS/TS, NativeScript, React Native/Expo, C#/.NET, Node Express/Fastify, Cocos Creator, Vue/Nuxt, Spring Boot, Django, FastAPI, Flask, Go HTTP) ПЛЮС универсальные правила чистого кода (функции, именование, объекты/данные, форматирование, обработка ошибок, SOLID/KISS/DRY, универсальные структурные правила), применимые к каждому языку. Проконсультируйтесь перед любым изменением кода. Используйте, когда пользователь говорит «написать компонент», «добавить конечную точку», «рефакторить это», «просмотреть этот diff/PR» или «это чисто?». Обязательно используйте этот навык для ЛЮБОЙ задачи по написанию или проверке кода, даже если пользователь явно не запрашивает «стандарты» — каждая запись/редактирование/проверка должна соответствовать.
