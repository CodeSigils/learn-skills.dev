Normes de codage pour l’écriture, l’édition et la révision du code. Routes vers des règles spécifiques au langage/framework (Next.js, NestJS, Laravel, vanilla JS/TS, NativeScript, React Native/Expo, C#/.NET, Node Express/Fastify, Cocos Creator, Vue/Nuxt, Spring Boot, Django, FastAPI, Flask, Go HTTP) PLUS des règles universelles de code propre (fonctions, dénomination, objets/données, formatage, gestion des erreurs, SOLID/KISS/DRY, structure universelle règles) qui s’appliquent à toutes les langues. Consultez avant tout changement de code. À utiliser lorsque l'utilisateur dit « écrire un composant », « ajouter un point de terminaison », « refactoriser ceci », « réviser ce diff/PR » ou « est-ce propre ? Assurez-vous de consulter cette compétence pour TOUTE tâche de création ou de révision de code, même lorsque l'utilisateur ne demande pas explicitement de « normes » — chaque écriture/modification/révision doit être conforme.
