Lesen Sie eine wissenschaftliche Arbeit (PDF oder arXiv-ID) gründlich durch und erstellen Sie eine strukturierte Markdown-Notiz mit Zahlenanalyse. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Forschungsarbeit lesen, zusammenfassen oder Notizen dazu machen möchte – einschließlich Phrasen wie „读一下这篇论文“, „Diese Arbeit zusammenfassen“, „Papier 2401.xxxxx lesen“, „论文笔记“, „Papiernotizen“ oder jede Erwähnung des Lesens/Analysierens einer arXiv-Arbeit oder einer PDF-Datei. Wird auch ausgelöst, wenn der Benutzer eine Papier-ID oder einen PDF-Pfad angibt und eine detaillierte Zusammenfassung erwartet. Diese Fähigkeit verwaltet die gesamte Pipeline: Textsegmentierung, Abbildungsextraktion über VLM, Kreuzanalyse und endgültige Notizzusammenstellung.
