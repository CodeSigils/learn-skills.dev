اقرأ بحثًا أكاديميًا بعمق (PDF أو arXiv ID) وأنتج ملاحظة منظمة مع تحليل الأشكال. استخدم هذه المهارة عندما يريد المستخدم قراءة ورقة بحثية أو تلخيصها أو تدوينها - بما في ذلك عبارات مثل "تلخيص هذه الورقة" أو "قراءة الورقة 2401.xxxxx" أو "الملاحظات الورقية" أو أي ذكر لقراءة/تحليل ورقة بحثية من نوع arXiv أو PDF. يتم تشغيله أيضًا عندما يقدم المستخدم معرفًا ورقيًا أو مسار PDF ويتوقع ملخصًا تفصيليًا. تتعامل هذه المهارة مع المسار الكامل: تجزئة النص، واستخراج الأشكال عبر VLM، والتحليل المتبادل، وتجميع الملاحظات النهائية.
