Lea en profundidad un artículo académico (PDF o arXiv ID) y produzca una nota de rebajas estructurada con análisis de cifras. Utilice esta habilidad siempre que el usuario quiera leer, resumir o tomar notas sobre un trabajo de investigación, incluidas frases como '读一下这篇论文', 'resumir este artículo', 'leer el artículo 2401.xxxxx', '论文笔记', 'notas en papel' o cualquier mención de lectura/análisis de un artículo de arXiv o PDF. También se activa cuando el usuario proporciona una identificación en papel o una ruta de PDF y espera un resumen detallado. Esta habilidad maneja todo el proceso: segmentación de texto, extracción de figuras mediante VLM, análisis cruzado y armado de notas finales.
