قم بإنشاء تكوينات tmuxinator YAML وtmux.conf لمساحات العمل الطرفية متعددة المشاريع. استخدم هذه المهارة عندما يريد المستخدم إعداد tmux، أو tmuxinator، أو إدارة مشاريع متعددة في الأجزاء الطرفية، أو إنشاء تخطيط مساحة عمل مطور، أو ذكر أي شيء حول تعدد الإرسال الطرفي، أو إدارة الجلسة، أو تشغيل مشاريع متعددة جنبًا إلى جنب. يتم تشغيله أيضًا عندما يقول المستخدمون أشياء مثل "إعداد مشاريعي" أو "أريد فتح جميع عمليات إعادة الشراء الخاصة بي" أو "تخطيط المحطة الطرفية" أو "إعداد مساحة العمل".
