Canal de encuestas de literatura profunda: búsqueda semántica a través de vec-db local, búsqueda web de artículos arXiv, descarga de archivos PDF, lectura de subagente paralelo y generación de informes estructurados. Utilice esta habilidad siempre que el usuario solicite realizar una encuesta, investigar o encontrar artículos relacionados sobre un tema, especialmente cuando mencione vec-db, arXiv, revisión de literatura, búsqueda de artículos o actualización de una idea/nota de encuesta. También se activa cuando el usuario dice cosas como "调研", "查论文", "找相关工作", "encuesta de literatura", "trabajo relacionado", "buscar artículos" o "leer artículos y resumir". Esta habilidad organiza todo el proceso desde la búsqueda hasta el informe de rebajas estructurado.
