Construcción de matrices de literatura multidimensional → Descubrimiento de brechas → Flujo de trabajo de investigación completo para la propuesta de método. Dado un problema de investigación y restricciones, descomponerlo en dimensiones de diseño, utilizar la búsqueda semántica vec-db + búsqueda web para seleccionar artículos, construir una matriz multidimensional de literatura cruzada, identificar brechas y proponer el método óptimo basado en evidencia experimental en la matriz. Se activa cuando el usuario dice "encontrar brecha", "matriz de literatura", "cualquier dirección en blanco", "proponer método", "análisis de brecha", "análisis del espacio de diseño", "ayúdame a analizar el espacio de diseño", "qué nuevas direcciones puedo tomar" o, sobre la base de encuestas existentes, pregunta "qué método debo seguir a continuación". También aplicable cuando el usuario proporciona restricciones y solicita una búsqueda sistemática de direcciones de investigación viables.
