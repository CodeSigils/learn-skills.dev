Mehrdimensionale Literaturmatrixkonstruktion → Lückenerkennung → Vollständiger Forschungsworkflow für Methodenvorschlag. Zerlegen Sie angesichts eines Forschungsproblems und von Einschränkungen in Designdimensionen, verwenden Sie die semantische Suche + Websuche von vec-db, um gezielt auf Papiere zu zielen, erstellen Sie eine mehrdimensionale literaturübergreifende Matrix, identifizieren Sie Lücken und schlagen Sie die optimale Methode basierend auf experimentellen Beweisen in der Matrix vor. Wird ausgelöst, wenn der Benutzer sagt: „Lücke finden“, „Literaturmatrix“, „irgendeine leere Richtung“, „Methode vorschlagen“, „Lückenanalyse“, „Analyse des Designraums“, „Hilf mir bei der Analyse des Designraums“, „Welche neuen Richtungen kann ich einschlagen“ oder auf der Grundlage bestehender Umfragen fragt: „Welche Methode soll ich als Nächstes anwenden?“. Auch anwendbar, wenn der Benutzer Einschränkungen angibt und eine systematische Suche nach möglichen Forschungsrichtungen anfordert.
