多次元文献マトリックスの構築 → ギャップ発見 → 方法提案のための完全な調査ワークフロー。研究課題と制約が与えられた場合、設計次元に分解し、vec-db セマンティック検索 + Web 検索を使用して論文を対象にし、多次元文献横断マトリクスを構築し、ギャップを特定し、マトリクス内の実験的証拠に基づいて最適な方法を提案します。ユーザーが「ギャップを見つける」、「文献マトリックス」、「空白の方向性」、「方法を提案する」、「ギャップ分析」、「デザイン空間分析」、「デザイン空間の分析を手伝ってください」、「どのような新しい方向性が可能ですか」、または既存の調査に基づいて「次にどのような方法をとるべきか」と尋ねたときにトリガーされます。ユーザーが制約を与えて、実現可能な研究方向の体系的な探索を求める場合にも適用できます。
