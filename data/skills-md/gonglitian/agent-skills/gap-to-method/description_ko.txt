다차원 문헌 매트릭스 구성 → 간격 발견 → 방법 제안을 위한 연구 워크플로우 완료. 연구 문제와 제약 조건을 고려하여 설계 차원으로 분해하고 vec-db 의미 검색 + 웹 검색을 사용하여 대상 논문을 작성하고 다차원 교차 문헌 매트릭스를 구축하고 격차를 식별하고 매트릭스의 실험적 증거를 기반으로 최적의 방법을 제안합니다. 사용자가 "간극 찾기", "문헌 매트릭스", "빈 방향", "방법 제안", "간극 분석", "설계 공간 분석", "설계 공간 분석에 도움", "어떤 새로운 방향을 취할 수 있습니까?"라고 말하거나 기존 설문 조사를 기반으로 "다음에 어떤 방법을 수행해야 합니까?"라고 묻는 경우 트리거됩니다. 사용자가 제약 조건을 제공하고 가능한 연구 방향에 대한 체계적인 검색을 요청하는 경우에도 적용 가능합니다.
