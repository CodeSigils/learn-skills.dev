Построение многомерной литературной матрицы → Обнаружение пробелов → Полный рабочий процесс исследования для предложения метода. Учитывая исследовательскую проблему и ограничения, выполните декомпозицию по измерениям проекта, используйте семантический поиск vec-db + веб-поиск для таргетинга статей, постройте многомерную межлитературную матрицу, выявите пробелы и предложите оптимальный метод на основе экспериментальных данных в матрице. Запускается, когда пользователь говорит «найти пробел», «матрица литературы», «любые пустые указания», «предложить метод», «анализ пробелов», «анализ пространства дизайна», «помогите мне проанализировать пространство дизайна», «какие новые направления я могу выбрать» или, на основе существующих опросов, спрашивает «какой метод мне следует использовать дальше». Также применимо, когда пользователь указывает ограничения и просит систематически искать возможные направления исследований.
