將 Web 可訪問性作為審查鏡頭，以 W3C Web 可訪問性計劃為基礎：WCAG 2.2 AA 級、WAI-ARIA 和 ARIA 創作實踐指南。框架中立。涵蓋語義 HTML 和結構、可存取名稱和 ARIA、鍵盤和焦點、表單、可感知內容（文字替代、顏色、對比度、運動、縮放）、即時區域和 SPA 路線公告以及 a11y 測試。由`react`和`Angular`組成框架機制。在建立或審查 UI 時，或當使用者說「accessibility」、「a11y」、「WCAG」、「ARIA」、「螢幕閱讀器」、「鍵盤導航」、「focus」、「contrast」、「axe」、「landmark」或「WAI」時，請使用它。
