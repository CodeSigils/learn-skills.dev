W3C Web Accessibility Initiative: WCAG 2.2 レベル AA、WAI-ARIA、および ARIA Authoring Practices Guide に基づいたレビュー レンズとしての Web アクセシビリティ。フレームワーク中立。セマンティック HTML と構造、アクセシブルな名前と ARIA、キーボードとフォーカス、フォーム、認識可能なコンテンツ (テキストの代替、色、コントラスト、モーション、ズーム)、ライブ リージョンと SPA ルートのアナウンス、および a11y テストをカバーします。フレームワークの仕組みとして「react」と「angular」を組み合わせて構成します。 UI を構築またはレビューするとき、またはユーザーが「アクセシビリティ」、「a11y」、「WCAG」、「ARIA」、「スクリーン リーダー」、「キーボード ナビゲーション」、「フォーカス」、「コントラスト」、「軸」、「ランドマーク」、または「WAI」と言うときに使用します。
