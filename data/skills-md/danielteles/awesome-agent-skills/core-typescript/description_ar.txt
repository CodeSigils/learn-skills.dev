اصطلاحات TypeScript على مستوى اللغة لكل مشروع، إطار عمل أم لا: صرامة المترجم، حظر الأنواع غير الآمنة، الاستدلال و"الإرضاء"، الاتحادات التمييزية والمعرفات ذات العلامات التجارية، التضييق مع حراس النوع ووظائف التأكيد، الأدوية العامة ذات التقييد، الأدوات المساعدة وأدوات مستوى النوع، الإلغاء، قواعد المزامنة، الأخطاء باعتبارها "غير معروفة"، نظافة الوحدة، وصحة اللغة. المهارة الأساسية التي يعتمد عليها "التفاعل" و"الزاوية" و"الهندسة المعمارية والتصميم". استخدمه عند كتابة TypeScript أو مراجعته أو إعادة هيكلته، أو إعداد `tsconfig.json`، أو عندما يقول المستخدم "TypeScript"، أو "tsconfig"، أو "الوضع الصارم"، أو "خطأ في الكتابة"، أو "أي"، أو "أدوية عامة"، أو "أمان النوع"، أو "أنواع المرافق"، أو "الاتحاد التمييزي"، أو "التضييق".
