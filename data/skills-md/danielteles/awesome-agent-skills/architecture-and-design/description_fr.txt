Architecture et normes de conception neutres en matière de framework pour l'ingénierie frontend dans TypeScript (React, Angular, Vue ou tout autre framework de composants) : SOLIDE, code propre, logique expressive, sécurité des types en tant que conception, architecture propre et limites des couches, structure axée sur les fonctionnalités d'abord, modèle d'adaptateur/référentiel, état asynchrone discriminé, niveaux d'état et récupération de données, sécurité, stratégie de test, modèles tactiques DDD, micro-frontends et formulaires. Utilisez-le lors de la génération d'un composant ou d'un module, de la refactorisation du code frontend, de la révision d'une pull request ou de la prise d'une décision d'architecture, ou lorsque l'utilisateur dit « révision du code », « architecture propre », « SOLID », « modèle de conception », « DDD », « contexte limité », « micro-frontend », « récupération de données », « validation de formulaire » ou « comment dois-je structurer cela ».
