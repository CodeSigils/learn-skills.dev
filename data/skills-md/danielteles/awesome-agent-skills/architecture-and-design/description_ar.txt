بنية محايدة للإطار ومعايير تصميم لهندسة الواجهة الأمامية في TypeScript (React أو Angular أو Vue أو أي إطار عمل مكون): SOLID، كود نظيف، منطق معبر، أمان الكتابة كتصميم، بنية نظيفة وحدود الطبقات، بنية الميزة الأولى، نمط المحول/المستودع، حالة المزامنة المميزة، طبقات الحالة وجلب البيانات، الأمان، استراتيجية الاختبار، أنماط DDD التكتيكية، الواجهات الصغيرة، والنماذج. استخدمها عند إنشاء مكون أو وحدة نمطية، أو إعادة هيكلة كود الواجهة الأمامية، أو مراجعة طلب سحب، أو اتخاذ قرار بشأن البنية، أو عندما يقول المستخدم "مراجعة الكود"، أو "هندسة نظيفة"، أو "SOLID"، أو "نمط التصميم"، أو "DDD"، أو "السياق المحدود"، أو "الواجهة الأمامية الدقيقة"، أو "جلب البيانات"، أو "التحقق من صحة النموذج"، أو "كيف يمكنني تنظيم هذا".
