Una herramienta CLI para gestionar artículos, comentarios, categorías, etiquetas, miembros, equipos y adjuntos de esa. Se utiliza para solicitudes como “buscar artículos de esa”, “leer un artículo”, “publicar en esa”, “comentar este artículo”, “guardar adjuntos”. Úsela para solicitudes de buscar, leer, crear o actualizar publicaciones en esa, comentar publicaciones, explorar información de equipos y subir o descargar adjuntos desde esa.io.
