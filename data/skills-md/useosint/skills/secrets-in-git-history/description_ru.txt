Собирайте данные из GitHub, GitLab и истории git для идентификации, инфраструктуры и утёкших учетных данных, используя email‑адреса авторов коммитов, поиск кода на GitHub, эндпоинт .patch коммита, trufflehog, gitleaks, git log pickaxe и сканирование полной истории ссылок. Применяйте при расследовании разработчика или организации на GitHub, поиске утёкших API‑ключей, AWS‑ключей или токенов в коде, перечислении участников организации и их личных репозиториев, либо восстановлении секретов, удалённых из HEAD, но всё ещё присутствующих в истории или форках. Подходит для оценки рисков цепочки поставок программного обеспечения, реагирования на утечку учётных данных, технической проверки при слиянии/покупке компаний и расследования внутренних угроз.
