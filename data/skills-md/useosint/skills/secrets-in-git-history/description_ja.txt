GitHub、GitLab、そして git の履歴を、コミット作者のメールアドレス、GitHub コード検索、commit .patch エンドポイント、trufflehog、gitleaks、git log pickaxe、フルリファレンス履歴スキャンを利用して、人物情報、インフラ情報、漏洩した認証情報の抽出に使用します。GitHub 上の開発者や組織を調査する際、コード中に漏洩した API キー、AWS キー、トークンを発見する際、組織メンバーやその個人リポジトリを列挙する際、または HEAD から削除されたが履歴やフォークに残っているシークレットを復元する際に活用できます。ソフトウェアサプライチェーンリスク、認証情報漏洩への対応、M&A の技術的デューデリジェンス、インサイダー脅威調査に適用できます。参照: useosint.com/skills/secrets-in-git-history
