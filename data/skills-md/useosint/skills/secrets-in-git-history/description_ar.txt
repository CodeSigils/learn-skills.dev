استخرج معلومات من GitHub وGitLab وتاريخ git للهوية والبنية التحتية والاعتمادات المسربة باستخدام عناوين بريد المؤلفين في الالتزام، بحث رمز GitHub، نقطة النهاية .patch للالتزام، trufflehog، gitleaks، git log pickaxe وفحص تاريخ الفروع بالكامل. يُستخدم عند التحقيق في مطور أو مؤسسة على GitHub، أو العثور على مفاتيح API أو مفاتيح AWS أو الرموز المتسربة في الكود، أو تعداد أعضاء المؤسسة ومستودعاتهم الشخصية، أو استعادة الأسرار المحذوفة من HEAD ولكن لا تزال موجودة في التاريخ أو الفروع المتفرعة. ينطبق على مخاطر سلسلة إمداد البرمجيات، والاستجابة لتسريب الاعتمادات، والعناية الفنية في عمليات الاندماج والاستحواذ، والتحقيق في تهديدات داخلية. المرجع على useosint.com/skills/secrets-in-git-history.
