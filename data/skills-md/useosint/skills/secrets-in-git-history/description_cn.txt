使用提交作者电子邮件、GitHub 代码搜索、commit .patch 接口、trufflehog、gitleaks、git log pickaxe 以及全引用历史扫描，对 GitHub、GitLab 和 Git 仓库历史进行挖掘，以获取身份信息、基础设施信息和泄露的凭证。适用于在 GitHub 上调查开发者或组织、查找代码中泄露的 API 密钥、AWS 密钥或令牌、枚举组织成员及其个人仓库，或恢复已从 HEAD 删除但仍保留在历史或分支中的机密。可用于软件供应链风险、凭证泄露响应、并购技术尽职调查以及内部威胁调查。参考 useosint.com/skills/secrets-in-git-history.
