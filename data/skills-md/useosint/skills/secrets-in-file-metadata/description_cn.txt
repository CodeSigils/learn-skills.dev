使用 exiftool 提取和解释嵌入的文件元数据——包括 EXIF GPS 坐标、相机品牌、型号和序列号、DateTimeOriginal 和 CreateDate 时间戳、XMP 和 IPTC 字段，以及 Office 和 PDF 属性，如作者、公司、LastModifiedBy、模板路径和修订次数。适用于读取照片的 EXIF、检查文档的真实作者、确定文件日期、指纹识别相机或手机，或调查 JPEG、HEIC、RAW、MP4、DOCX、XLSX 或 PDF 的来源。用于文档来源争议、内部泄漏归因、证据处理以及发布前的脱敏检查。参考网址 useosint.com/skills/secrets-in-file-metadata。
