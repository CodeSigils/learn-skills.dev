exiftool を使用して埋め込みファイルのメタデータを抽出して解釈します。EXIF GPS 座標、カメラのメーカー、モデルとシリアル、DateTimeOriginal と CreateDate のタイムスタンプ、XMP と IPTC フィールド、Office と PDF のプロパティ (Author、Company、LastModifiedBy、テンプレート パス、リビジョン数など)。写真から EXIF を読み取る場合、文書の実際の作成者を確認する場合、ファイルの日付を指定する場合、カメラや携帯電話のフィンガープリントを採取する場合、または JPEG、HEIC、RAW、MP4、DOCX、XLSX、または PDF の出所を調査する場合に使用します。文書の出所に関する論争、内部漏洩の帰属、証拠の処理、出版前の編集チェックに適用されます。 useosint.com/skills/secrets-in-file-metadata を参照してください。
