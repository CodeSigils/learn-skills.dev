قم بتعدين GitHub وGitLab وسجل git عن الهويات والبنية التحتية وبيانات الاعتماد المسربة باستخدام رسائل البريد الإلكتروني لمؤلف الالتزام والبحث عن كود GitHub ونقطة نهاية الالتزام .patch وtrufflehog وgitleaks وgit log Pickaxe وعمليات فحص سجل المرجع الكامل. يُستخدم عند التحقيق مع مطور أو مؤسسة على GitHub، أو العثور على مفاتيح API المسربة، أو مفاتيح AWS أو الرموز المميزة في التعليمات البرمجية، أو تعداد أعضاء المؤسسة ومستودعاتهم الشخصية، أو استعادة الأسرار المحذوفة من HEAD ولكنها لا تزال موجودة في السجل أو التفرعات. ينطبق على مخاطر سلسلة توريد البرامج، والاستجابة لتعرض بيانات الاعتماد، والعناية الفنية لعمليات الاندماج والاستحواذ، والتحقيق في التهديدات الداخلية. المرجع في useosint.com/skills/secrets-in-git-history.
