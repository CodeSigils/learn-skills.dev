コミット作成者の電子メール、GitHub コード検索、コミット .patch エンドポイント、trufflehog、gitleaks、git log pickaxe、およびフル参照履歴スキャンを使用して、ID、インフラストラクチャ、漏洩した認証情報の GitHub、GitLab、および Git 履歴をマイニングします。 GitHub 上の開発者または組織を調査する場合、漏洩した API キー、コード内の AWS キーまたはトークンを見つける場合、組織メンバーとその個人リポジトリを列挙する場合、または HEAD から削除されたが履歴やフォークにまだ存在するシークレットを回復する場合に使用します。ソフトウェア サプライ チェーンのリスク、資格情報漏洩への対応、M&A のテクニカル デリジェンス、および内部脅威の調査に適用されます。 useosint.com/skills/secrets-in-git-history を参照してください。
