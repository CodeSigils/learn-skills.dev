Estrae GitHub, GitLab e la cronologia git per identità, infrastruttura e credenziali trapelate utilizzando le e-mail dell'autore del commit, la ricerca del codice GitHub, l'endpoint commit .patch, tartufohog, gitleaks, git log pickaxe e le scansioni della cronologia completa dei riferimenti. Da utilizzare quando si indaga su uno sviluppatore o un'organizzazione su GitHub, si trovano chiavi API trapelate, chiavi AWS o token nel codice, si enumerano i membri dell'organizzazione e i loro repository personali o si recuperano segreti eliminati da HEAD ma ancora presenti nella cronologia o nei fork. Si applica al rischio della catena di fornitura del software, alla risposta all'esposizione delle credenziali, alla diligenza tecnica in materia di fusioni e acquisizioni e alle indagini sulle minacce interne. Riferimento a useosint.com/skills/secrets-in-git-history.
