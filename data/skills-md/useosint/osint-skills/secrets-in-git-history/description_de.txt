Durchsuchen Sie den GitHub-, GitLab- und Git-Verlauf nach Identitäten, Infrastruktur und durchgesickerten Anmeldeinformationen mithilfe von Commit-Autoren-E-Mails, GitHub-Codesuche, dem Commit-.patch-Endpunkt, Trufflehog, Gitleaks, Git-Log-Spitzhacke und vollständigen Ref-Verlaufsscans. Verwenden Sie es, wenn Sie einen Entwickler oder eine Organisation auf GitHub untersuchen, durchgesickerte API-Schlüssel, AWS-Schlüssel oder Token im Code finden, Organisationsmitglieder und ihre persönlichen Repos auflisten oder Geheimnisse wiederherstellen, die aus HEAD gelöscht wurden, aber noch im Verlauf oder in Forks vorhanden sind. Gilt für Risiken in der Software-Lieferkette, Reaktion auf Offenlegung von Anmeldeinformationen, technische Sorgfalt bei M&A und Untersuchung von Insider-Bedrohungen. Referenz unter useosint.com/skills/secrets-in-git-history.
