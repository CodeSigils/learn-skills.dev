使用 exiftool 提取和解释嵌入文件元数据 — EXIF GPS 坐标、相机制造商、型号和序列、DateTimeOriginal 和 CreateDate 时间戳、XMP 和 IPTC 字段以及 Office 和 PDF 属性，例如作者、公司、LastModifiedBy、模板路径和修订计数。当从照片中读取 EXIF、检查文档的真实编写者、文件的日期、对相机或手机进行指纹识别或调查 JPEG、HEIC、RAW、MP4、DOCX、XLSX 或 PDF 的出处时使用。适用于文件出处争议、内部泄密归因、证据处理和发布前修订检查。参考 useosint.com/skills/secrets-in-file-metadata。
