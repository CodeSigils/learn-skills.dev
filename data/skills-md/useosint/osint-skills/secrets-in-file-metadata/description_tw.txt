使用 exiftool 提取和解釋嵌入檔案元資料 — EXIF GPS 座標、相機製造商、型號和序列、DateTimeOriginal 和 CreateDate 時間戳記、XMP 和 IPTC 欄位以及 Office 和 PDF 屬性，例如作者、公司、LastModifiedBy、範本路徑和修訂計數。當從照片中讀取 EXIF、檢查文件的真實編寫者、文件的日期、相機或手機的指紋識別或調查 JPEG、HEIC、RAW、MP4、DOCX、XLSX 或 PDF 的來源時使用。適用於文件來源爭議、內部洩密歸因、證據處理及發布前修訂檢查。參考 useosint.com/skills/secrets-in-file-metadata。
