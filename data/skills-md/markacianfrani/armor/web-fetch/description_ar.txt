جلب المحتوى مباشرة من عناوين URL وإعادته بتنسيق تخفيض السعر أو النص أو HTML الخام. يُستخدم عندما يريد المستخدم قراءة صفحة ويب، أو فحص عنوان URL، أو سحب المستندات من موقع، أو استخراج محتوى الصفحة من رابط، أو جلب محتوى الويب دون فتح المتصفح. قم بتفضيل ذلك على أتمتة المتصفح عندما يكون جلب HTTP العادي كافياً. يدعم عناوين URL لـ GitHub blob والمواقع التي تُرجع تخفيض السعر المُحسّن لـ LLM للقبول: النص/تخفيض السعر.
