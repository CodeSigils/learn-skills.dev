Récupérez le contenu directement à partir des URL et renvoyez-le sous forme de démarque, de texte ou de HTML brut. À utiliser lorsque l'utilisateur souhaite lire une page Web, inspecter une URL, extraire des documents d'un site, extraire le contenu d'une page à partir d'un lien ou récupérer du contenu Web sans ouvrir de navigateur. Préférez cela à l’automatisation du navigateur lorsqu’une récupération HTTP normale suffit. Prend en charge les URL blob GitHub et les sites qui renvoient une démarque optimisée LLM pour Accept : text/markdown.
