Получайте контент непосредственно из URL-адресов и возвращайте его в виде уценки, текста или необработанного HTML. Используйте, когда пользователь хочет прочитать веб-страницу, проверить URL-адрес, извлечь документы с сайта, извлечь содержимое страницы по ссылке или получить веб-содержимое, не открывая браузер. Предпочитайте это автоматизации браузера, когда обычной HTTP-загрузки достаточно. Поддерживает URL-адреса больших двоичных объектов GitHub и сайты, которые возвращают оптимизированную для LLM уценку для Accept: text/markdown.
