Recupera i contenuti direttamente dagli URL e restituiscili come markdown, testo o HTML non elaborato. Da utilizzare quando l'utente desidera leggere una pagina Web, esaminare un URL, estrarre documenti da un sito, estrarre il contenuto di una pagina da un collegamento o recuperare contenuto Web senza aprire un browser. Preferiscilo all'automazione del browser quando è sufficiente un normale recupero HTTP. Supporta URL BLOB GitHub e siti che restituiscono markdown ottimizzato per LLM per Accetta: testo/markdown.
