Obtenga contenido directamente de las URL y devuélvalo como rebajas, texto o HTML sin formato. Úselo cuando el usuario quiera leer una página web, inspeccionar una URL, extraer documentos de un sitio, extraer contenido de una página de un enlace o buscar contenido web sin abrir un navegador. Prefiere esto a la automatización del navegador cuando una recuperación HTTP normal es suficiente.
