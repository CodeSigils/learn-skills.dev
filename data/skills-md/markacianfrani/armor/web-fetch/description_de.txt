Rufen Sie Inhalte direkt von URLs ab und geben Sie sie als Markdown, Text oder Roh-HTML zurück. Verwenden Sie diese Option, wenn der Benutzer eine Webseite lesen, eine URL überprüfen, Dokumente von einer Website abrufen, Seiteninhalte aus einem Link extrahieren oder Webinhalte abrufen möchte, ohne einen Browser zu öffnen. Ziehen Sie dies der Browser-Automatisierung vor, wenn ein normaler HTTP-Abruf ausreicht. Unterstützt GitHub-Blob-URLs und Websites, die LLM-optimierten Markdown für Accept: text/markdown zurückgeben.
