Generieren Sie n8n-Workflows, die den offiziellen ScraperAPI-Community-Knoten (n8n-nodes-scraperapi-official) verwenden. Verwenden Sie diesen Skill immer dann, wenn der Benutzer einen n8n-Workflow erstellen, entwerfen, automatisieren oder ein Gerüst erstellen möchte, der das Web über ScraperAPI durchsucht – auch wenn er „Skill“ oder „ScraperAPI-Knoten“ nicht namentlich nennt. Zu den Auslösern gehören: „Erstellen Sie einen n8n-Workflow, der die Amazon-Preise überwacht“, „erstellen Sie einen n8n-Flow, um die Google-Suche täglich zu scannen“, „generieren Sie einen n8n-JSON für einen Crawler, der auf diese Website gelangt“, „verbinden Sie ScraperAPI mit n8n, um mir Produktbewertungen per E-Mail zu senden“, „n8n-Automatisierung für Walmart-Preisverfolgung“, „verwenden Sie ScraperAPI in n8n, um Leads anzureichern“, „geben Sie meinem n8n-KI-Agenten Webzugriff über ScraperAPI“, „fügen Sie ScraperAPI hinzu als ein Tool für meinen N8N-Agenten". Erstellt entweder ein importierbares Workflow-JSON oder eine Schritt-für-Schritt-Anleitung im n8n-Editor und wählt das Format basierend auf der Formulierung der Anfrage durch den Benutzer aus.
