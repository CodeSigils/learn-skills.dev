ScraperAPI 非同步作業 API 的產品使用參考 — 在背景提交抓取作業並透過輪詢或 Webhook 擷取結果，包含最多 50,000 個 URL 的批次作業。當使用者抓取許多 URL、需要非阻塞請求或需要 Webhook 傳遞時進行諮詢。當使用者詢問：「如何使用 ScraperAPI 抓取 1000 個 URL」、「ScraperAPI 非同步作業」、「使用 ScraperAPI 批次抓取」、「提交抓取作業並輪詢結果」、「ScraperAPI Webhook 回呼」、「在後台抓取 URL」、「ScraperAPI 批次作業端點批次」時使用。涵蓋單一作業、批次作業（最多 50k 個 URL）、Webhook 回呼、所有 apiParams、非同步獨佔參數、二進位回應解碼、保留策略和錯誤處理。
