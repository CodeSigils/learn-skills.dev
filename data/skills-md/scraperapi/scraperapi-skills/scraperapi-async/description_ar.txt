مرجع استخدام المنتج لـ Async Jobs API الخاص بـ ScraperAPI - قم بإرسال مهام التجريد في الخلفية واسترجاع النتائج عبر الاستقصاء أو خطاف الويب، بما في ذلك المهام المجمعة التي تصل إلى 50000 عنوان URL. استشر عندما يقوم المستخدم باستخلاص العديد من عناوين URL، أو يحتاج إلى طلبات غير محظورة، أو يريد تسليم خطاف عبر الويب. يُستخدم عندما يسأل المستخدم: "كيف يمكنني استخراج 1000 عنوان URL باستخدام ScraperAPI"، و"مهام ScraperAPI غير المتزامنة"، و"التجميع المجمع باستخدام ScraperAPI"، و"إرسال مهمة تجريف واستطلاع للنتائج"، و"رد اتصال ScraperAPI على الويب"، و"مسح عناوين URL في الخلفية"، و"نقطة نهاية وظائف ScraperAPI". يغطي المهام الفردية، والوظائف المجمعة (ما يصل إلى 50 ألف عنوان URL)، وعمليات رد الاتصال عبر الويب، وجميع معلمات apiParams، والمعلمات غير المتزامنة الحصرية، وفك تشفير الاستجابة الثنائية، وسياسة الاحتفاظ، ومعالجة الأخطاء.
