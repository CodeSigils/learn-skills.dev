ScraperAPI の非同期ジョブ API の製品使用リファレンス — バックグラウンドでスクレイピング ジョブを送信し、ポーリングまたは Webhook 経由で結果を取得します (最大 50,000 URL のバッチ ジョブを含む)。ユーザーが多数の URL をスクレイピングしている場合、ノンブロッキング リクエストが必要な場合、または Webhook 配信を希望している場合に相談してください。ユーザーが「ScraperAPI で 1000 個の URL をスクレイピングするにはどうすればよいですか」、「ScraperAPI 非同期ジョブ」、「ScraperAPI を使用したバッチ スクレイピング」、「スクレイピング ジョブを送信して結果をポーリングする」、「ScraperAPI Webhook コールバック」、「バックグラウンドで URL をスクレイピングする」、「ScraperAPI バッチジョブ エンドポイント」を尋ねるときに使用します。単一ジョブ、バッチ ジョブ (最大 50,000 URL)、Webhook コールバック、すべての apiParams、非同期専用パラメーター、バイナリ レスポンス デコード、保持ポリシー、エラー処理をカバーします。
