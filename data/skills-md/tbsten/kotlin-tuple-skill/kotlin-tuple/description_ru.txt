Создает типобезопасные утилиты Tuple (Tuple0–Tuple20) для проектов Kotlin и Kotlin Multiplatform. Создает классы данных Tuple, фабрики tupleOf, преобразование toList, KSerializer для kotlinx.serialization, типобезопасные awaitAll и allNotNullOrNull за один раз. Используйте по запросу: «добавить Tuple», «сгенерировать tupleOf», «типобезопасный кортеж», «типобезопасный awaitAll», «добавить allNotNullOrNull», «ожидать несколько отложенных с типобезопасностью», «проверить несколько значений, допускающих значение NULL одновременно». Для проектов Kotlin/KMP, где Pair/Triple недостаточно для группировки нескольких элементов.
