Architecture de tranche verticale (VSA) pour les applications .NET — l'une des nombreuses architectures prises en charge dans dotnet-claude-kit. Couvre les dossiers de fonctionnalités, le regroupement de points de terminaison et les modèles de gestionnaire pour les classes Mediator, Wolverine et de gestionnaire brut. Chargez cette compétence lorsque le conseiller en architecture recommande VSA, lorsque vous travaillez dans une base de code VSA existante, lors de l'ajout de fonctionnalités à un projet de dossier de fonctionnalités ou lorsque vous discutez de modèles de tranches verticales, de dossiers de fonctionnalités ou de modèles de gestionnaire.
