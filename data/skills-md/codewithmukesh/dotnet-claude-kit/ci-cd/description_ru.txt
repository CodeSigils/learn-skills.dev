Конвейеры CI/CD для приложений .NET. Охватывает действия GitHub и конвейеры YAML Azure DevOps с этапами сборки, тестирования, публикации и развертывания. Загрузите этот навык при настройке непрерывной интеграции, автоматизированного тестирования, рабочих процессов развертывания или когда пользователь упоминает «CI/CD», «конвейер», «Действия GitHub», «Azure DevOps», «рабочий процесс», «развертывание», «построение конвейера», «публикация», «Push NuGet», «выпуск» или «непрерывная интеграция».
