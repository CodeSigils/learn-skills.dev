Modèles de messagerie asynchrone pour les applications .NET. Couvre Wolverine et MassTransit, le modèle de boîte d'envoi, la saga et la chorégraphie, ainsi que la configuration du courtier pour RabbitMQ et Azure Service Bus. Chargez cette compétence lors de la mise en œuvre d'une communication basée sur les événements, d'un traitement en arrière-plan, d'une messagerie de module à module ou lorsque l'utilisateur mentionne « Wolverine », « MassTransit », « message bus », « RabbitMQ », « Azure Service Bus », « événement », « publication », « consommateur », « boîte d'envoi », « saga », « événement d'intégration », « file d'attente » ou « pub/sub ».
