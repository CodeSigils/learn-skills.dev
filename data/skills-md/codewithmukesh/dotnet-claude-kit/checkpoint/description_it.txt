Punto di salvataggio a metà sessione: crea un git commit descrittivo e una breve nota di passaggio, quindi continua a lavorare. Da utilizzare prima di una modifica o di un refactoring rischioso, quando si cambiano le attività o per accumulare progressi senza terminare la sessione. Si attiva su: /checkpoint, "checkpoint", "salva avanzamento", "commit e handoff", "salva stato", "pausa qui", "prima di un cambiamento rischioso". Per il rituale completo di fine sessione con estrazione dell'apprendimento, utilizzare invece /wrap-up.
