Точка сохранения в середине сеанса: создайте описательный коммит git и краткую заметку о передаче, а затем продолжайте работу. Используйте перед рискованным изменением или рефакторингом, при переключении задач или для отслеживания прогресса без завершения сеанса. Срабатывает по: /checkpoint, «контрольная точка», «сохранить прогресс», «фиксировать и передать», «сохранить состояние», «пауза здесь», «перед рискованным изменением». Для полного ритуала завершения сеанса с извлечением знаний используйте вместо этого /wrap-up.
