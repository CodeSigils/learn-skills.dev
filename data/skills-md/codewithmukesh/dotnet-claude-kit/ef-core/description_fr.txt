Modèles Entity Framework Core pour .NET 10. Couvre la configuration DbContext, le flux de travail de migration, les intercepteurs, les requêtes compilées, ExecuteUpdateAsync, ExecuteDeleteAsync, les convertisseurs de valeur et l'optimisation des requêtes. Chargez cette compétence lorsque vous travaillez avec des bases de données, écrivez des requêtes, gérez des modifications de schéma ou lorsque l'utilisateur mentionne « EF Core », « Entity Framework », « DbContext », « migration », « requête LINQ », « base de données », « SQL », « N+1 », « Inclure », « requête fractionnée », « convertisseur de valeur », « intercepteur » ou « requête compilée ».
