Шаблоны Entity Framework Core для .NET 10. Охватывает конфигурацию DbContext, рабочий процесс миграции, перехватчики, скомпилированные запросы, ExecuteUpdateAsync, ExecuteDeleteAsync, преобразователи значений и оптимизацию запросов. Загрузите этот навык при работе с базами данных, написании запросов, управлении изменениями схемы или когда пользователь упоминает «EF Core», «Entity Framework», «DbContext», «миграцию», «запрос LINQ», «базу данных», «SQL», «N+1», «Включить», «разделенный запрос», «преобразователь значений», «перехватчик» или «скомпилированный запрос».
