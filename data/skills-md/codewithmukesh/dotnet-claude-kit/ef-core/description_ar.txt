الأنماط الأساسية لـ Entity Framework لـ .NET 10. تغطي تكوين DbContext، وسير عمل الترحيل، والمعترضات، والاستعلامات المجمعة، وExecuteUpdateAsync، وExecuteDeleteAsync، ومحولات القيمة، وتحسين الاستعلام. قم بتحميل هذه المهارة عند العمل مع قواعد البيانات، أو كتابة الاستعلامات، أو إدارة تغييرات المخطط، أو عندما يذكر المستخدم "EF Core"، أو "Entity Framework"، أو "DbContext"، أو "migration"، أو "LINQ query"، أو "database"، أو "SQL"، أو "N+1"، أو "Include"، أو "split query"، أو "value converter"، أو "interceptor"، أو "compiled query".
