MCP を利用した .NET プロジェクト用の多次元コード レビュー。アンチパターン、診断、参照、依存関係グラフに Roslyn 分析ツールを使用し、構造化された手動レビューと組み合わせます。 blast-radius スコアリング (スタイルよりもデータ アクセス、セキュリティ、同時実行性、統合境界) による作業に優先順位を付け、実用的な修正を伴う重大度分類の結果を生成します。次の場合に使用します: 「レビュー」、「コード レビュー」、「PR レビュー」、「これをレビュー」、「コードをレビュー」、「コードの品質をチェック」、「変更をレビュー」、「何をレビューすべきか」、「レビューの優先順位」、「爆発範囲」、「クリティカル パス」。
