Многомерная проверка кода на базе MCP для проектов .NET. Использует инструменты анализа Roslyn для антипаттернов, диагностики, ссылок и графиков зависимостей в сочетании со структурированным ручным анализом. Расставляет приоритеты усилий с помощью оценки радиуса взрыва — доступ к данным, безопасность, параллелизм и границы интеграции, прежде чем стиль — и выдает результаты с категорией серьезности и практическими исправлениями. Используйте, когда: «проверка», «проверка кода», «PR-обзор», «проверка этого», «проверка моего кода», «проверка качества кода», «проверка изменений», «что мне следует просмотреть», «приоритеты проверки», «радиус взрыва», «критический путь».
