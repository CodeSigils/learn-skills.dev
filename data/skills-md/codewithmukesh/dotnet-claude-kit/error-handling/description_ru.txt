Стратегия обработки ошибок для приложений .NET 10. Охватывает шаблон результата, сведения о проблеме (RFC 9457), глобальную обработку исключений, FluentValidation и структурированные ответы на ошибки. Загрузите этот навык при реализации обработки ошибок, проверке или разработке контрактов ошибок API или когда пользователь упоминает «обработку ошибок», «шаблон результата», «ProblemDetails», «исключение», «проверку», «FluentValidation», «ответ на ошибку», «глобальный обработчик исключений» или «RFC 9457».
