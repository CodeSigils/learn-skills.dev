Cicli di iterazione autonomi per .NET: porta al verde una build danneggiata o una suite di test non riuscita con iterazioni limitate, rilevamento dell'avanzamento e protezioni a prova di errore che impediscono tentativi infiniti e token sprecati. Il ciclo build-fix (compilazione dotnet, analisi, categorizzazione, correzione, ricostruzione) è il flusso principale; il ciclo test-fix è una variante di prima classe. Richiamare quando la build è danneggiata, dopo un refactoring importante o un aggiornamento delle dipendenze o quando l'utente dice "correggi la build", "la build è danneggiata", "fai compilare", "fai passare i test", "correggi i test non riusciti", "continua finché non funziona", "autonomo", "loop", "correzione automatica" o "continua a correggere".
