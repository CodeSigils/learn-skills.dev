Boucles d'itérations autonomes pour .NET : faites passer au vert une version cassée ou une suite de tests défaillante avec des itérations limitées, une détection de progression et des protections de sécurité qui empêchent les tentatives infinies et le gaspillage de jetons. La boucle build-fix (construction dotnet, analyse, catégorisation, correction, reconstruction) est le flux principal ; la boucle test-fix est une variante de première classe. Invoquer lorsque la build est interrompue, après un refactor majeur ou une mise à jour des dépendances, ou lorsque l'utilisateur dit « réparer la build », « la build est cassée », « faites-la compiler », « faites réussir les tests », « corrigez les tests qui échouent », « continuez jusqu'à ce que cela fonctionne », « autonome », « boucle », « correction automatique » ou « continuez à réparer ».
