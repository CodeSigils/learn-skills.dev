Bucles de iteración autónomos para .NET: haga que una compilación rota o un conjunto de pruebas fallido se vuelva verde con iteraciones limitadas, detección de progreso y protecciones a prueba de fallas que evitan reintentos infinitos y tokens desperdiciados. El ciclo de compilación y reparación (construcción dotnet, análisis, categorización, corrección, reconstrucción) es el flujo principal; El bucle Test-Fix es una variante de primera clase. Invocar cuando la compilación no funciona, después de una refactorización importante o una actualización de dependencia, o cuando el usuario dice "arreglar la compilación", "la compilación está rota", "hacer que se compile", "hacer que las pruebas pasen", "arreglar las pruebas fallidas", "seguir hasta que funcione", "autónomo", "bucle", "auto-reparación" o "seguir arreglando".
