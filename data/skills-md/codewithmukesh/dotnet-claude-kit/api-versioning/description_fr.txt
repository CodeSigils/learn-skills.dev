Stratégies de gestion des versions d'API pour ASP.NET Core. Couvre la bibliothèque Asp.Versioning, les stratégies de segment d'URL, d'en-tête et de chaîne de requête, la dépréciation de version et l'intégration OpenAPI. Chargez cette compétence lors de l'ajout de versions à une API, de l'évolution d'une API avec des modifications avec rupture, ou lorsque l'utilisateur mentionne "version API", "versioning", "v1/v2", "Asp.Versioning", "dépréciation", "modification avec rupture" ou "compatibilité ascendante".
