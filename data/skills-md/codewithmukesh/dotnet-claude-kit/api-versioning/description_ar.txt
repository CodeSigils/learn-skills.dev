استراتيجيات إصدار API لـ ASP.NET Core. يغطي مكتبة Asp.Versioning، وقطاع URL، والرأس، واستراتيجيات سلسلة الاستعلام، وإهمال الإصدار، وتكامل OpenAPI. قم بتحميل هذه المهارة عند إضافة إصدار إلى واجهة برمجة تطبيقات، أو تطوير واجهة برمجة تطبيقات مع تغييرات معطلة، أو عندما يذكر المستخدم "إصدار واجهة برمجة التطبيقات"، أو "إصدار الإصدار"، أو "v1/v2"، أو "Asp.Versioning"، أو "الإهمال"، أو "التغيير العاجل"، أو "التوافق مع الإصدارات السابقة".
