API-Versionierungsstrategien für ASP.NET Core. Behandelt die Asp.Versioning-Bibliothek, URL-Segment-, Header- und Abfragezeichenfolgenstrategien, die veraltete Version und die OpenAPI-Integration. Laden Sie diesen Skill, wenn Sie einer API Versionierung hinzufügen, eine API mit Breaking Changes weiterentwickeln oder wenn der Benutzer „API-Version“, „Versioning“, „v1/v2“, „Asp.Versioning“, „Deprecation“, „Breaking Change“ oder „Abwärtskompatibilität“ erwähnt.
