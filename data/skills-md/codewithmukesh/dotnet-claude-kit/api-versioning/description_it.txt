Strategie di controllo delle versioni API per ASP.NET Core. Copre la libreria Asp.Versioning, il segmento URL, le strategie di intestazione e stringa di query, la deprecazione della versione e l'integrazione OpenAPI. Carica questa competenza quando aggiungi il controllo delle versioni a un'API, evolvi un'API con modifiche importanti o quando l'utente menziona "versione API", "controllo delle versioni", "v1/v2", "Asp.Versioning", "deprecazione", "modifica importante" o "compatibilità con le versioni precedenti".
