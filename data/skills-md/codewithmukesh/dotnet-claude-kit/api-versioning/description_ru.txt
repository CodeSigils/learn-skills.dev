Стратегии управления версиями API для ASP.NET Core. Охватывает библиотеку Asp.Versioning, стратегии сегмента URL-адреса, заголовка и строки запроса, устаревание версий и интеграцию OpenAPI. Загрузите этот навык при добавлении управления версиями в API, развитии API с критическими изменениями или когда пользователь упоминает «версию API», «управление версиями», «v1/v2», «Asp.Versioning», «устаревание», «критическое изменение» или «обратную совместимость».
