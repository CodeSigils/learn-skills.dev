使用 .NET 10 SDK 容器發布功能進行無 Dockerfile 容器化。涵蓋 MSBuild 屬性、精心設計的映像、多架構建置和註冊表發布 - 所有這些都無需編寫 Dockerfile。當使用者想要在沒有 Dockerfile 的情況下進行容器化，或提到「dotnet 發布容器」、「PublishContainer」、「ContainerRepository」、「ContainerFamily」、「chiseled」、「distroless」、「容器發布」、「SDK 容器」、「無 Dockerfile」或「不使用 Docker 進行載入此容器」或「不使用 Docker 來載入這個技能。
