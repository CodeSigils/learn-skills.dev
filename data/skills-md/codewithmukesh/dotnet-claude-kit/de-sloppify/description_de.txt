Systematische Code-Bereinigungspipeline für .NET-Projekte. Führt 7 geordnete Schritte aus: Formatierung, ungenutzte Verwendungen, Analysewarnungen, Entfernung von totem Code, TODO-Auflösung, versiegelte Klassenprüfung und CancellationToken-Weitergabe. Jeder Schritt wird unabhängig mit Tests zwischen den Phasen überprüft. Laden Sie diesen Skill, wenn: „Aufräumen“, „Entschlacken“, „Aufräumen“, „toten Code entfernen“, „Code bereinigen“, „Housekeeping“, „Tech-Schulden“, „Warnungen beheben“, „Klassen versiegeln“, „CancellationToken hinzufügen“, „nicht verwendete Verwendungen“, „Code formatieren“.
