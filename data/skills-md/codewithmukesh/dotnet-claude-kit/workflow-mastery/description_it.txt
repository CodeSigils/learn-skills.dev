Padronanza del flusso di lavoro di Claude Code per sviluppatori .NET. Copre l'esecuzione parallela con alberi di lavoro git, strategia in modalità pianificazione, cicli di verifica, hook di formattazione automatica, configurazione delle autorizzazioni per la CLI dotnet, tecniche di prompt, modelli di subagenti e disciplina del contesto (gestione del budget dei token, navigazione MCP-first, caricamento lento e isolamento dei subagenti), il tutto adattato per l'ecosistema .NET. Caricare questa competenza quando si configura Claude Code per un progetto .NET, si ottimizzano i flussi di lavoro, si eseguono sessioni parallele, quando il contesto si sta esaurendo o le sessioni sembrano lente, quando si esplora in modo efficiente una base di codice di grandi dimensioni o quando l'utente menziona "produttività", "flusso di lavoro", "parallelo", "albero di lavoro", "modalità pianificazione", "autorizzazioni", "hook", "10x", "imposta Claude Code", "velocizza lo sviluppo", "contesto", "token", "budget", "in esaurimento" di contesto", "troppi file" o "base di codici di grandi dimensioni". Ispirato dai suggerimenti di Boris Cherny (creatore di Claude Code) e del team Anthropic.
