Claude Code-Workflow-Beherrschung für .NET-Entwickler. Behandelt die parallele Ausführung mit Git-Arbeitsbäumen, Planmodusstrategie, Verifizierungsschleifen, Hooks für die automatische Formatierung, Berechtigungseinrichtung für Dotnet-CLI, Aufforderungstechniken, Subagentenmuster und Kontextdisziplin – Token-Budgetverwaltung, MCP-First-Navigation, Lazy Loading und Subagenten-Isolation – alles angepasst an das .NET-Ökosystem. Laden Sie diesen Skill, wenn Sie Claude Code für ein .NET-Projekt einrichten, Arbeitsabläufe optimieren, parallele Sitzungen ausführen, wenn der Kontext zur Neige geht oder sich Sitzungen träge anfühlen, wenn Sie eine große Codebasis effizient erkunden oder wenn der Benutzer „Produktivität“, „Workflow“, „parallel“, „Arbeitsbaum“, „Planmodus“, „Berechtigungen“, „Hooks“, „10x“, „Claude Code einrichten“, „Entwicklung beschleunigen“, „Kontext“, „Tokens“, „Budget“, „Laufen“ erwähnt außerhalb des Kontexts“, „zu viele Dateien“ oder „große Codebasis“. Inspiriert durch Tipps von Boris Cherny (Erfinder von Claude Code) und dem Anthropic-Team.
