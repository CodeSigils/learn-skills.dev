Claude Maîtrise du workflow Code pour les développeurs .NET. Couvre l'exécution parallèle avec les arbres de travail git, la stratégie en mode plan, les boucles de vérification, les hooks de formatage automatique, la configuration des autorisations pour dotnet CLI, les techniques d'invite, les modèles de sous-agents et la discipline contextuelle - gestion du budget des jetons, navigation MCP-first, chargement paresseux et isolation des sous-agents - tous adaptés à l'écosystème .NET.
