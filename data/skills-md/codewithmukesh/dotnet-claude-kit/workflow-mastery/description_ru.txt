Освоение рабочего процесса Claude Code для разработчиков .NET. Охватывает параллельное выполнение с использованием рабочих деревьев git, стратегию режима планирования, циклы проверки, перехватчики автоматического форматирования, настройку разрешений для dotnet CLI, методы подсказок, шаблоны субагентов и контекстную дисциплину — управление бюджетом токенов, навигацию с приоритетом MCP, отложенную загрузку и изоляцию субагентов — все это адаптировано для экосистемы .NET. Загрузите этот навык при настройке Claude Code для проекта .NET, оптимизации рабочих процессов, запуске параллельных сеансов, когда контекст заканчивается или сеансы работают медленно, при эффективном изучении большой базы кода или когда пользователь упоминает «производительность», «рабочий процесс», «параллельный», «рабочее дерево», «режим планирования», «разрешения», «перехватчики», «10x», «настройка Claude Code», «ускорение разработки», «контекст», «токены», «бюджет», «недостаток контекста», «слишком много файлов» или «большая кодовая база». Вдохновлен советами Бориса Черного (создателя Claude Code) и команды Anthropic.
