Présentation de l'observabilité et colle pour .NET 10 : comment les éléments s'emboîtent, ainsi que les éléments transversaux détenus ici : points de terminaison de vérification de l'état ASP.NET (/health), ID de corrélation et stratégie au niveau du journal. Pour une configuration approfondie de Serilog, chargez « serilog » ; pour les traces et les métriques, chargez « opentelemetry ». Chargez cette compétence lors de la configuration de l'observabilité à partir de zéro, du câblage des points de terminaison de vérification de l'état ou des ID de corrélation, ou lorsque l'utilisateur dit « journalisation », « observabilité », « configuration de surveillance », « activité », « préparation » ou « ILogger ».
