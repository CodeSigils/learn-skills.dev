Descripción general de la observabilidad y pegamento para .NET 10: cómo encajan las piezas, además de las partes transversales que se poseen aquí: puntos finales de verificación de estado de ASP.NET (/health), ID de correlación y estrategia a nivel de registro. Para una configuración profunda de Serilog, cargue `serilog`; para seguimientos y métricas, cargue `opentelemetry`. Cargue esta habilidad al configurar la observabilidad desde cero, cablear puntos finales de verificación de estado o ID de correlación, o cuando el usuario diga "registro", "observabilidad", "configuración de monitoreo", "vida", "preparación" o "ILogger".
