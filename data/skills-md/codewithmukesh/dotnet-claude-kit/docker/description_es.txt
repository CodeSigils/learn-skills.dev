Contenedorización de Docker para aplicaciones .NET 10. Cubre compilaciones de varias etapas, imágenes de contenedores .NET, configuración de usuarios no root, comprobaciones de estado y .dockerignore. Cargue esta habilidad al contener una aplicación con un Dockerfile, optimizar el tamaño de la imagen, configurar Docker Compose para el desarrollo local o cuando el usuario mencione "Docker", "Dockerfile", "container", "docker-compose", "image", "multi-stage", "non-root", ".dockerignore" o "container health check". Para la publicación de SDK sin Dockerfile (`dotnet Publish /t:PublishContainer`), cargue la habilidad de publicación de contenedor.
