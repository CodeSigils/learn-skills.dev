.NET 10 アプリケーションの Docker コンテナ化。マルチステージ ビルド、.NET コンテナ イメージ、非 root ユーザー構成、ヘルス チェック、および .dockerignore をカバーします。 Dockerfile を使用したアプリケーションのコンテナ化、イメージ サイズの最適化、ローカル開発用の Docker Compose のセットアップ時、またはユーザーが「Docker」、「Dockerfile」、「container」、「docker-compose」、「image」、「multi-stage」、「non-root」、「.dockerignore」、「container health check」に言及したときに、このスキルをロードします。 Dockerfile を使用しない SDK 公開 (「dotnet pub /t:PublishContainer」) の場合は、代わりにコンテナー公開スキルを読み込みます。
