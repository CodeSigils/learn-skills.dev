.NET 10 應用程式的 Docker 容器化。涵蓋多階段建置、.NET 容器映像、非 root 使用者配置、執行狀況檢查和 .dockerignore。當使用 Dockerfile 對應用程式進行容器化、最佳化映像大小、設定 Docker Compose 進行本機開發時，或當使用者提到「Docker」、「Dockerfile」、「container」、「docker-compose」、「image」、「multi-stage」、「non-root」、「.dockerign」或「container」時，此技能。對於無 Dockerfile SDK 發布 (`dotnetpublish/t:PublishContainer`)，請改為載入容器發布技能。
