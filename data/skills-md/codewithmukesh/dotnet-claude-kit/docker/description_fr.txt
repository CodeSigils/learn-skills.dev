Conteneurisation Docker pour les applications .NET 10. Couvre les builds en plusieurs étapes, les images de conteneurs .NET, la configuration des utilisateurs non root, les vérifications de l'état et .dockerignore. Chargez cette compétence lors de la conteneurisation d'une application avec un Dockerfile, de l'optimisation de la taille de l'image, de la configuration de Docker Compose pour le développement local ou lorsque l'utilisateur mentionne "Docker", "Dockerfile", "conteneur", "docker-compose", "image", "multi-stage", "non-root", ".dockerignore" ou "container health check". Pour la publication du SDK sans Dockerfile (`dotnetpublish /t:PublishContainer`), chargez plutôt la compétence de publication de conteneur.
