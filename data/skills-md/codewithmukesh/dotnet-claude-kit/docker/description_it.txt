Containerizzazione Docker per applicazioni .NET 10. Copre build in più fasi, immagini di contenitori .NET, configurazione utente non root, controlli di integrità e .dockerignore. Caricare questa competenza quando si containerizza un'applicazione con un Dockerfile, si ottimizza la dimensione dell'immagine, si configura Docker Compose per lo sviluppo locale o quando l'utente menziona "Docker", "Dockerfile", "container", "docker-compose", "image", "multi-stage", "non-root", ".dockerignore" o "controllo dello stato del contenitore". Per la pubblicazione SDK senza Dockerfile (`dotnet pubblicare /t:PublishContainer`), caricare invece la competenza di pubblicazione del contenitore.
