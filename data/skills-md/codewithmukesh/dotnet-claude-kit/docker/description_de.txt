Docker-Containerisierung für .NET 10-Anwendungen. Behandelt mehrstufige Builds, .NET-Container-Images, Nicht-Root-Benutzerkonfiguration, Integritätsprüfungen und .dockerignore. Laden Sie diesen Skill, wenn Sie eine Anwendung mit einer Docker-Datei containerisieren, die Bildgröße optimieren, Docker Compose für die lokale Entwicklung einrichten oder wenn der Benutzer „Docker“, „Dockerfile“, „Container“, „docker-compose“, „image“, „multi-stage“, „non-root“, „.dockerignore“ oder „Container Health Check“ erwähnt. Laden Sie für die Dockerfile-lose SDK-Veröffentlichung („dotnetPublish /t:PublishContainer“) stattdessen den Container-Publish-Skill.
