حاويات Docker لتطبيقات .NET 10. يغطي عمليات الإنشاء متعددة المراحل، وصور حاويات .NET، وتكوين المستخدم غير الجذر، والفحوصات الصحية، و.dockerignore. قم بتحميل هذه المهارة عند وضع تطبيق في حاوية باستخدام ملف Dockerfile، أو تحسين حجم الصورة، أو إعداد Docker Compose للتطوير المحلي، أو عندما يذكر المستخدم "Docker" أو "Dockerfile" أو "container" أو "docker-compose" أو "image" أو "multi-stage" أو "non-root" أو ".dockerignore" أو "فحص صحة الحاوية". بالنسبة إلى نشر حزمة SDK بدون Dockerfile ("dotnet Publish /t:PublishContainer")، قم بتحميل مهارة نشر الحاوية بدلاً من ذلك.
