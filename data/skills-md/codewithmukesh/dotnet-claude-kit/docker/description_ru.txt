Контейнеризация Docker для приложений .NET 10. Охватывает многоэтапные сборки, образы контейнеров .NET, настройку пользователя без полномочий root, проверки работоспособности и .dockerignore. Загрузите этот навык при контейнеризации приложения с помощью Dockerfile, оптимизации размера образа, настройке Docker Compose для локальной разработки или когда пользователь упоминает «Docker», «Dockerfile», «container», «docker-compose», «image», «multi-stage», «non-root», «.dockerignore» или «проверка работоспособности контейнера». Для публикации SDK без Dockerfile (dotnetPublish/t:PublishContainer) вместо этого загрузите навык публикации контейнера.
