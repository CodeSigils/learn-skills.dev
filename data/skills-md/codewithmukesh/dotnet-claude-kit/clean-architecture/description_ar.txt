بنية نظيفة لتطبيقات .NET. يغطي تخطيط المشروعات الأربعة (المجال، التطبيق، البنية التحتية، واجهة برمجة التطبيقات)، وانعكاس التبعية، واستخدام معالجات الحالة، وكيانات المجال ذات السلوك، والبنية التحتية كمكون إضافي. قم بتحميل هذه المهارة عند إنشاء مشروع باستخدام Clean Architecture، أو مناقشة البنية ذات الطبقات، أو انعكاس التبعية، أو حالات الاستخدام، أو عندما يوصي مستشار البنية بـ Clean Architecture.
