Чистая архитектура для приложений .NET. Охватывает макет из 4 проектов (домен, приложение, инфраструктура, API), инверсию зависимостей, обработчики вариантов использования, объекты предметной области с поведением и инфраструктуру в виде плагина. Используйте этот навык при создании проекта с использованием «Чистой архитектуры», обсуждении многоуровневой архитектуры, инверсии зависимостей, вариантов использования или когда консультант по архитектуре рекомендует «Чистую архитектуру».
