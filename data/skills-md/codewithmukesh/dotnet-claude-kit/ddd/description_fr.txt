Modèles tactiques de conception pilotée par domaine pour les applications .NET. Couvre les agrégats, les racines d'agrégat, les objets de valeur, les événements de domaine, les services de domaine, les ID fortement typés et les modèles de référentiel pour la persistance des agrégats. Chargez cette compétence lors de l'implémentation de DDD, de l'utilisation d'agrégats, d'objets de valeur, d'événements de domaine, de contextes délimités ou lorsque le conseiller en architecture recommande DDD + Clean Architecture. Associez-le à la compétence d’architecture propre.
