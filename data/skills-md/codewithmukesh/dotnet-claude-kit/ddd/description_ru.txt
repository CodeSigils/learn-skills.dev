Тактические шаблоны доменно-ориентированного проектирования для приложений .NET. Охватывает агрегаты, корни агрегатов, объекты значений, события предметной области, службы предметной области, строго типизированные идентификаторы и шаблоны репозитория для устойчивости агрегатов. Используйте этот навык при реализации DDD, работе с агрегатами, объектами значений, событиями предметной области, ограниченными контекстами или когда консультант по архитектуре рекомендует DDD + Чистая архитектура. В сочетании с навыками создания чистой архитектуры.
