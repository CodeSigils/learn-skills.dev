Modelli tattici di progettazione basata su dominio per applicazioni .NET. Copre aggregati, radici aggregate, oggetti valore, eventi di dominio, servizi di dominio, ID fortemente tipizzati e modelli di repository per la persistenza degli aggregati. Carica questa competenza quando implementi DDD, lavori con aggregati, oggetti valore, eventi di dominio, contesti delimitati o quando il consulente di architettura consiglia DDD + Clean Architecture. Abbinalo all'abilità di architettura pulita.
