.NET 10-Minimal-APIs – der Standard zum Erstellen von HTTP-Endpunkten. Behandelt MapGroup, Endpunktfilter, TypedResults, OpenAPI-Metadaten, Parameterbindung und Routenkonventionen. Laden Sie diesen Skill, wenn Sie API-Endpunkte erstellen, Routing konfigurieren, OpenAPI-Dokumentation einrichten oder wenn der Benutzer „Endpunkt“, „MapGet“, „MapPost“, „MapGroup“, „TypedResults“, „Route“, „Minimal API“, „OpenAPI“, „Swagger“, „Ratenbegrenzung“ oder „Ausgabecaching“ erwähnt.
