Минимальные API .NET 10 — значение по умолчанию для создания конечных точек HTTP. Охватывает MapGroup, фильтры конечных точек, TypedResults, метаданные OpenAPI, привязку параметров и соглашения о маршрутах. Загрузите этот навык при создании конечных точек API, настройке маршрутизации, настройке документации OpenAPI или когда пользователь упоминает «конечную точку», «MapGet», «MapPost», «MapGroup», «TypedResults», «route», «минимальный API», «OpenAPI», «swagger», «ограничение скорости» или «кэширование вывода».
