Interface utilisateur de documentation de l'API scalaire pour les applications .NET 10. Couvre la configuration, les thèmes, le pré-remplissage de l'authentification, plusieurs documents, les options de mise en page et la sécurité. Un remplacement moderne pour l'interface utilisateur Swagger. Chargez cette compétence lors de la configuration de l'interface utilisateur de la documentation de l'API, ou lorsque l'utilisateur mentionne « Scalar », « MapScalarApiReference », « référence API », « remplacement de l'interface utilisateur Swagger », « interface utilisateur de la documentation API », « thème scalaire », « documents API interactifs » ou « Essayez-le ».
