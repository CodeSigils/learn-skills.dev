Interfaz de usuario de documentación de API escalar para aplicaciones .NET 10. Cubre configuración, temas, precarga de autenticación, múltiples documentos, opciones de diseño y seguridad. Un reemplazo moderno para Swagger UI. Cargue esta habilidad al configurar la interfaz de usuario de documentación de API, o cuando el usuario mencione "Escalar", "MapScalarApiReference", "referencia de API", "reemplazo de interfaz de usuario de Swagger", "IU de documentación de API", "tema de Scalar", "documentos de API interactivos" o "Pruébelo".
