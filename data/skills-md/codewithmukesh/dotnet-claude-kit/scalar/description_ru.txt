Пользовательский интерфейс документации скалярного API для приложений .NET 10. Охватывает настройку, темы, предварительную проверку подлинности, несколько документов, параметры макета и безопасность. Современная замена Swagger UI. Загрузите этот навык при настройке пользовательского интерфейса документации API или когда пользователь упоминает «Scalar», «MapScalarApiReference», «Справочник API», «Замена пользовательского интерфейса Swagger», «Пользовательский интерфейс документации API», «Скалярная тема», «Интерактивная документация API» или «Попробуйте».
