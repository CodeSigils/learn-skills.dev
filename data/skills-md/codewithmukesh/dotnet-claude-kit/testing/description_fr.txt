Stratégie de test pour les applications .NET 10. Couvre xUnit v3, WebApplicationFactory pour les tests d'intégration, Testcontainers pour les tests de bases de données réelles, Verify pour les tests d'instantanés et le modèle AAA. Chargez cette compétence lors de l'écriture de tests, de la configuration de l'infrastructure de test, de la révision de la couverture des tests ou lorsque l'utilisateur mentionne "test", "xUnit", "WebApplicationFactory", "Testcontainers", "integration test", "unit test", "bUnit", "snapshot test", "Verify", "test cover", "AAA pattern", "WireMock" ou "FakeTimeProvider".
