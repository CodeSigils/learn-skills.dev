Modèles de configuration pour les applications .NET 10. Couvre le modèle Options, IOptionsSnapshot vs IOptions, la gestion des secrets et la configuration basée sur l'environnement. Chargez cette compétence lors de la configuration de l'application, de la gestion des secrets, de la liaison des sections de configuration ou lorsque l'utilisateur mentionne « configuration », « appsettings », « modèle d'options », « IOptions », « IOptionsSnapshot », « secrets », « secrets utilisateur », « variables d'environnement », « chaîne de connexion » ou « liaison de configuration ».
