Élaborez une condition d'achèvement mesurable pour les exécutions d'agents autonomes à plusieurs tours - par ex. Claude Code /objectif — à partir d'une demande vague : entretien pour la méthode de vérification, les contraintes de portée et les limites d'arrêt, puis émettre une déclaration de condition qu'un évaluateur de sortie uniquement peut vérifier. À utiliser lorsqu'un utilisateur souhaite définir /goal, définir des critères de réalisation pour une boucle autonome ou transformer une description de tâche en une condition d'achèvement vérifiable.
