Audite periódicamente los documentos de un repositorio para comprobar si están obsoletos en comparación con la implementación: ejecute un análisis mecánico barato (referencias de rutas de origen inactivas, enlaces inactivos, pancartas DEPRECADAS/TBD sobrantes, brecha de actualización entre documentos y códigos, sobras ignoradas por git-invisible, archivos de plan completados pero no eliminados), luego envíe agentes paralelos de solo lectura para verificar solo los documentos sospechosos con respecto a la fuente y, finalmente, proponga disposiciones de actualización/eliminación/migración a ADR para el usuario. aprobación. Úselo en una revisión de documentos mensual o trimestral, después de grandes refactorizaciones o cambios de nombre, o cuando se le pregunte si los documentos están obsoletos.
