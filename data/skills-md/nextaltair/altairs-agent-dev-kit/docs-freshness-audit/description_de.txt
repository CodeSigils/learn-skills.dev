Überprüfen Sie die Dokumente eines Repositorys regelmäßig auf Veraltung im Vergleich zur Implementierung: Führen Sie einen kostengünstigen mechanischen Scan durch (tote Quellpfadverweise, tote Links, übrig gebliebene DEPRECATED/TBD-Banner, Aktualitätslücke zwischen Dokument und Code, von Git unsichtbar ignorierte Reste, abgeschlossene, aber nicht gelöschte Plandateien), senden Sie dann parallele schreibgeschützte Agenten, um nur die verdächtigen Dokumente anhand der Quelle zu überprüfen, und schlagen Sie schließlich eine Aktualisierung/Löschung/Entfernung vor. Dispositionen zur Migration nach ADR zur Genehmigung durch den Benutzer. Verwenden Sie es bei einer monatlichen oder vierteljährlichen Überprüfung von Dokumenten, nach umfangreichen Umgestaltungen oder Umbenennungen oder wenn Sie gefragt werden, ob Dokumente veraltet sind.
