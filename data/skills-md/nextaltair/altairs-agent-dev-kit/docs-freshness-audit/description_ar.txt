قم بمراجعة مستندات المستودع بشكل دوري للتأكد من عدم صلاحيتها ضد التنفيذ: قم بإجراء فحص ميكانيكي رخيص (مراجع مسار المصدر الميت، والروابط الميتة، وبقايا لافتات DEPRECATED/TBD، وفجوة حداثة المستند مقابل الكود، وبقايا تجاهل git غير المرئية، وملفات الخطة المكتملة ولكن غير المحذوفة)، ثم إرسال وكلاء متوازيين للقراءة فقط للتحقق فقط من المستندات المشبوهة مقابل المصدر، وأخيرًا اقتراح التحديث / الحذف / الترحيل إلى ADR التصرفات لموافقة المستخدم. استخدمه في مراجعة المستندات شهريًا أو ربع سنوي، بعد عمليات إعادة البناء أو إعادة التسمية الكبيرة، أو عند السؤال عما إذا كانت المستندات قديمة.
