TypeScript 6+ 项目开发、tsconfig 配置、诊断、模块解析、弃用和现代标准库类型的指南。在构建或维护 TypeScript 6+ 项目、调试编译器行为或使用 TS 6 特定的默认值和工具（例如“#/”子路径导入、“ignoreDeprecations”、“RegExp.escape”、“Temporal”和“--stableTypeOrdering”）时使用。在 typescript 6、ts 6、stableTypeOrdering、ignoreDeprecations、types array、noUncheckedSideEffectImports、baseUrl 已弃用、moduleResolution 节点已弃用和子路径导入上触发。
