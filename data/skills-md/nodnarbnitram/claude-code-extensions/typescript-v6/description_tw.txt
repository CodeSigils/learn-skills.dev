TypeScript 6+ 專案開發、tsconfig 設定、診斷、模組解析、棄用和現代標準函式庫類型的指南。在建置或維護 TypeScript 6+ 專案、偵錯編譯器行為或使用 TS 6 特定的預設值和工具（例如「#/」子路徑導入、「ignoreDeprecations」、「RegExp.escape」、「Temporal」和「--stableTypeOrdering」）時使用。在 typescript 6、ts 6、stableTypeOrdering、ignoreDeprecations、types array、noUncheckedSideEffectImports、baseUrl 已棄用、moduleResolution 節點已棄用和子路徑導入上觸發。
