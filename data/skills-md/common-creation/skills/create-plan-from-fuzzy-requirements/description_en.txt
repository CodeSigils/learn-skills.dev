A skill for breaking down vague or abstract requirement texts from management and stakeholders into concrete functional requirement lists and implementation plans. It is used when users say things like “organize this requirement,” “implement this (with vague instructions),” “concretize the requirement,” or “clarify what should be built,” or when you need to devise an implementation approach from ambiguous text fragments. It works with any input format, such as Slack messages, emails, meeting notes, or oral instruction notes.
