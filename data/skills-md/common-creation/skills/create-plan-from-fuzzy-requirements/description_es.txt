La capacidad de descomponer textos de requisitos vagos y abstractos de ejecutivos o partes interesadas en listas de requisitos funcionales y planes de implementación concretos. Se utiliza cuando un usuario dice cosas como "organizar estos requisitos", "implementar esto (con instrucciones vagas)", "concretar los requisitos" o "aclarar lo que se debe construir", o cuando es necesario idear un enfoque de implementación a partir de fragmentos de texto ambiguos. Funciona con cualquier formato de entrada, como mensajes de Slack, correos electrónicos, notas de reuniones o notas de instrucciones verbales.
