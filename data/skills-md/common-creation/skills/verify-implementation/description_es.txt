Una habilidad que compara los cambios no confirmados en un repositorio Git con el texto de especificaciones/requisitos para verificar si la implementación cumple con los requisitos. Se utiliza cuando el usuario dice cosas como "Compruebe si está implementado correctamente", "¿Está implementado de acuerdo con las especificaciones?" “/verify-implementation”, o cuando quieren confirmar la alineación con las especificaciones después de los cambios de código. Presenta el estado de cumplimiento de los requisitos en una lista, indicando claramente los elementos no implementados o parcialmente implementados.
