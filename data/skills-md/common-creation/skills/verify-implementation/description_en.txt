A skill that compares uncommitted changes in a Git repository with specification and requirement texts to verify whether the implementation meets the requirements. It is used when the user says things like “Check if it’s implemented correctly,” “Is it implemented according to the specs?” or “/verify-implementation,” or when they want to confirm alignment with the specification after code changes. It presents the fulfillment status of requirements in a list, clearly indicating items that are unimplemented or partially implemented.
