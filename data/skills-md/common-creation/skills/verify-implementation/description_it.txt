Una competenza che confronta le modifiche non confermate in un repository Git con il testo delle specifiche/requisiti per verificare se l'implementazione soddisfa i requisiti. Viene utilizzato quando l'utente dice cose come "Controlla se è implementato correttamente", "È implementato secondo le specifiche?" "/verify-implementation" o quando vogliono confermare l'allineamento con le specifiche dopo le modifiche al codice. Presenta lo stato di adempimento dei requisiti in un elenco, indicando chiaramente gli elementi non implementati o parzialmente implementati.
