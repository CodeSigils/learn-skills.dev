Forma codice scalabile: servizi di dominio con API pubbliche, primitive forti all'interno di moduli profondi, punti di ingresso semplici, cartelle cancellate, progettazione dei dati del percorso di scrittura. Doppia abilità: l'agente sceglie in modo autonomo rispetto al flusso tramite varianti.md. Da utilizzare quando si aggiungono funzionalità, si divide la logica, si progettano dati/letture o si sta per eseguire il dump di file/duplicare la logica del dominio. L'utente deve invocare.
