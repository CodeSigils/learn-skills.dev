Специально созданный механизм повторов + детерминированный симулятор заполнения для стратегий L1/L2/L3. Управляет итерациями каждого тиккера, снабжая каждую стратегию только прошлым баром t, поэтому ни одна идея не может заглянуть вперед. bt-1 охватывает цикл воспроизведения; bt-2 добавляет консервативный симулятор внутрибарного заполнения; bt-4 добавляет показатели для каждой стратегии + эталон «купи и держи»; bt-5 добавляет канонический интерфейс командной строки (--strategy/--ticker/--interval + --from/--to фильтры, --json AXI-конверт, --forensic-drill Audit Trail).
