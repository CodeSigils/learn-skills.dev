تنفيذ تصميم سريع الاستجابة لمواقع الويب وتطبيقات الويب - بدءًا من تخطيطات الهاتف المحمول القياسية أولاً وحتى الأنماط المعقدة (العناصر الثابتة، وتنسيق التمرير، وجداول البيانات، ولوحات المعلومات). ثلاثة أوضاع: تحويل المواقع الحالية، أو إنشاء مواقع مستجيبة من البداية، أو تشغيل معاينة مباشرة متعددة نقاط التوقف. تصمم الأسطح شوكات حيث لا توجد إجابة واحدة صحيحة. يُستخدم عند إنشاء تخطيطات سريعة الاستجابة، أو إصلاح مشكلات الهاتف المحمول، أو إضافة نقاط توقف، أو العمل مع أنماط التثبيت/التمرير، أو معاينة نقاط التوقف، أو عندما يذكر المستخدم الاستجابة، أو الجوال، أو نقاط التوقف، أو إطار العرض، أو التصميم التكيفي، أو المعاينة المستجيبة.
