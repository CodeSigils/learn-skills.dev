Implementa un design reattivo per siti Web e app Web: dai layout standard mobile-first ai modelli complessi (elementi permanenti, coordinazione dello scorrimento, tabelle dati, dashboard). Tre modalità: trasformare i siti esistenti, creare responsive da zero o avviare un'anteprima live multi-breakpoint. Le superfici progettano biforcazioni dove non esiste un'unica risposta giusta. Da utilizzare quando si creano layout reattivi, si risolvono problemi relativi ai dispositivi mobili, si aggiungono punti di interruzione, si lavora con pattern persistenti/scorrimento, si visualizza l'anteprima di punti di interruzione o quando l'utente menziona reattivo, mobile, punti di interruzione, viewport, progettazione adattiva o anteprima reattiva.
