Implemente un diseño responsivo para sitios web y aplicaciones web, desde diseños estándar para dispositivos móviles hasta patrones complejos (elementos fijos, coordinación de desplazamiento, tablas de datos, paneles). Tres modos: transformar sitios existentes, crear sitios responsivos desde cero o iniciar una vista previa en vivo de múltiples puntos de interrupción. Las superficies diseñan bifurcaciones donde no existe una única respuesta correcta. Úselo al crear diseños responsivos, solucionar problemas móviles, agregar puntos de interrupción, trabajar con patrones adhesivos/de desplazamiento, obtener una vista previa de puntos de interrupción o cuando el usuario mencione puntos de interrupción responsivos, móviles, ventana gráfica, diseño adaptable o vista previa responsiva.
