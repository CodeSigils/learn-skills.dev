Referencia de estilo de codificación C++. Seleccione la referencia adecuada según el sistema de compilación del proyecto: los proyectos xmake usan references-xmake (módulos C++ 20), los proyectos CMake + vcpkg usan references-cmake-vcpkg (.hpp/.cpp). Se aplica al escribir o revisar código C++, nombrar identificadores, organizar módulos o encabezados, o cuando el usuario menciona el estilo C++.
