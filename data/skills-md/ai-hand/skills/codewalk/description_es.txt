Instale, use y administre CodeWalk: una aplicación macOS + CLI para tutoriales de códigos visuales interactivos. Utilice esta habilidad siempre que el usuario mencione CodeWalk, codewalk, recorrido del código, explicación visual del código, presentación del código, recorrido del código o quiera recorrer visualmente el código con animaciones y aspectos destacados. También se activa cuando el usuario dice cosas como '코드를 가르쳐줘', '코드 설명을 눈으로 보여줘', 'UI로 보여줘', 'muéstrame el código visualmente', 'enséñame este código', 'guíame' o cualquier solicitud para explicar código de forma visual/interactiva en lugar de texto plano. Úselo también cuando el usuario quiera instalar, desinstalar, actualizar o solucionar problemas de CodeWalk, o cuando quiera crear archivos JSON de guía para explicar el código.
