Installez, utilisez et gérez CodeWalk – une application macOS + CLI pour des procédures pas à pas interactives de code visuel. Utilisez cette compétence chaque fois que l'utilisateur mentionne CodeWalk, codewalk, procédure pas à pas du code, explication visuelle du code, présentation du code, visite guidée du code ou souhaite parcourir visuellement le code avec des animations et des surlignages. Se déclenche également lorsque l'utilisateur dit des choses comme « 코드를 가르쳐줘 », « 코드 설명을 눈으로 보여줘 », « UI로 보여줘 », « montre-moi le code visuellement », « apprends-moi ce code », « promène-moi ». through', ou toute demande visant à expliquer le code de manière visuelle/interactive plutôt qu'en texte brut. À utiliser également lorsque l'utilisateur souhaite installer, désinstaller, mettre à jour ou dépanner CodeWalk, ou lorsqu'il souhaite créer des fichiers JSON pas à pas pour expliquer le code.
