قم بتثبيت CodeWalk واستخدامه وإدارته - وهو تطبيق macOS + CLI للإرشادات التفصيلية التفاعلية للكود المرئي. استخدم هذه المهارة عندما يذكر المستخدم CodeWalk، أو Codewalk، أو التعليمات التفصيلية للتعليمات البرمجية، أو شرح التعليمات البرمجية المرئية، أو عرض التعليمات البرمجية، أو جولة التعليمات البرمجية، أو عندما يريد التجول بشكل مرئي عبر التعليمات البرمجية باستخدام الرسوم المتحركة والإبرازات. يتم تشغيله أيضًا عندما يقول المستخدم أشياء مثل "코드를 가르쳐줘"، أو "코드 설명을 눈으로 보여줘"، أو "UI로 보여줘"، أو "أرني الرمز بشكل مرئي"، أو "علمني هذا الرمز"، أو "أرشدني خلال"، أو أي طلب شرح الكود بطريقة مرئية/تفاعلية بدلاً من النص العادي. يُستخدم أيضًا عندما يريد المستخدم تثبيت CodeWalk أو إلغاء تثبيته أو تحديثه أو استكشاف أخطاءه وإصلاحها، أو عندما يريد إنشاء ملفات JSON تفصيلية لشرح التعليمات البرمجية.
