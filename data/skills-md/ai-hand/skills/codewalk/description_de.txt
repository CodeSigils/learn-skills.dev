Installieren, verwenden und verwalten Sie CodeWalk – eine macOS-App + CLI für interaktive visuelle Code-Komplettlösungen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer CodeWalk, Codewalk, Code-Komplettlösung, visuelle Code-Erklärung, Code-Präsentation oder Code-Tour erwähnt oder mit Animationen und Hervorhebungen visuell durch den Code gehen möchte. Wird auch ausgelöst, wenn der Benutzer Dinge wie „코드를 가르쳐줘“, „코드 설명을 눈으로 보여줘“, „UI로 보여줘“, „Zeige mir den Code visuell“, „Bring mir diesen Code bei“, „Führe mich durch“ oder eine Aufforderung zur Erklärung sagt Code auf visuelle/interaktive Weise anstelle von einfachem Text erstellen. Verwenden Sie es auch, wenn der Benutzer CodeWalk installieren, deinstallieren, aktualisieren oder Fehler beheben möchte oder wenn er Walkthrough-JSON-Dateien zur Codeerklärung erstellen möchte.
