Habilidad de elaboración de documentación para documentos de proyectos que coincidan con el código y se lean bien. Úselo al escribir, auditar, sincronizar o extraer documentación: archivos README, referencias de API, tutoriales, guías prácticas, explicaciones, notas de arquitectura, registros de cambios, runbooks y documentos de API en código. Hace cumplir afirmaciones a nivel de evidencia (sin indicadores, puntos finales, parámetros, valores predeterminados o tipos de devolución fabricados), estructura alineada con Diátaxis, ajuste de audiencia, detección de deriva y prosa que gana su longitud.
