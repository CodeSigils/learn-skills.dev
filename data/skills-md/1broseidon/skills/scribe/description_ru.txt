Навыки создания документации для проектной документации, которая соответствует коду и хорошо читается. Используйте при написании, аудите, синхронизации или извлечении документации: файлы README, ссылки на API, учебные пособия, практические руководства, пояснения, заметки по архитектуре, журналы изменений, модули Runbook и документацию по API в коде. Обеспечивает соблюдение требований на уровне доказательств (без вымышленных флагов, конечных точек, параметров, значений по умолчанию или возвращаемых типов), структура, соответствующая Diátaxis, соответствие аудитории, обнаружение отклонений и проза, заслуживающая своей длины.
