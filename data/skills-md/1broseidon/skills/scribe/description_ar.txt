مهارة التوثيق الحرفية لمستندات المشروع التي تتطابق مع الكود وتقرأ جيدًا. يُستخدم عند الكتابة أو التدقيق أو المزامنة أو استخراج الوثائق: ملفات README، ومراجع API، والبرامج التعليمية، والأدلة الإرشادية، والشروحات، وملاحظات الهندسة المعمارية، وسجلات التغيير، وكتب التشغيل، ومستندات API المضمنة في التعليمات البرمجية. يفرض مطالبات على مستوى الأدلة (لا توجد علامات ملفقة، أو نقاط نهاية، أو معلمات، أو افتراضيات، أو أنواع إرجاع)، وبنية محاذاة للخط الفاصل، وملاءمة الجمهور، واكتشاف الانجراف، والنثر الذي يكسب طوله.
