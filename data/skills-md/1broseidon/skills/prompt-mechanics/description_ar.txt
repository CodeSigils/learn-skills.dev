يطالب نظام المهندس وتعليمات الوكيل ومهارات أخرى تتعارض مع كيفية معالجة LLM للنص فعليًا، بدلاً من كتابتها حسب الشعور. يُستخدم عند تأليف أو مراجعة أي قطعة أثرية تشبه المطالبة: موجه النظام، أو مجموعة تعليمات الوكيل، أو SKILL.md، أو سياسة استخدام الأداة، أو CLAUDE.md، أو كتلة التعليمات السلوكية الطويلة التي ينفذها LLM. المحفزات: "تشديد/تحسين هذه المطالبة"، أو طلب نقد أو إعادة كتابة، أو مطالبة يتم تجاهلها أو لا يمكن الاعتماد عليها، أو نقل مطالبة إلى أداة أو نموذج جديد. القيمة هي تطبيق الآلية وراء كل إصلاح، وليس الإصلاح فقط.
