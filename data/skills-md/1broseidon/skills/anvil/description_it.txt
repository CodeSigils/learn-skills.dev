Competenza artigianale nel backend per CLI indipendenti dalla lingua, API REST, servizi gRPC, API di pacchetti e struttura di repository backend. Da utilizzare durante la creazione, il controllo, la rimodellamento o lo studio dei limiti del backend: alberi dei comandi, contratti HTTP/gRPC, inviluppi di errore, precedenza di configurazione, hook di operabilità, limiti dei pacchetti, codice inattivo, forma dei pacchetti condivisi e strumenti compatibili con agenti/script. Non per l'interfaccia utente del browser, la progettazione di schemi ORM, la modellazione di domini aziendali, Kubernetes/Terraform o la progettazione di frontend.
