Habilidad de artesanía de backend para CLI independientes del idioma, API REST, servicios gRPC, API de paquetes y estructura de repositorio de backend. Úselo al crear, auditar, remodelar o estudiar los límites del backend: árboles de comandos, contratos HTTP/gRPC, sobres de error, precedencia de configuración, enlaces de operabilidad, límites de paquetes, código inactivo, forma de paquete compartido y herramientas compatibles con agentes/scripts. No para la interfaz de usuario del navegador, el diseño de esquemas ORM, el modelado de dominios empresariales, Kubernetes/Terraform o el diseño de interfaz.
