Compétence de conception back-end pour les CLI indépendantes du langage, les API REST, les services gRPC, les API de package et la structure des dépôts back-end. À utiliser lors de la création, de l'audit, de la refonte ou de l'étude des limites du backend : arborescences de commandes, contrats HTTP/gRPC, enveloppes d'erreurs, priorité de configuration, hooks d'opérabilité, limites de package, code mort, forme de package partagé et outils conviviaux pour les agents/scripts. Pas pour l'interface utilisateur du navigateur, la conception de schémas ORM, la modélisation de domaines métier, Kubernetes/Terraform ou la conception d'interfaces.
