Compétence de création d'artefacts statiques pour les documents HTML/CSS/JS autonomes : documents, feuilles, tableaux de bord, explicatifs, diapositives, outils et pages de destination. À utiliser lorsque l'utilisateur demande un livrable Web durable, ouvrable et partageable qu'il conservera ou remettra : un rapport, un tableau de bord, un diaporama, un tableau de données, une page. Dossier local d'abord, lien public temporaire via tunnel (localhost.run), publication durable facultative sur Surge, GitHub Pages ou Cloudflare. Pas pour les rendus rapides, les extraits de code en ligne ou les rayures jetables. Pas pour les frameworks SPA, les API backend, les applications de base de données ou l'interface utilisateur des produits de production.
