Abilità di creazione di artefatti statici per documenti HTML/CSS/JS autonomi: documenti, fogli, dashboard, spiegazioni, diapositive, strumenti e pagine di destinazione. Da utilizzare quando l'utente richiede un prodotto web durevole, apribile e condivisibile che conserverà o distribuirà: un report, un dashboard, una presentazione, una tabella dati, una pagina. Prima la cartella locale, collegamento pubblico temporaneo tramite tunnel (localhost.run), pubblicazione duratura opzionale su Surge, GitHub Pages o Cloudflare. Non per rendering rapidi, snippet in linea o graffi usa e getta. Non per framework SPA, API back-end, app di database o interfaccia utente di prodotti di produzione.
