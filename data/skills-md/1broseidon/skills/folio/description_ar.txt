مهارة حرفية ثابتة لمستندات HTML/CSS/JS القائمة بذاتها: المستندات والأوراق ولوحات المعلومات والشروحات والشرائح والأدوات والصفحات المقصودة. يُستخدم عندما يطلب المستخدم تسليم ويب متين وقابل للفتح والمشاركة، فسيحتفظ به أو يسلمه - تقرير، لوحة معلومات، مجموعة شرائح، جدول بيانات، صفحة. المجلد المحلي أولاً، رابط عام مؤقت عبر النفق (localhost.run)، نشر اختياري دائم إلى Surge أو GitHub Pages أو Cloudflare. ليس من أجل عرض المظهر السريع أو المقتطفات المضمنة أو الخدش. ليس لأطر عمل SPA أو واجهات برمجة التطبيقات الخلفية أو تطبيقات قواعد البيانات أو واجهة مستخدم منتج الإنتاج.
