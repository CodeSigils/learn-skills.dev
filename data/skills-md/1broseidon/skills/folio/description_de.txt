Fertigkeit zum Erstellen statischer Artefakte für eigenständige HTML/CSS/JS-Dokumente: Dokumente, Blätter, Dashboards, Erklärungen, Folien, Tools und Zielseiten. Verwenden Sie diese Option, wenn der Benutzer nach einem dauerhaften, öffenbaren und gemeinsam nutzbaren Webergebnis fragt, das er behält oder weitergibt – einen Bericht, ein Dashboard, eine Folienpräsentation, eine Datentabelle, eine Seite. Lokaler Ordner zuerst, temporärer öffentlicher Link über Tunnel (localhost.run), optional dauerhafte Veröffentlichung auf Surge, GitHub Pages oder Cloudflare. Nicht für schnelle Renderings, Inline-Snippets oder Wegwerf-Scratch. Nicht für SPA-Frameworks, Backend-APIs, Datenbank-Apps oder die Benutzeroberfläche von Produktionsprodukten.
