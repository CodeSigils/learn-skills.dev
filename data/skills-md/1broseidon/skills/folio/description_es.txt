Habilidad de creación de artefactos estáticos para documentos HTML/CSS/JS autónomos: documentos, hojas, paneles, explicadores, diapositivas, herramientas y páginas de destino. Utilícelo cuando el usuario solicite un producto web duradero, que se pueda abrir y compartir que conservará o entregará: un informe, un panel, una presentación de diapositivas, una tabla de datos, una página. Primero la carpeta local, enlace público temporal a través de un túnel (localhost.run), publicación duradera opcional en Surge, GitHub Pages o Cloudflare. No apto para renderizados de vista rápida, fragmentos en línea o borradores desechables. No para marcos SPA, API backend, aplicaciones de bases de datos o UI de productos de producción.
