Compétence de recherche pour Ketch : une CLI sans état rapide pour la recherche sur le Web, la recherche de code OSS, les documents de bibliothèque organisés, le scraping de pages et l'exploration de sites ; un serveur MCP en option existe pour les opérateurs qui le souhaitent, mais la CLI est l'interface principale. À utiliser lorsqu'une question nécessite des sources en direct : « rechercher X », « que disent les gens à propos de Y », « trouver des documents ou des exemples concrets pour Z », « parcourir/explorer ce site » — ou lors de l'installation ou de la configuration des backends Ketch. Achemine la recherche contre le code contre les documents contre le scrape contre l'exploration, conserve chaque récupération dans un budget de jetons, transforme les préfixes d'erreur en flux de contrôle et produit des synthèses citées. Pas pour la recherche dans la base de code locale, les dépôts privés ou les pages derrière l'authentification.
