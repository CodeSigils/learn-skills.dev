Habilidad de investigación para ketch: una CLI rápida y sin estado para búsqueda web, búsqueda de código OSS, documentos de biblioteca seleccionados, extracción de páginas y rastreo de sitios; Existe un servidor MCP opcional para los operadores que lo deseen, pero la CLI es la interfaz principal. Úselo cuando una pregunta necesite fuentes activas: 'investigar X', 'qué dice la gente sobre Y', 'encontrar documentos o ejemplos del mundo real para Z', 'rastrear/rastrear este sitio', o al instalar o configurar backends de ketch. Enruta la búsqueda, el código, los documentos, el raspado y el rastreo, mantiene cada recuperación dentro de un presupuesto simbólico, convierte los prefijos de error en un flujo de control y produce síntesis citadas. No para búsqueda de base de código local, repositorios privados o páginas detrás de la autenticación.
