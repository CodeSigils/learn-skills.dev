Навыки исследования для ketch — быстрого CLI без сохранения состояния для веб-поиска, поиска по коду OSS, курируемой библиотечной документации, очистки страниц и сканирования сайтов; Для операторов, которым он нужен, существует дополнительный сервер MCP, но CLI является основным интерфейсом. Используйте, когда вопрос требует живых источников: «исследуйте X», «что люди говорят о Y», «найдите документы или реальные примеры для Z», «очистите/сканируйте этот сайт» — или при установке или настройке серверных частей Ketch. Направляет поиск, код, документацию, очистку и сканирование, сохраняет каждую выборку в рамках бюджета токена, превращает префиксы ошибок в поток управления и производит цитируемый синтез. Не для поиска по локальной базе кода, частных репозиториев или страниц с аутентификацией.
