Crea una nuova abilità di Claude Code in modo casalingo o rifattorizza una grossa abilità in una snella SKILL.md + riferimenti/. Utilizzare quando si desidera "creare un'abilità", "scrivere una nuova abilità", "trasformare un prompt o un comando in un'abilità", "dividere un'abilità in riferimenti", "tagliare un SKILL.md" o richiamare /skills-create. La meta-abilità: un’abilità che costruisce abilità.
