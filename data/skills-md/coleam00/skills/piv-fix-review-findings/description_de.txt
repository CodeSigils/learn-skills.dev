Sortieren Sie die Ergebnisse der Codeüberprüfung (manuell oder KI), korrigieren Sie die von Ihnen ausgewählten Ergebnisse einzeln mit Tests, verschieben/protokollieren Sie den Rest und validieren Sie ihn – und wenn es sich bei der Arbeit um eine PR handelt, führen Sie einen Commit und Push durch, damit die PR die Korrekturen widerspiegelt. Wird verwendet, nachdem eine Überprüfung eine Liste von Problemen oder eine Überprüfungsdatei erstellt hat.
