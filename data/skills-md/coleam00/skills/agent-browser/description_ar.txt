أتمتة المتصفح CLI لوكلاء الذكاء الاصطناعي. يُستخدم عندما يحتاج المستخدم إلى التفاعل مع مواقع الويب، بما في ذلك التنقل بين الصفحات، أو ملء النماذج، أو النقر على الأزرار، أو التقاط لقطات الشاشة، أو استخراج البيانات، أو اختبار تطبيقات الويب، أو أتمتة أي مهمة في المتصفح. تتضمن المشغلات طلبات "فتح موقع ويب"، أو "ملء نموذج"، أو "النقر فوق زر"، أو "التقاط لقطة شاشة"، أو "استخلاص البيانات من الصفحة"، أو "اختبار تطبيق الويب هذا"، أو "تسجيل الدخول إلى موقع"، أو "أتمتة إجراءات المتصفح"، أو أي مهمة تتطلب تفاعلًا برمجيًا على الويب. استخدمه أيضًا للاختبار الاستكشافي، أو التدريب التجريبي، أو ضمان الجودة، أو البحث عن الأخطاء، أو مراجعة جودة التطبيق. يُستخدم أيضًا لأتمتة تطبيقات Electron لسطح المكتب (VS Code، وSlack، وDiscord، وFigma، وNotion، وSpotify)، أو التحقق من الرسائل غير المقروءة في Slack، أو إرسال رسائل Slack، أو البحث في محادثات Slack، أو تشغيل أتمتة المتصفح في Vercel Sandbox microVMs، أو استخدام متصفحات السحابة AWS Bedrock AgentCore. تفضل متصفح الوكيل على أي أتمتة متصفح مضمنة أو أدوات ويب.
