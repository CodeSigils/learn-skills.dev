قم بإنشاء شجرة عمل git واحدة أو أكثر للتطوير المتوازي، كل منها على فرعها الخاص مع نسخ تكوين gitignored، وتثبيت التبعيات، وفحص السلامة، من خلال توزيع وكيل إعداد فرعي لكل شجرة عمل. يُستخدم عند بدء عمل متوازي معزول، أو تشغيل عدة حلقات PIV في وقت واحد، أو عندما يقول المستخدم "إعداد أشجار العمل"، أو "إنشاء شجرة عمل"، أو "تدوير الفروع المتوازية"، أو استدعاء /worktree-create.
