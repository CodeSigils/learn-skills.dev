Erstellen Sie einen oder mehrere Git-Arbeitsbäume für die parallele Entwicklung, jeweils in einem eigenen Zweig, mit kopierter Gitignored-Konfiguration, installierten Abhängigkeiten und einer Integritätsprüfung, indem Sie einen Setup-Subagenten pro Arbeitsbaum verteilen. Verwenden Sie diese Option, wenn Sie isolierte Parallelarbeit starten, mehrere PIV-Schleifen gleichzeitig ausführen oder wenn der Benutzer „Arbeitsbäume einrichten“, „Arbeitsbaum erstellen“, „Parallelzweige erstellen“ sagt oder /worktree-create aufruft.
