Создайте одно или несколько рабочих деревьев git для параллельной разработки, каждое в отдельной ветке с скопированной конфигурацией gitignored, установленными зависимостями и проверкой работоспособности, распределяя субагент установки по каждому рабочему дереву. Используйте при запуске изолированной параллельной работы, одновременном запуске нескольких циклов PIV или когда пользователь говорит «настроить рабочие деревья», «создать рабочее дерево», «развернуть параллельные ветки» или вызывает /worktree-create.
