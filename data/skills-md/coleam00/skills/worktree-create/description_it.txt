Crea uno o più alberi di lavoro git per lo sviluppo parallelo, ciascuno sul proprio ramo con la configurazione gitignored copiata, le dipendenze installate e un controllo di integrità, distribuendo un sottoagente di installazione per albero di lavoro. Da utilizzare quando si avvia un lavoro parallelo isolato, si eseguono più cicli PIV contemporaneamente o quando l'utente dice "imposta alberi di lavoro", "crea un albero di lavoro", "avvia rami paralleli" o invoca /worktree-create.
