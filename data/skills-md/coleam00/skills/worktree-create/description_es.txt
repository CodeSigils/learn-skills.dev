Cree uno o más árboles de trabajo de git para el desarrollo paralelo, cada uno en su propia rama con la configuración ignorada de git copiada, las dependencias instaladas y una verificación de estado, distribuyendo un subagente de configuración por árbol de trabajo. Úselo al iniciar un trabajo paralelo aislado, ejecutar varios bucles PIV a la vez o cuando el usuario diga "configurar árboles de trabajo", "crear un árbol de trabajo", "activar ramas paralelas" o invoca /worktree-create.
