Zerlegt ein PRD in wohlgeformte, ingenieurbereite Tickets – Jira-Vorgänge oder GitHub-Vorgänge. Wird verwendet, nachdem ein PRD existiert, um seine Phasen und User Stories in ein strukturiertes Backlog umzuwandeln. Funktioniert für eine neue Codebasis (MVP-Bereich) oder eine vorhandene (epischer Bereich).
