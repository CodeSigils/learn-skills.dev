Nehmen Sie ein PRD und bauen Sie eine dunkle Fabrik darum auf – ein Repository, das Arbeit als Problem aufnimmt und validierten Code ausliefert, ohne dass jemand an der Tastatur sitzt – eine Komponente nach der anderen, in das eigentliche Repo des Benutzers. Deckt die fünf Komponenten in der Konstruktionsreihenfolge ab – die Führungsschicht, das Validierungskabel, das Workflow-gesteuerte Repo, die Bereitstellung und den Auslöser, der es autonom macht – und ist unabhängig davon, welcher Coding-Agent darunter ausgeführt wird (Claude Code, Codex, Archon, das Agent SDK, Cline, Goose, Amp, Pi). Es kodiert den KI-Kodierungsprozess, den der Benutzer bereits ausführt, anstatt ihn zu ersetzen. Erfordert ein PRD als Eingabe und schreibt bewusst keins. Verwenden Sie diese Option, wenn der Benutzer eine dunkle Fabrik, ein autonomes oder selbstfahrendes Repository, eine Softwarefabrik, einen Agenten, der seinen eigenen Code versendet, eine unbeaufsichtigte oder über Nacht laufende Codierungsschleife aufbauen möchte oder fragt, wie er Level 4 oder Level 5 der KI-Codierungsautonomie erreichen kann; und wenn sie Dark Factory, Lights-Out-Coding, autonome PRs oder ein Repo erwähnen, das sich selbst erhält.
