Configure las reglas globales de su proyecto, una raíz CLAUDE.md sencilla y bien estructurada (más un inicio .claude/), siguiendo la metodología del curso. Greenfield: pase su PRD y/o ruta de especificación de arquitectura y derivará reglas de sus decisiones de ingeniería (un PRD por sí solo es contexto del producto). Brownfield: déjelo en blanco para derivarlo de su código base preparado (ejecute primero /prime-codebase) o pase un documento de análisis de código base para un repositorio grande. Úselo al inicializar o volver a derivar las reglas de la capa AI, incorporar una base de código o reemplazar una salida /init genérica. El reemplazo personalizable de /init.
