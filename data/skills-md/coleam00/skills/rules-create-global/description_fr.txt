Mettez en place les règles globales de votre projet, un racine CLAUDE.md allégé et bien structuré (plus un starter .claude/), en suivant la méthodologie du cours. Greenfield : passez votre chemin PRD et/ou spécification d'architecture et il dérive des règles de vos décisions d'ingénierie (un PRD à lui seul constitue un contexte de produit). Brownfield : laissez-le vide pour dériver de votre base de code amorcée (exécutez d'abord /prime-codebase) ou transmettez un document d'analyse de base de code pour un dépôt volumineux. À utiliser lors de l'initialisation ou de la redérivation des règles de la couche AI, de l'intégration d'une base de code ou du remplacement d'une sortie générique /init.
