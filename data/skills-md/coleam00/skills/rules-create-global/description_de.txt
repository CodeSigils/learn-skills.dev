Richten Sie die globalen Regeln Ihres Projekts ein, eine schlanke und gut strukturierte Stammdatei CLAUDE.md (plus eine Starterdatei .claude/), und folgen Sie dabei der Kursmethodik. Greenfield: Übergeben Sie Ihren PRD- und/oder Architekturspezifikationspfad und es werden Regeln aus Ihren technischen Entscheidungen abgeleitet (ein PRD allein ist der Produktkontext). Brownfield: Lassen Sie es leer, um von Ihrer vorbereiteten Codebasis abzuleiten (führen Sie zuerst /prime-codebase aus) oder übergeben Sie ein Codebasis-Analysedokument für ein großes Repo. Verwenden Sie diese Option, wenn Sie die Regeln der KI-Ebene initialisieren oder neu ableiten, eine Codebasis integrieren oder eine generische /init-Ausgabe ersetzen. Der anpassbare Ersatz für /init.
