Créez un crochet Claude Code fonctionnel à partir d'une description en anglais simple de ce qu'il doit garantir ou faire. Vous décrivez le comportement ("ne laissez jamais l'agent modifier mes migrations", "ne vous arrêtez pas tant que les tests ne sont pas réussis", "enregistrez chaque commande"); cette compétence sélectionne le bon événement du cycle de vie, écrit le script hook et le connecte à .claude/settings.json. À utiliser lorsque vous souhaitez une garantie déterministe ou une automatisation dans votre couche AI ​​et que vous ne souhaitez pas écrire le crochet à la main. Le méta-outil pour la primitive hooks.
