Erstellen Sie einen funktionierenden Claude-Code-Hook anhand einer einfachen englischen Beschreibung dessen, was er garantieren oder tun soll. Sie beschreiben das Verhalten („Lassen Sie den Agenten niemals meine Migrationen bearbeiten“, „Hören Sie nicht auf, bis die Tests bestanden sind“, „Protokollieren Sie jeden Befehl“); Dieser Skill wählt das richtige Lebenszyklusereignis aus, schreibt das Hook-Skript und verbindet es mit .claude/settings.json. Verwenden Sie diese Option, wenn Sie eine deterministische Garantie oder Automatisierung in Ihrer KI-Ebene wünschen und den Hook nicht von Hand schreiben möchten. Das Meta-Tool für das Hooks-Grundelement.
