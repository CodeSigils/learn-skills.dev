Cree un gancho funcional de Claude Code a partir de una descripción en inglés sencillo de lo que debería garantizar o hacer. Usted describe el comportamiento ("nunca permita que el agente edite mis migraciones", "no se detenga hasta que pasen las pruebas", "registre cada comando"); esta habilidad selecciona el evento del ciclo de vida correcto, escribe el script de enlace y lo conecta a .claude/settings.json. Úselo cuando desee una garantía determinista o automatización en su capa de IA y no desee escribir el gancho a mano. La metaherramienta para los ganchos primitivos.
