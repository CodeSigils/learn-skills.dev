Überprüfen Sie, ob eine veröffentlichte Archon-Binärdatei über einen bestimmten Installationspfad durchgängig funktioniert.
Verwendung bei: Schneiden einer neuen Version, Reproduzieren eines Benutzerfehlerberichts für die veröffentlichte Version
Version oder Überprüfung, ob eine Hotfix-Binärdatei nach einem Re-Tag tatsächlich funktioniert.
Auslöser: „Release testen“, „0.3.1 über Brew testen“, „Curl-Installation überprüfen“,
          „Smoke Test the Binary“, „Hat die Release-Binärdatei funktioniert“,
          „Run /test-release“, „Release überprüfen“.
NICHT für: Testen von Entwicklungsarbeiten (verwenden Sie den Bun-Link direkt), Testen unveröffentlichter Änderungen
(zuerst lokal über scripts/build-binaries.sh erstellen) oder die vollständige Version ausführen
Validierungssuite (Bun Run Validierung ist separat).
