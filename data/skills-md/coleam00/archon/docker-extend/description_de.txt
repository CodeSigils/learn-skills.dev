Verwendung, wenn: Der Benutzer möchte Docker mit benutzerdefinierten Tools erweitern, die Docker-Umgebung personalisieren,
oder benutzerspezifische Docker-Anpassungen einrichten.
Auslöser: „Docker erweitern“, „Docker-extend“, „Tools zum Docker hinzufügen“, „Docker anpassen“,
          „Meine Tools zum Container hinzufügen“, „Docker-Setup personalisieren“, „Docker-Benutzer-Setup“,
          „Tools im Docker installieren“.
Funktioniert: Richtet Dockerfile.user und docker-compose.override.yml interaktiv ein, damit Benutzer dies tun können
Fügen Sie Ihrer Docker-Umgebung persönliche Tools hinzu, ohne dass sich dies auf die Betreuerdateien auswirkt
Übertragen einer benutzerspezifischen Konfiguration an Git.
