Cree una versión desde la rama de desarrollo. Genera entradas de registro de cambios a partir de confirmaciones,
actualiza la versión y crea un PR para main.

DESENCADENADORES: use esta habilidad cuando el usuario diga:
- "/release" - crea una versión de parche (predeterminado)
- "/release minor" - crea una versión menor
- "/release major" - crea una versión principal
- "hacer un lanzamiento", "cortar un lanzamiento", "enviarlo", "liberar al principal"
