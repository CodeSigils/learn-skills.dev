Создайте релиз из ветки разработки. Генерирует записи журнала изменений из коммитов,
поднимает версию и создает PR для основной.

ТРИГГЕРЫ. Используйте этот навык, когда пользователь говорит:
- "/release" - создать выпуск патча (по умолчанию)
- "/release минор" - создать минорный релиз
- "/release major" - создать основной выпуск
- «выпустить релиз», «вырезать релиз», «отправить его», «выпустить в основной»
