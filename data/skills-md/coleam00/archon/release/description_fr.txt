Créez une version à partir de la branche de développement. Génère des entrées de journal des modifications à partir des commits,
Bumps version et crée un PR vers main.

DÉCLENCHEURS - Utilisez cette compétence lorsque l'utilisateur dit :
- "/release" - crée une version de patch (par défaut)
- "/release mineur" - crée une version mineure
- "/release major" - crée une version majeure
- "créer une version", "couper une version", "l'expédier", "version principale"
