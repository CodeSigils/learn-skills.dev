Erstellen Sie eine Veröffentlichung aus dem Entwicklungszweig. Erzeugt Changelog-Einträge aus Commits,
Bumps-Version und erstellt eine PR für main.

AUSLÖSER – Verwenden Sie diesen Skill, wenn der Benutzer sagt:
- „/release“ – eine Patch-Version erstellen (Standard)
- „/release Minor“ – eine Nebenversion erstellen
- „/release main“ – eine Hauptversion erstellen
- „Eine Veröffentlichung erstellen“, „Eine Veröffentlichung ausschneiden“, „Versenden“, „Zur Hauptversion freigeben“
