Archon 專案的主要開發工作流程（遠端編碼代理）。
在處理 Archon 程式碼時，請使用此技能而不是任何 PRP 技能。
根據使用者想要做的事情路由到 10 本專門的食譜：

研究 —「協調器如何運作？」、「會話狀態在哪裡定義？」、
              “追蹤工作流程執行流程”、“IWorkflowStore是什麼？”
調查 —「我們應該使用 Drizzle 還是 Prisma？」、「新增 WebSocket 的最佳方式是什麼？」、
              “我們可以遷移到 Turso 嗎？”、“其他項目如何處理速率限制？”
PRD —“為深色模式編寫 PRD”，“指定通知功能”，
              “webhook 重試的產品要求”
PLAN —「計劃身份驗證重構」、「設計快取層」、
              “為 #42 制定實施計劃”
實施 —“實施計劃”，“執行 .claude/archon/plans/auth.plan.md”，
              “根據計劃建立功能”，“編寫程式碼”
審查 —“審查 PR #123”、“審查我的更改”、“代碼審查差異”
DEBUG —“調試失敗的測試”，“為什麼串流媒體損壞？”，
              《超時問題根本原因分析》
COMMIT —“提交這些變更”、“提交身份驗證重構”
PR —“建立 PR”、“為此分支開啟拉取要求”
ISSUE —「向 gh 回報此問題」、「建立 gh 問題」、「將其記錄在 github 中」、
              “為此提交錯誤”、“建立功能請求”

此技能會觸發任何開發任務：研究、調查、
規劃、建置、審查、調試、提交或交付程式碼。
不適用於：在工作樹中執行 Archon CLI 工作流程（改為使用 /archon）。
