Archon 프로젝트(원격 코딩 에이전트)의 기본 개발 워크플로입니다.
Archon 코드 작업 시 PRP 스킬 대신 이 스킬을 사용하세요.
사용자가 수행하려는 작업을 기반으로 10개의 전문 요리책으로 라우팅합니다.

연구 — "오케스트레이터는 어떻게 작동합니까?", "세션 상태는 어디에 정의되어 있습니까?",
              "워크플로 실행 흐름 추적", "IWorkflowStore가 무엇인가요?"
조사 — "Drizzle을 사용해야 할까요, 아니면 Prisma를 사용해야 할까요?", "WebSocket을 추가하는 가장 좋은 방법은 무엇입니까?",
              "Turso로 마이그레이션할 수 있나요?", "다른 프로젝트에서는 속도 제한을 어떻게 처리하나요?"
PRD — "다크 모드용 PRD 작성", "알림 기능 사양",
              "웹훅 재시도를 위한 제품 요구 사항"
PLAN — "인증 리팩터링 계획", "캐싱 계층 설계",
              "#42에 대한 구현 계획을 작성하세요"
구현 — "계획 구현", ".claude/archon/plans/auth.plan.md 실행",
              "계획에 따라 기능을 구축하세요", "이것을 코딩하세요"
REVIEW — "PR #123 검토", "변경 사항 검토", "차이점 코드 검토"
DEBUG — "실패한 테스트 디버깅", "스트리밍이 중단되는 이유는 무엇입니까?",
              "타임아웃 문제의 근본 원인 분석"
COMMIT — "이 변경 사항 커밋", "인증 리팩터링 커밋"
PR — "PR 생성", "이 브랜치에 대한 풀 요청 열기"
문제 — "gh에 보고", "gh 문제 생성", "github에 기록",
              "이것에 대한 버그를 제출하세요", "기능 요청 만들기"

이 기술은 연구, 조사, 조사 등 모든 개발 작업에서 실행됩니다.
코드 계획, 구축, 검토, 디버깅, 커밋 또는 배송.
해당되지 않는 경우: 작업 트리에서 Archon CLI 워크플로 실행(대신 /archon 사용)
