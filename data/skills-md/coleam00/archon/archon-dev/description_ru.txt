ОСНОВНОЙ рабочий процесс разработки проекта Archon (агент удаленного кодирования).
Используйте этот навык вместо любых навыков PRP при работе над кодом Архонта.
Маршруты к 10 специализированным кулинарным книгам в зависимости от того, что пытается сделать пользователь:

ИССЛЕДОВАНИЕ — «как работает оркестратор?», «где определяется состояние сеанса?»,
              «отслеживать ход выполнения рабочего процесса», «что такое IWorkflowStore?»
ИССЛЕДОВАНИЕ — «должны ли мы использовать Drizzle или Prisma?», «какой лучший способ добавить WebSockets?»,
              «Можем ли мы перейти на Turso?», «Как другие проекты справляются с ограничением скорости?»
PRD — «написать PRD для темного режима», «указать функцию уведомлений»,
              «Требования к продукту для повторной попытки веб-перехватчика»
ПЛАН — «спланировать рефакторинг аутентификации», «спроектировать уровень кэширования»,
              «создай план реализации №42»
IMPLEMENT — «реализовать план», «выполнить .claude/archon/plans/auth.plan.md»,
              «построить функцию по плану», «закодировать это»
ОБЗОР — «проверка PR № 123», «проверка моих изменений», «проверка кода, разница»
DEBUG — «отладка неудачного теста», «почему потоковая передача не работает?»,
              «Анализ первопричин проблемы тайм-аута»
COMMIT — «зафиксировать эти изменения», «зафиксировать рефакторинг аутентификации»
PR — «создать PR», «открыть пул-реквест для этой ветки»
ПРОБЛЕМА — «сообщить об этом gh», «создать проблему gh», «зарегистрировать ее в github»,
              «сообщить об ошибке», «создать запрос на добавление функции»

Этот навык активируется при выполнении ЛЮБОЙ задачи развития: исследование, расследование,
планирование, создание, проверка, отладка, фиксация или отправка кода.
НЕ для: запуска рабочих процессов Archon CLI в рабочих деревьях (вместо этого используйте /archon).
