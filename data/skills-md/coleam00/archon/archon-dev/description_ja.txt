Archon プロジェクトの PRIMARY 開発ワークフロー (remote-coding-agent)。
Archon コードで作業する場合は、PRP スキルの代わりにこのスキルを使用してください。
ユーザーが行おうとしていることに基づいて、10 の特殊なクックブックにルーティングします。

研究 — 「オーケストレーターはどのように動作するのですか?」、「セッション状態はどこで定義されますか?」、
              「ワークフローの実行フローをトレースする」「IWorkflowStore とは何ですか?」
調査 — 「Drizzle または Prisma を使用するべきですか?」、「WebSocket を追加する最良の方法は何ですか?」、
              「Turso に移行できますか?」、「他のプロジェクトはレート制限をどのように処理しますか?」
PRD — 「ダーク モード用の PRD を作成する」、「通知機能を仕様化する」、
              「Webhook 再試行の製品要件」
PLAN — 「認証リファクタリングを計画する」、「キャッシュ層を設計する」、
              「#42の実施計画を作成する」
IMPLEMENT — "計画を実装する"、".claude/archon/plans/auth.plan.md を実行"、
              「計画に基づいて機能を構築する」、「コードを作成する」
REVIEW — 「PR #123 をレビュー」、「変更をレビュー」、「差分をコードレビュー」
DEBUG — "失敗したテストをデバッグします"、"ストリーミングが壊れているのはなぜですか?"、
              「タイムアウト問題の根本原因分析」
COMMIT — 「これらの変更をコミット」、「認証リファクタリングをコミット」
PR — 「PR を作成する」、「このブランチのプル リクエストを開く」
問題 — 「これを gh に報告する」、「gh の問題を作成する」、「github に記録する」、
              「これについてバグを報告する」、「機能リクエストを作成する」

このスキルは、調査、調査、調査など、あらゆる開発タスクでトリガーされます。
コードの計画、構築、レビュー、デバッグ、コミット、または出荷。
対象外: ワークツリーでの Archon CLI ワークフローの実行 (代わりに /archon を使用)。
