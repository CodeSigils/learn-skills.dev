通过启动 Archon 来复制和验证 GitHub 问题，分析问题，
并使用浏览器自动化系统地测试所有描述的症状。
使用时机：用户想要重现错误、验证 GitHub 问题、确认报告的问题、
或在修复之前调查问题是否真实。
触发器：“复制问题”、“重现问题”、“验证问题”、“确认错误”、
          “测试问题”、“你能重现吗”、“尝试复制”、“验证错误”。
能力：检查 main、拉取最新版本、启动 Archon、阅读 GitHub 问题、
然后使用代理浏览器系统地测试每个症状并生成结果报告。
不适用于：修复问题（使用 /archon 或 /exp-piv-loop:fix-issue）、一般 UI 测试（使用 /validate-ui）。
