透過啟動 Archon 來複製和驗證 GitHub 問題，分析問題，
並使用瀏覽器自動化系統地測試所有描述的症狀。
使用時機：使用者想要重現錯誤、驗證 GitHub 問題、確認報告的問題、
或在修復之前調查問題是否真實。
觸發器：「複製問題」、「重現問題」、「驗證問題」、「確認錯誤」、
          「測試問題」、「你能重現嗎」、「嘗試複製」、「驗證錯誤」。
能力：檢查 main、拉取最新版本、啟動 Archon、閱讀 GitHub 問題、
然後使用代理瀏覽器系統地測試每個症狀並產生結果報告。
不適用於：修復問題（使用 /archon 或 /exp-piv-loop:fix-issue）、一般 UI 測試（使用 /validate-ui）。
