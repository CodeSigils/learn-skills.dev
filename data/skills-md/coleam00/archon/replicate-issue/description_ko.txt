Archon을 가동하고 문제를 분석하여 GitHub 문제를 복제하고 검증합니다.
브라우저 자동화를 사용하여 설명된 모든 증상을 체계적으로 테스트합니다.
사용 시기: 사용자가 버그 재현, GitHub 문제 확인, 보고된 문제 확인,
또는 수정 작업을 하기 전에 문제가 실제인지 조사해 보세요.
트리거: "문제 복제", "문제 재현", "문제 확인", "버그 확인",
          "문제 테스트", "재현 가능", "복제 시도", "버그 확인".
기능: 메인 확인, 최신 가져오기, Archon 시작, GitHub 문제 읽기,
그런 다음 에이전트 브라우저를 사용하여 모든 증상을 체계적으로 테스트하고 결과 보고서를 생성합니다.
해당 사항 없음: 문제 해결(/archon 또는 /exp-piv-loop:fix-issue 사용), 일반 UI 테스트(/validate-ui 사용)
