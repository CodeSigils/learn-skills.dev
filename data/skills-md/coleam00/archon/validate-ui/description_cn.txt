使用浏览器自动化和代码库审查对 Archon Web UI 进行全面的端到端验证。
使用时机：用户想要验证、测试或审核 Archon Web 界面，查找 UI/UX 错误，
测试工作流管理、验证并行代理编排或运行全面的基于浏览器的 E2E 测试。
触发器：“验证 ui”、“测试 ui”、“e2e 测试”、“浏览器测试”、“验证 archon”、
          “测试 archon ui”、“ui 审核”、“ux 审查”、“综合测试”、“验证一切”。
功能：启动 Archon，通过代理浏览器 CLI 运行详尽的浏览器自动化测试，
执行代码库审查，并生成详细的错误/UX 报告。
不适用于：单元测试（使用 `bun test`）、仅 CLI 验证（使用 /validation:validate-simple）。
