使用瀏覽器自動化和程式碼庫審查對 Archon Web UI 進行全面的端到端驗證。
使用時機：使用者想要驗證、測試或審核 Archon Web 介面，尋找 UI/UX 錯誤，
測試工作流程管理、驗證並行代理程式編排或執行全面的基於瀏覽器的 E2E 測試。
觸發器：「驗證 ui」、「測試 ui」、「e2e 測試」、「瀏覽器測試」、「驗證 archon」、
          「測試 archon ui」、「ui 審核」、「ux 審查」、「綜合測試」、「驗證一切」。
功能：啟動 Archon，透過代理瀏覽器 CLI 運行詳盡的瀏覽器自動化測試，
執行程式碼庫審查，並產生詳細的錯誤/UX 報告。
不適用於：單元測試（使用 `bun test`）、僅 CLI 驗證（使用 /validation:validate-simple）。
