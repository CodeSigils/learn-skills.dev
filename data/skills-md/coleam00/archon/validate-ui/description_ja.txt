ブラウザの自動化とコードベースのレビューを使用した Archon Web UI の包括的なエンドツーエンドの検証。
次の場合に使用します: ユーザーが Archon Web インターフェイスを検証、テスト、または監査したい場合、UI/UX のバグを見つけたい場合、
ワークフロー管理をテストしたり、並列エージェント オーケストレーションを検証したり、ブラウザベースの包括的な E2E テストを実行したりできます。
トリガー: "ui の検証"、"ui のテスト"、"e2e テスト"、"ブラウザ テスト"、"アーコンの検証"、
          「テスト アルコン ui」、「ui 監査」、「ux レビュー」、「総合テスト」、「すべてを検証」。
機能: Archon を起動し、エージェント ブラウザ CLI 経由で徹底的なブラウザ自動化テストを実行します。
コードベースのレビューを実行し、詳細なバグ/UX レポートを作成します。
対象外: 単体テスト (「bun test」を使用)、CLI のみの検証 (/validation:validate-simple を使用)。
