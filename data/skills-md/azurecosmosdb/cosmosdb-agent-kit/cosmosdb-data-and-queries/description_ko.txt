Azure Cosmos DB 데이터 디자인 및 쿼리: 문서 모델링(포함 대 참조, 비정규화, 스키마 버전 관리, 2MB 제한, ID 제약 조건), 파티션 키 디자인(높은 카디널리티, 핫스팟 방지, 계층적, 합성 키), 인덱싱 정책(합성, 범위 대 해시, 사용하지 않는 경로 제외, 공간), 쿼리 최적화(포인트 읽기, 파티션 간 스캔 방지, 예측, 페이지 매기기, 매개 변수화, 필터 순서) 및 데이터 액세스 패턴 (변경 피드 구체화된 뷰, 순위, 서비스 계층)
사용 대상: 파티션 키 선택, 참조 대 내장, 읽기를 위한 비정규화, ORDER BY를 위한 복합 인덱스, 경로를 제외하여 쓰기 RU 잘라내기, ID 및 파티션 키로 읽기 지점, 연속 토큰으로 페이지 매김, 파티션 간 쿼리 방지, 구체화된 뷰.
다음에는 사용하지 마십시오: SDK 클라이언트 코드(cosmosdb-sdk 사용) 처리량, 전역 배포, 모니터링, 보안(cosmosdb 작업 사용) 벡터 또는 전체 텍스트 검색 및 LangChain/LangGraph 에이전트(cosmosdb-ai-and-search 사용)
