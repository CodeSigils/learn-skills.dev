Проектирование данных и запросы Azure Cosmo DB: моделирование документов (встраивание или ссылка, денормализация, управление версиями схемы, ограничение в 2 МБ, ограничения идентификаторов), разработка ключей разделов (высокая мощность, избежание горячих точек, иерархические, синтетические ключи), политика индексирования (составная, диапазон против хэша, исключение неиспользуемых путей, пространственная), оптимизация запросов (точечное чтение, предотвращение сканирования между разделами, проекции, нумерация страниц, параметризация, порядок фильтрации) и шаблоны доступа к данным (материализованные представления каналов изменений, ранжирование, уровень обслуживания).
ИСПОЛЬЗОВАНИЕ ДЛЯ: выбор ключа раздела, встраивание или ссылка, денормализация для чтения, составной индекс для ORDER BY, сокращение записи RU путем исключения путей, чтение точки по идентификатору и ключу раздела, разбиение на страницы с токенами продолжения, избежание запросов между разделами, материализованные представления.
НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: клиентского кода SDK (используйте Cosmosdb-sdk); пропускная способность, глобальное распределение, мониторинг, безопасность (использование CosmosDB-операций); векторный или полнотекстовый поиск и агенты LangChain/LangGraph (используйте cosmosdb-ai-and-search).
