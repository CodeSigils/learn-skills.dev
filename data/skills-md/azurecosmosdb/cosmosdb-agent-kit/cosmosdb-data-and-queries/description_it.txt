Progettazione e query dei dati di Azure Cosmos DB: modellazione di documenti (incorporamento o riferimento, denormalizzazione, controllo delle versioni dello schema, limite di 2 MB, vincoli ID), progettazione della chiave di partizione (cardinalità elevata, evita hotspot, gerarchia, chiavi sintetiche), criteri di indicizzazione (composito, intervallo rispetto a hash, esclusione di percorsi inutilizzati, spaziale), ottimizzazione delle query (letture di punti, evitare scansioni tra partizioni, proiezioni, impaginazione, parametrizzazione, ordine di filtro) e modelli di accesso ai dati (viste materializzate di modifica-feed, classificazione, livello di servizio).
UTILIZZARE PER: scegliere la chiave di partizione, incorporare o fare riferimento, denormalizzare per letture, indice composito per ORDER BY, tagliare RU di scrittura escludendo percorsi, puntare la lettura per ID e chiave di partizione, impaginare con token di continuazione, evitare query su partizioni incrociate, viste materializzate.
NON UTILIZZARE PER: codice client SDK (utilizzare cosmosdb-sdk); throughput, distribuzione globale, monitoraggio, sicurezza (usare operazioni cosmosdb); ricerca vettoriale o full-text e agenti LangChain/LangGraph (utilizzare cosmosdb-ai-and-search).
