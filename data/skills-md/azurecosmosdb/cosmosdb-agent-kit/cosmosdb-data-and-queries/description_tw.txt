Azure Cosmos DB 資料設計與查詢：文件建模（嵌入與引用、非規範化、架構版本控制、2MB 限制、id 約束）、分區鍵設計（高基數、避免熱點、分層、合成鍵）、索引策略（複合、範圍與雜湊、排除未使用的路徑、空間）、查詢最佳化（點讀取、避免跨區掃描、複合、範圍與篩選、排除未使用的路徑、空間）、查詢最佳化（點讀取、避免跨區掃描、順序、分頁篩選、篩選順序、數位）。
用途：選擇分區鍵、嵌入與引用、讀取的反規範化、ORDER BY 的複合索引、透過排除路徑來剪切寫入 RU、透過 id 和分區鍵讀取點、使用連續標記進行分頁、避免跨分區查詢、物化視圖。
請勿用於：SDK 用戶端程式碼（使用 cosmosdb-sdk）；吞吐量、全域分佈、監控、安全性（使用 cosmosdb-operations）；向量或全文搜尋和 LangChain/LangGraph 代理程式（使用 cosmosdb-ai-and-search）。
