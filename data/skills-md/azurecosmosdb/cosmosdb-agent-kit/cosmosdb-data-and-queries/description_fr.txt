Conception et requêtes de données Azure Cosmos DB : modélisation de documents (intégration ou référence, dénormalisation, gestion des versions de schéma, limite de 2 Mo, contraintes d'identification), conception de clés de partition (cardinalité élevée, éviter les points chauds, clés hiérarchiques et synthétiques), stratégie d'indexation (composite, plage ou hachage, exclure les chemins inutilisés, spatial), optimisation des requêtes (lectures de points, éviter les analyses entre partitions, projections, pagination, paramétrage, ordre de filtrage) et modèles d'accès aux données (vues matérialisées de flux de modifications, classement, couche de service).
UTILISER POUR : choisir la clé de partition, intégrer ou référence, dénormaliser pour les lectures, index composite pour ORDER BY, couper l'écriture RU en excluant les chemins, pointer lu par identifiant et clé de partition, paginer avec des jetons de continuation, éviter les requêtes entre partitions, les vues matérialisées.
NE PAS UTILISER POUR : le code client du SDK (utilisez cosmosdb-sdk) ; débit, distribution mondiale, surveillance, sécurité (utiliser les opérations cosmosdb) ; recherche vectorielle ou en texte intégral et agents LangChain/LangGraph (utilisez cosmosdb-ai-and-search).
