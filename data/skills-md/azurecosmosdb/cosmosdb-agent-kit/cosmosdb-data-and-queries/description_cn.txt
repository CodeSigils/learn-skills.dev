Azure Cosmos DB 数据设计和查询：文档建模（嵌入与引用、非规范化、架构版本控制、2MB 限制、id 约束）、分区键设计（高基数、避免热点、分层、合成键）、索引策略（复合、范围与哈希、排除未使用的路径、空间）、查询优化（点读取、避免跨分区扫描、投影、分页、参数化、筛选顺序）和数据访问模式（更改源具体化）浏览量、排名、服务层）。
用途：选择分区键、嵌入与引用、读取的反规范化、ORDER BY 的复合索引、通过排除路径来剪切写入 RU、通过 id 和分区键读取点、使用连续标记进行分页、避免跨分区查询、物化视图。
请勿用于：SDK 客户端代码（使用 cosmosdb-sdk）；吞吐量、全局分布、监控、安全性（使用 cosmosdb-operations）；矢量或全文搜索和 LangChain/LangGraph 代理（使用 cosmosdb-ai-and-search）。
