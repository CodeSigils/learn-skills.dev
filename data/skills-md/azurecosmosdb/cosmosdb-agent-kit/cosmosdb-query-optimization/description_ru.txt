Рекомендации по оптимизации запросов Azure Cosmo DB: чтение точек, прогнозы,
нумерация страниц с токенами продолжения, параметризованные запросы, упорядочивание фильтров,
предотвращение межраздельных запросов и аналитическое обнаружение запросов.
ИСПОЛЬЗОВАНИЕ ДЛЯ: запросов Cosmos DB, чтения точек и запросов, проекций SELECT,
токены продолжения, параметризованные запросы, избегать перекрестного разделения, избегать сканирования,
селективность фильтра, литерал TOP, ORDER BY, последний по временной метке, обнаружение OLAP,
агрегатные запросы, ключевое слово DISTINCT.
НЕ ИСПОЛЬЗОВАТЬ ДЛЯ: индексирования (используйте CosmosDB-Indexing), моделирования данных (используйте CosmosDB-Data-Modeling),
Клиентский код SDK (используйте cosmosdb-sdk).
