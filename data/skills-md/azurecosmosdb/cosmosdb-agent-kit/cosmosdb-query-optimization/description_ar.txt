أفضل ممارسات تحسين استعلام Azure Cosmos DB: قراءة النقاط، والإسقاطات،
ترقيم الصفحات مع الرموز المميزة للاستمرار، والاستعلامات ذات المعلمات، وترتيب عوامل التصفية،
تجنب الاستعلام عبر التقسيم، والكشف عن الاستعلام التحليلي.
الاستخدام لـ: استعلامات Cosmos DB، وقراءة النقاط مقابل الاستعلامات، وإسقاطات SELECT،
رموز الاستمرارية، والاستعلامات ذات المعلمات، وتجنب التقسيم المتقاطع، وتجنب عمليات الفحص،
انتقائية المرشح، TOP الحرفي، ORDER BY، الأحدث حسب الطابع الزمني، اكتشاف OLAP،
الاستعلامات المجمعة، الكلمة الرئيسية DISTINCT.
لا تستخدمه من أجل: الفهرسة (استخدم فهرسة cosmosdb)، ونمذجة البيانات (استخدم نمذجة بيانات cosmosdb)،
رمز عميل SDK (استخدم cosmosdb-sdk).
