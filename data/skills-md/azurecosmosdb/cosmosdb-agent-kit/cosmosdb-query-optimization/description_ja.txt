Azure Cosmos DB クエリ最適化のベスト プラクティス: ポイント読み取り、投影、
継続トークンによるページネーション、パラメータ化されたクエリ、フィルターの順序付け、
パーティション間のクエリの回避と分析クエリの検出。
用途: Cosmos DB クエリ、ポイント読み取りとクエリ、SELECT プロジェクション、
継続トークン、パラメータ化されたクエリ、クロスパーティションの回避、スキャンの回避、
フィルター選択性、TOP リテラル、ORDER BY、タイムスタンプによる最新、OLAP 検出、
集計クエリ、DISTINCT キーワード。
以下には使用しないでください: インデックス作成 (cosmosdb-indexing を使用)、データ モデリング (cosmosdb-data-modeling を使用)、
SDK クライアント コード (cosmosdb-sdk を使用)。
