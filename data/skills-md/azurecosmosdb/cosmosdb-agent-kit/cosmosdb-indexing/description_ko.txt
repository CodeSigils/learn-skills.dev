Azure Cosmos DB 인덱싱 전략 모범 사례: 사용되지 않는 경로 제외,
ORDER BY용 복합 인덱스, 공간 인덱스, 인덱스 유형, 경로 구문,
및 인덱싱 모드(일관적 vs 게으른).
사용 대상: Cosmos DB 인덱싱 정책, 제외 경로, 복합 인덱스, 공간 인덱스,
인덱스 경로 구문 /? /* /[], 범위 대 해시 인덱스, 게으른 인덱싱 대 일관된 인덱싱,
인덱스 방향, 쓰기 오버헤드 감소.
사용하지 마세요: 쿼리 최적화(cosmosdb-query-optimization 사용),
전체 텍스트 검색 인덱스(cosmosdb-full-text-search 사용)
벡터 인덱스(cosmosdb-벡터 검색 사용)
