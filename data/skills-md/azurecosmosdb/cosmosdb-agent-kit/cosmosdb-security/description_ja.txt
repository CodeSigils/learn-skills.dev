Azure Cosmos DB のセキュリティのベスト プラクティス: ローカル認証 (キー) の無効化、
DefaultAzureCredential を使用したマネージド ID、ネットワーク アクセス制限、
RBAC の最小権限、およびポイントインタイム復元のための継続的なバックアップ。
用途: Cosmos DB セキュリティ、ローカル認証の無効化、キーの無効化、マネージド ID、
DefaultAzureCredential、Entra ID、ネットワーク制限、IP ファイアウォール、
プライベート エンドポイント、RBAC ロール、最小権限、データ プレーン ロール、
継続的バックアップ、ポイントインタイム復元、PITR、ゼロトラスト。
次の目的には使用しないでください: クライアント側の暗号化 (保留中)、SDK 認証コード (cosmosdb-sdk を使用)。
