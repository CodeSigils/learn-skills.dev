Azure Cosmos DB للذكاء الاصطناعي وRAG والبحث: بحث المتجهات (أنواع فهرس المتجهات، إعداد حاوية التضمين، استعلامات التشابه/الجار الأقرب)، البحث عن النص الكامل (تمكين FTS، تصنيف الصلة BM25، الكلمة الرئيسية المختلطة + المتجه)، تكامل LangChain وLangGraph (موفر نقطة تفتيش CosmosDB، init نقطة تفتيش غير متزامنة، جلسات MCP المستمرة، محتوى أداة MCP وتصفيتها، LangChain JS Vectorstore، سجل الدردشة، نموذج التضمين، وذاكرة التخزين المؤقت الدلالية)، وأنماط تصميم وكيل الذكاء الاصطناعي (توجيه متعدد الوكلاء، وفصل محفوظات الدردشة، والاستئناف من نقطة التفتيش، والوصول إلى التأريض، وكتابة المهام الخلفية).
الاستخدام من أجل: تخزين التضمينات وتشغيل بحث التشابه، واختيار فهرس متجه، وتمكين البحث عن النص الكامل/BM25، والبحث المختلط، وإنشاء تطبيق RAG، واستمرار نقاط تفتيش LangGraph، وحالة الوكيل المتعدد، وأدوات MCP، وذاكرة التخزين المؤقت الدلالية.
لا تستخدمه من أجل: النمذجة الأساسية/القسم/الفهرس/الاستعلام (استخدم بيانات واستعلامات cosmosdb)؛ الإنتاجية/العالمية/المراقبة/الأمان (استخدم عمليات cosmosdb)؛ إعداد عميل غير AI SDK (استخدم cosmosdb-sdk).
