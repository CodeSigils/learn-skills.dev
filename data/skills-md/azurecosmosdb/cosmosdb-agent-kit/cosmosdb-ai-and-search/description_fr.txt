Azure Cosmos DB pour IA, RAG et recherche : recherche vectorielle (types d'index vectoriels, configuration du conteneur d'intégration, requêtes de similarité/voisin le plus proche), recherche en texte intégral (activer FTS, classement de pertinence BM25, mot-clé hybride + vecteur), intégration LangChain et LangGraph (économiseur de point de contrôle CosmosDB, initialisation du point de contrôle asynchrone, sessions persistantes MCP, contenu et filtrage de l'outil MCP, magasin vectoriel LangChain JS, historique des discussions, modèle d'intégration, sémantique cache) et les modèles de conception d'agents IA (routage multi-agents, séparation de l'historique des discussions, reprise à partir du point de contrôle, accès à la terre, écritures de tâches en arrière-plan).
UTILISER POUR : stocker les intégrations et exécuter une recherche de similarité, choisir un index vectoriel, activer la recherche en texte intégral/BM25, la recherche hybride, créer une application RAG, conserver les points de contrôle LangGraph, l'état multi-agent, les outils MCP, le cache sémantique.
NE PAS UTILISER POUR : modélisation de base/partition/index/requête (utilisez cosmosdb-data-and-queries) ; débit/global/surveillance/sécurité (utiliser les opérations cosmosdb) ; Configuration du client non-AI SDK (utilisez cosmosdb-sdk).
