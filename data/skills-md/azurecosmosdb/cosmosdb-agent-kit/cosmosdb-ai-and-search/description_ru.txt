Azure Cosmos DB для искусственного интеллекта, RAG и поиска: векторный поиск (типы векторных индексов, настройка контейнера внедрения, запросы сходства/ближайшего соседа), полнотекстовый поиск (включение FTS, ранжирование релевантности BM25, гибридное ключевое слово + вектор), интеграция LangChain и LangGraph (сохранение контрольных точек CosmosDB, инициализация асинхронной контрольной точки, постоянные сеансы MCP, содержимое и фильтрация инструмента MCP, векторное хранилище LangChain JS, история чата, модель внедрения, семантический кеш) и шаблоны проектирования ИИ-агентов (многоагентная маршрутизация, разделение истории чата, возобновление с контрольной точки, заземление доступа, запись фоновых задач).
ИСПОЛЬЗОВАНИЕ ДЛЯ: хранения вложений и запуска поиска по сходству, выбора векторного индекса, включения полнотекстового поиска/поиска BM25, гибридного поиска, создания приложения RAG, сохранения контрольных точек LangGraph, многоагентного состояния, инструментов MCP, семантического кэша.
НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: основного моделирования/раздела/индекса/запроса (используйте CosmosDB-данные-и-запросы); пропускная способность/глобальная/мониторинг/безопасность (используйте CosmosDB-операции); Настройка клиента SDK, отличного от AI (используйте Cosmosdb-sdk).
