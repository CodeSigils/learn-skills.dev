用於 AI、RAG 和搜尋的 Azure Cosmos DB：向量搜尋（向量索引類型、嵌入容器設定、相似性/最近鄰查詢）、全文搜尋（啟用 FTS、BM25 相關性排名、混合關鍵字 + 向量）、LangChain 和 LangGraph 整合（CosmosDB 檢查點保護程式、非同步檢查點保護程式、MCP 持續性會話、MCP 內容會話、MCP 檢查點保護程式、異步檢查持久點初始化工具、MCP 內容會話、MCP 內容工具和 JSang Sangal 工具向量儲存、聊天歷史記錄、嵌入模型、語義快取）和人工智慧代理設計模式（多代理路由、聊天歷史記錄分離、從檢查點恢復、接地存取、後台任務寫入）。
用途：儲存嵌入並執行相似性搜尋、選擇向量索引、啟用全文/BM25 搜尋、混合搜尋、建立 RAG 應用程式、保留 LangGraph 檢查點、多代理狀態、MCP 工具、語義快取。
不要用於：核心建模/分區/索引/查詢（使用 cosmosdb-data-and-queries）；吞吐量/全域/監控/安全（使用 cosmosdb-operations）；非 AI SDK 用戶端設定（使用 cosmosdb-sdk）。
