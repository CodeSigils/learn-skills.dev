أفضل ممارسات Azure Cosmos DB SDK لـ .NET وJava وPython وSpring Boot و
LangChain: عميل فردي، واجهات برمجة التطبيقات غير المتزامنة، أوضاع الاتصال، إعادة محاولة المعالجة،
التشخيص، التسلسل، تكوين المحاكي، ETags، قاطع الدائرة،
استراتيجية التوفر، والأنماط الخاصة بالإطار.
الاستخدام لـ: CosmosClient Singleton، async API، Direct vs Gateway mode، أعد المحاولة 429،
المناطق المفضلة، المناطق المستبعدة، استراتيجية التوفر، قاطع الدائرة،
تشخيصات SDK، وتعدادات التسلسل، ومحاكي SSL، وتزامن ETag،
الإنشاء المشروط، زيادة التصحيح، رمز الاستمرار، استجابة المحتوى،
Spring Data Cosmos، إصدارات Spring Boot، تبعية Newtonsoft، تصادم مساحة الاسم،
أقسام Python غير المتزامنة، وتكوين التطوير المحلي، وموفر قاعدة بيانات LangChain Cosmos، ونقطة تفتيش LangGraph،
جلسة MCP المستمرة، تنسيق محتوى أداة MCP، تصفية أداة MCP،
مخزن ناقلات LangChain JS وسجل الدردشة LangChain JS وذاكرة التخزين المؤقت الدلالية LangChain JS.
لا تستخدمه من أجل: نمذجة البيانات (استخدم نمذجة بيانات cosmosdb)، والاستعلامات (استخدم تحسين استعلام cosmosdb)،
مفاتيح القسم (استخدم مفتاح قسم cosmosdb).
