Рекомендации по использованию пакета SDK Azure Cosmos DB для .NET, Java, Python, Spring Boot и
LangChain: одноэлементный клиент, асинхронные API, режимы подключения, обработка повторов,
диагностика, сериализация, настройка эмулятора, ETags, автоматический выключатель,
стратегия доступности и шаблоны, специфичные для платформы.
ИСПОЛЬЗОВАНИЕ ДЛЯ: одноэлементный CosmosClient, асинхронный API, режим Direct vs Gateway, повтор 429,
предпочтительные регионы, исключенные регионы, стратегия доступности, автоматический выключатель,
Диагностика SDK, перечисления сериализации, эмулятор SSL, параллелизм ETag,
условное создание, приращение исправления, токен продолжения, ответ содержимого,
Spring Data Cosmos, версии Spring Boot, зависимость Newtonsoft, коллизия пространств имен,
Асинхронные настройки Python, локальная конфигурация разработчика, заставка LangChain Cosmos DB, контрольный указатель LangGraph,
Постоянный сеанс MCP, формат содержимого инструмента MCP, фильтрация инструмента MCP,
Векторный магазин LangChain JS, история чатов LangChain JS, семантический кеш LangChain JS.
НЕ ИСПОЛЬЗОВАТЬ ДЛЯ: моделирования данных (используйте Cosmosdb-Data-Modeling), запросов (используйте CosmosDB-Query-Optimization),
ключи разделов (используйте cosmosdb-partition-key).
