Azure Cosmos DB のグローバル分散のベスト プラクティス: マルチリージョン書き込み、
整合性レベル、競合解決、自動フェイルオーバー、読み取り領域、
高可用性のためのゾーン冗長性。
用途: Cosmos DB マルチリージョン、整合性レベル、強整合性、
期限付きの古さ、セッションの一貫性、結果的な一貫性、競合の解決、
自動フェイルオーバー、読み取りリージョン、ゾーン冗長性、グローバル レプリケーション、
災害復旧、地理的冗長性、マルチマスター。
以下には使用しないでください: SDK 優先リージョン (cosmosdb-sdk を使用)、
モニタリング (cosmosdb-monitoring を使用)。
