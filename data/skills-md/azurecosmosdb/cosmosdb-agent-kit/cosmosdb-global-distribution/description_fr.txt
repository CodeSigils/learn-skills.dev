Bonnes pratiques de distribution mondiale Azure Cosmos DB : écritures multirégions,
niveaux de cohérence, résolution de conflits, basculement automatique, régions de lecture,
et redondance de zone pour une haute disponibilité.
UTILISER POUR : Cosmos DB multirégion, niveaux de cohérence, cohérence forte,
obsolescence limitée, cohérence de session, cohérence éventuelle, résolution de conflit,
basculement automatique, régions de lecture, redondance de zone, réplication globale,
reprise après sinistre, géoredondance, multi-maître.
NE PAS UTILISER POUR : les régions préférées du SDK (utilisez cosmosdb-sdk),
surveillance (utilisez cosmosdb-monitoring).
