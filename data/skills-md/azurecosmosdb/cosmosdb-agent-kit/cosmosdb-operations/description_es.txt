Operaciones, escalamiento y seguridad de Azure Cosmos DB: aprovisionamiento de rendimiento (escala automática frente a manual, sin servidor para desarrolladores, estimación de RU, ráfagas), distribución global (escrituras multirregionales, regiones de lectura, conmutación por error, niveles de coherencia, resolución de conflictos, redundancia de zonas), monitoreo y diagnóstico (consumo de RU, limitación/alertas 429, latencia P99, Azure Monitor, registros de diagnóstico) y seguridad (identidad administrada, deshabilitar autenticación de clave, privilegio mínimo de RBAC, restricción de red, copia de seguridad continua/restauración en un punto en el tiempo).
USO PARA: aprovisionar RU/s, escalamiento automático, sin servidor, escrituras multirregionales, conmutación por error de región, elegir nivel de coherencia, alerta sobre limitación, seguimiento de latencia P99, enviar métricas a Azure Monitor, autenticar con identidad administrada, bloquear en una VNet, RBAC, restaurar.
NO UTILIZAR PARA: modelado, claves de partición, indexación, consultas (use cosmosdb-data-and-queries); Código de cliente SDK (use cosmosdb-sdk); Búsqueda vectorial/de texto completo y agentes de IA (use cosmosdb-ai-and-search).
