Операции, масштабирование и безопасность Azure Cosmo DB: обеспечение пропускной способности (автомасштабирование или ручное масштабирование, бессерверное масштабирование для разработчиков, оценка количества единиц ресурса, пакетные пакеты), глобальное распределение (запись в несколько регионов, регионы чтения, отработка отказа, уровни согласованности, разрешение конфликтов, избыточность зон), мониторинг и диагностика (потребление RU, регулирование/предупреждения 429, задержка P99, Azure Monitor, журналы диагностики) и безопасность (управляемое удостоверение, отключение проверки подлинности по ключу, минимальные привилегии RBAC, ограничение сети, непрерывное резервное копирование/восстановление на определенный момент времени).
ИСПОЛЬЗОВАНИЕ ДЛЯ: подготовка ЕЗ/с, автомасштабирование, бессерверная запись, запись в несколько регионов, отработка отказа региона, выбор уровня согласованности, оповещение о регулировании, отслеживание задержки P99, передача метрик в Azure Monitor, проверка подлинности с помощью управляемого удостоверения, привязка к виртуальной сети, RBAC, восстановление.
НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: моделирования, ключей разделов, индексации, запросов (используйте cosmosdb-data-and-queries); Клиентский код SDK (используйте cosmosdb-sdk); векторный/полнотекстовый поиск и агенты искусственного интеллекта (используйте cosmosdb-ai-and-search).
