Рекомендации по пропускной способности и масштабированию Azure Cosmo DB: автоматическое масштабирование для переменных
рабочие нагрузки, правильное определение выделенной пропускной способности, бессерверные технологии для разработки и тестирования,
пакетная мощность и распределение пропускной способности контейнера и базы данных.
ИСПОЛЬЗОВАНИЕ ДЛЯ: автомасштабирование Cosmos DB, подготовленная пропускная способность, бессерверная работа, пакетная мощность,
Определение размера ЕЗ/с, пропускная способность контейнера, пропускная способность базы данных, оптимизация затрат,
предотвращение избыточного, недостаточного предоставления, предотвращения регулирования.
НЕ ИСПОЛЬЗОВАТЬ ДЛЯ: Мониторинг потребления RU (используйте cosmosdb-monitoring),
дизайн ключа раздела (используйте cosmosdb-partition-key).
