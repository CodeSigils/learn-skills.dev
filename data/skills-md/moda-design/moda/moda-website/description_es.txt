Cree y publique un sitio web en vivo alojado en Moda. Úselo cuando el usuario solicite un sitio web, un sitio, una página web, una página de destino, un sitio de marketing, un sitio de cartera, una página de inicio, una página próximamente, "ponga esto en la web" o quiera actualizar o volver a publicar un sitio moda.page existente. Produce un sitio alojado real en una URL pública *.moda.page que se puede editar y volver a publicar. Para un paginador imprimible/PDF, utilice moda-one-pager; para diapositivas utilice moda-deck.
