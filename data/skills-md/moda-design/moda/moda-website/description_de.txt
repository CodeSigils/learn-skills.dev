Erstellen und veröffentlichen Sie eine auf Moda gehostete Live-Website. Verwenden Sie diese Option, wenn der Benutzer nach einer Website, Site, Webseite, Landingpage, Marketingseite, Portfolioseite, Homepage, Coming-Bald-Seite fragt, „diese ins Web stellen“ möchte oder eine bestehende moda.page-Site aktualisieren oder erneut veröffentlichen möchte. Erstellt eine echte gehostete Website unter einer öffentlichen *.moda.page-URL, die weiterhin bearbeitet und erneut veröffentlicht werden kann. Für einen druckbaren/PDF-One-Pager verwenden Sie moda-one-pager; Für Folien verwenden Sie Moda-Deck.
