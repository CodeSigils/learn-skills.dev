Holen Sie sich Moda-Marken-Kits, erstellen Sie sie und wenden Sie sie an, damit jedes Design zur Marke passt. Verwenden Sie diese Option, wenn der Benutzer sagt: „Markenname“, „Markenkit“, „Markenfarben/Schriftarten/Logo“, „Verwenden Sie unsere Marke“, „Passen Sie zu unserer Website“, „Rebranding“ oder möchte, dass ein Markenkit aus einer Website-URL erstellt wird oder dass eine vorhandene Leinwand anhand der Marke geprüft wird. Liest Kit-Palette/Schriftarten/Logos deterministisch und übergibt sie an die anderen Moda-Fähigkeiten. Kits, keine Renderings: Eine von der Marke geleitete Bewegungsanfrage („Erstellen Sie mit dem Moda-Marken-Kit ein Video“) oder irgendetwas, das in mp4/gif → Moda-Video gerendert wurde, führt und zieht das Kit selbst.
