Nehmen Sie präzise Änderungen an einer vorhandenen Moda-Leinwand über deren URL vor oder teilen Sie den Link – formulieren Sie Text um oder formatieren Sie ihn neu, ändern Sie die Farbe, richten Sie ihn neu aus, ändern Sie die Größe, tauschen Sie ein Bild aus, fügen Sie einen Abschnitt hinzu oder löschen Sie ihn, reparieren Sie eine Folie, die jemand im Editor berührt hat. Wird verwendet, wenn der Benutzer einen moda.app-Canvas oder eine Freigabe-URL (oder eine cvs_id) einfügt und um Änderungen bittet oder um ein Design zu überarbeiten, das ein früherer Moda-Skill oder die von Moda erstellte KI erstellt hat. Deterministisch: Liest den Canvas-Status, wendet gezielte Markup-/Code-Änderungen an und überprüft anhand von Screenshots. Bewegung auf der Leinwand hinzufügen oder ändern: Moda-Video laden.
