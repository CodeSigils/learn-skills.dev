Entwerfen Sie auf Moda einen One-Pager, einen PDF-Bericht, ein Handout, einen Flyer oder ein druckbares Dokument. Verwenden Sie diese Option, wenn der Benutzer einen One-Pager, eine einseitige Zusammenfassung, ein PDF, einen Bericht, ein Briefing, ein Handout, ein Informationsblatt, ein Leave-behind oder „dieses Markdown/diese README-Datei gestaltet aussehen lassen“ oder eine Infografik anfordert. Dazu gehören auch mehrseitige Dokumente – ein 12-seitiger Bericht, Leitfaden, Whitepaper oder Vorschlag – sowie Drucksachen: Poster, Flyer, Menüs, Lebensläufe, Zertifikate, Einladungen, Visitenkarten (Folien gehen zu Moda-Deck; Social-Media-/Bannergrafiken zu Moda-Social). Erstellt gestaltete US-Letter- (oder A4-)Seiten auf einer Live-Moda-Leinwand und exportiert ein echtes PDF mit auswählbarem Text (Hyperlinks werden im PDF auf einfachen Text reduziert). Erfordert die Moda-CLI und ein Moda-Konto (Schritt 0 überprüft beide; es wird nie selbst etwas installiert).
