Прикрепите репозиторий к настройкам Moda по умолчанию через .moda/context.json — org, Brand, Canvas — чтобы каждый запуск этого репозитория попадал в нужное место; проверьте кредиты с помощью «использования/расходов учетной записи moda». Только CLI: эти значения по умолчанию относятся к файлам на вашем диске.
