L'intégration des agents Blazing fonctionne pour les agents BA, les fournisseurs, les invites, les sessions, les tours, les compétences d'exécution, les outils, les connexions MCP, la mémoire, les espaces de travail, les artefacts, les tâches, l'utilisation, la CLI et les clients SDK. À utiliser lorsque le contexte des Blazing Agents ou BA est explicite. Ne pas utiliser pour les agents AI génériques, le SDK Vercel AI, le bac à sable ou les questions de tâches sans contexte BA.
