Échafaudez ou auditez le faisceau d'agents (contexte/coffre-fort + AGENTS.md + modèles de spécifications + compétences regroupées) dans n'importe quel dépôt. Agent indépendant : fonctionne avec n'importe quel outil prenant en charge le standard de compétences d'agent ouvert (Claude Code, Codex, Cursor, OpenCode, etc.). Idempotent – ​​peut être exécuté en toute sécurité à plusieurs reprises. À utiliser lorsque l'utilisateur souhaite configurer, vérifier ou réparer l'infrastructure d'agent dans un projet.
