قم بدعم أو تدقيق أدوات الوكيل (السياق/القبو + AGENTS.md + قوالب المواصفات + المهارات المجمعة) في أي مستودع. Agent-agnostic — يعمل مع أي أداة تدعم معيار مهارات الوكيل المفتوح (Claude Code، Codex، Cursor، OpenCode، وما إلى ذلك). Idempotent — آمن للتشغيل بشكل متكرر. يُستخدم عندما يريد المستخدم إعداد البنية الأساسية للوكيل أو التحقق منها أو إصلاحها في مشروع.
