Audite cualquier tienda Shopify activa o página de producto para detectar riesgos de política de tergiversación de Google Merchant Center mediante el rastreo de páginas públicas; no se requiere token API. Úselo cuando la cuenta GMC de un comerciante se suspende por tergiversación, cuando prepara una tienda para el envío de GMC o cuando realiza un barrido de cumplimiento antes de una apelación. Activadores de frases como "mi GMC fue suspendido", "revise mi tienda para ver si hay tergiversaciones", "audite mis productos para Google Shopping", "por qué mi Merchant Center está suspendido" o "verifique si mi tienda cumple con la política de GMC".
