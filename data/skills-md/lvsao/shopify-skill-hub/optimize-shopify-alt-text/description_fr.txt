Auditez, planifiez et optimisez en toute sécurité le texte alternatif des images Shopify pour les supports de produits, les images en vedette dans les collections, les images en vedette dans les articles et les images en ligne des articles. À utiliser lorsqu'un commerçant souhaite qu'un agent d'IA analyse les images Shopify, teste si le modèle d'IA actif peut inspecter les images, génère un texte alternatif concis avec une compréhension multimodale des images lorsqu'il est disponible ou une solution de secours contextuelle uniquement lorsqu'il ne l'est pas, examine les modifications proposées par lots et applique les mises à jour approuvées de l'administrateur Shopify.
