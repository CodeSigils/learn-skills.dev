엔터프라이즈 비즈니스 시스템에서 후보 온톨로지 모델을 추출하고 모든 파일 시스템에서 개인 지식 그래프를 구축/유지합니다. 사용 시기: 온톨로지 추출, 本体提取, 스키마 분석, 엔터티 추출, 데이터 사전(数据字典), 表结构分析, 지식 그래프(知识图谱), 전체扫描, ​​파일 스캔, 개인 지식(个人知识) 또는 비즈니스 시스템 데이터 모델 분석. 세 가지 작동 모드: (A) 데이터베이스/스키마 추출 — SQL DDL, Word/Excel 데이터 사전에서 SCAN→EXTRACT→MERGE. 온톨로지.json + review.md를 출력합니다. (B) 파일 시스템 스캐닝 - 개인 지식 그래프에 대한 색인 → 파이프라인 분석. Office/PDF/텍스트를 읽고 엔터티와 도메인 구조를 추출합니다. graph.jsonl + Schema.yaml을 출력합니다. (C) 외부 데이터 스캐닝 - 다른 사람의 데이터 공간(클라이언트, 파트너)에 대한 B와 동일합니다. .docx .doc .wps .pdf .xlsx .xls .et .pptx .ppt .dps .md .txt .sql .yaml .json .csv를 처리합니다. python-docx, PyMuPDF, openpyxl, python-pptx를 사용합니다. 다중 모드 이미지 분석을 지원합니다. 외부 API 키나 네트워크 액세스가 필요하지 않습니다. 이 기술을 실행하는 LLM은 의미 분석 엔진입니다. 모든 처리는 로컬입니다. 파일 검사는 분석이 시작되기 전 필수 1.5단계 확인을 통해 사용자 범위로 이루어집니다.
