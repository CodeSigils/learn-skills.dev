Estrai modelli ontologici candidati da sistemi aziendali aziendali E crea/mantieni grafici della conoscenza personale da qualsiasi file system. Utilizzare quando: estrazione di ontologie, 本体提取, analisi dello schema, estrazione di entità, dizionario dei dati (数据字典), 表结构分析, grafico della conoscenza (知识图谱), 全量扫描, scansione di file, conoscenza personale (个人知识) o analisi di modelli di dati del sistema aziendale. Tre modalità operative: (A) Estrazione di database/schema: SCAN→EXTRACT→MERGE da SQL DDL, dizionari dati Word/Excel. Restituisce ontology.json + review.md. (B) Scansione del filesystem: indicizza→analizza la pipeline per il grafico della conoscenza personale. Legge Office/PDF/testo, estrae entità e strutture di dominio. Restituisce graph.jsonl + schema.yaml. (C) Scansione dei dati esterni: come B per gli spazi dati di altri (clienti, partner). Gestisce .docx .doc .wps .pdf .xlsx .xls .et .pptx .ppt .dps .md .txt .sql .yaml .json .csv. Utilizza python-docx, PyMuPDF, openpyxl, python-pptx. Supporta l'analisi multimodale delle immagini. Non sono richieste chiavi API esterne o accesso alla rete: il LLM che esegue questa competenza È il motore di analisi semantica. Tutta l'elaborazione è locale. La scansione dei file è a livello di utente tramite la conferma obbligatoria del Passaggio 1.5 prima dell'inizio di qualsiasi analisi.
