Extraiga modelos de ontología candidatos de sistemas empresariales Y cree/mantenga gráficos de conocimiento personal desde cualquier sistema de archivos. Utilícelo cuando: extracción de ontologías, análisis de esquemas, extracción de entidades, diccionario de datos (数据字典), análisis de archivos, conocimiento personal (个人知识) o análisis de modelos de datos de sistemas empresariales. Tres modos de funcionamiento: (A) Extracción de base de datos/esquema: ESCANEAR → EXTRAER → FUSIONAR de SQL DDL, diccionarios de datos de Word/Excel. Salidas ontology.json + review.md. (B) Escaneo del sistema de archivos: indexar → analizar la canalización para obtener un gráfico de conocimiento personal. Lee Office/PDF/texto, extrae entidades y estructuras de dominio. Genera Graph.jsonl + Schema.yaml. (C) Escaneo de datos externos: igual que B para los espacios de datos de otros (clientes, socios). Maneja .docx .doc .wps .pdf .xlsx .xls .et .pptx .ppt .dps .md .txt .sql .yaml .json .csv. Utiliza python-docx, PyMuPDF, openpyxl, python-pptx. Admite análisis de imágenes multimodales. No se requieren claves API externas ni acceso a la red: el LLM que ejecuta esta habilidad ES el motor de análisis semántico. Todo el procesamiento es local. El escaneo de archivos está al alcance del usuario mediante la confirmación obligatoria del Paso 1.5 antes de que comience cualquier análisis.
