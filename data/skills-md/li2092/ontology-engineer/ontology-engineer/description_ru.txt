Извлекайте возможные модели онтологий из корпоративных бизнес-систем И стройте/поддерживайте графики личных знаний из любой файловой системы. Используйте, когда: извлечение онтологии, 本体提取, анализ схемы, извлечение сущностей, словарь данных (数据字典), 表结构分析, граф знаний (知识图谱), 全量扫描, сканирование файлов, личные знания (个人知识) или анализ моделей данных бизнес-системы. Три режима работы: (A) Извлечение базы данных/схемы — СКАНИРОВАНИЕ→ИЗВЛЕЧЕНИЕ→ОБЪЕДИНЕНИЕ из SQL DDL, словарей данных Word/Excel. Выводит ontology.json + review.md. (B) Сканирование файловой системы — индексирование → анализ конвейера для графа личных знаний. Читает Office/PDF/текст, извлекает объекты и структуры доменов. Выводит граф.jsonl + схема.yaml. (C) Сканирование внешних данных — то же, что и B для чужих пространств данных (клиентов, партнеров). Обрабатывает файлы .docx .doc .wps .pdf .xlsx .xls .et .pptx .ppt .dps .md .txt .sql .yaml .json .csv. Использует python-docx, PyMuPDF, openpyxl, python-pptx. Поддерживает мультимодальный анализ изображений. Никаких внешних ключей API или доступа к сети не требуется — LLM, использующий этот навык, ЯВЛЯЕТСЯ механизмом семантического анализа. Вся обработка локальная. Сканирование файлов осуществляется пользователем посредством обязательного подтверждения шага 1.5 перед началом любого анализа.
