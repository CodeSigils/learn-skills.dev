استخراج نماذج علم الوجود المرشح من أنظمة أعمال المؤسسة وإنشاء/صيانة الرسوم البيانية للمعرفة الشخصية من أي نظام ملفات. يُستخدم عندما: استخراج الأنطولوجيا، أو تحليل المخطط، أو استخراج الكيان، أو قاموس البيانات، أو الرسم البياني المعرفي، أو تحليل البيانات، أو مسح الملفات، أو المعرفة الشخصية، أو تحليل بيانات نظام الأعمال نماذج. ثلاثة أوضاع تشغيل: (أ) استخراج قاعدة البيانات/المخطط - SCAN → EXTRACT → MERGE من SQL DDL وقواميس بيانات Word/Excel. النواتج ontology.json + review.md. (ب) فحص نظام الملفات — الفهرس → تحليل خط الأنابيب للرسم البياني للمعرفة الشخصية. يقرأ Office/PDF/النص، ويستخرج الكيانات وهياكل المجال. مخرجات graph.jsonl + schema.yaml. (ج) فحص البيانات الخارجية - مثل فحص ب لمساحات بيانات الآخرين (العملاء والشركاء). يعالج .docx .doc .wps .pdf .xlsx .xls .et .pptx .ppt .dps .md .txt .sql .yaml .json .csv. يستخدم python-docx، PyMuPDF، openpyxl، python-pptx. يدعم تحليل الصور متعدد الوسائط. لا يلزم وجود مفاتيح واجهة برمجة تطبيقات خارجية أو الوصول إلى الشبكة — إن LLM الذي يقوم بتشغيل هذه المهارة هو محرك التحليل الدلالي. جميع المعالجة محلية. يتم فحص الملفات على نطاق المستخدم من خلال تأكيد الخطوة 1.5 الإلزامية قبل بدء أي تحليل.
