エンタープライズ ビジネス システムから候補オントロジー モデルを抽出し、任意のファイル システムから個人のナレッジ グラフを構築/維持します。次の場合に使用します: オントロジー抽出、本体提取、スキーマ分析、エンティティ抽出、データ辞書 (数据字典)、表结构分析、ナレッジ グラフ (知识图谱)、全量扫描、ファイル スキャン、個人知識 (个人知识)、またはビジネス システム データ モデルの分析。 3 つの操作モード: (A) データベース/スキーマ抽出 — SQL DDL、Word/Excel データ ディクショナリからの SCAN→EXTRACT→MERGE。 ontology.json + review.md を出力します。 (B) ファイルシステムのスキャン — 個人の知識グラフのインデックス→分析パイプライン。 Office/PDF/テキストを読み取り、エンティティとドメイン構造を抽出します。 graph.jsonl + schema.yaml を出力します。 (C) 外部データ スキャン — 他者のデータ スペース (クライアント、パートナー) の場合は B と同じです。 .docx .doc .wps .pdf .xlsx .xls .et .pptx .ppt .dps .md .txt .sql .yaml .json .csv を処理します。 python-docx、PyMuPDF、openpyxl、python-pptx を使用します。マルチモーダル画像解析をサポートします。外部 API キーやネットワーク アクセスは必要ありません。このスキルを実行する LLM はセマンティック分析エンジンです。すべての処理はローカルで行われます。ファイル スキャンは、分析を開始する前に必須のステップ 1.5 確認を介してユーザー スコープで行われます。
