Collectez tous les avis clients à partir d'une URL de produit Amazon ou d'une URL d'avis sur les produits via une session Chrome connectée sur le port 9222, exportez un classeur factuel de 14 colonnes, remplissez éventuellement les traductions via DeepLX, puis aidez le modèle à baliser les lignes dans une feuille de calcul finale prête à être livrée. À utiliser lorsque l'utilisateur envoie un lien Amazon et souhaite récupérer les avis, analyser les avis des concurrents, exporter les avis ou une feuille de calcul prête à être livrée avec les noms d'utilisateur, les liens d'avis, l'heure de l'examen, les votes utiles, la traduction, le résumé, le sentiment, les catégories et les balises.
