Spenden Sie eine einzelne Coding-Agent-Sitzung an Trace Commons, einen offenen öffentlichen Datensatz von Agent-Traces. Verwenden Sie diesen Skill immer dann, wenn der Benutzer eine Agentensitzung, einen Trace oder einen Konversationsverlauf für Trace Commons oder einen offenen Datensatz spenden, beitragen, teilen oder veröffentlichen möchte oder Dinge wie „/donate-trace“, „diese Sitzung spenden“, „meinen Trace beisteuern“, „dies für die Commons freigeben“ oder „meinen Agentenverlauf veröffentlichen“ sagt. Der Skill lokalisiert die aktuelle Sitzung aus den eigenen Protokollen des Agenten, entfernt Pfade, Identität, Geheimnisse und PII lokal, zeigt dem Benutzer genau an, was entfernt wurde, bestätigt, dass das Projekt Open-Source ist, und öffnet eine Pull-Anfrage für den Datensatz. Spendet immer nur aus öffentlichen, Open-Source-Repositories – niemals privaten oder proprietären Code.
