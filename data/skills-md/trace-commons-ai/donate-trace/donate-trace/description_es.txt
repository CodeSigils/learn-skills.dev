Done una única sesión de agente de codificación a Trace Commons, un conjunto de datos públicos abiertos de seguimiento de agentes. Utilice esta habilidad siempre que el usuario quiera donar, contribuir, compartir o publicar una sesión de agente, un seguimiento o un historial de conversación en Trace Commons o un conjunto de datos abierto, o diga cosas como "/donate-trace", "donar esta sesión", "contribuir con mi seguimiento", "compartir esto con los comunes" o "publicar mi historial de agente". La habilidad localiza la sesión actual a partir de los propios registros del agente, elimina rutas, identidades, secretos y PII localmente, muestra al usuario exactamente lo que se eliminó, confirma que el proyecto es de código abierto y abre una solicitud de extracción al conjunto de datos. Solo done desde repositorios públicos de código abierto, nunca desde código privado o propietario.
