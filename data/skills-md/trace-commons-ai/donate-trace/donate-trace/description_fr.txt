Faites don d’une seule session d’agent de codage à Trace Commons, un ensemble de données publiques ouvertes de traces d’agent. Utilisez cette compétence chaque fois que l'utilisateur souhaite faire un don, contribuer, partager ou publier une session d'agent, une trace ou un historique de conversation sur Trace Commons ou un ensemble de données ouvert, ou dit des choses comme « /donate-trace », « faire don de cette session », « contribuer à ma trace », « partager ceci sur les communs » ou « publier l'historique de mon agent ». La compétence localise la session en cours à partir des propres journaux de l'agent, supprime les chemins, l'identité, les secrets et les informations personnelles localement, montre à l'utilisateur exactement ce qui a été supprimé, confirme que le projet est open source et ouvre une demande d'extraction sur l'ensemble de données. Les dons proviennent uniquement de référentiels publics et open source – jamais de code privé ou propriétaire.
