NetEase Cloud Music Smart Assistant, with model judgment at its core, executes operations via ncm-cli.  
Core capabilities: analyze user’s liked-songs playlist preference profile, craft multi-keyword search strategies, intelligently recommend playlists/albums/tracks (with two-layer recommendation explanations), playback control (play/pause/next/volume/queue), manage scheduled push scheduling, push recommendation results to Feishu and other IM channels via OpenClaw, create and write playlists.  
Trigger conditions (activates if any are met):  
- message contains “NetEase Cloud” or “Cloud Music”  
- user wants to listen to music, requests playlist recommendations, or searches for a certain type of music  
- user wants to analyze their music preferences or liked-songs history
