Moteur de compréhension approfondie de la base de code qui crée un graphe de connaissances persistant du référentiel. À utiliser lorsque l'utilisateur demande à comprendre, expliquer, tracer un flux, analyser l'impact d'un changement, examiner un PR/diff, explorer les dépendances ou générer des diagrammes. Phrases de déclenchement : « expliquer X », « comment fonctionne Y », « suivre le flux de paiement », « qu'est-ce qui se casse si je change X », « examiner ce PR », « ce qui dépend de ce fichier », « me guider à travers le flux d'authentification », « dessiner le flux X », « afficher l'architecture », « diagramme de séquence pour X », « visualiser les dépendances », « schématiser le flux de paiement ».
