2130 STANDARD Salesforce 개체에 대한 신뢰할 수 있는 필드/스키마 참조 - 계정, 연락처, 기회, 리드, 사례, ApexClass, ApexCodeCoverage, TraceFlag 등에 대한 표준 sObject 및 도구 필드 API 이름, 유형, 속성(필터링 가능/정렬 가능/그룹 가능/업데이트 가능) 및 관계 이름을 조회하는 데 사용됩니다. 필드 이름, 유형 또는 필터/정렬/그룹 기능이 확인되지 않은 경우 SOQL/쿼리/Apex 기술과 함께 이를 로드합니다. 필드가 이미 알려져 있고 쿼리 구문 또는 최적화만 필요한 경우가 아닙니다. 표준 개체(기능, 관계/하위 쿼리 경로 또는 개체에 포함된 필드)에 대해 SOQL/SOSL 쿼리 또는 DML의 필드를 확인, 유효성 검사 또는 디버깅할 때 트리거하면 추측하는 대신 쿼리가 실행됩니다. 사용자 정의 __c 개체 및 __c 필드는 이러한 자산에 없습니다. 해당 라이브 조직을 설명합니다(sf sobject explain). *-meta.xml 또는 sfdx 소스 작성/배포를 위해 트리거하지 마십시오(메타데이터 API 기술 사용).
