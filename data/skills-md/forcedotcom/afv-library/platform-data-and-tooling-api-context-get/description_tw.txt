2130 個標準 Salesforce 物件的權威欄位/架構參考 — 用於尋找標準 sObject 和工具欄位 API 名稱、類型、屬性（可過濾/可排序/可分組/可更新）以及客戶、聯絡人、機會、潛在客戶、案例、ApexClass、ApexCodeCoverage、TraceFlag 等的關係名稱。當欄位名稱、類型或篩選/排序/分組功能未經驗證時，而不是當欄位已知且僅需要查詢語法或最佳化時，將此與 SOQL/查詢/Apex 技能一起載入。當針對標準物件（功能、關係/子查詢路徑或物件具有哪些欄位）驗證、驗證或偵錯 SOQL/SOSL 查詢或 DML 中的欄位時觸發，因此查詢會運行而不是猜測。自訂 __c 物件和 __c 欄位不在這些資產中；描述這些的即時組織（sf sobject describe）。不要觸發創作/部署 *-meta.xml 或 sfdx 來源（使用元資料 API 技能）。
