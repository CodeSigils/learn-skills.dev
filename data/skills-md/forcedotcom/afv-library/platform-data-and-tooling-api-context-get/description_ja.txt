2130 STANDARD Salesforce オブジェクトの信頼できるフィールド/スキーマリファレンス — 標準の sObject およびツールフィールドの API 名、タイプ、プロパティ (フィルタ可能/並べ替え可能/グループ化可能/更新可能)、および取引先、取引先責任者、商談、リード、ケース、ApexClass、ApexCodeCoverage、TraceFlag などの関係名を検索するために使用します。項目名、タイプ、またはフィルタ/並べ替え/グループ機能が未検証の場合は、これを SOQL/クエリ/Apex スキルと一緒にロードします。項目がすでにわかっており、クエリ構文または最適化のみが必要な場合ではありません。 SOQL/SOSL クエリまたは DML のフィールド (機能、リレーションシップ/サブクエリのパス、オブジェクトに含まれるフィールド) を標準オブジェクトに対して検証、検証、またはデバッグするときにトリガーされるため、推測ではなくクエリが実行されます。カスタム __c オブジェクトと __c フィールドはこれらのアセットには含まれません。それらのライブ組織を説明します (sf sobject description)。 *-meta.xml または sfdx ソースの作成/デプロイのためにトリガーしないでください (メタデータ API スキルを使用してください)。
