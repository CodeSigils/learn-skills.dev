Installez, configurez et dépannez Salesforce Code Analyzer pour n'importe quel projet. Gère l'installation, les vérifications des prérequis, le diagnostic des configurations défectueuses, la création et la modification des remplacements code-analyzer.yml, les paramètres spécifiques au moteur, les modèles d'ignorance, les remplacements de gravité et la configuration du pipeline CI/CD. DÉCLENCHEMENT lorsque : l'utilisateur dit « configurer l'analyseur de code », « configurer l'analyseur de code », « installer l'analyseur de code », « l'analyseur de code ne fonctionne pas », « réparer ma configuration », « l'analyse échoue », « vérifier ma configuration », « l'analyseur de code est-il installé », « activer/désactiver le moteur », « exclure des fichiers », « modifier la gravité », « configurer les actions GitHub », « configurer CI/CD », « ajouter un analyseur de code au pipeline », « faire échouer le pipeline », « mettre à jour mon flux de travail », « porte de qualité », « échouer en cas de violations », « analyser les fichiers modifiés uniquement », « ajouter SARIF », « code-analyzer.yml », « configuration ESLint », « augmenter la mémoire SFGE » ou rapporte des erreurs lors de l'exécution de Code Analyzer. NE PAS DÉCLENCHER lorsque : l'utilisateur souhaite exécuter une analyse (utiliser l'analyseur de code en cours d'exécution), corriger les violations, expliquer les règles, créer des règles personnalisées ou supprimer les violations.
