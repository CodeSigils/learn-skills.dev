Configuration OAuth des applications connectées Salesforce et des applications client externes avec un score de 120 points. Utilisez cette compétence pour configurer les flux OAuth, l'authentification du porteur JWT, les applications connectées et les applications client externes dans Salesforce. DÉCLENCHEMENT lorsque : l'utilisateur configure les flux OAuth, l'authentification du porteur JWT, les applications connectées, les ECA ou touche les fichiers .connectedApp-meta.xml / .eca-meta.xml. NE PAS DÉCLENCHER lorsque : la configuration des informations d'identification nommées pour les appels (utilisez building-sf-integrations), la révision des politiques d'autorisation (utilisez le déploiement de métadonnées) ou l'écriture de code de gestion des jetons Apex (utilisez la génération d'apex).
