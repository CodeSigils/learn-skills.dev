Rufen Sie mithilfe von REST-APIs Data Lake Object (DLO)- und Data Model Object (DMO)-Schemainformationen aus der Salesforce Data Cloud ab. Verwenden Sie diese Fähigkeit, wenn Sie DLO- oder DMO-Felddefinitionen, Datentypen oder Metadaten überprüfen müssen. Akzeptiert den Organisationsalias und den optionalen DLO/DMO-Namen als Parameter.
