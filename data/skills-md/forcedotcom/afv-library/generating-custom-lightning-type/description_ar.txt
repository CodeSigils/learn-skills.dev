استخدم هذه المهارة عندما يحتاج المستخدمون إلى إنشاء أنواع Lightning Types (CLTs) مخصصة لإجراءات وكيل Einstein أو مخططات الإدخال/الإخراج المنظمة. يتم تشغيله عندما يذكر المستخدمون CLT، أو Custom Lightning Types، أو مخططات JSON للوكلاء، أو تعريفات النوع، أو Lightning__objectType، أو تكوينات المحرر/العارض. هذا أمر معقد - استخدم هذه المهارة دائمًا في عمل CLT.
