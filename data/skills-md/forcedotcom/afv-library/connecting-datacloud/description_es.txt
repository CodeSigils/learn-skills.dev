Fase de Salesforce Data Cloud Connect. Utilice esta habilidad cuando el usuario administre conexiones y conectores de Data Cloud o configure un nuevo sistema de origen. DISPARAR cuando: el usuario administra conexiones, conectores y metadatos de conectores de Data Cloud, prueba una conexión, explora objetos o bases de datos de origen o configura un nuevo sistema de origen. NO DISPARAR cuando: la tarea se refiere a flujos de datos o DLO (use la preparación de la nube de datos), DMO o resolución de identidad (use la armonización de la nube de datos), recuperación/búsqueda (use la recuperación de la nube de datos) o telemetría STDM (use la observación-agentforce).
