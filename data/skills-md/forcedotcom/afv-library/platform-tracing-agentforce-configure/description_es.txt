Genere metadatos de AgentforcePlatformTracingSettings para habilitar o deshabilitar los intervalos de seguimiento de ejecución del agente Agentforce que fluyen a Data Cloud. Utilice esta habilidad para cualquier trabajo de metadatos de AgentforcePlatformTracingSettings. DISPARAR cuando: el usuario menciona el seguimiento de Agentforce, los intervalos de seguimiento de agentes, el seguimiento de Data Cloud, AgentforcePlatformTracingSettings, el seguimiento de observabilidad de la plataforma, habilita el seguimiento de agentes, quiere intervalos de ejecución de agentes en Data Cloud, menciona .settings-meta.xml para AgentforcePlatformTracing o pregunta sobre cómo habilitar la observabilidad para los agentes de Agentforce. NO ACTIVAR cuando: el usuario quiera seguimiento de plataforma para TraceSpanEvent (use platform-tracing-configure), quiera consultar o analizar datos de seguimiento de agentes existentes en Data Cloud (use agentforce-observe), quiera archivos de registro de eventos o configuración ELF, quiera cambiar captura de datos (use Integration-eventing-cdc-configure) o quiera ManagedEventSubscription (use Integration-eventing-subscription-configure).
