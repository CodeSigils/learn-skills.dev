Создайте метаданные AgentforcePlatformTracingSettings, чтобы включить или отключить диапазоны трассировки выполнения агента Agentforce, передаваемые в облако данных. Используйте этот навык для любой работы с метаданными AgentforcePlatformTracingSettings. ТРИГГЕР, когда: пользователь упоминает трассировку Agentforce, диапазоны трассировки агента, трассировку облака данных, AgentforcePlatformTracingSettings, трассировку наблюдаемости платформы, включает трассировку агента, хочет, чтобы интервалы выполнения агента были в облаке данных, упоминает .settings-meta.xml для AgentforcePlatformTracing или спрашивает о включении наблюдения для агентов Agentforce. НЕ АКТИВИРУЙТЕ, когда: пользователь хочет отслеживать платформу для TraceSpanEvent (используйте платформу-tracing-configure), хочет запросить или проанализировать существующие данные трассировки агента в облаке данных (используйте Agentforce-observe), хочет использовать файлы журнала событий или конфигурацию ELF, хочет отслеживать измененные данные (используйте Integration-eventing-cdc-configure) или хочет ManagedEventSubscription (используйте Integration-eventing-subscription-configure).
