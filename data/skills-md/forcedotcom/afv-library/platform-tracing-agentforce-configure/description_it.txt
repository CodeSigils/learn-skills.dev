Genera metadati AgentforcePlatformTracingSettings per abilitare o disabilitare gli intervalli di traccia di esecuzione dell'agente Agentforce che fluiscono verso Data Cloud. Utilizza questa competenza per qualsiasi lavoro sui metadati AgentforcePlatformTracingSettings. SI ATTIVA quando: l'utente menziona la traccia Agentforce, gli intervalli di traccia dell'agente, la traccia Data Cloud, AgentforcePlatformTracingSettings, la traccia dell'osservabilità della piattaforma, abilita la traccia dell'agente, desidera intervalli di esecuzione dell'agente in Data Cloud, menziona .settings-meta.xml per AgentforcePlatformTracing o chiede di abilitare l'osservabilità per gli agenti Agentforce. NON SI ATTIVA quando: l'utente desidera Platform Tracing per TraceSpanEvent (utilizza platform-tracing-configure), desidera eseguire query o analizzare i dati di traccia dell'agente esistente in Data Cloud (utilizza agentforce-observe), desidera file di registro eventi o configurazione ELF, desidera Change Data Capture (utilizza Integration-Eventing-cdc-configure) o desidera ManagedEventSubscription (utilizza Integration-Eventing-Subscription-Configure).
