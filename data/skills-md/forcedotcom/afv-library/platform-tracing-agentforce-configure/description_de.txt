Generieren Sie AgentforcePlatformTracingSettings-Metadaten, um Trace-Spans für die Ausführung von Agentforce-Agenten zu aktivieren oder zu deaktivieren, die an Data Cloud übertragen werden. Verwenden Sie diese Fähigkeit für alle AgentforcePlatformTracingSettings-Metadatenarbeiten. TRIGGER, wenn: Der Benutzer erwähnt Agentforce-Tracing, Agent-Trace-Spans, Data Cloud-Tracing, AgentforcePlatformTracingSettings, Plattform-Beobachtbarkeits-Tracing, Agent-Tracing aktivieren, möchte Agent-Ausführungs-Spans in Data Cloud, erwähnt .settings-meta.xml für AgentforcePlatformTracing oder fragt nach der Aktivierung der Beobachtbarkeit für Agentforce-Agenten. NICHT AUSLÖSEN, wenn: Der Benutzer möchte Plattform-Tracing für TraceSpanEvent (verwenden Sie „platform-tracing-configure“), möchte vorhandene Agenten-Trace-Daten in Data Cloud abfragen oder analysieren (verwenden Sie „agentforce-observe“), möchte Ereignisprotokolldateien oder ELF-Konfiguration, möchte „Change Data Capture“ (verwenden Sie „integration-eventing-cdc-configure“) oder möchte ManagedEventSubscription (verwenden Sie „integration-eventing-subscription-configure“).
