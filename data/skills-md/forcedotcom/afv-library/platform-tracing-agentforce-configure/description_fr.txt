Générez des métadonnées AgentforcePlatformTracingSettings pour activer ou désactiver les étendues de trace d'exécution de l'agent Agentforce circulant vers Data Cloud. Utilisez cette compétence pour tout travail de métadonnées AgentforcePlatformTracingSettings. DÉCLENCHEMENT lorsque : l'utilisateur mentionne le traçage Agentforce, les étendues de trace d'agent, le traçage Data Cloud, AgentforcePlatformTracingSettings, le traçage d'observabilité de la plateforme, active le traçage d'agent, souhaite des étendues d'exécution d'agent dans Data Cloud, mentionne .settings-meta.xml pour AgentforcePlatformTracing ou demande comment activer l'observabilité pour les agents Agentforce. NE PAS DÉCLENCHER lorsque : l'utilisateur souhaite un suivi de plate-forme pour TraceSpanEvent (utilisez platform-tracing-configure), souhaite interroger ou analyser les données de trace d'agent existantes dans Data Cloud (utilisez agentforce-observe), souhaite des fichiers journaux d'événements ou une configuration ELF, souhaite une capture de données modifiées (utilisez Integration-eventing-cdc-configure) ou souhaite ManagedEventSubscription (utilisez Integration-eventing-subscription-configure).
