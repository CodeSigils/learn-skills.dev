DevOps Center 테스트 실패 또는 코드 분석기 위반 페이로드를 구문 분석하고 이를 일반 언어(실패 범주, 문제가 있는 파일/클래스/메서드/줄, 규칙 위반 및 수정 방향)로 설명한 다음 우선 순위가 지정된 테스트 개선 제안을 제공합니다(프로덕션 코드 수정과 테스트 코드 구별). 순수 추론: 시스템 호출이나 코드 작성이 없습니다. TRIGGER 언제: 테스트 실행이 실패했고 사용자가 근본 원인을 원하는 경우; 품질 게이트 실패에 대한 설명이 필요합니다. 코드 분석기 위반 사항을 일반 언어로 변환해야 합니다. 사용자가 실패 페이로드를 공유하고 이를 해결하는 방법을 묻습니다. 테스트가 계속 실패하고 사용자가 제안을 원합니다. 또는 사용자가 적용 범위 격차를 줄이고, 어설션을 강화하거나, 불안정하거나 약한 테스트를 수정하기를 원합니다. 다음과 같은 경우에는 트리거하지 마십시오: 사용자가 수정 코드를 작성하거나(생성-apex 사용) 새 테스트 클래스를 작성하기를 원합니다(생성-apex-test 사용).
