Analizza un payload di errore di test o violazione di Code Analyser del DevOps Center e lo spiega in un linguaggio semplice (categoria di errore, file/classe/metodo/riga offensivi, regola violata e direzione della correzione), quindi fornisce suggerimenti di miglioramento del test con priorità (distinguendo il codice di test dalle correzioni del codice di produzione). Ragionamento puro: nessuna chiamata di sistema o creazione di codice. TRIGGER quando: un'esecuzione di test non è riuscita e l'utente desidera la causa principale; un guasto del cancello di qualità deve essere spiegato; Le violazioni di Code Analyser devono essere tradotte in un linguaggio semplice; l'utente condivide un payload di errore e chiede come affrontarlo; i test continuano a fallire e l'utente desidera suggerimenti; oppure l'utente desidera colmare le lacune di copertura, rafforzare le asserzioni o correggere test instabili/deboli. NON SI ATTIVA quando: l'utente desidera scrivere il codice di correzione (usa generation-apex) o creare nuove classi di test (usa generation-apex-test).
