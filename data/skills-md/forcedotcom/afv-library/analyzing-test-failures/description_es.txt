Analiza una carga útil de falla de prueba de DevOps Center o infracción del Analizador de código y la explica en lenguaje sencillo (categoría de falla, archivo/clase/método/línea infractora, regla violada y dirección de corrección) y luego brinda sugerencias de mejora de prueba priorizadas (distinguiendo el código de prueba de las correcciones del código de producción). Razonamiento puro: sin llamadas al sistema ni creación de código. DISPARAR cuando: una ejecución de prueba falló y el usuario desea la causa raíz; es necesario explicar una falla en el control de calidad; Las infracciones del Analizador de código deben traducirse a un lenguaje sencillo; el usuario comparte una carga útil de falla y pregunta cómo solucionarla; las pruebas siguen fallando y el usuario quiere sugerencias; o el usuario quiere cerrar las brechas de cobertura, fortalecer las afirmaciones o corregir pruebas deficientes o débiles. NO DISPARE cuando: el usuario quiera escribir un código de corrección (use generate-apex) o que se creen nuevas clases de prueba (use generate-apex-test).
