Genere metadatos de EventSettings para habilitar o deshabilitar el seguimiento de plataforma (publicación de TraceSpanEvent) en Event Monitoring. Utilice esta habilidad para cualquier trabajo de metadatos de EventSettings enablePlatformTracing. ACTIVAR cuando: el usuario menciona el seguimiento de plataforma, TraceSpanEvent, habilita el seguimiento en la configuración de monitoreo de eventos, alterna el seguimiento de monitoreo de eventos, enablePlatformTracing, .settings-meta.xml para el seguimiento de la configuración de eventos, activa eventos de intervalo de seguimiento o deja de publicar intervalos de seguimiento. NO DISPARE cuando: el usuario quiera rastrear el agente de Agentforce hasta Data Cloud (use platform-tracing-agentforce-configure), quiera archivos de registro de eventos o generación de ELF, quiera captura de datos modificados (use integración-eventing-cdc-configure) o quiera ManagedEventSubscription (use integración-eventing-subscription-configure).
