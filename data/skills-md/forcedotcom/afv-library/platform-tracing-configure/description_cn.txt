Generate EventSettings metadata to enable or disable Platform Tracing (TraceSpanEvent publishing) in Event Monitoring. Use this skill for any EventSettings enablePlatformTracing metadata work.触发条件：用户提及平台跟踪、TraceSpanEvent、在事件监控设置中启用跟踪、事件监控跟踪切换、enablePlatformTracing、用于事件设置跟踪的 .settings-meta.xml、打开跟踪跨度事件或停止发布跟踪跨度。在以下情况下请勿触发：用户想要 Agentforce 代理跟踪到数据云（使用 platform-tracing-agentforce-configure）、想要生成事件日志文件或 ELF、想要更改数据捕获（使用integration-eventing-cdc-configure）或想要 ManagedEventSubscription（使用integration-eventing-subscription-configure）。
