يُستخدم لتكوين أو إعداد أو إصلاح وكيل إدارة المبيعات وإدارة تدفقات Agentforce في مؤسسة Salesforce. أتمتة عملية إنشاء بيانات التعريف للتدفقات وقوالب المطالبة ومجموعات الأذونات وتكوين مصدر البيانات. يتم تشغيله عندما: يرغب المستخدم في تمكين إدارة مسارات المبيعات، أو تكوين ميزات خطوط أنابيب المبيعات، أو إعداد وكيل إدارة المبيعات لتحديثات حقول الفرص (بما في ذلك التحديثات الذاتية)، أو توصيل مصادر البيانات الممكنة مثل Einstein Conversation Insights أو Einstein Activity Capture، أو تخصيص أوصاف مرحلة الفرصة، أو تكوين اقتراحات ما بعد الاجتماع، أو التحقق من حالة التكوين أو تدقيقها، أو إصلاح المؤسسات التي تم تكوينها جزئيًا، أو استكشاف مشكلات البيانات التعريفية لإدارة خطوط الأنابيب وإصلاحها. لا تقم بالتشغيل عندما: يريد المستخدم إنشاء وكيل مخصص (استخدم Agentforce-generate)، أو تكوين تتبع Agentforce العام (استخدم Platform-Tracing-agentforce-configure)، أو العمل مع وكلاء غير المبيعات، أو تمكين Einstein Conversation Insights أو Einstein Activity Capture من البداية (التزويد خارج النطاق).
