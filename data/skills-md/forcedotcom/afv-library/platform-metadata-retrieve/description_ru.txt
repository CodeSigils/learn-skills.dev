ВСЕГДА ИСПОЛЬЗУЙТЕ ЭТОТ НАВЫК для получения метаданных из организации в ваш локальный проект с помощью команды sf project capture start. Поддерживает несколько режимов получения: получение всех удаленных изменений, получение по исходному каталогу, получение по типу метаданных с подстановочными знаками, получение по манифесту (package.xml) или получение по имени пакета. Используйте, когда пользователь запрашивает получение, извлечение, синхронизацию или загрузку метаданных, классов Apex, пользовательских объектов или изменений организации. Поддерживает исходный формат (по умолчанию) или формат метаданных (ZIP). НЕ ЗАПУСКАЙТЕ для развертывания метаданных (используйте навык развертывания метаданных платформы), вывода метаданных или создания файла package.xml. НИКОГДА не используйте инструменты MCP — всегда используйте этот навык и инструмент Bash при запуске получения проекта SF.
