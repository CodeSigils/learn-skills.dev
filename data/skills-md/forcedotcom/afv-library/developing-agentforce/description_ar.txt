يمكنك إنشاء الوكلاء وتعديلهم وتصحيح أخطائهم ونشرهم باستخدام Agentforce Agent Script. يتم تشغيله عندما: يقوم المستخدم بإنشاء ملفات .agent أو تعديلها أو السؤال عنها أو بيانات تعريف aiAuthoringBundle؛ تغيير سلوك الوكيل أو الاستجابات أو منطق المحادثة؛ تصميم موضوعات الوكيل أو الإجراءات أو الأدوات أو الوكلاء الفرعيين أو التحكم في التدفق؛ يكتب أو يراجع مواصفات الوكيل؛ معاينات الوكلاء أو تصحيح الأخطاء أو نشرهم أو نشرهم أو اختبارهم؛ يستخدم أوامر Agent Script CLI (إنشاء/معاينة/نشر/اختبار وكيل sf). لا تقم بالتشغيل عند: تطوير Apex، أو بناء التدفق، أو تأليف القالب الفوري، أو تكوين تجربة السحابة، أو مهام Salesforce CLI العامة التي لا علاقة لها بالبرنامج النصي للوكيل.
