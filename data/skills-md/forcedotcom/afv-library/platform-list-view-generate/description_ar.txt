استخدم هذه المهارة عندما يحتاج المستخدمون إلى إنشاء البيانات التعريفية لعرض قائمة Salesforce أو إنشائها أو التحقق من صحتها. يتم التشغيل عندما يذكر المستخدمون طرق عرض القائمة، أو قوائم السجلات التي تمت تصفيتها، أو إنشاء طرق العرض، أو إعداد أعمدة السجلات، أو تصفية السجلات حسب المعايير، أو السؤال عن رؤية طريقة عرض القائمة. يُستخدم أيضًا عندما يقول المستخدمون أشياء مثل "أحتاج إلى طريقة عرض تظهر..." أو "تصفية السجلات حسب..." أو "إنشاء عرض قائمة لـ..." أو عندما يعملون مع ملفات ListView XML ويحتاجون إلى التحقق من الصحة أو استكشاف الأخطاء وإصلاحها.
