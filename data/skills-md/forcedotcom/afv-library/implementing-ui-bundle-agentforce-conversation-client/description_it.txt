DEVE essere attivato quando il progetto contiene una directory uiBundles/*/src/ e l'attività prevede l'aggiunta o la modifica di un widget di chat, chatbot o AI conversazionale. Utilizza questa abilità quando l'utente chiede di aggiungere, incorporare, integrare, configurare, applicare uno stile o rimuovere un agente, un chatbot, un widget di chat, un client di conversazione o un assistente AI. Riguarda lo stile (colori, caratteri, spaziatura, bordi), il layout (in linea o mobile, larghezza, altezza, dimensioni) e oggetti di scena (agentId, agentLabel, headerEnabled, showHeaderIcon, showAvatar, styleTokens). Attiva quando i file in uiBundles/*/src/ importano AgentforceConversationClient o quando aggiungi funzionalità di chat o agente a una pagina. Non creare mai un agente personalizzato, un chatbot o un componente widget di chat.
