Récupérez les informations de schéma Data Lake Object (DLO) et Data Model Object (DMO) à partir de Salesforce Data Cloud à l'aide des API REST. Utilisez cette compétence lorsque vous devez inspecter les définitions de champs, les types de données ou les métadonnées DLO ou DMO. Prend l'alias de l'organisation et le nom DLO/DMO facultatif comme paramètres.
