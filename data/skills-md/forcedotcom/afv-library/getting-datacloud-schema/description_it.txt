Recuperare le informazioni sullo schema Data Lake Object (DLO) e Data Model Object (DMO) da Salesforce Data Cloud utilizzando le API REST. Utilizza questa competenza quando è necessario controllare le definizioni dei campi, i tipi di dati o i metadati DLO o DMO. Accetta l'alias dell'organizzazione e il nome DLO/DMO facoltativo come parametri.
