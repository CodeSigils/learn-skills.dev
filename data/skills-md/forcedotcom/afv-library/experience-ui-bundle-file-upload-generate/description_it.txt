DEVE essere attivato quando il progetto contiene una directory uiBundles/*/src/ e l'attività prevede il caricamento, l'allegato o l'eliminazione di file. Utilizza questa competenza quando aggiungi la funzionalità di caricamento file a un'app bundle dell'interfaccia utente. Fornisce il monitoraggio dei progressi e l'integrazione di Salesforce ContentVersion. Questa funzionalità fornisce SOLO API programmatiche: crea un'interfaccia utente personalizzata utilizzando l'API upload(). Usalo SEMPRE invece di creare il caricamento dei file da zero con FormData o XHR.
