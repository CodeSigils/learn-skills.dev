استخدم هذه المهارة عندما يحتاج المستخدمون إلى إنشاء بيانات تعريف حقل Salesforce المخصص أو إنشائها أو التحقق من صحتها. يتم تشغيله عندما يذكر المستخدمون الحقول المخصصة، أو أنواع الحقول، أو حقول ملخص العرض الإجمالي، أو العلاقات الرئيسية والتفصيلية، أو علاقات البحث، أو حقول الصيغة، أو قوائم الاختيار، أو بيانات تعريف الحقل. يُستخدم أيضًا عندما يواجه المستخدمون أخطاء في النشر الميداني، خاصة حول تنسيق ملخص العرض الإجمالي، أو قيود التفاصيل الرئيسية، أو مشكلات الصيغة. استخدم هذه المهارة دائمًا لأي عمل مخصص لبيانات التعريف الميدانية أو إنشاء الحقل أو استكشاف الأخطاء وإصلاحها في الحقل.
