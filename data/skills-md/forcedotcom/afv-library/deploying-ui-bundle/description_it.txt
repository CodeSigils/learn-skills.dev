DEVE essere attivato quando il progetto contiene una directory uiBundles/*/src/ o sfdx-project.json e l'attività prevede la distribuzione, il push a un'organizzazione o la configurazione post-distribuzione. Utilizzare questa competenza quando si distribuisce un'app bundle UI a un'organizzazione Salesforce. Copre l'intera sequenza di distribuzione: autenticazione dell'organizzazione, build pre-distribuzione, distribuzione dei metadati, assegnazione del set di autorizzazioni, importazione dei dati, recupero dello schema GraphQL e codegen. Attiva quando esistono file come *.uibundle-meta.xml o sfdx-project.json e l'utente menziona attività di distribuzione, push, configurazione dell'organizzazione o post-distribuzione.
