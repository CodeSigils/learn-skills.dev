Замените OOTB (готовые) компоненты B2B Commerce эквивалентами с открытым исходным кодом в файлах метаданных сайта content.json или найдите эквивалентный компонент `site:` с открытым кодом для определений OOTB. Используйте, когда пользователи упоминают «заменить компоненты OOTB», «заменить коммерческие компоненты открытым кодом», «заменить OOTB на открытый код», «заменить commerce_builder:», «заменить OOTB на сайте», «заменить компонент в метаданных сайта», «заменить определение компонента», «найти эквивалент открытого кода», «эквивалентный компонент с открытым кодом», «Сопоставление OOTB с открытым кодом», «для чего предназначен компонент сайта», компоненты «в этом представлении» или «для данного представления» или конкретный список имен компонентов. - и хотите обновить или обнаружить только сопоставления в метаданных своего магазина.
