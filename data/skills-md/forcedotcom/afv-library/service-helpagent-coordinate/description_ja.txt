ガイド付きの 4 つのチェックポイント フローを通じて、Salesforce ヘルプ エージェント (Service Cloud の Agentforce サービス エージェント) をセットアップ、構成、接地、または稼働させるために使用します。ユーザーが次のいずれかを言うときに使用します。ヘルプ エージェント、サービス エージェント、またはサポート チャット エージェントをセットアップ / 作成 / 構築 / 追加します。 Web サイトまたは Experience Cloud / LWR サイトにチャット ウィジェットを追加または埋め込みます。 Web チャットを拒否している場合でも、チャネル (Web チャット、音声、電話、ヘルプ ポータル) にヘルプ エージェントを配置します。 Salesforce Knowledge にヘルプエージェントを配置します。または、AI に顧客の質問に答え、サポート ケースを管理し、人間にエスカレーションしてもらいたいと考えています。リクエストで 1 つの部分のみが指定されている場合、このスキルがハードストップする近日公開予定のチャネルに名前を指定している場合、または help-agent-spec.md または Agentforce クイック セットアップ ウィザードを参照している場合でも、適切なスキル。ヘルプ エージェント リネージのない新しいエージェントを作成する場合 (agentforce-generate を使用)、OAuth/ECA を構成する場合 (integration-connectivity-connected-app-configure を使用する)、またはメタデータのみをデプロイする場合 (platform-metadata-deploy を使用する) にはトリガーしないでください。
