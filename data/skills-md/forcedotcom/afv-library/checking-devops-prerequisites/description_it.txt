Convalida l'ambiente prima di qualsiasi azione di test della pipeline DevOps Center: conferma un'organizzazione Salesforce autenticata, il plug-in Agentforce DX, un'organizzazione DevOps Center autenticata e una pipeline identificata (e facoltativamente una fase della pipeline). Utilizzalo PRIMA, internamente, da qualsiasi competenza di test DevOps (esecuzione di una suite di test, polling dei risultati, sincronizzazione dei test, configurazione o riattivazione di un gate di qualità, assegnazione/mappatura di suite, creazione di elementi di lavoro correttivi, raccomandazione di test, spiegazione della copertura, analisi degli errori). SI ATTIVA quando un'altra competenza di test DevOps deve confermare il contesto dell'organizzazione/pipeline prima di una query o di una chiamata di sistema. NON ATTIVARE per attività non DevOps-Center.
