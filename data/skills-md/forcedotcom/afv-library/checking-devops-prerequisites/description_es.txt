Validar el entorno antes de cualquier acción de prueba de canalización de DevOps Center: confirma una organización de Salesforce autenticada, el complemento Agentforce DX, una organización de DevOps Center autenticada y una canalización identificada (y opcionalmente una etapa de canalización). Utilice esto PRIMERO, internamente, desde cualquier habilidad de prueba de DevOps (ejecutar un conjunto de pruebas, sondear resultados, sincronizar pruebas, configurar o reactivar una puerta de calidad, asignar/mapear conjuntos, crear elementos de trabajo fijos, recomendar pruebas, explicar la cobertura, analizar fallas). DISPARA cuando otra habilidad de prueba de DevOps necesita confirmar el contexto de la organización/canalización antes de una consulta o llamada al sistema. NO DISPARAR para trabajos que no sean de DevOps-Center.
