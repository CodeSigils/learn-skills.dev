يقوم بإنشاء أو تعديل أو إدارة مواقع Salesforce Experience Cloud LWR عبر البيانات التعريفية DigitalExperience. يتم التشغيل دائمًا عندما يذكر المستخدمون مواقع الخبرة، أو مواقع LWR، أو DigitalExperience، أو Experience Cloud، أو مواقع المجتمع، أو البوابات، أو إنشاء الصفحات، أو إضافة المسارات، أو طرق العرض، أو تخطيطات السمات، أو مجموعات العلامات التجارية، أو معاينة المواقع، أو أي عمل في حزمة DigitalExperience. يُستخدم أيضًا عندما يذكر المستخدمون أنواع محتوى معينة مثل sfdc_cms__route، أو sfdc_cms__themeLayout، وما إلى ذلك، أو عند استكشاف أخطاء نشر الموقع وإصلاحها. قم دائمًا بتشغيل أي قاعدة مشاركة ضيف (مشاركة نوع بيانات التعريفGuestRules) أو إنشاء/تعديل، أو وصول المستخدم الضيف، أو مشاركة السجلات مع المستخدمين الضيوف، أو عندما يقدم المستخدم معرف مستخدم ضيف (15 أو 18 حرفًا يبدأ بـ 005)
