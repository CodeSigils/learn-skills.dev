قم بتشغيل Salesforce Code Analyzer لفحص التعليمات البرمجية بحثًا عن الأمان والأداء وأفضل الممارسات وانتهاكات نمط التعليمات البرمجية. يدعم جميع المحركات (PMD، ESLint، CPD، RetireJS، Flow، SFGE، ApexGuru)، والأهداف (الملفات، المجلدات، git diff)، الفئات، ومستويات الخطورة. يتم تشغيله عندما: يقول المستخدم "فحص الكود الخاص بي"، أو "التحقق من مشكلات الأمان"، أو "تشغيل PMD/ESLint"، أو "البحث عن التكرارات"، أو "تحليل التدفقات"، أو "التحقق من المكتبات الضعيفة"، أو "مراجعة AppExchange"، أو "lint my LWC"، أو "التحليل الثابت"، أو "جودة الكود"، أو يذكر المحركات/أنواع الملفات (.cls، .trigger، .js، .flow-meta.xml). لا تقم بالتشغيل عندما: يريد المستخدم إصلاح التعليمات البرمجية دون إجراء مسح ضوئي، أو يسأل عن التثبيت/التكوين.
