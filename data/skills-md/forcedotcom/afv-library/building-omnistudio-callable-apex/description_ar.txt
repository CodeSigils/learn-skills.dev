Salesforce Industries Common Core (OmniStudio/Vlocity) مهارة إنشاء ومراجعة Apex القابلة للاستدعاء مع تسجيل 120 نقطة. يُستخدم عند إنشاء تطبيقات Apex القابلة للاستدعاء للصناعات أو مراجعتها أو ترحيلها. يتم تشغيله عندما: يقوم المستخدم بإنشاء فئات System.Callable أو مراجعتها، أو ترحيل VlocityOpenInterface أو VlocityOpenInterface2، أو إنشاء ملحقات قابلة للاستدعاء للصناعات تستخدم بواسطة OmniStudio، أو Integration إجراءات، أو DataRaptors. لا تقم بالتشغيل عندما: فئات أو مشغلات Apex العامة (استخدم التوليد-apex)، أو بناء إجراءات التكامل (استخدم إجراء تكامل البناء الشامل)، أو تأليف OmniScripts (استخدم Building-omnistudio-omniscript)، أو تكوين مخططي البيانات (استخدم Building-omnistudio-datamapper)، أو تحليل مشكلات مساحة الاسم/التبعية (استخدم تبعيات التحليل-omnistudio).
