Utilizza questa competenza per creare un WidgetBundle HXL completo (corpo UEM + schema.json + -meta.xml). TRIGGER quando: l'utente richiede un widget, un mosaico, un frammento, una scheda o una ricca superficie dell'interfaccia utente per qualsiasi soggetto, dominio, caratteristica o nome di entità; il prompt nomina solo un'entità o una forma dati senza richiamare tipi Lightning, CLT o tipi supportati da Apex. NON SI ATTIVA quando: il prompt dice esplicitamente 'Lightning Type', 'CLT', 'Custom Lightning Type', 'Apex-backed type' o fa riferimento a '@apexClassType/...' (utilizza platform-lightning-type-widget-coordinate); creazione di un renderer LWC personalizzato per un tipo di fulmine personalizzato (utilizzare platform-custom-lightning-type-generate); o modificando solo un componente LWC.
