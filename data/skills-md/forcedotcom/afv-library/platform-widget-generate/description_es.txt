Utilice esta habilidad para crear un WidgetBundle HXL completo (cuerpo UEM + esquema.json + -meta.xml). DISPARAR cuando: el usuario solicita un widget, mosaico, fragmento, tarjeta o superficie de interfaz de usuario enriquecida para cualquier tema, dominio, característica o sustantivo de entidad; el mensaje nombra solo una entidad o forma de datos sin invocar tipos Lightning, CLT o tipos respaldados por Apex. NO DISPARAR cuando: el mensaje dice explícitamente 'Tipo de Lightning', 'CLT', 'Tipo de Lightning personalizado', 'Tipo respaldado por Apex' o hace referencia a '@apexClassType/...' (use plataforma-tipo-relámpago-widget-coordinate); crear un renderizador LWC personalizado para un tipo de rayo personalizado (use platform-custom-lightning-type-generate); o editar solo un componente LWC.
