プロジェクトに uiBundles/*/src/ ディレクトリが含まれており、タスクにファイルのアップロード、添付、またはドロップが含まれる場合は、アクティブ化する必要があります。このスキルは、ファイル アップロード機能を UI バンドル アプリに追加するときに使用します。進行状況の追跡と Salesforce ContentVersion の統合を提供します。この機能はプログラム API のみを提供します。upload() API を使用してカスタム UI を構築します。 FormData または XHR を使用してファイルのアップロードを最初から構築するのではなく、常にこれを使用してください。
