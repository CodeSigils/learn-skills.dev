ДОЛЖЕН активироваться, когда проект содержит каталог uiBundles/*/src/ и задача включает загрузку, присоединение или удаление файлов. Используйте этот навык при добавлении функции загрузки файлов в приложение пакета пользовательского интерфейса. Обеспечивает отслеживание прогресса и интеграцию Salesforce ContentVersion. Эта функция предоставляет ТОЛЬКО программные API — создавайте собственный пользовательский интерфейс с помощью API upload(). ВСЕГДА используйте это вместо создания загрузки файла с нуля с помощью FormData или XHR.
