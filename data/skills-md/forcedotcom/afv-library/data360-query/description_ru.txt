Этап извлечения данных из облака данных Salesforce. Используйте этот навык, когда пользователь запускает Data Cloud SQL, асинхронные запросы, векторный поиск, рабочие процессы индексирования поиска или самоанализ метаданных для объектов Data Cloud. ТРИГГЕР, когда: пользователь запускает Data Cloud SQL, описание, асинхронные запросы, векторный поиск, рабочие процессы индексирования поиска или самоанализ метаданных для объектов Data Cloud. НЕ АКТИВИРУЙТЕСЬ, когда: задача представляет собой стандартный SOQL CRM (используйте запрос платформы-soql), создание сегмента или расчетное проектирование аналитики (используйте сегмент data360) или STDM/трассировку сеансов/анализ паркета (используйте Agentforce-observe).
