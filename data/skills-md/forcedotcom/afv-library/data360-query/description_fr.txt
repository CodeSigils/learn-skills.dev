Phase de récupération de Salesforce Data Cloud. Utilisez cette compétence lorsque l'utilisateur exécute Data Cloud SQL, des requêtes asynchrones, une recherche vectorielle, des workflows d'index de recherche ou une introspection de métadonnées pour les objets Data Cloud. DÉCLENCHEMENT lorsque : l'utilisateur exécute Data Cloud SQL, décrit, des requêtes asynchrones, une recherche vectorielle, des workflows d'index de recherche ou une introspection de métadonnées pour les objets Data Cloud. NE PAS DÉCLENCHER lorsque : la tâche est CRM SOQL standard (utilisez platform-soql-query), la création de segments ou la conception d'informations calculées (utilisez data360-segment), ou l'analyse STDM/traçage de session/parquet (utilisez agentforce-observe).
