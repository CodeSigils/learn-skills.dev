Fase di recupero di Salesforce Data Cloud. Utilizza questa competenza quando l'utente esegue Data Cloud SQL, query asincrone, ricerca vettoriale, flussi di lavoro di indici di ricerca o introspezione di metadati per oggetti Data Cloud. TRIGGER quando: l'utente esegue Data Cloud SQL, descrive, query asincrone, ricerca vettoriale, flussi di lavoro di indici di ricerca o introspezione di metadati per oggetti Data Cloud. NON SI ATTIVA quando: l'attività è CRM SOQL standard (utilizza platform-soql-query), creazione di segmenti o progettazione di insight calcolati (utilizza data360-segment) o STDM/tracciamento sessioni/analisi parquet (utilizza agentforce-observe).
