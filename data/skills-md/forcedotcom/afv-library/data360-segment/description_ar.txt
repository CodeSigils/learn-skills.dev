مرحلة قطاع سحابة بيانات Salesforce. استخدم هذه المهارة عندما يقوم المستخدم بإنشاء شرائح أو نشرها، أو إدارة الرؤى المحسوبة، أو استكشاف أخطاء SQL الخاصة بالجمهور وإصلاحها في Data Cloud. يتم تشغيله عندما: يقوم المستخدم بإنشاء شرائح أو نشرها، أو إدارة الرؤى المحسوبة، أو فحص أعداد الشرائح أو العضوية، أو استكشاف أخطاء SQL الخاصة بالجمهور وإصلاحها في Data Cloud. لا تقم بالتشغيل عندما: تكون المهمة عبارة عن عمل DMO/رسم الخرائط/تحليل الهوية (استخدام data360-harmonize)، أو عمل التنشيط (استخدام data360-activate)، أو عمل الاستعلام/فهرس البحث (استخدام data360-query)، أو نموذج البيانات القياسي (STDM)/تتبع الجلسة (استخدام agentforce-observe).
