Fase del segmento Salesforce Data Cloud. Utilizza questa competenza quando l'utente crea o pubblica segmenti, gestisce approfondimenti calcolati o risolve i problemi SQL del pubblico in Data Cloud. ATTIVA quando: l'utente crea o pubblica segmenti, gestisce approfondimenti calcolati, controlla i conteggi o l'appartenenza dei segmenti o risolve i problemi SQL del pubblico in Data Cloud. NON ATTIVARE quando: l'attività è un lavoro DMO/mappatura/risoluzione dell'identità (utilizzare data360-harmonize), un lavoro di attivazione (utilizzare data360-activate), un lavoro di query/indice di ricerca (utilizzare data360-query) o un modello di dati standard (STDM)/tracciamento delle sessioni (utilizzare agentforce-observe).
