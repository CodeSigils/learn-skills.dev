Fase de Segmento de Salesforce Data Cloud. Utilice esta habilidad cuando el usuario cree o publique segmentos, administre información calculada o solucione problemas de SQL de audiencia en Data Cloud. DISPARAR cuando: el usuario crea o publica segmentos, administra información calculada, inspecciona el recuento de segmentos o la membresía, o soluciona problemas de SQL de audiencia en Data Cloud. NO DISPARAR cuando: la tarea es DMO/trabajo de mapeo/resolución de identidad (use data360-harmonize), trabajo de activación (use data360-activate), trabajo de consulta/índice de búsqueda (use data360-query) o Modelo de datos estándar (STDM)/seguimiento de sesiones (use agentforce-observe).
