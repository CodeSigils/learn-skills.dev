Этап сегмента облака данных Salesforce. Используйте этот навык, когда пользователь создает или публикует сегменты, управляет расчетными данными или устраняет неполадки SQL аудитории в Data Cloud. ТРИГГЕР, когда: пользователь создает или публикует сегменты, управляет расчетными данными, проверяет количество сегментов или их членство или устраняет неполадки SQL аудитории в облаке данных. НЕ ЗАПУСКАЙТЕ, когда: задачей является работа по DMO/сопоставлению/разрешению личности (используйте data360-harmonize), работа по активации (используйте data360-activate), работа по запросу/поиску-индексу (используйте data360-query) или стандартную модель данных (STDM)/трассировку сеанса (используйте Agentforce-observe).
