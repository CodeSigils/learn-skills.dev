Référence de l'API de métadonnées Salesforce pour créer, comprendre ou modifier des fichiers XML de métadonnées (.object-meta.xml, .flow-meta.xml, etc.) et l'un des 604 types de métadonnées (CustomObject, Flow, ApexClass, ApexTrigger, Profile, PermissionSet, Layout, ValidationRule, RecordType, EmailTemplate, ...). À utiliser pour les questions sur les champs d'un type, le format XML ou la structure du projet Salesforce DX (force-app/main/default). DÉCLENCHEMENT lorsque : la création ou la modification d'un fichier *-meta.xml, la demande de quels champs/format un type de métadonnées possède, ou chaque fois que "métadonnées Salesforce" ou "projet sfdx" est mentionné. NE PAS DÉCLENCHER lorsque : un accès SOQL/DML/sObject d'exécution (utilisez la compétence API d'entreprise), des enregistrements de développeur d'API d'outils (ApexExecutionOverlayAction, TraceFlag) ou une logique non XML (code Apex, LWC JS, contrôleurs Visualforce).
