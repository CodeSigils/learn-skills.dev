Referencia de la API de metadatos de Salesforce para crear, comprender o modificar archivos XML de metadatos (.object-meta.xml, .flow-meta.xml, etc.) y cualquiera de los 604 tipos de metadatos (CustomObject, Flow, ApexClass, ApexTrigger, Profile, PermissionSet, Layout, ValidationRule, RecordType, EmailTemplate, ...). Úselo para preguntas sobre los campos de un tipo o el formato XML, o la estructura del proyecto Salesforce DX (force-app/main/default). DISPARAR cuando: crea o edita cualquier archivo *-meta.xml, pregunta qué campos/formato tiene un tipo de metadatos o cada vez que se menciona 'metadatos de Salesforce' o 'proyecto sfdx'. NO DISPARAR cuando: Acceso SOQL/DML/runtime sObject (use la habilidad Enterprise API), registros de desarrollador de API de herramientas (ApexExecutionOverlayAction, TraceFlag) o lógica no XML (código Apex, LWC JS, controladores Visualforce).
