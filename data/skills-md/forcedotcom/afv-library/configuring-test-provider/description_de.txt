Konfiguriert einen verfügbaren Testanbieter (z. B. Apex Unit Tests, Code Analyzer, Flow Tests, Provar) in einer DevOps Center-Pipeline über die Connect-API nach expliziter Benutzerbestätigung, sodass die Testsuiten des Anbieters für die Zuweisung zu Pipeline-Stufen verfügbar werden. Akzeptiert eine Pipeline-ID und eine TestProvider-ID. Verwenden Sie diesen Skill, wenn ein Anbieter in der Pipeline verfügbar, aber noch nicht konfiguriert ist und der Benutzer ihn aktivieren möchte. TRIGGER, wenn: der Benutzer einen Testanbieter in einer Pipeline konfigurieren, aktivieren, einrichten oder hinzufügen möchte oder möchte, dass die Suiten eines noch nicht konfigurierten Anbieters verfügbar werden. NICHT AUSLÖSEN, wenn: ein bereits konfigurierter Anbieter erneut synchronisiert wird, um neue Suiten aufzunehmen (Synchronisierungs-Testanbieter verwenden) oder vorhandene Suiten einer Phase zuweisen (Managing-Suite-Zuweisungen verwenden).
