명시적인 사용자 확인 후 Connect API를 통해 DevOps Center 파이프라인에서 사용 가능한 테스트 공급자(예: Apex 단위 테스트, 코드 분석기, 흐름 테스트, Provar)를 구성하므로 공급자의 테스트 도구 모음을 파이프라인 단계에 할당할 수 있습니다. PipelineId 및 testProviderId를 사용합니다. 파이프라인에서 제공자를 사용할 수 있지만 아직 구성되지 않았고 사용자가 이를 활성화하려는 경우 이 기술을 사용하십시오. TRIGGER 언제: 사용자가 파이프라인에서 테스트 공급자를 구성, 활성화, 설정 또는 추가하려고 하거나 아직 구성되지 않은 공급자의 제품군을 사용할 수 있기를 원합니다. 다음과 같은 경우에는 트리거하지 마십시오: 새 제품군을 선택하기 위해 이미 구성된 공급자를 다시 동기화하는 경우(syncing-test-providers 사용) 또는 기존 제품군을 단계에 할당하는 경우(managing-suite-locations 사용)
