Configura un provider di test disponibile (ad esempio Apex Unit Test, Code Analyser, Flow Test, Provar) su una pipeline DevOps Center tramite l'API Connect, dopo la conferma esplicita dell'utente, in modo che le suite di test del provider diventino disponibili per l'assegnazione alle fasi della pipeline. Accetta un pipelineId e un testProviderId. Utilizza questa competenza quando un provider è disponibile nella pipeline ma non ancora configurato e l'utente desidera abilitarlo. TRIGGER quando: l'utente desidera configurare, abilitare, impostare o aggiungere un fornitore di test su una pipeline o desidera che le suite di un fornitore non ancora configurato diventino disponibili. NON SI ATTIVA quando: si ri-sincronizza un provider già configurato per acquisire nuove suite (usa sincronizzazione-test-provider) o assegni suite esistenti a una fase (usa gestione-suite-assegnazioni).
