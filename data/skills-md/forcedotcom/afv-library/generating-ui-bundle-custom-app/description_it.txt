DEVE essere attivato quando il progetto contiene una directory uiBundles/*/src/ e l'attività prevede la creazione o la configurazione di un'applicazione personalizzata per ospitare un pacchetto UI in Lightning Experience. Utilizza questa competenza quando crei un record di metadati CustomApplication per far emergere il bundle dell'interfaccia utente nell'icona di avvio delle app. Attiva quando i file corrispondenti a application/*.app-meta.xml esistono e necessitano di modifiche o quando l'utente desidera esporre la propria app tramite Lightning App Launcher senza un sito Digital Experience. NON utilizzare la generazione di applicazioni personalizzate per questo: le app del bundle dell'interfaccia utente non utilizzano schede, sostituzioni di azioni o pagine flessibili.
