DOIT s'activer lorsque le projet contient un répertoire uiBundles/*/src/ et que la tâche implique la création ou la configuration d'une application personnalisée pour héberger un bundle d'interface utilisateur dans Lightning Experience. Utilisez cette compétence lors de la création d’un enregistrement de métadonnées CustomApplication pour faire apparaître le bundle d’interface utilisateur dans le lanceur d’application. Activez-le lorsque les fichiers correspondant à applications/*.app-meta.xml existent et doivent être modifiés, ou lorsque l'utilisateur souhaite exposer son application via le lanceur d'application Lightning sans site Digital Experience. N'utilisez PAS de génération d'application personnalisée pour cela : les applications du bundle d'interface utilisateur n'utilisent pas d'onglets, de remplacements d'actions ou de pages flexibles.
