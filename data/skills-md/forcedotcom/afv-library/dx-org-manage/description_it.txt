INVOCARE questa competenza per eseguire operazioni dell'organizzazione Salesforce: creare organizzazioni iniziali, creare istantanee dell'organizzazione, aprire organizzazioni nel browser. Questa abilità ESEGUISCE le operazioni immediatamente: NON genera script o file di codice. Richiama SEMPRE questa competenza (non eseguire direttamente i comandi CLI di SF) quando l'utente richiede di: creare un'organizzazione scratch (edizione Developer/Enterprise, dal file di definizione (.json), dallo snapshot o dalla forma dell'organizzazione), creare uno snapshot dell'organizzazione o aprire un'organizzazione Salesforce. Le frasi di attivazione includono: "crea un'istantanea", "crea un'istantanea della mia organizzazione scratch", "scatta uno snapshot", "crea un'organizzazione scratch", "crea un'organizzazione scratch per sviluppatori", "nuova organizzazione scratch", "crea un'organizzazione", "crea un'organizzazione da un'istantanea", "scratch-def.json", "project-scratch-def.json", "apri il mio Salesforce" org', 'apri org nel browser', 'trovami l'URL'. NON utilizzare per cambiare organizzazione predefinita (utilizzare dx-org-switch) o distribuire metadati (utilizzare platform-metadata-deploy).
