INVOQUE esta habilidad para ejecutar operaciones de organización de Salesforce: crear organizaciones borrador, crear instantáneas de organizaciones, abrir organizaciones en el navegador. Esta habilidad EJECUTA operaciones inmediatamente; NO genera scripts ni archivos de código. SIEMPRE invoque esta habilidad (no ejecute comandos SF CLI directamente) cuando el usuario solicite: crear una organización borrador (edición Developer/Enterprise, desde un archivo de definición (.json), desde una instantánea o desde la forma de la organización), crear una instantánea de la organización o abrir una organización de Salesforce. Las frases de activación incluyen: 'crear una instantánea', 'crear una instantánea de mi organización borrador', 'tomar una instantánea', 'crear una organización borrador', 'crear una organización borrador de la edición Developer', 'nueva organización borrador', 'activar una organización', 'crear una organización a partir de una instantánea', 'scratch-def.json', 'project-scratch-def.json', 'abrir mi organización de Salesforce', 'abrir org en el navegador', 'dame la URL'. NO lo use para cambiar la organización predeterminada (use dx-org-switch) ni para implementar metadatos (use platform-metadata-deploy).
