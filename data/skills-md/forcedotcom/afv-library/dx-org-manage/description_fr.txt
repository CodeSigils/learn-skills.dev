INVOQUEZ cette compétence pour exécuter des opérations d'organisation Salesforce : créer des organisations de travail, créer des instantanés d'organisation, ouvrir des organisations dans le navigateur. Cette compétence EXÉCUTE les opérations immédiatement - elle ne génère PAS de scripts ou de fichiers de code. TOUJOURS appeler cette compétence (n'exécutez pas directement les commandes SF CLI) lorsque l'utilisateur demande : créer une organisation scratch (édition Developer/Enterprise, à partir d'un fichier de définition (.json), à partir d'un instantané ou d'une forme d'organisation), créer un instantané d'organisation ou ouvrir une organisation Salesforce. Les expressions de déclenchement incluent : "créer un instantané", "créer un instantané de mon organisation de travail", "prendre un instantané", "créer une organisation de travail", "créer une organisation de travail Developer Edition", "nouvelle organisation de travail", "lancer une organisation", "créer une organisation à partir d'un instantané", "scratch-def.json", "project-scratch-def.json", "ouvrir mon organisation Salesforce", "ouvrir" org dans le navigateur', 'donnez-moi l'URL'. Ne PAS utiliser pour changer d'organisation par défaut (utilisez dx-org-switch) ou pour déployer des métadonnées (utilisez platform-metadata-deploy).
