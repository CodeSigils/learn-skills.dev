Crea un WorkItem del Centro DevOps para realizar un seguimiento de una solución para una falla de prueba o una infracción del Analizador de código. Antes de crear algo, muestra una vista previa del tema/asignado/proyecto y requiere confirmación explícita. Utilice esta habilidad cuando desee crear un elemento de trabajo de reparación, realizar un seguimiento de una tarea de corrección o asignar una falla de prueba o análisis a un desarrollador. DISPARAR cuando: el usuario desea crear un elemento de trabajo de reparación, registrar una corrección o asignar una falla a un desarrollador para su resolución. NO DISPARE cuando: escriba el código de reparación en sí (use generate-apex).
