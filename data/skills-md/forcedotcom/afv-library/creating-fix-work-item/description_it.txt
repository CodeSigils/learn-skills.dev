Crea un elemento di lavoro DevOps Center per tenere traccia di una correzione per un errore di test o una violazione dell'analizzatore di codice. Prima di creare qualsiasi cosa, mostra un'anteprima del soggetto/assegnatario/progetto e richiede una conferma esplicita. Utilizza questa competenza quando desideri creare un elemento di lavoro di correzione, tenere traccia di un'attività di correzione o assegnare un errore di test o analisi a uno sviluppatore. ATTIVA quando: l'utente desidera creare un elemento di lavoro di correzione, registrare una riparazione o assegnare un errore a uno sviluppatore per la risoluzione. NON SI ATTIVA quando: si scrive il codice di correzione stesso (usa generation-apex).
