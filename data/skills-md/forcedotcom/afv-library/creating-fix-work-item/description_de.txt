Erstellt ein DevOps Center WorkItem, um einen Fix für einen Testfehler oder einen Code-Analysator-Verstoß zu verfolgen. Bevor etwas erstellt wird, wird eine Betreff-/Beauftragten-/Projektvorschau angezeigt und erfordert eine ausdrückliche Bestätigung. Verwenden Sie diese Fähigkeit, wenn Sie ein Fix-Arbeitselement erstellen, eine Behebungsaufgabe verfolgen oder einem Entwickler einen Test- oder Analysefehler zuweisen möchten. TRIGGER, wenn: Der Benutzer ein Fix-Arbeitselement erstellen, eine Behebung protokollieren oder einen Fehler einem Entwickler zur Lösung zuweisen möchte. NICHT AUSLÖSEN, wenn: der Fixcode selbst geschrieben wird (generierender Apex verwenden).
