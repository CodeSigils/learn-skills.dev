Generazione, ottimizzazione e analisi di query SOQL con punteggio di 100 punti. Utilizzare questa competenza quando l'utente necessita di creazione o ottimizzazione SOQL/SOSL: generazione di linguaggio naturale per query, query di relazione, aggregati, analisi del piano di query e miglioramenti delle prestazioni o della sicurezza per le query Salesforce. SI ATTIVA quando: l'utente scrive, ottimizza o esegue il debug di query SOQL/SOSL, tocca file .soql o chiede informazioni su query di relazione, aggregazioni o prestazioni delle query. NON SI ATTIVA quando: operazioni di dati in blocco (utilizzare platform-data-manage), logica DML Apex (utilizzare platform-apex-generate) o query di report/dashboard.
