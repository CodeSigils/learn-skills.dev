نقطة الدخول لإنشاء أي تطبيق جوال أصلي من Salesforce على iOS أو Android. يتم تشغيله عندما يقول المستخدم: "إنشاء تطبيق Salesforce iOS"، أو "إضافة تسجيل دخول Salesforce إلى تطبيق Android الخاص بي"، أو "إعداد Mobile SDK"، أو "إضافة مساحة تخزين غير متصلة بالإنترنت لـ MobileSync / SmartStore"، أو "تضمين وكيل Agentforce في تطبيق الهاتف المحمول الخاص بي"، أو "إضافة دردشة Agentforce إلى iOS/Android"، أو يطلب إنشاء تجربة Salesforce للهاتف المحمول أو توسيعها أو دمجها في Swift أو Kotlin (MSDK أو Agentforce SDK أو كليهما). قم بالتخطي عندما يقوم المستخدم بإنشاء تطبيق جوال غير تابع لـ Salesforce، باستخدام React Native / Flutter / Ionic بدون تكامل Salesforce، أو السؤال عن تصميم عام لواجهة مستخدم الهاتف المحمول، أو العمل على سطح ويب/سطح مكتب مجاور لـ Salesforce (LWC، Experience Cloud، العلامة التجارية Mobile Publisher فقط).
