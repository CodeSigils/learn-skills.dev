Utilice esta habilidad cuando los usuarios necesiten crear o configurar aplicaciones personalizadas de Salesforce basadas en pestañas con anulaciones de navegación, marca y acciones. Se activa cuando los usuarios mencionan aplicaciones personalizadas, metadatos de aplicaciones, navegación de aplicaciones u organización de pestañas en aplicaciones. Úselo cuando los usuarios quieran crear contenedores de aplicaciones para pestañas y páginas. NO lo use cuando el objetivo sea alojar un paquete de React UI en el Iniciador de aplicaciones; use experiencia-ui-bundle-custom-app-generate en ese caso.
