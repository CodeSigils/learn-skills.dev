Empfiehlt und verwaltet DevOps Center-Testsuite-Zuweisungen für Pipeline-Stufen. Modus A analysiert einen Commit-Diff mit zugewiesenen Suite-Metadaten, um relevante vorhandene Suiten zu empfehlen und Abdeckungslücken zu kennzeichnen (reine Argumentation). Die Modi B–D weisen über die testSuiteStages Connect-API eine einzelne Suite zu, ordnen mehrere Suiten mit einer obligatorischen Auswirkungsvorschau in großen Mengen zu oder fügen Testklassen mit Governance-Regeln hinzu bzw. entfernen sie. Verwenden Sie diese Fähigkeit, um Suiten für einen Commit zu empfehlen, Suiten Phasen zuzuweisen oder zuzuordnen oder Tests in einer Suite hinzuzufügen/zu entfernen. TRIGGER, wenn: der Benutzer fragt, welche Suiten für einen Commit/Diff ausgeführt werden sollen oder was seine Änderungen abdeckt; Eine Suite ist nicht verknüpft und der Benutzer möchte, dass sie zugewiesen wird. Der Benutzer möchte Suite-zu-Stufen-Zuordnungen konfigurieren, mehrere Suiten zuweisen oder Tests in einer Suite hinzufügen/entfernen/synchronisieren. NICHT AUSLÖSEN, wenn: ein Testanbieter konfiguriert oder synchronisiert wird (verwenden Sie dx-devops-test-pipeline-configure), Suiten ausgeführt werden (verwenden Sie dx-devops-test-suite-run) oder Tests direkt erstellt/ausgeführt werden (verwenden Sie platform-apex-test-generate oder platform-apex-test-run).
