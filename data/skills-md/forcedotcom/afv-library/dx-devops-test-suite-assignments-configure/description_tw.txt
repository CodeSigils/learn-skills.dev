推薦和管理 DevOps 中心測試套件的管道階段分配。模式 A 根據分配的套件元資料分析提交差異，以推薦相關的現有套件並標記覆蓋範圍差距（純粹推理）。 B-D 模式透過 testSuiteStages Connect API 分配單一套件、使用強制影響預覽批次來對應多個套件，或使用治理規則新增/刪除測試類別。使用此技能推薦用於提交的套件，將套件分配或映射到階段，或新增/刪除套件中的測試。觸發時間：用戶詢問要運行哪些套件來進行提交/差異或哪些套件涵蓋了他們的更改；套件未連結且用戶希望對其進行分配；用戶想要配置套件到階段的映射、分配多個套件或在套件中添加/刪除/同步測試。請勿在下列情況下觸發：設定或同步測試提供者（使用 dx-devops-test-pipeline-configure）、執行套件（使用 dx-devops-test-suite-run）或直接編寫/執行測試（使用 platform-apex-test-generate 或 platform-apex-test-run）。
