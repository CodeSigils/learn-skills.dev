Recomienda y gestiona las asignaciones del conjunto de pruebas del Centro DevOps para las etapas del proceso. El modo A analiza una diferencia de confirmación con respecto a los metadatos de la suite asignada para recomendar suites existentes relevantes y marcar brechas de cobertura (razonamiento puro). Los modos B-D asignan un único conjunto, asignan de forma masiva varios conjuntos con una vista previa de impacto obligatoria o agregan o eliminan clases de prueba con reglas de gobernanza, a través de la API testSuiteStages Connect. Utilice esta habilidad para recomendar conjuntos para una confirmación, asignar o asignar conjuntos a etapas, o agregar o eliminar pruebas en un conjunto. DISPARAR cuando: el usuario pregunta qué suites ejecutar para una confirmación/diferencia o qué cubre sus cambios; una suite está desvinculada y el usuario quiere que se le asigne; el usuario desea configurar asignaciones de suite a etapa, asignar varias suites o agregar/eliminar/sincronizar pruebas en una suite. NO DISPARE cuando: configure o sincronice un proveedor de pruebas (use dx-devops-test-pipeline-configure), ejecute suites (use dx-devops-test-suite-run) o cree/ejecute pruebas directamente (use platform-apex-test-generate o platform-apex-test-run).
