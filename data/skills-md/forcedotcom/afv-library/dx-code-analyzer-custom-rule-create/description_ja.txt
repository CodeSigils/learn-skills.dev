Regex (パターン マッチング)、PMD (Apex およびメタデータ XML の XPath/AST)、および ESLint (LWC/JavaScript/TypeScript) 用のカスタム コード アナライザー ルールを作成します。ユーザーがコーディング標準の強制、パターンの禁止、ハードコードされた値の検出、メタデータの管理、または組み込みセットにないルールの追加を行う場合に使用します。トリガーのタイミング: ユーザーが「ルールを作成する」、「System.debug を禁止する」、「命名規則を強制する」、「ハードコードされた ID を検出する」、「カスタム ルール」、「Xpath ルール」、「正規表現ルール」、「PMD ルールを追加する」、「ポリシーを強制する」、「チェックを作成する」、「このパターンにフラグを立てる」、「キャッチするルールを作成する」、「メタデータ ルール」、 「権限の確認」、「API バージョンの適用」、「eslint ルール」、「lwc ルール」、「ルールのしきい値の上書き」、「複雑さのカスタマイズ」、または適用するパターンの説明。次の場合はトリガーしないでください: ユーザーがスキャンの実行 (dx-code-analyzer-run を使用)、エンジンの構成 (dx-code-analyzer-configure を使用)、または既存のルールの説明 (dx-code-analyzer-run を使用) を希望している場合。
