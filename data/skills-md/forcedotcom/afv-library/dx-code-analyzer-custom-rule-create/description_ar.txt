قم بإنشاء قواعد محلل الأكواد المخصصة لـ Regex (مطابقة الأنماط)، وPMD (XPath/AST لـ Apex وبيانات التعريف XML)، وESLint (LWC/JavaScript/TypeScript). يُستخدم عندما يريد المستخدمون فرض معايير الترميز، أو حظر الأنماط، أو اكتشاف القيم المضمنة، أو التحكم في بيانات التعريف، أو إضافة قواعد غير موجودة في المجموعة المضمنة. يتم تشغيله عندما: يقول المستخدم "إنشاء قاعدة"، "حظر System.debug"، "فرض اصطلاح التسمية"، "اكتشاف المعرفات المشفرة"، "قاعدة مخصصة"، "قاعدة xpath"، "قاعدة regex"، "إضافة قاعدة PMD"، "فرض سياسة"، "إنشاء فحص لـ"، "وضع علامة على هذا النمط"، "إنشاء قاعدة تلتقط"، "قاعدة بيانات التعريف"، "التحقق من الأذونات"، "فرض واجهة برمجة التطبيقات" الإصدار"، أو "قاعدة eslint"، أو "قاعدة lwc"، أو "تجاوز عتبة القاعدة"، أو "تخصيص التعقيد"، أو يصف نمطًا يجب فرضه. لا تقم بالتشغيل عندما: يريد المستخدم إجراء فحص (استخدم dx-code-analyzer-run)، أو تكوين المحركات (استخدم dx-code-analyzer-configure)، أو شرح القواعد الحالية (استخدم dx-code-analyzer-run).
