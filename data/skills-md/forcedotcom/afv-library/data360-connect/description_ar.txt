مرحلة Salesforce Data Cloud Connect. استخدم هذه المهارة عندما يقوم المستخدم بإدارة اتصالات Data Cloud أو الموصلات أو إعداد نظام مصدر جديد. يتم التشغيل عندما: يقوم المستخدم بإدارة اتصالات Data Cloud أو الموصلات أو بيانات تعريف الموصل أو اختبار الاتصال أو تصفح الكائنات المصدر أو قواعد البيانات أو إعداد نظام مصدر جديد. لا تقم بالتشغيل عندما: تتعلق المهمة بتدفقات البيانات أو DLOs (استخدم إعداد data360)، أو DMOs أو تحليل الهوية (استخدم تنسيق data360)، أو الاسترجاع/البحث (استخدم استعلام data360)، أو قياس STDM عن بعد (استخدم agentforce-observe).
