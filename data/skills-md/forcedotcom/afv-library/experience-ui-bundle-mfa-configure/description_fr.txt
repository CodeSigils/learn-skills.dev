Configurez l'authentification multifacteur (MFA) pour les utilisateurs de Salesforce Experience Site. DÉCLENCHEMENT lorsque : l'utilisateur souhaite activer MFA sur une communauté, appliquer l'authentification à deux facteurs pour les utilisateurs du portail, ajouter MFA à un site/application Web React Experience, configurer l'autorisation ForceTwoFactor, créer des ensembles d'autorisations MFA pour les utilisateurs externes ou dépanner MFA n'apparaissant pas lors de la connexion. Se déclenche également sur : la communauté MFA, le portail à deux facteurs, l'ensemble d'autorisations ForceTwoFactor, MFA Experience Cloud, le site MFA React, la communauté de vérification d'identité, le site d'expérience MFA, ForceTwoFactor permissionset-meta.xml, MFA permissionset-meta.xml. NE PAS DÉCLENCHER lorsque : la configuration de l'AMF à l'échelle de l'organisation pour les utilisateurs internes (c'est-à-dire Configuration > Vérification de l'identité), la création de composants d'interface utilisateur de connexion personnalisés (utilisez experience-ui-bundle-frontend-generate) ou la génération d'ensembles d'autorisations génériques sans contexte MFA (utilisez platform-permission-set-generate).
