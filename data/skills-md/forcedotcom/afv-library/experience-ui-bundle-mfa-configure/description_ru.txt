Настройте многофакторную аутентификацию (MFA) для пользователей сайта Salesforce Experience. ЗАПУСКАЕТСЯ, когда: пользователь хочет включить MFA в сообществе, обеспечить двухфакторную аутентификацию для пользователей портала, добавить MFA на сайт или веб-приложение React Experience, настроить разрешение ForceTwoFactor, создать наборы разрешений MFA для внешних пользователей или устранить неполадки, связанные с отсутствием MFA при входе в систему. Также активируется: сообщество MFA, двухфакторный портал, набор разрешений ForceTwoFactor, облако MFA Experience Cloud, сайт MFA React, сообщество проверки личности, сайт опыта MFA, набор разрешений ForceTwoFactor-meta.xml, набор разрешений MFA-meta.xml. НЕ ЗАПУСКАЕТСЯ при: настройке MFA в масштабах всей организации для внутренних пользователей (это Настройка > Проверка личности), создании пользовательских компонентов пользовательского интерфейса входа в систему (используйте experience-ui-bundle-frontend-generate) или создании общих наборов разрешений без контекста MFA (используйте Platform-permission-set-generate).
