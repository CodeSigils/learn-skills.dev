Úselo cuando la necesidad de datos de un componente web Lightning se describe en un lenguaje natural ambiguo: convierta "obtener información de contacto" o "mostrar datos de cuenta" en una especificación de requisitos de datos clara y lista para PRD. DISPARAR cuando el usuario dice "definir requisitos de datos para este LWC", "convertir esta sección de datos PRD en nombres de campo/objeto validados", "recomendar GraphQL vs UIAPI para esta necesidad de datos", "validar estos nombres de API de Salesforce" o "especificar el adaptador LDS para este componente", o hace referencia a archivos de paquete LWC (`.js`, `.js-meta.xml`) cuya capa de datos aún no está especificada. NO DISPARE cuando la capa de datos ya esté completamente especificada, cuando cree la consulta real o el código del adaptador a partir de una especificación conocida, o cuando implemente un LWC de un extremo a otro (use experiencia-lwc-generate).
