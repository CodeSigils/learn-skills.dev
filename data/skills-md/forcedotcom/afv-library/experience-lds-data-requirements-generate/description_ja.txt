Lightning Web コンポーネントのデータニーズがあいまいな自然言語で記述されている場合に使用します。「連絡先情報の取得」または「アカウントデータの表示」を明確な PRD 対応のデータ要件仕様に変換します。ユーザーが「この LWC のデータ要件を定義する」、「この PRD データ セクションを検証済みのオブジェクト/フィールド名に変換する」、「このデータのニーズに対して GraphQL と UIAPI を推奨する」、「これらの Salesforce API 名を検証する」、または「このコンポーネントの LDS アダプターを指定する」と述べた場合、またはデータ層がまだ指定されていない LWC バンドル ファイル (`.js`、`.js-meta.xml`) を参照したときにトリガーされます。データ層がすでに完全に指定されている場合、既知の仕様に基づいて実際のクエリまたはアダプター コードを作成する場合、または LWC をエンドツーエンドで実装する場合 ( experience-lwc-generate を使用する) にはトリガーしないでください。
