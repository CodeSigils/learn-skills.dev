À utiliser lorsqu'un besoin en données d'un composant Web Lightning est décrit dans un langage naturel ambigu : transformez « obtenir les informations de contact » ou « afficher les données du compte » en une spécification claire et prête pour le PRD. DÉCLENCHEMENT lorsque l'utilisateur dit « définir les exigences en matière de données pour ce LWC », « transformer cette section de données PRD en noms d'objet/champ validés », « recommander GraphQL vs UIAPI pour ce besoin de données », « valider ces noms d'API Salesforce » ou « spécifier l'adaptateur LDS pour ce composant », ou fait référence aux fichiers de bundle LWC (`.js`, `.js-meta.xml`) dont la couche de données n'est pas encore spécifiée. NE PAS DÉCLENCHER lorsque la couche de données est déjà entièrement spécifiée, lors de la création de la requête réelle ou du code de l'adaptateur à partir d'une spécification connue, ou lors de l'implémentation d'un LWC de bout en bout (utilisez experience-lwc-generate).
