Da utilizzare quando l'esigenza di dati di un componente Lightning Web è descritta in un linguaggio naturale ambiguo: trasforma "ottieni informazioni di contatto" o "mostra dati dell'account" in specifiche sui requisiti dei dati chiare e predisposte per PRD. SI ATTIVA quando l'utente dice "definisci i requisiti dei dati per questo LWC", "trasforma questa sezione di dati PRD in nomi di oggetto/campo convalidati", "consiglia GraphQL vs UIAPI per questa esigenza di dati", "convalida questi nomi API Salesforce" o "specifica l'adattatore LDS per questo componente" o fa riferimento a file bundle LWC (`.js`, `.js-meta.xml`) il cui livello dati non è ancora specificato. NON SI ATTIVA quando il livello dati è già completamente specificato, quando si crea la query effettiva o il codice dell'adattatore da una specifica nota o quando si implementa un LWC end-to-end (utilizzare experience-lwc-generate).
