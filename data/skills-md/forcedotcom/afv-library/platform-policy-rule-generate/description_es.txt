Utilice esta habilidad al crear metadatos XML de PolicyRuleDefinition y PolicyRuleDefinitionSet para Salesforce Enforce-O-Matic MDAPI (políticas de gobierno de nube de datos), o al editar archivos *.policyRuleDefinition / *.policyRuleDefinitionSet. Cubre el árbol de decisión de categorías, el esquema completo para todas las variantes de políticas (ACCESS, GOVERNANCE, RECORD, TRANSFORM), reglas de compatibilidad de UI para Data Governance Policy Builder y barreras de seguridad de validación. NO utilice esta habilidad para UserAccessPolicy, AccessPolicy, SharingRules, PermissionSet o cualquier metadato de control de acceso que no sea Enforce-O-Matic; estos tienen sus propios tipos y viven fuera del esquema PolicyRuleDefinition.
