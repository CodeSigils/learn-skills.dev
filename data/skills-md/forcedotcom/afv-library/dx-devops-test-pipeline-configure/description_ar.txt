تكوين البنية الأساسية لاختبار خط أنابيب DevOps Center: تمكين موفر الاختبار حتى تصبح أجنحته متاحة، أو إعادة مزامنة الموفر الذي تم تكوينه لسحب مجموعات جديدة، أو إنشاء بوابة جودة بقواعد على المسرح. يتم التوجيه حسب النية عبر ثلاثة أوضاع بعد تشغيل اختبارات المتطلبات الأساسية المشتركة وبوابة تأكيد صريحة. استخدم هذه المهارة عندما يريد المستخدم إعداد موفر اختبار أو تكوينه أو تمكينه أو مزامنته أو تحديثه، أو تعيين/تكوين بوابة الجودة أو حد التغطية في مرحلة خط أنابيب DevOps Center. يتم التشغيل عندما: يريد المستخدم تكوين/تمكين/إضافة/إعداد موفر اختبار، أو إعادة مزامنة أو تحديث قائمة مجموعة الموفر، أو سحب مجموعات جديدة، أو تعيين/تكوين بوابة الجودة، أو حد التغطية، أو اختبار المعيار على المسرح. لا تقم بالتشغيل عند: تعيين مجموعات موجودة لمرحلة (استخدم dx-devops-test-suite-assistant-configure)، أو تشغيل مجموعة أو إعادة تشغيلها (استخدم dx-devops-test-suite-run)، أو عمل غير تابع لـ DevOps-Center.
