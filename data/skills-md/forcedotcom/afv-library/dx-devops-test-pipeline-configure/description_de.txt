Konfiguriert die Testinfrastruktur der DevOps Center-Pipeline: Ermöglicht einem Testanbieter, dass seine Suiten verfügbar werden, synchronisiert einen konfigurierten Anbieter neu, um neue Suiten einzubinden, oder erstellt ein Qualitätstor mit Regeln auf einer Bühne. Leitet nach Absicht über drei Modi weiter, nachdem gemeinsame Voraussetzungsprüfungen und ein explizites Bestätigungsgate ausgeführt wurden. Verwenden Sie diese Fähigkeit, wenn ein Benutzer einen Testanbieter einrichten, konfigurieren, aktivieren, synchronisieren oder aktualisieren oder ein Qualitäts-Gate oder einen Abdeckungsschwellenwert in einer DevOps Center-Pipeline-Phase festlegen/konfigurieren möchte. TRIGGER, wenn: der Benutzer einen Testanbieter konfigurieren/aktivieren/hinzufügen/einrichten, die Suite-Liste eines Anbieters neu synchronisieren oder aktualisieren, neue Suites einbinden oder ein Qualitätsgate, einen Abdeckungsschwellenwert oder einen Test-Benchmark auf einer Stufe festlegen/konfigurieren möchte. NICHT AUSLÖSEN, wenn: bestehende Suiten einer Phase zugewiesen werden (verwenden Sie dx-devops-test-suite-assignments-configure), eine Suite ausgeführt oder erneut ausgelöst wird (verwenden Sie dx-devops-test-suite-run) oder Arbeiten außerhalb des DevOps-Centers.
