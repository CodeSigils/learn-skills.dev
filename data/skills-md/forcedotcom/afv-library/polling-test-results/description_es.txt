Sondea la ejecución de una prueba asíncrona de DevOps Center mediante runId hasta que se completa, falla o se agota el tiempo de espera (utilizando SOQL de solo lectura en el registro de ejecución en intervalos específicos del proveedor (Apex 15 s/5 m, Code Analyzer 10 s/3 m, Provar UI 60 s/20 m, Flow 20 s/8 m)) y luego muestra los resultados. Utilice esta habilidad cuando se esté ejecutando un conjunto de pruebas y el usuario esté esperando los resultados, o inmediatamente después de ejecutar un conjunto. DISPARAR cuando: se está ejecutando una suite de pruebas y el usuario está esperando los resultados, o inmediatamente después de ejecutar una suite y hay un runId disponible. NO DISPARAR cuando: no hay ningún runId activo.
