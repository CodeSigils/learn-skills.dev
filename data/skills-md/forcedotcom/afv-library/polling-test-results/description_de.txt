Fragt eine asynchrone DevOps Center-Testausführung nach runId ab, bis sie abgeschlossen ist, fehlschlägt oder eine Zeitüberschreitung auftritt – mithilfe von schreibgeschütztem SOQL für den Ausführungsdatensatz in anbieterspezifischen Intervallen (Apex 15 Sek./5 Min., Code Analyzer 10 Sek./3 Min., Provar UI 60 Sek./20 Min., Flow 20 Sek./8 Min.) – und zeigt dann Ergebnisse an. Verwenden Sie diese Fähigkeit, wenn eine Testsuite ausgeführt wird und der Benutzer auf Ergebnisse wartet, oder unmittelbar nach der Ausführung einer Suite. TRIGGER, wenn: eine Testsuite ausgeführt wird und der Benutzer auf Ergebnisse wartet, oder unmittelbar nach der Ausführung einer Suite und eine runId verfügbar ist. NICHT AUSLÖSEN, wenn: keine aktive RunId vorhanden ist.
