Utilice esta habilidad cuando los usuarios necesiten crear, generar o validar metadatos de tipos de informes personalizados de Salesforce. Se activa cuando los usuarios mencionan tipos de informes personalizados, tipos de informes, CRT, marcos de informes, informes entre objetos, fuentes de datos del generador de informes o solicitan exponer campos para generar informes entre objetos relacionados. Utilícelo también cuando los usuarios mencionen objetos principales y relacionados para informes, uniones internas y externas en informes, categorías de tipos de informes o encuentren errores de implementación para archivos .reportType-meta.xml. NO lo active para: ejecutar, editar o filtrar informes existentes; crear carpetas de informes, paneles o vistas de lista; o preguntas generales sobre informes que no implican la creación de un archivo .reportType-meta.xml.
