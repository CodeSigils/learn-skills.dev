Utilizzare questa competenza quando gli utenti devono creare, generare o convalidare i metadati del tipo di rapporto personalizzato Salesforce. Si attiva quando gli utenti menzionano tipi di report personalizzati, tipi di report, CRT, framework di reporting, report tra oggetti, origini dati del generatore di report o chiedono di esporre campi per il reporting su oggetti correlati. Da utilizzare anche quando gli utenti menzionano oggetti primari e correlati per report, join interni ed esterni nei report, categorie di tipi di report o riscontrano errori di distribuzione per file .reportType-meta.xml. NON attivare per: eseguire, modificare o filtrare report esistenti; creazione di cartelle di report, dashboard o visualizzazioni elenco; o domande generali sui rapporti che non implicano la creazione di un file .reportType-meta.xml.
