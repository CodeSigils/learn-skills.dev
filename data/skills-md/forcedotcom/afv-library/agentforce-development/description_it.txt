Utilizza questa competenza quando lavori con Salesforce Agent Script, il linguaggio di scripting per la creazione di agenti Agentforce utilizzando Atlas Reasoning Engine. I trigger includono: creazione, modifica o comprensione degli agenti Agent Script; lavorare con file AiAuthoringBundle o file .agent; progettazione di grafici tematici o controllo del flusso; produrre o aggiornare una specifica dell'agente; convalida dello script dell'agente o diagnosi degli errori di compilazione; visualizzare in anteprima gli agenti o eseguire il debug di problemi comportamentali; distribuire, pubblicare, attivare o disattivare agenti; eliminare o rinominare gli agenti; creare specifiche di test AiEvaluationDefinition o eseguire test dell'agente. Questa abilità insegna lo script dell'agente da zero: i modelli di intelligenza artificiale non hanno dati di addestramento precedenti su questo linguaggio. NON utilizzare per lo sviluppo Apex, la creazione di flussi, la creazione di modelli di prompt, la configurazione di Experience Cloud o attività generali della CLI di Salesforce non correlate allo script dell'agente.
