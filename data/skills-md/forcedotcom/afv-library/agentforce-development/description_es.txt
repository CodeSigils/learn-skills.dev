Utilice esta habilidad cuando trabaje con Salesforce Agent Script, el lenguaje de secuencias de comandos para crear agentes Agentforce utilizando Atlas Reasoning Engine. Los desencadenantes incluyen: crear, modificar o comprender agentes Agent Script; trabajar con archivos AiAuthoringBundle o archivos .agent; diseñar gráficos de temas o control de flujo; producir o actualizar una especificación de agente; validar Agent Script o diagnosticar errores de compilación; previsualizar agentes o depurar problemas de comportamiento; implementar, publicar, activar o desactivar agentes; eliminar o cambiar el nombre de los agentes; crear especificaciones de prueba de AiEvaluaciónDefinition o ejecutar pruebas de agente. Esta habilidad enseña Agent Script desde cero: los modelos de IA no tienen datos de entrenamiento previo en este lenguaje. NO lo use para desarrollo de Apex, creación de flujo, creación de plantillas de solicitud, configuración de Experience Cloud o tareas generales de CLI de Salesforce no relacionadas con Agent Script.
