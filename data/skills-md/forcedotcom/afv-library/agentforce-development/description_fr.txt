Utilisez cette compétence lorsque vous travaillez avec Salesforce Agent Script, le langage de script permettant de créer des agents Agentforce à l'aide du moteur de raisonnement Atlas. Les déclencheurs incluent : la création, la modification ou la compréhension des agents Agent Script ; travailler avec des fichiers AiAuthoringBundle ou des fichiers .agent ; concevoir des graphiques thématiques ou un contrôle de flux ; produire ou mettre à jour une spécification d'agent ; valider le script de l'agent ou diagnostiquer les erreurs de compilation ; prévisualiser les agents ou déboguer les problèmes de comportement ; déployer, publier, activer ou désactiver des agents ; supprimer ou renommer des agents ; création de spécifications de test AiEvaluationDefinition ou exécution de tests d'agent. Cette compétence enseigne Agent Script à partir de zéro : les modèles d'IA n'ont aucune donnée de formation préalable sur ce langage. Ne PAS utiliser pour le développement Apex, la création de flux, la création de modèles d'invite, la configuration Experience Cloud ou les tâches générales de Salesforce CLI sans rapport avec le script d'agent.
