Nutzen Sie diese Fähigkeit, wenn Sie mit Salesforce Agent Script arbeiten – der Skriptsprache zum Erstellen von Agentforce-Agenten mithilfe der Atlas Reasoning Engine. Zu den Auslösern gehören: Erstellen, Ändern oder Verstehen von Agent-Skript-Agenten; Arbeiten mit AiAuthoringBundle-Dateien oder .agent-Dateien; Entwerfen von Themendiagrammen oder Flusskontrolle; Erstellen oder Aktualisieren einer Agentenspezifikation; Validierung von Agent-Skripten oder Diagnose von Kompilierungsfehlern; Anzeigen einer Vorschau von Agenten oder Beheben von Verhaltensproblemen; Bereitstellen, Veröffentlichen, Aktivieren oder Deaktivieren von Agenten; Löschen oder Umbenennen von Agenten; Verfassen von AiEvaluationDefinition-Testspezifikationen oder Ausführen von Agententests. Diese Fähigkeit lehrt Agent Script von Grund auf – KI-Modelle verfügen über keine vorherigen Trainingsdaten für diese Sprache. NICHT für Apex-Entwicklung, Flow-Erstellung, Erstellung von Eingabeaufforderungsvorlagen, Experience Cloud-Konfiguration oder allgemeine Salesforce-CLI-Aufgaben verwenden, die nichts mit Agent-Skript zu tun haben.
