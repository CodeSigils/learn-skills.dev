このスキルは、Atlas Reasoning Engine を使用して Agentforce エージェントを作成するためのスクリプト言語である Salesforce Agent Script を操作するときに使用します。トリガーには、エージェント スクリプト エージェントの作成、変更、または理解が含まれます。 AiAuthoringBundle ファイルまたは .agent ファイルを操作する。トピックグラフまたはフロー制御の設計。エージェント仕様を作成または更新する。エージェント スクリプトの検証またはコンパイル エラーの診断。エージェントのプレビューまたは動作上の問題のデバッグ。エージェントの展開、公開、アクティブ化、または非アクティブ化。エージェントの削除または名前変更。 AiEvaluationDefinition テスト仕様の作成またはエージェント テストの実行。このスキルは、エージェント スクリプトをゼロから教えます。AI モデルには、この言語に関する事前トレーニング データがありません。 Apex 開発、フロー構築、プロンプトテンプレートの作成、Experience Cloud 設定、またはエージェントスクリプトに関係のない一般的な Salesforce CLI タスクには使用しないでください。
