Fase de Ley Salesforce Data Cloud. Utilice esta habilidad cuando el usuario administre activaciones, objetivos de activación, acciones de datos o entrega posterior de audiencias y datos de Data Cloud. DISPARAR cuando: el usuario gestiona activaciones, objetivos de activación, acciones de datos o entrega posterior de audiencias y datos de Data Cloud. NO DISPARAR cuando: la tarea es la creación de segmentos (use segmenting-datacloud), recuperación de datos/trabajo de búsqueda (use retrieving-datacloud) o STDM/rastreo de sesiones (use observer-agentforce).
