Fase Salesforce Data Cloud Act. Utilizza questa competenza quando l'utente gestisce attivazioni, obiettivi di attivazione, azioni dati o distribuzione downstream di segmenti di pubblico e dati di Data Cloud. TRIGGER quando: l'utente gestisce le attivazioni, gli obiettivi di attivazione, le azioni sui dati o la distribuzione downstream di segmenti di pubblico e dati di Data Cloud. NON ATTIVARE quando: l'attività è la creazione di segmenti (utilizzare segmenting-datacloud), il recupero/ricerca dei dati (utilizzare retrieving-datacloud) o il tracciamento STDM/sessione (utilizzare Observing-agentforce).
