مرحلة قانون سحابة بيانات Salesforce. استخدم هذه المهارة عندما يدير المستخدم عمليات التنشيط أو أهداف التنشيط أو إجراءات البيانات أو التسليم النهائي لجماهير وبيانات Data Cloud. يتم التشغيل عندما: يقوم المستخدم بإدارة عمليات التنشيط أو أهداف التنشيط أو إجراءات البيانات أو التسليم النهائي لجماهير وبيانات Data Cloud. لا تقم بالتشغيل عندما: تكون المهمة هي إنشاء مقطع (استخدم تجزئة البيانات السحابية)، أو عمل استرجاع/بحث البيانات (استخدم استرداد البيانات السحابية)، أو تتبع STDM/الجلسة (استخدم قوة وكيل المراقبة).
