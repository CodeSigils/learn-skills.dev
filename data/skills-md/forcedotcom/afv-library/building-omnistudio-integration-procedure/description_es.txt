Creación y validación de procedimientos de integración OmniStudio con puntuación de 110 puntos. Utilice esta habilidad al crear orquestaciones de procesos del lado del servidor que combinen acciones de Data Mapper, acciones remotas de Apex, llamadas HTTP y lógica condicional. SE DISPARA cuando: el usuario crea procedimientos de integración, agrega pasos del asignador de datos, configura acciones remotas o revisa las configuraciones de IP existentes. NO DISPARE cuando: cree OmniScripts (use building-omnistudio-omniscript), cree Data Mappers directamente (use building-omnistudio-datamapper) o analice dependencias entre componentes (use analysing-omnistudio-dependencies).
