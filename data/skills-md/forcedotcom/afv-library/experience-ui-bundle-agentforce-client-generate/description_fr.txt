Utilisez cette compétence lorsque l'utilisateur demande à ajouter, intégrer, intégrer, configurer, styliser ou supprimer un agent, un chatbot, un widget de chat, un client de conversation ou un assistant IA dans un projet UI Bundle. DÉCLENCHEMENT lorsque : le projet contient un répertoire uiBundles/*/src/ et que la tâche implique l'ajout ou la modification d'un widget de chat, d'un chatbot ou d'une IA conversationnelle ; fichiers sous uiBundles/*/src/ import AgentforceConversationClient ; l'utilisateur demande à ajouter une fonctionnalité de chat ou d'agent à une page. NE PAS DÉCLENCHER lorsque : l'utilisateur souhaite créer un composant d'agent personnalisé, de chatbot ou de widget de chat à partir de zéro ; le projet n'a pas de répertoire uiBundles.
