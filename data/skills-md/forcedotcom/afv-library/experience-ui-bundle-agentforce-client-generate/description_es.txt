Utilice esta habilidad cuando el usuario solicite agregar, incrustar, integrar, configurar, diseñar o eliminar un agente, chatbot, widget de chat, cliente de conversación o asistente de IA en un proyecto de paquete de interfaz de usuario. DISPARAR cuando: el proyecto contiene un directorio uiBundles/*/src/ y la tarea implica agregar o modificar un widget de chat, chatbot o IA conversacional; archivos en uiBundles/*/src/ import AgentforceConversationClient; El usuario solicita agregar cualquier funcionalidad de chat o agente a una página. NO DISPARAR cuando: el usuario quiera crear un agente personalizado, un chatbot o un componente de widget de chat desde cero; el proyecto no tiene un directorio uiBundles.
