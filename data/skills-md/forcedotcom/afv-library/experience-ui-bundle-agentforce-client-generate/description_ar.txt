استخدم هذه المهارة عندما يطلب المستخدم إضافة أو تضمين أو دمج أو تكوين أو تصميم أو إزالة وكيل أو chatbot أو عنصر واجهة المستخدم للدردشة أو عميل المحادثة أو مساعد AI في مشروع UI Bundle. يتم التشغيل عندما: يحتوي المشروع على دليل uiBundles/*/src/ وتتضمن المهمة إضافة أو تعديل أداة دردشة أو chatbot أو الذكاء الاصطناعي للمحادثة؛ الملفات الموجودة ضمن uiBundles/*/src/ import AgentforceConversationClient; يطلب المستخدم إضافة أي وظيفة دردشة أو وكيل إلى الصفحة. لا تقم بالتشغيل عندما: يريد المستخدم إنشاء وكيل مخصص، أو chatbot، أو مكون عنصر واجهة المستخدم للدردشة من البداية؛ لا يحتوي المشروع على دليل uiBundles.
