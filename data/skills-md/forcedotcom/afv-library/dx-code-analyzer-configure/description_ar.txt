قم بإعداد وتكوين واستكشاف أخطاء Salesforce Code Analyzer لأي مشروع. يتعامل مع التثبيت، وفحوصات المتطلبات الأساسية، وتشخيص الإعدادات المعطلة، وإنشاء تجاوزات code-analyzer.yml وتحريرها، والإعدادات الخاصة بالمحرك، وتجاهل الأنماط، وتجاوزات الخطورة، وإعداد خط أنابيب CI/CD. تشغيل عندما: يقول المستخدم "إعداد محلل التعليمات البرمجية"، "تكوين محلل التعليمات البرمجية"، "تثبيت محلل التعليمات البرمجية"، "محلل التعليمات البرمجية لا يعمل"، "إصلاح الإعداد الخاص بي"، "فشل المسح"، "التحقق من الإعداد"، "تم تثبيت محلل التعليمات البرمجية"، "تمكين / تعطيل المحرك"، "استبعاد الملفات"، "خطورة التغيير"، "إعداد إجراءات GitHub"، "إعداد CI/CD"، "إضافة محلل التعليمات البرمجية إلى خط الأنابيب"، "جعل خط الأنابيب يفشل"، أو "تحديث سير العمل الخاص بي"، أو "بوابة الجودة"، أو "الفشل عند الانتهاكات"، أو "فحص الملفات التي تم تغييرها فقط"، أو "إضافة SARIF"، أو "code-analyzer.yml"، أو "ESLint config"، أو "زيادة ذاكرة SFGE"، أو الإبلاغ عن أخطاء أثناء تشغيل Code Analyzer. لا تقم بالتشغيل عندما: يريد المستخدم إجراء فحص (استخدم dx-code-analyzer-run)، أو إصلاح الانتهاكات، أو شرح القواعد، أو إنشاء قواعد مخصصة، أو منع الانتهاكات.
