مرحلة إعداد سحابة بيانات Salesforce. استخدم هذه المهارة عندما يقوم المستخدم بإنشاء أو إدارة تدفقات بيانات Data Cloud أو DLOs أو التحويلات أو تكوينات Document AI. يتم التشغيل عندما: يقوم المستخدم بإنشاء أو إدارة تدفقات بيانات Data Cloud، أو DLOs، أو التحويلات، أو تكوينات Document AI، أو يسأل عن الاستيعاب في Data Cloud. لا تقم بالتشغيل عندما: تكون المهمة هي إعداد الاتصال فقط (استخدام data360-connect)، أو DMOs ودقة الهوية (استخدام data360-harmonize)، أو عمل الاستعلام/البحث (استخدام data360-query).
