명시적인 사용자 확인 후 Connect API 동기화 엔드포인트를 통해 새 테스트 제품군을 선택하기 위해 파이프라인에서 구성된 DevOps Center 테스트 공급자를 다시 동기화합니다. PipelineId와 하나 이상의 testProviderId를 사용하고 새로 추가된 제품군을 할당에 사용할 수 있도록 비동기식 재동기화를 트리거합니다. 테스트 공급자(예: Apex 단위 테스트, 코드 분석기, 흐름 테스트, Provar)가 마지막으로 구성된 이후 도구 모음을 추가했고 사용자가 해당 도구 모음이 DevOps Center에 표시되기를 원하는 경우 이 기술을 사용합니다. TRIGGER 언제: 사용자가 테스트 공급자를 다시 동기화하거나, 공급자에서 새 제품군을 가져오거나, 공급자의 제품군 목록을 새로 고치거나, 구성된 공급자에 대해 할당된 제품군이 누락되었거나 오래되었다고 말하는 경우. 다음과 같은 경우에는 트리거하지 마세요. 처음으로 공급자를 구성하는 경우(새 DevopsPipelineTestProvider 구성을 생성하는 경우) 또는 기존 제품군을 단계에 할당/매핑하는 경우(managing-suite-locations 사용).
