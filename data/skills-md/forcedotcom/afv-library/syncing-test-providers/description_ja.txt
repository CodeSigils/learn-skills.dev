明示的なユーザー確認後に、Connect API 同期エンドポイント経由で新しいテスト スイートを取得するために、パイプライン上で構成された DevOps Center テスト プロバイダーを再同期します。 PipelineId と 1 つ以上の testProviderId を取得し、非同期再同期をトリガーして、新しく追加されたスイートを割り当てできるようにします。このスキルは、テストプロバイダー (Apex 単体テスト、コードアナライザー、フローテスト、Provar など) が最後に構成されてからスイートが追加されており、ユーザーがそれらのスイートを DevOps Center に表示することを希望する場合に使用します。トリガーは次の場合に発生します: ユーザーがテスト プロバイダーを再同期する場合、プロバイダーから新しいスイートを取得する場合、プロバイダーのスイート リストを更新する場合、または構成済みのプロバイダーに対して割り当てられたスイートが見つからない/古いと主張する場合。次の場合にはトリガーしないでください: 初めてプロバイダーを構成する場合 (新しい DevopsPipelineTestProvider 構成を作成する場合)、または既存のスイートをステージに割り当てる/マッピングする場合 (管理スイート割り当てを使用する)。
