Повторно синхронизирует настроенного поставщика тестов Центра DevOps в конвейере для получения новых наборов тестов через конечную точку синхронизации Connect API после явного подтверждения пользователя. Принимает идентификатор конвейера и один или несколько идентификаторов testProviderId и запускает асинхронную повторную синхронизацию, чтобы вновь добавленные наборы стали доступны для назначения. Используйте этот навык, если поставщик тестов (например, Apex Unit Tests, Code Analyzer, Flow Tests, Provar) добавил наборы с момента последней настройки, и пользователь хочет, чтобы эти пакеты отображались в DevOps Center. ЗАПУСКАЕТСЯ, когда: пользователь хочет повторно синхронизировать поставщика тестов, получить новые наборы от поставщика, обновить список наборов поставщика или сообщить, что назначенные наборы отсутствуют/устарели для настроенного поставщика. НЕ ЗАПУСКАЙТЕ, когда: настраиваете поставщика в первый раз (при этом создается новая конфигурация DevopsPipelineTestProvider) или назначаете/сопоставляете существующие наборы с этапом (используйте назначения управления набором).
