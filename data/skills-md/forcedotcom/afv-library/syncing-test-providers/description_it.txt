Risincronizza un provider di test DevOps Center configurato su una pipeline per acquisire nuove suite di test, tramite l'endpoint di sincronizzazione dell'API Connect, dopo la conferma esplicita dell'utente. Accetta un pipelineId e uno o più testProviderId e attiva una risincronizzazione asincrona in modo che le suite appena aggiunte diventino disponibili per l'assegnazione. Utilizza questa competenza quando a un provider di test (ad esempio Apex Unit Test, Code Analyser, Flow Tests, Provar) sono state aggiunte suite dall'ultima configurazione e l'utente desidera che tali suite vengano visualizzate in DevOps Center. ATTIVA quando: l'utente desidera risincronizzare un fornitore di prova, inserire nuove suite da un fornitore, aggiornare l'elenco delle suite di un fornitore o afferma che le suite assegnate mancano/non sono aggiornate per un fornitore configurato. NON SI ATTIVA quando: si configura un provider per la prima volta (che crea una nuova configurazione DevopsPipelineTestProvider) o si assegnano/mappano suite esistenti a una fase (utilizzare le assegnazioni di suite di gestione).
