Resynchronise un fournisseur de tests DevOps Center configuré sur un pipeline pour récupérer de nouvelles suites de tests, via le point de terminaison de synchronisation de l'API Connect, après confirmation explicite de l'utilisateur. Prend un pipelineId et un ou plusieurs testProviderIds et déclenche une resynchronisation asynchrone afin que les suites nouvellement ajoutées deviennent disponibles pour l'affectation. Utilisez cette compétence lorsqu'un fournisseur de tests (par exemple, Apex Unit Tests, Code Analyzer, Flow Tests, Provar) a ajouté des suites depuis sa dernière configuration et que l'utilisateur souhaite que ces suites apparaissent dans DevOps Center. DÉCLENCHEMENT lorsque : l'utilisateur souhaite resynchroniser un fournisseur de test, extraire de nouvelles suites d'un fournisseur, actualiser la liste des suites d'un fournisseur ou indique que les suites attribuées sont manquantes/obsolètes pour un fournisseur configuré. NE PAS DÉCLENCHER lors de : la configuration d'un fournisseur pour la première fois (qui crée une nouvelle configuration DevopsPipelineTestProvider) ou l'attribution/le mappage de suites existantes à une étape (utilisez les affectations de suite de gestion).
