DOIT s'activer lorsque l'utilisateur souhaite créer, créer ou générer une application React, une application React, une application Web, une application monopage (SPA) ou une application frontale, même si aucun fichier de projet n'existe encore. DOIT également s'activer lorsque le projet contient un répertoire uiBundles/*/src/ ou sfdx-project.json et que l'invite indique créer, construire, construire ou générer une nouvelle application, un nouveau site ou une nouvelle page à partir de zéro, même si l'invite décrit également le style visuel. DOIT également s'activer lorsque la tâche s'étend sur plus d'une compétence de l'interface utilisateur. Utilisez cette compétence lors de la création d’une application complète de bout en bout. Ne PAS utiliser pour les applications Lightning Experience avec des objets personnalisés (utilisez platform-lightning-app-coordonnée). Ne PAS utiliser pour des modifications ponctuelles d'une page existante (utilisez experience-ui-bundle-frontend-generate).
