DEBE activarse cuando el usuario quiera construir, crear o generar una aplicación React, una aplicación React, una aplicación web, una aplicación de página única (SPA) o una aplicación frontend, incluso si aún no existen archivos de proyecto. También DEBE activarse cuando el proyecto contiene un directorio uiBundles/*/src/ o sfdx-project.json y el mensaje dice crear, compilar, construir o generar una nueva aplicación, sitio o página desde cero, incluso si el mensaje también describe el estilo visual. También DEBE activarse cuando la tarea abarca más de una habilidad del paquete de interfaz de usuario. Utilice esta habilidad al crear una aplicación completa de un extremo a otro. NO lo use para aplicaciones Lightning Experience con objetos personalizados (use plataforma-coordenada-aplicación-lightning). NO lo use para ediciones de una sola preocupación en una página existente (use experiencia-ui-bundle-frontend-generate).
