Verwenden Sie diese Fähigkeit, wenn Benutzer Salesforce-Validierungsregeln erstellen, ändern oder validieren müssen. Wird ausgelöst, wenn Benutzer Validierungsregeln, Feldvalidierung, Datenqualitätsregeln, Formelvalidierung, Fehlermeldungen oder Validierungslogik erwähnen. Verwenden Sie es auch, wenn Benutzer auf Validierungsfehler stoßen, Formeln aktualisieren müssen oder Geschäftsregeln auf der Datenebene durchsetzen möchten. Verwenden Sie diese Fähigkeit immer für alle Arbeiten an Validierungsregeln.
