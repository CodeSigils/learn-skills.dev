مهارة تحليل OmniStudio الشاملة لاكتشاف مساحة الاسم وتصور التبعية وتحليل التأثير عبر OmniScripts وFlexCards وإجراءات التكامل ومخططي البيانات. استخدم هذه المهارة لاكتشاف مساحة اسم OmniStudio التي تستخدمها المؤسسة، وإنشاء رسوم بيانية للتبعية الموجهة، وإجراء تحليل التأثير، وإنشاء مخططات حورية البحر لعلاقات المكونات. يتم تشغيله عندما: يسأل المستخدم عن تبعيات OmniStudio، أو يريد اكتشاف مساحة الاسم (Core vs vlocity_cmt vs vlocity_ins)، أو يحتاج إلى تحليل التأثير، أو يطلب مخططات التبعية، أو يسأل عن المكونات التي تتأثر بالتغيير. لا تقم بالتشغيل عند: تأليف OmniScripts (استخدم Building-omnistudio-omniscript)، أو إنشاء FlexCards (استخدم Building-omnistudio-flexcard)، أو إنشاء إجراءات التكامل (استخدم إجراء Building-omnistudio-integration)، أو تكوين مخططي البيانات (استخدم Building-omnistudio-datamapper).
