DEBE activarse cuando el proyecto contiene un directorio uiBundles/*/src/ y la tarea implica crear o configurar una aplicación personalizada para alojar un paquete de UI en Lightning Experience. Utilice esta habilidad al crear un registro de metadatos de CustomApplication para mostrar el paquete de interfaz de usuario en el Iniciador de aplicación. Actívelo cuando existan archivos que coincidan con apps/*.app-meta.xml y necesiten modificación, o cuando el usuario quiera exponer su aplicación a través del Iniciador de aplicaciones Lightning sin un sitio de experiencia digital. NO utilice platform-custom-application-generate para esto: las aplicaciones del paquete UI no usan pestañas, anulaciones de acciones ni páginas flexibles.
