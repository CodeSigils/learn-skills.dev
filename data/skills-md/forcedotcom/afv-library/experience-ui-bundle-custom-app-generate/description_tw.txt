當專案包含 uiBundles/*/src/ 目錄且任務涉及建立或配置自訂應用程式以在 Lightning Experience 中託管 UI 套件時，必須啟動。创建 CustomApplication 元数据记录时使用此技能以在应用程序启动器中显示 UI 包。當存在與 applications/*.app-meta.xml 相符的檔案並需要修改時，或當使用者想要透過 Lightning 應用程式啟動器公開其應用程式而無需數位體驗網站時，啟動。请勿为此使用 platform-custom-application-generate — UI 捆绑应用程序不使用选项卡、操作覆盖或 Flexipages。
