أتمتة Salesforce DevOps باستخدام sf CLI v2. يتم تشغيله عندما: يقوم المستخدم بنشر بيانات التعريف، أو إنشاء/إدارة المؤسسات المؤقتة أو صناديق الحماية، أو إعداد خطوط أنابيب CI/CD، أو استكشاف أخطاء النشر وإصلاحها من خلال نشر مشروع sf. لا تقم بالتشغيل عند: كتابة كود Apex (استخدم إنشاء القمة)، أو إنشاء مكونات LWC (استخدم إنشاء مكونات lwc)، أو إنشاء تعريفات البيانات الوصفية (استخدم إنشاء كائن مخصص أو إنشاء حقل مخصص)، أو الاستعلام عن بيانات المؤسسة (استخدم بيانات المعالجة sf).
