Automatización de Salesforce DevOps mediante sf CLI v2. DISPARAR cuando: el usuario implementa metadatos, crea/administra organizaciones borrador o entornos sandbox, configura canalizaciones de CI/CD o soluciona errores de implementación con la implementación del proyecto sf. NO DISPARE cuando: escriba código Apex (use generate-apex), construya componentes LWC (use generando-lwc-componentes), cree definiciones de metadatos (use generando-objeto-personalizado o generando-campo-personalizado) o consultando datos de la organización (use manejo-sf-data).
