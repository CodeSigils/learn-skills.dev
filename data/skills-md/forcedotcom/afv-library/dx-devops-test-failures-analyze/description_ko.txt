일반 언어로 DevOps Center 테스트 실패 및 코드 분석기 위반(실패 범주, 문제가 있는 파일/클래스/메서드/줄, 규칙 위반, 수정 방향 및 우선 순위가 지정된 개선 제안(테스트 코드 대 프로덕션 코드))을 분석한 다음 선택적으로 명시적인 요청에 따라 추적된 수정 작업 항목을 생성합니다. 분석은 순수한 추론입니다. 작업 항목 생성은 확인 기반 쓰기입니다. 이 기술을 사용하여 실패 또는 개선 제안을 설명하고, 코드 분석기 위반을 변환하거나, 수정 사항을 작업 항목으로 추적합니다. TRIGGER 언제: 실행이 실패했고 사용자가 근본 원인을 원합니다. 품질 게이트 실패에 대한 설명이 필요합니다. 위반 사항은 번역이 필요합니다. 사용자가 실패 페이로드를 공유하고 이를 해결하는 방법을 묻습니다. 테스트를 강화하고 싶습니다. 또는 수정 작업 항목을 생성하거나, 수정 사항을 기록하거나, 실패를 할당하려고 합니다. 다음과 같은 경우에는 트리거하지 마십시오: 사용자가 수정 코드를 작성하거나(platform-apex-generate 사용) 새 테스트 클래스를 작성하기를 원합니다(platform-apex-test-generate 사용).
