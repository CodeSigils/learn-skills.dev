Analizza gli errori dei test del DevOps Center e le violazioni dell'analizzatore di codice in un linguaggio semplice: categoria di errore, file/classe/metodo/riga offensivi, regola violata, direzione della correzione e suggerimenti di miglioramento con priorità (codice di test rispetto a codice di produzione), quindi crea facoltativamente un WorkItem di correzione tracciata su richiesta esplicita. L'analisi è puro ragionamento; la creazione dell'elemento di lavoro è una scrittura soggetta a conferma. Utilizza questa competenza per spiegare errori o suggerimenti di miglioramento, tradurre violazioni di Code Analyser o tenere traccia di una correzione come elemento di lavoro. TRIGGER quando: un'esecuzione non è riuscita e l'utente desidera la causa principale; un guasto del cancello di qualità deve essere spiegato; le violazioni devono essere tradotte; l'utente condivide un payload di errore e chiede come affrontarlo; vuole rafforzare i test; o desidera creare un elemento di lavoro di correzione, registrare una riparazione o assegnare un errore. NON SI ATTIVA quando: l'utente desidera scrivere il codice di correzione (utilizzare platform-apex-generate) o creare nuove classi di test (utilizzare platform-apex-test-generate).
