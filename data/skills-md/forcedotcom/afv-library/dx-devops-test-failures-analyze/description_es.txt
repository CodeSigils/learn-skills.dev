Analiza las fallas de las pruebas del DevOps Center y las infracciones del Analizador de código en lenguaje sencillo: categoría de falla, archivo/clase/método/línea infractores, regla violada, dirección de corrección y sugerencias de mejora priorizadas (código de prueba versus código de producción) y luego, opcionalmente, crea un elemento de trabajo de corrección con seguimiento a pedido explícito. El análisis es puro razonamiento; La creación de elementos de trabajo es una escritura controlada por confirmación. Utilice esta habilidad para explicar fallas o sugerencias de mejora, traducir infracciones del Analizador de código o realizar un seguimiento de una solución como elemento de trabajo. DISPARAR cuando: una ejecución falló y el usuario desea la causa raíz; es necesario explicar una falla en el control de calidad; las violaciones necesitan traducción; el usuario comparte una carga útil de falla y pregunta cómo solucionarla; quiere reforzar las pruebas; o desea crear un elemento de trabajo de reparación, registrar una corrección o asignar una falla. NO DISPARE cuando: el usuario quiera escribir un código de corrección (use platform-apex-generate) o crear nuevas clases de prueba (use platform-apex-test-generate).
