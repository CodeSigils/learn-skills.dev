Genere flujos de Salesforce utilizando la herramienta MCP ejecutar_metadata_action. Úselo cuando el usuario solicite crear, compilar o generar un flujo, incluido el de pantalla, el de inicio automático, el de activación por grabación (antes/después de guardar), el programado. También activa solicitudes similares a flujos como "cuando se crea un registro", "activar diariamente a las", "enviar un correo electrónico cuando", "actualizar el campo cuando", "automatizar", "flujo de trabajo" o "flujo XML/metadatos". Esta es la única habilidad para la generación de Salesforce Flow.
