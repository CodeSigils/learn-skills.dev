قم بإنشاء تدفقات Salesforce باستخدام أداة MCP Execute_metadata_action. يُستخدم عندما يطلب المستخدم إنشاء تدفق أو إنشائه أو إنشائه - بما في ذلك الشاشة والتشغيل التلقائي والتسجيل الذي يتم تشغيله (قبل/بعد الحفظ) والمجدول. قم أيضًا بتشغيل الطلبات الشبيهة بالتدفق مثل "عند إنشاء سجل"، أو "التشغيل يوميًا عند"، أو "إرسال بريد إلكتروني عند"، أو "تحديث الحقل عند"، أو "التشغيل التلقائي"، أو "سير العمل"، أو "تدفق XML/بيانات التعريف". هذه هي المهارة الوحيدة لتوليد تدفق Salesforce.
