Le point d'entrée pour créer n'importe quelle application mobile native Salesforce sur iOS ou Android. DÉCLENCHEMENT lorsque l'utilisateur dit : « créer une application Salesforce iOS », « ajouter une connexion Salesforce à mon application Android », « configurer le SDK mobile », « ajouter un stockage hors ligne MobileSync/SmartStore », « intégrer un agent Agentforce dans mon application mobile », « ajouter le chat Agentforce à iOS/Android » ou demande de toute autre manière de créer, d'étendre ou d'intégrer une expérience mobile Salesforce dans Swift ou Kotlin (MSDK, Agentforce SDK ou les deux). Ignorer lorsque l'utilisateur crée une application mobile non Salesforce, utilise React Native / Flutter / Ionic sans intégration Salesforce, pose des questions sur la conception générique de l'interface utilisateur mobile ou travaille sur une surface Web/de bureau adjacente à Salesforce (LWC, Experience Cloud, marque Mobile Publisher uniquement).
