在 iOS 或 Android 上建立任何 Salesforce 本機行動應用程式的入口點。当用户说：“构建 Salesforce iOS 应用程序”、“将 Salesforce 登录添加到我的 Android 应用程序”、“设置 Mobile SDK”、“添加 MobileSync / SmartStore 离线存储”、“在我的移动应用程序中嵌入 Agentforce 代理”、“将 Agentforce 聊天添加到 iOS/Android”或以其他方式要求在 Swift 或 Kotlin（MSDK、Agentforce SDK 或两者）中创建、扩展或集成 Salesforce移動體驗時觸發。当用户正在构建非 Salesforce 移动应用程序、使用 React Native/Flutter/Ionic 而不集成 Salesforce、询问通用移动 UI 设计或在 Salesforce 相邻的 Web/桌面表面（LWC、Experience Cloud、仅限 Mobile Publisher 品牌）上工作时，请跳过。
