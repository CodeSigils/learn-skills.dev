قم بتكوين (أو استكشاف الأخطاء وإصلاحها) وكيل ترميز الذكاء الاصطناعي أو واجهة سطر الأوامر (CLI) للتوجيه عبر واجهة برمجة تطبيقات نماذج Salesforce باستخدام OrgJWT الموقعة. استخدم هذه المهارة عند توجيه وكيل إلى نقطة نهاية نموذج Salesforce (api.salesforce.com/ai/gpt/v1)، أو إعداد مصادقة وضع OrgJWT / Bedrock، أو توصيل إعدادات الوكيل، أو مساعد مفتاح API، وملف بيانات الاعتماد لنقطة نهاية Salesforce، أو إصلاح أخطاء Models API 401 / 404 / "النموذج غير متوفر". لا تقم بالتشغيل عندما يحتاج المستخدم إلى إنشاء أو تكوين تطبيق Salesforce Connected نفسه (استخدم التكامل-الاتصال-الاتصال-التطبيق-التكوين) أو إعداد بيانات الاعتماد المسماة / مصادقة وسيلة الشرح (استخدم إنشاء التكامل-الاتصال).
