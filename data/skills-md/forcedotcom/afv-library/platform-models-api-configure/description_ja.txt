署名付き OrgJWT を使用して Salesforce Models API を介してルーティングするように AI コーディング エージェントまたは CLI を設定 (またはトラブルシューティング) します。このスキルは、エージェントを Salesforce モデル エンドポイント (api.salesforce.com/ai/gpt/v1) に指定する場合、OrgJWT / Bedrock モード認証を設定する場合、エージェントの設定、API キー ヘルパー、Salesforce エンドポイントの認証情報ファイルを接続する場合、またはモデル API 401 / 404 / 「モデルが使用できません」エラーを修正する場合に使用します。ユーザが Salesforce 接続アプリケーション自体を作成または設定する必要がある場合 (integration-connectivity-connected-app-configure を使用)、または名前付き認証情報/コールアウト認証を設定する必要がある場合 (integration-connectivity-generate を使用) にはトリガーしないでください。
