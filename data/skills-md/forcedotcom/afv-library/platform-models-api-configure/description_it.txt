Configura (o risolvi i problemi) di un agente di codifica AI o di una CLI da instradare attraverso l'API dei modelli Salesforce utilizzando un OrgJWT firmato. Utilizzare questa competenza quando si indirizza un agente all'endpoint del modello Salesforce (api.salesforce.com/ai/gpt/v1), si imposta l'autenticazione in modalità OrgJWT/Bedrock, si collegano le impostazioni dell'agente, l'helper della chiave API e il file delle credenziali per l'endpoint Salesforce o si correggono gli errori API dei modelli 401/404/"modello non disponibile". NON SI ATTIVA quando l'utente deve creare o configurare l'app Salesforce Connected stessa (utilizza integrazione-connettività-connettività-app-configura) o impostare credenziali denominate/autenticazione callout (utilizza integrazione-connettività-genera).
