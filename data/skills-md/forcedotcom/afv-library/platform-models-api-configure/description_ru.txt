Настройте (или устраните неполадки) агента кодирования AI или CLI для маршрутизации через API моделей Salesforce с использованием подписанного OrgJWT. Используйте этот навык при указании агенту конечной точки модели Salesforce (api.salesforce.com/ai/gpt/v1), настройке аутентификации в режиме OrgJWT/Bedrock, подключении настроек агента, помощника API-ключа и файла учетных данных для конечной точки Salesforce или исправлении ошибок Models API 401/404/"модель недоступна". НЕ ВЫЗЫВАЙТЕ, когда пользователю необходимо создать или настроить само подключенное приложение Salesforce (используйте Integration-Connectivity-Connected-App-Configure) или настроить Именованные учетные данные/выноску аутентификации (используйте Integration-Connectivity-Generate).
