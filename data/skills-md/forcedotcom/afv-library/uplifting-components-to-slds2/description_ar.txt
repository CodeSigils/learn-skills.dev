قم بترحيل Lightning Web Components من SLDS 1 إلى SLDS 2 عن طريق تشغيل SLDS linter وإصلاح الانتهاكات. استخدم هذه المهارة عندما يذكر المستخدمون SLDS 2، أو رفع SLDS، أو انتهاكات linter، أو ترحيل رمز LWC، أو تجاوزات الفئة، أو قيم CSS المشفرة التي تحتاج إلى استبدال ربط SLDS، أو تحديد ربط التصميم. يغطي جميع فئات ربط التصميم - اللون، والتباعد، والتحجيم، والطباعة، والحدود، ونصف القطر، والظلال. استخدمه أيضًا عندما يذكر المستخدمون القيم no-hardcoded، أو no-slds-class-overrides، أو lwc-to-slds-hooks، أو no-deprecated-tokens-slds1، أو يسألون عن ترحيل مكونات SLDS - حتى إذا لم يذكروا صراحة "uplift" أو "migration".
