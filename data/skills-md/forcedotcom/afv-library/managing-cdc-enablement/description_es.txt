Úselo para habilitar la captura de datos de cambios (CDC) de Salesforce en un objeto estándar o personalizado, configurar un canal de eventos personalizado, establecer una expresión de filtro o agregar campos de enriquecimiento. DISPARAR ampliamente en cualquiera de: 'habilitar CDC', 'habilitar captura de datos modificados', 'activar CDC', 'suscribirse X para cambiar eventos', 'solo emitir eventos para', 'filtrar eventos de cambio', 'enriquecer eventos de cambio', 'crear un canal de eventos personalizado'; o cualquier mención de CDC, eventos de cambio, PlatformEventChannel, PlatformEventChannelMember, EnrichedField, canal ChangeEvents, campos de enriquecimiento, filtro de eventos de cambio; o cuando el usuario desea que un sistema posterior reciba cambios de datos de Salesforce; o cuando el usuario toca archivos .platformEventChannelMember-meta.xml / .platformEventChannel-meta.xml. OMITIR al publicar eventos de plataforma, Pub/Sub API o REST/SOAP (use building-sf-integrations) o ManagedEventSubscription (fuera del alcance de CDC). Utilice siempre esta habilidad para los metadatos de membresía del canal CDC.
