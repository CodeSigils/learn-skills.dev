استخدم هذه المهارة لتكوين الوصول إلى Salesforce Data Cloud DataSpace لمجموعات الأذونات. يمنح الوصول على مستوى مساحة البيانات عبر MDAPI PermissionSet XML مع عناصر dataspaceScopes، ويمنح بشكل اختياري الوصول على مستوى الكائن إلى كائنات DMO أو DLO أو CIO محددة عبر Object Access Grants Connect API. يتم تشغيله عندما: يحتاج المستخدم إلى إنشاء أو تحديث مجموعة أذونات تتضمن الوصول إلى DataSpace، أو منح مجموعة أذونات الوصول إلى مساحة بيانات محددة، أو تكوين dataAccessLevel أو objectAccessLevel لنطاق مساحة البيانات، أو إضافة منح الوصول إلى كائن RBAC لكائنات Data Cloud، أو سرد أو إزالة منح الوصول إلى الكائن لمجموعة أذونات وزوج DataSpace. لا تقم بالتشغيل عندما: تكون المهمة عبارة عن مجموعة أذونات عامة دون أي وصول إلى مساحة البيانات (استخدم إنشاء مجموعة أذونات النظام الأساسي)، أو يكون الطلب متعلقًا بإدخال البيانات أو التدفقات (استخدم إعداد data360)، أو يتضمن العمل إنشاء مساحات البيانات نفسها بدلاً من منح الوصول إليها.
