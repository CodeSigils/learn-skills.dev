Verwenden Sie diesen Skill, um den Salesforce Data Cloud DataSpace-Zugriff für Berechtigungssätze zu konfigurieren. Gewährt Zugriff auf Datenraumebene über MDAPI PermissionSet XML mit dataspaceScopes-Elementen und gewährt optional Zugriff auf Objektebene auf bestimmte DMO-, DLO- oder CIO-Objekte über die Object Access Grants Connect-API. TRIGGER, wenn: Der Benutzer einen Berechtigungssatz erstellen oder aktualisieren muss, der DataSpace-Zugriff umfasst, einem Berechtigungssatz Zugriff auf einen bestimmten Datenraum gewähren, dataAccessLevel oder objectAccessLevel für einen Datenraumbereich konfigurieren, RBAC-Objektzugriffsgewährungen für Data Cloud-Objekte hinzufügen oder Objektzugriffsgewährungen für ein Berechtigungssatz- und DataSpace-Paar auflisten oder entfernen muss. NICHT AUSLÖSEN, wenn: es sich bei der Aufgabe um einen generischen Berechtigungssatz ohne Datenraumzugriff handelt (verwenden Sie „platform-permission-set-generate“), es bei der Anforderung um die Datenaufnahme oder Datenströme geht (verwenden Sie „data360-prepare“) oder die Arbeit die Erstellung von Datenräumen selbst beinhaltet, anstatt ihnen Zugriff zu gewähren.
