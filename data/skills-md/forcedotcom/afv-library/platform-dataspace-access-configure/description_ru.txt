Используйте этот навык, чтобы настроить доступ Salesforce Data Cloud к DataSpace для наборов разрешений. Предоставляет доступ на уровне пространства данных через MDAPI PermissionSet XML с элементами dataspaceScopes и дополнительно предоставляет доступ на уровне объекта к определенным объектам DMO, DLO или CIO через API Object Access Grants Connect. ТРИГГЕР, когда: пользователю необходимо создать или обновить набор разрешений, включающий доступ к DataSpace, предоставить набору разрешений доступ к определенному пространству данных, настроить dataAccessLevel или objectAccessLevel для области пространства данных, добавить разрешения на доступ к объектам RBAC для объектов Data Cloud или составить список или удалить разрешения на доступ к объектам для пары набора разрешений и DataSpace. НЕ ЗАПУСКАЙТЕ, когда: задача представляет собой общий набор разрешений без какого-либо доступа к пространству данных (используйте Platform-Permission-Set-Generate), запрос касается приема данных или потоков (используйте data360-prepare), или работа включает в себя создание самих пространств данных, а не предоставление доступа к ним.
