Utilisez cette compétence pour configurer l'accès à Salesforce Data Cloud DataSpace pour les ensembles d'autorisations. Accorde un accès au niveau de l'espace de données via MDAPI PermissionSet XML avec des éléments dataspaceScopes et accorde éventuellement un accès au niveau de l'objet à des objets DMO, DLO ou CIO spécifiques via l'API Object Access Grants Connect. DÉCLENCHEMENT lorsque : l'utilisateur doit créer ou mettre à jour un ensemble d'autorisations qui inclut l'accès DataSpace, accorder à un ensemble d'autorisations l'accès à un espace de données spécifique, configurer dataAccessLevel ou objectAccessLevel pour une étendue d'espace de données, ajouter des autorisations d'accès aux objets RBAC pour les objets Data Cloud, ou répertorier ou supprimer les autorisations d'accès aux objets pour un ensemble d'autorisations et une paire DataSpace. NE PAS DÉCLENCHER lorsque : la tâche est un ensemble d'autorisations génériques sans aucun accès à l'espace de données (utilisez platform-permission-set-generate), la demande concerne l'ingestion de données ou de flux (utilisez data360-prepare), ou le travail implique la création d'espaces de données eux-mêmes plutôt que d'y accorder l'accès.
