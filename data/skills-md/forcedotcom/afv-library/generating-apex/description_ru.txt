Основные авторские навыки Apex для создания классов, рефакторинга и проверки. ВСЕГДА АКТИВИРУЙТЕ, когда пользователь упоминает Apex, .cls, триггеры или просит создать/реорганизовать класс (службу, селектор, домен, пакет, очередь, планирование, вызов, DTO, утилиту, интерфейс, абстракцию, исключение, ресурс REST). Используйте этот навык для запросов, включающих SObject CRUD, сопоставление коллекций, выборку связанных записей, запланированные задания, пакетные задания, разработку триггеров, контроллеры @AuraEnabled, конечные точки @RestResource, пользовательские API REST или проверку кода существующих Apex.
