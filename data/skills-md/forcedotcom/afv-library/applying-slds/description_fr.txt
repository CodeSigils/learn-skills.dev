Appliquez une interface utilisateur conforme à SLDS en utilisant les plans, les crochets de style, les classes utilitaires et les icônes appropriés. À utiliser lors de la création d'une interface utilisateur nécessitant SLDS, en choisissant entre les composants de base Lightning et les plans SLDS, en appliquant des crochets de style pour les thèmes, en utilisant des classes utilitaires pour la mise en page et l'espacement ou en sélectionnant des icônes. Les déclencheurs incluent « créer un modal », « créer un formulaire », « table de données », « style SLDS », « style avec crochets », « ajouter une icône ».
