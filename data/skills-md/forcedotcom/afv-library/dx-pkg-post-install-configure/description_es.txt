Utilice esta habilidad para automatizar la configuración posterior a la instalación del paquete administrado. Independiente del paquete: funciona con cualquier paquete administrado (LMA, FMA, work.com, Certinia, etc.). SE DISPARA cuando: el usuario instala un paquete administrado y necesita una configuración posterior a la instalación, menciona la configuración posterior a la instalación de LMA/FMA/work.com, solicita configurar conjuntos de permisos/FLS/diseños de página para un paquete instalado, dice 'posterior a la instalación', 'configuración del paquete', 'configurar LMA', 'configurar FMA', 'pasos posteriores a la instalación'. NO DISPARAR para: asignación de conjunto de permisos independiente (use dx-org-permission-set-assign), generación de metadatos XML del conjunto de permisos (use platform-permission-set-generate), instalación de paquetes o cambio de organización.
