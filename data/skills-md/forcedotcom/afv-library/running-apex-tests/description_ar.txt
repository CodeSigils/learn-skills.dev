تنفيذ اختبار Apex، وتحليل التغطية، وحلقات إصلاح الاختبار بتسجيل 120 نقطة. يُستخدم عندما يحتاج المستخدم إلى تشغيل اختبارات Apex، أو التحقق من تغطية التعليمات البرمجية، أو إصلاح الاختبارات الفاشلة، أو العمل مع ملفات *Test.cls / *_Test.cls. يتم تشغيله عندما: يقوم المستخدم بإجراء اختبارات Apex، أو التحقق من تغطية التعليمات البرمجية، أو إصلاح الاختبارات الفاشلة، أو لمس ملفات *Test.cls / *_Test.cls. لا تقم بالتشغيل عند: كتابة كود إنتاج Apex (استخدم generator-apex)، أو اختبار وكيل Agentforce (استخدم test-agentforce)، أو اختبارات Jest/LWC (استخدم مكونات generator-lwc).
