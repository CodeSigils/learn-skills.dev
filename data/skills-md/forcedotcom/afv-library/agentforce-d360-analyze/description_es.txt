Vista de 360° de Data Cloud de una única sesión de Agentforce. DISPARA cuando el usuario solicita rastrear, inspeccionar, resumir o describir una sesión de Agentforce específica por ID de sesión (UUID de sesión de agente `019d…` o ID de sesión de mensajería `0Mw…`). También se activa al descubrir sesiones (buscar/enumerar/buscar sesiones por hora, agente, canal, resultado o texto de conversación) cuando el usuario aún no tiene una identificación de sesión. NO DISPARE para preguntas sobre arquitectura en tiempo de diseño (use agentforce-architecture-analyze en su lugar) o para preguntas sobre rendimiento/latencia/SLO en tiempo de ejecución que requieren telemetría de plataforma más allá de Data Cloud.
