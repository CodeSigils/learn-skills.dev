Data Cloud Vista a 360° di una singola sessione Agentforce. SI ATTIVA quando l'utente chiede di tracciare, ispezionare, riepilogare o descrivere una sessione specifica di Agentforce tramite l'ID di sessione (UUID sessione dell'agente `019d…` o ID MessagingSession `0Mw…`). Si attiva anche all'individuazione della sessione (trova/elenca/cerca sessioni per ora, agente, canale, risultato o testo della conversazione) quando l'utente non ha ancora un ID sessione. NON ATTIVARE per domande sull'architettura in fase di progettazione (utilizza invece agentforce-architecture-analyze) o per domande su prestazioni/latenza/SLO di runtime che richiedono la telemetria della piattaforma oltre Data Cloud.
