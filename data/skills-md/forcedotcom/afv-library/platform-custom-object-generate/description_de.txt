Verwenden Sie diese Fähigkeit, wenn Benutzer Metadaten für benutzerdefinierte Salesforce-Objekte erstellen, generieren oder validieren müssen. Wird ausgelöst, wenn Benutzer benutzerdefinierte Objekte, das Erstellen von Objekten, Objektmetadaten, .object-Dateien, das Teilen von Modellen, Namensfeldern oder Validierungsregeln für Objekte erwähnen. Verwenden Sie es auch, wenn Benutzer Dinge sagen wie „ein benutzerdefiniertes Objekt erstellen“, „Objektmetadaten generieren“, „ein Objekt einrichten für …“ oder wenn sie Fehler bei der Objektbereitstellung beheben, insbesondere im Zusammenhang mit der gemeinsamen Nutzung von Modellen und Master-Detail-Beziehungen. Verwenden Sie diese Fähigkeit immer für alle Arbeiten an benutzerdefinierten Objektmetadaten, einschließlich der Anreicherung und Aktualisierung der Beschreibung des Objekts, wenn sich seine Felder oder Validierungsregeln ändern. Verwenden Sie diesen Skill NICHT für Metadaten, die keine benutzerdefinierten Objekte sind (Apex, Flows, LWC, Berechtigungssätze, benutzerdefinierte Metadatentypen) oder für Standard-Salesforce-Objekte.
