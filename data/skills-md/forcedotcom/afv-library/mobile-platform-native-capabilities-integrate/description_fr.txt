Créez un LWC Salesforce qui utilise les fonctionnalités natives des appareils mobiles : lecteur de codes-barres, biométrie, localisation, NFC, calendrier, contacts, scanner de documents, géorepérage, capture d'espace AR, examen des applications et paiements. Utilisez cette compétence lorsque l'utilisateur demande un LWC qui scanne un code-barres, capture une photo d'un document, lit l'emplacement ou les barrières géographiques, demande des données biométriques, lit/écrit le calendrier ou les contacts de l'appareil, appuie sur NFC, accepte un paiement, demande un examen de l'application ou scanne un espace AR. Se déclenche également sur « lightning/mobileCapabilities », « capacité mobile », « Nimbus », « capacité de l'appareil ». Ne pas utiliser pour les révisions d'amorçage mobiles hors ligne / Komaci (utilisez « mobile-platform-offline-validate ») ou pour sélectionner des composants de base Lightning génériques (utilisez une compétence générique de composants de base Lightning).
