Génère un projet de démarrage SFDX minimal et prêt à développer à partir d'un modèle au lieu de fichiers d'échafaudage manuel. Utilisez cette compétence lors du démarrage d'une toute nouvelle application groupée Salesforce React UI et que le projet initial doit être échafaudé : les phrases de déclenchement incluent la création, le démarrage ou l'échafaudage d'une nouvelle application groupée React UI, la génération d'un projet de démarrage ou l'utilisation d'un modèle prédéfini/de démarrage. NE PAS DÉCLENCHER lorsque : vous modifiez, stylisez ou ajoutez des pages ou des composants à une application EXISTANTE (utilisez experience-ui-bundle-frontend-generate) ; configuration de ui-bundle.json ou des fichiers de métadonnées (utilisez experience-ui-bundle-metadata-generate) ; déploiement sur une organisation (utilisez experience-ui-bundle-deploy) ; ou lorsque l'utilisateur dit explicitement qu'il souhaite créer un échafaudage manuel à partir de zéro.
