Erzeugt ein minimales, entwicklungsfertiges SFDX-Starterprojekt aus einer Vorlage anstelle von manuell erstellten Gerüstdateien. Verwenden Sie diese Fertigkeit, wenn Sie eine brandneue Salesforce React UI-Bundle-App starten und das ursprüngliche Projekt ein Gerüst haben muss. Zu den Auslöserphrasen gehören das Erstellen, Starten oder Gerüstieren einer neuen React UI-Bundle-App, das Generieren eines Starterprojekts oder die Verwendung einer vorgefertigten/Starter-Vorlage. NICHT AUSLÖSEN, wenn: Seiten oder Komponenten einer VORHANDENEN App bearbeitet, gestaltet oder hinzugefügt werden (verwenden Sie experience-ui-bundle-frontend-generate); Konfigurieren von ui-bundle.json oder Metadatendateien (verwenden Sie experience-ui-bundle-metadata-generate); Bereitstellung in einer Organisation (verwenden Sie experience-ui-bundle-deploy); oder wenn der Benutzer ausdrücklich angibt, dass er das Gerüst von Grund auf neu erstellen möchte.
