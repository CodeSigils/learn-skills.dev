Создает минимальный, готовый к разработке стартовый проект SFDX на основе шаблона, а не файлов ручной настройки. Используйте этот навык при запуске совершенно нового приложения пакета пользовательского интерфейса React Salesforce, при этом первоначальный проект должен быть сформирован — триггерные фразы включают создание, запуск или создание нового приложения пакета пользовательского интерфейса React, создание стартового проекта или использование предварительно созданного/начального шаблона. НЕ ЗАПУСКАЕТСЯ при: редактировании, стилизации или добавлении страниц или компонентов в СУЩЕСТВУЮЩЕЕ приложение (используйте experience-ui-bundle-frontend-generate); настройка ui-bundle.json или файлов метаданных (используйте experience-ui-bundle-metadata-generate); развертывание в организации (используйте experience-ui-bundle-deploy); или когда пользователь прямо заявляет, что хочет создать каркас вручную с нуля.
