手動でスキャフォールディング ファイルを作成するのではなく、テンプレートから最小限の、すぐに開発できる SFDX スターター プロジェクトを生成します。このスキルは、新しい Salesforce React UI バンドル アプリケーションを開始し、最初のプロジェクトをスキャフォールディングする必要がある場合に使用します。トリガー フレーズには、新しい React UI バンドル アプリケーションの作成、開始、またはスキャフォールディング、スターター プロジェクトの生成、または事前構築/スターター テンプレートの使用が含まれます。次の場合にはトリガーしないでください: 既存のアプリにページやコンポーネントを編集、スタイル設定、または追加する場合 (experience-ui-bundle-frontend-generate を使用)。 ui-bundle.json またはメタデータ ファイルを構成します ( experience-ui-bundle-metadata-generate を使用します)。組織へのデプロイ ( experience-ui-bundle-deploy を使用);または、ユーザーが最初から手作業で足場を構築したいと明示的に言った場合。
