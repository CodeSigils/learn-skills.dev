Configurazione OAuth delle app Salesforce Connected e delle app client esterne con punteggio di 120 punti. Utilizzare questa competenza per configurare i flussi OAuth, l'autenticazione della portante JWT, le app connesse e le app client esterne in Salesforce. SI ATTIVA quando: l'utente configura i flussi OAuth, l'autenticazione bearer JWT, le app connesse, le ECA o tocca i file .connectedApp-meta.xml / .eca-meta.xml. NON SI ATTIVA quando: si configurano credenziali denominate per i callout (utilizza integrazione-connettività-generate), si rivedono le policy di autorizzazione (utilizza piattaforma-metadata-deploy) o si scrive codice di gestione token Apex (utilizza piattaforma-apex-generate).
