Automazione Salesforce DevOps utilizzando sf CLI v2. ATTIVA quando: l'utente distribuisce metadati, crea/gestisce organizzazioni di lavoro o sandbox, configura pipeline CI/CD o risolve errori di distribuzione con sf project deploy. NON SI ATTIVA quando: si scrive codice Apex (usa platform-apex-generate), si creano componenti LWC (usa experience-lwc-generate), si creano definizioni di metadati (usa platform-custom-object-generate o platform-custom-field-generate) o si eseguono query sui dati dell'organizzazione (usa platform-data-manage).
