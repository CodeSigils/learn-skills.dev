أتمتة Salesforce DevOps باستخدام sf CLI v2. يتم تشغيله عندما: يقوم المستخدم بنشر بيانات التعريف، أو إنشاء/إدارة المؤسسات المؤقتة أو صناديق الحماية، أو إعداد خطوط أنابيب CI/CD، أو استكشاف أخطاء النشر وإصلاحها من خلال نشر مشروع sf. لا تقم بالتشغيل عند: كتابة كود Apex (استخدم إنشاء منصة-apex)، أو بناء مكونات LWC (استخدم إنشاء الخبرة-lwc)، أو إنشاء تعريفات البيانات الوصفية (استخدم إنشاء كائن مخصص للنظام أو إنشاء حقل مخصص للنظام الأساسي)، أو الاستعلام عن بيانات المؤسسة (استخدم إدارة بيانات النظام الأساسي).
