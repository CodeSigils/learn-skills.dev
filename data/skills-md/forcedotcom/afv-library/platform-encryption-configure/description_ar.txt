تكوين Salesforce Shield Platform Encryption — إنشاء إعدادات تشفير قابلة للنشر وبيانات تعريف الحقول المشفرة، والإجابة على الأسئلة المتعلقة بالنموذج الرئيسي ودورة الحياة. TRIGGER عندما: يريد المستخدم تشغيل التشفير الحتمي، أو تشفير حقل، أو إعداد مفاتيح ذاكرة التخزين المؤقت فقط، أو إدارة المفاتيح الخارجية، أو اكتشاف إعادة التشغيل، أو الإشارة إلى تشفير منصة Shield، أو التشفير في حالة عدم النشاط، أو التشفير الحتمي مقابل التشفير الاحتمالي، أو نظام التشفير، أو PlatformEncryptionSettings، أو EncryptionKeySettings، أو BYOK، أو BYOKMS، أو أسرار المستأجر، أو تدوير المفاتيح، أو .settings-meta.xml / .field-meta.xml للتشفير — حتى عندما لا يُذكر "Shield". تخطي عندما: يحتاج المستخدم إلى حقل مخصص عام بدون تشفير (استخدم إنشاء حقل مخصص للنظام الأساسي)، أو يحتاج إلى مرجع نوع واجهة برمجة تطبيقات بيانات التعريف الأولية (استخدم بيانات تعريف النظام الأساسي-api-context-get)، أو يسأل عن التشفير الكلاسيكي (حقول نصية مشفرة)، وهي ميزة مختلفة. استخدم هذه المهارة لأي تكوين لتشفير النظام الأساسي، أو تشفير الحقل، أو سؤال النموذج الرئيسي.
