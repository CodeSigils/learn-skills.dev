Salesforce Shield プラットフォーム暗号化の設定 — 導入可能な暗号化設定と暗号化フィールドのメタデータを生成し、鍵モデルとライフサイクルの質問に答えます。トリガーのタイミング: ユーザーが確定的暗号化を有効にする、フィールドを暗号化する、キャッシュ専用キーのセットアップ、外部キー管理、またはリプレイ検出を希望する場合、または Shield プラットフォーム暗号化、保存時の暗号化、確定的暗号化と確率的暗号化、encryptionScheme、PlatformEncryptionSettings、EncryptionKeySettings、BYOK、BYOKMS、テナント シークレット、キー ローテーション、または .settings-meta.xml / について言及する場合暗号化用の .field-meta.xml — 「Shield」と書かれていない場合でも。次の場合はスキップします: ユーザーが暗号化のない汎用カスタム フィールドを必要とする場合 (platform-custom-field-generate を使用)、生のメタデータ API タイプの参照が必要な場合 (platform-metadata-api-context-get を使用)、または別の機能であるクラシック暗号化 (暗号化されたテキスト フィールド) について質問する場合。このスキルは、プラットフォーム暗号化構成、フィールド暗号化、またはキーモデルに関する質問に使用してください。
