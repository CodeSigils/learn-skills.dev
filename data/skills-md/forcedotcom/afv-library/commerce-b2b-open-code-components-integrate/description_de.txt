Integrieren Sie Salesforce B2B Commerce Open-Source-Komponenten von GitHub in B2B Commerce-Shops. Verwenden Sie diese Option, wenn Benutzer „Open-Source-Komponenten integrieren“, „Open-Source-B2B-Commerce“, „Open-Code-Komponenten hinzufügen“, „forcedotcom/b2b-commerce-open-source-components“ erwähnen oder ihrem Shop Open-Source-Commerce-Komponenten hinzufügen möchten. Kopiert alle Komponenten und Beschriftungen, sodass sie im Experience Builder verfügbar sind.
