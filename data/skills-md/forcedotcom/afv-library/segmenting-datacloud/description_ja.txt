Salesforce データクラウドセグメントフェーズ。このスキルは、ユーザーがデータ クラウドでセグメントを作成または公開したり、計算された分析情報を管理したり、オーディエンス SQL のトラブルシューティングを行ったりするときに使用します。トリガーのタイミング: ユーザーがセグメントの作成または公開、計算された分析情報の管理、セグメント数またはメンバーシップの検査、または Data Cloud でのオーディエンス SQL のトラブルシューティングを行う場合。次の場合はトリガーしないでください: タスクが DMO/マッピング/アイデンティティ解決作業 (harmonizing-datacloud を使用)、アクティブ化作業 (activating-datacloud を使用)、クエリ/検索インデックス作業 (retrieving-datacloud を使用)、または標準データ モデル (STDM)/セッション トレース (observing-agentforce を使用) である場合。
