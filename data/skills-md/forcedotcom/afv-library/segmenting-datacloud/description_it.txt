Fase del segmento Salesforce Data Cloud. Utilizza questa competenza quando l'utente crea o pubblica segmenti, gestisce approfondimenti calcolati o risolve i problemi SQL del pubblico in Data Cloud. ATTIVA quando: l'utente crea o pubblica segmenti, gestisce approfondimenti calcolati, controlla i conteggi o l'appartenenza dei segmenti o risolve i problemi SQL del pubblico in Data Cloud. NON SI ATTIVA quando: l'attività è un lavoro DMO/mappatura/risoluzione dell'identità (utilizzare harmonizing-datacloud), un lavoro di attivazione (utilizzare activating-datacloud), un lavoro di query/ricerca sull'indice (utilizzare retrieving-datacloud) o Standard Data Model (STDM)/tracciamento delle sessioni (utilizzare osservatore-agentforce).
