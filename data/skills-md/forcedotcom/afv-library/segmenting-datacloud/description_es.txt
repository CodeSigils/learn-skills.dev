Fase de Segmento de Salesforce Data Cloud. Utilice esta habilidad cuando el usuario cree o publique segmentos, administre información calculada o solucione problemas de SQL de audiencia en Data Cloud. DISPARAR cuando: el usuario crea o publica segmentos, administra información calculada, inspecciona el recuento de segmentos o la membresía, o soluciona problemas de SQL de audiencia en Data Cloud. NO DISPARAR cuando: la tarea es trabajo de DMO/mapeo/resolución de identidad (use armonización de nube de datos), trabajo de activación (use activación de nube de datos), trabajo de consulta/índice de búsqueda (use recuperación de nube de datos) o modelo de datos estándar (STDM)/rastreo de sesiones (use observación-agentforce).
