Orchestrateur de produits Salesforce Data Cloud pour les workflows de connexion → préparation → harmonisation → segmentation → action. Utilisez cette compétence lorsque l'utilisateur a besoin d'un pipeline Data Cloud en plusieurs étapes, d'un dépannage en plusieurs phases ou d'une gestion de l'espace de données et des kits de données. DÉCLENCHEMENT lorsque : l'utilisateur a besoin d'un pipeline Data Cloud en plusieurs étapes, demande de configurer ou de dépanner Data Cloud à travers les phases, gère des espaces de données ou des kits de données, ou souhaite un flux de travail sf data360 multi-phases. NE PAS DÉCLENCHER lorsque : le travail est isolé sur une seule phase (utilisez la compétence spécifique à la phase correspondante), la tâche est une télémétrie STDM/traçage de session/parquet (utilisez agentforce-observe), un CRM SOQL standard (utilisez platform-soql-query) ou une implémentation Apex (utilisez platform-apex-generate).
