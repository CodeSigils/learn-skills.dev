Salesforce Data Cloud-Produktorchestrator für Workflows „Verbinden→Vorbereiten→Harmonisieren→Segmentieren→Handeln“. Verwenden Sie diese Fähigkeit, wenn der Benutzer eine mehrstufige Data Cloud-Pipeline, eine phasenübergreifende Fehlerbehebung oder die Verwaltung von Datenraum und Datenpaketen benötigt. TRIGGER wenn: Der Benutzer benötigt eine mehrstufige Data Cloud-Pipeline, bittet darum, Data Cloud phasenübergreifend einzurichten oder zu beheben, verwaltet Datenräume oder Datenkits oder wünscht einen phasenübergreifenden SF Data360-Workflow. NICHT AUSLÖSEN, wenn: die Arbeit auf eine einzelne Phase beschränkt ist (verwenden Sie die passende phasenspezifische Fertigkeit), die Aufgabe STDM/Sitzungsverfolgung/Parketttelemetrie (verwenden Sie agentforce-observe), Standard-CRM-SOQL (verwenden Sie platform-soql-query) oder Apex-Implementierung (verwenden Sie platform-apex-generate) ist.
