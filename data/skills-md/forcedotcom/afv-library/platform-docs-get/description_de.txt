Offizielle Fähigkeit zum Abrufen von Salesforce-Dokumentationen. Verwenden Sie diese Option, wenn Sie verlässliche Salesforce-Dokumente von Developer.salesforce.com, help.salesforce.com, Architect.salesforce.com, admin.salesforce.com oder lightningdesignsystem.com benötigen, insbesondere wenn Seiten JS-lastig sind, Shell-gerendert werden oder mit naivem Fetching schwer zu extrahieren sind. Verwenden Sie diese Option, um Antworten in offiziellen Salesforce-Quellen statt in Blogs oder Zusammenfassungen von Drittanbietern zu finden. TRIGGER, wenn: Der Benutzer fragt nach offizieller Salesforce-Dokumentation, Apex- oder API-Referenz, LWC-Dokumenten, Agentforce-Dokumenten, Einrichtungs- oder Hilfeartikeln oder einem beliebigen Dokument aus einer Salesforce-eigenen Domäne. NICHT AUSLÖSEN, wenn: Der Benutzer eine Codeänderung, eine Bereitstellungsaufgabe oder etwas anfordert, das keinen Abruf der Dokumentation erfordert – verwenden Sie stattdessen die entsprechende sf-*-Fähigkeit.
