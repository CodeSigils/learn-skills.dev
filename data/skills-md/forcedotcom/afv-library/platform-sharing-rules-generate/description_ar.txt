استخدم هذه المهارة عندما يحتاج المستخدمون إلى إنشاء البيانات التعريفية لقواعد مشاركة Salesforce أو إنشاؤها أو تعديلها. يتم تشغيله عندما: يذكر المستخدمون قواعد المشاركة، أو مشاركة السجلات، أو المشاركة القائمة على المعايير، أو المشاركة القائمة على الأدوار، أو مشاركة مستخدم الضيف، أو مشاركة مستخدم المدخل، أو مشاركة Rules، أو مشاركة CriteriaRules، أو مشاركة GuestRules، أو مشاركة OwnerRules، أو ملفات .sharingRules-meta.xml، أو طلب مشاركة السجلات مع أدوار أو مجموعات محددة. يتم التشغيل أيضًا عندما يريد المستخدمون تكوين الوصول على مستوى السجل بما يتجاوز الإعدادات الافتراضية على مستوى المؤسسة (OWD)، أو مشاركة سجلات الكائنات مع الأدوار، أو المجموعات، أو المستخدمين الضيوف، أو إعداد رؤية سجل مستخدم الضيف في موقع الخبرة. تخطي عندما: يحتاج المستخدم إلى مجموعات أذونات أو ملفات تعريف (استخدم إنشاء مجموعة أذونات النظام الأساسي)، أو يحتاج إلى أمان على مستوى الكائن بدلاً من المشاركة على مستوى السجل (استخدم إنشاء مجموعة أذونات النظام الأساسي).
