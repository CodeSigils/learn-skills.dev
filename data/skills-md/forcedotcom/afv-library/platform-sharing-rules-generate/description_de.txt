Verwenden Sie diesen Skill, wenn Benutzer Metadaten für Salesforce-Freigaberegeln erstellen, generieren oder ändern müssen. TRIGGER, wenn: Benutzer Freigaberegeln, Datensatzfreigabe, kriterienbasierte Freigabe, rollenbasierte Freigabe, Gastbenutzerfreigabe, Portalbenutzerfreigabe, SharingRules, SharingCriteriaRules, SharingGuestRules, SharingOwnerRules, .sharingRules-meta.xml-Dateien erwähnen oder darum bitten, Datensätze mit bestimmten Rollen oder Gruppen zu teilen. Wird auch ausgelöst, wenn Benutzer den Zugriff auf Datensatzebene über die organisationsweiten Standardwerte (OWD) hinaus konfigurieren, Objektdatensätze mit Rollen, Gruppen oder Gastbenutzern teilen oder die Sichtbarkeit von Experience Site-Gastbenutzerdatensätzen einrichten möchten. ÜBERSPRINGEN, wenn: Der Benutzer Berechtigungssätze oder Profile benötigt (verwenden Sie „platform-permission-set-generate“) oder Sicherheit auf Objektebene anstelle der Freigabe auf Datensatzebene benötigt (verwenden Sie „platform-permission-set-generate“).
