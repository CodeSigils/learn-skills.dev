Recupera le categorie di prompt di configurazione dell'agente da un'organizzazione Salesforce connessa utilizzando l'API Connect. Utilizzare questa capacità per chiamare GET /agenticsetup/categories e restituire l'elenco delle categorie di prompt, facoltativamente con i relativi prompt nidificati. ATTIVA quando: l'utente chiede di ottenere, recuperare, elencare o mostrare le categorie di configurazione dell'agente, le categorie di prompt, le categorie di configurazione del copilota, le categorie della libreria di prompt, i prompt di configurazione disponibili, la libreria di prompt di Agentforce o i prompt del copilota. NON ATTIVARE quando: l'utente desidera creare nuove categorie, lavorare con endpoint non appartenenti a categorie o generare specifiche OpenAPI.
