Récupérez les catégories d'invites de configuration agent à partir d'une organisation Salesforce connectée à l'aide de l'API Connect. Utilisez cette compétence pour appeler GET /agenticsetup/categories et renvoyer la liste des catégories d'invites, éventuellement avec leurs invites imbriquées. DÉCLENCHEMENT lorsque : l'utilisateur demande à obtenir, récupérer, répertorier ou afficher les catégories de configuration agent, les catégories d'invites, les catégories de copilote de configuration, les catégories de bibliothèque d'invites, les invites de configuration disponibles, la bibliothèque d'invites Agentforce ou les invites de copilote. NE PAS DÉCLENCHER lorsque : l'utilisateur souhaite créer de nouvelles catégories, travailler avec des points de terminaison autres que des catégories ou générer des spécifications OpenAPI.
