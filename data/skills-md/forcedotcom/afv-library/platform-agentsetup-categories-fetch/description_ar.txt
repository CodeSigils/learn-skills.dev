جلب فئات مطالبة الإعداد الوكيل من مؤسسة Salesforce المتصلة باستخدام Connect API. استخدم هذه المهارة لاستدعاء GET /agenticsetup/categories وإرجاع قائمة فئات الموجهات، اختياريًا مع المطالبات المتداخلة الخاصة بها. يتم التشغيل عندما: يطلب المستخدم الحصول على فئات إعداد الوكيل أو جلبها أو إدراجها أو عرضها، أو فئات المطالبات، أو فئات مساعد الطيار للإعداد، أو فئات مكتبة المطالبات، أو مطالبات الإعداد المتاحة، أو مكتبة مطالبات Agentforce، أو مطالبات مساعد الطيار. لا تقم بالتشغيل عندما: يريد المستخدم إنشاء فئات جديدة، أو العمل مع نقاط نهاية غير الفئات، أو إنشاء مواصفات OpenAPI.
