必須在編輯 uiBundles/*/src/ 下的任何檔案之前激活，以對現有應用程式進行視覺或 UI 更改 - 頁面、元件、部分、佈局、樣式、顏色、字體、導航、動畫或任何外觀和感覺更改。在修改現有 UI 捆綁應用程式中的頁面、元件、佈局、樣式或導航時，請使用此技能。當專案包含 appLayout.tsx、routes.tsx、src/pages/、src/components/ 或 global.css 時啟動。此技能包含超越一般知識的關鍵專案特定約定（appLayout.tsx shell、shadcn/ui 元件、Tailwind CSS、Salesforce 基本路徑路由、模組限制）。如果沒有這項技能，產生的程式碼將使用錯誤的匯入、中斷路由或忽略專案結構。從頭開始建立新應用程式時請勿使用（請改用 experience-ui-bundle-app-coordinate）。
