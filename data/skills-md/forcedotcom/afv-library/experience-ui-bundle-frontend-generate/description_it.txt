DEVE essere attivato prima di modificare QUALSIASI file in uiBundles/*/src/ per modifiche visive o dell'interfaccia utente a un'app ESISTENTE: pagine, componenti, sezioni, layout, stile, colori, caratteri, navigazione, animazioni o qualsiasi modifica dell'aspetto. Utilizza questa competenza quando modifichi pagine, componenti, layout, stili o navigazione in un'app bundle dell'interfaccia utente esistente. Attiva quando il progetto contiene appLayout.tsx, Routes.tsx, src/pages/, src/components/ o global.css. Questa competenza contiene convenzioni critiche specifiche del progetto (shell appLayout.tsx, componenti shadcn/ui, CSS Tailwind, routing del percorso base di Salesforce, restrizioni sui moduli) che sovrascrivono le conoscenze generali. Senza questa competenza, il codice generato utilizzerà importazioni errate, interromperà il routing o ignorerà la struttura del progetto. NON utilizzare quando si crea una nuova app da zero (utilizza invece experience-ui-bundle-app-coordinate).
