Vista de 360° de Data Cloud de una única sesión de Agentforce. Extrae 24 filas STDM + GenAI DMO a través de la API REST de DC Query, ensambla un árbol de sesión jerárquico (Interacción → Paso → Generación → GatewayRequest), genera un resumen legible por humanos con transcripción + invocaciones de tema/acción por turno + generaciones de LLM + llamadas a herramientas + cadena de auditoría. DISPARA cuando el usuario solicita rastrear, inspeccionar, resumir o describir una sesión de Agentforce específica por ID de sesión (UUID de sesión de agente `019d…` o ID de sesión de mensajería `0Mw…`). También se activa al descubrir sesiones (buscar/enumerar/buscar sesiones por hora, agente, canal, resultado o texto de conversación) cuando el usuario aún no tiene una identificación de sesión. NO DISPARE para preguntas sobre arquitectura en tiempo de diseño (use investigating-agentforce-architecture en su lugar) o para preguntas sobre rendimiento/latencia/SLO en tiempo de ejecución que requieren telemetría de plataforma más allá de Data Cloud.
