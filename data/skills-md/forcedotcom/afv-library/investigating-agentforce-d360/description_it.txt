Data Cloud Vista a 360° di una singola sessione Agentforce. Estrae 24 righe STDM + GenAI DMO tramite l'API REST DC Query, assembla un albero di sessione gerarchico (Interazione → Passaggio → Generazione → GatewayRequest), esegue il rendering di un riepilogo leggibile dall'uomo con trascrizione + invocazioni di argomenti/azioni per turno + generazioni LLM + chiamate a strumenti + catena di audit. SI ATTIVA quando l'utente chiede di tracciare, ispezionare, riepilogare o descrivere una sessione specifica di Agentforce tramite l'ID di sessione (UUID sessione dell'agente `019d…` o ID MessagingSession `0Mw…`). Si attiva anche all'individuazione della sessione (trova/elenca/cerca sessioni per ora, agente, canale, risultato o testo della conversazione) quando l'utente non ha ancora un ID sessione. NON ATTIVARE per domande sull'architettura in fase di progettazione (usa invece indagating-agentforce-architecture) o per domande su prestazioni/latenza/SLO di runtime che richiedono la telemetria della piattaforma oltre Data Cloud.
