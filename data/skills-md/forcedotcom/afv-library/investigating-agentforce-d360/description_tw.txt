單一 Agentforce 會話的資料雲 360° 視圖。透過 DC 查詢 REST API 拉取 24 個 STDM + GenAI DMO 行，組裝分層會話樹（互動 → 步驟 → 產生 → GatewayRequest），透過腳本 + 每輪主題/操作呼叫 + LLM 產生 + 工具呼叫 + 審計鏈呈現人類可讀的摘要。當使用者要求透過會話 ID（代理會話 UUID「019d...」或 MessagingSession id「0Mw...」）追蹤、檢查、總結或描述特定 Agentforce 會話時觸發。當使用者還沒有會話 ID 時，也會觸發會話發現 - 按時間、代理、頻道、結果或對話文字尋找/列出/搜尋會話。不要觸發設計時架構問題（改為使用調查-agentforce-架構）或需要資料雲以外的平台遙測的執行時間效能/延遲/SLO 問題。
