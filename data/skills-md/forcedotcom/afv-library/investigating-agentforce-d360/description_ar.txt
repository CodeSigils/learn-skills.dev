عرض Data Cloud 360° لجلسة Agentforce واحدة. يسحب 24 صفًا من صفوف STDM + GenAI DMO عبر DC Query REST API، ويجمع شجرة جلسات هرمية (التفاعل → الخطوة → الجيل → GatewayRequest)، ويقدم ملخصًا يمكن قراءته بواسطة الإنسان مع النص + استدعاءات الموضوع/الإجراء لكل دورة + أجيال LLM + استدعاءات الأدوات + سلسلة التدقيق. يتم تشغيله عندما يطلب المستخدم تتبع جلسة Agentforce معينة أو فحصها أو تلخيصها أو وصفها بواسطة معرف الجلسة (UUID لجلسة الوكيل `019d...` أو معرف MessagingSession `0Mw...`). يتم تشغيله أيضًا عند اكتشاف الجلسة - ابحث عن/قائمة/بحث الجلسات حسب الوقت أو الوكيل أو القناة أو النتيجة أو نص المحادثة - عندما لا يكون لدى المستخدم معرف جلسة حتى الآن. لا تقم بالطرح لأسئلة بنية وقت التصميم (استخدم هندسة وكيل القوة بدلاً من ذلك) أو لأسئلة أداء وقت التشغيل/زمن الوصول/SLO التي تتطلب قياس النظام الأساسي عن بعد خارج Data Cloud.
