Fase de preparación de Salesforce Data Cloud. Utilice esta habilidad cuando el usuario cree o administre flujos de datos de Data Cloud, DLO, transformaciones o configuraciones de Document AI. DISPARAR cuando: el usuario crea o administra flujos de datos de Data Cloud, DLO, transformaciones o configuraciones de Document AI, o pregunta sobre la ingestión en Data Cloud. NO DISPARAR cuando: la tarea es solo la configuración de la conexión (use la nube de datos de conexión), las DMO y la resolución de identidad (use la nube de datos armonizadora) o el trabajo de consulta/búsqueda (use la nube de datos de recuperación).
