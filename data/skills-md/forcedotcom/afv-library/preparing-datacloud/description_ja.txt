Salesforce データクラウドの準備フェーズ。このスキルは、ユーザーが Data Cloud データ ストリーム、DLO、変換、または Document AI 構成を作成または管理するときに使用します。トリガーされるタイミング: ユーザーが Data Cloud データ ストリーム、DLO、変換、または Document AI 構成を作成または管理する場合、または Data Cloud への取り込みについて問い合わせる場合。次の場合はトリガーしないでください: タスクが接続セットアップのみ (connecting-datacloud を使用)、DMO と ID 解決 (harmonizing-datacloud を使用)、またはクエリ/検索作業 (retrieving-datacloud を使用) である場合。
