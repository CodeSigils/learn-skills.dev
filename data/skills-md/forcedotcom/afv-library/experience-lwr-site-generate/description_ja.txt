DigitalExperience メタデータを介して Salesforce Experience Cloud LWR サイトを作成、変更、管理します。タスクに LWR サイト構成が関係する場合は、常にトリガーします。ページ/ルート/ビュー/テーマ レイアウト/ブランド セットの作成/変更、サイトのプレビュー、またはゲスト共有ルール (メタデータ タイプ SharingGuestRules)/ゲスト ユーザー アクセス/ゲスト ユーザーへのレコードの共有の作成/変更、またはユーザーがゲスト ユーザー ID (005 で始まる 15 文字または 18 文字) を提供した場合。 React またはその他の UI バンドル フレームワークを決してトリガーしないでください。 LWR サイトのみ。
