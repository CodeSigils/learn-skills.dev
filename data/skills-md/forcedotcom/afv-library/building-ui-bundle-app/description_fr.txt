DOIT s'activer lorsque le projet contient un répertoire uiBundles/*/src/ ou sfdx-project.json et que l'invite indique créer, construire, construire ou générer une nouvelle application, un nouveau site ou une nouvelle page à partir de zéro, même si l'invite décrit également le style visuel. DOIT également s'activer lorsque la tâche s'étend sur plus d'une compétence de l'interface utilisateur. Utilisez cette compétence lors de la création d’une application complète de bout en bout. Il s'agit de l'orchestrateur qui coordonne l'échafaudage, les fonctionnalités, l'accès aux données, l'interface utilisateur frontale, les intégrations et le déploiement dans l'ordre de dépendance correct. Sans cela, les phases s'exécutent dans le désordre et l'application se bloque. Ne PAS utiliser pour les applications Lightning Experience avec des objets personnalisés (utilisez generate-lightning-app). Ne PAS utiliser pour des modifications ponctuelles d'une page existante (utilisez building-ui-bundle-frontend).
