Salesforce-Datenoperationen mit 130-Punkte-Bewertung. Verwenden Sie diese Fähigkeit zum Erstellen, Aktualisieren, Löschen, Massenimport/-export, zum Generieren von Testdaten und zum Bereinigen von Organisationsdatensätzen mithilfe von SF-CLI und anonymem Apex. TRIGGER, wenn: Der Benutzer Testdaten erstellt, einen Massenimport/-export durchführt, SF-Daten-CLI-Befehle verwendet, Data Factory-Muster für Apex-Tests benötigt oder Datensätze in einer Salesforce-Organisation bereinigen/säen muss. NICHT AUSLÖSEN, wenn: Nur SOQL-Abfrageschreiben (verwenden Sie „platform-soql-query“), Apex-Testausführung (verwenden Sie „platform-apex-test-run“) oder Metadatenbereitstellung (verwenden Sie „platform-metadata-deploy“).
