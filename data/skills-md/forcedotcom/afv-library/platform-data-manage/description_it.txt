Operazioni sui dati Salesforce con punteggio di 130 punti. Utilizza questa competenza per creare, aggiornare, eliminare, importare/esportare in blocco, generare dati di test e pulire i record dell'organizzazione utilizzando sf CLI e Apex anonimo. SI ATTIVA quando: l'utente crea dati di test, esegue l'importazione/esportazione in blocco, utilizza i comandi CLI sf data, necessita di modelli di data factory per i test Apex o deve eseguire il seeding/pulire i record in un'organizzazione Salesforce. NON SI ATTIVA quando: solo scrittura di query SOQL (utilizza platform-soql-query), esecuzione del test Apex (utilizza platform-apex-test-run) o distribuzione di metadati (utilizza platform-metadata-deploy).
