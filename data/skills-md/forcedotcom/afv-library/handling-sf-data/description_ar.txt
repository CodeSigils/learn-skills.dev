عمليات بيانات Salesforce بتسجيل 130 نقطة. استخدم هذه المهارة لإنشاء وتحديث وحذف واستيراد/تصدير مجمع وإنشاء بيانات اختبار وتنظيف سجلات المؤسسة باستخدام sf CLI وApex المجهول. يتم تشغيله عندما: يقوم المستخدم بإنشاء بيانات اختبار، أو إجراء استيراد/تصدير مجمع، أو استخدام أوامر sf data CLI، أو يحتاج إلى أنماط مصنع البيانات لاختبارات Apex، أو يحتاج إلى زرع/تنظيف السجلات في مؤسسة Salesforce. لا تقم بالتشغيل عندما: كتابة استعلام SOQL فقط (استخدم الاستعلام-soql)، أو تنفيذ اختبار Apex (استخدم اختبارات التشغيل-apex)، أو نشر البيانات التعريفية (استخدم بيانات التعريف النشر).
