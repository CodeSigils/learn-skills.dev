يدير جميع أشكال تعيين مجموعة الاختبار لمراحل خط أنابيب DevOps Center عبر نقطة نهاية Connect API testSuiteStages. يغطي ثلاثة أوضاع: (أ) ربط مجموعة واحدة بمرحلة كإضافة لمرة واحدة، (ب) تعيين مجموعات متعددة بشكل مجمّع لمرحلة كإستراتيجية اختبار مع جدول إلزامي لمعاينة التأثير قبل أي تغييرات، و(ج) إضافة أو إزالة فئات اختبار فردية ضمن مهمة مجموعة مع قواعد الإدارة التي تستبعد الاختبارات المرفوضة وإعادة تقديم القائمة النهائية قبل الالتزام. يتم التشغيل عندما: يتم العثور على مجموعة غير مرتبطة بمرحلة التدفق ويريد المستخدم تعيينها؛ يريد المستخدم تكوين تعيينات من مجموعة إلى مرحلة عبر خط الأنابيب أو تعيين مجموعات متعددة للمراحل كجزء من استراتيجية الاختبار؛ يريد المستخدم إضافة أو إزالة الاختبارات في مجموعة، أو مزامنة الاختبارات التي تمت مراجعتها في مجموعة، أو ترقية الاختبارات إلى مجموعة. لا تقم بالتشغيل عند: تأليف فئات اختبار جديدة (استخدم اختبار قمة القمة) أو تشغيل الاختبارات مباشرة (استخدم اختبارات قمة التشغيل).
