透過 Connect API testSuiteStages 端點管理 DevOps 中心管道階段的所有形式的測試套件分配。涵蓋三種模式：（A）將單個套件作為一次性添加附加到階段，（B）將多個套件批量映射到階段作為測試策略，在任何更改之前使用強制影響預覽表，以及（C）在套件分配中添加或刪除單個測試類，並使用排除被拒絕的測試並在提交之前重新呈現最終列表的治理規則。觸發條件：發現套件與管道階段未鏈接，並且用戶想要分配它；作為測試策略的一部分，用戶希望跨管道配置套件到階段的映射或將多個套件分配到階段；用戶想要添加或刪除套件中的測試、將已審核的測試同步到套件中或將測試提升到套件中。請勿在下列情況下觸發：編寫新的測試類別（使用generate-apex-test）或直接執行測試（使用running-apex-tests）。
