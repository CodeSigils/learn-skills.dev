Управляет всеми формами назначения наборов тестов для этапов конвейера DevOps Center через конечную точку Connect API testSuiteStages. Охватывает три режима: (A) присоединение одного пакета к этапу в качестве единовременного добавления, (B) массовое сопоставление нескольких наборов с этапом в качестве стратегии тестирования с обязательной таблицей предварительного просмотра перед любыми изменениями и (C) добавление или удаление отдельных классов тестов в назначении пакета с правилами управления, которые исключают отклоненные тесты и повторно представляют окончательный список перед фиксацией. ТРИГГЕР, когда: пакет обнаружен не связанным с этапом конвейера, и пользователь хочет его назначить; пользователь хочет настроить сопоставление пакетов с этапами в конвейере или назначить несколько наборов этапам в рамках стратегии тестирования; пользователь хочет добавить или удалить тесты в наборе, синхронизировать проверенные тесты с набором или добавить тесты в набор. НЕ АКТИВИРУЙТЕСЬ при: создании новых тестовых классов (используйтеgenerating-apex-test) или непосредственном запуске тестов (используйте Running-apex-tests).
