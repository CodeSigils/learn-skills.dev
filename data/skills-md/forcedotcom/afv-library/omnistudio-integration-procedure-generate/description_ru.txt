Создание и проверка процедуры интеграции OmniStudio с оценкой 110 баллов. Используйте этот навык при создании оркестровок процессов на стороне сервера, которые сочетают в себе действия Data Mapper, удаленные действия Apex, вызовы HTTP и условную логику. ТРИГГЕР, когда: пользователь создает процедуры интеграции, добавляет шаги Data Mapper, настраивает удаленные действия или просматривает существующие конфигурации IP. НЕ ЗАПУСКАЕТСЯ при: создании сценариев OmniScript (используйте omnistudio-omniscript-generate), непосредственном создании преобразователей данных (используйте omnistudio-datamapper-generate) или анализе межкомпонентных зависимостей (используйте omnistudio-dependents-analyze).
