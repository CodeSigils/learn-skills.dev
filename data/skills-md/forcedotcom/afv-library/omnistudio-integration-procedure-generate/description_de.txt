Erstellung und Validierung des OmniStudio-Integrationsvorgangs mit 110-Punkte-Bewertung. Nutzen Sie diese Fähigkeit, wenn Sie serverseitige Prozessorchestrierungen erstellen, die Data Mapper-Aktionen, Apex-Remote-Aktionen, HTTP-Callouts und bedingte Logik kombinieren. TRIGGER, wenn: Der Benutzer Integrationsverfahren erstellt, Data Mapper-Schritte hinzufügt, Remote-Aktionen konfiguriert oder vorhandene IP-Konfigurationen überprüft. NICHT AUSLÖSEN, wenn: OmniScripts erstellt werden (verwenden Sie omnistudio-omniscript-generate), Data Mapper direkt erstellt werden (verwenden Sie omnistudio-datamapper-generate) oder komponentenübergreifende Abhängigkeiten analysiert werden (verwenden Sie omnistudio-dependencies-analyze).
