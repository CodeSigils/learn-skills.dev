Analysiert einen Commit-Diff und die verfügbaren Metadaten der DevOps Center-Testsuite, um die relevantesten vorhandenen Testsuiten zu empfehlen, und markiert dann Abdeckungslücken, bei denen keine Suite eine neue Methode abdeckt – durch reine Argumentation, keine Systemaufrufe über die erforderlichen Abfragen hinaus. Verwenden Sie diese Fähigkeit, wenn ein Entwickler wissen möchte, welche Testsuiten für einen bestimmten Commit oder Diff ausgeführt werden sollen, welche Tests seine Änderungen abdecken oder Suite-Empfehlungen zum Zeitpunkt des Commits wünschen. TRIGGER, wenn: Der Benutzer fragt, welche Testsuiten für einen Commit/Diff ausgeführt werden sollen, welche Tests seine Änderungen abdecken oder vor der Heraufstufung nach Suite-Empfehlungen fragt. NICHT AUSLÖSEN, wenn: neue Tests erstellt werden (generierender-apex-test verwenden) oder sf-apex-run-test direkt ausgeführt wird (running-apex-tests verwenden).
