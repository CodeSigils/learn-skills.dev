Analizza una differenza di commit e i metadati della suite di test DevOps Center disponibili per consigliare le suite di test esistenti più rilevanti, quindi segnala le lacune di copertura in cui nessuna suite copre un nuovo metodo, tramite puro ragionamento, nessuna chiamata di sistema oltre le query prerequisite. Utilizza questa competenza quando uno sviluppatore desidera sapere quali suite di test eseguire per un commit o un differenziale specifico, quali test coprono le modifiche o desidera consigli sulle suite al momento del commit. TRIGGER quando: l'utente chiede quali suite di test eseguire per un commit/diff, chiede quali test coprono le modifiche o chiede consigli sulle suite prima di promuovere. NON SI ATTIVA quando: si creano nuovi test (usa generation-apex-test) o si esegue direttamente sf apex run test (usa running-apex-tests).
