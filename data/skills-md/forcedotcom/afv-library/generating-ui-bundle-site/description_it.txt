DEVE essere attivato quando il progetto contiene una directory uiBundles/*/src/ e l'attività prevede la creazione o la configurazione dell'infrastruttura del sito. Utilizzare questa competenza durante la creazione o la configurazione di un sito Salesforce Digital Experience per l'hosting di un pacchetto UI. Attiva quando esistono file corrispondenti a digitalExperiences/, reti/, customSite/ o DigitalExperienceBundle e necessitano di modifiche oppure quando l'utente desidera pubblicare, ospitare o configurare l'accesso ospite per la propria app.
