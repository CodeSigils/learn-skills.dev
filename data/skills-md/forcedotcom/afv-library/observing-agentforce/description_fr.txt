Analysez le comportement de l'agent Agentforce de production à l'aide des traces de session et de Data Cloud. DÉCLENCHEMENT lorsque : l'utilisateur interroge les données de session STDM ou les enregistrements de trace Data Cloud ; enquête sur les pannes, les régressions ou les problèmes de performances des agents de production ; pose des questions sur les traces de session, les journaux de conversation ou les métriques de l'agent ; souhaite reproduire un problème de production signalé en avant-première ; exécute des requêtes findSessions ou d’analyse de trace. NE PAS DÉCLENCHER lorsque : l'utilisateur crée, modifie ou débogue des fichiers .agent pendant le développement (utilisez development-agentforce) ; écrit ou exécute des spécifications de test (utilisez testing-agentforce) ; utilise l'aperçu de l'agent SF pour l'itération de développement local ; déploie ou publie des agents.
