Architettura di integrazione di Salesforce e funzionalità di runtime con punteggio di 120 punti. Utilizza questa competenza per impostare credenziali denominate, credenziali esterne, servizi esterni, modelli di callout REST/SOAP, eventi della piattaforma e Change Data Capture. SI ATTIVA quando: l'utente configura credenziali denominate, servizi esterni, chiamate REST/SOAP, eventi piattaforma, CDC o tocca file .namedCredential-meta.xml. NON SI ATTIVA quando: configurazione app connessa/OAuth (usa integrazione-connettività-connessa-app-configura), logica solo Apex (usa piattaforma-apex-generate), importazione/esportazione dati (usa piattaforma-data-gestione) o metadati di appartenenza al canale CDC come PlatformEventChannel, PlatformEventChannelMember o EnrichedField (usa integrazione-eventing-cdc-configure).
