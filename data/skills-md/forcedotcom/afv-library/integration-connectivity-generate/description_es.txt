Arquitectura de integración de Salesforce y plomería de tiempo de ejecución con puntuación de 120 puntos. Utilice esta habilidad para configurar credenciales con nombre, credenciales externas, servicios externos, patrones de llamada REST/SOAP, eventos de plataforma y captura de datos modificados. SE DISPARA cuando: el usuario configura credenciales con nombre, servicios externos, llamadas REST/SOAP, eventos de plataforma, CDC o toca archivos .namedCredential-meta.xml. NO DISPARAR cuando: Configuración de aplicación conectada/OAuth (use integración-conectividad-configuración-de-aplicación-conectada), lógica exclusiva de Apex (use plataforma-apex-generate), importación/exportación de datos (use plataforma-administración de datos) o metadatos de membresía de canal CDC como PlatformEventChannel, PlatformEventChannelMember o EnrichedField (use integración-eventing-cdc-configure).
