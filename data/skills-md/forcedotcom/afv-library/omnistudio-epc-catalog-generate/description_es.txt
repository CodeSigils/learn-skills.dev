Habilidad de modelado de productos CME EPC de Salesforce Industries para la creación de catálogos basados ​​en Product2. Úselo al crear productos EPC, configurar atributos de productos, crear paquetes de ofertas con elementos secundarios de productos o revisar metadatos JSON de EPC DataPack para cambios en el catálogo de productos. DISPARAR cuando: el usuario crea o actualiza registros EPC de Producto2, cargas útiles de Asignación de atributos, Metadatos de atributos/Valores predeterminados de atributos, paquetes de ofertas o relaciones de elementos de productos secundarios. NO DISPARE cuando: diseñe OmniScripts/FlexCards/procedimientos de integración (use omnistudio-omniscript-generate, omnistudio-flexcard-generate u omnistudio-integration-procedure-generate), implemente la lógica de negocios de Apex (use platform-apex-generate) o solucione problemas de canalizaciones de implementación (use platform-metadata-deploy).
