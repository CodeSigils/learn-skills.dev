UTILIZZA SEMPRE QUESTA COMPETENZA per assegnare set di autorizzazioni agli utenti dell'organizzazione. Assegna uno o più set di autorizzazioni agli utenti dell'organizzazione utilizzando il comando sf orgassign permset. SI ATTIVA quando l'utente chiede di assegnare, concedere, concedere, aggiungere o applicare set di autorizzazioni a utenti, amministratori, organizzazioni specifiche o utenti specifici. Supporta la concessione di autorizzazioni, la concessione dell'accesso e l'aggiunta di set di autorizzazioni all'amministratore predefinito o a utenti specifici tramite --on-behalf-of. NON ATTIVARE per elencare i set di autorizzazioni o controllare le autorizzazioni degli utenti.
