Verwenden Sie diese Fähigkeit, wenn Benutzer einen globalen Salesforce-Wertesatz erstellen, generieren oder validieren oder einen Standardwertesatz anpassen müssen. Wird ausgelöst, wenn Benutzer einen globalen Wertesatz (GlobalValueSet), einen Standardwertesatz (StandardValueSet), eine wiederverwendbare Auswahlliste, einen feldübergreifenden Auswahllistenwertesatz oder die Anpassung von Standardauswahllisten wie Branche, Lead-Quelle oder Opportunity-Phase erwähnen. Wird auch verwendet, wenn Benutzer beim Hinzufügen von Werten zu einer Standardauswahlliste, beim Verweisen auf einen Wertesatz aus einem benutzerdefinierten Feld oder beim Arbeiten mit .globalValueSet-meta.xml- oder .standardValueSet-meta.xml-Dateien auf Bereitstellungsfehler stoßen. TRIGGER NICHT für eine einmalige Inline-Auswahlliste für ein einzelnes Feld ohne Wiederverwendung oder für allgemeine Metadatenarbeit mit benutzerdefinierten Feldern, die kein GlobalValueSet oder StandardValueSet umfasst – verwenden Sie stattdessen „platform-custom-field-generate“.
