사용자가 Salesforce 전역 값 집합을 생성, 생성 또는 검증해야 하거나 표준 값 집합을 사용자 정의해야 하는 경우 이 기술을 사용하십시오. 사용자가 전역 값 세트, GlobalValueSet, 표준 값 세트, StandardValueSet, 재사용 가능한 선택 목록, 필드 간에 공유되는 선택 목록 값 세트 또는 산업, 리드 소스 또는 기회 단계와 같은 표준 선택 목록 사용자 정의를 언급할 때 트리거됩니다. 또한 사용자가 표준 선택 목록에 값을 추가하거나, 사용자 정의 필드에서 설정된 값을 참조하거나, .globalValueSet-meta.xml 또는 .standardValueSet-meta.xml 파일로 작업하면서 배포 오류가 발생한 경우에도 사용합니다. 재사용이 없는 단일 필드의 인라인 일회용 선택 목록이나 GlobalValueSet 또는 StandardValueSet을 포함하지 않는 일반 사용자 정의 필드 메타데이터 작업의 경우 트리거하지 마십시오. 대신 platform-custom-field-generate를 사용하십시오.
