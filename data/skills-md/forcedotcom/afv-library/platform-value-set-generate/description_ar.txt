استخدم هذه المهارة عندما يحتاج المستخدمون إلى إنشاء مجموعة قيم عالمية لـ Salesforce أو إنشائها أو التحقق من صحتها أو تخصيص مجموعة قيم قياسية. يتم تشغيله عندما يذكر المستخدمون مجموعة قيم عامة، أو GlobalValueSet، أو مجموعة القيم القياسية، أو StandardValueSet، أو قائمة اختيار قابلة لإعادة الاستخدام، أو مجموعة قيم قائمة اختيار مشتركة عبر الحقول، أو تخصيص قوائم الاختيار القياسية مثل الصناعة أو مصدر العميل المتوقع أو مرحلة الفرصة. يُستخدم أيضًا عندما يواجه المستخدمون أخطاء في النشر، حيث يقومون بإضافة قيم إلى قائمة اختيار قياسية، أو الرجوع إلى مجموعة قيم من حقل مخصص، أو العمل مع ملفات .globalValueSet-meta.xml أو .standardValueSet-meta.xml. لا تقم بتشغيل قائمة اختيار مضمنة لمرة واحدة في حقل واحد بدون إعادة استخدام، أو لعمل بيانات تعريف الحقل المخصص العام الذي لا يتضمن GlobalValueSet أو StandardValueSet - استخدم إنشاء حقل مخصص للنظام الأساسي بدلاً من ذلك.
