Utilizzare questa competenza quando gli utenti devono creare, generare o convalidare un insieme di valori globali Salesforce o personalizzare un insieme di valori standard. Si attiva quando gli utenti menzionano un set di valori globali, GlobalValueSet, un set di valori standard, StandardValueSet, un elenco di selezione riutilizzabile, un set di valori di elenchi di selezione condiviso tra campi o personalizzano elenchi di selezione standard come Settore, Origine lead o Fase opportunità. Da utilizzare anche quando gli utenti riscontrano errori di distribuzione aggiungendo valori a un elenco di selezione standard, facendo riferimento a un set di valori da un campo personalizzato o lavorando con file .globalValueSet-meta.xml o .standardValueSet-meta.xml. NON ATTIVARE per un elenco di selezione una tantum in linea su un singolo campo senza riutilizzo o per il lavoro generale sui metadati dei campi personalizzati che non coinvolge un GlobalValueSet o StandardValueSet: utilizzare invece platform-custom-field-generate.
