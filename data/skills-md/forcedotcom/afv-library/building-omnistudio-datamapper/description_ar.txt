إنشاء OmniStudio Data Mapper (المعروف سابقًا باسم DataRaptor) والتحقق من صحته بتسجيل 100 نقطة. يُستخدم عند إنشاء مخططات بيانات استخراج أو تحويل أو تحميل أو استخراج توربو، أو تعيين حقول كائنات Salesforce، أو مراجعة تكوينات مخطط البيانات الموجودة. يتم تشغيله عندما: يقوم المستخدم بإنشاء مخططي البيانات، أو تكوين تعيينات الحقول، أو العمل مع بيانات تعريف OmniDataTransform، أو السؤال عن أنماط DataRaptor/Data Mapper. لا تقم بالتشغيل عند: بناء إجراءات التكامل (استخدم إجراء تكامل البناء الشامل)، أو تأليف OmniScripts (استخدم البناء متعدد الاستخدامات، أو تحليل التبعيات عبر المكونات (استخدم تبعيات التحليل الشامل الاستوديو).
