Verwenden Sie diese Fähigkeit, wenn Benutzer Salesforce Lightning-Seiten (FlexiPages) erstellen, generieren, ändern oder validieren müssen. Wird ausgelöst, wenn Benutzer RecordPage, AppPage, HomePage, Lightning-Seiten, Seitenlayouts, das Hinzufügen von Komponenten zu Seiten oder die Seitenanpassung erwähnen. Verwenden Sie es auch, wenn Benutzer Dinge sagen wie „Erstellen Sie eine Lightning-Seite“, „Fügen Sie einer Seite eine Komponente hinzu“, „Anpassen der Datensatzseite“, „Generieren Sie eine FlexiPage“ oder wenn sie mit FlexiPage-XML-Dateien arbeiten und Hilfe bei Komponenten, Regionen oder Bereitstellungsfehlern benötigen. Verwenden Sie diese Fähigkeit immer für alle Arbeiten im Zusammenhang mit FlexiPage, auch wenn im Kontext von Salesforce nur „Seite“ erwähnt wird.
