이 기술을 사용하여 DevOps Center 작업 항목의 전체 수명주기(목록 작성, 생성, 업데이트, 변경 사항 커밋, 상태 전환 수행, 끌어오기 요청 생성)를 관리합니다. 제목, 설명, 상태 등의 필드를 업데이트하세요. 작업 항목 분기에 코드 변경 사항을 커밋하고 푸시합니다. DevOps Center API를 통해 작업 항목 분기에 대한 풀 요청을 생성합니다. 사용자가 작업 항목을 추적, 찾기, 생성 또는 업데이트하고, 작업 항목 분기에 변경 사항을 커밋하고, 파이프라인을 통해 작업 항목 상태를 향상시키거나, 코드 검토를 위한 끌어오기 요청을 생성하려고 할 때 호출합니다. SF DevOps 작업 항목 및 검토 작업을 통합합니다. 승격이나 배포 작업 또는 충돌 감지를 위해 트리거하지 마세요.
