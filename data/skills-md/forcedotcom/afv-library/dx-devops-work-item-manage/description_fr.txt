Utilisez cette compétence pour gérer le cycle de vie complet des éléments de travail du DevOps Center : répertorier, créer, mettre à jour, valider les modifications, effectuer des transitions de statut et créer des demandes d'extraction. Mettez à jour les champs tels que le sujet, la description et le statut. Validez et transmettez les modifications de code aux branches d’éléments de travail. Créez des demandes d'extraction pour les branches d'éléments de travail via l'API DevOps Center. Invoquer lorsque l'utilisateur souhaite suivre, rechercher, créer ou mettre à jour un élément de travail, valider des modifications dans une branche d'élément de travail, faire progresser le statut d'un élément de travail dans le pipeline ou créer une demande d'extraction pour la révision du code. Consolide les éléments de travail et les opérations de révision de SF Devops. NE PAS DÉCLENCHER pour des opérations de promotion ou de déploiement, ou pour la détection de conflits.
