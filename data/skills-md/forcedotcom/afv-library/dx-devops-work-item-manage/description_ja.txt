このスキルを使用して、DevOps Center の作業項目のライフサイクル全体 (変更の一覧表示、作成、更新、コミット、ステータス遷移の実行、プル リクエストの作成) を管理します。件名、説明、ステータスなどのフィールドを更新します。コードの変更を作業項目ブランチにコミットしてプッシュします。 DevOps Center API を介して作業項目ブランチのプル リクエストを作成します。ユーザーが作業項目の追跡、検索、作成、更新を行う場合、作業項目ブランチへの変更をコミットする場合、パイプラインを通じて作業項目のステータスを進める場合、またはコード レビュー用のプル リクエストを作成する場合に呼び出します。 sf devops の作業項目とレビュー操作を統合します。プロモーションまたはデプロイメント操作、または競合検出のためにトリガーしないでください。
