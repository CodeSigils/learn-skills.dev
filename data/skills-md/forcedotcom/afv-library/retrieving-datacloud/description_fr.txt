Phase de récupération de Salesforce Data Cloud. Utilisez cette compétence lorsque l'utilisateur exécute Data Cloud SQL, des requêtes asynchrones, une recherche vectorielle, des workflows d'index de recherche ou une introspection de métadonnées pour les objets Data Cloud. DÉCLENCHEMENT lorsque : l'utilisateur exécute Data Cloud SQL, décrit, des requêtes asynchrones, une recherche vectorielle, des workflows d'index de recherche ou une introspection de métadonnées pour les objets Data Cloud. NE PAS DÉCLENCHER lorsque : la tâche est un CRM SOQL standard (utilisez querying-soql), une création de segment ou une conception d'informations calculées (utilisez segmenting-datacloud), ou une analyse STDM/traçage de session/parquet (utilisez observation-agentforce).
