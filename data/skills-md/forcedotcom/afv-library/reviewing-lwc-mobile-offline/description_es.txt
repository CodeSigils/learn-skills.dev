Revise un componente web Lightning para compatibilidad **móvil fuera de línea**: el analizador estático fuera de línea de Komaci que prepara previamente el gráfico de datos para Salesforce Mobile App Plus y Field Service Mobile App. Produce una lista de hallazgos con correcciones a nivel de código que cubren consultas GraphQL en línea en configuraciones `@wire`, directivas modernas `lwc:if` / `lwc:elseif` / `lwc:else` y violaciones de las reglas Komaci ESLint (propiedades de cable privado, referencias reactivas no locales, efectos secundarios del getter). Úselo cuando el usuario solicite una "revisión móvil sin conexión", "verificación de Komaci", "auditoría de cebado sin conexión", "fallo de cebado sin conexión" o "error de gráfico de datos sin conexión", o para validar un LWC con el conjunto de reglas recomendado por `@salesforce/eslint-plugin-lwc-graph-analyzer`. No lo use para revisión de código LWC genérico (use una habilidad de revisión de dominio adecuada) o para crear LWC con capacidades móviles nativas (use "uso de capacidades nativas móviles").
