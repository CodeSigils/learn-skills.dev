プロジェクトに uiBundles/*/src/ ディレクトリが含まれており、新しい UI バンドルまたはアプリをスキャフォールディングする場合、または ui-bundle.json、.uibundle-meta.xml、または CSP 信頼済みサイト ファイルを編集する場合は、アクティブ化する必要があります。このスキルは、sf テンプレートでスキャフォールディングして ui-bundle を生成する場合、ui-bundle.json (ルーティング、ヘッダー、outputDir) を構成する場合、または CSP 信頼済みサイトを登録する場合に使用します。タスクに *.uibundle-meta.xml、ui-bundle.json、または cspTrustedSites/*.cspTrustedSite-meta.xml に一致するファイルが含まれる場合にアクティブ化します。
