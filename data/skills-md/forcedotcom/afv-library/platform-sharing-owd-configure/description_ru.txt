Используйте, когда пользователь хочет получить или обновить параметры общего доступа по умолчанию (OWD) для всей организации для объектов Salesforce. СИГНАЛИЗИРУЕТСЯ, когда: пользователь запрашивает проверку текущих настроек OWD, просмотр настроек общего доступа по умолчанию, изменение уровней доступа по умолчанию (частный, общедоступный только для чтения, общедоступный для чтения/записи, контролируемый родителем), настройку внутреннего или внешнего доступа к стандартным или настраиваемым объектам, упоминает настройки по умолчанию для всей организации, хочет сделать записи частными или ограничить круг лиц, которые могут видеть записи, хочет контролировать видимость записей по умолчанию для объекта или ссылается на поля общего доступа .settings-meta.xml или ShareModel в Файлы .object-meta.xml. НЕ АКТИВИРУЙТЕСЬ, когда: пользователь спрашивает о правилах совместного использования, совместном использовании на основе критериев, иерархии ролей или совместном использовании вручную — делегируйте полномочия по созданию правил совместного использования платформы.
