Types de métadonnées ISV App Analytics : AppAnalyticsQueryRequest et AppAnalyticsSettings. Utilisez cette compétence lorsque l'utilisateur demande comment récupérer les données d'utilisation des packages gérés, configurer le mode de simulation App Analytics, interroger les instantanés d'abonnés ou comprendre le cycle de vie AppAnalyticsQueryRequest (Nouveau → En attente → Terminé → Expiré). DÉCLENCHEMENT lorsque : l'utilisateur mentionne App Analytics, AppAnalyticsQueryRequest, AppAnalyticsSettings, les données d'utilisation du package, l'analyse des abonnés, l'analyse ISV ou le mode de simulation pour l'analyse des applications. NE PAS DÉCLENCHER lorsque : la tâche concerne des rapports/tableaux de bord Salesforce standard (utiliser des compétences en matière de reporting), un SOQL personnalisé sur un compte/un contact (utiliser platform-soql-query) ou une requête/recherche Data Cloud (utiliser data360-query).
