Compétence de création Apex principale pour la génération, la refactorisation et la révision de classes. TOUJOURS ACTIVER lorsque l'utilisateur mentionne Apex, .cls, déclenche ou demande de créer/refactoriser une classe (service, sélecteur, domaine, lot, file d'attente, planifiable, invocable, DTO, utilitaire, interface, résumé, exception, ressource REST). Utilisez cette compétence pour les requêtes impliquant SObject CRUD, le mappage de collections, la récupération d'enregistrements associés, les tâches planifiées, les tâches par lots, la conception de déclencheurs, les contrôleurs @AuraEnabled, les points de terminaison @RestResource, les API REST personnalisées ou la révision du code d'Apex existant.
