Habilidad de creación primaria de Apex para generación, refactorización y revisión de clases. ACTIVAR SIEMPRE cuando el usuario mencione Apex, .cls, activadores o solicite crear/refactorizar una clase (servicio, selector, dominio, lote, en cola, programable, invocable, DTO, utilidad, interfaz, resumen, excepción, recurso REST). Utilice esta habilidad para solicitudes que involucren SObject CRUD, mapeo de colecciones, obtención de registros relacionados, trabajos programados, trabajos por lotes, diseño de desencadenadores, controladores @AuraEnabled, puntos finales @RestResource, API REST personalizadas o revisión de código de Apex existente.
