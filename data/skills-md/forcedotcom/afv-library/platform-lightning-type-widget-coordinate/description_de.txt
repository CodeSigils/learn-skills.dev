Orchestrieren Sie die Generierung von Apex-gestützten Lightning Type + HXL-Widgets. TRIGGER nur, wenn die Eingabeaufforderung AUSDRÜCKLICH Lightning-Typen aufruft: Der Benutzer sagt „Lightning-Typ“, „CLT“, „Benutzerdefinierter Lightning-Typ“, „Apex-gestützter Typ“, verweist auf „@apexClassType/...“, bittet darum, ein Widget oder eine Karte für einen benannten Lightning-Typ zu erstellen, bittet darum, einen neuen Lightning-Typ und ein neues Widget zusammen zu erstellen, oder verankert ein Widget in einer bestimmten Apex-Klasse als Schema. NICHT AUSLÖSEN, wenn die Eingabeaufforderung nur ein Subjekt, eine Domäne, ein Feature oder ein Entitätsnomen nennt. Auch NICHT AUSLÖSEN, wenn: nur ein benutzerdefinierter Lightning-Typ erstellt wird (verwenden Sie platform-custom-lightning-type-generate), nur eine Apex-Klasse (verwenden Sie platform-apex-generate), ein vorhandenes Widget ohne Änderung des Lightning-Typs bearbeitet wird oder ein Widget auf einem objekt-/JSON-basierten Lightning-Typ basiert (lightning__objectType mit Grundelementen).
