Apex を利用した Lightning Type + HXL ウィジェットの生成を調整します。プロンプトが Lightning タイプを明示的に呼び出す場合にのみトリガーします。ユーザーが「Lightning Type」、「CLT」、「Custom Lightning Type」、「Apex-backed type」と言う場合、「@apexClassType/...」を参照する場合、名前付き Lightning タイプのウィジェットまたはカードを構築するように要求する場合、新しい Lightning タイプとウィジェットを一緒に作成するように要求する場合、またはウィジェットを特定の Apex クラスに固定する場合に限ります。スキーマ。プロンプトが件名、ドメイン、機能、またはエンティティの名詞のみを指定している場合はトリガーしないでください。また、カスタム Lightning タイプのみ (platform-custom-lightning-type-generate を使用)、Apex クラスのみ (platform-apex-generate を使用) を作成している場合、Lightning Type を変更せずに既存のウィジェットを編集している場合、またはオブジェクト/JSON ベースの Lightning Type (プリミティブを含む lightning__objectType) にウィジェットを固定している場合にもトリガーしないでください。
