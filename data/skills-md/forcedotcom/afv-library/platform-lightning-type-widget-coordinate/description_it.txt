Orchestra la generazione di widget Lightning Type + HXL supportata da Apex. SI ATTIVA solo quando il prompt richiama ESPLICITAMENTE i tipi di Lightning: l'utente dice "Tipo di Lightning", "CLT", "Tipo di Lightning personalizzato", "Tipo supportato da Apex", fa riferimento a "@apexClassType/...", chiede di creare un widget o una scheda per un tipo di Lightning con nome, chiede di creare un nuovo tipo di Lightning e un widget insieme o fonda un widget in una classe Apex specifica come schema. NON SI ATTIVA quando il prompt nomina solo un soggetto, un dominio, una caratteristica o un nome di entità. Inoltre NON SI ATTIVA quando: si crea solo un tipo Lightning personalizzato (utilizzare platform-custom-lightning-type-generate), solo una classe Apex (utilizza platform-apex-generate), si modifica un widget esistente senza alcuna modifica del tipo Lightning o si basa un widget su un tipo Lightning basato su oggetto/JSON (lightning__objectType con primitive).
