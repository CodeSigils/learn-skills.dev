Utilizzare questa competenza quando gli utenti devono creare tipi Lightning personalizzati (CLT) per le azioni dell'agente Einstein o schemi di input/output strutturati. Si attiva quando gli utenti menzionano CLT, Custom Lightning Types, Custom Lightning Types (CLT) con rendering/renderer di widget/mosaico/frammento, schemi JSON per agenti, definizioni di tipo, lightning__objectType o configurazioni di editor/renderer. Quando vengono richieste le rappresentazioni dei widget, DEVI prima leggere il file di riferimento widget-rendition.md nella directory references/ di questa abilità e seguire il suo flusso di lavoro completo. Questo è complesso: usa sempre questa abilità per il lavoro CLT.
