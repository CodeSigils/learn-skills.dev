在管道阶段（升级前、升级后或审核事件）端到端运行 DevOps 中心测试套件：在显式确认门后通过 Connect API 触发异步执行，然后按提供程序特定的时间间隔按 runId 进行轮询，直到完成、失败或超时，并将结果交给故障分析。修复后也会重新触发质量门，但只有在覆盖率达到阈值时才重新触发。当用户想要在舞台上运行、启动或启动测试套件、重新运行质量门或观看正在进行的运行直至完成时，请使用此技能。触发时间：用户想要在阶段上运行/启动套件、在升级之前或之后执行测试、修复故障后重新运行质量门、添加测试后解锁受阻止的升级，或轮询/观看正在进行的运行。不要在以下情况下触发：直接运行 sf apex run test（使用 platform-apex-test-run），或配置新的门或阈值（使用 dx-devops-test-pipeline-configure）。
