تشغيل مجموعات اختبار DevOps Center على مرحلة المسار (حدث ما قبل الترويج، أو ما بعد الترويج، أو المراجعة) من النهاية إلى النهاية: تشغيل التنفيذ غير المتزامن عبر Connect API بعد بوابة تأكيد صريحة، ثم الاستقصاء بواسطة runId على فترات زمنية خاصة بالموفر حتى يكتمل أو يفشل أو تنتهي المهلة، ويسلم النتائج لتحليل الفشل. يتم أيضًا إعادة تشغيل بوابة الجودة بعد الإصلاحات، ولكن بمجرد أن تصل التغطية إلى الحد الأدنى. استخدم هذه المهارة عندما يريد المستخدم تشغيل مجموعات الاختبار أو إطلاقها أو إطلاقها على المسرح، أو إعادة تشغيل بوابة الجودة، أو مشاهدة عملية التشغيل الجارية حتى الاكتمال. يتم التشغيل عندما: يريد المستخدم تشغيل/إطلاق مجموعات على خشبة المسرح، أو تنفيذ الاختبارات قبل الترقية أو بعدها، أو إعادة تشغيل بوابة الجودة بعد إصلاح حالات الفشل، أو إلغاء حظر الترويج المحظور بعد إضافة الاختبارات، أو استطلاع/مشاهدة تشغيل قيد التقدم. لا تقم بالتشغيل عند: تشغيل اختبار تشغيل sf apex مباشرةً (استخدم اختبار تشغيل النظام الأساسي)، أو تكوين بوابة أو عتبة جديدة (استخدم dx-devops-test-pipeline-configure).
