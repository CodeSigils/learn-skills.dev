Esegue le suite di test DevOps Center in una fase della pipeline (evento di pre-promozione, post-promozione o revisione) end-to-end: attiva l'esecuzione asincrona tramite l'API Connect dopo un cancello di conferma esplicito, quindi esegue il polling in base a runId a intervalli specifici del provider finché non viene completata, fallisce o scade e invia i risultati all'analisi degli errori. Inoltre, riattiva un controllo qualità dopo le correzioni, ma solo quando la copertura raggiunge la soglia. Utilizza questa competenza quando un utente desidera eseguire, avviare o lanciare suite di test su una fase, eseguire nuovamente un controllo qualità o guardare un'esecuzione in corso fino al completamento. ATTIVA quando: l'utente desidera eseguire/avviare suite su una fase, eseguire test prima o dopo la promozione, eseguire nuovamente un controllo qualità dopo aver corretto gli errori, sbloccare una promozione bloccata dopo aver aggiunto test o eseguire un sondaggio/osservare un'esecuzione in corso. NON SI ATTIVA quando: si esegue direttamente sf apex run test (usa platform-apex-test-run) o si configura un NUOVO gate o soglia (usa dx-devops-test-pipeline-configure).
