在明確的使用者確認門之後，透過 Connect API 在管道階段（預先升級、後升級或審核事件）觸發一個或多個 DevOps Center 測試套件的非同步執行，然後透過「輪詢測試結果」技能進行結果輪詢。修復後也會重新運行（重新觸發）品質門 - 但只有在驗證確認現在滿足覆蓋率閾值後才重新運行（重新觸發）質量門。觸發時間：使用者想要在管道階段運行、啟動或啟動測試套件；在晉升之前或之後執行測試；觸發促銷前、促銷後或審核事件運行；修復故障後重新運行質量門；一旦滿足覆蓋範圍，重試失敗的門；或在添加測試後解鎖被阻止的促銷。不要在以下情況下觸發：直接執行 sf apex run test（使用 running-apex-tests）；或設定新的閘或閾值（使用設定品質閘）。
