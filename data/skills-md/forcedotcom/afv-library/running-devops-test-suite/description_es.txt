Activa la ejecución asincrónica de uno o más conjuntos de pruebas de DevOps Center en una etapa de canalización (evento previo a la promoción, posterior a la promoción o revisión) a través de la API de Connect, después de una puerta de confirmación explícita del usuario, luego pasa al sondeo de resultados a través de la habilidad "resultados de la prueba de sondeo". También vuelve a ejecutar (reactiva) una puerta de calidad después de las correcciones, pero solo una vez que la validación confirma que se cumple el umbral de cobertura. DISPARAR cuando: el usuario desea ejecutar, iniciar o lanzar conjuntos de pruebas en una etapa de canalización; ejecutar pruebas antes o después de una promoción; desencadenar una ejecución de evento previo a la promoción, posterior a la promoción o revisión; volver a ejecutar un control de calidad después de corregir fallas; volver a intentar una puerta fallida una vez que se alcance la cobertura; o desbloquear una promoción bloqueada después de agregar pruebas. NO DISPARE cuando: ejecute sf apex run test directamente (use running-apex-tests); o configurar una NUEVA puerta o umbral (use configuración de puerta de calidad).
