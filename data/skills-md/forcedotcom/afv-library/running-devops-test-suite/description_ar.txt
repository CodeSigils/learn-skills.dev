تشغيل التنفيذ غير المتزامن لواحدة أو أكثر من مجموعات اختبار DevOps Center في مرحلة التدفق (حدث ما قبل الترويج، أو ما بعد الترويج، أو مراجعة الحدث) عبر Connect API، بعد بوابة تأكيد صريحة للمستخدم، ثم قم بالتمرير لاستقصاء النتائج عبر مهارة "نتائج اختبار الاقتراع". يتم أيضًا إعادة تشغيل (إعادة تشغيل) بوابة الجودة بعد الإصلاحات - ولكن بمجرد أن يؤكد التحقق من الصحة استيفاء حد التغطية الآن. يتم التشغيل عندما: يريد المستخدم تشغيل مجموعات الاختبار أو إطلاقها أو إطلاقها على مرحلة المسار؛ تنفيذ الاختبارات قبل الترقية أو بعدها؛ تشغيل حدث ما قبل الترويج، أو الترويج اللاحق، أو المراجعة؛ إعادة تشغيل بوابة الجودة بعد إصلاح الأعطال؛ أعد محاولة البوابة الفاشلة بمجرد استيفاء التغطية؛ أو قم بإلغاء حظر الترويج المحظور بعد إضافة الاختبارات. لا تقم بالتشغيل عند: تشغيل اختبار التشغيل sf apex مباشرة (استخدم اختبارات التشغيل-apex)؛ أو تكوين بوابة أو عتبة جديدة (استخدم تكوين بوابة الجودة).
