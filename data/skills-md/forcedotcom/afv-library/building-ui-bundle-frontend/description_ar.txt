يجب التنشيط قبل تحرير أي ملف ضمن uiBundles/*/src/ للتغييرات المرئية أو تغييرات واجهة المستخدم لتطبيق موجود - الصفحات أو المكونات أو الأقسام أو التخطيط أو التصميم أو الألوان أو الخطوط أو التنقل أو الرسوم المتحركة أو أي تغيير في الشكل والمظهر. استخدم هذه المهارة عند تعديل الصفحات أو المكونات أو التخطيط أو التصميم أو التنقل في تطبيق حزمة واجهة المستخدم الحالي. يتم التنشيط عندما يحتوي المشروع على appLayout.tsx، أو Routes.tsx، أو src/pages/، أو src/components/، أو global.css. تحتوي هذه المهارة على اصطلاحات مهمة خاصة بالمشروع (appLayout.tsx shell، ومكونات shadcn/ui، وTailwind CSS، وتوجيه المسار الأساسي لـ Salesforce، وقيود الوحدة النمطية) التي تتجاوز المعرفة العامة. بدون هذه المهارة، ستستخدم التعليمات البرمجية التي تم إنشاؤها عمليات استيراد خاطئة، أو قطع التوجيه، أو تجاهل بنية المشروع. لا تستخدمه عند إنشاء تطبيق جديد من البداية (استخدم build-ui-bundle-app بدلاً من ذلك).
