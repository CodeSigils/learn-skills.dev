Orchestratore di prodotti Salesforce Data Cloud per flussi di lavoro di connessione→preparazione→armonizzazione→segmentazione→azione. Utilizza questa competenza quando l'utente ha bisogno di una pipeline Data Cloud in più fasi, di risoluzione dei problemi in più fasi o di gestione dello spazio dati e dei kit dati. ATTIVA quando: l'utente ha bisogno di una pipeline Data Cloud in più fasi, chiede di configurare o risolvere i problemi di Data Cloud in tutte le fasi, gestisce spazi dati o kit di dati o desidera un flusso di lavoro sf data360 multifase. NON SI ATTIVA quando: il lavoro è isolato in una singola fase (utilizzare la competenza specifica della fase di corrispondenza), l'attività è STDM/tracciamento delle sessioni/telemetria del parquet (utilizzare osservatore-agentforce), SOQL CRM standard (utilizzare querying-soql) o implementazione Apex (utilizzare generazione-apex).
