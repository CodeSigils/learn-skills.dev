Оркестратор продуктов Salesforce Data Cloud для подключения → подготовки → гармонизации → сегментации → действий. Используйте этот навык, когда пользователю нужен многоэтапный конвейер облака данных, межфазное устранение неполадок или управление пространством данных и наборами данных. СРАБАТЫВАЙТЕ, когда: пользователю нужен многоэтапный конвейер Data Cloud, он запрашивает настройку или устранение неполадок Data Cloud на разных этапах, управляет пространствами данных или наборами данных или хочет использовать межфазный рабочий процесс SF data360. НЕ АКТИВИРУЙТЕСЬ, когда: работа изолирована от одного этапа (используйте соответствующий навык, специфичный для этапа), задачей является STDM/трассировка сеанса/телеметрия паркета (используйте Observer-Agentforce), стандартный SOQL CRM (используйте запрос-SOQL) или реализацию Apex (используйте генерирование-apex).
