منسق منتج Salesforce Data Cloud للاتصال → التحضير → التنسيق → المقطع → سير العمل الفعلي. استخدم هذه المهارة عندما يحتاج المستخدم إلى مسار Data Cloud متعدد الخطوات، أو استكشاف الأخطاء وإصلاحها عبر المراحل، أو إدارة مساحة البيانات ومجموعة البيانات. يتم التشغيل عندما: يحتاج المستخدم إلى مسار Data Cloud متعدد الخطوات، أو يطلب إعداد Data Cloud أو استكشاف أخطاء Data Cloud عبر المراحل، أو إدارة مساحات البيانات أو مجموعات البيانات، أو يريد سير عمل sf data360 عبر المراحل. لا تقم بالتشغيل عندما: يكون العمل معزولًا في مرحلة واحدة (استخدم مهارة المطابقة الخاصة بالمرحلة)، أو المهمة هي STDM/تتبع الجلسة/القياس عن بعد للباركيه (استخدم قوة وكيل المراقبة)، أو CRM SOQL القياسي (استخدم الاستعلام-soql)، أو تنفيذ Apex (استخدم التوليد-apex).
