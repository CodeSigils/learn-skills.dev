当 uiBundles/*/src/ 项目执行任何 Salesforce 记录操作（读取、创建、更新、删除或缓存/刷新查询结果）时，必须激活。触发器：导入 @salesforce/platform-sdk 的代码、调用 sdk.graphql.query / sdk.graphql.mutate / sdk.fetch、*.graphql 文件、需要强制刷新的陈旧数据，或者连接 UI 包的数据层以读取、写入或刷新 Salesforce 记录。新读/写工作的默认设置是使用当前 @salesforce/platform-sdk API 的读/写工作流程；仅当现有代码已使用旧的 @salesforce/sdk-data 可调用形式时才遵循迁移路径。不适用于构建应用程序 shell/UI、样式、文件上传或身份验证/搜索脚手架 — 使用其他 ui-bundle-* 技能。不要在以下情况下触发：OAuth 设置、架构更改、批量/工具/元数据 API 或声明性自动化。
