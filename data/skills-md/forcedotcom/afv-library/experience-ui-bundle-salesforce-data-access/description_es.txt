DEBE activarse cuando un proyecto uiBundles/*/src/ realiza CUALQUIER operación de registro de Salesforce: leer, crear, actualizar, eliminar o almacenar en caché/actualizar los resultados de la consulta. Desencadenantes: importación de código @salesforce/platform-sdk, llamadas a sdk.graphql.query / sdk.graphql.mutate / sdk.fetch, archivos *.graphql, datos obsoletos que necesitan una actualización forzada o conexión de la capa de datos de un paquete de interfaz de usuario para leer, escribir o actualizar registros de Salesforce. El valor predeterminado para el nuevo trabajo de lectura/escritura es el flujo de trabajo de lectura/escritura con la API @salesforce/platform-sdk actual; Solo siga la ruta de migración cuando el código EXISTENTE ya use el antiguo formulario invocable @salesforce/sdk-data. No para crear shell/UI de aplicaciones, estilo, carga de archivos o andamios de autenticación/búsqueda; use las otras habilidades ui-bundle-*. NO ACTIVAR cuando: configuración de OAuth, cambios de esquema, API masiva/herramientas/metadatos o automatización declarativa.
