Auslöser: Codeimport von @salesforce/platform-sdk, Aufrufe von sdk.graphql.query / sdk.graphql.mutate / sdk.fetch, *.graphql-Dateien, veraltete Daten, die eine erzwungene Aktualisierung erfordern, oder die Verbindung der Datenschicht eines UI-Bundles zum Lesen, Schreiben oder Aktualisieren von Salesforce-Datensätzen. Der Standardwert für neue Lese-/Schreibarbeiten ist der Lese-/Schreibworkflow mit der aktuellen @salesforce/platform-sdk-API; Folgen Sie dem Migrationspfad nur, wenn VORHANDENER Code bereits das alte aufrufbare @salesforce/sdk-data-Formular verwendet. Nicht zum Erstellen von App-Shell/UI, Styling, Datei-Upload oder Authentifizierungs-/Suchgerüst – verwenden Sie die anderen ui-bundle-*-Fähigkeiten.
