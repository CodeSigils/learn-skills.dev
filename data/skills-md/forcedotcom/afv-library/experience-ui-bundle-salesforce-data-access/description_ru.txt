ДОЛЖЕН активироваться, когда проект uiBundles/*/src/ выполняет ЛЮБУЮ операцию с записью Salesforce — чтение, создание, обновление, удаление или кэширование/обновление результатов запроса. Триггеры: импорт кода @salesforce/platform-sdk, вызовы sdk.graphql.query/sdk.graphql.mutate/sdk.fetch, *.graphql файлов, устаревшие данные, требующие принудительного обновления, или подключение уровня данных пакета пользовательского интерфейса для чтения, записи или обновления записей Salesforce. По умолчанию для новых операций чтения/записи используется рабочий процесс чтения/записи с текущим API @salesforce/platform-sdk; следуйте по пути миграции только в том случае, если СУЩЕСТВУЮЩИЙ код уже использует старую вызываемую форму @salesforce/sdk-data. Не для создания оболочки/UI приложения, стилизации, загрузки файлов или создания шаблонов аутентификации/поиска — используйте другие навыки ui-bundle-*. НЕ ЗАПУСКАЕТСЯ при: настройке OAuth, изменении схемы, API массовых операций/инструментов/метаданных или декларативной автоматизации.
