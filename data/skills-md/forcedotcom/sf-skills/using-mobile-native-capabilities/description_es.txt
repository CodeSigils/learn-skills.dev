Cree un LWC de Salesforce que utilice capacidades nativas del dispositivo móvil: escáner de códigos de barras, datos biométricos, ubicación, NFC, calendario, contactos, escáner de documentos, geocercas, captura de espacio AR, revisión de aplicaciones y pagos. Utilice esta habilidad cuando el usuario solicite un LWC que escanee un código de barras, capture una foto de un documento, lea la ubicación o las geocercas, solicite datos biométricos, lea/escriba el calendario o los contactos del dispositivo, toque NFC, acepte un pago, solicite una revisión de la aplicación o escanee un espacio AR. También se activa en "lightning/mobileCapabilities", "capacidad móvil", "Nimbus", "capacidad del dispositivo". No lo use para revisiones de preparación de Komaci/móvil sin conexión (use `reviewing-lwc-mobile-offline`) ni para seleccionar componentes básicos Lightning genéricos (use una habilidad de componentes básicos Lightning genéricos).
