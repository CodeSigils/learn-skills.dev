Utilizza questa competenza quando l'utente chiede di aggiungere, incorporare, integrare, configurare, applicare uno stile o rimuovere un agente, un chatbot, un widget di chat, un client di conversazione o un assistente AI in un progetto di pacchetto UI. TRIGGER quando: il progetto contiene una directory uiBundles/*/src/ e l'attività prevede l'aggiunta o la modifica di un widget di chat, chatbot o AI conversazionale; file in uiBundles/*/src/ import AgentforceConversationClient; l'utente chiede di aggiungere qualsiasi funzionalità di chat o agente a una pagina. NON SI ATTIVA quando: l'utente desidera creare da zero un agente personalizzato, un chatbot o un componente widget di chat; il progetto non ha una directory uiBundles.
