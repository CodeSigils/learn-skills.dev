Verwenden Sie diese Fähigkeit, wenn Benutzer Metadaten für Salesforce Lightning-Berichte erstellen, generieren oder validieren müssen. Wird ausgelöst, wenn Benutzer Berichte erwähnen, Berichte erstellen, Berichtsmetadaten, .report-meta.xml-Dateien, tabellarische Berichte, zusammenfassende Berichte, Matrixberichte, verbundene Berichte, Berichtsspalten, Berichtsgruppierungen, Berichtsfilter, Berichtsdiagramme, Kreuzfilter, Bucket-Felder, Berichtsformeln oder Berichtszeitrahmenfilter. Verwenden Sie es auch, wenn Benutzer Dinge sagen wie „Bericht erstellen“, „Bericht generieren“, „Bericht über Konten erstellen“, „Meinem Bericht ein Diagramm hinzufügen“ oder wenn sie auf Bereitstellungsfehler für .report-meta.xml-Dateien stoßen. NICHT auslösen für: Erstellen oder Ändern von Metadaten für benutzerdefinierte Berichtstypen (.reportType-meta.xml – verwenden Sie „platform-custom-report-type-generate“), Erstellen von Dashboards, Erstellen von Listenansichten, Ausführen oder Anzeigen vorhandener Berichte in der Benutzeroberfläche oder SOQL-Abfragen.
