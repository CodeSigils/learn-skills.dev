Utilizzare questa competenza quando gli utenti devono creare, generare o convalidare i metadati del report Salesforce Lightning. Si attiva quando gli utenti menzionano report, creano report, metadati di report, file .report-meta.xml, report tabulari, report di riepilogo, report a matrice, report uniti, colonne di report, raggruppamenti di report, filtri di report, grafici di report, filtri incrociati, campi bucket, formule di report o filtri dell'intervallo di tempo dei report. Da utilizzare anche quando gli utenti dicono cose come "crea un report", "genera un report", "crea un report sugli account", "aggiungi un grafico al mio report" o quando riscontrano errori di distribuzione per i file .report-meta.xml. NON eseguire l'attivazione per: creazione o modifica dei metadati del tipo di rapporto personalizzato (.reportType-meta.xml — utilizza platform-custom-report-type-generate), creazione di dashboard, creazione di visualizzazioni elenco, esecuzione o visualizzazione di report esistenti nell'interfaccia utente o query SOQL.
