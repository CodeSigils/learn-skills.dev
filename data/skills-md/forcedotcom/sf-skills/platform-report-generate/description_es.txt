Utilice esta habilidad cuando los usuarios necesiten crear, generar o validar metadatos de Salesforce Lightning Report. Se activa cuando los usuarios mencionan informes, crean informes, metadatos de informes, archivos .report-meta.xml, informes tabulares, informes resumidos, informes matriciales, informes unidos, columnas de informes, agrupaciones de informes, filtros de informes, gráficos de informes, filtros cruzados, campos de depósitos, fórmulas de informes o filtros de períodos de tiempo de informes. Utilícelo también cuando los usuarios digan cosas como "crear un informe", "generar un informe", "crear un informe sobre Cuentas", "agregar un gráfico a mi informe" o cuando encuentren errores de implementación para archivos .report-meta.xml. NO active para: crear o modificar metadatos de tipo de informe personalizado (.reportType-meta.xml: use platform-custom-report-type-generate), crear paneles, crear vistas de lista, ejecutar o ver informes existentes en la interfaz de usuario o consultas SOQL.
