Habilite la función CMDB (Base de datos de gestión de configuración) en Service Cloud ITSM en una organización de producción o sandbox: verifique el SKU de la organización CMDB, aprovisione el inquilino ITOM y habilite la función service-cloud-itsm-cmdb-integration que levanta la puerta de acceso a CMDB. Úselo cuando el usuario solicite habilitar CMDB, activar la base de datos de administración de configuración, aprovisionar el inquilino ITOM, habilitar la función CMDB o corregir un error CMDB 403 FUNCTIONALITY_NOT_ENABLED. Activadores activados: habilitar la función CMDB, aprovisionar el inquilino ITOM, activar CMDB, CMDB no habilitado, error CMDB 403, service-cloud-itsm-cmdb-integration. NO ACTIVAR cuando: el usuario solo desea asignar conjuntos de permisos CMDB a los usuarios, solo instalar un paquete de contenido CMDB o trabajar con registros CMDB directamente.
