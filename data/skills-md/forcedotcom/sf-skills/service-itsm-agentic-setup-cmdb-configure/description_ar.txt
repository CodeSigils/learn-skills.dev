قم بتمكين ميزة CMDB (قاعدة بيانات إدارة التكوين) في Service Cloud ITSM مقابل مؤسسة الإنتاج أو وضع الحماية: تحقق من SKU لمؤسسة CMDB، وقم بتوفير مستأجر ITOM، وقم بتمكين ميزة تكامل الخدمة السحابية-itsm-cmdb التي ترفع بوابة الوصول إلى CMDB. يُستخدم عندما يطلب المستخدم تمكين CMDB، أو تشغيل قاعدة بيانات إدارة التكوين، أو توفير مستأجر ITOM، أو تمكين ميزة CMDB، أو إصلاح خطأ CMDB 403 FUNCTIONALITY_NOT_ENABLED. تشغيل المشغلات: تمكين ميزة CMDB، توفير مستأجر ITOM، تشغيل CMDB، عدم تمكين CMDB، خطأ CMDB 403، تكامل الخدمة السحابية-itsm-cmdb. لا تقم بالتشغيل عندما: يريد المستخدم فقط تعيين مجموعات أذونات CMDB للمستخدمين، أو تثبيت حزمة محتوى CMDB فقط، أو العمل مع سجلات CMDB مباشرةً.
