Salesforce CLI (sf) を使用して、Agentforce for IT サービス Salesforce Go 機能の切り替え (Agentforce Studio、Einstein Generative AI、親アンブレラ、および履行者/従業員エージェント テンプレート) を有効にします。 Setup Discovery 機能/{apiName}/enable Connect API ルート経由で組織設定をオンにします。書き込み可能、​​冪等、依存関係の順序付け、書き込み確認が必要。 Agentforce Studio の有効化、Agentforce for IT サービスの有効化、Einstein 生成 AI の有効化、または組織レベルの Agentforce for IT サービスの前提条件の設定を求められた場合に使用します。トリガー: Agentforce Studio を有効にし、Agentforce for IT サービスを有効にし、Einstein Generative AI を有効にし、Agentforce 組織設定を構成します。トリガーしないでください: 読み取り専用の前提条件チェック (service-itsm-agentic-setup-agentforce-studio-validate)、エージェントの作成/アクティブ化 (service-itsm-agentic-setup-fulfiller-agent-configure)、または権限セットの割り当て。
