Включите переключатели функций Agentforce для ИТ-услуг Salesforce Go (Agentforce Studio, Einstein Generative AI, родительский зонт и шаблоны агентов Fulfiller/Employee) с помощью интерфейса командной строки Salesforce (sf). Включает настройки организации с помощью функции обнаружения настроек/{apiName}/включения маршрута Connect API. С возможностью записи, идемпотентный, упорядоченный по зависимостям, требуется подтверждение записи. Используйте, когда появится запрос на включение Agentforce Studio, включение Agentforce для ИТ-службы, включение генеративного искусственного интеллекта Эйнштейна или настройку предварительных требований Agentforce для ИТ-службы на уровне организации. Триггеры: включить Agentforce Studio, включить службу Agentforce for It, включить генеративный искусственный интеллект Эйнштейна, настроить настройки Agentforce org. НЕ ЗАПУСКАТЬ: проверку предварительных требований только для чтения (service-itsm-agentic-setup-agentforce-studio-validate), создание/активацию агента (service-itsm-agentic-setup-fulfiller-agent-configure) или назначение наборов разрешений.
