Activez les bascules de fonctionnalité Agentforce pour le service informatique Salesforce Go (Agentforce Studio, Einstein Generative AI, le parapluie parent et les modèles d'agent Fulfiller/Employee) à l'aide de Salesforce CLI (sf). Active les préférences d'organisation via la fonctionnalité Setup Discovery/{apiName}/enable Connect API route. Capable d'écriture, idempotent, ordonné par dépendances, confirmation d'écriture requise. À utiliser lorsqu'on vous demande d'activer Agentforce Studio, d'activer Agentforce pour le service informatique, d'activer l'IA générative d'Einstein ou de configurer les prérequis d'Agentforce pour le service informatique au niveau de l'organisation. Déclencheurs : activez Agentforce Studio, activez Agentforce pour son service, activez Einstein Generative AI, configurez les préférences d'organisation Agentforce. NE PAS DÉCLENCHER : vérification des prérequis en lecture seule (service-itsm-agentic-setup-agentforce-studio-validate), création/activation d'un agent (service-itsm-agentic-setup-fulfiller-agent-configure) ou attribution d'ensembles d'autorisations.
