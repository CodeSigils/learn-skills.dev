Habilite los conmutadores de funciones de Agentforce para servicios de TI Salesforce Go (Agentforce Studio, Einstein Generative AI, el paraguas principal y las plantillas de agente de cumplimiento/empleado) mediante la CLI de Salesforce (sf). Activa las preferencias de la organización a través de la función Configurar descubrimiento/{apiName}/habilitar la ruta API Connect. Con capacidad de escritura, idempotente, ordenado por dependencia, se requiere confirmación de escritura. Úselo cuando se le solicite habilitar Agentforce Studio, activar Agentforce para el servicio de TI, habilitar la IA generativa de Einstein o configurar los requisitos previos de Agentforce para el servicio de TI a nivel de organización. Activadores: habilite Agentforce Studio, active el servicio Agentforce para TI, habilite la IA generativa de Einstein, configure las preferencias de la organización de Agentforce. NO ACTIVAR: verificación de requisitos previos de solo lectura (service-itsm-agentic-setup-agentforce-studio-validate), crear/activar un agente (service-itsm-agentic-setup-fulfiller-agent-configure) o asignar conjuntos de permisos.
