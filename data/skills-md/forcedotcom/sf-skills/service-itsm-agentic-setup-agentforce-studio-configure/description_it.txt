Abilitare la funzione Salesforce Go di Agentforce per il servizio IT (Agentforce Studio, Einstein Generative AI, l'ombrello principale e i modelli di agente Gestore/Dipendente) utilizzando la CLI di Salesforce (sf). Attiva le preferenze dell'organizzazione tramite la funzione Setup Discovery/{apiName}/abilita il percorso API Connect. Con capacità di scrittura, idempotente, ordinato in base alle dipendenze, è richiesta la conferma di scrittura. Da utilizzare quando viene richiesto di abilitare Agentforce Studio, attivare Agentforce for IT Service, abilitare Einstein generativa AI o configurare i prerequisiti Agentforce for IT Service a livello di organizzazione. Trigger: abilita agentforce studio, attiva agentforce per il servizio it, abilita l'intelligenza artificiale generativa einstein, configura le preferenze dell'organizzazione agentforce. NON ATTIVARE: controllo dei prerequisiti di sola lettura (service-itsm-agentic-setup-agentforce-studio-validate), creazione/attivazione di un agente (service-itsm-agentic-setup-fulfiller-agent-configure) o assegnazione di set di autorizzazioni.
