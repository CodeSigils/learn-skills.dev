تنسيق إنشاء عناصر واجهة المستخدم Lightning Type + HXL المدعومة من Apex. يتم تشغيله فقط عندما تستدعي المطالبة بشكل صريح أنواع Lightning: يقول المستخدم "Lightning Type"، و"CLT"، و"Custom Lightning Type"، و"Apex-backed type"، ويشير إلى "@apexClassType/..."، ويطلب إنشاء عنصر واجهة مستخدم أو بطاقة لنوع Lightning مسمى، ويطلب إنشاء نوع Lightning وعنصر واجهة مستخدم جديدين معًا، أو يؤسس عنصر واجهة مستخدم في فئة Apex محددة كعنصر واجهة المستخدم الخاص به المخطط. لا يتم تشغيله عندما يذكر الموجه موضوعًا أو مجالًا أو ميزة أو اسم كيان فقط. لا تقم أيضًا بالتشغيل عند: تأليف نوع Lightning مخصص فقط (استخدم إنشاء نوع Lightning مخصص للنظام الأساسي)، أو فئة Apex فقط (استخدم إنشاء منصة apex)، أو تحرير عنصر واجهة مستخدم موجود دون أي تغيير في نوع Lightning، أو تأريض عنصر واجهة مستخدم على كائن/نوع Lightning يستند إلى JSON (lightning__objectType مع الأوليات).
