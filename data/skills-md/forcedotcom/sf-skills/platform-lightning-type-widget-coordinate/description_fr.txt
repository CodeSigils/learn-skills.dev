Orchestrez la génération de widgets Lightning Type + HXL basée sur Apex. DÉCLENCHEMENT uniquement lorsque l'invite appelle EXPLICITEMENT les types de foudre : l'utilisateur dit "Type de foudre", "CLT", "Type de foudre personnalisé", "Type soutenu par Apex", fait référence à "@apexClassType/...", demande de créer un widget ou une carte pour un type de foudre nommé, demande de créer un nouveau type de foudre et un nouveau widget ensemble, ou fonde un widget dans une classe Apex spécifique comme schéma. NE PAS DÉCLENCHER lorsque l'invite nomme uniquement un nom de sujet, de domaine, de fonctionnalité ou d'entité. NE PAS DÉCLENCHER également lorsque : vous créez uniquement un type de foudre personnalisé (utilisez platform-custom-lightning-type-generate), uniquement une classe Apex (utilisez platform-apex-generate), vous modifiez un widget existant sans aucune modification du type de foudre ou vous mettez à la terre un widget sur un type de foudre basé sur un objet/JSON (lightning__objectType avec des primitives).
