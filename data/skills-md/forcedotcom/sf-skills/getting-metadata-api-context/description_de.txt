Salesforce-Metadaten-API-Referenz zum Erstellen, Verstehen oder Ändern von Metadaten-XML-Dateien (.object-meta.xml, .flow-meta.xml usw.) und jedem von 604 Metadatentypen (CustomObject, Flow, ApexClass, ApexTrigger, Profile, PermissionSet, Layout, ValidationRule, RecordType, EmailTemplate, ...). Wird für Fragen zu den Feldern eines Typs oder zum XML-Format oder zur Salesforce DX-Projektstruktur (force-app/main/default) verwendet. TRIGGER, wenn: eine *-meta.xml-Datei erstellt oder bearbeitet wird, gefragt wird, welche Felder/Formate ein Metadatentyp hat, oder wann immer „Salesforce-Metadaten“ oder „sfdx-Projekt“ erwähnt wird. NICHT AUSLÖSEN, wenn: SOQL/DML/Laufzeit-sObject-Zugriff (Verwenden Sie die Enterprise-API-Skill), Tooling-API-Entwicklerdatensätze (ApexExecutionOverlayAction, TraceFlag) oder Nicht-XML-Logik (Apex-Code, LWC JS, Visualforce-Controller).
