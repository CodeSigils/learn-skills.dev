Salesforce 元数据 API 参考，用于创建、理解或修改元数据 XML 文件（.object-meta.xml、.flow-meta.xml 等）和 604 种元数据类型中的任何一种（CustomObject、Flow、ApexClass、ApexTrigger、Profile、PermissionSet、Layout、ValidationRule、RecordType、EmailTemplate...）。用于解答有关类型字段或 XML 格式或 Salesforce DX 项目结构（force-app/main/default）的问题。在以下情况下触发：创作或编辑任何 *-meta.xml 文件、询问元数据类型具有哪些字段/格式，或者每当提及“Salesforce 元数据”或“sfdx 项目”时。不要在以下情况下触发：SOQL/DML/运行时 sObject 访问（使用 Enterprise API 技能）、工具 API 开发人员记录（ApexExecutionOverlayAction、TraceFlag）或非 XML 逻辑（Apex 代码、LWC JS、Visualforce 控制器）。
