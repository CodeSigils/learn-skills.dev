Verwenden Sie diese Fähigkeit, um ein vollständiges HXL-WidgetBundle (UEM-Körper + schema.json + -meta.xml) zu erstellen. TRIGGER, wenn: Der Benutzer fragt nach einem Widget, Mosaik, Fragment, einer Karte oder einer Rich-UI-Oberfläche für ein beliebiges Subjekt, eine Domäne, ein Feature oder ein Entitätsnomen. Die Eingabeaufforderung benennt nur eine Entität oder Datenform, ohne Lightning-Typen, CLTs oder Apex-gestützte Typen aufzurufen. NICHT AUSLÖSEN, wenn: die Eingabeaufforderung explizit „Lightning Type“, „CLT“, „Custom Lightning Type“, „Apex-backed type“ sagt oder auf „@apexClassType/...“ verweist (verwenden Sie „platform-lightning-type-widget-coordinate“); Erstellen eines benutzerdefinierten LWC-Renderers für einen benutzerdefinierten Lightning-Typ (verwenden Sie „platform-custom-lightning-type-generate“); oder nur eine LWC-Komponente bearbeiten.
