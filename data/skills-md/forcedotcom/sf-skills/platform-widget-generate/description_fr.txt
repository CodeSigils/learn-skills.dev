Utilisez cette compétence pour créer un WidgetBundle HXL complet (corps UEM + schema.json + -meta.xml). DÉCLENCHEMENT lorsque : l'utilisateur demande un widget, une mosaïque, un fragment, une carte ou une interface utilisateur riche pour tout sujet, domaine, fonctionnalité ou nom d'entité ; l'invite nomme uniquement une entité ou une forme de données sans appeler les types Lightning, les CLT ou les types basés sur Apex. NE PAS DÉCLENCHER lorsque : l'invite indique explicitement "Type de foudre", "CLT", "Type de foudre personnalisé", "Type soutenu par Apex" ou fait référence à "@apexClassType/..." (utilisez platform-lightning-type-widget-coordonnée) ; création d'un moteur de rendu LWC personnalisé pour un type de foudre personnalisé (utilisez platform-custom-lightning-type-generate) ; ou en modifiant uniquement un composant LWC.
