Analysiert DevOps Center-Testfehler und Code-Analysator-Verstöße im Klartext – Fehlerkategorie, fehlerhafte Datei/Klasse/Methode/Zeile, verletzte Regel, Korrekturrichtung und priorisierte Verbesserungsvorschläge (Testcode vs. Produktionscode) – und erstellt dann optional auf ausdrückliche Anfrage ein nachverfolgtes Fix-WorkItem. Analyse ist reines Denken; Bei der Erstellung von Arbeitselementen handelt es sich um einen bestätigungsgesteuerten Schreibvorgang. Verwenden Sie diese Fähigkeit, um Fehler oder Verbesserungsvorschläge zu erklären, Code-Analysator-Verstöße zu übersetzen oder einen Fix als Arbeitsaufgabe zu verfolgen. TRIGGER, wenn: ein Lauf fehlgeschlagen ist und der Benutzer die Ursache angeben möchte; ein Quality-Gate-Fehler muss erklärt werden; Verstöße müssen übersetzt werden; Der Benutzer teilt eine Fehlernutzlast mit und fragt, wie er damit umgehen soll. will Tests stärken; oder möchte ein Fix-Arbeitselement erstellen, eine Behebung protokollieren oder einen Fehler zuweisen. NICHT AUSLÖSEN, wenn: Der Benutzer möchte, dass Korrekturcode geschrieben wird (verwenden Sie „platform-apex-generate“) oder dass neue Testklassen erstellt werden (verwenden Sie „platform-apex-test-generate“).
