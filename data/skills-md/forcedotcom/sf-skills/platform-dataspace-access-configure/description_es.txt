Utilice esta habilidad para configurar el acceso a Salesforce Data Cloud DataSpace para conjuntos de permisos. Otorga acceso a nivel de espacio de datos a través de MDAPI PermissionSet XML con elementos dataspaceScopes y, opcionalmente, otorga acceso a nivel de objeto a objetos DMO, DLO o CIO específicos a través de la API Object Access Grants Connect. DISPARAR cuando: el usuario necesita crear o actualizar un conjunto de permisos que incluya acceso a DataSpace, otorgar acceso a un conjunto de permisos a un espacio de datos específico, configurar dataAccessLevel u objectAccessLevel para un alcance de espacio de datos, agregar concesiones de acceso a objetos RBAC para objetos de Data Cloud, o enumerar o eliminar concesiones de acceso a objetos para un conjunto de permisos y un par de DataSpace. NO ACTIVAR cuando: la tarea es un conjunto de permisos genérico sin ningún acceso al espacio de datos (use platform-permission-set-generate), la solicitud es sobre la ingestión o flujos de datos (use data360-prepare), o el trabajo implica la creación de espacios de datos en lugar de otorgar acceso a ellos.
