Utilizzare questa competenza per configurare l'accesso a Salesforce Data Cloud DataSpace per gli insiemi di autorizzazioni. Concede l'accesso a livello di spazio dati tramite MDAPI PermissionSet XML con elementi dataspaceScopes e facoltativamente concede l'accesso a livello di oggetto a specifici oggetti DMO, DLO o CIO tramite l'API Object Access Grants Connect. SI ATTIVA quando: l'utente deve creare o aggiornare un set di autorizzazioni che include l'accesso a DataSpace, concedere l'accesso a un set di autorizzazioni a uno spazio dati specifico, configurare dataAccessLevel o objectAccessLevel per un ambito di spazio dati, aggiungere concessioni di accesso agli oggetti RBAC per oggetti Data Cloud oppure elencare o rimuovere le concessioni di accesso agli oggetti per un set di autorizzazioni e una coppia DataSpace. NON ATTIVARE quando: l'attività è un set di autorizzazioni generico senza alcun accesso allo spazio dati (utilizzare platform-permission-set-generate), la richiesta riguarda l'inserimento o i flussi di dati (utilizzare data360-prepare) o il lavoro prevede la creazione di spazi dati stessi anziché la concessione dell'accesso ad essi.
