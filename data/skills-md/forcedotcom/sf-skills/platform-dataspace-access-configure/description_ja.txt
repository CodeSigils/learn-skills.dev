このスキルを使用して、権限セットの Salesforce Data Cloud DataSpace アクセスを設定します。 dataspaceScopes 要素を含む MDAPI PermissionSet XML を介してデータスペース レベルのアクセスを許可し、オプションで Object Access Grants Connect API を介して特定の DMO、DLO、または CIO オブジェクトへのオブジェクト レベルのアクセスを許可します。トリガーされる場合: ユーザーが、DataSpace アクセスを含む権限セットの作成または更新、特定のデータスペースへの権限セット アクセスの付与、データスペース スコープの dataAccessLevel または objectAccessLevel の構成、Data Cloud オブジェクトに対する RBAC オブジェクト アクセス許可の追加、または権限セットと DataSpace ペアのオブジェクト アクセス許可の一覧表示または削除を行う必要がある場合。次の場合はトリガーしないでください: タスクがデータスペースへのアクセスを持たない汎用権限セットである (platform-permission-set-generate を使用)、リクエストがデータの取り込みまたはストリームに関するもの (data360-prepare を使用)、または作業にデータスペースへのアクセスを許可するのではなくデータスペース自体の作成が含まれる場合。
