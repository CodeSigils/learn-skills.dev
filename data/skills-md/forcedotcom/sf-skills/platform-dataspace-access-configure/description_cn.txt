使用此技能可以配置权限集的 Salesforce Data Cloud DataSpace 访问权限。通过带有 dataspaceScopes 元素的 MDAPI PermissionSet XML 授予数据空间级访问权限，并可选择通过对象访问授予 Connect API 授予对特定 DMO、DLO 或 CIO 对象的对象级访问权限。在以下情况下触发：用户需要创建或更新包含数据空间访问权限的权限集、授予权限集对特定数据空间的访问权限、为数据空间范围配置 dataAccessLevel 或 objectAccessLevel、为数据云对象添加 RBAC 对象访问授权，或者列出或删除权限集和数据空间对的对象访问授权。不要在以下情况下触发：任务是没有任何数据空间访问权限的通用权限集（使用 platform-permission-set-generate），请求与数据摄取或流有关（使用 data360-prepare），或者工作涉及创建数据空间本身而不是授予对它们的访问权限。
