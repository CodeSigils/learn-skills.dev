使用此技能可以配置權限集的 Salesforce Data Cloud DataSpace 存取權限。透過具有 dataspaceScopes 元素的 MDAPI PermissionSet XML 授予資料空間級存取權限，並可選擇透過物件存取授予 Connect API 授予對特定 DMO、DLO 或 CIO 物件的物件級存取權限。在下列情況下觸發：使用者需要建立或更新包含資料空間存取權限的權限集、授予權限集對特定資料空間的存取權限、設定資料空間範圍 dataAccessLevel 或 objectAccessLevel、為資料雲物件新增 RBAC 物件存取授權，或列出或刪除權限集和資料空間對的物件存取授權。不要在以下情況下觸發：任務是沒有任何資料空間存取權限的通用權限集（使用 platform-permission-set-generate），請求與資料攝取或流有關（使用 data360-prepare），或工作涉及建立資料空間本身而不是授予對它們的存取權限。
