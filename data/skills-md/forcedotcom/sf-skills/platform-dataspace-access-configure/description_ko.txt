이 기술을 사용하여 권한 집합에 대한 Salesforce Data Cloud DataSpace 액세스를 구성합니다. dataspaceScopes 요소가 포함된 MDAPI PermissionSet XML을 통해 데이터 공간 수준 액세스 권한을 부여하고 선택적으로 Object Access Grants Connect API를 통해 특정 DMO, DLO 또는 CIO 개체에 대한 개체 수준 액세스 권한을 부여합니다. TRIGGER 시기: 사용자가 DataSpace 액세스를 포함하는 권한 집합을 생성 또는 업데이트하고, 특정 데이터 공간에 대한 권한 집합 액세스를 부여하고, 데이터 공간 범위에 대해 dataAccessLevel 또는 objectAccessLevel을 구성하고, Data Cloud 개체에 대한 RBAC 개체 액세스 권한을 추가하거나, 권한 집합 및 DataSpace 쌍에 대한 개체 액세스 권한을 나열하거나 제거해야 합니다. 다음의 경우에는 트리거하지 마세요: 작업이 데이터 공간 액세스가 없는 일반 권한 집합인 경우(platform-permission-set-generate 사용), 요청이 데이터 수집 또는 스트림에 관한 경우(data360-prepare 사용), 작업에 액세스 권한을 부여하는 대신 데이터 공간 자체를 생성하는 작업이 포함됩니다.
