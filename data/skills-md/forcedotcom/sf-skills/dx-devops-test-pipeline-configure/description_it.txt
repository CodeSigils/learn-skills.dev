Configura l'infrastruttura di test della pipeline DevOps Center: consente a un provider di test di rendere disponibili le sue suite, risincronizza un provider configurato per inserire nuove suite o crea un controllo di qualità con regole su una fase. Instrada in base all'intento attraverso tre modalità dopo aver eseguito controlli dei prerequisiti condivisi e un gate di conferma esplicito. Utilizza questa competenza quando un utente desidera impostare, configurare, abilitare, sincronizzare o aggiornare un provider di test oppure impostare/configurare un cancello di qualità o una soglia di copertura in una fase della pipeline DevOps Center. ATTIVA quando: l'utente desidera configurare/abilitare/aggiungere/impostare un fornitore di test, risincronizzare o aggiornare l'elenco delle suite di un fornitore, inserire nuove suite o impostare/configurare un cancello di qualità, una soglia di copertura o un benchmark di test su una fase. NON SI ATTIVA quando: si assegnano suite esistenti a una fase (utilizzare dx-devops-test-suite-assignments-configure), si esegue o si riattiva una suite (utilizzare dx-devops-test-suite-run) o si lavora non DevOps-Center.
