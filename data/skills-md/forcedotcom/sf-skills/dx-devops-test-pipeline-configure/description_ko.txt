DevOps Center 파이프라인 테스트 인프라 구성: 테스트 공급자를 활성화하여 해당 제품군을 사용할 수 있도록 하고, 구성된 공급자를 다시 동기화하여 새 제품군을 가져오거나 단계에서 규칙을 사용하여 품질 게이트를 생성합니다. 공유 필수 구성 요소 검사와 명시적인 확인 게이트를 실행한 후 세 가지 모드에 걸쳐 의도적으로 라우팅합니다. 사용자가 테스트 공급자를 설정, 구성, 활성화, 동기화 또는 새로 고치거나 DevOps Center 파이프라인 단계에서 품질 게이트 또는 적용 범위 임계값을 설정/구성하려는 경우 이 기술을 사용합니다.
