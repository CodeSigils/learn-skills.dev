使用此技能來診斷與解決阻礙 DevOps Center 推廣工作項目功能分支的問題：Git 合併衝突與部署失敗。DevOps Center 基於 Git，因此重疊的 metadata 變更會在目標階段分支上顯示為合併衝突，需使用 git 解決（偵測、解決標記、提交、推送）。部署失敗常常因缺少依賴而發生，完整的推廣可在元件已存在於分支時修復此問題。觸發條件：使用者想在推廣前檢查工作項目的衝突、解決合併衝突或 metadata 檔案（.xml、.object‑meta.xml、.cls）中遺留的衝突標記、使功能分支與目標階段分支對齊，或診斷為何 DevOps Center 的推廣或部署失敗，以及完整推廣或缺少依賴的修正是否能解決。不要在以下情況觸發：執行推廣本身（使用 dx-devops-promote）、建立或更新工作項目（使用 dx-devops-work-item-manage），或直接將 metadata 部署到組織。

請始終以使用者的語言回覆。
