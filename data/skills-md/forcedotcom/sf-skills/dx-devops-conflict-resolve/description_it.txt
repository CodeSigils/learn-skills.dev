Utilizza questa competenza per diagnosticare e risolvere ciò che blocca una promozione DevOps Center del ramo di funzionalità di un elemento di lavoro: conflitti di unione Git ed errori di distribuzione. DevOps Center è supportato da Git, quindi le modifiche dei metadati sovrapposte emergono come conflitti di unione rispetto al ramo della fase di destinazione, risolti con git (rileva, risolvi marcatori, commit, push). Gli errori di distribuzione spesso citano una dipendenza mancante che una promozione completa può correggere quando il componente esiste già nel ramo. SI ATTIVA quando l'utente desidera verificare la presenza di conflitti in un elemento di lavoro prima della promozione, risolvere conflitti di unione o indicatori di conflitto rimanenti nei file di metadati (.xml, .object-meta.xml, .cls), riconciliare un ramo di funzionalità con il ramo della fase di destinazione o diagnosticare il motivo per cui una promozione o distribuzione di DevOps Center non è riuscita e se una promozione completa o una correzione delle dipendenze mancanti risolverà il problema. NON ATTIVARE per eseguire la promozione stessa (utilizzare dx-devops-promote), creare o aggiornare elementi di lavoro (utilizzare dx-devops-work-item-manage) o distribuire metadati direttamente a un'organizzazione.
