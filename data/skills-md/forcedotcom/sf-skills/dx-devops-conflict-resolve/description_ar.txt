استخدم هذه المهارة لتشخيص وحل ما يعرقل ترقية مركز DevOps لفرع الميزة الخاص بعنصر العمل: تعارضات دمج Git وفشل النشر. مركز DevOps يعتمد على Git، لذا فإن تغييرات البيانات الوصفية المتداخلة تظهر كتعارضات دمج ضد فرع المرحلة المستهدف، ويتم حلها باستخدام Git (اكتشاف، حل العلامات، الالتزام، الدفع). غالبًا ما تُشير فشل النشر إلى وجود اعتماد مفقود يمكن لترقية كاملة إصلاحه عندما يكون المكوّن موجودًا بالفعل على الفرع. **TRIGGER** عندما يرغب المستخدم في فحص عنصر عمل لتعارضات قبل الترقية، حل تعارضات الدمج أو علامات التعارض المتبقية في ملفات البيانات الوصفية (.xml, .object‑meta.xml, .cls)، تسوية فرع الميزة مع فرع المرحلة المستهدف، أو تشخيص سبب فشل ترقية أو نشر مركز DevOps وما إذا كانت ترقية كاملة أو إصلاح الاعتماد المفقود سيحل المشكلة. **DO NOT TRIGGER** لتشغيل الترقية نفسها (استخدم dx-devops-promote)، لإنشاء أو تحديث عناصر العمل (استخدم dx-devops-work-item-manage)، أو لنشر البيانات الوصفية مباشرةً إلى منظمة.

يرجى دائمًا الرد بلغة المستخدم.
