Utilisez cette compétence pour diagnostiquer et résoudre ce qui bloque une promotion DevOps Center d’une branche fonctionnelle d’un élément de travail : les conflits de fusion Git et les échecs de déploiement. DevOps Center repose sur Git, de sorte que les changements de métadonnées qui se chevauchent apparaissent comme des conflits de fusion contre la branche de stage cible, résolus avec Git (détecter, résoudre les marqueurs, valider, pousser). Les échecs de déploiement indiquent souvent une dépendance manquante qu’une promotion complète peut corriger lorsqu le composant existe déjà sur la branche. DÉCLENCHER lorsque l’utilisateur veut vérifier un élément de travail pour des conflits avant de promouvoir, résoudre les conflits de fusion ou les marqueurs de conflit restants dans les fichiers de métadonnées (.xml, .object‑meta.xml, .cls), réconcilier une branche fonctionnelle avec sa branche de stage cible, ou diagnostiquer pourquoi une promotion ou un déploiement DevOps Center a échoué et si une promotion complète ou une correction de dépendance manquante le résoudra. NE PAS DÉCLENCHER pour l’exécution de la promotion elle‑même (utilisez dx-devops-promote), la création ou la mise à jour d’éléments de travail (utilisez dx-devops-work-item-manage), ou le déploiement direct de métadonnées vers une organisation.
