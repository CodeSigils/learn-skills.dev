이 기능을 사용하여 작업 항목의 기능 브랜치에 대한 DevOps Center 승격을 차단하는 원인인 Git 병합 충돌 및 배포 실패를 진단하고 해결합니다. DevOps Center는 Git 기반이므로 겹치는 메타데이터 변경이 대상 스테이지 브랜치와의 병합 충돌로 나타나며, Git으로 해결합니다(감지, 충돌 표시 해결, 커밋, 푸시). 배포 실패는 종종 누락된 종속성을 언급하는데, 해당 컴포넌트가 이미 브랜치에 존재하는 경우 전체 승격으로 해결할 수 있습니다.  

사용자가 승격 전에 작업 항목의 충돌을 확인하거나, 메타데이터 파일(.xml, .object-meta.xml, .cls)에서 남은 충돌 표시를 해결하거나, 기능 브랜치를 대상 스테이지 브랜치와 정합시키거나, DevOps Center 승격 또는 배포가 실패한 이유를 진단하고 전체 승격이나 누락된 종속성 해결이 문제를 해결할지 여부를 판단하려는 경우 TRIGGER하십시오.  

승격 자체를 실행하는 경우(dx-devops-promote 사용), 작업 항목을 생성하거나 업데이트하는 경우(dx-devops-work-item-manage 사용), 또는 메타데이터를 직접 조직에 배포하는 경우에는 TRIGGER하지 마세요.
