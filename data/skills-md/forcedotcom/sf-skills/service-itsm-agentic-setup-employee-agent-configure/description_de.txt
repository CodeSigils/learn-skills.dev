Erstellen und aktivieren Sie einen IT-Service-Mitarbeiteragenten als nativen Next-Gen-Authoring-Agenten (NGA) aus dem Agentenskript einer ITSM-Mitarbeiteragentenvorlage über die Salesforce-CLI (sf): Lesen Sie die Vorlage, prüfen Sie die Idempotenz, erstellen Sie das NGA-Bundle, veröffentlichen und aktivieren Sie es und überprüfen Sie es live. Standardmäßig wird die umfassende Vorlage für IT-Servicemitarbeiter verwendet. Wenn der Benutzer eine spezielle Mitarbeitervorlage benennt (Password Manager Assistance, Certificate Management, Onboarding, Hardware Request und ~47 andere, die in references/specialized-templates.md katalogisiert sind – alle unter dem Namensraum „svc_emp_intelligence__“), wird stattdessen diese Vorlage angeheftet. Idempotent pro Entwicklername. TRIGGER, wenn der Benutzer den Mitarbeiteragenten, den IT-Service-Mitarbeiteragenten oder einen speziellen Mitarbeiteragenten (Passwortmanager, Zertifikat, Onboarding, Hardwareanforderung usw.) erstellen/einrichten/bereitstellen/aktivieren möchte. NICHT AUSLÖSEN: Voraussetzungsprüfungen (service-itsm-agentic-setup-agentforce-studio-validate), CMDB CRUD, Fulfiller-Setup (service-itsm-agentic-setup-fulfiller-agent-configure).
