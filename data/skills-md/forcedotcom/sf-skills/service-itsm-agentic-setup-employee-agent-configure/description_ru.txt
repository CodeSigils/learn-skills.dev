Создайте и активируйте агента сотрудника ИТ-службы в качестве собственного агента Next-Gen Authoring (NGA) из сценария агента шаблона агента сотрудника ITSM через интерфейс командной строки Salesforce (sf): прочитайте шаблон, проверьте идемпотентность, создайте пакет NGA, затем опубликуйте и активируйте, проверьте в реальном времени. По умолчанию используется широкий шаблон «Сотрудник ИТ-службы»; когда пользователь называет специализированный шаблон сотрудника (помощь в диспетчере паролей, управление сертификатами, адаптация, запрос оборудования и около 47 других шаблонов, каталогизированных в references/specialized-templates.md — все в пространстве имен `svc_emp_intelligence__`), вместо этого закрепляется именно этот шаблон. Идемпотент для каждого имени разработчика. ТРИГГЕР, когда пользователь запрашивает создание/настройку/предоставление/активацию агента сотрудника, агента сотрудника ИТ-службы или специализированного агента сотрудника (менеджер паролей, сертификат, подключение, запрос оборудования и т. д.). НЕ ЗАПУСКАТЬ: проверки предварительных условий (service-itsm-agentic-setup-agentforce-studio-validate), CMDB CRUD, настройка Fulfiller (service-itsm-agentic-setup-fulfiller-agent-configure).
