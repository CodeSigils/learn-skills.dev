El punto de entrada para crear cualquier aplicación móvil nativa de Salesforce en iOS o Android. DISPARAR cuando el usuario dice: "crear una aplicación iOS de Salesforce", "agregar el inicio de sesión de Salesforce a mi aplicación de Android", "configurar el SDK móvil", "agregar almacenamiento fuera de línea de MobileSync/SmartStore", "integrar un agente de Agentforce en mi aplicación móvil", "agregar el chat de Agentforce a iOS/Android" o solicita crear, ampliar o integrar una experiencia móvil de Salesforce en Swift o Kotlin (MSDK, SDK de Agentforce o ambos). OMITIR cuando el usuario esté creando una aplicación móvil que no sea de Salesforce, usando React Native/Flutter/Ionic sin integración de Salesforce, preguntando sobre el diseño genérico de la interfaz de usuario móvil o trabajando en una superficie web/escritorio adyacente a Salesforce (solo marca LWC, Experience Cloud, Mobile Publisher).
