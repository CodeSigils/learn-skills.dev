このスキルは、ユーザがナビゲーション、ブランディング、アクションの上書きを備えたタブベースの Salesforce カスタム アプリケーションを作成または設定する必要がある場合に使用します。ユーザーがカスタム アプリ、アプリケーション メタデータ、アプリ ナビゲーション、またはタブをアプリケーションに整理することに言及したときにトリガーされます。ユーザーがタブとページのアプリコンテナを作成する場合に使用します。目標が App Launcher で React UI バンドルをホストする場合には使用しないでください。その場合には、 experience-ui-bundle-custom-app-generate を使用してください。
