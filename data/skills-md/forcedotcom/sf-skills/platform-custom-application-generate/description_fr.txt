Utilisez cette compétence lorsque les utilisateurs doivent créer ou configurer des applications personnalisées Salesforce basées sur des onglets avec des remplacements de navigation, de personnalisation et d'action. Déclenchez lorsque les utilisateurs mentionnent des applications personnalisées, des métadonnées d'application, la navigation dans les applications ou l'organisation des onglets dans les applications. À utiliser lorsque les utilisateurs souhaitent créer des conteneurs d'applications pour les onglets et les pages. Ne pas utiliser lorsque l'objectif héberge un bundle React UI dans le lanceur d'applications - utilisez experience-ui-bundle-custom-app-generate dans ce cas.
