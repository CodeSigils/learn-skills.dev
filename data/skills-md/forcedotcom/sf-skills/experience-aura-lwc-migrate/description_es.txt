Utilice esta habilidad para analizar un paquete de componentes de Salesforce Aura (.cmp, .app, .evt, .intf, Controller.js, Helper.js, Renderer.js) y producir un plan de migración independiente del marco (PRD.yaml/PRD.md/PRD.json) que capture API pública, requisitos de datos, espacios, eventos, estados, accesibilidad, estilo, localización y postura de seguridad. Esta es solo la Fase 1 (análisis + PRD): NO crea ni edita código de componentes, adaptadores de cables ni pruebas Jest, y no escribe .html/.js/.css/.js-meta.xml. DISPARA cuando el usuario dice "analizar este componente de Aura", "migrar Aura", "convertir .cmp", "producir un plano de migración", "generar un PRD para este componente de Aura" o menciona aura:attribute, aura:handler, force:recordData, $Label, $Resource, componente.get, cmp.find o un directorio de entrada que contenga archivos .cmp. NO DISPARAR cuando no hay una fuente de Aura (delegar la creación de LWC posterior a experiencia-lwc-generar), para puntuación posterior a la migración o para refactorizar un componente moderno existente.
