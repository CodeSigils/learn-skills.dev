Utilizza questa competenza per analizzare un pacchetto di componenti Salesforce Aura (.cmp, .app, .evt, .intf, Controller.js, Helper.js, Renderer.js) e produrre un modello di migrazione indipendente dal framework (PRD.yaml / PRD.md / PRD.json) che acquisisce API pubbliche, requisiti di dati, slot, eventi, stati, accessibilità, stile, localizzazione e comportamento di sicurezza. Questa è solo la Fase 1 (analisi + PRD): NON crea o modifica codice componente, adattatori cablati o test Jest e non scrive .html/.js/.css/.js-meta.xml. SI ATTIVA quando l'utente dice "analizza questo componente Aura", "migra Aura", "converti .cmp", "produci un progetto di migrazione", "genera un PRD per questo componente Aura" o menziona aura:attribute, aura:handler, force:recordData, $Label, $Resource, componente.get, cmp.find o una directory di input contenente file .cmp. NON SI ATTIVA quando non è presente alcuna fonte Aura (delega la creazione LWC downstream a experience-lwc-generate), per il punteggio post-migrazione o per il refactoring di un componente moderno esistente.
