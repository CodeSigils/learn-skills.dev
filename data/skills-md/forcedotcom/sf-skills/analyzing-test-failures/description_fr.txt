Analyse un échec de test du DevOps Center ou une charge utile de violation de l'analyseur de code et l'explique en langage clair : catégorie d'échec, fichier/classe/méthode/ligne incriminés, règle violée et direction de correction - puis donne des suggestions d'amélioration de test prioritaires (en distinguant le code de test des correctifs de code de production). Raisonnement pur : pas d’appel système ni de création de code. DÉCLENCHEMENT lorsque : un test a échoué et l'utilisateur souhaite la cause première ; une défaillance du portail de qualité doit être expliquée ; Les violations de Code Analyzer doivent être traduites en langage clair ; l'utilisateur partage une charge utile d'échec et demande comment y remédier ; les tests échouent et l'utilisateur souhaite des suggestions ; ou l'utilisateur souhaite combler les lacunes de couverture, renforcer les assertions ou corriger des tests instables/faibles. NE PAS DÉCLENCHER lorsque : l'utilisateur souhaite écrire du code correctif (utiliser generate-apex) ou créer de nouvelles classes de test (utiliser generate-apex-test).
