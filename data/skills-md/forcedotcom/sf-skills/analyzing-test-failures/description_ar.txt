يوزع حمولة فشل اختبار DevOps Center أو حمولة انتهاك Code Analyzer ويشرحها بلغة واضحة - فئة الفشل، والملف/الفئة/الطريقة/الخط المخالف، وانتهاك القاعدة، واتجاه الإصلاح - ثم يقدم اقتراحات تحسين الاختبار ذات الأولوية (تمييز رمز الاختبار عن إصلاحات رمز الإنتاج). المنطق الخالص: لا يوجد استدعاءات للنظام أو تأليف التعليمات البرمجية. يتم تشغيله عندما: فشل التشغيل الاختباري ويريد المستخدم السبب الجذري؛ فشل بوابة الجودة يحتاج إلى شرح؛ تحتاج انتهاكات محلل الكود إلى الترجمة إلى لغة واضحة؛ يشارك المستخدم حمولة الفشل ويسأل عن كيفية معالجتها؛ تستمر الاختبارات بالفشل ويريد المستخدم اقتراحات؛ أو يريد المستخدم سد فجوات التغطية أو تعزيز التأكيدات أو إصلاح الاختبارات غير المستقرة/الضعيفة. لا تقم بالتشغيل عندما: يريد المستخدم كتابة رمز الإصلاح (استخدم إنشاء قمة) أو تأليف فئات اختبار جديدة (استخدم اختبار إنشاء قمة).
