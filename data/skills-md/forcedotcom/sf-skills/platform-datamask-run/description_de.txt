End-to-End-Datenmaskierungsvorgang in einer Sandbox: Konfigurieren Sie eine Maskierungsrichtlinie über personenbezogene Daten, führen Sie den Maskierungsjob aus, fragen Sie ihn bis zum Abschluss ab, melden Sie die Ergebnisse maskierter Datensätze und brechen Sie einen laufenden Lauf ab. Verwenden Sie diese Option, wenn der Benutzer einen Salesforce-Datenmaskenauftrag ausführen, überwachen oder abbrechen, PII-/Sandbox-Daten maskieren oder mit DataMaskPolicy/DataMaskPolicyJobRun arbeiten muss. TRIGGER, wenn: Der Benutzer einen Datenmaskierungsauftrag ausführt, Sandbox-PII maskiert, den Maskierungsstatus abfragt, maskierte Datensätze meldet oder eine laufende Maske abbricht. NICHT AUSLÖSEN, wenn: Anonymisierungs-Apex manuell schreiben (platform-apex-generate verwenden), Testdaten generieren (platform-data-manage verwenden) oder nicht verwandte Metadaten bereitstellen (platform-metadata-deploy verwenden).
