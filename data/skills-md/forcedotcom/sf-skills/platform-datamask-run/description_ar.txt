عملية شاملة لقناع البيانات في وضع الحماية: قم بتكوين سياسة الإخفاء عبر معلومات تحديد الهوية الشخصية (PII)، وتشغيل مهمة الإخفاء، واستقصائها حتى الاكتمال، والإبلاغ عن نتائج السجل المقنع، وإحباط التشغيل قيد التقدم. يُستخدم عندما يحتاج المستخدم إلى تشغيل وظيفة Salesforce Data Mask أو مراقبتها أو إلغائها، أو إخفاء بيانات PII/sandbox، أو العمل مع DataMaskPolicy / DataMaskPolicyJobRun. يتم تشغيله عندما: يقوم المستخدم بتشغيل مهمة قناع البيانات، أو أقنعة تحديد الهوية الشخصية (PII)، أو استقصاء حالة الإخفاء، أو الإبلاغ عن السجلات المقنعة، أو إحباط قناع قيد التشغيل. لا تقم بالتشغيل عند: كتابة إخفاء الهوية Apex يدويًا (استخدام إنشاء قمة النظام الأساسي)، أو إنشاء بيانات اختبار (استخدام إدارة بيانات النظام الأساسي)، أو نشر بيانات تعريف غير ذات صلة (استخدام نشر بيانات تعريف النظام الأساسي).
