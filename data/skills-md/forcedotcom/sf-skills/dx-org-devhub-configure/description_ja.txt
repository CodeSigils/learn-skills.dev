Salesforce 組織で Dev Hub を有効にし、Salesforce CLI (sf) を使用してスクラッチ組織の割り当てを表示します。 Dev Hub をオンまたは有効にする場合、スクラッチ組織または第 2 世代 (2GP) およびロック解除されたパッケージを作成するための組織の設定を行う場合、Dev Hub がすでに有効になっているかどうかを確認する場合、作成できるスクラッチ組織の数 (アクティブおよび日次スクラッチ組織の制限、残りの割り当て) を確認する場合、パッケージ化、組織形状のエクスポート、スクラッチ組織のスナップショットなどの Dev Hub の設定を行う場合、または Dev Hub から作成されたアクティブなスクラッチ組織の一覧を表示する場合に使用します。有効にすると、enableScratchOrgManagementPref 設定が展開され、元に戻すことはできず、システム管理者 (ModifyAllData または ModifyMetadata) が必要で、サンドボックスでは機能しません。個々のスクラッチ組織の作成または削除、デフォルト組織の切り替え (dx-org-switch を使用)、またはトライアルまたは組織の有効期限 (dx-org-trial-expiration-check を使用) に対してトリガーしないでください。
