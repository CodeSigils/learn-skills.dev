قم بتمكين Dev Hub في مؤسسة Salesforce واعرض تخصيص المؤسسة المؤقتة الخاصة بها، باستخدام Salesforce CLI (sf). استخدمه عندما يريد شخص ما تشغيل Dev Hub أو تمكينه، أو إعداد مؤسسة لإنشاء مؤسسات مؤقتة أو الجيل الثاني (2GP) والحزم غير المؤمنة، أو التحقق مما إذا كان Dev Hub ممكّنًا بالفعل، أو معرفة عدد مؤسسات التسويد التي يمكنه إنشاؤها (حدود مؤسسة التسويد النشطة واليومية، والتخصيص المتبقي)، أو تكوين تفضيلات Dev Hub مثل التعبئة، أو تصدير شكل المؤسسة، أو لقطات مؤسسة التسويد، أو سرد مؤسسات التسويد النشطة التي تم إنشاؤها من Dev Hub. يؤدي التمكين إلى نشر إعداد EnableScratchOrgManagementPref، وهو أمر لا رجعة فيه، ويحتاج إلى مسؤول النظام (ModifyAllData أو ModifyMetadata)، ولا يعمل في صناديق الحماية. لا تقم بالتشغيل لإنشاء أو حذف مؤسسات مؤقتة فردية، أو لتبديل المؤسسة الافتراضية (استخدم dx-org-switch)، أو لتواريخ انتهاء صلاحية النسخة التجريبية أو المؤسسة (استخدم dx-org-trial-expiration-check).
