Habilite Dev Hub en una organización de Salesforce y vea la asignación de su organización borrador mediante la CLI de Salesforce (sf). Úselo cuando alguien quiera activar o habilitar Dev Hub, configurar una organización para crear organizaciones borrador o paquetes de segunda generación (2GP) y desbloqueados, verificar si Dev Hub ya está habilitado, ver cuántas organizaciones borrador pueden crear (límites activos y diarios de organizaciones borrador, asignación restante), configurar preferencias de Dev Hub como empaquetado, exportación de forma de organización o instantáneas de organizaciones borrador, o enumerar las organizaciones borrador activas creadas desde un Dev Hub. La habilitación implementa la configuración enableScratchOrgManagementPref, es irreversible, necesita un administrador del sistema (ModifyAllData o ModifyMetadata) y no funciona en entornos sandbox. NO DISPARAR para crear o eliminar organizaciones borrador individuales, para cambiar la organización predeterminada (use dx-org-switch) o para fechas de vencimiento de prueba o de organización (use dx-org-trial-expiration-check).
