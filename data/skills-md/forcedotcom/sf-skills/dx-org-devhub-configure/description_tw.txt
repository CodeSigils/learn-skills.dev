使用 Salesforce CLI (sf) 在 Salesforce 組織上啟用 Dev Hub 並查看其臨時組織分配。當有人想要開啟或啟用 Dev Hub、設定組織來建立臨時組織或第二代 (2GP) 和解鎖套件、檢查 Dev Hub 是否已啟用、查看他們可以建立多少個臨時組織（活動和每日臨時組織限制、剩餘分配）、設定 Dev Hub 首選項（例如打包、組織形狀匯出或臨時組織快照）或列出從 Dev Hub 建立的活動臨時組織時使用。啟用會部署enableScratchOrgManagementPref 設置，不可逆轉，需要係統管理員（ModifyAllData 或ModifyMetadata），並且在沙箱中不起作用。請勿在建立或刪除單一臨時組織、切換預設組織（使用 dx-org-switch）或試用或組織到期日期（使用 dx-org-Trial-expiration-check）時觸發。
