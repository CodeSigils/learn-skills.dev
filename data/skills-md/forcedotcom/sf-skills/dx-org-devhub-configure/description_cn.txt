使用 Salesforce CLI (sf) 在 Salesforce 组织上启用 Dev Hub 并查看其临时组织分配。当有人想要打开或启用 Dev Hub、设置组织来创建临时组织或第二代 (2GP) 和解锁包、检查 Dev Hub 是否已启用、查看他们可以创建多少个临时组织（活动和每日临时组织限制、剩余分配）、配置 Dev Hub 首选项（例如打包、组织形状导出或临时组织快照）或列出从 Dev Hub 创建的活动临时组织时使用。启用会部署enableScratchOrgManagementPref 设置，不可逆转，需要系统管理员（ModifyAllData 或ModifyMetadata），并且在沙箱中不起作用。请勿在创建或删除单个临时组织、切换默认组织（使用 dx-org-switch）或试用或组织到期日期（使用 dx-org-Trial-expiration-check）时触发。
