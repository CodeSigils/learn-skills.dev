Aktivieren Sie Dev Hub in einer Salesforce-Organisation und zeigen Sie deren Scratch-Organisationszuordnung mithilfe der Salesforce-CLI (sf) an. Verwenden Sie diese Option, wenn jemand Dev Hub einschalten oder aktivieren, eine Organisation zum Erstellen von Testorganisationen oder freigeschalteten Paketen der zweiten Generation (2GP) einrichten möchte, überprüfen möchte, ob Dev Hub bereits aktiviert ist, sehen möchte, wie viele Testorganisationen erstellt werden können (Grenzwerte für aktive und tägliche Testorganisationen, verbleibende Zuteilung), Dev Hub-Einstellungen wie Paketierung, Export von Organisationsformen oder Snapshots von Testorganisationen konfigurieren oder die aktiven Testorganisationen auflisten möchte, die von einem Dev Hub erstellt wurden. Durch die Aktivierung wird die Einstellung „enableScratchOrgManagementPref“ bereitgestellt, ist irreversibel, erfordert einen Systemadministrator (ModifyAllData oder ModifyMetadata) und funktioniert nicht in Sandboxes. NICHT AUSLÖSEN zum Erstellen oder Löschen einzelner Testorganisationen, zum Wechseln der Standardorganisation (verwenden Sie dx-org-switch) oder für Ablaufdaten von Testversionen oder Organisationen (verwenden Sie dx-org-trial-expiration-check).
