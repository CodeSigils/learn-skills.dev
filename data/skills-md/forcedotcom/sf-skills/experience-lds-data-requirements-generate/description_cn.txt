当以不明确的自然语言描述 Lightning Web 组件数据需求时使用 - 将“获取联系信息”或“显示帐户数据”转换为清晰的、PRD 就绪的数据需求规范。当用户说“定义此 LWC 的数据要求”、“将此 PRD 数据部分转换为经过验证的对象/字段名称”、“针对此数据需求推荐 GraphQL 与 UIAPI”、“验证这些 Salesforce API 名称”或“为此组件指定 LDS 适配器”，或引用尚未指定数据层的 LWC 捆绑文件（`.js`、`.js-meta.xml`）时触发。当数据层已完全指定时、根据已知规范编写实际查询或适配器代码时或实现端到端 LWC 时（使用 experience-lwc-generate），请勿触发。
