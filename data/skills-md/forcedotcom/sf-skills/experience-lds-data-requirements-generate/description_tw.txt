當以不明確的自然語言描述 Lightning Web 元件資料需求時使用 - 將「取得聯絡資訊」或「顯示帳戶資料」轉換為清晰的、PRD 就緒的資料需求規格。當使用者說「定義此 LWC 的資料需求」、「將此 PRD 資料部分轉換為經過驗證的物件/欄位名稱」、「針對此資料需求推薦 GraphQL 與 UIAPI」、「驗證這些 Salesforce API 名稱」或「為此元件指定 LDS 適配器」，或引用尚未指定資料層的 LWC 捆綁檔案（`.js、`.當資料層已完全指定時、根據已知規範編寫實際查詢或適配器程式碼時或實作端對端 LWC 時（使用 experience-lwc-generate），請勿觸發。
