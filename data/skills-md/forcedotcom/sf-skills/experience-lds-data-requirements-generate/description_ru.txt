Используйте, когда потребность в данных веб-компонента Lightning описана двусмысленным естественным языком — превратите «получить контактную информацию» или «показать данные учетной записи» в четкую, готовую к PRD спецификацию требований к данным. TRIGGER, когда пользователь говорит «определить требования к данным для этого LWC», «превратить этот раздел данных PRD в проверенные имена объектов/полей», «рекомендовать GraphQL и UIAPI для этой потребности в данных», «проверить эти имена API Salesforce» или «определить адаптер LDS для этого компонента» или ссылается на файлы пакета LWC (`.js`, `.js-meta.xml`), уровень данных которых еще не указан. НЕ ЗАПУСКАЙТЕ, если уровень данных уже полностью указан, при разработке фактического запроса или кода адаптера из известной спецификации или при реализации сквозного LWC (используйте experience-lwc-generate).
