Lightning 웹 구성 요소 데이터 요구 사항이 모호한 자연어로 설명된 경우 사용합니다. "연락처 정보 가져오기" 또는 "계정 데이터 표시"를 명확한 PRD 지원 데이터 요구 사항 사양으로 전환하세요. 사용자가 "이 LWC에 대한 데이터 요구 사항 정의", "이 PRD 데이터 섹션을 검증된 개체/필드 이름으로 전환", "이 데이터 요구 사항에 대해 GraphQL 대 UIAPI 권장", "이 Salesforce API 이름 확인" 또는 "이 구성 요소에 대한 LDS 어댑터 지정"이라고 말하거나 데이터 계층이 아직 지정되지 않은 LWC 번들 파일(`.js`, `.js-meta.xml`)을 참조하는 경우 TRIGGER. 데이터 계층이 이미 완전히 지정되어 있는 경우, 알려진 사양에서 실제 쿼리 또는 어댑터 코드를 작성하는 경우 또는 LWC 엔드투엔드를 구현하는 경우(experience-lwc-generate 사용) 트리거하지 마세요.
