Salesforce의 통합 카탈로그 서비스 프로세스 수명 주기에 대한 단일 진입점 — 서비스 프로세스 템플릿을 찾아서 배포하고, 처음부터 서비스 프로세스를 만들고, 활성화하거나, 카탈로그 범주 아래에 구성합니다. 요청된 작업에 대한 플랫폼 자체의 안내 설정 레시피를 발견하고 실시간 단계를 따르므로 결과와 보호 조치가 항상 조직과 일치합니다. 비즈니스 사용자가 통합 카탈로그 또는 서비스 프로세스 템플릿으로 작업하고, 템플릿을 찾거나 찾아보고, 명명된 템플릿을 배포 또는 설치하고, 전체 설정을 설정하고, 서비스 프로세스를 활성화하거나, 카탈로그 또는 카테고리 아래에 서비스 프로세스를 추가, 보관 또는 배치하려는 경우에 사용합니다. 트리거 대상: 통합 카탈로그 템플릿 설정, 서비스 프로세스 템플릿 찾기, X 템플릿 배포, 서비스 프로세스 활성화, 카탈로그에 서비스 프로세스 추가. 요청이 통합 카탈로그 서비스 프로세스가 아닌 데이터 클라우드 데이터 키트, CRM 분석 또는 앱 프레임워크 카탈로그와 관련된 경우에는 트리거하지 마세요.
