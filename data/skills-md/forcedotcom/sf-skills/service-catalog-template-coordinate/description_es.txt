Punto de entrada único para el ciclo de vida del proceso de servicio del catálogo unificado en Salesforce: busque e implemente plantillas de proceso de servicio, cree un proceso de servicio desde cero, active uno u organícelo en una categoría de catálogo. Descubre la receta de configuración guiada propia de la plataforma para la operación solicitada y sigue sus pasos en vivo, de modo que los resultados y las salvaguardas siempre coincidan con la organización. Úselo cuando un usuario empresarial desee trabajar con plantillas de catálogo unificado o proceso de servicio, buscar o explorar plantillas, implementar o instalar una plantilla con nombre, configurar una de un extremo a otro, activar un proceso de servicio o agregar, archivar o colocar un proceso de servicio en un catálogo o categoría. Activadores: configurar plantillas de catálogo unificado, buscar una plantilla de proceso de servicio, implementar la plantilla X, activar un proceso de servicio, agregar un proceso de servicio a un catálogo. NO ACTIVAR cuando la solicitud se refiere a kits de datos de Data Cloud, análisis de CRM o catálogos de App Framework en lugar de procesos de servicio de catálogo unificado.
