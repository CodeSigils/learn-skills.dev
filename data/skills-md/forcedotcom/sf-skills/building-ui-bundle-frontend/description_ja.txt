既存のアプリ (ページ、コンポーネント、セクション、レイアウト、スタイル、色、フォント、ナビゲーション、アニメーション、または外観の変更) に対するビジュアルまたは UI の変更を行うには、uiBundles/*/src/ の下にあるファイルを編集する前にアクティブ化する必要があります。このスキルは、既存の UI バンドル アプリのページ、コンポーネント、レイアウト、スタイル、またはナビゲーションを変更するときに使用します。プロジェクトに appLayout.tsx、routes.tsx、src/pages/、src/components/、または global.css が含まれている場合にアクティブ化します。このスキルには、一般知識を無効にする重要なプロジェクト固有の規則 (appLayout.tsx シェル、shadcn/ui コンポーネント、Tailwind CSS、Salesforce ベースパス ルーティング、モジュール制限) が含まれています。このスキルがないと、生成されたコードは間違ったインポートを使用したり、ルーティングを中断したり、プロジェクト構造を無視したりすることになります。新しいアプリを最初から作成する場合は使用しないでください (代わりにbuilding-ui-bundle-appを使用してください)。
