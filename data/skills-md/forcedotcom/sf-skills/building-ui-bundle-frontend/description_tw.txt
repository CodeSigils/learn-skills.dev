必须在编辑 uiBundles/*/src/ 下的任何文件之前激活，以对现有应用程序进行视觉或 UI 更改 - 页面、组件、部分、布局、样式、颜色、字体、导航、动画或任何外观和感觉更改。在修改現有 UI 捆綁應用程式中的頁面、元件、佈局、樣式或導航時，請使用此技能。當專案包含 appLayout.tsx、routes.tsx、src/pages/、src/components/ 或 global.css 時啟動。此技能包含超越一般知识的关键项目特定约定（appLayout.tsx shell、shadcn/ui 组件、Tailwind CSS、Salesforce 基本路径路由、模块限制）。如果沒有這項技能，產生的程式碼將使用錯誤的匯入、中斷路由或忽略專案結構。從頭開始建立新應用程式時請勿使用（請改用building-ui-bundle-app）。
