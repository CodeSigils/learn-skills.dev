MUSS aktiviert werden, bevor JEGLICHE Datei unter uiBundles/*/src/ bearbeitet wird, um visuelle oder UI-Änderungen an einer VORHANDENEN App vorzunehmen – Seiten, Komponenten, Abschnitte, Layout, Stil, Farben, Schriftarten, Navigation, Animationen oder Änderungen am Erscheinungsbild. Verwenden Sie diesen Skill, wenn Sie Seiten, Komponenten, Layout, Stil oder Navigation in einer vorhandenen UI-Bundle-App ändern. Aktivieren Sie diese Option, wenn das Projekt appLayout.tsx, Routes.tsx, src/pages/, src/components/ oder global.css enthält. Dieser Skill enthält wichtige projektspezifische Konventionen (appLayout.tsx-Shell, shadcn/ui-Komponenten, Tailwind CSS, Salesforce-Basispfad-Routing, Moduleinschränkungen), die allgemeines Wissen außer Kraft setzen. Ohne diese Fähigkeit wird generierter Code falsche Importe verwenden, das Routing unterbrechen oder die Projektstruktur ignorieren. NICHT verwenden, wenn Sie eine neue App von Grund auf erstellen (verwenden Sie stattdessen „building-ui-bundle-app“).
