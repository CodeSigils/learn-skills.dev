Оркестратор верхнего уровня для настройки управления ИТ-услугами (ITSM) в Salesforce Service Cloud. Используйте, когда пользователь просит настроить ITSM, настроить управление службами, включить возможности ITSM, хочет получить пошаговое руководство или спрашивает, что необходимо для запуска ITSM. Предоставляет меню с множественным выбором треков и делегирование суб-оркестраторам домена — Incident Management, Agentforce для ITSM (Studio + Fulfiller), CMDB и Microsoft Teams (IT Desk/IT Service/Swarming). Любые предварительные условия (например, главный переключатель управления инцидентами для канала 1) принадлежат и применяются внутри соответствующего суборкестратора, а не на этом уровне. Запускается при: настройке ITSM, настройке управления службами, настройке ITSM, запуске ITSM, пошаговом руководстве, настройке CMDB/Teams/Agentforce для ITSM. НЕ АКТИВИРУЕТСЯ, когда: пользователь напрямую спрашивает о конкретной функции (например, только о матрице приоритетов), спрашивает только об управлении обращениями, хочет создать одного пользователя или задает общие вопросы ITSM без намерения настройки.
