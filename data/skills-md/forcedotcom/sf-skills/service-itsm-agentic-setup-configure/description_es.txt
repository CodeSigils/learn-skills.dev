Orquestador de alto nivel para configurar la Gestión de Servicios de TI (ITSM) en Salesforce Service Cloud. Úselo cuando el usuario solicite configurar ITSM, configurar la administración de servicios, habilitar capacidades de ITSM, desee un recorrido guiado o pregunte qué se necesita para que ITSM funcione. Presenta un menú de seguimiento de selección múltiple y delega a los suborquestadores del dominio: gestión de incidentes, Agentforce para ITSM (Studio + Fulfiller), CMDB y Microsoft Teams (IT Desk/IT Service/Swarming). Cualquier requisito previo (como el interruptor maestro de gestión de incidentes para la pista 1) pertenece y se aplica dentro del suborquestador correspondiente, no en este nivel. Activadores: configurar ITSM, configurar la administración de servicios, configurar ITSM, ejecutar ITSM, tutorial, configurar CMDB/Teams/Agentforce para ITSM. NO DISPARAR cuando: el usuario pregunta directamente sobre una característica específica (por ejemplo, solo la matriz de prioridades), pregunta solo sobre la gestión de casos, quiere crear un usuario único o hace preguntas generales de ITSM sin intención de configuración.
