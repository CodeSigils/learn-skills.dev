Выберите правильный базовый компонент Lightning («lightning-*») для конкретной задачи пользовательского интерфейса, получите его полный API (свойства, методы, события, слоты) из связанной ссылки на каждый компонент и подключите его к LWC (файлы LWC «.html», «.js» и «.css»), не нарушая SLDS. Используйте этот навык, когда пользователи говорят: «Мне нужна модальная форма / таблица данных / поле со списком / форма записи Lightning», спрашивают, какой компонент `lightning-*` подходит для конкретного варианта использования, хотят получить короткий список кандидатов на LBC, собираются вручную создать пользовательский интерфейс, который уже предоставляет базовый компонент, или редактируют `.html`/`.js`/`.css` пакета LWC и им необходимо выбрать или подключить базовый компонент. Также срабатывает по «базовому компоненту Lightning», «LBC», «lightning-combobox», «lightning-datatable», «использовать тег `lightning-`». НЕ ИНИЦИРУЙТЕ для применения токенов дизайна SLDS, чертежей или руководства по стилю в целом — это `design-systems-slds-apply`; этот навык только выбирает и подключает базовые компоненты `lightning-*`.
