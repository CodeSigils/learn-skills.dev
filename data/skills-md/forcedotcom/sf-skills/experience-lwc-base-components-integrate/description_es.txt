Elija el componente base Lightning correcto (`lightning-*`) para una tarea de interfaz de usuario determinada, recupere su API completa (accesorios, métodos, eventos, ranuras) de la referencia por componente incluida y conéctelo a un LWC (archivos LWC `.html`, `.js` y `.css`) sin romper SLDS. Utilice esta habilidad cuando los usuarios digan "Necesito un formulario Lightning modal/datatable/combobox/registro", pregunten qué componente `lightning-*` se ajusta a un caso de uso, quieran una lista corta de candidatos LBC, estén a punto de desarrollar manualmente una interfaz de usuario que un componente base ya proporciona, o estén editando `.html`/`.js`/`.css` de un paquete LWC y necesiten seleccionar o cablear un componente base. También se activa en "componente base Lightning", "LBC", "lightning-combobox", "lightning-datatable", "usar etiqueta `lightning-`". NO DISPARAR para aplicar tokens de diseño, planos o guías de estilo de SLDS en general, es decir, "sistemas de diseño-aplicar-slds"; esta habilidad solo selecciona y cablea los componentes base `lightning-*`.
