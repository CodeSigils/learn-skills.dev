주어진 UI 작업에 적합한 Lightning 기본 구성 요소(`lightning-*`)를 선택하고, 번들된 구성 요소별 참조에서 전체 API(props, 메서드, 이벤트, 슬롯)를 검색하고 SLDS를 손상시키지 않고 LWC(LWC `.html`, `.js` 및 `.css` 파일)에 연결합니다. 사용자가 "Lightning 모달/데이터 테이블/콤보박스/레코드 양식이 필요합니다"라고 말하고, 어떤 `lightning-*` 구성 요소가 사용 사례에 적합한지 묻고, LBC 후보 최종 목록을 원하고, 기본 구성 요소가 이미 제공하는 UI를 직접 작성하려고 하거나, LWC 번들의 `.html` / `.js` / `.css`를 편집 중이고 기본 구성 요소를 선택하거나 연결해야 하는 경우 이 기술을 사용하세요. 또한 "Lightning 기본 구성 요소", "LBC", "lightning-combobox", "lightning-datatable", "`lightning-` 태그 사용"에서도 트리거됩니다. SLDS 디자인 토큰, 청사진 또는 일반적인 스타일 지침 적용을 위해 트리거하지 마십시오. 즉, 'design-systems-slds-apply'입니다. 이 스킬은 `lightning-*` 기본 구성 요소만 선택하고 연결합니다.
