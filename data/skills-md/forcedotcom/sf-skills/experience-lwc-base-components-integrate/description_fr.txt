Choisissez le bon composant de base Lightning (`lightning-*`) pour une tâche d'interface utilisateur donnée, récupérez son API complète (accessoires, méthodes, événements, emplacements) à partir de la référence groupée par composant et connectez-le à un LWC (fichiers LWC `.html`, `.js` et `.css`) sans casser SLDS. Utilisez cette compétence lorsque les utilisateurs disent « J'ai besoin d'un formulaire Lightning modal / datatable / combobox / record », demandent quel composant « Lightning-* » correspond à un cas d'utilisation, veulent une liste restreinte de candidats LBC, sont sur le point de créer manuellement une interface utilisateur qu'un composant de base fournit déjà, ou sont en train de modifier le fichier « .html » / « .js » / « .css » d'un bundle LWC et doivent sélectionner ou câbler un composant de base. Se déclenche également sur "Composant de base Lightning", "LBC", "lightning-combobox", "lightning-datatable", "utiliser la balise `lightning-`". NE PAS DÉCLENCHER pour appliquer des jetons de conception SLDS, des plans ou des conseils de style en général — c'est-à-dire « design-systems-slds-apply » ; cette compétence sélectionne et câble uniquement les composants de base « Lightning-* ».
