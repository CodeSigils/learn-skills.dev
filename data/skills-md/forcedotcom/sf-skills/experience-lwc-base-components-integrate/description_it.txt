Scegli il componente Lightning Base corretto (`lightning-*`) per una determinata attività dell'interfaccia utente, recupera la sua API completa (oggetti di scena, metodi, eventi, slot) dal riferimento per componente in bundle e collegalo a un LWC (file LWC `.html`, `.js` e `.css`) senza interrompere SLDS. Utilizza questa competenza quando gli utenti dicono "Ho bisogno di un modulo Lightning modale/datatable/combobox/record", chiedono quale componente "lightning-*" si adatta a un caso d'uso, desiderano un elenco ristretto di candidati LBC, stanno per eseguire manualmente un'interfaccia utente fornita già da un componente di base o stanno modificando ".html" / ".js" / ".css" di un bundle LWC e devono selezionare o collegare un componente di base. Si attiva anche su "Componente base Lightning", "LBC", "lightning-combobox", "lightning-datatable", "usa il tag `lightning-`". NON ATTIVARE per l'applicazione di token di progettazione SLDS, progetti o linee guida di stile in generale, ovvero "design-systems-slds-apply"; questa abilità seleziona e collega solo i componenti di base `lightning-*`.
