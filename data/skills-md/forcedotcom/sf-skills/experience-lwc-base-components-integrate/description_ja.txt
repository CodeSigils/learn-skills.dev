特定の UI タスクに適切な Lightning Base コンポーネント (「lightning-*」) を選択し、バンドルされているコンポーネントごとのリファレンスからその完全な API (プロパティ、メソッド、イベント、スロット) を取得し、SLDS を壊さずにそれを LWC (LWC `.html`、`.js`、および `.css` ファイル) に接続します。このスキルは、ユーザが「Lightning モーダル / データテーブル / コンボボックス / レコードフォームが必要」と言っている場合、ユースケースに適合する `lightning-*` コンポーネントを尋ねる場合、LBC 候補の候補リストが必要な場合、基本コンポーネントがすでに提供している UI を手動でロールしようとしている場合、または LWC バンドルの `.html` / `.js` / `.css` を編集していて基本コンポーネントを選択または接続する必要がある場合に使用します。 「Lightning ベースコンポーネント」、「LBC」、「lightning-combobox」、「lightning-datatable」、「`lightning-` タグの使用」でもトリガーされます。一般に、SLDS デザイン トークン、ブループリント、またはスタイル ガイダンスを適用するためにトリガーしないでください。つまり、「design-systems-slds-apply」です。このスキルは、「lightning-*」ベース コンポーネントを選択して配線するだけです。
