CMDB 기능이 활성화된 후 프로덕션 또는 샌드박스 조직에 대해 Service Cloud ITSM에서 CMDB Foundation 기본 콘텐츠 번들을 배포(설치)합니다. 사용자가 CMDB 번들 설치, CMDB Foundation 배포, CMDB 기본 콘텐츠 설정, CMDB 기본 콘텐츠 설치 또는 기본 번들로 CMDB 설정 완료를 요청할 때 사용합니다. 트리거 조건: CMDB 번들 설치, CMDB Foundation 배포, CMDB 기본 콘텐츠, CMDB 콘텐츠 번들, 번들 설치, CMDB 설정 완료. 다음의 경우에는 트리거하지 마십시오: 사용자가 조직에 대해 CMDB 기능을 활성화하려는 경우(CMDB 기능 활성화 기술), 사용자에게 CMDB 권한 집합을 할당하려는 경우(CMDB 액세스 할당 기술), 기본이 아닌 선택적 추가 기능 번들을 설치하거나, ​​일반(CMDB가 아닌) 메타데이터 또는 패키지를 배포하거나, CMDB 레코드로 직접 작업하려는 경우.
