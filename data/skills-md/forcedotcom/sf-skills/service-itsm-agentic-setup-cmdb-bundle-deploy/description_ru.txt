Разверните (установите) пакет базового контента CMDB Foundation в Service Cloud ITSM в производственной или изолированной организации после включения функции CMDB. Используйте, когда пользователь запрашивает установку пакета CMDB, развертывание CMDB Foundation, настройку базового содержимого CMDB, установку готового содержимого CMDB или завершение установки CMDB с помощью базового пакета. Срабатывает при: установке пакета CMDB, развертывании CMDB Foundation, базовом контенте CMDB, пакете контента CMDB, установке пакета, завершении настройки CMDB. НЕ ЗАПУСКАЙТЕ, когда: пользователь хочет включить функцию CMDB для организации (то есть навык включения функции CMDB), назначить наборы разрешений CMDB пользователю (то есть навык назначения доступа к CMDB), установить дополнительные небазовые пакеты надстроек, развернуть общие (не CMDB) метаданные или пакеты или работать с записями CMDB напрямую.
