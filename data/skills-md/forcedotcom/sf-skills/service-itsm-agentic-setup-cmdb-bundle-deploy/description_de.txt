Stellen Sie das CMDB Foundation-Basisinhaltspaket in Service Cloud ITSM für eine Produktions- oder Sandbox-Organisation bereit (installieren Sie es), nachdem die CMDB-Funktion aktiviert wurde. Verwenden Sie diese Option, wenn der Benutzer das CMDB-Bundle installieren, CMDB Foundation bereitstellen, den CMDB-Basisinhalt einrichten, sofort einsatzbereite CMDB-Inhalte installieren oder die CMDB-Einrichtung mit dem Basispaket abschließen möchte. Auslöser bei: CMDB-Bundle installieren, CMDB Foundation bereitstellen, CMDB-Basisinhalt, CMDB-Inhaltsbundle, Bundle-Installation, CMDB-Einrichtung abschließen. NICHT AUSLÖSEN, wenn: der Benutzer die CMDB-Funktion für die Organisation aktivieren möchte (d. h. die CMDB-Feature-Aktivierungs-Skill), einem Benutzer CMDB-Berechtigungssätze zuweisen möchte (d. h. die CMDB-Zugriffszuweisungs-Skill), optionale Nicht-Basis-Add-On-Bundles installieren, allgemeine (nicht CMDB-)Metadaten oder Pakete bereitstellen oder direkt mit CMDB-Datensätzen arbeiten möchte.
