Implemente (instale) el paquete de contenido básico de CMDB Foundation en Service Cloud ITSM en una organización de producción o sandbox, después de habilitar la característica CMDB. Úselo cuando el usuario solicite instalar el paquete CMDB, implementar CMDB Foundation, configurar el contenido base de CMDB, instalar el contenido de CMDB listo para usar o finalizar la configuración de CMDB con el paquete base. Se activa: instalar el paquete CMDB, implementar CMDB Foundation, contenido base de CMDB, paquete de contenido de CMDB, instalación del paquete, finalizar la configuración de CMDB. NO ACTIVAR cuando: el usuario desea habilitar la función CMDB para la organización (es decir, la habilidad de habilitación de funciones de CMDB), asignar conjuntos de permisos de CMDB a un usuario (es decir, la habilidad de asignación de acceso de CMDB), instalar paquetes complementarios opcionales no básicos, implementar metadatos o paquetes generales (no CMDB), o trabajar con registros CMDB directamente.
