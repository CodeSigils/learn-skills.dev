قم بنشر (تثبيت) حزمة المحتوى الأساسي لـ CMDB Foundation في Service Cloud ITSM مقابل مؤسسة الإنتاج أو وضع الحماية، بعد تمكين ميزة CMDB. يُستخدم عندما يطلب المستخدم تثبيت حزمة CMDB، أو نشر CMDB Foundation، أو إعداد المحتوى الأساسي لـ CMDB، أو تثبيت محتوى CMDB الجاهز، أو إنهاء إعداد CMDB بالحزمة الأساسية. المشغلات: تثبيت حزمة CMDB، ونشر مؤسسة CMDB، والمحتوى الأساسي لـ CMDB، وحزمة محتوى CMDB، وتثبيت الحزمة، وإنهاء إعداد CMDB. لا تقم بالتشغيل عندما: يريد المستخدم تمكين ميزة CMDB للمؤسسة (أي مهارة تمكين ميزات CMDB)، أو تعيين مجموعات أذونات CMDB لمستخدم (أي مهارة تعيين الوصول إلى CMDB)، أو تثبيت حزم الوظائف الإضافية غير الأساسية الاختيارية، أو نشر بيانات التعريف أو الحزم العامة (غير CMDB)، أو العمل مع سجلات CMDB مباشرة.
