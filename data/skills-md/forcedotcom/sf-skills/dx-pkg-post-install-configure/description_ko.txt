이 기술을 사용하여 관리 패키지 설치 후 구성을 자동화합니다. 패키지에 구애받지 않음 — 모든 관리 패키지(LMA, FMA, work.com, Certinia 등)에서 작동합니다. TRIGGER 언제: 사용자가 관리 패키지를 설치하고 설치 후 구성이 필요하고, LMA/FMA/work.com 설치 후 설정을 언급하고, 설치된 패키지에 대한 권한 집합/FLS/페이지 레이아웃을 구성하도록 요청하고, '설치 후', '패키지 설정', 'LMA 구성', 'FMA 설정', '설치 후 단계'라고 말합니다. 다음의 경우에는 트리거하지 마세요: 독립형 권한 집합 할당(dx-org-permission-set-sign 사용), 권한 집합 메타데이터 XML 생성(플랫폼-permission-set-generate 사용), 패키지 설치 또는 조직 전환.
