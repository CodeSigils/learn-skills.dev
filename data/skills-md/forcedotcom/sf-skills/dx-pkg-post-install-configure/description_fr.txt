Utilisez cette compétence pour automatiser la configuration post-installation des packages gérés. Indépendant du package : fonctionne avec n'importe quel package géré (LMA, FMA, work.com, Certinia, etc.). DÉCLENCHEMENT lorsque : l'utilisateur installe un package géré et a besoin d'une configuration post-installation, mentionne la configuration post-installation de LMA/FMA/work.com, demande de configurer les ensembles d'autorisations/FLS/mises en page pour un package installé, dit "post-installation", "configuration du package", "configurer LMA", "configurer FMA", "étapes post-installation". NE PAS DÉCLENCHER pour : l'attribution d'un ensemble d'autorisations autonome (utilisez dx-org-permission-set-assign), la génération de métadonnées XML d'ensemble d'autorisations (utilisez platform-permission-set-generate), l'installation de packages ou le changement d'organisation.
