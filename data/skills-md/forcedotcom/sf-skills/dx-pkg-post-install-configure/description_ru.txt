Используйте этот навык для автоматизации настройки управляемого пакета после установки. Независимость от пакета — работает с любым управляемым пакетом (LMA, FMA, work.com, Certinia и т. д.). ТРИГГЕР, когда: пользователь устанавливает управляемый пакет и нуждается в настройке после установки, упоминает настройку после установки LMA/FMA/work.com, запрашивает настройку наборов разрешений/FLS/макетов страниц для установленного пакета, говорит «после установки», «настройка пакета», «настройка LMA», «настройка FMA», «шаги после установки». НЕ ЗАПУСКАТЬ для: автономного назначения набора разрешений (используйте dx-org-permission-set-assign), создания XML метаданных набора разрешений (используйте Platform-permission-set-generate), установки пакета или переключения организации.
