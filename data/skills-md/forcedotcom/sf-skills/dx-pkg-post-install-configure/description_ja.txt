このスキルを使用して、管理パッケージのインストール後の構成を自動化します。パッケージに依存しない — あらゆる管理パッケージ (LMA、FMA、work.com、Certinia など) で動作します。トリガーされる場合: ユーザーが管理パッケージをインストールし、インストール後の構成が必要な場合、LMA/FMA/work.com のインストール後のセットアップについて言及した場合、インストールされたパッケージの権限セット/FLS/ページ レイアウトの構成を要求した場合、「インストール後」、「パッケージのセットアップ」、「LMA の構成」、「FMA のセットアップ」、「インストール後の手順」と述べた場合。次の場合はトリガーしないでください: スタンドアロン権限セットの割り当て (dx-org-permission-set-assign を使用)、権限セット メタデータ XML の生成 (platform-permission-set-generate を使用)、パッケージのインストール、または組織の切り替え。
