Utilizza questa competenza per automatizzare la configurazione post-installazione del pacchetto gestito. Indipendente dal pacchetto: funziona con qualsiasi pacchetto gestito (LMA, FMA, work.com, Certinia, ecc.). SI ATTIVA quando: l'utente installa un pacchetto gestito e necessita di una configurazione post-installazione, menziona la configurazione post-installazione di LMA/FMA/work.com, chiede di configurare set di autorizzazioni/FLS/layout di pagina per un pacchetto installato, dice "post-installazione", "configurazione pacchetto", "configura LMA", "imposta FMA", "passaggi post-installazione". NON SI ATTIVA per: assegnazione di set di autorizzazioni autonomo (utilizzare dx-org-permission-set-assign), generazione di metadati XML di set di autorizzazioni (utilizzare platform-permission-set-generate), installazione di pacchetti o cambio di organizzazione.
