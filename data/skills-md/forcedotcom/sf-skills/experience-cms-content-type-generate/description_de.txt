Fertigkeit zur Erstellung von Salesforce CMS ContentTypeBundles. Verwenden Sie diese Fähigkeit JEDERZEIT, wenn eine Benutzeranfrage die Erstellung eines ContentTypeBundles beinhaltet, und aktivieren Sie sie ZUERST, wenn die Erstellung eines CMS ContentTypeBundles erwähnt wird. Erkennt vorhandene Typen über Metadatenerdung und erstellt ein validatorkorrektes Zwei-Dateien-Bundle, das die Probelaufbereitstellung besteht. TRIGGER, wenn: Der Benutzer möchte eine wiederverwendbare Inhaltsform in Salesforce CMS – einer beliebigen Domäne – definieren, ein Gerüst erstellen, generieren oder einrichten, einschließlich Formulierungen wie „Erstellen Sie einen Inhaltstyp für X“, „Generieren Sie ein Schema für X in CMS“ oder „Einrichten eines Inhaltstyps für X“. NICHT AUSLÖSEN, wenn: ein Datensatz erstellt (Experience-CMS-Content-Generate verwenden), Datensätze veröffentlicht/verwaltet (CMS-Benutzeroberfläche verwenden), ein vorhandenes Bundle, eine CMS-Marke (Experience-CMS-Brand-Apply), eine Mediensuche (Experience-Content-Media-Search), benutzerdefinierte Lightning-Typen (Platform-Custom-Lightning-Type-Generate) oder Nicht-CMS-Metadaten geändert/umbenennen/löschen.
