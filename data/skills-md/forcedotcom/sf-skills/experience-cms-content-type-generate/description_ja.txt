Salesforce CMS ContentTypeBundle 作成スキル。ユーザー リクエストに ContentTypeBundle の作成が含まれる場合は常にこのスキルを使用し、CMS ContentTypeBundle の作成が言及されたときに最初にアクティブ化します。メタデータ基盤を介して既存のタイプを検出し、ドライラン デプロイに合格するバリデーターが正しい 2 つのファイル バンドルを生成します。トリガーのタイミング: ユーザが、「X のコンテンツ タイプを作成する」、「CMS で X のスキーマを生成する」、または「X のコンテンツ タイプを設定する」などの表現を含む、Salesforce CMS (任意のドメイン) で再利用可能なコンテンツ シェイプを定義、スキャフォールディング、生成、または設定したい場合。次の場合はトリガーしないでください: レコードの作成 ( experience-cms-content-generate を使用)、レコードの公開/管理 (CMS UI を使用)、既存のバンドルの変更/名前変更/削除、CMS ブランド ( experience-cms-brand-apply )、メディア検索 ( experience-content-media-search )、カスタム Lightning タイプ (platform-custom-lightning-type-generate)、または非 CMS メタデータ。
