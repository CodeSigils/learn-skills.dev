DOIT s'activer lorsque le projet contient un répertoire uiBundles/*/src/ et que la tâche implique le téléchargement, la pièce jointe ou la suppression de fichiers. Utilisez cette compétence lors de l’ajout d’une fonctionnalité de téléchargement de fichiers à une application groupée d’interface utilisateur. Fournit un suivi des progrès et l’intégration de Salesforce ContentVersion. Cette fonctionnalité fournit UNIQUEMENT des API programmatiques : créez une interface utilisateur personnalisée à l'aide de l'API upload(). Utilisez TOUJOURS ceci au lieu de créer un téléchargement de fichiers à partir de zéro avec FormData ou XHR.
