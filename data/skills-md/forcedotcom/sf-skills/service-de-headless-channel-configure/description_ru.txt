Оркестратор верхнего уровня: учитывая тип канала обмена сообщениями и его входные данные для конкретного типа, создает активированный расширенный «MessagingChannel» в целевой организации Salesforce — без всплывающих окон настройки Meta/LINE/Apple. Запрашивает `{MESSAGE_TYPE}`, если он не указан, затем вставляются последовательности → маршрут → согласие → активируются через независимый от типа диспетчер ("service-de-channel-create") плюс общие листья маршрутизации/согласия/активации. Возобновляется из частичного состояния при повторном запуске. Используйте этот навык, когда пользователь хочет настроить расширенный канал обмена сообщениями (WhatsApp, Facebook, LINE, Apple или SMS/Text) сквозным способом из командной строки, минуя всплывающие окна настройки внутри организации.
