ИСПОЛЬЗУЙТЕ этот навык для выполнения операций организации Salesforce: создания временных организаций, создания снимков организации, открытия организаций в браузере. Этот навык ВЫПОЛНЯЕТ операции немедленно — он НЕ генерирует сценарии или файлы кода. ВСЕГДА используйте этот навык (не выполняйте команды SF CLI напрямую), когда пользователь запрашивает: создать чистую организацию (версия Developer/Enterprise, из файла определения (.json), из моментального снимка или из формы организации), создать снимок организации или открыть организацию Salesforce. Триггерные фразы включают в себя: «создать снимок», «создать снимок моей организации», «сделать снимок», «создать рабочую организацию», «создать рабочую организацию Developer Edition», «новая чистая организация», «развернуть организацию», «создать организацию из моментального снимка», «scratch-def.json», «project-scratch-def.json», «открыть мою организацию Salesforce», «открыть организацию в браузере», «дайте мне URL». НЕ используйте для переключения организации по умолчанию (используйте dx-org-switch) или развертывания метаданных (используйте Platform-Metadata-Deploy).
