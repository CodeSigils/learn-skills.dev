DOIT s'activer avant de modifier TOUT fichier sous uiBundles/*/src/ pour les modifications visuelles ou d'interface utilisateur d'une application EXISTANTE : pages, composants, sections, mise en page, style, couleurs, polices, navigation, animations ou tout changement d'apparence. Utilisez cette compétence lors de la modification de pages, de composants, de mise en page, de style ou de navigation dans une application groupée d'interface utilisateur existante. Activez lorsque le projet contient appLayout.tsx, routes.tsx, src/pages/, src/components/ ou global.css. Cette compétence contient des conventions critiques spécifiques au projet (shell appLayout.tsx, composants shadcn/ui, Tailwind CSS, routage du chemin de base Salesforce, restrictions de module) qui remplacent les connaissances générales. Sans cette compétence, le code généré utilisera des importations incorrectes, interrompra le routage ou ignorera la structure du projet. Ne PAS utiliser lors de la création d’une nouvelle application à partir de zéro (utilisez plutôt experience-ui-bundle-app-coordonnée).
