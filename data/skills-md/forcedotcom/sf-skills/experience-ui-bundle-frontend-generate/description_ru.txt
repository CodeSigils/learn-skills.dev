НЕОБХОДИМО активировать перед редактированием ЛЮБОГО файла в uiBundles/*/src/ для изменения визуальных элементов или пользовательского интерфейса СУЩЕСТВУЮЩЕГО приложения — страниц, компонентов, разделов, макета, стиля, цветов, шрифтов, навигации, анимации или любых изменений внешнего вида. Используйте этот навык при изменении страниц, компонентов, макета, стиля или навигации в существующем приложении пакета пользовательского интерфейса. Активируйте, если проект содержит appLayout.tsx, Routes.tsx, src/pages/, src/comComponents/ или global.css. Этот навык содержит важные соглашения, специфичные для проекта (оболочка appLayout.tsx, компоненты shadcn/ui, CSS Tailwind, маршрутизация базового пути Salesforce, ограничения модулей), которые переопределяют общие знания. Без этого навыка сгенерированный код будет использовать неправильный импорт, нарушать маршрутизацию или игнорировать структуру проекта. НЕ используйте при создании нового приложения с нуля (вместо этого используйте experience-ui-bundle-app-coordinate).
