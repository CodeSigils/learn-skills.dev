DEBE activarse antes de editar CUALQUIER archivo en uiBundles/*/src/ para cambios visuales o de interfaz de usuario en una aplicación EXISTENTE: páginas, componentes, secciones, diseño, estilo, colores, fuentes, navegación, animaciones o cualquier cambio de apariencia. Utilice esta habilidad al modificar páginas, componentes, diseño, estilo o navegación en una aplicación de paquete de interfaz de usuario existente. Actívelo cuando el proyecto contenga appLayout.tsx, route.tsx, src/pages/, src/components/ o global.css. Esta habilidad contiene convenciones críticas específicas del proyecto (shell appLayout.tsx, componentes shadcn/ui, Tailwind CSS, enrutamiento de ruta base de Salesforce, restricciones de módulo) que anulan el conocimiento general. Sin esta habilidad, el código generado utilizará importaciones incorrectas, interrumpirá el enrutamiento o ignorará la estructura del proyecto. NO lo use al crear una nueva aplicación desde cero (use en su lugar experiencia-ui-bundle-app-coordinate).
