Salesforce 元資料 API 參考，用於建立、理解或修改元資料 XML 檔案（.object-meta.xml、.flow-meta.xml 等）和 604 種元資料類型中的任何一種（CustomObject、Flow、ApexClass、ApexTrigger、Profile、PermissionSet、Layout、ValidationRZayout、ValidationR、RelateType...）。用於解答有關類型欄位或 XML 格式或 Salesforce DX 專案結構（force-app/main/default）的問題。在以下情況下觸發：創作或編輯任何 *-meta.xml 檔案、詢問元資料類型具有哪些欄位/格式，或每當提及「Salesforce 元資料」或「sfdx 專案」時。請勿在下列情況下觸發：SOQL/DML/執行階段 sObject 存取（使用 Enterprise API 技能）、工具 API 開發人員記錄（ApexExecutionOverlayAction、TraceFlag）或非 XML 邏輯（Apex 程式碼、LWC JS、Visualforce 控制器）。
