Справочник по API метаданных Salesforce для создания, понимания или изменения XML-файлов метаданных (.object-meta.xml, .flow-meta.xml и т. д.) и любого из 604 типов метаданных (CustomObject, Flow, ApexClass, ApexTrigger, Profile, PermissionSet, Layout, ValidationRule, RecordType, EmailTemplate, ...). Используйте для вопросов о полях типа, формате XML или структуре проекта Salesforce DX (force-app/main/default). ЗАПУСКАЕТСЯ при: создании или редактировании любого файла *-meta.xml, запросе, какие поля/формат имеет тип метаданных, или всякий раз, когда упоминаются «метаданные Salesforce» или «проект sfdx». НЕ ЗАПУСКАЕТСЯ при: доступе к объекту SOQL/DML/среды выполнения (используйте навык Enterprise API), записях разработчика Tooling API (ApexExecutionOverlayAction, TraceFlag) или логике, отличной от XML (код Apex, LWC JS, контроллеры Visualforce).
