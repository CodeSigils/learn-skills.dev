Riferimento API Salesforce Metadata per creare, comprendere o modificare file XML di metadati (.object-meta.xml, .flow-meta.xml, ecc.) e uno qualsiasi dei 604 tipi di metadati (CustomObject, Flow, ApexClass, ApexTrigger, Profile, PermissionSet, Layout, ValidationRule, RecordType, EmailTemplate, ...). Da utilizzare per domande sui campi di un tipo o sul formato XML oppure sulla struttura del progetto Salesforce DX (app-force/principale/predefinita). SI ATTIVA quando: si crea o si modifica qualsiasi file *-meta.xml, si chiede quali campi/formato ha un tipo di metadati o ogni volta che viene menzionato "metadati Salesforce" o "progetto sfdx". NON SI ATTIVA quando: accesso SOQL/DML/runtime sObject (utilizzare la competenza API Enterprise), record dello sviluppatore API Tooling (ApexExecutionOverlayAction, TraceFlag) o logica non XML (codice Apex, LWC JS, controller Visualforce).
