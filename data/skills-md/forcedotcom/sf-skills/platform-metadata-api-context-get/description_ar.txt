مرجع واجهة برمجة تطبيقات بيانات تعريف Salesforce لإنشاء ملفات XML للبيانات التعريفية أو فهمها أو تعديلها (.object-meta.xml، .flow-meta.xml، وما إلى ذلك) وأي من أنواع البيانات التعريفية البالغ عددها 604 (CustomObject، وFlow، وApexClass، وApexTrigger، وProfile، وPermissionSet، وLayout، وValidationRule، وRecordType، وEmailTemplate، ...). يُستخدم للأسئلة حول حقول النوع أو تنسيق XML، أو بنية مشروع Salesforce DX (force-app/main/default). يتم تشغيله عند: تأليف أو تحرير أي ملف *-meta.xml، أو السؤال عن الحقول/التنسيق الذي يحتوي عليه نوع بيانات التعريف، أو عند ذكر "بيانات تعريف Salesforce" أو "مشروع sfdx". لا تقم بالتشغيل عند: الوصول إلى SOQL/DML/sObject في وقت التشغيل (استخدم مهارة Enterprise API)، أو سجلات مطور Tooling API (ApexExecutionOverlayAction، أو TraceFlag)، أو منطق غير XML (رمز Apex، أو LWC JS، أو وحدات تحكم Visualforce).
