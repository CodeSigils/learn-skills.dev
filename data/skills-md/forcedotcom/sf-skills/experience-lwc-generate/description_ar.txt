مكونات الويب السريعة مع منهجية PICKLES وسجل 165 نقطة. استخدم هذه المهارة عندما يقوم المستخدم بإنشاء مكونات LWC أو تحريرها، أو إنشاء أنماط خدمة سلكية، أو كتابة اختبارات Jest لـ LWC. يتم تشغيله عندما: يقوم المستخدم بإنشاء/تحرير مكونات LWC، أو لمس ملفات lwc/**/*.js، أو .html، أو .css، أو .js-meta.xml، أو يسأل عن الخدمة السلكية، أو SLDS، أو اختبارات Jest LWC. لا تقم بالتشغيل عندما: فئات Apex (استخدم إنشاء منصة apex)، أو مكونات Aura، أو Visualforce.
