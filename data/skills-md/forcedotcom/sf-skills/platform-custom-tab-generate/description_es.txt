Utilice esta habilidad cuando los usuarios necesiten crear o configurar pestañas personalizadas de Salesforce. Se activa cuando los usuarios mencionan pestañas, pestañas de navegación, pestañas de objetos, pestañas web, pestañas de Visualforce, pestañas de componentes Lightning, pestañas de páginas de aplicaciones o configuración de pestañas. Úselo también cuando los usuarios quieran agregar navegación a objetos personalizados, crear pestañas para contenido externo o configurar pestañas de páginas Lightning. Utilice siempre esta habilidad para cualquier trabajo con pestañas personalizadas.
