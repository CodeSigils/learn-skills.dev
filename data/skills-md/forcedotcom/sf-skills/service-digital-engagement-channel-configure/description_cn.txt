配置和部署增强型聊天消息通道，用于应用程序内和 Web 消息传递 (MIAW)。当用户需要创建、部署和激活配置有全渠道流、全渠道队列、用户或 Agentforce 服务代理路由的消息传递通道时使用。生成 MessagingChannel 元数据，将其部署到目标组织，并通过元数据 API 通过用户验证、聊天前表单、自动响应、同意设置和所有可自定义的渠道选项激活渠道。当用户提及消息通道、MIAW、增强型聊天、应用内消息、Web 消息设置或引用 .messagingChannel-meta.xml 文件时触发。当用户配置旧版 Live Agent 聊天、没有消息传递的嵌入式服务部署或没有消息传递通道的标准全渠道路由规则时，请勿触发。
