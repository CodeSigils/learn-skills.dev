アプリ内および Web 用メッセージング用の拡張チャット メッセージング チャネル (MIAW) を構成および展開します。ユーザーが、オムニチャネル フロー、オムニチャネル キュー、ユーザー、または Agentforce サービス エージェント ルーティングで構成されたメッセージング チャネルを作成、展開、アクティブ化する必要がある場合に使用します。 MessagingChannel メタデータを生成し、対象の組織に展開し、メタデータ API を介してユーザー認証、事前チャット フォーム、自動応答、同意設定、およびすべてのカスタマイズ可能なチャネル オプションを使用してチャネルを有効化します。ユーザーがメッセージング チャネル、MIAW、拡張チャット、アプリ内メッセージング、Web メッセージングのセットアップに言及したとき、または .messagingChannel-meta.xml ファイルを参照したときにトリガーされます。ユーザーが従来の Live Agent チャット、メッセージングを使用しない組み込みサービス展開、またはメッセージング チャネルを使用しない標準のオムニチャネル ルーティング ルールを構成している場合は、トリガーしないでください。
