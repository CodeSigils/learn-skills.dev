Configura e implementa canales de mensajería de chat mejorados para mensajería en la aplicación y web (MIAW). Utilícelo cuando el usuario necesite crear, implementar y activar un canal de mensajería configurado con flujo omnicanal, cola omnicanal, usuario o enrutamiento de agente de servicio Agentforce. Genera metadatos de MessagingChannel, los implementa en la organización de destino y activa el canal con verificación de usuario, formularios previos al chat, respuestas automáticas, configuraciones de consentimiento y todas las opciones de canal personalizables a través de la API de metadatos. DISPARA cuando el usuario menciona un canal de mensajería, MIAW, chat mejorado, mensajería en la aplicación, configuración de mensajería web o hace referencia a un archivo .messagingChannel-meta.xml. NO DISPARAR cuando el usuario esté configurando el chat heredado de Live Agent, implementaciones de servicios integrados sin mensajería o reglas de enrutamiento omnicanal estándar sin un canal de mensajería.
