Настраивает и развертывает расширенные каналы обмена сообщениями чата для обмена сообщениями в приложениях и в Интернете (MIAW). Используйте, когда пользователю необходимо создать, развернуть и активировать канал обмена сообщениями, настроенный с использованием многоканального потока, многоканальной очереди, пользователя или маршрутизации агента службы Agentforce. Генерирует метаданные MessagingChannel, развертывает их в целевой организации и активирует канал с проверкой пользователя, формами предварительного чата, автоматическими ответами, настройками согласия и всеми настраиваемыми параметрами канала через API метаданных. ТРИГГЕР, когда пользователь упоминает канал обмена сообщениями, MIAW, расширенный чат, обмен сообщениями в приложении, настройку веб-сообщений или ссылается на файл .messagingChannel-meta.xml. НЕ ЗАПУСКАЙТЕ, когда пользователь настраивает устаревший чат Live Agent, развертывание встроенной службы без обмена сообщениями или стандартные правила многоканальной маршрутизации без канала обмена сообщениями.
