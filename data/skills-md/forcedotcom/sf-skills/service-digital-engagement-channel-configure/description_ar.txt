يقوم بتكوين ونشر قنوات مراسلة الدردشة المحسنة للمراسلة داخل التطبيق والويب (MIAW). يُستخدم عندما يحتاج المستخدم إلى إنشاء ونشر وتنشيط قناة مراسلة تم تكوينها باستخدام توجيه Omni-Channel Flow أو Omni-Channel Queue أو User أو Agentforce Service Agent. يُنشئ بيانات تعريف MessagingChannel، وينشرها في المؤسسة المستهدفة، وينشط القناة من خلال التحقق من المستخدم، ونماذج ما قبل الدردشة، والاستجابات الآلية، وإعدادات الموافقة، وجميع خيارات القناة القابلة للتخصيص عبر Metadata API. يتم تشغيله عندما يذكر المستخدم قناة المراسلة، أو MIAW، أو الدردشة المحسنة، أو المراسلة داخل التطبيق، أو إعداد مراسلة الويب، أو يشير إلى ملف .messagingChannel-meta.xml. لا تقم بالتشغيل عندما يقوم المستخدم بتكوين دردشة Live Agent القديمة، أو عمليات نشر الخدمة المضمنة بدون مراسلة، أو قواعد توجيه Omni-Channel القياسية بدون قناة مراسلة.
