配置和部署增強型聊天訊息通道，用於應用程式內和 Web 訊息傳遞 (MIAW)。當使用者需要建立、部署和啟動配置全渠道流、全渠道佇列、使用者或 Agentforce 服務代理路由的訊息傳遞通道時使用。產生 MessagingChannel 元數據，將其部署到目標組織，並透過元資料 API 透過使用者驗證、聊天前表單、自動回應、同意設定和所有可自訂的頻道選項啟動頻道。當使用者提及訊息通道、MIAW、增強型聊天、應用程式內訊息、Web 訊息設定或引用 .messagingChannel-meta.xml 檔案時觸發。當使用者設定舊版 Live Agent 聊天、沒有訊息傳遞的嵌入式服務部署或沒有訊息傳遞通道的標準全通路路由規則時，請勿觸發。
