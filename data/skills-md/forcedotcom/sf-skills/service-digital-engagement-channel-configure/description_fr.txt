Configure et déploie des canaux de messagerie de chat améliorés pour la messagerie pour les applications et le Web (MIAW). À utiliser lorsque l'utilisateur doit créer, déployer et activer un canal de messagerie configuré avec le routage Omni-Channel Flow, Omni-Channel Queue, User ou Agentforce Service Agent. Génère des métadonnées MessagingChannel, les déploie sur l'organisation cible et active le canal avec la vérification de l'utilisateur, les formulaires de pré-chat, les réponses automatisées, les paramètres de consentement et toutes les options de canal personnalisables via l'API de métadonnées. DÉCLENCHEMENT lorsque l'utilisateur mentionne le canal de messagerie, MIAW, le chat amélioré, la messagerie intégrée à l'application, la configuration de la messagerie Web ou fait référence à un fichier .messagingChannel-meta.xml. NE PAS DÉCLENCHER lorsque l'utilisateur configure le chat Live Agent existant, les déploiements de services intégrés sans messagerie ou les règles de routage Omni-Channel standard sans canal de messagerie.
