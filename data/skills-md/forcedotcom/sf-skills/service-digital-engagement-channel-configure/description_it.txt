Configura e distribuisce canali di messaggistica chat avanzati per la messaggistica per in-app e Web (MIAW). Da utilizzare quando l'utente deve creare, distribuire e attivare un canale di messaggistica configurato con il flusso multicanale, la coda multicanale, l'utente o il routing dell'agente di servizio Agentforce. Genera metadati MessagingChannel, li distribuisce all'organizzazione di destinazione e attiva il canale con verifica utente, moduli pre-chat, risposte automatizzate, impostazioni di consenso e tutte le opzioni di canale personalizzabili tramite API Metadata. SI ATTIVA quando l'utente menziona il canale di messaggistica, MIAW, la chat avanzata, la messaggistica in-app, la configurazione della messaggistica web o fa riferimento a un file .messagingChannel-meta.xml. NON SI ATTIVA quando l'utente sta configurando la chat legacy di Live Agent, le distribuzioni del servizio incorporato senza messaggistica o le regole di routing multicanale standard senza un canale di messaggistica.
