Coordinateur interactif de haut niveau pour la configuration des canaux du service aux employés (ITSM). Présente le menu des options de configuration des canaux (Équipes, Slack, Essaim, Notifications, Portail) et délègue à la compétence correspondante. Utilisez-le pour : « configurer les canaux ITSM », « configurer les canaux de service des employés », « configurer les canaux de communication du service cloud », « Je souhaite configurer les intégrations ITSM » ou toute demande générale de configuration de canal/intégration ITSM pour laquelle l'utilisateur n'a pas spécifié exactement quel canal il souhaite. NE DÉCLENCHEZ PAS les demandes qui nomment déjà un canal ou une compétence enfant spécifique (par exemple, « configurer Teams », « configurer Slack », « activer Swarming », « configurer les notifications ITSM », « créer un portail pour les employés ») – dirigez-vous directement vers la compétence enfant correspondante.
