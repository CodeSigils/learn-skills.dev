منسق لإعداد Agentforce في Salesforce Service Cloud ITSM - تمكين Agentforce Studio، ودورة حياة وكيل IT Service Fufiller، ودورة حياة وكيل موظف خدمة تكنولوجيا المعلومات. يُستخدم عندما يطلب المستخدم إعداد Agentforce لـ ITSM، أو تمكين Studio ووكلاء Fufiller/Employee معًا، أو يريد دليلاً إرشاديًا لـ Agentforce ITSM، أو يسأل عن ميزات Agentforce المتوفرة لخدمة تكنولوجيا المعلومات. يقدم قدرات Agentforce المتاحة ويفوض كل اختيار إلى مهارة الطفل المتخصصة أثناء تتبع التقدم. تشغيل المشغلات: إعداد AgentForce لـ itsm، وتكوين AgentForce Studio وCompiler، والإرشادات التفصيلية لـ AgentForce ITM، وما هي ميزات AgentForce لخدمتها. لا تقم بالتشغيل عندما: يطلب المستخدم تمكين Agentforce Studio وحده، أو يطلب إنشاء أو تنشيط وكيل Fufiller أو الموظف وحده، أو يسأل عن CMDB، أو إدارة الحوادث، أو الفرق، أو إعداد ITSM العام دون نية Agentforce.
