Оркестратор для настройки Agentforce в Salesforce Service Cloud ITSM — включение Agentforce Studio, жизненный цикл агента IT Service Fulfiller и жизненный цикл агента IT Service Staff. Используйте, когда пользователь просит настроить Agentforce для ITSM, одновременно включить Studio и агентов Fulfiller/Employee, хочет пройти пошаговое руководство по Agentforce ITSM или спрашивает, какие функции Agentforce доступны для ИТ-службы. Представляет доступные возможности Agentforce и делегирует каждый выбор специализированному детскому навыку, отслеживая прогресс. Запускается при: настройке Agentforce для ItSM, настройке Agentforce Studio и исполнителя, пошаговом руководстве по Agentforce ItSM, функциях Agentforce для It-сервиса. НЕ АКТИВИРУЙТЕСЬ, когда: пользователь просит включить только Agentforce Studio, просит создать или активировать только агента Fulfiller или сотрудника или спрашивает о CMDB, управлении инцидентами, командах или общей настройке ITSM без намерения Agentforce.
