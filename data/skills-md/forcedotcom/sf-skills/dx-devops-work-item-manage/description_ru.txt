Используйте этот навык для управления полным жизненным циклом рабочих элементов DevOps Center — составления списка, создания, обновления, фиксации изменений, выполнения переходов состояний и создания запросов на включение. Обновите такие поля, как тема, описание и статус. Зафиксируйте и отправьте изменения кода в ветки рабочих элементов. Создавайте запросы на включение для ветвей рабочих элементов через API DevOps Center. Вызывайте, когда пользователь хочет отслеживать, находить, создавать или обновлять рабочий элемент, фиксировать изменения в ветке рабочего элемента, продвигать состояние рабочего элемента через конвейер или создавать запрос на включение для проверки кода. Объединяет операции по определению рабочих элементов и проверке научной фантастики. НЕ ЗАПУСКАЙТЕ для операций продвижения или развертывания, а также для обнаружения конфликтов.
