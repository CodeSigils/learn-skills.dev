Utilice esta habilidad para administrar el ciclo de vida completo de los elementos de trabajo de DevOps Center: enumerar, crear, actualizar, confirmar cambios, realizar transiciones de estado y crear solicitudes de extracción. Actualice campos como asunto, descripción y estado. Confirme y envíe cambios de código a las ramas de elementos de trabajo. Cree solicitudes de extracción para ramas de elementos de trabajo a través de la API del Centro DevOps. Invocar cuando el usuario desea rastrear, buscar, crear o actualizar un elemento de trabajo, confirmar cambios en una rama de un elemento de trabajo, avanzar el estado de un elemento de trabajo a través de la canalización o crear una solicitud de extracción para revisión de código. Consolida las operaciones de revisión y elementos de trabajo de sf devops. NO DISPARAR para operaciones de promoción o implementación, o detección de conflictos.
