Competenza di orchestratore per abilitare CMDB (Configuration Management Database) end-to-end in Service Cloud ITSM rispetto a un'organizzazione di produzione o sandbox. Da utilizzare quando l'utente chiede di impostare CMDB, abilitare il database di gestione della configurazione, configurare il CMDB ITSM, eseguire l'onboarding del CMDB da zero, desidera una procedura guidata sull'abilitazione del CMDB o chiede quali passaggi di configurazione del CMDB sono disponibili. Trigger su: configurazione CMDB, abilitazione CMDB, configurazione CMDB, onboarding CMDB, configurazione del database di gestione della configurazione, procedura dettagliata ITSM CMDB. NON SI ATTIVA quando: l'utente richiede direttamente una specifica fase secondaria del CMDB (ad esempio, solo installazione di un bundle, solo assegnazione di set di autorizzazioni), record CRUD del CMDB (creazione di elementi della configurazione, relazioni), configurazione del connettore Discovery/Service Graph o query ITSM generali senza intento di configurazione del CMDB.
