Habilidad de orquestador para habilitar CMDB (base de datos de gestión de configuración) de un extremo a otro en Service Cloud ITSM en una organización de producción o sandbox. Úselo cuando el usuario solicita configurar CMDB, habilitar la base de datos de administración de configuración, configurar ITSM CMDB, incorporar CMDB desde cero, desea un recorrido guiado sobre la habilitación de CMDB o pregunta qué pasos de configuración de CMDB están disponibles. Activadores: configurar CMDB, habilitar CMDB, configurar CMDB, incorporación de CMDB, configuración de la base de datos de gestión de configuración, tutorial de ITSM CMDB. NO DISPARAR cuando: el usuario pregunta directamente sobre un subpaso de CMDB específico (por ejemplo, solo instalar un paquete, solo asignar conjuntos de permisos), registro CRUD de CMDB (creación de CI, relaciones), configuración del conector de gráfico de servicio/descubrimiento o consultas ITSM generales sin intención de configuración de CMDB.
