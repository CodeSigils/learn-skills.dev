Compétence d'orchestrateur pour activer CMDB (Configuration Management Database) de bout en bout dans Service Cloud ITSM sur une organisation de production ou sandbox. À utiliser lorsque l'utilisateur demande à configurer CMDB, à activer la base de données de gestion de configuration, à configurer ITSM CMDB, à intégrer CMDB à partir de zéro, souhaite une présentation guidée de l'activation de CMDB ou demande quelles étapes de configuration de CMDB sont disponibles. Déclencheurs sur : configurer CMDB, activer CMDB, configurer CMDB, intégration de CMDB, configuration de la base de données de gestion de configuration, procédure pas à pas ITSM CMDB. NE PAS DÉCLENCHER lorsque : l'utilisateur pose directement des questions sur une sous-étape CMDB spécifique (par exemple, installer uniquement un ensemble, attribuer uniquement des ensembles d'autorisations), CRUD d'enregistrement CMDB (création de CI, relations), configuration du connecteur Discovery/Service Graph ou requêtes ITSM générales sans intention de configuration CMDB.
