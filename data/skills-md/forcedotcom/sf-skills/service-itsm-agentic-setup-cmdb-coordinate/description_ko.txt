프로덕션 또는 샌드박스 조직에 대해 Service Cloud ITSM에서 엔드 투 엔드 CMDB(구성 관리 데이터베이스)를 활성화하기 위한 오케스트레이터 기술입니다. 사용자가 CMDB 설정, 구성 관리 데이터베이스 활성화, ITSM CMDB 구성, CMDB 처음부터 온보딩, CMDB 활성화 안내 안내를 원하거나 어떤 CMDB 설정 단계를 사용할 수 있는지 묻는 경우에 사용합니다. 트리거 대상: CMDB 설정, CMDB 활성화, CMDB 구성, CMDB 온보딩, 구성 관리 데이터베이스 설정, ITSM CMDB 연습. 다음의 경우에는 트리거하지 마세요: 사용자가 특정 CMDB 하위 단계에 대해 직접 질문하는 경우(예: 번들 설치만, 권한 집합만 할당하는 경우), CMDB 레코드 CRUD(CI, 관계 생성), 검색/Service Graph 커넥터 구성 또는 CMDB 설정 의도가 없는 일반 ITSM 쿼리에 대해 질문하는 경우.
