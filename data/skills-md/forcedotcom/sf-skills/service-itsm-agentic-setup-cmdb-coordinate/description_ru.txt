Навыки оркестратора для обеспечения сквозной реализации CMDB (базы данных управления конфигурациями) в Service Cloud ITSM для производственной или изолированной организации. Используйте, когда пользователь просит настроить CMDB, включить базу данных управления конфигурацией, настроить ITSM CMDB, подключить CMDB с нуля, хочет получить пошаговое руководство по включению CMDB или спрашивает, какие шаги по настройке CMDB доступны. Запускается при: настройке CMDB, включении CMDB, настройке CMDB, подключении CMDB, настройке базы данных управления конфигурацией, пошаговом руководстве по ITSM CMDB. НЕ АКТИВИРУЙТЕСЬ, когда: пользователь напрямую запрашивает конкретный подэтап CMDB (например, только установку пакета, только назначение наборов разрешений), запись CMDB CRUD (создание ЭК, связей), конфигурацию соединителя Discovery/Service Graph или общие запросы ITSM без намерения установки CMDB.
