표준 REST sobject 엔드포인트를 통해 `MessagingChannelUsage.DeploymentStatus`를 `Disabled`에서 `Provisioning`으로 패치하여 향상된 `MessagingChannel`(WhatsApp/Apple/Facebook/SMS/RCS)을 활성화합니다. UDD 세이브 후크는 REST 쓰기 시 실행되고, 외부 콜아웃에 대해 `MessageType`에 의해 전달되고(`WHATS_APP` → Meta `/register`, `FACEBOOK` → `subscribeFacebookPage`, `TEXT` → `registerCsotSms`, Apple, LINE 등은 외부 호출이 필요하지 않음) 터미널 `Active` 또는 `Error`를 쓰고 `MessagingChannel.IsActive`를 뒤집습니다. 체인은 HTTP 응답에서 동기식입니다. WhatsApp은 Meta가 등록을 확인한 후에만(~15-21초) 204를 반환합니다. 외부 콜아웃이 없는 채널은 거의 즉각적입니다(Apple의 경우 최대 1초). No Aura RPC; no CSRF cookies. 사용자가 REST를 통해 헤드리스로 이미 삽입된 향상된 메시징 채널을 활성화해야 하는 경우 이 기술을 사용하십시오.
