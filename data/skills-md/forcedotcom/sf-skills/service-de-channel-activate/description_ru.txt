Активируйте расширенный MessagingChannel (WhatsApp/Apple/Facebook/SMS/RCS), изменив MessagingChannelUsage.DeploymentStatus с Disabled на Provisioning через стандартную конечную точку объекта REST. Перехватчик сохранения UDD срабатывает при записи REST, отправляет по `MessageType` для внешнего вызова (`WHATS_APP` → Meta `/register`, `FACEBOOK` → `subscribeFacebookPage`, `TEXT` → `registerCsotSms`; Apple, LINE и другим не нужен внешний вызов), записывает терминалу `Active` или `Error` и переворачивает `MessagingChannel.IsActive`. Цепочка синхронна по HTTP-ответу — WhatsApp возвращает 204 только после того, как Meta подтвердит регистрацию (~ 15–21 с); каналы без внешнего вызова работают почти мгновенно (~ 1 с на Apple). Нет Ауры РПК; нет файлов cookie CSRF. Используйте этот навык, когда пользователю необходимо активировать уже вставленный канал расширенного обмена сообщениями без участия пользователя через REST.
