Aktivieren Sie einen erweiterten „MessagingChannel“ (WhatsApp / Apple / Facebook / SMS / RCS), indem Sie „MessagingChannelUsage.DeploymentStatus“ über den Standard-REST-Sobject-Endpunkt von „Disabled“ auf „Provisioning“ patchen. Der UDD-Speicher-Hook wird beim REST-Schreiben ausgelöst, sendet per „MessageType“ für den externen Callout („WHATS_APP“ → Meta „/register“, „FACEBOOK“ → „subscribeFacebookPage“, „TEXT“ → „registerCsotSms“; Apple, LINE und andere benötigen keinen externen Aufruf), schreibt das Terminal „Aktiv“ oder „Fehler“ und dreht um „MessagingChannel.IsActive“. Die Kette ist mit der HTTP-Antwort synchron – WhatsApp gibt 204 erst zurück, nachdem Meta die Registrierung bestätigt hat (~15–21 Sekunden); Kanäle ohne externe Beschriftung erfolgen nahezu augenblicklich (~1s bei Apple). Kein Aura-RPC; keine CSRF-Cookies. Verwenden Sie diesen Skill, wenn der Benutzer einen bereits eingefügten erweiterten Messaging-Kanal kopflos über REST aktivieren muss.
