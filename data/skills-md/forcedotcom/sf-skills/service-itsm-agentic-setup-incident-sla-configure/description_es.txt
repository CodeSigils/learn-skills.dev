Configuración de SLA de incidentes de extremo a extremo para Service Cloud ITSM: crear un MilestoneType, una política de SLA con alcance de incidente (SlaProcess), adjuntar un hito con criterios y conectar un derecho para que los incidentes deriven un EntityMilestone con una fecha objetivo calculada. Úselo cuando el usuario solicite configurar hitos de SLA en incidentes, crear una política de SLA para registros de incidentes, configurar procesos de derechos para ITSM, cablear hitos para que aparezcan en la página de incidentes o habilitar el seguimiento de SLA para la gestión de incidentes. NO ACTIVAR cuando: el usuario pregunta sobre derechos de caso o SLA de caso (no incidente), consulta políticas de SLA existentes sin intención de configuración, sObject CRUD de derecho general no relacionado con el incidente o consultas de hitos solo con fines de generación de informes.
