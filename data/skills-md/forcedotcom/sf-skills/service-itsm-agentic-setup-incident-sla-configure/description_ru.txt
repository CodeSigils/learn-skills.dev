Комплексная настройка соглашения об уровне обслуживания для инцидентов для Service Cloud ITSM — создание MilestoneType, политики SLA на уровне инцидента (SlaProcess), прикрепление Milestone с критериями и подключение разрешения, чтобы инциденты получали EntityMilestone с вычисленным TargetDate. Используйте, когда пользователь просит настроить этапы SLA для инцидентов, создать политику SLA для записей инцидентов, настроить процессы предоставления прав для ITSM, перенести этапы, чтобы они отображались на странице инцидентов, или включить отслеживание SLA для управления инцидентами. НЕ АКТИВИРУЕТСЯ, когда: пользователь запрашивает права на обращение или соглашение об уровне обслуживания (не инцидент), запрашивает существующие политики SLA без намерения установки, общий CRUD объекта прав, не связанный с инцидентом, или запросы Milestone только для целей отчетности.
