Fase Salesforce Data Cloud Connect. Utilizza questa competenza quando l'utente gestisce connessioni e connettori Data Cloud o configura un nuovo sistema di origine. TRIGGER quando: l'utente gestisce connessioni Data Cloud, connettori, metadati del connettore, testa una connessione, esplora oggetti o database di origine o configura un nuovo sistema di origine. NON SI ATTIVA quando: l'attività riguarda flussi di dati o DLO (usa preparazione-datacloud), DMO o risoluzione dell'identità (usa harmonizing-datacloud), recupero/ricerca (usa retrieving-datacloud) o telemetria STDM (usa osservatore-agentforce).
