Automatización de Salesforce DevOps mediante sf CLI v2. DISPARAR cuando: el usuario implementa metadatos, crea/administra organizaciones borrador o entornos sandbox, configura canalizaciones de CI/CD o soluciona errores de implementación con la implementación del proyecto sf. NO DISPARE cuando: escriba código Apex (use platform-apex-generate), cree componentes LWC (use experience-lwc-generate), cree definiciones de metadatos (use platform-custom-object-generate o platform-custom-field-generate) o consulte datos de la organización (use platform-data-manage).
