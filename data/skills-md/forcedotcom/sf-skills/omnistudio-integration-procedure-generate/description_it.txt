Integrazione OmniStudio Creazione e validazione di procedure con punteggio a 110 punti. Utilizzare questa competenza durante la creazione di orchestrazioni di processi lato server che combinano azioni Data Mapper, Apex Remote Actions, callout HTTP e logica condizionale. TRIGGER quando: l'utente crea procedure di integrazione, aggiunge passaggi del Data Mapper, configura azioni remote o esamina le configurazioni IP esistenti. NON SI ATTIVA quando: crei OmniScript (usa omnistudio-omniscript-generate), crei direttamente Data Mapper (usa omnistudio-datamapper-generate) o analizzi le dipendenze tra componenti (usa omnistudio-dependencies-analyze).
