Genera un progetto iniziale SFDX minimo e pronto per lo sviluppo da un modello anziché da file di impalcature manuali. Utilizza questa competenza quando avvii una nuovissima app in bundle dell'interfaccia utente Salesforce React e il progetto iniziale deve essere strutturato: le frasi di attivazione includono creare, avviare o impacchettare una nuova app in bundle dell'interfaccia utente React, generare un progetto iniziale o utilizzare un modello predefinito/iniziale. NON SI ATTIVA quando: modifichi, stili o aggiungi pagine o componenti a un'app ESISTENTE (usa experience-ui-bundle-frontend-generate); configurazione di ui-bundle.json o file di metadati (utilizzare experience-ui-bundle-metadata-generate); distribuzione in un'organizzazione (utilizzare experience-ui-bundle-deploy); o quando l'utente dice esplicitamente di voler costruire manualmente l'impalcatura da zero.
