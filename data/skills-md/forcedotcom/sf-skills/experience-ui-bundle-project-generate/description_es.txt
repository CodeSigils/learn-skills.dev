Genera un proyecto inicial SFDX mínimo y listo para desarrollar a partir de una plantilla en lugar de archivos manuales. Utilice esta habilidad cuando inicie una nueva aplicación de paquete de UI de Salesforce React y el proyecto inicial deba ser estructurado; las frases desencadenantes incluyen crear, iniciar o desarrollar una nueva aplicación de paquete de UI de React, generar un proyecto inicial o usar una plantilla inicial o prediseñada. NO DISPARE cuando: edite, diseñe o agregue páginas o componentes a una aplicación EXISTENTE (use experiencia-ui-bundle-frontend-generate); configurar ui-bundle.json o archivos de metadatos (use experience-ui-bundle-metadata-generate); implementar en una organización (use experiencia-ui-bundle-deploy); o cuando el usuario dice explícitamente que quiere realizar un andamiaje manual desde cero.
