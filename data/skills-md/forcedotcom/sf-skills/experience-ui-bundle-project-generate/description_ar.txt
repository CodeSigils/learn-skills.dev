يُنشئ مشروع SFDX المبدئي البسيط والجاهز للتطوير من القالب بدلاً من ملفات السقالات اليدوية. استخدم هذه المهارة عند بدء تطبيق حزمة Salesforce React UI جديد تمامًا ويجب دعم المشروع الأولي - تتضمن عبارات التشغيل إنشاء تطبيق حزمة React UI جديد أو بدءه أو دعمه، أو إنشاء مشروع مبتدئ، أو استخدام قالب تم إنشاؤه مسبقًا/بدء التشغيل. لا تقم بالتشغيل عند: تحرير أو تصميم أو إضافة صفحات أو مكونات إلى تطبيق موجود (استخدم experience-ui-bundle-frontend-generate)؛ تكوين ui-bundle.json أو ملفات البيانات الوصفية (استخدم إنشاء بيانات التعريف الخاصة بـ experience-ui-bundle)؛ النشر إلى مؤسسة (استخدم experience-ui-bundle-deploy)؛ أو عندما يقول المستخدم صراحةً أنه يريد السقالة يدويًا من الصفر.
