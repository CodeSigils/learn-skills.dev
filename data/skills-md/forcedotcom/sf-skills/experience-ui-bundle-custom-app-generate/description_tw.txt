當專案包含 uiBundles/*/src/ 目錄且任務涉及建立或配置自訂應用程式以在 Lightning Experience 中託管 UI 套件時，必須啟動。建立 CustomApplication 元資料記錄時使用此技能以在應用程式啟動器中顯示 UI 套件。當存在與 applications/*.app-meta.xml 相符的檔案並需要修改時，或當使用者想要透過 Lightning 應用程式啟動器公開其應用程式而無需數位體驗網站時，啟動。請勿為此使用 platform-custom-application-generate — UI 捆綁應用程式不使用選項卡、操作覆蓋或 Flexipages。
