Úselo para configurar o reparar el agente de administración de ventas y la administración de canalizaciones de Agentforce en una organización de Salesforce. Automatiza la creación de metadatos para flujos, plantillas de mensajes, conjuntos de permisos y configuración de fuentes de datos. ACTIVAR cuando: el usuario desea habilitar Pipeline Management, configurar funciones de canalización de ventas, configurar el agente de Sales Management para actualizaciones de campos de oportunidades (incluidas actualizaciones autónomas), conectar fuentes de datos habilitadas como Einstein Conversation Insights o Einstein Activity Capture, personalizar descripciones de etapas de oportunidades, configurar sugerencias posteriores a la reunión, verificar o auditar el estado de configuración, corregir organizaciones parcialmente configuradas o solucionar problemas de metadatos de Pipeline Management. NO ACTIVAR cuando: el usuario quiera crear un agente personalizado (use agentforce-generate), configure el seguimiento general de Agentforce (use platform-tracing-agentforce-configure), trabaje con agentes que no sean de ventas o habilite Einstein Conversation Insights o Einstein Activity Capture desde cero (el aprovisionamiento está fuera del alcance).
