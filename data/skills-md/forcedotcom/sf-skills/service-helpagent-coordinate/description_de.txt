Verwenden Sie diese Option, um einen Salesforce Help Agent (einen Agentforce Service Agent in der Service Cloud) über einen geführten Ablauf mit vier Prüfpunkten einzurichten, zu konfigurieren, zu etablieren oder in Betrieb zu nehmen. Wird immer dann verwendet, wenn ein Benutzer Folgendes sagt: einen Hilfeagenten, einen Serviceagenten oder einen Support-Chat-Agenten einrichten/erstellen/erstellen/hinzufügen; Fügen Sie ein Chat-Widget auf einer Website oder einer Experience Cloud-/LWR-Site hinzu oder betten Sie es ein. Setzen Sie einen Hilfeagenten auf einen Kanal (Web-Chat, Sprache, Telefon, Hilfeportal), auch wenn Sie den Web-Chat ablehnen. einen Hilfeagenten auf Salesforce Knowledge aufbauen; oder möchte, dass eine KI Kundenfragen beantwortet, Supportfälle verwaltet und an einen Menschen eskaliert. Der richtige Skill, auch wenn die Anfrage nur einen Teil benennt, einen demnächst verfügbaren Kanal benennt, auf dem dieser Skill hart stoppt, oder auf help-agent-spec.md oder den Agentforce-Schnelleinrichtungsassistenten verweist. NICHT AUSLÖSEN, wenn Sie einen brandneuen Agenten ohne Help-Agent-Herkunft erstellen (agentforce-generate verwenden), OAuth/ECAs konfigurieren (integration-connectivity-connected-app-configure verwenden) oder nur Metadaten bereitstellen (platform-metadata-deploy verwenden).
