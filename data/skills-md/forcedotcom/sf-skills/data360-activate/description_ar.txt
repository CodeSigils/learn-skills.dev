مرحلة قانون سحابة بيانات Salesforce. استخدم هذه المهارة عندما يدير المستخدم عمليات التنشيط أو أهداف التنشيط أو إجراءات البيانات أو التسليم النهائي لجماهير وبيانات Data Cloud. يتم التشغيل عندما: يقوم المستخدم بإدارة عمليات التنشيط أو أهداف التنشيط أو إجراءات البيانات أو التسليم النهائي لجماهير وبيانات Data Cloud. لا تقم بالتشغيل عندما: تكون المهمة هي إنشاء مقطع (استخدم مقطع data360)، أو عمل استرجاع/بحث البيانات (استخدم استعلام data360)، أو تتبع STDM/الجلسة (استخدم agentforce-observe).
