قم بتنسيق إنشاء عناصر واجهة المستخدم Lightning Type + HXL المستندة إلى الكائنات لعرض مخرجات أداة خادم MCP مخصصة مدعومة بإجراء Apex Invocable Action. يتم التشغيل فقط عندما تتضمن المطالبة بشكل صريح عرض نتيجة أداة MCP: يقول المستخدم "خادم MCP"، أو "أداة MCP"، أو "خادم MCP مخصص"، أو يشير إلى أداة "مخطط الإخراج" / "إخراج الأداة" / مغلف "outputValues"، أو تسمية "إجراء قابل للاستدعاء" يدعم أداة MCP، أو يطلب إنشاء عنصر واجهة مستخدم أو عرض واجهة مستخدم غني لإخراج Apex-invocable-backed أداة MCP. لا تقم بالتشغيل عند: تخصيص مخرجات إجراء وكيل مدعوم من Apex (استخدم تنسيق Platform-lightning-type-widget)، أو تأليف نوع Lightning مخصص فقط (استخدم إنشاء نوع Lightning مخصص للنظام الأساسي)، أو تأليف فئة Apex فقط (استخدم إنشاء منصة apex)، أو إنشاء عنصر واجهة مستخدم مستقل بدون استخدام أداة Lightning Type أو MCP (استخدم إنشاء عنصر واجهة المستخدم للنظام الأساسي).
