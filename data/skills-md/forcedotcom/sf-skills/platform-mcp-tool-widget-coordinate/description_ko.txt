객체 기반 Lightning Type + HXL 위젯 생성을 조정하여 Apex 호출 가능 작업이 지원하는 사용자 정의 MCP 서버 도구의 출력을 렌더링합니다. 프롬프트가 MCP 도구 결과 렌더링을 명시적으로 포함하는 경우에만 TRIGGER: 사용자가 'MCP 서버', 'MCP 도구', '사용자 정의 MCP 서버'라고 말하고, 도구 '출력 스키마' / '도구 출력' / 'outputValues' 봉투를 참조하고, MCP 도구를 지원하는 '호출 가능한 작업'의 이름을 지정하거나 Apex 호출 가능 지원 MCP 도구의 출력에 대한 위젯 또는 리치 UI 변환을 빌드하도록 요청합니다. 다음의 경우에는 트리거하지 마십시오: Apex 지원 에이전트 작업 출력 사용자 정의(플랫폼-lightning-type-widget-coordinate 사용), 사용자 정의 Lightning 유형만 작성(platform-custom-lightning-type-generate 사용), Apex 클래스만 작성(platform-apex-generate 사용) 또는 관련 Lightning 유형 또는 MCP 도구 없이 독립 실행형 위젯 구축(플랫폼 위젯 생성 사용).
