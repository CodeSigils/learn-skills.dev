Orchestrieren Sie die objektbasierte Lightning Type + HXL-Widget-Generierung, um die Ausgabe eines benutzerdefinierten MCP-Server-Tools zu rendern, das durch eine Apex Invocable Action unterstützt wird. TRIGGER nur, wenn die Eingabeaufforderung AUSDRÜCKLICH das Rendern eines MCP-Tool-Ergebnisses beinhaltet: Der Benutzer sagt „MCP-Server“, „MCP-Tool“, „benutzerdefinierter MCP-Server“, verweist auf einen „Ausgabeschema“-/„Tool-Ausgabe“-/„OutputValues“-Umschlag des Tools, benennt eine „aufrufbare Aktion“, die ein MCP-Tool unterstützt, oder bittet um die Erstellung eines Widgets oder einer Rich-UI-Wiedergabe für die Ausgabe eines von Apex invocable unterstützten MCP-Tools. NICHT AUSLÖSEN, wenn: eine von Apex unterstützte Agentenaktionsausgabe angepasst wird (verwenden Sie „platform-lightning-type-widget-coordinate“), nur ein benutzerdefinierter Lightning-Typ erstellt wird (verwenden Sie „platform-custom-lightning-type-generate“), nur eine Apex-Klasse erstellt wird (verwenden Sie „platform-apex-generate“) oder ein eigenständiges Widget ohne beteiligtes Lightning Type- oder MCP-Tool erstellt wird (verwenden Sie „platform-widget-generate“).
