Организуйте создание виджетов Lightning Type + HXL на основе объектов для рендеринга выходных данных пользовательского серверного инструмента MCP, поддерживаемого вызываемым действием Apex. ЗАПУСКАЕТСЯ только тогда, когда приглашение ЯВНО включает в себя рендеринг результата инструмента MCP: пользователь произносит «сервер MCP», «инструмент MCP», «пользовательский сервер MCP», ссылается на конверт «схема вывода» / «выход инструмента» / «выходные значения» инструмента, называет «вызываемое действие», поддерживающее инструмент MCP, или просит создать виджет или расширенное представление пользовательского интерфейса для выходных данных инструмента MCP, поддерживаемого Apex. НЕ АКТИВИРУЕТСЯ при: настройке выходных данных действия агента, поддерживаемого Apex (используйте платформу-lightning-type-widget-coordinate), разработке только пользовательского типа Lightning (используйте платформу-custom-lightning-type-generate), разработке только класса Apex (используйте платформу-apex-generate) или создании автономного виджета без использования Lightning Type или инструмента MCP (используйте Platform-widget-generate).
