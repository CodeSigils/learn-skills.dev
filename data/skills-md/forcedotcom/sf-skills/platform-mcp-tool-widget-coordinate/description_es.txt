Orqueste la generación de widgets Lightning Type + HXL basados ​​en objetos para representar la salida de una herramienta de servidor MCP personalizada respaldada por una acción invocable de Apex. DISPARAR solo cuando el mensaje implica EXPLÍCITAMENTE representar el resultado de una herramienta MCP: el usuario dice 'servidor MCP', 'herramienta MCP', 'servidor MCP personalizado', hace referencia a un sobre de herramienta 'esquema de salida' / 'salida de herramienta' / 'valores de salida', nombra una 'acción invocable' que respalda una herramienta MCP o solicita crear un widget o una representación de interfaz de usuario enriquecida para la salida de una herramienta MCP respaldada por Apex. NO DISPARE cuando: personalice una salida de acción de agente respaldada por Apex (use plataforma-tipo-widget-coordenada), cree solo un tipo de Lightning personalizado (use plataforma-personalizada-tipo-relámpago-generar), cree solo una clase de Apex (use plataforma-apex-generate), o cree un widget independiente sin ningún tipo de Lightning o herramienta MCP involucrada (use plataforma-widget-generate).
