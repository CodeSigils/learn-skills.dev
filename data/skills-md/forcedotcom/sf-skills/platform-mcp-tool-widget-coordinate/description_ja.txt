オブジェクトベースの Lightning Type + HXL ウィジェットの生成を調整して、Apex 呼び出し可能アクションに基づくカスタム MCP サーバーツールの出力をレンダリングします。プロンプトに明示的に MCP ツールの結果のレンダリングが含まれる場合にのみトリガーします。ユーザーが「MCP サーバー」、「MCP ツール」、「カスタム MCP サーバー」と言うか、ツールの「出力スキーマ」/「ツール出力」/「outputValues」エンベロープを参照するか、MCP ツールをサポートする「呼び出し可能なアクション」に名前を付けるか、またはApex 呼び出し可能な MCP ツール。次の場合にはトリガーしないでください: Apex-backed エージェントアクション出力をカスタマイズする場合 (platform-lightning-type-widget-coowned を使用)、カスタム Lightning タイプのみを作成する場合 (platform-custom-lightning-type-generate を使用する)、Apex クラスのみを作成する場合 (platform-apex-generate を使用する)、または Lightning Type や MCP ツールが関与しないスタンドアロンのウィジェットを構築する場合 (platform-widget-generate を使用する)。
