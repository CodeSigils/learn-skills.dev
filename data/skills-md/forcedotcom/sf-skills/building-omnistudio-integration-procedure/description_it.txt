Integrazione OmniStudio Creazione e validazione di procedure con punteggio a 110 punti. Utilizzare questa competenza durante la creazione di orchestrazioni di processi lato server che combinano azioni Data Mapper, Apex Remote Actions, callout HTTP e logica condizionale. SI ATTIVA quando: l'utente crea procedure di integrazione, aggiunge passaggi del Data Mapper, configura Azioni remote o esamina le configurazioni IP esistenti. NON SI ATTIVA quando: crei OmniScript (usa building-omnistudio-omniscript), crei direttamente Data Mapper (usa building-omnistudio-datamapper) o analizzi le dipendenze tra componenti (usa analyze-omnistudio-dependencies).
