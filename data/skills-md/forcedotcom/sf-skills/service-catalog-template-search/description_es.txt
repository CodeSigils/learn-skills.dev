Busca en el catálogo unificado de Salesforce plantillas de procesos de servicio disponibles que coincidan con una necesidad empresarial, utilizando Salesforce CLI (sf), clasificándolas por relevancia para la solicitud. Sólo lectura: no recomienda ni instala nada. Úselo cuando un usuario empresarial quiera buscar, explorar, descubrir o explorar plantillas de proceso de servicio o catálogo unificado disponibles para una solicitud, o pregunta qué plantillas de catálogo existen. Activadores: encontrar una plantilla de catálogo, buscar plantillas de proceso de servicio, qué plantillas de catálogo unificado están disponibles, explorar el catálogo de servicios, hay una plantilla para X, recomendar una plantilla para esta solicitud. NO ACTIVAR cuando: el usuario ya eligió una plantilla exacta y solicita implementarla, instalarla o activarla (use service-catalog-template-deploy), o la solicitud se refiere a kits de datos de Data Cloud, CRM Analytics o plantillas de App Framework en lugar de plantillas de proceso de servicio de catálogo unificado.
