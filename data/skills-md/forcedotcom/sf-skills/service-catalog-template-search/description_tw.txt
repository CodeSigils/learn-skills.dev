使用 Salesforce CLI (sf) 在 Salesforce 統一目錄中搜尋符合業務需求的可用服務流程模板，並按與要求的相關性對它們進行排名。只讀：它不建議也不安裝任何內容。當業務使用者想要針對請求尋找、搜尋、瀏覽、發現或探索可用的統一目錄或服務流程模板，或詢問存在哪些目錄模板時使用。觸發條件：尋找目錄範本、搜尋服務流程範本、可用的統一目錄範本、瀏覽服務目錄、是否有 X 範本、為此要求推薦範本。在下列情況下請勿觸發：使用者已選擇確切的範本並要求部署、安裝或啟動它（使用 service-catalog-template-deploy），或要求涉及 Data Cloud 封包、CRM Analytics 或應用程式框架範本而不是 Unified Catalog Service Process 範本。
