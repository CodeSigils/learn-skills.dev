Salesforce CLI(sf)를 사용하여 비즈니스 요구 사항과 일치하는 사용 가능한 서비스 프로세스 템플릿을 Salesforce 통합 카탈로그에서 검색하고 요청 관련성에 따라 순위를 매깁니다. 읽기 전용: 아무것도 권장하지 않고 설치하지 않습니다. 비즈니스 사용자가 요청에 대해 사용 가능한 통합 카탈로그 또는 서비스 프로세스 템플릿을 찾고, 검색하고, 탐색하고, 탐색하고 싶어하거나 어떤 카탈로그 템플릿이 있는지 묻는 경우에 사용합니다. 트리거 대상: 카탈로그 템플릿 찾기, 서비스 프로세스 템플릿 검색, 사용 가능한 통합 카탈로그 템플릿, 서비스 카탈로그 찾아보기, X용 템플릿이 있는지, 이 요청에 대한 템플릿 추천. 사용자가 이미 정확한 템플릿을 선택하고 이를 배포, 설치 또는 활성화하도록 요청하는 경우(service-catalog-template-deploy 사용) 또는 요청이 통합 카탈로그 서비스 프로세스 템플릿이 아닌 Data Cloud 데이터 키트, CRM 분석 또는 앱 프레임워크 템플릿과 관련된 경우에는 트리거하지 마세요.
