عرض Data Cloud 360° لجلسة Agentforce واحدة. يتم تشغيله عندما يطلب المستخدم تتبع جلسة Agentforce معينة أو فحصها أو تلخيصها أو وصفها بواسطة معرف الجلسة (UUID لجلسة الوكيل `019d...` أو معرف MessagingSession `0Mw...`). يتم تشغيله أيضًا عند اكتشاف الجلسة - ابحث عن/قائمة/بحث الجلسات حسب الوقت أو الوكيل أو القناة أو النتيجة أو نص المحادثة - عندما لا يكون لدى المستخدم معرف جلسة حتى الآن. لا تقم بالطرح للأسئلة المتعلقة بهندسة وقت التصميم (استخدم تحليل AgentForce-architecture بدلاً من ذلك) أو للأسئلة المتعلقة بأداء وقت التشغيل/زمن الوصول/SLO التي تتطلب قياس النظام الأساسي عن بعد خارج Data Cloud.
