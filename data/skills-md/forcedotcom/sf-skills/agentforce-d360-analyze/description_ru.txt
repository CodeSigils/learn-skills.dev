Обзор Data Cloud 360° для одного сеанса Agentforce. СИГНАЛИЗАЦИЯ, когда пользователь запрашивает отследить, проверить, обобщить или описать конкретный сеанс Agentforce по идентификатору сеанса (UUID сеанса агента `019d…` или идентификатор сеанса MessagingSession `0Mw…`). Также срабатывает при обнаружении сеанса — поиск/список/поиск сеансов по времени, агенту, каналу, результату или тексту разговора — когда у пользователя еще нет идентификатора сеанса. НЕ ИНИЦИРУЙТЕ для вопросов об архитектуре времени разработки (вместо этого используйте Agentforce-architecture-analyze) или для вопросов производительности/задержки/SLO во время выполнения, которые требуют телеметрии платформы за пределами облака данных.
