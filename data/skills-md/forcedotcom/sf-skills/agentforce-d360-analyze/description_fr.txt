Vue Data Cloud à 360° d'une seule session Agentforce. DÉCLENCHEMENT lorsque l'utilisateur demande de tracer, d'inspecter, de résumer ou de décrire une session Agentforce spécifique par ID de session (UUID de session d'agent `019d…` ou ID de session de messagerie `0Mw…`). Se déclenche également lors de la découverte de session (recherche/liste/recherche de sessions par heure, agent, canal, résultat ou texte de conversation) lorsque l'utilisateur n'a pas encore d'identifiant de session. NE PAS DÉCLENCHER pour les questions d'architecture au moment de la conception (utilisez plutôt agentforce-architecture-analyze) ou pour les questions de performances d'exécution/latence/SLO qui nécessitent une télémétrie de plate-forme au-delà de Data Cloud.
