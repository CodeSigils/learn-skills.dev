مرجع الحقل/المخطط المعتمد لكائنات 2130 STANDARD Salesforce - يُستخدم للبحث عن أسماء API القياسية لحقل الأدوات والكائنات والأنواع والخصائص (قابلة للتصفية/الفرز/القابلة للتجميع/القابلة للتحديث)، وأسماء العلاقات للحساب، وجهة الاتصال، والفرصة، والعميل المتوقع، والحالة، وApexClass، وApexCodeCoverage، وTraceFlag، والمزيد. قم بتحميل هذا جنبًا إلى جنب مع مهارة SOQL/الاستعلام/Apex عندما لا يتم التحقق من أسماء الحقول أو أنواعها أو قدرات التصفية/الفرز/المجموعة - وليس عندما تكون الحقول معروفة بالفعل ولا يلزم سوى بناء جملة الاستعلام أو التحسين. يتم تشغيله عند التحقق من الحقول أو التحقق من صحتها أو تصحيح أخطاء الحقول في استعلام SOQL/SOSL أو DML مقابل كائن قياسي - الإمكانات أو مسارات العلاقة/الاستعلام الفرعي أو الحقول التي يحتوي عليها الكائن - بحيث يتم تشغيل الاستعلام بدلاً من التخمين. لا توجد كائنات __c وحقول __c المخصصة في هذه الأصول؛ قم بوصف المؤسسة الحية لهؤلاء (وصف كائن sf). لا تقم بالبدء في تأليف/نشر *-meta.xml أو مصدر sfdx (استخدم مهارة Metadata API).
