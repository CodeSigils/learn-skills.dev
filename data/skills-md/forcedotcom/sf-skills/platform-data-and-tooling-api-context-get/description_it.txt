Riferimento a campi/schemi autorevoli per oggetti Salesforce 2130 STANDARD: utilizzare per cercare nomi, tipi, proprietà (filtrabili/ordinabili/raggruppabili/aggiornabili) standard delle API dei campi sObject e Strumenti e nomi di relazioni per Account, Contatto, Opportunità, Lead, Caso, ApexClass, ApexCodeCoverage, TraceFlag e altro ancora. Caricalo insieme a una competenza SOQL/query/Apex quando i nomi dei campi, i tipi o le funzionalità di filtro/ordinamento/raggruppamento non sono verificati, non quando i campi sono già noti ed è necessaria solo la sintassi o l'ottimizzazione della query. TRIGGER durante la verifica, la convalida o il debug dei campi in una query SOQL/SOSL o DML rispetto a un oggetto standard (capacità, percorsi di relazione/sottoquery o campi di un oggetto) in modo che la query venga eseguita invece di indovinare. Gli oggetti __c personalizzati e i campi __c NON sono presenti in queste risorse; descrivere l'organizzazione dal vivo per quelli (sf oggetto descrivere). NON ATTIVARE la creazione/distribuzione dell'origine *-meta.xml o sfdx (utilizzare la competenza API Metadata).
