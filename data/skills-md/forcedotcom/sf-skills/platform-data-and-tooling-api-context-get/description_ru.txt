Справочная ссылка на авторитетное поле/схему для объектов Salesforce 2130 STANDARD — используйте для поиска стандартных имен API полей sObject и Tooling, типов, свойств (фильтруемых/сортируемых/группируемых/обновляемых) и имен отношений для организации, контакта, возможности, интереса, дела, ApexClass, ApexCodeCoverage, TraceFlag и т. д. Загрузите это вместе с навыком SOQL/запроса/Apex, когда имена полей, типы или возможности фильтрации/сортировки/группировки не проверены, а не тогда, когда поля уже известны и требуется только синтаксис запроса или оптимизация. TRIGGER при проверке, проверке или отладке полей в запросе SOQL/SOSL или DML относительно стандартного объекта — возможностей, путей отношений/подзапросов или полей, которые имеет объект — поэтому запрос выполняется, а не угадывается. Пользовательские объекты __c и поля __c НЕ входят в эти активы; опишите для них действующую организацию (описание научно-фантастического объекта). НЕ ЗАПУСКАЙТЕ для создания/развертывания источника *-meta.xml или sfdx (используйте навык Metadata API).
