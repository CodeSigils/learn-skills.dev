アプリケーションまたは単一の LWC コンポーネントに対して Salesforce Lightning プレビューを実行するときに使用して、検査のためにランタイム DOM を抽出します。ユーザが「ローカルで LWC をプレビューする」、「sf lightning dev を実行する」、「ローカル開発を起動する」、「実行時にコンポーネントのシャドウ DOM を検査する」、「ライブプレビューからレンダリングされた HTML を取得する」、「実際にレンダリングされる内容とテンプレートのトラブルシューティングを行う」、「Salesforce Live Preview プラグインを設定する」、「Lightning プレビュー」、「ローカル開発サーバー」、または「ランタイム DOM を抽出する」と言ったときにトリガーされます。ユーザーが LWC ソース コードを作成または編集しているとき (experience-lwc-generate を使用)、またはコンポーネント コードを実行せずに静的にレビューしているときは、トリガーしないでください。
