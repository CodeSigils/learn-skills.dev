Используйте при запуске Salesforce Lightning Preview для приложения или отдельного компонента LWC, чтобы извлечь DOM среды выполнения для проверки. ТРИГГЕР, когда пользователь говорит «предварительный просмотр LWC локально», «запустите SF Lightning dev», «запустите локальную разработку», «проверьте теневой DOM компонента во время выполнения», «получите визуализированный HTML из предварительного просмотра в реальном времени», «устраните неполадки того, что на самом деле визуализируется по сравнению с шаблоном», «настройте плагин Salesforce Live Preview», «предварительный просмотр Lightning», «локальный сервер разработки» или «извлеките DOM времени выполнения». НЕ ЗАПУСКАЙТЕ, когда пользователь создает или редактирует исходный код LWC (используйте experience-lwc-generate) или статически просматривает код компонента, не запуская его.
