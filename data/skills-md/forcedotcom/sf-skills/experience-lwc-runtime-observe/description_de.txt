Verwenden Sie diese Option, wenn Sie Salesforce Lightning Preview für eine Anwendung oder eine einzelne LWC-Komponente ausführen, um das Laufzeit-DOM zur Überprüfung zu extrahieren. TRIGGER, wenn der Benutzer sagt: „LWC lokal in der Vorschau anzeigen“, „SF Lightning Dev ausführen“, „Local Dev starten“, „Schatten-DOM einer Komponente zur Laufzeit überprüfen“, „gerenderten HTML-Code aus einer Live-Vorschau abrufen“, „Fehler beheben, was tatsächlich im Vergleich zur Vorlage gerendert wird“, „Salesforce Live Preview-Plugin einrichten“, „Lightning-Vorschau“, „Lokaler Entwicklungsserver“ oder „Laufzeit-DOM extrahieren“. NICHT AUSLÖSEN, wenn der Benutzer LWC-Quellcode erstellt oder bearbeitet (verwenden Sie experience-lwc-generate) oder Komponentencode statisch überprüft, ohne ihn auszuführen.
