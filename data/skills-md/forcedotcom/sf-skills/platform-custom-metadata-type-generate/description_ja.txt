ユーザが Salesforce カスタム メタデータ タイプのメタデータ (__mdt オブジェクト、そのフィールド、およびそのデプロイ可能なレコード) を作成、生成、または検証する必要がある場合は、このスキルを使用します。ユーザーがカスタム メタデータ タイプ、CMDT、__mdt オブジェクト、カスタム メタデータ レコード、.md-meta.xml ファイル、または組織間で送信する必要がある参照/構成データに言及したときにトリガーされます。また、管理者が管理するマッピング、ルックアップ、またはクロスウォーク テーブルとフィールド マッピング (「フィールドを A から B にマップする」、コード ルックアップ) もトリガーします。コードを使用せずに設定管理者が変更するデプロイは CMDT に属し、Apex や Flow でハードコードされることはありません。また、CMDT レコード/タイプ デプロイ エラーのトラブルシューティングを行うときにもトリガーされます。カスタム設定ではトリガーしないでください — platform-custom-setting-generate にルーティングします。ビジネス レコードを保持する通常のカスタム オブジェクトの場合 — platform-custom-object-generate を使用します。またはシークレットと API キーの場合は、このスキルでは決して生成されない名前付き認証情報を推奨します。
