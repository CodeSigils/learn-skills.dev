Utilisez cette compétence lorsque les utilisateurs doivent créer, générer ou valider des métadonnées de type de métadonnées personnalisées Salesforce : l'objet __mdt, ses champs et ses enregistrements déployables. Déclenchez lorsque les utilisateurs mentionnent des types de métadonnées personnalisées, CMDT, des objets __mdt, des enregistrements de métadonnées personnalisées, des fichiers .md-meta.xml ou des données de référence/configuration qui doivent être transmises entre les organisations. Déclenchez également le mappage, la recherche ou les tables de concordance gérées par l'administrateur et les mappages de champs ("mapper les champs de A à B", recherches de code) - les administrateurs de configuration changent sans qu'un déploiement de code n'appartienne à un CMDT, jamais codé en dur dans Apex ou Flow - et lors du dépannage des erreurs de déploiement d'enregistrement/type CMDT. NE PAS DÉCLENCHER pour les paramètres personnalisés – route vers platform-custom-setting-generate ; pour les objets personnalisés réguliers contenant des enregistrements commerciaux, utilisez platform-custom-object-generate ; ou pour les secrets et les clés API, recommandez un identifiant nommé, que cette compétence ne génère jamais.
