Используйте этот навык, когда пользователям необходимо создать, сгенерировать или проверить метаданные типа пользовательских метаданных Salesforce — объект __mdt, его поля и его развертываемые записи. Срабатывает, когда пользователи упоминают типы пользовательских метаданных, объекты CMDT, __mdt, записи пользовательских метаданных, файлы .md-meta.xml или справочные данные/данные конфигурации, которые должны передаваться между организациями. Также активируется для поддерживаемых администратором таблиц сопоставления, поиска или перекрестного перехода и сопоставлений полей («сопоставление полей от A до B», поиск кода) — изменение конфигурации администраторами без развертывания кода принадлежит CMDT, никогда не запрограммировано жестко в Apex или Flow — и при устранении ошибок развертывания записи/типа CMDT. НЕ ЗАПУСКАТЬ для пользовательских настроек — перейдите к созданию пользовательских настроек платформы; для обычных пользовательских объектов, содержащих бизнес-записи, используйте Platform-custom-object-generate; или для секретов и ключей API — рекомендуем именованные учетные данные, которые этот навык никогда не генерирует.
