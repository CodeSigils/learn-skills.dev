Verwenden Sie diese Fähigkeit, wenn Benutzer Metadaten des benutzerdefinierten Salesforce-Metadatentyps erstellen, generieren oder validieren müssen – das __mdt-Objekt, seine Felder und seine bereitstellbaren Datensätze. Wird ausgelöst, wenn Benutzer benutzerdefinierte Metadatentypen, CMDT, __mdt-Objekte, benutzerdefinierte Metadatensätze, .md-meta.xml-Dateien oder Referenz-/Konfigurationsdaten erwähnen, die zwischen Organisationen versendet werden müssen. Wird auch für vom Administrator verwaltete Mapping-, Nachschlage- oder Crosswalk-Tabellen und Feldzuordnungen („Felder von A nach B zuordnen“, Code-Lookups) ausgelöst – Konfigurationsadministratoren ändern, ohne dass ein Code bereitgestellt wird, der in einen CMDT gehört, niemals fest in Apex oder Flow codiert – und bei der Fehlerbehebung bei CMDT-Datensatz-/Typ-Deploy-Fehlern. NICHT für benutzerdefinierte Einstellungen auslösen – Weiterleitung an „platform-custom-setting-generate“; für reguläre benutzerdefinierte Objekte, die Geschäftsunterlagen enthalten, verwenden Sie „platform-custom-object-generate“; oder für Geheimnisse und API-Schlüssel – empfehlen Sie einen benannten Berechtigungsnachweis, der von diesem Skill nie generiert wird.
