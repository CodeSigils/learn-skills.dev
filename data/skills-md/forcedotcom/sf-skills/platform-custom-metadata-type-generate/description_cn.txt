当用户需要创建、生成或验证 Salesforce 自定义元数据类型元数据（__mdt 对象、其字段及其可部署记录）时，请使用此技能。当用户提到自定义元数据类型、CMDT、__mdt 对象、自定义元数据记录、.md-meta.xml 文件或必须在组织之间传送的引用/配置数据时触发。还触发管理员维护的映射、查找或人行横道表和字段映射（“将字段从 A 映射到 B”、代码查找）——配置管理员在没有代码部署的情况下更改属于 CMDT，从未在 Apex 或 Flow 中进行硬编码——以及在排除 CMDT 记录/类型部署错误时触发。不要触发自定义设置 — 路由至平台-自定义-设置-生成；对于保存业务记录的常规自定义对象 - 使用 platform-custom-object-generate；或者对于秘密和 API 密钥 - 推荐一个命名凭证，该技能永远不会生成该凭证。
