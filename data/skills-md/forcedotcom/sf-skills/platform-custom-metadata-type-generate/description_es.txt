Utilice esta habilidad cuando los usuarios necesiten crear, generar o validar metadatos de tipo de metadatos personalizados de Salesforce: el objeto __mdt, sus campos y sus registros implementables. Se activa cuando los usuarios mencionan tipos de metadatos personalizados, CMDT, objetos __mdt, registros de metadatos personalizados, archivos .md-meta.xml o datos de referencia/configuración que deben enviarse entre organizaciones. También se activan tablas de mapeo, búsqueda o cruce de peatones mantenidas por el administrador y asignaciones de campos ("campos de mapa de A a B", búsquedas de código): los cambios de los administradores de configuración sin una implementación de código pertenecen a una CMDT, nunca están codificados en Apex o Flow, y cuando se solucionan problemas de errores de implementación de registros/tipos de CMDT. NO DISPARAR para configuraciones personalizadas: ruta a plataforma-configuración-personalizada-generar; para objetos personalizados habituales que contienen registros comerciales, utilice platform-custom-object-generate; o para secretos y claves API: recomiende una credencial con nombre, que esta habilidad nunca genera.
