當使用者需要建立、產生或驗證 Salesforce 自訂元資料類型元資料（__mdt 物件、其欄位及其可部署記錄）時，請使用此技能。當使用者提到自訂元資料類型、CMDT、__mdt 物件、自訂元資料記錄、.md-meta.xml 檔案或必須在組織之間傳送的引用/配置資料時觸發。還觸發管理員維護的映射、查找或人行橫道表和字段映射（“將字段從 A 映射到 B”、代碼查找）——配置管理員在沒有代碼部署的情況下更改屬於 CMDT，從未在 Apex 或 Flow 中進行硬編碼——以及在排除 CMDT 記錄/類型部署錯誤時觸發。不要觸發自訂設定 — 路由至平台-自訂-設定-產生；對於儲存業務記錄的常規自訂物件 - 使用 platform-custom-object-generate；或對於秘密和 API 金鑰 - 推薦一個命名憑證，該技能永遠不會產生該憑證。
