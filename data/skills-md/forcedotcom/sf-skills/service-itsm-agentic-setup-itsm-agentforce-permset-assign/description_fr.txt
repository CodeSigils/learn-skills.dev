Résolvez les actions invocables manquantes d’ITSM Intelligence afin qu’un agent Fulfiller NGA puisse s’activer. Lit lesquels des quatre permsets de personnages Core Fulfiller (IncidentFulfiller, ProblemFulfillerPermSet, ChangeRequestFulfillerPermSet, ReleaseManagerPermSet) sont fournis, puis attribue à l'utilisateur en cours d'exécution le personnage sélectionné (plus le PSL de sauvegarde en cas de licence) afin que les actions svc_itsm_intelligence__* apparaissent ; passez la main à service-itsm-agentic-setup-agentforce-studio-validate si aucun n’est fourni. À utiliser lorsque la compétence de configuration de l'agent Fulfiller signale des actions manquantes lors de l'activation, lorsque « L'action invocable svc_itsm_intelligence__X n'existe pas » apparaît ou lorsqu'un utilisateur demande à s'accorder l'accès au modèle d'invite Fulfiller. NE PAS DÉCLENCHER pour l'accès employé-agent, les bascules Agentforce pour service informatique, la création d'agent, l'accès CMDB ou l'attribution d'un ensemble de paramètres génériques.
