استخدم هذه المهارة لتحديد ما إذا كان مكوّن Lightning Web Component (LWC) قابلاً للوصول ويتوافق مع إرشادات إمكانية الوصول WCAG. يتم التفعيل عندما يطرح المستخدم أسئلة مثل "هل مكوّني قابل للوصول؟"، "هل يلتزم LWC الخاص بي بإرشادات إمكانية الوصول؟"، "هل هذا المكوّن متوافق مع WCAG؟"، "اعثر على مشاكل إمكانية الوصول في هذا LWC"، "هل هذا LWC قابل للوصول عبر لوحة المفاتيح؟"، "هل يعمل هذا المكوّن مع قارئ الشاشة؟"، "هل يمتلك هذا المكوّن تباين لوني كافٍ؟"، "تحقق من استخدام ARIA في هذا LWC"، أو "فحص إمكانية وصول WCAG 2.2". كما يتم التفعيل عندما يرغب المستخدم في إصلاح أو تحسين إمكانية الوصول (a11y، WCAG، ARIA) في HTML أو JS أو CSS الخاص بـ LWC — العلامات الدلالية، التركيز، التنقل عبر لوحة المفاتيح، التباين، تسميات قارئ الشاشة، معيار WCAG 2.2 SC. ينتج ملف `a11y‑review.md` يتضمن النتائج مع الاستشهاد ب WCAG. لا تقم بالتفعيل لأغراض إنشاء LWC عامة (استخدم `experience-lwc-generate`) أو لمراجعة التصميم/SLDS البصري غير الموجهة إلى إمكانية الوصول (استخدم `design-systems-slds-validate`).  

يرجى دائمًا الرد بلغة المستخدم.
