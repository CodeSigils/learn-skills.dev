Используйте этот навык, чтобы определить, доступен ли Lightning Web Component (LWC) и соответствует ли он руководствам по доступности WCAG. TRIGGER, когда пользователь задаёт вопросы «is my component accessible?», «does my LWC meet accessibility guidelines?», «is this component WCAG compliant?», «find accessibility problems in this LWC», «is this LWC keyboard accessible?», «does this component work with a screen reader?», «does this component have sufficient color contrast?», «check ARIA usage in this LWC» или «WCAG 2.2 accessibility check». Также TRIGGER, когда пользователь хочет исправить или улучшить доступность (a11y, WCAG, ARIA) в HTML, JS или CSS LWC — семантическая разметка, фокус, навигация с клавиатуры, контраст, метки для скрин‑ридера, критерии WCAG 2.2 SC. Создаёт `a11y-review.md` с выводами, ссылаясь на WCAG. DO NOT TRIGGER для общего генерации LWC (используйте `experience-lwc-generate`) или визуального/дизайнерского обзора SLDS, не сосредоточенного на доступности (используйте `design-systems-slds-validate`). Пожалуйста, всегда отвечайте на языке пользователя.
