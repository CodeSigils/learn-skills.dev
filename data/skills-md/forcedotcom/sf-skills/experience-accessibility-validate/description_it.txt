Utilizzare questa competenza per determinare se un componente Web Lightning (LWC) è accessibile e soddisfa le linee guida sull'accessibilità WCAG. SI ATTIVA quando l'utente chiede "il mio componente è accessibile?", "il mio LWC soddisfa le linee guida sull'accessibilità?", "questo componente è conforme a WCAG?", "trova problemi di accessibilità in questo LWC", "questa tastiera LWC è accessibile?", "questo componente funziona con uno screen reader?", "questo componente ha un contrasto di colore sufficiente?", "controlla l'utilizzo di ARIA in questo LWC" o "controllo di accessibilità WCAG 2.2". SI ATTIVA anche quando l'utente desidera correggere o migliorare l'accessibilità (a11y, WCAG, ARIA) in HTML, JS o CSS di un LWC: markup semantico, focus, navigazione da tastiera, contrasto, etichette per lettore di schermo, WCAG 2.2 SC. Produce "a11y-review.md" con i risultati citati dalle WCAG. NON SI ATTIVA per la generazione generale di LWC (utilizzare `experience-lwc-generate`) o per la revisione visiva/progettuale SLDS non incentrata sull'accessibilità (utilizzare `design-systems-slds-validate`).
