使用此技能来判断 Lightning Web Component（LWC）是否可访问且符合 WCAG 可访问性指南。 当用户提问“我的组件可访问吗？”，“我的 LWC 符合可访问性指南吗？”，“此组件符合 WCAG 吗？”，“查找此 LWC 的可访问性问题”，“此 LWC 是否支持键盘操作？”，“此组件能与屏幕阅读器配合使用吗？”，“此组件的颜色对比度是否足够？”，“检查此 LWC 中的 ARIA 使用情况”，或“WCAG 2.2 可访问性检查”时触发。 还应在用户希望修复或改进 LWC 的 HTML、JS 或 CSS 中的可访问性（a11y、WCAG、ARIA）时触发——包括语义化标记、焦点管理、键盘导航、对比度、屏幕阅读器标签、WCAG 2.2 成功准则。 生成 `a11y-review.md`，其中包含引用 WCAG 的发现。 对于普通的 LWC 生成（使用 `experience-lwc-generate`）或非针对可访问性的 SLDS 视觉/设计审查（使用 `design-systems-slds-validate`），请勿触发。 请始终使用用户的语言作答。
