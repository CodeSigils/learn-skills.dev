Utiliza esta habilidad para determinar si un Lightning Web Component (LWC) es accesible y cumple con las directrices de accesibilidad WCAG. ACTIVAR cuando el usuario pregunte “¿mi componente es accesible?”, “¿mi LWC cumple con las directrices de accesibilidad?”, “¿este componente cumple con WCAG?”, “buscar problemas de accesibilidad en este LWC”, “¿este LWC es accesible mediante teclado?”, “¿este componente funciona con un lector de pantalla?”, “¿este componente tiene suficiente contraste de color?”, “verificar uso de ARIA en este LWC”, o “verificación de accesibilidad WCAG 2.2”. También ACTIVAR cuando el usuario quiera corregir o mejorar la accesibilidad (a11y, WCAG, ARIA) en el HTML, JS o CSS de un LWC — marcado semántico, foco, navegación con teclado, contraste, etiquetas para lectores de pantalla, criterios de cumplimiento WCAG 2.2 SC. Genera `a11y-review.md` con hallazgos citados de WCAG. NO ACTIVAR para generación general de LWC (usar `experience-lwc-generate`) o revisión visual/diseño SLDS que no se centre en accesibilidad (usar `design-systems-slds-validate`). Por favor, responde siempre en el idioma del usuario.
