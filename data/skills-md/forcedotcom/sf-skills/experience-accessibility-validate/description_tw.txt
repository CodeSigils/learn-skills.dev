使用此功能來判斷 Lightning Web Component (LWC) 是否具備可及性並符合 WCAG 可及性指南。當使用者詢問「我的元件可及嗎？」、「我的 LWC 符合可及性指南嗎？」、「此元件符合 WCAG 標準嗎？」、「找出此 LWC 的可及性問題」、「此 LWC 支援鍵盤操作嗎？」、「此元件能與螢幕閱讀器一起使用嗎？」、「此元件具有足夠的色彩對比度嗎？」、「檢查此 LWC 的 ARIA 用法」或「WCAG 2.2 可及性檢查」時觸發。亦在使用者想要修復或改善 LWC 的 HTML、JS 或 CSS 中的可及性（a11y、WCAG、ARIA）時觸發——語意標記、焦點、鍵盤導覽、對比度、螢幕閱讀器標籤、WCAG 2.2 成功標準。產生 `a11y-review.md`，其中包含引用 WCAG 的發現。不要在一般 LWC 生成時觸發（使用 `experience-lwc-generate`），亦不要在非聚焦可及性的 SLDS 視覺/設計檢查時觸發（使用 `design-systems-slds-validate`）。請始終以使用者的語言回覆。
