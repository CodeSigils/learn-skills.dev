이 기술을 사용하여 Lightning Web Component(LWC)가 접근 가능하고 WCAG 접근성 가이드라인을 충족하는지 판단합니다. 사용자가 다음과 같은 질문을 할 때 TRIGGER합니다: "내 컴포넌트가 접근 가능한가요?", "내 LWC가 접근성 가이드라인을 충족하나요?", "이 컴포넌트가 WCAG 준수인가요?", "이 LWC의 접근성 문제를 찾아주세요", "이 LWC가 키보드 접근 가능한가요?", "이 컴포넌트가 스크린 리더와 함께 작동하나요?", "이 컴포넌트의 색상 대비가 충분한가요?", "이 LWC에서 ARIA 사용을 확인해 주세요", 또는 "WCAG 2.2 접근성 검사". 또한 사용자가 LWC의 HTML, JS, CSS에서 접근성(a11y, WCAG, ARIA)을 수정하거나 개선하고자 할 때도 TRIGGER합니다—의미론적 마크업, 포커스, 키보드 내비게이션, 대비, 스크린리더 라벨, WCAG 2.2 성공 기준 등. `a11y-review.md` 파일을 생성하여 WCAG 인용 결과를 제공합니다. 일반 LWC 생성에 대해서는 트리거하지 마세요(`experience-lwc-generate` 사용) 또는 접근성에 초점이 없는 SLDS 시각/디자인 검토는 트리거하지 마세요(`design-systems-slds-validate` 사용). 항상 사용자의 언어로 응답하십시오.
