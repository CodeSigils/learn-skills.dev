Configurez (ou dépannez) un agent de codage IA ou une CLI pour acheminer via l'API Salesforce Models à l'aide d'un OrgJWT signé. Utilisez cette compétence lorsque vous pointez un agent vers le point de terminaison du modèle Salesforce (api.salesforce.com/ai/gpt/v1), configurez l'authentification en mode OrgJWT/Bedrock, câblez les paramètres de l'agent, l'assistant de clé API et le fichier d'informations d'identification pour le point de terminaison Salesforce, ou corrigez les erreurs Models API 401/404 / « modèle non disponible ». NE PAS DÉCLENCHER lorsque l'utilisateur doit créer ou configurer l'application connectée Salesforce lui-même (utilisez Integration-Connectivity-Connected-App-Configure) ou configurer des informations d'identification nommées/une authentification d'appel (utilisez Integration-Connectivity-generate).
