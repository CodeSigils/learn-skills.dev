Configure (o solucione problemas) un agente de codificación de IA o CLI para enrutar a través de la API de modelos de Salesforce utilizando un OrgJWT firmado. Utilice esta habilidad cuando dirija a un agente al punto final del modelo de Salesforce (api.salesforce.com/ai/gpt/v1), configure la autenticación en modo OrgJWT/Bedrock, conecte la configuración del agente, la ayuda de clave API y el archivo de credenciales para el punto final de Salesforce o corrija errores de Modelos API 401/404/"modelo no disponible". NO DISPARE cuando el usuario necesite crear o configurar la propia aplicación Salesforce Connected (use integración-conectividad-conectada-aplicación-configurar) o configurar credenciales con nombre/autenticación de llamadas (use integración-conectividad-generar).
