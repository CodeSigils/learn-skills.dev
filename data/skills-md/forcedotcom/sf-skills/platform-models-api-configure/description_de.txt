Konfigurieren (oder beheben) Sie einen AI-Codierungsagenten oder eine CLI, um mithilfe eines signierten OrgJWT über die Salesforce Models-API weiterzuleiten. Verwenden Sie diesen Skill, wenn Sie einen Agenten auf den Salesforce-Modellendpunkt (api.salesforce.com/ai/gpt/v1) verweisen, die OrgJWT-/Bedrock-Modus-Authentifizierung einrichten, die Einstellungen des Agenten, den API-Schlüsselhelfer und die Anmeldeinformationsdatei für den Salesforce-Endpunkt verknüpfen oder Models API 401/404/„Modell nicht verfügbar“-Fehler beheben. NICHT AUSLÖSEN, wenn der Benutzer die Salesforce Connected App selbst erstellen oder konfigurieren muss (integration-connectivity-connected-app-configure verwenden) oder benannte Anmeldeinformationen/Callout-Authentifizierung einrichten muss (integration-connectivity-generate verwenden).
