Интерактивный рабочий процесс для создания коммерческих магазинов B2B и получения метаданных витрины. Используйте, когда пользователи хотят: создавать магазины B2B Commerce, создавать витрины магазинов Commerce, настраивать магазины B2B из Vibes, получать метаданные Commerce, развертывать возможности Commerce, работать с DigitalExperienceBundle for Commerce.
