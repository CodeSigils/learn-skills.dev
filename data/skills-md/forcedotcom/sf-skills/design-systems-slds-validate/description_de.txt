Führt den SLDS-Linter aus, analysiert CSS auf die Verwendung und Paarung von Theming-Hooks, überprüft HTML auf Barrierefreiheitsattribute und bewertet die Ergebnisse kategorienübergreifend in einer Gesamtnote. Verwenden Sie diese Option, wenn Sie aufgefordert werden, „meine Komponente zu bewerten“, „SLDS-Scorecard“, „Qualitätsbericht“, „SLDS-Konformität prüfen“, „Wie gut ist mein SLDS“, „Komponentenqualität prüfen“, „meine Komponente bewerten“, „meine Komponente bewerten“, „Ist diese Komponente versandbereit?“, „meinen LWC auf Probleme prüfen“, „dies vor dem Senden prüfen“, „meine Komponente vor der Codeüberprüfung überprüfen“ oder immer dann, wenn ein Benutzer eine Qualitätsbewertung oder Produktionsbereitschaftsprüfung einer LWC- oder SLDS-Komponente wünscht.
