Utilizzare per abilitare Salesforce Change Data Capture (CDC) su un oggetto standard o personalizzato, configurare un canale di eventi personalizzato, impostare un'espressione di filtro o aggiungere campi di arricchimento. ATTIVA in generale su uno qualsiasi dei seguenti: "abilita CDC", "abilita Change Data Capture", "attiva CDC", "iscriviti a X per modificare eventi", "emetti eventi solo per", "filtra eventi di modifica", "arricchisci eventi di modifica", "crea un canale di eventi personalizzato"; o qualsiasi menzione di CDC, eventi di modifica, PlatformEventChannel, PlatformEventChannelMember, EnrichedField, canale ChangeEvents, campi di arricchimento, filtro eventi di modifica; o quando l'utente desidera che un sistema a valle riceva le modifiche ai dati Salesforce; o quando l'utente tocca i file .platformEventChannelMember-meta.xml / .platformEventChannel-meta.xml. SALTA durante la pubblicazione di eventi della piattaforma, API Pub/Sub o REST/SOAP (usa building-sf-integrations) o ManagedEventSubscription (fuori dall'ambito di CDC). Utilizza sempre questa competenza per i metadati di appartenenza al canale CDC.
