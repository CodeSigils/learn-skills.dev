Установите, настройте и устраните неполадки Salesforce Code Analyzer для любого проекта. Управляет установкой, проверкой предварительных требований, диагностикой сломанных настроек, созданием и редактированием переопределений code-analyzer.yml, настройками для конкретного механизма, шаблонами игнорирования, переопределением серьезности и настройкой конвейера CI/CD. ТРИГГЕР, когда: пользователь говорит «настроить анализатор кода», «настроить анализатор кода», «установить анализатор кода», «анализатор кода не работает», «исправить мои настройки», «сканирование не работает», «проверить мои настройки», «установлен ли анализатор кода», «включить/отключить механизм», «исключить файлы», «изменить серьезность», «настроить действия GitHub», «настроить CI/CD», «добавить анализатор кода в конвейер», «сделать конвейер сбоем», «обновить мой рабочий процесс», «контроль качества», «сбой при нарушениях», «сканировать только измененные файлы», «добавить SARIF», «code-analyzer.yml», «конфигурация ESLint», «увеличить память SFGE» или сообщить об ошибках при запуске анализатора кода. НЕ ЗАПУСКАТЬ, когда: пользователь хочет запустить сканирование (используйте dx-code-analyzer-run), исправить нарушения, объяснить правила, создать собственные правила или подавить нарушения.
