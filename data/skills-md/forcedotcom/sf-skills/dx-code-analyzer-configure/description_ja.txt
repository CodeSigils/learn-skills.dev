あらゆるプロジェクトの Salesforce Code Analyzer をセットアップ、構成、トラブルシューティングします。インストール、前提条件のチェック、壊れたセットアップの診断、code-analyzer.yml オーバーライドの作成と編集、エンジン固有の設定、無視パターン、重大度オーバーライド、および CI/CD パイプライン セットアップを処理します。トリガーのタイミング: ユーザーが「コード アナライザーをセットアップする」、「コード アナライザーを構成する」、「コード アナライザーをインストールする」、「コード アナライザーが機能しない」、「セットアップを修正する」、「スキャンが失敗する」、「セットアップを確認する」、「コード アナライザーがインストールされているか」、「エンジンを有効化/無効にする」、「ファイルを除外する」、「重大度を変更する」、「GitHub アクションをセットアップする」、「セットアップする」と発言した場合にトリガーされます。 CI/CD」、「コード アナライザーをパイプラインに追加」、「パイプラインを失敗させる」、「ワークフローを更新する」、「クオリティ ゲート」、「違反で失敗する」、「変更されたファイルのみをスキャンする」、「SARIF を追加する」、「code-analyzer.yml」、「ESLint 構成」、「SFGE メモリを増やす」、またはコード アナライザーの実行中にエラーが報告される。次の場合はトリガーしないでください: ユーザーがスキャンの実行 (dx-code-analyzer-run を使用)、違反の修正、ルールの説明、カスタム ルールの作成、または違反の抑制を希望している場合。
