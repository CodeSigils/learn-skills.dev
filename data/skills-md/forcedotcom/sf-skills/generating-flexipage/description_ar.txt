استخدم هذه المهارة عندما يحتاج المستخدمون إلى إنشاء صفحات Salesforce Lightning (FlexiPages) أو إنشائها أو تعديلها أو التحقق من صحتها. يتم تشغيله عندما يذكر المستخدمون RecordPage، أو AppPage، أو HomePage، أو Lightning pages، أو تخطيطات الصفحة، أو إضافة مكونات إلى الصفحات، أو تخصيص الصفحة. يُستخدم أيضًا عندما يقول المستخدمون أشياء مثل "إنشاء صفحة Lightning"، أو "إضافة مكون إلى صفحة"، أو "تخصيص صفحة السجل"، أو "إنشاء صفحة FlexiPage"، أو عندما يعملون مع ملفات FlexiPage XML ويحتاجون إلى مساعدة بشأن المكونات أو المناطق أو أخطاء النشر. استخدم دائمًا هذه المهارة في أي عمل متعلق بـ FlexiPage، حتى لو ذكروا "صفحة" فقط في سياق Salesforce.
