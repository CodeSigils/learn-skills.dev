Esecuzione di test Apex, analisi di copertura e cicli di correzione dei test con punteggio di 120 punti. Da utilizzare quando l'utente deve eseguire test Apex, verificare la copertura del codice, correggere test non riusciti o lavorare con file *Test.cls/*_Test.cls. SI ATTIVA quando: l'utente esegue test Apex, controlla la copertura del codice, corregge test non riusciti o tocca i file *Test.cls / *_Test.cls. NON SI ATTIVA durante: la scrittura del codice di produzione Apex (utilizzare generation-apex), il test dell'agente Agentforce (utilizzare testing-agentforce) o i test Jest/LWC (utilizzare generation-lwc-components).
