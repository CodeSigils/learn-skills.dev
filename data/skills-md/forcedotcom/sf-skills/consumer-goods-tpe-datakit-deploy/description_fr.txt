Déployez les composants du kit de données TPM Accruals spécifiquement requis pour les tableaux de bord Trade Promotion Effectiveness (TPE). À utiliser lorsqu'un client ou un administrateur souhaite installer ou déployer le kit de données TPM pour les tableaux de bord TPE, ou en tant qu'étape déléguée depuis consumer-goods-tpe-dashboard-configure. N'utilisez pas cette compétence si le client souhaite déployer le kit de données TPM Accruals pour la fonctionnalité Accruals.
