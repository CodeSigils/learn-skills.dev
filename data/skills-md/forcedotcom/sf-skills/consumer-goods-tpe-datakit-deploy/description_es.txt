Implemente los componentes del kit de datos de acumulación de TPM que se requieren específicamente para los paneles de control de eficacia de la promoción comercial (TPE). Úselo cuando un cliente o administrador desee instalar o implementar el kit de datos de TPM para paneles de TPE, o como un paso delegado desde consumer-goods-tpe-dashboard-configure. No utilice esta habilidad si el cliente desea implementar el kit de datos de acumulaciones de TPM para la función de acumulaciones.
