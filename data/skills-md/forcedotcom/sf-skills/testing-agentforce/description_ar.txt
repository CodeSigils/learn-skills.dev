كتابة وتشغيل وتحليل مجموعات الاختبار المنظمة لوكلاء Agentforce. يتم تشغيله عندما: يكتب المستخدم أو يعدل مواصفات الاختبار YAML (AiEvaluationDefinition)؛ تشغيل أوامر إنشاء اختبار وكيل sf، أو تشغيله، أو تقييم تشغيله، أو النتائج؛ يسأل عن استراتيجية تغطية الاختبار، أو اختيار المقاييس، أو التقييمات المخصصة؛ يفسر نتائج الاختبار أو يشخص فشل الاختبار؛ يسأل عن اختبار الدفعات، أو مجموعات الانحدار، أو تكامل اختبار CI/CD. لا تقم بالتشغيل عندما: يقوم المستخدم بإنشاء ملفات .agent أو تعديلها أو معاينتها أو تصحيح أخطائها (استخدم programming-agentforce)؛ ينشر أو ينشر الوكلاء؛ يكتب رمز البرنامج النصي للوكيل؛ يستخدم معاينة وكيل SF لتكرار التطوير؛ يحلل آثار جلسة الإنتاج (استخدم Observing-agentforce).
