Écrivez, exécutez et analysez des suites de tests structurés pour les agents Agentforce. DÉCLENCHEMENT lorsque : l'utilisateur écrit ou modifie la spécification de test YAML (AiEvaluationDefinition) ; exécute les commandes sf agent test create, run, run-eval ou results ; des questions sur la stratégie de couverture des tests, la sélection de métriques ou les évaluations personnalisées ; interprète les résultats des tests ou diagnostique les échecs des tests ; pose des questions sur les tests par lots, les suites de régression ou l'intégration de tests CI/CD. NE PAS DÉCLENCHER lorsque : l'utilisateur crée, modifie, prévisualise ou débogue des fichiers .agent (utilisez development-agentforce) ; deploys or publishes agents; writes Agent Script code; uses sf agent preview for development iteration; analyse les traces de session de production (utilisez observer-agentforce).
