Orquestador de productos Salesforce Data Cloud para flujos de trabajo conectar→preparar→armonizar→segmentar→actuar. Utilice esta habilidad cuando el usuario necesite una canalización de nube de datos de varios pasos, solución de problemas entre fases o administración de espacio de datos y kit de datos. DISPARAR cuando: el usuario necesita una canalización de Data Cloud de varios pasos, solicita configurar o solucionar problemas de Data Cloud en todas las fases, administra espacios de datos o kits de datos, o desea un flujo de trabajo sf data360 de fases cruzadas. NO DISPARAR cuando: el trabajo está aislado en una sola fase (use la habilidad específica de la fase coincidente), la tarea es STDM/rastreo de sesiones/telemetría de parquet (use agentforce-observe), CRM SOQL estándar (use plataforma-soql-query) o implementación de Apex (use plataforma-apex-generate).
