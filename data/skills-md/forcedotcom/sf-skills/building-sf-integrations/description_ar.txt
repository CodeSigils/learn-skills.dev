بنية تكامل Salesforce والسباكة في وقت التشغيل مع تسجيل 120 نقطة. استخدم هذه المهارة لإعداد بيانات الاعتماد المسماة، وبيانات الاعتماد الخارجية، والخدمات الخارجية، وأنماط استدعاء REST/SOAP، وأحداث النظام الأساسي، وتغيير التقاط البيانات. يتم تشغيله عندما: يقوم المستخدم بإعداد بيانات الاعتماد المسماة، أو الخدمات الخارجية، أو وسائل شرح REST/SOAP، أو أحداث النظام الأساسي، أو CDC، أو يلمس ملفات .namedCredential-meta.xml. لا تقم بالتشغيل عند: تكوين التطبيق المتصل/OAuth (استخدم تكوين التطبيقات المتصلة)، أو منطق Apex فقط (استخدم إنشاء القمة)، أو استيراد/تصدير البيانات (استخدم معالجة بيانات sf).
