Architettura di integrazione di Salesforce e funzionalità di runtime con punteggio di 120 punti. Utilizza questa competenza per impostare credenziali denominate, credenziali esterne, servizi esterni, modelli di callout REST/SOAP, eventi della piattaforma e Change Data Capture. SI ATTIVA quando: l'utente configura credenziali denominate, servizi esterni, chiamate REST/SOAP, eventi piattaforma, CDC o tocca file .namedCredential-meta.xml. NON SI ATTIVA quando: configurazione app connessa/OAuth (usa configurazione-app-connesse), logica solo Apex (usa generazione-apex) o importazione/esportazione dati (usa gestione-sf-data).
