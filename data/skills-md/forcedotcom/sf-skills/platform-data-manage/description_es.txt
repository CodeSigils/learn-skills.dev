Operaciones de datos de Salesforce con puntuación de 130 puntos. Utilice esta habilidad para crear, actualizar, eliminar, importar/exportar de forma masiva, generar datos de prueba y limpiar registros de organización mediante sf CLI y Apex anónimo. DISPARAR cuando: el usuario crea datos de prueba, realiza importación/exportación masiva, usa comandos CLI de datos sf, necesita patrones de fábrica de datos para pruebas de Apex o necesita inicializar/limpiar registros en una organización de Salesforce. NO DISPARAR cuando: Escritura de consultas SOQL únicamente (use platform-soql-query), ejecución de pruebas de Apex (use platform-apex-test-run) o implementación de metadatos (use platform-metadata-deploy).
