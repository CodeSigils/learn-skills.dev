Операции с данными Salesforce с оценкой 130 баллов. Используйте этот навык для создания, обновления, удаления, массового импорта/экспорта, создания тестовых данных и очистки записей организации с помощью sf CLI и анонимного Apex. ТРИГГЕР, когда: пользователь создает тестовые данные, выполняет массовый импорт/экспорт, использует команды CLI для данных sf, нуждается в шаблонах фабрики данных для тестов Apex или нуждается в заполнении/очистке записей в организации Salesforce. НЕ ЗАПУСКАЙТЕ, когда: только запись запроса SOQL (используйте Platform-soql-query), выполнение теста Apex (используйте Platform-apex-test-run) или развертывание метаданных (используйте Platform-Metadata-Deploy).
