Utilice esta habilidad para crear y activar un tipo de territorio, un modelo de territorio y territorios para la nube de ciencias biológicas. Se activa cuando el usuario dice "configurar territorios", "crear modelo de territorio", "configurar jerarquía de territorios para Life Sciences", "configurar territorios para LSC" o "crear territorios para Life Sciences Cloud". Crea un tipo de territorio geográfico, un modelo de territorio LSC y una jerarquía de territorio de 3 niveles (Región, Distrito, Territorio). Confirma los nombres con el usuario, muestra una vista previa y luego implementa y activa el modelo. NO ACTIVAR cuando: el usuario quiera validar los requisitos previos, asignar usuarios a territorios, crear reglas de asignación de territorios o ejecutar la configuración/orquestación completa de extremo a extremo de Life Sciences Cloud (ese es el trabajo del orquestador de "coordinación-rep-de-campo-de-ciencias biológicas": esta habilidad se ejecuta solo como una configuración de territorio independiente).
