Configurare l'autenticazione a più fattori (MFA) per gli utenti del sito Salesforce Experience. ATTIVA quando: l'utente desidera abilitare MFA su una comunità, applicare l'autenticazione a due fattori per gli utenti del portale, aggiungere MFA a un sito/app Web React Experience, configurare l'autorizzazione ForceTwoFactor, creare set di autorizzazioni MFA per utenti esterni o risolvere i problemi di MFA che non viene visualizzato all'accesso. Si attiva anche su: community MFA, portale a due fattori, set di autorizzazioni ForceTwoFactor, MFA Experience Cloud, sito MFA React, community di verifica dell'identità, sito di esperienza MFA, ForceTwoFactor Permissionset-meta.xml, MFA Permissionset-meta.xml. NON SI ATTIVA quando: si configura MFA a livello di organizzazione per utenti interni (ovvero Configurazione > Verifica identità), si creano componenti dell'interfaccia utente di accesso personalizzati (utilizzare experience-ui-bundle-frontend-generate) o si generano set di autorizzazioni generici senza contesto MFA (utilizzare platform-permission-set-generate).
