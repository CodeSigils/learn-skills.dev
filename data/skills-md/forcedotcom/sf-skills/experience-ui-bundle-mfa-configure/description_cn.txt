为 Salesforce Experience Site 用户配置多重身份验证 (MFA)。在以下情况下触发：用户想要在社区上启用 MFA、对门户用户强制执行双因素身份验证、将 MFA 添加到 React 体验站点/Web 应用程序、配置 ForceTwoFactor 权限、为外部用户创建 MFA 权限集，或者对登录时未出现的 MFA 进行故障排除。还会触发：MFA 社区、双因素门户、ForceTwoFactor 权限集、MFA Experience Cloud、MFA React 站点、身份验证社区、MFA 体验站点、ForceTwoFactor 权限集-meta.xml、MFA 权限集-meta.xml。不要在以下情况下触发：为内部用户配置组织范围的 MFA（即设置 > 身份验证）、构建自定义登录 UI 组件（使用 experience-ui-bundle-frontend-generate）或在没有 MFA 上下文的情况下生成通用权限集（使用 platform-permission-set-generate）。
