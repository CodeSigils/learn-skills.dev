為 Salesforce Experience Site 使用者配置多重身份驗證 (MFA)。在以下情況下觸發：使用者想要在社群上啟用 MFA、對入口​​網站使用者強制執行雙重認證、將 MFA 新增至 React 體驗網站/Web 應用程式、設定 ForceTwoFactor 權限、為外部使用者建立 MFA 權限集，或對登入時未出現的 MFA 進行故障排除。也會觸發：MFA 社群、雙因素入口網站、ForceTwoFactor 權限集、MFA Experience Cloud、MFA React 網站、驗證社群、MFA 體驗網站、ForceTwoFactor 權限集-meta.xml、MFA 權限集-meta.xml。請勿在下列情況下觸發：為內部使用者配置組織範圍的 MFA（即設定 > 驗證）、建立自訂登入 UI 元件（使用 experience-ui-bundle-frontend-generate）或在沒有 MFA 上下文的情況下產生通用權限集（使用 platform-permission-set-generate）。
