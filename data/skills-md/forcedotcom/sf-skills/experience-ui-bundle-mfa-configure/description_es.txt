Configure la autenticación multifactor (MFA) para los usuarios del sitio de Salesforce Experience. DISPARAR cuando: el usuario desea habilitar MFA en una comunidad, aplicar la autenticación de dos factores para los usuarios del portal, agregar MFA a un sitio/aplicación web de React Experience, configurar el permiso ForceTwoFactor, crear conjuntos de permisos de MFA para usuarios externos o solucionar problemas de MFA que no aparecen al iniciar sesión. También se activa en: comunidad MFA, portal de dos factores, conjunto de permisos ForceTwoFactor, MFA Experience Cloud, sitio MFA React, comunidad de verificación de identidad, sitio de experiencia MFA, conjunto de permisos ForceTwoFactor-meta.xml, conjunto de permisos-meta.xml de MFA. NO DISPARE cuando: configure MFA en toda la organización para usuarios internos (es decir, Configuración > Verificación de identidad), cree componentes de interfaz de usuario de inicio de sesión personalizados (use experiencia-ui-bundle-frontend-generate) o genere conjuntos de permisos genéricos sin contexto de MFA (use plataforma-permiso-conjunto-generar).
