Fase de Armonización de Salesforce Data Cloud. Utilice esta habilidad cuando el usuario trabaje con DMO, asignaciones, relaciones, resolución de identidad, perfiles unificados, gráficos de datos o ID universales. DISPARAR cuando: el usuario trabaja con DMO, mapeos, relaciones, resolución de identidad, perfiles unificados, gráficos de datos o ID universales. NO DISPARAR cuando: la tarea se refiere solo a secuencias/DLO (use data360-prepare), segmentos/insights (use data360-segment), recuperación/búsqueda (use data360-query) o STDM/rastreo de sesiones (use agentforce-observe).
