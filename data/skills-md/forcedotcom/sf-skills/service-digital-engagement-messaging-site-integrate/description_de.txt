Integriert ein eingebettetes Messaging-Chat-Widget für Messaging für In-App und Web (MIAW) in eine Experience Cloud-Site, indem das LWR- oder Aura-Seitenpaket der Site gepatcht, der Gastzugriff bereitgestellt, veröffentlicht und überprüft wird. Verwenden Sie diese Option, wenn der Benutzer Nachrichten auf einer Experience-Site einbetten, ein Chat-Widget zu einer Community hinzufügen, die Komponente „Embedded Messaging“ auf einer LWR- oder Aura-Seite platzieren, eine eingebettete Dienstbereitstellung mit einer Site verbinden, auf die abgerufenen Bundle-Artefakte („content.json“, „homeGuestLayout.json“ oder eine „*.site-meta.xml“-Datei) verweisen oder den Abruf-/Patch-JSON-/Bereitstellungs-/Veröffentlichungsfluss automatisieren möchte, anstatt durch Experience zu klicken Baumeister. NICHT AUSLÖSEN, wenn Sie den Messaging-Kanal erstellen (verwenden Sie service-digital-engagement-channel-configure), wenn Sie die EmbeddedServiceConfig-Bereitstellung erstellen oder aktualisieren (verwenden Sie service-digital-engagement-deployment-configure) oder wenn Sie ein eigenständiges JavaScript-Snippet für eine Nicht-Experience-Website generieren.
