قم بتوفير وتمكين مستخدم ترخيص الموظف الموحد (UEL) في Salesforce مع سلسلة الكيانات الكاملة - المستخدم، وحساب الشخص، وPersonContact، وEmployee2 - من خلال خادم MCP 360 بدون رأس الذي تستضيفه Salesforce. يُستخدم عندما يطلب المستخدم إنشاء مستخدم UEL، أو إعداد حساب مستخدم موحد للموظف، أو تمكين موظف بموجب ترخيص الموظف الموحد، أو تزويد الموظف بحساب الشخص وسجل الموظف 2، أو إدراج موظف جديد في ملف تعريف الموظف الموحد. المشغلات: إنشاء مستخدم UEL، وإعداد موظف موحد، وتوفير موظف موحد، وتمكين موظف UEL، ومستخدم موظف على متن الطائرة، وإنشاء حساب شخص للموظف. لا تقم بالتشغيل عندما: يطلب المستخدم إنشاء مستخدم قياسي بدون UEL، أو استنساخ مستخدم حالي، أو إدارة أذونات المستخدم الحالية فقط، أو تعيين أذونات الحادث فقط، أو إعادة تعيين كلمات المرور فقط، أو البحث عن المستخدمين الحاليين دون نية الإنشاء.
