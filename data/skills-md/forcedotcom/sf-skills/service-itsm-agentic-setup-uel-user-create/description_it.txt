Fornire e abilitare un utente Unified Employee License (UEL) in Salesforce con l'intera catena di entità (Utente, Account personale, PersonContact e Employee2) tramite il server MCP headless-360 ospitato da Salesforce. Da utilizzare quando l'utente chiede di creare un utente UEL, impostare un account utente Unified Employee, abilitare un dipendente con la licenza Unified Employee, fornire a un dipendente l'account personale e il record Employee2 o inserire un nuovo dipendente nel profilo Unified Employee. Si attiva su: creazione utente UEL, impostazione dipendente unificato, fornitura dipendente unificato, abilitazione dipendente UEL, onboarding utente dipendente, creazione di un account personale per dipendente. NON SI ATTIVA quando: l'utente chiede di creare un utente standard senza UEL, clonare un utente esistente, gestire solo le autorizzazioni utente esistenti, assegnare solo autorizzazioni incidente, reimpostare solo password o cercare utenti esistenti senza intento di creazione.
