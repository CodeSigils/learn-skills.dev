Aprovisione y habilite un usuario de Licencia de empleado unificada (UEL) en Salesforce con la cadena de entidad completa (Usuario, Cuenta personal, Contacto personal y Empleado2) a través del servidor MCP headless-360 alojado en Salesforce. Úselo cuando el usuario solicite crear un usuario de UEL, configurar una cuenta de usuario de Empleado unificado, habilitar a un empleado bajo la licencia de Empleado unificado, proporcionarle a un empleado una Cuenta personal y un registro de Empleado2, o incorporar a un nuevo empleado al perfil de Empleado unificado. Activadores: crear usuario de UEL, configurar empleado unificado, aprovisionar empleado unificado, habilitar empleado de UEL, incorporar usuario de empleado, crear cuenta personal para empleado. NO ACTIVAR cuando: el usuario solicita crear un usuario estándar sin UEL, clonar un usuario existente, administrar solo permisos de usuarios existentes, asignar permisos de incidentes únicamente, restablecer contraseñas únicamente o buscar usuarios existentes sin intención de creación.
