Предоставьте и включите пользователя Единой лицензии сотрудника (UEL) в Salesforce с полной цепочкой сущностей — Пользователь, Лицевая учетная запись, PersonContact и Сотрудник2 — через сервер MCP headless-360, размещенный в Salesforce. Используйте, когда пользователь запрашивает создать пользователя UEL, настроить учетную запись пользователя Unified Employer, включить сотрудника в соответствии с лицензией Unified Employer, предоставить сотруднику учетную запись Person Account и сотрудника 2 или добавить нового сотрудника в профиль Unified Employer. Запускается при: создании пользователя UEL, настройке единого сотрудника, предоставлении единого сотрудника, включении сотрудника UEL, регистрации пользователя сотрудника, создании личной учетной записи для сотрудника. НЕ АКТИВИРУЙТЕСЬ, когда: пользователь запрашивает создать стандартного пользователя без UEL, клонировать существующего пользователя, управлять только разрешениями существующих пользователей, назначать только разрешения инцидентов, только сбрасывать пароли или искать существующих пользователей без намерения создания.
