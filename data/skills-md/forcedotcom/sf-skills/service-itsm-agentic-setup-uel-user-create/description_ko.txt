Salesforce에서 호스팅되는 headless-360 MCP 서버를 통해 전체 엔터티 체인(사용자, 개인 계정, PersonContact 및 Employee2)을 사용하여 Salesforce에서 UEL(Unified Employee License) 사용자를 프로비저닝하고 활성화합니다. 사용자가 UEL 사용자 생성, 통합 직원 사용자 계정 설정, 통합 직원 라이선스에 따라 직원 활성화, 개인 계정 및 직원2 레코드로 직원 프로비저닝, 통합 직원 프로필에 새 직원 온보딩 등을 요청할 때 사용합니다. 트리거 조건: UEL 사용자 생성, 통합 직원 설정, 통합 직원 프로비저닝, UEL 직원 활성화, 직원 사용자 온보딩, 직원용 개인 계정 생성. 다음의 경우에는 트리거하지 마십시오: 사용자가 UEL 없이 표준 사용자 생성, 기존 사용자 복제, 기존 사용자 권한만 관리, 인시던트 권한만 할당, 비밀번호만 재설정 또는 생성 의도 없이 기존 사용자 조회를 요청합니다.
