Utilisez cette compétence lorsque les utilisateurs doivent créer, générer ou valider des métadonnées de paramètres personnalisés Salesforce. Déclenchez lorsque les utilisateurs mentionnent des paramètres personnalisés (hiérarchie ou liste), customSettingsType, SetupOwnerId, des remplacements de configuration par profil/par utilisateur, des indicateurs de fonctionnalité, des bascules de fonctionnalités, des kill switchs ou des commutateurs marche/arrêt que les administrateurs actionnent pour activer/désactiver le comportement, par exemple. contourner les déclencheurs/automatisations lors d’un chargement de données. Utilisez également pour « créer un paramètre personnalisé » ou des erreurs telles que « Impossible de spécifier : pluralLabel pour CustomSettings » ou un paramètre déployé silencieusement en tant qu'objet personnalisé standard. Un contournement de déclencheur ou un kill switch n'est qu'une case à cocher sur un paramètre personnalisé de hiérarchie : générez UNIQUEMENT le paramètre, jamais un déclencheur/gestionnaire Apex. NE PAS DÉCLENCHER pour les types de métadonnées personnalisées ou les objets __mdt — acheminez vers platform-custom-metadata-type-generate ; pour les objets d'enregistrement commercial : utilisez platform-custom-object-generate ; pour les secrets, les clés API, les mots de passe ou les jetons – recommandez un identifiant nommé, jamais généré ici.
