Utilice esta habilidad cuando los usuarios necesiten crear, generar o validar metadatos de configuración personalizada de Salesforce. Se activa cuando los usuarios mencionan configuraciones personalizadas (jerarquía o lista), customSettingsType, SetupOwnerId, anulaciones de configuración por perfil/por usuario, indicadores de funciones, alternancias de funciones, interruptores de apagado o interruptores de encendido/apagado que los administradores activan para habilitar/deshabilitar el comportamiento, p. omitir activadores/automatización durante una carga de datos. Úselo también para "crear una configuración personalizada" o errores como "No se puede especificar: pluralLabel para CustomSettings" o una configuración que se implementó silenciosamente como un objeto personalizado normal. Un interruptor de desconexión o desconexión del disparador es solo una casilla de verificación en una configuración personalizada de jerarquía: genere SÓLO la configuración, nunca un disparador/controlador de Apex. NO DISPARAR para tipos de metadatos personalizados u objetos __mdt: ruta a plataforma-generación-de-tipo-de-metadatos personalizados; para objetos de registros comerciales: utilice plataforma-generación-de-objetos personalizados; para secretos, claves API, contraseñas o tokens: recomiende una credencial con nombre, que nunca se genera aquí.
