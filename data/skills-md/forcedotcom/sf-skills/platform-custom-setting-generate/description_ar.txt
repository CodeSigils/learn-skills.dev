استخدم هذه المهارة عندما يحتاج المستخدمون إلى إنشاء البيانات التعريفية لإعدادات Salesforce المخصصة أو إنشائها أو التحقق من صحتها. يتم تشغيله عندما يذكر المستخدمون الإعدادات المخصصة (التسلسل الهرمي أو القائمة)، أو customSettingsType، أو SetupOwnerId، أو تجاوزات التكوين لكل ملف تعريف/لكل مستخدم، أو علامات الميزات، أو تبديل الميزات، أو مفاتيح إيقاف التشغيل، أو مفاتيح التشغيل/الإيقاف التي يقلبها المسؤولون لتمكين/تعطيل السلوك، على سبيل المثال. تجاوز المشغلات/الأتمتة أثناء تحميل البيانات. استخدم أيضًا "لإنشاء إعداد مخصص" أو أخطاء مثل "لا يمكن تحديد: pluralLabel for CustomSettings" أو إعداد يتم نشره بصمت ككائن مخصص عادي. إن تجاوز الزناد أو مفتاح الإيقاف هو مجرد مربع اختيار في إعداد مخصص للتسلسل الهرمي - قم بإنشاء الإعداد فقط، وليس مشغل/معالج Apex أبدًا. لا تقم بتشغيل أنواع البيانات التعريفية المخصصة أو كائنات __mdt - قم بالتوجيه إلى إنشاء نوع بيانات التعريف المخصصة للنظام الأساسي؛ بالنسبة لكائنات سجل الأعمال - استخدم إنشاء كائن مخصص للنظام الأساسي؛ بالنسبة للأسرار، أو مفاتيح واجهة برمجة التطبيقات، أو كلمات المرور، أو الرموز المميزة - أوصي ببيانات الاعتماد المسماة، والتي لم يتم إنشاؤها هنا مطلقًا.
