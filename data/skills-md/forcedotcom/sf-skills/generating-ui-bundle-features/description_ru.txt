ДОЛЖЕН активироваться, когда проект содержит каталог uiBundles/*/src/ и пользователь хочет добавить аутентификацию или поиск в свое приложение. Используйте этот навык при добавлении аутентификации или поиска в приложение пакета пользовательского интерфейса. Охватывает только две функции: аутентификацию (вход в систему, выход из системы, защищенные маршруты, управление сеансами) и поиск (глобальный поиск по страницам и содержимому). Всегда используйте этот навык для этих двух функций вместо того, чтобы строить с нуля.
