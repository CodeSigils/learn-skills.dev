単一の Agentforce セッションのデータ クラウド 360 度ビュー。 DC Query REST API 経由で 24 の STDM + GenAI DMO 行を取得し、階層型セッション ツリー (インタラクション → ステップ → 生成 → GatewayRequest) を組み立て、トランスクリプト + ターンごとのトピック/アクション呼び出し + LLM 生成 + ツール呼び出し + 監査チェーンを含む人間が判読可能な概要をレンダリングします。ユーザーがセッション ID (エージェント セッション UUID `019d…` または MessagingSession ID `0Mw…`) による特定の Agentforce セッションのトレース、検査、要約、または説明を要求したときにトリガーされます。また、ユーザーがまだセッション ID を持っていない場合、セッション検出 (時間、エージェント、チャネル、結果、または会話テキストによるセッションの検索/リスト/検索) でもトリガーされます。設計時のアーキテクチャに関する質問 (代わりに、調査エージェントフォース アーキテクチャを使用してください) や、データ クラウドを超えたプラットフォーム テレメトリを必要とする実行時のパフォーマンス/遅延/SLO の質問についてはトリガーしないでください。
