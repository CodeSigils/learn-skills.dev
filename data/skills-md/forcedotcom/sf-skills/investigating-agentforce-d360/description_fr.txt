Vue Data Cloud à 360° d'une seule session Agentforce. Extrait 24 lignes STDM + GenAI DMO via l'API REST DC Query, assemble une arborescence de session hiérarchique (Interaction → Étape → Génération → GatewayRequest), restitue un résumé lisible par l'homme avec transcription + invocations de sujet/action par tour + générations LLM + appels d'outils + chaîne d'audit. DÉCLENCHEMENT lorsque l'utilisateur demande de tracer, d'inspecter, de résumer ou de décrire une session Agentforce spécifique par ID de session (UUID de session d'agent `019d…` ou ID de session de messagerie `0Mw…`). Se déclenche également lors de la découverte de session (recherche/liste/recherche de sessions par heure, agent, canal, résultat ou texte de conversation) lorsque l'utilisateur n'a pas encore d'identifiant de session. NE PAS DÉCLENCHER pour les questions d'architecture au moment de la conception (utilisez plutôt l'architecture d'investigation-agentforce-architecture) ou pour les questions de performances/latence/SLO d'exécution qui nécessitent une télémétrie de plate-forme au-delà de Data Cloud.
