Data Cloud 360°-Ansicht einer einzelnen Agentforce-Sitzung. Ruft 24 STDM + GenAI DMO-Zeilen über die DC Query REST API ab, stellt einen hierarchischen Sitzungsbaum zusammen (Interaktion → Schritt → Generierung → GatewayRequest), stellt eine für Menschen lesbare Zusammenfassung mit Transkript + Themen-/Aktionsaufrufen pro Runde + LLM-Generierungen + Toolaufrufen + Prüfkette dar. TRIGGER, wenn der Benutzer eine bestimmte Agentforce-Sitzung anhand der Sitzungs-ID verfolgen, untersuchen, zusammenfassen oder beschreiben möchte (Agent-Sitzungs-UUID „019d…“ oder MessagingSession-ID „0Mw…“). Wird auch bei der Sitzungserkennung ausgelöst – Sitzungen nach Zeit, Agent, Kanal, Ergebnis oder Konversationstext suchen/auflisten/suchen – wenn der Benutzer noch keine Sitzungs-ID hat. NICHT AUSLÖSEN für Fragen zur Design-Time-Architektur (verwenden Sie stattdessen investigating-agentforce-architecture) oder für Fragen zur Laufzeitleistung/Latenz/SLO, die Plattformtelemetrie über Data Cloud hinaus erfordern.
