单个 Agentforce 会话的数据云 360° 视图。通过 DC 查询 REST API 拉取 24 个 STDM + GenAI DMO 行，组装分层会话树（交互 → 步骤 → 生成 → GatewayRequest），通过脚本 + 每轮主题/操作调用 + LLM 生成 + 工具调用 + 审计链呈现人类可读的摘要。当用户要求通过会话 ID（代理会话 UUID“019d...”或 MessagingSession id“0Mw...”）跟踪、检查、总结或描述特定 Agentforce 会话时触发。当用户还没有会话 ID 时，还会触发会话发现 - 按时间、代理、频道、结果或对话文本查找/列出/搜索会话。不要触发设计时架构问题（改为使用调查-agentforce-架构）或需要数据云之外的平台遥测的运行时性能/延迟/SLO 问题。
