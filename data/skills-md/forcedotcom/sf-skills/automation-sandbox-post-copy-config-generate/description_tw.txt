從任何格式（PDF、xlsx、csv、JSON、docx、Markdown、純文字或端點表的螢幕截圖）的客戶 SOP 產生 Salesforce 沙箱複製後自動化工具使用的 JSON 設定檔。當使用者要求建立、建置、產生、產生或轉換複製後或刷新後自動化配置時使用 - 將沙箱刷新 SOP 轉換為包含 ConfigurationName、Label、Fields、IsActive 和 ExecutionOrder 的 OutboundMessages 和 RemoteSiteSettings 條目的 JSON 陣列。也會觸發「複製後配置」、「刷新後自動化 JSON」、「刷新後更新出站訊息 (OBM) 端點」、「將此 SOP 轉換為配置」、「遠端站點設定 JSON」、「刷新規劃器為 JSON」或「沙箱刷新配置」等短語。不要在以下情況下觸發：使用者想要將產生的配置部署到組織（使用平台元資料部署）或執行/運行複製後自動化工具。這是 Salesforce 沙箱複製後配置產生的唯一技能。
