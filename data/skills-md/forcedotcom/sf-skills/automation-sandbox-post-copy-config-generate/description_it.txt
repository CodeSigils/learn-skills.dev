Genera il file di configurazione JSON utilizzato dallo strumento di automazione post-copia sandbox di Salesforce, da una SOP del cliente in qualsiasi formato (PDF, xlsx, csv, JSON, docx, Markdown, testo semplice o uno screenshot di una tabella endpoint). Da utilizzare quando l'utente chiede di creare, compilare, generare, produrre o convertire una configurazione di automazione post-copia o post-aggiornamento, trasformando una SOP di aggiornamento sandbox in un array JSON di voci OutboundMessages e RemoteSiteSettings con ConfigurationName, Label, Fields, IsActive e ExecutionOrder. Attiva anche frasi come "configurazione post-copia", "JSON di automazione post-aggiornamento", "aggiorna gli endpoint dei messaggi in uscita (OBM) dopo l'aggiornamento", "converti questo SOP in configurazione", "impostazioni del sito remoto JSON", "aggiorna il pianificatore in JSON" o "aggiornamento configurazione sandbox". NON ATTIVARE quando: l'utente desidera distribuire la configurazione generata a un'organizzazione (utilizzare platform-metadata-deploy) o eseguire/eseguire lo strumento di automazione post-copia. Questa è l'unica competenza per la generazione della configurazione post-copia del sandbox Salesforce.
