Generieren Sie die JSON-Konfigurationsdatei, die das Post-Copy-Automatisierungstool der Salesforce-Sandbox verwendet, aus einer Kunden-SOP in einem beliebigen Format (PDF, XLSX, CSV, JSON, DocX, Markdown, einfacher Text oder ein Screenshot einer Endpunkttabelle). Wird verwendet, wenn der Benutzer eine Post-Copy- oder Post-Refresh-Automatisierungskonfiguration erstellen, erstellen, generieren, produzieren oder konvertieren möchte. Dadurch wird eine Sandbox-Refresh-SOP in ein JSON-Array von OutboundMessages- und RemoteSiteSettings-Einträgen mit ConfigurationName, Label, Fields, IsActive und ExecutionOrder umgewandelt. Triggern Sie auch für Formulierungen wie „Post-Copy-Konfiguration“, „Post-Refresh-Automatisierungs-JSON“, „Aktualisieren Sie die Endpunkte für ausgehende Nachrichten (OBM) nach der Aktualisierung“, „konvertieren Sie diese SOP in Konfiguration“, „Remote-Site-Einstellungen JSON“, „Aktualisierungsplaner in JSON“ oder „Sandbox-Aktualisierungskonfiguration“. NICHT AUSLÖSEN, wenn: Der Benutzer die generierte Konfiguration in einer Organisation bereitstellen möchte (verwenden Sie „platform-metadata-deploy“) oder das Post-Copy-Automatisierungstool ausführen/ausführen möchte. Dies ist die einzige Fähigkeit für die Post-Copy-Konfigurationsgenerierung in der Salesforce-Sandbox.
