Создайте файл конфигурации JSON, который будет использовать инструмент автоматизации посткопирования песочницы Salesforce, из СОП клиента в любом формате (PDF, xlsx, csv, JSON, docx, Markdown, обычный текст или снимок экрана таблицы конечных точек). Используйте, когда пользователь запрашивает создание, сборку, создание, создание или преобразование конфигурации автоматизации после копирования или обновления — преобразование SOP для обновления в песочнице в массив JSON записей OutboundMessages и RemoteSiteSettings с ConfigurationName, Label, Fields, IsActive и ExecutionOrder. Также триггер для таких фраз, как «конфигурация после копирования», «JSON автоматизации после обновления», «обновить конечные точки исходящих сообщений (OBM) после обновления», «преобразовать эту SOP в конфигурацию», «JSON настроек удаленного сайта», «обновить планировщик в JSON» или «обновить конфигурацию песочницы». НЕ ЗАПУСКАЙТЕ, когда: пользователь хочет развернуть сгенерированную конфигурацию в организации (используйте развертывание метаданных платформы) или выполнить/запустить инструмент автоматизации посткопирования. Это единственный навык для создания конфигурации песочницы Salesforce после копирования.
