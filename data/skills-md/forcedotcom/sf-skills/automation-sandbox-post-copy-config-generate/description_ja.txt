Salesforce サンドボックスのコピー後自動化ツールが使用する JSON 構成ファイルを、任意の形式 (PDF、xlsx、csv、JSON、docx、Markdown、プレーン テキスト、またはエンドポイント テーブルのスクリーンショット) の顧客 SOP から生成します。ユーザーがコピー後またはリフレッシュ後のオートメーション構成を作成、構築、生成、生成、または変換するように要求する場合に使用します。これにより、サンドボックスリフレッシュ SOP が、ConfigurationName、Label、Fields、IsActive、および ExecutionOrder を含む OutboundMessages および RemoteSiteSettings エントリの JSON 配列に変換されます。また、「コピー後の構成」、「更新後の自動化 JSON」、「更新後にアウトバウンド メッセージ (OBM) エンドポイントを更新する」、「この SOP を構成に変換する」、「リモート サイト設定 JSON」、「プランナーを JSON に更新する」、または「サンドボックスの更新構成」などのフレーズでもトリガーされます。次の場合はトリガーしないでください: ユーザーが、生成された構成を組織にデプロイする (platform-metadata-deploy を使用する) か、コピー後の自動化ツールを実行する必要がある場合。これは、Salesforce サンドボックスのコピー後の構成生成のための唯一のスキルです。
