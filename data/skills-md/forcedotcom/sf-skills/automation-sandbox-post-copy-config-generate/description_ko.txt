Salesforce 샌드박스 사후 복사 자동화 도구가 사용하는 JSON 구성 파일을 모든 형식(PDF, xlsx, csv, JSON, docx, Markdown, 일반 텍스트 또는 끝점 테이블의 스크린샷)으로 고객 SOP에서 생성합니다. 사용자가 복사 후 또는 새로 고침 후 자동화 구성을 생성, 빌드, 생성, 생성 또는 변환하도록 요청할 때 사용합니다. 즉, 샌드박스 새로 고침 SOP를 ConfigurationName, Label, Fields, IsActive 및 ExecutionOrder가 포함된 OutboundMessages 및 RemoteSiteSettings 항목의 JSON 배열로 전환합니다. 또한 "복사 후 구성", "새로 고침 후 자동화 JSON", "새로 고침 후 아웃바운드 메시지(OBM) 엔드포인트 업데이트", "이 SOP를 구성으로 변환", "원격 사이트 설정 JSON", "플래너를 JSON으로 새로 고침" 또는 "샌드박스 새로 고침 구성"과 같은 문구에 대해 트리거됩니다. 다음의 경우에는 트리거하지 마세요: 사용자가 생성된 구성을 조직에 배포하거나(플랫폼 메타데이터 배포 사용) 복사 후 자동화 도구를 실행/실행하려는 경우. 이는 Salesforce sandbox 사후 복사 구성 생성을 위한 유일한 기술입니다.
