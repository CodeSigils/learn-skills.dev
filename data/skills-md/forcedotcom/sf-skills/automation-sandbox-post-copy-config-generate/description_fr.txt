Générez le fichier de configuration JSON consommé par l'outil d'automatisation post-copie du bac à sable Salesforce, à partir d'une SOP client dans n'importe quel format (PDF, xlsx, csv, JSON, docx, Markdown, texte brut ou capture d'écran d'une table de points de terminaison). À utiliser lorsque l'utilisateur demande de créer, construire, générer, produire ou convertir une configuration d'automatisation post-copie ou post-actualisation — transformant une SOP d'actualisation sandbox en un tableau JSON d'entrées OutboundMessages et RemoteSiteSettings avec ConfigurationName, Label, Fields, IsActive et ExecutionOrder. Déclenchez également des expressions telles que « configuration post-copie », « automatisation post-actualisation JSON », « mettre à jour les points de terminaison des messages sortants (OBM) après l'actualisation », « convertir cette SOP en configuration », « paramètres du site distant JSON », « planificateur d'actualisation en JSON » ou « configuration d'actualisation du bac à sable ». NE PAS DÉCLENCHER lorsque : l'utilisateur souhaite déployer la configuration générée sur une organisation (utiliser platform-metadata-deploy) ou exécuter/exécuter l'outil d'automatisation post-copie. Il s’agit de la seule compétence pour la génération de configuration post-copie de sandbox Salesforce.
