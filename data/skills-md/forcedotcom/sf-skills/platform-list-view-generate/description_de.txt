Verwenden Sie diese Fähigkeit, wenn Benutzer Metadaten für die Salesforce-Listenansicht erstellen, generieren oder validieren müssen. Wird ausgelöst, wenn Benutzer Listenansichten, gefilterte Datensatzlisten, das Erstellen von Ansichten, das Einrichten von Datensatzspalten, das Filtern von Datensätzen nach Kriterien oder Fragen zur Sichtbarkeit von Listenansichten erwähnen. Verwenden Sie es auch, wenn Benutzer Dinge sagen wie „Ich benötige eine Ansicht, die … anzeigt“, „Datensätze filtern nach …“, „Eine Listenansicht erstellen für …“ oder wenn sie mit ListView-XML-Dateien arbeiten und eine Validierung oder Fehlerbehebung benötigen.
