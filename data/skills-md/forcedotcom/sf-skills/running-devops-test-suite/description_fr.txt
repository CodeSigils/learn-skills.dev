Déclenche l'exécution asynchrone d'une ou plusieurs suites de tests DevOps Center sur une étape du pipeline (événement de pré-promotion, de post-promotion ou de révision) via l'API Connect, après une porte de confirmation explicite de l'utilisateur, puis passe à l'interrogation des résultats via la compétence « polling-test-results ». Réexécute également (redéclenche) une porte de qualité après les correctifs, mais seulement une fois que la validation confirme que le seuil de couverture est désormais atteint. DÉCLENCHEMENT lorsque : l'utilisateur souhaite exécuter, lancer ou lancer des suites de tests sur une étape de pipeline ; exécuter des tests avant ou après une promotion ; déclencher une exécution d'événement de pré-promotion, de post-promotion ou de révision ; réexécutez une porte de qualité après avoir corrigé les échecs ; réessayez une porte défaillante une fois la couverture atteinte ; ou débloquer une promotion bloquée après avoir ajouté des tests. NE PAS DÉCLENCHER lorsque : vous exécutez directement le test d'exécution de sf apex (utilisez running-apex-tests) ; ou en configurant une NOUVELLE porte ou un NOUVEAU seuil (utilisez configuring-quality-gate).
