Löst die asynchrone Ausführung einer oder mehrerer DevOps Center-Testsuiten in einer Pipeline-Phase (Pre-Promote-, Post-Promote- oder Review-Ereignis) über die Connect-API aus, nach einem expliziten Benutzerbestätigungs-Gate, und übergibt dann an die Ergebnisabfrage über den Skill „polling-test-results“. Außerdem wird ein Qualitätstor nach Korrekturen erneut ausgeführt (ausgelöst), jedoch erst, wenn die Validierung bestätigt, dass der Abdeckungsschwellenwert nun erreicht ist. TRIGGER, wenn: der Benutzer Testsuiten in einer Pipeline-Phase ausführen, starten oder starten möchte; Durchführung von Tests vor oder nach einer Werbeaktion; einen Pre-Promote-, Post-Promote- oder Review-Event-Lauf auslösen; Führen Sie ein Qualitäts-Gate erneut durch, nachdem Fehler behoben wurden. Versuchen Sie es erneut mit einem fehlgeschlagenen Gate, sobald die Abdeckung erreicht ist. oder entsperren Sie eine blockierte Aktion, nachdem Sie Tests hinzugefügt haben. NICHT AUSLÖSEN, wenn: sf apex run test direkt ausgeführt wird (running-apex-tests verwenden); oder Konfigurieren eines NEUEN Gates oder Schwellenwerts (verwenden Sie „Configuring-Quality-Gate“).
