Attiva l'esecuzione asincrona di una o più suite di test DevOps Center in una fase della pipeline (evento di pre-promozione, post-promozione o revisione) tramite l'API Connect, dopo un cancello di conferma esplicito da parte dell'utente, quindi passa al polling dei risultati tramite la capacità "polling-test-results". Inoltre, esegue nuovamente (riattiva) un controllo di qualità dopo le correzioni, ma solo una volta che la convalida conferma che la soglia di copertura è stata raggiunta. TRIGGER quando: l'utente desidera eseguire, avviare o lanciare suite di test in una fase della pipeline; eseguire test prima o dopo una promozione; attivare un evento di pre-promozione, post-promozione o revisione; eseguire nuovamente un controllo qualità dopo aver corretto gli errori; riprovare un gate non riuscito una volta raggiunta la copertura; o sbloccare una promozione bloccata dopo aver aggiunto i test. NON SI ATTIVA quando: si esegue direttamente sf apex run test (usa running-apex-tests); o configurare un NUOVO cancello o soglia (usare configurazione-qualità-gate).
