명시적인 사용자 확인 게이트 이후에 Connect API를 통해 파이프라인 단계(사전 승격, 사후 승격 또는 검토 이벤트)에서 하나 이상의 DevOps Center 테스트 모음의 비동기 실행을 트리거한 다음 `polling-test-results` 기술을 통해 결과 폴링으로 전달합니다. 또한 수정 후 품질 게이트를 다시 실행(재트리거)합니다. 하지만 검증을 통해 적용 범위 임계값이 이제 충족되었음을 확인한 후에만 가능합니다. TRIGGER 언제: 사용자가 파이프라인 단계에서 테스트 스위트를 실행, 시작 또는 시작하려고 합니다. 프로모션 전후에 테스트를 실행합니다. 사전 승격, 사후 승격 또는 검토 이벤트 실행을 트리거합니다. 오류를 수정한 후 품질 게이트를 다시 실행합니다. 적용 범위가 충족되면 실패한 게이트를 다시 시도합니다. 또는 테스트를 추가한 후 차단된 프로모션을 차단 해제하세요. 다음과 같은 경우에는 트리거하지 마십시오: sf apex run test를 직접 실행(running-apex-tests 사용). 또는 새로운 게이트나 임계값을 구성합니다(구성 품질 게이트 사용).
