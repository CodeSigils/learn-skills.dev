在明确的用户确认门之后，通过 Connect API 在管道阶段（预升级、后升级或审核事件）触发一个或多个 DevOps Center 测试套件的异步执行，然后通过“轮询测试结果”技能进行结果轮询。修复后还会重新运行（重新触发）质量门 - 但只有在验证确认现在满足覆盖率阈值后才重新运行（重新触发）质量门。触发时间：用户想要在管道阶段运行、启动或启动测试套件；在晋升之前或之后执行测试；触发促销前、促销后或审核事件运行；修复故障后重新运行质量门；一旦满足覆盖范围，重试失败的门；或在添加测试后解锁被阻止的促销。不要在以下情况下触发：直接运行 sf apex run test（使用 running-apex-tests）；或配置新的门或阈值（使用配置质量门）。
