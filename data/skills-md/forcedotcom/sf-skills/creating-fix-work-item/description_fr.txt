Crée un élément de travail DevOps Center pour suivre un correctif en cas d'échec de test ou de violation de l'analyseur de code. Avant de créer quoi que ce soit, il affiche un aperçu du sujet/destinataire/projet et nécessite une confirmation explicite. Utilisez cette compétence lorsque vous souhaitez créer un élément de travail de correction, suivre une tâche de correction ou attribuer un échec de test ou d'analyse à un développeur. DÉCLENCHEMENT lorsque : l'utilisateur souhaite créer un élément de travail de correction, enregistrer une correction ou attribuer un échec à un développeur pour résolution. NE PAS DÉCLENCHER lorsque : vous écrivez le code correctif lui-même (utilisez generate-apex).
