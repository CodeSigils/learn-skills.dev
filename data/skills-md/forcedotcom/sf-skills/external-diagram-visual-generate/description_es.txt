Generación de imágenes impulsada por IA para elementos visuales de Salesforce a través de Nano Banana Pro. Utilice esta habilidad cuando el usuario necesite resultados PNG/SVG renderizados, como ERD (diagramas de relación de entidad) visuales, maquetas de interfaz de usuario, estructuras alámbricas o ilustraciones de arquitectura. DISPARAR cuando: el usuario solicita salida PNG/SVG, maquetas de UI, estructuras alámbricas, ERD visuales o dice "generar imagen"/"crear maqueta". NO ACTIVAR cuando: diagramas de sirena basados ​​en texto (use diagrama externo-generación de sirena) o tareas de documentación no visuales.
