يجب التنشيط لتوطين/تدويل مشروع uiBundles/*/src/ React: استخرج السلاسل المشفرة التي تواجه المستخدم في تسميات مخصصة، أو قم بتوصيل i18next عبر الواجهة الخلفية لـ Platform SDK GraphQL، أو أضف لغة إلى حزمة مترجمة، أو استكشاف أخطاء عرض الملصقات وإصلاحها عبر اللغات. المشغلات: سلسلة حرفية تواجه المستخدم في .tsx/.jsx، أو CustomLabels.labels-meta.xml، أو دليل src/i18n/ أو label-manifest.ts، أو مكالمات t(...)، أو طلبات "ترجمة / تعريب / تدويل / دعم لغة أخرى." النطاق: حزم واجهة المستخدم المصادق عليها فقط (التطبيقات المرتبطة بـ B2E CustomApplication، أو التطبيقات المرتبطة بالوصول إلى التحقق من الوصول إلى المركز). لا تقم بالتشغيل عندما: تكون الحزمة عبارة عن تطبيق موقع (B2C/B2B) مرتبط بـ DigitalExperienceConfig (تعريب الموقع غير مدعوم بعد)، أو إنشاء غلاف التطبيق/واجهة المستخدم أو التصميم، أو قراءة/كتابة/تحديث السجلات (استخدام experience-ui-bundle-salesforce-data-access)، أو إنشاء حزمة جديدة (استخدام experience-ui-bundle-frontend-generate)، أو النشر (استخدام experience-ui-bundle-deploy)، أو تأليف الترجمات في منضدة الترجمة.
