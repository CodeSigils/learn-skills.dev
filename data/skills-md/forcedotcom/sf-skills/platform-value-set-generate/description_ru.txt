Используйте этот навык, когда пользователям необходимо создать, сгенерировать или проверить глобальный набор значений Salesforce или настроить стандартный набор значений. Активируется, когда пользователи упоминают глобальный набор значений, GlobalValueSet, стандартный набор значений, StandardValueSet, многоразовый раскрывающийся список, набор значений раскрывающегося списка, общий для всех полей, или настройку стандартных раскрывающихся списков, таких как «Отрасль», «Источник потенциальных клиентов» или «Этап возможности». Также используйте, когда пользователи сталкиваются с ошибками развертывания, добавляя значения в стандартный раскрывающийся список, ссылаясь на набор значений из настраиваемого поля или работая с файлами .globalValueSet-meta.xml или .standardValueSet-meta.xml. НЕ ИСПОЛЬЗУЙТЕ для встроенного одноразового раскрывающегося списка для одного поля без повторного использования или для общей работы с метаданными настраиваемого поля, которая не включает GlobalValueSet или StandardValueSet — вместо этого используйте Platform-custom-field-generate.
