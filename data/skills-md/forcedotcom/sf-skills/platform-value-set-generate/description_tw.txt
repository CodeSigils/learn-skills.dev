当用户需要创建、生成或验证 Salesforce 全局值集或自定义标准值集时，请使用此技能。當使用者提及全域值集、GlobalValueSet、標準值集、StandardValueSet、可重複使用選項清單、跨欄位共享的選項清單值集或自訂標準選項清單（例如產業、潛在客戶來源或機會階段）時觸發。當使用者遇到部署錯誤將值新增至標準選項清單、引用自訂欄位中的值集或使用 .globalValueSet-meta.xml 或 .standardValueSet-meta.xml 檔案時，也可使用。不要觸發單一欄位上的內聯一次性選擇清單而不重用，或對於不涉及 GlobalValueSet 或 StandardValueSet 的一般自訂欄位元資料工作 - 請改用 platform-custom-field-generate。
