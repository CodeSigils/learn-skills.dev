Utilice esta habilidad cuando los usuarios necesiten crear, generar o validar un conjunto de valores globales de Salesforce o personalizar un conjunto de valores estándar. Se activa cuando los usuarios mencionan un conjunto de valores globales, GlobalValueSet, un conjunto de valores estándar, StandardValueSet, una lista de selección reutilizable, un conjunto de valores de lista de selección compartido entre campos o personalizan listas de selección estándar como Industria, Fuente de clientes potenciales o Etapa de oportunidad. Úselo también cuando los usuarios encuentren errores de implementación al agregar valores a una lista de selección estándar, hacer referencia a un conjunto de valores de un campo personalizado o trabajar con archivos .globalValueSet-meta.xml o .standardValueSet-meta.xml. NO DISPARE para una lista de selección única en línea en un solo campo sin reutilización, o para trabajo general de metadatos de campos personalizados que no involucre un GlobalValueSet o StandardValueSet; en su lugar, use platform-custom-field-generate.
