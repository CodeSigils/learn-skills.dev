استخدم هذه المهارة دائمًا لاسترداد البيانات التعريفية من مؤسسة إلى مشروعك المحلي باستخدام أمر استرداد مشروع sf. يدعم أوضاع استرجاع متعددة: استرداد جميع التغييرات عن بعد، أو الاسترداد عن طريق الدليل المصدر، أو الاسترداد عن طريق نوع بيانات التعريف باستخدام أحرف البدل، أو الاسترداد عن طريق البيان (package.xml)، أو الاسترداد عن طريق اسم الحزمة. يُستخدم عندما يطلب المستخدم استرداد البيانات التعريفية أو فئات Apex أو الكائنات المخصصة أو تغييرات المؤسسة أو سحبها أو مزامنتها أو تنزيلها. يدعم تنسيق المصدر (الافتراضي) أو تنسيق البيانات الوصفية (ZIP). لا تقم بتشغيل نشر البيانات التعريفية (استخدم مهارة نشر بيانات تعريف النظام الأساسي)، أو إدراج بيانات التعريف، أو إنشاء package.xml. لا تستخدم أبدًا أدوات MCP - استخدم دائمًا هذه المهارة وأداة Bash مع بدء استرداد مشروع sf.
