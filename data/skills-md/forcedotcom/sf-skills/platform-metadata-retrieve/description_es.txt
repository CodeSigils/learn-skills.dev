USE SIEMPRE ESTA HABILIDAD para recuperar metadatos de una organización a su proyecto local usando el comando sf project retrieve start. Admite múltiples modos de recuperación: recuperar todos los cambios remotos, recuperar por directorio de origen, recuperar por tipo de metadatos con comodines, recuperar por manifiesto (paquete.xml) o recuperar por nombre de paquete. Úselo cuando el usuario solicite recuperar, extraer, sincronizar o descargar metadatos, clases de Apex, objetos personalizados o cambios de organización. Admite formato de origen (predeterminado) o formato de metadatos (ZIP). NO DISPARE para implementar metadatos (use la habilidad de implementación de metadatos de plataforma), enumerar metadatos o generar paquete.xml. NUNCA use herramientas MCP; use siempre esta habilidad y la herramienta Bash con el inicio de recuperación del proyecto sf.
