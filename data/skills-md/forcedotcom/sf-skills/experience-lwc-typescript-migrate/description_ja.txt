既存の JavaScript Lightning Web コンポーネント (.js、.html、.css) を、完全な型アノテーションと、コンポーネントの `@api` サーフェスのみを公開する対応する `.d.ts` ファイルを備えた TypeScript に変換する場合に使用します。ユーザーが「LWC を TypeScript に変換する」、「LWC を TS に移行する」、「このコンポーネントの .js を .ts に名前変更する」、「LWC に型を追加する」、「この LWC の .d.ts を生成する」、「@api プロパティに型注釈を付ける」、または「モジュール 'c/componentName' 定義を生成する」と言ったときにトリガーされます。ユーザーが新しい LWC を最初から作成している場合 ( experience-lwc-generate を使用)、既存の LWC の Jest テストを生成している場合 ( experience-lwc-generate を使用)、または Aura コンポーネントを LWC に移行している場合は、トリガーしないでください。
