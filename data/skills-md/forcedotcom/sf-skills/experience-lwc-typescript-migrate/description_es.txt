Úselo al convertir un componente web Lightning de JavaScript existente (.js, .html, .css) a TypeScript con anotaciones de tipo completo y un archivo `.d.ts` coincidente que expone solo la superficie `@api` del componente. DISPARADOR cuando el usuario dice "convertir LWC a TypeScript", "migrar LWC a TS", "cambiar el nombre de .js a .ts para este componente", "agregar tipos a mi LWC", "generar .d.ts para este LWC", "escribir escribir propiedades @api" o "producir definiciones de módulo de declaración 'c/componentName'". NO DISPARE cuando el usuario esté creando un LWC nuevo desde cero (use experiencia-lwc-generate), generando pruebas Jest para un LWC existente (use experiencia-lwc-generate) o migrando un componente de Aura a LWC.
