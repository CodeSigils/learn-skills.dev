Используйте при преобразовании существующего веб-компонента Lightning JavaScript (.js, .html, .css) в TypeScript с полными аннотациями типов и соответствующим файлом `.d.ts`, который отображает только поверхность `@api` компонента. TRIGGER, когда пользователь говорит: «преобразовать LWC в TypeScript», «перенести LWC в TS», «переименовать .js в .ts для этого компонента», «добавить типы в мой LWC», «создать .d.ts для этого LWC», «типировать аннотации свойств @api» или «создать определения модуля 'c/comComponentName'». НЕ ЗАПУСКАЙТЕ, когда пользователь создает совершенно новый LWC с нуля (используйте experience-lwc-generate), создает Jest-тесты для существующего LWC (используйте experience-lwc-generate) или переносит компонент Aura в LWC.
