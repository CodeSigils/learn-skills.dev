يُستخدم عند تحويل مكون JavaScript Lightning Web Component الحالي (.js، .html، .css) إلى TypeScript مع التعليقات التوضيحية الكاملة للنوع وملف `.d.ts` المطابق الذي يعرض سطح `@api` الخاص بالمكون فقط. تشغيل عندما يقول المستخدم "تحويل LWC إلى TypeScript"، أو "ترحيل LWC إلى TS"، أو "إعادة تسمية .js إلى .ts لهذا المكون"، أو "إضافة أنواع إلى LWC الخاص بي"، أو "إنشاء .d.ts لـ LWC هذا"، أو "التعليق التوضيحي على خصائص @api"، أو "إنتاج تعريفات الوحدة النمطية 'c/componentName'". لا تقم بالتشغيل عندما يقوم المستخدم بتأليف LWC جديد تمامًا من البداية (استخدم experience-lwc-generate)، أو ينشئ اختبارات Jest لـ LWC موجود (استخدم experience-lwc-generate)، أو يرحل مكون Aura إلى LWC.
