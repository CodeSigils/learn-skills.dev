Utilice esta habilidad cuando los usuarios necesiten crear o configurar aplicaciones personalizadas de Salesforce. Se activa cuando los usuarios mencionan aplicaciones personalizadas, metadatos de aplicaciones, navegación de aplicaciones u organización de pestañas en aplicaciones. Úselo cuando los usuarios quieran crear contenedores de aplicaciones para pestañas y páginas. Utilice siempre esta habilidad para trabajos de aplicaciones personalizadas.
