Настройте контрольный список «Настройка ИТ-службы Salesforce» для Службы сотрудников Microsoft Teams (ITSM) — со стороны сотрудников, включая включение приложений, рекомендации по установке на рынке, назначение доступа пользователей и выбор сайта цифрового опыта. Используйте это для: «включить ИТ-службу Salesforce», «настроить ИТ-службу в Teams», «назначить набор разрешений Teams для сотрудников», «предоставить сотрудникам доступ к Teams для службы сотрудников», «управлять доступом пользователей для Teams ITSM», «предоставить пользователям наборы разрешений, необходимые для службы Teams для сотрудников», «выбрать сайт цифрового взаимодействия для Teams», «установить приложение ИТ-службы Salesforce в Teams» или для любого запроса на заполнение ИТ-службы половины контрольного списка страницы Teams ITSM Go. (включая шаг «Управление доступом пользователей»). НЕ АКТИВИРУЙТЕ для базового переключения страницы Teams Salesforce Go или настройки приложения Azure/Entra (service-itsm-teams-configure) или для половины контрольного списка для ИТ-отдела/исполнителя (service-itsm-teams-itdesk-configure).
