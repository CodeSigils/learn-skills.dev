Microsoft Teams ITSM 사용자 정의 클라이언트('Salesforce Employee Assist'/'Ask AI Agent') 내에서 응답하도록 포함된 Agentforce Employee 에이전트를 구성합니다. 'Teams에 직원 에이전트 설정', 'Teams에 Agentforce 에이전트 포함', 'Teams에서 IT 서비스 직원 에이전트 응답 만들기', 'Teams Ask AI 에이전트가 응답하지 않음', '에이전트 합류 후 응답 없이 떠남', 'Teams 직원 에이전트에 대한 MIAW 배포 구성', 'Teams 임베디드 메시징 에이전트 설정'에 사용하세요. 전체 스택을 헤드리스(설정 UI 클릭 없음)로 구축합니다. 사용자 확인이 ON인 웹 메시징 채널, 필요한 향상된 채팅 사용자 확인 키 세트(JWKS_URL), Teams_AgentForce 사용자 정의 클라이언트 배포, 에이전트에 대한 라우팅 흐름, 포털 사용자가 에이전트에 연결할 수 있도록 하는 에이전트 액세스 권한 집합. Teams 기능 Salesforce Go 페이지 토글(service-itsm-teams-configure)을 활성화하거나 알림 기본 설정을 구성하기 위해 트리거하지 마십시오.
