Настройте встроенный агент сотрудника Agentforce, чтобы он отвечал внутри пользовательского клиента Microsoft Teams ITSM («Помощь сотрудникам Salesforce» / «Спросить агента AI»). Используйте это для: «настроить агента сотрудника в Teams», «встроить агент Agentforce в Teams», «заставить агента сотрудника ИТ-службы ответить в Teams», «Команды запрашивают агента AI, который не отвечает», «агент присоединяется, а затем уходит без ответа», «настроить развертывание MIAW для агента сотрудника Teams», «Настройка встроенного агента обмена сообщениями Teams». Создает весь стек автоматически (нулевые щелчки по пользовательскому интерфейсу): канал веб-сообщений с включенной проверкой пользователя, требуемый набор ключей расширенной проверки пользователя чата (JWKS_URL), развертывание настраиваемого клиента Teams_AgentForce, поток маршрутизации к агенту и набор разрешений доступа агента, который позволяет пользователю портала связаться с агентом. НЕ ИНИЦИРУЙТЕ для включения функции Teams, переключателя страницы Salesforce Go (service-itsm-teams-configure) или для настройки предпочтений уведомлений.
