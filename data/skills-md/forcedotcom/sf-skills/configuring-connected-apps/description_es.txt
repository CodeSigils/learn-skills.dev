Configuración OAuth de aplicaciones conectadas de Salesforce y aplicaciones de cliente externo con puntuación de 120 puntos. Utilice esta habilidad para configurar flujos de OAuth, autenticación de portador JWT, aplicaciones conectadas y aplicaciones de cliente externo en Salesforce. SE DISPARA cuando: el usuario configura flujos de OAuth, autenticación de portador JWT, aplicaciones conectadas, ECA o toca archivos .connectedApp-meta.xml/.eca-meta.xml. NO DISPARE cuando: configure Credenciales con nombre para llamadas (use building-sf-integrations), revise políticas de permisos (use implementación de metadatos) o escriba código de manejo de tokens de Apex (use generate-apex).
