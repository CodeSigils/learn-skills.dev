Fase Salesforce Data Cloud Connect. Utilizza questa competenza quando l'utente gestisce connessioni e connettori Data Cloud o configura un nuovo sistema di origine. TRIGGER quando: l'utente gestisce connessioni Data Cloud, connettori, metadati del connettore, testa una connessione, esplora oggetti o database di origine o configura un nuovo sistema di origine. NON ATTIVARE quando: l'attività riguarda flussi di dati o DLO (utilizzare data360-prepare), DMO o risoluzione dell'identità (utilizzare data360-harmonize), recupero/ricerca (utilizzare data360-query) o telemetria STDM (utilizzare agentforce-observe).
