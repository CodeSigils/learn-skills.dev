DEBE UTILIZAR esta habilidad para CUALQUIER solicitud de sandbox, incluida simplemente la obtención de los detalles, el estado, el tipo de licencia o el estado de activación pendiente de un sandbox por nombre o ID. DISPARA cuando el usuario: escribe "sandbox -help"/"sandbox help"; menciona un ID de zona de pruebas (prefijo 07E); solicita enumerar o mostrar zonas de pruebas; solicita los detalles, el estado, el tipo de licencia o la configuración de un sandbox por nombre o ID; activa o descarta una actualización completa; elimina una zona de pruebas; verifica la activación o eliminación; crea o actualiza una zona de pruebas. NO DISPARAR cuando: el usuario quiera clonar un sandbox.
