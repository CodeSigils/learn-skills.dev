DOIT UTILISER cette compétence pour TOUTE demande de bac à sable, y compris simplement obtenir les détails, le statut, le type de licence ou l'état d'activation en attente d'un bac à sable par nom ou identifiant. DÉCLENCHEMENT lorsque l'utilisateur : tape "sandbox -help"/"sandbox help" ; mentionne un identifiant de bac à sable (préfixe 07E) ; demande de lister ou d'afficher les bacs à sable ; demande les détails, le statut, le type de licence ou la configuration d'un bac à sable par nom ou ID ; active ou rejette une actualisation terminée ; supprime un bac à sable ; vérifie l'activation ou la suppression ; crée ou actualise un bac à sable. NE PAS DÉCLENCHER lorsque : l'utilisateur souhaite cloner un bac à sable.
