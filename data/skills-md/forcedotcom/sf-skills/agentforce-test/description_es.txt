Escriba, ejecute y analice conjuntos de pruebas estructuradas para agentes de Agentforce. DISPARADOR cuando: el usuario escribe o modifica la especificación de prueba YAML (AiEvaluaciónDefinición); ejecuta los comandos sf agent test create, run, run-eval o results; pregunta sobre la estrategia de cobertura de pruebas, la selección de métricas o evaluaciones personalizadas; interpreta los resultados de las pruebas o diagnostica fallas en las pruebas; pregunta sobre pruebas por lotes, conjuntos de regresión o integración de pruebas de CI/CD. NO DISPARAR cuando: el usuario crea, modifica, obtiene una vista previa o depura archivos .agent (use agentforce-generate); implementa o publica agentes; escribe código de script de agente; utiliza la vista previa del agente sf para la iteración del desarrollo; analiza los seguimientos de las sesiones de producción (use agentforce-observe).
