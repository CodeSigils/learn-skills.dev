استخدم هذه المهارة عندما يحتاج المستخدمون إلى إنشاء البيانات التعريفية لنوع التقرير المخصص لـ Salesforce أو إنشائها أو التحقق من صحتها. يتم التشغيل عندما يذكر المستخدمون أنواع التقارير المخصصة، أو أنواع التقارير، أو CRTs، أو أطر عمل التقارير، أو التقارير عبر الكائنات، أو مصادر بيانات منشئ التقارير، أو يطلبون كشف الحقول لإعداد التقارير عبر الكائنات ذات الصلة. يُستخدم أيضًا عندما يذكر المستخدمون الكائنات الأساسية والكائنات ذات الصلة للتقارير، أو الروابط الداخلية مقابل الروابط الخارجية في التقارير، أو فئات نوع التقرير، أو عندما يواجهون أخطاء نشر لملفات .reportType-meta.xml. لا تقم بتشغيل: تشغيل التقارير الموجودة أو تحريرها أو تصفيتها؛ وإنشاء مجلدات التقارير أو لوحات المعلومات أو طرق عرض القائمة؛ أو أسئلة إعداد التقارير العامة التي لا تتضمن تأليف ملف ‎.reportType-meta.xml.
