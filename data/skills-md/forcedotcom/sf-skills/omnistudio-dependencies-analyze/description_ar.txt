مهارة تحليل OmniStudio الشاملة لاكتشاف مساحة الاسم وتصور التبعية وتحليل التأثير عبر OmniScripts وFlexCards وإجراءات التكامل ومخططي البيانات. يتم تشغيله عندما: يسأل المستخدم عن تبعيات OmniStudio، أو يريد اكتشاف مساحة الاسم (Core vs vlocity_cmt vs vlocity_ins)، أو يحتاج إلى تحليل التأثير، أو يطلب رسومًا بيانية للتبعية أو مخططات حورية البحر، أو يسأل عن المكونات التي تتأثر بالتغيير. لا تقم بالتشغيل عند: تأليف OmniScripts (استخدم omnistudio-omniscript-generate)، أو إنشاء FlexCards (استخدم omnistudio-flexcard-generate)، أو إنشاء إجراءات التكامل (استخدم omnistudio-integration-procedure-generate)، أو تكوين مخططي البيانات (استخدم omnistudio-datamapper-generate).
