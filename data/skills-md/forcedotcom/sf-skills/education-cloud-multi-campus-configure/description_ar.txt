استخدم هذه المهارة عندما يحتاج مسؤول Salesforce إلى إنشاء أو الحفاظ على تسلسل هرمي مؤسسي لـ Education Cloud عن طريق تحليل الهيكل التنظيمي من ملف PDF أو URL أو نص أو CSV. عند التشغيل لأول مرة، يقوم بإنشاء سجلات النظام والحرم الجامعي والكلية وحساب القسم المرتبطة عبر ParentId بالإضافة إلى سجلات ملف تعريف الأعمال 1:1. وفي عمليات التشغيل اللاحقة، يقوم بتسوية التسلسل الهرمي الحالي للمؤسسة مع البنية المطلوبة ويطبق الدلتا فقط - بإضافة وحدات جديدة، أو إعادة تسمية، أو نقل عقدة تحت عقدة أصل مختلفة - ولا يعيد إنشاء ما هو موجود أبدًا. يتم التشغيل عندما يريد المستخدم إعداد أو تكوين أو بناء أو تحديث أو إعادة هيكلة أو إعادة تنظيم هيكل متعدد الحرم الجامعي أو التسلسل الهرمي المؤسسي أو التسلسل الهرمي للحسابات مع ملفات تعريف الأعمال؛ أو إضافة أو إعادة تسمية أو نقل حرم جامعي أو كلية أو قسم. لا تقم بتشغيل عمليات الإعداد المسطحة لحرم جامعي واحد بدون مستويات هرمية، أو إنشاء حساب يدوي لمرة واحدة، أو إدارة حسابات غير تابعة لـ Education Cloud.
