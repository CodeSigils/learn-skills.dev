Salesforce CLI(sf)를 사용하여 선택한 통합 카탈로그 서비스 프로세스 템플릿을 Salesforce 조직에 배포하고, 라이브 카탈로그에 대해 이름별로 템플릿을 확인하고 다시 읽어 확인합니다. 결정적: 사용자가 명시적으로 명명한 템플릿만 배포하고 이름이 정확히 하나의 라이브 템플릿으로 확인되는 경우에만 배포하며 절대 추측하지 않습니다. 비즈니스 사용자가 이미 식별한 특정 통합 카탈로그 또는 서비스 프로세스 템플릿을 배포, 설치, 활성화, 설정 또는 프로비저닝하도록 요청할 때 사용합니다. '계정 비밀번호 재설정 템플릿 배포' 또는 '노트북 요청 서비스 프로세스 설치'. 트리거 대상: 카탈로그 템플릿 배포, 서비스 프로세스 템플릿 설치, X 템플릿 설정, X 서비스 프로세스 활성화. 사용자가 여전히 템플릿을 검색 또는 비교 중이고 이름을 지정하지 않은 경우(service-catalog-template-search 사용), 요청이 통합 카탈로그 서비스 프로세스 템플릿이 아닌 Data Cloud 데이터 키트, CRM 분석 또는 앱 프레임워크 템플릿과 관련된 경우에는 트리거하지 마세요.
