使用 Salesforce CLI (sf) 将选定的统一目录服务流程模板部署到 Salesforce 组织中，根据实时目录按名称解析模板并通过重新读取进行验证。确定性：它仅部署用户明确命名的模板，仅当名称解析为恰好一个实时模板时，并且从不猜测。当业务用户要求部署、安装、激活、设置或供应他们已经识别的特定统一目录或服务流程模板时使用 - 例如“部署重置帐户密码模板”或“安装笔记本电脑请求服务流程”。触发条件：部署目录模板、安装服务流程模板、设置 X 模板、激活 X 服务流程。在以下情况下请勿触发：用户仍在搜索或比较模板并且尚未命名模板（使用 service-catalog-template-search），或者请求涉及 Data Cloud 数据包、CRM Analytics 或应用程序框架模板，而不是统一目录服务流程模板。
