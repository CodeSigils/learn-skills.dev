Implementa una plantilla de proceso de servicio de catálogo unificado elegida en una organización de Salesforce mediante la CLI de Salesforce (sf), resolviendo la plantilla por nombre con el catálogo en vivo y verificando mediante relectura. Determinista: implementa solo una plantilla que el usuario nombró explícitamente, solo cuando el nombre se resuelve exactamente en una plantilla activa, y nunca adivina. Utilícelo cuando un usuario empresarial solicite implementar, instalar, activar, configurar o aprovisionar un catálogo unificado o una plantilla de proceso de servicio específicos que ya haya identificado (p. ej. 'implementar la plantilla Restablecer contraseña de cuenta' o 'instalar el proceso de servicio de solicitud de computadora portátil'. Activadores: implementar una plantilla de catálogo, instalar una plantilla de proceso de servicio, configurar la plantilla X, activar el proceso de servicio X. NO ACTIVAR cuando: el usuario todavía está buscando o comparando plantillas y no ha nombrado ninguna (use búsqueda de plantilla de catálogo de servicios), o la solicitud se refiere a kits de datos de Data Cloud, análisis de CRM o plantillas de App Framework en lugar de plantillas de proceso de servicio de catálogo unificado.
