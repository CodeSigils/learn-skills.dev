使用 Salesforce CLI (sf) 將選定的統一目錄服務流程範本部署到 Salesforce 組織中，根據即時目錄按名稱解析範本並透過重新讀取進行驗證。確定性：它僅部署使用者明確命名的模板，僅當名稱解析為恰好一個即時模板時，並且從不猜測。當業務使用者要求部署、安裝、啟動、設定或供應他們已經識別的特定統一目錄或服務流程範本時使用 - 例如「部署重設帳戶密碼範本」或「安裝筆記型電腦請求服務流程」。觸發條件：部署目錄範本、安裝服務流程範本、設定 X 範本、啟動 X 服務流程。在以下情況下請勿觸發：使用者仍在搜尋或比較範本且尚未命名範本（使用 service-catalog-template-search），或要求涉及 Data Cloud 資料包、CRM Analytics 或應用程式框架模板，而不是統一目錄服務流程範本。
