Erstellt ein DevOps Center-Qualitätsgate mit zugehörigen Regeln (PASS_PERCENTAGE, SEVERITY, ESSENTIAL) und verknüpft es mit einer Suite-Zuweisung auf der Pipeline-Stufe, nachdem eine obligatorische Auswirkungsvorschau angezeigt und eine explizite Bestätigung eingeholt wurde. Verwenden Sie diese Fähigkeit, wenn ein Benutzer ein Qualitätstor festlegen oder konfigurieren, einen Abdeckungsschwellenwert ändern oder Testbenchmarks in einer Pipeline-Phase festlegen möchte. TRIGGER, wenn: der Benutzer ein Qualitätstor festlegen/konfigurieren, einen Abdeckungsschwellenwert ändern oder Testbenchmarks auf einer Stufe festlegen möchte. NICHT AUSLÖSEN, wenn: nur ein vorhandenes Gate erneut ausgeführt wird (verwenden Sie „running-devops-test-suite“ im Retrigger-Modus).
