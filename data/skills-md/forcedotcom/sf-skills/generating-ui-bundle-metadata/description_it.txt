DEVE essere attivato quando il progetto contiene una directory uiBundles/*/src/ e supporta un nuovo bundle o app dell'interfaccia utente oppure quando si modificano ui-bundle.json, .uibundle-meta.xml o file di siti attendibili CSP. Utilizzare questa competenza quando si esegue l'impalcatura con il modello sf per generare ui-bundle, configurare ui-bundle.json (routing, intestazioni, outputDir) o registrare siti attendibili CSP. Attiva quando l'attività coinvolge file corrispondenti a *.uibundle-meta.xml, ui-bundle.json o cspTrustedSites/*.cspTrustedSite-meta.xml.
