Synchronisiert einen konfigurierten DevOps Center-Testanbieter in einer Pipeline erneut, um über den Connect API-Synchronisierungsendpunkt nach ausdrücklicher Benutzerbestätigung neue Testsuiten abzurufen. Nimmt eine Pipeline-ID und eine oder mehrere TestProvider-IDs entgegen und löst eine asynchrone Neusynchronisierung aus, sodass neu hinzugefügte Suiten für die Zuweisung verfügbar werden. Verwenden Sie diese Fähigkeit, wenn einem Testanbieter (z. B. Apex Unit Tests, Code Analyzer, Flow Tests, Provar) seit seiner letzten Konfiguration Suiten hinzugefügt wurden und der Benutzer möchte, dass diese Suiten im DevOps Center angezeigt werden. TRIGGER, wenn: der Benutzer einen Testanbieter neu synchronisieren möchte, neue Suiten von einem Anbieter abrufen, die Suite-Liste eines Anbieters aktualisieren möchte oder sagt, dass zugewiesene Suiten für einen konfigurierten Anbieter fehlen/veraltet sind. NICHT AUSLÖSEN, wenn: ein Anbieter zum ersten Mal konfiguriert wird (wodurch eine neue DevopsPipelineTestProvider-Konfiguration erstellt wird) oder vorhandene Suiten einer Phase zugewiesen/zugeordnet werden (verwenden Sie „Managing-Suite-Assignments“).
