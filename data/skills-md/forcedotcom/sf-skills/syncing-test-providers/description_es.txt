Vuelve a sincronizar un proveedor de pruebas configurado de DevOps Center en una canalización para seleccionar nuevos conjuntos de pruebas, a través del punto final de sincronización de Connect API, después de la confirmación explícita del usuario. Toma un pipelineId y uno o más testProviderIds y activa una resincronización asincrónica para que los conjuntos recién agregados estén disponibles para su asignación. Utilice esta habilidad cuando a un proveedor de pruebas (por ejemplo, Apex Unit Tests, Code Analyzer, Flow Tests, Provar) se le hayan agregado suites desde su última configuración y el usuario quiera que esas suites aparezcan en DevOps Center. DISPARAR cuando: el usuario quiere volver a sincronizar un proveedor de prueba, obtener nuevos conjuntos de un proveedor, actualizar la lista de conjuntos de un proveedor o dice que faltan conjuntos asignados o están desactualizados para un proveedor configurado. NO DISPARE cuando: configure un proveedor por primera vez (eso crea una nueva configuración de DevopsPipelineTestProvider), o asigne/mapee suites existentes a una etapa (use tareas de administración de suites).
