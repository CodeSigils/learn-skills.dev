headless-360 MCP サイト作成 API を使用して、新しいデジタル エクスペリエンス (コミュニティ) / Experience Cloud サイト (従業員サービス、IT サポート、ヘルプ デスク、人事、顧客、パートナー ポータル) を作成/プロビジョニング/セットアップします。ユーザーがポータル、サイト、またはコミュニティの作成/プロビジョニング/セットアップを要求する場合に常に使用します。例: 「従業員サービス ポータルの作成」、「IT サポート ポータルの作成」、「Agentforce 従業員センターの作成」 (作成時の MIAW (アプリ内/Web 用メッセージング) の接続を含む)。これはサイト作成スキルであり、新しい Aura または LWR Experience Builder サイトを最初からプロビジョニングする OWNS です。新しいサイトが必要である限り、ユーザーが「Experience Builder サイト」または「LWR サイト」と言った場合でもトリガーされます。常に最終ステップとしてポータル作成レポートを作成し (CLI 経由でアドホックに行うことはありません)、従来の Tabs+Visualforce サイトを作成することはありません。既存のサイトのページ/ルート/テーマ/ブランディング/ゲスト アクセス メタデータ (experience-lwr-site-generate)、既存サイトのカスタマイズ ( experience-ui-bundle)、CMS、コマースを変更する場合のみトリガーしないでください。
