헤드리스 360 MCP 사이트 생성 API를 통해 새로운 디지털 경험(커뮤니티)/Experience Cloud 사이트(직원 서비스, IT 지원, 헬프 데스크, HR, 고객 및 파트너 포털)를 생성/프로비저닝/설정합니다. 사용자가 포털, 사이트 또는 커뮤니티 생성/프로비저닝/설정을 요청할 때마다 사용합니다(예: '직원 서비스 포털 생성', 'IT 지원 포털 생성', 'Agentforce 직원 센터 생성', 생성 시 MIAW(인앱/웹용 메시징) 연결 포함). 이는 새로운 Aura 또는 LWR Experience Builder 사이트를 처음부터 프로비저닝하는 사이트 생성 기술 및 OWNS입니다. 새 사이트가 필요한 경우 사용자가 'Experience Builder 사이트' 또는 'LWR 사이트'라고 말할 때에도 이를 트리거합니다. 항상 최종 단계로 포털 생성 보고서를 작성하고(CLI를 통해 임시로 작성하지 않음) 레거시 Tabs+Visualforce 사이트를 만들지 않습니다. 기존 사이트의 페이지/경로/테마/브랜딩/게스트 액세스 메타데이터(experience-lwr-site-generate), 기존 사이트 사용자 정의(experience-ui-bundle), CMS, Commerce를 수정하는 경우에만 트리거하지 마십시오.
