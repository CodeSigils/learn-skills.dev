Erstellen/Bereitstellen/Einrichten einer NEUEN Digital Experience (Communities)/Experience Cloud-Site – Mitarbeiterservice, IT-Support, Helpdesk, HR, Kunden- und Partnerportale – über die Headless-360 MCP-Site-Erstellungs-APIs. Verwenden Sie diese Option immer dann, wenn ein Benutzer ein Portal, eine Website oder eine Community erstellen/bereitstellen/einrichten möchte, z. B.: „Erstellen eines Mitarbeiterserviceportals“, „Erstellen eines IT-Supportportals“, „Erstellen eines Agentforce-Mitarbeitercenters“, einschließlich der Verkabelung von MIAW (Messaging für In-App/Web) beim Erstellen. Dabei handelt es sich um die Fertigkeit „Site-CREATION“ und „OWNS“, die eine neue Aura- oder LWR-Experience-Builder-Site von Grund auf bereitstellt – sie wird auch dann ausgelöst, wenn der Benutzer „Experience-Builder-Site“ oder „LWR-Site“ sagt, solange eine NEUE Site gewünscht wird. Als letzten Schritt wird immer ein Bericht zur Portalerstellung geschrieben (niemals Ad-hoc über die CLI) und es wird niemals eine ältere Tabs+Visualforce-Site erstellt. NICHT AUSLÖSEN, nur zum Ändern der Seiten/Routen/Theme/Branding/Gastzugriffsmetadaten einer VORHANDENEN Site (experience-lwr-site-generate), zur Anpassung vorhandener Sites (experience-ui-bundle), CMS, Commerce.
