بنية تكامل Salesforce والسباكة في وقت التشغيل مع تسجيل 120 نقطة. استخدم هذه المهارة لإعداد بيانات الاعتماد المسماة، وبيانات الاعتماد الخارجية، والخدمات الخارجية، وأنماط استدعاء REST/SOAP، وأحداث النظام الأساسي، وتغيير التقاط البيانات. يتم تشغيله عندما: يقوم المستخدم بإعداد بيانات الاعتماد المسماة، أو الخدمات الخارجية، أو وسائل شرح REST/SOAP، أو أحداث النظام الأساسي، أو CDC، أو يلمس ملفات .namedCredential-meta.xml. لا تقم بالتشغيل عند: تكوين التطبيق/OAuth المتصل (استخدم تكامل-اتصال-اتصال-تطبيق-تكوين)، أو منطق Apex فقط (استخدم إنشاء منصة-apex)، أو استيراد/تصدير البيانات (استخدام إدارة بيانات النظام الأساسي)، أو البيانات التعريفية لعضوية قناة CDC مثل PlatformEventChannel، أو PlatformEventChannelMember، أو EnrichedField (استخدم تكامل الأحداث-cdc-configure).
