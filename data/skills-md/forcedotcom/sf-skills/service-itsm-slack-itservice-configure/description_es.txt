Configure la lista de verificación "Configurar autoservicio para empleados en Slack" / "Slack para servicio de empleados" para Servicio de empleados (ITSM) en Slack: el lado del empleado, que cubre la preferencia de organización de Slack para servicio de empleados, la asignación del conjunto de permisos de notificaciones de Slack para empleados, la habilitación/selección del portal de empleados (sitio de experiencia digital) y la conexión de Slack a un sitio de experiencia digital preferido. Utilice esto para: 'configurar Slack para el servicio de empleados', 'asignar el conjunto de permisos de notificaciones de Slack para empleados', 'administrar el acceso de usuarios para el servicio de empleados de Slack', 'seleccionar un sitio de experiencia digital preferido para Slack', 'configurar el autoservicio para empleados en Slack' o cualquier solicitud para completar la mitad de Servicio de TI/Servicio para empleados de la lista de verificación de la página Slack ITSM Go. NO DISPARAR para los equivalentes de Microsoft Teams (service-itsm-teams-itservice-configure) o para activar o desactivar las preferencias de notificación ITSM.
