Настройте контрольный список «Настройка самообслуживания для сотрудников в Slack» / «Slack для обслуживания сотрудников» для обслуживания сотрудников (ITSM) в Slack — на стороне сотрудника, охватывающий предпочтения организации Slack для обслуживания сотрудников, назначение набора разрешений для уведомлений Slack для сотрудников, включение/выбор портала сотрудников (сайт Digital Experience) и подключение Slack к предпочтительному сайту Digital Experience. Используйте это для: «настройки Slack для службы сотрудников», «назначения набора разрешений для уведомлений Slack сотрудников», «управления доступом пользователей для службы сотрудников Slack», «выбора предпочтительного сайта цифрового опыта для Slack», «настройки самообслуживания для сотрудников в Slack» или любого запроса на заполнение половины контрольного списка ИТ-услуги/Службы сотрудников контрольного списка на странице Slack ITSM Go. НЕ ИНИЦИРУЙТЕ для эквивалентов Microsoft Teams (service-itsm-teams-itservice-configure) или для включения или выключения предпочтений уведомлений ITSM.
