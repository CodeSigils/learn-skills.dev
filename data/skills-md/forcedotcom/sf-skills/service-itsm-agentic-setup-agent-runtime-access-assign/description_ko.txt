권한 오류로 인해 작업이 실패하지 않도록 활성화된 ITSM 에이전트의 작업에 필요한 런타임 권한을 사용자에게 부여합니다. Fulfiller 또는 Employee 에이전트가 활성화된 후 이 기술은 프로비저닝된 플랫폼 기능 권한 집합(프롬프트 템플릿, 데이터 클라우드, 통합 카탈로그)을 감지하고 기능당 계층(사용자/에이전트 대 관리자)과 할당할 사용자를 선택한 다음 할당할 수 있습니다(라이선스 제한 시 라이선스가 먼저 부여됨). 또한 선택한 활성화된 에이전트를 부여하는 사용자 정의 "에이전트 액세스" 권한 집합을 생성하고 이를 사용자에게 할당합니다. 이 모든 작업은 Salesforce CLI를 통해 이루어집니다. 사용자에게 활성화된 에이전트에 대한 액세스 권한을 부여하거나, 프롬프트 템플릿, 데이터 클라우드 또는 통합 카탈로그 액세스 권한을 할당하거나, 에이전트 액세스 권한 집합을 생성하는 데 사용됩니다. Agentforce for IT 서비스 토글 활성화, 에이전트 생성 또는 활성화, Fulfiller 활성화 작업 표면 공백(service-itsm-agentic-setup-itsm-agentforce-permset-할당), CMDB 액세스 또는 일반 권한 집합 할당을 위해 트리거하지 마십시오.
