Concede a un usuario los permisos de tiempo de ejecución que las acciones de un agente ITSM activado necesitan para que no fallen por errores de permiso. Después de que se activa un agente Fulfiller o Employee, esta funcionalidad detecta qué conjuntos de permisos de características de la plataforma están provisionados (Plantillas de Prompt, Data Cloud, Catálogo Unificado), te permite elegir un nivel (usuario/agente vs admin) por característica y qué usuario(s) asignar, y luego los asigna (primero la licencia cuando está restringida por licencia). También crea un conjunto de permisos personalizado “Acceso de Agente” que otorga los agentes activados que selecciones y lo asigna al usuario, todo a través del CLI de Salesforce. Úsalo para otorgar a un usuario acceso a un agente activado, para asignar acceso a plantillas de prompt, Data Cloud o Catálogo Unificado, o para crear un conjunto de permisos de Acceso de Agente. NO ACTIVES para habilitar los interruptores de Agentforce para IT Service, crear o activar un agente, la brecha de exposición de acción de activación de Fulfiller (service-itsm-agentic-setup-itsm-agentforce-permset-assign), acceso a CMDB o asignación genérica de conjuntos de permisos.
