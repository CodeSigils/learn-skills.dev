Otorgue a un usuario los permisos de tiempo de ejecución que necesitan las acciones de un agente ITSM activado para que las acciones no fallen debido a errores de permisos. Después de activar un agente Fulfiller o Empleado, esta habilidad detecta qué conjuntos de permisos de características de la plataforma se aprovisionan (Plantillas de solicitud, Nube de datos, Catálogo unificado), le permite elegir un nivel (usuario/agente vs administrador) por característica y qué usuarios asignar, luego los asigna (la licencia primero cuando está controlada por licencia). También crea un conjunto de permisos de "Acceso de agente" personalizado que otorga a los agentes activados que usted elija y se lo asigna al usuario, todo a través de la CLI de Salesforce. Úselo para otorgar acceso a un usuario a un agente activado, para asignar acceso a plantilla de solicitud, nube de datos o catálogo unificado, o para crear un conjunto de permisos de acceso de agente. NO DISPARAR para habilitar los cambios de servicio de Agentforce para TI, crear o activar un agente, la brecha de aparición de acciones de activación de Fulfiller (servicio-itsm-agentic-setup-itsm-agentforce-permset-assign), acceso a CMDB o asignación de conjunto de permisos genéricos.
