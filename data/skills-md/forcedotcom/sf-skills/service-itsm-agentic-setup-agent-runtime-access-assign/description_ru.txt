Предоставьте пользователю разрешения во время выполнения, необходимые для действий активированного агента ITSM, чтобы действия не завершались неудачно из-за ошибок разрешений. После активации агента исполнителя или сотрудника этот навык определяет, какие наборы разрешений функций платформы предоставлены (шаблоны подсказок, облако данных, единый каталог), позволяет вам выбрать уровень (пользователь/агент или администратор) для каждой функции и каких пользователей назначить, а затем назначает их (сначала лицензия, если действует лицензия). Он также создает собственный набор разрешений «Доступ к агенту», предоставляющий активированным агентам по вашему выбору, и назначает его пользователю — и все это через интерфейс командной строки Salesforce. Используйте, чтобы предоставить пользователю доступ к активированному агенту, назначить доступ к шаблону приглашения, облаку данных или единому каталогу или создать набор разрешений на доступ агента. НЕ ИНИЦИРУЙТЕ для включения переключателей Agentforce for IT Service, создания или активации агента, разрыва действия активации Fulfiller (service-itsm-agentic-setup-itsm-agentforce-permset-assign), доступа к CMDB или назначения общего набора разрешений.
