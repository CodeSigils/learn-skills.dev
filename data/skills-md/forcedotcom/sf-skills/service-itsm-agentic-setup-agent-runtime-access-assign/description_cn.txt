向用户授予激活的 ITSM 代理操作所需的运行时权限，以便操作不会因权限错误而失败。激活履行者或员工代理后，此技能会检测配置了哪些平台功能权限集（提示模板、数据云、统一目录），让您可以为每个功能选择一个层（用户/代理与管理员）以及要分配的用户，然后分配它们（在许可证门控时首先分配许可证）。它还创建自定义“代理访问”权限集，授予您选择的已激活代理并将其分配给用户 - 全部通过 Salesforce CLI 进行。用于授予用户对已激活代理的访问权限，分配提示模板、数据云或统一目录访问权限，或者创建代理访问权限集。请勿触发启用 Agentforce for IT 服务切换、创建或激活代理、履行者激活操作显示间隙 (service-itsm-agentic-setup-itsm-agentforce-permset-assign)、CMDB 访问或通用权限集分配。
