امنح المستخدم أذونات وقت التشغيل التي تحتاجها إجراءات وكيل ITSM المنشط حتى لا تفشل الإجراءات عند حدوث أخطاء في الأذونات. بعد تنشيط وكيل الوفاء أو الموظف، تكتشف هذه المهارة مجموعات أذونات ميزات النظام الأساسي التي يتم توفيرها (قوالب المطالبة، وسحابة البيانات، والكتالوج الموحد)، وتتيح لك اختيار طبقة (مستخدم/وكيل مقابل مسؤول) لكل ميزة والمستخدم (المستخدمين) الذي سيتم تعيينه، ثم تعيينهم (الترخيص أولاً عندما يكون الترخيص مشروطًا). كما أنه ينشئ أيضًا مجموعة أذونات مخصصة "وصول الوكيل" تمنح الوكلاء المنشطين الذين تختارهم ويعينهم للمستخدم - كل ذلك عبر Salesforce CLI. يُستخدم لمنح مستخدم حق الوصول إلى وكيل منشط، أو لتعيين وصول إلى قالب المطالبة، أو سحابة البيانات، أو الكتالوج الموحد، أو لإنشاء مجموعة أذونات وصول الوكيل. لا تقم بالتشغيل لتمكين Agentforce لتبديل خدمة تكنولوجيا المعلومات، أو إنشاء وكيل أو تنشيطه، أو فجوة ظهور إجراء تنشيط Fufiller (service-itsm-agentic-setup-itsm-agentforce-permset-sign)، أو الوصول إلى CMDB، أو تعيين مجموعة الأذونات العامة.
