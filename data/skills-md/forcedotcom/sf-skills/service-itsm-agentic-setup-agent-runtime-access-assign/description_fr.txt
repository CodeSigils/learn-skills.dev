Accordez à un utilisateur les autorisations d'exécution dont les actions d'un agent ITSM activé ont besoin afin que les actions n'échouent pas en cas d'erreurs d'autorisation. Une fois qu'un agent Fulfiller ou Employee est activé, cette compétence détecte quels ensembles d'autorisations de fonctionnalités de plate-forme sont fournis (modèles d'invite, Data Cloud, catalogue unifié), vous permet de choisir un niveau (utilisateur/agent vs administrateur) par fonctionnalité et quel(s) utilisateur(s) attribuer, puis les attribue (licence d'abord lorsque la licence est limitée). Il crée également un ensemble d'autorisations « Accès aux agents » personnalisé accordant les agents activés que vous choisissez et l'attribue à l'utilisateur, le tout via la CLI Salesforce. Utilisez-le pour accorder à un utilisateur l'accès à un agent activé, pour attribuer un accès au modèle d'invite, au cloud de données ou au catalogue unifié, ou pour créer un ensemble d'autorisations d'accès à l'agent. NE PAS DÉCLENCHER pour l'activation des bascules de service Agentforce pour IT, la création ou l'activation d'un agent, l'écart de surface d'action d'activation Fulfiller (service-itsm-agentic-setup-itsm-agentforce-permset-assign), l'accès CMDB ou l'attribution d'un ensemble d'autorisations générique.
