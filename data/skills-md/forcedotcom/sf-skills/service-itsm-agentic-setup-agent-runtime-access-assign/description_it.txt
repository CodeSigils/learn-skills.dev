Concedere a un utente le autorizzazioni di runtime necessarie per le azioni di un agente ITSM attivato in modo che le azioni non falliscano in caso di errori di autorizzazione. Dopo l'attivazione di un agente Fulfiller o Employee, questa competenza rileva di quali set di autorizzazioni di funzionalità della piattaforma è stato eseguito il provisioning (modelli di prompt, data cloud, catalogo unificato), consente di scegliere un livello (utente/agente o amministratore) per funzionalità e quali utenti assegnare, quindi assegnarli (prima la licenza quando è soggetta a licenza). Crea inoltre un set di autorizzazioni personalizzato "Accesso agente" che concede gli agenti attivati ​​scelti da te e lo assegna all'utente, il tutto tramite la CLI di Salesforce. Utilizzare per concedere a un utente l'accesso a un agente attivato, per assegnare l'accesso a modello di prompt, cloud di dati o catalogo unificato oppure per creare un set di autorizzazioni Accesso agente. NON ATTIVARE per l'attivazione/disattivazione del servizio Agentforce per IT, la creazione o l'attivazione di un agente, il divario di superficie dell'azione di attivazione del Gestore (service-itsm-agentic-setup-itsm-agentforce-permset-assign), l'accesso al CMDB o l'assegnazione di un set di autorizzazioni generico.
