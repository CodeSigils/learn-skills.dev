アクションが権限エラーで失敗しないように、アクティブ化された ITSM エージェントのアクションに必要な実行時権限をユーザーに付与します。履行者エージェントまたは従業員エージェントがアクティブ化されると、このスキルはどのプラットフォーム機能権限セットがプロビジョニングされているか (プロンプト テンプレート、データ クラウド、統合カタログ) を検出し、機能ごとに層 (ユーザー/エージェント対管理者) と割り当てるユーザーを選択して、それらを割り当てることができます (ライセンス ゲートの場合はライセンスが最初)。また、選択したアクティブ化されたエージェントを付与するカスタムの「エージェントアクセス」権限セットも作成され、それがすべて Salesforce CLI 経由でユーザに割り当てられます。アクティブ化されたエージェントへのユーザー アクセスの付与、プロンプト テンプレート、データ クラウド、または統合カタログへのアクセスの割り当て、またはエージェント アクセス権限セットの作成に使用します。 Agentforce for IT サービスの切り替えの有効化、エージェントの作成またはアクティブ化、フルフィラーのアクティブ化アクションの表面化ギャップ (service-itsm-agentic-setup-itsm-agentforce-permset-assign)、CMDB アクセス、または一般的な権限セットの割り当てをトリガーしないでください。
