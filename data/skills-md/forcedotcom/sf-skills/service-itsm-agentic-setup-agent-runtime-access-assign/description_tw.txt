向使用者授予啟動的 ITSM 代理操作所需的執行時間權限，以便操作不會因權限錯誤而失敗。啟動履行者或員工代理後，此技能會偵測配置了哪些平台功能權限集（提示範本、資料雲、統一目錄），讓您可以為每個功能選擇一個層（使用者/代理與管理員）以及要指派的用戶，然後指派它們（在許可證門控時先指派許可證）。它還會建立自訂「代理存取」權限集，授予您選擇的已啟動代理程式並將其指派給使用者 - 全部透過 Salesforce CLI 進行。用於授予使用者對已啟動代理的存取權限，分配提示範本、資料雲或統一目錄存取權限，或建立代理存取權限集。請勿觸發啟用 Agentforce for IT 服務切換、建立或啟動代理程式、履行者啟動操作顯示間隙 (service-itsm-agentic-setup-itsm-agentforce-permset-assign)、CMDB 存取或通用權限集指派。
