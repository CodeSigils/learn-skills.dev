Utilisez cette compétence en tant que validateur spécialisé Lightning Web Security (LWS) pour un ensemble de composants Web Lightning (`.js`, `.ts`, `.html`, `.css`, `.js-meta.xml`) — l'examen canonique LWS/Product-Security pour les LWC, PAS une passe générique de sécurité du code. Il produit soit une liste de résultats classés par gravité avec des corrections au niveau du code, soit un rapport de score JSON SARIF 2.1.0 saisi par le catalogue de règles « lws-001 »… « lws-023b ». DÉCLENCHEMENT lorsque l'utilisateur demande d'examiner, d'auditer ou de vérifier un composant LWC pour des problèmes de conformité LWS et de recommander des correctifs, d'évaluer la conformité LWS/sécurité d'un composant, de trouver des API DOM dangereuses ou des récepteurs bloqués (`eval`, `Function`, `document.write`, `innerHTML`, `document.createElement('script')`, affectation de portée globale à `window`/`globalThis`, schémas d'URL non sécurisés), ou émettre un Rapport de sécurité SARIF. NE PAS DÉCLENCHER pour un examen de sécurité générique non-LWC, pour la création d'un nouveau LWC (utilisez experience-lwc-generate), pour l'accessibilité (WCAG 2.2), RTL/i18n ou pour un examen Apex/Aura/côté serveur.
