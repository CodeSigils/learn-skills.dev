将此技能用作 Lightning Web 组件包（`.js`、`.ts`、`.html`、`.css`、`.js-meta.xml`）的专用 Lightning Web Security (LWS) 验证器 - LWC 的规范 LWS/产品安全审查，而不是通用代码安全通行证。它会生成包含代码级补救措施的严重性排名结果列表，或由“lws-001”...“lws-023b”规则目录键入的 SARIF 2.1.0 JSON 分数报告。当用户要求审查、审核或检查 LWC 组件是否存在 LWS 合规性问题并建议修复、对组件的 LWS/安全合规性进行评分、查找危险的 DOM API 或被阻止的接收器（`eval`、`Function`、`document.write`、`innerHTML`、`document.createElement('script')`、对 `window`/`globalThis` 的全局范围分配、不安全的 URL 方案）或发出 SARIF 安全报告时触发。不要触发通用非 LWC 安全审查、构建新的 LWC（使用 experience-lwc-generate）、可访问性 (WCAG 2.2)、RTL/i18n 或 Apex/Aura/服务器端审查。
