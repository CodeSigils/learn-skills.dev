Utilice esta habilidad como EL validador especializado de Lightning Web Security (LWS) para un paquete de componentes web Lightning (`.js`, `.ts`, `.html`, `.css`, `.js-meta.xml`): la revisión canónica de LWS/Product-Security para LWC, NO un pase genérico de seguridad de código. Produce una lista de hallazgos clasificados por gravedad con soluciones a nivel de código o un informe de puntuación JSON SARIF 2.1.0 codificado por el catálogo de reglas `lws-001`…`lws-023b`. DISPARAR cuando el usuario solicita revisar, auditar o verificar un componente LWC para detectar problemas de cumplimiento de LWS y recomendar soluciones, calificar el cumplimiento de seguridad/LWS de un componente, encontrar API DOM peligrosas o receptores bloqueados (`eval`, `Function`, `document.write`, `innerHTML`, `document.createElement('script')`, asignación de alcance global a `window`/`globalThis`, esquemas de URL inseguros), o emitir una seguridad SARIF informe. NO DISPARE para una revisión de seguridad genérica que no sea LWC, para crear una nueva LWC (use experiencia-lwc-generate), accesibilidad (WCAG 2.2), RTL/i18n o Apex/Aura/revisión del lado del servidor.
