استخدم هذه المهارة كمدقق متخصص في Lightning Web Security (LWS) لحزمة Lightning Web Component (`.js`، `.ts`، `.html`، `.css`، `.js-meta.xml`) — مراجعة LWS/Product-Security الأساسية لـ LWCs، وليس ممر أمان التعليمات البرمجية العام. وينتج إما قائمة نتائج مصنفة حسب الخطورة مع معالجات على مستوى الكود أو تقرير نتائج SARIF 2.1.0 JSON مرتبطًا بكتالوج القواعد `lws-001`...`lws-023b`. يتم تشغيله عندما يطلب المستخدم مراجعة مكون LWC أو تدقيقه أو التحقق من مشكلات امتثال LWS والتوصية بالإصلاحات أو تسجيل امتثال LWS/الأمان للمكون أو العثور على واجهات برمجة التطبيقات DOM الخطيرة أو المصارف المحظورة ('eval`، `Function`، `document.write`، `innerHTML`، `document.createElement('script')`، تعيين النطاق العالمي إلى `window`/`globalThis`، غير آمن مخططات URL)، أو قم بإصدار تقرير أمان SARIF. لا تقم بالبدء في إجراء مراجعة أمنية عامة غير متعلقة بـ LWC، أو لبناء LWC جديد (استخدم إنشاء تجربة lwc)، أو إمكانية الوصول (WCAG 2.2)، أو RTL/i18n، أو مراجعة Apex/Aura/جانب الخادم.
