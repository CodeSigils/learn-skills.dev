Используйте этот навык в качестве специализированного валидатора Lightning Web Security (LWS) для пакета веб-компонентов Lightning (`.js`, `.ts`, `.html`, `.css`, `.js-meta.xml`) — канонического обзора LWS/Product-Security для LWC, а НЕ общего прохода по обеспечению безопасности кода. Он создает либо список обнаружений с ранжированием по серьезности с исправлениями на уровне кода, либо отчет об оценках SARIF 2.1.0 JSON, основанный на каталоге правил `lws-001`…`lws-023b`. ТРИГГЕР, когда пользователь запрашивает просмотр, аудит или проверку компонента LWC на наличие проблем с соответствием LWS и рекомендации исправлений, оценку соответствия компонента LWS/безопасности, поиск опасных API DOM или заблокированных приемников (`eval`, `Function`, `document.write`, `innerHTML`, `document.createElement('script')`, присвоение глобальной области `window`/`globalThis`, небезопасные схемы URL-адресов), или опубликовать отчет о безопасности SARIF. НЕ ЗАПУСКАЙТЕ для общей проверки безопасности, отличной от LWC, для создания нового LWC (используйте experience-lwc-generate), проверки доступности (WCAG 2.2), RTL/i18n или проверки Apex/Aura/на стороне сервера.
