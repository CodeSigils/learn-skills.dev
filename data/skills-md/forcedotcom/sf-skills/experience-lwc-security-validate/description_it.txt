Utilizza questa competenza come IL validatore specializzato Lightning Web Security (LWS) per un bundle di componenti Lightning Web (`.js`, `.ts`, `.html`, `.css`, `.js-meta.xml`) — la revisione canonica LWS/Product-Security per LWC, NON un passaggio di sicurezza del codice generico. Produce un elenco di risultati classificati in base alla gravità con correzioni a livello di codice o un rapporto sul punteggio JSON SARIF 2.1.0 codificato dal catalogo di regole `lws-001`…`lws-023b`. SI ATTIVA quando l'utente chiede di rivedere, verificare o verificare un componente LWC per problemi di conformità LWS e consigliare correzioni, valutare la conformità LWS/sicurezza di un componente, trovare API DOM pericolose o sink bloccati (`eval`, `Function`, `document.write`, `innerHTML`, `document.createElement('script')`, assegnazione di ambito globale a "window`/`globalThis`, schemi URL non sicuri) o emettere un rapporto di sicurezza SARIF. NON ATTIVARE per revisione di sicurezza generica non LWC, per la creazione di un nuovo LWC (utilizzare experience-lwc-generate), accessibilità (WCAG 2.2), RTL/i18n o revisione Apex/Aura/lato server.
