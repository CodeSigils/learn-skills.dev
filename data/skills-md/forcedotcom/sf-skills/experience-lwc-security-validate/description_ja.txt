このスキルは、Lightning Web コンポーネントバンドル (`.js`、`.ts`、`.html`、`.css`、`.js-meta.xml`) の特殊な Lightning Web Security (LWS) 検証ツールとして使用します。これは、汎用のコードセキュリティパスではなく、LWC の正規の LWS/製品セキュリティレビューです。コードレベルの修復を含む重大度ランク付けされた結果リスト、または「lws-001」…「lws-023b」ルール カタログをキーとした SARIF 2.1.0 JSON スコア レポートのいずれかを生成します。ユーザーが LWS コンプライアンス問題について LWC コンポーネントをレビュー、監査、チェックして修正を推奨すること、コンポーネントの LWS/セキュリティ コンプライアンスをスコアリングすること、危険な DOM API またはブロックされたシンク (`eval`、`Function`、`document.write`、`innerHTML`、`document.createElement('script')`、`window`/`globalThis` へのグローバル スコープの割り当て、安全でない URL スキーム) を見つけることをユーザーが要求したときにトリガーされます。 SARIFセキュリティレポートを発行します。一般的な非 LWC セキュリティ レビュー、新しい LWC の構築 (experience-lwc-generate を使用)、アクセシビリティ (WCAG 2.2)、RTL/i18n、または Apex/Aura/サーバー側レビューの場合はトリガーしないでください。
