DevOps Center テスト スイートをパイプライン ステージ (プロモート前、プロモート後、またはレビュー イベント) でエンドツーエンドで実行します。明示的な確認ゲートの後に Connect API を介して非同期実行をトリガーし、完了、失敗、またはタイムアウトになるまでプロバイダー固有の間隔で runId によってポーリングし、結果を障害分析に渡します。また、修正後に品質ゲートを再トリガーしますが、カバレッジがしきい値を満たした場合に限ります。このスキルは、ユーザーがステージ上でテスト スイートを実行、開始、起動する場合、品質ゲートを再実行する場合、または進行中の実行が完了するまで監視する場合に使用します。トリガーのタイミング: ユーザーがステージ上でスイートを実行/起動する場合、プロモーションの前後にテストを実行する場合、失敗を修正した後に品質ゲートを再実行する場合、テストを追加した後にブロックされたプロモーションのブロックを解除する場合、または進行中の実行をポーリング/監視する場合。次の場合はトリガーしないでください: sf apex run test を直接実行している場合 (platform-apex-test-run を使用)、または新しいゲートまたはしきい値を設定している場合 (dx-devops-test-pipeline-configure を使用)。
