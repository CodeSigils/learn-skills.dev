在管道階段（升級前、升級後或審核事件）端對端執行 DevOps 中心測試套件：在明確確認門後透過 Connect API 觸發非同步執行，然後按提供者特定的時間間隔按 runId 進行輪詢，直到完成、失敗或逾時，並將結果交給故障分析。修復後也會重新觸發質量門，但只有在覆蓋率達到閾值時才重新觸發。當使用者想要在舞台上運行、啟動或啟動測試套件、重新運行品質門或觀看正在進行的運行直至完成時，請使用此技能。觸發時間：使用者想要在階段上運行/啟動套件、在升級之前或之後執行測試、修復故障後重新運行品質門、添加測試後解鎖受阻止的升級，或輪詢/觀看正在進行的運行。請勿在下列情況下觸發：直接執行 sf apex run test（使用 platform-apex-test-run），或設定新的閘或閾值（使用 dx-devops-test-pipeline-configure）。
