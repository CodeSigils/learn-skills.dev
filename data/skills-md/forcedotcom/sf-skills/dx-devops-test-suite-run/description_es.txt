Ejecuta conjuntos de pruebas de DevOps Center en una etapa de canalización (evento previo a la promoción, posterior a la promoción o revisión) de extremo a extremo: desencadena la ejecución asíncrona a través de la API Connect después de una puerta de confirmación explícita, luego sondea mediante runId en intervalos específicos del proveedor hasta que se completa, falla o se agota el tiempo de espera, y entrega los resultados al análisis de fallas. También vuelve a activar una puerta de calidad después de las correcciones, pero solo una vez que la cobertura alcanza el umbral. Utilice esta habilidad cuando un usuario desee ejecutar, iniciar o iniciar conjuntos de pruebas en un escenario, volver a ejecutar una puerta de calidad o observar una ejecución en progreso hasta su finalización. DISPARAR cuando: el usuario desea ejecutar/lanzar suites en un escenario, ejecutar pruebas antes o después de la promoción, volver a ejecutar una puerta de calidad después de corregir fallas, desbloquear una promoción bloqueada después de agregar pruebas o sondear/ver una ejecución en progreso. NO DISPARE cuando: ejecute sf apex run test directamente (use platform-apex-test-run), o configure una NUEVA puerta o umbral (use dx-devops-test-pipeline-configure).
