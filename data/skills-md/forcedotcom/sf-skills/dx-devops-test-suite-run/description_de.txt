Führt DevOps Center-Testsuiten auf einer Pipeline-Stufe (Pre-Promote-, Post-Promote- oder Review-Ereignis) von Ende zu Ende aus: Löst die asynchrone Ausführung über die Connect-API nach einem expliziten Bestätigungsgate aus, fragt dann in anbieterspezifischen Intervallen nach runId ab, bis der Vorgang abgeschlossen ist, fehlschlägt oder eine Zeitüberschreitung auftritt, und übergibt die Ergebnisse an die Fehleranalyse. Löst außerdem nach Korrekturen erneut ein Qualitätstor aus, jedoch erst, wenn die Abdeckung den Schwellenwert erreicht. Verwenden Sie diese Fähigkeit, wenn ein Benutzer Testsuiten auf einer Bühne ausführen, starten oder starten, ein Qualitätstor erneut ausführen oder einen laufenden Lauf bis zum Abschluss beobachten möchte. TRIGGER, wenn: der Benutzer Suiten auf einer Bühne ausführen/starten, Tests vor oder nach der Heraufstufung ausführen, ein Qualitätsgate nach der Behebung von Fehlern erneut ausführen, eine blockierte Hochstufung nach dem Hinzufügen von Tests entsperren oder einen laufenden Lauf abfragen/beobachten möchte. NICHT AUSLÖSEN, wenn: sf apex run test direkt ausgeführt wird (verwenden Sie „platform-apex-test-run“) oder ein NEUES Gate oder einen NEUEN Schwellenwert konfiguriert wird (verwenden Sie „dx-devops-test-pipeline-configure“).
