**ТОЛЬКО ДЛЯ ВНУТРЕННЕГО ИСПОЛЬЗОВАНИЯ — вызывается оркестратором `service-de-headless-channel-configure`.** Вставьте запись расширенного обмена сообщениями `MessagingChannel` (плюс ее дочерний элемент `MessagingChannelUsage` в качестве бесплатного побочного эффекта на стороне сервера) любого поддерживаемого типа — WhatsApp, LINE, Apple Business Chat, Facebook или SMS (текст). При наличии `{MESSAGE_TYPE}` и соответствующих входных данных, специфичных для типа, выполняется общая предварительная проверка → Connect-insert → проверка потока и разветвление только там, где тип действительно отличается (тело запроса, предварительные требования, классы ошибок). Использует санкционированную конечную точку POST /services/data/v{V}/connect/livemessage/channels Connect REST — без сеанса Aura, без извлечения токена в состояние оболочки. **Пользователи всегда должны вместо этого вызывать `service-de-headless-channel-configure` — он обрабатывает вставку → маршрут → активацию в одном потоке. ** Используйте этот навык при вставке канала обмена сообщениями любого типа; он заменяет четыре прежних навыка создания каждого типа.
