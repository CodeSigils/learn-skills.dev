Gewähren Sie einem bestimmten Benutzer Zugriff auf CMDB-Daten (Configuration Management Database) in Service Cloud ITSM für eine Produktions- oder Sandbox-Organisation, indem Sie die lizenzgestützten CMDB-Berechtigungssätze (Konfigurationselementleser, Eigentümer, Typleser, Typmanager) und die entsprechenden Berechtigungssatzlizenzen zuweisen. Verwenden Sie diese Option, wenn der Benutzer darum bittet, jemandem CMDB-Zugriff zu gewähren, CMDB-Berechtigungssätze zuzuweisen, einem Benutzer die Rolle „Konfigurationselement-Leser/-Besitzer“ zu gewähren oder eine CMDB 403 FUNCTIONALITY_NOT_ENABLED zu beheben, die ein Benutzer immer noch trifft, nachdem die CMDB-Funktion bereits aktiviert ist. Auslöser bei: CMDB-Berechtigungssatz zuweisen, CMDB-Zugriff gewähren, Benutzer Zugriff auf Konfigurationselemente gewähren, CMDB-Zugriff für Benutzer, Benutzer erhält nach der Aktivierung weiterhin CMDB 403. NICHT AUSLÖSEN, wenn: der Benutzer die CMDB-Funktion aktivieren oder den ITOM-Mandanten für die gesamte Organisation bereitstellen möchte (d. h. die Fähigkeit zur Aktivierung der CMDB-Funktion), nur ein CMDB-Inhaltspaket installieren, direkt mit CMDB-Datensätzen arbeiten oder Benutzern allgemeine (nicht CMDB) Berechtigungssätze zuweisen möchte (verwenden Sie dx-org-permission-set-assign).
