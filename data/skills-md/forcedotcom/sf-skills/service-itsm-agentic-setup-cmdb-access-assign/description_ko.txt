라이센스 지원 CMDB 권한 집합(구성 항목 판독기, 소유자, 유형 판독기, 유형 관리자) 및 해당 권한 집합 라이센스를 할당하여 프로덕션 또는 샌드박스 조직에 대해 Service Cloud ITSM의 CMDB(구성 관리 데이터베이스) 데이터에 대한 특정 사용자 액세스 권한을 부여합니다. 사용자가 다른 사람에게 CMDB 액세스 권한을 부여하거나, CMDB 권한 집합을 할당하거나, 사용자에게 구성 항목 리더/소유자 역할을 부여하거나, CMDB 기능이 이미 활성화된 후에도 사용자가 계속 작동하는 CMDB 403 FUNCTIONALITY_NOT_ENABLED를 수정하도록 요청할 때 사용합니다. 트리거 대상: CMDB 권한 집합 할당, CMDB 액세스 권한 부여, 사용자에게 구성 항목 액세스 권한 부여, 사용자에 대한 CMDB 액세스, 활성화 후에도 사용자는 CMDB 403을 얻습니다. 다음의 경우에는 트리거하지 마십시오: 사용자가 CMDB 기능을 켜거나 전체 조직에 대해 ITOM 테넌트를 프로비저닝하려는 경우(즉, CMDB 기능 활성화 기술), CMDB 컨텐츠 번들만 설치하거나, ​​CMDB 레코드로 직접 작업하거나, 사용자에게 일반(비CMDB) 권한 집합을 할당하려는 경우(dx-org-permission-set-sign 사용).
