Предоставьте конкретному пользователю доступ к данным CMDB (база данных управления конфигурациями) в Service Cloud ITSM для производственной или изолированной организации, назначив поддерживаемые лицензиями наборы разрешений CMDB (Читатель элементов конфигурации, Владелец, Чтец типов, Менеджер типов) и лицензии на их наборы разрешений. Используйте, когда пользователь просит предоставить кому-либо доступ к CMDB, назначить наборы разрешений CMDB, предоставить пользователю роль читателя/владельца элемента конфигурации или исправить CMDB 403 FUNCTIONALITY_NOT_ENABLED, который пользователь все еще использует после того, как функция CMDB уже включена. Срабатывает при: назначить набор разрешений CMDB, предоставить доступ к CMDB, предоставить пользователю доступ к элементу конфигурации, доступ к CMDB для пользователя, пользователь по-прежнему получает CMDB 403 после включения. НЕ АКТИВИРУЙТЕСЬ, когда: пользователь хочет включить функцию CMDB или подготовить арендатора ITOM для всей организации (то есть навык включения функции CMDB), установить только пакет содержимого CMDB, напрямую работать с записями CMDB или назначить пользователям общие (не CMDB) наборы разрешений (используйте dx-org-permission-set-assign).
