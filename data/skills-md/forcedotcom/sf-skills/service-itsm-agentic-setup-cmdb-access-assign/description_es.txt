Otorgue a un usuario específico acceso a los datos de CMDB (base de datos de gestión de configuración) en Service Cloud ITSM en una organización de producción o sandbox asignando los conjuntos de permisos de CMDB respaldados por licencia (lector de elementos de configuración, propietario, lector de tipos, administrador de tipos) y sus licencias de conjuntos de permisos. Úselo cuando el usuario solicite otorgarle a alguien acceso a CMDB, asignar conjuntos de permisos de CMDB, otorgarle a un usuario la función de lector/propietario de elementos de configuración o corregir un CMDB 403 FUNCTIONALITY_NOT_ENABLED que un usuario aún accede después de que la función CMDB ya esté habilitada. Activadores: asignar conjunto de permisos de CMDB, otorgar acceso a CMDB, otorgar al usuario acceso al elemento de configuración, acceso a CMDB para el usuario, el usuario aún obtiene CMDB 403 después de habilitarlo. NO DISPARAR cuando: el usuario desea activar la función CMDB o aprovisionar el inquilino ITOM para toda la organización (es decir, la habilidad de habilitación de funciones CMDB), solo instalar un paquete de contenido CMDB, trabajar con registros CMDB directamente o asignar conjuntos de permisos generales (no CMDB) a los usuarios (use dx-org-permission-set-assign).
