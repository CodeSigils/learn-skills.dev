Concedere a un utente specifico l'accesso ai dati CMDB (Configuration Management Database) in Service Cloud ITSM rispetto a un'organizzazione di produzione o sandbox assegnando i set di autorizzazioni CMDB supportati da licenza (Lettore elementi di configurazione, Proprietario, Lettore di tipi, Gestore di tipi) e le relative licenze di set di autorizzazioni. Da utilizzare quando l'utente chiede di concedere a qualcuno l'accesso CMDB, assegnare set di autorizzazioni CMDB, concedere a un utente il ruolo Lettore/Proprietario dell'elemento di configurazione o correggere un CMDB 403 FUNCTIONALITY_NOT_ENABLED che un utente continua a raggiungere dopo che la funzionalità CMDB è già abilitata. Si attiva: assegnazione del set di autorizzazioni CMDB, concessione dell'accesso CMDB, concessione dell'accesso all'elemento di configurazione dell'utente, accesso CMDB per l'utente, l'utente riceve comunque il CMDB 403 dopo l'abilitazione. NON ATTIVARE quando: l'utente desidera attivare la funzionalità CMDB o eseguire il provisioning del tenant ITOM per l'intera organizzazione (ovvero la competenza di abilitazione funzionalità CMDB), installare solo un pacchetto di contenuti CMDB, lavorare direttamente con i record CMDB o assegnare set di autorizzazioni generali (non CMDB) agli utenti (utilizzare dx-org-permission-set-assign).
