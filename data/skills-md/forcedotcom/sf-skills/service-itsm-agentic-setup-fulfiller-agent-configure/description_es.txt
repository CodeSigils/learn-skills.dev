Cree y active el agente IT Service Fulfiller como agente nativo de creación de próxima generación (NGA) desde el script de agente de la plantilla ITSM Fulfiller enviada, utilizando la CLI de Salesforce (sf): lea la plantilla, verifique la idempotencia, cree el paquete NGA, luego publíquelo y actívelo, luego verifique que esté activo. Idempotente por nombre de desarrollador. El agente Fulfiller es el asistente de los técnicos de TI para la clasificación de incidentes, el resumen de casos, las actualizaciones de campo y las automatizaciones de registros relacionados. Úselo cuando se le solicite crear el agente Fulfiller, configurar el agente Fulfiller de servicios de TI, aprovisionar el asistente Fulfiller o activar el agente Fulfiller. Activadores: crear agente de cumplimiento, configurar agente de cumplimiento, aprovisionar agente de cumplimiento, activar agente de cumplimiento. NO ACTIVAR: verificar los requisitos previos de la organización (service-itsm-agentic-setup-agentforce-studio-validate) o CMDB CRUD.
