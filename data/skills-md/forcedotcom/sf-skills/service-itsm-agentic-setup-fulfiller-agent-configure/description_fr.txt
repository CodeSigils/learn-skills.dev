Créez et activez l'agent IT Service Fulfiller en tant qu'agent natif Next-Gen Authoring (NGA) à partir du script d'agent du modèle ITSM Fulfiller fourni, à l'aide de Salesforce CLI (sf) : lisez le modèle, vérifiez l'idempotence, créez le bundle NGA, puis publiez-le et activez-le, puis vérifiez qu'il est en ligne. Idempotent par nom de développeur. L'agent Fulfiller est l'assistant du technicien informatique pour le tri des incidents, la synthèse des cas, les mises à jour sur le terrain et l'automatisation des enregistrements associés. À utiliser lorsqu'on vous demande de créer l'agent Fulfiller, de configurer l'agent Fulfiller de services informatiques, de provisionner l'assistant Fulfiller ou d'activer l'agent Fulfiller. Déclencheurs : créer un agent de traitement, configurer un agent de traitement, mettre à disposition un agent de traitement, activer un agent de traitement. NE PAS DÉCLENCHER : vérification des prérequis de l'organisation (service-itsm-agentic-setup-agentforce-studio-validate) ou CMDB CRUD.
