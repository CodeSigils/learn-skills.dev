Utilice esta habilidad cuando los usuarios necesiten crear, generar o validar metadatos de objetos personalizados de Salesforce. Se activa cuando los usuarios mencionan objetos personalizados, creación de objetos, metadatos de objetos, archivos .object, modelos compartidos, campos de nombres o reglas de validación de objetos. Utilícelo también cuando los usuarios digan cosas como "crear un objeto personalizado", "generar metadatos de objeto", "configurar un objeto para...", o cuando estén solucionando errores de implementación de objetos, especialmente en torno a modelos compartidos y relaciones Maestro-Detalle. Utilice siempre esta habilidad para cualquier trabajo de metadatos de objetos personalizados, incluido enriquecer y mantener actualizada la descripción del objeto cada vez que cambien sus campos o reglas de validación. NO utilice esta habilidad para metadatos que no sean objetos personalizados (Apex, flujos, LWC, conjuntos de permisos, tipos de metadatos personalizados) ni para objetos estándar de Salesforce.
