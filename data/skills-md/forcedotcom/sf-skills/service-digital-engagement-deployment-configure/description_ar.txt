يقوم بتكوين عمليات نشر المراسلة المضمنة للمراسلة داخل التطبيق والويب (MIAW). يُستخدم عندما يحتاج المستخدم إلى إنشاء عملية نشر رسائل مضمنة جديدة من البداية باستخدام Connect API مع الإعدادات الافتراضية، أو تحديث إعدادات النشر الحالية باستخدام Metadata API. يُنتج حمولات طلب Connect API لعمليات النشر الجديدة وبيانات تعريف EmbeddedServiceConfig XML للتحديثات. يتم تشغيله عندما يذكر المستخدم نشر الرسائل المضمنة، أو نشر الخدمة المضمنة، أو نشر MIAW، أو إعداد أداة المراسلة، أو تكوين أداة الدردشة، أو نشر الدردشة المضمنة، أو الإشارة إلى ملف .EmbeddedServiceConfig-meta.xml. لا تقم بالتشغيل عندما يقوم المستخدم بإنشاء قناة مراسلة (استخدم تكوين قناة المشاركة الرقمية للخدمة)، أو تكوين خدمة Live Agent المضمنة القديمة، أو إنشاء مقتطف كود JavaScript لتضمين موقع الويب.
