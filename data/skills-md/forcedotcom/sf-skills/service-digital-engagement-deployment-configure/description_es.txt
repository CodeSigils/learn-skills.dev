Configura implementaciones de mensajería integrada para mensajería en la aplicación y web (MIAW). Úselo cuando el usuario necesite crear una nueva implementación de mensajería integrada desde cero usando Connect API con los valores predeterminados o actualizar la configuración de una implementación existente usando Metadata API. Produce cargas útiles de solicitud de Connect API para nuevas implementaciones y metadatos XML de EmbeddedServiceConfig para actualizaciones. DISPARADOR cuando el usuario menciona la implementación de mensajería integrada, la implementación de servicios integrados, la implementación de MIAW, la configuración del widget de mensajería, la configuración del widget de chat, la implementación del chat integrado o hace referencia a un archivo .EmbeddedServiceConfig-meta.xml. NO DISPARE cuando el usuario esté creando un canal de mensajería (use service-digital-engagement-channel-configure), configurando el servicio integrado de Live Agent heredado o generando el fragmento de código JavaScript para la inserción del sitio web.
