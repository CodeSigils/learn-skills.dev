Messaging for In-App and Web (MIAW) の組み込みメッセージング展開を構成します。ユーザーがデフォルトの Connect API を使用して新しい組み込みメッセージング デプロイメントを最初から作成する必要がある場合、またはメタデータ API を使用して既存のデプロイメントの設定を更新する必要がある場合に使用します。新しいデプロイメント用の Connect API リクエスト ペイロードと更新用の EmbeddedServiceConfig メタデータ XML を生成します。ユーザーが埋め込みメッセージングの展開、埋め込みサービスの展開、MIAW 展開、メッセージング ウィジェットのセットアップ、チャット ウィジェットの構成、埋め込みチャットの展開に言及したとき、または .EmbeddedServiceConfig-meta.xml ファイルを参照したときにトリガーされます。ユーザーがメッセージング チャネルを作成しているとき (service-digital-engagement-channel-configure を使用)、従来の Live Agent 埋め込みサービスを設定しているとき、または Web サイト埋め込み用の JavaScript コード スニペットを生成しているときにはトリガーしないでください。
