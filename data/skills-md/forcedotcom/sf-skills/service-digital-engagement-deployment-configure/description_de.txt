Konfiguriert eingebettete Messaging-Bereitstellungen für Messaging für In-App und Web (MIAW). Verwenden Sie diese Option, wenn der Benutzer mithilfe der Connect-API mit Standardeinstellungen eine neue eingebettete Messaging-Bereitstellung von Grund auf erstellen oder die Einstellungen einer vorhandenen Bereitstellung mithilfe der Metadaten-API aktualisieren muss. Erstellt Connect-API-Anforderungsnutzlasten für neue Bereitstellungen und EmbeddedServiceConfig-Metadaten-XML für Aktualisierungen. TRIGGER, wenn der Benutzer die Bereitstellung eingebetteter Nachrichten, die Bereitstellung eingebetteter Dienste, die MIAW-Bereitstellung, die Einrichtung des Messaging-Widgets, die Konfiguration des Chat-Widgets, die Bereitstellung eingebetteter Chats erwähnt oder auf eine .EmbeddedServiceConfig-meta.xml-Datei verweist. NICHT AUSLÖSEN, wenn der Benutzer einen Nachrichtenkanal erstellt (verwenden Sie service-digital-engagement-channel-configure), den eingebetteten Legacy-Live Agent-Dienst konfiguriert oder das JavaScript-Code-Snippet für die Website-Einbettung generiert.
