Configure les déploiements de messagerie intégrée pour la messagerie pour les applications et le Web (MIAW). À utiliser lorsque l'utilisateur doit créer un nouveau déploiement de messagerie intégrée à partir de zéro à l'aide de l'API Connect avec les valeurs par défaut, ou mettre à jour les paramètres d'un déploiement existant à l'aide de l'API de métadonnées. Produit des charges utiles de demande d'API Connect pour les nouveaux déploiements et des métadonnées XML EmbeddedServiceConfig pour les mises à jour. DÉCLENCHEUR lorsque l'utilisateur mentionne le déploiement de messagerie intégrée, le déploiement de services intégrés, le déploiement MIAW, la configuration du widget de messagerie, la configuration du widget de chat, le déploiement de chat intégré ou fait référence à un fichier .EmbeddedServiceConfig-meta.xml. NE PAS DÉCLENCHER lorsque l'utilisateur crée un canal de messagerie (utilisez service-digital-engagement-channel-configure), configure l'ancien service intégré Live Agent ou génère l'extrait de code JavaScript pour l'intégration de sites Web.
