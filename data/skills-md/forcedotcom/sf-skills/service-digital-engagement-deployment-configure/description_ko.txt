MIAW(앱 내 및 웹용 메시징)에 대한 임베디드 메시징 배포를 구성합니다. 사용자가 Connect API를 기본값으로 사용하여 처음부터 새로운 포함된 메시징 배포를 생성하거나 메타데이터 API를 사용하여 기존 배포 설정을 업데이트해야 하는 경우에 사용합니다. 새로운 배포를 위한 Connect API 요청 페이로드와 업데이트를 위한 EmbeddedServiceConfig 메타데이터 XML을 생성합니다. 사용자가 임베디드 메시징 배포, 임베디드 서비스 배포, MIAW 배포, 메시징 위젯 설정, 채팅 위젯 구성, 임베디드 채팅 배포를 언급하거나 .EmbeddedServiceConfig-meta.xml 파일을 참조하는 경우 트리거됩니다. 사용자가 메시징 채널을 생성하거나(service-digital-engagement-channel-configure 사용) 레거시 Live Agent 포함 서비스를 구성하거나 웹 사이트 포함을 위한 JavaScript 코드 조각을 생성하는 경우에는 트리거하지 마십시오.
