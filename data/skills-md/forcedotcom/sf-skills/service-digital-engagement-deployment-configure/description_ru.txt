Настраивает развертывания встроенных сообщений для обмена сообщениями в приложениях и в Интернете (MIAW). Используйте, когда пользователю необходимо создать новое развертывание встроенного обмена сообщениями с нуля с помощью API Connect со значениями по умолчанию или обновить параметры существующего развертывания с помощью API метаданных. Создает полезные данные запроса API Connect для новых развертываний и XML метаданных EmbeddedServiceConfig для обновлений. ТРИГГЕР, когда пользователь упоминает развертывание встроенного обмена сообщениями, развертывание встроенных служб, развертывание MIAW, настройку виджета обмена сообщениями, конфигурацию виджета чата, развертывание встроенного чата или ссылается на файл .EmbeddedServiceConfig-meta.xml. НЕ ЗАПУСКАЙТЕ, когда пользователь создает канал обмена сообщениями (используйте конфигурацию канала обслуживания-цифрового взаимодействия), настраивает устаревшую встроенную службу Live Agent или генерирует фрагмент кода JavaScript для встраивания на веб-сайт.
