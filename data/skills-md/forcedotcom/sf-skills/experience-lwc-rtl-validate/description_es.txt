Utilice esta habilidad para revisar un componente web Lightning (archivos .html, .js, .css) para verificar la corrección de la internacionalización de derecha a izquierda (RTL), generando una lista de hallazgos con correcciones a nivel de código que cubren propiedades lógicas de CSS, manejo de texto bidireccional, semántica del teclado y uso de clases SLDS compatibles con RTL. DISPARAR cuando el usuario dice "revisar este LWC para RTL", "auditar el cumplimiento de i18n", "arreglar la representación de texto bidireccional", "reemplazar CSS izquierdo/derecho con propiedades lógicas", "verificar problemas de diseño RTL", "verificar clases SLDS RTL", "revisar mi componente para el diseño árabe/hebreo", "asegurarse de que este LWC funcione en configuraciones regionales RTL" o "verificar el manejo de texto bidi". NO DISPARE cuando el usuario esté creando un nuevo LWC (use experiencia-lwc-generate), refactorice las clases SLDS (use design-systems-slds-apply o design-systems-slds2-migrate) o realice una revisión de accesibilidad/seguridad.
