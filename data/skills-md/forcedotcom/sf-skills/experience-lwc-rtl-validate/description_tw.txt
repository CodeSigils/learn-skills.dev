使用此技能檢查 Lightning Web 元件（.html、.js、.css 檔案）的從右到左 (RTL) 國際化正確性，產生包含涵蓋 CSS 邏輯屬性、雙向文字處理、鍵盤語義和 RTL 感知 SLDS 類別使用的程式碼級修復的結果清單。當使用者說「檢查此 LWC 的 RTL」、「審核 i18n 合規性」、「修復雙向文字渲染」、「用邏輯屬性替換左/右 CSS」、「檢查 RTL 佈局問題」、「驗證 SLDS RTL 類別」、「檢查我的元件的阿拉伯語/希伯來文佈局」、「確保此程式設定 LWC 在 RTL環境中在「文字環境」中向文字處理時向文字環境檢查」、「確保資料當使用者建立新的 LWC（使用 experience-lwc-generate）、重構 SLDS 類別本身（使用 design-systems-slds-apply 或 design-systems-slds2-migrate）或執行可存取性/安全審查時，請勿觸發。
