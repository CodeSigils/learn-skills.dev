このスキルを使用して、Lightning Web コンポーネント (.html、.js、.css ファイル) の右から左へ (RTL) 国際化の正確性を確認し、CSS 論理プロパティ、双方向テキスト処理、キーボード セマンティクス、および RTL 対応の SLDS クラスの使用法をカバーするコードレベルの修正を含む結果リストを作成します。ユーザーが「RTL についてこの LWC を確認する」、「i18n 準拠を監査する」、「双方向テキスト レンダリングを修正する」、「左/右 CSS を論理プロパティで置き換える」、「RTL レイアウトの問題を確認する」、「SLDS RTL クラスを確認する」、「アラビア語/ヘブライ語レイアウトのコンポーネントを確認する」、「この LWC が RTL ロケールで動作することを確認する」、または「双方向テキスト処理を確認する」と言った場合にトリガーされます。ユーザーが新しい LWC を構築しているとき (experience-lwc-generate を使用)、SLDS クラス自体をリファクタリングしているとき (design-systems-slds-apply または design-systems-slds2-merge を使用)、またはアクセシビリティ/セキュリティのレビューを実行しているときにはトリガーしないでください。
