Объявленный снимок архитектуры для одного агента Agentforce: планировщик, темы, действия, потоки, Apex, шаблоны приглашений и подключаемые модули NGA. Отрисовывает удобочитаемый архитектурный документ и граф вызовов Mermaid на основе метаданных времени разработки (а не строк аудита времени выполнения). ТРИГГЕР, когда пользователь просит описать, построить диаграмму, провести инвентаризацию, провести аудит, задокументировать или сравнить (например, v3 и v5) архитектуру/дерево действий/структуру темы/инвентаризацию инструментов конкретного агента по имени API агента в конкретной организации. НЕ ИНИЦИРУЙТЕ для трассировок сеансов во время выполнения, расшифровок разговоров, времени генерации или цепочек аудита шлюза — этот навык считывает только метаданные времени разработки (для трассировок сеансов используйте исследовательский агент-d360).
