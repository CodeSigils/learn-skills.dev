하나의 Agentforce 에이전트에 대해 선언된 아키텍처 스냅샷: 플래너, 주제, 작업, 흐름, Apex, 프롬프트 템플릿 및 NGA 플러그인. 디자인 타임 메타데이터(런타임 감사 행 아님)에서 사람이 읽을 수 있는 아키텍처 문서와 Mermaid 호출 그래프를 렌더링합니다. 사용자가 특정 조직의 에이전트 API 이름별로 특정 에이전트의 아키텍처/작업 트리/주제 구조/도구 인벤토리에 대한 설명, 다이어그램, 인벤토리, 감사, 문서 또는 차이점(예: v3 대 v5)을 요청하면 트리거됩니다. 런타임 세션 추적, 대화 기록, 생성 타이밍 또는 게이트웨이 감사 체인에 대해 트리거하지 마십시오. 이 기술은 디자인 타임 메타데이터만 읽습니다(세션 추적에는 조사-agentforce-d360 사용).
