1 つの Agentforce エージェントの宣言されたアーキテクチャ スナップショット: プランナー、トピック、アクション、フロー、Apex、プロンプト テンプレート、NGA プラグイン。人間が判読できるアーキテクチャ ドキュメントとマーメイド呼び出しグラフを、設計時のメタデータ (実行時の監査行ではない) からレンダリングします。ユーザーが、特定の組織内のエージェント API 名による特定のエージェントのアーキテクチャ/アクション ツリー/トピック構造/ツール インベントリの説明、図表、インベントリ、監査、文書化、または差分 (例: v3 と v5) を要求したときにトリガーします。実行時セッション トレース、会話トランスクリプト、生成タイミング、またはゲートウェイ監査チェーンに対してトリガーしないでください。このスキルはデザイン時のメタデータのみを読み取ります (セッション トレースには Investigation-agentforce-d360 を使用します)。
