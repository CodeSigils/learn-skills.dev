قم بإنشاء بيانات تعريف EventSettings لتمكين أو تعطيل تتبع النظام الأساسي (نشر TraceSpanEvent) في مراقبة الأحداث. استخدم هذه المهارة لأي عمل في EventSettings لتمكين البيانات التعريفية لـPlatformTracing. يتم تشغيله عندما: يذكر المستخدم تتبع النظام الأساسي، أو TraceSpanEvent، أو تمكين التتبع في إعدادات مراقبة الأحداث، أو تبديل تتبع مراقبة الأحداث، أو EnablePlatformTracing، أو .settings-meta.xml لتتبع إعدادات الأحداث، أو تشغيل أحداث مدى التتبع، أو إيقاف نشر امتدادات التتبع. لا تقم بالتشغيل عندما: يريد المستخدم تتبع وكيل Agentforce إلى Data Cloud (استخدم تكوين النظام الأساسي للتتبع-agentforce)، أو يريد ملفات سجل الأحداث أو إنشاء ELF، أو يريد تغيير التقاط البيانات (استخدم تكامل الأحداث-cdc-configure)، أو يريد ManagedEventSubscription (استخدم تكوين اشتراك الأحداث التكاملية).
