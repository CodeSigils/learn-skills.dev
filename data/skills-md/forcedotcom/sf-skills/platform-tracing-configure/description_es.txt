Genere metadatos de EventSettings para habilitar o deshabilitar el seguimiento de plataforma (publicación de TraceSpanEvent) en Event Monitoring. Utilice esta habilidad para cualquier trabajo de metadatos de EventSettings enablePlatformTracing. DISPARAR cuando: el usuario menciona el seguimiento de plataforma, TraceSpanEvent, habilitar el seguimiento en la configuración de monitoreo de eventos, alternar el seguimiento de monitoreo de eventos, enablePlatformTracing, .settings-meta.xml para el seguimiento de la configuración de eventos, activar eventos de intervalo de seguimiento o dejar de publicar intervalos de seguimiento. NO DISPARAR cuando: el usuario quiere rastrear el agente de Agentforce hasta Data Cloud (use platform-tracing-agentforce-configure), quiere archivos de registro de eventos o generación ELF, quiere captura de datos modificados (use integración-eventing-cdc-configure) o quiere ManagedEventSubscription (use integración-eventing-subscription-configure).
