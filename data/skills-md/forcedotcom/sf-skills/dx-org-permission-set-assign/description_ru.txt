ВСЕГДА ИСПОЛЬЗУЙТЕ ЭТОТ НАВЫК, чтобы назначать наборы разрешений пользователям организации. Назначьте один или несколько наборов разрешений пользователям организации с помощью команды sf org Assign Permset. ТРИГГЕР, когда пользователь запрашивает назначение, предоставление, добавление или применение наборов разрешений для пользователей, администраторов, определенных организаций или определенных пользователей. Поддерживает предоставление разрешений, предоставление доступа и добавление наборов разрешений администратору по умолчанию или конкретным пользователям через --on-behalf-of. НЕ ЗАПУСКАЙТЕ для вывода списка наборов разрешений или проверки разрешений пользователя.
