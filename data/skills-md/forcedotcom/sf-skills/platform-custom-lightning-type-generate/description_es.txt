Utilice esta habilidad cuando los usuarios necesiten crear tipos de rayos personalizados (CLT) para acciones del Agente de Einstein o esquemas estructurados de entrada/salida. Se activa cuando los usuarios mencionan CLT, tipos de Lightning personalizados, tipos de Lightning personalizados (CLT) con representación/renderizador de widget/mosaico/fragmento, esquemas JSON para agentes, definiciones de tipos, tipo de objeto lightning__ o configuraciones de editor/renderizador. Cuando se solicitan representaciones de widgets, primero DEBE leer el archivo de referencia widget-rendition.md en el directorio references/ de esta habilidad y seguir su flujo de trabajo completo. Esto es complejo: utilice siempre esta habilidad para el trabajo CLT.
