تكوين مصفوفة أولوية الحوادث لـ Salesforce ITSM من خلال sf CLI - تمكين المصفوفة أو تعطيلها، وتشكيل شبكة Impact x Urgency التي تستمد الأولوية في سجلات الحوادث، وتبديل تفضيل التجاوز اليدوي، وقراءة أو تعيين الأولوية الاحتياطية الافتراضية. يقرأ كل قيمة قبل كتابتها، وهو غير قادر على ذلك، ويتطلب تأكيدًا صريحًا من المستخدم قبل أي تغيير. يُستخدم عندما يريد المستخدم عرض تكوين مصفوفة الأولوية أو تمكينه أو تعطيله أو إعداده أو بذره أو إضافته إلى أو تغييره أو إزالته لسجلات الحوادث، أو تغيير أولوية الحادث الافتراضية، أو السؤال عن إعداد أولوية الحادث، أو تعيين التأثير/الاستعجال، أو التجاوز، أو مصفوفة أولوية حادث ITSM. لا تقم بتشغيل مصفوفات أولوية المشكلة أو طلب التغيير، أو حقول أولوية الحالة، أو قوائم اختيار الأولوية القياسية خارج ITSM أو SLA أو تكوين المعالم الرئيسية، أو تمكين إدارة الحوادث نفسها (استخدم مهارة تكوين الخدمة-itsm-incident-mgmt-configure).
