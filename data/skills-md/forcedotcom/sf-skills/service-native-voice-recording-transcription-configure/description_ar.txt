قم بتمكين تسجيل المكالمات ونسخ المكالمات لـ Native Voice (Thunderbird Voice) برمجيًا عبر واجهة برمجة تطبيقات البيانات الوصفية، للحصول على دعم بدون رأس / يعتمد على واجهة برمجة التطبيقات حيث لا يستخدم أي إنسان واجهة مستخدم وحدة تحكم الخدمة. استخدم هذه المهارة عندما يطلب المستخدم تشغيل أو تمكين أو تكوين تسجيل الصوت الأصلي و/أو النسخ للمكالمات الصوتية بدون رأس أو المكالمات الصوتية الآلية. يتم تشغيله عندما: يذكر المستخدمون Thunderbird Voice، أو Native Voice، أو ThunderbirdVoiceSettings، أو EnableCallRecording، أو EnableCallTranscription، أو "تمكين التسجيل والنسخ"، أو "تشغيل تسجيل المكالمات عبر واجهة برمجة التطبيقات"، أو التسجيل الصوتي بدون رأس، أو تكوين التقاط المكالمات الصوتية دون النقر فوق "الإعداد". لا تقم بالتشغيل عندما: يريد المستخدم تنقيح أو مسح معلومات تحديد الهوية الشخصية (PII) من التسجيلات الموجودة، أو نسخ ملف صوتي مزود، أو تأليف Flow/Apex - فهذه خارج نطاق هذه المهارة.
