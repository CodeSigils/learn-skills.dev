メタデータ API を介してプログラムでネイティブ音声 (Thunderbird Voice) の通話録音と通話の文字起こしを有効にし、人間がサービス コンソール UI を使用しないヘッドレス/API 主導のサポートを実現します。このスキルは、ユーザーがヘッドレスまたは自動音声通話のネイティブ音声録音や文字起こしをオン、有効、または構成するように要求した場合に使用します。トリガーされるタイミング: ユーザーが Thunderbird Voice、Native Voice、ThunderbirdVoiceSettings、enableCallRecording、enableCallTranscription、「録音と文字起こしを有効にする」、「API 経由で通話録音をオンにする」、ヘッドレス音声録音、または [セットアップ] をクリックせずに音声通話キャプチャの設定を言及した場合。次の場合にはトリガーしないでください: ユーザーが既存の録音から PII を編集またはスクラブする場合、提供された音声ファイルを文字に起こす場合、または Flow/Apex を作成する場合 - これらはこのスキルの範囲外です。
