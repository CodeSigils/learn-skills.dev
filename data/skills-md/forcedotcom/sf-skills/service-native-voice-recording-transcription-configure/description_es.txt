Habilite la grabación y transcripción de llamadas para Native Voice (Thunderbird Voice) mediante programación a través de la API de metadatos, para soporte sin cabeza/basado en API donde ningún ser humano usa la interfaz de usuario de la Consola de servicio. Utilice esta habilidad cuando un usuario solicite activar, habilitar o configurar la grabación y/o transcripción de Native Voice para llamadas de voz automatizadas o sin cabeza. DISPARAR cuando: los usuarios mencionan Thunderbird Voice, Native Voice, ThunderbirdVoiceSettings, enableCallRecording, enableCallTranscription, 'habilitar grabación y transcripción', 'activar grabación de llamadas a través de API', grabación de voz sin cabeza o configurar la captura de llamadas de voz sin hacer clic en Configuración. NO ACTIVAR cuando: el usuario quiera redactar o eliminar PII de grabaciones existentes, transcribir un archivo de audio proporcionado o crear un Flow/Apex; estos están fuera del alcance de esta habilidad.
