Включите запись вызовов и транскрипцию вызовов для Native Voice (Thunderbird Voice) программно через API метаданных для поддержки без управления или на основе API, когда ни один человек не использует пользовательский интерфейс сервисной консоли. Используйте этот навык, когда пользователь просит включить, активировать или настроить запись и/или транскрипцию собственного голоса для безгласных или автоматических голосовых вызовов. ЗАПУСКАЕТСЯ, когда: пользователи упоминают Thunderbird Voice, Native Voice, ThunderbirdVoiceSettings, EnableCallRecording, EnableCallTranscription, «включить запись и транскрипцию», «включить запись вызовов через API», автономную запись голоса или настройку захвата голосовых вызовов без перехода в настройки. НЕ ЗАПУСКАЙТЕ, когда: пользователь хочет отредактировать или удалить личные данные из существующих записей, расшифровать предоставленный аудиофайл или создать Flow/Apex — это выходит за рамки этого навыка.
