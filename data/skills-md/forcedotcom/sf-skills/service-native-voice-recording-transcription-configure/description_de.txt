Aktivieren Sie die Anrufaufzeichnung und Anruftranskription für Native Voice (Thunderbird Voice) programmgesteuert über die Metadaten-API, für kopflose/API-gesteuerte Unterstützung, bei der kein Mensch die Benutzeroberfläche der Servicekonsole verwendet. Verwenden Sie diesen Skill, wenn ein Benutzer die Aufzeichnung und/oder Transkription von Native Voice für Headless- oder automatisierte Sprachanrufe aktivieren, aktivieren oder konfigurieren möchte. TRIGGER, wenn: Benutzer Thunderbird Voice, Native Voice, ThunderbirdVoiceSettings, enableCallRecording, enableCallTranscription, „Aufzeichnung und Transkription aktivieren“, „Anrufaufzeichnung über API aktivieren“, Headless-Sprachaufzeichnung oder die Konfiguration der Sprachanruferfassung erwähnen, ohne durch Setup zu klicken. NICHT AUSLÖSEN, wenn: der Benutzer personenbezogene Daten aus vorhandenen Aufzeichnungen schwärzen oder entfernen, eine bereitgestellte Audiodatei transkribieren oder einen Flow/Apex erstellen möchte – dies ist für diesen Skill nicht möglich.
