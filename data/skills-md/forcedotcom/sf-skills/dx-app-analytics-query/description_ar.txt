أنواع البيانات التعريفية لـ ISV App Analytics — AppAnalyticsQueryRequest وAppAnalyticsSettings. استخدم هذه المهارة عندما يسأل المستخدم عن استرداد بيانات استخدام الحزمة المُدارة، أو تكوين وضع محاكاة App Analytics، أو الاستعلام عن لقطات المشترك، أو فهم دورة حياة AppAnalyticsQueryRequest (جديد → معلق → مكتمل → منتهي الصلاحية). يتم تشغيله عندما: يذكر المستخدم App Analytics، أو AppAnalyticsQueryRequest، أو AppAnalyticsSettings، أو بيانات استخدام الحزمة، أو تحليلات المشترك، أو تحليلات ISV، أو وضع المحاكاة لتحليلات التطبيق. لا تقم بالتشغيل عندما: تتعلق المهمة بتقارير/لوحات معلومات Salesforce القياسية (استخدم مهارات إعداد التقارير)، أو SOQL المخصص على الحساب/جهة الاتصال (استخدم استعلام النظام الأساسي)، أو استعلام/بحث Data Cloud (استخدم استعلام data360).
