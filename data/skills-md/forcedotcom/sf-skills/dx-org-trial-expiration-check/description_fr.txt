Vérifiez quand les organisations Salesforce expirent (ou ont déjà expiré) et que faire à ce sujet, pour une organisation, l'organisation par défaut ou pour toutes les organisations authentifiées, à l'aide de Salesforce CLI (sf). À utiliser lorsque l'utilisateur pose des questions sur l'expiration de l'organisation ou de l'essai, « quand mon essai expire », « mon organisation d'essai est-elle toujours active », « combien de jours reste-t-il », « quelles organisations expirent bientôt », souhaite filtrer les organisations expirant dans N jours, a besoin d'une sortie lisible par machine (JSON/CSV) pour le cron ou les alertes, souhaite sauvegarder une organisation à risque avant son expiration, ou demande comment prolonger ou renouveler une évaluation expirante ou une organisation Developer Edition. Couvre les éditions d'essai, les organisations Developer Edition (tout ce qui a un TrialExpirationDate) et les organisations scratch (via la liste des organisations sf). NE PAS DÉCLENCHER pour le timing d'actualisation du sandbox, pour la création, la suppression ou le changement d'organisation active, ou pour les essais non-Salesforce tels qu'AWS, Netflix ou d'autres fournisseurs : cette compétence lit l'expiration et imprime les conseils, elle ne modifie pas les organisations.
