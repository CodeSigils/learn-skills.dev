Competenze di creazione di Apex primarie per la generazione, il refactoring e la revisione delle classi. ATTIVARE SEMPRE quando l'utente menziona Apex, .cls, trigger o chiede di creare/refactoring una classe (servizio, selettore, dominio, batch, accodabile, pianificabile, invocabile, DTO, utilità, interfaccia, astratto, eccezione, risorsa REST). Utilizza questa competenza per richieste che coinvolgono SObject CRUD, raccolte di mappature, recupero di record correlati, lavori pianificati, lavori batch, progettazione di trigger, controller @AuraEnabled, endpoint @RestResource, API REST personalizzate o revisione del codice di Apex esistente.
