Salesforce データクラウド取得フェーズ。このスキルは、ユーザーが Data Cloud SQL、非同期クエリ、ベクトル検索、検索インデックス ワークフロー、または Data Cloud オブジェクトのメタデータ イントロスペクションを実行するときに使用します。トリガーのタイミング: ユーザーが Data Cloud SQL、記述、非同期クエリ、ベクトル検索、検索インデックス ワークフロー、または Data Cloud オブジェクトのメタデータ イントロスペクションを実行したとき。次の場合はトリガーしないでください: タスクが標準 CRM SOQL (platform-soql-query を使用)、セグメント作成または計算されたインサイト設計 (data360-segment を使用)、または STDM/セッション トレース/パーケット分析 (agentforce-observe を使用) である場合。
