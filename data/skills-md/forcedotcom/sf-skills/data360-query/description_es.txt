Fase de recuperación de Salesforce Data Cloud. Utilice esta habilidad cuando el usuario ejecute Data Cloud SQL, consultas asíncronas, búsqueda de vectores, flujos de trabajo de índice de búsqueda o introspección de metadatos para objetos de Data Cloud. DISPARAR cuando: el usuario ejecuta Data Cloud SQL, describe, consultas asíncronas, búsqueda de vectores, flujos de trabajo de índice de búsqueda o introspección de metadatos para objetos de Data Cloud. NO ACTIVAR cuando: la tarea es CRM SOQL estándar (use plataforma-soql-query), creación de segmentos o diseño de información calculada (use datos 360-segmento), o STDM/rastreo de sesiones/análisis de parquet (use agentforce-observe).
