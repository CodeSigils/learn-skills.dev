用于通过元数据 API 在无头流中配置 Salesforce 电子邮件转个案。读取当前的 CaseSettings，通过 updateMetadata CRUD 调用应用所需的 emailToCase 配置，并通过重新读取进行验证。也是用户在电子邮件转个案上需要 Agentforce 服务代理时的入口点：此技能配置 E2C 基础，然后委派代理创建和通道连接。即使尚不存在代理，也可以从这里开始。当用户说设置电子邮件转个案、配置电子邮件转个案、启用电子邮件转个案路由地址、添加电子邮件路由地址、电子邮件转个案元数据 API 或使用 Agentforce 服务代理设置电子邮件转个案（将代理附加到电子邮件路由地址）时触发。当用户需要 E2cEasy 地址的交互式服务轻松设置向导时、仅配置按需电子邮件转个案、一般案件对象或网络转个案设置时、或仅创建不涉及电子邮件转个案的 Agentforce 代理时，请勿触发。
