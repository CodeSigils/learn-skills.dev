يُستخدم لتكوين Salesforce Email-to-Case في تدفق بلا رأس عبر واجهة برمجة التطبيقات للبيانات الوصفية. يقرأ CaseSettings الحالي، ويطبق تكوين emailToCase المطلوب مع استدعاء updateMetadata CRUD، ويتحقق من خلال إعادة القراءة. أيضًا نقطة الإدخال عندما يريد المستخدم وكيل خدمة Agentforce على البريد الإلكتروني إلى الحالة: تقوم هذه المهارة بتكوين قاعدة E2C، ثم تفويض إنشاء الوكيل وأسلاك القناة. ابدأ هنا حتى في حالة عدم وجود وكيل حتى الآن. يتم تشغيله عندما يطلب المستخدم إعداد البريد الإلكتروني إلى الحالة، أو تكوين البريد الإلكتروني إلى الحالة، أو تمكين عناوين توجيه البريد الإلكتروني إلى الحالة، أو إضافة عنوان توجيه البريد الإلكتروني، أو واجهة برمجة تطبيقات البيانات التعريفية من البريد الإلكتروني إلى الحالة، أو إعداد البريد الإلكتروني إلى الحالة مع وكيل خدمة Agentforce (إرفاق وكيل بعنوان توجيه البريد الإلكتروني). لا تقم بالتشغيل عندما يحتاج المستخدم إلى معالج Service Easy Setup التفاعلي لعناوين E2cEasy، أو عند تكوين بريد إلكتروني إلى حالة عند الطلب فقط، أو لكائن حالة عام أو إعداد ويب إلى حالة، أو عند إنشاء وكيل Agentforce فقط دون الحاجة إلى إرسال بريد إلكتروني إلى حالة.
