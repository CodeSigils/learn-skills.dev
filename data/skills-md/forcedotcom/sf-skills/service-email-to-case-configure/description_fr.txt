Utilisez-le pour configurer Salesforce Email-to-Case dans un flux sans tête via l'API de métadonnées. Lit les CaseSettings actuels, applique la configuration emailToCase souhaitée avec l'appel updateMetadata CRUD et vérifie en relisant. Egalement le point d'entrée lorsque l'utilisateur souhaite un agent de service Agentforce sur Email-to-Case : cette compétence configure la base E2C, puis délègue la création des agents et le câblage des canaux. Commencez ici même si aucun agent n’existe encore. DÉCLENCHEMENT lorsque l'utilisateur indique configurer l'e-mail vers la requête, configurer l'e-mail vers la requête, activer les adresses de routage de l'e-mail vers la requête, ajouter une adresse de routage de l'e-mail, l'API de métadonnées de l'e-mail vers la requête ou configurer l'e-mail vers la requête avec un agent de service Agentforce (attacher un agent à une adresse de routage de l'e-mail). NE PAS DÉCLENCHER lorsque l'utilisateur a besoin de l'assistant interactif de configuration de Service Easy pour les adresses E2cEasy, lors de la configuration de l'e-mail vers requête à la demande uniquement, pour la configuration générale d'un objet de requête ou du Web vers requête, ou lors de la création uniquement d'un agent Agentforce sans e-mail vers requête impliqué.
