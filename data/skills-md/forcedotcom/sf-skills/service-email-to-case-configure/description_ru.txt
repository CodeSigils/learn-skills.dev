Используйте для настройки Salesforce Email-to-Case в автономном потоке через API метаданных. Считывает текущие настройки CaseSettings, применяет нужную конфигурацию emailToCase с помощью CRUD-вызова updateMetadata и проверяет путем повторного чтения. Также точка входа, когда пользователю нужен агент службы Agentforce для Email-to-Case: этот навык настраивает базу E2C, затем делегирует создание агента и подключение каналов. Начните здесь, даже если агента еще не существует. ТРИГГЕР, когда пользователь говорит: «Настройте отправку электронной почты в дело», настройте отправку электронной почты в дело, включите адреса маршрутизации электронной почты, добавьте адрес маршрутизации электронной почты, API метаданных «электронная почта в дело» или настройте «электронную почту в дело» с помощью агента службы Agentforce (прикрепите агента к адресу маршрутизации электронной почты). НЕ ЗАПУСКАЙТЕ, когда пользователю нужен интерактивный мастер простой настройки служб для адресов E2cEasy, при настройке только электронной почты по требованию, для общего объекта дела или настройки веб-обращения, а также при создании только агента Agentforce без участия электронной почты в обращение.
