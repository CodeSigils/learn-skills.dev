Úselo para configurar el correo electrónico para casos de Salesforce en un flujo sin cabeza a través de la API de metadatos. Lee los CaseSettings actuales, aplica la configuración emailToCase deseada con la llamada CRUD updateMetadata y lo verifica volviendo a leer. También es el punto de entrada cuando el usuario desea un agente de servicio de Agentforce en Correo electrónico para caso: esta habilidad configura la base E2C y luego delega la creación de agentes y el cableado de canales. Comience aquí incluso cuando todavía no exista ningún agente. DISPARAR cuando el usuario dice configurar Correo electrónico para casos, configurar correo electrónico para casos, habilitar direcciones de enrutamiento de Correo electrónico para casos, agregar una dirección de enrutamiento de correo electrónico, API de metadatos de Correo electrónico para casos o configurar Correo electrónico para casos con un agente de servicio de Agentforce (adjunte un agente a una dirección de enrutamiento de correo electrónico). NO ACTIVAR cuando el usuario necesite el asistente interactivo de Configuración fácil de servicio para direcciones E2cEasy, cuando configure solo Correo electrónico para caso bajo demanda, para objetos de caso generales o configuración de caso web, o cuando solo cree un agente de Agentforce sin Correo electrónico para caso involucrado.
