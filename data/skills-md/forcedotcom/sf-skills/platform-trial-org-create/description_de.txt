Verwenden Sie diesen Skill, um eine Salesforce-Testversion, einen Entwickler oder eine Trialforce-Organisation für eine bereits authentifizierte Hostorganisation zu erstellen, genauso wie ein Web-Anmeldeformular für Entwickler/Trialforce eine solche bereitstellt. INVOKE, wenn der Benutzer Folgendes auffordert: eine Testorganisation erstellen, eine neue Test- oder Entwicklerorganisation registrieren, eine Trialforce-Organisation aus einer Vorlage bereitstellen oder den Status einer von ihm gestarteten Registrierung für eine Testorganisation überprüfen. Auslöserphrasen: „Testorganisation erstellen“, „Testorganisation anmelden“, „Entwicklerorganisation eröffnen“, „Trialforce-Anmeldung“, „Testversion aus Vorlage bereitstellen“, „Anmeldestatus meiner Testorganisation prüfen“. NICHT für Testorganisationen (verwenden Sie dx-org-manage) oder zum Überprüfen der Testablaufdaten bestehender Organisationen (verwenden Sie dx-org-trial-expiration-check) verwenden.
