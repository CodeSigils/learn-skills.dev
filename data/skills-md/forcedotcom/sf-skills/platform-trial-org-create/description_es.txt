Utilice esta habilidad para crear una prueba, desarrollador u organización de Trialforce de Salesforce contra una organización anfitriona ya autenticada, de la misma manera que un formulario de registro web de desarrollador/Trialforce aprovisiona uno. INVOCAR cuando el usuario solicite: crear una organización de prueba, registrar una nueva organización de prueba o de desarrollador, aprovisionar una organización de Trialforce a partir de una plantilla o verificar el estado de un registro de organización de prueba que inició. Frases de activación: 'crear una organización de prueba', 'registrar una organización de prueba', 'activar una organización de desarrollo', 'registro en Trialforce', 'proporcionar prueba desde plantilla', 'verificar el estado de registro de mi organización de prueba'. NO lo use para organizaciones borrador (use dx-org-manage) ni para verificar las fechas de vencimiento de las pruebas de organizaciones existentes (use dx-org-trial-expiration-check).
