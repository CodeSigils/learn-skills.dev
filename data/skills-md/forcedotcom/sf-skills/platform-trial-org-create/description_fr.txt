Utilisez cette compétence pour créer une organisation d'essai, de développeur ou Trialforce Salesforce sur une organisation hôte déjà authentifiée, de la même manière qu'un formulaire d'inscription Web de développeur/Trialforce en fournit une. INVOKE lorsque l'utilisateur demande : créer une organisation d'essai, inscrire une nouvelle organisation d'essai ou de développement, provisionner une organisation Trialforce à partir d'un modèle ou vérifier l'état d'une inscription à une organisation d'essai qu'il a démarrée. Phrases de déclenchement : « créer une organisation d'essai », « inscrire une organisation d'essai », « lancer une organisation de développement », « inscription à Trialforce », « fournir un essai à partir d'un modèle », « vérifier le statut d'inscription de mon organisation d'essai ». Ne PAS utiliser pour les organisations scratch (utilisez dx-org-manage) ou pour vérifier les dates d'expiration des essais d'organisations existantes (utilisez dx-org-trial-expiration-check).
