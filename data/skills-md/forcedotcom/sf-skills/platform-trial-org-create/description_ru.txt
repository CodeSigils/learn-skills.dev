Используйте этот навык для создания пробной версии, разработчика или организации Trialforce для уже проверенной хост-организации точно так же, как это делается в веб-форме регистрации разработчика/Trialforce. ВЫЗЫВАЙТЕ, когда пользователь запрашивает: создать пробную организацию, зарегистрировать новую пробную организацию или организацию разработчиков, предоставить организацию Trialforce из шаблона или проверить статус начатой ​​им регистрации пробной организации. Триггерные фразы: «создать пробную организацию», «зарегистрировать пробную организацию», «раскрутить организацию разработки», «регистрация Trialforce», «предоставить пробную версию из шаблона», «проверить статус регистрации моей пробной организации». НЕ используйте для пустых организаций (используйте dx-org-manage) или для проверки дат истечения срока действия пробной версии существующих организаций (используйте dx-org-trial-expiration-check).
