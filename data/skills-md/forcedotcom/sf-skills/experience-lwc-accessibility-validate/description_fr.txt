Utilisez cette compétence pour déterminer si un composant Web Lightning (LWC) est accessible et répond aux directives d'accessibilité WCAG. DÉCLENCHEMENT lorsque l'utilisateur demande « mon composant est-il accessible ? », « mon LWC est-il conforme aux directives d'accessibilité ? », « ce composant est-il conforme aux WCAG ? », « rechercher des problèmes d'accessibilité dans ce LWC », « ce clavier LWC est-il accessible ? Déclenchez également lorsque l'utilisateur souhaite corriger ou améliorer l'accessibilité (a11y, WCAG, ARIA) dans le HTML, JS ou CSS d'un LWC : balisage sémantique, focus, navigation au clavier, contraste, étiquettes de lecteur d'écran, WCAG 2.2 SC. Produit « a11y-review.md » avec les résultats cités par les WCAG. NE PAS DÉCLENCHER pour la génération générale de LWC (utilisez « experience-lwc-generate ») ou pour la révision visuelle/de conception SLDS non axée sur l'accessibilité (utilisez « design-systems-slds-validate »).
