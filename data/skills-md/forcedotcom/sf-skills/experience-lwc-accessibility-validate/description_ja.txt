このスキルを使用して、Lightning Web コンポーネント (LWC) がアクセス可能かどうか、および WCAG アクセシビリティガイドラインを満たしているかどうかを判断します。ユーザーが「コンポーネントはアクセシビリティ可能ですか?」、「LWC はアクセシビリティ ガイドラインを満たしていますか?」、「このコンポーネントは WCAG に準拠していますか?」、「この LWC でアクセシビリティの問題を見つけます」、「この LWC キーボードはアクセシビリティ可能ですか?」、「このコンポーネントはスクリーン リーダーで動作しますか?」、「このコンポーネントには十分な色のコントラストがありますか?」、「この LWC での ARIA の使用状況を確認してください」、または「WCAG 2.2 アクセシビリティ チェック」を尋ねたときにトリガーされます。また、ユーザーが LWC の HTML、JS、または CSS (セマンティック マークアップ、フォーカス、キーボード ナビゲーション、コントラスト、スクリーン リーダー ラベル、WCAG 2.2 SC) のアクセシビリティ (a11y、WCAG、ARIA) を修正または改善したい場合にもトリガーされます。 WCAG が引用した調査結果を含む「a11y-review.md」を作成します。一般的な LWC 生成 (` experience-lwc-generate` を使用) や、アクセシビリティに焦点を当てていない SLDS のビジュアル/デザイン レビュー (`design-systems-slds-validate` を使用) についてはトリガーしないでください。
