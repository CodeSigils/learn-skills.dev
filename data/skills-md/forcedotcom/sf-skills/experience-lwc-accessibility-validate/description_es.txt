Utilice esta habilidad para determinar si un componente web Lightning (LWC) es accesible y cumple con las pautas de accesibilidad WCAG. TRIGGER cuando el usuario pregunta "¿es accesible mi componente?", "¿mi LWC cumple con las pautas de accesibilidad?", "¿este componente cumple con las WCAG?", "encontrar problemas de accesibilidad en este LWC", "¿es accesible este teclado de LWC?", "¿este componente funciona con un lector de pantalla?", "¿este componente tiene suficiente contraste de color?", "verifica el uso de ARIA en este LWC" o "verificación de accesibilidad WCAG 2.2". También DISPARA cuando el usuario desea corregir o mejorar la accesibilidad (a11y, WCAG, ARIA) en HTML, JS o CSS de un LWC: marcado semántico, enfoque, navegación por teclado, contraste, etiquetas de lector de pantalla, WCAG 2.2 SC. Produce `a11y-review.md` con los hallazgos citados por las WCAG. NO DISPARAR para la generación general de LWC (use `experience-lwc-generate`) o revisión visual/de diseño de SLDS que no se centre en la accesibilidad (use `design-systems-slds-validate`).
