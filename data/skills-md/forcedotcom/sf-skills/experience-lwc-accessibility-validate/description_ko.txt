이 기술을 사용하여 LWC(Lightning 웹 구성 요소)에 액세스할 수 있고 WCAG 접근성 지침을 충족하는지 확인합니다. 사용자가 "내 구성 요소에 액세스할 수 있습니까?", "내 LWC가 접근성 지침을 충족합니까?", "이 구성 요소가 WCAG를 준수합니까?", "이 LWC에서 접근성 문제를 찾습니다", "이 LWC 키보드에 액세스할 수 있습니까?", "이 구성 요소가 화면 판독기와 작동합니까?", "이 구성 요소의 색상 대비가 충분합니까?", "이 LWC에서 ARIA 사용을 확인하세요" 또는 "WCAG 2.2 접근성 확인"이라고 물을 때 TRIGGER입니다. 또한 사용자가 LWC의 HTML, JS 또는 CSS(의미 체계 마크업, 포커스, 키보드 탐색, 대비, 화면 판독기 레이블, WCAG 2.2 SC)의 접근성(a11y, WCAG, ARIA)을 수정하거나 개선하려는 경우에도 트리거됩니다. WCAG에서 인용한 연구 결과로 'a11y-review.md'를 생성합니다. 일반 LWC 생성(`experience-lwc-generate` 사용) 또는 접근성에 초점을 맞추지 않은 SLDS 시각적/디자인 검토(`design-systems-slds-validate` 사용)에는 트리거하지 마세요.
