Используйте этот навык, чтобы определить, доступен ли веб-компонент Lightning (LWC) и соответствует ли он рекомендациям WCAG по доступности. TRIGGER, когда пользователь спрашивает: «Доступен ли мой компонент?», «Соответствует ли мой LWC рекомендациям по доступности?», «Этот компонент соответствует WCAG?», «Найти проблемы доступности в этом LWC», «Доступна ли эта клавиатура LWC?», «Работает ли этот компонент со программой чтения с экрана?», «Обладает ли этот компонент достаточным цветовым контрастом?», «Проверьте использование ARIA в этом LWC» или «Проверка доступности WCAG 2.2». Также TRIGGER, когда пользователь хочет исправить или улучшить специальные возможности (a11y, WCAG, ARIA) в HTML, JS или CSS LWC — семантическая разметка, фокус, навигация по клавиатуре, контрастность, метки средства чтения с экрана, WCAG 2.2 SC. Создает `a11y-review.md` с выводами, цитируемыми WCAG. НЕ ИНИЦИРУЙТЕ для общей генерации LWC (используйте `experience-lwc-generate`) или визуальной/проектной проверки SLDS, не ориентированной на доступность (используйте `design-systems-slds-validate`).
