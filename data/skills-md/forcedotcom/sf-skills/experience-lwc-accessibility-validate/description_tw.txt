使用此技能可以確定 Lightning Web 元件 (LWC) 是否可存取並符合 WCAG 可存取性準則。當使用者詢問「我的元件是否可存取？」、「我的 LWC 是否符合可訪問性準則？」、「此元件是否符合 WCAG 要求？」、「在此 LWC 中尋找可存取性問題」、「此 LWC 鍵盤是否可存取？」、「此元件是否可與螢幕閱讀器元件使用 ARD 、「此元件」可訪問性檢查”時觸發。當使用者想要修復或改進 LWC 的 HTML、JS 或 CSS 中的可訪問性（a11y、WCAG、ARIA）時也會觸發 - 語義標記、焦點、鍵盤導航、對比度、螢幕閱讀器標籤、WCAG 2.2 SC。產生包含 WCAG 引用的調查結果的「a11y-review.md」。不要觸發一般 LWC 生成（使用“experience-lwc-generate”）或不關注可訪問性的 SLDS 視覺/設計審核（使用“design-systems-slds-validate”）。
