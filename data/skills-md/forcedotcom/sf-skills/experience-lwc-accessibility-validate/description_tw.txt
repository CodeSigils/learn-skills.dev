使用此技能可以確定 Lightning Web 元件 (LWC) 是否可存取並符合 WCAG 可存取性準則。当用户询问“我的组件是否可访问？”、“我的 LWC 是否符合可访问性准则？”、“此组件是否符合 WCAG 要求？”、“在此 LWC 中查找可访问性问题”、“此 LWC 键盘是否可访问？”、“此组件是否可与屏幕阅读器配合使用？”、“此组件是否具有足够的颜色对比度？”、“检查此 LWC 中的 ARIA 使用情况”或“WCAG 2.2 可访问性检查”时触发。当用户想要修复或改进 LWC 的 HTML、JS 或 CSS 中的可访问性（a11y、WCAG、ARIA）时也会触发 - 语义标记、焦点、键盘导航、对比度、屏幕阅读器标签、WCAG 2.2 SC。產生包含 WCAG 引用的調查結果的「a11y-review.md」。不要触发一般 LWC 生成（使用“experience-lwc-generate”）或不关注可访问性的 SLDS 视觉/设计审核（使用“design-systems-slds-validate”）。
