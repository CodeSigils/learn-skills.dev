Examinez un composant Web Lightning pour vérifier sa compatibilité **mobile hors ligne** : l'analyseur statique hors ligne Komaci qui prépare le graphique de données pour Salesforce Mobile App Plus et Field Service Mobile App. Produit une liste de résultats avec des correctifs au niveau du code couvrant les requêtes GraphQL en ligne dans les configurations `@wire`, les directives modernes `lwc:if` / `lwc:elseif` / `lwc:else` et les violations des règles Komaci ESLint (propriétés de fil privées, références réactives non locales, effets secondaires du getter). À utiliser lorsque l'utilisateur demande un « examen mobile hors ligne », une « vérification Komaci », un « audit d'amorçage hors ligne », un « échec d'amorçage hors ligne » ou une « erreur de graphique de données hors ligne », ou pour valider un LWC par rapport à l'ensemble de règles recommandé « @salesforce/eslint-plugin-lwc-graph-analyzer ». Ne pas utiliser pour la révision du code LWC générique (utilisez une compétence de révision de domaine appropriée) ou pour créer des LWC avec des capacités mobiles natives (utilisez « using-mobile-native-capabilities »).
