استخدم هذه المهارة دائمًا لأي شيء يتضمن أرشيف Salesforce (يُسمى أيضًا أرشيف الخدمات الموثوقة) - البحث عن السجلات المؤرشفة وعرضها وإلغاء أرشفتها وتحليلها وإخفائها ومسحها (RTBF) عبر واجهة برمجة تطبيقات Archive Connect، وقراءة حالة مهمة الأرشيف من كائن ArchiveActivity. يتم تشغيله عندما: يذكر المستخدم أرشيف Salesforce، أو أرشيف الخدمات الموثوقة، أو سجلات الأرشفة/إلغاء الأرشفة، أو نشاط الأرشيف، أو وظائف الأرشيف، أو سياسة الأرشيف، أو محلل الأرشيف، أو البحث عن السجلات المؤرشفة، أو تخزين الأرشيف، أو سجلات فشل الأرشيف، أو الحق في النسيان / RTBF على البيانات المؤرشفة، أو إخفاء معلومات تحديد الهوية الشخصية المؤرشفة - بما في ذلك عبارات مثل "العثور على السجلات التي تم أرشفتها"، أو "استعادة البيانات المؤرشفة"، أو "لماذا فشلت مهمة الأرشيف"، أو "فشل تنزيل الأرشيف" log"، أو "مراقبة وظائف الأرشيف الخاصة بي"، وحتى عندما يطلبون منك شرحًا أو تقديم إرشادات أو كتابة دليل تشغيل/مستند حول هذه المواضيع بدلاً من تشغيل التعليمات البرمجية. تخطي عندما: يريد المستخدم تصدير/نسخ احتياطي عام للبيانات لا علاقة له بالوظيفة الإضافية للأرشيف، أو يريد إنشاء بيانات تعريفية لواجهة مستخدم سياسة الأرشيف.
