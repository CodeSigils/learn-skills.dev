ВСЕГДА ИСПОЛЬЗУЙТЕ ЭТОТ НАВЫК для всего, что связано с архивом Salesforce (также называемым архивом доверенных служб) — поиск, просмотр, разархивирование, анализ, маскирование и стирание (RTBF) архивных записей через API Archive Connect, а также чтение состояния задания архивирования из объекта ArchiveActivity. ТРИГГЕР, когда: пользователь упоминает архив Salesforce, архив Trusted Services, записи архивирования/разархивирования, ArchiveActivity, задания архивирования, политику архивирования, анализатор архива, поиск архивных записей, хранилище архивов, журналы сбоев архивов, право на забвение / RTBF для архивных данных или маскирование архивных личных данных, включая такие фразы, как «найти записи, которые были заархивированы», «восстановить архивные данные», «почему задание архивирования завершилось неудачно», «загрузить журнал сбоев архива», или «отслеживать мои задания по архивированию», И даже когда вас просят объяснить, дать рекомендации или написать книгу/документ по этим темам, а не запускать код. ПРОПУСКАЙТЕ, когда: пользователю нужен общий экспорт/резервное копирование данных, не связанное с надстройкой «Архив», или он хочет создать метаданные пользовательского интерфейса политики архивирования.
