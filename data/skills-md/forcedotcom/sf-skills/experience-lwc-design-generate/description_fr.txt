À utiliser lorsque vous devez créer un tout nouveau composant Web Lightning à partir d'une conception Figma, d'un document d'exigences de produit ou d'un autre artefact de conception - en orchestrant le flux de travail en cinq phases (rassembler les exigences → générer du code → optimiser → lint/format/compiler → tester) et assembler les compétences spécialisées pour SLDS, LDS, les composants de base, l'optimisation et les tests. Utilisez cette compétence chaque fois que l'utilisateur mentionne la création d'un nouveau LWC à partir de Figma, la création d'un LWC à partir d'un PRD, la génération d'un LWC à partir d'une conception ou d'une capture d'écran, ou la migration d'un composant Aura en tant que nouvelle version de LWC. NE PAS DÉCLENCHER lors de la refactorisation d'un LWC existant (utilisez experience-lwc-generate), pour la migration sur place Aura → LWC (hors de portée de cette compétence), pour un jeton SLDS autonome ou un travail de style (utilisez design-systems-slds-apply) ou pour un travail de couche de données autonome (utilisez experience-lds-best-practices-apply ou experience-lds-data-requirements-generate).
