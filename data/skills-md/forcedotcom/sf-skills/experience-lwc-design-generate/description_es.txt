Úselo cuando necesite crear un nuevo componente web Lightning a partir de un diseño de Figma, un documento de requisitos de producto u otro artefacto de diseño, orquestando el flujo de trabajo de cinco fases (reunir requisitos → generar código → optimizar → pelusa/formato/compilar → probar) y unir las habilidades especializadas para SLDS, LDS, componentes base, optimización y pruebas. Utilice esta habilidad siempre que el usuario mencione la creación de un nuevo LWC desde Figma, la creación de un LWC a partir de un PRD, la generación de un LWC a partir de un diseño o una captura de pantalla, o la migración de un componente de Aura como una nueva compilación de LWC. NO DISPARE al refactorizar un LWC existente (use experiencia-lwc-generate), para la migración in situ de Aura → LWC (fuera del alcance de esta habilidad), para token SLDS independiente o trabajo de estilo (use design-systems-slds-apply), o para trabajo de capa de datos independiente (use experiencia-lds-best-practices-apply o experiencia-lds-data-requirements-generate).
