استخدمه عندما تحتاج إلى إنشاء Lightning Web Component جديد تمامًا من تصميم Figma، أو مستند متطلبات المنتج، أو أي عنصر تصميم آخر - تنسيق سير العمل على خمس مراحل (جمع المتطلبات ← إنشاء التعليمات البرمجية ← التحسين ← الوبر/التنسيق/الترجمة ← الاختبار) وتجميع المهارات المتخصصة لـ SLDS وLDS والمكونات الأساسية والتحسين والاختبار. استخدم هذه المهارة عندما يذكر المستخدم بناء LWC جديد من Figma، أو إنشاء LWC من PRD، أو إنشاء LWC من تصميم أو لقطة شاشة، أو ترحيل مكون Aura كبناء LWC جديد. لا تقم بالتشغيل عند إعادة هيكلة LWC موجودة (استخدم إنشاء الخبرة-lwc)، أو الترحيل الموضعي لـ Aura → LWC (خارج نطاق هذه المهارة)، أو لرمز SLDS المستقل أو عمل التصميم (استخدم تطبيق أنظمة التصميم-slds)، أو لعمل طبقة البيانات المستقلة (استخدم تطبيق الخبرة-lds-أفضل-الممارسات أو إنشاء متطلبات-الخبرة-lds).
