使用 Salesforce CLI (sf) 验证履行者或员工代理的 Agentforce for IT 服务先决条件。只读先决条件检查：它通过一次 Connect API 调用读取 Agentforce for IT 服务设置页面（Agentforce Studio、IT 服务履行者/IT 服务员工模板、员工专用代理模板）后面的 Salesforce Go 功能切换，然后帮助程序脚本将所选路径分类为就绪/未就绪判定。它永远不会启用任何东西；当开关关闭时，它会将其交给agentforce-studio-configure 技能来将其打开。当要求检查 Agentforce 先决条件、验证组织是否已准备好使用 ITSM 代理或验证 Agentforce Studio 是否已启用时使用。触发器：检查agentforce先决条件，验证agentforce准备情况，我的组织是否已准备好使用履行者代理，验证agentforce工作室已启用。请勿触发：启用或打开开关、创建履行代理 (service-itsm-agentic-setup-fulfiller-agent-configure) 或 CMDB CRUD。
