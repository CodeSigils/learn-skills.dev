Validez les prérequis d'Agentforce for IT Service pour un agent Fulfiller ou Employee, à l'aide de Salesforce CLI (sf). La vérification des prérequis en LECTURE SEULE : elle lit la fonctionnalité Salesforce Go qui bascule derrière la page de configuration d'Agentforce pour le service informatique (Agentforce Studio, les modèles IT Service Fulfiller/IT Service Employee, Specialized Agent Templates for Employee) via un appel d'API Connect, puis un script d'assistance classe le chemin choisi dans un verdict PRÊT/NON PRÊT. Cela ne permet jamais rien ; lorsqu'une bascule est désactivée, elle est confiée à la compétence agentforce-studio-configure pour l'activer. À utiliser lorsqu'on vous demande de vérifier les prérequis d'Agentforce, de valider que l'organisation est prête pour un agent ITSM ou de vérifier qu'Agentforce Studio est activé. Déclencheurs : vérifier les prérequis d'Agentforce, valider l'état de préparation d'Agentforce, mon organisation est-elle prête pour l'agent de réalisation, vérifier que Agentforce Studio est activé. NE PAS DÉCLENCHER : activation ou activation des bascules, création de l'agent de réalisation (service-itsm-agentic-setup-fulfiller-agent-configure) ou CMDB CRUD.
