Salesforce CLI(sf)를 사용하여 Fulfiller 또는 Employee 에이전트에 대한 Agentforce for IT 서비스 전제 조건을 검증합니다. 읽기 전용 전제 조건 확인: 한 번의 Connect API 호출을 통해 Agentforce for IT 서비스 설정 페이지(Agentforce Studio, IT 서비스 이행자/IT 서비스 직원 템플릿, 직원용 전문 에이전트 템플릿) 뒤의 Salesforce Go 기능 토글을 읽은 다음 도우미 스크립트가 선택한 경로를 준비/준비 안 됨 판정으로 분류합니다. 그것은 결코 아무것도 가능하게 하지 않습니다. 토글이 꺼져 있으면 이를 켜기 위해 Agentforce-studio-configure 기술로 전달됩니다. Agentforce 전제 조건을 확인하거나, 조직이 ITSM 에이전트에 대해 준비가 되었는지 확인하거나, Agentforce Studio가 활성화되었는지 확인하라는 메시지가 표시될 때 사용합니다. 트리거: Agentforce 전제 조건 확인, AgentForce 준비 상태 확인, 내 조직이 이행자 에이전트에 대한 준비가 되었는지, AgentForce Studio가 활성화되었는지 확인합니다. 트리거하지 마세요: 토글 활성화 또는 켜기, 이행자 에이전트 생성(service-itsm-agentic-setup-fulfiller-agent-configure) 또는 CMDB CRUD.
