Salesforce CLI (sf) を使用して、履行者エージェントまたは従業員エージェントの Agentforce for IT サービスの前提条件を検証します。読み取り専用の前提条件チェック: 1 回の Connect API 呼び出しを介して、Agentforce for IT サービス設定ページ (Agentforce Studio、IT サービス フルフィラー / IT サービス従業員テンプレート、従業員用の特殊なエージェント テンプレート) の背後にある Salesforce Go 機能の切り替えを読み取り、ヘルパー スクリプトによって、選択されたパスが READY / NOT-READY の判定に分類されます。それは決して何も可能にはしません。トグルがオフの場合は、agentforce-studio-configure スキルに渡してオンにします。 Agentforce の前提条件を確認するか、ITSM エージェントに対して組織の準備ができているかを検証するか、Agentforce Studio が有効であることを確認するように求められた場合に使用します。トリガー: Agentforce の前提条件を確認し、Agentforce の準備が整っているかどうかを検証し、組織でフルフィルラー エージェントの準備ができているか、Agentforce Studio が有効になっていることを確認します。トリガーしないでください: トグルを有効またはオンにする、フルフィルラー エージェント (service-itsm-agentic-setup-fulfiller-agent-configure) または CMDB CRUD を作成します。
