使用 Salesforce CLI (sf) 驗證履行者或員工代理程式的 Agentforce for IT 服務先決條件。只讀先決條件檢查：它透過一次 Connect API 呼叫讀取 Agentforce for IT 服務設定頁面（Agentforce Studio、IT 服務履行者/IT 服務員工範本、員工專用代理範本）後面的 Salesforce Go 功能切換，然後幫助程式腳本將所選路徑分類為就緒/未就緒判定。它永遠不會啟用任何東西；當開關關閉時，它會將其交給agentforce-studio-configure 技能來將其打開。當要求檢查 Agentforce 先決條件、驗證組織是否已準備好使用 ITSM 代理程式或驗證 Agentforce Studio 是否已啟用時使用。觸發器：檢查agentforce先決條件，驗證agentforce準備情況，我的組織是否已準備好使用履行者代理，驗證agentforce工作室已啟用。請勿觸發：啟用或開啟開關、建立履行代理程式 (service-itsm-agentic-setup-fulfiller-agent-configure) 或 CMDB CRUD。
