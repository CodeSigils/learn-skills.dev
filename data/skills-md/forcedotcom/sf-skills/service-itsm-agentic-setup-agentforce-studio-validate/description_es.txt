Valide los requisitos previos del servicio Agentforce for IT para un agente de cumplimiento o empleado mediante la CLI de Salesforce (sf). La verificación de requisitos previos de SOLO LECTURA: lee la función Salesforce Go y alterna detrás de la página de configuración de Agentforce para servicios de TI (Agentforce Studio, las plantillas de cumplimiento de servicios de TI/empleado de servicios de TI, plantillas de agentes especializados para empleados) a través de una llamada API de Connect, luego un script de ayuda clasifica la ruta elegida en un veredicto LISTO/NO LISTO. Nunca permite nada; cuando un interruptor está desactivado, lo pasa a la habilidad de configuración de Agentforce-Studio para activarlo. Úselo cuando se le solicite verificar los requisitos previos de Agentforce, validar que la organización esté lista para un agente ITSM o verificar que Agentforce Studio esté habilitado. Activadores: verificar los requisitos previos de Agentforce, validar la preparación de Agentforce, si mi organización está lista para el agente de cumplimiento, verificar que Agentforce Studio esté habilitado. NO DISPARAR: habilitar o activar los conmutadores, crear el agente de cumplimiento (service-itsm-agentic-setup-fulfiller-agent-configure) o CMDB CRUD.
