مرحلة قطاع سحابة بيانات Salesforce. استخدم هذه المهارة عندما يقوم المستخدم بإنشاء شرائح أو نشرها، أو إدارة الرؤى المحسوبة، أو استكشاف أخطاء SQL الخاصة بالجمهور وإصلاحها في Data Cloud. يتم تشغيله عندما: يقوم المستخدم بإنشاء شرائح أو نشرها، أو إدارة الرؤى المحسوبة، أو فحص أعداد الشرائح أو العضوية، أو استكشاف أخطاء SQL الخاصة بالجمهور وإصلاحها في Data Cloud. لا تقم بالتشغيل عندما: تكون المهمة عبارة عن عمل DMO/رسم الخرائط/تحليل الهوية (استخدم تنسيق datacloud)، أو عمل التنشيط (استخدم activating-datacloud)، أو عمل الاستعلام/فهرس البحث (استخدم استرداد datacloud)، أو نموذج البيانات القياسي (STDM)/تتبع الجلسة (استخدم قوة وكيل المراقبة).
