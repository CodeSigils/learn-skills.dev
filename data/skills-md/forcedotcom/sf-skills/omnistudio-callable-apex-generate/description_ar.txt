Salesforce Industries Common Core (OmniStudio/Vlocity) مهارة إنشاء ومراجعة Apex القابلة للاستدعاء مع تسجيل 120 نقطة. يُستخدم عند إنشاء تطبيقات Apex القابلة للاستدعاء للصناعات أو مراجعتها أو ترحيلها. يتم تشغيله عندما: يقوم المستخدم بإنشاء فئات System.Callable أو مراجعتها، أو ترحيل VlocityOpenInterface أو VlocityOpenInterface2، أو إنشاء ملحقات قابلة للاستدعاء للصناعات تستخدم بواسطة OmniStudio، أو Integration إجراءات، أو DataRaptors. لا تقم بالتشغيل عندما: فئات أو مشغلات Apex عامة (استخدم إنشاء منصة أبيكس)، أو بناء إجراءات التكامل (استخدم omnistudio-integration-procedure-generate)، أو تأليف OmniScripts (استخدم omnistudio-omniscript-generate)، أو تكوين مخططي البيانات (استخدم omnistudio-datamapper-generate)، أو تحليل مشكلات مساحة الاسم/التبعية (استخدم تحليل التبعيات الشاملة).
