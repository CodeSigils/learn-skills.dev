透過開啟 service-cloud-itsm-discovery-integration 功能，在 Service Cloud ITSM 中針對生產或沙盒組織啟用 CMDB 資產發現，然後透過指派 IT Service Discovery Manager 權限集及其授權來向使用者授予發現頁面 — 最終的 CMDB 設定層，在 CMDB 功能、使用者存取權和內容捆綁位後執行就執行。當使用者要求啟用 CMDB 發現、開啟資產發現、啟用 service-cloud-itsm-discovery-integration、授予 Discovery 頁面存取權或指派 Discovery Manager 權限集時使用。觸發條件：啟用 CMDB 發現、開啟資產發現、service-cloud-itsm-discovery-integration、指派 Discovery Manager 存取權、未啟用 CMDB 發現。不要在下列情況下觸發：使用者想要啟用基本 CMDB 功能、設定 ITOM 租用戶、指派四個 CMDB 設定項權限集、安裝 CMDB 內容包或直接使用 CMDB 記錄 - 這些是早期的 CMDB 層。
