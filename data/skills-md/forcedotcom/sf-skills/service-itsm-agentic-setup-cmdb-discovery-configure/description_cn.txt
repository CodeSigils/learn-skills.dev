通过打开 service-cloud-itsm-discovery-integration 功能，在 Service Cloud ITSM 中针对生产或沙盒组织启用 CMDB 资产发现，然后通过分配 IT Service Discovery Manager 权限集及其许可证来向用户授予发现页面 — 最终的 CMDB 设置层，在 CMDB 功能、用户访问和内容捆绑就位后运行。当用户请求启用 CMDB 发现、打开资产发现、启用 service-cloud-itsm-discovery-integration、授予 Discovery 页面访问权限或分配 Discovery Manager 权限集时使用。触发条件：启用 CMDB 发现、打开资产发现、service-cloud-itsm-discovery-integration、分配 Discovery Manager 访问权限、未启用 CMDB 发现。不要在以下情况下触发：用户想要启用基本 CMDB 功能、配置 ITOM 租户、分配四个 CMDB 配置项权限集、安装 CMDB 内容包或直接使用 CMDB 记录 - 这些是早期的 CMDB 层。
