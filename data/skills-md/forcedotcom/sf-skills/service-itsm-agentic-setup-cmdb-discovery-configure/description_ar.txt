قم بتمكين اكتشاف أصول CMDB في Service Cloud ITSM مقابل مؤسسة إنتاج أو وضع الحماية من خلال تشغيل ميزة تكامل اكتشاف الخدمة السحابية، ثم امنح المستخدم صفحة الاكتشاف عن طريق تعيين مجموعة أذونات IT Service Discovery Manager وترخيصها - طبقة إعداد CMDB النهائية، التي يتم تشغيلها بعد تفعيل ميزة CMDB ووصول المستخدم وحزمة المحتوى. يُستخدم عندما يطلب المستخدم تمكين اكتشاف CMDB، أو تشغيل اكتشاف الأصول، أو تمكين تكامل اكتشاف الخدمة السحابية، أو منح الوصول إلى صفحة الاكتشاف، أو تعيين مجموعة أذونات Discovery Manager. تشغيل المشغلات: تمكين اكتشاف CMDB، وتشغيل اكتشاف الأصول، وتكامل اكتشاف الخدمة السحابية، وتعيين الوصول إلى Discovery Manager، وعدم تمكين اكتشاف CMDB. لا تقم بالتشغيل عندما: يريد المستخدم تمكين ميزة CMDB الأساسية، أو توفير مستأجر ITOM، أو تعيين مجموعات أذونات عنصر تكوين CMDB الأربعة، أو تثبيت حزمة محتوى CMDB، أو العمل مع سجلات CMDB مباشرة - تلك هي طبقات CMDB سابقة.
