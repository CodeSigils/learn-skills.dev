Service Cloud ITSM で、service-cloud-itsm-discovery-integration 機能を有効にして本番組織または Sandbox 組織に対して CMDB アセット検出を有効にし、IT Service Discovery Manager 権限セットとそのライセンスを割り当てることで、ユーザーに検出ページを付与します。これは、CMDB 機能、ユーザーアクセス、およびコンテンツバンドルが設定された後に実行される最後の CMDB セットアップレイヤーです。ユーザーが CMDB 検出の有効化、アセット検出の有効化、service-cloud-itsm-discovery-integration の有効化、Discovery ページへのアクセスの許可、または Discovery Manager 権限セットの割り当てを要求する場合に使用します。トリガー: CMDB 検出を有効にする、アセット検出をオンにする、service-cloud-itsm-discovery-integration、Discovery Manager アクセスを割り当てる、CMDB 検出が有効になっていない。次の場合にはトリガーしないでください: ユーザーが基本 CMDB 機能の有効化、ITOM テナントのプロビジョニング、4 つの CMDB 構成項目権限セットの割り当て、CMDB コンテンツ バンドルのインストール、または CMDB レコードの直接操作を希望している場合 (これらは以前の CMDB レイヤーです)。
