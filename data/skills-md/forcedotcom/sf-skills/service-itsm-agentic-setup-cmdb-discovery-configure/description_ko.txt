service-cloud-itsm-discovery-integration 기능을 켜서 프로덕션 또는 샌드박스 조직에 대해 Service Cloud ITSM에서 CMDB 자산 검색을 활성화한 다음, IT Service Discovery Manager 권한 집합과 해당 라이선스(CMDB 기능, 사용자 액세스 및 콘텐츠 번들이 설치된 후 실행되는 최종 CMDB 설정 계층)를 할당하여 사용자에게 검색 페이지를 부여합니다. 사용자가 CMDB 검색 활성화, 자산 검색 켜기, service-cloud-itsm-discovery-integration 활성화, 검색 페이지 액세스 권한 부여 또는 Discovery Manager 권한 집합 할당을 요청할 때 사용합니다. 트리거 조건: CMDB 검색 활성화, 자산 검색 활성화, service-cloud-itsm-discovery-integration, Discovery Manager 액세스 할당, CMDB 검색 활성화되지 않음. 다음과 같은 경우에는 트리거하지 마세요. 사용자가 기본 CMDB 기능 활성화, ITOM 테넌트 프로비저닝, 4개의 CMDB 구성 항목 권한 집합 할당, CMDB 컨텐츠 번들 설치 또는 CMDB 레코드 직접 작업을 원할 때(이것이 이전 CMDB 계층입니다.)
