Operaciones de datos de Salesforce con puntuación de 130 puntos. Utilice esta habilidad para crear, actualizar, eliminar, importar/exportar de forma masiva, generar datos de prueba y limpiar registros de organización mediante sf CLI y Apex anónimo. DISPARAR cuando: el usuario crea datos de prueba, realiza importación/exportación masiva, usa comandos CLI de datos sf, necesita patrones de fábrica de datos para pruebas de Apex o necesita inicializar/limpiar registros en una organización de Salesforce. NO DISPARAR cuando: solo escritura de consultas SOQL (use querying-soql), ejecución de pruebas de Apex (use running-apex-tests) o implementación de metadatos (use implementación de metadatos).
