استخدم هذه المهارة لإدارة دورة الحياة الكاملة لخط أنابيب DevOps Center — أدرج جميع المسارات، واحصل على تفاصيل مسار واحد، وأنشئ مسارًا جديدًا مرتبطًا بمستودع Git، وأضف أو أزل المراحل، وأعد تسمية مرحلة، وأضف أو أزل بيئات Salesforce على المراحل، وأرفق المشاريع أو فصلها، وقم بتنشيط المسار أو إلغاء تنشيطه. يتم الاستدعاء عندما يريد المستخدم إعداد مسار الإصدار، أو مراحل الترويج السلكي عبر التكامل، أو UAT، أو التدريج، أو مؤسسات الإنتاج، أو توصيل البيئات بالمراحل، أو إرفاق مشروع، أو تنشيط مسار التسليم المستمر. يستخدم خط أنابيب sf devops وأوامر مرحلة sf devops مع إخراج --json. لا تقم بالتنشيط لدورة حياة عنصر العمل، أو تنفيذ الترقية أو النشر، أو اكتشاف الصراع، أو إنشاء مشروع مستقل (مهارات منفصلة).
