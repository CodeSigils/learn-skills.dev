Verwenden Sie diese Fähigkeit, um den gesamten Lebenszyklus einer DevOps Center-Pipeline zu verwalten: Listen Sie alle Pipelines auf, rufen Sie die Details einer einzelnen Pipeline ab, erstellen Sie eine neue Pipeline, die mit einem Git-Repository verknüpft ist, fügen Sie Phasen hinzu oder entfernen Sie sie, benennen Sie eine Phase um, fügen Sie Salesforce-Umgebungen auf Phasen hinzu oder entfernen Sie sie, hängen Sie Projekte an oder trennen Sie sie und aktivieren oder deaktivieren Sie die Pipeline. Rufen Sie auf, wenn der Benutzer eine Release-Pipeline einrichten, Promotion-Phasen über Integrations-, UAT-, Staging- und Produktionsorganisationen hinweg vernetzen, Umgebungen mit Phasen verbinden, ein Projekt anhängen oder eine Continuous-Delivery-Pipeline aktivieren möchte. Verwendet die SF-Devops-Pipeline und die SF-Devops-Stage-Befehle mit der Ausgabe „--json“. NICHT für den Lebenszyklus von Arbeitselementen, die Ausführung von Hochstufungen oder Bereitstellungen, die Konflikterkennung oder die Erstellung eigenständiger Projekte (separate Fähigkeiten) auslösen.
