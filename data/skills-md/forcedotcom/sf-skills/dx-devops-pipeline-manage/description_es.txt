Utilice esta habilidad para administrar el ciclo de vida completo de una canalización de DevOps Center: enumere todas las canalizaciones, obtenga los detalles de una única canalización, cree una nueva canalización vinculada a un repositorio Git, agregue o elimine etapas, cambie el nombre de una etapa, agregue o elimine entornos de Salesforce en etapas, adjunte o separe proyectos y active o desactive la canalización. Invocar cuando el usuario desee configurar un canal de lanzamiento, conectar etapas de promoción entre organizaciones de integración, UAT, ensayo y producción, conectar entornos a etapas, adjuntar un proyecto o activar un canal de entrega continua. Utiliza los comandos sf devops pipeline y sf devops stage con salida --json. NO DISPARAR para el ciclo de vida del elemento de trabajo, promoción o ejecución de implementación, detección de conflictos o creación de proyectos independientes (habilidades separadas).
