Fase de recuperación de Salesforce Data Cloud. Utilice esta habilidad cuando el usuario ejecute Data Cloud SQL, consultas asíncronas, búsqueda de vectores, flujos de trabajo de índice de búsqueda o introspección de metadatos para objetos de Data Cloud. DISPARAR cuando: el usuario ejecuta Data Cloud SQL, describe, consultas asíncronas, búsqueda de vectores, flujos de trabajo de índice de búsqueda o introspección de metadatos para objetos de Data Cloud. NO DISPARAR cuando: la tarea es CRM SOQL estándar (use querying-soql), creación de segmentos o diseño de información calculada (use segmenting-datacloud), o STDM/rastreo de sesiones/análisis de parquet (use observer-agentforce).
