مرحلة استرداد البيانات السحابية من Salesforce. استخدم هذه المهارة عندما يقوم المستخدم بتشغيل Data Cloud SQL، أو الاستعلامات غير المتزامنة، أو بحث المتجهات، أو سير عمل فهرس البحث، أو استبطان البيانات التعريفية لكائنات Data Cloud. يتم تشغيله عندما: يقوم المستخدم بتشغيل Data Cloud SQL، أو الوصف، أو الاستعلامات غير المتزامنة، أو البحث المتجه، أو سير عمل فهرس البحث، أو استبطان البيانات التعريفية لكائنات Data Cloud. لا تقم بالتشغيل عندما: تكون المهمة قياسية CRM SOQL (استخدم الاستعلام-soql)، أو إنشاء مقطع أو تصميم رؤية محسوبة (استخدم تجزئة-datacloud)، أو تحليل STDM/تتبع الجلسة/الباركيه (استخدم قوة وكيل المراقبة).
