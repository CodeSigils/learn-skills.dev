Salesforce データクラウド取得フェーズ。このスキルは、ユーザーが Data Cloud SQL、非同期クエリ、ベクトル検索、検索インデックス ワークフロー、または Data Cloud オブジェクトのメタデータ イントロスペクションを実行するときに使用します。トリガーのタイミング: ユーザーが Data Cloud SQL、記述、非同期クエリ、ベクトル検索、検索インデックス ワークフロー、または Data Cloud オブジェクトのメタデータ イントロスペクションを実行したとき。次の場合はトリガーしないでください: タスクが標準 CRM SOQL (querying-soql を使用)、セグメント作成または計算されたインサイト設計 (segmenting-datacloud を使用)、または STDM/セッション トレース/寄木細工分析 (observing-agentforce を使用) である場合。
