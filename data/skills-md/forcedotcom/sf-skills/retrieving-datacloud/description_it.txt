Fase di recupero di Salesforce Data Cloud. Utilizza questa competenza quando l'utente esegue Data Cloud SQL, query asincrone, ricerca vettoriale, flussi di lavoro di indici di ricerca o introspezione di metadati per oggetti Data Cloud. TRIGGER quando: l'utente esegue Data Cloud SQL, descrive, query asincrone, ricerca vettoriale, flussi di lavoro di indici di ricerca o introspezione di metadati per oggetti Data Cloud. NON ATTIVARE quando: l'attività è CRM SOQL standard (utilizzare querying-soql), creazione di segmenti o progettazione di insight calcolati (utilizzare segmenting-datacloud) o STDM/tracciamento sessioni/analisi parquet (utilizzare osservatore-agentforce).
