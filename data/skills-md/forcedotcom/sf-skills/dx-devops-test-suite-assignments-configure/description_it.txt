Consiglia e gestisce le assegnazioni della suite di test DevOps Center per le fasi della pipeline. La modalità A analizza una differenza di commit rispetto ai metadati della suite assegnata per consigliare le suite esistenti pertinenti e segnalare le lacune di copertura (ragionamento puro). Le modalità B-D assegnano una singola suite, mappano in blocco più suite con un'anteprima dell'impatto obbligatoria o aggiungono/rimuovi classi di test con regole di governance, tramite l'API testSuiteStages Connect. Utilizza questa competenza per consigliare suite per un commit, assegnare o mappare suite su fasi oppure aggiungere/rimuovere test in una suite. TRIGGER quando: l'utente chiede quali suite eseguire per un commit/diff o cosa copre le proprie modifiche; una suite è scollegata e l'utente la vuole assegnata; l'utente desidera configurare mappature suite-stage, assegnare più suite o aggiungere/rimuovere/sincronizzare test in una suite. NON SI ATTIVA quando: si configura o si sincronizza un fornitore di test (utilizzare dx-devops-test-pipeline-configure), si eseguono suite (utilizzare dx-devops-test-suite-run) o si creano/eseguono test direttamente (utilizzare platform-apex-test-generate o platform-apex-test-run).
