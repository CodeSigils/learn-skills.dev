Рекомендует и управляет назначениями наборов тестов DevOps Center для этапов конвейера. Режим A анализирует разницу коммитов с метаданными назначенного пакета, чтобы рекомендовать соответствующие существующие пакеты и отмечать пробелы в покрытии (чистое рассуждение). Режимы BD назначают один набор, группируют несколько наборов с обязательным предварительным просмотром воздействия или добавляют/удаляют тестовые классы с помощью правил управления через API testSuiteStages Connect. Используйте этот навык, чтобы рекомендовать наборы для фиксации, назначать или сопоставлять наборы с этапами, а также добавлять/удалять тесты в наборе. ТРИГГЕР, когда: пользователь спрашивает, какие пакеты запускать для фиксации/разграничения или что охватывает их изменения; набор отключен, и пользователь хочет, чтобы его назначили; пользователь хочет настроить сопоставления между наборами и этапами, назначить несколько наборов или добавить, удалить или синхронизировать тесты в наборе. НЕ ЗАПУСКАЕТСЯ при: настройке или синхронизации поставщика тестов (используйте dx-devops-test-pipeline-configure), запуске наборов (используйте dx-devops-test-suite-run) или непосредственном написании/запуске тестов (используйте Platform-apex-test-generate или Platform-apex-test-run).
