推荐和管理 DevOps 中心测试套件的管道阶段分配。模式 A 根据分配的套件元数据分析提交差异，以推荐相关的现有套件并标记覆盖范围差距（纯粹推理）。 B-D 模式通过 testSuiteStages Connect API 分配单个套件、使用强制影响预览批量映射多个套件，或者使用治理规则添加/删除测试类。使用此技能推荐用于提交的套件，将套件分配或映射到阶段，或者添加/删除套件中的测试。触发时间：用户询问要运行哪些套件来进行提交/差异或哪些套件涵盖了他们的更改；套件未链接且用户希望对其进行分配；用户想要配置套件到阶段的映射、分配多个套件或在套件中添加/删除/同步测试。不要在以下情况下触发：配置或同步测试提供程序（使用 dx-devops-test-pipeline-configure）、运行套件（使用 dx-devops-test-suite-run）或直接编写/运行测试（使用 platform-apex-test-generate 或 platform-apex-test-run）。
