Configure un fournisseur de tests disponible (par exemple, Apex Unit Tests, Code Analyzer, Flow Tests, Provar) sur un pipeline DevOps Center via l'API Connect, après confirmation explicite de l'utilisateur, afin que les suites de tests du fournisseur deviennent disponibles pour une affectation aux étapes du pipeline. Prend un pipelineId et un testProviderId. Utilisez cette compétence lorsqu'un fournisseur est disponible sur le pipeline mais pas encore configuré et que l'utilisateur souhaite l'activer. DÉCLENCHEMENT lorsque : l'utilisateur souhaite configurer, activer, configurer ou ajouter un fournisseur de test sur un pipeline, ou souhaite que les suites d'un fournisseur non encore configuré soient disponibles. NE PAS DÉCLENCHER lorsque : vous resynchronisez un fournisseur déjà configuré pour récupérer de nouvelles suites (utilisez les fournisseurs de tests de synchronisation) ou attribuez des suites existantes à une étape (utilisez les affectations de suites de gestion).
