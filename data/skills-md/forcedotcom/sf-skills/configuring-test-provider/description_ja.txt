明示的なユーザー確認の後、Connect API 経由で DevOps Center パイプライン上で利用可能なテスト プロバイダー (Apex 単体テスト、コード アナライザー、フロー テスト、Provar など) を構成します。これにより、プロバイダーのテスト スイートをパイプライン ステージに割り当てることができるようになります。 PipelineId と testProviderId を受け取ります。このスキルは、プロバイダーがパイプラインで使用可能だがまだ構成されておらず、ユーザーがそれを有効にしたい場合に使用します。トリガーのタイミング: ユーザーがパイプライン上でテスト プロバイダーを構成、有効化、セットアップ、または追加したい場合、またはまだ構成されていないプロバイダー スイートを使用可能にしたい場合。次の場合にはトリガーしないでください: 新しいスイートを選択するために構成済みのプロバイダーを再同期する場合 (syncing-test-providers を使用)、または既存のスイートをステージに割り当てる場合 (managing-suite-assignments を使用)。
