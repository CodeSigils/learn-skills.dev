Настраивает доступного поставщика тестов (например, модульные тесты Apex, анализатор кода, Flow Tests, Provar) в конвейере DevOps Center через Connect API после явного подтверждения пользователя, чтобы наборы тестов поставщика стали доступны для назначения этапам конвейера. Принимает идентификатор конвейера и идентификатор testProviderId. Используйте этот навык, когда поставщик доступен в конвейере, но еще не настроен и пользователь хочет его включить. ТРИГГЕР, когда: пользователь хочет настроить, включить, настроить или добавить поставщика тестов в конвейер или хочет, чтобы наборы еще не настроенного поставщика стали доступными. НЕ ЗАПУСКАЕТСЯ при: повторной синхронизации уже настроенного поставщика для получения новых наборов (используйте поставщиков синхронизирующих тестов) или назначении существующих наборов на этап (используйте назначения управляющих наборов).
