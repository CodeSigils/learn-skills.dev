Wenden Sie eine Salesforce-Sandbox-Post-Copy-Automatisierungs-JSON-Konfiguration auf eine Zielorganisation an. Für jeden Eintrag leitet der Skill das richtige Tooling-API-Objekt aus dem „ConfigurationName“ des Eintrags ab, überprüft die Ableitung über eine Beschreibungsprobe, löst die Datensatz-ID über SOQL-over-REST auf und patcht den Datensatz dann über das zusammengesetzte „Metadata“-Feld mit „sf api request rest“. Verwenden Sie diese Option, wenn der Benutzer eine Post-Copy- oder Post-Refresh-Konfigurationsdatei (z. B. „post-copy-config.json“) in einer Sandbox anwenden, ausführen, ausführen, testen oder in der Vorschau anzeigen möchte. Auslösersätze: „Post-Copy-Konfiguration anwenden“, „Post-Copy-Automatisierung ausführen“, „Sandbox-Post-Refresh-JSON ausführen“, „Sandbox-Refresh-Konfiguration anwenden“, „Sandbox nach Aktualisierung konfigurieren“. NICHT auslösen, um den Konfigurations-JSON aus einer SOP zu generieren (an „automation-sandbox-post-copy-config-generate“ delegieren) oder um Metadaten-XML bereitzustellen.
