Appliquez une configuration JSON d’automatisation post-copie de sandbox Salesforce à une organisation cible. Pour chaque entrée, la compétence dérive le sobject API Tooling correct à partir du « ConfigurationName » de l'entrée, vérifie la dérivation via une sonde de description, résout l'ID d'enregistrement via SOQL-over-REST, puis corrige l'enregistrement via le champ composé « Metadata » à l'aide de « sf api request rest ». À utiliser lorsque l'utilisateur demande d'appliquer, d'exécuter, d'exécuter, d'exécuter à sec ou de prévisualiser un fichier de configuration post-copie ou post-actualisation (par exemple `post-copy-config.json`) sur un bac à sable. Phrases de déclenchement : « appliquer la configuration post-copie », « exécuter l'automatisation post-copie », « exécuter le bac à sable après actualisation JSON », « appliquer la configuration d'actualisation du bac à sable », « configurer le bac à sable après l'actualisation ». NE PAS DÉCLENCHER pour générer le JSON de configuration à partir d'une SOP (déléguer à « automation-sandbox-post-copy-config-generate ») ou pour déployer des métadonnées XML.
