Aplique una configuración JSON de automatización posterior a la copia de Sandbox de Salesforce en una organización de destino. Para cada entrada, la habilidad deriva el objeto API de herramientas correcto a partir del `ConfigurationName` de la entrada, verifica la derivación mediante una sonda de descripción, resuelve el Id. del registro mediante SOQL-over-REST y luego aplica un PATCH al registro mediante el campo compuesto `Metadata` utilizando `sf api request rest`. Úselo cuando el usuario solicite aplicar, ejecutar, realizar un ensayo o obtener una vista previa de un archivo de configuración posterior a la copia o actualización (por ejemplo, `post-copy-config.json`) en un entorno limitado. Frases de activación: "aplicar configuración posterior a la copia", "ejecutar automatización posterior a la copia", "ejecutar JSON posterior a la actualización de la zona de pruebas", "aplicar configuración de actualización de la zona de pruebas", "configurar la zona de pruebas después de la actualización". NO DISPARE para generar el JSON de configuración desde un SOP (delega a `automation-sandbox-post-copy-config-generate`), ni para implementar metadatos XML.
