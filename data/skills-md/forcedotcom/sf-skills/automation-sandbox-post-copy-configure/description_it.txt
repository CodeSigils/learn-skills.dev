Applicare una configurazione JSON di automazione post-copia sandbox Salesforce a un'organizzazione di destinazione. Per ogni voce, la competenza deriva l'oggetto API Tooling corretto dal "ConfigurationName" della voce, verifica la derivazione tramite un'analisi di descrizione, risolve l'ID del record tramite SOQL-over-REST, quindi esegue il PATCH del record tramite il campo composto "Metadata" utilizzando "sf api request rest". Da utilizzare quando l'utente chiede di applicare, eseguire, eseguire un test di prova o visualizzare in anteprima un file di configurazione post-copia o post-aggiornamento (ad esempio `post-copy-config.json`) su una sandbox. Frasi di attivazione: "applica configurazione post-copia", "esegui automazione post-copia", "esegui JSON post-aggiornamento sandbox", "applica configurazione di aggiornamento sandbox", "configura sandbox dopo l'aggiornamento". NON ATTIVARE per generare il JSON di configurazione da una SOP (delegare a `automation-sandbox-post-copy-config-generate`) o per distribuire metadati XML.
