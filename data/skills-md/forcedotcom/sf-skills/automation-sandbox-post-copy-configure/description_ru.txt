Примените конфигурацию JSON автоматизации песочницы Salesforce к целевой организации. Для каждой записи навык извлекает правильный объект Tooling API из записи `ConfigurationName`, проверяет деривацию с помощью зонда описания, разрешает идентификатор записи через SOQL-over-REST, затем исправляет запись через составное поле `Metadata` с помощью `sf api request rest`. Используйте, когда пользователь запрашивает применить, запустить, выполнить, выполнить пробный запуск или просмотреть файл конфигурации после копирования или обновления (например, `post-copy-config.json`) в песочнице. Триггерные фразы: «применить конфигурацию после копирования», «запустить автоматизацию после копирования», «выполнить JSON песочницы после обновления», «применить конфигурацию обновления песочницы», «настроить песочницу после обновления». НЕ ИСПОЛЬЗУЙТЕ для генерации JSON конфигурации из SOP (делегируйте `automation-sandbox-post-copy-config-generate`) или для развертывания метаданных XML.
