قم بتطبيق تكوين JSON لأتمتة ما بعد النسخ في وضع الحماية لـ Salesforce على مؤسسة مستهدفة. بالنسبة لكل إدخال، تستمد المهارة موضوع Tooling API الصحيح من "ConfigurationName" للإدخال، وتتحقق من الاشتقاق عبر مسبار الوصف، وتحل معرف السجل عبر SOQL-over-REST، ثم تقوم بتصحيح السجل عبر حقل "بيانات التعريف" المركب باستخدام "sf api request Rest". يُستخدم عندما يطلب المستخدم تطبيق أو تشغيل أو تنفيذ أو تشغيل جاف أو معاينة ملف تكوين ما بعد النسخ أو ما بعد التحديث (على سبيل المثال، `post-copy-config.json`) في وضع الحماية. عبارات التشغيل: "تطبيق تكوين ما بعد النسخ"، "تشغيل أتمتة ما بعد النسخ"، "تنفيذ وضع الحماية بعد التحديث JSON"، "تطبيق تكوين تحديث وضع الحماية"، "تكوين وضع الحماية بعد التحديث". لا تقم بالبدء في إنشاء تكوين JSON من إجراء SOP (تفويض إلى "automation-sandbox-post-copy-config-generate")، أو لنشر بيانات تعريف XML.
