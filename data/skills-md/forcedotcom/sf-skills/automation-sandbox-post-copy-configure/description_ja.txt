Salesforce サンドボックスのコピー後の自動化 JSON 設定をターゲット組織に対して適用します。各エントリに対して、スキルはエントリの `ConfigurationName` から正しい Tooling API sobject を導出し、describe プローブを介して導出を検証し、SOQL-over-REST を介してレコード ID を解決し、その後、`sf api requestrest` を使用して複合の `Metadata` フィールドを介してレコードにパッチを適用します。ユーザーがコピー後またはリフレッシュ後の構成ファイル (「post-copy-config.json」など) をサンドボックスに対して適用、実行、実行、ドライラン、またはプレビューするように要求する場合に使用します。トリガーフレーズ: 「コピー後の構成を適用する」、「コピー後のオートメーションを実行する」、「リフレッシュ後のサンドボックス JSON を実行する」、「サンドボックスのリフレッシュ構成を適用する」、「リフレッシュ後にサンドボックスを構成する」。 SOP (`automation-sandbox-post-copy-config-generate` にデリゲート) から設定 JSON を生成する場合、またはメタデータ XML をデプロイする場合はトリガーしないでください。
