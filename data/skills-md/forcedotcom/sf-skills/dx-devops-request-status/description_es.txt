Utilice esta habilidad para sondear el estado de una solicitud asincrónica del Centro DevOps: una operación de promoción o implementación. Proporcione el token de solicitud devuelto por dx-devops-promote (la respuesta de promoción) para verificar la finalización, monitorear el progreso o verificar el éxito o el fracaso a través del estado de la solicitud de sf devops. DISPARA cuando el usuario desea verificar si una promoción o implementación finalizó, monitorear una solicitud asíncrona en curso, sondear hasta que se complete una solicitud o confirmar que una solicitud se realizó correctamente antes de finalizar. NO DISPARAR para iniciar una promoción o implementación (use dx-devops-promote), para la creación de elementos de trabajo o transiciones de estado (use dx-devops-work-item-manage) o para la detección de conflictos. Comprobación de estado de solo lectura: nunca cambia el estado de la canalización.
