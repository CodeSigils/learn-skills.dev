Используйте этот навык, чтобы узнать статус асинхронного запроса Центра DevOps — операции повышения или развертывания. Предоставьте токен запроса, возвращаемый dx-devops-promote (ответ продвижения), чтобы проверить завершение, отслеживать ход выполнения или проверить успех или неудачу с помощью статуса запроса SF Devops. TRIGGER, когда пользователь хочет проверить, завершено ли продвижение или развертывание, отслеживать текущий асинхронный запрос, опросить до завершения запроса или подтвердить успешность запроса перед его завершением. НЕ ИНИЦИРУЙТЕ для инициации повышения или развертывания (используйте dx-devops-promote), для создания рабочих элементов или смены состояний (используйте dx-devops-work-item-manage) или для обнаружения конфликтов. Проверка статуса только для чтения — никогда не изменяет состояние конвейера.
