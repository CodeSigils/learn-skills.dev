Verwenden Sie diesen Skill, um den Status einer asynchronen DevOps Center-Anfrage abzufragen – einem Hochstufungs- oder Bereitstellungsvorgang. Geben Sie das von dx-devops-promote zurückgegebene Anforderungstoken (die Promo-Antwort) an, um den Abschluss zu überprüfen, den Fortschritt zu überwachen oder Erfolg oder Misserfolg über den SF-Devops-Anforderungsstatus zu überprüfen. TRIGGER, wenn der Benutzer überprüfen möchte, ob eine Heraufstufung oder Bereitstellung abgeschlossen ist, eine asynchrone Anfrage im laufenden Betrieb überwachen, eine Abfrage durchführen möchte, bis eine Anfrage abgeschlossen ist, oder bestätigen möchte, dass eine Anfrage erfolgreich war, bevor sie abgeschlossen wird. NICHT auslösen, um eine Heraufstufung oder Bereitstellung zu initiieren (verwenden Sie dx-devops-promote), für die Erstellung von Arbeitselementen oder Statusübergänge (verwenden Sie dx-devops-work-item-manage) oder für die Konflikterkennung. Nur-Lese-Statusprüfung – ändert niemals den Pipeline-Status.
