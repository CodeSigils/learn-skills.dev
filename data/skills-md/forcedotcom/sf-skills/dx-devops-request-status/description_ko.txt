이 기술을 사용하여 비동기 DevOps Center 요청(승격 또는 배포 작업)의 상태를 폴링합니다. 완료를 확인하고 진행 상황을 모니터링하거나 sf devops 요청 상태를 통해 성공 또는 실패를 확인하려면 dx-devops-promote(승격 응답)에서 반환된 요청 토큰을 제공하세요. 사용자가 승격 또는 배포 완료 여부를 확인하고, 진행 중인 비동기 요청을 모니터링하고, 요청이 완료될 때까지 폴링하거나, 완료 전에 요청 성공을 확인하려는 경우 TRIGGER를 수행합니다. 승격 또는 배포 시작(dx-devops-promote 사용), 작업 항목 생성 또는 상태 전환(dx-devops-work-item-manage 사용) 또는 충돌 감지를 위해 트리거하지 마십시오. 읽기 전용 상태 확인 — 파이프라인 상태를 변경하지 않습니다.
