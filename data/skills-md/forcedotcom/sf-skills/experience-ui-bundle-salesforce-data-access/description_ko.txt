uiBundles/*/src/ 프로젝트가 모든 Salesforce 레코드 작업(쿼리 결과 읽기, 생성, 업데이트, 삭제 또는 캐싱/새로 고침)을 수행할 때 활성화해야 합니다. 트리거: @salesforce/platform-sdk 가져오기 코드, sdk.graphql.query / sdk.graphql.mutate / sdk.fetch 호출, *.graphql 파일, 강제 새로 고침이 필요한 오래된 데이터 또는 Salesforce 레코드를 읽고 쓰거나 새로 고치기 위해 UI 번들의 데이터 계층 연결. 새로운 읽기/쓰기 작업의 기본값은 현재 @salesforce/platform-sdk API를 사용하는 읽기/쓰기 워크플로입니다. 기존 코드가 이미 이전 @salesforce/sdk-data 호출 가능 형식을 사용하는 경우에만 마이그레이션 경로를 따르십시오. 앱 셸/UI 구축, 스타일 지정, 파일 업로드 또는 인증/검색 스캐폴딩용이 아닌 다른 ui-bundle-* 기술을 사용하세요. OAuth 설정, 스키마 변경, 대량/도구/메타데이터 API 또는 선언적 자동화인 경우에는 트리거하지 마세요.
