當 uiBundles/*/src/ 專案執行任何 Salesforce 記錄操作（讀取、建立、更新、刪除或快取/刷新查詢結果）時，必須啟動。觸發器：匯入 @salesforce/platform-sdk 的程式碼、呼叫 sdk.graphql.query / sdk.graphql.mutate / sdk.fetch、*.graphql 檔案、需要強制刷新的陳舊數據，或連接 UI 套件的資料層以讀取、寫入或刷新 Salesforce 記錄。新讀取/寫入工作的預設設定是使用目前 @salesforce/platform-sdk API 的讀取/寫入工作流程；僅當現有程式碼已使用舊的 @salesforce/sdk-data 可呼叫形式時才遵循遷移路徑。不適用於建立應用程式 shell/UI、樣式、檔案上傳或驗證/搜尋鷹架 — 使用其他 ui-bundle-* 技能。不要在以下情況下觸發：OAuth 設定、架構變更、批次/工具/元資料 API 或聲明性自動化。
