DOIT s'activer lorsqu'un projet uiBundles/*/src/ effectue TOUTE opération d'enregistrement Salesforce : lecture, création, mise à jour, suppression ou mise en cache/actualisation des résultats de requête. Déclencheurs : importation de code @salesforce/platform-sdk, appels à sdk.graphql.query / sdk.graphql.mutate / sdk.fetch, fichiers *.graphql, données obsolètes nécessitant une actualisation forcée ou câblage de la couche de données d'un ensemble d'interface utilisateur pour lire, écrire ou actualiser les enregistrements Salesforce. La valeur par défaut pour les nouveaux travaux de lecture/écriture est le workflow de lecture/écriture avec l'API @salesforce/platform-sdk actuelle ; suivez le chemin de migration uniquement lorsque le code EXISTANT utilise déjà l'ancien formulaire appelable @salesforce/sdk-data. Pas pour la création d'un shell/interface utilisateur d'application, du style, du téléchargement de fichiers ou d'un échafaudage d'authentification/recherche - utilisez les autres compétences ui-bundle-*. NE PAS DÉCLENCHER lorsque : configuration OAuth, modifications de schéma, API Bulk/Tooling/Metadata ou automatisation déclarative.
