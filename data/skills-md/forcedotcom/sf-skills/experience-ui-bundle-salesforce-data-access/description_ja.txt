uiBundles/*/src/ プロジェクトが Salesforce レコード操作 (クエリ結果の読み取り、作成、更新、削除、またはキャッシュ/リフレッシュ) を実行するときにアクティブ化する必要があります。トリガー: @salesforce/platform-sdk をインポートするコード、sdk.graphql.query / sdk.graphql.mutate / sdk.fetch の呼び出し、*.graphql ファイル、強制更新が必要な古いデータ、または Salesforce レコードの読み取り、書き込み、または更新のための UI バンドルのデータレイヤーの接続。新しい読み取り/書き込み作業のデフォルトは、現在の @salesforce/platform-sdk API を使用した読み取り/書き込みワークフローです。既存のコードがすでに古い @salesforce/sdk-data 呼び出し可能フォームを使用している場合にのみ、移行パスに従います。アプリ シェル/UI、スタイリング、ファイル アップロード、または認証/検索スキャフォールディングの構築には使用しません。他の ui-bundle-* スキルを使用してください。次の場合にはトリガーしないでください: OAuth セットアップ、スキーマ変更、バルク/ツール/メタデータ API、または宣言的自動化。
