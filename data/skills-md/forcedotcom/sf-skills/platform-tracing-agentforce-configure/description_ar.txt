قم بإنشاء بيانات تعريف AgentforcePlatformTracingSettings لتمكين أو تعطيل امتدادات تتبع تنفيذ وكيل Agentforce المتدفقة إلى Data Cloud. استخدم هذه المهارة لأي عمل يتعلق بالبيانات التعريفية لـ AgentforcePlatformTracingSettings. يتم تشغيل TRIGGER عندما: يذكر المستخدم تتبع Agentforce، وامتدادات تتبع الوكيل، وتتبع Data Cloud، وAgentforcePlatformTracingSettings، وتتبع قابلية ملاحظة النظام الأساسي، وتمكين تتبع الوكيل، ويريد امتدادات تنفيذ الوكيل في Data Cloud، ويذكر .settings-meta.xml لـ AgentforcePlatformTracing، أو يسأل عن تمكين إمكانية الملاحظة لوكلاء Agentforce. لا تقم بالتشغيل عندما: يريد المستخدم تتبع النظام الأساسي لـ TraceSpanEvent (استخدم تكوين تتبع النظام الأساسي)، أو يريد الاستعلام عن بيانات تتبع الوكيل الموجودة في Data Cloud أو تحليلها (استخدم agentforce-observe)، أو يريد ملفات سجل الأحداث أو تكوين ELF، أو يريد تغيير التقاط البيانات (استخدم تكامل الأحداث-cdc-configure)، أو يريد ManagedEventSubscription (استخدم تكوين الاشتراك في الأحداث التكاملية).
