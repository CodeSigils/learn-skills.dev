Créez, modifiez, déboguez et déployez des agents avec Agentforce Agent Script. DÉCLENCHEMENT lorsque : l'utilisateur crée, modifie ou pose des questions sur les fichiers .agent ou les métadonnées aiAuthoringBundle ; modifie le comportement, les réponses ou la logique de conversation de l'agent ; conçoit des actions d'agent, des outils, des sous-agents ou un contrôle de flux ; rédige ou révise une spécification d'agent ; prévisualise, débogue, déploie, publie ou teste les agents ; utilise les commandes CLI Agent Script (sf agent generate/preview/publish/test). NE PAS DÉCLENCHER lorsque : le développement Apex, la création de flux, la création de modèles d'invite, la configuration d'Experience Cloud ou les tâches générales de Salesforce CLI sans rapport avec le script d'agent.
