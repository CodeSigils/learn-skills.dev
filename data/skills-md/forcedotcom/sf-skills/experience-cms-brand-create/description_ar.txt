قم بتأليف علامة تجارية للتجربة الرقمية لـ Salesforce ("brand.json") حتى تتمكن مجموعة أدوات العلامة التجارية VS Code من تحميلها وتحريرها ومعاينتها. استخدم هذه المهارة عندما يريد شخص ما: إنشاء علامة تجارية، أو إنشاء علامة تجارية جديدة، أو إنشاء علامة تجارية من وصف أو لون/شعار/حالة مزاجية، أو إضافة علامة تجارية إلى مشروع حتى تلتقطها مجموعة أدوات العلامة التجارية، أو دعم ملف Brand.json، أو تصميم موقع تجربة رقمية، أو تحويل فكرة العلامة التجارية ("علامة تجارية فاخرة داكنة"، "تطابق شعارنا"، "مرجاني + مستدير + صديق") إلى علامة تجارية قابلة للتحميل. استخدمه أيضًا عندما يذكر المستخدم "مجموعة أدوات العلامة التجارية"، أو "العلامة التجارية لمدير السمات"، أو "رمز العلامة التجارية"، أو "colorScheme"، أو "primaryAccent"، أو ".digitalExperience/brands"، أو "sfdc_cms:title"، أو "brand.json" التي يجب أن تظهر في مجموعة أدوات العلامة التجارية. لا تستخدم هذه المهارة لتطبيق صوت أو نغمة أو إرشادات علامة تجارية موجودة على المحتوى الذي تم إنشاؤه (استخدم experience-cms-brand-apply)، أو للبحث في Salesforce CMS عن العلامات التجارية الحالية، أو للبحث عن الصور أو الوسائط أو الشعارات (استخدم Experience-content-media-search).
