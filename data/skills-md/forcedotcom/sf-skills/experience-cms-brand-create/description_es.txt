Cree una marca de Salesforce Digital Experience (un "brand.json") para que VS Code Brand Toolkit pueda cargarla, editarla y obtener una vista previa. Utilice esta habilidad siempre que alguien quiera: crear una marca, crear una nueva marca, generar una marca a partir de una descripción o un color/logotipo/estado de ánimo, agregar una marca a un proyecto para que el Brand Toolkit la recoja, crear un archivo brand.json, crear un tema para un sitio de experiencia digital o convertir una idea de marca ("una marca de lujo oscura", "que combine con nuestro logotipo", "coral + redondeado + amigable") en una marca cargable. Úselo también cuando el usuario mencione "Brand Toolkit", "marca del administrador de temas", "token de marca", "colorScheme", "primaryAccent", ".digitalExperience/brands", "sfdc_cms:title" o un "brand.json" que debería aparecer en el Brand Toolkit. NO utilice esta habilidad para aplicar la voz, el tono o las pautas de una marca existente al contenido generado (use experiencia-cms-brand-apply), para buscar marcas existentes en Salesforce CMS o para buscar imágenes, medios o logotipos (use experiencia-contenido-media-búsqueda).
