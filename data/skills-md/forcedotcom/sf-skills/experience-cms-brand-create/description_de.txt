Erstellen Sie eine Salesforce Digital Experience-Marke (eine „brand.json“), damit das VS Code Brand Toolkit sie laden, bearbeiten und in der Vorschau anzeigen kann. Nutzen Sie diese Fähigkeit immer dann, wenn jemand Folgendes möchte: eine Marke erstellen, eine neue Marke erstellen, eine Marke aus einer Beschreibung oder einer Farbe/einem Logo/einer Stimmung generieren, eine Marke zu einem Projekt hinzufügen, damit das Brand Toolkit sie aufgreift, eine brand.json aufbauen, eine Digital Experience-Site thematisieren oder eine Markenidee („eine dunkle Luxusmarke“, „passend zu unserem Logo“, „Koralle + abgerundet + freundlich“) in eine ladbare Marke umwandeln. Verwenden Sie es auch, wenn der Benutzer „Brand Toolkit“, „Theme Manager Brand“, „Brand Token“, „colorScheme“, „primaryAccent“, „.digitalExperience/brands“, „sfdc_cms:title“ oder eine „brand.json“ erwähnt, die im Brand Toolkit angezeigt werden soll. Verwenden Sie diesen Skill NICHT, um die Stimme, den Ton oder die Richtlinien einer bestehenden Marke auf generierte Inhalte anzuwenden (verwenden Sie experience-cms-brand-apply), um Salesforce CMS nach vorhandenen Marken zu durchsuchen oder um nach Bildern, Medien oder Logos zu suchen (verwenden Sie experience-content-media-search).
