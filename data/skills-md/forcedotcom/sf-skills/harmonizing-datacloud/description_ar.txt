مرحلة تنسيق سحابة بيانات Salesforce. استخدم هذه المهارة عندما يعمل المستخدم مع DMOs أو التعيينات أو العلاقات أو تحليل الهوية أو الملفات الشخصية الموحدة أو الرسوم البيانية للبيانات أو المعرفات العامة. يتم التشغيل عندما: يعمل المستخدم مع DMOs، أو التعيينات، أو العلاقات، أو تحليل الهوية، أو الملفات الشخصية الموحدة، أو الرسوم البيانية للبيانات، أو المعرفات العامة. لا تقم بالتشغيل عندما: تتعلق المهمة فقط بالتدفقات/DLOs (استخدم إعداد datacloud)، أو المقاطع/الرؤى (استخدم تجزئة datacloud)، أو الاسترداد/البحث (استخدم استرداد datacloud)، أو تتبع STDM/الجلسة (استخدم قوة وكيل المراقبة).
