Esegue il polling dell'esecuzione di un test asincrono DevOps Center tramite runId finché non viene completato, fallisce o scade, utilizzando SOQL di sola lettura sul record di esecuzione a intervalli specifici del provider (Apex 15s/5m, Code Analyser 10s/3m, Provar UI 60s/20m, Flow 20s/8m), quindi mostra i risultati. Utilizza questa capacità quando è in corso l'esecuzione di una suite di test e l'utente è in attesa dei risultati o immediatamente dopo aver eseguito una suite. TRIGGER quando: è in corso l'esecuzione di una suite di test e l'utente è in attesa dei risultati oppure immediatamente dopo aver eseguito una suite ed è disponibile un runId. NON ATTIVARE quando: non è presente alcun runId attivo.
