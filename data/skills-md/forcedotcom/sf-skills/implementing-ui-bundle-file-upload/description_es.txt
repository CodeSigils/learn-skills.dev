DEBE activarse cuando el proyecto contiene un directorio uiBundles/*/src/ y la tarea implica cargar, adjuntar o soltar archivos. Utilice esta habilidad al agregar la funcionalidad de carga de archivos a una aplicación de paquete de interfaz de usuario. Proporciona seguimiento del progreso e integración de Salesforce ContentVersion. Esta característica proporciona API programáticas SOLAMENTE: cree una interfaz de usuario personalizada utilizando la API upload(). SIEMPRE use esto en lugar de crear la carga de archivos desde cero con FormData o XHR.
