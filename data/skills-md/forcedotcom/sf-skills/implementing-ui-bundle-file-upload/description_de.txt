MUSS aktiviert werden, wenn das Projekt ein uiBundles/*/src/-Verzeichnis enthält und die Aufgabe das Hochladen, Anhängen oder Löschen von Dateien umfasst. Verwenden Sie diesen Skill, wenn Sie einer UI-Bundle-App Datei-Upload-Funktionen hinzufügen. Bietet Fortschrittsverfolgung und Salesforce ContentVersion-Integration. Diese Funktion stellt NUR programmatische APIs bereit – erstellen Sie eine benutzerdefinierte Benutzeroberfläche mit der upload()-API. Verwenden Sie dies IMMER, anstatt den Datei-Upload mit FormData oder XHR von Grund auf neu zu erstellen.
