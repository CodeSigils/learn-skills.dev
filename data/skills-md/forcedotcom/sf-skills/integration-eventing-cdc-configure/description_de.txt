Verwenden Sie diese Option, um Salesforce Change Data Capture (CDC) für ein Standard- oder benutzerdefiniertes Objekt zu aktivieren, einen benutzerdefinierten Ereigniskanal zu konfigurieren, einen Filterausdruck festzulegen oder Anreicherungsfelder hinzuzufügen. TRIGGER im Allgemeinen auf Folgendes: „CDC aktivieren“, „Change Data Capture aktivieren“, „CDC aktivieren“, „X für Änderungsereignisse abonnieren“, „Ereignisse nur ausgeben für“, „Änderungsereignisse filtern“, „Änderungsereignisse anreichern“, „einen benutzerdefinierten Ereigniskanal erstellen“; oder jede Erwähnung von CDC, Änderungsereignissen, PlatformEventChannel, PlatformEventChannelMember, EnrichedField, ChangeEvents-Kanal, Anreicherungsfeldern, Änderungsereignisfilter; oder wenn der Benutzer möchte, dass ein nachgelagertes System Änderungen an Salesforce-Daten empfängt; oder wenn der Benutzer die Dateien .platformEventChannelMember-meta.xml / .platformEventChannel-meta.xml berührt. SKIP beim Veröffentlichen von Plattformereignissen, Pub/Sub-API oder REST/SOAP (integration-connectivity-generate verwenden) oder ManagedEventSubscription (außerhalb des CDC-Bereichs). Verwenden Sie diesen Skill immer für Metadaten zur CDC-Kanalmitgliedschaft.
