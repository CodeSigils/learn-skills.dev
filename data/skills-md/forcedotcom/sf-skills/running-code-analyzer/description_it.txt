Supporta tutti i motori (PMD, ESLint, CPD, RetireJS, Flow, SFGE, ApexGuru), destinazioni (file, cartelle, git diff), categorie e gravità. ATTIVA quando: l'utente dice "scansiona il mio codice", "verifica problemi di sicurezza", "esegui PMD/ESLint", "trova duplicati", "analizza flussi", "controlla librerie vulnerabili", "revisione AppExchange", "lint mio LWC", "analisi statica", "qualità del codice" o menziona motori/tipi di file (.cls, .trigger, .js, .flow-meta.xml). NON ATTIVARE quando: l'utente desidera correggere il codice senza eseguire la scansione o chiede informazioni sull'installazione/configurazione.
