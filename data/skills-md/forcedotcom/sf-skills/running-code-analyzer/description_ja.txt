Salesforce Code Analyzer を実行して、コードをスキャンして、セキュリティ、パフォーマンス、ベストプラクティス、およびコードスタイル違反がないか確認します。すべてのエンジン (PMD、ESLint、CPD、RetireJS、Flow、SFGE、ApexGuru)、ターゲット (ファイル、フォルダー、git diff)、カテゴリ、および重大度をサポートします。トリガーのタイミング: ユーザーが「コードをスキャンする」、「セキュリティ問題をチェックする」、「PMD/ESLint を実行する」、「重複を見つける」、「フローを分析する」、「脆弱なライブラリをチェックする」、「AppExchange レビュー」、「LWC をリントする」、「静的分析」、「コードの品質」と発言した場合、またはエンジン/ファイル タイプ (.cls、.trigger、.js、 .flow-meta.xml)。次の場合はトリガーしないでください: ユーザーがスキャンせずにコードを修正したい場合、またはインストール/構成について質問する場合。
