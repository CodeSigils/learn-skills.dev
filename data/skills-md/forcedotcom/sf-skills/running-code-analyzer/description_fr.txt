Exécutez Salesforce Code Analyzer pour analyser le code à la recherche de violations de sécurité, de performances, de bonnes pratiques et de style de code. Prend en charge tous les moteurs (PMD, ESLint, CPD, RetireJS, Flow, SFGE, ApexGuru), cibles (fichiers, dossiers, git diff), catégories et gravités. DÉCLENCHEMENT lorsque : l'utilisateur dit "analyser mon code", "vérifier les problèmes de sécurité", "exécuter PMD/ESLint", "trouver des doublons", "analyser les flux", "vérifier les bibliothèques vulnérables", "examen AppExchange", "lint mon LWC", "analyse statique", "qualité du code" ou mentionne des moteurs/types de fichiers (.cls, .trigger, .js, .flow-meta.xml). NE PAS DÉCLENCHER lorsque : l'utilisateur souhaite corriger le code sans le scanner ou pose des questions sur l'installation/la configuration.
