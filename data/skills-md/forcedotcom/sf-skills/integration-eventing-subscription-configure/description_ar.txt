إنشاء البيانات التعريفية ManagedEventSubscription وقراءتها وتحديثها وحذفها في Salesforce. استخدم هذه المهارة لأي عمل يتضمن اشتراكات أحداث مُدارة، أو اشتراكات أحداث النظام الأساسي، أو المشتركين في قنوات الأحداث، أو ملفات .managedEventSubscription-meta.xml. يتم تشغيله عندما: يطلب المستخدم الاشتراك في حدث منصة، أو إنشاء اشتراك مُدار، أو إعداد إعادة تشغيل الحدث، أو تكوين مشترك في قناة الحدث، أو تحديث الإعداد المسبق لإعادة التشغيل، أو تنشيط اشتراك أو إلغاء تنشيطه، أو حذف اشتراك، أو إدارة البيانات التعريفية ManagedEventSubscription. تخطي عندما: يحتاج المستخدم إلى إنشاء قناة حدث النظام الأساسي نفسها (استخدم مهارة إنشاء الكائنات المخصصة للنظام الأساسي) أو يحتاج إلى اشتراكات الأحداث المستندة إلى التدفق (استخدم مهارة إنشاء التدفق التلقائي).
