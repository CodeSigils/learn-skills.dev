Conecta un agente de Agentforce activo existente a un canal resolviendo una cola de reserva, configurando el enrutamiento entrante (ya sea PATCH SessionHandlerId en MessagingChannel o un RoutingFlow entrante para voz/correo electrónico) y, opcionalmente, configurando el escalamiento saliente. Úselo cuando el usuario desee agregar un canal a un agente existente, conectar un agente a un canal de voz o mensajería, enrutar voz o correo electrónico de caso a un agente de Agentforce o configurar una cola alternativa para un canal de agente. Se aplica a cualquier agente ya creado, incluido un agente de ayuda existente. La infraestructura del canal (MessagingChannel, configuración de voz, correo electrónico para casos) ya debe existir; esta habilidad solo agrega el enrutamiento. NO DISPARE cuando el agente aún no existe o aún necesita la configuración del Agente de ayuda (use agentforce-generate o service-helpagent-coordinate), al crear el propio MessagingChannel (use service-digital-engagement-channel-configure) o al crear una implementación de servicio integrada (use service-digital-engagement-deployment-configure).
