Verbindet einen vorhandenen, aktiven Agentforce-Agenten mit einem Kanal, indem er eine Fallback-Warteschlange auflöst, eingehendes Routing einrichtet (entweder PATCH SessionHandlerId auf dem MessagingChannel oder einen eingehenden RoutingFlow für Sprache/E-Mail) und optional eine ausgehende Eskalation konfiguriert. Verwenden Sie diese Option, wenn der Benutzer einen Kanal zu einem vorhandenen Agenten hinzufügen, einen Agenten mit einem Messaging- oder Sprachkanal verbinden, Voice oder E-Mail-zu-Vorgang an einen Agentforce-Agenten weiterleiten oder eine Fallback-Warteschlange für einen Agentenkanal einrichten möchte. Gilt für alle bereits erstellten Agenten, einschließlich eines vorhandenen Hilfeagenten. Die Kanalinfrastruktur (MessagingChannel, Sprachkonfiguration, E-Mail-zu-Fall) muss bereits vorhanden sein – dieser Skill fügt nur das Routing hinzu. NICHT AUSLÖSEN, wenn der Agent noch nicht existiert oder noch eine Einrichtung des Hilfeagenten benötigt (verwenden Sie agentforce-generate oder service-helpagent-coordinate), beim Erstellen des MessagingChannels selbst (verwenden Sie service-digital-engagement-channel-configure) oder beim Erstellen einer eingebetteten Dienstbereitstellung (verwenden Sie service-digital-engagement-deployment-configure).
