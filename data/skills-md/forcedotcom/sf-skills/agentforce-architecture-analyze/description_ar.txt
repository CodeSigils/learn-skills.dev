لقطة معمارية معلنة لوكيل Agentforce واحد: المخطط والموضوعات والإجراءات والتدفقات وApex وقوالب المطالبة ومكونات NGA الإضافية. يعرض وثيقة بنية يمكن قراءتها بواسطة الإنسان ورسمًا بيانيًا لاستدعاء حورية البحر من بيانات تعريف وقت التصميم (وليس صفوف تدقيق وقت التشغيل). يتم تشغيله عندما يطلب المستخدم وصف أو رسم تخطيطي أو جرد أو تدقيق أو مستند أو اختلاف (على سبيل المثال الإصدار 3 مقابل الإصدار 5) للبنية / شجرة الإجراءات / بنية الموضوع / جرد الأدوات لوكيل معين حسب اسم واجهة برمجة تطبيقات الوكيل في مؤسسة محددة. لا تقم بتشغيل تتبعات جلسة وقت التشغيل، أو نصوص المحادثة، أو توقيتات الإنشاء، أو سلاسل تدقيق البوابة - تقرأ هذه المهارة بيانات تعريف وقت التصميم فقط (استخدم تحليل agentforce-d360 لتتبعات الجلسة).
