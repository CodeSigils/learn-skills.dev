Gestisce tutte le forme di assegnazione della suite di test per le fasi della pipeline DevOps Center tramite l'endpoint testSuiteStages dell'API Connect. Copre tre modalità: (A) allegare una singola suite a una fase come aggiunta una tantum, (B) mappatura in blocco di più suite a una fase come strategia di test con una tabella di anteprima dell'impatto obbligatoria prima di qualsiasi modifica e (C) aggiunta o rimozione di singole classi di test all'interno di un'assegnazione di suite con regole di governance che escludono i test rifiutati e ripresentano l'elenco finale prima del commit. TRIGGER quando: una suite viene trovata scollegata da una fase della pipeline e l'utente vuole assegnarla; l'utente desidera configurare le mappature suite-stage attraverso una pipeline o assegnare più suite alle fasi come parte di una strategia di test; l'utente desidera aggiungere o rimuovere test in una suite, sincronizzare i test esaminati in una suite o promuovere test in una suite. NON SI ATTIVA quando: si creano nuove classi di test (usa generation-apex-test) o si eseguono test direttamente (usa running-apex-tests).
