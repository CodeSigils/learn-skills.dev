通过 Connect API testSuiteStages 端点管理 DevOps 中心管道阶段的所有形式的测试套件分配。涵盖三种模式：（A）将单个套件作为一次性添加附加到阶段，（B）将多个套件批量映射到阶段作为测试策略，在任何更改之前使用强制影响预览表，以及（C）在套件分配中添加或删除单个测试类，并使用排除被拒绝的测试并在提交之前重新呈现最终列表的治理规则。触发条件：发现套件与管道阶段未链接，并且用户想要分配它；作为测试策略的一部分，用户希望跨管道配置套件到阶段的映射或将多个套件分配到阶段；用户想要添加或删除套件中的测试、将已审核的测试同步到套件中或将测试提升到套件中。不要在以下情况下触发：编写新的测试类（使用generate-apex-test）或直接运行测试（使用running-apex-tests）。
