Gère toutes les formes d’attribution de suites de tests pour les étapes du pipeline DevOps Center via le point de terminaison testSuiteStages de l’API Connect. Couvre trois modes : (A) attacher une seule suite à une étape en tant qu'ajout unique, (B) mapper en bloc plusieurs suites à une étape en tant que stratégie de test avec un tableau d'aperçu d'impact obligatoire avant toute modification, et (C) ajouter ou supprimer des classes de tests individuelles dans une affectation de suite avec des règles de gouvernance qui excluent les tests rejetés et représentent la liste finale avant de s'engager. DÉCLENCHEMENT lorsque : une suite est trouvée non liée à une étape du pipeline et l'utilisateur souhaite l'attribuer ; l'utilisateur souhaite configurer des mappages de suite à étape sur un pipeline ou attribuer plusieurs suites à des étapes dans le cadre d'une stratégie de test ; l'utilisateur souhaite ajouter ou supprimer des tests dans une suite, synchroniser les tests révisés dans une suite ou promouvoir des tests dans une suite. NE PAS DÉCLENCHER lorsque : vous créez de nouvelles classes de tests (utilisez generate-apex-test) ou exécutez des tests directement (utilisez running-apex-tests).
