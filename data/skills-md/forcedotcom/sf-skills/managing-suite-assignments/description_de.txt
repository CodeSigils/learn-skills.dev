Verwaltet alle Formen der Testsuite-Zuweisung für DevOps Center-Pipeline-Stufen über den Connect API testSuiteStages-Endpunkt. Deckt drei Modi ab: (A) Anhängen einer einzelnen Suite an eine Stufe als einmaliges Hinzufügen, (B) Massenzuordnung mehrerer Suiten zu einer Stufe als Teststrategie mit einer obligatorischen Auswirkungsvorschautabelle vor Änderungen und (C) Hinzufügen oder Entfernen einzelner Testklassen innerhalb einer Suite-Zuweisung mit Governance-Regeln, die abgelehnte Tests ausschließen und die endgültige Liste vor dem Festschreiben erneut präsentieren. TRIGGER, wenn: eine Suite ohne Verknüpfung mit einer Pipeline-Stufe gefunden wird und der Benutzer sie zuweisen möchte; Der Benutzer möchte Suite-zu-Stufen-Zuordnungen in einer Pipeline konfigurieren oder im Rahmen einer Teststrategie mehrere Suiten den Stufen zuweisen. Der Benutzer möchte Tests zu einer Suite hinzufügen oder entfernen, überprüfte Tests zu einer Suite synchronisieren oder Tests zu einer Suite hochstufen. NICHT AUSLÖSEN, wenn: neue Testklassen erstellt werden (generierender-apex-test verwenden) oder Tests direkt ausgeführt werden (running-apex-tests verwenden).
