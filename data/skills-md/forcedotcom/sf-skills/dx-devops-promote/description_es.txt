Utilice esta habilidad para impulsar el flujo de trabajo completo de promoción del Centro DevOps para elementos de trabajo y etapas de canalización: valide condiciones previas, prepare elementos de trabajo,, opcionalmente, combine elementos de trabajo que compartan metadatos, promueva uno o más elementos de trabajo o una etapa completa a una etapa de canalización de destino y complete la promoción para finalizar la implementación. DISPARAR cuando el usuario desea promocionar un elemento de trabajo, avanzar cambios al siguiente entorno o etapa, combinar elementos de trabajo para una sola promoción o mover metadatos a través del canal de lanzamiento. El paso de validación obligatorio se ejecuta automáticamente al principio. NO DISPARAR para la creación de elementos de trabajo o actualizaciones de estado (use dx-devops-work-item-manage), para la detección de conflictos o para sondear el estado de una promoción existente.
