Используйте этот навык для управления полным рабочим процессом продвижения DevOps Center для рабочих элементов и этапов конвейера — проверяйте предварительные условия, подготавливайте рабочие элементы, при необходимости объединяйте рабочие элементы с общими метаданными, повышайте один или несколько рабочих элементов или весь этап до целевого этапа конвейера и завершайте продвижение для завершения развертывания. ТРИГГЕР, когда пользователь хочет повысить рабочий элемент, перенести изменения на следующую среду или этап, объединить рабочие элементы для одного продвижения или переместить метаданные через конвейер выпуска. Обязательный шаг проверки запускается автоматически при запуске. НЕ ИСПОЛЬЗУЙТЕ для создания рабочего элемента или обновления статуса (используйте dx-devops-work-item-manage), для обнаружения конфликтов или для опроса статуса существующего продвижения.
