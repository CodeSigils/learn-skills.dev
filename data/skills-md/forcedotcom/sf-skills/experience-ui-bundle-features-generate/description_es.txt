DEBE activarse cuando el proyecto contiene un directorio uiBundles/*/src/ y el usuario desea agregar autenticación o búsqueda a su aplicación. Utilice esta habilidad al agregar autenticación o búsqueda a una aplicación de paquete de interfaz de usuario. Sólo cubre dos funciones: autenticación (iniciar sesión, cerrar sesión, rutas protegidas, gestión de sesiones) y búsqueda (búsqueda global entre páginas y contenidos). Utilice siempre esta habilidad para estas dos funciones en lugar de construir desde cero.
