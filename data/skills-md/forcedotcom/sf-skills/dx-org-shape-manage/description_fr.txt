UTILISEZ TOUJOURS CETTE COMPÉTENCE pour créer, répertorier ou supprimer des formes d'organisation. Une forme d'organisation est une configuration de base capturée (fonctionnalités, limites, édition et paramètres de l'API de métadonnées) d'une organisation source, sans ses données ou métadonnées. À utiliser lorsque l'utilisateur demande de créer/créer/prendre une forme d'organisation, de capturer ou de répliquer la configuration/édition/limites d'une organisation, de lister/afficher/afficher les formes d'organisation existantes (y compris celles INACTIVES/remplacées) ou leurs ID et statut, ou de supprimer/supprimer les formes d'organisation pour une organisation source. Nécessite une organisation source avec Dev Hub et Org Shape pour les organisations Scratch activés. NE PAS DÉCLENCHER pour créer des instantanés ou des organisations scratch (utilisez dx-org-manage).
