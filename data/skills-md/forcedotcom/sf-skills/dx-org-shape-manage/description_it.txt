UTILIZZA SEMPRE QUESTA COMPETENZA per creare, elencare o eliminare forme di organizzazione. Una forma organizzativa è una configurazione di base acquisita (funzionalità, limiti, edizione e impostazioni API dei metadati) di un'organizzazione di origine, senza i relativi dati o metadati. Da utilizzare quando l'utente chiede di creare/creare/assumere una forma organizzativa, acquisire o replicare la configurazione/edizione/limiti di un'organizzazione, elencare/mostrare/visualizzare forme organizzazione esistenti (incluse quelle INATTIVE/sostituite) o i relativi ID e stato oppure eliminare/rimuovere forme organizzazione per un'organizzazione di origine. Richiede un'organizzazione di origine con Dev Hub e Org Shape per le organizzazioni Scratch abilitate. NON ATTIVARE per creare istantanee o organizzazioni scratch (utilizzare dx-org-manage).
