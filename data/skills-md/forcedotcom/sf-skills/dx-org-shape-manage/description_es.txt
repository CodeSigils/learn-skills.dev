USE SIEMPRE ESTA HABILIDAD para crear, enumerar o eliminar formas de organización. Una forma de organización es una configuración de referencia capturada (características, límites, edición y configuración de API de metadatos) de una organización de origen, sin sus datos o metadatos. Úselo cuando el usuario solicite crear/crear/tomar una forma de organización, capturar o replicar la configuración/edición/límites de una organización, listar/mostrar/ver formas de organización existentes (incluidas las INACTIVAS/reemplazadas) o sus ID y estado, o eliminar/eliminar formas de organización para una organización de origen. Requiere una organización de origen con Dev Hub y Org Shape para organizaciones Scratch habilitadas. NO DISPARAR para crear instantáneas u organizaciones borrador (use dx-org-manage).
