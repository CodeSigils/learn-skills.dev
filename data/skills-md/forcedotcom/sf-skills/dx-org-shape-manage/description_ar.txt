استخدم هذه المهارة دائمًا لإنشاء أو سرد أو حذف أشكال المنظمة. شكل المنظمة هو تكوين أساسي مُلتقط (الميزات، والحدود، والإصدار، وإعدادات واجهة برمجة تطبيقات البيانات الوصفية) لمنظمة المصدر، بدون بياناتها أو ميتاداتها. استخدمها عندما يطلب المستخدم إنشاء/عمل/أخذ شكل منظمة، أو التقاط أو تكرار تكوين/إصدار/حدود المنظمة، أو سرد/عرض/مشاهدة أشكال المنظمة الحالية (بما في ذلك غير النشطة/المستبدلة) أو معرّفاتها وحالتها، أو حذف/إزالة أشكال المنظمة لمنظمة المصدر. يتطلب وجود منظمة مصدر مع تمكين Dev Hub وشكل المنظمة للمنظمات المؤقتة. لا تُفعَّل هذه المهارة لإنشاء لقطات أو منظمات مؤقتة (استخدم dx-org-manage).

يرجى دائمًا الرد بلغة المستخدم.
