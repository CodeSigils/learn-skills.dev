ВСЕГДА ИСПОЛЬЗУЙТЕ ЭТОТ НАВЫК для создания, составления списка или удаления организационных структур. Форма организации — это записанная базовая конфигурация (функции, ограничения, версия и настройки API метаданных) исходной организации без ее данных или метаданных. Используйте, когда пользователь просит создать/создать/принять форму организации, записать или реплицировать конфигурацию/редакцию/ограничения организации, перечислить/показать/просмотреть существующие формы организации (включая НЕАКТИВНЫЕ/замененные) или их идентификаторы и статус, а также удалить/удалить формы организации для исходной организации. Требуется исходная организация с включенными Dev Hub и Org Shape для Scratch Orgs. НЕ ИСПОЛЬЗУЙТЕ ТРИГГЕР для создания снимков или чистых организаций (используйте dx-org-manage).
