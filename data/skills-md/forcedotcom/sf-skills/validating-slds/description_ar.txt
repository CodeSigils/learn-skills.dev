قم بتدقيق مكونات Lightning Web Components للتأكد من امتثال SLDS وإنتاج تقرير جودة مسجل. يقوم بتشغيل SLDS linter، ويحلل CSS لاستخدام الخطاف والاقتران، ويفحص HTML بحثًا عن سمات إمكانية الوصول، ويسجل النتائج عبر الفئات في تقدير عام. يُستخدم عندما يُطلب منك "تسجيل المكون الخاص بي"، أو "بطاقة أداء SLDS"، أو "تقرير الجودة"، أو "تدقيق امتثال SLDS"، أو "ما مدى جودة SLDS الخاصة بي"، أو "التحقق من جودة المكون"، أو "تقييم المكون الخاص بي"، أو "تقييم المكون الخاص بي"، أو "هل هذا المكون جاهز للشحن؟"، أو "انظر إلى LWC الخاص بي بحثًا عن المشكلات"، أو "تدقيق هذا قبل إرساله"، أو "مراجعة المكون الخاص بي قبل مراجعة الكود"، أو في أي وقت يريد المستخدم تقييم الجودة أو فحص جاهزية الإنتاج على مكون LWC أو SLDS. ليس لإصلاح الانتهاكات (استخدم مكونات الارتقاء إلى slds2) أو بناء مكونات جديدة (استخدم تطبيق slds).
