Auditez les composants Web Lightning pour vérifier leur conformité SLDS et produisez un rapport de qualité noté. Exécute le linter SLDS, analyse le CSS pour l'utilisation et l'appariement des hooks de thématisation, vérifie le HTML pour les attributs d'accessibilité et note les résultats dans toutes les catégories dans une note globale. À utiliser lorsqu'on lui demande de « noter mon composant », « carte de score SLDS », « rapport de qualité », « auditer la conformité SLDS », « quelle est la qualité de mon SLDS », « vérifier la qualité du composant », « évaluer mon composant », « évaluer mon composant », « ce composant est-il prêt à être expédié ? Pas pour corriger les violations (utilisez uplifting-components-to-slds2) ou pour créer de nouveaux composants (utilisez apply-slds).
