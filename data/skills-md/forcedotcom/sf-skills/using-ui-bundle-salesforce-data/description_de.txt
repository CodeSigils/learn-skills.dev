MUSS aktiviert werden, wenn das Projekt ein uiBundles/*/src/-Verzeichnis enthält und die Aufgabe IRGENDEINEN Salesforce-Datensatzvorgang umfasst – Lesen, Erstellen, Aktualisieren oder Löschen. Verwenden Sie diese Fähigkeit, wenn Sie Formulare erstellen, die an Salesforce übermittelt werden, Seiten, die Salesforce-Datensätze anzeigen, oder Code erstellen, der Salesforce-Objekte oder benutzerdefinierte Objekte berührt. Aktivieren Sie diese Option, wenn Dateien unter uiBundles/*/src/ aus @salesforce/sdk-data importiert werden oder wenn *.graphql-Dateien oder codegen.yml vorhanden sind. Dieser Skill besitzt alle Salesforce-Datenzugriffsmuster in UI-Bundles. Gilt nicht für die Authentifizierung/OAuth-Einrichtung, Schemaänderungen, Massen-/Tooling-/Metadaten-API oder deklarative Automatisierung.
