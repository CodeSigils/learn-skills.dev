DEBE activarse cuando el proyecto contiene un directorio uiBundles/*/src/ y la tarea implica CUALQUIER operación de registro de Salesforce: leer, crear, actualizar o eliminar. Utilice esta habilidad al crear formularios que se envían a Salesforce, páginas que muestran registros de Salesforce o cualquier código que toque objetos de Salesforce u objetos personalizados. Actívelo cuando los archivos en uiBundles/*/src/ se importen desde @salesforce/sdk-data, o cuando existan archivos *.graphql o codegen.yml. Esta habilidad posee todos los patrones de acceso a datos de Salesforce en paquetes de UI. No se aplica a la autenticación/configuración de OAuth, cambios de esquema, API masiva/herramientas/metadatos ni automatización declarativa.
