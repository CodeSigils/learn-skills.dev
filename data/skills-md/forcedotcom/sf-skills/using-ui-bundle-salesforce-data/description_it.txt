DEVE essere attivato quando il progetto contiene una directory uiBundles/*/src/ e l'attività coinvolge QUALSIASI operazione di record Salesforce: lettura, creazione, aggiornamento o eliminazione. Utilizzare questa capacità durante la creazione di moduli da inviare a Salesforce, pagine che visualizzano record Salesforce o qualsiasi codice che tocca oggetti Salesforce o oggetti personalizzati. Attiva quando i file in uiBundles/*/src/ vengono importati da @salesforce/sdk-data o quando esistono file *.graphql o codegen.yml. Questa competenza possiede tutti i modelli di accesso ai dati Salesforce nei pacchetti UI. Non si applica alla configurazione di autenticazione/OAuth, modifiche dello schema, API in blocco/strumenti/metadati o automazione dichiarativa.
