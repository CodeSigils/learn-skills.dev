DOIT s'activer lorsque l'utilisateur souhaite empaqueter, distribuer ou installer/mettre à niveau/désinstaller/promouvoir un package d'interface utilisateur en tant que package Salesforce de deuxième génération (2GP) (le projet peut contenir uiBundles/ ou sfdx-project.json pour les tâches d'empaquetage ; les tâches d'installation/de mise à niveau peuvent manquer de fichiers de bundle locaux). Gère la création d'un package empaquetable, le choix de la version gérée/déverrouillée, la création d'un package/version avec le package sf, l'installation/la mise à niveau dans une autre organisation et les échecs de débogage. DÉCLENCHEUR sur l'empaquetage, 2GP, package géré, package déverrouillé, AppExchange, version du package, package sf, installation du package sf, mise à niveau du package sf, installation d'un package, mise à niveau d'un package, distribution inter-organisations. NE PAS DÉCLENCHER pour le déploiement de sources simples sur une organisation (utilisez experience-ui-bundle-deploy) ou pour l'échafaudage d'un nouveau bundle (utilisez experience-ui-bundle-project-generate). Appliquez au coup par coup – faites UNIQUEMENT la partie demandée.
