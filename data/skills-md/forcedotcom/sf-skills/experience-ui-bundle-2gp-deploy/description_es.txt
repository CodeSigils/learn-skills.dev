DEBE activarse cuando el usuario desee empaquetar, distribuir o instalar/actualizar/desinstalar/promover un paquete de interfaz de usuario como un paquete de segunda generación (2GP) de Salesforce (el proyecto puede contener uiBundles/ o sfdx-project.json para tareas de empaquetado; las tareas de instalación/actualización pueden carecer de archivos de paquete locales).
