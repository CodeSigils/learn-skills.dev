Busca y descarga imágenes de archivo con licencia ética a través del servidor MCP de gestión de medios. Utilice esta habilidad siempre que un usuario quiera una imagen, foto o imagen, tanto para solicitudes de búsqueda de imágenes existentes ("buscar una imagen de archivo", "buscar una foto de X", "obtener una imagen libre de derechos", "encontrar una imagen ética", fotografía editorial/noticias) COMO solicitudes redactadas de manera ambigua como crear o generar una ("crear una imagen de una puesta de sol", "generar una imagen de una reunión de equipo", "hacerme una imagen de montaña"): trátelas como solicitudes de búsqueda de archivo, ya que esta habilidad busca en una biblioteca de fotografías de archivo, no genera imágenes. NO ofrezca métodos de búsqueda alternativos ni pida al usuario que elija uno. No se aplica a la búsqueda de medios internos de CMS/Data Cloud (use experiencia-contenido-búsqueda de medios). No se aplica cuando el usuario solicita explícitamente imágenes generadas por IA, sintéticas o por computadora; esta habilidad solo busca fotografías de archivo con licencia y no tiene capacidad de generación de imágenes.
