Tipos de metadatos de ISV App Analytics: AppAnalyticsQueryRequest y AppAnalyticsSettings. Utilice esta habilidad cuando el usuario pregunte sobre cómo recuperar datos de uso de paquetes administrados, configurar el modo de simulación de App Analytics, consultar instantáneas de suscriptores o comprender el ciclo de vida de AppAnalyticsQueryRequest (Nuevo → Pendiente → Completo → Caducado). DISPARAR cuando: el usuario menciona App Analytics, AppAnalyticsQueryRequest, AppAnalyticsSettings, datos de uso de paquetes, análisis de suscriptores, análisis de ISV o modo de simulación para análisis de aplicaciones. NO ACTIVAR cuando: la tarea se refiere a informes/paneles de control estándar de Salesforce (use habilidades de generación de informes), SOQL personalizado en cuenta/contacto (use querying-soql) o consulta/búsqueda de Data Cloud (use retrieving-datacloud).
