ДОЛЖЕН активироваться, если проект содержит каталог uiBundles/*/src/ и задача включает создание или настройку пользовательского приложения для размещения пакета пользовательского интерфейса в Lightning Experience. Используйте этот навык при создании записи метаданных CustomApplication, чтобы отображать пакет пользовательского интерфейса в средстве запуска приложений. Активируйте, когда файлы, соответствующие application/*.app-meta.xml, существуют и требуют изменения, или когда пользователь хочет предоставить доступ к своему приложению через средство запуска приложений Lightning без сайта Digital Experience. НЕ используйте для этого создание пользовательского приложения — приложения пакета пользовательского интерфейса не используют вкладки, переопределения действий или гибкие страницы.
