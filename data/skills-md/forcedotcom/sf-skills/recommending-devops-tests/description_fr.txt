Analyse une différence de validation et les métadonnées disponibles de la suite de tests DevOps Center pour recommander les suites de tests existantes les plus pertinentes, puis signale les lacunes de couverture là où aucune suite ne couvre une nouvelle méthode – via un raisonnement pur, aucun appel système au-delà des requêtes préalables. Utilisez cette compétence lorsqu'un développeur souhaite savoir quelles suites de tests exécuter pour une validation ou une différence spécifique, quels tests couvrent ses modifications ou souhaite des recommandations de suites au moment de la validation. DÉCLENCHEMENT lorsque : l'utilisateur demande quelles suites de tests exécuter pour un commit/diff, demande quels tests couvrent leurs modifications ou demande des recommandations de suite avant de promouvoir. NE PAS DÉCLENCHER lorsque : vous créez de nouveaux tests (utilisez generate-apex-test) ou exécutez sf apex run test directement (utilisez running-apex-tests).
