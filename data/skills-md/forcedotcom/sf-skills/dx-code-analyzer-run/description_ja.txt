Salesforce Code Analyzer を実行して、コードをスキャンして、セキュリティ、パフォーマンス、ベストプラクティス、およびコードスタイル違反がないか確認します。すべてのエンジン (PMD、ESLint、CPD、RetireJS、Flow、SFGE、ApexGuru)、ターゲット (ファイル、フォルダー、git diff)、カテゴリ、および重大度をサポートします。スキャン後の探索も処理します。エンジン/重大度/カテゴリ/ファイルごとに結果をフィルタリングし、特定のルールが何を意味するかを説明します。トリガーのタイミング: ユーザーが「コードをスキャンする」、「セキュリティ問題をチェックする」、「PMD/ESLint を実行する」、「重複を見つける」、「フローを分析する」、「脆弱なライブラリをチェックする」、「AppExchange レビュー」、「LWC をリントする」、「静的分析」、「コードの品質」、「セキュリティ違反のみを表示する」、「このルールとは何ですか」、「説明する」と発言した場合にトリガーされます。 「ApexCRUDViolation」、「結果のフィルタ」、またはエンジン/ファイルタイプ (.cls、.trigger、.js、.flow-meta.xml) についての言及。このスキルを使用して、スキャン、結果の探索、ルールの理解、および利用可能なルールのリストを作成します。次の場合はトリガーしないでください: ユーザーがスキャンせずにコードを修正したい場合、またはインストール/構成についてのみ質問する場合。
