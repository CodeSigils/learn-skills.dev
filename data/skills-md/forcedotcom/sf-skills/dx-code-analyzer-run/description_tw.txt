執行 Salesforce Code Analyzer 來掃描程式碼的安全性、效能、最佳實務和程式碼風格違規情況。支援所有引擎（PMD、ESLint、CPD、RetireJS、Flow、SFGE、ApexGuru）、目標（檔案、資料夾、git diff）、類別和嚴重性。也處理掃描後探索：按引擎/嚴重性/類別/文件過濾結果，並解釋特定規則的含義。触发时间：用户说“扫描我的代码”、“检查安全问题”、“运行 PMD/ESLint”、“查找重复项”、“分析流程”、“检查易受攻击的库”、“AppExchange 审核”、“检查我的 LWC”、“静态分析”、“代码质量”、“仅显示安全违规”、“此规则是什么”、“解释 ApexCRUDViolation”、 “過濾結果”，或提及引擎/檔案類型（.cls、.trigger、.js、.flow-meta.xml）。使用此技能來掃描、探索結果、理解規則和列出可用規則。請勿在以下情況觸發：使用者想要修復程式碼而不掃描，或僅詢問安裝/配置。
