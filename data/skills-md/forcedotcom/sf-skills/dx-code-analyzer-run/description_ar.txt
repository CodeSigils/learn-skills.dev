قم بتشغيل Salesforce Code Analyzer لفحص التعليمات البرمجية بحثًا عن الأمان والأداء وأفضل الممارسات وانتهاكات نمط التعليمات البرمجية. يدعم جميع المحركات (PMD، ESLint، CPD، RetireJS، Flow، SFGE، ApexGuru)، والأهداف (الملفات، المجلدات، git diff)، الفئات، ومستويات الخطورة. يتعامل أيضًا مع استكشاف ما بعد الفحص: تصفية النتائج حسب المحرك/الخطورة/الفئة/الملف، وشرح ما تعنيه القواعد المحددة. يتم تشغيله عندما: يقول المستخدم "مسح الكود الخاص بي"، أو "التحقق من مشكلات الأمان"، أو "تشغيل PMD/ESLint"، أو "البحث عن التكرارات"، أو "تحليل التدفقات"، أو "التحقق من المكتبات الضعيفة"، أو "مراجعة AppExchange"، أو "Lint my LWC"، أو "التحليل الثابت"، أو "جودة الكود"، أو "إظهار انتهاكات الأمان فقط"، أو "ما هي هذه القاعدة"، أو "شرح ApexCRUDViolation"، أو "نتائج التصفية"، أو الإشارات المحركات/أنواع الملفات (.cls، .trigger، .js، .flow-meta.xml). استخدم هذه المهارة لمسح النتائج واستكشافها وفهم القواعد وإدراج القواعد المتاحة. لا تقم بالتشغيل عندما: يريد المستخدم إصلاح التعليمات البرمجية دون إجراء مسح ضوئي، أو يسأل فقط عن التثبيت/التكوين.
