Запустите анализатор кода Salesforce, чтобы просканировать код на наличие нарушений безопасности, производительности, рекомендаций и стиля кода. Поддерживает все механизмы (PMD, ESLint, CPD, RetireJS, Flow, SFGE, ApexGuru), цели (файлы, папки, различия git), категории и уровни серьезности. Также выполняет исследование после сканирования: фильтрует результаты по механизму/серьезности/категории/файлу и объясняет, что означают конкретные правила. ТРИГГЕР, когда: пользователь говорит «сканировать мой код», «проверить наличие проблем безопасности», «запустить PMD/ESLint», «найти дубликаты», «проанализировать потоки», «проверить уязвимые библиотеки», «проверить AppExchange», «проверить мой LWC», «статический анализ», «качество кода», «показать только нарушения безопасности», «что это за правило», «объяснить ApexCRUDViolation», «фильтровать результаты» или упоминания механизмы/типы файлов (.cls, .trigger, .js, .flow-meta.xml). Используйте этот навык для сканирования, изучения результатов, понимания правил и составления списка доступных правил. НЕ ЗАПУСКАТЬ, когда: пользователь хочет исправить код без сканирования или спрашивает ТОЛЬКО об установке/настройке.
