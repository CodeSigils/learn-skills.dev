Комплексный оркестратор автопилота для настройки интеграции Microsoft Teams в Salesforce Service Cloud ITSM — запускает весь процесс (включение функции Teams для обслуживания сотрудников, регистрация приложения Microsoft Entra, заполнение именованных учетных данных, настройка контрольных списков ИТ-службы и ИТ-службы, включение Swarming и, при необходимости, внедрение агента Agentforce) за один непрерывный проход, останавливаясь только в тех моментах, когда человек должен действовать. Используйте, когда пользователь просит настроить Microsoft Teams для ITSM комплексно, «настроить команды для ИТ-сервиса», «выполнить настройку ITSM для всей команды», «настроить команды Microsoft для обслуживания сотрудников» или хочет получить пошаговое руководство по Teams ITSM. Делегирует каждый этап специализированному детскому навыку во время выполнения самой последовательности. НЕ ЗАПУСКАЙТЕ, когда пользователь просит включить только Teams, настроить только контрольный список ИТ-службы или ИТ-службы или включить только Swarming — в таких случаях делегируйте непосредственно конкретному дочернему навыку.
