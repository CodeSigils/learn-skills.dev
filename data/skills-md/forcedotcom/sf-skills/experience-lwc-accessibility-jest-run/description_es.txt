Utilice SIEMPRE cuando ejecute pruebas Jest de accesibilidad de Sa11y para un componente web Lightning: localmente antes de enviarlo, producir los comandos exactos, ejecutar un archivo frente a un conjunto completo, seleccionar pruebas mediante convención de nomenclatura, guardar HTML renderizado por Sa11y o reproducir una falla de Sa11y/A11yBug. Cubre el núcleo de Salesforce (Bazel; `WORKSPACE`, `./core` root, `bazel test //<module>:<target>`) y `npx jest` independiente (`.accessibility.test.js`, `@sa11y/jest`). REQUERIDO cuando un mensaje solicita un `run-plan.md` para las pruebas de accesibilidad, cuyo código de salida significa que una prueba de accesibilidad falló, o hace referencia a `SA11Y_*` env vars, `A11yBug` o una ruta core-Bazel `modules/<mod>/<cmp>/__tests__/*.test.js`. NO confíe en el conocimiento general: esta habilidad tiene el objetivo Bazel de archivo único correcto y la solución alternativa EPERM. NO DISPARE para pruebas de Jest funcionales (no accesibles), revise siempre sin ejecutar pruebas (use experiencia-lwc-accessibility-validate) o pruebas funcionales de todas basadas en Selenium.
