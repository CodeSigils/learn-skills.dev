استخدم دائمًا عند تشغيل اختبارات Jest لإمكانية الوصول Sa11y لمكون Lightning Web Component - محليًا قبل الدفع، أو إنتاج الأمر (الأوامر) الدقيق، أو تشغيل ملف واحد مقابل مجموعة كاملة، أو تحديد الاختبارات عن طريق اصطلاح التسمية، أو حفظ HTML المقدم بواسطة Sa11y، أو إعادة إنتاج فشل Sa11y / A11yBug. يغطي Salesforce الأساسية (Bazel؛ `WORKSPACE`، `./core` الجذر، `bazel test //<module>:<target>`) والمستقل `npx jest` (`.accessibility.test.js`، `@sa11y/jest`). مطلوب عندما يطلب موجه `run-plan.md` لاختبارات إمكانية الوصول، حيث يعني رمز الخروج فشل اختبار إمكانية الوصول، أو يشير إلى `SA11Y_*` env vars، أو `A11yBug`، أو مسار core-Bazel `modules/<mod>/<cmp>/__tests__/*.test.js`. لا تعتمد على المعرفة العامة - تحتوي هذه المهارة على هدف Bazel الصحيح ذو الملف الواحد والحل البديل لـ EPERM. لا تقم بتشغيل اختبارات الدعابة الوظيفية (عدم إمكانية الوصول)، أو مراجعة a11y دون تشغيل الاختبارات (استخدم experience-lwc-accessibility-validate)، أو اختبارات a11y الوظيفية المستندة إلى السيلينيوم.
