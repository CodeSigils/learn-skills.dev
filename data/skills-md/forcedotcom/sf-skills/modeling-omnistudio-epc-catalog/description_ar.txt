مهارة نمذجة المنتج Salesforce Industries CME EPC لإنشاء الكتالوج المستند إلى Product2. يُستخدم عند إنشاء منتجات EPC، أو تكوين سمات المنتج، أو إنشاء حزم العروض باستخدام عناصر المنتج الفرعية، أو مراجعة بيانات تعريف EPC DataPack JSON لتغييرات كتالوج المنتج. يتم تشغيله عندما: يقوم المستخدم بإنشاء أو تحديث سجلات Product2 EPC، أو حمولات AttributeAssignment، أو AttributeMetadata/AttributeDefaultValues، أو حزم العروض، أو علاقات ProductChildItem. لا تقم بالتشغيل عند: تصميم OmniScripts/FlexCards/إجراءات التكامل (استخدم Building-omnistudio-omniscript، أو Building-omnistudio-flexcard، أو إجراءات بناء omnistudio-integration)، أو تنفيذ منطق أعمال Apex (استخدم generator-apex)، أو استكشاف أخطاء مسارات النشر وإصلاحها (استخدم بيانات التعريف النشر).
