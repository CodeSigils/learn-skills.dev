MUSS aktiviert werden, wenn das Projekt ein uiBundles/*/src/-Verzeichnis enthält und die Aufgabe das Hinzufügen oder Ändern eines Chat-Widgets, Chatbots oder einer Konversations-KI umfasst. Verwenden Sie diese Fähigkeit, wenn der Benutzer einen Agenten, Chatbot, Chat-Widget, Konversations-Client oder KI-Assistenten hinzufügen, einbetten, integrieren, konfigurieren, gestalten oder entfernen möchte. Behandelt Stil (Farben, Schriftarten, Abstände, Ränder), Layout (inline vs. schwebend, Breite, Höhe, Abmessungen) und Requisiten (agentId, agentLabel, headerEnabled, showHeaderIcon, showAvatar, styleTokens). Aktivieren Sie diese Option, wenn Dateien unter uiBundles/*/src/ AgentforceConversationClient importieren oder wenn Sie einer Seite Chat- oder Agentenfunktionen hinzufügen. Erstellen Sie niemals einen benutzerdefinierten Agenten, Chatbot oder eine Chat-Widget-Komponente.
