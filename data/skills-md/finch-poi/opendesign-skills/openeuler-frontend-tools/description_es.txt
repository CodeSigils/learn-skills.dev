Convenciones y kit de herramientas de desarrollo frontend del portal openEuler. Utilice esta habilidad cuando necesite elementos componibles comunes, mixins SCSS o funciones de utilidad del proyecto. Casos de uso: (1) busque el elemento componible useScreen cuando necesite una adaptación de pantalla responsiva, (2) busque font.scss cuando necesite combinaciones de fuentes responsivas, (3) busque utils/common.ts cuando necesite utilidades para parámetros de URL, cookies, etc., (4) busque las utilidades correspondientes cuando necesite elementos componibles para internacionalización, portapapeles, búsqueda antirrebote, etc.
