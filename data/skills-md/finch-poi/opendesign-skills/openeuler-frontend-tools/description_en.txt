openEuler Portal frontend development toolkit and conventions. Use this skill when you need common composables, SCSS mixins, or utility functions from the project. Use cases: (1) look up the useScreen composable when you need responsive screen adaptation, (2) look up font.scss when you need responsive font mixins, (3) look up utils/common.ts when you need utilities for URL parameters, cookies, etc., (4) look up the corresponding utilities when you need composables for internationalization, clipboard, debounced search, etc.
