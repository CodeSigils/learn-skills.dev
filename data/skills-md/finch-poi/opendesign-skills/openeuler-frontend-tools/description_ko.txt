openEuler Portal 프런트엔드 개발 도구 및 표준 컬렉션. 프로젝트의 일반 컴포저블, SCSS 믹스인 또는 유틸리티 기능이 필요할 때 이 기술을 사용하세요. 사용 시나리오: (1) 반응형 화면 적응이 필요할 때 useScreen 컴포저블을 검색하고, (2) 반응형 글꼴 믹스인이 필요할 때 Font.scss를 검색하고, (3) URL 매개변수 또는 쿠키와 같은 유틸리티 기능이 필요할 때 utils/common.ts를 검색하고, (4) 국제화, 클립보드, 디바운스된 검색 등을 위한 컴포저블이 필요할 때 해당 유틸리티를 검색합니다.
