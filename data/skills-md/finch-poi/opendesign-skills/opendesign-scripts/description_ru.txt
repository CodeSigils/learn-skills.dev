Руководство по использованию инструмента OpenDesign Build Script. Используйте этот навык, когда вам нужно использовать инструмент CLI @opensig/open-scripts для создания значков, очистки SVG, создания компонентов, компиляции стилей и генерации токенов дизайна. Поддерживает 5 команд: gen:icon (компонент значков SVG в Vue), clean:svg (очистка и оптимизация SVG), build:comComponent (сборка библиотеки компонентов Vue), build:style (компиляция стиля SCSS), gen:token (генерация CSS-переменных токена дизайна). Варианты использования: (1) настройка и выполнение сценариев сборки, (2) запись файлов конфигурации значков/токенов, (3) понимание процесса сборки и использования команд.
