Руководство по использованию инструмента OpenDesign Build Script. Используйте этот навык, когда вам нужен интерфейс командной строки @opensig/open-scripts для создания значков, очистки SVG, создания компонентов, компиляции стилей или создания токенов дизайна. Он поддерживает пять команд: gen:icon (SVG → Компоненты значков Vue), clean:svg (очистка и оптимизация SVG), build:comComponent (сборка библиотеки компонентов Vue), build:style (компиляция SCSS), gen:token (переменные CSS дизайнерского токена). Варианты использования: (1) настройка и запуск сценариев сборки, (2) запись файлов конфигурации значков/токенов, (3) понимание потоков сборки и использования команд.
