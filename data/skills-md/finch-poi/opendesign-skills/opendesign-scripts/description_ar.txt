دليل أدوات البرنامج النصي لبناء OpenDesign. استخدم هذه المهارة عندما تحتاج إلى إنشاء أيقونات، أو تنظيف ملفات SVG، أو إنشاء مكونات، أو تجميع الأنماط، أو إنشاء رموز تصميم مميزة باستخدام @opensig/open-scripts CLI. وهو يدعم خمسة أوامر: gen:icon (مكون أيقونة SVG إلى Vue)، Clean:svg (تنظيف SVG وتحسينه)، build:component (إنشاء مكتبة مكونات Vue)، build:style (تجميع نمط SCSS)، gen:token (إنشاء متغير CSS للتصميم المميز). حالات الاستخدام: (1) تكوين البرامج النصية للإنشاء وتشغيلها، (2) كتابة ملفات تكوين الرمز/الرمز المميز، (3) فهم تدفق البناء واستخدام الأوامر
