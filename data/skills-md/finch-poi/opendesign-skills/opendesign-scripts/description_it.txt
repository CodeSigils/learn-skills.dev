Guida all'utilizzo dello strumento Build Script di OpenDesign. Utilizza questa competenza quando devi utilizzare lo strumento CLI @opensig/open-scripts per la generazione di icone, la pulizia SVG, la creazione di componenti, la compilazione di stili e la generazione di token di progettazione. Supporta 5 comandi: gen:icon (componente icona da SVG a Vue), clean:svg (pulizia e ottimizzazione SVG), build:component (build della libreria dei componenti Vue), build:style (compilazione dello stile SCSS), gen:token (generazione di variabili CSS del token di progettazione). Casi d'uso: (1) configurare ed eseguire script di build, (2) scrivere file di configurazione di icone/token, (3) comprendere i processi di build e l'utilizzo dei comandi
