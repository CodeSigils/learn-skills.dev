OpenDesign Build Script Tool Usage Guide. Use this skill when you need the @opensig/open-scripts CLI for icon generation, SVG cleanup, component building, style compilation, or design-token creation. It supports five commands: gen:icon (SVG → Vue icon components), clean:svg (SVG cleanup & optimization), build:component (Vue component library build), build:style (SCSS compilation), gen:token (design-token CSS variables). Use cases: (1) configure & run build scripts, (2) write icon/token config files, (3) understand build flows & command usage
