OpenDesign Build Script Tool Usage Guide. Use this skill when you need to use the @opensig/open-scripts CLI tool for icon generation, SVG cleanup, component building, style compilation, and design token generation. Supports 5 commands: gen:icon (SVG to Vue icon component), clean:svg (SVG cleanup and optimization), build:component (Vue component library build), build:style (SCSS style compilation), gen:token (design token CSS variable generation). Use cases: (1) configure and execute build scripts, (2) write icon/token configuration files, (3) understand build process and command usage
