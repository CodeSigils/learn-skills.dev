Guía de uso de la herramienta OpenDesign Build Script. Utilice esta habilidad cuando necesite utilizar la herramienta CLI @opensig/open-scripts para la generación de iconos, limpieza de SVG, creación de componentes, compilación de estilos y generación de tokens de diseño. Admite 5 comandos: gen:icon (componente de icono de SVG a Vue), clean:svg (limpieza y optimización de SVG), build:component (compilación de biblioteca de componentes de Vue), build:style (compilación de estilo SCSS), gen:token (generación de variable CSS de token de diseño). Casos de uso: (1) configurar y ejecutar scripts de compilación, (2) escribir archivos de configuración de íconos/tokens, (3) comprender el proceso de compilación y el uso de comandos
