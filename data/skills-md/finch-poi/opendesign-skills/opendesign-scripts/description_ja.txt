OpenDesign ビルド スクリプト ツールの使用ガイド。このスキルは、アイコンの生成、SVG クリーンアップ、コンポーネントの構築、スタイルのコンパイル、デザイン トークンの生成に @opensig/open-scripts CLI ツールを使用する必要がある場合に使用します。 5 つのコマンドをサポートします: gen:icon (SVG から Vue アイコン コンポーネントへ)、clean:svg (SVG クリーンアップと最適化)、build:component (Vue コンポーネント ライブラリ ビルド)、build:style (SCSS スタイル コンパイル)、gen:token (デザイン トークン CSS 変数生成)。使用例: (1) ビルド スクリプトの構成と実行、(2) アイコン/トークン構成ファイルの作成、(3) ビルド プロセスとコマンドの使用法の理解
