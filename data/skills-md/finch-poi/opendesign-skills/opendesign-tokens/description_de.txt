OpenDesign-Design-Token-Leitfaden. Nutzen Sie diesen Skill, wenn Sie CSS-Variablen aus dem @opensig/opendesign-token-Paket verwenden müssen. Es enthält ein vollständiges Token-System für sechs Themen (openEuler/Ascend/Kunpeng/Mindspore/openGauss/openUBMC), das alle Design-Token unterstützt, einschließlich Farben, Abstände, Rahmenradius, Typografie, Schatten, responsive Typografie und Rastersysteme. Anwendungsfälle: (1) Semantische Token finden, die Farbwerten entsprechen, (2) Token-Namen für Abstand/Rahmenradius/Typografie abrufen, (3) Unterschiede zwischen den sechs Themen verstehen, (4) CSS-Variablen im Code anstelle von fest codierten Werten verwenden, (5) reaktionsfähige Token für die Anpassung mehrerer Haltepunkte verwenden
