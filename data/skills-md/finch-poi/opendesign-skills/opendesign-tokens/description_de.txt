OpenDesign-Design-Token-Leitfaden. Verwenden Sie diesen Skill, wenn CSS-Variablen aus dem @opensig/opendesign-token-Paket benötigt werden. Enthält ein vollständiges Token-System für sechs Themen (openEuler/Ascend/Kunpeng/Mindspore/openGauss/openUBMC), das Farben, Abstände, Radius, Typografie, Schatten, responsive Schriftart, Rastersysteme und alle Design-Token abdeckt. Anwendungsfälle: (1) semantische Token für Farbwerte finden, (2) Token-Namen für Abstand/Radius/Typografie abrufen, (3) Unterschiede zwischen den sechs Themen verstehen, (4) hartcodierte Werte durch CSS-Variablen im Code ersetzen, (5) reaktionsfähige Token für die Anpassung mehrerer Haltepunkte verwenden
