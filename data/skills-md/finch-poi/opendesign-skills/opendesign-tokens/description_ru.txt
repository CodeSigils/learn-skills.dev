Руководство по токенам OpenDesign Design. Используйте этот навык, когда вам нужно использовать переменные CSS из пакета @opensig/opendesign-token. Он содержит полную систему токенов для шести тем (openEuler/Ascend/Kunpeng/Mindspore/openGauss/openUBMC), охватывающую все токены дизайна, включая цвета, интервалы, радиус, типографику, тени, адаптивную типографику и системы сеток. Варианты использования: (1) Найти семантические токены для значений цвета, (2) Получить имена токенов для интервала/радиуса/типографики, (3) Понять различия между шестью темами, (4) Заменить жестко запрограммированные значения переменными CSS в коде, (5) Использовать адаптивные токены для адаптации с несколькими точками останова.
