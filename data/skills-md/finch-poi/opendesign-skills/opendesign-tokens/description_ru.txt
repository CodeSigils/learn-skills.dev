Руководство по токенам OpenDesign Design. Используйте этот навык, когда нужны переменные CSS из пакета @opensig/opendesign-token. Содержит полную систему токенов для шести тем (openEuler/Ascend/Kunpeng/Mindspore/openGauss/openUBMC), включая цвета, интервалы, радиус, типографику, тени, адаптивный шрифт, системы сеток и все токены дизайна. Варианты использования: (1) найти семантические токены для значений цвета, (2) получить имена токенов для интервала/радиуса/типографики, (3) понять различия между шестью темами, (4) заменить жестко закодированные значения переменными CSS в коде, (5) использовать адаптивные токены для адаптации с несколькими точками останова
