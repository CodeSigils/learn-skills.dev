Guide des jetons de conception OpenDesign. Utilisez cette compétence lorsque les variables CSS du package @opensig/opendesign-token sont nécessaires. Contient un système de jetons complet pour six thèmes (openEuler/Ascend/Kunpeng/Mindspore/openGauss/openUBMC), couvrant les couleurs, l'espacement, le rayon, la typographie, les ombres, le type réactif, les systèmes de grille et tous les jetons de conception. Cas d'utilisation : (1) rechercher des jetons sémantiques pour les valeurs de couleur, (2) obtenir les noms de jetons pour l'espacement/rayon/typographie, (3) comprendre les différences entre les six thèmes, (4) remplacer les valeurs codées en dur par des variables CSS dans le code, (5) utiliser des jetons réactifs pour une adaptation multi-points d'arrêt
