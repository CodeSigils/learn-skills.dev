Guide des jetons de conception OpenDesign. Utilisez cette compétence lorsque vous devez utiliser des variables CSS du package @opensig/opendesign-token. Il contient un système complet de jetons pour six thèmes (openEuler/Ascend/Kunpeng/Mindspore/openGauss/openUBMC), couvrant tous les jetons de conception, y compris les couleurs, l'espacement, le rayon des bordures, la typographie, les ombres, la typographie réactive et les systèmes de grille. Cas d'utilisation : (1) Rechercher des jetons sémantiques correspondant aux valeurs de couleur, (2) Obtenir les noms de jetons pour l'espacement/le rayon de bordure/la typographie, (3) Comprendre les différences entre les six thèmes, (4) Utiliser des variables CSS dans le code au lieu de valeurs codées en dur, (5) Utiliser des jetons réactifs pour une adaptation multi-points d'arrêt.
