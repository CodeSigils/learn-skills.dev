OpenDesign Design Token Guide. Use this skill when CSS variables from the @opensig/opendesign-token package are needed. Contains a complete token system for six themes (openEuler/Ascend/Kunpeng/Mindspore/openGauss/openUBMC), covering colors, spacing, radius, typography, shadows, responsive type, grid systems, and all design tokens. Use cases: (1) find semantic tokens for color values, (2) get token names for spacing/radius/typography, (3) understand differences among the six themes, (4) replace hard-coded values with CSS variables in code, (5) use responsive tokens for multi-breakpoint adaptation
