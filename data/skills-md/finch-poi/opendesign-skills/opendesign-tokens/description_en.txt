OpenDesign Design Token Guide. Use this skill when you need to use CSS variables from the @opensig/opendesign-token package. It contains a complete token system for six themes (openEuler/Ascend/Kunpeng/Mindspore/openGauss/openUBMC), covering all design tokens including colors, spacing, radius, typography, shadows, responsive typography, and grid systems. Use cases: (1) Find semantic tokens for color values, (2) Get token names for spacing/radius/typography, (3) Understand differences among the six themes, (4) Replace hard-coded values with CSS variables in code, (5) Use responsive tokens for multi-breakpoint adaptation.
