Guida ai token di progettazione OpenDesign. Utilizza questa competenza quando sono necessarie variabili CSS del pacchetto @opensig/opendesign-token. Contiene un sistema di token completo per sei temi (openEuler/Ascend/Kunpeng/Mindspore/openGauss/openUBMC), che copre colori, spaziatura, raggio, tipografia, ombre, tipo reattivo, sistemi a griglia e tutti i token di progettazione. Casi d'uso: (1) trovare token semantici per valori di colore, (2) ottenere nomi di token per spaziatura/raggio/tipografia, (3) comprendere le differenze tra i sei temi, (4) sostituire valori hardcoded con variabili CSS nel codice, (5) utilizzare token reattivi per l'adattamento a più punti di interruzione
