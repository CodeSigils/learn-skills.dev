Guía de tokens de diseño de OpenDesign. Utilice esta habilidad cuando necesite utilizar variables CSS del paquete @opensig/opendesign-token. Contiene un sistema de tokens completo para seis temas (openEuler/Ascend/Kunpeng/Mindspore/openGauss/openUBMC), que admite todos los tokens de diseño, incluidos colores, espaciado, radio de borde, tipografía, sombras, tipografía responsiva y sistemas de cuadrícula. Casos de uso: (1) Encontrar tokens semánticos correspondientes a valores de color, (2) Obtener nombres de tokens para espaciado/radio de borde/tipografía, (3) Comprender las diferencias entre los seis temas, (4) Usar variables CSS en el código en lugar de valores codificados, (5) Usar tokens responsivos para lograr una adaptación de múltiples puntos de interrupción
