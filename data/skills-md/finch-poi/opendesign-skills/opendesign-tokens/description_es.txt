Guía de tokens de diseño de OpenDesign. Utilice esta habilidad cuando necesite variables CSS del paquete @opensig/opendesign-token. Contiene un sistema de tokens completo para seis temas (openEuler/Ascend/Kunpeng/Mindspore/openGauss/openUBMC), que cubre colores, espaciado, radio, tipografía, sombras, tipos responsivos, sistemas de cuadrícula y todos los tokens de diseño. Casos de uso: (1) encontrar tokens semánticos para valores de color, (2) obtener nombres de tokens para espaciado/radio/tipografía, (3) comprender las diferencias entre los seis temas, (4) reemplazar valores codificados con variables CSS en el código, (5) usar tokens responsivos para la adaptación de múltiples puntos de interrupción
