Используйте этот навык при анализе параметров шифрования веб-JS (например, «这个 знак 怎么生成的»/»这个 w 参数怎么破»/»定位加密函数»), обработке обфускации (оболочка OB/оболочка eval-Function), идентификации JSVMP/Worker/WASM операторов связи, выбирая схемы деобфускации/повторного использования или исправляя среду iv8 для локального запуска целевого JS. Охватывает всю цепочку: отслеживание параметров HAR, локализацию точки шифрования с помощью `_initiator.stack`, локальную деобфускацию, перезапись Python и выбор схемы исправления env8, а также локальную проверку на соответствие реальным значениям HAR. НЕ используйте для общей веб-разработки, разработки сканеров, перехвата среды выполнения на базе Frida, обратного проектирования двоичных протоколов (кроме веб-JS) или автоматизации RPC/браузера (Puppeteer/Playwright/Selenium — явно запрещено).
