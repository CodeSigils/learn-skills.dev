Principes de programmation défensive de Tiger Style pour TypeScript/JavaScript. Couvre les assertions, la lisibilité, la gestion des erreurs et les contrôles d'exhaustivité. À utiliser lors de l'écriture ou de la révision du code TS/JS, de l'ajout d'assertions, de la gestion des erreurs ou lorsque l'utilisateur mentionne « programmation défensive », « style tigre », « assertions », « exhaustif », « gérer toutes les erreurs » ou a besoin d'une révision du code.
