Verwenden Sie es, wenn Sie eine einfache Browser-Qualitätssicherung für eine Webseite, eine lokale HTML-Datei oder eine App benötigen: Überprüfen Sie Konsolenfehler, fehlerhafte Assets, Tastatur-/Fokusverhalten, Lesbarkeit des Ansichtsfensters und veröffentlichen Sie evidenzbasierte Ergebnisse im JSON-Format über einen lokalen HTML-Berichtsviewer.
