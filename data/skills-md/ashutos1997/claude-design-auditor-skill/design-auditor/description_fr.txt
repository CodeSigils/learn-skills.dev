Auditez les conceptions par rapport à 18 règles professionnelles dans les fichiers et le code Figma (HTML/CSS/React/Vue/Tailwind). Détecte automatiquement le framework, exécute les super pouvoirs de code spécifiques à la catégorie (aria, focus, contraste, jetons, responsive, mouvement, formulaires, navigation, espacement), audite les modèles sombres et les problèmes de conception éthique, génère des différences de code avant/après et génère un rapport de transfert structuré du développeur. Déclencheurs sur : vérifier ma conception, revoir mon interface utilisateur, auditer ma mise en page, est-ce accessible, révision de la conception, vérification de la typographie, contraste des couleurs, WCAG, a11y, pixel parfait, critique de l'interface utilisateur, audit Figma, vérification CSS, révision de ce composant, est-ce que cela a l'air bien, motifs sombres, conception éthique. Se déclenche également lors de la création de l'interface utilisateur dans VS Code ou Figma MCP.
