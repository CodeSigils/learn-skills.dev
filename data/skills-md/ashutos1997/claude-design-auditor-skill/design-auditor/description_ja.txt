Figma ファイルおよびコード (HTML/CSS/React/Vue/Tailwind) にわたる 18 の専門的なルールに基づいてデザインを監査します。フレームワークを自動的に検出し、カテゴリ固有のコード スーパーパワー (アリア、フォーカス、コントラスト、トークン、レスポンシブ、モーション、フォーム、ナビゲーション、スペース) を実行し、ダーク パターンと倫理的設計の問題を監査し、コードの差分の前後で出力し、構造化された開発者引き継ぎレポートを生成します。トリガー: デザインのチェック、UI のレビュー、レイアウトの監査、アクセス可能か、デザイン レビュー、タイポグラフィ チェック、カラー コントラスト、WCAG、a11y、ピクセル パーフェクト、UI 批評、Figma 監査、CSS チェック、このコンポーネントのレビュー、見た目は良いか、ダーク パターン、倫理的なデザイン。 VS Code または Figma MCP で UI を構築するときにもトリガーされます。
