Audite diseños según 18 reglas profesionales en archivos y código Figma (HTML/CSS/React/Vue/Tailwind). Detecta el marco automáticamente, ejecuta superpoderes de código específicos de categorías (aria, enfoque, contraste, tokens, responsivo, movimiento, formas, navegación, espaciado), audita patrones oscuros y problemas de diseño ético, genera antes/después de diferencias de código y genera un informe estructurado de transferencia de desarrolladores. Activadores: verificar mi diseño, revisar mi interfaz de usuario, auditar mi diseño, si es accesible, revisión de diseño, verificación de tipografía, contraste de color, WCAG, a11y, píxel perfecto, crítica de interfaz de usuario, auditoría de Figma, verificación de CSS, revisar este componente, se ve bien, patrones oscuros, diseño ético. También se activa al crear la interfaz de usuario en VS Code o Figma MCP.
