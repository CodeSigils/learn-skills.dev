Genera prototipi di prodotti aziendali standardizzati da requisiti aziendali, riferimenti a prototipi, file ".pen", modelli HTML o file di progettazione. Per impostazione predefinita, l'interfaccia utente di amministrazione in stile Element Plus supporta query/aggiungi/modifica/eliminazione di pagine di stato, flussi di lavoro del cassetto di destra, sovrapposizioni di pagine intere, strutture di tabelle reali, impaginazione, note di logica aziendale e convalida della coerenza dello stato della pagina. Da utilizzare durante la creazione o la normalizzazione di prototipi di gestione backend con Pencil MCP.
