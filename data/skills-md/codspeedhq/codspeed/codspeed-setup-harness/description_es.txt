Configure puntos de referencia de rendimiento y arnés CodSpeed ​​para un proyecto. Utilice esta habilidad siempre que el usuario quiera crear puntos de referencia, agregar pruebas de rendimiento, configurar CodSpeed, configurar codspeed.yml, integrar un marco de referencia (criterion, divan, pytest-benchmark, vitest bench, go test -bench, google benchmark), o cuando el usuario diga "agregar puntos de referencia", "configurar pruebas de rendimiento", "crear un punto de referencia", "comparar esto" o quiera medir el rendimiento de su código por primera vez. También se activa cuando la habilidad de optimización necesita puntos de referencia que aún no existen.
