Navegación y índice de documentación de desarrollo rápido de aplicaciones. Cuando un usuario hace preguntas relacionadas con el desarrollo de Quick App, o solicita escribir código de Quick App (incluso si no menciona explícitamente el término "Quick App", siempre que implique desarrollo de aplicaciones nativas para fabricantes de teléfonos nacionales, paquetes hap, paquetes rpk, configuración manifest.json, desarrollo de plantillas UX), se deben utilizar estas habilidades: (1) sintaxis del marco, ciclo de vida, enlace de datos, eventos, diseño de estilo; (2) uso de componentes (contenedor/básico/formulario/medios/canvas/extensión/componentes de terceros); (3) capacidades e interfaces del sistema (red, almacenamiento, dispositivo, sensores, servicios del fabricante, servicios de terceros); (4) herramientas IDE (crear proyecto, depurar, compilar, empaquetar, cargar, emular); (5) tutoriales introductorios, estructura del proyecto, proceso de desarrollo; (6) adaptación (modo oscuro/multilingüe), optimización del rendimiento, pruebas, problemas de compatibilidad; (7) proceso de embalaje y liberación. Cuando el usuario menciona los conceptos relacionados en chino “快应用” o en inglés “QuickApp”, se debe utilizar esta habilidad.
