Navegación y índice de documentación de desarrollo rápido de aplicaciones. Cuando los usuarios hacen preguntas relacionadas con el desarrollo de aplicaciones rápidas o solicitan código de aplicaciones rápidas (incluso si no mencionan explícitamente el término "快应用", siempre que implique el desarrollo de aplicaciones nativas para fabricantes de teléfonos nacionales, paquetes hap, paquetes rpk, configuración manifest.json o desarrollo de plantillas UX), se deben utilizar estas habilidades: (1) sintaxis del marco, ciclo de vida, enlace de datos, eventos, diseño de estilo; (2) uso de componentes (contenedor/básico/formulario/medios/canvas/extensión/componentes de terceros); (3) capacidades e interfaces del sistema (red, almacenamiento, dispositivo, sensores, servicios del fabricante, servicios de terceros); (4) herramientas IDE (crear proyecto, depurar, compilar, empaquetar, cargar, emular); (5) tutoriales para principiantes, estructura del proyecto, proceso de desarrollo; (6) adaptación (modo oscuro/multilingüe), optimización del rendimiento, pruebas, problemas de compatibilidad; (7) proceso de embalaje y liberación. Cuando los usuarios mencionan los conceptos chino "快应用" o inglés "QuickApp", se debe utilizar esta habilidad.
