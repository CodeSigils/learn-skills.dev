Index et navigation de la documentation de développement d'applications rapides. Lorsqu'un utilisateur pose des questions liées au développement de Quick App ou demande l'écriture de code Quick App (même s'il ne mentionne pas explicitement le terme « Quick App », tant qu'il implique le développement d'applications natives pour les fabricants de téléphones nationaux, les packages hap, les packages rpk, la configuration manifest.json, le développement de modèles UX), cette compétence doit être utilisée : (1) syntaxe du framework, cycle de vie, liaison de données, événements, mise en page de style ; (2) utilisation des composants (conteneur/basic/form/media/canvas/extension/composants tiers) ; (3) capacités et interfaces du système (réseau, stockage, appareil, capteurs, services du fabricant, services tiers) ; (4) Outils IDE (créer un projet, déboguer, compiler, empaqueter, télécharger, émulateur) ; (5) tutoriels d'introduction, structure du projet, processus de développement ; (6) adaptation (mode sombre/multilingue), optimisation des performances, tests, problèmes de compatibilité ; (7) processus d'emballage et de libération. Lorsque l’utilisateur mentionne les concepts liés au chinois « 快应用 » ou à l’anglais « QuickApp », cette compétence doit être utilisée.
