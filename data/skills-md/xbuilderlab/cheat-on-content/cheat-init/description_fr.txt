Processus unifié : tous les utilisateurs passent par la même boucle fermée en cinq étapes ; la seule différence est que les utilisateurs qui ont publié des vidéos effectuent une étape supplémentaire lors de l'initialisation : récupérer les vidéos existantes pour créer un contexte historique (utilisé pour les graines de triche ultérieures afin de fournir des sujets plus pertinents et une base de référence plus précise). Mots déclencheurs : « 初始化 », « init », « 首次使用 », « 我是新用户 », « setup cheat-on-content ». **Doit être exécuté lors de la première session de l'utilisateur ; d'autres sous-compétences sont automatiquement acheminées ici lorsque .cheat-state.json n'existe pas.**
