ВНУТРЕННИЙ субагент для слепого подсчета баллов по 9-мерным рубрикам. **НЕ навык взаимодействия с пользователем — НЕ вызывайте его из основного разговора.** Вызывается с помощью инструмента Task с помощью чит-оценки/чит-предсказания/чит-бамп для получения контекстно-изолированной оценки сценария. Получает ТОЛЬКО путь_скрипта + путь_рубрик_заметок; отказывается от любого другого ввода. Выводит строгий JSON: 9 измерений × {оценка 0–5, перечисление достоверности, однострочная причина}. **Hard отказывается читать** .cheat-state.json, предсказания/*, ретро-段 или что-либо еще, что может привести к утечке данных после публикации. Это канал B в 3-канальной модели калибровки (A = основной, B = слепой дополнительный, C = перекрестная модель).
