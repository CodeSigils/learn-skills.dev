ابحث في Mobbin عن لقطات شاشة لواجهة مستخدم التطبيق الحقيقي وقم بتحليلها بصريًا. مطلوبة قبل استدعاء أداة MCP "شاشات_البحث" - تحدد هذه المهارة كيفية تخطيط عمليات البحث والاستجابة وإنشاء لوحات أدلة HTML عندما تكون الشاشات هي الإجابة. يُستخدم عندما يسأل المستخدم عن أنماط تصميم واجهة المستخدم/تجربة المستخدم، أو يريد معرفة كيفية تعامل التطبيقات الأخرى مع الشاشة أو التدفق، أو يحتاج إلى إلهام التصميم أو المراجع، أو يطلب مقارنة أساليب واجهة المستخدم عبر التطبيقات، أو يذكر Mobbin، أو عندما تكون "شاشات_البحث" ذات صلة. قم بالإجابة بقوة على أي سؤال متعلق بالتصميم - حتى لو لم يتم طلب لقطات الشاشة صراحةً.
