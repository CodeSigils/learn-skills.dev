Blender でオブジェクト、カメラ、ライト、プロパティをアニメーション化します。キーフレーム、F カーブ、イージング (ベジェ、リニア、サイン、バウンス、エラスティック)、シェイプ キー (モーフ ターゲット / ブレンドシェイプ / 口形素)、ドライバー (プロパティの Python 式)、再利用とレイヤー化のための NLA アクション。ユーザーが「これをアニメーション化する」、「時間の経過とともに移動/回転/スケールする」、「キーフレームを追加する」、「ループ/振動する」、「シェイプキー/モーフ/ブレンドシェイプ」、「リップシンク用の口形素」、または時間ベースのプロパティ変更を要求する場合に使用します。ユーザーが「アニメート」と言わなくても、必ずこのスキルを使用してください。「ゆっくり回す」、「波打つ」、「フェードイン/アウト」、「パルス」、「表情」もカバーされます。
