حرك الكائنات والكاميرات والأضواء والخصائص في Blender - الإطارات الرئيسية، منحنيات F، التخفيف (Bezier، Linear، Sine، Bounce، Elastic)، مفاتيح الأشكال (أهداف التحويل / الأشكال الممزوجة / visemes)، المحركات (تعبيرات Python على الخصائص)، إجراءات NLA لإعادة الاستخدام والطبقات. استخدمه عندما يطلب المستخدم "تحريك هذا"، أو "جعله يتحرك / يدور / يتغير حجمه بمرور الوقت"، أو "يضيف إطارات رئيسية"، أو "حلقة / تتأرجح"، أو "مفتاح الشكل / التحويل / شكل المزج"، أو "أشكال لمزامنة الشفاه"، أو أي تغيير في الخصائص يعتمد على الوقت. تأكد من استخدام هذه المهارة حتى لو لم يقل المستخدم "تحريك" - وتغطي أيضًا "تدويرها ببطء"، "اجعلها تموج"، "تتلاشى للداخل/للخارج"، "نبض"، "تعبيرات الوجه".
