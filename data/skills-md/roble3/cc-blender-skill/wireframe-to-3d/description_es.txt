Convierta dibujos PNG de estructura alámbrica ortográfica 2D a modelos 3D de Blender exportados como glTF/GLB. Utilice esta habilidad siempre que el usuario proporcione imágenes de estructura alámbrica (dibujos técnicos, dibujos lineales, vistas ortográficas, paneles laterales/frontales/posteriores) y desee generar un modelo 3D, una malla o un archivo .glb. Se activan frases como "convertir esta estructura alámbrica a 3D", "hacer un modelo 3D a partir de estos dibujos", "construir un modelo a partir de esta estructura alámbrica", "generar GLB a partir de estas vistas" o cualquier solicitud de imagen a malla 3D que involucre dibujos lineales. Asegúrese de utilizar esta habilidad incluso si el usuario no dice explícitamente "estructura alámbrica"; también cubre "vistas ortográficas", "dibujos técnicos", "dibujos lineales de objetos", "vistas frontal y lateral". Requiere que se esté ejecutando el complemento Blender MCP (puerto 9876) y Python con opencv-python, numpy, scipy instalado.
