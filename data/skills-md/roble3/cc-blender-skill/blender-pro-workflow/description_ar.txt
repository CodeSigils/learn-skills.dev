إرشادات سير عمل الإنتاج الشاملة لـ Blender - ترتيب تجميع المشاهد (الحجب ← الكاميرا ← الضوء ← النماذج ← المواد ← التفاصيل ← العرض ← المركب ← التصدير)، وبروتوكولات النقد، وميزانيات الوقت، وأنماط الاسترداد. يُستخدم عندما يطلب المستخدم "إنشاء مشهد كامل / لقطة بطل / عرض جودة الإنتاج"، أو "ما هو الترتيب الصحيح للقيام بذلك"، أو "إعداد مسار كامل"، أو لديه طلب متعدد الخطوات يشمل النمذجة + الإضاءة + المواد + العرض. تأكد من استخدام هذه المهارة لأي طلب يمتد عبر مراحل متعددة من العمل ثلاثي الأبعاد، حتى لو لم يقل المستخدم "سير العمل" - ويغطي أيضًا "إنشاء صورة نهائية لـ X"، و"إنتاج عرض بطل"، و"نتيجة ذات مظهر احترافي".
