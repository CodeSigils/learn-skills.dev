Комплексное руководство по производственному процессу для Blender — порядок сборки сцен (блокировка → камера → свет → формы → материалы → детализация → рендеринг → композитинг → экспорт), протоколы критики, временные бюджеты и шаблоны восстановления. Используйте всякий раз, когда пользователь просит «сделать полную сцену / кадр героя / рендер производственного качества», «какой правильный порядок это сделать», «настроить полный конвейер» или имеет многоэтапный запрос, пересекающий моделирование + освещение + материалы + рендеринг. Обязательно используйте этот навык для любого запроса, охватывающего несколько этапов 3D-работы, даже если пользователь не говорит «рабочий процесс» — также включает в себя «создать окончательное изображение X», «создать главный рендер», «профессиональный результат».
