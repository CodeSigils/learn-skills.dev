Guida al flusso di lavoro di produzione end-to-end per Blender: l'ordine di assemblare le scene (blocco → telecamera → luce → forme → materiali → dettaglio → rendering → composito → esportazione), protocolli di critica, budget temporali e modelli di recupero. Da utilizzare ogni volta che l'utente chiede di "realizzare una scena completa/una ripresa dell'eroe/un rendering di qualità di produzione", "qual è l'ordine giusto per farlo", "impostare una pipeline completa" o ha una richiesta in più passaggi che comprende modellazione + illuminazione + materiali + rendering. Assicurati di utilizzare questa competenza per qualsiasi richiesta che abbraccia più fasi del lavoro 3D, anche se l'utente non dice "flusso di lavoro" - copre anche "creare un'immagine finale di X", "produrre un rendering di eroi", "risultato dall'aspetto professionale".
