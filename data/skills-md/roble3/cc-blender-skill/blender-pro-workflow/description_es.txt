Guía del flujo de trabajo de producción de un extremo a otro para Blender: el orden de ensamblar escenas (bloqueo → cámara → luz → formas → materiales → detalle → renderizado → compuesto → exportación), protocolos de crítica, presupuestos de tiempo y patrones de recuperación. Úselo siempre que el usuario solicite "hacer una escena completa/toma de héroe/renderizado con calidad de producción", "cuál es el orden correcto para hacer esto", "configurar un proceso completo" o tenga una solicitud de varios pasos que cruce modelado + iluminación + materiales + renderizado. Asegúrese de utilizar esta habilidad para cualquier solicitud que abarque múltiples fases del trabajo 3D, incluso si el usuario no dice "flujo de trabajo"; también cubre "crear una imagen final de X", "producir un renderizado de héroe", "resultado de apariencia profesional".
