Blender에 대한 엔드투엔드 제작 워크플로우 지침 — 장면 조립 순서(블록아웃 → 카메라 → 조명 → 양식 → 재료 → 디테일 → 렌더링 → 합성 → 내보내기), 비평 프로토콜, 시간 예산 및 복구 패턴. 사용자가 "완전한 장면/히어로 샷/프로덕션 품질 렌더링 만들기", "이 작업을 수행하는 올바른 순서는 무엇입니까", "전체 파이프라인 설정"을 요청하거나 모델링 + 조명 + 재료 + 렌더링을 교차하는 다단계 요청이 있을 때마다 사용합니다. 사용자가 "워크플로"라고 말하지 않더라도 3D 작업의 여러 단계에 걸쳐 요청하는 경우 이 기술을 사용해야 합니다. "X의 최종 이미지 만들기", "영웅 렌더링 생성", "전문가 수준의 결과"도 포함됩니다.
