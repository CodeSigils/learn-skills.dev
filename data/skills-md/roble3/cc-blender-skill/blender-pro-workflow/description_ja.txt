Blender のエンドツーエンドの制作ワークフロー ガイダンス — シーンを組み立てる順序 (ブロックアウト → カメラ → ライト → フォーム → マテリアル → ディテール → レンダリング → コンポジット → エクスポート)、批評プロトコル、時間予算、およびリカバリ パターン。ユーザーが「完全なシーン / ヒーロー ショット / プロダクション品質のレンダリングを作成する」、「これを行うための正しい順序は何か」、「完全なパイプラインを設定する」、またはモデリング + ライティング + マテリアル + レンダリングにまたがる複数ステップのリクエストがある場合に使用します。ユーザーが「ワークフロー」と言わなくても、3D 作業の複数のフェーズにまたがるリクエストには必ずこのスキルを使用してください。「X の最終イメージの作成」、「ヒーロー レンダリングの生成」、「プロフェッショナルな外観の結果」も含まれます。
