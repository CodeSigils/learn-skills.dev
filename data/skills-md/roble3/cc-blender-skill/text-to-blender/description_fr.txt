Pilotez Blender à partir du langage naturel. Convertit les requêtes en anglais simple (« modéliser une épée et la rendre avec un éclairage cinématographique », « donner à ce verre un aspect givré », « configurer un éclairage à trois points », « exporter cette scène au format glTF pour le Web ») en code Blender Python exécuté via le serveur Blender MCP. Agit en tant qu'orchestrateur qui sélectionne et charge en chaîne les sous-compétences spécialisées (modélisation de mélangeur, matériaux de mélangeur, éclairage de mélangeur, caméras de mélangeur, rendu de mélangeur, animation de mélangeur, exportation de mélangeur, filaire vers 3D, flux de travail de mélangeur professionnel, harmoniseur de compétences de mélangeur, boucle automatique de raffinement de la qualité). Utilisez cette compétence chaque fois que l'utilisateur souhaite que Claude fasse quelque chose dans Blender, notamment créer une géométrie, appliquer des matériaux, éclairer une scène, cadrer une caméra, effectuer un rendu, une animation ou une exportation. Assurez-vous d'invoquer cette compétence même si l'utilisateur ne dit pas « Blender » — couvre également les requêtes telles que « créer un modèle 3D de... », « rendre ceci... », « créer un glTF à partir de... », « configurer une scène avec... » ou toute tâche de création 3D. Nécessite le module complémentaire Blender MCP (ahujasid/blender-mcp) fonctionnant sur le port 9876.
