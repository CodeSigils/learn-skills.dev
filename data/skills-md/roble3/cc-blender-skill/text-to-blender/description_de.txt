Fahren Sie Blender mit natürlicher Sprache. Konvertiert einfach-englische Anfragen („ein Schwert modellieren und mit filmischer Beleuchtung rendern“, „dieses Glas matt aussehen lassen“, „Dreipunktbeleuchtung einrichten“, „diese Szene als glTF für das Web exportieren“) in Blender-Python-Code, der über den Blender-MCP-Server ausgeführt wird. Fungiert als Orchestrator, der spezielle Unterfähigkeiten auswählt und verkettet (Blender-Modellierung, Blender-Materialien, Blender-Beleuchtung, Blender-Kameras, Blender-Rendering, Blender-Animation, Blender-Export, Wireframe-to-3D, Blender-Pro-Workflow, Blender-Skill-Harmonizer, Qualitätsverfeinerung-Autoloop). Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer möchte, dass Claude irgendetwas in Blender tut, einschließlich der Erstellung von Geometrie, der Anwendung von Materialien, der Beleuchtung einer Szene, der Ausrichtung einer Kamera, des Renderns, Animierens oder Exportierens. Stellen Sie sicher, dass Sie diesen Skill auch dann aufrufen, wenn der Benutzer nicht „Blender“ sagt. Er deckt auch Anfragen wie „Erstellen Sie ein 3D-Modell von ...“, „Rendern Sie dies ...“, „Erstellen Sie ein glTF aus ...“, „Setzen Sie eine Szene mit ...“ oder jede andere 3D-Erstellungsaufgabe ab. Erfordert das Blender MCP-Add-on (ahujasid/blender-mcp), das auf Port 9876 ausgeführt wird.
