自然言語から Blender を駆動します。平易な英語のリクエスト (「剣をモデル化し、映画のような照明でレンダリングする」、「このガラスを曇ったように見せる」、「3 点照明を設定する」、「このシーンを Web 用の glTF としてエクスポートする」) を、Blender MCP サーバー経由で実行される Blender Python コードに変換します。特殊なサブスキル (ブレンダー モデリング、ブレンダー マテリアル、ブレンダー ライティング、ブレンダー カメラ、ブレンダー レンダリング、ブレンダー アニメーション、ブレンダー エクスポート、ワイヤーフレームから 3D、ブレンダー プロ ワークフロー、ブレンダー スキル ハーモナイザー、品質リファインメント オートループ) を選択してチェーンロードするオーケストレーターとして機能します。ユーザーが、ジオメトリの作成、マテリアルの適用、シーンの照明、カメラのフレーミング、レンダリング、アニメーション化、エクスポートなど、Blender でクロードに何かを実行してもらいたいときは常にこのスキルを使用します。ユーザーが「Blender」と言わなくても、必ずこのスキルを呼び出してください。また、「... の 3D モデルを作成する」、「これをレンダリングする...」、「... から glTF を作成する」、「... でシーンをセットアップする」、またはあらゆる 3D 作成タスクのようなリクエストもカバーされています。ポート 9876 で実行される Blender MCP アドオン (ahujasid/blender-mcp) が必要です。
