Blender シーンを glTF/GLB (Web/AR)、FBX (ゲーム エンジン)、OBJ (ユニバーサル)、USD (VFX パイプライン)、STL (3D プリント) にエクスポートします。フォーマットごとの設定、テクスチャの埋め込み/アンパック、軸変換、ポリゴンの最適化 (Decimate)、およびターゲット プラットフォームの検証が含まれます。ユーザーが「これをエクスポート」、「glTF / FBX / OBJ / STL / USD として保存」、「Unity / Unreal / Three.js / web / AR / 3D print 用のパッケージ」、または任意の出力形式の変換を要求する場合に使用します。ユーザーが「エクスポート」と言わなくても、必ずこのスキルを使用してください。「これを Web 用にパッケージ化する」、「Unity で動作させる」、「Unreal に送信する」、「3D プリント用に保存する」もカバーされています。
