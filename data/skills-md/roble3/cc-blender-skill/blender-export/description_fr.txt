Exportez les scènes Blender vers glTF/GLB (web/AR), FBX (moteurs de jeu), OBJ (universel), USD (pipelines VFX), STL (impression 3D). Comprend les paramètres par format, l'intégration/décompression des textures, la conversion des axes, l'optimisation des polygones (Decimate) et la validation de la plate-forme cible. À utiliser chaque fois que l'utilisateur demande "exporter ceci", "enregistrer sous glTF / FBX / OBJ / STL / USD", "package pour Unity / Unreal / Three.js / web / AR / impression 3D", ou toute conversion de format de sortie. Assurez-vous d'utiliser cette compétence même si l'utilisateur ne dit pas "exporter" - couvre également "emballer ceci pour le Web", "le faire fonctionner dans Unity", "envoyer vers Unreal", "enregistrer pour l'impression 3D".
