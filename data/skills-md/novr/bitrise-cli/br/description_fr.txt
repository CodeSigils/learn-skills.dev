Utilisez la br CLI pour inspecter les builds Bitrise CI, récupérer les journaux et diagnostiquer les échecs. À utiliser pour enquêter sur l'état de la build Bitrise, analyser les échecs de CI, récupérer les journaux de build avec --failed-only, résoudre les slugs d'application, exécuter br doctor ou lorsque l'utilisateur mentionne Bitrise, br build ou .br.yml.
