Utilizza la CLI br per ispezionare le build CI di Bitrise, recuperare i log e diagnosticare gli errori. Da utilizzare quando si indaga sullo stato della build di Bitrise, si analizzano gli errori CI, si recuperano i log di build con --failed-only, si risolvono gli slug dell'app, si esegue br doctor o quando l'utente menziona Bitrise, br build o .br.yml.
