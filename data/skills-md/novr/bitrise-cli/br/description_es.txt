Utilice la CLI de br para inspeccionar compilaciones de Bitrise CI, recuperar registros y diagnosticar fallas. Úselo cuando investigue el estado de compilación de Bitrise, analice fallas de CI, obtenga registros de compilación con --failed-only, resuelva slugs de aplicaciones, ejecute br doctor o cuando el usuario mencione Bitrise, br build o .br.yml.
