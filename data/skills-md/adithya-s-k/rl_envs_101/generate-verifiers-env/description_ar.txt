إنشاء متغير Verifiers (PrimeIntellect) لبيئة RL. يُستخدم عندما يطلب شخص ما دعم بيئة Verifiers، أو النقل إلى Verifiers، أو إنشاء مجموعة أدوات قيد التشغيل، أو إعداد `vf.ToolEnv` باستخدام نموذج تقييم، أو توصيل طرح TRL `GRPOTrainer`. تعد أدوات التحقق هي الإطار الصحيح عندما يريد المستخدم أدوات قيد التشغيل (بدون خادم HTTP)، أو استدعاء أداة منظمة مدفوعة بوظائف Python البسيطة، أو قواعد تقييم المكافأة القابلة للتركيب مع وظائف تصنيف متعددة، أو التكرار السريع بدون Docker، أو المسار الأنظف من النموذج الأولي إلى تدريب TRL. الإخراج عبارة عن مجلد `<env_dir>/verifiers/` قابل للتشغيل مع `env.py` (مجموعة الأدوات + وظائف الأداة المستقلة + `create_verifiers_env`)، و`rollout.py`، و`pyproject.toml`. استخدمه لمطالبات مثل "إنشاء بيئة تحقق لـ X" أو "تغليف لعبتي في أدوات التحقق" أو "إعداد vf.ToolEnv".
