Erstellt eine Verifiers-Variante (PrimeIntellect) einer RL-Umgebung. Verwenden Sie es immer dann, wenn jemand ein Gerüst für eine Verifiers-Umgebung erstellen, auf Verifiers portieren, ein In-Process-Toolkit erstellen, ein „vf.ToolEnv“ mit einer Rubrik einrichten oder einen TRL „GRPOTrainer“-Rollout verkabeln möchte. Verifiers ist das richtige Framework, wenn der Benutzer In-Process-Tools (kein HTTP-Server), strukturierte Tool-Aufrufe, die durch einfache Python-Funktionen gesteuert werden, zusammensetzbare Belohnungsrubriken mit mehreren Grader-Funktionen, schnelle Iteration ohne Docker oder den saubersten Weg vom Prototyp zum TRL-Training wünscht. Die Ausgabe ist ein ausführbarer Ordner „<env_dir>/verifiers/“ mit „env.py“ (Toolkit + eigenständige Toolfunktionen + „create_verifiers_env“), „rollout.py“ und „pyproject.toml“.
