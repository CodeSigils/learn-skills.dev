建構 RL 環境的 Verifiers (PrimeIntellect) 變體。每當有人要求建立驗證程式環境、移植到驗證程式、建置進程內工具包、使用 Rubric 設定「vf.ToolEnv」或連接 TRL「GRPOTrainer」卷展列時，請使用。當使用者需要進程內工具（無 HTTP 伺服器）、由普通 Python 函數驅動的結構化工具呼叫、具有多個評分器函數的可組合獎勵規則、無需 Docker 的快速迭代或從原型到 TRL 訓練的最乾淨路徑時，驗證器是正確的框架。輸出是一個可運行的“<env_dir>/verifiers/”資料夾，其中包含“env.py”（工具包+獨立工具函數+“create_verifiers_env”）、“rollout.py”和“pyproject.toml”。用於諸如“為 X 創建驗證器環境”、“將我的遊戲包裝在驗證器中”或“設置 vf.ToolEnv”等提示。
