Crea una variante de Verificadores (PrimeIntellect) de un entorno RL. Úselo siempre que alguien solicite crear un entorno de Verificadores, transferirlo a Verificadores, crear un conjunto de herramientas en proceso, configurar un `vf.ToolEnv` con una Rúbrica o conectar una implementación TRL `GRPOTrainer`. Verifiers es el marco adecuado cuando el usuario desea herramientas en proceso (sin servidor HTTP), llamadas de herramientas estructuradas impulsadas por funciones simples de Python, rúbricas de recompensa componibles con múltiples funciones de calificación, iteración rápida sin Docker o el camino más limpio desde el prototipo hasta el entrenamiento TRL. La salida es una carpeta ejecutable `<env_dir>/verifiers/` con `env.py` (kit de herramientas + funciones de herramienta independientes + `create_verifiers_env`), `rollout.py` y `pyproject.toml`. Úselo para mensajes como "crear un entorno de verificadores para X", "envolver mi juego en verificadores" o "configurar un vf.ToolEnv".
