构建 RL 环境的 Verifiers (PrimeIntellect) 变体。每当有人要求构建验证程序环境、移植到验证程序、构建进程内工具包、使用 Rubric 设置“vf.ToolEnv”或连接 TRL“GRPOTrainer”卷展栏时，请使用。当用户需要进程内工具（无 HTTP 服务器）、由普通 Python 函数驱动的结构化工具调用、具有多个评分器函数的可组合奖励规则、无需 Docker 的快速迭代或从原型到 TRL 训练的最干净路径时，验证器是正确的框架。输出是一个可运行的“<env_dir>/verifiers/”文件夹，其中包含“env.py”（工具包+独立工具函数+“create_verifiers_env”）、“rollout.py”和“pyproject.toml”。用于诸如“为 X 创建验证器环境”、“将我的游戏包装在验证器中”或“设置 vf.ToolEnv”等提示。
