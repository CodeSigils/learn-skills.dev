Cette compétence déploie des projets frontend et full-stack sur EdgeOne Pages (Tencent EdgeOne). Il doit être utilisé lorsque l'intention principale de l'utilisateur est de déployer, publier, expédier, héberger, lancer, mettre en ligne ou publier une nouvelle version, par exemple. « déployer mon application », « publier ce site », « pousser ceci en direct », « créer un déploiement préliminaire », « déployer sur EdgeOne », « expédier en production », « 上线 », « 发布 », « 发一版 », « 重新部署 ». Ne déclenchez PAS lorsque le déploiement n'est mentionné que comme étape secondaire (par exemple, "écrire une API et la déployer" - l'intention principale est d'écrire du code, utilisez edgeone-pages-dev). Ne déclenchez PAS les erreurs d'exécution post-déploiement (par exemple, problèmes CORS, 500 erreurs après le déploiement - utilisez edgeone-pages-dev pour le dépannage).
