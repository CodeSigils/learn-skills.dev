此技能將前端和全端專案部署到EdgeOne Pages（騰訊EdgeOne）。當使用者的主要意圖是部署、發布、發布、託管、啟動、上線或發布新版本時，應該使用它 - 例如「部署我的應用程式」、「發布此網站」、「推送此活動」、「建立預覽部署」、「部署到 EdgeOne」、「交付到生產環境」、「上線」、「發布」、「發一版」、「重新部署」。當部署僅作為次要步驟提及時不要觸發（例如「編寫 API 並部署它」——主要目的是編寫程式碼，使用 edgeone-pages-dev）。不要觸發部署後執行時間錯誤（例如 CORS 問題、部署後出現 500 個錯誤 - 使用 edgeone-pages-dev 進行故障排除）。
