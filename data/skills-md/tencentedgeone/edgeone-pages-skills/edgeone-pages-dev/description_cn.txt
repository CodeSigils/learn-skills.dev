此技能指导 EdgeOne Pages 上全栈功能的开发 - Edge Functions、Cloud Functions（Node.js / Go / Python 运行时）、中间件、KV 存储和本地开发工作流程。当用户想要专门在 EdgeOne Pages 上创建 API、无服务器函数、中间件、WebSocket 端点或全栈功能时，应该使用它 - 例如“创建 API”、“添加无服务器函数”、“编写中间件”、“构建全栈应用程序”、“添加 WebSocket 支持”、“设置边缘函数”、“使用 KV 存储”、“创建 Go API”、“构建 Python 后端”、“在 EdgeOne 页面上使用 Flask/FastAPI/Gin”。不要触发框架原生功能（Next.js API 路由、Next.js 中间件、Nuxt 服务器路由）或 EdgeOne Pages 项目之外的通用 Express/Koa 开发。不要触发部署 - 请改用edgeone-pages-deploy。请勿针对其他平台（Cloudflare Workers、Vercel Functions、AWS Lambda）触发。
