Cette compétence guide le développement de fonctionnalités full-stack sur EdgeOne Pages : fonctions Edge, fonctions Cloud (environnements d'exécution Node.js / Go / Python), middleware, stockage KV et flux de travail de développement local. Il doit être utilisé lorsque l'utilisateur souhaite créer des API, des fonctions sans serveur, des middlewares, des points de terminaison WebSocket ou des fonctionnalités full-stack spécifiquement sur les pages EdgeOne, par exemple. "créer une API", "ajouter une fonction sans serveur", "écrire un middleware", "créer une application full-stack", "ajouter la prise en charge de WebSocket", "configurer des fonctions Edge", "utiliser le stockage KV", "créer une API Go", "créer un backend Python", "utiliser Flask/FastAPI/Gin sur EdgeOne Pages". Ne déclenchez PAS les fonctionnalités natives du framework (routes API Next.js, middleware Next.js, routes de serveur Nuxt) ou le développement Express/Koa générique en dehors d'un projet EdgeOne Pages. Ne déclenchez PAS le déploiement – ​​utilisez plutôt edgeone-pages-deploy. Ne déclenchez PAS pour d'autres plates-formes (Cloudflare Workers, Vercel Functions, AWS Lambda).
