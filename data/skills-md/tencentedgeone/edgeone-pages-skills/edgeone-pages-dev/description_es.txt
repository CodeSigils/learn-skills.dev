Esta habilidad guía el desarrollo de funciones completas en EdgeOne Pages: funciones de borde, funciones de nube (tiempos de ejecución de Node.js/Go/Python), middleware, almacenamiento KV y flujos de trabajo de desarrollo local. Debe usarse cuando el usuario desea crear API, funciones sin servidor, middleware, puntos finales WebSocket o funciones completas específicamente en EdgeOne Pages, p. "crear una API", "agregar una función sin servidor", "escribir middleware", "crear una aplicación de pila completa", "agregar soporte WebSocket", "configurar funciones perimetrales", "usar almacenamiento KV", "crear una API Go", "crear un backend de Python", "usar Flask/FastAPI/Gin en páginas EdgeOne". NO active funciones nativas del marco (rutas API Next.js, middleware Next.js, rutas de servidor Nuxt) o desarrollo genérico Express/Koa fuera de un proyecto de EdgeOne Pages. NO active la implementación; utilice edgeone-pages-deploy en su lugar. NO active otras plataformas (Cloudflare Workers, Vercel Functions, AWS Lambda).
