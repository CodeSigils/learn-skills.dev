Этот навык помогает разрабатывать полнофункциональные функции на страницах EdgeOne — пограничные функции, облачные функции (среды выполнения Node.js/Go/Python), промежуточное программное обеспечение, хранилище KV и рабочие процессы локальной разработки. Его следует использовать, когда пользователь хочет создать API, бессерверные функции, промежуточное программное обеспечение, конечные точки WebSocket или полнофункциональные функции специально на страницах EdgeOne — например. «создать API», «добавить бессерверную функцию», «написать промежуточное программное обеспечение», «создать полнофункциональное приложение», «добавить поддержку WebSocket», «настроить пограничные функции», «использовать хранилище KV», «создать API Go», «создать серверную часть Python», «использовать Flask/FastAPI/Gin на страницах EdgeOne». НЕ активируйте встроенные функции платформы (маршруты API Next.js, промежуточное ПО Next.js, маршруты сервера Nuxt) или общую разработку Express/Koa вне проекта EdgeOne Pages. НЕ запускайте развертывание — вместо этого используйте Edgeone-pages-deploy. НЕ запускайте триггеры для других платформ (Cloudflare Workers, Vercel Functions, AWS Lambda).
