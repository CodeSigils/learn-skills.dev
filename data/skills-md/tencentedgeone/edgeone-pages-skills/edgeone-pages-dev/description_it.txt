Questa competenza guida lo sviluppo di funzionalità full-stack su EdgeOne Pages: Edge Functions, Cloud Functions (runtime Node.js/Go/Python), Middleware, KV Storage e flussi di lavoro di sviluppo locale. Dovrebbe essere utilizzato quando l'utente desidera creare API, funzioni serverless, middleware, endpoint WebSocket o funzionalità full-stack specificamente su EdgeOne Pages, ad es. "crea un'API", "aggiungi una funzione serverless", "scrivi middleware", "crea un'app full-stack", "aggiungi il supporto WebSocket", "imposta funzioni edge", "usa archiviazione KV", "crea un'API Go", "crea un backend Python", "usa Flask/FastAPI/Gin su EdgeOne Pages". NON attivare funzionalità native del framework (percorsi API Next.js, middleware Next.js, percorsi server Nuxt) o sviluppo Express/Koa generico al di fuori di un progetto EdgeOne Pages. NON attivare la distribuzione: utilizza invece edgeone-pages-deploy. NON attivare per altre piattaforme (Cloudflare Workers, Vercel Functions, AWS Lambda).
