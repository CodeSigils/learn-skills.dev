ترشد هذه المهارة تطوير الميزات الكاملة على صفحات EdgeOne - وظائف الحافة، والوظائف السحابية (أوقات تشغيل Node.js / Go / Python)، والبرمجيات الوسيطة، وتخزين KV، وسير عمل التطوير المحلي. يجب استخدامه عندما يريد المستخدم إنشاء واجهات برمجة التطبيقات، أو وظائف بدون خادم، أو برامج وسيطة، أو نقاط نهاية WebSocket، أو ميزات مكدسة كاملة على صفحات EdgeOne - على سبيل المثال. "إنشاء واجهة برمجة تطبيقات"، "إضافة وظيفة بدون خادم"، "كتابة برنامج وسيط"، "إنشاء تطبيق متكامل"، "إضافة دعم WebSocket"، "إعداد وظائف الحافة"، "استخدام تخزين KV"، "إنشاء واجهة برمجة تطبيقات Go"، "إنشاء واجهة خلفية لـ Python"، "استخدام Flask/FastAPI/Gin على صفحات EdgeOne". لا تقم بتشغيل الميزات الأصلية لإطار العمل (مسارات Next.js API أو البرامج الوسيطة Next.js أو مسارات خادم Nuxt) أو تطوير Express/Koa العام خارج مشروع EdgeOne Pages. لا تقم بتشغيل النشر — استخدم edgeone-pages-deploy بدلاً من ذلك. لا تقم بالتشغيل لمنصات أخرى (Cloudflare Workers، Vercel Functions، AWS Lambda).
