이 기술은 EdgeOne Pages(Edge Functions, Cloud Functions(Node.js/Go/Python 런타임), 미들웨어, KV Storage 및 로컬 개발 워크플로)의 전체 스택 기능 개발을 안내합니다. 사용자가 EdgeOne Pages에서 API, 서버리스 기능, 미들웨어, WebSocket 엔드포인트 또는 전체 스택 기능을 생성하려는 경우 사용해야 합니다. "API 생성", "서버리스 기능 추가", "미들웨어 작성", "풀 스택 앱 구축", "WebSocket 지원 추가", "에지 기능 설정", "KV 스토리지 사용", "Go API 생성", "Python 백엔드 구축", "EdgeOne Pages에서 Flask/FastAPI/Gin 사용". 프레임워크 기본 기능(Next.js API 경로, Next.js 미들웨어, Nuxt 서버 경로) 또는 EdgeOne Pages 프로젝트 외부의 일반 Express/Koa 개발을 트리거하지 마십시오. 배포를 트리거하지 마세요. 대신 edgeone-pages-deploy를 사용하세요. 다른 플랫폼(Cloudflare Workers, Vercel Functions, AWS Lambda)에 대해서는 트리거하지 마세요.
