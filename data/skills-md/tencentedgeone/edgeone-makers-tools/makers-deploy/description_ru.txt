Этот навык позволяет развертывать проекты внешнего интерфейса и полного стека на страницах EdgeOne (Tencent EdgeOne). Его следует использовать, когда основным намерением пользователя является развертывание, публикация, доставка, размещение, запуск, ввод в эксплуатацию или выпуск новой версии — например. «развернуть мое приложение», «опубликовать этот сайт», «опубликовать», «создать предварительную версию», «развернуть в EdgeOne», «отправить в производство», «ввести в эксплуатацию», «выпустить», «опубликовать новую версию», «переразвернуть», «上线», «发布», «发一版», «重新部署». НЕ запускайте триггер, когда развертывание упоминается только как второстепенный этап (например, «написать API и развернуть его» — основная цель — написание кода, использование облачных функций производителей). НЕ запускайте запуск при ошибках времени выполнения после развертывания (например, проблемы CORS, 500 ошибок после развертывания — для устранения неполадок используйте функцииmakers-cloud-functions илиmakers-edge-functions).
