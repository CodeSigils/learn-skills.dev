Esta habilidad implementa proyectos frontend y full-stack en EdgeOne Pages (Tencent EdgeOne). Debe usarse cuando la intención principal del usuario es implementar, publicar, enviar, alojar, lanzar, poner en marcha o lanzar una nueva versión, por ejemplo. "implementar mi aplicación", "publicar este sitio", "publicar esto", "crear una implementación de vista previa", "implementar en EdgeOne", "enviar a producción", "lanzar", "lanzar", "publicar una nueva versión", "volver a implementar", "上线", "发布", "发一版", "重新部署". NO active cuando la implementación solo se menciona como un paso secundario (por ejemplo, "escribir una API e implementarla"; la intención principal es escribir código, usar funciones de nube de creadores). NO active errores de tiempo de ejecución posteriores a la implementación (por ejemplo, problemas de CORS, errores 500 después de la implementación; utilice las funciones de nube de creadores o las funciones de borde de creadores para solucionar problemas).
