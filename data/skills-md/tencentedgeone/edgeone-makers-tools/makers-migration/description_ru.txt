Перенесите существующие проекты агентов ИИ (LangChain, LangGraph, OpenAI Agents SDK, Claude Agent SDK, CrewAI) на соглашения платформы EdgeOne Makers. Используйте, когда пользователь хочет адаптировать стандартный проект агента для запуска на EdgeOne Makers, преобразовать маршруты API Express/Next.js в обработчики Makers или добавить возможности платформы (context.tools, context.sandbox, context.store). НЕ запускайте триггеры для новых проектов агентов (вместо этого используйте создателей-агентов).
