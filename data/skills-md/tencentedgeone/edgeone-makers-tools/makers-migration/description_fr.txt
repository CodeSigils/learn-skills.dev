Migrez les projets d'agents IA existants (LangChain, LangGraph, OpenAI Agents SDK, Claude Agent SDK, CrewAI) vers les conventions de la plateforme EdgeOne Makers. À utiliser lorsque l'utilisateur souhaite adapter un projet d'agent standard pour l'exécuter sur EdgeOne Makers, convertir les routes API Express/Next.js en gestionnaires Makers ou ajouter des fonctionnalités de plate-forme (context.tools, context.sandbox, context.store). Ne déclenchez PAS de nouveaux projets d'agent (utilisez plutôt des créateurs-agents).
