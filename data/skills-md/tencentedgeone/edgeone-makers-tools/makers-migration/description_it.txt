Migra i progetti di agenti AI esistenti (LangChain, LangGraph, OpenAI Agents SDK, Claude Agent SDK, CrewAI) alle convenzioni della piattaforma EdgeOne Makers. Da utilizzare quando l'utente desidera adattare un progetto agente standard per l'esecuzione su EdgeOne Makers, convertire i percorsi API Express/Next.js in gestori Makers o aggiungere funzionalità della piattaforma (context.tools, context.sandbox, context.store). NON eseguire l'attivazione per nuovi progetti di agenti (utilizza invece maker-agents).
