既存の AI エージェント プロジェクト (LangChain、LangGraph、OpenAI Agents SDK、Claude Agent SDK、CrewAI) を EdgeOne Makers プラットフォーム規約に移行します。ユーザーが標準エージェント プロジェクトを EdgeOne Makers で実行するように調整する場合、Express/Next.js API ルートを Makers ハンドラーに変換する場合、またはプラットフォーム機能 (context.tools、context.sandbox、context.store) を追加する場合に使用します。新しいエージェント プロジェクトをトリガーしないでください (代わりに Maker-Agent を使用してください)。
