Migre proyectos de agentes de IA existentes (LangChain, LangGraph, OpenAI Agents SDK, Claude Agent SDK, CrewAI) a las convenciones de la plataforma EdgeOne Makers. Úselo cuando el usuario desee adaptar un proyecto de agente estándar para ejecutarlo en EdgeOne Makers, convertir rutas API Express/Next.js a controladores de Makers o agregar capacidades de plataforma (context.tools, context.sandbox, context.store). NO active proyectos de nuevos agentes (en su lugar, utilice agentes creadores).
