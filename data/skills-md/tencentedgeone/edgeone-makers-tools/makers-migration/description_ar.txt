قم بترحيل مشاريع وكيل الذكاء الاصطناعي الحالية (LangChain، وLangGraph، وOpenAI Agents SDK، وClaude Agent SDK، وCrewAI) إلى اتفاقيات النظام الأساسي EdgeOne Makers. يُستخدم عندما يريد المستخدم تكييف مشروع وكيل قياسي ليتم تشغيله على EdgeOne Makers، أو تحويل مسارات Express/Next.js API إلى معالجات Makers، أو إضافة إمكانات النظام الأساسي (context.tools، context.sandbox، context.store). لا تقم بتشغيل مشاريع الوكيل الجديدة (استخدم وكلاء المصنعين بدلاً من ذلك).
