このスキルは、EdgeOne Makers で AI エージェント エンドポイントを構築するためのガイドです。5 つのフレームワーク ルート (DeepAgents、LangGraph、CrewAI、OpenAI Agents SDK、Claude Agent SDK)、プラットフォームに挿入された `context.store` / `context.tools` / `context.sandbox`、conversation_id デュアルチャネル ルーティング、SSE ストリーミング、および `agents/` と `cloud-functions/` の分離です。これは、ユーザーが EdgeOne Maker で AI エージェント エンドポイントを作成またはレビューしたい場合に使用する必要があります。 「EdgeOne Makers でエージェントを構築する」、「Claude エージェント エンドポイントを作成する」、「LangGraph を Maker に接続する」、「SSE を使用して LLM 応答をストリーミングする」、「エージェント テンプレートを確認する」、「context.store / context.sandbox / context.tools を使用する」。プレーンな Edge 関数、クラウド関数、またはミドルウェアをトリガーしないでください (これらは AI ロジックを実行しません。代わりに Maker-cloud-functions またはmaker-edge-functions を使用してください)。デプロイメント ワークフローをトリガーしないでください (maker-deploy を使用)。 EdgeOne Makers プロジェクト以外の汎用 AI フレームワーク開発をトリガーしないでください。
