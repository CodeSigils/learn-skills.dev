Dieser Skill führt zum Aufbau von KI-Agent-Endpunkten auf EdgeOne Makers – fünf Framework-Routen (DeepAgents, LangGraph, CrewAI, OpenAI Agents SDK, Claude Agent SDK), plattforminjiziertes „context.store“ / „context.tools“ / „context.sandbox“, conversation_id Dual-Channel-Routing, SSE-Streaming und Trennung von „agents/“ vs. „cloud-functions/“. Es sollte verwendet werden, wenn der Benutzer einen KI-Agent-Endpunkt auf EdgeOne Makers erstellen oder überprüfen möchte – z. B. „Erstellen Sie einen Agenten auf EdgeOne Makers“, „Erstellen Sie einen Claude-Agenten-Endpunkt“, „Verbinden Sie LangGraph mit Makers“, „Streamen Sie LLM-Antworten mit SSE“, „überprüfen Sie meine Agentenvorlage“, „verwenden Sie context.store / context.sandbox / context.tools“. Lösen Sie NICHT für einfache Edge-Funktionen, Cloud-Funktionen oder Middleware aus (diese führen keine KI-Logik aus – verwenden Sie stattdessen Makers-Cloud-Functions oder Makers-Edge-Functions). NICHT für Bereitstellungsworkflows auslösen (makers-deploy verwenden). Lösen Sie NICHT die Entwicklung eines generischen KI-Frameworks außerhalb eines EdgeOne Makers-Projekts aus.
