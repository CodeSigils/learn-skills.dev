Этот навык помогает создавать конечные точки агентов ИИ в EdgeOne Makers — пять маршрутов инфраструктуры (DeepAgents, LangGraph, CrewAI, OpenAI Agents SDK, Claude Agent SDK), внедрённые в платформу `context.store` / `context.tools` / `context.sandbox`, двухканальная маршрутизация разговора_id, потоковая передача SSE и разделение `agents/` и `cloud-functions/`. Его следует использовать, когда пользователь хочет создать или просмотреть конечную точку агента ИИ в EdgeOne Makers — например. «создать агент на EdgeOne Makers», «создать конечную точку агента Claude», «подключить LangGraph к Makers», «потоковое вещание ответов LLM с помощью SSE», «просмотреть шаблон моего агента», «использовать context.store / context.sandbox / context.tools». НЕ запускайте триггеры для простых пограничных функций, облачных функций или промежуточного программного обеспечения (в которых не используется логика искусственного интеллекта — вместо этого используйте функции-облака-функции или функции-пограничные функции). НЕ запускайте рабочие процессы развертывания (используйтеmakers-deploy). НЕ инициируйте разработку общей платформы искусственного интеллекта за пределами проекта EdgeOne Makers.
