Cette compétence guide la création de points de terminaison d'agent IA sur EdgeOne Makers : cinq routes de structure (DeepAgents, LangGraph, CrewAI, OpenAI Agents SDK, Claude Agent SDK), "context.store" / "context.tools" / "context.sandbox" injectés par la plate-forme, le routage double canal conversation_id, le streaming SSE et la séparation "agents/" et "cloud-functions/". Il doit être utilisé lorsque l'utilisateur souhaite créer ou réviser un point de terminaison d'agent IA sur EdgeOne Makers, par exemple. "créer un agent sur EdgeOne Makers", "créer un point de terminaison d'agent Claude", "connecter LangGraph à Makers", "diffuser les réponses LLM avec SSE", "examiner mon modèle d'agent", "utiliser context.store / context.sandbox / context.tools". Ne déclenchez PAS pour les fonctions Edge simples, les fonctions Cloud ou les middlewares (ceux-ci n'exécutent pas de logique d'IA - utilisez plutôt les fonctions makers-cloud ou makers-edge-functions). Ne déclenchez PAS les workflows de déploiement (utilisez makers-deploy). Ne déclenchez PAS le développement d’un framework d’IA générique en dehors d’un projet EdgeOne Makers.
