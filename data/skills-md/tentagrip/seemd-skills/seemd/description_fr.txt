À utiliser lorsque l'utilisateur demande une URL Web partageable pour un fichier de démarque local. Se déclenche sur des expressions telles que « partager cette démarque », « partager ce document », « donnez-moi un lien pour ceci », « envoyer ceci sous forme d'URL », « publier ceci », « créer une page publique pour cela » et des équivalents coréens comme « 공유해줘 », « 이 README 공유 », « 링크로 보내줘 ». Surtout lorsque l'utilisateur nomme un chemin de fichier « .md » avec l'une de ces phrases. Exécute `npx @tentagrip/seemd <path>`, renvoie une URL de slug sur https://seemd.xyz. Les fichiers « .md » liés sont téléchargés ensemble et les liens entre documents sont réécrits en URL de slug. Les documents expirent automatiquement après 3 jours.
