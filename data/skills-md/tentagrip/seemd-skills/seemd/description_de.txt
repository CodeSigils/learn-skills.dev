Verwenden Sie diese Option, wenn der Benutzer nach einer gemeinsam nutzbaren Web-URL für eine lokale Markdown-Datei fragt. Löst Auslöser auf Ausdrücke wie „Teilen Sie diesen Markdown“, „Teilen Sie dieses Dokument“, „Gib mir einen Link dafür“, „Sende dies als URL“, „Veröffentliche dies“, „Erstelle eine öffentliche Seite dafür“ und koreanische Äquivalente wie „공유해줘“, „이 README 공유“, „링크로 보내줘“. Vor allem, wenn der Benutzer einen „.md“-Dateipfad zusammen mit einem dieser Ausdrücke benennt. Führt „npx @tentagrip/seemd <path>“ aus und gibt eine Slug-URL auf https://seemd.xyz zurück. Verknüpfte „.md“-Dateien werden zusammen hochgeladen und dokumentübergreifende Links in Slug-URLs umgeschrieben. Dokumente verfallen automatisch nach 3 Tagen.
