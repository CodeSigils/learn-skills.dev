Úselo cuando el usuario solicite una URL web que se pueda compartir para un archivo de rebajas local. Activadores de frases como "compartir esta rebaja", "compartir este documento", "darme un enlace para esto", "enviar esto como URL", "publicar esto", "crear una página pública para esto" y equivalentes coreanos como "공유해줘", "이 README 공유", "링크로 보내줘". Especialmente cuando el usuario nombra la ruta de un archivo `.md` junto con una de esas frases. Ejecuta `npx @tentagrip/seemd <ruta>`, devuelve una URL slug en https://seemd.xyz. Los archivos `.md` vinculados se cargan juntos y los enlaces entre documentos se reescriben en URL de slug. Los documentos caducan automáticamente después de 3 días.
