ユーザーがローカル マークダウン ファイルの共有可能な Web URL を要求する場合に使用します。 「このマークダウンを共有する」、「このドキュメントを共有する」、「このリンクをください」、「これを URL として送信する」、「これを公開する」、「この公開ページを作成する」などのフレーズ、および「공유해줘」、「이 README 공유」、「링크로 보내줘」などの韓国語の同等語でトリガーされます。特に、ユーザーがこれらのフレーズの 1 つと一緒に `.md` ファイル パスに名前を付ける場合はそうです。 `npx @tentagrip/seemd <path>` を実行し、https://seemd.xyz のスラッグ URL を返します。リンクされた `.md` ファイルは一緒にアップロードされ、ドキュメント間のリンクはスラッグ URL に書き換えられます。ドキュメントは 3 日後に自動的に期限切れになります。
