사용자가 로컬 마크다운 파일에 대해 공유 가능한 웹 URL을 요청할 때 사용합니다. "이 마크다운 공유", "이 문서 공유", "이 문서에 대한 링크 제공", "URL로 보내기", "이 게시", "공개 페이지 만들기"와 같은 문구와 "공유해줘", "이 README 공유", "링크로 보내줘"와 같은 한국어 상응어에 대해 트리거됩니다. 특히 사용자가 해당 문구 중 하나와 함께 '.md' 파일 경로 이름을 지정하는 경우 더욱 그렇습니다. `npx @tentagrip/seemd <path>`를 실행하고 https://seemd.xyz에서 슬러그 URL을 반환합니다. 연결된 `.md` 파일은 함께 업로드되고 문서 간 링크는 슬러그 URL로 다시 작성됩니다. 문서는 3일 후에 자동으로 만료됩니다.
