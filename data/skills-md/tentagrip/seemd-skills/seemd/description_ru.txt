Используйте, когда пользователь запрашивает общий веб-URL для локального файла уценки. Запускается по таким фразам, как «поделиться этой уценкой», «поделиться этим документом», «дайте мне ссылку на это», «отправить это как URL», «опубликовать это», «сделать общедоступную страницу для этого», а также корейские эквиваленты, такие как «공유해줘», «이 README 공유», «링크로 보내줘». Особенно, когда пользователь называет путь к файлу `.md` вместе с одной из этих фраз. Запускает `npx @tentagrip/seemd <path>`, возвращает URL-адрес https://seemd.xyz. Связанные файлы `.md` загружаются вместе, а междокументные ссылки перезаписываются в URL-адреса. Срок действия документов истекает автоматически через 3 дня.
