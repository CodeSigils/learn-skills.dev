Da utilizzare quando l'utente richiede un URL Web condivisibile per un file markdown locale. Si attiva su frasi come "condividi questo markdown", "condividi questo documento", "dammi un collegamento per questo", "invia questo come URL", "pubblica questo", "crea una pagina pubblica per questo" e equivalenti coreani come "공유해줘", "이 README 공유", "링크로 보내줘". Soprattutto quando l'utente nomina un percorso di file `.md` insieme a una di quelle frasi. Esegue `npx @tentagrip/seemd <path>`, restituisce uno slug URL su https://seemd.xyz. I file `.md` collegati vengono caricati insieme e i collegamenti tra documenti vengono riscritti in URL slug. I documenti scadono automaticamente dopo 3 giorni.
