【Habilidad de la etapa de desarrollo del controlador KWC KS】la programa kwc-orchestrator durante la fase de implementación del código del controlador y se activa solo cuando existe el directorio app/ks/controller/. Esta habilidad se centra en la escritura de configuración XML y la implementación de código TypeScript/KingScript para controladores de script KingScript; no maneja la creación, construcción o implementación de proyectos (manejado por kwc-project-scaffold), ni maneja el diseño UI/UX (manejado por kwc-design). Cuando se trate de especificaciones del lenguaje KingScript y uso del SDK, consulte el paquete de habilidades del generador de código kingscript. Si la tarea involucra la CLI, la construcción o la implementación de kd, debe notificar a kwc-orchestrator para que cambie a kwc-project-scaffold.
