【KWC KS Controller Development Stage Skill】is scheduled by kwc-orchestrator during the Controller code implementation phase and is activated only when the app/ks/controller/ directory exists. This Skill focuses on XML configuration writing and TypeScript/KingScript code implementation for KingScript script controllers; it does not handle project creation, building, or deployment (handled by kwc-project-scaffold), nor does it handle UI/UX design (handled by kwc-design). When involving KingScript language specifications and SDK usage, refer to the kingscript-code-generator skill pack. If the task involves the kd CLI, building, or deployment, you must notify kwc-orchestrator to switch to kwc-project-scaffold.
