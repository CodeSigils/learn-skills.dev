مهارة مرحلة تطوير وحدة التحكم KWC KS تتم جدولتها بواسطة kwc-orchestrator أثناء مرحلة تنفيذ رمز وحدة التحكم ويتم تنشيطها فقط عند وجود التطبيق/ks/وحدة التحكم/ الدليل. تركز هذه المهارة على كتابة تكوين XML وتنفيذ كود TypeScript/KingScript لوحدات تحكم البرنامج النصي KingScript؛ فهو لا يتعامل مع إنشاء المشروع أو بنائه أو نشره (يتم التعامل معه بواسطة kwc-project-scaffold)، ولا يتعامل مع تصميم واجهة المستخدم/UX (يتم التعامل معه بواسطة kwc-design). عند تضمين مواصفات لغة KingScript واستخدام SDK، راجع حزمة مهارات مولد كود Kingscript. إذا كانت المهمة تتضمن kd CLI أو البناء أو النشر، فيجب عليك إخطار kwc-orchestrator للتبديل إلى kwc-project-scaffold.
