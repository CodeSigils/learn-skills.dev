Эксперт по разработке компонентов для универсальных React-проектов. Подходит для сценариев, которые не полагаются на инженерную структуру KWC и требуют использования только @kdcloudjs/shoelace и расширенных компонентов KWC в проекте React. Отвечает за написание кода компонентов, методы интеграции, привязку событий, стандарты оформления и соответствующие консультации по API. Если текущий проект уже является проектом KWC React, переключитесь на kwc-react-development.
