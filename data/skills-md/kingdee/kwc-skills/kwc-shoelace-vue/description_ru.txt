Эксперт по разработке компонентов для общих проектов Vue. Подходит для сценариев, которые не полагаются на инженерную структуру KWC и нуждаются только в использовании @kdcloudjs/shoelace и компонентов расширения KWC в проектах Vue. Отвечает за написание кода компонента, методы импорта, привязку событий, передачу свойств, спецификации стилей и соответствующие консультации по API. Если текущий проект уже является проектом KWC Vue, переключитесь на kwc-vue-development.
