يستخدم للتعامل مع مهام تخصيص Kingscript، بما في ذلك إنشاء البرنامج النصي أو تعديله، أو تفسير إعلان SDK، أو تعيين قدرة Java المفتوحة، أو تشخيص أخطاء وقت التشغيل، أو مراجعة مخاطر التنفيذ، أو تصميم نمط التطوير الثانوي. إعطاء الأولوية لإعادة استخدام الأمثلة والقوالب وفهارس SDK وفهارس بناء الجملة المشتركة؛ لا تقم بتصنيع واجهات برمجة التطبيقات غير المتاحة.
