Utilizzato per gestire le attività di personalizzazione di Kingscript, tra cui la generazione o la modifica di script, l'interpretazione delle dichiarazioni SDK, la mappatura delle capacità aperte Java, la diagnosi degli errori di runtime, la revisione dei rischi di implementazione o la progettazione di modelli di sviluppo secondari. Dare priorità al riutilizzo di esempi, modelli, indici SDK e indici di sintassi condivisi; non creare API non disponibili.
