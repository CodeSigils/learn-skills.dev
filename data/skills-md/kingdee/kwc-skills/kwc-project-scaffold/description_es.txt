Utilice la CLI de KWC (kd) para traducir los requisitos del usuario en proyectos, componentes, metadatos de página, configuración del entorno, implementación y resultados de depuración de KWC entregables. Utilícelo cuando el Agente necesite desarrollar o expandir un proyecto de KWC, dividir funciones en componentes de KWC, crear o actualizar archivos *.page-meta.kwp, configurar el entorno kd, implementar metadatos en un entorno de destino o guiar el flujo de trabajo completo desde los requisitos hasta la representación de páginas de KWC.
