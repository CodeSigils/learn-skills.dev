Utilizza la CLI KWC (kd) per tradurre i requisiti degli utenti in progetti KWC, componenti, metadati di pagina, configurazione dell'ambiente, distribuzione e risultati di debug. Utilizzalo quando l'agente deve strutturare o espandere un progetto KWC, dividere le funzionalità in componenti KWC, creare o aggiornare file *.page-meta.kwp, configurare l'ambiente kd, distribuire metadati in un ambiente di destinazione o guidare l'intero flusso di lavoro dai requisiti al rendering della pagina KWC.
