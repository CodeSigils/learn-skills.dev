Utilizza la CLI KWC (kd) per tradurre i requisiti degli utenti in progetti KWC, componenti, metadati di pagina, configurazioni dell'ambiente, distribuzioni e risultati di debug consegnabili. Usalo quando l'agente deve strutturare o estendere un progetto KWC, dividere le funzionalità in componenti KWC, creare o aggiornare file *.page-meta.kwp, configurare kd env, distribuire metadati negli ambienti di destinazione o guidare l'intero processo dai requisiti al rendering della pagina KWC.
