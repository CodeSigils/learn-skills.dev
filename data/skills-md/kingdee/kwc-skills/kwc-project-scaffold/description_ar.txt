استخدم KWC CLI (kd) لترجمة متطلبات المستخدم إلى مشاريع KWC القابلة للتسليم والمكونات وبيانات تعريف الصفحة وتكوين البيئة والنشر ونتائج التصحيح. استخدمه عندما يحتاج الوكيل إلى دعم مشروع KWC أو توسيعه، أو تقسيم الميزات إلى مكونات KWC، أو إنشاء ملفات *.page-meta.kwp أو تحديثها، أو تكوين بيئة kd، أو نشر بيانات التعريف إلى بيئة مستهدفة، أو توجيه سير العمل الكامل من المتطلبات إلى عرض صفحة KWC.
