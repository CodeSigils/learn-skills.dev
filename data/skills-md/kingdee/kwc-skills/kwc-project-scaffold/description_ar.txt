استخدم KWC CLI (kd) لترجمة متطلبات المستخدم إلى هندسة KWC القابلة للتسليم والمكونات وبيانات تعريف الصفحة وتكوين البيئة والنشر ونتائج التصحيح. استخدمه عندما يحتاج الوكيل إلى دعم مشروع KWC أو توسيعه، أو تقسيم الميزات إلى مكونات KWC، أو إنشاء أو تحديث *.page-meta.kwp، أو تكوين kd env، أو نشر بيانات التعريف إلى البيئات المستهدفة، أو توجيه العملية الكاملة من المتطلبات إلى عرض صفحة KWC.
