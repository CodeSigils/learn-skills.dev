Verwenden Sie die KWC CLI (kd), um Benutzeranforderungen in lieferbare KWC-Projekte, Komponenten, Seitenmetadaten, Umgebungskonfigurationen, Bereitstellungen und Debugging-Ergebnisse zu übersetzen. Wird verwendet, wenn der Agent ein Gerüst erstellen oder ein KWC-Projekt erweitern, Features in KWC-Komponenten aufteilen, *.page-meta.kwp erstellen oder aktualisieren, kd env konfigurieren, Metadaten in einer Zielumgebung bereitstellen oder den gesamten Workflow von den Anforderungen bis zum Rendern von KWC-Seiten steuern muss.
