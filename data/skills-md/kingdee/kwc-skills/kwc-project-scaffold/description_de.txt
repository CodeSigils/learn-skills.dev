Verwenden Sie die KWC CLI (kd), um Benutzeranforderungen in lieferbare KWC-Projekte, Komponenten, Seitenmetadaten, Umgebungskonfiguration, Bereitstellung und Debugging-Ergebnisse zu übersetzen. Setzen Sie es ein, wenn der Agent ein KWC-Projekt aufbauen oder erweitern, Features in KWC-Komponenten aufteilen, *.page-meta.kwp-Dateien erstellen oder aktualisieren, die KD-Umgebung konfigurieren, Metadaten in einer Zielumgebung bereitstellen oder den gesamten Workflow von den Anforderungen bis zur KWC-Seitendarstellung steuern muss.
