Utilícelo cuando el usuario necesite preparar materiales para una reunión de un grupo de revisión de literatura económica, especialmente adecuado para revisiones de literatura económica china, selección y agrupación de artículos de revisión, conversión de archivos PDF en papel a Markdown, generación de esquemas de revisión, redacción de contenido PPT completo, creación de diapositivas para reuniones de grupo y preparación de notas de lectura exhaustivas como respaldo para artículos que puedan ser cuestionados. También es útil para flujos de trabajo de seminarios de revisión de literatura económica en contextos ingleses.
