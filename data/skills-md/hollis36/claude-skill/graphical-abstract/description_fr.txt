Assistant de création de résumé graphique d'article académique (Graphical Abstract/TOC figure). Prend en charge plusieurs outils : Python (matplotlib/PIL/drawsvg), HTML/CSS/SVG, TikZ/LaTeX, Figma MCP, Banana Pro MCP, Plotly+Kaleido. Intègre les dernières tendances de conception de 2025-2026 (design plat, Glassmorphisme, isométrique, animation) et les directives de conception d'accessibilité. Déclenché lorsque l'utilisateur doit : (1) dessiner un résumé d'article/une figure de table des matières, (2) créer un diagramme de flux de travail de recherche, (3) concevoir un résumé graphique pour la soumission d'une revue, (4) produire une illustration de base pour une affiche académique. Mots-clés : résumé graphique, figure abstraite, figure TOC, organigramme, diagramme schématique, diagramme de mécanisme, diagramme d'architecture.
