Academic paper graphical abstract (Graphical Abstract/TOC figure) creation assistant. Supports multiple tools: Python (matplotlib/PIL/drawsvg), HTML/CSS/SVG, TikZ/LaTeX, Figma MCP, Banana Pro MCP, Plotly + Kaleido.
