Academic paper abstract diagram (Graphical Abstract/TOC figure) creation assistant. Supports multiple tools: Python (matplotlib/PIL/drawsvg), HTML/CSS/SVG, TikZ/LaTeX, Figma MCP, Banana Pro MCP, Plotly+Kaleido. Incorporates the latest design trends for 2025‑2026 (flat design, Glassmorphism, isometric, animation) and accessibility design guidelines. Triggers when the user needs to: (1) draw a paper abstract/TOC figure, (2) create a research workflow schematic, (3) design a graphical abstract for journal submission, (4) produce core illustrations for academic posters. Keywords: graphical abstract, abstract figure, TOC figure, flowchart, schematic, mechanism diagram, architecture diagram.
