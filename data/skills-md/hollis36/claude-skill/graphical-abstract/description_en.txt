Academic paper graphical abstract (Graphical Abstract/TOC figure) creation assistant. Supports multiple tools: Python (matplotlib/PIL/drawsvg), HTML/CSS/SVG, TikZ/LaTeX, Figma MCP, Banana Pro MCP, Plotly + Kaleido. Incorporates the latest design trends of 2025‑2026 (flat design, Glassmorphism, isometric, animation) and accessibility design guidelines. Triggered when the user needs to: (1) draw a paper abstract/TOC figure, (2) create a research workflow diagram, (3) design a graphical abstract for journal submission, (4) produce a core illustration for an academic poster. Keywords: graphical abstract, abstract figure, TOC figure, flowchart, schematic diagram, mechanism diagram, architecture diagram.
