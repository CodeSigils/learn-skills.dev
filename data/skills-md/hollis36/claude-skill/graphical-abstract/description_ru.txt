Помощник по созданию графического реферата академической статьи (Graphical Abstract/TOC). Поддерживает несколько инструментов: Python (matplotlib/PIL/drawsvg), HTML/CSS/SVG, TikZ/LaTeX, Figma MCP, Banana Pro MCP, Plotly+Kaleido. Включает в себя последние тенденции дизайна 2025–2026 годов (плоский дизайн, глассморфизм, изометрия, анимация) и рекомендации по дизайну для обеспечения доступности. Срабатывает, когда пользователю необходимо: (1) нарисовать аннотацию статьи/оглавление, (2) создать диаграмму рабочего процесса исследования, (3) разработать графическую аннотацию для подачи в журнал, (4) создать основную иллюстрацию для академического плаката. Ключевые слова: графическая аннотация, абстрактная фигура, фигура оглавления, блок-схема, принципиальная схема, схема механизма, схема архитектуры.
