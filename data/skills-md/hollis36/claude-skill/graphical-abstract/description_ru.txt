Помощник по созданию абстрактной схемы академической статьи (графического реферата/оглавления). Поддерживает несколько инструментов: Python (matplotlib/PIL/drawsvg), HTML/CSS/SVG, TikZ/LaTeX, Figma MCP, Banana Pro MCP, Plotly+Kaleido. Включает в себя последние тенденции дизайна на 2025–2026 годы (плоский дизайн, глассморфизм, изометрию, анимацию) и рекомендации по дизайну для обеспечения доступности. Срабатывает, когда пользователю необходимо: (1) нарисовать реферат статьи/фигуру содержания, (2) создать диаграмму рабочего процесса исследования, (3) разработать графический реферат для подачи в журнал, (4) создать основную иллюстрацию для академического плаката. Ключевые слова: графическая аннотация, абстрактная фигура, фигура оглавления, блок-схема, принципиальная схема, схема механизма, архитектурная схема.
