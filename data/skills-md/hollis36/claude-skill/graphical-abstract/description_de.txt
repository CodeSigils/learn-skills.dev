Assistent für die Erstellung grafischer Zusammenfassungen wissenschaftlicher Arbeiten (Graphical Abstract/TOC Figure). Unterstützt mehrere Tools: Python (matplotlib/PIL/drawsvg), HTML/CSS/SVG, TikZ/LaTeX, Figma MCP, Banana Pro MCP, Plotly+Kaleido. Beinhaltet die neuesten Designtrends von 2025–2026 (flaches Design, Glasmorphismus, Isometrie, Animation) und Richtlinien für barrierefreies Design. Wird ausgelöst, wenn der Benutzer: (1) eine Papierzusammenfassung/TOC-Abbildung zeichnen muss, (2) ein Forschungs-Workflow-Diagramm erstellen, (3) eine grafische Zusammenfassung für die Einreichung in einer Zeitschrift entwerfen muss, (4) eine Kernillustration für ein wissenschaftliches Poster erstellen muss. Schlüsselwörter: grafische Zusammenfassung, abstrakte Abbildung, TOC-Abbildung, Flussdiagramm, schematisches Diagramm, Mechanismusdiagramm, Architekturdiagramm.
