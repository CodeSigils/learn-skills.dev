Рабочий процесс разработки на основе дерева перекрестных репозиториев. Используйте при настройке или обеспечении процесса командного кодирования с выделенным идентификатором коммиттера git, людьми в качестве авторов git, рабочими деревьями git для каждой задачи и предварительным просмотром ngrok на основе фрагмента рабочего дерева. Запускается по запросам о кодировании Vibe, рабочих деревьях, принудительном исполнении автором/коммиттером git, процессе перекрестного репозитория или рабочем процессе предварительного просмотра ngrok.
