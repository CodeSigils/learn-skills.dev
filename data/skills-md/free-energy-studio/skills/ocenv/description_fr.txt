Implémentez et maintenez la configuration d'environnement OpenClaw utilisée sur cette machine. À utiliser lorsqu'on vous demande de configurer, déboguer ou expliquer comment les variables d'environnement et les secrets doivent fonctionner pour OpenClaw, les shells et les CLI dépendantes des jetons. Couvre le flux de synchronisation canonique `.env.tpl` vers `.env`, les références secrètes 1Password, l'installation du script `env-sync.sh` dans `/root/.openclaw/env-sync.sh` et le chargement `/root/.openclaw/.env` à partir de `/root/.profile` afin que les shells normaux et les processus CLI générés par OpenClaw héritent de l'environnement par défaut. Utilisez également lors du débogage pourquoi un jeton est dans « .env » mais n'est pas disponible pour les commandes, ou lors de la réimplémentation de cette solution d'environnement sur une autre machine.
