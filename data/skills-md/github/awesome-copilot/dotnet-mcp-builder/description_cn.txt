根据当前的 ModelContextProtocol 1.x NuGet 包在 C#/.NET 中构建模型上下文协议 (MCP) 服务器。特别有助于模型在没有指导的情况下经常出错的情况 - 过时的预览版本（它倾向于选择 0.3 或 0.4 预览版）、MCP 应用程序（在主机中呈现的交互式 UI）、诱导 URL 模式、每会话 HTTP 接线、OAuth 和反向代理部署细节，以及调试具体的 MapMcp / STDIO / Streamable-HTTP 错误。还涵盖日常工作 — STDIO 和 Streamable HTTP 传输（SSE 已弃用）、工具、提示、资源、采样、根、完成、日志记录 — 以及基本的 .NET MCP 客户端。当用户说出或暗示任何 .NET MCP 服务器工作时触发：ModelContextProtocol、McpServerTool、MapMcp、WithStdioServerTransport、“C# 中的 MCP 服务器”、“dotnet 中的 MCP 工具”、“将其公开为 MCP”或在 .NET 上下文中命名原语（提示/资源/启发/MCP 应用程序）。跳过其他语言的 MCP 工作。
