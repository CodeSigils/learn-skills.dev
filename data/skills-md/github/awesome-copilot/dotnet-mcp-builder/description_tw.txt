根據目前的 ModelContextProtocol 1.x NuGet 套件在 C#/.NET 中建立模型上下文協定 (MCP) 伺服器。特別有助於模型在沒有指導的情況下經常出錯的情況 - 過時的預覽版本（它傾向於選擇 0.3 或 0.4 預覽版）、MCP 應用程式（在主機中呈現的交互式 UI）、誘導 URL 模式、每會話 HTTP 接線、OAuth 和反向代理部署細節，以及特定的 Map/p Stream STD /pable Stream STD /pable/pableTable/Table。也涵蓋日常工作 — STDIO 和 Streamable HTTP 傳輸（SSE 已棄用）、工具、提示、資源、取樣、根、完成、日誌記錄 — 以及基本的 .NET MCP 用戶端。當使用者說出或暗示任何 .NET MCP 伺服器工作時觸發：ModelContextProtocol、McpServerTool、MapMcp、WithStdioServerTransport、「C# 中的 MCP 伺服器」、「dotnet 中的 MCP 工具」、「將其公開為 MCP」或在 .NET 上下文中命名原語（跳過其他語言的 MCP 工作。
