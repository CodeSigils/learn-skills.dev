Erstellen Sie Model Context Protocol (MCP)-Server in C#/.NET mit den aktuellen ModelContextProtocol 1.x NuGet-Paketen. Hilft besonders in Fällen, in denen das Modell oft ohne Anleitung schief geht – veraltete Vorschauversionen (in der Regel werden die Vorschauversionen 0,3 oder 0,4 ausgewählt), MCP-Apps (interaktive, im Host gerenderte Benutzeroberfläche), Auslöse-URL-Modus, sitzungsspezifische HTTP-Verkabelung, OAuth- und Reverse-Proxy-Bereitstellungsspezifikationen und Debuggen konkreter MapMcp-/STDIO-/Streamable-HTTP-Fehler. Deckt auch die Routinearbeit ab – STDIO- und Streamable-HTTP-Transporte (SSE ist veraltet), Tools, Eingabeaufforderungen, Ressourcen, Sampling, Roots, Vervollständigungen, Protokollierung – und einen einfachen .NET MCP-Client. Wird ausgelöst, wenn der Benutzer eine .NET MCP-Serverarbeit sagt oder impliziert: ModelContextProtocol, McpServerTool, MapMcp, WithStdioServerTransport, „MCP-Server in C#“, „MCP-Tool in Dotnet“, „Dies als MCP verfügbar machen“ oder ein Grundelement (Eingabeaufforderung/Ressource/Elicitation/MCP-App) in einem .NET-Kontext benennt. Für MCP-Arbeiten in anderen Sprachen überspringen.
