إنشاء خوادم بروتوكول سياق النموذج (MCP) في C#/.NET مقابل حزم ModelContextProtocol 1.x NuGet الحالية. يساعد بشكل خاص في الحالات التي غالبًا ما يخطئ فيها النموذج دون توجيه - إصدارات المعاينة التي لا معنى لها (تميل إلى اختيار معاينة 0.3 أو 0.4)، وتطبيقات MCP (واجهة المستخدم التفاعلية المقدمة في المضيف)، ووضع URL الاستنباط، وأسلاك HTTP لكل جلسة، وتفاصيل نشر OAuth والوكيل العكسي، وتصحيح أخطاء MapMcp / STDIO / Streamable-HTTP الملموسة. يغطي أيضًا العمل الروتيني - عمليات نقل STDIO وHTTP القابلة للتدفق (تم إهمال SSE)، والأدوات، والمطالبات، والموارد، وأخذ العينات، والجذور، والإكمالات، والتسجيل - وعميل .NET MCP الأساسي. يتم تشغيله عندما يقول المستخدم أو يشير إلى أي عمل لخادم .NET MCP: ModelContextProtocol، أو McpServerTool، أو MapMcp، أو WithStdioServerTransport، أو "خادم MCP في C#"، أو "أداة MCP في dotnet"، أو "كشف هذا كـ MCP"، أو أسماء بدائية (موجه/مورد/استدعاء/تطبيق MCP) في سياق .NET. انتقل إلى عمل MCP بلغات أخرى.
