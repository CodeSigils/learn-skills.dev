Создайте серверы протокола контекста модели (MCP) на C#/.NET с использованием текущих пакетов NuGet ModelContextProtocol 1.x. Особенно помогает в тех случаях, когда модель часто ошибается без руководства — устаревшие версии предварительного просмотра (обычно выбирают предварительную версию 0,3 или 0,4), приложения MCP (интерактивный пользовательский интерфейс, отображаемый на хосте), режим извлечения URL-адресов, подключение HTTP для каждого сеанса, особенности развертывания OAuth и обратного прокси-сервера, а также отладка конкретных ошибок MapMcp / STDIO / Streamable-HTTP. Также охватывает рутинную работу — транспорты STDIO и Streamable HTTP (SSE устарел), инструменты, подсказки, ресурсы, выборку, корни, завершение, ведение журнала — и базовый клиент .NET MCP. Запускается, когда пользователь говорит или подразумевает работу любого сервера .NET MCP: ModelContextProtocol, McpServerTool, MapMcp, WithStdioServerTransport, «сервер MCP в C#», «инструмент MCP в dotnet», «представить это как MCP» или называет примитив (приглашение/ресурс/выявление/приложение MCP) в контексте .NET. Пропустите работу MCP на других языках.
