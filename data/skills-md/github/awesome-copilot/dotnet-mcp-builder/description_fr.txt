Créez des serveurs MCP (Model Context Protocol) en C#/.NET avec les packages NuGet ModelContextProtocol 1.x actuels. Cela aide particulièrement dans les cas où le modèle se trompe souvent sans conseils : versions d'aperçu obsolètes (il a tendance à choisir l'aperçu 0.3 ou 0.4), applications MCP (interface utilisateur interactive rendue dans l'hôte), mode URL d'élicitation, câblage HTTP par session, spécificités de déploiement OAuth et proxy inverse, et débogage des erreurs concrètes MapMcp / STDIO / Streamable-HTTP. Couvre également le travail de routine : transports HTTP STDIO et Streamable (SSE est obsolète), outils, invites, ressources, échantillonnage, racines, complétions, journalisation - et un client .NET MCP de base. Déclenchez lorsque l'utilisateur dit ou implique un travail de serveur .NET MCP : ModelContextProtocol, McpServerTool, MapMcp, WithStdioServerTransport, "Serveur MCP en C#", "Outil MCP en dotnet", "exposez-le en tant que MCP", ou nomme une primitive (invite/ressource/élicitation/application MCP) dans un contexte .NET. Ignorez le travail MCP dans d’autres langues.
