MCP (モデル コンテキスト プロトコル) サーバーの構成を監査して、セキュリティ上の問題がないか確認します。このスキルは次の場合に使用します。
- .mcp.json ファイルのセキュリティ リスクの確認
- MCP サーバーの引数をチェックして、ハードコードされたシークレットまたはシェル インジェクション パターンを確認する
- MCP サーバーが固定バージョン (@latest ではない) を使用していることを検証する
- MCP サーバー構成における固定されていない依存関係の検出
- プロジェクトがどの MCP サーバーを登録しているか、およびそれらが承認リストに載っているかどうかを監査する
- MCP 構成での環境変数の使用状況とハードコードされた資格情報の確認
- 「MCP 構成は安全ですか?」、「MCP サーバーを監査する」、または「.mcp.json を確認する」などのリクエスト
キーワード: [mcp、セキュリティ、監査、秘密、シェルインジェクション、サプライチェーン、ガバナンス]
