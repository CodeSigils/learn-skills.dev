審核 MCP（模型上下文協定）伺服器配置是否有安全性問題。在以下情況下使用此技能：
- 檢查 .mcp.json 檔案是否有安全風險
- 檢查 MCP 伺服器參數中的硬編碼機密或 shell 注入模式
- 驗證 MCP 伺服器使用固定版本（不是@latest）
- 偵測 MCP 伺服器設定中未固定的依賴關係
- 審核項目註冊的 MCP 伺服器以及它們是否在批准清單中
- 檢查 MCP 配置中的環境變數使用與硬編碼憑證
- 任何請求，例如“我的 MCP 配置安全嗎？”、“審核我的 MCP 伺服器”或“檢查 .mcp.json”
