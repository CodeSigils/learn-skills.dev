审核 MCP（模型上下文协议）服务器配置是否存在安全问题。在以下情况下使用此技能：
- 检查 .mcp.json 文件是否存在安全风险
- 检查 MCP 服务器参数中的硬编码机密或 shell 注入模式
- 验证 MCP 服务器使用固定版本（不是@latest）
- 检测 MCP 服务器配置中未固定的依赖关系
- 审核项目注册的 MCP 服务器以及它们是否在批准列表中
- 检查 MCP 配置中的环境变量使用情况与硬编码凭据
- 任何请求，例如“我的 MCP 配置安全吗？”、“审核我的 MCP 服务器”或“检查 .mcp.json”
关键词：[mcp、安全、审计、秘密、shell 注入、供应链、治理]
