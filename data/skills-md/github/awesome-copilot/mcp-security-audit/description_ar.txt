تدقيق تكوينات خادم MCP (بروتوكول سياق النموذج) لمشكلات الأمان. استخدم هذه المهارة عندما:
- مراجعة ملفات .mcp.json بحثًا عن المخاطر الأمنية
- التحقق من وسيطات خادم MCP بحثًا عن الأسرار المشفرة أو أنماط حقن الصدفة
- التحقق من أن خوادم MCP تستخدم الإصدارات المثبتة (وليس @latest)
- اكتشاف التبعيات غير المثبتة في تكوينات خادم MCP
- تدقيق خوادم MCP التي يسجلها المشروع وما إذا كانت مدرجة في القائمة المعتمدة
- التحقق من استخدام متغير البيئة مقابل بيانات الاعتماد المشفرة في تكوينات MCP
- أي طلب مثل "هل تكوين MCP الخاص بي آمن؟"، أو "تدقيق خوادم MCP الخاصة بي"، أو "التحقق من .mcp.json"
