Аудит конфигураций сервера MCP (Model Context Protocol) на предмет проблем безопасности. Используйте этот навык, когда:
- Проверка файлов .mcp.json на наличие угроз безопасности.
- Проверка аргументов сервера MCP на наличие жестко запрограммированных секретов или шаблонов внедрения оболочки.
- Проверка того, что серверы MCP используют закрепленные версии (не @latest).
- Обнаружение незакрепленных зависимостей в конфигурациях сервера MCP.
- Аудит того, какие серверы MCP регистрирует проект и находятся ли они в утвержденном списке.
— Проверка использования переменных среды по сравнению с жестко запрограммированными учетными данными в конфигурациях MCP.
- Любой запрос типа «безопасна ли моя конфигурация MCP?», «проверить мои серверы MCP» или «проверить .mcp.json».
ключевые слова: [mcp, безопасность, аудит, секреты, внедрение оболочки, цепочка поставок, управление]
