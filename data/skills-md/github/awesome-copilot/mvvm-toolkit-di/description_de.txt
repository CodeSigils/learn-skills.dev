Vernetzen Sie CommunityToolkit.Mvvm ViewModels mit Microsoft.Extensions.DependencyInjection. Behandelt den .NET Generic Host-Kompositionsstamm, die Konstruktorinjektion, die Dienstlebensdauer (Singleton/Transient/Scoped), die IMessenger-Registrierung, das Auflösen von ViewModels in Ansichten, verschlüsselte Dienste, das Testen von Nähten und die alte Ioc.Default-Escape-Schraffur. Verwendung in WPF, WinUI 3, .NET MAUI, Uno und Avalonia.
