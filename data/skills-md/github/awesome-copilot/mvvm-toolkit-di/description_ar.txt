قم بتوصيل CommunityToolkit.Mvvm ViewModels إلى Microsoft.Extensions.DependencyInjection. يغطي جذر تكوين مضيف .NET العام، وحقن المُنشئ، وعمر الخدمة (Singleton / Transient / Scoped)، وتسجيل IMessenger، وحل ViewModels في طرق العرض، والخدمات ذات المفاتيح، وطبقات الاختبار، وفتحة الهروب Ioc.Default القديمة. استخدم عبر WPF، وWinUI 3، و.NET MAUI، وUno، وAvalonia.
