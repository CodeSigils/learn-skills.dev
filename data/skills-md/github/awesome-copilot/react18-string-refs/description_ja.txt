React 文字列参照 (ref="name" + this.refs.name) からクラス コンポーネントの React.createRef() への正確な移行パターンを提供します。単一要素の ref、コンポーネント内の複数の ref、リスト内の ref、コールバック ref、子コンポーネントに渡される ref など、文字列 ref の使用法を移行する場合は常にこのスキルを使用します。参照移行コードを記述する前に必ずこのスキルを使用してください。リスト内の複数の参照パターンは特に注意が必要であり、このスキルは最も一般的な間違いを防ぎます。 React 18.3.1 の移行 (文字列参照の警告) および React 19 の移行 (文字列参照の削除) に使用します。
