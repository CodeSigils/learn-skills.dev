يوفر أنماط ترحيل دقيقة لمراجع سلسلة React (ref="name" + this.refs.name) إلى React.createRef() في مكونات الفئة. استخدم هذه المهارة عند ترحيل استخدام مرجع السلسلة - بما في ذلك مراجع العنصر الواحد، والمراجع المتعددة في المكون، والمراجع في القوائم، ومراجع رد الاتصال، والمراجع التي تم تمريرها إلى المكونات الفرعية. استخدم هذه المهارة دائمًا قبل كتابة أي كود ترحيل للمرجع - يعد نمط المراجع المتعددة في القائمة أمرًا صعبًا بشكل خاص وتمنع هذه المهارة الأخطاء الأكثر شيوعًا. استخدمه لترحيل React 18.3.1 (تحذير من مراجع السلسلة) وترحيل React 19 (تمت إزالة مراجع السلسلة).
