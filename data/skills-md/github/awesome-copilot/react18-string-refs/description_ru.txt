Предоставляет точные шаблоны миграции для ссылок на строки React (ref="name" + this.refs.name) в React.createRef() в компонентах класса. Используйте этот навык при переносе использования строковых ссылок, включая ссылки на один элемент, несколько ссылок в компоненте, ссылки в списках, ссылки обратного вызова и ссылки, передаваемые дочерним компонентам. Всегда используйте этот навык перед написанием любого кода миграции ссылок — шаблон с несколькими ссылками в списке особенно сложен, и этот навык предотвращает наиболее распространенные ошибки. Используйте его для миграции React 18.3.1 (ссылки на строки предупреждают) и миграции React 19 (ссылки на строки удалены).
