Stellt genaue Migrationsmuster für React-String-Refs (ref="name" + this.refs.name) zu React.createRef() in Klassenkomponenten bereit. Verwenden Sie diesen Skill immer dann, wenn Sie die Verwendung von String-Referenzen migrieren – einschließlich einzelner Element-Referenzen, mehrerer Referenzen in einer Komponente, Referenzen in Listen, Rückruf-Referenzen und an untergeordnete Komponenten übergebene Referenzen. Verwenden Sie diese Fähigkeit immer, bevor Sie einen Ref-Migrationscode schreiben – das Muster mit mehreren Referenzen in einer Liste ist besonders knifflig und diese Fähigkeit verhindert die häufigsten Fehler. Verwenden Sie es für die Migration von React 18.3.1 (Warnung zu String-Referenzen) und zur Migration von React 19 (String-Refs entfernt).
