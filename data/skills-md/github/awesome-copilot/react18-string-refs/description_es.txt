Proporciona patrones de migración exactos para las referencias de cadena de React (ref="nombre" + this.refs.name) a React.createRef() en los componentes de la clase. Utilice esta habilidad siempre que migre el uso de referencias de cadena, incluidas referencias de un solo elemento, referencias múltiples en un componente, referencias en listas, referencias de devolución de llamada y referencias pasadas a componentes secundarios. Utilice siempre esta habilidad antes de escribir cualquier código de migración de referencias: el patrón de múltiples referencias en la lista es particularmente complicado y esta habilidad evita los errores más comunes. Úselo para la migración de React 18.3.1 (advierten las referencias de cadena) y la migración de React 19 (se eliminan las referencias de cadena).
