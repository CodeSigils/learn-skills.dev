Fournit des modèles de migration exacts pour les références de chaîne React (ref="name" + this.refs.name) vers React.createRef() dans les composants de classe. Utilisez cette compétence lors de la migration de l'utilisation des références de chaîne, y compris les références à un seul élément, plusieurs références dans un composant, les références dans les listes, les références de rappel et les références transmises aux composants enfants. Utilisez toujours cette compétence avant d'écrire un code de migration de référence - le modèle de références multiples dans la liste est particulièrement délicat et cette compétence évite les erreurs les plus courantes. Utilisez-le pour la migration React 18.3.1 (avertissement des références de chaîne) et la migration React 19 (références de chaîne supprimées).
