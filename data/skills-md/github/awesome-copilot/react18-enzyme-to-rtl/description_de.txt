Bietet genaue Enzyme → React Testing Library-Migrationsmuster für React 18-Upgrades. Verwenden Sie diese Fähigkeit immer dann, wenn Enzyme-Tests neu geschrieben werden müssen – seichte, mount, wrapper.find(), wrapper.simulate(), wrapper.prop(), wrapper.state(), wrapper.instance(), Enzyme configure/Adapter-Aufrufe oder jede Testdatei, die aus Enzym importiert wird. Diese Fähigkeit deckt die vollständige API-Zuordnung und den Philosophiewechsel vom Implementierungstest zum Verhaltenstest ab. Lesen Sie diesen Skill immer, bevor Sie Enzymtests neu schreiben. Übersetzen Sie Enzym-APIs nicht 1:1, da dies zu brüchigen RTL-Tests führt.
