Fornisce modelli esatti di migrazione della libreria Enzyme → React Testing per gli aggiornamenti di React 18. Utilizza questa abilità ogni volta che i test dell'enzima devono essere riscritti: superficiale, mount, wrapper.find(), wrapper.simulate(), wrapper.prop(), wrapper.state(), wrapper.instance(), chiamate Enzyme configure/Adapter o qualsiasi file di test importato dall'enzima. Questa competenza copre la mappatura completa delle API e il passaggio della filosofia dal test di implementazione al test del comportamento. Leggi sempre questa competenza prima di riscrivere i test degli enzimi: non tradurre le API degli enzimi 1:1, che producono test RTL fragili.
