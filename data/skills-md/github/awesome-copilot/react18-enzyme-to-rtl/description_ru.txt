Предоставляет точные шаблоны миграции библиотеки тестирования Enzyme → React для обновлений React 18. Используйте этот навык всякий раз, когда необходимо переписать тесты Enzyme - неглубокие, монтирование, Wrapper.find(), Wrapper.simulate(), Wrapper.prop(), Wrapper.state(), Wrapper.instance(), вызовы конфигурации/адаптера Enzyme или любой тестовый файл, который импортируется из фермента. Этот навык охватывает полное сопоставление API и переход философии от тестирования реализации к тестированию поведения. Всегда читайте этот навык перед переписыванием тестов Enzyme — не переводите API-интерфейсы Enzyme 1:1, что приводит к нестабильным тестам RTL.
