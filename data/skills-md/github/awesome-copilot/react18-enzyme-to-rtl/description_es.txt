Proporciona patrones exactos de migración de Enzyme → React Testing Library para las actualizaciones de React 18. Utilice esta habilidad siempre que sea necesario reescribir las pruebas de Enzyme: superficial, montaje, wrapper.find(), wrapper.simulate(), wrapper.prop(), wrapper.state(), wrapper.instance(), llamadas de configuración/adaptador de Enzyme o cualquier archivo de prueba que importe desde enzima. Esta habilidad cubre el mapeo completo de API y el cambio de filosofía de las pruebas de implementación a las pruebas de comportamiento. Lea siempre esta habilidad antes de reescribir las pruebas de Enzyme; no traduzca las API de Enzyme 1:1, ya que produce pruebas RTL frágiles.
