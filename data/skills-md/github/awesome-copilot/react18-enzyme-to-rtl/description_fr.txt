Fournit des modèles de migration exacts Enzyme → React Testing Library pour les mises à niveau de React 18. Utilisez cette compétence chaque fois que les tests enzymatiques doivent être réécrits : peu profond, mount, wrapper.find(), wrapper.simulate(), wrapper.prop(), wrapper.state(), wrapper.instance(), Enzyme configure/Adapter, ou tout fichier de test importé depuis l'enzyme. Cette compétence couvre le mappage complet de l'API et le passage de la philosophie des tests d'implémentation aux tests de comportement. Lisez toujours cette compétence avant de réécrire les tests enzymatiques - ne traduisez pas les API Enzyme 1:1, qui produisent des tests RTL fragiles.
