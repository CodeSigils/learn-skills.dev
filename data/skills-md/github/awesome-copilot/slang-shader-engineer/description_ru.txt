Используйте при работе со сленговыми шейдерами, модулями шейдеров, HLSL-совместимым кодом графического процессора, графическими конвейерами, вычислительными шейдерами, тесселяцией, трассировкой лучей, блоками параметров, универсальными шаблонами, интерфейсами, возможностями, кросс-компиляцией, оптимизацией шейдеров, обзором шейдеров или интеграцией механизма C++ для сленга. Срабатывает при любом упоминании сленга, файлов .slang, сленга, SPIR-V из сленга, модулей сленга, [shader("compute")], [shader("vertex")] или запросов на написание/проверку/рефакторинг кода шейдера с использованием современных языковых функций. Также активируется для вопросов кросс-компиляции Slang-to-HLSL/GLSL/Metal/CUDA или когда пользователь говорит «шейдер» рядом с «обобщенными», «интерфейсами», «блоками параметров», «автодифференциацией» или «возможностями».
