Tour de incorporación interactivo para el servidor MCP contextual. Guía al usuario a través de lo que hace el servidor, muestra todas las API disponibles, le permite elegir una para explorar, lo explica en el lenguaje de su proyecto, demuestra model_search y endpoint_search en vivo y finaliza con un menú de cosas que el usuario puede pedirle al agente que haga. UTILIZAR PARA: configuración por primera vez; "¿Qué puede hacer este MCP?"; "muéstrame las API disponibles"; "a bordo de mí"; "¿Cómo uso el servidor contextual?"; "dame un recorrido". NO UTILIZAR PARA: integrar una API de extremo a extremo (use integrar-context-matic en su lugar).
