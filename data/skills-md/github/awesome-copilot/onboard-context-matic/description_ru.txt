Интерактивный ознакомительный тур по контекстному серверу MCP. Показывает пользователю, что делает сервер, показывает все доступные API, позволяет им выбрать один для изучения, объясняет его на языке своего проекта, демонстрирует в реальном времени model_search и endpoint_search и завершается меню действий, которые пользователь может попросить агента сделать. ИСПОЛЬЗОВАНИЕ ДЛЯ: первоначальная настройка; «что может этот MCP?»; "покажи мне доступные API"; «на борту меня»; «как мне использовать контекстный сервер»; «проведи мне экскурсию». НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: фактической сквозной интеграции API (вместо этого используйте Integrated-context-matic).
