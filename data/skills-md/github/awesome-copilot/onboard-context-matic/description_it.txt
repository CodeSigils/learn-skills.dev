Tour onboarding interattivo per il server MCP contestuale. Guida l'utente attraverso ciò che fa il server, mostra tutte le API disponibili, gli consente di sceglierne una da esplorare, lo spiega nella lingua del progetto, dimostra model_search ed endpoint_search dal vivo e termina con un menu di cose che l'utente può chiedere all'agente di fare. UTILIZZARE PER: prima configurazione; "cosa può fare questo MCP?"; "mostrami le API disponibili"; "a bordo di me"; "come utilizzo il server contestuale"; "fammi un giro". NON UTILIZZARE PER: integrare effettivamente un'API end-to-end (utilizzare invece integral-context-matic).
