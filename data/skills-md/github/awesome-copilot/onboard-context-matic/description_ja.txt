コンテキストマティック MCP サーバーのインタラクティブなオンボーディング ツアー。サーバーの動作をユーザーに説明し、利用可能なすべての API を表示し、探索する API を選択させ、プロジェクト言語で説明し、model_search と endpoint_search をライブでデモンストレーションし、ユーザーがエージェントに実行を依頼できる内容のメニューで終了します。用途: 初回セットアップ。 「この MCP は何ができるのですか?」; 「利用可能な API を表示」; 「私に乗って」; "コンテキストマティックサーバーの使用方法"; 「ツアーをお願いします」。 FOR は使用しないでください。実際に API をエンドツーエンドで統合します (代わりに、integrate-context-matic を使用します)。
