Visite d'intégration interactive pour le serveur MCP contextuel. Guide l'utilisateur à travers ce que fait le serveur, affiche toutes les API disponibles, lui permet d'en choisir une à explorer, l'explique dans la langue de son projet, démontre model_search et endpoint_search en direct et se termine par un menu de choses que l'utilisateur peut demander à l'agent de faire. UTILISER POUR : première installation ; « que peut faire ce MCP ? » ; "montre-moi les API disponibles" ; « à bord de moi » ; "comment utiliser le serveur contextuel"; "faites-moi visiter". NE PAS UTILISER POUR : intégrer réellement une API de bout en bout (utilisez plutôt Integra-Context-matic).
