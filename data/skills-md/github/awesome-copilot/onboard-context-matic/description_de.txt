Interaktive Onboarding-Tour für den kontextmatischen MCP-Server. Führt den Benutzer durch die Aufgaben des Servers, zeigt alle verfügbaren APIs an, lässt ihn eine zum Erkunden auswählen, erklärt sie in seiner Projektsprache, demonstriert model_search und endpoint_search live und endet mit einem Menü mit Dingen, die der Benutzer vom Agenten verlangen kann. VERWENDUNG FÜR: Ersteinrichtung; „Was kann dieser MCP?“; „Zeige mir die verfügbaren APIs“; „an Bord von mir“; „Wie verwende ich den kontextmatischen Server“; „Geben Sie mir eine Tour“. NICHT VERWENDEN FÜR: die tatsächliche End-to-End-Integration einer API (verwenden Sie stattdessen „integrate-context-matic“).
