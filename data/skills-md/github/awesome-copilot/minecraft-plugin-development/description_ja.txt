このスキルは、Paper、Spigot、または Bukkit 用の Minecraft サーバー プラグインを構築または変更するときに使用します。これには、plugin.yml セットアップ、コマンド、リスナー、スケジューラー、プレーヤーの状態、チームまたはアリーナ システム、永続的な進行状況、エコノミーまたはプロファイル データ、構成ファイル、アドベンチャー テキスト、およびバージョンセーフな API の使用が含まれます。 「Minecraft プラグインの構築」、「Paper コマンドの追加」、「Bukkit リスナーの修正」、「plugin.yml の作成」、「ミニゲーム メカニックの実装」、「パークまたはクエスト システムの追加」、または「サーバー プラグインの動作のデバッグ」などのリクエストをトリガーします。
