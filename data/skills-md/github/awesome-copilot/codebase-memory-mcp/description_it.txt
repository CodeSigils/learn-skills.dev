Da utilizzare durante l'esplorazione di codice sconosciuto, la mappatura dell'architettura, la ricerca di simboli o relazioni, il tracciamento di chiamanti, chiamati, flussi di dati o dipendenze, la valutazione dell'impatto, il controllo di codice morto o complesso o la gestione di richieste esplicite di memoria Codebase. Altrimenti salta le attività limitate a un file noto fornito, un piccolo controllo di un file, un valore letterale esatto, un valore di configurazione, una stringa di errore o un testo non di codice.
