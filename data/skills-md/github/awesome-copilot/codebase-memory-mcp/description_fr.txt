À utiliser pour explorer du code inconnu, cartographier l'architecture, rechercher des symboles ou des relations, rechercher des appelants, des appelés, des flux de données ou des dépendances, évaluer l'impact, auditer du code mort ou complexe ou gérer des requêtes explicites de mémoire de base de code. Sinon, ignorez les tâches confinées à un fichier connu fourni, une petite vérification d'un fichier, un littéral exact, une valeur de configuration, une chaîne d'erreur ou un texte non codé.
