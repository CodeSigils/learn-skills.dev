Verwenden Sie diese Funktion, wenn Sie unbekannten Code untersuchen, Architekturen zuordnen, Symbole oder Beziehungen finden, Aufrufer, Aufgerufene, Datenflüsse oder Abhängigkeiten verfolgen, Auswirkungen bewerten, toten oder komplexen Code prüfen oder explizite Codebase-Speicheranforderungen bearbeiten. Andernfalls überspringen Sie Aufgaben, die auf eine bereitgestellte bekannte Datei, eine kleine Einzeldateiprüfung, ein genaues Literal, einen Konfigurationswert, eine Fehlerzeichenfolge oder einen Nicht-Code-Text beschränkt sind.
