Úselo al explorar código desconocido, mapear arquitectura, encontrar símbolos o relaciones, rastrear personas que llaman, destinatarios, flujo de datos o dependencias, evaluar el impacto, auditar código inactivo o complejo o manejar solicitudes explícitas de memoria de base de código. De lo contrario, omita tareas limitadas a un archivo conocido proporcionado, una pequeña verificación de un archivo, un literal exacto, un valor de configuración, una cadena de error o un texto sin código.
