مهارة ملف دفعي Windows على مستوى الخبراء (.bat/.cmd) لكتابة البرامج النصية لـ CMD وتصحيح الأخطاء وصيانتها. استخدمه عندما يُطلب منك "إنشاء ملف دفعي"، أو "كتابة برنامج نصي بتنسيق ‎.bat"، أو "أتمتة مهمة Windows"، أو "البرمجة النصية لـ CMD"، أو "أتمتة الدفعات"، أو "برنامج نصي للمهمة المجدولة"، أو "برنامج نصي لـ Windows shell"، أو عند العمل باستخدام ملفات ‎.bat/.cmd في مساحة العمل. يغطي بناء جملة cmd.exe، ومتغيرات البيئة، وتدفق التحكم، ومعالجة السلسلة، ومعالجة الأخطاء، والتكامل مع أدوات النظام.
