Windows-Batchdatei-Kenntnisse (.bat/.cmd) auf Expertenniveau zum Schreiben, Debuggen und Verwalten von CMD-Skripten. Verwenden Sie diese Option, wenn Sie aufgefordert werden, „eine Batchdatei zu erstellen“, „ein .bat-Skript zu schreiben“, „eine Windows-Aufgabe zu automatisieren“, „CMD-Skripterstellung“, „Stapelautomatisierung“, „geplantes Aufgabenskript“, „Windows-Shell-Skript“ oder wenn Sie mit .bat-/.cmd-Dateien im Arbeitsbereich arbeiten. Behandelt die Syntax von cmd.exe, Umgebungsvariablen, Kontrollfluss, Zeichenfolgenverarbeitung, Fehlerbehandlung und Integration mit Systemtools.
