Compétence de niveau expert en matière de fichiers batch Windows (.bat/.cmd) pour l'écriture, le débogage et la maintenance de scripts CMD. À utiliser lorsqu'on vous demande de « créer un fichier batch », « écrire un script .bat », « automatiser une tâche Windows », « scripts CMD », « automatisation par lots », « script de tâche planifiée », « script shell Windows » ou lorsque vous travaillez avec des fichiers .bat/.cmd dans l'espace de travail. Couvre la syntaxe cmd.exe, les variables d'environnement, le flux de contrôle, le traitement des chaînes, la gestion des erreurs et l'intégration avec les outils système.
