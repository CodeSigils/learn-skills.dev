Проверьте целостность цепочки поставок плагинов, инструментов и зависимостей агента ИИ. Используйте этот навык, когда:
- Создание манифестов целостности SHA-256 для плагинов агентов или пакетов инструментов.
- Проверка соответствия установленных плагинов опубликованным манифестам.
- Обнаружение подделанных, измененных или неотслеживаемых файлов в каталогах инструментов агента.
- Аудит закрепления зависимостей и политик версий для компонентов агента.
- Построение цепочек происхождения для продвижения плагинов агентов (разработка → постановка → производство)
- Любой запрос типа «проверить целостность плагина», «создать манифест», «проверить цепочку поставок» или «подписать этот плагин».
