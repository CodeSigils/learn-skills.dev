Überprüfen Sie die Integrität der Lieferkette für Plugins, Tools und Abhängigkeiten von KI-Agenten. Verwenden Sie diese Fähigkeit, wenn:
- Generieren von SHA-256-Integritätsmanifesten für Agent-Plugins oder Tool-Pakete
– Überprüfen, ob installierte Plugins mit ihren veröffentlichten Manifesten übereinstimmen
– Erkennung manipulierter, geänderter oder nicht verfolgter Dateien in Agent-Tool-Verzeichnissen
– Überwachung der Abhängigkeits-Pinning- und Versionsrichtlinien für Agent-Komponenten
- Aufbau von Herkunftsketten für die Agent-Plugin-Werbung (Entwickler → Staging → Produktion)
- Jede Anfrage wie „Plugin-Integrität überprüfen“, „Manifest erstellen“, „Lieferkette prüfen“ oder „Dieses Plugin signieren“
