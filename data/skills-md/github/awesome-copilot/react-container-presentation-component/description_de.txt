Erstellen Sie eine React-Komponente mithilfe des Container-/Präsentationsmusters in src/components, indem Sie nach dem Komponentennamen und -typ (UI oder Features) fragen, und erstellen Sie dann ein Gerüst für Dateien, die den TypeScript-, Storybook- und SCSS-Konventionen dieses Repositorys entsprechen. Wird verwendet, wenn der Benutzer explizit nach einer Container-/Präsentationsbasierten Komponente fragt oder /react-container-presentation-component ausführt.
