Créez un composant React à l'aide du modèle Conteneur/Présentation dans src/components en demandant le nom et le type du composant (interface utilisateur ou fonctionnalités), puis échafaudez des fichiers qui suivent les conventions TypeScript, Storybook et SCSS de ce référentiel. À utiliser lorsque l'utilisateur demande explicitement un composant basé sur Container/Presentation ou exécute /react-container-presentation-component.
