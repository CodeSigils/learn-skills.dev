Cree un componente de React usando el patrón Contenedor/Presentación en src/components solicitando el nombre y el tipo del componente (ui o características), luego cree archivos que sigan las convenciones TypeScript, Storybook y SCSS de este repositorio. Úselo cuando el usuario solicita explícitamente un componente basado en contenedor/presentación o ejecuta /react-container-presentation-component.
