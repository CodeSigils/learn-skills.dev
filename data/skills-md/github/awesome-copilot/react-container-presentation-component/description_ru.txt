Создайте компонент React, используя шаблон «Контейнер/Презентация» в src/comComponents, запросив имя и тип компонента (пользовательский интерфейс или функции), а затем создайте файлы, соответствующие соглашениям TypeScript, Storybook и SCSS этого репозитория. Используйте, когда пользователь явно запрашивает компонент на основе контейнера/презентации или запускает /реагировать-контейнер-презентационный-компонент.
