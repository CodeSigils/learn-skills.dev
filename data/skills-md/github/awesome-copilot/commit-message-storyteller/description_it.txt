Analizza le differenze git o le modifiche graduali e genera messaggi di commit narrativi che spiegano PERCHÉ è stata apportata una modifica, non solo cosa è cambiato, seguendo il formato Commit convenzionale. Da utilizzare quando viene chiesto di "scrivere un messaggio di commit", "generare un commit", "descrivere le mie modifiche", "come dovrei commettere questo", "commettere questo", "riepilogare le mie differenze" o "aiutarmi a commettere". Funziona con output git diff, file in stage o semplici descrizioni delle modifiche.
