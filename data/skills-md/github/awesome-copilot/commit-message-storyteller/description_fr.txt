Analyse les différences git ou les modifications mises en scène et génère des messages de validation narratifs qui expliquent POURQUOI une modification a été effectuée, et pas seulement ce qui a changé – en suivant le format de validation conventionnel. À utiliser lorsqu'on vous demande « d'écrire un message de validation », « générer une validation », « décrire mes modifications », « sous quoi dois-je valider ceci », « valider ceci », « résumer ma différence » ou « m'aider à valider ». Fonctionne avec la sortie git diff, les fichiers préparés ou les descriptions simples des modifications.
