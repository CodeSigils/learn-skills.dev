Анализирует различия git или поэтапные изменения и генерирует описательные сообщения о фиксации, которые объясняют, ПОЧЕМУ было сделано изменение, а не только то, что изменилось — в соответствии с форматом обычных коммитов. Используйте, когда вас просят «написать сообщение о коммите», «сгенерировать коммит», «описать мои изменения», «как мне это закоммитить», «закоммитить это», «подвести итоги по моим различиям» или «помочь мне сделать коммит». Работает с выводом git diff, промежуточными файлами или простыми описаниями изменений.
