Pubblica presentazioni e contenuti Web su GitHub Pages. Converte PPTX, PDF, HTML o Presentazioni Google in un URL di pagine GitHub live. Gestisce la creazione di repository, la conversione di file, l'abilitazione delle pagine e restituisce l'URL live. Da utilizzare quando l'utente desidera pubblicare, distribuire o condividere una presentazione o un file HTML tramite GitHub Pages.
