Installa i pacchetti npm in un ambiente sandbox Docker. Utilizza questa competenza ogni volta che devi installare, reinstallare o aggiornare node_modules all'interno di un contenitore in cui lo spazio di lavoro è montato tramite virtiofs. I binari nativi (esbuild, lightningcss, rollup) si bloccano su virtiofs, quindi i pacchetti devono essere installati sul filesystem ext4 locale e collegati tramite collegamento simbolico.
