Установите пакеты npm в изолированной среде Docker. Используйте этот навык всякий раз, когда вам нужно установить, переустановить или обновить node_modules внутри контейнера, в котором рабочая область смонтирована через virtiofs. Собственные двоичные файлы (esbuild, Lightningcss, Rollup) аварийно завершают работу на Virtiofs, поэтому пакеты необходимо устанавливать в локальную файловую систему ext4 и возвращать их символическими ссылками.
