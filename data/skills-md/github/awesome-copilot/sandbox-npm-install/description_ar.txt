قم بتثبيت حزم npm في بيئة وضع الحماية Docker. استخدم هذه المهارة عندما تحتاج إلى تثبيت وحدات العقدة أو إعادة تثبيتها أو تحديثها داخل حاوية حيث تم تركيب مساحة العمل عبر أدوات virtiofs. تتعطل الثنائيات الأصلية (esbuild، وlightningcss، وrollup) في برامج virtiofs، لذا يجب تثبيت الحزم على نظام ملفات ext4 المحلي وربطها مرة أخرى.
