Instale paquetes npm en un entorno sandbox de Docker. Utilice esta habilidad siempre que necesite instalar, reinstalar o actualizar node_modules dentro de un contenedor donde el espacio de trabajo está montado mediante virtiofs. Los binarios nativos (esbuild, lightningcss, rollup) fallan en virtiofs, por lo que los paquetes deben instalarse en el sistema de archivos ext4 local y vincularse nuevamente.
