Installez les packages npm dans un environnement sandbox Docker. Utilisez cette compétence chaque fois que vous devez installer, réinstaller ou mettre à jour node_modules dans un conteneur où l'espace de travail est monté via virtiofs. Les binaires natifs (esbuild, Lightningcss, rollup) plantent sur virtiofs, les packages doivent donc être installés sur le système de fichiers ext4 local et liés par un lien symbolique.
