Installieren Sie npm-Pakete in einer Docker-Sandbox-Umgebung. Verwenden Sie diesen Skill immer dann, wenn Sie node_modules in einem Container installieren, neu installieren oder aktualisieren müssen, in dem der Arbeitsbereich über Virtiofs gemountet ist. Native Binärdateien (esbuild, lightningcss, rollup) stürzen auf Virtiofs ab, daher müssen Pakete auf dem lokalen ext4-Dateisystem installiert und wieder mit einem Symlink verknüpft werden.
