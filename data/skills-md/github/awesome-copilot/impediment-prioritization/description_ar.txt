يصنف أي قائمة من العوائق والتدابير المضادة لها باستخدام نموذج تسجيل تدفق القيمة (عائد الاستثمار، تكلفة التنفيذ، سهولة النشر، عامل المخاطرة) وصيغة تحديد الأولويات الثابتة. يُستخدم عندما يطلب شخص ما تحديد الأولويات أو التصنيف أو التسلسل أو الفرز للعوائق أو التدابير المضادة أو عناصر العلاج أو المخاطر أو النتائج أو الفجوات أو عناصر الإجراء أو الإدخالات المتراكمة؛ أو يذكر أولويات تدفق القيمة، أو تصنيف A3 / التدابير المضادة الهزيلة، أو تسجيل عائد الاستثمار مقابل الجهد، أو إنشاء تراكم للمعالجة/التحسين. يعمل مع نتائج GHQR، أو نتائج التدقيق، أو عناصر الإجراءات بأثر رجعي، أو سجلات المخاطر، أو فجوات مراجعة البنية، أو أي قائمة `{عوائق، تدابير مضادة}' ذات شكل حر.
