Análisis completo del modelo de amenazas STRIDE-A y habilidad de actualización incremental para repositorios y sistemas. Admite dos modos: (1) Análisis único: modelo completo de amenazas STRIDE-A de un repositorio, que produce descripciones generales de la arquitectura, diagramas DFD, análisis STRIDE-A, hallazgos priorizados y evaluaciones ejecutivas. (2) Análisis incremental: toma un informe de modelo de amenazas anterior como punto de referencia, compara el código base a más tardar (o una confirmación determinada) y produce un informe actualizado con seguimiento de cambios (amenazas nuevas, resueltas y aún presentes), mapa de calor STRIDE, diferencias de hallazgos y una comparación HTML integrada. Solo se activa cuando el usuario solicita explícitamente un análisis del modelo de amenazas, una actualización incremental o invoca /threat-model-analyst directamente.
