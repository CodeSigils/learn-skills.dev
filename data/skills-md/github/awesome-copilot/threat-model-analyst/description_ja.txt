完全な STRIDE - リポジトリとシステムの脅威モデル分析および増分更新スキル。 2 つのモードをサポートします: (1) 単一分析 — リポジトリの完全な STRIDE-A 脅威モデル。アーキテクチャの概要、DFD 図、STRIDE-A 分析、優先順位付けされた調査結果、およびエグゼクティブ評価を生成します。 (2) 増分分析 — 以前の脅威モデル レポートをベースラインとして取得し、最新 (または特定のコミット) のコードベースを比較し、変更追跡 (新規、解決済み、まだ存在する脅威)、STRIDE ヒートマップ、検出結果の差分、および埋め込み HTML 比較を含む更新レポートを生成します。ユーザーが脅威モデル分析、増分更新を明示的に要求した場合、または /threat-model-analyst を直接呼び出した場合にのみアクティブ化します。
