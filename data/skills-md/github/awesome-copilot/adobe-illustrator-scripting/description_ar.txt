كتابة البرامج النصية لأتمتة Adobe Illustrator وتصحيح أخطائها وتحسينها باستخدام ExtendScript (JavaScript/JSX). يُستخدم عند إنشاء أو تعديل البرامج النصية التي تعالج المستندات أو الطبقات أو المسارات أو إطارات النص أو الألوان أو الرموز أو لوحات الرسم أو أي كائنات Illustrator DOM. يغطي نموذج كائن JavaScript الكامل ونظام الإحداثيات ووحدات القياس وسير عمل التصدير وأفضل ممارسات البرمجة النصية.
