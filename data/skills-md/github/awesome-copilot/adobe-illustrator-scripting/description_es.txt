Escriba, depure y optimice scripts de automatización de Adobe Illustrator utilizando ExtendScript (JavaScript/JSX). Utilícelo al crear o modificar scripts que manipulen documentos, capas, trazados, marcos de texto, colores, símbolos, mesas de trabajo o cualquier objeto DOM de Illustrator. Cubre el modelo completo de objetos de JavaScript, el sistema de coordenadas, las unidades de medida, los flujos de trabajo de exportación y las mejores prácticas de secuencias de comandos.
