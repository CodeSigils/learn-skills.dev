Scrivi, esegui il debug e ottimizza gli script di automazione di Adobe Illustrator utilizzando ExtendScript (JavaScript/JSX). Da utilizzare durante la creazione o la modifica di script che manipolano documenti, livelli, tracciati, cornici di testo, colori, simboli, tavole da disegno o qualsiasi oggetto DOM di Illustrator. Copre il modello a oggetti JavaScript completo, il sistema di coordinate, le unità di misura, i flussi di lavoro di esportazione e le migliori pratiche di scripting.
