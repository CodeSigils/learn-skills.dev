「私が何をしたの？」と曖昧になってしまいます。パフォーマンスレビュー、セルフレビュー、プロモーションパケット、毎週の更新などの証拠に裏付けられた影響ステートメントを作成します。 Copilot CLI セッション ログを独自にマイニングして、忘れられた作業に加えて、git コミットと GitHub PR を再構築します。 3 つの部分からなる影響契約 (アクション → 結果 → 証拠) を強制します。依存関係なしでスタンドアロンで動作します。トリガー: 「自慢」、「仕事の記録」、「自分が何をしたか」、「職歴の埋め戻し」、「パフォーマンスのレビュー」、「自己レビュー」、「自己評価」、「影響ステートメントの作成」、「準備のレビュー」、「プロモーションパケット」、「プロモーションケース」、「毎週の更新」、「ステータスレポート」、「成果」、「何を出荷したか」、「仕事の記録を忘れた」、「仕事の要約」、「自分の仕事の追跡」 「勝利」、「何を強調すべきか」、「半分の終わり」、「キャリアの成長」、「作業日誌」、または作業の成果を文書化、要約、または整理するためのあらゆる要求。
