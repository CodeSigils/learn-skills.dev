Guide complet pour l'installation et la configuration de l'analyse de code CodeQL via les workflows GitHub Actions et la CLI CodeQL. Cette compétence doit être utilisée lorsque les utilisateurs ont besoin d'aide pour la configuration de l'analyse de code, les fichiers de flux de travail CodeQL, les commandes CLI CodeQL, la sortie SARIF, la configuration de l'analyse de sécurité ou le dépannage de l'analyse CodeQL.
