Créez ou enregistrez une extension de canevas dans le référentiel Awesome-copilot. À utiliser lorsqu'on vous demande d'élaborer une nouvelle extension de canevas, de créer son plugin.json, d'ajouter une extension réutilisable à un ou plusieurs plugins ou de migrer les métadonnées de l'extension. Les extensions sont des sources réutilisables sous extensions/; Les manifestes de plugin livrables appartiennent sous plugins/.
