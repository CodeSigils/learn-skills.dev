Erstellen oder registrieren Sie eine Canvas-Erweiterung im awesome-copilot-Repository. Verwenden Sie diese Option, wenn Sie aufgefordert werden, ein Gerüst für eine neue Canvas-Erweiterung zu erstellen, die Datei „plugin.json“ zu erstellen, eine wiederverwendbare Erweiterung zu einem oder mehreren Plugins hinzuzufügen oder Erweiterungsmetadaten zu migrieren. Erweiterungen sind wiederverwendbare Quellen unter extensions/; Auslieferbare Plugin-Manifeste gehören unter „plugins/“.
