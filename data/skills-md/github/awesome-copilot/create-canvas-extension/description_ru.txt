Создайте или зарегистрируйте расширение холста в репозитории Awesome-copilot. Используйте, когда вас попросят создать новое расширение холста, создать его плагин.json, добавить многократно используемое расширение в один или несколько плагинов или перенести метаданные расширения. Расширения являются многоразовым исходным кодом в Extensions/; Манифесты доступных для поставки плагинов находятся в папке plugins/.
