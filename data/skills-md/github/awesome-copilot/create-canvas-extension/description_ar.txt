قم بإنشاء أو تسجيل امتداد اللوحة القماشية في مستودع Awesome-copilot. يُستخدم عندما يُطلب منك دعم ملحق لوحة رسم جديد، أو إنشاء plugin.json الخاص به، أو إضافة ملحق قابل لإعادة الاستخدام إلى مكون إضافي واحد أو أكثر، أو ترحيل البيانات التعريفية للامتداد. الامتدادات مصدر قابل لإعادة الاستخدام ضمن الامتدادات/; تنتمي بيانات المكونات الإضافية القابلة للشحن إلى plugins/.
