Crea o registra un'estensione canvas nel repository awesome-copilot. Da utilizzare quando viene richiesto di strutturare una nuova estensione Canvas, creare il relativo plugin.json, aggiungere un'estensione riutilizzabile a uno o più plug-in o migrare i metadati dell'estensione. Le estensioni sono sorgenti riutilizzabili in extensions/; i manifest dei plugin spedibili appartengono a plugins/.
