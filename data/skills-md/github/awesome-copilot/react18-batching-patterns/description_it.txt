Fornisce modelli esatti per diagnosticare e correggere le regressioni in batch automatiche nei componenti della classe React 18. Utilizza questa abilità ogni volta che un componente di classe ha più chiamate setState in un metodo asincrono, all'interno di setTimeout, all'interno di Promise .then() o .catch() o in un gestore di eventi nativo. Usalo prima di scrivere qualsiasi chiamata flushSync: l'albero decisionale qui impedisce un uso eccessivo e non necessario di flushSync. Utilizzare questa abilità anche quando si correggono errori di test causati da asserzioni di stato intermedio che si interrompono dopo l'aggiornamento di React 18.
