يوفر أنماطًا دقيقة لتشخيص وإصلاح انحدارات التجميع التلقائي في مكونات فئة React 18. استخدم هذه المهارة عندما يكون لمكون فئة استدعاءات setState متعددة في طريقة غير متزامنة، داخل setTimeout، داخل Promise .then() أو .catch()، أو في معالج حدث أصلي. استخدمه قبل كتابة أي استدعاء لـflushSync - تمنع شجرة القرار هنا الاستخدام الزائد غير الضروري لـflushSync. استخدم هذه المهارة أيضًا عند إصلاح حالات فشل الاختبار الناتجة عن تأكيدات الحالة المتوسطة التي تنقطع بعد ترقية React 18.
