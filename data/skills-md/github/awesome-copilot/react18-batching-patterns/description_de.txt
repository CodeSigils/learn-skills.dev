Bietet genaue Muster zur Diagnose und Behebung automatischer Batch-Regressionen in React 18-Klassenkomponenten. Verwenden Sie diesen Skill immer dann, wenn eine Klassenkomponente mehrere setState-Aufrufe in einer asynchronen Methode, innerhalb von setTimeout, in einem Promise .then() oder .catch() oder in einem nativen Event-Handler hat. Verwenden Sie es, bevor Sie einen FlushSync-Aufruf schreiben. Der Entscheidungsbaum hier verhindert eine unnötige Überbeanspruchung von FlushSync. Verwenden Sie diese Fähigkeit auch, wenn Sie Testfehler beheben, die durch Zwischenzustandszusicherungen verursacht werden, die nach dem React 18-Upgrade nicht mehr funktionieren.
