Proporciona patrones exactos para diagnosticar y corregir regresiones por lotes automáticas en componentes de clase React 18. Utilice esta habilidad siempre que un componente de clase tenga múltiples llamadas setState en un método asíncrono, dentro de setTimeout, dentro de una Promise .then() o .catch(), o en un controlador de eventos nativo. Úselo antes de escribir cualquier llamada de FlushSync: el árbol de decisiones aquí evita el uso excesivo innecesario de FlushSync. Utilice también esta habilidad cuando solucione fallas de prueba causadas por afirmaciones de estado intermedio que se interrumpen después de la actualización de React 18.
