React 18 クラス コンポーネントの自動バッチリグレッションを診断および修正するための正確なパターンを提供します。このスキルは、クラス コンポーネントの非同期メソッド内、setTimeout 内、Promise .then() または .catch() 内、またはネイティブ イベント ハンドラー内で複数の setState 呼び出しがある場合に必ず使用します。これは、flushSync 呼び出しを書き込む前に使用してください。ここでのデシジョン ツリーは、不必要な flashSync の過剰使用を防ぎます。 React 18 アップグレード後に壊れた中間状態アサーションによって引き起こされたテストの失敗を修正する場合にも、このスキルを使用します。
