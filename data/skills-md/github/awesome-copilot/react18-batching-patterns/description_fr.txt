Fournit des modèles exacts pour diagnostiquer et corriger les régressions automatiques par lots dans les composants de classe React 18. Utilisez cette compétence chaque fois qu'un composant de classe a plusieurs appels setState dans une méthode asynchrone, dans setTimeout, dans une Promise .then() ou .catch() ou dans un gestionnaire d'événements natif. Utilisez-le avant d'écrire un appel flushSync - l'arbre de décision ici empêche une utilisation excessive de flushSync. Utilisez également cette compétence lors de la correction des échecs de test causés par des assertions d’état intermédiaire qui s’interrompent après la mise à niveau de React 18.
