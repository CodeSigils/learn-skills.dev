Предоставляет точные шаблоны для диагностики и исправления регрессий автоматического пакетирования в компонентах класса React 18. Используйте этот навык всякий раз, когда компонент класса имеет несколько вызовов setState в асинхронном методе, внутри setTimeout, внутри Promise .then() или .catch() или в собственном обработчике событий. Используйте его перед написанием любого вызова флешсинк — дерево решений здесь предотвращает ненужное чрезмерное использование флешсинк. Также используйте этот навык при исправлении сбоев тестов, вызванных утверждениями промежуточного состояния, которые не работают после обновления React 18.
