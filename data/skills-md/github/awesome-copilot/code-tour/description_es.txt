Utilice esta habilidad para crear archivos CodeTour .tour: tutoriales paso a paso dirigidos a personas que enlazan con archivos reales y números de línea. Activador para: "crear un recorrido", "hacer un recorrido de código", "generar un recorrido", "recorrido de incorporación", "recorrido para este PR", "recorrido para este error", "recorrido por RCA", "recorrido por arquitectura", "explicar cómo funciona X", "verificación de ambiente", "recorrido de revisión de relaciones públicas", "guía de colaborador", "ayudar a alguien a mejorar" o cualquier solicitud de un recorrido estructurado a través del código. Admite 20 personas de desarrollador (nuevo miembro, solucionador de errores, arquitecto, revisor de relaciones públicas, vibecoder, revisor de seguridad y más), todos los tipos de pasos de CodeTour (archivo/línea, selección, patrón, uri, comandos, vista) y campos de nivel de recorrido (ref, isPrimary, nextTour). Funciona con cualquier repositorio en cualquier idioma.
