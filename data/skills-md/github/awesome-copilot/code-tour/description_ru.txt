Используйте этот навык для создания файлов CodeTour .tour — ориентированных на пользователя пошаговых руководств, которые ссылаются на реальные файлы и номера строк. Триггер для: «создать экскурсию», «провести экскурсию по коду», «создать экскурсию», «ознакомительный тур», «экскурсия по этому пиару», «экскурсия по этой ошибке», «экскурсия по RCA», «экскурсия по архитектуре», «объяснить, как работает X», «проверка атмосферы», «экскурсия по PR-обзору», «руководство для участников», «помочь кому-нибудь в работе» или любой запрос на структурированное пошаговое руководство по коду. Поддерживает 20 профилей разработчиков (новый присоединитель, исправление ошибок, архитектор, рецензент по связям с общественностью, вибекодер, рецензент безопасности и т. д.), все типы шагов CodeTour (файл/строка, выбор, шаблон, uri, команды, представление) и поля уровня тура (ref, isPrimary, nextTour). Работает с любым репозиторием на любом языке.
