このスキルを使用して、CodeTour .tour ファイルを作成します。これは、実際のファイルと行番号にリンクする、人物をターゲットにした段階的なチュートリアルです。トリガー: 「ツアーの作成」、「コード ツアーの作成」、「ツアーの生成」、「オンボーディング ツアー」、「この PR のツアー」、「このバグのツアー」、「RCA ツアー」、「アーキテクチャ ツアー」、「X の仕組みの説明」、「雰囲気チェック」、「PR レビュー ツアー」、「寄稿者ガイド」、「誰かの立ち上げを支援」、またはコードによる構造化されたウォークスルーのリクエスト。 20 人の開発者ペルソナ (新規参加者、バグ修正者、アーキテクト、PR レビュー者、バイブコーダ、セキュリティ レビュー者など)、すべての CodeTour ステップ タイプ (ファイル/行、選択、パターン、URI、コマンド、ビュー)、およびツアー レベルのフィールド (ref、isPrimary、nextTour) をサポートします。あらゆる言語のあらゆるリポジトリで動作します。
