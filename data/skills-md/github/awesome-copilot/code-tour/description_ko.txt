이 기술을 사용하여 실제 파일과 줄 번호에 연결되는 개인별 단계별 연습인 CodeTour .tour 파일을 만듭니다. 트리거 대상: "투어 만들기", "코드 투어 만들기", "투어 생성", "온보딩 투어", "이 PR에 대한 투어", "이 버그에 대한 투어", "RCA 투어", "아키텍처 투어", "X 작동 방식 설명", "바이브 확인", "PR 리뷰 투어", "기고자 가이드", "다른 사람의 램프업 지원" 또는 코드를 통해 구조화된 둘러보기에 대한 요청. 20가지 개발자 페르소나(신규 조이너, 버그 수정자, 설계자, PR 검토자, 바이브코더, 보안 검토자 등), 모든 CodeTour 단계 유형(파일/라인, 선택, 패턴, uri, 명령, 보기) 및 투어 수준 필드(ref, isPrimary, nextTour)를 지원합니다. 모든 언어의 모든 저장소에서 작동합니다.
