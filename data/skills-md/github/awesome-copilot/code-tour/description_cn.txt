使用此技能创建 CodeTour .tour 文件 - 链接到真实文件和行号的针对角色的分步演练。触发：“创建游览”、“进行代码游览”、“生成游览”、“入职游览”、“此 PR 游览”、“此 bug 游览”、“RCA 游览”、“架构游览”、“解释 X 的工作原理”、“氛围检查”、“PR 审查游览”、“贡献者指南”、“帮助某人提升”或通过代码进行结构化演练的任何请求。支持 20 个开发人员角色（新加入者、错误修复者、架构师、PR 审阅者、vibecoder、安全审阅者等）、所有 CodeTour 步骤类型（文件/行、选择、模式、uri、命令、视图）和游览级别字段（ref、isPrimary、nextTour）。适用于任何语言的任何存储库。
