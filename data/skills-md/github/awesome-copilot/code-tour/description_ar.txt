استخدم هذه المهارة لإنشاء ملفات CodeTour .tour — وهي إرشادات تفصيلية تستهدف الأشخاص، وترتبط بالملفات الحقيقية وأرقام الأسطر. تشغيل لـ: "إنشاء جولة"، "إنشاء جولة رمزية"، "إنشاء جولة"، "جولة تأهيلية"، "جولة لهذه العلاقات العامة"، "جولة لهذا الخطأ"، "جولة RCA"، "جولة معمارية"، "شرح كيفية عمل X"، "فحص vibe"، "جولة مراجعة العلاقات العامة"، "دليل المساهم"، "مساعدة شخص ما على التكثيف"، أو أي طلب للحصول على إرشادات منظمة عبر التعليمات البرمجية. يدعم 20 شخصية مطور (منضم جديد، ومصلح الأخطاء، ومهندس معماري، ومراجع العلاقات العامة، وvibecoder، ومراجع الأمان، والمزيد)، وجميع أنواع خطوات CodeTour (ملف/خط، واختيار، ونمط، وURI، وأوامر، وعرض)، والحقول على مستوى الجولة (المرجع، isPrimary، nextTour). يعمل مع أي مستودع بأي لغة.
