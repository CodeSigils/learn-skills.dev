Написание и проверка модульных тестов для кодовых баз Vue 3 + TypeScript + Vitest + Pinia. Используйте при создании или обновлении тестов для компонентов, компонуемых объектов и хранилищ; издевательство над Пинией с помощью createTestingPinia; применение шаблонов Vue Test Utils; и применение утверждений «черного ящика» над деталями реализации.
