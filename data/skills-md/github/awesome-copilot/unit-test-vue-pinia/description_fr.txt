Rédigez et révisez des tests unitaires pour les bases de code Vue 3 + TypeScript + Vitest + Pinia. À utiliser lors de la création ou de la mise à jour de tests pour les composants, les composables et les magasins ; se moquer de Pinia avec createTestingPinia ; appliquer les modèles Vue Test Utils ; et appliquer des assertions de boîte noire sur les détails de mise en œuvre.
