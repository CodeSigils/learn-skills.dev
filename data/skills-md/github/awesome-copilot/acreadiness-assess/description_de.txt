Führen Sie die AgentRC-Bereitschaftsbewertung für das aktuelle Repository aus und erstellen Sie ein statisches HTML-Dashboard unter „reports/index.html“. Umschließt „npx github:microsoft/agentrc readiness“ und übergibt das Rendern an den benutzerdefinierten @ai-readiness-reporter-Agenten. Unterstützt Richtlinien (--policy) für organisationsspezifische Bewertung. Verwenden Sie diese Option, wenn Sie aufgefordert werden, die KI-Bereitschaft eines Repos zu bewerten, zu prüfen oder zu bewerten.
