Экспертные навыки написания скриптов, макросов и автоматизации FreeCAD Python. Используйте, когда вас попросят создать модели FreeCAD, параметрические объекты, скрипты Part/Mesh/Sketcher, инструменты рабочего места, диалоговые окна графического интерфейса с PySide, манипулирование графиками сцен Coin3D или любую задачу FreeCAD Python API. Охватывает основы написания сценариев FreeCAD, создание геометрии, объекты FeaturePython, инструменты интерфейса и разработку макросов.
