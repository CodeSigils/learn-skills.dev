Abilità esperta nella scrittura di script, macro e automazione di FreeCAD Python. Utilizzare quando richiesto per creare modelli di FreeCAD, oggetti parametrici, script Part/Mesh/Sketcher, strumenti dell'ambiente di lavoro, finestre di dialogo GUI con PySide, manipolazione di scenegraph Coin3D o qualsiasi attività API Python di FreeCAD. Copre le basi dello scripting di FreeCAD, la creazione di geometrie, gli oggetti FeaturePython, gli strumenti di interfaccia e lo sviluppo di macro.
