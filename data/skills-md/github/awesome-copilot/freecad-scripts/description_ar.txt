مهارة الخبراء في كتابة نصوص FreeCAD Python ووحدات الماكرو والأتمتة. استخدمه عندما يُطلب منك إنشاء نماذج FreeCAD، أو كائنات بارامترية، أو نصوص برمجية لجزء/شبكة/Sketcher، أو أدوات طاولة العمل، أو مربعات حوار واجهة المستخدم الرسومية باستخدام PySide، أو معالجة الرسم البياني Coin3D، أو أي مهمة FreeCAD Python API. يغطي أساسيات البرمجة النصية لـ FreeCAD، وإنشاء الأشكال الهندسية، وكائنات FeaturesPython، وأدوات الواجهة، وتطوير الماكرو.
