مهارة شاملة لبناء واختبار وفحص وإصدار ونشر مكتبة Python على مستوى الإنتاج إلى PyPI. يغطي جميع الواجهات الخلفية الأربعة للبناء (setuptools+setuptools_scm، Hatling، Flit، Poetry)، وإصدارات PEP 440، والإصدارات الدلالية، وإصدارات git-tag الديناميكية، وتصميم OOP/SOLID، وتلميحات النوع (PEP 484/526/544/561)، والنشر الموثوق (OIDC)، وتدفق تعبئة PyPA الكامل. يُستخدم من أجل: إنشاء حزم Python، أو مجموعات SDK قابلة للتثبيت، أو أدوات CLI، أو المكونات الإضافية لإطار العمل، أو إعداد pyproject.toml، أو py.typed، أو setuptools_scm، أو semver، أو mypy، أو الالتزام المسبق، أو GitHub Actions CI/CD، أو نشر PyPI.
