Комплексные навыки создания, тестирования, проверки, управления версиями и публикации библиотеки Python промышленного уровня в PyPI. Охватывает все четыре бэкэнда сборки (setuptools+setuptools_scm, Hatchling, Flit, Piese), управление версиями PEP 440, семантическое управление версиями, динамическое управление версиями git-тегов, проектирование ООП/SOLID, подсказки типов (PEP 484/526/544/561), Trusted Publishing (OIDC) и полный процесс упаковки PyPA. Используется для: создания пакетов Python, устанавливаемых через pip SDK, инструментов CLI, плагинов платформы, настройки pyproject.toml, py.typed, setuptools_scm, semver, mypy, pre-commit, GitHub Actions CI/CD или публикации PyPI.
