Verwendung für: Erstellen von Python-Paketen, pip-installierbaren SDKs, CLI-Tools, Framework-Plugins, pyproject.toml-Setup, py.typed, setuptools_scm, semver, mypy, pre-commit, GitHub Actions CI/CD oder PyPI-Veröffentlichung.
