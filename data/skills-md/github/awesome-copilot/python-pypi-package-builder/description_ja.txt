実稼働グレードの Python ライブラリを構築、テスト、lint、バージョン管理し、PyPI に公開するためのエンドツーエンドのスキル。 4 つのビルド バックエンドすべて (setuptools+setuptools_scm、ハッチリング、フリット、詩)、PEP 440 バージョニング、セマンティック バージョニング、動的 git タグ バージョニング、OOP/SOLID 設計、タイプ ヒント (PEP 484/526/544/561)、信頼できる公開 (OIDC)、および完全な PyPA パッケージ化フローをカバーします。用途: Python パッケージ、pip インストール可能な SDK、CLI ツール、フレームワーク プラグイン、pyproject.toml セットアップ、py.typed、setuptools_scm、semver、mypy、事前コミット、GitHub Actions CI/CD、または PyPI の作成の作成。
