Compétence de bout en bout pour créer, tester, pelucher, gérer les versions et publier une bibliothèque Python de qualité production sur PyPI. Couvre les quatre backends de build (setuptools+setuptools_scm, Hatchling, Flit, Poésie), la gestion des versions PEP 440, la gestion des versions sémantiques, la gestion des versions dynamiques des balises Git, la conception OOP/SOLID, les astuces de type (PEP 484/526/544/561), la publication sécurisée (OIDC) et le flux complet d'empaquetage PyPA. À utiliser pour : la création de packages Python, de SDK installables par pip, d'outils CLI, de plugins de framework, de configuration pyproject.toml, py.typed, setuptools_scm, semver, mypy, pre-commit, GitHub Actions CI/CD ou publication PyPI.
