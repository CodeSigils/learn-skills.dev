Rhinoceros 3D (Rhino 8 以降) のスクリプトの作成とデバッグ。 RhinoScript (VBScript / .rvb / .vbs)、RhinoPython、または RhinoCommon ベースのスクリプトを作成するように求められた場合に使用します。 Rhino モデリングタスクを自動化します。コマンドマクロを構築します。 Rhino のジオメトリ、レイヤー、ブロック、またはドキュメント オブジェクトを操作します。ビューポートからオブジェクトを選択します。再描画と元に戻すを制御します。または、Rhino Script Editor からスクリプトをロードして実行します。 「rhinoscriptsyntax」、「scriptcontext」、「Rhino.*」 RhinoCommon 名前空間 (「Rhino.Geometry」、「Rhino.DocObjects」、「Rhino.Input」、「Rhino.UI」、「Rhino.Display」、「Rhino.FileIO」)、および Rhino 8 統合スクリプト エディターをカバーします。
