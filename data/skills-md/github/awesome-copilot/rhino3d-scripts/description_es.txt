Creación y depuración de scripts para Rhinoceros 3D (Rhino 8 y posteriores). Utilícelo cuando se le solicite escribir scripts basados ​​en RhinoScript (VBScript/.rvb/.vbs), RhinoPython o RhinoCommon; automatizar tareas de modelado de Rhino; crear macros de comando; manipular geometría, capas, bloques u objetos de documentos de Rhino; seleccionar objetos de la ventana gráfica; controlar redibujar y deshacer; o cargar y ejecutar scripts desde Rhino Script Editor. Cubre `rhinoscriptsyntax`, `scriptcontext`, los espacios de nombres RhinoCommon `Rhino.*` (`Rhino.Geometry`, `Rhino.DocObjects`, `Rhino.Input`, `Rhino.UI`, `Rhino.Display`, `Rhino.FileIO`) y el editor de scripts unificado de Rhino 8.
