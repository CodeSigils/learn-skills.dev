为 Rhinoceros 3D（Rhino 8 及更高版本）编写和调试脚本。当要求编写 RhinoScript (VBScript / .rvb / .vbs)、RhinoPython 或基于 RhinoCommon 的脚本时使用；自动化 Rhino 建模任务；构建命令宏；操作 Rhino 几何体、图层、块或文档对象；从视口中选取对象；控制重画和撤消；或者从 Rhino 脚本编辑器加载并运行脚本。涵盖“rhinoscriptsyntax”、“scriptcontext”、“Rhino.*”RhinoCommon 命名空间（“Rhino.Geometry”、“Rhino.DocObjects”、“Rhino.Input”、“Rhino.UI”、“Rhino.Display”、“Rhino.FileIO”）和 Rhino 8 统一脚本编辑器。
