تأليف وتصحيح البرامج النصية لـRhinoceros 3D (Rhino 8 والإصدارات الأحدث). يُستخدم عندما يُطلب منك كتابة RhinoScript (VBScript / .rvb / .vbs)، أو RhinoPython، أو البرامج النصية المستندة إلى RhinoCommon؛ أتمتة مهام نمذجة وحيد القرن؛ بناء وحدات ماكرو الأوامر؛ التعامل مع هندسة وحيد القرن أو الطبقات أو الكتل أو كائنات المستند؛ اختيار الكائنات من إطار العرض؛ التحكم في إعادة الرسم والتراجع؛ أو قم بتحميل البرامج النصية وتشغيلها من Rhino Script Editor. يغطي `rhinoscriptsyntax` و`scriptcontext` و`Rhino.*` مساحات الأسماء RhinoCommon (`Rhino.Geometry` و`Rhino.DocObjects` و`Rhino.Input` و`Rhino.UI` و`Rhino.Display` و`Rhino.FileIO`)، ومحرر البرامج النصية الموحد Rhino 8.
