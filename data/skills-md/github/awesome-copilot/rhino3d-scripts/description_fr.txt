Création et débogage de scripts pour Rhinoceros 3D (Rhino 8 et versions ultérieures). À utiliser lorsqu'on vous demande d'écrire des scripts basés sur RhinoScript (VBScript / .rvb / .vbs), RhinoPython ou RhinoCommon ; automatiser les tâches de modélisation de Rhino ; créer des macros de commandes ; manipuler la géométrie, les calques, les blocs ou les objets de document de Rhino ; choisissez des objets dans la fenêtre ; contrôler le redessinage et l'annulation ; ou chargez et exécutez des scripts à partir de l'éditeur de scripts Rhino. Couvre `rhinoscriptsyntax`, `scriptcontext`, les espaces de noms `Rhino.*` RhinoCommon (`Rhino.Geometry`, `Rhino.DocObjects`, `Rhino.Input`, `Rhino.UI`, `Rhino.Display`, `Rhino.FileIO`) et l'éditeur de script unifié Rhino 8.
