Créez et synchronisez des agents AI basés sur des invites directement dans Azure AI Foundry via l'API REST, à partir d'un manifeste JSON local. Contrairement aux compétences d'échafaudage qui génèrent uniquement du code local, cette compétence enregistre les agents dans le service Foundry lui-même, les rendant immédiatement disponibles pour invocation. À utiliser lorsque l'utilisateur demande à créer des agents dans Foundry, à synchroniser, déployer, enregistrer ou envoyer des agents vers Foundry, à mettre à jour les instructions de l'agent ou à échafauder le manifeste et le script de synchronisation pour un nouveau référentiel. Déclencheurs : « créer un agent dans la fonderie », « synchroniser les agents de fonderie », « déployer des agents dans la fonderie », « enregistrer des agents dans la fonderie », « envoyer des agents », « créer un manifeste d'agent de fonderie », « synchronisation de l'agent d'échafaudage ».
