Crea e sincronizza agenti AI basati su prompt direttamente in Azure AI Foundry tramite API REST, da un manifest JSON locale. A differenza delle competenze di scaffolding che generano solo codice locale, questa competenza registra gli agenti nel servizio Foundry stesso, rendendoli immediatamente disponibili per l'invocazione. Da utilizzare quando l'utente chiede di creare agenti in Foundry, sincronizzare, distribuire, registrare o inviare agenti a Foundry, aggiornare le istruzioni dell'agente o eseguire lo scaffold del manifest e sincronizzare lo script per un nuovo repository.
