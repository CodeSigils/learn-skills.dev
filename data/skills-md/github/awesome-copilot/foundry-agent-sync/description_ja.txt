ローカル JSON マニフェストから、REST API を介して Azure AI Foundry 内でプロンプトベースの AI エージェントを直接作成し、同期します。ローカル コードのみを生成するスキャフォールディング スキルとは異なり、このスキルはエージェントを Foundry サービス自体に登録し、エージェントをすぐに呼び出せるようにします。ユーザーが、Foundry でのエージェントの作成、Foundry へのエージェントの同期、デプロイ、登録、プッシュ、エージェントの指示の更新、または新しいリポジトリのマニフェストと同期スクリプトのスキャフォールディングを要求する場合に使用します。トリガー: 「Foundry でのエージェントの作成」、「Foundry エージェントの同期」、「Foundry へのエージェントのデプロイ」、「Foundry でのエージェントの登録」、「エージェントのプッシュ」、「Foundry エージェント マニフェストの作成」、「スキャフォールド エージェント同期」。
