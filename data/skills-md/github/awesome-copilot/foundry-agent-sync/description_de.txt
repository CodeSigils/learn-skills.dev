Erstellen und synchronisieren Sie aufforderungsbasierte KI-Agenten direkt in Azure AI Foundry über die REST-API aus einem lokalen JSON-Manifest. Im Gegensatz zu Scaffolding-Skills, die nur lokalen Code generieren, registriert dieser Skill Agenten im Foundry-Dienst selbst und macht sie so sofort für den Aufruf verfügbar. Verwenden Sie diese Option, wenn der Benutzer Agenten in Foundry erstellen, Agenten synchronisieren, bereitstellen, registrieren oder an Foundry übertragen, Agentenanweisungen aktualisieren oder das Manifest und das Synchronisierungsskript für ein neues Repository erstellen möchte. Auslöser: „Agent in Foundry erstellen“, „Foundry-Agenten synchronisieren“, „Agenten in Foundry bereitstellen“, „Agenten in Foundry registrieren“, „Agenten pushen“, „Foundry-Agent-Manifest erstellen“, „Scaffold-Agent-Synchronisierung“.
