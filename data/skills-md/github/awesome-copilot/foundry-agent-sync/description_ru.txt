Создавайте и синхронизируйте агенты ИИ на основе подсказок непосредственно в Azure AI Foundry через REST API из локального манифеста JSON. В отличие от навыков создания лесов, которые генерируют только локальный код, этот навык регистрирует агентов в самой службе Foundry, что делает их немедленно доступными для вызова. Используйте, когда пользователь запрашивает создание агентов в Foundry, синхронизацию, развертывание, регистрацию или отправку агентов в Foundry, обновление инструкций агента или создание сценария манифеста и синхронизации для нового репозитория. Триггеры: «создать агента в литейном цехе», «синхронизировать агенты литейного производства», «развернуть агенты в литейном заводе», «зарегистрировать агенты в литейном заводе», «протолкнуть агенты», «создать манифест агента литейного производства», «синхронизировать агента леса».
