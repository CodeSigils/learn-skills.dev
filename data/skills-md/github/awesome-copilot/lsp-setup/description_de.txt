Aktivieren Sie Code-Intelligenz (Go-to-Definition, Find-Referenzen, Hover, Typinformationen) für jede Programmiersprache, indem Sie einen LSP-Server für Copilot CLI installieren und konfigurieren. Erkennt das Betriebssystem, installiert den richtigen Server und generiert die JSON-Konfiguration (Benutzerebene oder Repo-Ebene). Verwenden Sie diese Option, wenn Sie ein tieferes Verständnis des Codes benötigen und kein LSP-Server konfiguriert ist oder wenn der Benutzer einen LSP-Server einrichten, installieren oder konfigurieren möchte.
