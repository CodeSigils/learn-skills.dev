Abilita l'intelligenza del codice (vai alla definizione, trova riferimenti, passaggio del mouse, informazioni sul tipo) per qualsiasi linguaggio di programmazione installando e configurando un server LSP per la CLI di Copilot. Rileva il sistema operativo, installa il server corretto e genera la configurazione JSON (a livello utente o a livello di repository). Da utilizzare quando è necessaria una comprensione più approfondita del codice e non è configurato alcun server LSP o quando l'utente richiede di impostare, installare o configurare un server LSP.
