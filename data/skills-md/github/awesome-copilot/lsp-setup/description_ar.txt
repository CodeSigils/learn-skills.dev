قم بتمكين ذكاء التعليمات البرمجية (الانتقال إلى التعريف، والعثور على المراجع، والتمرير، واكتب المعلومات) لأي لغة برمجة عن طريق تثبيت وتكوين خادم LSP لـ Copilot CLI. يكتشف نظام التشغيل، ويثبت الخادم المناسب، وينشئ تكوين JSON (على مستوى المستخدم أو مستوى الريبو). يُستخدم عندما تحتاج إلى فهم أعمق للتعليمات البرمجية ولم يتم تكوين خادم LSP، أو عندما يطلب المستخدم إعداد خادم LSP أو تثبيته أو تكوينه.
