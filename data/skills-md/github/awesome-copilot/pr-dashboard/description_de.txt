Öffnen Sie ein GitHub PR-Dashboard im Browser. Verwenden Sie diese Option, wenn der Benutzer seine Pull-Anfragen sehen, das PR-Dashboard öffnen, PRs für einen Datumsbereich anzeigen oder den PR-Status überprüfen möchte. Zu den Triggerphrasen gehören „meine PRs anzeigen“, „PR-Dashboard öffnen“ und „Pull-Request-Dashboard“.
