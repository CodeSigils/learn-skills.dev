Откройте панель PR GitHub в браузере. Используйте, когда пользователь просит просмотреть свои запросы на включение, открыть панель PR, показать PR для диапазона дат или проверить статус PR. Триггерные фразы включают «показать мои PR», «открыть панель PR», «панель управления запросами на включение».
