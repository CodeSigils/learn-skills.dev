Ouvrez un tableau de bord GitHub PR dans le navigateur. À utiliser lorsque l'utilisateur demande à voir ses demandes d'extraction, ouvre le tableau de bord des PR, affiche les PR pour une plage de dates ou vérifie l'état des PR. Les phrases de déclenchement incluent « afficher mes PR », « ouvrir le tableau de bord des PR », « le tableau de bord des demandes d'extraction ».
