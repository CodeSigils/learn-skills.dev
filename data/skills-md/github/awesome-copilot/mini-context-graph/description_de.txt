Eine beständige, umfassende Wissensdatenbank, die das LLM-Wiki-Muster von Karpathy kombiniert
mit einem strukturierten Wissensgraphen. Dokumente einmal aufnehmen – der LLM schreibt Wiki
Seiten, extrahiert Entitäten/Beziehungen in das Diagramm und speichert Rohinhalte für
Beweisbeschaffung. Wissen sammelt sich an und es entstehen Querverweise; das ist es nie
von Grund auf neu abgeleitet.
