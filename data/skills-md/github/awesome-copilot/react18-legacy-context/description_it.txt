Fornisce il modello di migrazione completo per l'API del contesto legacy React (contextTypes, childContextTypes, getChildContext) alla moderna API createContext. Utilizza questa competenza ogni volta che esegui la migrazione del contesto legacy nei componenti della classe: si tratta sempre di una migrazione tra file che richiede che il provider E tutti i consumatori vengano aggiornati insieme. Utilizzalo prima di toccare qualsiasi codice contextTypes o childContextTypes, perché la migrazione solo del provider senza i consumer (o viceversa) causerà un errore di runtime. Leggi sempre questa competenza prima di scrivere qualsiasi migrazione del contesto: i passaggi di coordinamento tra file qui prevengono i bug di migrazione del contesto più comuni.
