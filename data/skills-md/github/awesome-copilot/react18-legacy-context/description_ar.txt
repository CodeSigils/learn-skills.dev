يوفر نمط الترحيل الكامل لواجهة برمجة تطبيقات سياق React القديمة (contextTypes، وchildContextTypes، وgetChildContext) إلى واجهة برمجة تطبيقات createContext الحديثة. استخدم هذه المهارة عند ترحيل السياق القديم في مكونات الفصل - وهذا دائمًا عبارة عن ترحيل عبر الملفات يتطلب تحديث الموفر وجميع المستهلكين معًا. استخدمه قبل لمس أي رمز contextTypes أو ChildContextTypes، لأن ترحيل الموفر فقط دون المستهلكين (أو العكس) سيؤدي إلى فشل وقت التشغيل. اقرأ دائمًا هذه المهارة قبل كتابة أي ترحيل للسياق - تمنع خطوات التنسيق عبر الملفات هنا أخطاء ترحيل السياق الأكثر شيوعًا.
