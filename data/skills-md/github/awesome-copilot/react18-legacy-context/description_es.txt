Proporciona el patrón de migración completo para la API de contexto heredada de React (contextTypes, childContextTypes, getChildContext) a la API createContext moderna. Utilice esta habilidad siempre que migre contexto heredado en componentes de clase; siempre se trata de una migración entre archivos que requiere que el proveedor Y todos los consumidores se actualicen juntos. Úselo antes de tocar cualquier código contextTypes o childContextTypes, porque migrar solo el proveedor sin los consumidores (o viceversa) provocará una falla en el tiempo de ejecución. Lea siempre esta habilidad antes de escribir cualquier migración de contexto: los pasos de coordinación entre archivos aquí evitan los errores de migración de contexto más comunes.
