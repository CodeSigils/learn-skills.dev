Stellt das vollständige Migrationsmuster für die React-Legacy-Kontext-API (contextTypes, childContextTypes, getChildContext) zur modernen createContext-API bereit. Verwenden Sie diese Fähigkeit immer dann, wenn Sie Legacy-Kontext in Klassenkomponenten migrieren. Dabei handelt es sich immer um eine dateiübergreifende Migration, bei der der Anbieter UND alle Verbraucher gemeinsam aktualisiert werden müssen. Verwenden Sie es, bevor Sie contextTypes- oder childContextTypes-Code berühren, da die Migration nur des Anbieters ohne die Verbraucher (oder umgekehrt) zu einem Laufzeitfehler führt. Lesen Sie diese Fertigkeit immer, bevor Sie eine Kontextmigration schreiben – die dateiübergreifenden Koordinationsschritte hier verhindern die häufigsten Fehler bei der Kontextmigration.
