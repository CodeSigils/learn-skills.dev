Предоставляет полный шаблон миграции для API устаревшего контекста React (contextTypes, childContextTypes, getChildContext) в современный API createContext. Используйте этот навык при миграции устаревшего контекста в компонентах класса — это всегда межфайловая миграция, требующая совместного обновления поставщика И всех потребителей. Используйте его, прежде чем прикасаться к любому коду contextTypes или childContextTypes, поскольку миграция только поставщика без потребителей (или наоборот) приведет к сбою во время выполнения. Всегда читайте этот навык перед написанием какой-либо миграции контекста — описанные здесь шаги по межфайловой координации предотвращают наиболее распространенные ошибки миграции контекста.
