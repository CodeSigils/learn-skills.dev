React レガシー コンテキスト API (contextTypes、childContextTypes、getChildContext) の最新の createContext API への完全な移行パターンを提供します。クラス コンポーネント内のレガシー コンテキストを移行する場合は必ずこのスキルを使用します。これは常にファイル間の移行であり、プロバイダーとすべてのコンシューマーを一緒に更新する必要があります。 contextTypes または childContextTypes コードに触れる前にこれを使用してください。これは、コンシューマーなしでプロバイダーのみを移行すると (またはその逆の場合)、実行時エラーが発生するためです。コンテキスト移行を作成する前に必ずこのスキルをお読みください。ここでのファイル間調整手順により、最も一般的なコンテキスト移行のバグが防止されます。
