Fournit le modèle de migration complet de l’API de contexte héritée de React (contextTypes, childContextTypes, getChildContext) vers l’API createContext moderne. Utilisez cette compétence lors de la migration d'un contexte hérité dans des composants de classe - il s'agit toujours d'une migration entre fichiers nécessitant que le fournisseur ET tous les consommateurs soient mis à jour ensemble. Utilisez-le avant de toucher au code contextTypes ou childContextTypes, car la migration uniquement du fournisseur sans les consommateurs (ou vice versa) entraînera un échec d'exécution. Lisez toujours cette compétence avant d'écrire une migration de contexte - les étapes de coordination entre fichiers ici évitent les bogues de migration de contexte les plus courants.
