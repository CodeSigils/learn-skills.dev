Núcleo de CommunityToolkit.Mvvm (el MVVM Toolkit): generadores de código fuente ([ObservableProperty], [RelayCommand], [NotifyPropertyChangedFor], [NotifyCanExecuteChangedFor], [NotifyDataErrorInfo]), clases base (ObservableObject/ObservableValidator/ObservableRecipient), comandos (RelayCommand/AsyncRelayCommand) y validación. Habilidades complementarias: mvvm-toolkit-messenger para pub/sub, mvvm-toolkit-di para cableado Microsoft.Extensions.DependencyInjection. Funciona en WPF, WinUI 3, MAUI, Uno y Avalonia.
