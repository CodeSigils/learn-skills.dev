CommunityToolkit.Mvvm (MVVM ツールキット) コア: ソース ジェネレーター ([ObservableProperty]、[RelayCommand]、[NotifyPropertyChangedFor]、[NotifyCanExecuteChangedFor]、[NotifyDataErrorInfo])、基本クラス (ObservableObject / ObservableValidator / ObservableRecipient)、コマンド (RelayCommand / AsyncRelayCommand)、および検証。コンパニオン スキル: パブリッシュ/サブスクライブ用の mvvm-toolkit-messenger、Microsoft.Extensions.DependencyInjection ワイヤリング用の mvvm-toolkit-di。 WPF、WinUI 3、MAUI、Uno、Avalonia で動作します。
