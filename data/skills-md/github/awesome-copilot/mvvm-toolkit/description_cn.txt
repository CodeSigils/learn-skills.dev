CommunityToolkit.Mvvm（MVVM 工具包）核心：源生成器（[ObservableProperty]、[RelayCommand]、[NotifyPropertyChangedFor]、[NotifyCanExecuteChangedFor]、[NotifyDataErrorInfo]）、基类（ObservableObject / ObservableValidator / ObservableRecipient）、命令（RelayCommand / AsyncRelayCommand）和验证。配套技能：用于 pub/sub 的 mvvm-toolkit-messenger、用于 Microsoft.Extensions.DependencyInjection 连接的 mvvm-toolkit-di。适用于 WPF、WinUI 3、MAUI、Uno 和 Avalonia。
