Noyau de CommunityToolkit.Mvvm (le MVVM Toolkit) : générateurs de sources ([ObservableProperty], [RelayCommand], [NotifyPropertyChangedFor], [NotifyCanExecuteChangedFor], [NotifyDataErrorInfo]), classes de base (ObservableObject / ObservableValidator / ObservableRecipient), commandes (RelayCommand / AsyncRelayCommand) et validation. Compétences compagnon : mvvm-toolkit-messenger pour pub/sub, mvvm-toolkit-di pour le câblage Microsoft.Extensions.DependencyInjection. Fonctionne sur WPF, WinUI 3, MAUI, Uno et Avalonia.
