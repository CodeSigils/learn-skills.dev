Ядро CommunityToolkit.Mvvm (набор инструментов MVVM): генераторы исходного кода ([ObservableProperty], [RelayCommand], [NotifyPropertyChangedFor], [NotifyCanExecuteChangedFor], [NotifyDataErrorInfo]), базовые классы (ObservableObject / ObservableValidator / ObservableRecipient), команды (RelayCommand / AsyncRelayCommand) и проверка. Дополнительные навыки: mvvm-toolkit-messenger для публикации/подписки, mvvm-toolkit-di для подключения Microsoft.Extensions.DependencyInjection. Работает в WPF, WinUI 3, MAUI, Uno и Avalonia.
