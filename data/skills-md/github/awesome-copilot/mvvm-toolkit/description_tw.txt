CommunityToolkit.Mvvm（MVVM 工具包）核心：來源產生器（[ObservableProperty]、[RelayCommand]、[NotifyPropertyChangedFor]、[NotifyCanExecuteChangedFor]、[NotifyDataErrorInfo]）、基底類別（ObservableObject / ObservableValidator inservableValReidator/clayable）指令驗證配套技能：用於 pub/sub 的 mvvm-toolkit-messenger、用於 Microsoft.Extensions.DependencyInjection 連接的 mvvm-toolkit-di。適用於 WPF、WinUI 3、MAUI、Uno 和 Avalonia。
