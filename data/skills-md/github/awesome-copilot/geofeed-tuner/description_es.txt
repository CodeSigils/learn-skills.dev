Utilice esta habilidad siempre que el usuario mencione feeds de geolocalización de IP, RFC 8805, geofeeds o necesite ayuda para crear, ajustar, validar o publicar un feed de geolocalización de IP autoeditado en formato CSV. El público objetivo es un operador de red, ISP, operador de telefonía móvil, proveedor de nube, empresa de alojamiento, IXP o proveedor de satélite que pregunta sobre la precisión de la geolocalización de IP o las mejores prácticas de creación de geofeed. Ayuda a crear, refinar y mejorar fuentes de geolocalización de IP en formato CSV con recomendaciones objetivas que van más allá del cumplimiento de RFC 8805. NO lo use para la administración de direcciones IP privadas o internas; se aplica solo a direcciones IP enrutables públicamente.
