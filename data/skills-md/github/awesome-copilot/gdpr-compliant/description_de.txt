Wenden Sie DSGVO-konforme Engineering-Praktiken in Ihrer gesamten Codebasis an. Verwenden Sie diese Fertigkeit immer dann, wenn Sie APIs entwerfen, Datenmodelle schreiben, Authentifizierungsflüsse erstellen, Protokollierung implementieren, Benutzerdaten verarbeiten, Aufbewahrungs-/Löschaufträge schreiben, Cloud-Infrastruktur entwerfen oder Pull-Anfragen auf Datenschutzkonformität überprüfen. Lösen Sie diese Fähigkeit für jede Aufgabe aus, die personenbezogene Daten, Benutzerkonten, Cookies, Analysen, E-Mails, Prüfprotokolle, Verschlüsselung, Pseudonymisierung, Anonymisierung, Datenexporte, Reaktion auf Sicherheitsverletzungen, CI/CD-Pipelines, die echte Daten verarbeiten, oder jede Frage mit der Formulierung „Ist das DSGVO-konform?“ betrifft. Inspiriert von den CNIL-Entwicklerrichtlinien und den DSGVO-Artikeln 5, 25, 32, 33, 35.
