قم بتطبيق الممارسات الهندسية المتوافقة مع اللائحة العامة لحماية البيانات (GDPR) عبر قاعدة التعليمات البرمجية الخاصة بك. استخدم هذه المهارة عندما تقوم بتصميم واجهات برمجة التطبيقات، أو كتابة نماذج البيانات، أو إنشاء تدفقات المصادقة، أو تنفيذ التسجيل، أو التعامل مع بيانات المستخدم، أو كتابة مهام الاحتفاظ/الحذف، أو تصميم البنية التحتية السحابية، أو مراجعة طلبات السحب للامتثال للخصوصية. قم بتشغيل هذه المهارة في أي مهمة تتضمن البيانات الشخصية، أو حسابات المستخدمين، أو ملفات تعريف الارتباط، أو التحليلات، أو رسائل البريد الإلكتروني، أو سجلات التدقيق، أو التشفير، أو إخفاء الهوية، أو تصدير البيانات، أو الاستجابة للانتهاكات، أو مسارات CI/CD التي تعالج البيانات الحقيقية، أو أي سؤال مؤطر على أنه "هل هذا متوافق مع اللائحة العامة لحماية البيانات؟". مستوحاة من إرشادات مطوري CNIL والمواد 5، 25، 32، 33، 35 من اللائحة العامة لحماية البيانات.
