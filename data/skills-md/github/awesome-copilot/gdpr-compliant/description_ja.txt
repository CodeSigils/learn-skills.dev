GDPR に準拠したエンジニアリング プラクティスをコードベース全体に適用します。 API の設計、データ モデルの作成、認証フローの構築、ロギングの実装、ユーザー データの処理、保持/削除ジョブの作成、クラウド インフラストラクチャの設計、またはプライバシー コンプライアンスのためのプル リクエストのレビューを行う場合には、必ずこのスキルを使用してください。個人データ、ユーザー アカウント、Cookie、分析、電子メール、監査ログ、暗号化、仮名化、匿名化、データ エクスポート、侵害への対応、実際のデータを処理する CI/CD パイプライン、または「これは GDPR に準拠していますか?」という質問に関連するあらゆるタスクに対してこのスキルをトリガーします。 CNIL 開発者ガイダンスと GDPR 第 5 条、第 25 条、第 32 条、第 33 条、第 35 条からインスピレーションを受けています。
