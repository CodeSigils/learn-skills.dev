استكشف أي قاعدة تعليمات برمجية من البداية وقم بإنشاء ستة عناصر جودة: دستور الجودة (QUALITY.md)، والاختبارات الوظيفية لتتبع المواصفات، وبروتوكول مراجعة التعليمات البرمجية، وبروتوكول اختبار التكامل، وتدقيق المواصفات متعدد النماذج (مجلس الثلاثة)، وملف تمهيد الذكاء الاصطناعي (AGENTS.md). يعمل مع أي لغة (Python، Java، Scala، TypeScript، Go، Rust، وما إلى ذلك). استخدم هذه المهارة عندما يطلب المستخدم إعداد دليل الجودة، أو إنشاء اختبارات وظيفية من المواصفات، أو إنشاء دستور الجودة، أو بناء بروتوكولات الاختبار، أو كود التدقيق مقابل المواصفات، أو إنشاء نظام جودة قابل للتكرار لمشروع. يتم تشغيله أيضًا عندما يذكر المستخدم "قواعد اللعبة" أو "تدقيق المواصفات" أو "مجلس الثلاثة" أو "الملاءمة للغرض" أو "مسرح التغطية" أو يريد تجاوز إنشاء الاختبار الأساسي لبناء نظام جودة كامل يرتكز على قاعدة التعليمات البرمجية الفعلية الخاصة بهم.
