Explorez n'importe quelle base de code à partir de zéro et générez six artefacts de qualité : une constitution de qualité (QUALITY.md), des tests fonctionnels tracés par les spécifications, un protocole de révision de code, un protocole de test d'intégration, un audit de spécifications multimodèles (Conseil des Trois) et un fichier d'amorçage d'IA (AGENTS.md). Fonctionne avec n'importe quel langage (Python, Java, Scala, TypeScript, Go, Rust, etc.). Utilisez cette compétence chaque fois que l'utilisateur demande de mettre en place un playbook de qualité, de générer des tests fonctionnels à partir de spécifications, de créer une constitution de qualité, de créer des protocoles de test, d'auditer le code par rapport aux spécifications ou d'établir un système qualité reproductible pour un projet. Déclenchez également lorsque l'utilisateur mentionne un « manuel de qualité », un « audit de spécifications », un « Conseil des Trois », « une adéquation à un objectif », un « théâtre de couverture » ou souhaite aller au-delà de la génération de tests de base pour créer un système de qualité complet fondé sur sa base de code actuelle.
