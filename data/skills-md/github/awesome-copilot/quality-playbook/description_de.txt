Erkunden Sie jede Codebasis von Grund auf und generieren Sie sechs Qualitätsartefakte: eine Qualitätskonstitution (QUALITY.md), spezifikationsbasierte Funktionstests, ein Codeüberprüfungsprotokoll, ein Integrationstestprotokoll, eine Multimodell-Spezifikationsprüfung (Council of Three) und eine AI-Bootstrap-Datei (AGENTS.md). Funktioniert mit jeder Sprache (Python, Java, Scala, TypeScript, Go, Rust usw.). Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein Qualitäts-Playbook einrichten, Funktionstests aus Spezifikationen generieren, eine Qualitätsverfassung erstellen, Testprotokolle erstellen, Code anhand von Spezifikationen prüfen oder ein wiederholbares Qualitätssystem für ein Projekt einrichten möchte. Wird auch ausgelöst, wenn der Benutzer „Quality Playbook“, „Spec Audit“, „Council of Three“, „Fitness-to-Purpose“, „Berichterstattungstheater“ erwähnt oder über die einfache Testgenerierung hinausgehen möchte, um ein vollständiges Qualitätssystem zu erstellen, das auf seiner tatsächlichen Codebasis basiert.
