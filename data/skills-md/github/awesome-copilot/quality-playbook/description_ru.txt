Исследуйте любую базу кода с нуля и создайте шесть артефактов качества: конституцию качества (QUALITY.md), функциональные тесты с отслеживанием спецификаций, протокол проверки кода, протокол интеграционного тестирования, аудит многомодельных спецификаций (Совет трех) и файл начальной загрузки AI (AGENTS.md). Работает с любым языком (Python, Java, Scala, TypeScript, Go, Rust и т. д.). Используйте этот навык всякий раз, когда пользователь просит настроить план качества, сгенерировать функциональные тесты на основе спецификаций, создать конституцию качества, разработать протоколы тестирования, проверить код на соответствие спецификациям или создать повторяемую систему качества для проекта. Также срабатывает, когда пользователь упоминает «сборник качества», «аудит спецификаций», «Совет трех», «соответствие цели», «театр покрытия» или хочет выйти за рамки базовой генерации тестов и создать полноценную систему качества, основанную на его реальной кодовой базе.
