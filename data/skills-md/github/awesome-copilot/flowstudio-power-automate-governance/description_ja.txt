FlowStudio MCP キャッシュ ストアを使用して、Power Automate フローと Power Apps を大規模に管理します。ビジネスへの影響によるフローの分類、孤立したリソースの検出、コネクタの使用状況の監査、コンプライアンス標準の適用、通知ルールの管理、ガバナンス スコアの計算をすべて Dataverse や CoE Starter Kit を使用せずに実行できます。フローのタグ付けまたは分類、ビジネスへの影響の設定、所有権の割り当て、孤立者の検出、コネクタの監査、コンプライアンスのチェック、アーカイブ スコアの計算、通知ルールの管理、ガバナンス レビューの実行、コンプライアンス レポートの生成、メーカーのオフボード、またはフローへのガバナンス メタデータの書き込みを伴うタスクを行うように求められた場合、このスキルをロードします。 FlowStudio for Teams または MCP Pro+ サブスクリプションが必要です — https://mcp.flowstudio.app を参照してください
