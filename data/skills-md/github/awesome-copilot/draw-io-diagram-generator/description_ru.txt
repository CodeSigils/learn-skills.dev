Используйте при создании, редактировании или генерации файлов диаграмм draw.io (.drawio, .drawio.svg, .drawio.png). Охватывает разработку XML mxGraph, библиотеки форм, строки стилей, блок-схемы, системную архитектуру, диаграммы последовательности, диаграммы ER, диаграммы классов UML, топологию сети, стратегию компоновки, расширение VS Code hediet.vscode-drawio и полный рабочий процесс агента от запроса до готового к открытию файла.
