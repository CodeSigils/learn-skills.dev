Руководство по обработке часовых поясов .NET для приложений C#. Используйте при работе с TimeZoneInfo, DateTimeOffset, NodaTime, преобразованием UTC, переходом на летнее время, планированием между часовыми поясами, кроссплатформенными идентификаторами часовых поясов Windows/IANA или когда пользователю .NET требуется часовой пояс для города, адреса, региона или страны и готовый к копированию код C#.
