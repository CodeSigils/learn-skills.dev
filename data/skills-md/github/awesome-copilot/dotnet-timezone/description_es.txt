Guía de manejo de zona horaria de .NET para aplicaciones C#. Úselo cuando trabaje con TimeZoneInfo, DateTimeOffset, NodaTime, conversión UTC, horario de verano, programación entre zonas horarias, ID de zona horaria multiplataforma de Windows/IANA o cuando un usuario de .NET necesita la zona horaria de una ciudad, dirección, región o país y código C# listo para copiar y pegar.
