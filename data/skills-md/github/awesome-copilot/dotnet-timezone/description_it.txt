Linee guida per la gestione del fuso orario .NET per le applicazioni C#. Da utilizzare quando si lavora con TimeZoneInfo, DateTimeOffset, NodaTime, conversione UTC, ora legale, pianificazione tra fusi orari, ID fuso orario Windows/IANA multipiattaforma o quando un utente .NET necessita del fuso orario per una città, un indirizzo, un'area geografica o un paese e un codice C# pronto per il copia e incolla.
