Conseils de gestion du fuseau horaire .NET pour les applications C#. À utiliser lorsque vous travaillez avec TimeZoneInfo, DateTimeOffset, NodaTime, la conversion UTC, l'heure d'été, la planification sur plusieurs fuseaux horaires, les ID de fuseau horaire Windows/IANA multiplateformes, ou lorsqu'un utilisateur .NET a besoin du fuseau horaire d'une ville, d'une adresse, d'une région ou d'un pays et d'un code C# prêt à copier-coller.
