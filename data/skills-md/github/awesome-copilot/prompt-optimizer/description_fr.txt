Transformez n'importe quelle invite approximative, idée à moitié formée ou description de tâche en une invite terminée, prête à être envoyée, optimisée pour n'importe quel modèle LLM dans une interface de discussion - PAS l'API. Utilisez cette compétence chaque fois que l'utilisateur souhaite écrire, réécrire, optimiser, améliorer, affiner ou peaufiner une invite de discussion. Les phrases de déclenchement incluent « réécrire cette invite », « en faire une meilleure invite », « optimiser cette invite », « transformer ceci en invite », « aidez-moi à inviter ceci », « rédiger une invite qui... », « Je veux demander... », ou chaque fois que l'utilisateur colle un brouillon d'invite et demande des améliorations. Déclenchez également lorsque l'utilisateur décrit une tâche qu'il envisage d'envoyer à un modèle LLM et souhaite clairement une invite réutilisable et bien structurée plutôt qu'une réponse directe. Le résultat est toujours une invite unique pouvant être copiée-collée dans un bloc de code que l'utilisateur envoie tel quel – jamais un modèle avec des espaces réservés.
