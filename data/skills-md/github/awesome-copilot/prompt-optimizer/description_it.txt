Trasforma qualsiasi richiesta approssimativa, idea a metà o descrizione dell'attività in una richiesta finita, pronta per l'invio, ottimizzata per qualsiasi modello LLM all'interno di un'interfaccia di chat, NON dell'API. Utilizza questa competenza ogni volta che l'utente desidera scrivere, riscrivere, ottimizzare, migliorare, affinare o perfezionare un messaggio per la chat. Le frasi trigger includono "riscrivi questo prompt", "rendi questo prompt migliore", "ottimizza questo prompt", "trasforma questo in un prompt", "aiutami a richiedere questo", "crea una bozza di prompt che...", "Voglio chiedere...", o ogni volta che l'utente incolla una bozza di prompt e chiede miglioramenti. Si attivano anche quando l'utente descrive un'attività che intende inviare a un modello LLM e desidera chiaramente un prompt riutilizzabile e ben strutturato anziché una risposta diretta. L'output è sempre un singolo prompt copia-incollabile in un blocco di codice che l'utente invia così com'è, mai un modello con segnaposto.
