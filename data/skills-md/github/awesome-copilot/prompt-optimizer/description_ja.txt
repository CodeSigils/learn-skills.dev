大まかなプロンプト、中途半端なアイデア、またはタスクの説明を、API ではなく、チャット インターフェイス内の LLM モデル向けに最適化された、完成したすぐに送信できるプロンプトに変換します。ユーザーがチャットのプロンプトを作成、書き直し、最適化、改善、シャープ化、または磨き上げたい場合は常に、このスキルを使用します。トリガー フレーズには、「このプロンプトを書き直す」、「これをより良いプロンプトにする」、「このプロンプトを最適化する」、「これをプロンプトに変える」、「このプロンプトを手伝ってください」、「...というプロンプトを下書きする」、「質問したいのですが...」、またはユーザーが下書きのプロンプトを貼り付けて改善を求める場合などがあります。また、ユーザーが LLM モデルに送信する予定のタスクを説明し、直接的な回答ではなく再利用可能で適切に構造化されたプロンプトを明らかに望んでいる場合にもトリガーされます。出力は常に、ユーザーがそのまま送信するコード ブロック内のコピー＆ペースト可能な単一のプロンプトであり、プレースホルダーを含むテンプレートではありません。
