Verwandeln Sie jede grobe Eingabeaufforderung, halbfertige Idee oder Aufgabenbeschreibung in eine fertige, versandfertige Eingabeaufforderung, die für jedes LLM-Modell innerhalb einer Chat-Schnittstelle optimiert ist – NICHT über die API. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Chataufforderung schreiben, umschreiben, optimieren, verbessern, schärfen oder verfeinern möchte. Zu den Triggerphrasen gehören „diese Eingabeaufforderung umschreiben“, „diese Eingabeaufforderung verbessern“, „diese Eingabeaufforderung optimieren“, „dies in eine Eingabeaufforderung umwandeln“, „hilf mir, diese Eingabeaufforderung auszuführen“, „eine Eingabeaufforderung entwerfen, die …“, „Ich möchte fragen …“ oder wann immer der Benutzer einen Eingabeaufforderungsentwurf einfügt und um Verbesserungen bittet. Wird auch ausgelöst, wenn der Benutzer eine Aufgabe beschreibt, die er an ein LLM-Modell senden möchte, und eindeutig eine wiederverwendbare, gut strukturierte Eingabeaufforderung anstelle einer direkten Antwort wünscht. Die Ausgabe ist immer eine einzelne, kopier- und einfügbare Eingabeaufforderung in einem Codeblock, den der Benutzer unverändert sendet – niemals eine Vorlage mit Platzhaltern.
