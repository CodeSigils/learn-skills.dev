Convierta cualquier mensaje aproximado, idea a medio formar o descripción de tarea en un mensaje terminado, listo para enviar, optimizado para cualquier modelo de LLM dentro de una interfaz de chat, NO la API. Utilice esta habilidad siempre que el usuario quiera escribir, reescribir, optimizar, mejorar, perfeccionar o pulir un mensaje de chat. Las frases desencadenantes incluyen "reescribir este mensaje", "hacer de este un mensaje mejor", "optimizar este mensaje", "convertir esto en un mensaje", "ayúdame a preguntar esto", "redactar un mensaje que...", "Quiero preguntar...", o cada vez que el usuario pegue un borrador y solicite mejoras. También se activa cuando el usuario describe una tarea que planea enviar a un modelo LLM y claramente quiere un mensaje reutilizable y bien estructurado en lugar de una respuesta directa. El resultado es siempre un mensaje único que se puede copiar y pegar en un bloque de código que el usuario envía tal cual, nunca una plantilla con marcadores de posición.
