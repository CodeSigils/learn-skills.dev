قم بتحويل أي مطالبة تقريبية أو فكرة نصف مكتملة أو وصف مهمة إلى مطالبة نهائية وجاهزة للإرسال مُحسّنة لأي نموذج LLM داخل واجهة الدردشة - وليس واجهة برمجة التطبيقات. استخدم هذه المهارة عندما يريد المستخدم كتابة مطالبة للدردشة أو إعادة كتابتها أو تحسينها أو تحسينها أو تحسينها أو صقلها. تتضمن عبارات التشغيل "إعادة كتابة هذه المطالبة" أو "اجعل هذه المطالبة أفضل" أو "تحسين هذه المطالبة" أو "تحويل هذه إلى مطالبة" أو "ساعدني في المطالبة بذلك" أو "صياغة مطالبة..." أو "أريد أن أسأل..." أو عندما يلصق المستخدم مسودة مطالبة ويطلب إجراء تحسينات. يتم التشغيل أيضًا عندما يصف المستخدم مهمة يخطط لإرسالها إلى نموذج LLM ويريد بوضوح مطالبة جيدة التنظيم وقابلة لإعادة الاستخدام بدلاً من إجابة مباشرة. يكون الإخراج دائمًا عبارة عن مطالبة واحدة قابلة للنسخ واللصق في مقطع تعليمات برمجية يرسله المستخدم كما هو - ولا يكون أبدًا قالبًا يحتوي على عناصر نائبة.
