每当用户想要在 vanilla JS、React 或 Next.js 中构建滚动动画、滚动效果、视差、滚动触发显示、固定部分、水平滚动、文本动画或任何与滚动位置相关的运动时，都可以使用此技能。涵盖 GSAP ScrollTrigger（固定、擦洗、捕捉、时间线、水平滚动、ScrollSmoother、matchMedia）和 Framer Motion / Motion v12（useScroll、useTransform、useSpring、whileInView、变体）。即使用户只是说“滚动时动画”、“滚动时淡入”、“使其像 Apple 一样滚动”、“视差效果”、“粘滞部分”、“滚动进度条”或“入口动画”，也可以使用此技能。还可以触发用于 GSAP 或 Framer Motion 代码生成的 Copilot 提示模式。与高级前端 UI 技能相结合，实现创意理念和设计级别的完善。
