每當使用者想要在 vanilla JS、React 或 Next.js 中建立滾動動畫、滾動效果、視差、滾動觸發顯示、固定部分、水平滾動、文字動畫或任何與滾動位置相關的運動時，都可以使用此技能。涵蓋 GSAP ScrollTrigger（固定、擦洗、捕捉、時間軸、水平滾動、ScrollSmoother、matchMedia）和 Framer Motion / Motion v12（useScroll、useTransform、useSpring、whileInView、變體）。即使用戶只是說“滾動時動畫”、“滾動時淡入”、“使其像 Apple 一樣滾動”、“視差效果”、“粘滯部分”、“滾動進度條”或“入口動畫”，也可以使用此技能。也可以觸發用於 GSAP 或 Framer Motion 程式碼產生的 Copilot 提示模式。與高階前端 UI 技能結合，實現創意理念和設計等級的完善。
