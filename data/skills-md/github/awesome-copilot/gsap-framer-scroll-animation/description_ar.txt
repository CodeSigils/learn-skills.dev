استخدم هذه المهارة عندما يريد المستخدم إنشاء رسوم متحركة للتمرير، أو تأثيرات التمرير، أو اختلاف المنظر، أو الكشف الناتج عن التمرير، أو الأقسام المثبتة، أو التمرير الأفقي، أو الرسوم المتحركة النصية، أو أي حركة مرتبطة بموضع التمرير - في Vanilla JS أو React أو Next.js. يغطي GSAP ScrollTrigger (التثبيت، والتنقية، والالتقاط، والجداول الزمنية، والتمرير الأفقي، وScrollSmoother، وmatchMedia) وFramer Motion / Motion v12 (useScroll، useTransform، useSpring، whileInView، المتغيرات). استخدم هذه المهارة حتى لو قال المستخدم فقط "تحريك عند التمرير"، أو "تتلاشى أثناء التمرير"، أو "اجعله يتم التمرير مثل Apple"، أو "تأثير اختلاف المنظر"، أو "قسم ثابت"، أو "شريط تقدم التمرير"، أو "رسوم الدخول المتحركة". يتم أيضًا تشغيل أنماط مطالبة Copilot لإنشاء كود GSAP أو Framer Motion. يقترن بمهارة واجهة المستخدم الأمامية المتميزة للفلسفة الإبداعية والصقل على مستوى التصميم.
