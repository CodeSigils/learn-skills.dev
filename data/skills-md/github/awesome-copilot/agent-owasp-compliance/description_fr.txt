Vérifiez la base de code de n’importe quel agent IA par rapport aux 10 principaux risques de l’OWASP Agentic Security Initiative (ASI).
Utilisez cette compétence lorsque :
- Évaluation de la posture de sécurité d'un système d'agent avant le déploiement en production
- Réalisation d'un contrôle de conformité aux normes OWASP ASI 2026
- Cartographie des contrôles de sécurité existants sur les 10 risques agents
- Génération d'un rapport de conformité pour examen ou audit de sécurité
- Comparaison des fonctionnalités de sécurité du framework d'agent avec la norme
- Toute demande du type "Mon agent est-il conforme à l'OWASP ?", "Vérifier la conformité ASI" ou "Audit de sécurité de l'agent"
