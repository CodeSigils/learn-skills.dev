تحقق من أي قاعدة تعليمات برمجية لوكلاء الذكاء الاصطناعي مقابل المخاطر العشرة الأهم لمبادرة أمان الوكيل (ASI) الخاصة بـ OWASP.
استخدم هذه المهارة عندما:
- تقييم الوضع الأمني لنظام الوكيل قبل نشر الإنتاج
- إجراء فحص الامتثال لمعايير OWASP ASI 2026
- رسم خرائط الضوابط الأمنية الحالية للمخاطر الوكيلة العشرة
- إنشاء تقرير امتثال للمراجعة الأمنية أو التدقيق
- مقارنة ميزات أمان إطار عمل الوكيل بالمعيار
- أي طلب مثل "هل وكيلي متوافق مع OWASP؟"، أو "التحقق من امتثال ASI"، أو "تدقيق أمان الوكيل"
