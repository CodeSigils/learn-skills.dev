GitHub Actions ワークフロー ファイル (.github/workflows/*.yml) のセキュリティ強化レビュー担当者。パターン マッチャーと一般的なコード リンターが見逃すアクション脅威モデルの理由 - 信頼できない入力スクリプト インジェクション、フォーク コードを実行する特権トリガー、変更可能なアクション参照、およびスコープを超えたトークン。このスキルは、GitHub Actions ワークフローのレビュー、監査、強化、保護を求められた場合、新しいワークフローを作成する場合、または「このワークフローは安全ですか?」、「セキュリティ上の問題がないか CI をレビューしてください」、「なぜ pull_request_target がここで危険なのですか?」、「アクションを固定する」、または「GITHUB_TOKEN 権限をロックダウンする」などのリクエストに対して使用します。 ${{ }} 補間によるスクリプト インジェクション、pull_request_target / workflow_run 権限エスカレーション、サードパーティ アクションの SHA 固定、最小権限パーミッション、GITHUB_ENV/GITHUB_OUTPUT インジェクション、シークレット漏洩、長期有効資格情報を介した OIDC、およびパブリック リポジトリでのセルフホスト ランナー漏洩をカバーします。
