Sicherheitshärtungsprüfer für GitHub Actions-Workflowdateien (.github/workflows/*.yml). Gründe für das Actions-Bedrohungsmodell, das Mustervergleicher und allgemeine Code-Linters übersehen – Skriptinjektion nicht vertrauenswürdiger Eingaben, privilegierte Trigger, die Fork-Code ausführen, veränderbare Aktionsreferenzen und Token mit zu großem Gültigkeitsbereich. Verwenden Sie diese Fähigkeit, wenn Sie aufgefordert werden, einen GitHub Actions-Workflow zu überprüfen, zu prüfen, zu härten oder zu sichern, wenn Sie einen neuen Workflow schreiben oder für Anfragen wie „Ist dieser Workflow sicher?“, „Überprüfen Sie mein CI auf Sicherheitsprobleme“, „Warum ist pull_request_target hier gefährlich?“, „Meine Aktionen anpinnen“ oder „GITHUB_TOKEN-Berechtigungen sperren“. Behandelt die Skriptinjektion über ${{ }}-Interpolation, pull_request_target/workflow_run-Berechtigungseskalation, SHA-Pinning von Aktionen Dritter, Least-Privilege-Berechtigungen, GITHUB_ENV/GITHUB_OUTPUT-Injection, geheime Offenlegung, OIDC über langlebige Anmeldeinformationen und selbstgehostete Runner-Offenlegung in öffentlichen Repositorys.
