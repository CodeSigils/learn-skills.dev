GitHub Actions 工作流程文件 (.github/workflows/*.yml) 的安全強化審核者。模式匹配器和通用代碼檢查器錯過的操作威脅模型的原因 - 不受信任的輸入腳本注入、運行分叉代碼的特權觸發器、可變操作引用和範圍過大的令牌。當被要求審查、審核、強化或保護 GitHub Actions 工作流程時、編寫新工作流程時或任何請求（例如「此工作流程安全嗎？」、「檢查我的 CI 是否存在安全性問題」、「為什麼 pull_request_target 這裡很危險？」、「固定我的操作」或「鎖定 GITHUB_TOKEN 權限」時很危險？權限。涵蓋透過 ${{ }} 插值進行的腳本注入、pull_request_target/workflow_run 權限升級、第三方操作的 SHA 固定、最低權限權限、GITHUB_ENV/GITHUB_OUTPUT 注入、秘密暴露、長期憑證上的 OIDC 以及公共儲存庫上的自託管執行程式暴露。
