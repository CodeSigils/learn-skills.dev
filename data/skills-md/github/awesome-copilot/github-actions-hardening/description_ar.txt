مراجع تقوية الأمان لملفات سير عمل GitHub Actions (.github/workflows/*.yml). الأسباب المتعلقة بنموذج تهديد الإجراءات الذي تفتقده مطابقات الأنماط وضوابط التعليمات البرمجية العامة - إدخال برنامج نصي غير موثوق به، والمشغلات المميزة التي تقوم بتشغيل كود التفرع، ومراجع الإجراءات القابلة للتغيير، والرموز المميزة ذات النطاق الزائد. استخدم هذه المهارة عندما يُطلب منك مراجعة سير عمل GitHub Actions أو تدقيقه أو تقويته أو تأمينه، أو عند كتابة سير عمل جديد، أو لأي طلب مثل "هل سير العمل هذا آمن؟"، أو "مراجعة CI الخاص بي بحثًا عن مشكلات أمنية"، أو "لماذا يكون pull_request_target خطيرًا هنا؟"، أو "تثبيت أفعالي"، أو "تأمين أذونات GITHUB_TOKEN". يغطي حقن البرنامج النصي عبر استيفاء ${{ }}، وتصعيد امتياز pull_request_target / Workflow_run، وتثبيت SHA لإجراءات الطرف الثالث، والأذونات الأقل امتيازًا، وحقن GITHUB_ENV/GITHUB_OUTPUT، والكشف السري، وOIDC على بيانات الاعتماد طويلة العمر، والتعرض للتشغيل المستضاف ذاتيًا في المستودعات العامة.
