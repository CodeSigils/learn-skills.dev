GitHub Actions 워크플로 파일(.github/workflows/*.yml)에 대한 보안 강화 검토자입니다. 패턴 일치자 및 일반 코드 린터가 놓치는 작업 위협 모델에 대한 이유 - 신뢰할 수 없는 입력 스크립트 삽입, 포크 코드를 실행하는 권한 있는 트리거, 변경 가능한 작업 참조 및 범위가 넓은 토큰. GitHub Actions 워크플로를 검토, 감사, 강화 또는 보호하라는 요청을 받을 때, 새 워크플로를 작성할 때 또는 "이 워크플로가 안전한가요?", "내 CI에서 보안 문제를 검토하세요", "여기서 pull_request_target이 위험한 이유는 무엇입니까?", "내 작업 고정" 또는 "GITHUB_TOKEN 권한 잠금"과 같은 요청에 대해 이 기술을 사용하세요. ${{ }} 보간법을 통한 스크립트 주입, pull_request_target/workflow_run 권한 에스컬레이션, 타사 작업의 SHA 고정, 최소 권한 권한, GITHUB_ENV/GITHUB_OUTPUT 주입, 비밀 노출, 장기 자격 증명에 대한 OIDC, 공개 저장소에 대한 자체 호스팅 실행기 노출을 다룹니다.
