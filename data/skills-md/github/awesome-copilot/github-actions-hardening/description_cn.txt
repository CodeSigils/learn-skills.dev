GitHub Actions 工作流程文件 (.github/workflows/*.yml) 的安全强化审核者。模式匹配器和通用代码检查器错过的操作威胁模型的原因 - 不受信任的输入脚本注入、运行分叉代码的特权触发器、可变操作引用和范围过大的令牌。当被要求审查、审核、强化或保护 GitHub Actions 工作流程时、编写新工作流程时或任何请求（例如“此工作流程安全吗？”、“检查我的 CI 是否存在安全问题”、“为什么 pull_request_target 这里很危险？”、“固定我的操作”或“锁定 GITHUB_TOKEN 权限”）时，请使用此技能。涵盖通过 ${{ }} 插值进行的脚本注入、pull_request_target/workflow_run 权限升级、第三方操作的 SHA 固定、最低权限权限、GITHUB_ENV/GITHUB_OUTPUT 注入、秘密暴露、长期凭证上的 OIDC 以及公共存储库上的自托管运行程序暴露。
