Revisor de refuerzo de seguridad para archivos de flujo de trabajo de GitHub Actions (.github/workflows/*.yml). Razones sobre el modelo de amenaza de acciones que los comparadores de patrones y los linters de código generales pasan por alto: inyección de scripts de entrada que no son de confianza, activadores privilegiados que ejecutan código bifurcado, referencias de acciones mutables y tokens con alcance excesivo. Utilice esta habilidad cuando se le solicite revisar, auditar, reforzar o proteger un flujo de trabajo de GitHub Actions, al escribir un nuevo flujo de trabajo o para cualquier solicitud como "¿es seguro este flujo de trabajo?", "revisar mi CI para detectar problemas de seguridad", "¿por qué pull_request_target es peligroso aquí?", "fijar mis acciones" o "bloquear permisos GITHUB_TOKEN". Cubre la inyección de scripts mediante interpolación ${{ }}, escalada de privilegios pull_request_target/flowwork_run, fijación SHA de acciones de terceros, permisos de privilegios mínimos, inyección GITHUB_ENV/GITHUB_OUTPUT, exposición de secretos, OIDC sobre credenciales de larga duración y exposición de corredores autohospedados en repositorios públicos.
