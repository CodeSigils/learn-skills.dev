Рецензент по усилению безопасности для файлов рабочих процессов GitHub Actions (.github/workflows/*.yml). Причины, связанные с моделью угроз Actions, которые пропускают средства сопоставления шаблонов и общие линтеры кода: внедрение скриптов с ненадежным входом, привилегированные триггеры, запускающие код вилки, ссылки на изменяемые действия и токены с превышением области действия. Используйте этот навык, когда вас просят просмотреть, проверить, усилить или защитить рабочий процесс GitHub Actions, при написании нового рабочего процесса или для любого запроса типа «безопасен ли этот рабочий процесс?», «проверьте мой CI на наличие проблем безопасности», «почему здесь опасен pull_request_target?», «закрепите мои действия» или «заблокируйте разрешения GITHUB_TOKEN». Охватывает внедрение скриптов посредством интерполяции ${{ }}, повышение привилегий pull_request_target/workflow_run, SHA-закрепление сторонних действий, разрешения с наименьшими привилегиями, внедрение GITHUB_ENV/GITHUB_OUTPUT, секретное раскрытие, OIDC по долгосрочным учетным данным и самостоятельную экспозицию бегуна в публичных репозиториях.
