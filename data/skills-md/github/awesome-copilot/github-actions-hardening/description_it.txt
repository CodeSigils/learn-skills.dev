Revisore del rafforzamento della sicurezza per i file del flusso di lavoro di GitHub Actions (.github/workflows/*.yml). Motivi del modello di minaccia Actions che i pattern matcher e i linter di codice generali non riescono a rilevare: inserimento di script di input non attendibili, trigger privilegiati che eseguono codice fork, riferimenti ad azioni modificabili e token con ambito eccessivo. Utilizza questa competenza quando ti viene chiesto di rivedere, controllare, rafforzare o proteggere un flusso di lavoro di GitHub Actions, quando scrivi un nuovo flusso di lavoro o per qualsiasi richiesta come "questo flusso di lavoro è sicuro?", "rivedi il mio elemento della configurazione per problemi di sicurezza", "perché pull_request_target è pericoloso qui?", "blocca le mie azioni" o "blocca le autorizzazioni GITHUB_TOKEN". Copre l'inserimento di script tramite interpolazione ${{ }}, l'escalation dei privilegi pull_request_target/flowflow_run, il blocco SHA di azioni di terze parti, autorizzazioni con privilegi minimi, l'iniezione GITHUB_ENV/GITHUB_OUTPUT, l'esposizione segreta, OIDC su credenziali di lunga durata e l'esposizione di runner self-hosted su repository pubblici.
