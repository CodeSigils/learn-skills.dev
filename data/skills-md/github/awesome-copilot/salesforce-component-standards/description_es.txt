Estándares de calidad para Salesforce Lightning Web Components (LWC), componentes Aura y páginas de Visualforce. Cubre el cumplimiento de SLDS 2, la accesibilidad (WCAG 2.1 AA), la selección de patrones de acceso a datos, las reglas de comunicación de componentes, la prevención de XSS, la aplicación de CSRF, FLS/CRUD en métodos AuraEnabled, la gestión de estado de visualización y los requisitos de prueba de Jest. Utilice esta habilidad al crear o revisar cualquier componente de la interfaz de usuario de Salesforce para aplicar estándares de calidad y seguridad específicos de la plataforma.
