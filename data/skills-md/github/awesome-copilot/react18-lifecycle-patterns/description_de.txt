Bietet genaue Vorher-/Nachher-Migrationsmuster für die drei Lebenszyklusmethoden unsicherer Klassenkomponenten – ComponentWillMount, ComponentWillReceiveProps und ComponentWillUpdate – für React 18.3.1. Verwenden Sie diese Fähigkeit immer dann, wenn die Lebenszyklusmethoden einer Klassenkomponente migriert werden müssen, wenn Sie sich zwischen getDerivedStateFromProps und ComponentDidUpdate entscheiden, wenn Sie getSnapshotBeforeUpdate hinzufügen oder wenn Sie React 18 UNSAFE_-Lebenszykluswarnungen beheben. Nutzen Sie diese Fähigkeit immer, bevor Sie Code für die Lebenszyklusmigration schreiben – erraten Sie das Muster nicht aus dem Gedächtnis, die Entscheidungsbäume hier verhindern die häufigsten Migrationsfehler.
