Fournit des modèles de migration avant/après exacts pour les trois méthodes de cycle de vie des composants de classe non sécurisées - composantWillMount, composantWillReceiveProps et composantWillUpdate - ciblant React 18.3.1. Utilisez cette compétence chaque fois qu'un composant de classe a besoin de migrer ses méthodes de cycle de vie, lorsque vous décidez entre getDerivedStateFromProps et composantDidUpdate, lors de l'ajout de getSnapshotBeforeUpdate ou lors de la correction des avertissements de cycle de vie React 18 UNSAFE_. Utilisez toujours cette compétence avant d'écrire un code de migration de cycle de vie - ne devinez pas le modèle de mémoire, les arbres de décision ici évitent les erreurs de migration les plus courantes.
