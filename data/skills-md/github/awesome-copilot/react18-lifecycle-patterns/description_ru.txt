Предоставляет точные шаблоны до и после миграции для трех небезопасных методов жизненного цикла компонентов классов — компонентWillMount, компонентWillReceiveProps и компонентWillUpdate — ориентированных на React 18.3.1. Используйте этот навык всякий раз, когда компонент класса нуждается в переносе своих методов жизненного цикла, при выборе между getDerivedStateFromProps и компонентомDidUpdate, при добавлении getSnapshotBeforeUpdate или при исправлении предупреждений жизненного цикла React 18 UNSAFE_. Всегда используйте этот навык перед написанием любого кода миграции жизненного цикла — не угадывайте шаблон по памяти, деревья решений здесь предотвращают наиболее распространенные ошибки миграции.
