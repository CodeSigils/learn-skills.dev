React 18.3.1 を対象とする 3 つの安全でないクラス コンポーネントのライフサイクル メソッド (componentWillMount、componentWillReceiveProps、componentWillUpdate) の正確な移行前/移行後のパターンを提供します。このスキルは、クラス コンポーネントのライフサイクル メソッドの移行が必要な場合、getDerivedStateFromProps か、componentDidUpdate のどちらかを決定する場合、getSnapshotBeforeUpdate を追加する場合、または React 18 UNSAFE_ ライフサイクル警告を修正する場合に使用します。ライフサイクル移行コードを作成する前に必ずこのスキルを使用してください。パターンを記憶から推測しないでください。ここでのデシジョン ツリーは、最も一般的な移行の間違いを防ぎます。
