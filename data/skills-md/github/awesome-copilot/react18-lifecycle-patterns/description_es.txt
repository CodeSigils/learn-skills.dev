Proporciona patrones de migración exactos antes y después de los tres métodos de ciclo de vida de componentes de clases inseguras: componenteWillMount, componenteWillReceiveProps y componenteWillUpdate, dirigidos a React 18.3.1. Utilice esta habilidad siempre que un componente de clase necesite migrar sus métodos de ciclo de vida, cuando decida entre getDerivedStateFromProps vs componenteDidUpdate, cuando agregue getSnapshotBeforeUpdate o cuando corrija las advertencias del ciclo de vida de React 18 UNSAFE_. Utilice siempre esta habilidad antes de escribir cualquier código de migración del ciclo de vida; no adivine el patrón de memoria, los árboles de decisión aquí evitan los errores de migración más comunes.
