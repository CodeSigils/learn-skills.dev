يوفر أنماطًا دقيقة قبل/بعد الترحيل لطرق دورة حياة مكونات الفئة الثلاثة غير الآمنة - ComponentWillMount، وcomponentWillReceiveProps، وcomponentWillUpdate - التي تستهدف React 18.3.1. استخدم هذه المهارة عندما يحتاج مكون الفصل إلى ترحيل أساليب دورة الحياة الخاصة به، عند الاختيار بين getDerivedStateFromProps وcomponentDidUpdate، أو عند إضافة getSnapshotBeforeUpdate، أو عند إصلاح تحذيرات دورة حياة React 18 UNSAFE_. استخدم هذه المهارة دائمًا قبل كتابة أي كود ترحيل لدورة الحياة - لا تخمن النمط من الذاكرة، فأشجار القرار هنا تمنع أخطاء الترحيل الأكثر شيوعًا.
