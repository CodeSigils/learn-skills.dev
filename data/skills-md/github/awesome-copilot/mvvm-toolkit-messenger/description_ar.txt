CommunityToolkit.Mvvm Messenger pub/sub للاتصال المنفصل بين ViewModels (أو أي كائنات). يغطي WeakReferenceMessenger vs StrongReferenceMessenger، وIRecipient<TMessage>، وRequestMessage<T> / AsyncRequestMessage<T> / CollectionRequestMessage<T>، وValueChangedMessage<T>، والقنوات (الرموز المميزة)، ودورة حياة تنشيط ObservableRecipient. استخدم عبر WPF، وWinUI 3، و.NET MAUI، وUno، وAvalonia.
