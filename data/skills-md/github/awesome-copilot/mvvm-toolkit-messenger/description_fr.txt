CommunityToolkit.Mvvm Messenger pub/sub pour une communication découplée entre ViewModels (ou n'importe quel objet). Couvre WeakReferenceMessenger vs StrongReferenceMessenger, IRecipient<TMessage>, RequestMessage<T> / AsyncRequestMessage<T> / CollectionRequestMessage<T>, ValueChangedMessage<T>, les canaux (jetons) et le cycle de vie d'activation d'ObservableRecipient. Utilisation sur WPF, WinUI 3, .NET MAUI, Uno et Avalonia.
