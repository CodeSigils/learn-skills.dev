CommunityToolkit.Mvvm Messenger pub/sub，用于 ViewModel（或任何对象）之间的解耦通信。涵盖 WeakReferenceMessenger 与 StrongReferenceMessenger、IRecipient<TMessage>、RequestMessage<T> / AsyncRequestMessage<T> / CollectionRequestMessage<T>、ValueChangedMessage<T>、通道（令牌）和 ObservableRecipient 激活生命周期。跨 WPF、WinUI 3、.NET MAUI、Uno 和 Avalonia 使用。
