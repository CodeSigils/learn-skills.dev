CommunityToolkit.Mvvm Messenger pub/sub，用於 ViewModel（或任何物件）之間的解耦通訊。涵蓋 WeakReferenceMessenger 與 StrongReferenceMessenger、IRecipient<TMessage>、RequestMessage<T> / AsyncRequestMessage<T> / CollectionRequestMessage<T>、ValueChangedMessage<T>、通道（令牌）和 ObservableRecipient 啟動生命週期。跨 WPF、WinUI 3、.NET MAUI、Uno 和 Avalonia 使用。
