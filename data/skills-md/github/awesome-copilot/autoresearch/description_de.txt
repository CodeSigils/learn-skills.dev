Autonome iterative Experimentierschleife für jede Programmieraufgabe. Führt den Benutzer durch die Definition von Zielen, messbaren Metriken und Umfangseinschränkungen und führt dann eine autonome Schleife aus Codeänderungen, Tests, Messungen und Beibehaltung/Verwerfung der Ergebnisse durch. Inspiriert von Karpathys Autorecherche. VERWENDUNG FÜR: autonome Verbesserung, iterative Optimierung, Experimentierschleife, automatische Forschung, Leistungsoptimierung, automatisiertes Experimentieren, Bergsteigen, Dinge automatisch ausprobieren, Code optimieren, Experimente ausführen, autonome Codierungsschleife. NICHT VERWENDEN FÜR: einmalige Aufgaben, einfache Fehlerbehebungen, Codeüberprüfung oder Aufgaben ohne messbare Metrik.
