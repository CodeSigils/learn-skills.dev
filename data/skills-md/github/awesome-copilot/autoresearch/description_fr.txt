Boucle d'expérimentation itérative autonome pour toute tâche de programmation. Guide l'utilisateur dans la définition d'objectifs, de mesures mesurables et de contraintes de portée, puis exécute une boucle autonome de modifications de code, de tests, de mesures et de conservation/rejet des résultats. Inspiré par l'autorecherche de Karpathy. UTILISER POUR : amélioration autonome, optimisation itérative, boucle d'expérimentation, recherche automatique, réglage des performances, expérimentation automatisée, escalade, essayer des choses automatiquement, optimiser le code, exécuter des expériences, boucle de codage autonome. NE PAS UTILISER POUR : les tâches ponctuelles, les corrections de bugs simples, la révision du code ou les tâches sans métrique mesurable.
