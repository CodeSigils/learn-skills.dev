Rufen Sie diesen Skill auf, wenn Sie Annotationskonfigurationen auf Arize (kategorisch, kontinuierlich, Freiform) erstellen, verwalten oder verwenden oder menschliche Annotationen über das Python SDK auf Projektbereiche anwenden. Konfigurationen sind das Beschriftungsschema für menschliches Feedback zu Spans und anderen Oberflächen in der Arize-Benutzeroberfläche. Auslöser: Annotationskonfiguration, Beschriftungsschema, Schema für menschliches Feedback, Massenannotationsspannen, update_annotations.
