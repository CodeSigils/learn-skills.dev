استخدم هذه المهارة عند إنشاء تكوينات التعليقات التوضيحية أو إدارتها أو استخدامها في Arize (فئوية أو مستمرة أو حرة)، أو عند تطبيق التعليقات التوضيحية البشرية على امتدادات المشروع عبر Python SDK. التكوينات هي مخطط التسمية للتعليقات البشرية على الامتدادات والأسطح الأخرى في Arize UI. المشغلات: تكوين التعليقات التوضيحية، ومخطط التصنيف، ومخطط التعليقات البشرية، وامتدادات التعليقات التوضيحية المجمعة، والتعليقات التوضيحية المحدثة.
