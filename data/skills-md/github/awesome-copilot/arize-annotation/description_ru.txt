ПРИМЕНЯЙТЕ ЭТОТ НАВЫК при создании, управлении или использовании конфигураций аннотаций в Arize (категориальных, непрерывных, произвольной формы) или при применении человеческих аннотаций к фрагментам проекта с помощью Python SDK. Конфигурации — это схема меток для обратной связи между людьми на промежутках и других поверхностях в пользовательском интерфейсе Arize. Триггеры: конфигурация аннотаций, схема меток, схема обратной связи с человеком, диапазоны массовых аннотаций, update_annotations.
