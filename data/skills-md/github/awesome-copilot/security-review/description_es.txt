Escáner de seguridad de base de código impulsado por IA que razona sobre el código como un investigador de seguridad: rastrea flujos de datos, comprende las interacciones de los componentes y detecta vulnerabilidades que las herramientas de coincidencia de patrones pasan por alto. Utilice esta habilidad cuando se le solicite escanear código en busca de vulnerabilidades de seguridad, encontrar errores, verificar inyección SQL, XSS, inyección de comandos, claves API expuestas, secretos codificados, dependencias inseguras, problemas de control de acceso o cualquier solicitud como "¿es seguro mi código?", "revisar problemas de seguridad", "auditar esta base de código" o "verificar vulnerabilidades". Cubre fallas de inyección, errores de autenticación y control de acceso, exposición de secretos, criptografía débil, dependencias inseguras y problemas de lógica empresarial en JavaScript, TypeScript, Python, Java, PHP, Go, Ruby y Rust.
