Scanner di sicurezza della base di codice basato sull'intelligenza artificiale che ragiona sul codice come un ricercatore di sicurezza: traccia i flussi di dati, comprende le interazioni dei componenti e rileva le vulnerabilità che gli strumenti di corrispondenza dei modelli non riescono a cogliere. Utilizza questa abilità quando ti viene chiesto di scansionare il codice per individuare vulnerabilità di sicurezza, trovare bug, verificare la presenza di SQL injection, XSS, command injection, chiavi API esposte, segreti codificati, dipendenze non sicure, problemi di controllo degli accessi o qualsiasi richiesta come "il mio codice è sicuro?", "rivedere per problemi di sicurezza", "controllare questa codebase" o "verificare le vulnerabilità". Copre difetti di iniezione, bug di autenticazione e controllo degli accessi, esposizione di segreti, crittografia debole, dipendenze non sicure e problemi di logica aziendale su JavaScript, TypeScript, Python, Java, PHP, Go, Ruby e Rust.
