KI-gestützter Codebasis-Sicherheitsscanner, der wie ein Sicherheitsforscher über Code nachdenkt – er verfolgt Datenflüsse, versteht Komponenteninteraktionen und erkennt Schwachstellen, die Mustervergleichstools übersehen. Verwenden Sie diese Fähigkeit, wenn Sie aufgefordert werden, Code auf Sicherheitslücken zu scannen, Fehler zu finden, auf SQL-Injection, XSS, Command-Injection, offengelegte API-Schlüssel, fest codierte Geheimnisse, unsichere Abhängigkeiten, Zugriffskontrollprobleme oder andere Anfragen wie „Ist mein Code sicher?“, „Überprüfung auf Sicherheitsprobleme“, „Überprüfen Sie diese Codebasis“ oder „Auf Schwachstellen prüfen“ zu prüfen. Behandelt Injektionsfehler, Authentifizierungs- und Zugriffskontrollfehler, Offenlegung von Geheimnissen, schwache Kryptografie, unsichere Abhängigkeiten und Probleme mit der Geschäftslogik in JavaScript, TypeScript, Python, Java, PHP, Go, Ruby und Rust.
