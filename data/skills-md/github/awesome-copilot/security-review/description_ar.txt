ماسح أمان قاعدة التعليمات البرمجية المدعوم بالذكاء الاصطناعي والذي يفكر في التعليمات البرمجية مثل الباحث الأمني ​​- يتتبع تدفقات البيانات، ويفهم تفاعلات المكونات، ويكتشف نقاط الضعف التي تفوتها أدوات مطابقة الأنماط. استخدم هذه المهارة عندما يُطلب منك فحص التعليمات البرمجية بحثًا عن الثغرات الأمنية، أو العثور على الأخطاء، أو التحقق من إدخال SQL، أو XSS، أو إدخال الأوامر، أو مفاتيح API المكشوفة، أو الأسرار المشفرة، أو التبعيات غير الآمنة، أو مشكلات التحكم في الوصول، أو أي طلب مثل "هل الكود الخاص بي آمن؟"، أو "مراجعة مشكلات الأمان"، أو "تدقيق قاعدة التعليمات البرمجية هذه"، أو "التحقق من الثغرات الأمنية". يغطي عيوب الحقن، وأخطاء المصادقة والتحكم في الوصول، والكشف عن الأسرار، والتشفير الضعيف، والتبعيات غير الآمنة، ومشكلات منطق الأعمال عبر JavaScript، وTypeScript، وPython، وJava، وPHP، وGo، وRuby، وRust.
