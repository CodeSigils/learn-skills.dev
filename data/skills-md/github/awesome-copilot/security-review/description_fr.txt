Scanner de sécurité de base de code alimenté par l'IA qui raisonne sur le code comme un chercheur en sécurité : traçant les flux de données, comprenant les interactions des composants et détectant les vulnérabilités manquées par les outils de correspondance de modèles. Utilisez cette compétence lorsqu'on vous demande d'analyser le code à la recherche de vulnérabilités de sécurité, de rechercher des bogues, de vérifier l'injection SQL, XSS, l'injection de commandes, les clés API exposées, les secrets codés en dur, les dépendances non sécurisées, les problèmes de contrôle d'accès ou toute demande telle que « mon code est-il sécurisé ? Couvre les failles d'injection, les bogues d'authentification et de contrôle d'accès, l'exposition de secrets, la cryptographie faible, les dépendances non sécurisées et les problèmes de logique métier dans JavaScript, TypeScript, Python, Java, PHP, Go, Ruby et Rust.
