Используйте при: сравнении таблиц SQL Server между экземплярами, проверке переноса данных, проверке ETL, обнаружении несоответствия строк, отклонении схемы, отчете о сверке, сравнении производства и промежуточного хранения. Использует драйвер mssql-python с Apache Arrow для быстрой передачи и сравнения столбчатых данных.
