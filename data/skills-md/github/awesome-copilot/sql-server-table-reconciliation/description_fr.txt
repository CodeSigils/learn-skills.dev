À utiliser dans les cas suivants : comparaison de tables SQL Server entre instances, validation de migration de données, vérification ETL, détection d'incompatibilité de lignes, dérive de schéma, rapport de rapprochement, comparaison de production et de préparation. Utilise le pilote mssql-python avec Apache Arrow pour un transfert et une comparaison rapides de données en colonnes.
