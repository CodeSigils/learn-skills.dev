Предоставляет полную, проверенную библиотеку команд сканирования grep для аудита кодовых баз React перед обновлением React 18.3.1 или React 19. Используйте этот навык при проведении аудита миграции — как для агентов реакции18-аудитора, так и для агента реакции19-аудитора. Содержит все шаблоны grep, необходимые для поиска устаревших API, удаленных API, небезопасных методов жизненного цикла, уязвимостей пакетной обработки, проблем с тестовыми файлами, конфликтов зависимостей и удалений, специфичных для React 19. Всегда используйте этот навык при написании команд сканирования аудита — не полагайтесь на память для синтаксиса grep, особенно для многострочных асинхронных шаблонов setState, которые требуют флагов контекста.
