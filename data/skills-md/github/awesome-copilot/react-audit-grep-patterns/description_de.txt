Bietet die vollständige, verifizierte grep-Scan-Befehlsbibliothek zur Prüfung von React-Codebasen vor einem React 18.3.1- oder React 19-Upgrade. Verwenden Sie diese Fähigkeit, wenn Sie eine Migrationsprüfung durchführen – sowohl für die Agenten „react18-auditor“ als auch „react19-auditor“. Enthält alle erforderlichen Grep-Muster, um veraltete APIs, entfernte APIs, unsichere Lebenszyklusmethoden, Batch-Schwachstellen, Probleme mit Testdateien, Abhängigkeitskonflikte und React 19-spezifische Entfernungen zu finden. Verwenden Sie diese Fähigkeit immer, wenn Sie Audit-Scan-Befehle schreiben. Verlassen Sie sich bei der grep-Syntax nicht auf den Speicher, insbesondere nicht bei den mehrzeiligen asynchronen setState-Mustern, die Kontextflags erfordern.
