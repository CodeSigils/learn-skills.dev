Proporciona la biblioteca de comandos grep scan completa y verificada para auditar las bases de código de React antes de una actualización de React 18.3.1 o React 19. Utilice esta habilidad siempre que ejecute una auditoría de migración, tanto para los agentes react18-auditor como para react19-auditor. Contiene todos los patrones grep necesarios para encontrar API obsoletas, API eliminadas, métodos de ciclo de vida inseguros, vulnerabilidades de procesamiento por lotes, problemas con archivos de prueba, conflictos de dependencia y eliminaciones específicas de React 19. Utilice siempre esta habilidad al escribir comandos de análisis de auditoría; no confíe en la memoria para la sintaxis grep, especialmente para los patrones setState asíncronos de varias líneas que requieren indicadores de contexto.
