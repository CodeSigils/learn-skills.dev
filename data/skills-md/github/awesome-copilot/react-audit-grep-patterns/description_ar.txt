يوفر مكتبة أوامر grep scan الكاملة والمعتمدة لتدقيق قواعد تعليمات React قبل ترقية React 18.3.1 أو React 19. استخدم هذه المهارة عند تشغيل تدقيق الترحيل - لكل من وكلاء React18-auditor وreact19-auditor. يحتوي على كل نمط grep اللازم للعثور على واجهات برمجة التطبيقات المهملة، وواجهات برمجة التطبيقات التي تمت إزالتها، وأساليب دورة الحياة غير الآمنة، ونقاط الضعف المجمعة، ومشكلات ملفات الاختبار، وتعارضات التبعية، وعمليات إزالة React 19 المحددة. استخدم هذه المهارة دائمًا عند كتابة أوامر فحص التدقيق - لا تعتمد على الذاكرة لبناء جملة grep، خاصة بالنسبة لأنماط setState غير المتزامنة متعددة الأسطر والتي تتطلب علامات سياق.
