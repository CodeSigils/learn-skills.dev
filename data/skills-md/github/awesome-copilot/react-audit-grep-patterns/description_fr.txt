Fournit la bibliothèque de commandes grep scan complète et vérifiée pour auditer les bases de code React avant une mise à niveau de React 18.3.1 ou React 19. Utilisez cette compétence chaque fois que vous exécutez un audit de migration - pour les agents React18-Auditor et React19-Auditor. Contient tous les modèles grep nécessaires pour rechercher les API obsolètes, les API supprimées, les méthodes de cycle de vie non sécurisées, les vulnérabilités de traitement par lots, les problèmes de fichiers de test, les conflits de dépendances et les suppressions spécifiques à React 19. Utilisez toujours cette compétence lors de l'écriture de commandes d'analyse d'audit - ne comptez pas sur la mémoire pour la syntaxe grep, en particulier pour les modèles setState asynchrones multilignes qui nécessitent des indicateurs de contexte.
