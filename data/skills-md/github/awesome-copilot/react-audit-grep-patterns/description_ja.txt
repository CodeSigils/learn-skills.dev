React 18.3.1 または React 19 のアップグレード前に React コードベースを監査するための、完全な検証済み grep scan コマンド ライブラリを提供します。移行監査を実行するときは常に、このスキルを使用します (react18-auditor エージェントとreact19-auditor エージェントの両方)。非推奨の API、削除された API、安全でないライフサイクル メソッド、バッチ処理の脆弱性、テスト ファイルの問題、依存関係の競合、React 19 固有の削除を見つけるために必要なすべての grep パターンが含まれています。監査スキャン コマンドを作成するときは常にこのスキルを使用してください。grep 構文、特にコンテキスト フラグを必要とする複数行の非同期 setState パターンではメモリに依存しないでください。
