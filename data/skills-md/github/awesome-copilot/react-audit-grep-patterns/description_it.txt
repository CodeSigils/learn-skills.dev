Fornisce la libreria di comandi grep scan completa e verificata per il controllo delle basi di codice React prima di un aggiornamento di React 18.3.1 o React 19. Utilizza questa competenza ogni volta che esegui un audit di migrazione, sia per gli agenti react18-auditor che per react19-auditor. Contiene tutti i pattern grep necessari per trovare API deprecate, API rimosse, metodi del ciclo di vita non sicuri, vulnerabilità in batch, problemi dei file di test, conflitti di dipendenze e rimozioni specifiche di React 19. Utilizza sempre questa abilità quando scrivi comandi di scansione di controllo: non fare affidamento sulla memoria per la sintassi grep, in particolare per i modelli setState asincroni multilinea che richiedono flag di contesto.
