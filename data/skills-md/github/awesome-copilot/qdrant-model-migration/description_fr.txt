Guide l’intégration de la migration de modèles dans Qdrant sans temps d’arrêt. À utiliser lorsque quelqu'un demande « comment changer de modèle d'intégration », « comment migrer des vecteurs », « comment mettre à jour vers un nouveau modèle », « changement de modèle sans temps d'arrêt », « comment réintégrer mes données » ou « puis-je utiliser deux modèles à la fois ». À utiliser également lors de la mise à niveau des dimensions du modèle, du changement de fournisseur ou des modèles de tests A/B.
