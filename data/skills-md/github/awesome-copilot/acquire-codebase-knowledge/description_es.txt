Utilice esta habilidad cuando el usuario solicite explícitamente mapear, documentar o incorporar en una base de código existente. Activa mensajes como "asignar esta base de código", "documentar esta arquitectura", "incorporarme a este repositorio" o "crear documentos de base de código". No active la implementación de funciones de rutina, corrección de errores o ediciones limitadas de código a menos que el usuario solicite descubrimiento a nivel de repositorio.
