Utilisez cette compétence lorsque l'utilisateur demande explicitement de mapper, de documenter ou d'intégrer une base de code existante. Déclenchez des invites telles que « mapper cette base de code », « documenter cette architecture », « m'intégrer à ce dépôt » ou « créer des documents de base de code ». Ne déclenchez pas l'implémentation de fonctionnalités de routine, les corrections de bogues ou les modifications de code restreintes, sauf si l'utilisateur demande une découverte au niveau du référentiel.
