استخدم هذه المهارة عندما يطلب المستخدم صراحة تعيين أو توثيق أو الانضمام إلى قاعدة تعليمات برمجية موجودة. قم بتشغيل مطالبات مثل "تعيين قاعدة التعليمات البرمجية هذه" أو "توثيق هذه البنية" أو "إضافتي إلى هذا الريبو" أو "إنشاء مستندات قاعدة التعليمات البرمجية". لا تقم بتشغيل تنفيذ الميزات الروتينية، أو إصلاحات الأخطاء، أو تعديلات التعليمات البرمجية الضيقة ما لم يطلب المستخدم الاكتشاف على مستوى المستودع.
