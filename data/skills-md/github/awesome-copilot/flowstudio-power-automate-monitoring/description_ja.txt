FlowStudio MCP キャッシュ ストアを使用して、Power Automate フローの健全性を監視し、障害率を追跡し、テナント資産をインベントリします。ライブ API はトップレベルの実行ステータスのみを返します。ストア ツールは、PA API にレート制限を課すことなく、高速キャッシュから集約された統計情報、修復ヒントを含む実行ごとの障害の詳細、メーカー アクティビティ、Power Apps インベントリを表示します。フローの健全性の確認、失敗しているフローの検索、失敗率の取得、エラー傾向の確認、監視が有効になっているすべてのフローの一覧表示、フローの構築者を確認する、非アクティブなメーカーの検索、Power Apps のインベントリ、環境または接続数の確認、フローの概要、またはテナント全体の健全性の概要の取得を求める場合は、このスキルをロードします。 FlowStudio for Teams または MCP Pro+ サブスクリプションが必要です — https://mcp.flowstudio.app を参照してください
