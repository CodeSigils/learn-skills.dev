Descubre e integra API de terceros utilizando el servidor MCP contextual. Utiliza `fetch_api` para buscar SDK de API disponibles, `preguntar` para obtener orientación sobre la integración, `model_search` y `endpoint_search` para obtener detalles del SDK. Úselo cuando el usuario solicite integrar una API de terceros, agregar un cliente API, implementar funciones con una API externa o trabajar con cualquier API o SDK de terceros.
