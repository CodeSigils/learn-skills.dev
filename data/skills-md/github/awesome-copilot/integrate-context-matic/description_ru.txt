Обнаруживает и интегрирует сторонние API с помощью контекстного сервера MCP. Использует fetch_api для поиска доступных API SDK, запрос руководства по интеграции, model_search и endpoint_search для получения подробной информации о SDK. Используйте, когда пользователь запрашивает интеграцию стороннего API, добавление клиента API, реализацию функций с помощью внешнего API или работу с любым сторонним API или SDK.
