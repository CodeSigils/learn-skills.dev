Rileva e integra API di terze parti utilizzando il server MCP contestuale. Utilizza "fetch_api" per trovare gli SDK API disponibili, "ask" per indicazioni sull'integrazione, "model_search" e "endpoint_search" per i dettagli dell'SDK. Da utilizzare quando l'utente richiede di integrare un'API di terze parti, aggiungere un client API, implementare funzionalità con un'API esterna o lavorare con API o SDK di terze parti.
