Erkennt und integriert APIs von Drittanbietern mithilfe des kontextmatischen MCP-Servers. Verwendet „fetch_api“, um verfügbare API-SDKs zu finden, „ask“ für Integrationsanleitungen, „model_search“ und „endpoint_search“ für SDK-Details. Verwenden Sie diese Option, wenn der Benutzer eine API eines Drittanbieters integrieren, einen API-Client hinzufügen, Funktionen mit einer externen API implementieren oder mit einer API oder einem SDK eines Drittanbieters arbeiten möchte.
