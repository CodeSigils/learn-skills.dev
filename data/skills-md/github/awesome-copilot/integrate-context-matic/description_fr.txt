Découvre et intègre des API tierces à l'aide du serveur MCP contextuel. Utilise `fetch_api` pour trouver les SDK API disponibles, `ask` pour des conseils d'intégration, `model_search` et `endpoint_search` pour les détails du SDK. À utiliser lorsque l'utilisateur demande à intégrer une API tierce, à ajouter un client API, à implémenter des fonctionnalités avec une API externe ou à travailler avec une API ou un SDK tiers.
