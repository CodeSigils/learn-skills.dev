يكتشف ويدمج واجهات برمجة التطبيقات التابعة لجهات خارجية باستخدام خادم MCP المتوافق مع السياق. يستخدم `fetch_api` للعثور على مجموعات SDK لواجهة برمجة التطبيقات المتاحة، و`اطلب` للحصول على إرشادات التكامل، و`model_search`، و`endpoint_search` للحصول على تفاصيل SDK. يُستخدم عندما يطلب المستخدم دمج واجهة برمجة تطبيقات تابعة لجهة خارجية، أو إضافة عميل واجهة برمجة التطبيقات، أو تنفيذ الميزات باستخدام واجهة برمجة تطبيقات خارجية، أو العمل مع أي واجهة برمجة تطبيقات أو مجموعة أدوات تطوير البرامج (SDK) تابعة لجهة خارجية.
