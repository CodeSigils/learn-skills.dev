Ajoutez une extension de communauté au catalogue Spec Kit à partir d’une soumission de problème GitHub. UTILISER POUR : traiter les problèmes de soumission d'extensions, valider les entrées de catalogue, mettre à jour catalog.community.json et docs/community/extensions.md, créer des PR. NE PAS UTILISER POUR : la création de nouvelles extensions à partir de zéro ou le travail d'extension de première partie.
