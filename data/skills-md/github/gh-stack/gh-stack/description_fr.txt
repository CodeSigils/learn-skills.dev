Gérez les branches empilées et les demandes d'extraction avec l'extension CLI GitHub gh-stack. À utiliser lorsque l'utilisateur souhaite créer, pousser, rebaser, synchroniser, naviguer ou afficher des piles de PR dépendants. Déclencheurs sur des tâches impliquant des différences empilées, des demandes d'extraction dépendantes, des chaînes de branches ou des workflows de révision de code incrémentiels.
