Используйте, когда пользователь спрашивает об умной торговле сигналами денег, 聪明钱策略, подписке KOL, отслеживании китов, сигнальном боте, 信号策略, 跟单策略, 同车地址, экономичном TP/SL, управлении рисками сеанса или хочет запустить/настроить/мониторинг бота-трекера сигналов. Охватывает: опрос OKX Signal API (SmartMoney/KOL/Whale), 17-точечный фильтр безопасности с проверками Dev/Bundler, тейк-профит с учетом затрат со смещением безубыточности, стоп-лосс с затуханием во времени, трейлинг-стоп, управление сессионными рисками (последовательная пауза для убытков / остановка кумулятивных убытков). НЕ используйте для сканирования токенов мемов — используйте Strategy-memepump-scanner. НЕ используйте для сеточной торговли — используйте Strategy-grid-trade. НЕ используйте для поиска сигналов вручную — используйте okx-dex-signal.
