Используйте, когда пользователь спрашивает о рейтинговом снайпере SOL, снайперском снайпе топ-токенов Solana, боте трендовых токенов, автоматической торговле на основе рейтинга, 排行榜狙击, снайперском боте SOL, торговле импульсными очками, стратегии выхода из рейтинга или хочет запустить/настроить/мониторинг рейтингового снайперского бота. Обложки: автоматическое снайпинг токенов SOL, попадающих в рейтинг тенденций OKX, 3-уровневый фильтр безопасности (Slot Guard + Advanced Safety + Holder Risk Scan), оценка импульса (0-125), 6-уровневая система выхода (ранговый выход + жесткая остановка + быстрая остановка + трейлинг + остановка по времени + градиент TP), уведомления Telegram и настраиваемые параметры через файл конфигурации JSON. НЕ используйте для ручного поиска токенов — используйте okx-dex-token. НЕ используйте для сеточной торговли — используйте Strategy-grid-trade. НЕ используйте для сканирования memepump — используйте Strategy-memepump-scanner.
