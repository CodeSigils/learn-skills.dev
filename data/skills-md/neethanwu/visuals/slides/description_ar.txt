ينشئ عروض تقديمية بتنسيق HTML جميلة مكونة من ملف واحد مع تصميم احترافي ورسوم متحركة وتأثيرات تفاعلية. يتم تشغيله عندما يريد المستخدم إنشاء شرائح أو عرض تقديمي أو عرض تقديمي أو عرض تقديمي عرضي أو محاضرة أو كلمة رئيسية أو محاضرة. يتم تفعيله على "إنشاء شرائح"، "إنشاء عرض تقديمي"، "مجموعة شرائح"، "إنشاء مجموعة شرائح"، "عرض تقديمي حول"، "شرائح لمحادثتي"، "مجموعة عروض تقديمية مخطّطة لـ"، "تحويل هذا إلى شرائح"، "تقديم هذا"، "/الشرائح". يتم تشغيله أيضًا عندما يقوم المستخدم بتجميع محتوى (ملاحظات، مخططات تفصيلية، بحث) ويريد تحويله إلى عرض تقديمي مرئي.
