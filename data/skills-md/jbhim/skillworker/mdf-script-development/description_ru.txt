Используйте при разработке сценариев внешнего клиента Yonyou MDF (Model-Driven Framework) для счетов, списков и форм. Триггеры включают обработку событий viewModel, вызовы API cb.rest, операции с сеткой/полем, перехватчики жизненного цикла счетов (customInit, afterLoadData, beforeValidate, beforePush), фильтрацию ссылок, бизнес-потоки инвентаризации/активов и работу с файлами diwork.
