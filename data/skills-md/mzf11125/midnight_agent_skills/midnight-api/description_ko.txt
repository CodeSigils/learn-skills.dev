분산형 애플리케이션 구축을 위한 Midnight Network API에 대한 종합 가이드입니다. 사용자가 Compact Runtime, DApp Connector, ZSwap, Wallet 및 Ledger API를 포함한 Midnight API를 통합하고, DApp을 Midnight 지갑에 연결하고, 프로그래밍 방식으로 영지식 증명을 생성 및 확인하고, 트랜잭션 및 블록체인 상태를 관리하고, Compact 스마트 계약을 배포 및 상호 작용하고, 인덱서를 통해 블록체인 데이터를 쿼리하고, 지갑 기능을 구현하고, Zswap 개인 거래를 처리하고, Midnight에서 완전한 web3 애플리케이션을 구축해야 하는 경우에 사용합니다.
