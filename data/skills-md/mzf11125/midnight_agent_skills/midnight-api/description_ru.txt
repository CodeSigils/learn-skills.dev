Подробное руководство по API Midnight Network для создания децентрализованных приложений. Используйте, когда пользователям необходимо интегрировать API Midnight, включая API Compact Runtime, DApp Connector, ZSwap, Wallet и Ledger API, подключать DApps к кошелькам Midnight, программно генерировать и проверять доказательства с нулевым разглашением, управлять транзакциями и состоянием блокчейна, развертывать смарт-контракты Compact и взаимодействовать с ними, запрашивать данные блокчейна через индексатор, реализовывать функции кошелька, обрабатывать частные транзакции Zswap и создавать полноценные веб3-приложения в Midnight.
