Guide complet des API Midnight Network pour la création d'applications décentralisées. À utiliser lorsque les utilisateurs doivent intégrer les API Midnight, notamment les API Compact Runtime, DApp Connector, ZSwap, Wallet et Ledger, connecter les DApp aux portefeuilles Midnight, générer et vérifier des preuves sans connaissance par programme, gérer les transactions et l'état de la blockchain, déployer et interagir avec les contrats intelligents Compact, interroger les données de la blockchain via un indexeur, implémenter la fonctionnalité de portefeuille, gérer les transactions privées Zswap et créer des applications Web3 complètes sur Midnight.
