分散型アプリケーションを構築するための Midnight Network API の包括的なガイド。ユーザーが、Compact Runtime、DApp Connector、ZSwap、Wallet、Ledger API を含む Midnight API の統合、DApps の Midnight ウォレットへの接続、プログラムによるゼロ知識証明の生成と検証、トランザクションとブロックチェーンの状態の管理、Compact スマート コントラクトのデプロイと操作、インデクサーを介したブロックチェーン データのクエリ、ウォレット機能の実装、Zswap プライベート トランザクションの処理、完全な Web3 アプリケーションの構築を Midnight で行う必要がある場合に使用します。
