دليل شامل لواجهات برمجة التطبيقات لشبكة Midnight Network لبناء التطبيقات اللامركزية. يُستخدم عندما يحتاج المستخدمون إلى دمج واجهات برمجة التطبيقات Midnight APIs بما في ذلك Compact Runtime وDApp Connector وZSwap وWallet وLedger APIs، وربط التطبيقات اللامركزية بمحافظ Midnight، وإنشاء إثباتات المعرفة الصفرية والتحقق منها برمجيًا، وإدارة المعاملات وحالة blockchain، والنشر والتفاعل مع العقود الذكية المدمجة، والاستعلام عن بيانات blockchain عبر المفهرس، وتنفيذ وظائف المحفظة، والتعامل مع معاملات Zswap الخاصة، وإنشاء تطبيقات web3 كاملة في منتصف الليل.
