Umfassender Leitfaden zu Midnight Network APIs zum Erstellen dezentraler Anwendungen. Wird verwendet, wenn Benutzer Midnight-APIs einschließlich Compact Runtime, DApp Connector, ZSwap, Wallet und Ledger-APIs integrieren, DApps mit Midnight-Wallets verbinden, wissensfreie Beweise programmgesteuert generieren und überprüfen, Transaktionen und Blockchain-Status verwalten, Compact-Smart-Verträge bereitstellen und mit ihnen interagieren, Blockchain-Daten über einen Indexer abfragen, Wallet-Funktionen implementieren, private Zswap-Transaktionen verarbeiten und komplette Web3-Anwendungen auf Midnight erstellen müssen.
