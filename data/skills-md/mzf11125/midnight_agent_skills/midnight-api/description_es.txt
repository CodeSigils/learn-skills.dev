Guía completa de las API de Midnight Network para crear aplicaciones descentralizadas. Úselo cuando los usuarios necesiten integrar las API de Midnight, incluidas Compact Runtime, DApp Connector, ZSwap, Wallet y Ledger API, conectar DApps a billeteras Midnight, generar y verificar pruebas de conocimiento cero mediante programación, administrar transacciones y el estado de blockchain, implementar e interactuar con contratos inteligentes compactos, consultar datos de blockchain a través de un indexador, implementar la funcionalidad de billetera, manejar transacciones privadas de Zswap y crear aplicaciones web3 completas en Midnight.
