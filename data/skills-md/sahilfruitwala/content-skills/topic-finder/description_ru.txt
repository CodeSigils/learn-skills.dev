Находите свежие, релевантные темы контента для ниши автора, извлекая реальные заголовки из веб-поиска и RSS-каналов, выполняя их дедупликацию и передавая пакет оценщику виральности заголовков для ранжирования. ИСПОЛЬЗУЙТЕ ЭТОТ НАВЫК, когда пользователь спрашивает: «О чем мне опубликовать/снять видео», «найдите для меня актуальные темы», «что происходит в моей нише», «дайте мне идеи для контента», «что стоит осветить на этой неделе» или иным образом хочет, чтобы для него были ИСТОЧЕНЫ кандидаты на темы/заголовки (а не просто оценены). По умолчанию используется ниша AI/tech/software/полезных приложений, но работает для ЛЮБОЙ ниши, которую называет пользователь. В сочетании с заголовком-оценщиком вирусности: этот навык привлекает кандидатов, этот навык их оценивает.
