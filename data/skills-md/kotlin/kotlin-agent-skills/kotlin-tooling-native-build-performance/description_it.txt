Diagnostica e corregge la compilazione e il collegamento lenti di Kotlin/nativo nei progetti multipiattaforma Kotlin destinati a iOS. Da utilizzare quando l'utente segnala build iOS o framework condiviso lente, attività linkDebug*/linkRelease* o XCFramework lunghe, build CI a freddo che scaricano nuovamente la toolchain Kotlin/nativa, KSP o altro codice generato sul percorso nativo, utilizzo di transitiveExport o richiede un piano di prestazioni della build di sviluppo locale rispetto a CI.
