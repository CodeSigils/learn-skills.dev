تشخيص وإصلاح عمليات التجميع والربط البطيئة لـ Kotlin/Native في مشاريع Kotlin Multiplatform التي تستهدف iOS. يُستخدم عندما يبلغ المستخدم عن بطء نظام التشغيل iOS أو إنشاءات إطار العمل المشترك، أو مهام linkDebug*/linkRelease* أو XCFramework الطويلة، أو إنشاءات CI الباردة التي تعيد تنزيل سلسلة أدوات Kotlin/Native، أو KSP أو تعليمات برمجية أخرى تم إنشاؤها على المسار الأصلي، أو استخدام TransitiveExport، أو يطلب خطة أداء تطوير محلي مقابل بناء CI.
