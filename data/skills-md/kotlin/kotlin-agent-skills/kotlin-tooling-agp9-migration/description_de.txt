Migriert Kotlin Multiplatform (KMP)-Projekte zum Android Gradle Plugin 9.0+. Behandelt den Plugin-Ersatz (com.android.kotlin.multiplatform.library), die Modulaufteilung, die DSL-Migration und die neue Standardprojektstruktur. Verwenden Sie diese Option, wenn Sie AGP aktualisieren, wenn der Build aufgrund von KMP+AGP-Inkompatibilität fehlschlägt oder wenn der Benutzer AGP 9.0, das Android-Multiplattform-Plugin, die KMP-Migration oder com.android.kotlin.multiplatform.library erwähnt.
