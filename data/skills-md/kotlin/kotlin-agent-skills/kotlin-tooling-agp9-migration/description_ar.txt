ترحيل مشاريع Kotlin Multiplatform (KMP) إلى Android Gradle Plugin 9.0+. يتعامل مع استبدال البرنامج المساعد (com.android.kotlin.multiplatform.library)، وتقسيم الوحدة، وترحيل DSL، وبنية المشروع الافتراضية الجديدة. يُستخدم عند ترقية AGP، أو عند فشل الإنشاء بسبب عدم توافق KMP+AGP، أو عندما يذكر المستخدم AGP 9.0، أو المكون الإضافي android multiplatform، أو ترحيل KMP، أو com.android.kotlin.multiplatform.library.
