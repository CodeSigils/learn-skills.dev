Переносит мультиплатформенные проекты Kotlin (KMP) на плагин Android Gradle 9.0+. Управляет заменой плагинов (com.android.kotlin.multiplatform.library), разделением модулей, миграцией DSL и новой структурой проекта по умолчанию. Используйте при обновлении AGP, при сбое сборки из-за несовместимости KMP+AGP или когда пользователь упоминает AGP 9.0, многоплатформенный плагин Android, миграцию KMP или com.android.kotlin.multiplatform.library.
