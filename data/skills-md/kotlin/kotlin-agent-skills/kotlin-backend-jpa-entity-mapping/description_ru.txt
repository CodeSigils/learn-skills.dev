Правильно моделируйте код персистентности Kotlin для Spring Data JPA и Hibernate. Охватывает дизайн сущностей, идентичность и равенство, ограничения уникальности, отношения, планы выборки и общие ловушки ORM (объектно-реляционное сопоставление), специфичные для Kotlin. Используйте при создании или проверке сущностей JPA (Java Persistence API), диагностике N+1 или LazyInitializationException, размещении индексов и правил уникальности или предотвращении ошибок, специфичных для Kotlin, таких как сущности класса данных и неработающие равенства/hashCode.
