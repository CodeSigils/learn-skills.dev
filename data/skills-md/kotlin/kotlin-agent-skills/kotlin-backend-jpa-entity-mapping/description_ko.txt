Spring Data JPA 및 Hibernate에 대해 Kotlin 지속성 코드를 올바르게 모델링합니다. Kotlin과 관련된 엔터티 디자인, ID 및 동등성, 고유성 제약 조건, 관계, 가져오기 계획, 일반적인 ORM(Object-Relational Mapping) 트랩을 다룹니다. JPA(Java Persistence API) 항목을 생성 또는 검토하고, N+1 또는 LazyInitializationException을 진단하고, 색인 및 고유성 규칙을 배치하거나, ​​데이터 클래스 항목 및 손상된 equals/hashCode와 같은 Kotlin 관련 버그를 방지할 때 사용합니다.
