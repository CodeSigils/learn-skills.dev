نموذج كود Kotlin المستمر بشكل صحيح لـ Spring Data JPA وHibernate. يغطي تصميم الكيان، والهوية والمساواة، وقيود التفرد، والعلاقات، وخطط الجلب، ومصائد ORM (رسم الخرائط العلائقية للكائنات) الشائعة الخاصة بـ Kotlin. يُستخدم عند إنشاء أو مراجعة كيانات JPA (Java Persistence API)، أو تشخيص N+1 أو LazyInitializationException، أو وضع الفهارس وقواعد التفرد، أو منع الأخطاء الخاصة بـ Kotlin مثل كيانات فئة البيانات ورمز التجزئة/المساواة المعطلة.
