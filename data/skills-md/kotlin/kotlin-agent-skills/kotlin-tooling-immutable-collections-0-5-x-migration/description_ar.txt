قم بترحيل كود Kotlin (وJava) من kotlinx.collections.immutable 0.3.x / 0.4.x إلى أحدث 0.5.x. يقوم السطر 0.5.x بإعادة تسمية كل طريقة إرجاع نسخ في PersistentList / PersistentMap / PersistentSet / PersistentCollection إلى نموذج مشارك لكل KEEP-0459 (add→adding، RemoveAt→removingAt، set→replacingAt، put→putting، Clear→cleared، …) ويتجاهل الأسماء القديمة (تحذير، مع استبدال مع). مدفوعًا بواسطة المترجم: قم برفع الإصدار، وإعادة الترجمة، وتطبيق إعادة تسمية كل أسماء تحذيرات الإهمال. يُستخدم عندما يذكر المستخدم kotlinx.collections.immutable 0.5.x، أو ترحيل PersistentList، أو "استخدم إضافة () بدلاً من ذلك"، أو KEEP-0459، أو يرى تحذيرات الإهمال من kotlinx.collections.immutable.
