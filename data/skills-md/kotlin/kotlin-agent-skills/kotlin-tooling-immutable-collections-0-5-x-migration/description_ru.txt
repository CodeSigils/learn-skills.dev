Перенесите код Kotlin (и Java) из kotlinx.collections.immutable 0.3.x/0.4.x в последнюю версию 0.5.x. Строка 0.5.x переименовывает каждый метод возврата копирования в PersistentList/PersistentMap/PersistentSet/PersistentCollection в причастную форму согласно KEEP-0459 (add→добавление, removeAt→removingAt, set→replacingAt, put→putting,clear→cleared,…) и объявляет устаревшими старые имена (ПРЕДУПРЕЖДЕНИЕ, с Заменить на). Управляется компилятором: увеличьте версию, перекомпилируйте и примените переименование каждого имени предупреждения об устаревании. Используйте, когда пользователь упоминает kotlinx.collections.immutable 0.5.x, миграцию PersistentList, «Вместо этого используйте add()», KEEP-0459 или видит предупреждения об устаревании от kotlinx.collections.immutable.
