Kotlin (および Java) コードを kotlinx.collections.immutable 0.3.x / 0.4.x から最新の 0.5.x に移行します。 0.5.x 行は、PersistentList / PersistentMap / PersistentSet / PersistentCollection 上のすべてのコピーを返すメソッドの名前を KEEP-0459 に従って分詞形式に変更し (add→adding、removeAt→removingAt、set→replacingAt、put→putting、clear→cleared、…)、古い名前を非推奨にします (警告、ReplaceWith)。コンパイラによって駆動されます。バージョンを上げ、再コンパイルし、各非推奨警告名の変更を適用します。ユーザーが kotlinx.collections.immutable 0.5.x、PersistentList の移行、「代わりにadding() を使用してください」、KEEP-0459 について言及した場合、または kotlinx.collections.immutable から非推奨の警告が表示された場合に使用します。
