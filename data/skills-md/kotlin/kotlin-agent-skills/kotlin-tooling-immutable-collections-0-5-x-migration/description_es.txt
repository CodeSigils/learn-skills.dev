Migre el código de Kotlin (y Java) desde kotlinx.collections.immutable 0.3.x/0.4.x a la última versión 0.5.x. La línea 0.5.x cambia el nombre de cada método de devolución de copias en PersistentList / PersistentMap / PersistentSet / PersistentCollection a una forma participial según KEEP-0459 (add→adding, removeAt→removingAt, set→replacingAt, put→putting, clear→cleared,…) y desaprueba los nombres antiguos (ADVERTENCIA, con Reemplazar con). Impulsado por el compilador: aumente la versión, vuelva a compilar y aplique el cambio de nombre a cada nombre de advertencia de obsolescencia. Úselo cuando el usuario mencione kotlinx.collections.immutable 0.5.x, migración de PersistentList, "Usar add() en su lugar", KEEP-0459, o vea advertencias de obsolescencia de kotlinx.collections.immutable.
