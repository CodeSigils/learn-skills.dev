Migrez le code Kotlin (et Java) de kotlinx.collections.immutable 0.3.x/0.4.x vers la dernière version 0.5.x. La ligne 0.5.x renomme chaque méthode de retour de copie sur PersistentList / PersistentMap / PersistentSet / PersistentCollection en une forme participative selon KEEP-0459 (add→adding, RemoveAt→removingAt, set→replacingAt, put→putting, clear→cleared,…) et déprécie les anciens noms (AVERTISSEMENT, avec ReplaceWith). Piloté par le compilateur : modifiez la version, recompilez et appliquez le renommage de chaque nom d'avertissement de dépréciation. À utiliser lorsque l'utilisateur mentionne kotlinx.collections.immutable 0.5.x, la migration PersistentList, "Utiliser l'ajout () à la place", KEEP-0459, ou voit des avertissements de dépréciation de kotlinx.collections.immutable.
