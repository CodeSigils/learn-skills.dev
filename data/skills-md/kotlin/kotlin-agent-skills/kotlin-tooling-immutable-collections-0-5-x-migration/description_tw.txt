將 Kotlin（和 Java）程式碼從 kotlinx.collections.immutable 0.3.x / 0.4.x 遷移到最新的 0.5.x。 0.5.x 行根據 KEEP-0459 將 PersistentList / PercientMap / PercientSet / PercientCollection 上的每個複製返回方法重新命名為分詞形式（add→adding、removeAt→removingAt、set→replacingAtput、→putting、clear→pputtingting.由編譯器驅動：更改版本、重新編譯並套用重命名每個棄用警告名稱。當使用者提及 kotlinx.collections.immutable 0.5.x、PersistentList 遷移、「使用adding() 取代」、KEEP-0459 或看到來自 kotlinx.collections.immutable 的棄用警告時使用。
