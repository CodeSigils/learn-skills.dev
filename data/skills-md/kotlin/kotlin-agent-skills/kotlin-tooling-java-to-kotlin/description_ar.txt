يُستخدم عند تحويل ملفات مصدر Java إلى Kotlin الاصطلاحية، عندما يذكر المستخدم "java إلى kotlin"، أو "j2k"، أو "تحويل java"، أو "ترحيل java إلى kotlin"، أو عند العمل مع ملفات .java التي تحتاج إلى أن تصبح ملفات .kt. يتعامل مع التحويل المدرك لإطار العمل لـ Spring وLombok وHibernate وJackson وMicronaut وQuarkus وDagger/Hilt وRxJava وJUnit وGuice وRetrofit وMockito.
