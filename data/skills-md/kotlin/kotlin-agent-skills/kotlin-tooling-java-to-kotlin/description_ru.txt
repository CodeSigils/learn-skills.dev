Используйте при преобразовании исходных файлов Java в идиоматический Kotlin, когда пользователь упоминает «java в kotlin», «j2k», «конвертировать java», «перенести Java в kotlin» или при работе с файлами .java, которые должны стать файлами .kt. Осуществляет преобразование с учетом платформы для Spring, Lombok, Hibernate, Jackson, Micronaut, Quarkus, Dagger/Hilt, RxJava, JUnit, Guice, Retrofit и Mockito.
