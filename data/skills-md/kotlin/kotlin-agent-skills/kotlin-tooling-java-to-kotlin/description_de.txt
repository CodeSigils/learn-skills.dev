Wird verwendet, wenn Sie Java-Quelldateien in das idiomatische Kotlin konvertieren, wenn der Benutzer „Java zu Kotlin“, „j2k“, „Java konvertieren“, „Java nach Kotlin migrieren“ erwähnt oder wenn Sie mit .java-Dateien arbeiten, die in .kt-Dateien umgewandelt werden müssen. Verwaltet die Framework-fähige Konvertierung für Spring, Lombok, Hibernate, Jackson, Micronaut, Quarkus, Dagger/Hilt, RxJava, JUnit, Guice, Retrofit und Mockito.
