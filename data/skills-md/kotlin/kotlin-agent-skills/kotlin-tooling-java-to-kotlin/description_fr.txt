À utiliser lors de la conversion de fichiers source Java en Kotlin idiomatique, lorsque l'utilisateur mentionne « Java vers Kotlin », « j2k », « convertir Java », « migrer Java vers Kotlin » ou lorsque vous travaillez avec des fichiers .java qui doivent devenir des fichiers .kt. Gère la conversion compatible avec le framework pour Spring, Lombok, Hibernate, Jackson, Micronaut, Quarkus, Dagger/Hilt, RxJava, JUnit, Guice, Retrofit et Mockito.
