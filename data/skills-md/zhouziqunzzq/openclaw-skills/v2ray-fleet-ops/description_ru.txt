Управляйте многоузловым парком V2Ray через SSH с таргетингом с учетом ролей (реле, выход, плоскость управления), включая проверки работоспособности, осторожные обновления ОС и безопасное обслуживание с учетом конфликтов зависимостей для смешанных узлов Debian/CentOS. Используйте, когда пользователи просят проверить состояние узла, запустить обновления пакета, проверить службы docker/v2ray или обслуживать парк VPS V2Ray/SS-панели.
