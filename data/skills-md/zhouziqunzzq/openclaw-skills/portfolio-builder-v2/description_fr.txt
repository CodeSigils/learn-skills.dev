À utiliser pour travailler avec le projet Portfolio-Builder v2 et son agent CLI. Comprend la configuration de l'environnement, les installations modifiables, les points d'entrée/sous-commandes CLI et les flux de travail de score de régime (y compris l'actualisation des données de marché). Déclenchez-le lorsqu'on vous demande d'effectuer des vérifications de régime, de récupérer des données de marché ou de configurer le dépôt de création de portefeuille v2.
