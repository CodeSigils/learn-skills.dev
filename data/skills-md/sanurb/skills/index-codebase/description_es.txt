Indexe una base de código para comprender el código del agente mediante codemogger (búsqueda semántica + de palabras clave) y cx (navegación por símbolos). Opcionalmente, agregue zoekt (expresión regular de trigrama). Úselo al prepararse para el análisis de arquitectura, explorar una base de código desconocida, incorporarse a un proyecto o cuando grep/ripgrep devuelva demasiadas coincidencias irrelevantes. NO lo use si los índices ya existen y están actualizados, para activos sin código o para búsquedas de un solo archivo donde grep es suficiente.
