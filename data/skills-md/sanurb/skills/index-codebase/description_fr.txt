Indexez une base de code pour la compréhension du code de l'agent à l'aide de codemogger (recherche sémantique + mot-clé) et cx (navigation par symboles). Ajoutez éventuellement zoekt (regex trigramme). À utiliser lors de la préparation d'une analyse d'architecture, de l'exploration d'une base de code inconnue, de l'intégration à un projet ou lorsque grep/ripgrep renvoie trop de correspondances non pertinentes. Ne pas utiliser si les index existent déjà et sont à jour, pour les ressources non codées ou pour les recherches de fichiers uniques où grep suffit.
