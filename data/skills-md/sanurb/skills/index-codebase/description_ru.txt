Индексируйте кодовую базу для понимания кода агента с помощью codemogger (семантический поиск + поиск по ключевым словам) и cx (навигация по символам). При желании добавьте zoekt (регулярное выражение триграммы). Используйте при подготовке к анализу архитектуры, изучении незнакомой кодовой базы, включении в проект или когда grep/ripgrep возвращает слишком много нерелевантных совпадений. НЕ используйте, если индексы уже существуют и являются текущими, для ресурсов, не связанных с кодом, или для поиска по одному файлу, где достаточно grep.
