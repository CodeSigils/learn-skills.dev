Android Jetpack Compose 用のマテリアル デザイン 3 Expressive (MD3E) デザイン システム スキル。このスキルは、テーマ (カラー スキーム、タイポグラフィ、形状、モーション)、コンポーネントの実装 (ボタン、カード、ナビゲーション、FAB、フローティング ツールバー、ボタン グループなど)、およびデザイン ガイダンス (どのコンポーネントをいつ使用するか、M3 と M3E の違い、表現力豊かなデザイン原則) を含む、マテリアル 3 / マテリアル 3 表現力豊かなデザイン言語を使用して Android UI を構築するときに使用する必要があります。 MD3E (Android 16 をターゲットとして 2025 年にリリースされた進化版) とベースライン M3 (多くのコンポーネントは M3 仕様のみを持つ) の両方をカバーします。マテリアル 3 Expressive、MD3E、マテリアル デザイン 3、M3 テーマ、マテリアルExpressiveTheme、Compose マテリアル 3 コンポーネントなどのリクエスト、または Google マテリアル デザイン ガイドラインに従う必要がある Android UI の設計/構築時にトリガーされます。
