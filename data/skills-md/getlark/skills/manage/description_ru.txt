Этот навык следует использовать, когда пользователь запрашивает «составить список рабочих процессов», «показать рабочие процессы getlark», «получить подробную информацию о рабочем процессе», «архивировать рабочий процесс», «обновить рабочий процесс», «составить список групп рабочих процессов», «управлять секретными контекстами», «показать выполнения», «показать ремонты», «показать поколения», «показать события» или запускает `/getlark:manage`. Охватывает операции чтения/обновления/архивирования всех ресурсов getlark и форматирует CLI JSON в виде удобных для пользователя таблиц. Используйте «create-workflow» для создания новых рабочих процессов и «invoke-workflow» (или «validate-branch») для их запуска — этот навык никогда не запускает выполнение, он только проверяет и изменяет метаданные.
