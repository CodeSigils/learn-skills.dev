Cette compétence doit être utilisée lorsque l'utilisateur demande de "lister les workflows", "afficher les workflows getlark", "obtenir les détails du workflow", "archiver un workflow", "mettre à jour un workflow", "lister les groupes de workflow", "gérer les contextes secrets", "afficher les exécutions", "afficher les réparations", "afficher les générations", "afficher les événements", ou exécute `/getlark:manage`. Couvre les opérations de lecture/mise à jour/archivage sur toutes les ressources et formats getlark CLI JSON sous forme de tables conviviales. Utilisez « create-workflow » pour créer de nouveaux workflows et « invoke-workflow » (ou « validate-branch ») pour les exécuter — cette compétence ne déclenche jamais d'exécutions, elle inspecte et mute uniquement les métadonnées.
