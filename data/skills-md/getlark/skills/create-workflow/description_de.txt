Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „einen Workflow erstellen“, „einen Getlark-Test erstellen“, „einen End-to-End-Test hinzufügen“, „einen Larkci-Workflow erstellen“ auffordert oder „/getlark:create-workflow“ ausführt. Konvertiert eine Testbeschreibung in natürlicher Sprache (Ziel + geordnete Schritte; Ziel kann eine URL, ein API-Endpunkt, eine CLI-Binärdatei, ein Skript oder eine andere Softwareoberfläche sein) in einen „getlark Workflows Create“-Aufruf mit einem automatisch generierten Namen. Bevorzugen Sie „manage“, wenn der Benutzer einen vorhandenen Workflow aktualisieren oder archivieren möchte, und „invoke-workflow“, wenn er einen ausführen möchte – dieser Skill *erstellt* nur neue Workflows.
