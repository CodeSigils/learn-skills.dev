Cette compétence doit être utilisée lorsque l'utilisateur demande de « créer un workflow », « créer un test getlark », « ajouter un test de bout en bout », « créer un workflow larkci » ou exécute `/getlark:create-workflow`. Convertit une description de test en langage naturel (cible + étapes ordonnées ; la cible peut être une URL, un point de terminaison d'API, un binaire CLI, un script ou toute autre surface logicielle) en une invocation « getlark workflows create » avec un nom généré automatiquement. Préférez « gérer » lorsque l'utilisateur souhaite mettre à jour ou archiver un workflow existant, et « invoke-workflow » lorsqu'il souhaite en exécuter un — cette compétence *crée* uniquement de nouveaux workflows.
