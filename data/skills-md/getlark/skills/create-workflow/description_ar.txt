يجب استخدام هذه المهارة عندما يطلب المستخدم "إنشاء سير عمل"، أو "إنشاء اختبار getlark"، أو "إضافة اختبار شامل"، أو "تأليف سير عمل larkci"، أو تشغيل `/getlark:create-workflow`. يحول وصف اختبار اللغة الطبيعية (الهدف + الخطوات المطلوبة؛ قد يكون الهدف هو عنوان URL أو نقطة نهاية واجهة برمجة التطبيقات أو ثنائي واجهة سطر الأوامر (CLI) أو البرنامج النصي أو أي سطح برنامج آخر) إلى استدعاء "إنشاء مسارات عمل getlark" باسم تم إنشاؤه تلقائيًا. تفضل "الإدارة" عندما يريد المستخدم تحديث سير عمل موجود أو أرشفته، و"استدعاء سير العمل" عندما يريد تشغيله - هذه المهارة فقط *تنشئ* مسارات عمل جديدة.
