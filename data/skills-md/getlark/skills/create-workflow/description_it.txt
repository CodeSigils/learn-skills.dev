Questa abilità dovrebbe essere utilizzata quando l'utente chiede di "creare un flusso di lavoro", "creare un test getlark", "aggiungere un test end-to-end", "creare un flusso di lavoro larkci" o esegue `/getlark:create-workflow`. Converte la descrizione di un test in linguaggio naturale (destinazione + passaggi ordinati; la destinazione può essere un URL, un endpoint API, un file binario CLI, uno script o qualsiasi altra superficie software) in un'invocazione `getlark workflows create` con un nome generato automaticamente. Preferisci "gestire" quando l'utente desidera aggiornare o archiviare un flusso di lavoro esistente e "invoke-workflow" quando desidera eseguirne uno: questa abilità *crea* solo nuovi flussi di lavoro.
