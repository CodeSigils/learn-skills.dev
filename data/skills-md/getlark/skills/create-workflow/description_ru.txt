Этот навык следует использовать, когда пользователь просит «создать рабочий процесс», «создать тест getlark», «добавить сквозной тест», «создать рабочий процесс Larkci» или запускает `/getlark:create-workflow`. Преобразует описание теста на естественном языке (цель + упорядоченные шаги; целью может быть URL-адрес, конечная точка API, двоичный файл CLI, скрипт или любая другая поверхность программного обеспечения) в вызов getlark workflows create с автоматически сгенерированным именем. Предпочитайте «управление», когда пользователь хочет обновить или заархивировать существующий рабочий процесс, и «вызов рабочего процесса», когда он хочет его запустить — этот навык только *создает* новые рабочие процессы.
