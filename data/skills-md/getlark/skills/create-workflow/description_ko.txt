이 기술은 사용자가 "워크플로 만들기", "getlark 테스트 만들기", "종단 간 테스트 추가", "larkci 워크플로 작성"을 요청하거나 `/getlark:create-workflow`를 실행할 때 사용해야 합니다. 자연어 테스트 설명(대상 + 순서가 지정된 단계, 대상은 URL, API 엔드포인트, CLI 바이너리, 스크립트 또는 기타 소프트웨어 표면일 수 있음)을 자동 생성된 이름이 있는 'getlark 워크플로 생성' 호출로 변환합니다. 사용자가 기존 워크플로를 업데이트하거나 보관하려는 경우 'manage'를 선호하고, 워크플로를 실행하려는 경우 'invoke-workflow'를 선호합니다. 이 기술은 새 워크플로만 *생성*합니다.
