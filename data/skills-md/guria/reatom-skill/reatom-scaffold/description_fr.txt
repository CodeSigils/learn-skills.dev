Flux de travail d'échafaudage et d'amorçage commandé pour les nouveaux projets Reatom v1000+. À utiliser pour les applications inédites, les exemples, les démos, les packages autonomes ou lorsque l'utilisateur souhaite créer un nouveau projet Reatom ou échafauder Reatom dans un autre dépôt. Concentrez-vous sur l'ordre de configuration, le pipeline de validation, l'amorçage en contexte strict et les portes de qualité initiales avant le travail sur les fonctionnalités.
