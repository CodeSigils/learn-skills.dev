Para el trabajo que requiere un progreso entre sesiones o de varios pasos, investigue la base del código, verifique los requisitos elemento por elemento y produzca un documento de planificación persistente. Esto se utiliza para la invocación explícita de z-brainstorm. Las tareas simples y únicas, las preguntas y respuestas puras o los cambios que se pueden realizar directamente no son aplicables; pueden ser manejados por las propias capacidades del agente.
