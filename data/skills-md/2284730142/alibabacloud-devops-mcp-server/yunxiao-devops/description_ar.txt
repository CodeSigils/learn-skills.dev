قدرات تكامل منصة Alibaba Cloud CloudEffect DevOps. يوفر إمكانات DevOps كاملة مثل إدارة التعليمات البرمجية وخطوط الأنابيب وإدارة المشاريع وإدارة المؤسسة ومستودع العناصر وتسليم التطبيقات وإدارة الاختبار. يُستخدم عندما يحتاج المستخدمون إلى التفاعل مع النظام الأساسي CloudEffect، بما في ذلك: (1) عمليات مستودع التعليمات البرمجية (الفروع والملفات وطلبات الدمج) (2) إنشاء خطوط الأنابيب وتنفيذها (3) إدارة المشروع وعناصر العمل (4) إدارة أعضاء المؤسسة (5) استعلامات مستودع العناصر (6) نشر التطبيق وإصداره (7) إدارة حالة الاختبار. كلمات التشغيل: CloudEffect، وCodeup، وFlow، وProjex، وAppStack، وDevOps.
