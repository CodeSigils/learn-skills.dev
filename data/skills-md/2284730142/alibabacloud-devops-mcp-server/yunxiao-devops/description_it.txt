Funzionalità di integrazione della piattaforma DevOps Alibaba Cloud CloudEffect. Fornisce funzionalità DevOps complete come gestione del codice, pipeline, gestione dei progetti, gestione dell'organizzazione, repository degli artefatti, distribuzione delle applicazioni e gestione dei test. Utilizzato quando gli utenti devono interagire con la piattaforma CloudEffect, tra cui: (1) operazioni del repository di codice (rami, file, richieste di unione) (2) creazione ed esecuzione della pipeline (3) gestione di progetti ed elementi di lavoro (4) gestione dei membri dell'organizzazione (5) query del repository di artefatti (6) distribuzione e rilascio dell'applicazione (7) gestione dei test case. Parole chiave: CloudEffect, Codeup, Flow, Projex, AppStack, DevOps.
