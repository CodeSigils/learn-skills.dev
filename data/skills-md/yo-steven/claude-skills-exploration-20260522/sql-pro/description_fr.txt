Optimise les requêtes SQL, conçoit des schémas de base de données et résout les problèmes de performances. À utiliser lorsqu'un utilisateur demande pourquoi sa requête est lente, a besoin d'aide pour écrire des jointures ou des agrégations complexes, mentionne des problèmes de performances de base de données ou souhaite concevoir ou migrer un schéma. Invocation pour des requêtes complexes, des fonctions de fenêtre, des CTE, des stratégies d'indexation, l'analyse du plan de requête, couvrant la création d'index, les requêtes récursives, l'interprétation EXPLAIN/ANALYZE, l'analyse comparative des requêtes avant/après ou la migration de requêtes entre les dialectes de base de données (PostgreSQL, MySQL, SQL Server, Oracle).
