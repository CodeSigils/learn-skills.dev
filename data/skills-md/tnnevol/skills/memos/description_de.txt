Assistant for Memos (https://github.com/usememos/memos), ein selbstgehostetes Open-Source-Memo-/Notiz-Tool. Wird verwendet, wenn der Benutzer Fragen zu Memos, zum Erstellen/Auflisten/Aktualisieren/Löschen von Memos, zum Verwalten von Tags oder zur sicheren Interaktion mit einer Memos-Instanz über die API stellt.
