パブリック アカウントの記事パイプライン · 決定論的な機械的手順を経て、書かれた Markdown/HTML 作品を取得し、最終的に自分のパブリック アカウントの **下書きボックス**に保存します (下書きとしてのみ保存され、一括送信されることはありません。後でパブリック アカウントのバックエンドに移動して確認し、手動で一括送信します)。これにより、その後の操作が自動化されます: ID コンテキストのロード → Whoami ターゲット アカウントの検証 → 事前チェック → マークダウン → パブリック アカウントの HTML レンダリング → ローカル画像の事前アップロード → 表紙 → ドラフトの保存 → レポート。ユーザーがパブリック アカウントの記事を作成する、パブリック アカウントの書式を変換する、パブリック アカウントの下書きをプッシュする、下書きを再プッシュする、下書きボックスにカバーを付けて公開する、記事をパブリック アカウントの下書きボックスに保存する、またはパブリック アカウントの記事パイプラインを実行する場合、ユーザーはこれを使用します。まず、doubaoya.com でパブリック アカウントをバインドし、DOUBAOYA_API_KEY を持っている必要があります。トリガーワード: パブリック アカウントを作成する / パブリック アカウントの書式を変換する / パブリック アカウントの下書きをプッシュする / ドラフトを再プッシュする / カバー付きで下書きボックスに公開する / 記事をパブリック アカウントの下書きボックスに保存する / パブリック アカウントの記事パイプライン / wechat-article-pipeline。
