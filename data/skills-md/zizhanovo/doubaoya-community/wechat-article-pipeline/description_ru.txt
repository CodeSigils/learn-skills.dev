Конвейер статей общедоступной учетной записи · Проводит письменный фрагмент Markdown/HTML через детерминированный механический процесс и, наконец, сохраняет его в **ящике черновиков** вашей общедоступной учетной записи (сохраняется только как черновик, а не массовая рассылка; после этого вы переходите к серверной части общедоступной учетной записи для подтверждения и массовой отправки вручную). Он автоматизирует последующие операции: загрузка контекста идентификации → проверка Whoami целевой учетной записи → предварительная проверка → уценка → рендеринг HTML общедоступной учетной записи → предварительная загрузка локальных изображений → обложка → сохранение черновика → отчет. Используется, когда пользователь хочет написать статью для общедоступной учетной записи, преобразовать в макет общедоступной учетной записи, отправить черновик общедоступной учетной записи, повторно отправить черновик, опубликовать с обложкой в ​​ящике черновиков, сохранить статью в ящике черновиков общедоступной учетной записи или запустить конвейер статей общедоступной учетной записи. Сначала вам необходимо привязать свою общедоступную учетную запись на doubaoya.com и иметь DOUBAOYA_API_KEY. Триггерные слова: написать статью для публичного аккаунта / преобразовать в макет публичного аккаунта / отправить черновик общедоступного аккаунта / повторно отправить черновик / опубликовать с обложкой в ​​ящик для черновиков / сохранить статью в ящик для черновиков публичного аккаунта / конвейер статей для общедоступного аккаунта / wechat-article-pipeline.
