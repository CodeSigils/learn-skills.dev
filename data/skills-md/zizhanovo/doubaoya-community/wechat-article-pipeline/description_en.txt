Public account article pipeline · Takes a written Markdown/HTML piece through a deterministic mechanical process and finally stores it in your own public account’s **draft box** (stores only as a draft, never mass‑sends; afterward you go to the public account backend to confirm and manually mass‑send). It automates subsequent operations: load identity context → whoami verify target account → pre‑check → markdown → public‑account HTML rendering → pre‑upload local images → cover → save draft → report. Used when a user wants to write a public‑account article, convert to public‑account layout, push a public‑account draft, re‑push a draft, publish with a cover to the draft box, save an article into the public‑account draft box, or run the public‑account article pipeline. You must first bind your public account at doubaoya.com and have a DOUBAOYA_API_KEY. Trigger words: write public‑account article / convert to public‑account layout / push public‑account draft / re‑push draft / publish with cover to draft box / save article into public‑account draft box / public‑account article pipeline / wechat-article-pipeline.
