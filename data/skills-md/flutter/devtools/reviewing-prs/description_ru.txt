Общий рабочий процесс для получения, проверки и рассмотрения запросов на извлечение GitHub с использованием интерфейса командной строки gh, составления комментариев к обзору, согласованных с пользователем, и обеспечения одобрения перед публикацией. Используйте, когда вас просят просмотреть PR или запрос на включение GitHub.
