Guide les agents dans la compilation et l'empaquetage du code source C/C++ dans des bibliothèques dynamiques ou statiques (Code Assets) à l'aide du système de hook Native Assets de Dart (via hook/build.dart et hook/link.dart en utilisant package:hooks et package:native_toolchain_c). À utiliser lorsqu'un utilisateur demande : « configurer des ressources natives », « compiler le code source C/C++ », « regrouper des bibliothèques dynamiques », « créer du code C natif », « lier des ressources natives », « implémenter des hooks build.dart ou link.dart » ou « intégrer l'interopérabilité C/C++ dans Dart/Flutter ». Aide les agents à éviter l’orchestration manuelle de la chaîne d’outils et configure des téléchargements binaires sécurisés validés par hachage ou une arborescence de liens avancée avec le mappage package:record_use.
