Guía a los agentes en la compilación y empaquetado de código fuente C/C++ en bibliotecas dinámicas o estáticas (Code Assets) utilizando el sistema de enlace Native Assets de Dart (a través de hook/build.dart y hook/link.dart utilizando el paquete:hooks y el paquete:native_toolchain_c). Úselo cuando un usuario solicite: 'configurar recursos nativos', 'compilar código fuente C/C++', 'agrupar bibliotecas dinámicas', 'compilar código C nativo', 'vincular recursos nativos', 'implementar enlaces build.dart o link.dart' o 'integrar interoperabilidad C/C++ en Dart/Flutter'. Ayuda a los agentes a evitar la orquestación manual de la cadena de herramientas y configura descargas binarias seguras validadas por hash o agitación avanzada del árbol del enlazador con mapeo package:record_use.
