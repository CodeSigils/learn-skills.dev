Regeln und Formatierungsrichtlinien zum Schreiben von Dart /// API-Dokumentation und Dokumentkommentaren. Verwenden Sie es, wenn Sie Dart-Code dokumentieren, Dokumentkommentare für jede Dart-Deklaration (Bibliotheken, Klassen, Methoden, Variablen usw.) schreiben oder wenn Sie angewiesen werden, die Dokumentationsrichtlinien von Effective Dart zu befolgen.
