Настраивает драйвер Flutter для взаимодействия с приложением и преобразует действия MCP в постоянные интеграционные тесты. Используйте при добавлении интеграционного тестирования в проект, изучении компонентов пользовательского интерфейса через MCP или автоматизации пользовательских потоков с помощью пакета Integration_test.
