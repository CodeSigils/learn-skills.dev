gh CLI を使用して、flutter/flutter リポジトリ内でシェパーディング、ステータスの確認、ブランチの更新、そしてオープン PR や承認済みのサードパーティ貢献者 PR のマージを自動化します。

使用すべき場面:
- オープン PR やシェパードされたサードパーティ PR のステータスを確認する必要があるとき。
- 古くなったブランチを更新したり、承認済み PR に「autosubmit」ラベルを付けてマージする必要があるとき。

使用すべきでない場面:
- 承認されていない PR（自分のものでステータスを確認したい場合を除く）には使用しないでください。
- flutter/flutter 以外のリポジトリでは使用しないでください。
