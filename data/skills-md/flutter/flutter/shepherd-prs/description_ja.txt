gh CLI を使用して、シェパーディング、ステータスの確認、ブランチの更新、およびオープン PR または承認されたサードパーティ コントリビュータ PR の Flutter/Flutter リポジトリへのランディングを自動化します。
いつ使用するか: - オープン PR またはシェパードされたサードパーティ PR のステータスを確認する必要がある場合。 - 古いブランチを更新する必要がある場合、または承認された PR を取得するために「自動送信」ラベルを適用する必要がある場合。
使用しない場合: - 承認されていない PR には使用しないでください (独自の PR でステータスを確認したい場合を除く)。・flutter/flutter以外のリポジトリには使用しないでください。
