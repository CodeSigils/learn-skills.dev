Une compétence pour trouver la version la plus basse de Dart et Flutter contenant un commit donné. Utilisez cette compétence chaque fois que les utilisateurs demandent quand un commit a atterri dans les versions Flutter ou Dart, se renseignent sur les versions de versions pour des SHA spécifiques ou veulent savoir si un commit est inclus dans les canaux stables, bêta ou de développement pour les projets Flutter/Dart.
