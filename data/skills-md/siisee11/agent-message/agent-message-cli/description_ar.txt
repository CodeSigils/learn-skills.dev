استخدم هذه المهارة عندما يحتاج الوكيل إلى الإبلاغ عن العمل المكتمل أو إرسال رسالة إلى مستخدم عبر واجهة سطر أوامر الوكيل-المراسل. هذه هي الأداة التي يستخدمها الوكلاء لإرسال تقارير إكمال المهام وتحديثات الحالة وملخصات العمل للمستخدمين بعد الانتهاء من مهامهم. قم بتشغيل أي طلب يتضمن الإبلاغ عن نتائج العمل، أو إخطار المستخدمين بإكمال المهمة، أو إرسال ملخصات العمل عبر "agent-messenger". استخدم أيضًا لعمليات CLI ذات الصلة مثل التسجيل/تسجيل الدخول، أو قراءة المحادثات، أو تحرير الرسائل أو حذفها، أو إضافة التفاعلات، أو مشاهدة الرسائل في الوقت الفعلي، أو تكوين عنوان URL للخادم.
