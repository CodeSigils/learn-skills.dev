このスキルは、エージェントが完了した作業を報告する必要がある場合、またはエージェント メッセンジャー CLI を介してユーザーにメッセージを送信する必要がある場合に使用します。これは、エージェントがタスクの完了後にタスク完了レポート、ステータス更新、作業概要をユーザーに送信するために使用するツールです。作業結果の報告、ユーザーへのタスク完了の通知、または「エージェント メッセンジャー」を介した作業概要の送信を含むあらゆるリクエストをトリガーします。また、登録/ログイン、会話の読み取り、メッセージの編集または削除、リアクションの追加、リアルタイム メッセージの監視、サーバー URL の構成など、関連する CLI 操作にも使用します。
