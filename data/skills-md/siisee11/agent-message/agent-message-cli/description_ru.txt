Используйте этот навык, когда агенту необходимо сообщить о выполненной работе или отправить сообщение пользователю через интерфейс командной строки агента-мессенджера. Это инструмент, который агенты используют для отправки пользователям отчетов о выполнении задач, обновлений статуса и сводок работы после завершения задач. Запускается по любому запросу, включающему отчет о результатах работы, уведомление пользователей о завершении задачи или отправку сводок работы через «агент-мессенджер». Также используйте для связанных операций CLI, таких как регистрация/вход в систему, чтение бесед, редактирование или удаление сообщений, добавление реакций, просмотр сообщений в реальном времени или настройка URL-адреса сервера.
