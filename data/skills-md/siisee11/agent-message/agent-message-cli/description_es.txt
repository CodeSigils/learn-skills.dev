Utilice esta habilidad cuando un agente necesite informar un trabajo completado o enviar un mensaje a un usuario a través de la CLI de agente-messenger. Esta es la herramienta que utilizan los agentes para enviar informes de finalización de tareas, actualizaciones de estado y resúmenes de trabajo a los usuarios después de finalizar sus tareas. Se activa ante cualquier solicitud que implique informar resultados de trabajo, notificar a los usuarios sobre la finalización de tareas o enviar resúmenes de trabajo a través de "agent-messenger". Úselo también para operaciones CLI relacionadas, como registrarse/iniciar sesión, leer conversaciones, editar o eliminar mensajes, agregar reacciones, observar mensajes en tiempo real o configurar la URL del servidor.
