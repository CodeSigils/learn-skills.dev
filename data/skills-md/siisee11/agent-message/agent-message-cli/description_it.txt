Utilizza questa abilità quando un agente deve segnalare il lavoro completato o inviare un messaggio a un utente tramite la CLI di agent-messenger. Questo è lo strumento utilizzato dagli agenti per inviare report di completamento delle attività, aggiornamenti di stato e riepiloghi del lavoro agli utenti dopo aver terminato le loro attività. Attiva qualsiasi richiesta che comporti il ​​reporting dei risultati del lavoro, la notifica agli utenti del completamento dell'attività o l'invio di riepiloghi del lavoro tramite "agent-messenger". Utilizzabile anche per operazioni CLI correlate come registrazione/accesso, lettura di conversazioni, modifica o eliminazione di messaggi, aggiunta di reazioni, ricerca di messaggi in tempo reale o configurazione dell'URL del server.
