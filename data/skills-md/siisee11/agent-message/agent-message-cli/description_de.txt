Verwenden Sie diesen Skill, wenn ein Agent abgeschlossene Arbeiten melden oder über die Agent-Messenger-CLI eine Nachricht an einen Benutzer senden muss. Dies ist das Tool, mit dem Agenten nach Abschluss ihrer Aufgaben Aufgabenabschlussberichte, Statusaktualisierungen und Arbeitszusammenfassungen an Benutzer senden. Wird bei jeder Anfrage ausgelöst, bei der es um die Meldung von Arbeitsergebnissen, die Benachrichtigung von Benutzern über den Abschluss von Aufgaben oder das Senden von Arbeitszusammenfassungen über „Agent-Messenger“ geht. Verwenden Sie es auch für verwandte CLI-Vorgänge wie Registrieren/Anmelden, Lesen von Konversationen, Bearbeiten oder Löschen von Nachrichten, Hinzufügen von Reaktionen, Überwachen von Echtzeitnachrichten oder Konfigurieren der Server-URL.
