Recherchez chaque flux de travail LLM dans le référentiel actuel et étiquetez-le afin que les groupes Caveman Cloud dépensent en fonction de ce que fait réellement le code (assistance-réponse, résumé nocturne) au lieu d'un seul compartiment anonyme. À utiliser lorsque l'utilisateur colle l'invite de découverte Caveman, dit « découvrir les flux de travail » ou demande de répartir les dépenses LLM par flux de travail. Le dépôt devrait déjà passer par la passerelle Caveman (la compétence de configuration de l'homme des cavernes fait cette partie).
