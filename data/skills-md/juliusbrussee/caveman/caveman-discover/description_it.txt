Trova ogni flusso di lavoro LLM nel repository corrente ed etichettalo, in modo che i gruppi Caveman Cloud spendano in base a ciò che fa effettivamente il codice (risposta di supporto, digest notturno) anziché in un bucket anonimo. Da utilizzare quando l'utente incolla la richiesta di individuazione di Caveman, dice "scopri flussi di lavoro" o chiede di suddividere la spesa LLM in base al flusso di lavoro. Il repository dovrebbe già instradarsi attraverso il gateway Caveman (l'abilità di configurazione del cavernicolo fa quella parte).
