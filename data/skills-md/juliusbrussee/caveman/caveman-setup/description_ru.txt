Подключите текущий репозиторий через шлюз Caveman Cloud, чтобы каждый запрос LLM измерялся — стоимость, токены, задержка — с нулевым изменением поведения. Используйте, когда пользователь вставляет запрос на настройку Caveman, говорит «настроить пещерного человека» или хочет, чтобы в приложение была добавлена ​​возможность наблюдения за расходами LLM. Требуется URL-адрес шлюза и ключ Cave API (в приглашении установки есть и то, и другое).
