Collega il repository corrente tramite il gateway Caveman Cloud in modo che ogni richiesta LLM venga misurata (costo, token, latenza) senza alcun cambiamento di comportamento. Da utilizzare quando l'utente incolla la richiesta di configurazione di Caveman, dice "configura Caveman" o desidera che l'osservabilità della spesa LLM venga aggiunta a un'app. Richiede l'URL del gateway e una chiave API Cave (la richiesta di configurazione li contiene entrambi).
