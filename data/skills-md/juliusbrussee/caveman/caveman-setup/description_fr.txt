Câblez le référentiel actuel via la passerelle Caveman Cloud afin que chaque demande LLM soit mesurée (coût, jetons, latence) sans aucun changement de comportement. À utiliser lorsque l'utilisateur colle l'invite de configuration de Caveman, dit « configurer Caveman » ou souhaite que l'observabilité des dépenses LLM soit ajoutée à une application. Nécessite l'URL de la passerelle et une clé API Cave (l'invite de configuration contient les deux).
