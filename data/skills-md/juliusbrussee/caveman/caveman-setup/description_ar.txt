قم بتوصيل المستودع الحالي من خلال بوابة Caveman Cloud بحيث يتم قياس كل طلب LLM - التكلفة، والرموز المميزة، وزمن الوصول - دون أي تغيير في السلوك. يُستخدم عندما يلصق المستخدم مطالبة إعداد Caveman، أو يقول "إعداد رجل الكهف"، أو يريد إضافة إمكانية مراقبة إنفاق LLM إلى التطبيق. يتطلب عنوان URL للبوابة ومفتاح Cave API (يحتوي موجه الإعداد على كليهما).
