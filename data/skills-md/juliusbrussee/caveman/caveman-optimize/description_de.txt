Verwandeln Sie Cavemans genaue, nur aus Berichten bestehende Repository-Beobachtungen in einen vom Bediener ausgewählten Optimierungskandidaten mit einer gepaarten Basislinien-/Kandidatenbewertung. Verwenden Sie diese Option, wenn der Benutzer eine Optimierungsbeobachtung überprüfen, eine mögliche Änderung bewerten oder auf den aktuellen Caveman-Optimierungsbericht reagieren möchte. Erfordern eine angemeldete Caveman-CLI-Verbindung und eine ausdrückliche Genehmigung; Schließen Sie niemals aus einem Profil auf Geld oder Betätigung ab.
