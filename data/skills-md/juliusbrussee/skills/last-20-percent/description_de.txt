Findet und beendet die letzten 20 % einer erstellten Lösung – die Agenten der Erfahrungsebene überspringen: wie die Ausgabe tatsächlich aussieht, welche Seiten oder Bildschirme vorhanden sein sollten, Erstausführungs- und Leerzustände, eigenwillige Standardeinstellungen, der goldene Pfad. Verwenden Sie diese Option, wenn Sie einen Build planen, damit die Magie genauso konkret spezifiziert wird wie die Installation, bevor Sie einen Build als „fertig“ bezeichnen, wenn eine Lösung funktioniert, sich aber wie eine Demo anfühlt, oder wenn der Benutzer sagt: „Letzte 20 %“, „Schließen Sie das ab“, „Machen Sie es tatsächlich gut“, „Ist das tatsächlich fertig“ oder „Warum fühlt sich das flach an?“.
