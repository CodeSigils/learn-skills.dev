Führen Sie eine spezifikationsgesteuerte Agentenschleife aus, in der Codierungsaufgaben als Markdown-Spezifikationen vorliegen, die durch Posteingang → Aktiv → Archiv wandern, von Claude Code oder Codex implementiert werden und ein Überprüfungstor passieren, bevor sie als erledigt gelten. Verwenden Sie diese Option, wenn der Benutzer „Loop Factory“, eine „spezifikationsgesteuerte Schleife“ oder eine „Agentenfabrik“ erwähnt, wiederholbare/überprüfbare Agentenarbeit wünscht oder wenn ein Repo über ein Verzeichnis „factory/specs/inbox“ oder „factory/specs/active“ verfügt. Behandelt auch die Installation und das Einbinden der Loop-Factory-CLI in ein Projekt.
