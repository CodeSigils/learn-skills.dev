Exécutez une boucle d'agent basée sur les spécifications dans laquelle les tâches de codage vivent sous forme de spécifications de démarque qui se déplacent via la boîte de réception → active → archive, sont implémentées par Claude Code ou Codex et passent une porte de révision avant d'être considérées comme terminées. À utiliser lorsque l'utilisateur mentionne une "usine de boucles", une "boucle pilotée par les spécifications", une "usine d'agents", souhaite un travail d'agent répétable/révisable, ou lorsqu'un dépôt a un répertoire factory/specs/inbox ou factory/specs/active. Couvre également l'installation et l'intégration de la CLI Loop-Factory dans un projet.
