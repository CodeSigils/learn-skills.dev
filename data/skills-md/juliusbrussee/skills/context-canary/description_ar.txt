قم بتثبيت إشارة كناري لكل دورة (على سبيل المثال، بدء كل رد باسم المستخدم وعداد الدوران) بحيث يصبح تدهور السياق الصامت مرئيًا لحظة حدوثه، وقم بتشغيل بروتوكول الاسترداد عندما يتعثر الكناري. يُستخدم عندما يذكر المستخدم "كناري" أو "كناري سياق" أو "فحص كناري"، أو يطلب اكتشاف تعفن السياق/ضغطه/انحرافه، أو يقول "لقد توقفت عن استخدام اسمي" أو "هل فقدت السياق"، أو يسأل "ما مدى تدهور السياق الخاص بك"، أو يريد نظام إنذار مبكر لجلسات الوكيل الطويلة.
