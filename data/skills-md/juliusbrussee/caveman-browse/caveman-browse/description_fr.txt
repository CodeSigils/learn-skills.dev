Pilotez des pages Web via les outils MCP de navigation de l'homme des cavernes (browser_snapshot, browser_act, browser_eval, browser_recover). À utiliser chaque fois que vous interagissez avec une page Web, un tableau de bord ou un formulaire via Caveman-Browse - il enseigne la boucle instantané → acte → vérifier, la discipline de requête d'abord sur les grandes pages et quand récupérer les octets exacts.
