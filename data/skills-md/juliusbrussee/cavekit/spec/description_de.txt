Erstellen, ändern oder backpropen Sie Fehler in SPEC.md im Repo-Stammverzeichnis. Einziger Mutator
der Projektspezifikation. Wird ausgelöst, wenn der Benutzer auffordert, eine Spezifikation zu schreiben und zu starten
eine neue Spezifikation erstellen, eine Spezifikation aus vorhandenem Code destillieren, Invarianten hinzufügen, ändern
Abschnitte (§G, §C, §I, §V, §T, §B) oder zeichnen Sie einen Fehler über Backprop auf.
Gängige Formulierungen: „Schreiben Sie die Spezifikation für …“, „Neue Spezifikation“, „Fehler: ...“,
„§V.3 ändern“, „Spezifikation aus Code destillieren“, „diese Idee spezifizieren“. Liest und
folgt FORMAT.md für die Caveman-Kodierungsregeln und die Pipe-Tabellenform
von §T und §B.
