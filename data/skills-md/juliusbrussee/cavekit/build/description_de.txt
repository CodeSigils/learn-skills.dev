Implementierung anhand von SPEC.md planen und dann ausführen. Nativer Single-Thread
Schleife, keine Unteragenten. Bei einem Test- oder Build-Fehler wird das Backprop automatisch aufgerufen
Skill vor einem erneuten Versuch – bei einer fehlgeschlagenen Überprüfung wird immer berücksichtigt, ob
Eine neue §V-Invariante würde eine Wiederholung verhindern. Wird ausgelöst, wenn der Benutzer danach fragt
um die Spezifikation zu erstellen, zu implementieren, auszuführen oder eine bestimmte §T-Aufgabe in Angriff zu nehmen
(„build §T.3“, „build --next“, „nächste Aufgabe implementieren“, „Build ausführen“).
Erwartet, dass SPEC.md vorhanden ist; Wenn nicht, wird die Spezialfähigkeit übernommen.
