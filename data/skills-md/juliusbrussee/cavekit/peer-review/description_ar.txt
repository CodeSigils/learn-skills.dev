أنماط استخدام وكيل أو نموذج الذكاء الاصطناعي الثاني لتحدي عمل وكيل البناء الأساسي. يغطي ستة أوضاع للمراجعة (نقد الاختلاف، وتحدي التصميم، والمناقشة المترابطة، والتدقيق المفوض، والتصويت الحاسم، وتدقيق التغطية)، وكيفية إعداد مراجعة النظراء مع أي نموذج عبر خادم MCP، وحلقات تكرار مراجعة النظراء التي يطالب بها المنشئ والمراجع البديل، ووضع حلقة Codex (Cavekit + Ralph Loop + Codex كمراجع عبر CLI أو MCP الاحتياطي)، وقوالب المطالبة لكل استراتيجية. مهمة المراجع النظير هي العثور على ما فاته البناء، وليس الموافقة عليه. المشغلات: "مراجعة النظراء"، "وكيل مراجعة النظراء"، "استخدام نموذج آخر للمراجعة"، "رأي ثانٍ حول الكود"، "مراجعة النماذج المشتركة"، "حلقة مراجعة النظراء"، "حلقة ralph مع المخطوطة"، "cavekit ralph"، "حلقة النماذج المتقاطعة"، "مراجعة النظراء للمخطوطة".
