Шаблоны использования второго агента или модели ИИ, чтобы бросить вызов работе основного агента-строителя. Охватывает шесть режимов проверки (критика различий, вызов дизайна, поточные дебаты, делегированная проверка, решающее голосование, аудит покрытия), способы настройки экспертной проверки для любой модели через сервер MCP, итерационные циклы экспертной проверки, в которых чередуются подсказки создателя и рецензента, режим цикла Кодекса (Cavekit + Ralph Loop + Codex в качестве рецензента через CLI или резервный вариант MCP), а также шаблоны подсказок для каждой стратегии. Задача рецензента — найти то, что упустил строитель, а не прийти к согласию. Триггеры: «партнерская проверка», «агент экспертной проверки», «использовать другую модель для проверки», «второе мнение по коду», «перекрестная проверка», «цикл экспертной проверки», «цикл Ральфа с кодексом», «Cavekit ralph», «цикл перекрестной модели», «рецензент Кодекса».
