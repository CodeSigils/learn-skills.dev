Modèles d'utilisation d'un deuxième agent ou modèle d'IA pour remettre en question le travail de l'agent constructeur principal. Couvre six modes d'examen (Diff Critique, Design Challenge, Threaded Debate, Delegated Scrutiny, Deciding Vote, Coverage Audit), comment configurer l'examen par les pairs avec n'importe quel modèle via le serveur MCP, les boucles d'itération d'examen par les pairs qui alternent les invites du constructeur et du réviseur, le mode de boucle du Codex (Cavekit + Ralph Loop + Codex en tant que réviseur via CLI ou MCP de secours) et les modèles d'invite pour chaque stratégie. Le travail de l'examinateur consiste à trouver ce que le constructeur a manqué, et non à être d'accord. Déclencheurs : « examen par les pairs », « agent d'examen par les pairs », « utiliser un autre modèle pour examiner », « deuxième avis sur le code », « examen inter-modèles », « boucle d'examen par les pairs », « boucle Ralph avec codex », « cavekit ralph », « boucle inter-modèles », « évaluateur par les pairs du codex ».
