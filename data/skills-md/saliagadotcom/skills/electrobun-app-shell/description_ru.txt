Windows, представления, собственный пользовательский интерфейс и системные API для настольных приложений Electrobun. Охватывает BrowserWindow, BrowserView, GpuWindow, Tray, ApplicationMenu, ContextMenu, буфер обмена, диалоговые окна, уведомления, пути, GlobalShortcut, Screen, Session. Используйте при создании окон, управлении представлениями, создании собственного пользовательского интерфейса или доступе к системным API.
