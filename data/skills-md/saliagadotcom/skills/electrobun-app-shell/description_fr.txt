Windows, vues, interface utilisateur native et API système pour les applications de bureau Electrobun. Couvre BrowserWindow, BrowserView, GpuWindow, Tray, ApplicationMenu, ContextMenu, le presse-papiers, les boîtes de dialogue, les notifications, les chemins, GlobalShortcut, Screen, Session. À utiliser lors de la création de fenêtres, de la gestion de vues, de la création d'une interface utilisateur native ou de l'accès aux API système.
