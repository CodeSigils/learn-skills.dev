Windows وطرق العرض وواجهة المستخدم الأصلية وواجهات برمجة تطبيقات النظام لتطبيقات سطح المكتب Electrobun. يغطي BrowserWindow، وBrowserView، وGpuWindow، وTray، وApplicationMenu، وContextMenu، والحافظة، ومربعات الحوار، والإشعارات، والمسارات، وGlobalShortcut، والشاشة، والجلسة. يُستخدم عند إنشاء النوافذ أو إدارة طرق العرض أو إنشاء واجهة مستخدم أصلية أو الوصول إلى واجهات برمجة تطبيقات النظام.
