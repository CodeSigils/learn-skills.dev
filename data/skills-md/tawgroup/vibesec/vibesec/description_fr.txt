Audit de sécurité pré-déploiement pour les applications codées par ambiance. Détecte les erreurs de base que les agents de codage d'IA (et les humains) envoient régulièrement en production : API d'administration non authentifiées, RLS manquant, fuite de clés de service, routes de débogage exposées, secrets codés en dur, CORS permissif. Stack-aware - détecte Next.js, Supabase, etc. à partir de package.json et exécute la liste de contrôle appropriée.
