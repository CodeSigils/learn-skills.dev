Configura un ambiente virtuale Python e installa Reflex. Da utilizzare quando si inizializza un nuovo progetto Reflex, si configura un ambiente di sviluppo o quando l'utente deve creare un venv e installare le dipendenze. Carica quando non è presente la directory .venv, quando l'utente chiede di avviare una nuova app Reflex o quando le importazioni falliscono a causa di pacchetti mancanti.
