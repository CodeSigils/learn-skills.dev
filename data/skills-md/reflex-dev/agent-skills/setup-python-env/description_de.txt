Richten Sie eine virtuelle Python-Umgebung ein und installieren Sie Reflex. Verwenden Sie diese Option, wenn Sie ein neues Reflex-Projekt initialisieren, eine Entwicklungsumgebung einrichten oder wenn der Benutzer ein Venv erstellen und Abhängigkeiten installieren muss. Wird geladen, wenn kein .venv-Verzeichnis vorhanden ist, wenn der Benutzer den Start einer neuen Reflex-App anfordert oder wenn Importe aufgrund fehlender Pakete fehlschlagen.
