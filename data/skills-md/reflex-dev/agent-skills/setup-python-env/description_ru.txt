Настройте виртуальную среду Python и установите Reflex. Используйте при инициализации нового проекта Reflex, настройке среды разработки или когда пользователю необходимо создать venv и установить зависимости. Загружается, когда каталог .venv отсутствует, когда пользователь просит запустить новое приложение Reflex или когда импорт не удается из-за отсутствия пакетов.
