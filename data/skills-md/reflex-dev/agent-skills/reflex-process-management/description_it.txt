Gestisci i processi dell'applicazione Reflex: compila per testare, esegui il server in modalità di produzione, ricarica un'app in esecuzione trovando e riavviando il processo dell'app e gestisci i log per il debug. Utilizzare quando l'utente desidera testare, eseguire, riavviare o ricaricare un'app Reflex, durante la risoluzione dei problemi di un server Reflex in esecuzione o durante l'analisi degli errori.
