وثائق الإطار الانعكاسي. يُستخدم عند إنشاء تطبيقات ويب Python متكاملة باستخدام Reflex، أو إنشاء المكونات، أو إدارة الحالة، أو التعامل مع الأحداث، أو التصميم، أو عمليات قاعدة البيانات، أو مسارات API، أو المصادقة، أو نشر التطبيقات، أو تغليف مكونات React. يتم التحميل عندما يعمل المستخدم مع Reflex (rx)، أو يكتب ملفات .py التي تستورد الانعكاس، أو يسأل عن مفاهيم Reflex مثل State، أو Vars، أو EventHandlers، أو Components.
