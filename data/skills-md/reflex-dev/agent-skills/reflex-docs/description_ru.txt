Документация по Reflex Framework. Используйте при создании полнофункциональных веб-приложений Python с помощью Reflex, создании компонентов, управлении состоянием, обработке событий, стилизации, операциях с базами данных, маршрутах API, аутентификации, развертывании приложений или упаковке компонентов React. Загружается, когда пользователь работает с Reflex (rx), пишет файлы .py, которые импортируют рефлекс, или задает вопросы о таких концепциях Reflex, как State, Vars, EventHandlers или Components.
