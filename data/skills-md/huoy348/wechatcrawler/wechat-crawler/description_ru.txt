Сканирует статьи из официальных аккаунтов WeChat, а также их статистику (количество прочитанных, лайков, количество «Стоит прочитать», количество репостов) и данные комментариев. Пользователям необходимо предоставить только файлы cookie своего браузера; программа автоматически извлечет токен, проверит доступность API, а затем просканирует все статьи целевой официальной учетной записи. Созданная с помощью Selenium + BeautifulSoup, она поддерживает интеллектуальное управление файлами cookie: она определяет приоритет файлов cookie, предоставленных пользователем браузера, автоматически преобразует его формат и сохраняет файл cookie в базе данных для обеспечения постоянного хранения.
