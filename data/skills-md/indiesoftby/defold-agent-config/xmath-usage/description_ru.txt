Предоставляет справочник по API xmath и шаблоны оптимизации математических вычислений на месте для Defold. Используйте при написании критически важного для производительности математического кода, оптимизации операций с векторами, кватернионами или матрицами, а также когда пользователь упоминает xmath, математические вычисления с нулевым выделением или уменьшает нагрузку на Lua GC.
