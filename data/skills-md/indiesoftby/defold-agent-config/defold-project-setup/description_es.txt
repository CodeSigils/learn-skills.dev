Descarga las dependencias del proyecto Defold en la carpeta .deps/. También proporciona la configuración recomendada de game.project. Utilice PRIMERO antes de cualquier otra tarea cuando la carpeta .deps/ falte o esté vacía, o después de editar las URL de dependencia en game.project. Úselo también al crear un nuevo proyecto, configurar game.project o preguntar sobre la configuración recomendada del proyecto.
