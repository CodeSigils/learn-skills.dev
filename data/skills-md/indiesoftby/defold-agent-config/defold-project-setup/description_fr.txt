Télécharge les dépendances du projet dans le dossier .deps/. Fournit également les paramètres game.project recommandés. Utilisez EN PREMIER avant toute autre tâche lorsque le dossier .deps/ est manquant ou vide, ou après avoir modifié les URL de dépendance dans game.project. À utiliser également lors de la création d'un nouveau projet, de la configuration de game.project ou de la demande d'informations sur les paramètres de projet recommandés.
