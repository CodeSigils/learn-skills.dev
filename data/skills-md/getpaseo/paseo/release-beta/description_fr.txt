Coupez une version bêta de Paseo. À utiliser lorsque l'utilisateur dit « publier une version bêta », « couper une version bêta », « expédier une version bêta », « version bêta » ou « /release-beta ». Les versions bêta sont des versions candidates silencieuses : pas de journal des modifications, pas de déplacement de site Web, npm uniquement sur la balise de distribution bêta.
