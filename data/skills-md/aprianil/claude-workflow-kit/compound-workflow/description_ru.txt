Рабочий процесс сложного проектирования для разработки с помощью искусственного интеллекта. Обеспечивает планирование перед работой, контекстное проектирование, самопроверку и сборку после отгрузки. Используйте для каждой нетривиальной задачи — реализации функций, исправления ошибок, рефакторинга, принятия архитектурных решений. Запускается при «сборке», «реализации», «исправлении», «рефакторинге», «планировании», «отправке» или при запуске любой многоэтапной задачи кодирования.
