Requête de jours fériés — vérifiez si un jour spécifique est un jour ouvrable ou un jour férié, consultez les horaires de travail et les noms des jours fériés. Utilisez-le lorsque vous voulez savoir s'il s'agit d'une journée de travail ou lorsque des journées de travail compensatoires se produisent. [Important] Vous devez d'abord lire la documentation originale sur les compétences pour obtenir le format de commande correct ; ne devinez pas.
