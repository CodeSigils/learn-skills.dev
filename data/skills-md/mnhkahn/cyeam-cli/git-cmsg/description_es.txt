Úselo cuando genere mensajes de confirmación de Git, escriba mensajes de confirmación, confirme código o cuando el usuario mencione confirmar, 提交, mensaje de confirmación, 提交信息. Organiza automáticamente todos los cambios de forma predeterminada, utiliza LLM para juzgar si se deben confirmar nuevos archivos y genera mensajes en formato de confirmaciones convencionales en chino.
