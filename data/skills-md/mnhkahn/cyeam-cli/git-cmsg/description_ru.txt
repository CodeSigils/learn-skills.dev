Используйте при создании сообщений о фиксации Git, написании сообщений о фиксации, фиксации кода или когда пользователь упоминает сообщение о фиксации. По умолчанию автоматически обрабатывает все изменения, использует LLM для определения необходимости фиксации новых файлов, генерирует сообщения в формате обычных коммитов на китайском языке.
