Wird zum Generieren von Git-Commit-Nachrichten, zum Schreiben von Commit-Nachrichten, zum Commit-Code oder wenn der Benutzer Commit, Commit-Nachricht oder Commit-Nachricht erwähnt, verwendet. Stellt standardmäßig alle Änderungen automatisch bereit, beurteilt mithilfe von LLM, ob neue Dateien festgeschrieben werden sollten, und generiert Meldungen im herkömmlichen Commits-Format auf Chinesisch.
