Impresión de archivos locales: descubra y controle la impresora actual, envíe PDF/documentos/imágenes a la impresora. Antes de cada trabajo de impresión, debe confirmar el tamaño del papel y la configuración de blanco y negro/color; El valor predeterminado es A4, blanco y negro. Adecuado para comandos de usuario como “imprimir/imprimir/imprimir/enviar este archivo a la impresora”. [Importante] Primero debes leer el texto original de la habilidad para obtener el procedimiento correcto; no escribas a ciegas.
