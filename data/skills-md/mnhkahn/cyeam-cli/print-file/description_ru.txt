Печать локальных файлов — обнаруживайте и управляйте текущим принтером, отправляйте PDF/документы/изображения на принтер. Перед каждым заданием на печать необходимо подтвердить размер бумаги и настройки черно-белого/цветного режима; по умолчанию — формат A4, черно-белый. Подходит для пользовательских команд типа «распечатать/распечатать/распечатать/отправить этот файл на принтер». [Важно] Сначала вы должны прочитать исходный текст навыка, чтобы получить правильную процедуру; не пишите вслепую.
