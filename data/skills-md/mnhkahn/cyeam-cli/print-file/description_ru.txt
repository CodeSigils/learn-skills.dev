Печать локальных файлов — обнаружение и управление текущим принтером, а также отправка PDF-файлов/документов/изображений на принтер. Перед каждой печатью необходимо подтвердить размер бумаги и ее тип: черно-белый или цветной; по умолчанию — формат A4, черно-белый. Это подходит для пользователей, которые говорят «распечатать/распечатать/отправить этот файл на принтер». 【Важно】 Вы должны сначала прочитать исходный текст навыка, чтобы понять правильную процедуру; слепой набор текста запрещен.
