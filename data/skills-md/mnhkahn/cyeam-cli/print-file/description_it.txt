Stampa di file locali: rileva e controlla la stampante corrente, invia PDF/documenti/immagini alla stampante. Prima di ogni lavoro di stampa, è necessario verificare il formato carta e le impostazioni in bianco e nero/a colori; l'impostazione predefinita è A4, bianco e nero. Adatto per comandi utente come "stampa / stampa / stampa / invia questo file alla stampante". [Importante] Devi prima leggere il testo originale dell'abilità per ottenere la procedura corretta; non digitare alla cieca.
