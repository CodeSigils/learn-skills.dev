Detecta, selecciona, cambia y verifica las toolchains de Go para un repositorio sin mutar el estado global del sistema. Úsalo cuando una compilación de Go informe un GOROOT o paquete de la biblioteca estándar incompatible, cuando el comportamiento de go.mod/go.sum difiera entre versiones de Go, cuando haya varias versiones de Go instaladas, al elegir un binario de Go para go mod tidy/test/build, o al configurar un flujo de trabajo reproducible con múltiples versiones de Go.
