Detecte, seleccione, cambie y verifique las cadenas de herramientas Go para un repositorio sin mutar el estado global del sistema. Utilícelo cuando una compilación de Go informe de un paquete de GOROOT o biblioteca estándar incompatible, cuando el comportamiento de go.mod/go.sum difiera entre las versiones de Go, cuando se instalen varias versiones de Go, al elegir un binario de Go para go mod tidy/test/build, o al configurar un flujo de trabajo repetible de múltiples versiones de Go.
