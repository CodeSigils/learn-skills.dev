Rileva, seleziona, cambia e verifica le toolchain Go per un repository senza modificare lo stato globale del sistema. Da utilizzare quando una build Go segnala un GOROOT incompatibile o un pacchetto della libreria standard, quando il comportamento go.mod/go.sum differisce tra le versioni Go, quando sono installate più versioni Go, quando si sceglie un binario Go per go mod tidy/test/build o quando si imposta un flusso di lavoro Go multi-versione ripetibile.
