Rileva, seleziona, cambia e verifica le toolchain Go per un repository senza modificare lo stato globale del sistema. Utilizza questa funzionalità quando una compilazione Go segnala un GOROOT incompatibile o un pacchetto della libreria standard, quando il comportamento di go.mod/go.sum differisce tra versioni di Go, quando sono installate più versioni di Go, quando si sceglie un binario Go per go mod tidy/test/build, o quando si configura un workflow Go ripetibile a più versioni.
