Обнаруживайте, выбирайте, переключайте и проверяйте Go‑toolchain’ы для репозитория без изменения глобального состояния системы. Используйте, когда сборка Go сообщает о несовместимом GOROOT или пакете стандартной библиотеки, когда поведение go.mod/go.sum различается между версиями Go, когда установлено несколько версий Go, при выборе бинарного файла Go для go mod tidy/test/build или при настройке воспроизводимого многоверсионного рабочего процесса Go.
