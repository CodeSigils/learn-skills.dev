Определять, выбирать, переключать и проверять наборы инструментов Go для репозитория без изменения глобального состояния системы. Использовать, когда сборка Go сообщает о несовместимом GOROOT или пакете стандартной библиотеки, когда поведение go.mod/go.sum различается в разных версиях Go, когда установлено несколько версий Go, при выборе бинарного файла Go для go mod tidy / test / build, или при настройке воспроизводимого многоверсионного рабочего процесса Go.
