Erkennen, Auswählen, Umschalten und Überprüfen von Go-Toolchains für ein Repository ohne Mutation des globalen Systemstatus. Wird verwendet, wenn ein Go-Build ein inkompatibles GOROOT- oder Standardbibliothekspaket meldet, wenn das Verhalten von go.mod/go.sum in den Go-Versionen unterschiedlich ist, wenn mehrere Go-Versionen installiert sind, wenn eine Go-Binärdatei für go mod tidy/test/build ausgewählt wird oder wenn ein wiederholbarer Go-Workflow mit mehreren Versionen eingerichtet wird.
