Erkennen, wählen, wechseln und überprüfen Sie Go-Toolchains für ein Repository, ohne den globalen Systemstatus zu ändern. Verwenden Sie diese Option, wenn ein Go-Build ein inkompatibles GOROOT- oder Standardbibliothekspaket meldet, wenn sich das Verhalten von go.mod/go.sum zwischen Go-Versionen unterscheidet, wenn mehrere Go-Versionen installiert sind, wenn Sie eine Go-Binärdatei für Go Mod Tidy/Test/Build auswählen oder wenn Sie einen wiederholbaren Go-Workflow mit mehreren Versionen einrichten.
