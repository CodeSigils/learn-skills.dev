Détectez, sélectionnez, changez et vérifiez les chaînes d'outils Go pour un référentiel sans muter l'état global du système. À utiliser lorsqu'une version Go signale un package GOROOT ou de bibliothèque standard incompatible, lorsque le comportement de go.mod/go.sum diffère selon les versions de Go, lorsque plusieurs versions de Go sont installées, lors du choix d'un binaire Go pour go mod spice/test/build, ou lors de la configuration d'un flux de travail Go multi-version reproductible.
