Détectez, sélectionnez, basculez et vérifiez les chaînes d'outils Go pour un référentiel sans modifier l'état du système global. À utiliser lorsqu'une build Go signale un package GOROOT ou de bibliothèque standard incompatible, lorsque le comportement de go.mod/go.sum diffère selon les versions Go, lorsque plusieurs versions Go sont installées, lors du choix d'un binaire Go pour go mod tidy/test/build, ou lors de la configuration d'un flux de travail Go multi-version reproductible.
