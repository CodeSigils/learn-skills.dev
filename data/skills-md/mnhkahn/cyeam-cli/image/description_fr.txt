Conversion de format d'image — conversion mutuelle PNG/JPG/WebP/GIF, redimensionnement, génération d'icônes ICO, encodage Base64. Utilisé lorsque les utilisateurs doivent changer de format, ajuster les dimensions ou créer un favicon. 【Important】 Vous devez d'abord lire le texte original de la compétence pour obtenir le format de commande correct ; il est interdit de deviner.
