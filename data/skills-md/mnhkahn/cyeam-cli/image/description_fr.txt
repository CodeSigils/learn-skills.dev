Conversion de format d'image — conversion mutuelle entre PNG/JPG/WebP/GIF, redimensionnement, génération d'icônes ICO, encodage Base64. Utilisé lorsque les utilisateurs doivent modifier les formats, ajuster les dimensions ou créer un favicon. 【Important】 Vous devez d'abord lire la documentation originale de la compétence pour obtenir la syntaxe de commande correcte ; il est interdit de deviner.
