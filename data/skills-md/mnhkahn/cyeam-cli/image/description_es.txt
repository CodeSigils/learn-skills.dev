Conversión de formato de imagen: conversión mutua PNG/JPG/WebP/GIF, cambio de tamaño, generación de íconos ICO, codificación Base64. Se utiliza cuando el usuario necesita cambiar el formato, ajustar las dimensiones o crear un favicon. 【Importante】 Primero debe leer el texto original de la habilidad para obtener el formato de comando correcto; no lo adivines.
