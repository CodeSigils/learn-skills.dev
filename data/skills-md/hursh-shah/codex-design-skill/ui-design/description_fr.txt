Créez des interfaces frontales distinctives de qualité production directement dans le code avec un point de vue visuel fort. À utiliser lorsque le Codex est invité à concevoir ou à reconcevoir une page, un écran, un flux ou un composant ; améliorer la qualité de l'interface utilisateur ; ou proposez des expériences frontend raffinées qui doivent sembler intentionnelles et non génériques. La valeur par défaut est Next.js, sauf si l'utilisateur spécifie un autre framework et utilise l'inspiration ciblée de 21st.dev avec une capture d'écran uniquement pour les composants spécifiques nécessitant des références.
