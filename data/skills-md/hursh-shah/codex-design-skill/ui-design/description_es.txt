Cree interfaces frontales distintivas y de nivel de producción directamente en código con un sólido punto de vista visual. Úselo cuando se le solicite a Codex que diseñe o rediseñe una página, pantalla, flujo o componente; mejorar la calidad de la interfaz de usuario; o ofrecer experiencias de interfaz pulidas que deben parecer intencionales y no genéricas. El valor predeterminado es Next.js a menos que el usuario especifique otro marco, y use inspiración específica de 21st.dev con captura de pantalla solo para componentes específicos que necesitan referencias.
