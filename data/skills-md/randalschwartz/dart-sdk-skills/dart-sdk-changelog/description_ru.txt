Экспертное руководство и справочник по поиску журнала изменений Dart SDK, истории версий, экспериментальных функций, макросов и дополнений от Dart 1.x до современной версии Dart 3.x. Используйте этот навык всякий раз, когда пользователь спрашивает «что нового в Dart X», «что нового в 3.13», «что нового в 3.12», спрашивает, как найти минимальную версию SDK (minSdk) для какой-либо функции языка или основного API, нуждается в руководстве по флагам экспериментальных функций (--enable-experiment), макросам и дополнениям (augment, augmented(), import augment) или требует помощи при спасении и модернизации устаревшие кодовые базы Dart 1.x/pre-2.12 на современные Dart 3.x.
