Guida esperta e riferimento per la ricerca di Dart SDK CHANGELOG, cronologia delle versioni, funzionalità sperimentali, macro e miglioramenti da Dart 1.x al moderno Dart 3.x. Utilizzare questa competenza ogni volta che l'utente chiede "novità di Dart X", "novità di 3.13", "novità di 3.12", chiede come trovare la versione minima dell'SDK (minSdk) per qualsiasi funzionalità del linguaggio o API principale, necessita di indicazioni su flag di funzionalità sperimentali (--enable-experiment), macro e miglioramenti (augment, augmented(), import augment) o richiede assistenza per il salvataggio e la modernizzazione di Dart legacy 1.x / pre-2.12 al moderno Dart 3.x.
