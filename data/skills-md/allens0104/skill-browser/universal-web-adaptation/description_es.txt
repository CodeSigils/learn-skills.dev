Utilice esta habilidad cuando se le solicite trabajar con un sitio web público desconocido y el objetivo sea progresar de manera genérica antes de escribir reglas específicas del sitio. Le enseña a Copilot cómo sondear controles, clasificar patrones de interfaz de usuario, probar múltiples estrategias de búsqueda y navegación, seguir ventanas emergentes y solo crear un perfil de sitio cuando el enfoque genérico ya no es suficiente.
