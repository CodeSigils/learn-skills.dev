Используйте этот навык, когда вас просят поработать с незнакомым общедоступным веб-сайтом, и цель состоит в том, чтобы добиться общего прогресса, прежде чем писать правила для конкретного сайта. Он учит Copilot проверять элементы управления, классифицировать шаблоны пользовательского интерфейса, пробовать несколько стратегий поиска и навигации, следить за всплывающими окнами и создавать профиль сайта только тогда, когда общего подхода уже недостаточно.
