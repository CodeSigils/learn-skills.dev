Genere presentaciones visuales de estilo "imagen + texto" en el marco React de diapositiva abierta con el sistema de diseño de 绿皮火车: temas verde azulado oscuro / coral oscuro, cuatro diseños principales (portada de héroe / portada de capítulo / comida para llevar / tesis), imágenes de fondo de Nano Banana y disciplina de tipografía de zona segura. Úselo cuando el usuario desee una presentación de diapositivas cinematográfica y visualmente densa donde el diseño se base en imágenes en lugar de texto y se sienta cómodo enviando una URL estática o un PDF.
