Générez des présentations visuelles de style « image + texte » sur le framework React ouvert avec le système de conception de 绿皮火车 : thèmes bleu sarcelle foncé/corail foncé, quatre mises en page principales (couverture de héros/couverture de chapitre/à emporter/thèse), images d'arrière-plan Nano Banana et discipline typographique de zone de sécurité. À utiliser lorsque l'utilisateur souhaite un diaporama cinématographique visuellement dense où la mise en page est basée sur l'image plutôt que sur le texte et est à l'aise pour envoyer une URL statique ou un PDF. PAS pour la sortie du fichier .pptx hérité - ce chemin a été supprimé dans la version 1.0 ; la future exportation PPTX est prévue comme une contribution en amont à diapositive ouverte.
