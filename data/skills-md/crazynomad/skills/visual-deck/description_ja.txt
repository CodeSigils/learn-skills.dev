绿皮火车のデザイン システムを使用して、オープン スライドの React フレームワーク上で「画像 + テキスト」スタイルのビジュアル デッキを生成します。ダーク ティール / ダーク コーラルのテーマ、4 つのコア レイアウト (ヒーロー カバー / チャプター カバー / テイクアウェイ / 論文)、Nano Banana の背景画像、および安全ゾーンのタイポグラフィ規律です。ユーザーが、レイアウトがテキスト駆動ではなく画像駆動で、静的な URL または PDF を配布することに抵抗がない、視覚的に密度の高い映画のようなスライド デッキを必要とする場合に使用します。従来の .pptx ファイル出力用ではありません。そのパスは v1.0 で削除されました。将来の PPTX エクスポートは、オープン スライドの上流への貢献として計画されています。
