Orientación experta para el desarrollo del miniprograma WeChat. Utilice esta habilidad cuando el usuario mencione la creación, modificación, depuración u optimización de un miniprograma WeChat y necesite ayuda con las API wx.*, WXML/WXSS/WXS, desarrollo en la nube (funciones en la nube, base de datos en la nube, almacenamiento en la nube), optimización de setData, navegación de páginas, desarrollo de componentes, compatibilidad de plataforma (iOS/Android), ajuste del rendimiento o configuración de app.json/project.config.json. También se aplica a tareas que involucran palabras clave específicas del Mini Programa, como AppID, carga de subpaquetes, vista previa de dispositivo real, implementación de herramientas de desarrollo de WeChat, etc. Siempre que el usuario esté trabajando en cualquier aspecto del desarrollo del Mini Programa WeChat, se debe utilizar esta habilidad, incluso si no menciona explícitamente el "Mini Programa".
