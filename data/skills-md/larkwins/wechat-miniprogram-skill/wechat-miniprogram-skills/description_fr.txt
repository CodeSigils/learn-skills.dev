Conseils d’experts pour le développement du programme WeChat Mini. Utilisez cette compétence lorsque l'utilisateur mentionne la création, la modification, le débogage ou l'optimisation d'un programme WeChat Mini et a besoin d'aide avec les API wx.*, WXML/WXSS/WXS, le développement cloud (fonctions cloud, base de données cloud, stockage cloud), l'optimisation setData, la navigation dans les pages, le développement de composants, la compatibilité des plateformes (iOS/Android), le réglage des performances ou la configuration de app.json/project.config.json. Cela s'applique également aux tâches impliquant des mots-clés spécifiques au mini-programme tels que AppID, le chargement de sous-packages, l'aperçu de l'appareil réel, le déploiement des outils de développement WeChat, etc. Chaque fois que l'utilisateur travaille sur un aspect du développement du mini-programme WeChat, cette compétence doit être utilisée, même s'il ne mentionne pas explicitement « mini-programme ».
