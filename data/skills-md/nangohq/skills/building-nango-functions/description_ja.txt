ローカル CLI またはリモート API ワークフローを選択せず​​に、createAction() および createSync() の Nango 関数実装パターンを構築します。ユーザーが Nango アクションまたは同期の作成または更新を要求し、その作業がチェックアウトされたプロジェクトで CLI 経由で実行されるべきか、Nango リモート API 経由で実行されるべきかが不明瞭な場合にのみ使用します。 build-nango-functions-locally またはbuilding-nango-functions-remotely が適用される場合はロードしません。これらのスキルはこのコンテンツと重複しており、ワークフロー固有の検証と展開の詳細を追加します。
