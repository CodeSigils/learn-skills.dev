Crea modelli di implementazione della funzione Nango per createAction() e createSync() senza scegliere un flusso di lavoro CLI locale o API remota. Da utilizzare solo quando l'utente richiede di creare o aggiornare un'azione o una sincronizzazione di Nango e non è chiaro se il lavoro debba avvenire in un progetto estratto tramite CLI o tramite API remote di Nango. Non caricare quando si applica building-nango-functions-localmente o building-nango-functions-remoto; tali competenze si sovrappongono a questo contenuto e aggiungono dettagli di convalida e distribuzione specifici del flusso di lavoro.
