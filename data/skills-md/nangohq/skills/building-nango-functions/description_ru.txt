Создает шаблоны реализации функций Nango для createAction() и createSync() без выбора рабочего процесса локального CLI или удаленного API. Используйте только тогда, когда пользователь запрашивает создание или обновление действия или синхронизации Nango, и неясно, должна ли работа выполняться в извлеченном проекте через CLI или через удаленные API Nango. Не загружайте, когда применяется локальное построение нанго-функций или удаленное построение нанго-функций; эти навыки пересекаются с этим контентом и добавляют детали проверки и развертывания, специфичные для рабочего процесса.
