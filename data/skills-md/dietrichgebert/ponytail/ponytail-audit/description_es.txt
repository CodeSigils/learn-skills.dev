Auditoría de repositorio completo para detectar exceso de ingeniería. Como ponytail-review, pero escanea todo el código base en lugar de una diferencia: una lista clasificada de qué eliminar, simplificar o reemplazar con equivalentes stdlib/nativo. Úselo cuando el usuario diga "auditar este código base", "auditar el exceso de ingeniería", "qué puedo eliminar de este repositorio", "buscar hinchazón", "ponytail-audit" o "/ponytail-audit". Informe único, no aplica correcciones.
