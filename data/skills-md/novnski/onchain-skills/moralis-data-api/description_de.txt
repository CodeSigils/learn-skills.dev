Query Web3 blockchain data from Moralis API. Wird verwendet, wenn der Benutzer nach Wallet-Daten (Guthaben, Token, NFTs, Transaktionsverlauf, Rentabilität, Nettovermögen), Token-Daten (Preise, Metadaten, DEX-Paare, Analysen, Sicherheitsbewertungen), NFT-Daten (Metadaten, Transfers, Merkmale, Seltenheit, Mindestpreise), DeFi-Positionen, Entitäts-/Label-Daten für Börsen und Fonds oder Block- und Transaktionsdaten fragt. Supports EVM chains (Ethereum, Polygon, BSC, Arbitrum, Base, Optimism, Avalanche, etc.) and Solana. NOT for real-time streaming - use moralis-streams-api instead.
