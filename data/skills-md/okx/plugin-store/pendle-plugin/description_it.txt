Plugin di tokenizzazione del rendimento di Pendle Finance. Acquista o vendi token PT a rendimento fisso, scambia token di rendimento YT, fornisci o rimuovi liquidità AMM e conia o riscatta coppie PT+YT. Frasi trigger: acquista PT, vendi PT, acquista YT, vendi YT, rendimento fisso Pendle, liquidità Pendle, aggiungi liquidità Pendle, rimuovi liquidità Pendle, conia PT YT, riscatta PT YT, posizioni Pendle, mercati Pendle, Pendle APY. Cinese: 购买PT, 出售PT, 购买YT, 出售YT, Pendle固定收益, Pendle流动性, Pendle持仓, Pendle市场
