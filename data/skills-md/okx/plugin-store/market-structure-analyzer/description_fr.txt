Agent de recherche sur la structure du marché de la cryptographie – plus de 24 indicateurs sur les produits dérivés, les options (mur gamma, biais), en chaîne (MVRV, signaux d'argent intelligents, jetons chauds DEX) et le sentiment macro. Propulsé par OKX CeFi CLI + OnchainOS + HTTP direct pour la chaîne d'options.

Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur : les données sur les produits dérivés, le mur gamma, le biais d'options, les taux de financement, l'intérêt ouvert, le ratio put/call, MVRV, la base de coût, le prix réalisé, les flux de change, les entrées/sorties de CEX, la pression de liquidation, le suivi des baleines, les flux d'argent intelligents, l'indice de peur/cupidité, la domination BTC, les flux de pièces stables, le volume des preneurs, la base/le déport, ou toute demande telle que "à quoi ressemble la structure du marché", "donnez-moi un aperçu macro", "comment sont les dérivés positionné", "le marché est-il surendetté", "dois-je être haussier ou baissier sur la base des données", "les baleines accumulent-elles ou distribuent-elles", "montrez-moi les flux d'échange". Déclenchez également lorsque les utilisateurs mentionnent des jetons spécifiques et souhaitent une analyse plus approfondie au-delà de la simple action sur les prix – par exemple, « que se passe-t-il avec l'ETH en ce moment », « le BTC est-il sur le point de bouger », « analyser les conditions du marché SOL ».
