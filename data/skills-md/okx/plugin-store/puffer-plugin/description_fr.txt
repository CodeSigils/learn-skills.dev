Reprise liquide sur Puffer Finance (Ethereum). Déposez de l'ETH dans PufferVault pour créer du pufETH (ERC-4626 nLRT). Vérifiez le solde, le taux pufETH<->ETH actuel et les frais de sortie. Choisissez entre le retrait instantané en 1 étape (tx unique, paie les frais de sortie - 1 par défaut) ou le retrait en file d'attente en 2 étapes (sans frais, ~ 14 jours). Toutes les commandes d'écriture impriment du JSON structuré sur la sortie standard afin que les agents externes puissent décider de l'étape suivante sans analyser stderr.
