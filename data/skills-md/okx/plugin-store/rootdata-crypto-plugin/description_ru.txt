RootData — это ведущая платформа данных Web3, охватывающая криптопроекты, инвесторов, данные о финансировании и перемещениях персонала. Этот навык представляет собой специальную интеграцию OKX, изолированную от стандартного навыка RootData с собственным пространством имен ключей API и конечными точками.
