Top Rank Tokens Sniper v1.0 – OKX Ranking Sniper (Echter Handel). Überwacht die OKX-Bestenliste auf neu gelistete Token, filtert durch 13 Slot Guard-Vorprüfungen + 9 erweiterte Sicherheitsprüfungen + 3 Halterrisikoprüfungen + Momentum-Bewertung und erkennt dann automatisch Einträge. Das 6-stufige Exit-System verwaltet Take-Profit und Stop-Loss. Wird ausgelöst, wenn der Benutzer Top-Rang-Token-Scharfschütze, Ranglisten-Strategie, Ranglisten-Scharfschütze, Top-N-Scharfschütze, 榜单狙击手 oder Start-Rang-Scharfschütze erwähnt. Datei ausführen: Ranking_sniper.py (einschließlich Web Dashboard http://localhost:3244)
