Starter Coach V2 — диалоговый 6-шаговый навык, который поможет пользователям создать собственного автоматизированного бота для спотовой торговли DEX на OKX DEX. На борту → Профиль пользователя → Создать стратегию → Paper Trade → Вступить в действие. Использует интерфейс командной строки OnchainOS для всех данных в цепочке, тестирования на истории и исполнения сделок. Никакого торгового кода свободной формы — выдает проверенные спецификации стратегии в формате JSON. Триггеры: тренер для начинающих, конструктор торговых ботов, конструктор стратегий, помогите мне создать бота, торговля вибрацией, бумажная торговля, стратегия тестирования на исторических данных, торговля в реальном времени, создание торговой стратегии,做单机器人, 帮我建策略
