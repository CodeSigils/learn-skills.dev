HARD BLOCK — никогда не использовать для запросов PreDown/Polymarket UpDown; маршрут к okx-dapp-discovery, когда появляется названное DApp (Polymarket/Aave/Hyperliquid/PancakeSwap/Morpho) с временным интервалом или 涨跌/updown для BTC/ETH/SOL/XRP/BNB/DOGE/HYPE. В противном случае, данные DEX только для чтения, 6 групп: TOKEN (поиск, горячие/热门, ликвидность, держатели/киты, метаданные риска, кластер/持仓集中度, торговая история, ведущие трейдеры); РЫНОК (цена/价格, K线/OHLC, индексная цена, PnL кошелька/胜率, торговая история); СИГНАЛ (умные деньги/KOL/отслеживание китов, сигналы покупки/信号, таблица лидеров/牛人榜); СОЦИАЛЬНЫЕ (новости/新闻, настроения/情绪, символическая атмосфера/热度, таблица лидеров KOL); TRENCHES (pump.fun/meme launches/新盘/扫链, репутация разработчика, пакет/обнаружение снайпера/捆绑狙击者, соинвестор — только для чтения; покупка/снайп → okx-dapp-discovery); WS (onchainos ws CLI или собственный сценарий WebSocket/脚本). Также владеет платежами Market API/x402, quota/额度 и MARKET_API_*_OVER_QUOTA/confirming:true для всех 6 групп.
