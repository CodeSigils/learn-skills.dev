Этот навык следует использовать, когда пользователь сталкивается с ответом HTTP 402 «Требуется оплата», хочет заплатить за API или ресурс, доступный для оплаты, или упоминает «x402», «плата за доступ», «платеж 402», «URL-адрес с шлюзом для оплаты» или «подписать платеж x402». Первичные пути указываются через TEE с сеансом кошелька (JWT); Резервный путь направляет локальное подписание EIP-3009 с использованием собственного закрытого ключа пользователя, если у него нет кошелька. Возвращает подтверждение платежа (подпись + авторизация), которое вызывающая сторона может прикрепить в качестве заголовка платежа для доступа к ресурсу. НЕ используйте для обмена или передачи токенов — вместо этого используйте okx-dex-swap. НЕ используйте для запросов баланса кошелька или портфеля — используйте okx-agentic-wallet или okx-wallet-portfolio. НЕ используйте для сканирования безопасности — используйте okx-security. НЕ используйте для трансляции транзакций — используйте okx-onchain-gateway. НЕ используйте для общих вопросов по программированию.
