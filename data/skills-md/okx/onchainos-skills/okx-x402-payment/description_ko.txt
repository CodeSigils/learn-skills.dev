이 기술은 사용자가 HTTP 402 결제 필요 응답을 접하거나 결제 관리 API 또는 리소스에 대한 비용을 지불하려고 하거나 'x402', '액세스 비용 지불', '402 결제', '결제 관리 URL' 또는 'x402 결제 서명'을 언급할 때 사용해야 합니다. 지갑 세션(JWT)을 통해 TEE를 통해 기본 경로가 서명됩니다. 대체 경로는 지갑이 없는 경우 사용자 자신의 개인 키로 로컬 EIP-3009 서명을 안내합니다. 호출자가 리소스에 액세스하기 위해 결제 헤더로 첨부할 수 있는 결제 증명(서명 + 승인)을 반환합니다. 스왑이나 토큰 전송에는 사용하지 마세요. 대신 okx-dex-swap을 사용하세요. 지갑 잔액이나 포트폴리오 쿼리에는 사용하지 마세요. okx-agentic-wallet 또는 okx-wallet-portfolio를 사용하세요. 보안 검색에는 사용하지 마십시오. okx-security를 ​​사용하십시오. 트랜잭션 브로드캐스팅에 사용하지 마세요. okx-onchain-gateway를 사용하세요. 일반적인 프로그래밍 질문에는 사용하지 마세요.
