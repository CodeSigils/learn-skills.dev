當使用者遇到 HTTP 402 Payment Needed 回應、想要為付款門控 API 或資源付費，或提及「x402」、「付費存取」、「402 付款」、「付款門控 URL」或「簽署 x402 付款」時，應使用此技能。主要路徑透過 TEE 與錢包會話 (JWT) 進行簽署；如果使用者沒有錢包，後備路徑會指導使用使用者自己的私鑰進行本機 EIP-3009 簽署。傳回呼叫者可以附加為付款標頭以存取資源的付款證明（簽名+授權）。請勿用於交換或代幣轉移 — 請改用 okx-dex-swap。請勿用於錢包餘額或投資組合查詢 - 使用 okx-agentic-wallet 或 okx-wallet-portfolio。請勿用於安全掃描 — 使用 okx-security。請勿用於交易廣播 — 使用 okx-onchain-gateway。請勿用於一般編程問題。
