Esta habilidad debe usarse cuando el usuario encuentra una respuesta HTTP 402 Pago requerido, quiere pagar por una API o recurso de pago, o menciona 'x402', 'pago por acceso', 'pago 402', 'URL de pago' o 'firmar pago x402'. Señales de ruta primaria a través de TEE con una sesión de billetera (JWT); La ruta alternativa guía la firma local EIP-3009 con la clave privada del usuario si no tiene billetera. Devuelve el comprobante de pago (firma + autorización) que el llamante puede adjuntar como encabezado de pago para acceder al recurso. NO lo use para intercambios o transferencias de tokens; use okx-dex-swap en su lugar. NO lo use para consultas de saldo de billetera o cartera; use okx-agentic-wallet o okx-wallet-portfolio. NO lo use para escaneo de seguridad; use okx-security. NO lo use para transmisión de transacciones; use okx-onchain-gateway. NO lo use para preguntas generales de programación.
