当用户遇到 HTTP 402 Payment Needed 响应、想要为付款门控 API 或资源付费，或提及“x402”、“付费访问”、“402 付款”、“付款门控 URL”或“签署 x402 付款”时，应使用此技能。主要路径通过 TEE 与钱包会话 (JWT) 进行签名；如果用户没有钱包，后备路径会指导使用用户自己的私钥进行本地 EIP-3009 签名。返回调用者可以附加为付款标头以访问资源的付款证明（签名+授权）。请勿用于交换或代币转移 — 请改用 okx-dex-swap。请勿用于钱包余额或投资组合查询 - 使用 okx-agentic-wallet 或 okx-wallet-portfolio。请勿用于安全扫描 — 使用 okx-security。请勿用于交易广播 — 使用 okx-onchain-gateway。请勿用于一般编程问题。
