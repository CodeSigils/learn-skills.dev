Cette compétence doit être utilisée lorsque l'utilisateur rencontre une réponse HTTP 402 Payment Required, souhaite payer pour une API ou une ressource à paiement limité, ou mentionne « x402 », « payer pour l'accès », « paiement 402 », « URL à paiement limité » ou « signer un paiement x402 ». Signalisation du chemin principal via TEE avec une session de portefeuille (JWT) ; Le chemin de secours guide la signature EIP-3009 locale avec la propre clé privée de l'utilisateur s'il n'a pas de portefeuille. Renvoie la preuve de paiement (signature + autorisation) que l'appelant peut joindre en en-tête de paiement pour accéder à la ressource. Ne PAS utiliser pour les échanges ou les transferts de jetons – utilisez plutôt okx-dex-swap. Ne PAS utiliser pour le solde du portefeuille ou les requêtes de portefeuille – utilisez okx-agentic-wallet ou okx-wallet-portfolio. Ne PAS utiliser pour l'analyse de sécurité - utilisez okx-security. Ne PAS utiliser pour la diffusion de transactions – utilisez okx-onchain-gateway. Ne PAS utiliser pour des questions générales de programmation.
