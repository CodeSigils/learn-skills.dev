このスキルは、ユーザーが HTTP 402 Payment Required 応答に遭遇した場合、支払いゲート API またはリソースの支払いを希望する場合、または「x402」、「アクセスに対する支払い」、「402 支払い」、「支払いゲート URL」、または「x402 支払いへの署名」に言及した場合に使用する必要があります。ウォレット セッション (JWT) を使用した TEE 経由のプライマリ パス署名。フォールバック パスは、ユーザーがウォレットを持っていない場合、ユーザー自身の秘密キーを使用したローカル EIP-3009 署名をガイドします。呼び出し元がリソースにアクセスするために支払いヘッダーとして添付できる支払い証明 (署名 + 承認) を返します。スワップまたはトークン転送には使用しないでください。代わりに okx-dex-swap を使用してください。ウォレット残高やポートフォリオのクエリには使用しないでください。okx-agentic-wallet または okx-wallet-portfolio を使用してください。セキュリティ スキャンには使用しないでください。okx-security を使用してください。トランザクションのブロードキャストには使用しないでください。okx-onchain-gateway を使用してください。一般的なプログラミングの質問には使用しないでください。
