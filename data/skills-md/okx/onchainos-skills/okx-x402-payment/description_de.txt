Dieser Skill sollte verwendet werden, wenn der Benutzer auf eine HTTP-402-Zahlung erforderlich-Antwort stößt, für eine zahlungsgesteuerte API oder Ressource bezahlen möchte oder „x402“, „für Zugriff bezahlen“, „402-Zahlung“, „zahlungsgesteuerte URL“ oder „x402-Zahlung signieren“ erwähnt. Primärpfadschilder über TEE mit einer Wallet-Sitzung (JWT); Der Fallback-Pfad leitet die lokale EIP-3009-Signierung mit dem eigenen privaten Schlüssel des Benutzers, wenn dieser keine Wallet hat. Gibt den Zahlungsnachweis (Signatur + Autorisierung) zurück, den der Anrufer als Zahlungskopf anhängen kann, um auf die Ressource zuzugreifen. NICHT für Swap- oder Token-Transfers verwenden – verwenden Sie stattdessen okx-dex-swap. NICHT für Wallet-Guthaben- oder Portfolio-Abfragen verwenden – verwenden Sie okx-agentic-wallet oder okx-wallet-portfolio. NICHT für Sicherheitsscans verwenden – verwenden Sie okx-security. NICHT für Transaktions-Broadcasting verwenden – verwenden Sie okx-onchain-gateway. NICHT für allgemeine Programmierfragen verwenden.
