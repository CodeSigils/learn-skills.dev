Utilice esta habilidad cuando el usuario mencione la creación de un enlace de pago, el pago de un enlace de pagoId/a2a_... o la verificación del estado del pago de a2a. Incluye el protocolo de pago de agente a agente "onchainos Payment a2a-pay": "creación" del lado del vendedor, "pago" del lado del comprador a través de EIP-3009 + firma TEE y consulta de "estado". La confianza del lado del comprador se delega al nivel ascendente: la habilidad firma lo que declara el desafío en el servidor. NO lo use para recursos HTTP 402 externos; use okx-x402-paid. NO lo use para saldo/transferencia/inicio de sesión de billetera; use okx-agentic-wallet.
