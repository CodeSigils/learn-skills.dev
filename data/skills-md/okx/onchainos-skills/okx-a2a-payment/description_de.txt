Verwenden Sie diesen Skill, wenn der Benutzer erwähnt, dass er einen Zahlungslink erstellt, einen paymentId/a2a_...-Link bezahlt oder den a2a-Zahlungsstatus überprüft. Umfasst das Agent-zu-Agent-Zahlungsprotokoll „onchainos payment a2a-pay“: Verkäuferseite „Erstellen“, Käuferseite „Bezahlen“ über EIP-3009 + TEE-Signierung und „Status“-Abfrage. Das Vertrauen auf Käuferseite wird an den Upstream delegiert – der Skill signiert alles, was die Herausforderung auf dem Server angibt. NICHT für externe HTTP 402-Ressourcen verwenden – verwenden Sie okx-x402-paid. NICHT für Wallet-Guthaben/Transfer/Login verwenden – verwenden Sie okx-agentic-wallet.
