x402 (`exact` / `aggr_deferred` スキーム)、MPP (`charge` / `session` インテント)、および a2a-pay (`a2a_charge`paymentId フロー) をカバーする統合支払いディスパッチャー。応答ヘッダーから HTTP 402 プロトコルを検出し、一致するスキーム/インテント参照にルーティングします。 402 なしの a2apaymentId メンションも処理します。「references/exact.md」（x402 の正確なスキーム - 完全な EIP-3009 TEE またはローカルキー フォールバック）、「references/aggr_deferred.md」（x402 aggr_deferred スキーム - sessionCert を使用したセッション キー Ed25519）、「references/charge.md」（MPP）をロードします。トランザクションまたはハッシュ モードでのワンショット チャージ、分割あり)、`references/session.md` (MPP チャネル: オープン + バウチャー ループ + topUp + close、状態エコーあり)、または `references/a2a_charge.md` (a2a-pay 作成 / 支払い / 自動ポーリング ステータス)。すぐに貼り付けられる認証ヘッダー (x402 / MPP) または tx-hash + ステータス (a2a) を返します。トリガーワード (英語): '402'、'payment required'、'mpp'、'machinepayment'、'pay for access'、'payment-gated'、'WWW-Authenticate: Payment'、'x402'、'x402Version'、'PAYMENT-REQUIRED'、'PAYMENT-SIGNATURE'、'X-PAYMENT'、'open channel'、 'バウチャー'、'セッション支払い'、'チャネルを閉じる'、'トップアップ チャネル'、'トップアップ チャネル'、'決済チャネル'、'セッション決済'、'返金チャネル'、'channelId'、'channel_id'、'paymentId'、'a2a_'、'a2a支払い'、'支払いリンクの作成'、'支払いリンク'、'支払いステータス'。トリガーワード (中国語): '支付道'、'关闭道'、'关闭会话'、'关闭支付道'、'充值道'、'续费道'、'结算通道'、'结算会话'、'关单'、 「凭证」、「会话支付」、「付款链接」、「创建支付」、「支付状态」。重大な機密性ルール: 「channel_id」、「0x...」チャネル ハッシュ、または「セッション」/「チャネル」コンテキスト = MPP セッション中の操作の近くでクローズ / トップアップ / 決済 / バウチャー / 払い戻しに関するユーザーの言及 - このスキルをロードし、「references/session.md」にジャンプし、別のクローズ/トップアップ ツールを検索しないでください。
