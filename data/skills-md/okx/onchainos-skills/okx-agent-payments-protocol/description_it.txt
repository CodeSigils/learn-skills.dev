Dispatcher di pagamento unificato che copre x402 (schemi `exact` / `aggr_deferred`), MPP (intenti `charge` / `session`) e a2a-pay (flusso paymentId `a2a_charge`). Rileva il protocollo HTTP 402 dalle intestazioni di risposta e dai percorsi al riferimento allo schema/intento corrispondente; gestisce anche le menzioni a2a paymentId senza 402. Carica `references/exact.md` (schema esatto x402 — TEE EIP-3009 completo o fallback con chiave locale), `references/aggr_deferred.md` (schema x402 aggr_deferred — Session Key Ed25519 con sessionCert), `references/charge.md` (addebito MPP one-shot nella transazione o hash modalità, con suddivisioni), `references/session.md` (canale MPP: aperto + voucher loop + topUp + chiudi, con stato eco) o `references/a2a_charge.md` (a2a-pay create / pay / status auto-poll). Restituisce un'intestazione di autorizzazione pronta da incollare (x402/MPP) o un hash tx + stato (a2a).
