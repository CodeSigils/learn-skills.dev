Используйте этот навык, когда пользователь просит: «найти торговый навык», «поиск навыков», «установить навык», «добавить навык», «загрузить навык», «просмотреть рынок навыков», «какие навыки доступны», «обновить навык», «проверить наличие обновлений навыков», «удалить навык», «удалить навык», «перечислить установленные навыки», «показать мои навыки», «категории навыков» или любой запрос на обнаружение, установку, обновляйте или управляйте торговыми навыками ИИ на торговой площадке OKX Skills Marketplace. Этот навык охватывает поиск, просмотр категорий, установку через CLI, загрузку zip-пакетов, проверку наличия обновлений и удаление установленных навыков. Требуются учетные данные API для доступа к API торговой площадки. НЕ используйте для размещения ордеров (используйте okx-cex-trade), рыночных данных (используйте okx-cex-market) или управления ботами (используйте okx-cex-bot).
