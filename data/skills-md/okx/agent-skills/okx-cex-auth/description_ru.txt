Используйте этот навык, когда пользователь хочет «войти в систему/вход/вход», «аутентифицироваться», «авторизовать», «подключить учетную запись OKX», «настроить учетные данные», «первая настройка», «настроить okx», «登录», «授权», «认证», «连接账户», «首次配置». Также, когда любая команда OKX CLI завершается с ошибкой аутентификации: «Сначала запустите аутентификацию okx», «Сессия истекла», «не аутентифицирована», «requires_auth», «401 Unauthorized», «токен истек/не найден», «StorageNotFoundError», «会话过期», «未认证», '需要登录'. Также, когда пользователь спрашивает о статусе входа или вход в систему был прерван. Также, когда пользователь хочет установить/обновить/проверить/удалить двоичный файл okx-auth — «установить/обновить/удалить аутентификацию», «загрузить okx-auth», «安装/更新/卸载认证», «статус двоичного файла аутентификации», «Не удалось создать okx-auth». Также используйте перед первым использованием okx-cex-trade/portfolio/earn/bot. НЕ используйте для запросов рыночных данных (используйте okx-cex-market).
