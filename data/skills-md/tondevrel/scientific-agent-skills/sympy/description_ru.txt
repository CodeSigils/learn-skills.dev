Подробное руководство по SymPy — библиотеке Python для символьной математики. Используется для символьных выражений, исчисления (производные, интегралы, пределы, ряды), решения уравнений (алгебраических, дифференциальных, систем), линейной алгебры, упрощения, матричных операций, специальных функций, генерации кода и математических доказательств. Необходим для аналитической математики и компьютерной алгебры.
