Guide complet pour SymPy - Bibliothèque Python pour les mathématiques symboliques. Utilisation pour les expressions symboliques, le calcul (dérivées, intégrales, limites, séries), la résolution d'équations (algébrique, différentielle, systèmes), l'algèbre linéaire, la simplification, les opérations matricielles, les fonctions spéciales, la génération de code et les preuves mathématiques. Indispensable pour les mathématiques analytiques et le calcul formel.
