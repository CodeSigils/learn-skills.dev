Biblioteca de bioinformática y estadísticas de ecología comunitaria. Proporciona estructuras de datos y algoritmos para secuencias, alineamientos, filogenética y análisis de diversidad. Esencial para la investigación del microbioma y la ciencia de datos ecológicos. Úselo para métricas de diversidad alfa/beta, ordenación (PCoA), árboles filogenéticos, manipulación de secuencias (ADN/ARN/Proteína), matrices de distancia, PERMANOVA y análisis de ecología comunitaria.
