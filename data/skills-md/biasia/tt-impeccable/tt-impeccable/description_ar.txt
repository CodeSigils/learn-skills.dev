قم ببناء واجهات TikTok-native (TUX) أو تحسينها أو إعدادها بجودة على مستوى الإنتاج. استخدم هذا عند إنشاء أي مكون أو شاشة TikTok/TUX UI، أو صياغة ميزة TikTok الأصلية، أو إعداد سياق مشروع TUX، أو محاذاة القيم المشفرة مع رموز TUX v2 الرسمية. ثلاثة أوضاع: "الحرفية" (الشكل ثم البناء)، "التدريس" (إعداد سياق المشروع)، "الاستخراج" (محاذاة الرمز المميز). قم بتشغيل أي طلب يتضمن تصميم TikTok، أو نظام تصميم TUX، أو شاشات الهاتف المحمول بنمط TikTok، أو أسطح الويب/التسويق TT Style - حتى لو لم يذكر المستخدم TUX أو لا تشوبها شائبة بالاسم.
