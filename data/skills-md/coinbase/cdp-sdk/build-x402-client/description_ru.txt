кошелек, управляемый CDP. Охватывает TypeScript и Python. Используйте, когда пользователь хочет позвонить на платную
конечная точка из собственного приложения или агента, добавить платежи x402 в HTTP-клиент, обратиться к API
который взимает плату за запрос, переносит существующий клиент x402 с необработанного закрытого ключа или зависает на
неожиданный ответ 402.
