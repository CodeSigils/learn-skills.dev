Operaciones de billetera criptográfica a través de la CLI de awal: inicie sesión, verifique saldos, envíe USDC/ETH/POL/SOL, intercambie tokens, financie la billetera y use el protocolo de pago x402 para descubrir servicios pagos, pagar llamadas API, monetizar una API o consultar datos en cadena. Úselo siempre que el usuario mencione el inicio de sesión, la autenticación, el estado de la billetera, el saldo, la dirección, el envío de dinero, el pago a alguien, la transferencia de tokens, los nombres de ENS, el intercambio/negociación/conversión de tokens, la financiación/recarga/entrada, USDC, ETH, POL, SOL, el bazar x402, las API pagas, la monetización de un punto final o la consulta de datos en cadena en Base.
