Opérations de portefeuille crypto via la CLI awal : connectez-vous, vérifiez les soldes, envoyez USDC/ETH/POL/SOL, échangez des jetons, financez le portefeuille et utilisez le protocole de paiement x402 pour découvrir des services payants, payer des appels d'API, monétiser une API ou interroger des données en chaîne. À utiliser chaque fois que l'utilisateur mentionne la connexion, la connexion, l'authentification, le statut du portefeuille, le solde, l'adresse, l'envoi d'argent, le paiement à quelqu'un, le transfert de jetons, les noms ENS, l'échange/l'échange/la conversion de jetons, le financement/recharge/onramp, USDC, ETH, POL, SOL, le bazar x402, les API payantes, la monétisation d'un point de terminaison ou l'interrogation de données en chaîne sur Base.
