Operazioni del portafoglio crittografico tramite la CLI di awal: accedi, controlla i saldi, invia USDC/ETH/POL/SOL, scambia token, finanzia il portafoglio e utilizza il protocollo di pagamento x402 per scoprire servizi a pagamento, pagare per chiamate API, monetizzare un'API o interrogare dati onchain. Utilizzare ogni volta che l'utente menziona accesso, login, autenticazione, stato del portafoglio, saldo, indirizzo, invio di denaro, pagamento a qualcuno, trasferimento di token, nomi ENS, scambio/negoziazione/conversione di token, finanziamento/ricarica/onramp, USDC, ETH, POL, SOL, il bazaar x402, API a pagamento, monetizzazione di un endpoint o query di dati onchain su Base.
