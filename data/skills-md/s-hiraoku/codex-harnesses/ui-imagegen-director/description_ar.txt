تعمل واجهة المستخدم الأمامية عالية الجودة بشكل مباشر باستخدام Codex Image Gen للنماذج المرئية، ثم تنفيذ الاتجاه المحدد في التعليمات البرمجية باستخدام ضمان الجودة المرئي المستند إلى المتصفح. يُستخدم عندما يطلب المستخدم واجهة مستخدم ويب ذات مظهر أفضل، أو نموذج واجهة مستخدم، أو شاشة تطبيق، أو لوحة معلومات، أو صفحة مقصودة، أو إعادة تصميم مرئي، أو يريد Image Gen/GPT Image 2 لتوجيه تنفيذ الواجهة الأمامية. تجنب العمل على الواجهة الخلفية فقط أو تعديلات الأسلوب الصغيرة التي لا تحتاج إلى توجيه مرئي.
