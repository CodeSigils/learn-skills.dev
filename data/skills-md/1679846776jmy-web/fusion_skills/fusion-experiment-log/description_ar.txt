تسجيل سجل التفريغ الموحد - تحميل أو قراءة الصور والصوت والنصوص المحلية مباشرة، وإنشاء سجل تفريغ Markdown مع المادة الأمامية YAML؛ تسجيل نظام ترقيم الطلقات، ومعلمات الماكينة (Ip/Bt/الشكل κ,δ/طاقة التسخين/هدف الكثافة/شكل الحافة LSN·USN·DN) والتكوين التشخيصي؛ التكامل اختياريًا مع Feishu CLI وObsidian. كلمات الزناد: سجل التفريغ، سجل اللقطة، سجل التفريغ، سجل التجربة، مؤشر التفريغ، سجل التمزق، التفريغ غير الطبيعي، سجل التكوين التشخيصي.
