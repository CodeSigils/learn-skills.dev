Стандартизированная запись журнала выгрузки — прямая загрузка или чтение локальных изображений, аудио и текста, создание журнала выгрузки Markdown с использованием YAML-формата; записать систему нумерации выстрелов, параметры машины (Ip/Bt/форму κ,δ/мощность нагрева/заданную плотность/форму кромки LSN·USN·DN) и диагностическую конфигурацию; опционально интегрируется с Feishu CLI и Obsidian. Триггерные слова: журнал разряда, запись выстрела, запись разряда, журнал эксперимента, индекс разряда, запись разрыва, ненормальный разряд, запись диагностической конфигурации.
