Package de support interne de référence partagée pour les compétences fusion-* installées (écriture de fusion, polissage de fusion, lecteur de fusion, analyse de données de fusion, diagnostic de fusion, opérations de machine de fusion, etc.). Ne l’appelez pas en tant que flux de travail utilisateur autonome. Chargez uniquement le fichier de base ou au format journal spécifique demandé par une autre compétence de fusion.
