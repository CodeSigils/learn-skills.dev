قراءة وتحرير وتحليل وإنشاء ملفات Microsoft Excel (.xlsx، .xls، .xlsm، .csv، .tsv). يُستخدم عندما يطلب المستخدم ما يلي: (1) فتح/قراءة/فحص ملف Excel، (2) تحرير أو تعديل بيانات جدول البيانات أو الصيغ أو التنسيق، (3) تحليل بيانات جدول البيانات وتقديم رؤى أو إحصائيات أو اتجاهات، (4) إنشاء ملفات Excel جديدة تحتوي على بيانات أو صيغ أو مخططات أو تنسيقات، (5) التحويل بين تنسيقات CSV/TSV وExcel، (6) إنشاء نماذج مالية أو لوحات معلومات في Excel.
