Cree, edite, analice y mejore presentaciones de PowerPoint (.pptx). Úselo cuando un usuario solicite: (1) Crear una nueva presentación desde cero, (2) Editar o modificar diapositivas, texto, imágenes o diseños, (3) Analizar la calidad, coherencia o contenido de una presentación, (4) Mejorar el diseño, la estructura o la legibilidad de una presentación existente, (5) Extraer texto o notas del orador, (6) Agregar gráficos, tablas o medios a las diapositivas, (7) Revisar o criticar una presentación.
