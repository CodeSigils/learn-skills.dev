When a user provides a journal/magazine name and wants to learn about submission requirements, submission forms/format checklists, journal website information, community evaluations, review speed, fees, article types, format details, or asks “how to submit to this journal / is it reliable / submission guide research,” this must be used. Verify the journal website and community assessments online, and by default isolate all intermediate files to the current working directory `.bensz-api/task-{yyyymmdd-hhmm}-{short description}/paper-know-journal/`, ultimately delivering only `KnowJournal-{journal name}.md`. ⚠️ Not applicable: when the user wants to select a journal based on a manuscript (using paper-select-journal), write the main text of the paper, download the full PDF, or ask a simple fact that does not require a draft.
