Quando un utente fornisce il nome di una rivista o di una rivista e desidera conoscere i requisiti di invio, i moduli di invio/liste di controllo del formato, informazioni sul sito web della rivista, valutazioni della comunità, velocità di revisione, tariffe, tipi di articoli, dettagli sul formato o chiede "come inviare a questa rivista / se è affidabile / ricerca sulla guida all'invio", deve essere utilizzato questo. Verifica il sito web della rivista e le valutazioni della comunità online e, per impostazione predefinita, isola tutti i file intermedi nella directory di lavoro corrente in `.bensz-api/task-{aaaammgg-hhmm}-{breve descrizione}/paper-know-journal/`, consegnando infine solo `KnowJournal-{JournalName}.md`. ⚠️ Non applicabile: quando l'utente deve scegliere una rivista di destinazione basata su un manoscritto (usa paper-select-journal), scrivere il testo principale di un articolo, scaricare il PDF completo o semplicemente chiedere un fatto che non richiede un manoscritto.
