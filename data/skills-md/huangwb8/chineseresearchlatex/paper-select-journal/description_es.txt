Cuando el usuario solicita explícitamente “recomendación de revista para el envío”, “ayúdame a elegir una revista de SCI para mi artículo”, “qué revistas son adecuadas para este manuscrito” o “consejos de comparación/selección/envío de revistas”, se debe utilizar esto. Se aplica a escenarios en los que el usuario proporciona el texto completo, resumen, Markdown, LaTeX, PDF, Word o materiales mixtos; esta habilidad, según el manuscrito y las preferencias del usuario, primero utilizará el `2023IF.xlsx` incorporado para realizar un filtro estricto mínimo y generar un grupo de candidatos, luego el modelo anfitrión planificará de forma autónoma Set1/Set2/Set3, verificará el alcance/calidad/los últimos tres meses de los artículos de PubMed en línea y, finalmente, generará un único informe de selección de revistas Markdown ordenado por rango de recomendación. ⚠️ No aplicable: el usuario solo desea pulir el artículo, solo traducir el resumen o solo solicita información del sitio web oficial de una sola revista sin necesidad de una selección sistemática de revistas.
