Когда пользователь явно запрашивает «рекомендовать журналы для подачи», «помогите мне выбрать журнал SCI для моей статьи», «какие журналы подходят для этой рукописи» или «советы по сопоставлению/выбору/подаче журналов», это необходимо использовать. Это применимо к сценариям, когда пользователь предоставляет полный текст, аннотацию, Markdown, LaTeX, PDF, Word или смешанные материалы; этот навык, основываясь на рукописи и предпочтениях пользователя, сначала использует встроенный файл «2023IF.xlsx» для минимальной жесткой фильтрации для создания пула кандидатов, затем заставляет хост-модель автономно планировать Set1/Set2/Set3 и проверять объем, качество и последние трехмесячные статьи PubMed в Интернете, наконец, выводя единый отчет о выборе журнала Markdown, отсортированный по рейтингу рекомендаций. ⚠️ Неприменимо: пользователь хочет только доработать статью, перевести только аннотацию или запрашивать информацию только с веб-сайта одного журнала без необходимости систематического выбора журналов.
