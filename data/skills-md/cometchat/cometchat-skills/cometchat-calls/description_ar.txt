نقطة الدخول لإضافة CometChat Voice & Video Calling إلى أي مشروع React أو React Native أو Angular أو Android الأصلي أو iOS الأصلي أو Flutter. يكتشف إطار العمل، ويختار الوضع المستقل (المكالمات فقط) مقابل الوضع الإضافي (المكالمات أعلى الدردشة الحالية)، ويوجه إلى مهارة المكالمات لكل عائلة. يتم استدعاؤه بواسطة مرسل `cometchat` ذي المستوى الأعلى عندما يكون `المنتج === "voice-video"` أو `chat-messaging+voice-video`، ومباشرة عندما يطلب المستخدم إجراء مكالمات بشكل صريح.
