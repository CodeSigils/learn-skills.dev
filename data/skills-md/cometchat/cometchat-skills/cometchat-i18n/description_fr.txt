Localisation (i18n) dans toutes les familles de kits d'interface utilisateur CometChat : React, React Native, Angular, Android (V5/V6), iOS, Flutter (V5/V6). Couvre les différences de signature CometChatLocalize.init (positionnelle ou objet), les langues groupées, l'enregistrement de langues personnalisées, la prise en charge de RTL, le repli vers l'anglais et les risques de dérive entre familles. Inter-famille : s'applique partout où l'agent configure la localisation CometChat.
