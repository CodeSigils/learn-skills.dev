Локализация (i18n) для всех семейств CometChat UI Kit — React, React Native, Angular, Android (V5/V6), iOS, Flutter (V5/V6). Охватывает различия в сигнатурах CometChatLocalize.init (позиционные и объектные), встроенные языки, регистрацию пользовательского языка, поддержку RTL, переход на английский язык и риски межсемейного смещения. Межсемейный — применяется везде, где агент настраивает локализацию CometChat.
