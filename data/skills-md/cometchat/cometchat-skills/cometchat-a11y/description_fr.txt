Accessibilité (a11y) pour les intégrations du CometChat UI Kit dans toutes les familles : React, React Native, Angular, Android (V5/V6), iOS, Flutter. Couvre les cibles WCAG 2.1 AA, la navigation au clavier dans le chat, les annonces du lecteur d'écran (régions en direct pour les nouveaux messages), le contraste des couleurs, la gestion de la mise au point sur les écrans d'appel, la prise en charge de la réduction de mouvement et les vérifications inter-familles qui détectent les bogues courants de production. Inter-famille : s'applique partout où l'agent vérifie l'accessibilité.
