Доступность (a11y) для интеграции CometChat UI Kit во всех семействах — React, React Native, Angular, Android (V5/V6), iOS, Flutter. Охватывает цели WCAG 2.1 AA, навигацию с помощью клавиатуры в чате, объявления средств чтения с экрана (активные области для новых сообщений), цветовой контраст, управление фокусом на экранах вызовов, поддержку уменьшения движения и межсемейные проверки, которые выявляют распространенные производственные ошибки. Межсемейный — применяется везде, где агент проверяет доступность.
