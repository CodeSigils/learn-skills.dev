Rédigez des articles de blog personnels pour le blog Astro de l'utilisateur (git repo zkl2333/blog, déployé sur blog.zkl2333.com). Le chemin local varie selon la machine : découvrez-le au moment de l'exécution, jamais de code en dur. À utiliser lorsque l'utilisateur souhaite écrire un nouveau message, documenter un projet/une exploration ou enregistrer une histoire qu'il a vécue. Pilote un flux de travail de type éditeur à plusieurs tours : interrogez d'abord l'utilisateur, planifiez un plan, rédigez, itérez sur les faits et la voix, ajoutez des images, validez. S'oppose fermement au modèle « L'IA génère simplement du texte à partir de zéro ». Voir references/interview.md pour la banque de questions, references/voice.md pour les modèles de tons, references/frontmatter.md pour le schéma.
