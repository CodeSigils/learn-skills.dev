Написание подсказки H3 для главного меню/открытия совместной игры для двух игроков: блокировка стиля и личности, подсказка для подтверждения ключа, 15-секундная видеоподсказка временной шкалы взаимодействия с меню. Подходит для подсказок для презентации концепции игры. Не подходит для игровых проектов или сложных многостраничных документов со спецификациями пользовательского интерфейса.
