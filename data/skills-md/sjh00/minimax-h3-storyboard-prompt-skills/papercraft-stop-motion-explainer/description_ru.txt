Написание подсказки H3 для научной коммуникации в технике покадровой анимации: цели обучения, блокировка стиля бумажной графики, многоуровневый дизайн декораций и механизмы, раскадровка и пакет для создания изображений/видео. Применимо к подсказкам для вырезания из бумаги/3D-книги/микромасштабных покадровых объяснений. Не подходит для обычных сценариев мультфильмов без текстуры paper‑art.
