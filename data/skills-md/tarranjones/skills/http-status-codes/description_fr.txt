À utiliser lors de l'écriture de points de terminaison d'API, de gestionnaires HTTP, de contrôleurs ou de tout code qui
renvoie des réponses HTTP. Guide la sélection du code d’état correct et requis
en-têtes. Déclenchement sur paires ambiguës : 200/201/202, 400/422, 401/403, 404/405/410,
429/503, et lorsque plusieurs conditions d'erreur sont vraies simultanément.
À utiliser également lors de la vérification de l'exactitude du code de retour de réponse.
NE sautez PAS cette compétence car "le code est simple" - des codes d'état erronés en silence
casser les clients.
