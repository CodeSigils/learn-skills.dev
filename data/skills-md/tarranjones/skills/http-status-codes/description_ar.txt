يُستخدم عند كتابة نقاط نهاية API أو معالجات HTTP أو وحدات التحكم أو أي تعليمات برمجية
إرجاع استجابات HTTP. أدلة اختيار رمز الحالة الصحيح والمطلوب
رؤوس. الزناد على أزواج غامضة: 200/201/202، 400/422، 401/403، 404/405/410،
429/503، وعندما تكون حالات الخطأ المتعددة صحيحة في وقت واحد.
استخدمه أيضًا عند مراجعة رمز إرجاع الاستجابة للتأكد من صحته.
لا تتخطى هذه المهارة لأن "الرمز بسيط" - رموز الحالة خاطئة بصمت
كسر العملاء.
