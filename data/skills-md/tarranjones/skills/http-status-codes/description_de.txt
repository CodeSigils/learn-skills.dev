Verwenden Sie diese Option beim Schreiben von API-Endpunkten, HTTP-Handlern, Controllern oder anderem Code
gibt HTTP-Antworten zurück. Führt die Auswahl des richtigen und erforderlichen Statuscodes durch
Kopfzeilen. Trigger auf mehrdeutige Paare: 200/201/202, 400/422, 401/403, 404/405/410,
429/503 und wenn mehrere Fehlerbedingungen gleichzeitig wahr sind.
Wird auch verwendet, wenn der Code, der die Antwort zurückgibt, auf Richtigkeit überprüft wird.
Überspringen Sie diesen Skill NICHT, denn „der Code ist einfach“ – falsche Statuscodes im Stillen
Kunden brechen.
