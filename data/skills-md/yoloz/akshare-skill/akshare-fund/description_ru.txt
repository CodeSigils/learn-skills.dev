Используйте библиотеку AKShare для получения и анализа данных китайского фондового рынка. AKShare — это бесплатная библиотека интерфейса финансовых данных Python с открытым исходным кодом, не требующая регистрации или токена. Он поддерживает: котировки фондов в реальном времени и исторические данные котировок. Используйте этот навык, когда пользователям необходимо получить данные о фонде или проанализировать основные показатели фонда.
