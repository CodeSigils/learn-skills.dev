Utilice la biblioteca AKShare para obtener y analizar datos del mercado de fondos chino. AKShare es una biblioteca de interfaz de datos financieros Python gratuita y de código abierto que no requiere registro ni token. Admite: cotizaciones de fondos en tiempo real y datos de cotizaciones históricas. Utilice esta habilidad cuando los usuarios necesiten adquirir datos de fondos o analizar los fundamentos de los fondos.
