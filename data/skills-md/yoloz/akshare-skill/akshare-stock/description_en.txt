Use the AKShare library to obtain and analyze China A-share market data. AKShare is a free, open-source Python financial-data interface library that requires no registration or token. It supports: real-time stock quotes, historical K-lines, financial statements, valuation indicators, capital flows, technical indicators, scheduled tasks, etc. Invoke this skill when the user needs to fetch A-share prices, analyze individual-stock fundamentals, query financial data, compute technical indicators, or study capital flows.
