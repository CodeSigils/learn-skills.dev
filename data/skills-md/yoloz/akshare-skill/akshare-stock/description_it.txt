Utilizza la libreria AKShare per ottenere e analizzare i dati di mercato delle azioni A cinesi. AKShare è una libreria di interfaccia per dati finanziari Python open source gratuita che non richiede registrazione o token. Supporta: quotazioni azionarie in tempo reale, linee K storiche, rendiconti finanziari, indicatori di valutazione, flussi di capitale, indicatori tecnici, attività pianificate, ecc. Richiama questa abilità quando l'utente ha bisogno di recuperare i prezzi delle azioni A, analizzare i fondamentali dei singoli titoli, interrogare dati finanziari, calcolare indicatori tecnici o studiare i flussi di capitale.
