Entretien de découverte de produit/entreprise fondé sur la base de code existante. À utiliser lorsqu'un PM, un fondateur, un propriétaire de produit ou une partie prenante de l'entreprise souhaite valider une idée, une fonctionnalité, une expérience, un signal client ou un pari sur un produit par rapport au produit/base de code réel avant de créer un PRD, des problèmes ou un plan de mise en œuvre. Se concentre sur le problème, l'utilisateur, l'hypothèse, la portée, les métriques, les flux existants et les compromis – pas encore de codage.
