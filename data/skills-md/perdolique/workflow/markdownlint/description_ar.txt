تكوين وإدارة واستكشاف أخطاء markdownlint وإصلاحها في المشاريع. يُستخدم عندما يريد المستخدم إعداد/تثبيت/تكوين markdownlint، أو إضافة/إزالة/تعديل قواعد الفحص، أو إصلاح مشكلات التحقق من صحة Markdown، أو تخصيص .markdownlint.yaml، أو تحديث أنماط التجاهل، أو التكامل مع الأدوات (Husky، CI)، أو استكشاف أخطاء فحص Markdown وإصلاحها. يُستخدم حتى عندما يذكر المستخدم مشكلات تنسيق تخفيض السعر، أو مشكلات الجودة، أو تناسق النمط دون قول "markdownlint" صراحةً.
