Conventions de codage TypeScript pour l'écriture, la révision et la refactorisation du code tapé. À utiliser lorsque vous travaillez sur `.ts`, `.tsx` ou sur des fichiers qui intègrent TypeScript tels que des composants Vue, Astro ou Svelte. Utilisez également pour les extraits de code TypeScript, les refactoristes typés et examinez les commentaires sur l'organisation du code ou la structure des fonctions.
