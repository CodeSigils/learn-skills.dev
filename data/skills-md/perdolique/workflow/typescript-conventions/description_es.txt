Convenciones de codificación de TypeScript para escribir, revisar y refactorizar código mecanografiado. Úselo cuando trabaje con `.ts`, `.tsx` o archivos que incrustan TypeScript, como componentes Vue, Astro o Svelte. Utilícelo también para fragmentos de TypeScript, refactorizaciones escritas y comentarios de revisión sobre la organización del código o la estructura de funciones.
