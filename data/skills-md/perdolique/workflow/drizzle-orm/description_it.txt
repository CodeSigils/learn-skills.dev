Modelli di query Drizzle ORM per TypeScript. Da utilizzare durante la scrittura, la revisione o il debug delle query Drizzle, in particolare quando si sceglie tra query relazionali e il builder SQL, si creano filtri dinamici, si caricano relazioni o si correggono mancate corrispondenze di forma e tipo di query Drizzle. Si applica anche durante la revisione del codice quando un file contiene una costruzione di query non banale con `drizzle-orm`.
