Eseguire il debug ed emulare frammenti di codice o funzioni specifici utilizzando il motore Unicorn. Attiva quando l'utente desidera emulare una funzione con Unicorn, tracciare l'esecuzione binaria senza eseguire il programma completo, decrittografare o decodificare i dati emulando l'algoritmo o ignorare le dipendenze dell'ambiente (JNI, chiamate di sistema, libc) durante l'emulazione.
