Referencia de scripts IDAPython e IDALib para ingeniería inversa. Actívelo cuando el usuario necesite escribir scripts IDAPython en IDA, usar IDALib para análisis sin cabeza, operar en bases de datos IDB, depurar con IDA, manipular memoria/registros, recorrer funciones/bloques/instrucciones, trabajar con la API del descompilador Hex-Rays, manejar la ofuscación o procesar archivos binarios por lotes.
