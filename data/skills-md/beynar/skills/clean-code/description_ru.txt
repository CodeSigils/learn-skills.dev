Инструмент проверки кода AI и набор инструментов для очистки TypeScript/Node.js. Проверяет сгенерированный ИИ код на наличие ненужных шаблонов (ненужные абстракции, монолиты, молчаливые сбои, мертвый код, ловушки производительности, галлюцинирующие API) и создает либо структурированный отчет о проверке, либо диагностическое сканирование, либо очищенную переписывание. Используйте этот навык всякий раз, когда пользователь просит просмотреть код, проверить качество кода, очистить код, сгенерированный искусственным интеллектом, обнаружить ошибки, просканировать антишаблоны, провести рефакторинг беспорядочного кода или проверить отсутствие чрезмерного проектирования. Также срабатывает по следующим запросам: «проверьте этот файл», «чист ли этот код», «найдите проблемы», «слишком сложно», «упростите это», «запах кода», «это написал ИИ, и это беспорядочно». Работает с отдельными файлами, блоками кода, различиями или PR.
