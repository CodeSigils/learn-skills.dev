Revisor de código de IA y kit de herramientas de limpieza para TypeScript/Node.js. Revisa el código generado por IA en busca de patrones descuidados (abstracciones innecesarias, monolitos, fallas silenciosas, código inactivo, trampas de rendimiento, API alucinadas) y produce un informe de revisión estructurado, un escaneo de diagnóstico o una reescritura limpia. Utilice esta habilidad siempre que el usuario solicite revisar el código, auditar la calidad del código, limpiar el código generado por IA, detectar desperdicios, escanear en busca de antipatrones, refactorizar código desordenado o verificar si hay exceso de ingeniería. También se activan: "revisar este archivo", "este código está limpio", "encontrar problemas", "demasiado complejo", "simplificar esto", "olor de código", "la IA escribió esto y es complicado". Funciona en archivos individuales, bloques de código, diferencias o relaciones públicas.
