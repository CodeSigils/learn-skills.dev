مراجع أكواد الذكاء الاصطناعي ومجموعة أدوات التنظيف لـ TypeScript/Node.js. يراجع التعليمات البرمجية التي تم إنشاؤها بواسطة الذكاء الاصطناعي لأنماط الانحراف (التجريدات غير الضرورية، والوحدات المتجانسة، والإخفاقات الصامتة، والرمز الميت، وفخاخ الأداء، وواجهات برمجة التطبيقات المهلوسة) وينتج إما تقرير مراجعة منظم، أو فحص تشخيصي، أو إعادة كتابة نظيفة. استخدم هذه المهارة عندما يطلب المستخدم مراجعة التعليمات البرمجية، أو تدقيق جودة التعليمات البرمجية، أو تنظيف التعليمات البرمجية التي تم إنشاؤها بواسطة الذكاء الاصطناعي، أو اكتشاف الأخطاء، أو المسح بحثًا عن الأنماط المضادة، أو إعادة بناء التعليمات البرمجية الفوضوية، أو التحقق من الهندسة الزائدة. يتم تشغيله أيضًا على: "مراجعة هذا الملف"، "هل هذا الرمز نظيف"، "العثور على مشكلات"، "معقد للغاية"، "تبسيط هذا"، "رائحة الكود"، "لقد كتب الذكاء الاصطناعي هذا وهو فوضوي". يعمل على الملفات الفردية أو كتل التعليمات البرمجية أو الاختلافات أو العلاقات العامة.
