AI-Code-Reviewer und Bereinigungs-Toolkit für TypeScript/Node.js. Überprüft KI-generierten Code auf Slop-Muster (unnötige Abstraktionen, Monolithen, stille Fehler, toter Code, Leistungsfallen, halluzinierte APIs) und erstellt entweder einen strukturierten Überprüfungsbericht, einen Diagnosescan oder eine bereinigte Neufassung. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer darum bittet, Code zu überprüfen, die Codequalität zu prüfen, KI-generierten Code zu bereinigen, Slop zu erkennen, nach Anti-Patterns zu suchen, unordentlichen Code umzugestalten oder auf Over-Engineering zu prüfen. Wird auch ausgelöst bei: „Diese Datei überprüfen“, „Ist dieser Code sauber“, „Probleme finden“, „zu komplex“, „Vereinfachen“, „Code riecht“, „Die KI hat das geschrieben und es ist chaotisch“. Funktioniert mit einzelnen Dateien, Codeblöcken, Diffs oder PRs.
