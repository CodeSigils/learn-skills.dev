AI code reviewer and cleanup toolkit for TypeScript/Node.js. Reviews AI-generated code for slop patterns (unnecessary abstractions, monoliths, silent failures, dead code, performance traps, hallucinated APIs) and produces either a structured review report, a diagnosis scan, or a cleaned rewrite. Use this skill whenever the user asks to review code, audit code quality, clean up AI-generated code, detect slop, scan for anti-patterns, refactor messy code, or check for over-engineering. Also triggers on: "review this file", "is this code clean", "find issues", "too complex", "simplify this", "code smell", "the AI wrote this and it's messy". Works on individual files, code blocks, diffs, or PRs.
