Entrée de sous-processus pour l'optimisation du code, gestion des tâches où « le comportement reste le même, la structure change » (structure/performance/lisibilité). Il se déroule étape par étape : numérisation → conception → application, chaque étape étant lancée manuellement. Déclenché lorsque l'utilisateur dit « optimiser un peu / refactoriser / réécrire / diviser / les performances sont médiocres / le code est trop long » sans impliquer de changements de comportement. Il ne traite pas les nouvelles exigences, les bogues ou les refontes architecturales inter-modules.
