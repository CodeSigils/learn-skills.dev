Unterprozesseintrag zur Codeoptimierung, Bearbeitung von Aufgaben, bei denen „das Verhalten gleich bleibt, sich die Struktur ändert“ (Struktur/Leistung/Lesbarkeit). Es wird Schritt für Schritt mit Scannen → Entwurf → Anwenden fortgefahren, wobei jeder Schritt manuell freigegeben wird. Wird ausgelöst, wenn der Benutzer sagt „Ein bisschen optimieren / umgestalten / neu schreiben / aufteilen / Leistung ist schlecht / Code ist zu lang“, ohne dass dies Verhaltensänderungen impliziert. Es werden keine neuen Anforderungen, Fehler oder modulübergreifenden Architektur-Redesigns verarbeitet.
