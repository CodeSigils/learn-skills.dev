Subprocess entry for code optimization, handling tasks where “behaviour stays the same, structure changes” (structure / performance / readability). It proceeds step‑by‑step as scan → design → apply, with each step manually released. Triggered when the user says “optimize a bit / refactor / rewrite / split it up / performance is poor / code is too long” without implying behavioural changes. It does not process new requirements, bugs, or cross‑module architectural redesigns.
