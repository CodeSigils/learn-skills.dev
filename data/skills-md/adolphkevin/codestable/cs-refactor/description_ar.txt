نقطة الدخول للعملية الفرعية لتحسين التعليمات البرمجية، والتعامل مع العمل حيث "يبقى السلوك كما هو، وتغييرات الهيكل" (الهيكل والأداء وسهولة القراءة)، يتم تنفيذها خطوة بخطوة مثل المسح → التصميم → تطبيق بموافقة يدوية في كل مرحلة. يتم تشغيله عندما يقول المستخدم "التحسين / إعادة البناء / إعادة الكتابة / التقسيم / الأداء ضعيف / الكود طويل جدًا" دون أي تغييرات سلوكية. ولا يتعامل مع المتطلبات الجديدة أو الأخطاء أو إعادة التصميم المعماري للوحدات المتقاطعة.
