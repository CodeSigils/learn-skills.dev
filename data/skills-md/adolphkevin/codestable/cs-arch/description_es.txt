Mantenga el archivo `.codestable/architecture/` como un mapa del sistema que solo registra el estado actual, usando tres modos: actualizar, verificar y rellenar. Desencadenantes: el usuario dice "actualizar arquitectura", "realizar una verificación de arquitectura", "agregar el documento de arquitectura para este módulo", "el plan coincide con el código" o cuando una fase de función requiere una acción de arquitectura por adelantado. No escriba planes futuros (siga la hoja de ruta de cs).
