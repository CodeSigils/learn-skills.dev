Generieren und erstellen Sie saubere Git-Commits aus bereitgestellten Änderungen. Verwenden Sie diese Option, wenn der Benutzer darum bittet, bereits bereitgestellte Arbeit festzuschreiben, eine Festschreibungsnachricht aus „git diff --cached“ zu generieren oder einen Festschreibungsworkflow auszuführen, der Typ, Umfang, Betreff, Text und Risiko aus dem bereitgestellten Diff ableitet.
