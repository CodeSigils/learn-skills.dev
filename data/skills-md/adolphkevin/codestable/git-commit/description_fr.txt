Générez et créez des commits git propres à partir de modifications par étapes. À utiliser lorsque l'utilisateur demande de valider un travail déjà effectué, de générer un message de validation à partir de `git diff --cached` ou d'exécuter un workflow de validation qui déduit le type, la portée, le sujet, le corps et le risque de la comparaison effectuée.
