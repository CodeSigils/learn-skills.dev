Генерируйте и создавайте чистые коммиты git на основе поэтапных изменений. Используйте, когда пользователь просит зафиксировать уже проиндексированную работу, сгенерировать сообщение о фиксации из `git diff --cached` или запустить рабочий процесс фиксации, который определяет тип, область действия, тему, тело и риск из промежуточного сравнения.
