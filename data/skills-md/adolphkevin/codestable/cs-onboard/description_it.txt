Integra un nuovo repository o un repository con documenti sparsi nel sistema CodeStable, con due percorsi determinati automaticamente: un repository vuoto costruisce il framework da zero, mentre un repository esistente con documenti viene sottoposto a audit e mappatura della migrazione. Si attiva quando l'utente dice "utilizza CodeStable in questo progetto", "imposta la struttura CodeStable", "inizializza CodeStable" o "migra a CodeStable".
