Integrieren Sie ein neues Repository oder ein Repository mit verstreuten Dokumenten in das CodeStable-System, wobei zwei Pfade automatisch bestimmt werden: Ein leeres Repository baut das Gerüst von Grund auf auf, während ein vorhandenes Dokumentations-Repository einer Prüfung und Migrationszuordnung unterzogen wird. Auslöser: wenn der Benutzer sagt „CodeStable in diesem Projekt verwenden“, „CodeStable-Struktur einrichten“, „CodeStable initialisieren“ oder „zu CodeStable migrieren“.
