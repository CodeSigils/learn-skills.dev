Contrôlez un vrai navigateur via une extension Chrome. Utilisez-le lorsque vous devez accéder à des pages Web, extraire des données Web, cliquer sur des boutons, remplir des formulaires, automatiser le navigateur, récupérer des preuves de composants rendus ou manipuler la page par programme. Il renvoie des résultats structurés efficaces en termes de jetons via DOM diff, HTML simplifié et un pack de preuves de composants. Convient pour le contrôle du navigateur, l'automatisation du Web, le scraping de pages, l'extraction de données Web, l'exécution de JS dans le navigateur, web_scan, web_execute_js, l'ouverture du navigateur, la navigation vers l'URL, l'obtention du contenu de la page, le remplissage du formulaire, le clic sur le bouton, l'extraction du composant, le rendu du DOM, les styles calculés, les preuves de composants.
