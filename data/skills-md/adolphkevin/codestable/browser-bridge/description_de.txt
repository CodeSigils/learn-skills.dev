Steuern Sie einen echten Browser über eine Chrome-Erweiterung. Verwenden Sie es, wenn Sie auf Webseiten zugreifen, Webdaten extrahieren, auf Schaltflächen klicken, Formulare ausfüllen, eine Browserautomatisierung durchführen, gerenderte Komponentennachweise abrufen oder die Seite programmgesteuert bearbeiten müssen. Es gibt tokeneffiziente strukturierte Ergebnisse über DOM diff, vereinfachtes HTML und ein Komponenten-Beweispaket zurück. Geeignet für Browsersteuerung, Webautomatisierung, Page Scraping, Webdatenextraktion, JS im Browser ausführen, web_scan, web_execute_js, Browser öffnen, zur URL navigieren, Seiteninhalt abrufen, Formular ausfüllen, Schaltfläche anklicken, Komponente extrahieren, gerendertes DOM, berechnete Stile, Komponentennachweis.
