Controla un navegador real a través de una extensión de Chrome. Úselo cuando necesite acceder a páginas web, extraer datos de páginas, hacer clic en botones, completar formularios, realizar automatización del navegador, extraer evidencia de componentes representados o manipular la página mediante programación. Devuelve resultados estructurados que guardan tokens a través de diferencias DOM, HTML simplificado y un paquete de evidencia de componentes. Adecuado para control de navegador, automatización web, extracción de páginas, extracción de datos web, ejecución de JS en el navegador, web_scan, web_execute_js, apertura de un navegador, navegación a una URL, obtención de contenido de la página, llenado de formularios, clic en botones, extracción de componentes, DOM renderizado, estilos calculados y evidencia de componentes.
