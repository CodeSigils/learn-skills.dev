Guide opérationnel pour la gestion des bases de données de graphes intégrés aux nanographes. Utilisez cette compétence chaque fois que l'utilisateur travaille avec des fichiers nanograph (schémas .pg, requêtes .gq, nanograph.toml, bases de données *.nano/), pose des questions sur les opérations de données graphiques, les mutations, les modifications de schéma, le chargement de données, les requêtes, la recherche ou toute commande CLI nanograph. Déclenchez également lorsque vous voyez des fichiers liés aux nanographes dans le projet ou que l'utilisateur mentionne des bases de données de graphiques, des graphiques de propriétés ou des ensembles de données Lance dans le contexte de cette base de code.
