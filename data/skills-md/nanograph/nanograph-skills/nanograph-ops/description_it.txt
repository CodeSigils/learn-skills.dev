Guida operativa per la gestione dei database grafici incorporati in nanografi. Utilizza questa competenza ogni volta che l'utente lavora con file nanograph (schemi .pg, query .gq, nanograph.toml, *.nano/ database), chiede informazioni su operazioni sui dati del grafico, mutazioni, modifiche dello schema, caricamento di dati, query, ricerca o qualsiasi comando CLI di nanograph. Si attiva anche quando vedi file relativi a nanografi nel progetto o l'utente menziona database di grafici, grafici di proprietà o set di dati Lance nel contesto di questa codebase.
