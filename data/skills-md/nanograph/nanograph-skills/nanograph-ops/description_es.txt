Guía operativa para la gestión de bases de datos de gráficos integrados de nanógrafos. Utilice esta habilidad siempre que el usuario trabaje con archivos de nanograph (esquemas .pg, consultas .gq, bases de datos nanograph.toml, *.nano/), pregunte sobre operaciones de datos de gráficos, mutaciones, cambios de esquema, carga de datos, consultas, búsquedas o cualquier comando CLI de nanograph. También se activa cuando ve archivos relacionados con nanografías en el proyecto o el usuario menciona bases de datos de gráficos, gráficos de propiedades o conjuntos de datos de Lance en el contexto de esta base de código.
