Gérez un flux de travail de projet soutenu par Obsidian avec obsidian-cli et le plugin Obsidian Kanban. À utiliser pour les tableaux de tâches du projet, les requêtes de statut/progression, le pool d'exigences vers les flux d'exécution/révision/achèvement/archivage, la création/déplacement de notes de tâche et les transferts humain/agent dans un coffre-fort Obsidian. Préférez le coffre-fort Obsidian en cours d'exécution via obsidian-cli ; ne présumez jamais que le répertoire de travail/session actuel est le coffre-fort.
