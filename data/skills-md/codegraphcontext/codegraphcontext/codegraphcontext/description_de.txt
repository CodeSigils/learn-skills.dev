Verwenden Sie CodeGraphContext (CGC), um ein Repo in einer Graph-Datenbank zu indizieren und es über CLI oder MCP abzufragen. Wenden Sie es an, wenn der Benutzer eine Semantik-/Codegraph-Suche, einen Aufruf von Graphen, eine Indizierung oder die Konfiguration des Codegraphcontext-MCP-Servers wünscht.
