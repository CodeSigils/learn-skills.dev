Configurez, renforcez, auditez ou expliquez un VPS Linux en tant qu'hôte SSH de l'application Codex pour les flux de travail d'agent de style Krypton. À utiliser lorsque l'utilisateur souhaite déplacer le travail Codex ou Claude Code d'un Mac local vers un VPS, connecter l'application Codex à un hôte SSH, configurer les outils Ubuntu 24.04/devbox, cloner un dépôt à distance, exécuter Codex/Claude/tmux/cmux sur le VPS, transférer des ports pour les tests de l'hôte local ou créer des instructions de configuration de fondateur/constructeur répétables avec des vérifications de preuve.
