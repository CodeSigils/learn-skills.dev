Configura, rafforza, controlla o spiega un VPS Linux come host SSH dell'app Codex per flussi di lavoro degli agenti in stile Krypton. Da utilizzare quando l'utente desidera spostare il lavoro Codex o Claude Code da un Mac locale a un VPS, connettere l'app Codex a un host SSH, configurare gli strumenti Ubuntu 24.04/devbox, clonare un repository in remoto, eseguire Codex/Claude/tmux/cmux sul VPS, inoltrare porte per test localhost o creare istruzioni di configurazione ripetibili per fondatore/costruttore con controlli di prova.
