قم بإعداد Linux VPS أو تقويته أو تدقيقه أو شرحه كمضيف Codex App SSH لسير عمل الوكيل على نمط Krypton. يُستخدم عندما يريد المستخدم نقل عمل Codex أو Claude Code من جهاز Mac محلي إلى VPS، أو توصيل تطبيق Codex بمضيف SSH، أو تكوين أدوات Ubuntu 24.04/devbox، أو استنساخ الريبو عن بعد، أو تشغيل Codex/Claude/tmux/cmux على VPS، أو إعادة توجيه المنافذ لاختبار المضيف المحلي، أو إنشاء تعليمات إعداد مؤسس/منشئ قابلة للتكرار مع عمليات التحقق من الإثبات.
