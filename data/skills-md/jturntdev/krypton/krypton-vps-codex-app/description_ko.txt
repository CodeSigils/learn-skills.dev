Krypton 스타일 에이전트 워크플로를 위한 Codex App SSH 호스트로 Linux VPS를 설정, 강화, 감사 또는 설명합니다. 사용자가 Codex 또는 Claude Code 작업을 로컬 Mac에서 VPS로 이동하고, Codex App을 SSH 호스트에 연결하고, Ubuntu 24.04/devbox 도구를 구성하고, 저장소를 원격으로 복제하고, VPS에서 Codex/Claude/tmux/cmux를 실행하고, 로컬 호스트 테스트를 위해 포트를 전달하거나, 증명 확인을 통해 반복 가능한 창립자/빌더 설정 지침을 생성하려는 경우에 사용합니다.
