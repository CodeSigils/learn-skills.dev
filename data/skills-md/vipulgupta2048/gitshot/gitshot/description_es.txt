Cargue capturas de pantalla e imágenes en GitHub y devuelva URL listas para rebajas para relaciones públicas, problemas y comentarios. Úselo cuando necesite adjuntar imágenes a problemas o relaciones públicas de GitHub, cargar capturas de pantalla, incrustar imágenes en Markdown o cuando un flujo de trabajo produzca imágenes que deban compartirse en GitHub. Palabras desencadenantes: cargar una imagen, adjuntar una captura de pantalla, agregar una imagen a PR, incrustar una captura de pantalla, diferenciación visual, captura de pantalla antes/después.
