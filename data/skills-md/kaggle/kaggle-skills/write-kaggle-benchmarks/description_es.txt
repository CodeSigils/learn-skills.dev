Escriba, envíe, ejecute, publique y administre tareas de Kaggle Benchmark utilizando la CLI de kaggle y el SDK de Python de kaggle-benchmarks. Úselo cuando el usuario desee crear o impulsar una tarea de referencia (opcionalmente con conjuntos de datos de Kaggle adjuntos), ejecutar pruebas comparativas con modelos LLM, verificar el estado de la tarea/ejecución, transmitir o recuperar registros de ejecución, descargar resultados y cuadernos de origen, publicar una tarea para hacerla pública o solucionar problemas de flujos de trabajo de referencia.
