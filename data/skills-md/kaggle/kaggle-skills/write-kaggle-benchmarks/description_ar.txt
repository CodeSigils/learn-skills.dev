يمكنك كتابة مهام Kaggle Benchmark ودفعها وتشغيلها ونشرها وإدارتها باستخدام kaggle CLI وKaggle-benchmarks Python SDK. يُستخدم عندما يريد المستخدم إنشاء مهمة قياس أداء أو دفعها (اختياريًا باستخدام مجموعات بيانات Kaggle المرفقة)، أو تشغيل معايير الأداء مقابل نماذج LLM، أو التحقق من حالة المهمة/التشغيل، أو تدفق سجلات التنفيذ أو جلبها، أو تنزيل النتائج ودفاتر الملاحظات المصدر، أو نشر مهمة لجعلها عامة، أو استكشاف أخطاء سير عمل قياس الأداء وإصلاحها.
