Scrivi, invia, esegui, pubblica e gestisci le attività di Kaggle Benchmark utilizzando la CLI di kaggle e l'SDK Python di kaggle-benchmarks. Da utilizzare quando l'utente desidera creare o inviare un'attività di benchmark (facoltativamente con set di dati Kaggle allegati), eseguire benchmark rispetto a modelli LLM, controllare lo stato di attività/esecuzione, eseguire lo streaming o recuperare registri di esecuzione, scaricare risultati e notebook di origine, pubblicare un'attività per renderla pubblica o risolvere i problemi dei flussi di lavoro di benchmark.
