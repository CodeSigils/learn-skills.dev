Générez des diagrammes techniques concis (schéma d'architecture/organigramme/diagramme de séquence/machine d'état/flux de données/ER/diagramme conceptuel, etc.) à partir de descriptions en langage naturel. **Ne laissez pas le LLM dessiner du SVG** : le LLM ne génère que du JSON décrivant les nœuds et les arêtes ; un moteur de rendu Python déterministe calcule le routage Manhattan, l'évitement des collisions et le placement des étiquettes, garantissant ainsi que la mise en page est 100 % propre. Style Ledger par défaut (fond blanc chaud + accent bleu sarcelle + trait gris foncé). Utilisez `rsvg-convert` pour produire également du PNG.
