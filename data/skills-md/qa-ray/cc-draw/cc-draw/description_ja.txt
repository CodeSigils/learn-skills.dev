自然言語記述から簡潔な技術図（アーキテクチャ図/フローチャート/シーケンス図/ステートマシン/データフロー/ER/概念図など）を生成します。 **LLM に SVG を描画させないでください**。LLM はノードとエッジを記述する JSON のみを出力します。決定論的な Python レンダラーがマンハッタンのルーティング、衝突回避、ラベルの配置を計算し、レイアウトが 100% クリーンであることを保証します。デフォルトの元帳スタイル (温かみのある白の背景 + 青緑のアクセント + ダークグレーのストローク)。 `rsvg-convert` を使用して PNG も生成します。
