Guía para la derivación de claves deterministas jerárquicas (HD) utilizando la caja bip32. Utilice esta habilidad siempre que el usuario desee: derivar claves secundarias de una semilla maestra; convertir un bip32::XPrv en un Alloy PrivateKeySigner para cadenas EVM; derivar pares de claves Solana Ed25519 a partir de una semilla; comprender las rutas de derivación reforzadas y no reforzadas; o implementar BIP44 para múltiples blockchains (Ethereum m/44'/60'/0'/0/n, Solana m/44'/501'/n'/0'). Asegúrese de utilizar esta habilidad cuando el usuario mencione billeteras HD, BIP32, SLIP-10, derivación de claves, claves secundarias o administración de cuentas multicadena desde un único mnemotécnico.
