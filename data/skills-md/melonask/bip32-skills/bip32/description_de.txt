Leitfaden für die Ableitung hierarchisch-deterministischer (HD) Schlüssel mithilfe der bip32-Kiste. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Folgendes möchte: Untergeordnete Schlüssel von einem Master-Seed ableiten; Konvertieren Sie einen bip32::XPrv in einen Alloy PrivateKeySigner für EVM-Ketten. Solana Ed25519-Schlüsselpaare aus einem Samen ableiten; Verstehen Sie gehärtete und nicht gehärtete Ableitungspfade. oder implementieren Sie BIP44 für mehrere Blockchains (Ethereum m/44'/60'/0'/0/n, Solana m/44'/501'/n'/0'). Stellen Sie sicher, dass Sie diese Fähigkeit verwenden, wenn der Benutzer HD-Wallets, BIP32, SLIP-10, Schlüsselableitung, untergeordnete Schlüssel oder die Verwaltung von Multi-Chain-Konten über eine einzige Mnemonik erwähnt.
