Руководство по получению иерархического детерминированного (HD) ключа с использованием крейта bip32. Используйте этот навык всякий раз, когда пользователь хочет: получить дочерние ключи из главного начального числа; преобразовать bip32::XPrv в Alloy PrivateKeySigner для цепочек EVM; получить пары ключей Solana Ed25519 из начального числа; понимать усиленные и незащищенные пути вывода; или внедрить BIP44 для нескольких блокчейнов (Ethereum m/44’/60’/0’/0/n, Solana m/44’/501’/n’/0’). Обязательно используйте этот навык, когда пользователь упоминает HD-кошельки, BIP32, SLIP-10, деривацию ключей, дочерние ключи или управление учетными записями с несколькими цепочками с помощью одной мнемоники.
