Guide for Hierarchical Deterministic (HD) key derivation using the bip32 crate. Use this skill whenever the user wants to: derive child keys from a master seed; convert a bip32::XPrv to an Alloy PrivateKeySigner for EVM chains; derive Solana Ed25519 keypairs from a seed; understand hardened vs unhardened derivation paths; or implement BIP44 for multiple blockchains (Ethereum m/44'/60'/0'/0/n, Solana m/44'/501'/n'/0'). Make sure to use this skill when the user mentions HD wallets, BIP32, SLIP-10, key derivation, child keys, or managing multi-chain accounts from a single mnemonic.
