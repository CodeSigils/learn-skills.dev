Guide complet pour créer des solutions avec la bibliothèque x402-rs Rust et le protocole de paiement x402 HTTP 402. Utilisez cette compétence chaque fois que l'utilisateur souhaite : créer des services API qui acceptent les paiements x402 et renvoient des résultats ; créer des agents qui paient automatiquement via le protocole x402 pour accéder aux données payantes ; mettre en œuvre la vérification des paiements sur leur propre facilitateur ; configurer des facilitateurs x402 pour les blockchains EVM/Solana/Aptos ; utilisez n'importe quel jeton ERC-20 ou pièce native comme paiement (pas seulement l'USDC) ; créer des schémas de paiement personnalisés (comme la délégation EIP-7702) ; mettre en œuvre des paiements sans gaz via EIP-3009, Permit2 ou EIP-2612 ; protéger les routes Axum derrière les micropaiements blockchain ; créer des clients reqwest qui gèrent de manière transparente les paiements x402 ; ou travaillez avec les formats de fil du protocole x402 V1 ou V2. Assurez-vous d'utiliser cette compétence lorsque l'utilisateur mentionne HTTP 402, x402, les paiements blockchain, les paiements cryptés, les micropaiements sur HTTP, les API de paiement à la demande ou la configuration d'un facilitateur.
