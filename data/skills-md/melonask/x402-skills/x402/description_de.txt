Umfassende Anleitung zum Erstellen von Lösungen mit der x402-rs Rust-Bibliothek und dem x402 HTTP 402-Zahlungsprotokoll. Verwenden Sie diese Fähigkeit, wann immer der Benutzer Folgendes möchte: API-Dienste erstellen, die x402-Zahlungen akzeptieren und Ergebnisse zurückgeben; Erstellen Sie Agenten, die automatisch über das x402-Protokoll bezahlen, um auf kostenpflichtige Daten zuzugreifen. Führen Sie die Zahlungsüberprüfung durch Ihren eigenen Moderator durch. x402-Vermittler für EVM/Solana/Aptos-Blockchains konfigurieren; Verwenden Sie einen beliebigen ERC-20-Token oder eine native Münze als Zahlungsmittel (nicht nur USDC); Erstellen Sie benutzerdefinierte Zahlungssysteme (wie die EIP-7702-Delegierung); gaslose Zahlungen über EIP-3009, Permit2 oder EIP-2612 implementieren; Schützen Sie Axum-Routen hinter Blockchain-Mikrozahlungen; Erstellen Sie Anforderungsclients, die x402-Zahlungen transparent abwickeln. oder arbeiten Sie mit den Kabelformaten x402-Protokoll V1 oder V2. Stellen Sie sicher, dass Sie diesen Skill verwenden, wenn der Benutzer HTTP 402, x402, Blockchain-Zahlungen, Krypto-Zahlungen, Mikrozahlungen über HTTP, Pay-per-Request-APIs oder die Einrichtung eines Moderators erwähnt.
