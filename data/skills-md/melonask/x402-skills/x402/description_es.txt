Guía completa para crear soluciones con la biblioteca Rust x402-rs y el protocolo de pago HTTP 402 x402. Utilice esta habilidad siempre que el usuario desee: crear servicios API que acepten pagos x402 y devuelvan resultados; crear agentes que paguen automáticamente a través del protocolo x402 para acceder a datos pagos; implementar la verificación de pagos en su propio facilitador; configurar facilitadores x402 para blockchains EVM/Solana/Aptos; utilizar cualquier token ERC-20 o moneda nativa como pago (no solo USDC); crear esquemas de pago personalizados (como la delegación EIP-7702); implementar pagos sin gas a través de EIP-3009, Permit2 o EIP-2612; proteger las rutas de Axum detrás de los micropagos blockchain; crear clientes reqwest que manejen de forma transparente pagos x402; o trabajar con los formatos de cable V1 o V2 ​​del protocolo x402. Asegúrese de utilizar esta habilidad cuando el usuario mencione HTTP 402, x402, pagos blockchain, pagos criptográficos, micropagos a través de HTTP, API de pago por solicitud o configuración del facilitador.
