x402-rs Rust ライブラリと x402 HTTP 402 支払いプロトコルを使用したソリューションを構築するための包括的なガイド。ユーザーが次のことを行う場合は常にこのスキルを使用します。x402 支払いを受け入れ、結果を返す API サービスを作成する。 x402 プロトコル経由で自動的に支払いを行い、有料データにアクセスするエージェントを構築します。独自のファシリテーターによる支払い検証を実装します。 EVM/Solana/Aptos ブロックチェーン用に x402 ファシリテーターを構成します。 (USDC だけでなく) 支払いとして任意の ERC-20 トークンまたはネイティブ コインを使用します。カスタム支払いスキーム (EIP-7702 委任など) を構築します。 EIP-3009、Permit2、または EIP-2612 を介してガスレス支払いを実装します。ブロックチェーンマイクロペイメントの背後にあるAxumルートを保護します。 x402 支払いを透過的に処理する reqwest クライアントを作成します。または、x402 プロトコル V1 または V2 ワイヤ形式で動作します。ユーザーが HTTP 402、x402、ブロックチェーン支払い、暗号通貨支払い、HTTP 経由のマイクロペイメント、ペイパーリクエスト API、またはファシリテーターのセットアップについて言及した場合は、必ずこのスキルを使用してください。
