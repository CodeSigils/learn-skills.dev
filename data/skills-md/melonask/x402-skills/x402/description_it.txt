Guida completa per la creazione di soluzioni con la libreria Rust x402-rs e il protocollo di pagamento x402 HTTP 402. Utilizza questa competenza ogni volta che l'utente desidera: creare servizi API che accettino pagamenti x402 e restituiscano risultati; creare agenti che pagano automaticamente tramite il protocollo x402 per accedere ai dati a pagamento; implementare la verifica dei pagamenti sul proprio facilitatore; configurare facilitatori x402 per blockchain EVM/Solana/Aptos; utilizzare qualsiasi token ERC-20 o moneta nativa come pagamento (non solo USDC); costruire schemi di pagamento personalizzati (come la delega EIP-7702); implementare pagamenti senza gas tramite EIP-3009, Permit2 o EIP-2612; proteggere le rotte Axum dietro i micropagamenti blockchain; creare client reqwest che gestiscano in modo trasparente i pagamenti x402; oppure funziona con i formati di cavo del protocollo x402 V1 o V2. Assicurati di utilizzare questa abilità quando l'utente menziona HTTP 402, x402, pagamenti blockchain, pagamenti crittografici, micropagamenti su HTTP, API pay-per-request o configurazione del facilitatore.
