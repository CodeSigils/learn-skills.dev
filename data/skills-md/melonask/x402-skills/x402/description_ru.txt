Комплексное руководство по созданию решений с использованием библиотеки Rust x402-rs и платежного протокола x402 HTTP 402. Используйте этот навык всякий раз, когда пользователь хочет: создавать службы API, которые принимают платежи x402 и возвращают результаты; создать агентов, которые автоматически платят по протоколу x402 за доступ к платным данным; реализовать проверку платежей на собственном посреднике; настроить посредники x402 для блокчейнов EVM/Solana/Aptos; используйте в качестве оплаты любой токен ERC-20 или собственную монету (не только USDC); создавать собственные схемы оплаты (например, делегирование EIP-7702); внедрить безгазовые платежи через EIP-3009, Permit2 или EIP-2612; защитить маршруты Axum с помощью микроплатежей на блокчейне; создавать клиенты reqwest, которые прозрачно обрабатывают платежи x402; или работайте с форматами проводов протокола x402 V1 или V2. Обязательно используйте этот навык, когда пользователь упоминает HTTP 402, x402, платежи через блокчейн, криптоплатежи, микроплатежи через HTTP, API с оплатой за запрос или настройку посредника.
