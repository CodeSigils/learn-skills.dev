Installieren Sie einen iOS-Build drahtlos auf einem echten iPhone oder iPad mit der „Remote-Installer“-CLI – sie validiert den Build, öffnet einen temporären HTTPS-Tunnel und druckt eine Installations-URL sowie einen QR-Code zum Scannen. Verwenden Sie dies immer dann, wenn jemand einen Build auf einem physischen Gerät ohne TestFlight oder ein Kabel wünscht: „Laden Sie dies auf mein Telefon“, „senden Sie diesen Build an einen Tester“, „teilen Sie die IPA“, „installieren Sie dies auf meinem iPad“, „lassen Sie QA diesen Build ausprobieren“, „erstellen Sie einen Link für diese .app“ oder jede Erwähnung von Over-the-Air-/OTA-Installation, itms-Diensten oder Ad-hoc-Verteilung. Verwenden Sie es auch, wenn jemand gerade einen Xcode-Build oder ein Xcode-Archiv fertiggestellt hat und fragt, wie er es auf ein Gerät bekommt. Nicht für Simulator-Installationen (stattdessen direkt erstellen und ausführen) und nicht für die Übermittlung im App Store oder TestFlight.
