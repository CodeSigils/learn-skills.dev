リポジトリの AI ハーネス (スキル、スラッシュ コマンド、エージェント、および MCP サーバー) のインタラクティブで自己完結型の HTML 依存関係マップを生成します。これには、どのスキルがどのスキルに引き継ぎ、どのエージェントにどの委任が行われ、何がどの MCP サーバーを使用するかを示す、型付きの証拠に裏付けられたエッジが含まれます。ユーザーがエージェントのハーネス、スキル、サブエージェント、または MCP セットアップのマッピング、視覚化、図表、または監査を要求する場合に使用します。 .claude/、skills/、または .mcp.json サーフェスを持つ任意のリポジトリで動作します。出力は単一のオフライン HTML ファイルです。
