Genera una mappa delle dipendenze HTML interattiva e autonoma del cablaggio AI di un repository: competenze, comandi slash, agenti e server MCP, con bordi digitati supportati da prove che mostrano quali competenze vengono trasferite a quali, cosa delega a quali agenti e cosa utilizza quali server MCP. Da utilizzare quando l'utente chiede di mappare, visualizzare, creare un diagramma o controllare il cablaggio degli agenti, le competenze, i subagenti o la configurazione MCP. Funziona su qualsiasi repository con superfici .claude/, skills/ o .mcp.json. L'output è un singolo file HTML offline.
