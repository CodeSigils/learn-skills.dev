قم بإنشاء خريطة تبعية HTML تفاعلية ومكتفية ذاتيًا لأدوات الذكاء الاصطناعي الخاصة بالمستودع - المهارات، وأوامر الشرطة المائلة، والوكلاء، وخوادم MCP، مع حواف مكتوبة مدعومة بالأدلة توضح المهارات التي يتم تسليمها إلى أي وكلاء، وما الذي يستخدم أي خوادم MCP. يُستخدم عندما يطلب المستخدم رسم خريطة أو تصور أو رسم تخطيطي أو تدقيق أدوات الوكلاء أو المهارات أو الوكلاء الفرعيين أو إعداد MCP. يعمل على أي ريبو مع أسطح .claude/، أو Skills/، أو .mcp.json. الإخراج هو ملف HTML واحد غير متصل بالإنترنت.
