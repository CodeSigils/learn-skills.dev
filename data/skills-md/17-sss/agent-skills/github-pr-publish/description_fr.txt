Flux de travail neutre en termes d'agent pour publier en toute sécurité des demandes d'extraction GitHub avec gh CLI, git local et une solution de repli GitHub REST contrainte. À utiliser lorsqu'on vous demande de créer, d'ouvrir, de publier, de rédiger ou de contrôler en amont un PR GitHub à partir d'une branche locale ; pousser une branche pour la création de relations publiques ; créer un PR dans un dépôt public ou privé ; diagnostiquer l'authentification de création de PR, le SSO, l'autorisation ou les échecs introuvables ; ou évitez les invites dangereuses de création de gh pr, la création de fork ou les poussées accidentelles.
