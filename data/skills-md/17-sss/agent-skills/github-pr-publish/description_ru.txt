Независимый от агентов рабочий процесс для безопасной публикации запросов на извлечение GitHub с помощью gh CLI, локального git и ограниченного резервного варианта GitHub REST. Используйте, когда вас попросят создать, открыть, опубликовать, набросать или выполнить предварительную проверку PR GitHub из локального филиала; продвигать ветку для создания пиара; создать PR в публичном или частном репозитории; диагностировать сбои аутентификации, единого входа, разрешений или необнаружения при создании PR; или избегайте небезопасных подсказок gh pr create, создания вилок или случайных нажатий.
