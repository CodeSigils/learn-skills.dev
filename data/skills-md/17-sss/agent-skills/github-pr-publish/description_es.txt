Flujo de trabajo neutral respecto al agente para publicar de forma segura solicitudes de extracción de GitHub con gh CLI, git local y respaldo REST de GitHub restringido. Úselo cuando se le solicite crear, abrir, publicar, redactar o realizar una verificación previa de un PR de GitHub desde una sucursal local; impulsar una rama para la creación de relaciones públicas; crear un PR en un repositorio público o privado; diagnosticar fallas de autenticación de creación de relaciones públicas, SSO, permisos o no encontrados; o evite indicaciones inseguras de gh pr create, creación de bifurcaciones o empujones accidentales.
