Agentenneutraler Workflow zum sicheren Veröffentlichen von GitHub-Pull-Anfragen mit gh CLI, lokalem Git und eingeschränktem GitHub REST-Fallback. Verwenden Sie diese Option, wenn Sie aufgefordert werden, eine GitHub-PR von einer lokalen Niederlassung aus zu erstellen, zu öffnen, zu veröffentlichen, zu entwerfen oder einen Preflight durchzuführen. einen Zweig für die PR-Erstellung vorantreiben; Erstellen Sie eine PR in einem öffentlichen oder privaten Repo; Diagnostizieren Sie PR-Erstellungsauthentifizierung, SSO, Berechtigungen oder nicht gefundene Fehler. oder vermeiden Sie unsichere gh pr create-Eingabeaufforderungen, Fork-Erstellung oder versehentliche Pushs.
