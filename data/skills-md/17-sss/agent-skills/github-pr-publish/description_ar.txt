سير عمل محايد للوكيل لنشر طلبات سحب GitHub بأمان باستخدام gh CLI، وgit المحلي، وGitHub REST الاحتياطي المقيد. يُستخدم عندما يُطلب منك إنشاء أو فتح أو نشر أو صياغة أو الاختبار المبدئي لـ GitHub PR من فرع محلي؛ دفع فرع لإنشاء العلاقات العامة؛ إنشاء علاقات عامة في مستودع عام أو خاص؛ تشخيص مصادقة إنشاء العلاقات العامة، أو تسجيل الدخول الموحد (SSO)، أو الإذن، أو حالات الفشل التي لم يتم العثور عليها؛ أو تجنب إنشاء مطالبات غير آمنة أو إنشاء شوكة أو دفعات غير مقصودة.
