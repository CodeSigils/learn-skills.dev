Flusso di lavoro indipendente dall'agente per la pubblicazione sicura delle richieste pull GitHub con gh CLI, git locale e fallback GitHub REST vincolato. Utilizzare quando viene richiesto di creare, aprire, pubblicare, bozza o preflight di un PR GitHub da una filiale locale; spingere un ramo per la creazione di PR; creare una PR in un pronti contro termine pubblico o privato; diagnosticare errori di autenticazione di creazione PR, SSO, autorizzazione o non trovati; oppure evitare prompt non sicuri di gh pr create, creazione di fork o pressioni accidentali.
