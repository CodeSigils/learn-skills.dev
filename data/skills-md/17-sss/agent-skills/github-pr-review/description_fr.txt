Flux de travail indépendant de l'agent pour examiner les demandes d'extraction GitHub avec gh CLI, git local, tests et API GitHub REST ou GraphQL, puis publier des commentaires de résumé ou de révision en ligne en tant que compte GitHub authentifié de l'utilisateur. À utiliser lorsqu'on vous demande de configurer l'authentification de révision de PR, de vérifier une URL de PR, de vérifier le propriétaire/dépôt n° 123, de vérifier le PR de la branche actuelle, de publier des commentaires de révision de PR, de consulter les PR de dépôt publics ou privés, d'utiliser gh pour inspecter une différence de PR ou de laisser des commentaires du compte GitHub de l'utilisateur.
