Flusso di lavoro indipendente dall'agente per la revisione delle richieste pull di GitHub con gh CLI, git locale, test e API GitHub REST o GraphQL, quindi la pubblicazione di riepiloghi o commenti di revisione in linea come account GitHub autenticato dell'utente. Utilizzare quando richiesto per impostare l'autenticazione della revisione PR, rivedere un URL PR, rivedere il proprietario/repo#123, rivedere il PR del ramo corrente, pubblicare commenti di revisione PR, rivedere i PR di repository pubblici o privati, utilizzare gh per ispezionare un diff PR o lasciare feedback dall'account GitHub dell'utente.
