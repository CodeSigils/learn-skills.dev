سير عمل محايد للوكيل لمراجعة طلبات سحب GitHub باستخدام gh CLI، وgit المحلي، والاختبارات، وGitHub REST أو واجهات برمجة تطبيقات GraphQL، ثم نشر تعليقات المراجعة الموجزة أو المضمنة كحساب GitHub المعتمد للمستخدم. استخدمه عندما يُطلب منك إعداد مصادقة مراجعة العلاقات العامة، أو مراجعة عنوان URL للعلاقات العامة، أو مراجعة المالك/المستودع رقم 123، أو مراجعة العلاقات العامة للفرع الحالي، أو نشر تعليقات مراجعة العلاقات العامة، أو مراجعة العلاقات العامة الخاصة بالريبو العامة أو الخاصة، أو استخدام gh لفحص فرق العلاقات العامة، أو ترك تعليقات من حساب GitHub الخاص بالمستخدم.
