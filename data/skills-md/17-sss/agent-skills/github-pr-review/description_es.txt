Flujo de trabajo neutral para el agente para revisar solicitudes de extracción de GitHub con gh CLI, git local, pruebas y API REST o GraphQL de GitHub, y luego publicar resúmenes o comentarios de revisión en línea como la cuenta de GitHub autenticada del usuario. Úselo cuando se le solicite configurar la autenticación de revisión de relaciones públicas, revisar una URL de relaciones públicas, revisar el propietario/repositorio n.° 123, revisar las relaciones públicas de la sucursal actual, publicar comentarios de revisión de relaciones públicas, revisar relaciones públicas de repositorios públicos o privados, usar gh para inspeccionar una diferencia de relaciones públicas o dejar comentarios desde la cuenta de GitHub del usuario.
