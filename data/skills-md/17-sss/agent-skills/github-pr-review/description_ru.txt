Независимый от агентов рабочий процесс для проверки запросов на извлечение GitHub с помощью gh CLI, локального git, тестов и API-интерфейсов GitHub REST или GraphQL, а затем публикации сводных или встроенных комментариев обзора от имени аутентифицированной учетной записи GitHub пользователя. Используйте, когда вас попросят настроить аутентификацию при просмотре PR, просмотреть URL-адрес PR, просмотреть владельца/репозиторий № 123, просмотреть текущий PR ветки, опубликовать комментарии к обзору PR, просмотреть публичные или частные PR репозитория, использовать gh для проверки разницы PR или оставить отзыв из учетной записи пользователя на GitHub.
