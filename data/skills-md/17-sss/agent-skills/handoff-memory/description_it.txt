Crea, aggiorna, convalida e riprendi documenti di memoria e HANDOFF condivisi per un repository, un contesto tra repository a livello di spazio di lavoro o un flusso di lavoro all'interno di uno spazio di lavoro più ampio. Da utilizzare quando viene richiesto di scrivere un handoff, l'avanzamento del checkpoint, riprendere il lavoro precedente o standardizzare le note sullo stato del progetto in file tracciabili da Git come `docs/HANDOFF.md`, `_memory/HANDOFF.md` o `_memory/workstreams/checkout-flow/HANDOFF.md`.
