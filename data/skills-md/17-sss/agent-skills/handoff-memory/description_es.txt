Cree, actualice, valide y reanude documentos de memoria y HANDOFF compartidos para un repositorio, un contexto de repositorio cruzado en todo el espacio de trabajo o un flujo de trabajo dentro de un espacio de trabajo más grande. Úselo cuando se le solicite escribir un traspaso, un punto de control del progreso, reanudar un trabajo anterior o estandarizar notas del estado del proyecto en archivos rastreables por Git como `docs/HANDOFF.md`, `_memory/HANDOFF.md` o `_memory/workstreams/checkout-flow/HANDOFF.md`.
