Écrivez, révisez, refactorisez ou déboguez le code d'état Jotai idiomatique pour React et TypeScript. À utiliser lorsque le travail implique des atomes Jotai, des atomes dérivés, des atomes d'action en écriture seule, des atomes asynchrones, l'utilisation du fournisseur/magasin, jotai/utils, des assistants atomWith*, la migration atomFamily ou jotai-family, l'état d'un grand objet/liste, les performances de rendu, le test du code Jotai ou la conversion de l'état React Context/useState/style réducteur en un modèle d'atome plus proche de celui de Jotai.
