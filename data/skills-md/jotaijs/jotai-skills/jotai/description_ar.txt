كتابة أو مراجعة أو إعادة بناء أو تصحيح كود حالة Jotai الاصطلاحي لـ React وTypeScript. يُستخدم عندما يتضمن العمل ذرات Jotai، أو الذرات المشتقة، أو ذرات الإجراء للكتابة فقط، أو الذرات غير المتزامنة، أو استخدام الموفر/المتجر، أو jotai/utils، أو مساعدي atomWith*، أو ترحيل atomFamily أو عائلة jotai، أو حالة الكائن الكبير/القائمة، أو عرض الأداء، أو اختبار كود Jotai، أو تحويل حالة نمط React context/useState/reducer إلى نموذج ذرة يشبه Jotai أكثر.
