Verwenden Sie es immer dann, wenn Sie TypeScript- oder TSX-Code schreiben, bearbeiten, umgestalten oder überprüfen. Diese Fähigkeit definiert, wie TypeScript modelliert werden sollte, wie Grenzen und gemeinsame Helfer gehandhabt werden sollten, wie Absichten ohne Codekommentare ausgedrückt werden sollten und wie der Code klar, trocken und frei von defensiven KI-Einflüssen gehalten werden sollte. Informationen zu Überprüfungsworkflows finden Sie unter references/review-and-fix-changes.md.
