Úselo siempre que escriba, edite, refactorice o revise código TypeScript o TSX. Esta habilidad define cómo se debe modelar TypeScript, cómo se deben manejar los límites y los ayudantes compartidos, cómo se debe expresar la intención sin comentarios de código y cómo mantener el código claro, SECO y libre de desechos de IA defensiva. Para revisar los flujos de trabajo, lea references/review-and-fix-changes.md.
