قم بإجراء مراجعة كود النموذج الثاني المحدود باستخدام Codex Sol أو Claude Fable. استخدم عقدًا مدمجًا واحدًا للصحة والأمان والبساطة الهيكلية والنمطية وإعادة الاستخدام لمراجعة أولية واحدة بالإضافة إلى ما يصل إلى محاولتي تقارب عندما تغير النتائج المقبولة المصدر. يُستخدم عندما يطلب المستخدم مراجعة الوكيل، أو الرأي الثاني، أو المراجعة الأمنية، أو المراجعة التنافسية، أو المراجعة العميقة لجودة التعليمات البرمجية.
