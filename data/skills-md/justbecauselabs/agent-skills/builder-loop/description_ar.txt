خطة منضبطة ← التحقق من الصحة ← سير عمل بناء نقاط التفتيش مع بوابة مراجعة الوكيل النهائية المحدودة. استخدم عندما يُطلب منك صراحةً تقسيم ميزة غير تافهة، أو إعادة البناء، أو الترحيل إلى نقاط تفتيش تم التحقق من صحتها، أو التخطيط قبل البرمجة، أو التنفيذ باستخدام بوابات المراجعة المسماة. أزواج مع مهارة مراجعة الوكيل.
