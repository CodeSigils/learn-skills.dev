Дисциплинированный рабочий процесс планирования → проверки → построения контрольных точек с ограниченным окончательным этапом проверки агентом. Используйте, когда явно просят сломать нетривиальную функцию, выполнить рефакторинг или миграцию в проверенные контрольные точки, спланировать перед кодированием или реализовать с помощью именованных шлюзов проверки. Сочетается с навыком проверки агента.
