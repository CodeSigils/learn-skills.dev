Выпуклое руководство по серверной части для запросов, мутаций, действий, схемы, валидаторов, аутентификации, компонентов, агентов, поиска, тестирования, производственной конфигурации и интеграции клиент/сервер. Используйте при взаимодействии с серверной частью Convex, включая функции Convex, изменения схемы, конечные точки HTTP, планирование, хранение, функции искусственного интеллекта или интеграцию инфраструктуры.
