Führen Sie langlebige Hintergrundbefehle mithilfe von tmux-Sitzungen anstelle von Hintergrundprozessen aus und verwalten Sie sie. Wird zum Starten von Backend-/API-Servern, Expo/React Native-Entwicklungsservern, Job-Workern, Watchern oder anderen Aufgaben verwendet, die weiter ausgeführt werden sollen, während andere Befehle ausgeführt werden.
