كيفية إضافة اتصال المحفظة والمصادقة إلى واجهة Monad الأمامية الحالية باستخدام Para - محافظ MPC المضمنة مع البريد الإلكتروني / الهاتف / مفتاح المرور / تسجيل الدخول الاجتماعي، بالإضافة إلى اتصال المحفظة الخارجية (MetaMask، Coinbase، WalletConnect، Rainbow، وما إلى ذلك). مدفوعًا بـ `para` CLI (`@getpara/cli`). يمكنك الجلب عندما يريد المستخدم دمج Para في واجهة Next.js أو Vite الأمامية الحالية، أو إدارة مشاريع Para ومفاتيح API وخطافات الويب من الوحدة الطرفية. هذه هي مهارة تكامل المحفظة الأساسية التي يتمتع بها مونسكيلز - لا توجد مهارة منفصلة لـ "تسجيل الدخول عبر مواقع التواصل الاجتماعي" أو "المحافظ المضمنة"، كل شيء موجود هنا.
