Come aggiungere la connessione e l'autenticazione del portafoglio a un frontend Monad esistente utilizzando Para: portafogli MPC incorporati con e-mail/telefono/passkey/accesso social, oltre alla connessione a portafoglio esterno (MetaMask, Coinbase, WalletConnect, Rainbow, ecc.). Guidato dalla CLI `para` ("@getpara/cli`). Recupera quando l'utente desidera integrare Para in un frontend Next.js o Vite esistente oppure gestire progetti Para, chiavi API e webhook dal terminale. Questa è la capacità canonica di integrazione del portafoglio di Monskills: non esiste una competenza separata per "accesso social" o "portafogli incorporati", è tutto qui.
