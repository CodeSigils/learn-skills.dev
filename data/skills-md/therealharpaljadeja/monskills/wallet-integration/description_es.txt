Cómo agregar conexión de billetera y autenticación a una interfaz Monad existente usando Para: billeteras MPC integradas con correo electrónico/teléfono/clave de acceso/inicio de sesión social, además de conexión de billetera externa (MetaMask, Coinbase, WalletConnect, Rainbow, etc.). Impulsado por la CLI `para` (`@getpara/cli`). Recupera cuando el usuario desea integrar Para en una interfaz Next.js o Vite existente, o administrar proyectos de Para, claves API y webhooks desde la terminal. Esta es la habilidad canónica de integración de billeteras de Monskills: no existe una habilidad separada para "inicio de sesión social" o "billeteras integradas", todo está aquí.
