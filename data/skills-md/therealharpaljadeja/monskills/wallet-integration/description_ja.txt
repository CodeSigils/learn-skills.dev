Para を使用して既存の Monad フロントエンドにウォレット接続と認証を追加する方法 — 電子メール / 電話 / パスキー / ソーシャル ログインを備えた組み込み MPC ウォレット、および外部ウォレット接続 (MetaMask、Coinbase、WalletConnect、Rainbow など)。 `para` CLI (`@getpara/cli`) によって駆動されます。ユーザーが Para を既存の Next.js または Vite フロントエンドに統合する場合、またはターミナルから Para プロジェクト、API キー、Webhook を管理する場合に取得します。これは、monskills の正規のウォレット統合スキルです。「ソーシャル ログイン」や「埋め込みウォレット」用の個別のスキルはなく、すべてここにあります。
