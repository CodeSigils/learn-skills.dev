Para를 사용하여 기존 Monad 프런트엔드에 지갑 연결 및 인증을 추가하는 방법 — 이메일/전화/패스키/소셜 로그인이 포함된 내장형 MPC 지갑과 외부 지갑 연결(MetaMask, Coinbase, WalletConnect, Rainbow 등). `para` CLI(`@getpara/cli`)에 의해 구동됩니다. 사용자가 Para를 기존 Next.js 또는 Vite 프런트엔드에 통합하거나 터미널에서 Para 프로젝트, API 키 및 웹후크를 관리하려고 할 때 가져옵니다. 이것이 몬스킬의 표준적인 지갑 통합 스킬입니다. "소셜 로그인"이나 "임베디드 지갑"에 대한 별도의 스킬은 없으며 모두 여기에 있습니다.
