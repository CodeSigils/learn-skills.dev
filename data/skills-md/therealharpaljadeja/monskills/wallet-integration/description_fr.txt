Comment ajouter une connexion de portefeuille et une authentification à une interface Monad existante à l'aide de Para - portefeuilles MPC intégrés avec e-mail/téléphone/clé d'accès/connexion sociale, ainsi qu'une connexion à un portefeuille externe (MetaMask, Coinbase, WalletConnect, Rainbow, etc.). Piloté par la CLI `para` ($`@getpara/cli`). Récupérez lorsque l'utilisateur souhaite intégrer Para dans une interface Next.js ou Vite existante, ou gérer des projets Para, des clés API et des webhooks à partir du terminal. Il s'agit de la compétence canonique d'intégration de portefeuille de Monskills : il n'y a pas de compétence distincte pour la « connexion sociale » ou les « portefeuilles intégrés », tout est là.
