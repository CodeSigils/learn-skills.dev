Lancez une session de développement sans port + tmux pour le SDK Workflow qui donne à chaque arbre de travail git des URL `<branch>.<name>.localhost` isolées pour l'atelier Next.js et l'interface utilisateur d'observabilité, ainsi qu'une ligne d'état Claude qui fait apparaître ces URL. À utiliser uniquement lorsque l'utilisateur demande une « session de développement sans port », une « disposition de développement tmux pour le workflow », des « URL de développement isolées par worktree » ou souhaite câbler les URL de développement de workflow dans la ligne d'état Claude. Ne pas activer pour la tâche générique "démarrer le serveur de développement" / "exécuter pnpm dev".
