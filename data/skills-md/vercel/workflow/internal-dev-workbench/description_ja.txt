Workflow SDK のポートレス + tmux 開発セッションをスピンアップします。これにより、各 git ワークツリーに Next.js ワークベンチとオブザーバビリティ UI 用の分離された `<branch>.<name>.localhost` URL が提供され、さらにそれらの URL を表示する Claude ステータスラインが提供されます。ユーザーが「ポートレス開発セッション」、「ワークフロー用の tmux 開発レイアウト」、「ワークツリー分離された開発 URL」を要求する場合、またはワークフロー開発 URL をクロード ステータスラインに接続したい場合にのみ使用します。一般的な「開発サーバーの起動」/「pnpm dev の実行」タスクをアクティブ化しないでください。
