Запустите сеанс разработки без порта + tmux для Workflow SDK, который предоставляет каждому рабочему дереву git изолированные URL-адреса `<branch>.<name>.localhost` для рабочей среды Next.js и пользовательского интерфейса наблюдения, а также строку состояния Claude, которая отображает эти URL-адреса. Используйте только тогда, когда пользователь запрашивает «сеанс разработки без портов», «макет разработки tmux для рабочего процесса», «URL-адреса разработки, изолированные от рабочего дерева» или хочет подключить URL-адреса разработки рабочего процесса к строке состояния Claude. Не активируйте общую задачу «запустить сервер разработки» или «запустить pnpm dev».
