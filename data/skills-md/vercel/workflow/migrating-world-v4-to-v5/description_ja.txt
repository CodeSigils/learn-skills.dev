カスタム Workflow SDK World 実装を v4 仕様から v5 にアップグレードします。パッケージが `@workflow/world` の `World` インターフェイスを実装し、5.x に移行するときに使用します。スロット位置ではなく ULID であるイベント ID、再生時にイベント ID にスロット番号が付けられていない、ランタイムが拒否する `specVersion`、トップレベルの World メソッドとしての `writeToStream` / `closeStream` / `readFromStream`、`steps.get` または「runId」、「step」キューの種類または「__wkf_step_*」トピック、「preconditionGuard」機能、または「createLocalWorld」/「createVercelWorld」ファクトリーのない「events.listByCorrelationId」。
