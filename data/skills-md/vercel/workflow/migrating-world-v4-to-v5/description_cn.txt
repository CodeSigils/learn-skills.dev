将自定义 Workflow SDK World 实现从 v4 规范升级到 v5。适用于实现 `@workflow/world` 中 `World` 接口且正迁移到 5.x 的包——事件 ID 为 ULID 而非槽位位置，回放时出现 `Event id is not slot-numbered`，运行时拒绝的 `specVersion`，`writeToStream` / `closeStream` / `readFromStream` 作为顶层 World 方法，`steps.get` 或 `events.listByCorrelationId` 缺少 `runId`，使用 `'step'` 队列类型或 `__wkf_step_*` 主题，具备 `preconditionGuard` 能力，或使用 `createLocalWorld` / `createVercelWorld` 工厂。
