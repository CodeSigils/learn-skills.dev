Aktualisiert eine benutzerdefinierte Workflow‑SDK‑World‑Implementierung von der v4‑Spezifikation auf v5. Verwenden Sie dies, wenn ein Paket das `World`‑Interface aus `@workflow/world` implementiert und zu 5.x wechselt – Ereignis‑IDs, die ULIDs statt Slot‑Positionen sind, `Event id is not slot-numbered` zur Wiederholungszeit, ein `specVersion`, den die Laufzeit ablehnt, `writeToStream` / `closeStream` / `readFromStream` als Top‑Level‑World‑Methoden, `steps.get` oder `events.listByCorrelationId` ohne `runId`, ein `'step'`‑Queue‑Typ oder `__wkf_step_*`‑Themen, eine `preconditionGuard`‑Fähigkeit oder eine `createLocalWorld` / `createVercelWorld`‑Factory.
