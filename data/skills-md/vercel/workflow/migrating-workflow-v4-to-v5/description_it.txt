Aggiorna un'app da Workflow SDK 4.x a 5.0. Da utilizzare quando si eseguono il bumping delle dipendenze `workflow` / `@workflow/*` alla v5 o quando si raggiungono le API v4 rimosse: `runStep`, `stepEntrypoint`, `workflow/internal/private`, `@workflow/core/private`, `writeToStream` / `closeStream` / `readFromStream` su un mondo, `world.steps.get` senza runId, `hook.getConflect()` restituisce `{ runId }`, `experimental_setAttributes`, `createLocalWorld` / `createVercelWorld`, `NestLocalBuilder` importati da `@workflow/nest` o una trasformazione SWC richiamata con `mode: 'client'`.
