アプリを Workflow SDK 4.x から 5.0 にアップグレードします。 `workflow` / `@workflow/*` 依存関係を v5 にバンプする場合、または削除された v4 API にアクセスする場合に使用します。 — ワールドの `runStep`、`stepEntrypoint`、`workflow/internal/private`、`@workflow/core/private`、`writeToStream` / `closeStream` / `readFromStream`、runId なしの `world.steps.get`、 `hook.getConflict()` は、`{ runId }`、`experimental_setAttributes`、`createLocalWorld` / `createVercelWorld`、`@workflow/nest` からインポートされた `NestLocalBuilder`、または `mode: 'client'` で呼び出された SWC 変換を返します。
