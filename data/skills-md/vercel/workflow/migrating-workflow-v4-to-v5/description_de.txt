Aktualisiert eine Anwendung von Workflow SDK 4.x auf 5.0. Verwenden Sie es, wenn Sie die `workflow`‑/ `@workflow/*`‑Abhängigkeiten auf v5 erhöhen oder wenn Sie auf entfernte v4‑APIs stoßen — `runStep`, `stepEntrypoint`, `workflow/internal/private`, `@workflow/core/private`, `writeToStream` / `closeStream` / `readFromStream` in einer World, `world.steps.get` ohne `runId`, `hook.getConflict()` das `{ runId }` zurückgibt, `experimental_setAttributes`, `createLocalWorld` / `createVercelWorld`, `NestLocalBuilder` aus `@workflow/nest` importiert oder ein SWC‑Transform, das mit `mode: 'client'` aufgerufen wird.
