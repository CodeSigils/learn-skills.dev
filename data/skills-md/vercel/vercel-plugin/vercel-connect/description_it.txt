Guida degli esperti di Vercel Connect: ottieni in modo sicuro token OAuth con ambito per servizi di terze parti (Slack, GitHub, server MCP, OAuth, Snowflake) per conto di app o utenti tramite Vercel OIDC. Da utilizzare quando si collega l'accesso API di terze parti, ci si connette ai server MCP, si inviano messaggi Slack, si accede alle API GitHub, si ricevono eventi webhook da Slack/Linear/GitHub e li si inoltra ai propri agenti e app o si creano connessioni con agenti Eve.
