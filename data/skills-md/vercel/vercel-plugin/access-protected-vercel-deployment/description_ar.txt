قم بالوصول واختبار عمليات نشر Vercel المحمية بواسطة Vercel Authentication أو SSO أو حماية النشر. يتم استخدامه عندما يصل curl أو Agent-browser أو Playwright أو أي طلب آلي آخر إلى صفحة تسجيل الدخول أو صفحة الحماية الخاصة بـ Vercel؛ عندما تعرض معاينة محمية أو عنوان URL للإنتاج 401 أو 403؛ عند ظهور TRUSTED_SOURCES_ENVIRONMENT_MISMATCH؛ أو عند الاختيار بين `vercel cur` ورأس `x-vercel-trusted-oidc-idp-token`.
