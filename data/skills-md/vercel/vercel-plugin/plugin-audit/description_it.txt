Controlla le prestazioni del plugin vercel su progetti reali. Estrae le chiamate dello strumento dai registri delle conversazioni di Claude Code, testa la corrispondenza degli hook rispetto agli input effettivi, identifica le lacune di copertura dei pattern e controlla la obsolescenza della cache dei plugin. Da utilizzare quando viene richiesto di verificare, testare o indagare sull'inserimento di competenze del plugin su un progetto reale.
