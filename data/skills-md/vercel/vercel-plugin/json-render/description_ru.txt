Руководство по рендерингу ответов чата ИИ — обработка частей UIMessage, отображение вызовов инструментов, состояния потоковой передачи и представление структурированных данных. Используйте при создании пользовательских интерфейсов чата, визуализации результатов инструментов или устранении неполадок с отображением ответов ИИ.
