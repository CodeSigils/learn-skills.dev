Руководство экспертов Vercel Chat SDK. Используйте при создании мультиплатформенных чат-ботов — Slack, Telegram, Microsoft Teams, Discord, Google Chat, GitHub, Linear — с единой кодовой базой. Охватывает класс Chat, адаптеры, потоки, сообщения, карточки, модальные окна, потоковую передачу, управление состоянием и настройку веб-перехватчика.
