Expertenanleitung für das Vercel Chat SDK. Zur Verwendung beim Erstellen von Chat-Bots für mehrere Plattformen – Slack, Telegram, Microsoft Teams, Discord, Google Chat, GitHub, Linear – mit einer einzigen Codebasis. Behandelt die Chat-Klasse, Adapter, Threads, Nachrichten, Karten, Modalitäten, Streaming, Statusverwaltung und Webhook-Einrichtung.
