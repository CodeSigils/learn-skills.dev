Автоматическая проверка браузера для серверов разработки. Запускается, когда сервер разработки начинает выполнять визуальную проверку с помощью агента-браузера — проверяет загрузку страницы, проверяет наличие ошибок консоли, проверяет ключевые элементы пользовательского интерфейса и сообщает о прохождении или сбое перед продолжением.
