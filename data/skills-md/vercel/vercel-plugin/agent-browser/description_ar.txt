أتمتة المتصفح CLI لوكلاء الذكاء الاصطناعي. يُستخدم عندما يحتاج المستخدم إلى التفاعل مع مواقع الويب، أو التحقق من مخرجات خادم التطوير، أو اختبار تطبيقات الويب، أو التنقل بين الصفحات، أو ملء النماذج، أو النقر على الأزرار، أو التقاط لقطات الشاشة، أو استخراج البيانات، أو تشغيل أي مهمة في المتصفح تلقائيًا. يتم تشغيله أيضًا عند بدء تشغيل خادم التطوير حتى تتمكن من التحقق منه بصريًا.
