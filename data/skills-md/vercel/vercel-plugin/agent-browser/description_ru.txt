Интерфейс командной строки автоматизации браузера для агентов ИИ. Используйте, когда пользователю необходимо взаимодействовать с веб-сайтами, проверять выходные данные сервера разработки, тестировать веб-приложения, перемещаться по страницам, заполнять формы, нажимать кнопки, делать снимки экрана, извлекать данные или автоматизировать любую задачу браузера. Также срабатывает при запуске сервера разработки, чтобы вы могли проверить это визуально.
