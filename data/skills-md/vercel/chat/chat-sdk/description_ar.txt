أنشئ روبوتات دردشة متعددة المنصات باستخدام Chat SDK (حزمة `chat` npm). يُستخدم عندما يرغب المطورون في دعم روبوت باستخدام create-chat-sdk، أو إنشاء روبوت Slack، أو Teams، أو Google Chat، أو Discord، أو Telegram، أو GitHub، أو Linear، أو WhatsApp، أو التعامل مع الإشارات، أو الرسائل المباشرة، أو سلاسل الرسائل المشتركة، أو التفاعلات، أو أوامر الشرطة المائلة، أو البطاقات، أو الوسائط، أو الملفات، أو تدفق الذكاء الاصطناعي، أو إعداد مسارات خطاف الويب أو روبوتات متعددة المحولات، أو إرسال بطاقات غنية أو استجابات الذكاء الاصطناعي المتدفقة إلى منصات الدردشة، أو إنشاء محول مخصص أو محول الدولة.
