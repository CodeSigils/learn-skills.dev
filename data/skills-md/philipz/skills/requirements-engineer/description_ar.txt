يكتب قصص المستخدمين، وينشئ مواصفات المتطلبات (BRS، SRS، PRD، BRD)، ويحدد احتياجات أصحاب المصلحة للمتطلبات الوظيفية، ويحدد معايير القبول. يُستخدم عندما يحتاج المستخدم إلى جمع المتطلبات، أو تحليل الأعمال، أو تطوير المواصفات، أو قصص المستخدمين، أو حالات الاستخدام، أو المتطلبات الوظيفية، أو متطلبات أصحاب المصلحة، أو معايير القبول، أو الربط بين فرق العمل والفرق الفنية. يتم التنشيط عند طلب مهارة مهندس المتطلبات.
