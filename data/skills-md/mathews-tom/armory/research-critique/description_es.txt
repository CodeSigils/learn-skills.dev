Análisis crítico de artículos de investigación, manuscritos académicos, preimpresiones y estudios técnicos: evaluación de metodología, alineación entre afirmaciones y pruebas, importancia de las contribuciones y honestidad intelectual. Produce respuestas analíticas coherentes (no listas de verificación) que distinguen las debilidades genuinas de las limitaciones estándar del campo. Gobierna la postura intelectual: lector colegiado, no crítico adversario. Activadores sobre: ​​"criticar este artículo", "revisar esta investigación", "qué piensa de este artículo", "analizar este estudio", "evaluar la metodología", "es sólido este artículo", "evaluar esta investigación", "fortalezas y debilidades de este artículo", "la evidencia respalda las afirmaciones". Utilice esta habilidad cuando el usuario proporcione un artículo de investigación, una preimpresión o un estudio técnico y solicite una evaluación crítica de su mérito científico, metodología o contribución, no del formato, la higiene de las citas o la preparación para el envío (use la revisión del manuscrito para estos casos).
