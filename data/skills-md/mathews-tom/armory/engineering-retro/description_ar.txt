التحليل الهندسي بأثر رجعي القائم على Git لتاريخ الالتزام وأنماط العلاقات العامة وسرعة التطوير خلال نافذة زمنية قابلة للتكوين. استخدم هذه المهارة عندما يطلب المستخدم إجراء مراجعة بأثر رجعي أو قديم أو سريع أو مراجعة أسبوعية أو مراجعة هندسية أو ملخص تطوير أو تحليل الالتزام أو تقرير سرعة الفريق أو يقول "ماذا قمنا بشحنه" أو "ماذا حدث هذا الأسبوع" أو "الهندسة الرجعية" أو "السباق القديم" أو "ملخص التطوير" أو "/engineering-retro". يدعم النوافذ الزمنية (7D الافتراضي، 24H، 14D، 30D) ونطاق مسار monorepo.
