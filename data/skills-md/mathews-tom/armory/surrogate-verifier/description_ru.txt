Информационно-изолированный навык проверки, который генерирует структурированные тестовые утверждения и диагностику ошибок для пакетов навыков. Учитывая определение навыка и подсказку задачи, выдает проверяемые машиной утверждения (проверки содержания, регулярного выражения, формата, вызова инструмента) и диагностику первопричин в случае сбоя утверждений. Реализует роль суррогатного проверяющего из коэволюционной генерации навыков (EvoSkills). Срабатывает при: «проверить этот навык», «сгенерировать утверждения для», «суррогатную проверку», «проверить выходные данные этого навыка», «диагностировать сбой навыка», «создать тестовые примеры для навыка», «проверить навык», «генерировать утверждения», «проверить качество навыка по задачам», «сгенерировать оценочные утверждения». Используйте этот навык при оценке качества результатов навыков посредством автоматического тестирования утверждений, а не проверки вручную. НЕ для общей проверки кода (используйте pr-ревью). НЕ для оценки метаданных пакета (используйте package-evaluator). НЕ для создания набора тестов для кода приложения (используйте тестовую обвязку).
