Оценивайте качество пакета Claude Code по 6 взвешенным параметрам: качество вступительной части, покрытие триггеров, структурная полнота, глубина контента, последовательность и целостность, а также соответствие CONTRIBUTING.md. Охватывает все 7 типов пакетов: навыки, агенты, хуки, правила, команды, утилиты и пресеты. Каждый тип имеет сигналы качества, специфичные для типа, которые уточняют оценку D3 и D4. Составляет отчеты о результатах аудита с выводами по степени серьезности и практическими рекомендациями. Два режима: (1) Быстрый аудит — единый пакет, полный отчет по каждому параметру с взвешенной оценкой; (2) Полный аудит — все пакеты в репозитории, сравнительная таблица рейтинга, а также сводные данные по каждому пакету, опционально отфильтрованные по типу. Запускается по: «оценить пакет», «оценить навык», «качество агента аудита», «оценить этот крючок», «оценить это правило», «оценить команду», «проверить качество утилиты», «оценить предустановку», «качество пакета», «аудит пакета», «проверить качество навыка», «оценить навык», «проверить навык», «проверить полноту навыка», «оценить этот навык», «проверить качество навыка», «оценить навык», «оценить навык», «проверить навык», «насколько хорош этот навык», «Отзыв SKILL.md», «насколько хорош этот агент», «Отзыв AGENT.md». Используйте этот навык при проверке пакетов Claude Code перед развертыванием, сравнении качества пакетов в репозитории или диагностике того, почему навык не активируется по соответствующим запросам. НЕ для оценки или улучшения подсказок LLM — вместо этого используйте Prompt-lab. НЕ для проверки запросов на включение — вместо этого используйте pr-review.
