Создавайте сложные, автономные статические HTML-артефакты, открываемые в браузере, — интерактивные диаграммы, визуальные элементы архитектуры, информационные панели данных, HTML-инфографику и богатые интерактивные результаты. Используйте этот навык, когда вывод представляет собой HTML-файл, просматриваемый в браузере. Нулевой набор инструментов для сборки — ни React, ни Vite, ни Parcel. Чистый HTML5 + CSS3 (Grid/Flexbox) + встроенный SVG. Запускается по: «интерактивный HTML», «автономный веб-компонент», «открыть в браузере», «интерактивная диаграмма», «визуальная панель мониторинга», «артефакт HTML», «инфографика HTML», «интерактивная инфографика». Для вывода файла изображения (PNG/SVG) вместо этого используйте преобразование концепции в изображение.
