ブラウザーで開く、精巧で自己完結型の静的 HTML 成果物 (インタラクティブな図、アーキテクチャ ビジュアル、データ ダッシュボード、HTML インフォグラフィックス、豊富なインタラクティブな成果物) を構築します。このスキルは、出力がブラウザで表示される HTML ファイルである場合に使用します。ゼロ ビルド ツールチェーン — React、Vite、Parcel はありません。純粋な HTML5 + CSS3 (グリッド/フレックスボックス) + インライン SVG。トリガー: 「インタラクティブ HTML」、「自己完結型 Web コンポーネント」、「ブラウザで開く」、「インタラクティブ ダイアグラム」、「ビジュアル ダッシュボード」、「HTML アーティファクト」、「HTML インフォグラフィック」、「インタラクティブ インフォグラフィック」。画像ファイル出力 (PNG/SVG) の場合は、代わりにコンセプトから画像を使用してください。
