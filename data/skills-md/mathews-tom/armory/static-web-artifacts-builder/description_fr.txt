Créez des artefacts HTML statiques élaborés et autonomes ouverts dans un navigateur : diagrammes interactifs, visuels d'architecture, tableaux de bord de données, infographies HTML et livrables interactifs riches. Utilisez cette compétence lorsque la sortie est un fichier HTML affiché dans un navigateur. Chaîne d’outils sans build – pas de React, pas de Vite, pas de Parcel. HTML5 pur + CSS3 (Grille/Flexbox) + SVG en ligne. Déclencheurs sur : "HTML interactif", "composant Web autonome", "ouvrir dans le navigateur", "diagramme interactif", "tableau de bord visuel", "artefact HTML", "infographie HTML", "infographie interactive". Pour la sortie de fichier image (PNG/SVG), utilisez plutôt concept-to-image.
