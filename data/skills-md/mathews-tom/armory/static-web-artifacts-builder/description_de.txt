Erstellen Sie aufwändige, eigenständige statische HTML-Artefakte, die in einem Browser geöffnet werden – interaktive Diagramme, Architekturvisualisierungen, Daten-Dashboards, HTML-Infografiken und umfangreiche interaktive Ergebnisse. Verwenden Sie diese Fähigkeit, wenn die Ausgabe eine HTML-Datei ist, die in einem Browser angezeigt wird. Zero-Build-Toolchain – kein React, kein Vite, kein Parcel. Reines HTML5 + CSS3 (Grid/Flexbox) + Inline-SVG. Löst aus bei: „interaktives HTML“, „eigenständige Webkomponente“, „im Browser öffnen“, „interaktives Diagramm“, „visuelles Dashboard“, „HTML-Artefakt“, „HTML-Infografik“, „interaktive Infografik“. Verwenden Sie für die Ausgabe von Bilddateien (PNG/SVG) stattdessen „Concept-to-Image“.
