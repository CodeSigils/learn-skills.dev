Convierta cualquier concepto, idea o descripción en un visual HTML estático pulido y luego expórtelo como un archivo de imagen PNG o SVG. Utilice esta habilidad cuando el usuario necesite explícitamente un archivo de imagen (PNG o SVG). Esto incluye: diagramas conceptuales, diagramas de flujo, cuadros comparativos, imágenes de procesos, diagramas educativos, gráficos de redes sociales, visualizaciones de datos, carteles, tarjetas, insignias, íconos, bocetos de logotipos o cualquier solicitud de "hazme una imagen de X" que se pueda lograr con HTML/CSS/SVG en lugar de generación de IA fotográfica. También se activa cuando el usuario tiene un objeto visual HTML existente y desea exportarlo/convertirlo a PNG o SVG. Frases desencadenantes: "crear una imagen de", "exportar como PNG", "guardar como SVG", "concepto en imagen", "convertir esto en una imagen", "captura de pantalla de este HTML", "diseñar un gráfico para exportar". Para elementos visuales HTML interactivos abiertos en un navegador, utilice static-web-artifacts-builder en su lugar.
