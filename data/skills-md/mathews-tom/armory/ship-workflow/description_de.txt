Automatisierte Release-Pipeline, die die Hauptversion zusammenführt, Tests ausführt, eine Überprüfung vor der Landung durchführt, die Version aktualisiert, das Änderungsprotokoll aktualisiert, halbierbare Commits erstellt und eine Pull-Anfrage öffnet. Verwenden Sie diesen Skill, wenn der Benutzer sagt: „Versenden“, „Versenden“, „Freigeben“, „Vorbereiten für die Veröffentlichung“, „Öffnen Sie eine PR“, „Push und PR“, „landen Sie dies“, „Machen Sie dies für den Versand bereit“, „Erstellen Sie eine Veröffentlichung“, „/ship-workflow“. Bewältigt den gesamten Lebenszyklus von den Kontrollen vor dem Flug bis zur PR-Erstellung.
