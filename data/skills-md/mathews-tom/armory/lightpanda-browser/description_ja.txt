エージェント ブラウザ CLI によるバックエンド エンジンとして Lightpanda を使用する、軽量のヘッドレス ブラウザ自動化。 Chromium よりもメモリが 9 倍少なく、11 倍高速です。 Web スクレイピング、DOM インタラクション、データ抽出、フォーム自動化、視覚的なレンダリングが必要ない API テストに使用します。 「lightpanda」、「軽量ブラウザ」、「高速ヘッドレス ブラウザ」、「ヘッドレス スクレイピング」、「低メモリ ブラウザ」、「レンダリングなしのブラウザ」、「lightpanda は chromium より速いですか」、「どのヘッドレス ブラウザがより少ないメモリを使用するか」、「chromium を使用せずにスクレイピングするにはどうすればよいですか」、または視覚的な忠実度よりも速度とリソース効率が重要なブラウザ自動化タスクでトリガーされます。
