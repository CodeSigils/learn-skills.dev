Aktienanalyse in einem Satz – sagen Sie „XXX analysieren“, sammeln Sie automatisch Daten aus über 30 Quellen → KI erstellt einen vollständigen Bericht über Fundamentaldaten (Schritt 0–8) + technische Daten + Kapitalfluss → generiert einen interaktiven HTML-Bericht. Unterstützt inkrementelle Aktualisierungen (automatische Aktualisierung von K-Line-/Markt-/technischen Indikatoren). Auslösewörter: „XXX-Bestand analysieren“ (erstmals) oder „XXX-Bestand aktualisieren“ (inkrementell).
