Trasforma le idee di codifica in progetti approvati e brief di implementazione pronti per la pianificazione prima dell'inizio della codifica. Utilizzare per nuove funzionalità, modifiche significative del comportamento, richieste di implementazione ambigue, refactoring che modificano la forma del sistema o discussioni iniziali sull'architettura e sulla progettazione. Non utilizzare per piccole modifiche evidenti, correzioni di errori di battitura isolati, controlli null banali o altre semplici correzioni di bug che non richiedono lavoro di progettazione.
