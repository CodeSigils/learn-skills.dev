Превратите идеи кодирования в утвержденные проекты и готовые к планированию описания реализации еще до начала кодирования. Используйте для новых функций, значимых изменений поведения, неоднозначных запросов на реализацию, рефакторингов, которые меняют форму системы, или ранних обсуждений архитектуры и дизайна. Не используйте для небольших очевидных изменений, отдельных исправлений опечаток, тривиальных проверок на ноль или других простых исправлений ошибок, которые не требуют дизайнерской работы.
