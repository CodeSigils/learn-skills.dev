قم بتحويل أفكار البرمجة إلى تصميمات معتمدة وملخصات تنفيذ جاهزة للتخطيط قبل بدء البرمجة. يُستخدم للميزات الجديدة، أو التغييرات السلوكية ذات المغزى، أو طلبات التنفيذ الغامضة، أو إعادة البناء التي تغير شكل النظام، أو مناقشات التصميم والهندسة المعمارية المبكرة. لا تستخدمه لإجراء تعديلات بسيطة وواضحة، أو إصلاحات أخطاء مطبعية معزولة، أو عمليات فحص فارغة تافهة، أو غيرها من إصلاحات الأخطاء المباشرة التي لا تحتاج إلى أعمال تصميم.
