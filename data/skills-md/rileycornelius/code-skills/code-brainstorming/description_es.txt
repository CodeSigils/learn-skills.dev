Convierta las ideas de codificación en diseños aprobados y resúmenes de implementación listos para la planificación antes de que comience la codificación. Úselo para nuevas funciones, cambios de comportamiento significativos, solicitudes de implementación ambiguas, refactorizaciones que cambian la forma del sistema o discusiones iniciales sobre arquitectura y diseño. No lo utilice para pequeñas ediciones obvias, correcciones de errores tipográficos aislados, comprobaciones triviales de nulos u otras correcciones de errores sencillas que no necesitan trabajo de diseño.
