Домашний стиль Спенсера для пользовательского интерфейса. НЕ ПРИЗЫВАЙТЕ ЭТОТ НАВЫК, ЕСЛИ СПЕЦИАЛЬНО НЕ ПРОСИЛИ. Используйте всякий раз, когда Спенсер запрашивает интерфейс, страницу, экран, компонент, панель мониторинга, оболочку приложения, модальное окно, форму, таблицу или любой веб-визуальный элемент, включая такие фразы, как «создать пользовательский интерфейс для X», «собрать экран», «создать панель мониторинга», «Мне нужно быстрое приложение». Также используйте при запуске нового проекта React с нуля на этом компьютере. Отменяет любые общие навыки «дизайна внешнего интерфейса»: Спенсеру не нравится стандартная эстетика блестящего искусственного интеллекта, и он хочет, чтобы пользовательские интерфейсы с системными шрифтами были четкими, нейтральными, плотными и выглядели как приложения для комплексной проверки и проверки безопасности. Если Спенсер редактирует существующий репозиторий с явно другим стеком (например, Next.js с уже подключенным shadcn), следуйте соглашениям этого репозитория, но все же примените настройки Спенсера по типографике, плотности и тону из этого навыка.
