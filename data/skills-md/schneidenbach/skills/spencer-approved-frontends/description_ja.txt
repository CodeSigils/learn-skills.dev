UI のスペンサー ハウス スタイル。特に求められない限り、このスキルを発動しないでください。 Spencer がフロントエンド、ページ、画面、コンポーネント、ダッシュボード、アプリ シェル、モーダル、フォーム、テーブル、またはあらゆる種類の Web ビジュアルを要求するときは常に使用します。これには、「X 用の UI を構築する」、「画面を一緒に投げる」、「ダッシュボードを作成する」、「簡単なアプリが必要です」などの表現が含まれます。このマシン上でまったく新しい React プロジェクトを最初から開始する場合にも使用します。一般的な「フロントエンド デザイン」スキルをオーバーライドします。スペンサーは、デフォルトの光沢のある AI の美学を嫌い、デューデリジェンス アプリやセキュリティ レビュー アプリのように見える、タイトで中立的で緻密なシステム フォント UI を望んでいます。スペンサーが明らかに異なるスタックを使用して既存のリポジトリを編集している場合 (例: shadcn がすでに接続されている Next.js)、そのリポジトリの規則に従いますが、このスキルによるスペンサーのタイポグラフィ、密度、トーンの設定は引き続き適用されます。
