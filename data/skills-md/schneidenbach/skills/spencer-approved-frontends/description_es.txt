El estilo de la casa de Spencer para las UI. NO INVOQUE ESTA HABILIDAD A MENOS QUE SE LO PIDA ESPECÍFICAMENTE. Úselo siempre que Spencer solicite una interfaz, una página, una pantalla, un componente, un panel, un shell de aplicación, un modal, un formulario, una tabla o cualquier tipo de elemento visual web, incluidas frases como "crear una interfaz de usuario para X", "crear una pantalla", "crear un panel", "Necesito una aplicación rápida". Úselo también al iniciar un proyecto React nuevo desde cero en esta máquina. Anula cualquier habilidad general de "diseño de interfaz": a Spencer no le gusta la estética de IA brillante predeterminada y quiere interfaces de usuario de fuentes de sistema ajustadas, neutrales y densas que se parezcan a las aplicaciones de revisión de seguridad y diligencia debida. Si Spencer está editando un repositorio existente con una pila claramente diferente (por ejemplo, Next.js con shadcn ya conectado), siga las convenciones de ese repositorio, pero aún aplique las preferencias de tipografía, densidad y tono de Spencer de esta habilidad.
