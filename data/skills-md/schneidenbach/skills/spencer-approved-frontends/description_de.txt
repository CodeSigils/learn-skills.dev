Spencers Hausstil für Benutzeroberflächen. FÜHREN SIE DIESE FÄHIGKEIT NICHT AN, ES SEI DENN, SIE SIND AUSDRÜCKLICH GEFRAGT. Verwenden Sie es immer dann, wenn Spencer nach einem Frontend, einer Seite, einem Bildschirm, einer Komponente, einem Dashboard, einer App-Shell, einem Modal, einem Formular, einer Tabelle oder einer beliebigen Art von Webvisual fragt – einschließlich Formulierungen wie „Erstellen Sie eine Benutzeroberfläche für X“, „Schaffe einen Bildschirm zusammen“, „Erstelle ein Dashboard“, „Ich brauche eine schnelle App“. Verwenden Sie diese Funktion auch, wenn Sie auf diesem Computer ein brandneues React-Projekt von Grund auf starten. Setzt alle allgemeinen „Frontend-Design“-Fähigkeiten außer Kraft: Spencer mag die standardmäßige glänzende KI-Ästhetik nicht und möchte straffe, neutrale, dichte Benutzeroberflächen mit Systemschriftarten, die wie die Due-Diligence- und Sicherheitsüberprüfungs-Apps aussehen. Wenn Spencer ein vorhandenes Repo mit einem deutlich anderen Stack bearbeitet (z. B. Next.js mit bereits verkabeltem Shadcn), befolgen Sie die Konventionen dieses Repos, wenden Sie jedoch weiterhin Spencers Typografie-, Dichte- und Tonpräferenzen aus diesem Skill an.
