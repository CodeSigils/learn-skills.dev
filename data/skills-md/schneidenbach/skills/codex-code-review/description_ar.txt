قم بمراجعة تغييرات التعليمات البرمجية بحثًا عن الأخطاء ومشكلات الأمان وجودة التعليمات البرمجية باستخدام OpenAI Codex CLI كمراجع عدائي خارجي. استخدم من أي وكيل أو مزود عندما يطلب المستخدم مراجعة التعليمات البرمجية، أو يريد التحقق من التعليمات البرمجية بحثًا عن أخطاء أو مشكلات أمنية، أو يطلب مراجعة العلاقات العامة أو الفرع أو الالتزام أو الاختلاف، أو يقول أشياء مثل "هل هناك مشكلات في هذا؟"، أو "المراجعة قبل الدفع"، أو "التحقق من تغييراتي"، أو "انظر إلى ما قمت بتغييره"، أو "مراجعة العلاقات العامة الخاصة بي". أخبر Codex بمكان العثور على الرمز.
