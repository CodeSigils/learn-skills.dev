Revise los cambios de código en busca de errores, problemas de seguridad y calidad del código utilizando Claude Code CLI como revisor adversario externo. Úselo por parte de cualquier agente o proveedor cuando el usuario solicita una revisión del código, desea verificar el código en busca de errores o problemas de seguridad, solicita revisar un PR, una rama, una confirmación o una diferencia, o dice cosas como "¿algún problema con esto?", "revisar antes de presionar", "verificar mis cambios", "ver lo que cambié" o "revisar mi PR". Dile a Claude dónde encontrar el código.
