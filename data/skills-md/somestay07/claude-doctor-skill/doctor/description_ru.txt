Аудит любого проекта на предмет безопасности, тестового покрытия и автоматизации Claude Code.
46 проверок на 6 уровнях: секреты, CLAUDE.md, хуки, навыки, агенты, правила, MCP, CI, память.
Адаптивная оценка — автоматически определяет зрелость проекта (Начальный/Растущий/Зрелый/Профессиональный).
Диагностирует пробелы, предписывает исправления для конкретного проекта, применяет их.

Использование:
  /doctor — полный аудит (все 6 слоев)
  /doctor fast — ТОП-3 приоритета + оценка (30 секунд)
  /doctor scan — только диагностика (без изменений)
  /doctor fix — прописать + применить исправления
  /doctor Layer <N> — уровень аудита (0-5)
  /doctorverify — проверка здоровья
