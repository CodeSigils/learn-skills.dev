통합 프로젝트 메모리 관리: 지식을 업데이트, 정리, 반영 및 유지합니다.
대화 검색, 중복 제거, 모순 감지,
단일 기술에 대한 신뢰도 점수 및 일관성 검사가 가능합니다.

사용법:
  /memory update [주제] — 대화 스캔, 학습 지속
  /memory prune [유형] — 중복, 모순, 오래된 항목 찾기
  /memory 반영 - 대화에서 초점을 맞춘 수정 캡처
  /memory status — 메모리 레이아웃, 크기, 상태 표시
