統合されたプロジェクト メモリ管理: 知識を更新、整理、反映、維持します。
会話スキャン、重複排除、矛盾検出、
信頼度スコアリングと単一スキルの一貫性チェック。

使用法:
  /memory update [トピック] — 会話をスキャンし、学習を継続します
  /memory prune [type] — 重複、矛盾、古いエントリを検索します
  /memory Reflect — 会話からの集中的な修正キャプチャ
  /memory status — メモリのレイアウト、サイズ、状態を表示します
