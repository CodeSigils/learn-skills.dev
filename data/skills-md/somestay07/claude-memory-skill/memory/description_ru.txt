Унифицированное управление памятью проектов: обновление, сокращение, отражение и поддержание знаний.
Сочетает в себе сканирование разговоров, дедупликацию, обнаружение противоречий.
оценка уверенности и проверка последовательности в одном навыке.

Использование:
  /memory update [тема] — сканировать разговор, сохранять знания
  /memory prune [тип] — найти дубликаты, противоречия, устаревшие записи
  /memory Reflection — запись целенаправленной коррекции из разговора
  /memory status — показать структуру памяти, размеры, состояние

Триггеры: «/memory», «обновить память», «очистить память»,
«запомнить это», «обновить память», «обрезать память», «состояние памяти»
