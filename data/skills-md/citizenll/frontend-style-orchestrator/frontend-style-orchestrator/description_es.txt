Transforme las indicaciones de estilo visual proporcionadas por el usuario en diseño de página web front-end o rediseñe implementaciones a través de un proceso repetible (extracción de estilo, contrato de diseño, sistema de tokens, implementación y control de calidad). Úselo cuando el usuario solicite crear una página web con un estilo específico, refactorizar una página existente con un estilo nuevo o iterar a través de múltiples direcciones de estilo en rondas.
