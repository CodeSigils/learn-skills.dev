Trasforma le richieste di stile visivo fornite dall'utente nella progettazione di pagine Web frontend o in implementazioni di riprogettazione attraverso una pipeline ripetibile (estrazione di stile, contratto di progettazione, sistema di token, implementazione e QA). Da utilizzare quando l'utente chiede di creare una pagina Web in uno stile specifico, eseguire il refactoring di una pagina esistente in un nuovo stile o ripetere più direzioni di stile nei round.
