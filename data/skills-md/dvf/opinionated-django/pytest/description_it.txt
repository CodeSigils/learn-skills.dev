Configura e scrivi test pytest per un progetto op-django: configurazione pytest-django, modalità Celery per test di segnali affidabili, freezegun per logica sensibile al tempo, dispositivi di conftest condivisi per DTO e sostituzioni svcs e convenzione di test a tre livelli (repository contro un DB reale, servizio contro repository derisi, API tramite HTTP). Da utilizzare quando si aggiungono test a un nuovo progetto, si scrivono test per una nuova funzionalità, si configura l'infrastruttura di test o si spiega come dovrebbero essere organizzati i test.
