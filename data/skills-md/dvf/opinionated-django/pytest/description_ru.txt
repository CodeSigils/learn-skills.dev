Настройте и напишите тесты pytest для проекта op-django — конфигурация pytest-django, режим Celery нетерпеливого для тестов надежных сигналов, фризерган для логики, чувствительной ко времени, общие приспособления conftest для переопределений DTO и svcs, а также трехуровневое соглашение о тестировании (репозиторий для реальной БД, сервис для имитации репозиториев, API через HTTP). Используйте при добавлении тестов в новый проект, написании тестов для новой функции, настройке тестовой инфраструктуры или объяснении того, как следует организовывать тесты.
