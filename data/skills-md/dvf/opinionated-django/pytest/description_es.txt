Configure y escriba pruebas de pytest para un proyecto op-django: configuración de pytest-django, modo Celery ansioso para pruebas de señales confiables, congelación para lógica sensible al tiempo, accesorios de prueba compartidos para anulaciones de DTO y svcs, y la convención de prueba de tres capas (repositorio contra una base de datos real, servicio contra repositorios simulados, API a través de HTTP). Úselo al agregar pruebas a un nuevo proyecto, escribir pruebas para una nueva característica, configurar la infraestructura de pruebas o explicar cómo se deben organizar las pruebas.
