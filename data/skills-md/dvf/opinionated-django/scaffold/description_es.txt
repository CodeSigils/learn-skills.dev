Configure un proyecto Django en el diseño de op-django para que las habilidades de arquitectura, señales y configuración tengan una base sobre la cual construir. Úselo al iniciar un nuevo proyecto desde cero o al convertir un proyecto Django existente para seguir esta estructura obstinada. Crea el src/project/shell (ids, registro de servicios, api, señales confiables), instala dependencias con uv y establece las convenciones de directorio por aplicación.
