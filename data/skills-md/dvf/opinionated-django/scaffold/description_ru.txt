Настройте проект Django в макете op-django, чтобы навыки архитектуры, сигналов и настроек имели основу для дальнейшего развития. Используйте при запуске нового проекта с нуля или при преобразовании существующего проекта Django в соответствии с этой продуманной структурой. Создает оболочку src/project/ (идентификаторы, реестр служб, API, надежные сигналы), устанавливает зависимости с помощью uv и устанавливает соглашения о каталогах для каждого приложения.
