Erstellen Sie ausgefeilte, eigenständige HTML-Folienpräsentationen – kein PowerPoint oder Keynote erforderlich. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer nach einer Präsentation, einem Dia-Deck, Folien oder einem One-Pager fragt, die in einem Browser angezeigt werden. Wird auch ausgelöst, wenn der Benutzer Dinge sagt wie „Machen Sie daraus ein Deck“, „Machen Sie daraus Folien“, „Erstellen Sie eine Präsentation aus diesem Inhalt“ oder „Ich brauche etwas zum Präsentieren“. Bevorzugen Sie dies gegenüber PPTX, wenn der Benutzer nicht ausdrücklich nach einer .pptx-Datei gefragt hat – HTML-Decks sind flexibler, optisch ansprechender und einfacher zu iterieren. Verwenden Sie diese Fähigkeit immer, wenn der Benutzer neben einer Präsentationsanfrage einen Marken-Styleguide (PDF, URL oder Beschreibung) bereitstellt. Lösen Sie es aus, auch wenn der Benutzer ohne weitere Details nur „Mach mir ein Deck“ sagt – beginnen Sie mit inhaltlichen Fragen.
