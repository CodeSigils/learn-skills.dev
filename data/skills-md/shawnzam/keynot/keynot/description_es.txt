Cree presentaciones de diapositivas HTML pulidas e independientes, sin necesidad de PowerPoint ni Keynote. Utilice esta habilidad siempre que el usuario solicite una presentación, un conjunto de diapositivas, diapositivas o un paginador que se mostrará en un navegador. También se activa cuando el usuario dice cosas como "conviértalo en una presentación", "convierta esto en diapositivas", "cree una presentación a partir de este contenido" o "Necesito algo para presentar". Prefiera esto a PPTX cuando el usuario no haya solicitado explícitamente un archivo .pptx: las presentaciones HTML son más flexibles, más ricas visualmente y más fáciles de iterar. Utilice siempre esta habilidad cuando el usuario proporcione una guía de estilo de marca (PDF, URL o descripción) junto con una solicitud de presentación. Activa incluso si el usuario solo dice "hazme un mazo" sin más detalles; comienza con preguntas de contenido.
