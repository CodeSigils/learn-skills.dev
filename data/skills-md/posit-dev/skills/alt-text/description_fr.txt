Générez et améliorez le texte alternatif accessible pour les visualisations de données et les images dans les packages R et les documents Quarto. À utiliser lorsque l'utilisateur souhaite ajouter, améliorer ou auditer le texte alternatif des figures d'un site pkgdown ou de fichiers .qmd. Activez pour les demandes qui mentionnent fig-alt, fig.alt, des descriptions de figures ou du texte alt dans le contexte d'un package R ou d'un document Quarto.
