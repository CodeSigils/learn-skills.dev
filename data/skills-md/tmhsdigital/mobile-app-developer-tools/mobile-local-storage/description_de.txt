Speichern Sie Daten lokal in einer React Native/Expo-App. Behandelt AsyncStorage für Schlüsselwerte, expo-sqlite für relationale Daten, expo-secure-store für sensible Token und React-native-mmkv für schnelle synchrone Lesevorgänge. Verwenden Sie diese Option, wenn der Benutzer Daten auf dem Gerät speichern muss.
