Используйте при создании или изменении веб-интерфейсов с помощью системы дизайна Vireya (@vireya/core, @vireya/ui, @vireya/next, @vireya/blocks). Охватывает рекомендации по проектированию (иерархия цветов, основной и акцентный ритм, типографский ритм, пространственная лестница, иерархия радиусов, философия высоты, бюджет движения, государственные контракты, решения о сочетании компонентов, такие как Dialog vs Sheet vs Popover), карта пакетов, импорт подпутей для каждого компонента, обязательные правила токенов --v-*, соглашения модуля frontRef + asChild + CSS, настройка Next.js (ThemeProvider + AppProvider с локалью + значками) и плоский каталог из 67 компонентов и 26 блоков. Запускайте при упоминании «vireya», «@vireya/*», создании целевых страниц или информационных панелей с помощью Vireya, проектировании с использованием токенов Vireya, выборе между компонентами Vireya или создании компонентов Vireya.
