يُستخدم عند إنشاء واجهات مستخدم الويب أو تعديلها باستخدام نظام Vireya Design System (@vireya/core، @vireya/ui، @vireya/next، @vireya/blocks). يغطي إرشادات التصميم (التسلسل الهرمي للألوان، الأساسي مقابل اللكنة، إيقاع الطباعة، سلم التباعد، التسلسل الهرمي لنصف القطر، فلسفة الارتفاع، ميزانية الحركة، عقود الحالة، قرارات اقتران المكونات مثل Dialog vs Sheet vs Popover)، خريطة الحزمة، واردات المسار الفرعي لكل مكون، قواعد الرموز المميزة الإلزامية --v-*، اصطلاحات وحدة ForwardRef + asChild + CSS، إعداد Next.js (ThemeProvider + AppProvider مع الإعدادات المحلية + أيقونات)، وكتالوج مسطح يضم 67 مكونًا و26 قطعة. قم بتشغيل الإشارات إلى "vireya"، "@vireya/*"، أو إنشاء صفحات مقصودة أو لوحات معلومات باستخدام Vireya، أو التصميم باستخدام رموز Vireya، أو الاختيار بين مكونات Vireya، أو إنشاء مكونات Vireya.
