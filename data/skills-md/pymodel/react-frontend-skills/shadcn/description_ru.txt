Текущее руководство по компонентам shadcn/ui для проектов, созданных с помощью пользовательского интерфейса Radix или базового пользовательского интерфейса, включая композицию для конкретных примитивов, темы Tailwind CSS v4, специальные возможности, формы, таблицы и шаблоны состояний. Проверьте реализацию возвращенного компонента перед применением API-интерфейсов рендеринга Radix asChild или Base UI.
