React‑Feature‑basierte Architekturrichtlinien für skalierbare Anwendungen (vormals Feature‑Architektur). Diese Richtlinie sollte beim Schreiben, Überprüfen oder Refaktorisieren von React‑Code verwendet werden, um eine ordnungsgemäße Feature‑Organisation sicherzustellen. Auslöser bei Aufgaben, die die Projektstruktur, Feature‑Organisation, Modulgrenzen, bereichsübergreifende Importe, Datenabrufmuster oder die Komponenten­zusammensetzung betreffen.
