Pautas de arquitectura basada en características para aplicaciones escalables en React (anteriormente arquitectura de características). Esta habilidad debe usarse al escribir, revisar o refactorizar código React para garantizar una organización adecuada de las características. Se activa en tareas que implican la estructura del proyecto, la organización de características, los límites de los módulos, importaciones entre características, patrones de obtención de datos o composición de componentes.
