Best practice per i test con Playwright per le applicazioni Next.js (precedentemente test-playwright). Questa competenza dovrebbe essere utilizzata quando si scrivono, revisionano o eseguono il debug di test E2E con Playwright. Si attiva per attività che coinvolgono selettori di test, test instabili, stato di autenticazione, mocking delle API, test di idratazione, esecuzione parallela, configurazione CI o debug dei fallimenti dei test.

Per favore rispondi sempre nella lingua dell'utente.
