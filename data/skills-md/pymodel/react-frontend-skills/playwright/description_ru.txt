Лучшие практики тестирования Playwright для приложений Next.js (ранее test‑playwright). Этот навык следует использовать при написании, ревью или отладке E2E‑тестов с Playwright. Срабатывает при задачах, связанных с селекторами тестов, нестабильными тестами, состоянием аутентификации, мокированием API, тестированием гидратации, параллельным выполнением, настройкой CI или отладкой сбоев тестов.
