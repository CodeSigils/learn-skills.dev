Linee guida per l'ottimizzazione delle prestazioni e le migliori pratiche di Tailwind CSS v4 (precedentemente tailwindcss-v4-style). Questa competenza dovrebbe essere utilizzata durante la scrittura, la revisione o il refactoring del codice Tailwind CSS v4 per garantire prestazioni di build ottimali, un output CSS minimo e un uso corretto delle funzionalità v4. Si attiva su attività che coinvolgono la configurazione di Tailwind, la direttiva @theme, le classi utility, il design responsivo, la modalità scura, le query di contenitore o l'ottimizzazione della generazione di CSS.

Rispondi sempre nella lingua dell'utente.
