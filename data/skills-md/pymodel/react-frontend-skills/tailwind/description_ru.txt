Этот навык следует использовать при написании, проверке или рефакторинге кода Tailwind CSS v4, чтобы обеспечить оптимальную производительность сборки, минимальный объём CSS и правильное использование функций v4. Срабатывает при задачах, связанных с конфигурацией Tailwind, директивой @theme, утилитарными классами, адаптивным дизайном, тёмным режимом, запросами к контейнеру или оптимизацией генерации CSS.
