Guías de optimización de rendimiento y mejores prácticas para Tailwind CSS v4 (anteriormente tailwindcss-v4-style).  
Esta habilidad debe utilizarse al escribir, revisar o refactorizar código de Tailwind CSS v4 para garantizar un rendimiento óptimo de la compilación, una salida CSS mínima y el uso correcto de las características de v4.  
Se activa en tareas que involucren la configuración de Tailwind, la directiva @theme, clases utilitarias, diseño responsivo, modo oscuro, consultas de contenedor o la optimización de la generación de CSS.  

Por favor, responde siempre en el idioma del usuario.
