أفضل الممارسات لـ nuqs (حالة استعلام URL الآمنة من النوع) لتطبيقات Next.js. يجب استخدام هذه المهارة عند كتابة أو مراجعة أو إعادة هيكلة الكود الذي يستخدم nuqs لإدارة حالة URL. تُثار عند المهام التي تتضمن useQueryState، useQueryStates، معلمات البحث، حالة URL، معلمات الاستعلام، محللات nuqs، أو توجيه Next.js مع الحالة. يرجى دائمًا الرد بلغة المستخدم.
