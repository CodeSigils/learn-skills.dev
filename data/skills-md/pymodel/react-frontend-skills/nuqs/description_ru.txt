nuqs (типобезопасное состояние URL‑запроса) — лучшие практики для приложений Next.js. Этот навык следует использовать при написании, обзоре или рефакторинге кода, использующего nuqs для управления состоянием URL. Срабатывает при задачах, связанных с useQueryState, useQueryStates, параметрами поиска, состоянием URL, параметрами запроса, парсерами nuqs или маршрутизацией Next.js с состоянием.
