Metodología de Desarrollo Guiado por Pruebas y flujo de trabajo rojo‑verde‑refactor (antes test‑tdd). Esta habilidad debe usarse al practicar TDD, escribir pruebas primero, diseñar pruebas antes de la implementación o revisar enfoques de prueba‑primer. Se activa con “escribir pruebas primero”, “prueba antes del código”, “rojo verde refactor”, “desarrollo guiado por pruebas”. Esta habilidad NO cubre aspectos específicos del framework Vitest (use la habilidad vitest) ni el simulacro de API con MSW (use la habilidad msw).
