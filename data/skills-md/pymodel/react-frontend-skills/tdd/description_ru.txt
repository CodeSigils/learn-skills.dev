Методология разработки через тестирование (Test‑Driven Development) и рабочий процесс red‑green‑refactor (ранее test‑tdd). Этот навык следует использовать при практиковании TDD, написании тестов в первую очередь, проектировании тестов до реализации или обзоре подходов test‑first. Срабатывает по запросам «write tests first», «test before code», «red green refactor», «test driven development». Этот навык НЕ охватывает специфические детали фреймворка Vitest (используйте навык vitest) или имитацию API с помощью MSW (используйте навык msw).
