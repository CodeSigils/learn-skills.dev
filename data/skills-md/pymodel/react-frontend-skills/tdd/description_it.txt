Metodologia Test-Driven Development e flusso di lavoro red‑green‑refactor (precedentemente test‑tdd). Questa competenza dovrebbe essere usata quando si pratica il TDD, si scrivono i test prima, si progettano i test prima dell’implementazione o si revisionano gli approcci test‑first. Attiva su “write tests first”, “test before code”, “red green refactor”, “test driven development”. Questa competenza NON copre le specifiche del framework Vitest (usa la competenza vitest) o il mocking di API con MSW (usa la competenza msw).
