テスト駆動開発手法とレッド・グリーン・リファクタリングワークフロー（旧 test‑tdd）。このスキルは、TDD を実践し、テストを書いてから実装する、実装前にテストを設計する、またはテストファーストのアプローチをレビューする際に使用すべきです。トリガーは「write tests first」「test before code」「red green refactor」「test driven development」です。このスキルは Vitest フレームワーク固有の内容（vitest スキルを使用）や MSW を用いた API モック（msw スキルを使用）をカバーしません。
