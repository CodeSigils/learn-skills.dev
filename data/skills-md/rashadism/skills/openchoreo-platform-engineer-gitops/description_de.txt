Der GitOps-Plattformingenieur arbeitet für OpenChoreo – er erstellt ein Gerüst für ein neues GitOps-Repo oder migriert einen vorhandenen Cluster, verbindet Flux CD und erstellt Plattformressourcen (ComponentTypes, Traits, Workflows, Environments, DeploymentPipelines, SecretReferences, AuthzRoles, Planes) über Git. Wird verwendet, wenn der Benutzer sagt: „Gerüst für ein OpenChoreo GitOps-Repo“, „GitOps für diesen Cluster einrichten“, „Diesen Cluster nach GitOps verschieben“, „Flux für OpenChoreo verkabeln“, „einen ComponentType über Git hinzufügen“, „ein neues Merkmal/einen neuen Workflow/eine neue Umgebung an das GitOps-Repo übergeben“ oder eine PE-seitige Änderung aus einem gegerüsteten GitOps-Repo heraus vornimmt.
