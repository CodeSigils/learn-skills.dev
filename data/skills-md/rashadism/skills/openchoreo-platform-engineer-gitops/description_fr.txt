L'ingénieur de plate-forme GitOps travaille pour OpenChoreo : échafaudage d'un nouveau dépôt GitOps ou migration d'un cluster existant, câblage de Flux CD et création de ressources de plate-forme (ComponentTypes, Traits, Workflows, Environments, DeploymentPipelines, SecretReferences, AuthzRoles, plans) via Git. À utiliser lorsque l'utilisateur dit « échafauder un dépôt OpenChoreo GitOps », « configurer GitOps pour ce cluster », « déplacer ce cluster vers GitOps », « câbler Flux pour OpenChoreo », « ajouter un ComponentType via Git », « valider un nouveau trait/workflow/environnement dans le dépôt GitOps » ou opère un changement côté PE depuis l'intérieur d'un dépôt GitOps échafaudé.
