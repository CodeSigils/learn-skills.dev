Инженер платформы GitOps работает для OpenChoreo — создает новый репозиторий GitOps или переносит существующий кластер, подключает компакт-диск Flux и создает ресурсы платформы (ComponentTypes, Traits, Workflows, Environments, DeploymentPipelines, SecretReferences, AuthzRoles, planes) через Git. Используйте, когда пользователь говорит: «собрать репозиторий OpenChoreo GitOps», «настроить GitOps для этого кластера», «переместить этот кластер в GitOps», «подключить Flux для OpenChoreo», «добавить ComponentType через Git», «зафиксировать новый признак/рабочий процесс/среду в репозитории GitOps» или выполнить изменение на стороне PE изнутри созданного репозитория GitOps.
