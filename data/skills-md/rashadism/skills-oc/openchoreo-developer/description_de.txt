Verwenden Sie es immer dann, wenn es bei der Aufgabe darum geht, mit einer Anwendung auf OpenChoreo zu arbeiten: Bereitstellen, Aktualisieren, Debuggen, Erklären von Ressourcen oder Schreiben von YAML für die Anwendung über die OpenChoreo MCP-Server. Aktivieren Sie „openchoreo-platform-engineer“ auch, wenn die Aufgabe Plattformressourcen (DataPlane, ComponentType, Trait, Workflow), Cluster-seitiges Debuggen, Zugriff auf Clusterebene, hartes Löschen einer Ressource oder einen Vorgang ohne MCP-Schreiboberfläche (SecretReference-Erstellung, Component-Trait-Anhang) benötigt.
