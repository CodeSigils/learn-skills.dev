Da utilizzare ogni volta che l'attività riguarda l'utilizzo di un'applicazione su OpenChoreo: distribuzione, aggiornamento, debug, spiegazione delle risorse o scrittura di file YAML rivolti all'app tramite i server MCP OpenChoreo. Attiva anche `openchoreo-platform-engineer` quando l'attività necessita di risorse della piattaforma (DataPlane, ComponentType, Trait, Workflow), debugging lato cluster, qualsiasi accesso a livello di cluster, eliminazione definitiva di qualsiasi risorsa o un'operazione senza superficie di scrittura MCP (creazione di SecretReference, collegamento di trait del componente).
