À utiliser lors de la migration d'un projet React Native vers l'API Strict TypeScript — l'API JavaScript par défaut de React Native 0.87, disponible en aperçu opt-in depuis la 0.80. Gère la configuration de tsconfig.json, les mises à jour des dépendances, la réécriture des importations profondes vers les importations racine et la résolution des modifications de type de rupture. Invoquez avec `/migrate-to-strict-api`.
