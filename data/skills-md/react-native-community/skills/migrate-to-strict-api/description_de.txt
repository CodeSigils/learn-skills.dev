Verwenden Sie diese Option, wenn Sie ein React Native-Projekt zur Strict TypeScript API migrieren – der Standard-JavaScript-API von React Native 0.87, die seit 0.80 als Opt-in-Vorschau verfügbar ist. Behandelt die Einrichtung von tsconfig.json, Aktualisierungen von Abhängigkeiten, das Umschreiben von Deep-Importen in Root-Importe und das Auflösen von Breaking-Type-Änderungen. Mit „/migrate-to-strict-api“ aufrufen.
