Da utilizzare durante la migrazione di un progetto React Native all'API Strict TypeScript: l'API JavaScript predefinita da React Native 0.87, disponibile come anteprima con attivazione a partire dalla versione 0.80. Gestisce la configurazione di tsconfig.json, gli aggiornamenti delle dipendenze, la riscrittura delle importazioni profonde in importazioni root e la risoluzione delle modifiche di tipo importanti. Invocare con "/migrate-to-strict-api".
