Используйте при переносе проекта React Native на Strict TypeScript API — API JavaScript по умолчанию из React Native 0.87, доступный в качестве предварительной версии по согласию с версии 0.80. Управляет настройкой tsconfig.json, обновлением зависимостей, перезаписью глубокого импорта в корневой импорт и устранением критических изменений типов. Вызовите с помощью `/migrate-to-strict-api`.
