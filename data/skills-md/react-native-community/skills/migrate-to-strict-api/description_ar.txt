يُستخدم عند ترحيل مشروع React Native إلى Strict TypeScript API — واجهة برمجة تطبيقات JavaScript الافتراضية من React Native 0.87، المتوفرة كمعاينة اختيارية منذ 0.80. يتعامل مع إعداد tsconfig.json، وتحديثات التبعية، وإعادة كتابة الواردات العميقة إلى الواردات الجذرية، وحل تغييرات النوع المعطلة. الاستدعاء باستخدام `/migrate-to-strict-api`.
