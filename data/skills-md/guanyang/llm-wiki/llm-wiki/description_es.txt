Utilice esta habilidad cuando el usuario quiera digerir notas o artículos en un wiki estructurado, hacer preguntas respondidas a partir de conocimientos compilados, comprobar el estado del wiki, producir entregables pulidos (publicaciones de blog, informes, diapositivas) o verificar si el contenido del wiki todavía está actualizado. Actívelo incluso si el usuario no dice "wiki": frases como "organice esto", "digerir este artículo", "búsqueme esto", "escriba una publicación de blog", "consulte la base de conocimientos", todas califican.
