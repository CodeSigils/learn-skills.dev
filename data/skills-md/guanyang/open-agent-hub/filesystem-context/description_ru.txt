Этот навык следует использовать, когда для работы агента требуется контекст, поддерживаемый файлами: надежные блокноты, разгрузка выходных данных инструментов, своевременное обнаружение, файлы передачи между агентами, память файловой системы или политики очистки для контекста, хранящегося вне командной строки.
