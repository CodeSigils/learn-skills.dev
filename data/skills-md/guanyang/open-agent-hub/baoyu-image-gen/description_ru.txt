Генерация изображений ИИ с помощью API OpenAI GPT Image 2, Azure OpenAI, Google, OpenRouter, DashScope, Z.AI GLM-Image, MiniMax, Jimeng, Seedream, Replication и Agnes API. Поддерживает преобразование текста в изображение, эталонные изображения, соотношения сторон и пакетную генерацию из сохраненных файлов подсказок. Последовательный по умолчанию; используйте пакетную параллельную генерацию, когда у пользователя уже есть несколько запросов или ему нужна стабильная пропускная способность нескольких изображений. Используйте, когда пользователь просит сгенерировать, создать или нарисовать изображения.
