Web とモバイル向けの UI/UX デザイン インテリジェンス。 10 スタック (React、Next.js、Vue、Svelte、SwiftUI、React Native、Flutter、Tailwind、shadcn/ui、HTML/CSS) にわたる 50 を超えるスタイル、161 のカラー パレット、57 のフォント ペア、161 の製品タイプ、99 の UX ガイドライン、および 25 のグラフ タイプが含まれます。アクション: UI/UX コードの計画、構築、作成、設計、実装、レビュー、修正、改善、最適化、強化、リファクタリング、およびチェック。プロジェクト: Web サイト、ランディング ページ、ダッシュボード、管理パネル、e コマース、SaaS、ポートフォリオ、ブログ、モバイル アプリ。要素: ボタン、モーダル、ナビゲーションバー、サイドバー、カード、テーブル、フォーム、グラフ。スタイル: グラスモーフィズム、クレイモーフィズム、ミニマリズム、ブルータリズム、ニューモーフィズム、ベント グリッド、ダーク モード、レスポンシブ、スキューモーフィズム、フラット デザイン。トピック: カラー システム、アクセシビリティ、アニメーション、レイアウト、タイポグラフィ、フォント ペアリング、間隔、インタラクション状態、シャドウ、グラデーション。統合: コンポーネントの検索と例用の shadcn/ui MCP。
