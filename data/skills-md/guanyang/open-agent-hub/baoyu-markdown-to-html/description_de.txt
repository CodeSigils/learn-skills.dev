Konvertiert Markdown in gestaltetes HTML mit WeChat-kompatiblen Themes. Unterstützt Code-Hervorhebung, Mathematik, Mermaid (über Headless Chrome in PNG gerendert), PlantUML, Fußnoten, Warnungen, Infografiken und optionale Zitate unten für externe Links. Verwenden Sie diese Option, wenn der Benutzer nach „Markdown in HTML“, „MD in HTML konvertieren“, „md 转 html“ oder „微信外链转底部引用“ fragt oder eine gestaltete HTML-Ausgabe von Markdown benötigt.
