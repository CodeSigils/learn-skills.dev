يحول Markdown إلى تنسيق HTML مع سمات متوافقة مع WeChat. يدعم تمييز التعليمات البرمجية، والرياضيات، وحورية البحر (التي يتم تقديمها إلى PNG عبر Chrome بدون رأس)، وPlantUML، والحواشي السفلية، والتنبيهات، والرسوم البيانية، والاستشهادات السفلية الاختيارية للروابط الخارجية. يُستخدم عندما يطلب المستخدم "تخفيض السعر إلى html"، أو "تحويل md إلى html"، أو "md 转 html"، أو "التخفيض إلى html"، أو يحتاج إلى إخراج HTML مُصمم من تخفيض السعر.
