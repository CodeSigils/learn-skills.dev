Этот навык следует использовать для объяснения или рассуждения об основных концепциях контекстной инженерии: что такое контекст, анатомия контекстного окна, как работает механика внимания, U-образная кривая внимания, почему качество контекста важнее количества, а также ментальные модели, необходимые для интерпретации любого другого решения контекстной инженерии. Используйте это для концептуального объяснения, ознакомления и базового чтения. Направьте операционную работу на специализированные навыки: отладка ошибок внимания переходит к ухудшению контекста, работа по повышению эффективности токенов — к оптимизации контекста, обобщение разговоров — к сжатию контекста, а решения по форме проекта — к разработке проекта.
