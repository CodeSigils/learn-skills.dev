Extrait les ressources et le JavaScript de toute application Electron installée (bundle `.asar`), restaure les sources originales à partir des fichiers `.js.map` lorsqu'ils sont disponibles ou formate le code minifié avec Prettier dans le cas contraire. À utiliser lorsque l'utilisateur souhaite « extraire l'application Electron », « décompiler Electron », « obtenir le code source de <app> », « inspecter app.asar », « 看 Electron 应用源码 », « 提取 .asar » ou demande comment une application de bureau Electron est créée. Ignore `node_modules` et prend en charge à la fois macOS et Windows.
