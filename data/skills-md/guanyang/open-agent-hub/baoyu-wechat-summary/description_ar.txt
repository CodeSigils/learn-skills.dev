يلخص أبرز أحداث دردشة WeChat الجماعية في ملخص منظم باستخدام ثنائي wx-cli المحلي (https://github.com/jackwener/wx-cli). يُنشئ ملخصًا عاديًا بشكل افتراضي؛ إصدار مشوي (毒舌) قابل للاشتراك. يحافظ على سجل كل مجموعة (history.json + History-digests.jsonl)، وملفات التعريف لكل مستخدم، وذاكرة الحقائق لكل مجموعة (memory.md) عبر عمليات التشغيل، مع وجود حواجز حماية للخصوصية. يُستخدم عندما يطلب المستخدم "总结群聊"، "群聊精华"، "群聊摘要"، "تلخيص الدردشة الجماعية"، "ملخص الدردشة الجماعية"، يذكر اسم مجموعة WeChat بنطاق زمني، ويقول "帮我看看 XX 群最近聊了什么" أو "XX 群有什么值得看的" أو يسأل "回溯画像" / "初始化画像" / "ملفات تعريف الردم". يضيف نسخة الشواء عندما يقول المستخدم "毒舌版" أو "مشوي 版" أو "再来个毒舌的" أو ما شابه.
