Обобщает основные моменты группового чата WeChat в структурированный дайджест с использованием локального двоичного файла wx-cli (https://github.com/jackwener/wx-cli). По умолчанию генерирует обычный дайджест; жареная версия (毒舌) является добровольной. Сохраняет историю каждой группы (history.json + History-digests.jsonl), профили каждого пользователя и память фактов для каждой группы (memory.md) во время запуска со встроенными средствами защиты конфиденциальности. Используйте, когда пользователь запрашивает «总结群聊», «群聊精华», «群聊摘要», «подведение итогов группового чата», «дайджест группового чата», упоминает имя группы WeChat с указанием временного диапазона, произносит «帮我看看 XX 群最近聊了什么», «XX 群有什么值得看的» или просит «回溯画像» / «初始化画像» / «заполнение профилей». Добавляет обжаренную версию, когда пользователь произносит «毒舌版», «жареное 版», «再来个毒舌的» или что-то подобное.
