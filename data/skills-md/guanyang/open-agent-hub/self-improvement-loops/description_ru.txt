Этот навык следует использовать, когда целью оптимизации является сама обвязка, каркас, рабочий процесс или оптимизатор: циклы рекурсивного самосовершенствования (RSI), мета-обвязки, самоулучшающиеся жгуты, которые обнаруживают свои собственные ошибки и предлагают ограниченные правки, эволюционный или популяционный поиск по каркасам агентов, приемные ворота для самомодифицирующихся систем и эволюция агентного контекста, где механизм, создающий контекст, версируется и развивается. Направьте управление единым автономным циклом (заблокированные поверхности, долговечные журналы, откат, шлюзы новизны, границы утверждения) для использования проектирования, измерения и проектирования шлюзов качества для оценки, оценки проекта для расширенной оценки и инфраструктуры удаленной изолированной программной среды для размещенных агентов.
