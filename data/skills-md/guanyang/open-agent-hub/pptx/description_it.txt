Utilizza questa abilità ogni volta che un file .pptx o .potx è coinvolto in qualsiasi modo: come input, output o entrambi. Ciò include: creazione di slide deck, pitch deck o presentazioni; leggere, analizzare o estrarre testo da qualsiasi file .pptx o .potx (anche se il contenuto estratto verrà utilizzato altrove, come in un'e-mail o in un riepilogo); modificare, modificare o aggiornare presentazioni esistenti; combinare o dividere file di diapositive; lavorare con modelli (.potx), layout, note del relatore o commenti. Si attiva ogni volta che l'utente menziona "composizione", "diapositive", "presentazione" o fa riferimento a un nome file .pptx o .potx, indipendentemente da cosa intende fare successivamente con il contenuto. Se è necessario aprire, creare o toccare un file .pptx o .potx, utilizza questa abilità.
