Questa competenza dovrebbe essere utilizzata specificamente per il livello di interfaccia degli strumenti di un sistema di agenti: scrivere descrizioni degli strumenti su cui gli agenti possono instradarsi, progettare schemi di strumenti e formati di risposta, convenzioni di denominazione, messaggi di ripristino degli errori utilizzabili, progettazione del server MCP, consolidamento del set di strumenti e decisione quando aggiungere o rimuovere un singolo strumento. Utilizzarlo quando l'unità di lavoro è un singolo strumento o un insieme di strumenti. Indirizzare le decisioni sulla forma del progetto, sull'architettura della pipeline e sull'adattamento del modello di attività allo sviluppo del progetto; percorso che decide se introdurre sub-agenti in modelli multi-agente.
