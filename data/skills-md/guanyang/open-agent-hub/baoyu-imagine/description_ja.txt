OpenAI GPT Image 2、Azure OpenAI、Google、OpenRouter、DashScope、Z.AI GLM-Image、MiniMax、Jimeng、Seedream、および Replicate API を使用した AI イメージの生成。テキストから画像への変換、参照画像、アスペクト比、および保存されたプロンプト ファイルからのバッチ生成をサポートします。デフォルトではシーケンシャルです。ユーザーがすでに複数のプロンプトを持っている場合、または安定した複数画像のスループットが必要な場合は、バッチ並列生成を使用します。ユーザーが画像の生成、作成、描画を要求する場合に使用します。
