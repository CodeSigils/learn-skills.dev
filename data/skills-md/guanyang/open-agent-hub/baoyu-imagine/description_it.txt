Generazione di immagini AI con OpenAI GPT Image 2, Azure OpenAI, Google, OpenRouter, DashScope, Z.AI GLM-Image, MiniMax, Jimeng, Seedream e API Replicate. Supporta la conversione da testo a immagine, immagini di riferimento, proporzioni e generazione batch da file di prompt salvati. Sequenziale per impostazione predefinita; utilizzare la generazione parallela batch quando l'utente dispone già di più richieste o desidera un throughput multi-immagine stabile. Da utilizzare quando l'utente chiede di generare, creare o disegnare immagini.
