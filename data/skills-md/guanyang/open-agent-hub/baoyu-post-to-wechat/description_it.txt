Pubblica contenuti sull'account ufficiale WeChat (微信公众号) tramite API o Chrome CDP. Supporta la pubblicazione di articoli (文章) con input HTML, markdown o testo semplice e la pubblicazione di testo-immagine (贴图, precedentemente 图文) con più immagini. Per impostazione predefinita, i flussi di lavoro degli articoli Markdown convertono i normali collegamenti esterni in citazioni finali per un output compatibile con WeChat. Da utilizzare quando l'utente menziona "发布公众号", "pubblica su wechat", "微信公众号" o "贴图/图文/文章".
