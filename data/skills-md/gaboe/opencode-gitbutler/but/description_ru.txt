Фиксируйте, отправляйте, разветвляйте и управляйте контролем версий. Используйте для git commit, git status, git push, git diff, создания ветвей, промежуточных файлов, истории редактирования, запросов на извлечение или любой операции git/контроля версий. Заменяет команды записи git на «но» — всегда используйте это вместо необработанного git.
