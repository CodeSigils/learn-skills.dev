Autonomer mehrseitiger Site-Builder mit einer Taktstock-Weitergabeschleife. Jede Iteration liest eine Aufgabe aus .design/next-prompt.md, generiert eine Seite in HTML/Tailwind, integriert sie in die Site, überprüft sie visuell und schreibt dann die nächste Aufgabe, um die Schleife am Leben zu halten. Verwenden Sie es immer dann, wenn der Benutzer eine komplette Website autonom erstellen, alle Seiten einer Website erstellen, mehrere Seiten nacheinander generieren oder eine „Design-Schleife“ / „Stabschleife“ / „autonome Website-Erstellung“ ausführen möchte – auch wenn er mitten im Prozess sagt: „Einfach weitermachen“ oder „Nächste Seite erstellen“ oder „Nächste Seite“.
