Creador de sitios autónomo de varias páginas que utiliza un bucle de paso de testigos. Cada iteración lee una tarea de .design/next-prompt.md, genera una página en HTML/Tailwind, la integra en el sitio, la verifica visualmente y luego escribe la siguiente tarea para mantener vivo el bucle. Úselo siempre que el usuario solicite crear un sitio completo de forma autónoma, crear todas las páginas de un sitio, generar varias páginas en secuencia o ejecutar un 'bucle de diseño'/'bucle de bastón'/'construcción de sitio autónomo', incluso si dice "simplemente continúa" o "construye la página siguiente" o "página siguiente" a mitad del flujo.
