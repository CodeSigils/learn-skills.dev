Wrangler や MCP がうまく処理できない操作については、Cloudflare REST API を直接ヒットします。一括 DNS、カスタム ホスト名、電子メール ルーティング、キャッシュ パージ、WAF ルール、リダイレクト ルール、ゾーン設定、ワーカー ルート、D1 データベース間クエリ、R2 一括操作、KV 一括読み取り/書き込み、ベクトル化クエリ、キュー、およびフリート全体のリソース監査。 curl コマンドまたはスクリプトを生成します。トリガー: 「cloudflare API」、「Bulk DNS」、「カスタム ホスト名」、「電子メール ルーティング」、「キャッシュ パージ」、「WAF ルール」、「D1 クエリ」、「R2 バケット」、「KV バルク」、「ベクトル化クエリ」、「監査リソース」、「フリート操作」。
