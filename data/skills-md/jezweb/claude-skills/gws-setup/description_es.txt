Configure la CLI de Google Workspace (gws) desde cero. Guía a través de la creación de proyectos de GCP, credenciales de OAuth, autenticación e instalación de más de 90 habilidades de agente para Claude Code. Úselo siempre que el usuario desee configurar gws por primera vez, configurar el acceso a la API de Google Workspace, instalar la CLI de Google Workspace o solucionar problemas de autenticación de gws.
