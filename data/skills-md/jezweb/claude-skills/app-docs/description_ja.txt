スクリーンショットを含む Web アプリの完全なユーザー ドキュメントを生成します。ブラウザ自動化によってアプリを参照し、すべての画面のスクリーンショットを作成し、ステップごとの手順、注釈付きのスクリーンショット、ワークフロー図、参照表を含む構造化されたユーザー ガイドを作成します。クイック (キー画面)、標準 (すべてのページ)、詳細 (すべての状態とフロー)、および徹底的 (公開可能なドキュメント スイート) をサポートします。トリガー: 「アプリのドキュメント作成」、「ユーザー ガイド」、「アプリのドキュメント」、「スクリーンショット ドキュメント」、「ユーザー ドキュメントの生成」、「ヘルプ ドキュメント」、「ハウツー ガイド」、「ドキュメントの作成」。
