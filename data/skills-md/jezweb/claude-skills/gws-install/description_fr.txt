Installation rapide de Google Workspace CLI (gws) sur une machine supplémentaire à l'aide des informations d'identification OAuth existantes. Nécessite client_secret.json d'une configuration gws précédente. À utiliser chaque fois que l'utilisateur souhaite installer gws sur un nouvel ordinateur, réinstaller après un nouveau système d'exploitation, configurer un deuxième poste de travail ou dire « installer gws », « gws sur une nouvelle machine », « configurer à nouveau gws ».
