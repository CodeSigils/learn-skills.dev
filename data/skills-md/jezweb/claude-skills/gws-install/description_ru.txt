Быстрая установка интерфейса командной строки Google Workspace (gws) на дополнительном компьютере с использованием существующих учетных данных OAuth. Требуется client_secret.json из предыдущей настройки gws. Используйте его всякий раз, когда пользователь хочет установить gws на новый компьютер, переустановить новую ОС, настроить вторую рабочую станцию ​​или сказать «установить gws», «gws на новом компьютере», «настроить gws еще раз».
