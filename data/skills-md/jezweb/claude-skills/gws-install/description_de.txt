Schnelle Installation der Google Workspace CLI (gws) auf einem zusätzlichen Computer mit vorhandenen OAuth-Anmeldeinformationen. Erfordert client_secret.json aus einem früheren GWS-Setup. Verwenden Sie diese Option immer dann, wenn der Benutzer gws auf einem neuen Computer installieren, nach einem neuen Betriebssystem neu installieren, eine zweite Workstation konfigurieren möchte oder „gws installieren“, „gws auf neuem Computer“ oder „gws erneut einrichten“ sagt.
