Instalación rápida de la CLI de Google Workspace (gws) en una máquina adicional utilizando credenciales OAuth existentes. Requiere client_secret.json de una configuración de gws anterior. Úselo siempre que el usuario desee instalar gws en una computadora nueva, reinstalarlo después de un sistema operativo nuevo, configurar una segunda estación de trabajo o diga "instalar gws", "gws en una máquina nueva", "configurar gws nuevamente".
