Ajoutez des paiements Stripe à une application Web : sessions de paiement, intentions de paiement, abonnements, webhooks, portail client et pages de tarification. Couvre la décision quant à l'API Stripe à utiliser, produit un code d'intégration fonctionnel et gère la vérification des webhooks. Aucun serveur MCP n'est nécessaire : utilise directement le package Stripe npm. Déclencheurs : « ajouter des paiements », « stripe », « paiement », « abonnement », « formulaire de paiement », « page de tarification », « facturation », « accepter les paiements », « webhook stripe », « portail client ».
