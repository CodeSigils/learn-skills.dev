Добавьте платежи Stripe в веб-приложение — сеансы оформления заказа, платежные намерения, подписки, веб-перехватчики, портал для клиентов и страницы цен. Охватывает решение о том, какой API-интерфейс Stripe использовать, создает рабочий код интеграции и выполняет проверку веб-перехватчика. Сервер MCP не требуется — используется пакет Stripe npm напрямую. Триггеры: «добавление платежей», «полоса», «оформление заказа», «подписка», «форма оплаты», «страница цен», «биллинг», «прием платежей», «вебхук полосы», «портал для клиентов».
