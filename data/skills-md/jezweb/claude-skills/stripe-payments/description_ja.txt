Web アプリに Stripe 支払いを追加します — チェックアウト セッション、支払いインテント、サブスクリプション、Webhook、カスタマー ポータル、および価格設定ページ。どの Stripe API を使用するかの決定をカバーし、機能する統合コードを生成し、Webhook 検証を処理します。 MCP サーバーは必要ありません。Stripe npm パッケージを直接使用します。トリガー: 「支払いの追加」、「ストライプ」、「チェックアウト」、「サブスクリプション」、「支払いフォーム」、「価格設定ページ」、「請求」、「支払いの受け入れ」、「ストライプ Webhook」、「カスタマー ポータル」。
