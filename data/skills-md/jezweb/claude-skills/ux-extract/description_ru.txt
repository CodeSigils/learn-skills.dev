Полностью извлекайте шаблоны UX из эталонного веб-приложения. Обходит каждый экран, делает снимки экрана каждого состояния, записывает шаблоны взаимодействия, дословное копирование, сочетания клавиш, отзывчивые обработки, движение и состояния пустого/ошибочного/загрузки. Создает повторно используемую библиотеку шаблонов, с которой могут сравниваться другие проверки. Противоположность ux-audit — спрашивает: «Какова планка?» а не «соответствует ли это планке?». Запустите триггер с помощью «учиться на X», «извлекать шаблоны из X», «изучать UX X», «обратное проектирование UX X», «создавать библиотеку шаблонов на основе X».
