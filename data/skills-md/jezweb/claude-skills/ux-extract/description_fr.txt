Extrayez de manière exhaustive les modèles UX d’une application Web de référence. Parcourt chaque écran, capture des captures d'écran de chaque état, enregistre les modèles d'interaction, copie textuellement, les raccourcis clavier, les traitements réactifs, les mouvements et les états vide/erreur/chargement. Produit une bibliothèque de modèles réutilisables à laquelle d’autres audits peuvent comparer. L'inverse de ux-audit — demande « quelle est la barre ? plutôt que « est-ce que cela correspond à la barre ? ». Déclenchez avec « apprendre de X », « extraire des modèles de X », « étudier l'UX de X », « procéder à l'ingénierie inverse de l'UX de X », « créer une bibliothèque de modèles à partir de X ».
