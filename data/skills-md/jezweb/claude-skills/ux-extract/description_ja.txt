リファレンス Web アプリから UX パターンを徹底的に抽出します。すべての画面を歩き回り、すべての状態のスクリーンショットをキャプチャし、インタラクション パターンを記録し、逐語的にコピー、キーボード ショートカット、応答性の高い処理、モーション、および空/エラー/読み込み状態を記録します。他の監査で比較できる再利用可能なパターン ライブラリを生成します。 ux-audit の逆 — 「バーは何ですか?」と尋ねます。 「これはバーに合いますか？」ではなく。 「X から学ぶ」、「X からパターンを抽出する」、「X の UX を研究する」、「X の UX をリバース エンジニアリングする」、「X からパターン ライブラリを構築する」でトリガーします。
