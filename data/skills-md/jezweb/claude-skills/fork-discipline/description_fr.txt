Auditez et appliquez la frontière cœur/client dans les projets multi-clients. Détecte où le code de la plate-forme partagée est mêlé au code spécifique au client, trouve les vérifications client codées en dur, les fichiers de configuration qui remplacent au lieu de fusionner, le code client dispersé, les conflits de migration et les points d'extension manquants. Produit une carte des limites, un rapport de violation et un plan de refactorisation. Génère éventuellement de la documentation FORK.md et des scripts de restructuration. Déclencheurs : « discipline du fork », « vérifier les limites », « s'agit-il d'un noyau ou d'un client », « audit de plate-forme », « séparation des clients », « test du fork », « refactoriser pour multi-client », « nettoyer le fork ».
