Générez la documentation du projet à partir de l'analyse de la base de code — ARCHITECTURE.md, API_ENDPOINTS.md, DATABASE_SCHEMA.md. Lit le code source, les fichiers de schéma, les itinéraires et la configuration pour produire des documents précis et structurés. À utiliser lors du démarrage d'un projet, de l'intégration de contributeurs ou lorsque des documents sont manquants ou obsolètes.
