Modèles React Native et Expo pour créer des applications mobiles performantes. Couvre les performances des listes, les animations avec Reanimated, la navigation, les modèles d'interface utilisateur, la gestion de l'état, le code spécifique à la plate-forme et les flux de travail Expo. À utiliser lors de la création ou de la révision du code React Native. Déclencheurs : « React Native », « Expo », « Application mobile », « React Native Performance », « Flatlist », « Réanimé », « Expo Router », « Mobile Development », « iOS App », « Android App ».
