Шаблоны React Native и Expo для создания эффективных мобильных приложений. Охватывает производительность списка, анимацию с помощью Reanimated, навигацию, шаблоны пользовательского интерфейса, управление состоянием, код для конкретной платформы и рабочие процессы Expo. Используйте при создании или проверке кода React Native. Триггеры: «реакция нативная», «экспо», «мобильное приложение», «реакция нативной производительности», «плоский список», «реанимация», «экспо-роутер», «разработка мобильных устройств», «приложение для iOS», «приложение для Android».
