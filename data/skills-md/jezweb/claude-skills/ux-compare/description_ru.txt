Сравните шаблоны UX в нескольких эталонных приложениях, используя библиотеки шаблонов, созданные ux-extract. Считывает более двух файлов Pattern-library.md, просматривает их по категориям, определяет, где приложения сходятся (сильный сигнал), где они расходятся (действительный выбор дизайна), что уникально для одного приложения и что отсутствует во всем наборе. Создает подробный сравнительный документ с рекомендациями для новой сборки. Браузер не требуется — чистый анализ уценки. Триггер с помощью «сравнить шаблоны UX», «как лучшие приложения обрабатывают X», «сравнение UX», «сравнение шаблонов между эталонными приложениями».
