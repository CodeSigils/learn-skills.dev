أنشئ صفحة مقصودة كاملة وقابلة للنشر من الموجز. يُنتج ملف HTML واحدًا مستقلاً باستخدام Tailwind CSS (عبر CDN)، وتصميم سريع الاستجابة، ووضع داكن، وHTML الدلالي، وعلامات OG الوصفية. الأقسام: البطل مع CTA، الميزات، الدليل الاجتماعي، التسعير (اختياري)، الأسئلة الشائعة، التذييل. يُستخدم عند إنشاء صفحة تسويق، أو صفحة إطلاق منتج، أو صفحة قادمة قريبًا، أو أي صفحة مقصودة مستقلة. المشغلات: "الصفحة المقصودة"، "إنشاء صفحة"، "صفحة التسويق"، "صفحة الإطلاق"، "صفحة ستتوفر قريبًا"، "موقع من صفحة واحدة".
