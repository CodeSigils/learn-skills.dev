概要から完全な展開可能なランディング ページを生成します。 Tailwind CSS (CDN 経由)、レスポンシブ デザイン、ダーク モード、セマンティック HTML、および OG メタ タグを含む単一の自己完結型 HTML ファイルを生成します。セクション: CTA 付きのヒーロー、機能、社会的証明、価格設定 (オプション)、FAQ、フッター。マーケティング ページ、製品発売ページ、近日公開ページ、またはスタンドアロンのランディング ページを作成するときに使用します。トリガー: 「ランディング ページ」、「ページの作成」、「マーケティング ページ」、「起動ページ」、「近日公開ページ」、「1 ページ サイト」。
