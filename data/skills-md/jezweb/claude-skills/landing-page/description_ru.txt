Создайте полную, готовую к развертыванию целевую страницу из брифа. Создает один автономный HTML-файл с Tailwind CSS (через CDN), адаптивным дизайном, темным режимом, семантическим HTML и метатегами OG. Разделы: герой с призывом к действию, функции, социальное доказательство, цены (необязательно), часто задаваемые вопросы, нижний колонтитул. Используйте при создании маркетинговой страницы, страницы запуска продукта, страницы «Скоро» или любой отдельной целевой страницы. Триггеры: «целевая страница», «создать страницу», «маркетинговая страница», «страница запуска», «страница, которая появится в ближайшее время», «одностраничный сайт».
