Fusionnez les résultats des évaluateurs d’architecture, de sécurité, de performances et de style dans un seul rapport hiérarchisé. Lit _workspace/{architecture,security,performance,style}_findings.md, dédupe les résultats qui se chevauchent entre les réviseurs, les trie par gravité et par catégorie, et rédige un rapport final. Invoqué par l'agent de synthèse de rapports à la fin de tout workflow de révision de code ou de développement de code ; déclencher via « fusionner les résultats », « synthétiser l'examen », « produire le rapport final », « consolider » ou « combiner les résultats de l'examen ».
