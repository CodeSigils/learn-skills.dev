Führen Sie /check vor dem Zusammenführen aus, um zu bestätigen, dass eine Änderung sinnvoll ist. Zwei Modi: „/check verify“ steuert die echte App und prüft das Verhalten anhand der Spezifikation (jedes Akzeptanzkriterium erfüllt, jede spezifizierte Oberfläche erstellt); „/check review“ führt eine Senior-Codeüberprüfung für ein anderes Modell durch, als den Code geschrieben hat. Nach /Entwicklung überprüfen, vor einer PR überprüfen. Schreibt Ergebnisse in docs/reviews/; Bearbeitet niemals Ihren Code.
