Exécutez /check avant la fusion pour confirmer qu’un changement est valable. Deux modes : `/check verify` pilote l'application réelle et prouve le comportement par rapport aux spécifications (chaque critère d'acceptation satisfait, chaque surface spécifiée construite) ; `/check review` exécute une révision de code senior sur un modèle différent de celui qui a écrit le code. Vérifiez après/développement, révisez avant un PR. Écrit les résultats dans les documents/revues/ ; ne modifie jamais votre code.
