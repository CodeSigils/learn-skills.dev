Führen Sie /test aus, um eine Testsuite für Code zu schreiben, den Sie gerade erstellt oder geändert haben, nachdem Sie eine Funktion, Route oder einen Fix implementiert haben. Nimmt nicht festgeschriebene Änderungen automatisch ins Visier, liest die Datei „Test Preferences.json“ für Ihr Framework (fragt nach und speichert sie, wenn sie nicht vorhanden ist) und wählt die richtige Strategie pro Datei aus: Happy Path, Randfälle, Fehlerzustände, Zugänglichkeit.
