Categorie di odori ricorrenti in questa codebase, con modelli grep per trovarli. Da utilizzare quando si esegue una revisione periodica del codice, si analizza un passaggio di pulizia o si cerca il tipo di odori sottili che si accumulano sessione dopo sessione: perdite di digitazione, confini non tipizzati, code di cerimonia, disciplina di registrazione della libreria, segnali di abbandono sindacale.
