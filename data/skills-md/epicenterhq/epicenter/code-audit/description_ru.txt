Повторяющиеся категории запахов в этой кодовой базе с шаблонами grep для их поиска. Используйте при периодическом обзоре кода, проверке прохода очистки или поиске тонких запахов, которые накапливаются в течение сеанса: утечки утиного ввода, нетипизированные границы, хвосты церемоний, дисциплина ведения журналов библиотек, сигналы оттока объединений.
