Categorías de olores recurrentes en este código base, con patrones grep para encontrarlas. Úselo al realizar una revisión periódica del código, determinar el alcance de un pase de limpieza o buscar el tipo de olores sutiles que se acumulan sesión tras sesión: fugas de escritura, límites sin tipo, colas de ceremonia, disciplina de registro de biblioteca, señales de abandono sindical.
