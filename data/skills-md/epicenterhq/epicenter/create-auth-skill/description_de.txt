Erstellen Sie mithilfe von Better Auth ein Gerüst und implementieren Sie die Authentifizierung in TypeScript-/JavaScript-Apps. Erkennen Sie Frameworks, konfigurieren Sie Datenbankadapter, richten Sie Routenhandler ein, fügen Sie OAuth-Anbieter hinzu und erstellen Sie Authentifizierungs-UI-Seiten. Verwenden Sie diese Option, wenn Benutzer mit Better Auth die Anmeldung, Registrierung oder Authentifizierung zu einem neuen oder vorhandenen Projekt hinzufügen möchten.
