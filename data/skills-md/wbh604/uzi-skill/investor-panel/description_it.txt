Una giuria di 50 investitori di pesi massimi. Date le dimensioni.json e raw_data.json di un titolo, ciascuno dei 50 investitori assegna un punteggio in base alla propria metodologia e genera un segnale Pydantic (segnale/fiducia/punteggio/verdetto/commento). Copre sette scuole: value classico, investimenti in crescita, macro/hedge globale, trend tecnico, value cinese, hot-money con azioni A e sistema quantitativo. Si attiva quando l'utente chiede "la giuria / cosa pensano i 50 pezzi grossi / tal dei tali lo comprerebbe / voterebbe un pezzo grosso".
