Kernworkflow für eine detaillierte Einzelaktienanalyse. Wird immer dann ausgelöst, wenn ein Benutzer „Tiefenanalyse / umfassende Analyse / Schauen Sie sich für mich um / lohnt sich zu kaufen / DCF / institutionelle Modellierung / Initiierung / IC-Memo“ oder eine andere Aktienrechercheaufgabe anfordert. Deckt A-Aktien, HK-Aktien und US-Aktien ab; Gibt 22-dimensionale Daten aus + 51 quantitative Bewertungen von Top-Gurus + 6 Bewertungsmodelle auf institutioneller Ebene (DCF/Comps/LBO/3-Stmt/Merger) + 7 Forschungsergebnisse (Initiierung/Gewinnübersicht/Katalysatorkalender/Thesis-Tracker/Morgennotiz/Quant Screen/Branchenzusammenfassung) + 6 Entscheidungsrahmen (IC Memo/DD/Porter/Unit-Econ/VCP/Rebalance) + Erkennung von Schweineschlachtbetrug und erstellt schließlich einen HTML-Bericht im Bloomberg-Stil + eine Social-Media-Battle-Card. Schlüsselwörter: Aktien, Einzelaktie, eingehende Analyse, Bewertung, DCF, Comps, Initiierung, IC-Memo, Schweineschlachtung, Dragon-Tiger, Akshare.
