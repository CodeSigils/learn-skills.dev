Kernworkflow für die detaillierte Analyse einzelner Aktien. Wird ausgelöst, wenn Benutzer „Tiefenanalyse / umfassende Analyse / Werfen Sie einen Blick für mich / Kauf lohnt sich / DCF / institutionelle Modellierung / Initiierung / IC-Memo“ oder Fragen zur Aktienanalyse anfordern. Deckt A-Aktien, Hongkong-Aktien und US-Aktien ab; liefert 22-dimensionale Daten + 51 Guru-Quant-Reviews + 6 institutionelle Bewertungsmodelle (DCF/Comps/LBO/3-Stmt/Merger) + 7 Forschungsergebnisse (Initiierung/Gewinnrückblick/Katalysatorkalender/Thesis-Tracker/Morning Note/Quant Screen/Branchenzusammenfassung) + 6 Entscheidungsrahmen (IC Memo/DD/Porter/Unit Economics/VCP/Rebalancing) + Schweineschlachtung Betrugserkennung, die in einem HTML-Bericht im Bloomberg-Stil und einer Social-Share-Battle-Card gipfelt. Schlüsselwörter: Aktien, Einzelaktien, eingehende Analyse, Bewertung, DCF, Comps, Initiierung, IC-Memo, Schweineschlachtbetrug, Dragon-Tiger-Liste, Akshare.
