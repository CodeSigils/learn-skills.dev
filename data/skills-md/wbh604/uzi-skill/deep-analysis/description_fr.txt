Flux de travail de base pour une analyse approfondie d’un seul stock. Déclenché chaque fois qu'un utilisateur demande « une analyse approfondie / une analyse complète / jetez un œil pour moi / vaut la peine d'acheter / DCF / modélisation institutionnelle / initiation / mémo IC » ou toute autre tâche de recherche sur les actions. Couvre les actions A, les actions de Hong Kong et les actions américaines ; produit des données en 22 dimensions + 51 évaluations quantitatives de grands gourous + 6 modèles d'évaluation de qualité institutionnelle (DCF/Comps/LBO/3-Stmt/Merger) + 7 livrables de recherche (initiation/enveloppement des bénéfices/calendrier catalyseur/suivi de thèse/note du matin/écran quantique/tour d'horizon de l'industrie) + 6 cadres de décision (IC Memo/DD/Porter/Unit-Econ/VCP/Rebalance) + abattage de porcs détection des arnaques, et produit enfin un rapport HTML de style Bloomberg + une carte de combat sur les réseaux sociaux. Mots clés : actions, stock unique, analyse approfondie, valorisation, DCF, comps, initiation, mémo IC, abattage de porcs, Dragon-Tiger, akshare.
