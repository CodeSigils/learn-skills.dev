Основной рабочий процесс для углубленного анализа отдельных акций. Запускается всякий раз, когда пользователь запрашивает «глубокий анализ / всесторонний анализ / посмотрите на меня / стоит покупать / DCF / институциональное моделирование / инициирование / памятка IC» или любую другую задачу по исследованию акций. Охватывает акции A, акции Гонконга, акции США; выводит 22-мерные данные + 51 количественный рейтинг от ведущих гуру + 6 моделей оценки институционального уровня (DCF/Comps/LBO/3-Stmt/Merger) + 7 исследовательских результатов (инициирование/обзор прибыли/календарь-катализатор/отслеживание диссертаций/утренняя заметка/количественный экран/сводный обзор отрасли) + 6 структур принятия решений (IC Memo/DD/Porter/Unit-Econ/VCP/Rebalance) + обнаружение мошенничества с забоем свиней и, наконец, создание HTML-отчета в стиле Bloomberg + боевая карта для социальных сетей. Ключевые слова: акции, отдельные акции, глубокий анализ, оценка, DCF, акции, инициация, IC-памятка, убой свиней, Дракон-Тигр, акшаре.
