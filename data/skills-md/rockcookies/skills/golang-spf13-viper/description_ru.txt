Библиотека конфигурации Golang с использованием spf13/viper — многоуровневый приоритет (флаг > env > файл > KV > default), BindPFlag/BindPFlags, SetEnvPrefix + SetEnvKeyReplacer + AutoEnv, ReadInConfig + ConfigFileNotFoundError, Unmarshal + теги структуры карты, Sub для поддеревьев, WatchConfig + OnConfigChange для горячей перезагрузки, viper.New() для изоляции тестов и удаленной интеграции напряжения. Применяется при использовании или внедрении spf13/viper или когда база кода импортирует github.com/spf13/viper. Структуру команд CLI вместе с Viper см. в навыке `golang-spf13-cobra`. Общую архитектуру CLI см. в `golang-cli`.
