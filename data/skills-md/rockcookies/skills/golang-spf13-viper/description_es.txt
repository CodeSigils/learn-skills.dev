Biblioteca de configuración de Golang usando spf13/viper: precedencia en capas (bandera > env > archivo > KV > predeterminado), BindPFlag/BindPFlags, SetEnvPrefix + SetEnvKeyReplacer + AutomaticEnv, ReadInConfig + ConfigFileNotFoundError, Unmarshal + etiquetas de estructura de estructura de mapa, Sub para subárboles, WatchConfig + OnConfigChange para recarga en caliente, viper.New() para aislamiento de prueba, e integración KV remota. Aplicar cuando se usa o se adopta spf13/viper, o cuando el código base importa `github.com/spf13/viper`. Para conocer la estructura de comandos CLI junto con viper, consulte la habilidad `golang-spf13-cobra`. Para conocer la arquitectura CLI general, consulte `golang-cli`.
