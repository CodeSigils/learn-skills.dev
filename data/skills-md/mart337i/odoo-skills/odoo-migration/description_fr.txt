Workflow de migration de module OCA de bout en bout pour le portage des modules complémentaires entre les versions majeures d'Odoo et la préparation des demandes d'extraction [MIG]. À utiliser lors de la migration de modules OCA, du portage de modules complémentaires entre les versions d'Odoo, de l'application des listes de contrôle de migration OCA, de la résolution des conflits de correctifs de migration ou de la préparation de PR de migration OCA versionnés.
