Комплексный рабочий процесс миграции модулей OCA для переноса дополнений между основными версиями Odoo и подготовки запросов на извлечение [MIG]. Используйте при миграции модулей OCA, переносе надстроек между версиями Odoo, применении контрольных списков миграции OCA, разрешении конфликтов патчей миграции или подготовке версий запросов на миграцию OCA.
