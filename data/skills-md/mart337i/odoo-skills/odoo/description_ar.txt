سير عمل هندسة Odoo لتطوير الوظائف الإضافية، واستكشاف قاعدة التعليمات البرمجية، وتصحيح الأخطاء، ومراجعة البنية/إعادة البناء، ومزامنة البيان/المستندات، والتوجيه إلى أعمال الترحيل. يُستخدم عندما يذكر المستخدم Odoo، أو الإضافات، أو الوحدات النمطية، أو البيانات، أو النماذج، أو طرق عرض XML، أو ملفات CSV للأمان، أو قواعد التسجيل، أو Odoo Shell، أو OWL/QWeb/assets، أو عند اكتشاف قاعدة بيانات Odoo البرمجية.
