Generieren Sie KI-Illustrationen für Artikel (Architekturdiagramme, Flussdiagramme, technische Schaltpläne usw.) und decken Sie dabei den gesamten Arbeitsablauf ab, von den Schreibstandards für „Zeichnungsaufforderungen“ bis hin zum Aufruf von gpt-image-2 für die tatsächliche Generierung, Qualitätsprüfung, das Hochladen und die Einbettung in den Artikel. Es gilt für jedes Schreibszenario, das Illustrationen erfordert, und ist nicht auf technische Artikel beschränkt. Auslöseschlüsselwörter: Zeichnen Sie ein Architekturdiagramm, zeichnen Sie ein Flussdiagramm, generieren Sie eine Illustration, generieren Sie ein Bild, zeichnen Sie das Bild, rendern Sie es, helfen Sie mir, ein Bild zu erstellen. Es kann auch von anderen schreibbezogenen Fertigkeiten über das Fertigkeitstool während der „Illustrationsphase“ aufgerufen werden.
