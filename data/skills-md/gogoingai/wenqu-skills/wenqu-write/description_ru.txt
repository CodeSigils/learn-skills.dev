Структурированный рабочий процесс для написания технических вводных статей для технологических проектов. Подходит для знакомства с проектами, глубокого технического анализа, анализа исходного кода, статей по проектированию систем и сравнения решений. Ключевые слова-триггеры: напишите введение, техническую статью, анализ исходного кода, глубокое погружение, напишите вводную документацию, помогите мне написать статью об этой системе.
