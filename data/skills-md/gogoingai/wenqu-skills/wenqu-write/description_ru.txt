Структурированный рабочий процесс для написания технических вводных статей для технических проектов. Подходит для обзоров проектов, углубленного технического анализа, анализа исходного кода, статей о проектировании систем и сравнения решений. Ключевые слова-триггеры: напишите введение, техническую статью, анализ исходного кода, глубокую интерпретацию, напишите вводный документ, помогите мне написать статью об этой системе.
