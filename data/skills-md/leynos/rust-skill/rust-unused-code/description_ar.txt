يُستخدم لنتائج Rust `dead_code` و`unused_imports`، خاصة عندما يؤدي التحويل البرمجي الشرطي أو علامات الميزات أو التعليمات البرمجية الخاصة بالهدف أو التعليمات البرمجية للاختبار فقط إلى تغيير ما يتم تجميعه فعليًا. تفضل الترجمة الشرطية، والوحدات المضمنة ذات النطاق الضيق، وعمليات الاستيراد داخل الوظيفة، بحيث يدخل الكود المطلوب فقط في كل وحدة مجمعة. يُستخدم عند تحديد ما إذا كان يجب نقل التعليمات البرمجية خلف `#[cfg(...)]`، إلى وحدة نمطية أكثر إحكامًا، أو إلى نطاق استيراد أضيق بدلاً من منع الخطوط.
