Verwenden Sie für Rust „dead_code“- und „unused_imports“-Ergebnisse, insbesondere wenn bedingte Kompilierung, Feature-Flags, zielspezifischer Code oder Nur-Test-Code ändern, was tatsächlich kompiliert wird. Bevorzugen Sie bedingte Kompilierung, eng begrenzte Inline-Module und funktionsinterne Importe, damit nur der benötigte Code in jedes kompilierte Modul gelangt. Verwenden Sie diese Option, wenn Sie entscheiden, ob Code hinter „#[cfg(...)]“, in ein engeres Modul oder in einen engeren Importbereich verschoben werden soll, anstatt Lints zu unterdrücken.
