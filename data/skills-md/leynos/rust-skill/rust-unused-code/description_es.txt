Úselo para los hallazgos de Rust `dead_code` y `unused_imports`, especialmente cuando la compilación condicional, los indicadores de características, el código específico de destino o el código de solo prueba cambian lo que realmente se compila. Prefiera la compilación condicional, módulos en línea de alcance limitado e importaciones en función para que solo el código necesario ingrese a cada módulo compilado. Úselo para decidir si el código debe moverse detrás de `#[cfg(...)]`, a un módulo más estricto o a un alcance de importación más limitado en lugar de suprimir las pelusas.
