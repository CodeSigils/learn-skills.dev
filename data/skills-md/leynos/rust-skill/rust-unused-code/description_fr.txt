À utiliser pour les résultats Rust `dead_code` et `unused_imports`, en particulier lorsque la compilation conditionnelle, les indicateurs de fonctionnalités, le code spécifique à la cible ou le code de test uniquement modifient ce qui est réellement compilé. Préférez la compilation conditionnelle, les modules en ligne à portée étroite et les importations en fonction afin que seul le code nécessaire entre dans chaque module compilé. À utiliser pour décider si le code doit se déplacer derrière `#[cfg(...)]`, dans un module plus restreint ou dans une portée d'importation plus étroite au lieu de supprimer les lints.
