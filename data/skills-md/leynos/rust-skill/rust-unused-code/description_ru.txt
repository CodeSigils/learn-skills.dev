Используйте для выводов Rust `dead_code` и `unused_imports`, особенно когда условная компиляция, флаги функций, целевой код или код, предназначенный только для тестирования, меняют то, что фактически компилируется. Отдавайте предпочтение условной компиляции, встроенным модулям с узкой областью действия и внутрифункциональному импорту, чтобы в каждый скомпилированный модуль входил только необходимый код. Используйте, когда решаете, следует ли коду перейти за `#[cfg(...)]`, в более жесткий модуль или в более узкую область импорта вместо подавления проверок.
