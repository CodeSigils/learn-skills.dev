Presentación HTML de un solo archivo con deslizamiento horizontal al estilo de Replit Slides
Galería de plantillas de página de destino. Ocho temas distintos (helix, holm, vance,
bisel, mundo oscuro, mundo menta, atlas, casa azul): cada uno de ellos es una imagen visual completa.
sistema (paleta + tipografía + acento) capturado desde replit.com/slides. Elige uno
tema, no mezclar. Para presentaciones, informes de juntas directivas, memorandos de marca y campañas.
revela: cuando el usuario desea explícitamente "estilo Replit Slides".
