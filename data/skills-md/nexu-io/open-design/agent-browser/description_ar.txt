أتمتة المتصفح CLI لوكلاء الذكاء الاصطناعي. يُستخدم عندما يحتاج المستخدم إلى الفحص،
اختبار أو أتمتة سلوك المتصفح: التنقل بين الصفحات، وملء النماذج،
النقر على الأزرار، والتقاط لقطات الشاشة، واستخراج بيانات الصفحة، واختبار الويب
التطبيقات، أو التطبيق التجريبي، أو معاينات التصميم المفتوح، أو ضمان الجودة، أو البحث عن الأخطاء، أو مراجعة التطبيق
الجودة. تفضل عناوين URL المحلية لمعاينة التصميم المفتوح ما لم يكن المستخدم صريحًا
يطلب التصفح الخارجي.
