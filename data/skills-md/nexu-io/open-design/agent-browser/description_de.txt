Browser-Automatisierungs-CLI für KI-Agenten. Verwenden Sie es, wenn der Benutzer prüfen muss,
Testen oder automatisieren Sie das Browserverhalten: Navigieren durch Seiten, Ausfüllen von Formularen,
Klicken auf Schaltflächen, Erstellen von Screenshots, Extrahieren von Seitendaten, Testen des Webs
Apps, Dogfooding von Open Design-Vorschauen, Qualitätssicherung, Fehlersuche oder Überprüfung von Apps
Qualität. Bevorzugen Sie lokale Open-Design-Vorschau-URLs, es sei denn, der Benutzer gibt dies ausdrücklich an
fragt nach externem Surfen.
