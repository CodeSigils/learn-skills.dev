CLI d’automatisation du navigateur pour les agents IA. À utiliser lorsque l'utilisateur a besoin d'inspecter,
tester, ou automatiser le comportement du navigateur : navigation dans les pages, remplissage de formulaires,
cliquer sur des boutons, prendre des captures d'écran, extraire des données de page, tester le Web
applications, aperçus Dogfooding Open Design, assurance qualité, chasse aux bogues ou révision d'applications
qualité. Préférez les URL d’aperçu Open Design locales, sauf si l’utilisateur l’a explicitement
demande une navigation externe.
