CLI de automatización del navegador para agentes de IA. Úselo cuando el usuario necesite inspeccionar,
probar o automatizar el comportamiento del navegador: navegar por páginas, completar formularios,
hacer clic en botones, tomar capturas de pantalla, extraer datos de la página, probar la web
aplicaciones, pruebas preliminares de diseño abierto, control de calidad, búsqueda de errores o revisión de aplicaciones
calidad. Prefiera las URL de vista previa locales de Open Design a menos que el usuario lo indique explícitamente.
Solicita navegación externa.
