Навык инструктажа Open Orbit — выбирается конвейером Orbit, когда
GitHub — единственный подключенный коннектор пользователя, или когда пользователь
явно ограничивает свой ежедневный дайджест GitHub. Вытягивает последние 24
часов PR, запросов на проверку, проблем, CI-прогонов и слияний из
аутентифицированное соединение пользователя с GitHub и отображает его в макете
это отражает родной визуальный язык Notifications + PR-diff GitHub.
Этот навык не следует активировать вручную — он вызывается
Планировщик ежедневных дайджестов Orbit на основе живых данных GitHub.
