Offene Orbit-Briefing-Fähigkeit – wird von der Orbit-Pipeline ausgewählt, wenn
GitHub ist der einzige verbundene Connector des Benutzers, oder wenn der Benutzer
beschränkt ihren täglichen Digest explizit auf GitHub. Zieht die letzten 24
Stundenlange PRs, Überprüfungsanfragen, Probleme, CI-Läufe und Zusammenführungen aus dem
authentifizierte GitHub-Verbindung des Benutzers und rendert sie in einem Layout
das die native Benachrichtigungs- und PR-Diff-Bildsprache von GitHub widerspiegelt.
Dieser Skill sollte nicht manuell ausgelöst werden – er wird von aufgerufen
Orbits täglicher Digest-Planer für Live-GitHub-Daten.
