Open Orbit ブリーフィング スキル — Orbit パイプラインによって選択される
GitHub がユーザーの唯一の接続コネクタである場合、またはユーザーが
毎日のダイジェストを GitHub に明示的にスコープします。過去を引く 24
数時間にわたる PR、レビューリクエスト、問題、CI の実行、および
ユーザーの認証された GitHub 接続を取得し、レイアウトでレンダリングします。
これは、GitHub のネイティブの通知 + PR-diff ビジュアル言語を反映しています。
このスキルは手動でトリガーすべきではありません。それはによって呼び出されます。
ライブ GitHub データに対する Orbit の日次ダイジェスト スケジューラー。
