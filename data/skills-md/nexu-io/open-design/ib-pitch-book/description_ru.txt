Инвестиционно-банковская презентационная книга стратегических альтернатив — торговые предложения,
прецедентные сделки, футбольное поле оценки, чувствительность DCF,
Матрица стратегических вариантов, рекомендации по процессу. Построен путем адаптации
`assets/template.html`, поэтому хром, специфичный для IB, полосы раскрытия и источник
этикетки сохранились. Используйте для материалов для обсуждения со стороны Совета директоров/продавцов. Не
Схема сбора средств венчурного капитала (см. html-ppt-pitch-deck). Рабочий процесс адаптирован из
Pitch Agent антропных финансовых услуг (Apache-2.0).
