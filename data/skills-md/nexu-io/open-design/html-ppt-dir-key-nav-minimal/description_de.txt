8-seitige minimalistische Pfeiltasten-Keynote – jede Folie hat einen einfarbigen Hintergrund (Indigo / Creme / Purpur / Jade / Grau / Lila / Weiß / Anthrazit), individuell farblich angepasst, 160 Pixel große Display-Überschrift + 4 Pixel kurze, dicke Akzentlinien-Trennlinie, Pfeil-vorangestellte Mono-Liste, unten links ← → kbd-Hinweis + unten rechts Seitenzahl, großer atmender Leerraum. Perfekt für eine „Etwas zu sagen, nichts zu zeigen“-Keynote, eine Eröffnungsrede oder einen öffentlichen Vortrag.
