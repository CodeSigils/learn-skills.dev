8-страничный минималистичный Keynote с клавишами со стрелками — каждый слайд имеет сплошной монохромный фон (индиго / кремовый / малиновый / нефритовый / серый / фиолетовый / белый / угольный), индивидуально подобранный цвет, отображаемый заголовок размером 160 пикселей + короткий толстый разделитель в виде акцентной линии в 4 пикселя, моно-список с префиксом в виде стрелки, слева внизу ← → подсказка kbd + номер страницы справа внизу, огромные пробелы. Идеально подходит для основного доклада, презентации или публичного выступления «что сказать, но нечего показать».
