Extraiga un kit de marca completo de un sitio web activo mediante la aplicación integrada
navegador. Úselo cuando se abre un proyecto de extracción de marca con un sitio en el navegador
pestaña, o cuando el usuario solicita "extraer una marca", "extraer la marca de <url>",
"obtener los colores/fuentes/logotipo de este sitio" o crear un sistema de marca/diseño
de una web de referencia. Se empareja con la herramienta de navegador de agentes para realizar mediciones
y se detiene para el usuario cuando un muro anti-bot bloquea la página.
