Ein-Klick-Beitragsfluss für Open Design (nexu-io/open-design) – auch für Nicht-Programmierer. Wählen Sie eine von vier Karten aus (Versenden Sie ein Fertigkeits- oder Designsystem, das Sie mit OD erstellt haben; übersetzen Sie Dokumente; korrigieren Sie einen Tippfehler / schreiben Sie einen Blog; melden Sie einen Fehler), der Agent validiert und öffnet eine PR (oder ein Problem) für Sie. Auslöserwörter tragen zum offenen Design bei, liefern meine OD-Fähigkeiten, liefern mein OD-Designsystem, übersetzen OD-Dokumente, melden einen OD-Fehler, tragen dazu bei.
