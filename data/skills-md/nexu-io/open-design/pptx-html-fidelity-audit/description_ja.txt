ソース HTML デックに対して Python-pptx エクスポートを監査し、レイアウト/コンテンツのドリフト (フッターのオーバーフロー、コンテンツのトリミング、イタリック/エムの欠落、スタイルの喪失、リズムのずれ) を特定し、厳密なフッター レール + カーソル フロー レイアウト規則に従って再エクスポートします。ユーザーが HTML スライドデッキから生成された .pptx を持っていて、エクスポートの比較/監査/検証/修正を要求するときは常にこのスキルを使用します。これには、「ppt を html と比較する」、「忠実度監査」、「pptx を修正する」、「ppt が切れている」、「フッターの重なり」、「pptx に斜体がない」、「デッキを再エクスポートする」、「pptx-html-fidelity-audit」などのフレーズが含まれます。 python-pptx → HTML の往復で検証または修復が必要な場合。また、ユーザーがデッキ.html とデッキ.pptx を並べて表示し、視覚的な違いをデバッグしているときにもトリガーされます。
