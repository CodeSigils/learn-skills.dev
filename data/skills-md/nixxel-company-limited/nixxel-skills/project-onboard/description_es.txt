Incorpore un agente de IA a cualquier proyecto: detecte la pila (web, móvil, backend), investigue documentos actualizados, ejecute una auditoría universal de 8 categorías (páginas, estado, interfaz de usuario, API, datos, autenticación, trabajos, integraciones) con detección y omisión automáticas, entreviste al desarrollador y genere archivos contextuales estructurados con enrutamiento basado en tareas para que el agente nunca vuelva a perder el tiempo explorando el proyecto. Volver a ejecutar el proyecto incorporado en un repositorio ya incorporado actualiza el contexto modificado, vuelve a ejecutar la auditoría de funciones, conserva las respuestas de las entrevistas y actualiza el enrutamiento sin requerir comandos de actualización o auditoría por separado. Utilice esta habilidad siempre que el usuario diga "a bordo", "a bordo nuevamente", "volver a ejecutar a bordo", "actualizar a bordo", "actualizar contexto", "configurar contexto", "escanear este proyecto", "generar AGENTS.md", "generar CLAUDE.md", "mapear esta base de código", "auditar características", "qué hace este proyecto" o cualquier solicitud para ayudar a un agente de IA a comprender una base de código nueva o existente. También se activa cuando el usuario comienza a trabajar en un repositorio desconocido o en un repositorio existente con archivos `.context/` obsoletos y se beneficiaría de la generación de contexto estructurado.
