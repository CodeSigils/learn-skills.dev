Binden Sie einen KI-Agenten in jedes Projekt ein – erkennen Sie Stacks (Web, Mobil, Backend), recherchieren Sie aktuelle Dokumente, führen Sie ein universelles 8-Kategorien-Audit (Seiten, Status, UI, API, Daten, Authentifizierung, Jobs, Integrationen) mit automatischer Erkennung und automatischem Überspringen durch, befragen Sie den Entwickler und generieren Sie strukturierte Kontextdateien mit aufgabenbasierter Weiterleitung, damit der Agent nie wieder Zeit mit der Erkundung des Projekts verschwendet. Durch die erneute Ausführung von project-onboard auf einem bereits integrierten Repo werden geänderte Kontexte aktualisiert, die Funktionsprüfung erneut ausgeführt, Interviewantworten beibehalten und die Weiterleitung aktualisiert, ohne dass separate Aktualisierungs- oder Prüfbefehle erforderlich sind. Verwenden Sie diesen Skill immer dann, wenn der Benutzer „onboard“, „erneut onboard“, „onboard erneut ausführen“, „onboard aktualisieren“, „Kontext aktualisieren“, „Kontext einrichten“, „dieses Projekt scannen“, „AGENTS.md generieren“, „CLAUDE.md generieren“, „diese Codebasis zuordnen“, „Funktionen prüfen“, „Was macht dieses Projekt“ sagt oder eine Anfrage stellt, um einem KI-Agenten zu helfen, eine neue oder vorhandene Codebasis zu verstehen. Wird auch ausgelöst, wenn der Benutzer beginnt, in einem unbekannten Repo oder einem vorhandenen Repo mit veralteten „.context/“-Dateien zu arbeiten, und würde von einer strukturierten Kontextgenerierung profitieren.
