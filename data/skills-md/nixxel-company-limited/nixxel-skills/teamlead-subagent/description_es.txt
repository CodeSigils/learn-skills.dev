Orquestación TeamLead: se utiliza cuando un humano desea una implementación/delegación coordinada para el código de producto, pruebas, configuración, infraestructura, funciones, correcciones de errores, refactorizaciones o cambios de comportamiento/UI/API. No lo active para inspecciones de solo lectura, actualizaciones de estado, explicaciones, resúmenes ligeros, revisiones sin edición o investigaciones a menos que el ser humano solicite explícitamente que la orquestación o delegación clara de TeamLead sea útil. Cualquier trabajo que cree o modifique el comportamiento siempre debe invocar primero "superpoderes: lluvia de ideas", después de lo cual el Líder debe crear puertas de Especificaciones/Plan antes de delegar; El cliente potencial no debe escribir el código del producto por sí mismo.
