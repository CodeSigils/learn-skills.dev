Utilice la CLI `redmine` para interactuar con Redmine. Actívelo cuando el usuario solicite crear, enumerar, actualizar, cerrar o buscar problemas, registrar o ver entradas de tiempo, administrar versiones o membresías, consultar proyectos/usuarios/grupos o realizar cualquier tarea de gestión de proyectos de Redmine. También se activa cuando el usuario dice "redmine", "problema", "ticket", "entrada de tiempo" o hace referencia a los flujos de trabajo de Redmine.
