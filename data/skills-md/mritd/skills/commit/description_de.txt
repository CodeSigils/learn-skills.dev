Generieren Sie Commit-Nachrichten gemäß der Spezifikation „Conventional Commits 1.0.0“ und committen Sie sie mit gitflow-toolkit („git ci -F“). Verwenden Sie diesen Skill immer dann, wenn der Benutzer Änderungen festschreiben möchte – Ausdrücke wie „提交“, „帮我提交“, „提交变更“, „提交一下“, „提交代码“, „/commit“, „diese Änderungen festschreiben“, „dies festschreiben“, „einen Commit erstellen“, „mir beim Festschreiben helfen“ oder jede explizite Anfrage zum Erstellen eines Git-Commits. Verwenden Sie diese Funktion auch, wenn der Benutzer eine Aufgabe beendet und Sie auffordert, das Ergebnis zu übernehmen. Dieser Skill stellt Dateien automatisch bereit – Benutzer müssen sie nicht manuell bereitstellen.
