Genere mensajes de confirmación siguiendo la especificación de confirmaciones convencionales 1.0.0 y confirme usando gitflow-toolkit (`git ci -F`). Utilice esta habilidad siempre que el usuario quiera confirmar cambios: frases como "提交", "帮我提交", "提交变更", "提交一下", "提交代码", "/commit", "confirmar estos cambios", "confirmar esto", "crear una confirmación", "ayúdame a confirmar" o cualquier solicitud explícita para crear una confirmación de git. Úselo también cuando el usuario finalice una tarea y le solicite que confirme el resultado. Esta habilidad prepara archivos automáticamente: los usuarios no necesitan preparar archivos manualmente.
