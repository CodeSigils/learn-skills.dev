Перенесите каталог проекта на новый путь, сохранив при этом память проекта Claude Code и знания на уровне проекта. Используйте этот навык, когда пользователь хочет переместить или скопировать проект в другой путь к каталогу — такие фразы, как «/project-migrate», «перенести проект в», «переместить проект в новый путь», «переместить каталог проекта». Для этого навыка навык Project-memory должен быть установлен отдельно. Он копирует каталог проекта (сохраняя разрешения), переносит память Claude Code и сохраняет знания о проекте через память проекта, чтобы ИИ мог быстро понять ход проекта в новом месте.
