قم بترحيل دليل المشروع إلى مسار جديد مع الحفاظ على ذاكرة مشروع Claude Code والمعرفة على مستوى المشروع. استخدم هذه المهارة عندما يريد المستخدم نقل مشروع أو نسخه إلى مسار دليل مختلف - عبارات مثل "/project-migrate"، "ترحيل المشروع إلى"، "نقل المشروع إلى مسار جديد"، "نقل دليل المشروع". تتطلب هذه المهارة تثبيت مهارة ذاكرة المشروع بشكل منفصل. يقوم بنسخ دليل المشروع (الحفاظ على الأذونات)، وترحيل ذاكرة Claude Code، والاحتفاظ بمعرفة المشروع عبر ذاكرة المشروع حتى يتمكن الذكاء الاصطناعي من فهم تقدم المشروع بسرعة في الموقع الجديد.
