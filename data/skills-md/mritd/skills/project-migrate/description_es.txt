Migre un directorio de proyecto a una nueva ruta mientras conserva la memoria del proyecto de Claude Code y el conocimiento a nivel de proyecto. Utilice esta habilidad cuando el usuario quiera mover o copiar un proyecto a una ruta de directorio diferente: frases como "/project-migrate", "migrar proyecto a", "mover proyecto a una nueva ruta", "reubicar el directorio del proyecto". Esta habilidad requiere que la habilidad de memoria de proyecto se instale por separado. Copia el directorio del proyecto (preservando los permisos), migra la memoria de Claude Code y conserva el conocimiento del proyecto a través de la memoria del proyecto para que la IA pueda comprender rápidamente el progreso del proyecto en la nueva ubicación.
