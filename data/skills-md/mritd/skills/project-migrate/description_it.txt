Migrare una directory di progetto su un nuovo percorso preservando la memoria del progetto Claude Code e la conoscenza a livello di progetto. Utilizza questa capacità quando l'utente desidera spostare o copiare un progetto in un percorso di directory diverso: frasi come "/project-migrate", "migra progetto in", "sposta progetto in un nuovo percorso", "riposiziona directory del progetto". Questa competenza richiede che la capacità di memoria del progetto venga installata separatamente. Copia la directory del progetto (preservando le autorizzazioni), migra la memoria di Claude Code e mantiene la conoscenza del progetto tramite project-memory in modo che l'intelligenza artificiale possa comprendere rapidamente l'avanzamento del progetto nella nuova posizione.
