Migrez un répertoire de projet vers un nouveau chemin tout en préservant la mémoire du projet Claude Code et les connaissances au niveau du projet. Utilisez cette compétence lorsque l'utilisateur souhaite déplacer ou copier un projet vers un chemin de répertoire différent — des expressions telles que "/project-migrate", "migrer le projet vers", "déplacer le projet vers un nouveau chemin", "déplacer le répertoire du projet". Cette compétence nécessite que la compétence de mémoire de projet soit installée séparément. Il copie le répertoire du projet (en préservant les autorisations), migre la mémoire de Claude Code et conserve les connaissances du projet via la mémoire du projet afin que l'IA puisse rapidement comprendre la progression du projet dans le nouvel emplacement.
