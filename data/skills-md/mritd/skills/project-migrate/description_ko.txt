Claude Code 프로젝트 메모리와 프로젝트 수준 지식을 유지하면서 프로젝트 디렉터리를 새 경로로 마이그레이션합니다. 사용자가 프로젝트를 다른 디렉터리 경로로 이동하거나 복사하려고 할 때 이 기술을 사용합니다(예: "/project- migration", "프로젝트 마이그레이션", "프로젝트를 새 경로로 이동", "프로젝트 디렉터리 재배치" 등). 해당 스킬을 사용하려면 프로젝트-메모리 스킬을 별도로 설치해야 합니다. 프로젝트 디렉터리를 복사하고(권한 유지), Claude Code 메모리를 마이그레이션하고, 프로젝트 메모리를 통해 프로젝트 지식을 유지하므로 AI가 새 위치에서 프로젝트 진행 상황을 빠르게 이해할 수 있습니다.
