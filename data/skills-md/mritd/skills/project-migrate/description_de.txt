Migrieren Sie ein Projektverzeichnis auf einen neuen Pfad und bewahren Sie dabei den Projektspeicher von Claude Code und das Wissen auf Projektebene. Verwenden Sie diese Fähigkeit, wenn der Benutzer ein Projekt in einen anderen Verzeichnispfad verschieben oder kopieren möchte – Ausdrücke wie „/project-migrate“, „Projekt migrieren nach“, „Projekt in neuen Pfad verschieben“, „Projektverzeichnis verschieben“. Für diesen Skill muss der Project-Memory-Skill separat installiert werden. Es kopiert das Projektverzeichnis (unter Beibehaltung der Berechtigungen), migriert den Claude-Code-Speicher und speichert das Projektwissen über den Projektspeicher, sodass die KI den Projektfortschritt am neuen Speicherort schnell verstehen kann.
