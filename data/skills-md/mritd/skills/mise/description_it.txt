Installa i runtime delle lingue mancanti e gli strumenti di sviluppo tramite mise. Da utilizzare quando (1) un comando fallisce a causa della mancanza di runtime (ad esempio nodo non trovato, python3 non trovato, comando go non trovato), (2) l'utente chiede di installare/configurare un runtime della lingua o un SDK (node, python, go, ruggine, java, ruby, ecc.), (3) l'utente menziona la gestione della versione per le lingue o (4) l'impostazione di un nuovo ambiente di sviluppo.
