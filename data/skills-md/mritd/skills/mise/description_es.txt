Instale los tiempos de ejecución de idiomas y las herramientas de desarrollo que faltan a través de mise. Úselo cuando (1) un comando falla debido a que falta un tiempo de ejecución (por ejemplo, no se encontró el nodo, no se encontró python3, no se encontró el comando go), (2) el usuario solicita instalar/configurar un tiempo de ejecución de lenguaje o SDK (nodo, python, go, rust, java, ruby, etc.), (3) el usuario menciona la administración de versiones para idiomas o (4) configura un nuevo entorno de desarrollo.
