Installez les environnements d'exécution de langage et les outils de développement manquants via mise. À utiliser lorsque (1) une commande échoue en raison d'un runtime manquant (par exemple, nœud introuvable, python3 introuvable, commande go introuvable), (2) l'utilisateur demande d'installer/configurer un runtime de langage ou un SDK (nœud, python, go, rust, java, ruby, etc.), (3) l'utilisateur mentionne la gestion des versions pour les langues, ou (4) la configuration d'un nouvel environnement de développement.
