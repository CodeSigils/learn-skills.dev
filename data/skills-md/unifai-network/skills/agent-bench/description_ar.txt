قياس ومقارنة الأداء الوكيل لنماذج LLM المتعددة في نفس المهمة. استخدم هذه المهارة عندما يريد المستخدم مقارنة النماذج، أو قياس LLMs، أو اختبار النموذج الأفضل في مهمة ما، أو تنافس النماذج مع بعضها البعض، أو تقييم أداء النموذج جنبًا إلى جنب. يتم تشغيل عبارات مثل "النماذج المعيارية"، و"مقارنة التأليف مقابل السوناتة"، و"أي نموذج أفضل فيه"، و"سابق هذه النماذج"، و"اختبار أداء النموذج"، و"معيار الوكيل".
