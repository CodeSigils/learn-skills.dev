Comparez et comparez les performances agentiques de plusieurs modèles LLM sur la même tâche. Utilisez cette compétence lorsque l'utilisateur souhaite comparer des modèles, comparer des LLM, tester quel modèle est le meilleur pour une tâche, opposer des modèles les uns aux autres ou évaluer les performances des modèles côte à côte. Se déclenche sur des expressions telles que « modèles de référence », « comparer opus vs sonnet », « quel modèle est le meilleur », « faire la course avec ces modèles », « tester les performances du modèle », « référence d'agent ».
