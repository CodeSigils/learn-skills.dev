Навыки рендеринга и публикации материалов Redbook (Xiaohongshu). Используется для преобразования текста уценки в потрясающие карточки с изображениями в собственном формате (обложка + страницы с контентом) и, при необходимости, их автоматическая публикация на платформе. Поддерживает 8 великолепных тем CSS и 4 режима умной нумерации страниц.
