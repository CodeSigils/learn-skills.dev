Универсальная карточка для социальных сетей и генератор макетов с автоматическим удалением фона с помощью искусственного интеллекта. Используйте это, когда пользователь хочет удалить фон с предметов (изображений) и скомпоновать их в настраиваемые, эстетичные плакаты для социальных сетей (например, карточки сравнения, лукбуки, витрины продуктов). Поддерживает полностью настраиваемые заголовки, субтитры, фоновые изображения и текстовые поля. Теперь изначально поддерживается двойной движок сатори (по умолчанию для макетов с большим количеством текста) и подушка (для сравнения изображений 1:1 с большим количеством теней).
