Douyin-Fähigkeit zur automatischen Veröffentlichung von Videos. Wenn Benutzer Videos auf Douyin veröffentlichen müssen, nutzen sie diese Fähigkeit. Der Skill umfasst Funktionen wie das Erhalten von Login-Cookies, das Hochladen von Videos, das Festlegen von Titeln und Hashtags sowie das Planen von Beiträgen.
