Fähigkeit zur automatischen Veröffentlichung von Douyin-Videos. Wenn ein Benutzer ein Video auf Douyin posten muss, wird diese Fähigkeit verwendet. Der Skill umfasst Funktionen wie das Erhalten von Login-Cookies, das Hochladen von Videos, das Festlegen von Titeln und Themen, das Planen von Beiträgen und mehr.
