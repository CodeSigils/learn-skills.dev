기업의 역사 발전 및 개발 분석 기술 - Qicchacha MCP 기반 KYB 3-D 내러티브 보고서 생성기.  
Qicchacha MCP의 146개 도구를 통해 11장 + 부록 KYB 역사적 진화 보고서를 자동으로 생성합니다.  

V1.2 핵심 기능(스키마 기반 · 조작 방지):  
- **USCC 체크 숫자**: GB 32100-2015 알고리즘; 위조된 통합사회신용코드는 차단됩니다.  
- **개수 ⇔ 행**: 주주 / 과거 주주 / 이사-감독자-선임 / 해외 투자 목록 — 신고된 개수는 실제 행 개수와 동일해야 합니다.  
- **증거 앵커**: 4-튜플(tool_name, json_path, snapshot_ts, raw_value)을 통해 추적 가능한 모든 필드  
- **장 간 일관성**: 페널티 상태는 MCP가 명시적으로 반환하지 않는 한 자체 선언된 "해결/종료"를 금지합니다. 특허 연간 총계는 정확하게 합산되어야 합니다. 시간적 건전성 자가점검  
- **manifest.json**: 감사 재생을 위한 보고서별 필드 수준 출처 체인  

핵심 기능:  
- 11장 구조: §1 회사 프로필 / §2 마일스톤 / §3 등록 자본 / §4 이름 변경 / §5 자산 진화 / §6 비즈니스 트랙 / §7 주소 마이그레이션 / §8 요약 / §9 개발 개요 / §10 부록 / §11 감사 아카이브  
- 3D 내러티브: 라이선스 자격 매트릭스, IP 레이아웃, 사업 확장 및 인원 수, 업계 입지 및 명예  
- 계층 자동 적응: 차별화된 통화로 마이크로(4.5엔) / 자금 지원(13엔) / 상장(18엔) 계층 자동 감지  
- 시각적 스타일: 점+세로 타임라인 + kyb-opus 파란색 챕터 막대 + 얼룩말 테이블, PDF로 직접 이동  

사용 사례: 투자 전 DD(PE/VC), IC 메모 첨부, 은행 신용 KYB, 공급업체 배경 확인, 관리 내역 확인.  

사용법: `/history-evolution-qcc 회사_이름 [unified_social_credit_code]`
