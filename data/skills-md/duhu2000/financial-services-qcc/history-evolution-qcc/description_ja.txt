企業の歴史的進化と発展分析スキル — Qichacha MCP を利用した KYB 3-D ナラティブ レポート ジェネレーター。  
Qichacha MCP の 146 ツールを使用して、11 章 + 付録の KYB 歴史的進化レポートを自動的に作成します。  

V1.2 のコア機能 (スキーマ駆動型、捏造防止):  
- **USCC チェックデジット**: GB 32100-2015 アルゴリズム。捏造された統一社会信用コードはブロックされます  
- **カウント ≡ 行**: 株主 / 元株主 / 取締役、監督者、上級者 / 対外投資リスト - 宣言されたカウントは実際の行カウントと等しくなければなりません  
- **証拠アンカー**: 4 タプル (tool_name、json_path、snapshot_ts、raw_value) 経由で追跡可能なすべてのフィールド  
- **章間の一貫性**: MCP が明示的にそれを返さない限り、ペナルティ ステータスは自己宣言による「解決済み/クローズ」を禁止します。特許の年間合計は正しく合計されなければなりません。一時的な正気度のセルフチェック  
- **manifest.json**: 監査再生のためのレポートごとのフィールドレベルの出自チェーン  

コア機能:  
- 11章構成: §1 会社概要 / §2 マイルストーン / §3 登録資本金 / §4 社名変更 / §5 株式の進化 / §6 事業の軌跡 / §7 アドレス移行 / §8 概要 / §9 開発概要 / §10 付録 / §11 監査アーカイブ  
- 3D ナラティブ: ライセンス資格マトリックス、IP レイアウト、事業拡大と従業員数、業界の地位と名誉  
- ティアの自動適応: マイクロ (4.5 円) / ファンド (13 円) / 上場 (18 円) ティアを差別化されたコールで自動検出  
- ビジュアル スタイル: ドット+垂直タイムライン + kyb-opus ブルーのチャプター バー + ゼブラ テーブル、PDF への直接変換  

ユースケース：投資前DD（PE/VC）、ICメモ添付、銀行信用KYB、サプライヤー身元調査、経営履歴検証。  

使用法: `/history-evolution-qcc company_name [unified_social_credit_code]`  

カスタマー エクスペリエンス: 一文のコマンド → 60 秒で MD + PDF + マニフェスト.json を自動生成、介入ゼロ、製造ゼロ。
