企業の歴史的進化と発展の軌跡分析スキル — Qichacha MCP を利用した KYB 3D ナラティブ レポート ジェネレーター。  
146 個の Qichacha MCP ツールを介して、11 章 + 付録の KYB 歴史的進化レポートを自動的に生成します。  
V1.2 のコア機能 (スキーマ駆動型、捏造防止):  
- **USCC チェック デジット**: GB 32100-2015 チェック デジット アルゴリズム。偽造された統一社会信用コードはブロックされます  
- **カウント ≡ 行**: 株主/過去の株主/取締役および監督者および上級役員/外部投資リストの場合、宣言されたカウントは実際の行カウントと等しくなければなりません  
- **証拠アンカー**: 4 タプル (tool_name、json_path、snapshot_ts、raw_value) 経由で追跡可能なすべてのフィールド  
- **章間の一貫性**: ペナルティ ステータスでは、MCP によって明示的に返されない限り、「解決済み/解決済み」などの単語は禁止されています。特許の年間分配額は合計と等しくなければなりません。時間的合理性の自己チェック  
- **manifest.json**: 各レポートは監査トレーサビリティのためのフィールドレベルの出自チェーンを出力します。  

コア機能:  
- 11章構成: §1 会社概要 / §2 開発マイルストーン / §3 登録資本金 / §4 社名変更 / §5 株式の進化 / §6 事業追跡 / §7 住所変更 / §8 概要 / §9 開発概要 / §10 付録 / §11 監査アーカイブ  
- 3D ナラティブ: ライセンスと資格のマトリックス、IP レイアウト、事業拡大と従業員数、業界での地位と栄誉  
- ティア適応: マイクロ (4.5 円) / ファイナンス (13 円) / 上場 (18 円) ティアは自動検出され、差分呼び出しされます。  
- ビジュアルスタイル: ドット + 垂直タイムライン + kyb-opus ブルーのチャプターバー + ゼブラストライプの表、直接 PDF 出力  

ユースケース: 投資前デューデリジェンス (PE/VC)、IC メモ添付ファイルの生成、銀行信用 KYB、サプライヤーの経歴調査、経営背景と開発軌跡の検証。  

使用法: /history-evolution-qcc 会社名 [統一社会信用コード]  
カスタマー エクスペリエンス: 一文のコマンド → 60 秒で MD + PDF + マニフェスト.json を自動生成、介入ゼロ、製造ゼロ。
