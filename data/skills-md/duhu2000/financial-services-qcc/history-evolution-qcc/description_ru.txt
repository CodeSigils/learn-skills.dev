Навыки анализа корпоративной исторической эволюции и развития — генератор трехмерных повествовательных отчетов KYB на базе Qichacha MCP.  
Автоматически создает отчет об исторической эволюции KYB из 11 глав + приложение с помощью 146 инструментов Qichacha MCP.  

Основные функции версии 1.2 (управляемые схемой · антифабрикация):  
- **Контрольная цифра USCC**: алгоритм GB 32100-2015; сфабрикованные единые коды социального кредита блокируются  
- **количество ≡ строк**: акционер/бывший акционер/директора-супервайзеры-старшие/списки исходящих инвестиций – объявленное количество должно равняться фактическому количеству строк.  
- **привязка доказательств**: каждое поле отслеживается через 4 кортежа (имя_инструмента, путь_json, snapshot_ts, raw_value).  
- **согласованность между главами**: статус штрафа запрещает самопровозглашение «разрешено/закрыто», если MCP явно не возвращает такое; годовые суммы патентов должны суммироваться правильно; временная вменяемость, самопроверка  
- **manifest.json**: цепочка происхождения на уровне поля для каждого отчета для воспроизведения аудита.  

Основные функции:  
- Структура из 11 глав: §1 Профиль компании / §2 Вехи / §3 Зарегистрированный капитал / §4 Изменение названия / §5 Эволюция капитала / §6 Бизнес-направление / §7 Миграция адресов / §8 Резюме / §9 Обзор развития / §10 Приложение / §11 Архив аудита  
- Трехмерное повествование: матрица лицензий и квалификаций, структура интеллектуальной собственности, расширение бизнеса и численность персонала, положение и награды в отрасли.  
- Автоматическая адаптация уровней: микро-(4,5 йен), накопительный (13 йен) / листинговый (18 йен) уровни автоматически определяются с помощью дифференцированных вызовов.  
- Визуальный стиль: точка + вертикальная временная шкала + синие полосы глав kyb-opus + таблицы «зебра», прямая передача в PDF.  

Варианты использования: прединвестиционное DD (PE/VC), вложение IC-памятки, банковский кредит KYB, проверка данных поставщика, проверка истории управления.  

Использование: `/history-evolution-qcc имя_компании [unified_social_credit_code]`  

Опыт работы с клиентами: команда из одного предложения → 60-секундное автоматическое создание MD + PDF + манифест.json, нулевое вмешательство, нулевое изготовление.
