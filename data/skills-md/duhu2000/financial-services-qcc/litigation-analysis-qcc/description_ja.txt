訴訟リスク評価 SKILL・Qichacha MCP V2.0 強化版。  
対象企業の 3 層の訴訟パノラマ スキャン (「現在の状況 + 過去の記録 + 主要人物」) を実行し、訴訟、信用、または投資の決定にすぐに使える司法リスク評価レポートを出力します。  

コア機能:  
- 3 層の訴訟パノラマ: 現在の状況 (17 の qcc リスク ツール) + 過去の記録 (14 の qcc 履歴ツール) + 主要担当者 (18 の qcc 執行ツール)  
- 時系列傾向: 過去の判決、申請、公聴会の発表に基づいた実際の 5 ～ 10 年の傾向分析  
- 執行能力診断: 執行/不正/高消費制限/回復なしで事件終了×現在×過去、「更生した」組織と「慢性的に不正な」組織を特定  
- 主要人物の訴訟プロファイル: 法定代理人、実際の管理者、会長、ゼネラルマネージャーの訴訟全体の状況  
- リスクエクスポージャーの計算: 係属中の訴訟の潜在的な支払い額、未払いの執行額、登録資本に対する比率  

ユースケース: 取引先チェックの提出前 / 信用デューデリジェンス / 投資DD / サプライヤーのオンボーディング / 顧客信用評価 / 破産の早期警告。  

使用法: /litigation-analysis-qcc CompanyName [--period lastNyears] [--type 契約紛争|労働紛争|IP|...] [--person-scan 主要な人事訴訟プロファイルをスキャンするかどうか]
