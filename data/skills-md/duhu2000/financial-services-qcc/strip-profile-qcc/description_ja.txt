企業スナップショット クイック ビュー SKILL · Qichacha MCP V2.0 Enhanced Edition。 LP ロードショー、初期プロジェクトのスクリーニング、および内部投資委員会の説明会前の PE/VC/FA 向けの軽量デューデリジェンス ツールです。事業登録、コア リスク シグナル、IP 資産、V2.0 エンティティの継続性、主要管理の概要の 5 つの構造化セクションを統合して、1 ページの企業スナップショットを 3 分で生成します。

コア機能:
- 基本的なビジネス検証 + エンティティ継続性 (V2.0 新機能、qcc-history ガバナンス-安定性バックトラッキング)
- コアリスクラベル: 不正行為、高等法院の制限、強制執行、株式凍結などの主要なシグナルを 1 ページに表示
- IP 資産概要 + IP 誓約 (V2.0 新ツール)
- 主要な管理概要: 実際の管理者、法定代理人、中核幹部の名前と簡単なプロフィール
- 財務および運営活動: 財務記録、採用活動、栄誉と賞

使用例: LP ロードショー前の 5 分間の対象企業の全体像 / 初期プロジェクトのスクリーニング / 内部投資委員会のブリーフィング / 投資アナリストによる素早い背景説明 / 投資マネージャーによる毎日のウォッチリストの閲覧。

使用法: /strip-profile-qcc CompanyName [-- Depth Quick|standard] [--format md|docx|pptx]
