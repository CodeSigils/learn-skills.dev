エンタープライズ スナップショット クイック ビュー SKILL · Qichacha MCP V2.0 Enhanced Edition。  
LP への売り込み、プロジェクトの事前審査、または社内提案の提示を行う際の、PE/VC/FA 向けの軽量デューデリジェンス ツールです。事業登録、コア リスク シグナル、IP 資産、V2.0 エンティティの継続性、主要管理の概要の 5 つの構造化セクションを統合して、1 ページの企業スナップショットを 3 分で生成します。

コア機能:  
- 基本的なビジネス検証 + エンティティ継続性 (V2.0 新機能、qcc-history ガバナンス-安定性バックトラッキング)  
- コアリスクタグ: 不正、高消費制限、執行、株式凍結などの重要なシグナルを 1 ページに表示  
- IP 資産概要 + IP 誓約 (V2.0 新ツール)  
- 主要な管理概要: 実際の管理者、法定代理人、中核幹部の名前と簡単なプロフィール  
- 財務および運営活動: 財務記録、採用活動、栄誉と賞  

ユースケース: 5 分間の LP 前ピッチの概要 / プロジェクトの事前スクリーニング / 内部立项レポート / アナリストの簡単なバックグラウンド チェック / 投資マネージャー向けの毎日の取引フローの閲覧。
