استخدم هذه المهارة عندما تبدو أتمتة Steel غير موثوقة بسبب اكتشاف الروبوتات، أو حلقات CAPTCHA، أو صفحات 403/رفض الوصول أو التحقق من أنك إنسان، أو فشل الوكيل، أو مشكلات الملف الشخصي أو الهوية، أو مشكلات استمرار بيانات الاعتماد أو تسجيل الدخول، أو سرعة مشبوهة، أو حلقات إعادة التوجيه، أو استراتيجية إعادة المحاولة، أو عندما يسأل المستخدم عن التخفي أو الوكلاء أو حل اختبار CAPTCHA أو الملفات الشخصية أو بيانات الاعتماد أو عمليات تسجيل الدخول الموثوقة. لا تستخدم كخطوة أولى للجلسات الفاشلة غير المعروفة؛ اجمع الأدلة باستخدام تصحيح أخطاء الجلسة الفولاذية أولاً عند الحاجة.
