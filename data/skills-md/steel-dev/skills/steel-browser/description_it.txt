Utilizza questa competenza per attività Web in tempo reale in cui WebFetch o curl fallirebbero o sarebbero insufficienti: pagine con rendering JavaScript, moduli, schermate, PDF, flussi di accesso, flussi CAPTCHA/protezione bot e navigazione in più passaggi. Esegue un vero browser cloud Steel tramite la CLI Steel. Da utilizzare quando l'agente deve visitare, fare clic, digitare, eseguire lo scraping, eseguire screenshot o estrarre ora. Non utilizzare per scrivere codice SDK/API Steel riutilizzabile; utilizzare Steel-developer per il codice. Se un'attività live fallisce, passa al debug della sessione d'acciaio; se le prove indicano il rilevamento di bot, proxy, CAPTCHA o identità, passa all'affidabilità dell'acciaio.
