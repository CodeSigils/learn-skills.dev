Verwenden Sie diesen Skill für Live-Webaufgaben, bei denen WebFetch oder Curl fehlschlagen oder nicht ausreichen würden: JavaScript-gerenderte Seiten, Formulare, Screenshots, PDFs, Anmeldeabläufe, CAPTCHA-/Bot-Schutzabläufe und mehrstufige Navigation. Über die Steel-CLI wird ein echter Steel-Cloud-Browser ausgeführt. Verwenden Sie diese Option, wenn der Agent „Jetzt“ besuchen, klicken, eingeben, kratzen, einen Screenshot erstellen oder extrahieren soll. Nicht zum Schreiben von wiederverwendbarem Steel SDK/API-Code verwenden; Verwenden Sie Steel-Developer für Code. Wenn eine Live-Aufgabe fehlschlägt, übergeben Sie sie an Steel-Session-Debugging. Wenn Beweise auf Bot-Erkennung, Proxys, CAPTCHA oder Identität hinweisen, übergeben Sie diese an Steel-Reliability.
