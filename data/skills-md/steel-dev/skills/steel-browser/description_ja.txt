このスキルは、JavaScript でレンダリングされたページ、フォーム、スクリーンショット、PDF、ログイン フロー、CAPTCHA/ボット保護フロー、マルチステップ ナビゲーションなど、WebFetch や Curl が失敗するか不十分なライブ Web タスクに使用します。 Steel CLI を通じて実際の Steel クラウド ブラウザを実行します。エージェントが今すぐ訪問、クリック、入力、スクレイピング、スクリーンショット、または抽出を行う必要がある場合に使用します。再利用可能な Steel SDK/API コードの作成には使用しないでください。コードには Steel-Developer を使用します。ライブタスクが失敗した場合は、steel-session-debugging に引き渡します。証拠がボット検出、プロキシ、CAPTCHA、または ID を示している場合は、スチールの信頼性に任せてください。
