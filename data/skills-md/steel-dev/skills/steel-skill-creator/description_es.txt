Utilice esta habilidad cuando el usuario quiera convertir un flujo de trabajo recurrente del navegador en una habilidad de agente parametrizada y reutilizable, especialmente cuando la tarea tiene entradas concretas y una salida clara, como raspaduras programadas, envíos de formularios, extracción de datos, flujos de monitoreo, sondeos de precios o informes de inicio de sesión. No lo utilice para tareas web puntuales; Utilice el navegador Steel.
