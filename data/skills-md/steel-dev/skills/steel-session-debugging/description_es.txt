Utilice esta habilidad cuando el usuario proporciona una ID de sesión de Steel fallida, una ejecución de automatización fallida, un tiempo de espera, un error del navegador, una página bloqueada o un resultado inesperado y desea un diagnóstico respaldado por evidencia de metadatos de sesión, registros del navegador, registros de agentes sin procesar, rastros semánticos, enlaces de reproducción, capturas de pantalla, fallas de red o errores. No lo utilice para la mitigación de bots de primer paso; recopile pruebas aquí y luego transfiéralas a Steel-reliability para correcciones de proxy, CAPTCHA, identidad o anti-bot.
