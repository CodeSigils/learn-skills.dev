Как написать, протестировать и развернуть приложение с помощью Prisma Composer (@prisma/composer`): объявить сервисы с помощью `compute()` и типизировать зависимости, определить контракты RPC, составить модули, объявить входные данные службы (конфигурация и секреты как одна схема, прочитать обратно с помощью `input()`), составить готовые модули cron/storage/streams, предоставить необработанную S3-совместимую корзину хранилища объектов с помощью `bucket()`, найти расширения (npm) пакеты с именем prisma-composer-*), протестируйте с помощью mockService/bootstrapService, запустите все приложение локально с помощью prisma-composer dev и завершите его журналы с помощью prisma-composer log, а затем разверните с помощью prisma-composer Deploy (этапы, уничтожение). Используйте при создании приложения Prisma, подключении зависимости службы, добавлении базы данных Postgres, добавлении запланированных заданий/хранилища BLOB-объектов/потоков событий/необработанной корзины, написании тестов для составных служб, локальном запуске приложения, чтении его журналов или развертывании/удалении среды. Триггеры на "prisma композитор", "@prisma/composer", "prisma app", "compute()", "service.load()", "module()", "contract()", "mockService", "bootstrapService", "prisma-composer dev", "prisma-composer log", "prisma-composer Deploy", "--stage", "--fresh", "--tail", "prisma-composer уничтожить", «призма-композитор-», «ведро()».
