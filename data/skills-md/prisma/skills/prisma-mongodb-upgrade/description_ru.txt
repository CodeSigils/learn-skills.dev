Руководство по принятию решений и миграции для проектов Prisma ORM MongoDB на v6, у которых нет пути обновления до v7. Используйте, когда проект MongoDB запрашивает обновление Prisma, когда в проекте появляется сообщение «обновление до prisma 7» с поставщиком = «mongodb» или при оценке перехода на Prisma Next. Запускает «обновление prisma mongodb», «prisma 7 mongodb», «миграция prisma mongodb», «prisma next mongodb».
