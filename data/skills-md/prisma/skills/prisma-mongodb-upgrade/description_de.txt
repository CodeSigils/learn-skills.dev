Entscheidungs- und Migrationsleitfaden für Prisma ORM MongoDB-Projekte auf Version 6, für die es keinen Upgrade-Pfad auf Version 7 gibt. Wird verwendet, wenn ein MongoDB-Projekt nach einem Upgrade von Prisma fragt, wenn in einem Projekt mit Provider = „mongodb“ „Upgrade auf Prisma 7“ angezeigt wird oder wenn ein Wechsel zu Prisma Next evaluiert wird. Wird ausgelöst bei „Upgrade von Prisma Mongodb“, „Prisma 7 Mongodb“, „Mongodb Prisma Migration“, „Prisma Next Mongodb“.
