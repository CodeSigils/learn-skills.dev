Напишите запросы Prisma Next — выберите полосу (`db.orm.<Model>` для CRUD и включает в себя, `db.sql.<table>` SQL builder для форм построителя наборов, которые ORM не выражает), фильтрация / проект / сортировка / разбиение на страницы, отношения быстрой загрузки с помощью `.include(...)`, транзакции через `db.transaction(...)`, агрегирование через `.aggregate(...)`. Используйте для запроса, где, выберите, orderBy, возьмите, пропустите, включите, нетерпеливую загрузку, сначала, все, подсчитать, агрегировать, создать, обновить, удалить, добавить, вернуть, транзакцию, db.transaction, стиль дождя, стиль kysely, клиент prisma, db.close, скрипт, скрипт не выйдет, зависает, закройте соединение, db.end, пул.конец, ожидайте использования. Также охватывает потребление результатов (`.all()` — это Thenable — просто `await`; никакой помощник `collect()` / `toArray()` не требуется), семантику одиночного потребления (`RUNTIME.ITERATOR_CONSUMED`), агрегированную возможность обнуления (`count` возвращает `number`, `sum/avg/min/max` возвращает `number | null` для семантики SQL) и условия диапазона (цепочка предложений `.where()` или использование `and(...)` — `.between(...)` нет).
