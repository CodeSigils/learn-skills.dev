Adoptez Prisma Next dans un nouveau projet, sur une base de données existante ou comme premier pas après qu'un outil d'amorçage vous ait déposé dans un échafaudage. Utiliser pour "que puis-je faire avec Prisma Next", "que puis-je faire ensuite avec Prisma", "par où commencer", "que dois-je faire en premier", "je viens d'exécuter createprisma", "createprisma", "npx createprisma", "npx create-prisma", "premiers pas", "première requête", "J'ai un projet Prisma Next échafaudé et maintenant" ; pour la configuration greenfield de «pnpm dlx prisma-next init» ; et pour « prisma-next contract infer » + « db sign » par rapport à une base de données existante. Couvre également l'orientation du premier arc de connexion-écriture-lecture, les commandes quotidiennes (`contract submit`, `db init`, `db update`, `migration plan`, `migrate`, `db schema`, `db verify`) et le routage vers `prisma-next-contract` / `prisma-next-queries` / `prisma-next-runtime` pour le prochain bouger. Indicateurs : --target, --authoring, --schema-path, --probe-db, --output.
