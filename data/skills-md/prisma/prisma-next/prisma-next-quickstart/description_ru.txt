Используйте Prisma Next в новом проекте, в существующей базе данных или в качестве первого шага после того, как инструмент начальной загрузки отправил вас в эшафот. Используйте для фраз «что я могу делать с Prisma Next», «что я могу делать дальше с Prisma», «с чего мне начать», «что мне делать в первую очередь», «только что запустил createprisma», «createprisma», «npx createprisma», «npx create-prisma», «первые шаги», «первый запрос», «У меня есть готовый проект Prisma Next, что теперь»; для настройки `pnpm dlx prisma-next init` с нуля; и для `prisma-next Contract Infer` + `db Sign` для существующей базы данных. Также охватывает ориентацию первой дуги соединение-запись-чтение, повседневные команды («contractemit», «db init», «db update», «migration plan», «migrate», «db Schema», «dbverify») и маршрутизацию к «prisma-next-contract» / «prisma-next-queries» / «prisma-next-runtime» для следующего перемещения. Флаги: --target, --authoring, --schema-path, --probe-db, --output.
