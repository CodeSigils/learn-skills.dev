Используйте Prisma Next с проектом Supabase через `@prisma-next/extension-supabase` — подключите `extensionPacks: [supabasePack]`, объявите межпространственные FK для `supabase:auth.AuthUser`, создайте политики RLS (предикаты `policy_select` / `policy_update` / `@@rls`, `auth.uid()`), создайте `db.ts` с фабрикой `supabase()`, привязка ролей для каждого запроса (`asUser(jwt)`/`asAnon()`/`asServiceRole()`), запрос `auth.*`/ `storage.*` через корень администратора `db.supabase` и проверка JWT (`jwksUrl` для текущих проектов/`jwtSecret` для устаревшего HS256). Использовать для supabase, RLS, безопасности на уровне строк, политики, привязки роли, анона, аутентификации, service_role, auth.users, auth.uid(), JWT, JWKS, SUPABASE_JWKS_URL, SUPABASE_JWT_SECRET, InvalidJwtError, SupabaseConfigError, RoleBoundDb, пула сеансов, supabase:auth.AuthUser, @prisma-next/extension-supabase.
