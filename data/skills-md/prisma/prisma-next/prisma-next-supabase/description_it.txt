Utilizza Prisma Next con un progetto Supabase tramite `@prisma-next/extension-supabase`: collega `extensionPacks: [supabasePack]`, dichiara FK tra spazi in `supabase:auth.AuthUser`, crea policy RLS (`policy_select` / `policy_update` / `@@rls`, predicati `auth.uid()`), crea `db.ts` con il factory `supabase()`, associare i ruoli per richiesta (`asUser(jwt)` / `asAnon()` / `asServiceRole()`), eseguire query su `auth.*` / `storage.*` tramite la root di amministrazione `db.supabase` e convalidare i JWT (`jwksUrl` per i progetti correnti / `jwtSecret` per legacy HS256). Utilizzare per supabase, RLS, sicurezza a livello di riga, policy, associazione di ruoli, anon, authenticated, service_role, auth.users, auth.uid(), JWT, JWKS, SUPABASE_JWKS_URL, SUPABASE_JWT_SECRET, InvalidJwtError, SupabaseConfigError, RoleBoundDb, session pooler, supabase:auth.AuthUser, @prisma-next/extension-supabase.
