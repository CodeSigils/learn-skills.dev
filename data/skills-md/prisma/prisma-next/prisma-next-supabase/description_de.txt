Verwenden Sie Prisma Next mit einem Supabase-Projekt über „@prisma-next/extension-supabase“ – verkabeln Sie „extensionPacks: [supabasePack]“, deklarieren Sie bereichsübergreifende FKs für „supabase:auth.AuthUser“, erstellen Sie RLS-Richtlinien („policy_select“ / „policy_update“ / „@@rls“, „auth.uid()“-Prädikate), erstellen `db.ts` mit der `supabase()`-Factory, binden Sie Rollen pro Anfrage (`asUser(jwt)` / `asAnon()` / `asServiceRole()`), fragen Sie `auth.*` / `storage.*` über das `db.supabase`-Administratorstammverzeichnis ab und validieren Sie JWTs (`jwksUrl` für aktuelle Projekte / `jwtSecret` für Legacy).
