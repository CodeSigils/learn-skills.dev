استخدم Prisma Next مع مشروع Supabase عبر `@prisma-next/extension-supabase` - قم بتوصيل حزم الامتداد: [supabasePack]`، قم بتعريف FKs عبر الفضاء إلى `supabase:auth.AuthUser`، مؤلف سياسات RLS (`policy_select` / `policy_update` / `@@rls`، `auth.uid()` المسندات)، البناء `db.ts` مع مصنع `supabase()`، وربط الأدوار لكل طلب (`asUser(jwt)` / `asAnon()` / `asServiceRole()`)، والاستعلام عن `auth.*` / `storage.*` عبر جذر المسؤول `db.supabase`، والتحقق من صحة JWTs (`jwksUrl` للمشاريع الحالية / `jwtSecret` للمشاريع القديمة HS256). يستخدم لـ supabase وRLS وأمان مستوى الصف والسياسة وربط الأدوار وanon والمصادقة وservice_role وauth.users وauth.uid() وJWT وJWKS وSUPABASE_JWKS_URL وSUPABASE_JWT_SECRET وInvalidJwtError وSupabaseConfigError وRoleBoundDb وتجمع الجلسة، Supabase:auth.AuthUser، @prisma-next/extension-supabase.
