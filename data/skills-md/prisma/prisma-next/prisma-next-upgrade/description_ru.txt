Обновите Prisma Next в своем приложении. Перемещает каждую зависимость `@prisma-next/*` из версии, закрепленной в файле блокировки, на запрошенную цель (или npm `latest`), применяет все необходимые шаги трансляции кода из инструкций по обновлению для каждого перехода, проверяет с помощью собственной проверки типов + тестов проекта и фиксирует каждый второстепенный шаг самостоятельно. Используйте, когда пользователь просит «обновить Prisma Next», «улучшить Prisma Next», «перейти на Prisma Next X.Y» или просит агента разобраться с незначительным дефектом `@prisma-next/*` в его приложении.
