Umfassender Leitfaden für die Entwicklung mit Prisma 8 (Prisma Next), der vertrag‑first Datenebene. Verwenden Sie ihn, wann immer Sie an Prisma‑Code in einem Projekt arbeiten, das Prisma nutzt — beim Authoring oder Bearbeiten des Datenvertrags (contract.prisma, PSL, TypeScript‑Builder), bei Migrationen, Abfragen (db.orm / db.sql), Runtime‑Verdrahtung (db.ts, Middleware, DATABASE_URL), Build‑Tool‑Integration, Supabase / RLS, beim Lesen von PN‑* strukturierten Fehlern oder beim Einreichen von Feedback — und für Orientierungsfragen wie „Was ist Prisma Next?“ oder zum Vergleich mit anderen ORMs. Hinweise, dass diese Fähigkeit zutrifft: @internal/*‑Imports, prisma.config.ts, contract.prisma / contract.json / contract.d.ts, das prisma‑next‑CLI, PN‑*‑Fehlercodes. Enthält zudem das Upgrade von Prisma in einem Projekt — „upgrade Prisma 8“, „bump Prisma Next“, „move to Prisma Next X.Y“ oder das Handling eines @internal/*‑Versionssprungs, in einer Consumer‑App oder in einem Erweiterungspaket. Gilt nicht für Prisma ORM 7 oder früher (schema.prisma + @prisma/client‑Projekte).
