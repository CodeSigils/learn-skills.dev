Prisma 8(Prisma Next)으로 구축하기 위한 포괄적인 가이드, 계약‑우선 데이터 레이어입니다. Prisma 코드를 사용하는 프로젝트에서 다음 작업을 할 때마다 이 가이드를 사용하세요: 데이터 계약(contract.prisma, PSL, TypeScript 빌더) 작성·수정, 마이그레이션, 쿼리(db.orm / db.sql), 런타임 연결(db.ts, 미들웨어, DATABASE_URL), 빌드 도구 통합, Supabase / RLS, PN-* 형태의 구조화된 오류 읽기, 피드백 제출 등. 또한 “Prisma Next가 뭐지?” 같은 입문 질문이나 다른 ORM과의 비교에도 활용할 수 있습니다. 이 스킬이 적용된다는 신호는 @internal/* 임포트, prisma.config.ts, contract.prisma / contract.json / contract.d.ts, prisma‑next CLI, PN-* 오류 코드 등을 포함합니다. 프로젝트에서 Prisma를 업그레이드하는 경우도 다룹니다—예: “Prisma 8 업그레이드”, “Prisma Next 버전 올리기”, “Prisma Next X.Y 로 이동”, 혹은 소비자 앱이나 확장 패키지에서 @internal/* 버전 bump 처리 등. Prisma ORM 7 이하( schema.prisma + @prisma/client 프로젝트)에는 적용되지 않습니다.
