Полное руководство по работе с Prisma 8 (Prisma Next), слоем данных, построенным по контракту. Используйте его каждый раз, когда работаете с кодом Prisma в проекте, где он применяется — при написании или редактировании контракта данных (contract.prisma, PSL, TypeScript‑билдеры), миграциях, запросах (db.orm / db.sql), настройке выполнения (db.ts, middleware, DATABASE_URL), интеграции с инструментами сборки, Supabase / RLS, чтении структурированных ошибок PN‑*, а также при отправке обратной связи — и для вопросов‑ориентиров, вроде «что такое Prisma Next» или сравнения с другими ORM. Признаки того, что этот навык применим: импорты @internal/*, prisma.config.ts, contract.prisma / contract.json / contract.d.ts, CLI prisma‑next, коды ошибок PN‑*. Также охватывается обновление Prisma в проекте — «обновить Prisma 8», «повысить версию Prisma Next», «перейти на Prisma Next X.Y», либо работа с повышением версии @internal/* в клиентском приложении или в пакете‑расширении. Не относится к Prisma ORM 7 и ниже (проекты с schema.prisma + @prisma/client).
