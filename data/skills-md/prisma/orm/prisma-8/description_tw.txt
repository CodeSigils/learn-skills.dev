Prisma 8（Prisma Next）合約優先資料層的完整建置指南。於任何使用 Prisma 的專案中處理 Prisma 程式碼時皆可使用——編寫或編輯資料合約（contract.prisma、PSL、TypeScript 建構器）、遷移、查詢（db.orm / db.sql）、執行時配線（db.ts、middleware、DATABASE_URL）、建構工具整合、Supabase / RLS、閱讀 PN-* 結構化錯誤，或提交回饋——以及「什麼是 Prisma Next」或與其他 ORM 比較等導向問題。以下情況顯示此技能適用：@internal/* 匯入、prisma.config.ts、contract.prisma / contract.json / contract.d.ts、prisma‑next CLI、PN-* 錯誤代碼。同時也涵蓋在專案中升級 Prisma——「升級 Prisma 8」、「升級 Prisma Next」、「遷移至 Prisma Next X.Y」或處理 @internal/* 版本升級，無論在消費者應用或擴充套件中。此指南不適用於 Prisma ORM 7 以前（schema.prisma + @prisma/client 專案）。
