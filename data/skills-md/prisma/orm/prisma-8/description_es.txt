Guía completa para trabajar con Prisma 8 (Prisma Next), la capa de datos basada en contratos. Úsala siempre que trabajes con código de Prisma en un proyecto que lo utilice — al crear o editar el contrato de datos (contract.prisma, PSL, generadores TypeScript), migraciones, consultas (db.orm / db.sql), cableado en tiempo de ejecución (db.ts, middleware, DATABASE_URL), integración con herramientas de compilación, Supabase / RLS, lectura de errores estructurados PN‑*, o al enviar comentarios — y para preguntas de orientación como “¿qué es Prisma Next?” o comparaciones con otros ORM. Señales de que esta habilidad es aplicable: importaciones @internal/*, prisma.config.ts, contract.prisma / contract.json / contract.d.ts, la CLI prisma‑next, códigos de error PN‑*. También cubre la actualización de Prisma en un proyecto — “actualizar Prisma 8”, “actualizar Prisma Next”, “migrar a Prisma Next X.Y”, o manejar un incremento de versión @internal/*, en una aplicación consumidora o en un paquete de extensión. No se aplica a Prisma ORM 7 o versiones anteriores (proyectos schema.prisma + @prisma/client).
