دليل شامل للبناء باستخدام Prisma 8 (Prisma Next)، طبقة البيانات القائمة على العقد أولاً. استخدمه كلما عملت على شفرة Prisma في مشروع يستخدمها — كتابة أو تعديل عقد البيانات (contract.prisma، PSL، منشئي TypeScript)، الترقيات، الاستعلامات (db.orm / db.sql)، ربط وقت التشغيل (db.ts، middleware، DATABASE_URL)، تكامل أداة البناء، Supabase / RLS، قراءة الأخطاء المهيكلة PN‑*، أو تقديم ملاحظات — وللأسئلة التوجيهية مثل «ما هو Prisma Next» أو المقارنات مع ORM أخرى. الإشارات التي تدل على تطبيق هذه المهارة: استيرادات @internal/*، prisma.config.ts، contract.prisma / contract.json / contract.d.ts، واجهة سطر الأوامر prisma‑next، رموز الأخطاء PN‑*. كما يغطي ترقية Prisma في مشروع — «ترقية Prisma 8»، «رفع نسخة Prisma Next»، «الانتقال إلى Prisma Next X.Y»، أو التعامل مع زيادة نسخة @internal/*، في تطبيق مستهلك أو في حزمة امتداد. لا ينطبق على Prisma ORM 7 أو أقدم (مشاريع schema.prisma + @prisma/client).
