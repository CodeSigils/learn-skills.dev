Mettez à niveau Prisma Next dans votre extension. Transfère chaque dépendance `@internal/*` vers la cible demandée (ou npm `latest`), exécute les instructions de mise à niveau par transition pour l'extension SPI (cycle de vie du middleware, désabonnement des codecs/outils de migration/composants de framework, forme de migration de départ sur le disque), vérifie que les broches sont correctement exactes via `prisma-8-check-pins`, exécute la propre vérification de type et les tests de l'extension et valide chaque étape mineure sur son propre. À utiliser lorsque l'utilisateur demande de « mettre à niveau Prisma Next » dans un package d'extension, ou de mettre à jour les dépôts « @internal/* » d'une extension vers un nouveau mineur.
