Обновите Prisma Next в своем расширении. Направляет каждую зависимость `@internal/*` на запрошенную цель (или npm `latest`), запускает инструкции по обновлению для каждого перехода для расширения SPI (жизненный цикл промежуточного программного обеспечения, изменение кодека/инструментов миграции/фреймворка-компонентов, исходную миграцию на диске), проверяет правильность и точность контактов с помощью `prisma-8-check-pins`, запускает собственную проверку типов и тесты расширения, а также фиксирует каждый второстепенный шаг самостоятельно. Используйте, когда пользователь просит «обновить Prisma Next» в пакете расширения или обновить deps `@internal/*` расширения до нового второстепенного значения.
