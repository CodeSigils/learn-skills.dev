Aktualisieren Sie Prisma Next in Ihrer Erweiterung. Überträgt jede „@internal/*“-Abhängigkeit auf das angeforderte Ziel (oder npm „latest“), führt die Upgrade-Anweisungen pro Übergang für die Erweiterungs-SPI aus (Middleware-Lebenszyklus, Codec/Migration-Tools/Framework-Components-Churn, Seed-Migration-On-Disk-Shape), überprüft die korrekte Genauigkeit der Pins über „prisma-8-check-pins“, führt die eigene Typprüfung und Tests der Erweiterung durch und schreibt jeden kleineren Schritt darauf fest besitzen. Verwenden Sie diese Option, wenn der Benutzer in einem Erweiterungspaket ein „Upgrade von Prisma Next“ anfordert oder die „@internal/*“-Abhängigkeiten einer Erweiterung auf eine neue Nebenversion aktualisieren möchte.
