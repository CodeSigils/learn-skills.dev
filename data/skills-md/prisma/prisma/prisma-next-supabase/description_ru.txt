Используйте Prisma Next с проектом Supabase через `@internal/extension-supabase` — подключите `extensions: [supabasePack]`, объявите межпространственные FK для `supabase:auth.AuthUser`, создайте политики RLS (предикаты `policy_select` / `policy_update` / `@@rls`, `auth.uid()`), постройте `db.ts` с Фабрика `supabase()`, привязка ролей для каждого запроса (`asUser(jwt)`/`asAnon()`/`asServiceRole()`), запрос `auth.*`/``storage.*` через корень администратора `db.asServiceRole().supabase` и проверка JWT (`jwksUrl` для текущих проектов/`jwtSecret` для устаревшего HS256). Использование для supabase, RLS, безопасности на уровне строк, политики, привязки ролей, анона, аутентификации, service_role, auth.users, auth.uid(), JWT, JWKS, SUPABASE_JWKS_URL, SUPABASE_JWT_SECRET, SUPABASE.JWT_INVALID, SUPABASE.CONFIG_INVALID, RoleBoundDb, пула сеансов, supabase:auth.AuthUser, @internal/extension-supabase.
