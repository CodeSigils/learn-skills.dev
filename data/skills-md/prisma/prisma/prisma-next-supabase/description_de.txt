Verwenden Sie Prisma Next mit einem Supabase-Projekt über „@internal/extension-supabase“ – verkabeln Sie „extensions: [supabasePack]“, deklarieren Sie bereichsübergreifende FKs für „supabase:auth.AuthUser“, erstellen Sie RLS-Richtlinien („policy_select“ / „policy_update“ / „@@rls“, „auth.uid()“-Prädikate), erstellen `db.ts` mit der `supabase()`-Factory, binden Sie Rollen pro Anfrage (`asUser(jwt)` / `asAnon()` / `asServiceRole()`), fragen Sie `auth.*` / `storage.*` über das Admin-Root `db.asServiceRole().supabase` ab und validieren Sie JWTs (`jwksUrl` für aktuelle Projekte / `jwtSecret`). für ältere HS256).
