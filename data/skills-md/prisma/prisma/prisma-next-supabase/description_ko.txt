`@internal/extension-supabase`를 통해 Supabase 프로젝트와 함께 Prisma Next 사용 — `extensions: [supabasePack]` 연결, 교차 공간 FK를 `supabase:auth.AuthUser`로 선언, RLS 정책(`policy_select` / `policy_update` / `@@rls`, `auth.uid()` 조건자) 작성, `supabase()`를 사용하여 `db.ts` 빌드 팩토리, 요청당 역할 바인딩(`asUser(jwt)` / `asAnon()` / `asServiceRole()`), `db.asServiceRole().supabase` 관리 루트를 통해 `auth.*` / `storage.*` 쿼리 및 JWT 유효성 검사(현재 프로젝트의 경우 `jwksUrl` / 레거시 HS256의 경우 `jwtSecret`). supabase, RLS, 행 수준 보안, 정책, 역할 바인딩, anon, authenticated, service_role, auth.users, auth.uid(), JWT, JWKS, SUPABASE_JWKS_URL, SUPABASE_JWT_SECRET, SUPABASE.JWT_INVALID, SUPABASE.CONFIG_INVALID, RoleBoundDb, 세션 풀러에 사용 supabase:auth.AuthUser, @internal/extension-supabase.
