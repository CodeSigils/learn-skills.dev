Écrivez des requêtes Prisma Next pour Postgres, SQLite ou Mongo — choisissez une voie (Postgres/SQLite `db.orm.<Model>` + `db.sql.<table>`; Mongo `db.orm.<root>` + `db.query.from(...)` générateur de pipeline), filtrez/projetez/triez/paginez, chargez avec impatience avec `.include(...)`, Postgres/SQLite `db.transaction(...)`, Postgres/SQLite ORM `.aggregate(...)`, agrégations Mongo via le générateur de requêtes, accesseurs prenant en charge les espaces de noms (`db.orm.<ns>.<Model>`, `db.sql.<ns>.<table>`). Déclencheurs : requête, où, correspondance, sélection, projet, orderBy, prendre, ignorer, inclure, rechercher, premier, tout, compter, agréger, grouper, créer, mettre à jour, supprimer, insérer, renvoyer, transaction, db.close, démontage de script, variante, polymorphisme, style bruine, style kysely. Notes : `.all()` est un Thenable (il suffit de l'attendre), les itérateurs sont à usage unique (`RUNTIME.ITERATOR_CONSUMED`), le `count` de Postgres est `number` tandis que sum/avg/min/max sont `number | null`, les plages utilisent `.where()` ou `and(...)` chaînés (pas de `.between(...)`).
