Mettez à niveau Prisma Next dans votre application. Transpose chaque dépendance `@internal/*` de la version épinglée dans le fichier de verrouillage à la cible demandée (ou npm `latest`), applique toutes les étapes de traduction de code requises à partir des instructions de mise à niveau par transition, valide avec la propre vérification de type + tests du projet et valide chaque étape mineure seule. À utiliser lorsque l'utilisateur demande de « mettre à niveau Prisma Next », de « déplacer Prisma Next », de « passer à Prisma Next X.Y » ou demande à un agent de gérer un problème mineur « @internal/* » dans son application.
