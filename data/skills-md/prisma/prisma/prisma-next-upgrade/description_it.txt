Aggiorna Prisma Next nella tua app. Applica ogni dipendenza `@internal/*` dalla versione bloccata nel file di lock alla destinazione richiesta (o npm `latest`), applica tutti i passaggi di traduzione del codice richiesti dalle istruzioni di aggiornamento per transizione, convalida con il typecheck + test del progetto ed esegue il commit di ogni passaggio minore da solo. Da utilizzare quando l'utente chiede di "aggiornare Prisma Next", "bump Prisma Next", "spostarsi a Prisma Next X.Y" o chiede a un agente di gestire un piccolo bump `@internal/*` nella propria app.
