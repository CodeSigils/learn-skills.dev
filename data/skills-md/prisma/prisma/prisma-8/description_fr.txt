Guide complet pour construire avec Prisma 8 (Prisma Next), la couche de données axée sur le contrat. À utiliser chaque fois que vous travaillez sur du code Prisma dans un projet qui l'utilise : création ou modification du contrat de données (contract.prisma, PSL, constructeurs TypeScript), migrations, requêtes (db.orm / db.sql), câblage d'exécution (db.ts, middleware, DATABASE_URL), intégration d'outils de construction, Supabase / RLS, lecture d'erreurs structurées PN-* ou dépôt de commentaires - et pour des questions d'orientation telles que "qu'est-ce que Prisma Next" ou des comparaisons avec d'autres ORM. Signale que cette compétence s'applique : @internal/* importations, prisma-next.config.ts, contract.prisma / contract.json / contract.d.ts, la CLI prisma-next, les codes d'erreur PN-*. Ne s'applique pas à Prisma ORM 7 ou version antérieure (projets schema.prisma + @prisma/client).
