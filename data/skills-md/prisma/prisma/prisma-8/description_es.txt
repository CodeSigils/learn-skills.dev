Guía completa para construir con Prisma 8 (Prisma Next), la capa de datos de primer contrato. Úselo siempre que trabaje con código Prisma en un proyecto que lo utilice: creación o edición del contrato de datos (contract.prisma, PSL, constructores de TypeScript), migraciones, consultas (db.orm/db.sql), cableado de tiempo de ejecución (db.ts, middleware, DATABASE_URL), integración de herramientas de compilación, Supabase/RLS, lectura de errores estructurados PN-* o presentación de comentarios, y para preguntas de orientación como "¿qué es Prisma Next" o comparaciones con otros? ORM. Señales de que se aplica esta habilidad: @internal/* imports, prisma-next.config.ts, contract.prisma / contract.json / contract.d.ts, prisma-next CLI, códigos de error PN-*. No se aplica a Prisma ORM 7 o versiones anteriores (proyectos esquema.prisma + @prisma/client).
