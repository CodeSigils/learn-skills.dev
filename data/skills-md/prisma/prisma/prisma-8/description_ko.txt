계약 우선 데이터 레이어인 Prisma 8(Prisma Next)을 사용하여 구축하기 위한 종합 가이드입니다. Prisma 코드를 사용하는 프로젝트에서 데이터 계약 작성 또는 편집(contract.prisma, PSL, TypeScript 빌더), 마이그레이션, 쿼리(db.orm / db.sql), 런타임 연결(db.ts, 미들웨어, DATABASE_URL), 빌드 도구 통합, Supabase/RLS, PN-* 구조 오류 읽기 또는 피드백 제출 등 Prisma 코드를 작업할 때마다 사용하고 "Prisma Next가 무엇인지"와 같은 방향 질문 또는 다른 항목과의 비교에 사용합니다. ORM. 이 기술이 적용된다는 신호: @internal/* 가져오기, prisma-next.config.ts, contract.prisma / contract.json / contract.d.ts, prisma-next CLI, PN-* 오류 코드. Prisma ORM 7 이하(schema.prisma + @prisma/client 프로젝트)에는 적용되지 않습니다.
