دليل شامل للبناء باستخدام Prisma 8 (Prisma Next)، طبقة البيانات ذات العقد الأول. استخدمه عند العمل على كود Prisma في مشروع يستخدمه - تأليف عقد البيانات أو تحريره (contract.prisma، PSL، TypeScript builders)، عمليات الترحيل، الاستعلامات (db.orm / db.sql)، أسلاك وقت التشغيل (db.ts، البرامج الوسيطة، DATABASE_URL)، تكامل أدوات البناء، Supabase / RLS، قراءة الأخطاء الهيكلية PN-*، أو حفظ التعليقات - ولأسئلة التوجيه مثل "ما هو Prisma Next" أو مقارنات مع ORMs الأخرى. الإشارات التي تنطبق عليها هذه المهارة: @internal/* imports، prisma-next.config.ts، Contract.prisma / Contract.json / Contract.d.ts، prisma-next CLI، PN-* رموز الخطأ. لا ينطبق على Prisma ORM 7 أو الإصدارات الأقدم (مشاريع schema.prisma + @prisma/client).
