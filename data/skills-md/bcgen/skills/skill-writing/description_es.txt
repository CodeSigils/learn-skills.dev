Crea una nueva habilidad, para una colección de habilidades, un proyecto o su configuración personal, recopilando requisitos que incluyen dónde reside la habilidad, redactando SKILL.md con convenciones aplicadas, verificando colisiones el nombre y estructurando un plan de prueba de aceptación. Úselo cuando el usuario quiera crear, escribir o agregar una habilidad, o cuando otra habilidad (codificar, retro) entrega un procedimiento de varios pasos para capturar como habilidad.
