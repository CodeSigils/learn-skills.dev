Lea hojas de datos y documentos técnicos en PDF con "pcb scan". Úselo cuando el usuario proporciona una ruta PDF local o una hoja de datos/documento `http(s)`, cuando una tarea requiere leer, resumir, extraer información o responder preguntas sobre una hoja de datos o un PDF técnico, o cuando un símbolo KiCad / `.kicad_sym` proporciona una propiedad `Hoja de datos` para resolver. Ejecute `pcb scan <input>` en bash, trate la salida estándar como la ruta `.md` generada y luego lea ese archivo de rebajas.
