Lesen Sie Datenblätter und technische PDF-Dokumente mit „PCB-Scan“. Verwenden Sie diese Option, wenn der Benutzer einen lokalen PDF-Pfad oder eine „http(s)“-Datenblatt-/Dokument-URL angibt, wenn eine Aufgabe das Lesen, Zusammenfassen, Extrahieren von Informationen aus oder Beantworten von Fragen zu einem Datenblatt oder einer technischen PDF-Datei erfordert oder wenn ein KiCad-Symbol / „.kicad_sym“ eine aufzulösende „Datenblatt“-Eigenschaft bereitstellt. Führen Sie „pcb scan <input>“ in Bash aus, behandeln Sie stdout als den generierten „.md“-Pfad und lesen Sie dann diese Markdown-Datei.
