Trozo no interactivo y puesta en escena de rango de línea con la CLI `git-hunk`. Úselo cuando un usuario desee confirmaciones atómicas, preparación selectiva, preparación parcial de fragmentos o un reemplazo seguro para el agente para `git add -p` o `git commit -p`, especialmente cuando `git-hunk` está disponible en el repositorio actual o en `PATH`.
