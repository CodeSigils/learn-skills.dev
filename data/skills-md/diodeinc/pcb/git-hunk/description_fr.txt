Mise en scène non interactive de morceaux et de plages de lignes avec la CLI `git-hunk`. À utiliser lorsqu'un utilisateur souhaite des validations atomiques, une mise en scène sélective, une mise en scène partielle ou un remplacement sécurisé par agent pour `git add -p` ou `git commit -p`, en particulier lorsque `git-hunk` est disponible dans le dépôt actuel ou sur `PATH`.
