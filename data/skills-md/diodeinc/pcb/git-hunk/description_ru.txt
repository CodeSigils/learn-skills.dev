Неинтерактивная обработка фрагментов и строк с помощью CLI `git-hunk`. Используйте, когда пользователю нужны атомарные фиксации, выборочная подготовка, частичная подготовка фрагментов или безопасная для агента замена `git add -p` или `git commit -p`, особенно если `git-hunk` доступен в текущем репозитории или в `PATH`.
