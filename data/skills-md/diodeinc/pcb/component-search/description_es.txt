Busque y agregue componentes electrónicos, módulos y diseños de referencia a un proyecto Zener PCB. Úselo cuando diseñe una placa, módulo o subsistema y necesite encontrar piezas, subcircuitos reutilizables o diseños de referencia, ya sea por descripción funcional o MPN específico. Cubre `búsqueda de PCB` (registro:módulos, registro:componentes, web:componentes) y `nuevo componente de PCB` para importar componentes web a un espacio de trabajo.
