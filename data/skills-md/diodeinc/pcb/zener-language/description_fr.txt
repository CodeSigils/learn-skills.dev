Sémantique canonique Zener HDL, règles de package, manifestes et API stdlib de grande valeur. À utiliser avant la création, l'édition, la refactorisation ou la révision non triviale de `.zen` lorsque la tâche touche `Module()`, `io()`, `config()`, les importations, `pcb.toml`, `pcb.sum`, les interfaces ou unités stdlib ou les API de package inconnues. Lisez ceci avant de modifier au lieu de deviner.
