Crea progetti di riferimento di alta qualità per componenti elettronici in Zener. Da utilizzare durante la creazione di un tipico circuito applicativo, di un modulo sottocircuito riutilizzabile o di un progetto di riferimento per un circuito integrato, compreso lo studio della scheda tecnica, la strutturazione del progetto, la scelta dei componenti passivi, la scrittura del file README e l'iterazione fino a una build funzionante.
