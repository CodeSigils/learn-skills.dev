Srcwalk est le navigateur de code de l'agent : une CLI arborescente pour les cartes de dépôt, les lectures de fichiers volumineux prenant en charge les jetons, la recherche de symboles, les appelants/appelés, les dépôts, les vérifications d'impact et les explorations précises. Utilisez-le avant les lectures brutes ou grep pour le travail de structure du code. Exécutez d'abord `srcwalk guide` ; c'est la source de vérité du binaire installé.
