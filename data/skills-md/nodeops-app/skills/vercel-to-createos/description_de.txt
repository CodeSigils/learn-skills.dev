Migrieren Sie Next.js, Vite, React, Vue, Svelte und andere Webanwendungen von Vercel zu CreateOS. Analysiert vercel.json, ordnet Umgebungsvariablen zu, erkennt Framework- und Build-Einstellungen und stellt über den CreateOS MCP-Server auf CreateOS bereit. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer die Migration von Vercel, das Verlassen von Vercel, das Verschieben einer Bereitstellung von Vercel, das Ersetzen von Vercel erwähnt oder wenn ein Repository eine vercel.json-Datei enthält und der Benutzer die Bereitstellung an einem anderen Ort durchführen möchte. Verwenden Sie diese Option auch, wenn der Benutzer Bedenken hinsichtlich der Zuverlässigkeit, Preisgestaltung, Sicherheit oder des Vercel-Verstoßes äußert und eine Alternative wünscht.
