Monitora una richiesta pull Bitbucket aperta per ottenere feedback dal revisore, rispondi ai commenti, applica correzioni, risolvi thread tramite API e porta il PR allo stato pronto. Da utilizzare dopo aver creato un PR Bitbucket o quando l'utente chiede di controllare lo stato della revisione, "controlla il mio PR" o rispondere al feedback su un PR ospitato da Bitbucket.
