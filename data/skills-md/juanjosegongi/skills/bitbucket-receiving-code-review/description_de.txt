Überwachen Sie eine offene Bitbucket-Pull-Anfrage auf Feedback von Prüfern, reagieren Sie auf Kommentare, wenden Sie Korrekturen an, lösen Sie Threads über die API und bringen Sie die PR in einen Bereitschaftszustand. Verwenden Sie diese Option nach dem Erstellen einer Bitbucket-PR oder wenn der Benutzer den Überprüfungsstatus überprüfen, „meine PR überprüfen“ oder auf Feedback zu einer von Bitbucket gehosteten PR antworten möchte.
