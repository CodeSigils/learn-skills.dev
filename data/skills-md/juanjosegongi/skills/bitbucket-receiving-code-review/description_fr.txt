Surveillez une demande d'extraction Bitbucket ouverte pour obtenir les commentaires des évaluateurs, répondez aux commentaires, appliquez des correctifs, résolvez les fils de discussion via l'API et conduisez le PR jusqu'à un état prêt. À utiliser après la création d'un PR Bitbucket ou lorsque l'utilisateur demande de vérifier l'état de l'avis, de « vérifier mon PR » ou de répondre aux commentaires sur un PR hébergé par Bitbucket.
