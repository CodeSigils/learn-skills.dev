Esegue query ES|QL su Elastic Cloud/Kibana riutilizzando la sessione del browser autenticata dell'utente tramite MCP claude-in-chrome, senza richiedere una chiave API. Da utilizzare quando l'utente menziona Kibana, ES|QL, Elasticsearch, Elastic Cloud, chiede di eseguire query su log o indici o desidera esplorare i dati nel proprio cluster e dispone solo dell'accesso SSO.
