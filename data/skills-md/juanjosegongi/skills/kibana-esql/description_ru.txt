Выполняет запросы ES|QL к Elastic Cloud/Kibana, повторно используя аутентифицированный сеанс браузера пользователя через MCP claude-in-chrome, не требуя ключа API. Используйте, когда пользователь упоминает Kibana, ES|QL, Elasticsearch, Elastic Cloud, запрашивает журналы или индексы или хочет изучить данные в своем кластере и имеет доступ только для единого входа.
