공개 끌어오기 요청에 대해 단일 베이비시팅 패스를 실행합니다. 플랫폼(GitHub, Bitbucket 또는 Truora의 Bitbucket+betico)을 감지하고, 검토 및 CI 상태를 가져오고, 실행 가능한 피드백에 수정 사항을 적용하고, 스레드를 해결하고, PR을 플랫폼의 기본 준비 게이트에 전달합니다. `/loop`를 통해 케이던스에서 호출되도록 설계되었습니다. 사용자가 "내 PR 돌보기", "이 PR 보기", "내 PR 루프", "내 PR 확인"이라고 말하거나 병합을 직접 수행하지 않고 PR을 병합 방향으로 계속 이동하도록 요청할 때 사용합니다.
