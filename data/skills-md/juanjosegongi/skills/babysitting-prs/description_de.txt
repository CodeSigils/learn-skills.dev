Führt einen einzelnen Babysitter-Durchgang für eine offene Pull-Anfrage aus – erkennt die Plattform (GitHub, Bitbucket oder Truoras Bitbucket+Betico), ruft die Überprüfung und den CI-Status ab, wendet Korrekturen auf umsetzbares Feedback an, löst Threads auf und übergibt die PR an das native Ready-Gate der Plattform. Entwickelt, um in einer Kadenz über „/loop“ aufgerufen zu werden. Wird verwendet, wenn der Benutzer sagt: „Auf meine PR aufpassen“, „Diese PR ansehen“, „Meine PR durchschleifen“, „Meine PR überprüfen“ oder darum bittet, dass eine PR in Richtung Zusammenführung weitergeführt wird, ohne die Zusammenführung direkt durchzuführen.
