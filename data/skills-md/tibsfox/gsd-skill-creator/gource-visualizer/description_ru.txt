Создавайте анимированные визуализации системы управления версиями с помощью Gource. Этот навык отвечает за установку Gource и ffmpeg, обнаружение метрик репозитория, настройку на основе предустановок, генерацию журналов с одним и несколькими репозиториями, конвейер кодирования видео ffmpeg, безголовый рендеринг для серверных сред, генерацию подписей из тегов git, разрешение аватаров GitHub и доставку выходных данных GSD. Используйте этот навык всякий раз, когда пользователь хочет визуализировать историю репозитория, создать видео об эволюции кода, просмотреть анимацию временной шкалы проекта, создать видеоролики Gource, объединить несколько репозиториев в одну визуализацию или создать любую визуализацию системы управления версиями. Также срабатывает, когда пользователь упоминает «Gource», «визуализацию репозитория», «видео истории кода», «анимацию развития проекта» или просит «показать мне, что мы создали».
