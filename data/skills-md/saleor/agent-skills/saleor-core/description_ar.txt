الأجزاء الداخلية للواجهة الخلفية ومرجع السلوك. يغطي أسبقية الخصم، وتخصيص الخصم على مستوى الطلب عبر الخطوط (الحساب ثنائي المسار، وما تفعله واجهة برمجة التطبيقات وما لا تعرضه، وإشكالات شكل سطر الهدية)، وأوضاع توفر المخزون (القديم مقابل المباشر، 3.23+)، وقواعد واجهة مستخدم لوحة المعلومات، وشروط تشغيل خطاف الويب، ودلالات الحقل غير الطبيعية، وأدوات الترحيل. يُستخدم عند العمل مع خصومات Saleor أو توفر المخزون، أو إنشاء واجهة مستخدم للوحة المعلومات، أو إنشاء أدوات لشرح الأسعار، أو تصحيح سلوك الواجهة الخلفية.
