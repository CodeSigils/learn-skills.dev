أضف الموسيقى والمؤثرات الصوتية إلى اللعبة باستخدام Web Audio API — موسيقى الخلفية وموضوعات اللعب والمؤثرات الصوتية. التبعيات صفر. يُستخدم عندما يقول المستخدم "أضف موسيقى"، أو "أضف مؤثرات صوتية"، أو "أضف صوتًا"، أو "اجعلها تبدو جيدة"، أو "أضف BGM"، أو "أضف تأثيرات صوتية إلى لعبتي". لا تستخدمه لميزات اللعب أو التصميم المرئي.
