Добавьте в игру музыку и звуковые эффекты с помощью API веб-аудио — фоновую музыку, темы игрового процесса и звуковые эффекты. Ноль зависимостей. Используйте, когда пользователь говорит «добавить музыку», «добавить звуковые эффекты», «добавить звук», «сделать хорошее звучание», «добавить фоновую музыку» или «добавить SFX в мою игру». НЕ используйте для функций игрового процесса или визуального дизайна.
