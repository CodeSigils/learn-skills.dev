Enregistrez votre jeu sur Play.fun (OpenGameProtocol), ajoutez le SDK du navigateur et obtenez une URL play.fun monétisée. À utiliser lorsque l'utilisateur dit « monétiser mon jeu », « ajouter Play.fun », « ajouter des récompenses », « s'inscrire sur Play.fun » ou « obtenir une URL play.fun ». Nécessite le serveur Play.fun MCP pour l'enregistrement du jeu.
