Canalización de juegos virales de una sola vez: convierta un tweet, una noticia o un mensaje breve en un juego de navegador estructurado, diseñado, implementado y monetizado en aproximadamente 10 minutos. Úselo cuando el usuario diga "crear un juego viral", "crear un juego a partir de este tweet", "convertir esta historia en un juego", "/juego viral" o proporciona una URL de tweet o un concepto breve que desea que se envíe de un extremo a otro rápidamente. NO lo use cuando el usuario quiera diseñar y construir un proyecto de juego real con hitos, ADR o iteraciones de múltiples sesiones; use `/make-game` para eso. Tampoco lo use para modificar juegos existentes (use `/add-feature` o `/improve-game`).
