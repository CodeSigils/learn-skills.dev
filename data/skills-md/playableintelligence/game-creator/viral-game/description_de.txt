One-Shot-Pipeline für virale Spiele – Verwandeln Sie einen Tweet, eine Nachrichtenmeldung oder eine kurze Aufforderung in etwa 10 Minuten in ein vorbereitetes, entworfenes, bereitgestelltes und monetarisiertes Browserspiel. Verwenden Sie diese Option, wenn der Benutzer sagt: „Machen Sie ein virales Spiel“, „Erstellen Sie ein Spiel aus diesem Tweet“, „Verwandeln Sie diese Geschichte in ein Spiel“, „/viral-game“ oder geben Sie eine Tweet-URL/ein kurzes Konzept an, das/der schnell durchgängig versendet werden soll. NICHT verwenden, wenn der Benutzer ein echtes Spielprojekt mit Meilensteinen, ADRs oder Multisession-Iteration entwerfen und erstellen möchte – verwenden Sie dafür „/make-game“. Auch NICHT zum Modifizieren vorhandener Spiele verwenden (verwenden Sie „/add-feature“ oder „/improve-game“).
