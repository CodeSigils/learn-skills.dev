أضف ميزات قابلة للبوابة إلى لعبة متصفح موجودة - منتقي المظهر، والمتابعة بعد الموت، ووضع المكافأة، وحفظ الفتحات، والتحدي اليومي. السقالات المحايدة لتحقيق الدخل والتي تترك خطافات نظيفة لأي جدار دفع أو اشتراك أو طبقة استحقاق. يتم دعم الميزات في المستويات الفضية والذهبية فقط (البرونزية هي الميزة الافتراضية التي يحصل عليها الجميع). يُستخدم عندما يقول المستخدم "أضف عناصر قابلة لتحقيق الدخل" أو "ميزات قابلة لتحقيق الدخل" أو "أضف منتقي المظهر" أو "أضف متابعة بعد الموت" أو "اجعل لعبتي قابلة لتحقيق الدخل" أو "أضف خطافات مميزة". لا تستخدمه لتكامل Play.fun SDK (استخدم لعبة تحقيق الدخل) أو ميزات اللعب العامة (استخدم ميزة إضافية).
