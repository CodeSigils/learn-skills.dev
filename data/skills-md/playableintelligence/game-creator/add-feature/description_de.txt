Fügen Sie einem vorhandenen Browserspiel eine neue Gameplay-Funktion hinzu, indem Sie dessen Architekturmustern folgen. Wird verwendet, wenn der Benutzer „Funktion hinzufügen“, „Doppelsprung hinzufügen“, „Power-Up hinzufügen“, „Bestenliste hinzufügen“ sagt oder eine bestimmte zu implementierende Spielmechanik beschreibt. NICHT für rein visuelle Änderungen (verwenden Sie Design-Game) oder das Ersetzen von Formen durch Sprites (verwenden Sie Add-Assets) verwenden.
