Aggiungi una nuova funzionalità di gioco a un browser game esistente seguendo i suoi modelli di architettura. Da utilizzare quando l'utente dice "aggiungi una funzione", "aggiungi doppio salto", "aggiungi un potenziamento", "aggiungi una classifica" o descrive una meccanica di gioco specifica da implementare. NON utilizzare per modifiche solo visive (utilizzare design-game) o per sostituire forme con sprite (utilizzare add-assets).
