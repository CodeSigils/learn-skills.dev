Agregue una nueva característica de juego a un juego de navegador existente siguiendo sus patrones de arquitectura. Úselo cuando el usuario diga "agregar una función", "agregar doble salto", "agregar un potenciador", "agregar una tabla de clasificación" o describe una mecánica de juego específica a implementar. NO lo use para cambios solo visuales (use el juego de diseño) ni para reemplazar formas con sprites (use agregar activos).
