最高の専用ピクセル アート モデルである Retro Diffusion API を使用して、真のピクセル アート スプライト、タイルセット、アニメーションを生成します。ユーザーが「ピクセル アートを生成する」、「AI でスプライトを作成する」、「レトロ ディフュージョンを使用する」、「rdpk」を指定する場合、または手動でコーディングしたスプライト配列よりも高速に高品質のピクセル アートを作成したい場合に使用します。 Retro Diffusion アカウントと RETRODIFFUSION_API_KEY (有料クレジット) が必要です。 2D Phaser ゲームの迅速なプロトタイピングに最適です。
