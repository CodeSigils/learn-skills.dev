Genere verdaderos sprites, conjuntos de mosaicos y animaciones de pixel art con la API Retro Diffusion, el mejor modelo de pixel art dedicado. Úselo cuando el usuario diga "generar pixel art", "crear un sprite con IA", "usar Retro Diffusion", "rdpk" o quiere pixel art de alta calidad más rápido que las matrices de sprites codificadas a mano. Requiere una cuenta Retro Diffusion y RETRODIFFUSION_API_KEY (créditos pagados). Ideal para creación rápida de prototipos de juegos 2D Phaser.
