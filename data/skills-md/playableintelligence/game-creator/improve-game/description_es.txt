Analice un juego, encuentre lo que necesita mejorar e implemente las mejoras de mayor impacto. Úselo cuando el usuario dice "mejorar mi juego", "mejorar mi juego", "arreglar mi juego", "qué hay de malo en mi juego" o "pulir mi juego". Ejecute repetidamente: cada pasada encuentra el siguiente elemento más impactante que hay que solucionar. NO lo use para agregar funciones nuevas específicas (use funciones adicionales) o para la creación inicial de juegos (use juegos virales para compilaciones de una sola vez, crear juegos para proyectos basados ​​en hitos).
