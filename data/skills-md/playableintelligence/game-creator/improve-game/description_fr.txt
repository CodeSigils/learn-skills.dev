Analysez un jeu, trouvez ce qui doit fonctionner et mettez en œuvre les améliorations ayant le plus grand impact. À utiliser lorsque l'utilisateur dit « améliorer mon jeu », « améliorer mon jeu », « réparer mon jeu », « qu'est-ce qui ne va pas avec mon jeu » ou « peaufiner mon jeu ». Exécutez à plusieurs reprises : chaque passe trouve la prochaine chose la plus importante à corriger. Ne PAS utiliser pour ajouter de nouvelles fonctionnalités spécifiques (utilisez add-feature) ou pour la création initiale de jeux (utilisez viral-game pour les versions uniques, make-game pour les projets axés sur des étapes importantes).
