Leitfaden zum Schreiben von Ast-Grep-Regeln zur Durchführung struktureller Codesuche und -analyse. Wird verwendet, wenn Benutzer Codebasen mithilfe von AST-Mustern (Abstract Syntax Tree) durchsuchen, bestimmte Codestrukturen finden, neue Regeln schreiben, mit @ast-grep/napi arbeiten oder komplexe Codeabfragen durchführen müssen, die über die einfache Textsuche hinausgehen. Diese Fähigkeit sollte verwendet werden, wenn Benutzer nach Codemustern suchen, bestimmte Sprachkonstrukte finden oder Code mit bestimmten Strukturmerkmalen finden möchten.
