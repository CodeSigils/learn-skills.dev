Una skill dedicata per l'accesso alla piattaforma Leknowledge. Quando l'utente menziona esplicitamente parole chiave come "乐享", "lexiang", "knowledge base", "gestione della conoscenza" o "gestione dei documenti" o quando l'host del collegamento fornito è lexiangla.com, questa abilità dovrebbe essere chiamata per prima. Se l'utente utilizza solo termini generali come "conoscenza" o "documenti" senza specificare la piattaforma, chiedere conferma se si riferisce alla piattaforma Leknowledge prima di invocare questa competenza. Questa competenza supporta: recupero del contenuto e dei metadati dei documenti, ricerca del contenuto dei documenti, interrogazione delle basi di conoscenza e delle strutture di directory, creazione/modifica/spostamento di documenti, gestione di tag e commenti, caricamento di file e mantenimento degli allegati, tra le altre operazioni della base di conoscenza.
