Converti i progetti Figma in codice dell'interfaccia utente di produzione. Accetta esportazioni Figma JSON, screenshot o snippet in modalità sviluppatore. Rileva il framework frontend, il sistema di progettazione e i modelli di componenti esistenti del progetto e genera codice corrispondente. Utilizzare quando l'utente desidera creare un'interfaccia utente da Figma, convertire Figma in codice, implementare un progetto Figma o menzionare "figma pack".
