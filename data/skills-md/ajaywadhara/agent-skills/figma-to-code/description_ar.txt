تحويل تصميمات Figma إلى كود واجهة المستخدم للإنتاج. يقبل تصدير Figma JSON أو لقطات الشاشة أو مقتطفات وضع التطوير. يكتشف إطار عمل الواجهة الأمامية الحالي للمشروع ونظام التصميم وأنماط المكونات، وينشئ كودًا مطابقًا. يُستخدم عندما يريد المستخدم إنشاء واجهة مستخدم من Figma، أو تحويل Figma إلى رمز، أو تنفيذ تصميم Figma، أو ذكر "حزمة Figma".
