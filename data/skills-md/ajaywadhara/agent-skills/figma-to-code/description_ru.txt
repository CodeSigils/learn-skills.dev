Преобразуйте проекты Figma в рабочий код пользовательского интерфейса. Принимает экспорт Figma JSON, снимки экрана или фрагменты кода в режиме разработки. Обнаруживает существующую структуру интерфейса проекта, систему дизайна и шаблоны компонентов — генерирует соответствующий код. Используйте, когда пользователь хочет создать пользовательский интерфейс из Figma, преобразовать Figma в код, реализовать дизайн Figma или упоминает «пакет Figma».
