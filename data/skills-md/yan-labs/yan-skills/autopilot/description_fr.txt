Recevez une instruction vague, étudiez-la, catégorisez-la et décomposez-la automatiquement dans un plan d'étape XML, sélectionnez la compétence appropriée et définissez les critères d'achèvement, puis exécutez-la entièrement en mode sans surveillance à l'aide du mode boucle/objectif + agent, y compris le déploiement automatique, les tests automatiques de bout en bout et la révision automatique du code, sans sauter aucune étape. Lorsque l'utilisateur lance une tâche générale telle que « corriger le bogue », « ajouter des tests », « optimiser les performances », « terminer cette fonctionnalité », « exécuter une analyse de code » ou « enquêter sur pourquoiXX », elle doit être utilisée de manière proactive. Il est également déclenché lorsque l'utilisateur dit « pilote automatique », « auto », « aidez-moi à planifier », « gérez-le vous-même », « exécutez directement », « vous le décomposez », « ne me demandez pas comment », etc. Même si l'utilisateur n'utilise pas ces mots-clés, tant que l'entrée est clairement une intention large non décomposée, elle doit être activée de manière proactive. Invoquer le pilote automatique = autoriser une exécution entièrement automatique et sans surveillance, sans aucune confirmation à mi-processus requise.
