Recevez une instruction vague, étudiez-la, catégorisez-la et décomposez-la automatiquement dans un plan par étapes XML, sélectionnez les compétences appropriées, définissez les critères d'achèvement, puis exécutez l'ensemble du processus en mode sans surveillance à l'aide du mode boucle/objectif+agent, couvrant le déploiement automatique, les tests automatiques de bout en bout et la révision automatique du code, sans sauter aucune étape.

Lorsqu'un utilisateur soumet une tâche générale, appliquez-la de manière proactive : par exemple, "corrigez le bogue", "ajoutez des tests", "optimisez les performances", "terminez cette fonctionnalité", "exécutez une analyse de code", "enquêtez sur pourquoiXX". Il se déclenche également lorsque l'utilisateur dit « pilote automatique », « auto », « aidez-moi à planifier », « gérez-le vous-même », « exécutez directement », « vous le décomposez », « ne me demandez pas comment », etc. Même si l'utilisateur n'utilise pas ces mots-clés, tant que l'entrée est clairement une intention large et non raffinée, elle doit être activée automatiquement.

Invoquer le pilote automatique = accorder l'autorisation pour une exécution entièrement automatique et sans surveillance, sans confirmation intermédiaire nécessaire.
