Verwenden Sie OpenCLI, um das echte, angemeldete Chrome des Benutzers auf seinem Computer zu steuern, oder rufen Sie dessen über 160 Site-Adapter auf. Jeder Seitenvorgang, der einen angemeldeten Status erfordert, beginnt hier – das Lesen des angemeldeten Backends, das Abrufen von Tabellen ohne API, das Ausfüllen und Senden von Formularen, das Ausführen eines Site-Befehls und das Zurückziehen von Seitendaten. Es umfasst außerdem Sitzungsbenennung und Lease-Disziplin („mein Tab wurde von jemand anderem belegt“), Massendatenextraktion und -persistenz, Adapterentwicklung und Selbstreparatur sowie die Fehlerbehebung bei OpenCLI Doctor. Wenn ein Benutzer OpenCLI, Browser-Automatisierung, die Verwendung meines Browsers, das Fahren von Chrome, den Anmeldestatus, das Abrufen von Backend-Daten, das Abrufen von Tabellen, das Exportieren von Berichten, das Ausfüllen von Formularen, das automatische Klicken, Screenshots, Adapter, Arztfehler, Kollisionen von Sitzungsnamen, belegte Tabs, Tab-Leaks erwähnt oder sagt: „Öffne diese Seite und schau nach“, „hilf mir, mich im Backend anzumelden und zu überprüfen“, „diese Website hat keine API“, solltest du diese Fähigkeit unbedingt verwenden. Solange die Aktion im Browser ausgeführt wird, lesen Sie dies zuerst, bevor Sie Maßnahmen ergreifen.

Bitte antworten Sie immer in der Sprache des Benutzers.
