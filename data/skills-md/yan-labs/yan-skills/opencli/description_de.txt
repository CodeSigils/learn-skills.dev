Verwenden Sie OpenCLI, um das echte, angemeldete Chrome des Benutzers auf seinem Computer zu steuern, oder rufen Sie dessen über 160 Site-Adapter auf. Jeder Seitenvorgang, der einen angemeldeten Status erfordert, beginnt hier – das Lesen des angemeldeten Backends, das Scrapen von Tabellen ohne API, das Ausfüllen und Senden von Formularen, das Ausführen eines Site-Befehls und das Zurückziehen von Seitendaten. Darüber hinaus werden Sitzungsbenennung und Lease-Disziplin („mein Tab wurde gekapert“), Massendatenextraktion und -persistenz, Adapterentwicklung und Selbstreparatur sowie OpenCLIdoctor-Fehlerbehebung behandelt. Wenn Benutzer OpenCLI, Browser-Automatisierung, die Verwendung meines Browsers, das Fahren von Chrome, den Anmeldestatus, das Scraping von Back-End-Daten, das Scraping von Tabellen, das Exportieren von Berichten, das Ausfüllen von Formularen, automatisches Klicken, Screenshots, Adapter, Arztfehler, Kollisionen von Sitzungsnamen, gekaperte Tabs, Tab-Leaks erwähnen oder sagen: „Öffne diese Seite und schau nach“, „hilf mir, mich beim Backend anzumelden und zu überprüfen“, „diese Website hat keine API“, solltest du diese Fähigkeit unbedingt verwenden. Solange die Aktion im Browser ausgeführt wird, lesen Sie dies zuerst, bevor Sie fortfahren.
