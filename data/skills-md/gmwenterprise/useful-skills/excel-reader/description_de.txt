Wird beim Lesen von Excel-Dateien (.xlsx/.xlsm) zum Extrahieren von Daten verwendet. Wird ausgelöst, wenn der Benutzer Excel, XLSX oder Tabellenkalkulationen erwähnt oder tabellarische Daten extrahieren/analysieren muss. Gibt KI-freundliches JSON mit Unterstützung für das Zusammenführen von Zellen und Typinferenz aus.
