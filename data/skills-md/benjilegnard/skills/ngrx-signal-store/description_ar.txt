يُنشئ كود NgRx SignalStore ويقدم إرشادات حول إدارة الحالة باستخدام @ngrx/signals. يتم تشغيله عند العمل مع SignalStore، أو signalState، أو patchState، أو withState، أو withComputed، أو withMethods، أو withProps، أو withLinkedState، أو withEntities، أو withHooks، أو signalStoreFeature، أو withFeature، أو rxMethod، أو signalMethod، أو DeepComputed، أو البرنامج المساعد للأحداث، أو أي استيراد @ngrx/signals.
