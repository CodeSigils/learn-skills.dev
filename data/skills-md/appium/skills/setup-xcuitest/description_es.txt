Prepare y verifique Appium XCUITest para iOS o tvOS en macOS mediante la validación de Node/Appium, Xcode, la instalación del controlador, la salida del médico, el simulador o los requisitos previos compartidos del dispositivo real y la evidencia de humo del servidor. Utilícelo cuando la habilidad de configuración seleccione XCUITest o appium-solución de problemas para eliminar un requisito previo de XCUITest o una falla del médico. Para un dispositivo real, continúa con xcuitest-real-device-config después de que pase esta habilidad. No lo utilice para la firma de dispositivos reales, el aprovisionamiento o la implementación de WebDriverAgent.
