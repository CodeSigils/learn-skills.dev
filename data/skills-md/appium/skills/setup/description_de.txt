Leiten und koordinieren Sie eine oder mehrere Appium-Treiber-Setup-Anfragen, indem Sie UiAutomator2, Espresso, Chromium, Gecko, Mac2, Safari oder XCUITest an den entsprechenden Setup-Skill übergeben und die Fertigstellung mehrerer Treiber sammeln. Für Appium-Setup-Anfragen ohne Treiber, mit einem benannten Treiber oder mit mehreren benannten Treibern verwenden. Führen Sie in diesem Skill keine treiberspezifische Einrichtung durch; Wählen Sie die genaue Kinderfähigkeit aus und geben Sie sie ab. Nicht für eine vorhandene fehlerhafte Sitzung oder einen fehlerhaften Befehl verwenden. Verwenden Sie stattdessen die Appium-Fehlerbehebung.
