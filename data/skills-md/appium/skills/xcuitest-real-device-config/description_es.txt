Úselo solo después de que setup-xcuitest complete los requisitos previos compartidos de XCUITest y continúe con esta Skill para un objetivo de dispositivo real. No lo use para la configuración general de XCUITest o fallas de tiempo de ejecución posteriores no relacionadas con la firma o la implementación de WebDriverAgent.
