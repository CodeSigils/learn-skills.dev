Conjunto de habilidades de análisis de rendimiento de Huawei Ascend NPU, **debe usarse cuando el usuario proporciona un archivo de perfil o ruta de directorio**, usado para analizar datos de perfil para identificar cuellos de botella de rendimiento en computación, comunicación, despacho y otras áreas; admite varios formatos de datos, como step_trace_time.csv, op_statistic.csv, kernel_details.csv, y proporciona un flujo de trabajo de análisis de rendimiento completo y recomendaciones de optimización.
