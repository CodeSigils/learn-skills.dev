Set di competenze di analisi delle prestazioni di Huawei Ascend NPU, **deve essere utilizzato quando l'utente fornisce un file di profilazione o un percorso di directory**, utilizzato per analizzare i dati di profilazione per identificare i colli di bottiglia delle prestazioni nel calcolo, nella comunicazione, nell'invio e in altre aree; supporta vari formati di dati come step_trace_time.csv, op_statistic.csv, kernel_details.csv e fornisce un flusso di lavoro completo di analisi delle prestazioni e consigli di ottimizzazione.
