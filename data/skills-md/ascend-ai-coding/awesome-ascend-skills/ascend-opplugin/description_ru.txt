Используется для управления интеграцией операторской разработки Ascend C (CANN / xpu_kernel) в PyTorch после завершения: взаимодействие с torch_npu, регистрация и сборка на стороне хоста, воздействие Python и дымовое тестирование. Охватывает упрощенную интеграцию внутри проекта оператора, обращение к op-plugin при необходимости, быструю совместную отладку с помощью Pybind, повторное использование инкапсуляции графовых операторов и т. д. Применимо к таким сценариям, как Ascend C, интеграция операторов, torch_npu, пользовательские операторы NPU, op-plugin, xpu_kernel, cpp_extension, пользовательские операторы и подобные контексты.
