GitHub Capacità di analisi della causa principale dei problemi. Analizza i problemi GitHub specificati per identificare le possibili cause principali esaminando il contenuto del problema, il repository del codice e le risorse correlate. Da utilizzare quando l'utente chiede di analizzare la causa principale del problema, indagare sul problema, eseguire l'analisi RCA o risolvere i problemi di GitHub. Fornisce indicazioni di indagine con stime di probabilità e indica esplicitamente quando non è possibile determinare la causa principale.
