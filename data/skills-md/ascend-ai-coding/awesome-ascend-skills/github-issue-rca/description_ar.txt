مهارة تحليل السبب الجذري لمشكلة GitHub. قم بتحليل مشكلات GitHub المحددة لتحديد الأسباب الجذرية المحتملة من خلال فحص محتوى المشكلة ومستودع التعليمات البرمجية والموارد ذات الصلة. يُستخدم عندما يطلب المستخدم تحليل السبب الجذري للمشكلة، أو التحقيق في المشكلة، أو تحليل RCA، أو استكشاف مشكلات GitHub وإصلاحها. يوفر توجيهات التحقيق مع تقديرات الاحتمالات ويذكر بوضوح متى لا يمكن تحديد السبب الجذري.
