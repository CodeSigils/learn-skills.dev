Fähigkeit zur Ursachenanalyse von GitHub-Problemen. Analysieren Sie bestimmte GitHub-Probleme, um mögliche Grundursachen zu identifizieren, indem Sie den Probleminhalt, das Code-Repository und zugehörige Ressourcen untersuchen. Verwenden Sie diese Option, wenn der Benutzer die Ursache eines Problems analysieren, das Problem untersuchen, eine RCA-Analyse durchführen oder GitHub-Probleme beheben möchte. Stellt Untersuchungsanweisungen mit Wahrscheinlichkeitsschätzungen bereit und gibt explizit an, wann die Grundursache nicht ermittelt werden kann.
