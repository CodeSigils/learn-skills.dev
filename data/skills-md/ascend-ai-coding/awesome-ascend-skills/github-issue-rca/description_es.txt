GitHub Habilidad de análisis de causa raíz de problemas. Analice problemas específicos de GitHub para identificar posibles causas fundamentales examinando el contenido del problema, el repositorio de código y los recursos relacionados. Úselo cuando el usuario solicite analizar la causa raíz del problema, investigar el problema, realizar análisis RCA o solucionar problemas de GitHub. Proporciona direcciones de investigación con estimaciones de probabilidad y establece explícitamente cuándo no se puede determinar la causa raíz.
