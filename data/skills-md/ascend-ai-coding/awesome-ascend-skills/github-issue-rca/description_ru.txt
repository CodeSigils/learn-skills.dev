GitHub Навыки анализа первопричин проблем. Проанализируйте указанные проблемы GitHub, чтобы определить возможные основные причины, изучив содержимое проблемы, репозиторий кода и связанные ресурсы. Используйте, когда пользователь просит проанализировать основную причину проблемы, исследовать проблему, провести анализ RCA или устранить проблемы GitHub. Предоставляет направления расследования с оценками вероятности и явно указывает, когда основная причина не может быть определена.
