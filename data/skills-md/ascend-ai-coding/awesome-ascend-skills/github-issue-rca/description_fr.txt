GitHub Compétence d’analyse des causes profondes des problèmes. Analysez les problèmes GitHub spécifiés pour identifier les causes profondes possibles en examinant le contenu du problème, le référentiel de code et les ressources associées. À utiliser lorsque l'utilisateur demande à analyser la cause première du problème, à enquêter sur le problème, à effectuer une analyse RCA ou à résoudre des problèmes GitHub. Fournit des orientations d’enquête avec des estimations de probabilité et indique explicitement quand la cause profonde ne peut pas être déterminée.
