Orquestador de referencia interactivo en línea para servicios de inferencia vLLM utilizando "vllm benchserve". Admite puntos de referencia únicos, ejecución por lotes de casos múltiples con agregación de resultados y optimización automática para encontrar simultaneidad/rendimiento óptimo bajo restricciones de SLO de latencia (TTFT, TPOT, P99, tasa de éxito). Utilice esta habilidad siempre que el usuario desee realizar una evaluación comparativa, una prueba de estrés o medir el rendimiento de un servicio de inferencia LLM/multimodal/incrustado en ejecución, incluso si no dice "servicio de banco vllm" explícitamente. NO lo use para rendimiento de inferencia fuera de línea, implementación/inicio de servicios, creación de perfiles/rastreo, solo controles de estado o análisis de resultados de referencia existentes sin ejecutar nuevas pruebas.
