Интерактивный онлайн-оркестратор тестов для служб вывода vLLM с использованием vllm Bench Serve. Поддерживает отдельные тесты, пакетное выполнение нескольких случаев с агрегированием результатов и автоматическую оптимизацию для поиска оптимального параллелизма/пропускной способности при ограничениях SLO по задержке (TTFT, TPOT, P99, показатель успеха). Используйте этот навык всякий раз, когда пользователь хочет протестировать, нагрузочное тестирование или измерить производительность работающего LLM/мультимодального/встраиваемого сервиса вывода — даже если он явно не говорит «vllm Bench Service». НЕ используйте для автономного вывода, развертывания/запуска служб, профилирования/отслеживания, только проверки работоспособности или анализа существующих результатов тестов без запуска новых тестов.
