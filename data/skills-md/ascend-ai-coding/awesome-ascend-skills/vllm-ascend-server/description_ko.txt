자동 모델 감지 및 최적화된 구성을 통해 Ascend NPU 서버에 vLLM 추론 서비스를 배포합니다. 베어메탈, 컨테이너, Docker 이미지 전반에 걸쳐 로컬 및 원격 배포를 지원합니다. 모델 검색, 양자화 자동 감지, 텐서 병렬 처리 구성, 그래프/열심히 모드 선택 및 서비스 상태 확인을 처리합니다. 사용자가 다음 작업을 수행해야 하는 경우에 사용합니다. (1) NPU에서 vLLM 서버 시작 또는 배포, (2) LLM 추론 서비스 실행, (3) 멀티 카드 텐서 병렬 배포 구성, (4) 추측 디코딩(Eagle) 또는 양자화 활성화, (5) vllm 오프라인 일괄 추론 실행, (6) vLLM 서비스 상태 확인 또는 테스트.
