Lancez directement les conteneurs Docker sur les serveurs Ascend NPU pour les utilisateurs. Collectez les exigences et exécutez les commandes d'exécution de Docker avec le montage de périphérique NPU, la mise en réseau, les montages de volume et les variables d'environnement appropriés. À utiliser lorsque les utilisateurs doivent : (1) démarrer un conteneur Docker sur un serveur NPU, (2) créer des conteneurs avec accès aux périphériques NPU, (3) configurer et lancer des conteneurs avec des exigences spécifiques de mise en réseau ou de montage.
