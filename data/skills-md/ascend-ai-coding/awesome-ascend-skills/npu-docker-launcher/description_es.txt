Inicie contenedores Docker directamente en servidores Ascend NPU para los usuarios. Recopile requisitos y ejecute comandos de ejecución de Docker con el montaje de dispositivos NPU, redes, montajes de volúmenes y variables de entorno adecuados. Úselo cuando los usuarios necesiten: (1) iniciar un contenedor Docker en un servidor NPU, (2) crear contenedores con acceso a dispositivos NPU, (3) configurar e iniciar contenedores con requisitos de montaje o de red específicos.
