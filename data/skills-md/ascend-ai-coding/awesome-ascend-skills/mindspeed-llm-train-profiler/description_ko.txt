Ascend NPU에서 MindSpeed-LLM 교육을 위한 프로파일링 데이터 수집을 안내하고 자동화합니다. CPU 수집, 메모리 수집, 다양한 수집 수준(레벨0/레벨1/레벨2) 및 사용자 정의 단계 범위를 포함한 프로파일링을 통해 모델 교육 구성 및 실행을 지원합니다. 생성된 프로파일링 데이터는 성능 분석을 위해 MindStudio Insight로 분석할 수 있습니다. 사용자가 모델 학습 중에 프로파일링 데이터를 수집하거나, 학습 성능 분석을 수행하거나, 성능 데이터/프로파일링 수집을 수행해야 할 때 트리거됩니다. 트리거 키워드: 프로파일링, 성능 분석, 성능 데이터 수집, 프로파일링 수집, 교육 프레임워크 프로파일링, MindSpeed-LLM 프로파일링.
