Guide and automate the collection of profiling data for MindSpeed-LLM training on Ascend NPU. Supports configuring and running model training with profiling, including CPU collection, memory collection, different collection levels (level0/level1/level2), and custom step ranges. The generated profiling data can be analyzed with MindStudio Insight for performance analysis. Triggered when a user needs to collect profiling data during model training, perform training performance analysis, or conduct performance data/profiling collection. Trigger keywords: profiling, performance analysis, performance data collection, profiling collection, training framework profiling, MindSpeed-LLM profiling.
