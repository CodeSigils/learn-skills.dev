Guíe y automatice la recopilación de datos de perfiles para la capacitación MindSpeed-LLM en Ascend NPU. Admite la configuración y ejecución del entrenamiento de modelos con creación de perfiles, incluida la recopilación de CPU, la recopilación de memoria, diferentes niveles de recopilación (nivel0/nivel1/nivel2) y rangos de pasos personalizados. Los datos de creación de perfiles generados se pueden analizar con MindStudio Insight para el análisis del rendimiento. Se activa cuando un usuario necesita recopilar datos de perfiles durante el entrenamiento del modelo, realizar un análisis del rendimiento del entrenamiento o realizar una recopilación de datos de rendimiento/recopilación de perfiles. Palabras clave desencadenantes: elaboración de perfiles, análisis de rendimiento, recopilación de datos de rendimiento, recopilación de perfiles, elaboración de perfiles del marco de formación, elaboración de perfiles MindSpeed-LLM.
