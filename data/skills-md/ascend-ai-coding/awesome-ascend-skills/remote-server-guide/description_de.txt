Leitfaden für die Verbindung zu Remote-Servern über SSH, die Verwaltung von Containern und die Remote-Ausführung von Befehlen. Behandelt den Aufbau einer SSH-Verbindung mit mehreren Authentifizierungsmethoden (SSH-Schlüssel, sshpass, Paramiko, Fabric, tmux Interactive), Docker-Container-Verbindung und Befehlsausführung, Dateiübertragung und Fehlerbehebung. Verwenden Sie diese Fähigkeit immer dann, wenn Benutzer: (1) über SSH eine Verbindung zu einem Remote-Server oder VPS herstellen, (2) Befehle auf Remote-Computern ausführen, (3) Dateien zu/von Remote-Servern übertragen, (4) eine Verbindung zu Docker-Containern auf Remote-Hosts herstellen müssen, (5) SSH-Passwortauthentifizierungstools einrichten müssen. Selbst wenn der Benutzer nur „Hilf mir, etwas auf meinem Server auszuführen“ oder „Mit meinem Computer verbinden“ sagt, gilt diese Fähigkeit.
