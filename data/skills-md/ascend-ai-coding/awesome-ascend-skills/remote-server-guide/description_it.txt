Guida per connettersi a server remoti tramite SSH, gestire contenitori ed eseguire comandi da remoto. Copre la configurazione della connessione SSH con più metodi di autenticazione (chiave SSH, sshpass, Paramiko, Fabric, tmux Interactive), connessione al contenitore Docker ed esecuzione dei comandi, trasferimento di file e risoluzione dei problemi. Utilizza questa competenza ogni volta che gli utenti necessitano di: (1) connettersi a un server remoto o VPS tramite SSH, (2) eseguire comandi su macchine remote, (3) trasferire file da/a server remoti, (4) connettersi a contenitori Docker su host remoti, (5) configurare strumenti di autenticazione con password SSH. Anche se l'utente dice semplicemente "aiutami a eseguire qualcosa sul mio server" o "connettiti al mio computer", questa abilità si applica.
