Guía para conectarse a servidores remotos vía SSH, administrar contenedores y ejecutar comandos de forma remota. Cubre la configuración de la conexión SSH con múltiples métodos de autenticación (clave SSH, sshpass, Paramiko, Fabric, tmux interactivo), conexión al contenedor Docker y ejecución de comandos, transferencia de archivos y solución de problemas. Utilice esta habilidad siempre que los usuarios necesiten: (1) conectarse a un servidor remoto o VPS a través de SSH, (2) ejecutar comandos en máquinas remotas, (3) transferir archivos hacia/desde servidores remotos, (4) conectarse a contenedores Docker en hosts remotos, (5) configurar herramientas de autenticación de contraseña SSH. Incluso si el usuario simplemente dice "ayúdame a ejecutar algo en mi servidor" o "conéctate a mi máquina", esta habilidad se aplica.
