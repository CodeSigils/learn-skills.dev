Utilisez cette compétence lors de l'exécution dans Herdr pour coordonner les espaces de travail, les onglets, les volets, les agents frères, les volets serveur/test/journal, les messages d'agent à agent ou la délégation multi-agent. Envoyez un message de troupeau léger (réponse à + tâche), puis arrêtez et terminez le tour. N'interrogez pas vos frères et sœurs et n'attendez pas les réponses en bloc ; gérer le message homologue lorsqu'il est injecté dans votre volet.
