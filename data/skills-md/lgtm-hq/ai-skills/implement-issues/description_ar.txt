تنفيذ مجموعة من مشكلات GitHub بالتوازي - الفرز أو أخذ قائمة مشكلات واضحة، وتجميعها حسب تعارض الملفات، وإنشاء شجرة عمل لكل مسار، وتفويض الوكلاء الفرعيين، وفتح العلاقات العامة لكل مسار؛ لا يدمج أبدا. استخدمه عندما يُطلب منك تنفيذ المشكلات، أو التعامل مع الأعمال المتراكمة، أو التقاط مشكلات متعددة بالتوازي.
