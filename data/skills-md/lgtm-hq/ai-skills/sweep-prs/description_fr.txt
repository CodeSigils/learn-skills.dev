Audit rétrospectif des PR récemment fusionnés/fermés pour les anomalies qui se sont glissées - fusions sans versions vertes, fusions sur les fils de révision principaux rouges, non résolus ou post-fusion, résolutions creuses. Balayage en lecture seule, puis correction confirmée (problèmes, réponses de disposition). À utiliser lorsqu'on vous demande de balayer les PR, d'auditer les PR fusionnés ou de vérifier ce qui s'est glissé.
