Создавайте агенты обмена сообщениями и приложения с помощью Spectrum — SDK для унифицированного обмена сообщениями Photon. Напишите логику обработчика один раз и отправьте ее через iMessage, WhatsApp Business, терминал или специальную платформу. Spectrum по своей сути является мультиплатформенным и становится многоязычным; текущий SDK — Spectrum-ts (TypeScript), запланированы дополнительные языковые SDK. Используйте этот навык для любого вопроса Spectrum — быстрый старт, многоплатформенная настройка, получение сообщений, сборщики контента, пространства и пользователи, реакции и ответы, сужение платформы, встроенные поставщики (облако iMessage/локальный/выделенный с эффектами сообщений, тестовый пакет TUI терминала, WhatsApp Business 1:1), настраиваемые потоки событий, плавное завершение работы, создание собственного поставщика с помощью `definePlatform` и шаблоны производственной архитектуры, которые Photon использует внутри себя для доставки агентов, которые изначально живут внутри приложений обмена мгновенными сообщениями. (пятиэтапный входящий конвейер с устранением дребезга → пакетной очисткой → пометить как прочитанное → сгенерировать → отправить, отмену в реальном времени с сигналами прерывания, обработчик стока, перенос вперед, идемпотентные повторные попытки через стабильные клиентские GUID и курсор возобновления startIndex, область памяти для каждого ресурса `resourceId` против `threadId`, устойчивый журнал аудита сбоев заданий). Это отправная точка для развития навыка; для получения полной информации обратитесь к файлам тем в этом каталоге.
