Spectrum — Photon의 통합 메시징 SDK로 메시징 에이전트와 앱을 구축하세요. 핸들러 로직을 한 번 작성하면 iMessage, WhatsApp Business, 터미널 또는 사용자 정의 플랫폼에 배포할 수 있습니다. Spectrum은 다중 플랫폼으로 설계되었으며 다중 언어로 바뀌고 있습니다. 현재 SDK는 `spectrum-ts`(TypeScript)이며 추가 언어 SDK가 계획되어 있습니다. 모든 Spectrum 질문에 이 기술을 사용하세요. 빠른 시작, 다중 플랫폼 설정, 메시지 수신, 콘텐츠 빌더, 스페이스 및 사용자, 반응 및 응답, 플랫폼 범위 좁히기, 내장 제공자(iMessage 클라우드/로컬/메시지 효과 전용, 터미널 TUI 테스트 하니스, WhatsApp Business 1:1), 사용자 정의 이벤트 스트림, 우아한 종료, `definePlatform`을 사용하여 자체 제공자 구축, Photon이 IM 앱 내에 기본적으로 존재하는 에이전트를 제공하기 위해 내부적으로 사용하는 프로덕션 아키텍처 패턴 (디바운스 → 일괄 플러시 → 읽음으로 표시 → 생성 → 전송, 중단 신호를 통한 진행 중 취소, 처리기 내 배수, 이월, 안정적인 클라이언트 GUID 및 startIndex 재개 커서를 통한 멱등성 재시도, 리소스별 메모리 범위 `resourceId` 대 `threadId`, 내구성 있는 작업 실패 감사 로그를 포함하는 5단계 인바운드 파이프라인). 이것이 스킬의 진입점입니다. 전체 참조는 이 디렉터리의 항목 파일을 참조하세요. 키워드: 스펙트럼, 스펙트럼-ts, 광자, 통합 메시징, 다중 플랫폼, 다중 언어, im 에이전트, 메시징 에이전트, imessage, whatsapp, whatsapp 비즈니스, 터미널, tuichat, 정의 플랫폼, 사용자 정의 플랫폼, 플랫폼 제공자, 플랫폼 축소, app.messages, Spectrum(), 공간, 보내기, 답장, 반응, 탭백, 입력 표시기, 응답, startTyping, stopTyping, 콘텐츠 빌더, 텍스트, 첨부 파일, 음성, 연락처, richlink, 설문 조사, 그룹, 사용자 정의 콘텐츠, 메시지 효과, 버블 효과, 화면 효과, 회선 모델, 전용 회선, 공유 풀, 사용자 정의 이벤트, app.stop, 수명 주기, SIGINT, 우아한 종료, 메시지 대기열, 디바운스, 배치, 진행 중, 취소, 컨트롤러 중단, 전달, 멱등성 재시도, 클라이언트 guid, 중복 제거, 중복 제거, startIndex, 커서 재개, 작업 메모리, resourcesId, threadId, 리소스별 메모리, 작업 실패, 감사 로그, 경쟁 조건, 작업자 충돌, 재시도, PG-Boss, 대기열 작업자, 대화 에이전트, 채팅 에이전트, 기본 메시징, 에이전트 아키텍처, 프로덕션 에이전트, 스펙트럼 패턴, 모범 사례.
