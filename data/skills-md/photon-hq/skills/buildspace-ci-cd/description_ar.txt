قم بتكوين واستكشاف أخطاء سير عمل BuildSpace القابلة لإعادة الاستخدام وإجراءات GitHub وإصلاحها للإصدارات التلقائية. يغطي Rust، وTypeScript (حزمة واحدة وmonorepo)، وGo، وحزمة Swift، وmacOS .pkg (ثنائي وحمولة فقط)، وdylib (Xcode وMakefile)، وإصدار عام، وملاحظات الإصدار/الإصدار المستندة إلى الذكاء الاصطناعي، وفحوصات حداثة README، وفحوصات وثائق المهارات، والعلامات، والأذونات، والأسرار، وتحديثات النقر على Homebrew، وتحميلات Jamf، واختبار التشغيل الجاف، وتكوين الكتلة المخصصة. يُستخدم عندما يذكر المستخدمون BuildSpace، أو أتمتة الإصدار، أو سير العمل القابل لإعادة الاستخدام، أو GitHub Actions CI/CD، أو النشر إلى npm/crates/Homebrew/Jamf. الكلمات الرئيسية: buildspace، ci/cd، إجراءات github، أتمتة الإصدار، سير العمل القابل لإعادة الاستخدام، npm، الصناديق، البيرة المنزلية، الصدأ، الآلة الكاتبة، go، Swift، monorepo، dylib، macOS، pkg، jamf، المهارات.
