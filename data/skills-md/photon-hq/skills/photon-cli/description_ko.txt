Photon CLI로 작업할 때 사용합니다 — `photon` 바이너리(별칭 `pho`). 사용자를 위해 Photon을 설정/부트스트랩하고 비대화식으로 직접 실행하려면(프로젝트 생성, ID + 비밀 캡처, 확인) — 사용자가 "나를 위해 설정해 줘"라고 말하면 이것이 여러분이 해야 할 일이지 돌려주는 것이 아닙니다. 또한 CLI 명령 실행, 인증(장치 인증 로그인/로그아웃/whoami/인증 상태), 프로젝트 관리(Spectrum API 비밀 생성, 표시, 나열, 이름 바꾸기, 재생성, 삭제, 대시보드에서 열기), Spectrum 리소스 관리(라인, 사용자, 플랫폼, 프로필, 아바타), 구성 및 환경 확인(PHOTON_PROJECT_ID, PHOTON_TOKEN, PHOTON_API_HOST, 자격 증명 저장소, 멀티 백엔드) 및 청구/업그레이드(계획, 결제, 관리, '프로젝트 업그레이드'). "나에게 있는 라인 수는 몇 개입니까?", "내 프로젝트 비밀은 무엇입니까?", "이것을 비즈니스 라인으로 만드는 방법은 무엇입니까?", "다른 백엔드에서 CLI를 어떻게 지정합니까?"와 같은 운영 질문에 답합니다. 이것이 진입점입니다.
