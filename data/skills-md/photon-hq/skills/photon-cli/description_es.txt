Úselo cuando trabaje con Photon CLI: el binario `photon` (alias `pho`). Utilice esta habilidad para configurar/iniciar Photon para un usuario y ejecutarlo usted mismo de forma no interactiva (crear un proyecto, capturar la identificación + el secreto, verificar): cuando el usuario dice "configurar esto por mí", ese es su trabajo, no devolvérselo. También cubre la ejecución de cualquier comando CLI, la autenticación (inicio de sesión/cierre de sesión con autorización del dispositivo/whoami/estado de autenticación), la administración de proyectos (crear, mostrar, enumerar, cambiar el nombre, regenerar el secreto de la API de Spectrum, eliminar, abrir en el panel), administrar los recursos de Spectrum (líneas, usuarios, plataformas, perfil, avatar), resolver la configuración y el entorno (PHOTON_PROJECT_ID, PHOTON_TOKEN, PHOTON_API_HOST, almacenamiento de credenciales, multi-backend) y facturación/actualizaciones (planes, pago, gestión, "actualización de proyectos"). Responde preguntas operativas como "¿cuántas líneas tengo?", "¿cuál es el secreto de mi proyecto?", "¿cómo puedo convertir esto en una línea de negocio?" y "¿cómo apunto la CLI a un backend diferente?". Este es el punto de entrada; la configuración de happy-path se encuentra justo debajo; consulte los archivos del tema para obtener una referencia completa.
