使用 Photon CLI 时使用 —“photon”二进制文件（别名“pho”）。利用此技能为用户设置/引导 Photon 并以非交互方式自行运行它（创建项目、捕获 id + 秘密、验证）——当用户说“为我设置这个”时，这就是你要做的工作，而不是交还给你。还包括运行任何 CLI 命令、身份验证（设备授权登录/注销/whoami/身份验证状态）、管理项目（创建、显示、列出、重命名、重新生成 Spectrum API 密钥、删除、在仪表板中打开）、管理 Spectrum 资源（线路、用户、平台、配置文件、头像）、解析配置和环境（PHOTON_PROJECT_ID、PHOTON_TOKEN、PHOTON_API_HOST、凭证存储、多后端）和计费/升级（计划、结帐、管理、“项目升级”）。回答操作问题，例如“我有多少行？”、“我的项目秘密是什么？”、“如何使其成为业务线？”以及“如何将 CLI 指向不同的后端？”。这是入口点； happy-path 设置就在下面——请参阅主题文件以获取完整参考。关键字：photon、pho、photon cli、photon-ai cli、@photon-ai/cli、photon 仪表板、命令行、终端、登录、设备授权、oauth 设备流程、注销、whoami、身份验证状态、凭证、PHOTON_PROJECT_ID、PHOTON_TOKEN、PHOTON_API_HOST、PHOTON_CONFIG_DIR、项目、创建项目、引导程序、项目 ID、项目秘密、重新生成秘密、旋转秘密、检查电话、升级、计费、计划、结账、条带、管理、门户、免费套餐、专业版、业务、企业、专用线路、频谱、线路、添加线路、消息线路、用户、邀请、平台、启用、禁用、配置文件、头像、ping、env、配置、json 输出、api 主机、多后端、后端、bun、指挥官、eden、仪表板-api、快速启动、代理设置、自动化设置、非交互式、可编写脚本的引导程序、设置光子。
