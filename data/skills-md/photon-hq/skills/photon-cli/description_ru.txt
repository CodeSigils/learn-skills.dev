Используйте при работе с Photon CLI — двоичный файл `photon` (псевдоним `pho`). Используйте этот навык, чтобы настроить/загрузить Photon для пользователя и запустить его самостоятельно в неинтерактивном режиме (создать проект, получить идентификатор + секрет, проверить) — когда пользователь говорит «настройте это для меня», это ваша работа, а не возвращать его обратно. Также охватывает выполнение любой команды CLI, аутентификацию (вход в систему / выход из системы / статус whoami / аутентификации), управление проектами (создание, отображение, список, переименование, повторное создание секрета Spectrum API, удаление, открытие на панели управления), управление ресурсами Spectrum (линии, пользователи, платформы, профиль, аватар), разрешение конфигурации и среды (PHOTON_PROJECT_ID, PHOTON_TOKEN, PHOTON_API_HOST, хранилище учетных данных, мультибэкэнд) и выставление счетов/обновления (планы, оформление заказа, управление, «обновление проектов»). Отвечает на оперативные вопросы, такие как «сколько у меня строк?», «Какой секрет моего проекта?», «Как мне сделать это бизнес-линейкой?» и «Как мне указать CLI на другой бэкэнд?».
