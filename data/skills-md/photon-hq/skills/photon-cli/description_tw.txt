使用 Photon CLI 時使用 —“photon”二進位檔案（別名“pho”）。利用此技能為用戶設定/引導 Photon 並以非互動方式自行運行它（創建專案、捕獲 id + 秘密、驗證）——當用戶說「為我設定這個」時，這就是你要做的工作，而不是交還給你。還包括執行任何 CLI 命令、驗證（裝置授權登入/登出/whoami/驗證狀態）、管理專案（建立、顯示、列出、重新命名、重新產生 Spectrum API 金鑰、刪除、在儀表板中開啟）、管理 Spectrum資源（線路、使用者、平台、設定檔、頭像）、解析配置和環境（PHOTON_PROJECT_ID、PHOTON_TOKEN、PHOTON_API_HOST、憑證儲存、多後端）和計費/升級（計畫、結帳、管理、「專案升級」）。回答操作問題，例如「我有多少行？」、「我的專案秘密是什麼？」、「如何使其成為業務線？」以及「如何將 CLI 指向不同的後端？」。這是入口點； happy-path 設定就在下面—請參閱主題檔案以取得完整參考。關鍵字：photon、pho、photon cli、photon-ai cli、@photon-ai/cli、photon 儀表板、命令列、終端、登入、裝置授權、oauth 設備流程、登出、whoami、驗證狀態、憑證、PHOTON_PROJECT_ID、PHOTON_TOKEN、PHOTON_API_HOST、PHOTON_PROJECT_ID、PHOTON_TOKEN、PHOTON_API_HOST、PHOTON_PROJST、ID、PHOTON_TOKEN、PHOTON_API_HOST、PHOTON 項目ID、專案機密、重新產生秘密、旋轉秘密、檢查電話、升級、計費、計劃、結帳、條帶、管理、入口網站、免費套餐、專業版、業務、企業、專用線路、頻譜、線路、新增線路、訊息線路、用戶、邀請、平台、啟用、停用、設定檔、頭像、ping、env、設定、json 輸出、api主機、多後端、後端、bun、指揮官、eden、儀表板-api、快速啟動、代理設定、自動化設定、非互動式、可編寫腳本的引導程式、設定光子。
