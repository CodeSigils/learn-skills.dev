Настраивает конечные точки VPC (интерфейс и шлюз) для доступа к частным сервисам AWS с помощью AWS PrivateLink. Используйте при настройке безопасного частного подключения к S3, DynamoDB и другим сервисам AWS без интернет-шлюза, устройства NAT или общедоступных IP-адресов. Охватывает создание конечных точек, группы безопасности, таблицы маршрутов и настройку DNS.
