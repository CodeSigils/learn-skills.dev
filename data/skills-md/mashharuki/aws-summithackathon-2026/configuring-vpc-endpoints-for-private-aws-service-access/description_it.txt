Configura gli endpoint VPC (interfaccia e gateway) per l'accesso privato al servizio AWS utilizzando AWS PrivateLink. Da utilizzare quando si configura una connettività privata sicura a S3, DynamoDB e altri servizi AWS senza gateway Internet, dispositivo NAT o indirizzi IP pubblici. Copre la creazione di endpoint, gruppi di sicurezza, tabelle di routing e configurazione DNS.
