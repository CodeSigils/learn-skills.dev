Configura puntos de enlace de VPC (interfaz y puerta de enlace) para acceso privado a servicios de AWS mediante AWS PrivateLink. Úselo al configurar una conectividad privada segura con S3, DynamoDB y otros servicios de AWS sin puerta de enlace de Internet, dispositivo NAT o direcciones IP públicas. Cubre la creación de puntos finales, grupos de seguridad, tablas de rutas y configuración de DNS.
