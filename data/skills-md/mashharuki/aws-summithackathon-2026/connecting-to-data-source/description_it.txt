Crea e risolvi i problemi delle connessioni AWS Glue ai database JDBC (Oracle, SQL Server, PostgreSQL, MySQL, RDS), Redshift, Snowflake e BigQuery. Raccoglie suggerimenti di connessione dall'utente, rileva connessioni esistenti e candidati RDS/Redshift, registra le credenziali in Secrets Manager o l'autenticazione DB IAM, configura VPC ed esegue test. Si attiva: connessione al database, configurazione della connessione Glue, registrazione dell'origine dati, connessione a Snowflake/BigQuery/RDS, timeout della connessione, test della connessione, risoluzione dei problemi di connessione. NON utilizzare per lo spostamento di dati (utilizzare ingesting-into-data-lake), creazione di tabelle (utilizzare Creation-Data-Lake-Table), query (utilizzare querying-data-lake), esplorazione del catalogo (utilizzare Explore-Data-Catlog) o SaaS (Salesforce, ServiceNow, SAP, MongoDB, Kafka).
