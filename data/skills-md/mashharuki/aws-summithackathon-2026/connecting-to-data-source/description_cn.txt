创建与 JDBC 数据库（Oracle、SQL Server、PostgreSQL、MySQL、RDS）、Redshift、Snowflake 和 BigQuery 的 AWS Glue 连接并排查问题。收集用户的连接提示，发现现有连接和 RDS/Redshift 候选连接，在 Secrets Manager 或 IAM DB 身份验证中注册凭证，配置 VPC 并进行测试。触发条件：连接到数据库、设置 Glue 连接、注册数据源、连接到 Snowflake/BigQuery/RDS、连接超时、测试连接、排除连接故障。请勿用于移动数据（使用 ingesting-into-data-lake）、创建表（使用创建数据湖表）、查询（使用查询数据湖）、目录探索（使用探索数据目录）或 SaaS（Salesforce、ServiceNow、SAP、MongoDB、Kafka）。
