建立與 JDBC 資料庫（Oracle、SQL Server、PostgreSQL、MySQL、RDS）、Redshift、Snowflake 和 BigQuery 的 AWS Glue 連線並排查問題。收集使用者的連接提示，發現現有連接和 RDS/Redshift 候選連接，在 Secrets Manager 或 IAM DB 驗證中註冊憑證，配置 VPC 並進行測試。觸發條件：連接到資料庫、設定 Glue 連線、註冊資料來源、連接到 Snowflake/BigQuery/RDS、連線逾時、測試連線、排除連線故障。請勿用於行動資料（使用 ingesting-into-data-lake）、建立表格（使用建立資料湖表）、查詢（使用查詢資料湖）、目錄探索（使用探索資料目錄）或 SaaS（Salesforce、ServiceNow、SAP、MongoDB、Kafka）。
