Cree y solucione problemas de conexiones de AWS Glue a bases de datos JDBC (Oracle, SQL Server, PostgreSQL, MySQL, RDS), Redshift, Snowflake y BigQuery. Recopila sugerencias de conexión del usuario, descubre conexiones existentes y candidatos de RDS/Redshift, registra credenciales en Secrets Manager o autenticación de base de datos de IAM, configura VPC y realiza pruebas. Activadores: conectarse a la base de datos, configurar la conexión de Glue, registrar la fuente de datos, conectarse a Snowflake/BigQuery/RDS, tiempo de espera de conexión, probar la conexión, solucionar problemas de conexión. NO lo use para mover datos (use ingesta en lago de datos), creación de tablas (use creación de tabla de lago de datos), consultas (use consulta de lago de datos), exploración de catálogos (use exploración de catálogo de datos) o SaaS (Salesforce, ServiceNow, SAP, MongoDB, Kafka).
