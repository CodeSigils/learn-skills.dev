Глубокий анализ любого проекта GitHub с открытым исходным кодом в красиво оформленный HTML-отчет, понятный как специалистам по продукту, так и инженерам. Охватывает архитектуру, проектные решения, сопоставимые репозитории и практические сценарии приложений. Используйте этот навык всякий раз, когда пользователь делится URL-адресом репозитория GitHub и просит проанализировать, объяснить, разобрать или понять проект. Также срабатывает, когда пользователь говорит такие вещи, как «разобрать этот репозиторий», «как работает этот проект», «проанализировать эту кодовую базу», «познакомить меня с этим репозиторием», «чему я могу научиться из этого проекта», «объяснить этот проект с открытым исходным кодом», «拆解一下», «帮我看看这个项目» или «讲解这个 репозиторий». Даже если пользователь просто бросит ссылку на GitHub с кратким вопросом: «Что это?» — используйте этот навык. Создает отточенный HTML-документ, описывающий логику продукта, техническую архитектуру и практические выводы.
