Desmontaje profundo de cualquier proyecto de código abierto de GitHub en un informe HTML bellamente diseñado que tanto el personal de producto como los ingenieros puedan entender. Cubre arquitectura, decisiones de diseño, repositorios comparables y escenarios de aplicaciones procesables. Utilice esta habilidad siempre que el usuario comparta una URL de repositorio de GitHub y solicite analizar, explicar, desmantelar o comprender un proyecto. También se activa cuando el usuario dice cosas como "desglosar este repositorio", "cómo funciona este proyecto", "analizar este código base", "guiarme a través de este repositorio", "qué puedo aprender de este proyecto", "explicar este proyecto de código abierto", "拆解一下", "帮我看看这个项目" o "讲解这个 repositorio". Incluso si el usuario simplemente coloca un enlace de GitHub con un breve "¿qué es esto?" - usa esta habilidad. Produce un documento HTML pulido que cubre la lógica del producto, la arquitectura técnica y conclusiones prácticas.
