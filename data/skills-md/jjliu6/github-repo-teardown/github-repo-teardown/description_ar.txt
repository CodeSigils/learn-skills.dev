قم بتفكيك أي مشروع مفتوح المصدر على GitHub إلى تقرير HTML مصمم بشكل جميل يمكن أن يفهمه كل من موظفي المنتج والمهندسين. يغطي الهندسة المعمارية وقرارات التصميم واتفاقيات إعادة الشراء القابلة للمقارنة وسيناريوهات التطبيق القابلة للتنفيذ. استخدم هذه المهارة عندما يشارك المستخدم عنوان URL الخاص بـ GitHub repo ويطلب تحليل المشروع أو شرحه أو هدمه أو فهمه. يتم تشغيله أيضًا عندما يقول المستخدم أشياء مثل "تفكيك هذا الريبو"، أو "كيف يعمل هذا المشروع"، أو "تحليل قاعدة التعليمات البرمجية هذه"، أو "التعرف على هذا الريبو"، أو "ما الذي يمكنني تعلمه من هذا المشروع"، أو "شرح هذا المشروع مفتوح المصدر"، أو "المصدر المفتوح"، أو "الريبو"، أو "الريبو". حتى لو قام المستخدم فقط بإسقاط رابط GitHub بملخص "ما هذا؟" - استخدم هذه المهارة. يُنتج مستند HTML مصقولًا يغطي منطق المنتج والهندسة الفنية والوجبات العملية.
