GitHub オープンソース プロジェクトを詳細に分解して、製品担当者とエンジニアの両方が理解できる美しくデザインされた HTML レポートを作成します。アーキテクチャ、設計上の決定、比較可能なリポジトリ、実用的なアプリケーション シナリオをカバーします。ユーザーが GitHub リポジトリ URL を共有し、プロジェクトの分析、説明、分解、または理解を求めるときは常に、このスキルを使用します。また、ユーザーが「このリポジトリを分解する」、「このプロジェクトはどのように機能するか」、「このコードベースを分析する」、「このリポジトリについて説明する」、「このプロジェクトから何が学べるか」、「このオープンソース プロジェクトについて説明する」、「拆解一下」、「帮我看看这个项目」、または「讲解这个リポジトリ」などの発言をしたときにもトリガーされます。ユーザーが単に「これは何ですか?」という短い文とともに GitHub リンクをドロップした場合でも、 — このスキルを使用します。製品ロジック、技術アーキテクチャ、実用的な要点を網羅した、洗練された HTML 分解ドキュメントを作成します。
