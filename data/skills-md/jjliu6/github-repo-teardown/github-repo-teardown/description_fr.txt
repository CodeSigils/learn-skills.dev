Démontage approfondi de n'importe quel projet open source GitHub dans un rapport HTML magnifiquement conçu que les responsables produit et les ingénieurs peuvent comprendre. Couvre l'architecture, les décisions de conception, les dépôts comparables et les scénarios d'application exploitables. Utilisez cette compétence chaque fois que l'utilisateur partage une URL de dépôt GitHub et demande à analyser, expliquer, démonter ou comprendre un projet. Déclenchez également lorsque l'utilisateur dit des choses comme "décomposer ce dépôt", "comment fonctionne ce projet", "analyser cette base de code", "guidez-moi à travers ce dépôt", "que puis-je apprendre de ce projet", "expliquer ce projet open source", "拆解一下", "帮我看看这个项目" ou "讲解这个 repo". Même si l'utilisateur dépose simplement un lien GitHub avec un bref « qu'est-ce que c'est ? - utilisez cette compétence. Produit un document de démontage HTML soigné couvrant la logique du produit, l'architecture technique et les points pratiques à retenir.
