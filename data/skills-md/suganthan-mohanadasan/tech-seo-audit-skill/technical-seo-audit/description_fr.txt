Compétence technique complète d'audit SEO qui analyse les données d'exploration pour identifier les problèmes, hiérarchiser les actions en fonction de leur impact commercial et produire un rapport détaillé ainsi qu'une feuille de calcul exploitable. Utilisez cette compétence chaque fois que l'utilisateur souhaite : exécuter un audit technique de référencement, analyser la santé technique d'un site Web, examiner les données d'exploration de Screaming Frog ou Sitebulb, explorer un site via une API (Firecrawl ou similaire), trouver des problèmes d'indexabilité ou d'exploration, vérifier les Core Web Vitals, auditer les données structurées ou le balisage de schéma, détecter la cannibalisation ou le contenu léger, examiner les chaînes de redirection, trouver des pages orphelines, évaluer l'architecture du site ou produire une liste prioritaire de correctifs SEO. Se déclenche également lorsque l'utilisateur télécharge un CSV à partir de n'importe quel outil d'analyse et demande une analyse, mentionne « SEO technique », « audit de site », « audit d'exploration », « bilan de santé SEO » ou souhaite comprendre pourquoi les pages ne sont pas classées d'un point de vue technique. Cette compétence gère tout, depuis l'ingestion de données jusqu'à l'élaboration d'un plan d'action priorisé en termes d'impact sur l'entreprise.
