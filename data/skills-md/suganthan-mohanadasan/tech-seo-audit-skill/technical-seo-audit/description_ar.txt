مهارة تدقيق فنية شاملة لتحسين محركات البحث (SEO) تعمل على تحليل الزحف إلى البيانات لتحديد المشكلات وتحديد أولويات الإجراءات حسب تأثير الأعمال وإنتاج تقرير مفصل بالإضافة إلى جدول بيانات قابل للتنفيذ. استخدم هذه المهارة عندما يريد المستخدم: إجراء تدقيق فني لتحسين محركات البحث، أو تحليل السلامة الفنية لموقع الويب، أو مراجعة بيانات الزحف من Screaming Frog أو Sitebulb، أو الزحف إلى موقع عبر واجهة برمجة التطبيقات (Firecrawl أو ما شابه)، أو العثور على مشكلات قابلية الفهرسة أو قابلية الزحف، أو التحقق من مؤشرات الويب الأساسية، أو تدقيق البيانات المنظمة أو ترميز المخطط، أو اكتشاف التفكيك أو المحتوى الرقيق، أو مراجعة سلاسل إعادة التوجيه، أو العثور على الصفحات اليتيمة، أو تقييم بنية الموقع، أو إنتاج قائمة ذات أولوية لإصلاحات SEO. يتم تشغيله أيضًا عندما يقوم المستخدم بتحميل ملف CSV من أي أداة زحف ويطلب التحليل، أو يذكر "تحسين محركات البحث الفني"، أو "تدقيق الموقع"، أو "تدقيق الزحف"، أو "فحص صحة تحسين محركات البحث"، أو يريد فهم سبب عدم ترتيب الصفحات من منظور تقني. تتعامل هذه المهارة مع كل شيء بدءًا من استيعاب البيانات وحتى خطة العمل ذات الأولوية لتأثير الأعمال.
