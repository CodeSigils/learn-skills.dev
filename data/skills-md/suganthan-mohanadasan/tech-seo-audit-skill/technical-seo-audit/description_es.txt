Habilidad técnica integral de auditoría de SEO que analiza datos de rastreo para identificar problemas, priorizar acciones según el impacto comercial y producir un informe detallado más una hoja de cálculo procesable. Utilice esta habilidad siempre que el usuario quiera: ejecutar una auditoría técnica de SEO, analizar el estado técnico de un sitio web, revisar datos de rastreo de Screaming Frog o Sitebulb, rastrear un sitio a través de API (Firecrawl o similar), encontrar problemas de indexabilidad o rastreabilidad, verificar Core Web Vitals, auditar datos estructurados o marcado de esquema, detectar canibalización o contenido delgado, revisar cadenas de redireccionamiento, encontrar páginas huérfanas, evaluar la arquitectura del sitio o producir una lista priorizada de correcciones de SEO. También se activa cuando el usuario carga un CSV desde cualquier herramienta de rastreo y solicita un análisis, menciona "SEO técnico", "auditoría del sitio", "auditoría de rastreo", "verificación del estado de SEO" o quiere comprender por qué las páginas no se clasifican desde una perspectiva técnica. Esta habilidad maneja todo, desde la ingesta de datos hasta un plan de acción priorizado para el impacto empresarial.
