Traitement interactif du backlog pour les problèmes GitHub ouverts. Classifie, relie, signale les obsolètes/obsolètes et propose des priorités — produit un rapport de tri des démarques que vous examinez avant de postuler. Conseil par défaut ; les mutations nécessitent un --apply explicite. À utiliser pour l'examen du backlog, le traitement des problèmes, le nettoyage obsolète, le reclassement des priorités, etc.
