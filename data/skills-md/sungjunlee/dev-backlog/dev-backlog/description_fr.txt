Gérez le travail de développement via les problèmes GitHub + les fichiers sprint locaux. Les problèmes/jalons sont la source de la vérité ; les fichiers de sprint locaux gèrent l'exécution : traitement par lots, classement, contexte et progression. À utiliser pour créer des problèmes, planifier des sprints, vérifier les éléments sur lesquels travailler, examiner les progrès, synchroniser avec GitHub, gérer les jalons, le backlog, etc.
