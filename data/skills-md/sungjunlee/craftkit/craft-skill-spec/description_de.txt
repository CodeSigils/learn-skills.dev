Entwerfen Sie einen neuen Skill (oder eine Skill-Suite, einen Subagenten oder ein Plugin) mithilfe der aktuellen Radaranleitung von CraftKit. Verwenden Sie dies immer dann, wenn ein Benutzer ein neues Skill-ähnliches Artefakt erstellen, entwerfen oder spezifizieren möchte und Hilfe bei der Entscheidung über die Artefaktklasse, die zu übernehmenden/vermeidenden Muster und die Datei- oder Paketform benötigt, bevor er „SKILL.md“ schreibt – einschließlich Anfragen wie „Entwerfen Sie einen Skill“, „Spezifizieren Sie diesen Skill“, „Erstellen Sie einen Meta-Skill“, „Entwerfen Sie einen Subagenten“, „Spezifizieren Sie ein Plugin“ oder „Was soll das sein – Skill oder Subagent?“
