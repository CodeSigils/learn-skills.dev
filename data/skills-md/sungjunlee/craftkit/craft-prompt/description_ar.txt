قم بصياغة مطالبات جيدة التنظيم وجاهزة للنسخ واللصق لأي ماجستير في القانون - Claude أو GPT أو Gemini أو Perplexity أو أي شيء آخر. استخدم هذا عندما يريد المستخدم إنشاء موجه من البداية، أو يطلب "كتابة/إنشاء/إنشاء موجه"، أو يحتاج إلى موجه تسليم للجلسة لنقل العمل إلى جلسة Claude Code أو Codex جديدة، أو يشارك ملاحظات متناثرة تحتاج إلى تشكيلها في موجه قابل للاستخدام، أو يطلب قالب موجه قابل لإعادة الاستخدام - حتى لو لم يذكر "مطالبة" صراحةً. يتم تشغيله أيضًا على المرادفات الكورية مثل "프롬프트 만들어،" "프롬프트 작성،" "프롬프트 빌드."
