Créez des invites bien structurées et prêtes à copier-coller pour n'importe quel LLM - Claude, GPT, Gemini, Perplexity ou tout autre. Utilisez-le chaque fois que l'utilisateur souhaite créer une invite à partir de zéro, demande « d'écrire/créer/construire une invite », a besoin d'une invite de transfert de session pour effectuer le travail dans une nouvelle session Claude Code ou Codex, partage des notes dispersées qui doivent être transformées en une invite utilisable ou demande un modèle d'invite réutilisable, même s'ils ne disent pas explicitement « invite ». Se déclenche également sur les équivalents coréens tels que « 프롬프트 만들어 », « 프롬프트 작성 », « 프롬프트 빌드 ».
