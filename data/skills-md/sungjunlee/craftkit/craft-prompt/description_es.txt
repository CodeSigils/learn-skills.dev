Cree indicaciones bien estructuradas y listas para copiar y pegar para cualquier LLM: Claude, GPT, Gemini, Perplexity o cualquier otro. Utilice esto siempre que el usuario desee crear un mensaje desde cero, solicite "escribir/crear/crear un mensaje", necesite un mensaje de transferencia de sesión para llevar el trabajo a una nueva sesión de Claude Code o Codex, comparta notas dispersas que deben transformarse en un mensaje utilizable o solicite una plantilla de mensaje reutilizable, incluso si no dicen explícitamente "mensaje". También se activan equivalentes coreanos como "프롬프트 만들어", "프롬프트 작성", "프롬프트 빌드".
