Trasforma un'idea approssimativa in un prompt strutturato o in un'impalcatura di competenze con obiettivi, input, flusso di lavoro, output espliciti e un piano di file concreto. Utilizzalo ogni volta che l'utente desidera progettare un nuovo prompt o competenza, strutturare un flusso di lavoro simile a una competenza, menziona "impalcatura", "progetto", "struttura" o "piano" per un prompt o arriva con una richiesta vaga che deve essere modellata prima dell'implementazione, anche se non chiede esplicitamente di utilizzare l'impalcatura.
