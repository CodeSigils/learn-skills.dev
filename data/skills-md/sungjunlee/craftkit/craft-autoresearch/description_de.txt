Bewertungsgesteuerte autonome Optimierungsschleife für eine Eingabeaufforderung oder Fertigkeit. Definieren Sie Bewertungskriterien und ein Laufsystem und führen Sie dann eine Iteration durch – führen Sie das Artefakt auf Testeingaben aus, bewerten Sie Ausgaben, ändern Sie die Eingabeaufforderung oder Fertigkeit, behalten Sie Verbesserungen bei, verwerfen Sie Regressionen und stoppen Sie bei einer schriftlichen Bedingung. Verwenden Sie dies immer dann, wenn der Benutzer eine Eingabeaufforderung oder Fertigkeit automatisch verbessern möchte, automatische Forschung, bewertungsgesteuerte Optimierung, Benchmarking einer Fertigkeit, das Ausführen von Bewertungen, die Selbstverbesserung einer Eingabeaufforderung oder eine iterative Test- und Verfeinerungsanforderung erwähnt – einschließlich 스킬 개선, 스킬 최적화, 스킬 벤치마크, Auch wenn dort nicht „Autoresearch“ steht.
