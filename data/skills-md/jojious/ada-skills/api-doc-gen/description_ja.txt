ソース コードから API ドキュメントを生成して検証します。ハンドラー/ルーター ファイルをスキャンして、構造化された Markdown API ドキュメントを docs/api/ に生成します。エンドポイントごとに 1 つのファイルがハンドラー ドメインごとにグループ化されます。または、既存のドキュメントを現在のコードベースと照合して検証します。ユーザーが API ドキュメントの生成、API ドキュメントの更新、API ドキュメントが古いかどうかの確認、コードからエンドポイント ドキュメントの作成を行う場合、または「gen api doc」、「สร้าง api doc」、「อัปเดต api doc」、「เช็ค api doc」などの発言をする場合は、このスキルを使用します。 「コード コード」、「これらのエンドポイントを文書化してください」、「API 文書が古くなっています」。また、ネオチームが API ドキュメントタスクをこのスキルに委任したときにもトリガーされます。
