Создавайте и проверяйте документацию API на основе исходного кода. Сканирует файлы обработчиков/маршрутизаторов для создания структурированных документов Markdown API в docs/api/ — по одному файлу на каждую конечную точку, сгруппированному по домену обработчика. Или проверяет существующие документы на соответствие текущей базе кода. Используйте этот навык всякий раз, когда пользователь хочет сгенерировать документацию API, обновить документацию API, проверить, не устарели ли документы API, создать документацию по конечным точкам из кода или сказать такие вещи, как «создать документ API», «создать документ API», «документ API Doc», «документ API Doc». Ошибка кода, "задокументируйте эти конечные точки", "документ API устарел". Также срабатывает, когда neo-team делегирует этому навыку задачи по документированию API.
