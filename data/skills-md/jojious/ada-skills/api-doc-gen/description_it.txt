Genera e convalida la documentazione API dal codice sorgente. Esegue la scansione dei file del gestore/router per produrre documenti API Markdown strutturati in docs/api/: un file per endpoint, raggruppato per dominio del gestore. Oppure convalida i documenti esistenti rispetto alla codebase corrente. Utilizza questa competenza ogni volta che l'utente desidera generare documenti API, aggiornare la documentazione API, verificare se i documenti API non sono aggiornati, creare documentazione endpoint dal codice o dire cose come "gen api doc", "สร้าง api doc", "อัปเดต api doc", "เช็ค api doc" Utilizzare il codice "documenta questi endpoint", "api doc obsoleto". Si attiva anche quando il neo-team delega le attività di documentazione API a questa competenza.
