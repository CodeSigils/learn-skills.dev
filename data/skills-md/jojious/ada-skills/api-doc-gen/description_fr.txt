Générez et validez la documentation de l'API à partir du code source. Analyse les fichiers du gestionnaire/routeur pour produire des documents structurés de l'API Markdown dans docs/api/ — un fichier par point de terminaison, regroupés par domaine du gestionnaire. Ou valide les documents existants par rapport à la base de code actuelle. Utilisez cette compétence chaque fois que l'utilisateur souhaite générer des documents API, mettre à jour la documentation API, vérifier si les documents API sont obsolètes, créer une documentation de point de terminaison à partir du code ou dire des choses comme "gen api doc", "สร้าง api doc", "อัปเดต api doc", "เช็ค api doc". Dans le code ci-dessus", "documentez ces points de terminaison", "document API obsolète". Se déclenche également lorsque la néo-équipe délègue des tâches de documentation API à cette compétence.
