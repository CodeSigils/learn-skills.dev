يُستخدم عندما يكون التغيير الأساسي هو استبدال أحد التطبيقات مع الحفاظ على استقرار السطح العام ونموذج التكنولوجيا ماديًا. المحفزات: إعادة كتابة خدمة فوضوية خلف نفس الواجهة، أو استبدال المنطق القديم بوحدة نظيفة، أو إعادة تنفيذ نظام فرعي خلف عقد موجود، أو تقديم محول أو واجهة حتى يمكن تنفيذ جديد. لا تستخدم عندما يكون العمل الرئيسي هو نقل الوحدة النمطية أو الحزمة أو حدود المتصل (استخدم `الترحيل الدلالي الآمن للوحدة النمطية`) أو عندما يكون تغيير إطار العمل أو وقت التشغيل أو الإصدار أو نظام الوحدة النمطية أو نموذج البرمجة هو المصدر الرئيسي للخطر (استخدم `الترحيل الدلالي الآمن للتكنولوجيا`).
