Audite y habilite la configuración de compilación de Xcode orientada a la seguridad. Habilita progresivamente advertencias del compilador, verificadores de analizadores estáticos y funciones de seguridad mejorada. Úselo cuando: el usuario quiera proteger su proyecto Xcode, auditar la configuración de seguridad, habilitar el refuerzo, revisar la postura de seguridad de la configuración de compilación, configurar un análisis estático centrado en la seguridad, habilitar el análisis estático, mejorar la cobertura de advertencias, reforzar los diagnósticos o detectar más errores en el tiempo de compilación en C/C++/Objective-C/Swift. SALTAR: seguridad de red (TLS/ATS), firma de código, API de privacidad.
