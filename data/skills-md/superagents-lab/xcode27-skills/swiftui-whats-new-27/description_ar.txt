واجهات برمجة تطبيقات SwiftUI الجديدة والسلوكيات وعمليات الإيقاف المقدمة في إصدارات نظام التشغيل 2027 (iOS 27 وmacOS 27 وwatchOS 27 وtvOS 27 وvisionOS 27). يُستخدم عندما يفشل عرض SwiftUI باستخدام @State في التجميع مع أخطاء "مستخدم قبل التهيئة"، أو "إعادة تعريف غير صالح للخاصية المركبة"، أو "تسمية وسيطة غير ضرورية" بعد تحديث SDK (تم ترحيل @State من غلاف خاصية إلى ماكرو في SDK 27؛ الإصلاح الواضح لإعادة ترتيب تعيينات init خاطئ وينتج سلوك وقت تشغيل غير صحيح؛ يجب عليك استشارة مراجع هذه المهارة قبل الإجابة)؛ عندما يصل كود @ViewBuilder أو @ContentBuilder إلى حمولات زائدة غامضة في التراكب/الخلفية أو تراجع أداء التحقق من النوع بعد تحديث SDK؛ عندما يسأل المستخدم عن الجديد في SwiftUI (بشكل عام، أو لمنصة 2027 محددة)؛ عند إضافة السحب لإعادة الترتيب إلى أي حاوية (List، أو LazyVStack، أو LazyVGrid، أو الأكوام، أو التخطيطات المخصصة) عبر reorderable()/reorderContainer، بما في ذلك السحب والإفلات الذي يتكامل معها (dragContainer، dropDestination)، أو دمج العناصر بإسقاط واحد على آخر؛ عند العمل مع تحميل AsyncImage والتخزين المؤقت (إعادة تحميل الصور عند التمرير للخلف، أو ذاكرة التخزين المؤقت HTTP الافتراضية، أو سياسة التخزين المؤقت لكل طلب عبر AsyncImage(request:)/URLRequest، أو تطبيق جلسة URL مخصصة باستخدام asyncImageURLSession)؛ عند إضافة إجراءات التمرير إلى الصفوف (التمرير السريع للحذف أو إجراءات التمرير الأخرى) في ScrollView أو LazyVStack أو LazyVGrid أو المكدس وليس القائمة فقط، عبر swipeActions()/swipeActionsContainer(); عند العمل باستخدام أشرطة الأدوات، مثل التحكم في العناصر التي تظل مرئية مقابل الانتقال إلى القائمة الكاملة عندما تكون المساحة محدودة أو يتم قطع الأزرار (visibilityPriority، ToolbarOverflowMenu)، أو تثبيت عنصر بحيث لا يفيض أبدًا (topBarPinnedTrailing)، أو تصغير شريط التنقل أو شريط الأدوات عند التمرير (toolbarMinimizeBehavior)، أو إنشاء عناصر شريط الأدوات باستخدام ForEach، أو إخفاء شريط الحالة عبر موضع شريط أدوات شريط الحالة؛ عند تقديم مربع حوار تأكيد أو تنبيه من ربط عنصر اختياري (شكل الورقة (العنصر :)) بحيث يظهر عندما تصبح القيمة المرتبطة غير صفرية ويمرر العنصر غير المغلف إلى الإجراءات وإغلاق الرسائل؛ عند إنشاء تطبيق يستند إلى مستند أو ترحيله (بما في ذلك عارضي المستندات للقراءة فقط)، أو قراءة الملفات أو كتابتها من خلال DocumentGroup، أو تحسين أداء الحفظ التلقائي لمستندات الحزمة، أو الوصول إلى عنوان URL لملف المستند مباشرةً (على سبيل المثال للتسليم إلى AVFoundation، أو PDFKit، أو Core Image، أو أي مكتبة C تأخذ مسارًا)، أو الإبلاغ عن التقدم من عملية حفظ أو تحميل، أو الترحيل من FileDocument / ReferenceFileDocument؛ أو عند حل حالات عدم توافق مصدر SDK 27.0 الأخرى وتحذيرات الإهمال (على سبيل المثال، StatusBarHidden في VisionOS).
