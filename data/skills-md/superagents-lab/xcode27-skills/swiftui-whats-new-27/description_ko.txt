2027 OS 릴리스(iOS 27, macOS 27, watchOS 27, tvOS 27, VisionOS 27)에 새로운 SwiftUI API, 동작 및 지원 중단이 도입되었습니다. @State를 사용하는 SwiftUI 뷰가 SDK 업데이트 후 "초기화되기 전에 사용됨", "합성된 속성의 잘못된 재선언" 또는 "외부 인수 레이블" 오류와 함께 컴파일에 실패할 때 사용합니다(@State는 속성 래퍼에서 SDK 27의 매크로로 마이그레이션되었습니다. 초기화 할당 재정렬의 명백한 수정은 잘못되었으며 잘못된 런타임 동작을 생성합니다. 응답하기 전에 이 기술의 참조를 참조해야 합니다). @ViewBuilder 또는 @ContentBuilder 코드가 오버레이/백그라운드에서 모호한 오버로드에 도달하거나 SDK 업데이트 후 유형 확인 성능 회귀가 발생하는 경우 사용자가 SwiftUI의 새로운 기능(일반적으로 또는 특정 2027 플랫폼의 경우)을 물을 때 reorderable()/reorderContainer를 통해 컨테이너(List, LazyVStack, LazyVGrid, 스택 또는 사용자 정의 레이아웃)에 드래그하여 재정렬을 추가할 때(dragContainer, dropDestination) 통합되는 드래그 앤 드롭을 포함하거나 항목을 다른 항목 위에 놓아 항목을 결합하는 경우 AsyncImage 로드 및 캐싱 작업 시(뒤로 스크롤할 때 이미지 다시 로드, 기본 HTTP 캐시, AsyncImage(request:)/URLRequest를 통한 요청별 캐시 정책 또는 asyncImageURLSession을 사용하여 사용자 정의 URLSession 적용) swipeActions()/swipeActionsContainer()를 통해 List뿐만 아니라 ScrollView, LazyVStack, LazyVGrid 또는 스택의 행에 스와이프 작업(스와이프하여 삭제 또는 기타 스와이프 작업)을 추가할 때; 공간이 제한되거나 버튼이 잘릴 때 오버플로 메뉴로 이동하는 항목과 표시 상태를 유지하는 항목 제어(visibilityPriority, ToolbarOverflowMenu), 오버플로되지 않도록 항목 고정(topBarPinnedTrailing), 스크롤 시 탐색 모음 또는 도구 모음 최소화(toolbarMinimizeBehavior), ForEach를 사용하여 도구 모음 항목 생성 또는 statusBar 도구 모음 배치를 통해 상태 표시줄 숨기기 등 도구 모음 작업 시 선택적 항목 바인딩(sheet(item:) 모양)에서 확인 대화 상자나 경고를 표시할 때 바인딩된 값이 nil이 아닌 시점을 표시하고 래핑 해제된 항목을 작업 및 메시지 클로저로 전달합니다. 문서 기반 앱(읽기 전용 문서 뷰어 포함)을 구축 또는 마이그레이션할 때, DocumentGroup을 통해 파일을 읽거나 쓸 때, 패키지 문서의 자동 저장 성능을 최적화할 때, 문서의 파일 URL에 직접 접근할 때(예: AVFoundation, PDFKit, Core Image 또는 경로를 사용하는 모든 C 라이브러리에 전달하기 위해), 저장 또는 로드에서 진행 상황을 보고하거나 FileDocument / ReferenceFileDocument에서 마이그레이션할 때 또는 다른 SDK 27.0 소스 비호환성 및 지원 중단 경고를 해결할 때(예: VisionOS의 statusBarHidden)
