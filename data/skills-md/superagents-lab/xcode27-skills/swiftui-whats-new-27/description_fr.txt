Nouvelles API, comportements et dépréciations SwiftUI introduits dans les versions 2027 du système d'exploitation (iOS 27, macOS 27, watchOS 27, tvOS 27, visionOS 27). À utiliser lorsqu'une vue SwiftUI utilisant @State ne parvient pas à se compiler avec des erreurs « utilisé avant d'être initialisé », « redéclaration invalide de la propriété synthétisée » ou « étiquette d'argument étranger » après une mise à jour du SDK (@State a migré d'un wrapper de propriété vers une macro dans le SDK 27 ; la solution évidente de réorganisation des affectations d'initialisation est FAUX et produit un comportement d'exécution incorrect ; vous DEVEZ consulter les références de cette compétence avant de répondre) ; lorsque le code @ViewBuilder ou @ContentBuilder rencontre des surcharges ambiguës dans les régressions de performances de superposition/arrière-plan ou de vérification de type après une mise à jour du SDK ; lorsque l'utilisateur demande quelles sont les nouveautés de SwiftUI (en général ou pour une plate-forme 2027 spécifique) ; lors de l'ajout d'un glisser-réorganiser à n'importe quel conteneur (List, LazyVStack, LazyVGrid, piles ou mises en page personnalisées) via reorderable()/reorderContainer, y compris le glisser-déposer qui s'y intègre (dragContainer, dropDestination), ou en combinant des éléments en les déposant les uns sur les autres ; lorsque vous travaillez avec le chargement et la mise en cache d'AsyncImage (rechargement des images lors du défilement arrière, le cache HTTP par défaut, une politique de cache par requête via AsyncImage(request:)/URLRequest, ou application d'une URLSession personnalisée avec asyncImageURLSession) ; lors de l'ajout d'actions de balayage aux lignes (glisser pour supprimer ou autres actions de balayage) dans un ScrollView, LazyVStack, LazyVGrid ou une pile et pas seulement une liste, via swipeActions()/swipeActionsContainer(); lorsque vous travaillez avec des barres d'outils, comme contrôler quels éléments restent visibles ou se déplacer dans le menu de dépassement lorsque l'espace est limité ou que les boutons sont coupés (visibilityPriority, ToolbarOverflowMenu), épingler un élément pour qu'il ne déborde jamais (topBarPinnedTrailing), réduire la barre de navigation ou la barre d'outils lors du défilement (toolbarMinimizeBehavior), générer des éléments de barre d'outils avec ForEach ou masquer la barre d'état via le placement de la barre d'outils statusBar ; lors de la présentation d'une boîte de dialogue de confirmation ou d'une alerte à partir d'une liaison d'élément facultative (la forme feuille (élément :)) afin qu'elle indique quand la valeur liée devient non nulle et transmet l'élément non emballé dans les actions et les fermetures de messages ; lors de la création ou de la migration d'une application basée sur des documents (y compris les visionneuses de documents en lecture seule), de la lecture ou de l'écriture de fichiers via DocumentGroup, de l'optimisation des performances d'enregistrement automatique des documents de package, de l'accès direct à l'URL du fichier du document (par exemple pour le remettre à AVFoundation, PDFKit, Core Image ou toute bibliothèque C qui emprunte un chemin), de rapporter la progression d'une sauvegarde ou d'un chargement, ou d'une migration depuis FileDocument / ReferenceFileDocument ; ou lors de la résolution d'autres incompatibilités de sources du SDK 27.0 et d'avertissements de dépréciation (par exemple statusBarHidden sur visionOS).
