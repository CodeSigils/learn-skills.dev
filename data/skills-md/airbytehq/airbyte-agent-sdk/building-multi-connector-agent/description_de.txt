Erstellt einen vollständigen Agenten mit mehreren Airbyte-Konnektoren mithilfe von PydanticAI oder Claude SDK. Erstellt ein Gerüst für die Projektstruktur, verkabelt Anschlüsse, stellt Werkzeuge zusammen und erstellt eine Laufschleife. Verwenden Sie diese Option, wenn Sie einen Agenten mit mehreren Konnektoren erstellen oder ein Gerüst für ein neues Agentenprojekt erstellen.
