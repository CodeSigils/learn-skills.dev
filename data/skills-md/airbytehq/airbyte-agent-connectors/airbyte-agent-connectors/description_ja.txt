Airbyte Agent Connector (厳密に型付けされた Python パッケージ) をセットアップして操作します
統合されたエンティティ アクション インターフェイスを通じて 51 以上のサードパーティ SaaS API にアクセスできます。
サポートされているサービスには、Salesforce、HubSpot、Stripe、GitHub、Slack、Jira、Shopify、Zendesk、Google 広告、Notion、Linear、Intercom、Gong、
CRM、請求、
支払い、電子商取引、マーケティング、分析、プロジェクト管理、ヘルプデスク、開発者
ツール、人事、コミュニケーション プラットフォーム。ユーザーが必要なときに必ずこのスキルを使用してください
SaaS API に接続するには、airbyte-agent コネクタ パッケージをインストールします。
サードパーティのサービス データを Python アプリケーションまたは AI エージェントに統合し、クエリまたは
サポートされているサービスからレコードを検索したり、クロード用に Airbyte MCP ツールを設定したりできます。
プラットフォーム モード (Airbyte クラウド) と OSS モード (ローカル Python SDK) をカバーします。
