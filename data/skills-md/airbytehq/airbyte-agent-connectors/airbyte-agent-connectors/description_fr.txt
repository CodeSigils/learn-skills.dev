Configure et exploite les connecteurs d'agent Airbyte - packages Python fortement typés
pour accéder à plus de 51 API SaaS tierces via une interface entité-action unifiée.
Les services pris en charge incluent Salesforce, HubSpot, Stripe, GitHub, Slack, Jira, Shopify, Zendesk, Google Ads, Notion, Linear, Intercom, Gong,
et 36 autres connecteurs couvrant le CRM, la facturation,
paiements, e-commerce, marketing, analytique, gestion de projet, helpdesk, développeur
outils, RH et plateformes de communication. Assurez-vous d'utiliser cette compétence lorsque l'utilisateur le souhaite
pour vous connecter à n'importe quelle API SaaS, installez un package de connecteur airbyte-agent,
intégrer des données de service tiers dans une application Python ou un agent IA, une requête ou
recherchez des enregistrements à partir de n'importe quel service pris en charge ou configurez les outils Airbyte MCP pour Claude.
Couvre le mode plateforme (Airbyte Cloud) et le mode OSS (SDK Python local).
