Устанавливает и управляет коннекторами агентов Airbyte — строго типизированными пакетами Python.
для доступа к более чем 51 сторонним API-интерфейсам SaaS через единый интерфейс действий с объектами.
Поддерживаемые сервисы включают Salesforce, HubSpot, Stripe, GitHub, Slack, Jira, Shopify, Zendesk, Google Ads, Notion, Linear, Intercom, Gong,
и еще 36 соединителей, охватывающих CRM, биллинг,
платежи, электронная коммерция, маркетинг, аналитика, управление проектами, служба поддержки, разработчик
инструменты, HR и коммуникационные платформы. Обязательно используйте этот навык, когда пользователь хочет
для подключения к любому SaaS API установите пакет коннектора airbyte-agent,
интегрировать данные сторонних сервисов в приложение Python или агент AI, запрос или
выполните поиск записей в любом поддерживаемом сервисе или настройте инструменты Airbyte MCP для Claude.
Охватывает режим платформы (Airbyte Cloud) и режим OSS (локальный Python SDK).
