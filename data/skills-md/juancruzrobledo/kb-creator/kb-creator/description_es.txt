Crea una base de conocimientos de proyectos estructurada de 10 archivos .md canónicos en Knowledge-base/ (raíz del proyecto). Tiene modo dual: generación silenciosa a partir de documentos fuente existentes en docs/, o creación iterativa interactiva desde cero. Activador: Cuando el usuario solicita crear, construir o generar una base de conocimiento para un proyecto, documentar un proyecto a partir de documentos fuente (.txt, .docx, .pdf), o solicita "armar base de conocimiento" / "crear KB" / "documentar proyecto".
