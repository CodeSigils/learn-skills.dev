إنشاء قواعد التقييم الذاتي ومعالجتها ومراجعتها لـ Active-IA من إرسالية أي دخل (TP، جزئي، استرداد، نهائي أو عالمي). من خلال طريقة CURAR، يقوم بتحليل إرسالية ANTES لتأمين القاعدة واكتشاف المتطلبات التي تعمل على تعزيز تدفق تصحيح IA (روابط المستودع ومقاطع الفيديو والصور في كود TP، "النشر"، وإبلاغ PDF + كود juntos)، مما يدعم كل محول إلى تدفق واحد - كود O PDF —، قم بترك دليل التصحيح أو خدعة الكتابة، وأعد كتابة الرسالة الصحيحة دون فقدان النية. في طريقة CREAR، يتم إنشاء قائمة معايير JSON للزر "معايير الشحن"؛ في طريقة AUDITAR، تحصل على رسالة + رمز موجود وتصحيح اكتشاف التناقضات والسهو والاختراعات وإعادة ضبطها بـ 100 دولار. في طريقة TEST، يحاكي التصحيح الحقيقي (التوحيد + موجه سير العمل N8N → Gemini) محليًا مع CLI de Claude، لمعرفة ما هي الملاحظات والتعليقات التي تنتجها Rúbrica sobre una entrega before de subirla. استخدام هذه المهارة SIEMPRE هو أن المستخدم يريد تصميم أو إنشاء أو تصميم أو تعديل أو تعديل أو مراجعة أو تدقيق أو التحقق من PROBAR/TESTEAR قاعدة بيانات أو إشارة أو معايير التقييم الخاصة به - حتى لا يطلع على كلمة "قاعدة" صريحة (على سبيل المثال: "تسليح معايير التقييم" este TP", "revisá si esta consigna se puede corregir con la IA", "esta consigna pide una photo y es un TP de codego", "curá este TP", "revisá si esta Evaluacion cubre todo lo que pide el parcial", "esta rúbrica est bien؟", "probá cómo corrige esta rúbrica con esta entrega"). لا تستخدم لتصحيح الإنجازات الحقيقية لخريجي الإنتاج (هذه هي المهارة "تصحيح")؛ طريقة الاختبار هي مجرد إجراء محلي.
