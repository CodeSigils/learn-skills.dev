Используйте при написании или изменении кода Python, который импортирует `genoray` для чтения генотипов/дозировок из файлов VCF, PGEN или SparseVar (`.svar`). Охватывает поверхность общедоступного API, константы режима, запросы диапазона, фрагментацию, фильтрацию и рабочий процесс SparseVar. Пропустите несвязанную работу по биоинформатике.
