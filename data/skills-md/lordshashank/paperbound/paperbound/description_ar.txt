قم بتحويل أي مقالة أو عنوان URL للمدونة إلى كتاب ورقي تفاعلي واقعي كملف HTML مستقل مع رسوم متحركة لقلب الصفحة وأغلفة جلدية وصفحات ورقية كريمية. يُستخدم عندما يقدم المستخدم عنوان URL لمقالة/مدونة ويريد تحويله إلى كتاب، أو يطلب "إنشاء غلاف ورقي"، أو "حجز هذه المقالة"، أو "تحويل هذا إلى كتاب"، أو "غلاف ورقي لهذا"، أو ما شابه ذلك. يدعم أي مقال ويب، أو منشور مدونة، أو محتوى خاص بالنظام الأساسي (مقالات X/Twitter، وMedium، وSubstack، وHashnode، وما إلى ذلك). ينتج ملف HTML واحد محمول.
