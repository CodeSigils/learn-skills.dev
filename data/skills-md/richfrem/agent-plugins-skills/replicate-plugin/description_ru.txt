Инструмент разработчика для репликации исходного кода плагина между локальными репозиториями проектов. Используйте, если вы хотите отправить обновления плагинов из агента-плагинов-навыков в потребительский проект или загрузить последние плагины в потребительский проект из этого центрального репозитория. Работает с явными путями --source и --dest; поддерживает режимы аддитивного обновления (по умолчанию), --clean (также удаляет удаленные файлы), --link (символическая ссылка) и --dry-run.
