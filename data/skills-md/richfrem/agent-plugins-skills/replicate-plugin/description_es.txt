Máquina herramienta de desarrollador para replicar el código fuente del complemento entre repositorios de proyectos locales. Úselo cuando desee enviar actualizaciones de complementos desde agent-plugins-skills a un proyecto de consumidor, o incorporar los complementos más recientes a un proyecto de consumidor desde este repositorio central. Funciona con rutas explícitas --source y --dest; admite los modos de actualización aditiva (predeterminado), --clean (también elimina archivos eliminados), --link (enlace simbólico) y --dry-run.
