Machine-outil de développement pour répliquer le code source du plugin entre les référentiels de projets locaux. À utiliser lorsque vous souhaitez transférer les mises à jour de plugins d'agent-plugins-skills vers un projet consommateur, ou extraire les derniers plugins dans un projet consommateur à partir de ce référentiel central. Fonctionne avec les chemins explicites --source et --dest ; prend en charge les modes additive-update (par défaut), --clean (supprime également les fichiers supprimés), --link (symlink) et --dry-run.
