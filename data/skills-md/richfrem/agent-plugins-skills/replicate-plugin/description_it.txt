Macchina utensile per sviluppatori per replicare il codice sorgente del plugin tra repository di progetti locali. Da utilizzare quando si desidera inviare gli aggiornamenti dei plug-in dalle competenze dei plug-in dell'agente a un progetto consumer o inserire i plug-in più recenti in un progetto consumer da questo repository centrale. Funziona con percorsi espliciti --source e --dest; supporta le modalità di aggiornamento additivo (impostazione predefinita), --clean (rimuove anche i file eliminati), --link (link simbolico) e --dry-run.
