دمج تسجيل الدخول مع ChatGPT (@opencoredev/loginwithchatgpt-*): اسمح للمستخدمين بتسجيل الدخول باستخدام حساب ChatGPT الخاص بهم وتشغيل طلبات الذكاء الاصطناعي مقابل خطة ChatGPT الخاصة بهم. يُستخدم عند إضافة معلومات تسجيل الدخول إلى حساب ChatGPT، أو تركيب createChatGPTHandler، أو عرض زر LoginWithChatGPT React أو خطاف useLoginWithChatGPT، أو توصيل الأسلاك createChatGTProxyProvider / createChatGPT باستخدام Vercel AI SDK، أو تصحيح أخطاء مسارات /api/chatgpt.
