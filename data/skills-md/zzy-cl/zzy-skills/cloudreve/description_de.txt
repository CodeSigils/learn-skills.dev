Verwalten Sie Dateien auf einer selbst gehosteten Cloudreve v4-Cloud-Speicherinstanz. Laden Sie lokale Dateien auf Cloudreve hoch, laden Sie Dateien von Cloudreve auf lokal herunter, listen Sie Dateien auf, überprüfen Sie die Speicherkapazität und löschen Sie Dateien. Aktivieren Sie diese Option, wenn der Benutzer „upload to cloudreve“, „cloudreve upload“, „网盘上传“, „传到网盘“, „cloudreve下载“, „从网盘下载“, „网盘文件列表“, „cloudreve文件“ oder beliebige Cloudreve-/Cloud-Drive-Dateivorgänge erwähnt.
