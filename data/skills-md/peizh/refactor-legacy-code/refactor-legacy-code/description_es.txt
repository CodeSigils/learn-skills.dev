Aplique flujos de trabajo de mantenimiento y refactorización de código heredado para bases de código grandes donde se debe preservar el comportamiento mientras se cambia código riesgoso, mal probado, estrechamente acoplado o difícil de entender. Úselo cuando se le solicite refactorizar, modernizar, estabilizar, mantener, agregar funciones, probar, desenredar, romper dependencias o planificar cambios seguros para sistemas heredados, repositorios grandes, métodos/clases monstruosos, código difícil de probar, código con muchas API, dependencias de biblioteca/globales/estáticas o cambios transversales repetidos.
