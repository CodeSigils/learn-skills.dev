قم بتطبيق سير عمل إعادة هيكلة التعليمات البرمجية القديمة والصيانة لقواعد التعليمات البرمجية الكبيرة حيث يجب الحفاظ على السلوك أثناء تغيير التعليمات البرمجية المحفوفة بالمخاطر أو التي تم اختبارها بشكل سيئ أو المقترنة بإحكام أو التي يصعب فهمها. يُستخدم عندما يُطلب منك إعادة البناء، أو التحديث، أو التثبيت، أو الصيانة، أو إضافة ميزات، أو اختبار، أو فك التشابك، أو فصل التبعيات، أو التخطيط لإجراء تغييرات آمنة للأنظمة القديمة، أو المستودعات الكبيرة، أو الأساليب/الفئات الضخمة، أو التعليمات البرمجية التي يصعب اختبارها، أو التعليمات البرمجية ذات واجهة برمجة التطبيقات الثقيلة، أو تبعيات المكتبة/العالمية/الثابتة، أو التغييرات الشاملة المتكررة.
