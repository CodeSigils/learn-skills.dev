Appliquez des workflows de refactorisation et de maintenance du code existant pour les bases de code volumineuses où le comportement doit être préservé lors de la modification de code risqué, mal testé, étroitement couplé ou difficile à comprendre. À utiliser lorsqu'on vous le demande pour refactoriser, moderniser, stabiliser, maintenir, ajouter des fonctionnalités, tester, démêler, rompre les dépendances ou planifier des modifications sécurisées pour les systèmes existants, les grands référentiels, les méthodes/classes monstres, le code difficile à tester, le code lourd d'API, les dépendances de bibliothèque/globales/statiques ou les modifications transversales répétées.
