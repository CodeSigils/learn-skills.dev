Применяйте рабочие процессы рефакторинга и обслуживания устаревшего кода для больших баз кода, где поведение необходимо сохранять при изменении рискованного, плохо протестированного, тесно связанного или сложного для понимания кода. Используйте, когда вас просят провести рефакторинг, модернизацию, стабилизацию, поддержку, добавление функций, тестирование, распутывание, разрыв зависимостей или планирование безопасных изменений для устаревших систем, больших репозиториев, чудовищных методов/классов, трудно тестируемого кода, кода с большим количеством API, библиотечных/глобальных/статических зависимостей или повторяющихся сквозных изменений.
