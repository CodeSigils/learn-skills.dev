Verwenden Sie es, wenn Sie gebeten werden, Altsysteme, große Repositories, Monstermethoden/-klassen, schwer zu testenden Code, API-lastigen Code, Bibliotheks-/globale/statische Abhängigkeiten oder wiederholte übergreifende Änderungen umzugestalten, zu modernisieren, zu stabilisieren, zu warten, Funktionen hinzuzufügen, zu testen, zu entwirren, Abhängigkeiten aufzubrechen oder sichere Änderungen zu planen.
