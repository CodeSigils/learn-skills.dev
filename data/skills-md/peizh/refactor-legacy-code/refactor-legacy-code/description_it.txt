Applica flussi di lavoro di refactoring e manutenzione del codice legacy per basi di codice di grandi dimensioni in cui il comportamento deve essere preservato modificando al contempo codice rischioso, scarsamente testato, strettamente associato o difficile da comprendere. Utilizzare quando viene richiesto di rifattorizzare, modernizzare, stabilizzare, mantenere, aggiungere funzionalità, testare, districare, interrompere dipendenze o pianificare modifiche sicure per sistemi legacy, repository di grandi dimensioni, metodi/classi mostruosi, codice difficile da testare, codice con API pesanti, dipendenze di libreria/globali/statiche o modifiche trasversali ripetute.
