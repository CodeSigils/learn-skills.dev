Respaldo genérico de estilo OpenTelemetry para lenguajes sin una habilidad de estilo otel-* dedicada (Go, Java/Kotlin, Ruby, Rust, .NET/C#, PHP, Elixir, Node simple, etc.). API de SDK nativo, medidores/trazadores de alcance de módulo, tramos acotados, registro de errores, registros OTLP y atributos de recursos.
