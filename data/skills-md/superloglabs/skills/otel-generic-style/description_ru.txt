Общий запасной вариант стиля OpenTelemetry для языков без специальных навыков работы со стилем otel* (Go, Java/Kotlin, Ruby, Rust, .NET/C#, PHP, Elixir, обычный Node и т. д.). Собственные API SDK, трассировщики/измерители на уровне модуля, ограниченные диапазоны, запись ошибок, журналы OTLP и атрибуты ресурсов.
