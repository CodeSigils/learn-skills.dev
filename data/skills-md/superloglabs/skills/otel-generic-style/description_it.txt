Fallback generico in stile OpenTelemetry per linguaggi senza una competenza dedicata in stile otel* (Go, Java/Kotlin, Ruby, Rust, .NET/C#, PHP, Elixir, Plain Node, ecc.). API SDK native, tracciatori/contatori dell'ambito del modulo, intervalli limitati, registrazione degli errori, log OTLP e attributi delle risorse.
