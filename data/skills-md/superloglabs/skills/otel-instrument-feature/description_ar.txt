قم بقياس أي ميزة جديدة، أو نقطة نهاية، أو مسار، أو معالج، أو عامل، أو وظيفة، أو أمر واجهة سطر الأوامر (CLI)، أو التدفق الذي يواجه المستخدم باستخدام امتدادات OpenTelemetry، والمقاييس، والسجلات قبل وصولها. يتم تشغيل طلبات مثل "إضافة نقطة نهاية جديدة"، أو "تنفيذ X"، أو "إنشاء معالج لـ Y"، أو "إنشاء مهمة إلى Z"، أو "إضافة هذه الميزة"، أو "توصيل مسار جديد"، أو أي تغيير في التعليمات البرمجية يقدم عملية تجارية جديدة.
