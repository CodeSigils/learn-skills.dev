Se déclenche sur des requêtes telles que « ajouter un nouveau point de terminaison », « implémenter X », « créer un gestionnaire pour Y », « créer un travail sur Z », « ajouter cette fonctionnalité », « connecter une nouvelle route » ou tout changement de code qui introduit une nouvelle opération commerciale.
