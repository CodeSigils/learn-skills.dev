Cette compétence doit être utilisée lorsque l'utilisateur demande de « tester l'application Electron », « d'automatiser l'application de bureau Electron », de « déboguer le moteur de rendu Electron », de « tester l'extension VS Code », de « tester E2E Electron » ou a besoin de l'automatisation du protocole Chrome DevTools pour les applications Electron. À utiliser pour le débogage du processus de rendu, le contrôle du processus principal, l'automatisation des menus natifs et les tests de dialogue de fichiers.
