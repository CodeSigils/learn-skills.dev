Scaffold Quarkus + LangChain4j proyecta de un extremo a otro y agrega componentes agentes a los existentes: servicios de IA, herramientas, agentes y flujos de trabajo de múltiples agentes, canalizaciones RAG, clientes y servidores MCP (Protocolo de contexto modelo), barreras de seguridad y configuraciones de tiendas integradas. Utilice esto siempre que el usuario solicite crear, desarrollar, configurar, arrancar, inicializar, iniciar, generar o poner en marcha un nuevo proyecto o módulo de Quarkus + LangChain4j, O para agregar un servicio de IA, herramienta, agente, componente RAG, cliente MCP o integración de servidor, barrera de seguridad o almacén integrado a un proyecto existente en esta pila. También se utiliza para generar pom.xml de referencia, application.properties, diseño de proyecto o clases iniciales para el trabajo de Quarkus + LangChain4j.
