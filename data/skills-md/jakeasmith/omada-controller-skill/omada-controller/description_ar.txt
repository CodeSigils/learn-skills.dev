التفاعل مع TP-Link Omada SDN Controller Open API. يُستخدم عند الاستعلام عن أو إدارة أجهزة شبكة Omada، أو العملاء، أو المواقع، أو نقاط الوصول، أو المحولات، أو البوابات، أو شبكات VLAN، أو قواعد جدار الحماية، أو شبكات VPN، أو أي تكوين لوحدة تحكم Omada. يُستخدم أيضًا عندما يذكر المستخدم Omada، أو وحدة تحكم SDN، أو يحتاج إلى المصادقة مقابل Omada API.
