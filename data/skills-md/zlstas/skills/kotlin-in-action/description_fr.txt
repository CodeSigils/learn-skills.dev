Appliquer les pratiques Kotlin In Action (Elizarov, Isakova, Aigner, Jemerov, 2e éd.). Couvre les bases (Ch 1-3 : fonctions, extensions, arguments par défaut), les classes (Ch 4 : scellés, données, délégation, objets compagnon), les Lambdas (Ch 5-6 : API fonctionnelles, séquences, fonctions de portée), la nullité (Ch 7-8 : appels sécurisés, Elvis, types de plate-forme, primitives), les conventions (Ch 9 : opérateurs, propriétés déléguées), l'ordre supérieur (Ch 10 : inline, noinline, crossinline), les génériques. (Ch 11 : variance, réifié), Réflexion (Ch 12 : KClass, KProperty), DSL (Ch 13 : récepteurs, @DslMarker), Coroutines (Ch 14 : concurrence structurée, répartiteurs, annulation), Flux (Ch 15 : opérateurs, StateFlow, SharedFlow). Déclenchez sur « Kotlin In Action », « Kotlin idiom », « Kotlin coroutine », « Kotlin flow », « Kotlin DSL », « Kotlin generics », « Kotlin null safety », « Kotlin délégation », « Kotlin inline » ou « Kotlin extension ».
