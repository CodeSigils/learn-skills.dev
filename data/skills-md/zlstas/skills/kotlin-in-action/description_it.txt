Applicare le pratiche di Kotlin In Action (Elizarov, Isakova, Aigner, Jemerov, 2a edizione). Copre nozioni di base (capitoli 1-3: funzioni, estensioni, argomenti predefiniti), classi (capitolo 4: sigillati, dati, delega, oggetti associati), lambda (capitoli 5-6: API funzionali, sequenze, funzioni di ambito), annullabilità (capitoli 7-8: chiamate sicure, Elvis, tipi di piattaforma, primitive), convenzioni (capitoli 9: operatori, proprietà delegate), ordine superiore (capitolo 10: inline, noinline, crossinline), Generici (Capitolo 11: varianza, reificato), Riflessione (Capitolo 12: KClass, KProperty), DSL (Capitolo 13: ricevitori, @DslMarker), Coroutine (Capitolo 14: concorrenza strutturata, dispatcher, cancellazione), Flussi (Capitolo 15: operatori, StateFlow, SharedFlow). Trigger su "Kotlin In Action", "Kotlin idiom", "Kotlin coroutine", "Kotlin flow", "Kotlin DSL", "Kotlin generics", "Kotlin null safety", "Kotlin delegate", "Kotlin inline" o "Kotlin extension".
