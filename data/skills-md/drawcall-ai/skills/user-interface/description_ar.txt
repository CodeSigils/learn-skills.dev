قم بتصميم وبناء واجهات المستخدم للتطبيقات والألعاب ثلاثية الأبعاد - التوجيه بين واجهة المستخدم المكانية ثلاثية الأبعاد/XR وواجهة المستخدم HUD ثنائية الأبعاد، بالإضافة إلى مبادئ التصميم المرئي. يُستخدم عند إضافة قوائم أو شاشات HUD أو لوحات أو لوحات معلومات أو أي واجهة مستخدم داخل التطبيق إلى مشروع Three.js، أو تحديد تقنية واجهة المستخدم التي سيتم استخدامها.
