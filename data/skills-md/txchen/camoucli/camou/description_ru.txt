Локальная автоматизация браузера Camoufox для агентов ИИ. Используйте, когда пользователю необходимо управлять веб-сайтами с помощью CLI каму, сохранять состояние входа в систему, взаимодействовать со страницами, переключать версии Camoufox, устранять неполадки совместимости или писать сценарии Node с помощью API Camou на основе Playwright.
