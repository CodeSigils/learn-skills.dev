Automatisation du navigateur Camoufox local pour les agents IA. À utiliser lorsque l'utilisateur a besoin de piloter des sites Web avec la CLI « camou », de conserver l'état de connexion, d'interagir avec les pages, de changer de version de Camoufox, de dépanner la compatibilité ou d'écrire des scripts Node avec l'API basée sur Playwright de Camou.
