Créez un nouveau bot Feishu autonome sur OpenClaw (mode multi-comptes). À utiliser lorsque l'utilisateur demande à créer un nouveau bot Feishu, à ajouter un nouvel agent ou à déployer un deuxième bot. Le processus comprend : collecter la configuration → sauvegarder → créer un espace de travail → modifier la configuration → vérifier.
