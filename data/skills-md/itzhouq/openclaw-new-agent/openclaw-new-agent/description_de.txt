Erstellen Sie einen neuen eigenständigen Feishu-Bot auf OpenClaw (Multi-Account-Modus). Verwenden Sie diese Option, wenn der Benutzer die Erstellung eines neuen Feishu-Bots, das Hinzufügen eines neuen Agenten oder die Bereitstellung eines zweiten Bots anfordert. Der Prozess umfasst: Konfigurationsinformationen sammeln → Sichern → Arbeitsbereich erstellen → Konfiguration ändern → Überprüfen.
