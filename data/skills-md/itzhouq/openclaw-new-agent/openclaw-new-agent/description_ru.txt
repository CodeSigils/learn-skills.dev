Создайте нового автономного бота Feishu на OpenClaw (режим нескольких учетных записей). Используйте, когда пользователь запрашивает создание нового бота Feishu, добавление нового агента или развертывание второго бота. Процесс включает в себя: сбор конфигурации → резервное копирование → создание рабочей области → изменение конфигурации → проверка.
