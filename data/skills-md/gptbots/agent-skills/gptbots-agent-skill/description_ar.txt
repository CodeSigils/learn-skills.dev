قم بإنشاء وقراءة وتحديث وتحسين تكوينات الوكيل وسير العمل لـ GTTBots (https://www.gptbots.ai) (ملفات .bot / .flow)، وقيادة الوكلاء/سير العمل المنشورين عبر واجهة برمجة تطبيقات GTBots Open API. استخدم هذه المهارة عندما يذكر المستخدم GPTBots، أو يقدم أو يشير إلى ملف .bot أو .flow، أو يريد إنشاء/تحسين وكيل chatbot أو FlowAgent أو سير العمل لمنصة GPTBots، أو يريد التقييم المستند إلى واجهة برمجة التطبيقات (API)، أو تقييم الجودة، أو اختبار RAG، أو التشغيل المجدول، أو إدارة قاعدة المعرفة/البيانات - حتى لو قالوا فقط "تحسين تكوين الروبوت الخاص بي" باستخدام ملف .bot/.flow مرفق.
