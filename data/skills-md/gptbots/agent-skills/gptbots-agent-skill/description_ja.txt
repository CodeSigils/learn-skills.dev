GPTBots (https://www.gptbots.ai) エージェントおよびワークフロー構成 (.bot / .flow ファイル) を作成、読み取り、更新、最適化し、GPTBots Open API を介して公開されたエージェント/ワークフローを駆動します。ユーザーが GPTBots について言及する場合、.bot または .flow ファイルを提供または参照する場合、GPTBots プラットフォーム用のチャットボット エージェント、FlowAgent、またはワークフローを構築/最適化したい場合、または API ベースの評価、品質評価、RAG テスト、スケジュールされたトリガー、またはナレッジベース/データ管理を希望する場合は常に、添付された .bot/.flow ファイルで「ボット構成を最適化する」と言った場合でも、このスキルを使用します。
