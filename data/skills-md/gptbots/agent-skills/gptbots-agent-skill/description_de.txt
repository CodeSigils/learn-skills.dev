Erstellen, lesen, aktualisieren und optimieren Sie GPTBots (https://www.gptbots.ai) Agenten- und Workflow-Konfigurationen (.bot/.flow-Dateien) und steuern Sie veröffentlichte Agents/Workflows über die GPTBots Open API. Verwenden Sie diesen Skill immer dann, wenn der Benutzer GPTBots erwähnt, eine .bot- oder .flow-Datei bereitstellt oder darauf verweist, einen Chatbot-Agenten, FlowAgent oder Workflow für die GPTBots-Plattform erstellen/optimieren möchte oder eine API-basierte Auswertung, Qualitätsbewertung, RAG-Tests, geplante Auslösung oder Wissensdatenbank-/Datenverwaltung wünscht – selbst wenn er nur „Meine Bot-Konfiguration optimieren“ mit einer angehängten .bot-/.flow-Datei sagt.
