Feishu Project (Meegle/Meego) أداة مساعدة للنشر الخاص لـ CLI. استخدم هذه المهارة عندما يحتاج المستخدم إلى الاستعلام عن المساحات أو طرق العرض أو عناصر العمل أو حالة سير العمل أو التعليقات أو المهام الفرعية أو إصدار مهام النشر أو التحقق من صحة وقت تشغيل MCP البعيد الخاص. الكلمات الرئيسية: مشروع Feishu، Meegle، Meego، عنصر العمل، المتطلبات، العيب، المهمة، العرض، العقدة، الانتقال، مهمة الإصدار، مهمة النشر.
