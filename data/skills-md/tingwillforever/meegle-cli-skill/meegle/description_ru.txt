Инструмент CLI для частного развертывания Feishu Project (Meegle/Meego). Используйте этот навык, когда пользователю необходимо запросить пространства, представления, рабочие элементы, состояние рабочего процесса, комментарии, подзадачи, выпуск задач развертывания или проверить частную удаленную среду выполнения MCP. Ключевые слова: проект Feishu, Meegle, Meego, рабочий элемент, требование, дефект, задача, представление, узел, переход, задача выпуска, задача развертывания.
