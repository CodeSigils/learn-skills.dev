General manual for operating ZCode (the ZhiPu GLM series coding agent). It covers three access modes (CLI --prompt / ACP bridge / MCP tools), credential configuration, dual-mode real streaming/pseudo streaming, extended protocol methods (session‑level + workspace‑level), thought‑intensity control, task‑template, and known pitfalls. It is intended for using ZCode as a sub‑agent to orchestrate, run coding/review tasks, or integrate into an editor. Compatible with ZCode CLI 0.14.5 ~ 0.16.1 (App 3.6.5).
