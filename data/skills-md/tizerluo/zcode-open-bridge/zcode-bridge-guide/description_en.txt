General manual for operating ZCode (the Zhihu GLM series coding agent). It covers three access modes (CLI --prompt / ACP bridge / MCP tools), credential configuration, true streaming/pseudo‑streaming dual mode, extended protocol methods (session‑level + workspace‑level), thinking intensity control, task template, and known pitfalls. Use this when employing ZCode as a sub‑agent for orchestrating, running coding or review tasks, or integrating it into an editor. Compatible with ZCode CLI 0.14.5 ~ 0.16.1 (App 3.6.5).
