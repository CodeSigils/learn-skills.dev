Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „ein Laufzeitproblem beheben“, „einen asynchronen Fehler verfolgen“, „Statusänderungen überprüfen“, „eine Racebedingung verfolgen“ möchte oder anderweitig eine Laufzeitinstrumentierung benötigt, weil Protokolle oder Stack-Traces nicht ausreichen.
