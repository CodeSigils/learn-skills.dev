Verwenden Sie Linear als Quelle der Wahrheit für technische Arbeiten in Projekten, die explizit einen „linearen“ MCP-Server bereitstellen. Verwenden Sie diese Funktion immer dann, wenn eine Aufgabe ein lineares Problem benennt, die Planung oder Nachverfolgung von Arbeit in Linear anfordert, ein dauerhaftes Planungs- oder Überprüfungsartefakt benötigt oder nachverfolgte Arbeit erstellen, beanspruchen, aktualisieren, überprüfen oder abschließen muss. Bestätigen Sie den authentifizierten Akteur vor dem Schreiben, bewahren Sie die Trennung zwischen Orchestrator, Planer, Builder, Prüfer und Eigentümer auf und führen Sie Linear niemals in ein Projekt ein, das nicht angemeldet ist.
