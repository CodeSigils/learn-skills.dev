SupSub full-text search — search content across sources within subscription feeds (public accounts/websites) and article bodies. Use this skill when the user says “search for X‑related content/articles”, “search X in SupSub”, “find X related articles”, “full-text search X”, “look for X’s content”, “search articles/content in SupSub”. Note: this skill is for searching “content/articles/subscription feed titles”; if the user wants to discover a new WeChat public account itself (using an mpId to prepare a subscription), use supsub‑mp instead.
