Полнотекстовый поиск SupSub — поиск контента между источниками в источниках подписки (публичные аккаунты/веб-сайты) и телах статей. Когда пользователи произносят «поиск контента/статей, связанных с X», «поиск X в SupSub», «найти статьи, связанные с X», «полнотекстовый поиск X», «найти контент о X», «поиск статей/контента в SupSub», используется этот навык. Примечание. Этот навык предназначен для поиска «заголовков источников контента/статей/подписок»; если пользователь хочет сам обнаружить новую общедоступную учетную запись (используя mpId для подписки), используйте supsub‑mp.
