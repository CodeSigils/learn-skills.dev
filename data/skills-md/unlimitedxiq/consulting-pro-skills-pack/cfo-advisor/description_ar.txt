القيادة المالية للشركات الناشئة وشركات التوسع. النمذجة المالية، واقتصاديات الوحدة، واستراتيجية جمع الأموال، وإدارة النقد، والحزم المالية لمجلس الإدارة. يُستخدم عند إنشاء النماذج المالية، أو تحليل اقتصاديات الوحدة، أو التخطيط لجمع التبرعات، أو إدارة المدرج النقدي، أو إعداد مواد مجلس الإدارة، أو عندما يذكر المستخدم المدير المالي، أو معدل الحرق، أو المدرج، أو جمع التبرعات، أو اقتصاديات الوحدة، أو LTV، أو CAC، أو أوراق الشروط، أو الإستراتيجية المالية.
