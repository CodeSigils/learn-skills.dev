عندما يريد المستخدم تطوير إستراتيجية وسائل التواصل الاجتماعي، أو تخطيط تقويمات المحتوى، أو إدارة مشاركة المجتمع، أو تنمية حضوره الاجتماعي عبر الأنظمة الأساسية. يُستخدم أيضًا عندما يذكر المستخدم "إستراتيجية وسائل التواصل الاجتماعي"، أو "التقويم الاجتماعي"، أو "إدارة المجتمع"، أو "خطة وسائل التواصل الاجتماعي"، أو "زيادة المتابعين"، أو "معدل المشاركة"، أو "تدقيق وسائل التواصل الاجتماعي"، أو "أي الأنظمة الأساسية يجب أن أستخدمها". لكتابة منشورات اجتماعية فردية، راجع المحتوى الاجتماعي. لتحليل بيانات الأداء الاجتماعي، راجع محلل الوسائط الاجتماعية.
