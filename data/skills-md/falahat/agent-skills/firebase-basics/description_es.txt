Proporciona flujos de trabajo básicos de configuración, autenticación y administración de proyectos para Firebase mediante Firebase CLI. Úselo al verificar la versión de Firebase CLI (debe usar 'npx -y firebase-tools@latest --version'), inicializar un entorno de Firebase, autenticar, configurar proyectos activos o configurar archivos `google-services.json` o `GoogleService-Info.plist`.
