يوفر الإعداد الأساسي والمصادقة وسير عمل إدارة المشروع لـ Firebase باستخدام Firebase CLI. يُستخدم عند التحقق من إصدار Firebase CLI (يجب استخدام "npx -y firebase-tools@latest --version")، أو تهيئة بيئة Firebase، أو المصادقة، أو إعداد المشاريع النشطة، أو إعداد ملفات `google-services.json` أو `GoogleService-Info.plist`.
