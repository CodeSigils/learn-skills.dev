Fornisce flussi di lavoro fondamentali per la configurazione, l'autenticazione e la gestione dei progetti per Firebase utilizzando la CLI di Firebase. Da utilizzare quando si controlla la versione della CLI di Firebase (è necessario utilizzare 'npx -y firebase-tools@latest --version'), si inizializza un ambiente Firebase, si esegue l'autenticazione, si impostano progetti attivi o si configurano file "google-services.json" o "GoogleService-Info.plist".
