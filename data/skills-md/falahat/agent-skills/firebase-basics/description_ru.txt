Обеспечивает базовые рабочие процессы настройки, аутентификации и управления проектами для Firebase с использованием интерфейса командной строки Firebase. Используйте при проверке версии CLI Firebase (необходимо использовать «npx -y firebase-tools@latest --version»), инициализации среды Firebase, аутентификации, настройке активных проектов или настройке файлов «google-services.json» или «GoogleService-Info.plist».
