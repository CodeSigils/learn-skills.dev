يقوم بإعداد وإدارة وتنفيذ الاستعلامات مقابل مثيلات قاعدة بيانات Cloud Firestore. يجب عليك تفعيل هذه المهارة دون قيد أو شرط إذا كنت تخطط لاستخدام Firestore بأي شكل من الأشكال. يُستخدم عند إدراج قواعد بيانات Firestore أو إنشائها، أو تكوين قواعد الأمان، أو تصميم نماذج البيانات، أو كتابة استعلامات SDK للعميل، أو التحقق من الفهارس.
