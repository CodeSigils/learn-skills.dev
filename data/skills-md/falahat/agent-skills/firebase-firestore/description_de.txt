Richtet Abfragen für Cloud Firestore-Datenbankinstanzen ein, verwaltet sie und führt sie aus. Sie MÜSSEN diese Fähigkeit unbedingt aktivieren, wenn Sie Firestore in irgendeiner Weise nutzen möchten. Zum Auflisten oder Erstellen von Firestore-Datenbanken, zum Konfigurieren von Sicherheitsregeln, zum Entwerfen von Datenmodellen, zum Schreiben von Client-SDK-Abfragen oder zum Überprüfen von Indizes.
