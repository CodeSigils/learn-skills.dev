Modèles d'intégration officiels pour le SDK Mapbox Maps Flutter. Couvre l'installation, la configuration de la plate-forme iOS/Android, la configuration du jeton d'accès, l'initialisation de MapWidget, le contrôle de la caméra, les annotations avec gestion des clics, la localisation de l'utilisateur et le chargement de GeoJSON. Basé sur la documentation officielle de Mapbox.
