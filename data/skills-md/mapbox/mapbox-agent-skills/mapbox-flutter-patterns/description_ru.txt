Официальные шаблоны интеграции для Mapbox Maps Flutter SDK. Охватывает установку, настройку платформы iOS/Android, настройку токена доступа, инициализацию MapWidget, управление камерой, аннотации с обработкой касаний, местоположение пользователя и загрузку GeoJSON. На основе официальной документации Mapbox.
