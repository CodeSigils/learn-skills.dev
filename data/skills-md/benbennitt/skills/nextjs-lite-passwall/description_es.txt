Agregue un muro liviano de contraseña única a cualquier aplicación Next.js usando cookies bcrypt + JWT. Úselo cuando un proyecto necesite autenticación básica, una puerta de contraseña, protección de implementación o cuando el usuario diga "agregar una contraseña" o "bloquear esto" para una aplicación Next.js. No para cuentas de usuario, autenticación multiusuario o aplicaciones de alta seguridad: se trata de una única contraseña compartida para mantener la privacidad de los paneles y las herramientas personales.
