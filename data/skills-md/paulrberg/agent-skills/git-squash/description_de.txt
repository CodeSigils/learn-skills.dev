Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „PR-Commits unterdrücken“, „meinen Zweig unterdrücken“, „Verzweigungsverlauf reduzieren“, „alle Commits zu einem kombinieren“, „einen sauberen PR-Commit vorbereiten“ oder „Commits relativ zum Haupt-/Standardzweig unterdrücken“ möchte. Es schreibt den aktuellen Zweig in einen einzelnen Commit um, dessen Nachricht die verbleibenden Nettoänderungen relativ zum Standardzweig semantisch zusammenfasst.
