Cette compétence doit être utilisée lorsque l'utilisateur demande « d'écraser les commits PR », « d'écraser ma branche », « d'aplatir l'historique des branches », de « combiner tous les commits en un seul », « de préparer un commit PR propre » ou « d'écraser les commits par rapport à la branche principale/par défaut ». Il réécrit la branche actuelle en un seul commit dont le message résume sémantiquement les modifications nettes survivantes par rapport à la branche par défaut.
