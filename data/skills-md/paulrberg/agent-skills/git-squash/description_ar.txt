يجب استخدام هذه المهارة عندما يطلب المستخدم "سحق التزامات العلاقات العامة"، أو "سحق فرعي"، أو "تسوية سجل الفرع"، أو "دمج كل الالتزامات في واحدة"، أو "التحضير لالتزام علاقات عامة نظيف"، أو "سحق الالتزامات المتعلقة بالفرع الرئيسي/الافتراضي". يقوم بإعادة كتابة الفرع الحالي في التزام واحد تلخص رسالته بشكل دلالي صافي التغييرات الباقية بالنسبة للفرع الافتراضي.
