Этот навык следует использовать, когда пользователь просит «сжать коммиты PR», «сжать мою ветку», «сгладить историю веток», «объединить все коммиты в один», «подготовить чистый PR-коммит» или «сжать коммиты относительно основной/по умолчанию ветки». Он перезаписывает текущую ветку в один коммит, сообщение которого семантически суммирует сохранившиеся чистые изменения относительно ветки по умолчанию.
