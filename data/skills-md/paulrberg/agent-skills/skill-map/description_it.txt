Utilizzare per trovare installazioni di competenze dell'agente, competenze duplicate, dipendenze incrociate, chiamate e riferimenti incrociati nel computer locale. Esegue la scansione in modo ampio ignorando i percorsi home protetti di macOS, le directory di installazione/stato home dell'agente (~/.agents, ~/.claude, ~/.codex, ~/.local/state/skills), le directory di trascrizione/cronologia/stato, le cartelle di dipendenza e i backup.
