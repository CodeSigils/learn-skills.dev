Diese Fähigkeit sollte verwendet werden, wenn der Benutzer einen EVM-Kettennamen oder eine Ketten-ID auflösen, Kettenmetadaten wie einen standardmäßigen öffentlichen RPC oder ein natives Währungssymbol finden, feststellen möchte, ob eine Kette von RouteMesh unterstützt wird, oder eine Kettenauflösung benötigt, bevor er Daten von einer EVM-Kette abruft oder mit ihr interagiert.
