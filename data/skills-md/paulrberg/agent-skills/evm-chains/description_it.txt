Questa competenza deve essere utilizzata quando l'utente chiede di risolvere il nome di una catena EVM o un ID di catena, trovare metadati di catena come un RPC pubblico predefinito o un simbolo di valuta nativa, determinare se una catena è supportata da RouteMesh o necessita di risoluzione della catena prima di recuperare dati o interagire con una catena EVM.
