Diseñe y cree experiencias web completas desde cero: páginas de marketing y productos de nivel de premios, sitios cinematográficos con desplazamiento dirigido donde la página se dirige como una película y productos multipantalla (aplicación, panel, administrador, configuración, incorporación, sitio de documentos) creados como un sistema de diseño con cada componente, estado y ruta en un solo estilo. Úselo siempre que el usuario desee crear o rediseñar una página de destino, un sitio web, una sección principal, un portafolio, una promoción o una página de producto; quiere animaciones de desplazamiento, páginas que cuenten historias o un sitio que parezca una película; o dice "hazlo hermoso", "hazlo sorprendente", "cinemático" o "sistema de diseño", incluso si no mencionan ninguna técnica. Genera sus propios activos a través de CLI locales (imágenes, cuadros de video, mapas de profundidad, 3D) y controla cada barco con un linter anti-slop ejecutable y un bucle de verificación de captura de pantalla. No para pulir una interfaz de usuario creada por otra persona, ni para trabajos de backend únicamente.
