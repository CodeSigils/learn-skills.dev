Memoria persistente basada en obsidiana para agentes codificadores. Úselo al inicio de la sesión para orientarse desde una bóveda de conocimientos, durante el trabajo para buscar notas de arquitectura/componentes/patrones, y cuando se hagan descubrimientos para escribirlas. Se activa cuando el usuario menciona la memoria de obsidiana, la bóveda de obsidiana, las notas de obsidiana o los comandos /obs. Proporciona comandos: iniciar, analizar, recapitular, proyectar, anotar, hacer, buscar, relacionar.
