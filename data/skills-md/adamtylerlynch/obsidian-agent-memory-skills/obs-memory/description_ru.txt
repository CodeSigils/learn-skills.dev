Постоянная память на основе обсидиана для кодирующих агентов. Используйте в начале сеанса для ориентации в хранилище знаний, во время работы для поиска примечаний по архитектуре/компонентам/шаблонам и при обнаружении для их обратной записи. Активируется, когда пользователь упоминает обсидиановую память, обсидиановое хранилище, обсидиановые заметки или команды /obs. Предоставляет команды: инициализация, анализ, резюме, проект, заметка, список дел, поиск, связь.
