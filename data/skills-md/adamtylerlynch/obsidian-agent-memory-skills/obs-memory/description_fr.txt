Mémoire persistante basée sur Obsidian pour les agents de codage. À utiliser au début de la session pour vous orienter à partir d'un coffre-fort de connaissances, pendant le travail pour rechercher des notes d'architecture/composant/modèle, et lorsque des découvertes sont faites pour les réécrire. Activez lorsque l'utilisateur mentionne la mémoire d'obsidienne, le coffre-fort d'obsidienne, les notes d'obsidienne ou les commandes /obs. Fournit des commandes : init, analyse, récapitulation, projet, note, tâche, recherche, relation.
