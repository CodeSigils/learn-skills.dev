Persistenter Obsidian-basierter Speicher für Codierungsagenten. Verwenden Sie es zu Beginn der Sitzung, um sich an einem Wissensspeicher zu orientieren, während der Arbeit, um Architektur-/Komponenten-/Musternotizen nachzuschlagen, und wenn Entdeckungen gemacht werden, um diese zurückzuschreiben. Aktivieren Sie diese Option, wenn der Benutzer Obsidian-Speicher, Obsidian-Tresor, Obsidian-Notizen oder /obs-Befehle erwähnt. Stellt Befehle bereit: init, analysieren, rekapitulieren, projizieren, notieren, erledigen, suchen, beziehen.
