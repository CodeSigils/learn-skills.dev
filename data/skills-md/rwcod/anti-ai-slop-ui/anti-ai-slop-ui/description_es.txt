Evita la interfaz de usuario genérica generada por IA al aplicar la dirección de diseño, los tokens de diseño, la estrategia de diseño y la revisión antideslizamiento específicos del producto. Úselo al generar o revisar páginas de destino, interfaz de usuario SaaS, paneles, flujos de incorporación, pantallas de aplicaciones, interfaz de usuario de escritorio/móvil, componentes de interfaz, Figma/maquetas, rediseños de interfaz de usuario o refactores shadcn/Tailwind. No lo utilice exclusivamente para backend, bases de datos, DevOps, procesamiento de datos, scripts de solo CLI o tareas de solo texto, a menos que se trate de una interfaz de usuario visible.
