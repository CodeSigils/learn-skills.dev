Crée un guide d'intégration complet pour n'importe quelle base de code. Analyse la structure du projet, les décisions d'architecture, les flux d'utilisateurs, les modèles de codage et génère une introduction de niveau expert qui explique par où commencer et comment les choses fonctionnent. À utiliser lors de l'exécution de `/project-onboarding` pour comprendre un nouveau projet.
