Machen Sie einen Zweig bereit für die Zusammenführung, indem Sie sicherstellen, dass ein PR vorhanden ist, Prüfungen überwachen, automatisierte Überprüfungskommentare selektieren, jeden behandelten Bot-Thread beantworten und auflösen und optional die Zusammenführung unterdrücken, wenn der Benutzer dies verlangt. Verwenden Sie diese Option, wenn der Benutzer „Versenden“, „landen“ sagt, „diese PR vorbereiten“, „CI babysitten“, „Bot-Review-Kommentare“ bearbeiten soll oder möchte, dass Sie eine PR bis zur Zusammenführung grün halten.
