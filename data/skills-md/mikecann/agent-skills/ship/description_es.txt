Haga que una rama esté lista para la fusión asegurándose de que exista un PR, monitoreando las comprobaciones, clasificando los comentarios de revisión automatizados, respondiendo y resolviendo cada hilo de bot manejado y, opcionalmente, eliminando la fusión cuando el usuario lo solicite. Úselo cuando el usuario diga enviar, aterrizar esto, preparar este PR, cuidar CI, manejar comentarios de revisión de bot o quiere que mantenga un PR verde hasta que se fusione.
