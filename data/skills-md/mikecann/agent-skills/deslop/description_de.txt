Führt eine Bereinigung im zweiten Durchgang über KI-geschriebenen Code unter Verwendung des Styleguides des Repos in style.md durch. Bevorzugt parallele Subagenten, um kürzlich geänderte Dateien zu vereinfachen, ohne das Verhalten zu ändern. Wird verwendet, wenn der Benutzer „deslop“, „bereinigen“, „weniger KI machen“, „meinen Styleguide anwenden“, „zweiter Durchgang“ sagt oder nach der Implementierung darum bittet, den generierten Code zu vereinfachen.
