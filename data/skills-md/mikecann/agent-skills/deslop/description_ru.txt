Запускает очистку второго прохода кода, написанного искусственным интеллектом, с использованием руководства по стилю репозитория в style.md. Предпочитает параллельные субагенты для упрощения недавно измененных файлов без изменения поведения. Используйте, когда пользователь говорит «убрать ошибки», «очистить это», «сделать это меньшим количеством искусственного интеллекта», «применить мое руководство по стилю», «второй проход» или просит упростить сгенерированный код после реализации.
