Créez un document de spécifications produit prospectif ou rétro‑ingénieré à partir d’une description, d’une conversation, d’artefacts fournis, de sources liées ou d’une base de code existante. Utilisez‑le lorsqu’on vous demande un PRD, une spécification produit, un brief de fonctionnalité ou une reconstruction au niveau du produit. Clarifiez les inconnues matérielles, indiquez le comportement déduit et enregistrez un fichier uniquement sur demande.
