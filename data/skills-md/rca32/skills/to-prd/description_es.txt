Cree un documento de requisitos del producto prospectivo o de ingeniería inversa a partir de una descripción, conversación, artefactos proporcionados, fuentes vinculadas o una base de código existente. Úselo cuando se solicite un PRD, especificación del producto, resumen de la característica o reconstrucción a nivel de producto. Aclare las incertidumbres materiales, etiquete el comportamiento inferido y guarde un archivo solo cuando se solicite.
