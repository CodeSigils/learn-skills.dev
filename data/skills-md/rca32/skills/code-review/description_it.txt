Revisiona una pull request, un diff di ramo, un intervallo di commit, l’albero di lavoro o il codice recentemente prodotto alla ricerca di bug, problemi di sicurezza, prestazioni, coerenza, test e lacune di raggio d’azione. Usalo per revisioni di codice, PR, diff, modifiche pendenti o pre‑push. Restituisci risultati azionabili senza modificare i file.

Per favore, rispondi sempre nella lingua dell’utente.
