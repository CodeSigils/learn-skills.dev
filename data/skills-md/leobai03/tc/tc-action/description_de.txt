Einführung von TC-Unternehmertumsmaßnahmen. Der Benutzer gibt „/tc-action“ ein oder es wird verwendet, wenn bereits ein Urteil oder eine Projekthypothese vorliegt, es aber an realen Beweisen mangelt, der Plan zu umfangreich ist, es bei Besprechungen ständig um Lernen geht, die Nachfrage validiert werden muss oder ein Angebot auf einen Verkauf umgestellt werden muss. Komprimieren Sie das Urteil oder die Hypothese in einem zehnminütigen Kickoff, einer 24-Stunden-Marktlieferung, einer siebentägigen Einzelmetrik, einer Kostenobergrenze, Stoppbedingungen und den Daten, die zurückgebracht werden müssen; Wenn Tools verfügbar sind, überprüfen Sie den aktuellen freien Markt, und wenn Tools nicht verfügbar sind, geben Sie ausdrücklich an, was unbekannt ist. Die Aktion muss reale Einheiten einbeziehen.
