Оцените производительность навыков Claude Code с помощью анализа отклонений, отслеживания скорости прохождения, времени выполнения и использования токенов на протяжении итераций. Запускает несколько испытаний для каждой оценки для обеспечения статистической надежности, объединяет результаты в файл сравнительного анализа.json и создает отчеты о сравнении между версиями навыков. Используйте, когда пользователь говорит «оценить навыки», «измерить эффективность навыков», «показатели навыков», «сравнить версии навыков», «эффективность навыков», «отследить улучшение навыков», «тест регрессии навыков» или «тест A/B навыков».
