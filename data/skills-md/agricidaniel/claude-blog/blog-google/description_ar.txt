تكامل Google API لأداء المدونة: PageSpeed ​​Insights، وCrUX Core Web Vitals بسجل مدته 25 أسبوعًا، وأداء Search Console، وفحص عنوان URL، وIndexing API، وحركة المرور العضوية في GA4، وتحليل كيان NLP لـ E-E-A-T، وبحث فيديو YouTube للتضمين، ومخطط الكلمات الرئيسية في إعلانات Google. توفر الميزات التدريجي استنادًا إلى مستوى بيانات الاعتماد (مفتاح واجهة برمجة التطبيقات، وحساب OAuth/الخدمة، وGA4، والإعلانات). يشارك التكوين مع claude-seo في ~/.config/clude-seo/google-api.json. يُستخدم عندما يقول المستخدم "بيانات Google"، و"سرعة الصفحة"، و"مؤشرات الويب الحيوية الأساسية"، و"Search Console"، و"الفهرسة"، و"GA4"، و"البحث عن الكلمات الرئيسية"، و"كيانات البرمجة اللغوية العصبية"، و"أداء المدونة"، و"بحث youtube"، و"إعداد Google API".
