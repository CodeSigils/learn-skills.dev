Интеграция API Google для повышения эффективности блога: PageSpeed ​​Insights, CrUX Core Web Vitals с 25-недельной историей, производительность Search Console, проверка URL-адресов, API индексирования, органический трафик GA4, анализ объектов NLP для E-E-A-T, поиск видео на YouTube для встраивания и планировщик ключевых слов Google Ads. Доступность прогрессивных функций в зависимости от уровня учетных данных (ключ API, OAuth/служебный аккаунт, GA4, реклама). Делится конфигурацией с claude-seo по адресу ~/.config/claude-seo/google-api.json. Используйте, когда пользователь говорит «данные Google», «скорость страницы», «основные веб-показатели», «консоль поиска», «индексация», «GA4», «исследование ключевых слов», «сущности NLP», «производительность блога», «поиск на YouTube», «настройка API Google».
