Génération d'images IA pour les actifs SEO : images d'aperçu OG/social, images de héros de blog, images de schéma, photographies de produits, infographies. Propulsé par Gemini via nanobanana-mcp. Nécessite l'installation d'une extension banane. À utiliser lorsque l'utilisateur dit « générer une image », « image OG », « aperçu social », « image de héros », « image de blog », « photo de produit », « infographie », « image de référencement », « créer un visuel », « génération d'image », « favicon », « image de schéma », « épingle Pinterest », « générer un visuel », « bannière » ou « miniature ».
