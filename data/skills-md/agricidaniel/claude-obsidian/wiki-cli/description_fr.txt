Transport de mutation de coffre-fort par défaut pour Claude-Obsidian v1.7+. Encapsule la CLI Obsidian (Obsidian 1.12+) comme moyen préféré pour lire, écrire, rechercher et modifier les notes du coffre-fort à partir de Claude – pas de serveur MCP, pas de plugin API REST, pas de solutions de contournement TLS. Revient au système de fichiers direct Lecture/Écriture/Édition lorsque la CLI n'est pas disponible. Déclencheurs sur : wiki-cli, obsidian cli, lecture d'obsidienne, écriture d'obsidienne, recherche d'obsidienne, note quotidienne, création d'obsidienne, ajout d'obsidienne, transport de coffre-fort, quel transport, détection de transport, ligne de commande d'obsidienne.
