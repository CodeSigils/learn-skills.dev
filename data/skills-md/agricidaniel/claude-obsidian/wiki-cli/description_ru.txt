Транспорт мутации хранилища по умолчанию для claude-obsidian v1.7+. Обертывает интерфейс командной строки Obsidian (Obsidian 1.12+) как предпочтительный способ чтения, записи, поиска и изменения заметок хранилища от Claude — без сервера MCP, без плагина REST API, без обходных путей TLS. Возвращается к прямому чтению/записи/редактированию файловой системы, когда интерфейс командной строки недоступен. Запускается по: wiki-cli, obsidian cli, чтение обсидиана, запись обсидиана, поиск обсидиана, ежедневная заметка, создание обсидиана, добавление обсидиана, транспорт хранилища, который транспортирует, обнаружение транспорта, командная строка обсидиана.
