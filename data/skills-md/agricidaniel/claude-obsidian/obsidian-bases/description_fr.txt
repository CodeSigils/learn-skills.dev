Créez et modifiez des bases Obsidian (fichiers .base) : la couche de base de données native d'Obsidian pour les tableaux dynamiques, les vues de cartes, les vues de liste, les filtres, les formules et les résumés sur les notes du coffre-fort. Déclencheurs sur : créer une base, ajouter un fichier de base, bases d'obsidienne, vue de base, filtrer les notes, formule, vue de base de données, table dynamique, base de suivi des tâches, base de liste de lecture.
