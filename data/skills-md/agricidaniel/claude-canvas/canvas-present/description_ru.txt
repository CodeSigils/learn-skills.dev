Создайте холсты в режиме презентации для плагина Advanced Canvas. Создает полотна слайдов с групповыми узлами 1200x675, соединенными краями, для навигации с помощью клавиш со стрелками. Поддерживает титульные слайды, слайды с контентом с изображениями, полнотекстовые слайды и дополнительные столбцы аннотаций сценариев для планирования видео. Срабатывает при: представлении на холсте, создании презентации, создании набора слайдов, слайдах на холсте, создании презентации, холсте презентации, представлении из заметок, холсте слайдов, презентации на холсте.
