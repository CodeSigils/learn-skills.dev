Utilice la herramienta de línea de comandos codeintel: indexación inteligente y consultas de seguimiento de campos para bases de código Go. Índice de compilación (init), resúmenes de lectura y escritura de símbolos/campos de consulta (campos de consulta), rastreo de campos (rastreo hacia atrás/adelante), rastreo de valores de datos de cadena completa (rastreo de valores), relaciones de llamadas (personas que llaman/llamadas/impacto), exportación (exportación) y servicio web (servicio). Utilice esta habilidad cuando el usuario solicite un análisis del flujo de datos de campo de una base de código Go, rastrear el uso del campo o los puntos de origen, ver lecturas/escrituras de campos de funciones o consultar relaciones de llamadas.
