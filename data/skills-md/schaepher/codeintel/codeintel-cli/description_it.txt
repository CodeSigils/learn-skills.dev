Utilizza lo strumento da riga di comando codeintel: indicizzazione intelligente e query di tracciamento dei campi per le codebase Go. Crea indici (init), esegui query di riepiloghi di lettura e scrittura di simboli/campi (campi di query), traccia campi all'indietro/in avanti (trace-backward/forward), esegui la traccia dei valori dei dati della catena completa (traccia del valore), analizza le relazioni di chiamata (chiamanti/chiamati/impatto), esporta (esporta) ed esegui un servizio Web (serve). Utilizza questa competenza quando un utente richiede di analizzare il flusso di dati di campo di una codebase Go, tracciare le origini di utilizzo dei campi o i punti di generazione, visualizzare letture/scritture di campi funzione o eseguire query sulle relazioni delle chiamate.
