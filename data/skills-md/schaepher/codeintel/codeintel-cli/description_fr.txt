Utilisez l'outil de ligne de commande codeintel : requêtes d'indexation intelligente et de trace de champ pour les bases de code Go. Créez l'index (init), les résumés en lecture-écriture des symboles/champs de requête (champs de requête), effectuez le traçage des champs (trace-arrière/forward), effectuez le traçage de la valeur des données de la chaîne complète (value-trace), examinez les relations d'appel (appelants/appelés/impact), exportez les résultats (export) et exécutez un service Web (serve). Utilisez cette compétence chaque fois qu'un utilisateur demande à analyser le flux de données de champ d'une base de code Go, à tracer les origines ou les destinations d'utilisation des champs, à afficher les lectures/écritures de champs de fonction ou à interroger les relations d'appel.
