Basata su QAS (Quark Cloud Disk Automatic Transfer Project), questa pigra funzionalità di tracciamento di programmi TV e anime include anche uno strumento CLI. Anche se l'abbonamento alla serie di QAS fallisce, può ricercare nuovamente le risorse, esplorare directory di risorse multilivello e trasferire episodi nuovi e mancanti nell'archivio in base alle preferenze dell'utente (ad esempio, risoluzione più elevata) tra più risorse candidate più recenti. Può essere consegnato a OpenClaw locale, Hermes Agent o altri agenti Claude Code/Codex per impostare attività pianificate, reporting periodico e assistenza nella riparazione quando un abbonamento fallisce. Gli utenti avanzati con un runtime Python possono anche utilizzarlo come strumento da riga di comando. Grazie al progetto QAS per le sue potenti funzionalità e l'eccellente esperienza utente; questo progetto non sostituisce l'interfaccia utente Web QAS, ma si concentra su un "aggiornamento lento" per le serie abbonate.
