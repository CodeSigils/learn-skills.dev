Based on QAS (Quark Cloud Disk Automatic Transfer Project), this lazy drama/animation tracking SKILL also includes a CLI tool. Even if QAS’s series subscription fails, it can re‑search for resources, explore multi‑level resource directories, and transfer new episodes and missing episodes from multiple latest candidate resources according to user preferences (e.g., higher resolution). It can be handed to local OpenClaw, Hermes Agent, or other Claude Code, Codex Agent for setting scheduled tasks, periodic reporting, and assisting in repair when a subscription fails. Advanced users with a Python runtime can also use it as a command‑line tool. Thanks to the QAS project for its powerful features and excellent user experience; this project is not a replacement for the QAS Web UI, but focuses on the “lazy updates” of subscribed series.
