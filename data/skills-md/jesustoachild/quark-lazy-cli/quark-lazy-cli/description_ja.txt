QAS (Quark Cloud Disk Automatic Transfer Project) に基づいた、この怠惰なドラマ/アニメーション トラッキング SKILL には、CLI ツールも含まれています。 QAS のシリーズ サブスクリプションが失敗した場合でも、ユーザーの好み (高解像度など) に応じて、リソースを検索し、複数レベルのリソース ディレクトリを探索し、複数の最新の候補リソースから新しいエピソードや欠落しているエピソードを転送できます。これは、スケジュールされたタスクの設定、定期的なレポート、およびサブスクリプションが失敗した場合の修復の支援のために、ローカルの OpenClaw、Hermes エージェント、または他のクロード コード、コーデックス エージェントに渡すことができます。 Python ランタイムを使用する上級ユーザーは、Python ランタイムをコマンドライン ツールとしても使用できます。 QAS プロジェクトの強力な機能と優れたユーザー エクスペリエンスに感謝します。このプロジェクトは QAS Web UI に代わるものではありませんが、購読しているシリーズの「遅延更新」に焦点を当てています。
