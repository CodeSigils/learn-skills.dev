QAS(Quark Cloud Disk 자동 전송 프로젝트)를 기반으로 하는 게으른 드라마 및 애니메이션 추적 SKILL에는 CLI 도구도 포함되어 있습니다. QAS의 시리즈 구독이 무효화되더라도 리소스를 다시 검색하고, 다단계 리소스 디렉터리를 탐색하고, 사용자 기본 설정(예: 더 높은 해상도)에 따라 여러 최신 후보 리소스에서 새 에피소드와 누락된 에피소드를 전송할 수 있습니다. 로컬 OpenClaw, Hermes 에이전트 또는 기타 Claude Code, Codex 에이전트에 전달하여 예약된 작업, 정기 보고서를 설정하고 구독 실패 시 수정 사항을 지원할 수 있습니다. Python 런타임을 사용하는 고급 사용자는 이를 명령줄 도구로 사용할 수도 있습니다. 강력한 기능과 고품질 사용자 경험을 제공하는 QAS 프로젝트에 감사드립니다. 이 프로젝트는 QAS 웹 UI를 대체하지는 않지만 구독 시리즈의 "지연 업데이트"에 중점을 둡니다.
