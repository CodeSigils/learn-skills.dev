애플리케이션 런타임, 배포 토폴로지 및 트래픽 동작에 맞게 조정된 프로덕션 Nginx 구성을 설계, 생성, 검토 및 문제 해결합니다. Codex가 FastAPI, Next.js, Django, Spring Boot 또는 다른 HTTP 애플리케이션에 대해 Nginx를 구성해야 할 때 사용합니다. 온프레미스, VM, Docker, Podman, Compose 또는 다른 컨테이너 플랫폼을 사용하여, ALB 유무에 관계없이 AWS EC2 또는 다른 신뢰할 수 있는 프록시 뒤에 배포합니다. 또는 정적 및 보호된 파일, 역방향 프록시, API 게이트웨이, 업로드, 캐싱, 로드 밸런싱, WebSocket, SSE, 스트리밍 응답 또는 gRPC를 지원합니다. 또한 nginx.conf 및 conf.d 검토, TLS 종료, 전달된 클라이언트 IP 처리, 속도 제한, 보안 헤더, 성능 조정, 구문 검증 및 안전한 다시 로드 계획에도 사용됩니다.
