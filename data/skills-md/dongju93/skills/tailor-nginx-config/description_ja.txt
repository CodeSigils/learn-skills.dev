アプリケーションのランタイム、展開トポロジ、トラフィック動作に合わせて調整された実稼働 Nginx 構成を設計、生成、レビュー、トラブルシューティングします。 Codex が FastAPI、Next.js、Django、Spring Boot、または別の HTTP アプリケーション用に Nginx を構成する必要がある場合に使用します。オンプレミス、VM、Docker、Podman、Compose、または別のコンテナ プラットフォーム、ALB の有無にかかわらず AWS EC2、または別の信頼できるプロキシの背後にデプロイします。または、静的ファイルと保護されたファイル、リバース プロキシ、API ゲートウェイ、アップロード、キャッシュ、負荷分散、WebSocket、SSE、ストリーミング応答、または gRPC をサポートします。 nginx.conf および conf.d のレビュー、TLS 終端、転送されたクライアント IP の処理、レート制限、セキュリティ ヘッダー、パフォーマンス チューニング、構文検証、安全なリロード プランニングにも使用します。
