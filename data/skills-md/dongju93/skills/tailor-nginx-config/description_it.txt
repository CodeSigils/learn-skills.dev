Progetta, genera, esamina e risolvi i problemi delle configurazioni Nginx di produzione personalizzate in base al runtime dell'applicazione, alla topologia di distribuzione e al comportamento del traffico. Da utilizzare quando Codex deve configurare Nginx per FastAPI, Next.js, Django, Spring Boot o un'altra applicazione HTTP; distribuire in locale, su una VM, con Docker, Podman, Compose o un'altra piattaforma di container, su AWS EC2 con o senza ALB o dietro un altro proxy attendibile; oppure supportare file statici e protetti, proxy inverso, gateway API, caricamenti, memorizzazione nella cache, bilanciamento del carico, WebSocket, SSE, risposte in streaming o gRPC. Utilizzare anche per revisioni nginx.conf e conf.d, terminazione TLS, gestione IP client inoltrati, limitazione della velocità, intestazioni di sicurezza, ottimizzazione delle prestazioni, convalida della sintassi e pianificazione sicura del ricaricamento.
