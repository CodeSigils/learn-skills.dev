تصميم وإنشاء ومراجعة واستكشاف أخطاء تكوينات Nginx الخاصة بالإنتاج والتي تم تصميمها خصيصًا لوقت تشغيل التطبيق وهيكل النشر وسلوك حركة المرور. يُستخدم عندما يحتاج Codex إلى تكوين Nginx لـ FastAPI أو Next.js أو Django أو Spring Boot أو تطبيق HTTP آخر؛ النشر محليًا، على جهاز افتراضي، باستخدام Docker، أو Podman، أو Compose، أو منصة حاوية أخرى، على AWS EC2 مع ALB أو بدونه، أو خلف وكيل آخر موثوق به؛ أو دعم الملفات الثابتة والمحمية، أو الوكيل العكسي، أو بوابات API، أو التحميلات، أو التخزين المؤقت، أو موازنة التحميل، أو WebSockets، أو SSE، أو استجابات البث، أو gRPC. استخدم أيضًا لمراجعات nginx.conf وconf.d، وإنهاء TLS، ومعالجة عنوان IP للعميل المعاد توجيهه، وتحديد المعدل، ورؤوس الأمان، وضبط الأداء، والتحقق من صحة بناء الجملة، والتخطيط لإعادة التحميل الآمن.
