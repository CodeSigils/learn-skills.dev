Diseñe, genere, revise y solucione problemas de configuraciones de producción de Nginx que se adapten al tiempo de ejecución de la aplicación, la topología de implementación y el comportamiento del tráfico. Úselo cuando Codex necesite configurar Nginx para FastAPI, Next.js, Django, Spring Boot u otra aplicación HTTP; implementar en las instalaciones, en una máquina virtual, con Docker, Podman, Compose u otra plataforma de contenedores, en AWS EC2 con o sin un ALB, o detrás de otro proxy confiable; o admitir archivos estáticos y protegidos, proxy inverso, puertas de enlace API, cargas, almacenamiento en caché, equilibrio de carga, WebSockets, SSE, respuestas de transmisión o gRPC. También se utiliza para revisiones de nginx.conf y conf.d, terminación de TLS, manejo de IP de cliente reenviado, limitación de velocidad, encabezados de seguridad, ajuste de rendimiento, validación de sintaxis y planificación de recarga segura.
