Generieren Sie ICS-Kalenderdateien (.ics) aus Beschreibungen in natürlicher Sprache. Verwenden Sie diese Option, wenn der Benutzer Kalenderereignisse, Besprechungen, Termine, Erinnerungen, wiederkehrende Ereignisse oder Zeitplanelemente erstellen möchte. Wird bei Anfragen ausgelöst, die „Kalenderereignis“, „ICS-Datei“, „.ics“, „Besprechungseinladung“, „Termin“, „wiederkehrendes Ereignis“, „Zeitplan“, „RRULE“, „Erinnerung“, „RSVP“, „Kalendereinladung“, „Meinen Kalender blockieren“ oder „Zum Kalender hinzufügen“ erwähnen.
