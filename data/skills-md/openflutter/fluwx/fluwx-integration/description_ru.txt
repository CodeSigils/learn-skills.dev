Полное руководство по интеграции плагинов WeChat SDK fluwx / fluwx_no_pay (v6+) в приложение Flutter: обмен в WeChat (сессия/Лента/избранное), вход через WeChat (получение кода авторизации), WeChat Pay, запуск мини‑программ, подписные сообщения, служба поддержки WeChat, запуск приложения из H5, а также настройка платформы и устранение неполадок для Android / iOS / OpenHarmony. Каждый раз, когда проект Flutter включает функции, связанные с WeChat — обмен в WeChat, авторизованный вход через WeChat, WeChat Pay, универсальные ссылки, LSApplicationQueriesSchemes, errCode ‑1, невозможность открыть WeChat и т.д., следует использовать этот навык, даже если пользователь явно не упоминает fluwx.
