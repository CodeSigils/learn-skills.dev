Un guide complet pour intégrer les plugins WeChat SDK fluwx / fluwx_no_pay (v6+) dans une application Flutter : partage WeChat (vers conversations/Moments/favoris), connexion WeChat (récupération du code d'authentification), paiement WeChat, lancement de mini-programmes, messages d'abonnement, service client WeChat, lancement de l'application H5, ainsi que configuration et dépannage de la plateforme pour Android / iOS / OpenHarmony. Chaque fois qu'un projet Flutter implique des fonctionnalités liées à WeChat (partage vers WeChat, connexion WeChat OAuth, WeChat Pay, liens universels, LSApplicationQueriesSchemes, errCode -1, échec de lancement de WeChat, etc.), même si l'utilisateur ne mentionne pas explicitement fluwx, cette compétence doit être utilisée.
