A complete guide to integrating the WeChat SDK plugins fluwx / fluwx_no_pay (v6+) in a Flutter app: WeChat sharing (chat, Moments, favorites), WeChat login (obtaining auth code), WeChat Pay, launching mini‑programs, subscribed messages, WeChat customer service, launching the app from H5, as well as platform configuration and troubleshooting for Android / iOS / OpenHarmony. As long as a Flutter project involves WeChat‑related features—sharing to WeChat, WeChat authorized login, WeChat Pay, universal link, LSApplicationQueriesSchemes, errCode -1, inability to launch WeChat, etc.—even if the user does not explicitly mention fluwx, this skill should still be used.
