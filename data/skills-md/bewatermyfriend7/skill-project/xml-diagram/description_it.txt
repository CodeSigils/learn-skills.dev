Genera un file di diagramma in formato XML (drawio) da una descrizione in linguaggio naturale. Supporta diagrammi di flusso, schede, grafici, icone e altre forme comuni; genera un file .drawio che può essere aperto e modificato direttamente in drawio. Funzionalmente identico al generatore SVG ma esporta drawio XML. Si attiva quando l'utente menziona disegno XML, drawio, generazione di diagrammi o diagrammi di flusso.
