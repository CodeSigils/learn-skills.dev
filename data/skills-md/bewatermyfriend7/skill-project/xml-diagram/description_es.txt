Genere un archivo de diagrama en formato XML (drawio) a partir de una descripción en lenguaje natural. Admite diagramas de flujo, tarjetas, gráficos, íconos y otras formas comunes; genera un archivo .drawio que se puede abrir y editar directamente en drawio. Funcionalmente idéntico al generador svg pero exporta drawio XML. Se activa cuando el usuario menciona dibujo XML, drawio, generar diagrama o diagrama de flujo.
