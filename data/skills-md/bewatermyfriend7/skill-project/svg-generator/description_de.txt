Generieren Sie SVG-Code aus Beschreibungen in natürlicher Sprache. Unterstützt Flussdiagramme, Karten, Diagramme, Symbole und andere gängige Grafiken und gibt eine SVG-Datei aus, die direkt in einem Browser angezeigt werden kann. Wird ausgelöst, wenn der Benutzer SVG erwähnt, ein Bild, eine Grafik, ein Symbol oder ein Flussdiagramm generiert.
