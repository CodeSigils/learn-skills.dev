Utilice esta habilidad siempre que el usuario tenga un código de interfaz de usuario existente O una URL de un sitio web activo y quiera comprender por qué los usuarios tienen dificultades con él, encontrar problemas de usabilidad o hacerlo más fácil de usar. Activadores de solicitudes directas como "revisar mi UI", "auditar mi interfaz", "verificar accesibilidad", "evaluar mi diseño", "mejorar la UX", "auditar este sitio web", "revisar https://example.com", pero TAMBIÉN en descripciones de síntomas indirectos como "los usuarios siguen abandonando este formulario", "algo se siente mal en esta página", "recibimos quejas sobre el flujo de pago", "la conversión cayó después del rediseño", "la gente dice que es confuso" o "hacer esto menos doloroso". utilizar".
