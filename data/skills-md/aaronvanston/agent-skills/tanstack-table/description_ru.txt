Создавайте таблицы и сетки данных с помощью TanStack Table v8. Охватывает определения столбцов, модели строк, сортировку, фильтрацию, нумерацию страниц, группировку, расширение, выбор строк, размер/упорядочение/закрепление/видимость столбцов, виртуализацию, закрепление строк, фасетирование, нечеткую фильтрацию, пользовательские функции, управление состоянием и рендеринг. Основной адаптер React, основной API не зависит от платформы. Используйте, когда вас просят «построить таблицу данных», «добавить сортировку в таблицу», «разбить результаты на страницы», «фильтровать данные таблицы», «создать сетку данных», «добавить выбор строки», «виртуализировать большую таблицу» или любую задачу, связанную с таблицей TanStack.
