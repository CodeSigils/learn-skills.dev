Créez des tables et des grilles de données avec TanStack Table v8. Couvre les définitions de colonnes, les modèles de lignes, le tri, le filtrage, la pagination, le regroupement, l'expansion, la sélection de lignes, la taille/l'ordre/l'épinglage/la visibilité des colonnes, la virtualisation, l'épinglage de lignes, le facettage, le filtrage flou, les fonctionnalités personnalisées, la gestion de l'état et le rendu. Adaptateur React principal, l'API principale est indépendante du framework. À utiliser lorsqu'on vous demande de « créer une table de données », « ajouter un tri à une table », « paginer les résultats », « filtrer les données de la table », « créer une grille de données », « ajouter une sélection de lignes », « virtualiser une grande table » ou toute tâche impliquant TanStack Table.
