قم ببناء الجداول وشبكات البيانات باستخدام TanStack Table v8. يغطي تعريفات الأعمدة، ونماذج الصفوف، والفرز، والتصفية، وترقيم الصفحات، والتجميع، والتوسيع، واختيار الصف، وحجم العمود/ترتيبه/تثبيته/رؤيته، والمحاكاة الافتراضية، وتثبيت الصفوف، والواجهات، والتصفية الغامضة، والميزات المخصصة، وإدارة الحالة، والعرض. محول React الأساسي، واجهة برمجة التطبيقات الأساسية هي إطار عمل حيادي. يُستخدم عندما يُطلب منك "إنشاء جدول بيانات"، أو "إضافة فرز إلى جدول"، أو "تقسيم الصفحات إلى صفحات"، أو "تصفية بيانات الجدول"، أو "إنشاء شبكة بيانات"، أو "إضافة تحديد صف"، أو "محاكاة جدول كبير"، أو أي مهمة تتضمن جدول TanStack.
