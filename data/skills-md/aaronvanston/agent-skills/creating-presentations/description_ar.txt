قم بإنشاء مجموعات شرائح جريئة وبسيطة وعروض تقديمية للمستثمرين. يغطي سير عمل العرض التقديمي الكامل بما في ذلك البنية السردية، وكتابة النصوص للشرائح، والتصميم المرئي (الطباعة، والتخطيطات، وألوان الأقسام)، وملاحظات المتحدث، والعروض التقديمية غير المتزامنة القابلة للقراءة. يدعم المواضيع الداكنة والفاتحة. استخدمه عندما يُطلب منك "إنشاء عرض تقديمي"، أو "مخطط تفصيلي لمجموعة"، أو "كتابة شرائح حول..."، أو "تصميم محاضرة حول..."، أو "إنشاء عرض تقديمي مبسط"، أو "عرض تقديمي للمستثمر"، أو "مساعدتي في محادثتي"، أو "مسودة محتوى الشريحة"، أو "كتابة ملاحظات المتحدث"، أو أي مهمة تتضمن التخطيط أو الهيكلة أو الكتابة أو التصميم أو إعداد مجموعة شرائح للعرض المباشر أو التوزيع المستقل.
