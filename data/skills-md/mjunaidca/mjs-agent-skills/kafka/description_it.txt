Apache Kafka su Kubernetes con Strimzi (modalità KRaft, senza ZooKeeper).
Questa competenza dovrebbe essere utilizzata quando gli utenti chiedono di distribuire cluster Kafka, build
produttori/consumatori, implementare modelli guidati dagli eventi o eseguire il debug di problemi di Kafka.
Include manifest testati e Makefile per la distribuzione con un solo comando.
