Apache Kafka auf Kubernetes mit Strimzi (KRaft-Modus, kein ZooKeeper).
Diese Fähigkeit sollte verwendet werden, wenn Benutzer Kafka-Cluster bereitstellen und erstellen möchten
Produzenten/Konsumenten, implementieren ereignisgesteuerte Muster oder debuggen Kafka-Probleme.
Enthält getestete Manifeste und Makefile für die Bereitstellung mit einem Befehl.
