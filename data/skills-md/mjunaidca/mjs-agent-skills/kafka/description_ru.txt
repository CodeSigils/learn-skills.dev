Apache Kafka в Kubernetes с Strimzi (режим KRaft, без ZooKeeper).
Этот навык следует использовать, когда пользователи просят развернуть кластеры Kafka, построить
производители/потребители, реализуйте шаблоны, управляемые событиями, или отлаживайте проблемы Kafka.
Включает протестированные манифесты и Makefile для развертывания одной командой.
