Compétence de gestion Nx monorepo pour le développement natif de l'IA. Cette compétence doit être utilisée lorsque vous travaillez avec des espaces de travail Nx, des graphiques de projet, la détection affectée, la génération de code et la mise en cache. À utiliser lorsque : analyser les dépendances, exécuter les commandes concernées, générer du code, configurer Nx Cloud ou optimiser les performances de build. Appelez les outils nx-mcp pour les requêtes de documentation.
