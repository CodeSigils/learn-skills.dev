Capacità di gestione di Nx monorepo per lo sviluppo nativo dell'intelligenza artificiale. Questa competenza dovrebbe essere utilizzata quando si lavora con spazi di lavoro Nx, grafici di progetto, rilevamento interessati, generazione di codice e memorizzazione nella cache. Da utilizzare quando: analizzare le dipendenze, eseguire comandi interessati, generare codice, configurare Nx Cloud o ottimizzare le prestazioni della build. Richiama gli strumenti nx-mcp per le query sulla documentazione.
