Habilidad de gestión de Nx monorepo para el desarrollo nativo de IA. Esta habilidad debe usarse cuando se trabaja con espacios de trabajo de Nx, gráficos de proyectos, detección de afectados, generación de código y almacenamiento en caché. Úselo cuando: analice dependencias, ejecute comandos afectados, genere código, configure Nx Cloud u optimice el rendimiento de la compilación. Invoque las herramientas nx-mcp para consultas de documentación.
