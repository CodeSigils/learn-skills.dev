Guida la creazione di app ChatGPT con widget interattivi utilizzando OpenAI Apps SDK e server MCP.
Da utilizzare quando si creano app personalizzate ChatGPT con componenti dell'interfaccia utente visiva, widget incorporati o rich
esperienze interattive. Copre l'architettura dei widget, la configurazione del server MCP con FastMCP, la risposta
metadati e configurazione della modalità sviluppatore. NON quando si costruiscono server MCP standard senza
widget (usa invece la skill building-mcp-servers).
