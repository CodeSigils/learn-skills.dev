يرشد إنشاء تطبيقات ChatGPT باستخدام عناصر واجهة المستخدم التفاعلية باستخدام خوادم OpenAI Apps SDK وMCP.
استخدمه عند إنشاء تطبيقات ChatGPT المخصصة باستخدام مكونات واجهة المستخدم المرئية، أو عناصر واجهة المستخدم المضمنة، أو العناصر الغنية
تجارب تفاعلية. يغطي بنية القطعة، وإعداد خادم MCP مع FastMCP، والاستجابة
البيانات التعريفية وتكوين وضع المطور. ليس عند إنشاء خوادم MCP القياسية بدونها
الأدوات (استخدم مهارة بناء خوادم mcp بدلاً من ذلك).
