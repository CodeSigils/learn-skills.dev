Руководства по созданию приложений ChatGPT с интерактивными виджетами с использованием OpenAI Apps SDK и серверов MCP.
Используйте при создании пользовательских приложений ChatGPT с компонентами визуального пользовательского интерфейса, встроенными виджетами или богатыми
интерактивный опыт. Охватывает архитектуру виджетов, настройку сервера MCP с помощью FastMCP, ответ.
метаданные и конфигурация режима разработчика. НЕ при создании стандартных серверов MCP без
виджеты (вместо этого используйте навык создания mcp-серверов).
