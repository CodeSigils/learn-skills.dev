Ouvrez une révision de code Diffo de l'ensemble de modifications git actuel dans le navigateur du réviseur et pilotez la boucle de rétroaction de cette session, à l'aide de la CLI diffo. À utiliser lorsque l'utilisateur souhaite examiner vos modifications, demande à ouvrir une révision de code ou lorsque vous terminez une modification volumineuse ou multi-fichiers qui mérite une lecture humaine avant qu'elle n'arrive.
