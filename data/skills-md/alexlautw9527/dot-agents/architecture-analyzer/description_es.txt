Úselo al incorporarse a un sistema de repositorios múltiples desconocido, prepararse para el trabajo de migración/refactorización o producir una auditoría de arquitectura con seguimiento del flujo de datos entre repositorios y comprobaciones de código inactivo. No para la depuración de errores de ruta única, la creación de perfiles de rendimiento en tiempo de ejecución o la planificación de implementación una vez que ya se comprende el sistema.
