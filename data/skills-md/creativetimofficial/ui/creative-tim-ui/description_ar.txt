مساعد مكتبة كتلة Tim UI الإبداعي. يُستخدم عند إضافة أو إنشاء أو تعديل كتل/مكونات/صفحات واجهة المستخدم من Creative-tim.com/ui. يغطي فلسفة التصميم (البساطة، قاعدة 95%، البحث أولاً)، واكتشاف الكتل، وطرق تثبيت واجهة سطر الأوامر (CLI)، وإعداد مفتاح PRO API، وقواعد تصميم Creative Tim (العلامة التجارية البرتقالية، وقاعدة shadcn/ui، وTailwind v4). يُنشئ كتلًا متعمدة ومقيدة، وليست الحد الأقصى.
