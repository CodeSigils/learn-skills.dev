Помощник по библиотеке блоков Creative Tim UI. Используйте при добавлении, создании или изменении блоков/компонентов/страниц пользовательского интерфейса с сайта Creative-tim.com/ui. Охватывает философию дизайна (минимализм, правило 95%, сначала исследования), обнаружение блоков, оба метода установки CLI, настройку ключей PRO API и правила дизайна Creative Tim (бренд Orange, база shadcn/ui, Tailwind v4). Создает преднамеренные и сдержанные блоки, а не максимальные.
