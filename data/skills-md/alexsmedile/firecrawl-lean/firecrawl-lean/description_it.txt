Web scraping, ricerca, scansione e interazione con il browser tramite la CLI di Firecrawl. Utilizzare quando l'utente desidera eseguire ricerche sul Web, recuperare un URL, acquisire contenuti, eseguire la scansione di documenti, scaricare un sito, estrarre dati strutturati o interagire con pagine con accesso pesante/JS. Si attiva su: "cerca", "scrape", "recupera questo URL", "ottieni la pagina", "scansione", "scarica il sito", "estrai dati strutturati", "fai clic sul pulsante", "compila il modulo", "accedi". NON utilizzare per file locali, git o modifica del codice.
Per uso avanzato (scansione in blocco, estrazione di agenti AI, profili browser, lavori paralleli): installa le competenze firecrawl-crawl, firecrawl-agent o firecrawl-instruct.
