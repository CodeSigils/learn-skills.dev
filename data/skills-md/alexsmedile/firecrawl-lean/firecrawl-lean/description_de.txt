Web-Scraping, Suche, Crawling und Browser-Interaktion über Firecrawl CLI. Verwenden Sie diese Option, wenn der Benutzer das Web durchsuchen, eine URL abrufen, Inhalte durchsuchen, Dokumente crawlen, eine Website herunterladen, strukturierte Daten extrahieren oder mit JS-lastigen/anmeldegeschützten Seiten interagieren möchte. Auslöser bei: „Suchen“, „Scrapen“, „Diese URL abrufen“, „Seite abrufen“, „Crawlen“, „Website herunterladen“, „Strukturierte Daten extrahieren“, „Auf die Schaltfläche klicken“, „Formular ausfüllen“, „Anmelden bei“. NICHT für lokale Dateien, Git oder Codebearbeitung verwenden.
Für erweiterte Verwendung (Massen-Crawl, KI-Agent-Extraktion, Browserprofile, parallele Jobs): Installieren Sie die Fähigkeiten Firecrawl-Crawl, Firecrawl-Agent oder Firecrawl-Instruct.
