Raspado web, búsqueda, rastreo e interacción con el navegador a través de Firecrawl CLI. Úselo cuando el usuario quiera buscar en la web, obtener una URL, extraer contenido, rastrear documentos, descargar un sitio, extraer datos estructurados o interactuar con páginas con mucho JS/con acceso controlado. Activadores de: "buscar", "extraer", "obtener esta URL", "obtener la página", "rastrear", "descargar el sitio", "extraer datos estructurados", "hacer clic en el botón", "rellenar el formulario", "iniciar sesión en". NO lo use para archivos locales, git o edición de código.
Para uso avanzado (rastreo masivo, extracción de agentes de IA, perfiles de navegador, trabajos paralelos): instale las habilidades firecrawl-crawl, firecrawl-agent o firecrawl-instruct.
