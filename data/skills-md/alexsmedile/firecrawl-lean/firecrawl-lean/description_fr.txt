Scraping Web, recherche, exploration et interaction avec le navigateur via Firecrawl CLI. À utiliser lorsque l'utilisateur souhaite effectuer une recherche sur le Web, récupérer une URL, extraire du contenu, explorer des documents, télécharger un site, extraire des données structurées ou interagir avec des pages lourdes JS/à connexion fermée. Déclencheurs sur : "rechercher", "scrape", "récupérer cette URL", "obtenir la page", "explorer", "télécharger le site", "extraire des données structurées", "cliquer sur le bouton", "remplir le formulaire", "se connecter à". Ne PAS utiliser pour les fichiers locaux, git ou l'édition de code.
Pour une utilisation avancée (analyse groupée, extraction d'agent IA, profils de navigateur, tâches parallèles) : installez les compétences firecrawl-crawl, firecrawl-agent ou firecrawl-instruct.
