تجريف الويب والبحث والزحف والتفاعل مع المتصفح عبر Firecrawl CLI. يُستخدم عندما يريد المستخدم البحث في الويب، أو جلب عنوان URL، أو استخراج المحتوى، أو الزحف إلى المستندات، أو تنزيل موقع، أو استخراج البيانات المنظمة، أو التفاعل مع صفحات JS الثقيلة/بوابات تسجيل الدخول. مشغلات عند: "البحث عن"، "كشط"، "جلب عنوان URL هذا"، "الحصول على الصفحة"، "الزحف"، "تنزيل الموقع"، "استخراج البيانات المنظمة"، "النقر على الزر"، "ملء النموذج"، "تسجيل الدخول إلى". لا تستخدمه للملفات المحلية أو git أو تحرير التعليمات البرمجية.
للاستخدام المتقدم (الزحف المجمع، واستخراج وكيل الذكاء الاصطناعي، وملفات تعريف المتصفح، والوظائف المتوازية): قم بتثبيت مهارات الزحف الناري، أو وكيل الزحف الناري، أو مهارات تعليمات الزحف الناري.
