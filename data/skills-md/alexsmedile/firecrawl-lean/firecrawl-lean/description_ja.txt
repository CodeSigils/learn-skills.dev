Firecrawl CLI を介した Web スクレイピング、検索、クローリング、およびブラウザー操作。ユーザーが Web の検索、URL の取得、コンテンツの取得、ドキュメントのクロール、サイトのダウンロード、構造化データの抽出、または JS を使用するページやログインゲート型ページの操作を行う場合に使用します。トリガー: 「検索」、「スクレープ」、「この URL を取得」、「ページを取得」、「クロール」、「サイトをダウンロード」、「構造化データを抽出」、「ボタンをクリック」、「フォームに記入」、「ログイン」。ローカル ファイル、git、またはコード編集には使用しないでください。
高度な使用 (一括クロール、AI エージェント抽出、ブラウザ プロファイル、並列ジョブ) の場合: firecrawl-crawl、firecrawl-agent、または firecrawl-instruct スキルをインストールします。
