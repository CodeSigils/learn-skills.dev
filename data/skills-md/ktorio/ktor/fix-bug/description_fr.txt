Workflow de correction de bogues de bout en bout pour le projet Ktor. Accepte un problème GitHub (#NUMBER), un problème YouTrack (KTOR-NUMBER) ou une URL YouTrack (https://youtrack.jetbrains.com/issue/KTOR-NUMBER). Récupère le problème, crée un test de reproduction défaillant, valide sur une nouvelle branche, implémente le correctif, valide et ouvre un PR. Utilisez cette compétence chaque fois que l'utilisateur souhaite corriger un bogue à partir d'un outil de suivi des problèmes, mentionne un numéro de problème KTOR ou fait référence à un problème GitHub à résoudre.
