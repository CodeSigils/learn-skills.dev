Flujo de trabajo de corrección de errores de un extremo a otro para el proyecto Ktor. Acepta una incidencia de GitHub (#NUMBER), una incidencia de YouTrack (KTOR-NUMBER) o una URL de YouTrack (https://youtrack.jetbrains.com/issue/KTOR-NUMBER). Recupera el problema, crea una prueba de reproducción fallida, confirma en una nueva rama, implementa la solución, valida y abre un PR. Utilice esta habilidad siempre que el usuario quiera corregir un error de un rastreador de problemas, mencione un número de problema de KTOR o haga referencia a un problema de GitHub para solucionarlo.
