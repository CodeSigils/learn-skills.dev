End-to-End-Bugfix-Workflow für das Ktor-Projekt. Akzeptiert ein GitHub-Problem (#NUMBER), ein YouTrack-Problem (KTOR-NUMBER) oder eine YouTrack-URL (https://youtrack.jetbrains.com/issue/KTOR-NUMBER). Ruft das Problem ab, erstellt einen fehlgeschlagenen Reproduktionstest, führt einen Commit für einen neuen Zweig durch, implementiert den Fix, validiert und öffnet einen PR. Verwenden Sie diesen Skill immer dann, wenn der Benutzer einen Fehler aus einem Issue-Tracker beheben möchte, eine KTOR-Problemnummer erwähnt oder auf ein zu behebendes GitHub-Problem verweist.
