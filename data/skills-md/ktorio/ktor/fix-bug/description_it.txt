Flusso di lavoro di correzione dei bug end-to-end per il progetto Ktor. Accetta un problema GitHub (#NUMBER), un problema YouTrack (KTOR-NUMBER) o un URL YouTrack (https://youtrack.jetbrains.com/issue/KTOR-NUMBER). Recupera il problema, crea un test di riproduzione non riuscito, esegue il commit su un nuovo ramo, implementa la correzione, convalida e apre un PR. Utilizza questa competenza ogni volta che l'utente desidera correggere un bug da un tracker di problemi, menziona un numero di problema KTOR o fa riferimento a un problema GitHub da risolvere.
