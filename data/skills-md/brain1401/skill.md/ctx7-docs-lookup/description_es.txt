Obliga al uso de ctx7 (context7 MCP) para consultar la documentación oficial cuando se encuentran errores repetidos o desconocidos durante la codificación, o cuando no está seguro de si su conocimiento se aplica con precisión al proyecto actual durante la planificación. Se activa en cualquier situación de planificación o implementación de código, especialmente cuando los errores se repiten más de 2 veces o el uso de la API de biblioteca/marco es incierto. Consulte esta habilidad siempre que depure errores, adopte nuevas bibliotecas, verifique el uso de API, escriba archivos de configuración, maneje migraciones o cualquier situación en la que verificar documentos oficiales pueda evitar el desperdicio de esfuerzos.
