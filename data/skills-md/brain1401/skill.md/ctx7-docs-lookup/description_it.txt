Forza l'uso di ctx7 (context7 MCP) per consultare la documentazione ufficiale quando si riscontrano errori ripetuti o sconosciuti durante la codifica o quando non si è sicuri che le proprie conoscenze si applichino accuratamente al progetto corrente durante la pianificazione. Si attiva su qualsiasi situazione di implementazione o pianificazione del codice, in particolare quando gli errori si ripetono più di 2 volte o l'utilizzo dell'API della libreria/framework è incerto. Consulta questa competenza ogni volta che esegui il debug di errori, adotta nuove librerie, verifica l'utilizzo dell'API, scrivi file di configurazione, gestisci migrazioni o qualsiasi situazione in cui il controllo dei documenti ufficiali potrebbe evitare sforzi inutili.
