كتالوج الرسوم المتحركة النصية المنسقة مع مواصفات JSON الدقيقة للعناوين والتسميات والعدادات ومقايضات النص. يُستخدم عندما يحتاج الوكيل إلى اختيار أو ترجمة التأثيرات المسماة مثل التمويه الناعم، أو الآلة الكاتبة، أو المحور المشترك، أو كشف الخط، أو stagger، أو crossfade، أو الإنشاءات الحركية إلى WAAPI، أو Motion، أو Framer Motion، أو GSAP، أو CSS، أو Lottie، أو Rive، أو مجموعات مماثلة.
