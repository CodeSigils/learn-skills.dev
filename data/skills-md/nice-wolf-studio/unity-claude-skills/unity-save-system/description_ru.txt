Архитектура системы сохранения/загрузки Unity. Выбор формата сериализации, DTO для сохранения данных, управление версиями и миграция, облачная синхронизация, определение области PlayerPrefs, стратегии автосохранения, постоянство мобильных устройств. Формат РЕШЕНИЯ: КОГДА/РЕШЕНИЕ/ЛЕША/ПОЛУЧИЛОСЬ. На основе Unity 6.3 LTS.
