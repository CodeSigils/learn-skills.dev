دليل Unity 6 المتعدد اللاعبين والشبكات. يُستخدم عند إنشاء ألعاب متعددة اللاعبين، أو العمل مع Netcode لـ GameObjects، أو NetworkManager، أو NetworkObject، أو NetworkBehaviour، أو RPCs (ServerRpc، أو ClientRpc)، أو NetworkVariables، أو خدمات Unity متعددة اللاعبين (Relay، أو Lobby). يغطي بنية خادم العميل، ومزامنة الحالة، وإدارة المشهد. استنادًا إلى وثائق Unity 6.3 LTS.
