Guide de test Unity 6. À utiliser lors de l'écriture de tests unitaires, de tests d'intégration ou lors de la réalisation de TDD avec Unity Test Framework. Couvre les tests du mode édition et du mode lecture, les attributs NUnit ([Test], [UnityTest], [SetUp], [TearDown]), le test des MonoBehaviors et des coroutines, ainsi que l'intégration CI/CD. Basé sur la documentation Unity 6.3 LTS.
