Unity 6-Testleitfaden. Verwenden Sie diese Option, wenn Sie Komponententests, Integrationstests schreiben oder TDD mit dem Unity Test Framework durchführen. Behandelt Tests im Bearbeitungsmodus und Wiedergabemodus, NUnit-Attribute ([Test], [UnityTest], [SetUp], [TearDown]), das Testen von MonoBehaviours und Coroutinen sowie die CI/CD-Integration. Basierend auf der Unity 6.3 LTS-Dokumentation.
