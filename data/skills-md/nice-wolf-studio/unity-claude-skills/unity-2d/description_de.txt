Entwicklungshandbuch für Unity 6 2D-Spiele. Verwenden Sie es beim Erstellen von 2D-Spielen, beim Arbeiten mit Sprites, Sprite-Atlas, SpriteRenderer, Tilemaps, 2D-Physik (Rigidbody2D, Collider2D), 2D-Beleuchtung, beim Sortieren von Ebenen oder beim Sortieren von Gruppen. Basierend auf der Unity 6.3 LTS-Dokumentation.
