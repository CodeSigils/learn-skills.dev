Guide des scripts et des outils personnalisés de l'éditeur Unity 6. À utiliser lors de la création d'inspecteurs personnalisés, de EditorWindows, de PropertyDrawers, de Gizmos, de Handles, d'éléments de menu ou d'extensions d'éditeur. Couvre le modèle SerializedObject/SerializedProperty, AssetDatabase et le code éditeur uniquement avec #if UNITY_EDITOR. Basé sur la documentation Unity 6.3 LTS.
