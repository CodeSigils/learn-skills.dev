Руководство по написанию сценариев редактора Unity 6 и пользовательским инструментам. Используйте при создании пользовательских инспекторов, EditorWindows, PropertyDrawers, Gizmos, Handle, пунктов меню или расширений редактора. Охватывает шаблон SerializedObject/SerializedProperty, AssetDatabase и код только для редактора с #if UNITY_EDITOR. На основе документации Unity 6.3 LTS.
