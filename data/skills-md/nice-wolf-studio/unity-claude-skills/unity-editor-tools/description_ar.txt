دليل البرمجة النصية لمحرر Unity 6 والأدوات المخصصة. يُستخدم عند إنشاء أدوات فحص مخصصة، أو EditorWindows، أو PropertyDrawers، أو Gizmos، أو Handles، أو عناصر القائمة، أو ملحقات المحرر. يغطي نمط SerializedObject/SerializedProperty، وقاعدة بيانات الأصول، والتعليمات البرمجية للمحرر فقط باستخدام #if UNITY_EDITOR. استنادًا إلى وثائق Unity 6.3 LTS.
