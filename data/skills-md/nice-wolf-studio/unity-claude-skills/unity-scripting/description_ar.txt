دليل البرمجة النصية للوحدة 6 C#. يُستخدم عند كتابة البرامج النصية MonoBehaviour، أو التعامل مع أحداث دورة الحياة (Awake، Start، Update، FixedUpdate)، باستخدام coroutines أو async/await (Awaitable)، أو العمل مع ScriptableObjects، أو الأحداث، أو المفوضين، أو واجهات برمجة التطبيقات الأساسية مثل Vector3، أو Quaternion، أو Time، أو Debug. استنادًا إلى وثائق Unity 6.3 LTS.
