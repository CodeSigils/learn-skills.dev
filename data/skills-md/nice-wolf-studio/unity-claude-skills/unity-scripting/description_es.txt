Guía de secuencias de comandos de Unity 6 C#. Úselo al escribir scripts MonoBehaviour, manejar eventos del ciclo de vida (Awake, Start, Update, FixUpdate), usar corrutinas o async/await (Awaitable), trabajar con ScriptableObjects, eventos, delegados o API principales como Vector3, Quaternion, Time, Debug. Basado en la documentación de Unity 6.3 LTS.
