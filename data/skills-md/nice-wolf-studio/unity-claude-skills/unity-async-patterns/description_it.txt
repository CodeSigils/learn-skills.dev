Modelli di correttezza unitaria asincrona e coroutine. Rileva gli errori comuni con Awaitable double-await, token di annullamento mancanti, contesto del thread dopo BackgroundThreadAsync, deglutizione degli errori di coroutine, modalità batch WaitForEndOfFrame e Addressables gestiscono le perdite. Formato PATTERN: QUANDO/SBAGLIATO/DESTRA/RICEVUTO. Basato sulla documentazione di Unity 6.3 LTS.
