Руководство по разработке пользовательского интерфейса Unity 6. Используйте при создании пользовательских интерфейсов, меню, HUD, кнопок или любых элементов пользовательского интерфейса. Охватывает UI Toolkit (рекомендуется для новых проектов — USS, UXML, UI Builder, привязка данных), uGUI/Canvas (устаревший пользовательский интерфейс среды выполнения) и IMGUI. На основе документации Unity 6.3 LTS.
