Guía de desarrollo de la interfaz de usuario de Unity 6. Úselo al crear interfaces de usuario, menús, HUD, botones o cualquier elemento de la interfaz de usuario. Cubre UI Toolkit (recomendado para nuevos proyectos: USS, UXML, UI Builder, enlace de datos), uGUI/Canvas (UI en tiempo de ejecución heredado) e IMGUI. Basado en la documentación de Unity 6.3 LTS.
