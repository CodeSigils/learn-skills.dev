Guide de développement de l'interface utilisateur Unity 6. À utiliser lors de la création d'interfaces utilisateur, de menus, de HUD, de boutons ou de tout élément d'interface utilisateur. Couvre UI Toolkit (recommandé pour les nouveaux projets – USS, UXML, UI Builder, liaison de données), uGUI/Canvas (interface utilisateur d'exécution héritée) et IMGUI. Basé sur la documentation Unity 6.3 LTS.
