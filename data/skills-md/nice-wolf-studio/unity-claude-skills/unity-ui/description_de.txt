Entwicklungshandbuch für die Unity 6-Benutzeroberfläche. Verwenden Sie es beim Erstellen von Benutzeroberflächen, Menüs, HUD, Schaltflächen oder anderen UI-Elementen. Deckt UI Toolkit (empfohlen für neue Projekte – USS, UXML, UI Builder, Datenbindung), uGUI/Canvas (ältere Laufzeit-Benutzeroberfläche) und IMGUI ab. Basierend auf der Unity 6.3 LTS-Dokumentation.
