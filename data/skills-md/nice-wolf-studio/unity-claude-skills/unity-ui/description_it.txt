Guida allo sviluppo dell'interfaccia utente di Unity 6. Da utilizzare durante la creazione di interfacce utente, menu, HUD, pulsanti o qualsiasi elemento dell'interfaccia utente. Copre UI Toolkit (consigliato per nuovi progetti: USS, UXML, UI Builder, associazione dati), uGUI/Canvas (interfaccia utente runtime legacy) e IMGUI. Basato sulla documentazione di Unity 6.3 LTS.
