Modelli di correttezza del nuovo sistema di input Unity. Rileva gli errori comuni relativi alla lettura dell'azione (triggered vs IsPressed vs WasPressedThisFrame), cambio della mappa di azione, riassociazione della persistenza, durata di InputValue, PassThrough vs Value, assegnazione del dispositivo multiplayer locale e commutazione automatica dello schema di controllo. Formato PATTERN: QUANDO/SBAGLIATO/DESTRA/RICEVUTO. Basato su Unity 6.3 LTS.
