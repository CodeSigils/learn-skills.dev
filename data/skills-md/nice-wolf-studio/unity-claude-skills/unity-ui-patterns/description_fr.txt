Traduction de la conception en code de modèles Unity UI/UX. Architecture de flux d'écran, séparation View/ViewModel, architecture HUD, systèmes de feedback et de jus, vues dynamiques de liste/grille, contrats de transition et d'animation. Boîte à outils d'interface utilisateur uniquement. Format d'INTENTION DE CONCEPTION : INTENTION/FAUX/DROITE/ÉCHAFAUDAGE/CROCHET DE CONCEPTION. Basé sur Unity 6.3 LTS.
