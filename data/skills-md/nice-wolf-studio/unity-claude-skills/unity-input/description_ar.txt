دليل نظام الإدخال الوحدة 6 يُستخدم عند التعامل مع إدخالات المشغل أو عناصر التحكم أو لوحة الألعاب أو لوحة المفاتيح أو الماوس أو اللمس أو وحدات تحكم XR. يغطي حزمة نظام الإدخال الجديدة (مستحسن)، وإجراءات الإدخال، وخرائط الإجراءات، وأنظمة التحكم، ومكون PlayerInput، وتصحيح أخطاء الإدخال. استنادًا إلى وثائق Unity 6.3 LTS.
