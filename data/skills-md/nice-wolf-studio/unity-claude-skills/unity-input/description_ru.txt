Руководство по системе ввода Unity 6. Используйте при работе с вводом игрока, элементами управления, геймпадом, клавиатурой, мышью, сенсорным экраном или контроллерами XR. Охватывает новый пакет системы ввода (рекомендуется), действия ввода, карты действий, схемы управления, компонент PlayerInput и отладку ввода. На основе документации Unity 6.3 LTS.
