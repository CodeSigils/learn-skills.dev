Esegui una revisione del codice statico e di sola lettura di una richiesta pull Astro o di un ramo locale, un intervallo di commit, un diff, una patch o un albero di lavoro preparato come richiesta pull. Utilizza questa abilità solo quando l'utente chiede di rivedere le modifiche del PR, rivedere il proprio ramo corrente prima di aprire o aggiornare un PR o auto-revisionare un PR per correttezza, sicurezza, test, semplicità, portabilità del runtime, gestione degli errori, commenti, documentazione del comportamento e copertura del set di modifiche. Non utilizzarlo per la revisione dei problemi, l'indagine sulle segnalazioni di bug, la riproduzione, la diagnosi o il triage. Questa competenza riporta solo i risultati: non modifica mai il codice né esegue codice di progetto, test, build, controlli o script
