Effectuez une révision statique du code en lecture seule d'une demande d'extraction Astro ou d'une branche locale, d'une plage de validation, d'un diff, d'un correctif ou d'une arborescence de travail en cours de préparation en tant que demande d'extraction. Utilisez cette compétence uniquement lorsque l'utilisateur demande à examiner les modifications apportées au PR, à examiner sa branche actuelle avant d'ouvrir ou de mettre à jour un PR, ou à examiner lui-même un PR pour en vérifier l'exactitude, la sécurité, les tests, la simplicité, la portabilité d'exécution, la gestion des erreurs, les commentaires, la documentation sur le comportement et la couverture des ensembles de modifications. Ne l'utilisez pas pour l'examen des problèmes, l'enquête sur les rapports de bogues, la reproduction, le diagnostic ou le tri. Cette compétence rapporte uniquement les résultats : elle ne modifie jamais le code et n'exécute jamais le code du projet, les tests, les builds, les vérifications ou les scripts.
