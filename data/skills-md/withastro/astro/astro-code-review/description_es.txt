Realice una revisión de código estático de solo lectura de una solicitud de extracción de Astro o de una rama local, rango de confirmación, diferencia, parche o árbol de trabajo que se esté preparando como una solicitud de extracción. Utilice esta habilidad solo cuando el usuario solicite revisar los cambios de PR, revisar su rama actual antes de abrir o actualizar un PR, o revisar automáticamente un PR para verificar su corrección, seguridad, pruebas, simplicidad, portabilidad en tiempo de ejecución, manejo de errores, comentarios, documentación de comportamiento y cobertura de conjuntos de cambios. No lo utilice para revisión de problemas, investigación de informes de errores, reproducción, diagnóstico o clasificación. Esta habilidad solo informa hallazgos: nunca edita código ni ejecuta código de proyecto, pruebas, compilaciones, verificaciones o scripts.
