Astro プル リクエスト、またはプル リクエストとして準備されているローカル ブランチ、コミット範囲、差分、パッチ、または作業ツリーの静的で読み取り専用のコード レビューを実行します。このスキルは、ユーザーが PR の変更をレビューする、PR を開いたり更新する前に現在のブランチをレビューする、または正確性、セキュリティ、テスト、シンプルさ、ランタイム移植性、エラー処理、コメント、動作ドキュメント、および変更セットの適用範囲について PR を自己レビューするように要求した場合にのみ使用してください。問題のレビュー、バグレポートの調査、再現、診断、またはトリアージには使用しないでください。このスキルは結果のみを報告します。コードを編集したり、プロジェクト コード、テスト、ビルド、チェック、スクリプトを実行したりすることはありません。
