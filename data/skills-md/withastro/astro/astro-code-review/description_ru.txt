Выполните статическую проверку кода запроса на извлечение Astro или локальной ветки, диапазона фиксации, различий, исправлений или рабочего дерева, подготовленных в качестве запроса на включение, только для чтения. Используйте этот навык только тогда, когда пользователь просит просмотреть изменения PR, просмотреть свою текущую ветку перед открытием или обновлением PR или самостоятельно проверить PR на предмет правильности, безопасности, тестов, простоты, переносимости среды выполнения, обработки ошибок, комментариев, документации по поведению и покрытия набора изменений. Не используйте его для проверки проблем, изучения отчетов об ошибках, воспроизведения, диагностики или сортировки. Этот навык сообщает только о результатах: он никогда не редактирует код и не запускает код проекта, тесты, сборки, проверки или сценарии.
