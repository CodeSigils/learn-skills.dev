Führen Sie eine statische, schreibgeschützte Codeüberprüfung einer Astro-Pull-Anfrage oder eines lokalen Zweigs, Commit-Bereichs, Diffs, Patches oder Arbeitsbaums durch, der als Pull-Anfrage vorbereitet wird. Verwenden Sie diese Fähigkeit nur, wenn der Benutzer PR-Änderungen überprüfen, seinen aktuellen Zweig überprüfen möchte, bevor er eine PR öffnet oder aktualisiert, oder eine PR selbst auf Korrektheit, Sicherheit, Tests, Einfachheit, Laufzeitportabilität, Fehlerbehandlung, Kommentare, Verhaltensdokumentation und Änderungssatzabdeckung überprüfen möchte. Verwenden Sie es nicht zur Überprüfung von Problemen, zur Untersuchung von Fehlerberichten, zur Reproduktion, zur Diagnose oder zur Triage. Dieser Skill meldet nur Ergebnisse: Er bearbeitet niemals Code oder führt Projektcode, Tests, Builds, Prüfungen oder Skripte aus
