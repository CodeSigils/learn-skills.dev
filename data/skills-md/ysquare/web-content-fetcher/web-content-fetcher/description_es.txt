Extraiga el contenido del artículo de cualquier URL como Markdown limpio. Utiliza el script Scrapling como método principal (con respaldo automático rápido → sigiloso), Jina Reader como alternativa para páginas simples. Conserva encabezados, enlaces, imágenes, listas y bloques de código. Utilice esta habilidad siempre que el usuario quiera buscar, leer, extraer, extraer o resumir contenido de una URL, incluidas publicaciones de blog, artículos de noticias, artículos de WeChat (微信公众号), páginas de documentación o cualquier página web. También se activa cuando el usuario dice cosas como "帮我读一下这篇文章", "抓取这个网页", "提取正文" o "lee esta página por mí".
