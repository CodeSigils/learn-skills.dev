À utiliser lors de l'ajout d'une authentification ou d'une autorisation à des actions sécurisées avec Better Auth : couvre la configuration du middleware betterAuth(), le contexte de session saisi (BetterAuthContext), les rappels d'autorisation personnalisés (AuthorizeFn), la gestion non autorisée(), la configuration nextCookies() et la configuration Next.js authInterrupts.
