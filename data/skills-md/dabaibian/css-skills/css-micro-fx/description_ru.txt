Функциональные эффекты обратной связи на чистом CSS для ввода форм, кнопок, состояний загрузки и текстовых ссылок. Запускается :focus, :active и изменениями состояния, а не наведением курсора. Автоматически подбирает интенсивность к существующему стилю дизайна. Ноль JS, ноль зависимостей, никаких проблем с SSR. Источник: cssfx (6.1k ★).
