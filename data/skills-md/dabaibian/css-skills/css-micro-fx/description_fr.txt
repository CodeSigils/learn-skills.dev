Effets de rétroaction fonctionnels CSS purs pour les entrées de formulaire, les boutons, les états de chargement et les liens texte. Déclenché par les changements de :focus, :active et d'état – et non par le survol. Adapte automatiquement l'intensité au style de conception existant. Zéro JS, zéro dépendance, pas de problème SSR. Provenant de cssfx (6,1k ★).
