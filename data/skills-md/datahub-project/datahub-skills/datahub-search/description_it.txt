Utilizza questa competenza quando l'utente desidera eseguire ricerche nel catalogo DataHub, scoprire entità, rispondere a domande ad hoc sui propri dati, trovare set di dati o esplorare per piattaforma o dominio. Si attiva su: "cerca DataHub", "trova set di dati", "chi possiede X", "quali tabelle contengono PII", "quali colonne ha X" o qualsiasi richiesta di ricerca, scoperta, navigazione o risposta a domande una tantum sui metadati DataHub. Per domande sulla derivazione ("cosa alimenta X"), utilizzare `/datahub-lineage`. Per controlli sistematici ("quanto sono completi i nostri metadati"), utilizzare `/datahub-audit`.
