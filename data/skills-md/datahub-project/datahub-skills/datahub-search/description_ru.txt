Используйте этот навык, когда пользователь хочет выполнить поиск в каталоге DataHub, обнаружить объекты, ответить на специальные вопросы о своих данных, найти наборы данных или выполнить поиск по платформе или домену. Запускается по следующим запросам: «поиск в DataHub», «найти наборы данных», «кому принадлежит X», «какие таблицы содержат персональные данные», «какие столбцы есть в X» или любой запрос на поиск, обнаружение, просмотр или ответ на разовые вопросы о метаданных DataHub. Для вопросов о происхождении («что входит в X») используйте `/datahub-lineage`. Для систематического аудита («насколько полны наши метаданные») используйте `/datahub-audit`.
