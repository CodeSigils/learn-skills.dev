Utilisez cette compétence lorsque l'utilisateur doit configurer une connexion DataHub, installer la CLI DataHub, configurer l'authentification, vérifier la connectivité, définir des étendues par défaut ou créer des profils de configuration d'agent. Se déclenche sur : « configurer DataHub », « se connecter à DataHub », « installer DataHub CLI », « configurer DataHub », « définir la plate-forme par défaut », « se concentrer sur le domaine X », « créer un profil » ou toute demande d'établissement, de configuration ou de dépannage de la connectivité DataHub.
