Utilisez cette compétence lorsque l'utilisateur demande à créer une seule spécification d'API REST à l'aide du style Spec Kit/Speckit. Cela inclut les invites indonésiennes telles que « buatkan speckit REST API », « buatkan API speckit », « buatkan spesifikasi REST API », « buatkan dokumen API » ou les invites en anglais telles que « générer une spécification d'API REST », « créer une spécification d'API REST » et « créer une spécification de fonctionnalité d'API REST ». La sortie doit être créée sous docs/speckit/<feature-name>/ et doit décrire une seule opération API demandée.
