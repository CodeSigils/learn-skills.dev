Verwenden Sie diese Fähigkeit, wenn der Benutzer eine einzelne REST-API-Spezifikation im Spec Kit-/Speckit-Stil erstellen möchte. Dazu gehören indonesische Eingabeaufforderungen wie „buatkan speckit REST API“, „buatkan API speckit“, „buatkan spesifikasi REST API“, „buatkan dokumen API“ oder englische Eingabeaufforderungen wie „generate REST API spec“, „create REST API Specification“ und „make REST API feature spec“. Die Ausgabe muss unter docs/speckit/<feature-name>/ erstellt werden und darf nur eine angeforderte API-Operation beschreiben.
