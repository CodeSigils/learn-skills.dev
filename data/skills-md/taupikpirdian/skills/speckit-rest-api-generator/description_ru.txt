Используйте этот навык, когда пользователь просит создать единую спецификацию REST API, используя стиль Spec Kit/Speckit. Сюда входят подсказки на индонезийском языке, такие как «buatkan speckit REST API», «buatkan speckit REST API», «buatkan spesifikasi REST API», «buatkan dokumen API», или подсказки на английском языке, такие как «создать спецификацию REST API», «создать спецификацию REST API» и «создать спецификацию функции REST API». Выходные данные должны быть созданы в docs/speckit/<имя-функции>/ и должны описывать только одну запрошенную операцию API.
