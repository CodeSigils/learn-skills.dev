Utilizza questa competenza quando l'utente richiede di creare una singola specifica API REST utilizzando lo stile Spec Kit/Speckit. Sono inclusi messaggi in indonesiano come "buatkan speckit REST API", "buatkan API speckit", "buatkan spesifikasi REST API", "buatkan dokumen API" o messaggi in inglese come "genera specifiche API REST", "crea specifiche API REST" e "crea specifiche funzionalità API REST". L'output deve essere creato in docs/speckit/<feature-name>/ e deve descrivere solo un'operazione API richiesta.
