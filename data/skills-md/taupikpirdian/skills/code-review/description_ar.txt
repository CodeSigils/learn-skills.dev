قم بمراجعة تغييرات التعليمات البرمجية الحالية وطلبات دمج GitLab واختلافات التعليمات البرمجية من خلال موقف الأمان أولاً والمشكلة فقط. يُستخدم عندما يُطلب من Codex مراجعة تغييرات git المحلية، أو عنوان MR URL، أو طلب دمج GitLab، أو فرق الكود، أو تغييرات الكود مقابل OWASP، أو Clean Architecture، أو قواعد طبقة التطبيق/المجال DDD، ومعايير كود Go، ومتطلبات الاختبار؛ يركز النتائج على الكود الذي تم تغييره ويتضمن سير عمل GitLab MCP وتصنيف الخطورة والتعليقات الموجزة وإرشادات البحث المضمنة.
