SolidWorks CAD 自動化スキル。Python COM インターフェイスを介して OpenClaw / Codex / Claude と連携して、部品モデリング、アセンブリ、図面、板金、溶接、シミュレーション、ファイル エクスポート、カスタム プロパティ、設計テーブル、構成管理のために Windows 上で実行される SolidWorks を制御できます。ユーザーが SolidWorks、SW、OpenClaw、ロブスター、3D モデリング、CAD、部品、アセンブリ、図面、板金、溶接、STEP/STL/PDF のエクスポート、BOM、設計テーブル、FEA シミュレーションなどについて言及するときに使用されます。
