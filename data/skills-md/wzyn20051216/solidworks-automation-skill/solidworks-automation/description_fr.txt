Compétences en automatisation de CAO SolidWorks, capable de collaborer avec OpenClaw / Codex / Claude via l'interface Python COM pour contrôler SolidWorks fonctionnant sous Windows pour la modélisation de pièces, les assemblages, les dessins, la tôlerie, les constructions soudées, la simulation, l'exportation de fichiers, les propriétés personnalisées, les tables de conception et la gestion de la configuration ; utilisé lorsque l'utilisateur mentionne SolidWorks, SW, OpenClaw, lobster, la modélisation 3D, la CAO, les pièces, les assemblages, les dessins, la tôlerie, les constructions soudées, l'exportation STEP/STL/PDF, la nomenclature, les tables de conception ou la simulation FEA, etc.
