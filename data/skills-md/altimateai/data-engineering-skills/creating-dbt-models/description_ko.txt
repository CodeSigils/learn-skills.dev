프로젝트 규칙에 따라 dbt 모델을 생성합니다. 다음을 위해 dbt 모델 작업 시 사용합니다.
(1) 새 모델 생성(모든 레이어 - 프로젝트의 명명 규칙을 먼저 검색)
(2) 작업에서 모델, 테이블 또는 SQL을 사용하여 "만들기", "구축", "추가", "쓰기", "새로 만들기" 또는 "구현"을 언급합니다.
(3) 기존 모델 논리, 열, 조인 또는 변환 수정
(4) Schema.yml 사양 또는 예상 출력 요구 사항에서 모델 구현
작성하기 전에 프로젝트 규칙을 검색합니다. 확인을 위해 dbt 빌드(컴파일뿐만 아니라)를 실행합니다.
