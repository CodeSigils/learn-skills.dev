ينشئ نماذج dbt باتباع اصطلاحات المشروع. يُستخدم عند العمل مع نماذج dbt من أجل:
(1) إنشاء نماذج جديدة (أي طبقة - تكتشف اصطلاحات تسمية المشروع أولاً)
(2) تشير المهمة إلى "إنشاء" أو "إنشاء" أو "إضافة" أو "كتابة" أو "جديد" أو "تنفيذ" باستخدام نموذج أو جدول أو SQL
(3) تعديل منطق النموذج أو الأعمدة أو الصلات أو التحويلات الموجودة
(4) تنفيذ نموذج من مواصفات schema.yml أو متطلبات الإخراج المتوقعة
يكتشف اتفاقيات المشروع قبل الكتابة. يقوم بتشغيل dbt build (وليس فقط الترجمة) للتحقق.
