يحول SQL القديم إلى نماذج dbt المعيارية. يُستخدم عند ترحيل SQL إلى dbt من أجل:
(1) تحويل الإجراءات المخزنة أو طرق العرض أو ملفات SQL الأولية إلى نماذج dbt
(2) تشير المهمة إلى "الترحيل" أو "التحويل" أو "SQL القديمة" أو "التحويل إلى dbt" أو "التحديث"
(3) تقسيم الاستعلامات المتجانسة إلى طبقات معيارية (اكتشاف اصطلاحات المشروع أولاً)
(4) نقل خطوط أنابيب البيانات الموجودة أو ETL إلى أنماط dbt
التحقق من النماذج/المصادر الموجودة، وبناء والتحقق من صحتها طبقة تلو الأخرى.
