Referenz zur Container-Engine für Podman und Podman Compose. Rufen Sie diesen Skill auf, wenn Sie Dockerfiles, Containerfiles, docker-compose.yml, compose.yaml, Containerbefehle oder Makefile-Ziele schreiben, die Container erstellen/ausführen. Rufen Sie es auch auf, wenn der Benutzer Podman, Container oder Rootless-Container erwähnt oder von Docker migriert. Diese Fähigkeit stellt sicher, dass Befehle auf Podman (nicht auf Docker) abzielen, und behandelt Rootless-Fallstricke, Netzwerk- und Kompositionsunterschiede.
