Установите стек многочипового программного обеспечения из 5 пакетов (vLLM, FlagTree, FlagGems, FlagCX,
vllm-plugin-FL) внутри контейнера графического процессора. Обрабатывает обнаружение сетевого зеркала, зависимость
заказ, выбор колес и проверка каждой упаковки. Использовать после установки графического процессора-контейнера
создал работающий контейнер с доступом к PyTorch + GPU.
