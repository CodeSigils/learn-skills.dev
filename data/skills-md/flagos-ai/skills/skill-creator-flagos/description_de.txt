Erstellen Sie neue Fertigkeiten, ändern Sie vorhandene Fertigkeiten und validieren Sie die Fertigkeitsqualität für das FlagOS-Fähigkeiten-Repository. Verwenden Sie diesen Skill immer dann, wenn jemand einen Skill von Grund auf erstellen, einen vorhandenen Skill verbessern oder bearbeiten, ein neues Skill-Verzeichnis erstellen, die Skill-Struktur validieren oder Testfälle für einen Skill ausführen möchte. Wird ausgelöst, wenn der Benutzer Dinge sagt wie „eine Fertigkeit erstellen“, „eine neue Fertigkeit für X erstellen“, „eine Fertigkeit aufbauen“, „diese Fertigkeit verbessern“, „meine Fertigkeit validieren“ oder einfach „/skill-creator-flagos“. Wird auch ausgelöst, wenn Benutzer die Umwandlung eines Workflows in einen wiederverwendbaren Skill erwähnen oder einen wiederholten Prozess als Skill verpacken möchten.
