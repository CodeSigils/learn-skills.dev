Cree nuevas habilidades, modifique las existentes y valide la calidad de las habilidades para el repositorio de habilidades de FlagOS. Utilice esta habilidad siempre que alguien quiera crear una habilidad desde cero, mejorar o editar una habilidad existente, crear un nuevo directorio de habilidades, validar la estructura de habilidades o ejecutar casos de prueba en una habilidad. Se activa cuando el usuario dice cosas como "crear una habilidad", "crear una nueva habilidad para X", "desarrollar una habilidad", "mejorar esta habilidad", "validar mi habilidad" o simplemente "/skill-creator-flagos". También se activa cuando los usuarios mencionan convertir un flujo de trabajo en una habilidad reutilizable o quieren empaquetar un proceso repetido como una habilidad.
