Migrieren Sie ein Modell aus dem neuesten vLLM-Upstream-Repository in das vllm-plugin-FL-Projekt (angeheftet an vLLM v0.13.0). Verwenden Sie diesen Skill immer dann, wenn jemand vllm-plugin-FL Unterstützung für ein neues Modell hinzufügen, Modellcode von Upstream-vLLM portieren oder ein neu veröffentlichtes Modell zurückportieren möchte. Wird ausgelöst, wenn der Benutzer Dinge wie „X-Modell migrieren“, „X-Modell-Unterstützung hinzufügen“, „X von Upstream-vLLM portieren“, „X mit dem FL-Plugin funktionieren lassen“ oder einfach „/model-migrate-flagos Modellname“ sagt. Das Argument „model_name“ verwendet „snake_case“ (z. B. qwen3_5, kimi_k25, deepseek_v4). NICHT für Modelle verwenden, die bereits vom vLLM 0.13.0-Kern unterstützt werden, oder für ausschließlich multimodale Komponenten, die kein Backporting benötigen.
