Migrez un modèle du dernier référentiel vLLM en amont vers le projet vllm-plugin-FL (épinglé sur vLLM v0.13.0). Utilisez cette compétence chaque fois que quelqu'un souhaite ajouter la prise en charge d'un nouveau modèle à vllm-plugin-FL, porter le code du modèle à partir de vLLM en amont ou rétroporter un modèle nouvellement publié. Déclenchez lorsque l'utilisateur dit des choses comme "migrer le modèle X", "ajouter la prise en charge du modèle X", "porter X à partir du vLLM en amont", "faire fonctionner X avec le plugin FL" ou simplement "/model-migrate-flagos model_name". L'argument model_name utilise Snake_case (par exemple qwen3_5, kimi_k25, deepseek_v4). Ne PAS utiliser pour les modèles déjà pris en charge par le noyau vLLM 0.13.0, ni pour les composants multimodaux uniquement qui n'ont pas besoin de rétroportage.
