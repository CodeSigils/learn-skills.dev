Migre un modelo desde el repositorio ascendente de vLLM más reciente al proyecto vllm-plugin-FL (fijado en vLLM v0.13.0). Utilice esta habilidad siempre que alguien quiera agregar soporte para un nuevo modelo a vllm-plugin-FL, transferir el código del modelo desde vLLM ascendente o respaldar un modelo recién lanzado. Se activa cuando el usuario dice cosas como "migrar el modelo X", "agregar soporte para el modelo X", "puerto X desde vLLM ascendente", "hacer que X funcione con el complemento FL" o simplemente "/model-migrate-flagos model_name". El argumento model_name usa Snake_case (por ejemplo, qwen3_5, kimi_k25, deepseek_v4). NO lo use para modelos que ya son compatibles con el núcleo vLLM 0.13.0, ni para componentes solo multimodales que no necesitan compatibilidad.
