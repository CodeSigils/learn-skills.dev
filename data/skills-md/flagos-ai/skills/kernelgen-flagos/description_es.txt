Habilidad unificada de generación y optimización del operador del kernel de GPU. Detecta automáticamente el tipo de repositorio de destino (FlagGems, vLLM o Python/Triton general) y lo envía a la subhabilidad especializada adecuada. Incluye subhabilidades de generación de operadores, optimización iterativa basada en MCP y envío de comentarios. Utilice esta habilidad cuando el usuario quiera generar u optimizar un operador de kernel de GPU, crear un kernel de Triton o decir cosas como "generar un operador", "crear un kernel para X", "optimizar el kernel de Triton" o "/kernelgen-flagos".
