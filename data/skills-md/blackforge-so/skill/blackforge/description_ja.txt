BlackForge を使用して、暗号通貨市場データの質問に答えます。ユーザーがスポット会場でのコインのオーダーブックまたは取引データ、つまり取引所に関する最新の統計、オーダーブックの深さまたはペアの休止/プル流動性、テイカーの買いと売りの出来高、オーダーラダーの段、価格レベルの存続期間、取引タイミング、大規模な取引、または時価総額/注目の強化について尋ねるたびに、このスキルを使用します。時間範囲にわたってメトリクスを取得、グラフ化、または比較したい場合。または、会場がどのペアをリストしているかを尋ねたとき。 9 つのスポット取引所 (binance、bitget、bybit、coinbase、gate、kraken、kucoin、mexc、okx) と約 11,800 のスポット ペアをカバーします。閉じた 5 分間のウィンドウごとにペアごとに 120 の測定列があります。 BlackForge の名前がなくても、質問が会場の仮想通貨市場データに関する場合でもトリガーされます。 BlackForge MCP ツール (blackforge_catalog / blackforge_symbols / blackforge_latest / blackforge_series / blackforge_usage) または `blackforge` CLI を駆動します。 API を再実装することはありません。返されるすべての列は測定値であり、取引コールではありません。
