Интегрируйте Sumsub Mobile SDK (IdensicMobileSDK/SNSMobileSDK) в приложение iOS — даже если пользователь не называет SDK (например, «добавить Sumsub/KYC в мое приложение для iPhone», «показать экран проверки на iOS», «запустить Sumsub из контроллера представления»). Охватывает установку, разрешения, инициализацию, обновление токена, представление потока. SKIP для веб-сайтов (`sumsub-integrate-websdk`), подписывания токенов серверной части/только API (`sumsub-api-generic`), темирования (`sumsub-theme-msdk`) и отличных от iOS — Android/React Native/Futter (не поддерживается). только iOS.
