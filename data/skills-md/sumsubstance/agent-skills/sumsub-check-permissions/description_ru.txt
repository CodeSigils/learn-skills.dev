Получите разрешенные права текущего клиента (список BackgroundCheckTarget). Возвращает JSON с `разрешенными` (массив ключей разрешений) и `описаниями` (карта ключей → удобочитаемая метка). Вызывается sumsub-create-level (и другими навыками create-*) перед созданием полезных данных для доступа к функциям, необходимым для предоставления прав.
