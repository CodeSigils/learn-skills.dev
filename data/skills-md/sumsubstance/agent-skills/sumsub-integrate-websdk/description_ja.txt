Sumsub WebSDK を介して Web サイトまたは Web アプリに Sumsub KYC を追加するためのエンドツーエンドのレシピ。ユーザーが「Sumsubの統合/埋め込み/追加」、「KYCウィジェットの表示」、「WebSDKの追加」、「フロントエンドでSumsubを使用してユーザーを検証」を要求したとき、ページにプラグインしたい既存のlevelNameを指定したとき、または任意のプロジェクトでSumsub検証用のアクセストークン/ライフサイクルイベント/Webhookを接続する方法を尋ねたときにトリガーされます。レベルのセットアップ、サーバー側のアクセス トークンの署名、snsWebSdk の初期化 (バニラ標準、React レシピ)、クライアント ライフサイクル イベント、トークンの更新、Webhook と申請者の GET による信頼できる情報源、サンドボックス テスト、ゴーライブ チェックリストなど、ループ全体をカバーします。レベル/アンケート/POA プリセット ペイロード自体を構築する場合 (兄弟スキルを使用)、またはフロントエンドを使用しないバックエンドのみの API 呼び出しの場合 (`sumsub-api-generic` を使用) にはスキップします。
