ApplicantResource API를 통해 Sumsub Transaction Monitoring(KYT)에 거래를 제출하세요. 사용자가 "거래 제출/생성/전송/기록", "거래로 KYT 규칙 테스트", 모니터링을 위한 법정화폐 또는 암호화폐 지불 게시, 전송에 여행 규칙 데이터 첨부, 모니터링을 위한 사용자 플랫폼 이벤트(가입/로그인/비밀번호 재설정/2FA 재설정)를 기록하거나 아직 존재하지 않는 신청자에 대한 거래 제출(요청에 의해 생성됨)을 요청할 때 TRIGGER. 기존 거래의 임의 필드 편집, 대량 가져오기(`/kyt/misc/txns/import`), 거래 가져오기/승인/거부, KYT 규칙 관리 또는 거래 생성이 아닌 여행 규칙 데이터 교환 흐름의 경우 건너뛰세요.
