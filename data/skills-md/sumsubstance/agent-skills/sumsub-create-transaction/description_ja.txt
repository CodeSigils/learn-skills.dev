ApplicantResource API を介して Sumsub Transaction Monitoring (KYT) にトランザクションを送信します。ユーザーが「トランザクションの送信 / 作成 / 送信 / 記録」、「トランザクションで KYT ルールのテスト」、モニタリングのための法定通貨または暗号通貨の支払いの投稿、送金へのトラベル ルール データの添付、モニタリングのためのユーザー プラットフォーム イベント (サインアップ / ログイン / パスワード リセット / 2FA リセット) の記録、またはまだ存在しない申請者のトランザクションの送信 (リクエストによって作成される) を要求したときにトリガーされます。 SKIP は、既存のトランザクションの任意のフィールドの編集、一括インポート (`/kyt/misc/txns/import`)、トランザクションの取得/承認/拒否、KYT ルール管理、またはトランザクション作成ではないトラベル ルールのデータ交換フローに使用します。
