أرسل معاملة إلى Sumsub Transaction Monitoring (KYT) عبر ApplicantResource API. يتم تشغيله عندما يطلب المستخدم "إرسال/إنشاء/إرسال/تسجيل معاملة"، أو "اختبار قاعدة KYT بمعاملة"، أو نشر دفعة ورقية أو مشفرة للمراقبة، أو إرفاق بيانات قاعدة السفر بعملية نقل، أو تسجيل حدث منصة المستخدم (الاشتراك / تسجيل الدخول / إعادة تعيين كلمة المرور / إعادة تعيين 2FA) للمراقبة، أو إرسال معاملة لمقدم طلب غير موجود بعد (الطلب ينشئها). تخطي لتحرير الحقول العشوائية في معاملة موجودة، أو للاستيراد المجمع (`/kyt/misc/txns/import`)، أو لجلب/الموافقة/رفض المعاملات، أو لإدارة قواعد KYT، أو لتدفقات تبادل بيانات قاعدة السفر التي لا تمثل إنشاء معاملات.
