Senden Sie eine Transaktion über die ApplicantResource-API an Sumsub Transaction Monitoring (KYT). TRIGGER, wenn der Benutzer auffordert, „eine Transaktion einzureichen/erstellen/senden/aufzeichnen“, „eine KYT-Regel mit einer Transaktion zu testen“, eine Fiat- oder Krypto-Zahlung zur Überwachung zu buchen, Reiseregeldaten an eine Überweisung anzuhängen, ein Benutzerplattformereignis (Anmeldung/Anmeldung/Passwort-Zurücksetzung/2FA-Zurücksetzung) zur Überwachung zu protokollieren oder eine Transaktion für einen Antragsteller einzureichen, der noch nicht existiert (die Anfrage erstellt sie). SKIP zum Bearbeiten beliebiger Felder einer vorhandenen Transaktion, zum Massenimport („/kyt/misc/txns/import“), zum Abrufen/Genehmigen/Ablehnen von Transaktionen, zur KYT-Regelverwaltung oder für Reiseregel-Datenaustauschflüsse, bei denen es sich nicht um die Erstellung von Transaktionen handelt.
