Créez un workflow de candidature Sumsub via l'API publique ApplyWorkflow (App Token auth). DÉCLENCHEMENT lorsque l'utilisateur demande de « créer/construire/ajouter un workflow Sumsub », fournit une description de style organigramme du routage de vérification (niveaux + branches + actions), souhaite câbler le routage basé sur le pays / le routage par âge / la logique de nouvelle tentative, demande de configurer des étapes de rejet final ou de révision manuelle dans un flux, ou souhaite modéliser un flux de travail d'action (automatisations post-vérification comme le marquage, les notes, les modifications de clé source). Couvre également la publication de la révision résultante (`/revisionStatus`). SKIP pour modifier des champs arbitraires d'une révision de flux de travail existante, ou pour les flux de configuration de produit plus larges (questionnaires, niveaux — des compétences distinctes les couvrent).
