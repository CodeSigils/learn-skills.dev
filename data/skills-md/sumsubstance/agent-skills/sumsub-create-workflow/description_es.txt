Cree un flujo de trabajo de solicitante de Sumsub a través de la API pública ApplicantWorkflow (autenticación de token de aplicación). DISPARAR cuando el usuario solicita "crear/construir/agregar un flujo de trabajo de Sumsub", proporciona una descripción estilo diagrama de flujo del enrutamiento de verificación (niveles + ramas + acciones), quiere conectar el enrutamiento basado en país/enrutamiento por edad/lógica de reintento, solicita configurar pasos de rechazo final o revisión manual en un flujo, o quiere modelar un flujo de trabajo de acción (automatizaciones posteriores a la verificación como etiquetado, notas, cambios de clave de origen). También cubre la publicación de la revisión resultante (`/revisionStatus`). SALTAR para editar campos arbitrarios de una revisión de flujo de trabajo existente, o para flujos de configuración de productos más amplios (cuestionarios, niveles; habilidades separadas los cubren).
