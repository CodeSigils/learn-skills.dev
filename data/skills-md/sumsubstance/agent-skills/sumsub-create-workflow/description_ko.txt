공개 ApplicantWorkflow API(앱 토큰 인증)를 통해 Sumsub 신청자 워크플로를 만듭니다. 사용자가 "Sumsub 워크플로 생성/구축/추가"를 요청하거나, 확인 라우팅(레벨 + 분기 + 작업)에 대한 플로차트 스타일 설명을 제공하거나, 국가 기반 라우팅/연령 라우팅/재시도 논리를 연결하려고 하거나, 흐름에서 최종 거부 또는 수동 검토 단계를 설정하도록 요청하거나, 작업 워크플로(태그 지정, 메모, 소스 키 변경과 같은 검증 후 자동화)를 모델링하려는 경우 TRIGGER입니다. 또한 결과 개정(`/revisionStatus`) 게시에 대해서도 다룹니다. 기존 워크플로우 개정의 임의 필드를 편집하거나 더 광범위한 제품 구성 흐름(설문지, 레벨 - 별도의 기술이 이를 포함)을 편집하려면 건너뛰십시오.
