قم بإنشاء سير عمل مقدم الطلب Sumsub عبر واجهة برمجة تطبيقات ApplicantWorkflow العامة (مصادقة رمز التطبيق). تشغيل عندما يطلب المستخدم "إنشاء/إنشاء/إضافة سير عمل Sumsub"، أو تقديم وصف على نمط مخطط انسيابي لتوجيه التحقق (المستويات + الفروع + الإجراءات)، أو يريد توصيل التوجيه المستند إلى البلد/توجيه العمر/منطق إعادة المحاولة، أو يطلب إعداد خطوات الرفض النهائي أو المراجعة اليدوية في التدفق، أو يريد تصميم نموذج لسير عمل (عمليات ما بعد التحقق مثل وضع العلامات والملاحظات وتغييرات مفتاح المصدر). يغطي أيضًا نشر المراجعة الناتجة (`/revisionStatus`). تخطي لتحرير الحقول العشوائية لمراجعة سير العمل الحالية، أو لتدفقات تكوين المنتج الأوسع (الاستبيانات والمستويات - تغطي المهارات المنفصلة تلك).
