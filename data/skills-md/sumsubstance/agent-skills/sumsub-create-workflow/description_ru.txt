Создайте рабочий процесс заявителя Sumsub с помощью общедоступного API ApplicantWorkflow (авторизация по токену приложения). TRIGGER, когда пользователь запрашивает «создать / построить / добавить рабочий процесс Sumsub», предоставляет описание маршрутизации проверки в виде блок-схемы (уровни + ветви + действия), хочет подключить логику маршрутизации на основе страны / возрастной маршрутизации / повторной попытки, просит настроить этапы окончательного отклонения или ручного просмотра в потоке или хочет смоделировать рабочий процесс действий (автоматизация после проверки, такая как тегирование, примечания, изменения исходного ключа). Также охватывает публикацию полученной версии (`/revisionStatus`). SKIP для редактирования произвольных полей существующей версии рабочего процесса или для более широких потоков настройки продукта (анкеты, уровни — их охватывают отдельные навыки).
