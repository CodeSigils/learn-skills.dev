Crea un flusso di lavoro del richiedente Sumsub tramite l'API pubblica ApplicantWorkflow (autenticazione Token App). ATTIVA quando l'utente chiede di "creare/costruire/aggiungere un flusso di lavoro Sumsub", fornisce una descrizione in stile diagramma di flusso del routing di verifica (livelli + rami + azioni), desidera collegare il routing basato sul paese / routing sull'età / logica di nuovo tentativo, chiede di impostare passaggi di rifiuto finale o di revisione manuale in un flusso o desidera modellare un flusso di lavoro di azioni (automazioni post-verifica come tag, note, modifiche della chiave di origine). Copre anche la pubblicazione della revisione risultante (`/revisionStatus`). SKIP per modificare campi arbitrari di una revisione del flusso di lavoro esistente o per flussi di configurazione del prodotto più ampi (questionari, livelli: competenze separate li coprono).
