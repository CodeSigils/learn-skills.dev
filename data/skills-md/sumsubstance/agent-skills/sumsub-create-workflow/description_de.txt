Erstellen Sie einen Sumsub-Bewerberworkflow über die öffentliche ApplicantWorkflow API (App Token Auth). TRIGGER, wenn der Benutzer „einen Sumsub-Workflow erstellen/erstellen/hinzufügen“ auffordert, eine Beschreibung des Verifizierungsroutings im Flussdiagrammstil (Ebenen + Zweige + Aktionen) bereitstellt, länderbasiertes Routing/Altersrouting/Logik für erneute Versuche verknüpfen möchte, Schritte zur endgültigen Ablehnung oder manuellen Überprüfung in einem Flow einrichten möchte oder einen Aktionsworkflow modellieren möchte (Automatisierungen nach der Verifizierung wie Tagging, Notizen, Quellschlüsseländerungen). Behandelt auch die Veröffentlichung der resultierenden Revision („/revisionStatus“). SKIP zum Bearbeiten beliebiger Felder einer vorhandenen Workflow-Revision oder für die umfassenderen Produktkonfigurationsabläufe (Fragebögen, Ebenen – diese werden von separaten Fertigkeiten abgedeckt).
