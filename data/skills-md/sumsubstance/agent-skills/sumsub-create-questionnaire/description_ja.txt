Sumsub KYC アンケート定義を作成または更新します。 `/resources/api/questionnaires` を POST して新規作成し (ID が存在する場合は 409 で失敗)、同じパスを PATCH して更新する (ID が不明な場合は 404 で失敗)、GET `/resources/api/questionnaires/{id}` を実行して 1 つ読み戻します。ユーザーが「Sumsub アンケートの作成 / 追加 / 構築 / 更新 / 編集」を要求したとき、または Sumsub 応募者フロー向けの質問のリスト / セクションを提供したとき、または POST または PATCH されるアンケート ID / 定義を参照したときにトリガーします。他の Sumsub エンティティ (レベル、ワークフロー、応募者)、アンケート データ (回答) 送信、または非 Sumsub フォーム ビルダーの場合はスキップします。
