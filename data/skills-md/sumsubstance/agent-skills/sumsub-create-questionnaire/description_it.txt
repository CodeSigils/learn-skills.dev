Creare o aggiornare la definizione del questionario Sumsub KYC. POST `/resources/api/questionnaires` per crearne uno nuovo (fallisce 409 se l'id esiste), PATCH stesso percorso per aggiornare (fallisce 404 se l'id è sconosciuto), GET `/resources/api/questionnaires/{id}` per rileggerne uno. TRIGGER quando l'utente chiede di "creare/aggiungere/costruire/aggiornare/modificare un questionario Sumsub" o fornisce un elenco di domande/sezioni destinate a un flusso di richiedente Sumsub o fa riferimento a un ID/definizione di questionario da pubblicare o applicare con PATCH. SALTA per altre entità Sumsub (livelli, flussi di lavoro, candidati), invio di dati di questionari (risposte) o generatori di moduli non Sumsub.
