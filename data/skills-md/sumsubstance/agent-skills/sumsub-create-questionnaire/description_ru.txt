Создайте или обновите определение анкеты Sumsub KYC. POST `/resources/api/questionnaires` для создания нового (ошибка 409, если идентификатор существует), PATCH тот же путь для обновления (ошибка 404, если идентификатор неизвестен), GET `/resources/api/questionnaires/{id}`, чтобы прочитать его обратно. ТРИГГЕР, когда пользователь просит «создать/добавить/создать/обновить/редактировать анкету Sumsub» или предоставляет список вопросов/разделов, предназначенных для потока кандидатов Sumsub, или ссылается на идентификатор/определение анкеты для публикации или исправления. ПРОПУСТИТЕ для других объектов Sumsub (уровни, рабочие процессы, кандидаты), отправки данных анкеты (ответов) или конструкторов форм, не принадлежащих Sumsub.
