Cree o actualice un ajuste preestablecido de prueba de dirección (POA) de Sumsub. POST `/resources/api/poaStepSettings` para crear un nuevo, PATCH la misma ruta para actualizar (id en el cuerpo), GET `/resources/api/poaStepSettings/{id}` para volver a leer uno. DISPARAR cuando el usuario solicita "crear / agregar / construir / configurar / actualizar / editar un ajuste preestablecido de POA" o "configuraciones de pasos de PoA", configurar qué tipos de documentos de prueba de dirección se aceptan (facturas de servicios públicos, extractos bancarios, facturas de impuestos, etc.), establecer períodos de validez por tipo de proveedor, habilitar POI como POA (aceptar documento de identidad como prueba de dirección), ajustar el validador cruzado (coincidencia aproximada de nombre/dirección entre POI y POA), o agregar POA por país anula. SALTAR para adjuntar un ajuste preestablecido a un nivel (establezca `poaStepSettingsId` en el nivel, a través de `sumsub-create-level`), o para ajustes preestablecidos que no sean POA (ajustes preestablecidos de verificación cruzada, ajustes preestablecidos de permisos, etc.).
