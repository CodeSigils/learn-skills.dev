Crea o aggiorna una preimpostazione Proof-of-Address (POA) Sumsub. POST `/resources/api/poaStepSettings` per crearne uno nuovo, PATCH stesso percorso da aggiornare (id nel corpo), GET `/resources/api/poaStepSettings/{id}` per rileggerne uno. SI ATTIVA quando l'utente chiede di "creare/aggiungere/costruire/configurare/aggiornare/modificare una preimpostazione POA" o "impostazioni passaggio PoA", configurare quali tipi di documenti di prova dell'indirizzo sono accettati (bollette, estratti conto bancari, fatture fiscali, ecc.), impostare periodi di validità per tipo di fornitore, abilitare POI-as-POA (accettare documento di identità come prova di indirizzo), ottimizzare il validatore incrociato (corrispondenza fuzzy nome/indirizzo tra POI e POA) o aggiungere POA per paese sovrascrive. SKIP per collegare una preimpostazione a un livello (imposta invece `poaStepSettingsId` sul livello, tramite `sumsub-create-level`) o per preimpostazioni non POA (preimpostazioni di controllo incrociato, preimpostazioni di autorizzazione, ecc.).
