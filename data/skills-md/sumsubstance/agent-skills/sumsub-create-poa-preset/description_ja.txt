Sumsub Proof-of-Address (POA) プリセットを作成または更新します。新しいパスを作成するには POST `/resources/api/poaStepSettings` を、更新するには同じパス (本文の ID) を PATCH し、再度読み取るには GET `/resources/api/poaStepSettings/{id}` を実行します。ユーザーが「POA プリセットの作成 / 追加 / 構築 / 構成 / 更新 / 編集」または「PoA ステップ設定」を要求したときにトリガーします。受け入れられる住所証明文書の種類 (公共料金請求書、銀行取引明細書、税金請求書など) を構成し、プロバイダー タイプごとに有効期間を設定し、POI-as-POA を有効化 (ID 文書を住所証明として受け入れます)、相互検証ツールの調整 (POI と住所間の名前/住所のあいまい一致) POA)、または国ごとの POA オーバーライドを追加します。レベルにプリセットをアタッチする場合 (代わりに、「sumsub-create-level」を介してレベルに「poaStepSettingsId」を設定する)、または非 POA プリセット (クロスチェック プリセット、権限プリセットなど) の場合は SKIP。
