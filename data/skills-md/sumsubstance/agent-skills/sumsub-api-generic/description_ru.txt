Универсальный запасной вариант для любой задачи Sumsub API, которая НЕ соответствует более конкретному навыку (например, `create-sumsub-level`, `sumsub-create-questionnaire`, `sumsub-api-auth`). ТРИГГЕР, когда пользователь хочет вызвать, проверить или отладить конечную точку API Sumsub, не охваченную иным образом — выборка кандидатов, уровни листинга, проверка попаданий AML, экспорт данных, генерация токенов SDK и все, что связано с `api.sumsub.com`. Процедура — найдите нужную конечную точку в схеме OpenAPI, прочитайте ее форму запроса/ответа, создайте полезную нагрузку, подпишите с помощью токена приложения и подтвердите. ПРОПУСКАЙТЕ всякий раз, когда более узкий навык Sumsub уже охватывает запрос.
