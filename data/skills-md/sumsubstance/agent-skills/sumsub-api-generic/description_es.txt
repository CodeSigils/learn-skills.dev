Reserva general para cualquier tarea de la API de Sumsub que NO coincida con una habilidad más específica (por ejemplo, `create-sumsub-level`, `sumsub-create-questionnaire`, `sumsub-api-auth`). DISPARAR cuando el usuario quiere llamar, inspeccionar o depurar un punto final de la API de Sumsub que no está cubierto de otra manera: buscar solicitantes, enumerar niveles, revisar visitas AML, exportar datos, generar tokens SDK, cualquier cosa en contra de `api.sumsub.com`. El procedimiento: ubicar el punto final correcto en el esquema OpenAPI, leer su forma de solicitud/respuesta, crear la carga útil, firmar con App Token y validar. SALTE cuando una habilidad de Sumsub más limitada ya cubra la solicitud.
