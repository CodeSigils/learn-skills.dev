より具体的なスキルに一致しない Sumsub API タスクのキャッチオール フォールバック (例: 「create-sumsub-level」、「sumsub-create-questionnaire」、「sumsub-api-auth」)。ユーザーが、他ではカバーされていない Sumsub API エンドポイントの呼び出し、検査、デバッグを行う場合 (申請者の取得、レベルのリスト表示、AML ヒットの確認、データのエクスポート、SDK トークンの生成など、「api.sumsub.com」に対するあらゆる処理) を行う場合にトリガーします。この手順では、OpenAPI スキーマで適切なエンドポイントを見つけ、そのリクエスト/レスポンスの形状を読み取り、ペイロードを構築し、App Token で署名し、検証します。より狭い Sumsub スキルがすでにリクエストをカバーしている場合はスキップします。
