أضف Sumsub Device Intelligence (وحدة Fisherman JS) إلى صفحات الويب الخاصة بك حيث لا توجد أداة التحقق من Sumsub - تسجيل الدخول أو الاشتراك أو إعادة تعيين كلمة المرور أو المصادقة الثنائية أو الخروج أو أي إجراء عالي القيمة تريد فحصه للاحتيال. يتم تشغيله عندما يطلب المستخدم "إضافة معلومات الجهاز لتسجيل الدخول/التسجيل"، أو "أخذ بصمة الجهاز على صفحة مخصصة"، أو "استخدام Fisherman المستقل/المستضاف ذاتيًا"، أو "المراقبة المستمرة لأحداث النظام الأساسي"، أو "فحص الجهاز قبل KYC"، أو "اكتشاف الحسابات المتعددة عند التسجيل"، أو "إرسال معاملة مالية باستخدام الجهاز الذي تم التقاطه". يغطي الحلقة بأكملها - رمز الوصول إلى السلوك، @sumsub/fisherman init + بصمة الإصبع، تأكيد الحدث (حدث النظام الأساسي / المعاملة المالية / إنشاء مقدم الطلب)، وقراءة النتائج، ووضع الحماية، والبدء المباشر. تخطي عندما تتضمن الصفحة بالفعل Sumsub WebSDK - تتنقل ذكاء الجهاز داخلها، استخدم `sumsub-integrate-dint-websdk`.
