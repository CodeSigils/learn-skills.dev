Authentifiez-vous auprès de l'API Sumsub avec un App Token + une clé secrète (signature de demande HMAC-SHA256). DÉCLENCHEMENT lorsque l'utilisateur demande « d'appeler/signer/authentifier les requêtes API Sumsub », débogue les erreurs « 401 Unauthorized »/signature par rapport à « api.sumsub.com », ou a besoin d'un exemple de requête de travail avec les en-têtes « X-App-Token » / « X-App-Access-Sig » / « X-App-Access-Ts ». SAUTER uniquement lorsqu'une compétence plus spécifique dans ce référentiel (questionnaire/niveau/workflow/POA-preset/générique) couvre déjà la tâche réelle de l'utilisateur - ces compétences signent les demandes de la même manière et n'ont besoin que de celle-ci pour des analyses approfondies d'authentification.
