Authentifizieren Sie sich bei der Sumsub-API mit einem App-Token + geheimem Schlüssel (HMAC-SHA256-Anforderungssignierung). TRIGGER, wenn der Benutzer „Sumsub-API-Anfragen aufrufen/signieren/authentifizieren“ auffordert, „401 Unauthorized“/Signaturfehler bei „api.sumsub.com“ debuggt oder ein funktionierendes Anforderungsbeispiel mit „X-App-Token“/„X-App-Access-Sig“/„X-App-Access-Ts“-Headern benötigt. ÜBERSPRINGEN Sie nur, wenn eine spezifischere Fertigkeit in diesem Repo (Fragebogen/Level/Workflow/POA-Voreinstellung/allgemein) bereits die eigentliche Aufgabe des Benutzers abdeckt – diese Fertigkeiten signieren Anfragen auf die gleiche Weise und benötigen diese nur für Auth-Tieftauchgänge.
