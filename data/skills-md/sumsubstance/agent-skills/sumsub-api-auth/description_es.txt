Autentíquese en la API de Sumsub con un token de aplicación + clave secreta (firma de solicitud HMAC-SHA256). DISPARADOR cuando el usuario solicita "llamar/firmar/autenticar solicitudes de API de Sumsub", depura errores `401 no autorizados`/firma contra `api.sumsub.com`, o necesita un ejemplo de solicitud funcional con los encabezados `X-App-Token`/`X-App-Access-Sig`/`X-App-Access-Ts`. SALTAR solo cuando una habilidad más específica en este repositorio (cuestionario/nivel/flujo de trabajo/POA-preset/genérico) ya cubra la tarea real del usuario; esas habilidades firman solicitudes de la misma manera y solo necesitan esta para profundizaciones de autenticación.
