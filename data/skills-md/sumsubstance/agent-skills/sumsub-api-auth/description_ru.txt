Выполните аутентификацию в API Sumsub с помощью токена приложения + секретного ключа (подпись запроса HMAC-SHA256). TRIGGER, когда пользователь запрашивает «вызов/подпись/аутентификацию запросов Sumsub API», отлаживает `401 Unauthorized`/ошибки подписи для `api.sumsub.com` или нуждается в примере рабочего запроса с `X-App-Token` / `X-App-Access-Sig` / `X-App-Access-Ts` заголовками. ПРОПУСКАЙТЕ только тогда, когда более конкретный навык в этом репозитории (опросник/уровень/рабочий процесс/предустановка POA/общий) уже охватывает реальную задачу пользователя — эти навыки подписывают запросы одинаково, и этот навык нужен только для более глубоких погружений в аутентификацию.
