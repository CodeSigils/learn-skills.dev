وصفة شاملة لدمج Sumsub ID Connect - تدفق "التحقق باستخدام معرف Sumsub" المستند إلى OIDC والذي يتيح للمستخدم مشاركة مطالبات الهوية التي تم التحقق منها مسبقًا مع تطبيقك. تشغيل عندما يطلب المستخدم "دمج اتصال معرف Sumsub"، أو "إضافة زر التحقق باستخدام معرف Sumsub"، أو "إعادة استخدام Sumsub KYC عبر OIDC"، أو "تبادل رمز ترخيص Sumsub"، أو "إصدار رمز مميز لمشاركة معرف Sumsub"، أو يسأل عن كيفية توصيل `@sumsub/id-connect`، أو تبادل OIDC `code → Access_token`. (`/api/snsId/oauth/token`)، أو تدفق رمز المشاركة/موافقة الشريك، أو إعادة توجيه رابط المشاركة. يغطي قائمة التحقق من الشروط المسبقة، والاختبار المبدئي التلقائي، وزر الواجهة الأمامية (زر المكتبة + بديل إعادة التوجيه الأولي)، وتبادل رمز الواجهة الخلفية للرمز المميز، وسك الرمز المميز للمشاركة، وتدفق ShareLink بموافقة الشريك، وتجسيد مقدم الطلب من خلال `/resources/api/reusableIdentity/reuse`. انتقل إلى عنصر واجهة المستخدم WebSDK / KYC المستقل (استخدم `sumsub-integrate-websdk`)، أو إلى Reusable-KYC-via-API العادي حيث يكون كل من المتبرع والمستلم مستأجرين لديك دون خطوة OIDC بوساطة المستخدم.
