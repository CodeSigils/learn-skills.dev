تأكد من أن حزمة مهارات وكيل Sumsub المثبتة محليًا متوافقة مع الإصدار المنشور قبل القيام بأي عمل لـ Sumsub. تشغيل في بداية أي مهمة تتعلق بـ Sumsub - أدوات Sumsub Dev MCP (mcp__Sumsub_Dev__*)، أو سير عمل KYC/AML، أو المتقدمين، أو الشيكات، أو المعاملات، أو مستويات التحقق، أو روابط التحقق، أو الاستبيانات، أو شبكة الاحتيال، أو قوائم VASP، أو أي شيء متعلق بـ Sumsub - لذلك يتم تحذير المستخدم قبل أن تؤدي حزمة المهارات القديمة إلى نتائج خاطئة. استخدم هذه المهارة أيضًا عندما يسأل المستخدم صراحةً "هل مهارات Sumsub الخاصة بي محدثة / حالية"، أو "هل هناك إصدار أحدث من مهارات Sumsub"، أو ما شابه ذلك. تخطي التحديث الفعلي (يقوم المستخدم بتشغيل مهارات npx وإضافة SumSubstance/agent-skills --all` بأنفسهم) وتخطي أي مهمة Sumsub API أو مهمة كيان أخرى - فهؤلاء لديهم مهاراتهم الخاصة.
