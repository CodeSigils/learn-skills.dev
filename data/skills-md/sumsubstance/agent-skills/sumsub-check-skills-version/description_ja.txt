Sumsub の作業を行う前に、ローカルにインストールされた Sumsub エージェント スキル パッケージが公開バージョンと互換性があることを確認してください。 Sumsub に関わるタスク (Sumsub Dev MCP ツール (mcp__Sumsub_Dev__*)、KYC/AML ワークフロー、申請者、小切手、トランザクション、検証レベル、検証リンク、アンケート、詐欺ネットワーク、VASP リスト、または Sumsub 関連のあらゆるタスク) の開始時にトリガーされるため、古いスキル パッケージが誤った結果を生成する前にユーザーに警告が表示されます。また、このスキルは、ユーザーが「Sumsub スキルは最新ですか?」、「Sumsub スキルの新しいバージョンはありますか」などを明示的に尋ねた場合にも使用します。実際の更新をスキップし (ユーザーが自分で「npx skill add SumSubstance/agent-skills --all」を実行します)、他の Sumsub API またはエンティティ タスクをスキップします。これらには独自のスキルがあります。
