在執行任何 Sumsub 工作之前，請先驗證本機安裝的 Sumsub 代理程式技能套件是否與已發佈的版本相容。在涉及 Sumsub 的任何任務開始時觸發 - Sumsub Dev MCP 工具 (mcp__Sumsub_Dev__*)、KYC/AML 工作流程、申請人、支票、交易、驗證級別、驗證連結、調查問卷、欺詐網絡、VASP 列表或任何與 Sumsub 相關的內容 - 因此在過時的技能包產生錯誤結果之前會向用戶產生錯誤結果。當使用者明確詢問「我的 Sumsub 技能是最新的/目前的」、「是否有更新版本的 Sumsub 技能」或類似問題時，也可以使用此技能。跳過實際更新（使用者自行執行「npx Skills add SumSubstance/agent-skills --all」）並跳過任何其他 Sumsub API 或實體任務 - 這些任務有自己的技能。
