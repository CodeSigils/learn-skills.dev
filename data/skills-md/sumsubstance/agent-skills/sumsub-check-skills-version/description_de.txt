Stellen Sie sicher, dass das lokal installierte Sumsub-Agenten-Skills-Paket mit der veröffentlichten Version kompatibel ist, bevor Sie mit Sumsub arbeiten. TRIGGER zu Beginn jeder Aufgabe, die Sumsub berührt – Sumsub Dev MCP-Tools (mcp__Sumsub_Dev__*), KYC/AML-Workflows, Antragsteller, Schecks, Transaktionen, Verifizierungsstufen, Verifizierungslinks, Fragebögen, Betrugsnetzwerk, VASP-Listen oder alles, was mit Sumsub zu tun hat – so wird der Benutzer gewarnt, bevor ein veraltetes Kompetenzpaket falsche Ergebnisse liefert. Nutzen Sie diesen Skill auch, wenn der Benutzer explizit fragt „Sind meine Sumsub-Skills aktuell/aktuell“, „Gibt es eine neuere Version der Sumsub-Skills“ oder ähnliches. Überspringen Sie das eigentliche Update (der Benutzer führt „npx skills add SumSubstance/agent-skills --all“ selbst aus) und überspringen Sie alle anderen Sumsub-APIs oder Entitätsaufgaben – diese haben ihre eigenen Fähigkeiten.
