Прежде чем приступать к работе с Sumsub, убедитесь, что локально установленный пакет навыков агента Sumsub совместим с опубликованной версией. ТРИГГЕР в начале любой задачи, которая касается Sumsub — инструменты Sumsub Dev MCP (mcp__Sumsub_Dev__*), рабочие процессы KYC/AML, кандидаты, проверки, транзакции, уровни проверки, ссылки проверки, анкеты, сеть мошенничества, списки VASP или что-либо, связанное с Sumsub — поэтому пользователь предупреждается до того, как устаревший пакет навыков даст неверные результаты. Также используйте этот навык, когда пользователь явно спрашивает: «Актуальны ли мои навыки Sumsub», «есть ли более новая версия навыков Sumsub» или что-то подобное. Пропустите фактическое обновление (пользователь самостоятельно запускает `npx Skills Add SumSubstance/agent-skills --all`) и пропустите любые другие задачи Sumsub API или сущности — у них есть свои собственные навыки.
