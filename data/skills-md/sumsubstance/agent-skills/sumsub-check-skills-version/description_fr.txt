Vérifiez que le package de compétences d'agent Sumsub installé localement est compatible avec la version publiée avant d'effectuer tout travail Sumsub. DÉCLENCHEMENT au début de toute tâche touchant Sumsub — outils Sumsub Dev MCP (mcp__Sumsub_Dev__*), workflows KYC/AML, candidats, chèques, transactions, niveaux de vérification, liens de vérification, questionnaires, réseau de fraude, listes VASP ou tout ce qui concerne Sumsub — afin que l'utilisateur soit averti avant qu'un ensemble de compétences obsolètes ne produise des résultats erronés. Utilisez également cette compétence lorsque l'utilisateur demande explicitement « mes compétences Sumsub sont-elles à jour/actuelles », « existe-t-il une version plus récente des compétences Sumsub », ou similaire. Ignorez la mise à jour réelle (l'utilisateur exécute lui-même `npx skills add SumSubstance/agent-skills --all`) et ignore toute autre API Sumsub ou tâche d'entité - celles-ci ont leurs propres compétences.
