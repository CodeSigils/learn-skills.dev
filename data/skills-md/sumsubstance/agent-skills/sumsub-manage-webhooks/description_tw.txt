透過 `/resources/clientWebhooks` 管理 Sumsub `clientWebhooks`（applicantReviewed/applicantPending/kytTxn/等的事件訂閱）。 **僅限沙箱** — 生產 Webhook 必須由人員直接在 Sumsub 儀表板中建立。當使用者要求針對其沙箱租用戶「列出/檢索/顯示 Webhook」、「建立/新增/註冊 Webhook」、「更新/編輯/更改 Webhook 目標/事件清單/秘密/簽名演算法」或「停用/重新啟用 Webhook」時觸發。跳過生產 Webhook 設定（將使用者開機至儀表板）、無關的 Webhook 表面（在 `/resources/webhooks/...` 下的 Stripe / videoIdent / Fireblocks / NFC / 合作夥伴特定接收路徑）、測試僅一次性交付（直接使用 `inspectionCallbacks/testpectionCallbacks部分中管理）。公共 API 不會公開刪除或每個 Webhook 交付統計信息 - 對於這些統計信息，請讓使用者參考 Sumsub 儀表板 UI。
