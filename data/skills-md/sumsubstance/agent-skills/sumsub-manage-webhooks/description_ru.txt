Управляйте Sumsub `clientWebhooks` (подписками на события для заявителяReviewed/claimPending/kytTxn/и т. д.) через `/resources/clientWebhooks`. **Только для песочницы** — рабочие вебхуки должны создаваться человеком непосредственно в панели управления Sumsub. ТРИГГЕР, когда пользователь запрашивает «составить список / получить / показать веб-перехватчики», «создать / добавить / зарегистрировать веб-перехватчик», «обновить / отредактировать / изменить цель веб-перехватчика / список событий / секретный алгоритм / алгоритм подписи» или «отключить / повторно включить веб-перехватчик» для своего клиента песочницы. SKIP для настройки производственного веб-перехватчика (направьте пользователя на панель управления), для несвязанных поверхностей веб-перехватчика (Stripe / videoIdent / Fireblocks / NFC / пути получения для конкретного партнера в каталоге `/resources/webhooks/...`), для тестирования однократной доставки (используйте конечную точку `inspectionCallbacks/testWebhook` напрямую) и для маршрутизации веб-перехватчика только для KYT (управляется в KYT на панели управления Sumsub). раздел). Публичный API не предоставляет статистику удалений или доставки по каждому веб-хуку — для этого отправьте пользователя в пользовательский интерфейс панели управления Sumsub.
