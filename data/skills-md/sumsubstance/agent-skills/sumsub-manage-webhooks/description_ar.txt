إدارة Sumsub `clientWebhooks` (اشتراكات الأحداث لمقدم الطلب/مقدم الطلبPending / kytTxn / وما إلى ذلك) عبر `/resources/clientWebhooks`. **وضع الحماية فقط** — يجب إنشاء خطافات الويب الخاصة بالإنتاج بواسطة الإنسان مباشرة في لوحة معلومات Sumsub. يتم تشغيله عندما يطلب المستخدم "سرد/استرداد/إظهار خطافات الويب"، أو "إنشاء/إضافة/تسجيل خطاف ويب"، أو "تحديث/تحرير/تغيير هدف خطاف الويب/قائمة الأحداث/خوارزمية السر/التوقيع"، أو "تعطيل/إعادة تمكين خطاف الويب" ضد مستأجر وضع الحماية الخاص به. تخطي لإعداد خطاف الويب للإنتاج (إحالة المستخدم إلى لوحة المعلومات)، لأسطح خطاف الويب غير ذات الصلة (Stripe / videoIdent / Fireblocks / NFC / مسارات الاستلام الخاصة بالشريك ضمن `/resources/webhooks/...`)، لاختبار التسليم لمرة واحدة (استخدم نقطة نهاية `inspectionCallbacks/testWebhook` مباشرة)، ولتوجيه خطاف الويب لـ KYT فقط (الذي تتم إدارته في لوحة معلومات Sumsub قسم KYT). لا تعرض واجهة برمجة التطبيقات العامة إحصائيات التسليم أو الحذف لكل خطاف على الويب - بالنسبة لذلك، قم بإحالة المستخدم إلى واجهة مستخدم لوحة معلومات Sumsub.
