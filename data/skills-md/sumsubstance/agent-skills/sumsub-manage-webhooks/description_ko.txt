`/resources/clientWebhooks`를 통해 Sumsub `clientWebhooks`(지원자 검토 / 지원자 Pending / kytTxn / 등에 대한 이벤트 구독)를 관리합니다. **샌드박스만 해당** — 프로덕션 웹후크는 Sumsub 대시보드에서 사람이 직접 생성해야 합니다. 사용자가 샌드박스 테넌트에 대해 "웹훅 나열/검색/표시", "웹훅 생성/추가/등록", "웹훅 대상/이벤트 목록/비밀/서명 알고리즘 업데이트/편집/변경" 또는 "웹훅 비활성화/재활성화"를 요청할 때 트리거됩니다. 프로덕션 웹훅 설정(사용자에게 대시보드 참조), 관련되지 않은 웹훅 표면(`/resources/webhooks/...` 아래의 Stripe / videoIdent / Fireblocks / NFC / 파트너별 수신 경로), 일회성 전송 테스트(`inspectionCallbacks/testWebhook` 엔드포인트 직접 사용) 및 KYT 전용 웹훅 라우팅(Sumsub 대시보드의 KYT 섹션에서 관리됨)의 경우 건너뛰세요. 공개 API는 삭제 또는 웹후크별 전달 통계를 공개하지 않습니다. 이에 대한 경우 사용자에게 Sumsub 대시보드 UI를 안내하세요.
