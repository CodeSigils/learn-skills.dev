通过 `/resources/clientWebhooks` 管理 Sumsub `clientWebhooks`（applicantReviewed/applicantPending/kytTxn/等的事件订阅）。 **仅限沙箱** — 生产 Webhook 必须由人员直接在 Sumsub 仪表板中创建。当用户要求针对其沙箱租户“列出/检索/显示 Webhook”、“创建/添加/注册 Webhook”、“更新/编辑/更改 Webhook 目标/事件列表/秘密/签名算法”或“禁用/重新启用 Webhook”时触发。跳过生产 Webhook 设置（将用户引导至仪表板）、无关的 Webhook 表面（在 `/resources/webhooks/...` 下的 Stripe / videoIdent / Fireblocks / NFC / 合作伙伴特定接收路径）、测试一次性交付（直接使用 `inspectionCallbacks/testWebhook` 端点）以及仅 KYT Webhook 路由（在 Sumsub 仪表板的 KYT 部分中管理）。公共 API 不会公开删除或每个 Webhook 交付统计信息 - 对于这些统计信息，请让用户参考 Sumsub 仪表板 UI。
