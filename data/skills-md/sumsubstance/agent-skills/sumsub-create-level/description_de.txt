Erstellen oder aktualisieren Sie eine Sumsub-Bewerberebene. POST `/resources/applicants/-/levels`, um ein neues zu erstellen, PATCH den gleichen Pfad zum Aktualisieren (ID im Text), GET `/resources/applicants/-/levels/{id}`, um einen zurückzulesen. TRIGGER, wenn der Benutzer „eine Sumsub-Ebene erstellen/hinzufügen/erstellen/aktualisieren/bearbeiten“ auffordert, eine Liste der erforderlichen Schritte für einen Bewerberfluss bereitstellt (Identität/Selfie/Wohnsitznachweis/Fragebogen/Zahlungsmethoden/E-Mail- oder Telefonverifizierung/KYB/E-Sign) oder eine Ebene wünscht, die mit einer bestimmten Fragebogen-DefId verknüpft ist. SKIP für andere Sumsub-Entitäten (Fragebögen, Workflows, Bewerber) oder für einmalige Teilmengenanpassungen, die nicht von der Kompaktspezifikation abgedeckt werden (verwenden Sie dafür „sumsub-api-generic“).
