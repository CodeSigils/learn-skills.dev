Sumsub 応募者レベルを作成または更新します。 `/resources/applicants/-/levels` を POST して新しい作成し、同じパス (本文の ID) を PATCH して更新し、GET `/resources/applicants/-/levels/{id}` で 1 つ読み戻します。ユーザーが「Sumsub レベルの作成 / 追加 / 構築 / 更新 / 編集」を要求したとき、申請者フローに必要なステップのリスト (身元証明 / 自撮り写真 / 居住証明 / アンケート / 支払い方法 / 電子メールまたは電話認証 / KYB / 電子署名) を提供したとき、または特定の questions DefId に関連付けられたレベルを希望したときにトリガーされます。他の Sumsub エンティティ (アンケート、ワークフロー、応募者)、またはコンパクト仕様でカバーされていない 1 回限りのサブセット調整の場合はスキップします (それらには「sumsub-api-generic」を使用します)。
