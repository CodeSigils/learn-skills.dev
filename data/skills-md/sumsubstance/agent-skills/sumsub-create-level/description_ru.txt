Создайте или обновите уровень заявителя Sumsub. POST `/resources/applicants/-/levels` для создания нового, PATCH того же пути для обновления (идентификатор в теле), GET `/resources/applicants/-/levels/{id}`, чтобы прочитать его обратно. TRIGGER, когда пользователь запрашивает «создать / добавить / создать / обновить / отредактировать уровень Sumsub», предоставляет список необходимых шагов для потока заявителя (личность / селфи / подтверждение места жительства / анкета / способы оплаты / проверка электронной почты или телефона / KYB / электронный знак) или хочет, чтобы уровень был привязан к определенному идентификатору анкеты. ПРОПУСТИТЕ для других объектов Sumsub (анкеты, рабочие процессы, кандидаты) или для одноразовых настроек подмножества, не предусмотренных компактной спецификацией (для них используйте sumsub-api-generic).
