Sumsub 신청자 수준을 생성하거나 업데이트합니다. POST `/resources/applicants/-/levels`를 사용하여 새 경로를 만들고 업데이트할 동일한 경로를 패치합니다(본문의 ID). GET `/resources/applicants/-/levels/{id}`를 사용하여 다시 읽습니다. 사용자가 "Sumsub 수준 생성/추가/구축/업데이트/편집"을 요청하거나 신청자 흐름(신분증/셀카/거주 증명/설문지/지불 방법/이메일 또는 전화 확인/KYB/전자 서명)에 필요한 단계 목록을 제공하거나 특정 설문지DefId에 연결된 수준을 원하는 경우 TRIGGER. 다른 Sumsub 엔터티(설문지, 워크플로, 지원자) 또는 컴팩트 사양에서 다루지 않는 일회성 하위 설정 조정의 경우 건너뛰십시오(이 경우 `sumsub-api-generic` 사용).
