Cree o actualice un nivel de solicitante de Sumsub. POST `/resources/applicants/-/levels` para crear un nuevo, PATCH la misma ruta para actualizar (id en el cuerpo), GET `/resources/applicants/-/levels/{id}` para volver a leer uno. DISPARAR cuando el usuario solicita "crear/agregar/construir/actualizar/editar un nivel de Sumsub", proporciona una lista de pasos requeridos para un flujo de solicitante (identidad/selfie/prueba de residencia/cuestionario/métodos de pago/verificación por correo electrónico o teléfono/KYB/firma electrónica), o quiere un nivel conectado a un cuestionarioDefId específico. SALTE para otras entidades de Sumsub (cuestionarios, flujos de trabajo, solicitantes) o para ajustes de subconjuntos únicos que no están cubiertos por la especificación compacta (use `sumsub-api-generic` para ellos).
