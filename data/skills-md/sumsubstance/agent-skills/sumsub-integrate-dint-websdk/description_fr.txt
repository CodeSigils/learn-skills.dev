Ajoutez Sumsub Device Intelligence (le module Fisherman) à un projet Web qui vérifie déjà les utilisateurs avec le Sumsub WebSDK. DÉCLENCHEMENT lorsque l'utilisateur demande « d'ajouter l'intelligence de l'appareil », « d'activer la capture/la prise d'empreintes digitales de l'appareil dans le WebSDK », « d'activer Fisherman », de « détecter la fraude sur l'appareil/la multi-compte dans le flux de vérification » ou demande comment les étiquettes de risque de l'appareil parviennent à un candidat vérifié via le WebSDK. Couvre toute la boucle : capture des données de l'appareil au niveau, cycle de vie automatique du Fisherman dans le SDK, câblage avancé auto-rendu, lecture des signaux de l'appareil (onglet Appareils, vérification des appareils, étiquettes de risque, webhooks), tests du bac à sable, liste de contrôle de mise en ligne. SKIP pour l'intelligence des appareils sur les pages sans widget WebSDK (connexion/inscription/paiement) — utilisez `sumsub-integrate-dint-standalone` ; SKIP pour l'intégration de base du WebSDK lui-même — utilisez `sumsub-integrate-websdk`.
