將 Sumsub 裝置智慧型（Fisherman 模組）新增至已使用 Sumsub WebSDK 驗證使用者的 Web 專案。當使用者要求“新增裝置智慧”、“在 WebSDK 中啟用裝置擷取/指紋識別”、“開啟 Fisherman”、“在驗證流程中偵測裝置詐欺/多重記帳”，或詢問如何將裝置風險標籤新增至透過 WebSDK 驗證的申請人上時觸發。涵蓋整個循環 - 啟用在關卡上捕獲設備數據、自動 SDK 內的 Fisherman 生命週期、高級自渲染接線、讀取設備信號（設備選項卡、設備檢查、風險標籤、webhooks）、沙箱測試、上線檢查表。在沒有 WebSDK 小工具的頁面上跳過裝置智慧（登入/註冊/結帳）－使用 `sumsub-integrate-dint-standalone`；跳過基本 WebSDK 嵌入本身 — 使用「sumsub-integrate-websdk」。
