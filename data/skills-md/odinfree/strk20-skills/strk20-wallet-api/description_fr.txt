Créez des dapps privées sur Starknet via l'API Starknet Wallet. Couvre le bouclier/non blindé, les transferts privés, les soldes protégés, les appels DeFi privés et les échanges privés AVNU à partir de TypeScript ou React. À utiliser chaque fois qu'une application demande au portefeuille de confidentialité de l'utilisateur d'effectuer des actions STRK20 (starknet.js WalletAccountV6, hooks useStrk20, strk20InvokeTransaction, STRK20_ACTION, notes ouvertes, espaces réservés openNoteIds). Pour le côté assistant du Caire, utilisez strk20-anonymizer-contracts, pour les portefeuilles ou les backends détenant leurs propres clés, utilisez strk20-privacy-sdk, pour les concepts et le choix d'itinéraire, utilisez strk20-privacy.
