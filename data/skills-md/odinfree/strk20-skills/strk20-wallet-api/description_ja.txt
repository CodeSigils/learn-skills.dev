Starknet Wallet API を介して Starknet 上にプライベート DAPP を構築します。 TypeScript または React からのシールド/シールド解除、プライベート転送、シールド残高、プライベート DeFi コール、AVNU プライベート スワップをカバーします。アプリがユーザーのプライバシー対応ウォレットに STRK20 アクション (starknet.js WalletAccountV6、useStrk20 フック、strk20InvokeTransaction、STRK20_ACTION、オープン ノート、openNoteIds プレースホルダー) の実行を要求する場合に使用します。 Cairo ヘルパー側には strk20-anonymizer-contracts を使用し、独自のキーを保持するウォレットまたはバックエンドには strk20-privacy-sdk を使用し、コンセプトとルート選択には strk20-privacy を使用します。
