Cree dapps privadas en Starknet a través de la API de Starknet Wallet. Cubre protección/desprotección, transferencias privadas, saldos protegidos, llamadas DeFi privadas e intercambios privados AVNU de TypeScript o React. Úselo siempre que una aplicación solicite a la billetera con privacidad habilitada del usuario que realice acciones STRK20 (starknet.js WalletAccountV6, ganchos useStrk20, strk20InvokeTransaction, STRK20_ACTION, notas abiertas, marcadores de posición openNoteIds). Para el lado auxiliar de El Cairo, use strk20-anonymizer-contracts, para billeteras o backends que tengan sus propias claves, use strk20-privacy-sdk, para conceptos y elección de ruta, use strk20-privacy.
