Создавайте частные децентрализованные приложения в Starknet с помощью API кошелька Starknet. Охватывает защиту/снятие защиты, частные переводы, защищенные балансы, частные вызовы DeFi и частные обмены AVNU из TypeScript или React. Используйте всякий раз, когда приложение запрашивает кошелек пользователя с включенной конфиденциальностью для выполнения действий STRK20 (starknet.js WalletAccountV6, перехватчики useStrk20, strk20InvokeTransaction, STRK20_ACTION, открытые заметки, заполнители openNoteIds). Для вспомогательной стороны Cairo используйте strk20-anonymizer-contracts, для кошельков или серверов, содержащих собственные ключи, используйте strk20-privacy-sdk, для концепций и выбора маршрута используйте strk20-privacy.
