Erstellen Sie private Dapps auf Starknet über die Starknet Wallet API. Deckt Shield/Unshield, private Transfers, Shielded Balances, private DeFi-Anrufe und private AVNU-Swaps von TypeScript oder React ab. Wird immer dann verwendet, wenn eine App die datenschutzaktivierte Wallet des Benutzers auffordert, STRK20-Aktionen auszuführen (starknet.js WalletAccountV6, useStrk20-Hooks, strk20InvokeTransaction, STRK20_ACTION, offene Notizen, openNoteIds-Platzhalter). Für die Kairo-Helferseite verwenden Sie strk20-anonymizer-contracts, für Wallets oder Backends, die ihre eigenen Schlüssel halten, verwenden Sie strk20-privacy-sdk, für Konzepte und Routenauswahl verwenden Sie strk20-privacy.
