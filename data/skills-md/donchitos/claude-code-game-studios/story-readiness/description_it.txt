Convalidare che un file di storia sia pronto per l'implementazione. Verifica i requisiti GDD incorporati, i riferimenti ADR, le note del motore, i criteri di accettazione chiari e nessuna domanda di progettazione aperta. Produce verdetto PRONTO / NECESSARIO LAVORO / BLOCCATO con lacune specifiche. Da utilizzare quando l'utente dice "questa storia è pronta", "posso iniziare questa storia", "la storia X è pronta per essere implementata".
