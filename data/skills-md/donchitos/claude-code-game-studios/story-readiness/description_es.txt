Valide que un archivo de historia esté listo para su implementación. Comprueba los requisitos de GDD integrados, referencias de ADR, notas del motor, criterios de aceptación claros y sin preguntas de diseño abiertas. Produce un veredicto LISTO / NECESITA TRABAJO / BLOQUEADO con lagunas específicas. Úselo cuando el usuario diga "¿está lista esta historia?", "¿puedo comenzar con esta historia?", "está la historia X lista para implementar".
