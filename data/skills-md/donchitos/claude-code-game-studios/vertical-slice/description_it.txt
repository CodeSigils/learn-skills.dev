Convalida pre-produzione: crea una build end-to-end di qualità di produzione per confermare che l'intero ciclo di gioco è realizzabile prima di impegnarsi nella produzione. Esegui dopo aver completato GDD, architettura e specifiche UX. Produce un verdetto PROCEED/PIVOT/KILL che blocca la transizione Pre-produzione → Produzione.
