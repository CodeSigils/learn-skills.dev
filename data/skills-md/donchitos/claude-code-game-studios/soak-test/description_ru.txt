Создайте протокол испытаний на выдержку для длительных игровых сессий. Определяет, что следует наблюдать, измерять и регистрировать во время длительных игровых сессий, чтобы выявить медленные утечки, эффекты усталости и крайние случаи, которые появляются только после длительной игры. В основном используется на этапах доработки и выпуска.
