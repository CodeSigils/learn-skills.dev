Управляемое поэтапное создание основного архитектурного документа игры. Считывает все GDD, системный индекс, существующие ADR и справочную библиотеку ядра, чтобы создать полный проект архитектуры перед написанием любого кода. С учетом версии движка: отмечает пробелы в знаниях и проверяет решения на основе закрепленной версии движка.
