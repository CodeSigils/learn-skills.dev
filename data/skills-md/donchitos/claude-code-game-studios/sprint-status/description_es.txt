Comprobación rápida del estado del sprint. Lee el plan de sprint actual, escanea archivos de historias para conocer el estado y produce una instantánea concisa del progreso con evaluación del estado de avance y riesgos emergentes. Corre en cualquier momento durante un sprint para tener un conocimiento rápido de la situación. Úselo cuando el usuario pregunte "cómo va el sprint", "actualización del sprint", "mostrar el progreso del sprint".
