Быстрая проверка статуса спринта. Считывает текущий план спринта, сканирует файлы историй на предмет статуса и создает краткий снимок прогресса с оценкой выгорания и возникающими рисками. Бегайте в любой момент во время спринта, чтобы быстро ориентироваться в ситуации. Используйте, когда пользователь спрашивает: «Как продвигается спринт», «Обновление спринта», «Показать прогресс спринта».
