قم بإنشاء خطة اختبار ضمان الجودة لسباق سريع أو ميزة. يقرأ ملفات GDD وملفات القصة، ويصنف القصص حسب نوع الاختبار (المنطق/التكامل/المرئي/واجهة المستخدم)، وينتج خطة اختبار منظمة تغطي الاختبارات الآلية المطلوبة، وحالات الاختبار اليدوية، ونطاق اختبار الدخان، ومتطلبات تسجيل الخروج من اختبار التشغيل. قم بالتشغيل قبل بدء السباق أو عند بدء تشغيل ميزة رئيسية.
