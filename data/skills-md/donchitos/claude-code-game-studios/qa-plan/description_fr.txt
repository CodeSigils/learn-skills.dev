Générez un plan de test QA pour un sprint ou une fonctionnalité. Lit les GDD et les fichiers d'histoires, classe les histoires par type de test (Logique/Intégration/Visuel/UI) et produit un plan de test structuré couvrant les tests automatisés requis, les cas de tests manuels, la portée des tests de fumée et les exigences d'approbation des tests de jeu. Exécutez avant le début du sprint ou lors du démarrage d’une fonctionnalité majeure.
