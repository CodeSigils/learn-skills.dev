Genera un piano di test QA per uno sprint o una funzionalità. Legge GDD e file di storie, classifica le storie per tipo di test (Logico/Integrazione/Visivo/UI) e produce un piano di test strutturato che copre i test automatizzati richiesti, i casi di test manuali, l'ambito del test del fumo e i requisiti di approvazione del playtest. Corri prima dell'inizio dello sprint o quando inizi una funzionalità importante.
