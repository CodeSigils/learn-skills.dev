Проверяет полноту и согласованность архитектуры проекта со всеми GDD. Создает матрицу прослеживаемости, сопоставляющую все технические требования GDD с ADR, выявляет пробелы в покрытии, выявляет конфликты между ADR, проверяет согласованность совместимости двигателей во всех решениях и выдает вердикт «ГОДНО/ПРЕКРАСНО/НЕ ПРОЙДЕНО». Архитектурный эквивалент /design-review.
