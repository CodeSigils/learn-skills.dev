После того, как архитектура завершена, создает для программистов простой список практических правил — что вы должны делать, чего никогда не должны делать, для каждой системы и для каждого уровня. Извлечено из всех принятых ADR, технических предпочтений и справочной документации по двигателям. Более действенны, чем ADR (что объясняет, почему).
