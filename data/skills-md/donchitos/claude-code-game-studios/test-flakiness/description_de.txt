Erkennen Sie nicht deterministische (unzuverlässige) Tests, indem Sie CI-Laufprotokolle oder den Testergebnisverlauf lesen. Fasst die Erfolgsquoten pro Test zusammen, identifiziert zeitweilige Fehler, empfiehlt die Quarantäne oder Korrektur und verwaltet ein fehlerhaftes Testregister. Bester Lauf während der polnischen Phase oder nach mehreren CI-Läufen.
