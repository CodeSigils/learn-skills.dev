Rileva test non deterministici (instabili) leggendo i registri di esecuzione CI o la cronologia dei risultati dei test. Aggrega le percentuali di superamento per test, identifica gli errori intermittenti, consiglia la quarantena o la correzione e mantiene un registro dei test instabile. Miglior esecuzione durante la fase polacca o dopo più esecuzioni CI.
