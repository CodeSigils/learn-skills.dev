Suddividi una singola epopea in file di storie implementabili. Legge l'epica, il suo GDD, gli ADR che governano e il manifest di controllo. Ogni storia incorpora il suo requisito GDD TR-ID, la guida ADR, i criteri di accettazione, il tipo di storia e il percorso delle prove del test. Corri dietro a /create-epics per ogni epica.
