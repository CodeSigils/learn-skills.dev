Организуйте работу команды контроля качества на протяжении всего цикла тестирования. Координирует руководство по обеспечению качества (стратегия + план тестирования) и тестировщика по обеспечению качества (написание тестовых примеров + отчет об ошибках) для создания полного пакета обеспечения качества для спринта или функции. Включает: создание плана тестирования, написание тестовых примеров, дымовую проверку, ручное выполнение контроля качества и подписание отчета.
