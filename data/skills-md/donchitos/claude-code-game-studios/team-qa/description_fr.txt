Orchestrez l’équipe d’assurance qualité tout au long d’un cycle de tests complet. Coordonne le responsable qualité (stratégie + plan de test) et le testeur qualité (rédaction de cas de test + rapport de bogues) pour produire un package d'assurance qualité complet pour un sprint ou une fonctionnalité. Couvre : la génération de plans de test, la rédaction de scénarios de test, la porte de contrôle de fumée, l'exécution manuelle de l'assurance qualité et le rapport de signature.
