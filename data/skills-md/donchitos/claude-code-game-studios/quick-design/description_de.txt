Leichte Designspezifikation für kleine Änderungen – Tuning-Anpassungen, kleinere Mechanik, Balance-Optimierungen. Überspringt die vollständige GDD-Erstellung, wenn bereits eine System-GDD vorhanden ist oder die Änderung zu gering ist, um eine solche zu rechtfertigen. Erstellt eine schnelle Designspezifikation, die direkt in Story-Dateien eingebettet wird.
