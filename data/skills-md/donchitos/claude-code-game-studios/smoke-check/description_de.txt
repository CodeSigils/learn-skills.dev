Führen Sie vor der QA-Übergabe die Rauchtestschleuse für den kritischen Pfad durch. Führt die automatisierte Testsuite aus, überprüft die Kernfunktionalität und erstellt einen PASS/FAIL-Bericht. Wird ausgeführt, nachdem die Storys eines Sprints implementiert wurden und bevor die manuelle Qualitätssicherung beginnt. Eine fehlgeschlagene Rauchprüfung bedeutet, dass der Build nicht für die Qualitätssicherung bereit ist.
