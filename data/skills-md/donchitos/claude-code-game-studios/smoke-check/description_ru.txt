Перед передачей контроля качества запустите шлюз для проверки задымления критического пути. Выполняет набор автоматизированных тестов, проверяет основные функции и формирует отчет PASS/FAIL. Запускайте после реализации историй спринта и до начала ручного контроля качества. Неудачная проверка дыма означает, что сборка не готова к тестированию.
