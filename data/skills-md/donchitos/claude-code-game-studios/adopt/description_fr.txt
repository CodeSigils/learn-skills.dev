Intégration des friches industrielles : audite les artefacts de projet existants pour vérifier la conformité du format de modèle (pas seulement l'existence), classe les lacunes par impact et produit un plan de migration numéroté. Exécutez-le lorsque vous rejoignez un projet en cours ou effectuez une mise à niveau à partir d'une ancienne version du modèle. Distinct de /project-stage-detect (qui vérifie ce qui existe) — cela vérifie si ce qui existe fonctionnera réellement avec les compétences du modèle.
