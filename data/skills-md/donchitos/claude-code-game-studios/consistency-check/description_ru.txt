Сканируйте все GDD по реестру объектов, чтобы обнаружить несоответствия между документами: один и тот же объект с разными статистическими данными, один и тот же элемент с разными значениями, одна и та же формула с разными переменными. Подход на основе Grep — чтение реестра, а затем нацеленность только на конфликтующие разделы GDD, а не на полное чтение документа.
