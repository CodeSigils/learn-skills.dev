Utilisez cette compétence lorsque la qualité visuelle et l’identité de conception sont importantes pour un PDF. CRÉER (générer à partir de zéro) : « créer un PDF », « générer un rapport », « rédiger une proposition », « créer un CV », « beau PDF », « document professionnel », « page de garde », « PDF peaufiné », « document prêt pour le client ». FILL (remplir les champs du formulaire) : "remplir le formulaire", "remplir ce PDF", "remplir les champs du formulaire", "écrire les valeurs dans le PDF", "quels champs contient ce PDF". REFORMAT (appliquer le design à un document existant) : "reformater ce document", "appliquer notre style", "convertir ce Markdown/texte en PDF", "rendre ce document beau", "re-styler ce PDF". Cette compétence utilise un système de conception basé sur des jetons : la couleur, la typographie et l'espacement sont dérivés du type de document et parcourent chaque page. Le résultat est prêt à être imprimé. Préférez cette compétence lorsque l’apparence est importante, pas seulement lorsqu’une sortie PDF est nécessaire.
