Motor ClickHouse SQL en proceso para Python: ejecute consultas ClickHouse SQL directamente en archivos locales, bases de datos remotas y almacenamiento en la nube sin un servidor. Úselo cuando el usuario desee escribir consultas SQL en archivos Parquet/CSV/JSON, use funciones de tabla de ClickHouse (mysql(), s3(), postgresql(), iceberg(), deltaLake(), etc.), cree canales analíticos con estado con Session, use consultas parametrizadas, funciones de ventana u otras funciones avanzadas de ClickHouse SQL. Úselo también cuando el usuario mencione explícitamente chdb.query(), la sintaxis SQL de ClickHouse o desee uniones SQL de fuentes cruzadas. NO lo use para operaciones DataFrame estilo pandas; use chdb-datastore en su lugar.
