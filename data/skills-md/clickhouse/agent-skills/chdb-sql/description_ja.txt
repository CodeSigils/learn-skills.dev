Python 用インプロセス ClickHouse SQL エンジン — サーバーを使用せずに、ローカル ファイル、リモート データベース、クラウド ストレージ上で ClickHouse SQL クエリを直接実行します。ユーザーが Parquet/CSV/JSON ファイルに対して SQL クエリを作成する場合、ClickHouse テーブル関数 (mysql()、s3()、postgresql()、iceberg()、deltaLake() など) を使用する場合、Session でステートフル分析パイプラインを構築する場合、パラメータ化されたクエリ、ウィンドウ関数、またはその他の高度な ClickHouse SQL 機能を使用する場合に使用します。ユーザーが chdb.query() や ClickHouse SQL 構文に明示的に言及する場合、またはクロスソース SQL 結合を必要とする場合にも使用します。 pandas スタイルの DataFrame 操作には使用しないでください。代わりに chdb-datastore を使用してください。
