Motore SQL ClickHouse in-process per Python: esegui query SQL ClickHouse direttamente su file locali, database remoti e spazio di archiviazione cloud senza un server. Da utilizzare quando l'utente desidera scrivere query SQL su file Parquet/CSV/JSON, utilizzare le funzioni di tabella ClickHouse (mysql(), s3(), postgresql(), iceberg(), deltaLake() ecc.), creare pipeline analitiche con stato con Session, utilizzare query parametrizzate, funzioni finestra o altre funzionalità SQL avanzate di ClickHouse. Da utilizzare anche quando l'utente menziona esplicitamente chdb.query(), la sintassi SQL di ClickHouse o desidera join SQL tra sorgenti. NON utilizzare per operazioni DataFrame in stile panda: utilizzare invece chdb-datastore.
