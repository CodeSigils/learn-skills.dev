Moteur SQL ClickHouse en cours pour Python : exécutez des requêtes SQL ClickHouse directement sur des fichiers locaux, des bases de données distantes et un stockage cloud sans serveur. À utiliser lorsque l'utilisateur souhaite écrire des requêtes SQL sur des fichiers Parquet/CSV/JSON, utiliser les fonctions de table ClickHouse (mysql(), s3(), postgresql(), iceberg(), deltaLake() etc.), créer des pipelines analytiques avec état avec Session, utiliser des requêtes paramétrées, des fonctions de fenêtre ou d'autres fonctionnalités SQL avancées de ClickHouse. À utiliser également lorsque l'utilisateur mentionne explicitement chdb.query(), la syntaxe SQL ClickHouse ou souhaite des jointures SQL inter-sources. Ne PAS utiliser pour les opérations DataFrame de style pandas – utilisez plutôt chdb-datastore.
