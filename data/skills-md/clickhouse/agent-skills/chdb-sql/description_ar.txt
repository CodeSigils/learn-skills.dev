محرك ClickHouse SQL قيد التشغيل لـ Python - قم بتشغيل استعلامات ClickHouse SQL مباشرةً على الملفات المحلية وقواعد البيانات البعيدة والتخزين السحابي بدون خادم. يُستخدم عندما يريد المستخدم كتابة استعلامات SQL مقابل ملفات Parquet/CSV/ JSON، واستخدام وظائف جدول ClickHouse (mysql()، وs3()، وpostgresql()، وiceberg()، وdeltaLake() وما إلى ذلك)، وإنشاء مسارات تحليلية ذات حالة مع الجلسة، واستخدام الاستعلامات ذات المعلمات، أو وظائف النافذة، أو ميزات ClickHouse SQL المتقدمة الأخرى. يُستخدم أيضًا عندما يذكر المستخدم صراحةً chdb.query()، أو بناء جملة ClickHouse SQL، أو يريد انضمام SQL عبر المصدر. لا تستخدمه لعمليات DataFrame بنمط الباندا - استخدم chdb-datastore بدلاً من ذلك.
