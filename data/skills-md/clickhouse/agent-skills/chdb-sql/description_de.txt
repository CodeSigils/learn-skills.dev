In-Process-ClickHouse-SQL-Engine für Python – Führen Sie ClickHouse-SQL-Abfragen direkt in lokalen Dateien, Remote-Datenbanken und Cloud-Speichern ohne Server aus. Verwenden Sie diese Option, wenn der Benutzer SQL-Abfragen für Parquet-/CSV-/JSON-Dateien schreiben, ClickHouse-Tabellenfunktionen (mysql(), s3(), postgresql(), iceberg(), deltaLake() usw.) verwenden, zustandsbehaftete Analysepipelines mit Session erstellen, parametrisierte Abfragen, Fensterfunktionen oder andere erweiterte ClickHouse-SQL-Funktionen verwenden möchte. Wird auch verwendet, wenn der Benutzer ausdrücklich chdb.query() oder die ClickHouse-SQL-Syntax erwähnt oder quellübergreifende SQL-Joins wünscht. NICHT für DataFrame-Vorgänge im Pandas-Stil verwenden – verwenden Sie stattdessen chdb-datastore.
