Внутрипроцессный механизм ClickHouse SQL для Python — запускайте SQL-запросы ClickHouse непосредственно к локальным файлам, удаленным базам данных и облачному хранилищу без сервера. Используйте, когда пользователь хочет писать SQL-запросы к файлам Parquet/CSV/JSON, использовать табличные функции ClickHouse (mysql(), s3(), postgresql(), Iceberg(), deltaLake() и т. д.), строить аналитические конвейеры с отслеживанием состояния с помощью Session, использовать параметризованные запросы, оконные функции или другие расширенные функции ClickHouse SQL. Также используйте, когда пользователь явно упоминает chdb.query(), синтаксис ClickHouse SQL или хочет объединить SQL-коды между исходными кодами. НЕ используйте для операций DataFrame в стиле pandas — вместо этого используйте chdb-datastore.
