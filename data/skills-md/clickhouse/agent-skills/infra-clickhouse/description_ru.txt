Настраивает ClickHouse и управляет им с помощью интерфейса командной строки clickhousectl — устанавливает и запускает локальный сервер ClickHouse для разработки, а также создает управляемые сервисы ClickHouse Cloud для производства (аутентификация, создание сервисов, миграция схемы, подключение приложений). Используйте, когда пользователь хочет создать приложение с помощью ClickHouse, настроить локальную среду разработки ClickHouse, создать таблицы и начать выполнять запросы, развернуть ClickHouse в рабочей среде или ClickHouse Cloud или выполнить миграцию из локальной установки в облако.
