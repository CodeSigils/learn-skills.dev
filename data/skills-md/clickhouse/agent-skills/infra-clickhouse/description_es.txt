Configura y administra ClickHouse mediante la CLI clickhousectl: instala y ejecuta un servidor ClickHouse local para desarrollo y crea servicios administrados en la nube de ClickHouse para producción (autenticación, creación de servicios, migración de esquemas, conexión de aplicaciones). Úselo cuando el usuario desee crear una aplicación con ClickHouse, configurar un entorno de desarrollo de ClickHouse local, crear tablas y comenzar a realizar consultas, implementar ClickHouse en producción o ClickHouse Cloud, o migrar desde una configuración local a la nube.
