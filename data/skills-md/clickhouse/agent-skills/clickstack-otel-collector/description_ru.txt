Используйте, когда пользователь хочет подключить сборщик OpenTelemetry к управляемой службе ClickStack в ClickHouse Cloud либо путем развертывания нового локального сборщика (Docker run или Docker Compose), либо путем настройки собственного существующего сборщика, а затем отправить расширенные синтетические данные телеметрии и убедиться, что они видны в ClickStack.
