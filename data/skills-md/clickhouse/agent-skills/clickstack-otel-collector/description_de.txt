Verwenden Sie diese Option, wenn ein Benutzer einen OpenTelemetry-Kollektor mit einem verwalteten ClickStack-Dienst in ClickHouse Cloud verbinden möchte, indem er entweder einen neuen lokalen Kollektor (Docker Run oder Docker Compose) bereitstellt oder seinen eigenen vorhandenen Kollektor konfiguriert, dann umfangreiche synthetische Telemetriedaten sendet und überprüft, ob diese in ClickStack sichtbar sind.
