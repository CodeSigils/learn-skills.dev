用 ClickHouse 性能替代 pandas。使用“import chdb.datastore as pd”（或“from datastore import DataStore”）并编写标准 pandas 代码 - 相同的 API，在大型数据集上速度提高 10-100 倍。支持 16+ 数据源（MySQL、PostgreSQL、S3、MongoDB、ClickHouse、Iceberg、Delta Lake 等）和 10+ 文件格式（Parquet、CSV、JSON、Arrow、ORC 等）以及跨源连接。当用户想要使用 pandas 风格的语法分析数据、加速缓慢的 pandas 代码、将远程数据库或云存储作为 DataFrame 查询或连接不同源的数据时，请使用此技能 - 即使它们没有明确提及 chdb 或 DataStore。请勿用于原始 SQL 查询、ClickHouse 服务器管理或非 Python 语言。
