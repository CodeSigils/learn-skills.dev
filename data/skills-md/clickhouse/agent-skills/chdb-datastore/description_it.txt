Sostituzione drop-in dei panda con prestazioni ClickHouse. Utilizza "import chdb.datastore as pd" (o "from datastore import DataStore") e scrivi il codice panda standard: stessa API, 10-100 volte più veloce su set di dati di grandi dimensioni. Supporta oltre 16 origini dati (MySQL, PostgreSQL, S3, MongoDB, ClickHouse, Iceberg, Delta Lake, ecc.) e oltre 10 formati di file (Parquet, CSV, JSON, Arrow, ORC, ecc.) con join tra sorgenti. Utilizza questa competenza quando l'utente desidera analizzare i dati con una sintassi in stile panda, accelerare il codice panda lento, eseguire query su database remoti o archiviazione cloud come DataFrames o unire dati da origini diverse, anche se non menzionano esplicitamente chdb o DataStore. NON utilizzare per query SQL non elaborate, amministrazione del server ClickHouse o linguaggi non Python.
