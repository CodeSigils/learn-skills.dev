ClickHouse 성능으로 드롭인 팬더를 대체합니다. `import chdb.datastore as pd`(또는 `from datastore import DataStore`)를 사용하고 표준 Pandas 코드를 작성하세요. 동일한 API로 대규모 데이터세트에서 10~100배 더 빠릅니다. 크로스 소스 조인을 통해 16개 이상의 데이터 소스(MySQL, PostgreSQL, S3, MongoDB, ClickHouse, Iceberg, Delta Lake 등)와 10개 이상의 파일 형식(Parquet, CSV, JSON, Arrow, ORC 등)을 지원합니다. 사용자가 pandas 스타일 구문으로 데이터를 분석하고, 느린 pandas 코드 속도를 높이고, 원격 데이터베이스 또는 클라우드 스토리지를 DataFrame으로 쿼리하거나, chdb 또는 DataStore를 명시적으로 언급하지 않더라도 다양한 소스에 걸쳐 데이터를 조인하려는 경우 이 기술을 사용하세요. 원시 SQL 쿼리, ClickHouse 서버 관리 또는 Python이 아닌 언어에는 사용하지 마십시오.
