Remplacement instantané des pandas avec les performances ClickHouse. Utilisez `import chdb.datastore as pd` (ou `from datastore import DataStore`) et écrivez du code pandas standard — même API, 10 à 100 fois plus rapide sur les grands ensembles de données. Prend en charge plus de 16 sources de données (MySQL, PostgreSQL, S3, MongoDB, ClickHouse, Iceberg, Delta Lake, etc.) et plus de 10 formats de fichiers (Parquet, CSV, JSON, Arrow, ORC, etc.) avec jointures multi-sources. Utilisez cette compétence lorsque l'utilisateur souhaite analyser des données avec une syntaxe de style pandas, accélérer le code pandas lent, interroger des bases de données distantes ou un stockage cloud en tant que DataFrames, ou joindre des données sur différentes sources, même s'ils ne mentionnent pas explicitement chdb ou DataStore. Ne PAS utiliser pour les requêtes SQL brutes, l'administration du serveur ClickHouse ou les langages non Python.
