用 ClickHouse 性能取代 pandas。使用“import chdb.datastore as pd”（或“from datastore import DataStore”）並編寫標準 pandas 程式碼 - 相同的 API，在大型資料集上速度提高 10-100 倍。支援 16+ 資料來源（MySQL、PostgreSQL、S3、MongoDB、ClickHouse、Iceberg、Delta Lake 等）和 10+ 檔案格式（Parquet、CSV、JSON、Arrow、ORC 等）以及跨來源連接。當使用者想要使用 pandas 風格的語法分析資料、加速緩慢的 pandas 程式碼、將遠端資料庫或雲端儲存作為 DataFrame 查詢或連接不同來源的資料時，請使用此技能 - 即使它們沒有明確提及 chdb 或 DataStore。请勿用于原始 SQL 查询、ClickHouse 服务器管理或非 Python 语言。
