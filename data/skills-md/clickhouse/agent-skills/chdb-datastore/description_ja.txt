ClickHouse のパフォーマンスを備えたドロップイン パンダの置き換え。 「import chdb.datastore as pd」 (または「from datastore import DataStore」) を使用して、標準のパンダ コードを作成します。同じ API で、大規模なデータセットでは 10 ～ 100 倍高速です。クロスソース結合により、16 個以上のデータ ソース (MySQL、PostgreSQL、S3、MongoDB、ClickHouse、Iceberg、Delta Lake など) と 10 個以上のファイル形式 (Parquet、CSV、JSON、Arrow、ORC など) をサポートします。このスキルは、ユーザーがパンダ スタイルの構文でデータを分析したい場合、遅いパンダ コードを高速化したい場合、リモート データベースやクラウド ストレージを DataFrame としてクエリしたい場合、または異なるソース間でデータを結合したい場合に使用します (chdb や DataStore について明示的に言及していない場合でも)。生の SQL クエリ、ClickHouse サーバー管理、または Python 以外の言語には使用しないでください。
