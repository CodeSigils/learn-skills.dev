Reemplazo directo de pandas con el rendimiento de ClickHouse. Utilice `import chdb.datastore as pd` (o `from datastore import DataStore`) y escriba código pandas estándar: la misma API, entre 10 y 100 veces más rápido en conjuntos de datos grandes. Admite más de 16 fuentes de datos (MySQL, PostgreSQL, S3, MongoDB, ClickHouse, Iceberg, Delta Lake, etc.) y más de 10 formatos de archivos (Parquet, CSV, JSON, Arrow, ORC, etc.) con uniones de fuentes cruzadas. Utilice esta habilidad cuando el usuario quiera analizar datos con sintaxis estilo pandas, acelerar el código pandas lento, consultar bases de datos remotas o almacenamiento en la nube como DataFrames, o unir datos de diferentes fuentes, incluso si no mencionan explícitamente chdb o DataStore. NO lo utilice para consultas SQL sin formato, administración del servidor ClickHouse o lenguajes que no sean Python.
