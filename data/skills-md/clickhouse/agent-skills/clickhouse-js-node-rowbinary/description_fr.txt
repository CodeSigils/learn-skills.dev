Générez du code TypeScript/JavaScript qui lit/décode ET écrit/encode les flux ClickHouse RowBinary pour le serveur HTTP ClickHouse. Utilisez cette compétence chaque fois qu'un utilisateur souhaite analyser ou produire `RowBinary`, `RowBinaryWithNames` ou `RowBinaryWithNamesAndTypes`. Node.js uniquement, ne couvre pas les navigateurs.
