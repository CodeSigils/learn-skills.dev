Escriba código de aplicación idiomática con el cliente ClickHouse Node.js (`@clickhouse/client`). Utilice esta habilidad siempre que un usuario esté *construyendo* contra el cliente Node.js: configurando el cliente, haciendo ping, insertando filas en formato JSON o sin formato, seleccionando y analizando resultados, vinculando parámetros de consulta, administrando sesiones y tablas temporales, trabajando con tipos de datos o personalizando el análisis JSON. NO lo use para código de navegador/cliente web.
