Écrivez du code d'application idiomatique avec le client ClickHouse Node.js ($`@clickhouse/client`). Utilisez cette compétence chaque fois qu'un utilisateur *construit* avec le client Node.js : configuration du client, ping, insertion de lignes au format JSON ou brut, sélection et analyse des résultats, liaison des paramètres de requête, gestion des sessions et des tables temporaires, utilisation des types de données ou personnalisation de l'analyse JSON. Ne PAS utiliser pour le code du navigateur/client Web.
