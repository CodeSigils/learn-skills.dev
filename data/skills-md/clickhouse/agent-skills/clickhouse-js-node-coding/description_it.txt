Scrivi il codice dell'applicazione idiomatico con il client ClickHouse Node.js ("@clickhouse/client`). Utilizza questa competenza ogni volta che un utente *crea* sul client Node.js: configura il client, esegue il ping, inserisce righe in formato JSON o non elaborato, seleziona e analizza risultati, associa parametri di query, gestisce sessioni e tabelle temporanee, lavora con tipi di dati o personalizza l'analisi JSON. NON utilizzare per il codice browser/client Web.
