Напишите идиоматический код приложения с помощью клиента ClickHouse Node.js (@clickhouse/client). Используйте этот навык всякий раз, когда пользователь *создает* клиент Node.js — настраивает клиент, проверяет связь, вставляет строки в JSON или необработанных форматах, выбирает и анализирует результаты, привязывает параметры запроса, управляет сеансами и временными таблицами, работает с типами данных или настраивает анализ JSON. НЕ используйте для кода браузера/веб-клиента.
