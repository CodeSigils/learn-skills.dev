Configura y administra Postgres utilizando la CLI clickhousectl: ejecuta un Postgres local respaldado por Docker para el desarrollo y crea y opera servicios administrados de ClickHouse Cloud Postgres (conexiones, TLS, configuración de tiempo de ejecución, réplicas de lectura, conmutación por error, restauración en un momento dado). Úselo cuando el usuario desee una base de datos Postgres o PostgreSQL para su aplicación, un entorno de desarrollo de Postgres local, acceso psql o un Postgres administrado/de producción en ClickHouse Cloud, o mencione mover un Postgres local a producción.
