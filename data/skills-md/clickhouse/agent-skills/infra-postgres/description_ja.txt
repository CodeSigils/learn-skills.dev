clickhousectl CLI を使用して Postgres をセットアップおよび管理します。開発用にローカルの Docker ベースの Postgres を実行し、マネージド ClickHouse Cloud Postgres サービス (接続、TLS、ランタイム構成、リードレプリカ、フェイルオーバー、ポイントインタイム復元) を作成および運用します。ユーザーがアプリケーション用の Postgres または PostgreSQL データベース、ローカル Postgres 開発環境、psql アクセス、または ClickHouse Cloud の管理/運用 Postgres を必要とする場合、またはローカル Postgres を運用環境に移行することに言及する場合に使用します。
