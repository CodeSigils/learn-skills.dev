clickhousectl CLI를 사용하여 Postgres를 설정 및 관리합니다. 개발을 위해 로컬 Docker 지원 Postgres를 실행하고 관리형 ClickHouse Cloud Postgres 서비스(연결, TLS, 런타임 구성, 읽기 복제본, 장애 조치, 특정 시점 복원)를 생성 및 운영합니다. 사용자가 애플리케이션용 Postgres 또는 PostgreSQL 데이터베이스, 로컬 Postgres 개발 환경, psql 액세스 또는 ClickHouse Cloud의 관리/프로덕션 Postgres를 원하거나 로컬 Postgres를 프로덕션으로 이동한다고 언급할 때 사용합니다.
