НЕОБХОДИМО ИСПОЛЬЗОВАТЬ при исследовании проблем с производительностью экземпляра Postgres, управляемого ClickHouse. Предоставляет основанный на фактических данных рабочий процесс RCA, который очищает конечную точку Prometheus на предмет системного сигнала, извлекает данные для каждой дайджеста из API шаблонов медленных запросов и рекомендует (не применяет) исправление.
