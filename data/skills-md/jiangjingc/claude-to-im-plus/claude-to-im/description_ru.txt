Соедините ЭТОТ сеанс Claude Code или Codex с Telegram, Discord, Feishu/Lark, QQ, WeChat или DingTalk, чтобы
пользователь может общаться с Клодом со своего телефона. Используется для: настройки, запуска, остановки,
или диагностика демона моста claude-to-im; пересылка ответов Клода на сообщение
приложение; любая фраза, например «Клод-то-им», «мост», «消息推送», «消息转发», «桥接»,
«连上飞书», «手机上看claude», «启动后台服务», «诊断», «查看日志», «配置», «切到微信继续聊».
Подкоманды: настройка, запуск, остановка, статус, журналы, передача обслуживания, перенастройка, врач.
НЕ используйте для: создания автономных ботов, интеграции веб-перехватчиков или написания кода с помощью IM.
SDK платформы — это обычные задачи программирования.
