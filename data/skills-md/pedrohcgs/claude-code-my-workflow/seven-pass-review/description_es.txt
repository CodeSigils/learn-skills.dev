Mechanize Pattern 15: el protocolo de revisión adversarial de siete pases para manuscritos académicos. Genera 7 subagentes bifurcados en paralelo (resumen, introducción, métodos, resultados, solidez, prosa, citas) y luego sintetiza una lista de verificación de revisión priorizada. Úselo para artículos listos para enviar o en etapa de R&R donde la revisión de una sola pasada no es suficiente.
