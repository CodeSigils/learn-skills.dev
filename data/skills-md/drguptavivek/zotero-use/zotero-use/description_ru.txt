Используйте, когда агенту требуется один из двух основных рабочих процессов Zotero: (1) поиск/запрос/извлечение ссылок из библиотеки Zotero пользователя и мозговой штурм на основе доказательств Zotero, включая семантический поиск ZOTseek, или (2) редактирование текста Word DOCX и добавление выбранных элементов Zotero в качестве полей цитирования в реальном времени. Предпочитайте структурированный интерфейс командной строки Pyzotero («zot») для точного поиска в низком контексте; используйте ZOTseek MCP для концептуального семантического открытия после открытия живого инструмента. Действия по созданию/обновлению/удалению библиотеки Zotero являются второстепенными и должны выполняться только по явному запросу. Триггер по Zotero, Pyzotero, zot, ZOTseek, поиск в семантической библиотеке, Zotero MCP, Word/DOCX цитаты Zotero, поиск литературы в Zotero, обзор ссылок Zotero, мозговой штурм документов из библиотеки Zotero, метаданные, коллекции, теги, последние элементы, вложения/заметки, полнотекстовый поиск или настройка Zotero.
