Verfassen, pflegen und nutzen Sie Wissenspakete im Open Knowledge Format (OKF) – portables Markdown + YAML-Frontmaterial, das sowohl Menschen als auch Agenten lesen können. Verwenden Sie diese Option, wenn Sie Projektwissen (Dienste, APIs, Schemata, Metriken, Runbooks, Entscheidungen) in einem OKF-Bundle erfassen, wenn Sie eines aktualisieren, nachdem sich Code oder Dokumente geändert haben, oder wenn ein Repository ein „.okf/“-Bundle (oder ein anderes OKF-Bundle) enthält, das die Aufgabe informieren soll. Wird ausgelöst bei: „Dokumentieren Sie dies in OKF“, „Aktualisieren Sie das Wissenspaket“, „Erfassen Sie dies als Konzept“ oder jede Arbeit in einem Repo, die über ein OKF-Paket verfügt.
