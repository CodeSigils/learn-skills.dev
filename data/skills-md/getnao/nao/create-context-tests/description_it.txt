Genera una suite di test di coppie linguaggio naturale → SQL che diventi il ​​punto di riferimento della qualità per un agente nao, quindi eseguila tramite `nao test`. Da utilizzare quando l'utente desidera iniziare a misurare l'affidabilità dell'agente, estendere una suite di test esistente o aggiungere test per nuovi parametri. I test sono l'unica risposta onesta alla domanda "il contesto funziona?". Non utilizzare per scrivere regole (write-context-rules) o diagnosticare errori (audit-context).
