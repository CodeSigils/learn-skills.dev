Создайте набор тестов из пар естественный язык → SQL, который станет эталоном качества для агента nao, а затем запустите его с помощью `nao test`. Используйте, когда пользователь хочет начать измерение надежности агента, расширить существующий набор тестов или добавить тесты для новых показателей. Тесты — единственный честный ответ на вопрос «работает ли контекст?». Не используйте для написания правил (write-context-rules) или диагностики сбоев (audit-context).
