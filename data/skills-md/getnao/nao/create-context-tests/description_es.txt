Genere un conjunto de pruebas de pares de lenguaje natural → SQL que se convierta en el punto de referencia de calidad para un agente nao, luego ejecútelo mediante "nao test". Úselo cuando el usuario quiera comenzar a medir la confiabilidad del agente, ampliar un conjunto de pruebas existente o agregar pruebas para nuevas métricas. Las pruebas son la única respuesta honesta a "¿funciona el contexto?". No lo utilice para escribir reglas (reglas de contexto de escritura) o diagnosticar fallas (contexto de auditoría).
