Générez une suite de tests de paires langage naturel → SQL qui devient la référence de qualité pour un agent nao, puis exécutez-la via `nao test`. À utiliser lorsque l'utilisateur souhaite commencer à mesurer la fiabilité des agents, étendre une suite de tests existante ou ajouter des tests pour de nouvelles métriques. Les tests sont la seule réponse honnête à la question « le contexte fonctionne-t-il ? ». Ne pas utiliser pour écrire des règles (write-context-rules) ou diagnostiquer des échecs (audit-context).
