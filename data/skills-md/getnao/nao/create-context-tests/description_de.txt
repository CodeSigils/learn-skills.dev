Generieren Sie eine Testsuite aus natürlichsprachlichen → SQL-Paaren, die zum Qualitätsmaßstab für einen Nao-Agenten wird, und führen Sie sie dann über „Nao-Test“ aus. Verwenden Sie diese Option, wenn der Benutzer mit der Messung der Agentenzuverlässigkeit beginnen, eine vorhandene Testsuite erweitern oder Tests für neue Metriken hinzufügen möchte. Tests sind die einzig ehrliche Antwort auf die Frage „Funktioniert der Kontext?“. Nicht zum Schreiben von Regeln (write-context-rules) oder zum Diagnostizieren von Fehlern (audit-context) verwenden.
