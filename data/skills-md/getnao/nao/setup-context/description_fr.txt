Démarrez un agent nao pour un projet : rassemblez les informations sur l'entrepôt + la portée + le contexte supplémentaire en un seul tour, recherchez la configuration spécifique à l'entrepôt à partir de la documentation nao, écrivez nao_config.yaml, exécutez nao init + nao sync, configurez la clé LLM et générez le premier RULES.md. À utiliser lorsque l'utilisateur vient de décider d'utiliser nao sur un nouveau projet. Uniquement pour la première configuration ; pour modifier des règles, générer des tests ou réviser un contexte existant, utilisez write-context-rules / create-context-tests / audit-context.
