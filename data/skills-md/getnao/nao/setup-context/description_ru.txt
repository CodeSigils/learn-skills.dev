Загрузите агент nao для проекта — соберите информацию о хранилище + области действия + дополнительный контекст за один раунд, найдите конфигурацию для конкретного хранилища в документации nao, напишите nao_config.yaml, запустите nao init + nao sync, настройте ключ LLM и сгенерируйте первый RULES.md. Используйте, когда пользователь только что решил использовать nao в новом проекте. Только при первой настройке; для редактирования правил, создания тестов или просмотра существующего контекста используйте write-context-rules/create-context-tests/audit-context.
