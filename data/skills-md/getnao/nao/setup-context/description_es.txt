Arranque un agente de nao para un proyecto: recopile información del almacén + alcance + contexto adicional en una ronda, busque la configuración específica del almacén en los documentos de nao, escriba nao_config.yaml, ejecute nao init + nao sync, configure la clave LLM y genere el primer RULES.md. Úselo cuando el usuario acaba de decidir usar nao en un nuevo proyecto. Sólo para configuración por primera vez; para editar reglas, generar pruebas o revisar un contexto existente, use write-context-rules / create-context-tests / audit-context.
