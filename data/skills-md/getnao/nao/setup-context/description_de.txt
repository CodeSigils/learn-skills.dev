Bootstrap eines Nao-Agenten für ein Projekt – Sammeln Sie Warehouse-, Scope- und Extra-Kontext-Informationen in einer Runde, suchen Sie die Warehouse-spezifische Konfiguration in den Nao-Dokumenten, schreiben Sie nao_config.yaml, führen Sie nao init + nao sync aus, richten Sie den LLM-Schlüssel ein und generieren Sie die erste RULES.md. Verwenden Sie diese Option, wenn der Benutzer sich gerade entschieden hat, nao für ein neues Projekt zu verwenden. Nur für die Ersteinrichtung; Verwenden Sie zum Bearbeiten von Regeln, zum Generieren von Tests oder zum Überprüfen eines vorhandenen Kontexts write-context-rules / create-context-tests / audit-context.
