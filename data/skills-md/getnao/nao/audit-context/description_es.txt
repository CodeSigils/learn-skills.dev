Diagnosticar la salud de un contexto nao en cualquier etapa de su ciclo de vida. Úselo cuando el usuario desee una revisión estructurada de lo que se ha sincronizado, cómo se compara RULES.md con la estructura de destino, si cada tabla está documentada, si el modelo de datos es MECE, si existen pruebas y qué revelan sus fallas, y si los archivos de contexto están inflados. Genera un informe de auditoría estructurado con recomendaciones clasificadas. No lo utilice para la configuración por primera vez (contexto de configuración) o para la escritura de reglas de rutina (reglas de contexto de escritura).
