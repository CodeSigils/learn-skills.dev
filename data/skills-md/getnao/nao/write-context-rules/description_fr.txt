Créez ou étendez le RULES.md d'un projet nao. Possède le modèle RULES.md. À utiliser lorsque l'utilisateur souhaite générer le RULES.md initial à partir de métadonnées synchronisées (appelées par le contexte de configuration) ou améliorer son RULES.md existant. Ne pas utiliser pour la première configuration de l'étendue (utilisez le contexte de configuration) ou pour diagnostiquer des problèmes existants (utilisez le contexte d'audit).
