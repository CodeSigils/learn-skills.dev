Cree o amplíe RULES.md de un proyecto nao. Posee la plantilla RULES.md. Úselo cuando el usuario desee generar el RULES.md inicial a partir de metadatos sincronizados (llamados por el contexto de configuración) o mejorar su RULES.md existente. No lo use para la configuración del alcance por primera vez (use el contexto de configuración) o para diagnosticar problemas existentes (use el contexto de auditoría).
