Tests d’audit pour une réelle valeur de recherche de bogues. À utiliser lorsque l'utilisateur demande si les tests sont utiles, triviaux, redondants, sur-moqués, couplés à l'implémentation, lourds en instantanés, remplissant la couverture, réussissant uniquement parce que le test contrôle les deux côtés, ou si les tests doivent être conservés, corrigés, coupés ou ajoutés. À utiliser également lors de l'examen des modifications de tests dans un PR et que l'utilisateur souhaite obtenir un jugement honnête quant à savoir si les tests méritent leur place.
