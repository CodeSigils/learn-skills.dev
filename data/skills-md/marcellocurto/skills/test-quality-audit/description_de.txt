Audit-Tests für echten Mehrwert bei der Fehlersuche. Wird verwendet, wenn der Benutzer fragt, ob Tests nützlich, trivial, redundant, übermäßig verspottet, an die Implementierung gekoppelt, Snapshot-intensiv, Coverage-Padding und nur bestanden sind, weil der Test beide Seiten kontrolliert, oder ob Tests beibehalten, korrigiert, gekürzt oder hinzugefügt werden sollen. Verwenden Sie es auch, wenn Sie Teständerungen in einer PR überprüfen und der Benutzer ein ehrliches Urteil darüber wünscht, ob die Tests ihren Platz verdienen.
