مهارة صريحة فقط لتصميم الواجهة الأمامية غير المقيدة والإبداعية للغاية. يُستخدم فقط عندما يطلب المستخدم صراحةً استخدام الواجهة الأمامية البرية أو يطلب استدعاء هذه المهارة بالضبط. لا يتم تشغيلها تلقائيًا لطلبات الواجهة الأمامية العادية أو التصميم أو التجميل أو واجهة مستخدم المنتج أو نظام التصميم أو طلبات تلميع الإنتاج.
