Автономный состязательный цикл проверки ПЛАНА, в котором Claude Code (разработчик) и OpenAI Codex (критик только для чтения) объединяют план реализации перед написанием любого кода. Используйте это, когда у вас УЖЕ есть план или ясная идея и вы просто хотите провести стресс-тест по нескольким моделям — без предварительного собеседования по требованиям. Клод составляет/загружает план в PLAN_FILE (по умолчанию PLAN.md), Кодекс просматривает его в изолированной программной среде только для чтения и возвращает VERDICT:APPROVED или VERDICT:REVISE, Клод пересматривает и повторно отправляет в ТО ЖЕ сеанс Кодекса (контекст сохраняется) до тех пор, пока APPROVED или не будет достигнуто настраиваемое ограничение MAX_ROUNDS. Человек утверждает конвергентный план перед написанием кода. Используйте, когда пользователь говорит: «/codex-plan-review», «кодекс рассмотрит мой план», «попросите Кодекс проверить мой план», «спорьте этот план с Кодексом», «состязательный обзор плана», «заставьте Клода и Кодекс спорить/ссориться из-за плана» или собирается построить что-то важное (аутентификация, схема, параллелизм, миграция, платежи) и хочет выполнить вторую модель проверки работоспособности ПЛАНА перед реализацией. Для собеседования по требованиям ПЕРЕД проверкой используйте вместо этого /grill-me-codex. НЕ для проверки уже написанного КОДА (то есть /codex-code-review или /codex:review плагина Кодекса) и НЕ для тривиальных изменений.
