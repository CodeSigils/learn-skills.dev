حلقة مراجعة PLAN عدائية مستقلة حيث يقوم Claude Code (المنشئ) وOpenAI Codex (الناقد للقراءة فقط) بوضع علامة على خطة التنفيذ قبل كتابة أي كود. استخدم هذا عندما يكون لديك بالفعل خطة أو فكرة واضحة وتريد فقط إجراء اختبار الإجهاد متعدد النماذج - لا توجد مقابلة مع المتطلبات أولاً. يقوم كلود بصياغة/تحميل الخطة في PLAN_FILE (الافتراضي PLAN.md)، ويراجعها Codex في وضع الحماية للقراءة فقط ويعيد VERDICT:APPROVED أو VERDICT:REVISE، ويقوم Claude بمراجعة وإعادة تقديمها إلى جلسة SAME Codex (السياق محفوظ) حتى APPROVED أو الوصول إلى حد أقصى MAX_ROUNDS قابل للتكوين. يوافق الإنسان على الخطة المتقاربة قبل الكود. يُستخدم عندما يقول المستخدم "/codex-plan-review"، أو "مراجعة المخطوطة لخطتي"، أو "طلب من Codex مراجعة خطتي"، أو "مناقشة هذه الخطة مع Codex"، أو "مراجعة خطة الخصومة"، أو "جعل Claude و Codex يتجادلان/يتشاجران حول الخطة"، أو على وشك بناء شيء عالي المخاطر (المصادقة، المخطط، التزامن، عمليات الترحيل، المدفوعات) ويريد فحص سلامة النموذج الثاني على PLAN قبل التنفيذ. لإجراء مقابلة موجهة بشأن المتطلبات قبل المراجعة، استخدم /grill-me-codex بدلاً من ذلك. ليس لمراجعة الكود المكتوب بالفعل (أي /codex-code-review أو /codex:review الخاص بمكون Codex الإضافي) وليس للتغييرات التافهة.
