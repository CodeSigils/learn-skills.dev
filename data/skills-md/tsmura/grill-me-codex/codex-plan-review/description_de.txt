Eine eigenständige kontradiktorische PLAN-Überprüfungsschleife, in der Claude Code (Ersteller) und OpenAI Codex (schreibgeschützter Kritiker) einen Implementierungsplan erstellen, bevor Code geschrieben wird. Verwenden Sie dies, wenn Sie BEREITS einen Plan oder eine klare Vorstellung haben und zunächst nur den modellübergreifenden Stresstest durchführen möchten – kein Anforderungsgespräch. Claude entwirft/lädt den Plan in PLAN_FILE (Standard PLAN.md), Codex überprüft ihn in einer schreibgeschützten Sandbox und gibt VERDICT:APPROVED oder VERDICT:REVISE zurück, Claude überarbeitet und übermittelt ihn erneut an die GLEICHE Codex-Sitzung (Kontext bleibt erhalten), bis APPROVED oder eine konfigurierbare MAX_ROUNDS-Grenze erreicht wird. Der Mensch genehmigt den konvergierten Plan vor dem Code. Verwenden Sie diese Option, wenn der Benutzer „/codex-plan-review“, „codex meinen Plan überprüfen lassen“, „Codex meinen Plan überprüfen lassen“, „diesen Plan mit Codex besprechen“, „kontradiktorische Planüberprüfung“, „Claude und Codex über den Plan streiten/streiten“ sagt oder kurz davor steht, etwas zu erstellen, bei dem viel auf dem Spiel steht (Authentifizierung, Schema, Parallelität, Migrationen, Zahlungen) und vor der Implementierung eine Plausibilitätsprüfung des zweiten Modells für den PLAN wünscht. Für ein geführtes Anforderungsinterview VOR der Überprüfung verwenden Sie stattdessen /grill-me-codex. NICHT zum Überprüfen von bereits geschriebenem CODE (das heißt /codex-code-review oder /codex:review des Codex-Plugins) und NICHT für triviale Änderungen.
