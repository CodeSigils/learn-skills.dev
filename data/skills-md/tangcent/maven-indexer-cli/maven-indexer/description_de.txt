Fragen Sie den lokalen Maven/Gradle-Artefaktindex vom Terminal ab. Verwenden Sie diese Option, wenn Sie einen Import sehen, die Klassendefinition jedoch nicht im Arbeitsbereich finden können (sie stammt wahrscheinlich aus einer kompilierten internen Bibliothek), wenn Sie die tatsächliche Implementierung einer internen oder nicht bekannten Bibliothek lesen müssen oder wenn Sie herausfinden müssen, welches Artefakt eine Klasse enthält, Implementierungen einer Schnittstelle ermitteln oder Proto-/Ressourcendateien in JARs überprüfen müssen. Nicht für bekannte Standardbibliotheken (java.util, Spring Core usw.) verwenden, die die KI bereits kennt.
