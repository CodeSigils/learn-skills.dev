Interrogez l’index d’artefact Maven/Gradle local à partir du terminal. À utiliser lorsque vous voyez une importation mais que vous ne trouvez pas la définition de classe dans l'espace de travail (elle provient probablement d'une bibliothèque interne compilée), lorsque vous devez lire l'implémentation réelle d'une bibliothèque interne ou peu connue, ou lorsque vous devez trouver quel artefact contient une classe, découvrir les implémentations d'une interface ou inspecter les fichiers proto/ressources dans les JAR. Ne pas utiliser pour des bibliothèques standards bien connues (java.util, Spring core, etc.) que l'IA connaît déjà.
