اكتب كود مخطط TikZ/LaTeX عالي الجودة وقابل للتجميع بتمريرة واحدة وآمن للتحرير كمهارة هندسية أساسية.  
قم بتعليم الوكيل كيفية استخدام "التخطيط البناء" (تحديد المواقع/الملاءمة/السلاسل/المرساة) بدلاً من الإحداثيات المطلقة المملوءة يدويًا، وتوفير ثمانية قيود صارمة، وأسهم أساسية، وأمثلة قبل/بعد، ونقطة إدخال للتحقق الثابت (lint.sh).  
يُستخدم عندما: كتابة أو مراجعة رمز شكل TikZ أو LaTeX، أو إصلاح مشكلات التخطيط/المحاذاة/التجاوز/السهم في المخططات، أو تخطيط TikZ، أو رمز شكل LaTeX، أو أخطاء تجميع TikZ، أو عرض أشكال CJK الصينية ككتل ذات ألوان ثابتة.
