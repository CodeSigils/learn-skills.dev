قم بكتابة رمز مخطط TikZ/LaTeX عالي الجودة ومترجم بتمريرة واحدة وآمن للتحرير كمهارة هندسية أساسية.  
قم بتعليم الوكيل استخدام "التخطيط البناء" (تحديد الموضع/الملاءمة/السلاسل/المرساة) بدلاً من ملء الإحداثيات المطلقة يدويًا، وتوفير ثمانية قيود صارمة، وأسهم أساسية، وأمثلة قبل/بعد، ونقطة إدخال للتحقق الثابت (lint.sh).  
يُستخدم عندما: كتابة أو مراجعة رمز شكل TikZ أو LaTeX، أو إصلاح مشكلات تخطيط المخطط/المحاذاة/التجاوز/السهم، أو تخطيط TikZ، أو رمز شكل LaTeX، أو أخطاء تجميع TikZ، أو عرض أشكال CJK الصينية ككتل صلبة.
