comprenant huit contraintes strictes, des flèches canoniques, des exemples avant/après et un point d'entrée pour l'analyse statique (lint.sh).  
À utiliser lorsque : l'écriture/révision du code de figure TikZ ou LaTeX, la résolution de problèmes de disposition/alignement/débordement/flèches dans les diagrammes, la mise en page TikZ, le code de figure LaTeX, les erreurs de compilation TikZ ou le rendu graphique chinois CJK sous forme de blocs de couleur unie.
