Eine spezielle Fähigkeit zur Erstellung hochwertiger Illustrationen für wissenschaftliche Arbeiten, die zwei Ausgabeformate unterstützt:  
(1) LaTeX/TikZ-Code: geeignet für Systemarchitekturdiagramme, Datenflussdiagramme, geometrische Schemata und andere strukturierte Diagramme und kann direkt in das Papier eingebettet werden;  
(2) draw.io XML: geeignet für technische Roadmaps, Forschungspräsentationsgrafiken, Illustrationen akademischer Berichte und andere äußerst dekorative Diagramme, unterstützt Farbverläufe, Schatten, Freiform-Layout und kann in app.diagrams.net geöffnet und bearbeitet werden.  

Unterstützt beide Ausgabeformate mit einem einheitlichen Workflow: Eingabe analysieren (Text/Bild/Papier) → Zeichenbefehl → Codegenerierung → Kompilierungsüberprüfung → einwandfreie Lieferung.  
Identifiziert automatisch das Fachgebiet der Arbeit und gestaltet die Illustration als Experte auf diesem Gebiet.  

Wird verwendet, wenn der Benutzer Folgendes wünscht: Papierfiguren zeichnen, Architekturdiagramme zeichnen, Flussdiagramme zeichnen, Schaltpläne zeichnen, LaTeX-Zeichnung, TikZ-Zeichnung, Papierillustration, Zeichenbefehle generieren, Bilder replizieren, Code zeichnen, wissenschaftliche Papiergrafiken, Systemarchitektur zeichnen, Protokollablauf zeichnen, Papiereinschub, TikZ-Diagramm, LaTeX-Figur, basierend auf einem Papier zeichnen, eine Figur zeichnen, mir beim Zeichnen helfen, TikZ generieren, TikZ auf Papier zeichnen, basierend auf Text zeichnen, ein Bild kopieren, dieses Bild replizieren, technische Roadmap, Forschungsarchitekturdiagramm, akademische Präsentationsgrafik, drawio, draw.io, Roadmap, Forschungsrahmendiagramm, technisches Lösungsdiagramm.
