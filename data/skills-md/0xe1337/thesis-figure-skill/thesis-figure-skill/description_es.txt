Una habilidad especializada para generar ilustraciones de alta calidad para artículos académicos, compatible con dos formatos de salida:  
(1) Código LaTeX/TikZ: adecuado para diagramas de arquitectura de sistemas, diagramas de flujo de datos, esquemas geométricos y otros gráficos estructurados, y puede incrustarse directamente en el papel;  
(2) draw.io XML: adecuado para hojas de ruta técnicas, gráficos de presentaciones de investigaciones, ilustraciones de informes académicos y otros gráficos muy decorativos, admite gradientes, sombras y diseños de forma libre, y se puede abrir y editar en app.diagrams.net.  

Admite ambos formatos de salida con un flujo de trabajo unificado: analizar la entrada (texto/imagen/papel) → comando de dibujo → generación de código → verificación de compilación → entrega impecable.
