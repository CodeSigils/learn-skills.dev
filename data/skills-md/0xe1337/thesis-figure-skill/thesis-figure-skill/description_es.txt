Una habilidad especializada para generar ilustraciones de alta calidad para artículos académicos, compatible con dos formatos de salida:  
1. **Código LaTeX/TikZ**: adecuado para gráficos estructurados, como diagramas de arquitectura de sistemas, diagramas de flujo de datos, esquemas geométricos, etc., y se puede incrustar directamente en un documento.  
2. **draw.io XML**: adecuado para gráficos muy decorativos, como hojas de ruta tecnológicas, figuras de exhibición de investigaciones, ilustraciones de presentaciones académicas, etc., con soporte para degradados, sombras, diseño de forma libre y se puede abrir y editar en app.diagrams.net.  

Ambos formatos de salida siguen un flujo de trabajo unificado: análisis de entrada (texto/imagen/papel) → instrucciones de dibujo → generación de código → verificación en tiempo de compilación → entrega perfecta.  

La herramienta detecta automáticamente el dominio del artículo y diseña la ilustración como un experto en ese campo.
