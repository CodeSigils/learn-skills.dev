Специализированный навык создания высококачественных рисунков для научных статей с поддержкой двух выходных форматов:
(1) Код LaTeX/TikZ: идеально подходит для структурированных диаграмм, таких как системные архитектуры, графики потоков данных и геометрические эскизы; готов встроить в бумаги;
(2) XML draw.io: идеально подходит для декоративных фигур, таких как технологические карты, исследовательские презентации и академические слайды; поддерживает градиенты, тени, свободный макет и может быть открыт/редактирован на app.diagrams.net.

Оба формата следуют единому рабочему процессу: анализ входных данных (текст/изображение/бумага) → инструкции по рисованию → генерация кода → компиляция и проверка → безупречная доставка.
Автоматически определяет область статьи и разрабатывает рисунки в качестве эксперта в предметной области.
