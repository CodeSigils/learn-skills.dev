Une compétence spécialisée pour générer des chiffres de haute qualité pour les articles universitaires, prenant en charge deux formats de sortie :
(1) Code LaTeX/TikZ : idéal pour les diagrammes structurés tels que les architectures de systèmes, les graphiques de flux de données et les croquis géométriques ; prêt à être intégré dans les documents ;
(2) draw.io XML : idéal pour les figures décoratives telles que les feuilles de route technologiques, les présentations de recherche et les diapositives académiques ; prend en charge les dégradés, les ombres, la mise en page gratuite et peut être ouvert/modifié sur app.diagrams.net.

Les deux formats suivent un flux de travail unifié : analyser les entrées (texte/image/papier) → instructions de dessin → génération de code → compiler et vérifier → livraison parfaite.
Identifie automatiquement le domaine du document et conçoit les chiffres en tant qu'expert du domaine.
