Une compétence spécialisée pour générer des chiffres de haute qualité pour les articles universitaires, prenant en charge deux formats de sortie :
(1) Code LaTeX/TikZ : adapté aux diagrammes structurés tels que l'architecture système, le flux de données et les illustrations géométriques, 
    intégrable directement dans les documents ;
(2) draw.io XML : convient aux figures décoratives telles que les feuilles de route technologiques, les présentations de recherche et les diapositives académiques, 
    prenant en charge les dégradés, les ombres et les mises en page gratuites, modifiables dans app.diagrams.net.
Prend en charge les deux formats avec un flux de travail unifié : analyser l'entrée (texte/image/papier) → instructions de dessin → génération de code → compiler et vérifier → livraison parfaite.
Identifie automatiquement le domaine du journal et conçoit des chiffres en tant qu'expert dans ce domaine.
