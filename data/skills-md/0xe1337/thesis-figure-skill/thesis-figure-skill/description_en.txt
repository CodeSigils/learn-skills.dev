A specialized skill for generating high‑quality illustrations for academic papers, supporting two output formats:  
(1) LaTeX/TikZ code: suitable for system architecture diagrams, data‑flow diagrams, geometric schematics, and other structured charts, and can be embedded directly in the paper;  
(2) draw.io XML: suitable for technical roadmaps, research presentation graphics, academic report illustrations, and other highly decorative charts, supporting gradients, shadows, free‑form layout, and can be opened and edited in app.diagrams.net.  

Supports both output formats with a unified workflow: analyze input (text / image / paper) → drawing command → code generation → compile verification → flawless delivery.  
Automatically identifies the paper’s field and designs the illustration as an expert in that domain.
