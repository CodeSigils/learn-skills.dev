A specialized skill for generating high‑quality illustrations for academic papers, supporting two output formats:  
1. **LaTeX/TikZ code** – suitable for structured charts such as system architecture diagrams, data‑flow diagrams, geometric schematics, etc., and can be embedded directly into a paper.  
2. **draw.io XML** – suitable for highly decorative charts such as technology roadmaps, research showcase figures, academic presentation illustrations, etc., with support for gradients, shadows, free‑form layout, and can be opened and edited in app.diagrams.net.  

Both output formats follow a unified workflow: analyze input (text / image / paper) → drawing instruction → code generation → compile‑time verification → perfect delivery.  

The tool automatically detects the paper’s domain and designs the illustration as an expert in that field.
