À utiliser lors de : la création d'une tâche asynchrone Celery dans le backend Overfitted.io, la configuration de worker.py, la distribution d'une tâche à partir d'un point de terminaison FastAPI ou l'interrogation de l'état de la tâche. Couvre la file d'attente Redis, l'initialisation de l'application Celery et le cycle de vie complet des tâches asynchrones.
