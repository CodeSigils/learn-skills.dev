Интерактивное руководство, которое обучает интерфейсу командной строки Cortex Code с нуля. Помогает нетехническим пользователям шаг за шагом освоить слэш-команды, навыки, специальный синтаксис, сеансы и многое другое. Используйте, когда пользователь хочет изучить код Cortex, начать работу с CLI или понять, как работают навыки и команды.
