Tutoriel interactif qui enseigne Cortex Code CLI à partir de zéro. Guide les utilisateurs non techniques étape par étape à travers les commandes slash, les compétences, la syntaxe spéciale, les sessions, etc. À utiliser lorsque l'utilisateur souhaite apprendre le code Cortex, démarrer avec la CLI ou comprendre le fonctionnement des compétences et des commandes.
