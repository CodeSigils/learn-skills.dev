Tutorial interactivo que enseña Snowflake Cortex Search para crear aplicaciones RAG y de búsqueda semántica. Guíe a los usuarios a través de la creación de servicios de búsqueda y sus consultas utilizando SQL y Python. Úselo cuando el usuario quiera aprender Cortex Search, búsqueda semántica, búsqueda híbrida, RAG o crear aplicaciones de búsqueda impulsadas por IA.
