برنامج تعليمي تفاعلي لتدريس Snowflake Cortex Search لبناء البحث الدلالي وتطبيقات RAG. إرشاد المستخدمين من خلال إنشاء خدمات البحث والاستعلام عنهم باستخدام SQL وPython. يُستخدم عندما يريد المستخدم تعلم Cortex Search، أو البحث الدلالي، أو البحث المختلط، أو RAG، أو إنشاء تطبيقات بحث مدعومة بالذكاء الاصطناعي.
