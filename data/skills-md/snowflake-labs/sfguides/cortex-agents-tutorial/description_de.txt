Interaktives Tutorial zum Unterrichten von Snowflake-Cortex-Agenten. Führen Sie Benutzer Schritt für Schritt durch die Erstellung von KI-Agenten, die mithilfe von Cortex Analyst, Cortex Search und benutzerdefinierten Tools strukturierte und unstrukturierte Daten orchestrieren. Verwenden Sie diese Option, wenn Benutzer Cortex-Agenten erlernen, KI-Agenten erstellen, intelligente Assistenten erstellen oder die Agenten-Orchestrierung verstehen möchten.
