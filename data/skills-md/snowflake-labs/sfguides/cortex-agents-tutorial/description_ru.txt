Интерактивное руководство по обучению агентов Snowflake Cortex. Пошаговые инструкции для пользователей по созданию агентов искусственного интеллекта, которые координируют структурированные и неструктурированные данные с помощью Cortex Analyst, Cortex Search и пользовательских инструментов. Используйте, когда пользователь хочет изучить агентов коры головного мозга, создать агентов ИИ, создать интеллектуальных помощников или понять оркестровку агентов.
