Расширенное руководство по обучению агентов Snowflake Cortex с помощью специальных инструментов. Расширяет базовое руководство за счет добавления инструментов на основе хранимых процедур (поиск запасов, калькулятор цен, сводка продуктов) наряду с Cortex Analyst и Cortex Search. Используйте, когда пользователь хочет создать агенты с собственной бизнес-логикой, хранимыми процедурами в качестве инструментов или оркестровкой нескольких инструментов.
