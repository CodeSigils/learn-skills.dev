Fortgeschrittenes Tutorial zum Erlernen von Snowflake Cortex-Agenten mit benutzerdefinierten Tools. Erweitert das Basis-Tutorial durch das Hinzufügen von auf gespeicherten Prozeduren basierenden Tools (Bestandssuche, Preisrechner, Produktzusammenfassung) neben Cortex Analyst und Cortex Search. Verwenden Sie diese Option, wenn der Benutzer Agenten mit benutzerdefinierter Geschäftslogik, gespeicherten Prozeduren als Tools oder Orchestrierung mit mehreren Tools erstellen möchte.
