Interactúe con Lynx DevTool para inspeccionar y depurar aplicaciones Lynx. Utilice esta habilidad para enumerar sesiones y clientes conectados, enviar comandos del Protocolo Chrome DevTools (CDP), enviar comandos de aplicaciones y abrir URL en Lynx. Esto es útil para depurar problemas de la interfaz de usuario, inspeccionar el estado del tiempo de ejecución o automatizar interacciones con aplicaciones Lynx.
