Interagissez avec Lynx DevTool pour inspecter et déboguer les applications Lynx. Utilisez cette compétence pour répertorier les clients et les sessions connectés, envoyer des commandes Chrome DevTools Protocol (CDP), envoyer des commandes d'application et ouvrir des URL dans Lynx. Ceci est utile pour déboguer les problèmes d'interface utilisateur, inspecter l'état d'exécution ou automatiser les interactions avec les applications Lynx.
