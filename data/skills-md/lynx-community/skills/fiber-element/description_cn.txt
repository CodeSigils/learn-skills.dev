在直接使用 @lynx-js/type-element-api 中的 FiberElement / Element PAPI API 构建 Lynx 应用程序时使用此技能，无需使用 ReactLynx JSX。它涵盖了项目设置、Rspeedy 模板-webpack 捆绑包组装、主线程 UI 树创建、后台线程事件调度、CSS 打包和常见 Element API 模式。

触发场景：
- 用户想要构建一个没有 ReactLynx、JSX 或框架的 Lynx 应用程序
- 用户要求使用 @lynx-js/type-element-api、Element PAPI、FiberElement 或 API，例如 __CreatePage、__CreateView、__CreateText、__AppendElement、__SetAttribute 或 __FlushElementTree
- 用户需要一个模板 webpack 风格的 Lynx 包，具有明确的背景、主线程和 CSS 资源
