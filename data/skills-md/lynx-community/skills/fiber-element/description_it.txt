Utilizza questa competenza quando crei applicazioni Lynx direttamente con le API PAPI FiberElement/Element da @lynx-js/type-element-api, senza ReactLynx JSX. Copre la configurazione del progetto, l'assemblaggio del pacchetto modello-webpack Rspeedy, la creazione dell'albero dell'interfaccia utente del thread principale, l'invio di eventi del thread in background, il packaging CSS e i modelli API Element comuni.

Scenari di attivazione:
- L'utente desidera creare un'app Lynx senza ReactLynx, JSX o un framework
- L'utente chiede di utilizzare @lynx-js/type-element-api, Element PAPI, FiberElement o API come __CreatePage, __CreateView, __CreateText, __AppendElement, __SetAttribute o __FlushElementTree
- L'utente necessita di un pacchetto Lynx in stile template-webpack con risorse esplicite di background, thread principale e CSS
