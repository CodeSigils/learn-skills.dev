Используйте этот навык при создании приложений Lynx напрямую с помощью API-интерфейсов FiberElement / Element PAPI из @lynx-js/type-element-api, без ReactLynx JSX. Он охватывает настройку проекта, сборку пакета шаблон-веб-пакет Rspeedy, создание дерева пользовательского интерфейса основного потока, отправку событий фонового потока, упаковку CSS и общие шаблоны Element API.

Триггерные сценарии:
- Пользователь хочет создать приложение Lynx без ReactLynx, JSX или фреймворка.
- Пользователь просит использовать @lynx-js/type-element-api, Element PAPI, FiberElement или API, такие как __CreatePage, __CreateView, __CreateText, __AppendElement, __SetAttribute или __FlushElementTree.
- Пользователю необходим пакет Lynx в стиле шаблона и веб-пакета с явным фоном, основным потоком и ресурсами CSS.
