قم بإنشاء برامج تدوين وظيفية صالحة لـ OpenUI Lang v0.5 لعارض Lynx OpenUI. يُستخدم عندما يتعين على Codex تحويل طلب واجهة مستخدم باللغة الطبيعية إلى OpenUI DSL خام لـ OpenUiRenderer، بما في ذلك واجهة مستخدم الهاتف المحمول الثابتة، أو $state، أو تدفقات أدوات الاستعلام/الطفرة، أو خطط العمل، أو المخرجات الملائمة للبث، أو المراجعات المقيدة بالكتالوج. لا تستخدمه مع JSX أو HTML أو CSS أو A2UI JSON أو تنفيذ مكونات ReactLynx الجديدة.
