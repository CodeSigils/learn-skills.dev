Создайте действительные программы функциональной нотации OpenUI Lang v0.5 для средства визуализации OpenUI Lynx. Используйте, когда Codex должен преобразовать запрос пользовательского интерфейса на естественном языке в необработанный OpenUI DSL для OpenUiRenderer, включая статический мобильный пользовательский интерфейс, $state, потоки инструментов запросов/мутаций, планы действий, потоковые выходные данные или версии, ограниченные каталогом. Не используйте для JSX, HTML, CSS, A2UI JSON или реализации новых компонентов ReactLynx.
