Genere programas válidos de notación funcional OpenUI Lang v0.5 para el renderizador Lynx OpenUI. Úselo cuando Codex deba convertir una solicitud de interfaz de usuario en lenguaje natural en OpenUI DSL sin formato para OpenUiRenderer, incluida la interfaz de usuario móvil estática, $state, flujos de herramientas de consulta/mutación, planes de acción, salida compatible con transmisión o revisiones restringidas por catálogo. No lo use para JSX, HTML, CSS, A2UI JSON o para implementar nuevos componentes de ReactLynx.
