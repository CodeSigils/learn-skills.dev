Verwenden Sie diese Option, bevor Sie Änderungen an einem Oracle-Objekt vorschlagen oder schreiben – einer Prozedur, einem Paket, einer Funktion, einem Trigger, einer Ansicht oder einer Tabelle. Die Auswirkungsanalyse steht an erster Stelle, denn was von einem Objekt abhängt, entscheidet darüber, wie sorgfältig die Änderung sein muss, und Oracle macht abhängige Objekte in einer Kaskade ungültig.
