Úselo cuando necesite comprender algo en un esquema de Oracle: buscar objetos, leer fuentes PL/SQL, firmas, columnas de tablas, DDL, buscar código o preguntar quién usa qué. Utilícelo TAMBIÉN cuando un archivo .sql, un volcado, una exportación, un script de migración o una copia de repositorio de un objeto ya parezca responder a la pregunta, incluido uno que el desarrollador le indique, porque esos archivos se derivan de la base de datos y son incorrectos en formas que se leen como correctas. La base de datos es la única fuente de verdad.
