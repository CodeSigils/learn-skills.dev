À utiliser lorsque vous avez besoin de comprendre quoi que ce soit dans un schéma Oracle : rechercher des objets, lire des sources PL/SQL, des signatures, des colonnes de table, du DDL, rechercher du code ou demander qui utilise quoi. À utiliser AUSSI lorsqu'un fichier .sql, un dump, une exportation, un script de migration ou une copie de dépôt d'un objet semble déjà répondre à la question, y compris celle vers laquelle le développeur vous pointe - parce que ces fichiers dérivent de la base de données et sont erronés d'une manière qui semble correcte. La base de données est la seule source de vérité.
