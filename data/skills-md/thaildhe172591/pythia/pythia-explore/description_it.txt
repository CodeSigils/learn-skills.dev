Utilizzare quando è necessario comprendere qualsiasi cosa in uno schema Oracle: trovare oggetti, leggere sorgenti PL/SQL, firme, colonne di tabelle, DDL, cercare codice o chiedere chi utilizza cosa. Utilizzare ANCHE quando un file .sql, un dump, un'esportazione, uno script di migrazione o una copia repository di un oggetto sembra già rispondere alla domanda, inclusa quella a cui lo sviluppatore ti indica, perché quei file si allontanano dal database e sono sbagliati in modi che vengono letti come corretti. Il database è l'unica fonte di verità.
