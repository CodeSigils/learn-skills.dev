قم بتحسين المطالبات وإعادة كتابتها باستخدام 61 إطار عمل (APE، وRACE، وCRISPE، وChain-of-Thought، وCOAST، وSMART، وما إلى ذلك). قم بتشغيل "تحسين المطالبة" أو "تحسين هذه المطالبة" أو "جعل هذه المطالبة أفضل" أو "إعادة الكتابة للذكاء الاصطناعي" أو "المطالبة السريعة" أو "الموجهة السريعة" أو "الموجهة السريعة" أو "الموجهة السريعة" أو أي شيء آخر تعليمات غامضة/قصيرة يريد المستخدم تحويلها إلى مطالبة عالية الجودة - حتى لو قال المستخدم فقط "اجعل هذا أكثر وضوحًا" أو "ساعدني في كتابة هذا". يتم تشغيله أيضًا عندما يلصق المستخدم نصًا أوليًا ويطلب إصدارًا منظمًا جاهزًا للذكاء الاصطناعي، أو يعبر عن عدم الرضا عن جودة مخرجات الذكاء الاصطناعي دون تسمية الإصلاح. استخدم هذه المهارة دائمًا عندما يُدخل المستخدم تعليمات غامضة، أو يحتاج إلى تحسين سريع، أو عندما يكون غير راضٍ عن جودة مخرجات الذكاء الاصطناعي.
