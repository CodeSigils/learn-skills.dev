OCR (reconocimiento óptico de caracteres) para extraer texto de imágenes.
Úselo cuando el usuario necesite: (1) extraer texto de capturas de pantalla, (2) reconocer códigos captcha, 
(3) Leer texto de fotografías, (4) Convertir archivos PDF escaneados en texto, (5) Identificar números/letras de imágenes.
Admite Tesseract OCR con Docker, preprocesamiento Python OpenCV y flujo de decisiones para el reconocimiento de captcha.
