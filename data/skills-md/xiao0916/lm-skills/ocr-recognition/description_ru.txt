OCR (оптическое распознавание символов) для извлечения текста из изображений.
Используйте, когда пользователю необходимо: (1) извлечь текст из снимков экрана, (2) распознать коды проверки, 
(3) Чтение текста с фотографий, (4) Преобразование отсканированных PDF-файлов в текст, (5) Определение цифр/букв на изображениях.
Поддерживает Tesseract OCR с Docker, предварительную обработку Python OpenCV и поток принятия решений для распознавания капчи.
