Интеллектуальный анализ кода компонента React, определение разделяемых подкомпонентов и создание отдельных файлов компонентов. Варианты использования: (1) оптимизация структуры больших компонентов, созданных с помощью psd-json-preview, (2) разделение одного сложного компонента на несколько более мелких компонентов, которые можно повторно использовать, (3) автоматическое создание стандартизированных компонентов с помощью интерфейсов Props.
