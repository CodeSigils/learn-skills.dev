قم بتوجيه الذكاء الاصطناعي لتشغيل البرامج النصية باستخدام إستراتيجية Docker-first. عندما يحتاج المستخدم إلى تنفيذ Python أو Node.js أو البرامج النصية الأخرى، فإن هذه المهارة تساعد الذكاء الاصطناعي في تحديد ما إذا كان سيتم استخدام حاوية Docker (المفضلة) أو التنفيذ المحلي بناءً على اكتشاف البيئة وتوافق الإصدار.
