Herramienta de optimización semántica HTML que convierte automáticamente etiquetas HTML genéricas (div, span) en etiquetas semánticas HTML5 (encabezado, navegación, principal, artículo, botón, etc.). Identifica de forma inteligente las funciones semánticas de los elementos en función de los nombres de clases CSS y admite la configuración de reglas personalizadas.
