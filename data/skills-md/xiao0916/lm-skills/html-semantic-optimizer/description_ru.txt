Инструмент семантической оптимизации HTML, который автоматически преобразует общие теги HTML (div, span) в семантические теги HTML5 (заголовок, навигация, главная, статья, кнопка и т. д.). Интеллектуальное определение семантических ролей элементов на основе имен классов CSS и поддержка настройки пользовательских правил.
