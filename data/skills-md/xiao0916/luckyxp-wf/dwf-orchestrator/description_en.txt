Use when the user wants to start, continue, resume, or restart a DWF development workflow, or needs to orchestrate `.dwf/state.json`, the specs queue, stage advancement, iteration addition/splitting/jumping the queue, pending confirmations, or reconstruction of `state.json`. As long as `.dwf/state.json` exists or the user requests progression according to DWF/development workflow steps, this skill must be used. If the user only separately requests generating requirement documents, design drafts, requirement analysis, technical solutions, implementation lists, or code, and has no workflow state/queue orchestration need, prioritize the corresponding `dwf‑xxx` sub‑skill. Trigger phrases include start project, continue dev‑workflow, resume workflow, restart, jump the queue, split iteration, advance to the next stage.
