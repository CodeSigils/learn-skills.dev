사용자가 DWF 개발 작업 흐름을 시작, 계속, 재개 또는 다시 시작하려고 하거나 '.dwf/state.json', 사양 대기열, 단계 발전, 대기열 반복 추가/분할/점프, 보류 중인 확인 또는 'state.json' 재구성을 조정해야 할 때 사용합니다. `.dwf/state.json`이 존재하거나 사용자가 DWF/개발 작업 흐름 단계에 따라 진행을 요청하는 한 이 기술을 사용해야 합니다. 사용자가 요구 사항 문서, 설계 초안, 요구 사항 분석, 기술 솔루션, 구현 목록 또는 코드 생성만 별도로 요청하고 워크플로 상태/대기열 오케스트레이션이 필요하지 않은 경우 해당 'dwf-xxx' 하위 기술의 우선순위를 지정합니다. 트리거 문구에는 프로젝트 시작, 개발 워크플로 계속, 워크플로 재개, 다시 시작, 대기열 점프, 반복 분할, 다음 단계로 진행이 포함됩니다.
