When users need to organize ideas, requirement descriptions, product requirements, project background, Markdown, plain text, or local documents into a DWF workflow‑style requirement document, this skill must be used. It is responsible for collecting and clarifying requirements, generating `01-需求/需求文档.md` under the target spec directory according to `references/requirements_template.md`, and requesting user confirmation. It applies to scenarios such as “generate requirement document,” “organize PRD,” “write requirement document first,” “standardize requirements,” “extract requirement phase,” and similar. It can run independently or as part of a dwf‑orchestrator orchestrated workflow (entering workflow mode when the spec in `state.json` has `status: active` and `current_step: requirements`).
