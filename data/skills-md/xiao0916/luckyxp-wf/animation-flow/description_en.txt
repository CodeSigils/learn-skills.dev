Generate previewable animation components for web pages, with the target framework determined by AI detection of the project. Use this skill when a user wants to implement preset web animation effects in React/Vue/Svelte/native projects—even if “animation” isn’t explicitly mentioned, it should still be triggered. It covers five categories of effects: 1) Number scrolling/counting (numbers jumping from 0 to a target value, incremental statistics, data achievement displays); 2) Hover light effects (card light sweep, cursor‑following halo, product‑card hover light sweep); 3) Accordion (horizontal collapsible panels, hover‑to‑expand and enlarge, category displays); 4) Fixed‑screen/sticky scrolling (left fixed right scroll, sticky titles that narrate with scrolling, Apple‑style website scroll layout); 5) Typewriter/letter‑by‑letter animation (text characters popping out one by one, blinking cursor, terminal‑style output, slogan carousel). The skill provides previewable HTML templates, which are converted into standards‑compliant component code according to component‑spec.md. Not applicable to: animation/effect debugging (Framer Motion stutter, CSS animation bugs), route‑change transition animations, loading spinners, data charts, carousels, SVG strokes, Three.js/3D particles, or purely backend/no‑frontend tasks.
