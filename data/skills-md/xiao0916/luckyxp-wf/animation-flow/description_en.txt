Generate previewable animation components for web pages, with the target framework determined by AI project detection. Use this skill when users need to implement preset web animation effects into React/Vue/Svelte/native projects—even if "animation" isn’t explicitly mentioned, it should still be triggered. Covers five categories of effects: 1) Number scrolling/counting (numbers jumping from 0 to the target value, incremental statistics, data achievement displays); 2) Hover light effects (card sweep light, mouse‑following halo, product card hover light sweep); 3) Accordion (horizontal collapsing panels, hover to expand and enlarge, category display); 4) Fixed‑screen scrolling/sticky scrolling (left fixed right scroll, sticky titles narrating with scroll, Apple‑website‑style scrolling layout); 5) Typewriter/character‑by‑character animation (text popping out one by one, blinking cursor, terminal‑style output, slogan carousel). The skill provides previewable HTML templates, converting them into specification‑compliant component code according to component‑spec.md. Not applicable for: animation/effect debugging (Framer Motion stutter, CSS animation bugs), route transition animations, loading spinners, data charts, carousels, SVG strokes, Three.js/3D particles, or purely backend/no‑frontend tasks.
