Создавайте доступные для предварительного просмотра компоненты анимации для веб-страниц, при этом целевая платформа определяется путем обнаружения проекта ИИ. Используйте этот навык, когда пользователь хочет реализовать предустановленные эффекты веб-анимации в проектах React/Vue/Svelte/native — даже если «анимация» явно не упоминается, ее все равно следует запускать. Он охватывает пять категорий эффектов: 1) Прокрутка/подсчет чисел (переход чисел от 0 к целевому значению, дополнительная статистика, отображение достижения данных); 2) световые эффекты при наведении (свет на карточке, ореол за курсором, свет при наведении на карточку продукта); 3) Аккордеон (горизонтальные складные панели, разворачивание и увеличение при наведении, отображение категорий); 4) Фиксированный экран/закрепленная прокрутка (фиксированная прокрутка слева направо, прикрепленные заголовки, рассказывающие с помощью прокрутки, макет прокрутки веб-сайта в стиле Apple); 5) Анимация пишущей машинки/буквы за буквой (текстовые символы появляются один за другим, мигающий курсор, вывод в стиле терминала, карусель слоганов). Этот навык предоставляет доступные для предварительного просмотра HTML-шаблоны, которые преобразуются в соответствующий стандартам код компонента в соответствии с компонентом-spec.md. Неприменимо к: отладке анимации/эффектов (заикание Framer Motion, ошибки CSS-анимации), анимации перехода при изменении маршрута, загрузке счетчиков данных, диаграммам данных, каруселям, обводкам SVG, частицам Three.js/3D или чисто серверным задачам/без внешнего интерфейса.
