Cuando un usuario necesita ejecutar una de las etapas del flujo de trabajo DWF (análisis de requisitos, solución técnica o lista de verificación de implementación) por separado, se debe utilizar esta capacidad. Genera solo un documento de una sola etapa en el directorio de especificaciones de destino según el `current_step` actual o la etapa de destino confirmada por el usuario, y se detiene después de solicitar la confirmación del usuario. Es adecuado para escenarios como "desglose de requisitos", "solución técnica", "lista de verificación de implementación", "generar solución técnica", "crear lista de verificación de implementación" y "extraer una etapa de desarrollo específica". Puede ejecutarse de forma independiente o como parte de un flujo de trabajo orquestado por dwf-orchestrator (ingresando al modo de flujo de trabajo cuando una especificación en `state.json` tiene `status: active` y `current_step` es `breakdown`/`plans`/`todos`).
