When the user needs to execute one of the stages of the DWF workflow—requirements analysis, technical solution, or implementation checklist—separately, this capability must be used. It generates only the document for the corresponding stage in the target spec directory according to the current `current_step` or the target stage confirmed by the user, then stops after requesting user confirmation. It is suitable for scenarios such as “requirements breakdown,” “technical solution,” “implementation checklist,” “generate technical solution,” “create implementation checklist,” “extract a specific development stage,” and so on. It can run independently or as part of a dwf-orchestrator‑orchestrated workflow (entering workflow mode when the spec in `state.json` has `status: active` and `current_step` is `breakdown`, `plans`, or `todos`).
