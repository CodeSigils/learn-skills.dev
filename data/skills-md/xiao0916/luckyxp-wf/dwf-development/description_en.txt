When a user needs to execute one of the DWF workflow stages—requirements analysis, technical solution, or implementation checklist—separately, this capability must be used. It generates only a single stage document under the target spec directory based on the current `current_step` or the target stage confirmed by the user, and stops after requesting user confirmation. It is suitable for scenarios such as “requirements breakdown,” “technical solution,” “implementation checklist,” “generate technical solution,” “create implementation checklist,” and “extract a specific development stage.” It can run independently or as part of a workflow orchestrated by dwf-orchestrator (entering workflow mode when a spec in `state.json` has `status: active` and `current_step` is `breakdown`/`plans`/`todos`).
