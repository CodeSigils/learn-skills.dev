عند مواجهة مشكلات سلسلة الأدوات أثناء التطوير، أو الاختبار، أو إنشاء الوثائق، أو إنشاء المهارات أو تعديلها، أو تحرير الملفات، أو عمليات المتصفح، أو لقطات الشاشة، أو البناء، أو التحقق من الصحة، أو تنفيذ البرنامج النصي، أو تنفيذ أوامر PowerShell/Python/Node، وما إلى ذلك، يجب استخدام هذه المهارة. وينطبق هذا على سيناريوهات مثل استثناءات مساعد وضع الحماية، أو مشكلات الأذونات أو المسار، أو فشل application_patch، أو فشل البرنامج النصي للتهيئة الجزئي، أو التبعيات المفقودة، أو أدوات التحقق من الصحة التي لا يمكن تشغيلها، أو نص Windows PowerShell الصيني المشوه، أو التشفير الذي تم التعرف عليه بشكل خاطئ، أو معلمات الأوامر غير المتوافقة، أو فشل الشبكة أو التثبيت، أو التحقق البديل، والحالات التي يطلب فيها المستخدم "تسجيل المشكلة الأخيرة" أو "توثيق الحل". إذا كانت هذه المهارة لا تغطي المشكلة الحالية، فيجب عليك بعد حلها كتابة التجربة القابلة لإعادة الاستخدام مرة أخرى في هذه المهارة أو تعليمات التقييم/الاستخدام الخاصة بها.
