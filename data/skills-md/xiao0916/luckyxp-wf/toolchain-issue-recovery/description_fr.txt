Lorsque vous rencontrez des problèmes de chaîne d'outils pendant le développement, les tests, la génération de documentation, la création ou la modification de compétences, l'édition de fichiers, les opérations du navigateur, les captures d'écran, la construction, la validation, l'exécution de scripts, l'exécution de commandes PowerShell/Python/Node, etc., cette compétence doit être utilisée. Il s'applique à des scénarios tels que les exceptions de l'assistant sandbox, les problèmes d'autorisation ou de chemin, les échecs d'apply_patch, les échecs partiels du script d'initialisation, les dépendances manquantes, les outils de validation qui ne peuvent pas s'exécuter, le texte chinois tronqué de Windows PowerShell, le codage mal identifié, les paramètres de commande incompatibles, les échecs de réseau ou d'installation, les vérifications alternatives et les cas où l'utilisateur demande « d'enregistrer le problème récent » ou de « documenter la solution ». Si cette compétence ne couvre pas le problème actuel, après l'avoir résolu, vous devez réécrire l'expérience réutilisable dans cette compétence ou dans ses instructions d'évaluation/d'utilisation.
