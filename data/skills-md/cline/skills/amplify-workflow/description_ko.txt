AWS Amplify Gen2(TypeScript 코드 우선)를 사용하여 전체 스택 웹 및 모바일 앱을 구축하고 배포합니다. 인증(Cognito), 데이터(스키마 모델링, 열거형 유형, 관계, 권한 부여 규칙을 포함하는 AppSync/DynamoDB), 스토리지(S3), 함수, API 및 AI(Amplify AI Kit with Bedrock)를 다룹니다. React, Next.js, Vue, Angular, React Native, Flutter, Swift 및 Android를 지원합니다. Amplify Gen2 주제에 대해 항상 이 기술을 사용하십시오. 심지어 알고 있다고 생각하는 질문에도 마찬가지입니다. 여기에는 일반적인 실수를 방지하는 검증된 버전별 패턴이 포함되어 있습니다. 트리거 시기: 사용자가 Amplify Gen2를 언급한 경우; 프로젝트에는 amplify/ 디렉토리 또는 amplify_outputs가 있습니다. 코드는 @aws-amplify 패키지를 가져옵니다. 사용자가 정의 백엔드, 정의 인증, 정의 데이터, 정의 저장 또는 npx ampx에 대해 질문합니다. 건너뛰기: Amplify Gen1(Amplify CLI v6), Amplify가 없는 독립형 SAM/CDK(aws-serverless 사용), Amplify AI Kit가 없는 직접 Bedrock(Bedrock 사용).
