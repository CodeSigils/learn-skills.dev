Cree e implemente aplicaciones web y móviles de pila completa con AWS Amplify Gen2 (primero el código TypeScript). Cubre autenticación (Cognito), datos (AppSync/DynamoDB, incluido el modelado de esquemas, tipos de enumeración, relaciones, reglas de autorización), almacenamiento (S3), funciones, API e IA (Amplify AI Kit con Bedrock). Admite React, Next.js, Vue, Angular, React Native, Flutter, Swift y Android. Utilice siempre esta habilidad para los temas de Amplify Gen2, incluso para preguntas que cree conocer; contiene patrones validados y específicos de la versión que evitan errores comunes. DISPARAR cuando: el usuario menciona Amplify Gen2; el proyecto tiene el directorio amplificar/ o amplificar_salidas; el código importa paquetes @aws-amplify; el usuario pregunta sobre defineBackend, defineAuth, defineData, defineStorage o npx ampx. SALTAR: Amplify Gen1 (amplify CLI v6), SAM/CDK independiente sin Amplify (use aws-serverless), Direct Bedrock sin Amplify AI Kit (use Bedrock).
