Créez et déployez des applications Web et mobiles complètes avec AWS Amplify Gen2 (code TypeScript d'abord). Couvre l'authentification (Cognito), les données (AppSync/DynamoDB, y compris la modélisation de schéma, les types d'énumération, les relations, les règles d'autorisation), le stockage (S3), les fonctions, les API et l'IA (Amplify AI Kit with Bedrock). Prend en charge React, Next.js, Vue, Angular, React Native, Flutter, Swift et Android. Utilisez toujours cette compétence pour les sujets Amplify Gen2 – même pour les questions que vous pensez connaître – elle contient des modèles validés et spécifiques à la version qui évitent les erreurs courantes. DÉCLENCHEMENT lorsque : l'utilisateur mentionne Amplify Gen2 ; le projet a un répertoire amplify/ ou amplify_outputs ; le code importe les packages @aws-amplify ; l'utilisateur pose des questions sur DéfinirBackend, DéfinirAuth, DéfinirData, DéfinirStorage ou Npx Ampx. SAUTER : Amplify Gen1 (amplify CLI v6), SAM/CDK autonome sans Amplify (utilisez aws-serverless), direct Bedrock sans Amplify AI Kit (utilisez bedrock).
