Создавайте и развертывайте полнофункциональные веб- и мобильные приложения с помощью AWS Amplify Gen2 (сначала код TypeScript). Охватывает аутентификацию (Cognito), данные (AppSync/DynamoDB, включая моделирование схемы, типы перечислений, связи, правила авторизации), хранилище (S3), функции, API и искусственный интеллект (Amplify AI Kit с Bedrock). Поддерживает React, Next.js, Vue, Angular, React Native, Flutter, Swift и Android. Всегда используйте этот навык для тем Amplify Gen2 — даже для вопросов, которые, как вам кажется, вы знаете — он содержит проверенные шаблоны для конкретной версии, которые предотвращают распространенные ошибки. ТРИГГЕР, когда: пользователь упоминает Amplify Gen2; в проекте есть каталог amplify/ или amplify_outputs; код импортирует пакеты @aws-amplify; пользователь спрашивает об defineBackend, defineAuth, defineData, defineStorage или npx ampx. ПРОПУСТИТЬ: Amplify Gen1 (amplify CLI v6), автономный SAM/CDK без Amplify (используйте aws-serverless), прямой Bedrock без Amplify AI Kit (используйте Bedrock).
