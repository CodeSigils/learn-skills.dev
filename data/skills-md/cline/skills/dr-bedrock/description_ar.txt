استكشاف أخطاء مصادقة AWS Bedrock المحلية وتكوين المنطقة لـ Cline CLI وإصلاحها مثل Dr. Bedrock. يُستخدم عندما يقوم المستخدمون بالإبلاغ عن أخطاء Bedrock CLI، أو مشكلات ملف تعريف AWS/السلسلة الافتراضية، أو فشل بيانات اعتماد credential_process/SSO/IAM، أو المنطقة المفقودة، أو AccessDenied، أو الوصول إلى النموذج، أو مشكلات تكوين الموفر.
