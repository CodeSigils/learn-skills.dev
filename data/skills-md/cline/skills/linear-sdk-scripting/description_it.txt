Esegui azioni in Linear (leggi, crea, aggiorna, cerca problemi, progetti, commenti, team, cicli, etichette, ecc.) scrivendo ed eseguendo piccoli script Node sull'SDK TypeScript @linear/sdk ufficiale con una chiave API personale. Utilizzalo quando l'utente desidera eseguire un lavoro Linear dal terminale senza il server Linear MCP o chiede di elencare/aprire/creare/aggiornare/chiudere problemi Linear, lasciare commenti o interrogare team, progetti, utenti o stati del flusso di lavoro.
