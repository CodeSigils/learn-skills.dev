قم بتنفيذ الإجراءات الخطية (القراءة، والإنشاء، والتحديث، ومشكلات البحث، والمشاريع، والتعليقات، والفرق، والدورات، والتسميات، وما إلى ذلك) عن طريق كتابة وتشغيل نصوص Node النصية الصغيرة مقابل @linear/sdk TypeScript SDK الرسمي باستخدام مفتاح API شخصي. استخدم هذا عندما يريد المستخدم القيام بعمل خطي من الجهاز بدون خادم Linear MCP، أو يطلب إدراج/فتح/إنشاء/تحديث/إغلاق المشكلات الخطية، أو ترك التعليقات، أو الاستعلام عن الفرق، أو المشاريع، أو المستخدمين، أو حالات سير العمل.
