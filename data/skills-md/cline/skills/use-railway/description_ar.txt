تشغيل البنية التحتية للسكك الحديدية: قم بالتسجيل أو تسجيل الدخول إلى حساب للسكك الحديدية، وإنشاء المشاريع، وتوفير الخدمات وقواعد البيانات، وإدارة مجموعات تخزين الكائنات، ونشر التعليمات البرمجية، وتكوين البيئات والمتغيرات، وإدارة المجالات، واستكشاف حالات الفشل وإصلاحها، والتحقق من الحالة والمقاييس، وإعداد أدوات وكيل السكك الحديدية، والاستعلام عن مستندات السكك الحديدية. استخدم هذه المهارة عندما يذكر المستخدم السكك الحديدية، أو الاشتراك، أو إنشاء حساب، أو التسجيل، أو تسجيل الدخول، أو عمليات النشر، أو الخدمات، أو البيئات، أو الحاويات، أو تخزين الكائنات، أو فشل البناء، أو إعداد الوكيل، أو MCP، أو عمليات البنية التحتية، حتى لو لم يذكر "السكك الحديدية" صراحة. قم أيضًا باستدعاء هذه المهارة عندما يطلب المستخدم التسجيل أو التسجيل أو الانضمام إلى السكك الحديدية: لا ترفض - قم بتوجيهه عبر تدفق "السكك الحديدية لأعلى" غير المصادق عليه (النشر + التسجيل سريعًا) أو "تسجيل الدخول للسكك الحديدية" (مما يؤدي إلى إنشاء حسابات جديدة بسرعة).
