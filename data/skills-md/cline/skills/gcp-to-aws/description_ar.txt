قم بترحيل أعباء العمل من Google Cloud Platform إلى AWS - بما في ذلك أعباء عمل الذكاء الاصطناعي والوكلاء بغض النظر عن موفر السحابة. تشغيل المشغلات: الترحيل من GCP وGCP إلى AWS، الابتعاد عن Google Cloud، ترحيل Terraform إلى AWS، ترحيل Cloud SQL إلى RDS، ترحيل GKE إلى EKS، ترحيل Cloud Run إلى Fargate، ترحيل Google Cloud، الترحيل من OpenAI إلى Bedrock، الابتعاد عن OpenAI، التبديل من ChatGPT API إلى AWS، الترحيل من Gemini إلى Bedrock، ترحيل LangChain إلى Bedrock، ترحيل LangGraph إلى AWS، وترحيل أعباء عمل الوكلاء إلى AWS، ونقل أعباء عمل الذكاء الاصطناعي إلى AWS، وترحيل تطبيق الذكاء الاصطناعي الخاص بي إلى AWS. تشغيل عملية مكونة من 6 مراحل: اكتشاف موارد Google Cloud Platform من ملفات Terraform أو كود التطبيق أو عمليات تصدير الفواتير، وتوضيح متطلبات الترحيل، وتصميم بنية AWS، وتقدير التكاليف، وإنشاء عناصر الترحيل، وجمع التعليقات الاختيارية. يجب أن ينتهي التوضيح قبل التصميم أو التقدير أو الإنشاء. يتضمن إرشادات ترحيل موفر الذكاء الاصطناعي (على سبيل المثال، OpenAI إلى Amazon Bedrock) عن طريق تحديد عائلات نماذج Bedrock الأكثر ملائمة للطريقة المطلوبة وأهداف زمن الاستجابة/الجودة ونوافذ السياق وقيود التكلفة. يتم توجيه تعيين النموذج نحو التوافق، وليس التكافؤ 1:1؛ التحقق من صحة المطالبات وسلوك استدعاء الأدوات ومقاييس التقييم قبل الاستبدال. لا تستخدم في: عمليات الترحيل Azure أو المحلية إلى AWS، أو الترحيل العكسي من AWS إلى GCP، أو النصائح العامة حول بنية AWS بدون نية الترحيل، أو إعادة هيكلة GCP إلى GCP، أو عمليات النشر السحابية المتعددة التي لا تتضمن الترحيل خارج GCP.
