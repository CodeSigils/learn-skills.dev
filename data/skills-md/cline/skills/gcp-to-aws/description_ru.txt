Переносите рабочие нагрузки с Google Cloud Platform на AWS, включая рабочие нагрузки искусственного интеллекта и агентов, независимо от поставщика облачных услуг. Срабатывает: миграция из GCP, GCP в AWS, переход из Google Cloud, миграция Terraform в AWS, миграция Cloud SQL в RDS, миграция GKE в EKS, миграция Cloud Run в Fargate, миграция Google Cloud, миграция из OpenAI в Bedrock, отход от OpenAI, переключение с ChatGPT API на AWS, миграция из Gemini в Bedrock, миграция LangChain в Bedrock, миграция LangGraph в AWS, миграция агентных рабочих нагрузок в AWS, перенесите рабочие нагрузки ИИ на AWS, перенесите мое приложение ИИ на AWS. Запускает шестиэтапный процесс: обнаруживает ресурсы GCP из файлов Terraform, кода приложения или экспорта счетов, уточняет требования к миграции, проектирует архитектуру AWS, оценивает затраты, генерирует артефакты миграции и собирает дополнительные отзывы. Уточнение должно завершиться до проектирования, оценки или создания. Включает руководство по миграции поставщиков ИИ (например, OpenAI на Amazon Bedrock) путем выбора наиболее подходящих семейств моделей Bedrock с учетом требуемой модальности, целевых значений задержки/качества, контекстных окон и ограничений стоимости. Сопоставление моделей основано на совместимости, а не на четности 1:1; проверять подсказки, поведение при вызове инструментов и оценивать показатели перед переключением. Не используйте для: Azure или локальной миграции на AWS, обратной миграции с AWS на GCP, общих рекомендаций по архитектуре AWS без намерения миграции, рефакторинга GCP на GCP или развертываний в нескольких облаках, которые не включают миграцию с GCP.
