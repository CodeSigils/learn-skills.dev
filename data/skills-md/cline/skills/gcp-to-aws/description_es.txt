Migre cargas de trabajo de Google Cloud Platform a AWS, incluidas cargas de trabajo de inteligencia artificial y agentes, independientemente del proveedor de la nube. Activadores activados: migrar de GCP, GCP a AWS, salir de Google Cloud, migrar Terraform a AWS, migrar Cloud SQL a RDS, migrar GKE a EKS, migrar Cloud Run a Fargate, migración de Google Cloud, migrar de OpenAI a Bedrock, salir de OpenAI, cambiar de ChatGPT API a AWS, migrar de Gemini a Bedrock, migrar LangChain a Bedrock, migrar LangGraph a AWS, migrar cargas de trabajo agentes a AWS, mover cargas de trabajo de IA a AWS, migrar mi aplicación de IA a AWS. Ejecuta un proceso de 6 fases: descubre recursos de GCP a partir de archivos Terraform, código de aplicación o exportaciones de facturación, aclara los requisitos de migración, diseña la arquitectura de AWS, estima costos, genera artefactos de migración y recopila comentarios opcionales. Aclarar debe terminar antes de Diseñar, Estimar o Generar. Incluye orientación para la migración de proveedores de IA (por ejemplo, OpenAI a Amazon Bedrock) mediante la selección de familias de modelos Bedrock que más se ajusten a la modalidad requerida, objetivos de latencia/calidad, ventanas de contexto y restricciones de costos. El mapeo del modelo está guiado por la compatibilidad, no por la paridad 1:1; valide las indicaciones, el comportamiento de llamada de herramientas y evalúe las métricas antes de la transición. No lo use para: migraciones de Azure o locales a AWS, migración inversa de AWS a GCP, asesoramiento general sobre arquitectura de AWS sin intención de migración, refactorización de GCP a GCP o implementaciones de múltiples nubes que no impliquen migrar fuera de GCP.
