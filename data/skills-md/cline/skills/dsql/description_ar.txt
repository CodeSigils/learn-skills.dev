البناء باستخدام Aurora DSQL — إدارة المخططات، وتنفيذ الاستعلامات، والتعامل مع عمليات الترحيل، وتشخيص خطط الاستعلام، وتحميل البيانات، وتطوير التطبيقات باستخدام قاعدة بيانات SQL موزعة بدون خادم. يغطي مصادقة IAM، وأنماط المستأجرين المتعددين، وتحويل مخطط MySQL إلى DSQL وPostgreSQL إلى DSQL، وإنشاء كود استبدال FK، وأنماط إعادة محاولة OCC، وترحيل ORM (Django/Hibernate/Rails)، وعمليات DDL، وإمكانية شرح خطة الاستعلام، والتحقق من توافق SQL، وتحميل البيانات المجمعة. مشغلات على عبارات مثل: DSQL، Aurora DSQL، قاعدة بيانات SQL الموزعة، قاعدة بيانات متوافقة مع PostgreSQL بدون خادم، الترحيل إلى DSQL، خطة استعلام DSQL، DSQL EXPLAIN ANALYZE، DSQL ENUM، المفتاح الخارجي DSQL، إعادة محاولة DSQL OCC، DSQL متعدد المناطق، DSQL JSONB، DSQL GIN Index، التحميل إلى DSQL، تحميل CSV إلى DSQL، تحميل DSQL بالجملة، أورورا-dsql-محمل.
