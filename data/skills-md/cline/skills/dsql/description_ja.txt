Aurora DSQL を使用して構築する — サーバーレスの分散 SQL データベースを使用して、スキーマの管理、クエリの実行、移行の処理、クエリプランの診断、データのロード、アプリケーションの開発を行います。 IAM 認証、マルチテナント パターン、MySQL から DSQL および PostgreSQL から DSQL へのスキーマ変換、FK 置換コード生成、OCC 再試行パターン、ORM 移行 (Django/Hibernate/Rails)、DDL 操作、クエリ プランの説明可能性、SQL 互換性検証、バルク データ ロードをカバーします。次のようなフレーズでトリガーされます: DSQL、Aurora DSQL、分散 SQL データベース、サーバーレス PostgreSQL 互換データベース、DSQL への移行、DSQL クエリ プラン、DSQL EXPLAIN ANALYZE、DSQL ENUM、DSQL 外部キー、DSQL OCC 再試行、DSQL マルチリージョン、DSQL JSONB、DSQL GIN インデックス、DSQL へのロード、DSQL への CSV のロード、DSQL の一括ロード、aurora-dsql-loader。
