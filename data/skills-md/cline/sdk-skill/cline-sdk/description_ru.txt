Комплексные навыки Cline SDK для создания агентов искусственного интеллекта. Охватывает непосредственное время выполнения агента, сеансы ClineCore, специальные инструменты, плагины, события, поставщиков LLM, планирование, многоагентные группы и производственное развертывание. Используйте для любой задачи, связанной с @cline/sdk или его подпакетами.
