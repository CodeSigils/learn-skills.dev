Realice una prueba automática de un cambio de función móvil o corrección de errores después de la implementación en "aplicaciones/móviles". Utilícelo siempre que el usuario solicite verificar un cambio de dispositivo móvil, ejecutar la aceptación del simulador, realizar una prueba de humo de un PR móvil o proporcionar una prueba de captura de pantalla para una solución móvil. Esta habilidad decide entre el modo de producción y API local, inicia el servidor de seguimiento local cuando es necesario, crea una aplicación de lanzamiento, usa Maestro solo para iniciar el registro para trabajos que no son de autenticación, luego cambia a validación visual basada en capturas de pantalla y devuelve evidencia de captura de pantalla.
