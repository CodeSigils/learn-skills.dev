Самостоятельно протестируйте изменение мобильной функции или исправление ошибки после реализации в `apps/mobile`. Используйте это всякий раз, когда пользователь просит подтвердить изменение мобильного устройства, запустить прием симулятора, провести дымовое тестирование мобильного PR или предоставить подтверждение снимка экрана для мобильного исправления. Этот навык выбирает между режимом prod и local API, при необходимости запускает локальный ведомый сервер, создает приложение для выпуска, использует Maestro только для начальной регистрации для работы без аутентификации, затем переключается на визуальную проверку на основе снимков экрана и возвращает подтверждение скриншота.
