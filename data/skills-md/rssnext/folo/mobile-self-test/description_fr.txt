Auto-testez une modification de fonctionnalité mobile ou une correction de bogue après la mise en œuvre dans « apps/mobile ». Utilisez-le chaque fois que l'utilisateur demande de vérifier une modification mobile, d'exécuter l'acceptation du simulateur, de tester un PR mobile ou de fournir une preuve de capture d'écran pour un correctif mobile. Cette compétence décide entre le mode production et le mode API locale, démarre le serveur de suivi local si nécessaire, crée une application de version, utilise Maestro uniquement pour amorcer l'enregistrement pour un travail non authentifié, puis passe à la validation visuelle basée sur une capture d'écran et renvoie des preuves de capture d'écran.
