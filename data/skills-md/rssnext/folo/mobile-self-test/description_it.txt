Testa automaticamente la modifica di una funzionalità mobile o la correzione di un bug dopo l'implementazione in "app/mobile". Utilizzalo ogni volta che l'utente chiede di verificare una modifica mobile, eseguire l'accettazione del simulatore, effettuare uno smoke test su un PR mobile o fornire una prova di screenshot per una correzione mobile. Questa competenza decide tra la modalità API prod e quella locale, avvia il server di follow-up locale quando necessario, crea un'app di rilascio, utilizza Maestro solo per avviare la registrazione per lavori non di autenticazione, quindi passa alla convalida visiva basata su screenshot e restituisce prove di screenshot.
