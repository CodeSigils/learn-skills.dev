Testen Sie eine Funktionsänderung oder Fehlerbehebung für Mobilgeräte nach der Implementierung in „apps/mobile“ selbst. Verwenden Sie dies immer dann, wenn der Benutzer eine mobile Änderung verifizieren, eine Simulatorabnahme durchführen, eine mobile PR einem Rauchtest unterziehen oder einen Screenshot-Beweis für eine mobile Korrektur bereitstellen möchte. Dieser Skill entscheidet zwischen dem Prod- und dem lokalen API-Modus, startet bei Bedarf den lokalen Follow-Server, erstellt eine Release-App, verwendet Maestro nur zur Bootstrap-Registrierung für nicht authentifizierte Arbeiten, wechselt dann zur Screenshot-gesteuerten visuellen Validierung und gibt Screenshot-Beweise zurück.
