Appliquez-le lors de la conception d'applications de configuration VTEX IO avec le générateur de configuration ou lorsqu'une application de service doit recevoir une configuration structurée via le contexte d'exécution. Couvre la séparation entre les applications de service et les applications de configuration, schema.json et configuration.json, settingsType et la lecture de la configuration injectée via ctx.vtex.settings. À utiliser pour la configuration de services partagés, le cycle de vie de configuration découplé ou pour vérifier si les paramètres de l'application doivent être remplacés par une application de configuration.
