Применяется при создании компонентов витрины VTEX IO в рамках реакции/для Store Framework. Охватывает структуру компонентов витрины, CSS-дескрипторы, перехватчики контекста витрины, безопасное для браузера извлечение данных и то, как компоненты должны вести себя при использовании в качестве блоков темы. Используйте для индивидуального пользовательского интерфейса витрины, виджетов продуктов, баннеров, форм или просмотра кода React, ориентированного на покупателя, в приложениях VTEX IO.
