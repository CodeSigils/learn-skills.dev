Wenden Sie es an, wenn Sie Suchfunktionen, Facettennavigation oder automatische Vervollständigung in einer Headless-VTEX-Storefront implementieren. Deckt die Endpunkte „product_search“, „autocomplete_suggestions“, „facets“, „banners“, „correction_search“ und „top_searches“ sowie die Sammlung von Analyseereignissen ab. Verwendung für jedes benutzerdefinierte Frontend, das die VTEX Intelligent Search API für die Produkterkennung und das Rendern von Suchergebnissen integriert.
