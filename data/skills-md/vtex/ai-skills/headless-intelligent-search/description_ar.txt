يتم تطبيقه عند تنفيذ وظيفة البحث، أو التنقل متعدد الأوجه، أو الإكمال التلقائي في واجهة متجر VTEX بدون رأس. يغطي البحث عن المنتجات، واقتراحات الإكمال التلقائي، والجوانب، واللافتات، وتصحيح_البحث، ونقاط نهاية أهم_البحث، بالإضافة إلى مجموعة أحداث التحليلات. يُستخدم لأي واجهة أمامية مخصصة تدمج VTEX Intelligent Search API لاكتشاف المنتج وعرض نتائج البحث.
