يتم تطبيقه عند توصيل مكونات React بكتل Store Framework وسلوك وقت تشغيل العرض في VTEX IO. يغطي واجهات ملف json، وتسجيل الكتلة، وتكوين الكتلة، وكيف تصبح مكونات واجهة المتجر كتل سمات قابلة للتكوين. يُستخدم لتعيين الكتل أو تكامل السمات أو مراجعة ما إذا كان مكون React قد تعرض بشكل صحيح لـ Store Framework.
