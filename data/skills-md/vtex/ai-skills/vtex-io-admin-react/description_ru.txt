Применяется при создании интерфейсов React с интерфейсом администратора VTEX IO в конструкторе администратора. Охватывает использование VTEX Styleguide и Shoreline, композицию страниц администратора, взаимодействие администраторов с большими объемами данных и обеспечение соответствия административных интерфейсов среде администрирования VTEX. Используйте для страниц настроек, инструментов модерации, информационных панелей или рабочих пользовательских интерфейсов внутри VTEX Admin.
