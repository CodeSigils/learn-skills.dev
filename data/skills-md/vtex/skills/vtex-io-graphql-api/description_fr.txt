Appliquez-le lorsque vous travaillez avec des fichiers de schéma GraphQL dans graphql/ ou implémentez des résolveurs dans node/resolvers/ pour les applications VTEX IO. Couvre les définitions schema.graphql, les directives @cacheControl et @auth, les définitions de types personnalisés et l'enregistrement du résolveur dans la classe Service. À utiliser pour exposer des données via des requêtes et des mutations GraphQL avec un contrôle de cache et une application d'authentification appropriés.
