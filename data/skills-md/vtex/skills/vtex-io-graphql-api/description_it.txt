Applicare quando si lavora con file di schema GraphQL in graphql/ o si implementano risolutori in node/resolvers/ per le app VTEX IO. Copre le definizioni schema.graphql, le direttive @cacheControl e @auth, le definizioni di tipo personalizzato e la registrazione del risolutore nella classe Service. Da utilizzare per esporre i dati tramite query e mutazioni GraphQL con il controllo della cache e l'applicazione dell'autenticazione adeguati.
