Применяется при реализации логики повторных попыток, обработки ограничения скорости или шаблонов устойчивости в интеграции VTEX API. Охватывает заголовки ограничения скорости VTEX (X-RateLimit-Remaining, X-RateLimit-Reset, Retry-After), обработку статуса 429, экспоненциальную задержку с джиттером, шаблоны автоматического выключателя и организацию очереди запросов. Используйте для любой интеграции с торговой площадкой VTEX, которая должна корректно обрабатывать регулирование API и поддерживать высокую доступность.
