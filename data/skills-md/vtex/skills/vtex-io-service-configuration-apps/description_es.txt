Aplicar al diseñar aplicaciones de configuración VTEX IO con el generador de configuración o cuando una aplicación de servicio debe recibir una configuración estructurada a través del contexto de tiempo de ejecución. Cubre la separación entre aplicaciones de servicio y aplicaciones de configuración, esquema.json y configuración.json, tipo de configuración y lectura de configuración inyectada a través de ctx.vtex.settings. Úselo para la configuración de servicios compartidos, el ciclo de vida de la configuración desacoplada o para revisar si la configuración de la aplicación debe reemplazarse por una aplicación de configuración.
