Применяется при реализации логики корзины, оформления заказа или размещения заказов, проксируемой через BFF, для автономных витрин VTEX. Охватывает жизненный цикл OrderForm, создание корзины, управление товарами, вложения профиля/доставки/платежа, управление orderFormId и безопасные процессы оформления заказа. Используйте для любого автономного интерфейса, которому необходимо проксировать вызовы API VTEX Checkout через серверный уровень с правильной обработкой файлов cookie сеанса.
