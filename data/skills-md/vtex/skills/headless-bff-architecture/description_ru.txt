Применяется при проектировании или изменении уровня BFF (Backend-for-Frontend), промежуточного программного обеспечения или прокси-сервера API для автономной витрины VTEX. Охватывает архитектуру промежуточного программного обеспечения BFF, классификацию общедоступных и частных API, управление VtexIdclientAutCookie, защиту ключей API и безопасное проксирование запросов. Используйте для любого проекта автономной коммерции, который никогда не должен предоставлять VTEX_APP_KEY или вызывать частные API VTEX из браузера.
