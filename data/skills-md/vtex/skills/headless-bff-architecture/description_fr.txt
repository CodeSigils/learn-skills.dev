Appliquer lors de la conception ou de la modification d'une couche BFF (Backend-for-Frontend), d'un middleware ou d'un proxy API pour une vitrine VTEX sans tête. Couvre l'architecture middleware BFF, la classification des API publiques et privées, la gestion VtexIdclientAutCookie, la protection des clés API et le proxy sécurisé des requêtes. À utiliser pour tout projet de commerce sans tête qui ne doit jamais exposer VTEX_APP_KEY ou appeler des API VTEX privées à partir du navigateur.
