يتم تطبيقه عند تصميم أو تعديل طبقة BFF (Backend-for-Frontend)، أو البرامج الوسيطة، أو وكيل API لواجهة متجر VTEX بدون رأس. يغطي بنية البرامج الوسيطة لـ BFF، وتصنيف واجهة برمجة التطبيقات العامة مقابل الخاصة، وإدارة VtexIdclientAutCookie، وحماية مفتاح واجهة برمجة التطبيقات، والتفويض الآمن للطلب. يُستخدم لأي مشروع تجاري بدون رأس والذي يجب ألا يكشف أبدًا عن VTEX_APP_KEY أو يستدعي واجهات برمجة تطبيقات VTEX الخاصة من المتصفح.
