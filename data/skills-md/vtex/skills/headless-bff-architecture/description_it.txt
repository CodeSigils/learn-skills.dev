Applicare durante la progettazione o la modifica di un livello BFF (Backend-for-Frontend), middleware o proxy API per una vetrina VTEX headless. Copre l'architettura del middleware BFF, la classificazione delle API pubbliche e private, la gestione di VtexIdclientAutCookie, la protezione delle chiavi API e il proxying delle richieste sicure. Utilizzare per qualsiasi progetto commerciale headless che non deve mai esporre VTEX_APP_KEY o chiamare API VTEX private dal browser.
