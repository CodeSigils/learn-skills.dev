Applicare durante la creazione di app di servizio backend in node/ in un progetto VTEX IO o la configurazione di route service.json. Copre la classe Service, le funzioni middleware, il pattern ctx.clients, la registrazione JanusClient, ExternalClient, MasterDataClient e IOClients. Da utilizzare per implementare API backend, gestori di eventi o integrazioni che devono utilizzare client @vtex/api anziché librerie HTTP non elaborate.
