Aplicar al diseñar o modificar una aplicación temática de escaparate VTEX IO: la aplicación que posee `store/blocks.json`, `store/routes.json`, `store/templates/`, `store/contentSchemas.json` y el árbol de páginas de escaparate ensamblado a partir de `store.home`, `store.product`, `store.search`, `store.custom` y otras plantillas de páginas nativas. Cubre cómo una aplicación de tema extiende un tema base, declara rutas, compone bloques entre páginas y cómo sus archivos `store/` se relacionan con el contenido del Editor del sitio comercial. Úselo para andamiaje de temas, rutas de páginas personalizadas, anulaciones de nivel de tema o para revisar si un cambio pertenece a la aplicación del tema, a una aplicación de componente o a la configuración de la aplicación.
