Aplicar al crear, personalizar o implementar extensiones para la aplicación VTEX Sales. Cubre el flujo de trabajo completo de 7 pasos, desde comprobaciones de requisitos previos hasta la generación de código hasta la implementación, incluidos puntos de extensión (carrito, PDP, menú), enlaces de React (useCart, usePDP, useCartItem, useCurrentUser, useExtension), tipos de TypeScript, patrones de integración de API seguros e ingesta de documentación de API (OpenAPI, URL o especificaciones en línea) para generar integraciones escritas.
