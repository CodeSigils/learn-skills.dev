Применяйте при создании, настройке или развертывании расширений для приложения VTEX Sales. Охватывает полный 7-этапный рабочий процесс от предварительных проверок до генерации кода и развертывания, включая точки расширения (cart, PDP, меню), перехватчики React (useCart, usePDP, useCartItem, useCurrentUser, useExtension), типы TypeScript, шаблоны безопасной интеграции API и прием документации API (OpenAPI, URL-адреса или встроенные спецификации) для создания типизированной интеграции.
