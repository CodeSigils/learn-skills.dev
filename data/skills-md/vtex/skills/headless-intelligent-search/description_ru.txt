Применяется при реализации функции поиска, фасетной навигации или автозаполнения в безголовой витрине VTEX. Охватывает конечные точки Product_search, autocomplete_suggestions, Facets, Banners, Correction_search и Top_searches, а также сбор аналитических событий. Используйте для любого пользовательского интерфейса, который интегрирует API интеллектуального поиска VTEX для обнаружения продуктов и отображения результатов поиска.
