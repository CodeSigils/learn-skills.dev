قم بالتطبيق عند تحديد ما إذا كانت بيانات VTEX الرئيسية هي التخزين المناسب لعبء عمل معين، أو تصميم مخططات JSON باستخدام v-indexed، وv-cache، وv-security، وv-triggers، أو تخطيط سعة الكيان ودورة الحياة، أو تدقيق استخدام البيانات الرئيسية الحالية. يغطي متى يتم استخدام MD مقابل الكتالوج، أو OMS، أو VBase، أو قواعد البيانات الخارجية، وأفضل ممارسات تصميم المخطط، واستراتيجية الفهرسة، وأنماط التشغيل، والاعتبارات التشغيلية. استخدمه قبل إنشاء أي كيان بيانات رئيسية جديد.
