Appliquez-le lors de la conception ou de la mise en œuvre de la manière dont une application backend VTEX IO s'intègre aux services VTEX ou aux API externes via @vtex/api et @vtex/clients. Couvre le choix du type de client correct, l'enregistrement des clients dans IOClients, la configuration d'InstanceOptions et la consommation des intégrations via ctx.clients. À utiliser pour la conception de clients personnalisés, les intégrations de VTEX Core Commerce ou la révision du code backend qui doit utiliser des modèles de client VTEX IO au lieu de bibliothèques HTTP brutes.
