Applicare durante la progettazione o l'implementazione del modo in cui un'app backend VTEX IO si integra con i servizi VTEX o le API esterne tramite @vtex/api e @vtex/clients. Copre la scelta del tipo di client corretto, la registrazione dei client in IOClients, la configurazione di InstanceOptions e l'utilizzo delle integrazioni tramite ctx.clients. Utilizzare per la progettazione di client personalizzati, integrazioni VTEX Core Commerce o revisione del codice backend che dovrebbe utilizzare modelli client IO VTEX anziché librerie HTTP non elaborate.
