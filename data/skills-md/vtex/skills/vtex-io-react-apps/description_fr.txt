Appliquer lors de la création de composants React sous React/ ou de la configuration de blocs de magasin en magasin/ pour les applications VTEX IO. Couvre interfaces.json, contentSchemas.json pour l'éditeur de site, VTEX Styleguide pour les applications d'administration et les poignées CSS pour le style de la vitrine. À utiliser pour créer des composants de vitrine personnalisés, des panneaux d'administration, des applications pixel ou tout développement frontal au sein de l'écosystème VTEX IO React Builder.
