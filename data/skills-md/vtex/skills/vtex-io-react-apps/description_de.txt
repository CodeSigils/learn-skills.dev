Anwenden, wenn Sie React-Komponenten unter „react/“ erstellen oder Store-Blöcke in „store/“ für VTEX IO-Apps konfigurieren. Behandelt interfaces.json, contentSchemas.json für Site Editor, VTEX Styleguide für Admin-Apps und CSS-Handles für Storefront-Styling. Zur Erstellung benutzerdefinierter Storefront-Komponenten, Admin-Panels, Pixel-Apps oder einer beliebigen Frontend-Entwicklung innerhalb des VTEX IO React Builder-Ökosystems.
