Применяется при создании компонентов React в разделе реагирования или настройке блоков хранилища в магазине/ для приложений VTEX IO. Охватывает интерфейсы.json, contentSchemas.json для редактора сайтов, руководство по стилю VTEX для приложений администратора и CSS-дескрипторы для оформления витрины. Используйте для создания пользовательских компонентов витрины, панелей администратора, пиксельных приложений или любой разработки внешнего интерфейса в экосистеме конструктора реагирования VTEX IO.
