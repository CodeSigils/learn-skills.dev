يتم تطبيقه عند إنشاء مكونات React ضمن التفاعل/ أو تكوين كتل المتجر في المتجر/ لتطبيقات VTEX IO. يغطي واجهات Interface.json، وcontentSchemas.json لمحرر الموقع، وVTEX Styleguide لتطبيقات الإدارة، ومقابض CSS لتصميم واجهة المتجر. يُستخدم لإنشاء مكونات واجهة متجر مخصصة، أو لوحات إدارية، أو تطبيقات بكسل، أو أي تطوير للواجهة الأمامية داخل النظام البيئي لمنشئ التفاعل VTEX IO.
