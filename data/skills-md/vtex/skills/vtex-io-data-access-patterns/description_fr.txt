Appliquez-le pour décider où et comment une application VTEX IO doit stocker et lire les données. Explique quand utiliser les paramètres d'application, les applications de configuration, les données de base, VBase, les API principales de VTEX ou les magasins externes, et comment éviter de dupliquer les sources de vérité ou d'abuser des magasins de configuration pour les données opérationnelles. À utiliser pour de nouveaux flux de données, la mise en cache des décisions, les refactorisations ou l'examen des modèles de stockage et d'accès suspects dans les applications VTEX IO.
