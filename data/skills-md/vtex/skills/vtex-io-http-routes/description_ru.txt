Применяется при проектировании или реализации конечных точек HTTP, предоставляемых внутренней службой ввода-вывода VTEX. Охватывает границы маршрутов, структуру обработчиков, состав промежуточного программного обеспечения, проверку запросов и моделирование ответов для маршрутов service.json. Используйте для конечных точек веб-перехватчика, партнерской интеграции, API обратного вызова или проверки обработчиков ввода-вывода VTEX, которые должны предоставлять явные контракты HTTP.
