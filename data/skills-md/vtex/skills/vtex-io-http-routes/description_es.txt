Aplicar al diseñar o implementar endpoints HTTP expuestos por un servicio backend de VTEX IO. Cubre los límites de las rutas, la estructura del controlador, la composición del middleware, la validación de solicitudes y el modelado de respuestas para rutas service.json. Úselo para endpoints de webhooks, integraciones de socios, API de devolución de llamadas o revisión de controladores de E/S de VTEX que deben exponer contratos HTTP explícitos.
