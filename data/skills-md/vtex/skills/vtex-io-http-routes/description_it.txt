Applicare durante la progettazione o l'implementazione di endpoint HTTP esposti da un servizio backend IO VTEX. Copre i limiti della route, la struttura del gestore, la composizione del middleware, la convalida delle richieste e la modellazione della risposta per le route service.json. Utilizzare per endpoint webhook, integrazioni di partner, API di callback o revisione dei gestori IO VTEX che dovrebbero esporre contratti HTTP espliciti.
