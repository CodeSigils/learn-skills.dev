Создавайте музыку из текста (и, при необходимости, из эталонного изображения) с помощью Google Lyria 3 через API данных Rebyte. Две модели — «лирия-3» для быстрых 30-секундных клипов, «лирия-3-про» для полных песен продолжительностью до ~3 минут с пониманием структуры (вступление/куплет/припев/переход). Стерео MP3 или WAV 44,1 кГц. Передайте «изображение», чтобы задать настроение/жанр визуального элемента. Используйте для саундтреков, джинглов, вступительной/заключительной музыки, эмбиентных кроватей, музыкальной темы подкаста, преобразования изображения в музыку или любых задач преобразования текста в музыку. Триггеры включают «создать музыку», «создать песню», «создать саундтрек», «сочинить музыку», «фоновую музыку», «джингл», «музыкальную тему», «музыку из подсказки», «текст в музыку», «изображение в музыку», «музыку из изображения», «музыку AI».
