Genere música a partir de texto (y opcionalmente una imagen de referencia) usando Google Lyria 3 a través de la API de datos de Rebyte. Dos modelos: `lyria-3` para clips rápidos de 30 segundos, `lyria-3-pro` para canciones completas de hasta ~3 minutos con conciencia estructural (introducción/verso/estribillo/puente). MP3 o WAV estéreo de 44,1 kHz. Pase una "imagen" para condicionar el estado de ánimo/género de una imagen. Úselo para bandas sonoras, jingles, música de introducción/final, ambientes, temas musicales de podcasts, conversión de imagen a música o cualquier tarea de conversión de texto a música. Los activadores incluyen "generar música", "crear una canción", "crear una banda sonora", "componer música", "música de fondo", "jingle", "tema musical", "música desde el mensaje", "texto a música", "imagen a música", "música a partir de imagen", "música AI".
