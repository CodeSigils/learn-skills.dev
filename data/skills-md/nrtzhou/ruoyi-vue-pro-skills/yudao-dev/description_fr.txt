ruoyi-vue-pro (yudao/芋道) spécifications de développement full-stack et base de connaissances du module. Il est utilisé lors de l'ajout, de l'extension ou de la refactorisation de modules métier, de la conception de tables de base de données et de classes d'entités (DO), de la génération d'opérations CRUD, de la conception d'API REST ou du choix de modèles de conception tels qu'une usine, une stratégie ou une méthode de modèle dans le projet yudao. Il couvre les modèles de domaine, les tableaux de données, les normes de code et les guides d'extension pour 14 modules métier (système, infra, paye, membre, centre commercial, crm, erp, bpm, ai, iot, mp, report, mes, wms, im).
