ruoyi-vue-pro (yudao/芋道) フルスタック開発仕様とモジュールのナレッジ ベース。これは、yudao プロジェクトでビジネス モジュールの追加、拡張、またはリファクタリング、データベース テーブルとエンティティ クラス (DO) の設計、CRUD 操作の生成、REST API の設計、またはファクトリ、ストラテジ、テンプレート メソッドなどの設計パターンの選択を行うときに使用されます。 14 のビジネス モジュール (システム、インフラ、ペイ、メンバー、モール、crm、erp、bpm、ai、iot、mp、レポート、mes、wms、im) のドメイン モデル、データ テーブル、コード標準、および拡張ガイドをカバーしています。
