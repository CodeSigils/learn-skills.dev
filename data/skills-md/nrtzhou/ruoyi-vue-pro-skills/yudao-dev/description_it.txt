ruoyi-vue-pro (yudao/芋道) standard di sviluppo full-stack e knowledge base del modulo. Viene utilizzato quando si aggiungono, si estendono o si effettua il refactoring di moduli aziendali, si progettano tabelle di database e classi di entità (DO), si generano operazioni CRUD, si progettano API REST o si scelgono modelli di progettazione come factory, strategia o metodo modello nel progetto yudao. Copre modelli di dominio, tabelle di dati, convenzioni di codice e linee guida per l'estensione per 14 moduli aziendali (system/infra/pay/member/mall/crm/erp/bpm/ai/iot/mp/report/mes/wms/im).
