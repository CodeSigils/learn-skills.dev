ruoyi-vue-pro (yudao/芋道) estándares de desarrollo completo y base de conocimientos de módulos. Se utiliza al agregar, ampliar o refactorizar módulos comerciales en el proyecto yudao, diseñar tablas de bases de datos y clases de entidad (DO), generar operaciones CRUD, diseñar API REST o seleccionar patrones de diseño como fábrica, estrategia o método de plantilla. Cubre los modelos de dominio, tablas de datos, estándares de código y guías de extensión para 14 módulos comerciales (sistema, infra, pago, miembro, centro comercial, crm, erp, bpm, ai, iot, mp, report, mes, wms, im).
