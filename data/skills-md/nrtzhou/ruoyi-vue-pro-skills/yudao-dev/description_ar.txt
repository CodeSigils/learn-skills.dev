ruoyi-vue-pro (yudao/芋道) مواصفات تطوير المكدس الكامل وقاعدة معارف الوحدة النمطية. استخدمه في مشروع yudao عند إضافة وحدات الأعمال أو توسيعها أو إعادة هيكلتها؛ تصميم جداول قاعدة البيانات وفئات الكيانات (DO)؛ توليد عمليات CRUD؛ وتصميم واجهات برمجة تطبيقات REST؛ أو اختيار أنماط التصميم مثل المصنع أو الإستراتيجية أو طريقة القالب. ويغطي نماذج المجال، وجداول البيانات، ومعايير التعليمات البرمجية، وإرشادات الإرشاد لـ 14 وحدة أعمال (النظام، الأشعة تحت الحمراء، الدفع، العضو، المركز التجاري، crm، erp، bpm، ai، iot، mp، report، mes، wms، im).
