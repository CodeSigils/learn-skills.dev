التحقق من التطبيقات الأصلية أو React Native أو Expo أو Flutter وتصحيح أخطائها على جهاز محاكاة iOS باستخدام جهاز الوكيل. يُستخدم عندما يحتاج الوكيل إلى تشغيل تطبيق ما، أو فحص واجهة المستخدم المباشرة الخاصة به، أو النقر، أو الكتابة، أو التمرير، أو التحقق من صحة تغيير التعليمات البرمجية، أو جمع أدلة الفشل، أو إعادة إنتاج سير العمل على iPhone أو iPad Simulator.
