MoWen-Tags. Wird ausgelöst, wenn Sie die Tags des aktuellen authentifizierten Benutzers, „Meine Tags“, „Meine Notizen“ anzeigen, abrufen oder auflisten, oder wenn Sie vor dem Markieren einer Notiz Tags aus vorhandenen Tags auswählen müssen. Das Ändern der Tags einer Notiz ist nicht möglich; Die Notiz-Tag-Verwaltung erfolgt über mo-note.
