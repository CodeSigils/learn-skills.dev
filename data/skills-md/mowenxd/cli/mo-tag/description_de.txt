MoWen-Tags. Wird ausgelöst, wenn Sie die Tags des aktuell authentifizierten Benutzers, „Meine Tags“ oder „Meine Notiz-Tags“ anzeigen, abrufen oder auflisten, oder wenn Sie vor dem Markieren einer Notiz ein Tag aus vorhandenen Tags auswählen müssen. Das Ändern der Tags einer Notiz ist nicht möglich. Die Notiz-Tag-Verwaltung wird von mo-note übernommen.
