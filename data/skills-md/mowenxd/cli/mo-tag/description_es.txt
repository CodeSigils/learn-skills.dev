Etiquetas MoWen. Se activa al ver, recuperar o enumerar las etiquetas del usuario actualmente autenticado, Mis etiquetas o Mis etiquetas de notas, o cuando necesita seleccionar una etiqueta entre las etiquetas existentes antes de etiquetar una nota. No maneja la modificación de las etiquetas de una nota; La gestión de etiquetas de notas está a cargo de mo-note.
