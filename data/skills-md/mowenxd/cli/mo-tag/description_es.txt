Etiquetas MoWen. Se activa al ver, recuperar o enumerar las etiquetas del usuario autenticado actual, mis etiquetas o mis etiquetas de notas, o cuando necesita seleccionar una etiqueta entre las etiquetas existentes antes de etiquetar una nota. No maneja la modificación de las etiquetas de una nota; La gestión de etiquetas de notas se realiza a través de mo-note.
