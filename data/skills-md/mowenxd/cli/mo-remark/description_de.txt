Legen Sie einen Bemerkungsnamen für eine MoWen-UID fest (Bemerkung → UID), entfernen Sie einen Bemerkungsnamen und verwenden Sie Bemerkungsnamen, um MoWen-UIDs abzurufen. Eine MoWen-UID kann mehrere Bemerkungsnamen haben. In Szenarios in natürlicher Sprache wie „Holen Sie sich die neuesten MoWen-Notizen von ‚Laochi‘“ oder „Sehen Sie sich das Profil von ‚ErYe‘ auf MoWen an“ können Sie, wenn „Laochi“ und „ErYe“ als persönliche Namen identifiziert werden, zunächst versuchen, mit dem Befehl „remark“ die entsprechende UID abzurufen, bevor Sie fortfahren. Dies wird beim Setzen, Entfernen oder Abrufen von Bemerkungsnamen ausgelöst.
