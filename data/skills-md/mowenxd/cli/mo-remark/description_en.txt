Set a remark name for a MoWen UID (remark → uid), remove a remark name, and use remark names to retrieve MoWen UIDs; a MoWen UID can have multiple remark names. In natural language scenarios such as “Get ‘Laochi’’s latest MoWen notes” or “View ‘Er Ye’'s profile on MoWen”, if ‘Laochi’ and ‘Er Ye’ are identified as personal names, you can first try using the `remark` command to retrieve the corresponding UID before proceeding. This is triggered when setting, removing, or retrieving remark names.
