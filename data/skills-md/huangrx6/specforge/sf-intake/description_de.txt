Erstellen oder organisieren Sie ein SpecForge-Arbeitselement für eine neue Anfrage. Wenn ein Benutzer eine neue Anforderung, einen Fehler, ein Problem, ein Refactoring, eine vorläufige Recherche, eine kleine Änderung mit geringem Risiko oder eine Arbeit mit unklaren Grenzen einreicht, müssen Sie den Workflow kategorisieren, feststellen, ob ein PRD erforderlich ist, Komponenten-Flags ausrichten und eine Kurzbeschreibung schreiben, die den nächsten Schritt unterstützen kann.
