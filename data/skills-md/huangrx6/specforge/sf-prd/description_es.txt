Generar o actualizar un Documento de Requisitos del Producto (PRD); se utiliza para elementos de trabajo de tipo producto, funciones de IA, herramientas de backend, aplicaciones de pila completa o requisitos vagos de alto nivel para definir el problema central, los usuarios objetivo, las funciones candidatas, el alcance de MVP, las métricas de éxito, los riesgos y la hoja de ruta antes de especificar los requisitos.
