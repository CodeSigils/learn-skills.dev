Perfile las aplicaciones de línea de comandos de Dart utilizando el protocolo de servicio VM para
capturar muestras de CPU e identificar cuellos de botella en el rendimiento. Ayuda a los agentes
automatizar la creación de perfiles de CPU, generar resúmenes de desgloses de llamadas de funciones y
exporte perfiles JSON sin un navegador o DevTools.
