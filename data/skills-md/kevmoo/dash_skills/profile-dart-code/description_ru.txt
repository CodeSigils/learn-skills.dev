Профилируйте приложения командной строки Dart, используя протокол службы VM, чтобы
собирать образцы ЦП и выявлять узкие места в производительности. Помогает агентам
автоматизировать профилирование ЦП, генерировать сводные данные по вызовам функций и
экспортируйте профили JSON без браузера или DevTools.
