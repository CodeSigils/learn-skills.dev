قم بإعداد الإنشاء التلقائي + النشر لمستودع Dockerized repo إلى مثيل Dokploy مستضاف ذاتيًا باستخدام GitHub Actions وGitHub Container Registry (GHCR) وDokploy MCP. يُستخدم عندما يريد المستخدم نشر الريبو تلقائيًا إلى Dokploy، أو إعداد CI/CD لاستهداف Dokploy، أو شحن حاوية إلى خادم Dokploy الخاص به، أو تكوين تطبيق جديد على Dokploy من repo موجود، أو توصيل إجراءات GitHub لدفع صورة وتشغيل إعادة نشر Dokploy - حتى إذا لم يذكر "GHCR" أو "GitHub Actions" صراحة. مشغلات لعبارات مثل "نشر هذا إلى dokploy"، و"إعداد dokploy لهذا الريبو"، و"الإنشاء التلقائي والنشر على الخادم الخاص بي"، و"شحن هذا التطبيق إلى dokploy الخاص بي"، و"أريد CI/CD إلى Dokploy المستضاف ذاتيًا".
