Configurez la création et le déploiement automatiques d'un dépôt Dockerisé sur une instance Dokploy auto-hébergée à l'aide de GitHub Actions, de GitHub Container Registry (GHCR) et de Dokploy MCP. À utiliser lorsque l'utilisateur souhaite déployer automatiquement un dépôt sur Dokploy, configurer CI/CD ciblant Dokploy, expédier un conteneur sur son propre serveur Dokploy, configurer une nouvelle application sur Dokploy à partir d'un dépôt existant ou câbler des actions GitHub pour pousser une image et déclencher un redéploiement Dokploy — même s'ils ne mentionnent pas explicitement « GHCR » ou « GitHub Actions ». Déclenche des expressions telles que « déployer ceci sur dokploy », « configurer dokploy pour ce dépôt », « construire et déployer automatiquement sur mon serveur », « expédier cette application sur mon dokploy », « je veux CI/CD sur mon Dokploy auto-hébergé ».
