Configure la compilación e implementación automática de un repositorio Dockerizado en una instancia de Dokploy autohospedada mediante GitHub Actions, GitHub Container Registry (GHCR) y Dokploy MCP. Úselo cuando el usuario quiera implementar automáticamente un repositorio en Dokploy, configurar CI/CD dirigido a Dokploy, enviar un contenedor a su propio servidor Dokploy, configurar una nueva aplicación en Dokploy desde un repositorio existente o conectar acciones de GitHub para enviar una imagen y activar una redistribución de Dokploy, incluso si no mencionan "GHCR" o "Acciones de GitHub" explícitamente. Activadores de frases como "implementar esto en dokploy", "configurar dokploy para este repositorio", "compilar e implementar automáticamente en mi servidor", "enviar esta aplicación a mi dokploy", "Quiero CI/CD en mi Dokploy autohospedado".
