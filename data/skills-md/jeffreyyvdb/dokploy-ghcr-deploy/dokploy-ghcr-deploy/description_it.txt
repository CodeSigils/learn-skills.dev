Configura la creazione e la distribuzione automatiche di un repository Dockerizzato su un'istanza Dokploy ospitata autonomamente utilizzando GitHub Actions, GitHub Container Registry (GHCR) e Dokploy MCP. Da utilizzare quando l'utente desidera distribuire automaticamente un repository su Dokploy, impostare CI/CD targeting Dokploy, spedire un container sul proprio server Dokploy, configurare una nuova app su Dokploy da un repository esistente o collegare azioni GitHub per inviare un'immagine e attivare una ridistribuzione Dokploy, anche se non menzionano esplicitamente "GHCR" o "Azioni GitHub". Si attivano frasi come "distribuisci questo su dokploy", "imposta dokploy per questo repository", "crea e distribuisci automaticamente sul mio server", "spedisci questa app al mio dokploy", "Voglio CI/CD sul mio Dokploy self-hosted".
