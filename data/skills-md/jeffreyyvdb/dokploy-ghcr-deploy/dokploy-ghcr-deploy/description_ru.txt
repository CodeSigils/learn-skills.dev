Настройте автоматическую сборку и развертывание репозитория Dockerized на локальном экземпляре Dokploy с помощью действий GitHub, реестра контейнеров GitHub (GHCR) и Dokploy MCP. Используйте, когда пользователь хочет автоматически развернуть репозиторий в Dokploy, настроить CI/CD, нацеленный на Dokploy, отправить контейнер на свой собственный сервер Dokploy, настроить новое приложение на Dokploy из существующего репозитория или подключить действия GitHub для отправки образа и запуска повторного развертывания Dokploy — даже если они явно не упоминают «GHCR» или «GitHub Actions». Запускается при таких фразах, как «развернуть это в dokploy», «настроить dokploy для этого репозитория», «автоматическая сборка и развертывание на моем сервере», «отправить это приложение в мой dokploy», «Я хочу CI/CD в свой локальный Dokploy».
