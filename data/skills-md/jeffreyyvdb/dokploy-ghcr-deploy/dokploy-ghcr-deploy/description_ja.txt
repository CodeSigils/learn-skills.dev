GitHub Actions、GitHub Container Registry (GHCR)、および Dokploy MCP を使用して、自己ホスト型 Dokploy インスタンスへの Docker 化リポジトリの自動ビルドとデプロイを設定します。 「GHCR」または「GitHub Actions」について明示的に言及していない場合でも、ユーザーが Dokploy へのリポジトリの自動デプロイ、Dokploy を対象とした CI/CD のセットアップ、独自の Dokploy サーバーへのコンテナの配布、既存のリポジトリから Dokploy 上で新しいアプリの構成、または GitHub Actions を接続してイメージをプッシュして Dokploy の再デプロイをトリガーする場合に使用します。 「これを dokploy にデプロイする」、「このリポジトリに dokploy をセットアップする」、「自動ビルドしてサーバーにデプロイする」、「このアプリを dokploy に配布する」、「自己ホスト型 Dokploy に CI/CD を使用したい」などのフレーズでトリガーされます。
