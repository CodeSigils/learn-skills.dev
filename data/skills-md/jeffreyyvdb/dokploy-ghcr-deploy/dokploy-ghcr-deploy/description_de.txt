Richten Sie mithilfe von GitHub Actions, GitHub Container Registry (GHCR) und dem Dokploy MCP die automatische Erstellung und Bereitstellung eines Docker-Repositorys auf einer selbst gehosteten Dokploy-Instanz ein. Verwenden Sie diese Option, wenn der Benutzer ein Repo automatisch auf Dokploy bereitstellen, CI/CD-Targeting auf Dokploy einrichten, einen Container an seinen eigenen Dokploy-Server versenden, eine neue App auf Dokploy aus einem vorhandenen Repo konfigurieren oder GitHub-Aktionen verbinden möchte, um ein Image zu pushen und eine Dokploy-Neubereitstellung auszulösen – auch wenn sie „GHCR“ oder „GitHub Actions“ nicht explizit erwähnen. Löst Auslöser bei Formulierungen wie „dies für dokploy bereitstellen“, „dokploy für dieses Repo einrichten“, „automatisch erstellen und auf meinem Server bereitstellen“, „diese App an meinen dokploy senden“, „Ich möchte CI/CD für meinen selbst gehosteten Dokploy“ verwenden.
