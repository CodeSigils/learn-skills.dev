Générez un ensemble personnalisé de questions d'entretien probables à partir du curriculum vitae (CV) et d'une description de poste (JD) d'un candidat, sous forme de feuille d'étude HTML interactive. Chaque question est cliquable pour copier une invite approfondie de l'IA et se marquer comme traitée. Prend deux entrées de fichier : CV et JD ; la langue de sortie est automatiquement détectée à partir de ces documents. Déclenchez sur « préparer les questions d'entretien », « préparation à l'entretien », « questions d'entretien simulées », « préparation ».
