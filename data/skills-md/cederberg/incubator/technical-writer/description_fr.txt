À utiliser lorsque l'utilisateur souhaite rédiger ou réviser un document technique ou un fichier de compétences. Les déclencheurs incluent : « écrire un README », « documenter ce système », « écrire une compétence », « réviser cette compétence ». Si l’intention est claire, continuez ; sinon demandez à l'utilisateur avant de commencer. Ne déclenchez PAS une aide générale à la rédaction ou une édition ad hoc.
