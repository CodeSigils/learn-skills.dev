Analice documentos en rebajas limpias o JSON estructurado a través de xparse-cli. Utilice esta habilidad cuando el usuario proporcione un PDF, una imagen, un archivo de Office, HTML, OFD u otro documento compatible y desee leerlo, convertirlo, resumirlo o prepararlo para su uso posterior por parte del agente. Maneja archivos PDF cifrados, rangos de páginas, rebajas/salida de texto y extracción estructurada detallada. Prefiera esta habilidad siempre que la tarea comience desde un archivo local o URL de un documento y el primer paso sea convertirlo en contenido amigable para el agente en lugar de inspeccionar manualmente el archivo sin formato.
