Analizza i documenti in un markdown pulito o in JSON strutturato tramite xparse-cli. Utilizzare questa capacità quando l'utente fornisce un PDF, un'immagine, un file Office, HTML, OFD o un altro documento supportato e desidera che venga letto, convertito, riepilogato o preparato per l'utilizzo da parte dell'agente downstream. Gestisce PDF crittografati, intervalli di pagine, output di markdown/testo ed estrazione strutturata dettagliata. Preferisci questa abilità ogni volta che l'attività inizia da un file locale o da un URL di documento e il primo passaggio è trasformarlo in contenuto utilizzabile dall'agente anziché ispezionare manualmente il file non elaborato.
