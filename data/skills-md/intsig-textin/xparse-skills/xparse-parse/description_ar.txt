قم بتحليل المستندات إلى تخفيض واضح أو JSON منظم عبر xparse-cli. استخدم هذه المهارة عندما يقدم المستخدم ملف PDF أو صورة أو ملف Office أو HTML أو OFD أو أي مستند مدعوم آخر ويريد قراءته أو تحويله أو تلخيصه أو إعداده لاستخدام الوكيل النهائي. يتعامل مع ملفات PDF المشفرة ونطاقات الصفحات وإخراج النص/إخراج النص والاستخراج المنظم التفصيلي. قم بتفضيل هذه المهارة عندما تبدأ المهمة من ملف محلي أو عنوان URL للمستند وتكون الخطوة الأولى هي تحويلها إلى محتوى صديق للوكيل بدلاً من فحص الملف الأولي يدويًا.
