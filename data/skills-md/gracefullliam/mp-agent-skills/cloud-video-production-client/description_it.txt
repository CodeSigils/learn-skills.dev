Integra server clienti affidabili o agenti locali con l'API Firefly Cloud Video Production. Da utilizzare durante il caricamento di file immagine/video locali selezionati in modo esplicito, l'invio di risorse locali o URL per la produzione di modelli cloud asincroni, il polling di una produzione tramite conversazione_id tramite il risultato video finale, la gestione di tentativi idempotenti, la ricezione di webhook di produzione firmati o la diagnosi di errori API pubblici dagli endpoint /api/rest/mva/out/cloud.
