قم بدمج خوادم العملاء الموثوقة أو الوكلاء المحليين مع Firefly Cloud Video Production API. يُستخدم عند تحميل ملفات صور/فيديو محلية محددة بشكل صريح، أو إرسال أصول محلية أو عنوان URL لإنتاج قالب سحابي غير متزامن، أو استقصاء الإنتاج عن طريق المحادثة_id من خلال نتيجة الفيديو النهائية، أو التعامل مع عمليات إعادة المحاولات غير الفعالة، أو تلقي خطافات الويب الخاصة بالإنتاج الموقعة، أو تشخيص أخطاء واجهة برمجة التطبيقات العامة من نقاط نهاية /api/rest/mva/out/cloud.
