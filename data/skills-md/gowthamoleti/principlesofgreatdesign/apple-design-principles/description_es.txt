Aplique los 8 principios de diseño fundamentales de Apple (de WWDC26) para revisar, criticar, calificar o generar decisiones de UI/UX. Utilice esta habilidad siempre que el usuario quiera evaluar un diseño, revisar una pantalla o flujo, auditar la calidad del diseño de una característica, decidir qué construir o cortar, verificar si una interfaz de usuario se siente bien o pensar en cómo diseñar algo para plataformas iPhone/Mac/Apple. También se activa cuando el usuario pregunta "¿es este un buen diseño?", "¿qué tiene de malo esta interfaz de usuario?", "¿cómo debería diseñar X?" o "revisar esto desde una perspectiva de diseño". No espere a que el usuario diga explícitamente "principios de diseño de Apple": invoque cada vez que la conversación sea claramente sobre la calidad del diseño, las decisiones de UX o la crítica del diseño del producto.
