Utilisez la CLI CCHistory : découvrez les sources, synchronisez, interrogez les projets/tours/sessions, exportez/importez/sauvegardez les bundles et vérifiez les restaurations. À utiliser lorsque l'utilisateur souhaite interagir avec les données CCHistory via la CLI locale. Couvre tous les flux de travail de lecture, de prévisualisation et de mutation avec des conseils de commande à plusieurs niveaux de sécurité.
