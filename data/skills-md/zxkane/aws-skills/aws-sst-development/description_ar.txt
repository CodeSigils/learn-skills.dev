خبير SST v4 (Ion) لإدارة موارد AWS كرمز مع إطار العمل المدعوم من Pulumi. يُستخدم عند كتابة sst.config.ts أو تحريره، أو إنشاء وحدات الأشعة تحت الحمراء/ (sst.aws.Function/Bucket/Dynamo/Cron/Service/Router، أو sst.Secret، أو sst.Linkable، أو موارد aws الأولية.* موارد Pulumi)، أو روابط موارد الأسلاك، أو تحديد نطاق IAM، أو تشغيل sst Publish/dev/diff/remove. ضروري عندما يذكر المستخدم SST، أو sst.config.ts، أو $config، أو $transform، أو $interpolate، أو sst.aws.*، أو sst.Secret، أو Pulumi/Ion، أو "sst Publish"، أو فشل نشر SST (ConflictException عند تغيير نوع المورد، أو "تم الإعلان عن المعرف '__filename'' بالفعل"، أو MalformedPolicyDocument على Output<T>)، أو يريد ذلك السقالة/استكشاف أخطاء البنية التحتية لـ AWS وإصلاحها باستخدام SST. استخدمه أيضًا عند تقديم طلب "نشر مكدس AWS الخاص بي" أو "إضافة Lambda/bucket/table" في الريبو الذي يحتوي بالفعل على sst.config.ts (باستخدام $config) أو تبعية sst. لا تستخدم عندما تكون المهمة في المقام الأول هي AWS CDK، أو Terraform، أو CloudFormation الخام، أو SAM مع عدم وجود SST - فهؤلاء لديهم أدواتهم الخاصة.
