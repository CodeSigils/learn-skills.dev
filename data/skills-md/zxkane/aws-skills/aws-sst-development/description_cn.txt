SST v4 (Ion) 专家，用于使用 Pulumi 支持的框架以代码形式管理 AWS 资源。在编写或编辑 sst.config.ts、构建基础设施/模块（sst.aws.Function/Bucket/Dynamo/Cron/Service/Router、sst.Secret、sst.Linkable、原始 aws.* Pulumi 资源）、连接资源链接、确定 IAM 范围或运行 sst deploy/dev/diff/remove 时使用。当用户提到 SST、sst.config.ts、$config、$transform、$interpolate、sst.aws.*、sst.Secret、Pulumi/Ion、“sst 部署”、失败的 SST 部署（资源类型更改上的 ConflictException、“标识符 '__filename' 已被声明”、Output<T> 上的 MalformedPolicyDocument）或想要使用 SST 对 AWS 基础设施进行脚手架/故障排除。当在已包含 sst.config.ts（使用 $config）或 sst 依赖项的存储库中发出“部署我的 AWS 堆栈”或“添加 Lambda/bucket/table”的请求时也可使用。当任务主要是 AWS CDK、Terraform、原始 CloudFormation 或没有 SST 的 SAM 时，请勿使用 - 这些都有自己的工具。
