SST v4 (Ion)-Experte für die Verwaltung von AWS-Ressourcen als Code mit dem von Pulumi unterstützten Framework. Verwenden Sie diese Option beim Schreiben oder Bearbeiten von sst.config.ts, beim Erstellen von Infra-Modulen (sst.aws.Function/Bucket/Dynamo/Cron/Service/Router, sst.Secret, sst.Linkable, rohe aws.* Pulumi-Ressourcen), beim Verknüpfen von Ressourcenverknüpfungen, beim Festlegen des IAM-Bereichs oder beim Ausführen von sstploy/dev/diff/remove. Unverzichtbar, wenn der Benutzer SST, sst.config.ts, $config, $transform, $interpolate, sst.aws.*, sst.Secret, Pulumi/Ion, „sst deploy“, eine fehlgeschlagene SST-Bereitstellung (ConflictException bei einer Änderung des Ressourcentyps, „Identifier '__filename' wurde bereits deklariert“, MalformedPolicyDocument bei einem Output<T>) erwähnt oder ein Gerüst/eine Fehlerbehebung für die AWS-Infrastruktur erstellen möchte SST. Wird auch verwendet, wenn eine Anfrage zum „Bereitstellen meines AWS-Stacks“ oder zum „Hinzufügen eines Lambda/Bucket/einer Tabelle“ in einem Repository gestellt wird, das bereits eine sst.config.ts (mit $config) oder eine SST-Abhängigkeit enthält. NICHT verwenden, wenn es sich bei der Aufgabe hauptsächlich um AWS CDK, Terraform, Raw CloudFormation oder SAM ohne vorhandenes SST handelt – diese verfügen über ihre eigenen Tools.
