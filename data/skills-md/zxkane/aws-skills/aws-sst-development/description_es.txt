Experto en SST v4 (Ion) para administrar recursos de AWS como código con el marco respaldado por Pulumi. Úselo al escribir o editar sst.config.ts, crear infraestructura/módulos (sst.aws.Function/Bucket/Dynamo/Cron/Service/Router, sst.Secret, sst.Linkable, recursos raw aws.* Pulumi), conectar enlaces de recursos, determinar el alcance de IAM o ejecutar sst implementar/dev/diff/remove. Esencial cuando el usuario menciona SST, sst.config.ts, $config, $transform, $interpolate, sst.aws.*, sst.Secret, Pulumi/Ion, "sst implementar", una implementación de SST fallida (ConflictException en un cambio de tipo de recurso, "El identificador '__filename' ya ha sido declarado", MalformedPolicyDocument en una salida<T>), o desea realizar scaffolding/solucionar problemas de infraestructura de AWS con SST. Utilícelo también cuando se realice una solicitud para "implementar mi pila de AWS" o "agregar un Lambda/bucket/table" en un repositorio que ya contiene un sst.config.ts (usando $config) o una dependencia sst. NO lo use cuando la tarea sea principalmente AWS CDK, Terraform, CloudFormation sin formato o SAM sin SST presente; estos tienen sus propias herramientas.
