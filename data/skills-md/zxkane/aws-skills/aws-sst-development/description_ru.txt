Эксперт SST v4 (Ion) для управления ресурсами AWS в виде кода с помощью инфраструктуры на базе Pulumi. Используйте при написании или редактировании sst.config.ts, создании инфраструктурных модулей (sst.aws.Function/Bucket/Dynamo/Cron/Service/Router, sst.Secret, sst.Linkable, сырые ресурсы aws.* Pulumi), подключении ссылок на ресурсы, определении области действия IAM или запуске sst Deploy/dev/diff/remove. Важно, когда пользователь упоминает SST, sst.config.ts, $config, $transform, $interpolate, sst.aws.*, sst.Secret, Pulumi/Ion, «sst Deploy», неудачное развертывание SST (исключение ConflictException при изменении типа ресурса, «Идентификатор '__filename' уже объявлен», MalformedPolicyDocument на выходе <T>) или хочет создать резервную копию или устранить неполадки. Инфраструктура AWS с SST. Также используйте, когда запрос на «развертывание моего стека AWS» или «добавление Lambda/bucket/table» делается в репозитории, который уже содержит sst.config.ts (с использованием $config) или зависимость sst. НЕ используйте, если задача в основном связана с AWS CDK, Terraform, необработанным CloudFormation или SAM без SST — у них есть свои собственные инструменты.
