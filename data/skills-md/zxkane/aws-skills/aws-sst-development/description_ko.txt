Pulumi 지원 프레임워크를 사용하여 AWS 리소스를 코드로 관리하는 SST v4(Ion) 전문가입니다. sst.config.ts 작성 또는 편집, 인프라/모듈 구축(sst.aws.Function/Bucket/Dynamo/Cron/Service/Router, sst.Secret, sst.Linkable, 원시 aws.* Pulumi 리소스), 리소스 링크 연결, IAM 범위 지정 또는 sst 배포/dev/diff/remove 실행 시 사용합니다. 사용자가 SST, sst.config.ts, $config, $transform, $interpolate, sst.aws.*, sst.Secret, Pulumi/Ion, "sst 배포", 실패한 SST 배포(리소스 유형 변경 시 ContributeException, "'__filename' 식별자가 이미 선언되었습니다.", Output<T>의 MalformedPolicyDocument)를 언급하거나 다음을 원할 때 필수입니다. SST를 사용하여 AWS 인프라를 스캐폴드/문제 해결합니다. 또한 sst.config.ts($config 사용) 또는 sst 종속성이 이미 포함된 리포지토리에서 "AWS 스택 배포" 또는 "Lambda/버킷/테이블 추가" 요청이 이루어진 경우에도 사용합니다. 작업이 주로 AWS CDK, Terraform, 원시 CloudFormation 또는 SST가 없는 SAM인 경우에는 사용하지 마십시오. 이러한 작업에는 자체 도구가 있습니다.
