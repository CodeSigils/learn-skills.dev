SST v4 (Ion) 專家，用於使用 Pulumi 支援的框架以程式碼形式管理 AWS 資源。在編寫或編輯 sst.config.ts、構建基礎設施/模塊（sst.aws.Function/Bucket/Dynamo/Cron/Service/Router、sst.Secret、sst.Linkable、原始 aws.* Pulumi 資源）、連接資源鏈接、確定 IAM 範圍或運行 sst deploy/dev/diff/remove 時使用。當使用者提到 SST、sst.config.ts、$config、$transform、$interpolate、sst.aws.*、sst.Secret、Pulumi/Ion、「sst 部署」、失敗的 SST 部署（資源類型變更上的 ConflictException、「識別碼 '__fileed'已被宣告）基礎設施進行鷹架/故障排除。當在已包含 sst.config.ts（使用 $config）或 sst 依賴項的儲存庫中發出「部署我的 AWS 堆疊」或「新增 Lambda/bucket/table」的請求時也可使用。當任務主要是 AWS CDK、Terraform、原始 CloudFormation 或沒有 SST 的 SAM 時，請勿使用 - 這些都有自己的工具。
