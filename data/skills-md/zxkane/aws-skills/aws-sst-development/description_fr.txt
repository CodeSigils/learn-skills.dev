Expert SST v4 (Ion) pour la gestion des ressources AWS sous forme de code avec le framework soutenu par Pulumi. À utiliser lors de l'écriture ou de la modification de sst.config.ts, de la création de modules infra/ (sst.aws.Function/Bucket/Dynamo/Cron/Service/Router, sst.Secret, sst.Linkable, raw aws.* Pulumi resources), du câblage de liens de ressources, de la portée d'IAM ou de l'exécution de sst déployer/dev/diff/remove. Essentiel lorsque l'utilisateur mentionne SST, sst.config.ts, $config, $transform, $interpolate, sst.aws.*, sst.Secret, Pulumi/Ion, "sst déployer", un échec de déploiement SST (ConflictException sur un changement de type de ressource, "L'identifiant '__filename' a déjà été déclaré", MalformedPolicyDocument sur un Output<T>), ou souhaite échafauder/dépanner l'infrastructure AWS avec SST. À utiliser également lorsqu'une demande de « déployer ma pile AWS » ou « d'ajouter un Lambda/bucket/table » est effectuée dans un dépôt qui contient déjà un sst.config.ts (à l'aide de $config) ou une dépendance sst. Ne pas utiliser lorsque la tâche est principalement AWS CDK, Terraform, CloudFormation brute ou SAM sans SST présent : ceux-ci ont leurs propres outils.
