Pulumi が支援するフレームワークを使用して AWS リソースをコードとして管理するための SST v4 (Ion) エキスパート。 sst.config.ts の作成または編集、infra/ モジュール (sst.aws.Function/Bucket/Dynamo/Cron/Service/Router、sst.Secret、sst.Linkable、生の aws.* Pulumi リソース) の構築、リソース リンクの配線、IAM のスコープ設定、または sstdeploy/dev/diff/remove の実行時に使用します。ユーザーが SST、sst.config.ts、$config、$transform、$interpolate、sst.aws.*、sst.Secret、Pulumi/Ion、「sst デプロイ」、失敗した SST デプロイ (リソース タイプの変更での ConflictException、「識別子 '__filename' はすでに宣言されています」、Output<T> での MalformedPolicyDocument) について言及する場合、または次のことを希望する場合に必須です。 SST を使用して AWS インフラストラクチャを足場/トラブルシューティングします。また、「AWS スタックをデプロイする」または「Lambda/バケット/テーブルを追加する」リクエストが、既に sst.config.ts ($config を使用) または sst 依存関係を含むリポジトリで行われた場合にも使用します。タスクが主に AWS CDK、Terraform、生の CloudFormation、または SST が存在しない SAM である場合は使用しないでください。これらには独自のツールがあります。
