قم بتكوين خوادم AWS MCP للبحث عن الوثائق والوصول إلى واجهة برمجة التطبيقات. يُستخدم عند إعداد AWS MCP، أو تكوين أدوات توثيق AWS، أو استكشاف أخطاء اتصال MCP وإصلاحها، أو عندما يذكر المستخدم aws-mcp، أو awsdocs، أو إعداد uvx، أو تكوين خادم MCP. يغطي كلاً من خادم AWS MCP الكامل (مع بيانات اعتماد uvx +) والوثائق خفيفة الوزن MCP (لا يلزم المصادقة).
