Configure AWS MCP servers for documentation search and API access. Da utilizzare durante la configurazione di AWS MCP, la configurazione degli strumenti di documentazione AWS, la risoluzione dei problemi di connettività MCP o quando l'utente menziona aws-mcp, awsdocs, uvx setup o la configurazione del server MCP. Covers both Full AWS MCP Server (with uvx + credentials) and lightweight Documentation MCP (no auth required).
