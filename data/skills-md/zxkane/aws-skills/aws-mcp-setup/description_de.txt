Konfigurieren Sie AWS MCP-Server für die Dokumentationssuche und den API-Zugriff. Verwenden Sie diese Option, wenn Sie AWS MCP einrichten, AWS-Dokumentationstools konfigurieren, Probleme mit der MCP-Konnektivität beheben oder wenn der Benutzer aws-mcp, awsdocs, uvx setup oder MCP-Serverkonfiguration erwähnt. Deckt sowohl den vollständigen AWS MCP-Server (mit uvx + Anmeldeinformationen) als auch den einfachen Dokumentations-MCP (keine Authentifizierung erforderlich) ab.
