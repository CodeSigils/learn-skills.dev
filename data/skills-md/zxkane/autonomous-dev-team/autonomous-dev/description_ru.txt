Этот навык следует использовать, когда пользователь хочет разработать функцию, исправить ошибку, создать запрос на включение, настроить рабочее дерево git, спроектировать компонент пользовательского интерфейса, написать тестовые примеры, внести изменения, проверить статус CI, адресовать комментарии к проверке, разрешить потоки проверки, запустить проверки ботов (проверка /q, проверка /codex) или следовать рабочему процессу разработки TDD. Охватывает полный жизненный цикл: от холста проектирования до создания рабочего дерева, разработки с упором на тестирование, проверки кода, создания PR, проверки CI, взаимодействия с ботами-ревьютерами, тестирования E2E и очистки рабочего дерева. Поддерживает интерактивный и полностью автономный режимы реализации задач GitHub.
