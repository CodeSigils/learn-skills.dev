يجب استخدام هذه المهارة عندما يريد المستخدم تطوير ميزة، أو إصلاح خطأ، أو إنشاء طلب سحب، أو إعداد شجرة عمل git، أو تصميم مكون واجهة المستخدم، أو كتابة حالات اختبار، أو دفع التغييرات، أو التحقق من حالة CI، أو تعليقات مراجعة العنوان، أو حل سلاسل المراجعة، أو تشغيل مراجعات الروبوت (مراجعة / q، أو مراجعة codex)، أو متابعة سير عمل تطوير TDD. يغطي دورة الحياة الكاملة بدءًا من لوحة التصميم وحتى إنشاء شجرة العمل، وتطوير الاختبار الأول، ومراجعة التعليمات البرمجية، وإنشاء العلاقات العامة، والتحقق من CI، وتفاعل روبوت المراجع، واختبار E2E، وتنظيف شجرة العمل. يدعم الأوضاع التفاعلية والمستقلة بالكامل لتنفيذ مشكلات GitHub.
