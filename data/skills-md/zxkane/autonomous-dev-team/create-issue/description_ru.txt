Этот навык следует использовать, когда пользователь просит «создать проблему», «заявить об ошибке», «создать запрос функции», «открыть проблему GitHub», «сообщить об ошибке», «запросить функцию», «создать задачу», «разбить это на проблемы» или описывает функцию/ошибку, которую он хочет отслеживать в GitHub. Управляет интерактивным созданием задач с помощью структурированных шаблонов, вложений изменений в рабочую область и дополнительной автономной метки для автоматизированного конвейера.
