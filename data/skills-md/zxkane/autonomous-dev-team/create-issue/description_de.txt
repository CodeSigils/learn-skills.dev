Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „ein Problem erstellen“, „einen Fehler einreichen“, „eine Funktionsanfrage erstellen“, „ein GitHub-Problem öffnen“, „einen Fehler melden“, „eine Funktion anfordern“, „eine Aufgabe erstellen“, „dies in Probleme aufteilen“ auffordert oder eine Funktion/einen Fehler beschreibt, den er in GitHub verfolgen möchte. Leitet die interaktive Problemerstellung mit strukturierten Vorlagen, Arbeitsbereichsänderungsanhang und optionaler autonomer Beschriftung für die automatisierte Pipeline.
