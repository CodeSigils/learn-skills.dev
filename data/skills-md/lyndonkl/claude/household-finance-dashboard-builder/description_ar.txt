ينشئ لوحة معلومات HTML ثابتة واحدة مستقلة لمتجر JSON للتمويل المنزلي، مع D3.js المضمنة والبيانات المضمنة وستة لوحات قياسية (صافي القيمة بمرور الوقت، والتدفق النقدي الشهري، والاشتراكات المتكررة، وتقدم الأهداف، وتخصيص الأصول، وموجز اليقظة). يطبق مبادئ التصميم المعرفي للتسلسل الهرمي البصري وتصميم رواية القصص المرئية للشروح السردية. يُستخدم عند إرسال لوحة معلومات مالية أسبوعية أو شهرية، أو عندما يذكر المستخدم لوحة معلومات أسبوعية، أو لوحة معلومات منزلية، أو تقرير HTML مالي، أو لوحة معلومات ثابتة.
