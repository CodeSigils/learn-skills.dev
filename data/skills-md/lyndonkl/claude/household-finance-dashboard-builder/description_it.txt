Genera un unico dashboard HTML statico autonomo per un negozio JSON di finanza domestica, con D3.js incorporato, dati incorporati e sei pannelli standard (patrimonio netto nel tempo, flusso di cassa mensile, ricorrenti e abbonamenti, progresso degli obiettivi, allocazione delle risorse, feed di vigilanza). Applica i principi di progettazione cognitiva per la gerarchia visiva e la progettazione visiva della narrazione per le annotazioni narrative. Da utilizzare quando si crea un dashboard finanziario settimanale o mensile oppure quando l'utente menziona un dashboard settimanale, un dashboard familiare, un report finanziario HTML o un dashboard statico.
