Группирует набор сохраненных статей в 2-5 тематических кластеров перед синтезом, используя абстрактную семантику + перекрытие совпадающих ключевых слов. Называет каждый кластер коротким существительным, описывающим то, что обсуждается в кластере, а не только тему. Вызывает корзину «выбросов» для отдельных тем, которые не подходят. Независимый от домена — можно использовать для любого рабочего процесса сканирования литературы. Используйте после фильтрации по релевантности и перед написанием сводного отчета. Ключевые слова-триггеры: группировать статьи, группировать по темам, тематические группы, темы статей, систематизировать статьи.
