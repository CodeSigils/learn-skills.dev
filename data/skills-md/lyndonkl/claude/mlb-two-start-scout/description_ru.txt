Для данной фэнтезийной недели (понедельник-воскресенье) определяет каждого стартового питчера, который должен выйти в стартовом составе дважды, проверяет оба вероятных старта, оценивает каждый матч по правилам подсчета очков за качество стартов (QS) лиги и ранжирует список по потокуstreamability_score. Флаги игры в КПЗ и риски открытия, которые почти никогда не приводят к QS. Используйте, когда пользователь упоминает «питчеры с двумя стартами», «еженедельную трансляцию», «план питчера с понедельника по воскресенье», «двойной старт», «SP с двумя стартами» или подготовку еженедельного плана трансляций в воскресенье вечером.
