يحدد المبلغ النقدي الذي يمكن للشركة إرجاعه إلى المساهمين وما إذا كان سيتم استخدام أرباح الأسهم أو عمليات إعادة الشراء أو الأرباح المحتجزة. يقارن العوائد النقدية الفعلية بقدرة FCFE، ويحدد النقد الزائد في الميزانية العمومية، ويوصي بسياسة عائد مثالية. يُستخدم عند تحليل سياسة توزيع الأرباح، أو تقييم عمليات إعادة شراء الأسهم، أو تقييم قدرة الإرجاع النقدي، أو عندما يذكر المستخدم سياسة توزيع الأرباح، أو إعادة الشراء، أو إعادة شراء الأسهم، أو FCFE، أو نسبة الدفع، أو الإرجاع النقدي، أو النقد الزائد.
