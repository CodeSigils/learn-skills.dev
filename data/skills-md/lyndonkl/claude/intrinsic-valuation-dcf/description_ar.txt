إجراء تقييم للتدفقات النقدية المخصومة باستخدام متغير النموذج المناسب (DDM أو FCFE أو FCFF) مع مراحل نمو قابلة للتكوين. تنتج توقعات التدفق النقدي سنة بعد سنة، والقيمة النهائية، وجسر الأسهم (طرح الديون، وإضافة النقدية، وطرح قيمة الخيار)، والقيمة الجوهرية للسهم الواحد، وتحليل الحساسية. يُستخدم عند تقييم شركة بشكل جوهري، أو إنشاء نموذج التدفقات النقدية المخصومة، أو تقدير القيمة العادلة، أو عندما يذكر المستخدم التدفقات النقدية المخصومة، أو التدفق النقدي المخصوم، أو القيمة الجوهرية، أو القيمة النهائية، أو تقييم التدفق النقدي الحر.
