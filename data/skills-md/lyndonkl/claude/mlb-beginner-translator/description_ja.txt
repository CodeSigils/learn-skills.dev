野球とファンタジー野球の専門用語を、野球の知識がゼロのユーザー向けにわかりやすい英語に変換します。 MLB エージェント チームが作成したユーザー向けのすべての文 (朝のブリーフィング、トレードに関する推奨事項、ウェイバー コール、チャットの概要) をラップします。専門用語を検出し、文書内の最初の言及にインラインの括弧付きの平易な英語の光沢を付け、アクションと動詞のラダー (START / SIT / ADD / DROP / BID $X / ACCEPT / COUNTER / REJECT) を強制し、「ホット ストリーク」や「ポジティブ マッチアップ」などの知識を想定したフレーズを拒否します。初心者向けに翻訳する、平易な英語で説明する、これを翻訳する、専門用語を使わずに書く、初心者向けにする、または K L D'Souza の Fantasy Baseball 2K25 チーム向けにユーザー向けの MLB 出力を作成するように求められた場合に使用します。
