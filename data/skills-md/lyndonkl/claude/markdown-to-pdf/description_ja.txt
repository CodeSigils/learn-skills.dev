Pandoc と xelatex を使用して、マークダウン レポートを PDF にレンダリングします (11 ポイントのセリフ本文、1 インチの余白、番号付き脚注、正式な見出し階層)。ユーザーのマシンに Pandoc と LaTeX エンジン (macOS の Basictex、Linux の texlive-xetex) を 1 回だけインストールする必要があります。自動インストールは試行しません。ユーザーの PATH に Pandoc または xelatex がない場合、正確なインストール コマンドは大声で失敗します。洗練されたマークダウン ソースから完成したストラテジストまたはアナリスト レポートの PDF を作成する場合に使用します。
