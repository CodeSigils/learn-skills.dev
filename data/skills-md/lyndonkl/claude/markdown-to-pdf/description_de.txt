Rendert einen Markdown-Bericht mithilfe von Pandoc mit Xelatex in ein PDF (11pt-Serifentext, 1-Zoll-Ränder, nummerierte Fußnoten, formale Überschriftenhierarchie). Erfordert eine einmalige Installation von pandoc und einer LaTeX-Engine auf dem Computer des Benutzers – basictex unter macOS oder texlive-xetex unter Linux. Versucht keine automatische Installation. Schlägt lautstark mit den genauen Installationsbefehlen fehl, wenn pandoc oder xelatex im PATH des Benutzers fehlt. Verwenden Sie diese Option, wenn Sie einen fertigen Strategen- oder Analystenbericht im PDF-Format aus einer ausgefeilten Markdown-Quelle erstellen.
