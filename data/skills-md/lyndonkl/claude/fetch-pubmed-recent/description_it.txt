Recupera gli articoli PubMed pubblicati in una determinata finestra di data corrispondente a un set di parole chiave, restituendo record normalizzati (PMID, titolo, autori, abstract, rivista, data, DOI, URL). Utilizza le utilità elettroniche NCBI ("esearch" + "esummary" + "efetch") tramite WebFetch per la portabilità, ma preferisce gli strumenti "search_articles" + "get_article_metadata" di un server MCP PubMed quando è connesso (più veloce, impaginato, analizzato). Crea query limitate alla data con espansione MeSH opzionale. Indipendente dal dominio: utilizzabile per qualsiasi scansione PubMed, non solo per un progetto. Da utilizzare quando l'utente menziona PubMed, NCBI, PubMed degli ultimi N giorni, scansione PubMed settimanale, ricerca MeSH o quando un agente di scansione della letteratura necessita di record PubMed strutturati.
