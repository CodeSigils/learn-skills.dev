جلب مقالات PubMed المنشورة في نافذة تاريخ معينة مطابقة لمجموعة كلمات رئيسية، وإرجاع السجلات المقيسة (PMID، العنوان، المؤلفون، الملخص، المجلة، التاريخ، DOI، URL). يستخدم أدوات NCBI الإلكترونية (`esearch` + ``الملخص`` + `efetch`) عبر WebFetch لسهولة النقل، لكنه يفضل أدوات `search_articles` + `get_article_metadata` الخاصة بخادم PubMed MCP عندما يكون أحدهم متصلاً (أسرع، ومرقّم، ومُحلل). ينشئ استعلامات محددة بالتاريخ مع توسيع MeSH الاختياري. محايد للمجال - يمكن استخدامه لأي فحص لـ PubMed، وليس لمشروع واحد فقط. يُستخدم عندما يذكر المستخدم PubMed، أو NCBI، أو PubMed لآخر N-days، أو فحص PubMed الأسبوعي، أو بحث MeSH، أو عندما يحتاج وكيل مسح الأدبيات إلى سجلات PubMed منظمة.
