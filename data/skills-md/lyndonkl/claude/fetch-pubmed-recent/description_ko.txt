키워드 세트와 일치하는 특정 날짜 창에 게시된 PubMed 기사를 가져오고 정규화된 레코드(PMID, 제목, 저자, 초록, 저널, 날짜, DOI, URL)를 반환합니다. 이식성을 위해 WebFetch를 통해 NCBI E-유틸리티(`esearch` + `esummary` + `efetch`)를 사용하지만, 연결된 경우(빠름, 페이지 매김, 구문 분석) PubMed MCP 서버의 `search_articles` + `get_article_metadata` 도구를 선호합니다. 선택적 MeSH 확장을 사용하여 날짜 제한 쿼리를 작성합니다. 도메인 중립 - 하나의 프로젝트가 아닌 모든 PubMed 스캔에 사용할 수 있습니다. 사용자가 PubMed, NCBI, 최근 N일 PubMed, 주간 PubMed 스캔, MeSH 검색을 언급하거나 문헌 스캔 에이전트에 구조화된 PubMed 레코드가 필요한 경우에 사용합니다.
