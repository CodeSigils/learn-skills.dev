Извлекает статьи PubMed, опубликованные в заданном окне даты, соответствующие набору ключевых слов, возвращая нормализованные записи (PMID, заголовок, авторы, аннотация, журнал, дата, DOI, URL). Использует электронные утилиты NCBI (search + esummary + efetch) через WebFetch для переносимости, но предпочитает инструменты search_articles + get_article_metadata сервера PubMed MCP, когда они подключены (быстрее, с разбивкой на страницы, анализом). Создает запросы с привязкой к дате с дополнительным расширением MeSH. Независимый от домена — можно использовать для любого сканирования PubMed, а не только для одного проекта. Используйте, когда пользователь упоминает PubMed, NCBI, PubMed за последние N дней, еженедельное сканирование PubMed, поиск MeSH или когда агенту сканирования литературы требуются структурированные записи PubMed.
