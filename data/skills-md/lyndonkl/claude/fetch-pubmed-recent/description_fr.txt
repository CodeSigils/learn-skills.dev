Récupère les articles PubMed publiés dans une fenêtre de date donnée correspondant à un ensemble de mots-clés, renvoyant des enregistrements normalisés (PMID, titre, auteurs, résumé, journal, date, DOI, URL). Utilise les utilitaires électroniques NCBI (`esearch` + `esummary` + `efetch`) via WebFetch pour la portabilité, mais préfère les outils `search_articles` + `get_article_metadata` d'un serveur PubMed MCP lorsqu'il est connecté (plus rapide, paginé, analysé). Crée des requêtes limitées par date avec une extension MeSH facultative. Indépendant du domaine : utilisable pour n'importe quelle analyse PubMed, pas seulement pour un seul projet. À utiliser lorsque l'utilisateur mentionne PubMed, NCBI, PubMed des N derniers jours, l'analyse PubMed hebdomadaire, la recherche MeSH ou lorsqu'un agent d'analyse de la littérature a besoin d'enregistrements PubMed structurés.
