Recupera artículos de PubMed publicados en una ventana de fecha determinada que coincide con un conjunto de palabras clave y devuelve registros normalizados (PMID, título, autores, resumen, revista, fecha, DOI, URL). Utiliza NCBI E-utilities (`esearch` + `esummary` + `efetch`) a través de WebFetch para mayor portabilidad, pero prefiere las herramientas `search_articles` + `get_article_metadata` de un servidor PubMed MCP cuando uno está conectado (más rápido, paginado, analizado). Crea consultas con fecha limitada con expansión MeSH opcional. Dominio neutral: utilizable para cualquier escaneo de PubMed, no solo para un proyecto. Úselo cuando el usuario mencione PubMed, NCBI, PubMed de los últimos N días, escaneo semanal de PubMed, búsqueda MeSH o cuando un agente de escaneo de literatura necesite registros estructurados de PubMed.
