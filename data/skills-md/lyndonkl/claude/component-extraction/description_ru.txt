Предметно-нейтральная методология для третьего уровня чтения в стиле Адлера – извлечение структурированных компонентов (терминов, предложений, аргументов, решений) из документа по разделам. Выбирает стратегию чтения, соответствующую размеру и структуре документа (на основе разделов для документов объемом менее 50 страниц с четкими разделами; оконное отображение для длинных документов без перерывов; ориентировано на гибридное содержимое, где важны только определенные разделы). Записывает примечания по извлечению для каждого раздела, которые могут быть использованы для последующего синтеза. Возможность многократного использования в любом рабочем процессе извлечения данных — создание навыков на основе методологического документа, понимание содержания Pass-2 в полном тексте статьи, сбор доказательств из развернутого отчета. Используйте, когда агент выполнил структурный анализ и теперь ему необходимо извлечь фактическое атомарное содержимое. Триггерные ключевые слова - извлечение компонентов, извлечение по разделам, извлечение терминов, извлечение предложений, извлечение аргументов, уровень Адлера 3, интерпретативное чтение.
