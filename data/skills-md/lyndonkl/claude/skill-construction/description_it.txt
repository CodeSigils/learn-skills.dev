Metodologia per costruire una competenza Claude Code adeguatamente strutturata (SKILL.md + risorse opzionali + rubrica di valutazione) da componenti estratti. Valuta la complessità (Livello 1 semplice - solo SKILL.md; Livello 2 moderato - SKILL.md più 1-3 risorse; Livello 3 complesso - SKILL.md più 4-8 risorse), pianifica il raggruppamento delle risorse, redige SKILL.md seguendo le migliori pratiche di creazione di Anthropic (frontmatter conciso con cosa + quando si attiva, corpo sotto le 500 righe, divulgazione progressiva ai file di risorse a un livello di profondità, elenchi di controllo del flusso di lavoro) e costruisce una valutazione rubrica. Utilizzare quando si hanno a portata di mano i componenti estratti e un verdetto di sintesi e il passo successivo è materializzarli come abilità. Attiva parole chiave: costruisci abilità, costruisci SKILL.md, costruzione di abilità, impalcature di abilità, genera file di abilità.
