Методология построения правильно структурированного навыка Claude Code (SKILL.md + дополнительные ресурсы + рубрика оценки) из извлеченных компонентов. Оценивает сложность (уровень 1 простой — только SKILL.md; уровень 2 средний — SKILL.md плюс 1–3 ресурса; уровень 3 сложный — SKILL.md плюс 4–8 ресурсов), планирует группировку ресурсов, составляет черновик SKILL.md в соответствии с лучшими практиками разработки Anthropic (краткое описание с указанием «что + когда триггеры», текст до 500 строк, постепенное раскрытие файлов ресурсов на один уровень глубины, контрольные списки рабочего процесса) и строит оценочную рубрику. Используйте, когда извлеченные компоненты и вердикт синтеза уже на руках и следующим шагом является их материализация в качестве навыка. Ключевые слова-триггеры - создание навыков, создание SKILL.md, создание навыков, формирование навыков, создание файлов навыков.
