Создавайте финансовый анализ институционального уровня: сравнительный анализ компаний, оценка DCF, модель LBO и рабочие процессы с электронными таблицами Excel.

**Функции:**
- Анализ конкурентоспособности: создавайте сопоставимый анализ компаний с помощью коэффициентов оценки.
- Модель DCF: модели оценки дисконтированных денежных потоков.
- Модель LBO: моделирование выкупа с использованием заемных средств.
- 3 отчета: отчет о прибылях и убытках, балансовый отчет, интеграция денежных потоков.

**Активируйте, когда:** Пользователь хочет финансовое моделирование, оценку компании, инвестиционный анализ, сделки по слияниям и поглощениям, отчеты Excel.

**Примечание.** Этот навык обеспечивает методологию анализа. Финансовые данные в режиме реального времени требуют внешних источников данных (API, Bloomberg и т. д.).
