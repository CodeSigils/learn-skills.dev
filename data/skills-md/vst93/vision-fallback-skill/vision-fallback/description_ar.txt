فهم الرؤية/الصورة للوكلاء الذين لا يستطيع نموذجهم قراءة الصور (إرجاع "النموذج لا يدعم الصور"، أو مخرجات فارغة/غير معروفة، أو ثقة منخفضة، أو فشل أبلغ عنه المستخدم). يستدعي واجهة برمجة تطبيقات الرؤية المتوافقة مع OpenAI (doubao أو أي مزود متوافق مع OpenAI)، ويعيد JSON المنظم. يُستخدم عندما يجب فهم الصورة. لا تستبدل بـ OCR المحلي (tesseract) - يستخرج OCR النص فقط، وليس التخطيط/الفهم البصري.
