Понимание видения/изображения для агентов, модель которых не может читать изображения (возвращает «модель не поддерживает изображения», пустой/неизвестный вывод, низкая достоверность или сбой, о котором сообщает пользователь). Вызывает OpenAI-совместимый API видения (doubao или любой OpenAI-совместимый поставщик), возвращает структурированный JSON. Используйте всякий раз, когда изображение необходимо понять. НЕ заменяйте локальное OCR (тессеракт) — OCR извлекает только текст, а не макет/визуальное понимание.
