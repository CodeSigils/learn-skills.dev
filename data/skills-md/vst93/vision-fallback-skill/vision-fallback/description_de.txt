Vision-/Bildverständnis für Agenten, deren Modell keine Bilder lesen kann (gibt „Modell unterstützt keine Bilder“, leere/unbekannte Ausgabe, geringe Konfidenz oder vom Benutzer gemeldeter Fehler zurück). Ruft eine OpenAI-kompatible Vision-API auf (doubao oder ein beliebiger OpenAI-kompatibler Anbieter) und gibt strukturiertes JSON zurück. Immer dann verwenden, wenn ein Bild verstanden werden muss. NICHT durch lokale OCR (Tesseract) ersetzen – OCR extrahiert nur Text, nicht Layout/visuelles Verständnis.
