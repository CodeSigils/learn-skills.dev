Audita proyectos de agentes de IA para detectar riesgos de seguridad en indicaciones, herramientas, memoria, RAG y permisos. Úselo cuando: el usuario solicita revisar la seguridad del agente, fortalecer un sistema de agente, verificar riesgos de inyección rápida, auditar permisos de herramientas o asegurar un asistente de IA antes de la implementación. NO lo use para: proyectos sin componentes agentes, equipos rojos en tiempo de ejecución o generación de exploits.
