Audite les projets d’agents IA pour détecter les risques de sécurité dans les invites, les outils, la mémoire, le RAG et les autorisations. À utiliser lorsque : l'utilisateur demande à revoir la sécurité de l'agent, à renforcer un système agent, à vérifier les risques d'injection rapide, à auditer les autorisations de l'outil ou à sécuriser un assistant IA avant le déploiement. Ne PAS utiliser pour : des projets sans composants agentiques, sans équipe rouge d'exécution ou génération d'exploits.
