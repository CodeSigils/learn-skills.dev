Überprüft KI-Agent-Projekte auf Sicherheitsrisiken in Eingabeaufforderungen, Tools, Speicher, RAG und Berechtigungen. Verwenden Sie diese Option, wenn: Der Benutzer möchte die Agentensicherheit überprüfen, ein Agentensystem härten, auf Risiken bei der sofortigen Injektion prüfen, Tool-Berechtigungen prüfen oder einen KI-Assistenten vor der Bereitstellung sichern. NICHT verwenden für: Projekte ohne Agentenkomponenten, Runtime Red Teaming oder Exploit-Generierung.
