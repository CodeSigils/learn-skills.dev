يدقق مشاريع وكيل الذكاء الاصطناعي للمخاطر الأمنية في المطالبات والأدوات والذاكرة وRAG والأذونات. يُستخدم عندما: يطلب المستخدم مراجعة أمان الوكيل، أو تعزيز نظام الوكيل، أو التحقق من مخاطر الحقن الفوري، أو أذونات أداة التدقيق، أو تأمين مساعد الذكاء الاصطناعي قبل النشر. لا تستخدمه في: المشاريع التي لا تحتوي على مكونات وكيلة، أو الفريق الأحمر في وقت التشغيل، أو توليد الاستغلال.
