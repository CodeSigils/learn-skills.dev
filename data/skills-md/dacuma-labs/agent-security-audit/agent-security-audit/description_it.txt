Controlla i progetti degli agenti AI per rilevare eventuali rischi per la sicurezza in prompt, strumenti, memoria, RAG e autorizzazioni. Da utilizzare quando: l'utente chiede di rivedere la sicurezza dell'agente, rafforzare un sistema di agenti, verificare i rischi di iniezione tempestiva, controllare le autorizzazioni dello strumento o proteggere un assistente AI prima della distribuzione. NON utilizzare per: progetti senza componenti agenti, red teaming di runtime o generazione di exploit.
