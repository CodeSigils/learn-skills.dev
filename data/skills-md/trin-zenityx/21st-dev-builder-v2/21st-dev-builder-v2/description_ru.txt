Создавайте веб-сайты и веб-приложения с помощью 21st.dev — крупнейшего рынка компонентов React Tailwind на основе shadcn/ui, включающего более 1400 компонентов. Используйте, когда пользователь упоминает «21st.dev», «21st», «ใช้ 21st», «จาก 21st», «сборка с 21st», «21st компонент», «21st Magic MCP» или ссылается на реестр компонентов 21st.dev на любом языке. Охватывает создание полноценных сайтов (целевые страницы, информационные панели, портфолио, витрины магазинов электронной коммерции, страницы аутентификации), просмотр и установку отдельных компонентов 21st.dev в существующие проекты, а также настройку сервера 21st.dev MCP. Также срабатывает, когда пользователю нужны премиум-компоненты пользовательского интерфейса конкретно из реестра 21st.dev. НЕ запускайте триггер для общей веб-разработки, стандартного shadcn/ui, простого CSS Tailwind, React Native, разработки API, тестирования, развертывания или любых задач, которые явно не ссылаются на 21st или 21st.dev.
