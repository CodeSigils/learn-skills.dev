Многоцелевой дизайн связывающего белка на основе градиента с помощью Mosaic. Используйте этот навык, когда: (1) объединяете несколько моделей структур или последовательностей в одну цель проектирования, (2) оптимизируете связующие с учетом пользовательских потерь, а не фиксированного конвейера, (3) хотите градиентного спуска по пространству последовательностей в стиле ColabDesign, RSO или BindCraft, но со взаимозаменяемыми предикторами, (4) позволяете оптимизатору выбирать эпитоп вместо исправления горячих точек.
Для сквозного конвейера связывания с фильтрами по умолчанию используйте bindcraft. Для проектирования диффузии всех атомов используйте Boltzgen. Для генерации только магистральной сети используйте RFDiffusion.
