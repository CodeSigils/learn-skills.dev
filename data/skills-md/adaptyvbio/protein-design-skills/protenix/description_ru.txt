Прогнозирование структуры с помощью Protenix, открытой репродукции AlphaFold3. Используйте этот навык, когда: (1) прогнозируете сложные структуры с помощью модели класса AF3, (2) ищете открытую альтернативу AF3 наряду с Больцем и Чаем, (3) проверяете разработанные комплексы связующее-мишень.
Для порогов контроля качества используйте белок-QC. Для ранжирования ipSAE используйте ipsae.
