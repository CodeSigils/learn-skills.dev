تنفيذ بوابة k-ID العمرية - نقطة الدخول لأي تكامل k-ID كامل الجلسة (الشكل أ)، الذي يغطي كل نظام (COPPA، وGDPR-Kids، وUK AADC، وUK OSA، وBrazil ECA Digital، وAustralia Online Safety). طريقتان: النموذج أ (الافتراضي) يبني واجهة مستخدم مخصصة بالكامل ويستدعي /age-gate/check مباشرة - أفضل مظهر، وأكثر تكاملاً مع العلامات التجارية، ويعمل على كل منصة (الويب، Unity WebGL، وحدات التحكم، الأصلية)؛ النموذج B عبارة عن مسار احتياطي سريع باستخدام عنصر واجهة المستخدم k-ID (/widget/generate-age-gate-url أو /widget/generate-e2e-url — يتعامل iframe مع التجميع العمري ويبدأ الموافقة تلقائيًا). يغطي الحالة العمرية الأولية الفارغة، وإشارات النظام الأساسي أولاً، والسلطة القضائية المستندة إلى IP مع احتياطي المنطقة الزمنية، وأشكال الاستجابة / بوابة العمر / التحقق (الجلسة، التحدي، البالغ الذي لم يتم التحقق منه). يُستخدم عند إضافة البوابة أو تصحيح أخطائها. استخدم حتى إذا كان المستخدم يقول COPPA، أو OSA، أو ECA، أو "التحقق من العمر" ولكنه يعني التحقق الأولي من العمر المزعوم. ليس لـ AgeKit+ (التحقق من عمر k-id P1)، أو التحقق بعد البوابة/العتبة (P2–3)، أو الموافقة (k-id-consent-and-challenges).
