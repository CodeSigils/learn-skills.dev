k-ID エイジ ゲートを実装します。これは、あらゆる体制 (COPPA、GDPR-Kids、英国 AADC、英国 OSA、ブラジル ECA デジタル、オーストラリア オンライン セーフティ) をカバーする、完全なセッション化された k-ID 統合 (シェイプ A) のエントリ ポイントです。 2 つのアプローチ: パターン A (デフォルト) は、完全なカスタム UI を構築し、/age-gate/check を直接呼び出します。見た目が最も良く、最もブランドに統合されており、あらゆるプラットフォーム (Web、Unity WebGL、コンソール、ネイティブ) で動作します。パターン B は、k-ID ウィジェット (/widget/generate-age-gate-url または /widget/generate-e2e-url — iframe が年齢収集を処理し、同意を自動開始します) を使用した高速パス フォールバックです。 null の初期年齢状態、最初のプラットフォーム信号、タイムゾーン フォールバックを備えた IP ベースの管轄区域、および /age-gate/check 応答形状 (セッション、チャレンジ、未認証アダルト) をカバーします。ゲートの追加またはデバッグ時に使用します。ユーザーが COPPA、OSA、ECA、または「年齢確認」と言っている場合でも、それが最初の年齢確認の確認を意味する場合でも使用してください。 AgeKit+ (k-id-age-verification P1)、ポストゲート / しきい値検証 (P2–3)、または同意 (k-id-consent-and-challenges) には適用されません。
