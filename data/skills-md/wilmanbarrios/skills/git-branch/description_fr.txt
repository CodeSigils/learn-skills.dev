Créez des branches git bien nommées avec des conventions de dénomination cohérentes. Guide à travers le type de branche, la description et la sélection de la branche cible. DÉCLENCHEMENT lorsque : l'utilisateur appelle /git-branch, demande de créer une nouvelle branche, souhaite commencer à travailler sur une nouvelle fonctionnalité/correctif/tâche, ou un agent doit créer une branche git dans le cadre d'une tâche. NE PAS DÉCLENCHER lorsque : l'utilisateur souhaite basculer vers une branche existante, supprimer une branche ou renommer une branche.
