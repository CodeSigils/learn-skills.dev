Crea rami git con nomi appropriati con convenzioni di denominazione coerenti. Guida attraverso il tipo di ramo, la descrizione e la selezione del ramo di destinazione. TRIGGER quando: l'utente invoca /git-branch, chiede di creare un nuovo ramo, vuole iniziare a lavorare su una nuova funzionalità/correzione/attività oppure un agente deve creare un ramo git come parte di un'attività. NON ATTIVARE quando: l'utente desidera passare a un ramo esistente, eliminare un ramo o rinominare un ramo.
