Создавайте ветки git с правильными именами и согласованными соглашениями об именах. Помогает выбрать тип ветки, описание и выбор целевой ветки. ТРИГГЕР, когда: пользователь вызывает /git-branch, просит создать новую ветку, хочет начать работу над новой функцией/исправлением/задачой или агенту необходимо создать ветку git как часть задачи. НЕ ЗАПУСКАТЬ, когда: пользователь хочет переключиться на существующую ветку, удалить ветку или переименовать ветку.
