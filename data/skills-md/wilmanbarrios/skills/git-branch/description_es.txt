Cree ramas de git bien nombradas con convenciones de nomenclatura consistentes. Guía a través del tipo de sucursal, descripción y selección de sucursal objetivo. DISPARAR cuando: el usuario invoca /git-branch, solicita crear una nueva rama, quiere comenzar a trabajar en una nueva característica/arreglo/tarea, o un agente necesita crear una rama de git como parte de una tarea. NO DISPARAR cuando: el usuario quiera cambiar a una rama existente, eliminar una rama o cambiar el nombre de una rama.
