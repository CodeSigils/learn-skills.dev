Erstellen Sie gut benannte Git-Branches mit konsistenten Namenskonventionen. Führt durch den Zweigtyp, die Beschreibung und die Auswahl des Zielzweigs. TRIGGER, wenn: Der Benutzer /git-branch aufruft, um die Erstellung eines neuen Zweigs bittet, mit der Arbeit an einer neuen Funktion/Fix/Aufgabe beginnen möchte oder ein Agent einen Git-Zweig als Teil einer Aufgabe erstellen muss. NICHT AUSLÖSEN, wenn: Der Benutzer zu einem vorhandenen Zweig wechseln, einen Zweig löschen oder einen Zweig umbenennen möchte.
