قم بإنشاء فروع git ذات أسماء جيدة مع اصطلاحات تسمية متسقة. أدلة من خلال نوع الفرع والوصف واختيار الفرع المستهدف. يتم تشغيله عندما: يستدعي المستخدم /git-branch، أو يطلب إنشاء فرع جديد، أو يريد بدء العمل على ميزة/إصلاح/مهمة جديدة، أو يحتاج الوكيل إلى إنشاء فرع git كجزء من مهمة. لا تقم بالتشغيل عندما: يريد المستخدم التبديل إلى فرع موجود، أو حذف فرع، أو إعادة تسمية فرع.
