قم بتقييم وتحسين مطالبات المهام أو قواعد النظام بشكل متكرر باستخدام نظام تسجيل سداسي الأبعاد. يكتشف تلقائيًا ما إذا كان الإدخال بمثابة مطالبة أم قاعدة ويقوم بتبديل معايير التسجيل وفقًا لذلك. يُستخدم عندما يذكر المستخدم "موجه التحسين"، أو "تحسين الموجه"، أو "تسجيل النقاط الفوري"، أو "تحسين الموجه"، أو "الموجه الموجه"، أو "الموجه المحسن"، أو "قواعد الموجه"، أو "الموجه المحسن"، أو "تحسين القاعدة"، أو عندما يريد تحسين جودة أي موجه أو قاعدة.
