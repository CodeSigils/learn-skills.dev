PR 검토, 버그 찾기, 코드 검토, "이 PR 검토", "버그 확인", "이 PR에서 문제 찾기"를 트리거합니다. 이는 5개의 병렬 패스, 다수 투표, 독립적인 Opus 검증 및 해결 비율 추적을 갖춘 다중 패스 검토 워크플로우입니다. 또한 /bug-review:resolve를 트리거하여 병합 시 발견 사항이 수정되었는지 여부를 분류하고, 해결률 통계를 보려면 /bug-review:report를 트리거합니다. 사용자가 PR 분기에서 "이것을 검토하세요"라고만 말하더라도 이 스킬이 발동됩니다.
