このスキルは、ユーザーがプル リクエストのバグのレビューを要求した場合、正確性の問題に焦点を当てた AI コード レビューを希望した場合、または /bug-review を実行した場合に使用します。 PR レビュー、バグ発見、コード レビュー、「この PR をレビューする」、「バグをチェックする」、「この PR で問題を見つける」をトリガーします。これは、5 つの並列パス、多数決、独立した Opus 検証、および解決率追跡を含むマルチパス レビュー ワークフローです。また、/bug-review:resolve でトリガーしてマージ時に検出結果が修正されたかどうかを分類し、/bug-review:report で解決率統計をトリガーします。ユーザーが PR ブランチ上で「これを確認してください」と言った場合でも、このスキルをトリガーします。
