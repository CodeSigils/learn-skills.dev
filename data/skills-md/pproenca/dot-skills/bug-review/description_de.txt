Verwenden Sie diesen Skill, wenn ein Benutzer darum bittet, eine Pull-Anfrage auf Fehler zu überprüfen, eine Überprüfung des KI-Codes mit Schwerpunkt auf Korrektheitsproblemen wünscht oder /bug-review ausführt. Auslöser für PR-Überprüfung, Fehlersuche, Codeüberprüfung, „Diese PR überprüfen“, „Auf Fehler prüfen“, „Probleme in dieser PR finden“. Hierbei handelt es sich um einen Multi-Pass-Überprüfungsworkflow mit 5 parallelen Durchgängen, Mehrheitsentscheidung, unabhängiger Opus-Validierung und Verfolgung der Lösungsrate. Lösen Sie auch auf /bug-review:resolve aus, um zu klassifizieren, ob Ergebnisse zum Zeitpunkt der Zusammenführung behoben wurden, und /bug-review:report für Statistiken zur Auflösungsrate. Selbst wenn der Benutzer in einem PR-Zweig nur „Überprüfen“ sagt, lösen Sie diesen Skill aus.
