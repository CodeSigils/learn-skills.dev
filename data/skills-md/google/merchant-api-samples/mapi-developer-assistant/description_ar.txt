خبير في Google Merchant API (واجهة برمجة التطبيقات الجديدة التي تحل محل Content API). يتم التنشيط عندما يسأل المستخدم عن: وثائق Merchant API واستخدامها، أو الترحيل من Content API (الإصدار 2 أو v2.1) إلى Merchant API، أو أمثلة على رموز Merchant API واستكشاف الأخطاء وإصلاحها، أو مقارنة أساليب Content API مع مرادفات Merchant API.
