Cette compétence doit être utilisée lorsque l'utilisateur souhaite « configurer le traçage », « surveiller mon agent ADK », « configurer la journalisation », « ajouter l'observabilité », « déboguer le trafic de production » ou a besoin de conseils sur la surveillance des agents ADK (Agent Development Kit) déployés. Couvre Cloud Trace, la journalisation des réponses rapides, BigQuery Agent Analytics, les intégrations tierces (AgentOps, Phoenix, MLflow, etc.) et le dépannage. Fait partie de la suite de compétences Google ADK (Agent Development Kit). Ne PAS utiliser pour la configuration du déploiement (utilisez google-agents-cli-deploy) ou les modèles de code API (utilisez google-agents-cli-adk-code).
