このスキルは、ユーザーが「トレースの設定」、「ADK エージェントの監視」、「ログの構成」、「可観測性の追加」、「運用トラフィックのデバッグ」を行う場合、またはデプロイされた ADK (エージェント開発キット) エージェントの監視に関するガイダンスが必要な場合に使用する必要があります。 Cloud Trace、プロンプトレスポンス ロギング、BigQuery Agent Analytics、サードパーティ統合（AgentOps、Phoenix、MLflow など）、トラブルシューティングについて説明します。 Google ADK (エージェント開発キット) スキル スイートの一部。デプロイ設定 (google-agents-cli-deploy を使用) または API コード パターン (google-agents-cli-adk-code を使用) には使用しないでください。
