Esta habilidad debe usarse cuando el usuario desea "configurar el seguimiento", "supervisar mi agente ADK", "configurar el registro", "agregar observabilidad", "depurar el tráfico de producción" o necesita orientación sobre cómo monitorear los agentes ADK (kit de desarrollo de agentes) implementados. Cubre Cloud Trace, registro de respuesta rápida, BigQuery Agent Analytics, integraciones de terceros (AgentOps, Phoenix, MLflow, etc.) y solución de problemas. Parte del conjunto de habilidades Google ADK (Agent Development Kit). NO lo use para la configuración de implementación (use google-agents-cli-deploy) ni para patrones de código API (use google-agents-cli-adk-code).
