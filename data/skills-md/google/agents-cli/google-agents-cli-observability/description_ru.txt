Этот навык следует использовать, когда пользователь хочет «настроить трассировку», «мониторить мой агент ADK», «настроить ведение журнала», «добавить возможность наблюдения», «отладить производственный трафик» или нуждается в руководстве по мониторингу развернутых агентов ADK (Agent Development Kit). Охватывает Cloud Trace, ведение журналов быстрого реагирования, BigQuery Agent Analytics, сторонние интеграции (AgentOps, Phoenix, MLflow и т. д.) и устранение неполадок. Часть набора навыков Google ADK (Agent Development Kit). НЕ используйте для настройки развертывания (используйте google-agents-cli-deploy) или шаблоны кода API (используйте google-agents-cli-adk-code).
