Questa competenza deve essere utilizzata quando l'utente desidera "impostare la traccia", "monitorare l'agente ADK", "configurare la registrazione", "aggiungere osservabilità", "debug del traffico di produzione" o necessita di indicazioni sul monitoraggio degli agenti ADK (Agent Development Kit) distribuiti. Copre Cloud Trace, registrazione delle risposte rapide, BigQuery Agent Analytics, integrazioni di terze parti (AgentOps, Phoenix, MLflow e così via) e risoluzione dei problemi. Parte della suite di competenze Google ADK (Agent Development Kit). NON utilizzare per la configurazione della distribuzione (utilizza google-agents-cli-deploy) o modelli di codice API (utilizza google-agents-cli-adk-code).
