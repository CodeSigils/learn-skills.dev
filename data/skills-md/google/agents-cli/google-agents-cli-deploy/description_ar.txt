يجب استخدام هذه المهارة عندما يريد المستخدم "نشر وكيل"، أو "نشر وكيل ADK الخاص بي"، أو "إعداد CI/CD"، أو "تكوين الأسرار"، أو "استكشاف أخطاء النشر وإصلاحها"، أو يحتاج إلى إرشادات حول أهداف نشر Agent Runtime أو Cloud Run أو GKE. يغطي سير عمل النشر وحسابات الخدمة والتراجع والبنية التحتية للإنتاج. جزء من مجموعة مهارات Google ADK (Agent Development Kit). لا تستخدم لأنماط كود واجهة برمجة التطبيقات (استخدم google-agents-cli-adk-code)، أو التقييم (استخدم google-agents-cli-eval)، أو سقالات المشروع (استخدم google-agents-cli-scaffold).
