Esta habilidad debe usarse cuando el usuario desea "implementar un agente", "implementar mi agente ADK", "configurar CI/CD", "configurar secretos", "solucionar problemas de una implementación" o necesita orientación sobre los objetivos de implementación de Agent Runtime, Cloud Run o GKE. Cubre flujos de trabajo de implementación, cuentas de servicio, reversión e infraestructura de producción. Parte del conjunto de habilidades Google ADK (Agent Development Kit). NO lo use para patrones de código API (use google-agents-cli-adk-code), evaluación (use google-agents-cli-eval) o andamiaje de proyectos (use google-agents-cli-scaffold).
