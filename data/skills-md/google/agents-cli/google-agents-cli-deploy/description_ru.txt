Этот навык следует использовать, когда пользователь хочет «развернуть агент», «развернуть мой агент ADK», «настроить CI/CD», «настроить секреты», «устранить неполадки при развертывании» или нуждается в руководстве по целям развертывания среды выполнения агента, Cloud Run или GKE. Охватывает рабочие процессы развертывания, учетные записи служб, откат и производственную инфраструктуру. Часть набора навыков Google ADK (Agent Development Kit). НЕ используйте шаблоны кода API (используйте google-agents-cli-adk-code), оценку (используйте google-agents-cli-eval) или каркас проекта (используйте google-agents-cli-scaffold).
