Questa competenza deve essere utilizzata quando l'utente desidera "distribuire un agente", "distribuire il mio agente ADK", "configurare CI/CD", "configurare segreti", "risolvere i problemi di una distribuzione" o ha bisogno di indicazioni sulle destinazioni di distribuzione Agent Runtime, Cloud Run o GKE. Copre flussi di lavoro di distribuzione, account di servizio, rollback e infrastruttura di produzione. Parte della suite di competenze Google ADK (Agent Development Kit). NON utilizzare per modelli di codice API (utilizza google-agents-cli-adk-code), valutazione (utilizza google-agents-cli-eval) o impalcature di progetto (utilizza google-agents-cli-scaffold).
