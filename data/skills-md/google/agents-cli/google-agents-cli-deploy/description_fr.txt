Cette compétence doit être utilisée lorsque l'utilisateur souhaite « déployer un agent », « déployer mon agent ADK », « configurer CI/CD », « configurer des secrets », « dépanner un déploiement » ou a besoin de conseils sur les cibles de déploiement d'Agent Runtime, Cloud Run ou GKE. Couvre les workflows de déploiement, les comptes de service, la restauration et l'infrastructure de production. Fait partie de la suite de compétences Google ADK (Agent Development Kit). Ne PAS utiliser pour les modèles de code API (utilisez google-agents-cli-adk-code), l'évaluation (utilisez google-agents-cli-eval) ou l'échafaudage de projet (utilisez google-agents-cli-scaffold).
