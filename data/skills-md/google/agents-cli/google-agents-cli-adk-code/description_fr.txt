Cette compétence doit être utilisée lorsque l'utilisateur souhaite « écrire du code d'agent », « créer un agent avec ADK », « ajouter un outil », « créer un rappel », « définir un agent », « utiliser la gestion d'état » ou a besoin de modèles d'API Python et d'exemples de code ADK (Agent Development Kit). Fait partie de la suite de compétences Google ADK. Il fournit une référence rapide sur les types d'agents, les définitions d'outils, les modèles d'orchestration, les rappels et la gestion des états. Ne PAS utiliser pour créer de nouveaux projets (utilisez google-agents-cli-scaffold) ou pour le déploiement (utilisez google-agents-cli-deploy).
