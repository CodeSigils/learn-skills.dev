このスキルは、ユーザーが「エージェント コードを作成する」、「ADK を使用してエージェントを構築する」、「ツールを追加する」、「コールバックを作成する」、「エージェントを定義する」、「状態管理を使用する」場合、または ADK (エージェント開発キット) Python API パターンとコード サンプルが必要な場合に使用する必要があります。 Google ADK スキル スイートの一部。エージェントの種類、ツール定義、オーケストレーション パターン、コールバック、および状態管理のクイック リファレンスを提供します。新しいプロジェクトの作成 (google-agents-cli-scaffold を使用) またはデプロイメント (google-agents-cli-deploy を使用) には使用しないでください。
