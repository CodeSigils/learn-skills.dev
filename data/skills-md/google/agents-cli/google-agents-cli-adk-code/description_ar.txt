يجب استخدام هذه المهارة عندما يريد المستخدم "كتابة رمز الوكيل"، أو "إنشاء وكيل باستخدام ADK"، أو "إضافة أداة"، أو "إنشاء رد اتصال"، أو "تحديد وكيل"، أو "استخدام إدارة الحالة"، أو يحتاج إلى أنماط ADK (مجموعة تطوير الوكيل) Python API وأمثلة التعليمات البرمجية. جزء من مجموعة مهارات Google ADK. فهو يوفر مرجعًا سريعًا لأنواع الوكلاء وتعريفات الأدوات وأنماط التنسيق وعمليات الاسترجاعات وإدارة الحالة. لا تستخدم لإنشاء مشاريع جديدة (استخدم google-agents-cli-scaffold) أو النشر (استخدم google-agents-cli-deploy).
