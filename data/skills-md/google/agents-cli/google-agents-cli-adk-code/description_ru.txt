Этот навык следует использовать, когда пользователь хочет «написать код агента», «создать агент с помощью ADK», «добавить инструмент», «создать обратный вызов», «определить агент», «использовать управление состоянием» или ему нужны шаблоны API Python ADK (комплект разработки агентов) и примеры кода. Часть набора навыков Google ADK. Он предоставляет краткий справочник по типам агентов, определениям инструментов, шаблонам оркестрации, обратным вызовам и управлению состоянием. НЕ используйте для создания новых проектов (используйте google-agents-cli-scaffold) или развертывания (используйте google-agents-cli-deploy).
