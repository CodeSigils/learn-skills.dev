Cette compétence doit être utilisée lorsque l'utilisateur souhaite « créer un projet d'agent », « démarrer un nouveau projet ADK », « créer un nouvel agent », « ajouter CI/CD à mon projet », « ajouter un déploiement », « améliorer mon projet » ou « mettre à niveau mon projet ». Fait partie de la suite de compétences Google ADK (Agent Development Kit). Couvre les commandes « agents-cli scaffold create », « scaffold enhancement » et « scaffold Upgrade », les options de modèle, les cibles de déploiement et le flux de travail du prototype d'abord. Ne PAS utiliser pour écrire du code d'agent (utilisez google-agents-cli-adk-code) ou pour des opérations de déploiement (utilisez google-agents-cli-deploy).
