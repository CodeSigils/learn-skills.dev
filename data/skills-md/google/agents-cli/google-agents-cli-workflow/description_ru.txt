Этот навык следует использовать, когда пользователь хочет «разработать агент», «создать агент с использованием ADK», «запустить агент локально», «отладить код агента», «протестировать агент», «развернуть агент», «опубликовать агент», «мониторить агент» или ему необходимы рекомендации по жизненному циклу разработки и написанию кода ADK (Agent Development Kit). Точка входа для создания агентов ADK. Всегда активен — предоставляет полный рабочий процесс (подготовку, сборку, оценку, развертывание, публикацию, наблюдение), правила сохранения кода, рекомендации по выбору модели и шаги по устранению неполадок для ADK или разработки любого агента.
