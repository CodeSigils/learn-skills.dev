Cette compétence doit être utilisée lorsque l'utilisateur souhaite « développer un agent », « créer un agent à l'aide d'ADK », « exécuter l'agent localement », « déboguer le code de l'agent », « tester un agent », « déployer un agent », « publier un agent », « surveiller un agent » ou a besoin du cycle de vie de développement et des directives de codage de l'ADK (Agent Development Kit). Point d’entrée pour la création d’agents ADK. Toujours actif : fournit le flux de travail complet (échafaudage, création, évaluation, déploiement, publication, observation), les règles de préservation du code, des conseils de sélection de modèle et des étapes de dépannage pour ADK ou tout développement d'agent.
