Esta habilidad debe usarse cuando el usuario desea "ejecutar una evaluación", "evaluar mi agente ADK", "escribir un conjunto de evaluaciones", "depurar puntuaciones de evaluación", "comparar resultados de evaluación" o necesita orientación sobre la metodología de evaluación de ADK (kit de desarrollo de agentes) y el bucle de corrección de evaluación. Cubre métricas de evaluación, esquema de conjunto de evaluaciones, LLM como juez, puntuación de trayectoria de herramientas y causas de fallas comunes. Parte del conjunto de habilidades Google ADK (Agent Development Kit). NO lo use para patrones de código API (use google-agents-cli-adk-code), implementación (use google-agents-cli-deploy) o andamiaje de proyectos (use google-agents-cli-scaffold).
