Этот навык следует использовать, когда пользователь хочет «провести оценку», «оценить моего агента ADK», «написать набор оценок», «отладить оценки оценки», «сравнить результаты оценки» или нуждается в руководстве по методологии оценки ADK (Agent Development Kit) и циклу оценки-исправления. Охватывает метрики оценки, схему набора оценок, LLM как судья, оценку траектории инструмента и распространенные причины сбоев. Часть набора навыков Google ADK (Agent Development Kit). НЕ используйте шаблоны кода API (используйте google-agents-cli-adk-code), развертывание (используйте google-agents-cli-deploy) или создание шаблонов проекта (используйте google-agents-cli-scaffold).
