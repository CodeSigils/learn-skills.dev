このスキルは、ユーザーが「評価の実行」、「ADK エージェントの評価」、「評価セットの作成」、「評価スコアのデバッグ」、「評価結果の比較」を行う場合、または ADK (エージェント開発キット) の評価方法と eval-fix ループに関するガイダンスが必要な場合に使用する必要があります。評価メトリクス、評価セット スキーマ、ジャッジとしての LLM、ツール軌道スコアリング、および一般的な失敗の原因について説明します。 Google ADK (エージェント開発キット) スキル スイートの一部。 API コード パターン (google-agents-cli-adk-code を使用)、デプロイメント (google-agents-cli-deploy を使用)、またはプロジェクト スキャフォールディング (google-agents-cli-scaffold を使用) には使用しないでください。
