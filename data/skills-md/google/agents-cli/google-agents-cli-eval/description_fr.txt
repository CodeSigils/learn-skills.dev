Cette compétence doit être utilisée lorsque l'utilisateur souhaite « exécuter une évaluation », « évaluer mon agent ADK », « écrire un ensemble d'évaluations », « déboguer les scores d'évaluation », « comparer les résultats d'évaluation » ou a besoin de conseils sur la méthodologie d'évaluation ADK (Agent Development Kit) et la boucle eval-fix. Couvre les métriques d'évaluation, le schéma d'évaluation, le LLM en tant que juge, la notation de la trajectoire des outils et les causes d'échec courantes. Fait partie de la suite de compétences Google ADK (Agent Development Kit). Ne PAS utiliser pour les modèles de code API (utilisez google-agents-cli-adk-code), le déploiement (utilisez google-agents-cli-deploy) ou l'échafaudage de projet (utilisez google-agents-cli-scaffold).
