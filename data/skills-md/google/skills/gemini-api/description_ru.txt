Руководства по использованию API Gemini на платформе агентов с помощью Google Gen AI SDK. Используйте, когда пользователь спрашивает об использовании Gemini в корпоративной среде или явно упоминает Vertex AI, Google Cloud или платформу агентов. Охватывает использование SDK (Python, JS/TS, Go, Java, C#), такие возможности, как Live API, инструменты, генерацию мультимедиа, кэширование и пакетное прогнозирование.
