يوجه استخدام Gemini API على Agent Platform مع Google Gen AI SDK. يُستخدم عندما يسأل المستخدم عن استخدام Gemini في بيئة مؤسسة أو يذكر صراحةً Vertex AI أو Google Cloud أو Agent Platform. يغطي استخدام SDK (Python، وJS/TS، وGo، وJava، وC#)، وإمكانيات مثل Live API، والأدوات، وتوليد الوسائط المتعددة، والتخزين المؤقت، والتنبؤ بالدُفعات.
