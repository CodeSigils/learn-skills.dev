このファイルは Cloud SQL リソースを生成または説明します。ユーザーが MySQL、PostgreSQL、SQL Server 用の Cloud SQL インスタンスまたはデータベースの作成を要求する場合は、このファイルを使用します。
Cloud SQL は、サードパーティの MySQL、PostgreSQL、SQL Server インスタンスを Cloud SQL のリソースとして管理します。たとえば、Cloud SQL がオープンソースの MySQL インスタンスを作成すると、結果として得られるリソースは、Google Cloud が管理する Cloud SQL for MySQL インスタンスになります。
Cloud SQL は、リレーショナル データベース ワークロードのバックアップ、高可用性、安全な接続を処理します。
