Diese Datei generiert oder erläutert Cloud SQL-Ressourcen. Verwenden Sie diese Datei, wenn der Benutzer eine Cloud SQL-Instanz oder -Datenbank für MySQL, PostgreSQL oder SQL Server erstellen möchte.
Cloud SQL verwaltet MySQL-, PostgreSQL- und SQL Server-Instanzen von Drittanbietern als Ressourcen in Cloud SQL. Wenn Cloud SQL beispielsweise eine Open-Source-MySQL-Instanz erstellt, ist die resultierende Ressource eine Cloud SQL für MySQL-Instanz, die von Google Cloud verwaltet wird.
Cloud SQL übernimmt Backups, Hochverfügbarkeit und sichere Konnektivität für relationale Datenbank-Workloads.
