Ce fichier génère ou explique les ressources Cloud SQL. Utilisez ce fichier lorsque l'utilisateur demande à créer une instance ou une base de données Cloud SQL pour MySQL, PostgreSQL ou SQL Server.
Cloud SQL gère les instances tierces MySQL, PostgreSQL et SQL Server en tant que ressources dans Cloud SQL. Par exemple, lorsque Cloud SQL crée une instance MySQL Open Source, la ressource résultante est une instance Cloud SQL pour MySQL gérée par Google Cloud.
Cloud SQL gère les sauvegardes, la haute disponibilité et la connectivité sécurisée pour les charges de travail de bases de données relationnelles.
