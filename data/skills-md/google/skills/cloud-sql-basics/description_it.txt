Questo file genera o spiega le risorse Cloud SQL. Utilizza questo file quando l'utente chiede di creare un'istanza o un database Cloud SQL per MySQL, PostgreSQL o SQL Server.
Cloud SQL gestisce istanze MySQL, PostgreSQL e SQL Server di terze parti come risorse in Cloud SQL. Ad esempio, quando Cloud SQL crea un'istanza MySQL open source, la risorsa risultante è un'istanza Cloud SQL per MySQL gestita da Google Cloud.
Cloud SQL gestisce backup, disponibilità elevata e connettività sicura per i carichi di lavoro dei database relazionali.
