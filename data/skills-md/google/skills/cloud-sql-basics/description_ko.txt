이 파일은 Cloud SQL 리소스를 생성하거나 설명합니다. 사용자가 MySQL, PostgreSQL, SQL Server용 Cloud SQL 인스턴스나 데이터베이스 생성을 요청할 때 이 파일을 사용하세요.
Cloud SQL은 타사 MySQL, PostgreSQL, SQL Server 인스턴스를 Cloud SQL의 리소스로 관리합니다. 예를 들어 Cloud SQL이 오픈소스 MySQL 인스턴스를 만들면 결과 리소스는 Google Cloud가 관리하는 MySQL용 Cloud SQL 인스턴스입니다.
Cloud SQL은 관계형 데이터베이스 워크로드를 위한 백업, 고가용성, 보안 연결을 처리합니다.
