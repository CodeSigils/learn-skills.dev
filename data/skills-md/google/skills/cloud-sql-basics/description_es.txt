Este archivo genera o explica los recursos de Cloud SQL. Utilice este archivo cuando el usuario solicite crear una instancia o base de datos de Cloud SQL para MySQL, PostgreSQL o SQL Server.
Cloud SQL administra instancias de MySQL, PostgreSQL y SQL Server de terceros como recursos en Cloud SQL. Por ejemplo, cuando Cloud SQL crea una instancia de MySQL de código abierto, el recurso resultante es una instancia de Cloud SQL para MySQL que administra Google Cloud.
Cloud SQL maneja copias de seguridad, alta disponibilidad y conectividad segura para cargas de trabajo de bases de datos relacionales.
