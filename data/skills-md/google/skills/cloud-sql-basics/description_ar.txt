يُنشئ هذا الملف موارد Cloud SQL أو يشرحها. استخدم هذا الملف عندما يطلب المستخدم إنشاء مثيل Cloud SQL أو قاعدة بيانات لـ MySQL أو PostgreSQL أو SQL Server.
يدير Cloud SQL مثيلات MySQL وPostgreSQL وSQL Server التابعة لجهات خارجية كموارد في Cloud SQL. على سبيل المثال، عندما يقوم Cloud SQL بإنشاء مثيل MySQL مفتوح المصدر، فإن المورد الناتج هو Cloud SQL لمثيل MySQL الذي يديره Google Cloud.
يتعامل Cloud SQL مع النسخ الاحتياطية والتوفر العالي والاتصال الآمن لأحمال عمل قواعد البيانات الارتباطية.
