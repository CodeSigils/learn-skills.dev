Этот файл создает или объясняет ресурсы Cloud SQL. Используйте этот файл, когда пользователь запрашивает создание экземпляра или базы данных Cloud SQL для MySQL, PostgreSQL или SQL Server.
Cloud SQL управляет сторонними экземплярами MySQL, PostgreSQL и SQL Server как ресурсами в Cloud SQL. Например, когда Cloud SQL создает экземпляр MySQL с открытым исходным кодом, результирующим ресурсом является экземпляр Cloud SQL для MySQL, которым управляет Google Cloud.
Cloud SQL обеспечивает резервное копирование, высокую доступность и безопасное подключение для рабочих нагрузок реляционных баз данных.
