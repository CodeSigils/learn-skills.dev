Verwaltet Cloud Run-Dienste, Jobs und Worker-Pools. Verwenden Sie diese Option, wenn Sie Anwendungen bereitstellen müssen, die auf HTTP-Anfragen reagieren (Dienste), ereignisgesteuerte oder geplante Aufgaben ausführen (Jobs) oder eine ständig aktive Pull-basierte Hintergrundverarbeitung (Worker-Pools) durchführen müssen.
