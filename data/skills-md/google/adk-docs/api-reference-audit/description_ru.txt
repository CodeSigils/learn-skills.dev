Проверяет актуальность справочной документации API ADK и строк, привязанных к версии, во всех языковых SDK. Сравнивает версии в репозитории с вышестоящими выпусками и реестрами пакетов, затем сообщает, что необходимо изменить и какой процесс следует выполнить, и создает исполняемый план только по запросу. Триггеры по «ссылке на API аудита», «проверить справочную документацию API», «обновлены ли документы API», «обновить версии документации API», «проверить версии документации SDK».
