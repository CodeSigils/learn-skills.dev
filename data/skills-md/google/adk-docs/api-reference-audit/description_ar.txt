يدقق ما إذا كانت المستندات المرجعية لـ ADK API والسلاسل المثبتة بالإصدار محدثة عبر جميع مجموعات SDK للغات. يقارن إصدارات الريبو بالإصدارات الأولية وسجلات الحزم، ثم يبلغ عن ما يحتاج إلى تحديث والعملية التي يجب اتباعها، ويصدر خطة قابلة للتنفيذ فقط عند الطلب. المشغلات على "مرجع واجهة برمجة التطبيقات للتدقيق"، و"التحقق من مستندات مرجع واجهة برمجة التطبيقات"، و"هل مستندات واجهة برمجة التطبيقات محدثة"، و"إصدارات مستند واجهة برمجة التطبيقات"، و"التحقق من إصدارات مستند SDK".
