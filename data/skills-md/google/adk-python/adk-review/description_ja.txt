adk-python ワーキング ツリー内のコミットされていない変更をレビューし、正確性、設計、パブリック API の安定性、テスト、サンプル、ドキュメントのギャップを優先順位付けされた調査結果レポートとして報告し、要求された場合にのみ修正します。ユーザーがローカルの変更をレビューするように要求する場合、プル リクエストを開く前にセルフレビューを希望する場合、変更がパブリック API に違反するかどうか、テスト、サンプル、またはドキュメントが必要かどうかを尋ねる場合、または現在の diff の何が問題なのかを尋ねる場合に使用します。パブリック API、コア アーキテクチャ (Runner、Workflow、BaseNode)、新機能、および主要なリファクタリングへの変更に必要です。単一スタイルの nit (adk-style を使用)、失敗したテストや実行時のエージェントの誤動作の診断 (adk-debug を使用)、またはコミット メッセージや PR の説明の文言 (adk-git を使用) には使用しないでください。
