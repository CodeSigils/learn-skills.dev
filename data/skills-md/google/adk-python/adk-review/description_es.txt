Revisa los cambios no confirmados en un árbol de trabajo de adk-python e informa la corrección, el diseño, la estabilidad de la API pública, las pruebas, las muestras y las lagunas en la documentación como un informe de hallazgos priorizados, y los corrige solo cuando se le solicita. Úselo cuando el usuario solicita revisar los cambios locales, desea una autoevaluación antes de abrir una solicitud de extracción, pregunta si un cambio interrumpe la API pública o necesita pruebas, muestras o documentos, o pregunta qué hay de malo en la diferencia actual. Requerido para cambios en las API públicas, la arquitectura central (Runner, Workflow, BaseNode), nuevas funciones y refactorizaciones importantes. No lo use para un solo estilo nit (use adk-style), para diagnosticar una prueba fallida o un agente que se comporta mal en tiempo de ejecución (use adk-debug) o para redactar un mensaje de confirmación o una descripción de PR (use adk-git).
