Richtet eine lokale ADK-Python-Entwicklungsumgebung in einem Git-Klon des Open-Source-Adk-Python-Repositorys ein: eine virtuelle UV-Umgebung, alle Abhängigkeits-Extras, Pre-Commit-Hooks und einen ersten Unit-Testlauf. Wird nur auf ausdrückliche Anfrage ausgeführt, niemals alleine. Verwenden Sie diese Option, wenn Sie aufgefordert werden, einen Entwicklungs-Checkout einzurichten, zu booten oder zu reparieren, Projektabhängigkeiten zu installieren, eine fehlende oder defekte .venv-Datei zu reparieren oder eine Maschine für die Bereitstellung einer Pull-Anfrage vorzubereiten. Nicht zum Debuggen eines laufenden Agenten (verwenden Sie adk-debug), für Commit- und Pull-Request-Mechaniken (verwenden Sie adk-git) oder zum erneuten Ausführen von Formatierern bei einem bereits eingerichteten Checkout (pre-commit run --all-files) verwenden.
