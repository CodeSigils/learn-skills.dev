Configure un environnement de développement ADK Python local dans un clone git du référentiel open source adk-python : un environnement virtuel uv, tous les extras de dépendance, des hooks de pré-validation et une première exécution de test unitaire. S'exécute uniquement lorsque cela est explicitement demandé, jamais seul. À utiliser lorsqu'on vous demande de configurer, d'amorcer ou de réparer une extraction de développement, d'installer des dépendances de projet, de réparer un .venv manquant ou cassé ou de préparer une machine pour contribuer à une demande d'extraction. Ne pas utiliser pour déboguer un agent en cours d'exécution (utilisez adk-debug), pour les mécanismes de validation et de demande d'extraction (utilisez adk-git) ou pour réexécuter les formateurs sur une extraction déjà configurée (exécution préalable à la validation --all-files).
