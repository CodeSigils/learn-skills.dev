Configura un entorno de desarrollo local de ADK Python en un clon de git del repositorio de código abierto adk-python: un entorno virtual uv, todos los extras de dependencia, enlaces de confirmación previa y una primera ejecución de prueba unitaria. Se ejecuta sólo cuando se solicita explícitamente, nunca por sí solo. Úselo cuando se le solicite configurar, iniciar o reparar una verificación de desarrollo, instalar dependencias del proyecto, reparar un .venv faltante o roto, o preparar una máquina para contribuir con una solicitud de extracción. No lo use para depurar un agente en ejecución (use adk-debug), para mecánicas de confirmación y solicitud de extracción (use adk-git) o ​​para volver a ejecutar formateadores en un proceso de pago que ya está configurado (ejecución previa a la confirmación --todos los archivos).
