オープンソースの adk-python リポジトリの git クローンにローカルの ADK Python 開発環境をセットアップします。これには、uv 仮想環境、すべての依存関係の追加機能、事前コミット フック、および最初の単体テストの実行が含まれます。明示的に要求された場合にのみ実行され、単独で実行されることはありません。開発チェックアウトのセットアップ、ブートストラップ、または修復、プロジェクトの依存関係のインストール、欠落または破損した .venv の修正、またはプル リクエストに貢献するためのマシンの準備を求められた場合に使用します。実行中のエージェントのデバッグ (adk-debug を使用)、コミットおよびプルリクエストの仕組み (adk-git を使用)、またはすでに設定されているチェックアウトでのフォーマッタの再実行 (pre-commit run --all-files) には使用しないでください。
