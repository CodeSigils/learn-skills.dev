Configura un ambiente di sviluppo ADK Python locale in un clone git del repository adk-python open source: un ambiente virtuale uv, tutte le dipendenze extra, hook di pre-commit e una prima esecuzione di unit test. Viene eseguito solo quando richiesto esplicitamente, mai da solo. Da utilizzare quando viene richiesto di configurare, avviare o riparare un checkout di sviluppo, installare dipendenze di progetto, correggere un file .venv mancante o danneggiato o preparare una macchina per contribuire con una richiesta pull. Non utilizzare per il debug di un agente in esecuzione (usa adk-debug), per meccanismi di commit e richiesta pull (usa adk-git) o ​​per rieseguire formattatori su un checkout già configurato (pre-commit run --all-files).
