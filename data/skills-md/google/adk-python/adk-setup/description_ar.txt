يقوم بإعداد بيئة تطوير ADK Python محلية في نسخة git لمستودع adk-python مفتوح المصدر: بيئة افتراضية للأشعة فوق البنفسجية، وجميع إضافات التبعية، وخطافات الالتزام المسبق، وتشغيل اختبار الوحدة الأول. يتم تشغيله فقط عند الطلب صراحة، وليس من تلقاء نفسه أبدًا. يُستخدم عندما يُطلب منك إعداد عملية فحص التطوير أو تمهيدها أو إصلاحها، أو تثبيت تبعيات المشروع، أو إصلاح .venv المفقود أو المعطوب، أو إعداد جهاز للمساهمة في طلب سحب. لا تستخدمه لتصحيح أخطاء وكيل قيد التشغيل (استخدم adk-debug)، أو لآليات الالتزام وطلب السحب (استخدم adk-git)، أو لإعادة تشغيل المنسقات في عملية سحب تم إعدادها بالفعل (تشغيل الالتزام المسبق --جميع الملفات).
