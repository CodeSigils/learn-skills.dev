Explica cómo encaja el tiempo de ejecución de ADK: el modelo de ejecución de gráficos y nodos, el flujo de contexto y eventos, el punto de control y la reanudación, el seguimiento y las reglas que rigen la superficie de API pública. Úselo al responder "cómo funciona X" sobre los aspectos internos de ADK, rastrear de dónde proviene un evento o un estado, decidir dónde pertenece una nueva capacidad, revisar un cambio en BaseNode, flujo de trabajo, corredor, agente, evento o contexto, determinar por qué un nodo se volvió a ejecutar o permaneció esperando después de un currículum, o para juzgar si un cambio interrumpe la API pública. No lo use para ensamblar un agente a partir de piezas existentes (use adk-agent-builder), diagnosticar una ejecución o prueba fallida (use adk-debug) o convenciones de formato y nomenclatura (use adk-style).
