ADK ランタイムがどのように組み合わされるかについて説明します。ノードとグラフの実行モデル、コンテキストとイベント フロー、チェックポイントと再開、トレース、パブリック API サーフェスを管理するルールです。 ADK 内部に関する「X はどのように機能するか」に答える場合、イベントまたは状態の一部がどこから来たのかを追跡する場合、新しい機能がどこに属するかを決定する場合、BaseNode、ワークフロー、ランナー、エージェント、イベント、またはコンテキストへの変更を確認する場合、ノードが再実行された理由や再開後に待機したままになった理由を解明した場合、または変更がパブリック API を破壊するかどうかを判断する場合に使用します。既存の要素からエージェントを組み立てる (adk-agent-builder を使用)、失敗した実行またはテストの診断 (adk-debug を使用)、またはフォーマットと命名規則 (adk-style を使用) には使用しないでください。
