Explique comment le runtime ADK s'articule : le modèle d'exécution de nœud et de graphique, le flux de contexte et d'événements, le point de contrôle et la reprise, le traçage et les règles régissant la surface de l'API publique. À utiliser pour répondre à "comment X fonctionne" sur les composants internes d'ADK, tracer l'origine d'un événement ou d'un élément d'état, décider à quoi appartient une nouvelle fonctionnalité, examiner une modification apportée à BaseNode, Workflow, Runner, Agent, Event ou Context, déterminer pourquoi un nœud a été réexécuté ou est resté en attente après une reprise, ou pour juger si une modification interrompt l'API publique. Ne pas utiliser pour assembler un agent à partir de pièces existantes (utilisez adk-agent-builder), pour diagnostiquer un échec d'exécution ou de test (utilisez adk-debug) ou pour des conventions de formatage et de dénomination (utilisez adk-style).
