Conseiller en sécurité proactif et assistant de garde-corps pour le développement de code sécurisé. Utilisez-le pour interroger les modèles de menace, les lignées de vulnérabilités historiques, les modèles de correctifs vérifiés, les faux positifs triés et les invariants de trajectoire appris avant et pendant les modifications de code afin d'éviter des erreurs répétées. Ne pas utiliser pour l'exploitation automatisée ou le fuzzing de red-team multi-passes.
