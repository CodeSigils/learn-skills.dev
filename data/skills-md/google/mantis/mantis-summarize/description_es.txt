Preprocesa el repositorio generando resúmenes centrados en la seguridad (mantis-summary.md) para cada directorio para hacer que la planificación y la investigación sean más eficientes. Úselo al iniciar una campaña de revisión para mapear la base del código antes del modelado y la planificación de amenazas. No lo utilice para ejecutar revisiones de código, escribir scripts de prueba o parchear código.
