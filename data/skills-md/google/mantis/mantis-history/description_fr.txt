Analyse l'historique du système de contrôle de version (VCS) du référentiel pour extraire les vulnérabilités passées, les correctifs de sécurité et les modèles de vulnérabilité. Utiliser comme étape de prétraitement initiale pour créer une base de données de vulnérabilités historiques (workspace/historical_learnings.jsonl) qui informe les étapes suivantes sur les problèmes et correctifs passés. Ne l'utilisez pas pour la révision du code, l'écriture de scripts de test ou l'application de correctifs au code.
