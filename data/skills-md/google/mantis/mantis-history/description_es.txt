Analiza el historial del sistema de control de versiones (VCS) del repositorio para extraer vulnerabilidades pasadas, correcciones de seguridad y patrones de vulnerabilidad. Úselo como paso inicial de preprocesamiento para crear una base de datos histórica de vulnerabilidades (workspace/historical_learnings.jsonl) que informe a las etapas posteriores sobre problemas y soluciones anteriores. No lo utilice para revisiones de código, escritura de scripts de prueba o parcheo de código.
