قم بإنشاء أو تحديث مسودة إصدارات GitHub لمستودع GitHub الرئيسي للمشروع الحالي، ثم قم بتنظيم ملاحظات الإصدار التي تم إنشاؤها بواسطة GitHub في أقسام سهلة الاستخدام دون إعادة كتابة عناصر ملاحظة الإصدار. يُستخدم لإعداد ملاحظات إصدار GitHub أو مسودات الإصدارات أو تنسيقها أو تصنيفها أو إنشائها أو تحديثها، بما في ذلك التمييزات الاختيارية عندما يطلبها المستخدم.
