Personalice los temas de Rspress utilizando variables CSS, ranuras de diseño, ajuste de componentes o expulsión de componentes. Úselo cuando un usuario desee cambiar la apariencia de un sitio Rspress, anular los componentes del tema, agregar contenido personalizado de navegación/barra lateral/pie de página, inyectar proveedores globales o modificar el tema predeterminado de Rspress de cualquier manera. Utilícelo también cuando un usuario mencione theme/index.tsx, espacios de diseño, anulaciones de clases BEM o rspress eject.
