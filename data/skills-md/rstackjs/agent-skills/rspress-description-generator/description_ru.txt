Создавайте и обслуживайте заголовок описания для файлов документации Rspress (.md/.mdx). Используйте, когда пользователь хочет добавить SEO-описания, улучшить фрагменты поисковых систем, сгенерировать метаданные llms.txt, подготовить документы для обобщения AI или пакетно обновить заголовок на сайте документации Rspress. Также используйте при добавлении новых страниц документации в проект Rspress — каждый новый файл документа требует описания.
