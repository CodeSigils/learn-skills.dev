Generare e gestire il frontmatter della descrizione per i file di documentazione Rspress (.md/.mdx). Da utilizzare quando un utente desidera aggiungere descrizioni SEO, migliorare gli snippet dei motori di ricerca, generare metadati llms.txt, preparare documenti per il riepilogo AI o aggiornare in batch il frontmatter in un sito di documenti Rspress. Da utilizzare anche quando si aggiungono nuove pagine di documentazione a un progetto Rspress: ogni nuovo file doc necessita di una descrizione.
