Générer et maintenir le frontmatter de description pour les fichiers de documentation Rspress (.md/.mdx). À utiliser lorsqu'un utilisateur souhaite ajouter des descriptions SEO, améliorer les extraits de moteur de recherche, générer des métadonnées llms.txt, préparer des documents pour le résumé de l'IA ou mettre à jour par lots des éléments de présentation sur un site de documentation Rspress. À utiliser également lors de l'ajout de nouvelles pages de documentation à un projet Rspress : chaque nouveau fichier doc nécessite une description.
