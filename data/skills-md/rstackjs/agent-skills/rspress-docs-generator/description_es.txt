Generar o mantener documentación Rspress para un proyecto. Úselo siempre que el usuario desee crear un nuevo sitio de documentos de Rspress v2, agregar documentos para trabajos de funciones de cara al usuario o relaciones públicas, mantener un proyecto de documentos de Rspress dedicado en un monorepo o evitar la deriva de versiones o andamios obsoletos de Rspress v1 antes del trabajo de documentación. Para una migración completa de v1 a v2, transmítala a la habilidad rspress-v2-upgrade.
