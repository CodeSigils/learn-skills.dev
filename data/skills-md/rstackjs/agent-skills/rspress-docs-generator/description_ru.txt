Создавайте или поддерживайте документацию Rspress для проекта. Используйте, когда пользователь хочет создать новый сайт документации Rspress v2, добавить документы для работы с пользовательскими функциями или PR, сохранить выделенный проект документации Rspress в монорепозитории или предотвратить изменение устаревших шаблонов/версий Rspress v1 до начала работы с документацией. Для полной миграции с версии v1 на версию 2 обратитесь к специалисту по обновлению rspress-v2-upgrade.
