Erstellen oder pflegen Sie die Rspress-Dokumentation für ein Projekt. Verwenden Sie es immer dann, wenn der Benutzer eine neue Rspress v2-Dokumentenseite erstellen, Dokumente für benutzerbezogene Funktionsarbeiten oder PRs hinzufügen, ein dediziertes Rspress v2-Dokumentenprojekt in einem Monorepo verwalten oder veraltete Rspress v1-Gerüste/Versionsdrift vor der Dokumentationsarbeit verhindern möchte. Übergeben Sie für eine vollständige v1-zu-v2-Migration an den Skill „rspress-v2-upgrade“.
