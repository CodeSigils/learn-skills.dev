Générer ou maintenir la documentation Rspress pour un projet. À utiliser chaque fois que l'utilisateur souhaite créer un nouveau site de documentation Rspress v2, ajouter des documents pour le travail de fonctionnalités ou les relations publiques destinés à l'utilisateur, maintenir un projet de documentation Rspress dédié dans un monorepo ou empêcher les échafaudages/versions Rspress v1 obsolètes avant le travail de documentation. Pour une migration complète de v1 vers v2, passez à la compétence rspress-v2-upgrade.
