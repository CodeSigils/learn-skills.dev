Convierta las respuestas complejas o visuales de los agentes en artefactos HTML enriquecidos y revisables sobre los que el usuario pueda anotar y enviar comentarios, e impulse el proceso de planificación de funciones de principio a fin, utilizando la CLI atelier-axi. Úselo cuando esté a punto de dar un plan, comparación, diagrama, tabla, diferencia de código o informe; cuando el usuario dice "planifique esto", "diseñemos X" o "escriba una especificación/plan para Y"; cuando se le solicite "implementar plan.md" o ejecutar un plan terminado; o cualquier cosa más fácil de entender visualmente que en prosa.
