Настройте и проверьте Splunk HTTP Event Collector (HEC), объясните подтверждение индексатора и поведение распределенного HEC, диагностируйте отсутствие данных HEC и сбои доставки HTTP на основе проверенных данных и подготовьте ограниченную передачу обслуживания. Используйте для Splunk Cloud Platform или Splunk Enterprise токены HEC, конечные точки, события или необработанные полезные данные, TLS, каналы, ACK, работоспособность, авторизацию, очереди и проверку доставки; не используйте для приема данных, не связанных с HEC, широкой архитектуры, изменений в белом списке или исправлений на стороне службы.
