Configurez et validez Splunk HTTP Event Collector (HEC), expliquez la reconnaissance de l'indexeur et le comportement HEC distribué, diagnostiquez l'absence de données HEC et les échecs de livraison HTTP à partir de preuves nettoyées, et préparez des transferts d'escalade limités. À utiliser pour les jetons Splunk Cloud Platform ou Splunk Enterprise HEC, les points de terminaison, les charges utiles d'événements ou brutes, TLS, les canaux, l'ACK, l'intégrité, l'autorisation, les files d'attente et la vérification de la livraison ; ne pas utiliser pour une ingestion non-HEC, une architecture large, des modifications de liste verte ou une correction côté service.
