Splunk HTTP Event Collector (HEC) のセットアップと検証、インデクサーの確認応答と分散 HEC の動作の説明、サニタイズされた証拠からの HEC のデータなしと HTTP 配信の失敗の診断、および制限付きエスカレーション ハンドオフの準備を行います。 Splunk Cloud Platform または Splunk Enterprise HEC トークン、エンドポイント、イベントまたは生のペイロード、TLS、チャネル、ACK、ヘルス、認可、キュー、および配信検証に使用します。非 HEC 取り込み、広範なアーキテクチャ、許可リストの変更、またはサービス側の修復には使用しないでください。
