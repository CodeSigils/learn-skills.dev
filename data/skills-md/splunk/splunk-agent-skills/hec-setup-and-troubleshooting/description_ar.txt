قم بإعداد Splunk HTTP Event Collector (HEC) والتحقق من صحته، وشرح إقرار المفهرس وسلوك HEC الموزع، وتشخيص عدم وجود بيانات HEC وفشل تسليم HTTP من الأدلة المعقمة، وإعداد عمليات تسليم التصعيد المحدودة. الاستخدام لرموز Splunk Cloud Platform أو Splunk Enterprise HEC، ونقاط النهاية، وحمولات الأحداث أو الخام، وTLS، والقنوات، وACK، والصحة، والترخيص، وقوائم الانتظار، والتحقق من التسليم؛ لا تستخدم للعرض بخلاف HEC، أو البنية العامة، أو تغييرات القائمة المسموح بها، أو المعالجة من جانب الخدمة.
