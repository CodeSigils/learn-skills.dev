Configura e convalida Splunk HTTP Event Collector (HEC), spiega il riconoscimento dell'indicizzatore e il comportamento HEC distribuito, diagnostica gli errori di consegna HEC senza dati e HTTP da prove disinfettate e prepara passaggi di escalation delimitati. Utilizzare per token HEC, endpoint, eventi o payload grezzi Splunk Cloud Platform o Splunk Enterprise, TLS, canali, ACK, integrità, autorizzazione, code e verifica della consegna; non utilizzare per l'inserimento di contenuti non HEC, un'architettura ampia, modifiche alle liste consentite o correzioni sul lato servizio.
