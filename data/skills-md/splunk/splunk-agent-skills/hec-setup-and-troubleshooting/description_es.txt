Configure y valide el recopilador de eventos HTTP (HEC) de Splunk, explique el reconocimiento del indexador y el comportamiento de HEC distribuido, diagnostique fallas de entrega HTTP y sin datos de HEC a partir de evidencia desinfectada y prepare transferencias de escalamiento acotadas. Úselo para tokens HEC de Splunk Cloud Platform o Splunk Enterprise, puntos finales, eventos o cargas útiles sin procesar, TLS, canales, ACK, estado, autorización, colas y verificación de entrega; no lo use para ingesta que no sea HEC, arquitectura amplia, cambios en la lista de permitidos o corrección del lado del servicio.
