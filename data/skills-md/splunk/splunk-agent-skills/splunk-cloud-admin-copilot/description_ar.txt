اقرأ حالة Splunk Cloud Platform ACS، وقم بتقييم الصيانة أو إعادة التشغيل دون تغييرها، وقم بتنفيذ إضافة أو إزالة IPv4 CIDR معتمدة بشكل صريح لقائمة IP المسموح بها بميزة واحدة من خلال موفر ACS العام الموثق. يُستخدم عندما يحتاج مسؤول السحابة إلى اختبار مبدئي دقيق للهدف، وحد أدنى من تغييرات القائمة المسموح بها، والقراءة، والتراجع، وإيصال مُنقّح؛ توجيه كل كتابة إدارة أخرى ومجال متخصص.
