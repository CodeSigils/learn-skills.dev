تشخيص وتحسين بحث Splunk وظيفي موجود من خلال SPL المتوفرة وأدلة وقت التشغيل. يُستخدم عندما يكون البحث أو التقرير أو لوحة المعلومات أو البحث المجدول بطيئًا أو في قائمة الانتظار أو مكلفًا أو كثيف الاستخدام للموارد أو تم الانتهاء منه قبل الأوان ويحتاج المستخدم إلى ضبط الاستعلام المدعوم بالأدلة أو تحليل ملاءمة التسريع أو فصل عبء العمل أو خطة قابلة للمقارنة قبل وبعد. قم بتوجيه تأليف البحث الجديد، والإصلاح/التوقف الوظيفي، والحوكمة، والعمليات على مستوى النشر إلى مسارات العمل الخاصة بهم.
