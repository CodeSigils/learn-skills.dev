الإجابة على الأسئلة المستشهد بها حول وحدة تحكم مراقبة Splunk Cloud، ووحدة تحكم مراقبة Splunk Enterprise، وتقارير صحة splunkd، ولوحات المعلومات الصحية، وhealth.log، ونقاط النهاية الصحية؛ جمع الأدلة الصحية وتطبيعها؛ توجيه التشخيص المدرك للخصوصية ومجموعة RapidDiag؛ وتفسير الإشارات الصحية المقدمة إلى فرضيات محدودة ودعم عمليات التسليم. يُستخدم لإشارات صحة النشر والأدوات التشخيصية لـ Splunk Cloud Platform أو Splunk Enterprise، وليس التحليل الواسع النطاق للسبب الجذري للحوادث، أو استكشاف الأخطاء وإصلاحها الخاصة بـ HEC، أو تنفيذ SPL العام، أو معالجة المجموعة، أو التحميلات، أو التذاكر، أو تغييرات البيئة.
