Convertissez les tableaux de bord Splunk Simple XML classiques (version 1) en Dashboard Studio (version 2). Prend le XML simple classique en entrée, conserve chaque requête SPL textuellement et renvoie la définition Studio JSON à l'appelant. À utiliser lorsque l'utilisateur demande à convertir, migrer, mettre à niveau, moderniser, porter ou créer une version v2 / Dashboard Studio d'un tableau de bord, d'un formulaire ou d'une vue XML simple Splunk classique existant.
