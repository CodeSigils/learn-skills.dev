Converti le dashboard classiche Splunk Simple XML (versione 1) in Dashboard Studio (versione 2). Accetta il classico XML semplice come input, conserva ogni query SPL alla lettera e restituisce la definizione JSON di Studio al chiamante. Da utilizzare quando l'utente richiede di convertire, migrare, aggiornare, modernizzare, trasferire o creare una versione v2/Dashboard Studio di una dashboard, un modulo o una visualizzazione XML semplice Splunk classica esistente.
