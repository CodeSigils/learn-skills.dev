قم بتحويل لوحات معلومات Splunk Simple XML الكلاسيكية (الإصدار 1) إلى Dashboard Studio (الإصدار 2). يأخذ Simple XML الكلاسيكي كمدخل، ويحتفظ بكل استعلام SPL حرفيًا، ويعيد تعريف Studio JSON إلى المتصل. يُستخدم عندما يطلب المستخدم التحويل أو الترحيل أو الترقية أو التحديث أو المنفذ أو إنشاء إصدار v2 / Dashboard Studio من لوحة معلومات Splunk الكلاسيكية أو النموذج أو عرض XML البسيط.
