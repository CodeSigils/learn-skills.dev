Konvertieren Sie klassische Splunk Simple XML-Dashboards (Version 1) in Dashboard Studio (Version 2). Nimmt klassisches einfaches XML als Eingabe, behält jede SPL-Abfrage wörtlich bei und gibt die Studio-JSON-Definition an den Aufrufer zurück. Verwenden Sie diese Option, wenn der Benutzer ein vorhandenes klassisches Splunk-Dashboard, Formular oder eine einfache XML-Ansicht konvertieren, migrieren, aktualisieren, modernisieren, portieren oder eine v2-/Dashboard Studio-Version erstellen möchte.
