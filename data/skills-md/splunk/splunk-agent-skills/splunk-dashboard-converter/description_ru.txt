Преобразование классических информационных панелей Splunk Simple XML (версия 1) в Dashboard Studio (версия 2). Принимает классический Simple XML в качестве входных данных, дословно сохраняет каждый запрос SPL и возвращает определение Studio JSON вызывающей стороне. Используйте, когда пользователь запрашивает преобразование, миграцию, обновление, модернизацию, перенос или создание версии v2/Dashboard Studio существующей классической информационной панели Splunk, формы или простого XML-представления.
