Convierta los paneles clásicos de Splunk Simple XML (versión 1) en Dashboard Studio (versión 2). Toma XML simple clásico como entrada, conserva cada consulta SPL palabra por palabra y devuelve la definición JSON de Studio a la persona que llama. Úselo cuando el usuario solicite convertir, migrar, actualizar, modernizar, migrar o crear una versión v2/Dashboard Studio de un panel, formulario o vista XML simple de Splunk clásico existente.
