Используйте Obscura — автономный браузер Rust с сервером протокола Chrome DevTools — для быстрого получения страниц, выполнения JS, очистки данных и автоматизации CDP. Встроенная замена CDP для Chrome на Puppeteer или Playwright. Запуск по запросам «открыть страницу», «получить URL-адрес с помощью JS», «очистить сайт», «отобразить эту страницу», «автоматизировать браузер через CDP» или любую задачу, для которой Chrome будет слишком тяжелым. Также используйте, когда пользователь упоминает скрытое снятие отпечатков пальцев, блокировку трекера, маскировку navigator.webdriver или уклонение от базового обнаружения ботов.
