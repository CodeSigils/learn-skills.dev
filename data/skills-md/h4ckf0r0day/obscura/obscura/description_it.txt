Utilizza Obscura, un browser headless Rust con un server Chrome DevTools Protocol, per recuperi rapidi delle pagine, esecuzione JS, scraping e automazione CDP. Sostituzione CDP drop-in per Chrome con Puppeteer o Playwright. Attiva le richieste di "aprire una pagina", "recuperare un URL con JS", "raschiare un sito", "renderizzare questa pagina", "automatizzare il browser tramite CDP" o qualsiasi attività in cui Chrome sarebbe troppo pesante. Da utilizzare anche quando l'utente menziona l'impronta digitale nascosta, il blocco del tracker, il mascheramento di `navigator.webdriver` o l'elusione del rilevamento di base dei bot.
