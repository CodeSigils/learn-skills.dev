Utilice Obscura, un navegador sin cabeza de Rust con un servidor de protocolo Chrome DevTools, para búsquedas rápidas de páginas, ejecución de JS, scraping y automatización de CDP. Reemplazo directo de CDP para Chrome con Puppeteer o Playwright. Activa solicitudes para "abrir una página", "obtener una URL con JS", "extraer un sitio", "presentar esta página", "automatizar el navegador a través de CDP" o cualquier tarea en la que Chrome sería demasiado pesado. Úselo también cuando el usuario mencione huellas dactilares sigilosas, bloqueo de rastreadores, enmascaramiento de `navigator.webdriver` o evadir la detección básica de bots.
