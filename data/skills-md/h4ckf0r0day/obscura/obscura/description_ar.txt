استخدم Obscura - متصفح Rust بدون رأس مع خادم بروتوكول Chrome DevTools - لجلب الصفحات بسرعة، وتنفيذ JS، واستخراج البيانات، وأتمتة CDP. استبدال CDP لمتصفح Chrome باستخدام محرك الدمى أو الكاتب المسرحي. تشغيل طلبات "فتح صفحة"، أو "جلب عنوان URL باستخدام JS"، أو "مسح موقع"، أو "عرض هذه الصفحة"، أو "أتمتة المتصفح عبر CDP"، أو أي مهمة قد يكون Chrome فيها ثقيلًا للغاية. يُستخدم أيضًا عندما يذكر المستخدم بصمات الأصابع الخفية، أو حظر المتعقب، أو إخفاء "navigator.webdriver"، أو التهرب من اكتشاف الروبوتات الأساسية.
