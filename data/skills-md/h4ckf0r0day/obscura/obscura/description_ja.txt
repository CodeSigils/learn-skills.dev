Obscura (Chrome DevTools Protocol サーバーを備えた Rust ヘッドレス ブラウザ) を使用して、高速ページ フェッチ、JS 実行、スクレイピング、CDP 自動化を実現します。 Puppeteer または Playwright を使用した Chrome のドロップイン CDP 代替品。 「ページを開く」、「JS で URL を取得する」、「サイトをスクレイピングする」、「このページをレンダリングする」、「CDP 経由でブラウザを自動化する」、または Chrome が重すぎるタスクのリクエストをトリガーします。ユーザーがステルス フィンガープリンティング、トラッカー ブロック、「navigator.webdriver」マスキング、または基本的なボット検出の回避について言及する場合にも使用します。
