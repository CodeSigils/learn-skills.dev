Recherchez sur Internet avec Google ou DuckDuckGo, inspectez les résultats et extrayez les pages sélectionnées sous forme de Markdown lisible. À utiliser lorsque les réponses nécessitent des sources Web actuelles, des pages rendues en JavaScript ou un accès à un navigateur capable de gérer la protection contre les robots. Préférez les outils dédiés tels que GitHub CLI pour les données GitHub et curl pour les fichiers directs ou les URL simples.
