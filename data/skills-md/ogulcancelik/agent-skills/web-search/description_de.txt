Durchsuchen Sie das Internet mit Google oder DuckDuckGo, überprüfen Sie die Ergebnisse und extrahieren Sie ausgewählte Seiten als lesbaren Markdown. Verwenden Sie diese Option, wenn für Antworten aktuelle Webquellen, mit JavaScript gerenderte Seiten oder ein Browserzugriff erforderlich sind, der den Bot-Schutz bewältigen kann. Bevorzugen Sie dedizierte Tools wie GitHub CLI für GitHub-Daten und Curl für direkte Dateien oder einfache URLs.
