Busque en Internet con Google o DuckDuckGo, inspeccione los resultados y extraiga las páginas seleccionadas como Markdown legible. Úselo cuando las respuestas requieran fuentes web actuales, páginas renderizadas en JavaScript o acceso a un navegador que pueda manejar la protección contra bots. Prefiera herramientas dedicadas como GitHub CLI para datos de GitHub y curl para archivos directos o URL simples.
