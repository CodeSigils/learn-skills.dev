ابحث في الإنترنت باستخدام Google أو DuckDuckGo، وافحص النتائج، واستخرج الصفحات المحددة كـ Markdown قابل للقراءة. يُستخدم عندما تتطلب الإجابات مصادر ويب حالية، أو صفحات معروضة بواسطة JavaScript، أو الوصول إلى المتصفح الذي يمكنه التعامل مع حماية الروبوتات. تفضل الأدوات المخصصة مثل GitHub CLI لبيانات GitHub والملفات المباشرة أو عناوين URL البسيطة.
