يجب استخدام هذه المهارة عندما يقوم مشروع GitHub بإصدار إصدار جديد، يغطي العملية الكاملة لإدارة رقم الإصدار، ومزامنة سجل التغيير، وكتابة ملاحظات الإصدار، وإنشاء العلامات، ومراقبة بناء CI، والتحقق من الإصدار، والتنظيف التاريخي. وينطبق هذا على أي مشروع برمجي يستند إلى GitHub مثل تطبيقات سطح المكتب، وأدوات واجهة سطر الأوامر (CLI)، وتطبيقات الويب، والمكتبات/مجموعات تطوير البرامج (SDK)، وما إلى ذلك. ويتم تشغيله عندما يذكر المستخدم "الإصدار"، أو "العلامة"، أو "الإصدار الجديد"، أو "تحديث رقم الإصدار"، أو "كتابة ملاحظات الإصدار"، أو "فشل الإصدار"، أو "تعطل CI". لا تستخدمه في مشاريع غير تابعة لـ GitHub (على سبيل المثال، مشاريع GitLab/Gitea الخالصة) أو سيناريوهات الإصدار اليدوي التي لا تتطلب CI.
