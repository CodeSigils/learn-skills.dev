このスキルは、GitHub プロジェクトが新しいバージョンをリリースするときに使用する必要があり、バージョン番号管理、CHANGELOG の同期、リリース ノートの作成、タグの作成、CI ビルドの監視、リリースの検証、履歴のクリーンアップのプロセス全体をカバーします。これは、デスクトップ アプリケーション、CLI ツール、Web アプリケーション、ライブラリ/SDK などの GitHub ベースのソフトウェア プロジェクトに適用されます。ユーザーが「リリース」、「タグ」、「新しいバージョン」、「バージョン番号の更新」、「リリース ノートの作成」、「リリースの失敗」、または「CI の破損」に言及するとトリガーされます。非 GitHub プロジェクト (純粋な GitLab/Gitea プロジェクトなど) や CI を必要としない手動リリース シナリオには使用しないでください。
