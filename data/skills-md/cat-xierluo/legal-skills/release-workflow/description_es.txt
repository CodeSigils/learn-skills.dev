Esta habilidad debe usarse cuando un proyecto de GitHub lanza una nueva versión, cubriendo todo el proceso de administración del número de versión, sincronización de CHANGELOG, redacción de notas de la versión, creación de etiquetas, monitoreo de compilación de CI, verificación de versiones y limpieza histórica. Se aplica a cualquier proyecto de software basado en GitHub, como aplicaciones de escritorio, herramientas CLI, aplicaciones web, bibliotecas/SDK, etc. Se activa cuando el usuario menciona "lanzamiento", "etiqueta", "nueva versión", "actualizar número de versión", "escribir notas de la versión", "lanzamiento fallido" o "CI se rompió". No lo utilice para proyectos que no sean de GitHub (por ejemplo, proyectos puros de GitLab/Gitea) o escenarios de lanzamiento manual que no requieran CI.
