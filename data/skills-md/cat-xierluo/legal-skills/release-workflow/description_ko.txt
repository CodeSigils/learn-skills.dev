이 기술은 GitHub 프로젝트가 새 버전을 출시할 때 버전 번호 관리, CHANGELOG 동기화, 릴리스 노트 작성, 태그 생성, CI 빌드 모니터링, 릴리스 확인 및 기록 정리의 전체 프로세스를 다루는 데 사용해야 합니다. 데스크톱 애플리케이션, CLI 도구, 웹 애플리케이션, 라이브러리/SDK 등과 같은 모든 GitHub 기반 소프트웨어 프로젝트에 적용됩니다. 사용자가 "릴리스", "태그", "새 버전", "버전 번호 업데이트", "릴리스 노트 쓰기", "릴리스 실패" 또는 "CI 중단"을 언급하면 ​​트리거됩니다. GitHub가 아닌 프로젝트(예: 순수 GitLab/Gitea 프로젝트) 또는 CI가 필요하지 않은 수동 릴리스 시나리오에는 사용하지 마세요.
