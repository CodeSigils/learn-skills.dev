Cette compétence doit être utilisée lorsqu'un projet GitHub publie une nouvelle version, couvrant l'ensemble du processus de gestion des numéros de version, de synchronisation CHANGELOG, de rédaction des notes de version, de création de balises, de surveillance des builds CI, de vérification des versions et de nettoyage historique. Il s'applique à tout projet logiciel basé sur GitHub, tel que les applications de bureau, les outils CLI, les applications Web, les bibliothèques/SDK, etc. Il est déclenché lorsque l'utilisateur mentionne « version », « balise », « nouvelle version », « numéro de version de mise à jour », « écrire des notes de version », « échec de la version » ou « CI cassé ». Ne l'utilisez pas pour des projets non GitHub (par exemple, des projets GitLab/Gitea purs) ou des scénarios de publication manuelle qui ne nécessitent pas de CI.
