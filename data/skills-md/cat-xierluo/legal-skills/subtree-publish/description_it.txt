Invia le sottodirectory di un monorepo per separare i repository GitHub utilizzando git subtree. Supporta manifesti di registrazione, rilevamento automatico delle modifiche e push incrementali. Questa funzionalità deve essere utilizzata dopo che un utente ha confermato le modifiche che coinvolgono un sottoprogetto registrato o quando viene effettuata una richiesta manuale per eseguire il push nel repository separato. Non utilizzarlo per creare inizialmente il monorepo o gestire i sottomoduli git.
