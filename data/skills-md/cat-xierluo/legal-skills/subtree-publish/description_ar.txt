ادفع الدلائل الفرعية لـ monorepo لفصل مستودعات GitHub باستخدام شجرة git الفرعية. يدعم بيانات التسجيل، والكشف التلقائي عن التغيير، والدفعات المتزايدة. يجب استخدام هذه الإمكانية بعد قيام المستخدم بإجراء تغييرات تتضمن مشروعًا فرعيًا مسجلاً، أو عند إجراء طلب يدوي للدفع إلى المستودع المنفصل. لا تستخدمه في البداية لإنشاء monorepo أو إدارة وحدات git الفرعية.
