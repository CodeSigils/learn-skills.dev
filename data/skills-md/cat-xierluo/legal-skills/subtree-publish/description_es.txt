Empuje subdirectorios de un monorepo para separar los repositorios de GitHub usando el subárbol git. Admite manifiestos de registro, detección automática de cambios y envíos incrementales. Esta capacidad debe usarse después de que un usuario confirma cambios que involucran un subproyecto registrado, o cuando se realiza una solicitud manual para enviar al repositorio separado. No lo use para crear inicialmente el monorepo o administrar submódulos de git.
