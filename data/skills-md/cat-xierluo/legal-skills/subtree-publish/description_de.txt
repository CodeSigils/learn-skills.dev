Pushen Sie Unterverzeichnisse eines Monorepos, um GitHub-Repositorys mithilfe von Git Subtree zu trennen. Unterstützt Registrierungsmanifeste, automatische Änderungserkennung und inkrementelle Pushs. Diese Funktion sollte verwendet werden, nachdem ein Benutzer Änderungen vorgenommen hat, die ein registriertes Unterprojekt betreffen, oder wenn eine manuelle Anforderung zum Pushen in das separate Repository gestellt wird. Verwenden Sie es nicht zum anfänglichen Erstellen des Monorepos oder zum Verwalten von Git-Submodulen.
