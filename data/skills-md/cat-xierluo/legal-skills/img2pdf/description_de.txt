Ordnen Sie Bilder oder PDF-Seiten in einem standardisierten A4-PDF mit N Bildern pro Seite an. This feature should be used when the user needs to combine screenshots (mobile screenshots, video screenshots), photos, or existing PDF pages into a compact A4 layout PDF. Verwenden Sie es nicht für: OCR-Texterkennung, Bearbeitung von PDF-Inhalten, Konvertierung von Bildformaten.
