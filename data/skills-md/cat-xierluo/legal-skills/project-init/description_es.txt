Herramienta de inicialización de proyectos. Lee el protocolo global~/.claude/CLAUDE.md, analiza la situación real del proyecto y genera un CLAUDE.md y docs/context específicos del proyecto. Esta habilidad debe usarse cuando el usuario dice "iniciar proyecto", "configurar proyecto", "configurar Claude Code", "nueva configuración de proyecto" o cuando ingresa a un nuevo proyecto que requiere una configuración rápida. No lo use para: desarrollo de contenido de habilidades (use Skill-Architect), instalación de una sola habilidad (use Skill-Manager), generación de código.
