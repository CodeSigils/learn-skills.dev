Outil d'initialisation de projet. Lit le protocole global ~/.claude/CLAUDE.md, analyse la situation réelle du projet et génère un CLAUDE.md et un docs/context spécifiques au projet. Cette compétence doit être utilisée lorsque l'utilisateur dit « initialiser le projet », « configuration du projet », « configurer Claude Code », « nouvelle configuration de projet » ou lors de la saisie d'un nouveau projet nécessitant une configuration rapide. Ne l'utilisez pas pour : le développement de contenu de compétence (utilisez Skill-Architect), l'installation d'une seule Skill (utilisez Skill-Manager), la génération de code.
