Project initialization tool. Reads the global protocol ~/.claude/CLAUDE.md, analyzes the actual project situation, and generates a project‑specific CLAUDE.md and docs/ context. This skill should be used when the user says “initialize project,” “project setup,” “configure Claude Code,” “new project configuration,” or when entering a new project that requires quick configuration. Do not use it for: Skill content development (use skill‑architect), single Skill installation (use skill‑manager), code generation.
