Projektinitialisierungstool. Liest das globale Protokoll ~/.claude/CLAUDE.md, analysiert die tatsächliche Projektsituation und generiert eine projektspezifische CLAUDE.md und einen docs/-Kontext. Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „Projekt initialisieren“, „Projekt einrichten“, „Claude Code konfigurieren“, „Neue Projektkonfiguration“ sagt oder wenn er ein neues Projekt eingibt, das eine schnelle Konfiguration erfordert. Verwenden Sie es nicht für: Entwicklung von Skill-Inhalten (Skill-Architect verwenden), einzelne Skill-Installation (Skill-Manager verwenden), Codegenerierung.
