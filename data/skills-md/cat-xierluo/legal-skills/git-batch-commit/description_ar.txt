زر اختصار الالتزام بدُفعة Smart Git. كلمات التشغيل: "التزام git"، أو "الالتزام المجمع"، أو "الالتزام المقسم"، أو "الالتزام التنظيمي"، أو يتم استخدامها عندما يريد المستخدم صراحةً تقسيم التغييرات المرحلية إلى التزامات مركزة متعددة. إنه يتعامل فقط مع تقسيم الالتزام وإنشاء الرسائل؛ تتبع دلالات الفرع والعلاقات العامة والدفع والدمج وإغلاق المشكلات سير عمل git.
