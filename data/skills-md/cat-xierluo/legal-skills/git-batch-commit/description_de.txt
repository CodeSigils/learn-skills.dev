Smart Git Batch-Commit-Shortcut-Schaltfläche. Auslöserwörter: „git commit“, „batch commit“, „split commit“, „organize commit“ oder werden verwendet, wenn der Benutzer gestaffelte Änderungen explizit in mehrere fokussierte Commits aufteilen möchte. Es übernimmt nur die Commit-Aufteilung und die Commit-Nachrichtengenerierung; Die Branch-, PR-, Push-, Merge- und Issue-Closing-Semantik folgt dem Git-Workflow.
