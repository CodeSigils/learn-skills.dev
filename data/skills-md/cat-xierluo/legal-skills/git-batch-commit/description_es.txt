Botón de acceso directo de confirmación por lotes de Git inteligente. Palabras desencadenantes: "git commit", "batch commit", "split commit", "organize commit", o se usan cuando el usuario desea explícitamente dividir los cambios por etapas en múltiples confirmaciones enfocadas. Solo maneja la división de compromisos y la generación de mensajes de compromiso; La semántica de bifurcación, relaciones públicas, envío, fusión y cierre de problemas sigue el flujo de trabajo de git.
