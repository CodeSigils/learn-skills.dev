Bouton de raccourci de validation par lots Smart Git. Mots déclencheurs : « git commit », « batch commit », « split commit », « organiser commit », ou utilisés lorsque l'utilisateur souhaite explicitement diviser les modifications par étapes en plusieurs validations ciblées. Il gère uniquement le fractionnement des validations et la génération de messages de validation ; Les sémantiques de branche, de relations publiques, de push, de fusion et de clôture de problème suivent le workflow git.
