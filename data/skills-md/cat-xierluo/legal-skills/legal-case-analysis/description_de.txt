Diese Funktion sollte verwendet werden, wenn der Benutzer eine rechtliche Analyse, eine Fallbewertung, eine Risikobewertung, eine Prozessstrategie, eine außergerichtliche Risikobeurteilung, eine Kundenerklärung oder einen rechtlichen Analysebericht auf der Grundlage von Fallmaterialien, Beratungsmaterialien, Vertragsdokumenten, Beweismaterial oder Suchergebnissen durchführen muss. Es dient als Voranalysemaschine für rechtliche Aufgaben und erfordert nicht jedes Mal die Erstellung eines formellen Berichts. Verwenden Sie es nicht für: reine OCR, einfache Abfrage von Gesetzestexten oder Rechtsprechungen, einfache Konvertierung von Word-Formatierungen oder die Erstellung von Dokumenten, bei denen lediglich ein Serviceplan zusammengestellt werden muss, ohne dass eine neue rechtliche Analyse hinzugefügt werden muss.
