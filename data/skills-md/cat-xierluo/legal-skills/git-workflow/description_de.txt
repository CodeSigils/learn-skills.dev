Git End-to-End-Workflow-Assistent. Umfasst die Erstellung von Zweigen, sichere Monorepo-Zusammenführungen, PR-Management, Lösung von Zusammenführungskonflikten und regelmäßige Git-Vorgänge. Es wird automatisch ausgelöst, wenn Benutzer Git-Aktionen wie Zweigstellenverwaltung, Code-Zusammenführung, Erstellen/Überprüfen von PRs und Lösen von Konflikten ausführen.
