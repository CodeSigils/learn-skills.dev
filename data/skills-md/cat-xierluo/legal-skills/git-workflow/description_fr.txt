Assistant de workflow Git de bout en bout. Couvre la création de branches, les fusions Monorepo sécurisées, la gestion des relations publiques, la résolution des conflits de fusion et les opérations Git régulières. Il est automatiquement déclenché lorsque les utilisateurs effectuent des actions Git telles que la gestion de succursales, la fusion de code, la création/révision de PR et la résolution de conflits.
