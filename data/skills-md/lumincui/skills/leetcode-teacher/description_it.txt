Uno strumento pratico passo passo per le domande dell'intervista LeetCode di livello medio. Si attiva quando gli utenti desiderano esercitarsi su problemi di algoritmo, elaborare LeetCode, prepararsi per colloqui tecnici o dire "una domanda", "prossimo problema", "genera impalcatura" o "inizia la pratica". Supporta pratiche categorizzate per tipo di problema (DP, elenchi collegati, alberi, grafici, finestre scorrevoli, due puntatori, tabelle hash, ricerca binaria, stack, heap, backtracking, intervalli, stringhe, union-find), generando scaffold Python con casi di test per ciascun problema. Tiene traccia dei progressi dell'apprendimento tramite tabelle Markdown, guidando gli utenti a pensare in modo indipendente prima di fornire soluzioni. Supporta obiettivi giornalieri di tre domande, utilizzando git diff README.md per monitorare i progressi e inviarli a Git.
