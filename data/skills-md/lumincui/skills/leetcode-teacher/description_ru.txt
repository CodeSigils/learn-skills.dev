LeetCode Medium: вопросы для собеседования. Пошаговый инструмент для практики. Срабатывает, когда пользователь хочет попрактиковаться в решении алгоритмических задач, отточить LeetCode, подготовиться к техническим собеседованиям или говорит «дайте мне задачу», «следующую задачу», «создайте каркас», «начните практиковаться». Поддерживает категоризацию практики по типам задач (DP, Связанный список, Дерево, График, Скользящее окно, Два указателя, Хэш-таблица, Двоичный поиск, Стек, Куча, Поиск с возвратом, Интервал, Строка, Поиск объединения), генерирует каркас Python с тестовыми примерами для каждой проблемы, отслеживает прогресс обучения с помощью таблицы Markdown, помогает пользователям думать независимо, прежде чем предлагать решения. Поддерживает ежедневную цель из трех вопросов, отслеживает прогресс с помощью git diff README.md и фиксирует изменения в Git.
