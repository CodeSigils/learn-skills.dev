أداة التدريب على أسئلة المقابلة ذات الصعوبة المتوسطة من LeetCode خطوة بخطوة. يتم تشغيله عندما يريد المستخدمون التدرب على مشاكل الخوارزمية، أو طحن LeetCode، أو الاستعداد للمقابلات الفنية، أو قول "来一道题"، "下一题"، "生成脚手架"، "开始练习". يدعم التدريب حسب نوع المشكلة (DP، القائمة المرتبطة، الشجرة، الرسم البياني، النافذة المنزلقة، مؤشرين، جدول التجزئة، البحث الثنائي، المكدس، الكومة، التراجع، الفاصل الزمني، السلسلة، المجموعة المنفصلة)، إنشاء نموذج بايثون مع حالات اختبار لكل مشكلة، وتتبع تقدم التعلم عبر جدول Markdown، وتوجيه المستخدمين إلى التفكير بشكل مستقل قبل تقديم الحلول. يدعم الهدف اليومي المكون من ثلاثة أسئلة، ويتتبع التقدم عبر git diff README.md ويلتزم بـ Git.
