LeetCode 中難易度の面接ドリル ツール。ユーザーがアルゴリズムの問​​題を練習したいとき、LeetCode を練習したいとき、技術面接の準備をしたいとき、あるいは「問題を出して」、「次の問題を」、「足場を生成して」、「練習を始めて」と言ったときにトリガーされます。問題タイプ (DP、リンク リスト、ツリー、グラフ、スライディング ウィンドウ、2 ポインター、ハッシュ テーブル、バイナリ検索、スタック、ヒープ、バックトラッキング、インターバル、文字列、ユニオン検索) によるドリルをサポートし、各問題のテスト ケースを含む Python スキャフォールドを生成し、マークダウン テーブルを介して進行状況を追跡し、解決策を示す前にユーザーが独自に考えるようにガイドします。毎日 3 つの問題を達成するという目標をサポートし、git diff README.md で進捗状況をカウントし、Git にコミットします。
