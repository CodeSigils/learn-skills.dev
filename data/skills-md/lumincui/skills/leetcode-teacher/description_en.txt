LeetCode Medium Interview Questions Step-by-Step Practice Tool. Triggered when the user wants to practice algorithm problems, grind LeetCode, prepare for technical interviews, or says "give me a problem", "next problem", "generate scaffold", "start practicing". Supports categorized practice by problem types (DP, Linked List, Tree, Graph, Sliding Window, Two Pointers, Hash Table, Binary Search, Stack, Heap, Backtracking, Interval, String, Union-Find), generates Python scaffold with test cases for each problem, tracks learning progress via Markdown table, guides users to think independently before providing solutions. Supports daily three-question goal, tracks progress via git diff README.md and commits to Git.
