Un outil d'exercice d'entretien LeetCode Medium étape par étape. Déclenché lorsque les utilisateurs souhaitent pratiquer des algorithmes, perfectionner LeetCode, préparer des entretiens techniques ou dire « un problème », « prochain problème », « générer un échafaudage », « commencer la pratique ». Filtrer par sujet (DP, liste chaînée, arbre, graphique, fenêtre coulissante, deux pointeurs, table de hachage, recherche binaire, pile, tas, retour en arrière, intervalle, chaîne, recherche d'union), générer un échafaudage Python avec des cas de test, suivre les progrès dans le tableau Markdown, inviter les utilisateurs à réfléchir avant de révéler une solution. Objectif quotidien de trois problèmes, comptage via git diff README.md et validation.
