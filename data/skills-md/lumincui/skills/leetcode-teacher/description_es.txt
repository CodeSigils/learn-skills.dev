Herramienta de práctica paso a paso de dificultad media LeetCode. Se activa cuando los usuarios quieren practicar problemas de codificación, procesar LeetCode, prepararse para entrevistas técnicas o decir "Iniciar un problema", "Siguiente problema", "Generar andamio", "Iniciar práctica". Admite la práctica categorizada por tipos de problemas (DP, lista vinculada, árbol, gráfico, ventana deslizante, dos punteros, tabla hash, búsqueda binaria, pila, montón, retroceso, intervalos, cadena, búsqueda de unión), generando andamios de Python con casos de prueba para cada problema, rastreando el progreso a través de la tabla Markdown, guiando a los usuarios a pensar de forma independiente antes de brindar soluciones. Admite objetivos diarios de tres problemas, rastreando el progreso a través de git diff README.md y confirmaciones de Git.
