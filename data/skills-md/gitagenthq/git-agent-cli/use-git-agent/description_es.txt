Opera la CLI de git-agent: confirmaciones, inicio, configuración y configuración del proveedor a través de ~/.config/git-agent/config.yml o git config. Las anulaciones de la CLI del proveedor pertenecen únicamente a los flujos de excepción. Úselo siempre que el usuario mencione git-agent, quiera confirmar/iniciar o necesite configurar un proveedor.
