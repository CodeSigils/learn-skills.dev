Управляет CLI git-agent — фиксирует, инициализирует, настраивает и устанавливает поставщика через ~/.config/git-agent/config.yml или git config. Переопределения CLI поставщика относятся только к потокам исключений. Используйте всякий раз, когда пользователь упоминает git-agent, хочет зафиксировать/инициализировать или ему необходимо настроить провайдера.
