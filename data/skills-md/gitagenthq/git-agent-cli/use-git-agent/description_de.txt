Betreibt die Git-Agent-CLI – Commits, Init, Konfiguration und Provider-Setup über ~/.config/git-agent/config.yml oder git config. Provider-CLI-Überschreibungen gehören nur zu Ausnahmeflüssen. Verwenden Sie es immer dann, wenn der Benutzer git-agent erwähnt, einen Commit/Init durchführen möchte oder einen Anbieter konfigurieren muss.
