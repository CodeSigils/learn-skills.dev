Sistema di memoria persistente per agenti AI. Ricorda decisioni, lezioni e flussi di lavoro passati prima di qualsiasi attività di codifica, sessione di debug o lavoro di architettura. Cattura automaticamente i nuovi apprendimenti al termine della sessione tramite Stop hook. Supporta la promozione della memoria consapevole del ciclo di vita, la distillazione delle scene e l'auto-miglioramento CLAUDE.md. Si attiva quando: si avvia un'attività e si necessita di un contesto precedente, dopo aver corretto un bug non ovvio o dopo aver preso una decisione architetturale chiave. NON per: progetti senza una directory .memobank/, pura scrittura di documentazione o script one-shot senza contesto precedente.
