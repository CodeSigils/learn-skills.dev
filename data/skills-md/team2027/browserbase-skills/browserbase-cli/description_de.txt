Verwenden Sie die Browserbase-CLI („browse“) für Browserbase-Funktionen und Plattform-API-Workflows. Verwenden Sie diese Option, wenn der Benutzer „Durchsuchen“ ausführen, Funktionen bereitstellen oder aufrufen, Sitzungen, Projekte, Kontexte oder Erweiterungen verwalten, eine Seite über die Browserbase Fetch API abrufen, das Web über die Browserbase Search API durchsuchen oder Startervorlagen erstellen möchte. Bevorzugen Sie die Browser-Fähigkeit für interaktives Surfen; Verwenden Sie die „Browse“-Treiberbefehle der obersten Ebene („Browse Open“, „Browse Get“ usw.) nur, wenn der Benutzer den CLI-Pfad ausdrücklich wünscht.
