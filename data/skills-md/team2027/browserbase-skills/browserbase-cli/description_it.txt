Utilizza la CLI Browserbase ("browse") per le funzioni Browserbase e i flussi di lavoro API della piattaforma. Da utilizzare quando l'utente chiede di eseguire "sfogliare", distribuire o richiamare funzioni, gestire sessioni, progetti, contesti o estensioni, recuperare una pagina tramite l'API Browserbase Fetch, effettuare ricerche sul Web tramite l'API Browserbase Search o modelli di avvio di scaffold. Preferire la skill Browser per la navigazione interattiva; utilizzare i comandi del driver `browse` di livello superiore (`browse open`, `browse get` e così via) solo quando l'utente desidera esplicitamente il percorso CLI.
