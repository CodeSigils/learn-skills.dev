Utilisez la CLI Browserbase (« browse ») pour les fonctions Browserbase et les workflows de l'API de la plateforme. À utiliser lorsque l'utilisateur demande d'exécuter « parcourir », de déployer ou d'invoquer des fonctions, de gérer des sessions, des projets, des contextes ou des extensions, de récupérer une page via l'API Browserbase Fetch, de rechercher sur le Web via l'API de recherche Browserbase ou des modèles de démarrage d'échafaudage. Préférer la compétence Navigateur pour une navigation interactive ; utilisez les commandes du pilote « browse » de niveau supérieur (« browse open », « browse get », etc.) uniquement lorsque l'utilisateur souhaite explicitement le chemin CLI.
