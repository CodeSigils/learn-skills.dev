استخدم Browserbase CLI (`browse`) لوظائف Browserbase وسير عمل واجهة برمجة تطبيقات النظام الأساسي. يُستخدم عندما يطلب المستخدم تشغيل "التصفح"، أو نشر الوظائف أو استدعائها، أو إدارة الجلسات أو المشاريع أو السياقات أو الامتدادات، أو جلب صفحة من خلال Browserbase Fetch API، أو البحث في الويب من خلال Browserbase Search API، أو قوالب بداية السقالة. تفضل مهارة المتصفح للتصفح التفاعلي؛ استخدم أوامر برنامج التشغيل "تصفح" ذات المستوى الأعلى ("تصفح مفتوح"، و"تصفح احصل"، وما إلى ذلك) فقط عندما يريد المستخدم صراحةً مسار واجهة سطر الأوامر (CLI).
