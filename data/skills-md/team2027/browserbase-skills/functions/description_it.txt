Distribuisci l'automazione del browser serverless come funzioni cloud utilizzando Browserbase. Da utilizzare quando l'utente desidera distribuire l'automazione del browser per l'esecuzione in base a una pianificazione o cron, creare un endpoint webhook per le attività del browser, eseguire l'automazione nel cloud anziché localmente o chiedere informazioni sulle funzioni Browserbase.
