Déployez l'automatisation du navigateur sans serveur en tant que fonctions cloud à l'aide de Browserbase. À utiliser lorsque l'utilisateur souhaite déployer l'automatisation du navigateur pour une exécution planifiée ou cron, créer un point de terminaison webhook pour les tâches du navigateur, exécuter l'automatisation dans le cloud plutôt que localement ou poser des questions sur les fonctions de base du navigateur.
