قم بتحويل حركة مرور HTTP التي يمكن ملاحظتها لموقع الويب إلى أفضل مواصفات OpenAPI 3.1 من خلال تحليل التقاط "تتبع المتصفح". يُستخدم عندما يريد المستخدم اكتشاف/استخراج نقاط نهاية واجهة برمجة التطبيقات (API) من جلسة متصفح، أو إنشاء مستند OpenAPI من حركة مرور الشبكة، أو توثيق سطح XHR/الجلب الخاص بموقع جهة خارجية لتكامل العميل.
