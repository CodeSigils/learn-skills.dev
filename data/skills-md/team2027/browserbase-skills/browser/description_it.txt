Automatizza le interazioni del browser Web utilizzando il linguaggio naturale tramite i comandi CLI. Utilizzare quando l'utente chiede di navigare in siti Web, navigare in pagine Web, estrarre dati da siti Web, acquisire schermate, compilare moduli, fare clic su pulsanti o interagire con applicazioni Web. Supporta sessioni Browserbase remote con identità Browserbase, browser verificati, risoluzione automatica dei CAPTCHA e proxy residenziali: ideale per siti Web protetti e pagine contenenti JavaScript.
