Automatice las interacciones del navegador web utilizando lenguaje natural mediante comandos CLI. Se utiliza cuando el usuario solicita navegar por sitios web, navegar por páginas web, extraer datos de sitios web, tomar capturas de pantalla, completar formularios, hacer clic en botones o interactuar con aplicaciones web. Admite sesiones remotas de Browserbase con Browserbase Identity, navegadores verificados, resolución automática de CAPTCHA y servidores proxy residenciales, ideal para sitios web protegidos y páginas con mucho JavaScript.
