Получите полную трассировку любой автоматизации браузера с помощью DevTools — пожарный шланг CDP, снимки экрана и дампы DOM — а затем разделите поток на сегменты с возможностью поиска по страницам. Используйте, когда пользователь хочет отладить неудачный запуск, проверить активность сети/консоли/DOM, прикрепить трассировку к текущему сеансу или передать структурированные постраничные сводки обратно в цикл агента, чтобы его следующая итерация обучалась на основе предыдущей.
