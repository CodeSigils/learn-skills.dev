Melden Sie einen echten Menschen in der CLI eines Entwicklungstools an, indem Sie das OAuth-Browser-Popup automatisch öffnen und die Anmeldung selbst durchführen lassen – kein Token-Kopieren und Einfügen. Verwenden Sie diese Option, wenn Sie sich bei einer CLI anmelden/authentifizieren müssen, wenn ein Befehl wie „sanity login“ oder „netlify login“ einen Browser öffnet, oder bei jedem interaktiven Login/OAuth-Popup. Sie lassen das Popup erscheinen und warten; Der Mensch klickt einfach auf „Genehmigen“. Sie automatisieren NIEMALS den Browser oder scrapen Tokens.
