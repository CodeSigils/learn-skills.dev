Tests d'interface utilisateur contradictoires basés sur l'IA via la CLI de navigation. Analyse les différences git pour tester uniquement ce qui a changé, ou explore l'application complète pour trouver des bugs. Teste l’exactitude fonctionnelle, l’accessibilité, la mise en page réactive et l’heuristique UX. À utiliser lorsque l'utilisateur demande à tester les modifications de l'interface utilisateur, à contrôler la qualité d'une pull request, à auditer l'accessibilité ou à exécuter des tests exploratoires. Prend en charge le navigateur local (localhost) et la base de navigateur distante (sites déployés).
