اختبار واجهة المستخدم الخصومة المدعومة بالذكاء الاصطناعي عبر واجهة سطر الأوامر للتصفح. يحلل اختلافات git لاختبار ما تم تغييره فقط، أو يستكشف التطبيق الكامل للعثور على الأخطاء. يختبر الصحة الوظيفية، وإمكانية الوصول، والتخطيط سريع الاستجابة، والاستدلال على تجربة المستخدم. يُستخدم عندما يطلب المستخدم اختبار تغييرات واجهة المستخدم، أو طلب سحب ضمان الجودة، أو إمكانية الوصول إلى التدقيق، أو تشغيل اختبار استكشافي. يدعم المتصفح المحلي (المضيف المحلي) وقاعدة المتصفح البعيدة (المواقع المنشورة).
