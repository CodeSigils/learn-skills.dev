Utilice la CLI de Browserbase ("browse") para las funciones de Browserbase y los flujos de trabajo API de la plataforma. Úselo cuando el usuario solicite ejecutar "navegar", implementar o invocar funciones, administrar sesiones, proyectos, contextos o extensiones, buscar una página a través de la API Browserbase Fetch, buscar en la web a través de la API Browserbase Search o plantillas de inicio de scaffolding. Prefiere la habilidad Navegador para navegación interactiva; use los comandos del controlador `browse` de nivel superior (`browse open`, `browse get`, etc.) solo cuando el usuario desee explícitamente la ruta CLI.
