Browserbase 関数とプラットフォーム API ワークフローには、Browserbase CLI (「browse」) を使用します。ユーザーが「browse」の実行、関数のデプロイまたは呼び出し、セッション、プロジェクト、コンテキスト、または拡張機能の管理、Browserbase Fetch API を介したページのフェッチ、Browserbase Search API を介した Web の検索、またはスキャフォールド スターター テンプレートを要求するときに使用します。インタラクティブなブラウジングにはブラウザ スキルを推奨します。ユーザーが明示的に CLI パスを必要とする場合にのみ、トップレベルの「browse」ドライバ コマンド (「browse open」、「browse get」など) を使用してください。
