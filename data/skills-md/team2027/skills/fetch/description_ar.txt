استخدم هذه المهارة عندما يريد المستخدم استرداد عنوان URL بدون جلسة متصفح كاملة: جلب HTML أو JSON من الصفحات الثابتة، أو فحص رموز الحالة أو الرؤوس، أو اتباع عمليات إعادة التوجيه، أو الحصول على مصدر الصفحة لإجراء عملية استخراج بسيطة. قم بتفضيله على المتصفح عندما لا تكون هناك حاجة لعرض JavaScript وتفاعل الصفحة. يدعم الوكلاء والتحكم في إعادة التوجيه.
