Utilice esta habilidad cuando el usuario desee recuperar una URL sin una sesión completa del navegador: obtenga HTML o JSON de páginas estáticas, inspeccione códigos de estado o encabezados, siga redirecciones u obtenga el origen de la página para realizar un simple scraping. Prefiérelo a un navegador cuando no se necesita la representación de JavaScript ni la interacción de la página. Admite proxies y control de redireccionamiento.
