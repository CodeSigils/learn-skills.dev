Verwenden Sie diese Fähigkeit, wenn der Benutzer eine URL ohne vollständige Browsersitzung abrufen möchte: HTML oder JSON von statischen Seiten abrufen, Statuscodes oder Header überprüfen, Weiterleitungen folgen oder Seitenquellen für einfaches Scraping abrufen. Bevorzugen Sie es gegenüber einem Browser, wenn JavaScript-Rendering und Seiteninteraktion nicht erforderlich sind. Unterstützt Proxys und Umleitungssteuerung.
