أنشئ وكلاء متصفح مقيد محليًا باستخدام أداة Safe_browser التي تمتلك CDP، وتفرض قائمة مسموح بها للمجال مع اعتراض الجلب، وتسمح لوكيل Claude Agent SDK في وقت التشغيل بإكمال مهام التصفح دون الوصول إلى المتصفح الأولي أو shell أو CDP. يُستخدم عندما يريد المستخدم أن يقوم الوكيل بالتصفح أو التنقيب أثناء البقاء في النطاقات المعتمدة، أو التنقل التجريبي خارج النطاق المحظور، أو إنشاء عميل متصفح آمن.
