Crea agenti con browser vincolato locale con uno strumento safe_browser che possiede CDP, applica una lista consentita di domini con intercettazione Fetch e consente a un agente SDK Claude Agent runtime di completare le attività di navigazione senza accesso a browser, shell o CDP non elaborati. Da utilizzare quando l'utente desidera che un agente effettui la navigazione o lo scraping rimanendo su domini approvati, demo blocchi la navigazione fuori dominio o generi un client browser sicuro.
