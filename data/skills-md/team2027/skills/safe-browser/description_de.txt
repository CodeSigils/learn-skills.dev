Erstellen Sie lokale Agenten mit eingeschränkten Browsern mit einem Safe_Browser-Tool, das CDP besitzt, eine Domänen-Zulassungsliste mit Fetch-Interception erzwingt und es einem Claude Agent SDK-Laufzeitagenten ermöglicht, Browsing-Aufgaben ohne unformatierten Browser-, Shell- oder CDP-Zugriff auszuführen. Verwenden Sie diese Option, wenn der Benutzer möchte, dass ein Agent durchsucht oder scrapt, während er sich auf genehmigten Domänen aufhält, blockierte Navigation außerhalb der Domäne demonstriert oder einen sicheren Browser-Client generiert.
