À utiliser lors de modifications visuelles CSS ou Tailwind à propriété unique dans les projets Next.js App Router. Présente un widget de contrôle flottant sur la page afin que l'utilisateur puisse modifier la valeur avant qu'elle ne soit conservée. Couvre les changements de style atomique, l’aperçu en direct et le nettoyage. Se déclenche sur une seule valeur CSS ou sur une seule modification de classe d'utilitaire Tailwind.
