Используйте при внесении визуальных изменений CSS с одним свойством или Tailwind в проектах Next.js App Router. Представляет плавающий виджет управления на странице, позволяющий пользователю настроить значение до его сохранения. Охватывает атомарные изменения стиля, предварительный просмотр в реальном времени и очистку. Запускается по одному значению CSS или по одной модификации служебного класса Tailwind.
