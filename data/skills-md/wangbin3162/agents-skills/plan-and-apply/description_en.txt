Use this skill whenever the user asks to first analyze, first plan, not directly modify code, work in small slices, or complete a non-trivial implementation with clear scope and verification. Also use it whenever the task obviously spans multiple steps, multiple files, migration work, refactoring, page closure work, or requires strong validation and clean handoff. This skill enforces a workflow of read rules first, clarify scope, create the smallest viable plan, apply changes in controlled slices, then verify and close out.
