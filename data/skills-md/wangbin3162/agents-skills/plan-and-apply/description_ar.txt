استخدم هذه المهارة عندما يطلب المستخدم التحليل أولاً، أو التخطيط أولاً، أو عدم تعديل التعليمات البرمجية مباشرة، أو العمل في شرائح صغيرة، أو إكمال تنفيذ غير تافه بنطاق واضح وتحقق. استخدمه أيضًا عندما تمتد المهمة بشكل واضح إلى خطوات متعددة، أو ملفات متعددة، أو أعمال الترحيل، أو إعادة البناء، أو أعمال إغلاق الصفحة، أو تتطلب التحقق القوي والتسليم النظيف. تفرض هذه المهارة سير عمل قواعد القراءة أولاً، وتوضيح النطاق، وإنشاء أصغر خطة قابلة للتطبيق، وتطبيق التغييرات في الشرائح الخاضعة للتحكم، ثم التحقق والإغلاق.
