Effettua il bootstrap e mantieni minimamente un servizio di portafoglio Superise locale dall'immagine ufficiale di Docker Hub. Utilizzalo quando l'attività consiste nell'installare, avviare, riavviare, verificare o ispezionare una distribuzione Superise locale, in particolare per la configurazione di avvio rapido di Docker di prima esecuzione, i controlli del volume, i controlli di integrità, l'ispezione dei log o le operazioni di base del contenitore.
