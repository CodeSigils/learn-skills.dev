Загрузите и минимально поддерживайте локальный сервис кошелька Superise из официального образа Docker Hub. Используйте это, когда задача состоит в установке, запуске, перезапуске, проверке или проверке локального развертывания Superise, особенно для быстрой настройки Docker при первом запуске, проверки томов, проверки работоспособности, проверки журналов или основных операций с контейнером.
