قم بتشغيل Bootstrap وحافظ على الحد الأدنى من خدمة محفظة Superise المحلية من صورة Docker Hub الرسمية. استخدم هذا عندما تكون المهمة هي تثبيت نشر Superise محلي أو بدء تشغيله أو إعادة تشغيله أو التحقق منه أو فحصه، خاصة لإعداد التشغيل السريع لـ Docker الذي يتم تشغيله لأول مرة، أو فحوصات الحجم، أو فحوصات الصحة، أو فحص السجل، أو عمليات الحاوية الأساسية.
