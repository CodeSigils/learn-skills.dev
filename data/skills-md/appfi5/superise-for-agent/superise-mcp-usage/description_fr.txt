Connectez-vous et utilisez Superise via le protocole MCP standard. Utilisez-le lorsque la tâche consiste à valider la connectivité MCP, à inspecter les métadonnées des outils en direct, à répertorier les outils, à appeler des outils ou à exploiter le portefeuille via un client MCP standard ou des requêtes HTTP Streamable manuelles.
