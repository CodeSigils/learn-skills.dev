처음부터 또는 기존 프로젝트를 개선하여 모든 프로젝트에 대해 세련되고 전문적인 README.md를 생성하세요. 사용자가 README를 언급하거나, 저장소의 첫인상을 개선하고 싶거나, Shields.io 배지에 대해 묻거나, README에 별 기록 차트, 기여자 아바타, 문서 테이블, 프로젝트 구조 트리 또는 인어 아키텍처 다이어그램을 원할 때마다 이 기술을 사용하세요. 또한 누군가 자신의 GitHub 저장소가 "더 전문적으로 보이도록", "합법적으로 보이도록" 하거나 더 나은 첫인상을 주기를 원하는 경우에도 이 기능을 사용하세요. "README"라는 단어를 전혀 말하지 않더라도 마찬가지입니다. 배지 생성, 새 버전에 대한 README 재작성, 포크 사용자 정의, README 구조를 다양한 프로젝트 유형(라이브러리, 앱, 문서 저장소, 모노 저장소)에 맞게 조정하는 방법을 다룹니다. 포함되지 않는 내용: CONTRIBUTING.md, CHANGELOG, API 문서, CI/CD 설정, GitHub 프로필 README 또는 개별 구성 요소에 대한 문서 생성.
