Generieren Sie eine ausgefeilte, professionelle README.md für jedes Projekt – von Grund auf oder durch Verbesserung eines bestehenden Projekts. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer die README-Datei erwähnt, den ersten Eindruck seines Repos verbessern möchte, nach Shields.io-Abzeichen fragt, ein Sternverlaufsdiagramm, Mitwirkende-Avatare, Dokumentationstabellen, Projektstrukturbäume oder Meerjungfrauen-Architekturdiagramme in seiner README-Datei haben möchte. Verwenden Sie es auch, wenn jemand möchte, dass sein GitHub-Repo „professioneller“ oder „legitim“ aussieht oder einen besseren ersten Eindruck hinterlässt – auch wenn er nie das Wort „README“ sagt. Behandelt die Badge-Generierung, das Umschreiben von README-Dateien für neue Versionen, die Fork-Anpassung und die Anpassung der README-Struktur an verschiedene Projekttypen (Bibliotheken, Apps, Dokument-Repos, Monorepos). NICHT abgedeckt: CONTRIBUTING.md, CHANGELOG, API-Dokumentation, CI/CD-Setup, GitHub-Profil-READMEs oder das Generieren von Dokumenten für einzelne Komponenten.
