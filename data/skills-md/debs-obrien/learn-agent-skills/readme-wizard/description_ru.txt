Создайте профессиональный README.md для любого проекта — с нуля или путем улучшения существующего. Используйте этот навык всякий раз, когда пользователь упоминает README, хочет улучшить первое впечатление о своем репозитории, спрашивает о значках Shields.io, хочет иметь диаграмму звездной истории, аватары участников, таблицы документации, деревья структуры проекта или диаграммы архитектуры русалки в своем README. Также используйте его, когда кто-то хочет, чтобы его репозиторий GitHub «выглядел более профессионально», «выглядел законно» или производил лучшее первое впечатление — даже если он никогда не произносит слово «README». Охватывает создание значков, переписывание README для новых версий, настройку ветвей и адаптацию структуры README к различным типам проектов (библиотеки, приложения, репозитории документов, монорепозитории). НЕ охватывает: CONTRIBUTING.md, CHANGELOG, документацию по API, настройку CI/CD, файлы README профиля GitHub или создание документации для отдельных компонентов.
