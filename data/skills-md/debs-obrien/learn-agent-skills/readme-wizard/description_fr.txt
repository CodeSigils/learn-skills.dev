Générez un fichier README.md soigné et professionnel pour n'importe quel projet, à partir de zéro ou en améliorant un projet existant. Utilisez cette compétence chaque fois que l'utilisateur mentionne README, souhaite améliorer la première impression de son dépôt, pose des questions sur les badges Shields.io, souhaite un graphique d'historique des étoiles, des avatars de contributeurs, des tableaux de documentation, des arborescences de structure de projet ou des diagrammes d'architecture de sirène dans son README. Utilisez-le également lorsque quelqu'un souhaite que son dépôt GitHub « ait l'air plus professionnel », « ait l'air légitime » ou fasse une meilleure première impression – même s'il ne prononce jamais le mot « README ». Couvre la génération de badges, les réécritures README pour les nouvelles versions, la personnalisation des forks et l'adaptation de la structure README à différents types de projets (bibliothèques, applications, dépôts de documents, monorepos). Ne couvre PAS : CONTRIBUTING.md, CHANGELOG, la documentation API, la configuration CI/CD, les README du profil GitHub ou la génération de documents pour des composants individuels.
