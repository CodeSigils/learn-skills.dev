为任何项目生成一份精美、专业的 README.md - 从头开始​​或通过改进现有项目。每当用户提到 README、想要改善其存储库的第一印象、询问有关shields.io 徽章、想要在 README 中提供明星历史图表、贡献者头像、文档表、项目结构树或美人鱼架构图时，请使用此技能。当有人希望他们的 GitHub 存储库“看起来更专业”、“看起来合法”或给人留下更好的第一印象时，也可以使用它——即使他们从未说过“自述文件”这个词。涵盖徽章生成、新版本的 README 重写、分叉自定义以及使 README 结构适应不同的项目类型（库、应用程序、文档存储库、monorepos）。不涵盖：CONTRIBUTING.md、CHANGELOG、API 文档、CI/CD 设置、GitHub 配置文件自述文件或为各个组件生成文档。
