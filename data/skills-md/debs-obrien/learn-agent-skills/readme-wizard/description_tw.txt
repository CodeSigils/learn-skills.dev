為任何專案產生精美、專業的 README.md - 從頭開始或透過改進現有專案。每當使用者提到 README、想要改善其儲存庫的第一印象、詢問有關shields.io 徽章、想要在 README 中提供明星歷史圖表、貢獻者頭像、文件表、專案結構樹或美人魚架構圖時，請使用此技能。當有人希望他們的 GitHub 儲存庫「看起來更專業」、「看起來合法」或給人留下更好的第一印象時，也可以使用它——即使他們從未說過「自述文件」這個詞。涵蓋徽章生成、新版本的 README 重寫、分叉自訂以及使 README 結構適應不同的專案類型（庫、應用程式、文件儲存庫、monorepos）。不涵蓋：CONTRIBUTING.md、CHANGELOG、API 文件、CI/CD 設定、GitHub 設定檔自述文件或為各個元件產生文件。
