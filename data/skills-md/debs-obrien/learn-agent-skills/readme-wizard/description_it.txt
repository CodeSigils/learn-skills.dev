Genera un README.md raffinato e professionale per qualsiasi progetto, da zero o migliorandone uno esistente. Utilizza questa abilità ogni volta che l'utente menziona README, desidera migliorare la prima impressione del proprio repository, chiede informazioni sui badge Shields.io, desidera un grafico della cronologia delle stelle, avatar dei contributori, tabelle di documentazione, alberi della struttura del progetto o diagrammi dell'architettura delle sirene nel proprio README. Usalo anche quando qualcuno vuole che il proprio repository GitHub "sembri più professionale", "sembri legittimo" o faccia una prima impressione migliore, anche se non dice mai la parola "README". Copre la generazione di badge, la riscrittura del README per nuove versioni, la personalizzazione del fork e l'adattamento della struttura README a diversi tipi di progetto (librerie, app, repository di documenti, monorepos). NON copre: CONTRIBUTING.md, CHANGELOG, documentazione API, configurazione CI/CD, file README del profilo GitHub o generazione di documenti per singoli componenti.
