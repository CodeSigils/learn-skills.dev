Genere un archivo README.md profesional y pulido para cualquier proyecto, desde cero o mejorando uno existente. Utilice esta habilidad siempre que el usuario mencione README, quiera mejorar la primera impresión de su repositorio, pregunte sobre las insignias de Shields.io, quiera un gráfico de historial de estrellas, avatares de contribuyentes, tablas de documentación, árboles de estructura de proyectos o diagramas de arquitectura de sirena en su README. Úselo también cuando alguien quiera que su repositorio de GitHub "parezca más profesional", "parezca legítimo" o dé una mejor primera impresión, incluso si nunca dice la palabra "README". Cubre la generación de insignias, reescrituras de README para nuevas versiones, personalización de bifurcaciones y adaptación de la estructura README a diferentes tipos de proyectos (bibliotecas, aplicaciones, repositorios de documentos, monorepos). NO cubre: CONTRIBUTING.md, CHANGELOG, documentación de API, configuración de CI/CD, archivos README de perfil de GitHub ni generación de documentos para componentes individuales.
