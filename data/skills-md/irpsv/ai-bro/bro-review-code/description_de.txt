Führt eine unabhängige Überprüfung von Codeänderungen durch, ohne diese zu beheben. Verwenden Sie es, wenn der Benutzer ausdrücklich darum bittet, Code, Commit, Branch, Pull Request oder Diff auf Übereinstimmung mit der Aufgabe, Korrektheit, Sicherheit, Leistung und Testqualität zu überprüfen. Verwenden Sie es nicht, wenn der Benutzer den Code ändern, eine Aufgabe implementieren oder zunächst die Ursache eines Problems ermitteln möchte.
