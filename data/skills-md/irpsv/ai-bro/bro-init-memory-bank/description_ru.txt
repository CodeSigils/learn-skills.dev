Создает банк памяти проекта с нуля и выполняет его первоначальное заполнение. Используйте его только при явном вызове с помощью /bro-init-memory-bank, когда пользователь хочет создать новый банк знаний проекта. Не используйте его для пополнения существующего банка памяти или для сохранения отдельного проектного решения.
