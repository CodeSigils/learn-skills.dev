Ayuda a aclarar conjuntamente una tarea, probar una idea, encontrar la causa raíz de un problema o elegir un enfoque sin implementarlo. Úselo cuando el usuario solicite discutir una tarea, comprender el problema, comparar opciones o hacer preguntas como "¿qué piensas?" y "¿cuál es la mejor manera de hacerlo?". No lo utilice cuando el usuario solicite explícitamente crear un plan, implementar una tarea, revisar cambios de código o preservar el conocimiento del proyecto.
