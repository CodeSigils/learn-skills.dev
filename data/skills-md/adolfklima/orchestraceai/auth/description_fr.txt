Authentification FastAPI avec JWT, OAuth 2.1, RBAC et clés API à l'aide de python-jose + passlib. À utiliser pour : les points de terminaison de connexion, l'émission de jetons, les itinéraires protégés, les vérifications de rôle, la connexion sociale. Déclencheurs : authentification, JWT, jeton, connexion, OAuth, RBAC, mot de passe, porteur, session, middleware.
