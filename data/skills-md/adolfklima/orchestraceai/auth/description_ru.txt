Аутентификация FastAPI с помощью JWT, OAuth 2.1, RBAC и ключей API с использованием python-jose + passlib. Используется для: конечных точек входа, выдачи токенов, защищенных маршрутов, проверок ролей, входа через социальные сети. Триггеры: аутентификация, JWT, токен, вход в систему, OAuth, RBAC, пароль, носитель, сеанс, промежуточное программное обеспечение.
