Detecte casos extremos de UI/UX descubiertos en el código de la interfaz o en las descripciones de los tickets haciendo preguntas sobre el diseño, los estados, el contenido y las interacciones. Genera problemas que el desarrollador puede evaluar; NO genera código. Úselo cuando: revise el código del componente de la interfaz de usuario (menú desplegable, formulario, modal, tabla, entrada, búsqueda, paso a paso, OTP, información sobre herramientas, alternar), verifique tickets para detectar casos extremos que faltan, revise el código de la interfaz o cuando alguien pregunte "qué problemas de la interfaz de usuario me faltan", "detectar casos extremos", "revisar este componente", "qué podría fallar", "qué olvidé", "auditoría de la interfaz de usuario", "qué casos extremos" o "verificación de control de calidad". También se activa cuando el usuario pega código React/Vue/Svelte/HTML/CSS/TypeScript para cualquier componente interactivo. Cubre: desbordamiento de diseño, estados vacío/cargando/error, desbordamiento de texto, responsivo, objetivos táctiles, posicionamiento desplegable, validación de formularios, navegación con teclado y casos extremos de componentes específicos.
