Produit des problèmes que le développeur peut évaluer – ne génère PAS de code. À utiliser lorsque : la révision du code d'un composant de l'interface utilisateur (liste déroulante, formulaire, modal, tableau, saisie, recherche, stepper, OTP, info-bulle, bascule), la vérification des tickets pour les cas extrêmes manquants, la révision du code frontal ou lorsque quelqu'un demande "quels problèmes d'interface utilisateur me manque", "cas extrêmes", "examiner ce composant", "qu'est-ce qui pourrait casser", "qu'ai-je oublié", "audit de l'interface utilisateur", "quels cas extrêmes" ou "vérification d'assurance qualité". Se déclenche également lorsque l'utilisateur colle du code React/Vue/Svelte/HTML/CSS/TypeScript pour n'importe quel composant interactif. Couvre : débordement de mise en page, états vide/chargement/erreur, débordement de texte, réactif, cibles tactiles, positionnement des listes déroulantes, validation de formulaire, navigation au clavier et cas extrêmes spécifiques aux composants.
