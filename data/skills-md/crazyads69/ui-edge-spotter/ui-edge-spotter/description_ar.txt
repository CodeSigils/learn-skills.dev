اكتشف حالات واجهة المستخدم/تجربة المستخدم غير المكشوفة في رمز الواجهة الأمامية أو أوصاف التذكرة من خلال طرح أسئلة "ماذا لو" حول التخطيط والحالات والمحتوى والتفاعلات. مشكلات المخرجات التي يمكن للمطور تقييمها - ولا تؤدي إلى إنشاء تعليمات برمجية. يُستخدم عندما: مراجعة كود مكون واجهة المستخدم (القائمة المنسدلة، النموذج، المشروط، الجدول، الإدخال، البحث، السائر، OTP، تلميح الأداة، التبديل)، التحقق من التذاكر لحالات الحافة المفقودة، إجراء مراجعة كود الواجهة الأمامية، أو عندما يسأل شخص ما "ما هي مشكلات واجهة المستخدم التي أفتقدها"، أو "حالات الحافة الموضعية"، أو "مراجعة هذا المكون"، أو "ما الذي يمكن أن ينكسر"، أو "ماذا نسيت"، أو "تدقيق واجهة المستخدم"، أو "ما هي حالات الحافة"، أو "فحص ضمان الجودة". يتم تشغيله أيضًا عندما يقوم المستخدم بلصق كود React/Vue/Svelte/HTML/CSS/TypeScript لأي مكون تفاعلي. يغطي: تجاوز التخطيط، وحالات فارغة/تحميل/خطأ، وتجاوز النص، والاستجابة، وأهداف اللمس، وتحديد موضع القائمة المنسدلة، والتحقق من صحة النموذج، والتنقل عبر لوحة المفاتيح، وحالات الحافة الخاصة بالمكونات.
