Выявляйте нераскрытые крайние случаи UI/UX в коде внешнего интерфейса или описаниях заявок, задавая вопросы «что, если» о макете, состояниях, контенте и взаимодействиях. Выводит проблемы, которые разработчик может оценить — НЕ генерирует код. Используйте при: просмотре кода компонента пользовательского интерфейса (раскрывающийся список, форма, модальное окно, таблица, ввод, поиск, пошаговое управление, OTP, всплывающая подсказка, переключение), проверке заявок на отсутствие пограничных случаев, выполнении проверки кода внешнего интерфейса или когда кто-то спрашивает: «Какие проблемы пользовательского интерфейса мне не хватает», «выявите крайние случаи», «проверьте этот компонент», «что может сломаться», «что я забыл», «аудит пользовательского интерфейса», «какие крайние случаи» или «проверка качества». Также срабатывает, когда пользователь вставляет код React/Vue/Svelte/HTML/CSS/TypeScript для любого интерактивного компонента. Обложки: переполнение макета, состояния пустого/загрузки/ошибки, переполнение текста, отзывчивость, сенсорные цели, расположение раскрывающегося списка, проверка формы, навигация с помощью клавиатуры и крайние случаи, специфичные для компонента.
