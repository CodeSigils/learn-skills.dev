عندما يحتاج المؤسس إلى تأهيل العملاء المتوقعين الوافدين، أو تحديد برنامج المقارنات الدولية (ICP) الخاص بهم، أو بناء نموذج تسجيل العملاء المحتملين، أو تعيين معايير MQL، أو توجيه العملاء المتوقعين عبر مراحل التدفق. يتم التنشيط عندما يذكر المستخدم نقاط العميل المتوقع، أو ICP، أو MQL، أو SQL، أو تأهيل العميل المتوقع، أو العملاء المتوقعين الواردين، أو تصميم خط الأنابيب.
