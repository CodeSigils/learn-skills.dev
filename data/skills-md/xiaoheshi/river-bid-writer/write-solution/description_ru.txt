Механизм написания тендерных предложений. Параметр: название предложения (соответствует списку предложений plan_budget.md).
Универсальный движок, не привязанный к какому-либо конкретному типу предложения. Вся специальная информация извлекается из plan_budget.md.
Ключевые слова-триггеры: написать предложение, написать решение, техническое предложение, предложение по внедрению, обеспечение качества, послепродажное обслуживание, написание предложения, состав предложения, написание заявки, тендерный документ, механизм написания.
