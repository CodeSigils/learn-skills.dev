Utilisez cette compétence chaque fois qu'un utilisateur souhaite installer, ajouter ou utiliser des composants Orizen TUI dans son projet CLI Node.js. Déclenchez sur toute mention de : orizen-tui, les composants de l'interface utilisateur du terminal, TUI spinner/badge/progress/select, `npx orizen-tui add` ou la création d'interfaces CLI avec des composants copier-coller. Déclenchez également lorsque l'utilisateur demande « comment ajouter un spinner à ma CLI », « comment afficher une barre de progression dans mon application de terminal » ou des questions similaires sur l'utilisation de composants dans un contexte de terminal/Node.js.
