استخدم هذه المهارة عندما يريد المستخدم تثبيت أو إضافة أو استخدام مكونات Orizen TUI في مشروع Node.js CLI الخاص به. قم بتشغيل أي ذكر لـ: orizen-tui، أو مكونات واجهة المستخدم الطرفية، أو TUI spinner/badge/progress/select، أو `npx orizen-tui add`، أو إنشاء واجهات CLI باستخدام مكونات النسخ واللصق. يتم تشغيله أيضًا عندما يسأل المستخدم "كيف يمكنني إضافة قرص دوار إلى واجهة سطر الأوامر الخاصة بي"، أو "كيف يمكنني إظهار شريط التقدم في تطبيقي الطرفي"، أو أسئلة مشابهة حول استخدام المكونات في سياق المحطة الطرفية/Node.js.
