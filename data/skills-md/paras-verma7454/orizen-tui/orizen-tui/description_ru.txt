Используйте этот навык всякий раз, когда пользователь хочет установить, добавить или использовать компоненты Orizen TUI в своем проекте Node.js CLI. Запуск при любом упоминании: orizen-tui, компонентов пользовательского интерфейса терминала, TUI spinner/badge/progress/select, npx orizen-tui add или создания интерфейсов CLI с помощью компонентов копирования и вставки. Также срабатывает, когда пользователь спрашивает «как добавить счетчик в мой CLI», «как показать индикатор выполнения в моем терминальном приложении» или аналогичные вопросы об использовании компонентов в контексте терминала/Node.js.
