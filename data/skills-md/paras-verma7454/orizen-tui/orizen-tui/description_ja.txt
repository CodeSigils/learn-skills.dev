ユーザーが Node.js CLI プロジェクトで Orizen TUI コンポーネントをインストール、追加、または使用する場合は常に、このスキルを使用します。 orizen-tui、ターミナル UI コンポーネント、TUI スピナー/バッジ/プログレス/選択、「npx orizen-tui add」、またはコピー＆ペースト コンポーネントを使用した CLI インターフェイスの構築に関する言及をトリガーします。また、ユーザーが「CLI にスピナーを追加するにはどうすればよいですか」、「ターミナル アプリでプログレス バーを表示するにはどうすればよいですか」、またはターミナル/Node.js コンテキストで同様のコンポーネントの使用法に関する質問をしたときにもトリガーされます。
