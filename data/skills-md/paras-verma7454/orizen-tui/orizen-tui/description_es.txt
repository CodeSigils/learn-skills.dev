Utilice esta habilidad siempre que un usuario quiera instalar, agregar o usar componentes Orizen TUI en su proyecto CLI de Node.js. Se activa ante cualquier mención de: orizen-tui, componentes de la interfaz de usuario del terminal, TUI spinner/badge/progress/select, `npx orizen-tui add` o creación de interfaces CLI con componentes de copiar y pegar. También se activa cuando el usuario pregunta "¿cómo agrego un control giratorio a mi CLI?", "cómo muestro una barra de progreso en mi aplicación de terminal" o preguntas similares sobre el uso de componentes en un contexto de terminal/Node.js.
