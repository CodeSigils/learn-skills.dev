Шаблоны Expo / React Native с Clerk — кеш токенов SecureStore, глубокая связь OAuth, использование Auth в собственных маршрутах, защищенных Expo Router, push-уведомления с пользовательским контекстом. Запускается по: клерку выставки, клерку, реагирующему на собственную реакцию, кэшу токенов SecureStore, аутентификации маршрутизатора выставки, клерку глубокой ссылки OAuth, клерку мобильной аутентификации.
