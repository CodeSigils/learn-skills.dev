Реализуйте аутентификацию Clerk для собственных приложений Android с помощью Kotlin и Jetpack Compose с шаблонами, управляемыми исходным кодом clerk-android. Используйте для предварительно созданных AuthView/UserButton или пользовательских потоков аутентификации на основе API. Не используйте для проектов Expo или React Native.
