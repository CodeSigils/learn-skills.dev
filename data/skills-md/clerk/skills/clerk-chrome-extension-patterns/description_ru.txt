Аутентификация расширения Chrome с помощью @clerk/chrome-extension — настройка всплывающего окна/боковой панели, syncHost для OAuth/SAML через веб-приложение, createClerkClient для сервисных работников и автономных расширений, стабильный идентификатор CRX. Запускается при: аутентификации расширения Chrome, Plasmo clerk, входе через всплывающее окно, syncHost, токене работника фоновой службы, createClerkClient, безголовом расширении.
