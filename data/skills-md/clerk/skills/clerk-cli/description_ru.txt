Используйте Clerk CLI (двоичный файл `clerk`) для аутентификации, управления пользователями/организациями/сессиями, проверки развертывания, настройки экземпляра, ключей среды и любого вызова Clerk Backend или API платформы. Используйте, когда пользователь упоминает задачи управления клерком, «составить список пользователей клерка», «создать пользователя клерка», «обновить организацию», «извлечь конфигурацию клерка», «вытащить среду клерка», «доктор клерка», «развертывание клерка», «статус развертывания клерка», «API клерка» или любой специальный запрос API клерка. Предпочитайте CLI вместо чистого HTTP: он автоматически обрабатывает аутентификацию, разрешение ключей, таргетинг на приложение/экземпляр и форматирование.
