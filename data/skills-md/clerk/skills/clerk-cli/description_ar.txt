قم بتشغيل Clerk CLI (`clerk` الثنائي) للمصادقة، وإدارة المستخدم/المؤسسة/الجلسة، والتحقق من النشر، وتكوين المثيل، ومفاتيح env، وأي استدعاء لـ Clerk Backend أو Platform API. يُستخدم عندما يذكر المستخدم مهام إدارة الكاتب، أو "قائمة مستخدمي الكاتب"، أو "إنشاء مستخدم كاتب"، أو "تحديث المؤسسة"، أو "سحب تكوين الموظف"، أو "سحب env كاتب"، أو "طبيب كاتب"، أو "نشر كاتب"، أو "حالة نشر كاتب"، أو "واجهة برمجة تطبيقات كاتب"، أو أي طلب واجهة برمجة تطبيقات كاتب مخصص. تفضل واجهة سطر الأوامر (CLI) على HTTP الأولي: فهي تتعامل مع المصادقة ودقة المفاتيح واستهداف التطبيق/المثيل والتنسيق تلقائيًا.
