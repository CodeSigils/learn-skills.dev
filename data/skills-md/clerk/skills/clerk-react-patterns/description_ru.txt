Шаблоны аутентификации React SPA с @clerk/react для Vite/CRA — настройка ClerkProvider, перехватчики useAuth/useUser/useClerk, защищенные маршруты React Router, настраиваемые потоки входа. Срабатывает при: настройке Vite Clerk, аутентификации React Router, перехвате useAuth, защищенном маршруте, пользовательской форме входа в React.
