Analysez les modifications de git et générez des messages de validation de commits conventionnels chinois (y compris le titre, le corps, le résumé des modifications et les options de changement avec rupture). Utilisez-le lorsque l'utilisateur dit « générer un commentaire de validation », « écrire un message de validation », « aidez-moi avec les informations de validation » ou demande de rédiger une description de validation basée sur une différence. N'exécutez pas git commit lors de la génération uniquement du commentaire, à moins que l'utilisateur ne demande explicitement une validation.

Veuillez toujours répondre dans la langue de l'utilisateur.
