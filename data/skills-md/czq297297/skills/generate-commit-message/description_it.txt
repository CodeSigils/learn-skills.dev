Analizza le modifiche git e genera messaggi di commit dei commit convenzionali cinesi (inclusi titolo, corpo, riepilogo delle modifiche e opzioni di modifica sostanziale). Utilizzalo quando l'utente dice "genera commento di commit", "scrivi messaggio di commit", "aiutami con le informazioni di commit" o richiede la stesura di una descrizione di commit basata su un diff. Non eseguire git commit solo durante la generazione del commento, a meno che l'utente non richieda esplicitamente un commit.

Si prega di rispondere sempre nella lingua dell'utente.
