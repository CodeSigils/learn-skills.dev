Анализируйте изменения git и генерируйте сообщения коммитов в соответствии с китайскими стандартами (включая заголовок, тело, сводку изменений и параметры критических изменений). Используйте это, когда пользователь говорит «создать комментарий к коммиту», «написать сообщение о коммите», «помогите мне с информацией о коммите» или просит составить описание коммита на основе различий. Не выполняйте git commit только при создании комментария, если только пользователь явно не запросит фиксацию.

Пожалуйста, всегда отвечайте на языке пользователя.
