قم بتحليل تغييرات git وإنشاء رسائل الالتزام الصينية التقليدية (بما في ذلك العنوان والنص وملخص التغيير وخيارات التغيير). استخدم هذا عندما يقول المستخدم "إنشاء تعليق التزام"، أو "اكتب رسالة التزام"، أو "ساعدني في معلومات الالتزام"، أو يطلب صياغة وصف التزام بناءً على اختلاف. لا تنفذ التزام git عند إنشاء التعليق فقط، ما لم يطلب المستخدم الالتزام صراحةً.

يرجى الرد دائمًا بلغة المستخدم.
