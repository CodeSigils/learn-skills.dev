Analysieren Sie Git-Änderungen und generieren Sie Commit-Nachrichten für herkömmliche chinesische Commits (einschließlich Titel, Text, Änderungszusammenfassung und Breaking-Change-Optionen). Verwenden Sie dies, wenn der Benutzer sagt „Commit-Kommentar generieren“, „Commit-Nachricht schreiben“, „Hilf mir mit Commit-Informationen“ oder den Entwurf einer Commit-Beschreibung basierend auf einem Unterschied anfordert. Führen Sie git commit nicht aus, wenn Sie nur den Kommentar generieren, es sei denn, der Benutzer fordert ausdrücklich einen Commit an.

Bitte antworten Sie immer in der Sprache des Benutzers.
