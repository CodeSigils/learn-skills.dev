Analice los cambios de git y genere mensajes de confirmación de compromisos convencionales chinos (incluidos el título, el cuerpo, el resumen de cambios y las opciones de cambios importantes). Utilice esto cuando el usuario diga "generar comentario de confirmación", "escribir mensaje de confirmación", "ayúdeme con información de confirmación" o solicite redactar una descripción de confirmación basada en una diferencia. No ejecute git commit cuando solo genere el comentario, a menos que el usuario solicite explícitamente una confirmación.

Por favor responda siempre en el idioma del usuario.
