| Протестированная на производстве настройка Tailwind CSS v4 с shadcn/ui, Vite и React. Используйте при инициализации проектов React с помощью Tailwind v4, настройке shadcn/ui, реализации темного режима, отладке проблем с переменными CSS, исправлении переключения тем, переходе с Tailwind v3 или возникновении проблем с цветом/темами. Охватывает: встроенный шаблон @theme, переменную архитектуру CSS, темный режим с ThemeProvider, композицию компонентов, настройку vite.config, распространенные ошибки версии 4 и шаблоны, проверенные на производстве.
