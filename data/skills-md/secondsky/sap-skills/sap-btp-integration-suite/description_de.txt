Unternehmensintegrationslösungen mit SAP Integration Suite auf BTP. Deckt Cloud-Integration (iFlows), API-Management, Event Mesh, Edge-Integrationszelle, Integrationsberater, Handelspartnermanagement und Migrationsbewertung ab. Verwendung zum Erstellen von Integrationsflüssen, Verwalten von API-Proxys, ereignisgesteuerten Architekturen, B2B/EDI-Integrationen, Hybridbereitstellungen, Adapterkonfiguration, Groovy/JavaScript-Nachrichtenverarbeitung und Fehlerbehebung.
