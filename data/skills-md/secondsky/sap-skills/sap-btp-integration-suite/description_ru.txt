Корпоративные интеграционные решения с использованием SAP Integration Suite на BTP. Охватывает облачную интеграцию (iFlows), управление API, сетку событий, ячейку пограничной интеграции, советник по интеграции, управление торговыми партнерами и оценку миграции. Используйте для построения потоков интеграции, управления прокси-серверами API, архитектур, управляемых событиями, интеграции B2B/EDI, гибридных развертываний, настройки адаптеров, обработки сообщений Groovy/JavaScript и устранения неполадок.
