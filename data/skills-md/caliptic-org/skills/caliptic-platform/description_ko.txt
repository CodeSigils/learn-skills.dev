Caliptic ITSM 플랫폼에 대한 종합적인 운영 가이드입니다. 이 기술을 에이전트에 연결하면 Caliptic의 도메인 모델(문제, 변경, 릴리스, 문제, 계약, CMDB, 스프린트), ITIL4 서비스 가치 사슬(사고 → 문제 → 변경 → 릴리스 → PIR → 개선), 해당 모듈을 서로 연결하는 접합 관계, REST API 표면, 일류 팀 동료 역할을 하는 에이전트에게 기대되는 행동 규칙에 대한 엔드투엔드 지식을 얻게 됩니다. 작업 공간의 기본 감독자와 연결되도록 설계되었습니다. 이는 모든 기본 상담원이 상속하는 공유 지식 기반입니다. 에이전트가 사건 분류, RCA 작성, 변경 요청 제기, 릴리스 범위 관리, PIR 제출, CSI 개선 사항 생성, 계약 분석, Caliptic의 API 및 아키텍처 규칙 내에서 작동할 수 있는 기능을 제공합니다.
