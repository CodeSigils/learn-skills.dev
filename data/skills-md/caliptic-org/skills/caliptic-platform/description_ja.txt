Caliptic ITSM プラットフォームの包括的な操作ガイド。このスキルをエージェントにアタッチすると、Caliptic のドメイン モデル (問題、変更、リリース、問題、契約、CMDB、スプリント)、ITIL4 サービス バリュー チェーン (インシデント → 問題 → 変更 → リリース → PIR → 改善)、これらのモジュールを結び付けるジャンクション関係、REST API サーフェス、および一流のチームメイトとして機能するエージェントに期待される行動ルールに関するエンドツーエンドの知識が得られます。ワークスペースのデフォルト スーパーバイザにバインドするように設計されており、すべてのデフォルト エージェントが継承する共有ナレッジ ベースです。エージェントがインシデントの優先順位付け、RCA の作成、変更リクエストの提起、リリース範囲の管理、PIR の送信、CSI 改善の生成、契約の分析、および Caliptic の API およびアーキテクチャ規約内での操作を行えるようにします。
