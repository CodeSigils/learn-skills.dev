Комплексное руководство по эксплуатации платформы Caliptic ITSM. Прикрепите этот навык к агенту, и он получит комплексные знания о модели предметной области Caliptic (проблемы, изменения, выпуски, проблемы, контракты, CMDB, спринты), цепочке создания стоимости услуги ITIL4 (инцидент → проблема → изменение → выпуск → PIR → улучшение), связях соединений, которые связывают эти модули вместе, поверхности REST API и правилах поведения, ожидаемых от агентов, действующих как первоклассные товарищи по команде. Предназначен для привязки к супервизору рабочей области по умолчанию — общей базе знаний, которую наследует каждый агент по умолчанию. Предоставляет агенту возможность сортировать инциденты, писать RCA, отправлять запросы на изменения, управлять объемом выпуска, отправлять PIR, запускать улучшения CSI, анализировать контракты и работать в рамках API Caliptic и архитектурных соглашений.
