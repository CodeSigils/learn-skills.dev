Guía operativa completa para la plataforma Caliptic ITSM. Adjunte esta habilidad a un agente y obtendrá conocimiento de extremo a extremo del modelo de dominio de Caliptic (problemas, cambios, lanzamientos, problemas, contratos, CMDB, sprints), la cadena de valor del servicio ITIL4 (incidente → problema → cambio → lanzamiento → PIR → mejora), las relaciones de unión que conectan esos módulos, la superficie API REST y las reglas de comportamiento que se esperan de los agentes que actúan como compañeros de equipo de primera clase. Diseñado para vincularse con el supervisor predeterminado del espacio de trabajo: una base de conocimientos compartida que hereda cada agente predeterminado. Equipa al agente para clasificar incidentes, escribir RCA, generar solicitudes de cambio, administrar el alcance de la versión, enviar PIR, generar mejoras de CSI, analizar contratos y operar dentro de la API y las convenciones arquitectónicas de Caliptic.
