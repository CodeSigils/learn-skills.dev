プロンプト作成規律を使用してプロンプトを形成した後、1 つの BrowserOS ChatGPT タブを通じてログインしている ChatGPT をクエリします。ユーザーが ChatGPT に質問する、ブラウザで ChatGPT を参照する、ChatGPT Web 意見を取得する、またはオプションの添付ファイルを使用してログインした ChatGPT UI を介してプロンプトを実行するように要求する場合に使用します。ユーザーがモードまたは労力を指定しない場合は、デフォルトで拡張思考の Pro になります。プロンプトを連続的に実行し、長い Pro 応答を辛抱強く待ちます。 OpenAI API の作業、一般的なブラウザの自動化、自動ログイン、スクリプト、ランナー、または隠しハーネスには使用できません。
