Interrogez ChatGPT connecté via un onglet ChatGPT de BrowserOS après avoir façonné l'invite avec la discipline de création d'invite. À utiliser lorsque l'utilisateur demande à demander à ChatGPT, à consulter ChatGPT dans le navigateur, à obtenir un avis sur ChatGPT sur le Web ou à exécuter une invite via l'interface utilisateur ChatGPT connectée avec des pièces jointes facultatives. La valeur par défaut est Pro avec réflexion étendue lorsque l'utilisateur ne spécifie pas de mode ou d'effort ; exécute les invites en série et attend patiemment les longues réponses Pro. Pas pour le travail de l'API OpenAI, l'automatisation générique du navigateur, la connexion automatisée, les scripts, les coureurs ou les harnais cachés.
