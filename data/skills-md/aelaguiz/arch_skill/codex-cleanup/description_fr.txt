Purgez l'état obsolète sous ~/.codex qui date de plus d'une semaine afin que les sessions CLI/TUI du codex parallèles cessent de se verrouiller sur des journaux SQLite gonflés, un journal TUI de 4 Go+ non pivoté et des mois de session JSONL datée. À utiliser lorsque ~/.codex est multi-Go, lorsque plus de 12 instances de codex parallèles se bloquent sur « la base de données est verrouillée », lorsque le WAL sur logs_2.sqlite a dépassé 100 Mo, ou lorsque vous souhaitez une purge hebdomadaire de routine. Pas pour éditer la configuration en direct (auth.json, config.toml, version.json, installation_id, .codex-global-state.json), pas pour le dépôt git du codex, pas pour nettoyer les caches non liés en dehors de ~/.codex.
