Доступный только для чтения статус потока и маршрутизатор следующего шага для документов Arch-Step, Miniarch-Step, Arch-mini-plan и Lilarch. Используйте, когда пользователь спрашивает: «Что дальше?», хочет получить контрольный список или хочет найти лучший следующий шаг без запуска рабочего процесса. Не для выполнения самой работы по планированию или реализации.
