تهيئة وإدارة عملاء Alibaba Cloud SDK في Java. يغطي النمط المفرد، وأمان سلسلة المحادثات، وتكوين نقطة النهاية مقابل المنطقة، ونقاط نهاية VPC، وعملاء المزامنة مقابل غير المتزامنين، وواجهات برمجة تطبيقات تحميل الملفات. يُستخدم عندما يقوم المستخدم بإنشاء عملاء Java SDK، أو تكوين نقاط النهاية، أو السؤال عن أمان سلسلة الرسائل، أو الأنماط المفردة، أو المكالمات غير المتزامنة، أو إعداد نقطة نهاية VPC.
