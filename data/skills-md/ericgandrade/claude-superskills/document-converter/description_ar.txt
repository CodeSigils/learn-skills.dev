يجب استخدام هذه المهارة عندما يحتاج المستخدم إلى تحويل المستندات بين التنسيقات (Office إلى PDF، أو PDF إلى صور، أو صورة إلى PDF)، أو إجراء عمليات PDF (دمج، أو تقسيم، أو تدوير، أو تشفير، أو فك تشفير)، أو تشغيل OCR على المستندات الممسوحة ضوئيًا. يستخدم الأدوات المحلية المجانية — LibreOffice، وghostscript، وpdftk، وtesseract، وimagemagick — دون الحاجة إلى مفتاح API. يتم تشغيله عندما يقول المستخدم "تحويل هذا المستند" أو "تصدير إلى PDF" أو "دمج ملفات PDF" أو "تقسيم PDF" أو "تدوير PDF" أو "OCR هذا المسح" أو "تحويل PPTX إلى PDF" أو "تحويل DOCX إلى PDF" أو أي طلب تحويل تنسيق مستند.
