Esta habilidad debe usarse cuando el usuario necesita convertir documentos entre formatos (Office a PDF, PDF a imágenes, imagen a PDF), realizar operaciones de PDF (fusionar, dividir, rotar, cifrar, descifrar) o ejecutar OCR en documentos escaneados. Utiliza herramientas locales gratuitas (LibreOffice, ghostscript, pdftk, tesseract e imagemagick) sin necesidad de clave API. Se activa cuando el usuario dice "convertir este documento", "exportar a PDF", "combinar archivos PDF", "dividir PDF", "rotar PDF", "OCR este escaneo", "convertir PPTX a PDF", "convertir DOCX a PDF" o cualquier solicitud de conversión de formato de documento.
