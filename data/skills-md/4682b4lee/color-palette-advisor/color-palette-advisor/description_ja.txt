科学的カラーマッチングコンサルタント。 2 ステップのガイド (使用シナリオの選択 + カラー スタイルの選択) を通じてプロフェッショナルなカラー スキームを生成し、Pantone スタイルの HTML レポートを出力します。プリセット スタイル、人気のスタイル、ブランド カラー スキームに加えて、カスタム スタイルの説明、参照 Web サイト、スクリーンショットのアップロードという 3 つの入力方法をサポートします。 Web サイトのデザイン、ミニプログラム、アプリのインターフェイス、UI アイコン、ポスター/グラフィック デザイン、データの視覚化、その他のシナリオに適しています。トリガーワード: カラーマッチング、色の組み合わせ、配色、ウェブサイトの配色、UI の配色、デザインの配色。
