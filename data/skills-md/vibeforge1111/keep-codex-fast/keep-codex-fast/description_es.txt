Úselo cuando Codex se sienta lento o sobrecargado, cuando las sesiones/registros/árboles de trabajo/configuración locales hayan crecido con el tiempo o cuando un usuario desee un mantenimiento seguro para el estado de Codex Desktop/CLI. Proporciona un informe de solo lectura de forma predeterminada, realiza copias de seguridad antes de aplicar cambios, archiva en lugar de eliminarlos, normaliza las rutas extendidas de Windows, elimina proyectos de configuración inactivos, rota registros grandes y mueve árboles de trabajo obsoletos.
