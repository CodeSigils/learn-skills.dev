Orientación experta para probar módulos EAF (Enterprise Application Foundation) utilizando xUnit, Shouldly, NSubstitute y coverlet. Cubre pruebas unitarias, pruebas de integración, cobertura de pruebas, patrones BDD en portugués y patrones de prueba específicos de EAF. Utilice esta habilidad al escribir pruebas para módulos EAF, mejorar la cobertura de las pruebas, depurar fallas de las pruebas o configurar la infraestructura de pruebas. NO lo use para código de producción, código que no sea de prueba o proyectos que no sean EAF.
