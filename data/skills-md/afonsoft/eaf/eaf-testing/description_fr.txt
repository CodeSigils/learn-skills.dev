Conseils d'experts pour tester les modules EAF (Enterprise Application Foundation) à l'aide de xUnit, Shouldly, NSubstitute et coverlet. Couvre les tests unitaires, les tests d'intégration, la couverture des tests, les modèles BDD en portugais et les modèles de test spécifiques à l'EAF. Utilisez cette compétence lors de l'écriture de tests pour les modules EAF, de l'amélioration de la couverture des tests, du débogage des échecs de test ou de la configuration de l'infrastructure de test. Ne PAS utiliser pour le code de production, le code non-test ou les projets non-EAF.
