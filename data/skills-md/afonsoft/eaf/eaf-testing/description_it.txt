Guida esperta per testare i moduli EAF (Enterprise Application Foundation) utilizzando xUnit, Shouldly, NSubstitute e coverlet. Copre test unitari, test di integrazione, copertura dei test, modelli BDD in portoghese e modelli di test specifici per EAF. Utilizzare questa competenza quando si scrivono test per i moduli EAF, si migliora la copertura dei test, si esegue il debug degli errori di test o si configura l'infrastruttura di test. NON utilizzare per codice di produzione, codice non di test o progetti non EAF.
