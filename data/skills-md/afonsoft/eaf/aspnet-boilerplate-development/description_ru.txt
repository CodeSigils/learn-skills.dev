Экспертное руководство по разработке ASP.NET Boilerplate (ABP) и .NET 10.0 для модулей промежуточного программного обеспечения EAF (Enterprise Application Foundation). Охватывает N-уровневую архитектуру, внедрение зависимостей с помощью Castle Windsor, многопользовательскую эксплуатацию, авторизацию, кэширование, фоновые задания, Entity Framework Core, модули промежуточного программного обеспечения, специфичные для EAF (Serilog, KeyVault, OpenTelemetry, кэш SQL Server/SQLite) и лучшие практики ABP. Используйте этот навык при разработке модулей промежуточного программного обеспечения EAF, работе с платформой ABP, реализации репозиториев/служб приложений или устранении проблем, связанных с ABP. НЕ используйте для общей разработки .NET, проектов, не связанных с ABP, или разработки внешнего интерфейса.
