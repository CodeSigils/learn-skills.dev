Conseils d'experts pour le développement ASP.NET Boilerplate (ABP) et .NET 10.0 pour les modules middleware EAF (Enterprise Application Foundation). Couvre l'architecture N-Layer, l'injection de dépendances avec Castle Windsor, la multilocation, l'autorisation, la mise en cache, les tâches en arrière-plan, Entity Framework Core, les modules middleware spécifiques à EAF (Serilog, KeyVault, OpenTelemetry, cache SQL Server/SQLite) et les meilleures pratiques ABP. Utilisez cette compétence lors du développement de modules middleware EAF, de l'utilisation du framework ABP, de la mise en œuvre de référentiels/services d'application ou du dépannage de problèmes liés à ABP. Ne PAS utiliser pour le développement .NET général, les projets non ABP ou le développement frontend.
