Orientación experta para desarrollar, mantener y ampliar la interfaz de usuario de EAF (Enterprise Application Foundation) utilizando Angular 18, TypeScript 5.2, PrimeNG 17 y RxJS 7. Cubre componentes independientes, señales, formularios reactivos, servicios HTTP, autenticación, protecciones de ruta, tablas de datos y patrones de interfaz de usuario específicos de EAF. Utilice esta habilidad al crear componentes Angular, implementar flujos de autenticación, crear tablas de datos con PrimeNG, configurar enrutamiento o solucionar problemas de interfaz. NO lo use para desarrollo de API de backend, trabajo de bases de datos o marcos de frontend que no sean Angular.
