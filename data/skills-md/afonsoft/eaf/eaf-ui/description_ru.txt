Экспертное руководство по разработке, обслуживанию и расширению пользовательского интерфейса EAF (Enterprise Application Foundation) с использованием Angular 18, TypeScript 5.2, PrimeNG 17 и RxJS 7. Охватывает автономные компоненты, сигналы, реактивные формы, службы HTTP, аутентификацию, защиту маршрутов, таблицы данных и шаблоны пользовательского интерфейса, специфичные для EAF. Используйте этот навык при создании компонентов Angular, реализации потоков аутентификации, построении таблиц данных с помощью PrimeNG, настройке маршрутизации или устранении неполадок внешнего интерфейса. НЕ используйте для разработки серверных API, работы с базами данных или интерфейсных платформ, отличных от Angular.
