Angular 18, TypeScript 5.2, PrimeNG 17 및 RxJS 7을 사용하여 EAF(Enterprise Application Foundation) UI를 개발, 유지 관리 및 확장하기 위한 전문가 지침입니다. 독립형 구성 요소, 신호, 반응 양식, HTTP 서비스, 인증, 경로 가드, 데이터 테이블 및 EAF 관련 UI 패턴을 다룹니다. Angular 구성 요소 생성, 인증 흐름 구현, PrimeNG로 데이터 테이블 구축, 라우팅 구성 또는 프런트엔드 문제 해결 시 이 기술을 사용하세요. 백엔드 API 개발, 데이터베이스 작업 또는 Angular가 아닌 프런트엔드 프레임워크에는 사용하지 마세요.
