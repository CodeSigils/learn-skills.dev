إرشادات الخبراء لتطوير وصيانة وتوسيع واجهة المستخدم EAF (Enterprise Application Foundation) باستخدام Angular 18 وTypeScript 5.2 وPrimeng 17 وRxJS 7. يغطي المكونات المستقلة والإشارات والنماذج التفاعلية وخدمات HTTP والمصادقة وحراس المسار وجداول البيانات وأنماط واجهة المستخدم الخاصة بـ EAF. استخدم هذه المهارة عند إنشاء مكونات Angular، أو تنفيذ تدفقات المصادقة، أو إنشاء جداول البيانات باستخدام PrimeNG، أو تكوين التوجيه، أو استكشاف مشكلات الواجهة الأمامية وإصلاحها. لا تستخدم لتطوير واجهة برمجة التطبيقات الخلفية أو عمل قاعدة البيانات أو أطر الواجهة الأمامية غير الزاوية.
