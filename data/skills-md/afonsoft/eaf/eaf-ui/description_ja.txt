Angular 18、TypeScript 5.2、PrimeNG 17、および RxJS 7 を使用して EAF (Enterprise Application Foundation) UI を開発、保守、拡張するための専門家によるガイダンス。スタンドアロン コンポーネント、シグナル、リアクティブ フォーム、HTTP サービス、認証、ルート ガード、データ テーブル、EAF 固有の UI パターンをカバーします。このスキルは、Angular コンポーネントの作成、認証フローの実装、PrimeNG でのデータ テーブルの構築、ルーティングの構成、またはフロントエンドの問題のトラブルシューティングを行うときに使用します。バックエンド API 開発、データベース作業、または非 Angular フロントエンド フレームワークには使用しないでください。
