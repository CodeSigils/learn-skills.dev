Guida esperta per lo sviluppo, la manutenzione e l'estensione dell'interfaccia utente EAF (Enterprise Application Foundation) utilizzando Angular 18, TypeScript 5.2, PrimeNG 17 e RxJS 7. Copre componenti autonomi, segnali, moduli reattivi, servizi HTTP, autenticazione, protezioni del percorso, tabelle di dati e modelli di interfaccia utente specifici di EAF. Utilizza questa competenza durante la creazione di componenti Angular, l'implementazione di flussi di autenticazione, la creazione di tabelle di dati con PrimeNG, la configurazione del routing o la risoluzione dei problemi del frontend. NON utilizzare per lo sviluppo di API backend, il lavoro su database o framework frontend non Angular.
