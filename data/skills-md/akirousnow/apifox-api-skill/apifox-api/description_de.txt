Verwenden Sie diese Fähigkeit, wenn Sie in einem JavaScript/TypeScript-Frontend-Projekt arbeiten und der Benutzer eine Seite, eine Komponente, eine API-Anforderungsdatei oder ein Feature überprüfen möchte, um herauszufinden, welche Schnittstellen sie aufruft, welche Anforderungspfade/-methoden verwendet werden oder welche Anforderungs-/Antwort-TypeScript-Typen benötigt werden. Auch verwenden, wenn der Benutzer direkt eine API-URL oder einen Endpunktpfad angibt. Zu den Triggerphrasen gehören „看看这个页面的接口“, „这个页面调了哪些接口“, „查一下这个接口的入参返回值“, „补接口类型“, „根据页面找接口“, „JS 项目没有类型“, „分析一下这个请求“, „帮我理解这段代码“, „这个返回结构是什么“. Der Agent sollte zunächst den Quellcode des Projekts untersuchen, um API-Anforderungsfunktionen zu finden, die Anforderungs-URL/den Anforderungspfad und die HTTP-Methode extrahieren und dann „apifox-api get „<path>““ oder „apifox-api get METHOD „<path>““ ausführen. Wenn der Benutzer eine vollständige URL angibt, suchen Sie niemals zuerst: Extrahieren Sie den Pfadnamen und führen Sie zuerst „get“ aus. Verwenden Sie „search“ nur für vage Schlüsselwörter oder nachdem „get“ den Endpunkt nicht finden kann.
