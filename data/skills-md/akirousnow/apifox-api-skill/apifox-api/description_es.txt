Utilice esta habilidad cuando trabaje en un proyecto frontend de JavaScript/TypeScript y el usuario solicite inspeccionar una página, componente, archivo de solicitud de API o característica para encontrar qué interfaces llama, qué rutas/métodos de solicitud se utilizan o qué tipos de solicitud/respuesta de TypeScript se necesitan. Úselo también cuando el usuario proporciona una URL de API o una ruta de punto final directamente. Las frases de activación incluyen "看看这个页面的接口", "这个页面调了哪些接口", "查一下这个接口的入参返回值", "补接口类型", "根据页面找接口", "JS 项目没有类型", "分析一下这个请求", "帮我理解这段代码", "这个返回结构是什么". El agente primero debe inspeccionar el código fuente del proyecto para ubicar las funciones de solicitud de API, extraer la URL/ruta de solicitud y el método HTTP, luego ejecutar `apifox-api get "<path>"` o `apifox-api get METHOD "<path>"`. Si el usuario proporciona una URL completa, nunca busque primero: extraiga el nombre de la ruta y ejecute "get" primero. Utilice "buscar" solo para palabras clave vagas o después de que "obtener" no pueda encontrar el punto final.
