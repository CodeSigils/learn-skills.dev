استخدم هذه المهارة عند العمل في مشروع الواجهة الأمامية لـ JavaScript/TypeScript ويطلب المستخدم فحص صفحة أو مكون أو ملف طلب API أو ميزة للعثور على الواجهات التي يستدعيها، أو مسارات/طرق الطلب المستخدمة، أو أنواع الطلب/الاستجابة المطلوبة لـ TypeScript. يُستخدم أيضًا عندما يقدم المستخدم عنوان URL لواجهة برمجة التطبيقات (API) أو مسار نقطة النهاية مباشرةً. تتضمن عبارات التشغيل "看看这个页面的接口"، "这个页面调了哪些接口"، "查一下这个接口的入参返回值"، "补接口类型"، "根据页面找接口"، "JS 项目没有类型"، "分析一下这个请求"، "帮我理解这段代码"، "这个返回结构是什么". يجب على الوكيل أولاً فحص الكود المصدري للمشروع لتحديد موقع وظائف طلب واجهة برمجة التطبيقات، واستخراج عنوان URL/مسار الطلب وطريقة HTTP، ثم تشغيل `apifox-api get "<path>"` أو `apifox-api get METHOD "<path>"`. إذا قدم المستخدم عنوان URL كاملاً، فلا تبحث أبدًا أولاً: قم باستخراج اسم المسار وتشغيل `get` أولاً. استخدم "البحث" فقط للكلمات الرئيسية الغامضة أو بعد أن يتعذر على "get" العثور على نقطة النهاية.
