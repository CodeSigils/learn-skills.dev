在 JavaScript/TypeScript 前端專案中工作且使用者要求檢查頁面、元件、API 請求檔案或功能以查找其呼叫的介面、使用的請求路徑/方法或需要哪些請求/回應 TypeScript 類型時，請使用此技能。當使用者直接提供 API URL 或端點路徑時也可使用。觸發短語包括「看看這個頁面的介面」、「這個頁面調整了哪些介面」、「查一下這個介面的入參回傳值」、「補接口類型」、「根據頁面找介面」、「JS專案沒有類型」、「分析這個請求」、「幫我理解程式碼」、「這個回傳結構是什麼」。代理程式應先檢查專案原始程式碼以定位 API 請求函數，提取請求 URL/路徑和 HTTP 方法，然後執行 `apifox-api get "<path>"` 或 `apifox-api get METHOD "<path>"`。如果使用者提供完整的 URL，切勿先搜尋：提取路徑名稱並先執行「get」。僅對模糊關鍵字或在「get」找不到端點後使用「search」。
