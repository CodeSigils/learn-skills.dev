在 JavaScript/TypeScript 前端项目中工作并且用户要求检查页面、组件、API 请求文件或功能以查找其调用的接口、使用的请求路径/方法或需要哪些请求/响应 TypeScript 类型时，请使用此技能。当用户直接提供 API URL 或端点路径时也可使用。触发短语包括“看看这个页面的接口”、“这个页面调整了哪些接口”、“查一下这个接口的入参返回值”、“补接口类型”、“根据页面找接口”、“JS项目没有类型”、“分析一下这个请求”、“帮我理解一下代码”、“这个返回结构是什么”。代理应首先检查项目源代码以定位 API 请求函数，提取请求 URL/路径和 HTTP 方法，然后运行 ​​`apifox-api get "<path>"` 或 `apifox-api get METHOD "<path>"`。如果用户提供完整的 URL，切勿先搜索：提取路径名并首先运行“get”。仅对模糊关键字或在“get”找不到端点后使用“search”。
