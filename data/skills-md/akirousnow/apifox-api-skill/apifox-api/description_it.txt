Utilizza questa abilità quando lavori in un progetto frontend JavaScript/TypeScript e l'utente chiede di ispezionare una pagina, un componente, un file di richiesta API o una funzionalità per scoprire quali interfacce chiama, quali percorsi/metodi di richiesta vengono utilizzati o quali tipi di richiesta/risposta TypeScript sono necessari. Da utilizzare anche quando l'utente fornisce direttamente un URL API o un percorso endpoint. Le frasi trigger includono "看看这个页面的接口", "这个页面调了哪些接口", "查一下这个接口的入参返回值", "补接口类型", "根据页面找接口", "JS 项目没有类型", "分析一下这个请求", "帮我理解这段代码", "这个返回结构是什么". L'agente deve prima ispezionare il codice sorgente del progetto per individuare le funzioni di richiesta API, estrarre l'URL/percorso della richiesta e il metodo HTTP, quindi eseguire `apifox-api get "<path>"` o `apifox-api get METHOD "<path>"`. Se l'utente fornisce un URL completo, non cercare mai prima: estrai il percorso ed esegui prima `get`. Utilizza "search" solo per parole chiave vaghe o dopo che "get" non riesce a trovare l'endpoint.
