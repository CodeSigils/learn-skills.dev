Utilisez cette compétence lorsque vous travaillez dans un projet frontal JavaScript/TypeScript et que l'utilisateur demande à inspecter une page, un composant, un fichier de requête API ou une fonctionnalité pour trouver les interfaces qu'il appelle, quels chemins/méthodes de requête sont utilisés ou quels types de requête/réponse TypeScript sont nécessaires. À utiliser également lorsque l'utilisateur fournit directement une URL d'API ou un chemin de point de terminaison. Les phrases déclencheurs incluent "看看这个页面的接口", "这个页面调了哪些接口", "查一下这个接口的入参返回值", "补接口类型", "根据页面找接口", "JS 项目没有类型", "分析一下这个请求", "帮我理解这段代码", "这个返回结构是什么". L'agent doit d'abord inspecter le code source du projet pour localiser les fonctions de requête API, extraire l'URL/le chemin de la requête et la méthode HTTP, puis exécuter `apifox-api get "<path>"` ou `apifox-api get METHOD "<path>"`. Si l'utilisateur fournit une URL complète, ne recherchez jamais en premier : extrayez le chemin d'accès et exécutez d'abord « get ». Utilisez « recherche » uniquement pour des mots-clés vagues ou après que « get » ne trouve pas le point de terminaison.
