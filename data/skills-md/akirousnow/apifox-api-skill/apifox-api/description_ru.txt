Используйте этот навык при работе над проектом внешнего интерфейса JavaScript/TypeScript, и пользователь просит проверить страницу, компонент, файл запроса API или функцию, чтобы найти, какие интерфейсы он вызывает, какие пути/методы запроса используются или какие типы запросов/ответов TypeScript необходимы. Также используйте, когда пользователь напрямую предоставляет URL-адрес API или путь к конечной точке. К триггерным фразам относятся «看看这个页面的接口», «这个页面调了哪些接口», «查一下这个接口的入参返回值», "补接口类型", "根据页面找接口", "JS 项目没有类型", "分析一下这个请求", "帮我理解这段代码", «这个返回结构是什么». Агент должен сначала проверить исходный код проекта, чтобы найти функции запроса API, извлечь URL-адрес/путь запроса и метод HTTP, а затем запустить `apifox-api get "<path>"` или `apifox-api get METHOD "<path>"`. Если пользователь предоставляет полный URL-адрес, никогда не выполняйте поиск первым: извлеките путь и сначала запустите get. Используйте `search` только для расплывчатых ключевых слов или если `get` не может найти конечную точку.
