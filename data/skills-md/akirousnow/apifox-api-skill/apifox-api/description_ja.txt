JavaScript/TypeScript フロントエンド プロジェクトで作業しており、ユーザーがページ、コンポーネント、API リクエスト ファイル、または機能を検査して、呼び出されるインターフェイス、使用されているリクエスト パス/メソッド、または必要なリクエスト/レスポンス TypeScript タイプを見つけるように要求する場合に、このスキルを使用します。ユーザーが API URL またはエンドポイント パスを直接指定する場合にも使用します。トリガー フレーズには、「看看衵面的インターフェイス」、「このインターフェイス调了哪これらのインターフェイス」、「查一下衵面的インターフェイスの入力参返值」、「补インターフェイスタイプ」、「ベース页面找インターフェイス」、「JS 项目なしタイプ」、 「分析一下这个请求」、「帮我理解この段代コード」、「これ返结构是何么」。エージェントはまずプロジェクトのソース コードを検査して API リクエスト関数を見つけ、リクエスト URL/パスと HTTP メソッドを抽出してから、`apifox-api get "<path>"` または `apifox-api get METHOD "<path>"` を実行する必要があります。ユーザーが完全な URL を指定した場合は、決して最初に検索しないでください。最初にパス名を抽出して `get` を実行します。 「search」は、あいまいなキーワードに対してのみ、または「get」でエンドポイントが見つからない場合にのみ使用してください。
