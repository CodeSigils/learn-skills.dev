Справочный указатель библиотеки пользовательского интерфейса Rust с компонентом gpui longbridge. Предоставляет сводные данные по каждому компоненту, основные API и готовые к копированию примеры использования Rust для 57 компонентов (кнопка, диалоговое окно, таблица, диаграмма, ввод, боковая панель и т. д.). Используйте при создании настольных приложений в стиле GPUI/Zed, импорте из крейта gpui_comComponent или когда пользователь спрашивает о компонентах, реквизитах или примерах использования компонента gpui. 中文组件速查,按类别索引到每个组件的详情文档.
