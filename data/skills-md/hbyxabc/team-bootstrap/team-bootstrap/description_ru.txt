Создайте полноценную команду ИИ-агентов из 4 ролей с рабочим процессом, управлением документацией и крючками для любого проекта. Используйте при запуске нового проекта, когда вам нужна структура команды, когда вас просят «настроить агентов» или «создать команду», при загрузке Claude Code для совместной разработки или когда кто-то упоминает о необходимости ролей, рабочего процесса или управления командой. Не используйте для изменения существующей настройки группы или для задач автоматизации с одним агентом.
