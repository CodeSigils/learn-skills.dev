قم بإعداد فريق كامل من وكلاء الذكاء الاصطناعي مكون من 4 أدوار مع سير العمل وإدارة المستندات والخطافات لأي مشروع. يُستخدم عند بدء مشروع جديد والحاجة إلى بنية الفريق، أو عندما يُطلب منك "إعداد الوكلاء" أو "إنشاء فريق"، أو عند تمهيد Claude Code للتطوير التعاوني، أو عندما يذكر شخص ما الحاجة إلى الأدوار أو سير العمل أو إدارة الفريق. لا تستخدم لتعديل إعداد فريق موجود أو لمهام التشغيل الآلي للوكيل الفردي.
