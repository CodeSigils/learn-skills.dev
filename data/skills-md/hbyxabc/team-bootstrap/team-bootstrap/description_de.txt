Richten Sie ein komplettes 4-Rollen-KI-Agententeam mit Workflow, Dokumentenverwaltung und Hooks für jedes Projekt ein. Verwenden Sie diese Funktion, wenn Sie ein neues Projekt starten und eine Teamstruktur benötigen, wenn Sie aufgefordert werden, „Agenten einzurichten“ oder „ein Team zu erstellen“, wenn Sie Claude Code für die kollaborative Entwicklung einsetzen oder wenn jemand erwähnt, dass Rollen, Arbeitsabläufe oder Teamverwaltung erforderlich sind. Nicht zum Ändern eines vorhandenen Team-Setups oder für Automatisierungsaufgaben mit einem einzelnen Agenten verwenden.
