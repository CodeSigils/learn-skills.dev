Configure un equipo completo de agentes de IA de 4 roles con flujo de trabajo, administración de documentos y enlaces para cualquier proyecto. Úselo cuando comience un nuevo proyecto y necesite una estructura de equipo, cuando se le solicite "configurar agentes" o "crear un equipo", cuando inicie Claude Code para el desarrollo colaborativo o cuando alguien mencione que necesita roles, flujo de trabajo o gestión de equipos. No lo use para modificar la configuración de un equipo existente ni para tareas de automatización de un solo agente.
