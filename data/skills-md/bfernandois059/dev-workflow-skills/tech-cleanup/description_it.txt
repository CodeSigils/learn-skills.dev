Tech Cleanup rileva codici, file, dipendenze e risorse non in uso e produce un piano di eliminazione sicuro classificato per rischio. Úsala SIEMPRE che l'utente vuole pulire correttamente in un sito, app o repository già in produzione o nel punto di partenza: codice morto, componenti senza uso, percorsi obsoleti, immagini/risorse duplicate o senza riferimenti, dipendenze non necessarie, script senza uso, test obsoleti, configurazioni duplicate, variabili di ambiente abbandonato o documentazione disattivata. Spara con frasi come "limpia el proyecto", "hay código muerto", "elimina lo que no se usa", "reduce el bundle", "poda el repo de basura técnica", "auditoría de código sin uso", "encuentra archivos huérfanos", "dependencias que no se usan" o quando il sito si trova in fase di produzione e si sta accumulando disordinare. Non la usa per auditar orden general, ramas o gobernanza (usa marcozen) né per definire l'architettura di un proyecto nuevo (usa project-blueprint).
