Tech Cleanup détecte le code, les fichiers, les dépendances et les assets non utilisés, et produit un plan d’élimination sécurisée classé par risque. Utilisez‑le TOUJOURS quand l’utilisateur veut nettoyer la dette technique sur un site, une application ou un dépôt déjà en production ou sur le point de l’être : code mort, composants inutilisés, routes obsolètes, images/assets dupliqués ou sans références, dépendances inutiles, scripts non utilisés, tests obsolètes, configurations dupliquées, variables d’environnement abandonnées ou documentation périmée. Déclenchez‑le avec des phrases comme « nettoie le projet », « il y a du code mort », « supprime ce qui n’est pas utilisé », « réduis le bundle », « taille le repo de déchets techniques », « audit du code inutilisé », « trouve les fichiers orphelins », « dépendances qui ne sont pas utilisées » ou quand le site est en production depuis un moment et a accumulé du désordre. Ne l’utilisez pas pour auditer l’ordre général, les branches ou la gouvernance (utilisez marcozen) ni pour définir l’architecture d’un nouveau projet (utilisez project‑blueprint).
