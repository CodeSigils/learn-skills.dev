Tech Cleanup は、コード、アーカイブ、依存関係のある資産を検出し、安全な廃棄計画を作成します。使用可能なシステム、アプリのリポジトリや製品の開発: コンピューター、コンポーネント、古いもの、参照、依存関係、必要なスクリプトの重複した画像/アセット使用、廃止されたテスト、重複した構成、エンターノ放棄された変数、または文書化された実際の変数。 「limpia el proyecto」、「hay código muerto」、「elimina lo que no se usa」、「reduce elbundle」、「poda el repo de basura técnica」、「auditoría de código sin uso」、「encuentra archives huérfanos」、「dependencias que no se usan」に関する内容の変更現場での作業と生産を行って、蓄積された環境を整えてください。 LA では、para Auditar Orden General、ramas o gobernanza (usa marcozen) ni para definir arquitectura de un proyecto nuevo (usa project-blueprint) を使用していません。
