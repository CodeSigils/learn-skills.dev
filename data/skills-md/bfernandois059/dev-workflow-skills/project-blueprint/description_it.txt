Progetta il progetto tecnico, funzionale e documentale di un progetto digitale prima di implementarlo. Usa l'avvio o la ristrutturazione di siti web, landing page, intranet, portali, SaaS, piattaforme interne, dashboard, e-commerce, API o automatizzazioni. È necessario intervistare, classificare il progetto, consigliare lo stack minimo sufficiente, definire architettura, dati, sicurezza, documenti, norme per IA e piano di implementazione. Non è necessario iniziare a costruire il prodotto o inventare requisiti non confermati.
