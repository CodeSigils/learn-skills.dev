Память агента для репо (индекс/вызов кода) и сеанса (сохранение/восстановление через приватный git). Используйте при настройке Mimir, сохранении прогресса на разных машинах, продолжении работы или вызове структуры репозитория. Установите через CLI навыков - не клонируйте Mimir только для того, чтобы использовать его.
