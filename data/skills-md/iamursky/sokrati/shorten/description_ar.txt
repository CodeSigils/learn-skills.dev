يقوم بتحرير وتحسين الكتابة التجارية والمهنية باللغة الإنجليزية باستخدام مبادئ أسلوب المعلومات - وهو نهج التحرير الذي يركز على القارئ أولاً والذي طوره مكسيم إلياهوف. يتم تفعيل المهارة عندما يطلب المستخدم تعديل أو مراجعة أو تنظيف أو تشديد أو تحسين أي نص خاص بالعمل: رسائل البريد الإلكتروني، أو الصفحات المقصودة، أو حول الصفحات، أو النشرات الصحفية، أو السير الذاتية، أو التقارير، أو مجموعات الشرائح، أو رسائل البريد الإلكتروني الباردة، أو المنشورات الاجتماعية، أو أي نسخة احترافية. يتم تشغيله أيضًا عند الإشارة إلى "أسلوب المعلومات"، أو "أسلوب المعلومات"، أو "إلياهوف"، أو "جلافريد"، أو "كلمات العلم الأحمر"، أو "كلمات الحشو"، أو "البيروقراطية"، أو بناءً على طلبات قطع الزغب، أو القضاء على الكليشيهات، أو جعل النص "أقوى"، أو إعادة الكتابة "بلغة واضحة". يعمل من أجل تصاريح التحرير الكاملة وللحصول على تعليقات مستهدفة. يمكن تطبيقه على النص الروسي إذا طلب المستخدم ذلك صراحةً.
