À utiliser lors du test d'une application Flutter sur un véritable appareil Android via adb (installer l'APK, lancer, vérifier l'interface utilisateur, vérifier logcat pour les plantages, vérifier le stockage créé). Couvre l'adb sans fil, l'inspection des données d'exécution, la capture d'écran et les vérifications fondées sur des preuves que l'application fonctionne réellement sur l'appareil.
