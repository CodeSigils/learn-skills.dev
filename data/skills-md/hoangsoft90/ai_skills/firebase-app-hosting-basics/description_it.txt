Distribuisce e gestisce applicazioni Web full-stack (Next.js, Angular) con rendering lato server (SSR) utilizzando Firebase App Hosting. Da utilizzare durante la distribuzione di app Next.js/Angular, la configurazione di blocchi di hosting di app apphosting.yaml o firebase.json, la gestione dei segreti, l'impostazione di GitHub CI/CD o la configurazione dei requisiti di fatturazione di Blaze. Non utilizzare per il classico hosting web statico, Auth, Firestore, Crashlytics o Xcode.
