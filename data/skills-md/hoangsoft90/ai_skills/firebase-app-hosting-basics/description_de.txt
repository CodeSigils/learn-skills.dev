Stellt Full-Stack-Webanwendungen (Next.js, Angular) mit Server-Side Rendering (SSR) mithilfe von Firebase App Hosting bereit und verwaltet sie. Verwenden Sie diese Option, wenn Sie Next.js/Angular-Apps bereitstellen, apphosting.yaml- oder firebase.json-Apphosting-Blöcke konfigurieren, Geheimnisse verwalten, GitHub CI/CD einrichten oder Blaze-Abrechnungsanforderungen konfigurieren. Nicht für klassisches statisches Webhosting, Auth, Firestore, Crashlytics oder Xcode verwenden.
