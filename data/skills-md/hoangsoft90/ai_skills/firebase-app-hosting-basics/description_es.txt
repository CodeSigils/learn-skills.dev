Implementa y administra aplicaciones web de pila completa (Next.js, Angular) con renderizado del lado del servidor (SSR) mediante Firebase App Hosting. Úselo al implementar aplicaciones Next.js/Angular, configurar bloques de alojamiento de aplicaciones apphosting.yaml o firebase.json, administrar secretos, configurar GitHub CI/CD o configurar los requisitos de facturación de Blaze. No lo utilice para alojamiento web estático clásico, Auth, Firestore, Crashlytics o Xcode.
