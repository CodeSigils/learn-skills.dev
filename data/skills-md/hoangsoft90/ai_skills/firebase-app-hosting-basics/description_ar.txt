نشر وإدارة تطبيقات الويب الكاملة (Next.js وAngular) مع العرض من جانب الخادم (SSR) باستخدام Firebase App Hosting. يُستخدم عند نشر تطبيقات Next.js/Angular، أو تكوين كتل apphosting.yaml أو firebase.json، أو إدارة الأسرار، أو إعداد GitHub CI/CD، أو تكوين متطلبات فوترة Blaze. لا تستخدمه لاستضافة الويب الثابتة الكلاسيكية، أو Auth، أو Firestore، أو Crashlytics، أو Xcode.
