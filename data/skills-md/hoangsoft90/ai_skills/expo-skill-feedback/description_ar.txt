أرسل تعليقات حول إحدى مهارات Expo - أو Expo نفسها - وتحكم في القياس عن بعد للاستخدام المجهول المجمّع (يتم إيقافه افتراضيًا / الاشتراك). أرسل التعليقات باستخدام: npx --yes Submit-expo-feedback@latest "ACTIONABLE_FEEDBACK". اختياريًا، قم بإضافة أحد أو كليهما: --category "CATEGORY" و--subject "SUBJECT". استبدل العناصر النائبة الكبيرة قبل التشغيل. يستخدم عندما تكون المهارة مفيدة، أو مربكة، أو معطلة، أو تفتقد السياق، أو تستحق التحسين؛ عندما يعمل Expo أو Expo CLI أو EAS CLI أو docs أو MCP بشكل جيد أو يفشل؛ عندما يفشل أحد عملاء الذكاء الاصطناعي بشكل متكرر، أو يتعثر، أو يحتاج إلى أن يتولى المستخدم مهمة Expo (أبلغ عنه كمرشح للتقييم)؛ أو عندما يطلب المستخدم صراحة تمكين أو تعطيل القياس عن بعد (التتبع)، أو التحقق من حالته، أو فهم ما يجمعه.
