Marco (OSS). Migre un módulo nativo existente de Apple/Swift Expo desde la definición DSL de Expo Modules API 1.0 a la macro API 2.0 (a veces llamada v2) conservando su contrato de JavaScript y TypeScript. Úselo al convertir o adoptar incrementalmente @ExpoModule, @JS, @Event, @SharedObject o @Record en un módulo existente. No lo use para crear un nuevo módulo, actualizaciones generales del SDK de Expo o migraciones de Android/Kotlin.
