نشر وتكوين استضافة Firebase الكلاسيكية لمواقع الويب الثابتة وتطبيقات الصفحة الواحدة (SPAs) والخدمات الصغيرة. يُستخدم عند نشر المواقع الثابتة/المنتجعات، أو إعداد المجالات المخصصة، أو تكوين إعدادات استضافة firebase.json (عمليات إعادة التوجيه، أو إعادة الكتابة، أو الرؤوس، أو المواقع المتعددة)، أو إدارة قنوات المعاينة. لا تستخدمه مع Firebase App Hosting (Next.js/SSR)، أو Auth، أو استعلامات/قواعد Firestore، أو Data Connect، أو Crashlytics.
