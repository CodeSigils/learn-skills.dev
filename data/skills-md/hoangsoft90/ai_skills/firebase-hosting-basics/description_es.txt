Implementa y configura Firebase Hosting clásico para sitios web estáticos, aplicaciones de una sola página (SPA) y microservicios. Úselo al implementar sitios estáticos/SPA, configurar dominios personalizados, configurar ajustes de alojamiento de firebase.json (redirecciones, reescrituras, encabezados, sitios múltiples) o administrar canales de vista previa. No lo use para Firebase App Hosting (Next.js/SSR), Auth, consultas/reglas de Firestore, Data Connect o Crashlytics.
