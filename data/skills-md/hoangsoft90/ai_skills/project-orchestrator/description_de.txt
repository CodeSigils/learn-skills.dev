Koordinieren Sie den gesamten Flutter-App-Entwicklungsprozess mithilfe von KI – vom Lesen der OpenSpec über die Entscheidung, ob eine Migration erforderlich ist, das Generieren von Code, das Ausführen der automatischen MCP-Korrektur, das Anfordern der UI-Genehmigung bis hin zur Festlegung auf Git. Verwenden Sie diese Fähigkeit IMMER zuerst, wenn ein Benutzer das Hinzufügen oder Ändern einer Funktion für eine Flutter-App anfordert, auch wenn er nur etwas Kurzes sagt wie „Anmeldebildschirm hinzufügen“ oder „eine Bubble-Tea-Verkaufs-App erstellen“. Dies ist eine Koordinationscheckliste, kein selbstgeschriebener Code.
