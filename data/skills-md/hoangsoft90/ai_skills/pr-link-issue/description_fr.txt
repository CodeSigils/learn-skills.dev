Ajoutez un lien de problème GitHub et son ticket linéaire à la description du PR actuel. À utiliser lorsqu'on lui demande de « lier le problème au pr », « de remplir le problème et le linéaire dans pr », « d'ajouter des références de problème au pr », ou lorsqu'on lui donne une URL de problème GitHub et qu'on lui demande de la joindre au PR actuel. Résout automatiquement le ticket linéaire à partir du commentaire de lien linéaire du problème.
