Hängen Sie einen GitHub-Issue-Link und sein Linear-Ticket an die Beschreibung des aktuellen PR an. Wird verwendet, wenn Sie aufgefordert werden, „Problem mit PR zu verknüpfen“, „Problem auszufüllen und linear in PR einzugeben“, „Issue-Referenzen zu PR hinzuzufügen“ oder wenn Sie eine GitHub-Issue-URL erhalten und aufgefordert werden, diese an die aktuelle PR anzuhängen. Löst das lineare Ticket automatisch aus dem linearen Linkback-Kommentar des Problems auf.
