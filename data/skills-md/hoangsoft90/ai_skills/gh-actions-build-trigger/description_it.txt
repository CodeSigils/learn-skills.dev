Problemi di attivazione/monitoraggio del flusso di lavoro GH Actions per qualsiasi repository con più flussi di lavoro (ad esempio build APK + AAB). Da utilizzare quando un push a main non sembra attivare un flusso di lavoro, quando è stato modificato solo .github/** (i filtri dei percorsi lo saltano, è necessario l'invio manuale), quando è necessario annullarne uno per le esecuzioni parallele, quando una compilazione non è riuscita ed è necessario estrarre il registro del lavoro o quando si controlla lo stato/gli artefatti dell'esecuzione. Per il flusso di build Expo APK/AAB end-to-end, utilizza invece gh-actions-expo-apk-build.
