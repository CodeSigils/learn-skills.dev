Рабочий процесс GH Actions, запускающий/отслеживающий ошибки для любого репозитория с несколькими рабочими процессами (например, сборки APK + AAB). Используйте, когда нажатие на main не запускает рабочий процесс, когда изменяется только .github/** (фильтры путей пропускают его, требуется ручная отправка), когда параллельные запуски требуют отмены, когда сборка не удалась и необходимо получить журнал задания, или при проверке статуса запуска/артефактов. Для сквозного процесса сборки Expo APK/AAB вместо этого используйте gh-actions-expo-apk-build.
