GH Actions-Workflow-Auslösung/Überwachung von Fallstricken für jedes Repo mit mehreren Workflows (z. B. APK + AAB-Builds). Wird verwendet, wenn ein Push an den Hauptserver scheinbar keinen Workflow auslöste, wenn nur .github/** geändert wurde (Pfadfilter überspringen es, muss manuell versendet werden), wenn parallele Ausführungen abgebrochen werden müssen, wenn ein Build fehlgeschlagen ist und das Jobprotokoll abgerufen werden muss, oder wenn der Ausführungsstatus/Artefakte überprüft werden. Für den End-to-End-Expo-APK/AAB-Build-Flow verwenden Sie stattdessen gh-actions-expo-apk-build.
