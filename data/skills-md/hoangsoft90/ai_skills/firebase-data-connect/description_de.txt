Erstellt und stellt sicher Firebase SQL Connect-Backends (auch bekannt als Firebase Data Connect) mit PostgreSQL bereit. Verwenden Sie es, wenn Sie Schemata mit Tabellen und Beziehungen entwerfen, autorisierte Abfragen und Mutationen schreiben, Echtzeit-Datenaktualisierungen konfigurieren oder typsichere SDKs generieren. Verwenden Sie diese Option, wenn Sie eine relationale Datenbank mit Firebase benötigen oder wenn der Benutzer SQL Connect oder Data Connect erwähnt.
