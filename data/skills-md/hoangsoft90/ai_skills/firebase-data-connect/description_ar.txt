يبني وينشر الواجهة الخلفية لـ Firebase SQL Connect (المعروف أيضًا باسم Firebase Data Connect) مع PostgreSQL بشكل آمن. يُستخدم عند تصميم المخططات باستخدام الجداول والعلاقات، أو كتابة الاستعلامات والتغييرات المعتمدة، أو تكوين تحديثات البيانات في الوقت الفعلي، أو إنشاء مجموعات SDK آمنة للنوع. استخدمها عندما تحتاج إلى قاعدة بيانات علائقية مع Firebase، أو عندما يذكر المستخدم SQL Connect أو Data Connect.
