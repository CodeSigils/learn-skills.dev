Costruisce e distribuisce backend Firebase SQL Connect (noto anche come Firebase Data Connect) con PostgreSQL in modo sicuro. Da utilizzare durante la progettazione di schemi con tabelle e relazioni, la scrittura di query e mutazioni autorizzate, la configurazione di aggiornamenti dei dati in tempo reale o la generazione di SDK indipendenti dai tipi. Da utilizzare quando è necessario un database relazionale con Firebase o quando l'utente menziona SQL Connect o Data Connect.
