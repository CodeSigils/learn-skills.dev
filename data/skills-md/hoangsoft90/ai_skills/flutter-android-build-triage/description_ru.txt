Используйте при сбое сборки Flutter Android (`flutter build apk`, ошибки Gradle, несовместимость плагинов, конфликты версий AGP/Gradle, ошибки собственных ресурсов, такие как sqlite3_initialize, ENOSPC/диск переполнен, поврежденный кеш публикации). Выполните диагностику, найдя строку обвинения в выводе Gradle, примените соответствующее исправление из таблицы симптомов, а затем проверьте с помощью чистой сборки.
