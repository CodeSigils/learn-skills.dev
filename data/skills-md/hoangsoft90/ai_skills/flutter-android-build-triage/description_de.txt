Wird verwendet, wenn ein Flutter-Android-Build fehlschlägt („flutter build apk“, Gradle-Fehler, Plugin-Inkompatibilität, AGP/Gradle-Versionskonflikte, Fehler bei nativen Assets wie sqlite3_initialize, ENOSPC/Festplatte voll, beschädigter Pub-Cache). Führen Sie eine Diagnose durch, indem Sie die Schuldzeile in der Gradle-Ausgabe finden, den passenden Fix aus der Symptomtabelle anwenden und dann mit einem sauberen Build überprüfen.
