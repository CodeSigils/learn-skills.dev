À utiliser lorsqu'une version Flutter Android échoue (`flutter build apk`, erreurs Gradle, incompatibilité de plugin, conflits de version AGP/Gradle, erreurs d'actifs natifs comme sqlite3_initialize, ENOSPC/disque plein, cache de pub corrompu). Diagnostiquez en recherchant la ligne de blâme dans la sortie Gradle, appliquez le correctif correspondant à partir du tableau des symptômes, puis vérifiez avec une version propre.
