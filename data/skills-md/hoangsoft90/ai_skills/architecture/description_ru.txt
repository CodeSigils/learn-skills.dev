Вы можете использовать Flutter для управления состоянием (управление состоянием, маршрутизатор, функция в первую очередь) и использовать код, который будет использоваться в данный момент. Если у вас нет навыков, которые нужны для написания кода, это функция, которая позволяет вам создать файл в рамках проекта Flutter.
