Framework (OSS). Leitfaden zum Erstellen und Schreiben nativer Expo-Module und -Ansichten mithilfe der Expo-Modul-API (Swift, Kotlin, TypeScript). Behandelt Moduldefinitions-DSL, native Ansichten, gemeinsam genutzte Objekte, Konfigurations-Plugins, Lebenszyklus-Hooks, Autolinking und Typsystem. Wird zum Erstellen oder Ändern nativer Module für Expo verwendet. Nicht für die Migration eines vorhandenen Swift-Moduls von der Definition DSL auf die Expo Modules API 2.0-Makros; Verwenden Sie dazu das Expo-Migrate-Modul (aus dem Expo-Experiments-Plugin).
