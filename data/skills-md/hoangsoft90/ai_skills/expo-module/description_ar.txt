الإطار (OSS). دليل لإنشاء وكتابة وحدات وطرق عرض Expo الأصلية باستخدام Expo Modules API (Swift وKotlin وTypeScript). يغطي تعريف الوحدة النمطية DSL، وطرق العرض الأصلية، والكائنات المشتركة، ومكونات التكوين الإضافية، وخطافات دورة الحياة، والربط التلقائي، ونوع النظام. يُستخدم عند إنشاء الوحدات النمطية الأصلية أو تعديلها لـ Expo. ليس لترحيل وحدة Swift موجودة من تعريف DSL إلى وحدات ماكرو Expo Modules API 2.0؛ استخدم وحدة Expo-Migrate (من البرنامج المساعد Expo-Experiments) لذلك.
