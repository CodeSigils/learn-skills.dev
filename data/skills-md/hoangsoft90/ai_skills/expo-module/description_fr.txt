Cadre (OSS). Guide pour créer et écrire des modules et des vues natifs d'Expo à l'aide de l'API Expo Modules (Swift, Kotlin, TypeScript). Couvre la définition du module DSL, les vues natives, les objets partagés, les plugins de configuration, les hooks de cycle de vie, la liaison automatique et le système de type. À utiliser lors de la création ou de la modification de modules natifs pour Expo. Pas pour migrer un module Swift existant de la définition DSL vers les macros Expo Modules API 2.0 ; utilisez expo-migrate-module (à partir du plugin expo-experiments) pour cela.
