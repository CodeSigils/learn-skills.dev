Фреймворк (ОСС). Руководство по созданию и написанию собственных модулей и представлений Expo с использованием API модулей Expo (Swift, Kotlin, TypeScript). Охватывает DSL определения модуля, собственные представления, общие объекты, плагины конфигурации, перехватчики жизненного цикла, автоматическое связывание и систему типов. Используйте при создании или изменении собственных модулей для Expo. Не для переноса существующего модуля Swift из определения DSL в макросы Expo Modules API 2.0; для этого используйте expo-migrate-module (из плагина expo-experiments).
