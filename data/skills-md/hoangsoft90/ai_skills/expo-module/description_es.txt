Marco (OSS). Guía para crear y escribir módulos y vistas nativos de Expo utilizando la API de módulos de Expo (Swift, Kotlin, TypeScript). Cubre la definición de módulos DSL, vistas nativas, objetos compartidos, complementos de configuración, enlaces de ciclo de vida, enlaces automáticos y sistemas de tipos. Úselo al crear o modificar módulos nativos para Expo. No para migrar un módulo Swift existente desde la definición DSL a las macros Expo Modules API 2.0; use expo-migrate-module (del complemento expo-experiments) para eso.
