フレームワーク（OSS）。 Expo モジュール API (Swift、Kotlin、TypeScript) を使用して Expo ネイティブ モジュールとビューを作成および記述するためのガイド。モジュール定義 DSL、ネイティブ ビュー、共有オブジェクト、構成プラグイン、ライフサイクル フック、自動リンク、および型システムをカバーします。 Expo のネイティブ モジュールを構築または変更するときに使用します。既存の Swift モジュールを定義 DSL から Expo Modules API 2.0 マクロに移行するためのものではありません。そのためには expo-merge-module (expo-experiments プラグインから) を使用してください。
