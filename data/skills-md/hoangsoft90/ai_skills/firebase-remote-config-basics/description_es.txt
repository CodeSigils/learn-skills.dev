Administra plantillas de Firebase Remote Config, indicadores de funciones, estrategias de carga y SDK (Android, iOS). Úselo al descargar/implementar plantillas JSON de configuración remota, administrar el historial de versiones/indicadores de funciones, configurar valores predeterminados en la aplicación, fetchAndActivate(), escuchas en tiempo real o configuración de SDK. No lo use para Firebase Hosting, Auth, Firestore, Data Connect, Crashlytics o App Hosting.
