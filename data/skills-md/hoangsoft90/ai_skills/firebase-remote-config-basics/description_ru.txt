Управляет шаблонами Firebase Remote Config, флагами функций, стратегиями загрузки и SDK (Android, iOS). Используйте при загрузке/развертывании шаблонов JSON удаленной конфигурации, управлении историей версий/флагами функций, установке значений по умолчанию в приложении, fetchAndActivate(), прослушивателях в реальном времени или настройке SDK. Не используйте для хостинга Firebase, Auth, Firestore, Data Connect, Crashlytics или хостинга приложений.
