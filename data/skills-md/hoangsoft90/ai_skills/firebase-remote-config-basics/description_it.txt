Gestisce modelli Firebase Remote Config, flag di funzionalità, strategie di caricamento e SDK (Android, iOS). Da utilizzare durante il download/distribuzione di modelli JSON remoteconfig, la gestione della cronologia delle versioni/flag delle funzionalità, l'impostazione delle impostazioni predefinite in-app, fetchAndActivate(), ascoltatori in tempo reale o la configurazione dell'SDK. Non utilizzare per Firebase Hosting, Auth, Firestore, Data Connect, Crashlytics o App Hosting.
