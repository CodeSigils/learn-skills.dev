يدير قوالب Firebase Remote Config وعلامات الميزات وإستراتيجيات التحميل ومجموعات SDK (Android وiOS). يُستخدم عند تنزيل/نشر قوالب JSON عن بعد، أو إدارة سجل الإصدارات/علامات الميزات، أو تعيين الإعدادات الافتراضية داخل التطبيق، أو fetchAndActivate()، أو المستمعين في الوقت الفعلي، أو إعداد SDK. لا تستخدمه مع Firebase Hosting، أو Auth، أو Firestore، أو Data Connect، أو Crashlytics، أو استضافة التطبيقات.
