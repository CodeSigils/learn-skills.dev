Überprüft die Sicherheitsregeln von Firebase (Firestore, Cloud Storage) auf Schwachstellen, Rechteausweitung, Rollenumgehungen, Inkonsistenzen zwischen Erstellung und Aktualisierung, Ressourcenerschöpfung, Typsicherheit, Größenbeschränkungen und HasOnly-Eigentumsprüfungen. Zur Verwendung bei der Prüfung/Überprüfung von Regeln, der Durchführung von Red-Team-Regelbewertungen oder der Bewertung anhand von Prüfer-Checklisten. Nicht für Firebase CLI (Anmeldung, Bereitstellung), Auth, Crashlytics, Remote Config oder Datenbankabfragen verwenden.
