تدقيق قواعد أمان Firebase (Firestore، Cloud Storage) الخاصة بالثغرات الأمنية، وتصعيد الامتيازات، وتجاوز الأدوار، وعدم اتساق الإنشاء مقابل التحديث، واستنفاد الموارد، وأمان النوع، وحدود الحجم، وعمليات التحقق من الملكية فقط. يُستخدم عند تدقيق/مراجعة القواعد، أو إجراء تقييمات لقواعد الفريق الأحمر، أو التسجيل مقابل قوائم مراجعة المدققين. لا تستخدمه مع Firebase CLI (تسجيل الدخول أو النشر) أو Auth أو Crashlytics أو Remote Config أو استعلامات قاعدة البيانات.
