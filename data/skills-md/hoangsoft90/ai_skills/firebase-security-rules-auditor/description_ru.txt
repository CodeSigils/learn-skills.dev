Аудит правил безопасности Firebase (Firestore, Cloud Storage) на наличие уязвимостей, повышение привилегий, обход ролей, несогласованность создания и обновления, исчерпание ресурсов, безопасность типов, ограничения размера и проверки владения hasOnly. Используйте при аудите/пересмотре правил, проведении оценок правил красной командой или выставлении оценок по контрольным спискам аудиторов. Не используйте для Firebase CLI (вход в систему, развертывание), Auth, Crashlytics, Remote Config или запросов к базе данных.
