Controlla le regole di sicurezza Firebase (Firestore, Cloud Storage) per vulnerabilità, escalation dei privilegi, bypass dei ruoli, incoerenze tra creazione e aggiornamento, esaurimento delle risorse, indipendenza dai tipi, limiti di dimensione e controlli di proprietà hasOnly. Da utilizzare durante il controllo/revisione delle regole, l'esecuzione di valutazioni delle regole del team rosso o il punteggio rispetto alle liste di controllo del revisore. Non utilizzare per la CLI Firebase (accesso, distribuzione), Auth, Crashlytics, Remote Config o query sul database.
