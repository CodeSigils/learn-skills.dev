Audita las reglas de seguridad de Firebase (Firestore, Cloud Storage) en busca de vulnerabilidades, escalada de privilegios, omisiones de roles, inconsistencias entre creación y actualización, agotamiento de recursos, seguridad de tipos, límites de tamaño y comprobaciones de propiedad de hasOnly. Úselo al auditar/revisar reglas, ejecutar evaluaciones de reglas del equipo rojo o calificar según las listas de verificación del auditor. No lo use para Firebase CLI (iniciar sesión, implementar), autenticación, Crashlytics, Remote Config o consultas de bases de datos.
