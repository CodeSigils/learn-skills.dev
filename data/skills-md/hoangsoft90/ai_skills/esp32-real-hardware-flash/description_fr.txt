À utiliser lors du flashage ou du test du micrologiciel ESP32 sur du matériel réel via USB : téléchargement via PlatformIO, ouverture du port série pour les journaux de démarrage, configuration du WiFi pour les réseaux domestiques, ou lorsque le téléchargement échoue avec "Impossible d'ouvrir le port" / "Opération non autorisée".
