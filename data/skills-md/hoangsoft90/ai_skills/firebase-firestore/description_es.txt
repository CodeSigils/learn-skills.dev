Configura, administra, consulta y configura bases de datos de Cloud Firestore (edición Standard/Enterprise), incluido el modelado de datos, reglas de seguridad, índices e integraciones de SDK (Web, Python, iOS, Android, Flutter). Úselo al crear/enumerar bases de datos de Firestore, definir modelos/índices de datos, escribir consultas de SDK o integrar SDK de Firestore. No lo use para Firebase Hosting, Data Connect, Auth, Storage/GCS, Crashlytics, Functions o BigQuery.
