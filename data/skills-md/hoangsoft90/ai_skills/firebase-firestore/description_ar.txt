يقوم بإعداد قواعد بيانات Cloud Firestore وإدارتها والاستعلام عنها وتكوينها (الإصدار القياسي/المؤسسي)، بما في ذلك نمذجة البيانات وقواعد الأمان والفهارس وتكاملات SDK (Web وPython وiOS وAndroid وFlutter). يُستخدم عند إنشاء/إدراج قواعد بيانات Firestore، أو تحديد نماذج/فهرس البيانات، أو كتابة استعلامات SDK، أو دمج حزم Firestore SDK. لا تستخدمه مع Firebase Hosting، أو Data Connect، أو Auth، أو Storage/GCS، أو Crashlytics، أو Functions، أو BigQuery.
