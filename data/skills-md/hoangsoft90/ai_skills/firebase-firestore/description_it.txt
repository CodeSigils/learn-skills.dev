Imposta, gestisce, interroga e configura i database Cloud Firestore (edizione Standard/Enterprise), inclusi modellazione dei dati, regole di sicurezza, indici e integrazioni SDK (Web, Python, iOS, Android, Flutter). Da utilizzare durante la creazione/l'elenco di database Firestore, la definizione di modelli/indici di dati, la scrittura di query SDK o l'integrazione di SDK Firestore. Non utilizzare per hosting Firebase, connessione dati, autenticazione, archiviazione/GCS, Crashlytics, Funzioni o BigQuery.
