Tạo 分支 riêng cho mỗi opsx 更改 (không code thẳng trên main)，tự động commit sau khi user xác nhận UI ổn (qua ui-checkpoint)，合并 vào main khi 更改 đã archive xong，và xử lý yêu cầu “quay lại”、“undo”、“bỏ tính năng vừa thêm”bằng git thay vì đọc lại 代码 để xóa thủ công - tiết kiệm 令牌 đáng kể。 Dùng 技能 này ngay khi 1 更改 mới được tạo (để 分支)、sau ui-checkpoint (để 提交)、sau 存档 (để 合并)、hoặc bất cứ khi nào 用户 muốn hủy/quay lại thay đổi gần đây。
