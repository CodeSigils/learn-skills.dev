Tạo Branch riêng cho mỗi opsx 변경(không code thẳng trên main), tự động 커밋 sau khi user xác nhận UI ổn(qua ui-checkpoint), merge vào main khi 변경 đã archive xong, và xử lý yêu cầu "quay lại", "undo", "bỏ tính năng vừa thêm" bằng git thay vì đọc lại 코드 để xóa thủ công - tiết kiêm 토큰 đáng kể. Dùng Skill này ngay khi 1 변경 mới đuợc tạo(để 분기), sau ui-checkpoint(để 커밋), sau 아카이브(để 병합), hoặc bất cứ khi nào user muốn hủy/quay lại thay đổi 그래.
