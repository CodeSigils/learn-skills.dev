Um den Branch zu verzweigen, um meine OPSX-Änderung (den Code des Hauptservers) zu ändern, den Benutzer auf der Benutzeroberfläche festzuschreiben (als UI-Checkpoint), die Haupt-Khi-Änderung in der Archivdatei zusammenzuführen und die Datei „Quay“ zu öffnen Wenn Sie den Code löschen, können Sie ihn rückgängig machen. Mit dieser Fertigkeit können Sie 1 Änderungsvorgang (Zweig) durchführen, den UI-Checkpoint (Festschreiben) und das Archiv (Zusammenführen) ändern und den Benutzernamen/-status ändern đổi gần đây.
