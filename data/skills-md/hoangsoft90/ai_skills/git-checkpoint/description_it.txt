Il ramo è stato modificato in opsx change (codice del menu principale), quindi commit o utente x nell'interfaccia utente (come ui-checkpoint), merge e main khi change in archivio xong e quindi "quay" lại", "undo", "bỏ tính năng vừa thêm" si trasforma in git thay in un codice per creare un token - tiết kiệm token đáng kể. L'abilità non può essere cambiata 1 volta (ramo), checkpoint dell'interfaccia utente (commit), archivio (unione), accesso all'utente/quay l'hay đổi va bene.
