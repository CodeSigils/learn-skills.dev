Fornisce la configurazione di base della CLI Firebase, l'installazione della CLI, i controlli della versione (`firebase-tools@latest --version`), l'accesso alla CLI (incluso --no-localhost), la creazione di progetti, la selezione del progetto (`firebase use`) e il download dei file di configurazione dell'app (`google-services.json`, `GoogleService-Info.plist`). Utilizzare SOLO per l'accesso alla CLI, la creazione/il cambio di progetto o il download dei file di configurazione dell'app. Non utilizzare per la distribuzione di Firebase Hosting, Firestore, Auth, App Hosting, Data Connect, Crashlytics o Remote Config.
