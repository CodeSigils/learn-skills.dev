Proporciona configuración básica de Firebase CLI, instalación de CLI, verificaciones de versión (`firebase-tools@latest --version`), inicio de sesión de CLI (incluido --no-localhost), creación de proyectos, selección de proyectos (`firebase use`) y descargas de archivos de configuración de aplicaciones (`google-services.json`, `GoogleService-Info.plist`). Úselo SÓLO para iniciar sesión en CLI, crear/cambiar proyectos o descargar archivos de configuración de aplicaciones. No lo use para la implementación de Firebase Hosting, Firestore, Auth, App Hosting, Data Connect, Crashlytics o Remote Config.
