Fournit la configuration de base de Firebase CLI, l'installation de la CLI, les vérifications de version (`firebase-tools@latest --version`), la connexion CLI (y compris --no-localhost), la création de projet, la sélection de projet (`firebase use`) et les téléchargements de fichiers de configuration d'application (`google-services.json`, `GoogleService-Info.plist`). À utiliser UNIQUEMENT pour la connexion CLI, la création/commutation de projet ou le téléchargement de fichiers de configuration d'application. Ne pas utiliser pour le déploiement de Firebase Hosting, Firestore, Auth, App Hosting, Data Connect, Crashlytics ou Remote Config.
