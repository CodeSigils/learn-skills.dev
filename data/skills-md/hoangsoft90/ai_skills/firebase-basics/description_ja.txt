基本的な Firebase CLI のセットアップ、CLI のインストール、バージョン チェック (`firebase-tools@latest --version`)、CLI ログイン (--no-localhost を含む)、プロジェクトの作成、プロジェクトの選択 (`firebase use`)、アプリ構成ファイルのダウンロード (`google-services.json`、`GoogleService-Info.plist`) を提供します。 CLI ログイン、プロジェクトの作成/切り替え、またはアプリ構成ファイルのダウンロードにのみ使用してください。 Firebase Hosting デプロイ、Firestore、Auth、App Hosting、Data Connect、Crashlytics、または Remote Config には使用しないでください。
