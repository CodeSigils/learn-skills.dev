Обеспечивает базовую настройку Firebase CLI, установку CLI, проверку версий (`firebase-tools@latest --version`), вход в CLI (включая --no-localhost), создание проекта, выбор проекта (`firebase use`) и загрузку файлов конфигурации приложения (`google-services.json`, `GoogleService-Info.plist`). Используйте ТОЛЬКО для входа в систему через интерфейс командной строки, создания/переключения проекта или загрузки файлов конфигурации приложения. Не используйте для развертывания хостинга Firebase, Firestore, аутентификации, хостинга приложений, подключения к данным, Crashlytics или удаленной настройки.
