يوفر إعداد Firebase CLI الأساسي، وتثبيت CLI، وعمليات التحقق من الإصدار (`firebase-tools@latest --version`)، وتسجيل دخول CLI (بما في ذلك --no-localhost)، وإنشاء المشروع، واختيار المشروع (`firebase use`)، وتنزيلات ملف تكوين التطبيق (`google-services.json`، `GoogleService-Info.plist`). استخدم فقط لتسجيل الدخول إلى واجهة سطر الأوامر (CLI)، أو إنشاء/تبديل المشروع، أو تنزيل ملفات تكوين التطبيق. لا تستخدمه لنشر Firebase Hosting، أو Firestore، أو Auth، أو App Hosting، أو Data Connect، أو Crashlytics، أو Remote Config.
