Фреймворк (ОСС). Структура папок для нового приложения Expo. Используйте при создании строительных лесов или планировании нового проекта Expo с помощью Expo Router или при принятии решения о том, где в нем должен находиться файл. Только для новых проектов — никогда не реструктуризируйте существующее приложение в соответствии с ним.
