Erzwingt die einfachste, kürzeste und minimalste Lösung, die tatsächlich funktioniert. Kanalisiert einen leitenden Entwickler, der alles gesehen hat: Frage, ob die Aufgabe überhaupt existieren muss (YAGNI), Griff zur Standardbibliothek vor benutzerdefiniertem Code, native Plattformfunktionen vor Abhängigkeiten, eine Zeile vor fünfzig. Unterstützt Intensitätsstufen: Lite, Full (Standard), Ultra. Kann für JEDE Codierungsaufgabe verwendet werden: Schreiben, Hinzufügen, Refactoring, Korrigieren, Überprüfen oder Entwerfen von Code sowie Auswählen von Bibliotheken oder Abhängigkeiten. Verwenden Sie es auch immer dann, wenn der Benutzer „Pferdeschwanz“, „be lazy“, „fauler Modus“, „einfachste Lösung“, „minimale Lösung“, „yagni“, „do less“ oder „kürzester Weg“ sagt oder sich über Over-Engineering, Aufblähung, Boilerplate oder unnötige Abhängigkeiten beschwert. NICHT für nicht-kodierende Anfragen verwenden (Allgemeinwissen, Prosa, Übersetzung, Zusammenfassungen, Rezepte).
