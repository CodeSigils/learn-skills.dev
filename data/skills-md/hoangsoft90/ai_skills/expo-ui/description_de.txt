Erstellen Sie eine native Benutzeroberfläche mit dem @expo/ui-Paket: echte SwiftUI auf iOS und Jetpack Compose auf Android, gerendert aus React in einer Expo- oder React Native-App. Behandelt universelle plattformübergreifende Komponenten (Host, Spalte, Zeile, Schaltfläche, Text, Liste und mehr, importiert aus @expo/ui), Drop-in-Ersetzungen für beliebte React Native-Community-Bibliotheken (BottomSheet, DateTimePicker, Slider, Menü usw.) und plattformspezifische SwiftUI-Bäume und Modifikatoren (@expo/ui/swift-ui, nur iOS) und Jetpack Compose (@expo/ui/jetpack-compose, nur Android). Verwenden Sie diese Option, wenn Sie @expo/ui Host/RNHostView-Bäume hinzufügen oder überprüfen, eine nativ anmutende Benutzeroberfläche erstellen, bei der standardmäßige React Native-Komponenten nicht ausreichen (gruppierte Einstellungsformulare mit Schaltern, Abschnitten, Menüs, Blättern, Auswahlmöglichkeiten, Schiebereglern), zwischen universellen und plattformspezifischen Komponenten wählen oder eine RN-Community-UI-Bibliothek durch ein natives @expo/ui-Äquivalent ersetzen. Nicht für benutzerdefinierte native Module, Expo-Router-Navigation, Reanimation oder Datenabruf.
