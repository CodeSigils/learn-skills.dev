フレームワーク（OSS）。 @expo/ui パッケージを使用してネイティブ UI を構築します。iOS では実際の SwiftUI、Android では Jetpack Compose を Expo または React Native アプリの React からレンダリングします。ユニバーサル クロスプラットフォーム コンポーネント (@expo/ui からインポートされたホスト、列、行、ボタン、テキスト、リストなど)、人気のある React Native コミュニティ ライブラリのドロップイン置換 (BottomSheet、DateTimePicker、Slider、Menu など)、プラットフォーム固有の SwiftUI (@expo/ui/swift-ui、iOS のみ) および Jetpack Compose (@expo/ui/jetpack-compose、Android のみ) ツリーをカバーします。修飾子。 @expo/ui Host/RNHostView ツリーを追加または確認する場合、標準の React Native コンポーネントでは不十分なネイティブ感覚の UI (トグル、セクション、メニュー、シート、ピッカー、スライダーを備えたグループ化された設定フォーム) を構築する場合、ユニバーサル コンポーネントとプラットフォーム固有のコンポーネントのどちらかを選択する場合、または RN コミュニティ UI ライブラリをネイティブの @expo/ui 同等のものに置き換える場合に使用します。カスタム ネイティブ モジュール、Expo Router ナビゲーション、Reanimated、またはデータ フェッチには使用できません。
