Фреймворк (ОСС). Создайте собственный пользовательский интерфейс с помощью пакета @expo/ui: настоящий SwiftUI на iOS и Jetpack Compose на Android, созданный из React в приложении Expo или React Native. Охватывает универсальные кросс-платформенные компоненты (Host, Column, Row, Button, Text, List и другие, импортированные из @expo/ui), вставные замены для популярных библиотек сообщества React Native (BottomSheet, DateTimePicker, Slider, Menu и т. д.), а также деревья SwiftUI (@expo/ui/swift-ui, только для iOS) и Jetpack Compose (@expo/ui/jetpack-compose, только для Android) и модификаторы. Используйте при добавлении или просмотре деревьев @expo/ui Host/RNHostView, создании естественного пользовательского интерфейса там, где стандартные компоненты React Native не подходят (формы сгруппированных настроек с переключателями, разделами, меню, листами, средствами выбора, ползунками), выборе между универсальными и специфичными для платформы компонентами или замене библиотеки пользовательского интерфейса сообщества RN на собственный эквивалент @expo/ui. Не для пользовательских собственных модулей, навигации Expo Router, реанимации или получения данных.
