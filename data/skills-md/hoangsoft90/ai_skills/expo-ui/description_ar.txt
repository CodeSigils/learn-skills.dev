الإطار (OSS). أنشئ واجهة مستخدم أصلية باستخدام حزمة @expo/ui: واجهة SwiftUI الحقيقية على iOS وJetpack Compose على Android المقدمة من React في تطبيق Expo أو React Native. يغطي المكونات العامة عبر الأنظمة الأساسية (المضيف والعمود والصف والزر والنص والقائمة والمزيد المستوردة من @expo/ui)، والبدائل المنسدلة لمكتبات مجتمع React Native الشهيرة (BottomSheet، وDateTimePicker، وSlider، وMenu، وما إلى ذلك)، وSwiftUI الخاصة بالنظام الأساسي (@expo/ui/swift-ui، iOS فقط) وJetpack Compose (@expo/ui/jetpack-compose، Android فقط) والأشجار و المعدلات. يُستخدم عند إضافة أو مراجعة أشجار @expo/ui Host/RNHostView، أو إنشاء واجهة مستخدم ذات طابع أصلي حيث تكون مكونات React Native القياسية قصيرة (نماذج الإعدادات المجمعة مع مفاتيح التبديل والأقسام والقوائم والأوراق والمنتقيات وشرائح التمرير)، أو الاختيار بين المكونات العامة والمكونات الخاصة بالنظام الأساسي، أو استبدال مكتبة واجهة مستخدم مجتمع RN بمكافئ @expo/ui الأصلي. ليس للوحدات الأصلية المخصصة، أو التنقل في Expo Router، أو Reanimated، أو جلب البيانات.
