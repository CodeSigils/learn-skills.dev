Identifiez pourquoi les annonces AdMob ne s'affichent dans aucune application Expo/React Native. À utiliser lorsque l'utilisateur signale que les annonces réelles/test ne s'affichent pas, demande pourquoi les annonces de production ont NO_FILL, si les ID de configuration/package/unité AdMob sont corrects, comment un indicateur TEST_ADS et une porte de consentement UMP affectent les annonces, ou comment déboguer les annonces sur un appareil réel via adb logcat. Non spécifique à un projet : fonctionne pour n'importe quelle application utilisant React-native-google-mobile-ads.
