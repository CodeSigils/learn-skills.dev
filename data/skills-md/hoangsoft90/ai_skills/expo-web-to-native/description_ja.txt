フレームワーク（OSS）。 Expo を使用して、既存の Web React アプリをネイティブ iOS/Android アプリに移行します。ユーザーが Web サイトをモバイル アプリに変換する場合、Next.js/Vite/CRA React コードベースを React Native に移植する場合、Web コードをネイティブで段階的に再利用する場合、または Web イディオム (DOM、CSS、React Router、localStorage、ウィンドウ) をネイティブにマッピングする方法を尋ねる場合に使用します。これはエンドツーエンドの移行ガイドです。 DOM コンポーネントのメカニズム自体に「expo-dom」スキルを使用します。
