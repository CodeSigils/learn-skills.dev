Quadro (OSS). Migra un'app Web React esistente a un'app iOS/Android nativa con Expo. Da utilizzare quando l'utente desidera trasformare un sito Web in un'app mobile, trasferire una base di codice React Next.js/Vite/CRA su React Native, riutilizzare il codice Web su nativo in modo incrementale o chiedere come gli idiomi Web (DOM, CSS, React Router, localStorage, finestra) vengono mappati su nativi. Questa è la guida alla migrazione end-to-end; utilizzare l'abilità "expo-dom" per il meccanismo del componente DOM stesso.
