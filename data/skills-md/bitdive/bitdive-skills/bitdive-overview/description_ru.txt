Справочное руководство по работе с BitDive с помощью инструментов MCP. Охватывает доступные инструменты, основной протокол взаимодействия агентов, примечания по времени и рекомендации по управлению тестированием. Используйте этот навык всякий раз, когда вам нужно знать, какой инструмент BitDive вызывать и когда.
