Напишите или улучшите документацию, используя сборник правил DocX. Используйте, когда пользователь запрашивает создание, переписывание, реструктуризацию, доработку или критику документации в качестве результата, включая файлы README, руководства, документацию по API, инструкции по адаптации, устранению неполадок, инструкции по реализации, документы по реализации и PR-описания. Не используйте для поиска, обобщения или сбора контекста документации, доступной только для чтения, если только пользователь не попросит внести изменения в документацию или просмотреть документацию.
