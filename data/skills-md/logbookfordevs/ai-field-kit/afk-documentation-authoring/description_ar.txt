قم بكتابة الوثائق أو تحسينها باستخدام دليل DocX. يُستخدم عندما يطلب المستخدم إنشاء وثائق أو إعادة كتابتها أو إعادة هيكلتها أو صقلها أو نقدها كمخرجات قابلة للتسليم، بما في ذلك READMEs والأدلة ومستندات API والإعداد واستكشاف الأخطاء وإصلاحها وسجلات التشغيل ومستندات التنفيذ وأوصاف العلاقات العامة. لا تستخدم للبحث عن الوثائق للقراءة فقط أو تلخيصها أو تجميع السياق ما لم يطلب المستخدم تغييرات في الوثائق أو مراجعة المستندات.
