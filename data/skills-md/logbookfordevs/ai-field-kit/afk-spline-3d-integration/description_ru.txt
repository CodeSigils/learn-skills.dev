Используйте при добавлении интерактивных 3D-сцен из Spline.design в веб-проекты. Охватывает методы внедрения (React, Next.js, vanilla JS), API @splinetool/ времени выполнения для программного управления (события, переменные, анимация, камера), оптимизации производительности, резервных вариантов для мобильных устройств и общих проблем интеграции, таких как перехват прокрутки, сдвиг макета, резервные варианты графического процессора и удаление водяных знаков.
