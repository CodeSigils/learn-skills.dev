Carte de référence pour choisir les registres d'interface utilisateur, les primitives de composants et les fondations sans tête dans le travail frontal de React/Tailwind. À utiliser lorsqu'une tâche nécessite une primitive d'interface utilisateur mature, un bloc de registre, un composant shadcn/ui, un registre communautaire ou une base de composant sans tête.
