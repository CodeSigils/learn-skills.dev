Playwright テスト自動化の受け入れ基準を変換して検証します。ユーザーが、(1) AC が自動化の準備ができているかどうかレビュー/評価/チェックする、(2) AC をそのまま変換できるかどうかを評価する、(3) Playwright の AC 品質を検証する、(4) AC をテストに変換する、(5) 受け入れ基準からテストを生成する、(6) .md Bullet または .feature Gherkin ファイルを Playwright 仕様に変換する、(7) 要件からテスト自動化を作成することを要求する場合に使用します。 JSON テスト計画の生成と検証を使用して、箇条書き形式のマークダウンと Gherkin 構文の両方を処理します。
