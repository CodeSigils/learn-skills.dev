À utiliser lorsque les utilisateurs fournissent des demandes vagues, sous-spécifiées ou peu claires lorsqu'ils ont besoin d'aide pour définir CE qu'ils veulent réellement - dans N'IMPORTE QUEL domaine (rédaction, analyse, code, documentation, propositions, rapports, présentations, travail créatif). Déclenchez de manière agressive lorsque les utilisateurs expriment des OBJECTIFS VAGUES (« améliorer cela », « améliorer notre X », « déterminer quoi inclure », « je ne sais pas par où commencer », « un peu perdu sur quoi faire », « je ne sais pas ce que cela signifie »), UN SUCCÈS INDÉFINI (« devrait avoir l'air professionnel », « expliquer cela clairement », « le rendre convaincant », « ce qui fonctionne le mieux », manque de contraintes/audience/format), COMMUNICATION PEU CLAIRE (« comment expliquer/communiquer cela », « mon équipe devient confus quand je le décris", "aidez-moi à comprendre quoi demander à propos de X"), EXIGENCES AMBIGUES ("analyser les données" sans dire quoi rechercher, "améliorer la documentation" sans dire comment, "la rendre plus robuste" sans définir la robustesse, toute demande avec plusieurs interprétations valides), ou META-PROMPTING ("optimiser cette invite", "améliorer mon invite", "rendre cela plus clair", "revoir mes instructions", apprendre les cadres d'invite comme CO-STAR/RISEN/RODES, comprendre ce qui rend les invites efficaces). Déclencheur pour les utilisateurs non techniques et TOUTE situation dans laquelle la demande doit être affinée, structurée ou clarifiée avant que l'exécution puisse commencer. En cas de doute quant à savoir si une demande est suffisamment claire, déclenchez.
