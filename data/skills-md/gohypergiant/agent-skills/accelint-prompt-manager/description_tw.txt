當使用者在任何領域（寫作、分析、程式碼、文件、提案、報告、簡報、創意工作）中需要協助定義他們實際想要的內容時，提出模糊、不明確或不明確的請求時使用。當用戶表達模糊的目標（“讓這變得更好”，“改進我們的X”，“弄清楚要包括什麼”，“我不知道從哪裡開始”，“有點迷失該做什麼”，“不確定這意味著什麼”），未定義的成功（“應該看起來專業”， “清楚地解釋這一點”，“使其令人信服”，“無論什麼效果最好”，缺少約束/受眾/格式），溝通時積極觸發不清楚（“我如何解釋/傳達這一點”，“當我描述它時，我的團隊感到困惑”，“幫助我找出關於X 的問題”），模棱兩可的要求（“分析數據”而不說要尋找什麼，“改進文檔”而不說如何，“使其更健壯”而不定義穩健性，任何具有多種有效解釋的請求），或元提示（“優化此提示”，“改進我的提示”， “讓這一點更清楚”，“查看我的提示提示”，了解 CO-STAR/RISEN/DES 等。針對非技術使用者以及請求在開始執行之前需要細化、結構或澄清的任何情況觸發。當懷疑請求是否足夠明確時 - 觸發。
