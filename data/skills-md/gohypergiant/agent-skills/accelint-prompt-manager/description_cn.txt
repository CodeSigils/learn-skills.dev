当用户在任何领域（写作、分析、代码、文档、提案、报告、演示、创意工作）中需要帮助定义他们实际想要的内容时，提出模糊、不明确或不明确的请求时使用。当用户表达模糊的目标（“让这变得更好”，“改进我们的X”，“弄清楚要包括什么”，“我不知道从哪里开始”，“有点迷失该做什么”，“不确定这意味着什么”），未定义的成功（“应该看起来专业”，“清楚地解释这一点”，“使其令人信服”，“无论什么效果最好”，缺少约束/受众/格式），沟通时积极触发不清楚（“我如何解释/传达这一点”，“当我描述它时，我的团队感到困惑”，“帮助我找出关于 X 的问题”），模棱两可的要求（“分析数据”而不说要寻找什么，“改进文档”而不说如何，“使其更健壮”而不定义稳健性，任何具有多种有效解释的请求），或元提示（“优化此提示”，“改进我的提示”， “让这一点更清楚”，“查看我的说明”，了解 CO-STAR/RISEN/RODES 等提示框架，了解如何使提示有效）。针对非技术用户以及请求在开始执行之前需要细化、结构或澄清的任何情况触发。当怀疑请求是否足够明确时 - 触发。
