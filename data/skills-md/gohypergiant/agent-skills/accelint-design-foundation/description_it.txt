Da utilizzare quando si applicano stili a componenti o elementi con i pacchetti @accelint/design-foundation o @accelint/design-toolkit o quando gli utenti dicono "stile questo", "aggiungi stile", "tema questo componente", "aggiungi colori", "aggiungi spaziatura", "moduli CSS", "imposta design Foundation", "@variant" o quando si lavora con file .module.css.
