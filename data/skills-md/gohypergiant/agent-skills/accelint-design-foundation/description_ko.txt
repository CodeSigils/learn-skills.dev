@accelint/design-foundation 또는 @accelint/design-toolkit 패키지를 사용하여 구성 요소나 요소의 스타일을 지정할 때 또는 사용자가 "스타일 지정", "스타일링 추가", "이 구성 요소 테마 지정", "색상 추가", "간격 추가", "CSS 모듈", "디자인 기초 설정", "@variant"라고 말할 때 또는 .module.css 파일로 작업할 때 사용합니다. 의미 체계 토큰, 사용자 정의 간격 배율, 윤곽선 기반 테두리, 변형 시스템 및 CSS 모듈 설정 지침을 포함하여 독자적인 Tailwind 규칙을 제공합니다.
