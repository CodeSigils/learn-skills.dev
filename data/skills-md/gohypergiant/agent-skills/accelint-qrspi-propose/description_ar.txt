استخدم هذه المهارة عندما يريد المستخدم بدء سير عمل تخطيط QRSPI/OpenSpec الرسمي لتذكرة أو خطأ أو طلب ميزة أو تغيير المنتج/CLI/التطبيق المقترح قبل التنفيذ. قم باستدعائها عندما يريد المستخدم حزمة تغيير تعتمد على المواصفات مع الأسئلة أولاً، والبحث الواقعي، وعناصر الاقتراح/التصميم، والمواصفات المتأثرة، وخطة مهمة مقسمة رأسيًا، مع توقف المراجعة/الموافقة الصريحة قبل بدء أي برمجة. هذه هي المهارة المناسبة عندما يريد المستخدم تخطيط التغيير نفسه أو نطاقه أو تقسيمه، خاصة إذا طلب استخدام QRSPI أو إنشاء تغيير OpenSpec أو تشغيل سير عمل التخطيط أو التوقف قبل كتابة التعليمات البرمجية. لا تستخدمه لتنفيذ مواصفات موجودة أو مراجعة أو تحسين العناصر الموجودة بالفعل أو إنشاء مستندات بنية عامة أو أرشفة التغييرات المكتملة أو دعم العصف الذهني الفضفاض دون طلب مخرجات QRSPI/OpenSpec رسمية.
