Implemente cambios OpenSpec planificados por QRSPI con paralelización inteligente. Úselo cuando el usuario quiera aplicar un cambio de QRSPI, implementar tareas con paralelización o diga "aplicar este cambio de QRSPI", "implementar con paralelización", "ejecutar los cortes paralelos". Esta habilidad está diseñada específicamente para cambios creados mediante accelint-qrspi que incluyen secciones "Estrategia de paralelización" en tareas.md. Orquesta la ejecución paralela de subagente para porciones de tareas independientes utilizando flujos de trabajo de OpenSpec CLI. Asegúrese de utilizar esta habilidad cuando el usuario mencione la aplicación de cambios QRSPI, la ejecución de una implementación paralela o el trabajo en cambios con cortes verticales.
