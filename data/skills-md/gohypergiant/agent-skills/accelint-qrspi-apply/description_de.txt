Implementieren Sie QRSPI-geplante OpenSpec-Änderungen mit intelligenter Parallelisierung. Verwenden Sie diese Option, wenn der Benutzer eine QRSPI-Änderung anwenden, Aufgaben mit Parallelisierung implementieren möchte oder sagt: „Diese QRSPI-Änderung anwenden“, „mit Parallelisierung implementieren“ oder „die parallelen Slices ausführen“. Dieser Skill wurde speziell für Änderungen entwickelt, die über accelint-qrspi erstellt wurden und Abschnitte „Parallelisierungsstrategie“ in task.md enthalten. Es orchestriert die parallele Subagentenausführung für unabhängige Aufgabenbereiche mithilfe von OpenSpec CLI-Workflows. Stellen Sie sicher, dass Sie diese Fähigkeit nutzen, wenn der Benutzer die Anwendung von QRSPI-Änderungen, die Ausführung einer parallelen Implementierung oder die Arbeit an Änderungen mit vertikalen Slices erwähnt.
