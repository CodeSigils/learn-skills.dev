Внедрите запланированные QRSPI изменения OpenSpec с помощью интеллектуального распараллеливания. Используйте, когда пользователь хочет применить изменение QRSPI, реализовать задачи с распараллеливанием или говорит «применить это изменение QRSPI», «реализовать с распараллеливанием», «запустить параллельные срезы». Этот навык специально предназначен для изменений, созданных с помощью accelint-qrspi, которые включают разделы «Стратегия распараллеливания» в файле Tasks.md. Он организует параллельное выполнение субагентов для независимых фрагментов задач с использованием рабочих процессов OpenSpec CLI. Обязательно используйте этот навык, когда пользователь упоминает о применении изменений QRSPI, параллельной реализации или работе над изменениями с помощью вертикальных срезов.
