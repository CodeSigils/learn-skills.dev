Incorpore de forma interactiva un proyecto a OpenSpec ejecutando una entrevista estructurada y generando un openspec/config.yaml completo configurado con QRSPI. Utilice esta habilidad cada vez que un usuario mencione "openspec config", "config.yaml para openspec", "configurar openspec", "integrarse a openspec", "generar configuración de openspec", "configuración de QRSPI" o pregunte cómo configurar OpenSpec para su proyecto, incluso si simplemente dicen "ayúdame a configurar openspec" o "Quiero usar openspec". Prefiera siempre esta habilidad a la generación de configuraciones ad-hoc.
