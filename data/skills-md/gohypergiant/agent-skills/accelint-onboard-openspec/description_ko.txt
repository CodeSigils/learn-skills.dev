구조화된 인터뷰를 실행하고 완전한 QRSPI 구성 openspec/config.yaml을 생성하여 OpenSpec에 프로젝트를 대화형으로 온보딩합니다. 사용자가 "openspec config", "openspec용 config.yaml", "openspec 설정", "openspec에 온보드", "openspec config 생성", "QRSPI config"를 언급하거나 프로젝트에 대해 OpenSpec을 구성하는 방법을 물을 때마다 이 기술을 사용하세요. "openspec 설정을 도와주세요" 또는 "openspec을 사용하고 싶어요"라고만 말하는 경우에도 마찬가지입니다. 임시 구성 생성보다 항상 이 기술을 선호합니다.
