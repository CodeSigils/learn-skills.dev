構造化インタビューを実行し、QRSPI で構成された完全な openspec/config.yaml を生成することで、プロジェクトを OpenSpec に対話的にオンボードします。ユーザーが「openspec config」、「openspec の config.yaml」、「openspec のセットアップ」、「openspec へのオンボード」、「openspec config の生成」、「QRSPI config」について言及したり、プロジェクトに OpenSpec を構成する方法を尋ねたりするときは常に、このスキルを使用してください。たとえ単に「openspec のセットアップを手伝ってください」または「openspec を使用したい」と言っただけであってもです。アドホックな構成生成よりも常にこのスキルを優先します。
