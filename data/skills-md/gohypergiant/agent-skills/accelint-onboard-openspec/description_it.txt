Effettua l'onboarding interattivo di un progetto in OpenSpec eseguendo un'intervista strutturata e generando un file openspec/config.yaml completo configurato con QRSPI. Utilizza questa competenza ogni volta che un utente menziona "configurazione openspec", "config.yaml per openspec", "imposta openspec", "onboarding su openspec", "genera configurazione openspec", "configurazione QRSPI" o chiede come configurare OpenSpec per il proprio progetto, anche se dice semplicemente "aiutami a impostare openspec" o "voglio utilizzare openspec". Preferisci sempre questa abilità rispetto alla generazione di configurazioni ad hoc.
