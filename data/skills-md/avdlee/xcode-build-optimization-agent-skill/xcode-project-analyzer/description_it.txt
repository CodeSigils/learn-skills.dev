Controlla la configurazione del progetto Xcode, le impostazioni di build, il comportamento dello schema e le fasi dello script per trovare miglioramenti in fase di build con cancelli di approvazione espliciti. Da utilizzare quando uno sviluppatore desidera analisi della build a livello di progetto, build incrementali lente, indicazioni sulle dipendenze di destinazione, revisione delle impostazioni di build, esecuzione dell'analisi della fase di script, miglioramenti della parallelizzazione o mappatura dei moduli e configurazione DEFINES_MODULE.
