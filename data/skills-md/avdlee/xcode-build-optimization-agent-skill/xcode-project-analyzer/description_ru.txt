Аудит конфигурации проекта Xcode, параметров сборки, поведения схемы и этапов сценария, чтобы найти улучшения во время сборки с явными воротами утверждения. Используйте, когда разработчику нужен анализ сборки на уровне проекта, медленные инкрементные сборки, рекомендации по целевым зависимостям, проверка параметров сборки, анализ фазы запуска сценария, улучшения распараллеливания или карта модулей и конфигурация DEFINES_MODULE.
