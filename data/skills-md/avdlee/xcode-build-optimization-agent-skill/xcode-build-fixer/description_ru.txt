Примените одобренные изменения оптимизации сборки Xcode, следуя передовым практикам, а затем повторите тестирование для проверки улучшения. Используйте, когда разработчик имеет утвержденный план оптимизации из xcode-build-orchestrator, хочет применить определенные исправления сборки, нуждается в помощи во внедрении изменений параметров сборки, защиты фазы сценария, исправлений компиляции на уровне исходного кода или реструктуризации SPM, рекомендованной специалистом по анализу.
