Aplique los cambios aprobados de optimización de compilación de Xcode siguiendo las mejores prácticas y luego vuelva a comparar para verificar la mejora. Úselo cuando un desarrollador tiene un plan de optimización aprobado por xcode-build-orchestrator, desea aplicar correcciones de compilación específicas, necesita ayuda para implementar cambios en la configuración de compilación, protecciones de fase de script, correcciones de compilación a nivel de fuente o reestructuración de SPM recomendada por una habilidad de análisis.
