Analizza le dipendenze di Swift Package Manager, i plug-in dei pacchetti, le varianti dei moduli e il sovraccarico di build orientato alla CI che rallentano le build di Xcode. Da utilizzare quando uno sviluppatore sospetta che pacchetti, plug-in o forme di grafici delle dipendenze stiano compromettendo le prestazioni di build pulite o incrementali, menziona la lentezza dell'SPM, i tempi di risoluzione dei pacchetti, il sovraccarico dei plug-in di build, build di moduli duplicati a causa di deviazioni della configurazione, dipendenze circolari tra moduli, moduli sovradimensionati che necessitano di suddivisione o best practice di modularizzazione.
