Analysieren Sie Swift Package Manager-Abhängigkeiten, Paket-Plugins, Modulvarianten und CI-orientierten Build-Overhead, der die Xcode-Builds verlangsamt. Verwenden Sie diese Option, wenn ein Entwickler vermutet, dass Pakete, Plugins oder die Form des Abhängigkeitsdiagramms die Leistung sauberer oder inkrementeller Builds beeinträchtigen, SPM-Langsamkeit, Paketauflösungszeit, Build-Plugin-Overhead, doppelte Modulbuilds aufgrund von Konfigurationsabweichungen, zirkuläre Abhängigkeiten zwischen Modulen, übergroße Module, die eine Aufteilung erfordern, oder Best Practices für die Modularisierung erwähnt.
