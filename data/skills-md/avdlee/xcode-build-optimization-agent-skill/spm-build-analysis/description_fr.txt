Analysez les dépendances de Swift Package Manager, les plugins de package, les variantes de module et la surcharge de build orientée CI qui ralentissent les builds Xcode. À utiliser lorsqu'un développeur soupçonne que les packages, les plugins ou la forme du graphique de dépendance nuisent aux performances de construction propre ou incrémentielle, mentionne la lenteur du SPM, le temps de résolution des packages, la surcharge du plugin de construction, les constructions de modules en double à partir d'une dérive de configuration, les dépendances circulaires entre les modules, les modules surdimensionnés nécessitant un fractionnement ou les meilleures pratiques de modularisation.
