Confronta build Xcode pulite e incrementali con input ripetibili, riepiloghi dei tempi e artefatti `.build-benchmark/` con timestamp. Da utilizzare quando uno sviluppatore vuole una linea di base, vuole confrontare le modifiche prima e dopo, chiede di misurare le prestazioni della build, menziona i tempi di build, la durata della build, quanto tempo impiegano le build o vuole sapere se le build sono diventate più veloci o più lente.
