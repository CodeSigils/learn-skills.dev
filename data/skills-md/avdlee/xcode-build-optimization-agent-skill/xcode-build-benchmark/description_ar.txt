إنشاءات Xcode النظيفة والتزايدية باستخدام مدخلات قابلة للتكرار، وملخصات توقيت، وعناصر `.build-benchmark/` ذات طابع زمني. يُستخدم عندما يريد المطور خطًا أساسيًا، أو يريد المقارنة قبل التغييرات وبعدها، أو يطلب قياس أداء البناء، أو يذكر أوقات البناء، أو مدة البناء، أو المدة التي تستغرقها عمليات البناء، أو يريد معرفة ما إذا كانت الإصدارات أسرع أم أبطأ.
