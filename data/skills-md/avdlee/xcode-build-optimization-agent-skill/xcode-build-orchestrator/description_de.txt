Orchestrieren Sie die Xcode-Build-Optimierung, indem Sie zuerst ein Benchmarking durchführen, die speziellen Analysefähigkeiten ausführen, Ergebnisse priorisieren, eine explizite Genehmigung anfordern, genehmigte Fixes an xcode-build-fixer delegieren und nach Änderungen ein erneutes Benchmarking durchführen. Verwenden Sie diese Option, wenn ein Entwickler einen End-to-End-Build-Optimierungsworkflow wünscht, Xcode-Builds beschleunigen möchte, eine vollständige Build-Prüfung wünscht oder einen „Empfehlen-zuerst“-Optimierungsdurchlauf benötigt, der Kompilierung, Projekteinstellungen und Pakete abdeckt.
