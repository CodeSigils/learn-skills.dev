Orchestra l'ottimizzazione della build di Xcode eseguendo innanzitutto il benchmarking, eseguendo le competenze di analisi specialistiche, dando priorità ai risultati, richiedendo l'approvazione esplicita, delegando le correzioni approvate a xcode-build-fixer ed eseguendo nuovamente il benchmarking dopo le modifiche. Da utilizzare quando uno sviluppatore desidera un flusso di lavoro di ottimizzazione della build end-to-end, chiede di velocizzare le build Xcode, desidera un controllo completo della build o ha bisogno di un passaggio di ottimizzazione consigliato per la compilazione, le impostazioni del progetto e i pacchetti.
