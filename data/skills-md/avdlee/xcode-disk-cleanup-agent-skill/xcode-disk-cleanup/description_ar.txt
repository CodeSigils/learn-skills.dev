قم بمراجعة مساحة تخزين المطورين المتعلقة بـ Xcode وتنظيفها بأمان على نظام التشغيل macOS. استخدمه عندما يذكر أحد المطورين انخفاض مساحة القرص، أو تخزين Xcode، أو DerivedData، أو أجهزة المحاكاة أو أوقات التشغيل، أو منصات بيتا التي لا معنى لها في إعدادات Xcode، أو DeviceSupport، أو الأرشيفات، أو dSYMs، أو ذاكرات التخزين المؤقت لـ CocoaPods، أو ذاكرات التخزين المؤقت لـ dyld، أو مجلدات المشروع.build، أو Xcode DMGs/XIPs التي تم تنزيلها، أو مثبتات Xcode المكررة، أو تطبيقات Xcode القديمة. استخدم أيضًا هذه المهارة بشكل استباقي عندما تصل مساحة التخزين المنخفضة أثناء أعمال أخرى، مثل فشل الإنشاء أو التنزيل أو التثبيت بسبب خطأ نفاد مساحة القرص. قم دائمًا بالقياس أولاً، والإبلاغ عن GiB القابل للاسترداد مع الأدلة، والحصول على موافقة مفصلة صريحة قبل أي طفرة.
