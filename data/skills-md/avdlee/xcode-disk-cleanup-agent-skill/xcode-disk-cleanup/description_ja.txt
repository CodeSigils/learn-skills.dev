macOS 上の Xcode 関連の開発者ストレージを監査し、安全にクリーニングします。開発者がディスク容量不足、Xcode ストレージ、DerivedData、シミュレーター デバイスまたはランタイム、Xcode 設定の古いベータ プラットフォーム、DeviceSupport、アーカイブ、dSYM、CocoaPods キャッシュ、シミュレーター dyld キャッシュ、プロジェクト .build フォルダー、ダウンロードされた Xcode DMG/XIP、重複した Xcode インストーラー、または古い Xcode アプリケーションについて言及する場合は常に使用します。また、ディスク容量不足エラーでビルド、ダウンロード、インストールが失敗するなど、他の作業中にストレージが不足した場合にも、このスキルを積極的に使用してください。常に最初に測定し、証拠とともに回復可能な GiB を報告し、突然変異の前に明示的な項目別の承認を取得します。
