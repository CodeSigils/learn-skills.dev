Prüfen und bereinigen Sie den Xcode-bezogenen Entwicklerspeicher unter macOS sicher. Verwenden Sie diese Option immer dann, wenn ein Entwickler wenig Speicherplatz, Xcode-Speicher, abgeleitete Daten, Simulatorgeräte oder -laufzeiten, veraltete Betaplattformen in den Xcode-Einstellungen, DeviceSupport, Archive, dSYMs, CocoaPods-Caches, Simulator-Dyld-Caches, Projekt-.build-Ordner, heruntergeladene Nutzen Sie diese Fähigkeit auch proaktiv, wenn Sie bei anderen Arbeiten auf wenig Speicherplatz stoßen, z. B. wenn ein Build, ein Download oder eine Installation aufgrund eines Fehlers wegen „Nicht genügend Speicherplatz“ fehlschlägt. Messen Sie immer zuerst, melden Sie den wiederherstellbaren GiB mit Belegen und holen Sie vor jeder Mutation eine ausdrückliche, detaillierte Genehmigung ein.
