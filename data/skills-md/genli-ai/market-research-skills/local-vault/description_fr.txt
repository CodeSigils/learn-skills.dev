Créez et interrogez une base de connaissances Markdown locale (« coffre-fort »). DEUX fonctions — (1) CONVERTIR les fichiers bruts (PDF, Word/docx, PowerPoint/pptx, Excel/xlsx, csv/tsv, images, html, md/txt, json/yaml/code, audio/video) en Markdown propre avec un frontmatter facile à récupérer ; local-first (pandoc / python-pptx / openpyxl / pymupdf4llm / murmure), avec cloud OCR (MinerU) uniquement comme solution de secours. (2) RÉPONDRE aux questions sur le coffre-fort résultant avec une discipline de récupération : couverture d'auto-surveillance, signalement du contenu manquant/avec perte et proposition de cartes de contenu (MOC). Déclencheurs : "créer/synchroniser ma base de connaissances locale", "convertir ces fichiers en markdown pour l'IA", "整理我的资料库", "把文件转成 md 给 AI 读", "本地知识库", "读我的本地 vault 回答", "这个主题我的资料里怎么说". Pas pour : des recherches ponctuelles sur le Web ou des fichiers qui se trouvent déjà dans un seul document que vous pouvez lire directement.
