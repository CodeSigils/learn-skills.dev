Habilidad inteligente de generación de gráficos y análisis de datos. Lee archivos de datos proporcionados por el usuario (CSV/Excel/JSON), analiza las características de los datos con asistencia de LLM, recomienda automáticamente y genera visualizaciones interactivas de ECharts. Úselo cuando el usuario solicite analizar datos, generar gráficos, crear visualizaciones o trabajar con archivos de datos tabulares.
