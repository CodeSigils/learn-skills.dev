Capacità di generazione intelligente di grafici e analisi dei dati. Legge i file di dati forniti dall'utente (CSV/Excel/JSON), analizza le caratteristiche dei dati con l'assistenza LLM, consiglia automaticamente e genera visualizzazioni EChart interattive. Da utilizzare quando l'utente richiede di analizzare dati, generare grafici, creare visualizzazioni o lavorare con file di dati tabulari.
