À utiliser lors de l'écriture de plugins ou de scripts QGIS 4 et nécessiter des signatures, des paramètres, des énumérations, des types de retour ou un statut de dépréciation exacts de l'API PyQGIS pour une version spécifique de QGIS (résolu en sondant les variables d'environnement existantes de la machine / QGIS installé, par défaut 4.2) ; lorsque le livre de recettes QGIS-Documentation (4.4-dev) peut s'écarter de la version cible ; ou lors de la vérification si une API a changé entre QGIS 3 et QGIS 4. Ne PAS utiliser pour les questions de comportement du manuel de l'utilisateur (utilisez plutôt le manuel de l'utilisateur docs.qgis.org).
