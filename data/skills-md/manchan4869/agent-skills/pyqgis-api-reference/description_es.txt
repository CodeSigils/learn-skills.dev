Úselo cuando escriba complementos o scripts de QGIS 4 y necesite firmas, parámetros, enumeraciones, tipos de retorno o estado de desuso exactos de la API de PyQGIS para una versión específica de QGIS (se resuelve investigando las variables de entorno existentes de la máquina/QGIS instalado, valor predeterminado 4.2); cuando el libro de recetas de QGIS-Documentation (4.4-dev) puede desviarse de la versión de destino; o al verificar si una API cambió entre QGIS 3 y QGIS 4. NO lo use para preguntas de comportamiento del manual de usuario (use el manual de usuario de docs.qgis.org en su lugar).
