Используйте при написании плагинов или скриптов QGIS 4 и вам нужны точные сигнатуры API PyQGIS, параметры, перечисления, типы возвращаемых значений или статус устаревания для конкретной версии QGIS (решается путем проверки существующих переменных окружения компьютера/установленной QGIS, по умолчанию 4.2); когда кулинарная книга документации QGIS (4.4-dev) может отличаться от целевой версии; или при проверке того, изменился ли API между QGIS 3 и QGIS 4. НЕ используйте для вопросов о поведении в руководстве пользователя (вместо этого используйте руководство пользователя docs.qgis.org).
