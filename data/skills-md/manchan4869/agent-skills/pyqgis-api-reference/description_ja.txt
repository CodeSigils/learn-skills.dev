QGIS 4 プラグインまたはスクリプトを作成し、正確な PyQGIS API 署名、パラメーター、列挙型、戻り値の型、または特定の QGIS バージョンの非推奨ステータスが必要な場合に使用します (マシンの既存の環境変数 / インストールされている QGIS、デフォルト 4.2 を調査することで解決されます)。 QGIS-Documentation クックブック (4.4-dev) がターゲット バージョンから逸脱する可能性がある場合。または、QGIS 3 と QGIS 4 の間で API が変更されたかどうかを確認する場合。ユーザーマニュアルの動作に関する質問には使用しないでください (代わりに docs.qgis.org ユーザーマニュアルを使用してください)。
