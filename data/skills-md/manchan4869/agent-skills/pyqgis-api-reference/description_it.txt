Utilizzare quando si scrivono plugin o script QGIS 4 e sono necessari firme API PyQGIS esatte, parametri, enumerazioni, tipi restituiti o stato di deprecazione per una versione specifica di QGIS (risolto sondando le variabili env esistenti della macchina/QGIS installato, impostazione predefinita 4.2); quando il ricettario della documentazione QGIS (4.4-dev) potrebbe discostarsi dalla versione di destinazione; o quando si controlla se un'API è cambiata tra QGIS 3 e QGIS 4. NON utilizzare per domande sul comportamento del manuale utente (utilizzare invece il manuale utente docs.qgis.org).
