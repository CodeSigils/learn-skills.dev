Web scraping y extracción de datos mediante Scrapling. Utilice esta habilidad siempre que el usuario quiera rastrear un sitio web, rastrear páginas, extraer datos de URL, buscar productos/precios en línea, comparar precios entre sitios o extraer datos estructurados de páginas web. Úselo también cuando el usuario mencione Coupang, Amazon, búsqueda de compras, comparación de precios o cualquier tarea que implique buscar y analizar contenido web, incluso si no dice explícitamente "scrape".
