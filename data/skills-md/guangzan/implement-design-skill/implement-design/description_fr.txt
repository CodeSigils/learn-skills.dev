Traduisez des ébauches de conception, des ébauches annotées ou des spécifications visuelles en code d’application déployable avec une reproduction visuelle haute fidélité. Utilisez-le lorsque les utilisateurs ont besoin de « mettre en œuvre des conceptions », de « développer selon des brouillons », de « restaurer l'interface utilisateur/des composants/des pages », de fournir des liens de conception/des captures d'écran/des documents d'annotation ou de demander la construction d'une interface conformément aux spécifications de conception. Si Tencent Design Ardot MCP est déjà connecté, extrayez le contexte et les captures d'écran comme décrit dans « Annexe : Ardot MCP » ci-dessous ; si l'objectif de l'utilisateur est uniquement de modifier les brouillons dans les outils de conception plutôt que de fournir le code du référentiel, consultez la description des compétences pour connaître les limites.
