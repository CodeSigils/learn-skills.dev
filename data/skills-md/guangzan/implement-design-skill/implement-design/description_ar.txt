قم بترجمة مسودات التصميم أو المسودات المشروحة أو المواصفات المرئية إلى كود تطبيق قابل للنشر مع إعادة إنتاج مرئية عالية الدقة. استخدم هذا عندما يحتاج المستخدمون إلى "تنفيذ التصميمات"، أو "التطوير وفقًا للمسودات"، أو "استعادة واجهة المستخدم/المكونات/الصفحات"، أو توفير روابط التصميم/لقطات الشاشة/مستندات التعليقات التوضيحية، أو طلب إنشاء الواجهة وفقًا لمواصفات التصميم. إذا كان Tencent Design Ardot MCP متصلاً بالفعل، فاسحب السياق ولقطات الشاشة كما هو موضح في "الملحق: Ardot MCP" أدناه؛ إذا كان هدف المستخدم هو تعديل المسودات داخل أدوات التصميم فقط بدلاً من تقديم رمز المستودع، فراجع وصف المهارة للحدود.
