Erstellt strukturierte RFC-Dokumente (Request for Comments), um wesentliche Änderungen vorzuschlagen und darüber zu entscheiden. Verwenden Sie es, wenn Sie aufgefordert werden, einen RFC zu erstellen oder zu schreiben, einen Vorschlag zu entwerfen, Stakeholder abzustimmen oder vor einer Entscheidung eine Änderung vorzuschlagen.
