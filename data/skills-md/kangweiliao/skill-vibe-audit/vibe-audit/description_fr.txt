Effectue un audit statique complet et indépendant de la plate-forme d'une base de code. Renvoie un rapport JSON structuré identifiant les incohérences architecturales, les failles de sécurité, la dette technique générée par l'IA et les violations des principes de code propre. Fournit un chemin de migration ciblé pour la refactorisation. Se déclenche lorsque l'utilisateur demande d'auditer, de réviser ou d'évaluer une base de code pour en vérifier la qualité, la cohérence, l'architecture ou la sécurité – même des expressions informelles telles que « vérifier mon code », « réviser ce dépôt », « trouver des problèmes dans mon projet » ou « qu'est-ce qui ne va pas avec cette base de code ». Déclenche également des recommandations d'architecture, la détection d'odeurs de code, des contrôles de santé des dépendances ou des examens d'hygiène de sécurité dans un projet. Ne PAS utiliser pour la révision de code d'un seul fichier, le profilage d'exécution ou l'analyse comparative des performances.
