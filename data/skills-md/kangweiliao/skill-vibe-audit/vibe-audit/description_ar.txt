إجراء تدقيق ثابت شامل ومستقل عن النظام الأساسي لقاعدة التعليمات البرمجية. إرجاع تقرير JSON منظم يحدد التناقضات المعمارية والعيوب الأمنية والديون الفنية الناتجة عن الذكاء الاصطناعي وانتهاكات مبادئ التعليمات البرمجية النظيفة. يوفر مسار ترحيل مستهدف لإعادة البناء. يتم تشغيله عندما يطلب المستخدم تدقيق قاعدة التعليمات البرمجية أو مراجعتها أو تقييمها من حيث الجودة أو الاتساق أو البنية أو الأمان - حتى العبارات غير الرسمية مثل "التحقق من التعليمات البرمجية الخاصة بي" أو "مراجعة هذا الريبو" أو "العثور على مشكلات في مشروعي" أو "ما الخطأ في قاعدة التعليمات البرمجية هذه". مشغلات أيضًا لتوصيات البنية، أو اكتشاف رائحة التعليمات البرمجية، أو فحوصات صحة التبعية، أو مراجعات النظافة الأمنية عبر المشروع. لا تستخدم لمراجعة التعليمات البرمجية ذات الملف الواحد، أو ملفات تعريف وقت التشغيل، أو قياس الأداء.
