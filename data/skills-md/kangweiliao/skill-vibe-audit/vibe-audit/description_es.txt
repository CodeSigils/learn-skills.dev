Realiza una auditoría estática integral e independiente de la plataforma de una base de código. Devuelve un informe JSON estructurado que identifica inconsistencias arquitectónicas, fallas de seguridad, deuda técnica generada por IA y violaciones de los principios del código limpio. Proporciona una ruta de migración específica para la refactorización. Se activa cuando el usuario solicita auditar, revisar o evaluar una base de código para determinar su calidad, coherencia, arquitectura o seguridad, incluso frases casuales como "verificar mi código", "revisar este repositorio", "encontrar problemas en mi proyecto" o "qué hay de malo en esta base de código". También activadores de recomendaciones de arquitectura, detección de olores de código, comprobaciones de estado de dependencias o revisiones de higiene de seguridad en todo un proyecto. NO lo utilice para revisiones de código de un solo archivo, perfiles de tiempo de ejecución o evaluaciones comparativas de rendimiento.
