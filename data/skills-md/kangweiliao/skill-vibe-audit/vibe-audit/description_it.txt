Esegue un controllo statico completo e indipendente dalla piattaforma di una codebase. Restituisce un report JSON strutturato che identifica incoerenze architetturali, difetti di sicurezza, debito tecnico generato dall'intelligenza artificiale e violazioni dei principi del codice pulito. Fornisce un percorso di migrazione mirato per il refactoring. Si attiva quando l'utente chiede di controllare, rivedere o valutare una base di codice per qualità, coerenza, architettura o sicurezza, anche frasi casuali come "controlla il mio codice", "rivedi questo repository", "trova problemi nel mio progetto" o "cosa c'è che non va in questa base di codice". Attiva anche suggerimenti sull'architettura, rilevamento dell'odore di codice, controlli sullo stato delle dipendenze o revisioni dell'igiene della sicurezza in un progetto. NON utilizzare per revisioni del codice di file singoli, profilazione di runtime o benchmarking delle prestazioni.
