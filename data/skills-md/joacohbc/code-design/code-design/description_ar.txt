توجيهات تصميم التعليمات البرمجية التي يتم تطبيقها افتراضيًا عند كتابة التعليمات البرمجية أو مراجعتها أو إعادة هيكلتها - تغطي تعليمات برمجية ذاتية التوثيق (بدون تعليقات)، والتسمية، وتدفق التحكم المسطح (شروط الحراسة / مستويين من التداخل كحد أقصى)، والتكوين على الميراث، وحقن التبعية، وتجنب التحسين المبكر، وتجنب الإفراط في التجريد، والواقعية بشأن النماذج. يُستخدم عندما يطلب المستخدم كتابة التعليمات البرمجية أو مراجعتها أو تنظيفها أو إعادة تصميمها، أو للتحقق من التغيير وفقًا لإرشادات التصميم/النمط.
