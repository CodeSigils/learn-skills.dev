Directivas de diseño de código que se aplicarán de forma predeterminada al escribir, revisar o refactorizar código: cubren código autodocumentado (sin comentarios), denominación, flujo de control plano (cláusulas de protección/máximo 2 niveles de anidamiento), composición sobre herencia, inyección de dependencia, evitar optimización prematura, evitar abstracción excesiva y pragmatismo sobre paradigmas. Úselo cuando el usuario solicite escribir, revisar, limpiar o refactorizar el código, o para verificar un cambio con respecto a las pautas de diseño/estilo.
