Code-Design-Anweisungen, die standardmäßig angewendet werden, wenn Code geschrieben, überprüft oder umgestaltet wird – umfassen selbstdokumentierenden Code (keine Kommentare), Benennung, flachen Kontrollfluss (Schutzklauseln / maximal 2 Verschachtelungsebenen), Komposition über Vererbung, Abhängigkeitsinjektion, Vermeidung vorzeitiger Optimierung, Vermeidung von Überabstraktion und Pragmatismus gegenüber Paradigmen. Verwenden Sie diese Option, wenn der Benutzer Code schreiben, überprüfen, bereinigen oder umgestalten möchte oder eine Änderung anhand von Design-/Stilrichtlinien überprüfen möchte.
