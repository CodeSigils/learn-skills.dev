Directives de conception de code à appliquer par défaut lors de l'écriture, de la révision ou de la refactorisation du code - couvrent le code auto-documenté (pas de commentaires), la dénomination, le flux de contrôle plat (clauses de garde / 2 niveaux maximum d'imbrication), la composition sur l'héritage, l'injection de dépendances, éviter l'optimisation prématurée, éviter la sur-abstraction et le pragmatisme sur les paradigmes. À utiliser lorsque l'utilisateur demande à écrire, réviser, nettoyer ou refactoriser le code, ou à vérifier une modification par rapport aux directives de conception/style.
