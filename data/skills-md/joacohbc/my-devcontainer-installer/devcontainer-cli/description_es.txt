Maneje devcontainer-cli desde el host para brindarle a un proyecto un entorno de desarrollo Docker desechable. Úselo cuando se le solicite crear, iniciar, detener, reconstruir o destruir un contenedor de desarrollo, para ejecutar compilaciones/pruebas/comandos dentro de uno en lugar de en esta máquina, para acceder a un servicio que se ejecuta en uno (puertos publicados, reenvío de puertos, SSH) o para inspeccionar lo que se ha instalado en un contenedor. Úselo también antes de instalar una cadena de herramientas o una base de datos en el host, cuando un contenedor es el mejor lugar para ello.
