Generador de interfaz de usuario de comercio electrónico de alimentos premium inspirado en el sistema de diseño "Mesa". Utilice esta habilidad siempre que el usuario solicite crear cualquier interfaz de entrega de alimentos, restaurante o comercio de alimentos, incluidas páginas de destino, cuadrículas de productos, tarjetas de alimentos, carritos, flujos de pago, paneles, barras de categorías, paletas de búsqueda, barras de navegación, pantallas de perfil, modos de inicio de sesión/registro o cualquier otra pantalla típica de una startup de tecnología alimentaria. También activa solicitudes como "crear una aplicación de comida", "diseñar la interfaz de usuario de un restaurante", "crear una pantalla de aplicación de entrega a domicilio", "crear una interfaz de pedido de comida" o "crear algo como Uber Eats/DoorDash". Esta habilidad garantiza que todos los resultados sigan el lenguaje de diseño de Mesa: minimalismo inspirado en Apple, marca naranja cálida, barra de navegación con morfismo de vidrio, fuente de visualización Inter Tight y React/JSX listo para producción con microinteracciones fluidas, totalmente responsivo desde dispositivos móviles de 375 px hasta escritorios de 1280 px.
