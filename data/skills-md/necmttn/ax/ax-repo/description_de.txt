Starten Sie das Axe-Repo, reichen Sie einen Problem-/Fehlerbericht ein oder forken und öffnen Sie eine PR gegen github.com/Necmttn/ax im Namen des Benutzers, indem Sie an die „gh“-CLI senden. Wird ausgelöst, wenn der Benutzer „Star Axe“, „Star the Repo“, „Ich möchte Axe unterstützen“, „Dies als Axe-Fehler melden“, „Ein Axe-Problem melden“, „Ein Problem auf Axe öffnen“, „Das sieht aus wie ein Axe-Bug“, „Ich möchte zu Axe beitragen“, „Das in Axe beheben“, „Eine PR gegen Axe öffnen“ sagt oder nach einem nicht behandelten Axe-Fehler, wenn der Benutzer ihn melden möchte. Wirkt nur auf eine explizite Benutzeranforderung hin – die proaktive Sternaufforderung wird deterministisch von der CLI („ax star“) gehandhabt, nicht von diesem Skill. Bestätigt vor jeder kontoverändernden Aktion (wird niemals ohne explizites „Ja“ markiert); greift auf eine einfache GitHub-URL zurück, wenn „gh“ fehlt oder nicht authentifiziert ist. Führen Sie KEINE automatische Auslösung bei nicht verwandten GitHub-Arbeiten oder anderen Repos durch.
