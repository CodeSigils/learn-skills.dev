`gh` CLI にシェルアウトすることで、ax リポジトリにスターを付けたり、問題/バグ レポートを提出したり、ユーザーに代わって github.com/Necmttn/ax に対して fork-and-open-a-PR を実行したりできます。ユーザーが「ax にスターを付ける」、「リポジトリにスターを付ける」、「ax をサポートしたい」、「ax のバグとして報告する」、「ax の問題を報告する」、「ax で問題を開く」、「これは ax のバグのようです」、「ax に貢献したい」、「ax でこれを修正する」、「ax に対して PR を開く」と言ったとき、または未処理の ax エラーの後にユーザーが報告したいときにトリガーされます。明示的なユーザー要求にのみ動作します。プロアクティブなスター プロンプトは、このスキルではなく CLI (`ax star`) によって決定的に処理されます。アカウントを変更するアクションの前に確認します (明示的な「はい」なしでスターを付けることはありません)。 「gh」が見つからないか認証されていない場合は、プレーンな GitHub URL に戻ります。無関係な GitHub 作業や他のリポジトリでは自動トリガーしないでください。
