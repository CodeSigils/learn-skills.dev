通过使用“gh” CLI，代表用户对 axe 存储库加注星标，提交问题/错误报告，或针对 github.com/Necmttn/ax 进行 fork-and-open-a-PR。当用户说“star axe”、“star the repo”、“我想支持 axe”、“将此作为 axe bug 报告”、“提交 axe 问题”、“在 axe 上打开一个问题”、“这看起来像 axe bug”、“我想为 axe 做出贡献”、“在 axe 中修复此问题”、“针对 axe 打开 PR”时触发，或者在用户想要报告未处理的 axe 错误后触发。仅对明确的用户请求起作用 - 主动星号提示由 CLI（“ax star”）确定性地处理，而不是由此技能处理。在任何帐户变更操作之前进行确认（如果没有明确的“是”，则不会加星标）；当“gh”丢失或未经身份验证时，回退到普通的 GitHub URL。不要在不相关的 GitHub 工作或其他存储库上自动触发。
