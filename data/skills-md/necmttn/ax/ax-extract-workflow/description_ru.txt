Реконструируйте рабочий процесс, лежащий в основе прошлого артефакта - «что заставило X работать» / «извлечь рабочий процесс из <date|sha>» / «как мы выпустили Y». Использует топор, чтобы найти соответствующие занятия и описать упорядоченные дуги навыков, которые дали результат. Триггеры по принципу «что заставило X работать», «как мы создали Y», «извлечь рабочий процесс из <дата>», «извлечь рабочий процесс из <sha>», «каков был рабочий процесс вокруг <темы>», «покажи мне, как я реализовал <функцию>», «реконструировать рецепт для <артефакта>». НЕ активируйте стандартное «показать недавнюю активность» — этот навык предназначен для реконструкции рабочего процесса, стоящего за конкретным артефактом.
