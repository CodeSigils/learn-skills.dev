حلقة التجربة الموجهة بأثر رجعي على الرسم البياني لتجربة وكيل الفأس. يرشد المستخدم عبر مقترحاته المفتوحة (القبول مع السقالة أو الرفض)، والأحكام المعلقة (تأكيد الحكم المقترح أو التجاوز)، وإشارة فعالية خطاف التثبيت الأخيرة. يتم تشغيله عندما يقول المستخدم "دعونا نجري فأسًا رجعيًا"، أو "بأثر رجعي للفأس"، أو "مراجعة مقترحات الفأس الخاصة بي"، أو "مقترحات الفرز"، أو "حالة حلقة التجربة"، أو "قفل الأحكام المعلقة"، أو "مراجعة فعالية الخطاف"، أو "مراجعة التدخل"، أو "جلسة التحسين الذاتي"، أو يستدعي /ax:retro. القراءة/الكتابة عبر واجهة سطر الأوامر المحلية "تحسين الفأس" و"خطافات الفأس". لا تقم بالتشغيل التلقائي للعمل غير ذي الصلة.
