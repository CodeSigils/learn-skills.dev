Definition-of-Done-Checkliste zum Senden eines neuen Schreibvorgangs, Signals, einer neuen Tabelle, einer neuen Kante oder einer neuen Abfrage an das Achsendiagramm. Verwenden Sie diese Option, wenn Sie eine SurrealDB-Tabelle/-Kante/ein SurrealDB-Feld, eine Aufnahme-Ableitungsphase, eine neue Analyseabfrage oder eine neue Axe-Funktion hinzufügen – bevor Sie die PR öffnen. Stellt sicher, dass jeder Schreibvorgang einen On-Demand-Lesevorgang UND einen proaktiven (Agenten-orientierten) Lesevorgang UND Dokumente/Verteilung erhält, nicht nur den Schreibvorgang. Wird ausgelöst bei „Versenden“, „Neues Signal“, „Neuer Tisch/Kante“, „Neue Linse/Abfrage“, „Verkabeln“, „Ist das erledigt“ oder beim Beenden eines Axt-Feature-Zweigs.
