Utilizza questa competenza quando un agente AI deve gestire, verificare, creare report, creare, mettere in pausa, aggiornare o risolvere i problemi relativi agli annunci Meta/Facebook/Instagram tramite la CLI annunci ufficiale di Meta ("meta annunci ..."). È progettato per qualsiasi agente compatibile con shell, non solo per OpenClaw. Si concentra sulla pianificazione sicura dei comandi, sull'output JSON, sui gate di conferma, sul comportamento di lettura prima della scrittura, sui lanci in pausa per impostazione predefinita, sui flussi di lavoro di reporting, sui set di dati/pixel, sulle operazioni di catalogo/prodotto e sulla gestione degli errori.
