Используйте этот навык, когда агенту ИИ необходимо управлять, проверять, составлять отчеты, создавать, приостанавливать, обновлять или устранять неполадки мета-рекламы/рекламы Facebook/Instagram через официальный интерфейс командной строки Meta Ads («мета-объявления...»). Он предназначен для любого агента с поддержкой оболочки, а не только для OpenClaw. Он фокусируется на безопасном планировании команд, выводе JSON, шлюзах подтверждения, поведении «чтение перед записью», запусках с паузой по умолчанию, рабочих процессах отчетности, наборах данных/пикселях, операциях с каталогом/продуктом и обработке сбоев.
