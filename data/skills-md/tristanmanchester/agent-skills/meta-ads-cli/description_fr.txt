Utilisez cette compétence lorsqu'un agent d'IA doit gérer, auditer, créer des rapports, créer, suspendre, mettre à jour ou dépanner les publicités Meta/Facebook/Instagram via la CLI publicitaire officielle de Meta (« méta-publicités... »). Il est conçu pour tout agent compatible Shell, pas seulement pour OpenClaw. Il se concentre sur la planification sécurisée des commandes, la sortie JSON, les portes de confirmation, le comportement de lecture avant écriture, les lancements suspendus par défaut, les flux de travail de reporting, les ensembles de données/pixels, les opérations de catalogue/produit et la gestion des échecs.
