Utilice esta habilidad para los flujos de trabajo de Fabric.so CLI con el comando de terminal `fabric`: diagnosticar/instalar/iniciar sesión, buscar o explorar una biblioteca de Fabric, guardar notas/enlaces/archivos, crear carpetas, preguntar al asistente de Fabric AI, administrar tareas/espacios de trabajo, generar finalización de shell, verificar el uso de suscripciones, producir resultados JSON y usar Fabric como memoria de agente persistente. No lo utilice para Microsoft Fabric/Azure/Power BI `fab`, el marco Fabric de Daniel Miessler, Python Fabric SSH, Fabric.js ni tejidos textiles/de moda.
