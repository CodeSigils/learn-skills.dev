Utilizza questa competenza per i flussi di lavoro della CLI di Fabric.so con il comando del terminale "fabric": diagnostica/installa/accedi, cerca o esplora una libreria Fabric, salva note/collegamenti/file, crea cartelle, chiedi all'assistente AI Fabric, gestisci attività/spazi di lavoro, genera il completamento della shell, controlla l'utilizzo dell'abbonamento, produce output JSON e utilizza Fabric come memoria agente persistente. Non utilizzare per Microsoft Fabric/Azure/Power BI `fab`, framework Fabric di Daniel Miessler, Python Fabric SSH, Fabric.js o tessuti tessili/moda.
