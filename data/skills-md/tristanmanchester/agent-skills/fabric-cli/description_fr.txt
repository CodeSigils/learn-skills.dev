Utilisez cette compétence pour les workflows Fabric.so CLI avec la commande de terminal `fabric` : diagnostiquer/installer/connecter, rechercher ou parcourir une bibliothèque Fabric, enregistrer des notes/liens/fichiers, créer des dossiers, demander à l'assistant Fabric AI, gérer les tâches/espaces de travail, générer l'achèvement du shell, vérifier l'utilisation des abonnements, produire une sortie JSON et utiliser Fabric comme mémoire d'agent persistante. Ne pas utiliser pour Microsoft Fabric/Azure/Power BI `fab`, le framework Fabric de Daniel Miessler, Python Fabric SSH, Fabric.js ou le tissu textile/mode.
