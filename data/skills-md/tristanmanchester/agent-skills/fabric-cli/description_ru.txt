Используйте этот навык для рабочих процессов CLI Fabric.so с помощью команды терминала «fabric»: диагностика/установка/вход в систему, поиск или просмотр библиотеки Fabric, сохранение заметок/ссылок/файлов, создание папок, обращение к помощнику Fabric AI, управление задачами/рабочими пространствами, создание завершения оболочки, проверка использования подписки, создание выходных данных JSON и использование Fabric в качестве постоянной памяти агента. Не используйте для Microsoft Fabric/Azure/Power BI `fab`, структуру Fabric Даниэля Мисслера, Python Fabric SSH, Fabric.js или ткань/модную ткань.
