استخدم هذه المهارة عندما يريد المستخدم فحص إعلانات Meta أو Facebook أو Instagram أو الإبلاغ عنها أو إنشائها أو تحديثها أو إيقافها مؤقتًا أو استئنافها أو تحديد ميزانيتها أو استهدافها أو تحميلها أو استكشاف أخطاء إعلانات Meta أو Facebook أو Instagram وإصلاحها عبر واجهة API التسويق. ويغطي الحسابات الإعلانية، والحملات، والمجموعات الإعلانية، والإعلانات، والتصميمات، والصور الإعلانية ومقاطع الفيديو، والبحث المستهدف، والقراءات المجمعة، وتقارير Insights. مفيد للطلبات المتعلقة بمدير الإعلانات الوصفية، أو تقارير عائد النفقات الإعلانية (ROAS) أو تكلفة الاكتساب (CPA)، أو إطلاق سير العمل، أو طرح المواد الإبداعية، أو إعداد الجمهور، أو مشكلات التسليم، أو تغييرات الميزانية، أو عمليات الإعلانات المجمعة.
