ユーザーが Marketing API を介してメタ、Facebook、または Instagram 広告の検査、レポート、作成、更新、一時停止、再開、予算設定、ターゲティング、アセットのアップロード、またはトラブルシューティングを行う場合は、このスキルを使用します。広告アカウント、キャンペーン、広告セット、広告、クリエイティブ、広告画像と動画、ターゲティング検索、バッチ読み取り、インサイト レポートが対象になります。 Meta Ads Manager、ROAS または CPA レポート、開始ワークフロー、クリエイティブのロールアウト、オーディエンスの設定、配信の問題、予算の変更、または一括広告操作に関するリクエストに役立ちます。
