Ajoute, répare ou migre une intégration RevenueCat plus Superwall de niveau production dans une application React Native Expo pour iOS et Android. Choisit entre CustomPurchaseControllerProvider et achatsAreCompletedBy ou la migration en mode observateur, connecte la configuration d'Expo et les versions de développement, synchronise les identités et les droits, gère les plans et offres de base Android, les bizarreries de l'application iOS UUID AccountToken, restaure le comportement, les analyses, les tests et le dépannage. À utiliser lorsque l'utilisateur demande à ajouter des abonnements, des paywalls, RevenueCat, Superwall, des droits, des flux de restauration, un changement de compte ou une migration de monétisation dans une application Expo. Ne pas utiliser pour le travail sur React Native, l'interface utilisateur de RevenueCat uniquement ou la facturation sur le Web uniquement.
