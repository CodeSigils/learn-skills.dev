iOS および Android 用の React Native Expo アプリで実稼働グレードの RevenueCat と Superwall の統合を追加、修復、または移行します。 CustomPurchaseControllerProvider と PurchaseAreCompletedBy またはオブザーバー モード移行のいずれかを選択し、Expo 構成と開発ビルドを接続し、ID と資格を同期し、Android の基本プランとオファー、iOS UUID appAccountToken の癖を処理し、動作、分析、テスト、およびトラブルシューティングを復元します。ユーザーが Expo アプリでサブスクリプション、ペイウォール、RevenueCat、Superwall、権利の追加、フローの復元、アカウントの切り替え、または収益化の移行を要求する場合に使用します。裸の React Native、RevenueCat のみの UI 作業、または Web のみの課金には使用しないでください。
