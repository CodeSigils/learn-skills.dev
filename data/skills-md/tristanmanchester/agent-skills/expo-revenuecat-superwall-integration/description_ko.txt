iOS 및 Android용 React Native Expo 앱에서 프로덕션 수준의 RevenueCat 및 Superwall 통합을 추가, 복구 또는 마이그레이션합니다. CustomPurchaseControllerProvider 및 buysAreCompletedBy 또는 관찰자 모드 마이그레이션 중에서 선택하고, Expo 구성 및 개발 빌드를 연결하고, ID 및 자격을 동기화하고, Android 기본 계획 및 제안을 처리하고, iOS UUID appAccountToken 문제, 복원 동작, 분석, 테스트 및 문제 해결을 수행합니다. 사용자가 Expo 앱에서 구독, 페이월, RevenueCat, Superwall, 자격, 복원 흐름, 계정 전환 또는 수익 창출 마이그레이션을 추가하도록 요청할 때 사용합니다. 기본 React Native, RevenueCat 전용 UI 작업 또는 웹 전용 청구에는 사용하지 마세요.
