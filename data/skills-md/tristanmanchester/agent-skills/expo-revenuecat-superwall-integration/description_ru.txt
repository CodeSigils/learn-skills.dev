Добавляет, исправляет или переносит интеграцию RevenueCat производственного уровня и Superwall в приложение React Native Expo для iOS и Android. Выбирает между CustomPurchaseControllerProvider и PurchaseAreCompletedBy или миграцией в режиме наблюдателя, подключает конфигурацию Expo и сборки разработки, синхронизирует удостоверения и права, обрабатывает базовые планы и предложения Android, особенности iOS UUID appAccountToken, восстановление поведения, аналитику, тестирование и устранение неполадок. Используйте, когда пользователь запрашивает добавление подписок, платного доступа, RevenueCat, Superwall, прав, потоков восстановления, переключения учетных записей или миграции монетизации в приложении Expo. Не используйте для голого React Native, работы с пользовательским интерфейсом только для RevenueCat или для выставления счетов только через Интернет.
