Textual を使用して、Python ターミナル ユーザー インターフェイスを構築、リファクタリング、デバッグ、テスト、パッケージ化します。ユーザーが TUI、ターミナル ダッシュボード、管理コンソール、マルチスクリーン ワークフロー、キーボード ファースト ツール、データ エクスプローラー、ファイル ブラウザー、マークダウンまたはログ ビューアー、エディター、コマンド パレット、ブラウザー提供のコンソール アプリを必要とする場合、または「テキスト」とは言わなくても、curses/リッチ専用 UI からテキストへの移行を必要とする場合に使用します。 TCSS とテーマ、組み込みウィジェット、画面とモード、反応状態、ワーカー、ブラウザ配信 API、pytest パイロットまたはスナップショット テストをカバーします。
