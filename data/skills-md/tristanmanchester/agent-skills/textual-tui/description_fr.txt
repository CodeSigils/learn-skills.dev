Créez, refactorisez, déboguez, testez et emballez les interfaces utilisateur du terminal Python avec Textual. À utiliser lorsque l'utilisateur souhaite un TUI, un tableau de bord de terminal, une console d'administration, un flux de travail multi-écran, un outil clavier en premier, un explorateur de données, un navigateur de fichiers, une visionneuse de démarques ou de journaux, un éditeur, une palette de commandes, une application de console servie par le navigateur ou une migration de Cursus/interface utilisateur riche uniquement vers textuel, même s'il ne dit jamais « textuel ». Couvre le TCSS et les thèmes, les widgets, les écrans et les modes intégrés, l'état réactif, les travailleurs, les API de livraison du navigateur et les tests pytest pilotes ou instantanés.
