使用 @shopify/react-native-skia、Reanimated 和 Gesture Handler 在 React Native 或 Expo 中設計、建構、調試和優化高品質動畫圖形。當使用者需要畫布驅動的 UI、著色器、路徑、富文本、圖像過濾器、精靈欄位、Skotie、視訊幀、快照、Web CanvasKit 設定或自訂運動密集元素（例如載入程式、英雄藝術、卡片、圖表、進度指示器、粒子系統或手勢驅動表面）的效能調整時使用。當使用者在 React Native 中請求流體、發光、玻璃、斑點、視差、60fps/120fps 或 GPU 友善的動畫效果時也可以使用，即使它們沒有明確地說「Skia」。請勿用於標準視圖的普通表單/佈局工作。
