قم بتصميم وإنشاء وتصحيح الأخطاء وتحسين الرسومات المتحركة عالية الجودة في React Native أو Expo باستخدام @shopify/react-native-skia وReanimated وGesture Handler. يُستخدم عندما يريد المستخدم واجهة مستخدم تعتمد على اللوحة القماشية، أو تظليلات، أو مسارات، أو نص منسق، أو مرشحات صور، أو حقول رموز متحركة، أو Skottie، أو إطارات فيديو، أو لقطات، أو إعداد CanvasKit على الويب، أو ضبط الأداء للعناصر المخصصة ذات الحركة الثقيلة مثل أدوات التحميل، أو فن البطل، أو البطاقات، أو المخططات، أو مؤشرات التقدم، أو أنظمة الجسيمات، أو الأسطح التي تعتمد على الإيماءات. استخدمه أيضًا عندما يطلب المستخدم تأثيرات متحركة أو متوهجة أو زجاجية أو نقطية أو اختلاف المنظر أو 60 إطارًا في الثانية/120 إطارًا في الثانية أو تأثيرات متحركة صديقة لوحدة معالجة الرسومات في React Native، حتى لو لم يذكر "Skia" صراحةً. لا تستخدمه في عمل النموذج/التخطيط العادي مع طرق العرض القياسية.
