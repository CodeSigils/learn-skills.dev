@shopify/react-native-skia、Reanimated、およびジェスチャー ハンドラーを使用して、React Native または Expo で洗練されたアニメーション グラフィックをデザイン、構築、デバッグ、最適化します。ユーザーがキャンバス駆動の UI、シェーダー、パス、リッチ テキスト、イメージ フィルター、スプライト フィールド、Skottie、ビデオ フレーム、スナップショット、Web CanvasKit セットアップ、またはローダー、ヒーロー アート、カード、チャート、進行状況インジケーター、パーティクル システム、またはジェスチャー駆動のサーフェスなどのモーションを重視するカスタム要素のパフォーマンス チューニングを必要とする場合に使用します。また、ユーザーが明示的に「Skia」と言わなくても、React Native で流体、グロー、ガラス、ブロブ、視差、60fps/120fps、または GPU 対応のアニメーション効果を要求する場合にも使用します。標準ビューを使用した通常のフォーム/レイアウト作業には使用しないでください。
