Проектируйте, создавайте, отлаживайте и оптимизируйте высококачественную анимированную графику в React Native или Expo, используя @shopify/react-native-skia, Reanimated и Gesture Handler. Используйте, когда пользователю нужен управляемый холстом пользовательский интерфейс, шейдеры, пути, форматированный текст, фильтры изображений, поля спрайтов, Скотти, видеокадры, снимки, веб-настройка CanvasKit или настройка производительности для пользовательских элементов с большим количеством движения, таких как загрузчики, герои-изображения, карты, диаграммы, индикаторы прогресса, системы частиц или поверхности, управляемые жестами. Также используйте, когда пользователь запрашивает плавность, свечение, стекло, каплю, параллакс, 60/120 кадров в секунду или анимированные эффекты, оптимизированные для графического процессора, в React Native, даже если они явно не говорят «Skia». Не используйте для обычной работы с формами/макетами со стандартными представлениями.
