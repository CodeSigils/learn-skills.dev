Entwerfen, erstellen, debuggen und optimieren Sie hochwertige animierte Grafiken in React Native oder Expo mit @shopify/react-native-skia, Reanimated und Gesture Handler. Verwenden Sie diese Option, wenn der Benutzer eine Canvas-gesteuerte Benutzeroberfläche, Shader, Pfade, Rich Text, Bildfilter, Sprite-Felder, Skottie, Videobilder, Schnappschüsse, Web-CanvasKit-Setup oder Leistungsoptimierung für benutzerdefinierte bewegungsintensive Elemente wie Loader, Hero-Art, Karten, Diagramme, Fortschrittsanzeigen, Partikelsysteme oder gestengesteuerte Oberflächen wünscht. Verwenden Sie es auch, wenn der Benutzer in React Native nach Flüssigkeits-, Glüh-, Glas-, Klecks-, Parallaxen-, 60fps/120fps- oder GPU-freundlichen animierten Effekten fragt, auch wenn er nicht ausdrücklich „Skia“ sagt. Nicht für normale Formular-/Layoutarbeiten mit Standardansichten verwenden.
