使用 @shopify/react-native-skia、Reanimated 和 Gesture Handler 在 React Native 或 Expo 中设计、构建、调试和优化高品质动画图形。当用户需要画布驱动的 UI、着色器、路径、富文本、图像过滤器、精灵字段、Skotie、视频帧、快照、Web CanvasKit 设置或自定义运动密集元素（例如加载程序、英雄艺术、卡片、图表、进度指示器、粒子系统或手势驱动表面）的性能调整时使用。当用户在 React Native 中请求流体、发光、玻璃、斑点、视差、60fps/120fps 或 GPU 友好的动画效果时也可以使用，即使它们没有明确地说“Skia”。请勿用于标准视图的普通表单/布局工作。
