Diseñe, cree, depure y optimice gráficos animados de alto brillo en React Native o Expo usando @shopify/react-native-skia, Reanimated y Gesture Handler. Úselo cuando el usuario desee una interfaz de usuario basada en lienzo, sombreadores, rutas, texto enriquecido, filtros de imagen, campos de sprites, Skottie, fotogramas de video, instantáneas, configuración web de CanvasKit o ajuste de rendimiento para elementos personalizados con mucho movimiento, como cargadores, arte de héroe, tarjetas, gráficos, indicadores de progreso, sistemas de partículas o superficies controladas por gestos. Úselo también cuando el usuario solicite efectos animados fluidos, brillantes, de vidrio, de manchas, de paralaje, de 60 fps/120 fps o compatibles con GPU en React Native, incluso si no dicen explícitamente "Skia". No lo utilice para trabajos de diseño/formulario ordinarios con vistas estándar.
