Progetta, crea, esegui il debug e ottimizza la grafica animata raffinata in React Native o Expo utilizzando @shopify/react-native-skia, Reanimated e Gesture Handler. Da utilizzare quando l'utente desidera un'interfaccia utente basata su canvas, shader, percorsi, testo RTF, filtri immagine, campi sprite, Skottie, fotogrammi video, istantanee, configurazione Web CanvasKit o ottimizzazione delle prestazioni per elementi personalizzati ricchi di movimento come caricatori, illustrazioni di eroi, carte, grafici, indicatori di avanzamento, sistemi di particelle o superfici guidate da gesti. Da utilizzare anche quando l'utente richiede effetti animati fluidi, luminosi, vetro, blob, parallasse, 60 fps/120 fps o compatibili con GPU in React Native, anche se non dicono esplicitamente "Skia". Non utilizzare per lavori ordinari di moduli/impaginazioni con visualizzazioni standard.
