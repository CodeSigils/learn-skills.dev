قم بإنشاء مهارات OpenCode واختبارها وتقييمها وتحسينها وحزمها باستخدام البرنامج الإضافي opencode-skill-creator. يُستخدم عندما يذكر المستخدمون صراحةً منشئ مهارات الكود المفتوح، أو منشئ مهارات OpenCode، أو إنشاء مهارة OpenCode، أو تحرير OpenCode SKILL.md، أو تشغيل تقييمات المهارات، أو قياس أداء المهارات، أو تحسين وصف مهارة OpenCode. لا تستخدمه لإنشاء Claude Code العام أو مهارات القوى الخارقة ما لم يطلب المستخدم نقل سير العمل هذا إلى OpenCode.
