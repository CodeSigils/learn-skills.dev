Créez, testez, évaluez, optimisez et emballez des compétences OpenCode avec le plugin opencode-skill-creator. À utiliser lorsque les utilisateurs mentionnent explicitement opencode-skill-creator, OpenCode Skill Creator, la création d'une compétence OpenCode, la modification d'un OpenCode SKILL.md, l'exécution d'évaluations de compétences, l'analyse comparative des performances d'une compétence ou l'optimisation d'une description de compétence OpenCode. Ne pas utiliser pour la création de compétences génériques Claude Code ou Superpowers, sauf si l'utilisateur demande de porter ce flux de travail vers OpenCode.
