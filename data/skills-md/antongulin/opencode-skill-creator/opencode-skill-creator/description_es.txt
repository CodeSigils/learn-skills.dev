Cree, pruebe, evalúe, optimice y empaquete habilidades OpenCode con el complemento opencode-skill-creator. Úselo cuando los usuarios mencionen explícitamente opencode-skill-creator, OpenCode Skill Creator, la creación de una habilidad OpenCode, la edición de un OpenCode SKILL.md, la ejecución de evaluaciones de habilidades, la evaluación comparativa del rendimiento de habilidades o la optimización de una descripción de habilidades OpenCode. No lo use para la creación de habilidades genéricas de Claude Code o Superpowers a menos que el usuario solicite transferir ese flujo de trabajo a OpenCode.
