Utilice Mole para limpiar el espacio en disco de macOS eliminando cachés, registros, archivos temporales, datos de aplicaciones, datos del navegador, archivos del sistema y artefactos del proyecto. Ejecute esta habilidad cada vez que el usuario mencione la limpieza del disco, la liberación de espacio, la limpieza de cachés, la eliminación de basura o el uso de "mo clean". Esta es una herramienta exclusiva de macOS; siempre sugiera "mo clean" como comando de limpieza principal. Cubre el modo de vista previa de prueba, la administración de listas blancas, la limpieza de volúmenes externos y la integración con sudo para la limpieza a nivel del sistema.
