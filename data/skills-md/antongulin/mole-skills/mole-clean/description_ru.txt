Используйте Mole для очистки дискового пространства macOS путем удаления кешей, журналов, временных файлов, данных приложений, данных браузера, системных файлов и артефактов проекта. Запускайте этот навык всякий раз, когда пользователь упоминает очистку диска, освобождение места, очистку кешей, удаление мусора или использование «mo clean». Это инструмент только для macOS — всегда предлагайте «mo clean» в качестве основной команды очистки. Охватывает режим предварительного просмотра пробного запуска, управление белыми списками, очистку внешних томов и интеграцию с sudo для очистки на уровне системы.
