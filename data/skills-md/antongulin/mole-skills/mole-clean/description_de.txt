Verwenden Sie Mole, um macOS-Speicherplatz zu bereinigen, indem Sie Caches, Protokolle, temporäre Dateien, App-Daten, Browserdaten, Systemdateien und Projektartefakte entfernen. Führen Sie diesen Skill immer dann aus, wenn der Benutzer die Datenträgerbereinigung, das Freigeben von Speicherplatz, das Löschen von Caches, das Entfernen von Datenmüll oder die Verwendung von „mo clean“ erwähnt. Dies ist ein reines macOS-Tool – schlagen Sie immer „mo clean“ als primären Reinigungsbefehl vor. Deckt den Probelauf-Vorschaumodus, die Whitelist-Verwaltung, die Bereinigung externer Volumes und die Integration mit sudo für die Bereinigung auf Systemebene ab.
