Используйте Mole для изучения использования диска macOS с помощью интерактивного вывода TUI или JSON. Запускайте этот навык всякий раз, когда пользователь упоминает анализ дискового пространства, поиск больших файлов, исследование использования диска, проверку хранилища или использование «mo Analysis». Охватывает режим обзора, сканирование каталогов, навигацию по файлам, обнаружение больших файлов, удаление файлов, вывод JSON и анализ пользовательского пути.
