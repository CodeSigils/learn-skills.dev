Verwenden Sie Mole, um macOS-Anwendungen einschließlich ihrer Supportdateien, Caches und Einstellungen vollständig zu entfernen. Führen Sie diesen Skill immer dann aus, wenn der Benutzer die Deinstallation von Apps, das Entfernen von Anwendungen, die App-Bereinigung, das Löschen von Software oder die Verwendung von „mo uninstall“ erwähnt. Behandelt das Scannen von Apps, den namensbasierten Abgleich, die interaktive Auswahl, den Probelaufmodus, das dauerhafte Löschen und das Auflisten installierbarer Apps.
