Genera notas de la versión apropiadas para la audiencia a partir de elementos de trabajo de Sprint completados, traduciendo los cambios técnicos en resultados de usuario en lenguaje sencillo para partes interesadas, clientes o equipos internos. Úselo cuando un propietario de producto dice cosas como "escribir notas de la versión", "qué envió este Sprint", "generar un registro de cambios", "qué entregamos", "redactar el correo electrónico de la versión" o "resumir lo que lanzamos". No lo utilice para facilitar la revisión de sprint; utilice sprint-review para eso. No utilizar para análisis de velocidad.
