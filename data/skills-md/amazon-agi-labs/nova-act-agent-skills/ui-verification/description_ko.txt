DOM에 대한 결정적 CSS 검사를 사용하여 라이브 웹 앱이 디자인 사양과 일치하는지 확인하고 Nova Act를 통해 Gherkin 시나리오를 실행하여 사용자 흐름을 확인합니다. 디자인 주장을 규칙으로 변환하고 verify_* MCP 도구를 통해 실행합니다. act() 및 act_get()을 통해 흐름을 실행합니다. 주석이 달린 스크린샷과 흐름별 세부 정보가 포함된 결합된 시각적 + 흐름 보고서를 생성합니다. 라이브 사이트에 대한 시각적 스타일, 구성 요소 규칙, 접근성, 프로젝트 규칙, 플랫폼 패턴 또는 엔드투엔드 사용자 여정을 확인할 때 사용합니다.
