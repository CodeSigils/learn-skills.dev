تحقق مما إذا كان تطبيق الويب المباشر يطابق مواصفات التصميم الخاصة به باستخدام عمليات فحص CSS الحتمية مقابل DOM، وتحقق من تدفقات المستخدم عن طريق تنفيذ سيناريوهات Gherkin عبر Nova Act. ترجمة مطالبات التصميم إلى قواعد وتشغيلها عبر أدوات Vere_* MCP؛ ينفذ التدفقات عبر act() وact_get(). يُنتج تقريرًا مرئيًا + تدفقًا مدمجًا مع لقطات شاشة توضيحية وتفاصيل لكل تدفق. يُستخدم عند التحقق من النمط المرئي، أو قواعد المكونات، أو إمكانية الوصول، أو اصطلاحات المشروع، أو أنماط النظام الأساسي، أو رحلات المستخدم الشاملة مقابل موقع مباشر.
