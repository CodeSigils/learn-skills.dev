DOM に対する確定的な CSS チェックを使用して、ライブ Web アプリがその設計仕様と一致しているかどうかを検証し、Nova Act を介して Gherkin シナリオを実行してユーザー フローを検証します。設計クレームをルールに変換し、verify_* MCP ツールを介して実行します。 act() および act_get() を介してフローを実行します。注釈付きのスクリーンショットとフローごとの詳細を含む、ビジュアルとフローを組み合わせたレポートを作成します。ビジュアル スタイル、コンポーネント ルール、アクセシビリティ、プロジェクト規約、プラットフォーム パターン、またはエンドツーエンドのユーザー ジャーニーをライブ サイトに対してチェックするときに使用します。
