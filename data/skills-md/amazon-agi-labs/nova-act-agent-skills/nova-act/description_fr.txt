SDK d'automatisation de navigateur basé sur l'IA pour le web scraping, les tests et l'automatisation des flux de travail. À utiliser lors de l'automatisation des navigateurs Web, de l'extraction de données de sites Web, du test d'applications Web ou de la création de flux de travail d'automatisation Web. Prend en charge à la fois la clé API et l'authentification des informations d'identification AWS.
