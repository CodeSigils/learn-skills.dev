Запустите проектирование базовой цепи белка RFDiffusion с помощью NVIDIA NIM. Используйте для белковых остовов de novo, построения мотивов, проектирования связующих, остатков горячих точек, синтаксиса контигов, этапов диффузии, размещенных вызовов API NVIDIA, локального развертывания Docker и выходных данных основной цепи PDB для проектирования последовательностей ProteinMPNN.
