Используйте этот навык всякий раз, когда пользователь хочет провести анализ параметров конвейера проектирования Proteina-Complexa — сканирование гиперпараметров декартовых произведений, поиск по Парето с помощью ручек генерации/вознаграждения/оценки или любой рабочий процесс «сравнения конфигураций». Триггерные фразы включают в себя «ширина луча развертки», «шаги развертки», «развертка гиперпараметра», «сканирование параметров», «ширина луча сканирования и температура», «сравнить конфигурации», «найти лучшие параметры генерации», «какие оптимальные n шагов», «поиск по Парето качества связующего по сравнению с настенными часами», «комплексная развертка», «настроить комплексу», «убрать веса вознаграждения», «конфигурации/развертки», "--sweeper", "запустите beam_width.yaml". Это единственный навык, который владеет широкими возможностями создания YAML, расширения декартовых продуктов и ранжирования результатов для каждой конфигурации. О механике кластерного подчинения см. навык «complexa-slurm».
