Используйте этот навык для OpenFold2, микросервиса NVIDIA BioNeMo NIM для прогнозирования структуры мономерных белков. Вызывайте каждый раз, когда пользователь упоминает OpenFold2, сворачивание мономера по принципу AlphaFold2, предсказание последовательности белка в структуру, A3M MSA, шаблоны mmCIF, вызовы размещенного API NVIDIA или локальное развертывание Docker.
