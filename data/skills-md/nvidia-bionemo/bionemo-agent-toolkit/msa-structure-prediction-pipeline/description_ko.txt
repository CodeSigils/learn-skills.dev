MSA-Search(ColabFold)로 MSA 정렬을 검색한 다음 검색된 정렬을 사용하여 OpenFold3으로 구조를 예측합니다. 사용자가 MSA 컨텍스트를 사용하여 최대 정확도로 단백질 구조를 예측하거나, 전체 AlphaFold3 스타일 파이프라인을 실행하거나, MSA 정보 구조 예측을 생성하거나, 진화 정보를 제공하여 구조 예측 정확도를 향상시키려는 경우 언제든지 이 기술을 사용하십시오. 트리거 대상: MSA 구조 예측 파이프라인, 구조 예측 파이프라인, MSA 기반 예측, OpenFold3, ColabFold MSA, AlphaFold3 파이프라인, 단백질 구조, 상동성 검색, a3m 정렬, UniRef30, NIM 마이크로서비스. 이 파이프라인은 MSA-Search와 OpenFold3을 연결합니다.
