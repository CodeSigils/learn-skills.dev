Запустите полный конвейер прогнозирования структуры белка с помощью NIM NVIDIA BioNeMo: найдите совпадения MSA с помощью MSA-Search (ColabFold), затем спрогнозируйте структуру с помощью OpenFold3, используя полученные сопоставления. Используйте этот навык всякий раз, когда пользователь хочет предсказать структуру белка с максимальной точностью, используя контекст MSA, запустить полный конвейер в стиле AlphaFold3, сгенерировать прогнозы структуры на основе MSA или повысить точность прогнозирования структуры, предоставляя эволюционную информацию. Запускается по: конвейеру прогнозирования структуры MSA, конвейеру прогнозирования структуры, прогнозированию на основе MSA, OpenFold3, ColabFold MSA, конвейеру AlphaFold3, структуре белка, поиску гомологии, выравниванию a3m, UniRef30, микросервису NIM. Этот конвейер объединяет MSA-Search и OpenFold3.
