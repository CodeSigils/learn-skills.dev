Trainieren Sie ein neues KERMT-Modell von Grund auf auf einem vom Benutzer bereitgestellten Korpus. Erstellt ein neues Vokabular aus dem Korpus, instanziiert die Modellarchitektur aus Standardwerten und startet pretrain_ddp.py im Kermt-Container (für lange Läufe getrennt). Im Gegensatz zu kermt-continue-pretrain wird kein Startprüfpunkt geladen – das Modell wird zufällig initialisiert.
