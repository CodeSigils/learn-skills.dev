Utilice esta habilidad para MolMIM, el microservicio BioNeMo NIM de NVIDIA para la generación y optimización del espacio latente de moléculas pequeñas. Invoke para MolMIM, incrustaciones moleculares, estados ocultos, decodificación latente, muestreo alrededor de una semilla SMILES, generación de moléculas guiada por CMA-ES, optimización QED o plogP, llamadas API alojadas de NVIDIA o implementación local de Docker.
