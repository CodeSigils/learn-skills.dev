Utilizza questa competenza per MolMIM, il microservizio NIM BioNeMo di NVIDIA per la generazione e l'ottimizzazione dello spazio latente di piccole molecole. Richiama MolMIM, incorporamenti molecolari, stati nascosti, decodifica latente, campionamento attorno a un seme SMILES, generazione guidata di molecole CMA-ES, ottimizzazione QED o plogP, chiamate API NVIDIA ospitate o distribuzione Docker locale.
