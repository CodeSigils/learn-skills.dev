Используйте этот навык для MolMIM, микросервиса NVIDIA BioNeMo NIM для генерации и оптимизации скрытого пространства малых молекул. Вызов для MolMIM, молекулярного внедрения, скрытых состояний, скрытого декодирования, выборки вокруг начального SMILES, управляемой генерации молекул CMA-ES, оптимизации QED или plogP, размещенных вызовов API NVIDIA или локального развертывания Docker.
