Автономная оценка существующего каталога PDB с помощью Proteina-Complexa. Используйте этот навык всякий раз, когда пользователь хочет «оценить файлы PDB», «пересложить эти проекты», «вычислить интерфейс pAE», «вычислить i_pLDDT для папки», «запустить AF2 / RF3 / ESMFold на моих проектах», «кандидатов для связывания оценок», «возможность проектирования этой папки», «scRMSD для проектов», «мотив RMSD для этих PDB», «комплексный анализ», «комплексную оценку из каталога PDB», «оценить из pdb dir» или оценивайте результаты сторонних разработчиков (BindCraft, AlphaProteo, RFdiffusion, созданные вручную ложные цели). Он выбирает правильную конфигурацию `evaluate_*.yaml`, подключает `++dataset.pdb_dir` и серверную часть свертывания, запускает `комплексный анализ` (цепочка оценки → анализа), анализирует CSV-результат, сообщает о скорости прохождения по правильным пороговым значениям `result_type` и генерирует воспроизводимый `eval_manifest.json`. Овладейте этим навыком, прежде чем писать сценарии переворачивания вручную.
