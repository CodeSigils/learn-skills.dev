Evaluación independiente de un directorio PDB existente con Proteina-Complexa. Utilice esta habilidad siempre que el usuario desee "evaluar archivos PDB", "volver a plegar estos diseños", "calcular la interfaz pAE", "calcular i_pLDDT para una carpeta", "ejecutar AF2/RF3/ESMFold en mis diseños", "puntuar candidatos de carpeta", "designabilidad de esta carpeta", "scRMSD para diseños", "motivo RMSD para estos PDB", "análisis de complejos", "evaluación de complejos desde un directorio de PDB", "evaluar desde el directorio de pdb", o obtenga resultados de terceros (BindCraft, AlphaProteo, RFdiffusion, señuelos seleccionados a mano). Selecciona la configuración correcta `evaluate_*.yaml`, conecta `++dataset.pdb_dir` y el backend plegable, ejecuta `análisis complexa` (la cadena evaluar → analizar), analiza el resultado CSV, informa las tasas de aprobación según los umbrales correctos de `result_type` y emite un `eval_manifest.json` reproducible. Busque esta habilidad antes de volver a doblar guiones a mano.
