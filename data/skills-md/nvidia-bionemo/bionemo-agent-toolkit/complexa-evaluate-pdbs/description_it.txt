Valutazione autonoma di una directory PDB esistente con Proteina-Complexa. Utilizzare questa capacità ogni volta che l'utente desidera "valutare file PDB", "ripiegare questi progetti", "computare l'interfaccia pAE", "calcolare i_pLDDT per una cartella", "eseguire AF2 / RF3 / ESMFold sui miei progetti", "candidati raccoglitore di punteggi", "progettabilità di questa cartella", "scRMSD per progetti", "motivo RMSD per questi PDB", "analisi complexa", "complexa valutare da una directory PDB", "valutare da pdb dir", o assegnare punteggi ai risultati di terze parti (BindCraft, AlphaProteo, RFdiffusion, esche curate manualmente). Seleziona la configurazione `evaluate_*.yaml` corretta, collega `++dataset.pdb_dir` e il backend pieghevole, esegue `complexa analysis` (la catena valutazione → analizza), analizza il CSV dei risultati, riporta le percentuali di passaggio rispetto alle soglie `result_type` corrette ed emette un `eval_manifest.json` riproducibile. Raggiungi questa abilità prima di eseguire manualmente gli script ripiegati.
