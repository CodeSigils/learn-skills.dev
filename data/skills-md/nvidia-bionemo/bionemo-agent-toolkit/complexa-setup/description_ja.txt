Proteina-Complexa の初回セットアップ、環境構成、およびモデル重量のインストール。ユーザーが「complexa をセットアップする」、「complexa をインストールする」、「.env を構成する」、「初回セットアップ」、「インストールしたモデルは何ですか」、「.env の内容」、「モデルの重みをダウンロードする」、「Complexa / AF2 / RF3 / ProteinMPNN / LigandMPNN / ESM2 / ESMFold チェックポイントをダウンロードする」、「GPU をプリフライトする」、「検証する」と言うたびに、このスキルに到達します。 「environment」、「complexa init」、「complexa download」、「complexa download --status」、「complexa validate env」、または新しいチェックアウトを実行可能にする必要があるとき。これは、新しいクローンで実行される最初のスキルです。これは、「complexa init」、「complexa download」、「complexa validate env」をエンドツーエンドで実行し、必要な「.env」キーを編集し、適切なランタイム (UV 対 Docker) を選択し、再生可能なセットアップ アーティファクトを生成します。
