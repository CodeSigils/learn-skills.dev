Создавайте новые молекулы, подобные лекарствам, с помощью микросервиса GenMol NIM. Используйте для генерации de novo, оформления строительных лесов, расширения мотивов, оптимизации потенциальных клиентов, нотации SAFE, ранжирования QED или LogP, размещенных вызовов API NVIDIA или локального развертывания Docker. GenMol использует БЕЗОПАСНУЮ нотацию в поле улыбок, а не обычные УЛЫБКИ.
