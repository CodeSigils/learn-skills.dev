Genera nuove molecole simili a farmaci utilizzando il microservizio GenMol NIM. Utilizzare per la generazione de novo, la decorazione di scaffold, l'estensione di motivi, l'ottimizzazione dei lead, la notazione SAFE, la classificazione QED o LogP, le chiamate API NVIDIA ospitate o la distribuzione Docker locale. GenMol prende la notazione SAFE nel campo dei sorrisi, non i SORRISI ordinari.
