Générez de nouvelles molécules de type médicament à l’aide du microservice GenMol NIM. À utiliser pour la génération de novo, la décoration d'échafaudage, l'extension de motif, l'optimisation de leads, la notation SAFE, le classement QED ou LogP, les appels d'API NVIDIA hébergés ou le déploiement Docker local. GenMol prend la notation SAFE dans le champ des sourires, pas les SMILES ordinaires.
