قم بإنشاء جزيئات جديدة تشبه الأدوية باستخدام خدمة GenMol NIM الصغيرة. يُستخدم للإنشاء الجديد، أو زخرفة السقالات، أو امتداد الفكرة، أو تحسين الرصاص، أو تدوين SAFE، أو تصنيف QED أو LogP، أو مكالمات NVIDIA API المستضافة، أو نشر Docker المحلي. يأخذ GenMol تدوينًا آمنًا في مجال الابتسامات، وليس الابتسامات العادية.
