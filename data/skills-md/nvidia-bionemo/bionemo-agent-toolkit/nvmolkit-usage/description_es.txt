Escriba código que llame a la API Python nvMolKit instalada para operaciones de estilo RDKit por lotes y aceleradas por GPU: huellas dactilares de Morgan, similitud de Tanimoto/coseno, incrustación de conformadores ETKDG, optimización MMFF/UFF, TFD, RMSD de conformadores, agrupación en clústeres de Butina y búsqueda de subestructuras. Úselo cuando el usuario esté importando `nvmolkit.*`, depurando una llamada `nvmolkit`, eligiendo entre nvMolKit y RDKit para un flujo de trabajo quimioinformático por lotes o conectando los resultados de nvMolKit a una canalización de antorcha/numpy. Fuera de alcance: compilar nvMolKit desde el código fuente.
