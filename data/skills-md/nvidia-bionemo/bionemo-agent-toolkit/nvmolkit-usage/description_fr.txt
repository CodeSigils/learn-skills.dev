Écrivez du code qui appelle l'API Python nvMolKit installée pour les opérations par lots de style RDKit accélérées par GPU : empreintes digitales Morgan, similarité Tanimoto/cosinus, intégration du conformateur ETKDG, optimisation MMFF/UFF, TFD, conformateur RMSD, clustering Butina et recherche de sous-structure. À utiliser lorsque l'utilisateur importe `nvmolkit.*`, débogue un appel `nvmolkit`, choisit entre nvMolKit et RDKit pour un flux de travail cheminformatique par lots ou câble les résultats de nvMolKit dans un pipeline torch/numpy. Hors de portée : créer nvMolKit à partir des sources.
