GPU アクセラレーションによるバッチ処理された RDKit スタイルの操作 (モーガン フィンガープリント、タニモト/コサイン類似度、ETKDG 配座異性体埋め込み、MMFF/UFF 最適化、TFD、配座異性体 RMSD、Butina クラスタリング、および部分構造検索) のために、インストールされている nvMolKit Python API を呼び出すコードを作成します。ユーザーが「nvmolkit.*」をインポートする場合、「nvmolkit」呼び出しをデバッグする場合、バッチケモインフォマティクスワークフロー用に nvMolKit と RDKit のどちらかを選択する場合、または nvMolKit の結果を torch/numpy パイプラインに接続する場合に使用します。範囲外: ソースから nvMolKit をビルドします。
