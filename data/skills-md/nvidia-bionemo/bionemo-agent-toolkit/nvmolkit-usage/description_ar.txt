اكتب التعليمات البرمجية التي تستدعي nvMolKit Python API المثبت لعمليات نمط RDKit المجمعة والمتسارعة بواسطة GPU - بصمات مورغان، وتشابه Tanimoto/cosine، وتضمين مطابق ETKDG، وتحسين MMFF/UFF، و TFD، و RMSD المطابق، وتجميع Butina، والبحث عن البنية التحتية. يُستخدم عندما يقوم المستخدم باستيراد `nvmolkit.*`، أو تصحيح أخطاء استدعاء `nvmolkit`، أو الاختيار بين nvMolKit وRDKit لسير عمل المعلوماتية الكيميائية المجمعة، أو توصيل نتائج nvMolKit إلى مسار شعلة/رقم. خارج النطاق: بناء nvMolKit من المصدر.
