Запустите полный вычислительный процесс поиска лекарств с помощью NIM NVIDIA BioNeMo: создавайте молекулы, подобные лекарству, с помощью GenMol, прикрепляйте их к белку-мишени с помощью DiffDock, а затем прогнозируйте аффинность связывания с помощью Boltz2. Используйте этот навык всякий раз, когда пользователь хочет создать и проверить кандидатов на низкомолекулярные лекарственные препараты, выполнить обнаружение совпадений, оптимизировать потенциальных клиентов по белку-мишени или провести виртуальный скрининг, сочетающий генерацию молекул, стыковку и прогнозирование аффинности. Запускается по: конвейеру поиска лекарств, обнаружению хитов, оптимизации потенциальных клиентов, виртуальному скринингу, генерации молекул, стыковке молекул, сродству связывания, GenMol, DiffDock, Boltz2, SMILES, нотации SAFE, микросервису NIM. Это многоэтапный конвейер, состоящий из трех NIM BioNeMo.
