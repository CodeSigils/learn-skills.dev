قم بتشغيل الطي العكسي لـ ProteinMPNN عبر NVIDIA NIM لتصميم تسلسلات البروتين للعمود الفقري المستهدف. يستخدم لـ ProteinMPNN، والطي العكسي، وتصميم التسلسل، وإعادة تصميم العمود الفقري، والسلاسل/البقايا الثابتة، وحذف_AAs، ودرجة حرارة أخذ العينات، والنموذج القابل للذوبان، وNVIDIA API المستضاف، وDocker المحلي، وإدخال PDB، ومخرجات FASTA المتعددة.
