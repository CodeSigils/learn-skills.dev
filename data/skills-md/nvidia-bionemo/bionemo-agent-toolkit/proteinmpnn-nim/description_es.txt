Ejecute el plegado inverso de ProteinMPNN a través de NVIDIA NIM para diseñar secuencias de proteínas para una columna vertebral objetivo. Úselo para ProteinMPNN, plegado inverso, diseño de secuencia, rediseño de la columna vertebral, cadenas/residuos fijos, omit_AA, temperatura de muestreo, modelo soluble, API NVIDIA alojada, Docker local, entrada PDB y salida multi-FASTA.
