Используйте этот навык для OpenFold3, микросервиса NVIDIA BioNeMo NIM для прогнозирования биомолекулярной структуры. Вызывайте каждый раз, когда пользователь упоминает OpenFold3 или ему требуется прогнозирование белков, белков-лигандов, белков-ДНК/РНК или многоцепочечных комплексов с помощью размещенного NVIDIA API или локального Docker NIM. Охватывает выбор конечной точки, аутентификацию, полезные данные запроса, выходные артефакты, оценки достоверности и настройку локального контейнера.
