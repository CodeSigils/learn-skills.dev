استخدم هذه المهارة مع OpenFold3، وهي خدمة BioNeMo NIM الصغيرة من NVIDIA للتنبؤ بالبنية الجزيئية الحيوية. قم بالاستدعاء عندما يذكر المستخدم OpenFold3 أو يحتاج إلى البروتين أو البروتين يجند أو البروتين DNA/RNA أو التنبؤ المعقد متعدد السلاسل باستخدام NVIDIA API المستضاف أو Docker NIM المحلي. يغطي اختيار نقطة النهاية، والمصادقة، وطلب الحمولات، وعناصر الإخراج، ودرجات الثقة، وإعداد الحاوية المحلية.
