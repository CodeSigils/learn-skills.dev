Точная настройка предварительно обученного кодировщика KERMT на помеченном CSV-файле. Навык проверяет входную контрольную точку (должен быть ckpt перед обучением — grover_base / cmim / Hybrid), проверяет помеченный CSV, подготавливает данные (чистка + функции + необязательное разделение), затем запускает тонкую настройку main.py внутри контейнера kermt (отсоединяется для запусков в масштабе часов). Гиперпараметры берутся из агента/config/defaults_finetune.json с переопределением CLI для каждого флага.
