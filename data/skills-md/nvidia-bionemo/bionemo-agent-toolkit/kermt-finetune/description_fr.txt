Affinez un encodeur KERMT pré-entraîné sur un CSV étiqueté. La compétence valide le point de contrôle d'entrée (doit être un ckpt de pré-entraînement - grover_base / cmim / hybrid), valide le CSV étiqueté, prépare les données (nettoyage + fonctionnalités + fractionnement facultatif), puis lance le réglage fin de main.py à l'intérieur du conteneur kermt (détaché pour les exécutions à l'échelle des heures). Les hyperparamètres proviennent de agent/config/defaults_finetune.json avec remplacement CLI par indicateur.
