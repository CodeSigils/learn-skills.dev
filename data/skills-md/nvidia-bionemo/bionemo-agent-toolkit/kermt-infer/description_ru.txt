Выполняйте прогнозы с помощью точно настроенной контрольной точки KERMT в CSV-файле только для SMILES. Навык проверяет, что входной ckpt имеет заголовки FFN задачи (отказывается от предварительной подготовки ckpt с перенаправлением на kermt-finetune), проверяет CSV, подготавливает данные (функции clean + rdkit_2d), затем запускает предсказание main.py внутри контейнера kermt (блокировка, в минутах).
