Esegui il docking molecolare DiffDock tramite NVIDIA NIM per prevedere le posizioni di legame di piccole molecole rispetto ai target proteici. Utilizzare per DiffDock, docking molecolare, docking di ligandi, docking cieco, ligandi SMILES o SDF, pose classificate, punteggi di confidenza, API NVIDIA ospitate o distribuzione Docker locale.
