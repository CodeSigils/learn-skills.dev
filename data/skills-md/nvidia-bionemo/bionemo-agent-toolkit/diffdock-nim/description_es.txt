Ejecute el acoplamiento molecular DiffDock a través de NVIDIA NIM para predecir las posiciones de unión de moléculas pequeñas frente a objetivos proteicos. Úselo para DiffDock, acoplamiento molecular, acoplamiento de ligandos, acoplamiento ciego, ligandos SMILES o SDF, poses clasificadas, puntuaciones de confianza, API NVIDIA alojada o implementación local de Docker.
