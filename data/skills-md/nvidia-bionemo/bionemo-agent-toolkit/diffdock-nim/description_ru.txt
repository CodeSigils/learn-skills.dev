Запустите молекулярную стыковку DiffDock через NVIDIA NIM, чтобы предсказать положение связывания малых молекул с белковыми мишенями. Используйте для DiffDock, молекулярной стыковки, стыковки лигандов, слепой стыковки, лигандов SMILES или SDF, ранжированных поз, оценок уверенности, размещенного NVIDIA API или локального развертывания Docker.
