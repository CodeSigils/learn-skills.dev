Создавайте множественные выравнивания последовательностей (MSA) для белковых последовательностей с помощью ColabFold MSA-Search NIM. Используйте для поиска гомологов, поиска в среде UniRef30/ColabFold, выравнивания A3M или FASTA, парного поиска комплексов MSA, структурных шаблонов PDB70, вызовов размещенного API NVIDIA или локального развертывания Docker.
