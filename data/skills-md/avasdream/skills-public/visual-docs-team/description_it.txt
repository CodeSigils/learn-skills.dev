Genera un'app React + Vite completamente funzionante che spiega i flussi di lavoro, i tipi di dati e l'architettura di una base di codice attraverso elementi visivi interattivi: procedure dettagliate animate passo-passo con riproduzione automatica, diagrammi di sequenza, tracciatori di pacchetti animati, ispettori dei messaggi che alternano tra la visualizzazione dei campi con nome e JSON non elaborato e visualizzazioni di codice comprimibili con citazioni file:line. Divide il repository in 4-6 cluster di dominio e invia un agente di contenuto per cluster per scrivere le pagine in parallelo. La competenza raggruppa le proprie pagine di riferimento (sotto riferimenti/esempi/) in modo che funzioni in qualsiasi repository. Utilizza questa capacità ogni volta che l'utente richiede documenti interattivi, spiegazioni animate, un "team di agenti" per i documenti, una pagina per dominio, desidera visualizzare il flusso di richieste di un sistema o un protocollo di collegamento o qualsiasi sito di documentazione visiva. Richiede CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 in .claude/settings.json.
