Générez une application React + Vite entièrement fonctionnelle qui explique les flux de travail, les types de données et l'architecture d'une base de code via des visuels interactifs : des procédures pas à pas animées en un clic avec lecture automatique, des diagrammes de séquence, des traceurs de paquets animés, des inspecteurs de messages qui basculent entre la vue du champ nommé et le JSON brut, et des aperçus de code pliables avec des citations file:line. Divise le référentiel en 4 à 6 clusters de domaines et distribue un agent de contenu par cluster pour écrire les pages en parallèle. La compétence regroupe ses propres pages de référence (sous références/exemples/) afin de fonctionner dans n'importe quel référentiel. Utilisez cette compétence chaque fois que l'utilisateur demande des documents interactifs, des explications animées, une « équipe d'agents » pour les documents, une page par domaine, souhaite visualiser le flux de requêtes ou le protocole filaire d'un système, ou tout site de documentation visuelle. Nécessite CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 dans .claude/settings.json.
