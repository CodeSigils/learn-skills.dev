Создайте полностью работающее приложение React + Vite, которое объясняет рабочие процессы, типы данных и архитектуру кодовой базы с помощью интерактивных визуальных эффектов — пошаговых анимированных пошаговых руководств с автоматическим воспроизведением, диаграмм последовательности, анимированных трассировщиков пакетов, инспекторов сообщений, которые переключаются между представлением именованного поля и необработанным JSON, а также свертываемые просмотры кода с цитатами из файла: строки. Разбивает репозиторий на 4–6 кластеров доменов и отправляет по одному агенту контента на каждый кластер для параллельной записи страниц. Навык объединяет свои собственные справочные страницы (в разделе «Ссылки/примеры/»), поэтому он работает в любом репозитории. Используйте этот навык всякий раз, когда пользователь запрашивает интерактивные документы, анимированные пояснения, «команду агентов» для документации, одну страницу на домен, хочет визуализировать поток запросов системы или протокол связи, или любой сайт с визуальной документацией. Требуется CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 в .claude/settings.json.
