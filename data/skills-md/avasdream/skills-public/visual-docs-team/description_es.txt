Genere una aplicación React + Vite completamente funcional que explique los flujos de trabajo, los tipos de datos y la arquitectura de una base de código a través de elementos visuales interactivos: tutoriales animados paso a paso con reproducción automática, diagramas de secuencia, rastreadores de paquetes animados, inspectores de mensajes que alternan entre vista de campo con nombre y JSON sin formato, y vistas de código plegables con citas de archivo:línea. Divide el repositorio en 4 a 6 grupos de dominios y envía un agente de contenido por grupo para escribir las páginas en paralelo. La habilidad incluye sus propias páginas de referencia (en referencias/ejemplos/) para que funcione en cualquier repositorio. Utilice esta habilidad siempre que el usuario solicite documentos interactivos, explicaciones animadas, un "equipo de agentes" para documentos, una página por dominio, quiera visualizar el flujo de solicitudes de un sistema o el protocolo de conexión, o cualquier sitio de documentación visual. Requiere CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 en .claude/settings.json.
