Generieren Sie eine voll funktionsfähige React + Vite-App, die die Arbeitsabläufe, Datentypen und Architektur einer Codebasis durch interaktive Visuals erklärt – animierte Schritt-für-Schritt-Anleitungen mit automatischer Wiedergabe, Sequenzdiagramme, animierte Paketverfolgungsfunktionen, Nachrichteninspektoren, die zwischen benannter Feldansicht und rohem JSON wechseln, und reduzierbare Code-Einblicke mit Datei-Zeilen-Zitaten. Teilt das Repo in 4–6 Domänencluster auf und entsendet einen Inhaltsagenten pro Cluster, um die Seiten parallel zu schreiben. Der Skill bündelt seine eigenen Referenzseiten (unter references/examples/), sodass er in jedem Repo funktioniert. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer interaktive Dokumente, animierte Erklärungen, ein „Agententeam“ für Dokumente, eine Seite pro Domäne, den Anforderungsfluss oder das Übertragungsprotokoll eines Systems oder eine andere visuelle Dokumentationsseite visualisieren möchte. Erfordert CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 in .claude/settings.json.
