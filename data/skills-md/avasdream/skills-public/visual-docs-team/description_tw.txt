產生一個功能齊全的 React + Vite 應用程序，透過互動式視覺效果解釋程式碼庫的工作流程、資料類型和架構 - 帶有自動播放功能的點擊式動畫演練、序列圖、動畫資料包追蹤器、在命名欄位視圖和原始 JSON 之間切換的訊息檢查器，以及帶有 file:line 引用的可折疊程式碼預覽。將儲存庫拆分為 4-6 個域集群，並為每個集群調度一個內容代理以並行寫入頁面。此技能捆綁了自己的參考頁面（在引用/範例/下），因此它可以在任何儲存庫中使用。每當使用者請求互動式文件、動畫解釋器、文件「代理團隊」、每個網域一頁、想要視覺化系統的請求流程或線路協議或任何視覺化文件網站時，請使用此技能。需要 .claude/settings.json 中的 CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1。
