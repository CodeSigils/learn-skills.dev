Créez et gérez une base de connaissances Markdown que tout agent d'IA peut lire, rechercher et mettre à jour. À utiliser lorsque l'utilisateur souhaite démarrer une base de connaissances, ajouter ou mettre à jour des notes, organiser des documents/notes pour qu'un agent ou un LLM les consomme, créer un index de notes ou exécuter une passe de nettoyage/maintenance sur une base de connaissances MD existante. Les déclencheurs incluent « base de connaissances », « base de connaissances », « notes pour l'agent », « index des notes », « deuxième cerveau », « documents pour le contexte de l'IA », « ajouter une note », « mettre à jour la base de connaissances ».
