使用 Desktop Commander 进行终端和命令行工作，尤其是需要状态持续持续的 shell 的任何内容：Python/Node REPL、数据库 shell、开发服务器和其他长时间运行的进程、远程计算机的 SSH 和 Windows PowerShell。还可以处理日常终端任务 - 导航文件夹、为用户 shell 选择正确的命令（PowerShell、cmd、bash、zsh）、运行 Docker/curl/cloud-CLI 命令、检查进程和端口以及将重复工作流程保存为脚本 - 即使用户没有说“Desktop Commander”或“终端”。针对“未找到命令”、“权限被拒绝”、“EADDRINUSE”、“地址已在使用”、“npm ERR！”、“ModuleNotFoundError”或“ENOENT”等粘贴错误，以及“正在使用端口 3000 的内容”、“终止该进程”、“ssh 进入我的服务器”或“为什么我的开发服务器无法启动”等意图来获取它。适用于 Windows、macOS 和 Linux。未经明确确认，切勿运行破坏性命令。
