使用 Desktop Commander 進行終端機和命令列工作，特別是任何需要狀態持續持續的 shell 的內容：Python/Node REPL、資料庫 shell、開發伺服器和其他長時間運行的進程、遠端電腦的 SSH 和 Windows PowerShell。還可以處理日常終端任務 - 導航資料夾、為使用者 shell 選擇正確的命令（PowerShell、cmd、bash、zsh）、執行 Docker/curl/cloud-CLI 命令、檢查進程和連接埠以及將重複工作流程儲存為腳本 - 即使使用者沒有說「Desktop Commander」或「終端」。針對「未找到命令」、「權限被拒絕」、「EADDRINUSE」、「地址已在使用」、「npm ERR！」、「ModuleNotFoundError」或「ENOENT」等貼上錯誤，以及「正在使用連接埠 3000 的內容」、「終止伺服器」、「ssh 進入我的開發伺服器或「為什麼我的伺服器」來啟動它等它。适用于 Windows、macOS 和 Linux。未經明確確認，切勿運行破壞性命令。
