Richten Sie Claude Desktop- und MCP-Server mit Desktop Commander ein, verbinden Sie sie, validieren und reparieren Sie sie. Überprüfen und reparieren Sie mcp.json / claude_desktop_config.json, stellen Sie sicher, dass MCP-Server eine Verbindung herstellen, und diagnostizieren Sie lokale KI-Tools. Verwenden Sie diese Option, wenn ein Benutzer Claude Desktop, einen MCP-Server, eine MCP-Konfigurationsdatei oder einen lokalen KI-Agenten/Gateway installieren, konfigurieren, verbinden, validieren oder reparieren möchte. Lösen Sie die Symptome aus, die tatsächlich Leute anlocken: „Claude kann meine Tools nicht sehen“, „mein MCP-Server wird nicht angezeigt“, „Tools werden in Claude nicht geladen“, „füge einen MCP-Server hinzu“, „mein MCP stellt keine Verbindung her“, „repariere meine Claude Desktop-Konfiguration“, „der Agent antwortet nicht“, „verbinde Ollama / LM Studio“, „starte Claude Desktop neu“. Deckt auch lokale Agent-Gateways wie OpenClaw und Hermes ab.
