Configurez, connectez, validez et réparez les serveurs Claude Desktop et MCP à l'aide de Desktop Commander : inspectez et corrigez mcp.json / claude_desktop_config.json, faites en sorte que les serveurs MCP se connectent et diagnostiquez les outils d'IA locaux. À utiliser lorsqu'un utilisateur souhaite installer, configurer, connecter, valider ou réparer Claude Desktop, un serveur MCP, un fichier de configuration MCP ou un agent/passerelle IA locale. Déclenchez les symptômes qui attirent réellement les gens : "Claude ne voit pas mes outils", "mon serveur MCP n'apparaît pas", "les outils ne se chargent pas dans Claude", "ajouter un serveur MCP", "mon MCP ne se connecte pas", "réparer ma configuration Claude Desktop", "l'agent ne répond pas", "câbler Ollama / LM Studio", "redémarrer Claude Desktop". Couvre également les passerelles d'agents locaux comme OpenClaw et Hermes.
