L'outil de ligne de commande Umeng prend en charge l'appel de toutes les API Umeng via trois méthodes d'authentification (interface de site Web officiel/ancienne OpenAPI/OpenAPI de style cloud Alibaba), couvrant l'analyse mobile, la surveillance des performances, les notifications push, le retour de données, etc. Il est utilisé lorsque les utilisateurs doivent interroger les statistiques Umeng, appeler les interfaces U-APM/U-Push/U-DOP ou gérer les comptes Umeng.
