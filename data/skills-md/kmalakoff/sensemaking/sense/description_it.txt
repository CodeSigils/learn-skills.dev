Interroga un albero di markdown con la CLI di senso: filtra le note in base all'argomento principale, cerca il testo completo nella prosa, segui wikilink/backlink e leggi i contorni delle note. Utilizzare quando l'utente desidera eseguire query, filtrare, contare, cercare o creare report su una cartella di note di markdown, quando è necessario trovare quali note trattano un argomento prima di leggerle, quando si desiderano i backlink o la struttura di una nota, quando una directory ha un sense.config.json o quando viene chiesto di aggiungere una query denominata a una.
