Fragen Sie einen Markdown-Baum mit der Sense-CLI ab – filtern Sie Notizen nach Titel, durchsuchen Sie die Prosa im Volltext, folgen Sie Wikilinks/Backlinks und lesen Sie Notizumrisse. Verwenden Sie diese Option, wenn der Benutzer einen Ordner mit Markdown-Notizen abfragen, filtern, zählen, durchsuchen oder darüber Bericht erstatten möchte, wenn Sie herausfinden müssen, welche Notizen ein Thema behandeln, bevor Sie sie lesen, wenn Sie die Backlinks oder die Struktur einer Notiz benötigen, wenn ein Verzeichnis über eine sense.config.json verfügt oder wenn Sie aufgefordert werden, einer solchen eine benannte Abfrage hinzuzufügen.
