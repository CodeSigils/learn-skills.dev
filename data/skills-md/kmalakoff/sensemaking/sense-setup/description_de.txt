Richten Sie die Sense-CLI für einen Markdown-Baum ein und treffen Sie die Baumdesign-Entscheidungen, die ihn prägen – Sense-Init, Aktivierung von Funktionen (Links, Abschnitte, Rang, Einbettung) und die Kompromisse zwischen Frontmatter-Konventionen, Zusammenfassungen, Ordnerlayout und Notizgröße. Verwenden Sie diese Option, wenn Sie eine Markdown-Wissensdatenbank erstellen oder umstrukturieren, Sense Init ausführen, sense.config.json bearbeiten, die semantische Suche aktivieren oder entscheiden, wie Notizen geschrieben werden sollen, damit ein Agent sie später abfragen kann.
