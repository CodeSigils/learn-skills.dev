قم بتطبيق عوامل إعادة بناء TypeScript الأساسية الخاصة بـ Alan: Promise<Result> → ResultAsync، تبديل/if السلاسل عبر النقابات المملوكة → ts-pattern .exhaustive()، عمليات فحص فارغة متكررة → ربما + مطابقة، رميات → نتيجة ملفوفة بالحدود، IO غير مكتوب → Zod، أنواع الكائنات المضمنة → الأنواع المسماة، IIFEs → المساعدين المسمى. يُستخدم عندما يقول المستخدم "refactor this"، أو "tighten this"، أو "alanstack-ify"، أو "/alanstack-refactor"، أو عندما توصي مراجعة (alanstack-review) بخطوة إعادة بناء معينة.
