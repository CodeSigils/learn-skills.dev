Wenden Sie Alans kanonische TypeScript-Refaktoren an: Promise<Result> → ResultAsync, Switch/if-Ketten über eigene Unions → ts-pattern .exhaustive(), wiederholte Nullprüfungen → Maybe + Match, Würfe → grenzenumschlossenes Ergebnis, untypisiertes IO → Zod, Inline-Objekttypen → benannte Typen, IIFEs → benannte Helfer. Wird verwendet, wenn der Benutzer „refactor this“, „tighten this“, „alanstack-ify“, „/alanstack-refactor“ sagt oder wenn eine Überprüfung (alanstack-review) einen bestimmten Refactor-Umzug empfohlen hat.
