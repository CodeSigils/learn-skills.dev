Примените канонические рефакторинги TypeScript, предложенные Аланом: Promise<Result> → ResultAsync, цепочки switch/if через принадлежащие объединениям → ts-pattern .exhaustive(), повторные проверки на null → Maybe + match, throws → результат с переносом по границе, нетипизированный ввод-вывод → Zod, встроенные типы объектов → именованные типы, IIFE → именованные помощники. Используйте, когда пользователь говорит «рефакторинг этого», «ужесточение этого», «alanstack-ify», «/alanstack-refactor» или когда обзор (alanstack-review) рекомендует конкретный шаг рефакторинга.
