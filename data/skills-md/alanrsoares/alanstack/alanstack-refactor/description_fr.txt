Appliquez les refactors TypeScript canoniques d'Alan : Promise<Result> → ResultAsync, chaînes switch/if sur les unions possédées → ts-pattern .exhaustive(), vérifications nulles répétées → Peut-être + correspondance, lancers → Résultat enveloppé dans les limites, IO non typées → Zod, types d'objets en ligne → types nommés, IIFE → assistants nommés. À utiliser lorsque l'utilisateur dit « refactoriser ceci », « resserrer ceci », « alanstack-ify », « /alanstack-refactor », ou lorsqu'une révision (alanstack-review) recommande un mouvement de refactorisation spécifique.
