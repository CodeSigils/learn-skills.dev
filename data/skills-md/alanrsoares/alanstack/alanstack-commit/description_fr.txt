Écrivez des commits conventionnels selon les règles d'Alan : portée requise, sujet ≤ 50 caractères, mode impératif, corps uniquement lorsque le "pourquoi" n'est pas évident. Aucune attribution d'agent/IA, de pieds de page de co-auteur, de lignes « Généré par <outil> » ou d'emoji. Sélectionne la portée du package ou du domaine touché. À utiliser lorsque l'utilisateur dit « valider », « écrire un commit », « /alanstack-commit », lors de la préparation de modifications ou après un travail de codage nécessitant un message de validation.
