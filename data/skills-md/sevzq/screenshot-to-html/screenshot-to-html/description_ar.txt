قم بنسخ لقطة شاشة/صورة/نموذج بالحجم الطبيعي لواجهة المستخدم في صفحة HTML عالية الدقة ومكتفية ذاتيًا. استنساخ صحيح من صورة إلى HTML / لقطة شاشة إلى رمز يطابق نتيجة RENDERED (لا يتم نسخ الأرقام المحسوبة) من خلال العرض -> لقطة الشاشة -> المقارنة -> حلقة التحسين باستخدام Chrome المحلي. استخدمه عندما يقدم المستخدم صورة/لقطة شاشة/نموذج بالحجم الطبيعي/تصدير Figma ويريد HTML/CSS (عادي أو Tailwind)، أو يطلب "النسخ / إعادة إنشاء / تحويل هذا التصميم إلى صفحة ويب".
