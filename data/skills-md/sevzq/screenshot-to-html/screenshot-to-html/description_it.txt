Replica uno screenshot/immagine/mockup dell'interfaccia utente in una pagina HTML autonoma e ad alta fedeltà. Clonazione fedele da immagine a HTML / screenshot da codice che corrisponde al risultato RENDERED (numeri calcolati non copiati) tramite un ciclo di rendering -> screenshot -> confronta -> perfeziona utilizzando Chrome locale. Utilizzare ogni volta che l'utente fornisce un'immagine/screenshot/mockup/esportazione Figma e desidera HTML/CSS (semplice o Tailwind) o chiede di "creare / modificare / clonare / ricreare / trasformare questo disegno in una pagina Web".
