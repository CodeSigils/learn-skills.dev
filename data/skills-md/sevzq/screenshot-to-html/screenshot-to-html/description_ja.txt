UI スクリーンショット/画像/モックアップを高忠実度の自己完結型 HTML ページに複製します。ローカル Chrome を使用した、レンダリング -> スクリーンショット -> 比較 -> 調整ループを通じて、レンダリングされた結果 (計算された数値をコピーしたものではない) と一致する、画像から HTML への忠実なクローン作成、またはスクリーンショットからコードへのクローン作成。ユーザーが画像/スクリーンショット/モックアップ/Figma エクスポートを提供し、HTML/CSS (プレーンまたは Tailwind) を希望する場合、または「复刻 / 还原 / クローン / 再作成 / このデザインを Web ページに変換する」ように要求する場合は常に使用します。
