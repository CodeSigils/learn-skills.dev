[Триггер] Когда в рабочем процессе PPT требуется проверка качества слайдов SVG через Gemini.
[Выходные данные] Структурированная обзорная оценка с оценками, зачетно/незачетно и предложениями по исправлению.
[Пропустить] Для задач создания контента или генерации SVG (этими занимается Клод).
[Спросить] Ввод пользователя не требуется; вызывается агентом ядра проверки.
[Использование ресурсов] Используйте ссылки/, скрипты/(`scripts/invoke-gemini-ppt.ts`).
