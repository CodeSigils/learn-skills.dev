Writer.skill — an AI engine that distills the styles of famous authors to achieve stylized writing.  
Core mental model: lexical feature mapping, syntactic rhythm reconstruction, rhetorical style mapping.  
Use: as a copy and style coach, input a passage of text and, using the distilled author‑style model, rewrite it in a stylized manner.  
Activate when the user says “rewrite in Hemingway’s style,” “distill Yu Hua’s style,” or “imitate Lu Xun.”
