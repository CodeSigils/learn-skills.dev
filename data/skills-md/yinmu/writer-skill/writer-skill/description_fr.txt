Writer.skill — Distille le style d'auteurs renommés, un moteur d'IA pour une écriture stylisée.  
Modèle mental de base : carte des caractéristiques lexicales, reconstruction du rythme syntaxique, cartographie du style rhétorique.  
Utilisation : sert de coach en rédaction et en style ; saisissez un passage et, en utilisant le modèle de style auteur distillé, réécrivez-le de manière stylisée.  
Appliquez-le lorsque l'utilisateur dit « réécrire dans le style d'Hemingway », « distiller le style de Yu Hua » ou « imiter Lu Xun ».
