La familia de ingeniería rápida: creación, migración, mejora y activación de mensajes para modelos Claude. Úselo cuando el usuario quiera (1) escribir o crear un mensaje, plan o especificación de tarea a partir de un objetivo ("escribir un mensaje para X", "convertir esto en algo que Fable 5 pueda ejecutar"), (2) actualizar o transferir un mensaje existente a Fable 5 ("actualizar este mensaje para Fable 5", "esto fue ajustado para sonnet/opus", "fablizar esto"), (3) mejorar un mensaje existente que permanece en Sonnet u Opus ("mejorar este mensaje sin cambiar de modelo", "fabelike esto"), (4) revisar, auditar, calificar o bloquear un mensaje antes de una ejecución costosa ("¿está listo para Fable 5?", "auditar este mensaje"), (5) elevar una solicitud a un objetivo bien especificado (/hasta), o (6) habilitar el comando de barra diagonal /hasta ("/fabble install", "configurar el comando fabble"). Cada trabajo conduce a un libro de referencias/playbook.
