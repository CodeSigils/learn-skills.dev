Cloud FinOps CLI pour l'analyse des coûts, la détection des anomalies, la découverte des ressources et l'optimisation. À utiliser lorsque l'utilisateur a besoin d'analyser les coûts du cloud, de rechercher des anomalies de coûts, de comparer les périodes de dépenses, de découvrir des ressources cloud, de générer des rapports de coûts ou d'effectuer toute tâche d'opérations financières dans le cloud. Se déclenche sur des requêtes telles que « analyser les coûts AWS », « rechercher les pics de coûts », « afficher les principaux services par dépenses », « comparer ce mois-ci avec le mois dernier », « répertorier les ressources cloud », « générer un rapport sur les coûts », « sur quoi je dépense », « y a-t-il des anomalies de coûts », « afficher les tendances des coûts » ou toute tâche d'optimisation des coûts du cloud.
