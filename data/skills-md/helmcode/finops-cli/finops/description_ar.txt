Cloud FinOps CLI لتحليل التكلفة واكتشاف الحالات الشاذة واكتشاف الموارد وتحسينها. يُستخدم عندما يحتاج المستخدم إلى تحليل تكاليف السحابة، أو العثور على حالات شاذة في التكلفة، أو مقارنة فترات الإنفاق، أو اكتشاف موارد السحابة، أو إنشاء تقارير التكلفة، أو تنفيذ أي مهمة للعمليات المالية السحابية. مشغلات لطلبات مثل "تحليل تكاليف AWS"، أو "العثور على ارتفاعات التكلفة"، أو "إظهار أفضل الخدمات حسب الإنفاق"، أو "مقارنة هذا الشهر بالشهر الماضي"، أو "إدراج الموارد السحابية"، أو "إنشاء تقرير تكلفة"، أو "ما الذي أنفق عليه"، أو "هل هناك أي حالات شاذة في التكلفة"، أو "إظهار اتجاهات التكلفة"، أو أي مهمة لتحسين تكلفة السحابة.
