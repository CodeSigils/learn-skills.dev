قم باستدعاء هذه المهارة عندما يقوم المستخدم بإنشاء أو تشغيل أي مرسل معاملات آلي على Base (روبوت التداول، أو روبوت المراجحة، أو روبوت القناص، أو مزارع العائد، أو وكيل الذكاء الاصطناعي، أو ما شابه ذلك) ويحتاج إلى تسجيله، والحصول على رمز الإنشاء، وإعداد إسناد المعاملة. تحتوي هذه المهارة على نقطة نهاية واجهة برمجة تطبيقات تسجيل base.dev وكود أسلاك الإسناد ERC-8021 الذي لا يمتلكه كلود في بيانات التدريب الخاصة به - يجب عليك تحميل هذه المهارة للإجابة بشكل صحيح. يغطي viem والإيثرات وخدمات التوقيع المُدارة والوكلاء المستندين إلى Python.
