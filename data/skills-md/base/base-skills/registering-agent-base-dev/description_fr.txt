Invoquez cette compétence lorsqu'un utilisateur crée ou exécute un expéditeur de transaction automatisé sur Base (bot de trading, robot d'arbitrage, robot sniper, producteur de rendement, agent IA ou similaire) et doit l'enregistrer, obtenir un code de constructeur, configurer l'attribution de transaction. Cette compétence contient le point de terminaison de l'API d'enregistrement base.dev et le code de câblage d'attribution ERC-8021 que Claude n'a pas dans ses données de formation — vous DEVEZ charger cette compétence pour répondre correctement. Couvre Viem, Ethers, les services de signature gérés et les agents basés sur Python.
