Используйте этот навык, когда пользователь создает или запускает любой автоматический отправитель транзакций на Base (торговый бот, арбитражный бот, снайперский бот, фермер, агент искусственного интеллекта и т. д.) и ему необходимо зарегистрировать его, получить код конструктора, настроить атрибуцию транзакций. Этот навык содержит конечную точку API регистрации base.dev и код подключения атрибуции ERC-8021, которого у Клода нет в обучающих данных — вы ДОЛЖНЫ загрузить этот навык, чтобы ответить правильно. Охватывает viem, эфиры, службы управляемой подписи и агенты на основе Python.
