ユーザーが Base 上で自動トランザクション センダー (トレーディング ボット、アービトラージ ボット、スナイパー ボット、イールド ファーマー、AI エージェントなど) を構築または実行しており、それを登録し、ビルダー コードを取得し、トランザクション アトリビューションを設定する必要がある場合に、このスキルを呼び出します。このスキルには、base.dev 登録 API エンドポイントと、クロードのトレーニング データに含まれていない ERC-8021 属性配線コードが含まれています。正しく回答するには、このスキルをロードする必要があります。 viem、ethers、マネージド署名サービス、Python ベースのエージェントをカバーします。
