Validieren und überprüfen Sie Basis-MCP-Plugin-Dateien anhand der Plugin-Spezifikation. Verwenden Sie diese Option, wenn Sie ein neues Plugin schreiben, eine Plugin-PR für die Einreichung vorbereiten, ein Plugin vor dem Öffnen einer PR selbst überprüfen oder die Plugin-PR einer anderen Person überprüfen. Wird bei Anfragen wie „Überprüfe mein Plugin anhand der Spezifikation“, „Validiere diese Plugin-Datei“, „Überprüfe die PR meines Plugins“, „Entspricht dieses Plugin der Spezifikation“, „bereite mein Plugin für die Übermittlung vor“ und „schreibe ein Plugin für das X-Protokoll“ ausgelöst.
