Проверьте и проверьте файлы подключаемого модуля Base MCP на соответствие спецификации подключаемого модуля. Используйте при написании нового плагина, подготовке PR плагина к отправке, самостоятельной проверке плагина перед открытием PR или просмотре PR чужого плагина. Запускается по таким запросам, как «проверить мой плагин на соответствие спецификации», «проверить этот файл плагина», «проверить PR моего плагина», «соответствует ли этот плагин спецификации», «подготовить мой плагин к отправке», «написать плагин для протокола X».
