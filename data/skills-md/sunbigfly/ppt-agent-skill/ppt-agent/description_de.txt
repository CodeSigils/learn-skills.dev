KI-gestützter Assistent für die vollständige Erstellung professioneller Präsentationsdecks. Imitiert den kompletten Arbeitsablauf erstklassiger Agenturen für Präsentationsdesign – von der Anforderungsrecherche über die Inhaltserfassung und Gliederungsplanung bis hin zur Entwurfserstellung und dem endgültigen Design – und liefert eine hochwertige Diashow im HTML-Format. Wird immer dann ausgelöst, wenn der Benutzer erwähnt, dass er eine PPT, eine Präsentation, Folien, eine Diashow, Berichtsmaterialien, Schulungsmaterialien, ein Roadshow-Deck oder Produkteinführungsseiten erstellt. Wird auch dann aktiviert, wenn der Benutzer nur sagt: „Machen Sie mir eine Einführung zu X“ oder „Ich muss Y meinem Chef melden“, sofern strukturierter mehrseitiger Inhalt impliziert ist. Gilt auch, wenn der Benutzer sagt „Dieses Dokument in eine PPT umwandeln“ oder „Dieses Thema in eine Präsentation umwandeln“, d. h. jedes Szenario, das die Konvertierung von Inhalten in ein Präsentationsformat erfordert.
