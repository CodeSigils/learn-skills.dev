مولد عملية كاملة مدعوم بالذكاء الاصطناعي لعروض PPT التقديمية الاحترافية. يحاكي سير العمل الكامل لوكالات تصميم PPT من الدرجة الأولى (يحتاج إلى بحث ← جمع البيانات ← التخطيط التفصيلي ← نسخة المسودة ← التصميم النهائي) ويخرج شرائح بتنسيق HTML عالية الجودة. يتم تشغيله عندما يذكر المستخدم إنشاء ملف PPT أو عرض تقديمي أو شرائح أو عرض شرائح أو مواد تقارير أو برامج تعليمية تدريبية أو مجموعة عروض ترويجية أو صفحات مقدمة للمنتج. يتم التنشيط حتى إذا قال المستخدم ببساطة "اجعلني مقدمة عن X" أو "أحتاج إلى إبلاغ مديري بـ Y"، طالما كان المحتوى المنظم متعدد الصفحات ضمنيًا. ينطبق أيضًا عندما يطلب المستخدم "تحويل هذا المستند إلى ملف PPT" أو "إنشاء عرض تقديمي خارج هذا الموضوع"، أي أي طلب لتحويل المحتوى إلى تنسيق عرض تقديمي.
