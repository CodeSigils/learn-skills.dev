Generador de proceso completo impulsado por IA para presentaciones PPT profesionales. Imita el flujo de trabajo completo de las agencias de diseño PPT de primer nivel (necesita investigación → recopilación de datos → planificación del esquema → borrador → diseño final) y genera diapositivas en formato HTML de alta calidad. Se activa cada vez que el usuario menciona la creación de un PPT, una presentación, diapositivas, presentaciones de diapositivas, materiales de informes, cursos de capacitación, presentaciones itinerantes o páginas de introducción de productos. Se activa incluso si el usuario simplemente dice "Hazme una introducción sobre X" o "Necesito informar Y a mi jefe", siempre que esté implícito contenido estructurado de varias páginas. También se aplica cuando el usuario solicita “convertir este documento en un PPT” o “hacer una presentación a partir de este tema”, es decir, cualquier solicitud para convertir contenido a formato de presentación.
