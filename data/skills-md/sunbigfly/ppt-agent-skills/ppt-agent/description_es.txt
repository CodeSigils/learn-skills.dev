Generador de proceso completo impulsado por IA para presentaciones PPT profesionales. Replica el flujo de trabajo completo de una empresa de diseño PPT de primer nivel, desde el análisis de necesidades, la investigación y la descripción hasta la redacción y el diseño, y ofrece una presentación HTML de alta calidad. Se activa cada vez que un usuario menciona la creación de un PPT, presentación, diapositivas, presentación de diapositivas, presentación de informes, presentación de capacitación, presentación de propuestas o páginas de introducción de productos. Incluso si el usuario simplemente dice "hazme una introducción sobre X" o "Necesito informar Y a mi jefe", siempre que implique una presentación estructurada de varias páginas, esta habilidad se activa. También se aplica cuando los usuarios solicitan "convertir este documento en un PPT", "hacer una presentación sobre este tema", etc. También funciona en inglés: "hacer una presentación sobre...", "crear diapositivas para...", "crear una presentación", "Necesito una nota clave para...". La intención implícita también cuenta: "visualizar estos datos para mi jefe", "necesito algo para presentar a los inversores", "hacer presentable este informe", "embellecer mi PPT existente", "rediseñar estas diapositivas". También se cubre la mejora o embellecimiento de los PPT existentes.
