Asistente de proceso completo impulsado por IA para presentaciones profesionales. Replica el flujo de trabajo completo de las empresas de diseño de presentaciones de primer nivel, desde la investigación de necesidades y la recopilación de datos hasta el esquema, la redacción y el diseño visual, y ofrece diapositivas en formato HTML de alta calidad. Se activa cada vez que el usuario menciona la creación de un PPT, presentación, diapositivas, presentación de diapositivas, informe, presentación de capacitación, presentación de propuestas o páginas de introducción de productos. Se activa incluso para solicitudes implícitas como "hazme una introducción sobre X", "ayúdame a presentar Y a mi jefe", "convierte este documento en un PPT" o "embellece mis diapositivas existentes". También responde a indicaciones en inglés: "hacer una presentación sobre...", "crear diapositivas para...", "crear una presentación", "necesito una conferencia magistral para...", etc.
