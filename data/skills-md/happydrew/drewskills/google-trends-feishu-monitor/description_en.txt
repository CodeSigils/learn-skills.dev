Execute the fixed Google Trends keyword monitoring workflow on the Feishu workbook. It is used to run, resume, and stabilize the periodic monitoring task from Google Trends to Feishu's "Daily Keyword Discovery." This skill only handles the monitoring workflow itself, including Trends data collection, surge keyword filtering, comparison and judgment against `GPTs`, writing back to Feishu, and orchestration of run logs/checkpoints; it does not handle browser environment installation, proxy installation/switching, or Feishu tool initialization.
