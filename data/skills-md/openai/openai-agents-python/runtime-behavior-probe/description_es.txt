Planifique y ejecute investigaciones de comportamiento en tiempo de ejecución con scripts de sondeo temporales, matrices de validación, controles de estado e informes de hallazgos primero. Úselo solo cuando el usuario invoque explícitamente esta habilidad para verificar el comportamiento real en tiempo de ejecución más allá de las comprobaciones normales a nivel de código, especialmente para descubrir casos extremos, comportamientos no documentados o modos de falla comunes en integraciones locales o en vivo. Una verificación de humo de referencia está bien como punto de entrada, pero no se detenga en la confirmación del camino feliz.
