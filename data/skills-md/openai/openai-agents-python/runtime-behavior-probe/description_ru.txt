Планируйте и выполняйте исследования поведения во время выполнения с помощью временных сценариев проверки, матриц проверки, средств контроля состояния и отчетов, ориентированных на результаты. Используйте только тогда, когда пользователь явно вызывает этот навык для проверки фактического поведения во время выполнения, выходящего за рамки обычных проверок на уровне кода, особенно для выявления крайних случаев, недокументированного поведения или распространенных режимов сбоя в локальных или интерактивных интеграциях. Базовая проверка дыма подойдет в качестве отправной точки, но не останавливайтесь на подтверждении счастливого пути.
