Pianifica ed esegui indagini sul comportamento in fase di esecuzione con script di sonda temporanei, matrici di convalida, controlli di stato e report sui risultati. Utilizzare solo quando l'utente richiama esplicitamente questa capacità per verificare il comportamento effettivo del runtime oltre i normali controlli a livello di codice, in particolare per scoprire casi limite, comportamenti non documentati o modalità di errore comuni nelle integrazioni locali o live. Un controllo del fumo di base va bene come punto di ingresso, ma non fermarti alla conferma del percorso felice.
