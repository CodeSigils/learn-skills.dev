قم بإنشاء دلائل المكونات الإضافية ودعمها لـ Codex باستخدام ".codex-plugin/plugin.json"، ومجلدات/ملفات المكونات الإضافية الاختيارية، والعناصر النائبة الأساسية التي يمكنك تحريرها قبل النشر أو الاختبار. يُستخدم عندما يحتاج Codex إلى إنشاء مكون إضافي محلي جديد، أو إضافة بنية مكون إضافي اختياري، أو إنشاء أو تحديث إدخالات repo-root `.agents/plugins/marketplace.json` لطلب المكونات الإضافية وبيانات تعريف التوفر.
