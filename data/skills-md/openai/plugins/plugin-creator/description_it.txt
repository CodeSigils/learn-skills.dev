Crea e impalcature di directory di plugin per Codex con un `.codex-plugin/plugin.json` richiesto, cartelle/file di plugin opzionali e segnaposto di base che puoi modificare prima della pubblicazione o del test. Da utilizzare quando Codex deve creare un nuovo plug-in locale, aggiungere una struttura di plug-in opzionale o generare o aggiornare le voci `.agents/plugins/marketplace.json` del repository per l'ordine dei plug-in e i metadati di disponibilità.
