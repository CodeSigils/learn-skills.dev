Esegui un digest dei problemi di GitHub per openai/codex in base alle etichette delle aree delle funzionalità, a tutte le aree e alle finestre temporali configurabili. Da utilizzare quando viene richiesto di riassumere le recenti segnalazioni di bug del Codex o le richieste di miglioramento, in particolare per etichette specifiche del proprietario come tui, exec, app o aree simili.
