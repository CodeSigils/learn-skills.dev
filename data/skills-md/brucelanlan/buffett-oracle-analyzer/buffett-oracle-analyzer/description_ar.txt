مجموعة مهارات تحليلية متعمقة للشركات المدرجة التي تدمج فلسفة وارن بافيت الاستثمارية مع أطر عمل حديثة متعددة الأبعاد، تغطي أسهم الولايات المتحدة وهونج كونج والأسهم A. يتم تشغيله عندما يطلب المستخدم تحليل شركة أو سهم أو مؤشر أو فرصة استثمارية. يشمل: تحليل الخلفية، تقييم الإدارة، نموذج الأعمال، تقييم الخندق، المراجعة المالية العميقة (تتبع أربعة أرباع + صحة الميزانية العمومية + جودة التدفق النقدي)، تدقيق مكالمات الأرباح (الأحدث بالإضافة إلى الربعين السابقين)، تقييم ثمانية نماذج (DCF، النسبي، PEG، DDM، NAV، مجموع الأجزاء، أرباح المالك، عكس DCF)، المشهد التنافسي، التحليل الفني والشموع (الاتجاه، المتوسطات المتحركة، مؤشر القوة النسبية، MACD، بولينجر، فيبوناتشي، توزيع الرقائق)، مصفوفة المخاطر، بطاقة أداء بافيت، ونصائح الشراء / البيع / تحديد المواقع القابلة للتنفيذ مع أهداف السعر.
