مهارات تحليلية متعمقة للشركات المدرجة التي تدمج فلسفة بافيت الاستثمارية مع إطار عمل حديث متعدد الأبعاد. يغطي الأسهم الأمريكية، وأسهم هونج كونج، والأسهم A. يتم تشغيله عندما يطلب المستخدم تحليل شركة أو سهم أو مؤشر أو فرصة استثمارية. يشمل: تحليل الخلفية، تقييم الإدارة، نموذج الأعمال، تحليل الخندق، البيانات المالية المتعمقة (تتبع الأربعة أرباع + صحة الميزانية العمومية + جودة التدفق النقدي)، مراجعة استدعاء الأرباح (الأخير + الربعين السابقين)، تقييم متعدد النماذج (DCF، النسبي، PEG، DDM، NAV، مجموع الأجزاء، أرباح المالك، عكس DCF - 8 في المجموع)، المشهد التنافسي، التحليل الفني والشموع (الاتجاه، المتوسطات المتحركة، RSI، MACD، بولينجر، فيبوناتشي، توزيع الرقائق)، مصفوفة المخاطر، بطاقة أداء بافيت، بالإضافة إلى نصائح الشراء/البيع/الاحتفاظ القابلة للتنفيذ، وحجم المركز، والسعر المستهدف.
