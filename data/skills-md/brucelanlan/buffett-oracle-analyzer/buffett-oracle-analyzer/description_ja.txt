ウォーレン・バフェットの投資哲学と現代の多次元フレームワークを融合した、上場企業のための詳細な分析スキル。米国、香港、A 株をカバーします。ユーザーが企業、株式、ティッカー、または投資機会の分析をリクエストするたびにトリガーされます。内容: 背景調査、経営評価、ビジネスモデル、堀分析、詳細な財務レビュー (4 四半期の追跡 + 貸借対照表の健全性 + キャッシュフローの質)、決算報告分析 (最新 + 過去 2 四半期)、8 つのモデル評価 (DCF、相対、PEG、DDM、NAV、部分合計、オーナー収益、逆 DCF)、競争環境、テクニカルおよびローソク足分析 (トレンド、移動平均、RSI、MACD、ボリンジャー、フィボナッチ、チップ分布）、リスク マトリックス、バフェット スコアカードに加え、目標価格とポジションサイジングを含む実用的な買い/売り/ホールドのアドバイス。
