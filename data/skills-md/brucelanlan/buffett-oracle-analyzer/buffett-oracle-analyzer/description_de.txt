Umfassende Analysefähigkeiten für börsennotierte Unternehmen, die Buffetts Anlagephilosophie mit einem modernen mehrdimensionalen Rahmen verbinden. Deckt US-Aktien, Hongkong-Aktien und A-Aktien ab. Wird ausgelöst, wenn ein Benutzer eine Analyse eines Unternehmens, einer Aktie, eines Tickers oder einer Investitionsmöglichkeit anfordert. Beinhaltet: Hintergrundanalyse, Managementbewertung, Geschäftsmodell, Moat-Analyse, detaillierte Finanzdaten (4-Quartal-Verfolgung + Bilanzgesundheit + Cashflow-Qualität), Ergebnisbericht (letzte + vorherige zwei Quartale), Multi-Modell-Bewertung (DCF, relativ, PEG, DDM, NAV, Summe der Teile, Eigentümereinkommen, umgekehrter DCF – insgesamt 8), Wettbewerbslandschaft, technische Analyse und Candlestick-Analyse (Trend, gleitende Durchschnitte, RSI, MACD, Bollinger, Fibonacci, Chip-Verteilung), Risikomatrix, Buffett-Scorecard sowie umsetzbare Kauf-/Verkaufs-/Halteempfehlungen, Positionsgrößenbestimmung und Kursziel.
