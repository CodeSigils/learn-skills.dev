Tiefgreifende analytische Fähigkeiten für börsennotierte Unternehmen, die Buffetts Anlagephilosophie mit einem modernen mehrdimensionalen Rahmen verbinden. Deckt US-, Hongkong- und A-Aktien ab. Wird immer dann ausgelöst, wenn ein Benutzer eine Analyse eines Unternehmens, einer Aktie, eines Tickers oder einer Investitionsmöglichkeit anfordert. Beinhaltet: Hintergrundanalyse, Managementbewertung, Geschäftsmodell, Moat-Analyse, detaillierte Finanzdaten (Vier-Quartals-Verfolgung + Bilanzgesundheit + Cashflow-Qualität), Ergebnisbericht (letzte + vorherige zwei Quartale), Acht-Modell-Bewertung (DCF, relativ, PEG, DDM, NAV, Summe der Teile, Eigentümereinkommen, umgekehrter DCF), Wettbewerbslandschaft, technische Analyse und Candlestick-Analyse (Trend, gleitende Durchschnitte, RSI, MACD, Bollinger, Fibonacci, Chipverteilung), Risiko Matrix, Buffett-Scorecard sowie umsetzbare Kauf-/Verkaufs-/Halte- und Positionsgrößenempfehlungen mit Kurszielen.
