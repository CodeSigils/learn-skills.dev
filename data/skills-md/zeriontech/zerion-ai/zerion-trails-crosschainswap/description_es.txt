Intercambios de tokens entre cadenas hacia y desde Polygon (chainId 137) utilizando el SDK de Trails, con Zerion CLI en la parte superior para verificación de fondos y cartera. Úselo cuando el usuario quiera conectar o intercambiar tokens entre cadenas donde Polygon es el origen o el destino, p. 'intercambiar ETH en Ethereum a USDC en Polygon', 'puentear USDC de Arbitrum a Polygon' o 'intercambiar a POL desde cualquier cadena'. Admite modos de integración de widget (interfaz de usuario de React integrada), ganchos sin cabeza (UX personalizado) y API directa (del lado del servidor).
