Trails SDK を使用して Polygon (chainId 137) との間でクロスチェーン トークン スワップを行い、資金調達とポートフォリオ チェックには Zerion CLI を使用します。ユーザーが、Polygon がソースまたは宛先であるチェーン間でトークンをブリッジまたはスワップしたい場合に使用します。 「イーサリアムのETHをポリゴンのUSDCにスワップ」、「ArbitrumからポリゴンにUSDCをブリッジ」、または「任意のチェーンからPOLにスワップ」。ウィジェット (ドロップイン React UI)、ヘッドレス フック (カスタム UX)、およびダイレクト API (サーバー側) 統合モードをサポートします。
