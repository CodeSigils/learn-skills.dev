Kettenübergreifender Token-Austausch zu und von Polygon (chainId 137) mithilfe des Trails SDK, mit Zerion CLI an der Spitze für Finanzierungs- und Portfolioprüfungen. Verwenden Sie diese Option, wenn der Benutzer Token über Ketten hinweg überbrücken oder austauschen möchte, bei denen Polygon die Quelle oder das Ziel ist – z. B. „ETH auf Ethereum zu USDC auf Polygon tauschen“, „USDC von Arbitrum zu Polygon überbrücken“ oder „von einer beliebigen Kette zu POL tauschen“. Unterstützt die Integrationsmodi Widget (Drop-in React UI), Headless Hooks (benutzerdefinierte UX) und Direct API (serverseitig).
