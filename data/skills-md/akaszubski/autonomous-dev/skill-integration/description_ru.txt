Шаблоны для обнаружения навыков агентов, ссылок и составления с использованием архитектуры прогрессивного раскрытия. Используйте при создании агентов, формировании навыков или оптимизации использования контекста. ЗАПУСКАЕТСЯ, когда: обнаружение навыков, интеграция агентов, формирование навыков, постепенное раскрытие. НЕ ЗАПУСКАТЬ, когда: реализация функций, написание тестов, изменения только в документации.
