Best practice per la progettazione dell'API REST che coprono il controllo delle versioni, la gestione degli errori, l'impaginazione e la documentazione OpenAPI. Da utilizzare durante la progettazione o l'implementazione di API REST o endpoint HTTP. TRIGGER quando: progettazione API, endpoint REST, percorso HTTP, OpenAPI, spavalderia, impaginazione. NON SI ATTIVA quando: codice della libreria interna, strumenti CLI, interfacce non HTTP.
