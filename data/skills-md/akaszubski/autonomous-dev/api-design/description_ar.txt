REST API design best practices covering versioning, error handling, pagination, and OpenAPI documentation. يُستخدم عند تصميم أو تنفيذ REST APIs أو نقاط نهاية HTTP. يتم التشغيل عندما: تصميم واجهة برمجة التطبيقات (API)، ونقطة نهاية REST، ومسار HTTP، وOpenAPI، والتباهي، وترقيم الصفحات. لا تقم بالتشغيل عندما: كود المكتبة الداخلي، أدوات CLI، واجهات غير HTTP.
