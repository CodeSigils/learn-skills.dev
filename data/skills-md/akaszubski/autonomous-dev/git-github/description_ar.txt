أنماط سير عمل Git وGitHub بما في ذلك الالتزامات التقليدية، وتسمية الفروع، وسير عمل العلاقات العامة، واستخدام gh CLI. يُستخدم عند إنشاء الالتزامات أو الفروع أو طلبات السحب. يتم تشغيله عندما: التزام git، فرع، PR، طلب سحب، دمج، gh cli. لا يتم تشغيله عندما: تنفيذ التعليمات البرمجية، أو الاختبار، أو التوثيق بدون عمليات git.
