Standard di documentazione che impongono il formato Keep a Changelog, la struttura README, i modelli ADR e le docstring in stile Google. Da utilizzare durante la scrittura di voci CHANGELOG, l'aggiornamento di README o la documentazione delle API. TRIGGER quando: changelog, readme, documentazione, docstring, ADR, documenti API. NON ATTIVARE quando: modifiche di solo codice, file di test, aggiornamenti di configurazione senza modifiche API.
