Normes de documentation appliquant le format Keep a Changelog, la structure README, les modèles ADR et les docstrings de style Google. À utiliser lors de l'écriture d'entrées CHANGELOG, de la mise à jour des README ou de la documentation des API. DÉCLENCHEMENT quand : journal des modifications, fichier Lisez-moi, documentation, docstring, ADR, documentation API. NE PAS DÉCLENCHER lorsque : des modifications de code uniquement, des fichiers de test, des mises à jour de configuration sans modifications de l'API.
