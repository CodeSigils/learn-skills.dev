Стандарты документации, обеспечивающие сохранение формата журнала изменений, структуры README, шаблонов ADR и строк документации в стиле Google. Используйте при написании записей CHANGELOG, обновлении README или документировании API. ЗАПУСКАЕТСЯ, когда: журнал изменений, файл readme, документация, строка документации, ADR, документация по API. НЕ ЗАПУСКАТЬ, когда: изменения только кода, тестовые файлы, обновления конфигурации без изменений API.
