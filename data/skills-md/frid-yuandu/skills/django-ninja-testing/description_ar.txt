كتابة اختبارات نقطة نهاية Django Ninja API واستكشاف الأخطاء وإصلاحها. يُستخدم عندما يطلب المستخدم كتابة اختبارات لواجهات برمجة تطبيقات Django Ninja، أو يواجه TestClient ConfigError، أو يحتاج إلى اختبار نقاط النهاية المعتمدة، أو يريد أنماط اختبار لأجهزة توجيه/عمليات ninja، أو يحتاج إلى تشخيص خطأ وقت تشغيل Django/Ninja، أو يريد تدقيق تغطية الاختبار.
