Impalcatura degli endpoint API Django Ninja con adeguata separazione dei livelli di servizio, wrapper di risposta di risposta, gerarchie di eccezioni e scheletri di test per il progetto della piattaforma di supporto dati. Da utilizzare quando l'utente chiede di implementare un nuovo endpoint API, creare un percorso RESTful, progettare schemi di richiesta/risposta, pianificare una funzionalità API o aggiungere operazioni CRUD.
