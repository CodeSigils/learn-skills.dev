نقاط نهاية Scaffold Django Ninja API مع فصل طبقة الخدمة المناسب، وأغلفة استجابة الرد، والتسلسلات الهرمية للاستثناءات، وهياكل الاختبار لمشروع منصة دعم البيانات. يُستخدم عندما يطلب المستخدم تنفيذ نقطة نهاية API جديدة، أو إنشاء مسار RESTful، أو تصميم مخططات الطلب/الاستجابة، أو التخطيط لميزة API، أو إضافة عمليات CRUD.
