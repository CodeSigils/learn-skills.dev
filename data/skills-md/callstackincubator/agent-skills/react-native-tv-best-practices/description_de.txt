Testet React Native TV-Apps für Fokus/D-Pad-Navigation, 10-Fuß-UI-Layout, TV-Wiedergabe/DRM-Integration, TV-Leistung bei geringem Speicher und TV-Zugänglichkeit. Verwenden Sie diese Option beim Erstellen, Debuggen oder Überprüfen von React-Native-TVOS-, Expo TV-, Amazon Vega/Kepler- oder React Native-Web-TV-Zielen, bei denen das Problem von der Remote-Eingabe, dem TV-Fokus, der TV-Verpackung, der TV-Hardware oder den Einschränkungen bei der TV-Wiedergabe abhängt.
