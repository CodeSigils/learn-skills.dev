Valuta se e come un prodotto mobile esistente dovrebbe migrare a React Native. Da utilizzare durante il controllo di uno o più repository di prodotti per la preparazione alla migrazione, inclusi prodotti i cui client iOS, Android e altri risiedono in directory o repository separati; scegliendo brownfield, greenfield o un percorso basato su checkpoint; definizione di un processo rappresentativo; o preparare una decisione di riferimento e sul ROI prima dell'implementazione. Quando la portata del prodotto o le prove materiali non sono disponibili, interroga lo stakeholder esattamente con una domanda per turno invece di inviare un questionario.
