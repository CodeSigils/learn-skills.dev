Wird verwendet, wenn Sie ein oder mehrere Produktrepositorys auf Migrationsbereitschaft prüfen, einschließlich Produkten, deren iOS-, Android- und andere Clients in separaten Verzeichnissen oder Repositories gespeichert sind. Wählen Sie Brownfield, Greenfield oder einen Checkpoint-basierten Pfad. Definition eines repräsentativen Prozesses; oder Vorbereiten einer Baseline- und ROI-Entscheidung vor der Implementierung.
