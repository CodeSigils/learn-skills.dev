تدقيق نشاط محفظة Pharos وجاهزيتها من خلال فحوصات للقراءة فقط. يُستخدم عندما يطلب المستخدم تقرير نشاط محفظة Pharos، أو التحقق من تقدم شبكة الاختبار أو الشبكة الرئيسية، أو مقارنة Pharos عبر الشبكات، أو ملخص صحة المحفظة، أو فحص رصيد الرمز المميز المعروف، أو مراجعة عدم النشاط/النشاط، أو التحقق من جاهزية الغاز، أو تدقيق دفعة المحفظة المتعددة أو ملف CSV، أو تصدير ملف CSV، أو تدقيق نمط الأهلية لاستخدام Pharos onchain. لا تطلب أبدًا مفاتيح خاصة؛ تؤدي هذه المهارة فقط عمليات قراءة JSON-RPC العامة والمستكشف الاختياري.
