يتفاعل مع مشاريع RHDH Jira (RHIDP، RHDHPLAN، RHDHBUGS، RHDHSUPP) باستخدام acli، GraphQL، وREST API. يُستخدم عندما يحتاج المستخدم إلى البحث عن مشكلات Jira الخاصة بـ RHDH أو إنشائها أو عرضها أو تحريرها أو نقلها أو تعيينها أو تحسينها أو الإبلاغ عنها. استخدم أيضًا لتخطيط السباق السريع، أو مراجعات السباق السريع، أو الاستعداد للإصدار، أو توصيات المكلفين، أو تحسين المشكلة. تشغيل مفاتيح إصدار Jira (RHIDP-1234، RHDHPLAN-567)، الإعداد لحفل الركض السريع، "من يجب أن يأخذ هذا"، "تحسين هذا"، "التخطيط للسباق السريع"، "تقرير الركض السريع"، "كيف يبدو الإصدار"، أو "حالة الإصدار".
