Riferimento completo per la CLI e l'API Northflank: gestione di servizi, lavori, componenti aggiuntivi, progetti, variabili di ambiente, distribuzioni, domini, segreti, modelli e tutte le altre risorse Northflank. Utilizza questa abilità in modo PROATTIVO ogni volta che l'utente menziona Northflank, distribuisce a Northflank, la CLI `northflank`, le chiamate API Northflank o gestisce qualsiasi risorsa Northflank (servizi, componenti aggiuntivi, progetti, variabili di ambiente, domini, modelli, ecc.). Da utilizzare anche quando l'utente lavora con Northflank anche se non dice esplicitamente "Northflank", ad esempio se fa riferimento a un ID progetto Northflank, a un ID servizio o utilizza modelli come `--projectId` o parla di ambienti runtime sulla propria piattaforma di distribuzione.
