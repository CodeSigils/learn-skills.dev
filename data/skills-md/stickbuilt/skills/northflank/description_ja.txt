Northflank CLI および API の包括的なリファレンス — サービス、ジョブ、アドオン、プロジェクト、環境変数、デプロイメント、ドメイン、シークレット、テンプレート、およびその他すべての Northflank リソースの管理。ユーザーが Northflank に言及した場合、Northflank へのデプロイ、「northflank」 CLI、Northflank API 呼び出し、または Northflank リソース (サービス、アドオン、プロジェクト、環境変数、ドメイン、テンプレートなど) の管理を行った場合には、このスキルを積極的に使用してください。また、ユーザーが「Northflank」と明示的に言わなくても、Northflank を使用しているときにも使用します。たとえば、Northflank プロジェクト ID やサービス ID を参照する場合、「--projectId」のようなパターンを使用する場合、またはデプロイメント プラットフォーム上のランタイム環境について話す場合などです。
