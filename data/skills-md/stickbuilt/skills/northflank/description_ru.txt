Комплексный справочник по CLI и API Northflank — управление службами, заданиями, надстройками, проектами, переменными окружения, развертываниями, доменами, секретами, шаблонами и всеми другими ресурсами Northflank. Используйте этот навык ПРОАКТИВНО всякий раз, когда пользователь упоминает Northflank, развертывание в Northflank, CLI `northflank`, вызовы API Northflank или управление любыми ресурсами Northflank (сервисами, надстройками, проектами, переменными окружения, доменами, шаблонами и т. д.). Также используйте, когда пользователь работает с Northflank, даже если он не говорит «Northflank» явно — например, если он ссылается на идентификатор проекта Northflank, идентификатор службы или использует такие шаблоны, как `--projectId`, или говорит о средах выполнения на своей платформе развертывания.
