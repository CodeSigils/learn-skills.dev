Используйте, когда пользователь хочет проверить данные компании или клиента, которые находятся за Velen, запустить специальный SQL-код только для чтения для источника, подключенного к Velen, проверить или расширить известную информацию Velen по общедоступному идентификатору или управлять памятью схемы знаний на уровне организации через Velen. Не используйте для локальных баз данных, прямых учетных данных или работы SQL в обход контроля доступа Velen.
