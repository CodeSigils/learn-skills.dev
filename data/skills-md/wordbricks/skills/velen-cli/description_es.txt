Úselo cuando el usuario desee inspeccionar los datos de la empresa o del cliente que se encuentran detrás de Velen, ejecutar SQL ad hoc de solo lectura en una fuente conectada a Velen, verificar o ampliar una información conocida de Velen mediante ID pública o administrar la memoria de Knowledge Graph con ámbito de organización a través de Velen. No lo utilice para bases de datos locales, credenciales directas o trabajos SQL que eludan los controles de acceso de Velen.
