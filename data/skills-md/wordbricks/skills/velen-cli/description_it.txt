Da utilizzare quando l'utente desidera ispezionare i dati dell'azienda o del cliente che risiedono dietro Velen, eseguire SQL ad hoc di sola lettura su un'origine connessa a Velen, verificare o estendere un insight noto di Velen tramite ID pubblico o gestire la memoria del Knowledge Graph a livello di organizzazione tramite Velen. Non utilizzare per database locali, credenziali dirette o lavori SQL che ignorano i controlli di accesso Velen.
