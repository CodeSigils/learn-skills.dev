À utiliser lorsque l'utilisateur souhaite inspecter les données de l'entreprise ou des clients qui se trouvent derrière Velen, exécuter du SQL ad hoc en lecture seule sur une source connectée à Velen, vérifier ou étendre une information Velen connue par ID public, ou gérer la mémoire Knowledge Graph à l'échelle de l'organisation via Velen. Ne pas utiliser pour des bases de données locales, des informations d'identification directes ou des travaux SQL qui contournent les contrôles d'accès Velen.
