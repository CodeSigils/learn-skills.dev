ユーザーが /todo-state を呼び出し、「X を完了としてマークする」、「タスク Y にチェックを入れる」、「チェックを外す」、「これを進行中に設定する」、「このプロジェクトを完了としてマークする」、または完全な実行パスなしで進行状況を記録したい場合に使用します。同様に、「インデックスは正確か」、「Todo は現実と一致していますか」、「プロジェクトのステータスを監査する」、「完了と言っているが、出荷されない」、またはハブの状態が実際に起こったことからずれていると疑う場合にも使用します。リポジトリ内で。 task.md チェックボックスと、所有するアクティブまたはアーカイブされたレジストリ行を同期して編集します。記録されたステータスをタスクと Git 証拠に照らして監査し、確認時にのみドリフトを修正します。以前の /todo-update-state (現在のデフォルト モード) と /todo-sync (現在の `audit`) を置き換えます。これらのスペルのいずれかをこのスキルの呼び出しとして扱います。
