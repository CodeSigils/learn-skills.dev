當使用者呼叫 /todo-state，說“將 X 標記為已完成”、“勾選任務 Y”、“取消選中它”、“將其設置為進行中”、“將此項目標記為已完成”，或者想要在沒有完整執行過程的情況下記錄進度時使用 -同樣，當他們說“索引是否準確”、“待辦事項是否與現實相符”、“審核我的專案狀態”、“這表示已完成但從未發貨”或懷疑集線器狀態已偏離實際發生的情況時使用回購協議。同步編輯tasks.md複選框和擁有的活動或存檔註冊表行；根據任務和 git 證據審核記錄的狀態，並僅在確認後修復偏差。取代先前的 /todo-update-state （現在是預設模式）和 /todo-sync （現在是「audit」）—將這些拼字中的任何一個視為對此技能的呼叫。
