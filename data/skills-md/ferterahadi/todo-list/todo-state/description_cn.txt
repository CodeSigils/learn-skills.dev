当用户调用 /todo-state，说“将 X 标记为已完成”、“勾选任务 Y”、“取消选中它”、“将其设置为进行中”、“将此项目标记为已完成”，或者想要在没有完整执行过程的情况下记录进度时使用 - 同样，当他们说“索引是否准确”、“待办事项是否与现实相符”、“审核我的项目状态”、“这表示已完成但从未发货”或怀疑集线器状态已偏离实际发生的情况时使用回购协议。同步编辑tasks.md复选框和拥有的活动或存档注册表行；根据任务和 git 证据审核记录的状态，并仅在确认后修复偏差。替换以前的 /todo-update-state （现在是默认模式）和 /todo-sync （现在是“audit”）——将这些拼写中的任何一个视为对此技能的调用。
