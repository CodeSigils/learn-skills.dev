À utiliser lorsque l'utilisateur invoque /todo-list, demande de lister les projets ou leur statut, demande d'afficher les projets terminés/archivés, ou dit « trier l'index », « classer les projets par progression » ou « réorganiser index.md ». La vue par défaut lit uniquement l'index.md actif ; la vue d'archive lit archive.md à froid ; sort réorganise uniquement les lignes actives.
