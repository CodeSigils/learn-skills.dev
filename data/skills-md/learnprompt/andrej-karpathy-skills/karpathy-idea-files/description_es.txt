Cree y comparta ideas como especificaciones abstractas de estilo Gist en lugar de código, permitiendo que los agentes u otras personas las implementen. Utilice esta habilidad cuando el usuario quiera capturar una nueva idea rápidamente, necesite escribir una especificación de proyecto para que la implemente un agente, quiera compartir un concepto sin desarrollarlo primero o diga "escribir esta idea", "crear una especificación", "resumir esto", "archivo de ideas", "el agente puede implementar esto", "resumen para este proyecto". Basado en la publicación LLM Wiki Gist similar a Karpathy 27k y el repositorio de GitHub.
