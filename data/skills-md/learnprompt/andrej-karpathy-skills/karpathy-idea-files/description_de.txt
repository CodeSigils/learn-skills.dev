Erstellen und teilen Sie Ideen als abstrakte Spezifikationen im Gist-Stil anstelle von Code – und lassen Sie Agenten oder andere diese umsetzen. Verwenden Sie diese Fähigkeit, wenn der Benutzer schnell eine neue Idee erfassen möchte, eine Projektspezifikation für die Implementierung durch einen Agenten schreiben muss, ein Konzept teilen möchte, ohne es vorher zu erstellen, oder wenn er sagt: „Schreiben Sie diese Idee auf“, „Erstellen Sie eine Spezifikation“, „Das Wesentliche“, „Ideendatei“, „Agent kann dies umsetzen“, „Briefing für dieses Projekt“. Basierend auf dem Karpathy 27k-ähnlichen LLM-Wiki-Gist-Beitrag und dem GitHub-Repo.
