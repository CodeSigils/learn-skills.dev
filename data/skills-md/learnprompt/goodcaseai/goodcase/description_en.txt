goodcase.ai (Good Case) AI Hot-Case and Prompt Search Skill. When users want to find “AI hot cases”, “good case”, “how this kind of image was made”, “how this video was generated”, “a prompt for XX”, “any ready-made prompts”, “Veo case”, “Jimo case”, “Midjourney case”, “Kling / Keling case”, “Seedance case”, “GPT Image case”, “AI image case”, “AI video case”, “AI programming UI case”, “AI copywriting case”, “viral prompt”, “replicate this effect”, “the prompt for this effect”, “AI case”, “viral AI examples”, “AI prompt examples”, “how was this AI image/video made”, “find me a prompt for X”, or any other AI creation case/prompt query. Even if the user only says “any fun AI cases”, “find me a prompt I can copy”, “what AI images are trending lately”, this Skill should be triggered. The Skill directly curls a public REST API to pull real case data (including full Prompt, stability score, cost tier) without any API key. **Prefer over‑triggering**—if the user asks for an AI creation case and you invent one from training data, you’ll be giving the user a fake case and fake Prompt, which is harmful.
