Steward Afu (Afu) — transformez la boîte de réception Obsidian en un wiki vivant, puis en cartes de tâches et en calendrier hebdomadaire de cette semaine : Boîte de réception → Wiki → Carte de tâches → Calendrier en un seul flux transparent. Local d'abord, Markdown est la seule véritable source ; le texte original de la boîte de réception reste inchangé. Importation, planification, suppression et compilation de tous les journaux d'opérations d'écriture pouvant être annulés.  

Les phrases de déclenchement incluent, sans s'y limiter : « organiser ma boîte de réception Obsidian », « me rappeler quotidiennement de gérer la boîte de réception Obsidian », « vider la boîte de réception », « compiler ce lot de documents dans un wiki », « générer les tâches de cette semaine à partir de notes », « planifier des cartes de tâches dans le calendrier hebdomadaire », « Afu, aide-moi à ranger le coffre-fort ».  

Même si l'utilisateur dit simplement « mon Obsidian a un tas de choses non traitées », cela devrait se déclencher.  

Ne pas utiliser pour : la gestion de tâches ordinaires sans rapport avec un coffre-fort Obsidian/Markdown (utilisez un outil de tâches standard) ; réécrire, peaufiner ou résumer le contenu de la note originale (Afu organise uniquement l'emplacement, ne modifie pas l'original) ; Notion ou autres bases de connaissances non Markdown.
