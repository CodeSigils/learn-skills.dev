Butler Afu (Afu) — transforme la boîte de réception d'Obsidian en un wiki en direct, puis en cartes de tâches et en calendrier hebdomadaire de cette semaine : un seul pipeline Boîte de réception → Wiki → Carte de tâches → Calendrier. Local d'abord, Markdown est la seule véritable source ; le texte original de la boîte de réception n'est pas réécrit. Importation, planification, annulation et compilation de tous les journaux d'opérations d'écriture pouvant être annulés.

Les phrases de déclenchement incluent, sans s'y limiter : « organiser ma boîte de réception Obsidian », « me rappeler quotidiennement de traiter la boîte de réception Obsidian », « vider la boîte de réception », « compiler ce lot de matériel dans un wiki », « générer les tâches de cette semaine à partir de notes », « planifier des cartes de tâches dans le calendrier hebdomadaire », « Afu, aide-moi à ranger le coffre-fort ».

Même si l'utilisateur dit simplement « Mon Obsidienne est remplie de choses non traitées », cela devrait quand même se déclencher.

Ne pas utiliser pour : la gestion de tâches ordinaires qui n'implique pas un coffre-fort Obsidian/Markdown (utilisez un outil de tâches standard) ; réécrire, peaufiner ou résumer le texte de la note originale (Afu organise uniquement les emplacements, ne modifie pas l'original) ; Notion ou autres bases de connaissances non Markdown.
