Метод выбора акций CAN SLIM. Основанный на книге Уильяма О'Нила «Как зарабатывать деньги на акциях», он систематически анализирует акции роста по семи измерениям (C = прибыль за текущий квартал, A = годовой доход, N = новые продукты/услуги, S = соотношение спроса и предложения, L = ведущие акции, I = институциональное признание, M = направление рынка), сочетая технический и фундаментальный анализ, чтобы точно уловить начало крупного восходящего тренда. Используйте, когда: пользователь хочет выбрать акции с использованием метода CAN SLIM, обсудить систему О'Нила, необходимо объединить технический и фундаментальный анализ для выявления сильных акций, определить время для покупки конкретной акции, проанализировать модели «ручки чашки» или другие технические формации прорыва.
