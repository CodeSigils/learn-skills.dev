Метод выбора акций CAN SLIM. Основанный на книге Уильяма О'Нила «Как делать деньги на акциях», он систематически отслеживает растущие бычьи акции по семи измерениям (C = прибыль за текущий квартал, A = годовой доход, N = новые разработки, S = соотношение спроса и предложения, L = ведущие акции, I = институциональная поддержка, M = направление рынка), сочетая технический и фундаментальный анализ, чтобы точно уловить начало основной восходящей волны. Используйте, когда: пользователь хочет выбрать акции с помощью метода CAN SLIM, обсудить систему О'Нила, ему необходимо объединить технический и фундаментальный анализ для выявления сильных акций, определить время для покупки отдельных акций, проанализировать модели «ручки чашки» или другие технические образования прорыва.
