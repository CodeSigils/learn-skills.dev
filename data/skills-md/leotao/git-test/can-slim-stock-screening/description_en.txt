CAN SLIM stock selection method. Originating from William O'Neil's *How to Make Money in Stocks*, it systematically screens growth bull stocks through seven dimensions (C = current quarter earnings, A = annual earnings, N = new developments, S = supply‑demand relationship, L = leading stocks, I = institutional acceptance, M = market direction), combining technical and fundamental analysis to precisely capture the start of a primary upward wave. Use when: the user wants to select stocks using the CAN SLIM method, discuss O'Neil's system, needs to combine technical and fundamental analysis to screen strong stocks, determine the timing for buying individual stocks, or analyze cup‑handle patterns or other technical breakout formations.
