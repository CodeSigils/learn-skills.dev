CAN SLIMの銘柄選択方法。ウィリアム・オニールの「株で儲ける方法」を起源とするこの手法は、テクニカル分析とファンダメンタルズ分析を組み合わせて、主な上昇波の始まりを正確に捉えるために、7つの側面（C = 当四半期利益、A = 年間利益、N = 新規開発、S = 需給関係、L = 主要銘柄、I = 機関投資家の支持、M = 市場の方向性）を通じて成長強気株を体系的にスクリーニングします。どのような場合に使用します: ユーザーが CAN SLIM メソッドを使用して銘柄を選択したい場合、オニールのシステムについて議論する場合、テクニカル分析とファンダメンタルズ分析を組み合わせて強い銘柄を選別する必要がある場合、個々の銘柄を購入するタイミングを決定する場合、カップハンドル パターンやその他のテクニカル ブレイクアウト フォーメーションを分析する必要がある場合。
