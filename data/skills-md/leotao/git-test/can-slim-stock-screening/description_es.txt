Método de selección de acciones CAN SLIM. Con origen en "Cómo ganar dinero con acciones" de William O'Neil, analiza sistemáticamente las acciones alcistas de crecimiento a través de siete dimensiones (C = ganancias del trimestre actual, A = ganancias anuales, N = nuevos desarrollos, S = relación oferta-demanda, L = acciones líderes, I = respaldo institucional, M = dirección del mercado), combinando análisis técnico y fundamental para capturar con precisión el inicio de la principal ola alcista. Úselo cuando: el usuario desea seleccionar acciones usando el método CAN SLIM, discutir el sistema de O'Neil, necesita combinar análisis técnico y fundamental para seleccionar acciones fuertes, determinar el momento para comprar acciones individuales, analizar patrones de manijas de copa u otras formaciones técnicas de ruptura.
