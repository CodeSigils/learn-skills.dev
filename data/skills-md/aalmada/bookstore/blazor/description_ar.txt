كتابة ومراجعة وإصلاح مكونات Blazor Server في مشروع BookStore - والتي تغطي أوضاع العرض (InteractiveServer)، ودورة الحياة مع تنظيف IDisposable، وDI عبر @inject/[Inject]، وReactiveQuery<T> لتحميل البيانات المستندة إلى SSE، ونماذج/مربعات حوار/جداول MudBlazor، والخدمات المدركة للمستأجر، وحراس AuthorizeView. يتم تشغيله عندما يكتب المستخدم أو يراجع أو يسأل عن ملفات .razor، أو إضافة صفحة أو مكون، أو ReactiveQuery، أو MudForm/MudTable/MudDialog، أو تحديثات واجهة المستخدم في الوقت الفعلي من SSE، أو المكونات المدركة للمستأجر، أو التحديثات المتفائلة في الواجهة الأمامية، أو حراس التفويض في الصفحات، أو BookStore.Web - حتى لو لم يذكر "Blazor" صراحة.
