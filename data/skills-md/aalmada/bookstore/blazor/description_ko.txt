BookStore 프로젝트의 Blazor Server 구성 요소를 작성, 검토 및 수정합니다. 여기에는 렌더링 모드(InteractiveServer), IDisposable 정리가 포함된 수명 주기, @inject/[Inject]를 통한 DI, SSE 기반 데이터 로딩을 위한 ReactiveQuery<T>, MudBlazor 양식/대화 상자/테이블, 테넌트 인식 서비스 및 AuthorizeView 가드가 포함됩니다. 사용자가 .razor 파일에 대해 작성, 검토 또는 요청할 때마다 트리거하고, 페이지 또는 구성 요소, ReactiveQuery, MudForm/MudTable/MudDialog, SSE의 실시간 UI 업데이트, 테넌트 인식 구성 요소, 프런트엔드의 낙관적 업데이트, 페이지의 인증 보호 장치 또는 BookStore.Web을 추가합니다. 명시적으로 "Blazor"라고 말하지 않더라도 마찬가지입니다.
