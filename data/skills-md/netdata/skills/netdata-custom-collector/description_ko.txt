Netdata가 아직 모니터링하지 않는 커스텀 애플리케이션, 내부 서비스, 스크립트나 CLI 도구의 출력, 혹은 장치와 같은 대상에서 메트릭을 수집해야 할 때 사용합니다. 내장된 StatsD 서버(컬렉터 코드 없이)부터 외부 플러그인 라인 프로토콜(C​HART/D​IMENSION/B​EGIN/S​ET/E​ND를 stdout에 출력)으로 어떤 언어든 컬렉터를 작성하는 방법, 혹은 레거시 python.d 및 charts.d 모듈 프레임워크까지의 의사결정 트리를 다룹니다. 작동하는 가장 저렴한 접근 방식을 선택하고, 실제 예시를 통해 스캐폴딩하는 방법을 가르치며, Netdata MCP 서버가 연결된 경우 MCP를 통해 메트릭이 올바른 형식으로 수집되었는지 자동으로 검증합니다.
