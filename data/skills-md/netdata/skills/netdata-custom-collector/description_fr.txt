À utiliser lorsque vous avez besoin de Netdata pour collecter des métriques à partir de quelque chose qu'il ne surveille pas déjà, comme une application personnalisée, un service interne, la sortie d'un script ou d'un outil CLI, ou un périphérique. Couvre l'arbre de décision du serveur StatsD intégré (zéro code collecteur) en écrivant un collecteur dans n'importe quelle langue via le protocole de ligne de plugin externe (CHART/DIMENSION/BEGIN/SET/END sur stdout) ou les anciens frameworks de modules python.d et charts.d. Apprenez à choisir l'approche la moins chère qui fonctionne, à l'élaborer à partir d'un exemple réel et, lorsqu'un serveur Netdata MCP est connecté, à vérifier automatiquement via MCP que les métriques sont collectées dans le bon format sans intervention de l'utilisateur.
