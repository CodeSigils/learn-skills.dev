Используйте при диагностике проблем с состоянием кластера Kubernetes: недоступна плоскость управления, медленная плоскость управления, остановка согласования, сбои узлов или блокировка доступа. Запрашивает Netdata через MCP о работоспособности сервера API, наличии лидера etcd, задержке запроса сервера API (p99), задержке etcd wal fsync, изменениях лидера etcd, применяет дерево диагностики из книги действий оператора Netdata и рекомендует исправления.
