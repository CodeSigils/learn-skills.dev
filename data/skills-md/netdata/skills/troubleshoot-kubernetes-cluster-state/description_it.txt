Da utilizzare durante la diagnosi di problemi con lo stato del cluster Kubernetes: piano di controllo non disponibile, piano di controllo lento, stallo della riconciliazione, errori dei nodi o blocco dell'ammissione. Interroga Netdata tramite MCP per informazioni sull'integrità del server API, sull'esistenza del leader etcd, sulla latenza delle richieste del server API (p99), sulla latenza etcd wal fsync, sulle modifiche del leader etcd, applica l'albero diagnostico dal playbook dell'operatore Netdata e consiglia la risoluzione.
