يُستخدم عند تشخيص المشكلات المتعلقة بحالة مجموعة Kubernetes: مستوى التحكم غير متاح، أو مستوى التحكم بطيء، أو توقف التسوية، أو فشل العقدة، أو انسداد القبول. يستعلم عن Netdata عبر MCP من أجل صحة خادم API، ووجود القائد etcd، وزمن استجابة طلب خادم API (p99)، وزمن استجابة etcd wal fsync، وتغييرات القائد etcd، ويطبق شجرة التشخيص من دليل تشغيل مشغل Netdata، ويوصي بالمعالجة.
