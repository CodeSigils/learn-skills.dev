Используйте при диагностике проблем с Uwsgi: истощение рабочих, шторм харакири, расползание памяти, зависание рабочих или сбой перезагрузки. Запрашивает Netdata через MCP для получения количества рабочих, коэффициента занятости рабочих, пропускной способности запросов (дельта-запросы), среднего времени ответа (avg_rt), времени работы рабочих, применяет дерево диагностики из книги действий оператора Netdata и рекомендует исправления.
