Úselo al diagnosticar problemas con el servidor API de Kubernetes: la parada del webhook, la tormenta de listas, la cascada de latencia etcd, el acantilado de memoria o el sangrado lento de rbac/auth. Consulta Netdata a través de MCP para obtener señales de estado del servidor API de Kubernetes, aplica el árbol de diagnóstico del manual del operador de Netdata y recomienda soluciones.
