Используйте при диагностике проблем с API-сервером Kubernetes: зависание веб-перехватчика, шторм списка, каскад задержек etcd, обрыв памяти или медленное кровотечение rbac/auth. Запрашивает Netdata через MCP для сигналов о работоспособности API-сервера Kubernetes, применяет дерево диагностики из книги действий оператора Netdata и рекомендует исправления.
