Используйте при диагностике проблем с Fluentd: насыщение буфера (противодавление), повторный штурм, раздувание памяти, цикл сбоя «ядовитой таблетки» или тихая потеря данных. Запрашивает Netdata через MCP для определения активности процесса Fluentd, отслеживания реакции API агента, частоты входных записей, частоты выходных записей, совокупного времени очистки, применения диагностического дерева из книги действий оператора Netdata и рекомендаций по исправлению.
