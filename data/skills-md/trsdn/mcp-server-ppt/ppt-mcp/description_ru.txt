Автоматизируйте Microsoft PowerPoint в Windows через COM-взаимодействие. Используйте при создании, чтении или изменении презентаций PowerPoint. Поддерживает слайды, фигуры, текст, диаграммы, таблицы, анимацию, переходы, заметки и мультимедиа. Триггеры: PowerPoint, презентация, pptx, слайды, фигуры, анимация.
