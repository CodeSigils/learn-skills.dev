Automatisez Microsoft PowerPoint sur Windows via COM Interop. À utiliser lors de la création, de la lecture ou de la modification de présentations PowerPoint. Prend en charge les diapositives, les formes, le texte, les graphiques, les tableaux, les animations, les transitions, les notes et les médias. Déclencheurs : PowerPoint, présentation, pptx, diapositives, formes, animations.
