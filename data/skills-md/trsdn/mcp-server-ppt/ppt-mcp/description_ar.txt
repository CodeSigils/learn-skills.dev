أتمتة Microsoft PowerPoint على نظام التشغيل Windows عبر إمكانية التشغيل المتداخل لـ COM. يُستخدم عند إنشاء عروض PowerPoint التقديمية أو قراءتها أو تعديلها. يدعم الشرائح والأشكال والنصوص والرسوم البيانية والجداول والرسوم المتحركة والانتقالات والملاحظات والوسائط. المشغلات: PowerPoint، العرض التقديمي، pptx، الشرائح، الأشكال، الرسوم المتحركة.
