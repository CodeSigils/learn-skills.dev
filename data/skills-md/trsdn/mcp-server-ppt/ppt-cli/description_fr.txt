Automatisez Microsoft PowerPoint sur Windows via CLI. À utiliser lors de la création, de la lecture ou de la modification de présentations PowerPoint à partir de scripts, de CI/CD ou d'agents de codage. Prend en charge les diapositives, les formes, le texte, les graphiques, les animations et les transitions. Déclencheurs : PowerPoint, présentation, pptx, pptcli, automatisation CLI.
