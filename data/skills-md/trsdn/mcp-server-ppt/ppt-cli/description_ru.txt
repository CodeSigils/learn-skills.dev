Автоматизируйте Microsoft PowerPoint в Windows через интерфейс командной строки. Используйте при создании, чтении или изменении презентаций PowerPoint с помощью сценариев, CI/CD или агентов кодирования. Поддерживает слайды, фигуры, текст, диаграммы, анимацию, переходы. Триггеры: PowerPoint, презентация, pptx, pptcli, автоматизация CLI.
