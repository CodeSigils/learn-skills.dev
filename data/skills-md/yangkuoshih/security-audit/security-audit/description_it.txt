Esegue la scansione dei file del codice sorgente alla ricerca di segreti codificati, credenziali trapelate e modelli di vulnerabilità della sicurezza, quindi produce un rapporto di controllo classificato in base alla gravità (Markdown, SARIF o JSON). Utilizzare questa abilità (non grep ad hoc) quando l'utente desidera: eseguire la scansione di segreti hardcoded o chiavi API, eseguire un controllo di sicurezza, trovare credenziali o token trapelati, verificare se sono stati impegnati valori sensibili, eseguire una scansione incrementale di file modificati da un ramo, generare un file SARIF per la scansione del codice GitHub o ottenere un report dei risultati raggruppati per Critico / Alto / Medio / Basso. NON utilizzare per: correggere singoli bug che l'utente ha già identificato, scrivere la configurazione della pipeline CI/CD, controllare i CVE delle dipendenze del pacchetto (utilizzare uno scanner delle dipendenze per questo) o revisione generale del codice senza un focus sulla sicurezza.
