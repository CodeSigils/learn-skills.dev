Analyse les fichiers de code source à la recherche de secrets codés en dur, d'informations d'identification divulguées et de modèles de vulnérabilité de sécurité, puis produit un rapport d'audit classé par gravité (Markdown, SARIF ou JSON). Utilisez cette compétence - et non grep ad hoc - lorsque l'utilisateur souhaite : rechercher des secrets codés en dur ou des clés API, effectuer un audit de sécurité, rechercher des informations d'identification ou des jetons divulgués, vérifier si des valeurs sensibles ont été validées, exécuter une analyse incrémentielle des fichiers modifiés depuis une branche, générer un fichier SARIF pour l'analyse du code GitHub ou obtenir un rapport des résultats regroupés par Critique/Élevé/Moyen/Faible. Ne PAS utiliser pour : corriger des bogues individuels que l'utilisateur a déjà identifiés, écrire une configuration de pipeline CI/CD, vérifier les CVE de dépendance de package (utilisez un scanner de dépendances pour cela) ou une révision générale du code sans se concentrer sur la sécurité.
