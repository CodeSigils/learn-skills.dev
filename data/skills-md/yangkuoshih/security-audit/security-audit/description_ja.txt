ソース コード ファイルをスキャンして、ハードコーディングされたシークレット、漏洩した認証情報、セキュリティ脆弱性パターンを探し、重大度別に分類された監査レポート (Markdown、SARIF、または JSON) を生成します。ユーザーが、ハードコーディングされたシークレットまたは API キーのスキャン、セキュリティ監査の実行、漏洩した認証情報またはトークンの検索、機密値がコミットされているかどうかの確認、ブランチ以降に変更されたファイルの増分スキャンの実行、GitHub コード スキャン用の SARIF ファイルの生成、または重要 / 高 / 中 / 低でグループ化された検出結果のレポートの取得を行う場合は、アドホック grep ではなく、このスキルを使用します。ユーザーが既に特定した個々のバグの修正、CI/CD パイプライン構成の作成、パッケージの依存関係 CVE のチェック (そのためには依存関係スキャナーを使用)、またはセキュリティを重視しない一般的なコード レビューには使用しないでください。
