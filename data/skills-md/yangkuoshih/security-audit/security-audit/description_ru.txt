Сканирует файлы исходного кода на наличие жестко закодированных секретов, утечек учетных данных и шаблонов уязвимостей безопасности, а затем создает отчет об аудите с классификацией серьезности (Markdown, SARIF или JSON). Используйте этот навык, а не специальный grep, когда пользователь хочет: сканировать жестко запрограммированные секреты или ключи API, провести аудит безопасности, найти утечку учетных данных или токенов, проверить, были ли зафиксированы конфиденциальные значения, запустить добавочное сканирование файлов, измененных с момента ветки, создать файл SARIF для сканирования кода GitHub или получить отчет о результатах, сгруппированных по критическому/высокому/среднему/низкому уровню. НЕ используйте для: исправления отдельных ошибок, которые уже обнаружил пользователь, написания конфигурации конвейера CI/CD, проверки CVE зависимостей пакетов (используйте для этого сканер зависимостей) или общей проверки кода без акцента на безопасность.
