Escanea archivos de código fuente en busca de secretos codificados, credenciales filtradas y patrones de vulnerabilidad de seguridad, luego produce un informe de auditoría clasificado por gravedad (Markdown, SARIF o JSON). Utilice esta habilidad (no grep ad-hoc) cuando el usuario desee: escanear en busca de secretos codificados o claves API, realizar una auditoría de seguridad, encontrar credenciales o tokens filtrados, verificar si se confirmaron valores confidenciales, ejecutar un escaneo incremental de archivos modificados desde una rama, generar un archivo SARIF para el escaneo de código de GitHub u obtener un informe de hallazgos agrupados por Crítico / Alto / Medio / Bajo. NO lo use para: corregir errores individuales que el usuario ya ha identificado, escribir la configuración de canalización de CI/CD, verificar CVE de dependencia de paquetes (use un escáner de dependencias para eso) o revisión general de código sin un enfoque de seguridad.
