Analice imágenes, sitios web y archivos Figma para extraer su diseño y generar un `design.md` con sistema de tokens, inventario de componentes y notas de reconstrucción. Utilice esta habilidad siempre que el usuario quiera comprender, documentar, replicar o auditar el diseño de algo visual: una captura de pantalla, una URL, un enlace de Figma, una referencia de Pinterest, una maqueta, el sitio de un competidor, un componente, un panel de control, una página de destino. También cuando preguntan 'extraer el sistema de diseño de X', 'documentar el estilo de Y', 'analizar esto visualmente', 'convertir esta imagen en tokens', 'ayúdame a replicar este diseño', 'qué paleta usa este sitio', 'cómo se construye esto'. También para elementos individuales: 'copiar esta barra de navegación', 'recrear esta ilustración', 'dame un mensaje para regenerar este gráfico': el modo de elemento genera un element.md enfocado, con mensajes de modelo de imagen basados ​​en tokens cuando el elemento es un arte visual. Si el usuario aporta alguna fuente visual y quiere comprenderla a nivel de diseño, esta habilidad debería activarse.
