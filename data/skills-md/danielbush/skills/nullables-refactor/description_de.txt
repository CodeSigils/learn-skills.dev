Analysieren Sie eine Datei und erstellen Sie einen Refactoring-Plan, um das Nullables-Muster anzuwenden. Klassifiziert Code nach Nebeneffektgrenze (PURE, IN_MEMORY, OUTSIDE_WORLD), identifiziert HARDWIRED_INFRA, empfiehlt die Konvertierung INFRASTRUCTURE_WRAPPER oder NULLABLE_CLASS, prüft die DUAL_FACTORY- und CREATE_BOUNDARY_RULE-Konformität und entscheidet über DELAYED_INSTANTIATION. Wird verwendet, wenn Sie aufgefordert werden, eine Datei oder ein Modul umzugestalten, um dem Nullables-Muster zu folgen.
