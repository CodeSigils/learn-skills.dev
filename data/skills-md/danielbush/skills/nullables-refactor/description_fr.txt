Analysez un fichier et produisez un plan de refactoring pour appliquer le modèle Nullables. Classifie le code par limite d'effet secondaire (PURE, IN_MEMORY, OUTSIDE_WORLD), identifie HARDWIRED_INFRA, recommande la conversion INFRASTRUCTURE_WRAPPER ou NULLABLE_CLASS, vérifie la conformité DUAL_FACTORY et CREATE_BOUNDARY_RULE et décide de DELAYED_INSTANTIATION. À utiliser lorsqu'on vous demande de refactoriser un fichier ou un module pour suivre le modèle nullables.
