Analizzare un file e produrre un piano di refactoring per applicare il modello Nullables. Classifica il codice in base al limite dell'effetto collaterale (PURE, IN_MEMORY, OUTSIDE_WORLD), identifica HARDWIRED_INFRA, consiglia la conversione INFRASTRUCTURE_WRAPPER o NULLABLE_CLASS, controlla la conformità DUAL_FACTORY e CREATE_BOUNDARY_RULE e decide su DELAYED_INSTANTIATION. Utilizzare quando viene richiesto di effettuare il refactoring di un file o di un modulo per seguire il modello nullable.
