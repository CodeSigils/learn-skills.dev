Analice un archivo y produzca un plan de refactorización para aplicar el patrón Nullables. Clasifica el código por límite de efectos secundarios (PURE, IN_MEMORY, OUTSIDE_WORLD), identifica HARDWIRED_INFRA, recomienda la conversión INFRASTRUCTURE_WRAPPER o NULLABLE_CLASS, verifica el cumplimiento de DUAL_FACTORY y CREATE_BOUNDARY_RULE y decide sobre DELAYED_INSTANTIATION. Úselo cuando se le solicite refactorizar un archivo o módulo para seguir el patrón de valores anulables.
