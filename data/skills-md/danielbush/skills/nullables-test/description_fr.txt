Écrivez des tests illustratifs pour le code qui suit le modèle Nullables. Vérifie que la classe testée est prête (tous HARDWIRED_INFRA remplacés par INJECTED_INFRA, chaque dépendance a .createNull), puis écrit des tests étroits, sociables, basés sur l'état à l'aide de .createNull(). Les tests doivent illustrer les concepts et l'architecture du système, et pas seulement assurer la couverture. À utiliser après avoir appliqué la compétence nullables-refactor ou lors de l'écriture de tests pour du code qui utilise déjà DUAL_FACTORY.
