Traduit les scripts R en récits méthodologiques en langage simple, lisibles par des experts du domaine qui ne sont pas des programmeurs R. Utilisez cette compétence chaque fois qu'un utilisateur colle ou télécharge un script R et demande une description de la méthodologie, un résumé en langage simple, un document d'examen par un expert ou une explication non technique de ce que fait le code. Déclenchez également lorsqu'un utilisateur dit des choses comme « expliquer ce script à un réviseur », « écrire ce que fait ce code », « traduire ce code R en étapes » ou « mon collègue doit réviser ceci mais ne peut pas lire R ». Le résultat est un récit méthodologique numéroté formaté pour être utilisé dans des documents Quarto ou Word.
