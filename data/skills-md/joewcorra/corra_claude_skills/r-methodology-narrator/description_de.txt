Übersetzt R-Skripte in verständliche Methodenerzählungen, die von Fachexperten gelesen werden können, die keine R-Programmierer sind. Verwenden Sie diese Fähigkeit immer dann, wenn ein Benutzer ein R-Skript einfügt oder hochlädt und nach einer Beschreibung der Methodik, einer Zusammenfassung in einfacher Sprache, einem Dokument zur Expertenbewertung oder einer nichttechnischen Erklärung der Funktionsweise des Codes fragt. Wird auch ausgelöst, wenn ein Benutzer Dinge sagt wie „Erklären Sie dieses Skript einem Prüfer“, „Schreiben Sie auf, was dieser Code bewirkt“, „Übersetzen Sie diesen R-Code in Schritte“ oder „Mein Kollege muss dies überprüfen, kann R aber nicht lesen“. Die Ausgabe ist eine nummerierte Methodenbeschreibung, die für die Verwendung in Quarto- oder Word-Dokumenten formatiert ist.
