Da utilizzare quando un'attività richiede la creazione o il check-out di un ramo di sviluppo per modifiche al progetto, il percorso root è occupato da tale ramo di sviluppo, la revisione in sola lettura di altri rami o versioni, l'esecuzione di operazioni Git ad alto rischio, il lavoro in parallelo o i file di destinazione si sovrappongono a modifiche esistenti.
