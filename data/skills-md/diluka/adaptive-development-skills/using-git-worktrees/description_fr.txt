À utiliser lorsqu'une tâche nécessite la création ou l'extraction d'une branche de développement pour les modifications du projet, le chemin racine est occupé par une telle branche de développement, la révision en lecture seule d'autres branches ou versions, l'exécution d'opérations Git à haut risque, le travail en parallèle ou les fichiers cibles chevauchent les modifications existantes.
