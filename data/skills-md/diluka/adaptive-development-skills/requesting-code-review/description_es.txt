Úselo cuando las tareas de desarrollo complejas o de alto riesgo requieren una revisión independiente final, las tareas de desarrollo de rutina tienen riesgos específicos que no están cubiertos por la verificación específica, los cambios sustanciales deben determinar si las revisiones existentes no son válidas o las investigaciones complejas que no son de desarrollo pueden mejorar la cobertura objetivo y la precisión de las conclusiones a través de verificaciones independientes.
