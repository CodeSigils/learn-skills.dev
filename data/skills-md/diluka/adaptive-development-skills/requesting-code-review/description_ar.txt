يُستخدم عندما تتطلب مهام التطوير المعقدة أو عالية المخاطر مراجعة مستقلة نهائية، أو عندما تكون مهام التطوير الروتينية بها مخاطر محددة لا يغطيها التحقق المستهدف، أو عندما تحتاج التغييرات الجوهرية إلى تحديد ما إذا كانت المراجعات الحالية غير صالحة، أو يمكن للتحقيقات المعقدة غير التطويرية تحسين التغطية المستهدفة ودقة الاستنتاج من خلال عمليات التحقق المستقلة.
