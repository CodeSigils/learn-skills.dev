Используйте, когда сложные задачи разработки или задачи разработки с высоким уровнем риска требуют окончательной независимой проверки, рутинные задачи разработки имеют особые риски, не охваченные целевой проверкой, существенные изменения необходимы для определения того, являются ли существующие проверки недействительными, или сложные расследования, не связанные с разработкой, могут улучшить целевой охват и точность выводов посредством независимых проверок.
