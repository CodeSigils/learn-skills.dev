Installieren Sie Nunchuk CLI, authentifizieren Sie sich, wechseln Sie zwischen Mainnet und Testnet, ändern Sie den Electrum-Server und überprüfen Sie die gespeicherte Konfiguration. Verwenden Sie diese Option, wenn für einen Befehl eine Anmeldung, ein Netzwerk oder eine Electrum-Einrichtung erforderlich ist oder wenn der Benutzer die aktuelle Authentifizierung oder Konfiguration überprüfen möchte.
