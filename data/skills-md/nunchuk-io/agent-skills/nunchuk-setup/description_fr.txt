Installez Nunchuk CLI, authentifiez-vous, basculez entre le réseau principal et le testnet, changez de serveur Electrum et inspectez la configuration enregistrée. À utiliser lorsqu'une commande nécessite une connexion, un réseau ou une configuration Electrum, ou lorsque l'utilisateur demande de vérifier l'authentification ou la configuration actuelle.
