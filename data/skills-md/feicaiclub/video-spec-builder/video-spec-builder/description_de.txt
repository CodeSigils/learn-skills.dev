Verwenden Sie dies, wenn ein Benutzer sagt, dass er ein Video, einen Werbeclip, eine Produktdemo, einen animierten Kurzfilm oder Douyin-/YouTube-Inhalte erstellen möchte oder wenn er das Storyboard überarbeiten, das Tempo anpassen, Einstellungen ändern, Untertitel bearbeiten, Voice-Overs hinzufügen oder Übergänge ändern möchte. Erfassen Sie Videoanforderungen durch sokratische Befragung, nutzen Sie proaktiv die vollen Funktionen der Rendering-Ebene (TTS / Untertitel / 3D / Shader / audio-reaktive Effekte usw.) und geben Sie eine standardisierte Video-Spezifikation für das Rendering aus.
