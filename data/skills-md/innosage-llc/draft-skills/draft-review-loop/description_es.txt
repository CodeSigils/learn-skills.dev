Ejecute el bucle de transferencia de revisión de borrador y creación local primero para archivos de rebajas del espacio de trabajo. Utilice esta habilidad cuando el usuario solicite escribir o revisar un documento y explícitamente desee una revisión humana en el Borrador, o cuando la tarea sea aplicar los comentarios del Borrador a un archivo local. NO utilice esta habilidad para preguntas de comando de borrador puro (use draft-cli) o tareas de escritura genéricas sin intención de revisión de borrador. Mantenga las rebajas del espacio de trabajo local como fuente de verdad y utilice Draft GUI como superficie de revisión humana.
