Esegui il ciclo di creazione locale e di trasferimento della revisione della bozza per i file di markdown dell'area di lavoro. Utilizza questa capacità quando l'utente chiede di scrivere o rivedere un documento e desidera esplicitamente la revisione umana in Draft o quando l'attività consiste nel riapplicare i commenti Draft a un file locale. NON utilizzare questa abilità per domande di comando Pure Draft (utilizzare draft-cli) o attività di scrittura generiche senza intento di revisione di Draft. Mantieni il markdown dell'area di lavoro locale come fonte di verità e utilizza la GUI di Draft come superficie di revisione umana.
