Запустите цикл локальной разработки и цикл передачи проверки черновика для файлов уценки рабочей области. Используйте этот навык, когда пользователь просит написать или отредактировать документ и явно хочет, чтобы его проверил человек в черновике, или когда задача состоит в том, чтобы применить комментарии черновика обратно к локальному файлу. НЕ используйте этот навык для чисто командных вопросов по черновику (используйте Draft-cli) или для общих письменных задач без намерения просмотреть черновик. Сохраняйте уценку локального рабочего пространства как источник достоверной информации и используйте графический интерфейс пользователя в качестве поверхности для проверки человеком.
