Déployez une installation Intel® SceneScape fonctionnelle à partir de zéro (en dehors du dépôt). Rassemble les flux fournis par l'utilisateur, les identifiants de caméra, le nom de la scène et le choix de mappage, puis exécute le bootstrap via la vérification du suivi via scripts/deploy_scenescape.sh. Gère également la réexécution ou la reprise d'une seule phase d'un déploiement existant sur demande (par exemple, "recalibrer", "refaire la reconstruction de la scène", "reprendre l'amorçage uniquement") via l'indicateur --phase de l'orchestrateur.
