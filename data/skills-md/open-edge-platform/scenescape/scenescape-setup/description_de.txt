Stellen Sie eine funktionierende Intel® SceneScape-Installation von Grund auf bereit (außerhalb des Repositorys). Sammelt vom Benutzer bereitgestellte Streams, Kamera-IDs, Szenennamen und Mapping-Auswahl und führt dann Bootstrap durch, indem es die Tracking-Verifizierung über scripts/deploy_scenescape.sh durchführt. Behandelt auch die erneute Ausführung oder Fortsetzung einer einzelnen Phase einer vorhandenen Bereitstellung auf Anfrage (z. B. „Neu kalibrieren“, „Szenenrekonstruktion wiederherstellen“, „Nur Bootstrap fortsetzen“) über das Flag „--phase“ des Orchestrators.
