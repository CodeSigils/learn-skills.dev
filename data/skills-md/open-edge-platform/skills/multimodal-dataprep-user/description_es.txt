Implemente y consuma Intel Multimodal DataPrep a partir de imágenes prediseñadas o de un repositorio. Úselo para configurar el almacenamiento vectorial VDMS o Milvus, MinIO o almacenamiento de medios locales, verificar las dependencias del servicio e ingerir, enumerar, transmitir o eliminar videos e imágenes; enviar trabajos por lotes; agregar incrustaciones de resúmenes de texto; e inspeccionar la telemetría. Este servicio prepara datos de recuperación pero no ejecuta búsqueda semántica. Utilice multimodal-dataprep-dev para cambios de origen, pruebas o compilaciones de imágenes.
