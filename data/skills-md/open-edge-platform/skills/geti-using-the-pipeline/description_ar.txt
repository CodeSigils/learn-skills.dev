استخدم تطبيق Geti من النهاية إلى النهاية من خلال REST API الخاص به — المشروع ← مجموعة البيانات ← التعليق التوضيحي ← التدريب ← نشر خط الأنابيب الذي تخدمه الواجهة الخلفية لـ FastAPI في "التطبيق/الواجهة الخلفية/". يُستخدم عندما يريد المستخدم (وليس المساهم) إنشاء مشروع، وتحميل الوسائط، وإضافة التعليقات التوضيحية، وإطلاق مهمة تدريب أو تكميم، وتتبع حالة المهمة، وتكوين مصدر → نموذج → تدفق خط أنابيب الاستدلال، وتمكين الاستدلال المباشر. يغطي نقاط النهاية `/api/...` ونموذج المهمة غير المتزامنة، وليس تغييرات كود الواجهة الخلفية.
