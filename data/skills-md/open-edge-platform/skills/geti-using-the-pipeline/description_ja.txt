REST API を通じて Geti アプリケーションをエンドツーエンドで使用します。つまり、「application/backend/」の FastAPI バックエンドによって提供されるプロジェクト → データセット → アノテーション → トレーニング → デプロイ パイプラインです。ユーザー (寄稿者ではない) がプロジェクトの作成、メディアのアップロード、注釈の追加、トレーニングまたは量子化ジョブの起動、ジョブ ステータスの追跡、ソース → モデル → シンク推論パイプラインの構成、およびライブ推論の有効化を行う場合に使用します。バックエンド コードの変更ではなく、`/api/...` エンドポイントと非同期ジョブ モデルについて説明します。
