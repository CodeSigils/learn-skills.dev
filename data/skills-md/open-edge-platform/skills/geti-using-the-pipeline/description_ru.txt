Используйте сквозное приложение Geti через его REST API — проект → набор данных → аннотирование → поезд → конвейер развертывания, обслуживаемый серверной частью FastAPI в `application/backend/`. Используйте, когда пользователь (не участник) хочет создать проект, загрузить медиафайлы, добавить аннотации, запустить задание обучения или квантования, отслеживать состояние задания, настроить конвейер вывода «источник → модель → приёмник» и включить вывод в реальном времени. Охватывает конечные точки `/api/...` и модель асинхронного задания, а не изменения внутреннего кода.
