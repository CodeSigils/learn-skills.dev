Utilisez l'application Geti de bout en bout via son API REST — le projet → ensemble de données → annoter → entraîner → déployer le pipeline servi par le backend FastAPI dans `application/backend/`. À utiliser lorsqu'un utilisateur (pas un contributeur) souhaite créer un projet, télécharger des médias, ajouter des annotations, lancer une tâche de formation ou de quantification, suivre l'état de la tâche, configurer un pipeline d'inférence source → modèle → récepteur et activer l'inférence en direct. Couvre les points de terminaison `/api/...` et le modèle de travail asynchrone, pas les modifications du code backend.
