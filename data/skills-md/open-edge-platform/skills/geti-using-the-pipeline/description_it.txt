Utilizza l'applicazione Geti end-to-end attraverso la sua API REST: il progetto → set di dati → annota → addestra → distribuisci la pipeline servita dal backend FastAPI in `application/backend/`. Da utilizzare quando un utente (non un collaboratore) desidera creare un progetto, caricare contenuti multimediali, aggiungere annotazioni, avviare un lavoro di formazione o quantizzazione, tenere traccia dello stato del lavoro, configurare una pipeline di inferenza sorgente → modello → sink e abilitare l'inferenza live. Copre gli endpoint `/api/...` e il modello di lavoro asincrono, non le modifiche al codice backend.
