Utilice la aplicación Geti de un extremo a otro a través de su API REST: el proyecto → conjunto de datos → anotar → entrenar → implementar canalización atendida por el backend FastAPI en `aplicación/backend/`. Úselo cuando un usuario (no un colaborador) desee crear un proyecto, cargar medios, agregar anotaciones, iniciar un trabajo de capacitación o cuantificación, realizar un seguimiento del estado del trabajo, configurar una fuente → modelo → receptor de canal de inferencia y habilitar la inferencia en vivo. Cubre los puntos finales `/api/...` y el modelo de trabajo asíncrono, no los cambios de código de backend.
