getitune ライブラリ (Geti トレーニング ライブラリ) の Python API または CLI を使用してコンピューター ビジョン モデルをトレーニングします。ユーザーが「create_engine(...)」および「engine.train()/engine.test()」を使用してモデルをトレーニング、微調整、または評価する場合、「getitune train」/「getitune test」を実行する場合、「getitune.recipe.<task>」の下でレシピを選択またはオーバーライドする場合、デバイス (cpu/gpu/xpu/cuda) を選択する場合、チェックポイントからウォームスタートする場合、またはトレーニング実行をデバッグする場合に使用します。分類、検出、インスタンス/セマンティック セグメンテーション、キーポイント検出をカバーします。
