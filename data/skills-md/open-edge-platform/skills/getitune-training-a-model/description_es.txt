Entrene un modelo de visión por computadora con la biblioteca getitune (la biblioteca de entrenamiento Geti) usando su API o CLI de Python. Úselo cuando un usuario quiera entrenar, ajustar o evaluar un modelo con `create_engine(...)` y `engine.train()/engine.test()`, ejecutar `getitune train`/`getitune test`, elegir o anular una receta en `getitune.recipe.<tarea>`, elegir un dispositivo (cpu/gpu/xpu/cuda), iniciar en caliente desde un punto de control o depurar una ejecución de entrenamiento. Cubre clasificación, detección, segmentación semántica/de instancias y detección de puntos clave.
