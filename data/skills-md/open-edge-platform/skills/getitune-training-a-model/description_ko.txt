Python API 또는 CLI를 사용하여 getitune 라이브러리(Geti 교육 라이브러리)로 컴퓨터 비전 모델을 교육합니다. 사용자가 `create_engine(...)` 및 `engine.train()/engine.test()`를 사용하여 모델을 훈련, 미세 조정 또는 평가하고, `getitune train`/`getitune test`를 실행하고, `getitune.recipe.<task>`에서 레시피를 선택 또는 재정의하고, 장치(cpu/gpu/xpu/cuda)를 선택하고, 체크포인트에서 웜 스타트하거나, 훈련 실행을 디버깅하려는 경우에 사용합니다. 분류, 감지, 인스턴스/의미론적 분할, 키포인트 감지를 다룹니다.
