قم بتدريب نموذج رؤية الكمبيوتر باستخدام مكتبة getitune (مكتبة تدريب Geti) باستخدام Python API أو CLI. يُستخدم عندما يريد المستخدم تدريب نموذج أو تحسينه أو تقييمه باستخدام `create_engine(...)` و`engine.train()/engine.test()`، أو تشغيل `getitune Train`/`getitune test`، أو اختيار وصفة أو تجاوزها ضمن `getitune.recipe.<task>`، أو اختيار جهاز (cpu/gpu/xpu/cuda)، أو البدء الدافئ من نقطة تفتيش، أو تصحيح أخطاء تشغيل التدريب. يغطي التصنيف والكشف والتجزئة الدلالية/المثالية واكتشاف النقاط الرئيسية.
