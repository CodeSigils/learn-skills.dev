Разверните и используйте микросервис Multimodal Embedding Serving — поднимите его с помощью setup.sh + docker Compose (из клона репозитория или извлеките те же файлы из GitHub, если клона не существует), используя предварительно созданный образ intel/multimodal-embedding-serving, встройте текст/изображения/видео через REST на порту 9777, выберите одну из 19 моделей. (CLIP/SigLIP/MobileCLIP/CN-CLIP/Blip2/QwenText) или интегрируйте в процесс с помощью колеса Python SDK. Используйте, когда приложению нужны внедрения для поиска или извлечения сходства. Не для изменения источника сервиса — это multimodal-embedding-serving-dev.
