Déployez et consommez le microservice Multimodal Embedding Serving - affichez-le avec setup.sh + docker compose (à partir d'un clone de dépôt ou en récupérant ces mêmes fichiers depuis GitHub lorsqu'aucun clone n'existe) à l'aide de l'image de service intel/multimodal-embedding prédéfinie, intégrez du texte/images/vidéos via REST sur le port 9777, choisissez parmi 19 modèles. (CLIP/SigLIP/MobileCLIP/CN-CLIP/Blip2/ QwenText), ou intégration en cours via la roue du SDK Python. À utiliser lorsqu'une application a besoin d'intégrations pour la recherche ou la récupération de similarités. Pas pour modifier la source du service - c'est-à-dire multimodal-embedding-serving-dev.
