Multimodal Embedding Serving マイクロサービスをデプロイして利用します。事前に構築された intel/multimodal-embedding-serving イメージを使用して、setup.sh + docker compose (リポ クローンから、またはクローンが存在しない場合は GitHub から同じファイルをフェッチすることによって) で起動し、ポート 9777 上の REST 経由でテキスト/画像/ビデオを埋め込み、19 のモデルから選択します。 (CLIP/SigLIP/MobileCLIP/CN-CLIP/Blip2/QwenText)、または Python SDK ホイールを介してインプロセスで統合します。アプリで類似性の検索または取得のために埋め込みが必要な場合に使用します。サービスのソース (multimodal-embedding-serving-dev) を変更するためのものではありません。
