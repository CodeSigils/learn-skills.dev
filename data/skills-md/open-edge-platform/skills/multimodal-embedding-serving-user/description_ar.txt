قم بنشر الخدمة الصغيرة لخدمة التضمين متعدد الوسائط واستهلاكها - قم بإحضارها باستخدام setup.sh + docker compose (من نسخة ريبو، أو عن طريق جلب تلك الملفات نفسها من GitHub في حالة عدم وجود نسخة) باستخدام صورة خدمة التضمين/التضمين المتعدد الوسائط التي تم إنشاؤها مسبقًا، وقم بتضمين النص/الصور/مقاطع الفيديو عبر REST على المنفذ 9777، واختر من بين 19 نموذجًا (CLIP/SigLIP/MobileCLIP/CN-CLIP/Blip2/ QwenText)، أو الدمج أثناء العملية عبر عجلة Python SDK. يُستخدم عندما يحتاج التطبيق إلى عمليات التضمين للبحث عن التشابه أو الاسترجاع. ليس لتعديل مصدر الخدمة - وهو multimodal-embedding-serving-dev.
