Stellen Sie den Microservice „Multimodal Embedding Serving“ bereit und nutzen Sie ihn – rufen Sie ihn mit setup.sh + Docker Compose auf (von einem Repo-Klon oder durch Abrufen derselben Dateien von GitHub, wenn kein Klon vorhanden ist) unter Verwendung des vorgefertigten Intel/multimodal-embedding-serving-Images, betten Sie Text/Bilder/Videos über REST auf Port 9777 ein und wählen Sie aus 19 Modellen (CLIP/SigLIP/MobileCLIP/CN-CLIP/Blip2/QwenText) oder prozessinterne Integration über das Python SDK-Rad. Verwenden Sie diese Option, wenn eine App Einbettungen für die Suche oder den Abruf von Ähnlichkeiten benötigt. Nicht zum Ändern der Quelle des Dienstes – das ist multimodal-embedding-serving-dev.
