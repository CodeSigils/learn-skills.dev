Implemente y consuma el microservicio de servicio de incrustación multimodal: inícielo con setup.sh + docker compose (desde un clon de repositorio o recuperando esos mismos archivos de GitHub cuando no exista ningún clon) usando la imagen de servidor de incrustación multimodal/intel prediseñada, incruste texto/imágenes/videos a través de REST en el puerto 9777, elija entre 19 modelos (CLIP/SigLIP/MobileCLIP/CN-CLIP/Blip2/QwenText) o integrarlo en el proceso a través de la rueda SDK de Python. Úselo cuando una aplicación necesite incrustaciones para búsqueda o recuperación de similitudes. No para modificar la fuente del servicio, es decir, multimodal-embedding-serving-dev.
