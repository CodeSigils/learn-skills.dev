Distribuisci e utilizza il microservizio Multimodal Embedding Serving: attivalo con setup.sh + docker compose (da un clone del repository o recuperando gli stessi file da GitHub quando non esiste alcun clone) utilizzando l'immagine precostruita Intel/multimodal-embedding-serving, incorpora testo/immagini/video su REST sulla porta 9777, scegli tra 19 modelli (CLIP/SigLIP/MobileCLIP/CN-CLIP/Blip2/QwenText) o integrarlo in-process tramite la ruota SDK Python. Da utilizzare quando un'app necessita di incorporamenti per la ricerca o il recupero di somiglianze. Non per modificare l'origine del servizio, ovvero multimodal-embedding-serving-dev.
