Distribuisci il core di domande e risposte della chat con Docker Compose (CPU OpenVINO, GPU OpenVINO o CPU Ollama), inclusa la configurazione dell'ambiente, la selezione del profilo, la verifica dell'avvio, i controlli di integrità e lo smontaggio. Utilizza questa abilità quando l'utente dice "deploy chatqna core", "avvia il contenitore chatqna", "esegui compose", "openvino gpu deploy" o "ollama deploy".
