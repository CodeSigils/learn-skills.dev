Crea nuove applicazioni di analisi video DL Streamer (riga di comando Python, C, C++ o GStreamer). Da utilizzare quando: l'utente descrive una pipeline AI di visione, desidera creare una nuova app di esempio, combinare elementi di campioni esistenti, aggiungere rilevamento/classificazione/VLM/tracciamento/avvisi/registrazione a una pipeline video o creare elementi GStreamer personalizzati in Python o C++. Traduce le descrizioni della pipeline in linguaggio naturale in codice DL Streamer funzionante utilizzando modelli di progettazione consolidati.
