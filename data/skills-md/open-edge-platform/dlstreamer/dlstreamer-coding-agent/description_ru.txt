Создавайте новые приложения видеоаналитики DL Streamer (командная строка Python, C, C++ или GStreamer). Используйте, когда: пользователь описывает конвейер искусственного интеллекта, хочет создать новый пример приложения, объединить элементы из существующих примеров, добавить обнаружение/классификацию/VLM/отслеживание/оповещения/запись в видеоконвейер или создать собственные элементы GStreamer на Python или C++. Переводит описания конвейеров на естественном языке в рабочий код DL Streamer, используя установленные шаблоны проектирования.
