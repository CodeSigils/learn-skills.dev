أنشئ تطبيقات جديدة لتحليلات الفيديو DL Streamer (سطر أوامر Python أو C أو C++ أو GStreamer). يُستخدم عندما: يصف المستخدم مسار الذكاء الاصطناعي للرؤية، أو يريد إنشاء نموذج تطبيق جديد، أو دمج عناصر من العينات الموجودة، أو إضافة الكشف/التصنيف/VLM/التتبع/التنبيهات/التسجيل إلى مسار الفيديو، أو إنشاء عناصر GStreamer مخصصة في Python أو C++. يترجم أوصاف خطوط الأنابيب باللغة الطبيعية إلى كود DL Streamer العامل باستخدام أنماط التصميم المعمول بها.
