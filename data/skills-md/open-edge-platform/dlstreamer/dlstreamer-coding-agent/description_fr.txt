Créez de nouvelles applications d'analyse vidéo DL Streamer (ligne de commande Python, C, C++ ou GStreamer). À utiliser lorsque : l'utilisateur décrit un pipeline Vision AI, souhaite créer un nouvel exemple d'application, combiner des éléments d'échantillons existants, ajouter une détection/classification/VLM/suivi/alertes/enregistrement à un pipeline vidéo ou créer des éléments GStreamer personnalisés en Python ou C++. Traduit les descriptions de pipeline en langage naturel en code DL Streamer fonctionnel à l'aide de modèles de conception établis.
