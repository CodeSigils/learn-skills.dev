Подходит для запроса, анализа и визуализации данных. Например, анализ данных из файлов CSV, Excel, Parquet, JSON, JSONL и других файлов, выполнение статистической агрегации и категориальных запросов. Сначала импортируйте данные, затем используйте операторы SQL для их запроса, анализа и визуализации.

**Поддерживаемые форматы файлов**:
- Файлы CSV: поддерживается прямая загрузка, включая сжатые файлы CSV (например, .gz).
- Файлы Excel: поддерживаются форматы .xlsx и .xls.
- Файлы паркета: поддерживается столбчатый формат хранения.
- Файлы JSON: поддерживается стандартный формат JSON.
- Файлы JSONL: поддерживается формат с одним объектом JSON на строку.

**Инструкции по импорту файлов**:
- На основе официальных рекомендованных DuckDB методов импорта.
- Автоматическое распознавание и загрузка формата файла.
- Поддерживает относительные и абсолютные пути
- Поддерживается прямая загрузка сжатых файлов.

**КОГДА ИСПОЛЬЗОВАТЬ:**
- Когда вам нужно запрашивать, анализировать и визуализировать данные.
- Когда вам нужно выполнить статистическое агрегирование и категориальные запросы к данным.
- Когда вам необходимо обрабатывать и анализировать файлы данных в нескольких форматах.
- Когда вам нужно создать диаграммы визуализации данных.

**ПРИМЕР ИСПОЛЬЗОВАНИЯ:**
- Анализировать данные о продажах и создавать диаграммы тенденций продаж.
- Обработка пользовательских данных из файлов CSV для анализа поведения пользователей.
- Анализ финансовых данных в файлах Excel для создания финансовых отчетов.
- Обработка данных журнала в формате JSON для анализа журнала.
