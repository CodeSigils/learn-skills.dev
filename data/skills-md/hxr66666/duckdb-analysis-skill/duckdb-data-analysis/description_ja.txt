データのクエリ、分析、視覚化に適しています。たとえば、CSV、Excel、Parquet、JSON、JSONL ファイルからのデータを分析し、統計集計やカテゴリ クエリを実行します。まずデータをインポートし、次に SQL ステートメントを使用してクエリ、分析、視覚化します。

**サポートされているファイル形式**:
- CSV ファイル: 圧縮された CSV ファイル (例: .gz) を含む直接ロードがサポートされています。
- Excel ファイル: .xlsx および .xls 形式をサポート
- 寄木細工ファイル: 列形式のストレージ形式をサポート
- JSON ファイル: 標準の JSON 形式がサポートされています
- JSONL ファイル: 1 行に 1 つの JSON オブジェクトを含む形式がサポートされています

**ファイルのインポート手順**:
- DuckDB の公式推奨インポート方法に基づく
- 自動フォーマット認識と読み込み
- 相対パスと絶対パスをサポート
- 圧縮ファイルの直接ロードをサポート

**使用する場合:**
- データをクエリ、分析、視覚化する必要がある。
- データに対して統計的集計とカテゴリクエリを実行する必要があります。
- 複数の形式のデータ ファイルを処理および分析する必要がある。
- データ視覚化チャートを生成する必要があります。

**使用例:**
- 販売データを分析し、販売傾向グラフを作成します
- CSV ファイル内のユーザー データを処理してユーザー行動分析を行う
- Excelファイルの財務データを分析し、財務レポートを作成します
- ログデータをJSON形式で処理してログ分析を行う
