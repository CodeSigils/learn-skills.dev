Suitable for querying, analyzing, and visualizing data. For example, analyze data from CSV, Excel, Parquet, JSON, JSONL, and other files, perform statistical aggregation and classification queries. First import the data, then use SQL statements to query, analyze, and visualize it.

**Supported file formats**:
- CSV files: Direct loading supported, including compressed CSV files (e.g., .gz)
- Excel files: .xlsx and .xls formats supported
- Parquet files: Columnar storage format supported
- JSON files: Standard JSON format supported
- JSONL files: One JSON object per line supported

**File import instructions**:
- Based on DuckDB's official recommended import methods
- Automatic file format recognition and loading
- Supports relative and absolute paths
- Direct loading of compressed files supported

**WHEN TO USE**:
- When you need to query, analyze, and visualize data.
- When you need to perform statistical aggregation and classification queries on data.
- When you need to process and analyze data files in multiple formats.
- When you need to generate data visualization charts.

**EXAMPLE USAGE**:
- Analyze sales data and generate sales trend charts
- Process user data from CSV files and perform user behavior analysis
- Analyze financial data from Excel files and generate financial reports
- Process JSON-format log data and perform log analysis
