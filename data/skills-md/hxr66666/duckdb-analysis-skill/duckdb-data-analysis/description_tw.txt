適用於查詢、分析和視覺化資料。例如，分析 CSV、Excel、Parquet、JSON、JSONL 等文件格式的數據，執行統計聚合和分類查詢。首先導入數據，然後使用SQL語句對其進行查詢、分析和視覺化。

**支援的文件格式**：
- CSV 檔案：支援直接加載，包括壓縮的 CSV 檔案（例如 .gz）
- Excel 檔案：支援 .xlsx 和 .xls 格式
- Parquet 檔案：支援列式儲存格式
- JSON 檔案：支援標準 JSON 格式
- JSONL 檔案：支援每行一個 JSON 物件的格式

**文件導入說明**：
- 基於DuckDB官方推薦的導入方式
- 自動檔案格式識別和載入
- 支持相對和絕對路徑
- 支援直接載入壓縮文件

**何時使用：**
- 您需要查詢、分析和視覺化資料。
- 您需要對資料進行統計聚合和分類查詢。
- 您需要處理和分析多種格式的資料檔案。
- 您需要產生資料視覺化圖表。

**使用範例：**
- 分析銷售數據並產生銷售趨勢圖
- 處理CSV檔案中的使用者資料並進行使用者行為分析
- 分析Excel文件中的財務資料並產生財務報告
- 處理JSON格式的日誌資料並進行日誌分析
