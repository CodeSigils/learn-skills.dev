适用于查询、分析和可视化数据。例如，分析来自 CSV、Excel、Parquet、JSON、JSONL 等文件的数据，执行统计聚合和分类查询。首先导入数据，然后使用SQL语句对其进行查询、分析和可视化。

**支持的文件格式**：
- CSV 文件：支持直接加载，包括压缩的 CSV 文件（例如 .gz）
- Excel 文件：支持 .xlsx 和 .xls 格式
- Parquet 文件：支持列式存储格式
- JSON 文件：支持标准 JSON 格式
- JSONL 文件：支持每行一个 JSON 对象

**文件导入说明**：
- 基于DuckDB官方推荐的导入方式
- 自动文件格式识别和加载
- 支持相对和绝对路径
- 支持直接加载压缩文件

**何时使用**：
- 当您需要查询、分析和可视化数据时。
- 当您需要对数据进行统计聚合和分类查询时。
- 当您需要处理和分析多种格式的数据文件时。
- 当您需要生成数据可视化图表时。

**使用示例**：
- 分析销售数据并生成销售趋势图
- 处理来自CSV文件的用户数据并执行用户行为分析
- 分析Excel文件中的财务数据并生成财务报告
- 处理JSON格式的日志数据并进行日志分析
