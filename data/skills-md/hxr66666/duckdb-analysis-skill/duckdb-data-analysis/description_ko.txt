데이터 쿼리, 분석, 시각화에 적합합니다. 예를 들어 통계 집계, 분류, 쿼리를 위해 CSV, Excel, Parquet, JSON, JSONL 파일의 데이터를 분석합니다. 먼저 데이터를 가져온 다음 SQL 문을 사용하여 데이터를 쿼리, 분석, 시각화합니다.

**지원되는 파일 형식**:
- CSV 파일: 압축된 CSV 파일(예: .gz)을 포함한 직접 로딩 지원
- Excel 파일: .xlsx 및 .xls 형식 지원
- Parquet 파일: 컬럼형 저장 형식 지원
- JSON 파일: 표준 JSON 형식 지원
- JSONL 파일: 한 줄에 하나의 JSON 개체가 포함된 형식 지원

**파일 가져오기 지침**:
- DuckDB의 공식 권장 가져오기 방법을 기반으로 합니다.
- 자동 파일 형식 인식 및 로딩
- 상대 경로와 절대 경로를 지원합니다.
- 압축파일 직접 로딩 지원

**사용 시기:**
- 데이터를 쿼리, 분석, 시각화해야 합니다.
- 데이터에 대한 통계적 집계 및 분류 쿼리를 수행해야 합니다.
- 다양한 형식의 데이터 파일을 처리하고 분석해야 합니다.
- 데이터 시각화 차트를 생성해야 합니다.

**사용 예:**
- 판매 데이터 분석 및 판매 동향 차트 생성
- 사용자 행동 분석을 위해 CSV 파일의 사용자 데이터를 처리합니다.
- Excel 파일의 재무 데이터를 분석하고 재무 보고서를 생성합니다.
- 로그 분석을 위해 로그 데이터를 JSON 형식으로 처리
