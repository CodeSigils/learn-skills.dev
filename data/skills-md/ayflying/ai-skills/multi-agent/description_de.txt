OpenCode Multi-Agent-Konfiguration für parallele Zusammenarbeit. Unterstützt die gleichzeitige Arbeit mehrerer Agenten und ermöglicht so ein Pipeline-Entwicklungsmodell.  
Verwenden Sie dies, wenn: (1) mehrere Agenten parallel arbeiten müssen (2) ein Master die Agenten koordinieren muss (3) ein standardisierter Prozess von Design → Entwicklung → Abnahme → Testen erforderlich ist (4) die Multi-Agenten-Zusammenarbeitsfunktion von OpenCode konfiguriert werden muss
