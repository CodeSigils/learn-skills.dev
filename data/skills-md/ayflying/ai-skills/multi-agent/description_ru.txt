Конфигурация многоагентного параллельного сотрудничества OpenCode. Поддерживает одновременную работу нескольких агентов, обеспечивая модель конвейерной разработки.  
Используйте, когда: (1) Несколько агентов должны работать параллельно (2) Для координации агентов необходим мастер (3) Требуется стандартизированный процесс проектирования → разработка → приемка → тестирование (4) Необходимо настроить возможность многоагентной совместной работы OpenCode
