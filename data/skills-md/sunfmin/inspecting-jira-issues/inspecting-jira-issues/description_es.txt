Úselo cuando comience a trabajar en un ticket de Jira y necesite contexto completo, no solo un resumen, sino también archivos adjuntos (capturas de pantalla, maquetas), comentarios (donde generalmente se encuentran las reproducciones), problemas vinculados y campos personalizados. Úselo cuando `acli jira workitem view` devuelva una descripción que sea solo una referencia multimedia como `image-20260427-021811.png` y no pueda ver cuál es el error. Úselo cuando un agente de IA esté a punto de adivinar un error del resumen o de pedirle al usuario que pegue una captura de pantalla que podría recuperar por sí mismo. Úselo cuando el curl autenticado contra la API REST de Jira devuelva 401, 403 o 406.
