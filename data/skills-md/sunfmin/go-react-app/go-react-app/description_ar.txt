دستور تطوير متكامل لمشاريع Go+React. يغطي تصميم OpenAPI-first (ogen for Go، orval for React)، واختبار التكامل مع PostgreSQL حقيقي (بدون نماذج)، واختبار Playwright E2E مقابل واجهات برمجة التطبيقات الخلفية الحقيقية، وبنية طبقة الخدمة مع نمط البناء، وسير عمل التطوير الاختباري الأول، وإعداد البنية التحتية لـ Playwright E2E مع مراسل صديق للذكاء الاصطناعي، وgo-bus للوظائف غير المتزامنة ورسائل النشر/الفرعية. استخدم هذه المهارة عند العمل على مشروع Go+React متكامل، أو كتابة اختبارات تكامل Go، أو تنفيذ معالجات ogen، أو إعداد إنشاء كود أورفال، أو كتابة أو إصلاح اختبارات Playwright E2E مقابل واجهة خلفية حقيقية، أو تصميم بنية الخدمة مع حقن التبعية، أو اتباع تطوير OpenAPI-first API، أو إعداد Playwright في مشروع جديد أو حالي، أو تكوين البنية التحتية لاختبار E2E، أو إنشاء مساعدين للاختبار ومراسلي الذكاء الاصطناعي، أو تنفيذ وظائف غير متزامنة، أو عمال الخلفية، أو مراسلة النشر/الفرعية، البنية المستندة إلى الحدث، أو عندما يذكر المستخدم دستور المشروع، أو تصميم المخطط أولاً، أو اختبار ServiceHTTP، أو حاويات الاختبار، أو تأكيدات cmp.Diff، أو تقارير الاختبار الصديقة للذكاء الاصطناعي، أو التقاط أخطاء وحدة التحكم، أو إعداد اختبار E2E، أو go-bus، أو pgbus، أو قوائم انتظار الرسائل، أو نشر الأحداث.
