Constitution de développement full-stack pour les projets Go+React. Couvre la conception OpenAPI first (ogen pour Go, orval pour React), les tests d'intégration avec le vrai PostgreSQL (pas de simulation), les tests Playwright E2E avec de vraies API backend, l'architecture de couche de service avec modèle de générateur, le flux de travail de développement test-first, la configuration de l'infrastructure Playwright E2E avec un journaliste compatible avec l'IA et le go-bus pour les tâches asynchrones et la messagerie pub/sub. Utilisez cette compétence lorsque vous travaillez sur un projet full-stack Go+React, écrivez des tests d'intégration Go, implémentez des gestionnaires ogen, configurez la génération de code orval, écrivez ou corrigez des tests Playwright E2E sur un véritable backend, concevez une architecture de service avec injection de dépendances, suivez le développement d'API OpenAPI-first, configurez Playwright dans un projet nouveau ou existant, configurez l'infrastructure de test E2E, créez des assistants de test et des rapporteurs IA, implémentez des tâches asynchrones, des travailleurs en arrière-plan, une messagerie pub/sub, une architecture basée sur les événements ou lorsque l'utilisateur mentionne la constitution du projet, la conception axée sur le schéma, les tests ServeHTTP, les conteneurs de test, les assertions cmp.Diff, les rapports de tests adaptés à l'IA, la capture d'erreurs de la console, la configuration des tests E2E, le go-bus, le pgbus, les files d'attente de messages ou la publication d'événements.
