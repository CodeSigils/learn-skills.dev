Конституция полнофункциональной разработки для проектов Go+React. Охватывает проектирование с упором на OpenAPI (ogen для Go, orval для React), интеграционное тестирование с реальным PostgreSQL (без макетов), тестирование Playwright E2E с реальными серверными API, архитектуру сервисного уровня с шаблоном компоновщика, рабочий процесс разработки с упором на тестирование, настройку инфраструктуры Playwright E2E с дружественным к AI генератором отчетов и go-bus для асинхронных заданий и обмена сообщениями издателя и подписки. Используйте этот навык при работе над полностековым проектом Go+React, написании интеграционных тестов Go, реализации обработчиков ogen, настройке генерации кода Orval, написании или исправлении E2E-тестов Playwright для реального бэкэнда, проектировании сервисной архитектуры с внедрением зависимостей, после разработки API-интерфейса OpenAPI, настройке Playwright в новом или существующем проекте, настройке инфраструктуры тестирования E2E, создании помощников по тестированию и репортеров AI, реализации асинхронных заданий, фоновых рабочих процессов, обмена сообщениями публикации и подписки, архитектуру, управляемую событиями, или когда пользователь упоминает структуру проекта, проектирование с приоритетом схемы, тестирование ServeHTTP, тестовые контейнеры, утверждения cmp.Diff, отчеты о тестах, удобные для искусственного интеллекта, захват ошибок консоли, настройку тестирования E2E, go-bus, pgbus, очереди сообщений или публикацию событий.
