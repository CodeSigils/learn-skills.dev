Constitución de desarrollo full-stack para proyectos Go+React. Cubre el primer diseño de OpenAPI (ogen para Go, orval para React), pruebas de integración con PostgreSQL real (sin simulaciones), pruebas de Playwright E2E contra API de backend reales, arquitectura de capa de servicio con patrón de construcción, flujo de trabajo de desarrollo de prueba primero, configuración de infraestructura de Playwright E2E con reportero compatible con IA y go-bus para trabajos asíncronos y mensajes de publicación/subscripción. Utilice esta habilidad siempre que trabaje en un proyecto de pila completa de Go+React, escriba pruebas de integración de Go, implemente controladores de ogen, configure la generación de código orval, escriba o corrija pruebas de Playwright E2E contra un backend real, diseñe arquitectura de servicio con inyección de dependencia, siga el primer desarrollo de API de OpenAPI, configure Playwright en un proyecto nuevo o existente, configure la infraestructura de prueba de E2E, cree asistentes de prueba y reporteros de IA, implemente trabajos asincrónicos, trabajadores en segundo plano, mensajería pub/sub, impulsado por eventos arquitectura, o cuando el usuario menciona la constitución del proyecto, el diseño de esquema primero, las pruebas ServeHTTP, los contenedores de prueba, las afirmaciones cmp.Diff, los informes de pruebas compatibles con la IA, la captura de errores de la consola, la configuración de las pruebas E2E, go-bus, pgbus, colas de mensajes o publicación de eventos.
