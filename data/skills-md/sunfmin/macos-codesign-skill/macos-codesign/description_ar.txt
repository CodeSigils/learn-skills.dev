قم بإعداد شهادة توقيع التعليمات البرمجية موقعة ذاتيًا لتطوير تطبيق macOS بحيث تستمر أذونات TCC (تسجيل الشاشة والميكروفون وإمكانية الوصول) عبر عمليات إعادة البناء. استخدم هذه المهارة عند العمل على تطبيق macOS الذي يحتاج إلى أذونات مستمرة، أو إعداد توقيع التعليمات البرمجية للتطوير المحلي، أو إصلاح مشكلات "تم إبطال الإذن بعد إعادة البناء"، أو عندما يذكر المستخدم أذونات TCC، أو مشكلات التوقيع المخصصة، أو CODE_SIGN_IDENTITY، أو الشهادة الموقعة ذاتيًا، أو تصميم التعليمات البرمجية، أو أذونات macOS المستمرة لإصدارات التطوير.
