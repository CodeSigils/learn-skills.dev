Настройте самозаверяющий сертификат подписи кода для разработки приложений macOS, чтобы разрешения TCC (запись экрана, микрофон, специальные возможности) сохранялись при пересборках. Используйте этот навык всякий раз, когда работаете над приложением macOS, которому требуются постоянные разрешения, настраиваете подпись кода для локальной разработки, устраняете проблемы «разрешения отозваны после пересборки» или когда пользователь упоминает разрешения TCC, специальные проблемы с подписью, CODE_SIGN_IDENTITY, самозаверяющий сертификат, кодовое обозначение или постоянные разрешения macOS для сборок разработки.
