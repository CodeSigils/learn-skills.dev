Configure un certificado de firma de código autofirmado para el desarrollo de aplicaciones macOS para que los permisos TCC (grabación de pantalla, micrófono, accesibilidad) persistan durante las reconstrucciones. Utilice esta habilidad siempre que trabaje en una aplicación macOS que necesite permisos persistentes, configure la firma de código para el desarrollo local, solucione problemas de "permiso revocado después de la reconstrucción" o cuando el usuario mencione permisos TCC, problemas de firma ad-hoc, CODE_SIGN_IDENTITY, certificado autofirmado, diseño de código o permisos persistentes de macOS para compilaciones de desarrollo.
