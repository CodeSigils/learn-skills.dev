Configurez un certificat de signature de code auto-signé pour le développement d'applications macOS afin que les autorisations TCC (enregistrement d'écran, microphone, accessibilité) persistent lors des reconstructions. Utilisez cette compétence lorsque vous travaillez sur une application macOS nécessitant des autorisations persistantes, configurez la signature de code pour le développement local, corrigez les problèmes d'« autorisation révoquée après reconstruction », ou lorsque l'utilisateur mentionne des autorisations TCC, des problèmes de signature ad hoc, CODE_SIGN_IDENTITY, un certificat auto-signé, une conception de code ou des autorisations macOS persistantes pour les versions de développement.
