Competenza di automazione a ciclo completo di Playwright: installa Playwright e i file binari del browser, recupera e memorizza nella cache la documentazione ufficiale da playwright.dev, supporta suite di test (funzionali, accessibilità, prestazioni, regressione visiva), esegue audit con reporter strutturati e genera report di audit Markdown con consigli di miglioramento basati sull'intelligenza artificiale. Attiva questa abilità ogni volta che l'utente menziona Drammaturgo, test E2E, automazione del browser, audit web, impalcature di test, pipeline di test CI/CD, regressione visiva, test di accessibilità o chiede di testare, controllare o ispezionare qualsiasi sito web o applicazione web, anche se non usa la parola "abilità".
