Compétence d'automatisation de cycle complet de Playwright : installe les binaires de Playwright et du navigateur, récupère et met en cache la documentation officielle à partir de playwright.dev, échafaude les suites de tests (fonctionnelles, accessibilité, performances, régression visuelle), exécute des audits avec des journalistes structurés et génère des rapports d'audit Markdown avec des recommandations d'amélioration basées sur l'IA. Déclenchez cette compétence chaque fois que l'utilisateur mentionne Playwright, les tests E2E, l'automatisation du navigateur, les audits Web, les échafaudages de tests, les pipelines de tests CI/CD, la régression visuelle, les tests d'accessibilité, ou demande de tester, d'auditer ou d'inspecter un site Web ou une application Web, même s'il n'utilise pas le mot « compétence ».
