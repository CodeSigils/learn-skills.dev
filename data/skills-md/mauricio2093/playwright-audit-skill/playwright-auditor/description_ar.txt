مهارة أتمتة الكاتب المسرحي ذات الدورة الكاملة: تثبيت ثنائيات الكاتب المسرحي والمتصفح، وجلب الوثائق الرسمية وتخزينها مؤقتًا من playwright.dev، ومجموعات اختبار السقالات (الوظيفية، وإمكانية الوصول، والأداء، والانحدار البصري)، وتنفيذ عمليات التدقيق مع المراسلين المنظمين، وإنشاء تقارير تدقيق Markdown مع توصيات تحسين تعتمد على الذكاء الاصطناعي. قم بتشغيل هذه المهارة عندما يذكر المستخدم Playwright، أو اختبار E2E، أو أتمتة المتصفح، أو عمليات تدقيق الويب، أو سقالات الاختبار، أو خطوط أنابيب اختبار CI/CD، أو الانحدار البصري، أو اختبار إمكانية الوصول، أو يطلب اختبار أو تدقيق أو فحص أي موقع ويب أو تطبيق ويب - حتى لو لم يستخدموا كلمة "مهارة".
