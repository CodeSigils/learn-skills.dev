フルサイクルの Playwright 自動化スキル: Playwright とブラウザーのバイナリをインストールし、playwright.dev から公式ドキュメントをフェッチしてキャッシュし、テスト スイート (機能、アクセシビリティ、パフォーマンス、視覚的回帰) を足場にし、構造化されたレポーターを使用して監査を実行し、AI 主導の改善推奨事項を含む Markdown 監査レポートを生成します。ユーザーが Playwright、E2E テスト、ブラウザ自動化、Web 監査、テスト スキャフォールディング、CI/CD テスト パイプライン、ビジュアル リグレッション、アクセシビリティ テストについて言及したとき、または Web サイトや Web アプリケーションのテスト、監査、検査を依頼したときは常に、「スキル」という言葉を使用していなくても、このスキルをトリガーします。
