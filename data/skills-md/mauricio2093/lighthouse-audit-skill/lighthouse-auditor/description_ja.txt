環境設定から結果の解釈まで、Web サイトと Web アプリケーションの Lighthouse CLI 監査を実行します。ユーザーがパフォーマンス、アクセシビリティ、SEO、ベスト プラクティス、PWA の準備状況、Core Web Vitals、Lighthouse CI、バッチ URL スキャン、localhost ページ、または運用ページを監査したい場合に使用します。 Linux または WSL での Lighthouse のセットアップとトラブルシューティング、「Chrome が見つかりません」や「ECONNREFused 127.0.0.1」などのブラウザ ランチャーのエラー、Chrome または Chromium の検出の問題、PageSpeed スタイルの分析リクエスト、または実用的な推奨事項を含む Lighthouse HTML および JSON レポートを生成するリクエストに対して、このスキルをトリガーします。
