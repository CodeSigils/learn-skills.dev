Ejecute auditorías Lighthouse CLI para sitios web y aplicaciones web desde la configuración del entorno hasta la interpretación de los resultados. Úselo cuando el usuario desee auditar el rendimiento, la accesibilidad, el SEO, las mejores prácticas, la preparación de PWA, Core Web Vitals, Lighthouse CI, escaneos de URL por lotes, páginas de host local o páginas de producción. Active esta habilidad para la configuración y solución de problemas de Lighthouse en Linux o WSL, fallas en el iniciador del navegador como "No se puede encontrar Chrome" o "ECONNREFUSED 127.0.0.1", problemas de detección de Chrome o Chromium, solicitudes de análisis de estilo PageSpeed ​​o cualquier solicitud para generar informes HTML y JSON de Lighthouse con recomendaciones procesables.
