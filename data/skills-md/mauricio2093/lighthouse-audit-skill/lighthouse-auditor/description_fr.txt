Exécutez des audits Lighthouse CLI pour les sites Web et les applications Web depuis la configuration de l'environnement jusqu'à l'interprétation des résultats. À utiliser lorsque l'utilisateur souhaite auditer les performances, l'accessibilité, le référencement, les meilleures pratiques, la préparation PWA, Core Web Vitals, Lighthouse CI, les analyses d'URL par lots, les pages d'hôte local ou les pages de production. Déclenchez cette compétence pour la configuration et le dépannage de Lighthouse sous Linux ou WSL, les échecs du lanceur de navigateur tels que « Impossible de trouver Chrome » ou « ECONNREFUSED 127.0.0.1 », les problèmes de détection de Chrome ou de Chromium, les demandes d'analyse de style PageSpeed ​​ou toute demande de génération de rapports Lighthouse HTML et JSON avec des recommandations exploitables.
