قم بتشغيل عمليات تدقيق Lighthouse CLI لمواقع الويب وتطبيقات الويب بدءًا من إعداد البيئة وحتى تفسير النتائج. يُستخدم عندما يريد المستخدم تدقيق الأداء، أو إمكانية الوصول، أو تحسين محركات البحث، أو أفضل الممارسات، أو جاهزية PWA، أو مؤشرات الويب الأساسية، أو Lighthouse CI، أو عمليات فحص URL المجمعة، أو صفحات المضيف المحلي، أو صفحات الإنتاج. قم بتشغيل هذه المهارة لإعداد Lighthouse واستكشاف الأخطاء وإصلاحها في Linux أو WSL، أو فشل مشغل المتصفح مثل "لا يمكن العثور على Chrome" أو "ECONNREFUSED 127.0.0.1"، أو مشكلات اكتشاف Chrome أو Chromium، أو طلبات تحليل نمط PageSpeed، أو أي طلب لإنشاء تقارير Lighthouse HTML وJSON مع توصيات قابلة للتنفيذ.
