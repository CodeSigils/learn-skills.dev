Используйте при разработке пакетов R, которым необходимо правильно обрабатывать ошибки, предупреждения и условия. Охватывает: (1) cli_abort/cli_warn/cli_inform для создания условий с форматированием, (2) Контекст вызова ошибки с помощью caller_env() и caller_arg(), (3) Помощники проверки ввода, которые сообщают о правильной функции, (4) Цепочка ошибок с помощью try_fetch() и родительского аргумента, (5) Тестирование ошибочных состояний с помощью снимков testthat.
