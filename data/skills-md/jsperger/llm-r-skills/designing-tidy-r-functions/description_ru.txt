Используйте при разработке API-интерфейсов функций R, проверке кода R на наличие проблем с дизайном, написании функций для пакетов R или оценке порядка аргументов и решений об именах. НЕ охватывает: стиль/линтинг, обработку ошибок (rlang-условия), вывод CLI (r-lib:cli), тестирование (testing-r-packages), соответствие CRAN (cran-extrachecks).
