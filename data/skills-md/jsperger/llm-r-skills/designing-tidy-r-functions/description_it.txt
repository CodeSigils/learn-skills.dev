Da utilizzare durante la progettazione di API di funzioni R, la revisione del codice R per problemi di progettazione, la scrittura di funzioni per pacchetti R o la valutazione delle decisioni sull'ordinamento e la denominazione degli argomenti. NON copre: stile/linting, gestione degli errori (condizioni rlang), output CLI (r-lib:cli), test (testing-r-packages), conformità CRAN (cran-extrachecks).
