À utiliser lors de l'écriture de code R qui manipule des expressions, construit du code par programme ou doit comprendre les mécanismes de désamorçage/injection de rlang. Couvre : désamorçage avec expr()/enquo()/enquos(), suivi de l'environnement de quosure, injection avec !!/!!!/{{, construction de symboles avec sym()/syms(). Ne couvre PAS : les modèles de programmation de masques de données (évaluation soignée), la gestion des erreurs (conditions rlang), la conception de fonctions (conception-tidy-r-fonctions).
