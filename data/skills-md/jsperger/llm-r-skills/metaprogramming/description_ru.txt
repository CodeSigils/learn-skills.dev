Используйте при написании кода R, который манипулирует выражениями, программно создает код или требует понимания механики обезвреживания/внедрения rlang. Охватывает: обезвреживание с помощью expr()/enquo()/enquos(), отслеживание среды quosure, внедрение с помощью !!/!!!/{{, построение символов с помощью sym()/syms(). НЕ охватывает: шаблоны программирования масок данных (аккуратная оценка), обработку ошибок (rlang-условия), проектирование функций (проектирование аккуратных r-функций).
