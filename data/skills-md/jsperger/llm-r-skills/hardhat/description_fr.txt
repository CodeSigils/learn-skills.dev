À utiliser lors de la création d'un package de modélisation R nécessitant un prétraitement standardisé pour les interfaces de formule, de bloc de données, de matrice et de recette. Couvre : mold() pour le prétraitement des données d'entraînement, forge() pour la validation des données de prédiction, les plans, les constructeurs de modèles, les fonctions Spruce pour le formatage de sortie.
