Используйте при создании пакета моделирования R, которому требуется стандартизированная предварительная обработка для интерфейсов формул, фреймов данных, матриц и рецептов. Охватывает: form() для предварительной обработки обучающих данных, forge() для проверки прогнозируемых данных, чертежи, конструкторы моделей, функции spruce для форматирования вывода.
