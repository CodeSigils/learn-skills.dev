Da utilizzare quando l'utente richiede 提PR, 提RFC, 关联 PR 和 RFC, 触发流水线, /retest, 看流水线过没过, 看门禁日志, 为什么 CI 挂了 o拉取失败 stage 日志 su un repository gitcode.com come mindspore/mindformers. Richiede GITCODE_TOKEN per le azioni API GitCode in uscita.
