Управляйте полным рабочим процессом внесения вклада в GitCode через GitCode REST API: составляйте проекты тел PR/RFC из шаблонов репо, открывайте или обновляйте запросы на включение, открывайте проблемы RFC, связывайте PR и RFC, запускайте/повторно тестируйте, опрашивайте метки CI и автоматически извлекайте неудачные журналы MindSpore-Bot OpenLiBing с помощью встроенного инструмента gitcode_pr_gate_log.py. Используйте, когда пользователь запрашивает 提PR, 提RFC, 关联 PR 和 RFC, 触发流水线, /retest, 看流水线过没过, 看门禁日志, 为什么 CI 挂了 или拉取失败 на этапе 日志 в репозитории gitcode.com, таком как Mindspore/mindformers. Требуется GITCODE_TOKEN для внешних действий GitCode API.
