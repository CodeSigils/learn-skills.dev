GitCode REST API 経由で完全な GitCode コントリビューション ワークフローを推進します。リポジトリ テンプレートからの PR/RFC 本文のドラフト、プル リクエストのオープンまたは更新、RFC の問題のオープン、PR と RFC のリンク、トリガー/再テスト、CI ラベルのポーリング、バンドルされている gitcode_pr_gate_log.py ツール経由で失敗した MindSpore-Bot OpenLiBing ゲート ログをヘッドレスで取得します。ユーザーが、mindspore/mindformers などの gitcode.com リポジトリで、提PR、提RFC、关联 PR および RFC、接触流水線、/retest、看流水線过没过、看门禁日志、為什么 CI 挂了、または拉取失败 stage 日志を要求する場合に使用します。外部への GitCode API アクションには GITCODE_TOKEN が必要です。
