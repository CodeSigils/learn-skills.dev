GitCode REST API를 통해 전체 GitCode 기여 워크플로우를 구동합니다. 번들로 제공되는 gitcode_pr_gate_log.py 도구를 통해 repo 템플릿에서 PR/RFC 본문 초안 작성, 풀 요청 열기 또는 업데이트, RFC 문제 열기, PR 및 RFC 연결, 트리거/재테스트, CI 라벨 폴링, 실패한 MindSpore-Bot OpenLiBing 게이트 로그 가져오기 등을 헤드리스로 수행할 수 있습니다. 사용자가 提PR, 提RFC, 关联 PR 와 RFC, 触发流水线, /retest, 看流水线过没过, 看门禁日志, 为什么 CI 挂了 또는 拉取失败 단계를 요청할 때 사용합니다. mindpore/mindformers와 같은 gitcode.com 저장소의 日志. 외부 GitCode API 작업에는 GITCODE_TOKEN이 필요합니다.
