Führen Sie Änderungsprotokolle gemäß der Spezifikation „Keep a Changelog 1.1.0“ (keepachangelog.com). Verwenden Sie diese Option, wenn Benutzer eine neue CHANGELOG.md erstellen, ein vorhandenes Änderungsprotokoll mit den letzten Änderungen aktualisieren, Einträge zum Abschnitt „Unveröffentlicht“ hinzufügen oder den Git-Verlauf überprüfen möchten, um Änderungsprotokolleinträge vorzuschlagen. Unterstützt jeden Projekttyp und jede Sprache.
