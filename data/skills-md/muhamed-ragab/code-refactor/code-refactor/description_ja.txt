React/TypeScript プロジェクト向けのインテリジェントなファイルレベルのリファクタリング。ファイルの名前変更、移動、分割を処理します 
ファイルサイズ、コンポーネントの純度を自動的に検出し、最適なコンポーネントを選択するインテリジェントな分析による操作 
リファクタリング戦略。戦略パターンを使用して選択します: 大きなファイルの場合はファイル分割、不純なファイルの場合はコンポーネント抽出 
コンポーネント、または簡単な場合は単純な名前変更/移動。ユーザーが再構築したいときは常にこのスキルを使用してください 
ファイルの名前変更、移動、分割、またはコンポーネント アーキテクチャの改善によってコードベースを変更します。ぜひこのスキルを使ってみてください 
ユーザーが「ファイル名の変更」、「ファイルの移動」、「ファイルの分割」、「新しいファイルに抽出」、「コードベースの再構築」と言及したとき、 
「ファイルを整理する」、「ファイル構造をリファクタリングする」、「コンポーネントを純粋にする」、「フックするロジックを抽出する」、または類似のもの 
ファイルの再構築またはコード品質の要求。
