componenti o semplice ridenominazione/spostamento per casi semplici. Utilizza questa competenza ogni volta che un utente desidera ristrutturare 
la loro base di codice rinominando, spostando, dividendo file o migliorando l'architettura dei componenti. Assicurati di utilizzare questa abilità 
quando gli utenti menzionano: "rinomina file", "sposta file", "dividi file", "estrai in un nuovo file", "ristruttura codebase",
