Intelligentes Refactoring auf Dateiebene für React/TypeScript-Projekte. Behandelt das Umbenennen, Verschieben und Teilen von Dateien 
Operationen mit intelligenter Analyse, die automatisch Dateigröße und Komponentenreinheit erkennt und das Optimum auswählt 
Refactoring-Strategie. Verwendet Strategiemuster zur Auswahl: Dateiaufteilung für große Dateien, Komponentenextraktion für unreine 
Komponenten oder einfaches Umbenennen/Verschieben für einfache Fälle. Verwenden Sie diese Fähigkeit immer dann, wenn ein Benutzer eine Umstrukturierung vornehmen möchte 
ihre Codebasis durch Umbenennen, Verschieben, Teilen von Dateien oder Verbessern der Komponentenarchitektur. Stellen Sie sicher, dass Sie diese Fähigkeit nutzen 
wenn Benutzer Folgendes erwähnen: „Datei umbenennen“, „Datei verschieben“, „Datei teilen“, „In neue Datei extrahieren“, „Codebasis umstrukturieren“, 
„Dateien organisieren“, „Dateistruktur umgestalten“, „Komponente rein machen“, „Logik zum Hook extrahieren“ oder ähnliches 
Dateiumstrukturierung oder Codequalitätsanfragen.
