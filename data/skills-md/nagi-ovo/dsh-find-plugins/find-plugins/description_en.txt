When users look for plugins for DeepSeek Harness, they say things like “Is there a plugin that can…”, “Help me install XX”, or “What fun stuff is in the ecosystem?”. We scan all public repositories tagged with the dsh‑plugin topic on GitHub, filter candidates, wait for the user’s decision, then infer the installation method from the repository’s manifest and verify the mounting. The system only handles finding and installing; creating new plugins is delegated to make‑dsh‑plugin.
