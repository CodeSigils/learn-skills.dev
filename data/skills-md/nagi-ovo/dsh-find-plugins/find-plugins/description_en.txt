When users want to find a plugin for DeepSeek Harness they say: “Is there a plugin that can…”, “Help me install XX”, “What’s fun in the ecosystem?” By scanning the dsh‑plugin topic across all of GitHub we discover public repositories from individuals and organizations, filter candidates, wait for the user’s decision, then determine the installation method from the repository’s declaration and verify the mounting. It only handles finding and installing; developing new plugins is delegated to make‑dsh‑plugin.
