Wenn ein Benutzer ein Plugin für DeepSeek Harness finden möchte, sagt er Dinge wie „Gibt es ein Plugin, das ... kann?“, „Helfen Sie mir bei der InstallationXX“ oder „Welche lustigen Dinge gibt es im Ökosystem?“. Indem wir das dsh-plugin-Thema auf GitHub scannen, entdecken wir öffentliche Repositories von Einzelpersonen und Organisationen, filtern die Kandidaten, warten auf die Entscheidung des Benutzers, bestimmen dann die Installationsmethode anhand der Deklaration des Repositorys und überprüfen die Bereitstellung. Diese Komponente übernimmt nur das Suchen und Installieren; Die Entwicklung neuer Plugins wird an make‑dsh‑plugin übergeben.
