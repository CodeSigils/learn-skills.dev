استخدم هذه المهارة عندما يقدم المستخدم هدفًا أو قائمة أهداف (عناوين IP وأسماء المضيفين وعناوين URL والشبكات الفرعية) ويطلب مهاجمتها أو اختبارها أو اختراقها أو مسحها أو تقييمها أو اختبارها. استخدم هذه المهارة أيضًا عندما يشير المستخدم إلى مشاركة حالية - الاستئناف أو المتابعة أو الالتقاط أو التحقق من الحالة أو السؤال عن الخطوات التالية. عبارات التشغيل: "attack X"، "pentest X"، "hack X"، "scan X"، "بدء اختبار X"، "pop X"، "CTF target X"، "engage X"، "هذه الأهداف"، "استئناف المشاركة"، "استلامها"، "مواصلة الاختبار"، "الخطوات التالية"، "أين كنا"، "الاستئناف"، "تقديم المشورة للخطوات التالية"، "ماذا يجب أن نفعل بعد ذلك"، "حالة المشاركة". هذه هي نقطة الدخول لجميع اختبارات الاختراق متعددة المراحل، مثل إعادة الاستطلاع، ورسم خرائط سطح الهجوم، وتسلسل نقاط الضعف، وطرق المهارات التقنية للاستغلال. لا تستخدم عندما يقوم المستخدم بتسمية تقنية واحدة محددة (على سبيل المثال، "تشغيل kerberoasting ضد X").
