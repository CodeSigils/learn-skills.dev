Интегрируйтесь с Match-Trade CRM-API (также известным как уровень Broker-API CRM) через REST и gRPC. Используйте этот навык для создания, подписания, отправки и отладки вызовов в Match-Trader CRM: аутентификация с помощью ключа API на предъявителя, создание и обновление учетных записей и торговых счетов, чтение предложений / ветвей / ролей / платежных шлюзов, внесение и снятие средств вручную, ввод / вывод средств, изменение пароля и кредитного плеча, открытие / закрытие / редактирование позиций и заказов, получение торговых данных (открытые и закрытые позиции, реестры, снимки баланса), чтение событий временной шкалы CRM, отправка уведомлений о входящих сообщениях, создание одноразового токена (OTT) Ссылки SSO, работа с Prop Trading v2 (задачи, соревнования, оценки, дополнения, снимки) и ставки/результаты рынка прогнозов. Охватывает потоковые сервисы gRPC (счета, позиции, реестр, ордера, котировки, группы, торговые события, символы, акции, реквизиты) и веб-перехватчики CRM-событий. Триггеры: «Match-Trader CRM API», «crm-api», «broker api», «интеграция match-trade», «API создания торгового счета», «API ручного депозита», PartnerID, OfferUuid, systemUuid, токен на предъявителя 401/403, ошибка 415/500 «Внутренняя ошибка приложения», «Неверный apiToken», несоответствие валюты шлюза, вход OTT/SSO.
