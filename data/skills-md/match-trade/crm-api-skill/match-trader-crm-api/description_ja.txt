REST および gRPC を介して Match-Trade CRM-API (別名 Broker-API CRM レイヤー) と統合します。このスキルを使用して、Match-Trader CRM への呼び出しの構築、署名、送信、デバッグを行います。Bearer API キーによる認証、アカウントと取引アカウントの作成と更新、オファー/支店/ロール/支払いゲートウェイの読み取り、手動入出金、与信/出金、パスワードとレバレッジの変更、ポジションと注文のオープン/クローズ/編集、取引データの取得 (オープンおよびクローズのポジション、元帳、残高スナップショット)、CRM タイムライン イベントの読み取り、受信箱通知の送信、生成ワンタイム トークン (OTT) SSO リンク、Prop Trading v2 (チャレンジ、コンペティション、評価、アドオン、スナップショット)、および予測市場のベット/結果と連携します。 gRPC ストリーミング サービス (口座、ポジション、元帳、注文、見積、グループ、取引イベント、シンボル、株式、小道具) と CRM イベント Webhook をカバーします。トリガー: 「Match-Trader CRM API」、「crm-api」、「ブローカー API」、「マッチトレード統合」、「取引口座作成 API」、「手動入金 API」、partnerID、offerUuid、systemUuid、ベアラー トークン 401/403、エラー 415/500 「内部アプリケーション エラー」、「無効な apiToken」、ゲートウェイ通貨の不一致、OTT / SSOログインします。
