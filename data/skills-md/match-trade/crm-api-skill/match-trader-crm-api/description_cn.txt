通过 REST 和 gRPC 与 Match-Trade CRM-API（又名 Broker-API CRM 层）集成。使用此技能来构建、签署、发送和调试对 Match-Trader CRM 的调用：使用 Bearer API 密钥进行身份验证，创建和更新帐户和交易帐户，读取报价/分支机构/角色/支付网关，进行手动存款和取款，贷入/贷出，更改密码和杠杆，开仓/平仓/编辑头寸和订单，提取交易数据（开仓和平仓头寸、账本、余额快照），读取 CRM 时间线事件，发送收件箱通知，生成一次性令牌 (OTT) SSO 链接，使用 Prop Trading v2（挑战、竞赛、评估、附加组件、快照）和预测市场投注/结果。涵盖 gRPC 流服务（账户、头寸、账本、订单、报价、群组、交易事件、交易品种、权益、道具）和 CRM 事件 Webhook。触发器：“Match-Trader CRM API”、“crm-api”、“经纪商 api”、“匹配交易集成”、“创建交易账户 API”、“手动存款 API”、partnerID、offerUuid、systemUuid、承载令牌 401/403、错误 415/500“内部应用程序错误”、“无效 apiToken”、网关货币不匹配、OTT / SSO 登录。
