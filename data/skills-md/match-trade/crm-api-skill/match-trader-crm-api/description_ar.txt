التكامل مع Match-Trade CRM-API (المعروف أيضًا باسم طبقة Broker-API CRM) عبر REST وgRPC. استخدم هذه المهارة لإنشاء وتوقيع وإرسال وتصحيح المكالمات إلى Match-Trader CRM: المصادقة باستخدام مفتاح Bearer API، وإنشاء وتحديث الحسابات وحسابات التداول، وقراءة العروض / الفروع / الأدوار / بوابات الدفع، وإجراء عمليات الإيداع والسحب اليدوية، والائتمان في / خارج، وتغيير كلمة المرور والرافعة المالية، وفتح / إغلاق / تحرير المراكز والأوامر، وسحب بيانات التداول (الصفقات المفتوحة والمغلقة، ودفاتر الأستاذ، ولقطات الرصيد)، وقراءة أحداث الجدول الزمني لإدارة علاقات العملاء، وإرسال إشعارات البريد الوارد، وإنشاء رمز مميز لمرة واحدة (OTT) روابط SSO، تعمل مع Prop Trading v2 (التحديات، المسابقات، التقييمات، الإضافات، اللقطات)، ورهانات/نتائج سوق التنبؤ. يغطي خدمات تدفق gRPC (الحساب، والمواقف، ودفتر الأستاذ، والأوامر، وعروض الأسعار، والمجموعة، وأحداث التداول، والرموز، والأسهم، والدعامة) وخطافات الويب لأحداث CRM. المشغلات: "Match-Trader CRM API"، "crm-api"، "broker api"، "تكامل Match-trade"، "واجهة برمجة تطبيقات إنشاء حساب تداول"، "واجهة برمجة تطبيقات الإيداع اليدوي"، معرف الشريك، OfferUuid، systemUuid، الرمز المميز لحامل 401/403، الخطأ 415/500 "خطأ داخلي في التطبيق"، "apiToken غير صالح"، عدم تطابق عملة البوابة، تسجيل الدخول OTT / SSO.
