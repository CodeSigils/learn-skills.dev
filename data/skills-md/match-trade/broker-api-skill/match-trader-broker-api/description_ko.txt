Match-Trader Broker API v2(broker-api-v2)와 통합하세요. 이는 Match-Trader 거래 플랫폼에 직접 연결하기 위한 REST + gRPC API입니다. 이 기술을 사용하여 Broker-api-v2 요청을 구축, 호출 또는 디버깅합니다. 사용자 계정 및 거래 계정 생성 및 관리, 잔액 작업 실행(예금, 출금, 입금, 입금), 포지션 개설/마감/편집, 보류 및 수정 주문 배치, 거래 데이터 쿼리(개방/마감 포지션, 주문 내역, 원장, 양초, 그룹, 기호, 플랫폼 로그), 예측 시장(베팅/결과) 사용 및 실시간 gRPC 스트림(자본, 자산, 포지션, 주문, 견적, 그룹, 기호, 계정 정보, 원장, 거래 이벤트). Bearer 토큰 인증, 브로커별 기본 URL 패턴, `version` 필드를 통한 낙관적 잠금, 비멱등성 균형 작업, RFC-3339/GMT 시간, 페이지 매김, 속도 제한, 전체 오류 카탈로그 및 문제 해결 결정 트리를 다룹니다. 트리거: "broker-api-v2", "Match-Trader Broker API", "broker api v2", MTR 브로커 API, 거래 계좌 생성, 브로커 API 입금/출금, gRPC 자산 스트림, Match-Trader 통합.
