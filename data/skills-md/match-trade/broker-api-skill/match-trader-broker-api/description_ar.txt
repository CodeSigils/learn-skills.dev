قم بالتكامل مع Match-Trader Broker API v2 (broker-api-v2) — واجهة REST + gRPC API للاتصال مباشرة بمنصة التداول Match-Trader. استخدم هذه المهارة لإنشاء أو استدعاء أو تصحيح طلبات وسيط-api-v2: إنشاء وإدارة حسابات المستخدمين وحسابات التداول، وتشغيل عمليات الرصيد (الإيداع والسحب والائتمان والسحب)، وفتح/إغلاق/تحرير المراكز، ووضع الأوامر المعلقة والتصحيح، والاستعلام عن بيانات التداول (الصفقات المفتوحة/المغلقة، وسجل الطلبات، ودفاتر الأستاذ، والشموع، والمجموعات، والرموز، وسجلات النظام الأساسي)، واستخدام سوق التنبؤ (الرهانات/النتائج)، واستهلاك تدفقات gRPC في الوقت الفعلي (الأسهم، المراكز، الأوامر، عروض الأسعار، المجموعات، الرموز، معلومات الحساب، دفاتر الأستاذ، أحداث التداول). يغطي مصادقة الرمز المميز لحاملها، ونمط عنوان URL الأساسي لكل وسيط، والقفل المتفائل عبر حقل "الإصدار"، وعمليات التوازن غير الفعالة، ووقت RFC-3339/GMT، وترقيم الصفحات، وحدود المعدل، وكتالوج الأخطاء الكامل، وشجرة قرارات استكشاف الأخطاء وإصلاحها. المشغلات: "broker-api-v2"، "Match-Trader Broker API"، "broker api v2"، واجهة برمجة تطبيقات وسيط MTR، إنشاء حساب تداول، واجهة برمجة تطبيقات وسيط الإيداع/السحب، تدفق أسهم gRPC، تكامل Match-Trader.
