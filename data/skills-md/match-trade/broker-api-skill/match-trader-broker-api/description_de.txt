Integrieren Sie die Match-Trader Broker API v2 (broker-api-v2) – die REST + gRPC API für die direkte Verbindung mit der Match-Trader-Handelsplattform. Verwenden Sie diese Fähigkeit, um Broker-API-v2-Anfragen zu erstellen, aufzurufen oder zu debuggen: Benutzerkonten und Handelskonten erstellen und verwalten, Kontostandvorgänge ausführen (Einzahlung, Auszahlung, Gutschrift, Gutschrift), Positionen öffnen/schließen/bearbeiten, ausstehende und Korrekturaufträge erteilen, Handelsdaten abfragen (offene/geschlossene Positionen, Auftragsverlauf, Hauptbücher, Kerzen, Gruppen, Symbole, Plattformprotokolle), den Prognosemarkt (Wetten/Ergebnisse) verwenden und die Echtzeit-gRPC-Streams nutzen (Eigenkapital, Positionen, Aufträge, Notierungen, Gruppen, Symbole, Kontoinformationen, Hauptbücher, Handelsereignisse). Behandelt Bearer-Token-Authentifizierung, das Basis-URL-Muster pro Broker, optimistisches Sperren über das Feld „Version“, nicht idempotente Balance-Operationen, RFC-3339/GMT-Zeit, Paginierung, Ratenbegrenzungen, den vollständigen Fehlerkatalog und einen Entscheidungsbaum zur Fehlerbehebung.
