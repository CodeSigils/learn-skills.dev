Интеграция с Match-Trader Broker API v2 (broker-api-v2) — REST + gRPC API для прямого подключения к торговой платформе Match-Trader. Используйте этот навык для создания, вызова или отладки запросовbroker-api-v2: создавайте и управляйте учетными записями пользователей и торговыми счетами, выполняйте балансовые операции (депозит, снятие средств, пополнение и вывод средств), открывайте/закрывайте/редактируйте позиции, размещайте отложенные и корректирующие ордера, запрашивайте торговые данные (открытые/закрытые позиции, историю ордеров, реестры, свечи, группы, символы, журналы платформы), используйте рынок прогнозов (ставки/результаты) и используйте потоки gRPC в реальном времени (капитал, позиции, ордера, котировки, группы, символы, информация о счете, реестры, торговые события). Охватывает аутентификацию токена-носителя, шаблон базового URL-адреса для каждого брокера, оптимистическую блокировку с помощью поля «версия», неидемпотентные операции баланса, время RFC-3339/GMT, нумерацию страниц, ограничения скорости, полный каталог ошибок и дерево решений по устранению неполадок. Триггеры: «broker-api-v2», «Match-Trader Broker API», «broker api v2», API брокера MTR, создание торгового счета, API брокера для ввода/вывода средств, поток средств gRPC, интеграция Match-Trader.
