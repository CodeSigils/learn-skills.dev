Integrazione con l'API Match-Trader Broker v2 (broker-api-v2): l'API REST + gRPC per la connessione diretta alla piattaforma di trading Match-Trader. Utilizza questa abilità per creare, chiamare o eseguire il debug di richieste broker-api-v2: creare e gestire account utente e conti di trading, eseguire operazioni di saldo (deposito, prelievo, accredito, accredito), aprire/chiudere/modificare posizioni, inserire ordini pendenti e di correzione, interrogare dati di trading (posizioni aperte/chiuse, cronologia degli ordini, registri, candele, gruppi, simboli, registri della piattaforma), utilizzare il mercato di previsione (scommesse/risultati) e consumare i flussi gRPC in tempo reale (equità, posizioni, ordini, quotazioni, gruppi, simboli, informazioni sul conto, registri, eventi di trading). Copre l'autenticazione del token al portatore, il pattern URL di base per broker, il blocco ottimistico tramite il campo "versione", le operazioni di saldo non idempotenti, l'ora RFC-3339/GMT, l'impaginazione, i limiti di velocità, il catalogo completo degli errori e un albero decisionale per la risoluzione dei problemi. Trigger: "broker-api-v2", "Match-Trader Broker API", "broker api v2", API broker MTR, creazione di un conto di trading, API del broker di deposito/prelievo, flusso di azioni gRPC, integrazione Match-Trader.
