Match-Trader Broker API v2 (broker-api-v2) (Match-Trader 取引プラットフォームに直接接続するための REST + gRPC API) と統合します。このスキルを使用して、broker-api-v2 リクエストを構築、呼び出し、またはデバッグします。ユーザー アカウントと取引アカウントの作成と管理、残高操作 (入金、出金、クレジットイン、クレジットアウト) の実行、ポジションのオープン/クローズ/編集、未決注文と修正注文の発行、取引データのクエリ (オープン/クローズしたポジション、注文履歴、元帳、ローソク足、グループ、シンボル、プラットフォーム ログ)、予測マーケット (ベット/結果) の使用、およびリアルタイム gRPC の使用ストリーム (株式、ポジション、注文、相場、グループ、シンボル、口座情報、元帳、取引イベント)。ベアラー トークン認証、ブローカーごとのベース URL パターン、「バージョン」フィールドによるオプティミスティック ロック、非冪等バランス操作、RFC-3339/GMT 時間、ページネーション、レート制限、完全なエラー カタログ、およびトラブルシューティング デシジョン ツリーをカバーします。トリガー: 「broker-api-v2」、「Match-Trader Broker API」、「broker api v2」、MTR ブローカー API、取引口座の作成、入出金ブローカー API、gRPC 株式ストリーム、Match-Trader の統合。
