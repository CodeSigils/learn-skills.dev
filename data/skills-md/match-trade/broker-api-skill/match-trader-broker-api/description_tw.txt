與 Match-Trader Broker API v2 (broker-api-v2) 整合 — 用於直接連接到 Match-Trader 交易平台的 REST + gRPC API。使用此技能來建立、調用或調試broker-api-v2請求：建立和管理用戶帳戶和交易帳戶、運行餘額操作（存款、提款、貸入、貸出）、開倉/平倉/編輯倉位、下達掛單和修正訂單、查詢交易資料（開倉/平倉、訂單歷史記錄、帳品種、單筆、群組、交易、平台日誌使用流（權益、部位、訂單、報價、群組、交易品種、帳戶資訊、帳本、交易事件）。涵蓋承載令牌身份驗證、每個經紀人的基本 URL 模式、透過「版本」欄位的樂觀鎖定、非冪等平衡操作、RFC-3339/GMT 時間、分頁、速率限制、完整的錯誤目錄和故障排除決策樹。觸發器：「broker-api-v2」、「Match-Trader 經紀商 API」、「經紀商 api v2」、MTR 經紀商 API、建立交易帳戶、存款/提款經紀商 api、gRPC 權益流、Match-Trader 整合。
