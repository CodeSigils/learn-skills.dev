Genere resúmenes de contenido semántico completos para contenido SEO local: páginas de ubicación, páginas de servicios, publicaciones de blog, contenido de preguntas frecuentes y páginas pilares. Utilice esta habilidad cuando el usuario necesite un resumen de contenido para cualquier pieza de contenido de SEO local, tenga un grupo de conceptos de estrategia de contenido local y necesite informar el contenido, pregunte "qué debería cubrir esta página", "infórmeme sobre [tema] para SEO local", "qué conceptos debería cubrir mi página de ubicación" o necesite saber con qué profundidad cubrir cada tema. También se activa cuando se producen resúmenes de forma masiva para una ejecución de producción de contenido. Esta habilidad combina una metodología de resumen de contenido semántico (cobertura de conceptos, requisitos de entidades, asignaciones de profundidad, mapeo de preguntas) con especificidad de SEO local (entidades geomodificadas, señales de intención locales, coherencia entre GBP y página, requisitos de esquema local, consideraciones de visibilidad de IA). El resultado es un resumen completo que un escritor o un bucle de generación de Claude CLI puede ejecutar directamente.
