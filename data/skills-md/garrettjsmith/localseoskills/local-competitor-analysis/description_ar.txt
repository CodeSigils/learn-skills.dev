عندما يريد المستخدم تحليل منافسي البحث المحليين، أو قياس الأداء مقابل منافسي حزمة الخرائط، أو فهم سبب تفوق المنافسين عليهم. يُستخدم أيضًا عندما يذكر المستخدم "تحليل المنافس"، أو "من يتفوق عليّ"، أو "الجنيه الاسترليني المنافس"، أو "المنافسة المحلية"، أو "التدقيق التنافسي". للحصول على بيانات التصنيف الخاصة بالشبكة الجغرافية، راجع تحليل الشبكة الجغرافية. للتعرف على الإستراتيجية العامة لحزمة الخرائط، راجع تحسين حزمة الخريطة.
