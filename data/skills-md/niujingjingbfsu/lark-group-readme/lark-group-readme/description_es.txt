Mantenga una pestaña "Léame" para un grupo de Lark/Feishu: un documento de proyecto activo adjunto como una pestaña de chat que consolida las decisiones, los entregables, el estado actual y todos los aspectos de la discusión del grupo. Se invoca cuando el usuario solicita "建/挂/创建 ReadMe", "把 X 写到 ReadMe", "整理群讨论到 ReadMe", "更新 ReadMe" o cuando responde a la tarjeta cron diaria. Utilice el chat_id de `<bridge_context>` a menos que el usuario nombre un chat específico.
