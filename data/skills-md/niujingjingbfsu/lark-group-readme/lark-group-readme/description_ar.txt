احتفظ بعلامة التبويب "ReadMe" لمجموعة Lark/Feishu - وهي وثيقة مشروع حية مرفقة كعلامة تبويب دردشة تعمل على دمج القرارات والتسليمات والحالة الحالية والمهام من مناقشة المجموعة. يتم الاستدعاء عندما يطلب المستخدم "ReadMe/挂/创建 ReadMe"، أو "把 X 写到 ReadMe"، أو "整理群讨论到 ReadMe"، أو "更新 ReadMe"، أو عند الرد على بطاقة cron اليومية. استخدم معرف الدردشة من `<bridge_context>` ما لم يقوم المستخدم بتسمية دردشة معينة.
