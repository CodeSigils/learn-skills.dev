Поддерживайте вкладку «ReadMe» для группы Lark/Feishu — живой проектный документ, прикрепленный в виде вкладки чата, который объединяет решения, результаты, текущий статус и задачи группового обсуждения. Вызывается, когда пользователь запрашивает «建/挂/创建 ReadMe», «把 X 写到 ReadMe», «整理群讨论到 ReadMe», «更新 ReadMe» или при ответе на ежедневную карточку cron. Используйте Chat_id из `<bridge_context>`, если пользователь не называет конкретный чат.
