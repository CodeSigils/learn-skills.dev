Conservez un onglet « Lisez-moi » pour un groupe Lark/Feishu – un document de projet évolutif joint sous forme d'onglet de discussion qui consolide les décisions, les livrables, l'état actuel et les tâches de la discussion de groupe. Invoquer lorsque l'utilisateur demande "建/挂/创建 ReadMe", "把 X 写到 ReadMe", "整理群讨论到 ReadMe", "更新 ReadMe" ou lorsqu'il répond à la carte cron quotidienne. Utilisez le chat_id de `<bridge_context>` à moins que l'utilisateur ne nomme un chat spécifique.
