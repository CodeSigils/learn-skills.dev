正確な URL がすでにわかっていて、そのコンテンツをクリーンなマークダウン (価格設定ページ、記事、ドキュメント ページ、または前の手順で見つかった URL) として必要とする場合に使用します。 Linkup Fetch API を呼び出すコードを作成する場合も、これをお読みください。 「linkup-fetch」MCP ツールまたは直接 REST 呼び出しを介して Linkup Fetch API を使用します。 URL がわかっている場合は、linkup-search よりもこれを優先します。 1 つのリスト ページから多くの構造化された行が必要な場合は、linkup-extract をお勧めします。
