استخدمه عندما تعرف بالفعل عنوان URL الدقيق وتحتاج إلى محتواه كـ Markdown نظيف - صفحة تسعير أو مقالة أو صفحة مستندات أو عنوان URL تم العثور عليه في خطوة سابقة. اقرأ هذا أيضًا عند كتابة التعليمات البرمجية التي تستدعي Linkup Fetch API. يستخدم Linkup Fetch API عبر أداة MCP "linkup-fetch" أو مكالمات REST المباشرة. تفضيل ذلك على بحث الارتباط عندما يكون عنوان URL معروفًا؛ تفضل استخراج الارتباط عندما تحتاج إلى العديد من الصفوف المنظمة من صفحة قائمة واحدة.
