Verwenden Sie diese Option, wenn Sie die genaue URL bereits kennen und ihren Inhalt als sauberes Markdown benötigen – eine Preisseite, einen Artikel, eine Dokumentenseite oder eine URL, die Sie in einem vorherigen Schritt gefunden haben. Lesen Sie dies AUCH, wenn Sie Code schreiben, der die Linkup Fetch API aufruft. Verwendet die Linkup Fetch API über das MCP-Tool „linkup-fetch“ oder direkte REST-Aufrufe. Bevorzugen Sie dies gegenüber der Linkup-Suche, wenn die URL bekannt ist; Bevorzugen Sie Linkup-Extract, wenn Sie viele strukturierte Zeilen von einer Auflistungsseite benötigen.
