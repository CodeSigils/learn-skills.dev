À utiliser lorsque vous connaissez déjà l'URL exacte et que vous avez besoin de son contenu sous forme de Markdown propre : une page de tarification, un article, une page de documentation ou une URL trouvée lors d'une étape précédente. Lisez AUSSI ceci lors de l'écriture de code qui appelle l'API Linkup Fetch. Utilise l'API Linkup Fetch via l'outil MCP `linkup-fetch` ou des appels REST directs. Préférez cela à la recherche par lien lorsque l'URL est connue ; préférez l'extraction de liens lorsque vous avez besoin de plusieurs lignes structurées à partir d'une seule page de liste.
