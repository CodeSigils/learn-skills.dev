Da utilizzare per estrarre molti record strutturati da UNA pagina di elenco nota: directory di team, cataloghi di prodotti/prezzi, elenchi di lavori, relatori di conferenze, elenchi impaginati. Leggilo ANCHE quando scrivi codice che integra l'endpoint /v1/extract (schema, polling asincrono, risultati NDJSON). Utilizza l'endpoint REST asincrono /v1/extract di Linkup e restituisce righe NDJSON. Richiede LINKUP_API_KEY. Per la prosa di una singola pagina utilizzare linkup-fetch; per la scoperta del web utilizzare linkup-search.
