Utilisez-le pour extraire de nombreux enregistrements structurés à partir d'UNE page de liste connue : répertoires d'équipe, catalogues de produits/tarifs, offres d'emploi, conférenciers, listes paginées. Lisez AUSSI ceci lors de l'écriture de code qui intègre le point de terminaison /v1/extract (schéma, interrogation asynchrone, résultats NDJSON). Utilise le point de terminaison REST async /v1/extract de Linkup et renvoie les lignes NDJSON. Nécessite LINKUP_API_KEY. Pour la prose d'une seule page, utilisez linkup-fetch ; pour la découverte du Web, utilisez Linkup-Search.
