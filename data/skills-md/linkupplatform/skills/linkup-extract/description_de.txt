Verwenden Sie diese Funktion, um viele strukturierte Datensätze von EINER bekannten Listenseite abzurufen – Teamverzeichnisse, Produkt-/Preiskataloge, Stellenangebote, Konferenzredner, paginierte Listen. Lesen Sie dies AUCH, wenn Sie Code schreiben, der den /v1/extract-Endpunkt integriert (Schema, asynchrone Abfrage, NDJSON-Ergebnisse). Verwendet den asynchronen /v1/extract-REST-Endpunkt von Linkup und gibt NDJSON-Zeilen zurück. Erfordert LINKUP_API_KEY. Für die Prosa einer einzelnen Seite verwenden Sie linkup-fetch; Verwenden Sie für die Weberkennung Linkup-Search.
