Используйте для извлечения множества структурированных записей с ОДНОЙ известной страницы списка — каталогов групп, каталогов продуктов/цен, списков вакансий, спикеров конференций, списков с нумерацией страниц. ТАКЖЕ прочтите это при написании кода, который интегрирует конечную точку /v1/extract (схема, асинхронный опрос, результаты NDJSON). Использует конечную точку REST async /v1/extract Linkup и возвращает строки NDJSON. Требуется LINKUP_API_KEY. Для прозы одной страницы используйте linkup-fetch; для веб-обнаружения используйте linkup-search.
