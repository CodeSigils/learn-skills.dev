Úselo para extraer muchos registros estructurados de UNA página de listado conocida: directorios de equipos, catálogos de productos/precios, ofertas de trabajo, oradores de conferencias, listas paginadas. TAMBIÉN lea esto cuando escriba código que integre el punto final /v1/extract (esquema, sondeo asíncrono, resultados NDJSON). Utiliza el punto final REST async /v1/extract de Linkup y devuelve filas NDJSON. Requiere LINKUP_API_KEY. Para la prosa de una sola página, utilice linkup-fetch; para el descubrimiento web utilice linkup-search.
