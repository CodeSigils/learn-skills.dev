ТОЛЬКО когда пользователь явно хочет провести тщательное, исчерпывающее или всестороннее расследование или отчет из нескольких источников, который может длиться несколько минут — комплексная проверка, рыночная ситуация, «сравнение X по многим объектам», проверенное установление фактов. ТАКЖЕ прочитайте это при написании кода, который интегрирует конечную точку /v1/research (режимы, глубина рассуждений, асинхронный опрос). Медленнее и дороже, чем поиск по ссылкам. Для обычного поиска и исследования вместо этого используйте linkup-search; для массовых записей со страницы используйте linkup-extract. Использует конечную точку REST async /v1/research Linkup. Требуется LINKUP_API_KEY.
