Руководство по реализации Bun для серверной части, управляемой PMA, и полнофункциональных монорепозиториев. Охватывает рабочие пространства Bun с `apps/*` и `packages/*`, модули API в `src/modules`, строгую проверку с помощью ESLint + @antfu/eslint-config, Drizzle поверх хранилища SQLite, OpenAPIHono поверх `Bun.serve()`, проверенную конфигурацию env, интеграцию разработчиков Vite, автономную двоичную компиляцию со встроенными ресурсами и миграциями, а также шлюзы качества CI.
