Guide de mise en œuvre de Bun pour le backend géré par PMA et les monorepos full-stack. Couvre les espaces de travail Bun avec `apps/*` et `packages/*`, les modules API sous `src/modules`, le linting strict avec ESLint + @antfu/eslint-config, Drizzle sur le stockage SQLite-first, OpenAPIHono au-dessus de `Bun.serve()`, la configuration d'environnement validée, l'intégration de développement Vite, la compilation binaire autonome avec actifs et migrations intégrés et les portes de qualité CI.
