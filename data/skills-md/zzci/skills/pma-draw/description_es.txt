Genere diagramas de ReactFlow como archivos .rfd.json utilizando una biblioteca predefinida de tipos de nodos personalizados, ajustes preestablecidos de bordes y plantillas de diseño. Úselo cuando el usuario quiera visualizar arquitecturas, flujos de trabajo, flujos de datos o conceptos, o quiera convertir el análisis de una base de código en un diagrama visible en un SPA basado en ReactFlow.
