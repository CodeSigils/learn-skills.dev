Genera diagrammi ReactFlow come file .rfd.json utilizzando una libreria predefinita di tipi di nodi personalizzati, preimpostazioni di bordi e modelli di layout. Utilizzare quando l'utente desidera visualizzare architetture, flussi di lavoro, flussi di dati o concetti oppure desidera convertire l'analisi di una base di codice in un diagramma visualizzabile in una SPA basata su ReactFlow.
