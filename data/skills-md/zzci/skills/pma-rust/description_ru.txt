Руководство по реализации проекта Rust для проектов с несколькими ящиками рабочего пространства. Охватывает конфигурацию рабочей области, цепочку инструментов (nightly + Rustfmt + Clippy + Cranky + Cargo-deny), строгие правила проверки (нет unsafe/unwrap/expect/panic), обработку ошибок (thiserror + Anyhow), асинхронную среду выполнения (Tokio), TLS (rustls + aws-lc-rs), CI/CD (действия GitHub с test/build/docker/SBOM) и соглашения о кодировании. Используйте при сборке, разработке или проверке приложений Rust.
