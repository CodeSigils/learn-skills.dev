Guida all'implementazione del progetto Rust per progetti di spazi di lavoro multi-cassa. Copre la configurazione dell'area di lavoro, la toolchain (nightly + rugginefmt + clippy + irritabile + cargo-deny), regole rigide per i lanugine (no unsafe/unwrap/expect/panic), gestione degli errori (thiserror + anyhow), runtime asincrono (Tokio), TLS (rustls + aws-lc-rs), CI/CD (azioni GitHub con test/build/docker/SBOM) e convenzioni di codifica. Da utilizzare durante lo scaffolding, lo sviluppo o la revisione di applicazioni Rust.
