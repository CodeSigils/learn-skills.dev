Guía de implementación de proyectos de Rust para proyectos de espacios de trabajo de varias cajas. Cubre la configuración del espacio de trabajo, la cadena de herramientas (nightly + rustfmt + clippy + cranky + cargo-deny), reglas estrictas de pelusa (no inseguro/unwrap/expect/panic), manejo de errores (thiserror + de todos modos), tiempo de ejecución asíncrono (Tokio), TLS (rustls + aws-lc-rs), CI/CD (Acciones de GitHub con test/build/docker/SBOM) y convenciones de codificación. Úselo al realizar scaffolding, desarrollo o revisión de aplicaciones Rust.
