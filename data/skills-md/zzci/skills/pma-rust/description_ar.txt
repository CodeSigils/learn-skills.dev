دليل تنفيذ مشروع الصدأ لمشاريع مساحة العمل متعددة الصناديق. يغطي تكوين مساحة العمل، وسلسلة الأدوات (ليلاً + Rustfmt + Clippy + Cranky + Cargo-deny)، وقواعد الوبر الصارمة (لا يوجد غير آمن/غير مغلف/متوقع/ذعر)، ومعالجة الأخطاء (هذا الخطأ + على أية حال)، ووقت التشغيل غير المتزامن (Tokio)، TLS (rustls + aws-lc-rs)، CI/CD (إجراءات GitHub مع الاختبار/البناء/الإرساء/SBOM)، واصطلاحات الترميز. يُستخدم عند دعم تطبيقات Rust أو تطويرها أو مراجعتها.
