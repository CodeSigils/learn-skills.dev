Rust-Projektimplementierungsleitfaden für Multi-Crate-Workspace-Projekte. Behandelt Arbeitsbereichskonfiguration, Toolchain (Nightly + Rustfmt + Clippy + Cranky + Cargo-Deny), strenge Lint-Regeln (kein Unsafe/Unwrap/Expect/Panic), Fehlerbehandlung (Thiserror + Anyhow), Async Runtime (Tokio), TLS (Rustls + Aws-LC-RS), CI/CD (GitHub Actions mit Test/Build/Docker/SBOM) und Codierungskonventionen. Zur Verwendung beim Gerüstbau, Entwickeln oder Überprüfen von Rust-Anwendungen.
