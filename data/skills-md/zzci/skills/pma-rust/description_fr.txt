Guide de mise en œuvre du projet Rust pour les projets d'espace de travail multi-crates. Couvre la configuration de l'espace de travail, la chaîne d'outils (nightly + rustfmt + clippy + grincheux + cargo-deny), les règles strictes de charpie (pas de risque/déballage/attente/panique), la gestion des erreurs (thiserror + anyhow), l'exécution asynchrone (Tokio), TLS (rustls + aws-lc-rs), CI/CD (actions GitHub avec test/build/docker/SBOM) et les conventions de codage. À utiliser lors de l'échafaudage, du développement ou de la révision d'applications Rust.
