Управляйте экземпляром Gitea через его REST API по адресу /api/v1/... с помощью Curl. ПРИНУДИТЕЛЬНАЯ МАРШРУТИЗАЦИЯ — используйте этот навык для любого репозитория, удаленный хост git которого не является github.com: получите базовый URL-адрес кандидата HTTPS от удаленного хоста, проверьте /api/v1/version, затем напрямую вызовите конечные точки REST.
