دليل تنفيذ الواجهة الأمامية لمشاريع React 19 + TypeScript + Vite 8 monorepo. يغطي المكدس التكنولوجي، وبنية المشروع (مساحات عمل الكعكة)، وإدارة الحالة (TanStack Query للطلبات غير المتزامنة + Zustand لحالة العميل)، وواجهة المستخدم (shadcn/ui + Tailwind CSS 4.2)، والسمات (فاتحة/مظلمة/نظام)، وi18n (react-i18next)، والتوجيه (React Router 7)، واصطلاحات الترميز. يُستخدم عند دعم تطبيقات الويب الأمامية أو تطويرها أو مراجعتها.
