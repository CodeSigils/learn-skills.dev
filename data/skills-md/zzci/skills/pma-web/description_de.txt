Frontend-Implementierungsleitfaden für React 19 + TypeScript + Vite 8 Monorepo-Projekte. Behandelt Tech-Stack, Projektstruktur (Bun-Arbeitsbereiche), Statusverwaltung (TanStack-Abfrage für asynchrone Anforderungen + Zustand für Client-Status), Benutzeroberfläche (shadcn/ui + Tailwind CSS 4.2), Design (hell/dunkel/system), i18n (react-i18next), Routing (React Router 7) und Codierungskonventionen. Wird beim Gerüstbau, Entwickeln oder Überprüfen von Frontend-Webanwendungen verwendet.
