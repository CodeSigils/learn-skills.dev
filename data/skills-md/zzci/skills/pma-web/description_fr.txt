Guide d'implémentation frontend pour les projets monorepo React 19 + TypeScript + Vite 8. Couvre la pile technologique, la structure du projet (espaces de travail chignon), la gestion de l'état (TanStack Query pour les requêtes asynchrones + Zustand pour l'état du client), l'interface utilisateur (shadcn/ui + Tailwind CSS 4.2), la thématique (clair/sombre/système), i18n (react-i18next), le routage (React Router 7) et les conventions de codage. À utiliser lors de l'échafaudage, du développement ou de la révision d'applications Web frontales.
