Руководство по реализации внешнего интерфейса для проектов монорепозитория React 19 + TypeScript + Vite 8. Охватывает технический стек, структуру проекта (рабочие области Bun), управление состоянием (TanStack Query для асинхронных запросов + Zustand для состояния клиента), пользовательский интерфейс (shadcn/ui + Tailwind CSS 4.2), темы (светлый/темный/системный), i18n (react-i18next), маршрутизацию (React Router 7) и соглашения о кодировании. Используйте при создании шаблонов, разработке или проверке интерфейсных веб-приложений.
