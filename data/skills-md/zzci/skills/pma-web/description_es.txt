Guía de implementación de frontend para proyectos monorepo de React 19 + TypeScript + Vite 8. Cubre la pila de tecnología, la estructura del proyecto (espacios de trabajo bun), la gestión del estado (TanStack Query para solicitudes asíncronas + Zustand para el estado del cliente), UI (shadcn/ui + Tailwind CSS 4.2), temática (claro/oscuro/sistema), i18n (react-i18next), enrutamiento (React Router 7) y convenciones de codificación. Utilícelo al crear andamios, desarrollar o revisar aplicaciones web frontend.
