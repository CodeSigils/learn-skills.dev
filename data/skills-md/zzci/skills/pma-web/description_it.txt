Guida all'implementazione del frontend per progetti monorepo React 19 + TypeScript + Vite 8. Copre stack tecnologico, struttura del progetto (spazi di lavoro bun), gestione dello stato (TanStack Query per richieste asincrone + Zustand per stato del client), interfaccia utente (shadcn/ui + Tailwind CSS 4.2), tematizzazione (chiaro/scuro/sistema), i18n (react-i18next), routing (React Router 7) e convenzioni di codifica. Da utilizzare durante la creazione di scaffold, lo sviluppo o la revisione di applicazioni Web frontend.
