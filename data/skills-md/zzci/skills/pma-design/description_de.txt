Erstellen Sie ausgefeilte Designartefakte als eigenständiges HTML: UI-Modelle, interaktive Prototypen, Wireframes, Landingpages, Dashboards, App-Bildschirme, mobile Apps, Foliendecks und visuelle Erkundungen. Verwenden Sie es immer dann, wenn der Benutzer eine Benutzeroberfläche, einen Produktbildschirm, einen Benutzerfluss, ein Inhaltslayout, ein visuelles Artefakt oder ein Pitch-/Deck-Konzept entwerfen, modellieren, prototypisieren, verdrahten, visualisieren oder erkunden möchte, auch wenn er nicht „Design“ sagt. Kann auch zum Einrichten, Importieren oder Erstellen wiederverwendbarer Designsysteme, UI-Kits, Markentokens, Komponentenbibliotheken oder ladbaren Designsystem-Bundles verwendet werden. Die Fertigkeit umfasst das Sammeln von Kontexten, das Klären von Fragen, die Wahl der Wiedergabetreue, das Auswählen oder Binden von Designsystemen, das Erstellen von Projektordnern, das Erstellen eines oder mehrerer HTML-Ergebnisse, deren Vorschau über von NSL bereitgestellte URLs und die Überprüfung, ob sie sauber geladen werden. Es läuft eigenständig (kein PMA-Workflow erforderlich) auf Claude Code und Codex Agent; Kabelbaumspezifische Vorschau-, Screenshot- und Verifizierungstools werden aus Referenzen/ aufgelöst.
