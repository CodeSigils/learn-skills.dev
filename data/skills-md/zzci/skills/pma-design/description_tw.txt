創建精美的設計工件作為獨立的 HTML：UI 模型、互動式原型、線框、登陸頁面、儀表板、應用程式螢幕、行動應用程式、幻燈片和視覺探索。每當使用者要求設計、模型、原型、線框圖、視覺化或探索介面、產品螢幕、使用者流程、內容佈局、視覺工件或推廣/甲板概念時使用，即使他們沒有說「設計」。也可用於設定、匯入或建立可重複使用設計系統、UI 套件、品牌令牌、元件庫或可載入設計系統套件。此技能指導上下文收集、澄清問題、選擇保真度、選擇或綁定設計系統、建立專案資料夾、建立一個或多個 HTML 可交付成果、透過 nsl 提供的 URL 預覽它們，並驗證它們是否正確載入。它在 Claude Code 和 Codex Agent 上獨立運行（無需 PMA 工作流程）；線束特定的預覽、螢幕截圖和驗證工具是從引用/解析的。
