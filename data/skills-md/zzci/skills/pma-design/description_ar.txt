قم بإنشاء عناصر تصميم مصقولة مثل HTML قائمة بذاتها: نماذج بالحجم الطبيعي لواجهة المستخدم، والنماذج الأولية التفاعلية، والإطارات السلكية، والصفحات المقصودة، ولوحات المعلومات، وشاشات التطبيقات، وتطبيقات الهاتف المحمول، ومجموعات الشرائح، والاستكشافات المرئية. يُستخدم عندما يطلب المستخدم تصميم واجهة أو شاشة منتج أو تدفق المستخدم أو تخطيط المحتوى أو قطعة أثرية مرئية أو مفهوم العرض التقديمي/سطح السفينة، أو نموذج نموذجي، أو نموذج أولي، أو إطار سلكي، أو تصور، أو استكشاف، أو استكشافها، حتى لو لم يذكر "تصميم". يُستخدم أيضًا لإعداد أو استيراد أو تأليف أنظمة تصميم قابلة لإعادة الاستخدام أو مجموعات واجهة المستخدم أو الرموز المميزة للعلامة التجارية أو مكتبات المكونات أو حزم نظام التصميم القابلة للتحميل. ترشد المهارة جمع السياق، وتوضيح الأسئلة، واختيار الدقة، واختيار أنظمة التصميم أو ربطها، وإنشاء مجلدات المشروع، وإنشاء واحد أو أكثر من تسليمات HTML، ومعاينتها عبر عناوين URL التي يتم تقديمها بواسطة NSL، والتحقق من تحميلها بشكل نظيف. يتم تشغيله بشكل مستقل (لا يتطلب سير عمل PMA) على Claude Code وCodex Agent؛ يتم حل أدوات المعاينة ولقطات الشاشة والتحقق الخاصة بالأداة من المراجع/.
