Guide de mise en œuvre Go pour les services gérés par PMA et les projets CLI. Couvre la disposition du projet (cmd/interne), le peluchage strict avec golangci-lint v2, l'accès à la base de données (sqlc + pgx ou GORM), les modèles HTTP (stdlib + Chi ou Gin), la configuration en couches avec koanf, la journalisation structurée avec slog, l'observabilité OpenTelemetry et les portes de qualité CI.
