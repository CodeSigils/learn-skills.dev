التحكم في إعادة شراء جدول البيانات والتعاون المستضاف في المراجعة/الأصل لمساحات عمل "ورقة الوكيل" المستمرة. يُستخدم عند الحاجة لتنظيم إدخالات المصنف، أو إنشاء التزامات أو مقترحات، أو فحص حالة الاقتراح، أو نشر اقتراح لمراجعة مستضافة، أو سحب تعليقات المراجعة القابلة للقراءة آليًا، أو تنسيق "الدفع/الجلب/السحب/إعادة الأساس" مقابل الأصل. لا تستخدمه لتحرير المصنف المباشر.
