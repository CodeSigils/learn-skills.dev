Univer 用のカスタム プラグインを開発します (スプレッドシート/ドキュメント/プレゼンテーション エンジン)。プラグインの作成、コマンド/ミューテーション/操作の登録、Facade API クラス (FUniver、FWorkbook、FWorksheet、FRange) の拡張、ツールバー ボタンまたはコンテキスト メニューの追加、ショートカットのバインド、またはワークブック/シート/セル イベントのリッスンを行うときに使用します。トリガーには、「プラグインの作成」、「カスタム コマンド」、「FRange の拡張」、「ツールバー ボタン」、「ショートカット」、「メニュー項目」、「ファサード拡張機能」、またはプラグイン開発エラーが含まれます。
