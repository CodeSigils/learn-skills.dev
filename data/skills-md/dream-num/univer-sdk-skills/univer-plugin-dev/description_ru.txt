Разрабатывайте собственные плагины для Univer (механизм электронных таблиц/документов/презентаций). Используйте при написании плагина, регистрации команд/мутаций/операций, расширении классов Facade API (FUniver, FWorkbook, FWorksheet, FRange), добавлении кнопок панели инструментов или контекстных меню, привязке ярлыков или прослушивании событий книги/листа/ячейки. Триггеры включают «написать плагин», «пользовательскую команду», «расширить FRange», «кнопку панели инструментов», «ярлык», «элемент меню», «расширение фасада» или любую ошибку разработки плагина.
