تطوير مكونات إضافية مخصصة لـ Univer (محرك جداول البيانات/المستندات/العروض التقديمية). يُستخدم عند كتابة مكون إضافي، أو تسجيل الأوامر/الطفرات/العمليات، أو توسيع فئات واجهة برمجة التطبيقات (FUniver، أو FWorkbook، أو FWorksheet، أو FRange)، أو إضافة أزرار شريط الأدوات أو قوائم السياق، أو ربط الاختصارات، أو الاستماع إلى أحداث المصنف/الورقة/الخلية. تتضمن المشغلات "كتابة مكون إضافي"، أو "أمر مخصص"، أو "تمديد FRange"، أو "زر شريط الأدوات"، أو "اختصار"، أو "عنصر قائمة"، أو "ملحق الواجهة"، أو أي خطأ في تطوير المكون الإضافي.
