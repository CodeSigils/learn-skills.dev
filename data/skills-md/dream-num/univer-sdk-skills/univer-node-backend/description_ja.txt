Node.js バックエンド環境で Univer (スプレッドシート エンジン) を使用して、ヘッドレス データ処理、バッチ レポート生成、サーバー側の数式計算、自動ワークブック操作を行います。ユーザーがブラウザを使用せずにサーバー上でスプレッドシートを作成、読み取り、変更する必要がある場合、Node.js で Univer を実行する場合、createUniverOnNode、UniverRPCNodeMainPlugin、フォーミュラ ワーカー用の child_process フォークを使用する場合、サーバー側の XLSX/JSON 処理、またはバックエンド コンテキストでの Facade API を介したバッチ セル操作を行う必要がある場合に使用します。トリガーには、「Node.js」、「サーバー側」、「バックエンド」、「ヘッドレス」、「バッチ生成」、「自動レポート」、「createUniverOnNode」、「rpc-node」、「フォーミュラ ワーカー」、または「Univer in Node」が含まれます。
