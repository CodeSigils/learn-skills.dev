Используйте Univer (механизм электронных таблиц) в серверных средах Node.js для автономной обработки данных, пакетного создания отчетов, расчета формул на стороне сервера и автоматического манипулирования книгами. Используйте, когда пользователю необходимо создавать, читать или изменять электронные таблицы на сервере без браузера, запускать Univer в Node.js, использовать createUniverOnNode, UniverRPCNodeMainPlugin, вилку child_process для рабочих формул, обработку XLSX/JSON на стороне сервера или пакетные операции с ячейками через Facade API в контексте серверной части. Триггеры включают «Node.js», «серверную часть», «бэкенд», «безголовый», «пакетное создание», «автоматический отчет», «createUniverOnNode», «rpc-node», «работник формулы» или «Univer in Node».
