Utilizza Univer (motore di fogli di calcolo) negli ambienti backend Node.js per l'elaborazione dei dati headless, la generazione di report batch, il calcolo di formule lato server e la manipolazione automatizzata delle cartelle di lavoro. Da utilizzare quando l'utente deve creare, leggere o modificare fogli di calcolo sul server senza un browser, eseguire Univer in Node.js, utilizzare createUniverOnNode, UniverRPCNodeMainPlugin, fork child_process per operatori di formule, elaborazione XLSX/JSON lato server o operazioni di celle batch tramite Facade API in un contesto backend. I trigger includono "Node.js", "lato server", "backend", "headless", "generazione batch", "report automatizzato", "createUniverOnNode", "rpc-node", "formula lavoratore" o "Univer in Node".
