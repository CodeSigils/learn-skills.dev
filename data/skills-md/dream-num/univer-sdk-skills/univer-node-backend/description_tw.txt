在 Node.js 後端環境中使用 Univer（電子表格引擎）進行無頭資料處理、批次報告產生、伺服器端公式計算和自動化工作簿操作。當使用者需要在沒有瀏覽器的情況下在伺服器上建立、讀取或修改電子表格、在 Node.js 中執行 Univer、使用 createUniverOnNode、UniverRPCNodeMainPlugin、用於公式工作者的 child_process fork、伺服器端 XLSX/JSON 處理或在後端上下文中透過 Facade API 進行批次操作。觸發器包括「Node.js」、「伺服器端」、「後端」、「無頭」、「批次產生」、「自動報告」、「createUniverOnNode」、「rpc-node」、「公式工作者」或「Node 中的 Univer」。
