Utilisez Univer (moteur de feuille de calcul) dans les environnements backend Node.js pour le traitement des données sans tête, la génération de rapports par lots, le calcul de formules côté serveur et la manipulation automatisée des classeurs. À utiliser lorsque l'utilisateur doit créer, lire ou modifier des feuilles de calcul sur le serveur sans navigateur, exécuter Univer dans Node.js, utiliser createUniverOnNode, UniverRPCNodeMainPlugin, un fork child_process pour les travailleurs de formule, un traitement XLSX/JSON côté serveur ou des opérations de cellule par lots via l'API Facade dans un contexte backend. Les déclencheurs incluent "Node.js", "côté serveur", "backend", "sans tête", "génération par lots", "rapport automatisé", "createUniverOnNode", "rpc-node", "formula worker" ou "Univer in Node".
