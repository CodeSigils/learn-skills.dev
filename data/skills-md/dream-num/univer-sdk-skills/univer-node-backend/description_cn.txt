在 Node.js 后端环境中使用 Univer（电子表格引擎）进行无头数据处理、批量报告生成、服务器端公式计算和自动化工作簿操作。当用户需要在没有浏览器的情况下在服务器上创建、读取或修改电子表格、在 Node.js 中运行 Univer、使用 createUniverOnNode、UniverRPCNodeMainPlugin、用于公式工作者的 child_process fork、服务器端 XLSX/JSON 处理或在后端上下文中通过 Facade API 进行批处理单元操作时使用。触发器包括“Node.js”、“服务器端”、“后端”、“无头”、“批量生成”、“自动报告”、“createUniverOnNode”、“rpc-node”、“公式工作者”或“Node 中的 Univer”。
