Verwenden Sie Univer (Tabellenkalkulations-Engine) in Node.js-Backend-Umgebungen für die kopflose Datenverarbeitung, die Generierung von Stapelberichten, die serverseitige Formelberechnung und die automatisierte Bearbeitung von Arbeitsmappen. Verwenden Sie diese Option, wenn der Benutzer Tabellenkalkulationen auf dem Server ohne Browser erstellen, lesen oder ändern, Univer in Node.js ausführen, createUniverOnNode, UniverRPCNodeMainPlugin, child_process fork für Formelarbeiter, serverseitige XLSX/JSON-Verarbeitung oder Stapelzellenoperationen über die Facade-API in einem Backend-Kontext verwenden muss. Zu den Auslösern gehören „Node.js“, „Serverseite“, „Backend“, „Headless“, „Batch-Generierung“, „automatisierter Bericht“, „createUniverOnNode“, „rpc-node“, „formula worker“ oder „Univer in Node“.
