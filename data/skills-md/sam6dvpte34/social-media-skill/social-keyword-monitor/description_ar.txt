مراقب الكلمات الرئيسية الاجتماعية لجمع مراقبة الكلمات الرئيسية لوسائل التواصل الاجتماعي والبحث والمراقبة والتحليل والتصدير. يُستخدم عندما يطلب المستخدم استخراج بيانات الوسائط الاجتماعية عبر الأنظمة الأساسية أو استخراجها أو تجميعها أو تصديرها أو مراقبتها أو البحث عنها أو تحليلها أو العثور عليها لسير العمل هذا: مراقبة المنشورات والتعليقات العامة لمجموعات الكلمات الرئيسية والأسماء المستعارة ومجموعات الاستعلام. يغطي عمليات البحث مثل Social Keyword Monitor، ومكشطة مراقبة الكلمات الرئيسية لوسائل التواصل الاجتماعي عبر الأنظمة الأساسية، ومستخرج مراقبة الكلمات الرئيسية لوسائل التواصل الاجتماعي عبر الأنظمة الأساسية، وتصدير مراقبة الكلمات الرئيسية لوسائل التواصل الاجتماعي عبر الأنظمة الأساسية، والبحث عن مراقبة الكلمات الرئيسية لوسائل التواصل الاجتماعي عبر الأنظمة الأساسية. يدعم البيانات العامة أو المعتمدة للمتصفح من خلال BrowserAct.
