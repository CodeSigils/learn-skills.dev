مراقب الهاشتاج الاجتماعي لجمع مراقبة الهاشتاج على وسائل التواصل الاجتماعي والبحث والمراقبة والتحليل والتصدير. يُستخدم عندما يطلب المستخدم استخراج بيانات الوسائط الاجتماعية عبر الأنظمة الأساسية أو استخراجها أو تجميعها أو تصديرها أو مراقبتها أو بحثها أو تحليلها أو العثور عليها لسير العمل هذا: تتبع حجم علامة التصنيف والمحتوى والمنشئين والمشاركة والعلامات الناشئة ذات الصلة. يغطي عمليات البحث مثل Social Hashtag Monitor، ومكشطة مراقبة هاشتاج الوسائط الاجتماعية عبر الأنظمة الأساسية، ومستخرج مراقبة هاشتاج الوسائط الاجتماعية عبر الأنظمة الأساسية، وتصدير مراقبة هاشتاج الوسائط الاجتماعية عبر الأنظمة الأساسية، وأبحاث مراقبة هاشتاج الوسائط الاجتماعية عبر الأنظمة الأساسية. يدعم البيانات العامة أو المعتمدة للمتصفح من خلال BrowserAct.
