مراقب الاتجاه الاجتماعي لجمع مراقبة اتجاهات وسائل التواصل الاجتماعي عبر الأنظمة الأساسية والبحث والمراقبة والتحليل والتصدير. يُستخدم عندما يطلب المستخدم استخراج بيانات الوسائط الاجتماعية عبر الأنظمة الأساسية أو استخراجها أو تجميعها أو تصديرها أو مراقبتها أو البحث عنها أو تحليلها أو العثور عليها لسير العمل هذا: قم بتجميع ومقارنة الموضوعات الشائعة والتسميات الموسيقية المرئية وعلامات التصنيف والمنشئين وتنسيقات المحتوى. يغطي عمليات البحث مثل Social Trend Monitor، ومكشطة مراقبة اتجاهات الوسائط الاجتماعية عبر الأنظمة الأساسية، ومستخرج مراقبة اتجاهات الوسائط الاجتماعية عبر الأنظمة الأساسية، وتصدير مراقبة اتجاهات وسائل التواصل الاجتماعي عبر الأنظمة الأساسية، وأبحاث مراقبة اتجاهات وسائل التواصل الاجتماعي عبر الأنظمة الأساسية. يدعم البيانات العامة أو المعتمدة للمتصفح من خلال BrowserAct.
