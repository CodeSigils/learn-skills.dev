الباحث عن المحتوى الفيروسي الاجتماعي لجمع الباحث عن المحتوى الفيروسي عبر منصات التواصل الاجتماعي والبحث والمراقبة والتحليل والتصدير. يُستخدم عندما يطلب المستخدم استخراج بيانات الوسائط الاجتماعية عبر الأنظمة الأساسية أو استخراجها أو تجميعها أو تصديرها أو مراقبتها أو بحثها أو تحليلها أو العثور عليها لسير العمل هذا: ابحث عن المنشورات سريعة النمو باستخدام سرعة المشاركة وإشارات الحداثة. يغطي عمليات البحث مثل Social Viral Content Finder، ومكشطة مكتشف المحتوى الفيروسي عبر الوسائط الاجتماعية، ومستخرج مكتشف المحتوى الفيروسي عبر الوسائط الاجتماعية، وتصدير مكتشف المحتوى الفيروسي عبر الوسائط الاجتماعية، والبحث عن المحتوى الفيروسي عبر الوسائط الاجتماعية. يدعم البيانات العامة أو المعتمدة للمتصفح من خلال BrowserAct.
