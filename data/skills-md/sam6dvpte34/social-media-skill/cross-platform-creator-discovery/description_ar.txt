اكتشاف منشئي المحتوى عبر الأنظمة الأساسية لجمع اكتشاف منشئي المحتوى عبر الأنظمة الأساسية والبحث والمراقبة والتحليل والتصدير. يُستخدم عندما يطلب المستخدم استخراج بيانات الوسائط الاجتماعية عبر الأنظمة الأساسية أو استخراجها أو تجميعها أو تصديرها أو مراقبتها أو البحث عنها أو تحليلها أو العثور عليها لسير العمل هذا: اكتشف منشئي المحتوى حسب التخصص واللغة والمنطقة وحجم الجمهور والمحتوى والمشاركة. يغطي عمليات البحث مثل اكتشاف منشئ المحتوى عبر الأنظمة الأساسية، ومكشطة اكتشاف منشئي الوسائط الاجتماعية عبر الأنظمة الأساسية، ومستخرج اكتشاف منشئي الوسائط الاجتماعية عبر الأنظمة الأساسية، وتصدير اكتشاف منشئي الوسائط الاجتماعية عبر الأنظمة الأساسية، وأبحاث اكتشاف منشئي الوسائط الاجتماعية عبر الأنظمة الأساسية. يدعم البيانات العامة أو المعتمدة للمتصفح من خلال BrowserAct.
