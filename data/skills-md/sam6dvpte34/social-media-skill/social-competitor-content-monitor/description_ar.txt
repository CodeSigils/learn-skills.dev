مراقب محتوى المنافس الاجتماعي لجمع محتوى منافس الوسائط الاجتماعية عبر الأنظمة الأساسية والبحث والمراقبة والتحليل والتصدير. يُستخدم عندما يطلب المستخدم استخراج بيانات الوسائط الاجتماعية عبر الأنظمة الأساسية أو استخراجها أو جمعها أو تصديرها أو مراقبتها أو بحثها أو تحليلها أو العثور عليها لسير العمل هذا: تتبع منشورات المنافسين والحملات وتكرار النشر والموضوعات وتغييرات المشاركة. يغطي عمليات البحث مثل مراقبة محتوى المنافس الاجتماعي، ومكشطة مراقبة محتوى منافس وسائل التواصل الاجتماعي عبر الأنظمة الأساسية، ومستخرج مراقبة محتوى منافس وسائل التواصل الاجتماعي عبر الأنظمة الأساسية، وتصدير مراقبة محتوى منافس وسائل التواصل الاجتماعي عبر الأنظمة الأساسية، وبحث مراقبة محتوى منافس وسائل التواصل الاجتماعي عبر الأنظمة الأساسية. يدعم البيانات العامة أو المعتمدة للمتصفح من خلال BrowserAct.
