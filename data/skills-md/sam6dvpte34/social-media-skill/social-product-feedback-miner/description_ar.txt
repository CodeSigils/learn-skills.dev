أداة تعدين تعليقات المنتج الاجتماعي لجمع تعليقات منتج الوسائط الاجتماعية والبحث والمراقبة والتحليل والتصدير. يُستخدم عندما يطلب المستخدم استخراج بيانات الوسائط الاجتماعية عبر الأنظمة الأساسية أو استخراجها أو تجميعها أو تصديرها أو مراقبتها أو بحثها أو تحليلها أو العثور عليها لسير العمل هذا: اجمع الثناء العام والشكاوى وطلبات الميزات ومناقشات استخدام المنتج. يغطي عمليات البحث مثل أداة تعدين تعليقات المنتج الاجتماعي، ومكشطة تعدين تعليقات منتج الوسائط الاجتماعية عبر الأنظمة الأساسية، ومستخرج تعدين تعليقات منتج الوسائط الاجتماعية عبر الأنظمة الأساسية، وتصدير عمال المناجم لتعليقات منتج الوسائط الاجتماعية عبر الأنظمة الأساسية، وأبحاث عمال المناجم الخاصة بتعليقات منتجات الوسائط الاجتماعية عبر الأنظمة الأساسية. يدعم البيانات العامة أو المعتمدة للمتصفح من خلال BrowserAct.
