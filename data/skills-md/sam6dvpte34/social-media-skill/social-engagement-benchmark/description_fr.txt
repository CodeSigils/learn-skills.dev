Référence d'engagement social pour la collecte, la recherche, la surveillance, l'analyse et l'exportation de références d'engagement sur les réseaux sociaux multiplateformes. À utiliser lorsque l'utilisateur demande à récupérer, extraire, collecter, exporter, surveiller, rechercher, analyser ou trouver des données de médias sociaux multiplateformes visibles dans le navigateur pour ce flux de travail : collectez des mesures d'engagement comparables pour les créateurs, les marques, les concurrents ou les campagnes. Couvre des recherches telles que Social Engagement Benchmark, grattoir de référence d'engagement sur les réseaux sociaux multiplateforme, extracteur de référence d'engagement sur les réseaux sociaux multiplateforme, exportation de référence d'engagement sur les réseaux sociaux multiplateforme, recherche de référence sur l'engagement sur les réseaux sociaux multiplateforme. Prend en charge les données publiques ou autorisées visibles par le navigateur via BrowserAct.
