معيار المشاركة الاجتماعية لجمع معايير المشاركة في وسائل التواصل الاجتماعي عبر الأنظمة الأساسية والبحث والمراقبة والتحليل والتصدير. يُستخدم عندما يطلب المستخدم استخراج بيانات الوسائط الاجتماعية عبر الأنظمة الأساسية أو استخراجها أو جمعها أو تصديرها أو مراقبتها أو بحثها أو تحليلها أو العثور عليها لسير العمل هذا: اجمع مقاييس المشاركة القابلة للمقارنة للمبدعين أو العلامات التجارية أو المنافسين أو الحملات. يغطي عمليات البحث مثل مقياس المشاركة الاجتماعية، ومكشطة معايير المشاركة في وسائل التواصل الاجتماعي عبر الأنظمة الأساسية، ومستخرج معايير المشاركة في وسائل التواصل الاجتماعي عبر الأنظمة الأساسية، وتصدير معايير المشاركة في وسائل التواصل الاجتماعي عبر الأنظمة الأساسية، والبحث القياسي للمشاركة في وسائل التواصل الاجتماعي عبر الأنظمة الأساسية. يدعم البيانات العامة أو المعتمدة للمتصفح من خلال BrowserAct.
