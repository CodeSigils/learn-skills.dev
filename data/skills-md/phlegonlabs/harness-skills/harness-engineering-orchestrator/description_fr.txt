Orchestration PRD-to-code basée sur le repo pour Claude et Codex. À utiliser lorsque l'utilisateur souhaite qu'une nouvelle application ou un référentiel existant soit exécuté via la découverte, l'architecture, les jalons, l'exécution et la validation au lieu d'une livraison ponctuelle par invite uniquement. Prend en charge les nouvelles bases de code et les bases de code existantes dans les projets Web, iOS, Android, CLI, agents, API et de bureau dans n'importe quel écosystème linguistique (JavaScript/TypeScript, Python, Go, Rust, Java, Kotlin, Swift, Flutter, etc.).
