Анализирует проиндексированные и непроиндексированные файлы из полного рабочего дерева, группирует их в функциональные кластеры (тест, документация, работа, префикс каталога), генерирует обычное сообщение о фиксации для каждой группы, обнаруживает общие проблемы (секреты, операторы отладки, большие файлы) и последовательно выполняет одну фиксацию для каждой группы после представления плана с несколькими фиксациями для подтверждения. Переходит к потоку с одной фиксацией, когда все обнаруженные файлы разрешаются в одну группу. Триггер: когда пользователь произносит «commit», «smart commit» или /commit.
