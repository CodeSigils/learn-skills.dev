Analizza i file in stage e non in stage dall'intero albero di lavoro, li raggruppa in cluster funzionali (test, documenti, lavoro di routine, prefisso di directory), genera un messaggio di commit convenzionale per gruppo, rileva problemi comuni (segreti, istruzioni di debug, file di grandi dimensioni) ed esegue un commit per gruppo in sequenza dopo aver presentato un piano multi-commit per la conferma. Passa a un flusso con commit singolo quando tutti i file rilevati vengono risolti in un gruppo. Trigger: quando l'utente dice "commit", "smart commit" o /commit.
