Проверяет папку времени выполнения ~/.claude/ или конфигурацию .claude/ проекта на предмет отклонений при установке, пробелов в развертывании навыков, потерянных артефактов и соответствия уровня области действия. Только для чтения. Создает файл claude-folder-audit-report.md в соответствующем месте. Триггер: /claude-folder-audit, среда выполнения аудита, папка аудита .claude, проверка отклонения установки, проверка развертывания навыков, проверка конфигурации Claude проекта.
