Ускоренный цикл SDD: включает обязательное исследование в качестве шага 0, затем автоматически выполняется предложение → спецификация + проектирование (параллельно) → задачи, а затем запрашивается перед применением. Триггер: /sdd-ff <описание>, быстрый цикл SDD, быстрая перемотка вперед, быстрая перемотка SDD вперед.
