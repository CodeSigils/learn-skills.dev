Utilisez cette compétence lorsque l'utilisateur est dans le cycle de vie de la compétence : créez une nouvelle compétence à partir d'un modèle de workflow/modèle/processus/décision, améliorez une compétence existante via une évaluation et une itération (avec compétence ou référence), optimisez indépendamment la description du déclencheur d'une compétence ou auditez la conformité de la compétence à l'aide de principes d'écriture (rapport uniquement, pas de réécriture).  

Déclencheurs : « Je veux / m'aider à créer une compétence pour X », « Construire une compétence à partir de zéro pour gérer X », « Distiller le processus XX en une compétence », « Pour qu'il puisse être utilisé plus tard / par des nouveaux arrivants / suivre ceci » ; améliorer/évaluer/itérer la compétence XX ; commentaires des utilisateurs indiquant que le déclencheur est inexact ou que le comportement est erroné ; souhaite réaliser une évaluation ; souhaite uniquement modifier la description initiale : lorsque l'utilisateur dit « optimiser la description » dans un sens générique (y compris le texte du corps), cela se déclenche également.  

Non applicable : requêtes en une seule étape, écriture de code ordinaire, édition de documents ordinaires (à l'aide de yzr‑writing‑review, etc.) ou tout ce qui n'implique pas le cycle de vie des compétences.
