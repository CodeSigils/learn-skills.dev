Wenn sich der Benutzer im Skill-Lebenszyklus befindet, verwenden Sie diesen Skill: Erstellen Sie einen neuen Skill aus Workflows/Vorlagen/Prozessen/Entscheidungsmodellen; Verbessern Sie eine vorhandene Fertigkeit durch Evaluierung und Iteration (mit Fertigkeit vs. Grundlinie); die Auslöserbeschreibung einer Fertigkeit unabhängig optimieren; oder die Einhaltung der Kompetenzen mithilfe von Schreibprinzipien prüfen (nur Bericht, kein Umschreiben).  

Auslöser: „Ich möchte/helfe mir, eine Fertigkeit für X zu entwickeln“; „Erstellen Sie eine Fertigkeit von Grund auf, um mit X umzugehen“; „Destillieren Sie den XX-Prozess in eine Fertigkeit“; „Damit es später / von Neulingen verwendet werden kann / folgen Sie diesem“; die XX-Fertigkeit verbessern/bewerten/wiederholen; Benutzer-Feedback, dass der Auslöser ungenau ist oder das Verhalten falsch ist; eine Evaluierung durchführen möchten; Ich möchte nur die Frontmatter-Beschreibung bearbeiten. Wenn der Benutzer im allgemeinen Sinne „Beschreibung optimieren“ sagt (einschließlich Text), wird dies ebenfalls ausgelöst.  

Nicht anwendbar: einstufige Anfragen; Schreiben von gewöhnlichem Code; Bearbeiten regulärer Dokumente (verwenden Sie yzr-writing-review usw.); Angelegenheiten, die nicht den Skill-Lebenszyklus betreffen.
