When users interact with a local, single‑user, compound‑interest‑style Markdown personal wiki (Karpathy’s “LLM owns wiki” mode), use this skill—covering: initial setup, bulk ingestion of raw material (papers / articles / clippings / external code‑repo symlink integration), cross‑page synthesis / comparison / conflict resolution / answer archiving back to the wiki, conflict / orphan / stale‑summary linting, spec upgrades and migration. Maintain the four‑layer discipline of raw/user control + wiki/LLM ownership + AGENTS.md as the single source of truth.

Triggers: “Ingest this paper into the wiki” / “Summarize the content about X in the wiki” / “The wiki has contradictory statements A and B, help me reconcile them” / “Scan the wiki for orphan pages / stale summaries” / “Upgrade the wiki / migrate to the latest spec / check the wiki version” / “Add repository X (source code) to the wiki” / “I want to set up a wiki to manage X”.

Not applicable: cloud / team‑collaboration wikis (Notion / Confluence / Outline / GitHub Wiki—use yz‑r‑outline‑wiki).
