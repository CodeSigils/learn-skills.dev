Когда пользователи взаимодействуют с локальной однопользовательской персональной вики Markdown в стиле сложных процентов (режим Karpathy «LLM владеет вики»), используйте этот навык, включая: первоначальную настройку, массовую загрузку исходного материала (документы/статьи/вырезки/интеграцию символических ссылок с внешним репозиторием кода), межстраничный синтез/сравнение/разрешение конфликтов/архивирование ответов обратно в вики, анализ конфликтов/сирот/устаревших сводок, обновления спецификаций и миграция. Поддерживайте четырехуровневую дисциплину: необработанный/пользовательский контроль+вики/владение LLM+AGENTS.md как единственный источник истины.

Триггеры: «Вставить эту статью в вики» / «Обобщить содержание X в вики» / «В вики есть противоречивые утверждения A и B, помогите мне согласовать их» / «Просканировать вики на наличие потерянных страниц / устаревших сводок» / «Обновить вики / перейти на последнюю спецификацию / проверить версию вики» / «Добавить репозиторий X (исходный код) в вики» / «Я хочу настроить вики для управления X».

Неприменимо: вики-сайты для облачной/командной совместной работы (Notion/Confluence/Outline/GitHub Wiki — используйте yz‑r‑outline‑wiki).
