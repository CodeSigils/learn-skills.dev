When a user wants to convert a local Markdown file or directory (README / technical documentation / notes / draft paper) into a self‑contained HTML file that can be opened in a browser with a double‑click, use this skill: default dark reading theme + sidebar TOC + offline code highlighting, formulas/Mermaid loaded via CDN on demand, and support for `--template` custom templates.  

Triggers: “Convert this README to a nice HTML to send to a colleague,” “This design document has formulas and flowcharts; export it as a web page that can be opened directly,” “Batch convert the .md files under the notes/ directory to HTML,” “After converting to HTML, upload and share with agent‑html‑drop.” As long as the user explicitly wants a one‑way conversion “local .md → self‑contained HTML file” — even if they don’t mention the skill name — this skill must be used.  

Not applicable: writing a web page from scratch / front‑end pages (use basic tools), documentation site / static site generation and deployment (for hosting online pages), Markdown → PDF or other formats, reverse conversion HTML → Markdown, real‑time preview / online editor, uploading to Outline Wiki (use yzr‑outline‑wiki).
