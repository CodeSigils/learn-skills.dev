Lorsque les utilisateurs souhaitent convertir un fichier ou un répertoire Markdown local (README/document technique/notes/brouillon papier) en un fichier HTML autonome pouvant être ouvert en double-cliquant dans un navigateur, ils doivent utiliser cette compétence : thème de lecture sombre par défaut + table des matières de la barre latérale + surbrillance de code hors ligne, formules/sirène chargées via CDN à la demande et prise en charge des modèles personnalisés `--template`.  
Déclencheurs : "Convertissez ce README en un joli HTML et envoyez-le à un collègue", "Ce document de conception contient des formules et des organigrammes ; exportez-le vers une page Web qui peut être ouverte directement", "Convertissez par lots les fichiers .md du répertoire notes/ en HTML", "Après la conversion en HTML, téléchargez et partagez avec l'agent-html-drop." Tant que l’utilisateur souhaite explicitement une conversion unidirectionnelle « .md local → fichier HTML autonome » – même s’il ne mentionne pas le nom de la compétence – la compétence doit être utilisée.  
Non applicable : écriture d'une page Web à partir de zéro/page frontale (utiliser des outils de base), génération et déploiement d'un site de documentation/site statique (pour les pages en ligne hébergées), Markdown → PDF ou autres formats, conversion inversée HTML → Markdown, aperçu en direct/éditeur en ligne, téléchargement vers Outline Wiki (utilisez yzr‑outline‑wiki).
