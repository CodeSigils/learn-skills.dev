عندما يريد المستخدم تحويل ملف أو دليل Markdown محلي (README / الوثائق الفنية / الملاحظات / مسودة الورق) إلى ملف HTML قائم بذاته يمكن فتحه في متصفح بنقرة مزدوجة، استخدم هذه المهارة: سمة القراءة المظلمة الافتراضية + جدول المحتويات على الشريط الجانبي + تمييز التعليمات البرمجية غير المتصلة بالإنترنت، وتحميل الصيغ/Mermaid عبر CDN عند الطلب، ودعم القوالب المخصصة `--template`.  

المشغلات: "تحويل ملف README هذا إلى ملف HTML جميل لإرساله إلى زميل"، "يحتوي مستند التصميم هذا على صيغ ومخططات انسيابية؛ قم بتصديره كصفحة ويب يمكن فتحها مباشرة"، "تحويل ملفات .md ضمن الملاحظات/ الدليل إلى HTML دفعة واحدة"، "بعد التحويل إلى HTML، قم بالتحميل والمشاركة مع Agent-html-drop." طالما أن المستخدم يريد صراحةً إجراء تحويل أحادي الاتجاه "ملف .md محلي → ملف HTML مستقل بذاته" - حتى لو لم يذكر اسم المهارة - فيجب استخدام هذه المهارة.  

غير قابل للتطبيق: كتابة صفحة ويب من البداية / صفحات الواجهة الأمامية (استخدم الأدوات الأساسية)، إنشاء ونشر موقع التوثيق / الموقع الثابت (لاستضافة الصفحات عبر الإنترنت)، Markdown → PDF أو تنسيقات أخرى، تحويل عكسي HTML → Markdown، معاينة في الوقت الفعلي / محرر عبر الإنترنت، تحميل إلى Outline Wiki (استخدم yzr‑outline‑wiki).
