ユーザーがローカルの Markdown ファイルまたはディレクトリ (README / 技術文書 / メモ / 草稿) を、ブラウザでダブルクリックして開くことができる自己完結型の HTML ファイルに変換したい場合は、このスキルを使用します: デフォルトのダーク リーディング テーマ + サイドバーの目次 + オフライン コードの強調表示、オンデマンドで CDN 経由でロードされる式/マーメイド、および `--template` カスタム テンプレートのサポート。  

トリガー: 「この README を同僚に送信するために適切な HTML に変換する」、「この設計ドキュメントには数式とフローチャートが含まれています。直接開くことができる Web ページとしてエクスポートします」、「notes/ ディレクトリにある .md ファイルを HTML にバッチ変換します」、「HTML に変換した後、アップロードして、agent-html-drop で共有します。」ユーザーが「ローカル .md → 自己完結型 HTML ファイル」という一方向の変換を明示的に希望している限り、たとえスキル名を言及していなくても、このスキルを使用する必要があります。  

該当なし: Web ページを最初から作成する / フロントエンド ページ (基本ツールを使用)、ドキュメント サイト / 静的サイトの生成と展開 (オンライン ページをホストする場合)、マークダウン → PDF またはその他の形式、HTML → マークダウンの逆変換、リアルタイム プレビュー / オンライン エディター、アウトライン Wiki へのアップロード (yzr-outline-wiki を使用)。
