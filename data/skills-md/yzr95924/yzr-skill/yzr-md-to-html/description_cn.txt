当用户想要将本地 Markdown 文件或目录（README/技术文档/笔记/草稿纸）转换为可在浏览器中双击打开的独立 HTML 文件时，可以使用此技巧：默认暗读主题 + 侧边栏 TOC + 离线代码高亮、通过 CDN 按需加载公式/Mermaid、支持 `--template` 自定义模板。  

触发因素：“将此README转换为漂亮的HTML发送给同事”，“此设计文档有公式和流程图，导出为可直接打开的网页”，“将notes/目录下的.md文件批量转换为HTML”，“转换为HTML后，上传并与agent-html-drop共享”。只要用户明确想要单向转换“本地 .md → 自包含 HTML 文件”——即使他们没有提及技能名称——就必须使用此技能。  

不适用：从头开始编写网页/前端页面（使用基本工具）、文档站点/静态站点生成和部署（用于托管在线页面）、Markdown→PDF或其他格式、反向转换HTML→Markdown、实时预览/在线编辑器、上传到Outline Wiki（使用yzr-outline-wiki）。
