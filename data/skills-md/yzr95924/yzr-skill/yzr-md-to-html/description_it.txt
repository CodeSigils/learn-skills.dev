Quando un utente desidera convertire un file o una directory Markdown locale (README/documentazione tecnica/note/bozza cartacea) in un file HTML autonomo che può essere aperto in un browser con un doppio clic, utilizza questa abilità: tema di lettura scuro predefinito + sommario della barra laterale + evidenziazione del codice offline, formule/Sirena carica CDN su richiesta e supporta `--template` per modelli personalizzati.  
Trigger: “Converti questo README in un bel HTML e invialo a un collega”; "Questo documento di progettazione contiene formule e diagrammi di flusso, esportalo in una pagina Web che può essere aperta direttamente"; "Converti in batch i file .md nella directory notes/ in HTML"; "Dopo la conversione in HTML, carica e condividi con agent-html-drop". Finché l'utente desidera esplicitamente una conversione unidirezionale ".md locale → file HTML autonomo" (anche se non menziona il nome della competenza), è necessario utilizzare questa competenza.  

Non applicabile: creazione di un sito Web da zero/pagine front-end (utilizzare strumenti di base), generazione e distribuzione di siti di documentazione/siti statici (per pagine online ospitate), Markdown → PDF o altri formati, conversione inversa HTML → Markdown, anteprima dal vivo/editor online, caricamento su Outline Wiki (utilizzare yzr‑outline‑wiki).
