Wenn ein Benutzer eine lokale Markdown-Datei oder ein lokales Markdown-Verzeichnis (README, technische Dokumentation, Notizen, Entwurfspapier) in eine eigenständige HTML-Datei konvertieren möchte, die mit einem Doppelklick in einem Browser geöffnet werden kann, verwenden Sie diese Fähigkeit: standardmäßiges dunkles Lesedesign + Seitenleisten-Inhaltsverzeichnis + Offline-Code-Hervorhebung, Formeln/Mermaid, die bei Bedarf vom CDN geladen werden, und Unterstützung für benutzerdefinierte „--template“-Vorlagen.

Auslöser: „Konvertieren Sie diese README-Datei in eine schöne HTML-Datei, um sie an einen Kollegen zu senden“, „Dieses Designdokument enthält Formeln und Flussdiagramme; exportieren Sie es als Webseite, die direkt geöffnet werden kann“, „Konvertieren Sie die .md-Dateien im Verzeichnis „notes/“ stapelweise in HTML“, „Nach der Konvertierung in HTML hochladen und mit agent-html-drop teilen.“ Solange der Benutzer explizit eine einseitige Konvertierung „lokale .md → eigenständige HTML-Datei“ wünscht – auch wenn er den Skillnamen nicht nennt – muss dieser Skill verwendet werden.

Nicht anwendbar: Erstellen einer Webseite von Grund auf/Front-End-Seiten (verwenden Sie grundlegende Tools), Dokumentations-Site/statische Site-Generierung und -Bereitstellung (erfordert Online-Hosting), Markdown → PDF oder andere Formate, HTML → Markdown-Rückkonvertierung, Echtzeitvorschau/Online-Editor, Hochladen in Outline Wiki (yzr-outline-wiki verwenden).
