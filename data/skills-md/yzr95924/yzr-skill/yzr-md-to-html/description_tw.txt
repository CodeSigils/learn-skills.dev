當使用者想要將本機 Markdown 檔案或目錄（README/技術文件/筆記/草稿紙）轉換為可在瀏覽器中雙擊開啟的獨立 HTML 檔案時，可以使用此技巧：預設暗讀主題 + 側邊欄 TOC + 離線程式碼高亮、透過 CDN 按需載入公式/Mermaid、支援 `--template` 自訂範本。  

觸發因素：“將此README轉換為漂亮的HTML發送給同事”，“此設計文件有公式和流程圖，導出為可直接打開的網頁”，“將notes/目錄下的.md文件批量轉換為HTML”，“轉換為HTML後，上傳並與agent-html-drop共享”。只要使用者明確想要單向轉換「本機 .md → 自包含 HTML 檔案」—即使他們沒有提及技能名稱—就必須使用此技能。  

不適用：從頭開始編寫網頁/前端頁面（使用基本工具）、文件網站/靜態網站產生和部署（用於託管線上頁面）、Markdown→PDF或其他格式、反向轉換HTML→Markdown、即時預覽/線上編輯器、上傳到Outline Wiki（使用yzr-outline-wiki）。
