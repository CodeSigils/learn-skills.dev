Cuando un usuario quiera convertir un archivo o directorio local de Markdown (README/documentación técnica/notas/borrador) en un archivo HTML independiente que se puede abrir en un navegador con un doble clic, use esta habilidad: tema de lectura oscuro predeterminado + TOC de la barra lateral + resaltado de código sin conexión, fórmulas/Sirena cargadas a través de CDN a pedido y soporte para plantillas personalizadas `--template`.  

Activadores: "Convierta este archivo README en un bonito HTML para enviárselo a un colega", "Este documento de diseño tiene fórmulas y diagramas de flujo; expórtelo como una página web que se puede abrir directamente", "Convierta por lotes los archivos .md en el directorio notas/a HTML", "Después de convertirlos a HTML, cárguelos y compártalos con agent-html-drop". Siempre que el usuario desee explícitamente una conversión unidireccional “.md local → archivo HTML autónomo” (incluso si no menciona el nombre de la habilidad), se debe utilizar esta habilidad.  

No aplicable: escribir una página web desde cero/páginas frontales (use herramientas básicas), sitio de documentación/generación e implementación de sitios estáticos (para alojar páginas en línea), Markdown → PDF u otros formatos, conversión inversa HTML → Markdown, vista previa en tiempo real/editor en línea, carga en Outline Wiki (use yzr‑outline‑wiki).
