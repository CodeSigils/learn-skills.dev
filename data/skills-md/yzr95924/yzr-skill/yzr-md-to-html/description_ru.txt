Когда пользователь хочет преобразовать локальный файл или каталог Markdown (README/техническая документация/заметки/черновик) в автономный HTML-файл, который можно открыть в браузере двойным щелчком мыши, используйте этот навык: темная тема чтения по умолчанию + оглавление боковой панели + подсветка автономного кода, формулы/Mermaid, загружаемые через CDN по требованию, и поддержка пользовательских шаблонов `--template`.  

Триггеры: «Преобразуйте этот README в красивый HTML-код для отправки коллеге», «Этот проектный документ содержит формулы и блок-схемы; экспортируйте его как веб-страницу, которую можно открыть напрямую», «Пакетное преобразование файлов .md в каталоге Notes/ в HTML», «После преобразования в HTML загрузите и поделитесь с агентом-html-drop». Пока пользователь явно хочет одностороннего преобразования «локальный .md → автономный HTML-файл» — даже если он не упоминает имя навыка — этот навык необходимо использовать.  

Неприменимо: написание веб-страницы с нуля / интерфейсных страниц (используйте базовые инструменты), создание сайта документации / статического сайта и развертывание (для размещения онлайн-страниц), Markdown → PDF или другие форматы, обратное преобразование HTML → Markdown, предварительный просмотр в реальном времени / онлайн-редактор, загрузка в Outline Wiki (используйте yzr‑outline‑wiki).
