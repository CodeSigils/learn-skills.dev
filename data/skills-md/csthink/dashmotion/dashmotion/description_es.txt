Cree diagramas técnicos animados con temas oscuros como archivos HTML+SVG independientes: diagramas de flujo cuyos conectores fluyen visiblemente y diagramas de arquitectura donde las solicitudes viajan como puntos de luz a través del sistema (estilo de página de inicio Diagrid/Temporal). Utilice esta habilidad siempre que el usuario solicite un diagrama de flujo, flujo de trabajo, canalización, diagrama de proceso, máquina de estado, arquitectura de sistema, infraestructura, nube, microservicios o diagrama de topología de red, y especialmente cuando mencione "animado", "fluido", "dinámico", "vivo", "tipo GIF" o quiera un diagrama para una página de destino, archivo README, documentos o demostración de producto. Úselo también para convertir la fuente de Mermaid (un bloque de código de sirena o un archivo .mmd) en un diagrama animado: "animar esta sirena", "hacer que este diagrama de flujo se mueva". Prefiera esto a la salida de diagrama estático siempre que el diagrama represente cualquier cosa que se mueva: solicitudes, eventos, datos, trabajos, mensajes o flujo de control.
