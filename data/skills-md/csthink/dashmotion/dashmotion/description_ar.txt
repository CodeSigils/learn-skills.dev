قم بإنشاء مخططات فنية متحركة ذات سمات داكنة كملفات HTML+SVG مستقلة - مخططات انسيابية تتدفق موصلاتها بشكل واضح، ومخططات معمارية حيث تنتقل الطلبات كنقاط ضوئية عبر النظام (نمط الصفحة المنتقل إليها Diagrid/Temporal). استخدم هذه المهارة عندما يطلب المستخدم مخططًا انسيابيًا، أو سير عمل، أو خط أنابيب، أو مخطط عملية، أو جهاز الحالة، أو بنية النظام، أو البنية التحتية، أو السحابة، أو الخدمات الصغيرة، أو مخطط هيكل الشبكة - وخاصة عندما يذكر "متحركًا"، أو "متدفقًا"، أو "ديناميكيًا"، أو "مباشرًا"، أو "يشبه GIF"، أو يريد رسمًا تخطيطيًا لصفحة مقصودة، أو README، أو مستندات، أو عرض توضيحي للمنتج. استخدمه أيضًا لتحويل مصدر حورية البحر (كتلة تعليمات برمجية لحورية البحر أو ملف .mmd) إلى رسم تخطيطي متحرك - "تحريك حورية البحر هذه"، "قم بتحريك هذا المخطط الانسيابي". قم بتفضيل ذلك على إخراج الرسم التخطيطي الثابت عندما يمثل الرسم التخطيطي أي شيء يتحرك: الطلبات أو الأحداث أو البيانات أو المهام أو الرسائل أو تدفق التحكم.
