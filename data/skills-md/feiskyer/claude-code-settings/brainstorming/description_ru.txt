Перед реализацией изучите намерения пользователей, требования и варианты дизайна посредством совместного диалога. Используйте перед созданием новых функций, компонентов или систем — всякий раз, когда пользователь описывает что-то для создания и принимает решения по проектированию. Триггеры: «мозговой штурм», «помоги мне спроектировать», «продумать требования», «头脑风暴», «设计方案», «梳理需求». Не для исправления ошибок, изменений конфигурации или задач с очевидным путем реализации.
