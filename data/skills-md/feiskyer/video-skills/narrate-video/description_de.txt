Erstellen Sie professionelle Voiceover-Kommentare für ein Video mit Audio-Video-Synchronisierung, indem Sie standardmäßig Azure TTS oder Gemini 3.1 Flash TTS verwenden, wenn es konfiguriert ist. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einer Videodatei einen Kommentar, einen Voiceover, einen Kommentar oder eine Synchronisation hinzufügen möchte – auch wenn er nur „Audio zu diesem Video hinzufügen“ oder „eine kommentierte Version erstellen“ sagt. Wird auch ausgelöst, wenn der Benutzer über eine Bildschirmaufzeichnung, eine Demo, ein Tutorial oder ein Präsentationsvideo verfügt, für das eine Sprachspur erforderlich ist. Auslösen bei chinesischen Anfragen wie „视频配音“, „给视频加旁白“, „录屏解说“, „视频加语音“, „视频添加声音“, „生成视频旁白“, „自动配音“, „视频解说词“.
