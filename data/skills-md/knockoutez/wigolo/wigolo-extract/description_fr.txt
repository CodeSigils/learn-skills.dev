Extraction structurée d'abord locale à partir de n'importe quelle page Web : tableaux, listes de définitions, paires clé-valeur, JSON-LD, microdonnées, conseils de graphiques (titres SVG/étiquettes aria/figcaptions), actifs de marque et métadonnées. À utiliser lorsque l'utilisateur souhaite des données structurées, des tableaux de prix, des comparaisons de fonctionnalités ou dit « extraire le tableau », « obtenir des données structurées », « extraire les prix », « extraire au format JSON ». Pour une navigation autonome sur de nombreuses pages, utilisez plutôt l'outil « agent » de wigolo.
