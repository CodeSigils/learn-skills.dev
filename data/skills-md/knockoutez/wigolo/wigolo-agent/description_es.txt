Recopilación autónoma de datos entre fuentes: planifica consultas de búsqueda y URL a partir de un mensaje en lenguaje natural, se ejecuta en paralelo dentro de un presupuesto de tiempo, opcionalmente extrae campos estructurados a través de un esquema JSON y sintetiza los resultados con total transparencia en los pasos. Úselo cuando el usuario necesita datos recopilados de la web con una forma específica, dice "recopilar datos", "buscar precios para", "recopilar información sobre", "extraer de múltiples sitios" o proporciona un esquema JSON para datos web.
