Collecte de données autonome entre sources : planifie les requêtes de recherche et les URL à partir d'une invite en langage naturel, s'exécute en parallèle dans un budget de temps, extrait éventuellement les champs structurés via le schéma JSON et synthétise les résultats avec une transparence totale. À utiliser lorsque l'utilisateur a besoin de données collectées sur le Web avec une forme spécifique, dit « collecter des données », « trouver des prix pour », « collecter des informations sur », « extraire de plusieurs sites » ou fournit un schéma JSON pour les données Web.
