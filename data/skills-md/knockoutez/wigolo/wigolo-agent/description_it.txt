Raccolta autonoma dei dati tra origini: pianifica query di ricerca e URL da un prompt in linguaggio naturale, viene eseguito in parallelo entro un budget temporale, facoltativamente estrae campi strutturati tramite schema JSON e sintetizza i risultati con trasparenza completa dei passaggi. Utilizzare quando l'utente necessita di dati raccolti dal Web con una forma specifica, ad esempio "raccogli dati", "trova prezzi per", "raccogli informazioni su", "estrai da più siti" o fornisce uno schema JSON per i dati Web.
