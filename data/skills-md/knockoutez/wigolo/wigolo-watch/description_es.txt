Supervise una página para detectar cambios a lo largo del tiempo. Cree trabajos de vigilancia diferida en una o varias URL, enumérelos y verifique si hay cambios a pedido, con entrega de webhook opcional protegido por SSRF cuando se detecta un cambio. Úselo cuando el usuario dice "supervisar esta página", "observar esta URL en busca de cambios", "avíseme cuando se actualice", "siga este registro de cambios", "notifiqueme si esto cambia" o desea una detección de cambios recurrente en el contenido web.
