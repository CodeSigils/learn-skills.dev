Überwachen Sie eine Seite auf Änderungen im Laufe der Zeit. Erstellen Sie Lazy-Watch-Jobs für eine oder mehrere URLs, listen Sie sie auf und prüfen Sie bei Bedarf auf Änderungen – mit optionaler SSRF-geschützter Webhook-Zustellung, wenn eine Änderung erkannt wird. Wird verwendet, wenn der Benutzer sagt: „Überwachen Sie diese Seite“, „Überwachen Sie diese URL auf Änderungen“, „Benachrichtigen Sie mich, wenn dies aktualisiert wird“, „Verfolgen Sie dieses Änderungsprotokoll“, „Benachrichtigen Sie mich, wenn sich dies ändert“ oder möchte, dass wiederkehrende Änderungen an Webinhalten erkannt werden.
