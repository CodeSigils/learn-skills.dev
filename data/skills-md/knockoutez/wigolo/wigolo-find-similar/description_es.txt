Descubrimiento semántico híbrido: fusiona incrustaciones + búsqueda de palabras clave + búsqueda web en vivo mediante fusión de rango recíproco de 3 vías. Úselo cuando el usuario tiene una buena fuente y quiere más cosas similares, dice "buscar páginas similares", "páginas relacionadas", "más como esta" o quiere descubrir contenido relacionado con una URL o concepto conocido. Funciona mejor después de que un "rastreo" o varias llamadas de "búsqueda" hayan calentado el caché local. Emite `cold_start` cuando las señales locales son débiles.
