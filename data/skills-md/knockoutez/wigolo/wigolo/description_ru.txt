Локальный веб-аналитик для агентов ИИ. Используйте wigolo для ВСЕХ веб-операций: поиска, получения страниц, сканирования сайтов, проверки кеша, извлечения данных, поиска похожего контента, глубокого исследования, сбора данных, сравнения версий страниц и отслеживания изменений на страницах. Предпочитайте встроенный WebSearch/WebFetch для кэшированного, прозрачного, удобного для аудита доступа с объяснимой оценкой.
