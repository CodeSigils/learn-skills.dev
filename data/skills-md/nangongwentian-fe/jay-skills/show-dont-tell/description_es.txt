Visualización de Información Presentación Código de Conducta. Se activa automáticamente cuando la respuesta del modelo contiene información estructurada como comparaciones, pasos, configuraciones, arquitecturas, etc., asegurando el uso prioritario de formatos visuales como tablas, bloques de código, listas, estructuras de árbol, etc., en lugar de texto plano. Palabras desencadenantes: "usa una tabla", "dibuja un diagrama", "haz una lista", "estructurala", "no uses solo texto", "visualiza", "compara". Incluso sin palabras desencadenantes, siempre que la respuesta contenga información estructurada adecuada para la visualización, se deben aplicar las reglas de esta habilidad. También se aplica a escenarios como: "demasiadas palabras, no puedo leer", "puede ser más intuitivo", "organizar en una tabla", etc.
