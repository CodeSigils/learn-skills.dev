Pautas de presentación de visualización de información. Se activa automáticamente cuando la respuesta del modelo contiene información estructurada como comparaciones, pasos, configuraciones, arquitecturas, etc., asegurando el uso prioritario de formatos visuales como tablas, bloques de código, listas, estructuras de árbol, etc., en lugar de texto plano. Palabras desencadenantes: "usa una tabla", "dibuja un diagrama", "haz una lista", "estructurala", "no uses solo texto", "visualiza", "compara". Incluso sin palabras desencadenantes, siempre que la respuesta contenga información estructurada adecuada para la visualización, las reglas de esta habilidad deberían surtir efecto. También se aplica a escenarios como: "demasiado texto no se puede leer", "puede ser más intuitivo", "organizar en una tabla".
