Un flusso di lavoro end-to-end per il runtime di WeChat DevTools destinato ai layout monorepo weapp-vite. Adatto per "e2e/ide/**", "miniprogram-automator", asserzioni di pagine di runtime reali, avvio di automatismi condivisi, concatenamento tramite "miniProgram.reLaunch(...)", manutenzione condizionale della pagina in "project.private.config.json" e formazione di una pipeline di accettazione di runtime reale insieme a "weapp-vite screenshot/compare/ide logs".
