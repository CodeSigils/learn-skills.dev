An engineering handbook for projects using the weapp-vite repository layout, covering weapp configuration in `vite.config.ts`, `app.json` routes/subPackages, chunk strategies, and CI/DevTools automation. Suitable for creating or refactoring weapp-vite projects, configuring automatic routing/components, splitting subpackages, optimizing chunk output, or troubleshooting build and output issues (e.g., “configure weapp-vite”, “subpackage strategy”, “build output anomalies”, “typed-router.d.ts generation problems”).
