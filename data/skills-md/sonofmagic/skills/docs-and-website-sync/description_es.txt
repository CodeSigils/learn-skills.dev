Un flujo de trabajo para sincronizar documentación, sitios web y habilidades en repositorios monorepo de weapp-vite. Diseñado para escenarios donde las capacidades del código han cambiado pero el sitio web/docs/README/skills/AI guías/documentos empaquetados pueden estar desactualizados, especialmente cubriendo páginas de configuración `weapp`, `dist/docs`, plantillas `AGENTS.md`, instalación de habilidades AI, `prepare`, MCP, `forwardConsole`, `screenshot/compare/ide logs`, tiempo de ejecución web, modo lib, multiplataforma y routeRules/layout sincronización de entrada.
