Un workflow pour synchroniser la documentation, le site Web et les compétences dans les référentiels monorepo weapp-vite. Conçu pour les scénarios dans lesquels les fonctionnalités du code ont changé mais où les sites Web/docs/README/skills/AI guides/documents packagés peuvent être obsolètes, en particulier couvrant les pages de configuration `weapp`, `dist/docs`, les modèles `AGENTS.md`, l'installation des compétences IA, `prepare`, MCP, `forwardConsole`, `screenshot/compare/ide logs`, Web runtime, mode lib, multi-plateforme et synchronisation des entrées routeRules/layout.
