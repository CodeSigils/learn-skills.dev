Un flusso di lavoro per sincronizzare documentazione, sito Web e competenze nei repository monorepo weapp-vite. Progettato per scenari in cui le funzionalità del codice sono cambiate ma sito web/docs/README/skills/guide AI/documenti in pacchetto potrebbero essere obsoleti, in particolare per quanto riguarda le pagine di configurazione di `weapp`, `dist/docs`, modelli `AGENTS.md`, installazione di competenze AI, `prepare`, MCP, `forwardConsole`, `screenshot/compare/ide logs`, runtime Web, modalità lib, multipiattaforma e routeRules/layout sincronizzazione degli ingressi.
