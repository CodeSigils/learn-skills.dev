A workflow for syncing documentation, website, and skills in weapp-vite monorepo repositories. Designed for scenarios where code capabilities have changed but website/docs/README/skills/AI guides/packaged docs may be outdated, especially covering `weapp` config pages, `dist/docs`, `AGENTS.md` templates, AI skills installation, `prepare`, MCP, `forwardConsole`, `screenshot/compare/ide logs`, Web runtime, lib mode, multi-platform and routeRules/layout entry synchronization.
