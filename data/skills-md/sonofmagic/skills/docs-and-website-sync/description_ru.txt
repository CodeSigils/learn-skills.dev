Рабочий процесс для синхронизации документации, веб-сайта и навыков в репозиториях монорепозиториев weapp-vite. Предназначен для сценариев, в которых возможности кода изменились, но веб-сайт/документы/README/навыки/руководства по искусственному интеллекту/упакованная документация могут быть устаревшими, особенно в отношении страниц конфигурации weapp, dist/docs, шаблонов AGENTS.md, установки навыков искусственного интеллекта, подготовки, MCP, forwardConsole, снимков экрана/сравнения/IDE журналов, среды выполнения Web, режима библиотеки, многоплатформенности и Синхронизация записей маршрута/макета.
