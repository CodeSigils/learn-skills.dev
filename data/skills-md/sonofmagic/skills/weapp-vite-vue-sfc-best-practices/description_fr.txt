Un manuel pratique pour Vue SFC dans les projets de mini-programmes basés sur weapp-vite, couvrant `<script setup lang="ts">`, les macros JSON, `definePageMeta`/layout, `defineModel`, `usingComponents`, la compatibilité des directives de modèle, les fichiers de support de type `.weapp-vite`, le flux de travail géré `prepare` et les conventions SFC actuelles alignées sur l'échafaudage. `AGENTS.md` et local `dist/docs`.
