Überprüft LLM-Antworten auf Fakten, indem er überprüfbare Behauptungen extrahiert, jede einzelne über eine Websuche überprüft, einen Prüfungsbericht mit Urteilen erstellt und optional ungenaue Antworten überarbeitet. Verwenden Sie diese Option, wenn der Benutzer eine Prüfung, Faktenprüfung, Doppelprüfung oder Verifizierung einer Antwort anfordert.
