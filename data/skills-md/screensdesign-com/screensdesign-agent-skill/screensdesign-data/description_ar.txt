ابحث عن تطبيقات الهاتف المحمول، والمنافسين، والإعداد، ونظام حظر الاشتراك غير المدفوع، والشاشات المسجلة، وتدفقات المستخدم، وتصميمات متجر التطبيقات، والمطورين، والمجموعات المحفوظة من خلال ScreensDesign MCP. يُستخدم عندما يطلب المستخدم إجراء بحث عن منتجات الأجهزة المحمولة، أو مراجع واجهة المستخدم، أو مقارنات التطبيقات، أو أدلة الإيرادات/التنزيل، أو التشابه المرئي، أو تحليل التسلسل، أو إعداد ScreensDesign MCP وتحديثات المهارات.
