Непрерывная обработка комментариев по PR-обзорам GitHub Copilot. Используйте, когда пользователь просит прочитать обзор Copilot по запросу на включение, решить, с какими комментариями следует действовать, внедрить соответствующие исправления, отправить последующие коммиты, ответить на каждую ветку проверки либо с исправлением, либо с обоснованием отсутствия изменения кода, а также разрешить потоки, которые полностью рассмотрены.
