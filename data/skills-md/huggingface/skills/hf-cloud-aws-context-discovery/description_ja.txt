AWS タスクの開始時に、ユーザーのローカル AWS コンテキスト (アクティブなプロファイル、リージョン、アカウント ID、発信者 ID) を検出します。このスキルは、SageMaker へのデプロイ、リソースの作成、AWS API の呼び出し、または AWS アカウントに関わるあらゆる作業など、他の AWS 作業の前に使用してください。特に、ユーザーがリージョンやプロファイルを明示的に指定していない場合、「AWS アカウントを使用する」、「AWS にデプロイする」、「私のプロファイルを使用する」などと言っている場合、または AWS CLI または SDK 呼び出しを行おうとしている場合に使用します。リージョンまたはアカウント ID を決して推測しないでください。必ずこのスキルを使用して、最初にローカル構成から読み取ります。
