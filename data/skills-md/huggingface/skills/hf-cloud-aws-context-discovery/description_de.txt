Entdecken Sie den lokalen AWS-Kontext des Benutzers (aktives Profil, Region, Konto-ID, Anruferidentität) zu Beginn einer beliebigen AWS-Aufgabe. Nutzen Sie diese Fertigkeit vor allen anderen AWS-Arbeiten – der Bereitstellung in SageMaker, der Erstellung von Ressourcen, dem Aufruf von AWS-APIs oder allem, was ein AWS-Konto berührt. Verwenden Sie es insbesondere, wenn der Benutzer nicht explizit eine Region oder ein Profil angegeben hat, wenn er Dinge sagt wie „Mein AWS-Konto verwenden“, „Auf AWS bereitstellen“, „Mein Profil verwenden“ oder wenn er einen AWS CLI- oder SDK-Aufruf tätigen möchte. Erraten Sie niemals die Region oder die Konto-ID – verwenden Sie diese Fähigkeit immer, um sie zuerst aus der lokalen Konfiguration zu lesen.
