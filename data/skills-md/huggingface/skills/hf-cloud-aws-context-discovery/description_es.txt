Descubra el contexto local de AWS del usuario (perfil activo, región, ID de cuenta, identidad de la persona que llama) al inicio de cualquier tarea de AWS. Utilice esta habilidad antes de cualquier otro trabajo de AWS: implementar en SageMaker, crear recursos, llamar a las API de AWS o cualquier cosa que afecte a una cuenta de AWS. Úselo especialmente cuando el usuario no haya especificado una región o perfil explícitamente, cuando diga cosas como "usar mi cuenta de AWS", "implementar en AWS", "usar mi perfil" o cuando esté a punto de realizar cualquier llamada a AWS CLI o SDK. Nunca adivine la región o el ID de la cuenta; utilice siempre esta habilidad para leerlo primero desde la configuración local.
