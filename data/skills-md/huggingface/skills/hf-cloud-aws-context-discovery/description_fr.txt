Découvrez le contexte AWS local de l'utilisateur (profil actif, région, ID de compte, identité de l'appelant) au début de toute tâche AWS. Utilisez cette compétence avant tout autre travail AWS : déploiement sur SageMaker, création de ressources, appel d'API AWS ou tout ce qui touche un compte AWS. Utilisez-le en particulier lorsque l'utilisateur n'a pas spécifié explicitement de région ou de profil, lorsqu'il dit des choses comme « utiliser mon compte AWS », « déployer sur AWS », « utiliser mon profil » ou lorsqu'il est sur le point d'effectuer un appel AWS CLI ou SDK. Ne devinez jamais la région ou l’ID de compte – utilisez toujours cette compétence pour le lire d’abord à partir de la configuration locale.
