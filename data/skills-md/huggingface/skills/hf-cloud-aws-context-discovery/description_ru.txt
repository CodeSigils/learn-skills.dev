Узнайте локальный контекст AWS пользователя (активный профиль, регион, идентификатор учетной записи, идентификатор вызывающего абонента) в начале любой задачи AWS. Используйте этот навык перед любой другой работой с AWS — развертыванием в SageMaker, созданием ресурсов, вызовом API AWS или всем, что связано с учетной записью AWS. Используйте его, особенно если пользователь не указал явно регион или профиль, когда он говорит такие вещи, как «используйте мою учетную запись AWS», «развертывание на AWS», «используйте мой профиль» или когда собираетесь выполнить какой-либо вызов AWS CLI или SDK. Никогда не угадывайте регион или идентификатор учетной записи — всегда используйте этот навык, чтобы сначала прочитать его из локальной конфигурации.
