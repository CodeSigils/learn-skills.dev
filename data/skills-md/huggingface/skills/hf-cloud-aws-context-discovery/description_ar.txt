اكتشف سياق AWS المحلي للمستخدم (ملف التعريف النشط، المنطقة، معرف الحساب، هوية المتصل) في بداية أي مهمة AWS. استخدم هذه المهارة قبل أي عمل آخر على AWS — النشر في SageMaker، أو إنشاء الموارد، أو الاتصال بواجهات برمجة تطبيقات AWS، أو أي شيء يتعلق بحساب AWS. استخدمه بشكل خاص عندما لا يحدد المستخدم منطقة أو ملفًا شخصيًا بشكل صريح، عندما يقول أشياء مثل "استخدام حساب AWS الخاص بي"، أو "النشر إلى AWS"، أو "استخدام ملف التعريف الخاص بي"، أو عندما يكون على وشك إجراء أي استدعاء لـ AWS CLI أو SDK. لا تخمن أبدًا المنطقة أو معرف الحساب — استخدم دائمًا هذه المهارة لقراءتها من التكوين المحلي أولاً.
