Scopri il contesto AWS locale dell'utente (profilo attivo, regione, ID account, identità del chiamante) all'inizio di qualsiasi attività AWS. Utilizza questa competenza prima di qualsiasi altro lavoro su AWS: distribuzione a SageMaker, creazione di risorse, chiamata di API AWS o qualsiasi cosa che tocchi un account AWS. Usalo soprattutto quando l'utente non ha specificato esplicitamente una regione o un profilo, quando dice cose come "usa il mio account AWS", "distribuisci su AWS", "usa il mio profilo" o quando sta per effettuare una chiamata AWS CLI o SDK. Non indovinare mai la regione o l'ID dell'account: utilizza sempre questa capacità per leggerlo prima dalla configurazione locale.
