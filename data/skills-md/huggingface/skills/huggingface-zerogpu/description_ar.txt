عروض الذكاء الاصطناعي وحسابات وحدة معالجة الرسومات باستخدام Gradio Spaces وHugging Face Spaces ZeroGPU. يُستخدم عند كتابة أو مراجعة تعليمات برمجية تستخدم `@spaces.GPU`، أو تكوين `python_version` أو `requirements.txt` لمساحة ZeroGPU، أو التعامل مع قيود التعليمات البرمجية الخاصة بـ ZeroGPU - عزل العملية القائمة على الاختيار، ودلالات `gr.State` عبر حدود العامل، وعدم وجود `torch.compile` (استخدم AoTI بدلاً من ذلك)، وإنشاءات عجلة CUDA فقط (لا يوجد `nvcc` عند الإنشاء أو وقت التشغيل)، والتحجيم الكبير مقابل xlarge، والمدة الديناميكية القابلة للاستدعاء. تأكد من استخدام هذه المهارة عندما يذكر المستخدم ZeroGPU أو `@spaces.GPU` أو حزمة Python `spaces`، أو يحدث عند حدوث أخطاء برمجية خاصة بـ ZeroGPU مثل `PicklingError` عبر حدود العامل، أو ``مدة غير قانونية``، أو فشل إنشاء العجلة ``flash-attn`` - حتى عندما لا يطلب المستخدم صراحةً إرشادات ترميز ZeroGPU. قم بتشغيل "استيراد المسافات" أو "@spaces.GPU" في الكود.
