適切な Python バージョンと現在の boto3 を使用して、SageMaker / AWS の作業用に分離された Python 環境をセットアップします。 SageMaker のデプロイ、トレーニング ジョブ、または AWS オートメーションで Python コードが実行されるときは常に、このスキルを使用します。これには、「pip install」を実行しようとしているとき、「boto3」を起動しようとしているとき、virtualenv を作成またはアクティブ化するとき、またはユーザーが「環境のセットアップ」を要求するときが含まれます。システム Python は決して使用しないでください。また、Python に「pip install」しないでください。常に隔離してください。このスキルは、間違った Python バージョン、依存関係の競合、古い SDK など、最も一般的な障害モードを防ぎます。
