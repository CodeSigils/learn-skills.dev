Настройте изолированную среду Python для работы SageMaker/AWS с нужной версией Python и текущим файлом boto3. Используйте этот навык всякий раз, когда код Python будет выполняться для развертывания SageMaker, задания обучения или любой автоматизации AWS, в том числе перед запуском pip install, вызовом boto3, созданием или активацией virtualenv или когда пользователь просит «настроить среду». Никогда не используйте системный Python и никогда не используйте в нем команду pip install. Всегда изолируйтесь. Этот навык предотвращает наиболее распространенные виды сбоев: неправильную версию Python, конфликты зависимостей и устаревшие SDK.
