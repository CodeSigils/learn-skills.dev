Configurez un environnement Python isolé pour le travail SageMaker / AWS, avec la bonne version Python et le boto3 actuel. Utilisez cette compétence chaque fois que du code Python sera exécuté pour un déploiement SageMaker, une tâche de formation ou toute automatisation AWS — y compris lorsque vous êtes sur le point d'exécuter « pip install », lorsque vous êtes sur le point d'invoquer « boto3 », lors de la création ou de l'activation d'un environnement virtuel, ou lorsque l'utilisateur demande de « configurer l'environnement ». N'utilisez jamais le système Python et n'y installez jamais de pip. Isolez-vous toujours. Cette compétence évite les modes de défaillance les plus courants : mauvaise version de Python, conflits de dépendances et SDK obsolètes.
