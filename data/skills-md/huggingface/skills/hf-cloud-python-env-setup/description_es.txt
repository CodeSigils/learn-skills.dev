Configure un entorno Python aislado para el trabajo de SageMaker/AWS, con la versión correcta de Python y boto3 actual. Utilice esta habilidad siempre que se ejecute código Python para una implementación de SageMaker, un trabajo de capacitación o cualquier automatización de AWS, incluso cuando esté a punto de ejecutar "pip install", cuando esté a punto de invocar "boto3", cuando cree o active un entorno virtual o cuando el usuario solicite "configurar el entorno". Nunca use el sistema Python y nunca haga "pip install" en él. Aislar siempre. Esta habilidad previene los modos de falla más comunes: versión incorrecta de Python, conflictos de dependencia y SDK obsoletos.
