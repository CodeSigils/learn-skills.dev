Richten Sie eine isolierte Python-Umgebung für die Arbeit mit SageMaker/AWS ein, mit der richtigen Python-Version und aktuellem boto3. Verwenden Sie diesen Skill immer dann, wenn Python-Code für eine SageMaker-Bereitstellung, einen Schulungsauftrag oder eine AWS-Automatisierung ausgeführt wird – einschließlich der Ausführung von „pip install“, des Aufrufs von „boto3“, beim Erstellen oder Aktivieren einer virtuellen Umgebung oder wenn der Benutzer „die Umgebung einrichten“ möchte. Verwenden Sie niemals System-Python und führen Sie niemals eine „Pip-Installation“ darin durch. Immer isolieren. Diese Fähigkeit verhindert die häufigsten Fehlermodi: falsche Python-Version, Abhängigkeitskonflikte und veraltete SDKs.
