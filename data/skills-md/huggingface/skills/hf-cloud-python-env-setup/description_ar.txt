قم بإعداد بيئة Python معزولة لعمل SageMaker / AWS، باستخدام إصدار Python الصحيح وboto3 الحالي. استخدم هذه المهارة عندما يتم تنفيذ كود Python لنشر SageMaker، أو مهمة التدريب، أو أي أتمتة AWS - بما في ذلك عندما تكون على وشك تشغيل "pip install"، أو عندما تكون على وشك استدعاء "boto3"، أو عند إنشاء Virtualenv أو تنشيطه، أو عندما يطلب المستخدم "إعداد البيئة". لا تستخدم أبدًا نظام Python ولا تقم مطلقًا بتثبيت النقطة فيه. عزل دائما. تمنع هذه المهارة أوضاع الفشل الأكثر شيوعًا: إصدار Python الخاطئ، وتعارضات التبعية، وحزم SDK التي لا معنى لها.
