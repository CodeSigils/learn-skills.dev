Configura un ambiente Python isolato per il lavoro di SageMaker/AWS, con la versione Python corretta e l'attuale boto3. Utilizza questa competenza ogni volta che verrà eseguito codice Python per una distribuzione SageMaker, un lavoro di formazione o qualsiasi automazione AWS, incluso quando si sta per eseguire `pip install`, quando si sta per invocare `boto3`, quando si crea o si attiva un virtualenv o quando l'utente chiede di "configurare l'ambiente". Non usare mai il sistema Python e non usare mai `pip install` al suo interno. Isolarsi sempre. Questa competenza previene le modalità di errore più comuni: versione Python errata, conflitti di dipendenze e SDK non aggiornati.
