ユーザー提供の LoRA の Hugging Face Spaces に関する Gradio デモを構築して公開します。 Qwen-Image、Qwen-Image-Edit、LTX-Video、Wan、FLUX、SDXL、またはその他の拡散ベース モデルの LoRA を含む、LoRA のスペース、デモ、Gradio アプリ、またはプレイグラウンドの作成、生成、配布、または公開を誰かが要求するときに使用します。また、誰かが自分がトレーニングした LoRA またはハブでホストした LoRA について説明し、それを共有したい場合にもトリガーされます。適切なベース パイプラインと「ディフューザー」推論レシピの選択、LoRA のタスクと入力 (ユニオン/マルチタスク制御、編集、ビデオ、画像など) に合わせた UI の設計、モデル カードの推奨事項 (トリガー ワード、ステップ、ガイダンス、LoRA スケール、入力例) の尊重、デフォルトでプライベート スペースとして ZeroGPU ハードウェアに送信することについて説明します。
