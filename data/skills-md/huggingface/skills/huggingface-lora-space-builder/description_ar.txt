قم ببناء ونشر عرض توضيحي لـ Gradio على Hugging Face Spaces لـ LoRA المقدمة من المستخدم. يُستخدم عندما يطلب شخص ما إنشاء أو إنشاء أو شحن أو نشر مساحة أو عرض توضيحي أو تطبيق Gradio أو ساحة لعب لـ LoRA - بما في ذلك LoRAs لـ Qwen-Image، أو Qwen-Image-Edit، أو LTX-Video، أو Wan، أو FLUX، أو SDXL، أو نماذج قاعدة النشر الأخرى. يتم تشغيله أيضًا عندما يصف شخص ما LoRA الذي قام بتدريبه أو استضافته على المركز ويريد مشاركته. يغطي اختيار المسار الأساسي الصحيح ووصفة الاستدلال "الناشرين"، وتصميم واجهة مستخدم مصممة خصيصًا لمهمة LoRA ومدخلاتها (التحكم في الاتحاد/المهام المتعددة، والتحرير، والفيديو، والصورة، وما إلى ذلك)، واحترام توصيات بطاقة النموذج (كلمات التشغيل، والخطوات، والإرشادات، ومقياس LoRA، ومدخلات الأمثلة)، والشحن إلى أجهزة ZeroGPU كمساحة خاصة بشكل افتراضي.
