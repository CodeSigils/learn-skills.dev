Planen und koordinieren Sie die Bereitstellung eines Modells für Amazon SageMaker AI. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein Modell auf SageMaker oder AWS bereitstellen, hosten, bereitstellen oder verfügbar machen möchte – einschließlich Formulierungen wie „ein Modell bereitstellen“, „dieses LLM auf AWS hosten“, „dieses Einbettungsmodell bereitstellen“, „einen Reranker bereitstellen“, „ein Text-zu-Bild-/Diffusionsmodell bereitstellen“, „dies für asynchrone Inferenz hosten“, „einen Endpunkt erstellen“, „mein fein abgestimmtes Modell bereitstellen“ oder jede Anfrage, bei der es darum geht, ein Modell für die Inferenz verfügbar zu machen auf AWS. Verwenden Sie dies auch, wenn der Benutzer unklar ist (z. B. „Ich möchte das nur auf AWS zum Laufen bringen, Sie finden es heraus“). Funktioniert für LLMs zur Textgenerierung, Einbettungsmodelle, Reranker, Klassifizierer, Text-zu-Bild-/Diffusionsmodelle – wählt den richtigen Serving-Stack aus und wählt zwischen Echtzeit- und asynchroner Inferenz. Dies ist die Einstiegskompetenz für die SageMaker-Bereitstellungsarbeit – sie stellt klärende Fragen, wählt einen Bereitstellungspfad aus und koordiniert die anderen Bereitstellungsfähigkeiten.
