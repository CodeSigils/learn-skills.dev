Amazon SageMaker AI へのモデルのデプロイを計画および調整します。ユーザーが SageMaker または AWS でモデルをデプロイ、ホスト、提供、公開したい場合は常にこのスキルを使用します。これには、「モデルをデプロイする」、「AWS でこの LLM をホストする」、「この埋め込みモデルを提供する」、「リランカーをデプロイする」、「テキストから画像へのモデル / 拡散モデルをデプロイする」、「非同期推論用にこれをホストする」、「エンドポイントを作成する」、「微調整されたモデルを提供する」、またはモデルの作成を伴うリクエストなどのフレーズが含まれます。 AWS で推論が可能です。ユーザーが曖昧な場合でもこれを使用します (例: 「これを AWS で実行したいだけですが、それはわかりますね」)。テキスト生成 LLM、埋め込みモデル、リランカー、分類器、テキストから画像への変換 / 拡散モデルで機能します。適切なサービス スタックを選択し、リアルタイム推論と非同期推論のどちらかを選択します。これは、SageMaker のデプロイメント作業のエントリポイント スキルです。明確な質問をし、デプロイメント パスを選択し、他のデプロイメント スキルを調整します。
