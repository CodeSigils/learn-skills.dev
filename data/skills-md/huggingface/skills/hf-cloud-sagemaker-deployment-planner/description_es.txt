Planificar y coordinar la implementación de un modelo en Amazon SageMaker AI. Utilice esta habilidad siempre que el usuario quiera implementar, alojar, servir o exponer un modelo en SageMaker o AWS, incluidas frases como "implementar un modelo", "hospedar este LLM en AWS", "servir este modelo de incorporación", "implementar un reordenador", "implementar un modelo de difusión/texto a imagen", "hospedar esto para inferencia asincrónica", "crear un punto final", "servir mi modelo ajustado" o cualquier solicitud que implique hacer que un modelo esté disponible para inferencia en AWS. Utilice esto incluso cuando el usuario sea vago (por ejemplo, "Solo quiero que esto se ejecute en AWS, usted lo resolverá"). Funciona para LLM de generación de texto, modelos de incrustación, reordenadores, clasificadores, modelos de difusión/texto a imagen: elige la pila de publicación adecuada y elige entre inferencia asincrónica y en tiempo real. Esta es la habilidad de punto de entrada para el trabajo de implementación de SageMaker: hace preguntas aclaratorias, elige una ruta de implementación y coordina las otras habilidades de implementación.
