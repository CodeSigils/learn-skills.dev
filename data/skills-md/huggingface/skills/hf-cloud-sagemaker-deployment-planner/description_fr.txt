Planifier et coordonner le déploiement d'un modèle sur Amazon SageMaker AI. Utilisez cette compétence chaque fois que l'utilisateur souhaite déployer, héberger, servir ou exposer un modèle sur SageMaker ou AWS, y compris des expressions telles que « déployer un modèle », « héberger ce LLM sur AWS », « servir ce modèle d'intégration », « déployer un reranker », « déployer un modèle texte-image/diffusion », « héberger ceci pour une inférence asynchrone », « créer un point de terminaison », « servir mon modèle affiné » ou toute demande impliquant de rendre un modèle disponible pour inférence sur AWS. Utilisez-le même lorsque l'utilisateur est vague (par exemple, "Je veux juste que cela fonctionne sur AWS, vous comprenez"). Fonctionne pour les LLM de génération de texte, les modèles d'intégration, les reclasseurs, les classificateurs, les modèles texte-image/diffusion - sélectionne la bonne pile de diffusion et choisit entre l'inférence en temps réel et asynchrone. Il s'agit de la compétence de point d'entrée pour le travail de déploiement de SageMaker : elle pose des questions de clarification, choisit une voie de déploiement et coordonne les autres compétences de déploiement.
