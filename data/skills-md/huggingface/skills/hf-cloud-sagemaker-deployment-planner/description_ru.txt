Планируйте и координируйте развертывание модели в Amazon SageMaker AI. Используйте этот навык всякий раз, когда пользователь хочет развернуть, разместить, обслужить или предоставить модель на SageMaker или AWS, включая такие фразы, как «развернуть модель», «разместить этот LLM на AWS», «обслуживать эту модель внедрения», «развернуть средство изменения ранжирования», «развернуть модель преобразования текста в изображение/распространения», «разместить это для асинхронного вывода», «создать конечную точку», «обслуживать мою точно настроенную модель» или любой запрос, который предполагает предоставление модели для вывода. на АВС. Используйте это, даже если пользователь не совсем уверен (например, «Я просто хочу, чтобы это работало на AWS, вы сами поймете»). Работает для LLM генерации текста, моделей внедрения, реранкинга, классификаторов, моделей преобразования текста в изображение/диффузии — выбирает правильный стек обслуживания и выбирает между выводом в реальном времени и асинхронным выводом. Это начальный навык для работы по развертыванию SageMaker — он задает уточняющие вопросы, выбирает путь развертывания и координирует другие навыки развертывания.
