Assurez-vous qu’un rôle d’exécution SageMaker utilisable existe avant le déploiement ou la formation. Utilisez cette compétence chaque fois que vous êtes sur le point de créer un point de terminaison, un modèle, une tâche de formation ou toute ressource SageMaker nécessitant un rôle d'exécution. Utilisez-le notamment lorsque l'utilisateur n'a pas fourni explicitement d'ARN de rôle, lorsque des scripts sont sur le point d'appeler `iam:CreateRole`, ou lorsqu'une erreur AccessDenied mentionne une action IAM. N'appelez jamais aveuglément « iam:CreateRole » — vérifiez toujours d'abord les rôles existants. Cette compétence évite l'échec de déploiement SageMaker le plus courant : tenter de créer des ressources IAM à partir d'un principal SSO qui ne dispose d'aucune autorisation d'écriture IAM.
