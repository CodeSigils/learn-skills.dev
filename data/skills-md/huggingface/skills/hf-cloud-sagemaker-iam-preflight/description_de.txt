Stellen Sie vor der Bereitstellung oder Schulung sicher, dass eine verwendbare SageMaker-Ausführungsrolle vorhanden ist. Verwenden Sie diese Fähigkeit immer dann, wenn Sie einen SageMaker-Endpunkt, ein Modell, einen Trainingsjob oder eine andere Ressource erstellen möchten, die eine Ausführungsrolle erfordert. Verwenden Sie es insbesondere, wenn der Benutzer keinen Rollen-ARN explizit angegeben hat, wenn Skripte „iam:CreateRole“ aufrufen möchten oder wenn ein AccessDenied-Fehler eine IAM-Aktion erwähnt. Rufen Sie niemals blind „iam:CreateRole“ auf – prüfen Sie immer zuerst, ob Rollen vorhanden sind. Diese Fähigkeit verhindert den häufigsten SageMaker-Bereitstellungsfehler: den Versuch, IAM-Ressourcen von einem SSO-Prinzipal zu erstellen, der keine IAM-Schreibberechtigungen hat.
