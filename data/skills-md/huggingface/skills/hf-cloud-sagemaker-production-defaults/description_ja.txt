自動スケーリング、CloudWatch アラーム、およびタグ付けがデフォルトで有効になっている SageMaker エンドポイント (リアルタイムまたは非同期) を作成します。 SageMaker エンドポイントを作成する場合、「create_endpoint」を呼び出すデプロイメント コードを作成する場合、またはイメージ URI と IAM ロールがわかった後にデプロイメントを完了する場合には、常にこのスキルを使用します。リアルタイム エンドポイント用のdeploy.pyと、非同期エンドポイント用のdeploy_async.pyを提供します(本物のスケール・トゥ・ゼロのサポート付き)。これは、SageMaker 導入ワークフローの最後のステップです。これらのデフォルトを使用せずに、裸の `create_endpoint` 呼び出しを生成しないでください。自動スケーリングやアラームのないエンドポイントは、デプロイメントではなくデモです。
