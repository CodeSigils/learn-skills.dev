SageMaker 모델 배포에 적합한 제공 컨테이너를 선택하고 현재 이미지 URI를 찾으세요. 사용자가 "이 LLM 배포", "이 HuggingFace 모델 호스팅", "이 미세 조정 모델 제공", "이 임베딩 모델 배포", "재순위 지정자 호스팅", "문장 변환기 모델 제공"이라고 말할 때를 포함하여 SageMaker 엔드포인트에 모델을 배포하려고 하고 이미지 URI를 선택해야 할 때마다 이 기술을 사용하거나 배포 코드에서 컨테이너 URI를 하드코딩하려고 할 때를 포함합니다. HuggingFace가 선별한 딥 러닝 컨테이너는 항상 선호됩니다: HuggingFace vLLM(LLM 및 생성적 reranker), HuggingFace vLLM-Omni(다중 모드), TEI(임베딩/교차 인코더 reranker), HF Inference Toolkit(기타 변환기). 일반 이미지(AWS vLLM, DJL-LMI, SGLang)는 HuggingFace 이미지가 호환되지 않는 경우에만 사용되며, 단순히 최신 버전이 있기 때문에 사용되는 것은 아닙니다. 메모리에서 컨테이너 URI를 하드코딩하지 말고 기본적으로 TGI를 사용하지 마세요. 오래된 이미지 오류 및 잘못된 지역 URI를 방지합니다.
