Elija el contenedor de servicio adecuado para la implementación de un modelo de SageMaker y busque su URI de imagen actual. Utilice esta habilidad siempre que esté a punto de implementar un modelo en un punto final de SageMaker y sea necesario elegir un URI de imagen, incluso cuando el usuario diga "implementar este LLM", "hospedar este modelo de HuggingFace", "ofrecer este modelo ajustado", "implementar este modelo de incrustación", "hospedar un reclasificador", "servir un modelo de transformadores de oraciones" o cuando esté a punto de codificar cualquier URI de contenedor en el código de implementación. SIEMPRE se prefieren los contenedores de aprendizaje profundo seleccionados por HuggingFace: HuggingFace vLLM (LLM y reordenadores generativos), HuggingFace vLLM-Omni (multimodal), TEI (incrustaciones/reordenadores de codificadores cruzados), HF Inference Toolkit (otros transformadores). Las imágenes genéricas (AWS vLLM, DJL-LMI, SGLang) se utilizan solo cuando ninguna imagen de HuggingFace es compatible, nunca simplemente porque llevan una versión más nueva. Nunca codifique un URI de contenedor desde la memoria y nunca establezca de forma predeterminada TGI. Previene errores de imágenes obsoletas y URI de regiones incorrectas.
