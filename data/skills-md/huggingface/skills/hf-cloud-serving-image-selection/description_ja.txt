SageMaker モデルのデプロイメントに適切なサービス提供コンテナーを選択し、その現在のイメージ URI を見つけます。 SageMaker エンドポイントにモデルをデプロイしようとしており、イメージ URI を選択する必要がある場合は常に、このスキルを使用します。これには、ユーザーが「この LLM をデプロイする」、「この HuggingFace モデルをホストする」、「この微調整されたモデルを提供する」、「この埋め込みモデルをデプロイする」、「リランカーをホストする」、「文変換モデルを提供する」と指示する場合、またはデプロイメント コードでコンテナ URI をハードコーディングしようとする場合が含まれます。 HuggingFace が厳選した深層学習コンテナーが常に推奨されます: HuggingFace vLLM (LLM および生成リランカー)、HuggingFace vLLM-Omni (マルチモーダル)、TEI (埋め込み/クロスエンコーダー リランカー)、HF Inference Toolkit (その他のトランスフォーマー)。汎用イメージ (AWS vLLM、DJL-LMI、SGLang) は、HuggingFace イメージに互換性がない場合にのみ使用されます。単に新しいバージョンを搭載しているという理由だけではありません。コンテナ URI をメモリからハードコードしたり、デフォルトで TGI を使用したりしないでください。古いイメージの失敗や間違ったリージョン URI を防ぎます。
