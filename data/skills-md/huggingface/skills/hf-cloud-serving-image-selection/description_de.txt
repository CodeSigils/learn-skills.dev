Wählen Sie den richtigen Bereitstellungscontainer für eine SageMaker-Modellbereitstellung aus und ermitteln Sie den aktuellen Image-URI. Verwenden Sie diese Fähigkeit immer dann, wenn ein Modell auf einem SageMaker-Endpunkt bereitgestellt werden soll und ein Bild-URI ausgewählt werden muss – auch wenn der Benutzer sagt: „Diesen LLM bereitstellen“, „Dieses HuggingFace-Modell hosten“, „Dieses fein abgestimmte Modell bereitstellen“, „Dieses Einbettungsmodell bereitstellen“, „einen Reranker hosten“, „ein Satztransformator-Modell bereitstellen“ oder wenn er im Begriff ist, einen Container-URI im Bereitstellungscode fest zu codieren. Von HuggingFace kuratierte Deep-Learning-Container werden IMMER bevorzugt: HuggingFace vLLM (LLMs und generative Reranker), HuggingFace vLLM-Omni (multimodal), TEI (Einbettungen/Cross-Encoder-Reranker), HF Inference Toolkit (andere Transformer). Generische Images (AWS vLLM, DJL-LMI, SGLang) werden nur verwendet, wenn kein HuggingFace-Image kompatibel ist – niemals nur, weil sie eine neuere Version enthalten. Codieren Sie einen Container-URI niemals fest aus dem Speicher und verwenden Sie niemals standardmäßig TGI. Verhindert veraltete Image-Fehler und URIs mit falschen Regionen.
