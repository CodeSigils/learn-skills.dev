Получите любой URL-адрес и преобразуйте его в уценку с помощью CLI baoyu-fetch (Chrome CDP с адаптерами для конкретного сайта). Встроенные адаптеры для X/Twitter, стенограмм YouTube, тредов Hacker News и общих страниц через Defuddle. Обрабатывает вход в систему/CAPTCHA через режимы ожидания взаимодействия. Используйте, когда пользователь хочет сохранить веб-страницу как уценку.
