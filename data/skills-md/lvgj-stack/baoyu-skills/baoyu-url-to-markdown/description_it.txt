Recupera qualsiasi URL e convertilo in markdown utilizzando la CLI baoyu-fetch (CDP di Chrome con adattatori specifici del sito). Adattatori integrati per X/Twitter, trascrizioni di YouTube, thread di Hacker News e pagine generiche tramite Defuddle. Gestisce l'accesso/CAPTCHA tramite le modalità di attesa dell'interazione. Utilizzare quando l'utente desidera salvare una pagina Web come markdown.
