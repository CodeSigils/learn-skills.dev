Адаптация проекта Vite + Vue 3 + Tailwind CSS 4 для устаревших браузеров (таких как QiAnXin Xinchang Browser, более старые версии Chrome/Edge и т. д.) путем понижения уровня синтаксиса JavaScript и совместимости с современными функциями CSS. Подходит для интерфейсных проектов, которым необходима поддержка государственных и корпоративных сред Xinchang, отечественных браузеров и старых браузеров на базе Chromium.
