Adaptación de un proyecto Vite + Vue 3 + Tailwind CSS 4 para navegadores heredados (como QiAnXin Xinchang Browser, versiones anteriores de Chrome/Edge, etc.) proporcionando reducción de nivel de sintaxis de JavaScript y compatibilidad con funciones modernas de CSS. Adecuado para proyectos front-end que necesitan admitir entornos Xinchang gubernamentales y empresariales, navegadores domésticos y navegadores antiguos basados ​​en Chromium.
