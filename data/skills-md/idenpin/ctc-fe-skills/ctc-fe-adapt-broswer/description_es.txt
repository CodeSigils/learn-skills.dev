Adapte los proyectos Vite + Vue 3 + Tailwind CSS 4 para navegadores heredados (navegador Qiankun Xinchuang, versión baja de Chrome/Edge, etc.), cubriendo la reducción de nivel de la sintaxis de JavaScript y la compatibilidad con las funciones modernas de CSS. Adecuado para proyectos frontend que necesitan ser compatibles con entornos Xinchuang de empresas gubernamentales, navegadores domésticos y navegadores basados ​​en Chromium de versión baja.
