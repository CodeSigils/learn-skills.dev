Anpassung eines Vite + Vue 3 + Tailwind CSS 4-Projekts für ältere Browser (wie QiAnXin Xinchang Browser, ältere Versionen von Chrome/Edge usw.) durch Bereitstellung von JavaScript-Syntax-Downleveling und CSS-Kompatibilität mit modernen Funktionen. Geeignet für Front-End-Projekte, die Xinchang-Umgebungen von Behörden und Unternehmen, inländische Browser und ältere Chromium-basierte Browser unterstützen müssen.
