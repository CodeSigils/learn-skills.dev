원격 PostgreSQL 데이터베이스(테스트/시험판 서버)를 로컬 PostgreSQL 인스턴스에 동기화합니다. pg_restore와 함께 사용자 정의 형식의 pg_dump를 사용하고 FORCE를 사용하여 데이터베이스를 삭제하고 template0/UTF8로 다시 빌드합니다. 사용자가 PostgreSQL 데이터베이스를 원격/테스트/스테이징 서버에서 로컬로 동기화/복사/새로 고침/미러링/풀링하도록 요청하거나 사용자가 "테스트 서버 데이터베이스를 로컬로 동기화/업데이트/풀링" 또는 "pg_dump/pg_restore 두 PostgreSQL 인스턴스 간에 데이터 복사"라고 말할 때 사용합니다.
