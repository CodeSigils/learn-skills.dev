Sincronizza un database PostgreSQL remoto (server di test/pre‑release) con un'istanza PostgreSQL locale. Utilizza pg_dump in formato personalizzato insieme a pg_restore, utilizzando FORCE per eliminare il database e ricostruirlo con template0/UTF8. Da utilizzare quando l'utente chiede di sincronizzare/copiare/aggiornare/mirrorare/estrarre un database PostgreSQL da un server remoto/di test/di gestione temporanea a quello locale o quando l'utente dice "sincronizza/aggiorna/estrai il database del server di test in locale" o "pg_dump/pg_restore copia i dati tra due istanze PostgreSQL".
