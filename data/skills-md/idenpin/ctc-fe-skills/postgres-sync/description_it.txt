Sincronizza il database PostgreSQL remoto (server di test/staging) con un'istanza PostgreSQL locale. Utilizza pg_dump in formato personalizzato + pg_restore, insieme a FORCE per eliminare il database e ricostruirlo con template0/UTF8. Da utilizzare quando l'utente chiede di sincronizzare/copiare/aggiornare/mirrorare/estrarre un database PostgreSQL da un server remoto/di prova/di staging a locale, oppure l'utente dice "sincronizza/aggiorna/estrae il database del server di test in locale" "pg_dump/pg_restore copia i dati tra due istanze PostgreSQL".
