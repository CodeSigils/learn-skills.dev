Synchronisez une base de données PostgreSQL distante (serveur de test/préversion) avec une instance PostgreSQL locale. Utilisez pg_dump dans un format personnalisé combiné avec pg_restore, avec FORCE pour supprimer la base de données et la reconstruire à l'aide de template0/UTF8. À utiliser lorsque l'utilisateur demande de synchroniser/copier/actualiser/miroir/extraire une base de données PostgreSQL d'un serveur distant/de test/de transfert vers le local, ou lorsque l'utilisateur dit « synchroniser/mettre à jour/extraire la base de données du serveur de test vers le local » ou « pg_dump / pg_restore copie les données entre deux instances PostgreSQL ».
