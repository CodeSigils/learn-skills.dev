Synchronisieren Sie die Remote-PostgreSQL-Datenbank (Test-/Vorabversionsserver) mit der lokalen PostgreSQL-Instanz. Verwenden Sie das benutzerdefinierte Format pg_dump + pg_restore zusammen mit FORCE Drop Database und Template0/UTF8-Neuerstellung. Verwenden Sie diese Option, wenn der Benutzer auffordert, eine PostgreSQL-Datenbank von einem Remote-/Test-/Staging-Server auf einen lokalen Server zu synchronisieren/kopieren/aktualisieren/spiegeln/zu ziehen, oder wenn der Benutzer sagt: „Testserverdatenbank synchronisieren/aktualisieren/auf lokal ziehen“ „pg_dump / pg_restore Daten zwischen zwei PostgreSQL-Instanzen kopieren“.
