Synchronisieren Sie eine Remote-PostgreSQL-Datenbank (Test-/Vorabversionsserver) mit einer lokalen PostgreSQL-Instanz. Verwenden Sie pg_dump im benutzerdefinierten Format zusammen mit pg_restore und verwenden Sie FORCE, um die Datenbank zu löschen und sie mit template0/UTF8 neu zu erstellen. Verwenden Sie diese Option, wenn der Benutzer eine PostgreSQL-Datenbank von einem Remote-/Test-/Staging-Server auf einen lokalen Server synchronisieren/kopieren/aktualisieren/spiegeln/ziehen möchte oder wenn der Benutzer „Testserver-Datenbank synchronisieren/aktualisieren/auf lokal ziehen“ oder „pg_dump/pg_restore Daten zwischen zwei PostgreSQL-Instanzen kopieren“ sagt.
