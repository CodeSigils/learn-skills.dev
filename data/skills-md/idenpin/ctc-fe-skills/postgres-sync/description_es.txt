Sincronice una base de datos PostgreSQL remota (servidor de prueba/prelanzamiento) con una instancia local de PostgreSQL. Utilice pg_dump en formato personalizado junto con pg_restore, empleando FORCE para descartar la base de datos y reconstruirla con template0/UTF8. Úselo cuando el usuario solicite sincronizar/copiar/actualizar/replicar/extraer una base de datos PostgreSQL de un servidor remoto/de prueba/ensayo al local, o cuando el usuario dice "sincronizar/actualizar/extraer la base de datos del servidor de prueba al local" o "pg_dump/pg_restore copiar datos entre dos instancias de PostgreSQL".
