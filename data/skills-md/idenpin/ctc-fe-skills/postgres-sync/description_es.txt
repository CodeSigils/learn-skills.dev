Sincronice la base de datos remota de PostgreSQL (servidor de prueba/prelanzamiento) con una instancia de PostgreSQL local. Utilice pg_dump en formato personalizado junto con pg_restore, combinado con la base de datos FORCE drop y reconstruya usando template0/UTF8. Úselo cuando el usuario solicite sincronizar/copiar/actualizar/replicar/extraer una base de datos PostgreSQL desde un servidor remoto/de prueba/ensayo a local, o cuando el usuario dice "sincronizar/actualizar/extraer la base de datos del servidor de prueba a local" o "pg_dump/pg_restore copiar datos entre dos instancias de PostgreSQL".
