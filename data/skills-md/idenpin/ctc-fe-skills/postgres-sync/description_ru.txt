Синхронизируйте удаленную базу данных PostgreSQL (тестовый/предварительный сервер) с локальным экземпляром PostgreSQL. Используйте pg_dump в собственном формате вместе с pg_restore, используя FORCE, чтобы удалить базу данных и перестроить ее с помощью template0/UTF8. Используйте, когда пользователь запрашивает синхронизацию/копирование/обновление/отражение/перенос базы данных PostgreSQL с удаленного/тестового/промежуточного сервера на локальный или когда пользователь говорит «синхронизировать/обновить/переместить базу данных тестового сервера на локальный» или «pg_dump/pg_restore копировать данные между двумя экземплярами PostgreSQL».
