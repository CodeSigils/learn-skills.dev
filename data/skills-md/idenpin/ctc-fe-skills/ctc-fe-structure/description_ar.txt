هيكل الدليل الأمامي الحديث ومعايير تطور الهندسة المعمارية. يجب استخدامه عند مناقشة أو إعادة بناء Vue، أو React، أو Vite، أو TypeScript، أو المكتب الخلفي الأوسط، أو أنظمة الأعمال، أو الدلائل الصديقة للذكاء الاصطناعي، أو FSD، أو تقسيم الميزات/التطبيقات/الخدمات المشتركة، أو طرق العرض/واجهة برمجة التطبيقات/المتجر/المكونات، أو إعادة هيكلة المشاريع القديمة تدريجيًا، أو تصميم أدلة داعمة للمشاريع الجديدة. ينطبق على تحديد المكان الذي يجب وضع الملف فيه، وكيفية تقسيم وحدات الأعمال، وكيفية تنظيم المسارات والمخازن، وكيفية جعل الدليل مناسبًا لكل من المطورين البشريين واسترجاع الذكاء الاصطناعي.
