Современный стиль написания Vue 3, TypeScript и CSS и спецификации кода. It standardizes the `<script setup>` declaration order, TypeScript strong typing boundaries, scoped styles, prevention of circular dependencies, and static toolchain (ESLint/Prettier) validation rules. Это применимо к ежедневной разработке, обзору архитектуры и ограничениям стиля при создании кода с помощью ИИ.
