パブリック API とバンドルされた CLI を介して、Boost Connect QuickBooks Desktop 統合を管理、診断、検証します。開発者がスキルのインストール、開発者 API キーによる認証、管理またはカスタム API キーのスコープとプロジェクト アクセスの選択、接続の作成または検査、ホストされたセットアップの生成、QuickBooks Web Connector の正常性の確認、サポートされている QBD データの読み取りまたは書き込み、Webhook の構成、認証またはコネクタの障害のトラブルシューティング、または統合がエンドツーエンドで機能することの証明を行う必要がある場合に使用します。
