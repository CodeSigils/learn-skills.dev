Gestisci, diagnostica e verifica le integrazioni Boost Connect QuickBooks Desktop tramite l'API pubblica e la CLI in bundle. Da utilizzare quando uno sviluppatore deve installare la competenza, autenticarsi con una chiave API sviluppatore, scegliere gli ambiti della chiave API amministratore o personalizzata e accedere al progetto, creare o ispezionare connessioni, generare configurazioni ospitate, verificare l'integrità del connettore Web QuickBooks, leggere o scrivere dati QBD supportati, configurare webhook, risolvere problemi di autenticazione o errori del connettore o dimostrare che un'integrazione funziona end-to-end.
