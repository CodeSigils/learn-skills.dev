ユーザーが白紙の状態から、既存のコース教材、またはその中間の状態から、インタラクティブな教育 Web サイト / コースのマイクロサイト / ワークショップのランディング ページを構築、計画、または進化させたいときは、このスキルをメインのエントリ ポイントとして使用します。 「做網準備站」、「做教學網頁」、「做工作坊網站」、「講義變網頁」、「コース マイクロサイト」、「ワークショップ サイト」、「インタラクティブ レッスン ページ」、「複数日カリキュラム Web サイト」、「做一套スケジュール」などの広範なフレーズでトリガーされます。このスキルは、教育サイトのパイプライン全体 (概要 → コンテンツ → SPA → インタラクション → ビジュアル → 企業/電子ブック) のルーターであり、必要に応じて 10 の専門的なサブスキルにディスパッチされます。ユーザーのリクエストが広範囲にわたる場合、またはユーザーがどのステージにいるのか不明瞭な場合は、これを優先します。サブスキル (例: 「course-ebook-publishing」) は、ステージ固有のリクエストに対して直接トリガー可能です。
