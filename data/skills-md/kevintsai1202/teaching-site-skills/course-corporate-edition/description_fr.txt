Utilisez cette compétence lorsqu'un site d'enseignement public de plusieurs jours existant doit être condensé et reconditionné pour une formation interne en entreprise - généralement une demi-journée ou une journée intensive (par exemple, cours public de 4 jours → entreprise de 6 heures). Se déclenche sur des expressions telles que "企業包班", "濃縮版", "客製化課程", "corporate edition", "inensive version", "in-house training", "客戶端課程", "壓縮成一天", ou lorsque l'utilisateur souhaite un livrable zippable dans un seul dossier pour un client. Cette compétence s'appuie sur un site existant : sélection d'unités, condensation de l'allocation de temps, intégration des données dans un seul code HTML, configuration de chaînes de secours d'actifs et production d'un package prêt à être utilisé hors ligne.
