Verwenden Sie diese Fähigkeit, wenn eine bestehende mehrtägige Unterrichtsseite für öffentliche Kurse für eine firmeninterne Schulung komprimiert und neu zusammengestellt werden muss – typischerweise eine halbtägige oder eintägige Intensivschulung (z. B. 4-tägiger öffentlicher Unterricht → 6-stündiges Firmentraining). Wird bei Phrasen wie „企業包班“, „濃縮版“, „客製化課程“, „Corporate Edition“, „Intensivversion“, „Inhouse-Schulung“, „客戶端課程“, „壓縮成一天“ ausgelöst oder wenn der Benutzer für einen Kunden eine in einem Ordner komprimierbare Lieferung wünscht. Diese Fähigkeit baut auf einer bestehenden Website auf – Einheiten auswählen, Zeitzuweisung verdichten, Daten in einen einzigen HTML-Code einbetten, Asset-Fallback-Ketten einrichten und ein Offline-fähiges Paket erstellen.
