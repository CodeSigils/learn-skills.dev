このスキルは、マークダウン形式で構造化されたコース コンテンツ (または章ベースのデータセット) があり、それをフレームワークを選択したりビルド手順を実行したりせずに、機能するインタラクティブな Web サイトに変換する必要がある場合に使用します。 "做成網頁"、"轉成 SPA"、"course-data.js"、"render 函式"、"ハンドル變網頁"、"static site from markdown"、"vanilla JS site" などのフレーズでトリガーされます。出力は、「npxserve」で開き、状態を localStorage に保持するバニラの HTML + JS シングルページ アプリです。常に「course-content-authoring」の後 (コンテンツが安定)、「static-spa-interactions」の前に呼び出してください (このスキルは足場を生成します。インタラクションは足場を飾ります)。
