Wenn ein Benutzer Produktbilder oder Produktinformationen hochlädt und ein kurzes Werbevideo auf Markenebene möchte, laden Sie die typische Formulierung: „Machen Sie einen TVC / eine Spot-Anzeige / ein Produkt-Werbevideo / einen Marken-Kurzfilm / ein neues Produkteinführungsvideo für mein Produkt / lassen Sie mein Produkt wie einen Werbespot einer großen Marke aussehen.“ Erstellen Sie einen 15–25 Sekunden langen Marken-Kurzfilm, der ausschließlich audiovisuelle Sprache verwendet: Präsentieren Sie zunächst sechs strategisch unterschiedliche kreative Konzepte, aus denen der Benutzer auswählen kann. Folgen Sie nach der Auswahl „Storyboard → Aufnahme für Aufnahme audiovisuelle Eingabeaufforderungen → segmentierte Generierung → Synthese“. Fälle, in denen es nicht geladen ist: Der Benutzer möchte einen KOL-Voice-Over/eine UGC-Empfehlung/eine Unboxing-Rezension/ein Verkaufsvideo (das sind Voice-Over-Formate, bei diesem Skill spricht keine Person mit der Kamera); Der Benutzer benötigt nur Poster, Grafiken und statische Assets (dieser Skill produziert nur Videos); Der Benutzer möchte ein Drama mit mehreren Episoden (diese Fähigkeit erstellt nur eine einzige Werbung).
