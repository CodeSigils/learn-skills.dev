Wenn ein Benutzer Produktbilder oder Produktinformationen hochlädt und einen Werbekurzfilm auf Markenebene wünscht – üblicherweise formuliert als „Erstellen Sie einen TVC für mein Produkt / drehen Sie einen Werbespot / Produkt-Werbevideo / Markenkurzfilm / Video zur Einführung eines neuen Produkts / lassen Sie mein Produkt wie eine High-End-Werbung aussehen“ – wird das System geladen. Es wird ein 15–25 Sekunden langer, rein audiovisueller Marken-Erzählkurzfilm produziert: Zunächst werden sechs strategisch unterschiedliche kreative Konzepte bereitgestellt, aus denen der Benutzer auswählen kann. Fahren Sie nach der Auswahl mit „Storyboard-Skript → audiovisueller Hinweis pro Aufnahme → Segmentgenerierung → Komposition“ fort. Situationen, in denen es nicht geladen wird: Der Benutzer möchte Influencer-Voice-Over / UGC-Empfehlung / Unboxing-Rezension / Verkaufsvideo (das sind Voice-Over-Formate, bei diesem Skill spricht keine Person in die Kamera); the user only needs posters, images, static assets (this skill only generates video); Der Benutzer möchte ein Drama mit mehreren Episoden (dieser Skill erstellt nur eine einzelne Anzeige).
