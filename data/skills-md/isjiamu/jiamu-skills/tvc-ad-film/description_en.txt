When a user uploads product images or product information and wants a brand‑level advertising short video, load—typical phrasing: “Make a TVC / a spot ad / a product promo video / a brand short film / a new product launch video for my product / make my product look like a big‑brand commercial.” Produce a 15–25‑second brand narrative short using only audiovisual language: first present six strategically distinct creative concepts for the user to choose from; after selection, follow “storyboard → shot‑by‑shot audiovisual prompts → segmented generation → synthesis.” Cases where it is not loaded: the user wants a KOL voice‑over / UGC recommendation / unboxing review / sales video (those are voice‑over formats, this skill has no person speaking to the camera); the user only needs posters, graphics, static assets (this skill only produces video); the user wants a multi‑episode drama (this skill only creates a single advertisement).
