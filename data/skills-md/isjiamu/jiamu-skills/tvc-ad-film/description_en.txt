When a user uploads product images or product information and wants a brand‑level advertising short video—commonly phrased as: “Make a TVC for my product / shoot an ad clip / product promo video / brand short film / new product launch video / make my product look like a high‑end commercial.” The output is a 15‑25‑second purely audiovisual brand narrative short: first provide six strategically distinct creative concepts for the user to choose from; once selected, proceed with “storyboard script → per‑shot audiovisual cue words → segmented generation → compositing.” Cases where it does not load: the user wants influencer voice‑over / UGC promotion / unboxing review / sales video (those are voice‑over formats, this skill has no on‑camera speaker); the user only needs posters, image‑text, static materials (this skill only produces video); the user wants a multi‑episode storyline (this skill only creates a single ad).
