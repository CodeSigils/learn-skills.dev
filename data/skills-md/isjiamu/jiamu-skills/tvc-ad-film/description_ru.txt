Когда пользователь загружает изображения продукта или информацию о продукте и хочет получить короткометражный рекламный видеоролик на уровне бренда, загрузите типичную фразу: «Сделайте ТВК / рекламный ролик / рекламный видеоролик продукта / короткометражный фильм о бренде / видеоролик о запуске нового продукта для моего продукта / сделайте мой продукт похожим на рекламу крупного бренда». Создайте короткометражный рассказ о бренде продолжительностью 15–25 секунд, используя только аудиовизуальный язык: сначала представьте шесть стратегически различных креативных концепций, из которых пользователь может выбрать; после выбора следуйте «раскадровка → покадровые аудиовизуальные подсказки → сегментированная генерация → синтез». Случаи, когда он не загружается: пользователю нужна закадровая речь KOL/рекомендация пользовательского контента/обзор распаковки/продающее видео (это форматы закадровой речи, для этого навыка никто не говорит в камеру); пользователю нужны только постеры, графика, статические ресурсы (этот навык производит только видео); пользователь хочет многосерийную драму (этот навык создает только одну рекламу).
