Когда пользователь загружает изображение продукта или информацию о продукте и хочет сделать короткую рекламу на уровне бренда, загружается навык — типичные запросы: «Сделать ТВК для моего продукта / снять рекламный ролик / промо-видео продукта / короткометражный фильм о бренде / видеоролик о запуске нового продукта / сделать мой продукт похожим на высококачественную рекламу». Он выводит короткометражное аудиовизуальное повествование о бренде продолжительностью 15–25 секунд: сначала предоставляет пользователю шесть стратегически различных креативных концепций на выбор; После выбора он переходит к следующему этапу: «раскадровка → покадровый аудиовизуальный сценарий → сегментированная генерация → синтез». Случаи, когда он не загружается: пользователю нужен закадровый голос влиятельного лица/рекомендация пользовательского контента/обзор распаковки/продающее видео (это форматы закадрового голоса; для этого навыка не используется человек, говорящий на камере); пользователю нужны только постеры, графика, статические ресурсы (этот навык производит только видео); пользователю нужна сюжетная линия, состоящая из нескольких эпизодов (этот навык позволяет создать только одну рекламу).
