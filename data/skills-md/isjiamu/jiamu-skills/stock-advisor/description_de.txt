Vollautomatische Pipeline für die Analyse von A-Aktien-Investitionen. Auslöseszenarien: (1) Der Benutzer lädt ein K-Liniendiagramm oder einen Screenshot eines Finanzberichts zur Analyse hoch; (2) Der Benutzer gibt einen A-Aktien-Aktiencode oder -Namen zur Analyse an (z. B. „Ping An Bank analysieren“, „Helfen Sie mir, 000001 anzusehen“, „Ist XX eine Investition wert?“); (3) Der Benutzer sagt „Aktienanalyse“, „Investmentanalyse“, „Aktienberater“ oder „Helfen Sie mir, Aktien zu analysieren“.
