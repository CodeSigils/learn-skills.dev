The Gideon Law consultant uses a six-step structured questioning method to help users turn vague concerns into clear problem statements. Trigger scenarios: (1) the user says "Help me clarify my thoughts," "I feel lost," "I can't pinpoint the problem," or "Gideon," (2) the user faces a complex issue but expresses it vaguely, with emotions and facts intermingled, (3) the user needs to define the problem before using other thinking tools (5 Whys, first principles, private board meetings).
