Die WeChat-Artikellayout-Engine für öffentliche Konten konvertiert Markdown in HTML, das direkt in den Editor für öffentliche Konten eingefügt werden kann. Themenstile werden aus einer benutzerdefinierten Themenbibliothek ausgewählt, die unter „references/theme-index.md“ registriert ist und über automatische Abschnittsnummerierung, Schlüsselwortunterstreichung, Zitatkarten, Inhaltsverzeichnisnavigation, Codeblöcke, Bilder/GIFs und Autorensignaturen verfügt. Es unterstützt die Eingabe in Markdown/Word (.docx)/PDF/einfachen Text (Nicht-Markdown wird zuerst automatisch normalisiert) und unterstützt auch das „automatische Layout mit einem Klick“ (automatische Strukturerkennung + Auswahl eines Themas). Darüber hinaus kann es eine benutzerdefinierte Designkomponentenbibliothek basierend auf Benutzerbeschreibungen oder Referenzbildern generieren und diese zur Wiederverwendung lokal speichern. Auslöseszenarien: (1) Der Benutzer erwähnt „öffentliches Kontolayout“, „öffentlicher Kontoartikel“, „WeChat-Layout“, „gzh“; (2) Der Benutzer möchte einen Artikel (md/docx/pdf/plain text) in HTML für ein öffentliches Konto konvertieren. (3) der Benutzer sagt „automatisches Layout“ oder „Ein-Klick-Layout“ für Inhalte für öffentliche Konten; (4) Der Benutzer möchte „ein neues Design/einen neuen Stil/eine Komponentenbibliothek basierend auf diesem Bild erstellen“ für das Layout für ein öffentliches Konto. Es ist nicht für die Generierung gewöhnlicher Webseiten/Landingpages/PPT gedacht (verwenden Sie Frontend- oder PPT-artige Fähigkeiten).
