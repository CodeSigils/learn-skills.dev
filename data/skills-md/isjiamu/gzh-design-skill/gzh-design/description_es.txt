Motor de diseño de artículos de cuentas públicas, que convierte Markdown en HTML que se puede pegar directamente en el editor de cuentas públicas de WeChat. Los estilos de tema se seleccionan de una biblioteca de temas personalizada registrada en references/theme-index.md, con numeración automática de capítulos, marcado de subrayado de palabras clave, tarjetas de citas, navegación por tabla de contenido, bloques de código, imágenes/GIF y firma del autor. Admite Markdown / Word (.docx) / PDF / entrada de texto sin formato (los que no son Markdown se normalizan primero automáticamente), también admite "diseño automático con un solo clic" (inferir estructura automáticamente + seleccionar tema) y puede generar una biblioteca de componentes de temas personalizados basada en la descripción del usuario/imágenes de referencia y guardarla localmente para su reutilización. Escenarios desencadenantes: (1) el usuario menciona "diseño de cuenta pública", "artículo de cuenta pública", "diseño de WeChat", "gzh"; (2) el usuario desea convertir un artículo (md/docx/pdf/texto sin formato) en HTML de cuenta pública; (3) el usuario dice "diseño automático" o "diseño con un clic" para el contenido de la cuenta pública; (4) el usuario desea “generar un nuevo tema/estilo personalizado/crear una biblioteca de componentes basada en esta imagen” para el diseño de la cuenta pública. No está diseñado para generar páginas web/páginas de destino/PPT ordinarias (use la habilidad front-end o tipo PPT).
