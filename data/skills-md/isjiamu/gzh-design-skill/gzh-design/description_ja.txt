WeChat パブリック アカウント記事レイアウト エンジンは、Markdown をパブリック アカウント エディターに直接貼り付けることができる HTML に変換します。テーマ スタイルは、「references/theme-index.md」に登録されているカスタム テーマ ライブラリから選択され、自動セクション番号付け、キーワードの下線、引用カード、目次ナビゲーション、コード ブロック、画像/GIF、および著者の署名が機能します。 Markdown / Word (.docx) / PDF / プレーンテキスト (Markdown 以外は最初に自動的に正規化されます) での入力をサポートし、「ワンクリック自動レイアウト」 (構造の自動検出 + テーマの選択) もサポートします。さらに、ユーザーの説明や参照画像に基づいてカスタム テーマ コンポーネント ライブラリを生成し、再利用できるようにローカルに保存できます。トリガーシナリオ: (1) ユーザーが「パブリック アカウント レイアウト」、「パブリック アカウントの記事」、「WeChat レイアウト」、「gzh」に言及します。 (2) ユーザーは記事 (md/docx/pdf/プレーン テキスト) をパブリック アカウント HTML に変換したいと考えています。 (3) ユーザーがパブリック アカウント コンテンツに対して「自動レイアウト」または「ワンクリック レイアウト」と発言した場合。 (4) ユーザーは、公開アカウントのレイアウト用に「この画像に基づいて新しいテーマ/カスタム スタイルを生成/コンポーネント ライブラリを作成」したいと考えています。通常の Web ページ/ランディング ページ/PPT (フロントエンドまたは PPT タイプのスキルを使用) を生成することを目的としたものではありません。
