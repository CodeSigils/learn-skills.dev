Markdown/Word(.docx)/PDF/일반 텍스트 입력 지원(Markdown이 아닌 경우 먼저 자동으로 정규화됨), "원클릭 자동 조판"(구조 자동 추론 + 테마 선택)도 지원하고, 추가로 사용자 설명/참조 이미지를 기반으로 사용자 정의 테마 구성 요소 라이브러리를 생성하고 재사용을 위해 로컬에 저장하는 것을 지원합니다. 트리거 시나리오: (1) 사용자가 "공개 계정 조판", "공개 계정 기사", "WeChat 조판", "gzh"를 언급합니다. (2) 사용자가 기사(md/docx/pdf/일반 텍스트)를 공개 계정 HTML로 변환하려고 합니다. (3) 사용자는 공개 계정 콘텐츠에 대해 "자동 조판" 또는 "원클릭 조판"이라고 말합니다.
