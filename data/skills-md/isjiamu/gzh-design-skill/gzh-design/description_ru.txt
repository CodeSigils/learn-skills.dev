Механизм макетирования статей общедоступной учетной записи WeChat, преобразующий Markdown в HTML, который можно напрямую вставить в редактор общедоступной учетной записи. Стили тем выбираются из пользовательской библиотеки тем, зарегистрированной в references/theme-index.md, с автоматической нумерацией глав, подчеркиванием ключевых слов, карточками цитат, навигацией по оглавлению, блоками кода, изображениями/GIF и подписями авторов. Поддерживает ввод Markdown/Word (.docx)/PDF/обычного текста (не-Markdown сначала автоматически нормализуется), также поддерживает «автоматическую разметку одним щелчком мыши» (автоматический вывод структуры + выбор темы) и поддерживает создание библиотеки компонентов пользовательской темы на основе пользовательского описания/эталонного изображения и сохранение ее локально для повторного использования. Триггерные сценарии: (1) пользователь упоминает «макет общедоступной учетной записи», «статью общедоступной учетной записи», «макет WeChat», «gzh»; (2) пользователь хочет преобразовать статью (md/docx/pdf/plain text) в общедоступный HTML-код; (3) пользователь произносит «автоматический макет» или «макет в один клик» для контента общедоступной учетной записи; (4) пользователь хочет «создать новую тему/собственный стиль/создать библиотеку компонентов на основе этого изображения» для макета общедоступной учетной записи. Не предназначен для создания обычных веб-страниц/целевых страниц/PPT (используйте навыки работы с интерфейсом или типа PPT).
