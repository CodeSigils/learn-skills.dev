The WeChat public account article layout engine converts Markdown into HTML that can be directly pasted into the public account editor. Theme styles are selected from a custom theme library registered in `references/theme-index.md`, featuring automatic section numbering, keyword underlining, quote cards, table of contents navigation, code blocks, images/GIFs, and author signatures. It supports input in Markdown / Word (.docx) / PDF / plain text (non‑Markdown is first automatically normalized), and also supports “one‑click automatic layout” (auto‑detecting structure + selecting a theme). Additionally, it can generate a custom theme component library based on user descriptions or reference images and save it locally for reuse. Trigger scenarios: (1) the user mentions “public account layout”, “public account article”, “WeChat layout”, “gzh”; (2) the user wants to convert an article (md/docx/pdf/plain text) into public‑account HTML; (3) the user says “automatic layout” or “one‑click layout” for public‑account content; (4) the user wants to “generate a new theme/custom style/create a component library based on this image” for public‑account layout. It is not intended for generating ordinary web pages/landing pages/PPT (use front‑end or PPT‑type skills).
