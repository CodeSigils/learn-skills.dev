Nutzen Sie diese Fähigkeit, wenn Sie einen neuen Kurs/Workshop/Trainingsprogramm beginnen und dessen Gliederung entwerfen müssen, bevor Vorlesungsinhalte geschrieben werden. Wird bei Phrasen wie „規劃課程“, „課程大綱“, „幾天怎麼排“, „學習目標“, „Workshop-Gliederung“, „Lehrplanentwurf“, „Kursgliederung“, „Lernziele“, „課程總覽“ ausgelöst oder wenn der Benutzer ein Thema und eine Zielgruppe, aber noch keine Struktur hat. Diese Fähigkeit erstellt das Grundgerüst (.md-Dateien), von dem alle nachgelagerten Phasen – Inhaltserstellung, SPA-Konvertierung, visuelle Assets – abhängen. Rufen Sie dies immer auf, BEVOR Sie mit dem Schreiben von Vorlesungsskripten oder dem Erstellen einer Website beginnen.
