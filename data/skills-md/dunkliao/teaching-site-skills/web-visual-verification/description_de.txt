Verwenden Sie diese Fähigkeit immer dann, wenn Sie überprüfen müssen, ob eine Web-Benutzeroberfläche tatsächlich so funktioniert, wie sie soll – indem Sie durch Abläufe klicken, den Status bestätigen, Konsolenfehler abfangen und Screenshots in mehreren Ansichtsfenstern zur visuellen Überprüfung erstellen.
