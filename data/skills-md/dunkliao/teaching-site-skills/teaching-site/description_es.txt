Utilice esta habilidad como punto de entrada principal siempre que el usuario desee crear, planificar o desarrollar un sitio web de enseñanza interactivo, un micrositio de curso o una página de inicio de taller, desde una pizarra en blanco, a partir de materiales de curso existentes o cualquier estado intermedio. Activadores de frases amplias como "做課程網站", "做教學網頁", "做工作坊網站", "把講義變網頁", "micrositio del curso", "sitio del taller", "página de lecciones interactivas", "sitio web del plan de estudios de varios días", "做一套課程". Esta habilidad es el enrutador para todo el proceso del sitio de enseñanza (esquema → contenido → SPA → interacciones → elementos visuales → corporativo/libro electrónico) y se envía a las 10 subhabilidades especializadas según sea necesario. Prefiera esto cuando la solicitud del usuario sea amplia o poco clara acerca de en qué etapa se encuentra: las subhabilidades (por ejemplo, "publicación de libros electrónicos de cursos") aún se pueden activar directamente para solicitudes específicas de la etapa.
