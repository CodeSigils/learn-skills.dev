Utilisez cette compétence comme point d'entrée principal chaque fois que l'utilisateur souhaite créer, planifier ou faire évoluer un site Web d'enseignement interactif/un microsite de cours/une page de destination d'atelier — à partir d'une page vierge, à partir de supports de cours existants ou de tout état intermédiaire. Déclencheurs sur des expressions larges telles que "做課程網站", "做教學網頁", "做工作坊網站", "把講義變網頁", "microsite de cours", "site d'atelier", "page de cours interactive", "site Web de programme sur plusieurs jours", "做一套課程". Cette compétence est le routeur de l'ensemble du pipeline du site d'enseignement (aperçu → contenu → SPA → interactions → visuels → entreprise/ebook) et répartie vers les 10 sous-compétences spécialisées selon les besoins. Préférez cela lorsque la demande de l'utilisateur est large ou peu claire quant à l'étape à laquelle il se trouve : les sous-compétences (par exemple, « édition de cours-ebook ») peuvent toujours être déclenchées directement pour les demandes spécifiques à l'étape.
