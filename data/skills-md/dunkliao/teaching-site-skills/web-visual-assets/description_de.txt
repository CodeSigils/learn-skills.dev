Verwenden Sie diese Fähigkeit, wenn auf einer Website mit vollständigem Inhalt fehlende Bilder/Platzhalterbilder fehlen und visuelle Elemente benötigt werden – Szenarioillustrationen, Werkzeug-Screenshots, Lehrerkarten, konzeptionelle Diagramme, Klassenraumpläne, QR-Codes. Löst auf Phrasen wie „插圖“, „工具截圖“, „QR“, „講師卡“, „地圖“, „示意圖“, „Playwright 爬蟲“, „AI 生圖“, „visuelle Assets“, „Screenshots“, „Illustrationen“, „QR-Codes“, „Lehrerkarten“ aus. Diese Fähigkeit deckt die vier Asset-Quellen (Scraping, KI-Generierung, handgezeichnetes SVG, generierte Codes), das PNG-First + SVG-Fallback-Rendermuster und Verifizierungsskripte ab. Wird normalerweise aufgerufen, NACHDEM Interaktionen verkabelt sind (damit fehlende Bilder sichtbar sind), kann aber auch früher aufgerufen werden, wenn Assets im Voraus geplant sind.
