Utilice esta habilidad cuando a un sitio web con contenido completo le falten imágenes o marcadores de posición y necesite recursos visuales: ilustraciones de escenarios, capturas de pantalla de herramientas, tarjetas de instructor, diagramas conceptuales, mapas de ubicación de aulas, códigos QR. Activadores de frases como "插圖", "工具截圖", "QR", "講師卡", "地圖", "示意圖", "Dramaturgo 爬蟲", "AI 生圖", "recursos visuales", "capturas de pantalla", "ilustraciones", "códigos QR", "tarjetas de instructor". Esta habilidad cubre las cuatro fuentes de activos (scraping, generación de IA, SVG dibujado a mano, códigos generados), el patrón de renderizado PNG primero + SVG alternativo y scripts de verificación. Por lo general, se invoca DESPUÉS de que se cablean las interacciones (para que las imágenes faltantes sean visibles), pero se puede invocar antes si los activos están planificados previamente.
