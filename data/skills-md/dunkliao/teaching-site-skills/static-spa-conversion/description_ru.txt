Используйте этот навык, когда у вас есть структурированный контент курса (или любой набор данных на основе глав) в форме уценки и вам нужно превратить его в работающий интерактивный веб-сайт — без выбора структуры и без этапа сборки. Запускается по таким фразам, как "做成網頁", "轉成 SPA", "course-data.js", "render 函式", "把講義變網頁", "статический сайт из уценки", "ванильный сайт JS", "сайт без фреймворка", "одностраничное приложение из уценки". На выходе получается стандартное одностраничное приложение HTML + JS, которое открывается с помощью npxserve и сохраняет состояние в localStorage. Всегда вызывайте ПОСЛЕ «авторства контента курса» (стабильный контент), ПЕРЕД «static-spa-interactions» (этот навык создает основу; взаимодействия украшают ее).
