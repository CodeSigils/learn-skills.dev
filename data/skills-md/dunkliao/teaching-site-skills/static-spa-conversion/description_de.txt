Nutzen Sie diese Fähigkeit, wenn Sie über strukturierte Kursinhalte (oder einen kapitelbasierten Datensatz) in Markdown-Form verfügen und diese in eine funktionierende interaktive Website umwandeln müssen – ohne ein Framework auszuwählen, ohne einen Erstellungsschritt. Löst auf Phrasen wie „做成網頁“, „轉成 SPA“, „course-data.js“, „render 函式“, „把講義變網頁“, „static site from markdown“, „vanilla JS site“, „no-framework site“, „single-page app from markdown“ aus. Die Ausgabe ist eine Vanilla-HTML + JS-Single-Page-App, die mit „npx server“ geöffnet wird und den Status im localStorage beibehält. Rufen Sie immer NACH „Course-Content-Authoring“ (Content Stable) und VOR „Static-Spa-Interactions“ auf (dieser Skill erzeugt das Gerüst; Interaktionen schmücken es).
