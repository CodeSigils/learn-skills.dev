Utilisez cette compétence lorsque vous disposez d'un contenu de cours structuré (ou de tout ensemble de données basé sur des chapitres) sous forme de démarque et que vous devez le transformer en un site Web interactif fonctionnel, sans choisir de cadre, sans étape de construction. Se déclenche sur des expressions telles que "做成網頁", "轉成 SPA", "course-data.js", "render 函式", "把講義變網頁", "site statique à partir de markdown", "site Vanilla JS", "site sans framework", "application d'une seule page à partir de markdown". Le résultat est une application vanille HTML + JS monopage qui s'ouvre avec « npx serve » et conserve son état dans localStorage. Invoquez toujours APRÈS la « création de contenu de cours » (contenu stable), AVANT les « interactions statiques-spa » (cette compétence produit l'échafaudage ; les interactions l'ornent).
