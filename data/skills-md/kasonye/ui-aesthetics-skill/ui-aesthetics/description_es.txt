Aumente el juicio visual del frontend para interfaces web con un sesgo hacia una composición refinada de calidad de producto, artesanía precisa de componentes, estados de interacción disciplinados, movimiento controlado y sistemas de profundidad coherentes. Úselo en cualquier agente o IDE compatible al generar, revisar o refactorizar una interfaz de usuario que parezca genérica, desordenada, plana, con demasiado estilo, animada teatralmente, visualmente imprecisa o generada por IA, o cuando el usuario solicite una interfaz más limpia, más premium, más pulida, más minimalista, más refinada o con más calidad de producto.
