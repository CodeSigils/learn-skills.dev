Führen Sie einen abgestuften Spec-First-Workflow für wesentliche Funktionen durch, indem Sie entscheiden, ob Spezifikationen benötigt werden, zuerst PRODUCT.md schreiben, vor TECH.md auf die PRODUCT-Überprüfung warten, vor der Implementierung auf die TECH-Review warten und beide Spezifikationen auf dem neuesten Stand halten. Verwenden Sie diese Option, wenn Sie eine wichtige Funktion starten, eine agentengesteuerte Implementierung planen oder wenn der Benutzer geschützte Produkt- und technische Spezifikationen in die Quellcodeverwaltung einchecken möchte.
