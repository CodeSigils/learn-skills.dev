Costruisce un sistema di progettazione completo di livello produttivo in Figma utilizzando il server MCP Figma remoto. Crea stili di colore, stili di testo, stili di effetti, variabili numeriche e tutti i 14 componenti (fisarmonica, pulsante, callout, scheda, menu a discesa, casella di controllo, chip, input, schede, navigazione, pulsante di opzione, riquadro, descrizione comando, attiva/disattiva) con copertura completa di varianti/stati. Utilizzare quando l'utente chiede di creare, costruire o impostare un sistema di progettazione in Figma o menziona token, componenti o una libreria Figma.
