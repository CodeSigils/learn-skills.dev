Generiert ordnungsgemäß formatierte Git-Zweignamen gemäß den Projektkonventionen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen Zweig benennen oder einen Zweig erstellen möchte oder Dinge fragt wie „Wie soll ich diesen Zweig nennen?“, „Welchen Zweignamen soll ich verwenden?“, „Hilf mir beim Zweignamen“ oder eine Funktion/einen Fix beschreibt und einen Zweignamen benötigt. Verwenden Sie diesen Skill immer, wenn der Benutzer einen Git-Branch-Namen benötigt, auch wenn er nicht explizit „Branch“ sagt.
