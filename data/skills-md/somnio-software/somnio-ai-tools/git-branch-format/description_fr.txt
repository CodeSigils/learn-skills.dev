Génère des noms de branches Git correctement formatés conformément aux conventions du projet. Utilisez cette compétence chaque fois que l'utilisateur souhaite nommer une branche, créer une branche ou demande des choses comme « comment dois-je appeler cette branche ? », « quel nom de branche dois-je utiliser ? », « aidez-moi avec le nom de la branche », ou décrit une fonctionnalité/un correctif et a besoin d'un nom de branche. Utilisez toujours cette compétence lorsque l'utilisateur a besoin d'un nom de branche git, même s'il ne dit pas explicitement « branche ».
