Genera nomi di rami Git correttamente formattati seguendo le convenzioni del progetto. Utilizza questa abilità ogni volta che l'utente desidera nominare un ramo, creare un ramo o chiede cose come "come dovrei chiamare questo ramo?", "quale nome di ramo dovrei usare?", "aiutami con il nome del ramo" o descrive una funzionalità/correzione e necessita di un nome di ramo. Usa sempre questa abilità quando l'utente ha bisogno di un nome di ramo git, anche se non dice esplicitamente "ramo".
