Генерирует правильно отформатированные имена ветвей Git в соответствии с соглашениями проекта. Используйте этот навык всякий раз, когда пользователь хочет назвать ветку, создать ветку или спрашивает такие вещи, как «как мне назвать эту ветку?», «Какое имя ветки мне использовать?», «Помогите мне с именем ветки», или описывает функцию/исправление, и ему нужно имя ветки. Всегда используйте этот навык, когда пользователю нужно имя ветки git, даже если он явно не говорит «ветвь».
