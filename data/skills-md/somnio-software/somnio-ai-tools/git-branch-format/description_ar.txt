يُنشئ أسماء فروع Git منسقة بشكل صحيح وفقًا لاتفاقيات المشروع. استخدم هذه المهارة عندما يريد المستخدم تسمية فرع، أو إنشاء فرع، أو يسأل أشياء مثل "ماذا يجب أن أسمي هذا الفرع؟"، أو "ما اسم الفرع الذي يجب أن أستخدمه؟"، أو "ساعدني في اسم الفرع"، أو يصف ميزة/إصلاحًا ويحتاج إلى اسم فرع. استخدم هذه المهارة دائمًا عندما يحتاج المستخدم إلى اسم فرع git، حتى لو لم يذكر "فرع" صراحةً.
