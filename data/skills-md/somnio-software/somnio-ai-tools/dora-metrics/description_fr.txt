Récupère la fréquence de déploiement des métriques DORA et le délai de modification, par projet et par dépôt, à partir de GitHub (API, pas git local). Utilisez cette compétence chaque fois que l'utilisateur demande d'exécuter ou de mettre à jour les métriques DORA, de mesurer la fréquence de déploiement ou le délai d'exécution d'un projet (par exemple « Exemple de projet »), de générer le rapport de métriques bihebdomadaire, ou demande combien de déploiements un projet a effectué ou combien de temps une modification prend pour atteindre la production. Déclenchez également des expressions telles que : "exécuter les métriques DORA", "métriques pour un exemple de projet", "fréquence de déploiement pour [projet]", "délai pour [projet]", "rapport de métriques bihebdomadaire", "combien de déploiements avons-nous effectué ce sprint".
