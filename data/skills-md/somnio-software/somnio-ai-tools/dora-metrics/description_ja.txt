DORA メトリクスのデプロイ頻度と変更のリードタイムをプロジェクトごとおよびリポジトリごとに GitHub から取得します (ローカル git ではなく API)。ユーザーが DORA メトリクスの実行または更新、プロジェクト (「サンプル プロジェクト」など) のデプロイメント頻度またはリード タイムの測定、隔週メトリクス レポートの生成、またはプロジェクトのデプロイ数や変更が本番環境に到達するまでにかかる時間を尋ねる場合には、このスキルを使用します。また、「DORA メトリクスの実行」、「サンプル プロジェクトのメトリクス」、「[プロジェクト] のデプロイ頻度」、「[プロジェクト] のリード タイム」、「隔週メトリクス レポート」、「このスプリントを実行したデプロイの数」などのフレーズでもトリガーします。
