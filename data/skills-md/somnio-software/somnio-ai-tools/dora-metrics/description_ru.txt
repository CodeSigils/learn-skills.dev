Получает метрики DORA «Частота развертывания» и «Время выполнения изменений» для каждого проекта и каждого репозитория из GitHub (API, а не локального git). Используйте этот навык всякий раз, когда пользователь просит запустить или обновить метрики DORA, измерить частоту развертывания или время выполнения проекта (например, «Пример проекта»), создать отчет о показателях раз в две недели или спросить, сколько раз развернут проект или сколько времени требуется, чтобы изменение достигло рабочей среды. Также запускайте такие фразы, как: «запустите метрики DORA», «метрики для примера проекта», «частота развертывания для [проекта]», «время выполнения для [проекта]», «отчет по метрикам раз в две недели», «сколько развертываний мы сделали в этом спринте».
