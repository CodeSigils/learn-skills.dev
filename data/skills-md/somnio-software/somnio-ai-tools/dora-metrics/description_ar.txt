جلب تردد نشر مقاييس DORA ومدة التنفيذ للتغييرات، لكل مشروع ولكل ريبو، من GitHub (واجهة برمجة التطبيقات، وليس بوابة محلية). استخدم هذه المهارة عندما يطلب المستخدم تشغيل مقاييس DORA أو تحديثها، أو قياس تكرار النشر أو المهلة الزمنية للمشروع (على سبيل المثال "مشروع نموذجي")، أو إنشاء تقرير المقاييس نصف الأسبوعية، أو السؤال عن عدد عمليات نشر المشروع التي تم إجراؤها أو المدة التي يستغرقها التغيير للوصول إلى الإنتاج. قم أيضًا بتشغيل عبارات مثل: "تشغيل مقاييس DORA"، "مقاييس لمشروع مثال"، "تكرار النشر لـ [مشروع]"، "مهلة [مشروع]"، "تقرير المقاييس كل أسبوعين"، "كم عدد عمليات النشر التي قمنا بها في هذا السباق السريع".
