Выполните аудит качества кода NestJS на микроуровне. Проверяет код на соответствие действующим стандартам GitHub для тестирования, архитектуры, проверки DTO, обработки ошибок и реализации кода. Составляет подробный отчет о нарушениях с приоритетным планом действий. Используйте, когда пользователь просит проверить качество кода NestJS, проверить лучшие практики или просмотреть стандарты внутреннего кода. Запускается по следующим критериям: «лучшие практики nestjs», «качество внутреннего кода», «проверка кода», «стандарты nestjs», «проверка dto», «проверка обработки ошибок».
