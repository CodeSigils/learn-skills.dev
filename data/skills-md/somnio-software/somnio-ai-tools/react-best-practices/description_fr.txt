Exécuter un audit de qualité du code React au niveau micro. Valide le code par rapport aux normes GitHub en direct pour les tests, l'architecture des composants, les modèles de hooks, la gestion des états, les performances et TypeScript. Produit un rapport détaillé des violations avec un plan d’action hiérarchisé. À utiliser lorsque l'utilisateur demande à vérifier la qualité du code React, à valider les meilleures pratiques ou à revoir les normes du code frontend. Déclencheurs sur : « meilleures pratiques de réaction », « qualité du code de réaction », « révision des composants », « révision des hooks », « normes de réaction », « qualité du code frontend ».
