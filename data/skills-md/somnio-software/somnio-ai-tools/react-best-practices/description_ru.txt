Выполните аудит качества кода React на микроуровне. Проверяет код на соответствие действующим стандартам GitHub для тестирования, архитектуры компонентов, шаблонов перехватов, управления состоянием, производительности и TypeScript. Составляет подробный отчет о нарушениях с приоритетным планом действий. Используйте, когда пользователь просит проверить качество кода React, проверить лучшие практики или просмотреть стандарты кода внешнего интерфейса. Запускается по следующим критериям: «лучшие практики реагирования», «качество кода реагирования», «проверка компонентов», «проверка крючков», «стандарты реагирования», «качество кода внешнего интерфейса».
