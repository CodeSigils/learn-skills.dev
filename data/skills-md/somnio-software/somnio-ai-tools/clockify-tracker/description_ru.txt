Управляет отслеживанием времени Clockify через официальный API REST Clockify (v1): выводит список рабочих пространств и проектов, создает записи времени с правильными временными метками UTC. Используйте, когда пользователь хочет регистрировать время, отслеживать часы, записывать работу в Clockify или упоминает Clockify или записи времени.
