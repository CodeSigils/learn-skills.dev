Verwaltet die Zeiterfassung von Clockify über die offizielle Clockify REST API (v1): Listen Sie Arbeitsbereiche und Projekte auf und erstellen Sie Zeiteinträge mit korrekten UTC-Zeitstempeln. Verwenden Sie diese Option, wenn der Benutzer Zeit protokollieren, Stunden verfolgen, Arbeit in Clockify aufzeichnen oder Clockify oder Zeiteinträge erwähnen möchte.
