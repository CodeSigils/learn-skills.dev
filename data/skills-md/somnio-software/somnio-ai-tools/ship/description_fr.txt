Expédier le workflow : fusionner la branche de base, exécuter des tests, réviser les différences, modifier la VERSION, mettre à jour le CHANGELOG, valider, pousser, créer un PR. À utiliser lorsqu'on vous demande de « expédier », « déployer », « pousser vers le principal », « créer un PR », « fusionner et pousser » ou « le déployer ». Invoquez cette compétence de manière proactive lorsque l'utilisateur indique que le code est prêt, pose des questions sur le déploiement, souhaite pousser le code vers le haut ou demande de créer un PR.
