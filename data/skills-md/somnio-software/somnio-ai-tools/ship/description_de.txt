Versand-Workflow: Basiszweig zusammenführen, Tests ausführen, Diff überprüfen, VERSION erhöhen, CHANGELOG aktualisieren, festschreiben, pushen, PR erstellen. Wird verwendet, wenn Sie zum „Versenden“, „Bereitstellen“, „Push to Main“, „Erstellen einer PR“, „Zusammenführen und Pushen“ oder „Bereitstellen“ aufgefordert werden. Rufen Sie diese Fähigkeit proaktiv auf, wenn der Benutzer sagt, dass der Code bereit ist, nach der Bereitstellung fragt, den Code vorantreiben möchte oder die Erstellung einer PR wünscht.
