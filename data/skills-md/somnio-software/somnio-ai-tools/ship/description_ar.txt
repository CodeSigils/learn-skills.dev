سير عمل السفينة: دمج الفرع الأساسي، وإجراء الاختبارات، ومراجعة الفرق، وإصدار النسخة، وتحديث سجل التغيير، والالتزام، والدفع، وإنشاء العلاقات العامة. استخدمه عندما يُطلب منك "الشحن" أو "النشر" أو "الدفع إلى الصفحة الرئيسية" أو "إنشاء علاقات عامة" أو "الدمج والدفع" أو "النشر". قم باستدعاء هذه المهارة بشكل استباقي عندما يقول المستخدم أن الكود جاهز، أو يسأل عن النشر، أو يريد دفع الكود للأعلى، أو يطلب إنشاء علاقات عامة.
