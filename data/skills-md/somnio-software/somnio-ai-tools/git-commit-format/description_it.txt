Genera messaggi di commit Git correttamente formattati (titolo + descrizione) seguendo i commit convenzionali. Usa questa abilità ogni volta che l'utente desidera scrivere un messaggio di commit, documentare le modifiche al codice in formato git o chiedere cose come "come dovrei eseguire il commit?", "scrivere un commit per queste modifiche", "aiutami con il mio messaggio di commit" o descrive cosa è stato modificato e necessita di un output pronto per git. Utilizza sempre questa abilità quando l'utente descrive le modifiche al codice e necessita di un commit, anche se non dice esplicitamente "commit".
