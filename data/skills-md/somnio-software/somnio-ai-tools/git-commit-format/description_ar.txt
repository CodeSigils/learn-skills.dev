يُنشئ رسائل التزام Git منسقة بشكل صحيح (العنوان + الوصف) بعد الالتزامات التقليدية. استخدم هذه المهارة عندما يريد المستخدم كتابة رسالة التزام، أو تغيير رمز المستند بتنسيق git، أو يسأل أشياء مثل "كيف يجب أن أقوم بهذا؟"، أو "اكتب التزامًا بهذه التغييرات"، أو "ساعدني في رسالة الالتزام الخاصة بي"، أو يصف ما تم تغييره ويحتاج إلى مخرجات جاهزة لـ git. استخدم هذه المهارة دائمًا عندما يصف المستخدم تغييرات التعليمات البرمجية ويحتاج إلى الالتزام، حتى لو لم يقول "التزام" صراحةً.
