Generates properly formatted Git commit messages (title + description) following Conventional Commits. Utilice esta habilidad siempre que el usuario quiera escribir un mensaje de confirmación, documentar cambios de código en formato git o pregunte cosas como "¿cómo debo confirmar esto?", "escribir una confirmación para estos cambios", "ayúdame con mi mensaje de confirmación", o describe lo que cambiaron y necesita una salida lista para git. Utilice siempre esta habilidad cuando el usuario describa cambios en el código y necesite una confirmación, incluso si no dice explícitamente "comprometer".
