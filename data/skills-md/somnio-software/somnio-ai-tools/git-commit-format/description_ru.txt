Создает правильно отформатированные сообщения о фиксации Git (заголовок + описание) после обычных коммитов. Используйте этот навык всякий раз, когда пользователь хочет написать сообщение о фиксации, задокументировать изменения кода в формате git или спрашивает такие вещи, как «как мне это зафиксировать?», «написать фиксацию для этих изменений», «помогите мне с моим сообщением о фиксации», или описывает, что они изменили и нуждаются в готовом к git выводе. Всегда используйте этот навык, когда пользователь описывает изменения кода и требует фиксации, даже если он явно не говорит «фиксация».
