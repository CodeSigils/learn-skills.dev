Génère des messages de validation Git correctement formatés (titre + description) après les validations conventionnelles. Utilisez cette compétence chaque fois que l'utilisateur souhaite écrire un message de validation, documenter les modifications du code au format git ou demande des choses telles que « comment dois-je valider cela ? », « écrire une validation pour ces modifications », « aidez-moi avec mon message de validation », ou décrit ce qu'ils ont modifié et nécessite une sortie prête pour git. Utilisez toujours cette compétence lorsque l'utilisateur décrit des modifications de code et a besoin d'une validation, même s'il ne dit pas explicitement « valider ».
