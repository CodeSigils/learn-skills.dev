Erzeugt ordnungsgemäß formatierte Git-Commit-Nachrichten (Titel + Beschreibung) nach herkömmlichen Commits. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Commit-Nachricht schreiben, Codeänderungen im Git-Format dokumentieren möchte oder Dinge fragt wie „Wie soll ich das committen?“, „Schreibe ein Commit für diese Änderungen“, „Hilf mir bei meiner Commit-Nachricht“ oder beschreibt, was er geändert hat und eine Git-fähige Ausgabe benötigt. Verwenden Sie diese Fähigkeit immer, wenn der Benutzer Codeänderungen beschreibt und ein Commit benötigt, auch wenn er nicht ausdrücklich „Commit“ sagt.
