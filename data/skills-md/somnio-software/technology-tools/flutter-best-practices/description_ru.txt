Выполните аудит качества кода Flutter на микроуровне. Проверяет код на соответствие действующим стандартам GitHub для тестирования, архитектуры и реализации кода. Составляет подробный отчет о нарушениях с приоритетным планом действий. Используйте, когда пользователь просит проверить качество кода Flutter, проверить лучшие практики или проверить соответствие кода стандартам. Запускается по следующим критериям: «лучшие практики Flutter», «качество кода», «проверка кода», «стандарты Flutter», «соответствие архитектуры», «качество тестирования».
