Verwenden Sie diese Option, wenn der Benutzer ausdrücklich nach einem Git-Arbeitsbaum, einem isolierten Zweig-Arbeitsbereich, einem parallelen Checkout oder einem branchensicheren Implementierungsbereich für riskante oder unabhängige Arbeit fragt oder wenn der Koordinator diese Option vorschlagen sollte, weil die Isolation das Risiko oder den Konflikt im Arbeitsbaum für eine riskante oder wirklich unabhängige Änderung erheblich reduzieren würde.
