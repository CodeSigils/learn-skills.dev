Da utilizzare quando l'utente richiede esplicitamente un albero di lavoro git, un'area di lavoro del ramo isolato, un checkout parallelo o un'area di implementazione sicura per il ramo per un lavoro rischioso o indipendente, o quando il coordinatore dovrebbe suggerire tale opzione perché l'isolamento ridurrebbe materialmente il rischio o il conflitto dell'albero di lavoro per una modifica rischiosa o veramente indipendente.
