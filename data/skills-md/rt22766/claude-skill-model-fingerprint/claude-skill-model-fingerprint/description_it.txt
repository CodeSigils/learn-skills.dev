Utilizza l'analisi introspettiva, l'impronta digitale Reasoning_Effort, i test di rifiuto Magic String e gli stress test mirati per determinare se l'API corrente è un modello Claude autentico o se sono presenti conflitti di inoltro, wrapper o prompt. Da utilizzare quando si sospetta che il modello sia falso, abbia una fonte anomala, sia stato confezionato da terzi o quando è necessario un rapporto sull'autenticità del modello.
