Utilizza l'analisi introspettiva, il rilevamento delle impronte digitali Reasoning_effort, i test di rifiuto Magic String e gli stress test mirati per determinare se l'API corrente è il modello Claude autentico o se sono presenti conflitti di inoltro, incapsulamento o prompt. Utile quando si sospetta che il modello sia falso, abbia una fonte anomala, sia stato confezionato da terzi o quando è necessario produrre un rapporto di test di autenticità del modello.
