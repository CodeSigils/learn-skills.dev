Utilice análisis introspectivo, huellas dactilares de razonamiento_esfuerzo, pruebas de rechazo de Magic String y pruebas de estrés específicas para determinar si la API actual es el modelo Claude genuino o si hay conflictos de retransmisión, encapsulación o avisos. Útil cuando se sospecha que el modelo es falso, tiene una fuente anormal, está envuelto por un tercero o cuando necesita generar un informe de prueba de autenticidad del modelo.
