Utilice análisis introspectivo, huellas dactilares de razonamiento_esfuerzo, pruebas de rechazo de Magic String y pruebas de estrés específicas para determinar si la API actual es un modelo Claude genuino o si hay conflictos de retransmisión, encapsulación o avisos. Se utiliza cuando se sospecha de la autenticidad del modelo, origen anómalo, envoltorio de terceros o cuando se necesita un informe de detección de autenticidad del modelo.
