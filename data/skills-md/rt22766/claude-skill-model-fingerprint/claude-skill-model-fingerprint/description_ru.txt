Используйте интроспективный анализ, отпечатки Reasoning_effort, тесты отказа Magic String и специальные стресс-тесты, чтобы определить, является ли текущий API подлинной моделью Claude или существуют ли реле, оболочки или конфликты подсказок. Используется при подозрении, что модель является поддельной, имеет необычный источник, упакована третьей стороной или когда необходим отчет о проверке подлинности модели.
