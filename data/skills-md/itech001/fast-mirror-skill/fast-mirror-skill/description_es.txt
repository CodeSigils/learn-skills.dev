Configure y cambie automáticamente a fuentes espejo nacionales para acelerar las instalaciones del administrador de paquetes. Utilice esta habilidad cuando un usuario esté instalando paquetes/dependencias (por ejemplo, npm install, pip install, Yarn install, brew install, apt install, gem install, cargo install, go get, etc.), se queja de descargas lentas, tiempos de espera de instalación, problemas de red o solicita explícitamente fuentes espejo nacionales.
