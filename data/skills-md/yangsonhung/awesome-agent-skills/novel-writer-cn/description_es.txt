Asistente de escritura de novelas que admite todo desde cero: redacción de historias, continuación de capítulos, diseño de personajes, construcción de mundos, etc. Funciona para cualquier género: ciencia ficción, fantasía, misterio, romance, wuxia y más. Se activa cuando: (1) el usuario solicita escribir una historia, p. “Ayúdame a escribir una novela de ciencia ficción” o “Crea una historia de detectives”; (2) continuar o revisar el contenido existente, p. “Agregar otro capítulo a esta historia” o “Revisar este personaje”; (3) tareas de personajes, p. “Diseña un villano para mí” o “Dale un interés amoroso al protagonista”; (4) construcción del mundo, p.e. "Crea un sistema mágico" o "Construye un mundo cyberpunk".
