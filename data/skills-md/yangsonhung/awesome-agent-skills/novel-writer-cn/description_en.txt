Novel-writing assistant supporting creation from scratch, chapter continuation, character design, world-building, etc. Works for all genres—sci-fi, fantasy, mystery, romance, wuxia, etc. Trigger scenarios: (1) user requests a novel, e.g. “Help me write a sci-fi novel,” “Create a detective story”; (2) continuation or revision, e.g. “Add another chapter to this story,” “Revise this character”; (3) character tasks, e.g. “Design a villain,” “Give the protagonist a love interest”; (4) world-building, e.g. “Design a magic system,” “Build a cyberpunk world.”
