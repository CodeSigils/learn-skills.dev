Помощник по написанию романов, который поддерживает все с нуля — сюжет, продолжение главы, дизайн персонажей, построение мира и т. д. Подходит для любого жанра (научная фантастика, фэнтези, детектив, романтика, уся и т. д.). Trigger scenarios: (1) User asks to write a novel, e.g. «Помоги мне написать научно-фантастический роман», «Создай детектив»; (2) Продолжить или пересмотреть существующий текст, например. “Add another chapter to this story,” “Revise this character”; (3) Задачи, связанные с персонажем, например. «Придумай мне злодея», «Дайте главному герою любовный интерес»; (4) Построение мира, например. «Разработайте волшебную систему», «Постройте мир киберпанка».
