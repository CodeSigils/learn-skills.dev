PLANERA (Planungslogik: Adaptive Notation, Architektur ausführbarer Anforderungen, Erkunden, Verfeinern, Artikulieren). Nutzen Sie diese Fähigkeit IMMER für die strukturierte Planung komplexer Arbeiten vor der Ausführung. Diese Fähigkeit ist immer dann ERFORDERLICH, wenn die Arbeit zu umfangreich für einen einzelnen Realisera-Zyklus ist, mehrere Dateiänderungen über mehrere Module hinweg umfasst, eine Aufgabenzerlegung und -reihenfolge erfordert oder von expliziten Akzeptanzkriterien vor Beginn der Implementierung profitieren würde. Versuchen Sie NICHT, eine mehrstufige Entwicklung ohne diese Fähigkeit durchzuführen. Es enthält den entscheidenden Workflow für skalenadaptive Planung, Verhaltensakzeptanzkriterien, kontradiktorische Überprüfung und Plan-to-Cycle-Integration, die verschwendete Arbeit bei komplexen Aufgaben verhindert. Auslöser bei: „Planera“, „Planen“, „Schreiben Sie einen Plan“, „Brechen Sie dies auf“, „Zerlegen Sie dies“, „Wie sollen wir das erstellen“, „Spezifizieren Sie dies“, „Planen Sie vor dem Erstellen“, „Mehrschritt-Feature“, „Das ist zu groß für einen Zyklus“, jede Anforderung, komplexe Arbeit vor der Ausführung zu planen, jede Erwähnung einer strukturierten Aufgabenzerlegung oder wenn Realisera-Begegnungen auf Arbeit treffen, die für einen einzelnen Zyklus zu groß ist. Wird auch ausgelöst, wenn der Benutzer eine Funktion beschreibt, die eindeutig mehrere Dateien oder Module umfasst.
