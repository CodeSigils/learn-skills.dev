INSPEKTERA (Navegación de integridad: evaluación sistemática de patrones, seguimiento de conocimientos; examinar, informar, asesorar). Utilice SIEMPRE esta habilidad para auditorías de estado de la base de código, revisiones de arquitectura y evaluaciones de calidad estructural. Esta habilidad es REQUERIDA siempre que el usuario desee evaluar el estado general de una base de código, detectar cambios en la arquitectura, encontrar inconsistencias de patrones, identificar puntos críticos de complejidad, evaluar la calidad de la cobertura de las pruebas o verificar el estado de las dependencias. NO intente realizar evaluaciones de calidad en toda la base de código sin esta habilidad porque contiene el flujo de trabajo crítico para la evaluación multidimensional, hallazgos basados ​​en evidencia, puntuación de confianza y seguimiento de tendencias que evita auditorías ruidosas o superficiales.
