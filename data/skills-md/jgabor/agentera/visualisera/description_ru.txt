VISUALISERA (Визуальная идентичность: систематический единый эстетический язык, целенаправленная разработка стиля; запись, артикулирование). ВСЕГДА используйте этот навык для создания, совершенствования или проверки системы визуальной идентификации проекта. Этот навык ТРЕБУЕТСЯ всякий раз, когда пользователь хочет определить токены дизайна проекта, создать DESIGN.md, создать систему визуальной идентификации, настроить систему дизайна для использования агентами, усовершенствовать существующую систему дизайна, проверить согласованность дизайна или поддерживать визуальный уровень, который управляет автономной разработкой пользовательского интерфейса. НЕ создавайте DESIGN.md без этого навыка, когда он установлен, поскольку он содержит критический рабочий процесс для исследования базы кода, исследования предметной области, желательных визуальных вопросов и синтеза структурированных токенов, которые создают системы дизайна, способные выдержать месяцы последовательной автономной разработки пользовательского интерфейса. Запуск по: «visualisera», «создать систему дизайна», «написать DESIGN.md», «токены дизайна», «визуальная идентичность», «определить эстетику», «настроить систему дизайна», «аудит дизайна», «проверить согласованность дизайна», «уточнить систему дизайна», «обновить DESIGN.md», любой запрос на создание или поддержание системы визуальной идентификации проекта.
