Генерация в один клик высококачественных эксклюзивных пакетов файлов навыков Red Fox Skill (SKILL.md + вспомогательные ресурсы). Просто опишите функциональные требования, предоставьте адрес интерфейса и документацию по API, и вы сможете автоматически генерировать файлы профессиональных навыков, соответствующие спецификациям Red Fox, готовые к использованию прямо из коробки. Поддерживает настройку по требованию и итеративную оптимизацию. Триггерные слова: используйте, когда пользователь упоминает «создать навык Red Fox», «создать навык Red Fox», «новый навык Red Fox», «написать навык Red Fox», «создать навык Red Fox», «Генерация навыка Red Fox».
