Инструмент Кими WebSearch. Он использует API Red Fox для вызова функции поиска Кими в Интернете, автоматически опрашивая результаты после отправки запроса. Он используется, когда пользователям необходимо получить информацию в режиме реального времени с помощью поиска Кими, поиска в Интернете или поиска с помощью искусственного интеллекта. Триггерные слова: поиск кими, веб-поиск кими, поиск в Интернете, поиск ИИ, поиск кими.
