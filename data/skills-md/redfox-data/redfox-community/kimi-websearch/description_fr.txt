Outil de recherche Web Kimi. Il utilise l'API Red Fox pour appeler la capacité de recherche Internet de Kimi, interrogeant automatiquement les résultats après la soumission d'une requête. Il est utilisé lorsque les utilisateurs ont besoin d'obtenir des informations en temps réel via la recherche Kimi, la recherche Internet ou la recherche AI. Mots déclencheurs : recherche kimi, recherche Web kimi, recherche Internet, recherche IA, recherche kimi.
