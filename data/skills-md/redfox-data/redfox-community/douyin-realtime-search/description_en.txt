Douyin real-time content search tool. It calls the Redfox API in real time based on the keywords entered by the user to search for the latest Douyin works, supports filtering by sorting method and release time, and returns real-time data (non‑cached/historical data). Use it when the user explicitly requests a “real‑time,” “latest,” “now,” or “current” search of Douyin content, or when there is doubt about the timeliness of existing data. Trigger phrases: Douyin real‑time search, Douyin latest works, real‑time Douyin hot, current Douyin data, Douyin real‑time query.
