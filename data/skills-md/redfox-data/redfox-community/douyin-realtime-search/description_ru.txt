Douyin — инструмент поиска контента в режиме реального времени. Он вызывает API Redfox в режиме реального времени на основе ключевых слов, введенных пользователем, для поиска последних работ Douyin, поддерживает фильтрацию по методу сортировки и времени выпуска и возвращает данные в реальном времени (некэшированные/исторические данные). Используйте его, когда пользователь явно запрашивает поиск контента Douyin «в реальном времени», «последний», «сейчас» или «текущий», или когда есть сомнения в актуальности существующих данных. Триггерные фразы: поиск Douyin в реальном времени, последние работы Douyin, горячие Douyin в реальном времени, текущие данные Douyin, запрос Douyin в реальном времени.
