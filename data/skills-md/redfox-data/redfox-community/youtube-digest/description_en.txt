YouTube script extraction — Input a YouTube video link or ID, and extract the video transcript (subtitles/script) with one click; by default it outputs a plain script without timestamps. Chinese subtitle tracks are prioritized; if no Chinese track is available, it falls back to English and automatically translates it into Chinese. The results are presented in a table (title/duration/script content), with support for exporting to Excel and an optional version with timestamps. It is used when users need to extract YouTube video scripts, convert videos into text, or create video notes/summary/translation/derivative works.
