Weibo post search tool. It calls the Redfox API to search Weibo posts based on user-entered keywords, supporting filtering by search category (comprehensive sort / hot sort / real-time sort) and verification type. Use it when you need to search Weibo content or find popular Weibo posts. Trigger words: Weibo search, search Weibo, Weibo hot, Weibo post, Weibo account search.
