Weibo content search tool. It calls the Redfox API to search Weibo posts based on user-entered keywords, supporting filtering by search category (comprehensive ranking/hot ranking/real-time ranking) and verification type. It is used when users need to search Weibo content or find popular Weibo posts. Trigger words: Weibo search, search Weibo, Weibo hot, Weibo post, Weibo account search.
