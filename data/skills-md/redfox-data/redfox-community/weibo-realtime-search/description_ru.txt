Инструмент поиска контента Weibo. Он вызывает API Redfox для поиска сообщений Weibo на основе введенных пользователем ключевых слов, поддерживая фильтрацию по категории поиска (комплексный рейтинг/горячий рейтинг/рейтинг в реальном времени) и типу проверки. Он используется, когда пользователям необходимо выполнить поиск контента Weibo или найти популярные публикации Weibo. Триггерные слова: поиск в Weibo, поиск в Weibo, горячий Weibo, публикация в Weibo, поиск в аккаунте Weibo.
