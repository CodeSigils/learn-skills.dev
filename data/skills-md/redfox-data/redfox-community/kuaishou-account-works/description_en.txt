Kuaishou account works query tool, featuring two main capabilities: a works list and details. By entering the account platform display ID (kwaiId) or homepage link ID (threeXId), you can retrieve the full list of works for that account (sorted by publication time descending, including playback/likes/comments/favorites/shares/duration/cover/video link); by using the work ID (photoId), you can precisely query the details of a single work. This is used when users need to query a Kuaishou works list by account, view all works of a particular blogger, analyze benchmark account works data, deep-dive into a single viral work, or view the work's main content data. Trigger phrases: query works by account, Kuaishou works list, account works query, check account videos, benchmark account works, work details, work content, query work details, single work, viral details, work data details.
