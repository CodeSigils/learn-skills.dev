استرجاع محتوى حساب Weibo. أدخل رابط الصفحة الرئيسية لمستخدم Weibo أو UID، واستدعِ Redfox API لجلب أحدث منشورات المستخدم، مع دعم التصفح المرقّم. استخدم هذا عندما يريد المستخدم عرض نشاط Weibo الخاص بمستخدم آخر أو تتبع أحدث محتوى للمدون. عبارات التحفيز: البحث في منشورات المستخدم، مستخدم Weibo، صفحة Weibo الرئيسية، البحث في المدون، نشاط Weibo.
