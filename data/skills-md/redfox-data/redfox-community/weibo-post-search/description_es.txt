Recuperación de contenido de cuentas de Weibo. Ingrese el enlace de la página de inicio o UID de un usuario de Weibo, llame a la API de Redfox para obtener las últimas publicaciones del usuario con soporte de paginación. Utilízalo cuando necesites ver la actividad de un usuario en Weibo o realizar un seguimiento del contenido más reciente de un blogger. Palabras desencadenantes: buscar publicaciones de usuarios, usuario de Weibo, página de inicio de Weibo, búsqueda de blogueros, actividad de Weibo.
