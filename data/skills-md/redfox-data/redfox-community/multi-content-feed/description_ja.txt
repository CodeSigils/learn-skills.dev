全ネットワーク コンテンツの海外情報ソース - すべてのプラットフォーム (WeChat 公式アカウント/Douyin/ビデオ アカウント/Xiaohongshu/Kuaishou/Bilibili) を毎日スキャンして海外のブレイク コンテンツを探し、いいね! でトップ 50 を選択し、トピックをインテリジェントにクラスタリングして、プラットフォーム タグ、カバー画像、インタラクション データ、作成に関する洞察を含む HTML 日次レポートを生成します。プラットフォーム、キーワード、時間範囲ごとにターゲットを絞ったクエリをサポートします。 ⚠️ 前日のデータは毎日 15:00 に更新されます。要求された日付のデータがない場合は、最初にユーザーに通知し、確認を待ってから API を呼び出す必要があります。自動取得は禁止されています。ユーザーがコンテンツの海外日次レポート、ブレイクアウトコンテンツ、ホットスポット、作成傾向、またはカスタムクエリを必要とする場合にこれを使用します。
