Инструмент для поиска рейтинга Weibo в горячем поиске. Вызывает API Redfox для получения текущего списка горячих поисковых запросов Weibo, отображает заголовки популярных поисковых запросов и их ссылки по рангу, а также предоставляет сводку анализа творческого вдохновения для популярного поискового контента. Используется, когда пользователи хотят просмотреть популярные поисковые запросы Weibo, горячие рейтинги Weibo или популярные темы Weibo. Триггерные слова: горячий поиск Weibo, горячий рейтинг Weibo, популярные темы Weibo, список горячего поиска, рейтинг горячего поиска Weibo.
