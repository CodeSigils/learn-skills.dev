Générez un document d'exigences produit (PRD) structuré à partir d'une analyse de problème GitHub. Produit des tickets/{ISSUE_NUMBER}/prd.md avec des user stories, des critères d'acceptation et des exigences fonctionnelles. Utilisez cette compétence lorsque vous devez créer un PRD à partir d'un problème GitHub analysé, planifier la mise en œuvre d'une fonctionnalité ou d'un correctif, ou lorsque la compétence solve-gh-issue délègue la génération de PRD. Se déclenche sur : "générer un prd", "créer un plan pour ce problème", "écrire des exigences" ou toute demande de production d'un plan de mise en œuvre structuré à partir d'un problème.
