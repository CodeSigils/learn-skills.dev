Genere un documento de requisitos del producto (PRD) estructurado a partir de un análisis de problemas de GitHub. Produce issues/{ISSUE_NUMBER}/prd.md con historias de usuarios, criterios de aceptación y requisitos funcionales. Utilice esta habilidad cuando necesite crear un PRD a partir de un problema de GitHub analizado, planificar la implementación de una característica o solución, o cuando la habilidad resolver-gh-issue delega la generación de PRD. Activadores en: "generar prd", "crear un plan para este problema", "escribir requisitos" o cualquier solicitud para producir un plan de implementación estructurado a partir de un problema.
