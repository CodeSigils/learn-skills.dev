Genera un documento strutturato sui requisiti del prodotto (PRD) da un'analisi dei problemi di GitHub. Produce Issues/{ISSUE_NUMBER}/prd.md con storie utente, criteri di accettazione e requisiti funzionali. Utilizza questa competenza quando è necessario creare un PRD da un problema GitHub analizzato, pianificare l'implementazione di una funzionalità o correzione o quando la competenza risolvere-gh-problema delega la generazione di PRD. Si attiva su: "genera prd", "crea un piano per questo problema", "scrivi requisiti" o qualsiasi richiesta di produrre un piano di implementazione strutturato da un problema.
