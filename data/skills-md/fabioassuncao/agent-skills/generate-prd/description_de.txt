Generieren Sie ein strukturiertes Produktanforderungsdokument (PRD) aus einer GitHub-Problemanalyse. Erstellt Issues/{ISSUE_NUMBER}/prd.md mit User Stories, Akzeptanzkriterien und funktionalen Anforderungen. Verwenden Sie diese Fähigkeit, wenn Sie eine PRD aus einem analysierten GitHub-Problem erstellen, die Implementierung einer Funktion oder eines Fixes planen müssen oder wenn die Fähigkeit „resolve-gh-issue“ die PRD-Generierung delegiert. Wird ausgelöst bei: „PRD generieren“, „Plan für dieses Problem erstellen“, „Anforderungen schreiben“ oder bei jeder Anforderung, einen strukturierten Implementierungsplan für ein Problem zu erstellen.
