Преобразуйте файл уценки PRD (issues/{N}/prd.md) в структурированный план задач JSON (issues/{N}/tasks.json), подходящий для автономного итеративного выполнения. Используйте этот навык, если у вас есть PRD и вам нужно преобразовать его в машиночитаемый план задач с упорядоченными пользовательскими историями, критериями приемки и отслеживанием зависимостей. Срабатывает при: «конвертировать PRD в JSON», «создать план задач из PRD» или когда навык разрешения проблем делегирует создание плана задач.
