Konvertieren Sie eine PRD-Markdown-Datei (issues/{N}/prd.md) in einen strukturierten JSON-Aufgabenplan (issues/{N}/tasks.json), der für die autonome iterative Ausführung geeignet ist. Nutzen Sie diese Fähigkeit, wenn Sie über ein PRD verfügen und es in einen maschinenlesbaren Aufgabenplan mit geordneten User Stories, Akzeptanzkriterien und Abhängigkeitsverfolgung umwandeln müssen. Wird ausgelöst bei: „PRD in JSON konvertieren“, „Aufgabenplan aus PRD erstellen“ oder wenn die Fähigkeit „resolve-gh-issue“ die Erstellung eines Aufgabenplans delegiert.
