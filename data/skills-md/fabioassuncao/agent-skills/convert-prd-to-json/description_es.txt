Convierta un archivo de rebajas PRD (issues/{N}/prd.md) en un plan de tareas JSON estructurado (issues/{N}/tasks.json) adecuado para la ejecución iterativa autónoma. Utilice esta habilidad cuando tenga un PRD y necesite convertirlo en un plan de tareas legible por máquina con historias de usuario ordenadas, criterios de aceptación y seguimiento de dependencias. Se activa en: "convertir prd a json", "crear plan de tareas a partir de prd" o cuando la habilidad resolve-gh-issue delega la creación del plan de tareas.
