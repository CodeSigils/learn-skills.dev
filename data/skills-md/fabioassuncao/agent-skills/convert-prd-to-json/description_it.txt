Converti un file di markdown PRD (issues/{N}/prd.md) in un piano di attività JSON strutturato (issues/{N}/tasks.json) adatto per l'esecuzione iterativa autonoma. Utilizza questa competenza quando disponi di un PRD e devi convertirlo in un piano di attività leggibile dalla macchina con storie utente ordinate, criteri di accettazione e monitoraggio delle dipendenze. Si attiva su: "converti prd in json", "crea un piano di attività da prd" o quando la capacità di risoluzione dei problemi di gh delega la creazione del piano di attività.
