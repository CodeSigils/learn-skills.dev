Récupérez et analysez un problème GitHub pour extraire le contexte, la portée, les zones affectées et la complexité avant de planifier la mise en œuvre. Utilisez cette compétence lorsque vous avez besoin de comprendre un problème GitHub en profondeur avant de créer un PRD ou un plan de tâches, par exemple lorsque l'utilisateur dit « analyser le problème n°42 », « qu'implique ce problème » ou lorsque la compétence résoudre-gh-issue délègue l'analyse.
