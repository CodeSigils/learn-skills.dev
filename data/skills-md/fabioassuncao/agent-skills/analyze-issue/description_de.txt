Rufen Sie ein GitHub-Problem ab und analysieren Sie es, um Kontext, Umfang, betroffene Bereiche und Komplexität zu extrahieren, bevor Sie die Implementierung planen. Verwenden Sie diese Fähigkeit, wenn Sie ein GitHub-Problem gründlich verstehen müssen, bevor Sie eine PRD oder einen Aufgabenplan erstellen – z. B. wenn der Benutzer sagt „Analysiere Problem Nr. 42“, „Was beinhaltet dieses Problem“ oder wenn die Fähigkeit „resolve-gh-issue“ die Analyse delegiert.
