Recupera e analizza un problema GitHub per estrarre contesto, ambito, aree interessate e complessità prima di pianificare l'implementazione. Utilizza questa competenza quando è necessario comprendere in modo approfondito un problema GitHub prima di creare un PRD o un piano di attività, ad esempio quando l'utente dice "analizza il problema n. 42", "che cosa comporta questo problema" o quando la competenza risolutivo-gh-problema delega l'analisi.
