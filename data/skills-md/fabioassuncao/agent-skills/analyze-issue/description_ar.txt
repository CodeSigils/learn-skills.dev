قم بإحضار مشكلة GitHub وتحليلها لاستخراج السياق والنطاق والمناطق المتأثرة والتعقيد قبل التخطيط للتنفيذ. استخدم هذه المهارة عندما تحتاج إلى فهم مشكلة GitHub بعمق قبل إنشاء PRD أو خطة مهمة - على سبيل المثال، عندما يقول المستخدم "تحليل المشكلة رقم 42"، "ما الذي تتضمنه هذه المشكلة"، أو عندما تقوم مهارة حل المشكلة بتفويض التحليل.
