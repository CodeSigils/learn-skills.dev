Obtenga y analice un problema de GitHub para extraer el contexto, el alcance, las áreas afectadas y la complejidad antes de planificar la implementación. Utilice esta habilidad cuando necesite comprender un problema de GitHub en profundidad antes de crear un PRD o un plan de tareas; por ejemplo, cuando el usuario dice "analizar el problema n.° 42", "qué implica este problema" o cuando la habilidad resolver-gh-issue delega el análisis.
