Implemente de forma iterativa historias de usuarios desde issues/{N}/tasks.json, comprometiéndose después de cada historia pasada y actualizando el plan de tareas. Utilice esta habilidad cuando tenga un plan de tareas JSON y necesite implementar de forma autónoma cada historia de usuario, una a la vez, con controles de calidad, confirmaciones y seguimiento del progreso. Se desencadena en: "ejecutar tareas", "implementar las historias", "comenzar a codificar el plan" o cuando la habilidad de resolver un problema delega la implementación.
