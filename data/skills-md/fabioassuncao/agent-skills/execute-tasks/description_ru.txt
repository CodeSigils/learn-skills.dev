Итеративно реализуйте пользовательские истории из Issues/{N}/tasks.json, фиксируя после каждой пройденной истории и обновляя план задач. Используйте этот навык, если у вас есть план задач JSON и вам необходимо автономно реализовать каждую пользовательскую историю по одной с проверками качества, коммитами и отслеживанием прогресса. Срабатывает при: «выполнении задач», «реализации историй», «начале кодирования плана» или когда навык решения проблем делегирует реализацию.
