Implementieren Sie User Stories iterativ aus issues/{N}/tasks.json, übernehmen Sie nach jeder Story einen Commit und aktualisieren Sie den Aufgabenplan. Verwenden Sie diese Fähigkeit, wenn Sie über einen JSON-Aufgabenplan verfügen und jede User Story einzeln einzeln mit Qualitätsprüfungen, Commits und Fortschrittsverfolgung implementieren müssen. Wird ausgelöst bei: „Aufgaben ausführen“, „Stories umsetzen“, „Plan programmieren beginnen“ oder wenn die Fähigkeit zur Problemlösung die Implementierung delegiert.
