تشغيل مشاريع Docker وDocker Compose بأمان، بما في ذلك إنشاء ملفات Dockerfiles وملفات .dockerignore وتكوينات Compose ومراجعتها وإصلاحها والتحقق من صحتها؛ فحص وتصحيح الحاويات قيد التشغيل؛ عرض السجلات؛ وتنفيذ الأوامر غير التفاعلية في الحاويات؛ وإدارة خدمات الإنشاء؛ بناء الخدمات وبدءها وإيقافها وإعادة تشغيلها؛ فحص الصور والشبكات والمجلدات؛ نسخ الملفات المحدودة؛ واستكشاف مشكلات وقت تشغيل Docker وإصلاحها. يُستخدم عندما يحتاج الوكيل إلى عمل ملف Docker أو Docker Compose، أو تنفيذ الأمر، أو عمليات الحاوية المحلية، أو تصحيح أخطاء البناء/وقت التشغيل، أو فحص الصورة أو الخدمة، أو التنظيف الآمن لـ Docker.
