Dockerfile、.dockerignore ファイル、Compose 構成の作成、レビュー、修復、検証など、Docker および Docker Compose プロジェクトを安全に操作します。実行中のコンテナの検査とデバッグ。ログの表示。コンテナ内で非対話型コマンドを実行する。 Compose サービスの管理。サービスの構築、開始、停止、再起動。イメージ、ネットワーク、ボリュームの検査。境界のあるファイルをコピーする。 Docker ランタイムの問題のトラブルシューティング。エージェントが Docker または Docker Compose ファイルの作業、コマンドの実行、ローカル コンテナーの操作、ビルド/ランタイム デバッグ、イメージまたはサービスの検査、または安全な Docker クリーンアップを必要とする場合に使用します。
