قم بتحليل تغييرات Git المرحلية وغير المرحلية، واستنتج أسلوب الالتزام الخاص بالمستودع من التاريخ الحديث، وقم بصياغة رسالة التزام مفصلة، ​​وقم بإنشاء الالتزام بأمان. استخدم هذه المهارة عندما يطلب المستخدم تنفيذ تعليمات برمجية، أو إنشاء رسالة التزام، أو التنفيذ التلقائي للتغييرات والالتزام بها، أو تلخيص التعديلات المحلية في التزام Git مصقول، بما في ذلك طلبات مثل "帮我提交代码"، أو "生成، أو التزام git".
