Erstellen Sie native Bildschirme für mobile Apps in Benchmark-Qualität (Expo / React Native). Verwenden Sie es beim Entwerfen oder Implementieren einer mobilen Benutzeroberfläche – Bildschirme, Abläufe, Onboarding, Paywalls, Tab-Leisten, Einstellungen, leere Zustände – oder beim Polieren von Bewegung, Typografie, Dunkelmodus oder wahrgenommener Leistung. Erzwingt Apple HIG-Wiedergabetreue, semantische Farben, native Steuerelemente, zielgerichtete reanimierte Bewegungen, eine vom Simulator verifizierte Iterationsschleife und einen Arbeitsablauf, bei dem zuerst echte Apps studiert werden (gepaart mit dem Appllama MCP). Lösen Sie aus auf „Bildschirm erstellen“, „Diesen Bildschirm verbessern“, „Onboarding entwerfen“, „Benutzeroberfläche aufpolieren“, „Nativ wirken lassen“ oder auf eine beliebige mobile Design-/Implementierungsaufgabe.
