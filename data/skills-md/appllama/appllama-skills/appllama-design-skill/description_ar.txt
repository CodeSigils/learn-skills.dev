أنشئ شاشات تطبيقات جوال ذات طابع أصلي وجودة قياسية (Expo / React Native). يُستخدم عند تصميم أو تنفيذ أي واجهة مستخدم للهاتف المحمول - الشاشات، أو التدفقات، أو الإعداد، أو نظام حظر الاشتراك غير المدفوع، أو أشرطة علامات التبويب، أو الإعدادات، أو الحالات الفارغة - أو عند تحسين الحركة، أو الطباعة، أو الوضع المظلم، أو الأداء الملحوظ. يفرض دقة Apple HIG، والألوان الدلالية، وعناصر التحكم الأصلية، والحركة Reanimated الهادفة، وحلقة تكرار تم التحقق منها بواسطة جهاز محاكاة، وسير عمل دراسة التطبيقات الحقيقية أولاً (أزواج مع Appllama MCP). قم بتشغيل "إنشاء شاشة"، أو "تحسين هذه الشاشة"، أو "تصميم الإعداد"، أو "تلميع واجهة المستخدم"، أو "جعلها تبدو أصلية"، أو أي مهمة تصميم/تنفيذ على الأجهزة المحمولة.
