ネイティブ感覚のベンチマーク品質のモバイル アプリ画面を構築します (Expo / React Native)。モバイル UI (画面、フロー、オンボーディング、ペイウォール、タブ バー、設定、空の状態) を設計または実装するとき、またはモーション、タイポグラフィ、ダーク モード、または知覚されるパフォーマンスを磨き上げるときに使用します。 Apple HIG 忠実度、セマンティック カラー、ネイティブ コントロール、目的を持った Reanimated モーション、シミュレータで検証された反復ループ、および Study-Real-Apps-First ワークフロー (Appllama MCP と組み合わせ) を強制します。 「画面を構築する」、「この画面をより良くする」、「オンボーディングを設計する」、「UI を洗練する」、「ネイティブな感じにする」、またはモバイル設計/実装タスクをトリガーします。
