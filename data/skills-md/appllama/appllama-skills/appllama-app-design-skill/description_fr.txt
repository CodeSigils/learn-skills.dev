Créez des écrans d'applications mobiles de qualité native et de qualité de référence (Expo / React Native). À utiliser lors de la conception ou de la mise en œuvre d'une interface utilisateur mobile (écrans, flux, intégration, paywalls, barres d'onglets, paramètres, états vides) ou pour peaufiner le mouvement, la typographie, le mode sombre ou les performances perçues. Applique la fidélité Apple HIG, les couleurs sémantiques, les contrôles natifs, la discipline anti-slop, le mouvement réanimé ciblé, une boucle d'itération complète vérifiée par simulateur de mouvement et un flux de travail axé sur les applications réelles (s'associe avec Appllama MCP). Déclenchez sur « créer un écran », « améliorer cet écran », « concevoir l'intégration », « peaufiner l'interface utilisateur », « le rendre natif » ou toute tâche de conception/implémentation mobile.
