Vollautomatischer SDLC – Vorschlag ausführen → Anwenden → [qa] → Akzeptieren → PR ohne Unterbrechung, direkt zu einem PR. Verwenden Sie diese Option, wenn der Benutzer PR ausführen möchte und dem Agenten voll und ganz vertraut. --review aktiviert Codex Gate 1+2; --qa fügt die Browser-Akzeptanz vor dem Festschreiben ein.
