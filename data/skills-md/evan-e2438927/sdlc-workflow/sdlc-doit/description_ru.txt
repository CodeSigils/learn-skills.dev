Полностью автоматический SDLC — запустить предложение → подать заявку → [qa] → принять → PR без остановки, прямо к PR. Используйте, когда пользователь хочет сделать пиар / 全自动 / 一路到 и полностью доверяет агенту. --review включает шлюзы Кодекса 1+2; --qa вставляет подтверждение браузера перед фиксацией.
