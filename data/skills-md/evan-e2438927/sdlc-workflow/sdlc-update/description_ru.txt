Двухэтапная синхронизация обновлений для уже инициализированного проекта — на этапе 1 безопасно синхронизируется последняя версия scaffold (идемпотентная, никогда не перезаписывающая пользовательский контент); Фаза 2 считывает реальный код и выполняет постепенное обновление с учетом отклонений (базовые показатели автоматически обновляются, пользовательские документы подтверждаются для каждого элемента). Используйте для обновления/升级同步 после обновления плагина или когда базовые версии/документы по архитектуре выглядят устаревшими.
