Gestisci le impostazioni e la diagnostica del runtime duoduo in modalità host. Da utilizzare quando l'utente chiede di controllare o modificare lo stato del daemon, la configurazione del daemon, i registri del daemon, l'abilitazione del runtime del Codex, il livello del registro di debug, la persistenza della telemetria, la frequenza di cadenza o altre impostazioni persistenti della modalità host archiviate in ~/.config/duoduo/.env. Attiva anche richieste cinesi come runtime del codice 帮我启用, registro di debug 打开, telemetria 关闭, 调 cadenza 频率 o 看看 duoduo daemon 配置.
