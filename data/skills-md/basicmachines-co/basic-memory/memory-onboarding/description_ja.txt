完全な個人知識システムの設計と構築を通じて、基本記憶の初心者をガイドします。追跡したい内容についてインタビューし、構造を提案し、スキーマと指示ノートを使用して構造を構築し、その使用方法を教え、それを自動的にロードするように AI アシスタントを設定します。ユーザーが Basic Memory を初めて使用する場合、Basic Memory を「開始」、「セットアップ」、または「オンボーディング」したい場合、それを何に使用すればよいかわからない場合、メモリ プロジェクトまたはナレッジ ベースを整理する方法を尋ねる場合、フォルダー/スキーマ/規則の設計について支援が必要な場合、またはアシスタントにセッション間のコンテキストを記憶させる方法を尋ねる場合は、必ずこのスキルを使用してください。また、ユーザーが空または乱雑な Basic Memory プロジェクトを持っており、構造を必要とする場合にも使用します。
