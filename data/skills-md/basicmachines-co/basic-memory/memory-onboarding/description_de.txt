Führen Sie jemanden, der neu im Bereich Basic Memory ist, durch den Entwurf und Aufbau eines vollständigen persönlichen Wissenssystems – befragen Sie ihn zu dem, was er verfolgen möchte, schlagen Sie eine Struktur vor, bauen Sie sie mit Schemata und Anleitungsnotizen auf, bringen Sie ihm bei, es zu verwenden, und richten Sie seinen KI-Assistenten so ein, dass er es automatisch lädt. Verwenden Sie diese Fertigkeit immer dann, wenn ein Benutzer angibt, dass er neu bei Basic Memory ist, mit Basic Memory „einsteigen“, „einrichten“ oder „einsteigen“ möchte, nicht weiß, wofür er es verwenden soll, fragt, wie er sein Speicherprojekt oder seine Wissensdatenbank organisieren soll, Hilfe beim Entwerfen von Ordnern/Schemata/Konventionen benötigt oder fragt, wie er seinen Assistenten dazu bringen kann, sich den Kontext zwischen Sitzungen zu merken. Verwenden Sie es auch, wenn ein Benutzer ein leeres oder unordentliches Basisspeicherprojekt hat und Struktur wünscht.
