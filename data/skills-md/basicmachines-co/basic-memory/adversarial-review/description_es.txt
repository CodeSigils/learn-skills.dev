Revisión del código contradictorio entre proveedores de la rama actual. Dos familias de modelos diferentes (Claude + Codex/GPT) revisan las diferencias de forma independiente y luego intentan refutar los hallazgos de cada uno; los supervivientes se informan por confianza. Se ejecuta desde Claude Code o Codex. Úselo cuando el usuario solicita una revisión contradictoria, una revisión de modelos cruzados/segunda opinión, o desea hallazgos de alta confianza antes de fusionar. Solo informe: nunca aplica correcciones automáticamente.
