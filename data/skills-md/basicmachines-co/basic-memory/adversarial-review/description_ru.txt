Межвендорный состязательный анализ кода текущей ветки. Два разных семейства моделей (Claude + Codex/GPT) независимо проверяют различия, а затем пытаются опровергнуть выводы друг друга; о выживших сообщается достоверно. Запускается либо из Claude Code, либо из Codex. Используйте, когда пользователь запрашивает состязательную проверку, проверку перекрестной модели/второго мнения или хочет получить выводы с высокой степенью достоверности перед объединением. Только отчеты — исправления не применяются автоматически.
