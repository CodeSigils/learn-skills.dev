مراجعة كود الخصم عبر البائعين للفرع الحالي. تقوم عائلتان نموذجيتان مختلفتان (Claude + Codex/GPT) بمراجعة الفرق بشكل مستقل، ثم تحاولان دحض نتائج بعضهما البعض؛ يتم الإبلاغ عن الناجين بالثقة. يتم تشغيله إما من Claude Code أو Codex. يُستخدم عندما يطلب المستخدم إجراء مراجعة تعارضية، أو مراجعة عبر النماذج/الرأي الثاني، أو عندما يريد نتائج عالية الثقة قبل الدمج. التقرير فقط - لا يتم تطبيق الإصلاحات تلقائيًا أبدًا.
