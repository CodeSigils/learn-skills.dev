Erfassen Sie den aktuellen Status eines Arbeitsthreads oder einer Konversation in einer einzigen zusammenhängenden Basic Memory-Notiz – fassen Sie zusammen, wo er gelandet ist, und hängen Sie kein Protokoll an. Schreiben Sie beim erneuten Erfassen dieselbe Notiz an Ort und Stelle neu, anstatt sie zu duplizieren. Verwenden Sie die Mitte oder das Ende des Threads, wenn Entscheidungen, Erkenntnisse oder Kontext erhaltenswert sind.
