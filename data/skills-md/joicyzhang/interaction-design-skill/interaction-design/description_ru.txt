Используется для выдачи решений в области интерактивного дизайна. Когда пользователи запрашивают такие вещи, как «дизайн взаимодействия, процесс дизайна, как работать, оптимизировать рабочий процесс, улучшить опыт, план взаимодействия, создать прототип», это применяется. Путём анализа требований, согласования целей, сбора фоновой информации, анализа путей, сравнения решений, детализации дизайна и проверки с помощью HTML‑прототипов он создаёт структурированный план взаимодействия и кликабельный прототип.
