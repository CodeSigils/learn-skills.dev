يُستخدم لأي إضافة أو تعديل أو مراجعة أو هندسة عكسية أو قبول المتطلبات وبيانات PRD والنماذج الأولية ومواد المنتجات التنافسية والأنظمة الحالية - بما في ذلك كتابة أو تعديل ميزة صغيرة، أو إضافة حقول/أعمدة/علامات تبويب/قوائم منسدلة، أو إجراء تغييرات طفيفة على HTML أو الأنظمة القديمة، أو إنشاء نموذج أولي أو نموذج أولي مباشرة. بغض النظر عن الحجم أو الوضوح، عندما تنشأ هذه المهام المطلوبة، يجب استدعاؤها أولاً ولا يمكن تخطيها على أساس "الوظيفة البسيطة" أو "المتطلبات الواضحة" أو "التغيير المباشر أسرع". بعد الاستدعاء، قم بتسليم الحد الأدنى ولكن الكامل والقابل للمراجعة والتنفيذ والتتبع والمقبول من العناصر المشتركة بين كل من البشر ووكلاء الترميز في المرحلة المستهدفة. يدعم تعريف المشكلة، واستكشاف الحلول، واستيعاب المتطلبات، والتوضيح، و PRD الموحد، والنموذج الهندسي، وخط الأساس للمراجعة، وتأثير التغيير، وأدلة القبول؛ لا يغطي الجدولة أو الترميز أو CI/CD أو النشر أو العمليات.
