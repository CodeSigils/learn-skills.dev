بالنسبة لأي متطلبات جديدة أو معدلة أو تمت مراجعتها أو تمت هندستها عكسيًا أو قبولها، ومتطلبات PRD، والنماذج الأولية، ومواد التحليل التنافسي، والأنظمة الحالية - بما في ذلك كتابة أو تعديل ميزة صغيرة، أو إضافة حقول/أعمدة/علامات تبويب/قوائم منسدلة، أو إجراء تغييرات طفيفة على HTML أو الأنظمة القديمة، أو إنشاء PRD أو نموذج أولي مباشرةً - يجب استدعاء هذه المهام أولاً بغض النظر عن حجمها أو وضوحها. ولا يمكن تجاوزها بأعذار مثل "الميزة بسيطة"، أو "المتطلبات واضحة"، أو "التحرير المباشر أسرع". بعد الاستدعاء، قم بتقديم الحد الأدنى من المخرجات ولكن الكاملة والقابلة للمراجعة والتنفيذ والتتبع والمقبولة التي يتقاسمها البشر ووكيل الترميز في المرحلة المناسبة. يدعم النطاق تعريف المشكلة، واستكشاف الحلول، واستيعاب المتطلبات، والتوضيح، و PRD الموحد، والنموذج الهندسي، وخط الأساس للمراجعة، وتحليل تأثير التغيير، وأدلة القبول؛ ولا يغطي الجدولة أو الترميز أو CI/CD أو النشر أو العمليات.
