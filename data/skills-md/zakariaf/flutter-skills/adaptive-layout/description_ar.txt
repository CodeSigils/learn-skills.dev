يفرض تكييف التخطيط من خلال القيود/الحجم المتاح، لا يتم فحص الجهاز أو النظام الأساسي مطلقًا - LayoutBuilder + MediaQuery.sizeOf/paddingOf/viewInsetsOf (وليس .of) لعمليات إعادة البناء الضيقة، وفئات حجم نافذة المادة 3 (مضغوط <600، متوسط 600-840، موسع 840-1200، كبير> 1200) كمفردات نقطة التوقف، وإمكانية التنقل التي تم اختيارها حسب العرض (NavigationBar → NavigationRail → NavigationDrawer)، جزء واحد بتفاصيل القائمة مقابل جزءين، أقصى عرض يمكن قراءته عبر ConstrainedBox، صندوق مرن/موسع/FractionallySizedBox على عروض ثابتة، SafeArea + قواطع العرض + إدخالات لوحة المفاتيح، عدم قفل الاتجاه مطلقًا، الوعي القابل للطي/المفصلة عبر MediaQuery.displayFeatures، والتحقق من المصفوفة الذهبية عبر الأحجام. يُستخدم عند إنشاء واجهة مستخدم سريعة الاستجابة أو قابلة للتكيف، أو دعم الكمبيوتر اللوحي/سطح المكتب/القابل للطي، أو الشاشات ذات التفاصيل الرئيسية أو الشاشات المكونة من جزأين، أو غلاف NavigationRail-vs-BottomNav، أو نقاط التوقف، أو LayoutBuilder، أو تغيير حجم MediaQuery، أو SafeArea/القواطع، أو إصلاح الفائض عند العروض الكبيرة.
