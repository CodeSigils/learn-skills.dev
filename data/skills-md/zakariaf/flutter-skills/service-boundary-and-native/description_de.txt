Verbindet jeden Nebeneffekt und jeden nativen Kanal als injizierbare Schnittstelle hinter einem Provider, der UnimplementedError auslöst, bis der Kompositionsstamm ihn überschreibt, mit einem Live-Impl pro Variante, werttypisierten Signaturen, die typisierte Ergebnisse zurückgeben, handgeschriebenen Fälschungen zur Einhaltung von Verträgen über Mocks, MethodChannel, der in einem lib/native/-Verzeichnis unter Quarantäne gestellt wird, und versionierten, sprachübergreifenden Verträgen, die auf beiden Seiten in einem Commit bearbeitet werden. Wird verwendet, wenn Sie einen ShareService/AnalyticsService/RemoteConfigService oder einen beliebigen Nebeneffekt-Port hinzufügen oder ändern, eine Uhr (Paket:Uhr) über einen ClockProvider, einen MethodChannel/Plattform-Kanal oder eine native Widget-Brücke, einen Flavor-Einstiegspunkt (main_*.dart) oder eine Pro-Flavor-Provider-Überschreibung, einen in Kotlin/Swift gespiegelten Shared-File/JSON-Vertrag einfügen und einen verirrten DateTime.now()- oder direkten SDK-Aufruf innerhalb eines ersetzen widget/notifier/repository oder die Verkabelung einer Fälschung über ProviderScope(overrides:) in Tests.
