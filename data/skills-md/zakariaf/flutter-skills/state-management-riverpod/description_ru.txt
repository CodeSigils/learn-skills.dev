Обеспечивает состояние функции как одну модель представления Notifier/AsyncNotifier/StreamNotifier для неизменяемого значения состояния с равенством значений, частное изменяемое состояние, изменяемое только с помощью методов намерения, получение-не-сохранение, единый путь записи через репозиторий и однонаправленный поток данных; Riverpod 3.x — это DI (поставщики как соавторы, переопределения ProviderScope для каждого варианта, бросание швов), считывает разделение ref.watch/.select для отображения, ref.read(p.notifier) в обратных вызовах и ref.listen для побочных эффектов, асинхронность, смоделированная как AsyncValue, состояние каждой сущности с семейным ключом + autoDispose и захваты устаревшего закрытия / наследие StateProvider-StateNotifierProvider-ChangeNotifierProvider /get_it/package:provider запрещены. Используйте при добавлении состояния на экран, написании контроллера функций/ViewModel, поставщиков подключений или DI, получения модели чтения из потока или проверки проблем перестроения/утечки состояния/удаления/пути записи.
