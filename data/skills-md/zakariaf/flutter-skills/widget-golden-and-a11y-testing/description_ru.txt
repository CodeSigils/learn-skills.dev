Обеспечивает дисциплинированную тестовую поверхность виджета/макета/золото/a11y — одна обвязка pumpApp, которая закрепляет tester.view.physicalSize x devicePixelRatio и слои MediaQuery (textScaler/boldText/accessibleNavigation) над MaterialApp, сеть переполнения, которая никогда не подавляется (один testWidgets на устройство x масштаб x полужирный кортеж, поскольку сообщение о переполнении сообщается один раз для каждого RenderObject), вычисляемый getSize/getRect ворота fit-and-geometry вместо золотых, две золотые полосы (кхм, геометрия + один реальный шрифт закрепленной ОС) с loadAppFonts и заблокированным --update-goldens, золотые RTL в разделе «Направленность», контрастность чистого Dart WCAG/APCA для ЗНАЧЕНИЙ цвета и честные ограничения на соответствие Guideline. Используйте при написании test/support/harness.dart, вызове pumpWidget/pumpApp, поиске ошибки «переполнение на N пикселей», достижении takeException/ignoreOverflowErrors/FittedBox/withClampedTextScaling, добавлении matchGoldenFile или написании a11y_test.dart с isSemantics/simulatedAccessibilityTraversal/meetsGuideline.
