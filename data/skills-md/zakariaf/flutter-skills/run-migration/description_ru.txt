Запускает ритуал прямой миграции схемы Drift/SQLite — самую опасную детерминированную операцию в автономном приложении: неправильная миграция автоматически уничтожает строки на устройстве, которые больше нигде не существуют. Обеспечивает точную упорядоченную последовательность: сделать снимок файла перед миграцией перед открытием базы данных, увеличить SchemaVersion ровно на единицу, записать шаг вперед, предназначенный только для добавления (никогда не редактировать отправленный шаг, никогда не записывать вниз миграцию), зафиксировать снимок схемыdrift_dev make-migrations, перегенерировать, затем доказать это с помощью тестов, охватывающих каждый путь from→to (включая переходы между несколькими версиями), запись-at-v(n)/чтение-at-v(n+1) проверка содержимого, проверка целостности PRAGMA + Foreign_key_check и принудительный вызов в середине миграции, который восстанавливает моментальный снимок. Ручной рабочий процесс с побочными эффектами. Используйте при добавлении или изменении таблицы, столбца, индекса или проверки Drift; изменение схемы версии; редактирование onUpgrade/stepByStep; или написание тестов миграции.
