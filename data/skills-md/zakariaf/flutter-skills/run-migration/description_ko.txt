오프라인 우선 앱에서 가장 위험한 결정적 작업인 정방향 전용 Drift/SQLite 스키마 마이그레이션 의식을 실행합니다. 잘못된 마이그레이션은 다른 어디에도 존재하지 않는 기기 내 행을 자동으로 파괴합니다. 정확한 순서를 적용합니다. 데이터베이스가 열리기 전에 마이그레이션 전 파일 스냅샷을 찍고,schemaVersion을 정확히 1만큼 올리고, 추가 전용 stepByStep 전진 단계를 작성하고(제공된 단계를 편집하지 않고, 마이그레이션을 기록하지 않음), Drift_dev make-migrations 스키마 스냅샷을 커밋하고, 재생성한 다음, 모든 from→to 경로(다중 버전 점프 포함)를 포괄하는 테스트로 증명합니다. write-at-v(n)/read-at-v(n+1) 콘텐츠 테스트, PRAGMA 무결성_검사 + foreign_key_check 및 스냅샷을 복원하는 강제 마이그레이션 중간 발생. 부작용을 일으키는 수동 작업 흐름. 드리프트 테이블, 열, 인덱스 또는 CHECK를 추가하거나 변경할 때 사용합니다. 범핑 스키마 버전; OnUpgrade/stepByStep 편집; 또는 마이그레이션 테스트 작성.
