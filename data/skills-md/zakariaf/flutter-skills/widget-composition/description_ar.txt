يفرض تكوين عنصر واجهة المستخدم Flutter - استخراج فئات const Widget المُسماة مطلقًا أساليب `Widget _buildX()`، Lean build() (لا توجد حسابات إدخال/إخراج/تنسيق/مجال، حساب مسبق في ViewModel)، طرق عرض غبية تشاهد مُنبهًا واحدًا وتوجيه الأهداف عبر ref.read، StatelessWidget افتراضيًا مع كل وحدة تحكم تم التخلص منها، وقوائم `.builder` البطيئة، واختيارات عناصر واجهة المستخدم الأرخص (SizedBox/ColoredBox/Align over Container)، وسياسة المفاتيح الصارمة (ValueKey للقوائم القابلة لإعادة الترتيب، وليس GlobalKey أبدًا)، والإيماءة → الأسلاك الاحتياطية المرئية القابلة للتركيز، بالإضافة إلى التخطيط الهيكلي - خلفية تجاوز الهوامش الكاملة مقابل محتوى SafeArea، وتحجيم الخلية المحسوبة، ومصيدة تباعد GridView عبر/المحور الرئيسي، وEdgeInsetsDirectional، وتغيير حجم ToAvoidBottomInset/IME. يُستخدم عند إنشاء أو إعادة هيكلة أي شاشة أو عنصر واجهة مستخدم، أو تقسيم بنية كبيرة () إلى مكونات، أو كتابة GridView/ListView/LayoutBuilder/SafeArea/Scaffold، أو توصيل الأسلاك على Tap/onLongPress/Draggable، أو اختيار مفتاح أو فئة بيانات، أو مراجعة رمز عنصر واجهة المستخدم بطريقة مختلفة.
