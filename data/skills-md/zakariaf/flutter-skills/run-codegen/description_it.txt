Esegue il passaggio codegen deterministico build_runner (drift_dev, freezed, json_serializable, riverpod_generator) come un comando bloccato con --delete-conflitto-output, sempre prima dell'analisi del flutter, mai modifica manuale o impegno forzato generato *.g.dart / *.freezed.dart / *.drift.dart output, guarda solo nello sviluppatore locale. Da utilizzare durante la rigenerazione del codegen, la correzione di "file di parti mancanti" / "uscite in conflitto" / errori di analizzatore di classe generata non definiti, dopo aver modificato una tabella di deriva o DAO, un oggetto con valore congelato, un notificatore o provider riverpod o un modello json_serializable o dopo un nuovo clone git, un cambio di ramo o un pull.
