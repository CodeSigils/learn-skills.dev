決定論的な build_runner codegen パス (drift_dev、frozend、json_serializable、riverpod_generator) を --delete-conflicting-outputs を使用した 1 つの固定コマンドとして実行します。常にフラッター分析の前に、生成された *.g.dart / *.freezed.dart / *.drift.dart 出力を手動で編集したり強制的にコミットしたりすることはなく、ローカル dev でのみ監視します。 codegen を再生成するとき、「欠落しているパーツ ファイル」/「競合する出力」/未定義の生成クラス アナライザー エラーを修正するとき、ドリフト テーブルまたは DAO、フリーズされた値オブジェクト、riverpod Notifier またはプロバイダー、または json_serializable モデルを編集した後、あるいは新しい git クローン、ブランチ スイッチ、またはプルを行った後、使用します。
