Flutter ランタイム パフォーマンスを強制します — const サブツリー、ref.watch(select) による最小限のリビルド スコープ、遅延 ListView/GridView ビルダーとスライバー、サイズ変更された画像デコード (cacheWidth/ResizeImage)、compute/Isolate による UI 分離による重労働、外科的 RepaintBoundary、すべての破棄、およびフロア デバイスでのプロファイル モードでの測定。 UI の最適化、ジャンクまたはフレーム落ちの診断、長いリストや画像の調整、リビルド/再ペイント スコープのレビューを行う場合、またはタスクで const、select、ListView.builder、cacheWidth、compute、RepaintBoundary、AnimatedBuilder、DevTools、ラスター スレッド、または 60/120fps が言及されている場合に使用します。
