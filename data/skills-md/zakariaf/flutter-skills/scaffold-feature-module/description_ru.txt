Поддерживает одну навигационную функцию каждый раз одинаково — фиксированную папку lib/features/<feature>/presentation/ (тупой View + один 1:1 Notifier/AsyncNotifier ViewModel + widgets/ + <feature>_providers.dart с областью действия), зависимости только вниз без импорта перекрестных функций, реактивное чтение в виде StreamProviders с ограниченной областью над репозиторием .watch(), каждая мутация через один репозиторий с одним путем записи метод, типизированный Result/Failure отображается как AsyncValue, типизированный маршрут go_router, несущий идентификатор в параметрах пути, четность ARB между локалями, ключевое слово Family+autoDispose и геометрию только EdgeInsetsDirectional. Используйте при добавлении экрана, вкладки или папки функций; подключение функции Notifier/ViewModel или поставщика потока с ограниченной областью действия; регистрация маршрута; добавление клавиш ARB для нового экрана; разделение переросшего объекта; или добавление постоянной записи, которую читает ее представление.
