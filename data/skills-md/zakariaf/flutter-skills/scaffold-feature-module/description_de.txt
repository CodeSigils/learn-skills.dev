Stellt jedes Mal ein navigierbares Feature auf die gleiche Weise zur Verfügung – ein fester Ordner lib/features/<feature>/presentation/ (dumb View + ein 1:1 Notifier/AsyncNotifier ViewModel + widgets/ + bereichsbezogener <feature>_providers.dart), nur nach unten gerichtete Abhängigkeiten ohne funktionsübergreifende Importe, reaktive Lesevorgänge als bereichsbezogene StreamProvider über ein Repository .watch(), jede Mutation durch eine Repository-Single-Write-Path-Methode, typisiert Ergebnis/Fehler wurde als AsyncValue angezeigt, eine typisierte go_router-Route mit Identität in Pfadparametern, ARB-Parität über Gebietsschemas, Family+AutoDispose-Verschlüsselung und EdgeInsetsDirectional-only-Geometrie. Zum Hinzufügen eines Bildschirms, einer Registerkarte oder eines Funktionsordners verwenden. Verkabelung eines Feature-Notifiers/ViewModels oder eines bereichsbezogenen Stream-Anbieters; Registrieren einer Route; Hinzufügen von ARB-Tasten für einen neuen Bildschirm; Aufteilen eines überwucherten Merkmals; oder einen persistenten Datensatz hinzufügen, den seine Ansicht liest.
