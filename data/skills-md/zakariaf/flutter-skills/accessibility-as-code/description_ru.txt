Обеспечивает доступность как свойство правильности, созданное в каждом виджете — Semantics(button/label) или ExcludeSemantics на каждом узле, состояние a11y считывается из MediaQuery, а не состояние приложения, никогда MediaQuery.withClampedTextScaling / textScaleFactor / FittedBox / TextOverflow.ellipsis для соответствия метке, каналы без избыточности цвета (значок+метка+форма+текст) для каждого состояния, контраст на составном фоне (4,5:1 тело / 3:1 большое), 44 пикселя для одного касания, обход OrdinalSortKey и поддержка жирного текста/уменьшения движения. Используйте при добавлении GestureDetector/InkWell или любой цели касания, добавлении значка или изображения, использовании withClampedTextScaling/FittedBox/ellipsis/textScaleFactor для подгонки текста, состояния кодирования с помощью цвета, типа размера, заказа перемещения фокуса или просмотра любого представления для поддержки чтения с экрана/переключения/слабовидящего.
