Strukturiert ein Flutter-Designsystem als Token → Thema → Modifikatoren → Formen mit zweistufigen Token (Primitive benannt nach Messwert, semantische Slots benannt nach Rolle), die über eine ThemeExtension verfügbar gemacht werden, die über ein Asserting of(context) gelesen wird; Erstellt von Hand sowohl helles als auch dunkles ColorScheme anstelle von ColorScheme.fromSeed, behält jede Rohfarbe/hex/Colors./Curves./Duration/BorderRadius/fontSize in lib/theme/ hinter einem Tor ohne Rohwerte, reduziert die Animation bei reduzierter Bewegung auf Null, stellt das beibehaltene Thema vor dem ersten Malen wieder her, bündelt Schriftarten (niemals google_fonts/dynamic_color) und leitet zuletzt die unterstützende Farbe jeder zustandsbehafteten Bedeutung ab Farbe ist also nie das einzige Signal. Verwenden Sie diese Option, wenn Sie ThemeData/ThemeExtension/ColorScheme erstellen oder bearbeiten, ein Design-Token hinzufügen oder umbenennen, Theme-Injection oder Theme-Modus-Persistenz verbinden, nach fromSeed/dynamic_color/google_fonts/FontVariation greifen, einen Theme- oder DesignSystem-Ordner strukturieren oder ein Widget überprüfen, das eine Farbe, einen Radius, eine Dauer oder eine Schriftart wiedergibt.
