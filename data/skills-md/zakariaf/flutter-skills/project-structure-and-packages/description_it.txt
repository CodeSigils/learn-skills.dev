Applica l'impalcatura del progetto Flutter/Dart in cui il layout rende i difetti greppabili: un'app a pacchetto singolo per impostazione predefinita (funzionalità prima in lib/features/, base condivisa divisa per ruolo in core/ data/ services/ routing/ theme/ l10n/, un thin main.dart che chiama bootstrap(), nessuna lib/src nell'app), estraendo un pacchetto pure-Dart dal nome generico solo quando un corpo di logica lo guadagna (barile pubblico su privato lib/src/ solo per PACKAGES, solo meta deps come firewall di compilazione, risoluzione: membro dell'area di lavoro, DAG di dipendenza solo verso il basso), con pubspec trattato come artefatto di controllo e nessuna cartella utils/helpers/common/misc/grab-bag-shared junk-drawer. Da utilizzare durante la creazione di qualsiasi file o directory .dart, per decidere dove appartiene un repository/Notifier/MethodChannel/value-type/token, per creare o correggere un pubspec.yaml, per aggiungere un membro dell'area di lavoro, per scrivere una direttiva di importazione, per eseguire il mirroring di un test in test/ o per rivedere un diff per l'organizzazione.
