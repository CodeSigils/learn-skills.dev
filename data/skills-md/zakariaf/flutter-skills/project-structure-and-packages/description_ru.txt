Обеспечивает создание шаблонов проекта Flutter/Dart, в которых макет позволяет обнаруживать дефекты — приложение с одним пакетом по умолчанию (сначала функция в lib/features/, общая основа, разделенная по ролям в ядре/data/services/routing/theme/l10n/, тонкий файл main.dart, который вызывает bootstrap(), в приложении нет библиотеки lib/src), извлечение пакета pure-Dart с общим именем только тогда, когда тело логики его заслужило (публичный ствол вместо частного lib/src/ только для ПАКЕТОВ, deps только для мета в качестве брандмауэра компиляции, разрешение: член рабочей области, зависимость DAG только для нисходящих), с pubspec, рассматриваемым как артефакт аудита, и без папок utils/helpers/common/misc/grab-bag-shared нежелательной папки. Используйте при создании любого файла или каталога .dart, принятии решения о принадлежности репозитория/Notifier/MethodChannel/типа значения/токена, создании или исправлении pubspec.yaml, добавлении члена рабочей области, написании директивы импорта, зеркалировании тестируемого теста/ или просмотре различий для организации.
