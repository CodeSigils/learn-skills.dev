يفرض CI البسيط لـ GitHub Actions Flutter CI حيث يتم تعيين كل بوابة إلى عقد حظر إصدار واحد مسمى - عداء مثبت + subosito/flutter-action@v2 Toolchain، تنسيق Dart --set-exit-if-changed، تحليل الرفرفة --fatal-infos، build_runner ونضارة مخطط الانجراف (git diff --exit-code)، اختبار الرفرفة --test-randomize-ordering-seed Random، static import/banned-string greps التي تلتقط ما لا يستطيع وقت التشغيل التقاطه، والتغطية كتقرير-never-a-gate مع الكذبة الصعودية الثابتة، والتحقق من الذهبيات التي لا تبارك أبدًا (لا يوجد --update-goldens في CI)، وبيان صادق لما لا يمكن لـ CI إثباته (الصوت، والخطوط الحقيقية، والسلوك على الجهاز). يُستخدم عند تحرير .github/workflows/*.yml، أو إضافة أو إزالة وظيفة أو خطوة، أو توصيل بوابة كود/مخطط/تنسيق/تحليل/تغطية، أو كتابة اختبار سياسة قائم على grep أو برنامج نصي للبوابة ضمن الاختبار/السياسة أو الأداة/، أو تثبيت إصدارات الإجراء، أو المطالبة بإثبات CI لشيء لا يمكن إثباته.
