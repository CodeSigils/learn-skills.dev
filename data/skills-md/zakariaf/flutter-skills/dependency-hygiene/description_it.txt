Applica la disciplina pubspec/lock: intervalli di accento circonflesso in pubspec.yaml con un pubspec.lock impegnato come unico pin, una stringa di versione dell'SDK registrata separatamente, un'inclusione very_good_analysis bloccata sulla versione (il cui file mancante non supera l'analisi predefinita o elimina silenziosamente il set di regole dove gli avvisi non sono fatali), controllo dell'albero transitivo prima di aggiungere un pacchetto, un gate di dipendenza che rifiuta network/telemetry/crash/ads/heavy-transitive dipende dai criteri e fornisce qualsiasi plug-in nativo bus-factor-1 dietro un'interfaccia in terze parti/. Da utilizzare quando si esegue dart pub add/get/upgrade/outdated/deps, si modifica pubspec.yaml o pubspec.lock, si esegue il bumping dell'SDK Flutter/Dart, si sceglie o si rifiuta una nuova dipendenza, si rimuove un pacchetto o si controlla cosa trascina una dipendenza.
