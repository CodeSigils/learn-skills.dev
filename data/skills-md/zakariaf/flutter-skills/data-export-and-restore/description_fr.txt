Applique la portabilité des données face à l'utilisateur dans une première application hors ligne : sauvegarde/restauration (exacte, exécutable sur machine) strictement séparée de l'exportation/du rapport (humain, avec perte, jamais source de restauration) ; une enveloppe versionnée contenant formatVersion, schemaVersion, appVersion, exportedAtUtc et une somme de contrôle de charge utile afin qu'une restauration refuse un fichier d'une application plus récente au lieu de corrompre la base de données ; restaurer sous forme d'importation tout ou rien dans une base de données intermédiaire échangée uniquement après validation ; valeurs canoniques dans des formats machine (unités mineures entières, entiers SI, ISO-8601 UTC, identifiants stables) et chiffres jamais localisés ; RFC 4180 CSV citant plus l'échappement de formule-injection =/+/-/@ ; écritures en streaming publiées par renommage atomique ; la feuille de partage derrière une Gateway injectée ; et un test aller-retour export → import → export sur un appareil hostile. À utiliser lors de l'ajout ou de la modification d'une exportation, d'une sauvegarde, d'une importation, d'une restauration, d'un partage ou d'une sortie CSV/JSON/PDF, lors de l'écriture d'un validateur d'importation ou d'une politique de fusion/remplacement, ou lors de la gestion d'un fichier sélectionné.
