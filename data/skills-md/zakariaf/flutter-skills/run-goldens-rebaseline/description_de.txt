Führt das goldene Re-Baselining-Ritual durch – die einzige genehmigte Art und Weise, wie festgeschriebene Referenzbilder überschrieben werden. Erzwingt die Reihenfolge: Landen und begrünen Sie die nicht-goldenen Geometrie-, Kontrast- und A11y-Tests ZUERST, stellen Sie die Baseline nur in der angehefteten Blessing-Umgebung neu, die die übergebenen Bilder erzeugt hat, mit loadAppFonts(), damit in Ahem nichts gerendert wird, über „flutter test --update-goldens --tags golden“ (niemals in CI, um niemals eine rote Pipeline grün zu machen), dann überprüfen Sie jedes geänderte PNG mit dem Auge, löschen Sie die Waisen, die durch umbenannte oder entfernte Tests übrig geblieben sind, landen Sie die Bilder als ihr eigenes Commit, das benennt, warum sie umgezogen sind, und dies beweisen, indem sie die Suite OHNE die Flagge erneut ausführen. Manueller, nebensächlicher Arbeitsablauf. Verwenden Sie diese Option, wenn eine absichtliche visuelle Änderung „MatchesGoldenFile“ unterbricht, wenn Sie einen Golden-Test hinzufügen oder umbenennen oder wenn jemand nach „--update-goldens“ greift.
