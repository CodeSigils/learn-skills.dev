Exécute le rituel doré de re-baselining – la seule manière sanctionnée d’écraser les images de référence validées. Applique l'ordre : posez et verdissez la géométrie non dorée, testez le contraste et tous les tests en PREMIER, redéfinissez la ligne de base uniquement dans l'environnement de bénédiction épinglé qui a produit les images validées, avec loadAppFonts() pour que rien ne soit rendu dans Ahem, via `flutter test --update-goldens --tags golden` (jamais dans CI, ne jamais rendre un pipeline rouge vert), puis inspectez chaque PNG modifié à l'oeil nu, supprimez les orphelins laissés par les tests renommés ou supprimés, atterrissez les images comme leur propre commit indiquant pourquoi ils ont déménagé, et prouvez-le en réexécutant la suite SANS le drapeau. Flux de travail manuel à effets secondaires. À utiliser lorsqu'un changement visuel délibéré interrompt matchesGoldenFile, lors de l'ajout ou du renommage d'un test d'or, ou lorsque quelqu'un cherche --update-goldens.
