Entwerfen und implementieren Sie eine verteilungsübergreifende Linux-Port-Scan-Erkennung, eine automatisierte Firewall-IP-Sperre und Intrusion-Defense-Regeln. Verwenden Sie diese Option, wenn Sie Linux-Server vor automatisierten Scannern schützen, iptables/nftables/firewalld-Ratenbegrenzungen konfigurieren oder fail2ban/psad-Schutzmaßnahmen einrichten.
