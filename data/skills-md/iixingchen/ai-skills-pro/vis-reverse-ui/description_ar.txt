قم بإجراء هندسة عكسية لواجهات مستخدم الويب ونماذج التصميم بالحجم الطبيعي إلى رموز تصميم CSS دقيقة البكسل ومواصفات الأنماط المحسوبة وخصائص CSS الذرية. يُستخدم عند استخراج أنظمة التصميم من مواقع الويب الموجودة، أو نسخ مكونات الواجهة الأمامية، أو تحويل واجهة المستخدم المقدمة إلى متغيرات CSS نظيفة ورموز Tailwind المميزة.
