Effettua il reverse engineering delle interfacce utente web e progetta mockup in token di progettazione CSS accurati al pixel, specifiche di stile calcolate e proprietà CSS atomiche. Da utilizzare quando si estraggono sistemi di progettazione da siti Web esistenti, si replicano componenti frontend o si converte l'interfaccia utente renderizzata in variabili CSS pulite e token Tailwind.
