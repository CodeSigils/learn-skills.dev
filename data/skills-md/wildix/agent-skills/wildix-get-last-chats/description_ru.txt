Используйте, когда вас попросят составить список чатов, показать папку «Входящие», просмотреть последние разговоры или найти чат по имени в x-bees, Collaboration 7 или x-hoppers. Возвращает список чатов пользователя, отсортированный по последнему действию. НЕ для разрешения чата по его идентификатору — для этого используйте wildix-get-chat.
