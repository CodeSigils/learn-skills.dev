Используйте, когда пользователь просит создать запрос на включение, открыть запрос на внесение изменений, отправить изменения на проверку или говорит «/pr». Проверяет состояние ветки, анализирует все коммиты с момента расхождения с базой, запускает проверки качества перед PR, генерирует структурированный заголовок и тело PR с разделами сводки/плана тестирования/критических изменений, отправляет ветку и создает PR через GitHub CLI (gh). Поддерживает проекты PR, назначение рецензентов и прикрепление меток.
