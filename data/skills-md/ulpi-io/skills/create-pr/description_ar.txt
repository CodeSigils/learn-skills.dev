يُستخدم عندما يطلب المستخدم إنشاء طلب سحب، أو فتح PR، أو إرسال تغييرات للمراجعة، أو قول "/pr". التحقق من صحة حالة الفرع، وتحليل جميع الالتزامات منذ الاختلاف عن القاعدة، وإجراء فحوصات جودة ما قبل العلاقات العامة، وإنشاء عنوان ونص العلاقات العامة المنظم مع أقسام الملخص/خطة الاختبار/التغييرات العاجلة، ودفع الفرع، وإنشاء العلاقات العامة عبر GitHub CLI (gh). يدعم مسودة العلاقات العامة وتعيين المراجع ومرفقات الملصقات.
