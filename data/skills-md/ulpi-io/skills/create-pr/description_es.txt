Úselo cuando el usuario solicita crear una solicitud de extracción, abrir un PR, enviar cambios para revisión o dice "/pr". Valida el estado de la rama, analiza todas las confirmaciones desde la divergencia desde la base, ejecuta comprobaciones de calidad previas al PR, genera un título y cuerpo del PR estructurado con secciones de resumen/plan de prueba/cambios importantes, impulsa la rama y crea el PR a través de GitHub CLI (gh). Admite borradores de relaciones públicas, asignación de revisores y fijación de etiquetas.
