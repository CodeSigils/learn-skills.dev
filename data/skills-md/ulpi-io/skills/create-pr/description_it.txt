Da utilizzare quando l'utente chiede di creare una richiesta pull, aprire una PR, inviare modifiche per la revisione o dice "/pr". Convalida lo stato del ramo, analizza tutti i commit dalla divergenza dalla base, esegue controlli di qualità pre-PR, genera titolo e corpo PR strutturati con sezioni di riepilogo/piano di test/modifiche importanti, invia il ramo e crea il PR tramite GitHub CLI (gh). Supporta bozze di PR, assegnazione di revisori e allegati di etichette.
