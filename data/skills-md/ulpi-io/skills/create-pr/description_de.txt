Wird verwendet, wenn der Benutzer eine Pull-Anfrage erstellen, eine PR öffnen, Änderungen zur Überprüfung einreichen möchte oder „/pr“ sagt. Validiert den Branch-Status, analysiert alle Commits seit der Abweichung von der Basis, führt Qualitätsprüfungen vor der PR durch, generiert einen strukturierten PR-Titel und -Körper mit Abschnitten „Zusammenfassung/Testplan/Breaking-Changes“, pusht den Branch und erstellt die PR über GitHub CLI (gh). Unterstützt PR-Entwürfe, Prüferzuweisung und Etikettenanhang.
