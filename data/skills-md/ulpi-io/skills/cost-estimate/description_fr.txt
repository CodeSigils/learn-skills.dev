Estimez le coût de développement d'une base de code (dépôt complet, différence de branche ou validation unique). Invoquez via /cost-estimate ou lorsque l'utilisateur dit « coût estimé », « combien cela coûterait-il », « coût de développement ». Accepte les arguments de portée facultatifs tels que "branch:feat/foo" ou "commit:abc1234".
