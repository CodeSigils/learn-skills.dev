Überprüfen Sie geänderten Code auf Wiederverwendung, Qualität und Effizienz. Analysen auf unnötige Komplexität,
redundante Abstraktionen, tiefe Verschachtelungen und unklare Benennungen und wendet dann gezielte Vereinfachungen an
unter Beibehaltung jeglichen Verhaltens. Aufruf über /code-simplify oder wenn der Benutzer „Vereinfachen“ sagt.
„Diesen Code bereinigen“, „einfacher machen“, „Komplexität reduzieren“.
