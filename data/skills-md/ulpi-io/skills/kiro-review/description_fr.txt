Exécutez Kiro CLI pour examiner les modifications de code apportées dans la session ou la branche en cours. Appelle le « kiro-cli chat » en mode non interactif avec des instructions de révision ciblées dérivées des modifications réelles. À utiliser lorsque l'utilisateur dit "kiro review", "second opinion", "rival review", "cross-review" ou "/kiro-review".
