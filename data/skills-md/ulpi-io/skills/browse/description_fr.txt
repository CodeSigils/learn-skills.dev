Navigation Web rapide pour les agents de codage IA via le démon Chromium sans tête persistant. Accédez à n'importe quelle URL,
lire le contenu de la page, cliquer sur les éléments, remplir des formulaires, exécuter JavaScript, prendre des captures d'écran,
inspectez CSS/DOM, capturez les journaux de console/réseau, et bien plus encore. ~100 ms par commande après
premier appel. Fonctionne avec Claude Code, Cursor, Cline, Windsurf et tout agent pouvant exécuter Bash.
Pas de MCP, pas d'extension Chrome - juste une CLI rapide.
