Быстрый просмотр веб-страниц для агентов кодирования искусственного интеллекта с помощью постоянного безголового демона Chromium. Перейдите к любому URL-адресу,
читать содержимое страницы, щелкать элементы, заполнять формы, запускать JavaScript, делать снимки экрана,
проверять CSS/DOM, собирать журналы консоли/сети и многое другое. ~100 мс на команду после
первый звонок. Работает с Claude Code, Cursor, Cline, Windsurf и любым агентом, который может запускать Bash.
Никакого MCP, никакого расширения Chrome — только быстрый CLI.
