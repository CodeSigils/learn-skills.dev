Исправьте ошибки, обнаруженные с помощью /find-bugs, о которых сообщил пользователь или которые возникли во время разработки.
Систематически воспроизводит, диагностирует основную причину, планирует минимальные исправления, реализует с
регрессионные тесты, проверка отсутствия регрессий и отчеты о результатах. Включает в себя специфичные для типа ошибки
исправить сценарии безопасности, логики, асинхронности, нулевой безопасности, условий гонки и многого другого.
Включает справочные файлы для 18 платформ/языков (Express, React,
Next.js, Fastify, Hono, Remix, Laravel, Go, Gin, Echo, Fiber, Swift, Bun, Rust,
Axum, Actix Web, Rocket, React Native). Обрабатывает отдельные ошибки, многофайловые ошибки и пакетные исправления из результатов поиска ошибок.
Вызов через /bugfix или когда пользователь говорит «исправить эту ошибку», «исправить выводы»,
«исправить обнаружение №3», «исправить критические ошибки».
