Verwenden Sie diese Option, wenn der Benutzer Fehler finden, Änderungen überprüfen, Sicherheitsüberprüfungen durchführen oder die Codequalität im aktuellen Zweig überprüfen möchte. Analysiert vollständige Unterschiede zum Standardzweig, ordnet Angriffsflächen zu, führt eine Sicherheitscheckliste für jede geänderte Datei aus, überprüft Ergebnisse anhand des Kontexts und meldet priorisierte Probleme. Aufruf über /find-bugs oder wenn der Benutzer „Fehler finden“, „Meine Änderungen überprüfen“, „Sicherheitsüberprüfung“ oder „Diesen Code prüfen“ sagt.
