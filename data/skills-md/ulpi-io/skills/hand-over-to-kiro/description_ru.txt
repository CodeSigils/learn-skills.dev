Делегируйте задачу реализации Kiro CLI (kiro-cli) и сообщите о результате. Используйте, когда пользователь
просит передать работу Киро — «/передать-киро», «делегировать Киро», «позволить Киро заняться/сделать это»,
«перейти к Киро», «передать Киро» или любой вариант, требующий выполнения kiro-cli. Два режима: План
режим передает существующий план Киро для реализации; Прямой режим передает задачу пользователя. Клод
собирает контекст, создает автономную, безопасную для внедрения подсказку, внедряет соответствующий киро задачи
навыки (`--skill <name>`, поскольку у kiro нет собственного инструмента Skill), вызывает kiro-cli через встроенный
помощник с ограниченным доверием, захватывает выходные данные, проверяет различия и отправляет отчеты.
