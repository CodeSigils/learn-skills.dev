Интерактивный планировщик сборки — исследует кодовую базу с помощью CodeMap, проверяет область действия пользователя, разлагает функции на атомарные записи TASK-NNN с сопоставлением зависимостей и назначением приоритетов, создает планы задач, поддающиеся машинному анализу, для параллельного выполнения агента. Используйте, когда вам нужно разбить функцию, исправление ошибок или проект на структурированную группу DAG задач для параллельного выполнения агента.
