Planificador de compilación interactivo: explora la base de código a través de CodeMap, desafía el alcance con el usuario, descompone características en entradas atómicas TASK-NNN con mapeo de dependencias y asignación de prioridades, produce planes de tareas analizables por máquina para la ejecución paralela de agentes. Úselo cuando necesite dividir una característica, corrección de errores o proyecto en un DAG estructurado de tareas para la ejecución paralela del agente.
