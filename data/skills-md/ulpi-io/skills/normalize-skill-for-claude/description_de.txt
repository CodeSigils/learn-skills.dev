Konvertieren Sie eine lokale Fertigkeit in eine für Claude Code optimierte Form. Prüft einen Skill-Ordner oder SKILL.md
Gegen das Laufzeitverhalten von Claude Code wird ein DAG-Umschreibungsplan pro Skill mit Quellunterstützung erstellt
Leitplanken und schreibt optional Frontmatter, Body und Referenzen für eine bessere Weiterleitung um,
Geringerer Prompt-Footprint und sicherere Ausführung. Wird verwendet, wenn der Benutzer sagt: „Diese Fertigkeit in Claude umwandeln“.
„diesen SKILL.md normalisieren“, „diesen Skill Claude-nativ machen“ oder „diesen Skill für Claude Code umschreiben“.
