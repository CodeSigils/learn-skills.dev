Navegación web sigilosa para agentes de codificación de IA utilizando el tiempo de ejecución camoufox de la CLI de navegación.
El mismo flujo de trabajo que la habilidad "navegar" (navegar, inspeccionar, interactuar, informar) pero con
un Firefox anti-detección que pasa Cloudflare Turnstile, tráfico inusual de Google,
Comprobaciones DataDome y PerimeterX. Fundas con nombres de perfiles camoufox, autentificadas.
sesiones y rotación de proxy.
