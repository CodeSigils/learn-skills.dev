ユーザーがブランチの遡及、事前 PR 分析、ブランチの健全性チェックを要求する場合、または「/pr-retro」と言う場合に使用します。現在のブランチとベース (main..HEAD) 上のすべてのコミットを分析し、サイズ メトリクス、テスト LOC 比率、フォーカス スコア、セッション分析、コミット ハイジーン、コントリビューターの内訳、セルフレビュー スキャン (TODO、デバッグ アーティファクト、.only、シークレット) を計算し、マージ準備状況の判定 (緑/黄/赤) を提供します。 --quick (ダッシュボードのみ) および --base <branch> (カスタム ベース) をサポートします。 JSON スナップショットを .history/pr-retros/ に保存します。
