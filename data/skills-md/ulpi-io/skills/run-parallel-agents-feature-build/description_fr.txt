Orchestrez plusieurs agents spécialisés travaillant en parallèle lors de la création de fonctionnalités indépendantes.
À utiliser lorsque la liste des tâches contient plus de 3 tâches non liées qui ne partagent pas d'état ou de fichiers.
Associe chaque tâche au bon agent expert et les lance simultanément via l'outil Agent
avec isolation de l'arbre de travail. Prend en charge tous les types de sous-agents disponibles.
