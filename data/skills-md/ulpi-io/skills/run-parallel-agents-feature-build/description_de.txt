Orchestrieren Sie beim Erstellen unabhängiger Funktionen mehrere spezialisierte Agenten, die parallel arbeiten.
Verwenden Sie diese Option, wenn die Aufgabenliste mehr als 3 unabhängige Aufgaben enthält, die weder den Status noch die Dateien gemeinsam haben.
Ordnet jede Aufgabe dem richtigen Expertenagenten zu und startet sie gleichzeitig über das Agententool
mit Worktree-Isolation. Unterstützt alle verfügbaren Subagententypen.
