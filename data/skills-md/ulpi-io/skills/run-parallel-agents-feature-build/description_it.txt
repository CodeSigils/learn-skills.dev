Orchestra più agenti specializzati che lavorano in parallelo durante la creazione di funzionalità indipendenti.
Da utilizzare quando l'elenco delle attività contiene più di 3 attività non correlate che non condividono stato o file.
Associa ciascuna attività all'agente esperto giusto e le avvia contemporaneamente tramite lo strumento Agente
con isolamento dell'albero di lavoro. Supporta tutti i tipi di agenti secondari disponibili.
