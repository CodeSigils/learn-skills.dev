Преобразуйте локальный AGENT.md в агент, оптимизированный для Claude Code. Проверяет одного агента на соответствие Клоду Коду
поведение во время выполнения, создает план перезаписи DAG для каждого агента с защитой на основе исходного кода и, при необходимости,
переписывает заголовок и тело системного приглашения, чтобы агент стал тоньше, более специфичным для ролей и
лучше согласовано со средой выполнения агента Клода. Используйте, когда пользователь говорит «преобразовать этого агента в Клода»,
«нормализовать этот AGENT.md», «утончить этого агента» или «переписать эту личность для Клода Кода».
