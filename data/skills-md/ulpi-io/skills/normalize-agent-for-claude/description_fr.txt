Convertissez un AGENT.md local en un agent optimisé Claude Code. Audite un agent contre Claude Code
comportement d'exécution, crée un plan de réécriture du DAG par agent avec des garde-fous basés sur la source et, éventuellement,
réécrit le texte de présentation et le corps de l'invite système afin que l'agent soit plus fin, plus spécifique à son rôle et
mieux aligné avec le runtime de l'agent de Claude. À utiliser lorsque l'utilisateur dit "convertir cet agent en Claude",
"normalisez cet AGENT.md", "allègez cet agent" ou "réécrivez ce personnage pour Claude Code".
