Konvertieren Sie eine lokale AGENT.md in einen für Claude Code optimierten Agenten. Prüft einen Agenten gegen Claude Code
Laufzeitverhalten, erstellt einen DAG-Umschreibungsplan pro Agent mit quellgestützten Leitplanken und optional
schreibt den Frontmatter- und System-Prompt-Körper neu, sodass der Agent dünner und rollenspezifischer ist
besser auf Claudes Agentenlaufzeit abgestimmt. Wird verwendet, wenn der Benutzer sagt: „Konvertieren Sie diesen Agenten in Claude“.
„diesen AGENT.md normalisieren“, „diesen Agenten verdünnen“ oder „diese Persona für Claude Code neu schreiben“.
