Palantir Ontology Practice Version 3.2 – Graphique de connaissances structuré + Moteur de règles + Méthodologie de raisonnement scientifique. Utilisé pour le calcul du raisonnement, l'analyse de sélection et les requêtes de base de connaissances. **Les résultats du raisonnement doivent afficher le processus de raisonnement détaillé** : inclure les exigences de l'utilisateur, l'ID de base de règle pour chaque étape, le contenu spécifique de la règle (pas seulement le nom), les formules de calcul, les sources des paramètres, les annotations de confiance. Utilisez scripts/enhanced_display.py pour la visualisation. Mots-clés déclencheurs : raisonnement, sélection, calcul, analyse, base de connaissances, ontologie, régulation de pression de gaz, alarme gaz.
