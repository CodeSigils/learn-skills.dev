Palantir Ontology Practice версии 3.2 — структурированный граф знаний + механизм правил + методология научного рассуждения. Используется для рассуждений, анализа выбора, запросов к базе знаний. **Результаты рассуждения должны отображать подробный процесс рассуждения**: включать требования пользователя, идентификатор основы правила для каждого шага, конкретное содержание правила (а не только имя), формулы расчета, источники параметров, достоверные аннотации. Используйте скрипты/enhanced_display.py для визуализации. Ключевые слова-триггеры: рассуждение, выбор, расчет, анализ, база знаний, онтология, регулирование давления газа, газовая сигнализация.
