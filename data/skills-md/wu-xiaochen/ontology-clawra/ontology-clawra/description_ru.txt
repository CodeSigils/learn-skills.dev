Онтология Palantir на практике v3.2 – структурированный граф знаний + механизм правил + методология научного рассуждения. Используется для логических вычислений, анализа выбора и запросов к базе знаний. **Результаты вывода должны отображать подробный процесс рассуждения**: включать требования пользователя, идентификатор основы правила для каждого шага, конкретное содержимое правила (а не только имя), формулы расчета, источники параметров и достоверные аннотации. Визуализируйте с помощью scripts/enhanced_display.py. Ключевые слова-триггеры: 推理, 选型, 计算, 分析, 知识库, 本体, 燃气调压, 燃气报警器.
