Palantir Ontology Practice Versión v3.2: gráfico de conocimiento estructurado + motor de reglas + metodología de razonamiento científico. Para cálculo de razonamiento, análisis de selección y consultas de bases de conocimientos. **Los resultados del razonamiento deben mostrar el proceso de razonamiento detallado**: incluya los requisitos del usuario, el ID de la base de la regla para cada paso, el contenido específico de la regla (no el nombre), las fórmulas de cálculo, las fuentes de los parámetros y las anotaciones de confianza. Utilice scripts/enhanced_display.py para la visualización. Palabras clave desencadenantes: razonamiento, selección, cálculo, análisis, base de conocimientos, ontología, regulación de presión de gas, alarma de gas.
