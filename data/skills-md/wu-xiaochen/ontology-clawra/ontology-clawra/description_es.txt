Palantir Ontology Practice Versión 3.2: Gráfico de conocimiento estructurado + Motor de reglas + Metodología de razonamiento científico. Se utiliza para cálculo de razonamiento, análisis de selección y consultas de bases de conocimientos. **Los resultados del razonamiento deben mostrar el proceso de razonamiento detallado**: incluya los requisitos del usuario, el ID de la base de la regla para cada paso, el contenido específico de la regla (no solo el nombre), las fórmulas de cálculo, las fuentes de los parámetros y las anotaciones de confianza. Utilice scripts/enhanced_display.py para la visualización. Palabras clave desencadenantes: razonamiento, selección, cálculo, análisis, base de conocimientos, ontología, regulación de presión de gas, alarma de gas.
