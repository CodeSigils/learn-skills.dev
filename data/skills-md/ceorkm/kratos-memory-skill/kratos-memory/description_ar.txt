نظام ذاكرة مستمر لوكلاء تشفير الذكاء الاصطناعي. استخدم هذا بشكل استباقي - لا تنتظر أن يُطلب منك ذلك. في بداية الجلسة، تحقق مما يتذكره كراتوس عن المشروع الحالي. أثناء العمل، قم بحفظ إصلاحات الأخطاء وقرارات التصميم وكيفية عمل الأشياء والدروس المستفادة. في نهاية الجلسة، احفظ ملخصًا إذا تم إنجاز عمل مهم. المحفزات: أي جلسة برمجة، أو أي عمل في المشروع، عندما يشرح المستخدم شيئًا مهمًا، بعد إصلاح الأخطاء، بعد اتخاذ القرارات، عند الانضمام إلى قاعدة التعليمات البرمجية، عندما يقول المستخدم "تذكر"، "احفظ هذا"، "ماذا تعرف عنه"، أو يسأل عن السياق السابق.
