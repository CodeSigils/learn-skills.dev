Sistema di memoria persistente per agenti di codifica AI. Usalo in modo PROATTIVO: non aspettare che ti venga chiesto. All'inizio della sessione, controlla cosa ricorda Kratos del progetto attuale. Durante il lavoro, salva le correzioni di bug, le decisioni sull'architettura, il funzionamento delle cose e le lezioni apprese. Al termine della sessione, salva un riepilogo se è stato svolto un lavoro significativo. Trigger: qualsiasi sessione di codifica, qualsiasi lavoro di progetto, quando l'utente spiega qualcosa di importante, dopo aver corretto i bug, dopo aver preso decisioni, durante l'onboarding in una base di codice, quando l'utente dice "ricorda", "salva questo", "cosa sai" o chiede informazioni sul contesto precedente.
