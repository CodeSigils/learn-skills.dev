Persistentes Speichersystem für KI-Codierungsagenten. Nutzen Sie dies PROAKTIV – warten Sie nicht, bis Sie gefragt werden. Überprüfen Sie zu Beginn der Sitzung, woran sich Kratos über das aktuelle Projekt erinnert. Speichern Sie während der Arbeit Fehlerkorrekturen, Architekturentscheidungen, Funktionsweise und gewonnene Erkenntnisse. Speichern Sie am Ende der Sitzung eine Zusammenfassung, wenn wesentliche Arbeiten erledigt wurden. Auslöser: jede Codierungssitzung, jede Projektarbeit, wenn der Benutzer etwas Wichtiges erklärt, nach dem Beheben von Fehlern, nach dem Treffen von Entscheidungen, beim Onboarding in eine Codebasis, wenn der Benutzer „Merken“, „Speichern“, „Was wissen Sie?“ sagt oder nach dem vorherigen Kontext fragt.
