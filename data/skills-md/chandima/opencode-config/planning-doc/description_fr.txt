Créez ou mettez à jour les documents de planification PLAN.md. À utiliser lorsque les utilisateurs demandent à créer un
plan, document de planification, plan de projet, feuille de route ou flux de travail basé sur un plan.
Déclencheurs : « élaborer un plan », « créer un plan », « plan de projet », « feuille de route »,
« suivre les progrès », « mettre à jour le plan ».
NE PAS utiliser pour : les listes de tâches, le suivi des problèmes, la documentation générale ou
Fichiers README.
