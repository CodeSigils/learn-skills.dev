Dateibasierter Arbeitskontext für Codierungsagenten unter Verwendung eines kompakten globalen Arbeitsspeichers, dauerhafter Referenznotizen und datierter Aufgabenaufzeichnungen für die meisten schreibtragenden Arbeiten. Wird verwendet, wenn ein Repository den Agentenkontext in „docs/memory.md“, „docs/reference/“ und „docs/tasks/...“ behält oder behalten sollte, damit spätere Sitzungen die Arbeit fortsetzen können, ohne den Status von Grund auf neu erstellen zu müssen.
