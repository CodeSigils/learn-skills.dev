Contexto de trabajo basado en archivos para agentes de codificación que utilizan una memoria de trabajo global compacta, notas de referencia duraderas y registros de tareas fechados para la mayoría de los trabajos con escritura. Úselo cuando un repositorio mantiene, o debería comenzar a mantener, el contexto del agente en `docs/memory.md`, `docs/reference/` y `docs/tasks/...` para que las sesiones posteriores puedan reanudar el trabajo sin reconstruir el estado desde cero.
