Рабочий контекст на основе файлов для агентов кодирования, использующий компактную глобальную рабочую память, надежные справочные заметки и датированные записи задач для большинства операций записи. Используйте, когда репозиторий хранит или должен начать хранить контекст агента в `docs/memory.md`, `docs/reference/` и `docs/tasks/...`, чтобы последующие сеансы могли возобновить работу без восстановления состояния с нуля.
