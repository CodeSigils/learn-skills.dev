يُستخدم عندما تحتاج ميزة عبر الطبقات، أو الترحيل، أو التكامل، أو المنفذ، أو إعادة البناء، أو المراجعة، أو إصلاح الأخطاء، أو تخطيط التصميم إلى مالك واحد للمستخدم/المجال عبر واجهة المستخدم، أو المسار، أو حالة العميل، أو الأمر، أو واجهة برمجة التطبيقات، أو التخزين، أو الوقت الفعلي، أو المحول، أو طبقات العرض التقديمي. تشغيل الأسماء المستعارة للهوية، ودورة الحياة/الحالة، والأذونات/الإمكانيات، وقواعد المسار/الاستعلام، وحمولات الأوامر، وإسقاط النتائج/الحدث، ودلالات الحداثة/الاحتياطي/المراجعة عبر التمثيلات، أو ترجمة التوافق، أو قواعد المعنى المكررة، أو تمثيلات متعددة لنفس معنى المستخدم/المجال. لا تستخدم لاكتشاف المالك للقراءة فقط، أو تنظيف التدفق المحلي بعد أن يصبح المالكون واضحين، أو عمل استجابة/حداثة غير متزامنة، أو التحكم في النطاق وحده.
