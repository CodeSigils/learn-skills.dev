Claude Desktop (Cowork + Code タブ) および Claude Code ターミナル CLI の完全な会話ログからその週のすべての作業内容を抽出することにより、週次レビュー レポート (内部レビュー + 公開週報) を自動的に生成します。このスキルは、ユーザーが次のシナリオのいずれかに言及するたびに使用する必要があります: 週次レポートの作成、週次レポートの生成、週次概要、週次レビュー、週次要約、今週の要約、週次ジャーナル、公開週次ジャーナル、社内週次レポート、今週やったこと、今週のレビュー。ユーザーが単に「週次レポートを書くのを手伝って」、「今週の要約」、または「今週何をしましたか」と言った場合でも、自動的にトリガーされる必要があります。
