Claude Desktop (Cowork + Code タブ) および Claude Code ターミナル CLI の完全な会話履歴からその週のすべての作業内容を抽出することにより、週次レビューとレポート (個別の内部レビューと公開週次ジャーナル) を自動的に生成します。ユーザーが次のいずれかに言及するたびに、このスキルを使用します: 週次レポートの作成、週次レポートの生成、週次概要、週次レビュー、週次要約、今週の要約、週次日誌、公開週次日誌、社内週次レポート、今週何をしたか、または今週のレビュー。ユーザーが単に「週次レポートを書くのを手伝って」、「今週の要約」、または「今週何をした」と言っただけでも、このスキルは自動的にトリガーされます。
