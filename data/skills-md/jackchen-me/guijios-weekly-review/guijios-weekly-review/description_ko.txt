Claude Desktop(Cowork + Code 탭)의 전체 대화 로그와 Claude Code 터미널 CLI에서 해당 주의 모든 업무 내용을 추출하여 주간 리뷰 보고서(내부 리뷰 + 공개 주간 저널)를 자동으로 생성합니다. 이 스킬은 사용자가 주간 보고서 작성, 주간 보고서 생성, 주간 요약, 주간 검토, 주간 요약, 이번 주 요약, 주간 일지, 공개 주간 일지, 내부 주간 보고서, 이번 주에 한 일, 이번 주 검토 등의 시나리오 중 하나를 언급할 때마다 사용해야 합니다. 사용자가 단순히 "주간 보고서 작성을 도와주세요", "이번 주 요약" 또는 "이번 주에 무엇을 했는지"라고 말하면 자동으로 트리거되어야 합니다.
