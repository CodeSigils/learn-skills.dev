Wird verwendet, wenn ein KI-Agent die lokale Calicat-CLI bedienen muss, um Designdaten, Interaktionsdaten, PRD-Daten, Canvas-/Seitenstruktur oder Screenshots aus Calicat-Links oder Datei-IDs zu extrahieren. Wird insbesondere dann ausgelöst, wenn der Benutzer eine Calicat-Design-URL angibt, den Agent auffordert, die Datei-ID, die Canvas-ID oder die Layer-ID korrekt zu analysieren, oder eine Frontend-Implementierung für die gesamte Leinwand anfordert, die Seitendaten schrittweise abrufen muss, anstatt den gesamten Design-JSON auf einmal zu laden. Verwenden Sie dies auch, wenn der Agent vor dem Fortfahren überprüfen muss, ob die lokale Calicat-CLI installiert ist, ihre Version überprüfen oder entscheiden muss, ob eine CLI-Aktualisierungs-/Installationsanleitung erforderlich ist.
