Úselo cuando un agente de IA necesite operar la CLI de Calicat local para extraer datos de diseño, datos de interacción, datos PRD, estructura de lienzo/página o capturas de pantalla de enlaces de Calicat o identificadores de archivos. Se activa especialmente cuando el usuario proporciona una URL de diseño de Calicat, le pide al agente que analice file_id, canvas id o Layer id correctamente, o solicita una implementación de frontend de lienzo completo que debe recuperar los datos de la página progresivamente en lugar de cargar todo el diseño JSON a la vez. Úselo también cuando el agente necesite verificar si la CLI de Calicat local está instalada, verificar su versión o decidir si es necesaria la guía de actualización/instalación de la CLI antes de continuar.
