يُستخدم عندما يحتاج وكيل الذكاء الاصطناعي إلى تشغيل Calicat CLI المحلي لاستخراج بيانات التصميم أو بيانات التفاعل أو بيانات PRD أو بنية اللوحة القماشية/الصفحة أو لقطات الشاشة من روابط Calicat أو معرفات الملفات. يتم التشغيل بشكل خاص عندما يقدم المستخدم عنوان URL لتصميم Calicat، أو يطلب من الوكيل تحليل file_id، أو معرف اللوحة القماشية، أو معرف الطبقة بشكل صحيح، أو يطلب تنفيذ الواجهة الأمامية للوحة القماشية بالكامل والتي يجب أن تجلب بيانات الصفحة تدريجيًا بدلاً من تحميل كل تصميم JSON مرة واحدة. استخدمه أيضًا عندما يحتاج الوكيل إلى التحقق من تثبيت Calicat CLI المحلي، أو التحقق من إصداره، أو تحديد ما إذا كانت هناك حاجة إلى إرشادات تحديث/تثبيت CLI قبل المتابعة.
