Используйте, когда агенту ИИ необходимо управлять локальным CLI Calicat для извлечения данных проекта, данных взаимодействия, данных PRD, структуры холста/страницы или снимков экрана из ссылок Calicat или идентификаторов файлов. Триггер особенно запускается, когда пользователь предоставляет URL-адрес дизайна Calicat, просит агента правильно проанализировать file_id, идентификатор холста или идентификатор слоя или запрашивает реализацию интерфейса всего холста, которая должна постепенно получать данные страницы вместо загрузки всего JSON дизайна сразу. Также используйте, когда агенту необходимо проверить, установлен ли локальный CLI Calicat, проверить его версию или решить, необходимы ли инструкции по обновлению/установке CLI, прежде чем продолжить.
