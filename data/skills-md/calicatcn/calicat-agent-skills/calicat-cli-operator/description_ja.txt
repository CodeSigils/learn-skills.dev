AI エージェントがローカルの Calicat CLI を操作して、デザイン データ、インタラクション データ、PRD データ、キャンバス/ページ構造、またはスクリーンショットを Calicat リンクまたはファイル ID から抽出する必要がある場合に使用します。特にユーザーが Calicat デザイン URL を提供する場合、エージェントに file_id、キャンバス ID、またはレイヤー ID を正しく解析するように要求する場合、またはすべてのデザイン JSON を一度にロードするのではなくページ データを段階的にフェッチする必要があるキャンバス全体のフロントエンド実装を要求する場合にトリガーされます。また、エージェントがローカルの Calicat CLI がインストールされているかどうかを確認したり、そのバージョンを確認したり、続行する前に CLI の更新/インストールのガイダンスが必要かどうかを判断したりする必要がある場合にも使用します。
