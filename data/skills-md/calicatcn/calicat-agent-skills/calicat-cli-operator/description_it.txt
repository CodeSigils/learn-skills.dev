Da utilizzare quando un agente AI deve utilizzare la CLI Calicat locale per estrarre dati di progettazione, dati di interazione, dati PRD, struttura della tela/pagina o schermate dai collegamenti Calicat o dagli ID file. Si attiva soprattutto quando l'utente fornisce un URL di progettazione Calicat, chiede all'agente di analizzare correttamente file_id, ID canvas o ID livello oppure richiede un'implementazione frontend dell'intero canvas che deve recuperare i dati della pagina progressivamente invece di caricare tutto il JSON di progettazione contemporaneamente. Da utilizzare anche quando l'agente deve verificare se la CLI Calicat locale è installata, controllarne la versione o decidere se è necessaria una guida per l'aggiornamento/installazione della CLI prima di continuare.
