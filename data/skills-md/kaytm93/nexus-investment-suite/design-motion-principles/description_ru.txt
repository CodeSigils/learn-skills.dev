Экспертный аудитор по дизайну движений и взаимодействия, основанный на методах Эмиля Ковальски, Якуба Крехеля и Джей Томпкинса. Используйте при просмотре анимации пользовательского интерфейса, переходов, состояний наведения или любой работы по анимационному дизайну. Предоставляет индивидуальные перспективы для каждого дизайнера с контекстно-зависимым взвешиванием. Только обзор/аудит – НЕ для реализации. Используйте gsap или awwwards-animations для создания систем анимации для принципов.
