Flujo de trabajo estándar de un extremo a otro para enviar una función/corrección de errores de una tarea de Jira a un GitLab MR fusionado. Úselo cuando el usuario hace referencia a un ID de tarea de Jira (WRA-XX, etc.), solicita "iniciar una tarea", "crear rama a partir de la tarea", "revisar el último cambio"/"revisar cambio" (opcionalmente con la palabra clave "simplificar", por ejemplo, "revisar cambio simplificar", para limpiar automáticamente antes de revisar), "revisar toda la rama", "confirmar y enviar", "crear una solicitud de fusión", "revisar el MR !N", "publicar el resultado de la revisión en el MR", "solucionar todos los problemas" o "fusionar la solicitud". Cubre la denominación de ramas, el formato de confirmación, la creación de MR, la revisión de código micro + macro (paralelo de 3 agentes), el bucle de corrección y la fusión.
