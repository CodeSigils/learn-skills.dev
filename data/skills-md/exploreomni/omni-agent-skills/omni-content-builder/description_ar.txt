يمكنك إنشاء مستندات ولوحات معلومات Omni Analytics وتحديثها وإدارتها برمجيًا - دورة حياة المستند والمسودات والتجانبات والمرئيات والمرشحات وعناصر التحكم والتخطيطات - باستخدام Omni CLI. استخدم هذه المهارة عندما يريد شخص ما إنشاء لوحة معلومات، أو إنشاء مصنف، أو إضافة إطارات متجانبة أو مخططات، أو تكوين عوامل تصفية أو عناصر تحكم لوحة المعلومات، أو تحديث نموذج لوحة معلومات موجودة، أو إعداد عرض مؤشرات الأداء الرئيسية، أو إنشاء تصورات، أو تخطيط لوحة معلومات، أو ترتيب الإطارات المتجانبة أو الصفحات، أو إنشاء مستند، أو تحرير لوحة معلومات كمسودة، أو نشر مسودة، أو تغيير إعدادات لوحة المعلومات، أو إعادة تسمية مصنف، أو حذف لوحة معلومات، أو نقل مستند إلى مجلد، أو تكرار لوحة معلومات، أو أي نوع مختلف من "إنشاء لوحة معلومات لـ" أو "إنشاء تقرير" عرض"، أو "إضافة مخطط إلى"، أو "إنشاء لوحة معلومات"، أو "تحديث تخطيط لوحة المعلومات"، أو "إعادة تسمية هذا المستند"، أو "نشر هذه المسودة"، أو "الانتقال إلى المجلد"، أو "حذف لوحة المعلومات هذه". استخدمه أيضًا عند تعديل تخصيصات النموذج على مستوى لوحة المعلومات مثل الصلات أو الحقول الخاصة بالمصنف.
