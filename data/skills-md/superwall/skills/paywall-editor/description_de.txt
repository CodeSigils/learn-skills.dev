Erstellen und bearbeiten Sie Live-Superwall-Paywalls über die CLI. Stellen Sie mithilfe eines Kopplungscodes eine Verbindung zu einer laufenden Browser-Editor-Sitzung her, listen Sie die Tools auf, die der Browser gerade verfügbar macht, und rufen Sie sie auf. Behandelt native sw-*-Elemente, Bearbeitungsworkflow, Designstandards und den Lebenszyklus „Anhängen/Aufrufen/Freigeben“. Verwenden Sie es immer dann, wenn der Benutzer eine Superwall-Paywall, ein Onboarding oder einen Web2App-Flow entwerfen, erstellen, ändern oder überprüfen möchte.
