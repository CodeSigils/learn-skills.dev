Scrive il corpo di una richiesta pull: il riepilogo, le sezioni del modello di repository e le indicazioni per il revisore, ad esempio l'ordine di lettura consigliato e le aree di interesse. Da utilizzare durante la stesura o la revisione di una descrizione PR, la compilazione di un modello PR di un repository, l'aggiornamento di una descrizione che non corrisponde più al ramo o la preparazione di un ramo per la revisione. Usalo anche quando l'utente dice solo "apri un PR", "mettilo per la revisione" o "scrivilo" senza nominare la descrizione.
