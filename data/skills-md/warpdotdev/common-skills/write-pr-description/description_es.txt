Escribe el cuerpo de una solicitud de extracción: el resumen, las secciones de la plantilla del repositorio y la guía del revisor, como un orden de lectura recomendado y áreas de enfoque. Úselo siempre que redacte o revise una descripción de PR, complete la plantilla de PR de un repositorio, actualice una descripción que ya no coincide con la rama o prepare una rama para su revisión. Úselo incluso cuando el usuario solo diga "abrir un PR", "poner esto para revisión" o "escribir esto" sin nombrar la descripción.
