Rédige le corps d’une pull request - le résumé, les sections du modèle du dépôt et les consignes pour le réviseur, comme un ordre de lecture recommandé et les zones d’attention. Utilise‑le chaque fois que tu rédiges ou révises la description d’une PR, remplis le modèle de PR du dépôt, rafraîchis une description qui ne correspond plus à la branche, ou prépares une branche pour la révision. Utilise‑le même lorsque l’utilisateur se contente de dire « ouvrir une PR », « mettre cela en revue » ou « rédiger cela » sans nommer la description.
