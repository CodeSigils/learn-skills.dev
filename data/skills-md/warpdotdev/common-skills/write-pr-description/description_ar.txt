يكتب نص طلب السحب - الملخص، وأقسام قالب المستودع، وتوجيهات المراجع مثل أمر القراءة الموصى به ومجالات التركيز. يُستخدم عند صياغة أو مراجعة وصف العلاقات العامة، أو ملء قالب العلاقات العامة الخاص بالمستودع، أو تحديث الوصف الذي لم يعد يطابق الفرع، أو إعداد فرع للمراجعة. استخدمه حتى عندما يقول المستخدم فقط "افتح PR" أو "ضع هذا للمراجعة" أو "اكتب هذا" دون تسمية الوصف.
