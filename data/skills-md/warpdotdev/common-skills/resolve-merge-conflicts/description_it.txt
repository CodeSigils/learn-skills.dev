Risolvi i conflitti di unione Git estraendo solo percorsi non risolti, blocchi di conflitto e differenze compatte invece di caricare interi file nel contesto. Da utilizzare quando un'operazione di unione, rebase, cherry-pick o stash pop si interrompe in caso di conflitti, quando "git status" mostra percorsi non uniti o quando i file contengono indicatori di conflitto.
