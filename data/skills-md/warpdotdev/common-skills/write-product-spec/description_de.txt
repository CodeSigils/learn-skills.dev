Schreiben Sie eine PRODUCT.md-Spezifikation für eine wichtige benutzerorientierte Funktion in Warp, die sich auf detailliertes Verhalten und Validierung konzentriert. Verwenden Sie diese Option, wenn der Benutzer nach einer Produktspezifikation, einem Dokument zum gewünschten Verhalten oder einem PRD fragt, das Funktionsverhalten vor der Implementierung definieren möchte oder wenn die Funktion umfangreich oder verhaltensmäßig so unklar ist, dass eine schriftliche Spezifikation die Implementierung oder Überprüfung verbessern würde.
