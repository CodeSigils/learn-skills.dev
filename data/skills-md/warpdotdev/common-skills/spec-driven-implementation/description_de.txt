Fördern Sie einen spezifikationsorientierten Workflow für wesentliche Funktionen, indem Sie PRODUCT.md vor der Implementierung schreiben, TECH.md schreiben, wenn dies gerechtfertigt ist, und beide Spezifikationen auf dem neuesten Stand halten, während sich die Implementierung weiterentwickelt. Verwenden Sie diese Option, wenn Sie eine wichtige Funktion starten, eine agentengesteuerte Implementierung planen oder wenn der Benutzer möchte, dass Produkt- und technische Spezifikationen in die Quellcodeverwaltung überprüft werden.
