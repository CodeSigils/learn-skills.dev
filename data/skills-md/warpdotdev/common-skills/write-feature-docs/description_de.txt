Entwerfen Sie eine vollständige Dokumentationsseite für eine neue Warp-Funktion aus der PRODUCT.md- und/oder TECH.md-Spezifikation. Verwenden Sie diese Option, wenn ein Ingenieur eine Spezifikation geschrieben hat und einen ersten MDX-Entwurf für das warpdotdev/docs-Repository erstellen muss. Behandelt auch Funktionen ohne Spezifikationen, indem zuerst die Codebasis untersucht wird. Rufen Sie diese Fähigkeit immer dann auf, wenn ein Ingenieur das Schreiben von Dokumenten für ein Feature, das Entwerfen einer Dokumentseite, das Erstellen einer Feature-Dokumentation, das Starten des Eng-Docs-Workflows oder das Konvertieren einer Spezifikation in eine Dokumentation erwähnt. Funktioniert von Warp-internal oder Warp-Server.
