Prepara una pagina di documentazione completa per una nuova funzionalità Warp dalle specifiche PRODUCT.md e/o TECH.md. Da utilizzare quando un ingegnere ha scritto una specifica e deve produrre una bozza MDX di primo passaggio per il repository warpdotdev/docs. Gestisce anche le funzionalità senza specifiche ricercando prima la base di codice. Richiama questa competenza ogni volta che un ingegnere menziona la scrittura di documenti per una funzionalità, la stesura di una pagina di documenti, la creazione di documentazione di funzionalità, l'avvio del flusso di lavoro dei documenti eng o la conversione di una specifica in documentazione. Funziona da warp-internal o warp-server.
