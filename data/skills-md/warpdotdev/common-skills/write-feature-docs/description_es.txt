Redacte una página de documentación completa para una nueva función Warp a partir de su especificación PRODUCT.md y/o TECH.md. Úselo cuando un ingeniero haya escrito una especificación y necesite producir un borrador MDX de primer paso para el repositorio warpdotdev/docs. También maneja funciones sin especificaciones investigando primero el código base. Invoque esta habilidad cada vez que un ingeniero mencione escribir documentos para una función, redactar una página de documentos, crear documentación de funciones, iniciar el flujo de trabajo de eng-docs o convertir una especificación en documentación. Funciona desde warp-internal o warp-server.
