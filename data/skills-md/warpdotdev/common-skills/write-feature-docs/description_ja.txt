PRODUCT.md および/または TECH.md 仕様から、新しい Warp 機能の完全なドキュメント ページの草案を作成します。エンジニアが仕様を作成し、warpdotdev/docs リポジトリのファーストパス MDX ドラフトを作成する必要がある場合に使用します。最初にコードベースを調査することで、仕様のない機能にも対応します。エンジニアが機能のドキュメントの作成、ドキュメント ページの草稿、機能ドキュメントの作成、eng-docs ワークフローの開始、または仕様のドキュメントへの変換について言及するたびに、このスキルを呼び出します。 warp-internal または warp-server から動作します。
