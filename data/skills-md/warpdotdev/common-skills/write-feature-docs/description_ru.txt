Создайте полную страницу документации для новой функции Warp из спецификации PRODUCT.md и/или TECH.md. Используйте, когда инженер написал спецификацию и ему необходимо создать первоначальный черновой вариант MDX для репозитория warpdotdev/docs. Также обрабатывает функции без спецификаций, предварительно исследуя кодовую базу. Используйте этот навык всякий раз, когда инженер упоминает о написании документации для какой-либо функции, создании черновика страницы документации, создании документации по функциям, запуске рабочего процесса eng-docs или преобразовании спецификации в документацию. Работает с варп-внутреннего или варп-сервера.
