Rédigez une page de documentation complète pour une nouvelle fonctionnalité Warp à partir de ses spécifications PRODUCT.md et/ou TECH.md. À utiliser lorsqu'un ingénieur a rédigé une spécification et doit produire un premier brouillon MDX pour le dépôt warpdotdev/docs. Gère également les fonctionnalités sans spécifications en recherchant d'abord la base de code. Invoquez cette compétence chaque fois qu'un ingénieur mentionne la rédaction de documents pour une fonctionnalité, la rédaction d'une page de documentation, la création de documentation sur les fonctionnalités, le démarrage du flux de travail eng-docs ou la conversion d'une spécification en documentation. Fonctionne depuis warp-internal ou warp-server.
