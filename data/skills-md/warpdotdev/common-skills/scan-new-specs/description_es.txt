Escanee warpdotdev/warp y warp-server en busca de especificaciones de PRODUCT.md recientemente fusionadas que aún no tengan un PR de documentos correspondiente en warpdotdev/docs. Cuando se encuentra una especificación completa, genera automáticamente un borrador de documento completo PR y etiqueta al ingeniero. Cuando una especificación es demasiado delgada para realizar borradores, envía un ping directamente al ingeniero. Diseñado para funcionar como agente ambiental Oz programado (por ejemplo, cada 2 o 3 días). Utilícelo al configurar el activador automático de documentos o al ejecutar un barrido manual de cobertura de documentos.
