Überprüfen Sie einen Pull-Request-Diff und schreiben Sie strukturiertes Feedback an review.json, damit der Workflow veröffentlicht werden kann. Verwenden Sie diese Option, wenn Sie eine ausgecheckte PR anhand lokaler Artefakte wie pr_diff.txt und pr_description.txt überprüfen und eine maschinenlesbare Überprüfungsausgabe erstellen, anstatt sie direkt auf GitHub zu veröffentlichen.
