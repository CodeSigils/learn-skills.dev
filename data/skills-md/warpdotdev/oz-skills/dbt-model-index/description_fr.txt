Fournissez un index de recherche de modèles DBT (tables BigQuery) pour guider l'écriture de requêtes sur un entrepôt de données. À utiliser lorsque vous avez besoin d'interroger, d'analyser ou de rechercher des données dans un entrepôt de données alimenté par dbt, ou lorsque vous résolvez une vague question de données dans les bonnes tables BigQuery à interroger.
