Stellen Sie einen Suchindex von DBT-Modellen (BigQuery-Tabellen) bereit, um das Schreiben von Abfragen für ein Data Warehouse zu steuern. Verwenden Sie diese Funktion, wenn Sie Daten in einem dbt-basierten Data Warehouse abfragen, analysieren oder nachschlagen müssen oder wenn Sie eine vage Datenfrage in die richtigen BigQuery-Tabellen für die Abfrage lösen möchten.
