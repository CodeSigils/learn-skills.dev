Запустите проверку кода с двумя агентами: создайте два новых агента с чистым контекстом, которые параллельно исследуют ОДНУ и ту же самую зафиксированную ветвь. Один агент запускает встроенную команду Кодекса `codex review --base`, а другой независимо проверяет код на соответствие рекомендациям Google «На что обращать внимание при проверке кода». Объедините оба результата в один отчет с рейтингом по соглашению. Используйте это всякий раз, когда пользователь запрашивает «проверку всех», проверку второго мнения, двойную проверку, перекрестную проверку перед PR или проверку с максимальной уверенностью внесенных изменений ветки. Не используйте его для ПРИМЕНЕНИЯ исправлений; это только обзор.
