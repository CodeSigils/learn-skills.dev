Exécutez une révision de code à deux agents : générez deux nouveaux agents à contexte propre qui examinent en parallèle la MÊME différence de branche validée. Un agent exécute la commande native « codex review --base » du Codex, tandis que l'autre examine indépendamment le code par rapport aux conseils de Google « Que rechercher dans une révision de code ». Fusionnez les deux résultats dans un seul rapport classé par accord. Utilisez-le chaque fois que l'utilisateur demande un « examen complet », un deuxième avis, un double examen, une vérification croisée avant un PR ou un examen de confiance maximale des modifications de branche engagées. Ne l'utilisez pas pour APPLIQUER des correctifs ; il s'agit uniquement d'une révision.
