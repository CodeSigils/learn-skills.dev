Ejecute una revisión de código de dos agentes: genere dos agentes nuevos y de contexto limpio que examinen la MISMA diferencia de rama comprometida en paralelo. Un agente ejecuta el comando nativo `codex review --base` de Codex, mientras que el otro revisa de forma independiente el código según la guía de Google "Qué buscar en una revisión de código". Fusione ambos resultados en un informe clasificado según acuerdo. Utilícelo siempre que el usuario solicite una "revisión de todo", una revisión de segunda opinión, una revisión dual, una verificación cruzada antes de un PR o una revisión de máxima confianza de los cambios de rama comprometidos. No lo utilice para APLICAR correcciones; es sólo para revisión.
