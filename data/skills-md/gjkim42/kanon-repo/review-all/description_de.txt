Führen Sie eine Codeüberprüfung mit zwei Agenten durch: Erzeugen Sie zwei neue Agenten mit sauberem Kontext, die den GLEICHEN bestätigten Zweigunterschied parallel untersuchen. Ein Agent führt den nativen Codex-Befehl „codex review --base“ aus, während der andere den Code unabhängig anhand der Google-Anleitung „Worauf Sie bei einer Codeüberprüfung achten sollten“ überprüft. Führen Sie beide Ergebnisse in einem Bericht mit Übereinstimmungsrang zusammen. Verwenden Sie dies immer dann, wenn der Benutzer eine Gesamtüberprüfung, eine Zweitmeinungsüberprüfung, eine Doppelüberprüfung, eine Gegenprüfung vor einer PR oder eine Überprüfung festgeschriebener Zweigänderungen mit maximaler Zuverlässigkeit anfordert. Verwenden Sie es nicht zum ANWENDEN von Korrekturen; Es ist nur eine Rezension vorbehalten.
