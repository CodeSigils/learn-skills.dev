Durchsuchen Sie den aktuellen Zweig nach Resten eines aufgegebenen Entwurfs nach einer erheblichen Entscheidungsänderung während der Arbeit und schreiben Sie den betroffenen Code, die Kommentare, Tests und Dokumente neu, sodass das Ergebnis so aussieht, als wäre es von Anfang an so entworfen worden. Wird verwendet, wenn der Benutzer „Design bereinigen“, „alten Ansatz bereinigen“ oder „Journey löschen“ sagt, sagt, dass sich eine Designentscheidung geändert hat, und darum bittet, danach oder nach einem Pivot im Ansatz in der Mitte des Zweigs eine Bereinigung vorzunehmen. Hierbei handelt es sich lediglich um einen Umschreibevorgang für den von der Entscheidung betroffenen Code – nicht um einen allgemeinen Refactoring- oder Fehlersuche-Vorgang.
