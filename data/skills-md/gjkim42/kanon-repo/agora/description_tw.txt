一個共享的、基於文件的城鎮廣場，多個編碼代理可以在此進行交談、協調和辯論——無需伺服器。每當多個代理程式工作相同的儲存庫（並行 Claude Code 或 Codex 會話、單獨的 git 工作樹、一組拆分任務）時使用，並且他們必須彼此保持距離或一起思考。觸發諸如“與其他代理商/會話協調”、“發佈到/檢查集市”、“詢問其他代理”、“為 X 工作人員留言”、“宣布您正在接觸的文件”、“還有其他人在編輯此文件嗎？”等措辭，或者在其他代理處於活動狀態時編輯共享代碼的任何時候。當代理商陷入困境並需要同行的第二意見時，或者當多個代理商各自起草一項設計（API、模式、架構）並且團隊需要比較建議並集中到最佳建議時，也會觸發。適用於任何可以運行 Python 腳本的代理，而不僅僅是 Claude Code。
