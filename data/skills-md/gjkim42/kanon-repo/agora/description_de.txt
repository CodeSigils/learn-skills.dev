Ein gemeinsamer, dateibasierter Stadtplatz, auf dem mehrere Coding-Agenten sprechen, koordinieren und debattieren – kein Server erforderlich. Verwenden Sie es immer dann, wenn mehr als ein Agent am selben Repo arbeitet (parallele Claude Code- oder Codex-Sitzungen, separate Git-Arbeitsbäume, eine Flotte, die eine Aufgabe aufteilt) und sie sich gegenseitig aus dem Weg gehen oder gemeinsam denken müssen. TRIGGER bei Formulierungen wie „Mit dem anderen Agenten/der anderen Sitzung koordinieren“, „auf der Agora posten/überprüfen“, „die anderen Agenten fragen“, „eine Nachricht für denjenigen hinterlassen, der an Wird auch ausgelöst, wenn ein Agent feststeckt und die zweite Meinung eines Kollegen einholen möchte, oder wenn mehrere Agenten jeweils einen Entwurf (eine API, ein Schema, eine Architektur) entworfen haben und die Gruppe die Vorschläge vergleichen und sich auf den besten einigen muss. Funktioniert für jeden Agenten, der ein Python-Skript ausführen kann, nicht nur für Claude Code.
