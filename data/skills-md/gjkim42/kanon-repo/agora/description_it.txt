Una piazza cittadina condivisa basata su file in cui più agenti di codifica parlano, coordinano e dibattono, senza bisogno di server. Da utilizzare ogni volta che più di un agente lavora sullo stesso repository (sessioni parallele di Claude Code o Codex, alberi di lavoro git separati, una flotta che divide un'attività) e devono tenersi lontani l'uno dall'altro o pensare insieme. TRIGGER su frasi come "coordinarsi con l'altro agente/sessione", "pubblicare/controllare l'agorà", "chiedere agli altri agenti", "lasciare un messaggio a chiunque stia lavorando su X", "annunciare quali file si sta toccando", "qualcun altro lo sta modificando?" o ogni volta che si sta per modificare il codice condiviso mentre altri agenti sono attivi. Si attiva anche quando un agente è bloccato e desidera la seconda opinione di un pari, o quando diversi agenti hanno redatto ciascuno un progetto (un'API, uno schema, un'architettura) e il gruppo deve confrontare le proposte e convergere su quella migliore. Funziona con qualsiasi agente in grado di eseguire uno script Python, non solo con Claude Code.
