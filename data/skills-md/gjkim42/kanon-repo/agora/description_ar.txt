ساحة مدينة مشتركة قائمة على الملفات حيث يتحدث العديد من وكلاء البرمجة وينسقون ويناقشون - لا يلزم وجود خادم. يُستخدم عندما يعمل أكثر من وكيل في نفس الريبو (جلسات Claude Code أو Codex المتوازية، أو أشجار عمل git منفصلة، ​​أو أسطول يقسم المهمة) ويجب عليهم الابتعاد عن طريق بعضهم البعض أو التفكير معًا. قم بتشغيل عبارات مثل "التنسيق مع الوكيل/الجلسة الأخرى"، "النشر إلى/التحقق من أغورا"، "اسأل الوكلاء الآخرين"، "اترك رسالة لمن يعمل على X"، "أعلن عن الملفات التي تلمسها"، "هل يقوم أي شخص آخر بتحرير هذا؟"، أو في أي وقت تكون فيه على وشك تحرير التعليمات البرمجية المشتركة بينما يكون الوكلاء الآخرون مباشرين. يتم تشغيله أيضًا عندما يكون الوكيل عالقًا ويريد الحصول على رأي ثانٍ من نظيره، أو عندما يقوم العديد من الوكلاء بصياغة تصميم (واجهة برمجة تطبيقات، مخطط، بنية) وتحتاج المجموعة إلى مقارنة المقترحات والتقارب حول أفضلها. يعمل مع أي وكيل يمكنه تشغيل برنامج Python النصي، وليس فقط مع Claude Code.
