Esamina il ramo Kelos corrente o un PR, un problema o una differenza esplicitamente specificati per verificare la qualità della progettazione dell'API Kubernetes e del CRD. Da utilizzare quando viene richiesta una revisione dell'API Kelos, una revisione della compatibilità CRD/API, una revisione della convenzione API Kubernetes o una revisione delle modifiche in api/, CRD generati, esempi/ o manifest di autosviluppo/. Il valore predefinito è il ramo corrente quando non è specificata alcuna destinazione. Questa competenza è di sola revisione.
