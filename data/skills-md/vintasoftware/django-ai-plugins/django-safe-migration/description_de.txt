Schreiben, überprüfen und überschreiben Sie Django-Migrationen für PostgreSQL mit Null-Ausfallzeit-Garantie. Verwenden Sie diesen Skill immer dann, wenn der Benutzer Migrationen, Django-Schemaänderungen oder Bereitstellungssicherheit erwähnt – auch wenn er nicht ausdrücklich „null Ausfallzeiten“ sagt. Auslösen bei: „Überprüfen Sie diese Migration“, „Ist diese Migration sicher?“, „Schreiben Sie eine Migration für ...“, „schreiben Sie diese Migration neu“, „Wie füge ich eine NOT NULL-Spalte hinzu / lösche eine Spalte / füge einen Index hinzu / benenne eine Spalte um / füge einen FK ohne Ausfallzeit hinzu“, „Führt diese Migration zu Sperren?“, „Diese Migration blockiert die Produktion“. Deckt ab: SeparateDatabaseAndState-Zwei-Datei-Splits, AddIndexConcurrently, FK NOT VALID + VALIDATE, db_default für NOT NULL-Spalten, lock_timeout und RunPython-Sicherheitsregeln.
