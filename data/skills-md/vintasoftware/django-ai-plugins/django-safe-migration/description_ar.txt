كتابة ومراجعة وإعادة كتابة عمليات ترحيل Django لـ PostgreSQL مع ضمانات عدم التوقف مطلقًا. استخدم هذه المهارة عندما يذكر المستخدم عمليات الترحيل، أو تغييرات مخطط Django، أو أمان النشر - حتى لو لم يذكر "صفر توقف عن العمل" بشكل صريح. تشغيل: "مراجعة هذا الترحيل"، "هل هذا الترحيل آمن؟"، "اكتب ترحيلًا لـ..."، "أعد كتابة هذا الترحيل"، "كيف يمكنني إضافة عمود غير فارغ / إسقاط عمود / إضافة فهرس / إعادة تسمية عمود / إضافة FK بدون وقت توقف عن العمل"، "هل سيؤدي هذا الترحيل إلى حدوث أقفال؟"، "هذا الترحيل يمنع الإنتاج". يغطي: تقسيمات الملفين SeparateDatabaseAndState، AddIndexConcurrently، FK NOT VALID + VALIDATE، db_default للأعمدة NOT NULL، lock_timeout، وقواعد أمان RunPython.
