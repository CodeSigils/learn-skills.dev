Создавайте, проверяйте и переписывайте миграции Django для PostgreSQL с гарантиями нулевого времени простоя. Используйте этот навык всякий раз, когда пользователь упоминает миграцию, изменение схемы Django или безопасность развертывания — даже если он явно не говорит «нулевое время простоя». Триггер: «проверить эту миграцию», «безопасна ли эта миграция?», «написать миграцию для...», «переписать эту миграцию», «как мне добавить столбец NOT NULL / удалить столбец / добавить индекс / переименовать столбец / добавить FK без простоя», «вызовет ли эта миграция блокировки?», «эта миграция блокирует производство». Охватывает: разделение двух файлов SeparateDatabaseAndState, AddIndexConcurrently, FK NOT VALID + VALIDATE, db_default для столбцов NOT NULL, lock_timeout и правила безопасности RunPython.
