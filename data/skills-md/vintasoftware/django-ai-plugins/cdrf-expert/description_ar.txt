إرشادات الخبراء لطرق العرض المستندة إلى الفصل الدراسي لـ Django REST Framework باستخدام Classy DRF (https://www.cdrf.co). يُستخدم عند تحديد أو تصحيح أخطاء APIView، أو GenericAPIView، أو طرق العرض العامة الملموسة، أو مجموعات المزج، أو سلوك ViewSet/GenericViewSet/ModelViewSet؛ ترتيب دقة أسلوب التتبع (MRO)؛ فهم الطريقة التي يجب تجاوزها (`إنشاء` مقابل `perform_create`، `update` مقابل `perform_update`، `destroy` vs `perform_destroy`، `get_queryset`، `get_serializer_class`)؛ ومقارنة السلوك عبر إصدارات DRF. لا تستخدمه مع طرق العرض المستندة إلى الوظائف، أو GraphQL، أو FastAPI/Flask، أو عمل الواجهة الأمامية، أو أطر عمل الواجهة الخلفية غير DRF.
