Verwenden Sie diese Funktion, wenn Sie ein Gespräch zwischen Hauptagent und Agent beginnen. Die Routen durchlaufen Duru-Fähigkeiten, Duru-Gedächtnis und Duru-Gateway, bevor eine Antwort oder Aktion erfolgt, einschließlich der Klärung von Fragen. Überspringen Sie nur für Subagenten, es sei denn, ihre Aufgabe erfordert Duru-Routing.
