Scansiona i siti web ed estrai contenuti da più pagine tramite la CLI di Tavily. Utilizza questa capacità quando l'utente desidera eseguire la scansione di un sito, scaricare documentazione, estrarre un'intera sezione di documenti, estrarre pagine in blocco, salvare un sito come file di markdown locale o dice "scansione", "ottieni tutte le pagine", "scarica i documenti", "estrai tutto in /docs", "estrai in blocco" o ha bisogno di contenuti da molte pagine sullo stesso dominio. Supporta il controllo di profondità/ampiezza, il filtraggio del percorso, le istruzioni semantiche e il salvataggio di ogni pagina come file di markdown locale.
