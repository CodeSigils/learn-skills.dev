コンテキスト分離によるプログラムによる Web 検索。このスキルは、生の HTML やボイラープレートでコンテキスト ウィンドウを汚すことなく、Web を検索し、結果をフィルタリングし、特定の情報を抽出する必要があるあらゆるリサーチ タスクに使用できます。これは、Web リサーチのデフォルトのスキルです。 「検索」、「調べる」、「見つける」、「リサーチ」、「最新情報」、または最新の Web 情報を必要とするクエリによってトリガーされます。また、「検索とフィルタリング」、「重要な部分の検索」、または「重要な詳細の抽出」を求められた場合にも使用します。これは、ユーザーが精選されたノイズのないコンテンツを必要とするあらゆる場合に使用します。
