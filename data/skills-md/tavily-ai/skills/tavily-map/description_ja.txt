Tavily CLI を使用して、コンテンツを抽出せずに Web サイト上のすべての URL を検出してリストします。このスキルは、ユーザーが大規模なサイト上の特定のページを検索する場合、すべての URL をリストする場合、サイト構造を確認する場合、ドメイン上の何かがある場所を検索する場合、または「サイトをマップする」、「URL を検索する」、「どのページがあるか」、「すべてのページをリストする」、または「サイト構造」を要求する場合に使用します。クロールより高速 — URL のみを返します。サイトのことは知っているが、正確なページはわからない場合に重要です。抽出と組み合わせて、ターゲットを絞ったコンテンツを取得します。
