Découvrez et répertoriez toutes les URL d'un site Web sans extraire de contenu, via la CLI Tavily. Utilisez cette compétence lorsque l'utilisateur souhaite rechercher une page spécifique sur un grand site, répertorier toutes les URL, voir la structure du site, trouver où se trouve quelque chose sur un domaine ou dire « cartographier le site », « trouver l'URL de », « quelles pages se trouvent », « répertorier toutes les pages » ou « structure du site ». Plus rapide que l'exploration : renvoie uniquement les URL. Indispensable quand on connaît le site mais pas la page exacte. Combinez avec un extrait pour une récupération de contenu ciblée.
