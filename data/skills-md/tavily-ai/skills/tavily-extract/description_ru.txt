Извлекайте чистую уценку или текстовый контент из определенных URL-адресов с помощью интерфейса командной строки Tavily. Используйте этот навык, когда у пользователя есть один или несколько URL-адресов и он хочет получить их контент, говорит «извлечь», «захватить контент», «вытащить текст», «получить страницу», «прочитать эту веб-страницу» или ему нужен чистый текст с веб-страниц. Обрабатывает страницы, отображаемые с помощью JavaScript, возвращает уценку, оптимизированную для LLM, и поддерживает фрагментацию, ориентированную на запросы, для целевого извлечения. Может обрабатывать до 20 URL-адресов за один вызов.
