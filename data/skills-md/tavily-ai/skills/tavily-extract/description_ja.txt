Tavily CLI を介して、特定の URL からクリーンなマークダウンまたはテキスト コンテンツを抽出します。このスキルは、ユーザーが 1 つ以上の URL を持っており、そのコンテンツを必要とする場合、「抽出する」、「コンテンツを取得する」、「テキストを取得する」、「ページを取得する」、「この Web ページを読む」といった場合、または Web ページからクリーン テキストが必要な場合に使用します。 JavaScript でレンダリングされたページを処理し、LLM に最適化されたマークダウンを返し、ターゲットを絞った抽出のためのクエリ中心のチャンクをサポートします。 1 回の呼び出しで最大 20 個の URL を処理できます。
