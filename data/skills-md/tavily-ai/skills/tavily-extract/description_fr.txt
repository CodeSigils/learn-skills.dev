Extrayez des démarques propres ou du contenu texte à partir d'URL spécifiques via la CLI Tavily. Utilisez cette compétence lorsque l'utilisateur possède une ou plusieurs URL et souhaite que son contenu, dit « extraire », « récupérer le contenu de », « extraire le texte de », « obtenir la page sur », « lire cette page Web » ou a besoin d'un texte propre à partir de pages Web. Gère les pages rendues en JavaScript, renvoie une démarque optimisée pour LLM et prend en charge le regroupement axé sur les requêtes pour une extraction ciblée. Can process up to 20 URLs in a single call.
