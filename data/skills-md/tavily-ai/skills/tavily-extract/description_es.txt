Extraiga rebajas limpias o contenido de texto de URL específicas a través de la CLI de Tavily. Utilice esta habilidad cuando el usuario tenga una o más URL y quiera su contenido, diga "extraer", "tomar el contenido de", "extraer el texto de", "obtener la página en", "leer esta página web" o necesite texto limpio de las páginas web. Maneja páginas renderizadas en JavaScript, devuelve rebajas optimizadas para LLM y admite fragmentación centrada en consultas para una extracción específica. Puede procesar hasta 20 URL en una sola llamada.
