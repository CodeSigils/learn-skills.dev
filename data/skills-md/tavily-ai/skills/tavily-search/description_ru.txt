Выполняйте поиск в Интернете с результатами, оптимизированными для LLM, с помощью интерфейса командной строки Tavily. Используйте этот навык, когда пользователь хочет выполнить поиск в Интернете, найти статьи, информацию, получить последние новости, открыть источники или сказать «найти», «найти меня», «поискать», «что нового», «найти статьи о» или ему нужна текущая информация из Интернета. Возвращает релевантные результаты с фрагментами контента, оценками релевантности и метаданными, оптимизированными для использования в рамках LLM. Поддерживает фильтрацию доменов, временные диапазоны и несколько глубин поиска.
