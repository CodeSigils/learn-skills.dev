Búsqueda web, extracción de contenido, rastreo e investigación profunda a través de Tavily CLI. Utilice esta habilidad siempre que el usuario quiera buscar en la web, encontrar artículos, investigar un tema, buscar algo en línea, extraer contenido de una URL, obtener texto de una página web, rastrear documentación, descargar las páginas de un sitio, descubrir URL en un dominio o realizar una investigación en profundidad con citas. Utilícelo también cuando diga "buscar esta página", "extraer el contenido de", "obtener la página en https://", "búsqueme artículos sobre" o haga referencia a la extracción de datos de sitios web externos. Esto proporciona búsqueda web optimizada para LLM, extracción de contenido, rastreo de sitios, descubrimiento de URL e investigación profunda impulsada por IA, capacidades que van más allá de lo que los agentes pueden hacer de forma nativa. NO active operaciones de archivos locales, comandos git, implementaciones o tareas de edición de código.
