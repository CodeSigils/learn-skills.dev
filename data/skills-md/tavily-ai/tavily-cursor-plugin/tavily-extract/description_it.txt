Estrai markdown pulito o contenuto di testo da URL specifici tramite la CLI di Tavily. Utilizza questa abilità quando l'utente ha uno o più URL e desidera il suo contenuto, dice "estrai", "prendi il contenuto da", "estrai il testo da", "trova la pagina in", "leggi questa pagina web" o ha bisogno di testo pulito dalle pagine web. Gestisce pagine con rendering JavaScript, restituisce markdown ottimizzato per LLM e supporta la suddivisione in blocchi incentrata sulle query per l'estrazione mirata. Può elaborare fino a 20 URL in una singola chiamata.
