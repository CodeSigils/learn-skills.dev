Rastree sitios web y extraiga contenido de varias páginas a través de la CLI de Tavily. Utilice esta habilidad cuando el usuario desee rastrear un sitio, descargar documentación, extraer una sección de documentos completa, extraer páginas de forma masiva, guardar un sitio como archivos de rebajas locales o decir "rastrear", "obtener todas las páginas", "descargar los documentos", "extraer todo en /docs", "extraer de forma masiva" o necesite contenido de muchas páginas en el mismo dominio. Admite control de profundidad/amplitud, filtrado de rutas, instrucciones semánticas y guardar cada página como un archivo de rebajas local.
