Tavily CLI を介した Web 検索、コンテンツ抽出、クローリング、および詳細な調査。このスキルは、ユーザーが Web の検索、記事の検索、トピックの調査、オンラインでの検索、URL からのコンテンツの抽出、Web ページからのテキストの取得、ドキュメントのクロール、サイトのページのダウンロード、ドメイン上の URL の検出、または引用を使用した詳細な調査を行う場合に使用します。 「このページを取得する」、「コンテンツを取得する」、「https:// でページを取得する」、「に関する記事を検索する」、または外部 Web サイトからデータを抽出する参照を言う場合にも使用します。これにより、LLM に最適化された Web 検索、コンテンツ抽出、サイト クローリング、URL 検出、AI を活用した詳細な調査など、エージェントがネイティブに実行できる機能を超えた機能が提供されます。ローカル ファイル操作、git コマンド、デプロイメント、またはコード編集タスクに対してトリガーしないでください。
