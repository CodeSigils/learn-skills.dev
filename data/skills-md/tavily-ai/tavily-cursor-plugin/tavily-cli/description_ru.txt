Веб-поиск, извлечение контента, сканирование и глубокие исследования с помощью интерфейса командной строки Tavily. Используйте этот навык всякий раз, когда пользователь хочет выполнить поиск в Интернете, найти статьи, изучить тему, поискать что-то в Интернете, извлечь контент из URL-адреса, получить текст с веб-страницы, просканировать документацию, загрузить страницы сайта, обнаружить URL-адреса в домене или провести углубленное исследование с цитатами. Также используйте, когда они говорят «получите эту страницу», «извлеките контент», «получите страницу по адресу https://», «найдите мне статьи» или ссылку на извлечение данных с внешних веб-сайтов. Это обеспечивает оптимизированный для LLM веб-поиск, извлечение контента, сканирование сайтов, обнаружение URL-адресов и глубокие исследования на базе искусственного интеллекта — возможности, выходящие за рамки того, что агенты могут делать изначально. НЕ запускайте запуск для локальных файловых операций, команд git, развертываний или задач редактирования кода.
