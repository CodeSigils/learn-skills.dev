Recherche sur le Web, extraction de contenu, exploration et recherche approfondie via la CLI Tavily. Utilisez cette compétence chaque fois que l'utilisateur souhaite effectuer une recherche sur le Web, trouver des articles, rechercher un sujet, rechercher quelque chose en ligne, extraire le contenu d'une URL, extraire du texte d'une page Web, explorer la documentation, télécharger les pages d'un site, découvrir des URL sur un domaine ou effectuer des recherches approfondies avec des citations. Utilisez également lorsqu'ils disent « récupérer cette page », « extraire le contenu de », « obtenir la page sur https:// », « trouver des articles sur » ou faire référence à l'extraction de données à partir de sites Web externes. Cela fournit une recherche Web optimisée pour LLM, une extraction de contenu, une exploration de sites, une découverte d'URL et une recherche approfondie basée sur l'IA — des capacités au-delà de ce que les agents peuvent faire de manière native. Ne déclenchez PAS les opérations sur les fichiers locaux, les commandes git, les déploiements ou les tâches d'édition de code.
