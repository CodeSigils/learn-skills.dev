Esta habilidad debe usarse cuando el usuario quiera escribir, revisar o refactorizar código TypeScript para seguir las mejores prácticas de la industria. Los desencadenantes comunes incluyen "seguir las mejores prácticas de ts", "revisar este texto mecanografiado", "corregir el estilo del texto mecanografiado", "crear este texto mecanografiado idiomático", "aplicar convenciones de mecanografiado" y "auditar este archivo ts". Se hornea en tipos de marca, uniones discriminadas, ts-pattern para lógica de múltiples ramas, JSDoc en exportaciones, nomenclatura de archivos kebab-case y convenciones *Params/*Options object-arg. Omita cuando el usuario quiera refactorizadores funcionales puros (use ts-best-practices-functional) o esté escribiendo componentes del marco (React/Vue/Svelte tienen convenciones diferentes).
