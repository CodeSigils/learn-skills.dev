Cette compétence doit être utilisée lorsque l'utilisateur souhaite écrire, réviser ou refactoriser du code TypeScript pour suivre les meilleures pratiques de l'industrie. Les déclencheurs courants incluent « suivre les meilleures pratiques ts », « réviser ce script dactylographié », « corriger le style dactylographié », « créer ce script dactylographié idiomatique », « appliquer les conventions dactylographiées » et « auditer ce fichier ts ». Bake dans des types de marque, des unions discriminées, un modèle ts pour une logique multi-branches, JSDoc sur les exportations, la dénomination des fichiers kebab-case et les conventions d'argument d'objet *Params/*Options. Ignorer lorsque l'utilisateur souhaite des refactors fonctionnels purs (utilisez ts-best-practices-Functional) ou écrit des composants de framework (React/Vue/Svelte ont des conventions différentes).
