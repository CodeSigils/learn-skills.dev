Questa competenza deve essere utilizzata quando l'utente desidera scrivere, rivedere o effettuare il refactoring del codice TypeScript per seguire le migliori pratiche del settore. I trigger comuni includono "segui le migliori pratiche di ts", "rivedi questo dattiloscritto", "correggi lo stile del dattiloscritto", "crea questo dattiloscritto idiomatico", "applica le convenzioni del dattiloscritto" e "controlla questo file ts". Cuoce in tipi con marchio, unioni discriminate, modello ts per logica multi-ramo, JSDoc sulle esportazioni, denominazione file kebab-case e convenzioni oggetto-arg *Params/*Options. Salta quando l'utente desidera refactor funzionali puri (usa ts-best-practices-functional) o sta scrivendo componenti del framework (React/Vue/Svelte hanno convenzioni diverse).
