このスキルは、ユーザーが既存のエージェント スキルに対してベースライン評価を実行する場合、モデルのアップグレード後にトランスクリプトを再生成する場合、またはスキルが作成時のギャップをまだ解決しているかどうかを確認する場合に使用する必要があります。一般的なトリガーには、「ベースラインの再実行」、「スキル X の再評価」、「すべてのスキルのテスト」、「スキル ドリフトのチェック」、「評価の実行」などがあります。逐語的なトランスクリプトのキャプチャ (言い換えなし)、決定論のみのグレーディング (regex / contains / file_exists — 判断としての LLM なし)、および反復 N ワークスペース規則をベイクします。新しいスキルを作成する場合（スキルクリエーターを使用する場合）、またはスキルのコンテンツを直接変更する場合はスキップしてください。
