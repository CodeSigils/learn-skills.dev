Cette compétence doit être utilisée lorsque l'utilisateur souhaite refactoriser le code TypeScript en modèles fonctionnels ou écrire un nouveau code suivant la doctrine fonctionnelle. Les déclencheurs courants incluent "rendre ceci fonctionnel", "supprimer la classe", "utiliser le résultat au lieu de lancer", "arrêter de muter ceci" et "refactoriser vers la fonction d'usine". Bake dans les fonctions d'usine sur les classes, Result<T,E> sur les exceptions, l'état immuable via spread/map/filter et les fonctions pures composées dans des pipelines. Ignorer lorsque l'utilisateur souhaite une hygiène générale TS (utiliser les meilleures pratiques ts), que la classe encapsule un SDK avec état (PrismaClient, Octokit, WebSocket) ou qu'un framework nécessite une classe.
