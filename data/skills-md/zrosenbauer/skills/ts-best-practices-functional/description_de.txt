Diese Fähigkeit sollte verwendet werden, wenn der Benutzer TypeScript-Code in funktionale Muster umgestalten oder neuen Code gemäß der funktionalen Doktrin schreiben möchte. Zu den üblichen Auslösern gehören „dies funktionsfähig machen“, „die Klasse entfernen“, „Ergebnis anstelle von werfen verwenden“, „Mutierung beenden“ und „zur Factory-Funktion umgestalten“. Backt Factory-Funktionen über Klassen, Result<T,E> über Ausnahmen, unveränderlichen Zustand über Spread/Map/Filter und reine Funktionen, die in Pipelines komponiert sind. Überspringen Sie, wenn der Benutzer allgemeine TS-Hygiene wünscht (verwenden Sie ts-best-practices), die Klasse ein zustandsbehaftetes SDK (PrismaClient, Octokit, WebSocket) umschließt oder ein Framework eine Klasse erfordert.
