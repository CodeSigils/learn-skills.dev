Этот навык следует использовать, когда пользователь хочет провести рефакторинг кода TypeScript с использованием функциональных шаблонов или написать новый код в соответствии с функциональной доктриной. Общие триггеры включают «сделать это функциональным», «удалить класс», «использовать результат вместо throw», «прекратить изменять это» и «рефакторинг до заводской функции». Запекает фабричные функции для классов, Result<T,E> для исключений, неизменяемое состояние через распространение/карту/фильтр и чистые функции, составленные в конвейерах. Пропускайте, когда пользователю нужна общая гигиена TS (используйте ts-best-practies), класс обертывает SDK с отслеживанием состояния (PrismaClient, Octokit, WebSocket) или инфраструктуре требуется класс.
