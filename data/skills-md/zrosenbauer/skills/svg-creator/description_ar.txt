يجب استخدام هذه المهارة عندما يريد المستخدم إنشاء أصول SVG أو إصلاحها أو تحويلها في أي مشروع — لافتات أو شارات أو أيقونات أو شعارات أو نماذج بالحجم الطبيعي للنوافذ/IDE أو لقطات شاشة طرفية أو عقد مخططات. تتضمن المشغلات الشائعة "إنشاء ملف SVG"، و"إنشاء لافتة"، و"تصميم رمز"، و"رسم شعار"، و"إصلاح مربع العرض"، و"تحويل SVG إلى PNG"، و"معاينة SVG هذا". يتم خبزه في نظام viewBox من الحافة إلى الحافة (`viewBox="0 0 W H"` - بدون حشوة أو إزاحات)، وألوان سداسية مضمنة (لا يمكن لـ SVG قراءة متغيرات CSS)، وخادم معاينة محلي قائم على العقدة للمتصفح + التحقق من لقطة الشاشة لـ chrome-devtools MCP، والتحويل المعتمد على الوضوح إلى PNG / JPEG / WebP / AVIF. قم بالتخطي عندما يكون الأصل نقطيًا تمامًا (بدون مصدر SVG) أو عندما يكون ملف PNG الموجود فقط بحاجة إلى التحرير.
