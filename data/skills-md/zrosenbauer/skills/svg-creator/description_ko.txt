이 기술은 사용자가 배너, 배지, 아이콘, 로고, 창/IDE 모형, 터미널 스크린샷 또는 다이어그램 노드 등 모든 프로젝트에서 SVG 자산을 생성, 수정 또는 변환하려고 할 때 사용해야 합니다. 일반적인 트리거에는 "SVG 만들기", "배너 만들기", "아이콘 디자인", "로고 그리기", "viewBox 수정", "SVG를 PNG로 변환" 및 "이 SVG 미리 보기"가 포함됩니다. 가장자리 전체 viewBox 규칙(`viewBox="0 0 W H"` - 패딩 없음, 오프셋 없음), 하드코딩된 16진수 색상(SVG는 CSS 변수를 읽을 수 없음), 브라우저 + chrome-devtools MCP 스크린샷 확인을 위한 노드 기반 로컬 미리보기 서버 및 PNG/JPEG/WebP/AVIF로의 선명한 기반 변환을 베이크합니다. 자산이 순수 래스터(SVG 소스 없음)이거나 기존 PNG만 편집해야 하는 경우 건너뜁니다.
