当用户想要在任何项目中创建、修复或转换 SVG 资源（横幅、徽章、图标、徽标、窗口/IDE 模型、终端屏幕截图或图表节点）时，应使用此技能。常见的触发器包括“创建 SVG”、“制作横幅”、“设计图标”、“绘制徽标”、“修复 viewBox”、“将 SVG 转换为 PNG”和“预览此 SVG”。烘焙边缘到边缘的 viewBox 规则（`viewBox="0 0 W H"` — 无填充，无偏移）、硬编码的十六进制颜色（SVG 无法读取 CSS 变量）、用于浏览器 + chrome-devtools MCP 屏幕截图验证的基于节点的本地预览服务器，以及基于锐利的 PNG / JPEG / WebP / AVIF 转换。当资源是纯光栅（无 SVG 源）或仅现有 PNG 需要编辑时跳过。
