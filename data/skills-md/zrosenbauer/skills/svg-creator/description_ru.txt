Этот навык следует использовать, когда пользователь хочет создать, исправить или преобразовать ресурсы SVG в любом проекте — баннеры, значки, значки, логотипы, макеты окон/IDE, снимки экрана терминала или узлы диаграмм. Общие триггеры включают «создать SVG», «создать баннер», «разработать значок», «нарисовать логотип», «исправить viewBox», «конвертировать SVG в PNG» и «предварительный просмотр этого SVG». Запекается в дисциплине viewBox от края до края (`viewBox="0 0 WH"` — без отступов и смещений), жестко закодированных шестнадцатеричных цветов (SVG не может читать переменные CSS), локального сервера предварительного просмотра на базе узла для браузера + проверка снимков экрана MCP с помощью chrome-devtools и четкого преобразования в PNG / JPEG / WebP / AVIF. Пропустите, если ресурс является чисто растровым (без источника SVG) или когда требуется редактирование только существующего PNG.
