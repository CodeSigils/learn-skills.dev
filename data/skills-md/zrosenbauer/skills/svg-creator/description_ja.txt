このスキルは、ユーザーがプロジェクト内のバナー、バッジ、アイコン、ロゴ、ウィンドウ/IDE モックアップ、端末のスクリーンショット、またはダイアグラム ノードなどの SVG アセットを作成、修正、または変換する場合に使用する必要があります。一般的なトリガーには、「SVG の作成」、「バナーの作成」、「アイコンのデザイン」、「ロゴの描画」、「viewBox の修正」、「SVG から PNG への変換」、「この SVG のプレビュー」などがあります。エッジツーエッジの viewBox 規則 (`viewBox="0 0 W H"` — パディングなし、オフセットなし)、ハードコードされた 16 進カラー (SVG は CSS 変数を読み取ることができません)、ブラウザー用のノードベースのローカル プレビュー サーバー + chrome-devtools MCP スクリーンショット検証、および PNG / JPEG / WebP / AVIF へのシャープベースの変換でベイク処理します。アセットが純粋にラスターである (SVG ソースがない) 場合、または既存の PNG のみを編集する必要がある場合はスキップします。
