當使用者想要在任何專案中建立、修復或轉換 SVG 資源（橫幅、徽章、圖示、徽標、視窗/IDE 模型、終端螢幕截圖或圖表節點）時，應使用此技能。常見的觸發器包括「建立 SVG」、「製作橫幅」、「設計圖示」、「繪製徽標」、「修復 viewBox」、「將 SVG 轉換為 PNG」和「預覽此 SVG」。烘焙邊緣到邊緣的 viewBox 規則（`viewBox="0 0 W H"` — 無填充，無偏移）、硬編碼的十六進位顏色（SVG 無法讀取 CSS 變數）、用於瀏覽器 + -devtools MCP 螢幕截圖驗證的基於節點的本地預覽伺服器，以及基於銳利的 PNG / JPEG / WebP 轉換。當資源是純光柵（無 SVG 來源）或僅現有 PNG 需要編輯時跳過。
