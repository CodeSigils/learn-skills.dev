Dieser Skill sollte verwendet werden, wenn der Benutzer prüfen möchte, ob ein Agenten-Skill anbieterübergreifend portierbar ist. Zu den häufigsten Auslösern gehören „Ist dieser Skill anbieterübergreifend sicher“, „Funktioniert mein Skill im Cursor“, „Skill-Kompatibilität prüfen“, „Überprüfen Sie, ob dieser im Codex geladen wird“ und „Welche Anbieter unterstützen diesen Skill“. Erzeugt einen Agenten pro Anbieter parallel für maßgebliche llms.txt-Dokumente und erstellt eine Kompatibilitätsmatrix sowie einen COMPAT.md-Bericht. Überspringen Sie, wenn Sie einen neuen Skill erstellen (Skill-Creator verwenden) oder Baselines erneut ausführen (Skill-Eval verwenden).
