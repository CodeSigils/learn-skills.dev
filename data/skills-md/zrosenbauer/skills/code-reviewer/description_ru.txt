Этот навык следует использовать, когда пользователь хочет просмотреть код, проверить различия, получить второе мнение об изменениях или провести состязательную проверку. Общие триггеры включают в себя «проверка этого кода», «проверка этой разницы», «найти проблемы», «второе мнение по этому поводу», «жесткая проверка», «проверка PR», «состязательная проверка» и «проверка безопасности». Выбирает один из четырех профилей рецензента (противоборческий, безопасность, архитектура, производительность), поддерживает подрежим PR через `gh pr diff` и может передаваться любому обнаруженному AI CLI для получения второго мнения по перекрестной модели. Пропускайте, когда пользователю нужны исправления форматирования (используйте линтер) или шаблоны рефакторинга (используйте ts-best-practices или ts-best-practice-functional).
