Cette compétence doit être utilisée lorsque l'utilisateur souhaite réviser le code, auditer une différence, obtenir un deuxième avis sur les modifications ou effectuer un examen contradictoire. Les déclencheurs courants incluent « examiner ce code », « auditer cette différence », « rechercher des problèmes dans », « un deuxième avis à ce sujet », « un examen approfondi de », « examiner le PR », « un examen contradictoire » et « un examen de sécurité de ». Sélectionne l'un des quatre personnages d'examinateurs (confrontation, sécurité, architecture, performances), prend en charge un sous-mode PR via « gh pr diff » et peut le transmettre à n'importe quelle CLI AI détectée pour un deuxième avis inter-modèles. Ignorer lorsque l'utilisateur souhaite des correctifs de formatage (utilisez un linter) ou des modèles de refactorisation (utilisez ts-best-practices ou ts-best-practices-fonctionnelles).
