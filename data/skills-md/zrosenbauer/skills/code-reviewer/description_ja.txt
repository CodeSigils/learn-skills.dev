このスキルは、ユーザーがコードをレビューしたり、差分を監査したり、変更についてセカンドオピニオンを得たり、敵対的レビューを実行したりするときに使用する必要があります。一般的なトリガーには、「このコードをレビューする」、「この差分を監査する」、「問題を見つける」、「これに関するセカンドオピニオン」、「厳しいレビュー」、「PR をレビューする」、「敵対的なレビュー」、および「セキュリティレビュー」が含まれます。 4 つのレビュアー ペルソナ (敵対者、セキュリティ、アーキテクチャ、パフォーマンス) から 1 つを選択し、「gh pr diff」を介して PR サブモードをサポートし、モデル間のセカンドオピニオンとして検出された AI CLI に引き継ぐことができます。ユーザーが書式設定の修正 (リンターを使用) またはリファクタリング パターン (ts-best-practices または ts-best-practices-Functional を使用) を必要とする場合はスキップします。
