이 기술은 사용자가 코드 검토, 차이점 감사, 변경 사항에 대한 2차 의견 얻기 또는 적대적 검토 실행을 원할 때 사용해야 합니다. 일반적인 트리거에는 "이 코드 검토", "이 차이 감사", "문제 찾기", "이에 대한 두 번째 의견", "가혹한 검토", "PR 검토", "적대적 검토" 및 "보안 검토"가 포함됩니다. 4가지 검토자 페르소나(적대적, 보안, 아키텍처, 성능) 중 하나를 선택하고 'gh pr diff'를 통해 PR 하위 모드를 지원하며 교차 모델 2차 의견을 위해 감지된 AI CLI에 전달할 수 있습니다. 사용자가 형식 수정(linter 사용) 또는 리팩토링 패턴(ts-best-practices 또는 ts-best-practices-functioning)을 원하는 경우 건너뜁니다.
