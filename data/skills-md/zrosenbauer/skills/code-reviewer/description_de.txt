Diese Fähigkeit sollte verwendet werden, wenn der Benutzer Code überprüfen, einen Unterschied prüfen, eine zweite Meinung zu Änderungen einholen oder eine kontradiktorische Überprüfung durchführen möchte. Zu den häufigsten Auslösern gehören „Diesen Code überprüfen“, „Diesen Unterschied prüfen“, „Probleme finden in“, „Zweite Meinung dazu“, „Harte Überprüfung von“, „Überprüfen Sie die PR“, „Gegnerische Überprüfung“ und „Sicherheitsüberprüfung von“. Wählt eine von vier Prüferpersönlichkeiten aus (Gegner, Sicherheit, Architektur, Leistung), unterstützt einen PR-Untermodus über „gh pr diff“ und kann eine modellübergreifende Zweitmeinung an jede erkannte KI-CLI übergeben. Überspringen Sie, wenn der Benutzer Formatierungskorrekturen (verwenden Sie einen Linter) oder Refactoring-Muster (verwenden Sie ts-best-practices oder ts-best-practices-Functional) wünscht.
