استخدمه عندما تحتاج إلى تحديد المنطقة الجغرافية، أو الجمهور المستهدف، أو اللغة الأساسية لموقع الويب، والحصول على توصيات لتحسين الترجمة عبر الحدود. مفيد لأبحاث السوق، أو عمليات تدقيق الترجمة، أو عمليات فحص hreflang، أو فهم التركيز الديموغرافي للموقع. يستهدف مواقع الويب متعددة اللغات وعابرة للحدود (على سبيل المثال، متاجر Shopify العالمية، ومواقع SaaS متعددة اللغات)، وليس المواقع المحلية أحادية اللغة.
