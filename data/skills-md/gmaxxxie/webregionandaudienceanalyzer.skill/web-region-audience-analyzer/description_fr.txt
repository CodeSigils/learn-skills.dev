À utiliser lorsque vous devez déterminer la région géographique, le public cible ou la langue principale d'un site Web et obtenir des recommandations d'optimisation de localisation transfrontalière. Utile pour les études de marché, les audits de localisation, les vérifications hreflang ou pour comprendre l'orientation démographique d'un site. Cible les sites Web transfrontaliers multilingues (par exemple, les magasins internationaux Shopify, les sites SaaS multilingues), NON les sites nationaux monolingues.
