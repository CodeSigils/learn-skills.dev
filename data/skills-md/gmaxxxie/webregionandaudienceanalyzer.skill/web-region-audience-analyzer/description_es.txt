Úselo cuando necesite determinar la región geográfica, el público objetivo o el idioma principal de un sitio web y obtener recomendaciones de optimización de localización transfronteriza. Útil para investigaciones de mercado, auditorías de localización, comprobaciones de hreflang o para comprender el enfoque demográfico de un sitio. Se dirige a sitios web transfronterizos multilingües (por ejemplo, tiendas globales Shopify, sitios SaaS multilingües), NO a sitios nacionales de un solo idioma.
