Индекс навыков Unified Express.js — охватывает безопасность API, аутентификацию и авторизацию, интеграцию базы данных с Prisma, настройку среды, обработку ошибок, проверку ввода с помощью Zod, ведение журнала и мониторинг с помощью Pino, архитектуру промежуточного программного обеспечения, модульную структуру проекта, дизайн REST API и документацию Swagger/OpenAPI. Используйте это как точку входа; он делегирует соответствующие файлы поднавыков для каждого домена.
