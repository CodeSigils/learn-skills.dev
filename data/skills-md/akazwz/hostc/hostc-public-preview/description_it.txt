Utilizza hostc quando un agente deve esporre un server di sviluppo locale come URL di anteprima pubblica temporanea, condividere localhost con un altro dispositivo o compagno di squadra, testare webhook rispetto a un'app locale o creare un tunnel pubblico per localhost. Attiva l'anteprima pubblica, condividi l'app locale, esponi localhost, tunnel localhost, anteprima webhook, anteprima remota o richieste simili.
