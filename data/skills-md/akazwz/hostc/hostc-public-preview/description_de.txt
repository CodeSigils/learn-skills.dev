Verwenden Sie hostc, wenn ein Agent einen lokalen Entwicklungsserver als temporäre öffentliche Vorschau-URL verfügbar machen, localhost mit einem anderen Gerät oder Teamkollegen teilen, Webhooks für eine lokale App testen oder einen öffentlichen Tunnel für localhost erstellen muss. Bei öffentlicher Vorschau auslösen, lokale App teilen, lokalen Host verfügbar machen, lokalen Host tunneln, Webhook-Vorschau, Remote-Vorschau oder ähnliche Anfragen.
