Пользовательский модуль pdf-cli: управление личной информацией, список файлов, история операций, управление ключами API, отправка отзывов. Используется, когда пользователям необходимо просмотреть/изменить личную информацию, управлять файлами и историей, создать/удалить ключи API или отправить отзыв.
