Пользовательский модуль pdf-cli: управление личной информацией, список файлов, история операций, управление ключами API, отправка отзывов. Используется, когда пользователям необходимо просмотреть/редактировать личную информацию, управлять файлами и историей операций, создавать/удалять ключи API или отправлять отзывы.
