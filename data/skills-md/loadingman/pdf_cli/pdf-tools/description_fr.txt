Module d'outils pdf-cli : traite les PDF via des chaînes de tâches asynchrones core/tools. Prend en charge la fusion, le fractionnement, la conversion, la rotation, la compression, les filigranes, l'extraction/suppression de pages, les numéros de page, les superpositions, l'extraction de contenu, les métadonnées, les paramètres de sécurité et les requêtes de tâches. Utilisé lors de la manipulation de fichiers PDF.
