Modulo strumento pdf-cli: elabora i PDF tramite catene di attività asincrone core/strumenti. Supporta l'unione, la divisione, la conversione, la rotazione, la compressione, le filigrane, l'estrazione/eliminazione delle pagine, i numeri di pagina, le sovrapposizioni, l'estrazione dei contenuti, i metadati, le impostazioni di sicurezza e le query delle attività. Utilizzato quando si gestiscono file PDF.
