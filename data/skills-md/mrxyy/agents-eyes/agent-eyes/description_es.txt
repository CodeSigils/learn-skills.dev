Verifique si `@agent-eyes/agent-eyes` está instalado en el proyecto actual, ayude a instalarlo cuando falte, asegúrese de que el proyecto tenga una regla `AGENTS.md` que requiera recuperar primero el contexto del código seleccionado de Agent Eyes y siempre obtenga el contexto del código seleccionado actual antes de realizar cambios en el código. Úselo cuando las tareas impliquen cambios de página, elementos seleccionados, ruta DOM, ediciones de la interfaz de usuario, modificaciones precisas del código o cuando un agente debe solicitar el contexto del elemento seleccionado del servicio local antes de codificar.
