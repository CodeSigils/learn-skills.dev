Utilisez Chrome DevTools MCP pour valider les pages de l'interface utilisateur et produire un rapport répertoriant uniquement les éléments ayant échoué. Convient pour « valider l'interface utilisateur », « vérifier les pages », « tester si les pages répondent aux exigences ». Ne convient pas au débogage de la logique backend, à la modification du code ou à l'écriture de tâches de test automatisées.
