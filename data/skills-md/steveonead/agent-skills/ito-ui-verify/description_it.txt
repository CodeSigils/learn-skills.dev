Utilizza Chrome DevTools MCP per convalidare le pagine dell'interfaccia utente e produrre un report che elenca solo gli elementi non riusciti. Adatto per "convalidare l'interfaccia utente", "controllare le pagine", "testare se le pagine soddisfano i requisiti". Non adatto per il debug della logica backend, la modifica del codice o la scrittura di attività di test automatizzate.
