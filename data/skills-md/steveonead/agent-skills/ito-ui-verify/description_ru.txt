Используйте Chrome DevTools MCP для проверки страниц пользовательского интерфейса и создания отчета, в котором перечислены только неудачные элементы. Подходит для «проверки пользовательского интерфейса», «проверки страниц», «проверки соответствия страниц требованиям». Не подходит для отладки серверной логики, модификации кода или написания задач автоматического тестирования.
