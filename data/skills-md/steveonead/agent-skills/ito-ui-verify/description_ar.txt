استخدم Chrome DevTools MCP للتحقق من صحة صفحات واجهة المستخدم وإنتاج تقرير يسرد العناصر الفاشلة فقط. مناسب لـ "التحقق من صحة واجهة المستخدم" و"فحص الصفحات" و"اختبار ما إذا كانت الصفحات تلبي المتطلبات". غير مناسب لتصحيح الأخطاء المنطقية الخلفية أو تعديل التعليمات البرمجية أو كتابة مهام الاختبار الآلي.
