Utilice un proceso de estilo entrevista para crear, modificar o revisar las habilidades de los agentes. Di "crear/agregar una habilidad" o "escribir una habilidad" para ingresar al modo de creación. Diga "cambiar/actualizar/arreglar una habilidad" y nombre una habilidad existente para ingresar al modo de edición. Di "revisar habilidad XXX" o "verificar habilidad XXX" para ingresar al modo de revisión. No para validar efectos de habilidades o realizar tareas descritas por la habilidad misma.
