Hypothesengesteuerte Debugging-Diagnosefähigkeit, die die Ursache anhand von Fehlermeldungen ermittelt, ohne den Code direkt zu ändern. Anwendbar, wenn Benutzer Fehlermeldungen oder Stack-Traces bereitstellen und eine systematische Ursachenermittlung benötigen. Geeignet für „Was bedeutet dieser Fehler“ und „Warum ist er kaputt gegangen“-Szenarien mit begleitenden Fehlermeldungen. Wenn Benutzer keine Fehlermeldungen bereitgestellt haben, leiten Sie sie zur Bereitstellung an, bevor Sie fortfahren. Gilt nicht für Aufgaben, die Codeänderungen oder etwas anderes als das Öffnen von Problemen beinhalten.
