Habilidad de depuración basada en hipótesis: rastrear la causa raíz del mensaje de error sin modificar el código. Úselo cuando el usuario proporciona un mensaje de error o un seguimiento de la pila y necesita una forma sistemática de encontrar la causa raíz. Se aplica a preguntas como "¿qué significa este error" y "¿por qué está roto?" cuando van acompañadas de un mensaje de error. Si no se proporciona ningún mensaje de error, solicite al usuario que lo proporcione; no continúe sin él. No está destinado a cambios de código ni tareas ajenas a la presentación de un problema.
