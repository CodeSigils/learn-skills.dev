Сканируйте все изменения в рабочем каталоге Git, разумно группируйте их, фиксируйте по порядку и отображайте план для подтверждения. Подходит, когда пользователь говорит «зафиксировать», «отправить изменения» или «помочь зафиксировать». Поддерживает быстрый режим (изменения файлов без блокировки, объединенные в одну фиксацию). Не подходит для сценариев, требующих ручной подготовки или принудительной отправки.
