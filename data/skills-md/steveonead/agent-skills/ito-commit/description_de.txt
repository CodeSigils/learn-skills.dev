Scannen Sie alle Änderungen im Git-Arbeitsbereich, gruppieren Sie sie intelligent, übernehmen Sie sie nacheinander und zeigen Sie den Plan zur Bestätigung an. Anwendbar, wenn der Benutzer „Festschreiben“, „Änderungen übermitteln“ oder „Hilf mir beim Festschreiben“ sagt. Unterstützt den Schnellmodus (nicht gesperrte Dateiänderungen, die in einem einzigen Commit zusammengeführt werden). Gilt nicht für Szenarien, die eine manuelle Staging-Steuerung oder Push-Ausführung erfordern.
