Разработка через тестирование для руководства по реализации функций и исправлению ошибок. Используйте, когда пользователь явно упоминает TDD, red-green-refactor или test-first. Неприменимо для чистых изменений конфигурации, обновлений документации или статических модификаций, не влияющих на поведение.
