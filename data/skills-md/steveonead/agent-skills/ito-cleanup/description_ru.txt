Очистите код в изменениях git или в отдельном файле: удалите журналы отладки, неиспользуемый импорт, закомментированный код, избыточную логику, проблемы с именованием и структурную сложность, сохраняя при этом поведение. Не для изменения логики, добавления функций, серьезного рефакторинга или незавершенного кода. Только ручной вызов.
