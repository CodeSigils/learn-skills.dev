Una herramienta exploratoria para la etapa de requisitos ambiguos, que se utiliza antes de establecer la dirección. Pregunta sobre cada rama de decisión de un plan, diseño o requisito, una por una, desafiando activamente los supuestos y exponiendo debilidades potenciales hasta que cada rama haya sido cuestionada y cada suposición haya sido probada. Úselo cuando los usuarios digan que "quieren discutir" o "necesitan ayuda para aclarar", o cuando un plan necesita pruebas de estrés o los supuestos de diseño necesitan validación. No lo utilice cuando la dirección ya esté fijada y necesite documentación, o cuando la tarea esté lista para su implementación directa.
