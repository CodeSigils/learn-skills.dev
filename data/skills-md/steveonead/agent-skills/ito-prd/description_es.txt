Entreviste los requisitos del usuario tema por tema, luego converja en un PRD estructurado con preguntas de seguimiento profundas, finalmente guárdelo en archivos locales o cree un problema de GitHub. Úselo cuando el usuario diga "escribir PRD", "organizar requisitos", "documentar esta característica", "abrir un problema de requisitos" o mencione modificar un PRD o problema existente. No se aplica a la implementación directa de funciones, discusiones de diseño de arquitectura técnica pura o notas generales (documentos que no son requisitos).
