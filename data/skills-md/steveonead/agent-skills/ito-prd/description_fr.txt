Après avoir interrogé les utilisateurs pour recueillir les exigences question par question, faites-les converger vers un PRD structuré avec des questions de suivi approfondies, et enfin enregistrez-les dans un fichier local ou créez un problème GitHub. Utilisez-le lorsque l'utilisateur dit « écrire un PRD », « organiser les exigences », « documenter cette fonctionnalité », « créer un problème d'exigence » ou mentionne la modification d'un PRD ou d'un problème existant. Non applicable pour la mise en œuvre directe de fonctionnalités, les discussions de conception d'architecture technique pure ou les notes générales (documents non requis).
