Interviewez les exigences des utilisateurs sujet par sujet, puis convergez vers un PRD structuré avec des questions de suivi approfondies, enfin enregistrez dans des fichiers locaux ou créez un problème GitHub. À utiliser lorsque l'utilisateur dit « écrire le PRD », « organiser les exigences », « documenter cette fonctionnalité », « ouvrir un problème d'exigence » ou mentionne la modification du PRD ou du problème existant. Non applicable pour la mise en œuvre directe de fonctionnalités, les discussions sur la conception d'une architecture technique pure ou les notes générales (documents non requis).
