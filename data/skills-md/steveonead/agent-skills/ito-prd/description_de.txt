Befragen Sie die Benutzeranforderungen Thema für Thema, konvergieren Sie dann zu einem strukturierten PRD mit ausführlichen Folgefragen und speichern Sie ihn schließlich in lokalen Dateien oder erstellen Sie ein GitHub-Problem. Wird verwendet, wenn der Benutzer „PRD schreiben“, „Anforderungen organisieren“, „diese Funktion dokumentieren“, „ein Anforderungsproblem öffnen“ sagt oder die Änderung vorhandener PRD oder Probleme erwähnt. Gilt nicht für die direkte Funktionsimplementierung, reine technische Architekturdesigndiskussionen oder allgemeine Hinweise (nicht erforderliche Dokumente).
