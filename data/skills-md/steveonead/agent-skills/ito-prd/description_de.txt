Nachdem Sie den Benutzer zu jeder Anforderung befragt haben, führen Sie die Ergebnisse in einer strukturierten PRD zusammen, prüfen Sie diese eingehend und speichern Sie sie schließlich in einer lokalen Datei oder erstellen Sie ein GitHub-Problem. Verwenden Sie dies, wenn der Benutzer sagt „PRD schreiben“, „Anforderungen organisieren“, „diese Funktion dokumentieren“, „ein Anforderungsproblem öffnen“ oder die Überarbeitung eines vorhandenen PRD oder Problems erwähnt. Verwenden Sie es nicht für die direkte Implementierung von Funktionen, rein technische Architekturdiskussionen oder allgemeine Hinweise (nicht erforderliche Dokumente).
