Estrai un elenco di attività a sezioni verticali dal PRD, genera attività eseguibili con criteri di accettazione ed etichette di dimensione dopo aver approfondito la base di codice, esegui l'iterazione per confermare, quindi salva localmente come Markdown o invia come sottoproblemi GitHub. Utilizzare al termine del PRD e le attività devono essere suddivise o convertite in problemi GitHub. Non per scrivere PRD, implementare direttamente funzionalità o modificare/chiudere problemi GitHub esistenti.
