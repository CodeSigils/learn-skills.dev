Suddividi gli elenchi di attività in sezioni verticali da PRD, conduci un'esplorazione approfondita della base di codice, quindi genera attività eseguibili con criteri di accettazione ed etichette di dimensione. Ripeti per la conferma prima di archiviare localmente in Markdown o inviare come problemi secondari GitHub. Da utilizzare quando è necessario suddividere le attività dal PRD completato o convertirle in problemi GitHub. Non applicabile per la scrittura di PRD, l'implementazione diretta di funzionalità o la modifica/chiusura di problemi GitHub esistenti.
