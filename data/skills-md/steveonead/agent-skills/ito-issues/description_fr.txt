Décomposez les listes de tâches en tranches verticales à partir du PRD, explorez en profondeur la base de code pour générer des tâches exécutables avec des critères d'acceptation et des étiquettes de taille, itérez pour confirmation, puis stockez localement sous forme de Markdown ou poussez en tant que sous-problèmes GitHub. Applicable lorsque les tâches doivent être décomposées à partir du PRD terminé ou converties en problèmes GitHub. Non applicable pour l'écriture de PRD, l'implémentation directe de fonctionnalités ou la modification/fermeture de problèmes GitHub existants.
