Extraiga una lista de tareas de corte vertical del PRD, explore en profundidad el código base y genere tareas ejecutables que incluyan criterios de aceptación y etiquetas de tamaño; después de la confirmación iterativa, guárdelos localmente como Markdown o envíelos como subproblemas de GitHub. Úselo cuando el PRD esté terminado y las tareas deban dividirse o convertirse en problemas de GitHub. No lo use para escribir PRD, implementar funciones directamente o modificar/cerrar problemas existentes de GitHub.
