Extraiga una lista de tareas de corte vertical del PRD, genere tareas ejecutables con criterios de aceptación y etiquetas de tamaño después de profundizar en el código base, itere para confirmar y luego guárdela localmente como Markdown o envíela como subproblemas de GitHub. Úselo después de realizar el PRD y las tareas necesiten dividirse o convertirse a problemas de GitHub. No para escribir PRD, implementar funciones directamente o editar/cerrar problemas existentes de GitHub.
