قم باستخراج قائمة مهام ذات شرائح رأسية من PRD، وقم بإنشاء مهام قابلة للتنفيذ بمعايير القبول وتسميات الحجم بعد الغوص العميق في قاعدة التعليمات البرمجية، ثم قم بالتكرار للتأكيد، ثم احفظ محليًا كـ Markdown أو ادفع كمشكلات فرعية لـ GitHub. استخدمه بعد الانتهاء من PRD وتحتاج المهام إلى التقسيم أو التحويل إلى مشكلات GitHub. ليس لكتابة PRDs، أو تنفيذ الميزات مباشرة، أو تحرير/إغلاق مشكلات GitHub الحالية.
