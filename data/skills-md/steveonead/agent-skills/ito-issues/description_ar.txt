قم بتقسيم قوائم مهام الشرائح العمودية من PRD، واستكشف قاعدة التعليمات البرمجية بعمق لإنشاء مهام قابلة للتنفيذ بمعايير القبول وتسميات الحجم، ثم كررها للتأكيد، ثم قم بتخزينها محليًا كـ Markdown أو دفعها كمشكلات فرعية لـ GitHub. ينطبق عندما يلزم تقسيم المهام من PRDs المكتملة أو تحويلها إلى مشكلات GitHub. لا ينطبق على كتابة PRDs، أو تنفيذ الميزات مباشرة، أو تعديل/إغلاق مشكلات GitHub الحالية.
