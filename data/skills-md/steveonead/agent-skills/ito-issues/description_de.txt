Extrahieren Sie eine Vertikal-Slice-Aufgabenliste aus dem PRD, generieren Sie ausführbare Aufgaben mit Akzeptanzkriterien und Größenbezeichnungen, nachdem Sie die Codebasis gründlich untersucht haben, iterieren Sie zur Bestätigung und speichern Sie sie dann lokal als Markdown oder übertragen Sie sie als GitHub-Unterausgaben. Wird verwendet, nachdem die PRD abgeschlossen ist und Aufgaben aufgeteilt oder in GitHub-Probleme konvertiert werden müssen. Nicht zum Schreiben von PRDs, zur direkten Implementierung von Funktionen oder zum Bearbeiten/Schließen bestehender GitHub-Probleme.
