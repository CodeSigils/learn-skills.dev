Erkunden Sie die Codebasis und beantworten Sie die Frage „Wie funktioniert X?“, um eine strukturierte Architekturbeschreibung zu erstellen. Verwenden Sie es, wenn der Benutzer sagt „Erkläre X“, „Wie funktioniert X“, „Ich möchte die Architektur von X verstehen“ oder /ito-explain eingibt. Nicht zum Implementieren, Schreiben oder Ändern von Code.
