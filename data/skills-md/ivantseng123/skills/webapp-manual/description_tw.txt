從頭開始將 Web 系統的操作手冊（操作說明書/操作手冊/使用者指南）建置為 .docx，或維護現有的操作手冊 - 將每個頁面放在即時運行的應用程式上並直接編輯 OOXML。每當使用者處理 Web 系統的操作手冊/使用者指南 .docx 時，請使用此功能：建立全新的手冊（將導航列枚舉到目錄中，然後使用功能描述、帶註釋的螢幕截圖和欄位規格表記錄每個畫面）、重新製作或新增章節、刷新過時的螢幕截圖、根據真實系統審核目錄，或保持文件/下拉/下拉式功能表與實際文件/下拉式功能的內容同步程式設定。即使使用者只說“從頭開始建立操作手冊”、“將選單列為目錄並記錄每個頁面”、“更新手冊”、“重製第 X 部分”、“將目錄與系統進行比較”、“螢幕截圖已過時”或“記錄這個新頁面”，只要文件必須與即時、經過驗證的單頁應用程式相匹配，即可觸發。即時驗證和捕獲需要瀏覽器自動化 - 捆綁的 Playwright 腳本（Node + `playwright`）或代理中的 Playwright MCP。透過新增即時驗證、螢幕截圖註解和基於來源的內容來補充文件技能：docx 技能（處理原始解包/編輯/打包機制）。
