Cree un manual de operación del sistema web (操作說明書/操作手冊/userguide) como un .docx desde cero, o mantenga uno existente, conectando cada página a la aplicación en vivo y editando el OOXML directamente. Utilice esto siempre que el usuario trabaje en un manual de operación/guía de usuario .docx para un sistema web: crear un manual nuevo (enumerar la barra de navegación en una tabla de contenido, luego documentar cada pantalla con descripciones de funciones, capturas de pantalla anotadas y tablas de especificaciones de campo), rehacer o agregar capítulos, actualizar capturas de pantalla obsoletas, auditar la tabla de contenido con el sistema real o mantener la documentación de campo/desplegable/menú sincronizada con lo que la aplicación realmente muestra. Se activa incluso cuando el usuario solo dice "crear el manual de operación desde cero", "enumerar el menú como una tabla de contenido y documentar cada página", "actualizar el manual", "rehacer la sección X", "comparar la tabla de contenido con el sistema", "las capturas de pantalla están obsoletas" o "documentar esta nueva página"; cada vez que un documento debe coincidir con una aplicación activa y autenticada de una sola página. La verificación y captura en vivo necesitan automatización del navegador: el script Playwright incluido (Nodo + `playwright`) o un MCP Playwright en el agente. Complementa la habilidad document-skills:docx (que maneja las mecánicas de descomprimir/editar/empacar sin procesar) agregando verificación en vivo, anotaciones de capturas de pantalla y contenido basado en fuentes.
