Erstellen Sie das Benutzerhandbuch eines Websystems (操作說明書/操作手冊/Benutzerhandbuch) als .docx von Grund auf oder behalten Sie ein vorhandenes bei, indem Sie jede Seite in der live ausgeführten App verankern und die OOXML direkt bearbeiten. Verwenden Sie dies immer dann, wenn der Benutzer an einer Bedienungsanleitung/Benutzeranleitung im .docx-Format für ein Websystem arbeitet: ein brandneues Handbuch erstellen (die Navigationsleiste in ein Inhaltsverzeichnis auflisten und dann jeden Bildschirm mit Funktionsbeschreibungen, kommentierten Screenshots und Feldspezifikationstabellen dokumentieren), Kapitel neu erstellen oder hinzufügen, veraltete Screenshots aktualisieren, das Inhaltsverzeichnis mit dem realen System vergleichen oder die Feld-/Dropdown-/Menüdokumentation mit dem synchronisieren, was die App tatsächlich anzeigt. Wird auch dann ausgelöst, wenn der Benutzer nur sagt: „Erstellen Sie das Benutzerhandbuch von Grund auf“, „Listen Sie das Menü als Inhaltsverzeichnis auf und dokumentieren Sie jede Seite“, „Aktualisieren Sie das Handbuch“, „erstellen Sie Abschnitt Live-Überprüfung und -Erfassung erfordern eine Browser-Automatisierung – das gebündelte Playwright-Skript (Node + „playwright“) oder ein Playwright-MCP im Agenten. Ergänzt den document-skills:docx-Skill (der die Rohmechanik zum Entpacken/Bearbeiten/Packen übernimmt) durch Hinzufügen von Live-Überprüfung, Screenshot-Anmerkungen und quellenbasierten Inhalten.
