Habilidad de investigación primaria: utilícela cuando el usuario solicite investigar, buscar, explorar, encontrar, rastrear, investigar o comprender el código. Los activadores incluyen "buscar X", "¿dónde está definido Y?", "explorar este directorio", "rastrear definiciones", "encontrar usos", "¿cómo funciona X?", "¿quién llama a Z?", "buscar X", "investigar esta biblioteca", "encontrar relaciones públicas", "¿qué paquete hace X?", "comprender este flujo", "investigar este error", "¿qué cambió?", o cualquier necesidad de exploración/descubrimiento de código, local o externa. Utiliza herramientas Octocode MCP directamente (preferido). Recurre a las herramientas gh CLI o Linux cuando MCP no está disponible.
