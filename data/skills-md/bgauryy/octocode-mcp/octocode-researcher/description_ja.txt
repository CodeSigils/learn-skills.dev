主な調査スキル — ユーザーがコードを調査、検索、探索、発見、トレース、調査、または理解することを要求するときに使用します。トリガーには、「X を見つける」、「Y はどこで定義されていますか?」、「このディレクトリを調べる」、「定義をトレースする」、「使用方法を見つける」、「X はどのように機能しますか?」、「Z を呼び出すのは誰ですか?」、「X を検索する」、「このライブラリを調査する」、「PR を見つける」、「X にどのようなパッケージが含まれていますか?」、「このフローを理解する」、「このバグを調査する」、「何が変更されましたか?」、または任意のコードの調査/発見が含まれます。ローカルまたは外部の必要性。 Octocode MCP ツールを直接使用します (推奨)。 MCP が使用できない場合は、gh CLI または Linux ツールにフォールバックします。
