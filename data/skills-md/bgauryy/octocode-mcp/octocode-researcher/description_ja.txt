主な調査スキル — ユーザーがコードを調査、検索、探索、発見、トレース、調査、または理解することを要求するときに使用します。トリガーには、「X を見つける」、「Y はどこで定義されていますか?」、「このディレクトリを調べます」、「定義をトレースします」、「使用方法を見つけます」、「X はどのように機能しますか?」、「Z を呼び出すのは誰ですか?」、「X を検索します」、「このライブラリを調べます」、「PR を見つけます」、「X を実行するパッケージは何ですか?」、「このフローを理解します」、「このバグを調査します」、「何が変更されましたか?」、または任意のコードの探索/発見が含まれます。ローカルまたは外部の必要性。 Octocode MCP ツールを直接使用します (推奨)。 MCP が使用できない場合は、gh CLI または Linux ツールにフォールバックします。
