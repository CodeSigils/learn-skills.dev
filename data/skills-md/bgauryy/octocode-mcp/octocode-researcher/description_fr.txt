Compétence de recherche principale : à utiliser lorsque l'utilisateur demande à rechercher, explorer, trouver, tracer, enquêter ou comprendre le code. Les déclencheurs incluent "trouver X", "où Y est-il défini ?", "explorer ce répertoire", "tracer les définitions", "trouver des utilisations", "comment X fonctionne-t-il ?", "qui appelle Z ?", "rechercher X", " rechercher cette bibliothèque", " trouver des PR ", " quel paquet fait X ? ", " comprendre ce flux ", " enquêter sur ce bug ", " qu'est-ce qui a changé ? ", ou tout besoin d'exploration/découverte de code - local ou externe. Utilise directement les outils Octocode MCP (de préférence). Revient aux outils gh CLI ou Linux lorsque MCP n'est pas disponible.
