Verwenden Sie die Unterbefehle „octocode-cli“, um Octocode MCP-Tools von einem Terminal aus auszuführen, ohne MCP zu verkabeln. Verwenden Sie diese Option, wenn der Benutzer „Octocode von der Shell ausführen“, „Octocode ohne MCP verwenden“ oder „githubSearchCode über die CLI aufrufen“ möchte oder eine einmalige GitHub-Code-/Datei-/PR-Suche im Terminal wünscht.
