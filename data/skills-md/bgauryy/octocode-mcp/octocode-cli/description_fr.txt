Utilisez les sous-commandes `octocode-cli` pour exécuter les outils Octocode MCP à partir d'un terminal sans câbler MCP. À utiliser lorsque l'utilisateur demande « d'exécuter octocode à partir du shell », « d'utiliser octocode sans MCP », « d'appeler githubSearchCode depuis CLI » ou souhaite une recherche unique de code/fichier/PR GitHub dans le terminal.
