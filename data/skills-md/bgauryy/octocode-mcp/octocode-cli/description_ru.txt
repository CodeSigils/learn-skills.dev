Используйте подкоманды Octocode-cli для запуска инструментов Octocode MCP с терминала без подключения MCP. Используйте, когда пользователь просит «запустить октокод из оболочки», «использовать октокод без MCP», «вызвать githubSearchCode из CLI» или хочет выполнить одноразовый поиск кода/файла/PR GitHub в терминале.
