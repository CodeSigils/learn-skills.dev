Utilizza i sottocomandi "octocode-cli" per eseguire gli strumenti Octocode MCP da un terminale senza collegare MCP. Da utilizzare quando l'utente chiede di "eseguire octocode dalla shell", "utilizzare octocode senza MCP", "chiamare githubSearchCode dalla CLI" o desidera una ricerca una tantum di codice/file/PR GitHub nel terminale.
