Sistema de diseño de alto nivel y generador de arquitectura de interfaz de usuario para proyectos nuevos o existentes. Primero utiliza las herramientas locales de Octocode MCP y luego crea un DESIGN.md dinámico (no rígido) que cubre el lenguaje visual, la estrategia de estilo, la arquitectura de componentes, las restricciones del marco, la accesibilidad, el rendimiento, el comportamiento responsivo y la guía de implementación.
