Programme d'installation interactif étape par étape pour les outils Octocode sur macOS et Windows. À utiliser lorsque l'utilisateur demande « installer octocode », « configurer octocode », « configurer octocode mcp », « démarrer avec octocode », « installer octocode-cli », « configurer octocode » ou a besoin d'aide pour l'authentification GitHub, la configuration IDE MCP ou l'installation de compétences.
