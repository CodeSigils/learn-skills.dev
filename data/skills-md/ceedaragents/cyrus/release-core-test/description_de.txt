Wird aufgerufen, wenn eine Cyrus-Änderung entwickelt wird, die CYPACK (Edgeworker + CLI) und CYHOST (von Vercel gehostete GUI) umfasst und die gehostete GUI auf einen unveröffentlichten „Cyrus-Kern“ aus diesem Repo verweisen muss. Veröffentlicht „cyrus-core“ (und „claude-runner“, falls erforderlich) als „-test.N“-Vorabversion unter dem npm-Dist-Tag „test“, damit CYHOST es über „cyrus-core@test“ installieren kann, ohne das Dist-Tag „latest“ zu beeinträchtigen oder eine echte Version zu versenden.
