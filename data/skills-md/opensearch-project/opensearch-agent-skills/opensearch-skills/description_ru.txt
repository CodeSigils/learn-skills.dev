Создавайте поисковые приложения и запрашивайте аналитические данные журналов с помощью OpenSearch. Используйте этот навык, когда пользователь упоминает OpenSearch, приложение поиска, настройку индекса, архитектуру поиска, семантический поиск, векторный поиск, гибридный поиск, BM25, плотный вектор, разреженный вектор, агентный поиск, RAG, встраивания, KNN, прием PDF-файлов, обработку документов или любую связанную тему поиска. Также используйте для анализа журналов и наблюдения — когда пользователь хочет настроить прием журналов, запросить журналы с помощью PPL, проанализировать шаблоны ошибок, настроить политики жизненного цикла индекса, исследовать трассировки или проверить работоспособность стека. Активируйте, даже если пользователь говорит «Анализ журнала», «Fluent Bit», «Fluentd», «Logstash», «syslog», «traceId», «OpenTelemetry» или «Analytics журнала», не упоминая OpenSearch.
