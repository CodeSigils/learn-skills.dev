Crea applicazioni di ricerca ed esegui query sui dati di analisi dei log con OpenSearch. Utilizza questa capacità quando l'utente menziona OpenSearch, app di ricerca, impostazione dell'indice, architettura di ricerca, ricerca semantica, ricerca vettoriale, ricerca ibrida, BM25, vettore denso, vettore sparso, ricerca agentica, RAG, incorporamenti, KNN, acquisizione di PDF, elaborazione di documenti o qualsiasi argomento di ricerca correlato. Utilizzabile anche per l'analisi e l'osservabilità dei log: quando l'utente desidera impostare l'inserimento di log, eseguire query sui log con PPL, analizzare modelli di errore, impostare policy del ciclo di vita dell'indice, indagare sulle tracce o verificare l'integrità dello stack. Attiva anche se l'utente dice analisi dei log, Fluent Bit, Fluentd, Logstash, syslog, traceId, OpenTelemetry o analisi dei log senza menzionare OpenSearch.
