قم ببناء تطبيقات البحث وبيانات تحليلات سجل الاستعلام باستخدام OpenSearch. استخدم هذه المهارة عندما يذكر المستخدم OpenSearch، أو تطبيق البحث، أو إعداد الفهرس، أو بنية البحث، أو البحث الدلالي، أو البحث المتجه، أو البحث المختلط، أو BM25، أو المتجه الكثيف، أو المتجه المتناثر، أو البحث الوكيل، أو RAG، أو التضمينات، أو KNN، أو استيعاب PDF، أو معالجة المستندات، أو أي موضوع بحث ذي صلة. يُستخدم أيضًا لتحليلات السجل وإمكانية المراقبة - عندما يريد المستخدم إعداد استيعاب السجل، أو الاستعلام عن السجلات باستخدام PPL، أو تحليل أنماط الخطأ، أو إعداد سياسات دورة حياة الفهرس، أو التحقق من التتبعات، أو التحقق من صحة المكدس. قم بالتنشيط حتى إذا قال المستخدم تحليل السجل، أو Fluent Bit، أو Fluentd، أو Logstash، أو syslog، أو TraceId، أو OpenTelemetry، أو تحليلات السجل دون ذكر OpenSearch.
