Utilisez cette compétence lorsque l'utilisateur mentionne OpenSearch, l'application de recherche, la configuration d'index, l'architecture de recherche, la recherche sémantique, la recherche vectorielle, la recherche hybride, BM25, le vecteur dense, le vecteur clairsemé, la recherche agentique, RAG, les intégrations, KNN, l'ingestion de PDF, le traitement de documents ou tout autre sujet de recherche connexe. À utiliser également pour l'analyse et l'observabilité des journaux : lorsque l'utilisateur souhaite configurer l'ingestion des journaux, interroger les journaux avec PPL, analyser les modèles d'erreur, configurer les politiques de cycle de vie des index, enquêter sur les traces ou vérifier l'état de la pile. Activez même si l'utilisateur indique l'analyse des journaux, Fluent Bit, Fluentd, Logstash, syslog, traceId, OpenTelemetry ou l'analyse des journaux sans mentionner OpenSearch.
