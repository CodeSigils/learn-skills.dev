إنشاء تطبيقات البحث باستخدام OpenSearch. يرشدك خلال إعداد البحث الدلالي، والبحث المتجهي، والبحث المختلط، والبحث العصبي، وBM25، والمتجه الكثيف، والمتجه المتناثر، والبحث الوكيل، وRAG، والاسترجاع، والتضمينات، وKNN. يقوم بإعداد OpenSearch محليًا عبر Docker، ويخطط لبنية البحث، وينشئ المؤشرات، ونماذج ML، ويستوعب خطوط الأنابيب، ويطلق واجهة مستخدم للبحث، وينشر بشكل اختياري إلى AWS OpenSearch Service أو Serverless. يُستخدم عندما يذكر المستخدم OpenSearch، أو تطبيق البحث، أو إعداد الفهرس، أو بنية البحث، أو البحث في المستندات، أو صلة البحث، أو أي موضوع بحث ذي صلة.
