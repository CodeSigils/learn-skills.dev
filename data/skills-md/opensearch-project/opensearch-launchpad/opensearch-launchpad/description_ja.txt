OpenSearch を使用して検索アプリケーションを構築します。セマンティック検索、ベクトル検索、ハイブリッド検索、ニューラル検索、BM25、密ベクトル、疎ベクトル、エージェント検索、RAG、取得、埋め込み、および KNN のセットアップについて説明します。 Docker 経由で OpenSearch をローカルに設定し、検索アーキテクチャを計画し、インデックス、ML モデルを作成し、パイプラインを取り込み、検索 UI を起動し、オプションで AWS OpenSearch Service またはサーバーレスにデプロイします。ユーザーが OpenSearch、検索アプリ、インデックス設定、検索アーキテクチャ、ドキュメント検索、検索の関連性、または関連する検索トピックについて言及する場合に使用します。
