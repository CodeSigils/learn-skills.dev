يدير مكونات ومشاريع shadcn-vue - إضافة واجهة المستخدم والبحث عنها وإصلاحها وتصحيح الأخطاء والتصميم وإنشاءها. يوفر سياق المشروع ومستندات المكونات وأمثلة الاستخدام. ينطبق عند العمل مع shadcn-vue، أو سجلات المكونات، أو الإعدادات المسبقة، أو رموز --preset، أو أي مشروع يحتوي على ملف Components.json. يتم أيضًا تشغيل "shadcn-vue init" أو "إنشاء تطبيق باستخدام --preset" أو "التبديل إلى --preset".
