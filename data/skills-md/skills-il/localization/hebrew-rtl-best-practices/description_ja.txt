ヘブライ語の Web アプリケーションとモバイル アプリケーションに右から左へ (RTL) レイアウトを実装します。ユーザーが RTL レイアウト、ヘブライ語テキストの方向、双方向 (bidi) テキスト、ヘブライ語 CSS、「右から左」について質問する場合、またはヘブライ語 UI を構築する必要がある場合に使用します。 CSS 論理プロパティ、Tailwind RTL、React/Next.js RTL セットアップ、ヘブライ語タイポグラフィ、フォント選択について説明します。ユーザーが共有 RTL パターンを明示的に要求しない限り、アラビア語 RTL (似ているが異なるタイポグラフィ) には使用しないでください。
