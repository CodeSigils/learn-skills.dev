Implemente diseños de derecha a izquierda (RTL) para aplicaciones web y móviles en hebreo. Úselo cuando el usuario pregunte sobre el diseño RTL, la dirección del texto hebreo, el texto bidireccional (bidi), el CSS hebreo, "de derecha a izquierda" o necesite crear una interfaz de usuario en hebreo. Cubre las propiedades lógicas de CSS, Tailwind RTL, configuración de React/Next.js RTL, tipografía hebrea y selección de fuentes. NO lo use para RTL árabe (tipografía similar pero diferente) a menos que el usuario solicite explícitamente patrones RTL compartidos.
