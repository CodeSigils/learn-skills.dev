تنفيذ تخطيطات من اليمين إلى اليسار (RTL) للويب العبري وتطبيقات الهاتف المحمول. يُستخدم عندما يسأل المستخدم عن تخطيط RTL، أو اتجاه النص العبري، أو النص ثنائي الاتجاه (ثنائي الاتجاه)، أو CSS العبري، أو "من اليمين إلى اليسار"، أو يحتاج إلى إنشاء واجهة مستخدم عبرية. يغطي خصائص CSS المنطقية، وTailwind RTL، وإعداد React/Next.js RTL، والطباعة العبرية، واختيار الخط. لا تستخدمه مع اللغة العربية RTL (طباعة مماثلة ولكن مختلفة) ما لم يطلب المستخدم صراحةً أنماط RTL المشتركة.
