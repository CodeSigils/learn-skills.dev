Flusso di lavoro interattivo per la creazione di nuove competenze per l'organizzazione skills-il. Guida attraverso la selezione delle categorie, la definizione dei casi d'uso, l'impalcatura delle cartelle, la generazione di metadata.json con metadati bilingui, la scrittura delle istruzioni, la creazione di compagni in ebraico e la convalida. Da utilizzare quando l'utente chiede di creare una nuova abilità, impalcare un'abilità per skills-il, scrivere un SKILL.md, contribuire con un'abilità, un nuovo modello di abilità o un chadash di abilità liztor. Applica le convenzioni di skills-il (denominazione dei casi kebab, traslitterazioni ebraiche, nomi visualizzati bilingue, divulgazione progressiva, conformità validate-skill.sh). NON utilizzare per modificare competenze esistenti, creare competenze per piattaforme non-skills o creare file di markdown generici.
