Интерактивный рабочий процесс для создания новых навыков для организации, занимающейся навыками. Сопровождает выбор категорий, определение вариантов использования, создание папок, создание файла Metadata.json с двуязычными метаданными, написание инструкций, создание сопутствующих материалов на иврите и проверку. Используйте, когда пользователь просит создать новый навык, создать навык для навыков-il, написать SKILL.md, добавить навык, новый шаблон навыка или чадаш навыка Liztor. Обеспечивает соблюдение соглашений о навыках (наименование регистров кебаба, транслитерация на иврите, двуязычные отображаемые имена, постепенное раскрытие информации, соответствие validate-skill.sh). НЕ используйте для редактирования существующих навыков, создания навыков для платформ, не требующих навыков, или создания общего файла уценки.
