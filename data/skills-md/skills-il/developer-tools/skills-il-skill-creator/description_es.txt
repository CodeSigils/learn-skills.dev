Flujo de trabajo interactivo para crear nuevas habilidades para la organización skills-il. Guía a través de la selección de categorías, definición de casos de uso, andamiaje de carpetas, generación de metadata.json con metadatos bilingües, redacción de instrucciones, creación de complementos en hebreo y validación. Úselo cuando el usuario solicite crear una nueva habilidad, desarrollar una habilidad para skills-il, escribir un SKILL.md, contribuir con una habilidad, una nueva plantilla de habilidad o un chadash de habilidad de Liztor. Hace cumplir las convenciones de skills-il (nomenclatura de casos de kebab, transliteraciones hebreas, nombres para mostrar bilingües, divulgación progresiva, cumplimiento de valida-skill.sh). NO lo use para editar habilidades existentes, crear habilidades para plataformas que no sean de habilidades o crear archivos de rebajas genéricos.
