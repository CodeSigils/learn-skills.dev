Interaktiver Workflow zum Erstellen neuer Fähigkeiten für die Skills-IL-Organisation. Leitet durch die Kategorieauswahl, Anwendungsfalldefinition, Ordnergerüst, metadata.json-Generierung mit zweisprachigen Metadaten, Anleitungsschreiben, Erstellung hebräischer Begleitdokumente und Validierung. Wird verwendet, wenn der Benutzer eine neue Fertigkeit erstellen, eine Fertigkeit für skills-il aufbauen, eine SKILL.md schreiben, eine Fertigkeit, eine neue Fertigkeitsvorlage oder einen Liztor-Fertigkeits-Chadash beisteuern möchte. Setzt Skills-IL-Konventionen durch (Benennung in Kebab-Fällen, hebräische Transliterationen, zweisprachige Anzeigenamen, progressive Offenlegung, Validate-skill.sh-Konformität). NICHT zum Bearbeiten vorhandener Fertigkeiten, zum Erstellen von Fertigkeiten für Nicht-Skills-IL-Plattformen oder zum Erstellen generischer Markdown-Dateien verwenden.
