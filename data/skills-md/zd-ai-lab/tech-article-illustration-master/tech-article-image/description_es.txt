Genere imágenes temáticas de alta calidad para artículos técnicos. Escenarios desencadenantes: (1) el usuario solicita imágenes para el artículo/una imagen de encabezado/una imagen de portada; (2) el usuario carga un artículo técnico y solicita imágenes coincidentes; (3) el usuario menciona "agregar una imagen para el artículo", "generar una imagen del tema" o "hacer una portada". Capacidad principal: analizar el tema y el estado de ánimo del artículo, elegir el que mejor se adapte a 25 estilos cursis anti-IA y producir indicaciones de imágenes de nivel profesional. Admite la generación automática mediante herramientas de imágenes MCP; cuando MCP no está disponible, genera el mensaje para uso manual.
