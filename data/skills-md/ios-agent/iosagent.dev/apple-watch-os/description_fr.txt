Conseils d'experts pour créer des applications watchOS avec SwiftUI, les complications WidgetKit, les notifications, les intentions Siri/App, HealthKit et la gestion du temps d'exécution WatchKit. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur le développement de l'Apple Watch, les fonctionnalités de watchOS, les complications, les cadrans de montre, Smart Stack, Always On, un double appui sur le bouton d'action (Ultra), les sessions en arrière-plan, les sessions d'exécution étendues, les applications de montre indépendantes ou les API spécifiques à watchOS. Déclencheur pour la migration de ClockKit vers WidgetKit, les modèles d'interface utilisateur watchOS, plusieurs tailles de montre et l'accessibilité. À utiliser également pour les questions SwiftUI dans un contexte watchOS.
