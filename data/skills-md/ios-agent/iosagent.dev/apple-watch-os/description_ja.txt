SwiftUI、WidgetKit コンプリケーション、通知、Siri/App Intents、HealthKit、WatchKit ランタイム管理を使用して watchOS アプリを構築するための専門家によるガイダンス。ユーザーが Apple Watch の開発、watchOS の機能、コンプリケーション、ウォッチフェイス、スマート スタック、Always On、ダブルタップ、アクション ボタン (ウルトラ)、バックグラウンド セッション、拡張ランタイム セッション、独立した Watch アプリ、または watchOS 固有の API について質問するときはいつでも、このスキルを使用してください。 ClockKit から WidgetKit への移行、watchOS UI パターン、複数のウォッチ サイズ、およびアクセシビリティのトリガー。 watchOS コンテキストでの SwiftUI の質問にも使用します。
