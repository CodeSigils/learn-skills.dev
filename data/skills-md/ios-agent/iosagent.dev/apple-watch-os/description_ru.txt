Экспертное руководство по созданию приложений для watchOS с использованием SwiftUI, осложнений WidgetKit, уведомлений, Siri/App Intents, HealthKit и управления временем выполнения WatchKit. Используйте этот навык всякий раз, когда пользователь спрашивает о разработке Apple Watch, функциях watchOS, сложностях, циферблатах, Smart Stack, Always On, двойном касании, кнопке «Действие» (Ultra), фоновых сеансах, расширенных сеансах времени выполнения, независимых приложениях для часов или API-интерфейсах, специфичных для watchOS. Триггер для миграции ClockKit на WidgetKit, шаблоны пользовательского интерфейса watchOS, несколько размеров часов и специальные возможности. Также используйте для вопросов SwiftUI в контексте watchOS.
