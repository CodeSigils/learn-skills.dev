قم بتوجيه المستخدمين من خلال إنشاء تصاريح Apple Wallet وتصميمها وتوقيعها وتوزيعها وتحديثها باستخدام إطار عمل PassKit. استخدم هذه المهارة عندما يذكر المستخدم بطاقات Wallet، أو ملفات .pkpass، أو بطاقات الصعود إلى الطائرة، أو تذاكر الأحداث، أو بطاقات المتجر، أو الكوبونات، أو بطاقات الولاء، أو بطاقات العضوية، أو بطاقات NFC، أو أي شيء متعلق بتكامل Apple Wallet. يتم التشغيل أيضًا عندما يسأل المستخدم عن شارات "إضافة إلى المحفظة"، أو تمرير شهادات التوقيع، أو تمرير التحديثات عبر إشعارات الدفع، أو تدفقات الاسترداد المستندة إلى الرمز الشريطي/NFC. حتى لو قال المستخدم فقط "أريد إنشاء تذكرة رقمية" أو "بطاقة ولاء لتطبيقي"، فإن هذه المهارة تنطبق.
