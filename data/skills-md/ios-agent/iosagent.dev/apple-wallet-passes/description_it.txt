Guida gli utenti nella creazione, progettazione, firma, distribuzione e aggiornamento dei pass Apple Wallet utilizzando il framework PassKit. Utilizza questa abilità ogni volta che l'utente menziona pass Wallet, file .pkpass, carte d'imbarco, biglietti per eventi, carte negozio, coupon, carte fedeltà, tessere associative, pass NFC o qualsiasi cosa relativa all'integrazione di Apple Wallet. Si attivano anche quando l'utente richiede badge "Aggiungi al portafoglio", trasmette certificati di firma, trasmette aggiornamenti tramite notifiche push o flussi di riscatto basati su codice a barre/NFC. Anche se l'utente dice semplicemente "Voglio creare un biglietto digitale" o "una carta fedeltà per la mia app", questa abilità si applica.
