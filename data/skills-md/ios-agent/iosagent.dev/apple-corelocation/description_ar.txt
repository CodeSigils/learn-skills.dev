المهارة المرجعية لإطار عمل CoreLocation من Apple في Swift/SwiftUI. استخدم هذه المهارة عندما يعمل المستخدم مع خدمات الموقع، أو نظام تحديد المواقع العالمي (GPS)، أو تحديد الموقع الجغرافي، أو تحديد نطاق الإشارة، أو الترميز الجغرافي، أو عناوين البوصلة، أو أي رمز متعلق بـ CLLocationManager على iOS، أو macOS، أو watchOS، أو VisionOS. تشغيل الإشارات إلى: CoreLocation، أو CLLocationManager، أو CLLocation، أو أذونات الموقع، أو تحديد الموقع الجغرافي، أو CLMonitor، أو iBeacon، أو CLGeocoder، أو الترميز الجغرافي العكسي، أو تحديثات الموقع في الخلفية، أو ترخيص "عند الاستخدام" / "دائمًا"، أو CLLocationUpdate، أو التحديثات المباشرة، أو التغييرات المهمة في الموقع، أو أي مفاتيح Info.plist ذات صلة بالموقع مثل NSLocationWhenInUseUsageDescription.
