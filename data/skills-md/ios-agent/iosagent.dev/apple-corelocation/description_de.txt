Referenzkompetenz für das CoreLocation-Framework von Apple in Swift/SwiftUI. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer mit Ortungsdiensten, GPS, Geofencing, Beacon-Entfernung, Geokodierung, Kompasskursen oder einem beliebigen CLLocationManager-bezogenen Code auf iOS, macOS, watchOS oder visionOS arbeitet. Auslösen bei Erwähnungen von: CoreLocation, CLLocationManager, CLLocation, Standortberechtigungen, Geofencing, CLMonitor, iBeacon, CLGeocoder, umgekehrter Geokodierung, Standortaktualisierungen im Hintergrund, Autorisierung „Bei Verwendung“/„Immer“, CLLocationUpdate, Live-Aktualisierungen, wesentlichen Standortänderungen oder allen standortbezogenen Info.plist-Schlüsseln wie NSLocationWhenInUseUsageDescription.
