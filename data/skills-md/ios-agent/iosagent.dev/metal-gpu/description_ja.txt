シェーダ (頂点、フラグメント、コンピューティング)、レンダー パイプライン、コンピューティング パイプライン、バッファ/テクスチャ管理、および Metal 4 API を含む Metal GPU コードを作成、説明、デバッグします。ユーザーが Metal、GPU プログラミング、シェーダー、MSL (Metal Shading Language)、レンダー パス、コンピューティング カーネル、MTLDevice、MTLCommandBuffer、MTLRenderPipelineState、または Apple GPU/グラフィックス プログラミングのトピックについて言及するたびに、このスキルを使用します。また、ユーザーが Apple デバイスで並列計算を実行する場合、GPU アクセラレーション コードを作成する場合、または Metal Performance Shaders、MetalFX、MetalKit、または Compositor Services を使用する場合にもトリガーします。 iOS、macOS、iPadOS、tvOS、visionOS をカバーします。
