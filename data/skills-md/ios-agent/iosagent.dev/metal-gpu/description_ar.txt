كتابة وشرح وتصحيح كود Metal GPU بما في ذلك التظليل (قمة الرأس، والجزء، والحساب)، وخطوط الأنابيب، وخطوط الأنابيب الحسابية، وإدارة المخزن المؤقت/النسيج، وواجهات برمجة تطبيقات Metal 4. استخدم هذه المهارة عندما يذكر المستخدم Metal، أو برمجة GPU، أو التظليل، أو MSL (لغة التظليل المعدني)، أو تمريرات العرض، أو النواة الحسابية، أو MTLDevice، أو MTLCommandBuffer، أو MTLRenderPipelineState، أو أي موضوع برمجة رسومات/رسومات Apple. يتم تشغيله أيضًا عندما يريد المستخدم إجراء عمليات حسابية متوازية على أجهزة Apple، أو كتابة تعليمات برمجية مُسرَّعة بواسطة وحدة معالجة الرسومات، أو العمل مع Metal Performance Shaders، أو MetalFX، أو MetalKit، أو Compositor Services. يغطي iOS وmacOS وiPadOS وtvOS وvisionOS.
