Écrivez, expliquez et déboguez le code du GPU Metal, y compris les shaders (sommet, fragment, calcul), les pipelines de rendu, les pipelines de calcul, la gestion des tampons/textures et les API Metal 4. Utilisez cette compétence chaque fois que l'utilisateur mentionne Metal, la programmation GPU, les shaders, MSL (Metal Shading Language), les passes de rendu, les noyaux de calcul, MTLDevice, MTLCommandBuffer, MTLRenderPipelineState ou tout autre sujet de programmation GPU/graphique Apple. Déclenchez également lorsque l'utilisateur souhaite effectuer des calculs parallèles sur des appareils Apple, écrire du code accéléré par GPU ou travailler avec Metal Performance Shaders, MetalFX, MetalKit ou Compositor Services. Couvre iOS, macOS, iPadOS, tvOS et visionOS.
