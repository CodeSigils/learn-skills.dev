قم بمراجعة واحدة أو أكثر من تدفقات Kestra الحالية وإضافة ضوابط تقوية الإنتاج - إعادة المحاولة، والمهلات، وحدود التزامن، ومعالجات الخطأ/أخيرًا/بعد التنفيذ، واتفاقيات مستوى الخدمة، والفحوصات، وحراس العجز. يصدر تقرير نتائج مصنفًا حسب درجة الخطورة، ثم يطبق التعديلات المؤكدة. يُستخدم عندما يطلب المستخدمون تشديد التدفق أو تدقيقه أو مراجعته أو جعله أكثر جاهزية للإنتاج أو مرونة أو ضعفًا - وليس لتأليف تدفقات جديدة (استخدم تدفق كيسترا).
