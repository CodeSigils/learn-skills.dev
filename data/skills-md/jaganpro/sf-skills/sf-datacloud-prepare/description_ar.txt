مرحلة إعداد سحابة بيانات Salesforce. يتم التشغيل عندما: يقوم المستخدم بإنشاء أو إدارة تدفقات بيانات Data Cloud، أو DLOs، أو التحويلات، أو تكوينات Document AI، أو يسأل عن الاستيعاب في Data Cloud. لا تقم بالتشغيل عندما: تكون المهمة هي إعداد الاتصال فقط (استخدم sf-datacloud-connect)، أو DMOs ودقة الهوية (استخدم sf-datacloud-harmonize)، أو عمل الاستعلام/البحث (استخدم sf-datacloud-retrieve).
