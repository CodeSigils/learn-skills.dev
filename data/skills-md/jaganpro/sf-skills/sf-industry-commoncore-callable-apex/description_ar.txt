Salesforce Industries Common Core (OmniStudio/Vlocity) إنشاء ومراجعة Apex القابلة للاستدعاء بتسجيل 120 نقطة. يتم تشغيله عندما: يقوم المستخدم بإنشاء فئات System.Callable أو مراجعتها، أو ترحيل `VlocityOpenInterface` / `VlocityOpenInterface2`، أو إنشاء ملحقات الصناعات القابلة للاستدعاء المستخدمة بواسطة OmniStudio، أو Integration إجراءات، أو DataRaptors. لا تقم بالتشغيل عندما: فئات/مشغلات Apex العامة (استخدم sf-apex)، أو بناء إجراءات التكامل (استخدم sf-industry-commoncore-integration-procedure)، أو تأليف OmniScripts (استخدم sf-industry-commoncore-omniscript)، أو تكوين مخططي البيانات (استخدم sf-industry-commoncore-datamapper)، أو تحليل مشكلات مساحة الاسم/التبعية (استخدم sf-الصناعة-المشتركة-omnistudio-تحليل).
