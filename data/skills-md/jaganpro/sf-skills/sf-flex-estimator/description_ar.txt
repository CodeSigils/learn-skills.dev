تقدير رصيد Salesforce Flex لأحمال عمل Agentforce وData Cloud. يتم التشغيل عندما: يحتاج المستخدم إلى توقعات التكلفة، أو تخطيط السيناريوهات، أو تحديد حجم الميزانية، أو تحليل مقايضة البنية لمطالبات/إجراءات Agentforce، أو عدادات Data Cloud، أو استخدام Flex Credit الشهري. لا تقم بالتشغيل عندما: يقوم المستخدم بإنشاء بيانات تعريف Agentforce أو ملفات .agent بنفسه (استخدم sf-ai-agentforce أو sf-ai-agentscript)، أو ينفذ أصول Data Cloud (استخدم sf-datacloud-*)، أو يطلب موافقة تجارية خاصة بعقد يعتمد على شروط تسعير غير عامة.
