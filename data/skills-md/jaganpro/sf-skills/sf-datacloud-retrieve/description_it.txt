Fase di recupero di Salesforce Data Cloud. TRIGGER quando: l'utente esegue Data Cloud SQL, descrive, query asincrone, ricerca vettoriale, flussi di lavoro di indici di ricerca o introspezione di metadati per oggetti Data Cloud. NON SI ATTIVA quando: l'attività è CRM SOQL standard (usa sf-soql), creazione di segmenti o progettazione di insight calcolati (usa sf-datacloud-segment) o STDM/tracciamento sessioni/analisi parquet (usa sf-ai-agentforce-observability).
