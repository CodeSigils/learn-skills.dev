مرحلة استرداد البيانات السحابية من Salesforce. يتم تشغيله عندما: يقوم المستخدم بتشغيل Data Cloud SQL، أو الوصف، أو الاستعلامات غير المتزامنة، أو البحث المتجه، أو سير عمل فهرس البحث، أو استبطان البيانات التعريفية لكائنات Data Cloud. لا تقم بالتشغيل عندما: تكون المهمة عبارة عن CRM SOQL قياسي (استخدم sf-soql)، أو إنشاء مقطع أو تصميم رؤية محسوبة (استخدم مقطع sf-datacloud)، أو تحليل STDM/تتبع الجلسة/الباركيه (استخدم sf-ai-agentforce-observability).
