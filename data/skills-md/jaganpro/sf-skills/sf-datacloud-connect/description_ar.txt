مرحلة Salesforce Data Cloud Connect. يتم التشغيل عندما: يقوم المستخدم بإدارة اتصالات Data Cloud أو الموصلات أو بيانات تعريف الموصل أو اختبار الاتصال أو تصفح الكائنات المصدر أو قواعد البيانات أو إعداد نظام مصدر جديد. لا تقم بالتشغيل عندما: تتعلق المهمة بتدفقات البيانات أو DLOs (استخدم sf-datacloud-prepare)، أو DMOs أو تحليل الهوية (استخدم sf-datacloud-harmonize)، أو الاسترجاع/البحث (استخدم sf-datacloud-retrieve)، أو قياس STDM عن بعد (استخدم sf-ai-agentforce-observability).
