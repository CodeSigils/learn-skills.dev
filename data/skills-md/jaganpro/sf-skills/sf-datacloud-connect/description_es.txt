Fase de Salesforce Data Cloud Connect. DISPARAR cuando: el usuario administra conexiones, conectores y metadatos de conectores de Data Cloud, prueba una conexión, explora objetos o bases de datos de origen o configura un nuevo sistema de origen. NO DISPARAR cuando: la tarea se refiere a flujos de datos o DLO (use sf-datacloud-prepare), DMO o resolución de identidad (use sf-datacloud-harmonize), recuperación/búsqueda (use sf-datacloud-retrieve) o telemetría STDM (use sf-ai-agentforce-observability).
