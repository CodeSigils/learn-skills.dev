Creación y validación de procedimientos de integración OmniStudio con puntuación de 110 puntos. Utilícelo al crear orquestaciones de procesos del lado del servidor que combinen acciones de Data Mapper, acciones remotas de Apex, llamadas HTTP y lógica condicional. SE DISPARA cuando: el usuario crea procedimientos de integración, agrega pasos de Data Mapper, configura acciones remotas o revisa configuraciones de IP existentes. NO DISPARE cuando: cree OmniScripts (use sf-industry-commoncore-omniscript), cree Data Mappers directamente (use sf-industry-commoncore-datamapper) o analice dependencias entre componentes (use sf-industry-commoncore-omnistudio-analyze).
