Integrazione OmniStudio Creazione e validazione di procedure con punteggio a 110 punti. Da utilizzare quando si creano orchestrazioni di processi lato server che combinano azioni Data Mapper, azioni remote Apex, callout HTTP e logica condizionale. TRIGGER quando: l'utente crea procedure di integrazione, aggiunge passaggi del Data Mapper, configura azioni remote o esamina le configurazioni IP esistenti. NON SI ATTIVA quando: crei OmniScript (usa sf-industry-commoncore-omniscript), crei direttamente Data Mapper (usa sf-industry-commoncore-datamapper) o analizzi le dipendenze tra componenti (usa sf-industry-commoncore-omnistudio-analyze).
