Verwenden Sie diese Fähigkeit immer dann, wenn Benutzer Workflows in Agentforce Grid (AI Workbench) mithilfe von Salesforce plus dem Grid MCP oder direkten Grid-REST-Aufrufen erstellen, prüfen, debuggen, automatisieren oder veröffentlichen möchten. Lösen Sie es für die Erstellung von Grid-Arbeitsmappen, die Einrichtung von Arbeitsblättern, das Spaltendesign „Object/Reference/AI/Agent/AgentTest/Evaluation/PromptTemplate/InvocableAction“, das Erstellen von Eingabeaufforderungen innerhalb von Grid, die Fehlerbehebung bei der Arbeitsblattausführung, Grid-YAML-„apply_grid“-Spezifikationen und Windows-spezifische Grid-Setup-Probleme aus. Verwenden Sie es auch, wenn Benutzer AI Workbench, Grid Studio, Arbeitsmappen-IDs, Arbeitsblatt-IDs, Grid Connect erwähnen oder nach Rezepten wie „Top-Chancen mit AI-E-Mail-Entwürfen“, „Agent-Testsuite in Grid“ oder „Dieses Arbeitsblatt aus YAML erstellen“ fragen. Verwenden Sie es nicht für allgemeine Salesforce-Arbeiten, die nichts mit Agentforce Grid zu tun haben.
