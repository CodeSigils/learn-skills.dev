每当用户想要使用 Salesforce 加上 Grid MCP 或直接 Grid REST 调用在 Agentforce Grid (AI Workbench) 中构建、检查、调试、自动化或发布工作流时，请使用此技能。触发它以进行网格工作簿创建、工作表设置、对象/参考/AI/Agent/AgentTest/Evaluation/PromptTemplate/InvocableAction 列设计、网格内提示起草、工作表执行故障排除、网格 YAML `apply_grid` 规范以及特定于 Windows 的网格设置问题。当用户提到 AI Workbench、Grid Studio、工作簿 ID、工作表 ID、Grid Connect 或询问诸如“AI 电子邮件草稿的最佳机会”、“Grid 中的代理测试套件”或“从 YAML 构建此工作表”等秘诀时，也可以使用它。请勿将其用于与 Agentforce Grid 无关的通用 Salesforce 工作。
