ユーザーが Salesforce と Grid MCP、または直接 Grid REST 呼び出しを使用して、Agentforce Grid (AI Workbench) でワークフローを構築、検査、デバッグ、自動化、または公開したい場合は常に、このスキルを使用します。グリッド ワークブックの作成、ワークシートのセットアップ、Object/Reference/AI/Agent/AgentTest/Evaluation/PromptTemplate/InvocableAction 列の設計、グリッド内のプロンプト ドラフト、ワークシート実行のトラブルシューティング、グリッド YAML の「apply_grid」仕様、および Windows 固有のグリッド セットアップの問題のためにトリガーします。また、ユーザーが AI Workbench、Grid Studio、ワークブック ID、ワークシート ID、Grid Connect について言及したり、「AI メールの下書きで最も重要な機会」、「Grid のエージェント テスト スイート」、「YAML からこのワークシートを構築する」などのレシピを求める場合にも使用します。 Agentforce Grid に関係のない一般的な Salesforce 作業には使用しないでください。
