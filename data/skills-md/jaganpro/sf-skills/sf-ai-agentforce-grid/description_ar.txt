استخدم هذه المهارة عندما يرغب المستخدمون في إنشاء مهام سير العمل أو فحصها أو تصحيح أخطائها أو أتمتتها أو نشرها في Agentforce Grid (AI Workbench) باستخدام Salesforce بالإضافة إلى Grid MCP أو مكالمات Grid REST المباشرة. قم بتشغيله لإنشاء مصنف Grid، وإعداد ورقة العمل، وتصميم عمود Object/Reference/AI/Agent/AgentTest/Evaluation/PromptTemplate/InvocableAction، والصياغة السريعة داخل Grid، واستكشاف أخطاء تنفيذ ورقة العمل وإصلاحها، ومواصفات Grid YAML `apply_grid`، ومشكلات إعداد الشبكة الخاصة بنظام التشغيل Windows. استخدمه أيضًا عندما يذكر المستخدمون AI Workbench أو Grid Studio أو معرفات المصنفات أو معرفات أوراق العمل أو Grid Connect أو يطلبون وصفات مثل "أفضل الفرص مع مسودات البريد الإلكتروني للذكاء الاصطناعي" أو "مجموعة اختبار الوكيل في Grid" أو "إنشاء ورقة العمل هذه من YAML". لا تستخدمه في أعمال Salesforce العامة التي لا علاقة لها بـ Agentforce Grid.
