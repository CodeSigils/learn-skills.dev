Используйте этот навык всякий раз, когда пользователи хотят создавать, проверять, отлаживать, автоматизировать или публиковать рабочие процессы в Agentforce Grid (AI Workbench) с помощью Salesforce плюс Grid MCP или прямых вызовов Grid REST. Запустите его для создания рабочей книги Grid, настройки рабочего листа, проектирования столбцов Object/Reference/AI/Agent/AgentTest/Evaluation/PromptTemplate/InvocableAction, быстрого создания черновиков внутри Grid, устранения неполадок при выполнении рабочих листов, спецификаций Grid YAML `apply_grid` и проблем настройки Grid, специфичных для Windows. Также используйте его, когда пользователи упоминают AI Workbench, Grid Studio, идентификаторы книг, идентификаторы листов, Grid Connect или просят рецепты, такие как «лучшие возможности с черновиками электронной почты AI», «набор тестов агента в Grid» или «создайте этот рабочий лист из YAML». Не используйте его для общей работы Salesforce, не связанной с Agentforce Grid.
