Utilisez cette compétence chaque fois que les utilisateurs souhaitent créer, inspecter, déboguer, automatiser ou publier des flux de travail dans Agentforce Grid (AI Workbench) à l'aide de Salesforce ainsi que de Grid MCP ou d'appels Grid REST directs. Déclenchez-le pour la création du classeur Grid, la configuration de la feuille de calcul, la conception des colonnes Objet/Référence/AI/Agent/AgentTest/Evaluation/PromptTemplate/InvocableAction, la rédaction d'invites dans Grid, le dépannage de l'exécution de la feuille de calcul, les spécifications Grid YAML `apply_grid` et les problèmes de configuration de Grid spécifiques à Windows. Utilisez-le également lorsque les utilisateurs mentionnent AI Workbench, Grid Studio, les ID de classeur, les ID de feuille de calcul, Grid Connect, ou demandent des recettes telles que « les meilleures opportunités avec les brouillons d'e-mails AI », « la suite de tests d'agent dans Grid » ou « créer cette feuille de calcul à partir de YAML ». Ne l'utilisez pas pour des travaux Salesforce génériques sans rapport avec Agentforce Grid.
