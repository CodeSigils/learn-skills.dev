Utilice esta habilidad siempre que los usuarios quieran crear, inspeccionar, depurar, automatizar o publicar flujos de trabajo en Agentforce Grid (AI Workbench) utilizando Salesforce más Grid MCP o llamadas directas de Grid REST. Actívelo para la creación de libros de trabajo de Grid, configuración de hojas de trabajo, diseño de columnas de Objeto/Referencia/AI/Agente/Prueba de agente/Evaluación/PromptTemplate/InvocableAction, redacción rápida dentro de Grid, solución de problemas de ejecución de hojas de trabajo, especificaciones de Grid YAML `apply_grid` y problemas de configuración de Grid específicos de Windows. Úselo también cuando los usuarios mencionen AI Workbench, Grid Studio, ID de libros de trabajo, ID de hojas de trabajo, Grid Connect o soliciten recetas como "principales oportunidades con borradores de correo electrónico de IA", "conjunto de pruebas de agentes en Grid" o "crear esta hoja de trabajo desde YAML". No lo utilice para trabajos genéricos de Salesforce no relacionados con Agentforce Grid.
