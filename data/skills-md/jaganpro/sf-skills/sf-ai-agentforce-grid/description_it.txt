Utilizza questa competenza ogni volta che gli utenti desiderano creare, ispezionare, eseguire il debug, automatizzare o pubblicare flussi di lavoro in Agentforce Grid (AI Workbench) utilizzando Salesforce più Grid MCP o chiamate dirette Grid REST. Attivalo per la creazione di cartelle di lavoro di Grid, l'impostazione di fogli di lavoro, la progettazione di colonne Object/Reference/AI/Agent/AgentTest/Evaluation/PromptTemplate/InvocableAction, la redazione di prompt all'interno di Grid, la risoluzione dei problemi di esecuzione dei fogli di lavoro, le specifiche di Grid YAML `apply_grid` e i problemi di configurazione di Grid specifici di Windows. Usalo anche quando gli utenti menzionano AI Workbench, Grid Studio, ID cartelle di lavoro, ID fogli di lavoro, Grid Connect o chiedono ricette come "migliori opportunità con le bozze di posta elettronica AI", "suite di test dell'agente in Grid" o "crea questo foglio di lavoro da YAML". Non utilizzarlo per attività Salesforce generiche non correlate a Agentforce Grid.
