每當使用者想要使用 Salesforce 加上 Grid MCP 或直接 Grid REST 呼叫在 Agentforce Grid (AI Workbench) 中建置、檢查、偵錯、自動化或發布工作流程時，請使用此技能。觸發它以進行網格工作簿建立、工作表設定、物件/參考/AI/Agent/AgentTest/Evaluation/PromptTemplate/InvocableAction 列設計、網格內提示起草、工作表執行故障排除、網格 YAML `apply_grid` 規格以及特定於 Windows 的網格設定問題。當使用者提到 AI Workbench、Grid Studio、工作簿 ID、工作表 ID、Grid Connect 或詢問諸如「AI 電子郵件草稿的最佳機會」、「Grid 中的代理程式測試套件」或「從 YAML 建立此工作表」等秘訣時，也可以使用它。請勿將其用於與 Agentforce Grid 無關的通用 Salesforce 工作。
