Orquestador de productos Salesforce Data Cloud para flujos de trabajo conectar→preparar→armonizar→segmentar→actuar. DISPARAR cuando: el usuario necesita una canalización de Data Cloud de varios pasos, solicita configurar o solucionar problemas de Data Cloud en todas las fases, administra espacios de datos o kits de datos, o desea un flujo de trabajo "sf data360" de fases cruzadas. NO DISPARAR cuando: el trabajo está aislado en una sola fase (use la habilidad sf-datacloud-* correspondiente), la tarea es STDM/rastreo de sesiones/telemetría de parquet (use sf-ai-agentforce-observability), CRM SOQL estándar (use sf-soql) o implementación de Apex (use sf-apex).
