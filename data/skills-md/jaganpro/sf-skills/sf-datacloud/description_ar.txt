منسق منتج Salesforce Data Cloud للاتصال → التحضير → التنسيق → المقطع → سير العمل الفعلي. يتم التشغيل عندما: يحتاج المستخدم إلى مسار Data Cloud متعدد الخطوات، أو يطلب إعداد Data Cloud أو استكشاف أخطاء Data Cloud عبر المراحل، أو إدارة مساحات البيانات أو مجموعات البيانات، أو يريد سير عمل `sf data360` عبر المراحل. لا تقم بالتشغيل عندما: يكون العمل معزولًا في مرحلة واحدة (استخدم مهارة sf-datacloud-* المطابقة)، وتكون المهمة هي STDM/تتبع الجلسة/القياس عن بعد للباركيه (استخدم sf-ai-agentforce-observability)، أو CRM SOQL القياسي (استخدم sf-soql)، أو تنفيذ Apex (استخدم sf-apex).
