Orchestrateur de produits Salesforce Data Cloud pour les workflows de connexion → préparation → harmonisation → segmentation → action. DÉCLENCHEMENT lorsque : l'utilisateur a besoin d'un pipeline Data Cloud en plusieurs étapes, demande de configurer ou de dépanner Data Cloud à travers les phases, gère des espaces de données ou des kits de données, ou souhaite un workflow "sf data360" multi-phases. NE PAS DÉCLENCHER lorsque : le travail est isolé en une seule phase (utilisez la compétence sf-datacloud-* correspondante), la tâche est une télémétrie STDM/traçage de session/parquet (utilisez sf-ai-agentforce-observability), un SOQL CRM standard (utilisez sf-soql) ou une implémentation Apex (utilisez sf-apex).
