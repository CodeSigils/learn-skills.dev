Orchestratore di prodotti Salesforce Data Cloud per flussi di lavoro di connessione→preparazione→armonizzazione→segmentazione→azione. ATTIVA quando: l'utente ha bisogno di una pipeline Data Cloud in più fasi, chiede di configurare o risolvere i problemi di Data Cloud in tutte le fasi, gestisce spazi dati o kit di dati o desidera un flusso di lavoro "sf data360" multifase. NON SI ATTIVA quando: il lavoro è isolato in una singola fase (utilizzare la competenza sf-datacloud-* corrispondente), l'attività è STDM/tracciamento sessioni/telemetria parquet (utilizzare sf-ai-agentforce-observability), SOQL CRM standard (utilizzare sf-soql) o implementazione Apex (utilizzare sf-apex).
