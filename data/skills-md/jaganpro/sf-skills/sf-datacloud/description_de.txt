Salesforce Data Cloud-Produktorchestrator für Workflows „Verbinden→Vorbereiten→Harmonisieren→Segmentieren→Handeln“. TRIGGER wenn: Der Benutzer benötigt eine mehrstufige Data Cloud-Pipeline, bittet darum, Data Cloud phasenübergreifend einzurichten oder zu beheben, verwaltet Datenräume oder Datenkits oder wünscht einen phasenübergreifenden „sf data360“-Workflow. NICHT AUSLÖSEN, wenn: die Arbeit auf eine einzelne Phase beschränkt ist (verwenden Sie den passenden sf-datacloud-*-Skill), die Aufgabe STDM/Sitzungsverfolgung/Parkett-Telemetrie ist (verwenden Sie sf-ai-agentforce-observability), Standard-CRM-SOQL (verwenden Sie sf-soql) oder Apex-Implementierung (verwenden Sie sf-apex).
