مرحلة قطاع سحابة بيانات Salesforce. يتم تشغيله عندما: يقوم المستخدم بإنشاء شرائح أو نشرها، أو إدارة الرؤى المحسوبة، أو فحص أعداد الشرائح أو العضوية، أو استكشاف أخطاء SQL الخاصة بالجمهور وإصلاحها في Data Cloud. لا تقم بالتشغيل عندما: تكون المهمة هي عمل DMO/التخطيط/تحليل الهوية (استخدم sf-datacloud-harmonize)، أو عمل التنشيط (استخدم sf-datacloud-act)، أو عمل الاستعلام/فهرس البحث (استخدم sf-datacloud-retrieve)، أو تتبع STDM/الجلسة (استخدم sf-ai-agentforce-observability).
