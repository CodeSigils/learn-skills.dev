Передайте задачу CLI агента кодирования другого поставщика — Claude Code, Codex или Kimi Code — запустив ее как безголовый подпроцесс. Используйте, когда пользователь называет одно из них для какой-либо работы («Пусть Кодекс посмотрит на это», «отдай это Кими», «спроси Клода»), в любом направлении и для любого рода задач. Ни для субагентов внутри вашей среды выполнения, ни для переключения моделей внутри одной системы, ни для делегирования, о котором пользователь не запрашивал.
