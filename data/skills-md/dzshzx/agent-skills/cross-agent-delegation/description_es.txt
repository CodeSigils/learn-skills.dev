Entregue una tarea a la CLI del agente de codificación de un proveedor diferente (Claude Code, Codex o Kimi Code) ejecutándola como un subproceso sin cabeza. Se usa cuando el usuario nombra a uno de ellos para un trabajo ("haz que Codex mire esto", "dale este a Kimi", "pregúntale a Claude"), en cualquier dirección y para cualquier tipo de tarea. No para subagentes dentro de su propio tiempo de ejecución, no para cambiar modelos dentro de un arnés y no para delegar que el usuario no solicitó.
