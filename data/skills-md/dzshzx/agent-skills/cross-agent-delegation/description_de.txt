Übergeben Sie eine Aufgabe an die Coding-Agent-CLI eines anderen Anbieters – Claude Code, Codex oder Kimi Code –, indem Sie sie als kopflosen Unterprozess ausführen. Wird verwendet, wenn der Benutzer einen von ihnen für eine Arbeit benennt („Codex soll sich das ansehen“, „Gib das hier Kimi“, „Fragen Sie Claude“), in jede Richtung und für jede Art von Aufgabe. Nicht für Subagenten innerhalb Ihrer eigenen Laufzeit, nicht für den Wechsel von Modellen innerhalb eines Harness und nicht für die Delegierung, die der Benutzer nicht angefordert hat.
