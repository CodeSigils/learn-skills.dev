Affida un compito al CLI di un agente di codifica di un altro fornitore — Claude Code, Codex o Kimi Code — eseguendolo come subprocesso senza interfaccia. Usalo quando l'utente cita uno di loro per un lavoro ("fai dare un'occhiata a Codex", "passa questo a Kimi", "chiedi a Claude"), in qualsiasi direzione e per qualsiasi tipo di compito. Non è per subagenti all'interno del tuo runtime, né per cambiare modello all'interno di un unico harness, né per deleghe che l'utente non ha richiesto.

Rispondi sempre nella lingua dell'utente.
