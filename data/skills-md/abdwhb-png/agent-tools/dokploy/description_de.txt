Zur Verwendung bei der Planung, Bereitstellung oder Fehlerbehebung von Workloads auf Dokploy. Dazu gehört die Wahl zwischen Anwendungs-, Docker Compose- oder Swarm-Bereitstellungsmodellen; Auswahl von Nixpacks, Dockerfile, Static oder vorgefertigten Image-Workflows; Konfigurieren von Domänen, HTTPS, Umgebungsvariablen und Persistenz; und Empfehlung von CI/CD-, Remote-Server- oder Zero-Downtime-Rollout-Strategien. Verwenden Sie dies immer dann, wenn der Benutzer Dokploy direkt erwähnt oder eine von Dokploy gehostete App beschreibt und Plattformentscheidungen statt allgemeiner Docker-Ratschläge benötigt.
