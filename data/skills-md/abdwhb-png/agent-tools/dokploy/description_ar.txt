يُستخدم عند تخطيط أحمال العمل أو نشرها أو استكشاف أخطاءها وإصلاحها على Dokploy. يتضمن ذلك الاختيار بين نماذج النشر Application أو Docker Compose أو Swarm؛ تحديد Nixpacks أو Dockerfile أو Static أو سير عمل الصور المضمنة مسبقًا؛ تكوين المجالات، HTTPS، ومتغيرات البيئة، والثبات؛ والتوصية باستراتيجيات الطرح CI/CD، أو الخادم البعيد، أو عدم التوقف عن العمل. استخدم هذا عندما يذكر المستخدم Dokploy مباشرة أو يصف تطبيقًا مستضافًا على Dokploy ويحتاج إلى قرارات النظام الأساسي بدلاً من نصيحة Docker العامة.
