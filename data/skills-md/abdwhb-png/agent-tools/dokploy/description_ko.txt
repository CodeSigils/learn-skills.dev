Dokploy에서 워크로드를 계획, 배포 또는 문제 해결하는 데 사용합니다. 여기에는 애플리케이션, Docker Compose 또는 Swarm 스타일 배포 모델 중에서 선택하는 것이 포함됩니다. Nixpacks, Dockerfile, Static 또는 사전 구축된 이미지 워크플로우를 선택합니다. 도메인, HTTPS, 환경 변수 및 지속성 구성 CI/CD, 원격 서버 또는 가동 중지 시간 없는 롤아웃 전략을 권장합니다. 사용자가 Dokploy를 직접 언급하거나 Dokploy에서 호스팅하는 앱을 설명하고 일반적인 Docker 조언이 아닌 플랫폼 결정이 필요할 때마다 이를 사용하세요.
