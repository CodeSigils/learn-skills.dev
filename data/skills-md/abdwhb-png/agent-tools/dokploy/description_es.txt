Úselo al planificar, implementar o solucionar problemas de cargas de trabajo en Dokploy. Esto incluye elegir entre modelos de implementación estilo Aplicación, Docker Compose o Swarm; seleccionar Nixpacks, Dockerfile, Static o flujos de trabajo de imágenes prediseñadas; configurar dominios, HTTPS, variables de entorno y persistencia; y recomendar estrategias de implementación de CI/CD, servidor remoto o tiempo de inactividad cero. Utilice esto siempre que el usuario mencione Dokploy directamente o describa una aplicación alojada en Dokploy y necesite decisiones sobre la plataforma en lugar de consejos genéricos de Docker.
