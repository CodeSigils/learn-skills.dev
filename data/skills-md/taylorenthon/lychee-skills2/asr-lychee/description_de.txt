Rufen Sie den Lychee-Openapi-Spracherkennungsendpunkt /open/asr auf, laden Sie eine Audiodatei hoch und geben Sie den erkannten Text zurück.  
Auslöser: Der Benutzer sagt „Audio transkribieren“, „dieses Audio in Text umwandeln“, „diese Sprache erkennen“, „ASR“ oder „/asr-lychee“.  
Verwenden Sie diesen Skill nicht für die Echtzeit-Streaming-Erkennung (Streaming sollte WebSocket verwenden; dieser Skill funktioniert über HTTP Multipart).
