Call the lychee‑openapi speech‑recognition endpoint /open/asr, upload an audio file, and return the recognized text.  
Trigger phrases: the user says “transcribe audio”, “convert this audio to text”, “recognize this speech”, “ASR”, or “/asr‑lychee”.  
Do not use this skill for real‑time streaming recognition (streaming should use WebSocket; this skill works via HTTP multipart).
