Wird geladen, wenn der Benutzer einen Agenten-Skill erstellen, aktualisieren oder umgestalten, das Skill-Routing verbessern, überlange Skill-Anweisungen aufteilen oder einen wiederholten Agenten-Workflow in einen wiederverwendbaren Skill umwandeln möchte. Übergabe an den Skill-Ersteller für Evaluierungsläufe, Paketierung und Optimierung der Triggerbeschreibung.
