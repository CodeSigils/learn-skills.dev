Bereiten Sie eine neue Neben-Alpha-Version von Earth2Studio vor, indem Sie den Release Candidate-Zweig auf den Hauptzweig umbasieren, die Version erhöhen, das Änderungsprotokoll aktualisieren, Beispielversions-Tags entfernen und auf PR drängen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer die Veröffentlichung, das Schneiden einer Veröffentlichung, die Vorbereitung eines Veröffentlichungszweigs, die Neubasierung einer Veröffentlichung, die Erhöhung der Version für einen neuen Entwicklungszyklus oder die Ausführung des Veröffentlichungsprozesses erwähnt. Wird auch ausgelöst, wenn der Benutzer auf „release-rebase“ verweist oder nach dem Release-Workflow fragt.
