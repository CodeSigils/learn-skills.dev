Запустите состязательную проверку артефакта PM через субагент pm-critic. Отправляет исходно на Claude Code с плагином pm-skills (вызывает @agent-pm-critic); на клиентах, отличных от Claude (CLI Codex, Cursor, Windsurf, Copilot, Gemini CLI), читает subagents/pm-critic.md и выполняет встроенное системное приглашение. Возвращает результаты с оценками P0/P1/P2/P3 с конкретными предложениями по исправлению каждого результата, а также многоуровневый раздел сводки состояния и машиночитаемый блок YAML состояния для каждого генерального плана D26.
