Проведите сквозной аудит управления в рамках всего репо с помощью субагента pm-skill-auditor. Отправляет исходно на Claude Code с плагином pm-skills (вызывает @agent-pm-skill-auditor); на клиентах, отличных от Claude (CLI Codex, Cursor, Windsurf, Copilot, Gemini CLI), читает subagents/pm-skill-auditor.md и выполняет встроенное системное приглашение. Возвращает многоуровневый отчет об аудите (полные выводы + краткое описание статуса + конверт YAML статуса для каждого генерального плана D26) со сквозными выводами с оценкой P0/P1/P2/P3, а также совокупный счетчик аудита и таблицу результатов валидатора.
