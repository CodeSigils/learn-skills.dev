pm-changelog-curator サブエージェントを介して git log から CHANGELOG エントリをドラフトします。 pm-skills プラグインを使用してクロード コードでネイティブにディスパッチします (@agent-pm-changelog-curator を呼び出します)。 Claude 以外のクライアント (Codex CLI、Cursor、Windsurf、Copilot、Gemini CLI) では、subagents/pm-changelog-curator.md を読み取り、システム プロンプトをインラインで実行します。 CLAUDE.md の衛生ルールを適用します (内部メモの参照なし、全角ダッシュなし、クロード帰属トレーラーなし、パブリック パスのみ)。メンテナー監査のための非表示の正当化コメントを含む、階層化されたドラフト (完全な CHANGELOG ドラフト + ステータス概要の文章 + マスター プラン D26 ごとのステータス YAML エンベロープ) を返します。 --committed-only が渡されない限り、ダーティ作業ツリーでは拒否されます。
