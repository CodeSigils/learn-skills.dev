pm-changelog-curator 하위 에이전트를 통해 git 로그에서 CHANGELOG 항목 초안을 작성합니다. pm-skills 플러그인(@agent-pm-changelog-curator 호출)을 사용하여 Claude Code에서 기본적으로 디스패치합니다. Claude가 아닌 클라이언트(Codex CLI, Cursor, Windsurf, Copilot, Gemini CLI)에서는 subagents/pm-changelog-curator.md를 읽고 시스템 프롬프트 인라인을 실행합니다. CLAUDE.md 위생 규칙을 적용합니다(내부 노트 참조 없음, 엠 대시 없음, Claude 속성 예고편 없음, 공개 경로만 해당). 유지 관리자 감사에 대한 숨겨진 정당성 설명과 함께 계층화된 초안(전체 CHANGELOG 초안 + 상태 요약 구문 + 마스터 플랜 D26당 상태 YAML 봉투)을 반환합니다. --committed-only가 전달되지 않는 한 더티 작업 트리를 거부합니다.
