Черновики записей CHANGELOG из журнала git через субагент pm-changelog-curator. Отправляет исходно на Claude Code с помощью плагина pm-skills (вызывает @agent-pm-changelog-curator); на клиентах, отличных от Claude (CLI Codex, Cursor, Windsurf, Copilot, Gemini CLI), читает subagents/pm-changelog-curator.md и выполняет встроенное системное приглашение. Применяет правила гигиены CLAUDE.md (без ссылок на внутренние заметки, без тире, без трейлеров с указанием авторства Claude, только общедоступные пути). Возвращает многоуровневый черновик (полный черновик CHANGELOG + краткое описание статуса + конверт YAML статуса для генерального плана D26) со скрытыми комментариями обоснования для аудита сопровождающего. Отказывается от грязного рабочего дерева, если не указан параметр --commited-only.
