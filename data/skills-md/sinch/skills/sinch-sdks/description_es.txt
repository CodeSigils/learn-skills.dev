Instalación de Sinch SDK e inicialización del cliente para Node.js, Python, Java y .NET. Úselo al instalar un SDK de Sinch, inicializar SinchClient, configurar las credenciales del SDK, configurar la región de conversación en el SDK o crear un cliente SDK multiproducto. Para conocer los SDK de llamadas dentro de la aplicación, consulte llamadas sinch-in-app.
