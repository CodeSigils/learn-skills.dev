Установка Sinch SDK и инициализация клиента для Node.js, Python, Java и .NET. Используйте при установке Sinch SDK, инициализации SinchClient, настройке учетных данных SDK, настройке региона диалога в SDK или создании многопродуктового клиента SDK. Информацию о SDK для вызовов в приложении см. в разделе «Вызовы в приложении».
