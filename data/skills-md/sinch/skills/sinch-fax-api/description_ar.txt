قم بإرسال واستقبال رسائل الفاكس برمجيًا باستخدام Sinch Fax API. يُستخدم عند إنشاء مسارات عمل الفاكس، أو التسليم من الفاكس إلى البريد الإلكتروني، أو إرسال ملفات PDF عبر الفاكس، أو التحقق من حالة الفاكس، أو إدارة خدمات الفاكس، أو تكوين صفحات الغلاف، أو تلقي خطافات الفاكس على الويب، أو دمج الفاكس في تطبيقات الرعاية الصحية أو التطبيقات القانونية أو المالية.
