Suchen, mieten, verwalten und geben Sie Telefonnummern mit der Sinch Numbers API frei. Verwenden Sie diese Funktion, wenn Sie aktive Nummern auflisten, nach verfügbaren Nummern suchen, Nummern mieten oder freigeben, die Nummernkonfiguration aktualisieren (SMS/Sprache/Rückruf), Notfalladressen verwalten oder verfügbare Regionen überprüfen.
