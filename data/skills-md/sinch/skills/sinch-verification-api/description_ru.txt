Подтверждайте номера телефонов с помощью SMS, Flashcall, телефонного звонка, данных (бесшовный уровень оператора связи) или WhatsApp с помощью Sinch Verification API. Используйте при реализации потоков проверки телефона пользователя, одноразового пароля, двухфакторной аутентификации или подтверждения владения номером.
