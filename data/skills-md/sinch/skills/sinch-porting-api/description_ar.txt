قم بنقل أرقام الهواتف من شركات النقل الأخرى إلى Sinch باستخدام Porting API. أتمتة عملية إنشاء طلب النقل، وفحص قابلية النقل، وتتبع الطلب، والتنشيط عند الطلب، وإشعارات خطاف الويب. يُستخدم عند نقل الأرقام، أو التحقق من إمكانية النقل، أو إنشاء أوامر النقل، أو تتبع حالة المنفذ، أو تنشيط الأرقام المنقولة، أو تحميل مستندات LOA، أو تكوين إعدادات النقل الافتراضية.
