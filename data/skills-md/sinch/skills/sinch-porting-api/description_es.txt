Transfiera números de teléfono de otros operadores a Sinch con la API de transferencia. Automatiza la creación de pedidos de transferencia, comprobaciones de portabilidad, seguimiento de pedidos, activación bajo demanda y notificaciones de webhooks. Úselo al transferir números, verificar la portabilidad, crear órdenes de transferencia, rastrear el estado del puerto, activar números transferidos, cargar documentos LOA o configurar valores predeterminados de transferencia.
