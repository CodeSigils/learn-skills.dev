Перенесите телефонные номера других операторов связи в Sinch с помощью API переноса. Автоматизирует создание заказов на перенос, проверку переносимости, отслеживание заказов, активацию по требованию и уведомления веб-перехватчика. Используйте при переносе номеров, проверке переносимости, создании заказов на перенос, отслеживании статуса порта, активации перенесенных номеров, загрузке документов LOA или настройке параметров переноса по умолчанию.
