Mailgun Optimize (InboxReady) API を介して電子メールの到達性を監視します。ユーザーがシード リストを使用して受信トレイの配置をテストする場合、IP またはドメインのブロックリストを監視する場合、スパム トラップを追跡する場合、電子メールの健全性スコアを確認する場合、DMARC レポートを確認する場合、または Google Postmaster または Microsoft SNDS データを取得する場合に使用します。また、電子メールがスパムになる場合、送信者の評判が低下している場合、受信トレイの速度が低下している場合、ドメインのウォームアップ監視が必要な場合、IP のブロックリストの削除が必要な場合、またはユーザーが電子メールの到達性監視を設定したい場合にも使用します。
