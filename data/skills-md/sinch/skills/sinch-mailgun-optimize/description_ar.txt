يراقب إمكانية تسليم البريد الإلكتروني عبر واجهة برمجة تطبيقات Mailgun Optimize (InboxReady). يُستخدم عندما يريد المستخدم اختبار موضع البريد الوارد باستخدام قوائم البذور، أو مراقبة قوائم IP أو قوائم حظر النطاق، أو تتبع مصائد البريد العشوائي، أو التحقق من نتائج صحة البريد الإلكتروني، أو مراجعة تقارير DMARC، أو سحب بيانات Google Postmaster أو Microsoft SNDS. يُستخدم أيضًا عندما تصل رسائل البريد الإلكتروني إلى رسائل غير مرغوب فيها، أو تنخفض سمعة المرسل، أو ينخفض ​​معدل البريد الوارد، أو يحتاج المجال إلى مراقبة تمهيدية، أو يحتاج عنوان IP إلى إزالة قائمة الحظر، أو يريد المستخدم إعداد مراقبة إمكانية تسليم البريد الإلكتروني.
