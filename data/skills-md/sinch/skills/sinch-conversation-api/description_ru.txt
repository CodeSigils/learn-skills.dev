Отправляет и получает многоканальные сообщения с помощью Sinch Conversation API. Один унифицированный API для SMS, WhatsApp, RCS, MMS, Viber, Messenger и многого другого. Используйте при отправке текстовых сообщений, сообщений WhatsApp, расширенных карточек, каруселей, шаблонов, пакетных сообщений или создания многоканального обмена сообщениями.
