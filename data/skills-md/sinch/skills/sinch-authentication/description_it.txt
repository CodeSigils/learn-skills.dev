Configura le credenziali e l'autenticazione dell'API Sinch. Da utilizzare durante la configurazione di OAuth2, autenticazione di base, firma dell'applicazione o chiavi API per qualsiasi prodotto Sinch, inclusi API di conversazione, Voce, Verifica, Numeri, Fax e Mailgun. Da utilizzare anche per la risoluzione dei problemi 401 Non autorizzato, 403 Proibito, firma non valida o errori di credenziale rispetto a qualsiasi API Sinch. Per l'utilizzo degli SDK, consulta sinch-sdks.
