Configura las credenciales y la autenticación de la API de Sinch. Úselo al configurar OAuth2, autenticación básica, firma de aplicaciones o claves API para cualquier producto Sinch, incluida la API de conversación, voz, verificación, números, fax y Mailgun. Úselo también para solucionar problemas 401 no autorizado, 403 prohibido, firma no válida o errores de credenciales en cualquier API de Sinch. Para conocer el uso de SDK, consulte sinch-sdks.
