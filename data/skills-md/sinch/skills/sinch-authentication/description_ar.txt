تكوين بيانات اعتماد Sinch API والمصادقة. يُستخدم عند إعداد OAuth2، أو المصادقة الأساسية، أو توقيع التطبيق، أو مفاتيح API لأي منتج Sinch بما في ذلك Conversation API، والصوت، والتحقق، والأرقام، والفاكس، وMailgun. استخدمه أيضًا عند استكشاف أخطاء 401 غير مصرح به، أو 403 محظور، أو التوقيع غير الصالح، أو أخطاء بيانات الاعتماد ضد أي Sinch API. لاستخدام أدوات تطوير البرامج (SDKs)، راجع sinch-sdks.
