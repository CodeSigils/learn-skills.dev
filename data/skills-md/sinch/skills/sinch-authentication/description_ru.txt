Настраивает учетные данные и аутентификацию Sinch API. Используйте при настройке OAuth2, базовой аутентификации, подписи приложений или ключей API для любого продукта Sinch, включая Conversation API, Voice, Verification, Numbers, Fax и Mailgun. Также используйте при устранении ошибок 401 Unauthorized, 403 Forbidden, неверной подписи или учетных данных в отношении любого API Sinch. Информацию об использовании SDK см. в разделе sinch-sdks.
