Отправляет, получает и отслеживает электронную почту через API Mailgun (Sinch). Используйте, когда пользователь хочет отправлять электронную почту, управлять доменами, настраивать веб-перехватчики, запрашивать события/журналы электронной почты, управлять шаблонами, обрабатывать подавления (возвраты, отписки, жалобы), настраивать входящие маршруты, управлять списками рассылки, ключами DKIM или прогревом IP с помощью Mailgun.
