Guía el flujo de trabajo de pedidos de números de varios pasos para comprar números de teléfono que cumplan con KYC a través de la API de Sinch Numbers. Úselo al comprar, realizar pedidos, aprovisionar o activar números Sinch en países que requieren registro KYC, cumplimiento normativo o verificación de identidad. Activadores de "orden de número", "KYC", "registro de número", "compra de número de teléfono" o "aprovisionamiento de número".
