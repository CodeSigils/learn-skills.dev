Leitet den mehrstufigen Nummernbestellungs-Workflow für den Kauf von Telefonnummern mit KYC-Konformität über die Sinch Numbers API. Verwenden Sie diese Option beim Kauf, Bestellen, Bereitstellen oder Aktivieren von Sinch-Nummern in Ländern, die eine KYC-Registrierung, die Einhaltung gesetzlicher Vorschriften oder eine Identitätsprüfung erfordern. Wird bei „Nummernbestellung“, „KYC“, „Nummernregistrierung“, „Rufnummernkauf“ oder „Nummernbereitstellung“ ausgelöst.
