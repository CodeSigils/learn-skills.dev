Управляет многоэтапным рабочим процессом заказа номеров для покупки телефонных номеров с соблюдением KYC через API Sinch Numbers. Используйте при покупке, заказе, предоставлении или активации номеров Sinch в странах, где требуется регистрация KYC, соблюдение нормативных требований или проверка личности. Срабатывает при «заказе номера», «KYC», «регистрации номера», «покупке номера телефона» или «предоставлении номера».
