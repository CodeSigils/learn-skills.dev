Создавайте голосовые приложения с помощью Sinch Voice REST API. Используйте для телефонных звонков, преобразования текста в речь (TTS), меню IVR, ввода DTMF, конференц-связи, записи вызовов, переадресации вызовов, обнаружения автоответчика (AMD), маршрутизации SIP, потоковой передачи звука через WebSocket и управления вызовами SVAML.
