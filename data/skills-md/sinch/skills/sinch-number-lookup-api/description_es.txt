Busca los detalles del número de teléfono a través de la API de búsqueda de números Sinch. Úselo al verificar el operador, el tipo de línea, el estado de la transferencia, el intercambio de SIM, la detección de VoIP o la detección de números reasignados (RND) para prevenir fraudes o tomar decisiones de enrutamiento.
