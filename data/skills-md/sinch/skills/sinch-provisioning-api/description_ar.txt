توفير وإدارة موارد القناة لمشاريع Conversation API، بما في ذلك حسابات WhatsApp/المرسلين/القوالب، ومرسلي RCS، ومرسلي/قوالب KakaoTalk، وخطافات الويب، والحزم. يُستخدم عندما يطلب المستخدم ضم القنوات، أو تكوين خطافات الويب الخاصة بالتوفير، أو إدارة القوالب، أو تنسيق حزم الخدمات المتعددة، أو أتمتة إعداد القناة.
