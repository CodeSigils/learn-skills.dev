Se utiliza para agregar, localizar o ajustar pruebas para OpenHarmony BundleManager. Úselo cuando el requisito implique pruebas unitarias, pruebas de sistemas, pruebas de módulos, evaluaciones comparativas, pruebas fuzz, objetivos de prueba GN, burlas, pruebas de HAP/recursos, pruebas de procesos de instalación, pruebas de IPC, pruebas de permisos/validación o diseño de pruebas de regresión.
