Utilizzato per aggiungere, individuare o modificare i test per OpenHarmony BundleManager. Applicarlo quando il requisito prevede test di unità, test di sistema, test di moduli, benchmark, fuzzing, obiettivi di test GN, mocking, test HAP/risorse, test del processo di installazione, test IPC, test di autorizzazione/convalida o progettazione di test di regressione.
