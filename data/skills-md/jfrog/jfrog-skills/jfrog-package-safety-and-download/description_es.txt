Consulte el catálogo público de JFrog y los paquetes almacenados para obtener una versión, interprete las señales de seguridad del catálogo y descargue a través de Artifactory (ubicaciones de la plataforma Jfrog, caché remoto, administradores de paquetes con control de curación o proxy de repositorio). Úselo cuando el usuario pregunta si un paquete es seguro, está permitido, está curado o desea descargar npm, Maven, PyPI, Go o paquetes similares a través de JFrog. NO lo utilice para búsquedas puras de CVE o vulnerabilidades (por ejemplo, "detalles sobre CVE-2021-23337"); estas se manejan mediante las consultas de dominio de seguridad pública de la habilidad jfrog sin este flujo de trabajo.
