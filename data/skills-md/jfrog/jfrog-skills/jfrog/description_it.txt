Interagisci con la piattaforma JFrog tramite la CLI JFrog e le API REST/GraphQL. Utilizzare questa competenza quando l'utente desidera gestire i repository Artifactory, caricare o scaricare artefatti, gestire build, configurare autorizzazioni, gestire utenti e gruppi, lavorare con token di accesso, configurare server CLI JFrog, cercare artefatti, gestire proprietà, impostare la replica, gestire progetti JFrog, eseguire controlli o scansioni di sicurezza, cercare dettagli CVE, eseguire query sui risultati della scansione delle esposizioni da JFrog Advanced Security, gestire pacchetti di rilascio e operazioni del ciclo di vita, aggregare o esportare dati della piattaforma o eseguire qualsiasi attività di amministrazione della piattaforma JFrog. Utilizzare anche quando l'utente menziona jf, jfrog, artifactory, xray, distribution, prove, apptrust, onemodel, graphql, lavoratori, controllo missione, curation, sicurezza avanzata, esposizioni o qualsiasi nome di prodotto JFrog.
