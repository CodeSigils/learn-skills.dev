Пакет публикации коротких видео. Используется для создания заголовков, ссылок на первый экран, ссылок на разделы комментариев, тегов, версий A/B-тестирования и проверки гипотез для каждого видео. Триггерные методы: /bmz-publish, /publish‑package, «создать пакет публикации», «помогите мне написать заголовок», «помогите мне создать версию для A/B-тестирования».
