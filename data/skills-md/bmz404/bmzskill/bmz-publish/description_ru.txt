Пакет для публикации коротких видеороликов. Используется для создания заголовков, ссылок на первый экран, ссылок на разделы комментариев, тегов, версий A/B-тестирования и проверки гипотез для каждого видео. Триггерные методы: /bmz-publish, /publish-package, «создать пакет публикации», «помогите мне написать заголовок», «помогите мне создать версии для A/B-тестирования». Пакет публикации коротких видеороликов для тестов релиза музыки. Триггер: /bmz-publish, «создать пакет публикации», «написать заголовок и хуки».
