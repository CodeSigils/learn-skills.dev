Paquete de publicación de vídeos cortos. Se utiliza para generar títulos, enlaces de copia de primera pantalla, enlaces de sección de comentarios, etiquetas, versiones de prueba A/B y hipótesis de prueba para cada vídeo. Métodos de activación: /bmz-publish, /publish‑package, “generar paquete de publicación”, “ayúdame a escribir un título”, “ayúdame a crear una versión de prueba A/B”.
