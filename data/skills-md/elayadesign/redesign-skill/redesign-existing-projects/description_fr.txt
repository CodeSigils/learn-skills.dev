Audite et met à niveau les sites Web et les applications existants vers une qualité supérieure. Diagnostique les modèles de conception génériques de l'IA, les états faibles et le code bâclé, puis applique des correctifs ciblés sans interrompre les fonctionnalités. Utilisez cette compétence chaque fois que l'utilisateur souhaite améliorer, peaufiner, mettre à niveau, affiner, auditer, réparer ou reconcevoir un site, une page, une application ou un composant EXISTANT, même s'il dit seulement qu'il a l'air mauvais, bon marché, générique ou créé par l'IA. Fonctionne avec n'importe quel framework CSS ou CSS vanille.
