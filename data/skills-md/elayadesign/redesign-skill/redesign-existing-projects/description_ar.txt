تدقيق وترقية مواقع الويب والتطبيقات الحالية إلى الجودة الممتازة. يقوم بتشخيص أنماط تصميم الذكاء الاصطناعي العامة والحالات الضعيفة والتعليمات البرمجية غير الدقيقة، ثم يطبق الإصلاحات المستهدفة دون تعطيل الوظائف. استخدم هذه المهارة عندما يريد المستخدم تحسين أو تلميع أو ترقية أو تحسين أو تدقيق أو إصلاح أو إعادة تصميم موقع أو صفحة أو تطبيق أو مكون موجود، حتى عندما يقولون فقط إنه يبدو سيئًا أو رخيصًا أو عامًا أو مصنوعًا بواسطة الذكاء الاصطناعي. يعمل مع أي إطار عمل CSS أو Vanilla CSS.
