عندما يطلب المستخدم أيًا من الأنواع التالية - مخطط معماري، أو مخطط انسيابي، أو مخطط حارة، أو مخطط تسلسلي، أو مخطط هيكلي، أو آلة حالة، أو مسار قمع، أو مخطط جانت، أو معلم رئيسي، أو رباعي المصفوفة، أو بنية الارتباط، أو بنية نمط مرسومة يدويًا، أو مخطط حارة عمل معقد، أو مخطط ER، أو خريطة ذهنية - ويريد تنفيذه في Feishu، أو يوفر عنوان URL لمستند Feishu ويطلب رسم رسم تخطيطي بداخله، أو يقول "مزامنة مع Feishu / الكتابة إلى Feishu" "السبورة البيضاء"، يجب استخدام هذه الإمكانية. بالإضافة إلى القوالب الـ 17 المدمجة المذكورة أعلاه، توفر هذه الإمكانية أيضًا "وضع رسم حر": عندما يطلب المستخدم إنشاء لوحة زيتية، أو رسم توضيحي مرسوم يدويًا، أو نموذج أولي لتطبيق جوال، أو خريطة، أو شاشة لعبة، أو مخطط Sankey، أو أي إعادة إنشاء صورة مرجعية لا تغطيها القوالب، أو يقول صراحة "رسم حر / انطلق إلى البرية / لا تستخدم قالبًا"، يجب استخدام نفس الإمكانية (يظل الإخراج عبارة عن لوحة معلومات Feishu قابلة للتحرير). يجب أن يتبع خط أنابيب الإنشاء الخطوات الثماني بدقة: تطبيع → تحديد → خطة → تخطيط → عرض → StaticCheck → VQA → تسليم. يحظر استخدام القوالب ذات الترميز الثابت أو الإحداثيات ذات الترميز الثابت أو اختلاق محتوى تجاري لم يذكره المستخدم. تتم قراءة جميع الأنماط من الأصول/style‑tokens/ (باستثناء مخططات التعليمات البرمجية الأصلية ووضع الشكل الحر). قبل التسليم، يجب أن تجتاز النتيجة بوابة الجودة (التي يتم تنفيذها وفقًا للتوجيه) والفحص البصري للمراجع المزدوج (أي درجة أقل من 9 أو أي مانع يؤدي إلى الفشل).
