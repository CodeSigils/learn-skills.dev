عندما يطلب المستخدم أي نوع مثل "مخطط معماري / مخطط انسيابي / مخطط مسار السباحة / مخطط تسلسلي / مخطط هيكلي / آلة الحالة / مخطط قمع / مخطط جانت / معلم بارز / رباعي المصفوفة / بنية الارتباط / تصميم نمط مرسوم يدويًا / مخطط مسار مسار الأعمال المعقد / مخطط ER / خريطة ذهنية" ويريد تنفيذه في Feishu، أو يقدم عنوان URL لمستند Feishu ويطلب الرسم بداخله، أو يقول "المزامنة مع Feishu / الكتابة إلى Feishu Whiteboard"، يجب أن تكون هذه المهارة تستخدم. بالإضافة إلى القوالب الـ 17 المضمنة المذكورة أعلاه، توفر هذه المهارة أيضًا "وضع رسم حر (رسم حر)": عندما يطلب المستخدم إنشاء لوحة زيتية / رسم توضيحي مرسوم يدويًا / نموذج أولي لتطبيق جوال / خريطة / شاشة لعبة / مخطط سانكي / أي إعادة بناء صورة مرجعية لا تغطيها القوالب، أو يقول صراحة "رسم حر / كن مبدعًا / لا تستخدم قالبًا"، يجب أيضًا استخدام المهارة (يظل الناتج عبارة عن لوحة معلومات Feishu قابلة للتحرير). يجب أن يتبع خط أنابيب الإنشاء الخطوات الثماني بدقة: تطبيع → تحديد → خطة → تخطيط → تقديم → StaticCheck → VQA → تسليم؛ يحظر استخدام القوالب ذات الترميز الثابت أو الإحداثيات ذات الترميز الثابت أو اختلاق محتوى تجاري لم يذكره المستخدم. تتم قراءة جميع الأنماط من الأصول/رموز الأنماط/ (باستثناء المخططات البرمجية الأصلية ووضع الرسم الحر). قبل التسليم، يجب أن تمر عبر بوابة الجودة (التي يتم تنفيذها وفقًا للتوجيه) والمراجعة البصرية للمراجع المزدوج (أي تصنيف أقل من 9 أو أي مانع يؤدي إلى الفشل).
