When a user requests any of the following types—architecture diagram, flowchart, swimlane diagram, sequence diagram, organization chart, state machine, funnel, Gantt chart, milestone, matrix quadrant, link architecture, hand‑drawn style architecture, complex business swimlane diagram, ER diagram, or mind map—and wants it implemented in Feishu, or provides a Feishu document URL and asks for a diagram to be drawn within it, or says “sync to Feishu / write to Feishu whiteboard,” this capability must be used. In addition to the 17 built‑in templates mentioned above, this capability also offers a “freeform drawing mode”: when a user asks to create an oil painting, hand‑drawn illustration, mobile app prototype, map, game screen, Sankey diagram, or any reference‑image recreation that the templates do not cover, or explicitly says “free drawing / go wild / don’t use a template,” the same capability must be used (the output remains an editable Feishu whiteboard). The generation pipeline must strictly follow the eight steps: Normalize → Select → Plan → Layout → Render → StaticCheck → VQA → Deliver. Hard‑coding templates, hard‑coding coordinates, or fabricating business content not mentioned by the user is prohibited. All styles are read from assets/style‑tokens/ (except native code diagrams and freeform mode). Before delivery, the result must pass the quality gate (executed according to routing) and a double‑reviewer visual check (any score below 9 or any blocker results in failure).
