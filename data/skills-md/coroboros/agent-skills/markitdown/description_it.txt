Converti qualsiasi documento in Markdown con la CLI "markitdown" di Microsoft: PDF, Word, Excel, PowerPoint, HTML, CSV, JSON, XML, ZIP, EPub, immagini (OCR/EXIF), audio (trascrizione) e URL di YouTube. Da utilizzare ogni volta che l'utente desidera estrarre testo da un documento binario, trascrivere audio, eseguire l'OCR di un'immagine, raschiare una trascrizione di YouTube o pre-elaborare un file per una finestra di contesto LLM, anche quando dice semplicemente "converti questo pdf", "cosa c'è in questo docx", "trascrivi questo mp3" o "estrai il testo da questo".
