Convierta cualquier documento a Markdown con la CLI `markitdown` de Microsoft: PDF, Word, Excel, PowerPoint, HTML, CSV, JSON, XML, ZIP, EPub, imágenes (OCR/EXIF), audio (transcripción) y URL de YouTube. Úselo siempre que el usuario quiera extraer texto de un documento binario, transcribir audio, realizar OCR de una imagen, extraer una transcripción de YouTube o preprocesar un archivo para una ventana contextual de LLM, incluso cuando simplemente diga "convertir este pdf", "qué hay en este docx", "transcribir este mp3" o "sacar el texto de esto".
