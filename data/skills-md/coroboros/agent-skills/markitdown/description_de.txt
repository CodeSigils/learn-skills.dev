Konvertieren Sie jedes Dokument mit der „markitdown“-CLI von Microsoft in Markdown – PDF, Word, Excel, PowerPoint, HTML, CSV, JSON, XML, ZIP, EPub, Bilder (OCR/EXIF), Audio (Transkription) und YouTube-URLs. Verwenden Sie es immer dann, wenn der Benutzer Text aus einem Binärdokument extrahieren, Audio transkribieren, ein Bild mit OCR OCR bearbeiten, ein YouTube-Transkript extrahieren oder eine Datei für ein LLM-Kontextfenster vorverarbeiten möchte – selbst wenn er nur sagt: „Dieses PDF konvertieren“, „Was ist in diesem Dokument“, „Diese MP3 transkribieren“ oder „Den Text daraus herausholen“.
