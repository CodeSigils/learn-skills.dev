Преобразуйте любой документ в Markdown с помощью интерфейса командной строки markitdown от Microsoft — PDF, Word, Excel, PowerPoint, HTML, CSV, JSON, XML, ZIP, EPub, изображения (OCR/EXIF), аудио (транскрипция) и URL-адреса YouTube. Используйте всякий раз, когда пользователь хочет извлечь текст из двоичного документа, расшифровать аудио, распознать изображение, очистить стенограмму YouTube или предварительно обработать файл для контекстного окна LLM — даже когда он просто говорит «конвертировать этот pdf», «что в этом документе», «расшифровать этот mp3» или «вытащить текст из этого».
