Convertissez n'importe quel document en Markdown avec la CLI « markitdown » de Microsoft : PDF, Word, Excel, PowerPoint, HTML, CSV, JSON, XML, ZIP, EPub, images (OCR/EXIF), audio (transcription) et URL YouTube. À utiliser chaque fois que l'utilisateur souhaite extraire du texte d'un document binaire, transcrire de l'audio, OCR une image, gratter une transcription YouTube ou prétraiter un fichier pour une fenêtre contextuelle LLM - même s'il dit simplement « convertir ce pdf », « qu'y a-t-il dans ce docx », « transcrire ce mp3 » ou « extraire le texte de ceci ».
