Aufruf vor einem Commit oder PR – „Meine Änderungen überprüfen“, „eingehend prüfen“, „Habe ich etwas verpasst“, „überprüfen, bevor ich einen Commit durchführe“, „diesen PR prüfen“, „Drift/Lücken/blinde Flecken“.
