Восьмиосный анализ кода для текущих различий — корректность, упрощение, тесты, документация, стиль, намерение, дизайн/API, производительность (+ согласованность изменений метаданных). Пятиэтапный объем конвейера → набор детерминированных инструментов (предпочтительно npx/uvx, нулевая установка для большинства JS + Python) → 8 параллельных рецензентов по оси LLM → валидаторы Haiku для результатов менее 80 (дословная рубрика, порог ≥80) → синтез с отсутствием молчания + обычные комментарии JSONL. Каждый отчет заканчивается словами «Что я НЕ проверял» (безопасность → /security-review, производительность среды выполнения, обнаружение нестабильностей). Флаги согласия `--verify-build`, `--mutation-test`, `--reconcile`, `--apply-safe`. Позиция общедоступных навыков — отсутствие автоматической установки, плавный пропуск отсутствующих встроенных инструментов. Вызов перед коммитом или PR — «просмотрите мои изменения», «глубокий обзор», «я что-то пропустил», «проверьте перед коммитом», «проверьте этот PR», «дрейф/пробелы/слепые зоны».
