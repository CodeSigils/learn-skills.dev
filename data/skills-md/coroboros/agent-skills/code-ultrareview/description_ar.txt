مراجعة كود الحكم المكون من ثمانية محاور للفرق الحالي - الصحة، والتبسيط، والاختبارات، والتوثيق، والأسلوب، والنية، والتصميم/واجهة برمجة التطبيقات، والأداء (+ التماسك في تغييرات البيانات الوصفية). نطاق خط أنابيب ذو خمس مراحل → بطارية أداة حتمية (مفضلة بـ npx/uvx، تثبيت صفري لأغلبية JS + Python) → 8 مراجعين متوازيين لمحور LLM → مدققي Haiku على النتائج دون 80 (عنوان حرفي، عتبة ≥80) → التوليف بدون إسقاط صامت + التعليقات التقليدية JSONL. يتم إغلاق كل تقرير بـ "ما لم أتحقق منه" (الأمان → / مراجعة الأمان، أداء وقت التشغيل، الكشف غير المستقر). علامات الاشتراك `--التحقق من البناء`، `--اختبار الطفرة`، `--التسوية`، `--التطبيق الآمن`. وضعية المهارات العامة - عدم التثبيت التلقائي، والتخطي السلس للأدوات الأصلية المفقودة. قم بالاستدعاء قبل الالتزام أو العلاقات العامة - "مراجعة تغييراتي"، "مراجعة عميقة"، "هل فاتني أي شيء"، "تحقق قبل الالتزام"، "تدقيق هذه العلاقات العامة"، "الانجراف/الفجوات/النقاط العمياء".
