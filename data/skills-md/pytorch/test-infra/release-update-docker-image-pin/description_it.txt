Blocca (o ricollega) le immagini docker del builder manywheel Linux utilizzate dai flussi di lavoro di build binari nightly/release in pytorch/pytorch su una build .ci/docker fissa. Prende la versione di rilascio (ad esempio 2.13) come input. Aggiorna DOCKER_IMAGE_PIN in .github/scripts/generate_binary_build_matrix.py e rigenera i flussi di lavoro. Attivato da menzioni di "pin docker image", "aggiorna docker pin", "docker image pin", "immagini pin builder" o "bump the manywheel image pin" per un ramo di rilascio.
