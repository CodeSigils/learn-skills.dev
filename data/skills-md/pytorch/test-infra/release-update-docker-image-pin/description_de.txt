Die von den Nightly/Release-Binär-Build-Workflows in Pytorch/Pytorch verwendeten Linux-Manywheel-Builder-Docker-Images an einen festen .ci/Docker-Build anheften (oder erneut anheften). Nimmt die Release-Version (z. B. 2.13) als Eingabe. Aktualisiert DOCKER_IMAGE_PIN in .github/scripts/generate_binary_build_matrix.py und generiert die Workflows neu. Ausgelöst durch Erwähnungen von „Pin Docker Image“, „Update Docker Pin“, „Docker Image Pin“, „Pin Builder Images“ oder „Bump the Manywheel Image Pin“ für einen Release-Zweig.
