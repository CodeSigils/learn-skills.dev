قم بتثبيت (أو إعادة تثبيت) صور عامل إرساء Linux Manywheel builder التي تستخدمها مسارات عمل البناء الثنائي الليلية/الإصدار في pytorch/pytorch إلى بنية .ci/docker ثابتة. يأخذ نسخة الإصدار (على سبيل المثال 2.13) كمدخل. يقوم بتحديث DOCKER_IMAGE_PIN في .github/scripts/generate_binary_build_matrix.py ويعيد إنشاء سير العمل. يتم تشغيله من خلال الإشارات إلى "صورة عامل الإرساء" أو "تحديث دبوس عامل الإرساء" أو "دبوس صورة عامل الإرساء" أو "صور منشئ الدبوس" أو "رفع دبوس صورة العجلة المتعددة" لفرع الإصدار.
