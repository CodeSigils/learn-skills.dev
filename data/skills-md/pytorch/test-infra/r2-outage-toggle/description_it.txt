Disabilita o riabilita l'utilizzo di Cloudflare R2 (download-r2.pytorch.org) in Manage_v2.py durante le interruzioni di R2. Puoi attivare/disattivare R2 per build notturne, build prod/stabili o entrambi. I pacchetti interessati sono PT_FOUNDATION_PACKAGES (torch, torchvision, torchaudio, fbgemm_gpu, fbgemm_gpu_genai, triton, pytorch_triton, pytorch_triton_rocm, pytorch_triton_xpu).
