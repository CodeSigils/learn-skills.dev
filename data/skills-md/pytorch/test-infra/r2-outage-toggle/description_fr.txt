Désactivez ou réactivez l'utilisation de Cloudflare R2 (download-r2.pytorch.org) dans manage_v2.py pendant les pannes de R2. Peut activer/désactiver R2 pour les builds nocturnes, les builds prod/stables ou les deux. Les packages concernés sont PT_FOUNDATION_PACKAGES (torch, torchvision, torchaudio, fbgemm_gpu, fbgemm_gpu_genai, triton, pytorch_triton, pytorch_triton_rocm, pytorch_triton_xpu).
