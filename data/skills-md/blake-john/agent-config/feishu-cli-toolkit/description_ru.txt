Интегрированный набор инструментов Feishu: электронные таблицы, календарные расписания, управление задачами, управление групповым чатом, операции с доской, диаграммы PlantUML, управление файлами, загрузка/выгрузка активов, комментарии к документам, база знаний, поиск, адресная книга пользователя, загрузка вложений документов. Используется, когда пользователь запрашивает работу с электронными таблицами Feishu, просмотр календарей, создание задач, управление групповыми чатами, работу с виртуальными досками, создание PlantUML, управление файлами, загрузку ресурсов, просмотр комментариев, просмотр базы знаний, поиск сообщений, поиск документов, запрос информации о пользователе, запрос отделов или загрузку вложений документов. Охватывает все функции feishu-cli, за исключением импорта/экспорта чтения/записи документов и управления разрешениями.
