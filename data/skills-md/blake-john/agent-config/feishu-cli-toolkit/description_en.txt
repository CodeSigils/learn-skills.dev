Feishu Integrated Toolbox: spreadsheets, calendar schedules, task management, group chat management, whiteboard operations, PlantUML diagrams, file management, asset upload/download, document comments, knowledge base, search, user address book, document attachment download. Used when a user requests to operate Feishu spreadsheets, view calendars, create tasks, manage group chats, operate whiteboards, generate PlantUML, manage files, upload assets, view comments, view the knowledge base, search messages, search documents, query user information, query departments, or download document attachments. Covers all functions of feishu-cli except document read/write import/export and permission management.
