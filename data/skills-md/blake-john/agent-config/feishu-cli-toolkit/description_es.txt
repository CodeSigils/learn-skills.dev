Feishu Integrated Toolbox: hojas de cálculo, cronogramas de calendario, administración de tareas, administración de chat grupal, operaciones de pizarra, diagramas PlantUML, administración de archivos, carga/descarga de medios, comentarios de documentos, base de conocimientos, búsqueda, libreta de direcciones de usuarios, descarga de documentos adjuntos. Se utiliza cuando el usuario solicita operar hojas de cálculo Feishu, ver calendarios, crear tareas, administrar chats grupales, operar pizarras, generar PlantUML, administrar archivos, cargar medios, ver comentarios, ver la base de conocimientos, buscar mensajes, buscar documentos, consultar información del usuario, consultar departamentos y descargar documentos adjuntos. Cubre todas las funciones de feishu-cli excepto la importación/exportación de lectura/escritura de documentos y la gestión de permisos.
