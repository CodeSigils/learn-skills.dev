Exportieren Sie Feishu-Dokumente oder Wissensdatenbankdokumente als Markdown-Dateien oder exportieren Sie sie als PDF/Word und andere Formate (asynchrone Aufgaben). Verwenden Sie dies, wenn der Benutzer „Dokument exportieren“, „Als Markdown exportieren“, „In Markdown konvertieren“, „Als MD speichern“, „PDF exportieren“, „Word exportieren“ oder „Dokument herunterladen“ anfordert. Diese Fähigkeit konzentriert sich auf Exportvorgänge. Um aus einer lokalen DOCX-Datei zu importieren, verwenden Sie bitte feishu-cli-import.
