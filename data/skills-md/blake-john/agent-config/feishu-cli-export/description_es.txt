Exporte documentos Feishu o documentos de la base de conocimientos como archivos Markdown, o expórtelos como PDF/Word y otros formatos (tareas asincrónicas). Utilícelo cuando el usuario solicite "exportar documento", "exportar como Markdown", "convertir a Markdown", "guardar como md", "exportar PDF", "exportar Word" o "descargar documento". Esta habilidad se centra en las operaciones de exportación. Para importar desde archivos DOCX locales, utilice feishu-cli-import.
