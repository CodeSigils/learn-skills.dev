Feishu ドキュメントまたはナレッジ ベース ドキュメントを Markdown ファイルとしてエクスポートするか、PDF/Word およびその他の形式としてエクスポートします (非同期タスク)。ユーザーが「文書をエクスポート」、「Markdown としてエクスポート」、「Markdown に変換」、「md として保存」、「PDF をエクスポート」、「Word をエクスポート」、または「文書をダウンロード」を要求する場合に使用します。このスキルはエクスポート操作に焦点を当てています。ローカルの DOCX ファイルからインポートするには、feishu-cli-import を使用してください。
