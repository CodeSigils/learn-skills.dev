Exportez des documents Feishu ou des documents de la base de connaissances vers des fichiers Markdown, ou exportez-les au format PDF/Word et d'autres formats (tâches asynchrones). Utilisez-le lorsque l'utilisateur demande « exporter le document », « exporter vers Markdown », « convertir en Markdown », « enregistrer sous md », « exporter PDF », « exporter Word » ou « télécharger un document ». Cette compétence se concentre sur les opérations d’exportation. Pour importer à partir de fichiers DOCX locaux, veuillez utiliser feishu-cli-import.
