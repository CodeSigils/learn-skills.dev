Exportez des documents Feishu ou des documents de la base de connaissances sous forme de fichiers Markdown, ou exportez-les au format PDF/Word et autres formats (tâches asynchrones). Utilisez cette option lorsque l'utilisateur demande « exporter le document », « exporter au format Markdown », « convertir en Markdown », « enregistrer sous md », « exporter au format PDF », « exporter Word » ou « télécharger un document ». Cette compétence se concentre sur les opérations d’exportation. Pour importer à partir de fichiers DOCX locaux, veuillez utiliser feishu-cli-import.
