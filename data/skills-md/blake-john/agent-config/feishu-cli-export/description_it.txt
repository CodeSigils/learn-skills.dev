Esporta documenti Feishu o documenti della knowledge base come file Markdown oppure esportali come PDF/Word e altri formati (attività asincrone). Utilizzalo quando l'utente richiede "esporta documento", "esporta come Markdown", "converti in Markdown", "salva come md", "esporta PDF", "esporta Word" o "scarica documento". Questa competenza si concentra sulle operazioni di esportazione. Per importare da file DOCX locali, utilizzare feishu-cli-import.
