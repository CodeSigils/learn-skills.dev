Fornisce una guida completa per la scrittura, il debug e la manutenzione dei test di Playwright in TypeScript. Utilizzare durante la scrittura di test di Playwright, la correzione di test instabili, il debug di errori, l'implementazione del modello di oggetti di pagina, la configurazione di CI/CD, l'ottimizzazione delle prestazioni, le API di simulazione, la gestione dell'autenticazione o OAuth, il test di accessibilità (axe-core), caricamenti/download di file, simulazione di data/ora, WebSocket, geolocalizzazione, autorizzazioni, flussi multi-tab/popup, layout mobili/responsive, gesti tattili, GraphQL, gestione degli errori, modalità offline, collaborazione multiutente, servizi di terze parti (pagamenti, verifica e-mail), monitoraggio degli errori della console, configurazione/smontaggio globale, annotazioni di test (skip, fixme, slow), dipendenze del progetto, test di sicurezza (XSS, CSRF, autenticazione), budget delle prestazioni (Web Vitals, Lighthouse), iframe, test dei componenti, canvas/WebGL, service operator/PWA, copertura dei test, i18n/localizzazione, app Electron o test delle estensioni del browser. Copre test E2E, componenti, API, visivi, accessibilità, sicurezza, Electron ed estensioni.
