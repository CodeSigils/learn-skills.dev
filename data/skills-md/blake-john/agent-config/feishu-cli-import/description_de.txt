Importieren Sie aus einer Markdown-Datei, um Feishu-Dokumente zu erstellen. Unterstützt verschachtelte Listen, automatische Konvertierung von Mermaid/PlantUML-Diagrammen in Whiteboards, automatische Aufteilung großer Tabellen, Formeln und Callout-Hervorhebungsblöcke. Wird verwendet, wenn Benutzer „Markdown importieren“, „Dokument aus MD erstellen“, „Dokument aus MD-Datei erstellen“, „Markdown in Feishu konvertieren“, „Markdown hochladen“, „Markdown in Feishu“, „MD-Import“ oder „Stapelimport“ anfordern.
