Importez à partir d'un fichier Markdown pour créer un document Feishu. Prend en charge les listes imbriquées, la conversion automatique des diagrammes Mermaid/PlantUML en tableaux, le fractionnement automatique des grands tableaux, des formules et des blocs de surbrillance des légendes. Utilisé lorsque l'utilisateur demande « Importer Markdown », « Créer un document à partir de md », « Créer un document à partir d'un fichier md », « Convertir Markdown en Feishu », « Télécharger Markdown », « Markdown vers Feishu », « md import » ou « importation par lots ».
