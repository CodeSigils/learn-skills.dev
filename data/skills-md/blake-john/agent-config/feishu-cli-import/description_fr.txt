Importez à partir d'un fichier Markdown pour créer des documents Feishu. Prend en charge les listes imbriquées, la conversion automatique des diagrammes Mermaid/PlantUML en tableaux, le fractionnement automatique des grands tableaux, des formules et des blocs de surbrillance des légendes. Utilisez-le lorsque l'utilisateur demande « importer Markdown », « créer un document à partir de md », « créer un document à partir d'un fichier md », « convertir Markdown en Feishu », « télécharger Markdown », « Markdown vers Feishu », « md import » ou « importation par lots ».
