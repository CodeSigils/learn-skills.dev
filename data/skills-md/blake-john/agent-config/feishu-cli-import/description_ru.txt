Импортируйте из файла Markdown для создания документов Feishu. Поддерживает вложенные списки, автоматическое преобразование диаграмм Mermaid/PlantUML в доски, автоматическое разделение больших таблиц, формул и блоков выделения выносок. Используйте это, когда пользователь запрашивает «импортировать Markdown», «создать документ из md», «создать документ из файла md», «конвертировать Markdown в Feishu», «загрузить Markdown», «Markdown в Feishu», «импорт md» или «пакетный импорт».
