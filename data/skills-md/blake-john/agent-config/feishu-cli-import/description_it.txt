Importa da un file Markdown per creare documenti Feishu. Supporta elenchi nidificati, conversione automatica di diagrammi Sirena/PlantUML in lavagne, suddivisione automatica di tabelle di grandi dimensioni, formule e blocchi di evidenziazione callout. Utilizzato quando gli utenti richiedono "Importa Markdown", "Crea documento da md", "Crea documento da file md", "Converti Markdown in Feishu", "Carica Markdown", "Markdown in Feishu", "Importazione md" o "Importazione batch".
