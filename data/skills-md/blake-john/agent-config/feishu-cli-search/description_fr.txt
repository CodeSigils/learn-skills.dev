Recherchez des documents, des messages et des applications cloud Feishu. Utilisez cette option lorsqu'un utilisateur demande « rechercher un document », « rechercher un message », « rechercher une application », « trouver un document », « le trouver », « rechercher des documents », « rechercher des documents Feishu » ou « existe-t-il un document sur xxx ». Cela s'applique également lorsqu'un utilisateur souhaite rechercher des documents Feishu ou un wiki sur un sujet spécifique, récupérer des enregistrements de messages par mot-clé ou localiser des applications internes. L'API de recherche doit utiliser un jeton d'accès utilisateur et cette compétence inclut un processus complet de pré-vérification d'authentification.
