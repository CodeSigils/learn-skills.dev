Ищите облачные документы, сообщения и приложения Feishu. Используется, когда пользователь запрашивает «поиск документов», «поиск сообщений», «поиск приложений», «найти документ», «найти что-то», «поиск документов», «поиск документов Feishu», «есть ли документ о xxx» и т. д. Также применяется, когда пользователь хочет найти документы Feishu или Wiki по определенной теме, получить записи сообщений по ключевому слову или найти внутренние приложения. API поиска должен использовать токен доступа пользователя, и этот навык включает в себя полный процесс проверки перед аутентификацией.
