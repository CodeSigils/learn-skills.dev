Feishu クラウドのドキュメント、メッセージ、アプリケーションを検索します。ユーザーが「ドキュメントの検索」、「メッセージの検索」、「アプリケーションの検索」、「ドキュメントの検索」、「何かを見つける」、「ドキュメントの検索」、「フェイシュのドキュメントを調べる」、「xxx に関するドキュメントはありますか」などを要求するときに使用されます。また、ユーザーが特定のトピックに関するフェイシュのドキュメントや Wiki を検索したり、キーワードでメッセージ レコードを取得したり、内部アプリケーションを検索したりする場合にも適用されます。検索 API はユーザー アクセス トークンを使用する必要があり、このスキルには完全な事前認証チェック プロセスが含まれています。
