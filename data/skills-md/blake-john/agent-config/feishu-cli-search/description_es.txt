Busque documentos, mensajes y aplicaciones en la nube de Feishu. Se utiliza cuando el usuario solicita "buscar documentos", "buscar mensajes", "buscar aplicaciones", "buscar documento", "encontrar algo", "buscar documentos", "buscar documentos de Feishu", "¿hay algún documento sobre xxx", etc. También se aplica cuando el usuario desea ubicar documentos de Feishu o un Wiki sobre un tema específico, recuperar registros de mensajes por palabra clave o buscar aplicaciones internas. La API de búsqueda debe utilizar un token de acceso de usuario y esta habilidad incluye el proceso completo de verificación previa a la autenticación.
