Busque documentos, mensajes y aplicaciones en la nube de Feishu. Utilice esto cuando el usuario solicite "buscar documentos", "buscar mensajes", "buscar aplicaciones", "buscar documento", "búsquelo", "buscar documentos", "buscar documentos Feishu" o "hay algún documento sobre xxx". También se aplica cuando el usuario desea buscar documentos Feishu o Wiki sobre un tema determinado, recuperar registros de mensajes por palabra clave o localizar aplicaciones internas. La API de búsqueda debe utilizar un token de acceso de usuario y esta habilidad incluye un proceso completo de verificación previa a la autenticación.
