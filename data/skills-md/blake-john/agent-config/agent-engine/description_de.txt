Lang laufende Agent-Engine für autonome Codierung. Wird verwendet, um die automatisierte Projektentwicklung zu leiten und eine kontinuierliche Entwicklung über mehrere Sitzungen und Kontextfenster hinweg zu erreichen. Implementiert eine zweistufige Agentenarchitektur: Initializer Agent (Umgebungsinitialisierung) und Coding Agent (inkrementelle Entwicklung). Wenn Benutzer komplexe Projekte erstellen müssen, für deren Abschluss mehrere Sitzungen erforderlich sind, und wenn Benutzer die Notwendigkeit autonomer Codierung, lang laufender Agenten, Entwicklung in mehreren Sitzungen oder inkrementeller Entwicklung erwähnen, muss diese Fähigkeit genutzt werden. Diese Fähigkeit bietet einen vollständigen Arbeitsablauf, einschließlich Umgebungsinitialisierung, Funktionslistenverwaltung, inkrementeller Fortschrittsverfolgung, Git-Commit-Standards und End-to-End-Tests.
