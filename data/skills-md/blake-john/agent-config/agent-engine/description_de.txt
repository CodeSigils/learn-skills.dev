Lang laufende Agent-Engine für autonome Codierung. Wird zur Steuerung der automatisierten Entwicklung von Projekten verwendet und ermöglicht eine kontinuierliche Entwicklung über mehrere Sitzungen und Kontextfenster hinweg. Implementiert eine zweistufige Agentenarchitektur: Initializer Agent (Umgebungseinrichtung) und Coding Agent (inkrementelle Entwicklung). Wenn der Benutzer komplexe Projekte erstellen muss, für deren Abschluss mehrere Sitzungen erforderlich sind, und den Bedarf an autonomer Codierung, Agenten mit langer Laufzeit, Entwicklung in mehreren Sitzungen oder inkrementeller Entwicklung erwähnt, muss diese Fähigkeit genutzt werden. Diese Fähigkeit bietet einen vollständigen Arbeitsablauf, einschließlich Umgebungsinitialisierung, Funktionslistenverwaltung, inkrementeller Fortschrittsverfolgung, Git-Commit-Konventionen und End-to-End-Tests.
