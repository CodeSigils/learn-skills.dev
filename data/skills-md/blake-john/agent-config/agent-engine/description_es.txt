Motor de agente de codificación autónomo de larga duración. Se utiliza para guiar el desarrollo automatizado de proyectos, lo que permite un desarrollo continuo en múltiples sesiones y ventanas contextuales. Implementa una arquitectura de Agente de dos etapas: Agente Inicializador (configuración del entorno) y Agente Codificador (desarrollo incremental). Cuando el usuario necesita crear proyectos complejos que requieren varias sesiones para completarse y menciona la necesidad de codificación autónoma, agentes de larga duración, desarrollo de múltiples sesiones o desarrollo incremental, se debe utilizar esta habilidad. Esta habilidad proporciona un flujo de trabajo completo, que incluye la inicialización del entorno, la gestión de la lista de funciones, el seguimiento del progreso incremental, las convenciones de confirmación de Git y las pruebas de un extremo a otro.
