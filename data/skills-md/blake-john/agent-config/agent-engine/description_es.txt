Motor de agente de codificación autónomo de larga duración. Se utiliza para guiar el desarrollo automatizado de proyectos, logrando un desarrollo continuo en múltiples contextos de sesión. Implementa una arquitectura de Agente de dos etapas: Agente Inicializador (inicialización del entorno) y Agente Codificador (desarrollo incremental). Cuando un usuario necesita crear un proyecto complejo que requiere múltiples sesiones y menciona la necesidad de codificación autónoma, agentes de larga duración, desarrollo de múltiples sesiones o desarrollo incremental, se debe utilizar esta habilidad. Esta habilidad proporciona un flujo de trabajo completo, que incluye la inicialización del entorno, la gestión de la lista de funciones, el seguimiento del progreso incremental, las convenciones de confirmación de Git y las pruebas de un extremo a otro.
