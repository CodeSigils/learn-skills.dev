محرك وكيل الترميز المستقل طويل الأمد. يستخدم لتوجيه التطوير الآلي للمشاريع، مما يتيح التطوير المستمر عبر جلسات متعددة ونوافذ السياق. ينفذ بنية وكيل من مرحلتين: وكيل التهيئة (إعداد البيئة) وعامل الترميز (التطوير المتزايد). عندما يحتاج المستخدم إلى إنشاء مشاريع معقدة تتطلب جلسات متعددة لإكمالها، ويذكر الحاجة إلى الترميز المستقل، أو الوكلاء طويلي التشغيل، أو التطوير متعدد الجلسات، أو التطوير المتزايد، فيجب استخدام هذه المهارة. توفر هذه المهارة سير عمل كاملاً، بما في ذلك تهيئة البيئة وإدارة قائمة الميزات وتتبع التقدم المتزايد واتفاقيات التزام Git والاختبار الشامل.
