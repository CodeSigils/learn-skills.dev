محرك وكيل الترميز المستقل طويل الأمد، يُستخدم لتوجيه التطوير الآلي للمشروع وتمكين التطوير المستمر عبر جلسات متعددة ونوافذ سياقية. وهي تنفذ بنية وكيل مكونة من مرحلتين: وكيل التهيئة (تهيئة البيئة) وعامل الترميز (التطوير المتزايد). عندما يحتاج المستخدم إلى إنشاء مشروع معقد يتطلب إكماله على جلسات متعددة، أو يذكر الحاجة إلى ترميز مستقل، أو وكلاء طويلي التشغيل، أو تطوير متعدد الجلسات، أو تطوير تدريجي، فيجب استخدام هذه المهارة. توفر هذه المهارة سير عمل كاملاً، بما في ذلك تهيئة البيئة وإدارة قائمة الميزات وتتبع التقدم المتزايد واتفاقيات التزام Git والاختبار الشامل.
