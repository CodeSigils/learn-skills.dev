長時間実行される自律コーディング エージェント エンジン。自動化されたプロジェクト開発をガイドするために使用され、マルチセッション コンテキスト ウィンドウにわたる継続的な開発を実現します。 Initializer Agent (環境の初期化) とコーディング エージェント (増分開発) の 2 段階のエージェント アーキテクチャを実装します。ユーザーが複数のセッションを完了する必要がある複雑なプロジェクトを構築する必要がある場合、およびユーザーが自律コーディング、長時間実行エージェント、マルチセッション開発、または増分開発の必要性について言及した場合、このスキルを使用する必要があります。このスキルは、環境の初期化、機能リストの管理、増分進行状況の追跡、Git コミット規則、エンドツーエンドのテストなどの完全なワークフローを提供します。
