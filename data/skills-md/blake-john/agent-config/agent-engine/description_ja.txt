長時間実行される自律コーディング エージェント エンジン。プロジェクトの自動開発をガイドするために使用され、複数のセッションとコンテキスト ウィンドウにわたる継続的な開発が可能になります。 Initializer Agent (環境セットアップ) とコーディング エージェント (増分開発) の 2 段階のエージェント アーキテクチャを実装します。ユーザーが完了するまでに複数のセッションを必要とする複雑なプロジェクトを構築する必要があり、自律コーディング、長時間実行されるエージェント、マルチセッション開発、または増分開発の必要性について言及する場合、このスキルを使用する必要があります。このスキルは、環境の初期化、機能リストの管理、増分進行状況の追跡、Git コミット規則、エンドツーエンドのテストなどの完全なワークフローを提供します。
