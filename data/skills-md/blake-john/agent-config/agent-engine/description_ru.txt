Долго работающий автономный механизм агента кодирования. Используется для управления автоматизированной разработкой проектов, обеспечивая непрерывную разработку в нескольких сеансах и контекстных окнах. Реализует двухэтапную архитектуру агента: агент инициализатора (настройка среды) и агент кодирования (добавочная разработка). Когда пользователю необходимо создать сложные проекты, для выполнения которых требуется несколько сеансов, и он упоминает о необходимости автономного кодирования, долгоиграющих агентов, многосессионной разработки или поэтапной разработки, необходимо использовать этот навык. Этот навык обеспечивает полный рабочий процесс, включая инициализацию среды, управление списком функций, постепенное отслеживание прогресса, соглашения о фиксации Git и сквозное тестирование.
