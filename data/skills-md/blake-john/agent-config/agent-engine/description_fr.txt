Moteur d’agent de codage autonome de longue durée. Utilisé pour guider le développement automatisé de projets, permettant un développement continu sur plusieurs sessions et fenêtres contextuelles. Implémente une architecture d'agent en deux étapes : Initializer Agent (initialisation de l'environnement) et Coding Agent (développement incrémentiel). Lorsqu'un utilisateur a besoin de créer un projet complexe nécessitant plusieurs sessions et lorsqu'il mentionne le besoin de codage autonome, d'agents à exécution longue, de développement multi-sessions ou de développement incrémentiel, cette compétence doit être utilisée. Cette compétence fournit un flux de travail complet, comprenant l'initialisation de l'environnement, la gestion de la liste des fonctionnalités, le suivi des progrès incrémentiels, les conventions de validation Git et les tests de bout en bout.
