장기 실행 자율 코딩 에이전트 엔진. 프로젝트의 자동화된 개발을 안내하는 데 사용되며 여러 세션과 컨텍스트 창에서 지속적인 개발을 가능하게 합니다. 2단계 에이전트 아키텍처인 초기화 에이전트(환경 초기화)와 코딩 에이전트(증분 개발)를 구현합니다. 사용자가 여러 세션이 필요한 복잡한 프로젝트를 빌드해야 하는 경우, 사용자가 자율 코딩, 장기 실행 에이전트, 다중 세션 개발 또는 증분 개발의 필요성을 언급하는 경우 이 기술을 사용해야 합니다. 이 기술은 환경 초기화, 기능 목록 관리, 증분 진행 상황 추적, Git 커밋 규칙 및 엔드투엔드 테스트를 포함한 완전한 워크플로를 제공합니다.
