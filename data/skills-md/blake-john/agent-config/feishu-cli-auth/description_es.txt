Autenticación Feishu OAuth y gestión de tokens de acceso de usuario. Inicio de sesión no interactivo en dos pasos (Agente AI dedicado), verificación del estado del token, configuración del alcance, mecanismo de actualización automática, dependencia del token para la funcionalidad de búsqueda. Se utiliza cuando un usuario solicita "Iniciar sesión en Feishu", "Obtener token", "Autorización OAuth", "Inicio de sesión de autenticación", "Autenticación", "Qué permisos necesita la búsqueda", "El token expiró" o "Actualizar token". También debe usarse cuando se encuentren errores de permisos (por ejemplo, 99991679 no autorizado), caducidad de tokens, discrepancias de estado y problemas similares. Aplicable a escenarios como comandos de búsqueda que informan errores de permisos, resolución de problemas relacionados con tokens y necesidad de determinar el estado de autorización actual. Cuando otras habilidades de Feishu (por ejemplo, kit de herramientas/msg/read) encuentran problemas con el token de acceso del usuario, también se debe hacer referencia a esta habilidad.
