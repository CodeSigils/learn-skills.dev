Autenticación Feishu OAuth y gestión de tokens de acceso de usuario. Inicio de sesión no interactivo de dos pasos (exclusivo del Agente AI), verificación del estado del token, configuración del alcance, mecanismo de actualización automática y dependencia del token para la funcionalidad de búsqueda. Úselo cuando el usuario solicite "iniciar sesión en Feishu", "obtener token", "autorización OAuth", "iniciar sesión con autenticación", "autenticación", "qué permisos se necesitan para la búsqueda", "el token ha caducado" o "actualizar token". También debe usarse cuando se encuentren errores de permisos (por ejemplo, 99991679 no autorizado), caducidad de tokens, discrepancias de estado y problemas similares. Aplicable a escenarios como comandos de búsqueda que informan errores de permisos, resolución de problemas relacionados con tokens y necesidad de determinar el estado de autorización actual. Cuando otras habilidades de Feishu (por ejemplo, kit de herramientas/msg/read) encuentran problemas con el token de acceso del usuario, se debe consultar esta habilidad.
