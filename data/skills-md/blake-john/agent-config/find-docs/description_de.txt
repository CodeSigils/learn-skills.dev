Ruft maßgebliche, aktuelle technische Dokumentation, API-Referenzen, Konfigurationsdetails und Codebeispiele für jede Entwicklertechnologie ab.
Nutzen Sie diese Fähigkeit immer dann, wenn Sie technische Fragen beantworten oder Code schreiben, der mit externen Technologien interagiert. Dazu gehören Bibliotheken, Frameworks, Programmiersprachen, SDKs, APIs, CLI-Tools, Cloud-Dienste, Infrastruktur-Tools und Entwicklerplattformen.
Gängige Szenarien: - Nachschlagen von API-Endpunkten, Klassen, Funktionen oder Methodenparametern - Überprüfen von Konfigurationsoptionen oder CLI-Befehlen - Beantworten technischer Fragen zum Thema „Wie mache ich das?“ – Generieren von Code, der eine bestimmte Bibliothek oder einen bestimmten Dienst verwendet – Debuggen von Problemen im Zusammenhang mit Frameworks, SDKs oder APIs – Abrufen von Setup-Anweisungen, Beispielen oder Migrationsleitfäden – Überprüfen von versionspezifischem Verhalten oder Breaking Changes
Bevorzugen Sie diese Fähigkeit, wenn es auf die Genauigkeit der Dokumentation ankommt oder wenn das Modellwissen möglicherweise veraltet ist.
