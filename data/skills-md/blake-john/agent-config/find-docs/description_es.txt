Recupera documentación técnica autorizada y actualizada, referencias de API, detalles de configuración y ejemplos de código para cualquier tecnología de desarrollador.
Utilice esta habilidad siempre que responda preguntas técnicas o escriba código que interactúe con tecnologías externas. Esto incluye bibliotecas, marcos, lenguajes de programación, SDK, API, herramientas CLI, servicios en la nube, herramientas de infraestructura y plataformas de desarrollo.
Escenarios comunes: - buscar puntos finales de API, clases, funciones o parámetros de métodos - verificar opciones de configuración o comandos CLI - responder preguntas técnicas de tipo "cómo lo hago" - generar código que utiliza una biblioteca o servicio específico - depurar problemas relacionados con marcos, SDK o API - recuperar instrucciones de configuración, ejemplos o guías de migración - verificar el comportamiento específico de la versión o cambios importantes
Prefiera esta habilidad siempre que la precisión de la documentación sea importante o cuando el conocimiento del modelo pueda estar desactualizado.
