Recupera documentazione tecnica autorevole e aggiornata, riferimenti API, dettagli di configurazione ed esempi di codice per qualsiasi tecnologia di sviluppo.
Utilizza questa competenza ogni volta che rispondi a domande tecniche o scrivi codice che interagisce con tecnologie esterne. Ciò include librerie, framework, linguaggi di programmazione, SDK, API, strumenti CLI, servizi cloud, strumenti infrastrutturali e piattaforme per sviluppatori.
Scenari comuni: - ricerca di endpoint API, classi, funzioni o parametri di metodo - verifica delle opzioni di configurazione o dei comandi CLI - risposta a domande tecniche "come faccio" - generazione di codice che utilizza una libreria o un servizio specifico - debug di problemi relativi a framework, SDK o API - recupero di istruzioni di configurazione, esempi o guide alla migrazione - verifica del comportamento specifico della versione o modifiche importanti
Preferire questa abilità ogni volta che l'accuratezza della documentazione è importante o quando la conoscenza del modello potrebbe essere obsoleta.
