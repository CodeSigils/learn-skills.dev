يسترد الوثائق الفنية الموثوقة والمحدثة ومراجع واجهة برمجة التطبيقات (API) وتفاصيل التكوين وأمثلة التعليمات البرمجية لأي تقنية مطور.
استخدم هذه المهارة عند الإجابة على الأسئلة الفنية أو كتابة التعليمات البرمجية التي تتفاعل مع التقنيات الخارجية. يتضمن ذلك المكتبات وأطر العمل ولغات البرمجة ومجموعات SDK وواجهات برمجة التطبيقات وأدوات CLI والخدمات السحابية وأدوات البنية التحتية ومنصات المطورين.
السيناريوهات الشائعة: - البحث عن نقاط نهاية واجهة برمجة التطبيقات أو الفئات أو الوظائف أو معلمات الأسلوب - التحقق من خيارات التكوين أو أوامر واجهة سطر الأوامر - الإجابة على الأسئلة الفنية "كيف يمكنني" - إنشاء تعليمات برمجية تستخدم مكتبة أو خدمة معينة - تصحيح الأخطاء المتعلقة بأطر العمل أو حزم SDK أو واجهات برمجة التطبيقات - استرداد تعليمات الإعداد أو الأمثلة أو أدلة الترحيل - التحقق من السلوك الخاص بالإصدار أو كسر التغييرات
تفضل هذه المهارة عندما تكون دقة التوثيق مهمة أو عندما تكون المعرفة النموذجية قديمة.
