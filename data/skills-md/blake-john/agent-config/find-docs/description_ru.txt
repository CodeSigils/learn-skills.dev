Получает авторитетную, актуальную техническую документацию, ссылки на API, сведения о конфигурации и примеры кода для любой технологии разработчика.
Используйте этот навык всякий раз, когда отвечаете на технические вопросы или пишете код, взаимодействующий с внешними технологиями. Сюда входят библиотеки, платформы, языки программирования, SDK, API, инструменты CLI, облачные сервисы, инструменты инфраструктуры и платформы разработчиков.
Общие сценарии: - поиск конечных точек API, классов, функций или параметров метода - проверка параметров конфигурации или команд CLI - ответы на технические вопросы "как это сделать" - создание кода, использующего определенную библиотеку или службу - проблемы отладки, связанные с платформами, SDK или API - получение инструкций по установке, примеров или руководств по миграции - проверка поведения конкретной версии или критических изменений
Отдавайте предпочтение этому навыку всякий раз, когда важна точность документации или когда знания моделей могут устареть.
