Convert methodology books into a meta‑Skill that is a reusable Skill. When a user uploads a book in PDF or TXT format (especially methodology, reference, or guide books) and wants to extract its core methods as a Skill, use this Skill. Typical trigger scenarios: “turn this book into a skill”, “extract the methodology of this book”, “convert this PDF/TXT into a skill”, “analyze the core methods of this book”, “help me summarize the methods/framework of this book”, “distill the key points of this book”, user asks how to process after uploading a PDF/TXT book, and even if “skill” is not explicitly mentioned, as long as the user wants to extract reusable methodology/framework/operational guide from the book, this Skill should be used. This Skill will automatically parse the PDF/TXT, extract the title, author, key chapters, and perform an in‑depth analysis of the book’s content through 16 core questions, finally generating a structured Skill file.
