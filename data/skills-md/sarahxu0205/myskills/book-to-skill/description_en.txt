Convert methodology books into a reusable meta‑Skill. When a user uploads a book in PDF or TXT format (especially methodology, reference, or guide books) and wants to extract its core methods as a Skill, this Skill should be used. Typical trigger scenarios include: “turn this book into a skill,” “extract the methodology of this book,” “convert this PDF/TXT into a skill,” “analyze the book’s core methods,” “help me summarize the book’s methods/framework,” “distill the book’s key points,” as well as users asking how to handle a PDF/TXT after uploading it. Even if the word “skill” isn’t explicitly mentioned, as long as the user wants to extract reusable methodology, frameworks, or operational guides from the book, this Skill applies. The Skill automatically parses the PDF/TXT, extracts the title, author, and key chapters, and conducts an in‑depth analysis of the content through 16 core questions, ultimately generating a structured Skill file.
