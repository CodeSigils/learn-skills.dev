DEVE UTILIZZARE durante l'esecuzione di query, trasformazioni o analisi di dati locali e incorporati con DuckDB. Copre l'analisi SQL su file CSV, Parquet e JSON, flussi di lavoro di importazione ed esportazione di dati, esplorazione ad hoc e utilizzo di database analitici incorporati in script o pipeline. NON utilizzare per la progettazione di database OLTP transazionale, l'amministrazione di magazzini esterni o lavori SQL generici che non coinvolgono specificamente DuckDB.
