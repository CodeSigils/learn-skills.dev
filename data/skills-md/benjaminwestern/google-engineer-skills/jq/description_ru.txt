НЕОБХОДИМО ИСПОЛЬЗОВАТЬ при анализе, фильтрации, запросе, преобразовании или проверке JSON с помощью jq. Охватывает извлечение полей из ответов API, изменение формы документов JSON, фильтрацию массивов и объектов, построение конвейеров оболочки на основе JSON и составление выражений jq. НЕ используйте для обработки YAML, запросов SQL или общих манипуляций с текстом, если jq явно не является частью задачи.
