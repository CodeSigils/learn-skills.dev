DEBE UTILIZARSE al analizar, filtrar, consultar, transformar o validar JSON con jq. Cubre la extracción de campos de respuestas API, la remodelación de documentos JSON, el filtrado de matrices y objetos, la creación de canalizaciones de shell alrededor de JSON y la composición de expresiones jq. NO lo use para procesamiento YAML, consultas SQL o manipulación de texto general a menos que jq sea explícitamente parte de la tarea.
