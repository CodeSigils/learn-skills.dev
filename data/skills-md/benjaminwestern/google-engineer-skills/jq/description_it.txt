DEVE UTILIZZARE durante l'analisi, il filtraggio, l'esecuzione di query, la trasformazione o la convalida di JSON con jq. Copre l'estrazione di campi dalle risposte API, il rimodellamento di documenti JSON, il filtraggio di array e oggetti, la creazione di pipeline di shell attorno a JSON e la composizione di espressioni jq. NON utilizzare per l'elaborazione YAML, le query SQL o la manipolazione generale del testo a meno che jq non sia esplicitamente parte dell'attività.
