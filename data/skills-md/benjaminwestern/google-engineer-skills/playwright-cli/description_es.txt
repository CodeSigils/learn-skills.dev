DEBE UTILIZARSE al automatizar un navegador con Playwright para navegación, llenado de formularios, capturas de pantalla, pruebas de un extremo a otro o extracción de datos estructurados de páginas web. Cubre la interacción programada con sitios web, la verificación de la interfaz de usuario y los flujos de trabajo repetibles del navegador. NO lo use para recuperación HTTP estática, pruebas de solo API o automatización sin navegador, a menos que se requiera una sesión de navegador real.
