DEVE UTILIZZARE quando si automatizza un browser con Playwright per la navigazione, la compilazione di moduli, gli screenshot, i test end-to-end o l'estrazione strutturata di dati dalle pagine Web. Copre l'interazione basata su script con siti Web, verifica dell'interfaccia utente e flussi di lavoro del browser ripetibili. NON utilizzare per il recupero HTTP statico, test solo API o automazione non del browser a meno che non sia richiesta una sessione del browser reale.
