DOIT UTILISER lors de l'automatisation d'un navigateur avec Playwright pour la navigation, le remplissage de formulaires, les captures d'écran, les tests de bout en bout ou l'extraction de données structurées à partir de pages Web. Couvre l'interaction scriptée avec les sites Web, la vérification de l'interface utilisateur et les flux de travail de navigateur reproductibles. Ne PAS utiliser pour la récupération HTTP statique, les tests API uniquement ou l'automatisation sans navigateur, sauf si une véritable session de navigateur est requise.
