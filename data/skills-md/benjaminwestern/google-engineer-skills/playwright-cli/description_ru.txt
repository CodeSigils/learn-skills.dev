НЕОБХОДИМО ИСПОЛЬЗОВАТЬ при автоматизации браузера с помощью Playwright для навигации, заполнения форм, создания снимков экрана, сквозного тестирования или извлечения структурированных данных с веб-страниц. Охватывает скриптовое взаимодействие с веб-сайтами, проверку пользовательского интерфейса и повторяемые рабочие процессы браузера. НЕ используйте для статической выборки HTTP, тестирования только через API или автоматизации без использования браузера, если не требуется реальный сеанс браузера.
