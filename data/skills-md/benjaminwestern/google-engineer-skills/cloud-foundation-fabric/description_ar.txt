يجب استخدامه عند إنشاء أو تعديل البنية الأساسية لـ Google Cloud باستخدام وحدات Cloud Foundation Fabric Terraform. يغطي اختيار وحدات CFF، ومدخلات ومخرجات الأسلاك، وتطبيق الإصدارات واتفاقيات المستودع، وتأليف بنيات Google Cloud فوق Fabric. لا تستخدمه في أعمال Terraform العامة خارج Cloud Foundation Fabric أو في الإعداد اليدوي لوحدة تحكم Google Cloud ما لم تعتمد المهمة صراحةً على CFF.
