DEBE USARSE al crear o modificar la infraestructura de Google Cloud con los módulos Cloud Foundation Fabric Terraform. Cubre la selección de módulos CFF, el cableado de entradas y salidas, la aplicación de convenciones de repositorio y control de versiones, y la composición de arquitecturas de Google Cloud sobre Fabric. NO lo use para trabajos genéricos de Terraform fuera de Cloud Foundation Fabric ni para la configuración manual de la consola de Google Cloud, a menos que la tarea dependa explícitamente de CFF.
