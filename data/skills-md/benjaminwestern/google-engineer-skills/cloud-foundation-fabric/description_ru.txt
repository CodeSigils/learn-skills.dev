НЕОБХОДИМО ИСПОЛЬЗОВАТЬ при создании или изменении инфраструктуры Google Cloud с помощью модулей Cloud Foundation Fabric Terraform. Охватывает выбор модулей CFF, подключение входов и выходов, применение соглашений о версиях и репозиториях, а также составление архитектур Google Cloud поверх Fabric. НЕ используйте для общей работы Terraform за пределами Cloud Foundation Fabric или для ручной настройки консоли Google Cloud, если только задача явно не зависит от CFF.
