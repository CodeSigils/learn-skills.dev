يدمج React-native-nitro-google-signin (Nitro Universal Google Sign-In) في تطبيقات React Native وExpo. يُستخدم عند إضافة تسجيل الدخول إلى Google، أو تسجيل الدخول بنقرة واحدة، أو GoogleOneTapSignIn، أو مدير بيانات الاعتماد، أو إعداد SHA-1 OAuth، أو google-services.json، أو GoogleService-Info.plist، أو المكون الإضافي Expo config، أو DEVELOPER_ERROR، أو webClientId autoDetect.
