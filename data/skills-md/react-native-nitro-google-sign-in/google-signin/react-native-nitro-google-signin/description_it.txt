Integra react-native-nitro-google-signin (Nitro Universal Google Sign-In) nelle app React Native ed Expo. Da utilizzare quando si aggiunge l'accesso con Google, l'accesso con un tocco, GoogleOneTapSignIn, Credential Manager, configurazione SHA-1 OAuth, google-services.json, GoogleService-Info.plist, plug-in di configurazione Expo, DEVELOPER_ERROR o webClientId autoDetect.
