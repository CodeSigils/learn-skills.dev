Migre les compétences, les agents et les règles entre le format Google Antigravity 2.0 (IDE/CLI) et d'autres formats de fournisseur d'IA agentique (Cursor, Windsurf, Claude Code, GitHub Copilot, Roo Code), et vice-versa. À utiliser lorsqu'on vous demande de migrer/convertir les personnalisations, les règles ou les compétences d'un agent vers ou depuis Antigravity.
