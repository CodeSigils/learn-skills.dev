Устраняет проблемы GitHub по предоставленному URL-адресу проблемы. Создает ветку функции, реализует исправление, обновляет документацию и навыки агента, когда это необходимо, и открывает запрос на включение. Используйте, когда вам дают ссылку на проблему GitHub или просят исправить/решить проблему и создать PR.
