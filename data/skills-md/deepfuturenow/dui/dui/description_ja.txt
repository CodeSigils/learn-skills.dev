デザイン トークンと 2 層継承を備えた Lit ベースのスタイル Web コンポーネント ライブラリである DUI を使用して、フロントエンド UI を構築します。ユーザーが DUI コンポーネントを使用する (または使用する必要がある) プロジェクトでページ、レイアウト、フォーム、ダッシュボード、またはフロントエンド UI を構築したい場合は常にこのスキルを使用します。`@deepfuture/dui-components` または `@dui/components` インポート、`dui-*` 要素タグ、または `--accent`、`--surface-1` などのデザイン トークン変数を探してください。また、ユーザーが「DUI」、「DUI コンポーネント」に言及した場合、またはデザイン トークンを含む Web コンポーネントの追加/使用を要求した場合にもトリガーされます。プロジェクトに DUI がインストールされている場合は、最初から構築するのではなく、常にこのスキルをフロントエンド作業に使用してください。
