Build frontend UIs using DUI, a Lit-based styled web component library with design tokens and two-layer inheritance. Use this skill whenever the user wants to build pages, layouts, forms, dashboards, or any frontend UI in a project that uses (or should use) DUI components — look for `@deepfuture/dui-components` or `@dui/components` imports, `dui-*` element tags, or design token variables like `--accent`, `--surface-1`. Also trigger when the user mentions "DUI", "dui components", or asks to add/use web components with design tokens. If a project has DUI installed, always use this skill for frontend work rather than building from scratch.
