Crea interfacce utente frontend utilizzando DUI, una libreria di componenti Web in stile basata su Lit con token di progettazione ed ereditarietà a due livelli. Utilizza questa competenza ogni volta che l'utente desidera creare pagine, layout, moduli, dashboard o qualsiasi interfaccia utente frontend in un progetto che utilizza (o dovrebbe utilizzare) componenti DUI: cerca le importazioni `@deepfuture/dui-components` o `@dui/components`, i tag degli elementi `dui-*` o progetta variabili token come `--accent`, `--surface-1`. Si attiva anche quando l'utente menziona "DUI", "componenti dui" o chiede di aggiungere/utilizzare componenti Web con token di progettazione. Se in un progetto è installato DUI, utilizza sempre questa competenza per il lavoro sul frontend anziché per la creazione da zero.
