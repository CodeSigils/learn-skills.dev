Cree interfaces de usuario utilizando DUI, una biblioteca de componentes web con estilo basada en Lit con tokens de diseño y herencia de dos capas. Utilice esta habilidad siempre que el usuario quiera crear páginas, diseños, formularios, paneles o cualquier interfaz de usuario en un proyecto que use (o deba usar) componentes DUI; busque importaciones `@deepfuture/dui-components` o `@dui/components`, etiquetas de elementos `dui-*` o variables de token de diseño como `--accent`, `--surface-1`. También se activa cuando el usuario menciona "DUI", "componentes dui" o solicita agregar/usar componentes web con tokens de diseño. Si un proyecto tiene DUI instalado, utilice siempre esta habilidad para el trabajo frontend en lugar de construir desde cero.
