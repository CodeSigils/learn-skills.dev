Деидентифицируйте данные клинических исследований перед анализом с помощью LLM. Автономный интерфейс командной строки Python обнаруживает PHI с помощью регулярных выражений + эвристики с пакетами локалей 10 стран (kr, us, jp, cn, de, uk, fr, ca, au, in). Интерактивный обзор терминала. Никакой LLM не затрагивает необработанные данные — сценарий выполняется локально без каких-либо вызовов сети или искусственного интеллекта.
