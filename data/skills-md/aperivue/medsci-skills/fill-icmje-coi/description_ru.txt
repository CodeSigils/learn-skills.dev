Пакетное создание форм раскрытия информации о конфликте интересов ICMJE для каждого автора (coi_disclosure.docx) для подачи рукописи. Предварительно заполняет все 13 пунктов раскрытия информации как «☒ Нет» + окончательная сертификация ☒ с использованием синтетического исходного шаблона, поставляемого вместе с навыком, затем клонирует исходное число для каждого автора с заменой Даты, имени и названия рукописи. Разработан для обычного случая обсервационных исследований в больницах, когда ни у одного автора нет реальных финансовых конфликтов; распространенные формы для большинства авторов становятся «ответом «без изменений» + знак» и отмечают только тех, кому необходимо внести поправки.
