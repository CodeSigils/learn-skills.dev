إنتاج أو تدقيق دراسة إشعاعية / دراسة سريرية جدولية للتعلم الآلي - التصوير أو السمات السريرية ← أي متعلم كلاسيكي (لوجستي معاقب [LASSO / ridge / Elastic-net]، SVM، k-NN، naive Bayes، LDA/QDA، شجرة القرار، غابة عشوائية، تعزيز التدرج [XGBoost / LightGBM / CatBoost]، MLP الضحلة، المجموعات المكدسة) ← نتيجة سريرية - لذلك يزيل شريط الصرامة الذي يتوقعه المراجعون: التحقق المتبادل المتداخل (الضبط مطلقًا على الطيات المُبلغ عنها)، والتحكم في الأبعاد لنظام أحداث تجاوز الميزات، واختيار الميزة داخل الطية، وتصفية استقرار الميزة (ICC / إعادة الاختبار)، والمعايرة، والتحقق الخارجي/الزمني. البوابة الحتمية لا تعرف المتعلم (فهي تقوم بتدقيق خط الأنابيب، وليس الخوارزمية). يصدر بيان خط الأنابيب والبوابة. سير العمل السريري ML الأكثر شيوعًا والذي يمكن تنفيذه منفردًا - لا توجد وحدة معالجة رسومات (GPU)، ولا يوجد مهندس. يدمج scikit-learn / xgboost / lightgbm / catboost / pyradiomics؛ ولا يعيد تنفيذها.
