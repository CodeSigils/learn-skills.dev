Erstellen oder prüfen Sie eine Radiomics-/tabellarische klinische ML-Studie – Bildgebung oder klinische Merkmale → jeder klassische Lernende (bestrafte Logistik [LASSO / Ridge / Elastic-Net], SVM, k-NN, naive Bayes, LDA/QDA, Entscheidungsbaum, Random Forest, Gradient Boosting [XGBoost / LightGBM / CatBoost], flaches MLP, gestapelte Ensembles) → ein klinisches Ergebnis – damit es die von Prüfern erwartete strenge Messlatte überschreitet: verschachtelt Kreuzvalidierung (Abstimmung nie auf den gemeldeten Falten), Dimensionskontrolle für das Feature-Far-Exceed-Events-Regime, Feature-Auswahl innerhalb der Falte, Feature-Stabilitätsfilterung (ICC/Test-Retest), Kalibrierung und externe/zeitliche Validierung. Das deterministische Gatter ist lernerunabhängig (es prüft die Pipeline, nicht den Algorithmus). Gibt ein Pipeline-Manifest und das Gate aus. Der am häufigsten alleine durchführbare klinische ML-Workflow – keine GPU, kein Ingenieur. Integriert scikit-learn / xgboost / lightgbm / catboost / pyradiomics; es implementiert sie nicht erneut.
