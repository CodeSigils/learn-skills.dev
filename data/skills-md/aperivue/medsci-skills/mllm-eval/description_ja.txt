臨床タスク (放射線レポート生成、視覚的質問応答、臨床テキスト抽出/分類) に関する LLM またはマルチモーダル LLM のモデルに依存しない評価ハーネスを設計または監査します。裁定された参照標準、臨床有効性メトリクス (BLEU/ROUGE を超える RadGraph-F1 / CheXbert-F1)、忠実性と幻覚、公共ベンチマークの事前トレーニング汚染、プロンプト感度および決定論、答え合わせ、読者調査、そしてそれらの軸の計画を決定します。クローズド API またはオープン ウェイトで動作します。出力やスコアを決して捏造したり、n グラムの重複を臨床上の正しさとして報告したりすることはありません。
