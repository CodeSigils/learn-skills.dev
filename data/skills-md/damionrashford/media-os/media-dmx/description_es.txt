Protocolos de iluminación de escenario: DMX512-A (serie ANSI E1.11, RS-485 de 250 kbps, 512 ranuras por universo, configuración bidireccional RDM E1.20), Art-Net 4 (puerto UDP 6454, encabezado ASCII Art-Net + direccionamiento de universo de 15 bits desde licencia artística), sACN/E1.31 (multidifusión UDP) 239.255.X.Y puerto 5568 con sincronización universal + prioridad), Open Lighting Architecture (OLA — olad daemon, ola_streaming_client, ola_recorder, ola_dmxconsole, ola_patch, ola_rdm_get/set, ola_artnet, ola_e131, ola_usbpro para Enttec USB Pro), encuadre en serie Enttec Open DMX + USB Pro. Úselo cuando el usuario solicite controlar las luces del escenario, enviar DMX, controlar un nodo Art-Net, transmitir sACN, descubrir dispositivos RDM, parchear un equipo de iluminación desde código, enviar una señal de espectáculo, grabar/reproducir un espectáculo DMX o conectar OSC/MIDI a la iluminación.
