Протоколы освещения сцены: DMX512-A (последовательный порт ANSI E1.11, RS-485 250 кбит/с, 512 слотов на каждую область, двунаправленная конфигурация RDM E1.20), Art-Net 4 (порт UDP 6454, заголовок ASCII Art-Net + 15-битная адресация вселенной из Artistic Licence), sACN/E1.31 (многоадресная передача UDP) Порт 239.255.XY 5568 с синхронизацией юниверса + приоритет), архитектура Open Lighting (OLA — olad daemon, ola_streaming_client, ola_recorder, ola_dmxconsole, ola_patch, ola_rdm_get/set, ola_artnet, ola_e131, ola_usbpro для Enttec USB Pro), Enttec Open DMX + последовательный порт USB Pro обрамление. Используйте, когда пользователь запрашивает управление освещением сцены, отправку DMX, управление узлом Art-Net, потоковую передачу sACN, обнаружение устройств RDM, исправление осветительной установки из кода, отправку сигнала шоу, запись/воспроизведение шоу DMX или соединение OSC/MIDI с освещением.
