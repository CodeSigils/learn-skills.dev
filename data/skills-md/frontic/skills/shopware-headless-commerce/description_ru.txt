Создавайте автономные витрины с помощью Shopware 6 Store API (6.6+). Используйте при работе с управлением сеансом/контекстом Shopware (sw-context-token), операциями с корзиной (добавление/обновление/удаление позиций, рекламные акции), процессом оформления заказа (создание заказа, обработка платежей с синхронизацией/асинхронными перенаправлениями) и функциями учетной записи клиента (регистрация, вход в систему, адреса, восстановление пароля, история заказов, списки желаний). Охватывает сторону API Store с сохранением состояния и записью, а не получение данных о продукте (для этого используйте Frontic).
