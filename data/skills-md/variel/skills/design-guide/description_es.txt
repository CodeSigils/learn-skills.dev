Guía de diseño de interfaz de usuario. Úselo siempre que diseñe, mejore o revise interfaces visuales como aplicaciones web, aplicaciones móviles, páginas de destino y diapositivas. Active esta habilidad cada vez que reciba solicitudes como "crear un panel", "estructurar la pantalla", "diseñar la interfaz de usuario", "establecer el diseño" o "hacer una maqueta". Para cualquier tarea de interfaz visual (estructuras alámbricas, creación de prototipos, tipografía, color, espaciado, diseño responsivo, ubicación de componentes), consulte esta habilidad incluso si el diseño no se menciona explícitamente.
