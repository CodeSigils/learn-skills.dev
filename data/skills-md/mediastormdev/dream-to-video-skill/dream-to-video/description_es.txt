Cuando el usuario proporciona el texto de un sueño, un extracto de un diario o el contenido de un sueño hablado y quiere generar un vídeo, esto se activa. Las palabras desencadenantes incluyen: "梦到", "梦见", "做了个梦", "梦境素材", "帮我生成视频", "转成视频", "dream to video". También se aplica cuando el usuario pega directamente la descripción de un sueño y espera recibir un archivo de vídeo. Esta habilidad convierte el texto en indicaciones de video, las envía automáticamente a la plataforma Jimeng para su generación y descarga el archivo de video.
