Lecteur Web local pour les passages bibliques avec annotations ELI5 : une page du SDK FastAPI + Claude Agent qui charge un passage de FHL, dépose des notes en langage clair sur les mots eux-mêmes et permet à un agent de la Bible de vérifier ou de développer n'importe lequel d'entre eux. À utiliser lorsque l'utilisateur souhaite LIRE ou ÉTUDIER les Écritures dans un navigateur plutôt que dans le terminal : 開網頁查經、網頁版 bible buddy、經文標注、ELI5 筆記、劃線筆記、annoter un passage, l'interface utilisateur du lecteur de la Bible, démarrer l'application Web de la Bible. EXCLURE : questions et réponses sur la Bible sur le terminal (bible-buddy), dévotions (bible-bread), révision du contenu (bible-fact-check).
