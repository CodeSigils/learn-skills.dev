Локальная веб-программа для чтения отрывков из Библии с аннотациями ELI5 — страница FastAPI + Claude Agent SDK, которая загружает отрывок из FHL, добавляет примечания открытым текстом к самим словам и позволяет агенту-другу по Библии проверять или расширять любое из них. Используйте, когда пользователь хочет ПРОЧИТАТЬ или ИЗУЧИТЬ Священные Писания в браузере, а не в терминале: 開網頁查經、網頁版 bible Buddy、經文標注、ELI5 筆記、劃線筆記、комментировать отрывок, пользовательский интерфейс для чтения Библии, запустить Библию веб-приложение. ИСКЛЮЧИТЬ: заключительные вопросы и ответы по Библии (библейский приятель), молитвы (библейский хлеб), обзор содержания (проверка библейских фактов).
