ELI5 注釈が付いた聖書箇所のローカル Web リーダー - FHL から箇所をロードし、単語自体に平易な言語のメモをドロップし、聖書仲間のエージェントがそれらのいずれかを検証または拡張できるようにする FastAPI + Claude Agent SDK ページ。ユーザーが端末ではなくブラウザで聖書を読んだり学習したりする場合に使用します: 開網頁查經、網頁版 bible buddy、經文標注、ELI5 書き込み、劃線書き込み、一節への注釈、聖書リーダー UI、聖書 Web アプリの開始。除外: ターミナル聖書 Q&A (聖書-バディ)、ディボーショナル (聖書-パン)、内容レビュー (聖書-ファクトチェック)。
