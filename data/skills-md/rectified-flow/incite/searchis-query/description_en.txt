Perform semantic search within internal financial research archives (research minutes, conference call transcripts, industry analyses). Input a research question in natural language and return a list of original textual evidence that matches the question (including source document title, author, date, line number). Understanding semantics is not keyword matching — the more specific the question description (research subject, time, dimension of interest, existing hypotheses), the more precise the returned evidence. Each invocation takes about 60–180 seconds.
