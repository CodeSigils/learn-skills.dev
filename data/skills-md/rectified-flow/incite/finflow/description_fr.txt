Interrogez les données des marchés financiers à l’aide de l’outil CLI finflow. Prend en charge les actions A, les actions de Hong Kong, les actions américaines, les contrats à terme et les données macro. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur les cotations boursières (SH600519, 00700, AAPL), les indices boursiers, les actualités financières, les flux de capitaux, les classements sectoriels, le calendrier macro, les contrats à terme ou toute autre donnée financière. Se déclenche également lorsque l'utilisateur mentionne des codes boursiers, des symboles boursiers (par exemple 茅台, NVDA, 腾讯), pose des questions sur le sentiment du marché, souhaite vérifier le portefeuille ou a besoin d'informations financières en temps réel pour prendre des décisions d'investissement.
