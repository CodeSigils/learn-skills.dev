يُستخدم عندما تتطلب مهمة التفاعل مع موقع ويب يتجاوز مجرد قراءته - النقر على العناصر، أو ملء النماذج، أو إرسال البيانات، أو التنقل عبر عمليات سير متعددة الخطوات، أو التقاط لقطات شاشة، أو أي سير عمل يحتاج فيه المستخدم إلى متصفح حقيقي يتضمن إجراءات مثل النقر أو الكتابة أو التمرير أو التحديد. استخدمه أيضًا لإدارة الإشارات المرجعية للمتصفح أو السجل أو علامات التبويب. يتم تشغيله عندما يذكر المستخدم browseros أو browseros-cli أو BrowserOS. لا تستخدمه عندما يكون جلب محتوى الصفحة أو قراءته كافيًا - استخدم تجعيد أو جلب أو WebFetch لذلك بدلاً من ذلك.
