Verwenden Sie diese Funktion, wenn eine Aufgabe die Interaktion mit einer Website erfordert, die über das bloße Lesen hinausgeht – das Anklicken von Elementen, das Ausfüllen von Formularen, das Senden von Daten, das Navigieren durch mehrstufige Abläufe, das Erstellen von Screenshots oder jeden Arbeitsablauf, bei dem der Benutzer einen echten Browser mit Aktionen wie Klicken, Tippen, Scrollen oder Auswählen benötigt. Kann auch zum Verwalten von Browser-Lesezeichen, -Verlauf oder -Registerkarten verwendet werden. Wird immer dann ausgelöst, wenn der Benutzer browseros, browseros-cli oder BrowserOS erwähnt. NICHT verwenden, wenn das einfache Abrufen oder Lesen von Seiteninhalten ausreicht – verwenden Sie stattdessen curl, fetch oder WebFetch.
