Úselo cuando una tarea requiera interactuar con un sitio web más allá de simplemente leerlo: hacer clic en elementos, completar formularios, enviar datos, navegar a través de flujos de varios pasos, tomar capturas de pantalla o cualquier flujo de trabajo donde el usuario necesite un navegador real con acciones como hacer clic, escribir, desplazarse o seleccionar. También se utiliza para administrar los marcadores, el historial o las pestañas del navegador. Se activa cada vez que el usuario menciona browseros, browseros-cli o BrowserOS. NO lo use cuando sea suficiente simplemente buscar o leer el contenido de la página; use curl, fetch o WebFetch para eso.
