Создание интерфейсов HumanSignal для Label Studio Enterprise: однофайловые экраны аннотаций JSX, которые запускаются в изолированном iframe оболочки редактора. Используйте, когда пользователь запрашивает пользовательский интерфейс маркировки, экран аннотаций, интерфейс Document AI, рабочий процесс проверки данных или преобразование макета React/Claude Design в интерфейс Label Studio.
