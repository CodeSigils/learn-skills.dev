Desarrolle una aplicación Base44 de forma remota desde su propio agente de codificación (Claude Code, claude.ai o cualquier cliente MCP) conectándolo al entorno limitado de Base44. Los agentes de la nube se conectan a través de MCP; los agentes locales pueden conectarse a través de MCP o controlar el mismo entorno sandbox con los subcomandos CLI `base44 sandbox` (el CLI usa nombres más cortos; por ejemplo, read_file es `sandbox read`, list_directory es `sandbox ls`, run_command es `sandbox run`). Cubre la conexión/autenticación, las herramientas sandbox disponibles (run_command, read_file, write_file, edit_file, grep, list_directory, create_checkpoint, get_app_preview_url, get_app_status, list_user_apps y las herramientas de conector list_connectors/iniciar_connector_connection), el bucle editar→vista previa→verificar, cómo persisten los cambios, simultaneidad entre generador/agente externo, el editor Botón "Enviar al agente de codificación" + incorporación de URL README y consejos como leer los registros del servidor de desarrollo de Vite. Activadores en "desarrollar mi aplicación Base44 de forma remota", "conectar Claude Code a Base44", "traer mi propio agente", "editar una aplicación Base44 a través de MCP", "Base44 sandbox MCP" o "Enviar al agente de codificación".
