Entwickeln Sie eine Base44-App remote von Ihrem eigenen Codierungsagenten (Claude Code, claude.ai oder einem beliebigen MCP-Client), indem Sie ihn mit der Base44-Sandbox verbinden. Cloud-Agenten stellen eine Verbindung über MCP her. Lokale Agenten können über MCP eine Verbindung herstellen oder dieselbe Sandbox mit den CLI-Unterbefehlen „base44 sandbox“ steuern (die CLI verwendet kürzere Namen – z. B. read_file ist „sandbox read“, list_directory ist „sandbox ls“, run_command ist „sandbox run“). Behandelt das Verbinden/Authentifizierung, die verfügbaren Sandbox-Tools (run_command, read_file, write_file, edit_file, grep, list_directory, create_checkpoint, get_app_preview_url, get_app_status, list_user_apps und die Connector-Tools list_connectors/initiate_connector_connection), die Edit→Preview→Verify-Schleife, wie Änderungen beibehalten werden, die Parallelität von Builder/externem Agent und den In-Editor Schaltfläche „An Coding Agent senden“ + Onboarding-README-URLs und Tipps wie das Lesen der Vite-Dev-Server-Protokolle. Auslöser für „Meine Base44-App remote entwickeln“, „Claude Code mit Base44 verbinden“, „Meinen eigenen Agenten mitbringen“, „Eine Base44-App über MCP bearbeiten“, „Base44-Sandbox-MCP“ oder „An Coding Agent senden“.
