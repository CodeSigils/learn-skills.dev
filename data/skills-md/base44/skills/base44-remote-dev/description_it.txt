Sviluppa un'app Base44 in remoto dal tuo agente di codifica (Claude Code, claude.ai o qualsiasi client MCP) collegandola alla sandbox Base44. Gli agenti cloud si connettono tramite MCP; gli agenti locali possono connettersi tramite MCP o gestire la stessa sandbox con i sottocomandi CLI `base44 sandbox` (la CLI utilizza nomi più brevi — ad esempio read_file è `sandbox read`, list_directory è `sandbox ls`, run_command è `sandbox run`). Riguarda la connessione/autenticazione, gli strumenti sandbox disponibili (run_command, read_file, write_file, edit_file, grep, list_directory, create_checkpoint, get_app_preview_url, get_app_status, list_user_apps e gli strumenti connettore list_connectors / inizia_connector_connection), il ciclo modifica→anteprima→verifica, come persistono le modifiche, concorrenza builder/agente esterno, editor interno Pulsante "Invia all'agente di codifica" + URL README di onboarding e suggerimenti come la lettura dei registri del server di sviluppo Vite. Si attiva "sviluppa la mia app Base44 in remoto", "connetti Claude Code a Base44", "porta il mio agente", "modifica un'app Base44 su MCP", "MCP sandbox Base44" o "Invia all'agente di codifica".
