Разработайте приложение Base44 удаленно с помощью собственного агента кодирования (Claude Code, claude.ai или любого клиента MCP), подключив его к изолированной программной среде Base44. Облачные агенты подключаются через MCP; локальные агенты могут подключаться через MCP или управлять одной и той же песочницей с помощью подкоманд CLI `base44 Sandbox` (CLI использует более короткие имена — например, read_file — это `sandbox read`, list_directory — `sandbox ls`, run_command — `sandbox run`). Охватывает подключение/аутентификацию, доступные инструменты песочницы (run_command, read_file, write_file, edit_file, grep, list_directory, create_checkpoint, get_app_preview_url, get_app_status, list_user_apps и инструменты коннектора list_connectors / инициировать_connector_connection), цикл редактирования → предварительный просмотр → проверки, сохранение изменений, параллелизм между сборщиком и внешним агентом, встроенный редактор. Кнопка «Отправить агенту кодирования» + URL-адреса README и советы, такие как чтение журналов сервера разработки Vite. Триггеры: «Удаленная разработка моего приложения Base44», «Подключение кода Claude к Base44», «Привлечение моего собственного агента», «Редактирование приложения Base44 через MCP», «Песочница MCP Base44» или «Отправка агенту кодирования».
