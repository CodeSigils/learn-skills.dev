Base44 アプリを Base44 サンドボックスに接続することで、独自のコーディング エージェント (Claude Code、claude.ai、または任意の MCP クライアント) からリモートで Base44 アプリを開発します。クラウド エージェントは MCP 経由で接続します。ローカル エージェントは、MCP 経由で接続することも、「base44 サンドボックス」 CLI サブコマンドを使用して同じサンドボックスを駆動することもできます (CLI では短い名前が使用されます。たとえば、read_file は「sandbox read」、list_directory は「sandbox ls」、run_command は「sandbox run」です)。接続/認証、利用可能なサンドボックス ツール (run_command、read_file、write_file、edit_file、grep、list_directory、create_checkpoint、get_app_preview_url、get_app_status、list_user_apps、およびコネクタ ツール list_connectors /Initial_connector_connection)、編集→プレビュー→検証ループ、変更の持続方法、ビルダー/外部エージェントの同時実行性、エディタ内について説明します。 「コーディング エージェントに送信」ボタン + オンボーディング README URL、および Vite 開発サーバー ログの読み取りなどのヒント。 「Base44 アプリをリモートで開発する」、「クロード コードを Base44 に接続する」、「独自のエージェントを使用する」、「MCP 経由で Base44 アプリを編集する」、「Base44 サンドボックス MCP」、または「コーディング エージェントに送信する」でトリガーされます。
