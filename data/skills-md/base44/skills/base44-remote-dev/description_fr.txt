Développez une application Base44 à distance depuis votre propre agent de codage (Claude Code, claude.ai ou n'importe quel client MCP) en la connectant au bac à sable Base44. Les agents cloud se connectent via MCP ; les agents locaux peuvent se connecter via MCP ou piloter le même bac à sable avec les sous-commandes CLI `base44 sandbox` (la CLI utilise des noms plus courts — par exemple, read_file est `sandbox read`, list_directory est `sandbox ls`, run_command est `sandbox run`). Couvre la connexion/l'authentification, les outils sandbox disponibles (run_command, read_file, write_file, edit_file, grep, list_directory, create_checkpoint, get_app_preview_url, get_app_status, list_user_apps et les outils de connecteur list_connectors / initiate_connector_connection), la boucle edit→preview→verify, la façon dont les modifications persistent, la concurrence constructeur/agent externe, l'éditeur intégré. Bouton "Envoyer à l'agent de codage" + URL README d'intégration et conseils comme la lecture des journaux du serveur de développement Vite. Déclencheurs sur "développer mon application Base44 à distance", "connecter Claude Code à Base44", "amener mon propre agent", "modifier une application Base44 via MCP", "Base44 sandbox MCP" ou "Envoyer à l'agent de codage".
