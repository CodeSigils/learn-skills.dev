Разрабатывайте приложение Base44 удаленно в облачной песочнице Base44 с помощью собственного агента — без локальной проверки и без команд развертывания и отправки. Реализация является удаленной: запись файла ресурсов в песочницу — это то, что его отправляет (внутренние функции, сущности и агенты автоматически синхронизируются из файла, который вы пишете), а соединители OAuth настраиваются для удаленного приложения с помощью инструментов MCP или безпроектного CLI `base44 Connectors`. Этот навык — место, где можно узнать, что можно создавать в песочнице, как структурированы серверные функции, сущности и агенты, а также как подключить коннектор без локальной файловой системы. Срабатывает при «разработке приложения Base44 удаленно», «нет локальных файлов», «облачной песочнице», «удаленном создании объекта/агента», «удаленном подключении соединителя», «приведении собственного агента» или любой работе по редактированию приложения Base44 внутри песочницы.
