Sviluppa un'app Base44 in remoto all'interno della sandbox cloud di Base44 utilizzando il tuo agente: senza checkout locale e senza comandi di distribuzione/push. L'implementazione è remota: la scrittura di un file di risorse nella sandbox è ciò che lo spedisce (funzioni di backend, entità e agenti si sincronizzano automaticamente dal file che scrivi) e i connettori OAuth vengono configurati rispetto all'app remota tramite strumenti MCP o la CLI "connettori base44" senza progetto. Questa competenza è il luogo in cui apprendere cosa puoi creare nella sandbox, come sono strutturate le funzioni, le entità e gli agenti di backend e come connettere un connettore senza un file system locale. Si attiva su "sviluppa la mia app Base44 in remoto", "nessun file locale", "sandbox cloud", "crea un'entità/agente in remoto", "connetti un connettore in remoto", "porta il mio agente" o qualsiasi lavoro di modifica di un'app Base44 all'interno di una sandbox.
