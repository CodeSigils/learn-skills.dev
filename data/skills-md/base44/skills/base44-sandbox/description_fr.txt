Développez une application Base44 à distance dans le sandbox cloud de Base44 à l'aide de votre propre agent — pas de paiement local et pas de commandes de déploiement/push. L'implémentation est à distance : l'écriture d'un fichier de ressources dans le bac à sable est ce qui l'expédie (les fonctions backend, les entités et les agents se synchronisent automatiquement à partir du fichier que vous écrivez), et les connecteurs OAuth sont configurés sur l'application distante via les outils MCP ou la CLI sans projet des « connecteurs base44 ». Cette compétence est l'endroit idéal pour apprendre ce que vous pouvez créer dans le bac à sable, comment les fonctions backend, les entités et les agents sont structurés et comment connecter un connecteur sans système de fichiers local. Déclencheurs sur « développer mon application Base44 à distance », « aucun fichier local », « bac à sable cloud », « créer une entité/un agent à distance », « connecter un connecteur à distance », « amener mon propre agent » ou tout travail d'édition d'une application Base44 dans un bac à sable.
