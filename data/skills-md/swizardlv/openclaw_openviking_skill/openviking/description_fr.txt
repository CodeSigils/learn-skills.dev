Recherche sémantique, gestion de contexte et indexation de documents via OpenViking. À utiliser lorsque l'utilisateur demande : indexer/importer des documents ou des fichiers dans une base de connaissances, effectuer une recherche sémantique dans le contenu indexé, parcourir ou explorer des ressources indexées, obtenir des résumés/aperçus de documents indexés, gérer une instance OpenViking ou intégrer une récupération de contexte structurée dans les flux de travail. À utiliser également lorsque les sous-agents doivent récupérer le contexte pertinent à partir d'une grande collection de documents.
