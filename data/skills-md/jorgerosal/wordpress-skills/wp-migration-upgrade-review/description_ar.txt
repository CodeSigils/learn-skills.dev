مراجعة ترحيل وترقية WordPress. يُستخدم عند مراجعة عمليات ترحيل قاعدة البيانات، أو إصدار الخيارات، أو إجراءات الترقية، أو عمليات إعادة تعبئة البيانات، أو استخدام dbDelta، أو توافق الإصدار، أو خطر التراجع، أو عندما يذكر المستخدم "مراجعة الترحيل"، أو "روتين الترقية"، أو "dbDelta"، أو "ترقية البرنامج المساعد"، أو "ترحيل البيانات"، أو "زيادة الإصدار"، أو "إعادة التعبئة"، أو "تغيير المخطط"، أو "التوافق مع الإصدارات السابقة". يكتشف عمليات الترحيل غير الآمنة، وغياب حراس الإصدار، وتغييرات البيانات المدمرة، ومخاطر تدفق الترقية في كود WordPress.
