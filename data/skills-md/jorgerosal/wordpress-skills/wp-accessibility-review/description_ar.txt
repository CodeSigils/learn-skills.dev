مراجعة إمكانية الوصول إلى WordPress للموضوعات والكتل والمكونات الإضافية وواجهات الإدارة. يُستخدم عند مراجعة التنقل عبر لوحة المفاتيح، أو سلوك التركيز، أو HTML الدلالي، أو استخدام ARIA، أو تسمية النماذج، أو دعم قارئ الشاشة، أو مشكلات التنفيذ المتعلقة بالتباين، أو عندما يذكر المستخدم "مراجعة إمكانية الوصول"، أو "a11y"، أو "التنقل عبر لوحة المفاتيح"، أو "إدارة التركيز"، أو "قارئ الشاشة"، أو "ARIA"، أو "HTML الدلالي"، أو "نموذج يمكن الوصول إليه"، أو "كتلة يمكن الوصول إليها". يكتشف مشكلات إمكانية الوصول على مستوى التنفيذ في مخرجات الواجهة الأمامية، وترميز الكتلة، وشاشات الإدارة، وسلوك واجهة المستخدم التفاعلية.
