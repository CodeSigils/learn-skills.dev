مراجعة رمز أمان WordPress واكتشاف الثغرات الأمنية. يُستخدم عند مراجعة كود WordPress PHP لمشاكل الأمان، أو تدقيق السمات/المكونات الإضافية بحثًا عن نقاط الضعف، أو التحقق من الكود قبل الإطلاق، أو تحليل معالجات AJAX/REST بحثًا عن عمليات استغلال، أو اكتشاف XSS، أو حقن SQL، أو CSRF، أو تجاوز الترخيص، أو عندما يذكر المستخدم "مراجعة الأمان"، أو "الثغرات الأمنية"، أو "XSS"، أو "حقن SQL"، أو "CSRF"، أو "nonce"، أو "التعقيم"، أو "الهروب"، أو "التحقق من القدرة"، أو "تصعيد الامتيازات"، "أمان تحميل الملفات" أو "رمز غير آمن" أو "تجاوز المصادقة" أو "تدقيق الأمان". يكتشف نقاط الضعف في معالجة المدخلات، والهروب من المخرجات، والترخيص، والأرقام غير المرغوب فيها، واستعلامات قاعدة البيانات، وتحميل الملفات، والوظائف الخطيرة.
