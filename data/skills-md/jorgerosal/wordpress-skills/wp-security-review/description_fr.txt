Révision du code de sécurité WordPress et détection des vulnérabilités. À utiliser lors de l'examen du code WordPress PHP pour les problèmes de sécurité, de l'audit des thèmes/plugins pour les vulnérabilités, de la vérification du code avant le lancement, de l'analyse des gestionnaires AJAX/REST pour les exploits, de la détection de XSS, d'injection SQL, de CSRF ou de contournement d'autorisation, ou lorsque l'utilisateur mentionne « examen de sécurité », « vulnérabilité », « XSS », « injection SQL », « CSRF », « nonce », « désinfection », « échappement », « contrôle de capacité », « élévation de privilèges », « sécurité du téléchargement de fichiers ». "code non sécurisé", "contournement d'authentification" ou "audit de sécurité". Détecte les vulnérabilités dans la gestion des entrées, l'échappement des sorties, l'autorisation, les noms occasionnels, les requêtes de base de données, les téléchargements de fichiers et les fonctions dangereuses.
