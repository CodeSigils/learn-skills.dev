WordPress のセキュリティ コードのレビューと脆弱性の検出。 WordPress PHP コードのセキュリティ問題のレビュー、テーマ/プラグインの脆弱性の監査、起動前のコードのチェック、エクスプロイトの AJAX/REST ハンドラーの分析、XSS、SQL インジェクション、CSRF、または認証バイパスの検出を行う場合、またはユーザーが「セキュリティ レビュー」、「脆弱性」、「XSS」、「SQL インジェクション」、「CSRF」、「ノンス」、「サニタイズ」、「エスケープ」、「機能チェック」に言及した場合に使用します。 「権限昇格」、「ファイルアップロードセキュリティ」、「安全でないコード」、「認証バイパス」、または「セキュリティ監査」。入力処理、出力エスケープ、認可、ノンス、データベース クエリ、ファイル アップロード、および危険な機能における脆弱性を検出します。
