Revisione del codice di sicurezza di WordPress e rilevamento delle vulnerabilità. Da utilizzare durante la revisione del codice PHP di WordPress per problemi di sicurezza, il controllo di temi/plugin per vulnerabilità, il controllo del codice prima del lancio, l'analisi dei gestori AJAX/REST per exploit, il rilevamento di XSS, SQL injection, CSRF o bypass di autorizzazione o quando l'utente menziona "revisione della sicurezza", "vulnerabilità", "XSS", "SQL injection", "CSRF", "nonce", "sanitization", "escaping", "capability check", "privilege escalation", "file upload security", "insecure code", "bypass di autenticazione" o "controllo di sicurezza". Rileva le vulnerabilità nella gestione dell'input, nell'escape dell'output, nell'autorizzazione, nei nonce, nelle query del database, nel caricamento di file e nelle funzioni pericolose.
