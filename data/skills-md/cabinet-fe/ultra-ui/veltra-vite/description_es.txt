Habilidades de documentación para integrar Vite con @veltra/vite. Se utiliza en cualquier proyecto de Vite para conectar VeltraDesktopUIResolver y unplugin-vue-components, solucionar problemas de importaciones automáticas de componentes @veltra/desktop, efectos secundarios de estilo, diferencias entre exportaciones de condiciones de importación y desarrollo, o para verificar los artefactos de instalación y las ubicaciones de origen de @veltra/vite en un proyecto consumidor.
