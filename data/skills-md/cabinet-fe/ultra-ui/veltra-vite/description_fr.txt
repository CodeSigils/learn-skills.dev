Documentation des compétences pour l'intégration de Vite ciblant @veltra/vite. Utilisé pour intégrer VeltraDesktopUIResolver et unplugin-vue-components dans n'importe quel projet Vite, dépanner les importations automatiques de composants @veltra/desktop, styliser les sideEffects, les différences entre le développement et l'importation des exportations conditionnelles, ou vérifier les artefacts installés et les chemins source de @veltra/vite dans le projet consommateur.
