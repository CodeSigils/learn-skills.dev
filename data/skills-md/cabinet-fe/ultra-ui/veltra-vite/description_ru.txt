Документация по навыкам интеграции Vite с @veltra/vite. Используется для подключения VeltraDesktopUIResolver и отключения компонентов vue в любом проекте Vite, устранения неполадок автоматического импорта компонентов @veltra/desktop, стилевых побочных эффектов, различий между условиями разработки и импорта или проверки выходных данных сборки и местоположения исходного кода @veltra/vite в потребляющем проекте.
