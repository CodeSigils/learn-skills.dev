Habilidades de documentación de composición de Vue 3 para `@veltra/compositions`. Se utiliza para comprender o modificar la lógica componible común como `useConfig`, `useModel`, `useFormComponent`, `useFormFallbackProps`, `usePop`, `useVirtual`, `useTransition`, o para rastrear el estado compartido, el contexto del formulario, el posicionamiento de superposición y el comportamiento de la lista virtual en componentes `@veltra/desktop`.
