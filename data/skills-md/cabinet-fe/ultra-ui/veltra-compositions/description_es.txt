Utilidades de composición de Vue 3 para el paquete `@veltra/compositions`. Se utiliza para comprender o modificar elementos componibles comunes como `useConfig`, `useModel`, `useFormComponent`, `useFormFallbackProps`, `usePop`, `useVirtual`, `useTransition`, o para rastrear el estado compartido, el contexto del formulario, el posicionamiento de superposición y el comportamiento de la lista virtual en componentes `@veltra/desktop`.
