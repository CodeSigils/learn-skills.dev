Habilidad de documentación para la biblioteca de componentes de escritorio de `@veltra/desktop`. Se utiliza para agregar, modificar, solucionar problemas o importar componentes de escritorio a pedido, rastrear el emparejamiento entre `src/components` y `src/types`, mantener la entrada de efectos secundarios `style.ts`, modos de componentes de formulario, contexto `di.ts`, directiva incorporada `vLoading` y comprender rápidamente el uso en el mundo real a través de los ejemplos de `playgrounds/desktop`.
