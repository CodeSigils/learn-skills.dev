Навыки документирования библиотеки компонентов рабочего стола `@veltra/desktop`. Используется для добавления, изменения, устранения неполадок или импорта компонентов рабочего стола по требованию, отслеживания сопряжения между src/comComponents и src/types, поддержки записи побочного эффекта style.ts, формирования режимов компонентов, контекста di.ts, встроенной директивы vLoading и быстрого понимания реального использования с помощью примеров playgrounds/desktop.
