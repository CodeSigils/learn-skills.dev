Utilidades de bajo nivel, constantes compartidas y habilidades de documentación de tipos para `@veltra/utils`. Se utiliza para rastrear BEM/nombres de clase, ayudantes DOM, validación de formularios, utilidades receptivas, tipos compartidos y exportaciones de subrutas, o cuando se modifica `@veltra/compositions`, `@veltra/directives`, `@veltra/desktop` se requiere regresar a la capa fundamental para ubicar implementaciones y límites.
