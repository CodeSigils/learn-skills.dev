SCSS compartido, funciones/mixins BEM, estilos de animación y habilidades de documentación de tiempo de ejecución de temas para `@veltra/styles`. Se utiliza para configurar `pkg:@veltra/styles/...` referencias de Sass, integrar `NodePackageImporter`, modificar `normalize`/`anime`, rastrear `UITheme`/`loadTheme`/la lógica del tema preestablecido en `@veltra/styles/theme` o reutilizar el sistema de temas Ultra UI en otros proyectos.
