Руководства по созданию приложений Expo/React Native с помощью TypeScript с использованием согласованной архитектуры и стека библиотек (NativeWind, React Navigation, TanStack Query, Zustand, Axios). Используйте при создании нового проекта React Native или обновлении архитектуры/UI/состояния/API/маршрутизации/стилизации в соответствии с этими соглашениями.
