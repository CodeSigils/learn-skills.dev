Guías para crear aplicaciones Vite + React SPA con TypeScript utilizando una arquitectura y una pila de biblioteca consistentes (Tailwind CSS v4, class-variance-authority, rutas basadas en archivos TanStack Router, TanStack Query, Zustand, Axios, tokens estilo shadcn, primitivas en src/ui). Úselo al crear un nuevo proyecto web de React o al actualizar la arquitectura/UI/estado/API/enrutamiento/estilo para seguir estas convenciones.
