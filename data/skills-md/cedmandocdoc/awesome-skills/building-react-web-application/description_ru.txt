Руководства по созданию приложений Vite + React SPA с помощью TypeScript с использованием согласованной архитектуры и стека библиотек (Tailwind CSS v4, class-variance-authority, файловые маршруты TanStack Router, TanStack Query, Zustand, Axios, токены в стиле shadcn, примитивы в src/ui). Используйте при создании нового веб-проекта React или обновлении архитектуры/UI/состояния/API/маршрутизации/стилизации в соответствии с этими соглашениями.
