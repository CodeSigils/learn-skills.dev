Guide la création d'applications Vite + React SPA avec TypeScript en utilisant une architecture et une pile de bibliothèques cohérentes (Tailwind CSS v4, class-variance-authority, routes basées sur des fichiers TanStack Router, TanStack Query, Zustand, Axios, jetons de style shadcn, primitives dans src/ui). À utiliser lors de la création d'un nouveau projet Web React ou de la mise à jour de l'architecture/UI/état/API/routage/style pour suivre ces conventions.
