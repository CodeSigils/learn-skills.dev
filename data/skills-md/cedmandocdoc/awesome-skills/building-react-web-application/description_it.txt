Guide alla creazione di app Vite + React SPA con TypeScript utilizzando un'architettura e uno stack di librerie coerenti (Tailwind CSS v4, class-variance-authority, percorsi basati su file TanStack Router, TanStack Query, Zustand, Axios, token in stile shadcn, primitive in src/ui). Da utilizzare quando si crea un nuovo progetto Web React o si aggiorna architettura/interfaccia utente/stato/API/routing/stile per seguire queste convenzioni.
