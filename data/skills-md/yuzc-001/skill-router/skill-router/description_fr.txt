À utiliser lorsque l'utilisateur demande quelle compétence utiliser, si une compétence installée existe déjà, si l'environnement de compétences actuel est suffisant ou si une compétence inconnue doit être vérifiée avant l'installation. À utiliser également lorsque plusieurs compétences installées se chevauchent suffisamment pour que le choix par défaut ne soit vraiment pas clair. Ne pas utiliser pour une exécution simple, des correspondances évidentes avec une seule compétence ou des cas où le routage ne modifierait pas l'action suivante.
