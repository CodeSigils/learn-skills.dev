Úselo cuando el usuario pregunta qué habilidad usar, si ya existe una habilidad instalada, si el entorno de habilidades actual es suficiente o si una habilidad desconocida debe examinarse antes de la instalación. Úselo también cuando varias habilidades instaladas se superpongan lo suficiente como para que la opción predeterminada no esté realmente clara. NO lo use para ejecuciones simples, coincidencias obvias de una sola habilidad o casos en los que el enrutamiento no cambiaría la siguiente acción.
