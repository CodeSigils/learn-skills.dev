Utilizza la CLI CreatiBI (cbi) per caricare file locali nella libreria di risorse e completare l'inizializzazione della prima configurazione e l'accesso OAuth quando necessario. Da utilizzare quando gli utenti menzionano scenari come "carica nella libreria di risorse", "carica file cbi", "crea file nel repository", "inizializza prima cbi", "prima accedi, poi carica", ecc.; applicabile alle attività di caricamento di file locali per immagini, video, documenti e altre risorse che devono essere archiviate nella libreria.
