Utilisez CreatiBI CLI (cbi) pour télécharger des fichiers locaux dans la bibliothèque d'actifs, et effectuez la première initialisation de la configuration et la connexion OAuth si nécessaire. À utiliser lorsque les utilisateurs mentionnent des scénarios tels que « télécharger vers la bibliothèque d'actifs », « télécharger un fichier cbi », « créer un fichier de référentiel », « initialiser d'abord cbi », « se connecter d'abord puis télécharger », etc. ; applicable aux tâches de téléchargement de fichiers locaux pour les images, vidéos, documents et autres ressources qui doivent être stockées dans la bibliothèque.
