OpenCode と Claude Code に最適なモデルとロールの割り当てを使用して、マルチエージェント コーディング チームを設計、生成、改良します。推論文書とすぐに貼り付けられる構成ファイルを作成します。コードベースのマルチエージェント設定の作成時、エージェント チームによる新しいプロジェクトの開始時、既存のエージェント チーム構成のレビューまたは改善時、どの AI モデルをどのエージェント ロールに割り当てるかを決定するとき、またはエージェント間のコスト/速度/品質のトレードオフを最適化するときにトリガーされます。また、サブエージェント設計、モデル ルーティング、エージェント オーケストレーション、コーディング エージェントのモデル選択、またはさまざまなタスク タイプでの Opus、Sonnet、Haiku の比較のトリガーも行います。
