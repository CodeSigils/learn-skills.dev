Проектирует, создает и совершенствует многоагентные группы кодирования с оптимальным распределением моделей и ролей для OpenCode и Claude Code. Создает обосновывающие документы и готовые к вставке файлы конфигурации. Срабатывает при создании мультиагентной установки для базы кода, запуске нового проекта с командой агентов, проверке или улучшении существующей конфигурации команды агентов, решении, какую модель ИИ назначить той или иной роли агента, или оптимизации соотношения стоимости/скорости/качества между агентами. Также триггеры для проектирования субагентов, маршрутизации моделей, оркестрации агентов, выбора модели для агентов кодирования или сравнения Opus, Sonnet и Haiku для разных типов задач.
