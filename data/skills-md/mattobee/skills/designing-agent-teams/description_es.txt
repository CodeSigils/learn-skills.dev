Diseña, genera y perfecciona equipos de codificación de múltiples agentes con asignaciones óptimas de modelo a rol para OpenCode y Claude Code. Produce documentos de razonamiento y archivos de configuración listos para pegar. Se activan al crear una configuración de múltiples agentes para una base de código, iniciar un nuevo proyecto con un equipo de agentes, revisar o mejorar la configuración de un equipo de agentes existente, decidir qué modelo de IA asignar a qué rol de agente u optimizar las compensaciones de costo/velocidad/calidad entre agentes. También activadores para el diseño de subagentes, enrutamiento de modelos, orquestación de agentes, selección de modelos para agentes de codificación o comparaciones de Opus, Sonnet y Haiku para diferentes tipos de tareas.
