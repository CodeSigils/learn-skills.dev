يقوم بتصميم وإنشاء وتحسين فرق الترميز متعددة الوكلاء مع التعيينات المثالية من النموذج إلى الدور لـ OpenCode وClaude Code. يُنتج مستندات منطقية وملفات تكوين جاهزة للصق. يتم التشغيل عند إنشاء إعداد متعدد الوكلاء لقاعدة التعليمات البرمجية، أو بدء مشروع جديد مع فريق الوكلاء، أو مراجعة أو تحسين تكوين فريق الوكلاء الحالي، أو تحديد نموذج الذكاء الاصطناعي الذي سيتم تعيينه لأي دور وكيل، أو تحسين مقايضات التكلفة/السرعة/الجودة عبر الوكلاء. مشغلات أيضًا لتصميم الوكيل الفرعي، أو توجيه النموذج، أو تنسيق الوكيل، أو اختيار النموذج لوكلاء الترميز، أو مقارنات Opus vs Sonnet vs Haiku لأنواع المهام المختلفة.
