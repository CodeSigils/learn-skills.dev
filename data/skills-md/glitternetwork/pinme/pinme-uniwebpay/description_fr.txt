À utiliser lors de la génération, de la modification ou de la révision du code TypeScript PinMe Cloudflare Worker qui accepte les paiements via UniwebPay. L'application cible est un projet PinMe Worker dans lequel PinMe injecte des liaisons UNIWEB_* et le Worker appelle UniwebPay directement avec @uniwebpay/sdk. Couvre les liaisons Env, la configuration du client SDK, les liens de paiement, les produits/prix, les sessions de paiement, les lectures de l'état de paiement, les remboursements/abonnements/webhooks sur demande et les règles de déploiement/sécurité spécifiques à PinMe.
