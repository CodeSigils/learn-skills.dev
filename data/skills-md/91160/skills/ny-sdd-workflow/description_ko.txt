SDD 워크플로우 v1.0.3 개발 워크플로우를 프로젝트에 설치하십시오. 스킬 설치 경로를 자동으로 확인하고, **AGENTS.md**(핵심 규칙 + 기본 제공 경로)를 생성하고, 동시에 **CLAUDE.md**(symlink → AGENTS.md, Claude Code가 자동으로 읽기)를 생성하고, 주문형 읽기를 위해 스킬 디렉터리에 스테이지 규칙 파일(rules/)을 유지하고, 선택적으로 다른 AI 도구와 동기화합니다.

**아키텍처**: G-시리즈 전역 규칙 + §1~§4 단계 번호 + 흐름 선언 헤더 메커니즘(**4개 값 차단 포함** true/false/gated/감사 필수) + 동적 로딩 + **통합 실행 자체 감사 메커니즘**(교차 대화 킥오프 + 단일 세션 내 섹션당 2개의 트리거 지점) + **context.md `생산` 필드**(아티팩트 경로 + 앵커 + SHA-256의 처음 8자, 챕터에서만 필수) §2.4, §3.6, §3.7) + **감사 시작 체크리스트**(§3.6 입력 시 의심 포인트 ≥3개 + 검증) + **이전 섹션 아티팩트 재주입**(§2.5/§3.7/§3.8 입력 시 이전 아티팩트 + 해시 검증) + 13개의 슬래시 명령, 여러 AI 도구와 호환됩니다.

**다음 시나리오에서 트리거되어야 합니다.**  
- 사용자가 "SDD 설치", "에이전트 설치", "AI 워크플로 설치" 또는 "개발 표준 구성"이라고 말합니다.  
- 사용자가 `/sdd-init` 명령을 실행합니다.  
- 사용자가 "워크플로 시작" 또는 "개발 시작"이라고 말하고 프로젝트 루트 디렉터리에 `AGENTS.md`가 없습니다**(대체: SDD가 설치되지 않은 경우 먼저 사용자를 위해 설치합니다. 설치 후 **자동으로 G0 대화 상자 초기화를 계속 진행**하므로 사용자는 "워크플로 시작"을 다시 트리거할 필요가 없습니다).  
- 새로운 프로젝트에서 AI 코딩 워크플로우 사양을 수립해야 하는 경우.  
- 사용자가 "워크플로 업데이트" 또는 "SDD 업데이트"라고 말합니다.

**참고:**  
- Claude Code의 내장 `/init` 명령(독립형 CLAUDE.md 생성)은 이 워크플로에서 생성된 CLAUDE.md 심볼릭 링크를 덮어씁니다. 혼합하지 마십시오.  
- 사용자가 "워크플로 시작"이라고 말하거나 `/sdd-start`를 실행하면 기본적으로 **프로젝트 개발 프로세스에 들어갑니다**(G0 대화 상자 초기화). `AGENTS.md`가 존재하지 않는 경우에만 인프라 설치를 수행하기 위해 이 기술로 대체됩니다. **자연어 "워크플로 시작"에 의해 트리거된 대체 설치는 완료 후 자동으로 첫 번째 G0 경로로 계속됩니다**(Step0 항목 유형 감지 + Step7 라우팅 분기 참조). 따라서 사용자는 이를 다시 트리거할 필요가 없습니다. 명시적인 `/sdd-init` 설치만이 "설치 후 사용자 확인을 위해 일시 ​​중지"하는 2단계 설계를 유지합니다.  

**출력:**  
① 프로젝트 루트 디렉터리의 `AGENTS.md` ({SKILL_DIR}을 실제 경로로 대체)  
② `CLAUDE.md`(symlink → `AGENTS.md`, Windows에서 복사 대체 사용)  
③ 각 AI 도구의 명령 파일에 대한 심볼릭 링크  
④ 슬래시 명령 설치(사용자 수준 / 프로젝트 수준 / 건너뛰기 중 하나 선택)
