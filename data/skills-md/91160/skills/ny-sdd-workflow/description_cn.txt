将 SDD Workflow v1.0.3 开发工作流程安装到项目中。自动解析技能安装路径，生成**AGENTS.md**（核心规则+烘焙路径），同时生成**CLAUDE.md**（符号链接→AGENTS.md，Claude代码自动读取），将阶段规则文件（rules/）保留在技能目录中以供按需读取，并可选择同步到其他AI工具。

**架构**：G系列全局规则+§1~§4阶段编号+流程声明标头机制（包括**四值阻塞**真/假/门控/审核要求）+动态加载+**统一执行自审核机制**（跨对话启动+单个会话中每个部分两个触发点）+**context.md“生产”字段**（工件路径+锚点+SHA-256的前8个字符，仅在章节中强制§2.4、§3.6、§3.7) + **审核启动清单**（当进入§3.6时，≥3个怀疑点+验证） + **上一节工件重新注入**（当输入§2.5 / §3.7 / §3.8时，cat以前的工件+哈希验证） + 13个斜杠命令，与多种AI工具兼容。

**以下场景必须触发：**  
- 用户说“安装 SDD”、“安装 AGENTS”、“安装 AI 工作流程”或“配置开发标准”。  
- 用户运行“/sdd-init”命令。  
- 用户说“开始工作流程”或“开始开发”**并且项目根目录缺少`AGENTS.md`**（回退：如果未安装SDD，请先为用户安装；安装后，**自动继续G0对话初始化**，因此用户不需要再次触发“启动工作流程”）。  
- 当一个新项目需要建立AI编码工作流程规范时。  
- 用户说“更新工作流程”或“更新 SDD”。

**注：**  
- Claude Code 中的内置“/init”命令（生成独立的 CLAUDE.md）将覆盖此工作流程创建的 CLAUDE.md 符号链接；不要混合它们。  
- 当用户说“启动工作流程”或运行“/sdd-start”时：默认情况下**进入项目开发流程**（G0对话初始化）。如果“AGENTS.md”不存在，则仅使用此技能来执行基础设施安装； **由自然语言“启动工作流程”触发的后备安装完成后自动继续第一个G0路径**（参见Step0入口类型检测+Step7路由分支），因此用户无需再次触发；只有显式的“/sdd-init”安装才会保留“安装然后暂停以进行用户验证”的两阶段设计。  

**输出：**  
① 项目根目录下的`AGENTS.md`（{SKILL_DIR}替换为实际路径）  
② `CLAUDE.md`（符号链接 → `AGENTS.md`，在 Windows 上有复制回退）  
③ 每个 AI 工具的命令文件的符号链接
