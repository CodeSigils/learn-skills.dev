Установите в проект рабочий процесс разработки SDD Workflow v1.0.3. Автоматический анализ пути установки навыков, создание **AGENTS.md** (основные правила + встроенный путь), одновременное создание **CLAUDE.md** (символическая ссылка → AGENTS.md, автоматическое чтение Claude Code), сохранение файлов правил этапа (`rules/`) в каталоге навыков для чтения по требованию и при необходимости синхронизация с другими инструментами ИИ.  

**Архитектура**: глобальные правила серии G + номера стадий §1–§4 + механизм заголовка объявления потока (включая **блокировку четырех значений** true/false/gated/audit‑required) + динамическую загрузку + **унифицированный механизм самоаудита выполнения** (запуск перекрестного диалога + две триггерные точки на раздел в одном сеансе) + **`context.md` `произведенное` поле** (путь к артефакту + привязка + первые 8 символов SHA-256, обязателен только в §§2.4,3.6,3.7) + **начальный контрольный список аудита** (≥3 точек подозрения + проверка при вводе §3.6) + **повторное внедрение артефакта предыдущего раздела** (кошка предыдущего артефакта + проверка хэша при вводе §§2.5,3.7,3.8) + 13 косых команд, совместимых с несколькими инструментами ИИ.  

**Должен срабатывать в следующих сценариях:**  
- Пользователь говорит «установить SDD», «установить АГЕНТЫ», «установить рабочий процесс AI», «настроить стандарты разработки».  
- Пользователь запускает команду `/sdd-init`  
- Пользователь говорит «начать рабочий процесс», «начать разработку» **а в корне проекта отсутствует `AGENTS.md`** (резервный вариант: если SDD не установлен, сначала установите его для пользователя; после установки **автоматически возобновляется инициализация диалогового окна G0**, поэтому пользователю не нужно снова запускать «начать рабочий процесс»)  
- Когда в новом проекте необходимо установить стандарт рабочего процесса кодирования ИИ.  
- Пользователь говорит «обновить рабочий процесс», «обновить SDD».  

**Примечание:**  
- Встроенная команда `/init` Claude Code (которая создает независимый `CLAUDE.md`) перезапишет символическую ссылку `CLAUDE.md`, созданную этим рабочим процессом; не смешивайте их.  
- Когда пользователь говорит «начать рабочий процесс» или запускает `/sdd-start`: по умолчанию используется **вход в процесс разработки проекта** (инициализация диалогового окна G0). Только если `AGENTS.md` не существует, этот навык будет задействован для завершения установки инфраструктуры; **резервная установка, инициируемая «запуском рабочего процесса» на естественном языке, автоматически продолжает первый путь G0 после завершения** (см. определение типа записи Step0 + ветки маршрутизации Step7), поэтому пользователю не нужно запускать ее снова; только явная установка `/sdd-init` сохраняет двухэтапную схему «остановиться после установки и дождаться проверки пользователя».  

**Выходы:**  
1️⃣ `AGENTS.md` в корне проекта (где `{SKILL_DIR}` заменен фактическим путем)  
2️⃣ `CLAUDE.md` (символическая ссылка → `AGENTS.md`, резервное копирование в Windows)  
3️⃣ Символические ссылки для каждого командного файла инструмента AI.  
4️⃣ Установка слэш-команд (выберите один: уровень пользователя/уровень проекта/пропустить)  
5️⃣ Отчет о состоянии инициализации
