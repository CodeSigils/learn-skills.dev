將 SDD Workflow v1.0.3 開發工作流程安裝到專案中。自動解析技能安裝路徑，產生**AGENTS.md**（核心規則+烘焙路徑），同時產生**CLAUDE.md**（符號連結→AGENTS.md，Claude程式碼自動讀取），將階段規則檔（rules/）保留在技能目錄中以供按需讀取，並可選擇同步到其他AI工具。

**架構**：G系列全域規則+§1~§4階段編號+流程聲明標頭機制（包括**四值阻塞**真/假/門控/審核要求）+動態載入+**統一執行自審核機制（**對話啟動+單一會話中每個部分兩個觸發點）+**context.md「生產」欄位**§+ **審核啟動清單**（當進入§3.6時，≥3個懷疑點+驗證） + **上一節工件重新註入**（當輸入§2.5 / §3.7 / §3.8時，cat以前的工件+哈希驗證） + 13個斜杠命令，與多種AI工具兼容。

**以下場景必須觸發：**
- 使用者說「安裝 SDD」、「安裝 AGENTS」、「安裝 AI 工作流程」或「配置開發標準」。  
- 使用者執行“/sdd-init”命令。  
- 使用者說「開始工作流程」或「開始開發」**且專案根目錄缺少`AGENTS.md`**（回退：如果未安裝SDD，請先為使用者安裝；安裝後，**自動繼續G0對話初始化**，因此使用者不需要再次觸發「啟動工作流程」）。  
- 當一個新專案需要建立AI編碼工作流程規格。  
- 使用者說「更新工作流程」或「更新 SDD」。

**註：**
- Claude Code 中的內建「/init」命令（產生獨立的 CLAUDE.md）將覆蓋此工作流程建立的 CLAUDE.md 符號連結；不要混合它們。  
- 當使用者說「啟動工作流程」或執行「/sdd-start」時：預設**進入專案開發流程**（G0對話初始化）。如果「AGENTS.md」不存在，則僅使用此技能來執行基礎設施安裝； **由自然語言「啟動工作流程」觸發的後備安裝完成後自動繼續第一個G0路徑**（請參閱Step0入口類型檢測+Step7路由分支），因此使用者無需再次觸發  

**輸出：**
① 專案根目錄下的`AGENTS.md`（{SKILL_DIR}替換為實際路徑）
② `CLAUDE.md`（符號連結 → `AGENTS.md`，在 Windows 上有複製回退）
③ 每個 AI 工具的命令檔的符號鏈接
④ Slash Commands 安裝（選擇一項：使用者等級/專案級/跳過）
⑤ 初始化狀態報告
