فحص كود الصدأ - مراجعة العلاقات العامة، وتصحيح الأخطاء، وتوصيف الأداء. يغطي قوائم مراجعة المراجعة حسب المنطقة (الهندسة المعمارية، الملكية، تدفق التحكم، غير المتزامن، معالجة الأخطاء، غير آمن، الاختبار، الأمان، الأداء)، تصنيف الخطورة، دليل تصحيح الأخطاء (الذعر، OOM، حالة توقف تام، المزامنة البطيئة، الاختبار غير المستقر، Miri UB، المطهرات)، دليل ملفات التعريف (المعيار، مخطط اللهب، الأداء، DHAT، tokio-console، samply)، كتالوج أخطاء الأداء، إعادة العامل القوالب، والتدقيق الأمني (تدقيق البضائع، والمراجعة غير الآمنة، والتحقق من صحة الإدخال، والتشفير)، وأسلوب المراجعة والتعليق. استخدمه دائمًا عند مراجعة Rust PRs أو الاختلافات أو الوحدات النمطية الموجودة. استخدمه دائمًا عند تصحيح أخطاء Rust (الذعر، وأخطاء الذاكرة، والجمود، والتزامن البطيء، والتقلب). استخدمه دائمًا عند تحديد مواصفات أداء الصدأ. استخدمه دائمًا عندما يُطلب منك التدقيق أو النقد أو المراجعة أو التصحيح أو الملف الشخصي لرمز الصدأ. لتصميم تخطيط الحمل الصدأ. لكتابة تحميل الصدأ التنفيذ.
