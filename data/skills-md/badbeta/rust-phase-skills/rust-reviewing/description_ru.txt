Проверка кода Rust — проверка PR, отладка ошибок, профилирование производительности. Охватывает контрольные списки проверки по областям (архитектура, владение, поток управления, асинхронность, обработка ошибок, небезопасность, тестирование, безопасность, производительность), классификация серьезности, книга отладки (паника, OOM, тупик, медленная асинхронность, нестабильный тест, Miri UB, дезинфицирующие средства), книга профилирования (критерий, Flamegraph, perf, DHAT, tokio-console, образец), каталог ошибок производительности, шаблоны рефакторинга, аудит безопасности (аудит грузов, небезопасная проверка, проверка ввода, шифрование) и стиль обзора-комментария. ВСЕГДА используйте при просмотре PR, различий или существующих модулей Rust. ВСЕГДА используйте при отладке ошибок Rust (паники, ошибки памяти, взаимоблокировки, медленная асинхронность, нестабильность). ВСЕГДА используйте при профилировании производительности Rust. ВСЕГДА используйте, когда вас просят провести аудит, критику, обзор, отладку или профилирование кода Rust. Для проектирования нагрузки ржавчины планирования; для написания нагрузки, реализации ржавчины.
