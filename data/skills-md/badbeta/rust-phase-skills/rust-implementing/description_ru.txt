Rust для идиоматической реализации — таблицы решений, шаблоны и антишаблоны, которые заставляют Клода писать идиоматический Rust в момент написания. Охватывает владение, сопоставление шаблонов, распространение ошибок `?`, итераторы, дизайн признаков, дженерики против `dyn Trait`, Pin/Unpin, Tokio, каналы, шаблоны `Arc<Mutex>`, serde, макросы, FFI, axum, sqlx/diesel, clap, WASM/GUI, GPU/wgpu и TDD с макетом, insta, proptest, Cargo-Fuzz. Rust 2024. ВСЕГДА используйте при написании кода Rust. ВСЕГДА используйте при выборе между match/if-let/let-else/`?`. ВСЕГДА используйте при выборе между «impl Trait», «dyn Trait» и дженериками. ВСЕГДА используйте при выборе между `Arc<Mutex<T>>` и каналами. ВСЕГДА используйте при написании асинхронного Rust (Tokio, каналы, спавн, выбор). ВСЕГДА используйте при написании тестов, макетов или практике TDD. ВСЕГДА используйте при рефакторинге Rust в сторону идиоматической формы. Для архитектуры/дизайна загрузите Rust-planning. Для проверки/отладки/профилирования загрузите Rust-Review.
