Rust para implementación idiomática: tablas de decisiones, plantillas y antipatrones que hacen que Claude escriba Rust idiomático en el momento de escribir. Cubre propiedad, coincidencia de patrones, propagación de errores `?`, iteradores, diseño de rasgos, genéricos vs `dyn Trait`, Pin/Unpin, Tokio, canales, patrones `Arc<Mutex>`, serde, macros, FFI, axum, sqlx/diesel, clap, WASM/GUI, GPU/wgpu y TDD con mockall, insta, proptest, cargo-fuzz. Rust 2024. Úselo SIEMPRE al escribir código Rust. Utilícelo SIEMPRE al decidir entre match/if-let/let-else/`?`. Utilícelo SIEMPRE al decidir entre `impl Trait`, `dyn Trait` y genéricos. SIEMPRE utilícelo al decidir entre `Arc<Mutex<T>>` y canales. Utilícelo SIEMPRE al escribir Rust asíncrono (Tokio, canales, generación, selección). Úselo SIEMPRE al escribir exámenes, simulacros o practicar TDD. Úselo SIEMPRE al refactorizar Rust hacia una forma idiomática. Para arquitectura/diseño, carga de planificación de óxido. Para revisar/depurar/perfilar, cargue Rust-Reviewing.
