الصدأ للتنفيذ الاصطلاحي - جداول القرار والقوالب والأنماط المضادة التي تجعل كلود يكتب الصدأ الاصطلاحي في لحظة الكتابة. يغطي الملكية، مطابقة الأنماط، `؟` انتشار الأخطاء، التكرارات، تصميم السمات، الأدوية العامة مقابل `dyn Trait`، Pin/Unpin، Tokio، القنوات، أنماط `Arc<Mutex>`، serde، وحدات الماكرو، FFI، axum، sqlx/diesel، clap، WASM/GUI، GPU/wgpu، وTDD مع mockall، insta،proptest،Cargo-Fuz. Rust 2024. استخدمه دائمًا عند كتابة كود Rust. يُستخدم دائمًا عند الاختيار بين match/if-let/let-else/`?`. استخدمه دائمًا عند الاختيار بين "السمات الضمنية" و"dyn Trait" والأسماء العامة. استخدمه دائمًا عند الاختيار بين `Arc<Mutex<T>>` والقنوات. استخدمه دائمًا عند كتابة Rust غير المتزامن (Tokio، Channels، Spawn، Select). استخدمه دائمًا عند كتابة الاختبارات أو السخرية أو ممارسة TDD. استخدم دائمًا عند إعادة هيكلة Rust نحو الشكل الاصطلاحي. بالنسبة للهندسة المعمارية/التصميم، قم بتحميل تخطيط الصدأ. للمراجعة/التصحيح/التوصيف، قم بتحميل مراجعة الصدأ.
