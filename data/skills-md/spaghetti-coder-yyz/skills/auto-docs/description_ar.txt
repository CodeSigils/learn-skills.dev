ينشئ وثائق فنية منظمة في /docs كملفات تخفيض السعر، مع مخططات حورية البحر، وأمثلة الاستخدام، ومراجع قاعدة التعليمات البرمجية، وعلامات المرجع الخلفي @docs التي تحافظ على مزامنة المستندات عند تحرير الملفات المصدر لاحقًا. يُستخدم عندما يطلب المستخدم إنشاء أو كتابة أو إنشاء وثائق لميزة أو واجهة برمجة تطبيقات أو مكون أو خطاف ويب أو تدفق.
