Crée une documentation technique structurée dans /docs sous forme de fichiers markdown, avec des diagrammes Mermaid, des exemples d'utilisation, des références de base de code et des balises de référence arrière @docs qui maintiennent les documents synchronisés lorsque les fichiers sources sont modifiés ultérieurement. À utiliser lorsque l'utilisateur demande à créer, écrire ou générer de la documentation pour une fonctionnalité, une API, un composant, un webhook ou un flux.
