Crea documentazione tecnica strutturata in /docs come file di markdown, con diagrammi Sirena, esempi di utilizzo, riferimenti alla base di codice e tag di riferimento all'indietro @docs che mantengono sincronizzati i documenti quando i file di origine vengono successivamente modificati. Da utilizzare quando l'utente richiede di creare, scrivere o generare documentazione per una funzionalità, un'API, un componente, un webhook o un flusso.
