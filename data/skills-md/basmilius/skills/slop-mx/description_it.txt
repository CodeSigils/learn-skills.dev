Pubblica un documento, un diagramma o un piccolo file dal terminale a un host di pubblicazione (URL non elencato), disegnando diagrammi con Flux Flow. Da utilizzare quando l'utente chiede di pubblicare, pubblicare o mettere qualcosa online ("publiceer dit plan op slop.mx", "zet dit diagram online"), di aggiornare qualcosa pubblicato in precedenza, di caricare una piccola immagine o desidera un diagramma di un processo, flusso, pipeline o architettura ("maak een diagram van het inlogproces", "teken deze pipeline") o desidera mostrare una modifica al codice come rich diff ("publiceer deze diff", "zet deze wijziging online als differenza"). Tre tipi: un documento (markdown, con componenti che includono una vista diff in stile GitHub), un diagramma (un modello Flux Flow con coordinate esplicite) e un file (byte grezzi).
