انشر مستندًا أو رسمًا تخطيطيًا أو ملفًا صغيرًا من الوحدة الطرفية إلى مضيف نشر (عنوان URL غير مدرج)، ورسم المخططات باستخدام Flux Flow. يُستخدم عندما يطلب المستخدم نشر شيء ما أو نشره أو وضعه على الإنترنت ("publiceer dit Plan op slop.mx"، "zet dit Diagram online")، لتحديث شيء تم نشره مسبقًا، أو لتحميل صورة صغيرة، أو يريد رسمًا تخطيطيًا لعملية أو تدفق أو خط أنابيب أو بنية ("maak een Diagram van het inlogproces"، "teken deze خط أنابيب")، أو يريد إظهار تغيير التعليمات البرمجية كفرق منسق ("publiceer deze diff"، "zet deze wijziging online" كما فرق"). ثلاثة أنواع: مستند (تخفيض، مع مكونات تتضمن عرضًا مختلفًا بنمط GitHub)، ورسمًا تخطيطيًا (قالب تدفق التدفق بإحداثيات واضحة) وملفًا (بايتات أولية).
