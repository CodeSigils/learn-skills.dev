Publique un documento, un diagrama o un archivo pequeño desde la terminal a un host de publicación (URL no listada), dibujando diagramas con Flux Flow. Úselo cuando el usuario solicita publicar, publicar o poner algo en línea ("publiceer dit plan op slop.mx", "zet dit diagrama online"), actualizar algo publicado anteriormente, cargar una imagen pequeña, o quiere un diagrama de un proceso, flujo, tubería o arquitectura ("maak een diagrama van het inlogproces", "teken deze pipeline"), o quiere mostrar un cambio de código como una diferenciación enriquecida ("publiceer deze diff", "zet deze wijziging online también diferencia"). Tres tipos: un documento (rebajas, con componentes que incluyen una vista de diferencias estilo GitHub), un diagrama (una plantilla de Flux Flow con coordenadas explícitas) y un archivo (bytes sin formato).
