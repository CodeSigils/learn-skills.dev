Veröffentlichen Sie ein Dokument, ein Diagramm oder eine kleine Datei vom Terminal aus auf einem Veröffentlichungshost (nicht aufgeführte URL) und zeichnen Sie Diagramme mit Flux Flow. Verwenden Sie diese Option, wenn der Benutzer etwas veröffentlichen, posten oder online stellen möchte („publiceer dit plan op slop.mx“, „zet dit chart online“), etwas früher Veröffentlichtes aktualisieren möchte, ein kleines Bild hochladen möchte oder ein Diagramm eines Prozesses, Ablaufs, einer Pipeline oder einer Architektur möchte („maak een Diagramm van het inlogproces“, „teken dezepipeline“) oder eine Codeänderung als Rich Diff anzeigen möchte („publiceer deze diff“, „zet deze wijziging online as“) diff"). Drei Arten: ein Dokument (Markdown, mit Komponenten, einschließlich einer Diff-Ansicht im GitHub-Stil), ein Diagramm (eine Flux Flow-Vorlage mit expliziten Koordinaten) und eine Datei (Rohbytes).
