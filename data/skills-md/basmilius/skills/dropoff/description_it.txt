Pubblica un documento, un diagramma, uno snippet di codice, una tabella, un diff o un piccolo file dal terminale, che risponde con un URL non elencato. Da utilizzare quando l'utente chiede di pubblicare, postare o mettere qualcosa online ("publiceer dit plan op dropoff.sh", "zet dit diagram online"), per aggiornare qualcosa pubblicato in precedenza, per caricare una piccola immagine, per mostrare una modifica al codice come rich diff ("publiceer deze diff") o desidera un diagramma di un processo, flusso, pipeline o architettura ("maak een diagram van het inlogproces", "teken deze pipeline").
