Publique un documento, un diagrama, un fragmento de código, una tabla, un diff o un archivo pequeño desde la terminal, que responde con una URL no listada. Úselo cuando el usuario solicita publicar, publicar o poner algo en línea ("publiceer dit plan op dropoff.sh", "zet dit diagrama online"), actualizar algo publicado anteriormente, cargar una imagen pequeña, mostrar un cambio de código como una diferenciación enriquecida ("publiceer deze diff"), o quiere un diagrama de un proceso, flujo, canalización o arquitectura ("maak een diagrama van het inlogproces", "teken deze pipeline").
