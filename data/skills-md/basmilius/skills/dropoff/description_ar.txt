انشر مستندًا أو رسمًا تخطيطيًا أو مقتطف تعليمات برمجية أو جدولًا أو فرقًا أو ملفًا صغيرًا من الوحدة الطرفية، والذي يجيب باستخدام عنوان URL غير مدرج. يُستخدم عندما يطلب المستخدم نشر شيء ما أو نشره أو وضعه على الإنترنت ("publiceer dit Plan op dropoff.sh"، "zet dit Diagram online")، لتحديث شيء تم نشره مسبقًا، أو تحميل صورة صغيرة، أو إظهار تغيير التعليمات البرمجية كفرق منسق ("publiceer deze diff")، أو يريد رسمًا تخطيطيًا لعملية أو تدفق أو خط أنابيب أو بنية ("maak een Diagram van het inlogproces"، "teken deze Pipeline").
