Помогите увольняющимся сотрудникам организовать свои беспорядочные рабочие материалы в структурированный пакет передачи, включающий настраиваемые правила классификации, адаптированную для отрасли систему классификации документов, портал визуальной передачи в формате HTML и выходные данные в формате ZIP, которые можно упаковать для доставки. Подходит для ситуаций, когда необходимо помочь увольняющимся сотрудникам сортировать разрозненные рабочие материалы, создавать каталог передачи, создавать визуальную страницу входа и организовывать содержимое передачи, соответствующее характеристикам должности.
