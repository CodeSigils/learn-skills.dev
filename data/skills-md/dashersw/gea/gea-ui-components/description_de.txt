Leitfaden zur Verwendung von @geajs/ui – einer Komponentenbibliothek im Tailwind-Stil mit Zag.js-Unterstützung für das Gea-Framework. Wird beim Erstellen von Benutzeroberflächen mit @geajs/ui-Komponenten wie Button, Select, Dialog, Tabs, Toast oder einer anderen vorgefertigten Komponente aus der Bibliothek verwendet.
