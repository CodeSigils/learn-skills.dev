Réconciliez les tâches planifiées de tâches XXL entre le code source et la console d'un environnement cible. Utilisez-le lorsque quelqu'un souhaite vérifier quels gestionnaires de tâches xxl codés (@JobHandler / @XxlJob) sont réellement planifiés dans un environnement (dev/test/prd), rechercher des gestionnaires de code mais non configurés ou de console mais non codés, ou repérer les incohérences de nom de gestionnaire entre le code et la console.
