Configurez et utilisez Alibaba Cloud CLI pour appeler Yunxiao (云效 / Apsara Devops) OpenAPI. Utilisez-le chaque fois que quelqu'un souhaite installer, configurer des informations d'identification ou exécuter des commandes sur Yunxiao/云效 — la plate-forme Aliyun DevOps couvrant Codeup (dépôts), Flow (pipelines), Projex (projets/éléments de travail), AppStack (applications), etc. — via la CLI `aliyun devops`. Déclenchez des expressions telles que "云效 CLI", "yunxiao", "aliyun devops", "配置云效", "流水线 CLI", "Codeup CLI" ou toute mention des variables d'environnement ALIBABA_CLOUD_YUNXIAO_*, même si l'utilisateur ne dit pas "compétence". Ne l'utilisez PAS pour la configuration générale AK/SK d'Alibaba Cloud (ECS/OSS/RDS) — qui utilise les profils « aliyun configure », que Yunxiao n'utilise PAS explicitement.
