Настройте и используйте Alibaba Cloud CLI для вызова Yunxiao (云效 / Apsara Devops) OpenAPI. Используйте это всякий раз, когда кто-то хочет установить, настроить учетные данные или выполнить команды для Yunxiao/云效 — платформы Aliyun DevOps, охватывающей Codeup (репозитории), Flow (конвейеры), Projex (проекты/рабочие элементы), AppStack (приложения) и т. д. — через CLI `aliyun devops`. Запуск по таким фразам, как «云效 CLI», «yunxiao», «aliyun devops», «配置云效», «流水线 CLI», «Codeup CLI» или любому упоминанию переменных среды ALIBABA_CLOUD_YUNXIAO_*, даже если пользователь не говорит «навык». НЕ используйте это для общей конфигурации Alibaba Cloud (ECS/OSS/RDS) AK/SK — которая использует профили `aliyun configure`, которые Yunxiao явно НЕ использует.
