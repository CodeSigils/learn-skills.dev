Alibaba Cloud CLI を設定して使用し、Yunxiao (云效 / Apsara Devops) OpenAPI を呼び出します。 「aliyun devops」CLI を介して、Codeup (リポジトリ)、Flow (パイプライン)、Projex (プロジェクト/ワークアイテム)、AppStack (アプリ) などをカバーする Aliyun DevOps プラットフォームである Yunxiao/云效 をインストール、認証情報の設定、またはコマンドの実行を行う場合は、これを使用します。ユーザーが「スキル」と言わなくても、「云效 CLI」、「yunxiao」、「aliyun devops」、「配置云效」、「流水線 CLI」、「Codeup CLI」などのフレーズ、または ALIBABA_CLOUD_YUNXIAO_* 環境変数への言及でトリガーされます。これは、一般的な Alibaba Cloud (ECS/OSS/RDS) AK/SK 構成には使用しないでください。これは、Yunxiao が明示的に使用しない「aliyun configure」プロファイルを使用します。
