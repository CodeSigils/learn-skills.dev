Configure y utilice la CLI de Alibaba Cloud para llamar a Yunxiao (云效 / Apsara Devops) OpenAPI. Úselo siempre que alguien quiera instalar, configurar credenciales o ejecutar comandos contra Yunxiao/云效, la plataforma Aliyun DevOps que cubre Codeup (repositorios), Flow (canalizaciones), Projex (proyectos/elementos de trabajo), AppStack (aplicaciones), etc., a través de la CLI `aliyun devops`. Active frases como "云效 CLI", "yunxiao", "aliyun devops", "配置云效", "流水线 CLI", "Codeup CLI", o cualquier mención de las variables de entorno ALIBABA_CLOUD_YUNXIAO_*, incluso si el usuario no dice "skill". NO use esto para la configuración general de AK/SK de Alibaba Cloud (ECS/OSS/RDS), que usa perfiles `aliyun configure`, que Yunxiao NO usa explícitamente.
