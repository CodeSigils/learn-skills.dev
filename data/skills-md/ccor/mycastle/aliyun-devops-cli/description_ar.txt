قم بإعداد واستخدام Alibaba Cloud CLI للاتصال بـ Yunxiao (云效 / Apsara Devops) OpenAPI. استخدم هذا عندما يريد شخص ما تثبيت أو تكوين بيانات الاعتماد أو تشغيل الأوامر ضد Yunxiao/云效 - منصة Aliyun DevOps التي تغطي Codeup (repos)، وFlow (خطوط الأنابيب)، وProjex (المشاريع/عناصر العمل)، وAppStack (التطبيقات)، وما إلى ذلك - عبر واجهة سطر الأوامر "aliyun devops". قم بتشغيل عبارات مثل "云效 CLI"، أو "yunxiao"، أو "aliyun devops"، أو "配置云效"، أو "流水线 CLI"، أو "Codeup CLI"، أو أي ذكر لمتغيرات البيئة ALIBABA_CLOUD_YUNXIAO_*، حتى لو لم يقل المستخدم "مهارة". لا تستخدم هذا لتكوين AK/SK العام لـ Alibaba Cloud (ECS/OSS/RDS) - الذي يستخدم ملفات تعريف "aliyunconfig"، والتي لا يستخدمها Yunxiao بشكل صريح.
