Получите и проанализируйте данные о состоянии здоровья WHOOP с терминала. Используйте, когда пользователь упоминает WHOOP, показатель восстановления, ВСР, вариабельность сердечного ритма, качество сна, нагрузку, данные о тренировках, показатели здоровья или хочет проверить свой ежедневный снимок состояния здоровья. Выводит структурированный JSON при передаче по конвейеру — идеально подходит для рабочих процессов агентов.
