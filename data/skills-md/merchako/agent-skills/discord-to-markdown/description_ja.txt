Discord メッセージのコピー (クリップボードから) を、LLM を使用せずに、確定的にクリーンな Markdown に変換します。 Discord は、作成者グループ、投稿者自身の箇条書き/番号リスト、リンク、コード、絵文字、および画像添付ファイルを保存するクリップボードに豊富な HTML フレーバーを置きます。単純な HTML から Markdown へのコンバーターは、Discord のメッセージ リスト (<ol>) を番号付きリストに変換し、実際のリストを上書きします。このスキルはその HTML を正しく解析します。ユーザーが「この Discord のコピーをマークダウンに変換する」、「Discord をマークダウンに」、「/discord-md」、「この Discord スレッドを Obsidian に貼り付ける」、「この Discord ペーストを LLM 用にクリーンアップする」と言う場合、または Discord からメッセージをコピーし、読み取り可能な Markdown が必要な場合に使用します。 macOS のみ (osascript/pbpaste 経由でクリップボードを読み取ります)。
