Convertissez une copie d'un message Discord (à partir du presse-papiers) en Markdown propre, de manière déterministe et sans LLM. Discord met une riche saveur HTML dans le presse-papiers qui préserve les groupes d'auteurs, les propres listes de puces/numéros de l'affiche, les liens, le code, les emoji et les images jointes ; un convertisseur HTML vers Markdown naïf transforme la liste de messages de Discord (un <ol>) en une liste numérotée et écrase les vraies listes. Cette compétence analyse correctement ce code HTML. À utiliser lorsque l'utilisateur dit "convertir cette copie Discord en markdown", "discord en markdown", "/discord-md", "coller ce fil Discord dans Obsidian", "nettoyer cette pâte Discord pour un LLM", ou copie les messages de Discord et souhaite que le Markdown soit lisible. macOS uniquement (lit le presse-papiers via osascript/pbpaste).
