Конвертируйте копию сообщения Discord (из буфера обмена) в чистый Markdown, детерминированно и без LLM. Discord помещает в буфер обмена богатую HTML-версию, в которой сохраняются группы авторов, собственные маркированные/нумерованные списки автора, ссылки, код, смайлы и вложения изображений; наивный преобразователь HTML в Markdown превращает список сообщений Discord (<ol>) в нумерованный список и уничтожает настоящие списки. Этот навык правильно анализирует HTML. Используйте, когда пользователь говорит «конвертировать эту копию Discord в уценку», «discord в уценку», «/discord-md», «вставить эту ветку Discord в Obsidian», «очистить эту вставку Discord для LLM» или копирует сообщения из Discord и хочет, чтобы уценка была читаемой. Только для macOS (читает буфер обмена через osascript/pbpaste).
