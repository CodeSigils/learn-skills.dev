클립보드의 Discord 메시지 사본을 LLM 없이 결정론적으로 깨끗한 마크다운으로 변환합니다. Discord는 작성자 그룹, 포스터 자체의 글머리 기호/번호 목록, 링크, 코드, 이모티콘 및 이미지 첨부 파일을 보존하는 풍부한 HTML 기능을 클립보드에 추가합니다. 순진한 HTML-to-Markdown 변환기는 Discord의 메시지 목록(<ol>)을 번호가 매겨진 목록으로 바꾸고 실제 목록을 훼손합니다. 이 기술은 해당 HTML을 올바르게 구문 분석합니다. 사용자가 "이 Discord 복사본을 마크다운으로 변환", "discord를 마크다운으로 변환", "/discord-md", "이 Discord 스레드를 Obsidian에 붙여넣기", "LLM용 Discord 붙여넣기 정리"라고 말하거나 Discord에서 메시지를 복사하고 읽을 수 있는 Markdown을 원할 때 사용하세요. macOS에만 해당(osascript/pbpaste를 통해 클립보드 읽기).
