Convierta una copia de un mensaje de Discord (desde el portapapeles) en Markdown limpio, de forma determinista y sin un LLM. Discord pone un rico sabor HTML en el portapapeles que conserva los grupos de autores, las listas de viñetas/números del cartel, enlaces, códigos, emoji e imágenes adjuntas; un ingenuo conversor de HTML a Markdown convierte la lista de mensajes de Discord (un <ol>) en una lista numerada y golpea las listas reales. Esta habilidad analiza ese HTML correctamente. Úselo cuando el usuario diga "convierta esta copia de Discord en Markdown", "discord en Markdown", "/discord-md", "pegue este hilo de Discord en Obsidian", "limpie este pegado de Discord para un LLM" o copie mensajes de Discord y quiera un Markdown legible. Solo macOS (lee el portapapeles mediante osascript/pbpaste).
