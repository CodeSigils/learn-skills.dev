قم بتحويل نسخة رسالة Discord (من الحافظة) إلى Markdown نظيف، بشكل حتمي وبدون LLM. يضع Discord نكهة HTML غنية في الحافظة التي تحافظ على مجموعات المؤلفين وقوائم التعداد النقطي/الأرقام الخاصة بالملصق والروابط والتعليمات البرمجية والرموز التعبيرية ومرفقات الصور؛ يقوم محول HTML-to-Markdown الساذج بتحويل قائمة رسائل Discord (<ol>) إلى قائمة مرقمة ويضرب القوائم الحقيقية. تقوم هذه المهارة بتوزيع لغة HTML بشكل صحيح. يُستخدم عندما يقول المستخدم "تحويل نسخة Discord هذه إلى تخفيض السعر"، أو "discord إلى تخفيض السعر"، أو "/discord-md"، أو "لصق مؤشر ترابط Discord هذا في Obsidian"، أو "تنظيف لصق Discord هذا للحصول على LLM"، أو نسخ الرسائل من Discord ويريد تخفيضًا قابلاً للقراءة. نظام التشغيل macOS فقط (يقرأ الحافظة عبر osascript/pbpaste).
