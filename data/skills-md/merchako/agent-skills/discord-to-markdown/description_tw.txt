將 Discord 訊息副本（從剪貼簿）轉換為乾淨的 Markdown，確定性且無需法學碩士。 Discord 在剪貼簿上增加了豐富的 HTML 風格，保留了作者群組、發布者自己的項目符號/編號清單、連結、程式碼、表情符號和圖片附件；一個簡單的 HTML 到 Markdown 轉換器將 Discord 的訊息清單（<ol>）轉換為編號清單並破壞真實清單。此技能可以正確解析 HTML。當使用者說「將此 Discord 副本轉換為 markdown」、「discord 為 markdown」、「/discord-md」、「將此 Discord 執行緒貼上到 Obsidian」、「清理此 Discord 貼上以獲得 LLM」或從 Discord 複製訊息並想要可讀的 Markdown 時使用。僅限 macOS（透過 osascript/pbpaste 讀取剪貼簿）。
