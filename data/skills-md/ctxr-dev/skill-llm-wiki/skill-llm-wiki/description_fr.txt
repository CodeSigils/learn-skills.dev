À utiliser lorsque l'utilisateur demande explicitement de créer, d'étendre, de valider, de réparer, de reconstruire ou de fusionner un wiki de connaissances optimisé pour LLM à partir de notes de démarque, de documentation, de code source ou de dossiers mixtes. La sortie par défaut est un seul frère stable `<source>.wiki/` avec un historique complet dans un dépôt git privé sous `.llmwiki/git/` ; `--layout-mode in-place` transforme le dossier source lui-même, et `--layout-mode hébergé --target <path>` honore un contrat `.llmwiki.layout.yaml` fourni par l'utilisateur. SKILL.md est le point d’entrée ; des instructions de fonctionnement détaillées sont chargées sur demande à partir de « guide/ » selon la procédure de routage ci-dessous.
