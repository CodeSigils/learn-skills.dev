Используйте, когда пользователь явно просит создать, расширить, проверить, исправить, перестроить или объединить вики-сайт знаний, оптимизированный для LLM, из заметок с уценкой, документации, исходного кода или смешанных папок. Вывод по умолчанию — это один стабильный родственный файл `<source>.wiki/` с полной историей в частном репозитории git под `.llmwiki/git/`; `--layout-mode in-place` преобразует саму исходную папку, а `--layout-mode Hosted --target <path>` учитывает предоставленный пользователем контракт `.llmwiki.layout.yaml`. SKILL.md — это точка входа; подробные инструкции по эксплуатации загружаются по запросу из `guide/` в соответствии с процедурой маршрутизации, приведенной ниже.
