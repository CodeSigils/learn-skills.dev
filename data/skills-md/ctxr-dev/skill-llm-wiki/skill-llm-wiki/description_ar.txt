يُستخدم عندما يطلب المستخدم صراحة إنشاء موقع wiki للمعرفة المحسنة لـ LLM أو توسيعه أو التحقق من صحته أو إصلاحه أو إعادة بنائه أو دمجه من ملاحظات تخفيض السعر أو الوثائق أو التعليمات البرمجية المصدر أو المجلدات المختلطة. الإخراج الافتراضي هو شقيق واحد مستقر `<source>.wiki/` مع سجل كامل في git repo خاص ضمن `.llmwiki/git/`؛ يقوم `--layout-mode in-place` بتحويل المجلد المصدر نفسه، ويحترم `--layout-mode host --target <path>` العقد المقدم من المستخدم `.llmwiki.layout.yaml`. SKILL.md هي نقطة الدخول؛ يتم تحميل تعليمات التشغيل التفصيلية عند الطلب من "الدليل/" وفقًا لإجراءات التوجيه أدناه.
