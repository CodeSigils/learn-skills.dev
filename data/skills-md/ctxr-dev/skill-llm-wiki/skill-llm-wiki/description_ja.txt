ユーザーがマークダウン ノート、ドキュメント、ソース コード、または混合フォルダーから LLM に最適化されたナレッジ Wiki を構築、拡張、検証、修復、再構築、またはマージすることを明示的に要求する場合に使用します。デフォルトの出力は、`.llmwiki/git/` の下のプライベート git リポジトリにある完全な履歴を含む単一の安定した兄弟 `<source>.wiki/` です。 「--layout-mode in-place」はソース フォルダー自体を変換し、「--layout-mode hosted --target <path>」はユーザー指定の「.llmwiki.layout.yaml」コントラクトを尊重します。 SKILL.md はエントリ ポイントです。詳細な操作命令は、以下のルーティング手順に従って「guide/」からオンデマンドでロードされます。
