Úselo cuando el usuario solicite explícitamente crear, ampliar, validar, reparar, reconstruir o fusionar una wiki de conocimiento optimizada para LLM a partir de notas de rebajas, documentación, código fuente o carpetas mixtas. La salida predeterminada es un único hermano estable `<fuente>.wiki/` con el historial completo en un repositorio privado de git en `.llmwiki/git/`; `--layout-mode in-place` transforma la carpeta de origen en sí, y `--layout-mode hosting --target <path>` respeta un contrato `.llmwiki.layout.yaml` proporcionado por el usuario. SKILL.md es el punto de entrada; Las instrucciones de operación detalladas se cargan a pedido desde `guide/` según el procedimiento de enrutamiento a continuación.
