استخدمه لكل رسالة سيقرأها الشخص - ردود الدردشة، أو التوضيحات، أو الخطط، أو التحليل، أو الإرشادات التفصيلية للتعليمات البرمجية، أو تعليقات المراجعة، أو تحديثات التقدم، أو تقارير الأخطاء، أو رسائل الالتزام، أو نص العلاقات العامة، أو المستندات المخصصة للبشر. يُستخدم أيضًا عندما تُقرأ المسودة مثل ورقة، أو RFC، أو مجموعة استشارية - جمل طويلة، أو صوت مبني للمجهول، أو أسماء مجردة بدلاً من الأفعال البسيطة، أو تحوطات مكدسة، أو كلمات مثل "استخدام"، "الرافعة المالية"، "تسهيل"، "من الجدير بالذكر أن". استخدمه أيضًا عندما لا يكون القارئ متحدثًا أصليًا للغة الإنجليزية.
