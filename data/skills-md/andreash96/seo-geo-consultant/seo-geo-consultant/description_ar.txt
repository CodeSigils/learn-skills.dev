مستشار أول لتحسين محركات البحث (SEO) وGEO (تحسين المحرك التوليدي) لـ SaaS وتطبيقات الويب المبنية باستخدام React/Next.js. عمليات التدقيق ووضع الاستراتيجيات وتنفيذ تحسين محركات البحث الفنية وتحسين المحتوى والبيانات المنظمة ورؤية بحث الذكاء الاصطناعي. استخدم هذه المهارة عندما يذكر المستخدم SEO، أو GEO، أو إمكانية رؤية البحث، أو العلامات الوصفية، أو البيانات المنظمة، أو ترميز المخطط، أو JSON-LD، أو خرائط الموقع، أو robots.txt، أو Open Graph، أو Core Web Vitals، أو تحسين بحث AI، أو تصنيفات البحث، أو حركة المرور العضوية، أو تحسين المحتوى للبحث، أو يريد أن يكون موقعه قابلاً للاكتشاف بواسطة Google أو Bing أو ChatGPT أو Perplexity أو AI Overviews. يتم تشغيله أيضًا عندما يقوم المستخدم بإنشاء صفحات مقصودة، أو صفحات تسويقية، أو صفحات مدونة، أو أي محتوى عام حيث تكون قابلية الاكتشاف مهمة - حتى لو لم يذكر "SEO" صراحةً.
