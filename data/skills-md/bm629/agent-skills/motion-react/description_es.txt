Úselo cuando agregue animación a una aplicación React con la biblioteca Motion (el sucesor de framer-motion: paquete npm `motion`, importe `motion/react`): animaciones de entrada/salida, variantes y escalonamiento, AnimatePresence, diseño y transiciones de elementos compartidos, tickers numéricos animados, estados de gestos, o cuando decida si un trabajo necesita Motion en lugar de transiciones CSS/Tailwind simples o AutoAnimate. Cubre la accesibilidad de movimiento reducido (MotionConfig, useReducedMotion, WCAG 2.3.3/2.2.2) como requisito de primera clase, disciplina de rendimiento (solo transformación/opacidad), restricción de movimiento para la interfaz de usuario del producto con gran densidad de datos, integración de Radix/shadcn y enrutador, y mantenimiento de pruebas estables (MotionGlobalConfig.skipAnimations). Palabras clave: movimiento, movimiento del encuadre, animación, AnimatePresence, animación de diseño, microinteracciones, movimiento reducido, transiciones de página, escalonamiento, resorte.
