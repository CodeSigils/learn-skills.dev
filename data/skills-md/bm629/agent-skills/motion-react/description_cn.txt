使用 Motion 库（framer-motion 后继者：npm 包 `motion`、导入 `motion/react`）向 React 应用添加动画时使用 - 进入/退出动画、变体和交错、AnimatePresence、布局和共享元素过渡、动画数字指示器、手势状态 - 或者在确定作业是否需要 Motion 与普通 CSS/Tailwind 过渡或 AutoAnimate 时使用。涵盖作为一流要求的简化运动可访问性（MotionConfig、useReducedMotion、WCAG 2.3.3/2.2.2）、性能规则（仅限变换/不透明度）、数据密集产品 UI 的运动限制、Radix/shadcn 和路由器集成，以及保持测试稳定（MotionGlobalConfig.skipAnimations）。关键词：运动、成帧器运动、动画、AnimatePresence、布局动画、微交互、简化运动、页面过渡、交错、弹簧。
