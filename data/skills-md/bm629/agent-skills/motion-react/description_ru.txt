Используйте при добавлении анимации в приложение React с библиотекой Motion (преемник Framer-Motion: пакет npm `motion`, import `motion/react`) — анимации входа и выхода, варианты и шатание, AnimatePresence, переходы макета и общих элементов, анимированные нумерованные бегущие строки, состояния жестов — или при принятии решения о том, нужно ли заданию Motion вообще по сравнению с простыми переходами CSS/Tailwind или AutoAnimate. Охватывает доступность с ограниченным движением (MotionConfig, useReducedMotion, WCAG 2.3.3/2.2.2) как первоклассное требование, дисциплину производительности (только преобразование/непрозрачность), ограничение движения для пользовательского интерфейса продукта с большим объемом данных, интеграцию Radix/shadcn и маршрутизатора, а также поддержание стабильности тестов (MotionGlobalConfig.skipAnimations). Ключевые слова: движение, Framer-motion, анимация, AnimatePresence, анимация макета, микровзаимодействия, уменьшенное движение, переходы страниц, шатание, пружина.
