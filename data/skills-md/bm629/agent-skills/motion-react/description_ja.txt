Motion ライブラリ (フレーマー モーションの後継: npm package `motion`、import `motion/react`) を使用して React アプリにアニメーションを追加するとき、アニメーションの開始/終了、バリアントとスタッガー、AnimatePresence、レイアウトと共有要素のトランジション、アニメーション化された番号ティッカー、ジェスチャーの状態、またはジョブに Motion が必要か、プレーンな CSS/Tailwind トランジションや AutoAnimate かを判断するときに使用します。第一級の要件としてのモーション削減アクセシビリティ (MotionConfig、useReducedMotion、WCAG 2.3.3/2.2.2)、パフォーマンス規律 (変換/不透明度のみ)、データ密度の高い製品 UI のモーション制限、基数/shadcn とルーターの統合、テストの安定性の維持 (MotionGlobalConfig.skipAnimations) をカバーします。キーワード: モーション、フレーマー モーション、アニメーション、AnimatePresence、レイアウト アニメーション、マイクロ インタラクション、モーションの削減、ページ遷移、千鳥、スプリング。
