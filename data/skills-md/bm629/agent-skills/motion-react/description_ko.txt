Motion 라이브러리(프레이머 모션 후속: npm 패키지 `motion`, import `motion/react`)를 사용하여 React 앱에 애니메이션을 추가할 때(애니메이션 시작/종료, 변형 및 스태거, AnimatePresence, 레이아웃 및 공유 요소 전환, 애니메이션 숫자 티커, 동작 상태) 또는 일반 CSS/Tailwind 전환 또는 AutoAnimate와 비교하여 작업에 Motion이 필요한지 여부를 결정할 때 사용합니다. 최고 수준의 요구 사항인 모션 감소 접근성(MotionConfig, useReducedMotion, WCAG 2.3.3/2.2.2), 성능 규율(변환/불투명도만 해당), 데이터 밀도가 높은 제품 UI를 위한 모션 제한, Radix/shadcn 및 라우터 통합, 테스트 안정성 유지(MotionGlobalConfig.skipAnimations)를 다루고 있습니다. 키워드: 모션, 프레이머 모션, 애니메이션, AnimatePresence, 레이아웃 애니메이션, 마이크로 인터랙션, 모션 감소, 페이지 전환, 스태거, 스프링.
