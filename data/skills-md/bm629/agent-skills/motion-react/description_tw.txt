使用 Motion 函式庫（framer-motion 後繼者：npm 套件 `motion`、匯入 `motion/react`）為 React 應用程式新增動畫時使用 - 進入/退出動畫、變體和交錯、AnimatePresence、佈局和共享元素過渡、動畫數字指示器、手勢狀態 - 或在確定 CSS/Amated 與普通作業是否需要 Moail 過渡時或普通作業是否需要在普通作業時。涵蓋作為一流要求的簡化運動可訪問性（MotionConfig、useReducedMotion、WCAG 2.3.3/2.2.2）、性能規則（僅限變換/不透明度）、數據密集產品 UI 的運動限制、Radix/shadcn 和路由器集成，以及保持測試穩定（MotionGlobalConfig.skipAnimations）。關鍵字：運動、成幀器運動、動畫、AnimatePresence、佈局動畫、微互動、簡化運動、頁面轉換、交錯、彈簧。
