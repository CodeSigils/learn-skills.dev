Используйте при разработке спецификации функции (функциональной спецификации) — детализация функций, именуемых PRD, в реализуемые и тестируемые детали. Помогает производителю использовать МЕТОД, а не схему: отслеживание каждой функции до цели PRD, определение наблюдаемого поведения и взаимодействий, перечисление входов/выходов + состояний, охват крайних случаев и обработка ошибок с их ожидаемой обработкой и написание проверяемых критериев приемки «Дано/Когда/Тогда» — до панели, где инженер может построить каждую функцию, а тестировщик может проверить ее, не спрашивая автора. Состоит из отдельного инструмента шаблонов спецификаций функций (который обеспечивает структуру разделов) и возможностей глубокого исследования (для обоснования каждой функции в PRD и домене). Предполагается, что утвержденный PRD является входными данными, а не пустой страницей. Не для создания самого PRD, не для проверки готовой спецификации функций и не для документации по инженерному проектированию (ADR/RFC).
