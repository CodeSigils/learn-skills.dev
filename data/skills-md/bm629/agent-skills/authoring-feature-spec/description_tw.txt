在編寫功能規格（功能規格）時使用 - 將 PRD 命名的功能細化為可實現、可測試的細節。指導生產者完成方法，而不是大綱：將每個功能追溯到 PRD 目標，指定可觀察的行為和交互，枚舉輸入/輸出 + 狀態，用預期的處理方式覆蓋邊緣情況和錯誤處理，並編寫可測試的給定/何時/然後驗收標準 - 到一個欄，工程師可以在其中構建每個功能，測試人員可以在不詢問作者的情況下進行驗證。由單獨的功能規格模板工具（提供部分結構）和深入研究功能（為 PRD 和領域中的每個功能奠定基礎）組成。假設已核准的 PRD 作為上游輸入－絕不是空白頁。不適用於創作 PRD 本身，不適用於審查完成的功能規範，也不適用於工程設計文件 (ADR/RFC)。
