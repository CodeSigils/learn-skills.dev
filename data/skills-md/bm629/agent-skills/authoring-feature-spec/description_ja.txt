機能仕様 (機能仕様) を作成するときに使用します。PRD で指定された機能を実装可能でテスト可能な詳細に詳しく説明します。概要ではなくメソッドを通してプロデューサーをガイドします。各機能を PRD の目標まで追跡し、観察可能な動作と相互作用を指定し、入力/出力 + 状態を列挙し、エッジ ケースとエラー処理を期待される処理でカバーし、テスト可能な Given/When/Then 受け入れ基準を記述します。エンジニアが各機能を構築し、テスターが作成者に問い合わせることなくそれを検証できるバーまで表示されます。個別の機能仕様テンプレート ツール (セクション構造を提供) と詳細な調査機能 (PRD およびドメイン内の各機能を基礎付ける) で構成されます。承認された PRD が上流入力として想定されます。決して空白ページではありません。 PRD 自体を作成するためではなく、完成した機能仕様をレビューするためでも、エンジニアリング設計ドキュメント (ADR/RFC) のためでもありません。
