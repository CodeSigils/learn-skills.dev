Vitest에서 Vite + React + TypeScript SPA를 위한 RTL + MSW + vitest-axe 구성 요소 테스트 레이어입니다. 실제 구성 요소 트리를 렌더링하는 구성 요소 테스트를 작성하거나 설정할 때 사용하고, 사용자처럼 구동하고(React 테스트 라이브러리 + 사용자 이벤트), 네트워크 경계를 모의하고(모의 서비스 작업자 v2 - 모듈 아님), 렌더링된 출력에 액세스할 수 있는지 확인합니다(vitest-axe toHaveNoViolations). jsdom 테스트 환경(axe를 손상시키는 명시적으로 happy-dom이 아님), 액세스 가능 쿼리 우선순위, 항상 대기 user-event v14 규칙, async findBy/waitFor, MSW setupServer 수명 주기, 가져오기 계층에서 생성된 @hey-api/openapi-ts 클라이언트 가로채기, retry:false 및 form + request-body + a11y 어설션을 사용하는 테스트별 TanStack 쿼리 QueryClientProvider를 다룹니다. 테스트 피라미드의 중간: Vitest 단위 테스트 위, Playwright e2e 아래.
