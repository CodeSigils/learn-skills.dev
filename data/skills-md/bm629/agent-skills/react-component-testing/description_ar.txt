RTL + MSW + طبقة اختبار مكون vitest-axe لـ Vite + React + TypeScript SPA ضمن Vitest. يُستخدم عند كتابة أو إعداد اختبارات المكونات التي تعرض شجرة مكونات حقيقية، وتدفعها كما يفعل المستخدم (مكتبة اختبار React + حدث المستخدم)، وتسخر من حدود NETWORK (Mock Service Worker v2 - وليس الوحدة النمطية)، وتؤكد أن المخرجات المقدمة يمكن الوصول إليها (vitest-axe toHaveNoViolations). يغطي بيئة اختبار jsdom (بشكل صريح ليس Happy-dom، الذي يكسر الفأس)، وأولوية استعلام الوصول، وقاعدة v14 لحدث المستخدم الذي ينتظر دائمًا، وasync findBy/waitFor، ودورة حياة MSW setupServer، واعتراض عميل @hey-api/openapi-ts الذي تم إنشاؤه في طبقة الجلب، واستعلام TanStack QueryClientProvider لكل اختبار مع إعادة المحاولة: خطأ، ونموذج + نص الطلب + التأكيدات a11y. منتصف هرم الاختبار: فوق اختبارات وحدة Vitest، أسفل الكاتب المسرحي e2e.
