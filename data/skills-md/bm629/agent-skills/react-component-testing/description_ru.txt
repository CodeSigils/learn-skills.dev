RTL + MSW + слой тестирования компонентов vitest-axe для Vite + React + TypeScript SPA под Vitest. Используйте при написании или настройке тестов компонентов, которые отображают реальное дерево компонентов, управляйте им так, как это делает пользователь (библиотека тестирования React + пользовательское событие), имитируйте границу NETWORK (Mock Service Worker v2 — не модуль) и подтверждайте доступность визуализированного вывода (vitest-axe toHaveNoViolations). Охватывает тестовую среду jsdom (явно не Happy-dom, которая ломает топор), приоритет доступных запросов, правило всегда ожидания пользовательского события v14, асинхронный findBy/waitFor, жизненный цикл MSW setupServer, перехват сгенерированного клиента @hey-api/openapi-ts на уровне выборки, запрос TanStack QueryClientProvider для каждого теста с retry:false и form + request-body + а11у утверждения. Середина пирамиды тестов: выше юнит-тесты Vitest, ниже Playwright e2e.
