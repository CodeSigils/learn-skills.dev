RTL + MSW + livello componente-test vitest-axe per Vite + React + TypeScript SPA sotto Vitest. Da utilizzare durante la scrittura o l'impostazione di test dei componenti che eseguono il rendering di un albero dei componenti reale, guidarlo come fa un utente (React Testing Library + evento utente), deridere il confine della RETE (Mock Service Worker v2 — non il modulo) e affermare che l'output renderizzato è accessibile (vitest-axe toHaveNoViolations). Copre l'ambiente di test jsdom (esplicitamente non happy-dom, che rompe axe), la priorità delle query accessibili, la regola v14 sempre attesa degli eventi utente, findBy/waitFor asincrono, il ciclo di vita di MSW setupServer, l'intercettazione di un client @hey-api/openapi-ts generato al livello di recupero, una query TanStack QueryClientProvider per test con retry:false e il modulo + corpo della richiesta + asserzioni a11y. Il centro della piramide del test: sopra i test unitari di Vitest, sotto Playwright e2e.
