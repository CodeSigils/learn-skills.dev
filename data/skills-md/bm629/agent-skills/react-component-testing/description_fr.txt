Couche de test de composants RTL + MSW + vitest-axe pour un SPA Vite + React + TypeScript sous Vitest. À utiliser lors de l'écriture ou de la configuration de tests de composants qui restituent une véritable arborescence de composants, pilotez-la comme le fait un utilisateur (React Testing Library + événement utilisateur), simulez la limite NETWORK (Mock Service Worker v2 - pas le module) et affirmez que la sortie rendue est accessible (vitest-axe toHaveNoViolations). Couvre l'environnement de test jsdom (explicitement pas happy-dom, qui casse hache), la priorité des requêtes accessibles, la règle d'événement utilisateur toujours en attente v14, async findBy/waitFor, le cycle de vie MSW setupServer, l'interception d'un client @hey-api/openapi-ts généré au niveau de la couche de récupération, un TanStack Query QueryClientProvider par test avec retry:false et form + request-body + a11y affirmations. Le milieu de la pyramide des tests : au-dessus des tests unitaires Vitest, en dessous de Playwright e2e.
