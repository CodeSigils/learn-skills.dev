エンドユーザー製品ガイド (一般に非技術者が製品目標を達成するために読む消費者向けのヘルプ (チュートリアル、ハウツー、説明、製品機能/設定リファレンス、トラブルシューティング、用語集)) をレビュー/判断するときに使用します。実際のユーザーがガイドだけでサポートされているすべての目標を達成できるかどうかを判断します。オーサリングではなくゲートです。単一ソースの 12 条件のユーザビリティ + 精度バーを判断します。目標ごとに 1 つのハウツー。 4 つの Diataxis モードが正しく入力されています (混同されていません)。完全な製品リファレンス (HTTP API ではありません)。正確な UI ラベルによって名前が付けられた正確なステップ。症状に応じたトラブルシューティング。専門知識のない読者でも理解できる平易な言語。アクセシビリティ + 見つけやすさ。表面化した仮定、捏造はありません。デルタスコープの修正。正確に「評決: 承認|改訂」と実用的な結果を出力します。基準を満たすガイドを承認し (誤った改訂はありません)、指定されたギャップのみを改訂します。開発者導入ガイド、エンドポイント カタログ、またはエンジニアリング設計ドキュメント (設計レビュー) を作成するのではありません。
