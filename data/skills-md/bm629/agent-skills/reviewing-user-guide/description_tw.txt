在審查/判斷最終用戶產品指南時使用 - 面向消費者的幫助，通常非技術人員閱讀以實現產品目標（教程、操作方法、解釋、產品功能/設置參考、故障排除、術語表） - 決定真正的用戶是否可以僅通過指南實現每個支持的目標。一扇門，而不是創作。判斷單一來源的 12 條件可用性 + 準確性欄：每個目標一個操作方法；正確鍵入四種 Diataxis 模式（未合併）；完整的產品參考（不是 HTTP API）；準確的步驟由其確切的 UI 標籤命名；以症狀為重點的故障排除；非技術讀者可以理解的簡單語言；可訪問性+可查找性+可查找性的增量；準確發出「VERDICT：批准|修訂」以及可操作的調查結果；批准符合標準的指南（無錯誤修訂），僅針對指定的差距進行修訂。不創作它、開發人員採用指南、端點目錄或工程設計文件（設計審查）。
