Используйте при просмотре/оценке готового документа пользовательских потоков, чтобы решить, может ли последующий этап каркасного проектирования перечислять все его экраны — ворота приемки, а не авторинга. Документ пользовательских потоков — это граф навигации/взаимодействия: пути, которые пользователь выбирает для достижения каждой цели, с точками входа, ветвями принятия решений, путями ошибок/восстановления и пройденными экранами. Оценивает это по шкале полноты + проходимости: каждая цель/персонаж PRD сопоставляется с потоком (без сирот), каждый поток имеет определенный вход и выход, каждая ветвь разрешается, каждое состояние ошибки имеет восстановление (нет тупиков), шаги доступны для прохождения, диаграмма Русалки и пронумерованное повествование остаются синхронизированными, а индекс экранов является перечислимым. Выдает именно «ВЕРДИКТ: утвердить|пересмотреть» с выводами, требующими принятия мер (неудачное условие + исправление). Утверждает документ, соответствующий планке (без ложных изменений), вносит изменения только в случае именованного пробела. Ни для создания документа о пользовательских потоках, ни для макета экрана/каркасов (используйте навыки проверки каркасов), ни для восходящего PRD (используйте навыки проверки PRD).
