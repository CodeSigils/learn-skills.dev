완성된 사용자 흐름 문서를 검토/판단할 때 다운스트림 와이어프레임 패스가 문서의 모든 화면(작성이 아닌 승인 게이트)을 열거할 수 있는지 여부를 결정하는 데 사용합니다. 사용자 흐름 문서는 탐색/상호작용 그래프입니다. 진입점, 결정 분기, 오류/복구 경로 및 화면 통과를 통해 사용자가 각 목표를 달성하기 위해 선택하는 경로입니다. 완전성 + 보행 가능성 기준에 따라 판단합니다. 모든 PRD 목표/페르소나는 흐름에 매핑되고(고아 없음), 모든 흐름에는 정의된 진입 + 출구가 있고, 모든 분기가 해결되고, 모든 오류 상태에는 복구가 있고(막다른 골목 없음), 단계는 보행 가능하고, 인어 다이어그램과 번호가 매겨진 내러티브는 동기화 상태로 유지되며, 화면 인덱스는 열거 가능합니다. 실행 가능한 결과(실패한 조건 + 수정 사항)와 함께 정확하게 'VERDICT: 승인|수정'을 내보냅니다. 기준을 충족하는 문서를 승인하고(허위 수정 없음), 명명된 간격만 수정합니다. 사용자 흐름 문서 작성용이 아니고, 화면 레이아웃/와이어프레임용이 아니며(와이어프레임 검토 기술 사용), 업스트림 PRD용이 아닙니다(PRD 검토 기술 사용).
