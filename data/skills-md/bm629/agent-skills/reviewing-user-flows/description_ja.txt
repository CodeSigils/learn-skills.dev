完成したユーザー フロー ドキュメントをレビュー/判断するときに使用して、下流のワイヤーフレーム パスがそこからすべての画面を列挙できるかどうかを判断します (オーサリングではなく受け入れゲート)。ユーザー フロー ドキュメントは、ナビゲーション/インタラクション グラフです。つまり、エントリー ポイント、意思決定の分岐、エラー/回復パス、および通過する画面を含む、ユーザーが各目標を達成するためにたどるパスです。完全性 + ウォークカビリティ バーに照らして判断します。すべての PRD 目標/ペルソナがフローにマップされ (孤立なし)、すべてのフローに定義された入り口と出口があり、すべての分岐が解決され、すべてのエラー状態に回復機能があり (行き止まりがない)、ステップは歩きやすく、マーメイド ダイアグラムと番号付きのナラティブは同期を保ち、画面インデックスは列挙可能です。実行可能な結果 (失敗した条件 + 修正) を含む正確な「VERDICT: accept|revise」を出力します。基準を満たすドキュメントを承認し (誤った改訂はしない)、指定されたギャップのみを改訂します。ユーザー フロー ドキュメントの作成、画面レイアウト/ワイヤーフレーム (ワイヤーフレーム レビュー スキルを使用)、上流の PRD (PRD レビュー スキルを使用) の場合ではありません。
