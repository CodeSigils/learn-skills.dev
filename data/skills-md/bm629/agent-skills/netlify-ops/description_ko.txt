사이트 생성, 빌드 배포(초안 또는 프로덕션), 사용자 정의 도메인 설정 + 확인, 배포 상태 읽기, 사이트/배포/DNS 나열/검사 등 Netlify 웹 호스팅을 직접 구동할 때 사용합니다. https://api.netlify.com/api/v1(권한 부여: Bearer <token>)에서 Netlify의 공식 OpenAPI에 대한 REST 폴백을 사용하여 `netlify` CLI(NETLIFY_AUTH_TOKEN을 읽고 헤드리스로 실행되며 `netlify login`은 아님)의 CLI 우선입니다. 다이제스트 배포 프로토콜, 속도 제한 및 site_id 규칙을 명시적으로 처리하여 엔드포인트 인덱스 + $ref-resolver를 통해 번들 사양에서 ~174개의 REST 작업을 해결합니다. 호출자가 삽입한 자격 증명(변수 이름으로 확인된 토큰)을 사용합니다. 이를 프로비저닝하거나 확인하지 않습니다. 토큰 값은 CLI/curl 하위 프로세스에 의해서만 읽히고 인쇄되지 않습니다. 전체 스택 컨테이너 앱이 아닌 Netlify 정적/JAMstack + 서버리스 호스팅의 경우.
