À utiliser lors de la gestion directe de l'hébergement Web Netlify : création d'un site, déploiement d'une version (ébauche ou production), définition et vérification d'un domaine personnalisé, lecture de l'état de déploiement et liste/inspection des sites/déploiements/DNS. CLI d'abord sur la CLI `netlify` (qui lit NETLIFY_AUTH_TOKEN et s'exécute sans tête — jamais `netlify login`) avec un repli REST sur l'OpenAPI officielle de Netlify à l'adresse https://api.netlify.com/api/v1 (Autorisation : Bearer <token>). Résout l'une des ~174 opérations REST à partir d'une spécification groupée via un index de point de terminaison + un $ref-resolver, avec le protocole de déploiement de résumé, les limites de débit et les conventions site_id gérées explicitement. Consomme les informations d'identification injectées par l'appelant (un jeton résolu par le nom de la variable) — il ne les fournit ni ne les résout ; la valeur du jeton est lue uniquement par le sous-processus CLI/curl, jamais imprimée. Pour l'hébergement sans serveur Netlify statique/JAMstack +, pas pour les applications de conteneur full-stack.
