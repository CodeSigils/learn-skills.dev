Da utilizzare quando si guida direttamente l'hosting web Netlify: creazione di un sito, distribuzione di una build (bozza o produzione), impostazione e verifica di un dominio personalizzato, lettura dello stato di distribuzione ed elenco/ispezione di siti/distribuzioni/DNS. Prima CLI sulla CLI `netlify` (che legge NETLIFY_AUTH_TOKEN e funziona senza testa, mai `netlify login`) con un fallback REST sull'OpenAPI ufficiale di Netlify all'indirizzo https://api.netlify.com/api/v1 (Autorizzazione: Bearer <token>). Risolve qualsiasi delle ~174 operazioni REST da una specifica in bundle tramite un indice endpoint + un risolutore $ref, con il protocollo di distribuzione digest, i limiti di velocità e le convenzioni site_id gestiti in modo esplicito. Consuma credenziali inserite dal chiamante (un token risolto dal nome della variabile): non le fornisce né le risolve; il valore del token viene letto solo dal sottoprocesso CLI/curl, mai stampato. Per Netlify static/JAMstack + hosting serverless, non per app contenitore full-stack.
