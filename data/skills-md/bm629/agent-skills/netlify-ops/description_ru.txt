Используйте при непосредственном управлении веб-хостингом Netlify — создании сайта, развертывании сборки (черновой или рабочей), настройке + проверке личного домена, чтении статуса развертывания и перечислении/проверке сайтов/развертываний/DNS. Сначала CLI в CLI `netlify` (который читает NETLIFY_AUTH_TOKEN и запускается без головы — никогда не `netlify login`) с резервным вариантом REST на официальном OpenAPI Netlify по адресу https://api.netlify.com/api/v1 (Авторизация: Bearer <token>). Разрешает любую из ~174 операций REST из объединенной спецификации через индекс конечной точки + $ref-resolver, с явной обработкой протокола дайджеста-развертывания, ограничений скорости и соглашений site_id. Потребляет учетные данные, введенные вызывающим абонентом (токен, разрешенный по имени переменной) — он не предоставляет и не разрешает их; значение токена читается только подпроцессом CLI/curl и никогда не печатается. Для статического/JAMstack + бессерверного хостинга Netlify, а не для полнофункциональных контейнерных приложений.
