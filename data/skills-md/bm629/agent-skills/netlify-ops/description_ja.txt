Netlify Web ホスティングを直接操作する場合に使用します。サイトの作成、ビルド (ドラフトまたは実稼働) のデプロイ、カスタム ドメインの設定と検証、デプロイ ステータスの読み取り、サイト/デプロイ/DNS のリスト/検査を行います。 https://api.netlify.com/api/v1 の Netlify の公式 OpenAPI での REST フォールバックを使用して、`netlify` CLI で CLI ファースト (NETLIFY_AUTH_TOKEN を読み取り、ヘッドレスで実行されます。決して `netlify login` ではありません) を使用します (認可: Bearer <token>)。エンドポイント インデックスと $ref リゾルバーを介して、バンドルされた仕様から最大 174 の REST 操作を解決します。ダイジェスト デプロイ プロトコル、レート制限、および site_id 規則は明示的に処理されます。呼び出し元が挿入した資格情報 (変数名によって解決されるトークン) を消費します。資格情報のプロビジョニングや解決は行いません。トークン値は CLI/curl サブプロセスによってのみ読み取られ、出力されることはありません。フルスタックコンテナアプリではなく、Netlify 静的/JAMstack + サーバーレスホスティングの場合。
