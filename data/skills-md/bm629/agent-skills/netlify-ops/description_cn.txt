直接驱动 Netlify Web 托管时使用 - 创建站点、部署构建（草稿或生产）、设置 + 验证自定义域、读取部署状态以及列出/检查站点/部署/DNS。 “netlify” CLI 上的 CLI 优先（读取 NETLIFY_AUTH_TOKEN 并无头运行 — 绝不是“netlify 登录”），并在 Netlify 的官方 OpenAPI（https://api.netlify.com/api/v1）上进行 REST 回退（授权：Bearer <token>）。通过端点索引 + $ref-resolver 解析捆绑规范中约 174 个 REST 操作，并显式处理摘要部署协议、速率限制和 site_id 约定。使用调用者注入的凭据（通过变量名称解析的令牌）——它不提供或解析它们；令牌值只能由 CLI/curl 子进程读取，从不打印。适用于 Netlify 静态/JAMstack + 无服务器托管，而不是全栈容器应用程序。
