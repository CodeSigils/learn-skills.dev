Úselo al gestionar el alojamiento web de Netlify directamente: crear un sitio, implementar una compilación (borrador o producción), configurar y verificar un dominio personalizado, leer el estado de implementación y enumerar/inspeccionar sitios/implementaciones/DNS. CLI primero en la CLI `netlify` (que lee NETLIFY_AUTH_TOKEN y se ejecuta sin cabeza, nunca `netlify login`) con un respaldo REST en la OpenAPI oficial de Netlify en https://api.netlify.com/api/v1 (Autorización: Portador <token>). Resuelve cualquiera de las ~174 operaciones REST de una especificación incluida a través de un índice de punto final + un $ref-resolver, con el protocolo de implementación de resumen, los límites de velocidad y las convenciones de site_id manejadas explícitamente. Consume credenciales inyectadas por la persona que llama (un token resuelto por nombre de variable); no las aprovisiona ni las resuelve; el valor del token solo lo lee el subproceso CLI/curl, nunca se imprime. Para alojamiento Netlify estático/JAMstack + sin servidor, no para aplicaciones de contenedor de pila completa.
