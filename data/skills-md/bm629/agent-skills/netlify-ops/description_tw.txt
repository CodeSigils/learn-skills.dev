直接驅動 Netlify Web 託管時使用 - 建立網站、部署建置（草稿或生產）、設定 + 驗證自訂網域、讀取部署狀態以及列出/檢查網站/部署/DNS。 「netlify」 CLI 上的 CLI 優先（讀取 NETLIFY_AUTH_TOKEN 並無頭運行 — 絕不是「netlify 登入」），並在 Netlify 的官方 OpenAPI（https://api.netlify.com/api/v1）上進行 REST 回退（授權：Bearer <token>）。透過端點索引 + $ref-resolver 解析捆綁規範中約 174 個 REST 操作，並明確處理摘要部署協定、速率限制和 site_id 約定。使用呼叫者註入的憑證（透過變數名稱解析的令牌）－它不提供或解析它們；令牌值只能由 CLI/curl 子程序讀取，從不列印。適用於 Netlify 靜態/JAMstack + 無伺服器託管，而不是全端容器應用程式。
