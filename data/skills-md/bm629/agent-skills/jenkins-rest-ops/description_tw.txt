當直接使用curl（無SDK）驅動Jenkins伺服器的REST（遠端存取）API時使用 - 觸發構建，輪詢建置的佇列項，讀取建置狀態+控制台日誌，列出/檢查作業，作業CRUD（透過config.xml建立專案/複製/刪除/啟用/停用）以及建置管理（停止/刪除）。 Jenkins 是使用 HTTP Basic 使用者名稱：API_TOKEN 進行路徑尋址的 REST 驗證。構建觸發器是異步的——它返回一個隊列項，而不是構建，因此您將queue/item/<id>/api/json輪詢到可執行檔。 API 令牌驗證不受 CSRF crumb 的影響（Jenkins 2.96/2.107+）；麵包屑只是 403 的後備。不存在官方的 Jenkins OpenAPI，因此 CORE 路徑表基於官方遠端存取文件（捆綁的 swaggy-jenkins 規範是非官方的交叉檢查）。使用呼叫者註入的憑證（base_url + 使用者名稱 + 由變數名稱解析的令牌） - 它不會提供或解析它們；令牌值只能由curl 讀取，從不列印。
