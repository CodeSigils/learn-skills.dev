当直接使用curl（无SDK）驱动Jenkins服务器的REST（远程访问）API时使用 - 触发构建，轮询构建的队列项，读取构建状态+控制台日志，列出/检查作业，作业CRUD（通过config.xml创建项目/复制/删除/启用/禁用）以及构建管理（停止/删除）。 Jenkins 是使用 HTTP Basic 用户名：API_TOKEN 进行路径寻址的 REST 身份验证。构建触发器是异步的——它返回一个队列项，而不是构建，因此您将queue/item/<id>/api/json轮询到可执行文件。 API 令牌身份验证不受 CSRF crumb 的影响（Jenkins 2.96/2.107+）；面包屑只是 403 的后备。不存在官方的 Jenkins OpenAPI，因此 CORE 路径表基于官方远程访问文档（捆绑的 swaggy-jenkins 规范是非官方的交叉检查）。使用调用者注入的凭据（base_url + 用户名 + 由变量名称解析的令牌） - 它不会提供或解析它们；令牌值只能由curl 读取，从不打印。
