Jenkins サーバーの REST (リモート アクセス) API をcurl (SDK なし) で直接駆動する場合に使用します。ビルドのトリガー、ビルドへのキュー アイテムのポーリング、ビルド ステータスとコンソール ログの読み取り、ジョブの一覧表示/検査、ジョブ CRUD (config.xml 経由の createItem/copy/delete/enable/disable)、およびビルド管理 (停止/削除) です。 Jenkins は、HTTP Basic ユーザー名:API_TOKEN で認証されたパスアドレス指定された REST です。ビルド トリガーは ASYNC です。ビルドではなくキュー アイテムを返すため、queue/item/<id>/api/json を実行可能ファイルにポーリングします。 API トークン認証は CSRF クラムから除外されます (Jenkins 2.96/2.107+)。クラムは単なる 403 フォールバックです。公式の Jenkins OpenAPI は存在しないため、CORE パス テーブルは公式のリモート アクセス ドキュメントに基づいています (バンドルされている swaggy-jenkins 仕様は非公式のクロスチェックです)。呼び出し元が挿入した資格情報 (base_url + ユーザー名 + 変数名によって解決されたトークン) を消費します。これらの資格情報のプロビジョニングや解決は行いません。トークン値はcurlによってのみ読み取られ、出力されることはありません。
