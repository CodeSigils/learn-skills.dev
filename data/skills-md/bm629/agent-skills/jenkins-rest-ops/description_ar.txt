استخدمه عند تشغيل واجهة برمجة تطبيقات REST (الوصول عن بعد) لخادم Jenkins مباشرةً باستخدام حليقة (بدون SDK) - تشغيل البنية، واستقصاء عنصر قائمة الانتظار إلى البنية، وقراءة حالة البناء + سجل وحدة التحكم، وإدراج/فحص المهام، والمهمة CRUD (إنشاء عنصر/نسخ/حذف/تمكين/تعطيل عبر config.xml)، وإدارة البناء (إيقاف/حذف). Jenkins عبارة عن مسار REST تمت مصادقته باستخدام اسم مستخدم HTTP Basic: API_TOKEN. مشغل البناء هو ASYNC - فهو يُرجع عنصر قائمة انتظار، وليس بناء، لذا يمكنك استقصاء queue/item/<id>/api/json إلى الملف القابل للتنفيذ. تم استثناء مصادقة الرمز المميز لواجهة برمجة التطبيقات (API) من فتات CSRF (Jenkins 2.96/2.107+)؛ الفتات ليست سوى 403 احتياطي. لا يوجد Jenkins OpenAPI رسمي، لذا فإن جدول المسار CORE يرتكز على مستندات الوصول عن بعد الرسمية (مواصفات swaggy-jenkins المجمعة هي فحص متقاطع غير رسمي). يستهلك بيانات الاعتماد المحقونة بواسطة المتصل (base_url + اسم المستخدم + رمز مميز يتم حله بواسطة اسم متغير) - ولا يوفرها أو يحلها؛ تتم قراءة قيمة الرمز المميز فقط عن طريق التجعيد، ولا تتم طباعتها أبدًا.
