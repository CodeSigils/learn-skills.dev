Úselo cuando controle la API REST (acceso remoto) de un servidor Jenkins directamente con curl (sin SDK): desencadenar una compilación, sondear el elemento de la cola para una compilación, leer el estado de la compilación + registro de la consola, enumerar/inspeccionar trabajos, CRUD de trabajos (crear elemento/copiar/eliminar/habilitar/deshabilitar a través de config.xml) y administración de compilaciones (detener/eliminar). Jenkins tiene una ruta REST autenticada con un nombre de usuario HTTP básico: API_TOKEN. Un activador de compilación es ASYNC: devuelve un elemento de la cola, no una compilación, por lo que sondea cola/elemento/<id>/api/json al ejecutable. La autenticación de token API está exenta de la miga CSRF (Jenkins 2.96/2.107+); una migaja es sólo un recurso 403. No existe una OpenAPI oficial de Jenkins, por lo que la tabla de rutas CORE se basa en los documentos oficiales de acceso remoto (la especificación swaggy-jenkins incluida es una verificación cruzada no oficial). Consume credenciales inyectadas por la persona que llama (base_url + nombre de usuario + un token resuelto por nombre de variable); no las aprovisiona ni las resuelve; el valor del token solo lo lee curl, nunca se imprime.
