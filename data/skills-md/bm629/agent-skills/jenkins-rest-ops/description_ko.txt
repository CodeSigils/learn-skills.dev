컬(SDK 없음)을 사용하여 Jenkins 서버의 REST(원격 액세스) API를 직접 구동할 때 사용합니다. 빌드 트리거, 대기열 항목을 빌드로 폴링, 빌드 상태 + 콘솔 로그 읽기, 작업 나열/검사, 작업 CRUD(config.xml을 통해 항목/복사/삭제/활성화/비활성화) 및 빌드 관리(중지/삭제). Jenkins는 HTTP 기본 사용자 이름:API_TOKEN으로 인증된 경로 주소 지정 REST입니다. 빌드 트리거는 ASYNC입니다. 빌드가 아닌 대기열 항목을 반환하므로 queue/item/<id>/api/json을 실행 파일로 폴링합니다. API 토큰 인증은 CSRF 부스러기(Jenkins 2.96/2.107+)에서 면제됩니다. 부스러기는 403 대체일 뿐입니다. 공식 Jenkins OpenAPI가 존재하지 않으므로 CORE 경로 테이블은 공식 원격 액세스 문서를 기반으로 합니다(번들된 swaggy-jenkins 사양은 비공식 교차 확인입니다). 호출자가 삽입한 자격 증명(base_url + 사용자 이름 + 변수 이름으로 확인된 토큰)을 사용합니다. 이를 프로비저닝하거나 확인하지 않습니다. 토큰 값은 컬로만 읽혀지며 인쇄되지 않습니다.
