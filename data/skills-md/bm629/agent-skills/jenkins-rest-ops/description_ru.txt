Используйте при управлении API REST (удаленный доступ) сервера Jenkins напрямую с помощью Curl (без SDK) — запуск сборки, опрос элемента очереди для сборки, чтение состояния сборки + журнал консоли, составление списка/проверка заданий, CRUD заданий (создание/копирование/удаление/включение/отключение через config.xml) и управление сборкой (остановка/удаление). Дженкинс имеет REST с адресом пути, аутентифицированный с использованием базового имени пользователя HTTP: API_TOKEN. Триггером сборки является ASYNC — он возвращает элемент очереди, а не сборку, поэтому вы опрашиваете очередь/item/<id>/api/json для исполняемого файла. Аутентификация API-токена освобождена от крошки CSRF (Jenkins 2.96/2.107+); крошка - это всего лишь запасной вариант 403. Официального Jenkins OpenAPI не существует, поэтому таблица путей CORE основана на официальной документации по удаленному доступу (входящая в комплект спецификация swaggy-jenkins является неофициальной перекрестной проверкой). Потребляет учетные данные, введенные вызывающим абонентом (base_url + имя пользователя + токен, разрешенный по имени переменной) — он не предоставляет и не разрешает их; значение токена читается только программой Curl и никогда не печатается.
