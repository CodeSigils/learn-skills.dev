Da utilizzare durante la gestione dell'API REST (Accesso remoto) di un server Jenkins direttamente con curl (senza SDK): attivazione di una build, polling dell'elemento della coda su una build, lettura dello stato della build + registro della console, elenco/ispezione dei lavori, CRUD del lavoro (createItem/copia/elimina/abilita/disabilita tramite config.xml) e gestione della build (interrompi/elimina). Jenkins è un REST con indirizzo autenticato con nome utente HTTP Basic: API_TOKEN. Un trigger di build è ASYNC: restituisce un elemento della coda, non una build, quindi esegui il polling Queue/item/<id>/api/json sull'eseguibile. L'autenticazione del token API è esente dal requisito CSRF (Jenkins 2.96/2.107+); una briciola è solo un ripiego 403. Non esiste alcuna Jenkins OpenAPI ufficiale, quindi la tabella dei percorsi CORE si basa sui documenti ufficiali di accesso remoto (le specifiche swaggy-jenkins in bundle sono un controllo incrociato non ufficiale). Consuma le credenziali inserite dal chiamante (base_url + nome utente + un token risolto dal nome della variabile): non le fornisce né le risolve; il valore del token viene letto solo da curl, mai stampato.
