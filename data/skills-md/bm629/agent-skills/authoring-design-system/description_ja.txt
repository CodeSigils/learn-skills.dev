デザイン システム ドキュメントを作成するときに使用します。製品の UI が描画する再利用可能なビジュアルおよびインタラクション言語です。デザイン原則、デザイン トークン (色、タイポグラフィ、間隔、高さ、動き)、コンポーネント カタログ、共有パターン、アクセシビリティ標準、音声などです。アウトラインではなくメソッドを通じてプロデューサーをガイドします。確立された慣行に基づいてトークンとコンポーネントを基礎付け、プリミティブ/セマンティック/コンポーネント階層化で意図に基づいてトークンに名前を付け、製品に合わせてカタログのサイズを設定し、解剖学 + 状態 + バリアント + 使用法 + アクセシビリティを使用して各コンポーネントを指定し、デザイナー/エンジニアが一貫性のあるアクセス可能な UI を構築できる基準に達します。独立したデザイン システム テンプレート ツール (セクション構造) と詳細な調査機能で構成されます。レンダリングされたスウォッチではなく、テキストのマークダウン アーティファクト (16 進数/HSL 値、タイプスケール + コンポーネント仕様テーブル) をターゲットとします。完成したデザインシステムのレビュー用ではなく、画面ごとのレイアウト (つまりワイヤーフレーム化) 用でも、コード化されたコンポーネント ライブラリ用でもありません。
