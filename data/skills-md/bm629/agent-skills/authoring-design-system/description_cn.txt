在创作设计系统文档时使用 - 产品 UI 所借鉴的可重用视觉和交互语言：设计原则、设计标记（颜色、排版、间距、高度、运动）、组件目录、共享模式、可访问性标准和语音。指导生产者通过方法，而不是大纲：在既定实践中扎根标记和组件，在原始/语义/组件分层中按意图命名标记，根据产品调整目录大小，并通过解剖+状态+变体+用法+可访问性来指定每个组件——设计师/工程师可以从中构建一致的、可访问的UI。由独立的设计系统模板工具（剖面结构）和深度研究能力组成。针对文本 Markdown 工件（十六进制/HSL 值、类型比例 + 组件规格表），而不是渲染的样本。不适用于审查已完成的设计系统，不适用于每个屏幕布局（即线框图），也不适用于编码组件库。
