在創作設計系統文件時使用 - 產品 UI 所借鑒的可重複使用視覺和互動語言：設計原則、設計標記（顏色、排版、間距、高度、運動）、元件目錄、共享模式、可訪問性標準和語音。指導生產者通過方法，而不是大綱：在既定實踐中紮根標記和組件，在原始/語義/組件分層中按意圖命名標記，根據產品調整目錄大小，並通過解剖+狀態+變體+用法+可訪問性來指定每個組件——設計師/工程師可以從中構建一致的、可訪問的UI。由獨立的設計系統模板工具（剖面結構）和深度研究能力組成。針對文字 Markdown 工件（十六進位/HSL 值、類型比例 + 元件規格表），而不是渲染的樣本。不適用於審查已完成的設計系統，不適用於每個螢幕佈局（即線框圖），也不適用於編碼元件庫。
