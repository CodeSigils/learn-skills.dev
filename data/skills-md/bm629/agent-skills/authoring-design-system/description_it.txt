Da utilizzare durante la creazione di un documento del sistema di progettazione: il linguaggio visivo e di interazione riutilizzabile su cui si basa l'interfaccia utente di un prodotto: principi di progettazione, token di progettazione (colore, tipografia, spaziatura, elevazione, movimento), un catalogo di componenti, modelli condivisi, standard di accessibilità e voce. Guida il produttore attraverso il METODO, non lo schema: radicamento di token e componenti nella pratica consolidata, denominazione dei token in base all'intento in una suddivisione primitiva/semantica/dei componenti, dimensionamento del catalogo in base al prodotto e specificazione di ciascun componente con anatomia + stati + varianti + utilizzo + accessibilità - fino a una barra da cui un progettista/ingegnere può creare un'interfaccia utente coerente e accessibile. Si compone con uno strumento di modello di sistema di progettazione separato (struttura di sezione) e una capacità di ricerca approfondita. Ha come target un artefatto di markdown testuale (valori esadecimali/HSL, scala del tipo + tabelle delle specifiche dei componenti), non campioni renderizzati. Non per la revisione di un sistema di progettazione finito, non per il layout per schermo (ovvero il wireframing) e non per una libreria di componenti codificati.
