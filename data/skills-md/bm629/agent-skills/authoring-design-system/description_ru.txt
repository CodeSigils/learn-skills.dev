Используйте при разработке документа системы дизайна — многоразовый визуальный язык и язык взаимодействия, на котором основывается пользовательский интерфейс продукта: принципы дизайна, маркеры дизайна (цвет, типографика, интервалы, высота, движение), каталог компонентов, общие шаблоны, стандарты доступности и голос. Помогает производителю использовать МЕТОД, а не схему: обосновать токены и компоненты в устоявшейся практике, именовать токены по назначению в ярусах примитивов/семантики/компонентов, определять размер каталога для продукта и определять каждый компонент с анатомией + состояниями + вариантами + использованием + доступностью - до панели, на основе которой дизайнер/инженер может построить последовательный, доступный пользовательский интерфейс. Состоит из отдельного инструмента шаблонов дизайн-системы (структура разделов) и возможностей глубокого исследования. Нацелен на текстовый артефакт уценки (шестнадцатеричные значения/значения HSL, таблицы типов и спецификаций компонентов), а не на визуализированные образцы. Не для проверки готовой дизайн-системы, не для поэкранной компоновки (то есть каркасного моделирования) и не для закодированной библиотеки компонентов.
