Úselo al crear un documento de sistema de diseño: el lenguaje visual y de interacción reutilizable en el que se basa la interfaz de usuario de un producto: principios de diseño, tokens de diseño (color, tipografía, espaciado, elevación, movimiento), un catálogo de componentes, patrones compartidos, estándares de accesibilidad y voz. Guía al productor a través del MÉTODO, no del esquema: conectar los tokens y componentes a la práctica establecida, nombrar los tokens por intención en una clasificación por niveles primitiva/semántica/componente, dimensionar el catálogo según el producto y especificar cada componente con anatomía + estados + variantes + uso + accesibilidad, hasta una barra desde la cual un diseñador/ingeniero puede construir una interfaz de usuario consistente y accesible. Se compone con una herramienta de plantilla de sistema de diseño independiente (estructura de secciones) y una capacidad de investigación profunda. Se dirige a un artefacto de rebajas textual (valores hexadecimales/HSL, escala de tipos + tablas de especificaciones de componentes), no a muestras renderizadas. No para revisar un sistema de diseño terminado, ni para el diseño por pantalla (es decir, estructura alámbrica) ni para una biblioteca de componentes codificados.
