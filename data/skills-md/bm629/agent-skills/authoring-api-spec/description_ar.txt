يُستخدم عند تأليف مواصفات واجهة برمجة التطبيقات - عقد الأسلاك الهندسية لسطح واجهة برمجة التطبيقات: العمليات/نقاط النهاية، ومخططات الطلب + الاستجابة (الحقول، والأنواع، المطلوبة/الاختيارية، والقيود)، والمصادقة، ونموذج الخطأ الكامل، وترقيم الصفحات/حدود المعدل، والإصدار، والأمثلة العملية. يرشد المنتج من خلال الطريقة، وليس المخطط التفصيلي: عرض العقد بأسلوب المشروع (OpenAPI لـ REST، وSDL لـ GraphQL، وproto لـ RPC)، وكتابة كل حقل، وتعداد حالات الخطأ (وليس فقط المسار السعيد)، وتتبع كل عملية إلى سلوك خاص بمواصفات الميزة، والإشارة إلى نموذج البيانات بدلاً من إعادة تعريفه - إلى شريط حيث يمكن للعميل استدعاء كل عملية ويمكن للخادم تنفيذها من العقد وحده. يتم التأليف باستخدام أداة قالب منفصلة لمواصفات واجهة برمجة التطبيقات وقدرة على البحث العميق. يفترض مواصفات الميزات الأولية (+ مستند معماري + نموذج بيانات في حالة وجوده) - لا تكون صفحة فارغة أبدًا. ليس نموذج بيانات الثبات، أو مرجع واجهة برمجة التطبيقات (API) المواجه للمستهلك، أو التنفيذ، أو مراجعة مواصفات واجهة برمجة التطبيقات النهائية.
