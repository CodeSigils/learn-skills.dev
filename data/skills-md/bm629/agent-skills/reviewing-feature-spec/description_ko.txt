완성된 기능 사양을 검토하거나 판단할 때 엔지니어링이 이를 계획하고 구축할 수 있는지 여부(저작이 아닌 수용 게이트)를 결정하는 데 사용합니다. 기능 사양은 PRD 아래의 레이어입니다. 각 기능이 어떻게 작동하는지, 구축하고 테스트하기에 충분히 자세하게 설명되어 있습니다. 구현 가능성 + 테스트 가능성 기준에 따라 판단합니다. 모든 기능은 업스트림 PRD 요구 사항을 추적하고(고아 없음, 적용 범위 격차 없음) 동작이 명확하고 관찰 가능하며 입력/출력/상태가 완전하고 모든 엣지 케이스에 예상 응답이 지정되고 승인 기준이 독립적으로 테스트 가능하며(Given/When/Then 또는 규칙 기반) 공개 질문이 표시됩니다. 정확하게 `VERDICT: 승인|수정`과 실행 가능한 결과(실패한 조건 + 해결 방법)를 내보냅니다. 기준을 충족하고(잘못된 수정 없음) 실제 명명된 간격만 수정하는 사양을 승인합니다. 사양 작성, 업스트림 PRD(PRD 검토 기술 사용), ADR/RFC(설계 검토 사용)와 같은 엔지니어링 설계 문서 및 기타 문서 유형용이 아닙니다.
