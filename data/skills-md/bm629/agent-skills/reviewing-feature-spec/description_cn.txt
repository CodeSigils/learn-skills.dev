在审查或判断已完成的功能规范时使用，以决定工程是否可以根据它进行规划和构建 - 验收门，而不是创作。功能规范是 PRD 之下的一层——它描述了每个功能的行为方式，并提供足够详细的信息以供构建和测试。根据可实施性+可测试性栏来判断：每个功能都跟踪上游 PRD 需求（没有孤儿，没有覆盖差距），行为明确且可观察，输入/输出/状态完整，每个边缘案例命名其预期响应，验收标准可独立测试（给定/何时/然后或基于规则），并且开放问题浮出水面。准确发出“VERDICT：批准|修订”加上可操作的结果（失败的情况+如何修复）。批准符合标准的规范（无错误修订），并且仅针对真实的、指定的差距进行修订。不适用于编写规范，不适用于上游 PRD（使用 PRD 审核技能），不适用于 ADR/RFC 等工程设计文档（使用设计审核），不适用于其他文档类型。
