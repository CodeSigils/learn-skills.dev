高忠実度の UI デザインを作成または修正するときにコードとして使用します。各キー画面は実行可能なコード (デフォルトではスタンドアロン HTML+Tailwind、ビルド スタックが React の場合は React+shadcn) として実現され、上流のワイヤーフレーム + デザイン システムから派生し、ヘッドレスでレンダリングされ、スクリーンショットを取得され、ビルド シードとして使用されます。アウトラインではなくメソッドをガイドします: ワイヤーフレームで名前付きの画面/状態ごとに 1 つの画面を導出し、トークンからコードへのマップを通じてデザイン システム トークンを消費し (トークンや生の hex/px を決して発明しない)、視覚言語 + 客観的な磨き + 名前付きの美的ヒューリスティックを実際のピクセルに実現し、実際のコンテンツ + すべての状態をレンダリングし、制限された生成-レンダリング-スクリーンショット-ビジョン-レビュー-リファイン ループを実行し、数値 WCAG 2.2 AA を判断します。レンダー上で、スコープ付きのバージョン付きデルタとして修正します。テンプレートツール+エージェントブラウザ+shadcn+リサーチで構成。ビジョン対応のランタイムが必要です。ハイファイ、画面構造 (ワイヤーフレーム)、トークン システム (デザイン システム)、または最終コードをレビューするためのものではありません。
