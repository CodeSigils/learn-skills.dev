يُستخدم عند تأليف أو تعديل تصميم واجهة مستخدم عالي الدقة AS CODE - يتم تحقيق كل شاشة رئيسية كرمز قابل للتشغيل (HTML+Tailwind مستقل افتراضيًا، React+shadcn عندما تكون حزمة البناء React)، مشتقة من الإطارات السلكية الأولية + نظام التصميم، ويتم عرضها بدون رأس ولقطة شاشة، وتستخدم كبناء SEED. يوجه الطريقة، وليس المخطط التفصيلي: اشتقاق شاشة واحدة لكل شاشة/حالة مسماة بإطار سلكي، واستهلاك الرموز المميزة لنظام التصميم من خلال خريطة رمزية إلى رمزية (عدم اختراع رمز مميز أو سداسي عشري/بيكسل خام)، وتحقيق اللغة المرئية + تلميع موضوعي + الاستدلال الجمالي المسمى على وحدات البكسل الحقيقية، وتقديم محتوى حقيقي + كل حالة، وتشغيل حلقة إنشاء-عرض-لقطة شاشة-رؤية-مراجعة-تحسين محددة، والحكم على WCAG الرقمية 2.2 AA على العرض، وتعديله كدلتا ذات إصدار محدد النطاق. يؤلف باستخدام أداة القالب + متصفح الوكيل + shadcn + البحث. يتطلب وقت تشغيل قادرًا على الرؤية. ليس لمراجعة hi-fi، أو بنية الشاشة (الإطارات السلكية)، أو نظام الرمز المميز (نظام التصميم)، أو الكود النهائي.
