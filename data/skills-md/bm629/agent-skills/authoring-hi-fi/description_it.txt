Da utilizzare durante la creazione o la modifica di una progettazione dell'interfaccia utente ad alta fedeltà AS CODE: ciascuna schermata chiave realizzata come codice eseguibile (HTML autonomo+Tailwind per impostazione predefinita, React+shadcn quando lo stack di build è React), derivato da wireframe upstream + sistema di progettazione, reso senza testa e screenshot, utilizzato come SEED di build. Guida il METODO, non lo schema: derivare uno schermo per schermata/stato con nome wireframe, consumare token del sistema di progettazione attraverso una mappa token-to-code (non inventare mai un token o un esadecimale/px grezzo), realizzare il linguaggio visivo + perfezionamento dell'obiettivo + euristica estetica denominata in pixel reali, eseguire il rendering del contenuto reale + ogni stato, eseguire un ciclo limitato di generazione-rendering-screenshot-visione-revisione-raffinazione, giudicare le WCAG 2.2 AA numeriche sul render e modificandolo come delta con ambito di versione. Compone con uno strumento modello + browser agente + shadcn + ricerca. Richiede un runtime con funzionalità di visione. Non per rivedere l'hi-fi, la struttura dello schermo (wireframe), il sistema di token (design-system) o il codice finale.
