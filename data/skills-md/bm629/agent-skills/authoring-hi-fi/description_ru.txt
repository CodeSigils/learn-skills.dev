Используйте при разработке или изменении высокоточного дизайна пользовательского интерфейса КАК КОДА — каждый ключевой экран реализован как исполняемый код (автономный HTML+Tailwind по умолчанию, React+shadcn, если стек сборки — React), полученный из вышестоящих каркасов + дизайн-системы, визуализируемый без головы и снятый с экрана, используемый в качестве SEED сборки. Направляет МЕТОД, а не схему: создание одного экрана для каждого экрана/состояния с именем в виде каркаса, использование токенов системы дизайна через карту токена в код (никогда не изобретая токен или необработанный шестнадцатеричный/пиксельный код), реализация визуального языка + объективная полировка + именованные эстетические эвристики для реальных пикселей, рендеринг реального контента + каждое состояние, выполнение ограниченного цикла генерации-рендеринга-скриншота-видения-обзора-уточнения, оценка числового WCAG 2.2 AA на рендеринге и внесение поправок в виде дельта-версии с ограниченной областью действия. Составляется с помощью инструмента шаблона + агента-браузера + shadcn + исследования. Требуется среда выполнения с поддержкой машинного зрения. Не для обзора hi-fi, структуры экрана (вайрфреймов), системы токенов (дизайн-системы) или финального кода.
