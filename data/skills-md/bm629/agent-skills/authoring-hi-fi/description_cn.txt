在创作或修改高保真 UI 设计时使用 AS CODE — 每个关键屏幕均实现为可运行代码（默认情况下为独立 HTML+Tailwind，当构建堆栈为 React 时为 React+shadcn），源自上游线框 + 设计系统，无头渲染并截屏，用作构建 SEED。指导方法，而不是大纲：为每个线框命名的屏幕/状态派生一个屏幕，通过令牌到代码映射消耗设计系统令牌（不要发明令牌或原始十六进制/像素），实现视觉语言+客观抛光+对真实像素的命名美学启发，渲染真实内容+每个状态，运行有界生成-渲染-屏幕截图-视觉-审查-优化循环，判断数字WCAG 2.2 AA渲染，并修改为范围版本增量。由模板工具+代理浏览器+shadcn+研究组成。需要支持视觉的运行时。不适用于审查高保真音响、屏幕结构（线框）、令牌系统（设计系统）或最终代码。
