À utiliser lors de la création ou de la modification d'une conception d'interface utilisateur haute fidélité AS CODE — chaque écran clé réalisé sous forme de code exécutable (HTML+Tailwind autonome par défaut, React+shadcn lorsque la pile de build est React), dérivé des wireframes en amont + du système de conception, rendu sans tête et capturé par capture d'écran, utilisé comme SEED de build. Guide la MÉTHODE, pas le contour : dériver un écran par écran/état nommé filaire, consommer des jetons du système de conception via une carte jeton-code (ne jamais inventer un jeton ou un hexadécimal/px brut), réaliser le langage visuel + polissage objectif + heuristique esthétique nommée en pixels réels, restituer le contenu réel + chaque état, exécuter une boucle limitée de génération-rendu-capture d'écran-vision-examen-raffinement, juger les WCAG 2.2 AA numériques sur le rendu, et modification en tant que delta versionné étendu. Compose avec un outil de modèle + agent-navigateur + shadcn + recherche. Nécessite un runtime compatible avec la vision. Pas pour revoir la chaîne hi-fi, la structure de l'écran (wireframes), le système de jetons (design-system) ou le code final.
