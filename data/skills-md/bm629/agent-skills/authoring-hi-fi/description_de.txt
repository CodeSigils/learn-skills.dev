Wird beim Erstellen oder Ändern eines High-Fidelity-UI-Designs als CODE verwendet – jeder Schlüsselbildschirm wird als ausführbarer Code realisiert (standardmäßig eigenständiges HTML+Tailwind, React+shadcn, wenn der Build-Stack React ist), abgeleitet von vorgelagerten Wireframes + Design-System, kopflos gerendert und als Screenshot erstellt, als Build-SEED verwendet. Leitet die METHODE, nicht die Gliederung: Ableiten eines Bildschirms pro Wireframe-benanntem Bildschirm/Zustand, Verbrauchen von Designsystem-Tokens durch eine Token-zu-Code-Zuordnung (niemals Erfinden eines Tokens oder roher Hex/Pixel), Realisieren der visuellen Sprache + objektiver Feinschliff + benannte ästhetische Heuristiken für echte Pixel, Rendern von echtem Inhalt + jedem Zustand, Ausführen einer begrenzten Schleife zum Generieren, Rendern, Screenshot, Sehen, Überprüfen und Verfeinern, Beurteilen numerischer WCAG 2.2 AA auf dem Rendering und Änderung als bereichsbasiertes versioniertes Delta. Verfasst mit einem Vorlagentool + Agent-Browser + Shadcn + Recherche. Erfordert eine visionfähige Laufzeit. Nicht zur Überprüfung von Hi-Fi, der Bildschirmstruktur (Wireframes), dem Token-System (Design-System) oder dem endgültigen Code.
