在創作或修改高保真 UI 設計時使用 AS CODE — 每個關鍵螢幕均實作為可運行程式碼（預設為獨立 HTML+Tailwind，當建置堆疊為 React 時為 React+shadcn），源自上游線框 + 設計系統，無頭渲染並截圖，用作建置 SEED。指導方法，而不是大綱：為每個線框命名的屏幕/狀態派生一個屏幕，通過令牌到代碼映射消耗設計系統令牌（不要發明令牌或原始十六進制/像素），實現視覺語言+客觀拋光+對真實像素的命名美學啟發，渲染真實內容+每個狀態，運行有界生成-渲染-屏幕截圖-視覺-審查-增量循環，判斷為 AAWC 2.由範本工具+代理瀏覽器+shadcn+研究組成。需要支持视觉的运行时。不適用於審查高傳真音響、螢幕結構（線框）、令牌系統（設計系統）或最終程式碼。
