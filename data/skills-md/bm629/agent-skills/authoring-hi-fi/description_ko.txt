충실도가 높은 UI 디자인을 작성하거나 수정할 때 코드로 사용합니다. 각 주요 화면은 실행 가능한 코드(기본적으로 독립형 HTML+Tailwind, 빌드 스택이 React인 경우 React+shadcn)로 구현되며, 업스트림 와이어프레임 + 디자인 시스템에서 파생되고, 헤드리스로 렌더링되고 스크린샷화되며, 빌드 SEED로 사용됩니다. 개요가 아닌 방법 안내: 와이어프레임 이름이 지정된 화면/상태당 하나의 화면 파생, 토큰-코드 맵을 통해 디자인 시스템 토큰 사용(토큰 또는 원시 16진수/px를 발명하지 않음), 시각적 언어 실현 + 객관적인 다듬기 + 명명된 미적 휴리스틱을 실제 픽셀로 구현, 실제 콘텐츠 + 모든 상태 렌더링, 제한된 생성-렌더-스크린샷-비전-검토-수정 루프 실행, 숫자 WCAG 2.2 AA 판단 렌더링 시 범위가 지정된 버전의 델타로 수정됩니다. 템플릿 도구 + 에이전트 브라우저 + shadcn + 연구로 구성합니다. 비전 지원 런타임이 필요합니다. Hi-Fi, 화면 구조(와이어프레임), 토큰 시스템(디자인 시스템) 또는 최종 코드를 검토하기 위한 것이 아닙니다.
