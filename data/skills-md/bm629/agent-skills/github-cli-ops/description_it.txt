Da utilizzare quando si esegue un'operazione GitHub in modo programmatico (creando un problema o una richiesta pull, gestendo repository, versioni, etichette, esecuzioni di azioni, progetti, segreti o qualsiasi attività github.com) preferendo la CLI `gh` e ricorrendo a `gh api` (REST) ​​o `gh api graphql` solo dove non esiste alcun comando. Ogni chiamata è autenticata per invocazione con `GH_TOKEN`; non esegue mai `gh auth switch` e non stampa mai il token. Utilizza i comandi di alto livello di `gh` (che crittografano anche i segreti lato client) per copertura ed ergonomia; per la coda lunga REST crea una chiamata `gh api` da una specifica OpenAPI in bundle tramite un indice endpoint + un risolutore `$ref`. github.comNuvola; consuma credenziali inserite dal chiamante (host + un token risolto dal nome della variabile) - non le fornisce né le risolve.
