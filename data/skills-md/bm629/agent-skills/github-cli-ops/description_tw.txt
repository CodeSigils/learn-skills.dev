以程式設計方式執行 GitHub 操作時使用 - 建立問題或拉取請求、管理儲存庫、發布、標籤、操作運行、專案、機密或任何 github.com 任務 - 首選「gh」 CLI，並僅在不存在命令的情況下回退到「gh api」（REST）或「gh api graphql」。每次呼叫都會使用“GH_TOKEN”進行身份驗證；它從不執行“gh auth switch”，也從不列印令牌。使用“gh”的高級命令（也對客戶端的秘密進行加密）來實現覆蓋範圍和人體工學；對於 REST 長尾，它透過端點索引 + “$ref”解析器從捆綁的 OpenAPI 規範構建“gh api”調用。 github.com 雲端；使用呼叫者註入的憑證（主機+由變數名稱解析的令牌）－它不提供或解析它們。
