Úselo al realizar una operación de GitHub mediante programación (crear un problema o solicitud de extracción, administrar repositorios, lanzamientos, etiquetas, ejecuciones de acciones, proyectos, secretos o cualquier tarea de github.com), prefiriendo la CLI `gh` y recurriendo a `gh api` (REST) ​​o `gh api graphql` solo donde no exista ningún comando. Cada llamada se autentica por invocación con `GH_TOKEN`; nunca ejecuta "gh auth switch" y nunca imprime el token.
