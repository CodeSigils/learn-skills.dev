À utiliser lors de l'exécution d'une opération GitHub par programme — création d'un problème ou d'une demande d'extraction, gestion des dépôts, des versions, des étiquettes, des exécutions d'actions, des projets, des secrets ou toute tâche github.com — en préférant la CLI `gh` et en revenant à `gh api` (REST) ​​ou `gh api graphql` uniquement là où aucune commande n'existe. Chaque appel est authentifié par invocation avec « GH_TOKEN » ; il n'exécute jamais « gh auth switch » et n'imprime jamais le jeton. Utilise les commandes de haut niveau de « gh » (qui chiffrent également les secrets côté client) pour la couverture et l'ergonomie ; pour la longue traîne REST, il crée un appel `gh api` à partir d'une spécification OpenAPI fournie via un index de point de terminaison + un résolveur `$ref`. Nuage github.com ; consomme les informations d'identification injectées par l'appelant (hôte + un jeton résolu par nom de variable) - il ne les fournit ni ne les résout.
