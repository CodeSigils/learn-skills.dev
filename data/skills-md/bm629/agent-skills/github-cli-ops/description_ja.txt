GitHub 操作をプログラムで実行する場合 (課題やプル リクエストの作成、リポジトリ、リリース、ラベル、アクションの実行、プロジェクト、シークレット、または github.com タスクの管理) を実行する場合に使用します。`gh` CLI を優先し、コマンドが存在しない場合にのみ `gh api` (REST) または `gh apigraphql` にフォールバックします。すべての呼び出しは、「GH_TOKEN」を使用して呼び出しごとに認証されます。 「gh auth switch」は実行されず、トークンも出力されません。カバレッジと人間工学のために「gh」の高レベル コマンド (クライアント側で秘密情報も暗号化します) を使用します。 REST ロングテールの場合、エンドポイント インデックス + `$ref` リゾルバーを介して、バンドルされた OpenAPI 仕様から `gh api` 呼び出しを構築します。 github.com クラウド;呼び出し元が挿入した資格情報 (ホスト + 変数名によって解決されたトークン) を消費します。それらのプロビジョニングや解決は行いません。
