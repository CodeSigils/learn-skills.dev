Используйте при программном выполнении операции GitHub — создании задачи или запроса на включение, управлении репозиториями, выпусками, метками, запусками действий, проектами, секретами или любой задачей github.com — отдавая предпочтение CLI `gh` и возвращаясь к `gh api` (REST) ​​или `gh apigraphql` только там, где команда не существует. Каждый вызов аутентифицируется для каждого вызова с помощью `GH_TOKEN`; он никогда не запускает `gh auth switch` и никогда не печатает токен. Использует команды высокого уровня `gh` (которые также шифруют секреты на стороне клиента) для покрытия и эргономики; для длинного хвоста REST он создает вызов `gh api` из связанной спецификации OpenAPI через индекс конечной точки + преобразователь `$ref`. Облако github.com; использует учетные данные, введенные вызывающим абонентом (хост + токен, разрешенный по имени переменной), — он не предоставляет и не разрешает их.
