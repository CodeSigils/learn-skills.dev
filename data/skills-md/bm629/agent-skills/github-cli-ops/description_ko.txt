프로그래밍 방식으로 GitHub 작업을 수행할 때 사용합니다(문제 생성, 풀 요청 생성, 리포지토리, 릴리스, 레이블, 작업 실행, 프로젝트, 비밀 또는 기타 github.com 작업 관리). `gh` CLI를 선호하고 명령이 없는 경우에만 `gh api`(REST) ​​또는 `gh api graphql`로 대체합니다. 모든 호출은 `GH_TOKEN`을 사용하여 호출별로 인증됩니다. `gh auth switch`를 실행하지 않으며 토큰을 인쇄하지 않습니다. 적용 범위와 인체 공학을 위해 `gh`의 고급 명령(클라이언트 측 비밀도 암호화함)을 사용합니다. REST 롱테일의 경우 엔드포인트 인덱스 + `$ref` 해석기를 통해 번들 OpenAPI 사양에서 `gh api` 호출을 빌드합니다. github.com 클라우드; 호출자가 주입한 자격 증명(호스트 + 변수 이름으로 확인된 토큰)을 사용하며 이를 프로비저닝하거나 확인하지 않습니다.
