以编程方式执行 GitHub 操作时使用 - 创建问题或拉取请求、管理存储库、发布、标签、操作运行、项目、机密或任何 github.com 任务 - 首选“gh” CLI，并仅在不存在命令的情况下回退到“gh api”（REST）或“gh api graphql”。每次调用都会使用“GH_TOKEN”进行身份验证；它从不运行“gh auth switch”，也从不打印令牌。使用“gh”的高级命令（也对客户端的秘密进行加密）来实现覆盖范围和人体工程学；对于 REST 长尾，它通过端点索引 + “$ref”解析器从捆绑的 OpenAPI 规范构建“gh api”调用。 github.com 云；使用调用者注入的凭据（主机+由变量名解析的令牌）——它不提供或解析它们。
