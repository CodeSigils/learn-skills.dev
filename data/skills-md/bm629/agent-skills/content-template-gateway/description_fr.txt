À utiliser lorsque quelqu'un (utilisateur ou agent) est sur le point de créer un contenu structuré (RFC, ADR, runbook, spécification, plan, PRD, README, rétrospective, article de blog, description de PR, corps de problème, ticket, message de validation multi-paragraphes, annonce ou toute autre forme) quelle que soit la destination (fichier local, GitHub, Jira, Linear, Slack, e-mail, Confluence, Notion, Google Drive, etc.). Cette compétence est la porte par laquelle passe toute action de création de contenu. Il (1) identifie le type de contenu + la variante à partir de l'intention via la recherche, (2) vérifie docs/templates/<content-type>/<variant>/ pour un modèle existant, (3) s'il existe, le renvoie plus une directive de refus absolu que vous DEVEZ suivre, (4) s'il manque, en forge un nouveau via la recherche, puis le renvoie sous la même directive, (5) sur l'intention "conseiller :", aide à placer le contenu qui ne convient pas (mappage vers des sections ou propose une nouvelle variante). Modes : utiliser ou créer (par défaut), forcer la régénération, forcer une nouvelle variante. Autonome : préfère une compétence capable de recherche si disponible, sinon WebSearch + WebFetch intégré.
