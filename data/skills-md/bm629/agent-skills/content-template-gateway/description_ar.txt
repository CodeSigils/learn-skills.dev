يُستخدم عندما يكون أي شخص (مستخدم أو وكيل) على وشك تأليف أي محتوى منظم - RFC، أو ADR، أو دليل التشغيل، أو المواصفات، أو الخطة، أو PRD، أو README، أو بأثر رجعي، أو منشور مدونة، أو وصف العلاقات العامة، أو نص الإصدار، أو التذكرة، أو رسالة التزام متعددة الفقرات، أو إعلان، أو أي شكل آخر - بغض النظر عن الوجهة (ملف محلي، أو GitHub، أو Jira، أو Linear، أو Slack، أو البريد الإلكتروني، أو Confluence، أو Notion، أو Google Drive، وما إلى ذلك). هذه المهارة هي البوابة التي يمر من خلالها كل إجراء تأليف المحتوى. إنه (1) يحدد نوع المحتوى + متغير من النية عبر البحث، (2) يتحقق من docs/templates/<content-type>/<variant>/ لقالب موجود، (3) إذا كان موجودًا، يعرضه بالإضافة إلى توجيه الرفض الصارم الذي يجب عليك اتباعه، (4) إذا كان مفقودًا، يقوم بتزوير واحد جديد عبر البحث، ثم يعيده تحت نفس التوجيه، (5) على "نصيحة:" القصد، ويساعد على وضع المحتوى الذي لا يتناسب (خرائط للأقسام أو تقترح متغيرًا جديدًا). الأوضاع: الاستخدام أو الإنشاء (افتراضي)، وتجديد القوة، ومتغير القوة الجديد. مكتفي بذاته: يفضل مهارة البحث إذا كانت متوفرة، وإلا فهي مدمجة في WebSearch + WebFetch.
