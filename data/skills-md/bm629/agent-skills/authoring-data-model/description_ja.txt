データ モデル ドキュメントを作成するときに使用します。保存されたデータの永続性/ドメイン モデル: 型付きエンティティ、リレーションシップ + カーディナリティ、キー/制約、インデックス、正規化、ストレージの選択、ライフサイクルなどです。アウトラインではなく、メソッドを通じてプロデューサーをガイドします。機能仕様の名詞 + アクセス パターンからエンティティを導出し、パラダイムの検出とそのモデル化 (リレーショナル、ドキュメント/NoSQL アクセス パターン優先、グラフ、ワイドカラム、キー値)、整合性ルールの明示化 (キー、制約、カーディナリティ + 参照ルール)、アクセス パターンによる各インデックスの正当化、および承認されたモデルの修正を行います。バージョン管理され、移行が計画されたデルタ - これにより、エンジニアはスキーマを構築してクエリを実行できます。データモデルテンプレートツールと詳細な調査機能で構成されます。アップストリームの機能仕様 (+ アーキテクチャ ドキュメント) を前提としています。空白ページは決してありません。 API ワイヤ コントラクト (API 仕様はこれらのエンティティをダウンストリームで一方向に参照します)、実装/DDL、完成したデータ モデルのレビューではありません。
