在创作数据模型文档时使用 - 存储数据的持久性/域模型：类型化实体、关系+基数、键/约束、索引、规范化、存储选择和生命周期。指导生产者完成方法，而不是大纲：从功能规范的名词+访问模式中派生实体，检测其中的范式和建模（关系、文档/NoSQL访问模式优先、图形、宽列、键值），使完整性规则明确（键、约束、基数+引用规则），通过访问模式证明每个索引的合理性，并将批准的模型修改为版本化、迁移计划的增量——以便工程师可以构建+查询架构。由数据模型模板工具+深度研究能力组成。假设上游功能规范（+架构文档）——绝不是空白页面。不是 API 线合同（API 规范引用这些下游实体，单向），不是实现/DDL，也不是审查完成的数据模型。
