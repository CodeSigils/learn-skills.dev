在决定软件或产品项目需要生成哪些文档才能交付生产时使用 - 将项目想法转化为成比例的文档计划：哪些文档、每个文档由谁或什么生成，以及它们所依赖的顺序。涵盖完整的 SDLC 文档范围（规划、分析、产品/需求、设计/用户体验、架构/工程、交付/投入生产、面向用户的文档）以及域覆盖（数据/机器学习、安全/合规、法律/治理、监管/验证），并将该集设置为项目原型，因此瘦 CLI 工具可以得到一些，而 UI 产品可以得到很多。仅发现：它决定哪些文档以及生成它们需要什么，而不是如何创作它们（这是一个单独的每个文档创作问题）。关键词：我的项目需要哪些文档、文档发现、文档计划、SDLC 文档、文档清单、项目文档范围、比例文档。
