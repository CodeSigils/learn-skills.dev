소프트웨어 또는 제품 프로젝트가 프로덕션으로 배송하기 위해 생성해야 하는 문서를 결정할 때 사용합니다. 즉, 프로젝트 아이디어를 비례적인 문서 계획으로 전환합니다. 즉, 문서, 각 문서를 생산하는 사람 또는 대상, 의존하는 순서 등이 있습니다. 전체 SDLC 문서 세계(계획, 분석, 제품/요구 사항, 디자인/UX, 아키텍처/엔지니어링, 납품/생산 시작, 사용자 대면 문서)와 도메인 오버레이(데이터/ML, 보안/규정 준수, 법률/거버넌스, 규제/검증)를 다루고 프로젝트 원형에 대한 세트를 지정하므로 씬 CLI 도구는 소수이고 UI 제품은 다수를 얻습니다. 검색 전용: 문서 작성 방법이 아니라 문서 생성에 필요한 내용과 문서 작성 방법을 결정합니다(문서별 작성 관련 사항은 별도로 있음). 키워드: 내 프로젝트에 필요한 문서, 문서 검색, 문서 계획, SDLC 문서, 문서 매니페스트, 프로젝트 문서 범위, 비례 문서.
