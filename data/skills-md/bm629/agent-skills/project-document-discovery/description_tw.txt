在決定軟體或產品專案需要產生哪些文件才能交付生產時使用 - 將專案想法轉化為成比例的文件計劃：哪些文件、每個文件由誰或什麼生成，以及它們所依賴的順序。涵蓋完整的 SDLC 文件範圍（規劃、分析、產品/需求、設計/使用者體驗、架構/工程、交付/投入生產、面向使用者的文件）以及網域覆蓋（資料/機器學習、安全/合規、法律/治理、監管/驗證），並將該集設定為專案原型，因此瘦 CLI 工具可以得到一些，而 UI 產品可以得到很多。僅發現：它決定哪些文件以及產生它們需要什麼，而不是如何創作它們（這是一個單獨的每個文件創作問題）。關鍵字：我的專案需要哪些文件、文件發現、文件計畫、SDLC 文件、文件清單、專案文件範圍、比例文件。
