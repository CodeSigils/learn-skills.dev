À utiliser lors de l'appel direct de l'API REST Atlassian Cloud — Confluence Cloud v2 (pages, espaces, recherche) ou Jira Cloud v3 (problèmes, recherche JQL, commentaires) — pour effectuer des opérations par programmation, y compris des écritures telles que la création d'une page Confluence. Appelle REST avec curl (pas de SDK, pas de pip), en s'authentifiant avec un e-mail Cloud + un jeton API à partir d'un enregistrement par compte. Construit l'un des plus de 800 points de terminaison à partir d'une spécification OpenAPI groupée via un index de point de terminaison + un résolveur $ref, avec des modèles par API (URL de base, pagination, erreurs, limites de débit) et les formats de texte riche ADF/stockage gérés explicitement. Lit les informations d'identification à partir d'un enregistrement .service-accounts.yaml + un jeton .env dans l'espace de travail ou dans la portée du projet ; la valeur du jeton est lue uniquement par curl, jamais imprimée.
