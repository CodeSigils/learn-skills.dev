استخدمه عند استدعاء Atlassian Cloud REST API مباشرةً - Confluence Cloud v2 (الصفحات والمسافات والبحث) أو Jira Cloud v3 (المشكلات وبحث JQL والتعليقات) - لتنفيذ العمليات برمجيًا، بما في ذلك عمليات الكتابة مثل إنشاء صفحة Confluence. يستدعي REST مع الضفيرة (بدون SDK، بدون نقطة)، والمصادقة باستخدام البريد الإلكتروني السحابي + رمز واجهة برمجة التطبيقات (API) من سجل لكل حساب. إنشاء أي من نقاط النهاية التي يزيد عددها عن 800 نقطة من مواصفات OpenAPI المجمعة عبر فهرس نقطة النهاية + محلل $ref، مع أنماط لكل واجهة برمجة تطبيقات (عنوان URL الأساسي، ترقيم الصفحات، الأخطاء، حدود المعدل) وتنسيقات النصوص الغنية بالتخزين ADF/التخزينية التي تتم معالجتها بشكل صريح. قراءة بيانات الاعتماد من سجل ‎.service-accounts.yaml + رمز ‎.env في مساحة العمل أو نطاق المشروع؛ تتم قراءة قيمة الرمز المميز فقط عن طريق التجعيد، ولا تتم طباعتها أبدًا.
