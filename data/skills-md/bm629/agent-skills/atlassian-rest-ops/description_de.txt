Wird verwendet, wenn Sie die Atlassian Cloud REST API direkt aufrufen – Confluence Cloud v2 (Seiten, Bereiche, Suche) oder Jira Cloud v3 (Probleme, JQL-Suche, Kommentare) – um Vorgänge programmgesteuert auszuführen, einschließlich Schreibvorgängen wie dem Erstellen einer Confluence-Seite. Ruft REST mit Curl auf (kein SDK, kein Pip) und authentifiziert sich mit einer Cloud-E-Mail + API-Token aus einem kontospezifischen Datensatz. Konstruiert jeden der über 800 Endpunkte aus einer gebündelten OpenAPI-Spezifikation über einen Endpunktindex + einen $ref-Resolver, wobei API-spezifische Muster (Basis-URL, Paginierung, Fehler, Ratenbeschränkungen) und die ADF-/Speicher-Rich-Text-Formate explizit behandelt werden. Liest Anmeldeinformationen aus einem .service-accounts.yaml-Datensatz + .env-Token im Arbeitsbereich oder Projektbereich; Der Tokenwert wird von Curl nur gelesen und nie gedruckt.
