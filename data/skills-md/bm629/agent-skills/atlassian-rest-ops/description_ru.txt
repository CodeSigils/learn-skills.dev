Используйте при прямом вызове REST API Atlassian Cloud — Confluence Cloud v2 (страницы, пространства, поиск) или Jira Cloud v3 (ошибки, поиск JQL, комментарии) — для программного выполнения операций, включая запись, например создание страницы Confluence. Вызывает REST с помощью Curl (без SDK, без pip), аутентифицируясь с помощью электронной почты Cloud + токена API из записи для каждой учетной записи. Создает любую из более чем 800 конечных точек из объединенной спецификации OpenAPI через индекс конечной точки + преобразователь $ref, с шаблонами для каждого API (базовый URL-адрес, разбиение на страницы, ошибки, ограничения скорости) и форматами расширенного текста ADF/хранилища, обрабатываемыми явно. Считывает учетные данные из записи .service-accounts.yaml + токена .env в рабочей области или области проекта; значение токена читается только программой Curl и никогда не печатается.
