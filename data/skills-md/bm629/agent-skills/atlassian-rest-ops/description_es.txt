Úselo cuando llame directamente a la API REST de Atlassian Cloud (Confluence Cloud v2 (páginas, espacios, búsqueda) o Jira Cloud v3 (problemas, búsqueda JQL, comentarios)) para realizar operaciones mediante programación, incluidas escrituras como la creación de una página de Confluence. Llama a REST con curl (sin SDK, sin pip), autenticándose con un correo electrónico en la nube + token de API desde un registro por cuenta. Construye cualquiera de los más de 800 puntos finales a partir de una especificación OpenAPI incluida a través de un índice de punto final + un $ref-resolver, con patrones por API (URL base, paginación, errores, límites de velocidad) y los formatos de texto enriquecido de almacenamiento/ADF manejados explícitamente. Lee las credenciales de un registro .service-accounts.yaml + token .env en el ámbito del espacio de trabajo o del proyecto; el valor del token solo lo lee curl, nunca se imprime.
