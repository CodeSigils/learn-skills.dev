Atlassian Cloud REST API (Confluence Cloud v2 (ページ、スペース、検索) または Jira Cloud v3 (課題、JQL 検索、コメント)) を直接呼び出して、Confluence ページの作成などの書き込みを含む操作をプログラムで実行する場合に使用します。 curl を使用して REST を呼び出し (SDK なし、pip なし)、アカウントごとのレコードからのクラウドメール + API トークンで認証します。 API ごとのパターン (ベース URL、ページネーション、エラー、レート制限) と明示的に処理される ADF/ストレージ リッチテキスト形式を使用して、エンドポイント インデックス + $ref リゾルバーを介してバンドルされた OpenAPI 仕様から 800 以上のエンドポイントを構築します。ワークスペースまたはプロジェクト スコープで .service-accounts.yaml レコード + .env トークンから資格情報を読み取ります。トークン値はcurlによってのみ読み取られ、出力されることはありません。
