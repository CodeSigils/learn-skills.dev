Da utilizzare quando si chiama direttamente l'API REST di Atlassian Cloud — Confluence Cloud v2 (pagine, spazi, ricerca) o Jira Cloud v3 (problemi, ricerca JQL, commenti) — per eseguire operazioni a livello di codice, incluse scritture come la creazione di una pagina Confluence. Chiama REST con curl (nessun SDK, nessun pip), autenticandosi con un'e-mail cloud + token API da un record per account. Costruisce uno qualsiasi degli oltre 800 endpoint da una specifica OpenAPI in bundle tramite un indice endpoint + un risolutore $ref, con modelli per API (URL di base, impaginazione, errori, limiti di velocità) e i formati rich-text di archiviazione/ADF gestiti esplicitamente. Legge le credenziali da un record .service-accounts.yaml + token .env nell'area di lavoro o nell'ambito del progetto; il valore del token viene letto solo da curl, mai stampato.
