Atlassian Cloud REST API(Confluence Cloud v2(페이지, 공간, 검색) 또는 Jira Cloud v3(문제, JQL 검색, 댓글))를 직접 호출할 때 사용하여 Confluence 페이지 생성과 같은 쓰기를 포함하여 작업을 프로그래밍 방식으로 수행합니다. 컬(SDK 없음, pip 없음)로 REST를 호출하여 계정별 레코드에서 클라우드 이메일 + API 토큰으로 인증합니다. 엔드포인트 인덱스 + $ref-resolver를 통해 번들 OpenAPI 사양에서 API별 패턴(기본 URL, 페이지 매김, 오류, 속도 제한) 및 ADF/스토리지 서식 있는 텍스트 형식이 명시적으로 처리되는 800개 이상의 엔드포인트를 구성합니다. 작업공간 또는 프로젝트 범위에서 .service-accounts.yaml 레코드 + .env 토큰에서 자격 증명을 읽습니다. 토큰 값은 컬에 의해서만 읽히고 인쇄되지 않습니다.
