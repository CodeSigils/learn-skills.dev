단일 마이그레이션 기록에서 둘 이상의 방언(SQLite, PostgreSQL 및 MySQL)을 대상으로 하는 SQLAlchemy 2.x 데이터 계층 위에서 Alembic 데이터베이스 마이그레이션을 실행할 때 사용합니다. env.py / alembic.ini를 모델의 Base.metadata에 연결(환경에서 DB URL 소싱, 짧은 async run_async_migrations 메모를 사용한 동기화 우선), 전체 수정 -> 자동 생성 -> 검토 -> 업그레이드/다운그레이드 워크플로, 분기(기록/현재/헤드/여러 헤드에 대한 병합) 및 로드 베어링 다중 언어 문제를 다룹니다. SQLite는 대부분의 스키마를 변경할 수 없으므로 BATCH로 마이그레이션을 작성합니다. (이동 및 복사) 스타일 — 동일한 Batch_alter_table 코드는 PG/MySQL에서 일반 ALTER를 내보냅니다. 또한 create_all-vs-Alembic 결정과 create_all'd DB의 기준 스탬프 경로를 소유합니다. 다국어, 휴대성, 동기화 우선. SQLAlchemy 모델/엔진 작성(sqlalchemy 참조)이 아니며 작업 대기열/임대 패턴(sql-job-queue 참조)이 아닙니다.
