完成または修正された開発者ガイド (開発者ツール製品 (SDK/ライブラリ/CLI/フレームワーク/API プラットフォーム) の導入と統合の説明) をレビューまたは判断するときに使用します。開発者がガイドだけでツールをインストール、統合、操作できるかどうかを決定します。オーサリングではなくゲートです。単一ソースの 14 条件の採用可能性 + 正確さの基準に照らして判断します。標識付きのスタート地点 + 検証可能な最初の成功。レシピの前にコンセプト。ハウツーでは、引き渡されたシナリオをカバーしています。サンプルは実行可能かつ現在のツールに対して正確です (製造された/古いエンドポイントはありません)。 API 参照にリンクし、決して複製しないでください。ジアタキシスモードの種類。トラブルシューティングのパス。デルタスコープで修正をレビューしました。正確に「評決: 承認|改訂」+実用的な調査結果を出力します。バーを満たすガイドを承認し (細いガイドでは誤った改訂はありません)、指定されたギャップのみを改訂します。エンドユーザーのユーザー ガイド、エンドポイント カタログ (API リファレンス レビュー)、またはエンジニアリング設計ドキュメント (デザイン レビュー) を作成するためではありません。
