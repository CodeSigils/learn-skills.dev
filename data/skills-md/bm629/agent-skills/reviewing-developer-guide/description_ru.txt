Используйте при просмотре или оценке готового или измененного руководства для разработчиков — описание внедрения и интеграции продукта инструмента разработчика (SDK/библиотека/CLI/фреймворк/платформа API). Решает, может ли разработчик установить, интегрировать и использовать инструмент, используя только руководство. Ворота, не авторские. Оценивает его на основе 14 условий из одного источника: приемлемость + планка точности: обозначенное начало + поддающийся проверке первый успех; концепции важнее рецептов; инструкции по рассмотренным сценариям; образцы работоспособны + точны для ТЕКУЩЕГО инструмента (без сфабрикованных/устаревших конечных точек); ССЫЛКИ НА API-ссылку, никогда не дублируют ее; Набраны режимы диатаксиса; путь устранения неполадок; поправка рассмотрена в дельта-области. Выдает именно «ВЕРДИКТ: утвердить|пересмотреть» + выводы, требующие принятия мер; утверждает направляющую, соответствующую планке (без ложных доработок на тонкой), дорабатывает только на поименованный разрыв. Не для его разработки, руководства пользователя для конечного пользователя, каталога конечных точек (справочный обзор API) или документации по инженерному проектированию (обзор дизайна).
