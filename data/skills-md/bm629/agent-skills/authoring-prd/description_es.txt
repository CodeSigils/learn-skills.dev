Úselo al crear un PRD (documento de requisitos de producto) para un proyecto de software o producto, convirtiendo una idea de producto en un documento de requisitos integral y planificable. Guía al productor a través del MÉTODO, no del esquema: fundamentar el problema en evidencia, definir métricas de éxito mensurables, trazar un límite MVP defendible, escribir requisitos comprobables + criterios de aceptación, y sacar a la luz riesgos y preguntas abiertas, hasta una barra desde la cual un ingeniero puede planificar hitos. Se compone de una herramienta de plantilla PRD separada (que proporciona la estructura de la sección) y una capacidad de investigación profunda (para fundamentar cada sección en la idea dada). No para revisar un PRD terminado ni para crear otros tipos de documentos.
