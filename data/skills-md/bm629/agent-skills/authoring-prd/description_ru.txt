Используйте при разработке PRD (документа с требованиями к продукту) для проекта программного обеспечения или продукта — превращая идею продукта в всеобъемлющий, планируемый документ с требованиями. Проводит продюсера через МЕТОД, а не через схему: обосновывает проблему фактами, определяет измеримые показатели успеха, рисует защищаемую границу MVP, записывает тестируемые требования + критерии приемки, выявляет риски и открытые вопросы — до уровня, от которого инженер может планировать основные этапы. Составляется с помощью отдельного инструмента шаблонов PRD (который обеспечивает структуру разделов) и возможностей глубокого исследования (обосновать каждый раздел на заданной идее). Не для просмотра готового PRD и не для создания других типов документов.
