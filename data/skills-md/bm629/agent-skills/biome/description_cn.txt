在使用 Biome 在 JavaScript 或 TypeScript 项目中设置或运行 linting 和格式化时使用 - Biome 是一个快速的 Rust 工具，可对导入进行 lint、格式化和组织导入，替换 ESLint + Prettier 对（Ruff 的 JS 类似物）。涵盖安装 Biome v2、biome.json 配置（格式化程序、linter 规则组、辅助/导入组织操作、VCS 集成、覆盖、monorepo 扩展）、CLI（biome check --write、biome ci for CI）、从 ESLint/Prettier 迁移、v1->v2 增量（例如 --apply 变为 --write）以及将自定义 lint 规则编写为 GritQL 插件。在添加 lint/格式门、编写或修复 biome.json 或移植 ESLint/Prettier 设置时使用。不是 Turborepo 任务接线（用该技能进行组合）。
