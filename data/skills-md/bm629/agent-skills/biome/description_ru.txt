Используйте при настройке или запуске проверки и форматирования в проекте JavaScript или TypeScript с помощью Biome — единственного быстрого инструмента Rust, который проверяет, форматирует и организует импорт, заменяя пару ESLint + Prettier (JS-аналог Ruff). Охватывает установку Biome v2, конфигурацию biome.json (форматер, группы правил линтера, действия по оказанию помощи/организации импорта, интеграцию VCS, переопределения, расширения монорепо), CLI (проверка биома --write, biome ci для CI), миграцию с ESLint/Prettier, дельты v1->v2 (например, --apply стало --write) и создание пользовательских правил lint в виде плагинов GritQL. Используйте при добавлении шлюза lint/format, написании или исправлении biome.json или переносе настройки ESLint/Prettier. Не подключение задач Турборепо (сочинение с этим навыком).
