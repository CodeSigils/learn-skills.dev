استخدمها عند إعداد أو تشغيل الفحص والتنسيق في مشروع JavaScript أو TypeScript باستخدام Biome - أداة Rust السريعة الوحيدة التي تقوم بفحص وتنسيق وتنظيم عمليات الاستيراد، لتحل محل زوج ESLint + Prettier (نظير JS لـ Ruff). يغطي تثبيت Biome v2، وتكوين biome.json (المنسق، ومجموعات قواعد linter، وإجراءات المساعدة/الاستيراد والتنظيم، وتكامل VCS، والتجاوزات، وتمديدات monorepo)، وCLI (فحص biome --write، biome ci for CI)، والترحيل من ESLint/Prettier، ودلتا v1->v2 (على سبيل المثال --apply أصبح --write)، وتأليف قواعد Lint المخصصة مثل GritQL الإضافات. يُستخدم عند إضافة بوابة لينت/تنسيق، أو كتابة أو إصلاح biome.json، أو نقل إعداد ESLint/Prettier. ليست مهمة Turborepo (التأليف بهذه المهارة).
