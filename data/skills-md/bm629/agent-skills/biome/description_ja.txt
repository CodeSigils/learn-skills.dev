Biome を使用して JavaScript または TypeScript プロジェクトでリンティングとフォーマットを設定または実行するときに使用します。Biome は、ESLint + Prettier ペア (Ruff の JS アナログ) を置き換える、リンティング、フォーマット、インポートの整理を行う単一の高速 Rust ツールです。 Biome v2 のインストール、biome.json 設定 (フォーマッタ、リンター ルール グループ、アシスト/インポート整理アクション、VCS 統合、オーバーライド、モノリポ拡張)、CLI (biome check --write、CI の biome ci)、ESLint/Prettier からの移行、v1->v2 デルタ (例: --apply が --write になった)、GritQL としてのカスタム lint ルールの作成について説明します。プラグイン。 lint/format ゲートを追加する場合、biome.json を作成または修正する場合、または ESLint/Prettier セットアップを移植する場合に使用します。ターボレポのタスク配線（そのスキルで構成）ではありません。
