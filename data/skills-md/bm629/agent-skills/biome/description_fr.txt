À utiliser lors de la configuration ou de l'exécution du peluchage et du formatage dans un projet JavaScript ou TypeScript avec Biome - le seul outil Rust rapide qui peluche, formate et organise les importations, remplaçant la paire ESLint + Prettier (l'analogue JS de Ruff). Couvre l'installation de Biome v2, la configuration biome.json (formateur, groupes de règles linter, les actions d'assistance/importation-organisation, l'intégration VCS, les remplacements, les extensions monorepo), la CLI (biome check --write, biome ci pour CI), la migration depuis ESLint/Prettier, les deltas v1->v2 (par exemple --apply est devenu --write) et la création de règles de charpie personnalisées en tant que plugins GritQL. À utiliser lors de l'ajout d'une porte lint/format, de l'écriture ou de la correction d'un biome.json, ou du portage d'une configuration ESLint/Prettier. Pas le câblage des tâches Turborepo (composer avec cette compétence).
