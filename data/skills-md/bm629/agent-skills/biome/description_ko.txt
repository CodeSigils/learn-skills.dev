JavaScript 또는 TypeScript 프로젝트에서 Biome을 사용해 린팅 및 포맷팅을 설정하거나 실행할 때 사용합니다 — 린팅, 포맷팅, import 정리를 한 번에 수행하는 단일 고속 Rust 도구로, ESLint + Prettier 조합을 대체합니다 (Ruff의 JS 유사체). 여기에는 Biome v2 설치, biome.json 설정(포맷터, 린터 규칙 그룹, assist/import‑organize 액션, VCS 연동, 오버라이드, monorepo 확장), CLI(biome check --write, CI용 biome ci), ESLint/Prettier에서 마이그레이션, v1→v2 차이점(예: --apply가 --write로 변경) 및 GritQL 플러그인으로 커스텀 린트 규칙을 작성하는 내용이 포함됩니다. 린트/포맷 게이트를 추가하거나 biome.json을 작성·수정하거나 ESLint/Prettier 설정을 포팅할 때 활용합니다. Turborepo 작업 연결은 포함되지 않으며, 해당 스킬과 함께 구성합니다.
