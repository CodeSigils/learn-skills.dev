使用 Biome 在 JavaScript 或 TypeScript 專案中設定或執行 linting 和格式化時使用 - Biome 是一個快速的 Rust 工具，可對導入進行 lint、格式化和組織導入，取代 ESLint + Prettier 對（Ruff 的 JS 類似物）。涵蓋安裝 Biome v2、biome.json 配置（格式化程式、linter 規則群組、輔助/導入組織操作、VCS 整合、覆蓋、monorepo 擴充功能）、CLI（biome check --write、biome ci for CI）、從 ESLint/Prettier 遷移、v1->v2 增量（例如 --apprit）以及將自 --wint 定義為外掛程式設定為單位。在新增 lint/格式閘、編寫或修復 biome.json 或移植 ESLint/Prettier 設定時使用。不是 Turborepo 任務接線（用該技能進行組合）。
