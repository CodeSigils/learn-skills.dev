在为某个功能或组件编写（或修改）技术设计文档（TDD/工程设计文档/设计 RFC）时使用 - 在现有系统中构建它的详细实现设计。指导生产者通过方法，而不是大纲：将设计植根于既定的设计文档实践和项目的实际约束，双向跟踪每个决策到需求，将至少一个真实的（非稻草人）替代方案与规定的决策标准进行比较，引用架构文档/API规范/数据模型而不是重复它们，命名故障模式，可观察性信号，测试和推出 - 并将已批准的设计修改为版本化的，纹波分析增量——工程师可以在不重新推导设计的情况下实现该功能。由单独的技术设计模板工具（剖面结构）和深度研究能力组成。假设已批准的 PRD + 功能规范作为上游输入 - 绝不是空白页。不适用于系统范围的架构，不适用于 API 合约或数据模式，也不适用于审查已完成的 TDD。
