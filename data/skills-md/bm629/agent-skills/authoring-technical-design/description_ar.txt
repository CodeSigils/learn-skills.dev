يُستخدم عند تأليف (أو تعديل) مستند تصميم فني (TDD / مستند التصميم الهندسي / تصميم RFC) لميزة أو مكون واحد - تصميم التنفيذ التفصيلي لبنائه ضمن نظام موجود. يرشد المنتج من خلال الطريقة، وليس المخطط التفصيلي: ترسيخ التصميم في ممارسة مستند التصميم الراسخة والقيود الحقيقية للمشروع، وتتبع كل قرار ثنائي الاتجاه إلى أحد المتطلبات، ومقارنة بديل حقيقي واحد على الأقل (غير رجل القش) مع معيار قرار محدد، والإشارة إلى مواصفات مستند البنية / واجهة برمجة التطبيقات / نموذج البيانات بدلاً من تكرارها، وتسمية أوضاع الفشل، وإشارات قابلية الملاحظة، والاختبار، والطرح - وتعديل التصميم المعتمد باعتباره دلتا تم تحليلها بالتموج - إلى شريط حيث يمكن للمهندس تنفيذ الميزة دون إعادة اشتقاق التصميم. يتم التأليف باستخدام أداة قالب تصميم فني منفصلة (هيكل القسم) وقدرة على البحث العميق. بافتراض مواصفات ميزات PRD + المعتمدة كمدخل أولي - لا تكون صفحة فارغة أبدًا. ليس للبنية على مستوى النظام، وليس لعقد API أو مخطط البيانات، وليس لمراجعة TDD النهائية.
