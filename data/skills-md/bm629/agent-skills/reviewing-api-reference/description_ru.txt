Используйте при проверке/оценке опубликованной ссылки на API, ориентированной на потребителя, разработчик-интегратор вызывает API, из которого он решает, могут ли они интегрироваться из него. Ворота, не авторские. Судит по единому стандарту из 11 условий: удобство использования + полоса согласованности контракта: начало работы + аутентификация, первый звонок; каждая операция API-спецификации (включая события/веб-перехватчики) документируется с указанием цели + типизированных параметров + проработанный пример + ошибки; ошибки первоклассные; ограничения скорости + нумерация страниц, документированная, где это применимо; указано управление версиями + прекращение поддержки/закрытие; ссылка СООТВЕТСТВУЕТ ПРЕДОСТАВЛЕННОЙ API-спецификации (без дрейфа, без искусственной конечной точки — проверка несущей способности); образцы работоспособны; поправка повторно синхронизируется с измененным контрактом. Выдает именно «ВЕРДИКТ: утвердить|пересмотреть» плюс выводы, требующие принятия мер; утверждает ссылку пропорционального размера, вносит исправления в указанный пробел. Ни его авторство, ни руководство пользователя для конечного пользователя, ни руководство по внедрению разработчиком, ни инженерная спецификация API (обзор API-спецификации).
