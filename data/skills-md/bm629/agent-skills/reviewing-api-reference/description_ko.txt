게시된 소비자 대상 API 참조를 검토/판단할 때 통합 개발자가 API를 호출하여 통합할 수 있는지 결정하는 데 사용합니다. 작성하지 않는 게이트입니다. 단일 소스의 11가지 조건 유용성 + 계약 일관성 기준에 대한 판단: 시작하기 + 인증이 첫 번째 호출에 도달합니다. 모든 API 사양 작업(이벤트/웹후크 포함)은 목적 + 입력된 매개변수 + 실제 예제 + 오류로 문서화됩니다. 일류 오류; 해당하는 경우 속도 제한 + 페이지 매김을 문서화합니다. 버전 관리 + 지원 중단/일시가 명시됨; 참조는 제공된 API 사양과 일치합니다(드리프트 없음, 조작된 엔드포인트 없음 - 내하중 검사). 샘플 실행 가능; 수정안은 변경된 계약에 다시 동기화됩니다. 정확하게 `VERDICT: 승인|수정`과 실행 가능한 결과를 내보냅니다. 비례적인 크기의 참조를 승인하고 명명된 간격을 수정합니다. 최종 사용자 사용자 가이드, 개발자 채택 가이드, 엔지니어링 API 사양(reviewing-api-spec)을 작성하지 않습니다.
