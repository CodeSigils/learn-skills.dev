يُستخدم عند مراجعة/الحكم على مرجع واجهة برمجة التطبيقات (API) المنشور والمواجه للمستهلك، حيث يستدعي المطور المتكامل واجهة برمجة التطبيقات (API) منه - ليقرر ما إذا كان بإمكانه التكامل منها. بوابة وليس التأليف. القضاة ضد قابلية الاستخدام أحادية المصدر المكونة من 11 شرطًا + شريط اتساق العقد: البدء + المصادقة للوصول إلى المكالمة الأولى؛ يتم توثيق كل عملية خاصة بمواصفات واجهة برمجة التطبيقات (بما في ذلك الأحداث/خطافات الويب) بغرض + معلمات مكتوبة + مثال عملي + أخطاء؛ أخطاء من الدرجة الأولى؛ حدود المعدل + ترقيم الصفحات موثق حيثما ينطبق ذلك؛ الإصدار + الإهمال/غروب الشمس المذكور؛ المرجع متوافق مع مواصفات واجهة برمجة التطبيقات (لا يوجد انحراف، ولا توجد نقطة نهاية ملفقة - فحص الحامل)؛ عينات قابلة للتشغيل؛ تعديل يعيد المزامنة مع العقد الذي تم تغييره. يُصدر بالضبط "الحكم: الموافقة على المراجعة" بالإضافة إلى النتائج القابلة للتنفيذ؛ يوافق على مرجع ذو حجم متناسب، ويراجع فجوة محددة. عدم تأليفه، وليس دليل المستخدم النهائي، وليس دليل اعتماد المطور، وليس مواصفات واجهة برمجة التطبيقات الهندسية (مواصفات واجهة برمجة التطبيقات للمراجعة).
