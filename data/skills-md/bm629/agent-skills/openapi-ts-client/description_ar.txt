يُستخدم عند إنشاء أو إعادة إنشاء عميل TypeScript مكتوب من عقد OpenAPI 3.1 - على سبيل المثال FastAPI /openapi.json - مع @hey-api/openapi-ts. يُنتج نماذج مطبوعة، وSDK مكتوبًا (وظيفة واحدة لكل عملية)، وخطافات استعلام TanStack، ومخططات Zod مباشرة من المواصفات، بحيث تظل الواجهة الأمامية متوافقة مع واجهة برمجة التطبيقات (API) بدلاً من العميل المكتوب بخط اليد. يغطي تكوين openapi-ts.config.ts، وعملاء fetch/axios/next، واستعلام tanstack والمكونات الإضافية zod، وسير عمل regenerate-and-drift-check، وإصلاح تسمية عملية FastAPI. يُستخدم عند توصيل واجهة OpenAPI أو FastAPI الخلفية بالواجهة الأمامية TS/React، أو استبدال عميل API الذي يتم صيانته يدويًا، أو إضافة روابط استعلام تم إنشاؤها. ليس برنامجًا تعليميًا لاستخدام استعلام TanStack (قم بالإنشاء بهذه المهارة) وليس تأليف الواجهة الخلفية/مواصفات OpenAPI.
