@hey-api/openapi-ts를 사용하여 OpenAPI 3.1 계약(예: FastAPI /openapi.json)에서 형식화된 TypeScript 클라이언트를 생성하거나 다시 생성할 때 사용합니다. 사양에서 바로 형식화된 모델, 형식화된 SDK(작업당 하나의 함수), TanStack 쿼리 후크 및 Zod 스키마를 생성하므로 프런트엔드는 직접 작성한 클라이언트 대신 API와 고정 단계를 유지합니다. openapi-ts.config.ts 구성, fetch/axios/next 클라이언트, tanstack-query 및 zod 플러그인, 재생성 및 드리프트 확인 워크플로, FastAPI OperationId 명명 수정 사항을 다룹니다. OpenAPI 또는 FastAPI 백엔드를 TS/React 프런트엔드에 연결할 때, 직접 관리하는 API 클라이언트를 교체하거나 생성된 쿼리 후크를 추가할 때 사용합니다. TanStack 쿼리 사용 튜토리얼(해당 기술로 작성)이 아니며 백엔드/OpenAPI 사양 작성이 아닙니다.
