在使用 @hey-api/openapi-ts 从 OpenAPI 3.1 合约（例如 FastAPI /openapi.json）生成或重新生成类型化 TypeScript 客户端时使用。直接根据规范生成类型化模型、类型化 SDK（每个操作一个函数）、TanStack 查询挂钩和 Zod 架构，因此前端与 API 保持同步，而不是手写客户端。涵盖 openapi-ts.config.ts 配置、fetch/axios/next 客户端、tanstack-query 和 zod 插件、重新生成和漂移检查工作流程以及 FastAPI operationId 命名修复。在将 OpenAPI 或 FastAPI 后端连接到 TS/React 前端、替换手动维护的 API 客户端或添加生成的查询挂钩时使用。不是 TanStack 查询使用教程（使用该技能编写），也不是后端/OpenAPI 规范创作。
