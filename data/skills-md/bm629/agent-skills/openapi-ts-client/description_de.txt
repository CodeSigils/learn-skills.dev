Verwenden Sie diese Option, wenn Sie einen typisierten TypeScript-Client aus einem OpenAPI 3.1-Vertrag generieren oder neu generieren – beispielsweise eine FastAPI /openapi.json – mit @hey-api/openapi-ts. Erzeugt typisierte Modelle, ein typisiertes SDK (eine Funktion pro Vorgang), TanStack Query-Hooks und Zod-Schemas direkt aus der Spezifikation, sodass das Frontend im Gleichschritt mit der API bleibt und kein handgeschriebener Client erforderlich ist. Behandelt die openapi-ts.config.ts-Konfiguration, die fetch/axios/next-Clients, die tanstack-query- und zod-Plugins, den Regenerate-and-Drift-Check-Workflow und die FastAPI-OperationId-Benennungskorrektur. Verwenden Sie diese Option, wenn Sie ein OpenAPI- oder FastAPI-Backend mit einem TS/React-Frontend verbinden, einen manuell verwalteten API-Client ersetzen oder generierte Abfrage-Hooks hinzufügen. Kein Tutorial zur Verwendung von TanStack Query (mit dieser Fertigkeit verfassen) und kein Backend-/OpenAPI-Spezifikations-Authoring.
