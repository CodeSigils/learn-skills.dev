Используйте при создании или повторном создании типизированного клиента TypeScript из контракта OpenAPI 3.1 — например, FastAPI /openapi.json — с @hey-api/openapi-ts. Создает типизированные модели, типизированный SDK (одна функция на операцию), перехватчики запросов TanStack и схемы Zod прямо из спецификации, поэтому интерфейс остается синхронизированным с API, а не с написанным вручную клиентом. Охватывает конфигурацию openapi-ts.config.ts, клиенты fetch/axios/next, плагины tanstack-query и zod, рабочий процесс регенерации и проверки смещения, а также исправление именования идентификатора операции FastAPI. Используйте при подключении серверной части OpenAPI или FastAPI к интерфейсу TS/React, замене клиента API, обслуживаемого вручную, или добавлении сгенерированных перехватчиков запросов. Не руководство по использованию TanStack Query (сочинение с этим навыком) и не разработка бэкэнда/спецификаций OpenAPI.
