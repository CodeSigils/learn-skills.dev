@hey-api/openapi-ts を使用して、OpenAPI 3.1 コントラクト (FastAPI /openapi.json など) から型付き TypeScript クライアントを生成または再生成するときに使用します。型付きモデル、型付き SDK (操作ごとに 1 つの関数)、TanStack クエリ フック、および Zod スキーマを仕様から直接生成するため、フロントエンドは手書きのクライアントではなく API と同期した状態を保ちます。 openapi-ts.config.ts 構成、fetch/axios/next クライアント、tanstack-query および zod プラグイン、regenerate-and-drift-check ワークフロー、および FastAPI OperationId 命名修正について説明します。 OpenAPI または FastAPI バックエンドを TS/React フロントエンドに接続する場合、手動で管理する API クライアントを置き換える場合、または生成されたクエリ フックを追加する場合に使用します。 TanStack Query の使用方法のチュートリアル (そのスキルを使用して作成) ではなく、バックエンド/OpenAPI 仕様のオーサリングでもありません。
