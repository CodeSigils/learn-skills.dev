Úselo al generar o regenerar un cliente TypeScript escrito a partir de un contrato OpenAPI 3.1 (por ejemplo, FastAPI /openapi.json) con @hey-api/openapi-ts. Produce modelos escritos, un SDK escrito (una función por operación), enlaces de consulta TanStack y esquemas Zod directamente desde la especificación, por lo que la interfaz permanece sincronizada con la API en lugar de un cliente escrito a mano. Cubre la configuración de openapi-ts.config.ts, los clientes fetch/axios/next, los complementos tanstack-query y zod, el flujo de trabajo de regeneración y verificación de deriva y la corrección de nomenclatura de OperationId de FastAPI. Úselo cuando conecte un backend OpenAPI o FastAPI a un frontend TS/React, reemplace un cliente API mantenido manualmente o agregue enlaces de consulta generados. No es un tutorial de uso de TanStack Query (componga con esa habilidad) ni tampoco creación de backend/especificaciones OpenAPI.
