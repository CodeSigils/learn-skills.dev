在使用 @hey-api/openapi-ts 從 OpenAPI 3.1 合約（例如 FastAPI /openapi.json）產生或重新產生類型化 TypeScript 用戶端時使用。直接根據規格產生類型化模型、類型化 SDK（每個操作一個函數）、TanStack 查詢掛鉤和 Zod 架構，因此前端與 API 保持同步，而不是手寫客戶端。涵蓋 openapi-ts.config.ts 設定、fetch/axios/next 用戶端、tanstack-query 和 zod 外掛程式、重新產生和漂移檢查工作流程以及 FastAPI operationId 命名修復。在將 OpenAPI 或 FastAPI 後端連接到 TS/React 前端、取代手動維護的 API 用戶端或新增產生的查詢掛鉤時使用。不是 TanStack 查詢使用教學（使用該技能編寫），也不是後端/OpenAPI 規範創作。
