يُستخدم عند تعريف البيانات أو التحقق من صحتها أو تسلسلها أو تكوينها باستخدام Pydantic v2 في Python - BaseModel، وقيود الحقل، ومدققات الحقل/النموذج، وتسلسل model_dump، وإعدادات pydantic، وTypeAdapter، والتعدادات، والحرفية، والاتحادات المميزة - أو عند إصلاح التعليمات البرمجية التي لا تزال تستخدم مصطلحات عصر v1 (class Config، .dict()/.json()، @validator). يُنتج كود Pydantic v2 الحالي الصحيح والاصطلاحي. الكلمات الرئيسية: pydantic، BaseModel، ConfigDict، model_validate، validator، settings.
