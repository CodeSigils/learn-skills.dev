استخدمها عند إعداد خطافات Git لمشروع متعدد اللغات أو monorepo باستخدام Lefthook - توصيل سريع للتنسيق/فحص الوبر على الملفات المرحلية عند الالتزام المسبق وبوابات فحص النوع/الاختبار الأبطأ عند الدفع المسبق، عبر أشجار فرعية مختلطة اللغات (مثل TypeScript وPython) من ملف lefthook.yml واحد، بالتوازي. يغطي التثبيت + التنشيط، ومخطط lefthook.yml (الأوامر/الوظائف، والكرة الأرضية، والجذر، والتشغيل باستخدام {staged_files}/{push_files}، وstage_fixed، والتخطي/فقط، والتوازي)، ومثال عملي متعدد اللغات، وتقسيم العمل بين الخطافات مقابل CI، وتجاوز --no-verify. يعلم الأسلاك هوك. يشير إلى المهارات الخاصة بكل أداة (biome، ruff، ty، typescript-typecheck) وturborepo بدلاً من إعادة تدريسها. الكلمات الرئيسية: خطافات git، الالتزام المسبق، الدفع المسبق، الخطاف الأيسر، الملفات المرحلية، خطافات monorepo، تنسيق الوبر متعدد اللغات.
