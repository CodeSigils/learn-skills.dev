Используйте при настройке перехватчиков Git для проекта полиглота или монорепозитория с помощью Lefthook — подключение быстрых проверок формата/lint для промежуточных файлов при предварительной фиксации и более медленных шлюзов проверки/тестирования типов при предварительной отправке, через поддеревья на разных языках (например, TypeScript и Python) из одного lefthook.yml, параллельно. Охватывает установку + активацию, схему lefthook.yml (команды/задания, glob, root, запуск с {staged_files}/{push_files}, stage_fixed, Skip/only, Parallel), настоящий полиглотный пример, разделение труда перехватчиков и CI и обход --no-verify. Обучает проводке крючка; ссылается на навыки каждого инструмента (биом, ерш, тай, машинопись-проверка текста) и турборепо, а не на их повторное обучение. Ключевые слова: git-хуки, pre-commit, pre-push, lefthook, промежуточные файлы, перехватчики монорепо, формат полиглотского lint.
