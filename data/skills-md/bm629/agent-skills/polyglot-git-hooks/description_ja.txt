Lefthook を使用してポリグロットまたはモノリポ プロジェクトの Git フックをセットアップするときに使用します。単一の lefthook.yml から、混合言語のサブツリー (TypeScript や Python など) にわたって、コミット前のステージングされたファイルに対する高速なフォーマット/lint チェックと、プッシュ前の低速な型チェック/テスト ゲートを並行して配線します。インストールとアクティベーション、lefthook.yml スキーマ (コマンド/ジョブ、グロブ、ルート、{staged_files}/{push_files} で実行、stage_fixed、スキップ/のみ、並列)、真に多言語で動作する例、フックと CI の分業、および --no-verify バイパスについて説明します。フックの配線を教えます。ツールごとのスキル (biome、ruff、ty、typescript-typecheck) と Turborepo を再教育するのではなく参照します。キーワード: git フック、事前コミット、事前プッシュ、左フック、ステージングされたファイル、モノレポ フック、ポリグロット lint 形式。
