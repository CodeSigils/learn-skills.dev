Verwenden Sie diese Option, wenn Sie Git-Hooks für ein polyglottes oder monorepo-Projekt mit Lefthook einrichten – schnelle Format-/Lint-Prüfungen für bereitgestellte Dateien beim Pre-Commit und langsamere Typprüfung/Test-Gates beim Pre-Push über gemischtsprachige Teilbäume (z. B. TypeScript und Python) aus einer einzigen lefthook.yml parallel. Behandelt die Installation + Aktivierung, das lefthook.yml-Schema (Befehle/Jobs, Glob, Root, Ausführen mit {staged_files}/{push_files}, stage_fixed, skip/only, parallel), ein wirklich polyglottes Beispiel, die Arbeitsteilung zwischen Hooks und CI und die Umgehung von --no-verify. Erlernt die Hakenverkabelung; verweist auf die pro-Tool-Fähigkeiten (Biome, Ruff, Ty, Typescript-Typecheck) und Turborepo, anstatt sie erneut zu unterrichten. Schlüsselwörter: Git-Hooks, Pre-Commit, Pre-Push, Lefthook, bereitgestellte Dateien, Monorepo-Hooks, polyglottes Lint-Format.
