使用 Lefthook 為多語言或單一倉庫專案設定 Git 掛鉤時使用 - 在預先提交時對暫存檔案進行快速格式/lint 檢查，並在預推送時從單一 lefthook.yml 跨混合語言子樹（例如 TypeScript 和 Python）並行連接較慢的類型檢查/測試門。涵蓋安裝 + 啟動、lefthook.yml 架構（命令/作業、glob、root、使用 {staged_files}/{push_files} 運行、stage_fixed、skip/only、並行）、真正的多語言工作範例、hooks-vs-CI 分工以及 --no-verify 繞過。教導掛鉤接線；參考每個工具的技能（biome、ruff、ty、typescript-typecheck）和turborepo，而不是重新教導它們。關鍵字：git hooks、預先提交、預先推播、lefthook、暫存檔案、monorepo hooks、多語言 lint 格式。
