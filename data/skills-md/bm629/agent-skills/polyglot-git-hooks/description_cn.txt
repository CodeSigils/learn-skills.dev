使用 Lefthook 为多语言或单一仓库项目设置 Git 挂钩时使用 - 在预提交时对暂存文件进行快速格式/lint 检查，并在预推送时从单个 lefthook.yml 跨混合语言子树（例如 TypeScript 和 Python）并行连接较慢的类型检查/测试门。涵盖安装 + 激活、lefthook.yml 架构（命令/作业、glob、root、使用 {staged_files}/{push_files} 运行、stage_fixed、skip/only、并行）、真正的多语言工作示例、hooks-vs-CI 分工以及 --no-verify 绕过。教导挂钩接线；参考每个工具的技能（biome、ruff、ty、typescript-typecheck）和turborepo，而不是重新教授它们。关键词：git hooks、预提交、预推送、lefthook、暂存文件、monorepo hooks、多语言 lint 格式。
