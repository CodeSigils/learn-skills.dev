Lefthook을 사용하여 다중 언어 또는 단일 저장소 프로젝트에 대한 Git 후크를 설정할 때 사용합니다. 단일 lefthook.yml에서 혼합 언어 하위 트리(예: TypeScript 및 Python) 전체에 걸쳐 사전 커밋에서 준비된 파일에 대한 빠른 형식/린트 검사를 연결하고 사전 푸시에서 느린 유형 검사/테스트 게이트를 병렬로 연결합니다. 설치 + 활성화, lefthook.yml 스키마(명령/작업, glob, 루트, {staged_files}/{push_files}로 실행, stage_fixed, 건너뛰기/전용, 병렬), 진정한 다중 언어 작업 예제, Hooks-vs-CI 작업 분할 및 --no-verify 우회를 다룹니다. 후크 배선을 가르칩니다. 다시 가르치기보다는 도구별 기술(biome, ruff, ty, typescript-typecheck) 및 터보레포를 참조합니다. 키워드: git 후크, 사전 커밋, 사전 푸시, lefthook, 준비된 파일, 모노레포 후크, 다중 언어 린트 형식.
