استخدمه عند تأليف دليل المستخدم النهائي - المساعدة التي يواجهها المستهلك الشخص (غير الفني عادةً) الذي يستخدم منتجًا يقرأ لتحقيق أهدافه: برنامج تعليمي للبدء، وأدلة إرشادية موجهة نحو المهام، وشرح مفاهيمي، وميزة المستخدم النهائي/مرجع التكوين (الميزات، والإعدادات، وأوامر CLI - وليس HTTP API)، واستكشاف الأخطاء وإصلاحها/الأسئلة الشائعة. يوجه الطريقة، وليس المخطط التفصيلي: استخلاص طريقة واحدة لكل هدف مستخدم من المنبع الذي تم تسليمه (لا يخترع خطوات أبدًا)، والحفاظ على أوضاع Diataxis الأربعة متميزة، والحفاظ على دقة كل خطوة لسلوك المنتج الفعلي. يتم الإنشاء باستخدام أداة قالب دليل مستخدم منفصلة (والتي توفر بنية القسم) والقدرة على البحث. تفترض المستندات الأولية التي تم تسليمها (عادةً مواصفات الميزات + تدفقات المستخدم + الإطارات السلكية) - لا تكون أبدًا صفحة فارغة. ليس لسرد اعتماد أداة المطور (دليل مطور منفصل)، وليس لكتالوج نقطة نهاية HTTP/SDK (مرجع منفصل لواجهة برمجة التطبيقات)، وليس لمراجعة دليل المستخدم النهائي.
