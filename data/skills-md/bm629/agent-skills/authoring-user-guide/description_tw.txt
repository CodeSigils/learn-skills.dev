在編寫最終使用者指南時使用 - 面向消費者的幫助（通常是非技術人員）使用產品的人員閱讀以實現他們的目標：入門教程、面向任務的操作指南、概念解釋、最終用戶功能/配置參考（功能、設定、CLI 命令 - 而不是 HTTP API）以及故障排除/常見問題解答。指導方法，而不是大綱：從上交的上游導出每個使用者的操作目標（從不發明步驟），保持四種 Diataxis 模式的獨特性，並使每一步都準確地反映實際的產品行為。由單獨的使用者指南範本工具（提供部分結構）和研究功能組成。假設提交的上游文件（通常是功能規格+使用者流程+線框）－絕不是空白頁面。不適用於開發人員工具採用敘述（單獨的開發人員指南），不適用於 HTTP/SDK 端點目錄（單獨的 api 參考），也不適用於查看完成的使用者指南。
