Используется при оценке НАБОРА готовых проектных документов как одного корпуса, чтобы решить, являются ли они взаимно согласованными и готовы ли к планированию — аналог на уровне корпуса анализа проекта одного документа. Предполагается, что каждый документ прошел свои ворота; оценивает только то, как они связаны, по восьмимерной шкале: согласованность между документами (включая одно имя на объект); полнота/отслеживаемость самого исходного документа (отсутствие потерянных/потерянных элементов или TBD); противоречия; целостность зависимостей; дивергентное дублирование; Достаточность готового плана (Определение готовности + документ, на который есть ссылка, но отсутствует); внесение поправок/повторное рассмотрение с учетом дельты при изменении документа (влияние на его зависимые элементы); и перекос версий (документ, цитирующий устаревшую версию другого). Выдает ровно один терминал `VERDICT: Approval|Revise` для всего набора, причем каждый результат имеет префикс с идентификатором(ами) затронутого документа. Утверждает связный корпус (без ложных исправлений); вносит изменения только в случае реального, названного разрыва между документами. Ни за внутреннее качество одного документа, ни за его авторство или исправление.
