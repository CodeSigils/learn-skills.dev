완성된 프로젝트 문서 세트를 하나의 코퍼스로 판단할 때 문서가 상호 일관성이 있고 계획할 준비가 되었는지 여부(단일 문서 설계 검토의 코퍼스 수준 아날로그)를 결정하는 데 사용합니다. 각 문서가 자체 게이트를 통과했다고 가정합니다. 8차원 기준: 문서 간 일관성(엔티티당 하나의 이름 포함)을 기준으로 이들이 어떻게 관련되어 있는지 판단합니다. 최상류 문서의 완전성/추적성(삭제/고아 항목 또는 TBD 없음) 모순; 의존성 무결성; 다양한 복제; 즉시 계획이 가능한 충분성(준비의 정의 + 참조되었으나 부재한 문서) 문서가 변경되면 수정/델타 범위 재검토(종속 문서에 파급) 및 버전 왜곡(다른 버전의 오래된 버전을 인용하는 문서). 전체 집합에 대해 정확히 하나의 터미널 `VERDICT: 승인|수정`을 내보냅니다. 각 결과에는 영향을 받은 문서 ID가 앞에 붙습니다. 일관된 자료를 승인합니다(허위 수정 없음). 실제 명명된 문서 간 간격에 대해서만 수정합니다. 한 문서의 내부 품질을 위한 것도 아니고 문서를 작성하거나 수정하는 것도 아닙니다.
