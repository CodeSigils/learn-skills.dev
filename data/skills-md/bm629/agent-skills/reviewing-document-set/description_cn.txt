在将一组已完成的项目文档判断为一个语料库时使用，以确定它们是否相互一致并准备好进行计划 - 单文档设计审查的语料库级别模拟。假设每个文档都通过了自己的大门；仅根据八维条判断它们之间的关系：跨文档一致性（包括每个实体一个名称）；最上游文档的完整性/可追溯性（无丢弃/孤立项目或 TBD）；矛盾；依赖性完整性；不同的重复；准备好计划的充分性（准备好定义+引用但不存在的文档）；当文档更改时修改/增量范围的重新审查（对其依赖者产生影响）；和版本偏差（一个文档引用了另一个文档的过时版本）。为整个集合发出一个终端“VERDICT：批准|修订”，每个结果都以受影响的文档 ID 为前缀。批准一个连贯的语料库（无错误修改）；仅针对真实的、命名的跨文档间隙进行修改。不是为了一份文档的内部质量，也不是为了创作或修复它们。
