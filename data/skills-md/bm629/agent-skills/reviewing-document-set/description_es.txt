Úselo al juzgar un CONJUNTO de documentos de proyecto terminados como un corpus, para decidir si son mutuamente coherentes y están listos para planificar: el análogo a nivel de corpus de una revisión de diseño de un solo documento. Se supone que cada documento pasó por su propia puerta; juzga sólo cómo se relacionan, frente a una barra de ocho dimensiones: coherencia entre documentos (incluido un nombre por entidad); integridad/trazabilidad desde el documento más ascendente (sin elementos descartados/huérfanos ni TBD); contradicciones; integridad de la dependencia; duplicación divergente; suficiencia lista para planificar (Definición de Listo + un documento referenciado pero ausente); modificar o volver a revisar el ámbito delta cuando un documento cambia (se propaga a sus dependientes); y version-skew (un documento que cita una versión obsoleta de otro). Emite exactamente una terminal `VEREDICTO: aprobar|revisar` para todo el conjunto, cada hallazgo tiene el prefijo de la(s) identificación(es) del documento afectado. Aprueba un corpus coherente (sin falsas revisiones); revisa sólo una brecha real entre documentos con nombre. No por la calidad interna de un documento, ni por su creación o corrección.
