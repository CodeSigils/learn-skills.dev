TypeScript 코드베이스에서 TSDoc 문서 주석을 작성하거나 검토할 때 사용합니다. 이는 TypeDoc, API 추출기 및 편집기가 구문 분석하는 표준화된 /** ... */ 주석 문법(Microsoft의 @microsoft/tsdoc)입니다. 문서화할 내용(내보낸/공개 표면: 함수, 클래스, 유형, React 구성 요소 + 소품, 후크)과 건너뛸 내용(비공개/내부, 생성된 코드, 사소한 사례, 유형을 다시 기술하는 산문)을 다룹니다. 블록 태그(@param, @returns, @remarks, @example, @defaultValue, @typeParam, @see, @throws, @deprecated), 인라인 태그({@link}, {@inheritDoc}, {@label}) 및 수정자 태그(@public, @internal, @beta, @alpha, @readonly, @override)로 분류된 태그 분류 체계 summary-then-@remarks 구조; 그리고 주요 TSDoc-vs-JSDoc 규칙 — 주석(TS 유형에 이미 있음), 문서 의도/동작에서 유형을 반복하지 마십시오. 문서 주석 규칙을 설정하거나 문서화할 대상/방법을 결정하거나 TS에서 JSDoc 스타일 유형 주석을 수정할 때 사용합니다. 시행은 기본적으로 규칙에만 적용됩니다. eslint-plugin-tsdoc는 선택적 CI 포인터입니다. TypeDoc 사이트 또는 Storybook 설정이 아닙니다(포인터만 해당).
