TypeScript コードベースで TSDoc ドキュメント コメントを作成またはレビューするときに使用します。これは、TypeDoc、API Extractor、およびエディターが解析する標準化された /** ... */ コメント文法 (Microsoft の @microsoft/tsdoc) です。文書化すべきもの (エクスポート/パブリックの表面: 関数、クラス、型、React コンポーネント + 小道具、フック) とスキップすべきもの (プライベート/内部、生成されたコード、簡単なケース、型を再説明する散文) をカバーします。タグ分類は、ブロック タグ (@param、@returns、@remarks、@example、@defaultValue、@typeParam、@see、@throws、@deprecated)、インライン タグ ({@link}、{@inheritDoc}、{@label})、および修飾子タグ (@public、@internal、@beta、@alpha、@readonly、@override) に分類されます。 summary-then-@remarks 構造。そして重要な TSDoc-vs-JSDoc ルール — コメント内でタイプを繰り返さないでください (TS タイプにはすでにそれらが含まれています)。意図/動作を文書化します。ドキュメントコメント規則を確立する場合、何を/どのようにドキュメント化するかを決定する場合、または TS で JSDoc スタイルの型アノテーションを修正する場合に使用します。デフォルトでは、施行は規約のみです。 eslint-plugin-tsdoc はオプションの CI ポインターです。 TypeDoc サイトまたは Storybook セットアップではありません (ポインターのみ)。
