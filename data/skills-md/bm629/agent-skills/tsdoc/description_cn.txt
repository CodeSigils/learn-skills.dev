在 TypeScript 代码库上编写或查看 TSDoc 文档注释时使用 - TypeDoc、API Extractor 和编辑器解析的标准化 /** ... */ 注释语法（Microsoft 的 @microsoft/tsdoc）。涵盖要记录的内容（导出的/公共的表面：函数、类、类型、React 组件 + props、钩子）与要跳过的内容（私有/内部、生成的代码、琐碎的案例、重述类型的散文）；标签分类法分为块标签（@param、@returns、@remarks、@example、@defaultValue、@typeParam、@see、@throws、@deprecated）、内联标签（{@link}、{@inheritDoc}、{@label}）和修饰符标签（@public、@internal、@beta、@alpha、@readonly、@override）； “summary-then-@remarks”结构；以及关键的 TSDoc-vs-JSDoc 规则——不要在注释中重复类型（TS 类型已经有它们）、文档意图/行为。在建立文档注释约定、决定记录内容/如何记录或修复 TS 中的 JSDoc 样式类型注释时使用。默认情况下，强制执行仅限于约定； eslint-plugin-tsdoc 是一个可选的 CI 指针。不是 TypeDoc 站点或 Storybook 设置（仅限指针）。
