استخدمه عند كتابة أو مراجعة تعليقات مستند TSDoc على قاعدة تعليمات TypeScript — القواعد النحوية القياسية للتعليقات /** ... */ (Microsoft @microsoft/tsdoc) التي يقوم TypeDoc وAPI Extractor والمحررون بتحليلها. يغطي ما يجب توثيقه (السطح المُصدَّر/العام: الوظائف، والفئات، والأنواع، ومكونات React + الدعائم، والخطافات) مقابل ما يجب تخطيه (الخاص/الداخلي، والتعليمات البرمجية المولدة، والحالات التافهة، والنثر الذي يعيد صياغة النوع)؛ تصنيف العلامات مقسم إلى علامات كتلة (@param، @returns، @remarks، @example، @defaultValue، @typeParam، @see، @throws، @deprecated)، والعلامات المضمنة ({@link}، {@inheritDoc}، {@label})، وعلامات التعديل (@public، @internal، @beta، @alpha، @readonly، @override)؛ بنية الملخص-ثم-@remarks؛ وقاعدة TSDoc-vs-JSDoc الرئيسية — لا تكرر الأنواع في التعليقات (أنواع TS تحتوي عليها بالفعل)، وقصد/سلوك المستند. يُستخدم عند إنشاء اتفاقية تعليق مستند، أو تحديد ما/كيفية التوثيق، أو إصلاح التعليقات التوضيحية من نوع JSDoc في TS. يتم التنفيذ بشكل افتراضي فقط؛ eslint-plugin-tsdoc هو مؤشر CI اختياري. ليس موقع TypeDoc أو إعداد Storybook (المؤشرات فقط).
