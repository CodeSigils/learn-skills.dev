استخدمه عندما تحتاج إلى تقليل استخدام الرمز المميز، أو خفض تكلفة واجهة برمجة التطبيقات (API)، أو ملاءمة العمل ضمن نافذة السياق، أو تسريع حلقة وكيل مكلفة/بطيئة. تشغيل عبارات مثل "تحسين الرموز المميزة"، و"تقليل استخدام الرمز المميز"، و"توفير التكلفة"، و"الملاءمة في السياق"، و"السياق طويل جدًا"، و"نفاد الرموز المميزة"، و"التخزين المؤقت السريع"، و"ضغط السياق"، و"الوكيل مكلف للغاية"، و"تقليص الموجه"، و"نموذج أرخص"، و"الرموز المميزة لكل مهمة". يوفر كتالوج تكتيكي متعدد الطبقات - القياس (العد الإرشادي وتخصيص الميزانية)، وأذرع الجانب السريع (التخزين المؤقت، والنظام الغذائي الفوري للنظام، وتشذيب تعريف الأداة)، وإدارة السياق (الضغط، وإخفاء المراقبة، وتفريغ نظام الملفات)، وأنماط حلقة الوكيل (استدعاءات الأدوات المتوازية، والعمليات المجمعة، وتوجيه النموذج حسب التعقيد)، وعناصر التحكم في جانب الإخراج (طبقات العمق، وتسلسلات التوقف، والإخراج المنظم). ملحد المشروع وملاحدة مقدم الخدمة؛ يعمل عبر Claude Code وCodex CLI وCursor وGemini CLI وCopilot.
