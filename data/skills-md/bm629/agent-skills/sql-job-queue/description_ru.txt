Используйте при построении очереди заданий/планировщика задач на базе БД в SQLAlchemy 2.x, готовность которого зависит от зависимостей, задания выполняются долго и с отслеживанием состояния, а единственной надежной основой является реляционная БД — единый блок, встраиваемый, без брокера, многодиалектный (SQLite/PostgreSQL/MySQL). Охватывает общую модель jobs/job_deps, готовый запрос, атомарную аренду для каждого диалекта (FOR UPDATE SKIP LOCKED в PostgreSQL + MySQL 8 против BEGIN IMMEDIATE в SQLite, с обнаружением диалекта), возобновление сбоя через тактовый сигнал + истечение срока аренды + возврат устаревшей аренды, тайм-аут «завис, но активен» для каждой отправки, взвешенное справедливое распределение по group_key, цикл сканирования → ранг → аренда → отправка → сохранение → восстановление тиков, опрос против пробуждения LISTEN/NOTIFY и контракт идемпотентности хотя бы один раз. Ключевые слова: очередь заданий, планировщик задач, готовый набор, SKIP LOCKED, аренда, аварийное возобновление, мультидиалект, SQLAlchemy, фоновые задания. Сначала синхронизация. Ни уровень данных SQLAlchemy, ни примитив блокировки (sqlalchemy), ни миграции (перегонный куб).
