在 SQLAlchemy 2.x 上构建数据库支持的作业队列/任务调度程序时使用，其准备情况是依赖驱动的，其作业是长时间运行和有状态的，其唯一持久的基础是关系数据库 - 单盒、可嵌入、无代理、多方言（SQLite / PostgreSQL / MySQL）。涵盖通用 jobs/job_deps 模型、ready-set 查询、每个方言原子租约（对于 PostgreSQL + MySQL 8 上的 UPDATE SKIP LOCKED 与 SQLite 上的 BEGIN IMMEDIATE，带有方言检测）、通过心跳的崩溃恢复 + 租约到期 + 陈旧租约回收、挂起但活动的每次调度超时、group_key 上的加权公平共享、扫描→排序→租赁→调度→持久→回收滴答循环，轮询与LISTEN/NOTIFY唤醒，以及至少一次幂等性合约。关键词：作业队列、任务调度程序、就绪集、SKIP LOCKED、租约、崩溃恢复、多方言、SQLAlchemy、后台作业。同步优先。不是 SQLAlchemy 数据层或锁定原语 (sqlalchemy)，也不是迁移 (alembic)。
