在 SQLAlchemy 2.x 上建立資料庫支援的作業佇列/任務排程器時使用，其準備情況是依賴驅動的，其作業是長時間運行且有狀態的，其唯一持久的基礎是關聯式資料庫 - 單盒、可嵌入、無代理、多方言（SQLite / PostgreSQL / MySQL）。涵蓋通用 jobs/job_deps 模型、ready-set 查詢、每個方言原子租約（對於 PostgreSQL + MySQL 8 上的 UPDATE SKIP LOCKED 與 SQLite 上的 BEGIN IMMEDIATE，帶有陳舊檢測）、透過心跳的崩潰方言恢復 + 租約到期 + 陳年租約到期時但陳舊活動的崩潰、group_group_group_groups）上的加權公平共享、掃描→排序→租賃→調度→持久→回收滴答循環，輪詢與LISTEN/NOTIFY喚醒，以及至少一次冪等性合約。關鍵字：作業佇列、任務排程器、就緒集、SKIP LOCKED、租約、崩潰復原、多方言、SQLAlchemy、後台作業。同步優先。不是 SQLAlchemy 資料層或鎖定原語 (sqlalchemy)，也不是遷移 (alembic)。
