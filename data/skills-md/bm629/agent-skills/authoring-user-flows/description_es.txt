Úselo al crear un documento de flujos de usuarios: el mapa de las rutas que sigue un usuario a través de un producto para lograr cada objetivo: puntos de entrada, el camino feliz, las ramas de decisión, las rutas de error/recuperación, las pantallas/estados atravesados ​​y los criterios de éxito, cada flujo se remonta a un objetivo/persona del producto. Guía el MÉTODO, no el esquema: derivar flujos de objetivos ascendentes + personas (nunca inventarlos), enumerar cada rama y ruta de error para que no haya callejones sin salida y representar cada flujo como un diagrama sincronizado + narrativa numerada. Se compone de una herramienta de plantilla de flujos de usuario separada (que proporciona la estructura de la sección) y una capacidad de investigación. Asume un PRD aprobado como entrada inicial, nunca una página en blanco. No para revisar un documento de flujos de usuario terminado, ni para el diseño de pantalla/estructuras alámbricas, ni para crear el PRD en sí.
