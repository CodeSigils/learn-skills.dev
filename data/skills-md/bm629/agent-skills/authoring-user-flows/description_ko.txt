사용자 흐름 문서를 작성할 때 사용합니다. 각 목표를 달성하기 위해 사용자가 제품을 통해 취하는 경로 맵(진입 지점, 행복한 경로, 결정 분기, 오류/복구 경로, 통과한 화면/상태 및 성공 기준), 각 흐름은 제품 목표/페르소나로 추적됩니다. 개요가 아닌 방법을 안내합니다. 업스트림 목표 + 페르소나(절대로 발명하지 않음)에서 흐름을 파생하고, 막다른 경로가 없도록 모든 분기 및 오류 경로를 열거하고, 각 흐름을 동기화된 다이어그램 + 번호가 매겨진 내러티브로 렌더링합니다. 별도의 사용자 흐름 템플릿 도구(섹션 구조 제공)와 연구 기능으로 구성됩니다. 승인된 PRD를 업스트림 입력으로 가정합니다. 결코 빈 페이지가 아닙니다. 완성된 사용자 흐름 문서를 검토하거나 화면 레이아웃/와이어프레임을 검토하거나 PRD 자체를 작성하기 위한 것이 아닙니다.
