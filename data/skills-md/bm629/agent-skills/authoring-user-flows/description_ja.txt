ユーザー フロー ドキュメントを作成するときに使用します。これは、各目標を達成するためにユーザーが製品を通過するパスのマップです。エントリ ポイント、ハッピー パス、意思決定の分岐、エラー/回復パス、通過する画面/状態、成功基準など、各フローは製品の目標/ペルソナまで遡ります。概要ではなく方法をガイドします。上流の目標とペルソナからフローを導出し (決して発明しない)、パスの行き止まりがないようにすべての分岐とエラー パスを列挙し、各フローを同期した図と番号付きの物語としてレンダリングします。別個のユーザー フロー テンプレート ツール (セクション構造を提供) と調査機能で構成されます。承認された PRD が上流入力として想定されます。空白ページは決してありません。完成したユーザーフロードキュメントをレビューするためではなく、画面レイアウト/ワイヤーフレームをレビューするためでも、PRD 自体をオーサリングするためでもありません。
