استخدمها عند تأليف مستند تدفقات المستخدم - خريطة المسارات التي يسلكها المستخدم عبر المنتج لتحقيق كل هدف: نقاط الدخول، والمسار السعيد، وفروع القرار، ومسارات الخطأ/الاسترداد، والشاشات/الحالات التي تم اجتيازها، ومعايير النجاح، حيث يتم تتبع كل تدفق إلى هدف/شخصية المنتج. يوجه الطريقة، وليس المخطط التفصيلي: استخلاص التدفقات من الأهداف الأولية + الشخصيات (لا تخترعها أبدًا)، وتعداد كل فرع ومسار خطأ حتى لا يكون هناك طريق مسدود، وتقديم كل تدفق كمخطط متزامن + سرد مرقم. يتم التأليف باستخدام أداة قالب تدفقات المستخدم المنفصلة (التي توفر بنية القسم) والقدرة على البحث. يفترض أن PRD معتمد كمدخل أولي - لا توجد صفحة فارغة أبدًا. ليس لمراجعة مستند تدفقات المستخدم النهائي، وليس لتخطيط الشاشة/الإطارات السلكية، وليس لتأليف PRD نفسه.
