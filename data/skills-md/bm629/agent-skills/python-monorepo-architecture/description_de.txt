Verwenden Sie es, wenn Sie ein Python-Repository in ein UV-Workspace-Monorepo mit mehreren Paketen entwerfen oder aufteilen – eine gemeinsam genutzte interne Bibliothek plus eine oder mehrere davon abhängige App- oder CLI-Mitglieder – und Sie benötigen die richtigen Paketgrenzen: Welcher Code wird zu einer gemeinsam genutzten Bibliothek im Vergleich zu einem App-Mitglied, die azyklische nach innen gerichtete Abhängigkeitsrichtung (Apps hängen von der Kernbibliothek ab, niemals voneinander), die Importisolationsdisziplin, die UV nicht erzwingen kann, die öffentliche API jedes Mitglieds an der Paketgrenze, mitgliederübergreifender Test Layout und sicheres Extrahieren von gemeinsam genutztem Code aus einem vorhandenen Paket. Behandelt die Verkabelung des UV-Arbeitsbereichs (Mitglieder, tool.uv.sources, einzelne Sperrdatei, --package) und erstellt mit den Fähigkeiten UV und Python-Projektstruktur. Schlüsselwörter: Monorepo, UV-Arbeitsbereich, Multipaket, gemeinsam genutzte Bibliothek, Paketgrenzen, Abhängigkeitsrichtung, zirkulärer Import, Import-Linter.
