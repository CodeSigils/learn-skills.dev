يُستخدم عند تصميم أو تقسيم مستودع Python إلى monorepo لمساحة عمل uv متعددة الحزم - مكتبة داخلية مشتركة بالإضافة إلى تطبيق واحد أو أكثر أو أعضاء CLI يعتمدون عليها - وتحتاج إلى حدود الحزم المشتركة بشكل صحيح: أي كود يصبح lib مشتركًا مقابل عضو تطبيق، واتجاه التبعية غير الدوري الذي يعتمد على الداخل (تعتمد التطبيقات على lib الأساسي، وليس على بعضها البعض أبدًا)، ولا يمكن لـ uv فرض نظام عزل الاستيراد، وواجهة برمجة التطبيقات العامة لكل عضو عند حدود الحزمة، تخطيط اختبار عبر الأعضاء، واستخراج التعليمات البرمجية المشتركة بأمان من الحزمة الموجودة. يغطي أسلاك مساحة عمل الأشعة فوق البنفسجية (الأعضاء، Tool.uv.sources، ملف قفل واحد، --package) ويؤلف باستخدام مهارات هيكل مشروع الأشعة فوق البنفسجية والبايثون. الكلمات المفتاحية: monorepo، مساحة عمل uv، الحزم المتعددة، المكتبة المشتركة، حدود الحزمة، اتجاه التبعية، الاستيراد الدائري، import-linter.
