Используйте при проектировании или разделении репозитория Python на монорепозиторий uv-workspace с несколькими пакетами — общую внутреннюю библиотеку плюс одно или несколько приложений или элементов CLI, которые зависят от нее — и вам нужны правильные границы между пакетами: какой код становится общей библиотекой, а не членом приложения, направление ациклической зависимости внутрь (приложения зависят от основной библиотеки, а не друг от друга), дисциплина изоляции импорта, которую uv не может обеспечить, публичный API каждого члена на границе пакета, макет теста между участниками, и безопасное извлечение общего кода из существующего пакета. Охватывает проводку рабочего пространства uv (члены,tool.uv.sources, один файл блокировки, --package) и компонует с использованием навыков uv и python-project-structure. Ключевые слова: монорепозиторий, рабочее пространство uv, мультипакет, общая библиотека, границы пакета, направление зависимости, циклический импорт, import-linter.
