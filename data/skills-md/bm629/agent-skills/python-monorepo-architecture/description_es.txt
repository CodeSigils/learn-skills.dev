Úselo al diseñar o dividir un repositorio de Python en un monorepo de espacio de trabajo uv de paquetes múltiples (una biblioteca interna compartida más una o más aplicaciones o miembros de CLI que dependen de ella) y necesita los límites entre paquetes correctos: qué código se convierte en una biblioteca compartida frente a un miembro de la aplicación, la dirección de dependencia acíclica hacia adentro (las aplicaciones dependen de la biblioteca principal, nunca entre sí), la disciplina de aislamiento de importación que uv no puede aplicar, la API pública de cada miembro en el límite del paquete, diseño de prueba entre miembros y extracción segura de código compartido de un paquete existente. Cubre el cableado del espacio de trabajo uv (miembros, tool.uv.sources, archivo de bloqueo único, --package) y compone con las habilidades de uv y python-project-structure. Palabras clave: monorepo, espacio de trabajo uv, paquete múltiple, biblioteca compartida, límites del paquete, dirección de dependencia, importación circular, import-linter.
