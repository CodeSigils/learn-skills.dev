Python 리포지토리를 다중 패키지 uv-workspace monorepo(공유 내부 라이브러리와 이에 의존하는 하나 이상의 앱 또는 CLI 멤버)로 설계하거나 분할할 때 사용하고 패키지 간 경계가 필요합니다. 어떤 코드가 앱 멤버에 비해 공유 라이브러리가 되는지, 비순환 내부 종속 종속성 방향(앱은 서로 종속되지 않고 핵심 라이브러리에 종속됨), uv가 시행할 수 없는 가져오기-격리 원칙, 패키지 경계에서 각 멤버의 공개 API, 멤버 간 테스트 레이아웃 및 안전하게 기존 패키지에서 공유 코드를 추출합니다. uv 작업공간 배선(멤버, tool.uv.sources, 단일 잠금 파일, --package)을 다루고 uv 및 python-project-structure 기술로 구성합니다. 키워드: 모노레포, uv 작업 공간, 다중 패키지, 공유 라이브러리, 패키지 경계, 종속성 방향, 순환 가져오기, 가져오기-린터.
