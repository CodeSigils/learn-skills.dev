Python リポジトリをマルチパッケージの uv-workspace monorepo (共有内部ライブラリとそれに依存する 1 つ以上のアプリまたは CLI メンバー) に設計または分割する場合に使用します。また、パッケージ間の境界を正しく設定する必要があります。どのコードが共有ライブラリとアプリ メンバーになるか、非循環依存 - 内向き依存関係の方向 (アプリはコア ライブラリに依存し、相互に依存することはありません)、UV が強制できないインポート分離規律、パッケージでの各メンバーのパブリック API境界、メンバー間テストのレイアウト、既存のパッケージから共有コードを安全に抽出します。 UV ワークスペースの配線 (メンバー、tool.uv.sources、単一のロックファイル、--package) をカバーし、UV および Python プロジェクト構造のスキルを使用して構成します。キーワード: モノリポジトリ、UV ワークスペース、マルチパッケージ、共有ライブラリ、パッケージ境界、依存関係の方向、循環インポート、インポート リンター。
