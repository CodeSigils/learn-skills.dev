Verwenden Sie es, wenn Sie auf eine Wissenslücke stoßen – ein Thema, eine Bibliothek, ein Framework, ein Tool oder eine Domäne, die Sie recherchieren, lernen oder nachschlagen müssen, bevor Sie mit der Arbeit fortfahren. Recherchiert das Thema (Suche nach vorhandenen veröffentlichten Fertigkeiten als Quellmaterial, anschließend Webrecherche mit einem Verifizierungsdurchlauf) und synthetisiert eine fokussierte, tragbare Fertigkeit/<slug>/SKILL.md – die Erstellung einer neuen Fertigkeit oder die Verbesserung einer verwandten gefälschten Fertigkeit. Umfassende Themen, die mehrere Fertigkeiten umfassen, werden behandelt, indem mehrere Fertigkeiten parallel empfohlen und trainiert werden. Ein optionaler task_context schärft den Forschungsschwerpunkt. Gibt die fertige SKILL.md inline zur sofortigen Verwendung in derselben Runde zurück; Der Skill ist für zukünftige Sitzungen eigenständig auf der Festplatte gespeichert.
