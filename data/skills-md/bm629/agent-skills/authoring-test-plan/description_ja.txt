テスト計画/QA 検証計画を作成または修正するときに使用します。つまり、何を、どのレベルで、どの完了基準に従ってテストし、実行するケースを作成します。概要ではなくメソッドをガイドします。すべてのケースを機能仕様の動作/AC または API 仕様の操作/エラーから導き出します (決して発明したものではありません)。プロジェクトが保証する機能レベル。リスク加重カタログサイジング (BVA/同等性/デシジョンテーブル/状態遷移/ペアワイズ、クロス積ではありません)。非機能分類法 (パフォーマンス/セキュリティ/アクセシビリティ WCAG 2.2 AA/compat/i18n) には、保証されている場合には数値目標が含まれます。 ML/確率的動作の名前付きデータセットのメトリックしきい値のケース。そして、影響+リスク回帰選択を使用してバージョン化されたデルタとして修正します。テスターが質問なしで実行し、すべての動作が追跡されるバーまで修正します。テンプレートツール+ディープリサーチで構成。渡されたアップストリーム (feature-spec/api-spec/PRD/NFR) を消費し、空白ページを使用することはありません。スクリプトではなくケースを指定します。ランブックでも、行動契約でも、レビューでもありません。
