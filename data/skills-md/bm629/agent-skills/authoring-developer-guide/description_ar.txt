يُستخدم عند تأليف أو تعديل وثائق أداة المطور - سرد الاعتماد والتكامل لـ SDK أو المكتبة أو واجهة سطر الأوامر (CLI) أو إطار العمل أو النظام الأساسي لواجهة برمجة التطبيقات (API): الدليل الذي يقرأه المطور لتثبيت الأداة ودمجها وتشغيلها. يرشد الطريقة، وليس المخطط التفصيلي: أهداف المطور ليست نقاط النهاية؛ بداية مميزة هنا + نجاح أول سريع يمكن التحقق منه؛ المفاهيم قبل الوصفات؛ وصفات قابلة للتشغيل مسماة بالهدف؛ برنامج تعليمي شامل؛ أفضل الممارسات المرتكزة؛ مسار استكشاف الأخطاء وإصلاحها؛ التركيز على النموذج الأصلي (API/SDK/CLI/framework)؛ يشير إلى مرجع واجهة برمجة التطبيقات (API) - ولا يُنسخ منه على الإطلاق؛ وتعديل الدليل باعتباره دلتا تم إصدارها والتي تمسح تغييرات الأداة للعينات القديمة. تم كتابة Diataxis الكامل بشكل صحيح، كل عينة قابلة للتشغيل + دقيقة للأداة، لا شيء ملفق. يؤلف باستخدام أداة القالب + البحث العميق. يستهلك مواصفات الميزات التي تم تسليمها + مرجع واجهة برمجة التطبيقات + PRD - لا توجد صفحة فارغة أبدًا. ليس الكتالوج المرجعي لواجهة برمجة التطبيقات، أو دليل المستخدم النهائي، أو المستندات الهندسية، أو مراجعة أحد المستندات.
