Используйте при просмотре/оценке готового (или измененного) высококачественного дизайна пользовательского интерфейса, созданного КАК КОДА — ворота приемки: является ли визуализированный Hi-Fi качественным зародышем сборки? Рецензент ПЕРЕОБРАЖАЕТ сам код (безголовый браузер) и просматривает свежие скриншоты, никогда не доверяя переданным изображениям. Оценивает панель из одного источника: полное покрытие по сравнению с каркасными моделями; высокая точность + не перегруженность семян; визуальное исполнение + объективная полировка + названная эстетическая эвристика (субъективный вкус никогда не бывает пробелом); с поддержкой токенов/без дрейфа DS; реальный контент (без лорема); визуализированные состояния; отзывчивая перекомпоновка; ЧИСЛОВОЙ WCAG 2.2 AA на рендере (топор-ядро + зрение, правила не отключены); появились пробелы; поправка в виде дельты с ограниченной областью действия. Выдает `VERDICT: утвердить|пересмотреть` + выводы, требующие принятия мер; утверждает начальное значение, соответствующее полосе (без ложной проверки на тонком экране), проверяет только поименованный визуализируемый пробел. Требуется среда выполнения с поддержкой машинного зрения. Не для создания Hi-Fi, структуры (вайрфреймов), системы токенов (дизайн-системы) или финального кода.
