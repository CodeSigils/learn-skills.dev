À utiliser lors de l'examen/jugement d'une conception d'interface utilisateur haute fidélité terminée (ou modifiée) produite AS CODE — une porte d'acceptation : la chaîne hi-fi rendue est-elle une graine de construction sonore ? Le réviseur RE-REND le code lui-même (navigateur sans tête) et examine visuellement les nouvelles captures d'écran - sans jamais faire confiance aux images remises. Juge une barre à source unique : couverture complète par rapport aux wireframes ; haute fidélité + graine pas trop construite ; exécution visuelle + polissage objectif + heuristique esthétique nommée (le goût subjectif ne laisse jamais de lacune) ; soutenu par un jeton/sans dérive DS ; contenu réel (pas de lorem) ; états rendus; refusion réactive ; NUMERIC WCAG 2.2 AA sur le rendu (axe-core + vision, aucune règle désactivée) ; des lacunes sont apparues ; une modification en tant que delta versionné étendu. Émet « VERDICT : approuver | réviser » + des conclusions exploitables ; approuve une graine répondant à la barre (pas de fausse révision sur un écran fin), révise uniquement sur un espace nommé et rendu. Nécessite un runtime compatible avec la vision. Pas pour la création de chaînes hi-fi, la structure (wireframes), le système de jetons (système de conception) ou le code final.
