Realice apuestas de predicción sobre precios de tokens en Base a través de AgenticBets. Úselo cuando el usuario quiera apostar ARRIBA o ABAJO sobre si el precio de un token subirá o bajará, verificar las probabilidades de predicción del mercado, ver rondas de apuestas abiertas o reclamar ganancias de rondas liquidadas. Admite todos los tokens con mercados activos en AgenticBets (AGBETS, CLAWD, MOLT, WCHAN y más). Utiliza Bankr Submit API para ejecutar transacciones de apuestas y reclamos en Base.
