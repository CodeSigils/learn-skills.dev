AI エージェントのために解釈された暗号通貨ウォレット データ。エージェントがポートフォリオ値、トークンポジション、DeFiポジション、NFT保有、取引履歴、損益データ、トークン価格、チャート、ガス価格、スワップ相場、または41以上のチェーンにわたるDApp情報を必要とする場合に使用します。 Zerion は、生のブロックチェーン データを、USD 値、プロトコル ラベル、強化されたメタデータを含むエージェント対応の JSON に変換します。 x402 ペイパーリクエスト (ベースで $0.01 USDC) と API キー アクセスをサポートします。ポートフォリオ、ウォレット分析、ポジション、取引、損益、損益、DeFi、トークン残高、NFT、スワップ相場、ガス価格、またはゼリオンに関する言及をトリガーします。
