تفسير بيانات محفظة التشفير لعملاء الذكاء الاصطناعي. يُستخدم عندما يحتاج الوكيل إلى قيم المحفظة، أو مراكز الرمز المميز، أو مراكز DeFi، أو مقتنيات NFT، أو سجل المعاملات، أو بيانات PnL، أو أسعار الرمز المميز، أو الرسوم البيانية، أو أسعار الغاز، أو عروض أسعار المبادلة، أو معلومات DApp عبر أكثر من 41 سلسلة. تقوم Zerion بتحويل بيانات blockchain الأولية إلى JSON جاهزة للوكيل بقيم الدولار الأمريكي، وتسميات البروتوكول، والبيانات التعريفية المخصبة. يدعم x402 الدفع لكل طلب (0.01 USDC على القاعدة) والوصول إلى مفتاح API. يتم تشغيله عند ذكر المحفظة، أو تحليل المحفظة، أو المراكز، أو المعاملات، أو الربح والخسارة، أو الربح/الخسارة، أو DeFi، أو أرصدة الرموز المميزة، أو NFTs، أو عروض أسعار المبادلة، أو أسعار الغاز، أو Zerion.
