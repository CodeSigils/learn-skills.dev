Recherchez des opportunités de refactorisation de composition et d’amélioration d’état dans une base de code React. Audits pour le gonflement des accessoires booléens, les composants monolithiques avec explosion de variantes, les clusters frères et sœurs qui devraient partager des sous-composants de briques Lego, les emplacements d'accessoires de rendu qui ne peuvent pas sortir des sentiers battus et l'état synchronisé entre les frères et sœurs via useEffect. À utiliser lorsque l'utilisateur souhaite améliorer le code de réaction, auditer les composants de réaction, trouver des opportunités de refactorisation de réaction, exécuter une révision de la composition de réaction ou demande « améliorer la réaction », « auditer la réaction », « révision de l'architecture de réaction ».
