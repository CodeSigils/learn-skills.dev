ابحث عن فرص إعادة بناء البنية ورفع الحالة في قاعدة بيانات React. عمليات تدقيق لتضخم الدعامة المنطقية، والمكونات المتجانسة ذات الانفجار المتنوع، والمجموعات الشقيقة التي يجب أن تتشارك في المكونات الفرعية من الطوب المكعب، وفتحات عرض الدعامات التي لا يمكن الوصول إليها خارج الصندوق، والحالة المتزامنة بين الأشقاء عبر useEffect. يُستخدم عندما يريد المستخدم تحسين كود التفاعل، أو تدقيق مكونات التفاعل، أو العثور على فرص إعادة بناء التفاعل، أو تشغيل مراجعة تكوين التفاعل، أو يسأل "تحسين التفاعل"، أو "تدقيق التفاعل"، أو "مراجعة بنية التفاعل".
