Trova opportunità di refactoring per la composizione e il sollevamento dello stato in una base di codice React. Controlla il rigonfiamento delle prop booleane, i componenti monolitici con esplosione variante, i cluster fratelli che dovrebbero condividere sottocomponenti mattoncini lego, gli slot render prop che non possono raggiungere l'esterno della scatola e lo stato sincronizzato tra fratelli tramite useEffect. Utilizzare quando l'utente desidera migliorare il codice di reazione, controllare i componenti di reazione, trovare opportunità di refactoring di reazione, eseguire una revisione della composizione di reazione o chiedere "migliora reazione", "reazione di controllo", "revisione dell'architettura di reazione".
