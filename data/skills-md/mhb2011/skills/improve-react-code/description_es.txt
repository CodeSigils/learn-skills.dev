Encuentre oportunidades de refactorización de composición y elevación de estado en un código base de React. Auditorías para hinchazón de accesorios booleanos, componentes monolíticos con explosión variante, grupos hermanos que deberían compartir subcomponentes de ladrillos lego, ranuras de accesorios de renderizado que no pueden salir de la caja y estado sincronizado entre hermanos a través de useEffect. Úselo cuando el usuario quiera mejorar el código de reacción, auditar los componentes de reacción, encontrar oportunidades de refactorización de reacción, ejecutar una revisión de la composición de reacción o solicite "mejorar reacción", "auditar reacción", "revisión de arquitectura de reacción".
