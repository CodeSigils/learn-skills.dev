Найдите возможности рефакторинга композиции и поднятия состояния в базе кода React. Аудит на предмет раздувания логических элементов, монолитных компонентов с развертыванием вариантов, одноуровневых кластеров, которые должны использовать общие подкомпоненты из кубиков LEGO, слотов для рендеринга, которые не могут выйти за пределы коробки, и синхронизации состояния между братьями и сестрами через useEffect. Используйте, когда пользователь хочет улучшить код реагирования, провести аудит компонентов реагирования, найти возможности рефакторинга реагирования, запустить проверку композиции реагирования или спрашивает «улучшить реакцию», «аудит реакции», «обзор архитектуры реагирования».
