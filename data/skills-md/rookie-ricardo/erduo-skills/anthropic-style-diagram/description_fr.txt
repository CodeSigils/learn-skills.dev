Dessinez des diagrammes d'architecture, de flux et de structure dans le langage visuel Anthropic/Claude au format SVG, puis restituez-les et enregistrez-les au format PNG. Se déclenche UNIQUEMENT lorsque l'utilisateur nomme ce langage visuel — « Anthropique 风格架构图 », « Claude 风格流程图 », « Diagramme de style anthropique », « Organigramme de style Claude », « Anthropique 配色的图 » - ou demande un autre diagramme dans le même style après que cette compétence en a déjà produit un dans la conversation. Utilisez également pour restituer ou exporter un SVG qui utilise déjà le système de classes de cette compétence (th/ts/box/arr/c-blue…). Ne PAS utiliser pour une simple demande de diagramme sans style nommé, pour les graphiques de données, les maquettes d'interface utilisateur, les illustrations, les sorties TikZ ou sirène, ou les ERD de bases de données.
