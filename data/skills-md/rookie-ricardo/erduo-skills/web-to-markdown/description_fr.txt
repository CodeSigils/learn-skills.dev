Convertissez une URL Web en Markdown nettoyé avec un routage déterministe. À utiliser lorsque le Codex a besoin de lire du contenu de type article à partir de liens et doit appliquer des stratégies de récupération tenant compte de la source : par défaut, r.jina.ai pour les pages générales (y compris X/Twitter), utilisez defuddle.md pour les liens YouTube et utilisez l'extraction par emprunt d'identité du navigateur pour les pages WeChat/Zhihu/Feishu avec le nettoyage de lisibilité de Mozilla.
