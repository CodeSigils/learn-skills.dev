Создавайте настоящие спрайты, наборы плиток и анимацию в пиксельной графике с помощью API Retro Diffusion — лучшей специализированной модели пиксельной графики. Используйте, когда пользователь говорит «создать пиксельную графику», «создать спрайт с помощью ИИ», «использовать Retro Diffusion», «rdpk» или хочет, чтобы высококачественная пиксельная графика была быстрее, чем массивы спрайтов, написанные вручную. Требуется учетная запись Retro Diffusion и RETRODIFFUSION_API_KEY (оплаченные кредиты). Отлично подходит для быстрого прототипирования 2D-игр Phaser.
