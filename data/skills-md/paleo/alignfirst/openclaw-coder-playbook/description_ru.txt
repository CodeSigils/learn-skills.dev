Диспетчер инструкций по эксплуатации для рабочей области автономного программиста openclaw-coder. Маршрутизирует каждое пользовательское сообщение по поверхностям — поток → рабочий сеанс, канал/DM → обработка канала — и применяет глобальные правила. Рабочая область AGENTS.md сначала загружает этот навык в каждом сообщении пользователя.
