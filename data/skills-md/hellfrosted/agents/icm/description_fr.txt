Fournit la règle de mémoire persistante ICM (Infinite Context Memory) pour le Codex. À utiliser lorsque la mémoire persistante doit être consultée ou maintenue pour une tâche, lorsque l'utilisateur demande à utiliser ICM de manière générale, ou lorsqu'un contexte durable tel que les préférences de l'utilisateur, les erreurs résolues, les décisions d'architecture ou l'avancement significatif du projet doit persister dans les sessions du Codex.
