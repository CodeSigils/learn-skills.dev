Proporciona la regla de memoria persistente ICM (Infinite Context Memory) para Codex. Se utiliza cuando se debe consultar o mantener la memoria persistente para una tarea, cuando el usuario solicita utilizar ICM en general, o cuando un contexto duradero como las preferencias del usuario, los errores resueltos, las decisiones de arquitectura o el progreso significativo del proyecto deben persistir en las sesiones del Codex.
