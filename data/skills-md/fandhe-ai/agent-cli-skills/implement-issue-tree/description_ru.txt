Подзадачи (включая дочерние) родительской задачи автоматически реализуются параллельно с использованием рабочих деревьев с сохранением порядка зависимостей, а весь процесс — от реализации, предварительной проверки, создания PR, мониторинга CI до слияния — автоматизируется за один шаг. Он используется для «параллельной реализации дерева задач», «совместной реализации всех подзадач родительского элемента», «параллельной реализации всего дерева» и «автоматической разработки иерархии задач». Планирование каждого выпуска (План: опус) → реализация (Реализация: сонет) распределяется между работниками. Предварительная проверка (создание push-уведомлений и PR только после прохождения проверки, запуск CI только один раз). Автоматическое определение внешних проверок (ожидание не требуется даже в репозиториях без установленного CursorBugbot). Порядок выполнения контролируется параллелизмом (parallel) и зависимостями (dependentsOn). Информацию о реализации одной проблемы см. в разделе «Проблема реализации»; обзор PR см. в разделеimplement-review-pr.
