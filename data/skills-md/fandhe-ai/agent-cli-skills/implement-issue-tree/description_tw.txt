使用工作樹並行自動實現父問題下的子問題（包括孫子問題），同時保留依賴順序，並透過預先推送審查、PR 創建、CI 監控和擠壓合併來自動化整個工作流程。用於「問題樹的平行實作」、「一起實作父級下的所有子問題」、「整個樹的平行實作」和「問題層次結構的自動開發」。每期分工：規劃（Plan：opus）→實施（Implement：sonnet）。推送前審核（審核通過後才會進行推送和 PR 創建，僅觸發 CI 一次）。自動判斷外部檢查（即使在沒有 Cursor Bugbot 的儲存庫中也不需要等待）。執行順序由並行性（parallel）和依賴性（dependsOn）控制。有關單一問題的實現，請參閱實作問題；有關 PR 審查，請參閱 Implement-review-pr。
