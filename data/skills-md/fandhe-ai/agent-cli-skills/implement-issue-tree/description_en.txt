Automatically implement sub‑issues (including grandchildren) under a parent issue in parallel using worktree while preserving dependency order, and automate everything from pre‑push review, PR creation, CI monitoring, to squash merge. Used for “parallel implementation of the issue tree,” “implement sub‑issues together,” “implement the whole tree in parallel,” and “automatic development of the issue hierarchy.” Division of labor per issue: planning (Plan: opus) → implementation (Implement: sonnet). Pre‑push review (push and PR creation only after Review passes, triggering CI only once). Automatic external‑check determination (no unnecessary waiting even in repositories without Cursor Bugbot). Control execution order with parallelism (parallel) and dependencies (dependsOn). For single‑issue implementation see implement‑issue; for PR review see implement‑review‑pr.
