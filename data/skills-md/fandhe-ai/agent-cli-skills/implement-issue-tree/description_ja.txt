依存関係の順序を維持しながら、ワークツリーを使用して親課題の下にサブ課題 (孫を含む) を並行して自動的に実装し、プッシュ前レビュー、PR 作成、CI モニタリング、スカッシュ マージに至るワークフロー全体を自動化します。 「課題ツリーの並列実装」、「サブ課題の一括実装」、「ツリー全体の並列実装」、「課題階層の自動開発」に使用されます。課題ごとの計画（Plan：opus）→実装（Implement：sonnet）が役割分担されます。レビュー前にプッシュ (プッシュと PR の作成はレビューに合格した後にのみ行われ、CI は 1 回だけトリガーされます)。外部チェックは自動的に評価されます (Cursor Bugbot のないリポジトリであっても、不必要な待機はありません)。実行順序は並列処理 (Parallel) と依存関係 (dependsOn) によって制御されます。単一の問題を実装する場合は「実装-問題」を、PR レビューについては「実装-レビュー-pr」を参照してください。
