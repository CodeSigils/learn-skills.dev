使用工作树并行自动实现父问题下的子问题（包括孙子问题），同时保留依赖顺序，并自动执行从预推送审查、PR 创建、CI 监控到压缩合并的所有操作。用于“问题树的并行实现”、“一起实现子问题”、“并行实现整个树”和“问题层次结构的自动开发”。每期分工：规划（Plan：opus）→实施（Implement：sonnet）。推送前审核（审核通过后才推送和创建 PR，仅触发 CI 一次）。自动外部检查确定（即使在没有 Cursor Bugbot 的存储库中也没有不必要的等待）。通过并行性（parallel）和依赖性（dependsOn）控制执行顺序。对于单一问题的实现，请参阅实现问题；有关 PR 审查，请参阅 Implement-review-pr。
