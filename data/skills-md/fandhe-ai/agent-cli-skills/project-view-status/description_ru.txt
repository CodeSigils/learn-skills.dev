Обобщите ход выполнения проекта по статусу, приоритету и размеру для создания отчета. Навык, доступный только для чтения, который выводит степень завершения и разбивку незавершенных элементов по приоритету в табличном формате. Используется с такими командами, как «показать прогресс», «отчет о проекте», «какова степень завершения?» и «считать по статусу».
