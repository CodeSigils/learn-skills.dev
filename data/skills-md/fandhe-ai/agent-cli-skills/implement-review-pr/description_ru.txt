Просмотрите статус CI PR GitHub («gh pr checks»), качество кода, безопасность (OWASP Top10) и соответствие стандартным обязательствам. Вы также можете отправлять отзывы с помощью `gh pr review --approve/--request-changes/--comment`. Используйте такие фразы, как «рассмотреть PR #N» или «рассмотреть PR». Для просмотра локальных различий используйтеimplement‑review.
