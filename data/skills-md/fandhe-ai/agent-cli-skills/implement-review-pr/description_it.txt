Esamina lo stato del CI di GitHub PR ("gh pr checks"), la qualità del codice, la sicurezza (OWASPTop10) e la conformità con i commit convenzionali. Puoi anche inviare una recensione con `gh pr review --approve/--request-changes/--comment`. Usalo con comandi come "review PR #N" o "review PR". Per rivedere le differenze locali, utilizzare implementa-review.
