Vérifiez le statut CI du GitHub PR (« gh pr checks »), la qualité du code, la sécurité (OWASPTop10) et la conformité aux engagements conventionnels. Vous pouvez également soumettre une révision avec `gh pr review --approve/--request-changes/--comment`. Utilisez-le avec des commandes telles que « review PR #N » ou « review PR ». Pour examiner les différences locales, utilisezimplement‑review.
