Überprüfen Sie den CI-Status („gh pr checks“) des GitHub PR, die Codequalität, die Sicherheit (OWASPTop10) und die Einhaltung konventioneller Commits. Sie können eine Bewertung auch mit „gh pr review --approve/--request-changes/--comment“ abgeben. Verwenden Sie es mit Befehlen wie „review PR #N“ oder „review PR“. Zum Überprüfen lokaler Unterschiede verwenden Sie „implement-review“.
