قم بمراجعة حالة CI الخاصة بـ GitHub PR ('gh pr checks`)، وجودة الكود، والأمان (OWASP Top10)، والامتثال للالتزامات التقليدية. يمكنك أيضًا نشر مراجعة باستخدام `gh pr review --approve/--request-changes/--comment`. استخدمه مع أوامر مثل "review PR #N" أو "review PR". لمراجعة الاختلافات المحلية، استخدم مراجعة التنفيذ.
