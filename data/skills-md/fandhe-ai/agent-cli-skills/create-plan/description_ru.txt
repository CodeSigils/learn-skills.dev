Создайте план задачи реализации в `_/local-plans/<имя-плана>.md`. Сначала исследуйте базу кода с помощью агента исследования, затем напишите ее с такой степенью детализации и в модулях, которые можно проверять и выполнять параллельно, следуя стандартному формату, который может проверять агент проверки плана (предыстория, текущее состояние, проект, дерево файловой структуры, этапы реализации, метод проверки). Он используется для таких задач, как «составить план», «проектирование», «декомпозиция задачи», «рассмотреть подход к реализации» и т. д. план, планирование, проектирование, план реализации, декомпозиция задачи, создание плана.
