Créez le plan de tâches de mise en œuvre dans `_/local-plans/<plan-name>.md`.  
Examinez d’abord la base de code avec l’agent Explore, puis écrivez-la avec une granularité et dans des unités qui peuvent être vérifiées et exécutées en parallèle, en suivant un format standard qui peut être validé par l’agent vérificateur de plan (historique, état actuel, conception, arborescence de structure de fichiers, étapes de mise en œuvre, méthode de vérification). Il est utilisé pour des tâches telles que « élaborer un plan », « concevoir », « décomposer les tâches », « étudier la politique de mise en œuvre », etc.
