Erstellen Sie den Implementierungsaufgabenplan in „_/local-plans/<plan-name>.md“.  
Untersuchen Sie zunächst die Codebasis mit dem Explore Agent und schreiben Sie sie dann mit einer Granularität und in Einheiten, die überprüft und parallel ausgeführt werden können. Dabei folgen Sie einem Standardformat, das vom Planverifier Agent validiert werden kann (Hintergrund, aktueller Status, Design, Dateistrukturbaum, Implementierungsschritte, Überprüfungsmethode). Es wird für Aufgaben wie „Plan erstellen“, „Design“, „Aufgaben aufschlüsseln“, „Umsetzungsrichtlinie prüfen“ usw. verwendet.
