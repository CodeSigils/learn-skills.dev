Создайте новый проект GitHub v2, задайте стандартные поля «Статус», «Приоритет» и «Размер» и свяжите его с репозиторием. Также используются встроенные настройки рабочего процесса (автодобавление, автоматическое архивирование, автоматическое закрытие и т. д.) и их URL-адреса (интерфейс командной строки не поддерживается — только веб-интерфейс). Используется для таких команд, как «Создать проект», «Настройка проекта v2», «Создать канбан» и т. д.
