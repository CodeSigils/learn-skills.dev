Créez un nouveau projet GitHub v2, configurez les champs standard Statut, Priorité et Taille et liez-le à un référentiel. Fournissez également des conseils pour les URL de paramètres de flux de travail intégrés, telles que l'ajout automatique, l'archivage automatique et la fermeture automatique (CLI non prise en charge ; interface utilisateur Web uniquement). Utilisé avec des commandes telles que « créer un projet », « configuration Projectv2 », « créer un kanban », etc.
