Cree un nuevo Proyecto GitHub v2, configure los campos estándar Estado, Prioridad y Tamaño, y vincúlelo a un repositorio. También proporcione orientación para las URL de configuración del flujo de trabajo integradas, como Agregar automáticamente, Archivar automáticamente y Cerrar automáticamente (no se admite CLI; solo interfaz de usuario web). Se utiliza con comandos como "crear proyecto", "configurar Projectv2", "crear kanban", etc.
