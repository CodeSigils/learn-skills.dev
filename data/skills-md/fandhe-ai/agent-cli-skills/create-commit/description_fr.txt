Créez des commits git au format Conventional Commits. Déduisez le type/la portée à partir des différences par étapes et détectez les modifications importantes et les fuites secrètes (par exemple, les fichiers .env). Le hook de pré-validation doit toujours être passé (l'utilisation de `--no-verify` n'est pas autorisée). Utilisé avec des commandes telles que « commit », « git commit », « record changes » et similaires.
