قم بإنشاء التزامات git بتنسيق الالتزامات التقليدية. استنتج النوع/النطاق من الاختلافات المرحلية، واكتشف التغييرات العاجلة وإدراج الأسرار (على سبيل المثال، ملفات .env). قم دائمًا بتمرير خطاف الالتزام المسبق (disallow `--no-verify`). يُستخدم مع أوامر مثل "الالتزام" و"جيت الالتزام" و"تسجيل التغييرات" وما إلى ذلك.
