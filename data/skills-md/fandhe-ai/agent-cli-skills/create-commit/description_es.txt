Cree confirmaciones de git en el formato de confirmaciones convencionales. Infiera el tipo/alcance a partir de diferencias preparadas y detecte cambios importantes y filtraciones secretas (por ejemplo, archivos .env). Siempre se debe pasar el gancho de confirmación previa (no se permite el uso de `--no-verify`). Se utiliza con comandos como "commit", "git commit", "record change" y similares.
