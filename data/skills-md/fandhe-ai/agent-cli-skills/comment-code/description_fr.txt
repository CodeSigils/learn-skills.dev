Ajoutez ou renforcez des commentaires et des commentaires de documentation dans le code. Utilisez des commandes telles que « ajouter des commentaires », « écrire des commentaires », « renforcer les commentaires », « ajouter du JSDoc », « ajouter une docstring » ou « ajouter des commentaires de documentation ». Préservez les limites des rôles du point de vue du package/service, les hypothèses et les contrats des appelants et des appelés, ainsi que le contexte des autres fichiers ou services sous une forme lisible sur place. Ne modifiez pas le code lui-même (les modifications d’implémentation vont au problème d’implémentation). Reportez-vous à code-comment-style pour les conventions détaillées, create-commit pour créer des commits et update-docs pour synchroniser CLAUDE.md.
