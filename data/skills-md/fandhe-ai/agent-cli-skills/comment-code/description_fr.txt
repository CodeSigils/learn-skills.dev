Ajoutez ou renforcez des commentaires et des commentaires de documentation dans le code. Utilisez des commandes telles que « ajouter un commentaire », « écrire un commentaire », « renforcer le commentaire », « ajouter du JSDoc », « ajouter une docstring » ou « ajouter un commentaire de documentation ». Préservez, sous une forme lisible sur place, les limites des rôles du point de vue du package/service, les hypothèses et les contrats des appelants et des appelés, ainsi que le contexte d'autres fichiers ou services. Ne modifiez pas le code lui-même (les modifications d'implémentation vont à Implement-issue). Reportez-vous à code-comment-style pour les conventions détaillées, create-commit pour créer des commits et update-docs pour synchroniser CLAUDE.md.
