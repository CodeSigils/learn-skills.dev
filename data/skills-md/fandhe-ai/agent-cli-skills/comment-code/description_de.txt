Fügen Sie Kommentare und Dokumentationskommentare im Code hinzu oder verstärken Sie sie. Verwenden Sie dies für Eingabeaufforderungen wie „Kommentare hinzufügen“, „Kommentare schreiben“, „Kommentare verstärken“, „JSDoc hinzufügen“, „Dokumentzeichenfolge hinzufügen“ oder „Dokumentationskommentare hinzufügen“. Behalten Sie in einer Form, die vor Ort gelesen werden kann, die Rollengrenzen aus Paket- oder Serviceperspektive, die Annahmen und Verträge von Anrufern und Angerufenen sowie den Kontext aus anderen Dateien oder Services bei. Ändern Sie nicht den Code selbst (Implementierungsänderungen gehen zum Implementierungsproblem). Ausführliche Spezifikationen finden Sie im Code-Kommentar-Stil, im Abschnitt „Create-Commit“ zum Erstellen von Commits und in „Update-Dokumente“ zum Synchronisieren von CLAUDE.md.
