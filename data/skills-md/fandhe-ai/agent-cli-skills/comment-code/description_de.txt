Fügen Sie Kommentare und Dokumentationskommentare im Code hinzu oder verstärken Sie sie. Verwenden Sie Befehle wie „Kommentar hinzufügen“, „Kommentar schreiben“, „Kommentar verstärken“, „JSDoc hinzufügen“, „Dokumentzeichenfolge hinzufügen“ oder „Dokumentationskommentar hinzufügen“. Bewahren Sie in einer sofort lesbaren Form die Rollengrenzen aus Paket-/Dienstperspektive, die Annahmen und Verträge von Anrufern und Angerufenen sowie den Kontext aus anderen Dateien oder Diensten. Ändern Sie nicht den Code selbst (Implementierungsänderungen gehen zu „implement-issue“). Ausführliche Konventionen finden Sie unter code-comment-style, zum Erstellen von Commits unter create-commit und zum Synchronisieren von CLAUDE.md unter update-docs.
