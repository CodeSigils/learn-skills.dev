コード内のコメントおよびドキュメント コメントを追加または強化します。 「コメントの追加」、「コメントの書き込み」、「コメントの強化」、「JSDoc の添付」、「docstring の添付」、「ドキュメント コメントの添付」などのコマンドを使用します。パッケージ/サービスの観点からの役割の境界、呼び出し元と呼び出し先の前提と契約、および他のファイルまたは他のサービスからのコンテキストを、その場で読み取り可能な形式で保存します。コード自体を変更しないでください (実装の変更は実装の問題に移行する必要があります)。詳細な仕様は code-comment-style で、コミットの作成については create-commit で、CLAUDE.md の同期については update-docs を参照してください。
