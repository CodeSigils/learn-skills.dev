コード内のコメントおよびドキュメント コメントを追加または強化します。 「コメントの追加」、「コメントの書き込み」、「コメントの強化」、「JSDoc の追加」、「docstring の追加」、「ドキュメント コメントの追加」などのコマンドを使用します。パッケージ/サービスの観点からの役割の境界、呼び出し元と呼び出し先の前提と契約、および他のファイルまたはサービスからのコンテキストを、その場で読み取り可能な形式で保存します。コード自体は変更しないでください (実装の変更は実装の問題に反映されます)。詳細な規則については code-comment-style を、コミットの作成については create-commit を、CLAUDE.md の同期については update-docs を参照してください。
