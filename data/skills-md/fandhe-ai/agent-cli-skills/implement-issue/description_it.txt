Leggi il numero di GitHub, crea un piano dettagliato in `_/local-plans/<numero-numero>-<slug>.md` e implementa il codice **dopo l'approvazione dell'utente**. Dopo l'implementazione, esegui una revisione della sicurezza (OWASP Top10) → esegui test → esegui il commit utilizzando i commit convenzionali. Utilizzato per le richieste di implementazione in cui viene fornito un numero di problema o un URL, ad esempio "implementa il problema n. N" o "inizia a lavorare su questo problema".
