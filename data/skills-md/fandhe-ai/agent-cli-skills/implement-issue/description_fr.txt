Lisez le problème GitHub, créez un plan détaillé dans `_/local-plans/<issue-number>-<slug>.md` et implémentez le code **après approbation de l'utilisateur**. Après la mise en œuvre, effectuez un examen de sécurité (OWASP Top10) → exécutez des tests → validez à l'aide de Conventional Commits. Utilisé pour les demandes de mise en œuvre qui incluent un numéro de problème ou une URL, telle que « implémenter le problème #N » ou « démarrer ce problème ».
