Lesen Sie das GitHub-Problem, erstellen Sie einen detaillierten Plan in „_/local-plans/<issue-number>-<slug>.md“ und implementieren Sie den Code **nach Zustimmung des Benutzers**. Führen Sie nach der Implementierung eine Sicherheitsüberprüfung durch (OWASP Top10) → führen Sie Tests durch → Commit mit konventionellen Commits. Wird für Implementierungsanfragen verwendet, die eine Problemnummer oder URL enthalten, z. B. „Implementieren Sie Problem Nr. N“ oder „Starten Sie dieses Problem“.
