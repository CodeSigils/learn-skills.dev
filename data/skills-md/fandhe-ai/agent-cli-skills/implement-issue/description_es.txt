Lea el problema de GitHub, cree un plan detallado en `_/local-plans/<issue-number>-<slug>.md` e implemente el código **después de la aprobación del usuario**. Después de la implementación, realice una revisión de seguridad (OWASP Top10) → ejecute pruebas → confirme mediante confirmaciones convencionales. Se utiliza para solicitudes de implementación que incluyen un número de problema o una URL, como "Implementar el problema n.° N" o "Iniciar este problema".
