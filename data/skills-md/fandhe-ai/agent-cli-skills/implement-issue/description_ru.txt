Прочтите выпуск GitHub, создайте подробный план в `_/local‑plans/<issue-number>-<slug>.md` и внедрите код **только после одобрения пользователя**. После реализации выполните проверку безопасности (OWASP Top10) → запустите тесты → зафиксируйте с помощью обычных коммитов. Для запросов на внедрение, которые включают номер проблемы или URL-адрес, используйте такие фразы, как «Реализовать проблему № N» или «Начать работу над этой проблемой».
