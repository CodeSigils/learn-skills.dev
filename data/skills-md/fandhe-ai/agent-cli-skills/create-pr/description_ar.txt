قم بإنشاء GitHub PR باستخدام تنسيق الالتزامات التقليدية. يعد فحص أمان OWASP Top10 أمرًا إلزاميًا، وإذا تم العثور على أية مشكلات، قم بإلغاء إنشاء العلاقات العامة. قم بإنشاء نص يتضمن ملخصًا وخطة اختبار وتصميم. استخدمها مع أوامر مثل "إنشاء علاقات عامة" و"طلب سحب" و"`gh pr create`" وما إلى ذلك. تعتبر المساهمة في مستودع مختلف (المنبع) بمثابة مهارة مساهمة.
