Erstellen Sie eine GitHub-PR im herkömmlichen Commits-Format. Eine OWASP Top10-Sicherheitsüberprüfung ist erforderlich. Wenn Probleme gefunden werden, brechen Sie die PR-Erstellung ab. Generieren Sie einen Hauptteil, der Zusammenfassung, Testplan und Design enthält. Verwendung mit Befehlen wie „create PR“, „pull request“ oder „gh pr create“. Beiträge zu einem anderen Repository (Upstream) werden als Contribute-Skill bezeichnet.
