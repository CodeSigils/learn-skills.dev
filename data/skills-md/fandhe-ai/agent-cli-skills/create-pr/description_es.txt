Cree un PR de GitHub en formato de confirmaciones convencionales. Se requiere una verificación de seguridad OWASP Top10 y, si se encuentra algún problema, cancele la creación de PR. Generar un cuerpo que incluya Resumen, Plan de prueba y Diseño. Úselo con comandos como "crear PR", "solicitud de extracción" o "gh pr create". Las contribuciones a un repositorio diferente (ascendente) se denominancontribute‑skill.
