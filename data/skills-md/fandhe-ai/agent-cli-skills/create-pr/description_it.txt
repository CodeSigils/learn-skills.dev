Crea un PR GitHub nel formato Commit convenzionali. È richiesto un controllo di sicurezza OWASP Top10 e, se vengono rilevati problemi, interrompere la creazione della PR. Genera un corpo che include riepilogo, piano di test e progettazione. Utilizzare con comandi come "crea PR", "pull request" o "gh pr create". I contributi a un repository diverso (upstream) sono chiamati abilità di contributo.
