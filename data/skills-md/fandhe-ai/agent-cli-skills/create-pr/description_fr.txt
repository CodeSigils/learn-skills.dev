Créez un PR GitHub au format Conventional Commits. Un contrôle de sécurité OWASP Top10 est requis et si des problèmes sont détectés, abandonnez la création du PR. Générez un corps comprenant un résumé, un plan de test et une conception. À utiliser avec des commandes telles que « create PR », « pull request » ou « gh pr create ». Les contributions à un référentiel différent (en amont) sont appelées compétence-contribution.
