Преобразуйте черновой элемент проекта (DraftIssue) в фактическую проблему GitHub, сохранив значения полей, такие как статус, приоритет, размер и т. д. Вы можете указать существующую родительскую проблему или создать новую и связать ее как подзадачу через `gh api …/sub_issues`. Используется для «превращения черновика в задачу», «преобразования DraftIssue», «превращения задачи проекта в задачу» и подобных сценариев.
