Convierta el elemento borrador de un proyecto (DraftIssue) en un problema de GitHub real, conservando valores de campo como Estado, Prioridad y Tamaño. Puede especificar un problema principal existente o crear uno nuevo y vincularlo como un subproblema usando `gh api…/sub_issues`. Se utiliza para acciones como "convertir un borrador en un Issue", "convertir un DraftIssue" o "convertir una tarea de proyecto en un Issue".
