Konvertieren Sie das Entwurfselement (DraftIssue) eines Projekts in ein echtes GitHub-Problem und behalten Sie dabei Feldwerte wie Status, Priorität und Größe bei. Sie können ein vorhandenes übergeordnetes Problem angeben oder ein neues erstellen und es mit „gh api …/sub_issues“ als Unterproblem verknüpfen. Es wird für Aktionen wie „Einen Entwurf in ein Problem umwandeln“, „Ein Entwurfsproblem umwandeln“ oder „Eine Projektaufgabe in ein Problem umwandeln“ verwendet.
