قم بتحويل عنصر مسودة المشروع (DraftIssue) إلى إصدار GitHub حقيقي، مع ترحيل قيم الحقول مثل الحالة والأولوية والحجم. يمكنك تحديد مشكلة رئيسية موجودة أو إنشاء مشكلة جديدة وربطها كمسألة فرعية عبر `gh api .../sub_issues`. يُستخدم لإجراءات مثل "تحويل مسودة إلى مشكلة" أو "تحويل مسودة" أو "تحويل مهمة مشروع إلى مشكلة".
