Converti l'elemento bozza di un progetto (DraftIssue) in un vero problema GitHub, preservando i valori dei campi come Stato, Priorità e Dimensioni. Puoi specificare un problema principale esistente o crearne uno nuovo e collegarlo come problema secondario utilizzando "gh api …/sub_issues". Viene utilizzato per azioni come "trasformare una bozza in un problema", "convertire un progetto in un problema" o "trasformare un'attività progettuale in un problema".
