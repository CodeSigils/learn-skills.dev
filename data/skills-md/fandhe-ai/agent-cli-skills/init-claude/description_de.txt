Initialisieren Sie das Claude Code-Framework „.claude/“ (CLAUDE.md, Agents, Rules, Skills, Hooks) in einem beliebigen Ziel-Repository. Wird mit Befehlen wie „set up claude“, „create .claude“, „initialize CLAUDE.md“, „maintain Agent“, „claude-code setup“ usw. verwendet. Um Unterschiede in einem vorhandenen „.claude/“-Verzeichnis anzureichern, verwenden Sie „update-claude“. Dazu gehört auch die Vorbereitung der Umgebung, die für die Ausführung von „implement-issue-tree“ erforderlich ist (gh auth / sub_issues / Workflow js).
