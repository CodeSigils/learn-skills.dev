Inicialice la estructura Claude Code.claude/ (CLAUDE.md, Agentes, Reglas, Habilidades, ganchos) en cualquier repositorio de destino. Úselo con comandos como "configurar Claude", "crear .claude", "inicializar CLAUDE.md", "preparar agentes" o "configurar código Claude". Para enriquecer las diferencias de un directorio .claude/ existente, utiliceupdate‑claude. La configuración también incluye la preparación del entorno necesario para que se ejecute implement-issue-tree (gh auth, sub_issues, flujo de trabajo JS).
