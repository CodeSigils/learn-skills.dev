Initialisez la structure Claude Code `.claude/` (CLAUDE.md, Agents, Règles, Compétences, hooks) dans n'importe quel référentiel cible. Utilisé avec des commandes telles que « setup claude », « create .claude », « initialize CLAUDE.md », « prepare Agent », « claude-code setup », etc. Utilisez « update-claude » pour enrichir les différences dans un « .claude/ » existant. La configuration comprend également la préparation de l'environnement en supposant que `implement-issue-tree` fonctionne (gh auth / sub_issues / workflow js).
