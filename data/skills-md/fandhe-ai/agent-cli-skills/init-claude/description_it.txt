Inizializza la struttura `.claude/` del codice Claude (CLAUDE.md, agenti, regole, competenze, hook) in qualsiasi repository scelto. Viene utilizzato con comandi come "set up claude", "create .claude", "initialize CLAUDE.md", "maintain Agent", "claude‑code setup", ecc. Per arricchire le differenze in un file `.claude/` esistente, utilizzare `update-claude`. Ciò include anche la preparazione dell'ambiente in modo che `implement-issue-tree` funzioni (gh auth / sub_issues / flusso di lavoro js).
