Массовое обновление значений полей (таких как Статус, Приоритет, Размер и т. д.) элементов проекта, сужая их с помощью фильтров запроса или спецификаций элементов. Поддерживает типы полей SINGLE_SELECT, TEXT, NUMBER и DATE. Используется для таких действий, как «Изменить статус на «Выполняется», «Приоритет массового обновления» или «Установить для всех задач статус «Выполняется».
