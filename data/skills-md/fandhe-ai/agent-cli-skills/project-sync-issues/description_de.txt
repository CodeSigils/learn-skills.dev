Richten Sie die automatische Synchronisierung des Problem-/PR-Status und des Projektstatus ein. Modus A generiert eine „.github/workflows/project-sync.yml“ mithilfe der zusammengesetzten Aktion „Fandhe-AI/actions/project-sync“ (PAT oder GitHub App-Token). Modus B korrigiert bestehende Inkonsistenzen stapelweise. Wird für Aufgaben wie „Automatische Synchronisierungseinrichtung“, „Während der PR-Überprüfung als „In Prüfung“ markieren“ und „Board- und Problemstatus synchronisieren“ verwendet.
