Configure la sincronización automática del estado del problema/PR y del estado del proyecto. El modo A genera un `.github/workflows/project-sync.yml` usando la acción compuesta `Fandhe-AI/actions/project-sync` (PAT o token de aplicación GitHub). El modo B corrige por lotes las inconsistencias existentes. Se utiliza para tareas como "configuración de sincronización automática", "marcar como En revisión durante la revisión de relaciones públicas" y "sincronizar el estado del tablero y del problema".
