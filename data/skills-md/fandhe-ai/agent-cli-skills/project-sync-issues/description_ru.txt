Настройте автоматическую синхронизацию статуса Issue/PR со статусом проекта. ModeA создает файл .github/workflows/project-sync.yml, который использует составное действие Fandhe-AI/actions/project-sync (с токеном приложения PAT или GitHub). ModeB массово исправляет существующие несоответствия. Он используется для таких задач, как «автоматическая настройка синхронизации», «отметить как на рассмотрении во время проверки PR», «синхронизировать статус доски и проблемы» и тому подобных.
