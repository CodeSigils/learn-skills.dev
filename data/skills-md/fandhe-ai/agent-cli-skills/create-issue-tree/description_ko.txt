단계별로 나누어진 새로운 GitHub 이슈 트리를 생성하는 기술입니다. “이슈 트리 생성”, “작업을 단계별 이슈로 변환”, “이슈 트리 파일링”과 같은 명령과 함께 사용됩니다. 요구 사항 및 작업 목록을 수신하고 작업을 분해(4시간 단위로) → 단계로 분할 → 루트(추적) 문제 → 단계 상위 문제 → 하위 문제, sub_issues API를 통해 계층 구조 연결. 단계 레이블 추가 및 근본 문제 본문에 단계별 테이블 생성을 자동화합니다. 임의의 단계를 지정하여 부분 파일링도 지원합니다. 트리 목록 작성/업데이트에 대해서는 update-issue-tree를 참조하세요. 트리 구현에 대해서는 Implement-issue-tree를 참조하세요.
