مهارة إنشاء شجرة مشكلات GitHub جديدة مقسمة حسب المرحلة. يُستخدم مع أوامر مثل "إنشاء شجرة المشكلات"، و"تحويل المهام إلى مشكلات حسب المرحلة"، و"رفع شجرة المشكلات". يتلقى قائمة بالمتطلبات والمهام، ويقسم المهام (إلى تفاصيل مدتها 4 ساعات) → يقسم إلى مراحل → ينشئ مشكلة جذر (تتبع) → المشكلة الأصلية للمرحلة → التسلسل الهرمي للمشكلات الفرعية المرتبط عبر واجهة برمجة تطبيقات sub_issues. أتمتة إضافة تسميات المرحلة وإنشاء جدول المرحلة في نص المشكلة الجذرية. كما يدعم الإنشاء الجزئي عن طريق تحديد مراحل تعسفية. لجرد/تحديث الشجرة، راجعupdate-issue-tree؛ لتنفيذ الشجرة، راجع شجرة إصدار التنفيذ.
