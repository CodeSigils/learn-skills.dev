مهارة إنشاء شجرة مشكلات GitHub جديدة مقسمة حسب المرحلة. يُستخدم مع أوامر مثل "إنشاء شجرة المشكلات"، و"تحويل المهام إلى مشكلات حسب المرحلة"، و"حفظ شجرة المشكلات". يتلقى قائمة بالمتطلبات والمهام، ويقسم المهام (إلى تفاصيل مدتها 4 ساعات) ← ينقسم إلى مراحل ← مشكلة الجذر (التتبع) ← مشكلة أصل المرحلة ← مشكلات فرعية، وربط التسلسل الهرمي عبر واجهة برمجة تطبيقات sub_issues. أتمتة إضافة تسميات المرحلة وإنشاء جدول المرحلة في نص المشكلة الجذرية. كما يدعم الإيداع الجزئي عن طريق تحديد المراحل التعسفية. لجرد/تحديث الشجرة، راجع شجرة التحديث-الإصدار؛ لتنفيذ الشجرة، راجع شجرة التنفيذ-المشكلة.
