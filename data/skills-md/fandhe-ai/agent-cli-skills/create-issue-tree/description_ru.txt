Навыки создания нового дерева задач GitHub, разделенного по этапам. Используется с такими командами, как «Создать дерево задач», «Преобразовать задачи в задачи по этапам», «Сохранить дерево задач». Получает список требований и задач, декомпозирует задачи (на 4-часовую детализацию) → разбивает на Фазы → корневую (отслеживающую) проблему → Родительскую проблему фазы → дочерние проблемы, связывая иерархию через API sub_issues. Автоматизирует добавление меток фаз и создание таблицы фаз в теле основной задачи. Также поддерживается частичная регистрация путем указания произвольных этапов. Для инвентаризации/обновления дерева см. update-issue-tree; информацию о реализации дерева см. в разделе «Реализация-проблемного-дерева».
