Abilità per creare un nuovo albero dei problemi di GitHub diviso per Fase. Utilizzato con comandi come "Crea albero dei problemi", "Converti attività in problemi per fase" e "File albero dei problemi". Riceve un elenco di requisiti e attività, suddivide le attività (con granularità di 4 ore) → si suddivide in Fasi → problema root (monitoraggio) → Problema principale della fase → problemi secondari, collegando la gerarchia tramite l'API sub_issues. Automatizza l'aggiunta di etichette di fase e la generazione di una tabella per fasi nel corpo del problema principale. Supporta anche l'archiviazione parziale specificando qualsiasi Fase. Per inventariare/aggiornare l'albero, vedere update-issue-tree; per implementare l'albero, vedere implement-issue-tree.
