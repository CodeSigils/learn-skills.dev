Compétence pour créer une nouvelle arborescence de problèmes GitHub divisée par phase. Utilisé avec des commandes telles que « Créer une arborescence de problèmes », « Convertir les tâches en problèmes par phase », « Classer une arborescence de problèmes ». Reçoit une liste d'exigences et de tâches, décompose les tâches (en granularité de 4 heures) → se divise en phases → problème racine (suivi) → problème parent de phase → problèmes enfants, reliant la hiérarchie via l'API sub_issues. Automatise l’ajout d’étiquettes de phase et la génération d’un tableau par phase dans le corps du problème racine. Prend également en charge le classement partiel en spécifiant des phases arbitraires. Pour l'inventaire/la mise à jour de l'arborescence, voir update-issue-tree ; pour implémenter l'arborescence, voir Implement-issue-tree.
