フェーズごとに分割された新しい GitHub 課題ツリーを作成するスキル。 「課題ツリーの作成」、「フェーズごとにタスクを課題に変換」、「課題ツリーをファイルする」などのコマンドで使用されます。要件とタスクのリストを受け取り、タスクを（4 時間の粒度に）分解→フェーズ→ルート（追跡）課題→フェーズの親課題→子課題に分割し、sub_issues API を介して階層をリンクします。フェーズラベルの追加と、ルート課題本文でのフェーズごとのテーブルの生成を自動化します。任意のフェーズを指定して部分ファイリングにも対応します。ツリーのインベントリ/更新については、update-issue-tree を参照してください。ツリーの実装については、implement-issue-tree を参照してください。
