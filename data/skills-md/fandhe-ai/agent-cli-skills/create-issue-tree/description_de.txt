Fähigkeit zum Erstellen eines neuen GitHub-Issue-Baums, unterteilt nach Phase. Wird mit Befehlen wie „Problembaum erstellen“, „Aufgaben nach Phase in Probleme konvertieren“ und „Problembaum ablegen“ verwendet. Empfängt eine Liste von Anforderungen und Aufgaben, zerlegt Aufgaben (in 4-Stunden-Granularität) → teilt sich in Phasen → Stammproblem (Verfolgung) → übergeordnetes Phasenproblem → untergeordnete Probleme auf und verknüpft die Hierarchie über die sub_issues-API. Automatisiert das Hinzufügen von Phasenbezeichnungen und das Generieren einer phasenweisen Tabelle im Hauptteil des Problems. Unterstützt auch die Teilablage durch Angabe beliebiger Phasen. Informationen zur Inventarisierung/Aktualisierung des Baums finden Sie unter update-issue-tree; Informationen zur Implementierung des Baums finden Sie unter „implement-issue-tree“.
