قم بإنشاء التحليلات والمقارنات ونتائج البحث والتقدم والخطط كتقارير HTML قائمة بذاتها يسهل اتخاذ القرار فيها. استخدمه مع المطالبات مثل "إنشاء تقرير HTML"، و"تلخيص في تقرير"، و"تصور المقارنة"، و"إظهار باستخدام الرسوم البيانية"، و"إنشاء مخطط جانت"، و"تلخيص في نمط لوحة المعلومات"، و"تلخيص لسهولة العرض". اعتمادًا على البيانات والعلاقة التي تريد نقلها، حدد التمثيل المناسب من مؤشرات الأداء الرئيسية أو الجداول أو الشريط أو الخط أو المبعثر أو الخريطة الحرارية أو الشلال أو الكعكة أو الرادار أو جانت، وقم بإنشاء ملف HTML واحد يمكن الوصول إليه وسريع الاستجابة وقابل للطباعة.
