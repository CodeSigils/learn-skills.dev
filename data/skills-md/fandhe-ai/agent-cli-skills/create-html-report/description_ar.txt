قم بإنشاء التحليلات والمقارنات ونتائج البحث والتقدم والخطط كتقارير HTML قائمة بذاتها تسهل اتخاذ القرار. استخدمه مع أوامر مثل "إنشاء تقرير HTML"، و"تلخيص في تقرير"، و"تصور المقارنة"، و"إظهارها في رسم بياني"، و"إنشاء مخطط جانت"، و"تلخيص في نمط لوحة المعلومات"، و"اجعلها سهلة القراءة". اعتمادًا على البيانات والعلاقة التي تريد نقلها، اختر التمثيل المناسب من مؤشرات الأداء الرئيسية أو الجداول أو الشريط أو الخط أو المبعثر أو الخريطة الحرارية أو الشلال أو الكعكة أو الرادار أو جانت، وقم بإنشاء ملف HTML واحد يمكن الوصول إليه وسريع الاستجابة وقابل للطباعة.
