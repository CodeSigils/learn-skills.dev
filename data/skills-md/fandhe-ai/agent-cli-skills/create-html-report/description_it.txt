Utilizza comandi come "Crea un report HTML", "Riepiloga in un report", "Visualizza il confronto", "Mostra con un grafico", "Crea un diagramma di Gantt", "Riepiloga in uno stile dashboard", "Riepiloga per una facile visualizzazione". A seconda dei dati e della relazione che desideri trasmettere, seleziona la rappresentazione appropriata tra KPI, tabelle, barre, linee, dispersione, mappa termica, cascata, ciambella, radar o Gantt e genera un singolo file HTML accessibile, reattivo e stampabile.
