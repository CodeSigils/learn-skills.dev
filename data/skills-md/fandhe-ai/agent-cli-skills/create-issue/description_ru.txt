Создавайте задачи GitHub в родительско-дочерней структуре (подзадачи). Создайте родительские и дочерние задачи с помощью `gh Issue create` и свяжите отношения родитель-потомок с помощью `gh api …/sub_issues`. Заголовки должны соответствовать формату обычных коммитов (`feat:`, `fix:` и т. д.). Используется для таких действий, как «Создать задачу» и «Разбить задачи на задачи».
