Erstellen Sie GitHub-Probleme mithilfe einer übergeordneten/untergeordneten Struktur (Unterproblem). Generieren Sie übergeordnete und untergeordnete Probleme mit „gh issue create“ und verknüpfen Sie sie über „gh api …/sub_issues“. Titel sollten dem herkömmlichen Commits-Format („feat:“, „fix:“ usw.) folgen. Wird für Befehle wie „Ein Problem erstellen“ oder „Aufgaben in Probleme aufteilen“ verwendet.
