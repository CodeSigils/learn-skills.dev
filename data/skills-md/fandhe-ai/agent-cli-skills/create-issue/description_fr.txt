Créez des tickets GitHub à l’aide d’une structure parent‑enfant (sous‑problème). Générez des problèmes parents et enfants avec `gh issue create` et liez-les via `gh api …/sub_issues`. Les titres doivent suivre le format Conventional Commits (`feat:`, `fix:`, etc.). Utilisé pour des commandes telles que « créer un problème » ou « diviser les tâches en problèmes ».
