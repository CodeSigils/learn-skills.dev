قم بإنشاء مشكلات GitHub في بنية الأصل والفرع (القضايا الفرعية). استخدم `gh Issue create` لإنشاء مشكلات الأصل والفرع، وربط العلاقة بين الوالدين والطفل مع `gh api .../sub_issues`. يوصى باتباع العناوين تنسيق الالتزامات التقليدية (`fet:`، `fix:` وما إلى ذلك). يُستخدم لأشياء مثل "إنشاء مشكلة" و"تقسيم المهام إلى مشكلات".
