Cree problemas de GitHub utilizando una estructura principal-secundaria (subasunto). Genere problemas de padres e hijos con `gh issues create` y vincúlelos a través de `gh api…/sub_issues`. Los títulos deben seguir el formato de confirmaciones convencionales (`feat:`, `fix:`, etc.). Se utiliza para comandos como "crear un problema" o "dividir tareas en problemas".
