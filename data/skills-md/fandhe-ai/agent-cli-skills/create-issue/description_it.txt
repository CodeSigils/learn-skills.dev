Crea problemi GitHub utilizzando una struttura genitore-figlio (sottoproblema). Genera problemi genitore e figlio con `gh issue create` e collegali tramite `gh api …/sub_issues`. I titoli dovrebbero seguire il formato Commit convenzionale (`feat:`, `fix:`, ecc.). Utilizzato per comandi come "crea un problema" o "suddividi le attività in problemi".
