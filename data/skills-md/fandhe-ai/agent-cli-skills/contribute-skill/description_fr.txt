Publiez les `skills/<skill-name>/` modifiés localement dans le référentiel en amont (par exemple, Fandhe‑AI/agent-cli-skills) en tant que PR. Lisez le champ « source » dans « skills-lock.json » et abandonnez toute poussée vers des référentiels autres que « Fandhe-AI/ » par mesure de sécurité. Ensuite : cloner → appliquer les modifications → contrôle de sécurité → créer une branche → pousser → exécuter `gh pr create`. Après la fusion, mettez à jour le hachage avec `sync-skills-lock`. Utilisé pour « apporter une compétence en amont », « RP vers un référentiel externe », etc.
