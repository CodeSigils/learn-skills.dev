Pubblica "skills/<skill-name>/" modificato localmente nel repository upstream (ad esempio, Fandhe‑AI/agent-cli-skills) come PR. Leggi il campo "source" in "skills-lock.json" e interrompi qualsiasi push a repository diversi da "Fandhe‑AI/" come misura di sicurezza. Quindi: clona → applica modifiche → controllo di sicurezza → crea ramo → push → esegui `gh pr create`. Dopo l'unione, aggiorna l'hash con `sync-skills-lock`. Utilizzato per "contribuire con una competenza a monte", "PR su un repository esterno", ecc.
