Veröffentlichen Sie die lokal geänderten „skills/<skill-name>/“ als PR im Upstream-Repository (z. B. Fandhe-AI/agent-cli-skills). Lesen Sie das Feld „Quelle“ in „skills-lock.json“ und brechen Sie aus Sicherheitsgründen jeden Push an andere Repositorys als „Fandhe-AI/“ ab. Dann: Klonen → Änderungen anwenden → Sicherheitsprüfung → Zweig erstellen → Push → „gh pr create“ ausführen. Aktualisieren Sie nach dem Zusammenführen den Hash mit „sync-skills-lock“. Wird für „Einen Skill im Upstream beisteuern“, „PR an ein externes Repository“ usw. verwendet.
