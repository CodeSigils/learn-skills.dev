Post the locally modified `skills/<skill-name>/` to the upstream repository (e.g., Fandhe‑AI/agent-cli-skills) as a PR. Read the `source` field in `skills-lock.json` and abort any push to repositories other than `Fandhe‑AI/` as a safety measure. Then: clone → apply changes → security check → create branch → push → run `gh pr create`. After merging, update the hash with `sync-skills-lock`. Used for “contribute a skill upstream,” “PR to an external repository,” etc.
