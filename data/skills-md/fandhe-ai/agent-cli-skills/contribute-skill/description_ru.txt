Опубликуйте локально измененные `skills/<skill-name>/` в вышестоящий репозиторий (например, Fandhe‑AI/agent-cli-skills) в качестве PR. Прочтите поле `source` в `skills-lock.json` и в целях безопасности прекратите любую отправку данных в репозитории, кроме `Fandhe‑AI/`. Затем: клонировать → применить изменения → проверка безопасности → создать ветку → нажать → запустить `gh pr create`. После слияния обновите хэш с помощью `sync-skills-lock`. Используется для «внести свой вклад в разработку навыков», «PR во внешний репозиторий» и т. д.
