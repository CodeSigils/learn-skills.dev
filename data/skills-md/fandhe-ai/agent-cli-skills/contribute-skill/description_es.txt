Publique las `skills/<skill-name>/` modificadas localmente en el repositorio ascendente (por ejemplo, Fandhe‑AI/agent-cli-skills) como PR. Lea el campo `source` en `skills-lock.json` y cancele cualquier envío a repositorios que no sean `Fandhe-AI/` como medida de seguridad. Luego: clonar → aplicar cambios → verificación de seguridad → crear rama → presionar → ejecutar `gh pr create`. Después de fusionar, actualice el hash con `sync-skills-lock`. Se utiliza para "contribuir con una habilidad en sentido ascendente", "RP a un repositorio externo", etc.
