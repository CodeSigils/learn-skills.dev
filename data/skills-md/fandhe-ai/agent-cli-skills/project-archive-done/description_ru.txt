Массовая архивация элементов проекта со статусом «Готово» с помощью `gh project item-archive`. Также проверяйте и контролируйте состояние конфигурации встроенного рабочего процесса автоматического архивирования (если он включен, ручное выполнение, как правило, не требуется). Используется для таких задач, как «архивирование завершенных элементов», «организация выполнения», «очистка доски» и т. д.
