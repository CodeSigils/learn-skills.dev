Archivez en masse les éléments du projet avec un statut Terminé à l'aide de « gh project item-archive ». Vérifiez et informez également sur les paramètres de flux de travail intégrés d'archivage automatique (s'ils sont activés, l'exécution manuelle est généralement inutile). Utilisé pour des tâches telles que « Archiver les éléments terminés », « Organiser les éléments terminés » et « Nettoyer le tableau ».
