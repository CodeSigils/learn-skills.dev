مهارة جرد وتحديث شجرة مشكلات GitHub الموجودة. يُستخدم مع "شجرة الجرد" و"تحديث شجرة الإصدارات" و"تنظيم تتبع المشكلة". يتلقى رقم إصدار تتبع الجذر، ويسترد الشجرة بأكملها بشكل متكرر عبر واجهة برمجة تطبيقات sub_issues ← يعيد تعيين الإصدارات المفتوحة المتبقية ضمن الأصول المغلقة، ويعيد وضع الأعداد اليتيمة، وينشئ أصول مرحلة جديدة، ويتزامن مع تسميات المرحلة ← يعيد إنشاء وتحديث جدول مرحلة تلو الأخرى وقسم المخزون في نص الإصدار الجذر. راجع إنشاء شجرة المشكلات لإنشاء شجرة جديدة وشجرة مشكلات التنفيذ لاستهلاك التنفيذ.
