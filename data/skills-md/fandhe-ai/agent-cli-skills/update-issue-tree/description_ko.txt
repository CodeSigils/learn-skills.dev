기존 GitHub 문제 트리를 목록화하고 업데이트하는 기술입니다. "트리 인벤토리", "이슈 트리 업데이트" 및 "추적 이슈 구성"과 함께 사용됩니다. 루트 추적 이슈 번호를 수신하고, sub_issues API를 통해 전체 트리를 반복적으로 검색하고 → 닫힌 상위 항목 아래에 남아 있는 공개 이슈를 재할당하고, 분리된 이슈의 위치를 ​​변경하고, 새 단계 상위 항목을 생성하고, 단계 레이블을 동기화하고 → 루트 이슈 본문의 단계별 테이블과 인벤토리 섹션을 재생성 및 업데이트합니다. 새 트리를 생성하려면 create-issue-tree를 참조하고 구현을 사용하려면 Implement-issue-tree를 참조하세요.
