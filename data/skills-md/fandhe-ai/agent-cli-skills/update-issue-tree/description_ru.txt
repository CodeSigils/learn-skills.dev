Навыки инвентаризации и обновления существующего дерева проблем GitHub. Используется с «Инвентаризацией дерева», «Обновлением дерева проблем» и «Организацией отслеживания проблем». Он получает номер корневой задачи отслеживания, рекурсивно извлекает все дерево через API sub_issues → переназначает открытые задачи, оставшиеся под закрытыми родительскими задачами, перемещает потерянные задачи, создает новые родительские фазы, синхронизирует метки фаз → восстанавливает и обновляет таблицу поэтапного выполнения и раздел инвентаризации в теле корневой задачи. См. create-issue-tree для создания нового дерева иimplement-issue-tree для использования реализации.
