Compétence pour inventorier et mettre à jour une arborescence de problèmes GitHub existante. Utilisé avec « Inventaire de l'arborescence », « Mettre à jour l'arborescence des problèmes » et « Organiser le suivi des problèmes ». Il reçoit le numéro de problème de suivi racine, récupère de manière récursive l'intégralité de l'arborescence via l'API sub_issues → réaffecte les problèmes ouverts laissés sous les parents fermés, repositionne les problèmes orphelins, crée de nouveaux parents de phase, synchronise les étiquettes de phase → régénère et met à jour la table Phase par Phase et la section d'inventaire dans le corps du problème racine. Voir create-issue-tree pour créer une nouvelle arborescence et Implement-issue-tree pour utiliser l'implémentation.
