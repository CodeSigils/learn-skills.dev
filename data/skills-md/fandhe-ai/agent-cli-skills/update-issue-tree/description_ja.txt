既存の GitHub 問題ツリーのインベントリを作成して更新するスキル。 「ツリーのインベントリ」、「課題ツリーの更新」、および「課題の追跡を整理」とともに使用されます。ルート追跡課題番号を受け取り、sub_issues API を介してツリー全体を再帰的に取得します。 → 閉じられた親の下に残された未解決の課題を再割り当てし、孤立した課題を再配置し、新しいフェーズの親を作成し、フェーズ ラベルを同期します。 → ルート課題本体のフェーズごとのテーブルとインベントリ セクションを再生成して更新します。新しいツリーの作成については create-issue-tree を、実装の使用についてはimplement-issue-treeを参照してください。
