Skill to inventory and update an existing GitHub Issue tree. Used with “Inventory the tree”, “Update the issue tree”, and “Organize tracking issue”. It receives the root tracking issue number, recursively retrieves the entire tree via the sub_issues API → reassigns open issues left under closed parents, repositions orphaned issues, creates new Phase parents, syncs phase labels → regenerates and updates the Phase‑by‑Phase table and inventory section in the root issue body. See create-issue-tree for creating a new tree and implement-issue-tree for consuming the implementation.
