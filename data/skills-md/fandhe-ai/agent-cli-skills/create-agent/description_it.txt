Impalcatura di una nuova definizione di sub-agente. Automatizza l'intero flusso di lavoro in modo coerente: dalla selezione delle categorie e creazione di file alle impostazioni di autorizzazione minime per modelli/strumenti e controlli di qualità. Utilizzato con comandi quali "Crea agente", "Aggiungi sottoagente", "crea agente", ecc.
