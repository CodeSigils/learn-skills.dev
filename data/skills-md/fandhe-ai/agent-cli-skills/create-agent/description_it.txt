Impalcatura di una nuova definizione di sub-agente. Automatizza l'intero flusso di lavoro, dalla selezione delle categorie e la creazione dei file alle impostazioni minime dei permessi per modelli/strumenti e controlli di qualità. Utilizzato con comandi quali "Crea agente", "Aggiungi sub-agente", "crea agente" e così via.
