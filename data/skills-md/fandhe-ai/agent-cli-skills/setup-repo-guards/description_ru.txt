Внедрите в целевой репозиторий полный набор стандартных средств защиты CI организации Fandhe‑AI (реализация проверки кодекса, проверка сбора точек зрения AGENTS.md, задание агрегации необходимой проверки, набор правил защиты ветвей и дополнительные меры защиты). Используйте его с такими командами, как «добавить защиту репозитория», «установить CI Guard», «настроить защиту ветки», «установить проверку кодекса», «поддерживать AGENTS.md» и т. д. Он также поддерживает массовое применение к нескольким репозиториям. Для системы .claude/ см. init-claude для начальной настройки и update-claude для улучшения существующей настройки.
