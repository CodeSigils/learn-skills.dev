Introduisez l'ensemble complet des gardes CI standard de l'organisation Fandhe-AI (implémentation de la révision du codex / collection de points de vue de révision AGENTS.md / travail d'agrégation des vérifications essentielles / ensemble de règles de protection des branches et gardes supplémentaires) dans le référentiel cible. Utilisez-le avec des commandes telles que « ajouter un référentiel guard », « installer CI guard », « setup branch protection », « install codex-review », « maintain AGENTS.md », etc. Il prend également en charge les applications groupées sur plusieurs référentiels. Pour le système .claude/, voir init‑claude pour la configuration initiale et update‑claude pour améliorer la configuration existante.
