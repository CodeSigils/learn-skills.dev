Introdurre il set completo di protezioni CI dallo standard dell'organizzazione Fandhe‑AI (integrazione della revisione del codice, lista di controllo di revisione AGENTS.md, lavoro di aggregazione dei controlli essenziali, set di regole di protezione dei rami e protezioni aggiuntive) nel repository di destinazione. Utilizzare con comandi quali "aggiungi repository guard", "installa CI guard", "imposta protezione ramo", "installa codex-review", "mantieni AGENTS.md", ecc. È supportata anche l'applicazione in blocco su più repository. Per la configurazione iniziale del framework.claude vedere init‑claude; per migliorare un quadro esistente vedere aggiornamento‑claude.
