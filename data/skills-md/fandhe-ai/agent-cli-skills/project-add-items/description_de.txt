Erstellen Sie Projektelemente in großen Mengen aus Markdown-Checklisten, YAML-Aufgabenlisten, Anforderungsdefinitionsdokumenten und ähnlichen Quellen. Analysieren Sie Titel, Text, Priorität und Größe und legen Sie dann die Felder mit „gh project item-create“ plus „item-edit“ fest. Wird für Aktionen wie „Elemente aus Anforderungsdokumenten erstellen“, „Aufgaben zu einem Projekt hinzufügen“, „Roadmap importieren“ usw. verwendet.
