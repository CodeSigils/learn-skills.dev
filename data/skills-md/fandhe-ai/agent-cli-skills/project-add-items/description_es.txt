Cree elementos de proyecto de forma masiva a partir de listas de verificación de Markdown, listas de tareas YAML, documentos de definición de requisitos y fuentes similares. Analice el título, el cuerpo, la Prioridad y el Tamaño, luego configure los campos usando `gh project item-create` más `item-edit`. Se utiliza para acciones como "crear elementos a partir de documentos de requisitos", "agregar tareas a un proyecto", "importar una hoja de ruta", etc.
