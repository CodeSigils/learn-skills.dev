Массовое создание элементов проекта из таких источников, как контрольные списки Markdown, списки задач YAML и документы с определением требований. Проанализируйте заголовок, тело, приоритет и размер, затем задайте поля, используя `gh project item-create` + `item-edit`. Используется для таких сценариев, как «создание элементов из документов с требованиями», «добавление задач в проект» и «импорт дорожной карты».
