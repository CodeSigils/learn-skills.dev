قم بإنشاء عناصر المشروع بشكل مجمّع من مصادر مثل قوائم مراجعة Markdown وقوائم مهام YAML ومستندات تعريف المتطلبات. قم بتحليل العنوان والنص والأولوية والحجم، وقم بتعيين الحقول باستخدام `gh project item-create` بالإضافة إلى`item-edit`. يتم استخدامه لأشياء مثل "إنشاء عناصر من مستند المتطلبات" و"إضافة مهام إلى مشروع" و"استيراد خريطة طريق".
