La revisión de solo lectura de los cambios de código (`git diff`) para determinar la calidad, el cumplimiento de la arquitectura y la seguridad (OWASP Top10) se realiza delegando a una herramienta del Agente. Se utiliza para la autoevaluación antes de confirmar o crear un PR, por ejemplo, "revisar los cambios" o "revisión del código". Para revisar las relaciones públicas de GitHub, utiliceimplement‑review‑pr.
