La revisione in sola lettura delle modifiche al codice (`git diff`) per qualità, conformità dell'architettura e sicurezza (OWASP Top10) viene eseguita delegando a uno strumento agente. Viene utilizzato per l'auto-revisione prima di impegnarsi o creare una PR, come ad esempio "revisionare le modifiche" o "revisione del codice". Per le revisioni PR di GitHub, utilizzare implement-review-pr.
