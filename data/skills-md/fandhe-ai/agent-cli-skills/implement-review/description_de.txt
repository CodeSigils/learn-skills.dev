Schreibgeschützte Überprüfung von Codeänderungen („git diff“) auf Qualität, Architekturkonformität und Sicherheit (OWASP Top10), delegiert an ein Agent-Tool. Es wird zur Selbstüberprüfung vor dem Festschreiben oder Erstellen einer PR verwendet, z. B. „Überprüfen Sie die Änderungen“ oder „Codeüberprüfung“. Für GitHub-PR-Bewertungen verwenden Sieimplement-review-pr.
