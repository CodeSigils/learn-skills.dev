Examen en lecture seule des modifications de code (`git diff`) pour la qualité, la conformité architecturale et la sécurité (OWASP Top10) déléguée à un outil Agent. Utilisé pour l'auto-évaluation avant de valider ou de créer une demande de tirage, comme « examiner les modifications » ou « révision du code ». Utilisez `implement-review-pr` pour examiner les PR GitHub.
