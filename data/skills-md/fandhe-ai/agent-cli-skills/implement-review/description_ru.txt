Проверка изменений кода только для чтения («git diff») на предмет качества, соответствия архитектуре и безопасности (OWASP Top10) выполняется путем делегирования полномочий инструменту агента. Он используется для самопроверки перед фиксацией или созданием PR, например «проверка изменений» или «проверка кода». Для просмотра запросов GitHub используйтеimplement-review-pr.
