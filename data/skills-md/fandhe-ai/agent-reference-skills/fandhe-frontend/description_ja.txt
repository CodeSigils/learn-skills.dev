Rust ベースのフロントエンド フレームワーク **fandhe-frontend** のリファレンス: SSR、SPA、SSG、およびビュー トランジションを統合します。ハイドレーションと単一の実行可能ファイルとしての配布をサポートします。デフォルトのエスケープと `forbid(unsafe_code)` を使用して安全に設計されています。コア クレートには、**core**、**app**、**interactive**、**headless-ui** (プリミティブ)、**pre-styled-ui** (テーマ)、**server** (SSG `generate_pages`/`generate_assets`) が含まれます。これらはすべて `fandhe-frontend-` というプレフィックスが付きます。 **new**、**gate**、**struction**、**impact** などのコマンドを備えた CLI フレームワークが含まれています。
