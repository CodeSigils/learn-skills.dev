Rust ベースのフロントエンド フレームワーク **fandhe-frontend** のリファレンス。 SSR、SPA、SSG、およびビューの遷移、ハイドレーション、および配布を単一の実行可能ファイルとして統合。デフォルトのエスケープと `forbid(unsafe_code)` を備えた安全な設計。メインクレート: `core`、`app`、`interactive`、`headless-ui` (プリミティブ)、`pre-styled-ui` (テーマ)、`server` (SSG `generate_pages`/`generate_assets`) — すべてに `fandhe-frontend-` というプレフィックスが付きます。 CLI フレームワーク (`新しい` / `ゲート` / `構造` / `インパクト`)。
