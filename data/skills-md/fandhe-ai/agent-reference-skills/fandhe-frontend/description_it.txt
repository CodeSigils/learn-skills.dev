Riferimento per il framework frontend basato su Rust **fandhe-frontend**. Integrazione di SSR, SPA, SSG e transizioni di visualizzazione, idratazione e distribuzione come un unico file eseguibile. Progettazione sicura con escape predefinito e `forbid(unsafe_code)`. Casse principali: `core`, `app`, `interactive`, `headless-ui` (primitive), `pre-styled-ui` (temi), `server` (SSG `generate_pages`/`generate_assets`), tutti con il prefisso `fandhe-frontend-`. Framework CLI (`nuovo` / `gate` / `struttura` / `impatto`).
