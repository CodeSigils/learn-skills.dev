Riferimento per il framework frontend basato su Rust fandhe-frontend. Integrazione di transizioni SSR/SPA/SSG/View, idratazione e distribuzione eseguibile singola. Progettazione di sicurezza con escape predefinito e proibisci (unsafe_code). Casse principali: core, app, interattiva, headless‑ui (primitive), pre‑styled‑ui (temi), server (SSG generate_pages/generate_assets) (con prefisso fandhe‑frontend‑). Framework CLI (nuovo, cancello, struttura, impatto).
