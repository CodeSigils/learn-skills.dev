Referencia para el marco de interfaz de usuario basado en Rust fandhe-frontend. Integración de SSR, SPA, SSG y View Transitions, hidratación y distribución de un solo ejecutable. Diseño seguro con escape y prohibición predeterminados (unsafe_code). Cajas principales: núcleo, aplicación, interactivo, interfaz de usuario sin cabeza (primitivos), interfaz de usuario prediseñada (temas), servidor (SSG generate_pages/generate_assets) (con el prefijo fandhe-frontend-). Marco CLI (nuevo, puerta, estructura, impacto).
