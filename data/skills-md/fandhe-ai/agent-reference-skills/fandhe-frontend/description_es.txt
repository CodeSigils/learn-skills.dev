Referencia para el marco de interfaz de usuario basado en Rust **fandhe-frontend**. Integración de SSR, SPA, SSG y View Transitions, hidratación y distribución como un único archivo ejecutable. Diseño seguro con escape predeterminado y "prohibir (código_inseguro)". Cajas principales: `core`, `app`, `interactive`, `headless-ui` (primitivos), `pre-styled-ui` (temas), `server` (SSG `generate_pages`/`generate_assets`), todos con el prefijo `fandhe-frontend-`. Marco CLI (`nuevo` / `puerta` / `estructura` / `impacto`).
