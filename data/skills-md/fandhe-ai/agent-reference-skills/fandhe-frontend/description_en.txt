Reference for the Rust-based frontend framework fandhe-frontend. Integration of SSR, SPA, SSG, and View Transitions, hydration, and single‑executable distribution. Safe design with default escape and forbid(unsafe_code). Main crates: core, app, interactive, headless‑ui (Primitives), pre‑styled‑ui (Themes), server (SSG generate_pages/generate_assets) (prefixed with fandhe‑frontend‑). CLI framework (new, gate, structure, impact).
