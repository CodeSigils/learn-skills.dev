Reference for the Rust-based frontend framework **fandhe-frontend**. Integration of SSR, SPA, SSG, and View Transitions, hydration, and distribution as a single executable file. Safe design with default escaping and `forbid(unsafe_code)`. Main crates: `core`, `app`, `interactive`, `headless-ui` (primitives), `pre-styled-ui` (themes), `server` (SSG `generate_pages`/`generate_assets`)—all prefixed with `fandhe-frontend-`. CLI framework (`new` / `gate` / `structure` / `impact`).
