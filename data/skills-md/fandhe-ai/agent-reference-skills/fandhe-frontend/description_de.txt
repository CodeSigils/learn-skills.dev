Referenz für das Rust-basierte Frontend-Framework fandhe-frontend. Integration von SSR, SPA, SSG und Ansichtsübergängen, Hydratation und Verteilung einzelner ausführbarer Dateien. Sicheres Design mit Standard-Escape und Forbid (unsafe_code). Hauptkästen: Core, App, Interactive, Headless-UI (Primitives), Pre-Styled-UI (Themes), Server (SSGgenerate_pages/generate_assets) (mit dem Präfix „fandhe-frontend“). CLI-Framework (Neu, Gate, Struktur, Auswirkung).
