Справочник по интерфейсной платформе **fandhe-frontend** на основе Rust. Интеграция SSR/SPA/SSG/View Transitions, гидратация и распространение в виде одного исполняемого файла. Безопасный дизайн с экранированием по умолчанию и запретом (unsafe_code). Основные крейты: `core`/`app`/`interactive`/`headless-ui`(Primitives)/`pre-styled-ui`(Themes)/`server`(SSG `generate_pages`/`generate_assets`) (с префиксом `fandhe-frontend-`). Фреймворк CLI (новый/ворота/структура/воздействие).
