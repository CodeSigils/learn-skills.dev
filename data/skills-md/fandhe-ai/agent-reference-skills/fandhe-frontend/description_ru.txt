Справочник по интерфейсной платформе **fandhe-frontend** на основе Rust. Интеграция SSR, SPA, SSG и View Transitions, гидратация и распространение в виде одного исполняемого файла. Безопасный дизайн с экранированием по умолчанию и запретом (unsafe_code). Основные крейты: `core`, `app`, `interactive`, `headless-ui` (примитивы), `pre-styled-ui` (темы), `server` (SSG `generate_pages`/`generate_assets`) — все с префиксом `fandhe-frontend-`. Фреймворк CLI («новый» / «ворота» / «структура» / «воздействие»).
