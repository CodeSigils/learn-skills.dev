Справочник по Zod (библиотеке проверки схемы, ориентированной на TypeScript). Определения схем, такие как z.object, z.string, z.number, z.array, z.union, z.enum и т. д.; синтаксический анализ, SafeParse, z.infer (выведение типа), уточнение, преобразование, конвейер, по умолчанию, необязательный, допускающий значение NULL; обработка ошибок; миграция на Zod4.
