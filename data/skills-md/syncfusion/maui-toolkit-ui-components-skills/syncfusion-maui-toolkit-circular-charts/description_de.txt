Implementiert Syncfusion .NET MAUI-Kreisdiagramme (SfCircularChart), einschließlich Kreis-, Donut- und radialer Balkendiagrammtypen. Verwenden Sie diese Option, wenn Sie eine kreisförmige Datenvisualisierung, Kreisdiagramme, Donut-Diagramme oder radiale Balkendiagramme implementieren. Ideal für prozentuale Aufschlüsselungen, Kategorievergleiche, Teil-zu-Ganze-Beziehungen oder die Anzeige proportionaler Daten im Kreisformat.
