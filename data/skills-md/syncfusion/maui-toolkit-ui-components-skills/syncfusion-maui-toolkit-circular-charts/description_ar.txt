يطبق المخططات الدائرية Syncfusion .NET MAUI (SfCircularChart) بما في ذلك أنواع المخططات الشريطية الدائرية والدونات والشعاعية. يُستخدم عند تنفيذ تصور البيانات الدائرية، أو المخططات الدائرية، أو المخططات الدائرية، أو المخططات الشريطية الشعاعية. مثالية لتقسيم النسبة المئوية، أو مقارنات الفئات، أو العلاقات من جزء إلى كل، أو عرض البيانات التناسبية بتنسيق دائري.
