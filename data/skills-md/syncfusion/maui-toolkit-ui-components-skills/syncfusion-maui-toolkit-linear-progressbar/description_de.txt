Implementiert das Syncfusion .NET MAUI Linear ProgressBar-Steuerelement (SfLinearProgressBar). Verwenden Sie diese Option, wenn Sie mit Fortschrittsbalken, Fortschrittsindikatoren, Ladeindikatoren, bestimmtem/unbestimmtem Fortschritt oder Pufferfortschrittsvisualisierung arbeiten. Umfasst Fortschrittsverfolgung, Fortschritt in mehreren Segmenten, animierten Fortschritt und Verlaufsfortschrittsbalken.
