Implementa il controllo Syncfusion .NET MAUI Linear ProgressBar (SfLinearProgressBar). Da utilizzare quando si lavora con barre di avanzamento, indicatori di avanzamento, indicatori di caricamento, avanzamento determinato/indeterminato o visualizzazione dell'avanzamento del buffer. Copre il monitoraggio dell'avanzamento, l'avanzamento multisegmento, l'avanzamento animato e le barre di avanzamento del gradiente.
