Реализует элемент управления Syncfusion .NET MAUI Linear ProgressBar (SfLinearProgressBar). Используйте при работе с индикаторами выполнения, индикаторами прогресса, индикаторами загрузки, определенным/неопределенным прогрессом или визуализацией прогресса буферизации. Охватывает отслеживание прогресса, многосегментный прогресс, анимированный прогресс и градиентные индикаторы выполнения.
