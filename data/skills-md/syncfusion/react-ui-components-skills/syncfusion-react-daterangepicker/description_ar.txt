قم بتنفيذ مكون Syncfusion React DateRangePicker لتحديد النطاق الزمني وأنظمة الحجز وواجهات إعداد التقارير. استخدم هذا عند العمل مع منتقي النطاق الزمني لحجز المواعيد أو جدولة الأحداث أو تصفية التاريخ أو طلبات العطلات. يغطي التحقق من صحة النطاق الزمني، والنطاقات المحددة مسبقًا، وتخصيص التنسيق، ومعالجة الأحداث، وتكامل النماذج.
