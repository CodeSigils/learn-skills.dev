ينفذ Syncfusion React contextMenu (SfContextMenu) لتفاعلات النقر بزر الماوس الأيمن والقوائم المنبثقة الحساسة للسياق. استخدم هذا عند إضافة عناصر القائمة، أو التعامل مع أحداث التحديد، أو تخصيص القوالب والتصميم. يغطي الإعداد وربط البيانات وإمكانية الوصول والتنقل باستخدام لوحة المفاتيح والأساليب والخصائص الشائعة وأنماط التكامل.
