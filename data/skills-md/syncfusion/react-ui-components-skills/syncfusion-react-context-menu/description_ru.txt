Реализует Syncfusion React ContextMenu (SfContextMenu) для взаимодействия с помощью щелчка правой кнопкой мыши и контекстно-зависимых всплывающих меню. Используйте это при добавлении пунктов меню, обработке событий выбора или настройке шаблонов и стилей. Охватывает настройку, привязку данных, специальные возможности, навигацию с помощью клавиатуры, общие методы и свойства, а также шаблоны интеграции.
