Implementa il componente Syncfusion React Dropdown Tree per la selezione gerarchica dei dati con l'interazione a discesa. Utilizzalo quando lavori con caselle di controllo a selezione multipla, caricamento lento, integrazione OData remota, modelli personalizzati, navigazione da tastiera, supporto RTL o interfacce localizzate. Supporta la gerarchia di controllo automatico, il filtraggio, le impostazioni dell'albero, la gestione completa degli eventi e l'accessibilità completa.
