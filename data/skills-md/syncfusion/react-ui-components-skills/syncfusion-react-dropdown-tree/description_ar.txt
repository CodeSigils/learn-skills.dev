قم بتنفيذ مكون شجرة القائمة المنسدلة Syncfusion React لاختيار البيانات الهرمية مع تفاعل القائمة المنسدلة. استخدم هذا عند العمل مع مربعات الاختيار متعددة التحديد، أو التحميل البطيء، أو تكامل OData عن بعد، أو القوالب المخصصة، أو التنقل عبر لوحة المفاتيح، أو دعم RTL، أو الواجهات المترجمة. يدعم التحقق التلقائي من التسلسل الهرمي، والتصفية، وإعدادات الشجرة، والتعامل الشامل مع الأحداث، وإمكانية الوصول الكامل.
