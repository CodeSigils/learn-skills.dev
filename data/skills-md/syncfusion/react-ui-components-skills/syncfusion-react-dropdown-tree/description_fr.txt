Implémentez le composant Syncfusion React Dropdown Tree pour la sélection hiérarchique des données avec interaction dans la liste déroulante. Utilisez-le lorsque vous travaillez avec des cases à cocher à sélection multiple, un chargement paresseux, une intégration OData à distance, des modèles personnalisés, une navigation au clavier, une prise en charge RTL ou des interfaces localisées. Prend en charge la hiérarchie de vérification automatique, le filtrage, les paramètres d'arborescence, la gestion complète des événements et l'accessibilité complète.
