Внедрите компонент Syncfusion React ListView для отображения динамических списков с одиночным или множественным выбором, шаблонами, фильтрацией, группировкой, перетаскиванием и виртуализацией. Используйте это, когда вам нужна визуализация списков, управление элементами, обработка выбора, пользовательские шаблоны и фильтрация данных. Поддерживает локальную и удаленную привязку данных, флажки, анимацию, RTL и функции специальных возможностей.
