Implémentez le composant Syncfusion React ListView pour afficher des listes dynamiques avec sélection simple/multiple, modèles, filtrage, regroupement, glisser-déposer et virtualisation. Utilisez-le lorsque vous avez besoin de visualisation de liste, de gestion d'éléments, de gestion de sélection, de modèles personnalisés et de filtrage de données. Prend en charge la liaison de données locale/à distance, les cases à cocher, les animations, RTL et les fonctionnalités d'accessibilité.
