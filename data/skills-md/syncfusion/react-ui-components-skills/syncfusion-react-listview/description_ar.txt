قم بتنفيذ مكون Syncfusion React ListView لعرض القوائم الديناميكية مع تحديد فردي/متعدد، والقوالب، والتصفية، والتجميع، والسحب والإفلات، والمحاكاة الافتراضية. استخدم هذا عندما تحتاج إلى تصور القائمة وإدارة العناصر ومعالجة التحديد والقوالب المخصصة وتصفية البيانات. يدعم ربط البيانات المحلية/البعيدة، ومربعات الاختيار، والرسوم المتحركة، وRTL، وميزات إمكانية الوصول.
