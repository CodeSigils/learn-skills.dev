ينفذ مكون Syncfusion React Stock Chart لتصور البيانات المالية وبيانات السوق. استخدم هذا عندما يحتاج المستخدمون إلى تصور لسعر السهم، أو مخططات OHLC، أو مخططات الشموع اليابانية، أو واجهات مخططات التداول. يدعم أنواع سلاسل متعددة، ومحددات الفترة، وأدوات الملاحة في النطاق، والمؤشرات الفنية (على سبيل المثال، SMA، وMACD، وBollinger Bands)، وأدوات التحليل التفاعلية للبيانات المالية في تطبيقات React.
