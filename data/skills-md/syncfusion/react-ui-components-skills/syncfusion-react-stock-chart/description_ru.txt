Реализует компонент Syncfusion React Stock Chart для визуализации финансовых и рыночных данных. Используйте это, когда пользователям нужна визуализация цен на акции, диаграммы OHLC, свечные графики или интерфейсы торговых графиков. Поддерживает несколько типов рядов, селекторы периодов, навигаторы диапазонов, технические индикаторы (например, SMA, MACD, полосы Боллинджера) и инструменты интерактивного анализа финансовых данных в приложениях React.
