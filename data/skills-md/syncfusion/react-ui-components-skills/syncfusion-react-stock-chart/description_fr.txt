Implémente le composant Syncfusion React Stock Chart pour visualiser les données financières et de marché. Utilisez-le lorsque les utilisateurs ont besoin d'une visualisation du cours des actions, de graphiques OHLC, de graphiques en chandeliers ou d'interfaces de graphiques de trading. Prend en charge plusieurs types de séries, sélecteurs de période, navigateurs de plage, indicateurs techniques (par exemple, SMA, MACD, bandes de Bollinger) et outils d'analyse interactifs pour les données financières dans les applications React.
