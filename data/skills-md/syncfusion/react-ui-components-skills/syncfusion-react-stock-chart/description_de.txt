Implementiert die Syncfusion React Stock Chart-Komponente zur Visualisierung von Finanz- und Marktdaten. Verwenden Sie dies, wenn Benutzer eine Aktienkursvisualisierung, OHLC-Diagramme, Candlestick-Diagramme oder Handelsdiagrammschnittstellen benötigen. Unterstützt mehrere Serientypen, Periodenselektoren, Bereichsnavigatoren, technische Indikatoren (z. B. SMA, MACD, Bollinger-Bänder) und interaktive Analysetools für Finanzdaten in React-Anwendungen.
