Реализует компонент Syncfusion React 3D Circular Chart для визуализации круговых и кольцевых диаграмм. Используйте это, когда пользователям нужны круговые трехмерные диаграммы, метки данных, легенды, всплывающие подсказки или обработка пустых точек. Помогает установить, настроить, настроить и устранить неполадки трехмерных круговых диаграмм в приложениях React.
