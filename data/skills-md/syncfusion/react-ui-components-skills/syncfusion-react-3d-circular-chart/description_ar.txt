يطبق مكون المخطط الدائري Syncfusion React 3D لتصور المخطط الدائري والدائري المجوف. استخدم هذا عندما يحتاج المستخدمون إلى مخططات دائرية ثلاثية الأبعاد، أو تسميات البيانات، أو وسائل الإيضاح، أو تلميحات الأدوات، أو معالجة النقاط الفارغة. يرشدك خلال التثبيت والتكوين والتخصيص واستكشاف الأخطاء وإصلاحها للمخططات الدائرية ثلاثية الأبعاد في تطبيقات React.
