دليل شامل لتنفيذ مكونات Syncfusion React Notification بما في ذلك الرسالة والهيكل العظمي والخبز المحمص والغزل. استخدم هذا عند عرض رسائل إعلامية أو نجاح أو تحذير أو خطأ؛ تكوين مستويات الخطورة ومتغيرات العرض (نص، محدد، معبأ)؛ التعامل مع رفض الرسالة؛ تحديد موضع الخبز المحمص، وقوالب الخبز المحمص، ورسوم الخبز المحمص؛ عرض العناصر النائبة للتحميل الهيكلي مع الرسوم المتحركة المتلألئة (موجة، نبض، تلاشي) والأشكال (دائرة، مستطيل، نص)؛ أو تخصيص مظهر الإشعارات وإمكانية الوصول إليها.
