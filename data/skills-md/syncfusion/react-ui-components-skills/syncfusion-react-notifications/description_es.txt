Guía completa para implementar los componentes de notificación de Syncfusion React, incluidos Message, Skeleton, Toast y Spinner. Úselo cuando muestre mensajes informativos, de éxito, de advertencia o de error; configurar niveles de gravedad y variantes de visualización (texto, delineado, relleno); manejo del descarte de mensajes; posicionamiento de brindis, plantillas de brindis, animaciones de brindis; mostrar marcadores de posición de carga de esqueleto con animaciones brillantes (onda, pulso, desvanecimiento) y formas (círculo, rectángulo, texto); o personalizar la apariencia y accesibilidad de las notificaciones.
