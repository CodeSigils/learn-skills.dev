Implementa il componente Syncfusion React 3D Chart dal pacchetto @syncfusion/ej2-react-charts. Utilizza questa funzionalità quando gli utenti necessitano di varianti di grafici a colonne, a barre, a colonne in pila, a barre in pila 3D o al 100% del grafico in pila. Copre Chart3DComponent, configurazione degli assi (categoria, numerico, data/ora, logaritmico), associazione dati, riquadri multipli, etichette dati, legende, descrizioni comandi, selezione, stampa/esportazione, temi e accessibilità.
