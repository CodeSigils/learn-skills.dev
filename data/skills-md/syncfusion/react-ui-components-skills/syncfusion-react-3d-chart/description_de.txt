Implementieren Sie die Syncfusion React 3D Chart-Komponente aus dem Paket @syncfusion/ej2-react-charts. Verwenden Sie diese Fähigkeit, wenn Benutzer 3D-Säulen-, Balken-, gestapelte Säulen-, gestapelte Balken- oder 100 % gestapelte Diagrammvarianten benötigen. Behandelt Chart3DComponent, Achsenkonfiguration (Kategorie, numerisch, Datum/Uhrzeit, logarithmisch), Datenbindung, mehrere Bereiche, Datenbeschriftungen, Legenden, Tooltips, Auswahl, Drucken/Exportieren, Themengestaltung und Barrierefreiheit.
