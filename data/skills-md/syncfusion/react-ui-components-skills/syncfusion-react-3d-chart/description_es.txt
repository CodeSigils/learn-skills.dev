Implemente el componente Syncfusion React 3D Chart del paquete @syncfusion/ej2-react-charts. Utilice esta habilidad cuando los usuarios necesiten columnas 3D, barras, columnas apiladas, barras apiladas o variaciones de gráficos 100% apilados. Cubre Chart3DComponent, configuración de ejes (categoría, numérica, fecha y hora, logarítmica), enlace de datos, paneles múltiples, etiquetas de datos, leyendas, información sobre herramientas, selección, impresión/exportación, temática y accesibilidad.
