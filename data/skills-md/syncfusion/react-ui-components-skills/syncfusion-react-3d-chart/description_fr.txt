Implémentez le composant Syncfusion React 3D Chart à partir du package @syncfusion/ej2-react-charts. Utilisez cette compétence lorsque les utilisateurs ont besoin de variations de colonnes 3D, de barres, de colonnes empilées, de barres empilées ou de graphiques empilés à 100 %. Couvre Chart3DComponent, la configuration des axes (catégorie, numérique, date/heure, logarithmique), la liaison de données, les volets multiples, les étiquettes de données, les légendes, les info-bulles, la sélection, l'impression/exportation, la thématique et l'accessibilité.
