Внедрите компонент Syncfusion React 3D Chart из пакета @syncfusion/ej2-react-charts. Используйте этот навык, когда пользователям нужны трехмерные столбцы, столбцы, столбцы с накоплением, столбцы с накоплением или 100% варианты диаграмм с накоплением. Охватывает Chart3DComponent, конфигурацию осей (категория, числовая, дата-время, логарифмическая), привязку данных, несколько панелей, метки данных, легенды, подсказки, выбор, печать/экспорт, оформление тем и специальные возможности.
