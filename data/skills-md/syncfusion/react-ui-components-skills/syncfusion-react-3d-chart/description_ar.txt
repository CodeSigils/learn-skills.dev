قم بتنفيذ مكون Syncfusion React 3D Chart من حزمة @syncfusion/ej2-react-charts. استخدم هذه المهارة عندما يحتاج المستخدمون إلى أعمدة ثلاثية الأبعاد، أو شريط، أو عمود مكدس، أو شريط مكدس، أو أشكال مخططات مكدسة بنسبة 100%. يغطي Chart3DComponent، وتكوين المحور (الفئة، والرقم، والوقت، واللوغاريتمي)، وربط البيانات، والأجزاء المتعددة، وتسميات البيانات، والأساطير، وتلميحات الأدوات، والتحديد، والطباعة/التصدير، والسمات، وإمكانية الوصول.
