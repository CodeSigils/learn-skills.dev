Внедрите и настройте компонент Syncfusion React Breadcrumb для путей навигации, маршрутизации и иерархии сайтов. Используйте этот навык всякий раз, когда пользователям нужна навигационная цепочка, они хотят создавать иерархические пути навигации, отображать навигационные цепочки, управлять навигацией между страницами, настраивать поведение при переполнении или интегрировать навигационные цепочки с библиотеками маршрутизации.
