قم بتنفيذ مكون Syncfusion React Breadcrumb وتكوينه لمسارات التنقل والتوجيه والتسلسل الهرمي للموقع. استخدم هذه المهارة عندما يحتاج المستخدمون إلى التنقل التفصيلي، أو يريدون إنشاء مسارات تنقل هرمية، أو عرض فتات التنقل للموقع، أو التعامل مع التنقل بين الصفحات، أو تخصيص سلوكيات التجاوز، أو دمج مسارات التنقل مع مكتبات التوجيه.
