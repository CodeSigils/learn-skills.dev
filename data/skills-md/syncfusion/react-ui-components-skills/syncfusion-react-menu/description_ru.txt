Создайте и настройте компонент навигации Syncfusion React Menu для иерархических структур меню, 
выпадающие списки и контекстные меню. Используйте этот навык всякий раз, когда пользователю нужно реализовать меню, панели навигации, 
выпадающие меню, меню-гамбургеры, мобильные меню, расположение подменю, взаимодействие пунктов меню, меню привязки данных, 
Макеты меню RTL, настройка меню с помощью значков/разделителей, обработка событий или расширенные функции, такие как 
прокручиваемые меню, постоянство и управление состоянием элементов.
