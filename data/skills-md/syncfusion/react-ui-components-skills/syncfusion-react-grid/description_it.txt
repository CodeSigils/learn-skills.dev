Implementa il componente Syncfusion React Grid per tabelle e griglie di dati ricche di funzionalità. Utilizzalo quando lavori con la visualizzazione, l'ordinamento, il filtraggio, il raggruppamento, l'aggregazione, la modifica o l'esportazione dei dati. Questa competenza copre la configurazione della griglia, le operazioni CRUD, lo scorrimento virtuale o scorrimento infinito, le griglie gerarchiche, la persistenza dello stato e le funzionalità avanzate di gestione dei dati per applicazioni ad uso intensivo di dati.
