Implémente le composant Syncfusion React Grid pour les tables et grilles de données riches en fonctionnalités. Utilisez-le lorsque vous travaillez avec l'affichage, le tri, le filtrage, le regroupement, les agrégats, la modification ou l'exportation de données. Cette compétence couvre la configuration de la grille, les opérations CRUD, le défilement virtuel ou le défilement infini, les grilles hiérarchiques, la persistance de l'état et les fonctionnalités avancées de gestion des données pour les applications gourmandes en données.
