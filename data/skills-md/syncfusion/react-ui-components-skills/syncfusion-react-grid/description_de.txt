Implementiert die Syncfusion React Grid-Komponente für funktionsreiche Datentabellen und Grids. Verwenden Sie dies, wenn Sie mit der Datenanzeige, dem Sortieren, Filtern, Gruppieren, Aggregieren, Bearbeiten oder Exportieren arbeiten. Diese Fertigkeit umfasst Rasterkonfiguration, CRUD-Operationen, virtuelles Scrollen oder unendliches Scrollen, Hierarchieraster, Zustandspersistenz und erweiterte Datenverwaltungsfunktionen für datenintensive Anwendungen.
