ينفذ مكون Syncfusion React Grid لجداول وشبكات البيانات الغنية بالميزات. استخدم هذا عند العمل مع عرض البيانات أو فرزها أو تصفيتها أو تجميعها أو تجميعها أو تحريرها أو تصديرها. تغطي هذه المهارة تكوين الشبكة، وعمليات CRUD، والتمرير الافتراضي أو التمرير اللانهائي، وشبكات التسلسل الهرمي، واستمرارية الحالة، وميزات إدارة البيانات المتقدمة للتطبيقات كثيفة البيانات.
