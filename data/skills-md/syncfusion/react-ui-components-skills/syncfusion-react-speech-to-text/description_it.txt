Implementa il componente Syncfusion React SpeechToText. Utilizza questa competenza per convertire la voce in testo, gestire l'input del microfono, controllare gli stati di ascolto, elaborare eventi vocali, personalizzare l'interfaccia utente, supportare moduli accessibili abilitati alla voce e gestire la globalizzazione e la sicurezza nelle applicazioni React.
