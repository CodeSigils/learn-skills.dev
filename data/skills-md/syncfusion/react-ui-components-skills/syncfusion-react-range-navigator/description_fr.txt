Implémente le composant Syncfusion React Range Navigator pour faire défiler et naviguer dans les données avec sélection de plage. Utilisez-le lorsque les utilisateurs ont besoin d'une navigation basée sur le temps, d'une visualisation de données financières ou d'une intégration de graphiques avec un contrôle de sélection de plage. Prend en charge la liaison de données numériques, logarithmiques et DateTime, plusieurs types de séries, le sélecteur de période, le mode léger, les info-bulles, RTL et la fonctionnalité d'exportation/impression.
