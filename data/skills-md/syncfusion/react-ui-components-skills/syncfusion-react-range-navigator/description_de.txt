Implementiert die Syncfusion React Range Navigator-Komponente zum Scrollen und Navigieren durch Daten mit Bereichsauswahl. Verwenden Sie dies, wenn Benutzer zeitbasierte Navigation, Finanzdatenvisualisierung oder Diagrammintegration mit einer Bereichsauswahlsteuerung benötigen. Unterstützt numerische, logarithmische und DateTime-Datenbindung, mehrere Serientypen, Periodenauswahl, Lightweight-Modus, Tooltips, RTL und Export-/Druckfunktionen.
