Implementa el componente Syncfusion React Range Navigator para desplazarse y navegar a través de datos con selección de rango. Utilícelo cuando los usuarios necesiten navegación basada en el tiempo, visualización de datos financieros o integración de gráficos con un control selector de rango. Admite enlace de datos numéricos, logarítmicos y de fecha y hora, múltiples tipos de series, selector de período, modo ligero, información sobre herramientas, RTL y funcionalidad de exportación/impresión.
