ينفذ مكون Syncfusion React Range Navigator للتمرير والتنقل عبر البيانات مع تحديد النطاق. استخدم هذا عندما يحتاج المستخدمون إلى التنقل المستند إلى الوقت، أو تصور البيانات المالية، أو تكامل المخطط مع عنصر تحكم محدد النطاق. يدعم ربط البيانات الرقمية واللوغاريتمية والتاريخية وأنواع السلاسل المتعددة ومحدد الفترة والوضع الخفيف وتلميحات الأدوات وRTL ووظيفة التصدير/الطباعة.
