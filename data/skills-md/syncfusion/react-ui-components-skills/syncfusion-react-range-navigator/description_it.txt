Implementa il componente Syncfusion React Range Navigator per lo scorrimento e la navigazione tra i dati con la selezione dell'intervallo. Utilizzalo quando gli utenti necessitano di navigazione basata sul tempo, visualizzazione di dati finanziari o integrazione di grafici con un controllo selettore di intervallo. Supporta associazione dati numerici, logaritmici e DateTime, tipi di serie multipli, selettore di periodi, modalità leggera, descrizioni comandi, RTL e funzionalità di esportazione/stampa.
