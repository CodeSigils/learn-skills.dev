Реализует компонент Syncfusion React Range Navigator для прокрутки и навигации по данным с выбором диапазона. Используйте это, когда пользователям нужна навигация по времени, визуализация финансовых данных или интеграция диаграмм с элементом управления выбором диапазона. Поддерживает привязку числовых, логарифмических данных и данных DateTime, несколько типов рядов, выбор периода, упрощенный режим, всплывающие подсказки, RTL и функции экспорта/печати.
