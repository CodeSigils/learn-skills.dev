الدليل الكامل لتنفيذ مكون Syncfusion React Carousel لمعارض الصور الدوارة ودوائر المنتجات وعروض عرض الشرائح والشهادات وعرض المحتوى المتسلسل. استخدم هذه المهارة عند العمل مع انتقالات الشرائح وعناصر التحكم في التنقل والرسوم المتحركة والتصميم وميزات إمكانية الوصول. يغطي التثبيت وعدد العناصر وجميع خصائص واجهة برمجة التطبيقات وطرقها وأحداثها.
