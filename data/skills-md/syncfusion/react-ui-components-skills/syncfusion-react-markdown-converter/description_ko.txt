Markdown 텍스트를 깨끗한 HTML로 변환하려면 React에서 Syncfusion Markdown Converter를 구현하세요. React에서 Markdown을 HTML로 변환하거나, Markdown 모드에서 서식 있는 텍스트 편집기와 라이브 Markdown 미리 보기를 통합하거나, GFM 또는 줄바꿈 옵션을 구성하거나, MarkdownConverter.toHtml() 및 MarkdownConverterOptions로 작업할 때 이 기능을 사용하세요. 이 기술은 @syncfusion/ej2-markdown-converter 패키지 및 React 애플리케이션의 HTML 미리보기와 Markdown 편집기 통합을 다룹니다.
