Внедрите конвертер Syncfusion Markdown в React, чтобы преобразовать текст Markdown в чистый HTML. Используйте это при преобразовании Markdown в HTML в React, интеграции предварительного просмотра Markdown в реальном времени с редактором форматированного текста в режиме Markdown, настройке параметров GFM или разрыва строки, а также при работе с MarkdownConverter.toHtml() и MarkdownConverterOptions. Этот навык охватывает пакет @syncfusion/ej2-markdown-converter и интеграцию редактора Markdown с предварительным просмотром HTML в приложениях React.
