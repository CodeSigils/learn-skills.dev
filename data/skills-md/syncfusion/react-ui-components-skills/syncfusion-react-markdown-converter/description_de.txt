Implementieren Sie den Syncfusion Markdown Converter in React, um Markdown-Text in sauberes HTML zu konvertieren. Verwenden Sie dies, wenn Sie Markdown in React in HTML konvertieren, eine Live-Markdown-Vorschau mit dem Rich-Text-Editor im Markdown-Modus integrieren, GFM- oder Zeilenumbruchoptionen konfigurieren oder mit MarkdownConverter.toHtml() und MarkdownConverterOptions arbeiten. Diese Fertigkeit deckt das @syncfusion/ej2-markdown-converter-Paket und die Markdown-Editor-Integration mit der HTML-Vorschau in React-Anwendungen ab.
