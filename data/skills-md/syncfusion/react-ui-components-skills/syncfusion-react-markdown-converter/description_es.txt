Implemente Syncfusion Markdown Converter en React para convertir el texto de Markdown en HTML limpio. Úselo al convertir Markdown a HTML en React, integrar una vista previa de Markdown en vivo con el Editor de texto enriquecido en modo Markdown, configurar GFM o opciones de salto de línea, o trabajar con MarkdownConverter.toHtml() y MarkdownConverterOptions. Esta habilidad cubre el paquete @syncfusion/ej2-markdown-converter y la integración de Markdown Editor con la vista previa HTML en aplicaciones React.
