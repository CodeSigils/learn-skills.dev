قم بتنفيذ محول Syncfusion Markdown في React لتحويل نص Markdown إلى HTML نظيف. استخدم هذا عند تحويل Markdown إلى HTML في React، أو دمج معاينة Markdown المباشرة مع محرر النص المنسق في وضع Markdown، أو تكوين خيارات GFM أو فاصل الأسطر، أو العمل مع MarkdownConverter.toHtml() وMarkdownConverterOptions. تغطي هذه المهارة حزمة @syncfusion/ej2-markdown-converter وتكامل Markdown Editor مع معاينة HTML في تطبيقات React.
