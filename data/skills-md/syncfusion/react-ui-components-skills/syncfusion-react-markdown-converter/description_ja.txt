React に Syncfusion Markdown Converter を実装して、Markdown テキストをクリーンな HTML に変換します。これは、React で Markdown を HTML に変換する場合、Markdown モードのリッチ テキスト エディターとライブ Markdown プレビューを統合する場合、GFM または改行オプションを構成する場合、または MarkdownConverter.toHtml() および MarkdownConverterOptions を操作する場合に使用します。このスキルでは、@syncfusion/ej2-markdown-converter パッケージと、React アプリケーションでの Markdown Editor の HTML プレビューとの統合について説明します。
