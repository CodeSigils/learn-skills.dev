Implementa Syncfusion Markdown Converter in React per convertire il testo Markdown in HTML pulito. Utilizzalo quando converti Markdown in HTML in React, integra un'anteprima Markdown live con l'editor Rich Text in modalità Markdown, configura GFM o opzioni di interruzione di riga o lavora con MarkdownConverter.toHtml() e MarkdownConverterOptions. Questa competenza copre il pacchetto @syncfusion/ej2-markdown-converter e l'integrazione di Markdown Editor con l'anteprima HTML nelle applicazioni React.
