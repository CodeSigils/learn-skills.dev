قم بتطبيق مكون Syncfusion React File Manager للتنقل في نظام الملفات وإدارته. يُستخدم عندما يحتاج المستخدمون إلى تصفح الملفات، أو تحميلها/تنزيلها، أو عمليات الملفات (الإنشاء، أو الحذف، أو إعادة التسمية)، أو طرق العرض المتعددة، أو السحب والإفلات، أو التخصيص، أو ميزات إمكانية الوصول. يدعم أنظمة الملفات المحلية والبعيدة مع خيارات التخصيص الشاملة.
