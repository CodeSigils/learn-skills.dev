Внедрите компонент Syncfusion React File Manager для навигации и управления файловой системой. Используйте, когда пользователям нужен просмотр файлов, загрузка/скачивание, операции с файлами (создание, удаление, переименование), несколько представлений, перетаскивание, настройка или специальные возможности. Поддерживает локальные и удаленные файловые системы с широкими возможностями настройки.
