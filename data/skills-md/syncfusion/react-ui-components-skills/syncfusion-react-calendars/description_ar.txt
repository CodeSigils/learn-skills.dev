دليل شامل لتنفيذ مكونات Syncfusion React Calendar بما في ذلك Calendar وDatePicker وDateRangePicker وDateTimePicker وTimePicker. يغطي التثبيت، وربط البيانات، واختيار التاريخ/الوقت، واختيار النطاق، والتنسيق، والترجمة، والإخفاء، والتحقق من الصحة، والتخصيص، والقوالب، وإمكانية الوصول، وأنماط المكونات التي يتم التحكم فيها في تطبيقات React.
