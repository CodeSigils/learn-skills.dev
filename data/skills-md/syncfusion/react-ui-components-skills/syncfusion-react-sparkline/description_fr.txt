Implémentez les composants Syncfusion React Sparkline pour une visualisation de données compacte et en ligne. Utilisez-le lorsque vous travaillez avec des sparklines, des mini-graphiques ou des indicateurs de tendance dans des espaces contraints. Cette compétence couvre les 5 types de sparklines (ligne, colonne, zone, gain-perte, tarte), les info-bulles, les marqueurs, les étiquettes de données, les bandes de plage, la personnalisation des axes et les thèmes. Idéal pour afficher les tendances des données dans des grilles, des tableaux de bord ou des tableaux sans graphiques en taille réelle.
