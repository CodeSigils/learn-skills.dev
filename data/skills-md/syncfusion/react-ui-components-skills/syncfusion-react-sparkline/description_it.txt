Implementa i componenti Syncfusion React Sparkline per la visualizzazione compatta e in linea dei dati. Utilizzalo quando lavori con sparkline, mini grafici o indicatori di tendenza in spazi ristretti. Questa competenza copre tutti e 5 i tipi di sparkline (linea, colonna, area, vincita-sconfitta, torta), descrizioni comandi, indicatori, etichette dati, fasce di intervallo, personalizzazione degli assi e temi. Ideale per visualizzare le tendenze dei dati all'interno di griglie, dashboard o tabelle senza grafici a grandezza naturale.
