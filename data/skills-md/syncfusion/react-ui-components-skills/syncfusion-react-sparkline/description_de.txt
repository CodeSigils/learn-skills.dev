Implementieren Sie Syncfusion React Sparkline-Komponenten für eine kompakte Inline-Datenvisualisierung. Verwenden Sie dies, wenn Sie mit Sparklines, Minidiagrammen oder Trendindikatoren auf engstem Raum arbeiten. Diese Fertigkeit deckt alle 5 Sparkline-Typen (Linie, Spalte, Fläche, Gewinn-Verlust, Kreis), Tooltips, Markierungen, Datenbeschriftungen, Bereichsbänder, Achsenanpassung und Themen ab. Ideal für die Anzeige von Datentrends in Rastern, Dashboards oder Tabellen ohne Diagramme in Originalgröße.
