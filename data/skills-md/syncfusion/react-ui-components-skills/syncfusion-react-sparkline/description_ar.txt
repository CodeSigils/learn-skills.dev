قم بتنفيذ مكونات Syncfusion React Sparkline لتصور البيانات المدمجة والمضمنة. استخدم هذا عند العمل باستخدام خطوط المؤشرات أو المخططات المصغرة أو مؤشرات الاتجاه في المساحات المقيدة. تغطي هذه المهارة جميع أنواع خطوط المؤشر الخمسة (الخط، والعمود، والمنطقة، والربح والخسارة، والدائري)، وتلميحات الأدوات، والعلامات، وتسميات البيانات، ونطاقات النطاق، وتخصيص المحاور، والسمات. مثالية لعرض اتجاهات البيانات داخل الشبكات أو لوحات المعلومات أو الجداول بدون مخططات كاملة الحجم.
