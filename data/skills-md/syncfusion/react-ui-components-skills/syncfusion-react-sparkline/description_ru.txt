Внедрите компоненты Syncfusion React Sparkline для компактной встроенной визуализации данных. Используйте это при работе со спарклайнами, мини-диаграммами или индикаторами тренда в ограниченном пространстве. Этот навык охватывает все 5 типов спарклайнов (линия, столбец, область, выигрыш-проигрыш, круговая диаграмма), всплывающие подсказки, маркеры, метки данных, диапазоны диапазонов, настройку осей и темы. Идеально подходит для отображения тенденций данных в сетках, информационных панелях или таблицах без полноразмерных диаграмм.
