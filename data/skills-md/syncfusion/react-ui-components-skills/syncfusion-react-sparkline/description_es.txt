Implemente los componentes Syncfusion React Sparkline para una visualización de datos compacta y en línea. Úselo cuando trabaje con minigráficos, minigráficos o indicadores de tendencia en espacios restringidos. Esta habilidad cubre los 5 tipos de minigráficos (línea, columna, área, ganancias y pérdidas, circular), información sobre herramientas, marcadores, etiquetas de datos, bandas de rango, personalización de ejes y temas. Ideal para mostrar tendencias de datos dentro de cuadrículas, paneles o tablas sin gráficos de tamaño completo.
