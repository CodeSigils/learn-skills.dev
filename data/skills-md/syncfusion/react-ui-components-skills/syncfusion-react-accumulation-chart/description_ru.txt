Внедрите диаграммы накопления Syncfusion React, включая круговые, кольцевые, воронкообразные и пирамидальные диаграммы. Используйте этот навык, когда пользователям нужна круговая визуализация данных, процентные диаграммы или пропорциональное отображение данных. Охватывает метки данных, легенды, подсказки, группировку, интеллектуальные метки, детализированные диаграммы, эффекты разнесения, темы, доступность, возможности экспорта/печати и динамические обновления данных.
