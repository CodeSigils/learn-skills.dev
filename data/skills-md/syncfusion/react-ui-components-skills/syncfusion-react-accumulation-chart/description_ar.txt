تنفيذ مخططات تراكم Syncfusion React بما في ذلك أنواع المخططات الدائرية والدونات والقمع والهرمية. استخدم هذه المهارة عندما يحتاج المستخدمون إلى تصور دائري للبيانات، أو مخططات تعتمد على النسبة المئوية، أو عروض بيانات متناسبة. يغطي تسميات البيانات، والأساطير، وتلميحات الأدوات، والتجميع، والملصقات الذكية، والمخططات التفصيلية، والتأثيرات المتفجرة، والسمات، وإمكانية الوصول، وإمكانيات التصدير/الطباعة، وتحديثات البيانات الديناميكية.
