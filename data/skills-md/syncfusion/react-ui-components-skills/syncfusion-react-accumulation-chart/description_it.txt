Implementa i grafici di accumulo Syncfusion React, inclusi i tipi di grafico a torta, a ciambella, a imbuto e a piramide. Utilizza questa competenza quando gli utenti necessitano di visualizzazioni di dati circolari, grafici basati su percentuali o visualizzazioni di dati proporzionali. Copre etichette dati, legende, descrizioni comando, raggruppamento, etichette intelligenti, grafici drill-down, effetti esplosi, temi, accessibilità, funzionalità di esportazione/stampa e aggiornamenti dinamici dei dati.
