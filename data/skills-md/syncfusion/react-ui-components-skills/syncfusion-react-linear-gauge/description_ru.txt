Внедрите Syncfusion React Linear Gauge для отображения измерений в линейной шкале. Используйте этот навык, когда пользователям нужны датчики температуры, индикаторы ключевых показателей эффективности, индикаторы прогресса или панели мониторинга в реальном времени. Охватывает конфигурацию осей, типы указателей, диапазоны, аннотации, настройку, анимацию, печать/экспорт, доступность и интернационализацию.
