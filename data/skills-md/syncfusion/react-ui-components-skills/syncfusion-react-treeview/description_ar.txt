قم بتنفيذ مكون Syncfusion React TreeView لعرض البيانات الهرمية مع تحديد العقدة وإعادة ترتيب السحب والإفلات والتحرير المضمن والقوالب المخصصة. استخدم هذا عند إنشاء المخططات التنظيمية أو أنظمة الملفات أو أشجار التنقل أو أي واجهة هرمية متعددة المستويات. يغطي أوضاع التحديد ومربعات الاختيار والتصفية والفرز والتنقل باستخدام لوحة المفاتيح وإمكانية الوصول وتحسين الأداء باستخدام قوالب عديمة الحالة.
