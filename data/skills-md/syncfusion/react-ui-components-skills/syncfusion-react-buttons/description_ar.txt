دليل شامل لتنفيذ مكونات زر Syncfusion React بما في ذلك Button وButtonGroup وDropDownButton وزر الإجراء العائم وProgressButton وSplitButton وSpeed ​​Dial وزر Switch وزر الاختيار. استخدم هذا عند إضافة أزرار ذات نمط، أو سلوك تبديل، أو دعم أيقونات، أو تحديدات مجمعة، أو قوائم إجراءات منسدلة، أو تحكم برمجي في الإجراءات الأساسية العائمة، أو قوائم الاتصال السريع القابلة للتوسيع إلى تطبيق React.
