Комплексное руководство по реализации компонентов кнопок Syncfusion React, включая кнопку, ButtonGroup, DropDownButton, плавающую кнопку действия, ProgressButton, SplitButton, кнопку быстрого набора, переключатель и переключатель. Используйте это при добавлении стилизованных кнопок, поведения переключения, поддержки значков, сгруппированных вариантов выбора, раскрывающихся меню действий, плавающих основных действий программного управления или расширяемых меню быстрого набора в приложение React.
