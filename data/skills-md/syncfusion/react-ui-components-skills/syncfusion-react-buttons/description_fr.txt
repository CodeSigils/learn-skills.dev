Guide complet pour la mise en œuvre des composants du bouton Syncfusion React, notamment Button, ButtonGroup, DropDownButton, Floating Action Button, ProgressButton, SplitButton, Speed ​​Dial, Switch et le bouton radio. Utilisez-le lors de l'ajout de boutons stylisés, de comportements de bascule, de prise en charge d'icônes, de sélections groupées, de menus d'action déroulants, d'actions principales flottantes de contrôle programmatique ou de menus de numérotation abrégée extensibles à une application React.
