Внедрите Syncfusion React Circular Gauge для отображения ключевых показателей эффективности, данных датчиков, спидометров и панелей мониторинга в реальном времени. Используйте этот навык, когда пользователям необходимо визуализировать количественные измерения в круговой шкале. Охватывает оси, указатели, диапазоны, настройку, анимацию, печать/экспорт, доступность и интернационализацию.
