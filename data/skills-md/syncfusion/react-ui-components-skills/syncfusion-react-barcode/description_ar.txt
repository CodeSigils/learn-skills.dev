قم بإنشاء وتخصيص وتصدير الرموز الشريطية في React باستخدام Syncfusion BarcodeGenerator. تشغيل الطلبات التي تتضمن الرموز الشريطية Code39 أو Code128، ورموز QR، وإنشاء مصفوفة البيانات، وتصميم الرمز الشريطي (الحجم واللون والنص والهوامش)، وإعداد مكون React، والدعائم أو الأحداث، وعرض SVG أو Canvas، وتصدير صور الرمز الشريطي أو طباعتها.
