Внедрите компонент Syncfusion React HeatMap Chart для визуализации данных. Используйте этот навык, когда пользователю необходимо создавать тепловые карты, визуализировать шаблоны 2D-данных, отображать матричные данные с цветовыми градиентами, настраивать оси (числовые/категориальные/дата-время), реализовывать легенды, обрабатывать выбор ячеек, применять собственные стили или работать с большими наборами данных. Охватывает установку, привязку данных, настройку осей, настройку внешнего вида, шаблоны взаимодействия, всплывающие подсказки, события и специальные возможности.
