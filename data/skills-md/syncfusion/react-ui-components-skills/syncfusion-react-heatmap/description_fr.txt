Implémentez le composant Syncfusion React HeatMap Chart pour la visualisation des données. Utilisez cette compétence lorsque l'utilisateur doit créer des cartes thermiques, visualiser des modèles de données 2D, afficher des données matricielles avec des dégradés de couleurs, configurer des axes (numériques/catégoriels/date/heure), implémenter des légendes, gérer la sélection de cellules, appliquer un style personnalisé ou travailler avec de grands ensembles de données. Couvre l'installation, la liaison de données, la configuration des axes, la personnalisation de l'apparence, les modèles d'interaction, les info-bulles, les événements et l'accessibilité.
