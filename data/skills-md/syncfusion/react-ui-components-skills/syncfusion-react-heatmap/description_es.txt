Implemente el componente Syncfusion React HeatMap Chart para visualización de datos. Utilice esta habilidad cuando el usuario necesite crear mapas de calor, visualizar patrones de datos 2D, mostrar datos matriciales con degradados de color, configurar ejes (numéricos/categóricos/de fecha y hora), implementar leyendas, manejar la selección de celdas, aplicar estilos personalizados o trabajar con grandes conjuntos de datos. Cubre instalación, enlace de datos, configuración de ejes, personalización de apariencia, patrones de interacción, información sobre herramientas, eventos y accesibilidad.
