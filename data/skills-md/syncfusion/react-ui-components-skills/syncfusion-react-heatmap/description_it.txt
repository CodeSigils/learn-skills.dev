Implementare il componente Grafico Syncfusion React HeatMap per la visualizzazione dei dati. Utilizza questa competenza quando l'utente deve creare mappe di calore, visualizzare modelli di dati 2D, visualizzare dati di matrici con sfumature di colore, configurare assi (numerici/categoriali/data/ora), implementare legende, gestire la selezione di celle, applicare stili personalizzati o lavorare con set di dati di grandi dimensioni. Copre installazione, associazione dati, configurazione degli assi, personalizzazione dell'aspetto, modelli di interazione, descrizioni comandi, eventi e accessibilità.
