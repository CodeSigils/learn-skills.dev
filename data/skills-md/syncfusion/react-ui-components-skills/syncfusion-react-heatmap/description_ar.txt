تنفيذ مكون مخطط Syncfusion React HeatMap لتصور البيانات. استخدم هذه المهارة عندما يحتاج المستخدم إلى إنشاء خرائط حرارية، أو تصور أنماط بيانات ثنائية الأبعاد، أو عرض بيانات المصفوفة بتدرجات لونية، أو تكوين محاور (رقمية/فئوية/وقت التاريخ)، أو تنفيذ وسائل الإيضاح، أو التعامل مع اختيار الخلية، أو تطبيق تصميم مخصص، أو العمل مع مجموعات بيانات كبيرة. يغطي التثبيت وربط البيانات وتكوين المحور وتخصيص المظهر وأنماط التفاعل وتلميحات الأدوات والأحداث وإمكانية الوصول.
