Внедрите компонент Syncfusion React DropDownList для выбора одного значения из предопределенных списков. Используйте это при работе с раскрывающимися списками, полями выбора или списками с одним выбором. Этот навык охватывает установку, привязку данных (локальные массивы, объекты JSON, удаленные/OData), фильтрацию, группировку, шаблоны, привязку значений, виртуальную прокрутку, каскадные раскрывающиеся списки, специальные возможности, стилизацию и локализацию.
