قم بتنفيذ مكون Syncfusion React DropDownList لاختيار القيمة الفردية من القوائم المحددة مسبقًا. استخدم هذا عند العمل مع القوائم المنسدلة أو مربعات التحديد أو قوائم التحديد الفردي. تغطي هذه المهارة التثبيت وربط البيانات (المصفوفات المحلية وكائنات JSON والبيانات البعيدة/OData) والتصفية والتجميع والقوالب وربط القيمة والتمرير الافتراضي والقوائم المنسدلة المتتالية وإمكانية الوصول والتصميم والترجمة.
