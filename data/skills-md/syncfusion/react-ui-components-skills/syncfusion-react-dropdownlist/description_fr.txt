Implémentez le composant Syncfusion React DropDownList pour la sélection d'une valeur unique à partir de listes prédéfinies. Utilisez-le lorsque vous travaillez avec des listes déroulantes, des zones de sélection ou des listes à sélection unique. Cette compétence couvre l'installation, la liaison de données (tableaux locaux, objets JSON, distant/OData), le filtrage, le regroupement, les modèles, la liaison de valeurs, le défilement virtuel, les listes déroulantes en cascade, l'accessibilité, le style et la localisation.
