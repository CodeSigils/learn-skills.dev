Implemente el componente Syncfusion React DropDownList para la selección de un solo valor de listas predefinidas. Utilícelo cuando trabaje con menús desplegables, cuadros de selección o listas de selección única. Esta habilidad cubre la instalación, enlace de datos (matrices locales, objetos JSON, remoto/OData), filtrado, agrupación, plantillas, enlace de valores, desplazamiento virtual, menús desplegables en cascada, accesibilidad, estilo y localización.
