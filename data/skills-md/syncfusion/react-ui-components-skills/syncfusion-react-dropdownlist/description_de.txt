Implementieren Sie die Syncfusion React DropDownList-Komponente für die Einzelwertauswahl aus vordefinierten Listen. Verwenden Sie dies, wenn Sie mit Dropdowns, Auswahlfeldern oder Einzelauswahllisten arbeiten. Diese Fertigkeit umfasst Installation, Datenbindung (lokale Arrays, JSON-Objekte, Remote/OData), Filterung, Gruppierung, Vorlagen, Wertebindung, virtuelles Scrollen, kaskadierende Dropdowns, Barrierefreiheit, Stil und Lokalisierung.
