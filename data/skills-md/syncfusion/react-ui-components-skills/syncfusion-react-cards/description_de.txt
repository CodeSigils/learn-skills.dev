Erstellen Sie flexible Kartenlayouts für die Anzeige von Inhalten in React. Die Kartenkomponente ist ein leichter Container, der Kopfzeilen, Bilder, Aktionsschaltflächen, horizontale Layouts und die Integration mit anderen Syncfusion-Komponenten unterstützt. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Karten erstellen, kartenbasierte Benutzeroberflächen erstellen, Inhaltskarten anzeigen, Aktionsschaltflächen zu Karten hinzufügen, Kartenlayouts anpassen oder Komponenten in Karten einbetten muss.
