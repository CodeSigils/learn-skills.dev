Crea layout di carte flessibili per visualizzare i contenuti in React. Il componente Card è un contenitore leggero che supporta intestazioni, immagini, pulsanti di azione, layout orizzontali e integrazione con altri componenti Syncfusion. Utilizza questa competenza ogni volta che l'utente ha bisogno di creare schede, creare interfacce utente basate su schede, visualizzare schede di contenuti, aggiungere pulsanti di azione alle schede, personalizzare layout di schede o incorporare componenti all'interno delle schede.
