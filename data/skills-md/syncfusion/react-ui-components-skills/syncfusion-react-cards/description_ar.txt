أنشئ تخطيطات بطاقة مرنة لعرض المحتوى في React. مكون البطاقة عبارة عن حاوية خفيفة الوزن تدعم الرؤوس والصور وأزرار الإجراءات والتخطيطات الأفقية والتكامل مع مكونات Syncfusion الأخرى. استخدم هذه المهارة عندما يحتاج المستخدم إلى إنشاء بطاقات، أو إنشاء واجهات مستخدم قائمة على البطاقة، أو عرض بطاقات المحتوى، أو إضافة أزرار الإجراءات إلى البطاقات، أو تخصيص تخطيطات البطاقة، أو تضمين المكونات داخل البطاقات.
