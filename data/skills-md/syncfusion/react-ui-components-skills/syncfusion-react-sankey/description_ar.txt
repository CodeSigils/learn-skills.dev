قم بتنفيذ مخطط Syncfusion React Sankey لتصور تدفقات الطاقة وتبعيات العمليات والعلاقات الهرمية بين العقد. استخدم هذه المهارة عند إنشاء مخططات Sankey، أو تصورات التدفق، أو شبكات ارتباط العقد. يغطي التثبيت وتكوين العقد والروابط ووضع العلامات والأساطير وتلميحات الأدوات والأحداث وتخصيص المظهر ودعم RTL وإمكانية الوصول وميزات التصدير.
