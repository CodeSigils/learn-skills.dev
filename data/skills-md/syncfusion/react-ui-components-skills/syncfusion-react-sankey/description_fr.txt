Implémentez Syncfusion React Sankey Chart pour visualiser les flux d'énergie, les dépendances des processus et les relations hiérarchiques entre les nœuds. Utilisez cette compétence lors de la création de diagrammes Sankey, de visualisations de flux ou de réseaux de liens de nœuds. Couvre l'installation, la configuration des nœuds et des liens, l'étiquetage, les légendes, les info-bulles, les événements, la personnalisation de l'apparence, la prise en charge RTL, l'accessibilité et les fonctionnalités d'exportation.
