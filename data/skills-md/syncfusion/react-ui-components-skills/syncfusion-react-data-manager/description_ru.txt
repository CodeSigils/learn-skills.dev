Реализует Syncfusion DataManager для локальной/удаленной привязки, CRUD, запросов, кэширования и промежуточного программного обеспечения. Поддерживает JsonAdaptor, ODataAdaptor, ODataV4Adaptor, UrlAdaptor, WebApiAdaptor, WebMethodAdaptor, RemoteSaveAdaptor, GraphQLAdaptor, CustomDataAdaptor и CustomAdaptor. Охватывает класс запроса, фильтрацию, сортировку, разбиение на страницы, группировку, сохранение, автономный режим, кэширование и обработку ошибок.
