Реализует и настраивает компонент Syncfusion React Smith Chart для визуализации линий передачи и радиочастотных цепей. Используйте это, когда пользователям нужны диаграммы Смита для согласования импедансов, проектирования радиочастот или визуализации телекоммуникационных данных. Охватывает конфигурацию серии, настройку осей, маркеры, метки данных, легенду, всплывающую подсказку, печать/экспорт и специальные возможности.
