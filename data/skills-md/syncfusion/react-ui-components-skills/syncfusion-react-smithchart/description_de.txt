Implementiert und passt die Syncfusion React Smith Chart-Komponente für die Visualisierung von Übertragungsleitungen und HF-Schaltkreisen an. Verwenden Sie dies, wenn Benutzer Smith-Diagramme für die Impedanzanpassung, das HF-Design oder die Visualisierung von Telekommunikationsdaten benötigen. Behandelt Serienkonfiguration, Achsenanpassung, Markierungen, Datenbeschriftungen, Legende, Tooltip, Drucken/Export und Barrierefreiheitsfunktionen.
