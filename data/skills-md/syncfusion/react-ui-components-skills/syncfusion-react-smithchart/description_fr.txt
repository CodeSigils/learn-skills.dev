Implémente et personnalise le composant Syncfusion React Smith Chart pour la visualisation des lignes de transmission et des circuits RF. Utilisez-le lorsque les utilisateurs ont besoin de Smith Charts pour l'adaptation d'impédance, la conception RF ou la visualisation de données de télécommunications. Couvre la configuration des séries, la personnalisation des axes, les marqueurs, les étiquettes de données, la légende, l'info-bulle, l'impression/exportation et les fonctionnalités d'accessibilité.
