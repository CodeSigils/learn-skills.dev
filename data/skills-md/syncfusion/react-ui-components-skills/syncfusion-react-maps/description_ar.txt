تنفيذ مكون Syncfusion React Maps لتصور البيانات الجغرافية. استخدم هذا عند عرض الخرائط التفاعلية أو المعلومات المستندة إلى الموقع أو تحليل البيانات الإقليمية. تغطي هذه المهارة موفري الخرائط (Bing وOpenStreetMap) وعرض GeoJSON والعلامات والفقاعات والتكبير/التصغير والتحريك وتسميات البيانات ووسائل الإيضاح والمرئيات التصحيحية في تطبيقات React.
