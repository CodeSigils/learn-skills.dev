Implementieren Sie die Syncfusion React Maps-Komponente für die Visualisierung geografischer Daten. Verwenden Sie dies, wenn Sie interaktive Karten, standortbezogene Informationen oder regionale Datenanalysen anzeigen. Diese Fähigkeit umfasst Kartenanbieter (Bing, OpenStreetMap), GeoJSON-Rendering, Markierungen und Blasen, Zoomen/Schwenken, Datenbeschriftungen, Legenden und Choroplethenvisualisierungen in React-Anwendungen.
