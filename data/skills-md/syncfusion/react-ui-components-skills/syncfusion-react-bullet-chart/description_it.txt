Implementa il componente Syncfusion React Bullet Chart per la visualizzazione di KPI e indicatori di prestazione. Utilizzarlo quando gli utenti necessitano di visualizzazioni di misure di funzionalità, misure comparative, confronti di target o visualizzazioni di metriche. Copre associazione dati, barre dei valori, barre di destinazione, intervalli, titoli, descrizioni comandi, etichette dati, personalizzazione degli assi, orientamento e accessibilità.
