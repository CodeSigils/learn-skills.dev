Implémente le composant Syncfusion React Bullet Chart pour la visualisation des KPI et des indicateurs de performance. Utilisez-le lorsque les utilisateurs ont besoin d'affichages de mesures de caractéristiques, de mesures comparatives, de comparaisons de cibles ou de visualisations de métriques. Couvre la liaison de données, les barres de valeurs, les barres cibles, les plages, les titres, les info-bulles, les étiquettes de données, la personnalisation des axes, l'orientation et l'accessibilité.
