Implementa el componente Syncfusion React Bullet Chart para visualización de KPI y indicadores de rendimiento. Utilícelo cuando los usuarios necesiten visualizaciones de medidas de funciones, medidas comparativas, comparaciones de objetivos o visualizaciones de métricas. Cubre enlace de datos, barras de valores, barras de destino, rangos, títulos, información sobre herramientas, etiquetas de datos, personalización de ejes, orientación y accesibilidad.
