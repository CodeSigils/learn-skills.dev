Implementiert die Syncfusion React Bullet Chart-Komponente für die Visualisierung von KPIs und Leistungsindikatoren. Verwenden Sie dies, wenn Benutzer Funktionskennzahlenanzeigen, Vergleichskennzahlen, Zielvergleiche oder Metrikvisualisierungen benötigen. Behandelt Datenbindung, Wertbalken, Zielbalken, Bereiche, Titel, QuickInfos, Datenbeschriftungen, Achsenanpassung, Ausrichtung und Barrierefreiheit.
