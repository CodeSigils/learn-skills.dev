Реализует компонент Syncfusion React Bullet Chart для визуализации ключевых показателей эффективности и показателей производительности. Используйте это, когда пользователям нужны отображения показателей функций, сравнительные измерения, целевые сравнения или визуализации показателей. Охватывает привязку данных, панели значений, целевые панели, диапазоны, заголовки, всплывающие подсказки, метки данных, настройку осей, ориентацию и доступность.
