Cree encabezados de navegación responsivos con el componente AppBar. Cree barras de aplicaciones superiores, inferiores o fijas con botones, menús, íconos y barras laterales. Úselo al crear elementos de navegación, barras de herramientas, barras de acción o encabezados responsivos con diseño de contenido dinámico. Incluye modos de color (Claro, Oscuro, Primario, Heredado), modos de tamaño (Regular, Destacado, Denso), espaciado, separadores y soporte de accesibilidad total.
