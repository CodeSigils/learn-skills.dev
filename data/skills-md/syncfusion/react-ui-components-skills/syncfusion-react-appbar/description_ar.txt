قم بإنشاء رؤوس تنقل سريعة الاستجابة باستخدام مكون AppBar. أنشئ أشرطة تطبيقات علوية أو سفلية أو لاصقة باستخدام الأزرار والقوائم والأيقونات والأشرطة الجانبية. يُستخدم عند إنشاء عناصر التنقل أو أشرطة الأدوات أو أشرطة الإجراءات أو الرؤوس سريعة الاستجابة ذات تخطيط المحتوى الديناميكي. يتضمن أوضاع الألوان (فاتح، داكن، أساسي، وراثي)، أوضاع الحجم (العادي، البارز، الكثيف)، والمسافات، والفواصل، والدعم الكامل لإمكانية الوصول.
