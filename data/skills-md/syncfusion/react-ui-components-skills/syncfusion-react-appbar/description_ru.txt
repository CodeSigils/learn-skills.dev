Используйте при создании элементов навигации, панелей инструментов, панелей действий или адаптивных заголовков с динамическим макетом контента. Включает цветовые режимы (Светлый, Темный, Основной, Наследование), режимы размера (Обычный, Заметный, Плотный), интервалы, разделители и полную поддержку специальных возможностей.
