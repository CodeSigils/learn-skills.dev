Utilice esta habilidad cuando los usuarios necesiten ayuda para crear visualizaciones de datos jerárquicos, configurar interacciones detalladas, aplicar mapeo de colores, trabajar con múltiples niveles de jerarquía, personalizar elementos de hoja o solucionar problemas de vinculación y visualización de datos de TreeMap. Cubre la instalación, los patrones de enlace de datos, los diseños, las leyendas, la información sobre herramientas, la selección, la accesibilidad y la personalización avanzada para la exploración interactiva de datos jerárquicos.
