Подробное руководство по реализации компонента Syncfusion React TreeMap. Используйте этот навык, когда пользователям нужна помощь в создании иерархических визуализаций данных, настройке взаимодействий детализации, применении цветового сопоставления, работе с несколькими уровнями иерархии, настройке конечных элементов или устранении неполадок привязки и отображения данных TreeMap. Охватывает установку, шаблоны привязки данных, макеты, легенды, всплывающие подсказки, выбор, доступность и расширенную настройку для интерактивного иерархического исследования данных.
