Руководство по реализации компонента Syncfusion Angular ListView. Используйте этот навык при создании интерактивных списков с функциями привязки данных, группировки, шаблонов, выбора, событий, перетаскивания или виртуализации. Эти навыки охватывают начало работы, привязку данных, настройку, выбор, расширенные функции, специализированные варианты использования, стили и доступность для создания готовых к использованию интерфейсов списков.
