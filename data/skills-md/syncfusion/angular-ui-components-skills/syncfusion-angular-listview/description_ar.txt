دليل لتنفيذ مكون Syncfusion Angular ListView. استخدم هذه المهارة عند إنشاء قوائم تفاعلية تحتوي على ميزات ربط البيانات أو التجميع أو القوالب أو التحديد أو الأحداث أو السحب والإفلات أو المحاكاة الافتراضية. تغطي هذه المهارة البدء، وربط البيانات، والتخصيص، والاختيار، والميزات المتقدمة، وحالات الاستخدام المتخصصة، والتصميم، وإمكانية الوصول لبناء واجهات قائمة جاهزة للإنتاج.
