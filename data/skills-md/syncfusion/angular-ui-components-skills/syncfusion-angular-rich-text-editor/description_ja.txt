RichTextEditorModule、HtmlEditorService、MarkdownEditorService を使用して、@syncfusion/ej2-angular-richtexteditor から Syncfusion Angular リッチ テキスト エディター (ejs-richtexteditor) を実装します。ツールバーの構成、画像/ビデオ/オーディオの挿入、ペーストのクリーンアップ、AI アシスタントの統合、絵文字ピッカー、スラッシュ メニュー、メンション、Word/PDF のインポート/エクスポート、フォーム検証、およびソース コード ビューにこのスキルを使用します。 Angular アプリケーション。
