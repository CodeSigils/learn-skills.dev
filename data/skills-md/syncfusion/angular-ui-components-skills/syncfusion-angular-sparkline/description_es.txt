Implemente el componente Syncfusion Angular Sparkline para una visualización de datos compacta. Utilice esta habilidad siempre que el usuario necesite crear minigráficos, visualizar pequeños conjuntos de datos en línea, agregar marcadores o etiquetas de datos, implementar diferentes tipos de minigráficos (línea, columna, área, circular, ganancias y pérdidas) o manejar la personalización de minigráficos como información sobre herramientas, configuración de ejes y estilo de tema. Cubre la instalación, renderizado básico, selección de tipo, configuración de marcadores, formato de etiquetas de datos, funciones avanzadas, accesibilidad y migración desde EJ1.
