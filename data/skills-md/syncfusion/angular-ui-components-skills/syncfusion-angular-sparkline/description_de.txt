Implementieren Sie die Syncfusion Angular Sparkline-Komponente für eine kompakte Datenvisualisierung. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Sparkline-Diagramme erstellen, kleine Datensätze inline visualisieren, Markierungen oder Datenbeschriftungen hinzufügen, verschiedene Sparkline-Typen (Linie, Spalte, Fläche, Kreis, Win-Loss) implementieren oder Sparkline-Anpassungen wie Tooltips, Achseneinstellungen und Designstil vornehmen muss. Behandelt Installation, grundlegendes Rendering, Typauswahl, Markierungskonfiguration, Datenetikettenformatierung, erweiterte Funktionen, Barrierefreiheit und Migration von EJ1.
