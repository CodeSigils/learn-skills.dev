تنفيذ مكون Syncfusion Angular Sparkline لتصور البيانات المضغوطة. استخدم هذه المهارة عندما يحتاج المستخدم إلى إنشاء مخططات خطية لامعة، أو تصور مجموعات بيانات صغيرة مضمنة، أو إضافة علامات أو تسميات بيانات، أو تنفيذ أنواع مختلفة من خطوط المؤشرات (خط، عمود، منطقة، دائري، فوز-خسارة)، أو التعامل مع تخصيص خط المؤشر مثل تلميحات الأدوات، وإعدادات المحور، وتصميم السمة. يغطي التثبيت والعرض الأساسي واختيار النوع وتكوين العلامة وتنسيق تسمية البيانات والميزات المتقدمة وإمكانية الوصول والترحيل من EJ1.
