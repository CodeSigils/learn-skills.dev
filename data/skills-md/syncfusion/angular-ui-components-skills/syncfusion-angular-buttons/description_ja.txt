Button、ButtonGroup、DropDownButton、Floating Action Button (FAB)、ProgressButton、RadioButton、Switch、Speed Dial、SplitButtons を含む Syncfusion Angular ボタン コンポーネントを実装するための包括的なガイド。これらのコンポーネントを実装およびスタイル設定するときにこれを使用します。これには、視覚スタイル (プライマリ、アウトライン、トグル、アイコン、ラウンド、ブロック)、グループ化、ポップアップ項目とアニメーションを含むドロップダウン、FAB の位置決め/スコープ、スピード ダイヤルのリニア/ラジアル アクション アイテム、プログレス対応ボタン、トグル/ラジオ コントロールが含まれます。
