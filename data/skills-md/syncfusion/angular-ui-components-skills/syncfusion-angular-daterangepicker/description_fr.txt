Guide complet pour la mise en œuvre du composant Syncfusion Angular DateRangePicker. Utilisez-le lorsque vous travaillez avec la sélection de plages de dates, les plages prédéfinies, la validation de plages ou les contraintes de date dans les applications angulaires. Couvre l'API DateRangePicker, les événements, le formatage et les modèles d'accessibilité.
