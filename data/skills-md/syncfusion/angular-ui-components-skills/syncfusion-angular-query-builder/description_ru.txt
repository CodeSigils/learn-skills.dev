Внедрите компонент Syncfusion Angular Query Builder для визуального построения запросов, динамической фильтрации и управления правилами. Используйте это при создании пользовательских интерфейсов визуальных фильтров, программном создании условий запросов, импорте/экспорте запросов SQL или MongoDB или настройке шаблонов построителя запросов. Этот навык охватывает привязку данных, настройку столбцов с помощью операторов, группы правил, темы и интеграцию форм Angular для компонента QueryBuilder (ejs-querybuilder).
