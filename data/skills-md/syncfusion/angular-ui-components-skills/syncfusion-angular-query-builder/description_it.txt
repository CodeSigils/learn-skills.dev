Implementa il componente Syncfusion Angular Query Builder per la costruzione di query visive, il filtraggio dinamico e la gestione delle regole. Utilizzalo durante la creazione di interfacce utente di filtri visivi, la creazione di condizioni di query a livello di codice, l'importazione/esportazione di query SQL o MongoDB o la personalizzazione di modelli di creazione di query. Questa competenza copre l'associazione dei dati, la configurazione delle colonne con operatori, gruppi di regole, temi e integrazione dei moduli Angular per il componente QueryBuilder (ejs-querybuilder).
