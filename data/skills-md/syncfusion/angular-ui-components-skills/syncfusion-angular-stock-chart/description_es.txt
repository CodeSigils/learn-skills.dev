Implemente el componente Syncfusion Angular Stock Chart para mostrar datos financieros y gráficos OHLC. Utilice esta habilidad siempre que los usuarios necesiten crear gráficos de acciones, mostrar datos de velas japonesas o OHLC, agregar indicadores técnicos, implementar la selección de rangos de fechas o trabajar con visualización financiera de series temporales. Incluye tipos de series, personalización de ejes, funciones interactivas y capacidades de exportación.
