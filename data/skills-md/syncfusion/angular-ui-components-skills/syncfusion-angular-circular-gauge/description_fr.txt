Implémentez le composant Syncfusion Angular Circular Gauge pour la visualisation des données radiales. Utilisez-le lors de la création de jauges circulaires pour les tableaux de bord, les affichages de surveillance, les mesures de performances, les compteurs de vitesse ou les indicateurs KPI. Couvre l'installation, la configuration des axes, les types de pointeurs (aiguille, barre de plage, marqueur), les plages, le style, les animations et les interactions utilisateur.
