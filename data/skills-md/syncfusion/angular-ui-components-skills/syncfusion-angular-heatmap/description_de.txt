Implementieren Sie die Syncfusion Angular HeatMap Chart-Komponente zur Visualisierung zweidimensionaler Daten mit Farbverläufen. Verwenden Sie diese Fähigkeit immer dann, wenn Benutzer Heatmaps erstellen, Datenmatrizen visualisieren, Daten mit farbcodierten Zellen anzeigen, Achsen (numerisch/kategorisch/Datum/Uhrzeit) konfigurieren, Legenden hinzufügen, Farben und Rendering-Modi anpassen, Zellenauswahl und Ereignisse verwalten oder Barrierefreiheitsfunktionen implementieren müssen. Beinhaltet Datenbindung, Achsentypen, interaktive Auswahl, Tooltips und Blasen-Heatmaps.
