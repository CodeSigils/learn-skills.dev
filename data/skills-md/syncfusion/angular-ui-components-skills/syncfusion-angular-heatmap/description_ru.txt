Внедрите компонент Syncfusion Angular HeatMap Chart для визуализации двумерных данных с цветовыми градиентами. Используйте этот навык всякий раз, когда пользователям нужно создавать тепловые карты, визуализировать матрицы данных, отображать данные с помощью ячеек с цветовой кодировкой, настраивать оси (числовые/категориальные/дата-время), добавлять легенды, настраивать цвета и режимы рендеринга, обрабатывать выбор ячеек и события или реализовывать функции специальных возможностей. Включает привязку данных, типы осей, интерактивный выбор, всплывающие подсказки и пузырьковые тепловые карты.
