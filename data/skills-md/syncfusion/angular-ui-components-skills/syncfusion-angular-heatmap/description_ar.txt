قم بتنفيذ مكون Syncfusion Angular HeatMap Chart لتصور البيانات ثنائية الأبعاد مع تدرجات الألوان. استخدم هذه المهارة عندما يحتاج المستخدمون إلى إنشاء خرائط حرارية، أو تصور مصفوفات البيانات، أو عرض البيانات باستخدام خلايا مرمزة بالألوان، أو تكوين المحاور (رقمية/فئية/وقت التاريخ)، أو إضافة وسائل إيضاح، أو تخصيص الألوان وأوضاع العرض، أو التعامل مع تحديد الخلايا والأحداث، أو تنفيذ ميزات إمكانية الوصول. يتضمن ربط البيانات وأنواع المحاور والاختيار التفاعلي وتلميحات الأدوات وخرائط الحرارة الفقاعية.
