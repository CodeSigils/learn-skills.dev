Implemente el componente Syncfusion Angular HeatMap Chart para visualizar datos bidimensionales con degradados de color. Utilice esta habilidad siempre que los usuarios necesiten crear mapas de calor, visualizar matrices de datos, mostrar datos con celdas codificadas por colores, configurar ejes (numéricos/categóricos/de fecha y hora), agregar leyendas, personalizar colores y modos de representación, manejar la selección de celdas y eventos, o implementar funciones de accesibilidad. Incluye enlace de datos, tipos de ejes, selección interactiva, información sobre herramientas y mapas de calor de burbujas.
