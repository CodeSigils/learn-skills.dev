Implements Syncfusion Angular Grid component for feature-rich data tables and grids. Utilícelo cuando trabaje con visualización, clasificación, filtrado, agrupación, agregación, edición o exportación de datos. Esta habilidad cubre la configuración de cuadrículas, operaciones CRUD, desplazamiento virtual o desplazamiento infinito, cuadrículas jerárquicas, persistencia de estado y funciones avanzadas de administración de datos para aplicaciones con uso intensivo de datos.
