Implementieren Sie die Syncfusion Angular AppBar-Komponente für Navigation, Branding und Aktionen. Verwenden Sie diese Fähigkeit, wenn der Benutzer eine obere oder untere Navigationsleiste, Sticky-Header, eine AppBar mit Schaltflächen/Menüs/Seitenleisten, Positionierungsoptionen, Größenmodi (Normal/Prominent/Dicht), Farbmodi (Hell/Dunkel/Primär/Übernehmen) und eine Styling-Anpassung hinzufügen muss. Behandelt AppBar-Eigenschaften wie isSticky, enablePersistence, enableRtl, htmlAttributes, responsive Navigationsmuster, Aktionsleisten, Header-Layouts und Navigationskomponenten.
