Implementa il componente Syncfusion Angular AppBar per la navigazione, il branding e le azioni. Utilizza questa competenza quando l'utente deve aggiungere barra di navigazione superiore o inferiore, intestazioni fisse, AppBar con pulsanti/menu/barre laterali, opzioni di posizionamento, modalità di ridimensionamento (Normale/Prominente/Dense), modalità colore (Chiaro/Scuro/Primario/Eredita) e personalizzazione dello stile. Copre le proprietà AppBar come isSticky, EnablePersistence, EnableRtl, htmlAttributes, modelli di navigazione reattivi, barre delle azioni, layout di intestazione e componenti di navigazione.
