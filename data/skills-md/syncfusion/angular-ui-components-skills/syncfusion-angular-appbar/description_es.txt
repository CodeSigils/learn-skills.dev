Implemente el componente Syncfusion Angular AppBar para navegación, marca y acciones. Utilice esta habilidad cuando el usuario necesite agregar una barra de navegación superior o inferior, encabezados adhesivos, AppBar con botones/menús/barras laterales, opciones de posicionamiento, modos de tamaño (Regular/Prominente/Denso), modos de color (Claro/Oscuro/Primario/Heredar) y personalización de estilo. Cubre propiedades de AppBar como isSticky, enablePersistence, enableRtl, htmlAttributes, patrones de navegación receptivos, barras de acciones, diseños de encabezado y componentes de navegación.
