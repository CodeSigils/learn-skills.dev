تنفيذ مكون Syncfusion Angular Chart لتصور البيانات بشكل احترافي. استخدم هذا عند إنشاء مخططات أو تخصيصها مثل المخططات الخطية أو الشريطية أو العمودية أو المساحية أو الدائرية أو المالية (الشمعدان، OHLC)، أو المبعثرة، أو الفقاعية، أو الأسهم. يدعم تكوين المحاور، وربط السلسلة، والأساطير، وتلميحات الأدوات، والتكبير/التصغير، والتحديثات في الوقت الفعلي، والمؤشرات الفنية، والموضوعات، والتصدير، وميزات إمكانية الوصول.
