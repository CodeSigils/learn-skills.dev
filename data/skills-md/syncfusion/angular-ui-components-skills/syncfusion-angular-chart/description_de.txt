Implementieren Sie die Syncfusion Angular Chart-Komponente für eine professionelle Datenvisualisierung. Verwenden Sie dies beim Erstellen oder Anpassen von Diagrammen wie Linien-, Balken-, Säulen-, Flächen-, Kreis-, Finanz- (Candlestick, OHLC), Streu-, Blasen- oder Aktiendiagrammen. Unterstützt Achsenkonfiguration, Serienbindung, Legenden, Tooltips, Zoomen, Echtzeitaktualisierungen, technische Indikatoren, Themen, Export und Barrierefreiheitsfunktionen.
