Implementieren Sie die Syncfusion Angular Dropdown Tree-Komponente für die hierarchische Datenauswahl mit einzelnen oder mehreren Werten. Verwenden Sie dies, wenn Sie Elemente aus baumstrukturierten Hierarchien auswählen, Kontrollkästchen für die Mehrfachauswahl aktivieren, hierarchische Daten binden, Baumelemente mit Vorlagen anpassen oder eine über- und untergeordnete Auswahl abhängiger Elemente implementieren. Funktioniert mit selbstreferenziellen Strukturen und Remote-OData/REST-Endpunkten für Kategorieselektoren und Organisationsschnittstellen.
