Внедрите компонент раскрывающегося списка Angular Syncfusion для иерархического выбора данных с одним или несколькими значениями. Используйте это при выборе элементов из иерархий с древовидной структурой, включении флажков для множественного выбора, привязке иерархических данных, настройке элементов дерева с помощью шаблонов или реализации выбора, зависящего от родительских и дочерних элементов. Работает с самореферентными структурами и удаленными конечными точками OData/REST для селекторов категорий и организационных интерфейсов.
