Implemente el componente Syncfusion Angular Dropdown Tree para la selección de datos jerárquicos con valores únicos o múltiples. Utilícelo al seleccionar elementos de jerarquías estructuradas en árbol, habilitar casillas de verificación para selección múltiple, vincular datos jerárquicos, personalizar elementos del árbol con plantillas o implementar una selección dependiente de padre-hijo. Funciona con estructuras autorreferenciales y puntos finales OData/REST remotos para selectores de categorías e interfaces organizativas.
