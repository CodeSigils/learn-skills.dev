Implement Syncfusion Angular Dropdown Tree component for hierarchical data selection with single or multiple values. Utilícelo al seleccionar elementos de jerarquías estructuradas en árbol, habilitar casillas de verificación para selección múltiple, vincular datos jerárquicos, personalizar elementos del árbol con plantillas o implementar una selección dependiente de padre-hijo. Works with self-referential structures and remote OData/REST endpoints for category selectors and organizational interfaces.
