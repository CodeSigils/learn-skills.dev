Implementa il componente Syncfusion Angular Dropdown Tree per la selezione gerarchica dei dati con valori singoli o multipli. Utilizzarlo quando si selezionano elementi da gerarchie strutturate ad albero, si abilitano caselle di controllo per la selezione multipla, si associano dati gerarchici, si personalizzano elementi dell'albero con modelli o si implementa la selezione dipendente dal genitore-figlio. Funziona con strutture autoreferenziali ed endpoint OData/REST remoti per selettori di categoria e interfacce organizzative.
