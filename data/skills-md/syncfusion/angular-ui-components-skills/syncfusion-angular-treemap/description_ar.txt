قم بإنشاء وتخصيص مكونات Syncfusion Angular TreeMap لتصور البيانات الهرمية. استخدم هذه المهارة عندما تحتاج إلى تنفيذ TreeMap، أو تصور هياكل البيانات الهرمية، أو تكوين تخطيطات متعددة المستويات، أو تطبيق تعيين الألوان، أو تمكين التنقل المتعمق، أو إضافة تسميات وتلميحات الأدوات، أو تكوين وسائل الإيضاح، أو التعامل مع التحديد والتمييز، أو التصدير إلى الصور أو PDF، أو الطباعة، أو تخصيص التدويل وإمكانية الوصول. يغطي التثبيت، وربط البيانات، وأنواع التخطيط، والمستويات، ورسم خرائط الألوان، والتسميات، وتلميحات الأدوات، والأساطير، والتنقل، والتفاعل، والطباعة/التصدير، وRTL، والتنسيق المحلي، وإمكانية الوصول.
