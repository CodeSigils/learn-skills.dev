Cree y personalice los componentes de Syncfusion Angular TreeMap para la visualización de datos jerárquicos. Utilice esta habilidad cuando necesite implementar un TreeMap, visualizar estructuras de datos jerárquicas, configurar diseños de varios niveles, aplicar mapeo de colores, habilitar la navegación detallada, agregar etiquetas e información sobre herramientas, configurar leyendas, manejar la selección y resaltar, exportar a imágenes o PDF, imprimir o personalizar la internacionalización y la accesibilidad. Cubre instalación, enlace de datos, tipos de diseño, niveles, asignación de colores, etiquetas, información sobre herramientas, leyendas, desglose, interactividad, impresión/exportación, RTL, formato local y accesibilidad.
