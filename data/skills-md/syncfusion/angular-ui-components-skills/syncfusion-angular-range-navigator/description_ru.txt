Внедрите интерактивный Range Navigator в приложениях Angular с помощью Syncfusion. Охватывает привязку данных из локальных и удаленных источников, конфигурацию осей (числовую и дату-время), типы рядов, настройку всплывающих подсказок, настройку выбора периода, упрощенный режим, поддержку RTL, метки и форматирование осей, отметки сетки, функции печати/экспорта (PNG, SVG, PDF) и специальные возможности. Используйте этот навык при создании инструментов выбора диапазона данных, навигаторов временной шкалы и интерактивных компонентов исследования данных.
