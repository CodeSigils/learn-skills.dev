Implémentez un Range Navigator interactif dans les applications angulaires à l'aide de Syncfusion. Couvre la liaison de données à partir de sources locales et distantes, la configuration des axes (numérique et date-heure), les types de séries, la personnalisation des info-bulles, la configuration du sélecteur de période, le mode léger, la prise en charge RTL, les étiquettes et le formatage des axes, les graduations de grille, la fonctionnalité d'impression/exportation (PNG, SVG, PDF) et les fonctionnalités d'accessibilité. Utilisez cette compétence lors de la création d’outils de sélection de plages de données, de navigateurs de chronologie et de composants interactifs d’exploration de données.
