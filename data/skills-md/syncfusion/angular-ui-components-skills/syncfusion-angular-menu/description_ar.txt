دليل لتنفيذ مكون القائمة Syncfusion Angular. استخدم هذه المهارة عندما يحتاج المستخدم إلى إنشاء قوائم التنقل، أو هياكل القائمة الهرمية، أو عناصر القائمة الفرعية، أو أحداث القائمة، أو الرسوم المتحركة، أو تغييرات الاتجاه، أو دعم RTL، أو تخصيص مظهر القائمة. يغطي التثبيت وربط البيانات والقوالب والأحداث والتصميم وإمكانية الوصول والتطبيقات الواقعية مثل قوائم الشريط الجانبي وأشرطة الأدوات.
