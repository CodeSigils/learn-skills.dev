تنفيذ مكون Syncfusion Angular Maps لتصور البيانات الجغرافية. استخدم هذا عندما يحتاج المستخدمون إلى عرض الخرائط، أو تصور البيانات الجغرافية باستخدام العلامات والفقاعات، أو دمج موفري الخرائط مثل Bing أو OpenStreetMap، أو عرض أشكال GeoJSON، أو إنشاء خرائط تصحيحية مع مناطق مرمزة بالألوان. يدعم الميزات التفاعلية مثل التكبير/التصغير والتحريك والطبقات والأساطير وتلميحات الأدوات ورسم خرائط الألوان وإمكانية الوصول.
