Guide d'implémentation des composants Syncfusion Angular Breadcrumb pour les sentiers de navigation. Couvre l'installation, la liaison de données, la configuration de la navigation, les icônes, les modes de débordement et la personnalisation des modèles. Utilisez-le lors de la création d'un fil d'Ariane qui affiche l'emplacement de l'utilisateur dans les hiérarchies, permet de cliquer sur les éléments parents pour la navigation, ajoute des icônes pour le contexte visuel ou personnalise l'apparence avec des modèles.
