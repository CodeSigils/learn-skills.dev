Guía para implementar componentes Syncfusion Angular Breadcrumb para rutas de navegación. Cubre la instalación, el enlace de datos, la configuración de navegación, los iconos, los modos de desbordamiento y la personalización de plantillas. Utilícelo cuando cree una navegación de ruta de navegación que muestre la ubicación del usuario en jerarquías, permita hacer clic en elementos principales para la navegación, agregue íconos para el contexto visual o personalice la apariencia con plantillas.
