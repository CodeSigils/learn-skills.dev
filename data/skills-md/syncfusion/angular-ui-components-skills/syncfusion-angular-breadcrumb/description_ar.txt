دليل لتنفيذ مكونات Syncfusion Angular Breadcrumb لمسارات التنقل. يغطي التثبيت وربط البيانات وإعداد التنقل والأيقونات وأوضاع التجاوز وتخصيص القالب. استخدم هذا عند إنشاء التنقل التفصيلي الذي يعرض موقع المستخدم في التسلسلات الهرمية، أو يتيح النقر فوق العناصر الأصلية للتنقل، أو يضيف أيقونات للسياق المرئي، أو يخصص المظهر باستخدام القوالب.
