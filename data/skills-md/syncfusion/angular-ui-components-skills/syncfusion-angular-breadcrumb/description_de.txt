Leitfaden zur Implementierung von Syncfusion Angular Breadcrumb-Komponenten für Navigationspfade. Behandelt Installation, Datenbindung, Navigationseinrichtung, Symbole, Überlaufmodi und Vorlagenanpassung. Verwenden Sie dies, wenn Sie eine Breadcrumb-Navigation erstellen, die den Benutzerstandort in Hierarchien anzeigt, das Klicken auf übergeordnete Elemente zur Navigation ermöglicht, Symbole für den visuellen Kontext hinzufügt oder das Erscheinungsbild mit Vorlagen anpasst.
