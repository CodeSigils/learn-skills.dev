Руководство по реализации компонентов Syncfusion Angular Breadcrumb для навигационных маршрутов. Охватывает установку, привязку данных, настройку навигации, значки, режимы переполнения и настройку шаблонов. Используйте это при создании навигационной навигации, которая отображает местоположение пользователя в иерархии, позволяет щелкать родительские элементы для навигации, добавляет значки для визуального контекста или настраивает внешний вид с помощью шаблонов.
