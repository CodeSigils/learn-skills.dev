Implementa il componente Syncfusion Angular ContextMenu per i menu cliccabili con il tasto destro e tenendo premuto il tocco. Utilizza questa competenza quando l'utente deve creare menu contestuali, aggiungere/rimuovere/abilitare voci di menu, gestire clic di menu, personalizzare animazioni, applicare modelli, gestire associazione dati, attivare finestre di dialogo dalle voci di menu, mostrare/nascondere elementi dinamicamente, aggiungere icone, creare menu scorrevoli o personalizzare l'aspetto del menu.
