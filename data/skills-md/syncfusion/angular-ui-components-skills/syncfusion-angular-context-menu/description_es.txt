Implemente el componente Syncfusion Angular ContextMenu para menús de clic derecho y menús táctiles. Utilice esta habilidad cuando el usuario necesite crear menús contextuales, agregar/eliminar/habilitar elementos de menú, manejar clics en menús, personalizar animaciones, aplicar plantillas, manejar enlace de datos, activar cuadros de diálogo desde elementos de menú, mostrar/ocultar elementos dinámicamente, agregar íconos, crear menús desplazables o personalizar la apariencia del menú.
