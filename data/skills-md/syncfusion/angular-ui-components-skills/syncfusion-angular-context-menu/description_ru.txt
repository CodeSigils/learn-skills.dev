Внедрите компонент Syncfusion Angular ContextMenu для меню, вызываемого щелчком правой кнопкой мыши и удерживанием касания. Используйте этот навык, когда пользователю необходимо создавать контекстные меню, добавлять/удалять/включать элементы меню, обрабатывать щелчки меню, настраивать анимацию, применять шаблоны, обрабатывать привязку данных, запускать диалоговые окна из элементов меню, динамически показывать/скрывать элементы, добавлять значки, создавать прокручиваемые меню или настраивать внешний вид меню.
