Implement and configure the Syncfusion Angular Gantt Chart component (ejs-gantt, GanttModule). Use this when building Angular applications with Gantt chart functionality, task scheduling, dependencies, or resource management. Cubre la configuración de componentes, dependencias de tareas, edición de la barra de tareas, análisis de rutas críticas, asignación de recursos, configuración de la línea de tiempo, filtrado, clasificación, exportación, deshacer/rehacer, persistencia del estado y localización.
