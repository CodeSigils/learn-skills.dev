تنفيذ وتكوين مكون Syncfusion Angular Gantt Chart (ejs-gantt، GanttModule). استخدم هذا عند إنشاء تطبيقات Angular باستخدام وظيفة مخطط جانت، أو جدولة المهام، أو التبعيات، أو إدارة الموارد. يغطي إعداد المكونات، وتبعيات المهام، وتحرير شريط المهام، وتحليل المسار الحرج، وتخصيص الموارد، وتكوين المخطط الزمني، والتصفية، والفرز، والتصدير، والتراجع/الإعادة، واستمرارية الحالة، والترجمة.
