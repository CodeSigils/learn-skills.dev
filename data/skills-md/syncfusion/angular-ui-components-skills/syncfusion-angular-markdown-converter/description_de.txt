Implementieren Sie den Syncfusion Angular Markdown Converter, um Markdown-Text in sauberes HTML zu konvertieren. Verwenden Sie dies, wenn Sie Markdown in Angular in HTML konvertieren, eine Live-Markdown-Vorschau integrieren, GFM- oder Zeilenumbruchoptionen konfigurieren oder mit MarkdownConverter.toHtml() und MarkdownConverterOptions arbeiten. Diese Fertigkeit deckt das @syncfusion/ej2-markdown-converter-Paket und die Markdown-Editor-Integration mit paralleler HTML-Vorschau ab.
