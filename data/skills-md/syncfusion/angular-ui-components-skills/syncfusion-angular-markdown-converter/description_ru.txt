Внедрите конвертер Markdown Angular Syncfusion для преобразования текста Markdown в чистый HTML. Используйте это при преобразовании Markdown в HTML в Angular, интеграции предварительного просмотра Markdown в реальном времени, настройке параметров GFM или разрыва строки, а также при работе с MarkdownConverter.toHtml() и MarkdownConverterOptions. Этот навык охватывает пакет @syncfusion/ej2-markdown-converter и интеграцию редактора Markdown с параллельным предварительным просмотром HTML.
