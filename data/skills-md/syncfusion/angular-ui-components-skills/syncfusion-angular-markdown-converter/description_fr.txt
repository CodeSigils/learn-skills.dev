Implémentez le convertisseur Syncfusion Angular Markdown pour convertir le texte Markdown en HTML propre. Utilisez-le lors de la conversion de Markdown en HTML dans Angular, de l'intégration d'un aperçu Markdown en direct, de la configuration des options GFM ou de saut de ligne, ou de l'utilisation de MarkdownConverter.toHtml() et MarkdownConverterOptions. Cette compétence couvre le package @syncfusion/ej2-markdown-converter et l'intégration de Markdown Editor avec un aperçu HTML côte à côte.
