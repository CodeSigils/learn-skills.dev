Общие утилиты и функции для элементов управления Syncfusion JavaScript. Используйте этот навык, когда пользователю необходимо реализовать анимацию, перетаскивание, сохранение состояния, поддержку RTL, локализацию, глобализацию, безопасность, шаблоны и расширенные функции для элементов управления Syncfusion JavaScript.
