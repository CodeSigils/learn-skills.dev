Implementa i controlli grafici JavaScript Syncfusion (Linea, Area, Barra, Colonna, Torta, Polare, Radar, Cascata, Azionario). Da utilizzare durante la creazione di visualizzazioni di dati interattive, dashboard o grafici in tempo reale. Copre la configurazione di serie e assi, stile, animazioni, esportazione e indicatori tecnici. Funziona con TypeScript (webpack/moduli) e JavaScript (CDN/ES5).
