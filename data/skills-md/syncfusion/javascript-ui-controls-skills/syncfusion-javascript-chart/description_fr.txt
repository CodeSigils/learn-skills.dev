Implémente les contrôles graphiques JavaScript Syncfusion (Ligne, Zone, Barre, Colonne, Secteur, Polaire, Radar, Cascade, Stock). À utiliser lors de la création de visualisations de données interactives, de tableaux de bord ou de graphiques en temps réel. Couvre la configuration des séries et des axes, le style, les animations, l'exportation et les indicateurs techniques. Fonctionne avec TypeScript (webpack/modules) et JavaScript (CDN/ES5).
