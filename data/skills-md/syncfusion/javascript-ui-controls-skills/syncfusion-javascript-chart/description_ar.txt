يطبق عناصر التحكم في مخطط JavaScript Syncfusion (الخط، المنطقة، الشريط، العمود، الدائري، القطبي، الرادار، الشلال، المخزون). يُستخدم عند إنشاء تصورات بيانات تفاعلية أو لوحات معلومات أو مخططات في الوقت الفعلي. يغطي تكوين السلسلة والمحاور والتصميم والرسوم المتحركة والتصدير والمؤشرات الفنية. يعمل مع TypeScript (حزمة الويب/الوحدات النمطية) وJavaScript (CDN/ES5).
