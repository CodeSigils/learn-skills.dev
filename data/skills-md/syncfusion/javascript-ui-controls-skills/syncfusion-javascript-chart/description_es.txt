Implementa controles de gráficos JavaScript de Syncfusion (línea, área, barra, columna, circular, polar, radar, cascada, stock). Úselo al crear visualizaciones de datos interactivas, paneles o gráficos en tiempo real. Cubre la configuración de series y ejes, estilos, animaciones, exportación e indicadores técnicos. Funciona con TypeScript (paquete web/módulos) y JavaScript (CDN/ES5).
