Реализует элементы управления диаграммами Syncfusion JavaScript (линия, площадь, полоса, столбец, круговая диаграмма, полярная, радар, водопад, акции). Используйте при создании интерактивных визуализаций данных, информационных панелей или диаграмм в реальном времени. Охватывает конфигурацию рядов и осей, стиль, анимацию, экспорт и технические индикаторы. Работает с TypeScript (веб-пакет/модули) и JavaScript (CDN/ES5).
