Комплексное руководство по реализации компонентов диалогового окна Syncfusion TypeScript (всплывающего окна). Используйте это при создании модальных или немодальных диалоговых окон, окон предупреждений/подтверждений или подсказок на основе DialogUtility в проектах TypeScript/EJ2. Охватывает анимацию, перетаскивание, изменение размера, вложенные диалоги, шаблоны и специальные возможности WAI-ARIA.
