Implemente y configure los componentes de los botones JavaScript de Syncfusion EJ2 (ProgressButton, RadioButton y SplitButton). Utilícelo cuando agregue controles de botones interactivos, indicadores de progreso, selecciones de radio o menús de doble acción en una aplicación JavaScript o ES5. Esta habilidad cubre la configuración de componentes, estados, eventos, plantillas, accesibilidad y patrones de interfaz de usuario comunes.
