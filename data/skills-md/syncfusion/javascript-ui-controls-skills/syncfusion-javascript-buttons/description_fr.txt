Implémentez et configurez les composants des boutons JavaScript Syncfusion EJ2 (ProgressButton, RadioButton et SplitButton). Utilisez-le lors de l'ajout de commandes de boutons interactifs, d'indicateurs de progression, de sélections radio ou de menus à double action dans une application JavaScript ou ES5. Cette compétence couvre la configuration des composants, les états, les événements, les modèles, l'accessibilité et les modèles d'interface utilisateur courants.
