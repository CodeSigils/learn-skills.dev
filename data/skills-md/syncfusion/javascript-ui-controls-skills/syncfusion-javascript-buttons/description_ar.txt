قم بتنفيذ وتكوين مكونات Syncfusion EJ2 JavaScript Buttons (ProgressButton، وRadioButton، وSplitButton). استخدم هذا عند إضافة عناصر تحكم تفاعلية بالأزرار، أو مؤشرات التقدم، أو تحديدات الراديو، أو قوائم الإجراءات المزدوجة في تطبيق JavaScript أو ES5. تغطي هذه المهارة تكوين المكونات والحالات والأحداث والقوالب وإمكانية الوصول وأنماط واجهة المستخدم الشائعة.
