Implementare e configurare i componenti dei pulsanti JavaScript Syncfusion EJ2 (ProgressButton, RadioButton e SplitButton). Utilizzalo quando aggiungi controlli pulsanti interattivi, indicatori di avanzamento, selezioni radio o menu a doppia azione in un'applicazione JavaScript o ES5. Questa competenza copre la configurazione dei componenti, gli stati, gli eventi, i modelli, l'accessibilità e i modelli comuni dell'interfaccia utente.
