Внедрите и настройте компоненты кнопок JavaScript Syncfusion EJ2 (ProgressButton, RadioButton и SplitButton). Используйте это при добавлении интерактивных кнопок, индикаторов прогресса, переключателей или меню двойного действия в приложении JavaScript или ES5. Этот навык охватывает конфигурацию компонентов, состояния, события, шаблоны, специальные возможности и общие шаблоны пользовательского интерфейса.
