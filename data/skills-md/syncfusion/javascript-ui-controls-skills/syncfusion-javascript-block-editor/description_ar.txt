قم بتنفيذ عنصر التحكم Syncfusion JavaScript BlockEditor - وهو محرر نصوص حديث قائم على الكتلة مع أوامر السحب والإفلات والشرطة المائلة وإمكانيات التنسيق الشاملة. استخدم هذه المهارة فورًا من أجل: تنفيذ BlockEditor، والمحررين المعتمدين على الكتلة، وتحرير المحتوى باستخدام الكتل، ومحرري المستندات ببنية الكتلة، وتحرير النص باستخدام واجهة المستخدم الحديثة، وقوائم الأوامر المائلة، وإعادة ترتيب المحتوى بالسحب والإفلات، وأشرطة الأدوات المضمنة، وميزات التحرير التعاوني، وإنشاء المحتوى المنظم، @الإشارات والتسميات، وكتل التعليمات البرمجية مع تمييز بناء الجملة، والجداول والقوائم، والأقسام القابلة للطي، أو أي عنصر تحكم Syncfusion EJ2 BlockEditor. الاستخدام في تطبيقات جافا سكريبت.
