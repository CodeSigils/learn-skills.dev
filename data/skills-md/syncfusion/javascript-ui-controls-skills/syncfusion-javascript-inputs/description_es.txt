Guía completa para implementar componentes de entrada de Syncfusion TypeScript, incluidos ColorPicker, MaskedTextBox, OtpInput, Slider, TextArea, NumericTextBox, Rating, Signature, TextBox y uploader. Utilícelo cuando agregue selección de color, formato enmascarado, entrada OTP, controles deslizantes de rango, texto multilínea, entradas numéricas, carga de archivos, clasificación de estrellas, captura de firmas o entradas de texto a una aplicación TypeScript.
