تنفيذ مكونات Syncfusion TypeScript Avatar لتمثيل المستخدم. يُستخدم عندما يحتاج المستخدم إلى عرض ملفات تعريف المستخدمين، أو الصور الرمزية بأشكال مختلفة (دائرية أو مستطيلة)، أو الحجم المخصص، أو تنسيقات الوسائط (الصور، SVG، الأيقونات، الحروف)، تخصيص الألوان، أو دمج الصور الرمزية مع عناصر التحكم الأخرى مثل Badge أو ListView.
