Внедрите компоненты аватара Syncfusion TypeScript для представлений пользователей. Используйте, когда пользователю необходимо отображать профили пользователей, аватары различной формы (круглые или прямоугольные), настраиваемый размер, форматы мультимедиа (изображения, SVG, значки, буквы), настройку цвета или интегрировать аватары с другими элементами управления, такими как Badge или ListView.
