Implementieren Sie Syncfusion TypeScript-Avatar-Komponenten für Benutzerdarstellungen. Verwenden Sie diese Option, wenn der Benutzer Benutzerprofile, Avatare mit unterschiedlichen Formen (rund oder rechteckig), benutzerdefinierte Größen, Medienformate (Bilder, SVG, Symbole, Buchstaben), Farbanpassungen anzeigen oder Avatare mit anderen Steuerelementen wie Badge oder ListView integrieren muss.
