Implementare i componenti Avatar Syncfusion TypeScript per le rappresentazioni degli utenti. Utilizzare quando l'utente deve visualizzare profili utente, avatar con forme diverse (circolari o rettangolari), dimensioni personalizzate, formati multimediali (immagini, SVG, icone, lettere), personalizzazione del colore o integrare avatar con altri controlli come Badge o ListView.
