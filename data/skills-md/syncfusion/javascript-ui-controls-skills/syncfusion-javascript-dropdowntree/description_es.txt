Implemente el control del árbol desplegable de Syncfusion para mostrar datos jerárquicos en formato desplegable. Utilice esta habilidad al implementar la selección de valores únicos o múltiples a partir de datos jerárquicos, habilitar casillas de verificación con estados padre-hijo dependientes, cargar grandes conjuntos de datos de forma diferida, personalizar elementos del árbol con plantillas y configurar la compatibilidad con varios idiomas. Cobertura completa de propiedades, métodos, eventos, modos de enlace de datos, selección de casillas de verificación, plantillas y funciones de accesibilidad.
