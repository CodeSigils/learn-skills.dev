قم بتنفيذ التحكم في شجرة القائمة المنسدلة Syncfusion لعرض البيانات الهرمية بتنسيق القائمة المنسدلة. استخدم هذه المهارة عند تنفيذ تحديد قيمة فردية أو متعددة من البيانات الهرمية، وتمكين مربعات الاختيار مع الحالات التابعة للأصل والفرع، وتحميل مجموعات البيانات الكبيرة البطيئة، وتخصيص عناصر الشجرة باستخدام القوالب، وتكوين الدعم متعدد اللغات. تغطية شاملة للخصائص والأساليب والأحداث وأوضاع ربط البيانات واختيار خانة الاختيار والقوالب وميزات إمكانية الوصول.
