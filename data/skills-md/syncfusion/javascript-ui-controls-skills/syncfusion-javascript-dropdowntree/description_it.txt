Implementare il controllo Syncfusion Dropdown Tree per visualizzare i dati gerarchici in formato a discesa. Utilizzare questa competenza quando si implementa la selezione di valori singoli o multipli da dati gerarchici, si abilitano caselle di controllo con stati padre-figlio dipendenti, si caricano lentamente set di dati di grandi dimensioni, si personalizzano gli elementi dell'albero con modelli e si configura il supporto multilingue. Copertura completa di proprietà, metodi, eventi, modalità di associazione dati, selezione di caselle di controllo, modelli e funzionalità di accessibilità.
