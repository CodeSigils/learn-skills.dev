Внедрите элемент управления раскрывающимся списком Syncfusion Tree для отображения иерархических данных в формате раскрывающегося списка. Используйте этот навык при реализации выбора одного или нескольких значений из иерархических данных, включении флажков с зависимыми родительскими и дочерними состояниями, ленивой загрузке больших наборов данных, настройке элементов дерева с помощью шаблонов и настройке поддержки нескольких языков. Комплексный охват свойств, методов, событий, режимов привязки данных, выбора флажков, шаблонов и специальных возможностей.
