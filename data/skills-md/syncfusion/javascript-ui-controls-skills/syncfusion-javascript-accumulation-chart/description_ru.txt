Реализует диаграммы накопления Syncfusion JavaScript (пирог, пончик, воронка, пирамида) для пропорциональных и процентных визуализаций. Используйте при отображении категориальных или пропорциональных данных. Охватывает конфигурацию условных обозначений и меток, интерактивность, доступность и настройку. Работает с TypeScript (модулями) и JavaScript (CDN/ES5).
