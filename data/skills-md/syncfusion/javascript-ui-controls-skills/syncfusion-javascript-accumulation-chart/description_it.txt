Implementa i grafici di accumulo JavaScript Syncfusion (torta, ciambella, imbuto, piramide) per visualizzazioni proporzionali e basate su percentuale. Da utilizzare quando si visualizzano dati categorici o proporzionali. Riguarda la configurazione della legenda e dell'etichetta, l'interattività, l'accessibilità e la personalizzazione. Funziona con TypeScript (moduli) e JavaScript (CDN/ES5).
