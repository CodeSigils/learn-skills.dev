Implémente des graphiques d'accumulation JavaScript Syncfusion (Tarte, Donut, Entonnoir, Pyramide) pour des visualisations proportionnelles et basées sur des pourcentages. À utiliser lors de l'affichage de données catégorielles ou proportionnelles. Couvre la configuration des légendes et des étiquettes, l’interactivité, l’accessibilité et la personnalisation. Fonctionne avec TypeScript (modules) et JavaScript (CDN/ES5).
