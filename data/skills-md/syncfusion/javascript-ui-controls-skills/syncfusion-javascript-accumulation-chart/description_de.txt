Implementiert Syncfusion JavaScript-Akkumulationsdiagramme (Kreis, Donut, Trichter, Pyramide) für proportionale und prozentuale Visualisierungen. Verwenden Sie diese Option, wenn Sie kategoriale oder proportionale Daten anzeigen. Behandelt Legenden- und Beschriftungskonfiguration, Interaktivität, Barrierefreiheit und Anpassung. Funktioniert mit TypeScript (Module) und JavaScript (CDN/ES5).
