Implementa gráficos de acumulación de JavaScript de Syncfusion (Pie, Donut, Funnel, Pyramid) para visualizaciones proporcionales y porcentuales. Úselo al mostrar datos categóricos o proporcionales. Cubre la configuración, interactividad, accesibilidad y personalización de leyendas y etiquetas. Funciona con TypeScript (módulos) y JavaScript (CDN/ES5).
