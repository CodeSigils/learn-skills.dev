Implémente Syncfusion TypeScript/JavaScript (ES6+) DataManager pour la liaison locale/à distance, CRUD, les requêtes, la mise en cache et le middleware. Prend en charge JsonAdaptor, ODataAdaptor, ODataV4Adaptor, UrlAdaptor, WebApiAdaptor, WebMethodAdaptor, RemoteSaveAdaptor, GraphQLAdaptor, CustomDataAdaptor et CustomAdaptor. Couvre la classe de requête, le filtrage, le tri, la pagination, le regroupement, la persistance, le mode hors ligne, la mise en cache et la gestion des erreurs.
