ローカル/リモート バインディング、CRUD、クエリ、キャッシュ、ミドルウェア用に Syncfusion TypeScript/JavaScript(ES6+) DataManager を実装します。 JsonAdaptor、ODataAdaptor、ODataV4Adaptor、UrlAdaptor、WebApiAdaptor、WebMethodAdaptor、RemoteSaveAdaptor、GraphQLAdaptor、CustomDataAdaptor、および CustomAdaptor をサポートします。クエリ クラス、フィルタリング、並べ替え、ページング、グループ化、永続化、オフライン モード、キャッシュ、エラー処理について説明します。
