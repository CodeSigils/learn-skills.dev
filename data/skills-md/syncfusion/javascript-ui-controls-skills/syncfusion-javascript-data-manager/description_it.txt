Implementa Syncfusion TypeScript/JavaScript(ES6+) DataManager per associazione locale/remota, CRUD, query, memorizzazione nella cache e middleware. Supporta JsonAdaptor, ODataAdaptor, ODataV4Adaptor, UrlAdaptor, WebApiAdaptor, WebMethodAdaptor, RemoteSaveAdaptor, GraphQLAdaptor, CustomDataAdaptor e CustomAdaptor. Copre classi di query, filtraggio, ordinamento, paginazione, raggruppamento, persistenza, modalità offline, memorizzazione nella cache e gestione degli errori.
