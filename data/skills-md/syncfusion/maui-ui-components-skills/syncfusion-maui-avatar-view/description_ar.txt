يطبق Syncfusion .NET MAUI Avatar View (SfAvatarView) لعرض صور الملف الشخصي للمستخدم، أو الأحرف الأولى من اسمه، أو الصور الرمزية للمجموعة. يُستخدم عند العمل مع طرق عرض الصورة الرمزية، أو صور الملف الشخصي، أو صور المستخدم، أو عرض الأحرف الأولى، أو أيقونات ملف التعريف، أو صور جهات الاتصال. مثالي لتنفيذ عروض ملفات تعريف المستخدمين أو قوائم جهات الاتصال أو واجهات الدردشة أو الخلاصات الاجتماعية.
