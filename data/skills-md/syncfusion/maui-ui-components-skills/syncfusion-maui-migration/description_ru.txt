Переносит компоненты Syncfusion из Xamarin.Forms в .NET MAUI. Используйте при миграции приложений Xamarin.Forms в .NET MAUI, изменении пространства имен, переименовании API, миграции свойств или критических изменениях. Охватывает миграцию SfChart в SfCartesianChart, регистрацию обработчика, обновления пакетов NuGet и обновления перечислений.
