ترحيل مكونات Syncfusion من Xamarin.Forms إلى .NET MAUI. يُستخدم عند ترحيل تطبيقات Xamarin.Forms إلى .NET MAUI، أو معالجة تغييرات مساحة الاسم، أو إعادة تسمية واجهة برمجة التطبيقات، أو ترحيل الخصائص، أو كسر التغييرات. يغطي ترحيل SfChart إلى SfCartesianChart، وتسجيل المعالج، وتحديثات حزمة NuGet، وتحديثات التعداد.
