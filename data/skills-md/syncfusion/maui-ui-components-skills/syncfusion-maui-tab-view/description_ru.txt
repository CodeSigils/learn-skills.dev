Реализует элементы управления представлением вкладок Syncfusion .NET MAUI (SfTabView) для интерфейсов навигации по вкладкам и макетов содержимого с вкладками. Используйте при работе с элементами управления вкладками, навигацией по вкладкам, вложенными вкладками или перелистываемым содержимым в приложениях .NET MAUI. Этот навык охватывает настройку панели вкладок, настройку элементов вкладок, жесты смахивания, события и визуальную настройку, включая индикаторы и эффекты жидкого стекла.
