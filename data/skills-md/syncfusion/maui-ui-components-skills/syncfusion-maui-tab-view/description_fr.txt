Implémente les contrôles Syncfusion .NET MAUI Tab View (SfTabView) pour les interfaces de navigation par onglets et les dispositions de contenu par onglets. À utiliser lorsque vous travaillez avec des contrôles d'onglets, la navigation par onglets, des onglets imbriqués ou du contenu pouvant être glissé dans les applications .NET MAUI. Cette compétence couvre la personnalisation de la barre d'onglets, la configuration des éléments d'onglet, les gestes de balayage, les événements et la personnalisation visuelle, y compris les indicateurs et les effets Liquid Glass.
