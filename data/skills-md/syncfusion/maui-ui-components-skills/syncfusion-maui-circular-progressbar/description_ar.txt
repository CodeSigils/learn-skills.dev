ينفذ ويخصص مكونات Syncfusion .NET MAUI Circular ProgressBar (SfCircularProgressBar). يُستخدم عند العمل باستخدام أشرطة التقدم الدائرية، أو مؤشرات التقدم الدائرية، أو التقدم الشعاعي، أو دوائر التقدم، أو التقدم القوسي في تطبيقات .NET MAUI. يغطي حالات التقدم المحددة/غير المحددة، ومؤشرات التقدم المتحركة، والتقدم الدائري المجزأ، والزوايا المخصصة.
