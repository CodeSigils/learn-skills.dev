Implementiert den Syncfusion .NET MAUI Scheduler (SfScheduler). Verwendung beim Erstellen von Planungsanwendungen, Kalenderansichten, Terminverwaltung, Ereignisplanung oder Ressourcenplanung in .NET MAUI. Umfasst Planeransichten, Terminverwaltung, wiederkehrende Ereignisse und Zeitleistenansichten.
