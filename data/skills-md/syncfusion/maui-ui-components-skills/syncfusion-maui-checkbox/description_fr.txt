Implémente les contrôles Syncfusion .NET MAUI CheckBox (SfCheckBox) dans les applications MAUI. À utiliser lors de l'implémentation de cases à cocher, de contrôles de sélection ou de boutons à bascule dans .NET MAUI. Couvre les cases à cocher à trois états, l'état indéterminé, la personnalisation des cases à cocher, les événements de case à cocher, les états visuels et les groupes de cases à cocher.
