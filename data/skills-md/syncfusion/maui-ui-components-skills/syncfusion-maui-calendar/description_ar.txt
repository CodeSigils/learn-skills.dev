ينفذ ويخصص التحكم في Syncfusion .NET MAUI Calendar (SfCalendar). يُستخدم عند تنفيذ وظيفة التقويم، أو تحديد التاريخ (فردي، أو متعدد، أو نطاق)، أو طرق عرض التقويم (الشهر، أو السنة، أو العقد، أو القرن). يغطي قيود التاريخ (الحد الأدنى/الحد الأقصى للتواريخ، EnablePastDates، SelectableDayPredicate)، وتخصيص التقويم، والأحداث (ViewChanged، SelectionChanged، Tapped)، وتخصيص الرأس/التذييل.
