Implémente Syncfusion .NET MAUI Smart DataGrid (SfSmartDataGrid) avec des fonctionnalités basées sur l'IA. À utiliser lorsque vous travaillez avec SfSmartDataGrid, des opérations de grille basées sur l'IA, des commandes de données en langage naturel, le tri de l'IA, le filtrage de l'IA ou l'interaction de grille conversationnelle. Couvre l’intégration de grille Azure OpenAI et les commandes en langage naturel pour les grilles.
