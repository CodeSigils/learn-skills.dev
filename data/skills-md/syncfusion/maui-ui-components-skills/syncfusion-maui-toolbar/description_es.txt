Implementa la barra de herramientas Syncfusion .NET MAUI (SfToolbar) para barras de navegación y barras de comandos. Úselo cuando trabaje con barras de herramientas, elementos de barras de herramientas, barras de navegación, botones de barras de herramientas o barras de herramientas de acciones en aplicaciones .NET MAUI. Esta habilidad cubre la configuración de elementos de la barra de herramientas, íconos, texto, comportamiento de desbordamiento, orientación, modos de selección y personalización de la barra de herramientas.
