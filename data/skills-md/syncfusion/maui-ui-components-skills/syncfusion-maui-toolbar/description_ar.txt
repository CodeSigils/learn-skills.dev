يطبق شريط أدوات Syncfusion .NET MAUI (SfToolbar) لأشرطة التنقل وأشرطة الأوامر. يُستخدم عند العمل باستخدام أشرطة الأدوات، أو عناصر شريط الأدوات، أو أشرطة التنقل، أو أزرار شريط الأدوات، أو أشرطة أدوات الإجراءات في تطبيقات .NET MAUI. تغطي هذه المهارة تكوين عنصر شريط الأدوات، والأيقونات، والنص، وسلوك التجاوز، والاتجاه، وأوضاع التحديد، وتخصيص شريط الأدوات.
