Реализует панель инструментов Syncfusion .NET MAUI (SfToolbar) для панелей навигации и панелей команд. Используйте при работе с панелями инструментов, элементами панели инструментов, панелями навигации, кнопками панели инструментов или панелями действий в приложениях .NET MAUI. Этот навык охватывает настройку элементов панели инструментов, значки, текст, поведение при переполнении, ориентацию, режимы выбора и настройку панели инструментов.
