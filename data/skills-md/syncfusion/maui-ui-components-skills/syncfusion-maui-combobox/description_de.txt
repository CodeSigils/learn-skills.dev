Implementiert das Syncfusion .NET MAUI ComboBox (SfComboBox)-Steuerelement. Verwenden Sie diese Option, wenn Sie mit ComboBox, Dropdown-Auswahl, bearbeitbarem Dropdown, durchsuchbarem Dropdown oder filterbarem Dropdown in .NET MAUI arbeiten. Behandelt die grundlegende ComboBox-Einrichtung, bearbeitbare/nicht bearbeitbare Modi, Einzel-/Mehrfachauswahl, Filterung und Suche, benutzerdefiniertes UI-Design und KI-gestützte intelligente Suche.
