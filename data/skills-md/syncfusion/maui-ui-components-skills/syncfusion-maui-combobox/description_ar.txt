ينفذ التحكم Syncfusion .NET MAUI ComboBox (SfComboBox). يُستخدم عند العمل مع ComboBox، أو تحديد القائمة المنسدلة، أو القائمة المنسدلة القابلة للتحرير، أو القائمة المنسدلة القابلة للبحث، أو القائمة المنسدلة القابلة للتصفية في .NET MAUI. يغطي إعداد ComboBox الأساسي، والأوضاع القابلة للتحرير/غير القابلة للتحرير، والاختيار الفردي/المتعدد، والتصفية والبحث، وتصميم واجهة المستخدم المخصصة، والبحث الذكي المدعوم بالذكاء الاصطناعي.
