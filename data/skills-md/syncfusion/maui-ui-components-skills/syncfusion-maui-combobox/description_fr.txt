Implémente le contrôle Syncfusion .NET MAUI ComboBox (SfComboBox). À utiliser lorsque vous travaillez avec ComboBox, une sélection déroulante, une liste déroulante modifiable, une liste déroulante consultable ou une liste déroulante filtrable dans .NET MAUI. Couvre la configuration de base de ComboBox, les modes modifiables/non modifiables, la sélection simple/multiple, le filtrage et la recherche, le style d'interface utilisateur personnalisé et la recherche intelligente alimentée par l'IA.
