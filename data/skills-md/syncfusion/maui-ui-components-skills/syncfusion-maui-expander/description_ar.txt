يطبق عنصر التحكم Syncfusion .NET MAUI Expander (SfExpander) لأقسام المحتوى القابلة للطي والقابلة للتوسيع. يُستخدم عند العمل مع الموسعات أو الأقسام القابلة للطي أو الأكورديون أو اللوحات القابلة للتوسيع أو وظيفة التوسيع/الطي في تطبيقات .NET MAUI. يغطي التخطيطات الموفرة للمساحة، وتخصيص الرأس، والرسوم المتحركة للتوسيع/الطي، وتأثيرات الزجاج السائل.
