Implémente le contrôle Syncfusion .NET MAUI Expander (SfExpander) pour les sections de contenu pliables et extensibles. À utiliser lorsque vous travaillez avec des extensions, des sections pliables, des accordéons, des panneaux extensibles ou des fonctionnalités d'extension/réduction dans les applications .NET MAUI. Couvre les mises en page économes en espace, la personnalisation des en-têtes, les animations de développement/réduction et les effets de verre liquide.
