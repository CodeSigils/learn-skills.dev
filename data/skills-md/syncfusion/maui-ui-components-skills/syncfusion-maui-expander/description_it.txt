Implementa il controllo Syncfusion .NET MAUI Expander (SfExpander) per sezioni di contenuto comprimibili ed espandibili. Da utilizzare quando si lavora con espansori, sezioni comprimibili, fisarmoniche, pannelli espandibili o funzionalità di espansione/compressione nelle applicazioni .NET MAUI. Copre layout salvaspazio, personalizzazione dell'intestazione, animazioni di espansione/compressione ed effetti di vetro liquido.
