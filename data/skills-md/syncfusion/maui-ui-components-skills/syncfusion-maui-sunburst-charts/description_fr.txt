Implémente le graphique Sunburst Syncfusion .NET MAUI (SfSunburstChart) pour la visualisation hiérarchique des données à l'aide d'une disposition circulaire radiale à plusieurs niveaux. Utilisez-le pour les graphiques sunburst, les graphiques hiérarchiques radiaux, les diagrammes circulaires à plusieurs niveaux ou la visualisation de données hiérarchiques avec des capacités d'exploration. Idéal pour visualiser les structures organisationnelles, les systèmes de fichiers ou les données catégorielles imbriquées.
