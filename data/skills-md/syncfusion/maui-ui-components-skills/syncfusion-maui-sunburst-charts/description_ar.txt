ينفذ Syncfusion .NET MAUI Sunburst Chart (SfSunburstChart) لتصور البيانات الهرمية باستخدام تخطيط دائري شعاعي متعدد المستويات. استخدم هذا للمخططات المتسلسلة، أو المخططات الهرمية الشعاعية، أو المخططات الدائرية متعددة المستويات، أو تصور البيانات الهرمية مع إمكانيات التنقل لأسفل. مثالية لتصور الهياكل التنظيمية أو أنظمة الملفات أو البيانات الفئوية المتداخلة.
