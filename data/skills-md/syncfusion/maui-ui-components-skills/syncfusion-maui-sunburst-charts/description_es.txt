Implementa Syncfusion .NET MAUI Sunburst Chart (SfSunburstChart) para la visualización de datos jerárquicos utilizando un diseño circular radial de varios niveles. Utilícelo para gráficos tipo rayos de sol, gráficos jerárquicos radiales, gráficos circulares de varios niveles o visualización de datos jerárquicos con capacidades de desglose. Ideal para visualizar estructuras organizativas, sistemas de archivos o datos categóricos anidados.
