Implementa Syncfusion .NET MAUI Sunburst Chart (SfSunburstChart) per la visualizzazione gerarchica dei dati utilizzando un layout circolare radiale a più livelli. Utilizzalo per grafici sunburst, grafici gerarchici radiali, grafici a torta multilivello o visualizzazione di dati gerarchici con funzionalità di drill-down. Ideale per visualizzare strutture organizzative, file system o dati categorici annidati.
