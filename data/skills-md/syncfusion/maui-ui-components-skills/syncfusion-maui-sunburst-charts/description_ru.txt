Реализует диаграмму солнечных лучей Syncfusion .NET MAUI (SfSunburstChart) для иерархической визуализации данных с использованием радиальной многоуровневой круговой компоновки. Используйте это для диаграмм солнечных лучей, радиальных иерархических диаграмм, многоуровневых круговых диаграмм или иерархической визуализации данных с возможностью детализации. Идеально подходит для визуализации организационных структур, файловых систем или вложенных категориальных данных.
