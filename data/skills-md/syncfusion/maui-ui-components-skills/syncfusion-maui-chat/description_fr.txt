Implémente le contrôle Syncfusion .NET MAUI Chat (SfChat) dans les applications .NET MAUI. À utiliser lorsque vous travaillez avec des interfaces de discussion, une interface utilisateur de messagerie, des interfaces conversationnelles, des bulles de discussion ou des fils de discussion. Couvre les types de messages (texte, image, calendrier, carte), la liaison de données, les événements, les suggestions, les indicateurs de saisie, les pauses et les actions de balayage.
