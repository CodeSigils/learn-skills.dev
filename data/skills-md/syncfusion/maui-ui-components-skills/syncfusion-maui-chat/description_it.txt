Implementa il controllo Syncfusion .NET MAUI Chat (SfChat) nelle applicazioni .NET MAUI. Da utilizzare quando si lavora con interfacce di chat, interfaccia utente di messaggistica, interfacce di conversazione, fumetti di chat o thread di messaggi. Copre i tipi di messaggio (testo, immagine, calendario, scheda), associazione dati, eventi, suggerimenti, indicatori di digitazione, interruzioni temporali e azioni di scorrimento.
