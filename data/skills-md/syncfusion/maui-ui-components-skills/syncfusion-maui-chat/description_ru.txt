Реализует элемент управления Syncfusion .NET MAUI Chat (SfChat) в приложениях .NET MAUI. Используйте при работе с интерфейсами чата, пользовательским интерфейсом обмена сообщениями, диалоговыми интерфейсами, всплывающими окнами чата или цепочками сообщений. Охватывает типы сообщений (текст, изображение, календарь, карточка), привязку данных, события, предложения, индикаторы набора текста, перерывы во времени и действия смахивания.
