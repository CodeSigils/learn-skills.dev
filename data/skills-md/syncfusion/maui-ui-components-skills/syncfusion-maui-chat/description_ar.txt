ينفذ التحكم في Syncfusion .NET MAUI Chat (SfChat) في تطبيقات .NET MAUI. يُستخدم عند العمل مع واجهات الدردشة أو واجهة مستخدم المراسلة أو واجهات المحادثة أو فقاعات الدردشة أو سلاسل الرسائل. يغطي أنواع الرسائل (نصية، صورة، تقويم، بطاقة)، ​​وربط البيانات، والأحداث، والاقتراحات، ومؤشرات الكتابة، والفواصل الزمنية، وإجراءات الضرب.
