Implementa el control deslizante de rango Syncfusion .NET MAUI (SfRangeSlider) para seleccionar valores de rango numérico con dos pulgares. Úselo para controles de selección de rango, controles deslizantes de valor dual, selectores de rango de precios, filtros de rango de fechas o escenarios que requieran una selección de valor mínimo y máximo con pulgares interactivos.
