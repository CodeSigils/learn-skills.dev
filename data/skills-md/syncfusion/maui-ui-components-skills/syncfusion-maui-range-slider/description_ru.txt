Реализует ползунок диапазона Syncfusion .NET MAUI (SfRangeSlider) для выбора значений числового диапазона с помощью двух больших пальцев. Используйте это для элементов управления выбором диапазона, ползунков с двумя значениями, переключателей ценовых диапазонов, фильтров диапазона дат или сценариев, требующих выбора минимального и максимального значений с помощью интерактивных ползунов.
