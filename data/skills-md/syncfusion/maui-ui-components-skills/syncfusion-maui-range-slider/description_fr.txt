Implémente le curseur de plage Syncfusion .NET MAUI (SfRangeSlider) pour sélectionner les valeurs de plage numérique avec deux pouces. Utilisez-le pour les contrôles de sélection de plage, les curseurs à double valeur, les sélecteurs de plage de prix, les filtres de plage de dates ou les scénarios nécessitant une sélection de valeur minimale-maximale avec des pouces interactifs.
