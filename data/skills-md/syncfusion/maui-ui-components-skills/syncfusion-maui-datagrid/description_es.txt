Implementa y personaliza Syncfusion .NET MAUI DataGrid (SfDataGrid) para mostrar datos tabulares. Úselo cuando trabaje con cuadrículas de datos MAUI, SfDataGrid, visualización de datos tabulares, enlace de datos a cuadrículas o configuración de columnas. Cubre la edición de celdas, clasificación, filtrado, agrupación, paginación, exportación a Excel/PDF, operaciones de filas, selección y resúmenes.
