Implémente et personnalise Syncfusion .NET MAUI DataGrid (SfDataGrid) pour afficher des données tabulaires. À utiliser lorsque vous travaillez avec des grilles de données MAUI, SfDataGrid, l'affichage de données tabulaires, la liaison de données à des grilles ou la configuration de colonnes. Couvre l'édition de cellules, le tri, le filtrage, le regroupement, la pagination, l'exportation vers Excel/PDF, les opérations sur les lignes, la sélection et les résumés.
