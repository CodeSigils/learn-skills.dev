Implémente le contrôle Syncfusion .NET MAUI DateTime Range Slider (SfDateTimeRangeSlider). À utiliser lors de l'implémentation de curseurs de plage, de sélecteurs de plage de dates, de sélecteurs de plage de temps, de curseurs à double pouce ou de contrôles de sélection de plage interactifs dans les applications .NET MAUI. Cette compétence couvre l'installation, la configuration, le style des pistes, les étiquettes, les graduations, les séparateurs, les info-bulles, la personnalisation du pouce et l'effet Liquid Glass.
