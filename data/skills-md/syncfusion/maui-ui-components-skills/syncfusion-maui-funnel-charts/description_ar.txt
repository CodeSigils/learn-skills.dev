ينفذ ويخصص مخططات مسار التحويل Syncfusion .NET MAUI (SfFunnelChart). يُستخدم عند تنفيذ المخططات القمعية، أو تصور مسار المبيعات، أو تحليل مسار التحويل، أو تصور مرحلة العملية، أو تتبع مسار التسويق. يغطي تنفيذ المخطط التحويلي، والتخصيص، وتسميات البيانات، ووسائل الإيضاح، وتلميحات الأدوات، وتباعد المقاطع، والاتجاه.
