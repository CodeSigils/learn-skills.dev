Реализует Syncfusion .NET MAUI DockLayout (SfDockLayout) для упорядочения и закрепления дочерних элементов в определенных областях. Используйте это для создания макетов закрепления, размещения элементов пользовательского интерфейса по краям (сверху/снизу/слева/справа), создания макетов информационной панели или организации многорегиональных интерфейсов. Охватывает позиционирование закрепления, расположение краев и расстояние между закрепленными элементами.
