Implementa Syncfusion .NET MAUI DockLayout (SfDockLayout) para organizar y acoplar elementos secundarios en áreas definidas. Úselo para crear diseños de acoplamiento, colocar elementos de la interfaz de usuario en los bordes (arriba/abajo/izquierda/derecha), crear diseños de paneles u organizar interfaces multirregionales. Cubre el posicionamiento del muelle, el posicionamiento del borde y el espaciado entre elementos acoplados.
