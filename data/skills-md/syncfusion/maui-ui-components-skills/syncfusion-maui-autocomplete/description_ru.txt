Реализует и настраивает элемент управления автозаполнением Syncfusion .NET MAUI (SfAutocomplete) для интеллектуального ввода текста с предложениями. Используйте при реализации автозаполнения, автозаполнения, поиска с опережением ввода, интеллектуального поиска или отфильтрованных раскрывающихся списков в приложениях .NET MAUI. Охватывает привязку данных, режимы фильтрации, настраиваемую логику поиска, поиск на основе искусственного интеллекта, множественный выбор с помощью токенов и настройку пользовательского интерфейса.
