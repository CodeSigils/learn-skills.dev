ينفذ ويكوّن التحكم في Syncfusion .NET MAUI للإكمال التلقائي (SfAutocomplete) لإدخال النص الذكي مع الاقتراحات. يُستخدم عند تنفيذ الإكمال التلقائي، أو الاقتراح التلقائي، أو البحث بالكتابة المسبقة، أو البحث الذكي، أو القوائم المنسدلة التي تمت تصفيتها في تطبيقات .NET MAUI. يغطي ربط البيانات، وأوضاع التصفية، ومنطق البحث المخصص، والبحث المدعوم بالذكاء الاصطناعي، والاختيار المتعدد باستخدام الرموز المميزة، وتخصيص واجهة المستخدم.
