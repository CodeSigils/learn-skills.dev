Implémente Syncfusion .NET MAUI Shimmer (SfShimmer) en chargeant les effets d'espace réservé. À utiliser lors de l'implémentation d'animations de chargement chatoyantes ou squelettes, du chargement d'espaces réservés ou d'indicateurs de chargement de contenu dans les applications .NET MAUI. Couvre les types de reflets (CirclePersona, Article, Feed, Shopping), les vues chatoyantes personnalisées, l'animation de vagues et la personnalisation.
