Implémente le contrôle Syncfusion .NET MAUI Badge View (SfBadgeView). À utiliser lors de l'ajout de notifications de badge, d'indicateurs d'état, de décomptes non lus ou de superpositions de notifications aux applications MAUI. Couvre la configuration de SfBadgeView, la personnalisation du texte du badge, les ajustements de position, les animations, les symboles prédéfinis et les fonctionnalités d'accessibilité.
