Реализует переключатель Syncfusion .NET MAUI (SfRadioButton) для взаимоисключающих элементов управления выбором. Используйте при реализации переключателей, элементов управления выбором со взаимоисключающими параметрами или сгруппированных переключателей в приложениях .NET MAUI. Охватывает управление состоянием переключателя, механизмы группировки (GroupKey или SfRadioGroup), события и визуальную настройку.
