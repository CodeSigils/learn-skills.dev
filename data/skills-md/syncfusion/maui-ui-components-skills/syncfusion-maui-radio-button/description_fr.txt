Implémente le bouton radio Syncfusion .NET MAUI (SfRadioButton) pour des contrôles de sélection mutuellement exclusifs. À utiliser lors de l'implémentation de boutons radio, de contrôles de sélection avec des options mutuellement exclusives ou de boutons radio groupés dans les applications .NET MAUI. Couvre la gestion de l’état des boutons radio, les mécanismes de regroupement (GroupKey ou SfRadioGroup), les événements et la personnalisation visuelle.
