ينفذ زر الراديو Syncfusion .NET MAUI (SfRadioButton) لعناصر التحكم في الاختيار الحصرية المتبادلة. يُستخدم عند تنفيذ أزرار الاختيار، أو عناصر التحكم في التحديد ذات الخيارات الحصرية المتبادلة، أو أزرار الاختيار المجمعة في تطبيقات .NET MAUI. يغطي إدارة حالة زر الاختيار وآليات التجميع (GroupKey أو SfRadioGroup) والأحداث والتخصيص المرئي.
