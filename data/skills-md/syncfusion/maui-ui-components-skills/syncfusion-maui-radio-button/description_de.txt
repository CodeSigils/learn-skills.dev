Implementiert den Syncfusion .NET MAUI Radio Button (SfRadioButton) für sich gegenseitig ausschließende Auswahlsteuerelemente. Verwenden Sie diese Option, wenn Sie Optionsfelder, Auswahlsteuerelemente mit sich gegenseitig ausschließenden Optionen oder gruppierte Optionsfelder in .NET MAUI-Anwendungen implementieren. Behandelt die Statusverwaltung von Optionsfeldern, Gruppierungsmechanismen (GroupKey oder SfRadioGroup), Ereignisse und visuelle Anpassung.
