Implementiert das Syncfusion .NET MAUI Radial Menu (SfRadialMenu) – ein hierarchisches kreisförmiges Menü, das für Touch optimiert ist. Verwenden Sie diese Option, wenn Sie mit radialen Menüs, kreisförmigen Menüs, Kontextmenüs, berührungsoptimierten Menüs oder hierarchischer kreisförmiger Navigation arbeiten. Behandelt schwebende Menüs, Menüs mit Drag-Funktion, verschachtelte kreisförmige Menüs und benutzerdefinierte segmentierte Layouts in .NET MAUI-Anwendungen.
