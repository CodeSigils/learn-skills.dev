Implémente le menu radial Syncfusion .NET MAUI (SfRadialMenu) - un menu circulaire hiérarchique optimisé pour le toucher. À utiliser lorsque vous travaillez avec des menus radiaux, des menus circulaires, des menus contextuels, des menus tactiles optimisés ou une navigation circulaire hiérarchique. Couvre les menus flottants, les menus activés par glisser-déposer, les menus circulaires imbriqués et les mises en page segmentées personnalisées dans les applications .NET MAUI.
