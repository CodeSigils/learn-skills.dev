ينفذ Syncfusion .NET MAUI Radial Menu (SfRadialMenu) - قائمة دائرية هرمية محسنة للمس. يُستخدم عند العمل مع القوائم الشعاعية، أو القوائم الدائرية، أو قوائم السياق، أو القوائم المحسنة باللمس، أو التنقل الدائري الهرمي. يغطي القوائم العائمة، والقوائم التي يمكن سحبها، والقوائم الدائرية المتداخلة، والتخطيطات المقسمة المخصصة في تطبيقات .NET MAUI.
