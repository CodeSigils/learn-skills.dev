Реализует Syncfusion .NET MAUI MarkdownViewer (SfMarkdownViewer) для рендеринга содержимого Markdown с полной поддержкой форматирования. Используйте при отображении файлов уценки, документации, примечаний к выпуску или содержимого справки в приложениях MAUI. Охватывает рендеринг уценки, настройку внешнего вида, стили CSS и источники контента (строка/файл/URL/ресурс).
