Implémente Syncfusion .NET MAUI MarkdownViewer (SfMarkdownViewer) pour restituer le contenu Markdown avec une prise en charge complète du formatage. À utiliser lors de l'affichage de fichiers de démarques, de documentation, de notes de version ou de contenu d'aide dans les applications MAUI. Couvre le rendu markdown, la personnalisation de l'apparence, le style CSS et les sources de contenu (chaîne/fichier/URL/ressource).
