Implementa Syncfusion .NET MAUI MarkdownViewer (SfMarkdownViewer) para representar contenido de Markdown con soporte completo de formato. Utilícelo cuando muestre archivos de rebajas, documentación, notas de la versión o contenido de ayuda en aplicaciones MAUI. Cubre la representación de rebajas, la personalización de la apariencia, el estilo CSS y las fuentes de contenido (cadena/archivo/URL/recurso).
