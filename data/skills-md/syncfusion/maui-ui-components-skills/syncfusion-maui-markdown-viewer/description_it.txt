Implementa Syncfusion .NET MAUI MarkdownViewer (SfMarkdownViewer) per il rendering di contenuti Markdown con supporto completo della formattazione. Da utilizzare quando si visualizzano file di markdown, documentazione, note sulla versione o contenuto della guida nelle app MAUI. Copre il rendering del markdown, la personalizzazione dell'aspetto, lo stile CSS e le origini dei contenuti (stringa/file/URL/risorsa).
