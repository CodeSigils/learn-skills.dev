Implementa Syncfusion .NET MAUI Accordion (SfAccordion): un pannello comprimibile verticalmente con intestazioni impilate per espandere/comprimere il contenuto. Da utilizzare quando si lavora con fisarmoniche, pannelli comprimibili, elenchi espandibili, elenchi di dipendenti con dettagli o sezioni FAQ nelle applicazioni .NET MAUI. Riguarda la configurazione di AccordionItem, le modalità di espansione e la visualizzazione dei contenuti raggruppati.
