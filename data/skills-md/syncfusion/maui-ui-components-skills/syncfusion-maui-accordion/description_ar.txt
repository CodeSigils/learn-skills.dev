ينفذ Syncfusion .NET MAUI Accordion (SfAccordion) - لوحة قابلة للطي رأسيًا مع رؤوس مكدسة لتوسيع/طي المحتوى. يُستخدم عند العمل مع الأكورديون، أو اللوحات القابلة للطي، أو القوائم القابلة للتوسيع، أو قوائم الموظفين مع التفاصيل، أو أقسام الأسئلة الشائعة في تطبيقات .NET MAUI. يغطي تكوين AccordionItem، وتوسيع الأوضاع، وعرض المحتوى المجمع.
