Реализует компоненты Syncfusion .NET MAUI Radial Gauge (SfRadialGauge). Используйте при работе с радиальными датчиками, круглыми датчиками, спидометрами, датчиками температуры, измерительными приборами или при визуализации круговых данных в приложениях .NET MAUI. Этот навык охватывает установку, конфигурацию осей, диапазоны, типы указателей (стрелка, форма, содержимое, диапазон), аннотации и анимацию.
