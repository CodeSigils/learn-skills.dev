Implémente le composant Syncfusion .NET MAUI Navigation Drawer (SfNavigationDrawer). À utiliser lorsque vous travaillez avec des tiroirs de navigation, des tiroirs coulissants, des menus latéraux, des menus hamburger ou des panneaux de tiroirs dans les applications .NET MAUI. Couvre le positionnement des tiroirs (gauche/droite/haut/bas), les animations (SlideOnTop/Push/Reveal), la gestion de contenu, les gestes de balayage et les événements.
