يطبق مكون Syncfusion .NET MAUI Navigation Drawer (SfNavigationDrawer). يُستخدم عند العمل مع أدراج التنقل، أو الأدراج المنزلقة، أو القوائم الجانبية، أو قوائم الهامبرغر، أو لوحات الأدراج في تطبيقات .NET MAUI. يغطي وضع الدرج (يسار/يمين/أعلى/أسفل)، والرسوم المتحركة (SlideOnTop/Push/Reveal)، وإدارة المحتوى، وإيماءات التمرير، والأحداث.
