Implementa Syncfusion .NET MAUI Pyramid Chart (SfPyramidChart) para representar visualmente datos jerárquicos, proporcionales y de partes a todo mediante segmentos en forma de pirámide. Úselo para gráficos piramidales, visualización de datos jerárquicos, visualización de datos proporcionales o gráficos basados ​​en segmentos. Esta habilidad cubre la instalación, el enlace de datos, las leyendas, la información sobre herramientas, las etiquetas de datos, la personalización de la apariencia y los degradados.
