ينفذ Syncfusion .NET MAUI Pyramid Chart (SfPyramidChart) لتمثيل البيانات الهرمية والتناسبية والأجزاء إلى الكل بشكل مرئي باستخدام مقاطع على شكل هرم. استخدم هذا للمخططات الهرمية، أو تصور البيانات الهرمية، أو عرض البيانات المتناسبة، أو المخططات المستندة إلى المقاطع. تغطي هذه المهارة التثبيت وربط البيانات والأساطير وتلميحات الأدوات وتسميات البيانات وتخصيص المظهر والتدرجات.
