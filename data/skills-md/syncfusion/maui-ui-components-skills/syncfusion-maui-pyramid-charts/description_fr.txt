Implémente le graphique pyramidal Syncfusion .NET MAUI (SfPyramidChart) pour représenter visuellement des données hiérarchiques, proportionnelles et parties-tout à l'aide de segments en forme de pyramide. Utilisez-le pour les graphiques pyramidaux, la visualisation de données hiérarchiques, l'affichage de données proportionnelles ou les graphiques basés sur des segments. Cette compétence couvre l'installation, la liaison de données, les légendes, les info-bulles, les étiquettes de données, la personnalisation de l'apparence et les dégradés.
