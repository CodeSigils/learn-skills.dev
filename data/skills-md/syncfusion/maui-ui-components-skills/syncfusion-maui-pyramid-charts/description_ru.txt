Реализует пирамидальную диаграмму Syncfusion .NET MAUI (SfPyramidChart) для визуального представления иерархических, пропорциональных данных и данных от частей к целому с использованием сегментов пирамидальной формы. Используйте это для пирамидальных диаграмм, иерархической визуализации данных, пропорционального отображения данных или сегментных диаграмм. Этот навык охватывает установку, привязку данных, легенды, всплывающие подсказки, метки данных, настройку внешнего вида и градиенты.
