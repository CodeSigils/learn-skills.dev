Implementa Syncfusion .NET MAUI Pyramid Chart (SfPyramidChart) per rappresentare visivamente dati gerarchici, proporzionali e da parti a tutto utilizzando segmenti a forma di piramide. Utilizzalo per grafici a piramide, visualizzazione di dati gerarchici, visualizzazione di dati proporzionali o grafici basati su segmenti. Questa competenza copre l'installazione, l'associazione dati, le legende, le descrizioni comandi, le etichette dati, la personalizzazione dell'aspetto e le sfumature.
