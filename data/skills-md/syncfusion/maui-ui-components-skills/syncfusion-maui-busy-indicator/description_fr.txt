Implémente l'indicateur d'activité Syncfusion .NET MAUI (SfBusyIndicator) pour afficher les états de chargement, le traitement des données et les indicateurs d'activité des applications. À utiliser lors de l'affichage d'indicateurs de chargement, d'animations occupées, de compteurs d'activité ou de traitement des commentaires dans les applications .NET MAUI. Couvre la configuration des indicateurs d'occupation, les animations et les commentaires visuels lors des opérations de longue durée.
