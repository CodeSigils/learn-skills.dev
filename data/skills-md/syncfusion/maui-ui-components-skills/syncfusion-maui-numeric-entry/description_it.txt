Implementa il controllo di immissione numerica Syncfusion .NET MAUI. Da utilizzare quando si lavora con input numerici con pulsanti di convalida, formattazione (valuta, percentuale, decimale), pulsanti di incremento/decremento del valore o restrizioni di intervallo. Ideale per input di prezzi, selettori di quantità, calcolatori di percentuali o immissione di dati numerici con formati personalizzati.
