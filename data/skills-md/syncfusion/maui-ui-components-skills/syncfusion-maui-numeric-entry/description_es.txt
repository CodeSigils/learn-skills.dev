Implementa el control de entrada numérica Syncfusion .NET MAUI. Úselo cuando trabaje con entradas numéricas con validación, formato (moneda, porcentaje, decimal), botones de incremento/disminución de valores o restricciones de rango. Ideal para entradas de precios, selectores de cantidades, calculadoras de porcentajes o entrada de datos numéricos con formatos personalizados.
