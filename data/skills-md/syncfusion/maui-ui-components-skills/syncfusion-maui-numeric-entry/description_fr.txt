Implémente le contrôle d'entrée numérique Syncfusion .NET MAUI. À utiliser lorsque vous travaillez avec une saisie numérique avec validation, formatage (devise, pourcentage, décimal), boutons d'incrémentation/décrémentation de valeur ou restrictions de plage. Idéal pour la saisie de prix, les sélecteurs de quantités, les calculateurs de pourcentage ou la saisie de données numériques avec des formats personnalisés.
