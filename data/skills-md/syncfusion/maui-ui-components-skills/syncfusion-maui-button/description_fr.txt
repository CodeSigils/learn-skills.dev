Implémente et personnalise le contrôle Syncfusion .NET MAUI Button (SfButton). À utiliser lorsque vous travaillez avec des boutons MAUI, l'implémentation de SfButton, la personnalisation des boutons ou les états visuels. Couvre les icônes de boutons, les images d'arrière-plan, la prise en charge RTL, les effets Liquid Glass, les vues de boutons personnalisées, le style des boutons, les événements et les boutons cochables.
