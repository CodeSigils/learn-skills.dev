ينفذ Syncfusion .NET MAUI Rich Text Editor (SfRichTextEditor) لتحرير النص WYSIWYG باستخدام التنسيق والصور والجداول والارتباطات التشعبية. يُستخدم عند إنشاء برامج تحرير نص منسق، أو برامج تحرير المستندات، أو مؤلفي البريد الإلكتروني، أو برامج تحرير منشورات المدونات، أو تطبيقات المراسلة ذات التنسيق. يغطي تصميم النص وتنسيق شريط الأدوات والصور والجداول والارتباطات التشعبية ومخرجات HTML.
