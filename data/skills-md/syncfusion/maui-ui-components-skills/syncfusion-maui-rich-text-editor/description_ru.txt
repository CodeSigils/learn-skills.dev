Реализует редактор форматированного текста Syncfusion .NET MAUI (SfRichTextEditor) для редактирования текста WYSIWYG с форматированием, изображениями, таблицами и гиперссылками. Используйте при создании редакторов форматированного текста, редакторов документов, составителей электронной почты, редакторов сообщений в блогах или приложений для обмена сообщениями с форматированием. Охватывает стили текста, форматирование панели инструментов, изображения, таблицы, гиперссылки и вывод HTML.
