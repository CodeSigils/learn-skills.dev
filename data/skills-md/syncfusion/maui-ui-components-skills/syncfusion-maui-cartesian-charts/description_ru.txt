Реализует декартову диаграмму Syncfusion .NET MAUI (SfCartesianChart) для визуализации данных с помощью более 20 типов диаграмм, включая линейные, площади, столбцы, гистограммы, финансовые, статистические и составные диаграммы. Используйте при реализации декартовых диаграмм, линейных диаграмм, диаграмм с областями или финансовых диаграмм (свеча, OHLC). Охватывает оси диаграммы, легенды, всплывающие подсказки, трекбол, масштабирование и панорамирование, аннотации диаграммы и линии тренда.
