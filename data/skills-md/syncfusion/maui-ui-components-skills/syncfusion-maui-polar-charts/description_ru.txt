Реализует полярные диаграммы Syncfusion .NET MAUI (SfPolarChart) для визуализации данных в полярных координатах. Используйте при работе с полярными диаграммами, радиолокационными диаграммами, диаграммами-пауками, веб-диаграммами или круговой визуализацией данных. Идеально подходит для отображения данных в виде значений и углов, создания рядов линий или площадей в полярных макетах или сравнения нескольких рядов данных в радиальном направлении.
