ينفذ Syncfusion .NET MAUI Polar Charts (SfPolarChart) لتصور البيانات في الإحداثيات القطبية. يُستخدم عند العمل مع المخططات القطبية، أو المخططات الرادارية، أو المخططات العنكبوتية، أو مخططات الويب، أو تصور البيانات الدائرية. مثالية لعرض البيانات من حيث القيم والزوايا، أو إنشاء سلسلة خطوط أو مناطق في تخطيطات قطبية، أو مقارنة سلاسل بيانات متعددة شعاعيًا.
