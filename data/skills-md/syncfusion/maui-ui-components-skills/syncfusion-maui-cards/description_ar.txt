تنفذ بطاقات Syncfusion .NET MAUI (SfCards) - طرق عرض البطاقات القابلة للرفض ومكدسات البطاقات القابلة للتمرير. يُستخدم عند العمل مع البطاقات، أو طرق عرض البطاقة، أو تخطيطات البطاقة، أو البطاقات القابلة للتمرير، أو البطاقات القابلة للرفض، أو مجموعات البطاقات في .NET MAUI. يغطي تخصيص البطاقة وأحداث البطاقة وربط بيانات البطاقة ومكونات البطاقة التفاعلية مع وظيفة التمرير.
