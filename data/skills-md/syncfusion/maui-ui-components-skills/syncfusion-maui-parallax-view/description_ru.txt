Реализует представление параллакса Syncfusion .NET MAUI (SfParallaxView) для создания эффектов прокрутки параллакса, при которых элементы фона перемещаются медленнее, чем содержимое переднего плана. Используйте при работе с эффектами параллакса, параллаксной прокруткой, эффектами фоновой прокрутки или прокруткой по глубине. Охватывает как простой параллакс изображений, так и сложные реализации настраиваемых элементов управления для ScrollView и ListView.
