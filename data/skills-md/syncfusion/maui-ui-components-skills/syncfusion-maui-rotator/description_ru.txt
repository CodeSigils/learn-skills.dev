Реализует элемент управления Syncfusion .NET MAUI Rotator (SfRotator) для отображения каруселей изображений, слайд-шоу или вращения содержимого. Используйте это для галерей изображений, витрин продуктов, слайдеров отзывов, ротаторов баннеров или сценариев, требующих автоматической или ручной навигации по визуальному контенту.
