Implementa el control Syncfusion .NET MAUI Rotator (SfRotator) para mostrar carruseles de imágenes, presentaciones de diapositivas o contenido giratorio. Úselo para galerías de imágenes, exhibiciones de productos, controles deslizantes de testimonios, rotadores de pancartas o escenarios que requieran navegación automática o manual a través de contenido visual.
