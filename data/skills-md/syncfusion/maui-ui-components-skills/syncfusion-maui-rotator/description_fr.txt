Implémente le contrôle Syncfusion .NET MAUI Rotator (SfRotator) pour afficher des carrousels d'images, des diaporamas ou du contenu en rotation. Utilisez-le pour les galeries d'images, les présentations de produits, les curseurs de témoignages, les rotateurs de bannières ou les scénarios nécessitant une navigation automatique ou manuelle dans le contenu visuel.
