Implementa y configura el editor de texto inteligente impulsado por IA Syncfusion .NET MAUI (SfSmartTextEditor). Úselo cuando trabaje con SfSmartTextEditor, entrada de texto impulsada por IA, sugerencias de texto predictivo, sugerencias en línea o emergentes, o configuraciones de UserRole/UserFrases. Cubre modos de visualización de sugerencias, servicios de IA personalizados (Claude, DeepSeek, Gemini, Groq), integración de Azure OpenAI y opciones de personalización.
