Implementa e configura l'editor di testo intelligente basato sull'intelligenza artificiale Syncfusion .NET MAUI (SfSmartTextEditor). Da utilizzare quando si lavora con SfSmartTextEditor, input di testo basato sull'intelligenza artificiale, suggerimenti di testo predittivi, suggerimenti in linea o popup o configurazioni UserRole/UserPhrases. Copre le modalità di visualizzazione dei suggerimenti, i servizi di intelligenza artificiale personalizzati (Claude, DeepSeek, Gemini, Groq), l'integrazione di Azure OpenAI e le opzioni di personalizzazione.
