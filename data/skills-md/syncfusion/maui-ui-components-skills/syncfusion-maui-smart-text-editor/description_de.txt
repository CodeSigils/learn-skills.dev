Implementiert und konfiguriert den Syncfusion .NET MAUI AI-Powered Smart Text Editor (SfSmartTextEditor). Verwendung bei der Arbeit mit SfSmartTextEditor, KI-gestützter Texteingabe, prädiktiven Textvorschlägen, Inline- oder Popup-Vorschlägen oder UserRole/UserPhrases-Konfigurationen. Behandelt Anzeigemodi für Vorschläge, benutzerdefinierte KI-Dienste (Claude, DeepSeek, Gemini, Groq), Azure OpenAI-Integration und Anpassungsoptionen.
