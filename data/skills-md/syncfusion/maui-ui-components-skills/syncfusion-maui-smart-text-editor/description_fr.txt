Implémente et configure l'éditeur de texte intelligent alimenté par l'IA Syncfusion .NET MAUI (SfSmartTextEditor). À utiliser lorsque vous travaillez avec SfSmartTextEditor, la saisie de texte basée sur l'IA, les suggestions de texte prédictives, les suggestions en ligne ou contextuelles ou les configurations UserRole/UserPhrases. Couvre les modes d’affichage des suggestions, les services d’IA personnalisés (Claude, DeepSeek, Gemini, Groq), l’intégration Azure OpenAI et les options de personnalisation.
