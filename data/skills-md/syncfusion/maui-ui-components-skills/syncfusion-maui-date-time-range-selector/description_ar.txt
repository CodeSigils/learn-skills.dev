ينفذ Syncfusion .NET MAUI DateTime Range Selector (SfDateTimeRangeSelector) لاختيار نطاق التاريخ/الوقت التفاعلي مع تكامل المخطط. يُستخدم عند العمل مع محددات النطاق، أو منتقيات النطاق الزمني، أو تحديد النطاق الزمني، أو تصفية نطاق المخطط، أو عناصر التحكم في النطاق التفاعلي. يغطي واجهة مستخدم اختيار النطاق، وتصفية بيانات المخطط حسب النطاق الزمني، واختيار الفترات الزمنية.
