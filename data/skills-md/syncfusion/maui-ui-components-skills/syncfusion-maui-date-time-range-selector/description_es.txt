Implementa Syncfusion .NET MAUI DateTime Range Selector (SfDateTimeRangeSelector) para la selección interactiva de rango de fecha/hora con integración de gráficos. Úselo cuando trabaje con selectores de rango, selectores de rango de fechas, selección de rango de tiempo, filtrado de rango de gráficos o controles de rango interactivos. Cubre la interfaz de usuario de selección de rango, el filtrado de datos del gráfico por rango de fechas y la selección de períodos de tiempo.
