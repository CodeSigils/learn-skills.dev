Implémente le contrôle Syncfusion .NET MAUI Maps (SfMaps). À utiliser lors de la mise en œuvre de cartes, de la visualisation de données géographiques ou de l'affichage de couches de formes et de couches de tuiles (OpenStreetMap, Azure Maps, Google Maps, Bing Maps). Couvre les marqueurs, les bulles, les légendes, les étiquettes de données, les info-bulles, les sous-couches, les fonctionnalités de zoom et de panoramique ou la visualisation de données spatiales dans les applications .NET MAUI.
