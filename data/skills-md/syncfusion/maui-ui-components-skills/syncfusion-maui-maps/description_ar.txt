يطبق التحكم في خرائط Syncfusion .NET MAUI (SfMaps). يُستخدم عند تنفيذ الخرائط، أو تصور البيانات الجغرافية، أو عرض طبقات الأشكال وطبقات التجانب (OpenStreetMap، وخرائط Azure، وخرائط Google، وخرائط Bing). يغطي العلامات والفقاعات ووسائل الإيضاح وتسميات البيانات وتلميحات الأدوات والطبقات الفرعية وميزات التكبير/التصغير والتحريك أو تصور البيانات المكانية في تطبيقات .NET MAUI.
