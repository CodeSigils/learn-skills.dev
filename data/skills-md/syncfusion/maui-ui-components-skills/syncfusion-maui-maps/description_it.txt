Implementa il controllo Syncfusion .NET MAUI Maps (SfMaps). Da utilizzare durante l'implementazione di mappe, la visualizzazione di dati geografici o la visualizzazione di layer di forma e layer di riquadro (OpenStreetMap, mappe di Azure, Google Maps, Bing Maps). Copre marcatori, bolle, legende, etichette dati, descrizioni comandi, sottolivelli, funzionalità di zoom e panoramica o visualizzazione di dati spaziali nelle applicazioni .NET MAUI.
