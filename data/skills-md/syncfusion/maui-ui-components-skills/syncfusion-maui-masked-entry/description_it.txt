Implementa il controllo Syncfusion .NET MAUI Masked Entry (SfMaskedEntry) per l'input di testo formattato e limitato con modelli di maschera. Da utilizzare quando si lavora con input mascherato, maschere di testo, voce formattata, input di numero di telefono, input di data con formato o convalida con maschere. Copre maschere semplici, maschere RegEx, caratteri prompt e formattazione automatica con convalida.
