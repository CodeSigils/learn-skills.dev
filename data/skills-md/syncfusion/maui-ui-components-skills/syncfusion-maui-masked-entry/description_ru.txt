Реализует элемент управления Syncfusion .NET MAUI Masked Entry (SfMaskedEntry) для ограниченного ввода форматированного текста с шаблонами маски. Используйте при работе с вводом по маске, текстовыми масками, форматированной записью, вводом номера телефона, вводом даты в формате или проверкой с помощью масок. Охватывает простые маски, маски RegEx, символы подсказок и автоматическое форматирование с проверкой.
