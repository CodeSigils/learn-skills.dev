Implementa il layout di input testo Syncfusion .NET MAUI (SfTextInputLayout). Da utilizzare quando si aggiungono elementi decorativi come etichette mobili, icone, etichette assistive o contenitori ai controlli Entry, Editor, Completamento automatico o ComboBox. Riguarda la configurazione del layout di input del testo, le etichette dei suggerimenti, il testo di supporto, i messaggi di errore, il contatore dei caratteri e l'attivazione/disattivazione della visibilità della password.
