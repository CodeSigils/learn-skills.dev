ينفذ Syncfusion .NET MAUI تخطيط إدخال النص (SfTextInputLayout). يُستخدم عند إضافة عناصر زخرفية مثل التسميات العائمة أو الأيقونات أو التسميات المساعدة أو الحاويات إلى عناصر تحكم الإدخال أو المحرر أو الإكمال التلقائي أو ComboBox. يغطي إعداد تخطيط إدخال النص، وتسميات التلميحات، والنص المساعد، ورسائل الخطأ، وعداد الأحرف، وتبديل رؤية كلمة المرور.
