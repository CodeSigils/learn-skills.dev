Verwenden Sie diesen Skill für WPF-Anwendungen, die eine Excel-ähnliche Benutzeroberfläche mit der Syncfusion-Tabellenkalkulationskomponente benötigen. Auslöser zum Erstellen, Anzeigen und Bearbeiten von Excel-Dateien (.xlsx, .xls); Verwenden von Formeln, Filtern, Sortieren oder Zellenformatieren. Wird auch ausgelöst, wenn Benutzer auf Tabellenkalkulationsdateien verweisen („XLSX öffnen“, „Excel-Datei laden“, „Syncfusion-Tabelle hinzufügen“). Lösen Sie KEINE eigenständige Dateiverarbeitung ohne UI-Komponenten aus.
