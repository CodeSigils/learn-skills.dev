استخدم هذه المهارة لتطبيقات Vue التي تحتاج إلى واجهة مستخدم تشبه Excel باستخدام مكون جدول بيانات Syncfusion. مشغل لإنشاء ملفات Excel (.xlsx و.xls و.xlsb) وملفات CSV وعرضها وتحريرها؛ تضمين محرري جداول البيانات؛ ربط البيانات من واجهات برمجة التطبيقات/JSON؛ باستخدام الصيغ أو المخططات أو التحقق من الصحة أو التصفية أو التنسيق الشرطي. يتم تشغيله أيضًا عندما يشير المستخدمون إلى ملفات جداول البيانات ("فتح xlsx"، "تحميل ملف Excel"، "إضافة جدول بيانات Syncfusion"، "ربط البيانات بجدول بيانات"). لا تقم بتشغيل معالجة الملفات المستقلة بدون مكونات واجهة المستخدم.
