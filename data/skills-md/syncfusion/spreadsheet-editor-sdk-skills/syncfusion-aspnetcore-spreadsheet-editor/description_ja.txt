このスキルは、Syncfusion スプレッドシート コンポーネントを使用して Excel のような UI を必要とする ASP.NET Core アプリに使用します。 Excel (.xlsx、.xls、.xlsb) および CSV ファイルの作成、表示、編集のトリガー。スプレッドシートエディタの埋め込み。 API/JSON からのデータ バインディング。数式、グラフ、検証、フィルタリング、または条件付き書式設定を使用します。ユーザーがスプレッドシート ファイルを参照するときにもトリガーされます (「xlsx を開く」、「Excel ファイルをロードする」、「Syncfusion スプレッドシートを追加する」、「データをスプレッドシートにバインドする」)。 UI コンポーネントを使用しないスタンドアロン ファイル処理をトリガーしないでください。
