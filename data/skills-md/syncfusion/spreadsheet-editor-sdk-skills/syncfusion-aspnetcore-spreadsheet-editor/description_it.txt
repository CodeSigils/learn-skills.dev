Usare questa competenza per le app ASP.NET Core che necessitano di un'interfaccia utente simile a Excel usando il componente foglio di calcolo Syncfusion. Trigger per creare, visualizzare, modificare file Excel (.xlsx, .xls, .xlsb) e CSV; incorporare editor di fogli di calcolo; associazione dati da API/JSON; utilizzando formule, grafici, convalida, filtraggio o formattazione condizionale. Si attiva anche quando gli utenti fanno riferimento a file di fogli di calcolo ("apri xlsx", "carica file Excel", "aggiungi foglio di calcolo Syncfusion", "associa dati a foglio di calcolo"). NON attivare l'elaborazione di file autonoma senza componenti dell'interfaccia utente.
