Utilisez cette compétence pour les applications JavaScript nécessitant une interface utilisateur de type Excel à l'aide du composant de feuille de calcul Syncfusion. Déclencheur pour créer, visualiser, éditer des fichiers Excel (.xlsx, .xls, .xlsb) et CSV ; intégration d'éditeurs de feuilles de calcul ; liaison de données à partir d'API/JSON ; à l'aide de formules, de graphiques, de validation, de filtrage ou de mise en forme conditionnelle. Se déclenche également lorsque les utilisateurs référencent des fichiers de feuille de calcul (« ouvrir xlsx », « charger un fichier Excel », « ajouter une feuille de calcul Syncfusion », « lier des données à une feuille de calcul »). Ne déclenchez PAS le traitement de fichiers autonome sans composants d’interface utilisateur.
