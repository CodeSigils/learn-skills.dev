Verwenden Sie diesen Skill für JavaScript-Apps, die eine Excel-ähnliche Benutzeroberfläche benötigen, unter Verwendung der Syncfusion-Tabellenkalkulationskomponente. Auslöser zum Erstellen, Anzeigen und Bearbeiten von Excel- (.xlsx, .xls, .xlsb) und CSV-Dateien; Einbetten von Tabellenkalkulationseditoren; Datenbindung von APIs/JSON; mithilfe von Formeln, Diagrammen, Validierung, Filterung oder bedingter Formatierung. Wird auch ausgelöst, wenn Benutzer auf Tabellenkalkulationsdateien verweisen („XLSX öffnen“, „Excel-Datei laden“, „Syncfusion-Tabelle hinzufügen“, „Daten an Tabellenkalkulation binden“). Lösen Sie KEINE eigenständige Dateiverarbeitung ohne UI-Komponenten aus.
