Utilisez cette compétence pour les applications Windows Forms nécessitant une interface utilisateur de type Excel à l'aide du composant de feuille de calcul Syncfusion. Déclencheur pour créer, visualiser, éditer des fichiers Excel (.xlsx, .xls) ; à l'aide de formules, de filtrage, de tri ou de formatage de cellule. Se déclenche également lorsque les utilisateurs référencent des fichiers de feuille de calcul (« ouvrir xlsx », « charger un fichier Excel », « ajouter une feuille de calcul Syncfusion »). Ne déclenchez PAS le traitement de fichiers autonome sans composants d’interface utilisateur.
