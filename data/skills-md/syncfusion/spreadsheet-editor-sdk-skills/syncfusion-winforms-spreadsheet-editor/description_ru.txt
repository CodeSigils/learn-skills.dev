Используйте этот навык для приложения Windows Forms, которому требуется пользовательский интерфейс, подобный Excel, с использованием компонента электронной таблицы Syncfusion. Триггер для создания, просмотра, редактирования файлов Excel (.xlsx, .xls); использование формул, фильтрации, сортировки или форматирования ячеек. Также срабатывает, когда пользователи ссылаются на файлы электронных таблиц («открыть xlsx», «загрузить файл Excel», «добавить электронную таблицу Syncfusion»). НЕ запускайте автономную обработку файлов без компонентов пользовательского интерфейса.
