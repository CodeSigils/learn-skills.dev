Utilizza questa competenza per l'applicazione Windows Form che richiede un'interfaccia utente simile a Excel utilizzando il componente Foglio di calcolo Syncfusion. Trigger per creare, visualizzare, modificare file Excel (.xlsx, .xls); utilizzando formule, filtraggi, ordinamenti o formattazione delle celle. Si attiva anche quando gli utenti fanno riferimento a file di fogli di calcolo ("apri xlsx", "carica file Excel", "aggiungi foglio di calcolo Syncfusion"). NON attivare l'elaborazione di file autonoma senza componenti dell'interfaccia utente.
