Используйте этот навык для приложений Angular, которым требуется пользовательский интерфейс, подобный Excel, с использованием компонента электронных таблиц Syncfusion. Триггер для создания, просмотра, редактирования файлов Excel (.xlsx, .xls, .xlsb) и CSV; встраивание редакторов электронных таблиц; привязка данных из API/JSON; использование формул, диаграмм, проверки, фильтрации или условного форматирования. Также срабатывает, когда пользователи ссылаются на файлы электронных таблиц («открыть xlsx», «загрузить файл Excel», «добавить электронную таблицу Syncfusion», «привязать данные к электронной таблице»). НЕ запускайте автономную обработку файлов без компонентов пользовательского интерфейса.
