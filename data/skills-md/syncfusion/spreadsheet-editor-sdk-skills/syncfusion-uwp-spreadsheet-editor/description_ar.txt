استخدم هذه المهارة لتطبيق UWP الذي يحتاج إلى واجهة مستخدم تشبه Excel باستخدام مكون جدول بيانات Syncfusion. مشغل لإنشاء ملفات Excel (.xlsx، .xls) وعرضها وتحريرها؛ باستخدام الصيغ أو التصفية أو الفرز أو تنسيق الخلايا. يتم تشغيله أيضًا عندما يشير المستخدمون إلى ملفات جدول البيانات ("فتح xlsx"، "تحميل ملف Excel"، "إضافة جدول بيانات Syncfusion"). لا تقم بتشغيل معالجة الملفات المستقلة بدون مكونات واجهة المستخدم.
