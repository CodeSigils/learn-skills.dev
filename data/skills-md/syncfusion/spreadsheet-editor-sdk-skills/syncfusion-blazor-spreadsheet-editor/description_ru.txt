Используйте этот навык для приложений Blazor, которым требуется пользовательский интерфейс, подобный Excel, с использованием компонента электронных таблиц Syncfusion. Триггер для создания, просмотра, редактирования файлов Excel (.xlsx, .xls); встраивание редакторов электронных таблиц; использование формул, фильтрации, сортировки или форматирования ячеек. Также срабатывает, когда пользователи ссылаются на файлы электронных таблиц («открыть xlsx», «загрузить файл Excel», «добавить электронную таблицу Syncfusion»). НЕ запускайте автономную обработку файлов без компонентов пользовательского интерфейса.
