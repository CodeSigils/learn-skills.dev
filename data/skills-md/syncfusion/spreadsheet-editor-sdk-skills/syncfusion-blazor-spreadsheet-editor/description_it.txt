Usare questa competenza per le app Blazer che necessitano di un'interfaccia utente simile a Excel usando il componente foglio di calcolo Syncfusion. Trigger per creare, visualizzare, modificare file Excel (.xlsx, .xls); incorporare editor di fogli di calcolo; utilizzando formule, filtraggi, ordinamenti o formattazione delle celle. Si attiva anche quando gli utenti fanno riferimento a file di fogli di calcolo ("apri xlsx", "carica file Excel", "aggiungi foglio di calcolo Syncfusion"). NON attivare l'elaborazione di file autonoma senza componenti dell'interfaccia utente.
