Utilice esta habilidad para aplicaciones Blazor que necesitan una interfaz de usuario similar a Excel utilizando el componente de hoja de cálculo Syncfusion. Activador para crear, ver y editar archivos de Excel (.xlsx, .xls); incorporar editores de hojas de cálculo; usando fórmulas, filtrado, clasificación o formato de celdas. También se activa cuando los usuarios hacen referencia a archivos de hojas de cálculo ("abrir xlsx", "cargar archivo de Excel", "agregar hoja de cálculo de Syncfusion"). NO active el procesamiento de archivos independiente sin componentes de la interfaz de usuario.
