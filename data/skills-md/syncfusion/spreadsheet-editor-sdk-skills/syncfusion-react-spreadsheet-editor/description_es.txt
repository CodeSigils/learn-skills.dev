Utilice esta habilidad para aplicaciones React que necesitan una interfaz de usuario similar a Excel usando el componente de hoja de cálculo Syncfusion. Activador para crear, ver y editar archivos Excel (.xlsx, .xls, .xlsb) y CSV; incorporar editores de hojas de cálculo; enlace de datos desde API/JSON; utilizando fórmulas, gráficos, validación, filtrado o formato condicional. También se activa cuando los usuarios hacen referencia a archivos de hojas de cálculo ("abrir xlsx", "cargar archivo de Excel", "agregar hoja de cálculo de Syncfusion", "vincular datos a la hoja de cálculo"). NO active el procesamiento de archivos independiente sin componentes de la interfaz de usuario.
