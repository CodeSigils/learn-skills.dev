Implementiert Syncfusion ASP.NET Core TreeGrid für hierarchische Daten mit Sortieren, Filtern, Bearbeiten, Exportieren, Paging, virtuellem Scrollen und erweiterten Funktionen. Unterstützt Konfiguration, CRUD, Aggregate, Vorlagen, Zustandspersistenz und Leistungsoptimierung in ASP.NET Core-Anwendungen.
