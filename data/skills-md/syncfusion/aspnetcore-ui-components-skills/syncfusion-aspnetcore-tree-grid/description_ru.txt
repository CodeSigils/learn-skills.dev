Реализует Syncfusion ASP.NET Core TreeGrid для иерархических данных с сортировкой, фильтрацией, редактированием, экспортом, разбиением на страницы, виртуальной прокруткой и расширенными функциями. Поддерживает конфигурацию, CRUD, агрегаты, шаблоны, сохранение состояния и оптимизацию производительности в приложениях ASP.NET Core.
