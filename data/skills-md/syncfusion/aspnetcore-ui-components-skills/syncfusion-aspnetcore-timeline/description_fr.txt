Affichez les séquences temporelles avec le composant Syncfusion Timeline. Prend en charge les orientations verticales/horizontales, l'alignement flexible des éléments (avant/après/alternatif), des modèles riches pour le contenu et les points, les stratégies de positionnement du contenu et la gestion complète des événements pour le cycle de vie du rendu des éléments. Indispensable pour la visualisation chronologique dans les applications ASP.NET Core.
