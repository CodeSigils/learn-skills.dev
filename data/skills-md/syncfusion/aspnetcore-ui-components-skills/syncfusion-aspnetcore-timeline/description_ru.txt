Отображение временных последовательностей с помощью компонента Syncfusion Timeline. Поддерживает вертикальную/горизонтальную ориентацию, гибкое выравнивание элементов (До/После/Альтернативно), богатые шаблоны для контента и точек, стратегии позиционирования контента и комплексную обработку событий для жизненного цикла рендеринга элементов. Необходим для хронологической визуализации в приложениях ASP.NET Core.
