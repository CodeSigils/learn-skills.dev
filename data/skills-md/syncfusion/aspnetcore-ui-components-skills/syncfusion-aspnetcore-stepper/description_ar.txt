قم بإنشاء وتكوين عناصر تحكم ASP.NET Core Stepper لدعم سير العمل متعدد الخطوات وواجهات المستخدم التقدمية. يجب تطبيق هذه المهارة عند تنفيذ التنقل بين الخطوات، أو المعالجات، أو متتبعات التقدم، أو تدفقات النماذج، أو عمليات الخروج، أو أي واجهة مستخدم تسلسلية قائمة على الخطوات. كما أنها ذات صلة عندما تتضمن المتطلبات أجهزة السائر، أو التحقق من صحة الخطوات، أو التنقل بين الخطوات، أو التدفقات الخطية، أو إدارة الحالة القائمة على الخطوات.
