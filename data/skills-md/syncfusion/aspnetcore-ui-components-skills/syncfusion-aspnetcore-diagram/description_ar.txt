قم بتنفيذ مكون Syncfusion ASP.NET Core Diagram (EJ2 Tag Helper `ejs-diagram`) لإنشاء مخططات تفاعلية في Razor Pages أو تطبيقات MVC. استخدم هذه المهارة عند العمل مع المخططات التنظيمية، أو المخططات الانسيابية، أو مخططات عملية BPMN، أو مخططات UML، أو مخططات المسار. تغطي هذه المهارة تكوين العقدة والموصل، وخيارات التخطيط، وتصميم الشكل، وربط البيانات، وأدوات الرسم، ووظيفة التصدير/الطباعة، وميزات الرسم التخطيطي الأخرى.
