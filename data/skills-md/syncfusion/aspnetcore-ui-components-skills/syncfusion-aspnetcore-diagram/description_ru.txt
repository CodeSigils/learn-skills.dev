Внедрите компонент Syncfusion ASP.NET Core Diagram (помощник тега EJ2 `ejs-diagram`) для создания интерактивных диаграмм в Razor Pages или приложениях MVC. Используйте этот навык при работе с организационными диаграммами, блок-схемами, диаграммами процессов BPMN, диаграммами UML или диаграммами «дорожки». Этот навык охватывает настройку узлов и соединителей, параметры макета, стили фигур, привязку данных, инструменты рисования, функции экспорта/печати и другие функции диаграмм.
