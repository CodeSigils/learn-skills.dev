قم بتنفيذ Syncfusion RangeNavigator (Range Selector) في تطبيقات ASP.NET Core لتحديد نطاق البيانات التفاعلي والتنقل فيه. استخدم هذه المهارة عندما يحتاج المستخدم إلى تحديد نطاقات البيانات، أو تصور بيانات السلاسل الزمنية باستخدام أشرطة التمرير التفاعلية، أو إضافة محددات الفترة، أو تخصيص مظهر النطاق، أو تصدير تصورات النطاق، أو دمج تحديد النطاق في لوحات المعلومات والمخططات.
