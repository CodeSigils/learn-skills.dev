Внедрите Syncfusion RangeNavigator (выбор диапазона) в приложениях ASP.NET Core для интерактивного выбора диапазона данных и навигации. Используйте этот навык, когда пользователю необходимо выбрать диапазоны данных, визуализировать данные временных рядов с помощью интерактивных ползунков, добавить селекторы периодов, настроить внешний вид диапазона, экспортировать визуализации диапазонов или интегрировать выбор диапазона в информационные панели и диаграммы.
