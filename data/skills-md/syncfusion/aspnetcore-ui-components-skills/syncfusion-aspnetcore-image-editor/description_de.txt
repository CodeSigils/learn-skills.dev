Implementieren Sie die Syncfusion ASP.NET Core Image Editor (EJ2)-Komponente. Verwenden Sie dies, wenn Sie einer ASP.NET Core-Anwendung Bildbearbeitung hinzufügen, einschließlich Zuschneiden, Drehen, Anmerkungen, Feinabstimmung (Helligkeit, Kontrast, Unschärfe) und Filteranwendung. Behandelt das Öffnen/Speichern von Bildern, die Anpassung der Symbolleiste, das Schwärzen, die Größenänderung und die Verarbeitung von Bildeditor-Ereignissen mit ejs-imageeditor.
