Implemente el componente Syncfusion ASP.NET Core Image Editor (EJ2). Utilícelo cuando agregue edición de imágenes a una aplicación ASP.NET Core, incluido el recorte, la rotación, las anotaciones, el ajuste fino (brillo, contraste, desenfoque) y la aplicación de filtros. Cubre la apertura/guardado de imágenes, la personalización de la barra de herramientas, la redacción, el cambio de tamaño y el manejo de eventos del editor de imágenes con ejs-imageeditor.
