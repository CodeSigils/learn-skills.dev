قم بتنفيذ مكون Syncfusion ASP.NET Core Image Editor (EJ2). استخدم هذا عند إضافة تحرير الصور إلى تطبيق ASP.NET Core، بما في ذلك الاقتصاص والتدوير والتعليقات التوضيحية والضبط الدقيق (السطوع والتباين والتمويه) وتطبيق التصفية. يغطي فتح/حفظ الصور، وتخصيص شريط الأدوات، والتنقيح، وتغيير الحجم، ومعالجة أحداث محرر الصور باستخدام ejs-imageeditor.
