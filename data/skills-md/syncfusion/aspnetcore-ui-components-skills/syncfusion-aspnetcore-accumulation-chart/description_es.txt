Implemente gráficos de acumulación de Syncfusion ASP.NET Core para visualización de datos proporcionales. Úselo al crear gráficos circulares, gráficos de anillos, gráficos piramidales o gráficos de embudo en aplicaciones ASP.NET Core. Esta habilidad cubre la configuración de gráficos, enlace de datos, leyendas, información sobre herramientas, etiquetas de datos, agrupación y funciones de accesibilidad. Adecuado para visualizar participación de mercado, distribución de ventas, resultados de encuestas y otras representaciones de datos basados ​​en porcentajes.
