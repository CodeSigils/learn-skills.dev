Implémentez les graphiques d’accumulation Syncfusion ASP.NET Core pour une visualisation proportionnelle des données. Utilisez-le lors de la création de diagrammes circulaires, de diagrammes en anneau, de diagrammes pyramidaux ou de diagrammes en entonnoir dans les applications ASP.NET Core. Cette compétence couvre la configuration des graphiques, la liaison des données, les légendes, les info-bulles, les étiquettes de données, le regroupement et les fonctionnalités d'accessibilité. Convient pour visualiser la part de marché, la répartition des ventes, les résultats d'enquêtes et d'autres représentations de données basées sur un pourcentage.
