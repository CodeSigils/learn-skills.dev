Внедрите диаграммы накопления Syncfusion ASP.NET Core для пропорциональной визуализации данных. Используйте это при создании круговых диаграмм, кольцевых диаграмм, пирамидальных диаграмм или воронкообразных диаграмм в приложениях ASP.NET Core. Этот навык охватывает настройку диаграмм, привязку данных, легенды, всплывающие подсказки, метки данных, группировку и функции специальных возможностей. Подходит для визуализации доли рынка, распределения продаж, результатов опросов и других представлений данных в процентах.
