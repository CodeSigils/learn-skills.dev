Implementieren Sie Syncfusion ASP.NET Core Accumulation Charts für die proportionale Datenvisualisierung. Verwenden Sie dies beim Erstellen von Kreisdiagrammen, Ringdiagrammen, Pyramidendiagrammen oder Trichterdiagrammen in ASP.NET Core-Anwendungen. Diese Fertigkeit umfasst Diagrammeinrichtung, Datenbindung, Legenden, Tooltips, Datenbeschriftungen, Gruppierung und Barrierefreiheitsfunktionen. Geeignet zur Visualisierung von Marktanteilen, Umsatzverteilung, Umfrageergebnissen und anderen prozentualen Datendarstellungen.
