**دليل السمات والمظهر** — المساعدة في تخصيص سمات مكونات Syncfusion ASP.NET Core EJ2، والتخصيص، وأوضاع الحجم، والتبديل الديناميكي للموضوعات. يُستخدم عندما: تطبيق السمات (Bootstrap، وMaterial، وTailwind، وFluent، وما إلى ذلك)، أو تخصيص متغيرات السمات، أو تنفيذ مبدلات السمات، أو تمكين وضع اللمس، أو تخصيص الرموز والمظهر.
