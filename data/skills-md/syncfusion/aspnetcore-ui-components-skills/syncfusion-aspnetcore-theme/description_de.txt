**THEMING- UND ERSCHEINUNGSANLEITUNG** – Unterstützung bei der Themengestaltung, Anpassung, Größenmodi und dynamischen Themenumschaltung von Syncfusion ASP.NET Core EJ2-Komponenten. Verwendung bei: Anwenden von Themen (Bootstrap, Material, Tailwind, Fluent usw.), Anpassen von Themenvariablen, Implementieren von Themenwechslern, Aktivieren des Touch-Modus oder Anpassen von Symbolen und Erscheinungsbild.
