تنفيذ مكون Syncfusion ASP.NET Core Gantt Chart (EJ2) لإدارة المشاريع وجدولة المهام. استخدم هذا عند العمل مع مخططات جانت، أو المخططات الزمنية للمشروع، أو تبعيات المهام، أو تخصيص الموارد في تطبيقات ASP.NET Core (Tag Helper/Razor Pages/MVC). تغطي هذه المهارة ربط البيانات وإدارة المهام والتحرير والتصفية والتصدير وتخصيص الجدول الزمني.
