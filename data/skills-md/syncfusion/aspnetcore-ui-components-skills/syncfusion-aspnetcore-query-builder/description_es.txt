Guía completa para implementar el componente Syncfusion QueryBuilder en aplicaciones ASP.NET Core. Utilícelo cuando trabaje con creadores de filtros/consultas visuales, interfaz de usuario de filtrado basada en reglas, generación de consultas SQL/JSON/MongoDB, reordenamiento de reglas de arrastrar y soltar o importación/exportación de condiciones de filtro utilizando Syncfusion EJ2 TagHelpers.
