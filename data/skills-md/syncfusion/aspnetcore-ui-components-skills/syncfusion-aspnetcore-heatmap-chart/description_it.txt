Implementazione del componente grafico Syncfusion HeatMap per ASP.NET Core Razor Pages. Utilizza SEMPRE questa competenza quando l'utente deve creare mappe di calore per visualizzare dati bidimensionali, personalizzare celle con gradienti o colori fissi, configurare assi con più tipi, aggiungere legende con posizionamento flessibile, associare array o dati JSON, abilitare descrizioni comandi e selezione di celle, creare mappe di calore a bolle o personalizzare aspetto e stile. Essenziale per i casi d'uso di visualizzazione dei dati, rilevamento di modelli e visualizzazione di matrici.
