تنفيذ مكون مخطط Syncfusion HeatMap لصفحات ASP.NET Core Razor. استخدم هذه المهارة دائمًا عندما يحتاج المستخدم إلى إنشاء خرائط حرارية لتصور البيانات ثنائية الأبعاد، أو تخصيص الخلايا بالتدرجات أو الألوان الثابتة، أو تكوين محاور بأنواع متعددة، أو إضافة وسائل إيضاح بموضع مرن، أو ربط المصفوفة أو بيانات JSON، أو تمكين تلميحات الأدوات واختيار الخلايا، أو إنشاء خرائط حرارية فقاعية، أو تخصيص المظهر والتصميم. ضروري لتصور البيانات، واكتشاف الأنماط، وحالات استخدام تصور المصفوفة.
