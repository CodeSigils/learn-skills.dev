Implementación del componente Syncfusion HeatMap Chart para ASP.NET Core Razor Pages. Utilice esta habilidad SIEMPRE cuando el usuario necesite crear mapas de calor para visualizar datos bidimensionales, personalizar celdas con degradados o colores fijos, configurar ejes con múltiples tipos, agregar leyendas con posicionamiento flexible, vincular matrices o datos JSON, habilitar información sobre herramientas y selección de celdas, crear mapas de calor de burbujas o personalizar la apariencia y el estilo. Esencial para casos de uso de visualización de datos, detección de patrones y visualización de matrices.
