قم بتطبيق مكون الإعلام Syncfusion ASP.NET Core Toast لعرض الرسائل المختصرة والتنبيهات والإشعارات. استخدم هذه المهارة عند إنشاء إشعارات الخبز المحمص، أو رسائل التنبيه، أو لافتات النجاح/الخطأ/التحذير/المعلومات، أو إشعارات التقدم، أو نوافذ الإشعارات المنبثقة، أو رسائل الفصل المحددة بوقت، أو أي واجهة مستخدم للإشعارات على الشاشة في ASP.NET Core (EJ2 Tag Helper / Razor). تشغيل الكلمات الرئيسية مثل الخبز المحمص والإشعارات ونافذة التنبيه المنبثقة وشريط الوجبات الخفيفة والرسالة المختصرة ورفض الرسالة ونخب التقدم وأزرار الإجراءات نخب.
