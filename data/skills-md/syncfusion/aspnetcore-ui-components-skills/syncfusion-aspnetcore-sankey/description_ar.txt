أنشئ تصورات تفاعلية لمخطط Sankey Chart توضح التدفقات المرجحة والعلاقات بين الفئات باستخدام العقد والروابط. استخدم هذه المهارة عندما يذكر المستخدم مخططات Sankey، أو تصور التدفق، أو تدفقات العمليات، أو تدفقات القيمة بين الفئات، أو تصميم العقدة والارتباط، أو يريد إنشاء مخططات تعرض حجم واتجاه التدفقات عبر المراحل أو الأنظمة. يعد مخطط Sankey مثاليًا لتصور سلاسل التوريد وتدفقات الطاقة وتدفقات الإيرادات ورحلات العملاء وتحويلات البيانات.
