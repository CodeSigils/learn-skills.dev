قم بتنفيذ مكونات Syncfusion ASP.NET Core Barcode بما في ذلك BarcodeGenerator (رموز 1D مثل Code39 وCode128 وCodabar) وQR Code Generator وDataMatrix Generator. استخدم هذا عند عرض الرموز الشريطية، أو تنفيذ رموز QR مع تضمين الشعار، أو إنشاء رموز DataMatrix. تغطي هذه المهارة اختيار نوع الرمز الشريطي، وتخصيص اللون والأبعاد، وتكوين نص العرض، ووظيفة التصدير (JPG، PNG، Base64).
