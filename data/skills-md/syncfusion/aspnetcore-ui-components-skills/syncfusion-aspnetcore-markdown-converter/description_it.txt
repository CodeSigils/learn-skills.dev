Guida l'implementazione del convertitore Markdown Syncfusion ASP.NET Core (Syncfusion.EJ2 NuGet). Usare questa competenza quando l'utente deve convertire il testo Markdown in HTML, usare il metodo MarkdownConverter toHtml, configurare MarkdownConverterOptions (async, gfm, lineBreak, silenzio) o integrare Markdown Converter con l'helper tag Syncfusion Rich Text Editor per l'anteprima live o la modifica affiancata nei progetti ASP.NET Core MVC o Razor Pages. Si attiva quando l'utente menziona il markdown in conversione HTML, MarkdownConverter, toHtml, ej2-markdown-converter, anteprima markdown o modalità markdown RTE.
