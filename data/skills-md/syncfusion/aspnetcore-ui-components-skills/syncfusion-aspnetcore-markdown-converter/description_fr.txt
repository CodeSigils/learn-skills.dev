Guide la mise en œuvre du convertisseur Syncfusion ASP.NET Core Markdown (Syncfusion.EJ2 NuGet). Utilisez cette compétence lorsque l'utilisateur a besoin de convertir du texte Markdown en HTML, d'utiliser la méthode MarkdownConverter toHtml, de configurer MarkdownConverterOptions (async, gfm, lineBreak, silence) ou d'intégrer le convertisseur Markdown avec l'assistant de balise Syncfusion Rich Text Editor pour un aperçu en direct ou une édition côte à côte dans les projets ASP.NET Core MVC ou Razor Pages. Déclenchez lorsque l'utilisateur mentionne la conversion de démarque en HTML, MarkdownConverter, toHtml, ej2-markdown-converter, l'aperçu de démarque ou le mode de démarque RTE.
