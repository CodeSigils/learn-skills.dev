Guía la implementación de Syncfusion ASP.NET Core Markdown Converter (Syncfusion.EJ2 NuGet). Utilice esta habilidad cuando el usuario necesite convertir texto de Markdown a HTML, usar el método MarkdownConverter toHtml, configurar MarkdownConverterOptions (async, gfm, lineBreak, silencio) o integrar Markdown Converter con el asistente de etiquetas Syncfusion Rich Text Editor para obtener una vista previa en vivo o edición en paralelo en proyectos ASP.NET Core MVC o Razor Pages. Se activa cuando el usuario menciona conversión de rebajas a HTML, MarkdownConverter, toHtml, ej2-markdown-converter, vista previa de rebajas o modo de rebajas RTE.
