Leitet die Implementierung des Syncfusion ASP.NET Core Markdown Converter (Syncfusion.EJ2 NuGet) an. Verwenden Sie diese Fähigkeit, wenn der Benutzer Markdown-Text in HTML konvertieren, die MarkdownConverter toHtml-Methode verwenden, MarkdownConverterOptions (async, gfm, lineBreak, silence) konfigurieren oder den Markdown Converter mit dem Syncfusion Rich Text Editor-Tag-Hilfsprogramm für die Live-Vorschau oder die parallele Bearbeitung in ASP.NET Core MVC- oder Razor Pages-Projekten integrieren muss. Wird ausgelöst, wenn der Benutzer die Markdown-zu-HTML-Konvertierung, MarkdownConverter, toHtml, ej2-markdown-converter, Markdown-Vorschau oder RTE-Markdown-Modus erwähnt.
