يوجه تنفيذ محول Syncfusion ASP.NET Core Markdown (Syncfusion.EJ2 NuGet). استخدم هذه المهارة عندما يحتاج المستخدم إلى تحويل نص Markdown إلى HTML، أو استخدم طريقة MarkdownConverter toHtml، أو تكوين MarkdownConverterOptions (async، gfm، lineBreak، Silence)، أو دمج Markdown Converter مع مساعد علامة Syncfusion Rich Text Editor للمعاينة المباشرة أو التحرير جنبًا إلى جنب في مشاريع ASP.NET Core MVC أو Razor Pages. يتم تشغيله عندما يذكر المستخدم تخفيض السعر إلى تحويل HTML، أو MarkdownConverter، أو toHtml، أو ej2-markdown-converter، أو معاينة تخفيض السعر، أو وضع تخفيض سعر RTE.
