Syncfusion ASP.NET Core Markdown Converter (Syncfusion.EJ2 NuGet) の実装をガイドします。このスキルは、ユーザーが Markdown テキストを HTML に変換する必要がある場合、MarkdownConverter toHtml メソッドを使用する場合、MarkdownConverterOptions (async、gfm、lineBreak、silence) を構成する場合、または ASP.NET Core MVC または Razor Pages プロジェクトでライブ プレビューまたは並列編集するために Markdown Converter を Syncfusion リッチ テキスト エディターのタグ ヘルパーと統合する必要がある場合に使用します。ユーザーがマークダウンから HTML への変換、MarkdownConverter、toHtml、ej2-markdown-converter、マークダウン プレビュー、または RTE マークダウン モードに言及したときにトリガーされます。
