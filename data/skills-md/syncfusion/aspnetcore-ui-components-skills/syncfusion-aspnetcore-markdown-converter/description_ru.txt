Руководствуется реализацией преобразователя уценки Syncfusion ASP.NET Core (Syncfusion.EJ2 NuGet). Используйте этот навык, когда пользователю необходимо преобразовать текст Markdown в HTML, использовать метод MarkdownConverter toHtml, настроить MarkdownConverterOptions (async, gfm, lineBreak, молчание) или интегрировать преобразователь Markdown с вспомогательным тегом редактора форматированного текста Syncfusion для предварительного просмотра в реальном времени или параллельного редактирования в проектах ASP.NET Core MVC или Razor Pages. Срабатывает, когда пользователь упоминает преобразование уценки в HTML, MarkdownConverter, toHtml, ej2-markdown-converter, предварительный просмотр уценки или режим уценки RTE.
