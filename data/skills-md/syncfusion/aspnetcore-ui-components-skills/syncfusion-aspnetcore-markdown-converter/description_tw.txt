指導 Syncfusion ASP.NET Core Markdown 轉換器 (Syncfusion.EJ2 NuGet) 的實作。當使用者需要將 Markdown 文字轉換為 HTML、使用 MarkdownConverter toHtml 方法、配置 MarkdownConverterOptions（async、gfm、lineBreak、silence）或將 Markdown Converter 與 Syncfusion Rich Text Editor 標籤幫助程式整合以在 ASP.NET Core MVC 或 Razor Pages 專案中編輯當使用者提及 Markdown 到 HTML 轉換、MarkdownConverter、toHtml、ej2-markdown-converter、Markdown 預覽或 RTE Markdown 模式時觸發。
