** دليل سياسة أمان المحتوى (CSP) ** — المساعدة في تكوين مكونات Syncfusion ASP.NET Core EJ2 للعمل مع رؤوس سياسة أمان المحتوى الصارمة (CSP). يُستخدم عندما: تنفيذ رؤوس CSP، أو إنشاء وتطبيق الحروف غير الموجودة على البرامج النصية/الأنماط المضمنة، أو تكوين قوائم الخطوط الخارجية المسموح بها، أو استكشاف أخطاء انتهاكات CSP وإصلاحها.
