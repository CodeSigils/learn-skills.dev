**GUIDA ALLA POLICY DI SICUREZZA DEI CONTENUTI (CSP)**: assistenza nella configurazione dei componenti Syncfusion ASP.NET Core EJ2 per funzionare con intestazioni CSP (Content Security Policy) rigorose. Da utilizzare quando: si implementano intestazioni CSP, si generano e si applicano nonce a script/stili incorporati, si configurano liste consentite di caratteri esterni o si risolvono problemi di violazioni CSP.
