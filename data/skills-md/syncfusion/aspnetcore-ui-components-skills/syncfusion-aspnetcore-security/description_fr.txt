**GUIDE DE POLITIQUE DE SÉCURITÉ DE CONTENU (CSP)** — Aide à la configuration des composants Syncfusion ASP.NET Core EJ2 pour qu'ils fonctionnent avec des en-têtes stricts de politique de sécurité de contenu (CSP). À utiliser dans les cas suivants : implémentation d'en-têtes CSP, génération et application de noms occasionnels à des scripts/styles en ligne, configuration de listes autorisées de polices externes ou dépannage de violations CSP.
