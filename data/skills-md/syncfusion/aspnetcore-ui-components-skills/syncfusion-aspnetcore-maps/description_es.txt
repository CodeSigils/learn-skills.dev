Implemente el componente Syncfusion Maps para ASP.NET Core para visualizar datos geográficos. Utilícelo cuando trabaje con mapas, archivos GeoJSON, visualizaciones de coropletas o visualización de datos espaciales. Esta habilidad cubre capas de mapas, marcadores, burbujas, proveedores de mapas (Bing Maps, Azure Maps, OpenStreetMap), enlace de datos, mapeo de colores e interacciones del usuario como zoom y panorámica. Adecuado para mapas mundiales, mapas de países, visualizaciones regionales y presentación de datos basados ​​en la ubicación.
