تنفيذ مكون Syncfusion Maps لـ ASP.NET Core لتصور البيانات الجغرافية. استخدم هذا عند العمل مع الخرائط أو ملفات GeoJSON أو تصورات تصحيحية أو عرض البيانات المكانية. تغطي هذه المهارة طبقات الخريطة، والعلامات، والفقاعات، وموفري الخرائط (خرائط Bing، وAzure Maps، وOpenStreetMap)، وربط البيانات، ورسم خرائط الألوان، وتفاعلات المستخدم مثل التكبير/التصغير والتحريك. مناسب لخرائط العالم وخرائط البلدان والمرئيات الإقليمية وعرض البيانات المستندة إلى الموقع.
