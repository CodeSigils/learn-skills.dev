Внедрите компонент Syncfusion Maps для ASP.NET Core для визуализации географических данных. Используйте это при работе с картами, файлами GeoJSON, картографическими визуализациями или отображением пространственных данных. Этот навык охватывает слои карты, маркеры, пузырьки, поставщиков карт (Bing Maps, Azure Maps, OpenStreetMap), привязку данных, цветовое сопоставление и взаимодействие с пользователем, такое как масштабирование и панорамирование. Подходит для карт мира, карт стран, региональных визуализаций и представления данных на основе местоположения.
