Implementa l'editor di testo ricco di Syncfusion ASP.NET Core (helper tag ejs-richtexteditor) che supporta le modalità di modifica HTML (WYSIWYG) e Markdown. Imposta editorMode='Markdown' per Markdown; l'impostazione predefinita è HTML. Usare questa competenza per la configurazione della barra degli strumenti, il caricamento di immagini, la modifica di tabelle, la modalità inline o iframe, l'integrazione dell'assistente AI, le menzioni e la convalida dei moduli con testo RTF nei progetti ASP.NET Core.
