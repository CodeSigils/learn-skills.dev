Implémente l'éditeur de texte enrichi Syncfusion ASP.NET Core (assistant de balise ejs-richtexteditor) prenant en charge les modes d'édition HTML (WYSIWYG) et Markdown. Définissez editorMode='Markdown' pour Markdown ; la valeur par défaut est HTML. Utilisez cette compétence pour la configuration de la barre d'outils, le téléchargement d'images, l'édition de tableaux, le mode en ligne ou iframe, l'intégration de l'assistant IA, les mentions et la validation de formulaires avec du texte enrichi dans les projets ASP.NET Core.
