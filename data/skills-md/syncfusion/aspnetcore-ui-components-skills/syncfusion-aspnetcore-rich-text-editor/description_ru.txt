Реализует редактор форматированного текста Syncfusion ASP.NET Core (помощник тега ejs-richtexteditor), поддерживающий режимы редактирования HTML (WYSIWYG) и Markdown. Установите editorMode='Markdown' для Markdown; по умолчанию — HTML. Используйте этот навык для настройки панели инструментов, загрузки изображений, редактирования таблиц, встроенного режима или режима iframe, интеграции AI Assistant, упоминаний и проверки форм с форматированным текстом в проектах ASP.NET Core.
