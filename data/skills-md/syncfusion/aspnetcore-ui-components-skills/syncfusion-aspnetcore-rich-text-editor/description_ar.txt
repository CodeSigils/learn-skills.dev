ينفذ محرر النصوص الغنية Syncfusion ASP.NET Core (مساعد علامة ejs-richtexteditor) الذي يدعم أوضاع تحرير HTML (WYSIWYG) وMarkdown. تعيين EditorMode='Markdown' لـ Markdown؛ الافتراضي هو HTML. استخدم هذه المهارة لتكوين شريط الأدوات، وتحميل الصور، وتحرير الجدول، والوضع المضمّن أو iframe، وتكامل مساعد الذكاء الاصطناعي، والإشارات، والتحقق من صحة النماذج باستخدام نص منسق في مشاريع ASP.NET Core.
