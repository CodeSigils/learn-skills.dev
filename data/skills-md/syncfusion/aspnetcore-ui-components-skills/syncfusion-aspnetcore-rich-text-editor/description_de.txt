Implementiert den Syncfusion ASP.NET Core-Rich-Text-Editor (ejs-richtexteditor-Tag-Helfer) und unterstützt die Bearbeitungsmodi HTML (WYSIWYG) und Markdown. Setzen Sie editorMode='Markdown' für Markdown; Standard ist HTML. Verwenden Sie diesen Skill für die Symbolleistenkonfiguration, das Hochladen von Bildern, die Tabellenbearbeitung, den Inline- oder Iframe-Modus, die Integration von KI-Assistenten, Erwähnungen und die Formularvalidierung mit Rich Text in ASP.NET Core-Projekten.
