Implementa el editor de texto enriquecido Syncfusion ASP.NET Core (ayudante de etiquetas ejs-richtexteditor) que admite modos de edición HTML (WYSIWYG) y Markdown. Establezca editorMode='Markdown' para Markdown; El valor predeterminado es HTML. Utilice esta habilidad para la configuración de la barra de herramientas, carga de imágenes, edición de tablas, modo en línea o iframe, integración del asistente de IA, menciones y validación de formularios con texto enriquecido en proyectos ASP.NET Core.
