دليل لتنفيذ Syncfusion Bullet Chart في تطبيقات ASP.NET Core. استخدم هذه المهارة عند إنشاء تصورات مقارنة للأداء، أو لوحات معلومات مؤشرات الأداء الرئيسية، أو تتبع التقدم، أو مخططات مقارنة الأهداف، أو أي سيناريو يتطلب عرض القيمة الفعلية مقابل القيمة المستهدفة. تقوم المخططات النقطية بمقارنة الأداء الفعلي مع المعايير المستهدفة بشكل فعال في تنسيق مضغوط، وهي مثالية للوحات المعلومات والملخصات التنفيذية وأنظمة مراقبة الأداء. يتم تشغيله عندما يذكر المستخدم الرسم البياني النقطي، ومقارنة الأداء، وتصور الهدف، ولوحة معلومات مؤشرات الأداء الرئيسية، وأشرطة التقدم مع الأهداف.
