Внедрите компонент Syncfusion ASP.NET Core File Manager для просмотра, управления и организации файлов. Используйте это при создании файловых браузеров, реализации файловых операций (загрузка/загрузка), настройке панелей инструментов и контекстных меню, включении перетаскивания и настройке привязки данных для файловых систем. Этот навык охватывает доступ к файлам, события с файлами, поиск и фильтрацию, а также настройку макета.
