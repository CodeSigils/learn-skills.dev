Implementieren Sie das Syncfusion ASP.NET Core SpeechToText-Steuerelement zum Konvertieren gesprochener Wörter in Text mithilfe der Web Speech API. Verwenden Sie diese Fertigkeit, wenn Sie Spracherkennung mit Razor Tag Helpern implementieren, Sprache in Text in ASP.NET Core-Anwendungen umwandeln, Mikrofoneingaben verarbeiten, Sprachereignisse verarbeiten, das Erscheinungsbild von Schaltflächen anpassen, Hörzustände verwalten oder barrierefreie sprachgesteuerte Formulare erstellen. Behandelt Einrichtung, Spracherkennungsfunktionen, Razor Tag Helper-Syntax, Ereignisse, Methoden, Globalisierung und Sicherheit.
