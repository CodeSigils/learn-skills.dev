Web Speech API を使用して話し言葉をテキストに変換するための Syncfusion ASP.NET Core SpeechToText コントロールを実装します。このスキルは、Razor タグ ヘルパーを使用した音声認識の実装、ASP.NET Core アプリケーションでの音声からテキストへの変換、マイク入力の処理、音声イベントの処理、ボタンの外観のカスタマイズ、リスニング状態の管理、またはアクセス可能な音声対応フォームの構築を行うときに使用します。セットアップ、音声認識機能、Razor タグ ヘルパーの構文、イベント、メソッド、グローバリゼーション、セキュリティについて説明します。
