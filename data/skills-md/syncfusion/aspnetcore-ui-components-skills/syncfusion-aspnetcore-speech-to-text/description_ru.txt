Реализуйте элемент управления SpeechToText Syncfusion ASP.NET Core для преобразования произнесенных слов в текст с помощью API веб-речи. Используйте этот навык при реализации распознавания речи с помощью Razor Tag Helpers, преобразовании голоса в текст в приложениях ASP.NET Core, обработке ввода с микрофона, обработке речевых событий, настройке внешнего вида кнопок, управлении состояниями прослушивания или создании доступных форм с голосовой поддержкой. Охватывает настройку, функции распознавания речи, синтаксис Razor Tag Helper, события, методы, глобализацию и безопасность.
