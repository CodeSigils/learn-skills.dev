قم بتنفيذ عنصر التحكم Syncfusion ASP.NET Core SpeechToText لتحويل الكلمات المنطوقة إلى نص باستخدام Web Speech API. استخدم هذه المهارة عند تنفيذ التعرف على الكلام باستخدام Razor Tag Helpers، أو تحويل الصوت إلى نص في تطبيقات ASP.NET Core، أو التعامل مع إدخال الميكروفون، أو معالجة أحداث الكلام، أو تخصيص مظهر الزر، أو إدارة حالات الاستماع، أو إنشاء نماذج يمكن الوصول إليها بالصوت. يغطي الإعداد وميزات التعرف على الكلام وبناء جملة Razor Tag Helper والأحداث والأساليب والعولمة والأمان.
