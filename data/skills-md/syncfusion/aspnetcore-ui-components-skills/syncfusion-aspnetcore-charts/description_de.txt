Implementiert Syncfusion ASP.NET Core Chart (SfChart) zur Datenvisualisierung. Verwenden Sie dies, wenn Sie Diagramme erstellen, Zeitreihen oder kategoriale Daten visualisieren oder Dashboards erstellen. Behandelt die Serienkonfiguration (Linie, Balken, Kreis), Achsen, Tooltips, Legenden und die Anpassung für ASP.NET Core-Anwendungen.
