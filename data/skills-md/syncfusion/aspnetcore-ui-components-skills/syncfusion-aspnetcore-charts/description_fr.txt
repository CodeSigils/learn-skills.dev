Implémente Syncfusion ASP.NET Core Chart (SfChart) pour la visualisation des données. Utilisez-le lors de la création de graphiques, de la visualisation de séries chronologiques ou de données catégorielles, ou de la création de tableaux de bord. Couvre la configuration des séries (ligne, barre, secteur), les axes, les info-bulles, les légendes et la personnalisation pour les applications ASP.NET Core.
