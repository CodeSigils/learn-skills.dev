Razor タグ ヘルパーを使用して、ASP.NET Core アプリケーションに Syncfusion ブロック エディター コントロールを実装します。このスキルは、Syncfusion Block Editor、EJ2 BlockEditor、ASP.NET Core ブロックベースのコンテンツ編集、または <ejs-blockeditor> 構文を使用するときに使用します。ブロック管理、ネストされたコンテンツ構造、ドラッグ アンド ドロップ機能、コンテンツのサニタイズ、インストール、タグ ヘルパーのセットアップ、ブロック タイプ、コンテンツ操作、イベント、メニュー、およびリッチなブロック ベースのドキュメント エディターを作成するための高度な機能について説明します。
