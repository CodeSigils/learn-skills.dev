Реализуйте элемент управления редактором блоков Syncfusion в приложениях ASP.NET Core с помощью вспомогательных функций тегов Razor. Используйте этот навык при работе с редактором блоков Syncfusion, EJ2 BlockEditor, блочным редактированием контента ASP.NET Core или синтаксисом <ejs-blockeditor>. Охватывает управление блоками, вложенные структуры контента, функции перетаскивания, очистку контента, установку, настройку вспомогательных тегов, типы блоков, манипулирование контентом, события, меню и расширенные функции для создания многофункциональных редакторов документов на основе блоков.
