تنفيذ التحكم في Syncfusion Block Editor في تطبيقات ASP.NET Core باستخدام Razor Tag Helpers. استخدم هذه المهارة عند العمل باستخدام Syncfusion Block Editor، أو EJ2 BlockEditor، أو تحرير المحتوى المستند إلى كتلة ASP.NET Core، أو بناء جملة <ejs-blockeditor>. يغطي إدارة الكتل، وهياكل المحتوى المتداخلة، ووظيفة السحب والإفلات، وتعقيم المحتوى، والتثبيت، وإعداد مساعد العلامات، وأنواع الكتل، ومعالجة المحتوى، والأحداث، والقوائم، والميزات المتقدمة لإنشاء محررات مستندات غنية تعتمد على الكتل.
