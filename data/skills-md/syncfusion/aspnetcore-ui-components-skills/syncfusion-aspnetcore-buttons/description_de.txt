Bietet umfassende Anleitungen für die Implementierung der Syncfusion ASP.NET Core Switch (Toggle Switch Button) und SplitButton-Komponente mithilfe von Tag Helper. Verwenden Sie dies, wenn Sie einer ASP.NET Core-Anwendung einen Kippschalter, eine Ein-/Aus-Steuerung oder einen binären Zustandseingang hinzufügen. Diese Fertigkeit umfasst den aktivierten/deaktivierten Status, die Etikettenanpassung (onLabel/offLabel), RTL-Unterstützung, Formularintegration, BeforeChange-Ereignisbehandlung und benutzerdefiniertes Erscheinungsbild.
