Proporciona una guía completa para implementar el componente SplitButton de Syncfusion ASP.NET Core Switch (botón de conmutación) mediante Tag Helper. Úselo cuando agregue un interruptor de palanca, un control de encendido/apagado o una entrada de estado binario a una aplicación ASP.NET Core. Esta habilidad cubre el estado marcado/deshabilitado, personalización de etiquetas (onLabel/offLabel), compatibilidad con RTL, integración de formularios, manejo de eventos BeforeChange y apariencia personalizada.
