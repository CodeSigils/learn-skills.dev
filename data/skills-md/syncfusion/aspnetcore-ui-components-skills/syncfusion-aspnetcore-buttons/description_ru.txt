Содержит полное руководство по реализации Syncfusion ASP.NET Core Switch (кнопка переключения) и компонента SplitButton с помощью Tag Helper. Используйте это при добавлении тумблера, элемента управления включением/выключением или входа двоичного состояния в приложение ASP.NET Core. Этот навык охватывает проверенное/отключенное состояние, настройку меток (onLabel/offLabel), поддержку RTL, интеграцию форм, обработку событий BeforeChange и настраиваемый внешний вид.
