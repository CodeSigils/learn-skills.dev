يوفر إرشادات كاملة لتنفيذ Syncfusion ASP.NET Core Switch (زر التبديل)، ومكون SplitButton باستخدام Tag Helper. استخدم هذا عند إضافة مفتاح تبديل أو تحكم تشغيل/إيقاف أو إدخال حالة ثنائية إلى تطبيق ASP.NET Core. تغطي هذه المهارة حالة التحديد/التعطيل، وتخصيص التسمية (onLabel/offLabel)، ودعم RTL، وتكامل النماذج، ومعالجة حدث BeforeChange، والمظهر المخصص.
