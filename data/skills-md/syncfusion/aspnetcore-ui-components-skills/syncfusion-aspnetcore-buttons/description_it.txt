Fornisce indicazioni complete per l'implementazione del componente SplitButton Syncfusion ASP.NET Core Switch (pulsante di attivazione/disattivazione) tramite Tag Helper. Utilizzarlo quando si aggiunge un interruttore, un controllo di attivazione/disattivazione o un input di stato binario a un'applicazione ASP.NET Core. Questa competenza copre lo stato selezionato/disabilitato, la personalizzazione delle etichette (onLabel/offLabel), il supporto RTL, l'integrazione dei moduli, la gestione degli eventi BeforeChange e l'aspetto personalizzato.
