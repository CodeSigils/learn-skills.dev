Cuando el usuario necesite crear minigráficos (visualizaciones de datos compactos) en aplicaciones ASP.NET Core, utilice siempre esta habilidad para implementar componentes de minigráficos, configurar tipos de gráficos (línea, columna, área, ganancias y pérdidas, circular), vincular datos, personalizar la apariencia, agregar marcadores y etiquetas de datos, permitir interacciones del usuario (información sobre herramientas, líneas de seguimiento) y garantizar el cumplimiento de la accesibilidad de inmediato.
