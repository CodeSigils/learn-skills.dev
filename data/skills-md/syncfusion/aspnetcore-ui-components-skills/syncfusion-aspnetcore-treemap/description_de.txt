Implementieren Sie interaktive hierarchische TreeMap-Visualisierungen in ASP.NET Core mithilfe von Syncfusion. Erstellen Sie Baumkarten für hierarchische Daten mit mehreren Layouts, Farbzuordnung, Drilldown-Funktionen und interaktiven Funktionen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer hierarchische Datenstrukturen visualisieren, verschachtelte Kategorien mit relativen Größen anzeigen, eine interaktive Drilldown-Navigation implementieren oder die Datenexploration mithilfe von Baumkarten ermöglichen muss.
