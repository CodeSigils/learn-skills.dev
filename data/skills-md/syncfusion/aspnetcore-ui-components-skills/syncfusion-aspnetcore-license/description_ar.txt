** دليل تسجيل الترخيص ** — المساعدة في إنشاء مفتاح ترخيص Syncfusion ASP.NET Core EJ2 وتسجيله واستكشاف الأخطاء وإصلاحها وحل الأخطاء. يُستخدم عندما: تسجيل مفاتيح الترخيص، أو التعامل مع أخطاء الترخيص، أو الترقية من الإصدار التجريبي إلى الإصدار المدفوع، أو إنشاء مفاتيح خاصة بالإصدار، أو التعامل مع الترخيص الخاص بالنظام الأساسي.
