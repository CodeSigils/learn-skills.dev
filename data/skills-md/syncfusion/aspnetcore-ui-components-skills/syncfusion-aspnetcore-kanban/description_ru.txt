Руководство по реализации канбан-компонента Syncfusion ASP.NET Core с использованием синтаксиса Tag Helper. Используйте этот навык при создании досок задач, настройке столбцов и дорожек или включении перетаскивания. Охватывает настройки карточек, диалоговые окна и привязку удаленных данных для ASP.NET Core MVC и Razor Pages.
