Guía para implementar el componente Kanban de Syncfusion ASP.NET Core utilizando la sintaxis de Tag Helper. Utilice esta habilidad al crear tableros de tareas, configurar columnas y carriles o habilitar la función de arrastrar y soltar. Cubre la configuración de la tarjeta, los cuadros de diálogo y el enlace de datos remotos para ASP.NET Core MVC y Razor Pages.
