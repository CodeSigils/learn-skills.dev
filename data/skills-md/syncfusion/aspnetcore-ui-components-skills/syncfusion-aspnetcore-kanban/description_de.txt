Leitfaden zur Implementierung der Syncfusion ASP.NET Core Kanban-Komponente mithilfe der Tag Helper-Syntax. Nutzen Sie diese Fähigkeit, wenn Sie Aufgabentafeln erstellen, Spalten und Swimlanes konfigurieren oder Drag-and-Drop aktivieren. Behandelt Karteneinstellungen, Dialoge und die Bindung von Remotedaten für ASP.NET Core MVC und Razor Pages.
