Простой компонент панели инструментов, который объединяет командные кнопки и адаптивные элементы управления в горизонтальный интерфейс. Идеально подходит для редакторов документов, систем управления контентом и заголовков приложений для запуска действий и эффективного управления рабочими процессами пользователей.
