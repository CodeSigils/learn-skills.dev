Руководство по реализации компонента Syncfusion ASP.NET Core Switch. Используйте этот навык при создании кнопки/переключателя для ввода формы или управления состоянием. Охватывает установку, базовую реализацию, настройку свойств, обработку событий и настройку стилей. Содержит рекомендации по началу работы, свойствам, событиям и документации по стилю.
