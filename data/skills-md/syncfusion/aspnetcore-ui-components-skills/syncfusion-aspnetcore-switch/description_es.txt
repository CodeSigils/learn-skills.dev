Guía para implementar el componente Syncfusion ASP.NET Core Switch. Utilice esta habilidad al crear un botón/interruptor de alternancia para entradas de formulario o gestión de estado. Cubre la instalación, implementación básica, configuración de propiedades, manejo de eventos y personalización de estilos. Proporciona orientación sobre cómo empezar, propiedades, eventos y documentación de estilo.
