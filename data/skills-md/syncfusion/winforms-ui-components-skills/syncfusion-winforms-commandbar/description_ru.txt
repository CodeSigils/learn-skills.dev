Реализуйте элемент управления CommandBar в Windows Forms для создания настраиваемых панелей инструментов, арматурных стержней и строк состояния с возможностями закрепления, плавания и сохранения состояния. CommandBar обеспечивает организацию пользовательского интерфейса, подобную Office, с поддержкой размещения нескольких элементов управления, настройки пользовательского макета и сериализуемого управления состоянием.
