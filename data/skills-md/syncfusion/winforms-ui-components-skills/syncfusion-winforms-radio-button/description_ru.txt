Руководство по реализации элемента управления Syncfusion RadioButtonAdv в приложениях Windows Forms. Используйте при создании расширенных переключателей с темами Office (2007/2016), стилем Metro, градиентным фоном, эффектами тени текста, настраиваемыми изображениями для каждого состояния или 2D/3D-границами для профессионального стиля, выходящего за рамки стандартного WinForms RadioButton.
