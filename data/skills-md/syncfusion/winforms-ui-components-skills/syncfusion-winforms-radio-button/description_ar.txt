دليل لتطبيق التحكم Syncfusion RadioButtonAdv في تطبيقات Windows Forms. استخدمها عند إنشاء أزرار اختيار محسّنة مع سمات Office (2007/2016)، أو نمط Metro، أو الخلفيات المتدرجة، أو تأثيرات ظل النص، أو الصور المخصصة لكل حالة، أو حدود ثنائية/ثلاثية الأبعاد لتصميم احترافي يتجاوز WinForms RadioButton القياسي.
