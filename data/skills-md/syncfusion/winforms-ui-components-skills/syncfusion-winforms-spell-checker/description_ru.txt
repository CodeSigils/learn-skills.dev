Реализуйте возможности проверки орфографии в приложениях Windows Forms с помощью Syncfusion SpellCheckerAdv. Используйте этот навык всякий раз, когда пользователю нужно добавить проверку орфографии в элементы управления текстом, настроить словари, настроить предложения контекстного меню, настроить параметры игнорирования или получить предложения по правописанию. Этот навык охватывает прикрепление элемента управления к RichTextBox/TextBox, управление словарями нескольких языков, включение контекстных меню в реальном времени и обработку предложений слов с ошибками.
