ينفذ التحكم Syncfusion MetroForm لإنشاء نماذج Windows حديثة على طراز Metro مع أشرطة تعليق وحدود وألوان قابلة للتخصيص. استخدم هذا عند العمل مع MetroForm أو أشرطة العناوين المخصصة أو نماذج واجهة المستخدم المسطحة أو تحديث مظهر Windows Forms. توفر المهارة إرشادات لتخصيص شريط التسميات التوضيحية، والزوايا الدائرية، وتسميات التسميات التوضيحية والصور، وميزات التصميم المتقدمة.
