Реализует элемент управления Syncfusion MetroForm для создания современных форм Windows Forms в стиле Metro с настраиваемыми заголовками, границами и цветами. Используйте это при работе с MetroForm, настраиваемыми заголовками, плоскими формами пользовательского интерфейса или модернизацией внешнего вида Windows Forms. Этот навык дает рекомендации по настройке строки заголовка, закругленным углам, меткам и изображениям подписей, а также расширенным функциям стилизации.
