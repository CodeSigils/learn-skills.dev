Реализует Syncfusion Windows Forms GridGroupingControl для расширенного управления данными с группировкой, сортировкой, фильтрацией и иерархическим отображением. Используйте это при работе с многоуровневой группировкой, сетками «основная-детализация», связями вложенных таблиц или сводками данных с агрегатами. Этот навык охватывает операции группировки, фильтрацию в стиле Excel, фильтры динамических записей, иерархические структуры данных и возможности сетки на уровне предприятия.
