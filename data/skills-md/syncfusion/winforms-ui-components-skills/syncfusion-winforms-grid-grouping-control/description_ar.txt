يطبق Syncfusion Windows Forms GridGroupingControl لإدارة البيانات المتقدمة من خلال التجميع والفرز والتصفية والعرض الهرمي. استخدم هذا عند العمل مع التجميع متعدد المستويات، أو الشبكات الرئيسية التفصيلية، أو علاقات الجداول المتداخلة، أو ملخصات البيانات مع التجميعات. تغطي المهارة عمليات التجميع، والتصفية الشبيهة ببرنامج Excel، ومرشحات السجلات الديناميكية، وهياكل البيانات الهرمية، وقدرات الشبكة على مستوى المؤسسة.
