Implementieren und passen Sie das ColorPickerButton-Steuerelement von Syncfusion Windows Forms für die Farbauswahl an. Wird ausgelöst, wenn der Benutzer ein Farbauswahl-Dropdown-Menü, eine Farbauswahl-Benutzeroberfläche oder eine Farbeingabesteuerung benötigt oder Benutzern die Auswahl aus Farbgruppen (Standard, System, Benutzerdefiniert, Benutzerfarben) ermöglichen muss. Behandelt die ersten Schritte, die Farbauswahl, die Anpassung und die Eigenschaften des UI-Erscheinungsbilds.
