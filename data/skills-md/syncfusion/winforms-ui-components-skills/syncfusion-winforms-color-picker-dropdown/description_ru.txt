Реализуйте и настройте элемент управления ColorPickerButton Syncfusion Windows Forms для выбора цвета. Срабатывает, когда пользователю нужен раскрывающийся список выбора цвета, пользовательский интерфейс выбора цвета, элемент управления вводом цвета или ему нужно разрешить пользователям выбирать из групп цветов (стандартные, системные, пользовательские, пользовательские цвета). Описывает начало работы, выбор цвета, настройку и свойства внешнего вида пользовательского интерфейса.
