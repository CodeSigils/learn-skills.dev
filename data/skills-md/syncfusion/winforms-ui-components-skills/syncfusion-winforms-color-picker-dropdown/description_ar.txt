قم بتنفيذ وتخصيص عنصر التحكم Syncfusion Windows Forms ColorPickerButton لاختيار اللون. يتم تشغيله عندما يحتاج المستخدم إلى قائمة منسدلة لمنتقي الألوان، أو واجهة مستخدم لاختيار اللون، أو التحكم في إدخال اللون، أو يحتاج إلى السماح للمستخدمين بالاختيار من مجموعات الألوان (ألوان قياسية أو نظامية أو مخصصة أو ألوان المستخدم). يغطي البدء واختيار اللون والتخصيص وخصائص مظهر واجهة المستخدم.
