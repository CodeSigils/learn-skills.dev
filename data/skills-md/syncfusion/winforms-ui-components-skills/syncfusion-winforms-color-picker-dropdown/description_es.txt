Implement and customize the Syncfusion Windows Forms ColorPickerButton control for color selection. Se activa cuando el usuario necesita un menú desplegable de selección de color, una interfaz de usuario de selección de color, control de entrada de color o necesita permitir que los usuarios seleccionen entre grupos de colores (estándar, sistema, personalizado, colores de usuario). Covers getting started, color selection, customization, and UI appearance properties.
