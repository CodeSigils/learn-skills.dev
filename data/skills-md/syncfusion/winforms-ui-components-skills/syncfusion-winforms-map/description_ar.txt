دليل التنفيذ للتحكم في خرائط Syncfusion WinForms - مكون تصور البيانات الجغرافية الذي يعرض البيانات الإحصائية والإقليمية باستخدام ملفات الأشكال والفقاعات والعلامات والميزات التفاعلية. استخدم هذا عند العمل مع خرائط WinForms، أو الخرائط الجغرافية في Windows Forms، أو تصورات ملفات الأشكال، أو الخرائط التصحيحية، أو الخرائط الفقاعية. تغطي هذه المهارة طبقات الخريطة، والتكبير/التصغير، وربط البيانات الجغرافية، وملفات أشكال ESRI، وإنشاء تطبيقات سطح المكتب المستندة إلى الموقع باستخدام خرائط تفاعلية.
