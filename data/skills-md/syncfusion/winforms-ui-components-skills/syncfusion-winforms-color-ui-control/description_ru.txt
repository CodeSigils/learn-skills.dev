Руководство по реализации Syncfusion ColorUIControl в приложениях Windows Forms. Используйте это при работе с пользовательским интерфейсом выбора цвета, палитрами цветов или элементами управления цветовой палитрой. Охватывает цветовые группы (Системные, Стандартные, Пользовательские, Пользовательские), настройку внешнего вида и интеграцию всплывающих меню в приложениях .NET Windows Forms.
