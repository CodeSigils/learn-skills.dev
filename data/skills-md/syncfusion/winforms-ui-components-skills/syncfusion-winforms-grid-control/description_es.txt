Implements Syncfusion Windows Forms GridControl with cell-oriented architecture, virtual data loading, and Excel-like features. Use this when working with spreadsheet-like grids, GridStyleInfo cell styling, grid formulas, or covered cell ranges. La habilidad cubre eventos QueryCellInfo, PopulateValues, ChangeCells, selección de cuadrícula, validación de edición y amplias capacidades de personalización de celdas.
