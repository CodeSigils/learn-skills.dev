دليل شامل لتطبيق قائمة Syncfusion MainFrameBarManager ونظام شريط الأدوات في Windows Forms. يُستخدم عند إنشاء القوائم أو أشرطة الأدوات أو أشرطة الأوامر أو بنيات القائمة. يغطي نماذج القائمة الهرمية، وأنواع BarItem، والميزات التفاعلية، ودعم لوحة المفاتيح، وتكامل MDI، واستمرارية الحالة لإنشاء تطبيقات احترافية تعتمد على القائمة باستخدام الاختصارات وتقنيات الإستذكار وتلميحات الأدوات وأشرطة الأدوات القابلة للتخصيص.
