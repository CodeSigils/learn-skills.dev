Guía para implementar el control Syncfusion GroupView en aplicaciones de Windows Forms. Úselo al crear controles de lista con imágenes, interfaces estilo caja de herramientas de Visual Studio o listas de elementos de navegación. Cubre colecciones de GroupViewItem, listas de elementos de arrastrar y soltar, selecciones resaltadas, interfaces estilo caja de herramientas y controles de cliente GroupBar para interfaces estilo OutlookBar.
