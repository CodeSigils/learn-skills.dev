دليل لتطبيق التحكم Syncfusion GroupView في تطبيقات Windows Forms. يُستخدم عند إنشاء عناصر تحكم في القائمة باستخدام الصور أو واجهات نمط مربع أدوات Visual Studio أو قوائم عناصر التنقل. يغطي مجموعات GroupViewItem وقوائم عناصر السحب والإفلات والتحديدات المميزة وواجهات نمط مربع الأدوات وعناصر تحكم عميل GroupBar للواجهات ذات نمط OutlookBar.
