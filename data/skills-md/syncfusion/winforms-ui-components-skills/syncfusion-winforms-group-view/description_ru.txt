Руководство по реализации элемента управления Syncfusion GroupView в приложениях Windows Forms. Используйте при создании элементов управления списками с изображениями, интерфейсами в стиле панели инструментов Visual Studio или списками элементов навигации. Охватывает коллекции GroupViewItem, списки перетаскиваемых элементов, выделенные элементы, интерфейсы в стиле панели инструментов и клиентские элементы управления GroupBar для интерфейсов в стиле OutlookBar.
