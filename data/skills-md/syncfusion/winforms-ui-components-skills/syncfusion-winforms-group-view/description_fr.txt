Guide d'implémentation du contrôle Syncfusion GroupView dans les applications Windows Forms. À utiliser lors de la création de contrôles de liste avec des images, des interfaces de style boîte à outils Visual Studio ou des listes d'éléments de navigation. Couvre les collections GroupViewItem, les listes d'éléments par glisser-déposer, les sélections en surbrillance, les interfaces de style boîte à outils et les contrôles client GroupBar pour les interfaces de style OutlookBar.
