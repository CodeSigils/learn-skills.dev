Руководство по реализации элемента управления Syncfusion SfListView в Windows Forms для создания пользовательских интерфейсов на основе списков с возможностями привязки данных, группировки, сортировки, фильтрации и выбора. Используйте при создании приложений с коллекциями элементов, представлениями проводника, списками контактов или каталогами продуктов с сортируемыми/фильтруемыми списками. Охватывает привязку данных, списки флажков, сгруппированные списки, отфильтрованные списки и расширенное отображение данных для интерфейсов списков.
