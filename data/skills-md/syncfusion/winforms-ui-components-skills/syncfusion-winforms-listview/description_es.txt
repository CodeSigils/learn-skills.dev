Guía para implementar el control Syncfusion SfListView en Windows Forms para crear interfaces de usuario basadas en listas con capacidades de enlace, agrupación, clasificación, filtrado y selección de datos. Úselo al crear aplicaciones con colecciones de artículos, vistas del Explorador, listas de contactos o catálogos de productos con listas ordenables/filtrables. Cubre enlace de datos, listas de casillas de verificación, listas agrupadas, listas filtradas y visualización de datos enriquecidos para interfaces de listas.
