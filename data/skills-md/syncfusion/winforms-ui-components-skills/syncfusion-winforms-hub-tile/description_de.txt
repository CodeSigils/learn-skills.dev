Leitfaden zur Implementierung der Syncfusion HubTile-Steuerung in Windows Forms-Anwendungen. Verwenden Sie diese Option, wenn Sie Live-Kachelfunktionen mit animierten Inhaltskacheln ähnlich wie bei Windows 8/Windows Phone erstellen, einschließlich Schiebe-, Dreh- oder Impulsübergängen. Deckt Dashboard-Kacheln, Live-Benachrichtigungen, animierte Statusanzeigen, eine Benutzeroberfläche im Windows 8-Stil mit automatischen Animationen, Bannern und visuellen Updates ab.
