دليل لتطبيق التحكم Syncfusion HubTile في تطبيقات Windows Forms. يُستخدم عند إنشاء وظيفة التجانب المباشر باستخدام مربعات المحتوى المتحرك المشابهة لنظام التشغيل Windows 8/Windows Phone، بما في ذلك انتقالات الشريحة أو التدوير أو النبض. يغطي مربعات لوحة المعلومات والإشعارات المباشرة وعروض الحالة المتحركة وواجهة مستخدم Windows 8 مع الرسوم المتحركة التلقائية واللافتات والتحديثات المرئية.
