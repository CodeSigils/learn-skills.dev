Руководство по реализации элемента управления Syncfusion HubTile в приложениях Windows Forms. Используйте при создании функций живых плиток с анимированными плитками содержимого, аналогичных Windows 8/Windows Phone, включая скольжение, поворот или импульсные переходы. Включает плитки информационной панели, живые уведомления, анимированные индикаторы состояния, пользовательский интерфейс в стиле Windows 8 с автоматической анимацией, баннерами и визуальными обновлениями.
