Implementa Syncfusion SfNumericTextBox per l'input numerico con formattazione, convalida e personalizzazione in Windows Forms. Da utilizzare durante la creazione di controlli di input numerici con formattazione valuta, valori percentuali, convalida numerica o formattazione decimale. Copre le opzioni di formattazione numerica, la convalida dell'intervallo di valori e l'immissione di dati numerici formattati con funzionalità di convalida.
