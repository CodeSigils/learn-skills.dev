Внедрите Syncfusion SfNumericTextBox для числового ввода с форматированием, проверкой и настройкой в ​​Windows Forms. Используйте при создании элементов управления числовым вводом с денежным форматированием, процентными значениями, проверкой чисел или десятичным форматированием. Охватывает параметры числового форматирования, проверку диапазона значений и ввод форматированных числовых данных с возможностями проверки.
