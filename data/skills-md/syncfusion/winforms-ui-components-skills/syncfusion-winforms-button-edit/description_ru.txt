Реализуйте элемент управления Syncfusion WinForms ButtonEdit для создания текстового ввода со встроенными кнопками. Используйте этот навык, когда пользователям нужно создать браузеры файлов/папок, раскрывающиеся элементы управления или настраиваемые элементы управления вводом с кнопками действий. Включает настройку сборки, подходы дизайнера/кода, настройку внешнего вида, настройку дочерних кнопок, события и шаблоны взаимодействия.
