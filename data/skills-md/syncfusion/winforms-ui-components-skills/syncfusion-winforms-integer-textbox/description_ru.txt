Руководство по реализации элемента управления Integer TextBox Syncfusion Windows Forms. Используйте при создании целочисленных полей ввода с числовой проверкой, форматированием чисел или ограничениями значений в сценариях ввода данных. Охватывает проверку целых чисел, форматирование чисел, ограничения минимального/максимального значения, форматирование значений и поля числового ввода в приложениях WinForms.
