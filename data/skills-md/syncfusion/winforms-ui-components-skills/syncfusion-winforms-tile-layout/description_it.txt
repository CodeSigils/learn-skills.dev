Guida per l'implementazione del controllo Syncfusion TileLayout nelle applicazioni Windows Forms. Da utilizzare durante la creazione di interfacce di riquadri in stile Windows 8 Metro, contenitori di riquadri raggruppati, riquadri animati con immagini/testo rotanti utilizzando ImageStreamer, riordino con trascinamento della selezione o layout in stile dashboard con posizionamento e aspetto personalizzabili.
