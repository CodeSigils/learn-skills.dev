Leitfaden zur Implementierung des Syncfusion TileLayout-Steuerelements in Windows Forms-Anwendungen. Verwenden Sie diese Option, wenn Sie Kacheloberflächen im Metro-Stil von Windows 8, gruppierte Kachelcontainer, Live-Kacheln mit rotierenden Bildern/Text mithilfe von ImageStreamer, Drag-and-Drop-Neuordnung oder Layouts im Dashboard-Stil mit anpassbarer Positionierung und Darstellung erstellen.
