Guía para implementar el control Syncfusion TileLayout en aplicaciones de Windows Forms. Úselo al crear interfaces de mosaicos estilo Metro de Windows 8, contenedores de mosaicos agrupados, mosaicos en vivo con imágenes/texto rotativos usando ImageStreamer, reordenamiento mediante arrastrar y soltar o diseños estilo tablero con posicionamiento y apariencia personalizables.
