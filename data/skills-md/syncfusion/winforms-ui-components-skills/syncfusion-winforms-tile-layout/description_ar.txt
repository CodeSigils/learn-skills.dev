دليل لتطبيق التحكم Syncfusion TileLayout في تطبيقات Windows Forms. يُستخدم عند إنشاء واجهات تجانب بنمط Windows 8 Metro، أو حاويات تجانب مجمعة، أو تجانبات حية تحتوي على صور/نص دوار باستخدام ImageStreamer، أو إعادة ترتيب السحب والإفلات، أو تخطيطات على نمط لوحة المعلومات مع تحديد موضع ومظهر قابلين للتخصيص.
