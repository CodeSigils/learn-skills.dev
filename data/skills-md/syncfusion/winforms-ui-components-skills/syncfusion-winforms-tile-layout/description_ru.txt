Руководство по реализации элемента управления Syncfusion TileLayout в приложениях Windows Forms. Используйте при создании интерфейсов плиток в стиле Windows 8 Metro, сгруппированных контейнеров плиток, живых плиток с вращающимися изображениями/текстом с помощью ImageStreamer, изменения порядка перетаскиванием или макетов в стиле информационной панели с настраиваемым расположением и внешним видом.
