Руководство по реализации элемента управления Syncfusion Windows Forms Scheduler (календарь событий) для планирования встреч и управления событиями. Используйте этот навык при реализации функций календаря, планирования встреч или управления событиями в приложениях Windows Forms. Охватывает представления расписания, повторяющиеся встречи, навигацию по календарю, перетаскивание встреч и привязку данных.
