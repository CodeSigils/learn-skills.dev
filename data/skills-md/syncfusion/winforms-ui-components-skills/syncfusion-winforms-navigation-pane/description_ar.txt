دليل لتطبيق التحكم Syncfusion GroupBar (جزء التنقل) في تطبيقات Windows Forms. يُستخدم عند إنشاء التنقل بنمط Outlook، أو التنقل الهرمي بالشريط الجانبي، أو حاويات المجموعات القابلة للطي، أو واجهات بنمط مربع الأدوات. يغطي أجزاء التنقل المكدسة، والتنقل تحت عنوان Office 2007/2010/2016، وحاويات GroupBar المتداخلة، ومجموعات التحكم المصنفة لتخطيطات التنقل المنظمة.
