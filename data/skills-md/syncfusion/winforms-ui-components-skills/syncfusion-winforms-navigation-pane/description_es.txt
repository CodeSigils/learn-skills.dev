Guía para implementar el control Syncfusion GroupBar (Panel de navegación) en aplicaciones de Windows Forms. Úselo al crear navegación estilo Outlook, navegación de barra lateral jerárquica, contenedores de grupos plegables o interfaces estilo caja de herramientas. Cubre paneles de navegación apilados, navegación temática de Office 2007/2010/2016, contenedores GroupBar anidados y colecciones de controles categorizados para diseños de navegación estructurados.
