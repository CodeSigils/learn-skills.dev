Leitfaden zur Implementierung der Syncfusion GroupBar-Steuerung (Navigationsbereich) in Windows Forms-Anwendungen. Verwenden Sie diese Option, wenn Sie eine Navigation im Outlook-Stil, eine hierarchische Seitenleistennavigation, reduzierbare Gruppencontainer oder Schnittstellen im Toolbox-Stil erstellen. Deckt gestapelte Navigationsbereiche, themenbezogene Navigation in Office 2007/2010/2016, verschachtelte GroupBar-Container und kategorisierte Steuerelementsammlungen für strukturierte Navigationslayouts ab.
