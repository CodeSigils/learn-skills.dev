Guide d'implémentation du contrôle Syncfusion GroupBar (volet de navigation) dans les applications Windows Forms. À utiliser lors de la création d'une navigation de style Outlook, d'une navigation hiérarchique dans la barre latérale, de conteneurs de groupe pliables ou d'interfaces de style boîte à outils. Couvre les volets de navigation empilés, la navigation thématique Office 2007/2010/2016, les conteneurs GroupBar imbriqués et les collections de contrôles catégorisés pour les mises en page de navigation structurées.
