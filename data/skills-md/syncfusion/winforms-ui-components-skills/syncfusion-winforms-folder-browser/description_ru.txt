Реализовать диалог Windows Forms FolderBrowser для выбора папки. Используйте это при реализации диалогов выбора папки, просмотра каталогов или выбора пути к папке в приложениях. Охватывает настройку сборки, инициализацию диалога, настройку местоположения/стиля, события обратного вызова и общие шаблоны просмотра.
