Implémentez la boîte de dialogue Windows Forms FolderBrowser pour la sélection de dossiers. Utilisez-le lors de l'implémentation de boîtes de dialogue de sélection de dossier, de navigation dans des répertoires ou de sélection de chemin de dossier dans des applications. Couvre la configuration de l'assembly, l'initialisation de la boîte de dialogue, la configuration de l'emplacement/style, les événements de rappel et les modèles de navigation courants.
