Implemente el cuadro de diálogo FolderBrowser de Windows Forms para la selección de carpetas. Utilícelo cuando implemente cuadros de diálogo de selección de carpetas, exploración de directorios o selección de rutas de carpetas en aplicaciones. Cubre la configuración del ensamblaje, la inicialización del diálogo, la configuración de ubicación/estilo, eventos de devolución de llamada y patrones de navegación comunes.
