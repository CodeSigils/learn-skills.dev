Implementieren Sie das Windows Forms FolderBrowser-Dialogfeld zur Ordnerauswahl. Verwenden Sie dies, wenn Sie Dialoge zur Ordnerauswahl, das Durchsuchen von Verzeichnissen oder die Auswahl von Ordnerpfaden in Anwendungen implementieren. Behandelt Assembly-Setup, Dialoginitialisierung, Speicherort-/Stilkonfiguration, Rückrufereignisse und allgemeine Browsing-Muster.
