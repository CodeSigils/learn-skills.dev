Guía para implementar el control FontListBox de Syncfusion WinForms en aplicaciones de Windows Forms. Utilice esta habilidad cuando el usuario necesite mostrar una lista de fuentes del sistema instaladas, configurar modos de selección para la selección de fuentes, aplicar estilos visuales, habilitar la función de autocompletar de fuentes, personalizar las barras de desplazamiento o manejar eventos de selección de fuentes. Cubre UseAutoComplete, FontListBoxStyle, SelectionMode y el comportamiento de la barra de desplazamiento.
