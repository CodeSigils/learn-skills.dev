دليل لتنفيذ عنصر التحكم Syncfusion WinForms FontListBox في تطبيقات Windows Forms. استخدم هذه المهارة عندما يحتاج المستخدم إلى عرض قائمة خطوط النظام المثبتة، أو تكوين أوضاع التحديد لاختيار الخط، أو تطبيق الأنماط المرئية، أو تمكين الإكمال التلقائي للخط، أو تخصيص أشرطة التمرير، أو التعامل مع أحداث تحديد الخط. يغطي سلوك UseAutoComplete وFontListBoxStyle وSelectionMode وشريط التمرير.
