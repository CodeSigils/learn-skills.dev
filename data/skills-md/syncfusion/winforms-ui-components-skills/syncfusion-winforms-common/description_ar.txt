دليل شامل لتطبيق عناصر التحكم Syncfusion Essential Studio Windows Forms (WinForms) في تطبيقات سطح المكتب. استخدم هذه المهارة عند العمل مع مكونات Syncfusion WinForms أو Essential Studio WinForms. يغطي تثبيت WinForms والتعريب ودعم DPI العالي وتوافق .NET Core. يساعد في إضافة عناصر التحكم وتسجيل مفاتيح الترخيص واستكشاف مشكلات مكونات WinForms وإصلاحها.
