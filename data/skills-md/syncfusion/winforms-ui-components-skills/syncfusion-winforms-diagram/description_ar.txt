تنفيذ التحكم في الرسم التخطيطي لنماذج Windows Syncfusion لإنشاء تطبيقات الرسوم التخطيطية التفاعلية. استخدم هذا عند إنشاء مخططات انسيابية أو مخططات تنظيمية أو مخططات شبكة أو تصورات قائمة على العقد. يوفر عنصر التحكم إمكانية التحرير بالسحب والإفلات ولوحات الرموز وإدارة الموصل وتسلسل المخططات لإنشاء تطبيقات تشبه Visio في Windows Forms.
