Guide d’implémentation du contrôle Syncfusion NavigationView dans Windows Forms pour la navigation dans le fil d’Ariane et le suivi du chemin hiérarchique. À utiliser lors de la création d'explorateurs de fichiers, de navigateurs de dossiers ou d'interfaces de type navigateur de fichiers avec des fils d'Ariane. Couvre la navigation dans le fil d'Ariane, la navigation par liste déroulante, le suivi de l'historique et les structures de barres hiérarchiques pour le suivi de localisation basé sur le chemin avec sélection d'enfants dans la liste déroulante.
