Руководство по реализации элемента управления Syncfusion NavigationView в Windows Forms для навигации по крошкам и отслеживания иерархических путей. Используйте при создании проводников файлов, браузеров папок или интерфейсов в стиле файлового браузера с навигационными цепочками. Охватывает навигационную цепочку, раскрывающуюся навигацию, отслеживание истории и иерархические структуры панелей для отслеживания местоположения на основе пути с выбором дочернего элемента в раскрывающемся списке.
