Guía para implementar el control Syncfusion NavigationView en Windows Forms para navegación de ruta de navegación y seguimiento de rutas jerárquicas. Úselo al crear exploradores de archivos, exploradores de carpetas o interfaces estilo explorador de archivos con rutas de navegación. Cubre la navegación de ruta de navegación, la navegación desplegable, el seguimiento del historial y las estructuras de barras jerárquicas para el seguimiento de ubicación basado en rutas con selección secundaria desplegable.
