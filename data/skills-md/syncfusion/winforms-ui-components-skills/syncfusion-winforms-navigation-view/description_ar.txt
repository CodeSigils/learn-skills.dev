دليل لتطبيق التحكم Syncfusion NavigationView في Windows Forms للتنقل التفصيلي وتتبع المسار الهرمي. يُستخدم عند إنشاء مستكشفات الملفات أو مستعرضات المجلدات أو واجهات نمط مستعرض الملفات مع مسارات التنقل. يغطي التنقل التفصيلي، والتنقل عبر القائمة المنسدلة، وتتبع السجل، وهياكل الشريط الهرمي لتتبع الموقع المستند إلى المسار مع اختيار القائمة المنسدلة الفرعية.
