Руководства по реализации элемента управления Syncfusion WinForms SfCalendar для выбора даты и просмотра календаря. Используйте это при работе с элементами управления календарем, средствами выбора дат или календарями с несколькими представлениями с представлениями «Месяц/Год/Десятилетие/Век». Охватывает режимы выбора даты, навигацию по просмотру, ограничения дат, особые даты и настройку внешнего вида для Windows Forms.
