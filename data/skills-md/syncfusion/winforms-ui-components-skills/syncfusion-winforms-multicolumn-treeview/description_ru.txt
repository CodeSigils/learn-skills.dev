Реализует элемент управления Syncfusion MultiColumnTreeView для приложений Windows Forms для отображения иерархических данных с дополнительными столбцами. Используйте это при работе с TreeNodeAdv, TreeColumnAdv, древовидными структурами с несколькими столбцами или иерархическими данными, требующими нескольких столбцов на узел. Этот навык охватывает коллекции узлов, флажки, кнопки выбора, привязку данных XML, функции загрузки по требованию и настройку внешнего вида дерева.
