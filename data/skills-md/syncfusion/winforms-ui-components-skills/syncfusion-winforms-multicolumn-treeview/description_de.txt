Implementiert das Syncfusion MultiColumnTreeView-Steuerelement für Windows Forms-Anwendungen, um hierarchische Daten mit zusätzlichen Spalten anzuzeigen. Verwenden Sie dies, wenn Sie mit TreeNodeAdv, TreeColumnAdv, mehrspaltigen Baumstrukturen oder hierarchischen Daten arbeiten, die mehrere Spalten pro Knoten erfordern. Die Fertigkeit umfasst Knotensammlungen, Kontrollkästchen, Optionsschaltflächen, XML-Datenbindung, Load-on-Demand-Funktionen und die Anpassung der Baumdarstellung.
