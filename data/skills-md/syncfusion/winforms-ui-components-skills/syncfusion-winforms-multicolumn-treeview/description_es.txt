Implementa el control Syncfusion MultiColumnTreeView para aplicaciones de Windows Forms para mostrar datos jerárquicos con columnas adicionales. Utilícelo cuando trabaje con TreeNodeAdv, TreeColumnAdv, estructuras de árbol de varias columnas o datos jerárquicos que requieran varias columnas por nodo. La habilidad cubre colecciones de nodos, casillas de verificación, botones de opción, enlace de datos XML, funciones de carga bajo demanda y personalización de la apariencia del árbol.
