Implementa el control Syncfusion MultiColumnTreeView para que las aplicaciones de Windows Forms muestren datos jerárquicos con columnas adicionales. Utilice esto cuando trabaje con TreeNodeAdv, TreeColumnAdv, estructuras de árbol de varias columnas o datos jerárquicos que requieran varias columnas por nodo. La habilidad cubre las colecciones de nodos, las casillas de verificación, los botones de opción, el enlace de datos XML, las funciones de carga bajo demanda y la personalización de la apariencia del árbol.
