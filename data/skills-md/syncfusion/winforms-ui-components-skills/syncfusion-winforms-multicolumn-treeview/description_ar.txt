ينفذ التحكم Syncfusion MultiColumnTreeView لتطبيقات Windows Forms لعرض البيانات الهرمية مع أعمدة إضافية. استخدم هذا عند العمل مع TreeNodeAdv، أو TreeColumnAdv، أو بنيات الشجرة متعددة الأعمدة، أو البيانات الهرمية التي تتطلب أعمدة متعددة لكل عقدة. تغطي المهارة مجموعات العقد، ومربعات الاختيار، وأزرار الخيارات، وربط بيانات XML، وميزات التحميل عند الطلب، وتخصيص مظهر الشجرة.
