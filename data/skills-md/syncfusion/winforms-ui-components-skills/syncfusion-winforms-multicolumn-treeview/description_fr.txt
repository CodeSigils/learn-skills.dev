Implémente le contrôle Syncfusion MultiColumnTreeView pour les applications Windows Forms afin d'afficher des données hiérarchiques avec des colonnes supplémentaires. Utilisez-le lorsque vous travaillez avec TreeNodeAdv, TreeColumnAdv, des structures arborescentes à plusieurs colonnes ou des données hiérarchiques nécessitant plusieurs colonnes par nœud. La compétence couvre les collections de nœuds, les cases à cocher, les boutons d'option, la liaison de données XML, les fonctionnalités de chargement à la demande et la personnalisation de l'apparence de l'arborescence.
