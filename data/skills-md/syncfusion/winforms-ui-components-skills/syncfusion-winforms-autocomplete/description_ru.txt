Управляет реализацией элемента управления Syncfusion WinForms AutoComplete для ввода текста с функцией автоматического предложения. Используйте, когда пользователи хотят добавить текстовые поля автозаполнения, реализовать функции автозаполнения, создать поля поиска с предложениями, включить автозаполнение URL-адресов или электронной почты или создать функцию поиска с опережением ввода в настольных приложениях Windows. Охватывает привязку данных, настройку, фильтрацию, раскрывающиеся списки с несколькими столбцами, события и все функции автозаполнения.
