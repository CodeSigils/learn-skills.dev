Guía la implementación del control Syncfusion WinForms AutoLabel para el posicionamiento automático de etiquetas con controles de formulario. Úselo cuando los usuarios quieran agregar etiquetas que se reposicionen automáticamente cuando los controles se mueven, crear diseños de formulario con unidades de control de etiqueta emparejadas, implementar diseños de formularios complejos con FlowLayout o garantizar que las etiquetas permanezcan sincronizadas con sus controles asociados. Cubre controles de etiquetado, posicionamiento, espaciado, configuración de tamaño, temática y eventos.
