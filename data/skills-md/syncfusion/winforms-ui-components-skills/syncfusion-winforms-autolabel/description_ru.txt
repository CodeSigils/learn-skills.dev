Управляет реализацией элемента управления Syncfusion WinForms AutoLabel для автоматического позиционирования меток с помощью элементов управления формы. Используйте его, когда пользователи хотят добавлять метки, которые автоматически перемещаются при перемещении элементов управления, создавать макеты форм с парными блоками управления метками, реализовывать сложные конструкции форм с помощью FlowLayout или обеспечивать синхронизацию меток со связанными с ними элементами управления. Охватывает элементы управления маркировкой, расположением, интервалами, настройками размера, темами и событиями.
