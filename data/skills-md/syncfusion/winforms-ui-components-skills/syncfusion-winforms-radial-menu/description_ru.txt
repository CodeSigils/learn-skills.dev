Руководство по реализации элемента управления Syncfusion RadialMenu в приложениях Windows Forms. Используйте при создании круговых контекстных меню, иерархической радиальной навигации или удобных для сенсорного управления интерфейсов круговых меню. Охватывает RadialColorPalette для выбора цвета, RadialFontListBox для выбора шрифта, RadialMenuSlider для числового ввода и тематические меню Office 2016 для современной круговой навигации, выходящей за рамки стандартных контекстных меню.
