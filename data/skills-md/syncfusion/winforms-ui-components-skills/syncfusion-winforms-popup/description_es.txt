Guide for implementing Syncfusion PopupControlContainer in Windows Forms applications. Use when creating custom popup panels, attaching popups to parent controls, or configuring auto-close behavior. Cubre el ciclo de vida de las ventanas emergentes, los métodos ShowPopup/HidePopup, el manejo de eventos (BeforePopup, Popup, CloseUp), el alojamiento de controles secundarios en ventanas emergentes, la configuración de desplazamiento automático, las ventanas emergentes transparentes y escenarios avanzados como el alojamiento ComboBoxBase dentro de ventanas emergentes.
