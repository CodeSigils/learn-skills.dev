دليل لتنفيذ Syncfusion Windows Forms AI AssistView (SfAIAssistView) لبناء واجهات الذكاء الاصطناعي للمحادثة في تطبيقات سطح المكتب. استخدم هذا عند إنشاء واجهات الدردشة أو مساعدي الذكاء الاصطناعي أو روبوتات الدردشة باستخدام Windows Forms. يدعم تكامل OpenAI وAzure OpenAI ومؤشرات الكتابة واقتراحات الدردشة وفقاعات الرسائل وطرق العرض المخصصة لتجارب المراسلة التفاعلية.
