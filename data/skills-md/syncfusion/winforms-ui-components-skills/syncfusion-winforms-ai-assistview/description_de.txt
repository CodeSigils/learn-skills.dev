Leitfaden zur Implementierung von Syncfusion Windows Forms AI AssistView (SfAIAssistView) zum Erstellen von Konversations-KI-Schnittstellen in Desktop-Anwendungen. Verwenden Sie dies, wenn Sie Chat-Schnittstellen, KI-Assistenten oder Chatbots mit Windows Forms erstellen. Unterstützt die Integration von OpenAI und Azure OpenAI, Tippindikatoren, Chat-Vorschläge, Nachrichtenblasen und benutzerdefinierte Ansichten für interaktive Messaging-Erlebnisse.
