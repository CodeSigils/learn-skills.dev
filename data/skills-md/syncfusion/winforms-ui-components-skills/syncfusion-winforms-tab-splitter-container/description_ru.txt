Внедрите элемент управления Syncfusion TabSplitterContainer для создания макетов разделенного представления с панелями с вкладками в Windows Forms. Используйте при создании разделенных представлений в стиле Visual Studio, редакторов документов с режимами проектирования и предварительного просмотра или многопанельных приложений. Охватывает коллекции первичных и вторичных страниц, функциональность кнопок переключения, свертывание/развертывание панелей, горизонтальную/вертикальную ориентацию, регулируемое положение разделителя и темы Office2016 для профессиональных многоэкранных интерфейсов.
