قم بتطبيق عنصر التحكم Syncfusion TabSplitterContainer لإنشاء تخطيطات عرض منقسمة مع لوحات مبوبة في Windows Forms. يُستخدم عند إنشاء طرق عرض مقسمة بنمط Visual Studio، أو برامج تحرير المستندات مع أوضاع التصميم/المعاينة، أو التطبيقات متعددة الأجزاء. يغطي مجموعات الصفحات الأساسية/الثانوية، ووظيفة زر التبديل، وأجزاء الطي/التوسيع، والاتجاه الأفقي/الرأسي، وموضع التقسيم القابل للتعديل، وموضوعات Office2016 للواجهات الاحترافية متعددة العرض.
