Implementieren Sie das Syncfusion TabSplitterContainer-Steuerelement zum Erstellen von Split-View-Layouts mit Registerkartenfeldern in Windows Forms. Verwenden Sie diese Option, wenn Sie geteilte Ansichten im Visual Studio-Stil, Dokumenteditoren mit Entwurfs-/Vorschaumodi oder Anwendungen mit mehreren Fenstern erstellen. Deckt primäre/sekundäre Seitensammlungen, Tauschschaltflächenfunktionen, Fenster zum Reduzieren/Erweitern, horizontale/vertikale Ausrichtung, anpassbare Teilerposition und Office2016-Designs für professionelle Schnittstellen mit mehreren Ansichten ab.
