Implementieren Sie Syncfusion Windows Forms BorderLayout, um untergeordnete Steuerelemente entlang der Grenzen (Nord, Süd, Ost, West) und in der Mitte anzuordnen. Verwenden Sie dies, wenn Sie mit BorderLayout arbeiten, Steuerelemente in Randbereichen positionieren, Andockalternativen verwenden oder Containerlayout und Steuerelementabstände in Windows Forms-Anwendungen konfigurieren.
