Implementieren Sie maskierte Texteingabesteuerelemente in WinForms-Anwendungen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Eingabefelder mit Formatmasken (Telefonnummern, IP-Adressen, Datumsangaben, Währung) erstellen, formatierte Eingaben validieren, die Dateneingabe auf bestimmte Muster beschränken oder das Verhalten von Benutzereingaben mit Maskenbeschränkungen konfigurieren muss.
