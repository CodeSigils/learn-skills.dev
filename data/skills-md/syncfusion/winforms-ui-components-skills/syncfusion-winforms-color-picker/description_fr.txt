Guide pour implémenter et personnaliser le contrôle Syncfusion WinForms ColorPickerUIAdv. Utilisez-le lors de l'implémentation d'interfaces de sélection de couleurs avec des palettes organisées (Récente, Standard, Thème), des groupes de couleurs personnalisés, des mises en page de style Office, une boîte de dialogue « Plus de couleurs » ou des ajouts de couleurs d'exécution dans les applications Windows Forms.
