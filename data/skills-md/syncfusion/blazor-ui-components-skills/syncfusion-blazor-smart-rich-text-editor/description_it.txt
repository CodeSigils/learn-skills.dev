Implementa Syncfusion SfSmartRichTextEditor, un editor WYSIWYG potenziato dall'intelligenza artificiale che estende SfRichTextEditor in Blazor. Usare questa opzione quando si configurano i back-end AI (OpenAI, Azure OpenAI, Ollama, IChatClient personalizzato), la barra degli strumenti Smart Action, la finestra di dialogo delle query AI, AssistViewSettings, eventi e metodi popup AI o qualsiasi funzionalità ereditata dell'editor RTF ereditata nel server Blazor e nell'app Web.
