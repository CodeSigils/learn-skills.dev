Implementa Syncfusion SfSmartRichTextEditor, un editor WYSIWYG mejorado con IA que extiende SfRichTextEditor en Blazor. Úselo al configurar backends de IA (OpenAI, Azure OpenAI, Ollama, IChatClient personalizado), barra de herramientas de acción inteligente, cuadro de diálogo de consulta de IA, AssistViewSettings, eventos y métodos emergentes de IA o cualquier característica heredada del editor de texto enriquecido en Blazor Server y la aplicación web.
