تطبق Syncfusion SfSmartRichTextEditor، وهو محرر WYSIWYG معزز بالذكاء الاصطناعي ويوسع SfRichTextEditor في Blazor. استخدم هذا عند تكوين الواجهات الخلفية للذكاء الاصطناعي (OpenAI، أو Azure OpenAI، أو Ollama، أو IChatClient المخصص)، أو شريط أدوات Smart Action، أو مربع حوار استعلام AI، أو AssistViewSettings، أو أحداث وأساليب AI المنبثقة، أو أي ميزات Rich Text Editor الموروثة في Blazor Server وتطبيق الويب.
