Реализует Syncfusion SfSmartRichTextEditor, редактор WYSIWYG с улучшенными искусственным интеллектом, расширяющий SfRichTextEditor в Blazor. Используйте это при настройке серверных частей AI (OpenAI, Azure OpenAI, Ollama, пользовательский IChatClient), панели инструментов Smart Action, диалогового окна запросов AI, AssistViewSettings, всплывающих событий и методов AI или любых унаследованных функций редактора форматированного текста в Blazor Server и веб-приложении.
