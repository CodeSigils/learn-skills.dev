قم بتنفيذ وتكوين مكون Syncfusion Blazor TreeMap (SfTreeMap) لتصور البيانات الهرمية. استخدم هذا عند العمل مع الخرائط الهيكلية، أو المرئيات المتناسبة مع المنطقة، أو عروض الكتل المشابهة للخريطة الحرارية. تغطي هذه المهارة إعداد TreeMap، وتكوين التخطيط، وربط البيانات، ورسم خرائط الألوان، والتنقل المتعمق، وميزات إمكانية الوصول.
