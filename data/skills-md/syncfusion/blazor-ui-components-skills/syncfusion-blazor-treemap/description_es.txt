Implemente y configure el componente Syncfusion Blazor TreeMap (SfTreeMap) para la visualización de datos jerárquicos. Utilícelo cuando trabaje con mapas de árbol, visualizaciones proporcionales al área o visualizaciones de bloques similares a mapas de calor. Esta habilidad cubre la configuración de TreeMap, la configuración del diseño, el enlace de datos, el mapeo de colores, la navegación detallada y las funciones de accesibilidad.
