Implementare il componente Syncfusion Blazor Query Builder per creare interfacce di query dinamiche e personalizzabili con logica di filtro complessa. Utilizzalo quando crei interfacce di ricerca avanzata, implementi motori di regole aziendali o crei flussi di lavoro di filtraggio dei dati con gruppi di condizioni nidificati e logica AND/OR. Supporta la gestione delle regole, l'interfaccia utente con trascinamento, la persistenza dello stato e ampie opzioni di personalizzazione.
