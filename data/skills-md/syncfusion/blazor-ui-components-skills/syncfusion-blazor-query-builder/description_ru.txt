Внедрите компонент Syncfusion Blazor Query Builder для создания динамических настраиваемых интерфейсов запросов со сложной логикой фильтрации. Используйте это при создании интерфейсов расширенного поиска, реализации механизмов бизнес-правил или построении рабочих процессов фильтрации данных с помощью вложенных групп условий и логики И/ИЛИ. Поддерживает управление правилами, пользовательский интерфейс с возможностью перетаскивания, сохранение состояния и широкие возможности настройки.
