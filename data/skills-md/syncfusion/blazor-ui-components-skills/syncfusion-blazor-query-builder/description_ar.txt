قم بتنفيذ مكون Syncfusion Blazor Query Builder لإنشاء واجهات استعلام ديناميكية وقابلة للتخصيص مع منطق تصفية معقد. استخدم هذا عند إنشاء واجهات بحث متقدمة، أو تنفيذ محركات قواعد العمل، أو إنشاء مهام سير عمل تصفية البيانات باستخدام مجموعات الشروط المتداخلة ومنطق AND/OR. يدعم إدارة القواعد، وواجهة مستخدم السحب والإفلات، واستمرارية الحالة، وخيارات التخصيص الشاملة.
