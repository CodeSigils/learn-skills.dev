Blazor 애플리케이션에서 컴팩트한 인라인 추세 시각화를 위해 Syncfusion Blazor Sparkline Charts를 구현합니다. 미니 차트, KPI 지표, 대시보드 스파크라인 또는 단어 크기의 데이터 시각화를 만들 때 이 기능을 사용하세요. 이 기술은 데이터 레이블, 마커, 특수 포인트(높음/낮음/음수), 범위 밴드, 도구 설명 및 모양 사용자 정의를 포함하여 선, 영역, 열, WinLoss 및 파이 스파크라인을 다룹니다. 대시보드, 인라인 추세가 포함된 데이터 테이블, 이메일 보고서, 컴팩트한 추세 표시기가 필요한 모바일 데이터 시각화 시나리오에 이상적입니다.
