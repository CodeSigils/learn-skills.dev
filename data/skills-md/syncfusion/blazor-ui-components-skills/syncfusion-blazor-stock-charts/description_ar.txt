تنفيذ مخطط أسهم Syncfusion Blazor (SfStockChart) لتصور البيانات المالية. استخدم هذا عند العمل مع مخططات الأسهم، أو شاشات الشموع اليابانية، أو بيانات OHLC، أو المؤشرات الفنية مثل SMA، وEMA، وMACD، وBollinger Bands. تغطي هذه المهارة محددات الفترة والتنقل عبر النطاق وتصور بيانات السلاسل الزمنية المالية في تطبيقات Blazor.
