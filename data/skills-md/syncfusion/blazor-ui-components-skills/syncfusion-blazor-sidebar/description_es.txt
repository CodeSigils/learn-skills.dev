Guía para implementar el componente Syncfusion Blazor Sidebar para barras laterales de navegación responsivas. Úselo al crear Blazor WebAssembly y aplicaciones web .NET 8 que necesitan barras laterales. Cubre la configuración, el control de apertura/cierre, el acoplamiento, la persistencia del estado, múltiples barras laterales y estilo completo. Incluye integración con ListView y TreeView.
