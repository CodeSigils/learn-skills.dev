Leitfaden zur Implementierung der Syncfusion Blazor Sidebar-Komponente für responsive Navigationsseitenleisten. Verwenden Sie dies, wenn Sie Blazor WebAssembly und .NET 8-Web-Apps erstellen, die Seitenleisten benötigen. Behandelt die Einrichtung, die Steuerung zum Öffnen/Schließen, das Andocken, die Statuspersistenz, mehrere Seitenleisten und das vollständige Design. Beinhaltet ListView- und TreeView-Integration.
