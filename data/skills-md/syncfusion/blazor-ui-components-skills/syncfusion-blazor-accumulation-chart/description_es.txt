Implemente el gráfico de acumulación de Syncfusion Blazor (SfAccumulationChart) para la visualización de datos proporcionales. Úselo al crear gráficos circulares, gráficos de anillos, gráficos de embudo o gráficos piramidales. Esta habilidad cubre etiquetas de datos, leyendas, información sobre herramientas, agrupación de sectores y visualizaciones de parte a todo en aplicaciones Blazor.
