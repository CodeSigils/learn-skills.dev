Внедрите диаграмму накопления Syncfusion Blazor (SfAccumulationChart) для пропорциональной визуализации данных. Use this when creating pie charts, doughnut charts, funnel charts, or pyramid charts. Этот навык охватывает метки данных, легенды, всплывающие подсказки, группировку фрагментов и визуализацию частей к целому в приложениях Blazor.
