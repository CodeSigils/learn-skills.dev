Implémentez le graphique d'accumulation Syncfusion Blazor (SfAccumulationChart) pour la visualisation proportionnelle des données. Utilisez-le lors de la création de diagrammes circulaires, de diagrammes en anneau, de diagrammes en entonnoir ou de diagrammes pyramidaux. Cette compétence couvre les étiquettes de données, les légendes, les info-bulles, le regroupement de tranches et les visualisations partie-tout dans les applications Blazor.
