Trigger per componenti Blazor, associazione dati, analisi OLAP, aggregazione, drill-down/drill-through, raggruppamento, filtro, formattazione condizionale, esportazioni (Excel/PDF/CSV) o grafici pivot. Solo Blazor, non React/Angular/Vue/JS.
