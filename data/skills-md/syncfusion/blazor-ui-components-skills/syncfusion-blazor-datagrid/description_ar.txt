يطبق Syncfusion Blazor DataGrid (SfGrid) لإجراء عمليات جدولية فعالة مثل الفرز والتصفية وترحيل الصفحات والتجميع والتحرير والتجميعات والمحاكاة الافتراضية وتجميع التحميل البطيء وتمديد الصفوف أو الأعمدة. استخدم هذه المهارة عند إنشاء مسارات عمل شبكة البيانات في تطبيقات Blazor Server أو WebAssembly أو Web App أو MAUI. يدعم تصدير Excel/PDF، والتمرير الظاهري أو غير المحدود، والقوالب القابلة للتخصيص، واستمرارية حالة الشبكة للحصول على سلوك شبكة بيانات متسق ومحسّن.
