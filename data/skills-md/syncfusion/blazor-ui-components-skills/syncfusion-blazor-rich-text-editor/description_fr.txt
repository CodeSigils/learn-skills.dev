Implémente l'éditeur de texte enrichi Syncfusion Blazor (SfRichTextEditor) à partir de Syncfusion.Blazor.RichTextEditor. Prend en charge les modes d'édition HTML, Markdown et IFrame. Utilisez ces compétences pour la configuration de la barre d'outils, l'insertion d'images/vidéo/audio, la gestion de tables, le nettoyage de collage, l'importation/exportation Word/PDF, l'accessibilité, la mondialisation, RTL et les scénarios d'outils de barre d'outils en ligne ou personnalisés dans les applications Blazor.
