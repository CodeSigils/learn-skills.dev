Реализует редактор форматированного текста Syncfusion Blazor (SfRichTextEditor) из Syncfusion.Blazor.RichTextEditor. Поддерживает режимы редактора HTML, Markdown и IFrame. Используйте эти навыки для настройки панели инструментов, вставки изображений/видео/аудио, управления таблицами, очистки вставки, импорта/экспорта Word/PDF, специальных возможностей, глобализации, RTL, а также встроенных или настраиваемых сценариев инструментов панели инструментов в приложениях Blazor.
