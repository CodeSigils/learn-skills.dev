Implements the Syncfusion Blazor Rich Text Editor (SfRichTextEditor) from Syncfusion.Blazor.RichTextEditor. Supports HTML, Markdown, and IFrame editor modes. Utilice estas habilidades para la configuración de la barra de herramientas, inserción de imágenes/videos/audio, administración de tablas, limpieza de pegado, importación/exportación de Word/PDF, accesibilidad, globalización, RTL y escenarios de herramientas de barra de herramientas personalizadas o en línea en aplicaciones Blazor.
