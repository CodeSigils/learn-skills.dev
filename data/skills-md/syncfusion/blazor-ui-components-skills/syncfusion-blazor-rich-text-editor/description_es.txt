Implementa el editor de texto enriquecido Syncfusion Blazor (SfRichTextEditor) de Syncfusion.Blazor.RichTextEditor. Admite los modos de edición HTML, Markdown e IFrame. Utilice estas habilidades para la configuración de la barra de herramientas, inserción de imágenes/videos/audio, administración de tablas, limpieza de pegado, importación/exportación de Word/PDF, accesibilidad, globalización, RTL y escenarios de herramientas de barra de herramientas personalizadas o en línea en aplicaciones Blazor.
