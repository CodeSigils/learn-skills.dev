Implemente Syncfusion Blazor RangeNavigator para la selección interactiva de rangos de datos y navegación de gráficos. Se activa cuando los usuarios mencionan el selector de rango, el navegador de rango, SfRangeNavigator, Syncfusion.Blazor.Charts.RangeNavigator, el filtrado de series temporales, el selector de rango de fechas para gráficos, el zoom de datos, la navegación con control deslizante, la selección de rango basada en el pulgar, el selector de período o la selección de rango de datos de gráficos para datos de gran tamaño.
