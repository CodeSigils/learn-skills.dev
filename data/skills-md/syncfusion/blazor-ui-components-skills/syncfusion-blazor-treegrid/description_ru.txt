Реализует Syncfusion Blazor TreeGrid (SfTreeGrid) для иерархических или самоссылающихся данных с расширяемыми узлами и вложенными структурами строк. Используйте этот навык при построении рабочих процессов в виде дерева в приложениях Blazor Server, WebAssembly, Web App или MAUI. Поддерживает привязку GraphQL, шаблоны, сортировку, фильтрацию, редактирование, разбиение по страницам, агрегирование, поиск, экспорт, виртуализацию, действия в буфере обмена и управление состоянием для богатого опыта работы с иерархическими данными.
