يطبق Syncfusion Blazor TreeGrid (SfTreeGrid) للبيانات الهرمية أو المرجعية الذاتية مع العقد القابلة للتوسيع وهياكل الصفوف المتداخلة. استخدم هذه المهارة عند إنشاء مسارات عمل العرض الشجري في Blazor Server، أو WebAssembly، أو Web App، أو تطبيقات MAUI. يدعم ربط GraphQL، والقوالب، والفرز، والتصفية، والتحرير، والترحيل، والتجميعات، والبحث، والتصدير، والمحاكاة الافتراضية، وإجراءات الحافظة، وإدارة الحالة لتجارب البيانات الهرمية الغنية.
