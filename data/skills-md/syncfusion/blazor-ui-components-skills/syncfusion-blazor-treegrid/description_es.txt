Implementa Syncfusion Blazor TreeGrid (SfTreeGrid) para datos jerárquicos o autorreferenciales con nodos expandibles y estructuras de filas anidadas. Utilice esta habilidad al crear flujos de trabajo de vista de árbol en aplicaciones Blazor Server, WebAssembly, Web App o MAUI. Admite enlace GraphQL, plantillas, clasificación, filtrado, edición, paginación, agregados, búsqueda, exportación, virtualización, acciones del portapapeles y administración de estado para experiencias ricas de datos jerárquicos.
