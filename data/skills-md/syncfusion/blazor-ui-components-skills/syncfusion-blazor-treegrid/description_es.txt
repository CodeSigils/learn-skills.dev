Implementa Syncfusion Blazor TreeGrid (SfTreeGrid) para datos jerárquicos o autorreferenciales con nodos expandibles y estructuras de filas anidadas. Use this skill when building tree‑view workflows in Blazor Server, WebAssembly, Web App, or MAUI applications. Admite enlace GraphQL, plantillas, clasificación, filtrado, edición, paginación, agregados, búsqueda, exportación, virtualización, acciones del portapapeles y administración de estado para experiencias ricas de datos jerárquicos.
