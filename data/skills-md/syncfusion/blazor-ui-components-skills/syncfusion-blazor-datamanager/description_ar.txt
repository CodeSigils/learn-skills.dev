يطبق Syncfusion Blazor SfDataManager للوصول إلى البيانات وربط البيانات وتكوين المحول في Blazor Server وWebAssembly وتطبيق الويب. يُستخدم عند ربط مكونات مثل SfGrid وSfDropDownList بمصادر البيانات المحلية أو البعيدة، أو اختيار المحولات (UrlAdaptor، أو ODataAdaptor، أو WebApiAdaptor، أو GraphQLAdaptor)، أو تنفيذ CRUD. يتضمن ربطًا مخصصًا باستخدام DataAdaptor وDataManagerRequest وDataOperations وحزمة Syncfusion.Blazor.Data.
