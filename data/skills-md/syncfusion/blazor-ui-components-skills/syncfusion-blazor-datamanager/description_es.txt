Implementa Syncfusion Blazor SfDataManager para el acceso a datos, el enlace de datos y la configuración del adaptador en Blazor Server, WebAssembly y Web App. Se utiliza al vincular componentes como SfGrid y SfDropDownList a fuentes de datos locales o remotas, elegir adaptadores (UrlAdaptor, ODataAdaptor, WebApiAdaptor, GraphQLAdaptor) o realizar CRUD. Incluye enlace personalizado mediante DataAdaptor, DataManagerRequest, DataOperations y el paquete Syncfusion.Blazor.Data.
