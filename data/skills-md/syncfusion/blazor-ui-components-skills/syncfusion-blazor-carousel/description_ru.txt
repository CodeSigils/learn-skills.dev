Руководство по реализации компонента Syncfusion Blazor Carousel для галерей изображений, витрин продуктов и слайдеров контента. Используйте, когда пользователь упоминает карусель, слайдер изображений, слайд-шоу, ротацию контента, галереи продуктов, вращающиеся баннеры, переходы между слайдами или необходимость отобразить несколько элементов в формате циклической презентации.
