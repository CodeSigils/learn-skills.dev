دليل لتطبيق مكون Syncfusion Blazor Carousel لمعارض الصور وعروض المنتجات وشرائح تمرير المحتوى. يُستخدم عندما يذكر المستخدم الرف الدائري، أو شريط تمرير الصور، أو عرض الشرائح، أو تدوير المحتوى، أو معارض المنتجات، أو الشعارات الدوارة، أو انتقالات الشرائح، أو يحتاج إلى عرض عناصر متعددة بتنسيق عرض تقديمي دوري.
