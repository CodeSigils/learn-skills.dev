Внедрите элемент управления Syncfusion Blazor Breadcrumb (SfBreadcrumb) для иерархической навигации. Используйте это при построении навигационных цепочек, автоматическом создании элементов из URL-адресов или управлении динамическими последовательностями навигации. Этот навык охватывает режимы переполнения, шаблоны элементов, настройку значков и конфигурации адаптивного макета.
