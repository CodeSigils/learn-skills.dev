Implemente el control Syncfusion Blazor Breadcrumb (SfBreadcrumb) para la navegación jerárquica. Úselo al crear rutas de navegación, generar automáticamente elementos a partir de URL o administrar secuencias de navegación dinámicas. Esta habilidad cubre modos de desbordamiento, plantillas de elementos, personalización de íconos y configuraciones de diseño responsivos.
