Реализует компонент диаграммы Syncfusion Blazor HeatMap для многомерной визуализации данных с использованием сеток с цветовой кодировкой. Используйте это при работе с тепловыми картами, матрицами данных, отображениями корреляций или вариантами пузырьковых тепловых карт. Этот навык охватывает установку, привязку данных, настройку осей, цветовые палитры, легенды, всплывающие подсказки и специальные возможности.
