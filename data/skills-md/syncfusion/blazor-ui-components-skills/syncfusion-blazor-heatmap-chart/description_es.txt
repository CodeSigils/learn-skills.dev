Implementa el componente Syncfusion Blazor HeatMap Chart para visualización de datos multidimensionales mediante cuadrículas codificadas por colores. Utilícelo cuando trabaje con mapas de calor, matrices de datos, visualizaciones de correlación o variantes de mapas de calor de burbujas. Esta habilidad cubre la instalación, el enlace de datos, la configuración de ejes, las paletas de colores, las leyendas, la información sobre herramientas y las funciones de accesibilidad.
