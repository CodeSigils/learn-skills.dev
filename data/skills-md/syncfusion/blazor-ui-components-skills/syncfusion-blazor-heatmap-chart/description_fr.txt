Implémente le composant Syncfusion Blazor HeatMap Chart pour la visualisation de données multidimensionnelles à l'aide de grilles à code couleur. Utilisez-le lorsque vous travaillez avec des cartes thermiques, des matrices de données, des affichages de corrélation ou des variantes de cartes thermiques à bulles. Cette compétence couvre l'installation, la liaison de données, la configuration des axes, les palettes de couleurs, les légendes, les info-bulles et les fonctionnalités d'accessibilité.
