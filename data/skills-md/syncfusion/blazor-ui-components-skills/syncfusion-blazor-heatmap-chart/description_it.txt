Implementa il componente grafico Syncfusion Blazor HeatMap per la visualizzazione di dati multidimensionali utilizzando griglie codificate a colori. Utilizzalo quando lavori con mappe di calore, matrici di dati, visualizzazioni di correlazione o varianti di mappe di calore a bolle. Questa competenza copre l'installazione, l'associazione dei dati, la configurazione degli assi, le tavolozze dei colori, le legende, le descrizioni comandi e le funzionalità di accessibilità.
