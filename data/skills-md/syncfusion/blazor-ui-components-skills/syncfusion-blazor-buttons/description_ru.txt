Реализуйте компоненты кнопок Syncfusion Blazor, включая Button, ButtonGroup, CheckBox, Chip, DropdownMenu, FloatingActionButton, ProgressButton, SpeedDial, SplitButton и ToggleSwitch. Используйте этот навык при работе с компонентами, связанными с кнопками, в приложениях Blazor. Охватывает установку, настройку, стиль, доступность, обработку событий и расширенные функции для всех типов компонентов кнопок.
