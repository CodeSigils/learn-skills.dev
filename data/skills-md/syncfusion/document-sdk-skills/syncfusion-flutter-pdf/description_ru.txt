Создавайте PDF-документы и управляйте ими с помощью библиотеки PDF Syncfusion Flutter. Поддерживает два режима — генерировать код Dart для пользовательского проекта Flutter или предоставлять фрагменты кода. Используйте, когда пользователь упоминает создание PDF-файла, рисование, таблицы, изображения, текст, аннотации, закладки, шифрование или Syncfusion Flutter PDF.
