Создавайте, редактируйте и конвертируйте книги Excel (.xlsx/.xls) с помощью Syncfusion XlsIO. Поддерживает два режима — генерировать код C# для проекта пользователя или выполнять временный скрипт CSX. Используйте, когда пользователь упоминает Excel, xlsx, книгу, маркеры шаблонов, Syncfusion XlsIO или преобразование PDF.
