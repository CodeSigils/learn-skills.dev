Créez, modifiez et convertissez des documents Markdown (.md) à l'aide de Syncfusion Markdown. Prend en charge deux modes : générer du code C# pour le projet de l'utilisateur ou exécuter une tâche via un script CSX. À utiliser lorsque l'utilisateur mentionne le démarque, les fichiers .md, la génération de démarque, Syncfusion Markdown.
