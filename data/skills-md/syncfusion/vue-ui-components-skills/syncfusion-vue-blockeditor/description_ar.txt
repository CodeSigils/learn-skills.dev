قم بتنفيذ مكون Syncfusion Vue BlockEditor لتحرير المحتوى المستند إلى الكتلة باستخدام النص المنسق والصور والجداول والكتل التفاعلية. استخدم هذه المهارة دائمًا عندما يحتاج المستخدم إلى محرر الكتل، أو محرر نمط الفكرة، أو كتل المحتوى، أو كتل النص المنسق، أو محرر المستندات مع الكتل، أو محرر المحتوى المعياري، أو يذكر @syncfusion/ej2-vue-blockeditor، أو BlockEditor، أو التحرير القائم على الكتلة، أو محرر إدارة المحتوى. يغطي جميع أنواع الكتل الـ 14، وأنواع المحتوى الخمسة، والسحب والإفلات، والقوائم، والأساليب، والأحداث، وأنماط واجهة برمجة التطبيقات للتركيب.
