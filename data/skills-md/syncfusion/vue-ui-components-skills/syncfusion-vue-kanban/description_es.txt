Implementa el componente Syncfusion Vue Kanban para interfaces de usuario de tableros de tareas basadas en columnas con arrastrar y soltar, carriles, restricciones WIP y desplazamiento virtual. Úselo al crear tableros de sprint, tableros kanban, rastreadores de flujo de trabajo o cualquier interfaz de usuario de administración de tareas basada en columnas. Cubre enlace de datos (local y remoto), tarjetas, columnas, diálogo, eventos y accesibilidad.
