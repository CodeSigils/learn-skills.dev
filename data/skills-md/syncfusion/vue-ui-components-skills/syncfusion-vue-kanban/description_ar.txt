ينفذ مكون Syncfusion Vue Kanban لواجهات مستخدم لوحة المهام المستندة إلى الأعمدة مع السحب والإسقاط، والممرات، وقيود WIP، والتمرير الظاهري. استخدم هذا عند إنشاء لوحات السباق السريع، أو لوحات كانبان، أو أدوات تتبع سير العمل، أو أي واجهة مستخدم لإدارة المهام قائمة على الأعمدة. يغطي ربط البيانات (المحلية والبعيدة)، والبطاقات، والأعمدة، ومربعات الحوار، والأحداث، وإمكانية الوصول.
