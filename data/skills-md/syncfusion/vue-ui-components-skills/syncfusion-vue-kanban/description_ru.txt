Реализует компонент Syncfusion Vue Kanban для пользовательских интерфейсов доски задач на основе столбцов с перетаскиванием, дорожками для плавания, ограничениями незавершенного производства и виртуальной прокруткой. Используйте это при создании досок спринта, досок канбана, трекеров рабочих процессов или любого пользовательского интерфейса управления задачами на основе столбцов. Охватывает привязку данных (локальных и удаленных), карточки, столбцы, диалоги, события и специальные возможности.
