Implémente le composant Syncfusion Vue Kanban pour les interfaces utilisateur de tableaux de tâches basées sur des colonnes avec glisser-déposer, couloirs, contraintes WIP et défilement virtuel. Utilisez-le lors de la création de tableaux de sprint, de tableaux Kanban, de suivis de flux de travail ou de toute interface utilisateur de gestion de tâches basée sur des colonnes. Couvre la liaison de données (locale et distante), les cartes, les colonnes, les boîtes de dialogue, les événements et l'accessibilité.
