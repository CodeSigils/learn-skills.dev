قم بإنشاء وتخصيص الباركود ورمز الاستجابة السريعة ومكونات مصفوفة البيانات باستخدام Syncfusion Vue Barcode Generator. استخدم هذه المهارة عند تنفيذ إنشاء الرمز الشريطي وإنشاء رمز الاستجابة السريعة وأكواد مصفوفة البيانات ووظيفة التصدير وتصميم الرمز الشريطي. يغطي مكونات BarcodeGenerator وQRCodeGenerator وDataMatrixGenerator الخاصة بـ Syncfusion لتطبيقات Vue (Composition API وOptions API).
