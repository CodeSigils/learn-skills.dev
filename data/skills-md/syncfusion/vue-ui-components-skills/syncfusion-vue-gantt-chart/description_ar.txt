قم بتنفيذ Syncfusion Vue Gantt Chart (@syncfusion/ej2-vue-gantt) لـ Vue 2 وVue 3. استخدم هذا عند إنشاء واجهات جدولة المشروع مع الجداول الزمنية للمهام والتبعيات وإدارة الموارد. يغطي ربط البيانات، وجدولة المهام، والأعمدة، والتصفية، والتحرير، وتصدير Excel/PDF، والمسار الحرج، وتخصيص الموارد. يدعم ejs-gantt وGanttComponent.
