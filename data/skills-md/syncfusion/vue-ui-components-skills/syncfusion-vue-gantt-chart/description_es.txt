Implemente el diagrama de Gantt de Syncfusion Vue (@syncfusion/ej2-vue-gantt) para Vue 2 y Vue 3. Utilícelo al crear interfaces de programación de proyectos con cronogramas de tareas, dependencias y gestión de recursos. Cubre el enlace de datos, la programación de tareas, las columnas, el filtrado, la edición, la exportación a Excel/PDF, la ruta crítica y la asignación de recursos. Admite ejs-gantt y GanttComponent.
