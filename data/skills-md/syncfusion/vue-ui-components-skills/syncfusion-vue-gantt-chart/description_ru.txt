Внедрите диаграмму Syncfusion Vue Gantt (@syncfusion/ej2-vue-gantt) для Vue 2 и Vue 3. Используйте ее при создании интерфейсов планирования проектов со сроками выполнения задач, зависимостями и управлением ресурсами. Охватывает привязку данных, планирование задач, столбцы, фильтрацию, редактирование, экспорт Excel/PDF, критический путь и распределение ресурсов. Поддерживает ejs-gantt и GanttComponent.
