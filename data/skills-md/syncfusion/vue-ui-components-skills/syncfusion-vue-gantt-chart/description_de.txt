Implementieren Sie das Syncfusion Vue Gantt-Diagramm (@syncfusion/ej2-vue-gantt) für Vue 2 und Vue 3. Verwenden Sie dies beim Erstellen von Projektplanungsschnittstellen mit Aufgabenzeitplänen, Abhängigkeiten und Ressourcenmanagement. Deckt Datenbindung, Aufgabenplanung, Spalten, Filterung, Bearbeitung, Excel/PDF-Export, kritischen Pfad und Ressourcenzuweisung ab. Unterstützt ejs-gantt und GanttComponent.
