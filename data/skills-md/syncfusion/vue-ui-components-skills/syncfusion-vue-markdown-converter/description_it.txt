Implementa Syncfusion Vue Markdown Converter per convertire il testo Markdown in HTML pulito. Utilizzalo quando converti Markdown in HTML in Vue, integri un'anteprima Markdown live, configuri GFM o opzioni di interruzione di riga o lavori con MarkdownConverter.toHtml() e MarkdownConverterOptions. Questa competenza copre il pacchetto @syncfusion/ej2-markdown-converter e l'integrazione di Markdown Editor con anteprima HTML affiancata.
