Implemente Syncfusion Vue Markdown Converter para convertir texto de Markdown en HTML limpio. Úselo al convertir Markdown a HTML en Vue, integrar una vista previa de Markdown en vivo, configurar GFM o opciones de salto de línea, o trabajar con MarkdownConverter.toHtml() y MarkdownConverterOptions. Esta habilidad cubre el paquete @syncfusion/ej2-markdown-converter y la integración del Markdown Editor con vista previa HTML en paralelo.
