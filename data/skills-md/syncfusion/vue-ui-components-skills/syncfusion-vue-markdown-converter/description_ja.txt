Syncfusion Vue Markdown Converter を実装して、Markdown テキストをクリーンな HTML に変換します。これは、Vue で Markdown を HTML に変換する場合、ライブ Markdown プレビューを統合する場合、GFM または改行オプションを構成する場合、または MarkdownConverter.toHtml() および MarkdownConverterOptions を操作する場合に使用します。このスキルでは、@syncfusion/ej2-markdown-converter パッケージと、Markdown Editor のサイドバイサイド HTML プレビューとの統合について説明します。
