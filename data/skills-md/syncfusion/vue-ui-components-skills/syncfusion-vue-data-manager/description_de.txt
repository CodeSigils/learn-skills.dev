Implementiert Syncfusion Vue DataManager für lokale/Remote-Bindung, CRUD, Abfragen, Caching und Middleware. Unterstützt JsonAdaptor, ODataAdaptor, ODataV4Adaptor, UrlAdaptor, WebApiAdaptor, WebMethodAdaptor, RemoteSaveAdaptor, GraphQLAdaptor, CustomDataAdaptor und CustomAdaptor. Behandelt Abfrageklasse, Filterung, Sortierung, Paging, Gruppierung, Persistenz, Offline-Modus, Caching und Fehlerbehandlung.
