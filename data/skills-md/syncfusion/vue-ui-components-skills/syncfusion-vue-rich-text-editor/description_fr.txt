Implémente l'éditeur de texte riche Syncfusion Vue (ejs-richtexteditor) prenant en charge les modes d'édition HTML (WYSIWYG) et Markdown via l'API editorMode de @syncfusion/ej2-vue-richtexteditor. Utilisez cette compétence pour la personnalisation de la barre d'outils, le téléchargement d'images, le nettoyage du collage, l'édition en ligne, l'intégration de l'assistant IA, le menu slash, le sélecteur d'emoji et la prise en charge des mentions dans les applications Vue.
