Реализует редактор расширенного текста Syncfusion Vue (ejs-richtexteditor), поддерживающий режимы редактирования HTML (WYSIWYG) и Markdown через API editorMode из @syncfusion/ej2-vue-richtexteditor. Используйте этот навык для настройки панели инструментов, загрузки изображений, очистки вставки, встроенного редактирования, интеграции помощника AI, косого меню, выбора смайлов и поддержки упоминаний в приложениях Vue.
