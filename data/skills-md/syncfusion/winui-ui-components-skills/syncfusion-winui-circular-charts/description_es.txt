Implemente gráficos circulares de Syncfusion WinUI (SfCircularChart) con visualizaciones circulares y de anillos para visualización de datos proporcionales. Utilícelo cuando trabaje con gráficos circulares, gráficos circulares o gráficos de anillos en aplicaciones WinUI. Esta habilidad cubre la configuración de series de gráficos, etiquetas de datos, leyendas, información sobre herramientas, selección de segmentos, explosión de segmentos y personalización visual para visualizaciones circulares interactivas.
