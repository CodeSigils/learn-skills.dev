Реализует элемент управления Syncfusion WinUI Kanban (SfKanban) для визуализации рабочего процесса и управления задачами. Используйте это при создании досок Kanban, гибкого отслеживания проектов или систем управления рабочими процессами в приложениях WinUI. Этот навык охватывает карточки, столбцы, дорожки для плавания, ограничения незавершенного производства, перетаскивание, рабочие процессы, сортировку, события и настройку.
