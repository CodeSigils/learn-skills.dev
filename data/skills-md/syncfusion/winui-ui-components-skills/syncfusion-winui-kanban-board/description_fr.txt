Implémente le contrôle Syncfusion WinUI Kanban (SfKanban) pour la visualisation du flux de travail et la gestion des tâches. Utilisez-le lors de la création de tableaux Kanban, de suivi de projet agile ou de systèmes de gestion de flux de travail dans les applications WinUI. Cette compétence couvre les cartes, les colonnes, les couloirs, les limites WIP, le glisser-déposer, les flux de travail, le tri, les événements et la personnalisation.
