Guía para implementar el control Syncfusion WinUI ComboBox (SfComboBox) para selección única y múltiple con filtrado y visualización de tokens. Utilícelo cuando trabaje con menús desplegables con capacidad de búsqueda, cuadros combinados de selección múltiple o cuadros combinados editables en aplicaciones WinUI. Esta habilidad cubre modos de selección, enlace de datos, filtrado, agrupación y plantillas de elementos personalizados.
