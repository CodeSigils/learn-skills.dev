Implémente le contrôle Syncfusion WinUI RangeSlider (SfRangeSlider) pour la sélection de plage dans les applications de bureau. Utilisez-le lorsque vous travaillez avec des sélecteurs de plage, des curseurs à deux pouces ou des interfaces de sélection de plage numérique. Cette compétence couvre la configuration, les étiquettes, les graduations, les séparateurs, la personnalisation des pistes, le style des pouces, les info-bulles et la gestion des valeurs pour la sélection de plage interactive dans les applications WinUI.
