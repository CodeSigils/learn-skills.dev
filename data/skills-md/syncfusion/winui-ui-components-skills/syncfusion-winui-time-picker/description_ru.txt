Реализует элемент управления Syncfusion WinUI TimePicker (SfTimePicker) для ввода и выбора времени в настольных приложениях. Используйте это при создании элементов управления вводом времени, интерфейсов выбора времени или счетчиков раскрывающегося списка времени. Этот навык охватывает ограничения по времени, форматирование времени, настройку раскрывающегося счетчика и выбор времени для планирования и сценариев встреч в приложениях WinUI.
