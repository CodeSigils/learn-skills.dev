Implemente los gráficos piramidales de Syncfusion WinUI (SfPyramidChart) para visualizar datos proporcionales jerárquicos. Utilícelo cuando trabaje con gráficos piramidales, visualización jerárquica o visualización de datos proporcionales en aplicaciones WinUI. Esta habilidad cubre el enlace de datos, la configuración de leyendas, la explosión de segmentos, información sobre herramientas, etiquetas de datos, interacciones de selección y estilos personalizados con paletas y degradados.
