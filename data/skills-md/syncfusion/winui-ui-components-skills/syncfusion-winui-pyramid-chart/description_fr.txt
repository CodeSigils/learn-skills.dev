Implémentez des graphiques pyramidaux Syncfusion WinUI (SfPyramidChart) pour visualiser des données proportionnelles hiérarchiques. Utilisez-le lorsque vous travaillez avec des graphiques pyramidaux, une visualisation hiérarchique ou un affichage de données proportionnelles dans les applications WinUI. Cette compétence couvre la liaison de données, la configuration des légendes, l'explosion des segments, les info-bulles, les étiquettes de données, les interactions de sélection et le style personnalisé avec des palettes et des dégradés.
