Implementa gráficos cartesianos de Syncfusion WinUI (SfCartesianChart) para visualización de datos en aplicaciones WinUI. Utilícelo cuando trabaje con gráficos de columnas, líneas, barras, áreas o financieros (OHLC, Vela). Esta habilidad cubre la configuración de ejes, leyendas, información sobre herramientas, zoom/panorámica, etiquetas de datos y series rápidas de alto rendimiento para grandes conjuntos de datos.
