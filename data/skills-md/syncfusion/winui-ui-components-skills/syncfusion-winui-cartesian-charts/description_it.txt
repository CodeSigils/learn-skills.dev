Implementa Syncfusion WinUI Cartesian Charts (SfCartesianChart) per la visualizzazione dei dati nelle applicazioni WinUI. Utilizzalo quando lavori con grafici a colonne, a linee, a barre, ad area o finanziari (OHLC, Candela). Questa competenza copre la configurazione degli assi, le legende, le descrizioni comandi, lo zoom/panoramica, le etichette dei dati e le serie veloci ad alte prestazioni per set di dati di grandi dimensioni.
