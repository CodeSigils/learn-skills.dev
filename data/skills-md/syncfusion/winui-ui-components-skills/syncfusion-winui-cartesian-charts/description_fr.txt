Implémente les graphiques cartésiens Syncfusion WinUI (SfCartesianChart) pour la visualisation des données dans les applications WinUI. Utilisez-le lorsque vous travaillez avec des graphiques en colonnes, en lignes, à barres, en aires ou financiers (OHLC, Candle). Cette compétence couvre la configuration des axes, les légendes, les info-bulles, le zoom/panoramique, les étiquettes de données et les séries rapides hautes performances pour les grands ensembles de données.
