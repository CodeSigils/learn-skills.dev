Реализует декартовы диаграммы Syncfusion WinUI (SfCartesianChart) для визуализации данных в приложениях WinUI. Используйте это при работе со столбчатыми, линейными, столбчатыми, областными или финансовыми диаграммами (OHLC, Candle). Этот навык охватывает конфигурацию осей, легенды, всплывающие подсказки, масштабирование/панорамирование, метки данных и высокопроизводительные быстрые серии для больших наборов данных.
