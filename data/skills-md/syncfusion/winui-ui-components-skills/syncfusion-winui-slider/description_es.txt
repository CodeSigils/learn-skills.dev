Implementa el control Syncfusion WinUI Slider (SfSlider) para la selección de valores numéricos en aplicaciones de escritorio. Utilícelo cuando trabaje con controles deslizantes, selectores de rango, selectores de valores o controles de rango interactivos. Esta habilidad cubre la configuración del control deslizante, ticks, etiquetas, información sobre herramientas, selección de valores y personalización para aplicaciones WinUI.
