Guía para implementar el control AvatarView de Syncfusion WinUI para mostrar avatares de usuario e imágenes de perfil. Úselo al implementar perfiles de usuario, listas de contactos o interfaces de chat que requieran representación visual del usuario en aplicaciones WinUI. Esta habilidad cubre la visualización de iniciales, avatares de imágenes, avatares de grupo y personajes de avatar predefinidos.
