Implementa el control Syncfusion WinUI DatePicker (SfDatePicker) para la entrada y selección de fechas en aplicaciones de escritorio. Úselo al crear controles de entrada de fechas, selectores desplegables de calendario o interfaces de selección de fechas. Esta habilidad cubre restricciones de fecha, formato de fecha, tipos de calendario, menús desplegables, localización y fechas restringidas para aplicaciones WinUI.
