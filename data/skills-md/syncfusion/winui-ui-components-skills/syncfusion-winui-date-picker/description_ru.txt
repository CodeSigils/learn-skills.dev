Реализует элемент управления Syncfusion WinUI DatePicker (SfDatePicker) для ввода и выбора даты в настольных приложениях. Используйте это при создании элементов управления вводом даты, средств выбора раскрывающегося списка календаря или интерфейсов выбора даты. Этот навык охватывает ограничения даты, форматирование даты, типы календаря, счетчики раскрывающихся списков, локализацию и даты отключения для приложений WinUI.
