Реализует элемент управления Syncfusion WinUI Linear Gauge (SfLinearGauge) для визуализации данных в настольных приложениях. Используйте это при создании индикаторов прогресса, дисплеев температуры или датчиков измерения данных в WinUI. Этот навык охватывает настройку оси, типы указателей (полоса и фигура), настройку диапазона и анимацию.
