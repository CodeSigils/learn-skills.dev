Руководство по реализации элемента управления автозаполнением WinUI Syncfusion (SfAutoComplete) для создания раскрывающихся списков с возможностью поиска с одним или несколькими вариантами выбора, фильтрации предложений и настраиваемого отображения токенов. Используйте этот навык при реализации функции поиска по мере ввода, автозаполнения раскрывающихся списков с множественным выбором, систем тегов с отображением токенов/чипов или отфильтрованных окон предложений в приложениях WinUI.
