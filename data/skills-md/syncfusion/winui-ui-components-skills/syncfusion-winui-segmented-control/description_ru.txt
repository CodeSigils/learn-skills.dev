Руководство по реализации сегментированного элемента управления Syncfusion WinUI для создания взаимоисключающих селекторов опций. Используйте этот навык при реализации сегментированных элементов управления, средств выбора сегментов, средств выбора вкладок или взаимоисключающих средств выбора опций в приложениях WinUI. Необходим для навигации на основе сегментов, переключения фильтров, переключателей представлений, групп кнопок с одним выбором или любого сценария, требующего взаимоисключающего выбора из двух+ вариантов в WinUI.
