Guide d'implémentation du contrôle segmenté Syncfusion WinUI pour créer des sélecteurs d'options mutuellement exclusifs. Utilisez cette compétence lors de l’implémentation de contrôles segmentés, de sélecteurs de segments, de sélecteurs d’onglets ou de sélecteurs d’options mutuellement exclusifs dans les applications WinUI. Indispensable pour la navigation basée sur les segments, les bascules de filtres, les sélecteurs de vue, les groupes de boutons avec sélection unique ou tout scénario nécessitant une sélection mutuellement exclusive parmi plus de 2 options dans WinUI.
