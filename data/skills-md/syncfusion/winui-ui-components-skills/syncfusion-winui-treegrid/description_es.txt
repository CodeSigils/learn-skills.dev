Guía para implementar componentes de Syncfusion WinUI TreeGrid (SfTreeGrid) para mostrar datos jerárquicos o autorrelacionales. Utilice esta habilidad cuando trabaje con cuadrículas estructuradas en árbol, relaciones de datos padre-hijo o filas de cuadrícula expandibles. Cubre las características de TreeGrid para organigramas, pantallas de sistemas de archivos y representación de datos de varios niveles en aplicaciones WinUI.
