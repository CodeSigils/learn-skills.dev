Руководство по реализации компонентов Syncfusion WinUI TreeGrid (SfTreeGrid) для отображения иерархических или самореляционных данных. Используйте этот навык при работе с сетками с древовидной структурой, связями данных родитель-потомок или расширяемыми строками сетки. Охватывает функции TreeGrid для организационных диаграмм, отображения файловой системы и многоуровневого представления данных в приложениях WinUI.
