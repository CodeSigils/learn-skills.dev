Guida per l'implementazione dei componenti Syncfusion WinUI TreeGrid (SfTreeGrid) per la visualizzazione di dati gerarchici o auto-relazionali. Utilizza questa capacità quando lavori con griglie strutturate ad albero, relazioni dati padre-figlio o righe di griglia espandibili. Copre le funzionalità TreeGrid per organigrammi, visualizzazioni di file system e rappresentazione di dati multilivello nelle applicazioni WinUI.
