Реализует элемент управления Syncfusion WinUI CalendarDateRangePicker (SfCalendarDateRangePicker) для выбора диапазонов дат в настольных приложениях. Используйте это при создании средств выбора диапазона дат, календарей выбора диапазона или интерфейсов ввода даты начала/окончания. Этот навык охватывает выбор диапазона, предустановленные диапазоны, закрытые даты, ограничения дат, номера недель, локализацию и настройку календаря для приложений WinUI.
