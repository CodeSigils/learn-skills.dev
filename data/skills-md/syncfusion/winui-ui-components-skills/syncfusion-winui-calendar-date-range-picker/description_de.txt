Implementiert das Syncfusion WinUI CalendarDateRangePicker (SfCalendarDateRangePicker)-Steuerelement zum Auswählen von Datumsbereichen in Desktopanwendungen. Verwenden Sie dies, wenn Sie Datumsbereichsauswahlen, Bereichsauswahlkalender oder Eingabeschnittstellen für Start-/Enddatum erstellen. Diese Fertigkeit umfasst Bereichsauswahl, voreingestellte Bereiche, Sperrdaten, Datumsbeschränkungen, Wochennummern, Lokalisierung und Kalenderanpassung für WinUI-Anwendungen.
