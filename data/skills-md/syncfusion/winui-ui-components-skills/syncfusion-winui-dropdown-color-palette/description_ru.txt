Руководство по реализации элемента управления раскрывающейся цветовой палитрой WinUI Syncfusion для выбора цвета в настольных приложениях Windows. Используйте этот навык при реализации раскрывающихся списков выбора цвета, поддержки цветов темы, пользовательских цветовых палитр, кнопок разделенного режима или диалогового окна «Дополнительные цвета». Охватывает настройку раскрывающегося списка, структуру палитры и взаимодействие пользовательского интерфейса на основе цветов.
