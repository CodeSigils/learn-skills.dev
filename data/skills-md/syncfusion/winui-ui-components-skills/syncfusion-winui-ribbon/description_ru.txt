Руководство по реализации элемента управления ленты WinUI Syncfusion (SfRibbon) для организации команд приложения по вкладкам и группам, аналогично Microsoft Office. Используйте это при работе с навигацией на основе ленты, панелью быстрого доступа (QAT) или закулисными меню. Этот навык охватывает настройку ленты, настройку вкладок и групп, навигацию с помощью клавиатуры (KeyTip) и всплывающие подсказки ScreenTip.
