Implementa il controllo Syncfusion WinUI Calendar (SfCalendar) per la selezione della data nelle applicazioni desktop. Utilizzalo quando crei selettori di date, interfacce di selezione di date (singole, multiple o intervallo), navigazione mese/anno o visualizzazioni di calendario. Questa competenza copre la configurazione del calendario, le restrizioni sulle date, le date di blackout, i numeri delle settimane, la localizzazione e la personalizzazione per le applicazioni desktop Windows.
