Реализует элемент управления Syncfusion WinUI Calendar (SfCalendar) для выбора даты в настольных приложениях. Используйте это при создании средств выбора даты, интерфейсов выбора даты (одна, несколько или диапазон), навигации по месяцу/году или представлений календаря. Этот навык охватывает настройку календаря, ограничения дат, закрытые даты, номера недель, локализацию и настройку настольных приложений Windows.
