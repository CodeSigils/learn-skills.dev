Руководство по реализации элемента управления Syncfusion WinUI Rating (SfRating) для сбора оценок пользователей и отзывов в числовой шкале. Используйте это при реализации звездных рейтингов, отзывов пользователей или сбора отзывов в WinUI 3. Этот навык охватывает режимы точности (полный, половинный, точный), пользовательские шаблоны, всплывающие подсказки и отображение рейтинга только для чтения.
