Leitfaden zur Implementierung des Syncfusion WinUI Rating (SfRating)-Steuerelements zum Sammeln von Benutzerbewertungen und Feedback auf einer numerischen Skala. Verwenden Sie dies, wenn Sie Sternebewertungen, Benutzerrezensionen oder die Erfassung von Feedback in WinUI 3 implementieren. Dieser Skill deckt Präzisionsmodi (voll, halb, genau), benutzerdefinierte Vorlagen, Tooltips und die schreibgeschützte Bewertungsanzeige ab.
