Implementieren Sie Syncfusion WPF GroupBar (Navigationsbereich) für eine erweiterbare Kategoriennavigation im Outlook-Stil. Verwenden Sie dies, wenn Sie einen Navigationsbereich, eine Gruppenleiste, eine Seitenleiste mit reduzierbaren Abschnitten oder eine Navigation im Stapelmodus in WPF erstellen. Behandelt Elementhierarchie, visuelle Modi, Datenbindung, Drag-and-Drop, Ausrichtung, Verhalten, Erscheinungsbild und Themen.
