Implémentez Syncfusion WPF GroupBar (volet de navigation) pour la navigation dans les catégories extensibles de style Outlook. Utilisez-le lors de la création d'un volet de navigation, d'une GroupBar, d'une barre latérale avec des sections pliables ou d'une navigation en mode pile dans WPF. Couvre la hiérarchie des éléments, les modes visuels, la liaison de données, le glisser-déposer, l'orientation, le comportement, l'apparence et les thèmes.
