Implementa el control Syncfusion WPF DateTimeEdit (DateTimePicker) para la selección de fecha y hora con compatibilidad con calendario/reloj desplegable. Utilícelo al agregar selectores de fecha y hora, entradas de fecha y hora enmascaradas o controles de selección de fecha y hora en aplicaciones WPF. Cubre el enlace DateTime, la edición de máscara/forma libre, el formato de patrones, la localización de CultureInfo, las vistas desplegables, las restricciones de rango de fechas, las fechas restringidas, el manejo de valores nulos, las marcas de agua y la temática con SfSkinManager.
