Внедрите Syncfusion WPF TaskBar для сгруппированных панелей задач в стиле Windows Explorer со сворачиваемыми разделами TaskBarItem. Используйте это при создании сгруппированных складных панелей, боковых панелей в стиле Windows XP или расширяемых разделов панели действий в WPF. Охватывает TaskBarItem, GroupMargin, GroupPadding, GroupWidth, GroupOrientation, IsOpened, ButtonSize и настройку скорости анимации.
