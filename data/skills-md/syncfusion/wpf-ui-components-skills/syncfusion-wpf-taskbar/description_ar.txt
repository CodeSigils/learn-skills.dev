قم بتنفيذ لوحات المهام المجمعة على نمط Syncfusion WPF لنظام التشغيل Windows Explorer مع أقسام TaskBarItem القابلة للطي. استخدم هذا عند إنشاء لوحات مجمعة قابلة للطي أو أشرطة جانبية بنمط Windows XP أو أقسام لوحة إجراءات قابلة للتوسيع في WPF. يغطي TaskBarItem وGroupMargin وGroupPadding وGroupWidth وGroupOrientation وIsOpened وButtonSize وتكوين سرعة الرسوم المتحركة.
