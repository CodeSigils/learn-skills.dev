Implementieren Sie Syncfusion WPF TaskBar für gruppierte Aufgabenbereiche im Windows Explorer-Stil mit zusammenklappbaren TaskBarItem-Abschnitten. Verwenden Sie dies, wenn Sie gruppierte reduzierbare Bedienfelder, Seitenleisten im Windows XP-Stil oder erweiterbare Aktionsfeldabschnitte in WPF erstellen. Behandelt die Konfiguration von TaskBarItem, GroupMargin, GroupPadding, GroupWidth, GroupOrientation, IsOpened, ButtonSize und Animationsgeschwindigkeit.
