Implementiert den Syncfusion WPF Smart Text Editor (SfSmartTextEditor), ein KI-gestütztes mehrzeiliges Eingabesteuerelement mit intelligenter Textvervollständigung. Verwenden Sie dies, wenn Sie intelligente Texteditoren, KI-gestützte Texteingabe oder prädiktive Textvorschläge in WPF-Anwendungen implementieren. Das Steuerelement bietet kontextbezogene Tippunterstützung durch die Integration mit KI-Diensten wie Azure OpenAI, OpenAI, Ollama, Claude, Gemini, Groq und DeepSeek. Zu den Funktionen gehören zwei Anzeigemodi für Vorschläge (Inline/Popup), benutzerdefinierte Phrasenbibliotheken für Offline-Vorschläge, Volltextanpassung und umfassende Befehlsverarbeitung für die Workflow-Integration.
