Implements Syncfusion WPF Smart Text Editor (SfSmartTextEditor), an AI-powered multiline input control with intelligent text completion. Use this when implementing smart text editors, AI-powered text input, or predictive text suggestions in WPF applications. El control proporciona asistencia para escribir según el contexto mediante la integración con servicios de inteligencia artificial, incluidos Azure OpenAI, OpenAI, Ollama, Claude, Gemini, Groq y DeepSeek. Las características incluyen modos de visualización de sugerencias duales (en línea/emergente), bibliotecas de frases personalizadas para sugerencias sin conexión, personalización de texto completo y manejo integral de comandos para la integración del flujo de trabajo.
