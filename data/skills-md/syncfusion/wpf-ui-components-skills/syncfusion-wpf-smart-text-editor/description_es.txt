Implementa Syncfusion WPF Smart Text Editor (SfSmartTextEditor), un control de entrada multilínea impulsado por IA con finalización de texto inteligente. Úselo al implementar editores de texto inteligentes, entrada de texto basada en IA o sugerencias de texto predictivo en aplicaciones WPF. El control proporciona asistencia para escribir según el contexto mediante la integración con servicios de inteligencia artificial, incluidos Azure OpenAI, OpenAI, Ollama, Claude, Gemini, Groq y DeepSeek. Las características incluyen modos de visualización de sugerencias duales (en línea/emergente), bibliotecas de frases personalizadas para sugerencias sin conexión, personalización de texto completo y manejo integral de comandos para la integración del flujo de trabajo.
