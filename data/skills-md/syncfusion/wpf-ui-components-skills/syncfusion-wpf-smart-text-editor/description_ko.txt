지능형 텍스트 완성 기능을 갖춘 AI 기반 여러 줄 입력 컨트롤인 Syncfusion WPF 스마트 텍스트 편집기(SfSmartTextEditor)를 구현합니다. WPF 애플리케이션에서 스마트 텍스트 편집기, AI 기반 텍스트 입력 또는 예측 텍스트 제안을 구현할 때 이를 사용하세요. 이 컨트롤은 Azure OpenAI, OpenAI, Ollama, Claude, Gemini, Groq 및 DeepSeek를 포함한 AI 서비스와의 통합을 통해 상황 인식 입력 지원을 제공합니다. 기능에는 이중 제안 표시 모드(인라인/팝업), 오프라인 제안을 위한 사용자 정의 구문 라이브러리, 전체 텍스트 사용자 정의 및 작업 흐름 통합을 위한 포괄적인 명령 처리가 포함됩니다.
