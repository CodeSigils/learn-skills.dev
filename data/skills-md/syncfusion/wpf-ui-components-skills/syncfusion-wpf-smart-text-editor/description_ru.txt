Реализует интеллектуальный текстовый редактор Syncfusion WPF (SfSmartTextEditor), элемент управления многострочным вводом на базе искусственного интеллекта с интеллектуальным завершением текста. Используйте это при реализации интеллектуальных текстовых редакторов, ввода текста на основе искусственного интеллекта или интеллектуальных текстовых предложений в приложениях WPF. Этот элемент управления обеспечивает контекстно-зависимую помощь при вводе текста за счет интеграции со службами искусственного интеллекта, включая Azure OpenAI, OpenAI, Ollama, Claude, Gemini, Groq и DeepSeek. Функции включают в себя два режима отображения предложений (встроенные и всплывающие), пользовательские библиотеки фраз для автономных предложений, полнотекстовую настройку и комплексную обработку команд для интеграции рабочего процесса.
