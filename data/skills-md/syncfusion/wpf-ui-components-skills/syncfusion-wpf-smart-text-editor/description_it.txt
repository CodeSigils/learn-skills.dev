Implementa Syncfusion WPF Smart Text Editor (SfSmartTextEditor), un controllo di input multilinea basato sull'intelligenza artificiale con completamento intelligente del testo. Utilizzalo quando implementi editor di testo intelligenti, input di testo basato sull'intelligenza artificiale o suggerimenti di testo predittivo nelle applicazioni WPF. Il controllo fornisce assistenza per la digitazione sensibile al contesto attraverso l'integrazione con servizi di intelligenza artificiale tra cui Azure OpenAI, OpenAI, Ollama, Claude, Gemini, Groq e DeepSeek. Le funzionalità includono modalità di visualizzazione dei suggerimenti doppi (in linea/popup), librerie di frasi personalizzate per suggerimenti offline, personalizzazione del testo completo e gestione completa dei comandi per l'integrazione del flusso di lavoro.
