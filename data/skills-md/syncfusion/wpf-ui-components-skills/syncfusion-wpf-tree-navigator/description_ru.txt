Внедрите Syncfusion WPF SfTreeNavigator для навигации по иерархическому дереву на месте и панелей детализации. Используйте это при создании иерархических панелей навигации, детализированной навигации или навигации по дереву в стиле «хлебные крошки» в WPF. Охватывает декларативное создание элементов, привязку данных ItemsSource с HierarchicalDataTemplate, режимы навигации по умолчанию и расширенный, настройку HeaderTemplate и выбор SelectedItem на основе MVVM.
