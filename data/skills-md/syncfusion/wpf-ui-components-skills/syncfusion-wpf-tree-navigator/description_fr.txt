Implémentez Syncfusion WPF SfTreeNavigator pour la navigation dans l'arborescence hiérarchique sur place et les panneaux d'exploration. Utilisez-le lors de la création de panneaux de navigation hiérarchiques, d’une navigation détaillée ou d’une navigation arborescente de type fil d’Ariane dans WPF. Couvre la création d'éléments déclaratifs, la liaison de données ItemsSource avec HierarchicalDataTemplate, les modes de navigation par défaut et étendu, la personnalisation de HeaderTemplate et la sélection SelectedItem basée sur MVVM.
