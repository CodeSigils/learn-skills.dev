Implemente el cliente OLAP Syncfusion WPF para inteligencia empresarial y análisis de datos multidimensionales. Utilícelo cuando trabaje con controles de cliente OLAP, análisis de cubos, SSAS (SQL Server Analysis Services) o datos multidimensionales. Cubre conexiones de bases de datos de cubos (cubos sin conexión, Mondrian, ActivePivot), exploración de dimensiones, informes OLAP, operaciones de obtención de detalles y análisis de KPI.
