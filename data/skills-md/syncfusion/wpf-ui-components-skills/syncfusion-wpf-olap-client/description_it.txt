Implementa il client OLAP Syncfusion WPF per la business intelligence e l'analisi dei dati multidimensionali. Utilizzarlo quando si lavora con controlli client OLAP, analisi del cubo, SSAS (SQL Server Analysis Services) o dati multidimensionali. Copre le connessioni al database dei cubi (cubi offline, Mondrian, ActivePivot), l'esplorazione delle dimensioni, i report OLAP, le operazioni drill-through e l'analisi KPI.
