تنفيذ Syncfusion WPF OLAP Client لذكاء الأعمال وتحليل البيانات متعددة الأبعاد. استخدم هذا عند العمل مع عناصر تحكم عميل OLAP، أو تحليل المكعب، أو SSAS (خدمات تحليل SQL Server)، أو البيانات متعددة الأبعاد. يغطي اتصالات قاعدة بيانات المكعب (المكعبات غير المتصلة بالإنترنت، وMondrian، وActivePivot)، وتصفح الأبعاد، وتقارير OLAP، وعمليات التصفح، وتحليل مؤشرات الأداء الرئيسية.
