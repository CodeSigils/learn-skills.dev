Implémentez le client Syncfusion WPF OLAP pour la business intelligence et l'analyse de données multidimensionnelles. Utilisez-le lorsque vous travaillez avec des contrôles client OLAP, une analyse de cube, SSAS (SQL Server Analysis Services) ou des données multidimensionnelles. Couvre les connexions aux bases de données de cubes (cubes hors ligne, Mondrian, ActivePivot), la navigation dans les dimensions, les rapports OLAP, les opérations d'exploration amont et l'analyse des KPI.
