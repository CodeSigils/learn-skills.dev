يطبق مكون Syncfusion WPF DataGrid (SfDataGrid) لعرض البيانات الجدولية ومعالجتها في تطبيقات Windows Presentation Foundation. استخدم هذا عند العمل مع شبكات البيانات أو طرق عرض الجدول أو سيناريوهات ربط البيانات. يدعم الفرز والتصفية والتجميع والتحرير وتصدير Excel/PDF والسحب والإفلات وطرق عرض التفاصيل الرئيسية والملخصات وخيارات التصميم الشاملة.
