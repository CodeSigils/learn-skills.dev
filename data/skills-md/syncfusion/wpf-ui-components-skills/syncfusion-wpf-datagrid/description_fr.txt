Implémente le composant Syncfusion WPF DataGrid (SfDataGrid) pour afficher et manipuler des données tabulaires dans les applications Windows Presentation Foundation. Utilisez-le lorsque vous travaillez avec des grilles de données, des vues de table ou des scénarios de liaison de données. Prend en charge le tri, le filtrage, le regroupement, l'édition, l'exportation Excel/PDF, le glisser-déposer, les vues maître-détails, les résumés et les options de style étendues.
