دليل شامل لتنفيذ التحكم Syncfusion WPF PivotGrid، وهو مكون جدول محوري قوي لتحليل البيانات المجدولة. استخدم هذا عند العمل مع الجداول المحورية WPF، أو PivotGridControl، أو سيناريوهات البيانات المجدولة. يغطي تكوين الصفوف/الأعمدة المحورية، وPivotSchemaDesigner، وشريط التجميع، وقائمة الحقول المحورية، والحسابات المحورية، والتصفية، والفرز، وربط البيانات لتطبيقات ذكاء الأعمال.
