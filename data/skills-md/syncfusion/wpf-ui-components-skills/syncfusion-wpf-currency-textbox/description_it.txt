Implementa il controllo Syncfusion WPF CurrencyTextBox per l'input di valuta formattato con formattazione specifica della lingua. Utilizzarlo quando si aggiungono campi di input valuta, controlli di immissione dati finanziari o input di valori decimali con simboli di valuta nelle applicazioni WPF. Copre la formattazione della valuta, il supporto delle impostazioni cultura, la convalida minima/massima, la personalizzazione di NumberFormatInfo e l'associazione di valori.
