Внедрите элемент управления Syncfusion WPF TreeMap (SfTreeMap) для иерархической визуализации данных с использованием вложенных прямоугольников. Используйте это при визуализации больших наборов данных с иерархической структурой, создании тепловых карт или отображении пропорциональных данных. Этот навык охватывает настройку TreeMap, алгоритмы компоновки, цветовое отображение, привязку данных и интерактивные функции для анализа запасов, категоризации данных и сценариев иерархической визуализации.
