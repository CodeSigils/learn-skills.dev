Implemente el control Syncfusion WPF TreeMap (SfTreeMap) para la visualización de datos jerárquicos utilizando rectángulos anidados. Utilícelo cuando visualice grandes conjuntos de datos con estructura jerárquica, cree mapas de calor o muestre datos proporcionales. Esta habilidad cubre la configuración de TreeMap, algoritmos de diseño, mapeo de colores, enlace de datos y funciones interactivas para análisis de acciones, categorización de datos y escenarios de visualización jerárquica.
