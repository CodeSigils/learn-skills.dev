Implement Syncfusion WPF TreeMap (SfTreeMap) control for hierarchical data visualization using nested rectangles. Use this when visualizing large datasets with hierarchical structure, creating heat maps, or displaying proportional data. Esta habilidad cubre la configuración de TreeMap, algoritmos de diseño, mapeo de colores, enlace de datos y funciones interactivas para análisis de acciones, categorización de datos y escenarios de visualización jerárquica.
