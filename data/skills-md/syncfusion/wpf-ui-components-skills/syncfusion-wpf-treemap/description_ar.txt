تنفيذ التحكم Syncfusion WPF TreeMap (SfTreeMap) لتصور البيانات الهرمية باستخدام المستطيلات المتداخلة. استخدم هذا عند تصور مجموعات البيانات الكبيرة ببنية هرمية، أو إنشاء خرائط حرارية، أو عرض البيانات المتناسبة. تغطي هذه المهارة تكوين TreeMap، وخوارزميات التخطيط، ورسم خرائط الألوان، وربط البيانات، والميزات التفاعلية لتحليل المخزون، وتصنيف البيانات، وسيناريوهات التصور الهرمي.
