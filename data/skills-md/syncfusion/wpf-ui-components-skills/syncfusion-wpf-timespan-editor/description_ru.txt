Как реализовать элемент управления Syncfusion WPF TimeSpanEdit (редактор TimeSpan) для ввода длительности времени. Используйте этот навык при создании входных данных о продолжительности времени, захвате значений «Дни:Часы:Минуты:Секунды», создании редакторов временных интервалов или реализации элементов управления временным диапазоном с помощью ввода времени с помощью клавиатуры и мыши. Включает настройку, форматирование, взаимодействие с пользователем, ограничения и стили.
