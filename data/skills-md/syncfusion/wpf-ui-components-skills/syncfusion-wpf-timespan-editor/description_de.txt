So implementieren Sie das Syncfusion WPF TimeSpanEdit-Steuerelement (TimeSpan Editor) für Zeitdauereingaben. Verwenden Sie diese Fähigkeit, wenn Sie Zeitdauereingaben erstellen, Tage:Stunden:Minuten:Sekunden-Werte erfassen, Zeitintervalleditoren erstellen oder Zeitbereichssteuerungen mit tastatur- und mausbasierter Zeiteingabe implementieren. Beinhaltet Einrichtung, Formatierung, Benutzerinteraktionen, Einschränkungen und Stil.
