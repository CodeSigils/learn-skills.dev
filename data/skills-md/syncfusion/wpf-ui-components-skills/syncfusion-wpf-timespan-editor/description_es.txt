Utilice esta habilidad al crear entradas de duración de tiempo, capturar valores de Días: Horas: Minutos: Segundos, crear editores de intervalos de tiempo o implementar controles de rango de tiempo con entrada de tiempo basada en teclado y mouse. Incluye configuración, formato, interacciones del usuario, restricciones y estilo.
