كيفية تنفيذ عنصر التحكم Syncfusion WPF TimeSpanEdit (TimeSpan Editor) لمدخلات المدة الزمنية. استخدم هذه المهارة عند إنشاء مدخلات المدة الزمنية، أو التقاط قيم الأيام:الساعات:الدقائق:الثواني، أو إنشاء محررات الفاصل الزمني، أو تنفيذ عناصر تحكم النطاق الزمني باستخدام إدخال الوقت المستند إلى لوحة المفاتيح والماوس. يتضمن الإعداد والتنسيق وتفاعلات المستخدم والقيود والتصميم.
