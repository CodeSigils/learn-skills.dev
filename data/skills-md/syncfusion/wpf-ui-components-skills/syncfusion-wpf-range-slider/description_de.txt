Implementiert das Syncfusion WPF SfRangeSlider-Steuerelement zum Auswählen numerischer Bereiche mit einem oder zwei Daumen. Verwenden Sie diese Option beim Erstellen von Benutzeroberflächen zur Auswahl von Wertebereichen, Schiebereglern mit Häkchen/QuickInfos oder benutzerdefinierten Ausrichtungs- und Fangverhaltensweisen.
