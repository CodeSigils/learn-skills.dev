Внедрите редактор синтаксиса Syncfusion WPF (EditControl) для редакторов кода и расширенных приложений для редактирования текста. Используйте это при создании редакторов кода с подсветкой синтаксиса, редакторов, подобных IDE, или интерфейсов редактирования исходного кода в WPF. Охватывает подсветку синтаксиса, IntelliSense, поиск и замену, поддержку языков программирования и функции редактирования в стиле Visual Studio.
