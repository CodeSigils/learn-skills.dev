Implementa Syncfusion WPF Syntax Editor (EditControl) per editor di codice e applicazioni avanzate di modifica del testo. Utilizzarlo durante la creazione di editor di codice con evidenziazione della sintassi, editor di tipo IDE o interfacce di modifica del codice sorgente in WPF. Copre l'evidenziazione della sintassi, IntelliSense, trova/sostituisci, il supporto del linguaggio di programmazione e le funzionalità di modifica in stile Visual Studio.
