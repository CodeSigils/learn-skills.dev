Implémentez l'éditeur de syntaxe Syncfusion WPF (EditControl) pour les éditeurs de code et les applications avancées d'édition de texte. Utilisez-le lors de la création d'éditeurs de code à syntaxe mise en évidence, d'éditeurs de type IDE ou d'interfaces d'édition de code source dans WPF. Couvre la coloration syntaxique, IntelliSense, la recherche/remplacement, la prise en charge du langage de programmation et les fonctionnalités d'édition de style Visual Studio.
