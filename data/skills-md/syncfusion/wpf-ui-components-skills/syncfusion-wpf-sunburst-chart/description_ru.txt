Внедрите Syncfusion WPF Sunburst Chart (SfSunburstChart) для иерархической визуализации данных. Используйте это при работе с диаграммами солнечных лучей, иерархической визуализацией данных, многоуровневыми круговыми диаграммами или детализированными визуализациями. Этот навык охватывает отображение организационных иерархий, структур файловой системы, данных о продажах по регионам/категориям и других многоуровневых категориальных данных в концентрических кругах для приложений WPF.
