Implemente Syncfusion WPF Sunburst Chart (SfSunburstChart) para visualización de datos jerárquicos. Utilícelo cuando trabaje con gráficos tipo rayos de sol, visualización de datos jerárquicos, gráficos circulares de varios niveles o visualizaciones detalladas. Esta habilidad cubre la visualización de jerarquías organizativas, estructuras de sistemas de archivos, datos de ventas por región/categoría y otros datos categóricos de varios niveles en círculos concéntricos para aplicaciones WPF.
