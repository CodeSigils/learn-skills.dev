Implementa Syncfusion WPF Sunburst Chart (SfSunburstChart) per la visualizzazione gerarchica dei dati. Utilizzalo quando lavori con grafici sunburst, visualizzazione gerarchica dei dati, grafici circolari multilivello o visualizzazioni drill-down. Questa competenza riguarda la visualizzazione di gerarchie organizzative, strutture di file system, dati di vendita per regione/categoria e altri dati categorici multilivello in cerchi concentrici per le applicazioni WPF.
