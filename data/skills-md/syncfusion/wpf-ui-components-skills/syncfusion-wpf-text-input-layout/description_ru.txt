Реализует элемент управления Syncfusion WPF SfTextInputLayout для предоставления плавающих меток, вспомогательных меток и пользовательского интерфейса проверки ввода для текстовых входных данных WPF. Используйте при добавлении плавающих меток, настройке стилей входного контейнера или отображении проверочного/вспомогательного текста.
