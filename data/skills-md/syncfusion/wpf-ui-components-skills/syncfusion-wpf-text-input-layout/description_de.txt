Implementiert das Syncfusion WPF SfTextInputLayout-Steuerelement, um schwebende Beschriftungen, unterstützende Beschriftungen und eine Eingabevalidierungs-Benutzeroberfläche für WPF-Texteingaben bereitzustellen. Verwenden Sie diese Option, wenn Sie schwebende Beschriftungen hinzufügen, Eingabecontainer-Stile anpassen oder Validierungs-/Hilfstext anzeigen.
