Implémente le contrôle Syncfusion WPF SfTextInputLayout pour fournir des étiquettes flottantes, des étiquettes d'assistance et une interface utilisateur de validation d'entrée pour les entrées de texte WPF. À utiliser lors de l'ajout d'étiquettes flottantes, de la personnalisation des styles de conteneur d'entrée ou de l'affichage du texte de validation/d'aide.
