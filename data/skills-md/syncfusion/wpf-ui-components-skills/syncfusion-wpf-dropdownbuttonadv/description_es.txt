Implementar Syncfusion WPF DropDownButtonAdv para controles de botones desplegables con menús emergentes. Utiliza esta opción cuando añadas un botón desplegable, un menú desplegable o un botón con una lista de opciones en WPF. Cubre elementos de menú, enlace de datos, enlace de comandos, dirección desplegable, eventos, texto de líneas múltiples, estilos y temas.
