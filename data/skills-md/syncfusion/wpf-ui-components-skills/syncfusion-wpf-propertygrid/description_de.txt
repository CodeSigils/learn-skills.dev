Implementieren Sie Syncfusion WPF PropertyGrid zum Durchsuchen und Bearbeiten von Objekteigenschaften mit benutzerdefinierten Editoren und Kategorieeditoren. Verwenden Sie dies beim Erstellen von Eigenschafteninspektoren, Eigenschaftenfenstern ähnlich dem Eigenschaftenfenster von Visual Studio oder beim dynamischen Überprüfen und Bearbeiten von Objekteigenschaften in WPF. Behandelt benutzerdefinierte Werteeditoren, Kategorieeditoren, Sammlungsbearbeitung und die Anpassung von Eigenschaftseditoren zur Entwurfszeit.
