Implementa Syncfusion WPF PropertyGrid per sfogliare e modificare le proprietà degli oggetti con editor personalizzati ed editor di categorie. Utilizzarlo durante la creazione di finestre di ispezione delle proprietà, pannelli delle proprietà simili alla finestra Proprietà di Visual Studio o l'ispezione e la modifica dinamica delle proprietà degli oggetti in WPF. Copre editor di valori personalizzati, editor di categorie, modifica di raccolte e personalizzazione dell'editor di proprietà in fase di progettazione.
