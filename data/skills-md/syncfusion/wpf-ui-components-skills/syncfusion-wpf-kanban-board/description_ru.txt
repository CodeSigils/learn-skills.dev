Внедрите элемент управления Syncfusion WPF Kanban (SfKanban) для визуализации рабочего процесса и управления задачами. Используйте это при создании гибких интерфейсов отслеживания проектов, досок рабочих процессов или систем управления задачами. Этот навык охватывает настройку карт, управление столбцами, дорожки для плавания, ограничения незавершенного производства, функции перетаскивания, рабочие процессы, сортировку и обработку событий.
