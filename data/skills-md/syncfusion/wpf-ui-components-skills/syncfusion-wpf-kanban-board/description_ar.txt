تنفيذ التحكم Syncfusion WPF Kanban (SfKanban) لتصور سير العمل وإدارة المهام. استخدم هذا عند إنشاء واجهات تتبع مشروع رشيقة أو لوحات سير العمل أو أنظمة إدارة المهام. تغطي هذه المهارة تكوين البطاقة، وإدارة الأعمدة، وممرات السباحة، وحدود WIP، ووظيفة السحب والإفلات، وسير العمل، والفرز، والتعامل مع الأحداث.
