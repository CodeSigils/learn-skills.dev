دليل شامل لتطبيق التحكم Syncfusion WPF TreeView (SfTreeView) لعرض البيانات الهرمية في تطبيقات Windows Presentation Foundation. استخدم هذا عند العمل مع الهياكل الشجرية أو التسلسلات الهرمية للمجلدات أو المخططات التنظيمية أو علاقات البيانات بين الأصل والفرع. يدعم إعادة الترتيب بالسحب والإفلات، وتحديد خانة الاختيار، والتحميل عند الطلب لمجموعات البيانات الكبيرة، والتحرير المضمن لعقد الشجرة.
