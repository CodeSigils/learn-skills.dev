Implement the Syncfusion WPF HierarchyNavigator (Breadcrumb) control for hierarchical path navigation. Úselo al crear IU de ruta de navegación o barra de direcciones, vincular datos jerárquicos a un control de navegación o habilitar el modo de edición con la entrada de ruta de Autocompletar en WPF. Covers navigation history, refresh button, progress bar during navigation, and keyboard-driven hierarchical navigation.
