Реализует элемент управления Syncfusion WPF Color Palette (SfColorPalette) для интерфейсов выбора цвета с помощью образцов. Используйте это при реализации функций выбора цвета, образцов цвета или привязки цвета в приложениях WPF. Охватывает настройку обложек, выбор цвета, привязку данных, навигацию по образцам, настройку внешнего вида и темы.
