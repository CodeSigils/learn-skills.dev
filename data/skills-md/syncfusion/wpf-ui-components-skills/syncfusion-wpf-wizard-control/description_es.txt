Implemente Syncfusion WPF WizardControl para las IU del asistente paso a paso. Utilícelo cuando cree flujos de asistente de varias páginas, asistentes de instalación o interfaces de asistente de configuración en WPF. Cubre la adición de WizardPages, la configuración de tipos de páginas (En blanco, Interior, Exterior), el control de los botones de navegación (Atrás, Siguiente, Finalizar, Cancelar, Ayuda), el enlace de datos de ItemsSource, la navegación no lineal y la personalización de imágenes de banner.
