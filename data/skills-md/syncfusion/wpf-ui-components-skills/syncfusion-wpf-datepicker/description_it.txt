Implementa il controllo Syncfusion WPF DatePicker (SfDatePicker) per la selezione della data touch-friendly. Utilizzarlo quando si aggiungono controlli di input della data, si personalizza l'aspetto del selettore data, si formatta la visualizzazione della data o si limitano gli intervalli di date nelle applicazioni WPF. Copre l'installazione, la formattazione della data, lo stile, la personalizzazione, la gestione del valore e la gestione degli eventi.
