Реализует элемент управления Syncfusion WPF DatePicker (SfDatePicker) для удобного выбора даты с помощью сенсорного управления. Используйте это при добавлении элементов управления вводом даты, настройке внешнего вида средства выбора даты, форматировании отображения даты или ограничении диапазонов дат в приложениях WPF. Охватывает установку, форматирование даты, стиль, настройку, управление значениями и обработку событий.
