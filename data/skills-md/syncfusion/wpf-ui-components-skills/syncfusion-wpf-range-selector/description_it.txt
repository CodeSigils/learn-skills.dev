Guida completa per l'implementazione di Syncfusion WPF Range Selector (SfDateTimeRangeNavigator) per la visualizzazione di dati con limiti di tempo con scorrimento interattivo, zoom e selezione di intervalli. Utilizzalo quando lavori con i selettori di intervallo, la navigazione nell'intervallo di date e ore o la visualizzazione di dati con limiti di tempo. Questa competenza copre la selezione interattiva dell'intervallo di dati, lo zoom dell'intervallo del grafico e le funzionalità di navigazione temporale del dashboard per set di dati basati sul tempo di grandi dimensioni nelle applicazioni WPF.
