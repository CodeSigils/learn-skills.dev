Подробное руководство по реализации Syncfusion WPF Range Selector (SfDateTimeRangeNavigator) для визуализации данных с привязкой ко времени с интерактивной прокруткой, масштабированием и выбором диапазона. Используйте это при работе с селекторами диапазонов, навигацией по диапазону дат и времени или визуализацией данных с привязкой ко времени. Этот навык охватывает интерактивный выбор диапазона данных, масштабирование диапазона диаграмм и функции навигации по времени на информационной панели для больших наборов данных на основе времени в приложениях WPF.
