Guide complet pour la mise en œuvre du sélecteur de plage Syncfusion WPF (SfDateTimeRangeNavigator) pour la visualisation de données limitées dans le temps avec défilement interactif, zoom et sélection de plage. Utilisez-le lorsque vous travaillez avec des sélecteurs de plage, la navigation par plage date-heure ou la visualisation de données limitées dans le temps. Cette compétence couvre la sélection interactive de plages de données, le zoom sur la plage de graphiques et les fonctionnalités de navigation temporelle du tableau de bord pour les grands ensembles de données temporelles dans les applications WPF.
