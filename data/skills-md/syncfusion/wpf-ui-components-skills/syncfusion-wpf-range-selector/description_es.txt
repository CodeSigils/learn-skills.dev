Guía completa para implementar Syncfusion WPF Range Selector (SfDateTimeRangeNavigator) para visualización de datos con límite de tiempo con desplazamiento interactivo, zoom y selección de rango. Use this when working with range selectors, date-time range navigation, or time-bound data visualization. Esta habilidad cubre la selección interactiva de rangos de datos, el zoom del rango de gráficos y las funciones de navegación en el tiempo del panel para grandes conjuntos de datos basados ​​en el tiempo en aplicaciones WPF.
