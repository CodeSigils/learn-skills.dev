تنفيذ التحكم في خرائط Syncfusion WPF (SfMap) لتصور البيانات الجغرافية في تطبيقات Windows Presentation Foundation. استخدم هذا عند عرض البيانات الجغرافية، أو عرض ملفات الأشكال، أو دمج طبقات الخريطة مع العلامات والفقاعات. تغطي هذه المهارة ShapeFileLayer وImageryLayer وتخصيص الخريطة والأساطير وتكامل OpenStreetMap/Bing Maps وميزات الخريطة التفاعلية.
