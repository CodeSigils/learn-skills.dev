Implémentez le contrôle Syncfusion WPF Maps (SfMap) pour la visualisation des données géographiques dans les applications Windows Presentation Foundation. Utilisez-le lors de l'affichage de données géographiques, du rendu de fichiers de forme ou de l'intégration de couches cartographiques avec des marqueurs et des bulles. Cette compétence couvre ShapeFileLayer, ImageryLayer, la personnalisation des cartes, les légendes, l'intégration OpenStreetMap/Bing Maps et les fonctionnalités de cartes interactives.
