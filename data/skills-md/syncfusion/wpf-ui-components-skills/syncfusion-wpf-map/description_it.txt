Implementare il controllo Syncfusion WPF Maps (SfMap) per la visualizzazione dei dati geografici nelle applicazioni Windows Presentation Foundation. Utilizzarlo quando si visualizzano dati geografici, si esegue il rendering di file di forma o si integrano livelli di mappa con indicatori e bolle. Questa competenza copre ShapeFileLayer, ImageryLayer, personalizzazione della mappa, legende, integrazione OpenStreetMap/Bing Maps e funzionalità della mappa interattiva.
