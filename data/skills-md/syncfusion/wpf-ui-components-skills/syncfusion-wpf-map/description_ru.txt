Внедрите элемент управления Syncfusion WPF Maps (SfMap) для визуализации географических данных в приложениях Windows Presentation Foundation. Используйте это при отображении географических данных, рендеринге файлов форм или интеграции слоев карты с маркерами и пузырьками. Этот навык охватывает ShapeFileLayer, ImageryLayer, настройку карт, легенды, интеграцию OpenStreetMap/Bing Maps и функции интерактивных карт.
