Implementieren Sie das Syncfusion WPF Maps (SfMap)-Steuerelement für die Visualisierung geografischer Daten in Windows Presentation Foundation-Anwendungen. Verwenden Sie dies, wenn Sie geografische Daten anzeigen, Formdateien rendern oder Kartenebenen mit Markierungen und Blasen integrieren. Diese Fertigkeit umfasst ShapeFileLayer, ImageryLayer, Kartenanpassung, Legenden, OpenStreetMap/Bing Maps-Integration und interaktive Kartenfunktionen.
