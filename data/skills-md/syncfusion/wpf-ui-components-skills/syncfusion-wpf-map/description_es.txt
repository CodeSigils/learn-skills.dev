Implemente el control Syncfusion WPF Maps (SfMap) para la visualización de datos geográficos en aplicaciones Windows Presentation Foundation. Utilícelo cuando muestre datos geográficos, renderice archivos de formas o integre capas de mapas con marcadores y burbujas. Esta habilidad cubre ShapeFileLayer, ImageryLayer, personalización de mapas, leyendas, integración de OpenStreetMap/Bing Maps y funciones de mapas interactivos.
