Guía completa para implementar el control Syncfusion WPF TreeGrid (SfTreeGrid) en aplicaciones de Windows Presentation Foundation. Utilícelo cuando muestre datos jerárquicos o autorelacionales en un formato de cuadrícula con estructura de árbol expandible. Admite configuración de columnas, clasificación y filtrado de datos jerárquicos, edición de nodos de árbol, combinación de celdas, exportación y estilo condicional.
