Umfassende Anleitung zur Implementierung der Syncfusion WPF TreeGrid (SfTreeGrid)-Steuerung in Windows Presentation Foundation-Anwendungen. Verwenden Sie dies, wenn Sie hierarchische oder selbstrelationale Daten in einem Rasterformat mit erweiterbarer Baumstruktur anzeigen. Unterstützt die Spaltenkonfiguration, das Sortieren und Filtern hierarchischer Daten, das Bearbeiten von Baumknoten, das Zusammenführen von Zellen, das Exportieren und die bedingte Formatierung.
