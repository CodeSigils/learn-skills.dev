دليل شامل لتطبيق التحكم Syncfusion WPF TreeGrid (SfTreeGrid) في تطبيقات Windows Presentation Foundation. استخدم هذا عند عرض بيانات هرمية أو ذاتية الارتباط بتنسيق شبكة ذي بنية شجرية قابلة للتوسيع. يدعم تكوين العمود، وفرز البيانات الهرمية وتصفيتها، وتحرير عقد الشجرة، ودمج الخلايا، والتصدير، والتصميم الشرطي.
