Guide complet pour implémenter le contrôle Syncfusion WPF TreeGrid (SfTreeGrid) dans les applications Windows Presentation Foundation. Utilisez-le lors de l'affichage de données hiérarchiques ou auto-relationnelles dans un format de grille avec une structure arborescente extensible. Prend en charge la configuration des colonnes, le tri et le filtrage des données hiérarchiques, la modification des nœuds d'arborescence, la fusion de cellules, l'exportation et le style conditionnel.
