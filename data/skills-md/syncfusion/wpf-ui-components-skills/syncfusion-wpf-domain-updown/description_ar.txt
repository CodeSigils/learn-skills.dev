ينفذ عنصر التحكم Syncfusion WPF DomainUpDown (SfDomainUpDown) للتنقل عبر قوائم العناصر المحددة مسبقًا باستخدام أزرار الدوران. استخدم هذا عند إضافة محددات المجال، أو محددات العناصر ذات الأزرار لأعلى/لأسفل، أو عناصر التحكم التي تتنقل عبر المجموعات باستخدام أزرار الزيادة/النقصان في تطبيقات WPF. يغطي عدد العناصر، ومحاذاة زر الدوران، والتصميم، والعكس التلقائي، وربط البيانات باستخدام قوالب مخصصة.
