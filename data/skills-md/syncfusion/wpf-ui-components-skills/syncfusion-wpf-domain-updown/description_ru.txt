Реализует элемент управления Syncfusion WPF DomainUpDown (SfDomainUpDown) для циклического перемещения по предопределенным спискам элементов с помощью кнопок прокрутки. Используйте это при добавлении селекторов доменов, селекторов элементов с кнопками вверх/вниз или элементов управления, которые перемещаются по коллекциям с помощью кнопок увеличения/уменьшения в приложениях WPF. Охватывает заполнение элементов, выравнивание кнопок прокрутки, стилизацию, автореверс и привязку данных с помощью пользовательских шаблонов.
