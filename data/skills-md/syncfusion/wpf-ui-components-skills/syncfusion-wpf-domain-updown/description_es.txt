Implementa el control Syncfusion WPF DomainUpDown (SfDomainUpDown) para recorrer listas de elementos predefinidos mediante botones giratorios. Úselo al agregar selectores de dominio, selectores de elementos con botones arriba/abajo o controles que navegan a través de colecciones usando botones de incremento/disminución en aplicaciones WPF. Cubre la población de elementos, la alineación de los botones giratorios, el estilo, la inversión automática y el enlace de datos con plantillas personalizadas.
