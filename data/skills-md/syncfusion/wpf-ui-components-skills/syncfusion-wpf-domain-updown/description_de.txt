Implementiert das Syncfusion WPF DomainUpDown (SfDomainUpDown)-Steuerelement zum Durchlaufen vordefinierter Elementlisten mithilfe von Drehschaltflächen. Verwenden Sie dies, wenn Sie Domänenselektoren, Elementselektoren mit Auf-/Ab-Schaltflächen oder Steuerelemente hinzufügen, die mithilfe von Inkrement-/Dekrement-Schaltflächen in WPF-Anwendungen durch Sammlungen navigieren. Behandelt das Auffüllen von Elementen, die Ausrichtung von Drehschaltflächen, das Styling, die automatische Umkehrung und die Datenbindung mit benutzerdefinierten Vorlagen.
