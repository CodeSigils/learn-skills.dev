Implemente el control Syncfusion WPF Heat Map (SfHeatMap) para la visualización de datos basada en matrices utilizando gradientes de color. Utilícelo cuando visualice datos tabulares con celdas codificadas por colores, cree gráficos de mapas de calor o muestre patrones de densidad de datos. Esta habilidad cubre el mapeo de datos, la configuración de la paleta de colores, la personalización de leyendas y el formato de etiquetas de celdas para aplicaciones WPF.
