Implémentez les contrôles Syncfusion WPF ButtonAdv pour les interfaces utilisateur de boutons configurables. Utilisez-le lors de l'ajout, de la configuration ou de la personnalisation d'un ButtonAdv Syncfusion WPF — y compris les étiquettes, les icônes, les modes de taille, le comportement bascule/vérifiable, la liaison de commande MVVM, le texte multiligne, le rayon de coin, les modes IsDefault/IsCancel, les modèles d'icônes et les thèmes.
