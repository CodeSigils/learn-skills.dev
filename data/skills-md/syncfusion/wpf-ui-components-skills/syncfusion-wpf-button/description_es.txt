Implemente controles Syncfusion WPF ButtonAdv para interfaces de usuario de botones configurables. Úselo al agregar, configurar o personalizar un ButtonAdv de Syncfusion WPF, incluidas etiquetas, íconos, modos de tamaño, comportamiento de alternancia/verificación, enlace de comandos MVVM, texto multilínea, radio de esquina, modos IsDefault/IsCancel, plantillas de íconos y temas.
