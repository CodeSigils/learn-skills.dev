Implement Syncfusion WPF ButtonAdv controls for configurable button UIs. Úselo al agregar, configurar o personalizar un ButtonAdv de Syncfusion WPF, incluidas etiquetas, íconos, modos de tamaño, comportamiento de alternancia/verificación, enlace de comandos MVVM, texto multilínea, radio de esquina, modos IsDefault/IsCancel, plantillas de íconos y temas.
