دليل لاستخدام عنصر التحكم Syncfusion WPF CalendarEdit لتحديد التاريخ والتنقل. استخدم هذه المهارة عندما يحتاج المستخدم إلى تنفيذ وظيفة التقويم، أو تحديد التواريخ، أو تقييد نطاقات التاريخ، أو تخصيص مظهر التقويم، أو العمل مع التحديد متعدد التواريخ. ضروري لبناء واجهات منتقي التاريخ وأنظمة الحجز وتطبيقات الجدولة وأي مشروع WPF يتطلب ضوابط التقويم.
