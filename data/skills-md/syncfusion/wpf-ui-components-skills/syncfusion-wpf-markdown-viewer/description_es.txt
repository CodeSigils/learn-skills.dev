Implemente Syncfusion WPF SfMarkdownViewer para renderizar y mostrar contenido de Markdown en aplicaciones WPF. Utilícelo cuando represente texto de Markdown, cargue Markdown desde cadenas, archivos o URL, gestione clics en hipervínculos o muestre diagramas de Mermaid. Cubre la propiedad Fuente, los eventos HyperlinkClicked y la personalización de MermaidBlockTemplate.
