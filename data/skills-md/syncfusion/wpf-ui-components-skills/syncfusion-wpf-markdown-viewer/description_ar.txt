قم بتطبيق Syncfusion WPF SfMarkdownViewer لعرض وعرض محتوى Markdown في تطبيقات WPF. استخدم هذا عند عرض نص Markdown، أو تحميل Markdown من سلاسل أو ملفات أو عناوين URL، أو التعامل مع نقرات الارتباط التشعبي، أو عرض مخططات حورية البحر. يغطي خاصية المصدر، وأحداث HyperlinkClicked، وتخصيص MermaidBlockTemplate.
