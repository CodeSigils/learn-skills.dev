Implémentez Syncfusion WPF SfMarkdownViewer pour le rendu et l'affichage du contenu Markdown dans les applications WPF. Utilisez-le lors du rendu du texte Markdown, du chargement de Markdown à partir de chaînes, de fichiers ou d'URL, de la gestion des clics sur des liens hypertexte ou de l'affichage de diagrammes Mermaid. Couvre la propriété Source, les événements HyperlinkClicked et la personnalisation de MermaidBlockTemplate.
