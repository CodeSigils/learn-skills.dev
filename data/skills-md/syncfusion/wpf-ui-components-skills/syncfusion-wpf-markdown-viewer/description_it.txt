Implementa Syncfusion WPF SfMarkdownViewer per il rendering e la visualizzazione del contenuto Markdown nelle applicazioni WPF. Utilizzalo durante il rendering del testo Markdown, il caricamento di Markdown da stringhe, file o URL, la gestione dei clic sui collegamenti ipertestuali o la visualizzazione dei diagrammi della sirena. Copre la proprietà Source, gli eventi HyperlinkClicked e la personalizzazione di SirenBlockTemplate.
