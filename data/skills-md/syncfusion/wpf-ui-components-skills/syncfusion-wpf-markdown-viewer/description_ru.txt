Внедрите Syncfusion WPF SfMarkdownViewer для рендеринга и отображения содержимого Markdown в приложениях WPF. Используйте это при рендеринге текста Markdown, загрузке Markdown из строк, файлов или URL-адресов, обработке кликов по гиперссылкам или отображении диаграмм Mermaid. Охватывает свойство Source, события HyperlinkClicked и настройку MermaidBlockTemplate.
