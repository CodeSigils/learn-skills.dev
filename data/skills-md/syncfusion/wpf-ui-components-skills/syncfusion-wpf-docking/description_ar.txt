يطبق عنصر التحكم Syncfusion WPF DockingManager لواجهات الإرساء الشبيهة بـ Visual Studio مع دعم MDI/TDI والنوافذ العائمة واللوحات ذاتية الإخفاء. استخدم هذا عند إنشاء تخطيطات الإرساء أو أنظمة إدارة النوافذ أو واجهات المستندات المبوبة أو تخطيطات نمط IDE في تطبيقات WPF. يغطي لوحات الإرساء، والنوافذ العائمة، ووظيفة الإخفاء التلقائي، واستمرارية الحالة، وإدارة النوافذ.
