Implementa il controllo Syncfusion WPF DockingManager per interfacce di ancoraggio simili a Visual Studio con supporto MDI/TDI, finestre mobili e pannelli nascosti automaticamente. Utilizzarlo durante la creazione di layout di aggancio, sistemi di gestione delle finestre, interfacce di documenti a schede o layout in stile IDE nelle applicazioni WPF. Copre i pannelli Dock, le finestre mobili, la funzionalità di nascondimento automatico, la persistenza dello stato e la gestione delle finestre.
