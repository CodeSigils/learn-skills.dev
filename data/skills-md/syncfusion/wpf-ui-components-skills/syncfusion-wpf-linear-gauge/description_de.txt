Implementieren Sie Syncfusion WPF Linear Gauge (SfLinearGauge) in Windows Presentation Foundation-Anwendungen. Verwenden Sie dies, wenn Sie mit linearen Messgeräten, Thermometeranzeigen oder Fortschrittsanzeigen mit Skalen arbeiten. Diese Fertigkeit umfasst die Skalenkonfiguration, das Hinzufügen von Zeigern (Balken oder Symbol), das Erstellen farbiger Bereiche, das Anpassen von Beschriftungen und Häkchen, das Festlegen der horizontalen oder vertikalen Ausrichtung und das Implementieren von Visualisierungen im Thermometerstil.
