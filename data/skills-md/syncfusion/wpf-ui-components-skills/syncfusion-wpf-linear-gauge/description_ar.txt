تنفيذ Syncfusion WPF Linear Gauge (SfLinearGauge) في تطبيقات Windows Presentation Foundation. استخدم هذا عند العمل باستخدام أجهزة قياس خطية أو شاشات عرض مقياس الحرارة أو مؤشرات التقدم ذات المقاييس. تغطي هذه المهارة تكوين المقياس، وإضافة المؤشرات (شريط أو رمز)، وإنشاء نطاقات ملونة، وتخصيص التسميات وعلامات التجزئة، وتحديد الاتجاه الأفقي أو الرأسي، وتنفيذ تصورات على طراز مقياس الحرارة.
