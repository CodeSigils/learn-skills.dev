دليل لتطبيق التحكم في مقياس Syncfusion WPF OLAP لعرض مؤشرات الأداء الرئيسية (KPI) من مصادر بيانات OLAP. استخدم هذا عند العمل مع تصور OLAP KPI، أو لوحات معلومات ذكاء الأعمال، أو ربط بيانات XML/A في WPF. تغطي هذه المهارة الاتصال بمكعبات OLAP وخدمات تحليل SQL Server وخوادم Mondrian وتكوين شاشات مؤشرات الأداء الرئيسية للوحات المعلومات التنفيذية وتطبيقات ذكاء الأعمال.
