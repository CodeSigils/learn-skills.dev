Guida per l'implementazione del controllo indicatore OLAP di Syncfusion WPF per la visualizzazione degli indicatori di prestazioni chiave (KPI) da origini dati OLAP. Utilizzarlo quando si lavora con la visualizzazione KPI OLAP, i dashboard di business intelligence o l'associazione dati XML/A in WPF. Questa competenza copre la connessione a cubi OLAP, SQL Server Analysis Services, server Mondrian e la configurazione di visualizzazioni KPI per dashboard esecutivi e applicazioni BI.
