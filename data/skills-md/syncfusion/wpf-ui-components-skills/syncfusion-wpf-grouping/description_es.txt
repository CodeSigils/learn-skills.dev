Implementa Syncfusion Essential Grouping para WPF, un motor de organización de datos que funciona sin controles de UI. Úselo cuando trabaje con GroupingEngine, TableDescriptor u organice datos tabulares con agrupación jerárquica, clasificación personalizada y filtrado. Admite estructuras de datos de árbol binario, campos de expresión, cálculos resumidos y operaciones agregadas para aplicaciones de análisis de datos WPF.
