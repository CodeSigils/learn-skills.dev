Реализует Syncfusion Essential Grouping для WPF, механизм организации данных, который работает без элементов управления пользовательского интерфейса. Используйте это при работе с GroupingEngine, TableDescriptor или при организации табличных данных с помощью иерархической группировки, пользовательской сортировки и фильтрации. Поддерживает структуры данных двоичного дерева, поля выражений, сводные вычисления и агрегатные операции для приложений анализа данных WPF.
