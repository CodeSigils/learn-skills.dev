Implémente Syncfusion Essential Grouping pour WPF, un moteur d'organisation des données qui fonctionne sans contrôles d'interface utilisateur. Utilisez-le lorsque vous travaillez avec GroupingEngine, TableDescriptor ou organisez des données tabulaires avec un regroupement hiérarchique, un tri personnalisé et un filtrage. Prend en charge les structures de données d'arborescence binaire, les champs d'expression, les calculs récapitulatifs et les opérations d'agrégation pour les applications d'analyse de données WPF.
