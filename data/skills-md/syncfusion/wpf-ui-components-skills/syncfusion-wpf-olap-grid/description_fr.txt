Implémentez Syncfusion WPF OLAP Grid pour l'analyse de données OLAP multidimensionnelles. Utilisez-le lorsque vous travaillez avec des grilles OLAP, des analyses multidimensionnelles, des grilles de business intelligence ou l'affichage de données SSAS. Couvre les connexions aux sources de données OLAP, les opérations d'exploration vers le haut/vers le bas, l'affichage des KPI, l'analyse dimensionnelle et la visualisation des données de cube pour les applications WPF.
