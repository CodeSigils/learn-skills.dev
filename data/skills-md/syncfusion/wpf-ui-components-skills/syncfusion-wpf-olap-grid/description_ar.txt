تنفيذ Syncfusion WPF OLAP Grid لتحليل بيانات OLAP متعددة الأبعاد. استخدم هذا عند العمل مع شبكات OLAP، أو التحليل متعدد الأبعاد، أو شبكات ذكاء الأعمال، أو عرض بيانات SSAS. يغطي اتصالات مصدر بيانات OLAP، وعمليات التنقل لأسفل/لأعلى، وعرض مؤشرات الأداء الرئيسية، وتحليل الأبعاد، وتصور بيانات المكعب لتطبيقات WPF.
