Implementieren Sie Syncfusion WPF OLAP Grid für die mehrdimensionale OLAP-Datenanalyse. Verwenden Sie dies, wenn Sie mit OLAP-Rastern, mehrdimensionalen Analysen, Business-Intelligence-Rastern oder der SSAS-Datenanzeige arbeiten. Behandelt OLAP-Datenquellenverbindungen, Drilldown-/Up-Vorgänge, KPI-Anzeige, Dimensionsanalyse und Cube-Datenvisualisierung für WPF-Anwendungen.
