Implementa la griglia OLAP Syncfusion WPF per l'analisi dei dati OLAP multidimensionali. Utilizzarlo quando si lavora con griglie OLAP, analisi multidimensionali, griglie di business intelligence o visualizzazione di dati SSAS. Copre le connessioni alle origini dati OLAP, le operazioni di drill down/up, la visualizzazione KPI, l'analisi dimensionale e la visualizzazione dei dati del cubo per le applicazioni WPF.
