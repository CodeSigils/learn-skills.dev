Внедрите Syncfusion WPF OLAP Grid для многомерного анализа данных OLAP. Используйте это при работе с сетками OLAP, многомерным анализом, сетками бизнес-аналитики или отображением данных SSAS. Охватывает подключения к источникам данных OLAP, операции детализации/вверх, отображение ключевых показателей эффективности, анализ размерностей и визуализацию данных куба для приложений WPF.
