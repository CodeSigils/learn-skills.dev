Implemente Syncfusion WPF SplitButton (SplitButtonAdv) con menús desplegables, enlace de comandos y enlace de datos. Esta habilidad se aplica cada vez que un usuario menciona el botón dividido de WPF, los botones desplegables con menús, el control SplitButtonAdv, la implementación de patrones de botones divididos, las combinaciones de botones y menús o escenarios que requieren un botón con una acción predeterminada y un menú desplegable. También es relevante para el botón dividido habilitado para comandos WPF, implementaciones de botón dividido basadas en MVVM, menús desplegables vinculados a datos o cualquier situación que involucre botones que ofrezcan elementos desplegables seleccionables.
