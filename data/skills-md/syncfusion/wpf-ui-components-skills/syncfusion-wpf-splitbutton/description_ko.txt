드롭다운 메뉴, 명령 바인딩 및 데이터 바인딩을 사용하여 Syncfusion WPF SplitButton(SplitButtonAdv)을 구현합니다. 이 기술은 사용자가 WPF 분할 버튼, 메뉴가 포함된 드롭다운 버튼, SplitButtonAdv 컨트롤, 분할 버튼 패턴 구현, 버튼 메뉴 조합 또는 기본 작업과 드롭다운 메뉴가 모두 포함된 버튼이 필요한 시나리오를 언급할 때마다 적용됩니다. 또한 WPF 명령 사용 분할 버튼, MVVM 기반 분할 버튼 구현, 데이터 바인딩된 드롭다운 메뉴 또는 선택 가능한 드롭다운 항목을 제공하는 버튼과 관련된 모든 상황과도 관련이 있습니다.
