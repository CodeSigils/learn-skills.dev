Реализуйте Syncfusion WPF SplitButton (SplitButtonAdv) с раскрывающимися меню, привязкой команд и привязкой данных. Этот навык применяется всякий раз, когда пользователь упоминает кнопку разделения WPF, раскрывающиеся кнопки с меню, элемент управления SplitButtonAdv, реализацию шаблонов кнопок разделения, комбинации кнопок и меню или сценарии, которые требуют кнопки как с действием по умолчанию, так и с раскрывающимся меню. Это также актуально для разделенных кнопок WPF с поддержкой команд, реализаций разделенных кнопок на основе MVVM, раскрывающихся меню с привязкой к данным или любой ситуации, связанной с кнопками, которые предлагают выбираемые раскрывающиеся элементы.
