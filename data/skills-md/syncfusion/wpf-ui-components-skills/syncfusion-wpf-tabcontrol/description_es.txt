Cree y administre componentes WPF TabControl (TabControlExt) para organizar el contenido en pestañas. Utilice esta habilidad cuando los usuarios necesiten implementar interfaces con pestañas, administrar la selección de pestañas, configurar botones de cierre, manejar interacciones de pestañas (hacer clic, navegación con el teclado), personalizar la apariencia de las pestañas (orientación, ubicación) o vincular datos de pestañas. Cubre la creación de pestañas a través de XAML/C#, administración de elementos de pestañas, manejo de eventos, menús contextuales, reordenamiento mediante arrastrar y soltar y temas.
