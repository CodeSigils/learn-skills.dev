Create and manage WPF TabControl (TabControlExt) components for organizing content into tabs. Utilice esta habilidad cuando los usuarios necesiten implementar interfaces con pestañas, administrar la selección de pestañas, configurar botones de cierre, manejar interacciones de pestañas (hacer clic, navegación con el teclado), personalizar la apariencia de las pestañas (orientación, ubicación) o vincular datos de pestañas. Covers tab creation via XAML/C#, tab item management, event handling, context menus, drag-and-drop reordering, and theming.
