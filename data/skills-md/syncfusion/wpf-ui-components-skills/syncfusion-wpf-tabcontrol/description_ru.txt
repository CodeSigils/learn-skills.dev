Создавайте компоненты WPF TabControl (TabControlExt) и управляйте ими для организации контента на вкладках. Используйте этот навык, когда пользователям необходимо реализовать интерфейсы с вкладками, управлять выбором вкладок, настраивать кнопки закрытия, обрабатывать взаимодействия с вкладками (щелчок, навигация с помощью клавиатуры), настраивать внешний вид вкладок (ориентацию, размещение) или привязывать данные вкладок. Охватывает создание вкладок с помощью XAML/C#, управление элементами вкладок, обработку событий, контекстные меню, изменение порядка перетаскиванием и оформление тем.
