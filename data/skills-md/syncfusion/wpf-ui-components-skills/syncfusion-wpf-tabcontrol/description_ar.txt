قم بإنشاء وإدارة مكونات WPF TabControl (TabControlExt) لتنظيم المحتوى في علامات تبويب. استخدم هذه المهارة عندما يحتاج المستخدمون إلى تنفيذ واجهات مبوبة، أو إدارة تحديد علامات التبويب، أو تكوين أزرار الإغلاق، أو التعامل مع تفاعلات علامات التبويب (النقر، والتنقل عبر لوحة المفاتيح)، أو تخصيص مظهر علامة التبويب (الاتجاه، أو الموضع)، أو ربط بيانات علامة التبويب. يغطي إنشاء علامة التبويب عبر XAML/C#، وإدارة عناصر علامة التبويب، ومعالجة الأحداث، وقوائم السياق، وإعادة ترتيب السحب والإفلات، والسمات.
