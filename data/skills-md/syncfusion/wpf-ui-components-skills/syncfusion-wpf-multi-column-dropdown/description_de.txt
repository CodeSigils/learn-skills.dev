Implementiert Syncfusion WPF Multi Column Dropdown (SfMultiColumnDropDownControl) zum Anzeigen durchsuchbarer Dropdown-Listen mit Rasteransicht. Verwenden Sie dies, wenn Sie Dropdown-Listen mit mehreren Spalten, Autovervollständigungsfunktionen oder filterbaren Datenrastern in Kombinationsfeldern erstellen. Unterstützt Datenbindung, Spaltenkonfiguration, Auswahl mehrerer Zeilen und Popup-Anpassung.
