Implementa el menú desplegable de múltiples columnas de Syncfusion WPF (SfMultiColumnDropDownControl) para mostrar listas desplegables con capacidad de búsqueda con vista de cuadrícula. Úselo al crear menús desplegables con varias columnas, función de autocompletar o cuadrículas de datos filtrables en cuadros combinados. Admite enlace de datos, configuración de columnas, selección de varias filas y personalización de ventanas emergentes.
