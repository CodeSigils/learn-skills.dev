Реализует раскрывающийся список с несколькими столбцами Syncfusion WPF (SfMultiColumnDropDownControl) для отображения раскрывающихся списков с возможностью поиска в виде сетки. Используйте это при создании раскрывающихся списков с несколькими столбцами, функцией автозаполнения или фильтруемых сеток данных в полях со списком. Поддерживает привязку данных, настройку столбцов, выбор нескольких строк и настройку всплывающих окон.
