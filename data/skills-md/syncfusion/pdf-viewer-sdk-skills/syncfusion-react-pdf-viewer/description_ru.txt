Реализует средство просмотра PDF-файлов Syncfusion React (PdfViewerComponent) для встраивания, настройки и загрузки PDF-документов. Используйте это при рендеринге PDF-файлов в приложении React, внедрении элементов управления средством просмотра или создании кода TSX/HTML для отображения и взаимодействия с PDF-файлами.
