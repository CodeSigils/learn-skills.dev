Implémente Syncfusion .NET MAUI SfPdfViewer pour la visualisation, la navigation, les annotations, le remplissage/validation de formulaires, la recherche/sélection de texte, les signatures électroniques, la rédaction, l'impression et la personnalisation de la barre d'outils/de l'interface utilisateur de PDF multiplateforme. À utiliser lorsque vous travaillez avec la configuration de la visionneuse PDF, les annotations de documents, les champs de formulaire ou les flux de travail de signature dans les applications MAUI.
