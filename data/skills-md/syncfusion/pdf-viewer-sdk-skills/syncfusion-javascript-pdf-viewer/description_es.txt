Implementa Syncfusion Javascript (ES6) y un visor de PDF (PdfViewer) que distingue entre mayúsculas y minúsculas para incrustar, configurar y cargar documentos PDF. Úselo al renderizar archivos PDF en una aplicación TypeScript utilizando el enfoque basado en clases EJ2, incrustando controles de visor o generando código TypeScript y HTML para visualización e interacción de PDF.
