Implementa Syncfusion Javascript (ES6) è un visualizzatore PDF con distinzione tra maiuscole e minuscole (PdfViewer) per incorporare, configurare e caricare documenti PDF. Utilizzalo durante il rendering di PDF in un'applicazione TypeScript utilizzando l'approccio basato sulla classe EJ2, incorporando controlli del visualizzatore o generando codice TypeScript e HTML per la visualizzazione e l'interazione del PDF.
