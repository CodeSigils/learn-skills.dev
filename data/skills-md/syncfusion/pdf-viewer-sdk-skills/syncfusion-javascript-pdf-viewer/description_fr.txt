Implémente Syncfusion Javascript (ES6) qui est une visionneuse PDF sensible à la casse (PdfViewer) pour l'intégration, la configuration et le chargement de documents PDF. Utilisez-le lors du rendu de PDF dans une application TypeScript à l'aide de l'approche basée sur les classes EJ2, en intégrant des contrôles de visualisation ou en générant du code TypeScript et HTML pour l'affichage et l'interaction des PDF.
