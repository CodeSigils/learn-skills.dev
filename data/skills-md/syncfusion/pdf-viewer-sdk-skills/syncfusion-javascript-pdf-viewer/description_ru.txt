Реализует Syncfusion Javascript (ES6) — средство просмотра PDF-файлов (PdfViewer) с учетом регистра для встраивания, настройки и загрузки PDF-документов. Используйте это при рендеринге PDF-файлов в приложении TypeScript с использованием подхода на основе классов EJ2, внедрении элементов управления средства просмотра или создании кода TypeScript и HTML для отображения и взаимодействия с PDF-файлами.
