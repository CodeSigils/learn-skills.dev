Écrit des preuves de vérificateur de modèle limité Kani pour les programmes Rust. Prouve les propriétés de conservation, d’isolement, de sécurité arithmétique et de contrôle d’accès. À utiliser lorsque l'utilisateur demande des preuves Kani, une vérification de modèle bornée ou une vérification formelle exhaustive -- ou lorsque le code contient kani::, #[kani::proof] ou #[kani::unwind]. Ne PAS utiliser pour le fuzzing (proptest, quickcheck, cargo-fuzz), les tests de propriété ou Miri.
