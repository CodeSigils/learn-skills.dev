Escribe pruebas de verificación de modelos acotados Kani para programas Rust. Demuestra propiedades de conservación, aislamiento, seguridad aritmética y control de acceso. Úselo cuando el usuario solicite pruebas de Kani, verificación de modelo acotado o verificación formal exhaustiva, o cuando el código contenga kani::, #[kani::proof] o #[kani::unwind]. NO lo use para fuzzing (proptest, quickcheck, cargo-fuzz), pruebas de propiedades o Miri.
