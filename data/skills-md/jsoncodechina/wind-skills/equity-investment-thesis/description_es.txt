Se utiliza para una investigación en profundidad sobre la lógica de inversión central de acciones individuales, centrándose en la investigación de acciones, el análisis fundamental y la investigación institucional. Esta habilidad sirve principalmente para escenarios como responder preguntas de los usuarios, redactar informes y redactar artículos financieros. El informe genera un contenido extenso y no es adecuado para escenarios de diálogo simples. Se puede obtener diversa información y datos utilizando la herramienta wind.financial.data con palabras clave apropiadas o combinaciones de palabras clave. Cuando un usuario ingresa el nombre de una acción, espera recibir rápidamente un análisis de acciones de alta calidad que se asemeje al estilo de un analista de investigación de corretaje.
