Wind MCP Data Bridge-Skill (v1.1.0, 6 Server / 19 Tools). Geroutet von „server_type“:  
(1) „Kurs“-Marktdaten (A-Aktien/Hongkong-Aktien-Snapshots, tägliche/wöchentliche/monatliche K-Linien, Minutenbalken);  
(2) „fund_data“-Fondsinformationen (Profile/Finanzdaten/Bestände/Leistung/Aktionäre/Unternehmen);  
(3) „stock_data“ Deep Equity (Profile/Fundamentaldaten/Kapitalstruktur/Ereignisse/Technik/Risiko);  
(4) „financial_docs“-Dokument RAG (Ankündigungen/Finanznachrichten);  
(5) „economic_data“ EDB-Makro- und Branchenindikatoren;  
(6) „analytics_data“ generische NL → Winddaten.  

Erfordert WIND_API_KEY (erhalten Sie im aimarket.wind.com.cn Developer Center).  
Auslöseszenarien: A-Aktien / HK-Ticker / K-Linien / Minutenbalken, jede Fondsdimension, Aktiengewinne / -bewertung, Einreichungen / Nachrichten börsennotierter Unternehmen, Makrodaten, Vergleiche zwischen Vermögenswerten.  

**Ausgeschlossen**: US-/EU-/JP-Aktien, FX-/Futures-Orderbuch, Krypto, nichtfinanzielle Daten.
