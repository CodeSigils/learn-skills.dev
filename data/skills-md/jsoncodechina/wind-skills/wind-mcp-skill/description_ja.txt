Wind MCP データ ブリッジ スキル (v1.1.0、6 サーバー / 19 ツール)。 `server_type` によるルート: (1) `quote` 市場データ (A 株 / 香港株スナップショット、日次 / 週次 / 月次 K ライン、分足)。 (2) `fund_data` ファンド (プロフィール / 財務 / 保有銘柄 / 業績 / 株主 / 企業); (3) 「stock_data」の深い株式 (プロファイル / ファンダメンタルズ / 資本構成 / イベント / テクニカル / リスク); (4) 「financial_docs」ドキュメント RAG (お知らせ/ニュース)。 (5) 「economic_data」EDB マクロ + 業界指標。 (6) `analytics_data` 汎用 NL → 風力データ。 WIND_API_KEY が必要です (aimarket.wind.com.cn 開発者センターで入手)。トリガー: A 株 / 香港コード / K ライン / 分、あらゆるファンドのディメンション、株式レポート / 評価、上場企業の申告書 / ニュース、マクロ データ、資産間の比較。 **除外対象**: 米国/EU/日本株、FX/先物注文簿、仮想通貨、非財務データ。
