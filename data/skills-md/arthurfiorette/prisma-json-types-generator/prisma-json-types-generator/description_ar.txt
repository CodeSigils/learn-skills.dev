يُستخدم عند إنشاء أو تحديث حقول Prisma `Json` أو `String` أو `String[]` أو `Int` أو `Float` المكتوبة باستخدام prisma-json-types-generator، بما في ذلك تعليقات `/// [Type]` و`/// ![Type]`، والحقول الحرفية المشابهة للتعداد، والأنواع المضمنة مقابل الأنواع المسماة، والأنواع التي تم إنشاؤها لا تزال تعرض `JsonValue`، "غير معروف"، أو أنواع عددية عادية.
