Используйте при поиске или изучении документации API, проиндексированной в каталоге сканирования API через REST. Используется для: поиска конечной точки, поиска документации API, содержимого раздела поиска, запроса каталога сканирования API, изучения вставленного API, получения сведений о конечной точке, получения сведений о разделе.
