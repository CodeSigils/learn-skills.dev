يُستخدم عند البحث أو استكشاف وثائق واجهة برمجة التطبيقات المفهرسة في كتالوج زحف واجهة برمجة التطبيقات عبر REST. يُستخدم من أجل: البحث عن نقطة النهاية، والبحث في مستندات واجهة برمجة التطبيقات، ومحتوى قسم البحث، والاستعلام عن كتالوج الزحف إلى واجهة برمجة التطبيقات، واستكشاف واجهة برمجة التطبيقات المستوعبة، وجلب تفاصيل نقطة النهاية، وجلب تفاصيل القسم.
