À utiliser lors de la recherche ou de l'exploration de la documentation API indexée dans le catalogue api-crawl via REST. À utiliser pour : rechercher un point de terminaison, rechercher des documents sur l'API, rechercher le contenu d'une section, interroger un catalogue d'exploration d'API, explorer l'API ingérée, récupérer les détails du point de terminaison, récupérer les détails de la section.
