Créez un design Figma à partir d'un code ou d'une description - l'inverse de figma-codegen. Réutilise le système de conception existant du fichier connecté (composants, variables, styles) au lieu de dessiner des primitives avec des valeurs codées en dur. Se déclenche chaque fois que l'utilisateur souhaite que quelque chose soit créé ou mis à jour DANS Figma à partir d'un code ou d'une spécification - par ex. « construire ceci dans Figma », « créer une conception Figma pour cela », « pousser ce composant/écran vers Figma », « transformer ce React/Vue en une conception Figma », « recréer cette interface utilisateur dans Figma », « créer une version Figma de… », « concevoir une page de destination/un écran dans Figma » – ou chaque fois qu'un artefact de codage (un composant, une page ou une spécification) apparaît à côté d'une demande de création dans un fichier Figma connecté. Fonctionne pour les pleins écrans, les sections, les composants uniques ou les ressources du système de conception.
