Erstellen Sie ein Figma-Design aus Code oder einer Beschreibung – das Gegenteil von figma-codegen. Verwendet das vorhandene Designsystem der verbundenen Datei (Komponenten, Variablen, Stile) wieder, anstatt Grundelemente mit fest codierten Werten zu zeichnen. Wird immer dann ausgelöst, wenn der Benutzer möchte, dass aus Code oder einer Spezifikation etwas IN Figma erstellt oder aktualisiert wird – z. B. „Erstellen Sie dies in Figma“, „Erstellen Sie ein Figma-Design dafür“, „Übertragen Sie diese Komponente/diesen Bildschirm an Figma“, „verwandeln Sie diesen React/Vue in ein Figma-Design“, „erstellen Sie diese Benutzeroberfläche in Figma neu“, „erstellen Sie eine Figma-Version von …“, „Entwerfen Sie eine Landingpage/einen Landingpage/Bildschirm in Figma“ – oder wann immer ein Codierungsartefakt (eine Komponente, Seite oder Spezifikation) neben einer Anfrage zum Verfassen in einer verbundenen Figma-Datei erscheint. Funktioniert für Vollbildschirme, Abschnitte, einzelne Komponenten oder Designsystem-Assets.
