Cree un diseño de Figma a partir de un código o una descripción: lo contrario de figma-codegen. Reutiliza el sistema de diseño existente del archivo conectado (componentes, variables, estilos) en lugar de dibujar primitivos con valores codificados. Se activa cuando el usuario quiere que se cree o actualice algo EN Figma a partir de un código o una especificación, p. 'construir esto en Figma', 'crear un diseño de Figma para esto', 'empujar este componente/pantalla a Figma', 'convertir este React/Vue en un diseño de Figma', 'recrear esta interfaz de usuario en Figma', 'hacer una versión de Figma de...', 'diseñar una página de destino/pantalla en Figma', o cada vez que un artefacto de codificación (un componente, página o especificación) aparece junto con una solicitud de creación en un archivo Figma conectado. Funciona para pantallas completas, secciones, componentes individuales o activos de sistemas de diseño.
