Générez du code compatible avec le framework à partir d'une conception Figma. Lit le profil de pile du projet et émet du code correspondant au framework existant (React/Vue/Svelte/Next/etc.) et au style (Tailwind/CSS/CSS-in-JS), en réutilisant les composants et les jetons de conception existants au lieu de régénérer à partir de zéro. Se déclenche chaque fois que l'utilisateur souhaite qu'une conception Figma soit transformée en code - par ex. « coder cette conception », « implémenter ce cadre », « construire cet écran/composant », « transformer ce Figma en React/Vue », « convertir cette conception en code » – ou chaque fois qu'une URL Figma ou la sélection Figma actuelle apparaît à côté d'une demande de codage. Fonctionne pour les pleins écrans, les sections uniques ou un composant.
