Genere código compatible con el marco a partir de un diseño de Figma. Lee el perfil de pila del proyecto y emite código que coincide con el marco existente (React/Vue/Svelte/Next/etc.) y el estilo (Tailwind/CSS/CSS-in-JS), reutilizando componentes existentes y tokens de diseño en lugar de regenerarse desde cero. Se activa cuando el usuario desea que un diseño de Figma se convierta en código, p. 'codificar este diseño', 'implementar este marco', 'construir esta pantalla/componente', 'convertir este Figma en React/Vue', 'convertir este diseño en código', o cada vez que aparezca una URL de Figma o la selección actual de Figma junto con una solicitud de codificación. Funciona para pantallas completas, secciones individuales o un componente.
