Generieren Sie Framework-fähigen Code aus einem Figma-Design. Liest das Stack-Profil des Projekts und gibt Code aus, der dem vorhandenen Framework (React/Vue/Svelte/Next/etc.) und dem Stil (Tailwind/CSS/CSS-in-JS) entspricht, wobei vorhandene Komponenten und Design-Tokens wiederverwendet werden, anstatt sie von Grund auf neu zu generieren. Wird immer dann ausgelöst, wenn der Benutzer möchte, dass ein Figma-Design in Code umgewandelt wird – z. B. „Dieses Design codieren“, „Diesen Frame implementieren“, „Diesen Bildschirm/diese Komponente erstellen“, „Dieses Figma in React/Vue umwandeln“, „Dieses Design in Code konvertieren“ – oder wann immer eine Figma-URL oder die aktuelle Figma-Auswahl neben einer Codierungsanfrage erscheint. Funktioniert für Vollbildschirme, einzelne Abschnitte oder eine Komponente.
