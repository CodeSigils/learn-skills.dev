Genere un proyecto Wren MDL explorando una base de datos con las herramientas disponibles (SQLAlchemy, controladores de bases de datos, conectores MCP o SQL sin formato). Guía a los agentes a través del descubrimiento de esquemas, la normalización de tipos y la generación de MDL YAML mediante la CLI de wren. Úselo cuando: el usuario desee crear o configurar un nuevo MDL, incorporar una nueva fuente de datos o desarrollar un proyecto a partir de una base de datos existente.
