Generieren Sie ein Wren-MDL-Projekt, indem Sie eine Datenbank mit verfügbaren Tools (SQLAlchemy, Datenbanktreiber, MCP-Konnektoren oder Roh-SQL) erkunden. Führt Agenten mithilfe der Wren-CLI durch die Schemaerkennung, Typnormalisierung und MDL-YAML-Generierung. Verwenden Sie diese Option, wenn: Der Benutzer eine neue MDL erstellen oder einrichten, eine neue Datenquelle integrieren oder ein Projekt aus einer vorhandenen Datenbank erstellen möchte.
