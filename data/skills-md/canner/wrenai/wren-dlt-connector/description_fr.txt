Connectez les données SaaS (HubSpot, Stripe, Salesforce, GitHub, Slack, etc.) à Wren Engine pour l'analyse SQL. Guide l'utilisateur tout au long du flux : installer dlt, choisir une source SaaS, configurer les informations d'identification, exécuter le pipeline de données dans DuckDB, puis générer automatiquement un projet sémantique Wren à partir des données chargées. Utilisez cette compétence chaque fois que l'utilisateur mentionne : connecter des données SaaS, importer des données à partir d'une API, des pipelines dlt, charger des données HubSpot/Stripe/Salesforce/GitHub/Slack, interroger des données SaaS avec SQL ou configurer une nouvelle source de données à partir d'une API REST. Se déclenche également lorsque l'utilisateur dispose déjà d'un fichier DuckDB produit par dlt et souhaite créer un projet Wren à partir de celui-ci.
