Conecte datos de SaaS (HubSpot, Stripe, Salesforce, GitHub, Slack, etc.) a Wren Engine para análisis SQL. Guía al usuario a través del flujo completo: instale dlt, elija una fuente SaaS, configure las credenciales, ejecute la canalización de datos en DuckDB y luego genere automáticamente un proyecto semántico Wren a partir de los datos cargados. Utilice esta habilidad siempre que el usuario mencione: conectar datos de SaaS, importar datos desde una API, canalizaciones dlt, cargar datos de HubSpot/Stripe/Salesforce/GitHub/Slack, consultar datos de SaaS con SQL o configurar una nueva fuente de datos desde una API REST. También se activa cuando el usuario ya tiene un archivo DuckDB producido por dlt y desea crear un proyecto Wren a partir de él.
