Connetti i dati SaaS (HubSpot, Stripe, Salesforce, GitHub, Slack, ecc.) a Wren Engine per l'analisi SQL. Guida l'utente attraverso il flusso completo: installa dlt, scegli un'origine SaaS, imposta le credenziali, esegui la pipeline di dati in DuckDB, quindi genera automaticamente un progetto semantico Wren dai dati caricati. Utilizza questa competenza ogni volta che l'utente menziona: connessione di dati SaaS, importazione di dati da un'API, pipeline dlt, caricamento di dati HubSpot/Stripe/Salesforce/GitHub/Slack, query di dati SaaS con SQL o impostazione di una nuova origine dati da un'API REST. Si attiva anche quando l'utente ha già un file DuckDB prodotto da dlt e desidera creare un progetto Wren da esso.
