DB スキーマでは扱えないビジネス コンテキストを使用して Wren プロジェクトを強化します。列挙値の意味、単位 (USD とセント、ミリ秒と秒)、NULL セマンティクス、マジック センチネル (-1 = 不明)、ソフトデリートのデフォルト フィルター、ビジネス シノニム、時間粒度 / TZ 規則、システム間識別子、通貨ルール、正規テーブルの設定、および名前付き集計メトリクス (ARR、チャーン、DAU、 WAU、NRR) は立方体として提案されます。セッション開始時に選択された 2 つのモードのいずれかで実行されます: 「グリル」 (一度に 1 つの質問、ユーザー主導) または「自動パイロット」 (エージェントが推論して適用し、競合および新しいキューブ/ビュー/関係などの大きな爆発半径の追加の場合にのみエスカレーションします)。 <project>/raw/ 内のすべて (PDF、用語集、ハンドブック、コード、データ ディクショナリ) を読み取り、オプションでライブ DB (グリル モード) からカーディナリティの低い列をサンプリングし、現在の MDL / cubes /指示.md / queries.yml / メモリのペアと比較して、10 カテゴリのギャップ カタログとキューブ提案フローを介してギャップを埋めます。確認された結果は、右のシンクに書き戻されます。次の場合に使用します: ユーザーが「コンテキストを充実させてください」、「プロジェクトを拡張してください」、「このプロジェクトについて詳しく説明してください」、「コンテキストを自動入力してください」、「エージェントがドキュメント / 列挙値 / 単位 / null の意味を理解していません」、「ビジネス コンテキストが欠落しています」、「status=A の意味は何ですか」、「この金額は米ドルですか、それともセントですか」、「間違った集計が繰り返されます」、「ARR のキューブを追加します」 DAU / チャーン」、「エージェントが知っておくべきハンドブック / 用語集 / データ辞書があります」;または、MDL を生成し、エージェントにビジネス セマンティクスが欠けていることに気づいた後。
