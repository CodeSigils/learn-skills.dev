Wren CLI per agenti AI: un livello SQL semantico su oltre 22 database (Postgres, MySQL, BigQuery, Snowflake, Spark, ...). Le guide al flusso di lavoro effettive si trovano all'interno della stessa CLI `wren`; questa è solo una matrice di scoperta. Utilizzare ogni volta che l'utente pone una domanda sui dati (quanti, mostrami, top N, confronto, tendenza, suddivisione, metrica, entrate, clienti, ordini), desidera installare/configurare Wren Engine, connettere un nuovo database, connettere dati SaaS tramite dlt (HubSpot, Stripe, Salesforce, GitHub, Slack), generare o rigenerare un progetto MDL da uno schema di database o arricchire un progetto con contesto aziendale (significati enum, unità, cubi come ARR/DAU/ sbattimento).
