Wren CLI لوكلاء الذكاء الاصطناعي - طبقة SQL دلالية تزيد عن 22 قاعدة بيانات (Postgres، MySQL، BigQuery، Snowflake، Spark، ...). توجد أدلة سير العمل الفعلية داخل واجهة سطر الأوامر "wren" نفسها؛ هذا مجرد كعب اكتشاف. يُستخدم عندما يسأل المستخدم سؤالاً عن البيانات (كم، أرني، أعلى N، مقارنة، اتجاه، تفصيل، قياس، إيرادات، عملاء، طلبات)، يريد تثبيت/إعداد Wren Engine، توصيل قاعدة بيانات جديدة، توصيل بيانات SaaS عبر dlt (HubSpot، Stripe، Salesforce، GitHub، Slack)، إنشاء أو إعادة إنشاء مشروع MDL من مخطط قاعدة بيانات، أو إثراء مشروع بسياق الأعمال (معاني التعداد، الوحدات، المكعبات مثل ARR / DAU / مخض). المشغلات: "تثبيت wren"، "إعداد محرك wren"، "ربط قاعدة البيانات بـ wren"، "توصيل SaaS بـ wren"، "تحميل بيانات hubspot / stripe / salesforce"، "إنشاء mdl"، "مشروع scaffold wren"، "إثراء سياق wren"، "زيادة مشروعي"، "إضافة مكعبات"، "wren onboarding"، "استخدام wren"، "wren create mdl"، "wren" موصل dlt، "سياق إثراء النمنمة".
