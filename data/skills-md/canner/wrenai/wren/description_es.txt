Wren CLI para agentes de IA: una capa SQL semántica sobre más de 22 bases de datos (Postgres, MySQL, BigQuery, Snowflake, Spark,…). Las guías de flujo de trabajo reales se encuentran dentro de la propia CLI `wren`; esto es sólo un trozo de descubrimiento. Úselo siempre que el usuario haga una pregunta sobre datos (cuántos, muéstreme, N principales, comparar, tendencia, desglose, métrica, ingresos, clientes, pedidos), quiera instalar/configurar Wren Engine, conectar una nueva base de datos, conectar datos SaaS a través de dlt (HubSpot, Stripe, Salesforce, GitHub, Slack), generar o regenerar un proyecto MDL a partir de un esquema de base de datos o enriquecer un proyecto con contexto empresarial (significados de enumeración, unidades, cubos como ARR/DAU/ abandono).
