Wren CLI для агентов ИИ — семантический уровень SQL для более чем 22 баз данных (Postgres, MySQL, BigQuery, Snowflake, Spark,…). Фактические руководства по рабочему процессу находятся внутри самого CLI `wren`; это всего лишь заглушка открытия. Используйте всякий раз, когда пользователь задает вопрос о данных (сколько, покажите мне, верхнее N, сравнение, тренд, разбивка, метрика, доход, клиенты, заказы), хочет установить/настроить Wren Engine, подключить новую базу данных, подключить данные SaaS через dlt (HubSpot, Stripe, Salesforce, GitHub, Slack), сгенерировать или восстановить проект MDL из схемы базы данных или обогатить проект бизнес-контекстом (значения перечисления, единицы измерения, кубы, такие как ARR/DAU/ отток). Триггеры: «установить wren», «настроить механизм wren», «подключить базу данных к wren», «подключить SaaS к wren», «загрузить данные Hubspot / Stripe / Salesforce», «сгенерировать mdl», «проект wren scaffold», «обогатить контекст wren», «расширить мой проект», «добавить кубы», «включение крапивника», «использование крапивника», «крапивник генерировать mdl», «крапивник dlt» соединитель», «крапивник обогащает контекст».
