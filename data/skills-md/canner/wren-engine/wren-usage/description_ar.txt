دليل سير عمل Wren Engine CLI لوكلاء الذكاء الاصطناعي. أجب عن أسئلة البيانات من البداية إلى النهاية باستخدام Wren CLI: جمع سياق المخطط، واستدعاء الاستعلامات السابقة، وكتابة SQL من خلال الطبقة الدلالية MDL، والتنفيذ، والتعلم من النتائج المؤكدة. يُستخدم عندما: يطرح المستخدم سؤالاً يتعلق بالبيانات، أو يطلب تقريرًا أو تحليلاً، أو يسأل عن المقاييس، أو الإيرادات، أو العملاء، أو الطلبات، أو الاتجاهات، أو أي بيانات عمل؛ يقول المستخدم "كم"، "أرني"، "ما هو"، "أعلى N"، "مقارنة"، "الاتجاه"، "النمو"، "الانهيار"؛ يريد المستخدم استكشاف البيانات أو تحليلها أو تصفيتها أو تجميعها أو تلخيصها من قاعدة البيانات؛ يحتاج الوكيل إلى الاستعلام عن البيانات، أو توصيل مصدر بيانات، أو معالجة الأخطاء، أو إدارة تغييرات MDL عبر Wren CLI.
