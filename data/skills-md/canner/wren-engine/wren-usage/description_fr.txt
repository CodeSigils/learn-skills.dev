Guide de flux de travail Wren Engine CLI pour les agents IA. Répondez aux questions sur les données de bout en bout à l'aide de la CLI wren : rassemblez le contexte du schéma, rappelez les requêtes précédentes, écrivez du SQL via la couche sémantique MDL, exécutez et apprenez des résultats confirmés. À utiliser lorsque : l'utilisateur pose une question sur les données, demande un rapport ou une analyse, pose des questions sur les mesures, les revenus, les clients, les commandes, les tendances ou toute autre donnée commerciale ; l'utilisateur dit « combien », « montre-moi », « quel est le », « top N », « comparer », « tendance », « croissance », « répartition » ; l'utilisateur souhaite explorer, analyser, filtrer, agréger ou résumer les données d'une base de données ; L'agent doit interroger des données, connecter une source de données, gérer les erreurs ou gérer les modifications MDL via la CLI wren.
