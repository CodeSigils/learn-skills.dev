Guida al flusso di lavoro CLI di Wren Engine per agenti AI. Rispondi alle domande sui dati end-to-end utilizzando la CLI wren: raccogli il contesto dello schema, richiama le query precedenti, scrivi SQL attraverso il livello semantico MDL, esegui e apprendi dai risultati confermati. Utilizzare quando: l'utente pone una domanda sui dati, richiede un report o un'analisi, chiede informazioni su metriche, entrate, clienti, ordini, tendenze o dati aziendali; l'utente dice "quanti", "mostrami", "qual è il", "top N", "confronta", "tendenza", "crescita", "ripartizione"; l'utente desidera esplorare, analizzare, filtrare, aggregare o riepilogare i dati da un database; l'agente deve eseguire query sui dati, connettere un'origine dati, gestire errori o gestire le modifiche MDL tramite la CLI wren.
