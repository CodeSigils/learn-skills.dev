Руководство по рабочему процессу CLI Wren Engine для агентов ИИ. Отвечайте на вопросы о данных комплексно, используя Wren CLI: собирайте контекст схемы, вспоминайте прошлые запросы, записывайте SQL через семантический уровень MDL, выполняйте и учитесь на подтвержденных результатах. Используйте, когда: пользователь задает вопрос о данных, запрашивает отчет или анализ, спрашивает о показателях, доходах, клиентах, заказах, тенденциях или любых бизнес-данных; пользователь говорит «сколько», «покажи мне», «что такое», «верхнее N», «сравнить», «тенденция», «рост», «разбивка»; пользователь хочет исследовать, анализировать, фильтровать, агрегировать или суммировать данные из базы данных; Агенту необходимо запрашивать данные, подключать источник данных, обрабатывать ошибки или управлять изменениями MDL через Wren CLI.
