Guía de flujo de trabajo CLI de Wren Engine para agentes de IA. Responda preguntas sobre datos de un extremo a otro utilizando la CLI de wren: recopile el contexto del esquema, recupere consultas anteriores, escriba SQL a través de la capa semántica MDL, ejecute y aprenda de los resultados confirmados. Úselo cuando: el usuario hace una pregunta sobre datos, solicita un informe o análisis, pregunta sobre métricas, ingresos, clientes, pedidos, tendencias o cualquier dato comercial; el usuario dice "cuántos", "muéstrame", "cuál es el", "N superior", "comparar", "tendencia", "crecimiento", "desglose"; el usuario desea explorar, analizar, filtrar, agregar o resumir datos de una base de datos; El agente necesita consultar datos, conectar una fuente de datos, manejar errores o administrar cambios de MDL a través de la CLI de wren.
