Wren Engine CLI-Workflow-Leitfaden für KI-Agenten. Beantworten Sie Datenfragen durchgängig mit der Wren-CLI: Sammeln Sie den Schemakontext, rufen Sie frühere Abfragen ab, schreiben Sie SQL über die semantische MDL-Schicht, führen Sie sie aus und lernen Sie aus bestätigten Ergebnissen. Verwenden Sie diese Option, wenn: der Benutzer eine Datenfrage stellt, einen Bericht oder eine Analyse anfordert, nach Kennzahlen, Umsatz, Kunden, Bestellungen, Trends oder anderen Geschäftsdaten fragt; Der Benutzer sagt „wie viele“, „zeig mir“, „was ist das“, „Top N“, „vergleichen“, „Trend“, „Wachstum“, „Aufschlüsselung“; Der Benutzer möchte Daten aus einer Datenbank untersuchen, analysieren, filtern, aggregieren oder zusammenfassen. Der Agent muss Daten abfragen, eine Datenquelle verbinden, Fehler behandeln oder MDL-Änderungen über die Wren-CLI verwalten.
