قم بإنشاء مشروع Wren MDL من خلال استكشاف قاعدة بيانات باستخدام الأدوات المتاحة (SQLAlchemy، أو برامج تشغيل قاعدة البيانات، أو موصلات MCP، أو SQL الخام). يرشد الوكلاء من خلال اكتشاف المخطط وتطبيع النوع وإنشاء MDL YAML باستخدام wren CLI. يُستخدم عندما: يريد المستخدم إنشاء MDL جديد أو إعداده، أو تضمين مصدر بيانات جديد، أو دعم مشروع من قاعدة بيانات موجودة.
