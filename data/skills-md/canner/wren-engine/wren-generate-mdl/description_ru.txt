Создайте проект Wren MDL, исследуя базу данных с помощью доступных инструментов (SQLAlchemy, драйверы базы данных, соединители MCP или необработанный SQL). Помогает агентам обнаруживать схемы, нормализовать типы и генерировать MDL YAML с помощью Wren CLI. Используйте, когда: пользователь хочет создать или настроить новый MDL, подключить новый источник данных или создать проект на основе существующей базы данных.
