Générez un projet Wren MDL en explorant une base de données avec les outils disponibles (SQLAlchemy, pilotes de base de données, connecteurs MCP ou SQL brut). Guide les agents tout au long de la découverte de schémas, de la normalisation des types et de la génération MDL YAML à l’aide de la CLI wren. À utiliser lorsque : l'utilisateur souhaite créer ou configurer un nouveau MDL, intégrer une nouvelle source de données ou échafauder un projet à partir d'une base de données existante.
