SaaS データ (HubSpot、Stripe、Salesforce、GitHub、Slack など) を Wren Engine に接続して SQL 分析を行います。ユーザーに完全なフローをガイドします: dlt のインストール、SaaS ソースの選択、資格情報のセットアップ、DuckDB へのデータ パイプラインの実行、ロードされたデータからの Wren セマンティック プロジェクトの自動生成。 SaaS データの接続、API からのデータのインポート、DLT パイプライン、HubSpot/Stripe/Salesforce/GitHub/Slack データのロード、SQL を使用した SaaS データのクエリ、または REST API からの新しいデータ ソースのセットアップについてユーザーが言及するたびに、このスキルを使用します。また、ユーザーが dlt で生成された DuckDB ファイルを既に持っており、そこから Wren プロジェクトを作成したい場合にもトリガーされます。
