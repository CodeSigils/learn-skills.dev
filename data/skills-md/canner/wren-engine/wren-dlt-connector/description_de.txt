Verbinden Sie SaaS-Daten (HubSpot, Stripe, Salesforce, GitHub, Slack usw.) zur SQL-Analyse mit Wren Engine. Führt den Benutzer durch den gesamten Ablauf: dlt installieren, eine SaaS-Quelle auswählen, Anmeldeinformationen einrichten, die Datenpipeline in DuckDB ausführen und dann automatisch ein semantisches Wren-Projekt aus den geladenen Daten generieren. Verwenden Sie diesen Skill immer dann, wenn der Benutzer Folgendes erwähnt: SaaS-Daten verbinden, Daten aus einer API importieren, DLT-Pipelines laden, HubSpot-/Stripe-/Salesforce-/GitHub-/Slack-Daten laden, SaaS-Daten mit SQL abfragen oder eine neue Datenquelle über eine REST-API einrichten. Wird auch ausgelöst, wenn der Benutzer bereits über eine von DLT erstellte DuckDB-Datei verfügt und daraus ein Wren-Projekt erstellen möchte.
