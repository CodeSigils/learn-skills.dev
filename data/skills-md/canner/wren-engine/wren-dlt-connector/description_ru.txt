Подключите данные SaaS (HubSpot, Stripe, Salesforce, GitHub, Slack и т. д.) к Wren Engine для анализа SQL. Проводит пользователя через весь процесс: устанавливает dlt, выбирает источник SaaS, устанавливает учетные данные, запускает конвейер данных в DuckDB, а затем автоматически генерирует семантический проект Wren на основе загруженных данных. Используйте этот навык всякий раз, когда пользователь упоминает: подключение данных SaaS, импорт данных из API, конвейеры DLT, загрузку данных HubSpot/Stripe/Salesforce/GitHub/Slack, запрос данных SaaS с помощью SQL или настройку нового источника данных из REST API. Также срабатывает, когда у пользователя уже есть файл DuckDB, созданный dlt, и он хочет создать из него проект Wren.
