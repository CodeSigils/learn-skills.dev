Используйте этот навык всякий раз, когда пользователю требуется мультиагентная проверка локальных изменений — триггеры включают «проверьте мой код», «проверьте эти изменения», «сделайте проверку кода» или «проверьте мои изменения перед их фиксацией». Пишет REVIEW.md. НЕ используйте для открытого PR по номеру (используйте /review) или для пропуска, специфичного для безопасности (используйте /security-review).
