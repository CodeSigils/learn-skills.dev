Tipografía y sistemas tipográficos: tamaño de fuente, escala de tipografía, altura de línea, peso, ritmo vertical, emparejamiento de fuentes y un nivel mínimo de legibilidad que detiene el texto pequeño/delgado/de bajo contraste. Utilice esta habilidad siempre que el usuario quiera ajustar el tamaño del texto, crear una escala de tipos, corregir tipos ilegibles, establecer un ritmo vertical o seleccionar y emparejar fuentes. NO lo use para paletas de colores; consulte el sistema de colores; diseño: consulte diseño de interfaz.
