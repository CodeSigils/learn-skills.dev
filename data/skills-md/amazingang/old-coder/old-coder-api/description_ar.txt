صمم أو غيّر أو راجع سطح واجهة برمجة التطبيقات HTTP/JSON — النقاط النهائية، هياكل الطلب/الاستجابة، المصادقة والتفويض، التقسيم إلى صفحات، عدم التكرار، حدود السرعة، النسخ وإهمالاتها. استخدمه عند إضافة أو تعديل نقطة نهائية HTTP، مراجعة مواصفة OpenAPI أو اختلافات مسار HTTP، أو اتخاذ قرار ما إذا كان تغيير واجهة HTTP يعرّض المستهلكين لمشكلات. لا تستخدمه كقائمة تحقق لتوافق البروتوكول لـ gRPC/Protobuf أو GraphQL أو WebSockets أو أي واجهات غير HTTP/JSON.
