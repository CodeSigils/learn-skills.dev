تصميم أو تغيير أو مراجعة سطح HTTP/JSON API - نقاط النهاية، وأشكال الطلب/الاستجابة، والمصادقة والترخيص، وترقيم الصفحات، والعجز، وحدود المعدل، والإصدارات، والإهمال. يُستخدم عند إضافة نقطة نهاية HTTP أو تعديلها، أو مراجعة مواصفات OpenAPI أو اختلاف مسار HTTP، أو تحديد ما إذا كان تغيير HTTP API يعطل المستهلكين. لا تستخدم كقائمة التحقق من توافق البروتوكول مع gRPC/protobuf، أو GraphQL، أو WebSockets، أو واجهات أخرى غير HTTP/JSON.
