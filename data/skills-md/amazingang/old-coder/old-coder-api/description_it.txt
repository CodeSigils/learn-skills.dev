Progetta, modifica o rivedi una superficie API HTTP/JSON: endpoint, forme di richiesta/risposta, autenticazione e autorizzazione, impaginazione, idempotenza, limiti di velocità, controllo delle versioni e deprecazioni. Da utilizzare quando si aggiunge o si modifica un endpoint HTTP, si esamina una specifica OpenAPI o una differenza di percorso HTTP o si decide se una modifica dell'API HTTP danneggia i consumer. Non utilizzare come elenco di controllo della compatibilità del protocollo per gRPC/protobuf, GraphQL, WebSocket o altre interfacce non HTTP/JSON.
