Progetta, modifica o revisiona la superficie di un'API HTTP/JSON — endpoint, forme delle richieste/risposte, autenticazione e autorizzazione, paginazione, idempotenza, limiti di velocità, versionamento e deprecazioni. Usala quando aggiungi o modifichi un endpoint HTTP, rivedi una specifica OpenAPI o un diff di rotte HTTP, o decidi se una modifica all'API HTTP impatta i consumatori. Non usarla come checklist di compatibilità di protocollo per gRPC/protobuf, GraphQL, WebSocket o altre interfacce non HTTP/JSON.
