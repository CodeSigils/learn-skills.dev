Entwerfen, ändern oder überprüfen Sie eine HTTP/JSON-API-Oberfläche – Endpunkte, Anforderungs-/Antwortformen, Authentifizierung und Autorisierung, Paginierung, Idempotenz, Ratenbegrenzungen, Versionierung und Verwerfungen. Verwenden Sie diese Option, wenn Sie einen HTTP-Endpunkt hinzufügen oder ändern, eine OpenAPI-Spezifikation oder einen HTTP-Routenunterschied überprüfen oder entscheiden, ob eine HTTP-API-Änderung Verbraucher unterbricht. Nicht als Protokollkompatibilitäts-Checkliste für gRPC/protobuf, GraphQL, WebSockets oder andere Nicht-HTTP/JSON-Schnittstellen verwenden.
