Entwerfen, ändern oder überprüfen Sie eine HTTP/json-API-Oberfläche — Endpunkte, Anfrage-/Antwortformen, Authentifizierung und Autorisierung, Paginierung, Idempotenz, Ratenlimits, Versionierung und Deprecations. Verwenden Sie diese Option, wenn Sie einen HTTP-Endpunkt hinzufügen oder ändern, eine OpenAPI-Spezifikation oder eine HTTP-Route-Diff überprüfen oder entscheiden, ob eine HTTP-API-Änderung den Verbrauchern schadet. Verwenden Sie nicht als Protokollkompatibilitätscheckliste für gRPC/protobuf-, GraphQL-, WebSockets- oder andere Nicht-HTTP/json-Schnittstellen.
