Diseña, modifica o revisa la superficie de una API HTTP/JSON — puntos finales, formas de solicitud/respuesta, autenticación y autorización, paginación, idempotencia, límites de tasa, versionado y deprecaciones. Úsalo al agregar o modificar un punto final HTTP, al revisar una especificación OpenAPI o una diferencia de rutas HTTP, o al decidir si un cambio en la API HTTP rompe a los consumidores. No lo uses como lista de verificación de compatibilidad de protocolo para gRPC/protobuf, GraphQL, WebSockets u otras interfaces que no sean HTTP/JSON.
