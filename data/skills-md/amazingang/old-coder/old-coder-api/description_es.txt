Diseñar, cambiar o revisar una superficie de API HTTP/JSON: puntos finales, formas de solicitud/respuesta, autenticación y autorización, paginación, idempotencia, límites de velocidad, control de versiones y obsoletos. Úselo al agregar o modificar un punto de conexión HTTP, al revisar una especificación OpenAPI o una diferencia de ruta HTTP, o al decidir si un cambio de API HTTP afecta a los consumidores. No lo utilice como una lista de verificación de compatibilidad de protocolos para gRPC/protobuf, GraphQL, WebSockets u otras interfaces que no sean HTTP/JSON.
