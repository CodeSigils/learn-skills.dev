كتابة أو تعديل مطالبات الفيديو العامة القابلة للتكرار ومواصفات الحركة للقطات الدراما القصيرة والإطارات الرئيسية المقبولة. عندما يذكر المستخدم مطالبات الفيديو، أو تحويل النص إلى فيديو، أو إجراءات الصورة إلى الفيديو، أو عملية أداء الشخصية، أو حركة الكاميرا، أو مزامنة الحوار مع الشفاه، أو الحركة البيئية، أو مدة اللقطة، أو حالات البداية/الانتهاء، أو استخدامها مباشرة عند تحويل القصص المصورة إلى مطالبات فيديو؛ قم فقط بوصف الحركة والأداء والتصوير السينمائي والصوت ضمن لقطة واحدة محددة مسبقًا، دون إنشاء فيديو أو استدعاء أي نماذج أو واجهات برمجة التطبيقات الخاصة بالموردين، ودون تغيير حدود القصة المصورة.
