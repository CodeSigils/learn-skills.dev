استنادًا إلى تهيئة نظام الملفات ومواصلته واسترداده وتسليم مشاريع الدراما القصيرة أو الدراما الكوميدية، وتوفير لوحة معلومات محلية للمبدعين؛ كما أنه يتعامل أيضًا مع تنظيم تطوير المظهر على مستوى المشروع / اتجاه إطار النمط ومعايرة مراقبة الإنتاج المعتمدة. يخدم كتاب السيناريو واستوديوهات الدراما الكوميدية والمخرجين. يمكن للمستخدمين طلب "إنشاء/مواصلة مشروع درامي قصير"، أو "عرض التقدم/الخطوات التالية"، أو "تنفيذ تطوير المظهر"، أو "معايرة هذا المشروع من خلال مراقبة الإنتاج"، أو "لوحة التحكم المفتوحة/محطة إنشاء الدراما القصيرة"، أو "استعادة إصدار متقطع أو غير مكتمل"، أو "تصدير مواد الإنتاج"، أو عندما تمتد المهام إلى مراحل متعددة ويكون الهدف غير واضح، حدد أولاً الحالة الحالية والمهارة المسؤولة؛ يتم التعامل مع الكتابة الصريحة أو الأصول أو المطالبات أو القصص المصورة أو طلبات المراجعة مباشرة من خلال المهارة الفرعية المقابلة.
