اكتب أو قم بتعديل مطالبات صورة الأصل العامة القابلة لإعادة الاستخدام لشخصيات الدراما القصيرة والتصميمات والمشاهد ووجهات النظر والدعائم والحالات، وقم بإسقاط الاتجاه المرئي المقبول في شخصيات تطوير المظهر أو المواقع أو إطارات نمط الضغط العالي. عندما يذكر المستخدم فن مفهوم الشخصية، أو طرق العرض الإملائية، أو الصور المرجعية للشخصية، أو فن مفهوم المشهد، أو لقطات المشهد الفارغة، أو لوحات المشهد، أو صور الدعامات، أو إطارات النمط، أو تطوير المظهر، أو متغيرات التصميم أو الحالة، أو مطالبات التحرير المحلية، أو طلبات تعديل مطالبات الصور الموجودة باستخدام اللغة الطبيعية، استخدمها مباشرة؛ قم بإخراج المواصفات المنظمة ونص Markdown فقط، ولا تنشئ صورًا، ولا تستدعي أي نموذج أو واجهات برمجة التطبيقات الخاصة بالمورد.
