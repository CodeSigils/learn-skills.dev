اكتب أو قم بتحرير مطالبات صور الأصول العامة القابلة لإعادة الاستخدام لشخصيات الدراما القصيرة والتصميمات والمشاهد ووجهات النظر والدعائم والحالات، وقم بعرض الاتجاه المرئي المقبول في شخصيات تطوير المظهر أو المواقع أو إطارات النمط عالية الضغط. عندما يذكر المستخدمون أوراق تصميم الشخصيات، أو طرق العرض الإملائية، أو الصور المرجعية للشخصية، أو أوراق تصميم المشهد، أو لقطات المشهد الفارغة، أو لوحات المشهد، أو صور الدعامات، أو إطارات الأنماط، أو تطوير المظهر، أو متغيرات التصميم أو الحالة، أو مطالبات التحرير المترجمة، أو طلب تعديلات على مطالبات الصور الموجودة باستخدام اللغة الطبيعية، استخدمها مباشرة؛ قم بإخراج المواصفات المنظمة ونص Markdown فقط، ولا تنشئ صورًا، ولا تستدعي أي نموذج أو واجهات برمجة التطبيقات الخاصة بالمورد.
