Configure y utilice mise para la gestión de herramientas de desarrollo, variables de entorno y ejecución de tareas. Utilice esta habilidad cuando el usuario quiera configurar las herramientas del proyecto con mise, administrar versiones de herramientas (nodo, python, go, etc.), definir tareas en mise.toml, configurar variables de entorno por proyecto o preguntar sobre la configuración de mise, backends, ganchos o comandos CLI.
