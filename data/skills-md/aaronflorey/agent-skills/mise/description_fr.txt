Configurez et utilisez mise pour la gestion des outils de développement, les variables d'environnement et l'exécution des tâches. Utilisez cette compétence lorsque l'utilisateur souhaite configurer les outils du projet avec mise, gérer les versions des outils (node, python, go, etc.), définir des tâches dans mise.toml, configurer les variables d'environnement par projet ou poser des questions sur la configuration de mise, les backends, les hooks ou les commandes CLI.
