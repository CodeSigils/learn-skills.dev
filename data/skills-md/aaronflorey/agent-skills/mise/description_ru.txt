Настройте и используйте Mise для управления инструментами разработки, переменными среды и выполнением задач. Используйте этот навык, когда пользователь хочет настроить инструменты проекта с помощью Mise, управлять версиями инструментов (node, Python, go и т. д.), определять задачи в mise.toml, настраивать переменные среды для каждого проекта или задавать вопросы о конфигурации Mise, бэкэндах, перехватчиках или командах CLI.
