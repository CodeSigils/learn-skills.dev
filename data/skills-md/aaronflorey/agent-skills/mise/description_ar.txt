قم بتكوين واستخدام mise لإدارة أدوات التطوير ومتغيرات البيئة وتشغيل المهام. استخدم هذه المهارة عندما يريد المستخدم إعداد أدوات المشروع باستخدام Mise، أو إدارة إصدارات الأداة (العقدة، أو python، أو go، وما إلى ذلك)، أو تحديد المهام في Mise.toml، أو تكوين متغيرات البيئة لكل مشروع، أو الاستفسار عن تكوين Mise، أو الواجهات الخلفية، أو الخطافات، أو أوامر واجهة سطر الأوامر (CLI).
