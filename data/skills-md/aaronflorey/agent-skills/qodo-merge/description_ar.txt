قم بتكوين واستخدام Qodo Merge، المعروف سابقًا باسم PR-Agent، لمراجعات طلبات السحب والأوصاف والاقتراحات المضمنة والتسميات والمستندات وفحص التذاكر المدعومة بالذكاء الاصطناعي عبر GitHub وGitLab وBitbucket وAzure DevOps. استخدم هذه المهارة عندما يذكر المستخدم Qodo Merge أو PR-Agent أو `.pr_agent.toml` أو `pr_agent` أو روبوتات مراجعة PR أو `/describe` أو `/review` أو `/improve` أو تطبيق GitHub أو إعداد الإجراء أو تكوين النموذج أو تصحيح أخطاء أتمتة PR-Agent.
