Configurez et utilisez Qodo Merge, anciennement PR-Agent, pour les examens, les descriptions, les suggestions en ligne, les étiquettes, les documents et les vérifications de tickets alimentés par l'IA sur GitHub, GitLab, Bitbucket et Azure DevOps. Utilisez cette compétence chaque fois que l'utilisateur mentionne Qodo Merge, PR-Agent, `.pr_agent.toml`, `pr_agent`, les robots de révision des relations publiques, `/describe`, `/review`, `/improve`, la configuration de l'application ou de l'action GitHub, la configuration du modèle ou le débogage de l'automatisation du PR-Agent.
