Создавайте, формируйте и отлаживайте приложения Go CLI, используя библиотеку spf13/cobra. Используйте этот навык всякий раз, когда пользователь хочет создать интерфейс командной строки в Go, добавить команды/подкоманды, работать с флагами (постоянными, локальными, обязательными), реализовать завершение оболочки, сгенерировать документацию или задать что-либо о разработке CLI на основе Cobra.
