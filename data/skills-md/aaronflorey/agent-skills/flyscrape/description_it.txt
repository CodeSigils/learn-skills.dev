Scrivi ed esegui script di web scraping con "flyscrape", lo scraper CLI autonomo con selettori simili a jQuery. Utilizza questa abilità quando l'utente chiede di eseguire lo scraping di un sito, estrarre dati da HTML, seguire l'impaginazione, eseguire la scansione di più pagine, scaricare file, utilizzare la modalità browser, configurare selettori o menziona "flyscrape", uno script di scraping, scraping nidificato o scansione con controllo della profondità.
