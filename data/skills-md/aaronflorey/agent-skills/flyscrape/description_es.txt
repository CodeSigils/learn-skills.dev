Escriba y ejecute scripts de raspado web con `flyscrape`, el raspador CLI independiente con selectores similares a jQuery. Utilice esta habilidad cuando el usuario solicite raspar un sitio, extraer datos de HTML, seguir la paginación, rastrear varias páginas, descargar archivos, usar el modo de navegador, configurar selectores o mencione "flyscrape", un script de raspado, raspado anidado o rastreo controlado en profundidad.
