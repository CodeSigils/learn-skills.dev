Используйте GitHub CLI, `gh`, для аутентификации, работы с репозиторием, проблем, запросов на включение, выпусков, действий, проектов и вызовов `gh api`. Используйте этот навык всякий раз, когда пользователь упоминает `gh`, `gh pr`, `gh Issue`, `gh repo`, `gh run`, `gh workflow`, `gh auth`, хочет получить пример команды GitHub CLI, ему нужно создать сценарий операций GitHub или перевести шаги пользовательского интерфейса GitHub в команды терминала.
