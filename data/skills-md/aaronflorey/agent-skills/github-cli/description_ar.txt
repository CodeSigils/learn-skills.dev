استخدم GitHub CLI، `gh`، للمصادقة، وعمل المستودع، والمشكلات، وطلبات السحب، والإصدارات، والإجراءات، والمشاريع، واستدعاءات `gh api`. استخدم هذه المهارة عندما يذكر المستخدم `gh`، `gh pr`، `gh Issue`، `gh repo`، `gh run`، `gh Workflow`، `gh auth`، أو يريد مثال أمر GitHub CLI، أو يحتاج إلى برمجة عمليات GitHub، أو يريد ترجمة خطوات GitHub UI إلى أوامر طرفية.
