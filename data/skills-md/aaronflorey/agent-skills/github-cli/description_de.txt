Verwenden Sie die GitHub-CLI „gh“ für Authentifizierung, Repository-Arbeit, Probleme, Pull-Requests, Releases, Aktionen, Projekte und „gh-API“-Aufrufe. Verwenden Sie diesen Skill immer dann, wenn der Benutzer „gh“, „gh pr“, „gh issue“, „gh repo“, „gh run“, „gh Workflow“, „gh auth“ erwähnt, ein GitHub-CLI-Befehlsbeispiel wünscht, GitHub-Vorgänge skripten muss oder GitHub-UI-Schritte in Terminalbefehle übersetzen möchte.
