Utilizza la CLI di GitHub, `gh`, per l'autenticazione, il lavoro sul repository, i problemi, le richieste pull, le versioni, le azioni, i progetti e le chiamate `gh api`. Utilizza questa competenza ogni volta che l'utente menziona `gh`, `gh pr`, `gh issue`, `gh repo`, `gh run`, `gh flusso di lavoro`, `gh auth`, desidera un esempio di comando CLI di GitHub, deve eseguire script di operazioni GitHub o desidera tradurre i passaggi dell'interfaccia utente di GitHub in comandi del terminale.
