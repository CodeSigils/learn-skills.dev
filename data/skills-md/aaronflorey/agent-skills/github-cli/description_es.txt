Utilice GitHub CLI, `gh`, para autenticación, trabajo de repositorio, problemas, solicitudes de extracción, lanzamientos, acciones, proyectos y llamadas de `gh api`. Utilice esta habilidad siempre que el usuario mencione `gh`, `gh pr`, `gh issues`, `gh repo`, `gh run`, `gh flow`, `gh auth`, quiera un ejemplo de comando de la CLI de GitHub, necesite escribir un script de operaciones de GitHub o quiera traducir los pasos de la interfaz de usuario de GitHub en comandos de terminal.
