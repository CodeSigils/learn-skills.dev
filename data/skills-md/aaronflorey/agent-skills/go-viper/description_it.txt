Scrivi, esegui il debug e spiega il codice di configurazione di Go utilizzando github.com/spf13/viper. Utilizzare questa abilità ogni volta che l'utente desidera il caricamento della configurazione basato su Viper, le strutture di configurazione, la precedenza di file più env più flag, l'integrazione di Cobra o pflag, l'annullamento del marshalling della configurazione nelle strutture, i sostituti della chiave env o un bootstrap di configurazione dell'applicazione pulito che segua il comportamento README di Viper.
