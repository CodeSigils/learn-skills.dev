Configura e utilizza GoReleaser per l'automazione del rilascio. Utilizza questa competenza durante la creazione o la modifica di file .goreleaser.yaml, l'impostazione di pipeline di rilascio, la creazione di file binari multipiattaforma, la pubblicazione su gestori di pacchetti (pacchetti Homebrew, Scoop, AUR, nFPM), la creazione di immagini Docker o l'automazione della generazione del registro delle modifiche. Supporta progetti Go, Rust, Zig, TypeScript (Bun/Deno) e Python (PyInstaller/UV/Poetry). Utilizzare anche quando viene chiesto di rilasciare software, creare versioni di GitHub o automatizzare la distribuzione binaria.
