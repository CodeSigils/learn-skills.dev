قم بتكوين واستخدام GoReleaser لأتمتة الإصدار. استخدم هذه المهارة عند إنشاء ملفات .goreleaser.yaml أو تحريرها، أو إعداد مسارات الإصدار، أو إنشاء ثنائيات عبر الأنظمة الأساسية، أو النشر إلى مديري الحزم (حزم Homebrew، أو Scoop، أو AUR، أو nFPM)، أو إنشاء صور Docker، أو إنشاء سجل التغيير تلقائيًا. يدعم مشاريع Go وRust وZig وTypeScript (Bun/Deno) وPython (PyInstaller/UV/Poetry). استخدمه أيضًا عند سؤالك عن إصدار البرامج، أو إنشاء إصدارات GitHub، أو أتمتة التوزيع الثنائي.
