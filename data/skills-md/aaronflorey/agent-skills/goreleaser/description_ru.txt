Настройте и используйте GoReleaser для автоматизации выпуска. Используйте этот навык при создании или редактировании файлов .goreleaser.yaml, настройке конвейеров выпуска, создании кросс-платформенных двоичных файлов, публикации в менеджерах пакетов (пакеты Homebrew, Scoop, AUR, nFPM), создании образов Docker или автоматизации создания журнала изменений. Поддерживает проекты Go, Rust, Zig, TypeScript (Bun/Deno) и Python (PyInstaller/UV/Poetry). Также используйте, когда вас спрашивают о выпуске программного обеспечения, создании выпусков GitHub или автоматизации распространения двоичных файлов.
