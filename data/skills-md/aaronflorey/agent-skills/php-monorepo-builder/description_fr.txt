Utilisez `symplify/monorepo-builder` pour gérer les monorepo PHP avec `vendor/bin/monorepo-builder` et `monorepo-builder.php`. Déclenchez cette compétence lorsque l'utilisateur mentionne monorepo-builder, fusionnant les fichiers du package « composer.json » dans une racine « composer.json », validant les versions inter-packages, configurant les répertoires de packages, propageant les dépendances ou automatisant les versions monorepo et les release Workers.
