Используйте `symplify/monorepo-builder` для управления монорепозиториями PHP с помощью `vendor/bin/monorepo-builder` и `monorepo-builder.php`. Активируйте этот навык, когда пользователь упоминает monorepo-builder, объединяет файлы пакета `composer.json` в корневой `composer.json`, проверяет версии между пакетами, настраивает каталоги пакетов, распространяет зависимости или автоматизирует выпуски monorepo и исполнителей релизов.
