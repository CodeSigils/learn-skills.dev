Utilice `symplify/monorepo-builder` para administrar monorepos PHP con `vendor/bin/monorepo-builder` y `monorepo-builder.php`. Active esta habilidad cuando el usuario mencione monorepo-builder, fusione archivos del paquete `composer.json` en una raíz `composer.json`, valide versiones entre paquetes, configure directorios de paquetes, propague dependencias o automatice lanzamientos de monorepo y trabajadores de lanzamiento.
