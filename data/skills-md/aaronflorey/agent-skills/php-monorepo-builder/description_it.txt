Utilizza `symplify/monorepo-builder` per gestire monorepos PHP con `vendor/bin/monorepo-builder` e `monorepo-builder.php`. Attiva questa abilità quando l'utente menziona monorepo-builder, unendo i file del pacchetto "composer.json" in un "composer.json" root, convalidando le versioni tra pacchetti, configurando le directory dei pacchetti, propagando le dipendenze o automatizzando i rilasci di monorepo e i releaseworker.
