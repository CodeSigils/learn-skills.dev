Verwenden Sie „symplify/monorepo-builder“, um PHP-Monorepos mit „vendor/bin/monorepo-builder“ und „monorepo-builder.php“ zu verwalten. Lösen Sie diesen Skill aus, wenn der Benutzer den Monorepo-Builder, das Zusammenführen von Paketdateien „composer.json“ in einem Stammverzeichnis „composer.json“, das Validieren von Versionen zwischen Paketen, das Konfigurieren von Paketverzeichnissen, die Weitergabe von Abhängigkeiten oder das Automatisieren von Monorepo-Releases und Release-Workern erwähnt.
