استخدم `symplify/monorepo-builder` لإدارة PHP monorepos باستخدام `vendor/bin/monorepo-builder` و`monorepo-builder.php`. قم بتشغيل هذه المهارة عندما يذكر المستخدم monorepo-builder، أو دمج ملفات الحزمة "composer.json" في جذر "composer.json"، أو التحقق من صحة الإصدارات بين الحزم، أو تكوين دلائل الحزمة، أو نشر التبعيات، أو أتمتة إصدارات monorepo وعمال الإصدار.
