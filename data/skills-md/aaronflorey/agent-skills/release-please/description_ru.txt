Настройте выпуск-пожалуйста для автоматических выпусков в репозитории. Используйте этот навык, когда пользователи хотят добавить в свой проект «пожалуйста, выпустите», настроить GitHub Actions для автоматических выпусков, настроить обычные рабочие процессы фиксации, создать файлы конфигурации «пожалуйста, выпустите» или загрузить «пожалуйста, выпустите» в новом или существующем репозитории.
