Configurez release-please pour les versions automatisées dans un référentiel. Utilisez cette compétence lorsque les utilisateurs souhaitent ajouter une version s'il vous plaît à leur projet, configurer des actions GitHub pour des versions automatisées, configurer des workflows de validation conventionnels, créer des fichiers de configuration s'il vous plaît ou amorcer une version s'il vous plaît dans un référentiel nouveau ou existant.
