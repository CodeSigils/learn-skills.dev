استخدم واجهة برمجة التطبيقات deps.dev، والتي تسمى أيضًا Open Source Insights، لجلب البيانات التعريفية للحزمة والإصدارات والرسوم البيانية التبعية والاستشارات وتعيينات المشروع وعمليات البحث عن التجزئة. استخدم هذه المهارة عندما يذكر المستخدم deps.dev، أو Open Source Insights، أو عمليات البحث عن الحزم أو الإصدارات، أو ذكاء التبعية، أو الرسوم البيانية التبعية التي تم حلها، أو عمليات البحث الخاطئة، أو الاستعلامات الاستشارية، أو دمج واجهة برمجة التطبيقات deps.dev في التعليمات البرمجية.
