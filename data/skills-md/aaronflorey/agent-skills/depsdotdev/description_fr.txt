Utilisez l'API deps.dev, également appelée Open Source Insights, pour récupérer les métadonnées des packages, les versions, les graphiques de dépendances, les conseils, les mappages de projets et les recherches de hachage. Utilisez cette compétence lorsque l'utilisateur mentionne deps.dev, Open Source Insights, les recherches de packages ou de versions, les informations sur les dépendances, les graphiques de dépendances résolus, les recherches purl, les requêtes consultatives ou l'intégration de l'API deps.dev dans le code.
