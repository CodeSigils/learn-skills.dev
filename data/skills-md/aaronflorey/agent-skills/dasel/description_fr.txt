Utilisez la CLI dasel v3 pour interroger, modifier et transformer des données structurées (JSON, YAML, TOML, XML, CSV, HCL, INI). Chargez cette compétence chaque fois que l'utilisateur souhaite : lire/écrire/convertir des fichiers de données avec dasel, écrire des expressions de requête dasel, filtrer/mapper/transformer des données structurées sur la ligne de commande, modifier les fichiers de configuration en place à l'aide de dasel, transmettre des données via dasel dans des scripts shell ou poser des questions sur la syntaxe, les fonctions ou les indicateurs CLI de dasel. Même s'ils disent simplement "utiliser Dasel pour..." ou "requête Dasel pour...", chargez cette compétence.
