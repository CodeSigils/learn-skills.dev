Laden Sie diesen Skill immer dann, wenn der Benutzer Folgendes möchte: Datendateien mit Dasel lesen/schreiben/konvertieren, Dasel-Abfrageausdrücke schreiben, strukturierte Daten auf der Befehlszeile filtern/zuordnen/transformieren, Konfigurationsdateien mit Dasel direkt bearbeiten, Daten in Shell-Skripten über Dasel weiterleiten oder nach Dasel-Syntax, Funktionen oder CLI-Flags fragen. Laden Sie diesen Skill, auch wenn sie nur „Verwenden Sie Dasel für…“ oder „Dasel-Abfrage für…“ sagen.
