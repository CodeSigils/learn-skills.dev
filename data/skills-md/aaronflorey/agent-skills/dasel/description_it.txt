Utilizza la CLI dasel v3 per eseguire query, modificare e trasformare dati strutturati (JSON, YAML, TOML, XML, CSV, HCL, INI). Carica questa competenza ogni volta che l'utente desidera: leggere/scrivere/convertire file di dati con dasel, scrivere espressioni di query dasel, filtrare/mappare/trasformare dati strutturati sulla riga di comando, modificare file di configurazione sul posto utilizzando dasel, convogliare dati tramite dasel negli script della shell o chiedere informazioni sulla sintassi, le funzioni o i flag della CLI di dasel. Anche se dicono semplicemente "usa dasel per..." o "dasel query per...", carica questa abilità.
