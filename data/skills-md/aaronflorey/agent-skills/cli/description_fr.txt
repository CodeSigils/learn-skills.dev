Acheminez le travail du terminal vers la CLI la plus étroite au lieu des modèles de shell génériques. Utilisez cette compétence lorsque l'utilisateur demande de rechercher avec `rg` ou `fd`, de réécrire du texte avec `sd`, `comby` ou `ast-grep`, d'inspecter la sortie avec `head` ou `less`, de récupérer des fichiers avec `wget`, de transformer JSON ou YAML avec `jq` ou `yq`, de sélectionner des éléments avec `fzf`, de comparer le code avec `difftastic`, de lint shell avec `shellcheck`, ou mesurez un dépôt avec `scc`.
