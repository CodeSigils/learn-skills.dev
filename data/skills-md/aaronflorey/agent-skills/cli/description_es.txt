Enrute el trabajo del terminal a la CLI más estrecha en lugar de patrones de shell genéricos. Utilice esta habilidad cuando el usuario solicite buscar con `rg` o `fd`, reescribir texto con `sd`, `comby` o `ast-grep`, inspeccionar la salida con `head` o `less`, recuperar archivos con `wget`, transformar JSON o YAML con `jq` o `yq`, seleccionar elementos con `fzf`, comparar código con `difftastic`, lint shell con `shellcheck` o medir un repositorio con `scc`.
