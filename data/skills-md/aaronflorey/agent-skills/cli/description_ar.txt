تعمل محطة التوجيه على أضيق واجهة سطر أوامر (CLI) بدلاً من أنماط الصدفة العامة. استخدم هذه المهارة عندما يطلب المستخدم البحث باستخدام `rg` أو `fd`، أو إعادة كتابة النص باستخدام `sd`، أو `comby`، أو ``ast-grep`، أو فحص المخرجات باستخدام `head` أو `less`، أو جلب الملفات باستخدام `wget`، أو تحويل JSON أو YAML باستخدام `jq` أو `yq`، واختيار العناصر باستخدام `fzf`، أو مقارنة التعليمات البرمجية بـ `difftastic`، أو lint shell باستخدام "shellcheck"، أو قياس الريبو باستخدام "scc".
