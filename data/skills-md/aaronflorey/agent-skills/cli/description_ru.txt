Направляйте работу терминала на самый узкий интерфейс командной строки вместо общих шаблонов оболочки. Используйте этот навык, когда пользователь просит выполнить поиск с помощью rg или fd, переписать текст с помощью sd, comby или ast-grep, проверить выходные данные с помощью head или less, получить файлы с помощью wget, преобразовать JSON или YAML с помощью jq или yq, выбрать элементы с помощью fzf, сравнить код с помощью difftastic, проверить оболочку с помощью Shellcheck или измерить репозиторий с помощью `скк`.
