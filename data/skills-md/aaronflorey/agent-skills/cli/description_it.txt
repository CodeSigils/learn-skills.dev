Indirizza il lavoro del terminale alla CLI più ristretta anziché a modelli di shell generici. Utilizza questa abilità quando l'utente chiede di cercare con `rg` o `fd`, riscrivere il testo con `sd`, `comby` o `ast-grep`, ispezionare l'output con `head` o `less`, recuperare file con `wget`, trasformare JSON o YAML con `jq` o `yq`, selezionare elementi con `fzf`, confrontare codice con `difftastic`, lint shell con `shellcheck` o misurare un repository con `scc`.
