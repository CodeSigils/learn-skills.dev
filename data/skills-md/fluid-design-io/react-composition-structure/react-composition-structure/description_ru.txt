Масштабируемые шаблоны архитектуры файловой системы React и React Native. Используйте при реструктуризации папок компонентов, модулей домена с привязкой к маршруту (календарь, корзина или поверхность оформления заказа, размещенные в `comComponents/`, `screens/` или любом дереве репо, а не в буквальном каталоге `features/`), границах экспорта `index.ts`, соглашениях об именах, совмещенных файлах `*.data.ts` или преобразовании шаблонов композиции в стабильную структуру репо. Триггеры по папкам составных компонентов, папкам модулей с привязкой к маршруту, очистке общедоступного API и примерам плохой и хорошей организации файлов.
