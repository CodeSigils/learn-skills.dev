React および React Native の拡張可能なファイル システム アーキテクチャ パターン。コンポーネント フォルダー、ルート バインドされたドメイン モジュール (`components/`、`screens/`、または任意のリポジトリ ツリーの下に配置されるカレンダー、カート、またはチェックアウト サーフェス - リテラルの `features/` ディレクトリではない)、`index.ts` エクスポート境界、命名規則、同じ場所に配置された `*.data.ts` ファイルを再構築するとき、または構成パターンを安定したリポジトリ構造に変換するときに使用します。複合コンポーネント フォルダー、ルート バインド モジュール フォルダー、パブリック API クリーンアップ、および悪いファイル構成と良いファイル構成の例をトリガーします。
