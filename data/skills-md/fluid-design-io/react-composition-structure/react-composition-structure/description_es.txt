Patrones de arquitectura de sistema de archivos React y React Native que escalan. Úselo al reestructurar carpetas de componentes, módulos de dominio vinculados a rutas (un calendario, carrito o superficie de pago colocado debajo de `componentes/`, `pantallas/` o cualquier árbol de repositorio, no un directorio literal `features/`), límites de exportación de `index.ts`, convenciones de nomenclatura, archivos `*.data.ts` colocados o al traducir patrones de composición a una estructura de repositorio estable. Activadores en carpetas de componentes compuestos, carpetas de módulos vinculados a rutas, limpieza de API pública y ejemplos de organización de archivos malos versus buenos.
