Modèles d'architecture de système de fichiers React et React Native évolutifs. À utiliser lors de la restructuration de dossiers de composants, de modules de domaine liés à un itinéraire (un calendrier, un panier ou une surface de paiement placé sous `components/`, `screens/` ou toute arborescence de dépôt - pas un répertoire littéral `features/`), les limites d'exportation `index.ts`, les conventions de dénomination, les fichiers `*.data.ts` colocalisés ou la traduction de modèles de composition en structure de dépôt stable. Déclencheurs sur les dossiers de composants composés, les dossiers de modules liés à l'itinéraire, le nettoyage de l'API publique et les exemples d'organisation de fichiers mauvais ou bon.
