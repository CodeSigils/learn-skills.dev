React e React Modelli di architettura di file system nativi scalabili. Da utilizzare durante la ristrutturazione delle cartelle dei componenti, dei moduli di dominio legati al percorso (un calendario, un carrello o una superficie di pagamento posizionata sotto "components/", "screens/" o qualsiasi albero di repository - non una directory "features/" letterale), i limiti di esportazione di "index.ts", le convenzioni di denominazione, i file "*.data.ts" co-localizzati o la traduzione di modelli di composizione in una struttura di repository stabile. Trigger su cartelle di componenti composti, cartelle di moduli legati al percorso, pulizia dell'API pubblica ed esempi di organizzazione di file cattivi/buoni.
