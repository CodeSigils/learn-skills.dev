React وReact أنماط بنية نظام الملفات الأصلية القابلة للقياس. يُستخدم عند إعادة هيكلة مجلدات المكونات، أو وحدات المجال المرتبطة بالمسار (تقويم، أو عربة التسوق، أو سطح الخروج الموضوع تحت `المكونات/`، أو الشاشات/`، أو أي شجرة ريبو - وليس دليل `الميزات/` الحرفي)، أو حدود التصدير `index.ts`، أو اصطلاحات التسمية، أو ملفات `*.data.ts`، أو ترجمة أنماط التركيب إلى بنية ريبو مستقرة. المشغلات على مجلدات المكونات المركبة، ومجلدات الوحدة النمطية المرتبطة بالمسار، وتنظيف واجهة برمجة التطبيقات العامة، وأمثلة تنظيم الملفات السيئة مقابل الجيدة.
