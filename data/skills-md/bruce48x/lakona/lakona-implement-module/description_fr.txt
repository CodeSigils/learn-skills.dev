Implémentez ou révisez les cycles de vie des ressources d'application ILakonaModule dans le code Server.App stable. À utiliser lors de l'ajout d'une base de données, de Redis, d'un cache, d'une file d'attente, d'un travailleur en arrière-plan ou d'autres ressources liées au processus ; déclarer le module NodeRole ; décider de la propriété DI pour les clients créés de manière asynchrone ; vérifier l'état de préparation à l'initialisation ; ou réparer les adaptateurs métier qui dépendent des modules de cycle de vie.
