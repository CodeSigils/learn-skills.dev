Controlla, spiega o riorganizza un server di gioco Lakona senza imporre un albero di cartelle universale. Da utilizzare quando si esaminano gli odori delle directory del server, si decide dove appartiene il codice Shared, Server.App o Server.Hotfix, si sostituiscono i cassetti spazzatura di livello tecnico con una località di dominio più chiara, si allineano gli spazi dei nomi dopo gli spostamenti o si convalida un layout server proposto preservando le scelte architettoniche dell'utente.
