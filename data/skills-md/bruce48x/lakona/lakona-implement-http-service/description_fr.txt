Implémentez ou mettez à jour les services HTTP complets de l'application Lakona dans Server.Hotfix. À utiliser lors de l'ajout d'un point de terminaison d'opérations, d'un webhook, d'un rappel de paiement ou d'un autre itinéraire de demande/réponse ; modifier les déclarations LakonaHttpService ou LakonaHttpEndpoint ; sélectionner l'exposition de l'auditeur ; correction de la liaison manifeste HTTP-à-Hotfix ; ou valider le corps brut, l'annulation, l'idempotence, le statut et le comportement de réponse.
