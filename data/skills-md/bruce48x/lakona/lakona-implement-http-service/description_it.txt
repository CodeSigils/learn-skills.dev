Implementare o aggiornare i servizi HTTP completi dell’applicazione Lakona in Server.Hotfix. Utilizzare quando si aggiunge un endpoint operazionale, webhook, callback di pagamento o altra rotta request/response; si modificano le dichiarazioni di LakonaHttpService o LakonaHttpEndpoint; si seleziona l’esposizione dell’ascoltatore; si corregge il binding del manifesto HTTP a Hotfix; o si valida raw‑body, cancellazione, idempotenza, stato e comportamento della risposta.  

Si prega di rispondere sempre nella lingua dell’utente.
