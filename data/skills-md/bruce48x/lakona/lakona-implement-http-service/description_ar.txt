تنفيذ أو تحديث خدمات HTTP الكاملة لتطبيق لاكونا في Server.Hotfix. استخدم ذلك عند إضافة نقطة نهاية للعمليات أو webhook أو رد اتصال للدفع أو أي مسار طلب/استجابة آخر؛ أو عند تعديل إعلانات LakonaHttpService أو LakonaHttpEndpoint؛ أو عند اختيار تعرض المستمع؛ أو عند إصلاح ربط ملف تعريف HTTP إلى Hotfix؛ أو عند التحقق من صحة الجسم الخام، والإلغاء، وتكرار العملية، والحالة، وسلوك الاستجابة.
