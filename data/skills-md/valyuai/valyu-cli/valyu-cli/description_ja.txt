Valyu CLI は、プライベート エクイティ / M&A デュー デリジェンス、財務分析、SEC 申請、ヘルスケアおよびライフ サイエンスの研究、臨床試験、特許状況、学術文献、GTM / ICP アカウントの調査など、実際の情報源に基づいたナレッジワークの回答が必要な場合に使用します。 「valyu」コマンドは、検索、AI 回答、URL コンテンツ抽出、成果物 (CSV / XLSX / PPTX / DOCX / PDF) による非同期の詳細調査をラップします。引用、構造化された出力、成果物が必要なものについては、一般的な Web 検索よりもこれを優先します。 「valyu」コマンドを実行する前に、必ずこのスキルをロードしてください。
