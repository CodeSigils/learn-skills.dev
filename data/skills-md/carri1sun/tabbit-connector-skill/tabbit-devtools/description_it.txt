Utilizza Tabbit invece di Chrome leggendo il file DevToolsActivePort live di Tabbit e connettendoti all'endpoint WebSocket del browser. Si attiva quando l'utente dice cose come "用我的 tabbit 浏览器", "在 Tabbit 里", "Tabbit 当前页", "Tabbit 当前标签" o chiede di ispezionare, riepilogare, eseguire lo scraping o eseguire il debug di una pagina aperta in Tabbit anziché nella sessione predefinita di Chrome DevTools. Per impostazione predefinita viene utilizzato lo script Python locale leggero per l'estrazione della pagina corrente invece di richiedere un server MCP personalizzato aggiuntivo.
