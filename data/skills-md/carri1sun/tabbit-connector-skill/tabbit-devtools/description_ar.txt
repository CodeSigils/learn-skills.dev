استخدم Tabbit بدلاً من Chrome من خلال قراءة ملف DevToolsActivePort المباشر الخاص بـ Tabbit والاتصال بنقطة نهاية WebSocket للمتصفح. يتم تشغيله عندما يقول المستخدم أشياء مثل "Tabbit 浏览器"، أو "Tabbit 里"، أو "Tabbit 当前页"، أو "Tabbit 当前标签"، أو عندما يطلب فحص أو تلخيص أو مسح أو تصحيح الأخطاء لصفحة مفتوحة في Tabbit بدلاً من جلسة Chrome DevTools الافتراضية. الافتراضي هو برنامج Python المحلي خفيف الوزن لاستخراج الصفحة الحالية بدلاً من طلب خادم MCP مخصص إضافي.
