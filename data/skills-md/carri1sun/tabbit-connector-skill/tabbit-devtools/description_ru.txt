Используйте Tabbit вместо Chrome, прочитав действующий файл DevToolsActivePort Tabbit и подключившись к конечной точке WebSocket браузера. Срабатывает, когда пользователь произносит такие слова, как «用我的 tabbit 浏览器», «在 Tabbit 里», «Tabbit 当前页», «Tabbit 当前标签» или просит проверить, обобщить, очистить или отладить страницу, открытую в Tabbit, а не в сеансе Chrome DevTools по умолчанию. По умолчанию используется облегченный локальный скрипт Python для извлечения текущей страницы вместо необходимости использования дополнительного пользовательского сервера MCP.
