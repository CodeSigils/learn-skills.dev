Rekonstruieren Sie den Designgeschmack jeder Website. Erfasst bei gegebener URL DOM-Daten und einen Screenshot über einen echten Browser und führt dann eine 4-stufige Analyse durch, um {domain}.md + {domain}.json mit praktischen Design-Tokens (Farben, Typografie, Abstände, Radien, Schatten, Raster) UND Geschmacks-DNA (Trigger → Entscheidung → Grund → Beweiskompromisse, die erklären, WARUM das Design funktioniert) zu erstellen. Verwenden Sie es immer dann, wenn der Benutzer das Designsystem einer Website extrahieren, die visuelle Sprache eines Mitbewerbers studieren, eine Ästhetik auf ein neues Projekt übertragen oder Designanweisungen für einen KI-Codierungsagenten generieren möchte. Auslöser für „/taste <url>“, „das Design von X analysieren“, „was die Website von X gut macht“, „Design-Tokens von Die Ausgabe lehnt KI-Vorurteile („sauber“, „modern“, „benutzerfreundlich“) zugunsten konkreter px/hex-Werte und eingeschränkter Kompromisse ab. NICHT zum Scrapen von Daten, zum Zusammenfassen von Seiteninhalten oder für Aufgaben verwenden, die nichts mit der visuellen Gestaltung zu tun haben.
