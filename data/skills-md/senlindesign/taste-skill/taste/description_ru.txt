Реверс-инжиниринг дизайна любого веб-сайта. Учитывая URL-адрес, захватывает данные DOM и делает снимок экрана через реальный браузер, затем запускает 4-этапный анализ для создания {domain}.md + {domain}.json с практическими токенами дизайна (цвета, типографика, интервалы, радиусы, тени, сетка) И ДНК вкуса (триггер → Решение → Причина → компромиссные доказательства, объясняющие, ПОЧЕМУ дизайн работает). Используйте его всякий раз, когда пользователь хочет извлечь информацию о системе дизайна сайта, изучить визуальный язык конкурентов, перенести эстетику в новый проект или создать руководство по дизайну для агента кодирования ИИ. Запускается по «/taste <url>», «проанализируйте дизайн X», «что делает сайт X хорошим», «извлеките токены дизайна из X», «дайте мне ДНК дизайна X», «создайте что-нибудь в стиле X», «Я хочу, чтобы мое приложение выглядело как X». В выводе отклоняются отбросы ИИ («чистые», «современные», «удобные для пользователя») в пользу конкретных значений пикселей/шестнадцатеричных значений и компромиссных ограничений. НЕ используйте для сбора данных, обобщения содержимого страниц или задач, не связанных с визуальным дизайном.
