Orquestador para la suite de aprendizaje: detecta automáticamente el tipo de fuente (artículo académico, repositorio de GitHub, blog/artículo web o aprendizaje en conversación) y dirige a la subhabilidad correcta para verificación de credibilidad, análisis de seguridad, extracción de información y aplicación. Se carga cuando el usuario dice "aprender de", "aprender de esto", "extraer conocimientos de", "aplicar lo aprendido de", "de qué podemos aprender" o proporciona una URL, una ruta de archivo o contenido pegado que debe ser ingerido como conocimiento. Punto de entrada único para todos los flujos de trabajo de aprendizaje.
