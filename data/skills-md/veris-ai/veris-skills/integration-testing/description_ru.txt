Запускайте интеграционные тесты репозитория в песочнице зависимостей Veris, а не в реальных поставщиках, при этом veris-proxy перенаправляет исходящий HTTP(S) кода на уровне ядра. Проверяет предварительные условия (ключ API, сервер Veris MCP, двоичный файл veris-proxy, докер), затем запускает тесты в контейнере рядом с прокси-сервером с помощью одной команды, которая развертывает песочницу для каждого запуска и доказывает, что песочница действительно получила трафик, прежде чем доверять любому зеленому. Используйте, когда код, который взаимодействует с внешними службами, нуждается в проверке своего поведения при интеграции, прежде чем изменение будет объявлено выполненным.
