Integre un repositorio de agente de cliente sin procesar con Veris de principio a fin. Instala o verifica veris-cli, inicia sesión, crea o reutiliza un entorno Veris, analiza el repositorio, genera o actualiza `.veris/veris.yaml`, `.veris/Dockerfile.sandbox`, `.veris/.dockerignore`, configura las variables env de tiempo de ejecución y puede finalizar con `veris env push`. Úselo cuando un repositorio aún no tiene la configuración de Veris, o cuando una integración `.veris/` existente está obsoleta y necesita ser actualizada.
