Trasforma un'idea di app o un'app React Native esistente in una lettura Nav: struttura a schede, albero del percorso, decisioni push/modali/foglio, collegamenti diretti, piano posteriore Android, senza creare schermate. Da utilizzare quando si pianifica la navigazione per una nuova app, si ristruttura la navigazione di un'app esistente o si decide se qualcosa è una scheda, un push, un modale o un foglio inferiore. Per costruire successivamente le schermate utilizzare mobile-taste; per la riprogettazione visiva dell'app completa, utilizzare l'app mobile-redesign.
