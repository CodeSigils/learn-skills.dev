Превратите идею приложения или существующее приложение React Native в структуру Nav Read — структуру вкладок, дерево маршрутов, решения push/modal/sheet, глубокие ссылки, задний план Android — без создания каких-либо экранов. Используйте при планировании навигации для нового приложения, реструктуризации навигации существующего приложения или принятии решения о том, является ли что-либо вкладкой, нажатием, модальным окном или нижним листом. Для последующего создания экранов используйте mobile-taste; для полного визуального редизайна приложения используйте mobile-redesign-app.
