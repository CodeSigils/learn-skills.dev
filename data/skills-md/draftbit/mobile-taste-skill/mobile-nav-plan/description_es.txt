Convierta una idea de aplicación o una aplicación React Native existente en una lectura de navegación (estructura de pestañas, árbol de rutas, decisiones push/modales/hojas, enlaces profundos, plan posterior de Android) sin crear ninguna pantalla. Úselo al planificar la navegación para una nueva aplicación, reestructurar la navegación de una aplicación existente o decidir si algo es una pestaña, una inserción, un modal o una hoja inferior. Para construir las pantallas posteriormente utilice mobile-taste; para el rediseño visual de la aplicación completa, utilice la aplicación de rediseño móvil.
