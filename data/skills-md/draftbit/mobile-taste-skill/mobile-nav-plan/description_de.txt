Verwandeln Sie eine App-Idee oder eine vorhandene React Native-App in eine Nav Read – Tab-Struktur, Routenbaum, Push-/Modal-/Sheet-Entscheidungen, Deep Links, Android-Backplan – ohne Bildschirme zu erstellen. Verwenden Sie diese Option, wenn Sie die Navigation für eine neue App planen, die Navigation einer vorhandenen App umstrukturieren oder entscheiden, ob es sich bei etwas um eine Registerkarte, einen Push, ein Modal oder ein unteres Blatt handelt. Zum anschließenden Erstellen der Bildschirme verwenden Sie mobile-taste; Für eine vollständige visuelle Neugestaltung der App verwenden Sie die mobile-redesign-app.
