Полный редизайн существующего приложения React Native / Expo — полный аудит (токены, навигация по сравнению с правилами Nav Read, архетипы экрана, считывание циферблата), решение о сохранении или капитальном ремонте, затем поэтапный план модернизации, выполняемый рычаг за рычагом на экранах с контрольными точками и регулятором рисков. Единственный навык в этом пакете позволял предлагать реструктуризацию навигации (с одобрением). Используйте, когда вас просят изменить дизайн, пересмотреть, провести ребрендинг или модернизировать все приложение. Для одного экрана используйте mobile-redesign-screen; для аудита без изменений используйте mobile-design-review.
