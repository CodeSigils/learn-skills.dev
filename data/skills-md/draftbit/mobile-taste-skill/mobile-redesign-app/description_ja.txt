既存の React Native / Expo アプリのアプリ全体の再設計 - 完全な監査 (トークン、ナビゲーションと Nav Read ルール、画面アーキタイプ、ダイヤル読み取り)、保存かオーバーホールかの決定、その後、チェックポイントとリスク ガバナーを備えた画面全体でレバーごとに段階的なモダナイゼーション プランを実行します。このスイートの唯一のスキルは、ナビゲーションの再構築を提案することができます (承認ゲート)。アプリ全体の再設計、オーバーホール、ブランド変更、または最新化を求められた場合に使用します。 1 つの画面の場合は mobile-redesign-screen を使用します。変更を加えずに監査するには、mobile-design-review を使用します。
