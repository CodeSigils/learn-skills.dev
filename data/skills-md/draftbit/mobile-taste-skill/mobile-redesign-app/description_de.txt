Komplette App-Neugestaltung einer bestehenden React Native/Expo-App – vollständige Prüfung (Tokens, Navigation im Vergleich zu den Nav-Read-Regeln, Bildschirmarchetypen, Zifferblattablesung), Entscheidung zwischen Erhaltung und Überholung, dann ein schrittweiser Modernisierungsplan, der Hebel für Hebel über Bildschirme hinweg mit Kontrollpunkten und einem Risikoregler ausgeführt wird. Der einzige Skill in dieser Suite, der es erlaubt, eine Navigationsumstrukturierung vorzuschlagen (genehmigungsabhängig). Verwenden Sie es, wenn Sie eine komplette App neu gestalten, überarbeiten, umbenennen oder modernisieren möchten. Für einen Bildschirm verwenden Sie mobile-redesign-screen; Für ein Audit ohne Änderungen nutzen Sie mobile-design-review.
