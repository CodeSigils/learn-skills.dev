إعادة تصميم التطبيق بالكامل لتطبيق React Native / Expo الحالي - التدقيق الكامل (الرموز المميزة، والتنقل مقابل قواعد Nav Read، ونماذج الشاشة، وقراءة القرص)، وقرار الحفظ مقابل الإصلاح الشامل، ثم يتم تنفيذ خطة التحديث المرحلية عبر الشاشات ذات نقاط التفتيش ومنظم المخاطر. المهارة الوحيدة في هذه المجموعة هي السماح باقتراح إعادة هيكلة التنقل (الموافقة عليها). يُستخدم عندما يُطلب منك إعادة تصميم تطبيق بأكمله أو إصلاحه أو تغيير علامته التجارية أو تحديثه. لشاشة واحدة، استخدم شاشة إعادة تصميم الهاتف المحمول؛ لإجراء تدقيق بدون تغييرات، استخدم mobile-design-review.
