Rediseño completo de una aplicación React Native/Expo existente: auditoría completa (tokens, navegación versus reglas de lectura de navegación, arquetipos de pantalla, lectura de marcación), decisión de preservación versus revisión, luego un plan de modernización por fases ejecutado palanca por palanca en todas las pantallas con puntos de control y un regulador de riesgos. La única habilidad de esta suite permitía proponer una reestructuración de la navegación (con aprobación). Úselo cuando se le solicite rediseñar, revisar, cambiar el nombre o modernizar una aplicación completa. Para una pantalla, utilice la pantalla de rediseño móvil; para una auditoría sin cambios utilice mobile-design-review.
