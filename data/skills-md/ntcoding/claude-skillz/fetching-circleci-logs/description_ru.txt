Получает журналы заданий CircleCI через API версии 1.1 и отображает выходные данные на уровне шагов. Фокусируется на неудачных шагах. Используйте, когда: проверки CI терпят неудачу в PR, пользователь делится URL-адресом задания CircleCI, пользователь просит проверить журналы сборки, «circleci», «сборка не удалась», «сбой CI», «проверьте журналы».
