قم بإنشاء الرسوم البيانية المعرفية للمشروع وتحديثها والاستعلام عنها والتحقق من صحتها والمخزنة ضمن "المعرفة/" باستخدام Markdown بنكهة Obsidian. يُستخدم عندما يذكر المستخدم الرسم البياني للمعرفة، أو قاعدة المعرفة، أو مستندات المشروع، أو مستندات الهندسة المعمارية، أو ADRs، أو ملاحظات Obsidian، أو تنظيم الملاحظات، أو فحوصات سلامة المستندات، أو الروابط المعطلة، أو المستندات القديمة، أو يطلب التهيئة أو المزامنة أو الاستعلام أو تدقيق وثائق المشروع المنظمة. استخدمه بشكل استباقي عندما تحتوي مساحة العمل على دليل "المعرفة/": ابحث فيه قبل الإجابة على أسئلة سياق المشروع، أو إجراء تغييرات جوهرية على التعليمات البرمجية أو التصميم، أو مراجعة التغييرات، أو تحديث الوثائق.
