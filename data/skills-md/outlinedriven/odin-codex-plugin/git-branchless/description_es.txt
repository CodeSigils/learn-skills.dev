Aplique git-branchless idiomático durante la planificación y ejecución de tareas: trabajo con HEAD primero separado, rebase en memoria a través de "git move", recuperación del registro de eventos a través de "git deshacer", creación de rama diferida, fusión especulativa "git sync" para actualizaciones de base. Úselo al planificar o ejecutar trabajos de múltiples confirmaciones, reescrituras de historial, ediciones de pilas, rebase/reordenamiento, inserción de correcciones en mitad de la pila, publicación de relaciones públicas apiladas o recuperación de operaciones incorrectas de git; o cuando el usuario menciona sucursales, smartlog, "git move" o "git undo". Silenciosamente inerte si el sistema sin sucursales no se inicializa para el repositorio actual.
