タスクの計画と実行中に慣用的な git ブランチレスを強制します。デタッチされた HEAD ファーストの作業、`git move` によるメモリ内リベース、`git undo` によるイベント ログのリカバリ、遅延ブランチの作成、ベース更新のための投機的マージ `git sync` です。マルチコミット作業、履歴の書き換え、スタックの編集、リベース/並べ替え、スタック中の修正挿入、スタックされた PR の公開、または不正な Git 操作からのリカバリを計画または実行するときに使用します。または、ユーザーがブランチレス、スマートログ、`git move`、または `git undo` について言及したとき。現在のリポジトリに対してブランチレスが初期化されていない場合は、サイレントに不活性になります。
