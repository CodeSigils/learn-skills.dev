فرض git-branchless الاصطلاحية أثناء التخطيط للمهام وتنفيذها - العمل المنفصل لـ HEAD أولاً، وإعادة التأسيس في الذاكرة عبر `git move`، واسترداد سجل الأحداث عبر ``git undo``، وإنشاء الفرع المؤجل، والدمج التخميني ``git sync`` للتحديثات الأساسية. يُستخدم عند تخطيط أو تنفيذ عمل متعدد الالتزامات، أو إعادة كتابة السجل، أو تعديلات المكدس، أو إعادة التأسيس/إعادة الترتيب، أو إدراج الإصلاح في منتصف المكدس، أو نشر العلاقات العامة المكدسة، أو الاسترداد من عمليات git السيئة؛ أو عندما يذكر المستخدم Branchless أو Smartlog أو git move أو git undo. خامل بصمت إذا لم تتم تهيئة Branchless للريبو الحالي.
