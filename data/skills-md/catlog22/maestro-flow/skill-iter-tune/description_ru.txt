Итеративная настройка навыков с помощью цикла обратной связи «выполнить-оценить-улучшить». Использует ccw cli Claude для проверки навыков, Gemini для оценки качества и Agent для применения улучшений. Итерации до достижения порога качества или максимального количества итераций. Срабатывает при «настройке навыков», «итеративной настройке навыков», «настройке навыков».
