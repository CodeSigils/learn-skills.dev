Coordinador inteligente: clasifica la intención mediante extracción estructurada (acción × objeto × estilo), asigna a la cadena de habilidades, ejecuta ola por ola a través de spawn_agents_on_csv. Las habilidades de barrera activan el análisis de artefactos del lado del coordinador entre oleadas para ensamblar dinámicamente argumentos de Skill_call posteriores. Cada ola puede tener 1 o N tareas paralelas.
