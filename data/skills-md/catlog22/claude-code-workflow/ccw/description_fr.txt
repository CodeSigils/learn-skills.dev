Coordinateur intelligent : classifiez l'intention via une extraction structurée (action × objet × style), mappez-la à la chaîne de compétences, exécutez vague par vague via spawn_agents_on_csv. Les compétences de barrière déclenchent une analyse des artefacts côté coordinateur entre les vagues pour assembler dynamiquement les arguments skills_call suivants. Chaque vague peut être constituée de 1 ou N tâches parallèles.
