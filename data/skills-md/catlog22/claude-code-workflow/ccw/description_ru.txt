Интеллектуальный координатор — классифицируйте намерения посредством структурированного извлечения (действие × объект × стиль), сопоставляйте их с цепочкой навыков, выполняйте поэтапно с помощью spawn_agents_on_csv. Навыки барьера запускают анализ артефактов на стороне координатора между волнами для динамической сборки последующих аргументов Skill_call. В каждой волне может быть 1 или N параллельных задач.
