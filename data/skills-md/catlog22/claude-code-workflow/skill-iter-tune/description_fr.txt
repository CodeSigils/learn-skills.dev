Ajustement itératif des compétences via une boucle de rétroaction exécuter-évaluer-améliorer. Utilise ccw cli Claude pour exécuter les compétences, Gemini pour évaluer la qualité et Agent pour appliquer les améliorations. Itère jusqu'au seuil de qualité ou au nombre maximal d'itérations. Se déclenche sur « réglage des compétences iter », « réglage des compétences itératives », « réglage des compétences ».
