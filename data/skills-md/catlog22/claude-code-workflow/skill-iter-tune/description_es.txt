Ajuste iterativo de habilidades a través del ciclo de retroalimentación ejecutar-evaluar-mejorar. Utiliza ccw cli Claude para ejecutar habilidades, Gemini para evaluar la calidad y Agente para aplicar mejoras. Itera hasta el umbral de calidad o el máximo de iteraciones.
