Единые командные навыки для обеспечения визуальной доступности. Цветовой контраст OKLCH, читаемость типографики, управление фокусом, аудит WCAG AA/AAA на уровне рендеринга. Использует архитектуру агента «командный работник». Запускается по «командному визуальному a11y», «аудиту доступности», «визуальному a11y».
