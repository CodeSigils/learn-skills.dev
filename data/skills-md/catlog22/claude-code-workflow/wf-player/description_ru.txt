Проигрыватель шаблонов рабочего процесса — загрузка шаблона JSON, созданного wf-composer, привязка контекстных переменных, выполнение узлов в порядке DAG (последовательный/параллельный), сохранение состояния на контрольных точках, поддержка возобновления с любой контрольной точки. Использует последовательную блокировку ccw-координатора для узлов CLI и шаблон рабочего координатора для параллельных узлов агента. Запускается по "wf-player" или "/wf-player".
