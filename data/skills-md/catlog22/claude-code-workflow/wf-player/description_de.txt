Workflow-Vorlagen-Player – Laden Sie eine von wf-composer erstellte JSON-Vorlage, binden Sie Kontextvariablen, führen Sie Knoten in DAG-Reihenfolge (seriell/parallel) aus, behalten Sie den Status an Prüfpunkten bei, unterstützen Sie die Wiederaufnahme von jedem Prüfpunkt. Verwendet die serielle CCW-Koordinator-Blockierung für CLI-Knoten und das Teamkoordinations-Worker-Muster für parallele Agentenknoten. Wird bei „wf-player“ oder „/wf-player“ ausgelöst.
