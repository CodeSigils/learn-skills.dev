Lecteur de modèles de workflow : chargez un modèle JSON produit par wf-composer, liez les variables de contexte, exécutez les nœuds dans l'ordre DAG (série/parallèle), conservez l'état aux points de contrôle, prenez en charge la reprise à partir de n'importe quel point de contrôle. Utilise le blocage en série du coordinateur ccw pour les nœuds CLI et le modèle de travail de coordination d'équipe pour les nœuds d'agent parallèles. Se déclenche sur "wf-player" ou "/wf-player".
