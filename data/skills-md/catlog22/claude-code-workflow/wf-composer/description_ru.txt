Компоновщик семантического рабочего процесса — синтаксический анализ описания рабочего процесса на естественном языке в группу DAG узлов навыков/CLI/агента, автоматическое внедрение узлов сохранения контрольных точек, подтверждение пользователю, сохранение в виде многоразового шаблона JSON. Запускается по "wf-composer" или "/wf-composer".
