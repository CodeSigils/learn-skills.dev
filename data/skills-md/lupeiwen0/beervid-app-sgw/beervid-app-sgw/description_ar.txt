دليل تكامل خدمة تطبيق TikTok/TikTok Shop. يغطي ترخيص OAuth (منصات TT + TTS المزدوجة)، وإدارة دورة حياة الرمز المميز، وتحميل الفيديو ونشره، واستعلامات بيانات الفيديو بعد النشر (معلومات فيديو TT، وأداء التجارة TTS)، واستراتيجية تحديث قائمة الانتظار المجدولة، واستعلامات المنتج، وعمليات الاسترجاعات عبر Webhook — التدفق الكامل وأفضل الممارسات. استخدم هذه المهارة عندما يحتاج المستخدمون إلى: دمج TT/TTS OAuth، والتعامل مع ربط الحساب وتحديث الرمز المميز، وتحميل مقاطع الفيديو إلى TT/TTS، وإنشاء مهام النشر، والاستعلام عن بيانات الفيديو أو أداء التجارة بعد النشر، وتصميم تحديث قائمة الانتظار المجدولة، وتلقي أحداث webhook، وتصميم جداول قاعدة البيانات ذات الصلة، والتعامل مع أخطاء واجهة برمجة التطبيقات. يتم التشغيل حتى إذا ذكر المستخدم جانبًا واحدًا فقط مثل مصادقة TikTok، أو نشر الفيديو، أو إدارة الحساب، أو تحميل OSS، أو تسليم الخطاف عبر الويب، أو الاستعلام عن بيانات الفيديو.
