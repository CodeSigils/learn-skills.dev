Prestazioni di Next.js 16 App Router, memorizzazione nella cache, componenti server, azioni server, routing e best practice per l'igiene della base di codice, oltre a un algoritmo di revisione/refactoring principale di categoria con risultati a livello di base di codice (rimozione/scaricamento/riutilizzo). Questa competenza deve essere utilizzata durante la scrittura del codice Next.js 16 App Router, la configurazione della memorizzazione nella cache con "usa cache", la creazione di componenti server, l'impostazione di percorsi paralleli/di intercettazione, la configurazione di next.config.js O proxy.ts, O il controllo/refactoring di una base di codice Next.js (file singolo o intero repository). Questa competenza NON copre i modelli React 19 generici (utilizzare vercel-react-v1) o il rendering del server non Next.js.
