Performances du routeur d'applications Next.js 16, mise en cache, composants du serveur, actions du serveur, routage et meilleures pratiques en matière d'hygiène de la base de code, ainsi qu'un algorithme de révision/refactorisation de catégorie majeure avec des résultats au niveau de la base de code (suppression/dup/réutilisation). Cette compétence doit être utilisée lors de l'écriture du code Next.js 16 App Router, de la configuration de la mise en cache avec « utiliser le cache », de la création de composants de serveur, de la configuration de routes parallèles/d'interception, de la configuration de next.config.js OU proxy.ts, OU de l'audit/refactorisation d'une base de code Next.js (un seul fichier ou un dépôt entier). Cette compétence ne couvre PAS les modèles génériques React 19 (utilisez vercel-react-v1) ou le rendu du serveur non-Next.js.
