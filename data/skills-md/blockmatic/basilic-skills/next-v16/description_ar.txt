Next.js 16 أداء جهاز توجيه التطبيقات، والتخزين المؤقت، ومكونات الخادم، وإجراءات الخادم، والتوجيه، وأفضل ممارسات سلامة قاعدة التعليمات البرمجية - بالإضافة إلى خوارزمية المراجعة/إعادة البناء للفئة الرئيسية مع نتائج مستوى قاعدة التعليمات البرمجية (إزالة/إزالة/إعادة الاستخدام). يجب استخدام هذه المهارة عند كتابة رمز Next.js 16 App Router، أو تكوين التخزين المؤقت باستخدام "استخدام ذاكرة التخزين المؤقت"، أو إنشاء مكونات الخادم، أو إعداد مسارات متوازية/اعتراضية، أو تكوين next.config.js أو proxy.ts، أو تدقيق/إعادة بناء قاعدة تعليمات Next.js (ملف واحد أو الريبو بالكامل). لا تغطي هذه المهارة أنماط React 19 العامة (استخدم vercel-react-v1) أو عرض خادم غير Next.js.
