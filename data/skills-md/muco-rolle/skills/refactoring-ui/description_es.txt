Sistema integral de diseño de UI para desarrolladores: cree, revise y pula interfaces de usuario utilizando principios sistemáticos de Refactoring UI. Cubre jerarquía visual, espaciado, tipografía, paletas de colores, profundidad/sombras, imágenes y toques finales con valores concretos de CSS/Tailwind. Utilice esta habilidad siempre que el usuario desee crear un componente de interfaz de usuario, crear un diseño de página, diseñar un panel, diseñar un formulario, crear una página de destino, mejorar la jerarquía visual, solucionar problemas de espaciado, elegir colores, agregar sombras, pulir un diseño, hacer que algo "se vea mejor" o "más profesional", revisar el código de la interfaz de usuario, refactorizar un diseño o cualquier tarea que implique diseño visual de interfaz. Esta habilidad debe usarse incluso cuando el usuario no menciona explícitamente "diseño"; si están creando una interfaz orientada al usuario, se aplican estos principios.
