نظام تصميم واجهة المستخدم الشامل للمطورين - إنشاء واجهات المستخدم ومراجعتها وصقلها باستخدام مبادئ منهجية من Refactoring UI. يغطي التسلسل الهرمي المرئي، والتباعد، والطباعة، ولوحات الألوان، والعمق/الظلال، والصور، واللمسات النهائية مع قيم CSS/Tailwind الملموسة. استخدم هذه المهارة كلما أراد المستخدم إنشاء مكون واجهة مستخدم، أو إنشاء تخطيط صفحة، أو تصميم لوحة معلومات، أو تصميم نموذج، أو إنشاء صفحة مقصودة، أو تحسين التسلسل الهرمي المرئي، أو إصلاح مشكلات التباعد، أو اختيار الألوان، أو إضافة الظلال، أو تلميع التصميم، أو جعل شيء ما "يبدو أفضل" أو "أكثر احترافية"، أو مراجعة كود واجهة المستخدم، أو إعادة تصميم التصميم، أو أي مهمة تتضمن التصميم المرئي للواجهة الأمامية. يجب استخدام هذه المهارة حتى عندما لا يذكر المستخدم "التصميم" صراحةً - إذا كان يقوم ببناء أي واجهة تواجه المستخدم، تنطبق هذه المبادئ.
