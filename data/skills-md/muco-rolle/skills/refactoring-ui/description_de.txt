Umfassendes UI-Designsystem für Entwickler – Erstellen, überprüfen und verfeinern Sie Benutzeroberflächen mithilfe der systematischen Prinzipien von Refactoring UI. Behandelt visuelle Hierarchie, Abstände, Typografie, Farbpaletten, Tiefe/Schatten, Bilder und den letzten Schliff mit konkreten CSS/Tailwind-Werten. Verwenden Sie diese Fertigkeit immer dann, wenn der Benutzer eine UI-Komponente erstellen, ein Seitenlayout erstellen, ein Dashboard entwerfen, ein Formular formatieren, eine Zielseite erstellen, die visuelle Hierarchie verbessern, Abstandsprobleme beheben, Farben auswählen, Schatten hinzufügen, ein Design aufpolieren, etwas „besser“ oder „professioneller“ machen, den UI-Code überprüfen, ein Design umgestalten oder eine Aufgabe mit visuellem Frontend-Design ausführen möchte. Diese Fähigkeit sollte auch dann genutzt werden, wenn der Benutzer „Design“ nicht ausdrücklich erwähnt – wenn er eine benutzerorientierte Schnittstelle erstellt, gelten diese Prinzipien.
