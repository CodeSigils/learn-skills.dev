Комплексная система проектирования пользовательского интерфейса для разработчиков — создавайте, проверяйте и совершенствуйте пользовательские интерфейсы, используя систематические принципы рефакторинга пользовательского интерфейса. Охватывает визуальную иерархию, интервалы, типографику, цветовые палитры, глубину/тени, изображения и последние штрихи с конкретными значениями CSS/Tailwind. Используйте этот навык всякий раз, когда пользователь хочет создать компонент пользовательского интерфейса, создать макет страницы, спроектировать панель мониторинга, стилизовать форму, создать целевую страницу, улучшить визуальную иерархию, исправить проблемы с интервалами, выбрать цвета, добавить тени, отполировать дизайн, сделать что-то «выглядящим лучше» или «более профессионально», просмотреть код пользовательского интерфейса, реорганизовать дизайн или выполнить любую задачу, связанную с визуальным дизайном интерфейса. Этот навык следует использовать, даже если пользователь явно не упоминает «дизайн» — если он создает какой-либо пользовательский интерфейс, эти принципы применимы.
