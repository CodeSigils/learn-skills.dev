개발자를 위한 포괄적인 UI 디자인 시스템 — 리팩토링 UI의 체계적인 원칙을 사용하여 사용자 인터페이스를 구축, 검토 및 다듬습니다. 구체적인 CSS/Tailwind 값을 사용하여 시각적 계층 구조, 간격, 타이포그래피, 색상 팔레트, 깊이/그림자, 이미지 및 마무리 작업을 다룹니다. 사용자가 UI 구성 요소 구축, 페이지 레이아웃 생성, 대시보드 디자인, 양식 스타일 지정, 랜딩 페이지 만들기, 시각적 계층 구조 개선, 간격 문제 수정, 색상 선택, 그림자 추가, 디자인 다듬기, "더 좋게 보이거나" "더 전문적인" 항목 만들기, UI 코드 검토, 디자인 리팩터링 또는 프런트엔드 시각적 디자인과 관련된 작업을 원할 때마다 이 기술을 사용하세요. 이 기술은 사용자가 "디자인"을 명시적으로 언급하지 않는 경우에도 사용해야 합니다. 사용자 지향 인터페이스를 구축하는 경우 이러한 원칙이 적용됩니다.
