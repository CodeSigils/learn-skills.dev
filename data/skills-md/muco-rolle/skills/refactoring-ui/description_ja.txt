開発者向けの包括的な UI デザイン システム — リファクタリング UI の体系的な原則を使用して、ユーザー インターフェイスを構築、レビュー、磨き上げます。視覚的な階層、間隔、タイポグラフィ、カラー パレット、深度/影、画像、具体的な CSS/Tailwind 値による仕上げをカバーします。ユーザーが UI コンポーネントの構築、ページ レイアウトの作成、ダッシュボードのデザイン、フォームのスタイルの設定、ランディング ページの作成、視覚的な階層の改善、間隔の問題の修正、色の選択、影の追加、デザインの磨き上げ、「見栄えを良く」または「よりプロフェッショナルに」する、UI コードのレビュー、デザインのリファクタリング、またはフロントエンドのビジュアル デザインに関連するタスクを行う場合は常に、このスキルを使用します。このスキルは、ユーザーが「デザイン」について明示的に言及していない場合でも使用する必要があります。ユーザー向けインターフェイスを構築している場合は、これらの原則が適用されます。
