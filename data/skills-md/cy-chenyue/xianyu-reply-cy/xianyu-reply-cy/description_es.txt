El Asistente de respuesta automática de Xianyu utiliza Playwright para controlar un navegador Chrome real para monitorear los mensajes web de Xianyu y responder automáticamente a las consultas de los compradores. Se activa cuando el usuario dice "Iniciar respuesta automática de Xianyu", "Monitorear mensajes de Xianyu", "Servicio al cliente de Xianyu" o "Respuesta de Xianyu".
