قم بإنشاء عروض تقديمية مذهلة من أي مدخلات — أوصاف الموضوع، أو المخططات التفصيلية المنظمة، أو محتوى Markdown، أو الملاحظات الملصقة. يدعم تنسيقين للإخراج: HTML (غني بالرسوم المتحركة، قائم على المتصفح) وPPTX (متوافق مع PowerPoint، قابل للتحرير). يتميز بأكثر من 12 سمة مرئية منسقة مع فلسفة تصميم مضادة للذكاء الاصطناعي.
استخدم هذه المهارة عندما يريد المستخدم: إنشاء عرض تقديمي أو مجموعة شرائح (HTML أو PPTX)، أو إنشاء شرائح لمحادثة/عرض تقديمي/تقرير/فصل دراسي، أو إنشاء عرض شرائح يعتمد على المتصفح، أو تحويل Markdown أو الملاحظات إلى شرائح، أو إنشاء عرض تقديمي مميز بصريًا، أو طلب "شرائح" / "مجموعة" / "عرض تقديمي" / "PPT" / "幻灯片" / "演示文稿".
يُستخدم أيضًا عندما: يقدم المستخدم مستندًا/مقالًا ويطلب تحويله إلى شرائح، أو يريد المستخدم عرضًا تقديميًا يحتوي على مقتطفات من التعليمات البرمجية أو الرسوم البيانية الفنية، أو يطلب المستخدم شرائح متحركة أو تفاعلية، أو يريد المستخدم ملف PowerPoint.
