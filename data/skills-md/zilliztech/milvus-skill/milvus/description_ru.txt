Работайте с векторной базой данных Milvus с помощью pymilvus Python SDK. Используйте, когда пользователь хочет подключиться к Milvus, создавать коллекции, вставлять векторы, выполнять поиск по сходству, гибридный поиск, полнотекстовый поиск, управлять индексами, разделами, базами данных или RBAC через код Python.
