Utilisez la base de données vectorielles Milvus avec le SDK Python pymilvus. À utiliser lorsque l'utilisateur souhaite se connecter à Milvus, créer des collections, insérer des vecteurs, effectuer une recherche de similarité, une recherche hybride, une recherche en texte intégral, gérer des index, des partitions, des bases de données ou RBAC via du code Python.
