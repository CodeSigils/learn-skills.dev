Добавьте инструменты функций на стороне клиента в Supervisor API. Используйте, когда: (1) пользователь хочет совместить вызовы Python с размещенными инструментами, (2) пользователь спрашивает об инструментах-функциях с Supervisor API, (3) пользователю необходимо выполнить пользовательскую бизнес-логику вместе с вызовами размещенных инструментов.
