Предоставьте агенту надежную межсеансовую долговременную память, используя УПРАВЛЯЕМУЮ память Databricks (интерфейсы REST API-интерфейсы хранилища памяти каталога Unity) в качестве инструментов — под управлением UC без необходимости запуска клиентом инфраструктуры. Это работает как для OpenAI Agents SDK, так и для шаблонов LangGraph. Используйте, когда: агент должен помнить предпочтения/факты/решения пользователя (или коллектива/организации) во время разговоров; ключевые слова «долговременная память», «управляемая память», «хранилище памяти», «агентная память». Это отдельно от автономного решения памяти Lakebase с навыками (agent-openai-memory / Agent-langgraph-memory).
