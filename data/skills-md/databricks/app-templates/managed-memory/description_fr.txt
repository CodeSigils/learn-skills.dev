Offrez à un agent une mémoire à long terme durable entre sessions en utilisant la mémoire GÉRÉE de Databricks (les API REST de stockage de mémoire du catalogue Unity) comme outils - régis par les communications unifiées sans aucune infrastructure que le client a besoin d'exécuter. Cela fonctionne pour les modèles OpenAI Agents SDK ou LangGraph. À utiliser lorsque : l'agent doit se souvenir des préférences/faits/décisions d'un utilisateur (ou d'une équipe/organisation) au cours des conversations ; mots-clés « mémoire à long terme », « mémoire gérée », « magasin de mémoire », « mémoire agentique ». Ceci est distinct de la solution de mémoire Lakebase auto-hébergée avec des compétences en (agent-openai-memory / agent-langgraph-memory).
