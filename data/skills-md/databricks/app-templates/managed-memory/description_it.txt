Fornisci a un agente memoria durevole e a lungo termine per sessioni incrociate utilizzando la memoria GESTITA di Databricks (le API REST dell'archivio di memoria di Unity Catalog) come strumenti, gestiti dalle UC senza alcuna infrastruttura che il cliente debba eseguire. Funziona con i modelli OpenAI Agents SDK o LangGraph. Da utilizzare quando: l'agente deve ricordare le preferenze/fatti/decisioni di un utente (o di un team/organizzazione condivisa) durante le conversazioni; parole chiave "memoria a lungo termine", "memoria gestita", "archivio di memoria", "memoria agente". Questa è separata dalla soluzione di memoria Lakebase self-hosted con competenze in (agent-openai-memory/agent-langgraph-memory).
