Ofrezca a un agente una memoria duradera y a largo plazo entre sesiones utilizando la memoria ADMINISTRADA de Databricks (las API REST de almacenamiento de memoria de Unity Catalog) como herramientas, gobernadas por UC sin infraestructura que el cliente necesite ejecutar. Esto funciona tanto para el SDK de agentes OpenAI como para las plantillas LangGraph. Úselo cuando: el agente debe recordar las preferencias/hechos/decisiones de un usuario (o un equipo/organización compartida) a lo largo de las conversaciones; palabras clave 'memoria a largo plazo', 'memoria gestionada', 'almacén de memoria', 'memoria agente'. Esto es independiente de la solución de memoria Lakebase autohospedada con habilidades en (agent-openai-memory/agente-langgraph-memory).
