Databricks MANAGED メモリ (Unity カタログ メモリストア REST API) をツールとして使用し、エージェントに耐久性のあるクロスセッションの長期メモリを提供します。これは、顧客が実行する必要のあるインフラストラクチャなしで UC によって管理されます。これは、OpenAI Agents SDK または LangGraph テンプレートのいずれかで機能します。使用する場合: エージェントは、会話全体にわたるユーザー (またはチーム/組織の共有) の好み/事実/決定を覚えておく必要があります。キーワード「長期記憶」、「管理された記憶」、「記憶装置」、「エージェント記憶」。これは、(agent-openai-memory / Agent-langgraph-memory) のスキルを備えた自己ホスト型の Lakebase メモリ ソリューションとは別のものです。
