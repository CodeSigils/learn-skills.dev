امنح الوكيل ذاكرة متينة وطويلة الأمد عبر الجلسات باستخدام ذاكرة Databricks MANAGED (واجهات برمجة تطبيقات REST لمخزن الذاكرة Unity Catalog) كأدوات - تحكمها UC بدون أي أشعة تحتية يحتاجها العميل للتشغيل. يعمل هذا مع قوالب OpenAI Agents SDK أو LangGraph. يُستخدم عندما: يجب أن يتذكر الوكيل تفضيلات/حقائق/قرارات المستخدم (أو الفريق/المؤسسة المشتركة) عبر المحادثات؛ الكلمات الرئيسية "الذاكرة طويلة المدى"، "الذاكرة المُدارة"، "مخزن الذاكرة"، "الذاكرة الوكيلة". وهذا منفصل عن حل ذاكرة Lakebase المستضاف ذاتيًا والذي يتمتع بمهارات في (agent-openai-memory / agent-langgraph-memory).
