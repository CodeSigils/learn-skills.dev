Geben Sie einem Agenten einen dauerhaften, sitzungsübergreifenden Langzeitspeicher mit Databricks MANAGED-Speicher (den Unity Catalog-Speicher-REST-APIs) als Tools – verwaltet von UC, ohne dass der Kunde eine Infrastruktur ausführen muss. Dies funktioniert entweder für OpenAI Agents SDK- oder LangGraph-Vorlagen. Verwenden Sie Folgendes: Der Agent sollte sich über Gespräche hinweg an die Präferenzen/Fakten/Entscheidungen eines Benutzers (oder eines Teams/einer Organisation) erinnern; Schlüsselwörter „Langzeitgedächtnis“, „verwaltetes Gedächtnis“, „Speicher“, „agentisches Gedächtnis“. Dies ist unabhängig von der selbstgehosteten Lakebase-Speicherlösung mit Kenntnissen in (agent-openai-memory / agent-langgraph-memory).
