Aktivieren Sie die Unterstützung lang laufender Hintergrundaufgaben mit LongRunningAgentServer. Verwenden Sie dies, wenn: (1) Agent-Aufgaben das HTTP-Timeout (~120 s) überschreiten können, (2) der Benutzer eine Hintergrund-/asynchrone Ausführung wünscht, (3) der Benutzer „lange Laufzeit“, „Hintergrundaufgaben“ oder „asynchroner Agent“ sagt.
