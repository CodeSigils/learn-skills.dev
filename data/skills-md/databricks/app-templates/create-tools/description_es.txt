Cree recursos de Databricks a los que los agentes se conectan como herramientas. Úselo cuando: (1) El usuario necesita crear un espacio Genie, un índice de búsqueda vectorial, una función UC o una conexión UC, (2) El usuario dice "crear herramienta", "configurar genio", "crear búsqueda vectorial", "registrar servidor MCP", (3) Antes de agregar herramientas cuando el recurso aún no existe, (4) El usuario pregunta "qué necesito crear antes de agregar esta herramienta".
