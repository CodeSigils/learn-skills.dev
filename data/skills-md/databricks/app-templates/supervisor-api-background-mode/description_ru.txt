Включите фоновый режим Supervisor API для длительных задач агента. Используйте, когда: (1) агенту необходимо запускать задачи дольше, чем пределы тайм-аута HTTP, (2) пользователь говорит «фоновый режим», «долгоиграющий», «supervisor API», (3) происходит переход от потоковой передачи к шаблону фонового опроса, (4) агенту необходима устойчивость к обрывам соединения во время выполнения.
