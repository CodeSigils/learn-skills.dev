Aktivieren Sie den Supervisor-API-Hintergrundmodus für Agentenaufgaben mit langer Laufzeit. Verwenden Sie dies, wenn: (1) der Agent Aufgaben länger als die HTTP-Zeitüberschreitungsgrenzen ausführen muss, (2) der Benutzer „Hintergrundmodus“, „langfristig“, „Supervisor-API“ sagt, (3) beim Konvertieren vom Streaming- in das Hintergrundabfragemuster, (4) der Agent Widerstandsfähigkeit gegenüber Verbindungsabbrüchen während der Ausführung benötigt.
