Sostituire il ciclo dell'agente lato client con l'API Databricks Supervisor (strumenti ospitati + strumenti delle funzioni lato client). Utilizzare quando: (1) l'utente chiede informazioni sull'API Supervisor, (2) l'utente desidera che Databricks esegua il loop dell'agente sul lato server, (3) connette spazi Genie, funzioni UC, endpoint agente o server MCP come strumenti ospitati, (4) combina strumenti di funzioni lato client (chiamabili Python eseguiti dall'app) con strumenti ospitati.
