クライアント側のエージェント ループを Databricks Supervisor API (ホストされたツール + クライアント側の関数ツール) に置き換えます。次の場合に使用します: (1) ユーザーがスーパーバイザー API について質問する、(2) ユーザーが Databricks にエージェント ループをサーバー側で実行することを希望する、(3) Genie スペース、UC 関数、エージェント エンドポイント、または MCP サーバーをホストされたツールとして接続する、(4) クライアント側の関数ツール (アプリが実行する Python 呼び出し可能ツール) とホストされるツールを混合する。
