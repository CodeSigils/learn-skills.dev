Замените цикл агента на стороне клиента API Databricks Supervisor (размещенные инструменты + функциональные инструменты на стороне клиента). Используйте, когда: (1) пользователь спрашивает об API-интерфейсе Supervisor, (2) пользователь хочет, чтобы Databricks запускал цикл агента на стороне сервера, (3) подключение пространств Genie, функций UC, конечных точек агента или серверов MCP в качестве размещенных инструментов, (4) смешивание инструментов функций на стороне клиента (вызовы Python, которые выполняет ваше приложение) с размещенными инструментами.
