Ersetzen Sie die clientseitige Agentenschleife durch die Databricks Supervisor API (gehostete Tools + clientseitige Funktionstools). Verwenden Sie diese Option, wenn: (1) der Benutzer nach der Supervisor-API fragt, (2) der Benutzer möchte, dass Databricks die Agentenschleife serverseitig ausführt, (3) Genie-Spaces, UC-Funktionen, Agentenendpunkte oder MCP-Server als gehostete Tools verbinden, (4) clientseitige Funktionstools (Python-Callables, die Ihre App ausführt) mit gehosteten Tools mischen.
