Générez des données synthétiques réalistes à l'aide de Spark + Faker (fortement recommandé). Prend en charge l'exécution sans serveur, plusieurs formats de sortie (Parquet/JSON/CSV/Delta) et évolue de plusieurs milliers à des millions de lignes. Pour les petits ensembles de données (<10 000 lignes), vous pouvez éventuellement générer localement et télécharger sur des volumes. À utiliser lorsque l'utilisateur mentionne « données synthétiques », « données de test », « générer des données », « ensemble de données de démonstration », « Faker » ou « exemples de données ».
