Genere datos sintéticos realistas utilizando Spark + Faker (muy recomendable). Admite ejecución sin servidor, múltiples formatos de salida (Parquet/JSON/CSV/Delta) y escala de miles a millones de filas. Para conjuntos de datos pequeños (<10 000 filas), opcionalmente se pueden generar localmente y cargarlos en volúmenes. Úselo cuando el usuario mencione "datos sintéticos", "datos de prueba", "generar datos", "conjunto de datos de demostración", "falso" o "datos de muestra".
