Generieren Sie realistische synthetische Daten mit Spark + Faker (dringend empfohlen). Unterstützt serverlose Ausführung, mehrere Ausgabeformate (Parquet/JSON/CSV/Delta) und skaliert von Tausenden auf Millionen von Zeilen. Für kleine Datensätze (<10.000 Zeilen) können optional lokal generiert und auf Volumes hochgeladen werden. Wird verwendet, wenn der Benutzer „synthetische Daten“, „Testdaten“, „Daten generieren“, „Demo-Datensatz“, „Faker“ oder „Beispieldaten“ erwähnt.
