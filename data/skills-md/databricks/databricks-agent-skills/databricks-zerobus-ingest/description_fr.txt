Créez des clients Zerobus Ingest pour une ingestion de données en temps quasi réel dans les tables Databricks Delta via gRPC. À utiliser lors de la création de producteurs qui écrivent directement dans les tables Unity Catalog sans bus de messages, en travaillant avec le SDK Zerobus Ingest dans Python/Java/Go/TypeScript/Rust, en générant des schémas Protobuf à partir de tables UC ou en implémentant une ingestion basée sur les flux avec la gestion ACK et la logique de nouvelle tentative.
