Создавайте клиенты Zerobus Ingest для приема данных практически в реальном времени в таблицы Databricks Delta через gRPC. Используйте при создании производителей, которые записывают данные непосредственно в таблицы каталога Unity без шины сообщений, при работе с Zerobus Ingest SDK в Python/Java/Go/TypeScript/Rust, при создании схем Protobuf из таблиц UC или при реализации приема на основе потоков с обработкой ACK и логикой повторных попыток.
