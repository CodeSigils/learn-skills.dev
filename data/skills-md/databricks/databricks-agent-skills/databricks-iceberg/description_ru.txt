Таблицы Apache Iceberg на Databricks — управляемые таблицы Iceberg, внешнее чтение Iceberg (fka Uniform), режим совместимости, каталог REST Iceberg (IRC), Iceberg v3, взаимодействие Snowflake, PyIceberg, OSS Spark, доступ к внешнему механизму и продажа учетных данных. Использование при создании таблиц Iceberg, включение внешнего чтения Iceberg (унифицированное) для таблиц Delta (включая потоковые таблицы и материализованные представления в режиме совместимости), настройка внешних механизмов для чтения таблиц Databricks через IRC каталога Unity, интеграция с каталогом Snowflake для чтения таблиц Foreign Iceberg.
