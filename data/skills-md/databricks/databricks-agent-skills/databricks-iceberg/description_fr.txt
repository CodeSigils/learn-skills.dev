Tables Apache Iceberg sur Databricks — Tables Iceberg gérées, lectures Iceberg externes (fka Uniform), mode de compatibilité, catalogue REST Iceberg (IRC), Iceberg v3, interopérabilité Snowflake, PyIceberg, OSS Spark, accès au moteur externe et vente d'informations d'identification. À utiliser lors de la création de tables Iceberg, en activant les lectures Iceberg externes (uniformes) sur les tables Delta (y compris les tables de streaming et les vues matérialisées via le mode de compatibilité), en configurant des moteurs externes pour lire les tables Databricks via Unity Catalog IRC, en intégrant le catalogue Snowflake pour lire les tables Iceberg étrangères.
