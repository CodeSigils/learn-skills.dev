Databricks 上の Apache Iceberg テーブル — マネージド Iceberg テーブル、外部 Iceberg 読み取り (fka ユニフォーム)、互換モード、Iceberg REST カタログ (IRC)、Iceberg v3、Snowflake 相互運用性、PyIceberg、OSS Spark、外部エンジン アクセス、資格情報の自動販売。 Iceberg テーブルの作成、デルタ テーブル (互換モードによるストリーミング テーブルおよびマテリアライズド ビューを含む) での外部 Iceberg 読み取り (均一) の有効化、Unity カタログ IRC 経由で Databricks テーブルを読み取るように外部エンジンを構成、外部 Iceberg テーブルを読み取るために Snowflake カタログと統合するときに使用します。
