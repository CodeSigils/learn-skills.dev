Découvrez, explorez et interrogez les données Databricks via Genie, l'équivalent CLI du Genie One MCP. DOIT être invoqué chaque fois que l'utilisateur demande à trouver ou à localiser des données (« quelles tables se trouvent dans X », « où se trouve X », « quel catalogue/schéma contient Y »), à répondre à une question en langage naturel sur les données ou à écrire une requête SQL.
