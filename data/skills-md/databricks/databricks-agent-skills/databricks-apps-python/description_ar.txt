يبني تطبيقات Databricks. يفضل AppKit (TypeScript + React SDK) للتطبيقات الجديدة؛ يعود إلى أطر عمل Python (Dash، Streamlit، Gradio، Flask، FastAPI، Reflex) عندما تكون لغة Python مطلوبة. يتعامل مع ترخيص OAuth وموارد التطبيق ومستودع SQL واتصال Lakebase وخدمة النماذج وواجهات برمجة التطبيقات للنموذج الأساسي والنشر. يُستخدم عند إنشاء تطبيقات الويب أو لوحات المعلومات أو العروض التوضيحية لتعلم الآلة أو REST APIs لـ Databricks، أو عندما يذكر المستخدم تطبيق AppKit أو Streamlit أو Dash أو Gradio أو Flask أو FastAPI أو Reflex أو Databricks.
