Databricks 애플리케이션을 빌드합니다. 새로운 앱에는 AppKit(TypeScript + React SDK)를 선호합니다. Python이 필요한 경우 Python 프레임워크(Dash, Streamlit, Gradio, Flask, FastAPI, Reflex)로 대체됩니다. OAuth 승인, 앱 리소스, SQL Warehouse 및 Lakebase 연결, 모델 제공, 기초 모델 API 및 배포를 처리합니다. Databricks용 웹 앱, 대시보드, ML 데모 또는 REST API를 구축할 때 또는 사용자가 AppKit, Streamlit, Dash, Gradio, Flask, FastAPI, Reflex 또는 Databricks 앱을 언급할 때 사용합니다.
