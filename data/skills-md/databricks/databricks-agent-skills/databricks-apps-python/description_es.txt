Crea aplicaciones de Databricks. Prefiere AppKit (TypeScript + React SDK) para nuevas aplicaciones; recurre a los marcos de Python (Dash, Streamlit, Gradio, Flask, FastAPI, Reflex) cuando se requiere Python. Maneja la autorización de OAuth, los recursos de aplicaciones, el almacén SQL y la conectividad de Lakebase, el servicio de modelos, las API del modelo básico y la implementación. Úselo al crear aplicaciones web, paneles, demostraciones de aprendizaje automático o API REST para Databricks, o cuando el usuario mencione la aplicación AppKit, Streamlit, Dash, Gradio, Flask, FastAPI, Reflex o Databricks.
