Databricks アプリケーションを構築します。新しいアプリには AppKit (TypeScript + React SDK) を優先します。 Python が必要な場合は、Python フレームワーク (Dash、Streamlit、Gradio、Flask、FastAPI、Reflex) にフォールバックします。 OAuth 認証、アプリのリソース、SQL ウェアハウスと Lakebase の接続、モデルの提供、基盤モデルの API、およびデプロイメントを処理します。 Databricks 用の Web アプリ、ダッシュボード、ML デモ、または REST API を構築する場合、またはユーザーが AppKit、Streamlit、Dash、Gradio、Flask、FastAPI、Reflex、または Databricks アプリについて言及する場合に使用します。
