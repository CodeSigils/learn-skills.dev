Construit des applications Databricks. Préfère AppKit (TypeScript + React SDK) pour les nouvelles applications ; revient aux frameworks Python (Dash, Streamlit, Gradio, Flask, FastAPI, Reflex) lorsque Python est requis. Gère l'autorisation OAuth, les ressources d'application, l'entrepôt SQL et la connectivité Lakebase, la diffusion de modèles, les API de modèle de base et le déploiement. À utiliser lors de la création d'applications Web, de tableaux de bord, de démos ML ou d'API REST pour Databricks, ou lorsque l'utilisateur mentionne l'application AppKit, Streamlit, Dash, Gradio, Flask, FastAPI, Reflex ou Databricks.
