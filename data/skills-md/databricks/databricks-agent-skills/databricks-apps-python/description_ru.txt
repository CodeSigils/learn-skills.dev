Создает приложения Databricks. Предпочитает AppKit (TypeScript + React SDK) для новых приложений; возвращается к платформам Python (Dash, Streamlit, Gradio, Flask, FastAPI, Reflex), когда требуется Python. Управляет авторизацией OAuth, ресурсами приложений, подключением к хранилищу SQL и Lakebase, обслуживанием моделей, API базовой модели и развертыванием. Используйте при создании веб-приложений, панелей мониторинга, демонстраций машинного обучения или API REST для Databricks, а также когда пользователь упоминает приложение AppKit, Streamlit, Dash, Gradio, Flask, FastAPI, Reflex или Databricks.
