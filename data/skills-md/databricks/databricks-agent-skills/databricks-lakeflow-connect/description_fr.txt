Créez des pipelines d'ingestion gérés dans Databricks à l'aide de Lakeflow Connect. À utiliser lors de l'ingestion d'applications SaaS (Salesforce, Workday Reports, ServiceNow, Google Analytics 4, HubSpot, Confluence) ou de bases de données (SQL Server cloud et sur site ; PostgreSQL/MySQL CDC dans PuPr) dans Unity Catalog avec des pipelines sans serveur.
