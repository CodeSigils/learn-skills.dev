Переносите рабочие нагрузки Databricks с классических вычислений на бессерверные вычисления. Сканирует код на наличие проблем с бессерверной совместимостью, предоставляет конкретные исправления для бессерверной архитектуры Spark Connect и направляет полный переход на бессерверные среды. Используйте для миграции с классической версии на бессерверную, проверки совместимости бессерверного кода или написания новых блокнотов и заданий, совместимых с бессерверной версией. Не для обновлений классической версии DBR или изменений конфигурации кластера в рамках классических вычислений.
