Migrieren Sie Databricks-Workloads von klassischer Datenverarbeitung zu serverloser Datenverarbeitung. Scannt Code auf serverlose Kompatibilitätsprobleme, stellt konkrete Korrekturen für die serverlose Spark Connect-Architektur bereit und leitet die vollständige Migration zu serverlosen Umgebungen. Verwenden Sie diese Option für Migrationen von klassisch auf serverlos, für Kompatibilitätsprüfungen von serverlosem Code oder für das Schreiben neuer serverlos kompatibler Notebooks und Jobs. Nicht für klassische DBR-Versions-Upgrades oder Cluster-Konfigurationsänderungen innerhalb der klassischen Datenverarbeitung.
