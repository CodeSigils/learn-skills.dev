MLflow 추적 및 Unity Catalog 등록을 통해 Databricks에서 ML 또는 사용자 지정 에이전트 모델을 교육합니다. 요청 시 사용: Optuna 튜닝을 통해 분류/회귀 또는 딥 러닝 모델(XGBoost, scikit-learn, LightGBM, PyTorch 등) 훈련, UC에 등록 및 `@prod`/`@challenger` 별칭 홍보, `spark_udf`를 통한 배치 점수 매기기, 사용자 정의 PyFunc 모델 구축, UC 함수/벡터 검색 도구를 사용하여 사용자 정의 `ResponsesAgent` 작성 또는 교육 노트북을 서버리스 일회성 작업. 해당되지 않음: 엔드포인트 작업(databricks-model-serving), 지식 도우미/감독자 에이전트(databricks-agent-bricks), MLflow 평가(databricks-mlflow-evaluation).
