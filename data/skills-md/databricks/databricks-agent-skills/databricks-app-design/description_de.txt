Entwerfen Sie die Benutzeroberfläche von Databricks Apps (AppKit/React)-Datenbildschirmen mit benutzerdefiniertem Code – KPI-/Übersichtsseiten, Berichte, Diagramme, Tabellen und Genie-/Chat-Datenassistenten –, die konkreten AppKit-Komponenten zugeordnet sind. Zum Erstellen oder Überprüfen der Benutzeroberfläche einer AppKit/React-App, die Daten anzeigt oder Datenfragen beantwortet: Auswahl von Genre, Layout, Diagrammen, KPIs, semantischer Farbe, erforderlichen Zuständen (Laden/Leer/Fehler), IBCS-Notation und KI-Ergebnisvertrauen (Anzeige generierter SQL/Quellen für Genie/Chat). Eine einfache Anfrage „Dashboard erstellen“ bedeutet ein verwaltetes AI/BI-Dashboard (Lakeview) → Verwenden Sie databricks-aibi-dashboards, NICHT diesen Skill. Auch NICHT für Nicht-Daten-Frontends (Formulare, Einstellungen, Authentifizierung, Marketing) oder Gerüstbau/Build/Deploy (→ Databricks-Apps). Ergänzt Databricks-Apps; Verwenden Sie es immer dann, wenn eine benutzerdefinierte App über ein Diagramm, eine Tabelle, einen KPI, einen Bericht oder eine Genie-/Chat-/KI-Oberfläche verfügt.
