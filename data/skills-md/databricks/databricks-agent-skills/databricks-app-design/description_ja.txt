具体的な AppKit コンポーネントにマッピングされた、カスタム コード Databricks アプリ (AppKit/React) データ画面 (KPI/概要ページ、レポート、グラフ、テーブル、Genie/チャット データ アシスタント) の UX を設計します。データを表示する、またはデータに関する質問に答える AppKit/React アプリの UI を構築またはレビューするときに使用します。ジャンル、レイアウト、チャート、KPI、セマンティック カラー、必要な状態 (読み込み/空/エラー)、IBCS 表記、AI 結果の信頼性 (Genie/チャット用に生成された SQL/ソースの表示) の選択。単純な「ダッシュボードの作成」リクエストは、マネージド AI/BI (Lakeview) ダッシュボードを意味します → このスキルではなく、databricks-aibi-dashboards を使用します。また、データ以外のフロントエンド (フォーム、設定、認証、マーケティング) やスキャフォールディング/構築/デプロイ (→ databricks-apps) には使用できません。 databricks-apps を補完します。カスタム アプリにチャート、テーブル、KPI、レポート、または Genie/チャット/AI サーフェスがある場合は常に、これを併用します。
