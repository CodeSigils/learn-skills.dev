Verificare un elenco di fonti di etichette/valori/mappature dichiarati (un controllo dei nomi, un dizionario di dati, un file di traduzione/i18n, una guida di stile, una configurazione o qualsiasi elenco di risultati "X dovrebbe essere Y") rispetto alla fonte di record AUTOREVOLE di un sistema, un elemento alla volta. Per ogni affermazione, traccia l'etichetta di implementazione al campo/record effettivo a cui si collega, estrai il valore autorevole dal sistema LIVE (non dal documento di origine, che spesso è sbagliato o dall'entità sbagliata), confronta la formulazione e regola: vince la fonte della verità. Indipendente dallo stack: implementazione = web/app/codice; autorità = CRM/Dataverse, schema DB, contratto API, token di progettazione, set di opzioni. L'output è una scheda fissa per articolo con un verdetto e l'esatto percorso app+codice da verificare. Attivazione su controllo di denominazione, controllo di etichetta, controllo di formulazione/terminologia, "l'etichetta del portale corrisponde a CRM", "confronta queste etichette con la fonte della verità", "verifica questo foglio di calcolo dei nomi", riconciliazione dei nomi di campo, vittorie CRM/controlli delle etichette canoniche. NON utilizzare per un'ampia copertura di capacità ("quanto siamo lontani da X", parità di funzionalità) - questa è un'analisi fit-gap; o per trasformare i risultati in ticket: questi sono i plugin del backlog.
