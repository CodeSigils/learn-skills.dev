git コミットから毎日の作業の概要を生成し、マネジメント トークを通じてリーダーシップに合わせて再構築します。ユーザーが Tribletext、請求書、日次概要、タイムシート、勤怠報告書、作業ログ、日次報告書、管理用のステータス更新について言及する場合、または git 履歴から昨日/今日行ったことを要約したい場合には、このスキルを使用します。また、ユーザーが「今日何をしたのか」、「コミットを要約する」、「タイムシートを生成する」、または「毎日の/リーダーシップの最新情報を準備する」などの発言をしたときにもトリガーされます。生のコミット概要は常にマネジメントトークスキルに渡されるため、最終的な成果物は、送信先のチャネル (Tribletext エントリ、Slack、スタンドアップ、電子メール、JIRA、または会議の論点) に合わせて形成されます。
