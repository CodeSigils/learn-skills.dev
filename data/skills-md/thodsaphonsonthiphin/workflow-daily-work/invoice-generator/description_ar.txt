قم بإنشاء ملخص عمل يومي من التزامات git وأعد تشكيله للقيادة عبر الحديث الإداري. استخدم هذه المهارة عندما يذكر المستخدم Tribletext، أو الفاتورة، أو الملخص اليومي، أو الجدول الزمني، أو تقرير الوقت، أو سجل العمل، أو التقرير اليومي، أو تحديث الحالة للإدارة، أو يريد تلخيص ما فعلوه بالأمس/اليوم من سجل git. يتم تشغيله أيضًا عندما يقول المستخدم أشياء مثل "ماذا فعلت اليوم"، أو "تلخيص التزاماتي"، أو "إنشاء الجدول الزمني الخاص بي"، أو "إعداد التحديث اليومي/القيادة". يتم دائمًا تسليم ملخص الالتزام الأولي إلى مهارة الحديث الإداري بحيث يتم تشكيل الناتج النهائي للقناة التي سيذهب إليها (إدخال نص ثلاثي، أو Slack، أو standup، أو البريد الإلكتروني، أو JIRA، أو نقاط التحدث للاجتماع).
