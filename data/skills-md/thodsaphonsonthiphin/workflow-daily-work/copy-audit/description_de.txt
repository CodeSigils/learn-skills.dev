Finden Sie jede Kopie eines Plugins oder Skills auf diesem Computer und stellen Sie fest, welche davon veraltet sind. Verwenden Sie diese Option, wenn der Benutzer jeden Ort/überall auf diesem PC aktualisieren möchte, den Plugin-Cache überprüfen, bestätigen möchte, dass eine Bearbeitung tatsächlich live gegangen ist, überprüfen möchte, ob ein Skill bereitgestellt wurde, abweichende oder verkaufte Kopien finden möchte oder fragt, warum sich ein Skill immer noch wie die alte Version verhält. Verwenden Sie vor der Auslieferung eines Plugins auch den Wechsel des anderen Repos-Anbieters. Es berichtet und schreibt nie.
