Erzwingt die React-Komponentenstruktur, indem Hooks und Benutzeroberfläche immer in verschiedene Dateien aufgeteilt werden. Verwenden Sie diese Fähigkeit, wenn Sie React-Komponenten erstellen, ändern oder umgestalten, einer React-App neue Funktionen hinzufügen oder React-Code jeglicher Art generieren. Löst alle React/TSX-Arbeiten aus, einschließlich Komponentenerstellung, UI-Änderungen, Formularerstellung, Tabellenansichten, Seitenlayouts und Funktionsimplementierung. Auch wenn der Benutzer nur „Schaltfläche hinzufügen“ oder „Seite erstellen“ sagt – wenn es um React geht, nutzen Sie diese Fähigkeit.
