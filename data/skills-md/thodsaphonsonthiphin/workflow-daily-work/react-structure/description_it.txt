Applica la struttura dei componenti React separando sempre hook e interfaccia utente in file distinti. Utilizza questa competenza ogni volta che crei, modifichi o esegui il refactoring di componenti React, aggiungi nuove funzionalità a un'app React o generi codice React di qualsiasi tipo. Trigger su qualsiasi lavoro React/TSX, tra cui creazione di componenti, modifiche dell'interfaccia utente, creazione di moduli, visualizzazioni di tabelle, layout di pagina e implementazione di funzionalità. Anche se l'utente dice semplicemente "aggiungi un pulsante" o "crea una pagina", se si tratta di React, usa questa abilità.
