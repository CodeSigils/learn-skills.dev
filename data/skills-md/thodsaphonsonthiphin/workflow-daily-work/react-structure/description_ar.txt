يفرض بنية مكون React من خلال فصل الخطافات وواجهة المستخدم دائمًا في ملفات مميزة. استخدم هذه المهارة عند إنشاء مكونات React أو تعديلها أو إعادة هيكلتها، أو إضافة ميزات جديدة إلى تطبيق React، أو إنشاء تعليمات برمجية React من أي نوع. يتم تشغيله في أي عمل React/TSX بما في ذلك إنشاء المكونات، وتغييرات واجهة المستخدم، وبناء النماذج، وطرق عرض الجدول، وتخطيطات الصفحة، وتنفيذ الميزات. حتى لو قال المستخدم فقط "أضف زرًا" أو "أنشئ صفحة" - إذا كان الأمر يتعلق بـ React، فاستخدم هذه المهارة.
