Hace cumplir la estructura de los componentes de React separando siempre los ganchos y la interfaz de usuario en archivos distintos. Utilice esta habilidad siempre que cree, modifique o refactorice componentes de React, agregue nuevas funciones a una aplicación de React o genere código de React de cualquier tipo. Activadores de cualquier trabajo de React/TSX, incluida la creación de componentes, cambios en la interfaz de usuario, creación de formularios, vistas de tablas, diseños de páginas e implementación de funciones. Incluso si el usuario simplemente dice "agregar un botón" o "crear una página", si se trata de React, use esta habilidad.
