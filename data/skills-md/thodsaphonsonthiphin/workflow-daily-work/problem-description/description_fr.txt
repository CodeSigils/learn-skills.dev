À utiliser lorsque l'utilisateur souhaite une présentation HTML interactive étape par étape expliquant un problème technique complexe (erreur de base de données, condition de concurrence critique, problème de conception, bloqueur conceptuel) à l'aide de données concrètes et d'une navigation manuelle. Déclencheurs sur des phrases telles que "faites-moi une procédure pas à pas", "expliquez étape par étape avec des données", "explication interactive", "créez une animation", "guidez-moi avec des exemples réels", "diagramme de présentation", "animation/procédure pas à pas/visualisation", "diagramme de présentation", "présentation schéma". Ne PAS utiliser pour des clarifications sur une seule ligne, des questions et réponses conceptuelles auxquelles il est possible de répondre dans un paragraphe ou de simples questions « que signifie X » – uniquement lorsqu'un artefact HTML interactif serait clairement utile.
