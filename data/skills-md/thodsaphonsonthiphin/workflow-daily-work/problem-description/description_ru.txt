Используйте, когда пользователю нужно интерактивное пошаговое руководство в формате HTML, объясняющее сложную техническую проблему (ошибка базы данных, состояние гонки, проблема проектирования, концептуальный блокировщик) с использованием конкретных данных и ручной навигации. Запускается по таким фразам, как «сделай мне пошаговое руководство», «объясни шаг за шагом с помощью данных», «интерактивное объяснение», «сделай анимацию», «покажи мне реальные примеры», «пошаговое руководство», «пошаговая анимация/пошаговое руководство/визуализация», «диаграмма приложения», «Диаграмма исчезновения». НЕ используйте однострочные пояснения, концептуальные вопросы и ответы, на которые можно ответить в абзаце, или простые вопросы «что означает X» — только тогда, когда интерактивный артефакт HTML явно может помочь.
