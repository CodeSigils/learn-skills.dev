Úselo cuando el usuario desee un tutorial HTML interactivo paso a paso que explique un problema técnico complejo (error de base de datos, condición de carrera, problema de diseño, bloqueador conceptual) utilizando datos concretos y navegación manual. Activadores de frases como "hazme un recorrido", "explica paso a paso con datos", "explicación interactiva", "haz una animación", "guíame con ejemplos reales", "อธิบายแบบ paso a paso", "animación/recorrido/visualización", "diagrama", "diagrama วาด". NO lo utilice para aclaraciones de una línea, preguntas y respuestas conceptuales que se puedan responder en un párrafo o preguntas simples de "¿qué significa X?", solo cuando un artefacto HTML interactivo sería claramente útil.
