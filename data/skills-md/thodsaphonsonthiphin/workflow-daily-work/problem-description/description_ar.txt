يُستخدم عندما يريد المستخدم إرشادات HTML تفاعلية خطوة بخطوة تشرح مشكلة فنية معقدة (خطأ في قاعدة البيانات، وحالة السباق، ومشكلة التصميم، والحظر المفاهيمي) باستخدام بيانات ملموسة والتنقل اليدوي. مشغلات لعبارات مثل "اجعلني في جولة تفصيلية"، "اشرح خطوة بخطوة باستخدام البيانات"، "شرح تفاعلي"، "اصنع رسمًا متحركًا"، "أرشدني عبر أمثلة حقيقية"، "خطوة بخطوة"، "رسوم متحركة/جولة تفصيلية/تصور"، "مخطط تفصيلي"، "مخطط تفصيلي". لا تستخدمه للتوضيحات المكونة من سطر واحد، أو الأسئلة والأجوبة المفاهيمية التي يمكن الإجابة عليها في فقرة، أو الأسئلة البسيطة "ماذا يعني X" - فقط عندما تكون عناصر HTML التفاعلية مفيدة بشكل واضح.
