Normalice CUALQUIER entrada en hallazgos.json: el primer paso para convertir las notas de revisión en un trabajo pendiente de GitHub Issues. Úselo cada vez que alguien le entregue una lista de problemas, discrepancias, lagunas, notas de revisión o resultados de auditoría sobre los que quiera actuar: una hoja de auditoría de Excel/CSV/TSV, una especificación de Word/PDF/Markdown o un chat/texto pegado en la conversación. Se activa incluso cuando el usuario NO dice "extraer", p. "aquí hay una auditoría de nombres", "estos son los problemas que encontramos", "convertir esta hoja de cálculo en problemas de GitHub", "revisé el código y noté estas lagunas", "crear un trabajo pendiente a partir de este documento". Si el objetivo finalmente son problemas de GitHub, esto se ejecuta primero. No intervenga en los hallazgos de clasificación de github (luego clasifique los problemas de github, github-create-issues). Impulsado de principio a fin por el orquestador de hallazgos a github.
