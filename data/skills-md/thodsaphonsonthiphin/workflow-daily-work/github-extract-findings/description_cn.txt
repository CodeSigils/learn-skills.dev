将任何输入规范化到 discovery.json 中——这是将审阅笔记转化为 GitHub Issues 待办事项的第一步。每当有人向您提供他们想要采取行动的问题、差异、差距、审阅笔记或审核结果列表时使用：Excel/CSV/TSV 审核表、Word/PDF/Markdown 规范或粘贴到对话中的聊天/文本。即使用户没有说“提取”也会触发 - 例如“这是一个命名审核”，“这些是我们发现的问题”，“将此电子表格转换为 GitHub 问题”，“我审查了代码并注意到了这些差距”，“根据此文档制作积压工作”。如果最终目标是 GitHub Issues，则它首先运行。移交给 github-triage-findings（然后分类 github-issues、github-create-issues）。由“finds-to-github-issues”协调器端到端驱动。
