將任何輸入規範化到 discovery.json 中——這是將審查筆記轉換為 GitHub Issues 待辦事項的第一步。每當有人向您提供他們想要採取行動的問題、差異、差距、審查筆記或審核結果清單時使用：Excel/CSV/TSV 審核表、Word/PDF/Markdown 規範或貼上到對話中的聊天/文字。即使用戶沒有說“提取”也會觸發 - 例如“這是一個命名審核”，“這些是我們發現的問題”，“將此電子表格轉換為 GitHub 問題”，“我審查了代碼並註意到了這些差距”，“根據此文件製作積壓工作”。如果最終目標是 GitHub Issues，則它首先運行。移交給 github-triage-findings（然後分類 github-issues、github-create-issues）。由“finds-to-github-issues”協調器端對端驅動。
