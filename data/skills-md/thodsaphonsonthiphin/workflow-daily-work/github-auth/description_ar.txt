قم بالمصادقة على GitHub وحل مشكلات المصادقة - البدائية المشتركة التي تعتمد عليها كل مهارة github-* الأخرى. استخدم هذا قبل أي إنشاء/استعلام عندما تكون مصادقة GitHub غير مؤكدة، وعندما يسيء استدعاء GitHub API: ترجع المكالمة 401 أو 403، "لم يتم تسجيل الدخول"/الرمز المميز مفقود، وتعود النتائج فارغة أو من الريبو الخاطئ. يغطي الطريقتين المعتمدتين (gh CLI عبر `gh auth token` أو GH_TOKEN env var)، ومقتطف التحقق من PowerShell المكون من سطر واحد مقابل واجهة برمجة تطبيقات الريبو، وجدول استكشاف أخطاء الريبو وإصلاحها 401/403/wrong-repo. الاستدعاء عندما يقول شخص ما "أحصل على 401 من GitHub"، أو "تقول مشكلات إنشاء github عدم وجود رمز مميز"، أو "فشل مصادقة gh"، أو "التحقق من تسجيل الدخول إلى GitHub قبل أن نبدأ".
