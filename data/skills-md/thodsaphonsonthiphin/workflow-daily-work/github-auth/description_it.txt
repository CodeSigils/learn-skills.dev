Autenticati su GitHub e risolvi i problemi di autenticazione: la primitiva condivisa su cui si basa ogni altra abilità github-*. Utilizzalo PRIMA di qualsiasi creazione/query quando l'autenticazione di GitHub è incerta e ogni volta che una chiamata API GitHub si comporta in modo anomalo: una chiamata restituisce 401 o 403, "gh non loggato" / token mancante, i risultati tornano vuoti o dal repository sbagliato. Copre i due metodi supportati (gh CLI tramite `gh auth token` o GH_TOKEN env var), uno snippet di verifica PowerShell a una riga rispetto all'API del repository e una tabella per la risoluzione dei problemi 401/403/wrong-repo. Richiama quando qualcuno dice "Sto ricevendo un 401 da GitHub", "github-create-issues non dice token", "gh auth failing" o "controlla il mio login GitHub prima di eseguire".
