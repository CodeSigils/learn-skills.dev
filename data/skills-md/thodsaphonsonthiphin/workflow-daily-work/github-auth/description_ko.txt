GitHub에 인증하고 인증 문제를 해결하세요 — 다른 모든 github-* 스킬이 의존하는 공유 기본 기능입니다. GitHub 인증이 불확실할 때, 그리고 GitHub API 호출이 비정상적으로 동작할 때(예: 호출이 401 또는 403을 반환하거나, “gh not logged in”/토큰 누락, 결과가 비어 있거나 잘못된 저장소에서 반환될 때) 이 절차를 CREATE/QUERY 전 반드시 사용하십시오. 지원되는 두 가지 방법(gh CLI의 `gh auth token` 사용 또는 GH_TOKEN 환경 변수)과 저장소 API에 대한 한 줄 PowerShell 검증 스니펫, 그리고 401/403/잘못된 저장소 문제 해결 표를 포함합니다. 누군가가 “GitHub에서 401 오류가 나옵니다”, “github-create-issues에서 토큰이 없습니다”, “gh 인증이 실패합니다”, 혹은 “실행하기 전에 내 GitHub 로그인을 확인해 주세요” 라고 말할 때 호출하세요.
