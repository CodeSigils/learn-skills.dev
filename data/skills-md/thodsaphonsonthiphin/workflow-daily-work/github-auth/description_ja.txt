GitHub に認証し、認証問題を修正する — すべての他の github-* スキルが依存する共有プリミティブです。GitHub の認証が不確かである場合や、GitHub API 呼び出しが異常を示すとき（401 または 403 が返る、"gh not logged in" / トークンが欠如している、結果が空になる、または誤ったリポジトリから返ってくる）に、作成/クエリを行う前に必ず使用してください。このガイドは、サポートされている 2 つの方法（`gh auth token` を使った gh CLI、または GH_TOKEN 環境変数）と、リポジトリ API に対するワンライン PowerShell 検証スニペット、そして 401/403/誤リポジトリ のトラブルシューティング表をカバーしています。「GitHub から 401 が返ってきた」「github-create-issues がトークンなしと言っている」「gh の認証が失敗している」「実行前に GitHub ログインを確認したい」などと言われたときに呼び出してください。
