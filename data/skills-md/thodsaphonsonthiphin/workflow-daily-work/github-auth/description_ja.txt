GitHub に対して認証し、認証の問題を修正します。これは、他のすべての github-* スキルが依存する共有プリミティブです。 GitHub 認証が不確実な場合、および GitHub API 呼び出しが誤動作する場合は常に、これを作成/クエリの前に使用します。呼び出しは 401 または 403、「gh not logged in」/トークンが返され、結果は空または間違ったリポジトリから返されます。サポートされている 2 つの方法 (「gh auth token」または GH_TOKEN 環境変数を使用した gh CLI)、リポジトリ API に対する 1 行の PowerShell 検証スニペット、および 401/403/間違ったリポジトリのトラブルシューティング テーブルについて説明します。誰かが「GitHub から 401 を受け取りました」、「github-create-issues でトークンがありません」、「gh 認証に失敗しました」、または「実行する前に GitHub ログインを確認してください」と言ったときに呼び出します。
