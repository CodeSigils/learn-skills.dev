Authentifiez-vous sur GitHub et résolvez les problèmes d'authentification - la primitive partagée sur laquelle s'appuient toutes les autres compétences github-*. Utilisez-le AVANT toute création/requête lorsque l'authentification GitHub est incertaine et chaque fois qu'un appel d'API GitHub se comporte mal : un appel renvoie 401 ou 403, "gh non connecté" / jeton manquant, les résultats reviennent vides ou proviennent du mauvais référentiel. Couvre les deux méthodes prises en charge (gh CLI via `gh auth token` ou GH_TOKEN env var), un extrait de vérification PowerShell d'une ligne par rapport à l'API de repo et un tableau de dépannage 401/403/wrong-repo. Invoquez lorsque quelqu'un dit "Je reçois un 401 de GitHub", "github-create-issues ne dit aucun jeton", "gh auth failing" ou "vérifiez ma connexion GitHub avant d'exécuter".
