Аутентификация на GitHub и устранение проблем с аутентификацией — общий примитив, на который опираются все остальные навыки github-*. Используйте это ПЕРЕД любым созданием/запросом, когда аутентификация GitHub неопределенна, а также всякий раз, когда вызов API GitHub ведет себя неправильно: вызов возвращает 401 или 403, «gh не вошел в систему» ​​/ токен отсутствует, результаты возвращаются пустыми или из неправильного репозитория. Охватывает два поддерживаемых метода (gh CLI через `gh auth token` или GH_TOKEN env var), однострочный фрагмент проверки PowerShell по API репозитория и таблицу устранения неполадок 401/403/wrong-repo. Вызов, когда кто-то говорит: «Я получаю ошибку 401 от GitHub», «github-create-issues говорит, что токена нет», «gh auth error» или «проверьте мой логин на GitHub, прежде чем мы запустим».
