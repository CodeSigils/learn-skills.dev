Authentifizieren Sie sich bei GitHub und beheben Sie Authentifizierungsprobleme – das gemeinsame Grundelement, auf das sich jeder andere Github-*-Skill verlässt. Verwenden Sie dies VOR jeder Erstellung/Abfrage, wenn die GitHub-Authentifizierung unsicher ist und wenn sich ein GitHub-API-Aufruf schlecht verhält: Ein Aufruf gibt 401 oder 403 zurück, „gh nicht angemeldet“/Token fehlt, Ergebnisse kommen leer zurück oder stammen aus dem falschen Repo. Behandelt die beiden unterstützten Methoden (gh CLI über „gh auth token“ oder GH_TOKEN env var), ein einzeiliges PowerShell-Überprüfungs-Snippet für die Repo-API und eine 401/403/wrong-repo-Fehlerbehebungstabelle. Rufen Sie auf, wenn jemand sagt: „Ich erhalte eine 401 von GitHub“, „Github-create-issues sagt kein Token“, „GH-Authentifizierung fehlgeschlagen“ oder „Überprüfen Sie mein GitHub-Login, bevor wir es ausführen“.
