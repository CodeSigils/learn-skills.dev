Autentíquese en GitHub y solucione problemas de autenticación: la primitiva compartida en la que se basan todas las demás habilidades de github-*. Use esto ANTES de cualquier creación/consulta cuando la autenticación de GitHub sea incierta y siempre que una llamada a la API de GitHub se comporte mal: una llamada devuelve 401 o 403, "gh no ha iniciado sesión"/falta el token, los resultados aparecen vacíos o provienen del repositorio incorrecto. Cubre los dos métodos admitidos (gh CLI a través de `gh auth token` o GH_TOKEN env var), un fragmento de verificación de PowerShell de una línea con la API del repositorio y una tabla de solución de problemas de repositorio incorrecto 401/403/. Invocar cuando alguien dice "Estoy recibiendo un 401 de GitHub", "github-create-issues dice que no hay token", "falla la autenticación de gh" o "verifique mi inicio de sesión de GitHub antes de ejecutar".
