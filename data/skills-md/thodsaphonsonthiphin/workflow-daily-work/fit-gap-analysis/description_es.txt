Compare un objetivo (especificación, visión del producto, competidor, RFP o diseño futuro) con un sistema tal como está realmente construido y produzca una brecha de ajuste basada en la evidencia: una matriz de capacidades más una comparación paso a paso del recorrido del usuario, verificada con el sistema LIVE (esquema + código, no documentos) y resumida en decisiones. Agnóstico de pila (aplicaciones web, API, ERP, low-code/CRM, canalizaciones, infraestructura). Úselo siempre que el usuario quiera comparar una especificación/visión/competidor con un sistema existente, pregunte "qué tan lejos estamos de X" o "qué se necesitaría para admitir Y", ejecute un análisis de brechas o una evaluación COTS/paquete/proveedor, o evalúe un esfuerzo de migración/nueva plataforma/paridad de características. Active la brecha de ajuste, el análisis de brechas, la comparación de capacidades, el estado actual frente al futuro, la comparación de sistemas, la paridad de características, la evaluación de la migración, incluso cuando el usuario nunca diga "brecha de ajuste". NO lo use para: revisar una única diferencia/PR, una revisión/auditoría de código genérico sin un objetivo con el cual comparar, o comparar dos documentos en prosa en cuanto a redacción.
