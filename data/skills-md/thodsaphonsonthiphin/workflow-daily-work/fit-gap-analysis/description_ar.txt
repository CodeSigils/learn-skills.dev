قارن هدفًا (المواصفات، أو رؤية المنتج، أو المنافس، أو طلب تقديم العروض، أو التصميم "المتوقع") مع نظام تم إنشاؤه بالفعل، وقم بإنتاج فجوة ملائمة للأدلة أولاً - مصفوفة قدرة بالإضافة إلى مقارنة رحلة المستخدم خطوة بخطوة، تم التحقق منها مقابل النظام المباشر (المخطط + الكود، وليس المستندات) ودمجها في القرارات. لا تعتمد على المكدس (تطبيقات الويب، واجهات برمجة التطبيقات، تخطيط موارد المؤسسات، التعليمات البرمجية المنخفضة/إدارة علاقات العملاء، خطوط الأنابيب، الأشعة تحت الحمراء). يُستخدم عندما يريد المستخدم مقارنة المواصفات/الرؤية/المنافس بنظام موجود، أو يسأل "إلى أي مدى نحن بعيدون عن X" أو "ما الذي يتطلبه دعم Y"، أو يجري تحليل الفجوات أو تقييم COTS/الحزمة/المورد، أو يحدد نطاق جهود الترحيل/إعادة النظام الأساسي/تكافؤ الميزات. تفعيل فجوة التوافق، وتحليل الفجوة، ومقارنة القدرات، والوضع الحالي مقابل ما سيكون، ومقارنة النظام، وتكافؤ الميزات، وتقييم الترحيل - حتى عندما لا يقول المستخدم أبدًا "فجوة التوافق". لا تستخدم من أجل: مراجعة فرق/علاقات عامة واحدة، أو مراجعة/تدقيق كود عام بدون هدف للمقارنة به، أو مقارنة مستندين نثريين من أجل الصياغة.
