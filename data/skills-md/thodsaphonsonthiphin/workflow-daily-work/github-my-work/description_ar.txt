اعرض مشكلات GitHub المفتوحة المخصصة لك في الريبو المستهدف، مجمعة حسب تصنيف الأولوية (P0 أولاً)، مع روابط المشكلات القابلة للنقر عليها. يُستخدم عندما يسأل المستخدم "ما الذي يوجد على لوحتي"، أو "مشكلات GitHub الخاصة بي"، أو "ما الذي يجب أن أعمل عليه بعد ذلك"، أو "إظهار مشكلاتي المفتوحة"، أو يبدأ اليوم راغبًا في عمله المتبقي. للقراءة فقط - إنه يسرد، ولا يغير أي شيء أبدًا.
