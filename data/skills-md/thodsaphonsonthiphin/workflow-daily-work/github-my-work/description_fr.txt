Affichez les problèmes GitHub ouverts qui vous sont attribués dans le dépôt cible, regroupés par étiquette de priorité (P0 en premier), avec des liens de problème cliquables. À utiliser chaque fois que l'utilisateur demande « ce qu'il y a dans mon assiette », « mes problèmes GitHub », « sur quoi dois-je travailler ensuite », « afficher mes problèmes en suspens » ou commence la journée en voulant son travail restant. En lecture seule : il répertorie, il ne change jamais rien.
