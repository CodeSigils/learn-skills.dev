Entscheiden Sie, WELCHE Ergebnisse zu GitHub-Problemen werden und in welcher Reihenfolge/Batches, indem Sie auf der von github-extract-findings erstellten fundings.json-Datei arbeiten. Verwenden Sie dies, NACHDEM die Ergebnisse extrahiert wurden und BEVOR Sie Probleme erstellen – insbesondere, wenn mehr Ergebnisse vorliegen, als Sie auf einmal einreichen möchten. Auslöser bei „mit den kritischen beginnen“, „was sollten wir zuerst einreichen“, „nicht alles auf GitHub abladen“, „wir machen das in Stapeln/Wellen“, „vorerst nur die bestätigten“, „die Bedarfsüberprüfungspunkte zurückhalten“, „den Rückstand reduzieren“, „diese Ergebnisse priorisieren“ oder jede Anfrage, eine Teilmenge der Ergebnisse auszuwählen, die in Probleme umgewandelt werden sollen. Erstellt eine bereichsbezogene, geordnete Teilmenge und übergibt sie an „classify-github-issues“.
