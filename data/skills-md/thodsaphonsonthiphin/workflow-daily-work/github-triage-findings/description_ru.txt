Решите, КАКИЕ результаты станут проблемами GitHub и в каком порядке/пакетах, работая на основе файла results.json, созданного с помощью github-extract-findings. Используйте это ПОСЛЕ того, как результаты будут извлечены, и ДО того, как создавать проблемы, особенно если результатов больше, чем вы хотите зарегистрировать одновременно. Триггеры по принципу «начните с критически важных», «что нам следует подать в первую очередь», «не выгружайте все в GitHub», «давайте делать это партиями/волнами», «пока только подтвержденные», «придержите элементы проверки потребностей», «ограничьте список невыполненных задач», «приоритизируйте эти выводы» или любой запрос на выбор подмножества результатов, которые можно превратить в проблемы. Создает упорядоченное подмножество с ограниченной областью действия и передает его для классификации проблем GitHub.
