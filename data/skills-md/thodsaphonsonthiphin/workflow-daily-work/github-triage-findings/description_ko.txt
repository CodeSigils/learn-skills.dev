github-extract-findings에서 생성된 Finding.json을 사용하여 어떤 결과가 GitHub 문제가 될지, 어떤 순서/배치로 처리할지 결정하세요. 결과를 추출한 후 문제를 생성하기 전, 특히 한 번에 파일로 제출하려는 것보다 더 많은 결과가 있는 경우 이 방법을 사용하세요. "중요한 항목부터 시작", "먼저 파일링해야 하는 항목", "GitHub에 모든 것을 덤프하지 마세요", "일괄/웨이브로 합시다", "지금은 확인된 항목만", "필요 검토 항목 보류", "백로그 범위 축소", "이러한 결과 우선 순위 지정" 또는 문제로 전환할 결과의 하위 집합을 선택하라는 요청에 대해 트리거됩니다. 범위가 지정되고 순서가 지정된 하위 집합을 생성하여 classify-github-issues에 전달합니다.
