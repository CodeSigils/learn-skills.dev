github-extract-findings によって生成された Finding.json に基づいて、どの検出結果が GitHub Issue になるのか、またどのような順序/バッチで処理されるのかを決定します。これは、調査結果が抽出された後、問題を作成する前に使用してください。特に、一度に提出したい調査結果よりも多くの調査結果がある場合に使用してください。 「重要なものから始める」、「どれを最初にファイルするべきか」、「すべてを GitHub にダンプしないでください」、「バッチ/ウェーブで実行しましょう」、「今のところは確認済みのものだけ」、「ニーズのレビュー項目を保持する」、「バックログを詳細に調査する」、「これらの調査結果に優先順位を付ける」、または問題にする調査結果のサブセットを選択するリクエストをトリガーします。範囲が指定され、順序付けされたサブセットを生成し、それをclassification-github-issuesに渡します。
