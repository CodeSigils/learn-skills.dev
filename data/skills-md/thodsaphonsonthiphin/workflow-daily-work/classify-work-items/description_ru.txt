Сопоставьте результаты сортировки с правильными типами рабочих элементов Azure DevOps для процесса проекта TARGET и создайте файл backlog_input.json, готовый к созданию. Используйте эту сортировку ПОСЛЕ и ПЕРЕД созданием элементов — когда пользователь спрашивает «какого типа они должны быть», «превратить их в рабочие элементы/заявки», «превратить эти результаты в невыполненную работу», «классифицировать их для ADO» или «создать входные данные невыполненной работы». Выбранный вами тип ДОЛЖЕН существовать на целевой плате: проект базового процесса не имеет ошибок или пользовательских историй, поэтому выбор их автоматически не удается во время создания. Этот навык сначала обнаруживает процесс проекта, применяет отраслевые правила типизации (дефект, новая возможность или родительская группировка), сопоставляет серьезность с приоритетом, создает поля для каждого типа (заголовки, теги, воспроизведение/описание в виде экранированного HTML), переносит «ключ» каждого обнаружения и передает его на ado-create-work-items.
