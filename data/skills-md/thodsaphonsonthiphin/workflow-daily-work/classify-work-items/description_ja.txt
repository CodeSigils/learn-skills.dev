トリアージされた結果を TARGET プロジェクトのプロセスの正しい Azure DevOps 作業項目タイプにマッピングし、作成可能な backlog_input.json を出力します。これは、トリアージの後、項目を作成する前に使用します。ユーザーが「これらをどのタイプにすべきか」、「これらを作業項目/チケットに作成する」、「これらの結果をバックログに変換する」、「これらを ADO 用に分類する」、または「バックログ入力を構築する」と尋ねた場合に使用します。選択するタイプはターゲット ボード上に存在する必要があります。基本プロセス プロジェクトにはバグやユーザー ストーリーがないため、作成時にこれらを選択すると通知なく失敗します。このスキルは、最初にプロジェクトのプロセスを検出し、業界の型付けルール (欠陥、新機能、グループ化の親) を適用し、重大度を優先度にマップし、タイプごとのフィールド (タイトル、タグ、エスケープされた HTML としての再現/説明) を構築し、各検出結果の「キー」を渡して、ado-create-work-items に渡します。
