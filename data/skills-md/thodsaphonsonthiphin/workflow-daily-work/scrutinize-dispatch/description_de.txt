Die Prüfmaschine für einen DISPATCHED-Prüfer-Subagenten – das bereichsbezogene Gegenstück zur Prüfung. Verwenden Sie dies nur, wenn eine Prüfer-Eingabeaufforderung (code-reviewer.md, task-reviewer-prompt.md) Sie zur Überprüfung eines Aufgabenunterschieds geschickt hat und ein Controller Ihren Bericht analysiert. Gibt eine kritische/wichtige/geringfügige Bewertung sowie eine Spezifikationskonformitätsbewertung ab. Für eine persönliche Überprüfung in einer Live-Sitzung verwenden Sie stattdessen Scrutinize.
