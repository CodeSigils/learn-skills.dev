エンジニアリング組織のリーダーシップ (エンジニアリングに精通した企業の副社長、ディレクター、PM、リリース マネージャー、幹部) 向けにエンジニア間のコンテンツを書き直し、そのチャネル (JIRA コメント、Slack 投稿、非同期スタンドアップ ライン、電子メール、会議の論点など) に合わせて形作ります。ユーザーが経営陣 / 幹部 / 副社長 / ディレクター / PM / リリース マネージャーに執筆/リライトを依頼したとき、「経営陣の概要 / リーダーシップの最新情報 / ステータスの最新情報」を要求したとき、「専門用語を減らして専門用語を減らしてください」と言ったとき、または元々エンジニア間で書かれた作業のスラック / 電子メール / スタンドアップ / ミーティング版を要求したときにトリガーされます。
