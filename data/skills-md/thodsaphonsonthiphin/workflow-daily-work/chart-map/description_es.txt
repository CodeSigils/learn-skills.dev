Trace un mapa de decisión para un esfuerzo demasiado grande para una sesión de agente: nombre el destino, cocine primero en amplitud para separar los tickets de decisión reales de la niebla, cree el mapa y sus tickets detrás de una puerta de prueba, despida a los subagentes de investigación y luego DETÉNGASE. Úselo cuando el usuario tiene una idea vaga, confusa y de varias sesiones: "esto es enorme, ¿por dónde empezamos?", "planificar esta migración", "trazar esto", "hacer un mapa de decisiones", "trazar esta iniciativa", "demasiado grande para una sesión" y la ruta hacia la meta aún no es visible. NO lo use para un diseño de sesión única con un alcance bien definido (es decir, grill-then-plan/sp-grill-with-doc), y NO lo use para continuar un mapa que ya existe (es decir, mapa de trabajo). Si la parrilla de apertura no muestra niebla, esta habilidad se detiene y dice que no se necesita un mapa.
