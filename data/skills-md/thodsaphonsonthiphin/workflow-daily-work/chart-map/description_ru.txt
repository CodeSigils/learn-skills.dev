Составьте карту решений для усилий, слишком больших для одного сеанса агента — назовите пункт назначения, сначала задайте ширину, чтобы отделить реальные билеты решений от тумана, создайте карту и ее билеты за воротами пробного запуска, уволите исследовательских субагентов, затем ОСТАНОВИТЕСЬ. Используйте его, когда у пользователя есть расплывчатая, туманная идея, состоящая из нескольких сеансов — «это огромная задача, с чего нам вообще начать», «спланируйте эту миграцию», «наметьте это», «составьте карту решений», «наметьте эту инициативу», «слишком большая для одного сеанса» — и путь к цели еще не виден. НЕ используйте для односеансового проекта с широким охватом (то есть гриль-затем-план/sp-гриль-с-документом) и НЕ используйте для продолжения уже существующей карты (то есть рабочей карты). Если на открывающейся решетке нет тумана, этот навык останавливается и сообщает, что карта не нужна.
