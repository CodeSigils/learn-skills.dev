모든 입력(감사 스프레드시트, 코드/보안 검토, QA 보고서, 회의 메모, 붙여넣은 문제 목록)의 결과를 연결된 작업 항목의 Azure DevOps 백로그로 변환하는 엔드투엔드 오케스트레이터입니다. 안전문과 함께 6남매의 아도백로그 스킬을 순서대로 구동합니다. 사용자가 "이 감사/스프레드시트/검토/문제 목록을 ADO 작업 항목으로 전환", "이 결과에서 백로그 생성", "ADO 티켓/버그/스토리로 파일링", "이 xlsx/csv를 Azure DevOps로 가져오기", "이 보고서에서 작업 항목 만들기"라고 말하거나 소스 문서를 건네주고 ADO에 배치하도록 요청할 때마다 트리거됩니다. 이것은 헤드라인의 일회성 진입점입니다(/ado-backlog:run이 이를 래핑합니다). 사용자가 전체 파이프라인을 원할 때 하위 기술을 단편적으로 실행하는 것보다 이를 선호합니다. 기존 항목을 개별적으로 편집하는 것이 아니라 ado-create-work-items를 사용하세요.
