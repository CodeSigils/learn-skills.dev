Orquestador de un extremo a otro que convierte los hallazgos de CUALQUIER entrada (hoja de cálculo de auditoría, revisión de código/seguridad, informe de control de calidad, notas de reuniones, una lista pegada de problemas) en un trabajo pendiente de Azure DevOps de elementos de trabajo vinculados. Maneja las habilidades de ado-backlog de los seis hermanos en orden con puertas de seguridad. Se activa cada vez que el usuario dice "convertir esta auditoría/hoja de cálculo/revisión/lista de problemas en elementos de trabajo de ADO", "crear un trabajo pendiente a partir de estos hallazgos", "archivarlos como tickets/errores/historias de ADO", "importar este xlsx/csv a Azure DevOps", "crear elementos de trabajo a partir de este informe" o le entrega un documento fuente y le solicita que llegue a ADO. Este es el título, un punto de entrada único (/ado-backlog:run lo envuelve). Prefiera esto a ejecutar las subhabilidades poco a poco cuando el usuario quiere todo el proceso. No para editar elementos existentes individualmente: utilice ado-create-work-items.
