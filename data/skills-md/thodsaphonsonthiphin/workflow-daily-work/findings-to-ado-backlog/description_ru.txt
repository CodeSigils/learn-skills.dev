Комплексный оркестратор, который превращает результаты ЛЮБЫХ входных данных (таблица аудита, проверка кода/безопасности, отчет по обеспечению качества, заметки о собраниях, вставленный список проблем) в невыполненную работу Azure DevOps из связанных рабочих элементов. Приводит в порядок шесть родственных навыков отставания в работе с помощью защитных ворот. Вызывается каждый раз, когда пользователь говорит: «превратите этот аудит/таблицу/проверку/список проблем в рабочие элементы ADO», «создайте очередь из этих результатов», «сохраните их как заявки/ошибки/истории ADO», «импортируйте этот xlsx/csv в Azure DevOps», «создайте рабочие элементы из этого отчета» или передает вам исходный документ и просит разместить его в ADO. Это заголовок, однократная точка входа (/ado-backlog:run завершает его). Предпочитайте это, а не выполнение поднавыков по частям, когда пользователю нужен весь конвейер. Не для редактирования существующих элементов по отдельности — используйте ado-create-work-items.
