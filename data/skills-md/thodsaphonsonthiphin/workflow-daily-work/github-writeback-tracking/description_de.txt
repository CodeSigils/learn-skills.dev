Fügen Sie Rückverfolgbarkeitsspalten zu einer Tabellenquelle hinzu und schreiben Sie erstellte GitHub-Problemnummern/URLs wieder hinein, abgeglichen Zeile für Zeile nach Schlüssel. Verwenden Sie dies direkt nach dem Erstellen von Issues – wenn Sie eine github_backlog_result.json haben und die ursprüngliche Quelle eine Tabelle (xlsx/csv) war. Löst aus bei „Schreiben Sie die Issue-Links zurück“, „Verfolgen Sie, welche Zeile welches Issue erhalten hat“, „Aktualisieren Sie die Tabelle mit den GitHub-IDs“, „Füllen Sie die Issue-Spalte aus“, „Schließen Sie die Schleife auf dem Prüfblatt“.
