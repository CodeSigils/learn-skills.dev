トレーサビリティ列をスプレッドシート ソースに追加し、作成した Azure DevOps チケット ID/URL をキーで行ごとに照合して書き込みます。 backlog_result.json があり、元のソースがスプレッドシート (xlsx/csv) であった場合、作業項目を作成した直後にこれを使用します。 「チケット リンクを書き戻す」、「どの行がどのチケットを取得したか追跡する」、「ADO ID を使用してスプレッドシートを更新する」、「チケット列に記入する」、「監査シートのループを閉じる」、または作成された項目 ID をソース行に記録し直すリクエストがトリガーされます。バンドルされている tracking.py (列の追加 + ライトバック) を実行します。ドキュメント/貼り付けられたテキスト入力の場合、書き込む行はありません。その場合は、代わりに作成されたリンクを報告するだけです。
