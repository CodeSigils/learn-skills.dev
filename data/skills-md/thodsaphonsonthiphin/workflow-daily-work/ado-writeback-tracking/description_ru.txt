Добавьте столбцы трассируемости в источник электронной таблицы и запишите обратно в него созданные идентификаторы и URL-адреса билетов Azure DevOps, сопоставляя их построчно по ключу. Используйте это сразу после создания рабочих элементов — если у вас есть backlog_result.json, а исходным источником была электронная таблица (xlsx/csv). Триггеры по «обратной записи ссылок на заявку», «отслеживанию, какая строка получила какой билет», «обновлению электронной таблицы с помощью идентификаторов ADO», «заполнению столбца заявки», «замыканию цикла на листе аудита» или любому запросу на запись идентификаторов созданных элементов обратно в исходные строки. Запускает связанный файл track.py (добавление столбцов + обратная запись). Для ввода документа/вставленного текста нет строк для записи — в этом случае вместо этого просто сообщите о созданных ссылках.
