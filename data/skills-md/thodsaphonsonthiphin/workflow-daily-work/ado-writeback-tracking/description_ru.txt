Добавьте столбцы трассируемости в источник электронной таблицы и запишите обратно в него созданные идентификаторы и URL-адреса билетов Azure DevOps, сопоставляя их построчно по ключу. Используйте это сразу после создания рабочих элементов — если у вас есть backlog_result.json, а исходным источником была электронная таблица (xlsx/csv). Триггеры «записать ссылки обратно на заявку», «отследить, какая строка получила какой билет», «обновить электронную таблицу с помощью идентификаторов ADO», «заполнить столбец заявки», «закрыть цикл на листе аудита» или любой запрос на запись идентификаторов созданных элементов обратно в исходные строки. Запускает связанный файл track.py (добавление столбцов + обратная запись). Для ввода документа/вставленного текста нет строк для записи — в этом случае вместо этого просто сообщите о созданных ссылках.
