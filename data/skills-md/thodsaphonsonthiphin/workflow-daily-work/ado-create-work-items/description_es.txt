Cree elementos de trabajo de Azure DevOps a partir de backlog_input.json (la salida de classify-work-items) mediante el script create-backlog.cs incluido. Siempre realiza primero una validación de prueba y solo crea elementos reales después de que el usuario los apruebe explícitamente. Use esto siempre que haya un backlog_input.json o cualquier archivo de elementos para archivar en ADO, o cuando el usuario diga "crear estos elementos de trabajo", "archivar el trabajo pendiente", "enviarlos a Azure DevOps", "crear los tickets/errores/historias", "crear los elementos de trabajo" o solicite convertir una lista clasificada de hallazgos en un trabajo pendiente de ADO real. Este es el paso que realmente escribe en la organización, así que prefiérelo a las llamadas REST/MCP manuales cuando existe un backlog_input.json. Después de crear, escribe backlog_result.json para realizar un seguimiento de ado-writeback.
