번들 create-backlog.cs 스크립트를 통해 backlog_input.json(classify-work-items의 출력)에서 Azure DevOps 작업 항목을 만듭니다. 항상 테스트 실행 검증을 먼저 수행하고 사용자가 명시적으로 승인한 후에만 실제 항목을 생성합니다. backlog_input.json 또는 ADO에 보관할 항목 파일이 있을 때마다 또는 사용자가 "이 작업 항목 만들기", "백로그 파일링", "Azure DevOps에 푸시", "티켓/버그/스토리 만들기", "작업 항목 만들기"라고 말하거나 분류된 결과 목록을 실제 ADO 백로그로 전환하도록 요청할 때 이 기능을 사용하세요. 이는 실제로 조직에 쓰는 단계이므로 backlog_input.json이 존재할 때 직접 REST/MCP 호출을 수행하는 것보다 이 단계를 선호합니다. 생성 후 ado-writeback-tracking을 위해 backlog_result.json을 작성합니다.
