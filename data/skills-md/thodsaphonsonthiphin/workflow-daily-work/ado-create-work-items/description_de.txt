Erstellen Sie Azure DevOps-Arbeitselemente aus einer backlog_input.json (der Ausgabe von classify-work-items) über das gebündelte Skript „create-backlog.cs“. Führt immer zuerst eine Probeprüfung durch und erstellt echte Elemente erst, nachdem der Benutzer dies ausdrücklich genehmigt hat. Verwenden Sie dies immer dann, wenn eine Datei „backlog_input.json“ oder eine beliebige Datei mit Elementen vorhanden ist, die in ADO abgelegt werden sollen, oder wenn der Benutzer sagt „Diese Arbeitselemente erstellen“, „das Backlog ablegen“, „diese an Azure DevOps übertragen“, „die Tickets/Bugs/Storys erstellen“, „die Arbeitselemente erstellen“ oder wenn er darum bittet, eine klassifizierte Liste von Ergebnissen in ein echtes ADO-Backlog umzuwandeln. Dies ist der Schritt, der tatsächlich in die Organisation schreibt. Ziehen Sie ihn daher dem manuellen Rollieren von REST/MCP-Aufrufen vor, wenn eine backlog_input.json vorhanden ist. Nach der Erstellung wird backlog_result.json für das Ado-Writeback-Tracking geschrieben.
