バンドルされている create-backlog.cs スクリプトを使用して、backlog_input.json (classify-work-items の出力) から Azure DevOps 作業項目を作成します。常に最初にドライラン検証が行われ、ユーザーが明示的に承認した後にのみ実際のアイテムが作成されます。 backlog_input.json または ADO にファイルする項目のファイルがある場合、またはユーザーが「これらの作業項目を作成する」、「バックログをファイルする」、「これらを Azure DevOps にプッシュする」、「チケット/バグ/ストーリーを作成する」、「作業項目を作成する」と指示した場合、または分類された検出結果リストを実際の ADO バックログに変換するよう要求した場合は、これを使用します。これは実際に組織に書き込むステップであるため、backlog_input.json が存在する場合は手動で REST/MCP 呼び出しを実行するよりも優先してください。作成後、ado-writeback-tracking 用に backlog_result.json を書き込みます。
