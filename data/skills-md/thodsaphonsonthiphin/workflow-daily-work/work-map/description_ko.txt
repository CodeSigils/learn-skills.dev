기존 결정 맵의 한 세션 작업 — 로드하고, 이름으로 개척지(열린, 차단되지 않은, 청구되지 않은 티켓)를 표시하고, 정확히 1개를 청구하고, 일치하는 아크 기술(굽기/프로토타입/연구/작업)로 문제를 해결하고, 티켓에 답변을 기록하고, 드라이런 게이트를 통해 제거된 안개를 졸업한 다음 중지합니다. 이는 지도에 가져갈 수 있는 것이 없고 안개가 남아 있을 때 자체적으로 안개를 졸업시키는 스킬이기도 합니다. 맵이 이미 존재하고 사용자가 "맵 계속", "다음 결정", "의사 결정 맵 작업"이라고 말하거나 맵에 티켓 이름을 지정하거나 차트 작업으로 돌아올 때 사용하세요. 지도를 생성하거나 안개가 낀 아이디어(즉, 차트 지도)에 첫 번째 티켓을 추가하는 데 사용하지 마세요. 또한 뒤에 지도가 없는 단일 세션 디자인(즉, grill-then-plan / sp-grill-with-doc)에는 사용하지 마세요. 한 세션에서 두 개 이상의 HITL 티켓을 해결하지 마세요.
