Поработайте один сеанс с существующей картой решений — загрузите ее, отобразите границу (открытые, разблокированные, невостребованные билеты) по имени, заявите ровно ОДНУ, решите ее с помощью соответствующего навыка дуги (гриль / прототип / исследование / задача), запишите ответ в билете, пропустите любой туман, который он рассеял, через ворота пробного хода, затем СТОП. Это также навык, который сам по себе устраняет туман, когда на карте не осталось ничего, что можно было бы взять, но туман остается. Используйте, когда карта уже существует и пользователь говорит «продолжить карту», ​​«следующее решение», «работать с картой решений», называет на ней заявку или возвращается к запланированному усилию. НЕ используйте для создания карты или для добавления первых билетов к туманной идее (то есть диаграмме-карте) и НЕ используйте для односессионного дизайна без карты (то есть гриль-затем-план/sp-гриль-с-документом). Никогда не разрешает более одного билета HITL за сеанс.
