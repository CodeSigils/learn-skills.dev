Revisión integral desde una perspectiva externa de un plan, PR o cambio de código. Primero cuestiona la intención y si un enfoque más simple/elegante lograría el mismo objetivo, luego rastrea la ruta del código real (no solo la diferencia) para verificar que el cambio hace lo que dice. El resultado es conciso, procesable y cada llamada tiene su justificación. Active /examine y proactivamente cada vez que el usuario solicite revisar, auditar, verificar la idoneidad u obtener una segunda opinión sobre un plan, relaciones públicas, diferencias, documentos de diseño o cambios de código propuestos.
