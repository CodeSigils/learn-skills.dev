管理者が管理していない UI (管理コンソール、ポータル、設定ページ、ダッシュボード) で手動で行う必要がある変更をユーザーにガイドし、前後のシステムを測定することで変更が成功したことを証明します。エージェント自身が変更を行うことができない、または行う必要がなく、人間がクリックする必要がある場合に、これを使用します。ユーザーは、「手順を追って教えてください、ポータルでこれを行うにはどうすればよいですか、手動で行います、このシステムに書き込むことはできません」と言った場合、または任意のコンソール (CRM、クラウド ポータル、DNS、SaaS 管理者、CI 設定、データベース GUI、ルーター、支払いダッシュボード) の Runbook、ハンドオーバー チェックリスト、またはクリック バイ クリック ガイドを要求した場合に使用します。また、エージェントが部分的にしか自動化できなかったタスクの終了時に手作業を引き戻すときにも使用します。エージェントがコード内で、または呼び出しが許可されている API 経由でエージェント自身が行うことができる変更には使用しないでください。
