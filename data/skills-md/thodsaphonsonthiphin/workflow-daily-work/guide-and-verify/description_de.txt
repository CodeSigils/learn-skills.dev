Führen Sie eine Person durch eine Änderung, die sie manuell in einer Benutzeroberfläche vornehmen muss, die Sie nicht kontrollieren – eine Admin-Konsole, ein Portal, eine Einstellungsseite, ein Dashboard – und beweisen Sie, dass sie umgesetzt wurde, indem Sie das System vorher und nachher messen. Verwenden Sie dies immer dann, wenn der Agent die Änderung nicht selbst vornehmen kann oder darf und ein Mensch klicken muss: Der Benutzer sagt: „Führe mich durch, bring mir Schritt für Schritt bei“, „Wie mache ich das im Portal“, „Ich mache es von Hand“, „Du kannst nicht in dieses System schreiben“ oder er fragt nach einem Runbook, einer Übergabe-Checkliste oder einer Click-by-Click-Anleitung für eine beliebige Konsole (CRM, Cloud-Portal, DNS, SaaS-Administrator, CI-Einstellungen, Datenbank-GUI, Router, Zahlungs-Dashboard). Verwenden Sie es auch, wenn Sie Handarbeit am Ende einer Aufgabe zurückgeben, die der Agent nur teilweise automatisieren konnte. Verwenden Sie es nicht für Änderungen, die der Agent einfach selbst im Code oder über eine API vornehmen kann, die er aufrufen darf.
