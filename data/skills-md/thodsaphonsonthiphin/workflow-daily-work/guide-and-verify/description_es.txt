Guíe a una persona a través de un cambio que debe realizar manualmente en una interfaz de usuario que no controla (una consola de administración, un portal, una página de configuración, un panel) y demuestre que se realizó midiendo el sistema antes y después. Use esto siempre que el agente no pueda o no deba realizar el cambio por sí mismo y un humano tenga que hacer clic: el usuario dice: guíeme, enséñeme paso a paso, cómo hago esto en el portal, lo haré a mano, no puede escribir en este sistema, o solicita un runbook, una lista de verificación de entrega o una guía clic a clic para cualquier consola (CRM, portal en la nube, DNS, administrador de SaaS, configuración de CI, GUI de base de datos, enrutador, panel de pagos). Úselo también cuando devuelva el trabajo manual al final de una tarea que el agente solo pudo automatizar parcialmente. No lo utilice para cambios que el agente pueda realizar él mismo en el código o mediante una API a la que pueda llamar.
