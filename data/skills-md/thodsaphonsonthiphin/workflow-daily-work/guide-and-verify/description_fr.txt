Guidez une personne dans une modification qu'elle doit effectuer manuellement dans une interface utilisateur que vous ne contrôlez pas (une console d'administration, un portail, une page de paramètres, un tableau de bord) et prouvez qu'elle a été effectuée en mesurant le système avant et après. Utilisez-le chaque fois que l'agent ne peut pas ou ne doit pas effectuer le changement lui-même et qu'un humain doit cliquer : l'utilisateur dit de me guider à travers le processus, de m'apprendre étape par étape, comment faire cela dans le portail, je le ferai à la main, vous ne pouvez pas écrire sur ce système, ou demande un runbook, une liste de contrôle de transfert ou un guide clic par clic pour n'importe quelle console (CRM, portail cloud, DNS, administrateur SaaS, paramètres CI, interface graphique de base de données, routeur, tableau de bord de paiement). Utilisez-le également lorsque vous remettez du travail manuel à la fin d’une tâche que l’agent n’a pu automatiser que partiellement. Ne l'utilisez pas pour des modifications que l'agent peut simplement apporter lui-même dans le code ou via une API qu'il est autorisé à appeler.
