قم بإنشاء مشكلات GitHub من github_backlog_input.json (مخرجات classify-github-issues) عبر البرنامج النصي create_github_issues.py المجمع. يعرض دائمًا جدول التشغيل التجريبي المرئي أولاً ولا يخلق مشكلات حقيقية إلا بعد موافقة المستخدم صراحةً. استخدم هذا عندما يكون هناك github_backlog_input.json أو أي ملف من العناصر المراد حفظها في GitHub، أو عندما يقول المستخدم "قم بإنشاء مشكلات GitHub" أو "احفظ التراكم" أو "ادفع هذه إلى GitHub" أو "قم بإنشاء المشكلات". هذه هي الخطوة التي تكتب فعليًا في الريبو، لذا تفضلها على استدعاءات واجهة برمجة التطبيقات (API) اليدوية. بعد الإنشاء، يكتب github_backlog_result.json لتتبع github-writeback.
