Создайте задачи GitHub из файла github_backlog_input.json (выходные данные classify-github-issues) с помощью встроенного скрипта create_github_issues.py. Всегда сначала показывает визуальную таблицу пробного прогона и создает реальные проблемы только после явного одобрения пользователя. Используйте это всякий раз, когда есть github_backlog_input.json или любой файл элементов для хранения в GitHub, или когда пользователь говорит «создать эти проблемы GitHub», «сохранить невыполненную работу», «отправить их в GitHub» или «создать проблемы». Это шаг, который фактически записывает данные в репозиторий, поэтому предпочтите его ручным вызовам API. После создания он записывает github_backlog_result.json для отслеживания github-writeback-tracking.
