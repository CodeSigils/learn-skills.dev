バンドルされている create_github_issues.py スクリプトを使用して、github_backlog_input.json (classify-github-issues の出力) から GitHub Issue を作成します。常に最初に視覚的な予行演習テーブルを表示し、ユーザーが明示的に承認した後にのみ実際の問題を作成します。 github_backlog_input.json または GitHub にファイルする項目のファイルがある場合、またはユーザーが「GitHub の課題を作成する」、「バックログをファイルする」、「これらを GitHub にプッシュする」、または「課題を作成する」と指示する場合には、これを使用します。これは実際にリポジトリに書き込むステップであるため、手動で API 呼び出しを行うよりも優先してください。作成後、github-writeback-tracking 用に github_backlog_result.json を書き込みます。
