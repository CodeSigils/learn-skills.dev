번들로 제공되는 create_github_issues.py 스크립트를 통해 github_backlog_input.json(classify-github-issues의 출력)에서 GitHub 문제를 생성합니다. 항상 시각적인 테스트 실행 테이블을 먼저 표시하고 사용자가 명시적으로 승인한 후에만 실제 문제를 생성합니다. github_backlog_input.json 또는 GitHub에 보관할 항목 파일이 있을 때마다 또는 사용자가 "이 GitHub 문제 만들기", "백로그 파일 만들기", "GitHub에 푸시" 또는 "문제 만들기"라고 말할 때 이 기능을 사용하세요. 이는 실제로 저장소에 쓰는 단계이므로 직접 API 호출을 수행하는 것보다 선호합니다. 생성 후 github-writeback-tracking을 위해 github_backlog_result.json을 작성합니다.
