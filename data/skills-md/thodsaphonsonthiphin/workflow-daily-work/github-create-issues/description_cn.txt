通过捆绑的 create_github_issues.py 脚本从 github_backlog_input.json （classify-github-issues 的输出）创建 GitHub 问题。始终首先显示可视化的试运行表，并且仅在用户明确批准后才会产生真正的问题。每当 GitHub 中存在 github_backlog_input.json 或任何要归档的项目文件时，或者当用户说“创建这些 GitHub 问题”、“归档待办事项”、“将这些推送到 GitHub”或“创建问题”时，请使用此选项。这是实际写入存储库的步骤，因此优于手动 API 调用。创建后，它会写入 github_backlog_result.json 以用于 github-writeback-tracking。
