Crea problemi GitHub da github_backlog_input.json (l'output di classify-github-issues) tramite lo script create_github_issues.py in bundle. Mostra sempre prima una tabella visiva di prova e crea problemi reali solo dopo l'approvazione esplicita dell'utente. Utilizzalo ogni volta che è presente un github_backlog_input.json o qualsiasi file di elementi da archiviare in GitHub o quando l'utente dice "crea questi problemi su GitHub", "archivia il backlog", "invia questi su GitHub" o "crea i problemi". Questo è il passaggio che scrive effettivamente nel repository, quindi preferiscilo alle chiamate API a rotazione manuale. Dopo la creazione, scrive github_backlog_result.json per il tracciamento github-writeback.
