Erstellen Sie GitHub-Issues aus einer github_backlog_input.json (der Ausgabe von classify-github-issues) über das gebündelte Skript create_github_issues.py. Zeigt immer zuerst eine visuelle Probelauftabelle an und erstellt echte Probleme erst, nachdem der Benutzer dies ausdrücklich genehmigt hat. Verwenden Sie dies immer dann, wenn eine Datei „github_backlog_input.json“ oder eine beliebige Datei mit Elementen zum Ablegen in GitHub vorhanden ist oder wenn der Benutzer „Diese GitHub-Probleme erstellen“, „den Backlog einreichen“, „diese auf GitHub übertragen“ oder „die Probleme erstellen“ sagt. Dies ist der Schritt, der tatsächlich in das Repo schreibt. Bevorzugen Sie ihn daher gegenüber manuellen API-Aufrufen. Nach der Erstellung wird github_backlog_result.json für das Github-Writeback-Tracking geschrieben.
