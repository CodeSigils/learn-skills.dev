Cree problemas de GitHub desde github_backlog_input.json (la salida de classify-github-issues) a través del script create_github_issues.py incluido. Siempre muestra primero una tabla visual de ejecución en seco y solo crea problemas reales después de que el usuario lo apruebe explícitamente. Use esto siempre que haya un github_backlog_input.json o cualquier archivo de elementos para archivar en GitHub, o cuando el usuario diga "crear estos problemas de GitHub", "archivar el trabajo pendiente", "enviarlos a GitHub" o "crear los problemas". Este es el paso que realmente escribe en el repositorio, así que prefiérelo a las llamadas API manuales. Después de crear, escribe github_backlog_result.json para github-writeback-tracking.
