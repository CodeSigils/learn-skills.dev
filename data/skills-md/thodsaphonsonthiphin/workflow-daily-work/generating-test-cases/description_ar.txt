يُستخدم عندما تحتاج إلى إنتاج مجموعة حالات اختبار لميزة أو تغيير أو علاقات عامة أو خطأ ثابت - يدوي أو آلي - للتسليم إلى Excel/xlsx، أو Markdown، أو CSV، أو أداة تعقب. مشغلات عند "كتابة حالات الاختبار"، أو "إنشاء خطة اختبار"، أو "حالات ضمان الجودة"، أو "تحويل هذه المواصفات/الفرق/الخطأ إلى اختبارات"، أو بعد إنشاء الميزة / إصلاح الخلل وقبل التقديم أو تسجيل الخروج. ترتكز كل حالة على أدلة حقيقية (docs، أو code، أو git، أو النظام المباشر)؛ المهارة ترفض اختراع القيم. لا تستخدم للتحقق من مهمة واحدة منتهية بالفعل (أي التحقق المزدوج)، أو لتقديم النتائج كعناصر عمل (أي المكونات الإضافية المتراكمة - فهذا تسليمها لهم).
