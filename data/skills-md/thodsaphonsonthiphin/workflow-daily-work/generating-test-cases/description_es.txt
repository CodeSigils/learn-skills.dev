Úselo cuando necesite producir un conjunto de casos de prueba para una característica, cambio, PR o error corregido (manual o automatizado) para enviarlo a Excel/xlsx, Markdown, CSV o un rastreador. Activadores al "escribir casos de prueba", "crear un plan de prueba", "casos de control de calidad", "convertir esta especificación/diferencia/error en pruebas", o después de crear una función/corregir un error y antes de presentarlo o cerrar sesión. Cada caso se basa en evidencia real (docs, code, git o el sistema LIVE); la habilidad se niega a inventar valores. NO lo utilice para verificar una tarea ya finalizada (es decir, un verificador dual) ni para archivar los hallazgos como elementos de trabajo (es decir, los complementos de trabajo pendiente; esto les pasa a ellos).
