Используйте, когда вам нужно создать набор тестовых примеров для функции, изменения, PR или исправленной ошибки — вручную или автоматически — для доставки в Excel/xlsx, Markdown, CSV или трекер. Срабатывает при «написании тестовых примеров», «создании плана тестирования», «кейсах контроля качества», «превращении этой спецификации/разницы/ошибки в тесты» или после создания функции/исправления ошибки, но перед подачей или подписанием. Каждое дело основано на реальных доказательствах (документы, код, git или система LIVE); навык отказывается изобретать ценности. НЕ используйте для проверки одной уже завершенной задачи (то есть двойной проверки) или для сохранения результатов в качестве рабочих элементов (то есть плагинов невыполненной работы — это им).
