À utiliser lorsque vous devez produire une suite de cas de test pour une fonctionnalité, une modification, une PR ou un bug corrigé (manuel ou automatisé) pour livraison vers Excel/xlsx, Markdown, CSV ou un outil de suivi. Déclencheurs sur "écrire des cas de test", "créer un plan de test", "cas d'assurance qualité", "transformer cette spécification/diff/bug en tests", ou après la création d'une fonctionnalité/la correction d'un bug et avant le dépôt ou la signature. Chaque cas est fondé sur des preuves réelles (documents, code, git ou système LIVE) ; la compétence refuse d'inventer des valeurs. Ne PAS utiliser pour vérifier une tâche déjà terminée (c'est-à-dire un double vérificateur) ou pour classer les résultats en tant qu'éléments de travail (c'est-à-dire les plugins de backlog - cela leur est confié).
