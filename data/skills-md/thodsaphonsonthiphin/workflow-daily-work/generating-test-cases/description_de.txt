Verwenden Sie diese Option, wenn Sie eine Testfallsuite für eine Funktion, Änderung, PR oder einen behobenen Fehler erstellen müssen – manuell oder automatisiert – zur Übermittlung an Excel/XLSX, Markdown, CSV oder einen Tracker. Wird ausgelöst bei „Testfälle schreiben“, „Testplan erstellen“, „QA-Fälle“, „diese Spezifikation/diesen Unterschied/Fehler in Tests umwandeln“ oder nachdem eine Funktion erstellt/ein Fehler behoben wurde und vor der Einreichung oder Freigabe. Jeder Fall basiert auf echten Beweisen (Dokumente, Code, Git oder das LIVE-System); Die Fähigkeit weigert sich, Werte zu erfinden. NICHT verwenden, um eine bereits abgeschlossene Aufgabe zu überprüfen (d. h. Dual-Verifizierer) oder Ergebnisse als Arbeitselemente abzulegen (d. h. die Backlog-Plugins – diese werden ihnen überlassen).
