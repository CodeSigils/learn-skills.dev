Asigne los resultados clasificados a los problemas de GitHub con las etiquetas, los hitos y el cuerpo correctos, y emita github_backlog_input.json listo para su creación. Utilice esto DESPUÉS de la clasificación y ANTES de crear problemas, cuando el usuario pregunte "qué etiquetas deberían recibir", "convierta estos hallazgos en problemas de GitHub", "clasificarlos para GitHub" o "construya la entrada del trabajo pendiente de GitHub". Asigna la gravedad a las etiquetas de prioridad (P0-P3), el tipo a las etiquetas de tipo (error/mejora/tarea) y las horas a las etiquetas de tamaño (tamaño: XS-XL). Crea un hito para el lote. No intervengas en github-create-issues.
