قم بتعيين النتائج المصنفة إلى مشكلات GitHub باستخدام التصنيفات الصحيحة والمعالم الرئيسية والنص، ثم قم بإصدار github_backlog_input.json جاهزًا للإنشاء. استخدم هذا الفرز بعد وقبل إنشاء المشكلات - عندما يسأل المستخدم "ما هي التصنيفات التي يجب أن تحصل عليها"، أو "تحويل هذه النتائج إلى مشكلات GitHub"، أو "تصنيفها لـ GitHub"، أو "إنشاء مدخلات Github المتراكمة". يقوم بتعيين الخطورة إلى تسميات الأولوية (P0-P3)، والنوع لكتابة التسميات (خطأ/تحسين/مهمة)، والساعات حسب حجم التسميات (الحجم: XS-XL). ينشئ علامة فارقة للدفعة. ارفعوا أيديكم عن مشكلات إنشاء github.
