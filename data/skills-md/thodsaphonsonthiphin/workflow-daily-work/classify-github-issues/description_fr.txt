Mappez les résultats triés aux problèmes GitHub avec les étiquettes, le jalon et le corps corrects, et émettez github_backlog_input.json prêt pour la création. Utilisez ceci APRÈS le tri et AVANT de créer des problèmes — lorsque l'utilisateur demande « quelles étiquettes devraient-ils recevoir », « transformer ces résultats en problèmes GitHub », « les classer pour GitHub » ou « créer l'entrée du backlog github ». Mappe la gravité aux étiquettes de priorité (P0-P3), le type aux étiquettes de type (bug/amélioration/tâche) et les heures aux étiquettes de taille (taille : XS-XL). Crée un jalon pour le lot. Ne touchez pas aux problèmes de création de github.
