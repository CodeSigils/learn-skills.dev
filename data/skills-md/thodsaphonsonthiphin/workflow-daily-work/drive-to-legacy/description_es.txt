Úselo al explorar, estudiar o portar una base de código heredada desconocida. Se activa cuando el usuario dice "explorar este proyecto", "entender este código", "necesito portar esto", "cómo funciona esta aplicación", "documentar esta base de código", "estudiar este código" o cualquier solicitud para comprender profundamente un proyecto existente que no escribió. También se activa al incorporar a un nuevo repositorio o al preparar planes de migración/reescritura.
