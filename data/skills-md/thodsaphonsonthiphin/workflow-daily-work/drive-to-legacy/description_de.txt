Zum Erkunden, Studieren oder Portieren einer unbekannten Legacy-Codebasis. Wird ausgelöst, wenn der Benutzer sagt: „Dieses Projekt erkunden“, „Diesen Code verstehen“, „Ich muss das portieren“, „Wie funktioniert diese App“, „Diese Codebasis dokumentieren“, „Diesen Code studieren“ oder eine Anfrage stellt, ein bestehendes Projekt, das er nicht geschrieben hat, gründlich zu verstehen. Wird auch beim Onboarding in ein neues Repo oder beim Vorbereiten von Migrations-/Umschreibungsplänen ausgelöst.
