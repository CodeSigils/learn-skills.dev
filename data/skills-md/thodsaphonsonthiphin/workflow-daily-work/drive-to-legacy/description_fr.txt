À utiliser lors de l'exploration, de l'étude ou du portage d'une base de code héritée inconnue. Se déclenche lorsque l'utilisateur dit « explorer ce projet », « comprendre ce code », « Je dois porter ceci », « comment fonctionne cette application », « documenter cette base de code », « étudier ce code » ou toute demande visant à comprendre en profondeur un projet existant qu'il n'a pas écrit. Se déclenche également lors de l'intégration dans un nouveau dépôt ou de la préparation de plans de migration/réécriture.
