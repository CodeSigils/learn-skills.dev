Покажите назначенные вам рабочие элементы Azure DevOps в виде чистой сгруппированной таблицы — сначала откройте работу, отсортируйте ее по состоянию, а затем по приоритету, с номером заявки в виде интерактивной ссылки. Используйте всякий раз, когда пользователь спрашивает: «Что у меня на тарелке», «Мои рабочие задачи/мои задачи», «над чем мне работать дальше», «показать мое невыполненное задание», «прочитать центр задач», «ежедневная подготовка к стендапу» или начинает день, желая выполнить оставшуюся работу. Это второй шаг ежедневной работы (читайте раздел задач). Только для чтения — он перечисляет, никогда ничего не меняет.
