Orquestador de extremo a extremo que convierte los hallazgos de CUALQUIER entrada (hoja de cálculo de auditoría, revisión de código/seguridad, informe de control de calidad, notas de reuniones, una lista pegada de problemas) en un trabajo pendiente de problemas de GitHub con un hito, etiquetas y un problema de seguimiento. Impulsa las habilidades de los hermanos de github-backlog en orden con puertas de seguridad. Se activa cada vez que el usuario dice "convertir esta auditoría/hoja de cálculo/revisión/lista de problemas en problemas de GitHub", "crear un trabajo pendiente a partir de estos hallazgos", "archivarlos como problemas de GitHub", "importar este xlsx/csv a GitHub", "crear problemas a partir de este informe" o le entrega un documento fuente y le solicita que llegue a GitHub. Este es el título, punto de entrada único (/github-backlog:run lo envuelve). No para editar ediciones existentes individualmente.
