End-to-End-Orchestrator, der Erkenntnisse aus JEDEM Input (Audit-Tabelle, Code-/Sicherheitsüberprüfung, QS-Bericht, Besprechungsnotizen, eine eingefügte Liste von Problemen) in ein GitHub-Problem-Backlog mit einem Meilenstein, Labels und einem Tracking-Problem umwandelt. Bringt die Geschwister-Github-Backlog-Fähigkeiten mit Sicherheitstoren in Ordnung. Wird immer dann ausgelöst, wenn der Benutzer sagt: „Diese Prüfung/Tabelle/Überprüfung/Liste von Problemen in GitHub-Probleme umwandeln“, „einen Rückstand aus diesen Ergebnissen erstellen“, „diese als GitHub-Probleme ablegen“, „diese XLSX/CSV-Datei in GitHub importieren“, „Probleme aus diesem Bericht erstellen“ oder Ihnen ein Quelldokument überreicht und darum bittet, dass es in GitHub landet. Dies ist die Schlagzeile, ein einmaliger Einstiegspunkt (/github-backlog:run umschließt ihn). Nicht zum individuellen Bearbeiten vorhandener Probleme.
