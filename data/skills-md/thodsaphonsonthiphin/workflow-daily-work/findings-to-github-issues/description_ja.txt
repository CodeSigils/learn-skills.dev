あらゆる入力 (監査スプレッドシート、コード/セキュリティ レビュー、QA レポート、会議メモ、貼り付けられた問題のリスト) から得た結果を、マイルストーン、ラベル、追跡問題を含む GitHub 問題バックログに変換するエンドツーエンドのオーケストレーターです。安全ゲートを使用して、兄弟の github-backlog スキルを順番に駆動します。ユーザーが「この監査/スプレッドシート/レビュー/問題のリストを GitHub の問題に変換する」、「これらの結果からバックログを作成する」、「これらを GitHub の問題としてファイルする」、「この xlsx/csv を GitHub にインポートする」、「このレポートから問題を作成する」、またはソース ドキュメントを渡して GitHub に配置するように要求するたびにトリガーされます。これは見出しであり、ワンショットのエントリ ポイントです (/github-backlog:run でラップされます)。既存の問題を個別に編集するためのものではありません。
