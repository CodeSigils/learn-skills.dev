端到端编排器，可将任何输入（审计电子表格、代码/安全审查、QA 报告、会议记录、粘贴的问题列表）中的结果转换为带有里程碑、标签和跟踪问题的 GitHub Issues 积压工作。通过安全门按顺序驱动同级 github 积压技能。每当用户说“将此审核/电子表格/审查/问题列表转换为 GitHub 问题”、“根据这些发现创建积压工作”、“将这些文件归档为 GitHub 问题”、“将此 xlsx/csv 导入 GitHub”、“从此报告中提出问题”或向您提供源文档并要求将其放入 GitHub 时触发。这是标题，一次性入口点（/github-backlog:run 包装它）。不适用于单独编辑现有问题。
