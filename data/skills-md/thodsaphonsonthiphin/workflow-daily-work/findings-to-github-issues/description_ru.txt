Комплексный оркестратор, который превращает результаты ЛЮБЫХ входных данных (таблица аудита, проверка кода/безопасности, отчет по обеспечению качества, заметки о встрече, вставленный список проблем) в журнал невыполненных задач GitHub с контрольной точкой, метками и проблемой отслеживания. Приводит в порядок навыки работы братьев и сестер в github-backlog с помощью защитных ворот. Вызывается всякий раз, когда пользователь говорит: «превратите этот аудит/таблицу/проверку/список проблем в проблемы GitHub», «создайте резервную копию этих результатов», «сохраните их как проблемы GitHub», «импортируйте этот xlsx/csv в GitHub», «создайте проблемы из этого отчета» или передает вам исходный документ и просит разместить его в GitHub. Это заголовок, одноразовая точка входа (/github-backlog:run завершает его). Не для индивидуального редактирования существующих задач.
