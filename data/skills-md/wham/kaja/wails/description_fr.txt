Référence rapide pour Wails v2, le framework de bureau Go + natif-webview. À utiliser chaque fois que la tâche touche un projet Wails — `wails.json`, `wails.Run`, `options.App`, `assetserver`, les liaisons Go ↔ JS sous `frontend/wailsjs/`, l'API d'exécution (`runtime.WindowSetTitle`, `runtime.EventsEmit`, `window.runtime.*`), `wails build` / `wails dev` / `wails generate`, `frontend/dist` intégré, rechargement à chaud du serveur de développement, signature de code ou tout ce qui se trouve dans `desktop/main.go` qui connecte une application Wails. À utiliser également lorsque l'utilisateur mentionne WebView2, WebKitGTK ou « la version de bureau ».
