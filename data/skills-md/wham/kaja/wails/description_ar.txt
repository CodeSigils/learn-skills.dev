مرجع سريع لـ Wails v2، إطار عمل Go + webview الأصلي لسطح المكتب. يُستخدم عندما تلامس المهمة مشروع Wails - `wails.json`، `wails.Run`، `options.App`، `assetserver`، روابط Go ↔ JS ضمن `frontend/wailsjs/`، واجهة برمجة تطبيقات وقت التشغيل (`runtime.WindowSetTitle`، `runtime.EventsEmit`، `window.runtime.*`)، `wails build`. / `wails dev` / `wails generator`، أو الواجهة الأمامية/dist المضمنة، أو إعادة التحميل السريع لخادم dev، أو توقيع التعليمات البرمجية، أو أي شيء في `desktop/main.go` الذي يربط تطبيق Wails. يُستخدم أيضًا عندما يذكر المستخدم WebView2 أو WebKitGTK أو "إصدار سطح المكتب".
