Краткий справочник по Wails v2, платформе рабочего стола Go + own-webview. Используйте всякий раз, когда задача касается проекта Wails — `wails.json`, `wails.Run`, `options.App`, `assetserver`, привязки Go ↔ JS в `frontend/wailsjs/`, API времени выполнения (`runtime.WindowSetTitle`, `runtime.EventsEmit`, `window.runtime.*`), `wails build` / `wails dev` / `wailsgenerate`, встроенный `frontend/dist`, горячая перезагрузка dev-сервера, подпись кода или что-либо в `desktop/main.go`, которое подключает приложение Wails. Также используйте, когда пользователь упоминает WebView2, WebKitGTK или «сборку рабочего стола».
