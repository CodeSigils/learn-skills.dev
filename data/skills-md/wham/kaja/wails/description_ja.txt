Wails v2、Go + ネイティブ Webview デスクトップ フレームワークのクイック リファレンス。タスクが Wails プロジェクトに触れるときは常に使用します — `wails.json`、`wails.Run`、`options.App`、`assetserver`、`frontend/wailsjs/` の Go ↔ JS バインディング、ランタイム API (`runtime.WindowSetTitle`、`runtime.EventsEmit`、`window.runtime.*`)、`wails build` / `wails dev` / `wails generated`、埋め込まれた `frontend/dist`、dev-server ホット リロード、コード署名、または Wails アプリを接続する `desktop/main.go` 内のあらゆるもの。ユーザーが WebView2、WebKitGTK、または「デスクトップ ビルド」について言及する場合にも使用します。
