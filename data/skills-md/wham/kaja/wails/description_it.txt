Riferimento rapido per Wails v2, il framework desktop Go+ con visualizzazione Web nativa. Da utilizzare ogni volta che l'attività tocca un progetto Wails: `wails.json`, `wails.Run`, `options.App`, `assetserver`, i collegamenti Go ↔ JS in `frontend/wailsjs/`, l'API runtime (`runtime.WindowSetTitle`, `runtime.EventsEmit`, `window.runtime.*`), `wails build` / `wails dev` / `wails generate", "frontend/dist" incorporato, ricarica a caldo del server di sviluppo, firma del codice o qualsiasi cosa in "desktop/main.go" che colleghi un'app Wails. Da utilizzare anche quando l'utente menziona WebView2, WebKitGTK o "la build desktop".
