Referencia rápida para Wails v2, el marco de escritorio de vista web nativa Go +. Úselo siempre que la tarea toque un proyecto Wails: `wails.json`, `wails.Run`, `options.App`, `assetserver`, los enlaces Go ↔ JS en `frontend/wailsjs/`, la API de tiempo de ejecución (`runtime.WindowSetTitle`, `runtime.EventsEmit`, `window.runtime.*`), `wails build` / `wails dev` / `wails generate`, `frontend/dist` integrado, recarga en caliente del servidor dev, firma de código o cualquier cosa en `desktop/main.go` que conecte una aplicación Wails. Úselo también cuando el usuario mencione WebView2, WebKitGTK o "la compilación del escritorio".
