Подключите amondnet/vercel-action к рабочему процессу GitHub Actions для развертывания проектов Vercel из CI. Используйте, когда пользователь запрашивает развертывание в Vercel из действий GitHub, добавление предварительных развертываний Vercel, публикацию URL-адреса предварительного просмотра Vercel в PR, настройку готовых развертываний Vercel, настройку псевдонимов доменов для предварительного просмотра, создание развертывания GitHub для Vercel или миграцию с собственной интеграции Vercel с GitHub. Охватывает необходимые токены/идентификаторы, режимы CLI и экспериментального API, готовые потоки, заполнители псевдонимов, устаревшие псевдонимы `zeit-*`/`now-*` и выходные данные действия (`preview-url`, `preview-name`, `deployment-id`).
