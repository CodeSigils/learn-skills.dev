Collega "amondnet/vercel-action" in un flusso di lavoro GitHub Actions per distribuire progetti Vercel da CI. Da utilizzare quando l'utente chiede di eseguire la distribuzione a Vercel da GitHub Actions, aggiungere distribuzioni di anteprima Vercel, pubblicare un URL di anteprima Vercel su un PR, configurare distribuzioni Vercel predefinite, impostare domini alias per le anteprime, creare una distribuzione GitHub per Vercel o eseguire la migrazione dall'integrazione GitHub nativa di Vercel. Copre i token/ID richiesti, le modalità CLI e API sperimentale, i flussi predefiniti, i segnaposto degli alias, gli alias `zeit-*`/`now-*` deprecati e gli output dell'azione (`preview-url`, `preview-name`, `deployment-id`).
