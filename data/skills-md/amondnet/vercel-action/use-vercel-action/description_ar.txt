قم بتوصيل "amondnet/vercel-action" إلى سير عمل GitHub Actions لنشر مشاريع Vercel من CI. يُستخدم عندما يطلب المستخدم النشر إلى Vercel من GitHub Actions، أو إضافة عمليات نشر معاينة Vercel، أو نشر عنوان URL لمعاينة Vercel على العلاقات العامة، أو تكوين عمليات نشر Vercel المعدة مسبقًا، أو إعداد نطاقات مستعارة للمعاينات، أو إنشاء نشر GitHub لـ Vercel، أو الترحيل من تكامل GitHub الأصلي لـ Vercel. يغطي الرموز/المعرفات المطلوبة، وأوضاع سطر الأوامر مقابل أوضاع واجهة برمجة التطبيقات التجريبية، والتدفقات المعدة مسبقًا، والعناصر النائبة للاسم المستعار، والأسماء المستعارة `zeit-*`/`now-*` المهملة، ومخرجات الإجراء (`preview-url`، `preview-name`، `deployment-id`).
