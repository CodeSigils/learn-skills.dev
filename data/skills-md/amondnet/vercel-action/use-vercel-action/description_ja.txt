「amondnet/vercel-action」を GitHub Actions ワークフローに接続して、CI から Vercel プロジェクトをデプロイします。ユーザーが、GitHub Actions から Vercel へのデプロイ、Vercel プレビュー デプロイの追加、PR への Vercel プレビュー URL の投稿、事前構築済み Vercel デプロイの構成、プレビュー用のエイリアス ドメインの設定、Vercel の GitHub デプロイメントの作成、または Vercel のネイティブ GitHub 統合からの移行を要求する場合に使用します。必要なトークン/ID、CLI と実験的 API モード、事前構築されたフロー、エイリアス プレースホルダー、非推奨の `zeit-*`/`now-*` エイリアス、およびアクションの出力 (`preview-url`、`preview-name`、`deployment-id`) について説明します。
