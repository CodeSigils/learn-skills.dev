Connectez « amondnet/vercel-action » à un workflow GitHub Actions pour déployer des projets Vercel à partir de CI. À utiliser lorsque l'utilisateur demande un déploiement sur Vercel à partir des actions GitHub, ajoute des déploiements d'aperçu de Vercel, publie une URL d'aperçu de Vercel sur un PR, configure des déploiements Vercel prédéfinis, configure des domaines d'alias pour les aperçus, crée un déploiement GitHub pour Vercel ou migre hors de l'intégration GitHub native de Vercel. Couvre les jetons/ID requis, les modes CLI et API expérimentale, les flux prédéfinis, les espaces réservés d'alias, les alias obsolètes `zeit-*`/`now-*` et les sorties de l'action (`preview-url`, `preview-name`, `deployment-id`).
