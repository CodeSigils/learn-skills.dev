CI에서 Vercel 프로젝트를 배포하려면 'amondnet/vercel-action'을 GitHub Actions 워크플로에 연결하세요. 사용자가 GitHub Actions에서 Vercel에 배포, Vercel 미리 보기 배포 추가, PR에 Vercel 미리 보기 URL 게시, 사전 구축된 Vercel 배포 구성, 미리 보기용 별칭 도메인 설정, Vercel용 GitHub 배포 생성 또는 Vercel의 기본 GitHub 통합에서 마이그레이션을 요청할 때 사용합니다. 필수 토큰/ID, CLI 및 실험적 API 모드, 사전 구축된 흐름, 별칭 자리 표시자, 더 이상 사용되지 않는 `zeit-*`/`now-*` 별칭 및 작업의 출력(`preview-url`, `preview-name`, `deployment-id`)을 다룹니다.
