Verknüpfen Sie „amondnet/vercel-action“ mit einem GitHub Actions-Workflow, um Vercel-Projekte über CI bereitzustellen. Verwenden Sie diese Option, wenn der Benutzer eine Bereitstellung auf Vercel aus GitHub-Aktionen anfordert, Vercel-Vorschaubereitstellungen hinzufügt, eine Vercel-Vorschau-URL auf einem PR postet, vorgefertigte Vercel-Bereitstellungen konfiguriert, Aliasdomänen für Vorschauen einrichtet, eine GitHub-Bereitstellung für Vercel erstellt oder von der nativen GitHub-Integration von Vercel migriert. Behandelt erforderliche Token/IDs, die CLI- und Experimental-API-Modi, vorgefertigte Flows, Alias-Platzhalter, veraltete „zeit-*“/„now-*“-Aliase und die Ausgaben der Aktion („preview-url“, „preview-name“, „deployment-id“).
