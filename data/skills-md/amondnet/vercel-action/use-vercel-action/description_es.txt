Conecte `amondnet/vercel-action` a un flujo de trabajo de GitHub Actions para implementar proyectos de Vercel desde CI. Úselo cuando el usuario solicite implementar en Vercel desde GitHub Actions, agregar implementaciones de vista previa de Vercel, publicar una URL de vista previa de Vercel en un PR, configurar implementaciones de Vercel prediseñadas, configurar dominios de alias para vistas previas, crear una implementación de GitHub para Vercel o migrar desde la integración nativa de GitHub de Vercel. Cubre los tokens/ID requeridos, los modos CLI versus API experimental, flujos prediseñados, marcadores de posición de alias, alias obsoletos `zeit-*`/`now-*` y las salidas de la acción (`preview-url`, `preview-name`, `deployment-id`).
