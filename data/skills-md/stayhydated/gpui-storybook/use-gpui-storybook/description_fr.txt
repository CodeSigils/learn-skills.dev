Intégrez ou dépannez GPUI Storybook dans les référentiels d'applications. À utiliser lorsque le Codex doit ajouter un binaire Storybook ; enregistrer les aperçus avec #[story], #[derive(ComponentStory)], #[derive(Substory)] ou #[story_init] ; configurer les groupes storybook.toml, les filtres ou lancer les remplacements ; choisissez le mode Galerie ou Dock ; ajoutez des contrôles d'histoire dactylographiés ou utilisez l'atelier de contrôles/thèmes et l'intégration opt-in de l'inspecteur ; câblez l'adaptateur de paramètres régionaux es-fluent et les préférences de démarrage ; activer les outils MCP, l'interaction opt-in en cours de processus ou la capture PNG ; ou diagnostiquer les histoires manquantes, les itinéraires instables, la préparation aux préférences, les échecs de contrôle, les échecs d'interaction ou les échecs de capture.
