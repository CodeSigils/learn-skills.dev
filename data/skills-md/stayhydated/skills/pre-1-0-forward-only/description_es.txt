Aplique reglas de edición, documentación y revisión solo hacia adelante para cajas o espacios de trabajo de Rust cuyo paquete o versión del espacio de trabajo sea inferior a 1.0. Úselo al editar, revisar o documentar API de Rust anteriores a 1.0, archivos README, guías de AGENTS.md, ejemplos, notas de versión, texto de migración o documentos de flujo de trabajo: omita la prosa negativa duradera y de superficie ausente como "actualmente no..." y evite obligaciones de compatibilidad con versiones anteriores o heredadas, preservación de API antiguas, alias, envoltorios o correcciones, a menos que la política de repositorio explícita o el usuario los requiera.
