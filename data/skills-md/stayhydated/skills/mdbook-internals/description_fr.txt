Crée et révise la documentation mdBook destinée aux responsables en-US pour l'architecture, les composants, les flux de contrôle et de données, les invariants, les modes de défaillance, les opérations, les points d'extension, les flux de travail des contributeurs et les décisions de conception. S'applique lorsque les lecteurs ont besoin d'un contexte d'implémentation vérifié pour modifier, déboguer, exploiter ou réviser un système. Exclut la documentation sur les tâches de l'utilisateur final, qui appartient à mdbook-user-docs.
