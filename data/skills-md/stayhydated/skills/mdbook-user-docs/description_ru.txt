Создает и редактирует пользовательскую документацию на английском языке в проектах mdBook для продуктов, интерфейсов командной строки, библиотек и API. Применяется к учебникам, практическим руководствам, концепциям, справочным страницам, руководствам по миграции и устранению неполадок для конечных пользователей. Исключает документацию по архитектуре и реализации, предназначенную только для сопровождающих, которая принадлежит mdbook-internals.
