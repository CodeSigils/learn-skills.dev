Analyse les applications Android pour identifier les flux de travail des utilisateurs clés pour AppFunctions, tels que la création d'une note, la lecture multimédia ou l'envoi d'un message automatisé ou déclenché par un agent IA, des commandes vocales ou des raccourcis système, sans avoir besoin d'ouvrir l'interface utilisateur de l'application. Génère du code Kotlin pour exposer ces flux de travail au système Android, permettant aux agents de les découvrir et de les exécuter sur l'appareil. Affine également la documentation KDoc pour garantir que les agents IA comprennent et utilisent correctement les fonctionnalités fournies.
