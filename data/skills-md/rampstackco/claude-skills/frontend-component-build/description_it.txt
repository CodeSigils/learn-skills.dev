Crea componenti frontend pronti per la produzione con markup accessibile, supporti sensibili, stati definiti e comportamento testato. Utilizza questa competenza ogni volta che l'utente desidera creare un componente da zero, effettuare il refactoring di uno esistente, progettare un'API del componente o implementare un elemento dell'interfaccia utente con stati e accessibilità adeguati. Si attiva per creare un componente, creare un pulsante, creare un modale, creare un input del modulo, API del componente, progettazione degli oggetti di scena, stati del componente, componente refactoring, componente accessibile. Si attiva anche quando si implementa l'interfaccia utente da un progetto che deve essere riutilizzabile.
