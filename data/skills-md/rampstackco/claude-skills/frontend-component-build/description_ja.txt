アクセス可能なマークアップ、適切なプロパティ、定義された状態、およびテストされた動作を備えた、本番環境に対応したフロントエンド コンポーネントを構築します。ユーザーがコンポーネントを最初から構築する場合、既存のコンポーネントをリファクタリングする場合、コンポーネント API を設計する場合、または適切な状態とアクセシビリティを備えた UI 要素を実装する場合は、常にこのスキルを使用します。コンポーネントのビルド、ボタンの作成、モーダルの作成、フォーム入力の作成、コンポーネント API、小道具のデザイン、コンポーネントの状態、コンポーネントのリファクタリング、アクセス可能なコンポーネントのトリガー。再利用可能にする必要があるデザインから UI を実装するときにもトリガーされます。
