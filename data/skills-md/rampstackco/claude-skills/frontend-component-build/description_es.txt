Cree componentes frontend listos para producción con marcado accesible, accesorios sensibles, estados definidos y comportamiento probado. Utilice esta habilidad siempre que el usuario quiera crear un componente desde cero, refactorizar uno existente, diseñar una API de componente o implementar un elemento de interfaz de usuario con estados y accesibilidad adecuados. Activadores al crear un componente, crear un botón, crear un modal, crear una entrada de formulario, API de componente, diseño de accesorios, estados de componentes, refactorizar componente, componente accesible. También se activa al implementar la interfaz de usuario a partir de un diseño que debe ser reutilizable.
