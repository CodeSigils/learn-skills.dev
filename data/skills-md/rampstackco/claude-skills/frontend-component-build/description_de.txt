Erstellen Sie produktionsbereite Frontend-Komponenten mit zugänglichem Markup, sinnvollen Requisiten, definierten Zuständen und getestetem Verhalten. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Komponente von Grund auf erstellen, eine vorhandene umgestalten, eine Komponenten-API entwerfen oder ein UI-Element mit den richtigen Zuständen und Zugänglichkeit implementieren möchte. Auslöser beim Erstellen einer Komponente, Erstellen einer Schaltfläche, Erstellen eines Modals, Erstellen einer Formulareingabe, Komponenten-API, Requisitendesign, Komponentenzustände, Refaktorierungskomponente, zugängliche Komponente. Wird auch ausgelöst, wenn eine Benutzeroberfläche aus einem Design implementiert wird, das wiederverwendbar sein muss.
