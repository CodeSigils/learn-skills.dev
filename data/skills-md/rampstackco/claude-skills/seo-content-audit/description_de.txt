Überprüfen Sie vorhandene Inhalte auf einer Website, um zu entscheiden, was beibehalten, aktualisiert, zusammengeführt, umgeleitet oder gelöscht werden soll. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer vorhandene Inhalte prüfen, den Verfall von Inhalten beheben, die Kannibalisierung von Schlüsselwörtern auflösen, leistungsschwache Seiten bereinigen, Inhaltsaktualisierungen priorisieren oder ein Framework zum Halten/Aktualisieren/Zusammenführen/Umleiten/Löschen auf eine Inhaltsbibliothek anwenden möchte. Löst Folgendes aus: Inhaltsprüfung, Inhaltsverfall, Inhaltsaktualisierung, Kannibalisierung, Kannibalisierung von Schlüsselwörtern, Beschneiden von Inhalten, Löschen von Seiten, Umleiten alter Seiten, Inhaltsinventar, Was soll behalten werden, was soll aktualisiert werden, Inhalts-Scorecard, Evergreen-Aktualisierung. Wird auch ausgelöst, wenn der Datenverkehr auf der gesamten Website zurückgeht und die Ursache möglicherweise in der Qualität des Inhalts liegt, auch wenn „Überprüfung“ nicht ausdrücklich erwähnt wird.
