Establezca una línea de base de seguridad para un sitio web o una aplicación web. Utilice esta habilidad al configurar HTTPS y TLS, establecer encabezados de seguridad, planificar la gestión de secretos, evaluar políticas de CSP, realizar una auditoría de seguridad básica o reforzar un sitio antes del lanzamiento. Activadores en encabezados de seguridad, HTTPS, TLS, CSP, política de seguridad de contenido, HSTS, gestión de secretos, escaneo de vulnerabilidades, auditoría de seguridad, refuerzo, OWASP, línea de base de seguridad. También se activa cuando se requiere una revisión de seguridad para el cumplimiento o antes de entrar en funcionamiento.
