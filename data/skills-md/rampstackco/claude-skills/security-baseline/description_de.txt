Richten Sie eine Sicherheitsbasis für eine Website oder Web-App ein. Verwenden Sie diese Fähigkeit, wenn Sie HTTPS und TLS konfigurieren, Sicherheitsheader festlegen, die Verwaltung von Geheimnissen planen, CSP-Richtlinien bewerten, eine grundlegende Sicherheitsüberprüfung durchführen oder eine Site vor dem Start härten. Löst Sicherheitsheader, HTTPS, TLS, CSP, Inhaltssicherheitsrichtlinie, HSTS, Geheimnisverwaltung, Schwachstellenscan, Sicherheitsüberprüfung, Härtung, OWASP und Sicherheitsbasis aus. Wird auch ausgelöst, wenn eine Sicherheitsüberprüfung aus Compliance-Gründen oder vor der Produktivsetzung erforderlich ist.
