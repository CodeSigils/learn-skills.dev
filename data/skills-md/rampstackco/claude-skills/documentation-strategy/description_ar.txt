تصميم وتشغيل نظام التوثيق لفريق أو منتج. استخدم هذه المهارة عند التخطيط لما تريد توثيقه، أو اختيار أداة التوثيق، أو تنظيم المستندات الموجودة، أو إصلاح الوثائق القديمة، أو تصميم إيقاع الصيانة، أو تحديد نطاق أعمال الكتابة الفنية. مشغلات التوثيق، والمستندات، والكتابة التقنية، وقاعدة المعرفة، ويكي، ودفتر التشغيل، وREADME، والمستندات الداخلية، وتدقيق المستندات، وصيانة المستندات، والمستندات القديمة، وأين نقوم بالتوثيق. يتم تشغيله أيضًا عندما يجيب الفريق بشكل متكرر على نفس الأسئلة أو عندما يستغرق الإعداد وقتًا طويلاً.
