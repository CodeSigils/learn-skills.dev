Verfassen Sie Landingpage-Texte mit besonderem Augenmerk auf den Helden, das Wertversprechen, den Social Proof, den Umgang mit Einwänden und auf die Konvertierung ausgerichtete CTAs. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Landingpage, eine Verkaufsseite, einen Hero-Bereich oder einen auf die Konvertierung ausgerichteten Webtext schreiben möchte. Auslöser auf Landingpage, Verkaufsseite, Hero-Text, Wertversprechen, Überschrift, Unterüberschrift, Hero-Bereich, CTA-Text, Conversion-Text, Opt-in-Seite, Squeeze-Seite. Wird auch ausgelöst, wenn der Benutzer eine Marketingkampagne oder Produkteinführung durchführt, für die eine spezielle Konvertierungskopie erforderlich ist.
