دليل خطوة بخطوة لإنشاء مهارات Claude Skills الخاصة بك، بدءًا من تحديد ما إذا كانت المهارة هي الأداة الصحيحة وحتى كتابة ملف SKILL.md، وتنظيم المواد المرجعية، وتشغيلها بشكل موثوق. يُستخدم عندما تريد حزم سير عمل أو إطار عمل أو مهمة متكررة في مهارة قابلة لإعادة الاستخدام، أو عندما لا يتم تشغيل مهارة موجودة أو عدم تحميل السياق الصحيح، أو عندما تقوم بمراجعة مهارة ذات أداء ضعيف، أو عندما تريد نشر مهارة للآخرين. يتم تشغيله أيضًا عندما يسأل شخص ما "كيف أصنع مهارة" أو "ما الذي يجعل المهارة جيدة". مفيد للأفراد والفرق وأي شخص ينشر مهاراته بشكل عام.
