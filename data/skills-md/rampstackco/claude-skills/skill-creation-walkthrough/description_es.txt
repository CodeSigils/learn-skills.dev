Guía paso a paso para crear sus propias Claude Skills, desde decidir si una habilidad es la herramienta adecuada hasta escribir el archivo SKILL.md, estructurar el material de referencia y hacer que se active de manera confiable. Úselo cuando desee empaquetar un flujo de trabajo, marco o tarea repetida en una habilidad reutilizable, cuando una habilidad existente no se activa o no carga el contexto correcto, cuando está auditando una habilidad que tiene un rendimiento deficiente o cuando desea publicar una habilidad para otros. También se activa cuando alguien pregunta "cómo creo una habilidad" o "qué hace que una habilidad sea buena". Útil para individuos, equipos y cualquier persona que publique habilidades públicamente.
