Schritt-für-Schritt-Anleitung zum Erstellen Ihrer eigenen Claude-Skills, von der Entscheidung, ob ein Skill das richtige Werkzeug ist, über das Schreiben der SKILL.md-Datei, die Strukturierung des Referenzmaterials bis hin zur zuverlässigen Auslösung. Verwenden Sie diese Option, wenn Sie einen Workflow, ein Framework oder eine wiederholte Aufgabe in einen wiederverwendbaren Skill packen möchten, wenn ein vorhandener Skill nicht auslöst oder nicht den richtigen Kontext lädt, wenn Sie einen Skill prüfen, der leistungsschwach ist, oder wenn Sie einen Skill für andere veröffentlichen möchten. Wird auch ausgelöst, wenn jemand fragt: „Wie erstelle ich eine Fertigkeit?“ oder „Was macht eine gute Fertigkeit aus?“ Nützlich für Einzelpersonen, Teams und alle, die ihre Fähigkeiten öffentlich veröffentlichen.
