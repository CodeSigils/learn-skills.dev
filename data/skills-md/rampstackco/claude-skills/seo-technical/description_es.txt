Utilice esta habilidad siempre que el usuario pregunte sobre SEO técnico, problemas de rastreo, problemas de indexación, mapas de sitio, robots.txt, etiquetas canónicas, marcado de esquema, velocidad de la página, Core Web Vitals, hreflang, redirecciones o rendimiento de búsqueda en todo el sitio. Activadores de SEO técnico, auditoría del sitio, rastreabilidad, indexabilidad, mapa del sitio, robots.txt, canónico, cadena de redireccionamiento, esquema, JSON-LD, Core Web Vitals, velocidad de la página, hreflang, usabilidad móvil, HTTPS, encabezados de seguridad, bloqueo de renderizado, JavaScript SEO. También se activa cuando un sitio tiene problemas de indexación, caídas de tráfico o problemas de migración, incluso si no se dice explícitamente "SEO técnico".
