Exécutez un audit SEO technique complet couvrant l'exploration, l'indexabilité, le rendu, l'architecture du site, les données structurées, l'expérience des pages, la sécurité et l'internationalisation. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur le référencement technique, les problèmes d'exploration, les problèmes d'indexation, les plans de site, les robots.txt, les balises canoniques, le balisage de schéma, la vitesse des pages, les Core Web Vitals, le hreflang, les redirections ou les performances de recherche à l'échelle du site. Déclencheurs sur le référencement technique, l'audit du site, l'exploration, l'indexabilité, le plan du site, robots.txt, canonique, chaîne de redirection, schéma, JSON-LD, Core Web Vitals, vitesse des pages, hreflang, convivialité mobile, HTTPS, en-têtes de sécurité, blocage du rendu, référencement JavaScript. Se déclenche également lorsqu'un site rencontre des problèmes d'indexation, des baisses de trafic ou des problèmes de migration, même si le « référencement technique » n'est pas explicitement mentionné.
