Ejecute el descubrimiento de marcas ascendentes que abarquen la investigación de audiencia, el panorama competitivo, la dinámica de categorías, el espacio problemático y la exploración del territorio de posicionamiento. Utilice esta habilidad desde el comienzo de un proyecto de marca o sitio web cuando el usuario necesite comprender para quién es, con quién compite, qué necesita realmente la audiencia y dónde podría ubicarse la marca de manera plausible. Desencadenantes de descubrimiento de marca, investigación de audiencia, investigación de mercado, escaneo competitivo, investigación de categorías, investigación de clientes, para quién es esto, quiénes somos, investigación de posicionamiento, admisión, inicio. También se activa cuando se solicita un resumen creativo pero los aportes iniciales (audiencia, competidores, espacio problemático) aún no están claros.
