تخطيط وتشغيل مسار الوسائط للصور والفيديو والأصول القابلة للتنزيل. استخدم هذه المهارة عند تصميم تخزين الصور وتسليمها، أو اختيار التنسيقات (WebP، أو AVIF)، أو إعداد صور سريعة الاستجابة، أو اختيار مضيف فيديو، أو تنظيم مكتبة أصول العلامة التجارية، أو تدقيق مسار الصور البطيء. المشغلات على خط أنابيب الصور، مكتبة الأصول، DAM، تحسين الصورة، WebP، AVIF، الصور المستجيبة، استضافة الفيديو، CDN للصور، سير عمل الأصول، إدارة الوسائط. يتم تشغيله أيضًا عندما تكون الصور بطيئة أو معطلة أو متناثرة عبر الأنظمة.
