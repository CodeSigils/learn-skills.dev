Examinez le code de l'application Web pour détecter les bogues, les problèmes de sécurité, les problèmes de performances et les anti-modèles spécifiques à la pile. Utilisez cette compétence chaque fois que l'utilisateur souhaite réviser le code, déboguer un problème de production, enquêter sur un échec de build, auditer la sécurité ou vérifier un PR avant la fusion. Déclencheurs lors de la révision du code, révision de mon code, débogage, erreur de construction, cassé, ne fonctionne pas, pourquoi X échoue-t-il, vérifiez ce code, contrôle de sécurité, examen des relations publiques, code d'audit, refactorisation. Se déclenche également lors de l'enquête sur les erreurs 4xx ou 5xx, les échecs de déploiement, les problèmes de variables d'environnement et les problèmes d'intégration du CMS.
