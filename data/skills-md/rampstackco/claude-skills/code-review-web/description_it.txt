Esamina il codice dell'applicazione Web per rilevare bug, problemi di sicurezza, problemi di prestazioni e anti-pattern specifici dello stack. Utilizza questa competenza ogni volta che l'utente desidera rivedere il codice, eseguire il debug di un problema di produzione, indagare su un errore di compilazione, verificare la sicurezza o controllare un PR prima della fusione. Si attiva durante la revisione del codice, rivedi il mio codice, esegui il debug, errore di creazione, rotto, non funziona, perché X non funziona, controlla questo codice, controllo di sicurezza, revisione PR, codice di controllo, refactoring. Si attiva anche durante l'analisi di errori 4xx o 5xx, errori di distribuzione, problemi relativi alle variabili di ambiente e problemi di integrazione CMS.
