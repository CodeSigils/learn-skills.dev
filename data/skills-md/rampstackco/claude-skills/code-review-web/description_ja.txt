Web アプリケーション コードをレビューして、バグ、セキュリティ上の問題、パフォーマンス上の問題、スタック固有のアンチパターンを確認します。ユーザーがコードのレビュー、運用上の問題のデバッグ、ビルドの失敗の調査、セキュリティの監査、またはマージ前の PR のチェックを行う場合には、このスキルを使用します。コード レビューのトリガー、コードのレビュー、デバッグ、ビルド エラー、壊れている、動作していない、X が失敗する理由、このコードを確認する、セキュリティ チェック、PR レビュー、コードの監査、リファクタリング。 4xx または 5xx エラー、展開の失敗、環境変数の問題、CMS 統合の問題を調査するときにもトリガーされます。
