Revise el código de la aplicación web en busca de errores, problemas de seguridad, problemas de rendimiento y antipatrones específicos de la pila. Utilice esta habilidad siempre que el usuario quiera revisar el código, depurar un problema de producción, investigar una falla de compilación, auditar la seguridad o verificar un PR antes de fusionar. Activadores de revisión de código, revisar mi código, depurar, error de compilación, roto, no funciona, por qué falla X, verificar este código, verificación de seguridad, revisión de relaciones públicas, código de auditoría, refactorización. También se activa al investigar errores 4xx o 5xx, fallas de implementación, problemas de variables de entorno y problemas de integración de CMS.
