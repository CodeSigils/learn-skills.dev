Wenden Sie Designstandards in Produktionsqualität an, wenn Sie Seiten, Komponenten oder Benutzeroberflächen erstellen oder überprüfen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Seite erstellen, eine Komponente entwerfen, einen Abschnitt gestalten, die Benutzeroberfläche überprüfen, das Layout korrigieren oder die Designqualität überprüfen möchte. Auslöser beim Erstellen einer Seite, Erstellen einer Komponente, Entwerfen eines Abschnitts, Held, Karte, CTA, Layout, Überprüfen der Benutzeroberfläche, Korrigieren des Designs, Designsystem, Design-Tokens, Abstand, Typografieskalierung, Schaltflächenstandards, mobiles Design. Auch Auslöser für jede Produktionsdesign-Entscheidung, bei der es auf Kontrast, Zugänglichkeit, Abstände oder visuelle Hierarchie ankommt.
