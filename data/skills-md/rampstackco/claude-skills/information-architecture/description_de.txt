Entwerfen Sie die Struktur einer Website oder eines Produkts, einschließlich Sitemap, Navigation, URL-Struktur, Inhaltstypen, Taxonomie und Beschriftung. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Sitemap planen, eine Navigation entwerfen, URLs strukturieren, Inhaltstypen definieren, Taxonomien erstellen, eine Website-Suche entwerfen oder Inhalte auf Systemebene organisieren möchte. Auslöser für Sitemap, Site-Struktur, Navigation, IA, Informationsarchitektur, URL-Struktur, Inhaltstypen, Taxonomie, Kategorisierung, Breadcrumbs, Hub-Seiten, Facettennavigation, Site-Suche, Beschriftung. Wird auch ausgelöst, wenn Inhalte ohne Strukturplan erstellt werden oder wenn die Struktur einer vorhandenen Site überprüft oder umstrukturiert wird.
