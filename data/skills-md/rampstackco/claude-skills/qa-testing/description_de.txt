Führen Sie QA-Tests für eine Seite, ein Feature oder eine vollständige Site auf einer von drei Tiefenstufen durch (Smoke, Standard, Full). Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Seite testen, eine Website prüfen, auf Fehler prüfen, eine Bereitstellung überprüfen, eine Qualitätssicherung durchführen oder die Zugänglichkeit, Leistung oder SEO-Grundlagen überprüfen möchte. Auslöser für Test, QA, Audit, Überprüfung, Prüfung, funktioniert es, sieht es richtig aus, defekt, 404, Image wird nicht geladen, Überprüfung nach der Bereitstellung, Regressionstest. Wird auch proaktiv nach jeder wesentlichen Codeänderung oder dem Start einer neuen Seite ausgelöst, bei der es auf die Überprüfung ankommt.
