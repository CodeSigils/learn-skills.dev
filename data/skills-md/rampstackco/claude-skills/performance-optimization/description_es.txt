Diagnostique y solucione problemas de rendimiento web, incluidos Core Web Vitals (LCP, INP, CLS), tamaño del paquete, optimización de activos, rendimiento de procesamiento y eficiencia del tiempo de ejecución. Utilice esta habilidad siempre que el usuario desee mejorar la velocidad de la página, corregir Core Web Vitals, optimizar activos, reducir el tamaño del paquete, depurar renderizaciones lentas o mejorar sistemáticamente el rendimiento de un sitio. Activadores de rendimiento, velocidad de la página, Core Web Vitals, LCP, INP, CLS, FID, TTFB, tamaño del paquete, división de código, optimización de imágenes, carga diferida, bloqueo de renderizado, página lenta, auditoría de rendimiento, puntuación Lighthouse. También se activa cuando el tráfico o la conversión disminuyen debido a la lentitud percibida.
