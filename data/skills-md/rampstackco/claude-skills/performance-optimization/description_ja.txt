Core Web Vitals (LCP、INP、CLS)、バンドル サイズ、アセットの最適化、レンダリング パフォーマンス、ランタイム効率などの Web パフォーマンスの問題を診断して修正します。ユーザーがページ速度の向上、Core Web Vitals の修正、アセットの最適化、バンドル サイズの削減、遅いレンダリングのデバッグ、またはサイトのパフォーマンスの体系的な向上を希望する場合は常にこのスキルを使用します。パフォーマンス、ページ速度、Core Web Vitals、LCP、INP、CLS、FID、TTFB、バンドル サイズ、コード分割、画像の最適化、遅延読み込み、レンダリング ブロック、遅いページ、パフォーマンス監査、Lighthouse スコアに基づいてトリガーされます。また、速度が遅いと感じられるためにトラフィックやコンバージョンが低下している場合にもトリガーされます。
