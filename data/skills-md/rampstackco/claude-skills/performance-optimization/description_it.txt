Diagnostica e risolvi i problemi di prestazioni web, inclusi Core Web Vitals (LCP, INP, CLS), dimensioni del bundle, ottimizzazione delle risorse, prestazioni di rendering ed efficienza di runtime. Utilizza questa competenza ogni volta che l'utente desidera migliorare la velocità della pagina, correggere i Core Web Vitals, ottimizzare le risorse, ridurre le dimensioni del bundle, eseguire il debug di rendering lenti o migliorare sistematicamente le prestazioni di un sito. Trigger su prestazioni, velocità della pagina, Core Web Vitals, LCP, INP, CLS, FID, TTFB, dimensioni del bundle, suddivisione del codice, ottimizzazione delle immagini, caricamento lento, blocco del rendering, pagina lenta, controllo delle prestazioni, punteggio Lighthouse. Si attiva anche quando il traffico o la conversione diminuiscono a causa della lentezza percepita.
