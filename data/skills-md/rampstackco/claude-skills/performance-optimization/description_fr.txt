Diagnostiquez et résolvez les problèmes de performances Web, notamment Core Web Vitals (LCP, INP, CLS), la taille du bundle, l'optimisation des actifs, les performances de rendu et l'efficacité d'exécution. Utilisez cette compétence chaque fois que l'utilisateur souhaite améliorer la vitesse des pages, corriger les Core Web Vitals, optimiser les ressources, réduire la taille du bundle, déboguer les rendus lents ou améliorer systématiquement les performances d'un site. Déclencheurs sur les performances, la vitesse de la page, Core Web Vitals, LCP, INP, CLS, FID, TTFB, taille du bundle, fractionnement de code, optimisation d'image, chargement paresseux, blocage de rendu, page lente, audit de performance, score Lighthouse. Se déclenche également lorsque le trafic ou la conversion diminue en raison d'une lenteur perçue.
