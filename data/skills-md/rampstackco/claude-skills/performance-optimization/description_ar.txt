تشخيص وإصلاح مشكلات أداء الويب بما في ذلك Core Web Vitals (LCP وINP وCLS) وحجم الحزمة وتحسين الأصول وأداء العرض وكفاءة وقت التشغيل. استخدم هذه المهارة عندما يريد المستخدم تحسين سرعة الصفحة، أو إصلاح مؤشرات الويب الأساسية، أو تحسين الأصول، أو تقليل حجم الحزمة، أو تصحيح أخطاء العرض البطيء، أو تحسين أداء الموقع بشكل منهجي. المشغلات المتعلقة بالأداء، وسرعة الصفحة، ومؤشرات أداء الويب الأساسية، وLCP، وINP، وCLS، وFID، وTTFB، وحجم الحزمة، وتقسيم التعليمات البرمجية، وتحسين الصورة، والتحميل البطيء، وحظر العرض، والصفحة البطيئة، وتدقيق الأداء، ونقاط Lighthouse. يتم تشغيله أيضًا عندما تنخفض حركة المرور أو التحويل بسبب البطء الملحوظ.
