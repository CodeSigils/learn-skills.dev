専用の実験プラットフォームを経由するのではなく、データ ウェアハウスから実験を実行します。 SQL ベースの割り当て、エクスポージャ ロギング規律、dbt モデルでのメトリクス定義、SQL または Python での統計分析、CUPED による分散削減、逐次テスト、および Statsig や Optimizely などのプラットフォームとの運用上のトレードオフ。ウェアハウス ネイティブの実験のトリガー、BigQuery での実験の実行、Snowflake での実験の実行、dbt 実験、SQL t 検定、CUPED 分散削減、エクスポージャー ログ、サンプル比率の不一致、逐次テスト、mSPRT、二重ロバスト推定、構築と購入の実験のトリガー。また、チームがプラットフォームとウェアハウスのどちらを選択するか、ウェアハウスネイティブの実験インフラストラクチャを構築するか、インフラストラクチャを監査するか、プラットフォームが処理できないカスタムメトリックを使用して実験を実行するときにもトリガーされます。
