إجراء التجارب خارج مستودع البيانات بدلاً من منصات التجارب المخصصة. المهمة المستندة إلى SQL ونظام تسجيل التعرض والتعريفات المترية في نماذج dbt والتحليل الإحصائي في SQL أو Python وتقليل التباين باستخدام CUPED والاختبار المتسلسل والمفاضلات التشغيلية مقابل الأنظمة الأساسية مثل Statsig وOptimizely. تشغيل التجارب في المستودعات الأصلية، وإجراء التجارب في BigQuery، وإجراء التجارب في Snowflake، وتجارب dbt، واختبار SQL t، وتقليل تباين CUPED، وسجل التعرض، وعدم تطابق نسبة العينات، والاختبار المتسلسل، وmSPRT، والتقدير القوي المضاعف، وتجربة البناء مقابل الشراء. يتم تشغيله أيضًا عندما يختار الفريق بين النظام الأساسي والمستودع، أو إنشاء بنية تحتية للتجربة الأصلية للمستودع، أو تدقيق إحداهما، أو تشغيل تجربة باستخدام مقياس مخصص لا يمكن للنظام الأساسي التعامل معه.
