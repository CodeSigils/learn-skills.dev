قم بكتابة أو تحرير نسخة موقع الويب ومحتوى المدونة والمقالات التحريرية مع الاهتمام بالصوت والبنية والهدف. استخدم هذه المهارة عندما يريد المستخدم كتابة مقال، أو صياغة نسخة موقع ويب، أو تحرير المحتوى الحالي من أجل الوضوح أو الصوت، أو كتابة منشور مدونة، أو إنتاج محتوى تحريري عام. المشغلات عند كتابة منشور مدونة، أو صياغة مقال، أو كتابة نسخة لـ، أو تحرير هذا، أو إعادة كتابة هذا، أو كتابة محتوى، أو كتابة دليل، أو صياغة طريقة إرشادية، أو كتابة نسخة ويب. يتم تشغيله أيضًا عندما يتم تحديد المحتوى ويحتاج الآن إلى كتابته، أو عندما يحتاج المحتوى الموجود إلى تعديلات صوتية أو واضحة.
