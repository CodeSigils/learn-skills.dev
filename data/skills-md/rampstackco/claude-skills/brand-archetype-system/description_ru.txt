Примените заранее составленные эстетические архетипы по умолчанию, чтобы начать работу по дизайну бренда, включающую цвет, типографику, макет, голос и направление изображения. Используйте этот навык всякий раз, когда пользователю нужна отправная точка для визуального и словесного направления бренда, он ссылается на бренд, который он хочет спроектировать рядом (например, «что-то вроде Stripe» или «редакционное издание вроде Linear»), ему необходимо быстрее сблизиться со многих направлений к одному или ему нужны заведомо хорошие значения по умолчанию для конкретной отраслевой вертикали. Триггеры по архетипу, архетипу дизайна, архетипу бренда, близкому к (бренду), стилю, схожей эстетике, отправной точке дизайна, шаблону бренда, типичному по вертикали, типичному для отрасли. Также срабатывает, когда у пользователя есть задание и он хочет сопоставить его с известным эстетическим семейством, а не проектировать на основе основных принципов.
