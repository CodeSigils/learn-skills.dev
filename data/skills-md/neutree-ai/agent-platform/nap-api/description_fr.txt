Gérez les espaces de travail NAP, les invites, les modèles, les informations d'identification, les jetons de service, les fichiers d'agent, les fournisseurs, les balises, les partages et les planifications via REST. Déclenchez lorsque l'utilisateur souhaite créer un script ou automatiser NAP en dehors de l'interface utilisateur, par exemple. "créer un espace de travail", "faire pivoter un jeton", "invites de téléchargement groupé", "répertorier les fichiers d'agent dans l'espace de travail X", intégration CI avec NAP.
