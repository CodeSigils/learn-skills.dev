Управляйте рабочими пространствами NAP, приглашениями, шаблонами, учетными данными, токенами служб, файлами агентов, поставщиками, тегами, общими ресурсами и расписаниями через REST. Запускается, когда пользователь хочет создать сценарий или автоматизировать NAP вне пользовательского интерфейса — например. «создать рабочую область», «повернуть токен», «запросы на массовую загрузку», «составить список файлов агента в рабочей области X», интеграция CI с NAP.
