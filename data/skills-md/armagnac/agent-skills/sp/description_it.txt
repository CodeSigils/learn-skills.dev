Alias ​​di scelta rapida per /superplan. Produci codice di qualità superiore suddividendo una funzionalità in attività piccole e mirate che l'agente di codifica può eseguire una alla volta. Funziona come un team di ingegneri: funzionalità → traguardi → attività di circa 30 minuti con file specifici, criteri di accettazione e dipendenze. Ogni attività viene eseguita in un contesto nuovo: ambito ristretto, massima attenzione, un commit git per attività.
