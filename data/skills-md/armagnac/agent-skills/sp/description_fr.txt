Alias ​​de raccourci pour /superplan. Produisez un code de meilleure qualité en divisant une fonctionnalité en petites tâches ciblées que l'agent de codage peut réaliser une par une. Fonctionne comme une équipe d'ingénierie : fonctionnalité → jalons → tâches d'environ 30 minutes avec des fichiers spécifiques, des critères d'acceptation et des dépendances. Chaque tâche s'exécute dans un nouveau contexte : portée étroite, attention totale, un commit git par tâche.
