Псевдоним ярлыка для /superplan. Создавайте более качественный код, разбивая функцию на небольшие целенаправленные задачи, которые агент кодирования может выполнять по одной за раз. Работает как команда инженеров: функция → этапы → ~30-минутные задачи с конкретными файлами, критериями приемки и зависимостями. Каждая задача выполняется в новом контексте — узкая область действия, полное внимание, один git-коммит на каждую задачу.
