Erstellen Sie qualitativ hochwertigeren Code, indem Sie eine Funktion in kleine, gezielte Aufgaben aufteilen, die der Codierungsagent einzeln erledigen kann. Funktioniert wie ein Engineering-Team: Feature → Meilensteine ​​(Produktergebnisse) → ca. 30-minütige Aufgaben mit spezifischen Dateien, Akzeptanzkriterien und Abhängigkeiten. Jede Aufgabe wird in einem neuen Kontext ausgeführt – enger Umfang, volle Aufmerksamkeit, ein Git-Commit pro Aufgabe. Verwenden Sie diese Funktion, wenn Sie eine nicht triviale Funktion oder eine komplexe Umgestaltung starten oder wenn Sie möchten, dass sich der Agent jeweils auf eine kleine Sache konzentriert, anstatt eine ganze Funktion in einer Sitzung zu jonglieren. Unterstützt /loop für autonome Ausführung.
