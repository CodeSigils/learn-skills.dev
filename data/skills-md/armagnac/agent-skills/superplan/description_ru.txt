Создавайте более качественный код, разбивая функцию на небольшие целенаправленные задачи, которые агент кодирования может выполнять по одной за раз. Работает как команда инженеров: функция → этапы (результаты продукта) → ~30-минутные задачи с конкретными файлами, критериями приемки и зависимостями. Каждая задача выполняется в новом контексте — узкая область действия, полное внимание, один git-коммит на каждую задачу. Используйте при запуске любой нетривиальной функции, сложном рефакторинге или когда вы хотите, чтобы агент сосредоточился на одной маленькой задаче за раз, а не манипулировал всей функцией за один сеанс. Поддерживает /loop для автономного выполнения.
