Daemon-AI プラットフォーム API を使用して構築するための完全なリファレンスです。これは、OpenRouter、ブロックチェーン インテリジェンス ツール (MCP)、Web 検索を介して 300 以上の LLM へのアクセスを提供する AI エージェント バックエンドであり、Solana での USDC 支払いによるリアルタイムの財務データも提供します。
ユーザーが必要なときにこのスキルを使用します: Daemon-AI API との統合、Daemon-AI を使用した AI エージェントの構築、電子メールまたは Solana ウォレットを介したユーザーの認証、チャット完了エンドポイントの呼び出し、MCP ツール (daemon-intel、exa、arkham) の操作、ファイナンスの使用またはエンドポイントの検出、API キーの管理、またはプラットフォームのエージェント ループ パターンの理解。
また、ユーザーが daemonai.io、daemon_<key> API キーについて言及した場合、または開発者または AI エージェントとして Daemon-AI プラットフォームの機能を使用する方法を尋ねた場合にも、このスキルをトリガーします。
