使用 Daemon-AI 平台 API 進行構建的完整參考 — 一個 AI 代理後端，可透過 OpenRouter、區塊鏈智慧工具 (MCP)、網路搜尋和 Solana 上的 USDC 付款來存取 300 多個 LLM。
每當使用者想要執行以下操作時，就可以使用此技能：與 Daemon-AI API 整合、使用 Daemon-AI 建立 AI 代理、透過電子郵件或 Solana 錢包對使用者進行身份驗證、呼叫聊天完成端點、使用 MCP 工具（daemon-intel、exa、arkham）、消費財務或發現端點、管理 API 金鑰或了解平台的代理循環模式。
當使用者提及 daemonai.io、daemon_<key> API 金鑰，或詢問如何作為開發人員或 AI 代理使用 Daemon-AI 平台的任何功能時，也會觸發此技能。
