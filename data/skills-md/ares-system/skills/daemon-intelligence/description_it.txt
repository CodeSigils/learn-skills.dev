Riferimento completo per la creazione con l'API della piattaforma Daemon-AI: un backend dell'agente AI che fornisce accesso a oltre 300 LLM tramite OpenRouter, strumenti di blockchain intelligence (MCP), ricerca web e dati finanziari in tempo reale con pagamenti USDC su Solana.
Utilizza questa competenza ogni volta che l'utente desidera: integrarsi con l'API Daemon-AI, creare un agente AI utilizzando Daemon-AI, autenticare gli utenti tramite e-mail o portafoglio Solana, chiamare l'endpoint di completamento della chat, lavorare con strumenti MCP (daemon-intel, exa, arkham), utilizzare i finanziamenti o scoprire endpoint, gestire le chiavi API o comprendere il modello di loop degli agenti della piattaforma.
Attiva questa abilità anche quando l'utente menziona daemonai.io, chiavi API daemon_<key> o chiede come utilizzare qualsiasi funzionalità della piattaforma Daemon-AI come sviluppatore o come agente AI.
