Référence complète pour la construction avec l'API de la plateforme Daemon-AI — un backend d'agent IA qui donne accès à plus de 300 LLM via OpenRouter, des outils d'intelligence blockchain (MCP), une recherche sur le Web et des données financières en temps réel avec des paiements USDC sur Solana.
Utilisez cette compétence chaque fois que l'utilisateur souhaite : intégrer l'API Daemon-AI, créer un agent IA à l'aide de Daemon-AI, authentifier les utilisateurs par e-mail ou par portefeuille Solana, appeler le point de terminaison de discussion, travailler avec les outils MCP (daemon-intel, exa, arkham), consommer les finances ou découvrir les points de terminaison, gérer les clés API ou comprendre le modèle de boucle agent de la plate-forme.
Déclenchez également cette compétence lorsque l'utilisateur mentionne daemonai.io, les clés API daemon_<key> ou demande comment utiliser n'importe quelle fonctionnalité de la plateforme Daemon-AI en tant que développeur ou en tant qu'agent IA.
