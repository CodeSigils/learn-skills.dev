Referencia completa para construir con la API de la plataforma Daemon-AI: un backend de agente de IA que brinda acceso a más de 300 LLM a través de OpenRouter, herramientas de inteligencia blockchain (MCP), búsqueda web y datos financieros en tiempo real con pagos en USDC en Solana.
Utilice esta habilidad siempre que el usuario quiera: integrarse con la API de Daemon-AI, crear un agente de IA usando Daemon-AI, autenticar usuarios por correo electrónico o billetera Solana, llamar al punto final de finalización del chat, trabajar con herramientas MCP (daemon-intel, exa, arkham), consumir las finanzas o descubrir puntos finales, administrar claves API o comprender el patrón de bucle agente de la plataforma.
También active esta habilidad cuando el usuario mencione daemonai.io, claves API daemon_<key> o pregunte cómo usar cualquier función de la plataforma Daemon-AI como desarrollador o agente de IA.
