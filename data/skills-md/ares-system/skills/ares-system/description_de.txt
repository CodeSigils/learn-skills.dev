Verwenden Sie diese Fähigkeit, wann immer der Benutzer: Sicherheitsscans für Smart Contracts durchführen, KI-gestützte Schwachstellenanalysen durchführen, Pentest-Automatisierungen ausführen, Rust/Solana-Code analysieren, Solana-Programme unscharf machen, LLM-Sicherheit testen, Systemeingabeaufforderungen extrahieren, MCP-Tools prüfen oder mehrere Sicherheitstools über das Multiagentensystem orchestrieren möchte. Wird auch ausgelöst, wenn der Benutzer ARES, aressystem.dev, Security Audit Workflow oder eines der 8 Sicherheitstools erwähnt.
