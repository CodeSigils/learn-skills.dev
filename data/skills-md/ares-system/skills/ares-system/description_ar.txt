مرجع كامل للعمل مع منصة ARES (Advanced Rust & Ethereum Security) - منصة اختبار أمان مدعومة بالذكاء الاصطناعي مع 8 أدوات متكاملة: Trident (Solana fuzzing)، Semgrep (تحليل ثابت)، Checked Math (اكتشاف تجاوز الصدأ)، FuzzyAI (LLM fuzzing)، Whistleblower (استخراج فوري)، MCP حقن (اختبار أمان MCP)، نظام متعدد العوامل (تنسيق AI)، وHexStrike AI (أتمتة penest).
استخدم هذه المهارة عندما يريد المستخدم: إجراء عمليات فحص الأمان على العقود الذكية، أو إجراء تحليل الثغرات الأمنية المدعومة بالذكاء الاصطناعي، أو تنفيذ أتمتة الاختبار، أو تحليل كود Rust/Solana، أو برامج Fuzz Solana، أو اختبار أمان LLM، أو استخراج مطالبات النظام، أو تدقيق أدوات MCP، أو تنسيق أدوات أمان متعددة عبر نظام متعدد الوكلاء. يتم تشغيله أيضًا عندما يذكر المستخدم ARES، أو aressystem.dev، أو سير عمل التدقيق الأمني، أو أي من أدوات الأمان الثمانية.
