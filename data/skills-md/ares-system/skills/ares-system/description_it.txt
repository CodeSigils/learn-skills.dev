Riferimento completo per lavorare con la piattaforma ARES (Advanced Rust & Ethereum Security): una piattaforma di test di sicurezza basata sull'intelligenza artificiale con 8 strumenti integrati: Trident (Solana fuzzing), Semgrep (analisi statica), Checked Math (rilevamento di overflow di Rust), FuzzyAI (fuzzing LLM), Whistleblower (estrazione rapida), MCP Injection (test di sicurezza MCP), Multi-Agent System (orchestrazione AI) e HexStrike AI (pentest automazione).
Utilizza questa competenza ogni volta che l'utente desidera: eseguire scansioni di sicurezza su contratti intelligenti, eseguire analisi di vulnerabilità basate sull'intelligenza artificiale, eseguire automazione pentest, analizzare codice Rust/Solana, fuzz programmi Solana, testare la sicurezza LLM, estrarre prompt di sistema, controllare strumenti MCP o orchestrare più strumenti di sicurezza tramite il sistema multi-agente. Si attiva anche quando l'utente menziona ARES, aressystem.dev, il flusso di lavoro di controllo della sicurezza o uno qualsiasi degli 8 strumenti di sicurezza.
