Référence complète pour travailler avec la plateforme ARES (Advanced Rust & Ethereum Security) — une plateforme de test de sécurité basée sur l'IA avec 8 outils intégrés : Trident (fuzzing Solana), Semgrep (analyse statique), Checked Math (détection de débordement de rouille), FuzzyAI (fuzzing LLM), Whistleblower (extraction rapide), MCP Injection (tests de sécurité MCP), système multi-agents (orchestration IA) et HexStrike AI (automatisation pentest).
Utilisez cette compétence chaque fois que l'utilisateur souhaite : exécuter des analyses de sécurité sur des contrats intelligents, effectuer une analyse de vulnérabilité basée sur l'IA, exécuter l'automatisation de pentest, analyser le code Rust/Solana, fuzzer les programmes Solana, tester la sécurité LLM, extraire les invites du système, auditer les outils MCP ou orchestrer plusieurs outils de sécurité via le système multi-agent. Déclenchez également lorsque l'utilisateur mentionne ARES, aressystem.dev, le workflow d'audit de sécurité ou l'un des 8 outils de sécurité.
