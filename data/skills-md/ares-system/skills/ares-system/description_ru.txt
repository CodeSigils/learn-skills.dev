Полный справочник по работе с платформой ARES (Advanced Rust & Ethereum Security) — платформой для тестирования безопасности на базе искусственного интеллекта с 8 интегрированными инструментами: Trident (фаззинг Solana), Semgrep (статический анализ), Checked Math (обнаружение переполнения Rust), FuzzyAI (фаззинг LLM), Whistleblower (быстрое извлечение), MCP Injection (тестирование безопасности MCP), многоагентная система (оркестровка AI) и HexStrike AI (автоматизация пентеста).
Используйте этот навык всякий раз, когда пользователь хочет: запускать сканирование безопасности смарт-контрактов, выполнять анализ уязвимостей с помощью искусственного интеллекта, выполнять автоматизацию пентестов, анализировать код Rust/Solana, анализировать программы Solana, тестировать безопасность LLM, извлекать системные подсказки, проверять инструменты MCP или управлять несколькими инструментами безопасности через многоагентную систему. Также срабатывает, когда пользователь упоминает ARES, aressystem.dev, рабочий процесс аудита безопасности или любой из 8 инструментов безопасности.
