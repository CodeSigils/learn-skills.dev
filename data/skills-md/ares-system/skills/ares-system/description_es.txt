Referencia completa para trabajar con la plataforma ARES (Advanced Rust & Ethereum Security), una plataforma de pruebas de seguridad impulsada por IA con 8 herramientas integradas: Trident (solana fuzzing), Semgrep (análisis estático), Checked Math (detección de desbordamiento de Rust), FuzzyAI (LLM fuzzing), Whistleblower (extracción rápida), MCP injection (pruebas de seguridad de MCP), sistema multiagente (orquestación de IA) y HexStrike AI (automatización de pentest).
Utilice esta habilidad siempre que el usuario desee: ejecutar análisis de seguridad en contratos inteligentes, realizar análisis de vulnerabilidad impulsados ​​por IA, ejecutar automatización de pentest, analizar código Rust/Solana, modificar programas Solana, probar la seguridad LLM, extraer indicaciones del sistema, auditar herramientas MCP u orquestar múltiples herramientas de seguridad a través del sistema multiagente. También se activa cuando el usuario menciona ARES, aressystem.dev, flujo de trabajo de auditoría de seguridad o cualquiera de las 8 herramientas de seguridad.
