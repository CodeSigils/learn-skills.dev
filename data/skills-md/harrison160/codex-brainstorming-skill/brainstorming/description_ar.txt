استكشاف الأفكار وتحسينها قبل التنفيذ. يُستخدم عندما يريد المستخدم إنشاء أو إنشاء أو إضافة أو إعادة تصميم أو تغيير منتج أو ميزة أو مشروع أو سير عمل أو سلوك ويجب توضيح القصد أو المتطلبات أو التصميم أولاً، أو عندما يطلب المستخدم صراحةً تبادل الأفكار. افحص السياق الحالي، واطرح سؤالاً واحدًا في كل مرة، وقارن بين الأساليب، وقدم تصميمًا، واطلب موافقة صريحة من المستخدم قبل التنفيذ.
