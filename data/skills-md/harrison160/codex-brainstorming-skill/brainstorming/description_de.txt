Erkunden und verfeinern Sie Ideen vor der Umsetzung. Verwenden Sie diese Option, wenn der Benutzer ein Produkt, eine Funktion, ein Projekt, einen Arbeitsablauf oder ein Verhalten erstellen, erstellen, hinzufügen, neu gestalten oder ändern möchte und die Absicht, Anforderungen oder das Design zuerst geklärt werden sollten, oder wenn der Benutzer ausdrücklich um ein Brainstorming bittet. Untersuchen Sie den aktuellen Kontext, stellen Sie jeweils eine Frage, vergleichen Sie Ansätze, präsentieren Sie einen Entwurf und fordern Sie vor der Implementierung eine ausdrückliche Zustimmung des Benutzers ein.
