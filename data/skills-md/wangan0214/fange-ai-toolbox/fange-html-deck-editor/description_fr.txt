Éditeur visuel local de diapositives HTML (deck) : modifiez le texte directement dans le navigateur et enregistrez-le sur le disque + rendu Playwright en une seule session + restauration de l'instantané historique + exportation PPT modifiable à trois couches + téléchargement en un clic vers l'espace cloud Feishu. Convient à n'importe quel HTML de style deck (diapositives multipages où chaque page est enveloppée par `<section class="slide">`). Il s'agit d'un maillon de la chaîne de livraison : « guizang‑ppt‑skill (générer du HTML) → cet outil (affiner le texte) → exporter PPTX / télécharger vers Feishu », se connectant au chemin de livraison Feishu des feishu‑html‑slides.
