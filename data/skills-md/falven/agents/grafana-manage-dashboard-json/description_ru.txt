Работайте напрямую с JSON панели мониторинга Grafana и рабочими процессами «панели как код». Используйте при редактировании экспортированной информационной панели JSON, подготовке информационных панелей, подготовке полезных данных HTTP API, управлении полями схемы или версии или создании безопасных шаблонных информационных панелей из существующих структур Grafana.
