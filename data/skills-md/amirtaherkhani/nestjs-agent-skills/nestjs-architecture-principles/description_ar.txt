تصميم ومراجعة بنية تطبيق NestJS باستخدام وحدات ميزات متماسكة، ووحدات متراصة معيارية، وحدود ذات طبقات أو سداسية، وانعكاس التبعية، ومبادئ هندسية عملية. يُستخدم عند التخطيط لمشروع NestJS، أو تغيير حدود الوحدة النمطية، أو تقييم البنية النظيفة أو DDD، أو حل التبعيات الدائرية، أو تحديد المنافذ والمحولات، أو مراجعة الاقتران، أو تحديد ما إذا كان CQRS أو الخدمات الصغيرة مبررة. لا تستخدمه في أعمال الواجهة الأمامية الخالصة أو الواجهات الخلفية غير التابعة لـ NestJS. عندما تنطبق مهارات أخرى أيضا، التوفيق بين الملكية قبل الطفرة.
