Bereitet absichtliche Git-Änderungen für NestJS-Projekte vor und veröffentlicht sie. Verwenden Sie diese Option, wenn der Benutzer einen Commit, Push, eine Pull-Anfrage erstellen oder aktualisieren, ein Änderungsprotokoll oder einen Release-Text vorbereiten oder eine GitHub Pages-Bereitstellung nach der Veröffentlichung überprüfen möchte. Es prüft den gesamten Diff, bewahrt nicht verwandte Arbeiten auf, scannt bereitgestellte Inhalte auf Geheimnisse, gleicht Repository-Commit-Konventionen ab, führt relevante Prüfungen durch und führt nur die explizit angeforderten Remote-Aktionen aus. Wenn auch andere Fähigkeiten zutreffen, stimmen Sie die Eigentumsverhältnisse vor der Mutation ab.
