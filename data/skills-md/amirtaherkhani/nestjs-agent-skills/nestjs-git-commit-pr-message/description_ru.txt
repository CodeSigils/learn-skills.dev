Готовит и публикует намеренные изменения Git для проектов NestJS. Используйте, когда пользователь просит зафиксировать, отправить, создать или обновить запрос на включение, подготовить журнал изменений или текст выпуска или проверить развертывание GitHub Pages после публикации. Он проверяет все различия, сохраняет несвязанную работу, сканирует подготовленный контент на наличие секретов, соблюдает соглашения о фиксации репозитория, выполняет соответствующие проверки и выполняет только явно запрошенные удаленные действия. Если применимы и другие навыки, согласуйте владение до мутации.
