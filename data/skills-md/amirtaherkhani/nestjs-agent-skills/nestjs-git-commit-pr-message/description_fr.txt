Prépare et publie les modifications Git intentionnelles pour les projets NestJS. À utiliser lorsque l'utilisateur demande de valider, pousser, créer ou mettre à jour une demande d'extraction, de préparer un journal des modifications ou de publier un texte, ou de vérifier un déploiement de pages GitHub après la publication. Il inspecte la différence complète, préserve les travaux non liés, analyse le contenu intermédiaire à la recherche de secrets, correspond aux conventions de validation du référentiel, exécute les vérifications pertinentes et exécute uniquement les actions à distance explicitement demandées. Lorsque d’autres compétences s’appliquent également, conciliez la propriété avant la mutation.
