Prepara y publica cambios intencionales de Git para proyectos NestJS. Úselo cuando el usuario solicite confirmar, enviar, crear o actualizar una solicitud de extracción, preparar un registro de cambios o publicar un texto, o verificar una implementación de GitHub Pages después de la publicación. Inspecciona la diferenciación completa, preserva el trabajo no relacionado, escanea el contenido preparado en busca de secretos, coincide con las convenciones de confirmación del repositorio, ejecuta comprobaciones relevantes y realiza solo las acciones remotas solicitadas explícitamente. Cuando también se apliquen otras habilidades, concilie la propiedad antes de la mutación.
