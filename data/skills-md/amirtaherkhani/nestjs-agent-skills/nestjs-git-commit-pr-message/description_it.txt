Prepara e pubblica modifiche Git intenzionali per i progetti NestJS. Da utilizzare quando l'utente chiede di confermare, inviare, creare o aggiornare una richiesta pull, preparare il registro delle modifiche o rilasciare testo o verificare una distribuzione di GitHub Pages dopo la pubblicazione. Ispeziona il differenziale completo, preserva il lavoro non correlato, analizza i segreti del contenuto organizzato, rispetta le convenzioni di commit del repository, esegue controlli pertinenti ed esegue solo le azioni remote esplicitamente richieste. Quando si applicano anche altre abilità, riconcilia la proprietà prima della mutazione.
