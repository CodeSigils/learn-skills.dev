يقوم بإعداد ونشر تغييرات Git المتعمدة لمشاريع NestJS. يُستخدم عندما يطلب المستخدم الالتزام بطلب سحب أو دفعه أو إنشائه أو تحديثه، أو إعداد سجل التغيير أو إصدار نص، أو التحقق من نشر صفحات GitHub بعد النشر. فهو يفحص الفرق الكامل، ويحافظ على العمل غير ذي الصلة، ويفحص المحتوى المرحلي بحثًا عن الأسرار، ويطابق اتفاقيات التزام المستودع، ويجري عمليات التحقق ذات الصلة، وينفذ فقط الإجراءات عن بعد المطلوبة بشكل صريح. عندما تنطبق مهارات أخرى أيضا، التوفيق بين الملكية قبل الطفرة.
