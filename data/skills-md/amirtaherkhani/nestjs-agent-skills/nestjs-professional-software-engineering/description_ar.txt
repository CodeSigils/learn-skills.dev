يقوم بتصميم وتنفيذ وإعادة بناء وتصحيح الأخطاء ومراجعة برامج NestJS وTypeScript والتحقق من جودة الإنتاج. يُستخدم لتطوير ميزات NestJS، أو إصلاحات الأخطاء، أو واجهات برمجة التطبيقات، أو المكتبات، أو الاختبار، أو قابلية الصيانة، أو تجربة المطور، أو بناء الجملة الاصطلاحي، أو السكر النحوي. فهو يقوم بفحص المشروع الحالي والوثائق الرسمية المناسبة للإصدار قبل تحديد بناء الجملة، ويحافظ على السلوك العام، ويختبر النتيجة. عندما تنطبق مهارات أخرى أيضا، التوفيق بين الملكية قبل الطفرة.
