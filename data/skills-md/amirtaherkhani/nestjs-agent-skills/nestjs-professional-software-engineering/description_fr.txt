Conçoit, implémente, refactorise, débogue, examine et vérifie les logiciels NestJS et TypeScript de qualité production. À utiliser pour le développement de fonctionnalités NestJS, les corrections de bogues, les API, les bibliothèques, les tests, la maintenabilité, l'expérience des développeurs, la syntaxe idiomatique ou le sucre syntaxique. Il inspecte le projet actuel et la documentation officielle appropriée à la version avant de sélectionner la syntaxe, préserve le comportement public et teste le résultat. Lorsque d’autres compétences s’appliquent également, conciliez la propriété avant la mutation.
