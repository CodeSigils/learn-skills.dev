NestJS アーキテクチャ、OOP、機能のスキルを使用して既存の NestJS リポジトリを監査し、優先順位が付けられた証拠に裏付けられたコード品質レポートを 1 つ返します。 NestJS コードベース全体またはスコープ指定されたフォルダーの構文、TypeScript、lint、モジュール境界、依存関係、デザイン臭、セキュリティ、テスト、パフォーマンス、信頼性、実稼働準備の問題をチェックするように求められた場合に使用します。これは読み取り専用のレビュー ワークフローです。コードの修正、依存関係のインストール、移行の実行、またはデプロイは行われません。他のスキルも適用される場合は、突然変異の前に所有権を調整します。
