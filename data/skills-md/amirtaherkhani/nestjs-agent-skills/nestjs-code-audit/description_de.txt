Überprüft ein vorhandenes NestJS-Repository anhand der Kompetenzen NestJS-Architektur, OOP und Funktionen und gibt einen priorisierten, evidenzgestützten Codequalitätsbericht zurück. Verwenden Sie diese Option, wenn Sie aufgefordert werden, eine gesamte NestJS-Codebasis oder einen bereichsbezogenen Ordner auf Syntax-, TypeScript-, Lint-, Modulgrenzen-, Abhängigkeits-, Designgeruchs-, Sicherheits-, Test-, Leistungs-, Zuverlässigkeits- oder Produktionsbereitschaftsprobleme zu überprüfen. Dies ist ein schreibgeschützter Überprüfungsworkflow: Er korrigiert keinen Code, installiert keine Abhängigkeiten, führt keine Migrationen aus und stellt keine bereit. Wenn auch andere Fähigkeiten zutreffen, stimmen Sie die Eigentumsverhältnisse vor der Mutation ab.
