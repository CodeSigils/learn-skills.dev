Audita un repositorio NestJS existente con las habilidades de arquitectura, programación orientada a objetos y funciones de NestJS y devuelve un informe de calidad de código priorizado y respaldado por evidencia. Úselo cuando se le solicite verificar una base de código NestJS completa o una carpeta de alcance en busca de problemas de sintaxis, TypeScript, pelusa, límite de módulo, dependencia, olor de diseño, seguridad, pruebas, rendimiento, confiabilidad o preparación para la producción. Este es un flujo de trabajo de revisión de solo lectura: no corrige código, no instala dependencias, no ejecuta migraciones ni implementa. Cuando también se apliquen otras habilidades, concilie la propiedad antes de la mutación.
