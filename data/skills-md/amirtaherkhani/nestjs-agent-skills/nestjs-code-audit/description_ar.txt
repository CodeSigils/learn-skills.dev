يقوم بتدقيق مستودع NestJS الحالي باستخدام مهارات NestJS Architecture وOOP والميزات وإرجاع تقرير جودة التعليمات البرمجية محدد الأولويات ومدعوم بالأدلة. استخدمه عندما يُطلب منك التحقق من قاعدة بيانات NestJS بأكملها أو مجلد محدد بحثًا عن مشكلات البنية أو TypeScript أو الوبر أو حدود الوحدة النمطية أو التبعية أو رائحة التصميم أو الأمان أو الاختبار أو الأداء أو الموثوقية أو الاستعداد للإنتاج. هذا سير عمل مراجعة للقراءة فقط: فهو لا يصلح التعليمات البرمجية أو تثبيت التبعيات أو تشغيل عمليات الترحيل أو النشر. عندما تنطبق مهارات أخرى أيضا، التوفيق بين الملكية قبل الطفرة.
