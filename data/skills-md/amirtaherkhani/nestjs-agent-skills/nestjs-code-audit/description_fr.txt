Audite un référentiel NestJS existant avec les compétences en architecture, POO et fonctionnalités NestJS et renvoie un rapport sur la qualité du code hiérarchisé et étayé par des preuves. À utiliser lorsqu'on vous demande de vérifier l'intégralité d'une base de code NestJS ou un dossier limité pour des problèmes de syntaxe, TypeScript, lint, limite de module, dépendance, odeur de conception, sécurité, tests, performances, fiabilité ou préparation à la production. Il s'agit d'un workflow de révision en lecture seule : il ne corrige pas le code, n'installe pas de dépendances, n'exécute pas de migrations ni ne déploie. Lorsque d’autres compétences s’appliquent également, conciliez la propriété avant la mutation.
