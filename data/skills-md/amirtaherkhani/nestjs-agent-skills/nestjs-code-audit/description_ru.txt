Проводит аудит существующего репозитория NestJS с использованием навыков архитектуры NestJS, ООП и функций и возвращает один приоритетный, подтвержденный доказательствами отчет о качестве кода. Используйте, когда вас просят проверить всю кодовую базу NestJS или папку с заданной областью на наличие проблем с синтаксисом, TypeScript, lint, границами модулей, зависимостями, запахом дизайна, безопасностью, тестированием, производительностью, надежностью или готовностью к производству. Это рабочий процесс проверки, доступный только для чтения: он не исправляет код, не устанавливает зависимости, не запускает миграцию и не развертывает. Если применимы и другие навыки, согласуйте владение до мутации.
