Controlla un repository NestJS esistente con le competenze di Architettura, OOP e Funzionalità di NestJS e restituisce un report sulla qualità del codice con priorità e supportato da prove. Da utilizzare quando viene richiesto di controllare un'intera base di codice NestJS o una cartella con ambito per problemi di sintassi, TypeScript, lanugine, limiti del modulo, dipendenze, odore di progettazione, sicurezza, test, prestazioni, affidabilità o preparazione alla produzione. Questo è un flusso di lavoro di revisione di sola lettura: non corregge il codice, non installa dipendenze, non esegue migrazioni o distribuisce. Quando si applicano anche altre abilità, riconcilia la proprietà prima della mutazione.
