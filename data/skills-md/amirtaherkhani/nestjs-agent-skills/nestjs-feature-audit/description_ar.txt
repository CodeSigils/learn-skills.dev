يقوم بتدقيق إحدى ميزات NestJS مقابل خريطة الطريق الموثقة الخاصة بها في فرع Git محدد وإرجاع تقرير مدعوم بالأدلة عن التنفيذ والفجوات والإرث والأخطاء والحظر. استخدمه عندما يُطلب منك تدقيق ميزة ما، أو التحقق من اكتمال الميزة، أو مقارنة التعليمات البرمجية بخريطة طريق أو خطة قبول، أو تشغيل تحليل فجوة الميزات، أو مراجعة حالة الترحيل، أو استدعاء /audit_feature باسم الميزة والفرع الاختياري. ويتوقف عند عدم توفر خريطة طريق واضحة ولا يتم تنفيذ الإصلاحات. عندما تنطبق مهارات أخرى أيضا، التوفيق بين الملكية قبل الطفرة.
