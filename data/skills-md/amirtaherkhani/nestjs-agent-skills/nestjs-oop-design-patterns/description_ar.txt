يطبق قواعد OOP وSOLID العملية وتصميم الكائنات وأنماط التصميم على كود NestJS وTypeScript. تُستخدم عند كتابة أو إعادة بناء وحدات التحكم أو الموفرين أو حالات الاستخدام أو الكيانات أو كائنات القيمة أو المستودعات أو المحولات أو المصانع أو الاستراتيجيات أو المعالجات أو الاختبارات؛ عند تشخيص خدمات الله، أو الهوس البدائي، أو إساءة استخدام الميراث، أو الشروط المكررة، أو التجريدات المتسربة؛ وعند اختيار نمط دون الإفراط في الهندسة. لا تستخدمه لقواعد الأكواد الوظيفية البحتة أو أعمال الواجهة الأمامية غير التابعة لـ NestJS. عندما تنطبق مهارات أخرى أيضا، التوفيق بين الملكية قبل الطفرة.
