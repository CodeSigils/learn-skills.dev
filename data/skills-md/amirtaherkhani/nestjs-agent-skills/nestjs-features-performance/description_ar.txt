يحدد وينفذ ميزات وقت تشغيل NestJS، وعقود الأخطاء وواجهة برمجة التطبيقات (API)، والأمان، والاختبار، وDevOps، والأداء، والقياس الآمن. الاستخدام للبرامج الوسيطة، والحراس، والأنابيب، والمعترضات، ومرشحات الاستثناء، والفشل/النتائج المكتوبة، وتفاصيل المشكلة، وأخطاء التحقق من الصحة، وتخطيط أخطاء HTTP/GraphQL/RPC/gRPC/WebSocket، والمواعيد النهائية، والإلغاء، وإعادة محاولة التصنيف، وأخطاء العملية الفادحة، والمصادقة، والتخويل، والتخزين المؤقت، وقوائم الانتظار، والمجدولين، وCI/CD، والحاويات، وKubernetes، والتكوين والأسرار، والترحيلات، وضوابط سلسلة التوريد، وتحقيقات الصحة، السجلات/المقاييس/الآثار، وSLOs والتنبيهات، واسترداد الحوادث، والبدء والتراجع، وحلقة الأحداث أو اختناقات قاعدة البيانات، واختبارات التحميل، والقياس الأفقي، والعجز، والضغط الخلفي، والإيقاف السلس. لا تستخدمه لأداء الواجهة الأمامية فقط أو للخدمات غير التابعة لـ NestJS.
