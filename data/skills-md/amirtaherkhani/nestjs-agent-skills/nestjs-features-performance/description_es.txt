Selecciona e implementa funciones de tiempo de ejecución de NestJS, contratos de error y API, seguridad, pruebas, DevOps, rendimiento y escalado seguro. Úselo para middleware, guardias, canalizaciones, interceptores, filtros de excepción, fallas/resultados escritos, detalles del problema, errores de validación, mapeo de errores HTTP/GraphQL/RPC/gRPC/WebSocket, fechas límite, cancelación, clasificación de reintentos, errores fatales de proceso, autenticación, autorización, almacenamiento en caché, colas, programadores, CI/CD, contenedores, Kubernetes, configuración y secretos, migraciones, controles de la cadena de suministro, sondas de estado, registros/métricas/rastreos, SLO y alertas, recuperación de incidentes, implementación y reversión, bucles de eventos o cuellos de botella en la base de datos, pruebas de carga, escalamiento horizontal, idempotencia, contrapresión y cierre ordenado. No lo utilice para rendimiento solo de frontend o servicios que no sean NestJS.
