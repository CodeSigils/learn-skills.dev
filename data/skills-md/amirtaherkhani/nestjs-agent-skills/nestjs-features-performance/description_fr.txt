Sélectionne et implémente les fonctionnalités d'exécution NestJS, les contrats d'erreur et d'API, la sécurité, les tests, le DevOps, les performances et l'évolutivité sécurisée. À utiliser pour les middlewares, les gardes, les tuyaux, les intercepteurs, les filtres d'exception, les échecs/résultats saisis, les détails du problème, les erreurs de validation, le mappage des erreurs HTTP/GraphQL/RPC/gRPC/WebSocket, les délais, l'annulation, la classification des nouvelles tentatives, les erreurs de processus fatales, l'authentification, l'autorisation, la mise en cache, les files d'attente, les planificateurs, CI/CD, les conteneurs, Kubernetes, la configuration et les secrets, les migrations, les contrôles de la chaîne d'approvisionnement, les sondes d'intégrité, les journaux/métriques/traces, les SLO. et les alertes, la récupération après incident, le déploiement et la restauration, les goulots d'étranglement des boucles d'événements ou des bases de données, les tests de charge, la mise à l'échelle horizontale, l'idempotence, la contre-pression et l'arrêt progressif. Ne pas utiliser pour des performances frontend uniquement ou des services non NestJS.
