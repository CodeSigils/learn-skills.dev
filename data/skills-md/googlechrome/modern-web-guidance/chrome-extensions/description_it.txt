Crea e pubblica estensioni di Chrome utilizzando le best practice di Manifest V3. Utilizza questa competenza ogni volta che l'utente chiede di creare, modificare, eseguire il debug o comprendere le estensioni, i componenti aggiuntivi del browser Chrome o qualsiasi cosa coinvolga l'API delle estensioni di Chrome. Attivazione in caso di menzioni di: "estensione Chrome", "estensione browser", "manifest.json", "script contenuto", "service lavoratore" (nel contesto del browser), "popup" (nel contesto dell'estensione del browser), "pannello laterale", "chrome.* API", "declarativeNetRequest", "omnibox", "menu contestuale" (nel contesto dell'estensione) o qualsiasi richiesta di creare funzionalità che si integri con l'interfaccia utente del browser Chrome. Attiva anche la pubblicazione sul Chrome Web Store: "pubblica estensione", preparazione di un'estensione per la pubblicazione, risposta al rifiuto di una recensione, scrittura di giustificazioni di autorizzazione o stesura di un'informativa sulla privacy.
