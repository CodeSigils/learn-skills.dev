Cree y publique extensiones de Chrome utilizando las mejores prácticas de Manifest V3. Utilice esta habilidad siempre que el usuario solicite crear, modificar, depurar o comprender extensiones o complementos del navegador Chrome o cualquier cosa que involucre la API de extensiones de Chrome. Se activa ante menciones de: 'extensión de Chrome', 'extensión del navegador', 'manifest.json', 'script de contenido', 'trabajador de servicio' (en el contexto del navegador), 'emergente' (en el contexto de la extensión del navegador), 'panel lateral', 'chrome.* API', 'declarativeNetRequest', 'omnibox', 'menú contextual' (en el contexto de la extensión) o cualquier solicitud para crear una funcionalidad que se integre con la interfaz de usuario del navegador Chrome. También activa la publicación en Chrome Web Store: 'extensión de publicación', preparación de una extensión para publicación, respuesta a un rechazo de revisión, redacción de justificaciones de permiso o redacción de una política de privacidad.
