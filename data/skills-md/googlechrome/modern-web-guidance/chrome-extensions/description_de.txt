Erstellen und veröffentlichen Sie Chrome-Erweiterungen mithilfe der Best Practices von Manifest V3. Verwenden Sie diesen Skill immer dann, wenn der Benutzer Chrome-Browsererweiterungen, Add-ons oder alles, was mit der Chrome Extensions API zu tun hat, erstellen, ändern, debuggen oder verstehen möchte. Auslösen bei Erwähnungen von: „Chrome-Erweiterung“, „Browser-Erweiterung“, „manifest.json“, „Inhaltsskript“, „Service Worker“ (im Browser-Kontext), „Popup“ (im Browser-Erweiterungs-Kontext), „Side Panel“, „chrome.* API“, „declarativeNetRequest“, „omnibox“, „Kontextmenü“ (im Erweiterungs-Kontext) oder bei jeder Anforderung zum Erstellen von Funktionen, die in die Benutzeroberfläche des Chrome-Browsers integriert sind. Außerdem Auslöser für die Veröffentlichung im Chrome Web Store: „Erweiterung veröffentlichen“, Vorbereiten einer Erweiterung zur Veröffentlichung, Reagieren auf eine Ablehnung einer Bewertung, Verfassen von Berechtigungsbegründungen oder Verfassen einer Datenschutzrichtlinie.
