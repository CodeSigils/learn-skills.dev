قم ببناء ونشر ملحقات Chrome باستخدام أفضل ممارسات Manifest V3. استخدم هذه المهارة عندما يطلب المستخدم إنشاء أو تعديل أو تصحيح الأخطاء أو فهم ملحقات متصفح Chrome أو الوظائف الإضافية أو أي شيء يتضمن Chrome Extensions API. تشغيل الإشارات إلى: "ملحق Chrome"، أو "ملحق المتصفح"، أو "manifest.json"، أو "البرنامج النصي للمحتوى"، أو "عامل الخدمة" (في سياق المتصفح)، أو "الإطار المنبثق" (في سياق ملحق المتصفح)، أو "اللوحة الجانبية"، أو "chrome.* API"، أو "declarativeNetRequest"، أو "omnibox"، أو "قائمة السياق" (في سياق الملحق)، أو أي طلب لإنشاء وظيفة تتكامل مع واجهة مستخدم متصفح Chrome. قم أيضًا بتشغيل النشر في سوق Chrome الإلكتروني: "نشر الامتداد"، أو إعداد ملحق للنشر، أو الاستجابة لرفض المراجعة، أو كتابة مبررات الإذن، أو صياغة سياسة الخصوصية.
