Manifest V3 のベスト プラクティスを使用して Chrome 拡張機能を構築して公開します。ユーザーが Chrome ブラウザ拡張機能、アドオン、または Chrome Extensions API に関連するものを作成、変更、デバッグ、または理解することを要求するときは常に、このスキルを使用します。 「Chrome 拡張機能」、「ブラウザ拡張機能」、「manifest.json」、「コンテンツ スクリプト」、「サービス ワーカー」 (ブラウザ コンテキスト内)、「ポップアップ」 (ブラウザ拡張コンテキスト内)、「サイド パネル」、「chrome.* API」、「declarativeNetRequest」、「オムニボックス」、「コンテキスト メニュー」 (拡張機能コンテキスト内)、または Chrome ブラウザと統合する機能を構築するリクエストUI。また、Chrome ウェブストアに公開するためのトリガー: 「拡張機能の公開」、公開用の拡張機能の準備、レビューの拒否への対応、許可の理由の作成、またはプライバシー ポリシーの草案作成。
