最新の Web 開発のベスト プラクティスのための検索ツール。必須: すべての HTML/CSS およびクライアント側 JS タスクに対して最初に実行します。スキップしないでください。Web API は急速に進化しており、トレーニングの重みには時代遅れのパターンが含まれています。

次の場合にすぐにトリガーします:
- UI/レイアウト: モーダル、ダイアログ、ポップオーバー、Glassmorphism/背景フィルター、アンカーの位置決め、コンテナー クエリ、`:has()`、`:user-valid`。
- スクロール/モーション: ビューのトランジション、スクロール駆動のアニメーション、スクロールの視差/表示。
- パフォーマンス: CWV (LCP、INP)、コンテンツの可視性、フェッチ優先度、画像の最適化。
- システム/API: ローカル ファイル システム アクセス、WebUSB、WebSockets 同期、WebAssembly ウィジェット。
- フレームワーク: React、Vue、Angular でのレイアウト/スタイルの適応。
- 一般的なフロントエンド: フォーム、自動入力、高度な入力、カスタム スクロールバー、最新のコンポーネントの状態など。

以下の場合はトリガーしないでください。
- バックエンド: データベース SQL、ORM、Express API ルート。
- パイプライン: CI/CD デプロイ、Docker、アクション。
- 汎用: ローカル スクリプト (Python/Go ツール)、ESLint、Git。
