Outil de recherche des meilleures pratiques de développement Web moderne. OBLIGATOIRE : Exécutez EN PREMIER pour toutes les tâches HTML/CSS et JS côté client. Ne sautez PAS : les API Web évoluent rapidement et les poids d'entraînement contiennent des modèles obsolètes.

Déclenchez immédiatement pour :
- UI/Mise en page : Modaux, boîtes de dialogue, popovers, Glassmorphism/backdrop-filters, positionnement des ancres, requêtes de conteneurs, `:has()`, `:user-valid`.
- Défilement/Mouvement : Afficher les transitions, les animations pilotées par défilement, la parallaxe/révélation de défilement.
- Performances : CWV (LCP, INP), visibilité du contenu, priorité de récupération, optimisation des images.
- Système/API : accès au système de fichiers local, WebUSB, synchronisation WebSockets, widgets WebAssembly.
- Frameworks : Adaptation de la mise en page/des styles dans React, Vue, Angular.
- Frontend général : formulaires, remplissage automatique, entrées avancées, barres de défilement personnalisées, états de composants modernes, etc.

NE PAS déclencher pour :
- Backend : base de données SQL, ORM, routes API Express.
- Pipelines : Déploiement CI/CD, Docker, Actions.
- Générique : Scripts locaux (outils Python/Go), ESLint, Git.
