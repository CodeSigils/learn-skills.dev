Strumento di ricerca per le migliori pratiche di sviluppo web moderno. OBBLIGATORIO: eseguire PRIMA per tutte le attività HTML/CSS e JS lato client. NON saltare: le API Web si evolvono rapidamente e i pesi di addestramento contengono modelli obsoleti.

Attiva immediatamente per:
- Interfaccia utente/layout: modali, finestre di dialogo, popover, Glassmorphism/filtri sullo sfondo, posizionamento degli ancoraggi, query sui contenitori, `:has()`, `:user-valid`.
- Scorrimento/movimento: visualizza transizioni, animazioni guidate da scorrimento, parallasse/rivela scorrimento.
- Prestazioni: CWV (LCP, INP), visibilità dei contenuti, Fetch Priority, ottimizzazione delle immagini.
- Sistema/API: accesso al file system locale, WebUSB, sincronizzazione WebSocket, widget WebAssembly.
- Framework: adattamento di layout/stili in React, Vue, Angular.
- Frontend generale: moduli, compilazione automatica, input avanzati, barre di scorrimento personalizzate, stati dei componenti moderni, ecc.

NON attivare per:
- Backend: database SQL, ORM, percorsi API Express.
- Pipeline: distribuzione CI/CD, Docker, azioni.
- Generico: script locali (strumenti Python/Go), ESLint, Git.
