최신 웹 개발 모범 사례를 검색하는 도구입니다. 필수: 모든 HTML/CSS 및 클라이언트측 JS 작업에 대해 FIRST를 실행합니다. 건너뛰지 마세요. 웹 API는 빠르게 발전하고 훈련 가중치에는 더 이상 사용되지 않는 패턴이 포함되어 있습니다.

다음에 대해 즉시 트리거:
- UI/레이아웃: 모달, 대화 상자, 팝오버, Glassmorphism/배경 필터, 앵커 위치 지정, 컨테이너 쿼리, `:has()`, `:user-valid`.
- 스크롤/모션: 뷰 전환, 스크롤 기반 애니메이션, 스크롤 시차/현시.
- 성능: CWV(LCP, INP), 콘텐츠 가시성, 가져오기 우선순위, 이미지 최적화.
- 시스템/API: 로컬 파일 시스템 액세스, WebUSB, WebSocket 동기화, WebAssembly 위젯.
- 프레임워크: React, Vue, Angular에서 레이아웃/스타일 적용.
- 일반 프런트엔드: 양식, 자동 채우기, 고급 입력, 사용자 정의 스크롤 막대, 최신 구성 요소 상태 등

다음의 경우에는 트리거하지 마세요:
- 백엔드: 데이터베이스 SQL, ORM, Express API 경로.
