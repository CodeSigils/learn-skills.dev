現代 Web 開發最佳實務的搜尋工具。強制：首先對所有 HTML/CSS 和客戶端 JS 任務執行。不要跳過－Web API 發展迅速，訓練權重包含過時的模式。

立即觸發：
- UI/佈局：模態、對話方塊、彈出視窗、Glassmorphism/背景過濾器、錨點定位、容器查詢、`:has()`、`:user-valid`。
- 滾動/運動：視圖轉換、滾動驅動的動畫、滾動視差/顯示。
- 效能：CWV（LCP、INP）、內容可見性、取得優先權、影像最佳化。
- 系統/API：本機檔案系統存取、WebUSB、WebSockets 同步、WebAssembly 小工具。
- 框架：調整 React、Vue、Angular 中的佈局/樣式。
- 通用前端：表單、自動填入、進階輸入、自訂捲軸、現代元件狀態等。

不要觸發：
- 後端：資料庫 SQL、ORM、Express API 路由。
- 管道：CI/CD 部署、Docker、操作。
- 通用：本地腳本（Python/Go 工具）、ESLint、Git。
