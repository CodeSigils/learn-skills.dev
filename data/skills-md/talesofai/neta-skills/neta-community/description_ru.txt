Навыки сообщества Neta API — просматривайте интерактивные каналы, просматривайте сведения о коллекциях, ставьте лайки и взаимодействуйте с контентом, а также просматривайте контент по тегам и символам в контексте сообщества. Используйте этот навык, когда пользователь хочет «увидеть, что делают люди», «пролистать ленту» или «взаимодействовать с работами». Не используйте его для исследований на уровне таксономии/ключевых слов (осуществляется neta-suggest) или для создания изображений/видео/песен (обрабатывается neta-creative).
