Навыки просмотра пространства и обзора мира Neta API — просматривайте построение мира, подпространства и игровой контент по пробелу/хэштегу. Используйте этот навык, когда пользователь говорит о мирах/пространствах/вселенных/сценах или хочет просмотреть персонажей и игровой процесс на основе пространства и структуры действий. Не используйте его для создания конкретных медиа (осуществляется neta-creative).
