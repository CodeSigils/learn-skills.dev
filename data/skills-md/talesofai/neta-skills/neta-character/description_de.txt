Neta Character Forging Skill – Führt Benutzer durch die Erstellung oder Aktualisierung von VTokens (Virtual Tokens, TCP) für Anime/kulturelle IP/Originalcharaktere (OC). Beinhaltet eine visuelle Vorschau, Charakterdokumentation, Bestätigung der Hintergrundgeschichte und einen vollständigen kreativen Workflow. Verwenden Sie diese Fähigkeit, wenn Benutzer neue Charaktere erstellen, vorhandene ändern oder mit dem Charakterdesign beginnen möchten.
