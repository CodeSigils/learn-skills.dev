Содержит подробное руководство по библиотеке компонентов MateChat Vue 3, включая компоненты пользовательского интерфейса AI-чата/агента, установку, справочник по API и демонстрационные примеры. Используйте при создании интерфейсов чата AI с помощью Vue 3, реализации всплывающих окон разговоров, компонентов ввода или любых компонентов пользовательского интерфейса MateChat.
