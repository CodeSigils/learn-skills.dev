Fornisce una guida completa per la libreria dei componenti di MateChat Vue 3, inclusi i componenti dell'interfaccia utente della chat/agente AI, installazione, riferimento API ed esempi demo. Da utilizzare durante la creazione di interfacce di chat AI con Vue 3, l'implementazione di fumetti di conversazione, componenti di input o qualsiasi componente dell'interfaccia utente di MateChat.
