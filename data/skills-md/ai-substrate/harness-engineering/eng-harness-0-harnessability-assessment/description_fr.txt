Évaluez l'exploitabilité d'un référentiel Git : la facilité avec laquelle un humain ou un agent peut y accéder, l'exploiter, le modifier, l'observer, le prouver et l'améliorer grâce à un exploit d'ingénierie. Produit des rapports Markdown et JSON fondés sur des données probantes notant Operate-Today et Adaptability, cartographiant les surfaces de contre-pression, les plafonds de preuve, l'exposition aux dépendances externes, les sondes de scénarios et les possibilités de harnais/code produit à effet de levier le plus élevé.
