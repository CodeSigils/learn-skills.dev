Complete tareas web especificadas por el usuario utilizando un enfoque de código como acción: ejecute paso a paso en un navegador Playwright local, almacene capturas de pantalla y registros de acciones en final_runs/run_<id>/ y verifique los resultados. Adecuado para automatización web, búsqueda, filtrado, llenado de formularios, procesos de múltiples pasos, extracción de datos; se utiliza cuando el usuario necesita poder volver a ejecutar scripts y tener evidencia de captura de pantalla en lugar de una respuesta verbal única. Palabras desencadenantes: Webwright, guión de Playwright, automatización web, automatización del navegador.
