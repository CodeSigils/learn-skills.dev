Используйте при преобразовании проектов Stitch в производственные компоненты React. Обеспечивает модульную архитектуру: логика в хуках, данные вockData.ts, интерфейсы TypeScript только для чтения, классы Tailwind с сопоставлением тем. Запускается при: Stitch to React, design to code, экспорт стежков, стежок MCP, стежок: get_screen.
