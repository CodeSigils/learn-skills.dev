Verwenden Sie diese Option, wenn der Benutzer Agentenfähigkeiten finden, installieren oder suchen möchte. Wird auch verwendet, wenn der Benutzer fragt: „Können Sie X machen?“ oder „Gibt es eine Fertigkeit für X?“, wobei X eine spezielle Fähigkeit ist. Schlüsselwörter: Skill installieren, Skill finden, Npx-Skills, skills.sh, Agent erweitern, Fähigkeit hinzufügen.
