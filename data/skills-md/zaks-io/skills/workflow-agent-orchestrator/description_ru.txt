Используйте для Agent Orchestrator, агента с коротким циклом, который организует работу по реализации с отслеживанием проблем, выбирая запускаемые проблемы, запуская или подталкивая исполнителей, запрашивая проверку агента, обновляя средство отслеживания и останавливая, когда требуется участие человека.
