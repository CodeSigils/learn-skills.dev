Лучшие практики для API Terra API Streaming (Real-Time) — живые биометрические данные примерно в секунду с носимых устройств через веб-сокеты. Используйте при создании потоковой передачи в реальном времени с помощью Terra API, TerraRT SDK или wss://ws.tryterra.co; потоковая трансляция сердечного ритма, шагов, расстояния, ускорения, ЭКГ, ВСР, калорий, местоположения или гироскопа; сопряжение носимого устройства через BLE или ANT+; получение данных датчиков из мобильного приложения; использование прямой трансляции на бэкэнде; или потоковую передачу с часов Apple Watch или Wear OS. Охватывает архитектуру производителя/брокера/потребителя, подтверждение связи и коды операций веб-сокета, создание токенов, коды закрытия, воспроизведение/обратное заполнение и настройку SDK для каждой платформы (iOS, Android, React Native, Flutter, Wear OS).
