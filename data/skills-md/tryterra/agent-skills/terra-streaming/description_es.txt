Mejores prácticas para la API Terra API Streaming (en tiempo real): datos biométricos en vivo, aproximadamente por segundo, de dispositivos portátiles a través de websockets. Úselo al crear transmisión en tiempo real con Terra API, TerraRT SDK o wss://ws.tryterra.co; transmisión en vivo de frecuencia cardíaca, pasos, distancia, aceleración, ECG, VFC, calorías, ubicación o giroscopio; emparejar un dispositivo portátil a través de BLE o ANT+; producir datos de sensores desde una aplicación móvil; consumir una transmisión en vivo en un backend; o transmisión desde un reloj Apple Watch o Wear OS. Cubre la arquitectura del productor/corredor/consumidor, el protocolo de enlace y los códigos de operación de websocket, la acuñación de tokens, los códigos de cierre, la reproducción/relleno y la configuración del SDK por plataforma (iOS, Android, React Native, Flutter, Wear OS).
