أفضل الممارسات لواجهة برمجة تطبيقات Terra API Streaming (Real-Time) - بيانات بيومترية مباشرة في الثانية تقريبًا من الأجهزة القابلة للارتداء عبر مقابس الويب. يُستخدم عند إنشاء البث في الوقت الفعلي باستخدام Terra API أو TerraRT SDK أو wss://ws.tryterra.co؛ بث معدل ضربات القلب المباشر أو الخطوات أو المسافة أو التسارع أو تخطيط القلب أو معدل ضربات القلب أو السعرات الحرارية أو الموقع أو الجيروسكوب؛ إقران جهاز يمكن ارتداؤه عبر BLE أو ANT+؛ وإنتاج بيانات الاستشعار من تطبيق الهاتف المحمول؛ استهلاك البث المباشر على الواجهة الخلفية؛ أو البث من ساعة Apple Watch أو Wear OS. يغطي بنية المنتج/الوسيط/المستهلك، ومصافحة websocket وأكواد التشغيل، وسك الرموز المميزة، وأكواد الإغلاق، وإعادة التشغيل/إعادة التعبئة، وإعداد SDK لكل منصة (iOS، Android، React Native، Flutter، Wear OS).
