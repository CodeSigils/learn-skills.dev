Terra API Streaming（即時）API 的最佳實踐 - 透過 Websocket 來自穿戴式裝置的即時、大約每秒的生物辨識資料。使用 Terra API、TerraRT SDK 或 wss://ws.tryterra.co 建立即時串流時使用；即時傳輸心率、步數、距離、加速度、心電圖、心率變異性、卡路里、位置或陀螺儀；透過 BLE 或 ANT+ 配對穿戴裝置；從行動應用程式產生感測器；在後端消費即時資料流；或從 Apple Watch 或從 Apple Watch 串流傳輸。涵蓋生產者/經紀人/消費者架構、websocket 握手和操作碼、代幣鑄造、關閉程式碼、重播/回填以及每個平台的 SDK 設定（iOS、Android、React Native、Flutter、Wear OS）。
