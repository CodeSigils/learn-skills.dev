Terra API 스트리밍(실시간) API에 대한 모범 사례 - 웹소켓을 통해 웨어러블에서 제공되는 대략 초당 생체 인식 데이터입니다. Terra API, TerraRT SDK 또는 wss://ws.tryterra.co를 사용하여 실시간 스트리밍을 구축할 때 사용합니다. 실시간 심박수, 걸음 수, 거리, 가속도, ECG, HRV, 칼로리, 위치 또는 자이로스코프 스트리밍 BLE 또는 ANT+를 통해 웨어러블을 페어링합니다. 모바일 앱에서 센서 데이터를 생성하는 단계; 백엔드에서 라이브 스트림을 소비합니다. 또는 Apple Watch 또는 Wear OS 시계에서 스트리밍할 수 있습니다. 생산자/브로커/소비자 아키텍처, 웹소켓 핸드셰이크 및 opcode, 토큰 발행, 종료 코드, 재생/백필 및 플랫폼별 SDK 설정(iOS, Android, React Native, Flutter, Wear OS)을 다룹니다.
