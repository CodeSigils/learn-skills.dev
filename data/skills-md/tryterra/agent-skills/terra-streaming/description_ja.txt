Terra API ストリーミング (リアルタイム) API のベスト プラクティス – WebSocket を介したウェアラブルからのおよそ 1 秒ごとのライブ生体認証データ。 Terra API、TerraRT SDK、または wss://ws.tryterra.co を使用してリアルタイム ストリーミングを構築する場合に使用します。ライブ心拍数、歩数、距離、加速度、ECG、HRV、カロリー、位置、またはジャイロスコープをストリーミングします。 BLE または ANT+ を介してウェアラブルをペアリングします。モバイルアプリからセンサーデータを生成します。バックエンドでライブ ストリームを消費します。または、Apple Watch または Wear OS ウォッチからストリーミングします。プロデューサー/ブローカー/コンシューマー アーキテクチャ、WebSocket ハンドシェイクとオペコード、トークン ミント、クローズ コード、リプレイ/バックフィル、プラットフォームごとの SDK セットアップ (iOS、Android、React Native、Flutter、Wear OS) について説明します。
