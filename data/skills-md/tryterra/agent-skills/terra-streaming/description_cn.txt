Terra API Streaming（实时）API 的最佳实践 - 通过 Websocket 来自可穿戴设备的实时、大约每秒的生物识别数据。使用 Terra API、TerraRT SDK 或 wss://ws.tryterra.co 构建实时流时使用；实时传输心率、步数、距离、加速度、心电图、心率变异性、卡路里、位置或陀螺仪；通过 BLE 或 ANT+ 配对可穿戴设备；从移动应用程序生成传感器数据；在后端消费实时流；或从 Apple Watch 或 Wear OS 手表进行流式传输。涵盖生产者/经纪人/消费者架构、websocket 握手和操作码、代币铸造、关闭代码、重放/回填以及每个平台的 SDK 设置（iOS、Android、React Native、Flutter、Wear OS）。
