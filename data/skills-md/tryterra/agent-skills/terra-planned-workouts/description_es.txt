Cree con el producto Terra API Planned Workouts (prelanzamiento): defina un entrenamiento estructurado una vez y Terra API lo envía a los dispositivos de los usuarios. Úselo al enviar entrenamientos planificados o estructurados a relojes Garmin, COROS, Wahoo, Suunto, TrainingPeaks, Huawei, Zepp, Hevy o Apple, crear planes de entrenamiento o plantillas de entrenamiento, trabajar con intervalos, calentamientos, objetivos (FC, potencia, ritmo, cadencia, RPE, zonas), FTP o personalización basada en umbrales, parámetros de atleta, plantillas de natación o fuerza, o manejar advertencias de coerción del proveedor cuando un dispositivo no puede representar una característica.
