Crea con il prodotto Terra API Planned Workouts (pre-release): definisci un allenamento strutturato una volta e Terra API lo invia ai dispositivi degli utenti. Da utilizzare quando si inviano allenamenti pianificati o strutturati a Garmin, COROS, Wahoo, Suunto, TrainingPeaks, Huawei, Zepp, Hevy o Apple Watch, si creano piani di allenamento o modelli di allenamento, si lavora con intervalli, riscaldamenti, obiettivi (FC, potenza, andatura, cadenza, RPE, zone), FTP o personalizzazione basata su soglie, parametri dell'atleta, modelli di nuoto o forza o si gestiscono avvisi di coercizione del fornitore quando un dispositivo non può rappresentare una funzionalità.
