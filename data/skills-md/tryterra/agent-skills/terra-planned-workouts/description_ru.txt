Создавайте с помощью продукта Terra API Planned Workouts (предварительная версия) — определите структурированную тренировку один раз, и Terra API отправит ее на устройства пользователей. Используйте при отправке запланированных или структурированных тренировок на часы Garmin, COROS, Wahoo, Suunto, TrainingPeaks, Huawei, Zepp, Hevy или Apple, построении планов тренировок или шаблонов тренировок, работе с интервалами, разминками, целевыми показателями (ЧСС, мощность, темп, частота вращения педалей, RPE, зоны), FTP или персонализацией на основе пороговых значений, параметрами спортсменов, шаблонами плавания или силы или обработкой предупреждений поставщика о принуждении, когда устройство не может отображать функцию.
