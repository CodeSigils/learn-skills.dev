Terra API Planned Workouts 製品 (プレリリース) を使用して構築する – 構造化されたワークアウトを一度定義すると、Terra API がそれをユーザーのデバイスにプッシュします。計画または構造化されたワークアウトを Garmin、COROS、Wahoo、Suunto、TrainingPeaks、Huawei、Zepp、Hevy、または Apple ウォッチにプッシュする場合、トレーニング プランやワークアウト テンプレートを構築する場合、インターバル、ウォームアップ、目標 (HR、パワー、ペース、ケイデンス、RPE、ゾーン)、FTP またはしきい値ベースのパーソナライゼーション、アスリート パラメーター、水泳または筋力テンプレートを使用する場合、またはデバイスが機能を表現できない場合にプロバイダーの強制警告を処理する場合に使用します。
