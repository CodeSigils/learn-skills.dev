يمكنك البناء باستخدام منتج Terra API Planned Workouts (الإصدار التجريبي) - حدد تمرينًا منظمًا مرة واحدة وستقوم Terra API بدفعه إلى أجهزة المستخدمين. يُستخدم عند دفع التدريبات المخططة أو المنظمة إلى Garmin، أو COROS، أو Wahoo، أو Suunto، أو TrainingPeaks، أو Huawei، أو Zepp، أو Hevy، أو ساعات Apple، أو بناء خطط تدريب أو قوالب تمرين، أو العمل مع فترات زمنية، أو عمليات إحماء، أو أهداف (HR، أو الطاقة، أو السرعة، أو الإيقاع، أو RPE، أو المناطق)، أو FTP أو التخصيص القائم على العتبة، أو معلمات الرياضي، أو قوالب السباحة أو القوة، أو التعامل مع تحذيرات إكراه الموفر عندما لا يتمكن الجهاز من تمثيل ميزة.
