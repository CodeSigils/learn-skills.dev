Erstellen Sie mit dem Terra API Planned Workouts-Produkt (Vorabversion) – definieren Sie einmal ein strukturiertes Training und Terra API überträgt es an die Geräte der Benutzer. Verwenden Sie diese Funktion, wenn Sie geplante oder strukturierte Trainingseinheiten an Garmin-, COROS-, Wahoo-, Suunto-, TrainingPeaks-, Huawei-, Zepp-, Hevy- oder Apple-Uhren übertragen, Trainingspläne oder Trainingsvorlagen erstellen, mit Intervallen, Aufwärmübungen, Zielen (HF, Leistung, Tempo, Trittfrequenz, RPE, Zonen), FTP oder schwellenbasierter Personalisierung, Sportlerparametern, Schwimm- oder Kraftvorlagen arbeiten oder Zwangwarnungen von Anbietern verarbeiten, wenn ein Gerät eine Funktion nicht darstellen kann.
