Terra Vantage API を使用して、自宅およびラボに行って診断テストを注文し、結果を提供します。血液検査または DNA 検査の注文、在宅検査キットの統合、診断の注文、検査製品とバリアントの閲覧、キットのアクティベーションの処理、履行と発送の追跡、結果ステータス Webhook の受信、FHIR 形式の検査結果の取得、または結果の確認 (患者が結果を表示する前の必須のコンプライアンス手順) を行うときに使用します。製品から注文、結果に至るまでのワークフロー、HTTP Basic 認証、AT_HOME と GO_TO_LAB の収集方法、Webhook イベントと HMAC 署名の検証、サンドボックス環境、開始するために必要な手動のパートナー オンボーディングについて説明します。
