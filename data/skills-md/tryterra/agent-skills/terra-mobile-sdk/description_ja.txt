Web API を持たないオンデバイスのヘルス ソース (Apple Health (HealthKit)、Samsung Health、Health Connect) に Terra API モバイル SDK を統合します。モバイル アプリから Apple Health、Samsung Health、または Health Connect に接続するときに使用します。 TerraiOS、TerraAndroid、terra-react、または terra_flutter_bridge を使用する場合。 generateAuthToken 経由でモバイル SDK 認証トークンを生成するとき。 HealthKit バックグラウンド配信、initConnection 権限ポップアップ、getUserId 検証、Samsung 用の ProGuard ルール、または Health Connect マニフェスト権限を構成するとき。または、postActivity/postBody/postNutrition を使用してデバイス上のデータを書き込む場合。
