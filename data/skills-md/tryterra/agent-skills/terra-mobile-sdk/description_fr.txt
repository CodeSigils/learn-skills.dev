Intégrez le SDK mobile Terra API pour les sources de santé sur appareil qui n'ont pas d'API Web : Apple Health (HealthKit), Samsung Health et Health Connect. À utiliser lors de la connexion d'Apple Health, Samsung Health ou Health Connect à partir d'une application mobile ; lorsque vous travaillez avec TerraiOS, TerraAndroid, terra-react ou terra_flutter_bridge ; lors de la création d'un jeton d'authentification du SDK mobile via generateAuthToken ; lors de la configuration de la diffusion en arrière-plan de HealthKit, des fenêtres contextuelles d'autorisation initConnection, de la validation getUserId, des règles ProGuard pour Samsung ou des autorisations du manifeste Health Connect ; ou lors de l'écriture de données sur l'appareil avec postActivity/postBody/postNutrition.
