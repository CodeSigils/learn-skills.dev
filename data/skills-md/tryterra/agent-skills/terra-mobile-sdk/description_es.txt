Integre el SDK móvil Terra API para fuentes de salud en el dispositivo que no tienen API web: Apple Health (HealthKit), Samsung Health y Health Connect. Úselo cuando conecte Apple Health, Samsung Health o Health Connect desde una aplicación móvil; cuando se trabaja con TerraiOS, TerraAndroid, terra-react o terra_flutter_bridge; al acuñar un token de autenticación de SDK móvil a través de generateAuthToken; al configurar la entrega en segundo plano de HealthKit, ventanas emergentes de permisos de initConnection, validación getUserId, reglas de ProGuard para Samsung o permisos de manifiesto de Health Connect; o al escribir datos en el dispositivo con postActivity/postBody/postNutrition.
