Интегрируйте мобильный SDK Terra API для источников здоровья на устройстве, у которых нет веб-API — Apple Health (HealthKit), Samsung Health и Health Connect. Используйте при подключении Apple Health, Samsung Health или Health Connect из мобильного приложения; при работе с TerraiOS, TerraAndroid, terra-react или terra_flutter_bridge; при создании токена авторизации мобильного SDK черезgenerAuthToken; при настройке фоновой доставки HealthKit, всплывающих окон разрешений initConnection, проверки getUserId, правил ProGuard для Samsung или разрешений манифеста Health Connect; или при записи данных на устройстве с помощью postActivity/postBody/postNutrition.
