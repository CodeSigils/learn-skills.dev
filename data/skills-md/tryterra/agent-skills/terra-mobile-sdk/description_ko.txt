웹 API가 없는 온디바이스 건강 소스(Apple Health(HealthKit), Samsung Health 및 Health Connect)를 위해 Terra API 모바일 SDK를 통합합니다. 모바일 앱에서 Apple Health, Samsung Health, Health Connect를 연결할 때 사용합니다. TerraiOS, TerraAndroid, terra-react 또는 terra_flutter_bridge로 작업할 때; generateAuthToken을 통해 모바일 SDK 인증 토큰을 생성할 때; HealthKit 백그라운드 전달, initConnection 권한 팝업, getUserId 유효성 검사, Samsung용 ProGuard 규칙 또는 Health Connect 매니페스트 권한을 구성할 때 또는 postActivity/postBody/postNutrition을 사용하여 기기 내 데이터를 작성할 때.
