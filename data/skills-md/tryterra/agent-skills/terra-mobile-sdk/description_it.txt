Integra l'SDK mobile Terra API per fonti sanitarie sul dispositivo che non dispongono di API Web: Apple Health (HealthKit), Samsung Health e Health Connect. Da utilizzare quando si collega Apple Health, Samsung Health o Health Connect da un'app mobile; quando si lavora con TerraiOS, TerraAndroid, terra-react o terra_flutter_bridge; quando si conia un token di autenticazione SDK mobile tramite generateAuthToken; durante la configurazione della distribuzione in background di HealthKit, dei popup di autorizzazione initConnection, della convalida getUserId, delle regole ProGuard per Samsung o delle autorizzazioni manifest di Health Connect; o quando si scrivono dati sul dispositivo con postActivity/postBody/postNutrition.
