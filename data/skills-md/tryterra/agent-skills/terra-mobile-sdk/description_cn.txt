为没有 Web API 的设备上健康源（Apple Health (HealthKit)、Samsung Health 和 Health Connect）集成 Terra API 移动 SDK。从移动应用程序连接 Apple Health、Samsung Health 或 Health Connect 时使用；使用 TerraiOS、TerraAndroid、terra-react 或 terra_flutter_bridge 时；通过generateAuthToken创建移动SDK身份验证令牌时；配置 HealthKit 后台交付、initConnection 权限弹出窗口、getUserId 验证、Samsung 的 ProGuard 规则或 Health Connect 清单权限时；或者使用 postActivity/postBody/postNutrition 写入设备上的数据时。
