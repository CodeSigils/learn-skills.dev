أفضل الممارسات لدمج Terra API - واجهة برمجة التطبيقات الموحدة لبيانات الصحة واللياقة البدنية لأكثر من 500 جهاز قابل للارتداء (Garmin، وFitbit، وOra، وWhoop، وApple Health، وStrava، وDexcom). استخدمه عند البناء باستخدام Terra API أو Tryterra.co، أو التعامل مع خطافات الويب الخاصة بـ terra-signature (X-Terra-Signature)، أو تخزين البيانات الصحية القابلة للارتداء (النشاط، والنوم، واليومي، والجسم، والتغذية، والحيض، والهرمونات)، أو إدارة اتصالات الأجهزة، أو دمج البيانات عبر أجهزة متعددة.
