Рекомендации по интеграции Terra API — унифицированного API данных о здоровье и фитнесе для более чем 500 носимых устройств (Garmin, Fitbit, Oura, Whoop, Apple Health, Strava, Dexcom). Используйте при сборке с помощью Terra API или tryterra.co, обработке веб-перехватчиков terra-signature (X-Terra-Signature), хранении носимых данных о здоровье (активность, сон, день, тело, питание, менструация, гормоны), управлении подключениями устройств или объединении данных с нескольких устройств.
