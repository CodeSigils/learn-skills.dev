Terra Lab Reports のベスト プラクティスと API リファレンス (プレリリース) – 臨床検査レポートの PDF と画像を構造化された標準化されたバイオマーカー データに変換します。血液検査結果の解析、バイオマーカーの抽出、LOINC または UCUM 単位コードへのマッピング、参照範囲の処理、lab_report.completed / lab_report.failed Webhook の処理、または PDF 検査結果および検査レポート OCR の操作を行う場合に使用します。非同期アップロード/標準化/配信ライフサイクル、イベント エンベロープ (event_id、upload_id)、階層化された結果モデル (ソース、バイオマーカー、測定、解釈、参照範囲)、不一致バイオマーカーの処理、スノーフレーク ID、冪等 Webhook 処理をカバーします。
