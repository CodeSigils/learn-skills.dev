أفضل الممارسات ومرجع واجهة برمجة التطبيقات (API) لتقارير Terra Lab (الإصدار التجريبي) - قم بتحويل ملفات PDF والصور الخاصة بتقارير المختبر السريري إلى بيانات مؤشرات حيوية منظمة وموحدة. يُستخدم عند تحليل نتائج اختبار الدم، أو استخراج المؤشرات الحيوية، أو التعيين إلى رموز وحدة LOINC أو UCUM، أو التعامل مع النطاقات المرجعية، أو التعامل مع خطافات الويب lab_report.Completed / lab_report.failed، أو العمل مع نتائج مختبر PDF وتقرير التعرف الضوئي على الحروف (OCR). يغطي دورة حياة التحميل/التوحيد/التسليم غير المتزامن، ومظروف الحدث (event_id، upload_id)، ونموذج النتائج ذو الطبقات (المصدر، والعلامة الحيوية، والقياس، والتفسير، والنطاقات المرجعية)، ومعالجة العلامات الحيوية غير المتطابقة، ومعرفات ندفة الثلج، ومعالجة خطاف الويب غير الفعال.
