Übertragen Sie GPS-Routen mit Terra API Routes (Vorabversion) an die Fitnessgeräte der Benutzer. Verwenden Sie es, wenn Sie GPS-Kurse oder Navigationsrouten erstellen, Wegpunkte und Kurspunkte definieren, eine Route an Garmin-, COROS- oder Wahoo-Geräte übertragen, GPX- oder FIT-Routenformate verarbeiten oder eine Turn-by-Turn-Navigation auf Wearables erstellen. Behandelt den „Erstellen-dann-Push“-Workflow, das RouteTemplate- und Waypoint-Datenmodell, anbieterspezifische Leitungsformate und Funktionslücken, kaskadierende erneute Pushvorgänge und das Löschen von Routen.
