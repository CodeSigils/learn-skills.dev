Terra API Routes (プレリリース) を使用して、GPS ルートをユーザーのフィットネス デバイスにプッシュします。 GPS コースまたはナビゲーション ルートの作成、ウェイポイントとコース ポイントの定義、Garmin、COROS、または Wahoo デバイスへのルートのプッシュ、GPX または FIT ルート形式の処理、またはウェアラブルへのターンバイターン ナビゲーションの構築時に使用します。作成してからプッシュするワークフロー、RouteTemplate と Waypoint データ モデル、プロバイダーごとのワイヤ形式と機能のギャップ、カスケードの再プッシュ、およびルートの削除について説明します。
