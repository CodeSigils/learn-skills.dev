ادفع مسارات نظام تحديد المواقع العالمي (GPS) إلى أجهزة اللياقة البدنية الخاصة بالمستخدمين باستخدام مسارات Terra API (الإصدار التجريبي). يُستخدم عند إنشاء دورات GPS أو مسارات التنقل، أو تحديد نقاط الطريق ونقاط المسار، أو دفع المسار إلى أجهزة Garmin أو COROS أو Wahoo، أو التعامل مع تنسيقات مسار GPX أو FIT، أو إنشاء التنقل خطوة بخطوة على الأجهزة القابلة للارتداء. يغطي سير عمل الإنشاء ثم الدفع، ونموذج بيانات RouteTemplate وWaypoint، وتنسيقات الأسلاك لكل مزود وفجوات الميزات، وعمليات إعادة الدفع المتتالية، وحذف المسار.
