Интеллектуальный процессор голосовых заметок с автоматической классификацией типов записи.
Классифицирует записи по 7 типам и генерирует заметки в формате для конкретного типа.

**ОБЯЗАТЕЛЬНО используйте этот навык, когда пользователь упоминает:**
- Обработка/сканирование голосовых заметок, голосовых заметок, записей
- Преобразование записей в заметки (встречи, лекции, интервью и т. д.)
- Обработка записей основных выступлений/лекций/подкастов → извлекает ключевые идеи + цитаты
- Обработка записей интервью → генерирует отчет об оценке с оценкой
- Обработка записей разговоров с клиентами/продажами → отслеживание обязательств и последующих действий.
- "帮我处理录音"、"语音备忘录"、"录音转笔记"

**Поддерживаемые типы записи (определяются автоматически):**
- встреча: Внутренние встречи → Список TODO с исполнителями
- основной доклад: Лекции/конференции/подкасты → Ключевые идеи + цитаты
- собеседование: Собеседование → Отчет об оценке с 5-мерной оценкой
- клиент: звонки по продажам/BD → отслеживание обязательств
- мозговой штурм: Мозговые штурмы → Идеи с технико-экономическим обоснованием
- консультация: Консультации экспертов → Обзор результатов
- примечание: Персональные голосовые заметки → Чистое форматирование текста.

**НЕ используйте, если:**
- Пользователь хочет записать звук (используйте системное приложение Voice Memos)
- Нужна только необработанная транскрипция без форматирования (используйте Gemini-Transcribe)
- Сканируйте заметки о встречах или извлекайте TODO из текстовых файлов (не голосовых заметок)
