自動録音タイプ分類機能を備えたスマートなボイスメモプロセッサ。
録音を 7 つのタイプに分類し、タイプ固有の形式のメモを生成します。

**ユーザーが次のことを言及した場合は、このスキルを使用する必要があります。**
- ボイスメモ、ボイスメモ、録音の処理/スキャン
- 録音をメモに変換します (会議、講義、インタビューなど)
- 基調講演/講演/ポッドキャストの録画を処理 → 重要な洞察と引用を抽出
- インタビュー録音を処理 → スコアリング付きの評価レポートを生成
- 顧客/営業電話の録音を処理 → 約束とフォローアップを追跡
- "帮我处理录音"、"语音备忘录"、"录音转笔记"

**サポートされている録画タイプ (自動検出):**
- 会議: 社内会議 → 担当者との TODO リスト
- 基調講演: 講演/カンファレンス/ポッドキャスト → 重要な洞察 + 引用
- 面接：就職面接 → 5次元スコアリングによる評価レポート
- 顧客: 営業/BD コール → コミットメント追跡
- ブレーンストーミング: ブレーンストーミング セッション → 実現可能性分析によるアイデア
- 相談: 専門家による相談 → 洞察の概要
- メモ: 個人的な音声メモ → クリーンなテキスト形式

**次の場合は使用しないでください**
- ユーザーは音声を録音したい（システムのボイスメモアプリを使用）
- フォーマットなしの生の転写のみが必要です (gemini-transcribe を使用)
- 会議メモをスキャンするか、テキスト ファイルから TODO を抽出します (ボイスメモではありません)。
