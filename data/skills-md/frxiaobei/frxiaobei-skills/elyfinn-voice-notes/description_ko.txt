자동 녹음 유형 분류 기능을 갖춘 스마트 음성 메모 프로세서입니다.
녹음 내용을 7가지 유형으로 분류하고 유형별 형식의 메모를 생성합니다.

**사용자가 다음을 언급할 때 이 기술을 사용해야 합니다.**
- 음성 메모, 음성 메모, 녹음 처리/스캔
- 녹음 내용을 노트로 변환(회의, 강의, 인터뷰 등)
- 기조연설/강의/팟캐스트 녹음 처리 → 핵심 인사이트 + 인용문 추출
- 인터뷰 녹음 진행 → 채점을 통한 평가 보고서 생성
- 고객/판매 통화 녹음 처리 → 약속 및 후속 조치 추적
- "帮我处理录음을"、"语음을 备忘录"、"录음을 转笔记"

**지원되는 녹음 유형(자동 감지):**
- 회의 : 내부 회의 → 담당자와의 TODO 목록
- 기조연설: 강의/컨퍼런스/팟캐스트 → 주요 인사이트 + 인용문
- 면접 : 직무면접 → 5차원 채점을 통한 평가보고서
- 고객 : 영업/BD 통화 → 약속 추적
- 브레인스토밍 : 브레인스토밍 → 타당성 분석을 통한 아이디어 도출
- 상담 : 전문가 상담 → Insights 요약
- 참고: 개인 음성 메모 → 깔끔한 텍스트 서식 지정

**다음과 같은 경우에는 사용하지 마세요**
- 사용자가 오디오를 녹음하려고 합니다(시스템 음성 메모 앱 사용).
- 형식화 없이 원시 전사만 필요합니다(gemini-transcribe 사용).
- 회의 메모를 스캔하거나 텍스트 파일에서 TODO를 추출합니다(음성 메모 제외).
