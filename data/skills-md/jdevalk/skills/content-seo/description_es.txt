Audita el borrador de una publicación de blog o la copia de una página para SEO a nivel de contenido: ajuste de la intención de búsqueda, ubicación de las frases clave, señales E-E-A-T (experiencia, conocimientos, autoridad, confiabilidad), utilidad y originalidad, frescura del contenido y enlaces internos. Úselo cuando el usuario pregunte "¿esta clasificación se clasificará?", "SEO verificará esta publicación", "auditoría SEO de contenido" u "optimizará esta publicación para la búsqueda", o de manera proactiva después de una revisión de legibilidad de una publicación que debe clasificarse. Para saber cómo se lee la prosa, utilice la habilidad "verificación de legibilidad"; para títulos y meta descripciones, utilice `metadata-check`; para SEO técnico en todo el sitio (mapas de sitio, datos estructurados, canónicos), utilice "astro-seo" o "seo estático".
