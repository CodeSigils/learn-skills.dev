Prüft und verbessert SEO für statische HTML-Sites. Verwenden Sie diese Option, wenn der Benutzer SEO auf einer statischen Website prüfen, einrichten oder verbessern möchte (Hugo, Jekyll, 11ty, Gatsby, Next.js statischer Export, handgerolltes HTML oder „wp-static-clone“-Ausgabe) oder Kopfmetadaten, strukturierte Daten, JSON-LD, Sitemaps, IndexNow, Open Graph-Bilder, Schema-Endpunkte, NLWeb, hreflang oder Suchmaschinenindizierung für eine statische Website erwähnt. Verwenden Sie für Astro-Projekte stattdessen „astro-seo“ – seine Rezepte erzeugen weniger handgerollte Boilerplate, indem sie über „@jdevalk/astro-seo-graph“ weitergeleitet werden.
