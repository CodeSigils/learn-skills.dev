تدقيق وتحسين SEO لمواقع HTML الثابتة. يُستخدم عندما يطلب المستخدم تدقيق أو إعداد أو تحسين تحسين محركات البحث على موقع ثابت (Hugo، أو Jekyll، أو 11ty، أو Gatsby، أو Next.js تصدير ثابت، أو HTML ملفوف يدويًا، أو إخراج `wp-static-clone`)، أو يذكر بيانات تعريف الرأس، أو البيانات المنظمة، أو JSON-LD، أو خرائط المواقع، أو IndexNow، أو صور الرسم البياني المفتوح، أو نقاط نهاية المخطط، أو NLWeb، أو hreflang، أو فهرسة محرك البحث لـ موقع ثابت. بالنسبة إلى مشاريع Astro، استخدم "astro-seo" بدلاً من ذلك - تنتج وصفاته كمية أقل من القوالب النمطية الملفوفة يدويًا عن طريق التوجيه عبر "@jdevalk/astro-seo-graph".
