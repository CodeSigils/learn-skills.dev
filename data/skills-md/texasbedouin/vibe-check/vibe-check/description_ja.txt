完全な初心者向けのアプリのアイデアを構築可能な計画に変換し、構築中に方向性を保ちます。コーディングをしたことがない人がアプリを構築したり「雰囲気のあるコーディング」をしたい場合、アイデアはあるがどこから始めればよいかわからない場合、またはそれを計画、MVP スコープ、技術スタック、ユーザー フロー、またはブループリントに変換したい場合に使用します。また、非プログラマーがビルド時の基礎を必要とする場合にも使用します。つまり、Git と GitHub とは何か、アカウントの作成、「コミットとプッシュ」、ローカルとステージングと本番環境、アプリをオンラインにする (デプロイ/配布)、API キーを安全に保管するなどです。そして、AI を使って構築した人が、「めちゃくちゃになった」「AI が物を壊し続けたり、堂々巡りを繰り返したりする」「コードに触れるのが怖い」「コードは整理されていますか」「クリーンアップしてもらえますか」と尋ねたときに、チェックアップ モードで使用します。 API、データベース、GitHub が何なのかを知らない人向けに構築されているため、「計画」や「アーキテクチャ」を決して言わない人に手を伸ばしてください。デバッグ、リファクタリング、または CI/CD のセットアップの経験豊富な開発者向けではありません。
