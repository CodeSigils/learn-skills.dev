将初学者的完整应用创意转变为可构建的计划，然后在构建时保持他们的导向。每当从未编码过的人想要构建或“氛围编码”应用程序、有想法但不知道从哪里开始，或者希望将其变成计划、MVP 范围、技术堆栈、用户流程或蓝图时，请使用它。当非编码人员需要构建时基础知识时，也可以使用它：什么是 Git 和 GitHub、创建帐户、“提交和推送”、本地与暂存与生产、将应用程序放到网上（部署/发布）或保持 API 密钥安全。当使用人工智能构建的人说它变得一团糟，人工智能不断破坏事物或原地踏步，他们害怕触摸他们的代码，或者他们问“我的代码是否组织良好”或“你能清理它吗”时，请在检查模式下使用它。专为那些不知道 API、数据库或 GitHub 是什么的人而构建，因此当他们从不说“计划”或“架构”时就可以使用它。不适合经验丰富的开发调试、重构或设置 CI/CD。
