Verifique que una característica ejecutada por el desarrollador se haya comportado correctamente analizando el tráfico HTTP capturado por Fiddler Everywhere. Utilice siempre esta habilidad cuando un desarrollador pregunte si las llamadas HTTP de su función se completaron correctamente, quiera ver qué solicitudes realizó una función, necesite depurar una llamada API fallida, esté verificando el tráfico después de ejecutar una función, quiera confirmar lo que devolvió cada punto final o pregunte si algo en el tráfico parece incorrecto, incluso si no usan la palabra "verificar" o "Fiddler". Resume la captura por punto final y señala posibles problemas, como llamadas fallidas, solicitudes de seguimiento faltantes, reintentos, errores de autenticación, tiempos de espera y patrones de códigos de estado sospechosos. Requiere que Fiddler Everywhere se ejecute con su servidor MCP habilitado.
