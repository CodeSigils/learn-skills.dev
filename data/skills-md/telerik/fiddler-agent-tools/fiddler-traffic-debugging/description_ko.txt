Fiddler Everywhere에서 캡처한 HTTP 트래픽을 분석하여 개발자 실행 기능이 올바르게 작동하는지 확인합니다. 개발자가 기능의 HTTP 호출이 올바르게 완료되었는지 묻고, 기능이 어떤 요청을 했는지 확인하고 싶고, 실패한 API 호출을 디버깅해야 하고, 기능 실행 후 트래픽을 확인하고 싶고, 각 엔드포인트가 반환한 내용을 확인하고 싶거나, 트래픽에 잘못된 부분이 있는지 묻는 경우 항상 이 기술을 사용하세요. "확인" 또는 "Fiddler"라는 단어를 사용하지 않더라도 마찬가지입니다. 엔드포인트별 캡처를 요약하고 호출 실패, 후속 ​​요청 누락, 재시도, 인증 실패, 시간 초과 및 의심스러운 상태 코드 패턴과 같은 문제에 플래그를 지정합니다. MCP 서버가 활성화된 상태에서 Fiddler Everywhere를 실행해야 합니다.
