Verifica che una funzionalità eseguita dallo sviluppatore si sia comportata correttamente analizzando il traffico HTTP acquisito da Fiddler Everywhere. Utilizza sempre questa competenza quando uno sviluppatore chiede se le chiamate HTTP della propria funzionalità sono state completate correttamente, vuole vedere quali richieste ha effettuato una funzionalità, deve eseguire il debug di una chiamata API non riuscita, controlla il traffico dopo aver eseguito una funzionalità, vuole confermare ciò che ciascun endpoint ha restituito o chiede se qualcosa nel traffico sembra sbagliato, anche se non utilizza la parola "verifica" o "Fiddler". Riepiloga l'acquisizione per endpoint e segnala problemi probabili come chiamate non riuscite, richieste di follow-up mancanti, nuovi tentativi, errori di autenticazione, timeout e modelli di codici di stato sospetti. Richiede che Fiddler Everywhere sia in esecuzione con il server MCP abilitato.
