Vérifiez qu'une fonctionnalité exécutée par un développeur s'est comportée correctement en analysant le trafic HTTP capturé par Fiddler Everywhere. Utilisez toujours cette compétence lorsqu'un développeur demande si les appels HTTP de sa fonctionnalité se sont terminés correctement, veut voir quelles requêtes une fonctionnalité a effectuée, doit déboguer un appel d'API qui a échoué, vérifie le trafic après l'exécution d'une fonctionnalité, veut confirmer ce que chaque point de terminaison a renvoyé ou demande si quelque chose dans le trafic semble faux, même s'il n'utilise pas le mot « vérifier » ou « Fiddler ». Résume la capture par point de terminaison et signale les problèmes probables tels que les appels échoués, les demandes de suivi manquantes, les tentatives, les échecs d'authentification, les délais d'attente et les modèles de code d'état suspects. Nécessite que Fiddler Everywhere soit exécuté avec son serveur MCP activé.
