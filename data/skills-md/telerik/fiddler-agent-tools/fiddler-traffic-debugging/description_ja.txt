Fiddler Everywhere によってキャプチャされた HTTP トラフィックを分析することで、開発者が実行した機能が正しく動作することを確認します。開発者が機能の HTTP 呼び出しが正しく完了したかどうかを尋ねる場合、機能が行ったリクエストを確認したい場合、失敗した API 呼び出しをデバッグする必要がある場合、機能の実行後にトラフィックをチェックしている場合、各エンドポイントが何を返したかを確認したい場合、またはトラフィック内の何かが間違っているように見えるかどうかを尋ねる場合は、「検証」や「Fiddler」という言葉を使用しない場合でも、常にこのスキルを使用してください。エンドポイントごとのキャプチャを要約し、失敗した呼び出し、フォローアップ要求の欠落、再試行、認証失敗、タイムアウト、疑わしいステータス コード パターンなどの可能性のある問題にフラグを立てます。 MCP サーバーを有効にして Fiddler Everywhere を実行する必要があります。
