Configure la conexión del servidor MCP de Fiddler Everywhere para las herramientas del agente de IA (Claude Code, GitHub Copilot CLI, GitHub Copilot en VS Code, Cursor, OpenAI Codex CLI). SIEMPRE use esta habilidad cuando las herramientas de Fiddler MCP no estén disponibles, no pueda ver las herramientas de Fiddler, obtenga un error de autenticación al conectarse a Fiddler, necesite configurar Fiddler MCP por primera vez o escuche errores de "herramienta no encontrada" al intentar usar otras habilidades de Fiddler. Llama al punto final API local de Fiddler para obtener o generar la clave API MCP automáticamente, escribe el archivo de configuración correcto para el agente detectado, lo ignora y verifica la conexión de un extremo a otro. El único requisito previo es que Fiddler Everywhere esté ejecutándose.
