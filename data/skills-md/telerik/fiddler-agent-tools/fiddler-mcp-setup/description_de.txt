Richten Sie die Fiddler Everywhere MCP-Serververbindung für AI-Agent-Tools ein (Claude Code, GitHub Copilot CLI, GitHub Copilot in VS Code, Cursor, OpenAI Codex CLI). Verwenden Sie diesen Skill IMMER, wenn die Fiddler MCP-Tools nicht verfügbar sind, Sie die Fiddler-Tools nicht sehen können, beim Herstellen einer Verbindung zu Fiddler ein Authentifizierungsfehler auftritt, Sie Fiddler MCP zum ersten Mal konfigurieren müssen oder wenn Sie die Fehlermeldung „Tool nicht gefunden“ hören, wenn Sie versuchen, andere Fiddler-Skills zu verwenden. Ruft den lokalen API-Endpunkt von Fiddler auf, um den MCP-API-Schlüssel automatisch abzurufen oder zu generieren, schreibt die richtige Konfigurationsdatei für den erkannten Agenten, ignoriert ihn und überprüft die Verbindung Ende-zu-Ende. Die einzige Voraussetzung ist, dass Fiddler Everywhere läuft.
