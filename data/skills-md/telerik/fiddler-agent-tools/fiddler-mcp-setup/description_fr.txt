Configurez la connexion au serveur Fiddler Everywhere MCP pour les outils d'agent IA (Claude Code, GitHub Copilot CLI, GitHub Copilot in VS Code, Cursor, OpenAI Codex CLI). Utilisez TOUJOURS cette compétence lorsque les outils Fiddler MCP ne sont pas disponibles, que vous ne pouvez pas voir les outils Fiddler, que vous obtenez une erreur d'authentification lors de la connexion à Fiddler, que vous devez configurer Fiddler MCP pour la première fois ou que vous entendez des erreurs « outil introuvable » lorsque vous essayez d'utiliser d'autres compétences Fiddler. Appelle le point de terminaison de l'API locale de Fiddler pour obtenir ou générer automatiquement la clé API MCP, écrit le fichier de configuration correct pour l'agent détecté, l'ignore par git et vérifie la connexion de bout en bout. La seule condition préalable est que Fiddler Everywhere soit exécuté.
