Configura la connessione al server MCP Fiddler Everywhere per gli strumenti dell'agente AI (Claude Code, GitHub Copilot CLI, GitHub Copilot in VS Code, Cursor, OpenAI Codex CLI). Utilizza SEMPRE questa competenza quando gli strumenti MCP di Fiddler non sono disponibili, non puoi visualizzare gli strumenti di Fiddler, ricevi un errore di autenticazione durante la connessione a Fiddler, devi configurare Fiddler MCP per la prima volta o senti gli errori "strumento non trovato" quando tenti di utilizzare altre competenze di Fiddler. Chiama l'endpoint API locale di Fiddler per ottenere o generare automaticamente la chiave API MCP, scrive il file di configurazione corretto per l'agente rilevato, lo ignora e verifica la connessione end-to-end. L'unico prerequisito è che Fiddler Everywhere sia in esecuzione.
