قم بإعداد اتصال خادم Fiddler Everywhere MCP لأدوات وكيل الذكاء الاصطناعي (Claude Code وGitHub Copilot CLI وGitHub Copilot in VS Code وCursor وOpenAI Codex CLI). استخدم هذه المهارة دائمًا عندما لا تكون أدوات Fiddler MCP متاحة، أو لا يمكنك رؤية أدوات Fiddler، أو تحصل على خطأ في المصادقة أثناء الاتصال بـ Fiddler، أو تحتاج إلى تكوين Fiddler MCP لأول مرة، أو تسمع أخطاء "لم يتم العثور على الأداة" عند محاولة استخدام مهارات Fiddler الأخرى. يستدعي نقطة نهاية واجهة برمجة التطبيقات المحلية الخاصة بـ Fiddler للحصول على مفتاح MCP API أو إنشائه تلقائيًا، ويكتب ملف التكوين الصحيح للوكيل المكتشف، ويتجاهله، ويتحقق من الاتصال من طرف إلى طرف. الشرط الوحيد هو أن يكون Fiddler Everywhere قيد التشغيل.
