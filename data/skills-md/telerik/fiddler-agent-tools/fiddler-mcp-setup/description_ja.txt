AI エージェント ツール (Claude Code、GitHub Copilot CLI、VS Code の GitHub Copilot、Cursor、OpenAI Codex CLI) 用に Fiddler Everywhere MCP サーバー接続をセットアップします。 Fiddler MCP ツールが利用できない場合、Fiddler ツールが表示されない場合、Fiddler への接続時に認証エラーが発生した場合、初めて Fiddler MCP を設定する必要がある場合、または他の Fiddler スキルを使用しようとすると「ツールが見つかりません」というエラーが聞こえる場合は、常にこのスキルを使用してください。 Fiddler のローカル API エンドポイントを呼び出して、MCP API キーを自動的に取得または生成し、検出されたエージェントの正しい構成ファイルを書き込み、gitignore して、接続をエンドツーエンドで検証します。唯一の前提条件は、Fiddler Everywhere が実行されていることです。
