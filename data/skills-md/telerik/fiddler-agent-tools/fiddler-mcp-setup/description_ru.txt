Настройте подключение к серверу Fiddler Everywhere MCP для инструментов агента AI (Claude Code, GitHub Copilot CLI, GitHub Copilot в VS Code, Cursor, OpenAI Codex CLI). ВСЕГДА используйте этот навык, когда инструменты Fiddler MCP недоступны, вы не можете видеть инструменты Fiddler, получаете ошибку аутентификации при подключении к Fiddler, вам необходимо впервые настроить Fiddler MCP или слышите ошибки «инструмент не найден» при попытке использовать другие навыки Fiddler. Вызывает локальную конечную точку API Fiddler для автоматического получения или создания ключа API MCP, записывает правильный файл конфигурации для обнаруженного агента, игнорирует его с помощью git и проверяет сквозное соединение. Единственное необходимое условие — запуск Fiddler Everywhere.
