전문적인 PPT 프레젠테이션 엔드투엔드 AI 생성 도우미. 최고의 PPT 디자인 회사의 전체 워크플로우(연구 필요 → 데이터 수집 → 개요 계획 → 계획 초안 → 디자인 초안)를 시뮬레이션하여 고품질 HTML 형식 프레젠테이션을 출력합니다. 이 기능은 사용자가 PPT 만들기, 프레젠테이션 만들기, 슬라이드, 슬라이드쇼, 보고 자료, 교육 코스웨어, 로드쇼 데크 또는 제품 소개 페이지를 언급할 때마다 실행됩니다. 사용자가 "X에 대해 소개하는 데 도움을 주세요." 또는 "Y를 상사에게 보고해야 합니다."라고만 말하더라도 구조화된 여러 페이지 프레젠테이션이 필요하다는 점을 암시하는 한 해당 내용이 실행되어야 합니다. 또한 사용자가 "이 문서를 PPT로 변환하는 데 도움을 주세요.", "이 주제를 프레젠테이션으로 만들어 주세요."라고 말하거나 콘텐츠를 프레젠테이션 형식으로 변환하라는 기타 요청을 하는 시나리오에도 적용됩니다.
