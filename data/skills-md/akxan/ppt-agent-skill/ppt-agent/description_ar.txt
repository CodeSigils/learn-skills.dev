مساعد توليد الذكاء الاصطناعي الشامل لعرض PPT الاحترافي. يحاكي سير العمل الكامل لأفضل شركات تصميم PPT (بحث المتطلبات ← جمع البيانات ← التخطيط التفصيلي ← مسودة الخطة ← مسودة التصميم)، وإخراج عروض تقديمية بتنسيق HTML عالية الجودة. يتم تشغيل هذه المهارة عندما يذكر المستخدم إنشاء عرض PPT، أو تقديم عرض تقديمي، أو شرائح، أو عرض شرائح، أو مواد إعداد تقارير، أو برامج تعليمية تدريبية، أو عرض ترويجي، أو صفحة مقدمة للمنتج، وما إلى ذلك. حتى لو قال المستخدم فقط "ساعدني في تقديم مقدمة حول X" أو "أحتاج إلى إبلاغ المدير بـ Y"، طالما أنه يلمح إلى الحاجة إلى عرض تقديمي منظم متعدد الصفحات، فيجب تفعيل هذه المهارة. وينطبق أيضًا على السيناريوهات التي يقول فيها المستخدم "ساعدني في تحويل هذا المستند إلى PPT"، و"اجعل هذا الموضوع في عرض تقديمي"، والحالات الأخرى التي يلزم فيها تحويل المحتوى إلى تنسيق عرض تقديمي.

يرجى الرد دائمًا بلغة المستخدم.
