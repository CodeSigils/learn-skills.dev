عرض PPT احترافي لمساعد توليد الذكاء الاصطناعي الشامل. يحاكي سير العمل الكامل لأفضل شركات تصميم PPT (يحتاج إلى بحث ← جمع البيانات ← التخطيط التفصيلي ← مسودة التخطيط ← مسودة التصميم)، وإخراج عروض تقديمية بتنسيق HTML عالية الجودة. يتم تشغيل هذه الإمكانية عندما يذكر المستخدم إنشاء ملف PPT، أو تقديم عرض تقديمي، أو شرائح، أو عرض شرائح، أو مواد إعداد التقارير، أو برامج تعليمية تدريبية، أو عرض ترويجي، أو صفحة مقدمة للمنتج. حتى لو قال المستخدم فقط "ساعدني في تقديم مقدمة حول X" أو "أحتاج إلى إبلاغ مديري بـ Y"، طالما أن ذلك يشير ضمنًا إلى الحاجة إلى عرض تقديمي منظم متعدد الصفحات، فيجب تشغيله. وينطبق أيضًا على السيناريوهات التي يقول فيها المستخدم "ساعدني في تحويل هذا المستند إلى PPT" أو "اجعل هذا الموضوع في عرض تقديمي" أو أي طلب آخر لتحويل المحتوى إلى تنسيق عرض تقديمي.

يرجى الرد دائمًا بلغة المستخدم.
