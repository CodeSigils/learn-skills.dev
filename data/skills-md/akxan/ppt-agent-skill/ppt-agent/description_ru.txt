Профессиональный комплексный помощник по созданию ИИ-презентаций для презентаций PPT. Имитирует полный рабочий процесс ведущей дизайнерской фирмы PPT (необходимы исследования → сбор материалов → эскизное планирование → черновой вариант планирования → проектный проект), выводя высококачественные презентации в формате HTML. Этот навык срабатывает всякий раз, когда пользователь упоминает создание PPT, создание презентации, слайдов, слайд-шоу, материалов для отчетов, обучающих курсов, роуд-шоу, страницы с описанием продукта и т. д. Даже если пользователь говорит только «Помогите мне рассказать об X» или «Мне нужно сообщить об Y начальнику», если они подразумевают необходимость структурированного многостраничного контента презентации, его следует активировать. Это также применимо к сценариям, когда пользователь говорит: «Помогите мне превратить этот документ в PPT» или «Сделайте презентацию по этой теме», т. е. когда контент необходимо преобразовать в формат презентации.
