Wireframe-first pass : génère une mise en page ASCII + une liste d'états + un inventaire de contenu + une liste de questions avant tout code. À utiliser lors du démarrage d'un nouvel écran à partir de zéro ou lorsque le brief de l'utilisateur est encore ambigu. Invoquer lorsque l'utilisateur demande une forme sur son interface utilisateur ou mentionne « forme » à côté du travail de conception/interface utilisateur/frontend.
