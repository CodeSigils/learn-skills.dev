One-Shot-Build-Pipeline für eine vollständige Oberfläche aus einem Ergebnisrezept – Eingaben (oder Standardeinstellungen) → Zusammensetzung → Thema → Build-Reihenfolge → Akzeptanzleiste. Verwenden Sie diese Option, wenn der Benutzer nach einer vollständigen Oberfläche fragt („baue mir ein Dashboard“, „hazme un Dashboard“) und ein versandfähiges Ergebnis erwartet, keine Hilfe auf Komponentenebene. Wird aufgerufen, wenn der Benutzer auf seiner Benutzeroberfläche nach „Craft“ fragt oder „Craft“ neben Design-/UI-/Frontend-Arbeit erwähnt.
