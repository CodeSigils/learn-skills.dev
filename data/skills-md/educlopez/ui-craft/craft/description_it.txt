Pipeline di creazione one-shot per una superficie completa da una ricetta di risultato: input (o valori predefiniti) → composizione → tema → ordine di creazione → barra di accettazione. Da utilizzare quando l'utente richiede un'intera superficie ("costruiscimi una dashboard", "hazme un dashboard") e si aspetta un risultato consegnabile, non un aiuto a livello di componente. Richiama quando l'utente richiede craft sulla propria interfaccia utente o menziona "craft" insieme al lavoro di progettazione/interfaccia utente/frontend.
