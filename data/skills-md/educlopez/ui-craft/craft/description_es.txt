Canal de construcción de una sola vez para una superficie completa a partir de una receta de resultado: entradas (o valores predeterminados) → composición → tema → orden de construcción → barra de aceptación. Úselo cuando el usuario solicite una superficie completa ("constrúyame un panel", "hazme un panel") y espera un resultado entregable, no ayuda a nivel de componente. Invocar cuando el usuario solicita artesanía en su interfaz de usuario o menciona "artesanía" junto con el trabajo de diseño/UI/frontend.
