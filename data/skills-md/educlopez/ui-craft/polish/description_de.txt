Abschließender Basteldurchlauf, bei dem die zusammengesetzten Details aus der polnischen Checkliste – Mikrotypografie, Abstandsrhythmus, Schwebezustände und ein Signaturdetail – direkt in den Code übernommen werden. Verwenden Sie es, wenn die Oberfläche funktionell vollständig ist, sich aber unvollendet anfühlt, oder wenn der Benutzer sagt: „Polieren Sie dies“ / „Sie sieht allgemein aus“ / „Fügen Sie den letzten Schliff hinzu“. Rufen Sie es auf, wenn der Benutzer nach einer Verfeinerung seiner Benutzeroberfläche fragt oder „Verfeinerung“ neben der Arbeit an Design, Benutzeroberfläche und Frontend erwähnt.
