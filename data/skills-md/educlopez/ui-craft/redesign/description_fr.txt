Repensez un site ou une application existante sans perdre ce qui fonctionne déjà : audite d'abord la surface actuelle, classe ce qu'il faut préserver (marque, IA, référencement, contenu), choisit une portée d'actualisation/relookage/reconstruction, puis modernise délibérément. À utiliser lorsque l'utilisateur dit « repenser », « moderniser ce site », « actualiser l'interface utilisateur », « rendre cela actuel » ou pointe vers une page/URL existante qu'il souhaite améliorer plutôt que reconstruite à partir de zéro. Invoquer lorsque l'utilisateur demande une refonte de son interface utilisateur ou mentionne « refonte » à côté du travail de conception/interface utilisateur/frontend.
