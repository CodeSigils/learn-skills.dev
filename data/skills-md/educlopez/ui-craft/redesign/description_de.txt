Gestalten Sie eine bestehende Website oder App neu, ohne dass dabei verloren geht, was bereits funktioniert – prüft zunächst die aktuelle Oberfläche, klassifiziert, was beibehalten werden soll (Marke, IA, SEO, Inhalt), wählt einen Aktualisierungs-/Reskin-/Neuerstellungsbereich aus und führt dann eine bewusste Modernisierung durch. Verwenden Sie diese Option, wenn der Benutzer sagt: „Neu gestalten“, „Diese Website modernisieren“, „Benutzeroberfläche aktualisieren“, „Dieses Erscheinungsbild auf den neuesten Stand bringen“ oder auf eine vorhandene Seite/URL verweist, die verbessert werden soll, anstatt von Grund auf neu erstellt zu werden. Wird aufgerufen, wenn der Benutzer eine Neugestaltung seiner Benutzeroberfläche anfordert oder „Neugestaltung“ neben der Design-/Benutzeroberflächen-/Frontend-Arbeit erwähnt.
