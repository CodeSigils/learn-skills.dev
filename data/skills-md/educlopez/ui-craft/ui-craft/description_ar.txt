المهارة الهندسية القصوى لتصميم واجهة المستخدم - إنشاء واجهات وتحريكها ومراجعتها وصقلها بجودة على مستوى الحرف اليدوية. يغطي الرسوم المتحركة، والتخفيف، والينابيع، والتوقيت، والتخطيط، والتباعد، والطباعة، واللون، وإمكانية الوصول، والنماذج، والتفاعلات، والأداء، والتصميم سريع الاستجابة، وتصميم الصوت، ونسخة UX، ومراجعة واجهة المستخدم المنهجية. استخدم هذه المهارة بشكل استباقي في أي وقت: إنشاء مكونات واجهة المستخدم، أو إضافة رسوم متحركة أو انتقالات، أو مراجعة/نقد كود الواجهة، أو تلميع واجهة المستخدم الحالية أو تحسينها، أو العمل مع التخفيف/الزنبركات/التوقيت/الحركة، أو القيام بالتخطيط/التباعد/الطباعة/الألوان، أو تنفيذ النماذج/التفاعلات/إمكانية الوصول، أو تحسين أداء الرسوم المتحركة، أو إعداد أنظمة التصميم أو الرموز المميزة، أو القيام بتصميم سريع الاستجابة/متكيف، أو إضافة صوت إلى واجهة المستخدم، أو عندما يذكر المستخدم: تحريك، انتقال، تخفيف، ربيع، حركة، تخطيط، تباعد، طباعة، لون، تلميع، مراجعة، نقد، تدقيق، إمكانية الوصول، a11y، استجابة، الوضع المظلم، نظام التصميم، ضبط، قرص، تحويم، مشروط، درج، تلميح الأدوات، بوبوفر، نخب، سحب، إيماءة، تمرير الرسوم المتحركة، عرض التحولات، الأداء، غير المرغوب فيه، 60 إطارا في الثانية، انخفاض الحركة، واجهة المستخدم، UX، الواجهة، المكون.
