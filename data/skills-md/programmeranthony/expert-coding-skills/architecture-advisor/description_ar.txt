يُستخدم عندما يحتاج المستخدمون إلى تصميم بنية نظام جديدة، أو مراجعة بنية النظام الحالي أو تحسينها، أو تحديد الحلول التقنية. سيناريوهات التشغيل: تحليل الهندسة المعمارية، تصميم الهندسة المعمارية، تصميم النظام، الهندسة المعمارية، تحسين الهندسة المعمارية، بنية النظام، مراجعة الهندسة المعمارية، الاستشارات المعمارية، الحلول التقنية، التصميم الفني، كيفية تنظيم هيكل التعليمات البرمجية، تقسيم الوحدة النمطية، تقسيم الخدمة، اختيار قاعدة البيانات، تصميم الخدمات الصغيرة.
