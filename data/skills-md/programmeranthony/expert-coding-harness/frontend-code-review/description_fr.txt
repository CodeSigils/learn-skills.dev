À utiliser lorsqu'un utilisateur doit examiner le code frontal (React, Vue, Next.js, TypeScript, Tailwind, etc.), vérifier la qualité du code, les problèmes de performances, la maintenabilité, les vulnérabilités de sécurité et la mise en œuvre des meilleures pratiques. Scénarios de déclenchement : révision du code front-end, optimisation du code front-end, inspection du code React/Vue, révision du code TypeScript, optimisation des performances front-end, audit de sécurité front-end, vérification des normes du code front-end.
