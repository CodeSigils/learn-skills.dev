Da utilizzare quando un utente deve rivedere il codice front-end (React, Vue, Next.js, TypeScript, Tailwind e così via), verificare la qualità del codice, i problemi di prestazioni, la manutenibilità, le vulnerabilità della sicurezza e l'implementazione delle migliori pratiche. Scenari di attivazione: revisione del codice front-end, ottimizzazione del codice front-end, ispezione del codice React/Vue, revisione del codice TypeScript, ottimizzazione delle prestazioni front-end, audit di sicurezza front-end, controllo degli standard del codice front-end.
