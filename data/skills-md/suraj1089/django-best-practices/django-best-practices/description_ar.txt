دليل أفضل الممارسات لـ Django وDjango REST Framework. استخدم هذه المهارة لمراجعة تطبيقات Django ذات الأداء وتحسينها وتصميمها وكتابتها. يتم تشغيله عندما يطلب المستخدم تنفيذ أو مراجعة نماذج Django، أو استعلامات ORM، أو واجهات برمجة تطبيقات DRF، أو مهام Celery، أو عمال الخلفية، أو WebSockets (القنوات)، أو منطق التخزين المؤقت، أو الاختبارات.
