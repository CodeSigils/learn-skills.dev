React と Next.js のベスト プラクティス ガイド。 React コンポーネントまたは Next.js コードを作成、レビュー、最適化、またはリファクタリングするときにこのスキルを使用します。パフォーマンスの問題、古いクロージャ、不要な再レンダリング、サーバー コンポーネント (RSC)、データ フェッチ、サスペンス ストリーミング、useTransition/useDeferredValue、コンポーネントの構成、およびメモ化/ref について説明します。 「React パフォーマンス」、「React 最適化」、「古いクロージャー」、「再レンダリング」、「React 19」、「サーバー コンポーネント」、「サスペンス」、「useTransition」、「リスト内のキー」などのフレーズでトリガーします。ユーザーが本番環境に対応した、またはパフォーマンスの高い React コードを要求したときにアクティブ化します。
