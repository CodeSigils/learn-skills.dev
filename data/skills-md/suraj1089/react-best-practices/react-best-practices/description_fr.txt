Guide des bonnes pratiques React et Next.js. Utilisez cette compétence lors de l'écriture, de la révision, de l'optimisation ou de la refactorisation des composants React ou du code Next.js. Couvre les problèmes de performances, les fermetures obsolètes, les rendus inutiles, les composants serveur (RSC), la récupération de données, le streaming Suspense, useTransition/useDeferredValue, la composition des composants et la mémorisation/références. Déclenchez des expressions telles que « Performances de React », « Optimisation de React », « Fermeture obsolète », « Rendus », « React 19 », « Composants du serveur », « Suspense », « useTransition » ou « Clés dans les listes ». Activez lorsque l'utilisateur demande du code React prêt pour la production ou performant.
