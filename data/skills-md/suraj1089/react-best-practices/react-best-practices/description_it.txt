Guida alle best practice per React e Next.js. Utilizza questa competenza durante la scrittura, la revisione, l'ottimizzazione o il refactoring dei componenti React o del codice Next.js. Copre problemi di prestazioni, chiusure obsolete, nuovi rendering non necessari, componenti server (RSC), recupero dei dati, streaming di suspense, useTransition/useDeferredValue, composizione dei componenti e memoizzazione/riferimenti. Attiva frasi come "Prestazioni React", "React ottimizza", "chiusura obsoleta", "re-render", "React 19", "Componenti server", "Suspense", "useTransition" o "chiavi negli elenchi". Attiva quando l'utente richiede un codice React pronto per la produzione o performante.
