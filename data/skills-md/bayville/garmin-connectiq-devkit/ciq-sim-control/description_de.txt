Steuern Sie den Garmin Connect IQ-Simulator für jedes Monkey C-Projekt – legen Sie den Gerätestatus fest (Akku, Aufladen, DND, Benachrichtigungen, Farbwechsel, Ruhezustand, Einheiten, Zeit), wechseln Sie Wetter und AOD/Anzeigemodus, führen Sie wiederverwendbare Szenariokonfigurationen aus, erstellen Sie eine Screenshot-Galerie und erfassen Sie Store-Screenshots. Verwenden Sie diese Option immer dann, wenn Sie dazu aufgefordert werden, den Simulator zu starten/auszuführen, einen Gerätezustand zu reproduzieren, zu testen, wie Code in einem bestimmten Zustand gerendert wird, einen Screenshot eines Zifferblatts/einer App zu erstellen oder die Testautomatisierung des Simulators auszuführen. File-First und deterministisch; KI orchestriert nur.
