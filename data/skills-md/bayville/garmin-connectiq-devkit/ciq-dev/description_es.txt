Desarrolle aplicaciones Garmin Connect IQ y esferas de reloj en Monkey C con este kit de herramientas: cree con una estricta verificación de tipos (nivel 3), escriba y ejecute pruebas unitarias, verifique los cambios en el simulador, ejecute la puerta de preparación para la publicación y encuentre los documentos y pautas de diseño del SDK de Garmin correctos. Úselo siempre que escriba o cambie el código Monkey C (.mc), esferas de reloj, campos de datos, widgets o aplicaciones de dispositivos; cuando una compilación tiene errores de tipo/advertencia; o al preparar una aplicación para Connect IQ Store. Rutas a los scripts de compilación/prueba/verificación y las habilidades de configuración y control del simulador.
