Développez des applications Garmin Connect IQ et des cadrans de montre dans Monkey C avec cette boîte à outils : créez avec une vérification de type stricte (niveau 3), écrivez et exécutez des tests unitaires, vérifiez les modifications dans le simulateur, exécutez la porte de préparation à la publication et trouvez les bons documents et directives de conception du SDK Garmin. À utiliser lors de l'écriture ou de la modification du code Monkey C (.mc), des cadrans de montre, des champs de données, des widgets ou des applications d'appareil ; lorsqu'une build contient des erreurs de type/d'avertissement ; ou lors de la préparation d'une application pour le Connect IQ Store. Itinéraires vers les scripts de construction/test/vérification et les compétences de contrôle et de configuration du simulateur.
