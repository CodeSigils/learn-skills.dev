Cubre figuras matplotlib listas para publicación para artículos académicos, diapositivas e informes (barras, tendencias, dispersión, mapas de calor y diseños de paneles múltiples) con el estilo propio de este repositorio, las convenciones de exportación de impresión/vectores y la paridad con las demostraciones de figure4papers. Úselo cuando el usuario esté finalizando o creando dichas figuras en matplotlib. No lo utilice para paneles interactivos o visualizaciones web (Plotly, Altair, Bokeh), gráficos solo exploratorios sin un objetivo de publicación, mapas geográficos o 3D dominantes, ni flujos de trabajo infográficos exclusivos de Illustrator/Figma.
