AI raw-image prompt assistant tool, aimed at Chinese users. Based on the fundamental principles of diffusion models (CLIP/T5 encoders, cross‑attention mechanism, CFG guidance), it helps users create high‑quality raw-image prompts and can also diagnose and fix faulty prompts. Supports Midjourney, Stable Diffusion, DALL‑E, ChatGPT raw images, Gemini, Flux, Jimo, Kelin, Tongyi Wanxiang, ComfyUI. Whenever a user wants to generate an image, write/optimize a raw-image prompt, diagnose why a generated image is incorrect, or discuss AI drawing techniques, use this skill immediately—even if the user casually says “help me draw something,” it should be employed.
