Strumento di assistente rapido per immagini RAW AI, rivolto agli utenti cinesi. Basato sui principi fondamentali dei modelli di diffusione (codificatori CLIP/T5, meccanismo di attenzione incrociata, guida CFG), aiuta gli utenti a creare prompt di immagini grezze di alta qualità e può anche diagnosticare e correggere prompt errati. Supporta Midjourney, Diffusione stabile, DALL‑E, immagini raw ChatGPT, Gemini, Flux, Jimo, Kelin, TongyiWanxiang, ComfyUI. Ogni volta che un utente desidera generare un'immagine, scrivere/ottimizzare un prompt di un'immagine grezza, diagnosticare il motivo per cui un'immagine generata non è corretta o discutere le tecniche di disegno dell'intelligenza artificiale, utilizzare immediatamente questa abilità, anche se l'utente dice casualmente "aiutami a disegnare qualcosa", dovrebbe essere impiegata.
