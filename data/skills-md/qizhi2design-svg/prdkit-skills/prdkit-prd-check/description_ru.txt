Этот навык используется, когда пользователь запрашивает обзор, проверку, выявление проблем, исправление ошибок или предложения по улучшению PRD, документа с требованиями, плана продукта или документа проектирования системы. Сначала он определяет целевой PRD с помощью интерфейса командной строки набора Prdkit, затем завершает доработку продукта и оценку его пригодности, выводит результаты по 14 измерениям и, наконец, объединяет основные риски, список приоритетных проблем и основные рекомендации по улучшению.
