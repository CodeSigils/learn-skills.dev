When a user asks for an audit, review, inspection, problem identification, vulnerability fixing, or improvement suggestions for a PRD, requirement document, product proposal, or system design document, use this skill. The skill first locates the target PRD via the prdkit CLI, then completes product finalization and suitability assessment, outputs findings across 14 dimensions one by one, and finally aggregates major risks, a prioritized issue list, and top improvement recommendations.
