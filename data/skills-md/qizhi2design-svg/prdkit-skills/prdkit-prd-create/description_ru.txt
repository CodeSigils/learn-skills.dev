Этот навык используется, когда пользователь запрашивает написать PRD, создать PRD, сгенерировать документ с требованиями, организовать план продукта, дополнить документацию по продукту или вывести документы с требованиями высокой/средней/низкой сложности. Навык состоит из двухэтапного процесса: на первом этапе проверяется статус проекта Prdkit, сканируется контекст, завершается доработка продукта и оценка его сложности, заполняет недостающую информацию с помощью структурированных вопросов и пишет черновик плана в форматеdraft/reference/<title>-prd-plan.md; второй этап, только после того, как пользователь подтвердит черновик плана, вызывает `prdkit prd create --from-plan` для создания официального проекта PRD underworkspace/prds, затем завершает формальный контент в соответствии со сложностью и типом продукта.
