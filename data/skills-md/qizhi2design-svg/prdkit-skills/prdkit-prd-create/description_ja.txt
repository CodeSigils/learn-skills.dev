ユーザーが PRD の作成、PRD の開始、要件ドキュメントの生成、製品計画の整理、製品ドキュメントの補足、または高/中/低複雑さの要件ドキュメントの出力を要求する場合、このスキルが使用されます。このスキルは 2 段階のプロセスに従います。第 1 段階では、prdkit プロジェクトのステータスをチェックし、コンテキストをスキャンし、製品の最終化と複雑さの評価を完了し、構造化された質問を通じて不足している情報を埋め、計画草案をdraft/reference/<title>-prd-plan.md に書き込みます。第 2 段階では、ユーザーが計画草案を確認した後にのみ、「prdkit prd create --from-plan」を呼び出して、ワークスペース/prd の下に公式の PRD 最初の草案を生成し、複雑さと製品タイプに従って正式なコンテンツを完成させます。
