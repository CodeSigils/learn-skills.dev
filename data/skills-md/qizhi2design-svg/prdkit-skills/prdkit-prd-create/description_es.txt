Cuando un usuario solicita escribir un PRD, iniciar un PRD, generar documentos de requisitos, organizar planes de productos, complementar la documentación del producto o generar documentos de requisitos de alta/media/baja complejidad, se utiliza esta habilidad. La habilidad sigue un proceso de dos etapas: la primera etapa verifica el estado del proyecto prdkit, analiza el contexto, completa la finalización del producto y la evaluación de la complejidad, completa la información faltante a través de preguntas estructuradas y escribe el borrador del plan en borrador/referencia/<título>-prd-plan.md; En la segunda etapa, solo después de que el usuario confirma el borrador del plan, invoca `prdkit prd create --from-plan` para generar el primer borrador oficial del PRD underworkspace/prds, y luego completa el contenido formal de acuerdo con la complejidad y el tipo de producto.
