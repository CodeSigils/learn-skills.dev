When a user asks to write a PRD, start a PRD, generate requirement documents, organize product plans, supplement product documentation, or output high/medium/low‑complexity requirement documents, this skill is used. The skill follows a two‑stage process: the first stage checks the prdkit project status, scans the context, completes product finalization and complexity assessment, fills in missing information through structured questioning, and writes the plan draft to draft/reference/<title>-prd-plan.md; the second stage, only after the user confirms the plan draft, invokes `prdkit prd create --from-plan` to generate the official PRD first draft under workspace/prds, and then completes the formal content according to the complexity and product type.
