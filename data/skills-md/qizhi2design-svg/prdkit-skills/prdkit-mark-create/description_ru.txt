Используется, когда пользователь копирует информацию об элементе из средства просмотра. Этот навык сначала анализирует контекст элемента и существующие аннотации, подтверждает намерение пользователя выполнить операцию, затем уточняет содержание аннотации с помощью структурированных вопросов и, наконец, вызывает команду prdkitmarkcreate для создания аннотации.
