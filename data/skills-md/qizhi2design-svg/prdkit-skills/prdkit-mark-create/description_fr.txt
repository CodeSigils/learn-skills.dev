Utilisé lorsque l'utilisateur copie les informations sur les éléments à partir du visualiseur. Cette compétence analyse d'abord le contexte de l'élément et les annotations existantes, confirme l'intention de l'utilisateur, puis clarifie le contenu de l'annotation grâce à des questions structurées et appelle enfin la commande prdkit mark create pour créer l'annotation.
