Lorsque l'utilisateur demande à réinjecter le prototype dans le PRD, à synchroniser les mises à jour du prototype avec le document d'exigences, à intégrer le contenu des marques dans un PRD spécifié, à réviser les descriptions d'exigences spécifiques en fonction du prototype, à ajouter des liens de prototype ou à générer des enregistrements de révision du PRD, cette compétence utilise la CLI prdkit pour localiser le PRD et le prototype cibles, lit les marques, identifie les sections d'exigences correspondantes dans le PRD, compare les différences avec le contenu existant et réécrit les résultats de la révision directement dans le PRD.
