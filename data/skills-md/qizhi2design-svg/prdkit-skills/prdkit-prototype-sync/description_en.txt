When the user requests to feed the prototype back into the PRD, sync prototype updates to the requirement document, embed mark content into a specified PRD, revise specific requirement descriptions based on the prototype, add prototype links, or generate PRD revision records, this skill uses the prdkit CLI to locate the target PRD and prototype, reads the marks, identifies the corresponding requirement sections in the PRD, compares the differences with the existing content, and writes the revision results directly back to the PRD.
