Когда пользователь запрашивает создание прототипа, запуск прототипа, создание прототипа страницы, создание мобильного прототипа или создание серверного прототипа ПК, этот навык следует двухэтапному процессу: сначала сгенерируйте документ предложения и дождитесь подтверждения пользователя, затем создайте прототип.
