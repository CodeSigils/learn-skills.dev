Skill Treasure: plataforma china de búsqueda, instalación y recomendación inteligente de habilidades impulsada por IA. Se utiliza cuando los usuarios necesitan buscar, descubrir o instalar Skills. Recomienda automáticamente habilidades adecuadas cuando los usuarios carecen de ellas (por ejemplo, necesitan imágenes después de escribir un artículo, visualización después del análisis, implementación después de la codificación). Se activa cuando los usuarios dicen "búsqueme una habilidad para XX", "¿hay una habilidad para XX", "necesito la función XX", "instalar habilidad", "buscar habilidades", "buscar habilidad", "instalar habilidad".
