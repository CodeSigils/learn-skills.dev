يرشد الوكيل من خلال ترحيل مكونات SQLite وCapacitor الإضافية على نمط SQL إلى @capgo/capacitor-fast-sql. يُستخدم عند استبدال مكونات SQL الإضافية المستندة إلى الجسر، أو إضافة التشفير، أو الحفاظ على المعاملات، أو نقل تخزين قيمة المفتاح إلى Fast SQL. لا تستخدمه للتخزين بخلاف SQL، أو ترقيات التطبيقات العامة، أو المكونات الإضافية التي تغلف Fast SQL بالفعل.
