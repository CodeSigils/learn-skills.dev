Führt den Agenten durch die Migration von SQLite- und SQL-ähnlichen Capacitor-Plugins zu @capgo/capacitor-fast-sql. Verwenden Sie es, wenn Sie Bridge-basierte SQL-Plugins ersetzen, Verschlüsselung hinzufügen, Transaktionen beibehalten oder den Schlüsselwertspeicher auf Fast SQL verschieben. Nicht für Nicht-SQL-Speicher, generische App-Upgrades oder Plugins verwenden, die Fast SQL bereits umschließen.
