Guía para migrar una aplicación web, PWA o SPA existente a una aplicación Capacitor para iOS y Android lista para la tienda. Utilice esta habilidad cuando los usuarios quieran empaquetar o convertir una aplicación web en una aplicación móvil, evitar el rechazo de la tienda de aplicaciones WebView, agregar una experiencia de usuario nativa, manejar permisos, comportamiento fuera de línea, eliminación de cuentas, facturación, pruebas y actualizaciones en vivo de Capgo.
