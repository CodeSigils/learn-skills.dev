Guide pour la migration d'une application Web, d'une PWA ou d'un SPA existant vers une application Capacitor iOS et Android prête à être stockée. Utilisez cette compétence lorsque les utilisateurs souhaitent envelopper ou convertir une application Web en application mobile, éviter le rejet léger de la boutique d'applications WebView, ajouter une UX native, gérer les autorisations, le comportement hors ligne, la suppression de compte, la facturation, les tests et les mises à jour en direct de Capgo.
