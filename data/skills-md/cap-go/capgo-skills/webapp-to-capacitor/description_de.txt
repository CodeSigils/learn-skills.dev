Leitfaden für die Migration einer vorhandenen Web-App, PWA oder SPA in eine Store-fähige Capacitor-App für iOS und Android. Verwenden Sie diese Fähigkeit, wenn Benutzer eine Web-App in eine mobile App umschließen oder konvertieren, die Ablehnung von Thin WebView App Stores vermeiden, eine native Benutzeroberfläche hinzufügen, Berechtigungen, Offline-Verhalten, Kontolöschung, Abrechnung, Tests und Capgo-Live-Updates verwalten möchten.
