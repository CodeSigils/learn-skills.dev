Guide l’agent dans la création et la validation des compétences d’agent. À utiliser lors de la création de nouveaux répertoires de compétences, du resserrement des métadonnées des compétences, de l'extraction de références de support ou de la préparation d'évaluations de niveaux de compétences. Ne pas utiliser pour la documentation générale de l'application, l'édition générique du README ou le code de bibliothèque non agent.
