Guide l'agent à travers la surface de commande Capgo CLI et achemine les requêtes vers des compétences Capgo plus spécifiques. À utiliser lorsque l'utilisateur pose des questions générales sur la CLI Capgo, la configuration de l'application, les diagnostics, les opérations OTA, les versions natives ou les commandes d'organisation. Ne pas utiliser lorsqu'une compétence Capgo plus spécifique correspond déjà clairement à la demande.
