Guide l'agent dans la configuration des workflows de publication centrés sur Capgo pour les applications Capacitor. À utiliser lorsque l'utilisateur a besoin d'un chemin unifié pour les mises à jour en direct, les versions natives et la publication sur la boutique d'applications à l'aide de Capgo et du CI/CD appartenant au référentiel. Ne pas utiliser pour les frameworks non-Capacitor ou pour la migration du plugin Ionic Enterprise.
