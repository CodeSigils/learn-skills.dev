Помогает агенту создавать и проверять навыки агента. Используйте при создании новых каталогов навыков, уточнении метаданных навыков, извлечении вспомогательных ссылок или подготовке оценок навыков. Не используйте для общей документации приложения, общего редактирования README или неагентного библиотечного кода.
