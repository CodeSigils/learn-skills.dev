Используйте CLI mcpc для работы с серверами MCP (Model Context Protocol) из оболочки — подключайтесь к серверу в качестве постоянного сеанса, затем составляйте список и вызывайте инструменты, читайте ресурсы, получайте подсказки и запускайте асинхронные задачи. Используйте --json для режима сценариев и кода. Используйте это при каждом взаимодействии с серверами MCP, вызове инструментов MCP или программном доступе к ресурсам MCP.
