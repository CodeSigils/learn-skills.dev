Utilisez la CLI mcpc pour travailler avec les serveurs MCP (Model Context Protocol) à partir du shell : connectez-vous à un serveur en tant que session persistante, puis répertoriez et appelez les outils, lisez les ressources, obtenez des invites et exécutez des tâches asynchrones. Utilisez --json pour les scripts et le mode code. Atteignez-le chaque fois que vous interagissez avec des serveurs MCP, appelez des outils MCP ou accédez aux ressources MCP par programme.
