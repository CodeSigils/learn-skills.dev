Verwenden Sie die mcpc-CLI, um über die Shell mit MCP-Servern (Model Context Protocol) zu arbeiten. Stellen Sie als dauerhafte Sitzung eine Verbindung zu einem Server her, listen Sie dann Tools auf und rufen Sie sie auf, lesen Sie Ressourcen, erhalten Sie Eingabeaufforderungen und führen Sie asynchrone Aufgaben aus. Verwenden Sie --json für den Skript- und Codemodus. Greifen Sie darauf zu, wenn Sie mit MCP-Servern interagieren, MCP-Tools aufrufen oder programmgesteuert auf MCP-Ressourcen zugreifen.
