Utilizza la CLI mcpc per lavorare con i server MCP (Model Context Protocol) dalla shell: connettiti a un server come sessione persistente, quindi elenca e chiama strumenti, leggi risorse, ottieni prompt ed esegui attività asincrone. Utilizza --json per la modalità di scripting e codice. Raggiungilo ogni volta che interagisci con i server MCP, richiami gli strumenti MCP o accedi alle risorse MCP in modo programmatico.
