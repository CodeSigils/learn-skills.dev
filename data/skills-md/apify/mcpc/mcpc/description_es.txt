Utilice la CLI de mcpc para trabajar con servidores MCP (Protocolo de contexto modelo) desde el shell: conéctese a un servidor como una sesión persistente, luego enumere y llame a herramientas, lea recursos, obtenga indicaciones y ejecute tareas asíncronas. Utilice --json para secuencias de comandos y modo de código. Utilice esto siempre que interactúe con servidores MCP, llame a herramientas MCP o acceda a recursos MCP mediante programación.
