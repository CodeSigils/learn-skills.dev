Découvrez, payez et exécutez n'importe quel acteur Apify en payant USDC sur base via le protocole x402 avec un portefeuille agent Coinbase (awal) – pas de compte Apify ni de clé API. Vous achetez un petit jeton Apify prépayé plafonné dans les dépenses, puis vous exécutez autant d'acteurs que la demande le nécessite. À utiliser lorsque l'utilisateur souhaite utiliser les outils Apify sans s'inscrire, payer à l'utilisation avec crypto/USDC, configurer un portefeuille agent, mentionne « x402 », « awal », « portefeuille agent », « portefeuille Coinbase », « payer avec USDC », « pas de clé API », ou demande d'extraire des données Web en direct (médias sociaux, recherche, cartes, marchés, actualités) tout en payant en chaîne par utilisation.
