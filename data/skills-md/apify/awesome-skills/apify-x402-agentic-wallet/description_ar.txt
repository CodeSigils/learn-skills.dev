اكتشف أي ممثل Apify وادفع مقابله وقم بتشغيله عن طريق دفع USDC على Base عبر بروتوكول x402 باستخدام Coinbase Agentic Wallet (awal) - بدون حساب Apify أو مفتاح API. يمكنك شراء رمز Apify صغير مدفوع مسبقًا مع حد أقصى للإنفاق، ثم تشغيل العدد الذي يحتاجه الطلب من الممثلين معه. يُستخدم عندما يريد المستخدم استخدام أدوات Apify دون الاشتراك، أو الدفع مقابل كل استخدام باستخدام crypto / USDC، أو إعداد محفظة وكيل، أو ذكر "x402"، أو "awal"، أو "agent Wallet"، أو "Coinbase Wallet"، أو "الدفع باستخدام USDC"، أو "بدون مفتاح API"، أو يطلب سحب بيانات الويب المباشرة (وسائل التواصل الاجتماعي، البحث، الخرائط، الأسواق، الأخبار) أثناء الدفع على السلسلة لكل استخدام.
