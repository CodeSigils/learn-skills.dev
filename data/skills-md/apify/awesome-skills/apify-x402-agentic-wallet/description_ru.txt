Находите, оплачивайте и запускайте любого участника Apify, заплатив USDC на базе по протоколу x402 с помощью агентского кошелька Coinbase (awal) — без учетной записи Apify или ключа API. Вы покупаете один небольшой предоплаченный токен Apify с ограниченным размером расходов, а затем запускаете с ним столько Актеров, сколько необходимо запросу. Используйте, когда пользователь хочет использовать инструменты Apify без регистрации, платить за использование с помощью криптовалюты/USDC, настроить агентский кошелек, упоминает «x402», «awal», «агентский кошелек», «кошелек Coinbase», «платить с помощью USDC», «без ключа API» или просит получить актуальные веб-данные (социальные сети, поиск, карты, торговые площадки, новости) при оплате по цепочке за использование.
