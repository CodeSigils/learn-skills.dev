Coinbase Agentic Wallet (awal) を使用して x402 プロトコル経由で Base 上で USDC を支払うことで、Apify アクタを検出、支払い、実行できます。Apify アカウントや API キーは必要ありません。支出制限付きの小規模なプリペイド Apify トークンを 1 つ購入し、それを使用してリクエストに必要な数のアクターを実行します。ユーザーが、サインアップせずに Apify ツールを使用する場合、暗号通貨 / USDC による使用量ごとの支払い、エージェント ウォレットの設定、「x402」、「awal」、「エージェント ウォレット」、「Coinbase ウォレット」、「USDC での支払い」、「API キーなし」について言及する場合、またはオンチェーンで使用量ごとに支払いながらライブ Web データ (ソーシャル メディア、検索、地図、マーケットプレイス、ニュース) を取得するように要求する場合に使用します。
