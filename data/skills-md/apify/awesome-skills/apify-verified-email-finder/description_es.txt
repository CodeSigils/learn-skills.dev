Crea una lista de correos electrónicos comerciales verificados de Google Maps, Google SERP o una lista de URL proporcionada por el usuario. La verificación se realiza dentro de la misma ejecución de Apify; no se necesita un verificador externo. Úselo cuando el usuario solicite buscar correos electrónicos verificados, crear una lista de clientes potenciales, extraer correos electrónicos de Maps o SERP, verificar correos electrónicos para una lista de URL o encontrar una alternativa de Apollo/Hunter.
