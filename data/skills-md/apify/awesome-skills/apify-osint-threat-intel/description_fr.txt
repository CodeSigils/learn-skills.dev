Utilisez cette compétence lorsque l'utilisateur demande « rechercher des CVE pour », « vérifier si mon domaine est violé », « informations sur les menaces », « OSINT activé », « actualités de sécurité sur », « surface d'attaque de », « cette IP est-elle malveillante », « quelles vulnérabilités affectent », « avis de sécurité pour », « surveiller les menaces pour », « recherche sur les acteurs menaçants », « exploits récents pour », « vérification des violations de données », « posture de sécurité de », « à quoi sert le paysage des menaces », « enquêter » [domaine/IP/logiciel]", "[entreprise] est exposée", ou toute demande impliquant une recherche de vulnérabilité, une détection de violation, un profilage d'acteurs menaçants ou des renseignements sur la sécurité. Nécessite le serveur Apify CLI ou Apify MCP.
