Bewerten und bereichern Sie eine CSV-Datei mit B2B-Leads mithilfe von Apify Actors. Nimmt eine CSV-Datei mit Unternehmens-URLs, Freitext-Bewertungsregeln und einer Anreicherungspräferenz an; führt BuiltWith (Tech-Stack), Website Content Crawler (Inhaltsklassifizierung) und Contact Info Scraper (Unternehmensmetadaten) zur Bewertung aus; Bereichert sich entweder mit abteilungsspezifischen Kontakten (Contact Info Scraper + Bulk Email Finder Fallback) oder der Textererkennung (Google Search Scraper → AI Web Scraper → Bulk Email Finder). Gibt eine angereicherte CSV-Datei mit einer numerischen Bewertung und einer outreach_hook-Spalte pro Lead aus, die die Kopie einer Kalt-E-Mail personalisiert (z. B. „verwendet Shopify → Shopify-Installationsanleitung senden“). Verwenden Sie es, wenn Benutzer Leads bewerten, Leads qualifizieren, eine Lead-Liste anreichern, den Tech-Stack eines Unternehmens für die Kontaktaufnahme ermitteln, Marketing-/Vertriebs-/Technik-Kontakte in einer Liste von Unternehmen finden, Blog-Texter für Gastbeiträge ausfindig machen, Kalt-E-Mails in großem Maßstab personalisieren oder eine Roh-Domainliste in eine sofort verfügbare Kontoliste umwandeln möchten.
