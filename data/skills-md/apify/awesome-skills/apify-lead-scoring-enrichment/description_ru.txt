Оцените и обогатите CSV потенциальных клиентов B2B с помощью Apify Actors. Принимает CSV-файл с URL-адресами компаний, правилами оценки в виде произвольного текста и настройками обогащения; запускает встроенный стек (технический стек), веб-сайт Content Crawler (классификация контента) и скребок контактной информации (метаданные компании) для оценки; дополняется либо контактами конкретного отдела (скребок контактной информации + резервный поиск по массовой рассылке по электронной почте), либо обнаружением копирайтера (скребок Google Search → AI Web Scraper → массовый поиск по электронной почте). Выводит расширенный CSV-файл с числовой оценкой и столбцом outreach_hook для каждого лида, который персонализирует копию холодного электронного письма (например, «использует Shopify → отправить руководство по установке Shopify»). Используйте, когда пользователь просит оценить потенциальных клиентов, оценить потенциальных клиентов, расширить список потенциальных клиентов, определить технологический стек компании для охвата, найти контакты по маркетингу/продажам/инжинирингу в списке компаний, найти копирайтеров блогов для гостевых публикаций, персонализировать холодную электронную почту в масштабе или превратить необработанный список доменов в готовый к презентации список учетных записей.
