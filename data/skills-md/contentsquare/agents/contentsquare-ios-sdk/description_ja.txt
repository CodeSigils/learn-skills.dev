Contentquare iOS SDK (現在のバージョン 1.11.x) を統合またはアップグレードします -- セッション リプレイ、画面追跡、トランザクション、分析、マスキング、プライバシー オプトイン/アウト。他の作業の前に、常に必須の Contentquare プロジェクト ヘルスチェック (アプリ バンドル ID の解決、ヘルスチェック エンドポイントの呼び出し、プロジェクトの健全性のレポート) から開始します。 Contentquare、CSQ、CSQ.start、CSQ.trackScreenview、CSQ.optIn、CSQ.registerWebView、WKWebView 追跡を使用する場合、または SDK バージョン 1.0 ～ 1.6 / `configureProductAnalytics` から `CSQ.start(environmentID:options:)` に移行する場合に使用します。
