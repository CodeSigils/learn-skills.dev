Contentquare Flutter SDK を統合またはアップグレードします -- セッション リプレイ、画面追跡、トランザクション、分析、マスキング、プライバシー オプトイン/アウト。他の作業の前に、常に必須の Contentquare プロジェクトのヘルスチェック (Android および iOS のバンドル ID の解決、ヘルスチェック エンドポイントの呼び出し、プロジェクトの健全性のレポート) から開始します。 Contentquare、CSQ、CSQ.start、StartConfig、AnalyticsOptions、ProductAnalyticsOptions、CSQNavigatorObserver、CSQNavigatorAutoRouteObserver、auto_route、AutoRoute、GoRouter、go_router、CSQWebViewWrapper、configureProductAnalytics を操作する場合、または従来の `Contentsquare()` API から移行する場合に使用します。 `CSQ()` (v3.x から v4.x) または 4.1.x から 4.4.x。
