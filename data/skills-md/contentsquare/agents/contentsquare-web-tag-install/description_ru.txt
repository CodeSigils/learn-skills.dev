Установите и проверьте тег отслеживания Contentsquare в любом веб-проекте. Используйте, когда вас просят «добавить Contentsquare», «установить тег CS», «настроить аналитику Contentsquare» или настроить отслеживание Contentsquare для веб-приложения. Проверка осуществляется с помощью `npx @contentsquare/wizardverify`, который управляет встроенным браузером Playwright — автоматизация браузера MCP не требуется.
