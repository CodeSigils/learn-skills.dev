Installa e verifica il tag di tracciamento di Contentsquare in qualsiasi progetto web. Da utilizzare quando viene richiesto di "aggiungere Contentsquare", "installare tag CS", "impostare l'analisi di Contentsquare" o configurare il monitoraggio di Contentsquare per un'applicazione web. La verifica viene eseguita tramite "npx @contentsquare/wizard verify", che gestisce un browser Playwright incorporato: non è richiesto alcun MCP di automazione del browser.
