Instale y verifique la etiqueta de seguimiento de Contentsquare en cualquier proyecto web. Úselo cuando se le solicite "agregar Contentsquare", "instalar etiqueta CS", "configurar análisis de Contentsquare" o configurar el seguimiento de Contentsquare para una aplicación web. La verificación se ejecuta a través de `npx @contentsquare/wizard verificar`, que impulsa un navegador Playwright integrado; no se requiere MCP de automatización del navegador.
