Installieren und überprüfen Sie das Contentsquare-Tracking-Tag in jedem Webprojekt. Verwenden Sie diese Option, wenn Sie aufgefordert werden, „Contentsquare hinzuzufügen“, „CS-Tag zu installieren“, „Contentsquare-Analysen einzurichten“ oder Contentsquare-Tracking für eine Webanwendung zu konfigurieren. Die Verifizierung erfolgt über „npx @contentsquare/wizard verify“, das einen eingebetteten Playwright-Browser steuert – kein Browser-Automatisierungs-MCP erforderlich.
