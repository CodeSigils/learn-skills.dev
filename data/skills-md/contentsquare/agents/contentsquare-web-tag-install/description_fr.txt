Installez et vérifiez la balise de suivi Contentsquare dans n'importe quel projet Web. À utiliser lorsqu'on vous demande « d'ajouter Contentsquare », « d'installer la balise CS », de « configurer Contentsquare Analytics » ou de configurer le suivi Contentsquare pour une application Web. La vérification s'effectue via « npx @contentsquare/wizard verify », qui pilote un navigateur Playwright intégré — aucun MCP d'automatisation du navigateur n'est requis.
