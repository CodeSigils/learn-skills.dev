Создавайте технически правильные, отличительные по дизайну шаблоны блоков WordPress. Используйте при создании шаблонов блоков, шаблонов начальной страницы, шаблонов шаблонов, шаблонов частей шаблона или для улучшения качества дизайна шаблонов. Охватывает регистрацию шаблонов (заголовки PHP, автоматический/вручную), синтаксис разметки блоков, токены дизайна theme.json, категории, типы шаблонов, специальные возможности и i18n/экранирование.
