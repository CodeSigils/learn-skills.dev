Используйте, когда пользователь хочет, чтобы конвейер разработки GitNexus выполнял задачу непрерывно: gitnexus-plan (глубина плана выбирается заранее), блокирующий шлюз для выполнения с gitnexus-work или остановки, завершающийся gitnexus-проверкой результата. Примеры: «/gitnexus-lfg Добавить поддержку повторных попыток в конвейер приема», «запустить конвейер gitnexus для этого», «планировать, создавать и проверять эту функцию».
