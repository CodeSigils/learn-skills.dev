Esamina le modifiche al codice con GitNexus da un URL o numero GitHub PR, un ramo/rif o intervallo di commit oppure modifiche locali con stage, non stage e non tracciate. Da utilizzare quando l'utente richiede una revisione del codice, una valutazione del rischio di fusione, una ricerca di regressione, un'analisi dei test mancanti o un verdetto sulla sicurezza di un PR, di un ramo, di un intervallo di commit o di una differenza locale.
