قم بمراجعة تغييرات التعليمات البرمجية باستخدام GitNexus من عنوان URL أو رقم GitHub PR، أو فرع/مرجع أو نطاق التزام، أو تغييرات محلية مرحلية وغير مرحلية وغير متعقبة. يُستخدم عندما يطلب المستخدم مراجعة التعليمات البرمجية، أو تقييم مخاطر الدمج، أو البحث عن الانحدار، أو تحليل الاختبار المفقود، أو إصدار حكم بشأن ما إذا كان PR أو الفرع أو نطاق الالتزام أو الفرق المحلي آمنًا.
