Examinez les modifications de code avec GitNexus à partir d’une URL ou d’un numéro PR GitHub, d’une branche/référence ou d’une plage de validation, ou de modifications locales planifiées, non planifiées et non suivies. À utiliser lorsque l'utilisateur demande une révision du code, une évaluation des risques de fusion, une recherche de régression, une analyse des tests manquants ou un verdict indiquant si un PR, une branche, une plage de validation ou une différence locale est sûr.
