Verwenden Sie diese Option, wenn der Benutzer eine Pull-Anfrage überprüfen, verstehen möchte, was sich in einer PR ändert, das Risiko einer Zusammenführung bewerten oder nach fehlender Testabdeckung suchen möchte. Beispiele: „Überprüfen Sie diese PR“, „Was ändert PR Nr. 42?“, „Kann diese PR sicher zusammengeführt werden?“
