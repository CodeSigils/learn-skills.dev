Orchestrateur de pipeline de développement basé sur les spécifications. À partir d'une URL ou d'une description textuelle, génère automatiquement des spécifications, implémente le code, exécute la révision du codex, applique une barrière de sécurité, exécute des tests, synchronise les documents et informe via Telegram. Déclencheurs sur : /start-workflow, démarrage du workflow, création de fonctionnalité, implémentation de fonctionnalité, basé sur les spécifications, démarrage du pipeline.
