Spezifikationsgesteuerter Entwicklungs-Pipeline-Orchestrator. Anhand einer URL oder einer Textbeschreibung werden automatisch Spezifikationen generiert, Code implementiert, eine Codex-Überprüfung durchgeführt, ein Sicherheitstor angewendet, Tests ausgeführt, Dokumente synchronisiert und Benachrichtigungen per Telegram gesendet. Wird ausgelöst bei: /start-workflow, Workflow starten, Feature erstellen, Feature implementieren, spezifikationsgesteuert, Pipeline starten.
