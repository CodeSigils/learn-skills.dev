Verwenden Sie diese Funktion, wenn eine NocoBase-Aufgabe eine KI-Mitarbeiterlebenszyklusarbeit erfordert, z. B. das Erkennen vorhandener Mitarbeiter, die Eignungsbeurteilung, die Erstellung eines dedizierten Mitarbeiters oder die Konfiguration von Profilen, Eingabeaufforderungen, Modellen, Fertigkeiten, Werkzeugen oder einer Wissensdatenbank, bevor eine andere Fertigkeit sie an eine UI-Oberfläche bindet.
