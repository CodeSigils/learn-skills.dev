Inspeccione el inventario y el estado de los complementos de NocoBase desde fuentes respaldadas en tiempo de ejecución e instale, habilite o deshabilite complementos de forma segura para aplicaciones locales o remotas. Para aplicaciones locales, la inspección/lectura debe preferir la salida JSON CLI `pm list`, mientras que las escrituras deben preferir la CLI de composición acoplable o la CLI del host.
