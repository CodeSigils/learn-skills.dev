Inspectez l'inventaire et l'état des plugins NocoBase à partir de sources sauvegardées au moment de l'exécution, et installez, activez ou désactivez en toute sécurité les plugins pour les applications locales ou distantes. Pour les applications locales, l'inspection/la relecture doit préférer la sortie JSON CLI `pm list`, tandis que les écritures doivent préférer la CLI docker-compose ou la CLI hôte.
