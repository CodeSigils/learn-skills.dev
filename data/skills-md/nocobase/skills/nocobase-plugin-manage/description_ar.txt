افحص مخزون المكونات الإضافية لـ NocoBase وحالة المكونات الإضافية من المصادر المدعومة بوقت التشغيل، وقم بتثبيت المكونات الإضافية أو تمكينها أو تعطيلها بأمان للتطبيقات المحلية أو البعيدة. بالنسبة للتطبيقات المحلية، يجب أن يفضل الفحص/القراءة إخراج JSON لـ CLI `pm list`، بينما يجب أن تفضل الكتابة CLI لتكوين عامل الإرساء أو CLI المضيف.
