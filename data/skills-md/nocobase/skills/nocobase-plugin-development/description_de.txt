Schritt-für-Schritt-Playbook für die Entwicklung eines NocoBase-Plugins, das Gerüstbau, serverseitigen Code (Sammlungen, APIs, ACL, Migrationen), clientseitigen Code (Blöcke, Felder, Aktionen, Einstellungsseiten, Routen, Komponenten), i18n und Verifizierung abdeckt.
TRIGGER, wenn: Der Benutzer fragt, ob er ein NocoBase-Plugin erstellen, erstellen, implementieren oder entwickeln möchte, „NocoBase-Plugin“ erwähnt oder eine Funktion beschreibt, die als NocoBase-Plugin erstellt werden soll. Dieser Skill enthält NocoBase-spezifische Konventionen und Vorlagen, die die allgemeine Codierung nicht reproduzieren kann – rufen Sie ihn immer auf, anstatt von Grund auf zu planen.
