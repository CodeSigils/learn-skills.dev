Playbook passo passo per lo sviluppo di un plugin NocoBase, che copre scaffolding, codice lato server (raccolte, API, ACL, migrazioni), codice lato client (blocchi, campi, azioni, pagine di impostazioni, percorsi, componenti), i18n e verifica.
SI ATTIVA quando: l'utente chiede di creare, costruire, implementare o sviluppare un plugin NocoBase, menziona "plugin NocoBase" o descrive una funzionalità da creare come plugin NocoBase. Questa competenza contiene convenzioni e modelli specifici di NocoBase che la codifica generale non può replicare: invocala sempre invece di pianificare da zero.
