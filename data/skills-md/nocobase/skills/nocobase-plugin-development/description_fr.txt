Playbook étape par étape pour développer un plugin NocoBase, couvrant l'échafaudage, le code côté serveur (collections, API, ACL, migrations), le code côté client (blocs, champs, actions, pages de paramètres, itinéraires, composants), i18n et la vérification.
DÉCLENCHEMENT lorsque : l'utilisateur demande à créer, construire, implémenter ou développer un plugin NocoBase, mentionne "plugin NocoBase" ou décrit une fonctionnalité à construire en tant que plugin NocoBase. Cette compétence contient des conventions et des modèles spécifiques à NocoBase que le codage général ne peut pas reproduire : invoquez-le toujours au lieu de planifier à partir de zéro.
