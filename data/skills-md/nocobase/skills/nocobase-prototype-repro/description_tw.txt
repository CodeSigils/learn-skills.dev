當任務移交原型以在 NocoBase 中重現時使用 - HTML 文件、圖像或鏈接，包括發布的表單“構建 NocoBase 應用程序 - X ...匹配此參考原型的佈局和簽名視覺效果：<url>” - 或者當有人說構建的頁面“與原型不匹配/看起來單調/難看”時使用。存在的原型/URL 會觸發此技能，即使同一提示還顯示“構建應用程式”，動詞“構建”也不會取消原型。只有在根本沒有原型時才跳過它：一個簡單的“為我建立一個 CRM/應用程式” → nocobase-app-discipline；單字段編輯/重命名 → nocobase-ui-builder。它將「這是原型，建造它」變成一個忠實的應用程式 - 分析原型、本機 CRUD、每個區域正確的本機區塊，然後是螢幕截圖與原型視覺循環。本土第一； JS 僅在本機容器內；絕非整頁 JS 塊。機制位於 nocobase-ui-builder、nocobase-data-modeling、nocobase-app-discipline 中。
