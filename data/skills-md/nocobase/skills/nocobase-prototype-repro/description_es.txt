Úselo cuando la tarea entrega un prototipo para reproducir en NocoBase: un archivo HTML, una imagen o un enlace, INCLUYENDO el formulario publicado "Crear una aplicación NocoBase - X... Coincide con el diseño y las imágenes de firma de este prototipo de referencia: <url>", o cuando alguien dice que una página creada "no coincide con el prototipo / parece monótona / es fea". La presencia de un prototipo/URL es lo que desencadena esta habilidad, INCLUSO CUANDO el mismo mensaje también dice "crear una aplicación", el verbo "crear" no cancela el prototipo. Omítelo solo cuando NO haya ningún prototipo: simplemente "constrúyeme una aplicación/CRM" → nocobase-app-disciplina; una edición/cambio de nombre de un campo → nocobase-ui-builder. Convierte "aquí está el prototipo, constrúyelo" en una aplicación fiel: analiza el prototipo, el CRUD nativo, el bloque nativo correcto por región y luego un bucle visual de captura de pantalla versus prototipo. Nativo primero; JS sólo dentro de un contenedor nativo; nunca un bloque JS de página completa. La mecánica vive en nocobase-ui-builder, nocobase-data-modeling, nocobase-app-disciplina.
