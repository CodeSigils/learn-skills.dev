当任务移交原型以在 NocoBase 中重现时使用 - HTML 文件、图像或链接，包括发布的表单“构建 NocoBase 应用程序 - X ...匹配此参考原型的布局和签名视觉效果：<url>” - 或者当有人说构建的页面“与原型不匹配/看起来单调/难看”时使用。存在的原型/URL 会触发此技能，即使同一提示还显示“构建应用程序”，动词“构建”也不会取消原型。仅当根本没有原型时才跳过它：一个简单的“为我构建一个 CRM/应用程序” → nocobase-app-discipline；单字段编辑/重命名 → nocobase-ui-builder。它将“这是原型，构建它”变成一个忠实的应用程序 - 分析原型、本机 CRUD、每个区域正确的本机块，然后是屏幕截图与原型视觉循环。本土第一； JS 仅在本机容器内；绝不是整页 JS 块。机制位于 nocobase-ui-builder、nocobase-data-modeling、nocobase-app-discipline 中。
