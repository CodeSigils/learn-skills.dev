Orchestrieren Sie Dutzende bis Hunderte von Subagenten aus einem Skript, das Claude schreibt (Claude Code Dynamic Workflows, Trigger „Ultracode“). Verwenden Sie diese Funktion, wenn eine Aufgabe über den Kontext eines einzelnen Agenten hinausgeht oder mehr als ca. 4 gleichzeitige Mitarbeiter benötigt – große Audits, Migrationen, Recherchen aus mehreren Quellen, Fanout-Überprüfungen. Unterscheidet sich von Agent Teams (synchron, ≤4 Worker) und Ralph-Run (sequentielle Einzelkontextschleife).
