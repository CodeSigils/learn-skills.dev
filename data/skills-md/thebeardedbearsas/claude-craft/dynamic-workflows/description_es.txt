Orqueste entre docenas y cientos de subagentes a partir de un script que escribe Claude (Claude Code Dynamic Workflows, desencadenante "ultracódigo"). Úselo cuando una tarea excede el contexto de un solo agente o necesita más de ~4 trabajadores simultáneos: auditorías grandes, migraciones, investigaciones de múltiples fuentes, revisiones distribuidas. Distinto de Agent Teams (sincrónico, ≤4 trabajadores) y ralph-run (bucle secuencial de contexto único).
