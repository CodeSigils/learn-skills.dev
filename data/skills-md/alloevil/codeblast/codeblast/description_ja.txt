TypeScript および Python リポジトリの決定論的なコードグラフ分析。ユーザーがこれを変更すると何が変わるのかを尋ねる場合、シンボルを編集する前に影響分析や爆発範囲が必要な場合、実際のコードに基づいたリポジトリ アーキテクチャ マップを要求する場合、または 2 つの git ref 間または PR 内で構造的に何が変更されたかを知りたい場合に使用します。 LLM で描画された図とは異なり、すべてのノードとエッジはコンパイラー グレードの静的解析によって抽出され、ファイル:行の証拠が保持されます。影響に関する回答は保守的です (静的解析の境界内で偽陰性はありません。動的盲点は明示的に報告され、黙って削除されることはありません)。
