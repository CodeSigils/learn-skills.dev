Analyse déterministe de graphe de code pour les référentiels TypeScript et Python. À utiliser lorsque l'utilisateur demande ce qui casse si je change cela, souhaite une analyse d'impact ou un rayon d'explosion avant de modifier un symbole, demande une carte d'architecture de référentiel fondée sur du code réel, ou veut savoir ce qui a changé structurellement entre deux références git ou dans un PR. Contrairement aux diagrammes dessinés par LLM, chaque nœud et chaque arête est extrait par une analyse statique de niveau compilateur et contient des preuves fichier:ligne ; les réponses à l'impact sont conservatrices (pas de faux négatifs dans les limites de l'analyse statique ; les angles morts dynamiques sont explicitement signalés, jamais ignorés silencieusement).
