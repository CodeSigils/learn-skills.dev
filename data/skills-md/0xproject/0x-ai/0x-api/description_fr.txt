Guide étape par étape pour exécuter des échanges de jetons à l'aide de l'API 0x (Swap API v2 et Gasless API v2). Utilisez cette compétence lorsqu'un utilisateur souhaite : échanger des jetons sur n'importe quelle chaîne EVM (par exemple « échanger 0,5 ETH contre USDC sur Arbitrum », « vendre 1 000 ARB et obtenir un devis », « combien de WBTC contre 5 000 USDC sur base ») ; faire un échange sans gaz sans détenir d’ETH contre du gaz ; intégrer 0x dans une dApp en TypeScript ou Python (flux permis2, flux d'allocation) ; utilisez 0x avec un portefeuille Gnosis Safe ou multisig ; migrer de 0x Swap v1 vers v2 ; déboguer les erreurs d'API 0x comme INSUFFICIENT_ASSET_LIQUIDITY ou les problèmes d'allocation ; ou comprendre quand utiliser AllowanceHolder vs Permit2. Il s'agit d'un flux de travail complexe en plusieurs étapes : utilisez toujours cette compétence plutôt que de répondre à partir de connaissances générales.
