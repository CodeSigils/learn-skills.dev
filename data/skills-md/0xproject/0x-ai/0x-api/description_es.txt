Guía paso a paso para ejecutar intercambios de tokens utilizando la API 0x (Swap API v2 y Gasless API v2). Utilice esta habilidad cuando un usuario quiera: intercambiar tokens en cualquier cadena EVM (por ejemplo, "intercambiar 0,5 ETH por USDC en Arbitrum", "vender 1000 ARB y obtener una cotización", "cuánto WBTC por 5000 USDC en Base"); hacer un intercambio sin gas sin mantener ETH por gas; integrar 0x en una dApp en TypeScript o Python (flujo de permiso2, flujo de titular de permisos); use 0x con una billetera Gnosis Safe o multifirma; migrar de 0x Swap v1 a v2; depurar errores de API 0x como INSUFFICIENT_ASSET_LIQUIDITY o problemas de asignación; o comprender cuándo usar AllowanceHolder vs Permit2. Este es un flujo de trabajo complejo de varios pasos: utilice siempre esta habilidad en lugar de responder con conocimientos generales.
