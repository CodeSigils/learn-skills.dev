0x API (Swap API v2 および Gasless API v2) を使用してトークン スワップを実行するためのステップバイステップ ガイド。ユーザーが次のことを行う場合にこのスキルを使用します。任意の EVM チェーンでトークンを交換する (例: 「Arbitrum で 0.5 ETH を USDC と交換する」、「1000 ARB を売って見積もりを取得する」、「Base で 5000 USDC に WBTC をいくらにする」)。ガスのETHを保持せずにガスレススワップを実行します。 TypeScript または Python で 0x を dApp に統合します (permit2 フロー、allowanceholder フロー)。 Gnosis Safe またはマルチシグ ウォレットでは 0x を使用します。 0x スワップ v1 から v2 に移行します。 INSUFFICIENT_ASSET_LIQUIDITY や許容量の問題などの 0x API エラーをデバッグします。または、AllowanceHolder と Permit2 をいつ使用するかを理解してください。これは複雑な複数のステップからなるワークフローです。一般的な知識に基づいて回答するのではなく、常にこのスキルを使用してください。
