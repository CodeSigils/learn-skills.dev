使用 0x API（Swap API v2 和 Gasless API v2）執行代幣交換的逐步指南。當使用者想要執行以下操作時，請使用此技能： 在任何 EVM 鏈上交換代幣（例如「在 Arbitrum 上將 0.5 ETH 交換為 USDC」、「出售 1000 個 ARB 並獲得報價」、「在 Base 上用多少 WBTC 換取 5000 USDC」）；中（permit2 流、allowanceholder 流）；將 0x 與 Gnosis Safe 或多簽名錢包一起使用；從 0x Swap v1 遷移到 v2；調試 0x API 錯誤，例如 INSUFFICIENT_ASSET_LIQUIDITY 或津貼問題；或了解何時使用AllowanceHolder 與Permit2。這是一個複雜的多步驟工作流程——始終使用此技能，而不是根據常識進行回答。
