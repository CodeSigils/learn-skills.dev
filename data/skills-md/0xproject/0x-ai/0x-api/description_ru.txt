Пошаговое руководство по выполнению обмена токенов с использованием API 0x (Swap API v2 и Gasless API v2). Используйте этот навык, когда пользователь хочет: обменять токены в любой цепочке EVM (например, «обменять 0,5 ETH на USDC на Arbitrum», «продать 1000 ARB и получить котировку», «сколько WBTC за 5000 USDC на базе»); выполнить безгазовый своп, не удерживая ETH за газ; интегрировать 0x в dApp на TypeScript или Python (поток разрешения2, поток разрешения); используйте 0x с Gnosis Safe или мультиподписным кошельком; перейти с 0x Swap v1 на v2; отладка ошибок API 0x, таких как INSUFFICIENT_ASSET_LIQUIDITY или проблемы с разрешениями; или понять, когда использовать AllowanceHolder или Permit2. Это сложный многоэтапный рабочий процесс — всегда используйте этот навык, а не отвечайте на основе общих знаний.
