Guida passo passo per eseguire scambi di token utilizzando l'API 0x (Swap API v2 e Gasless API v2). Utilizza questa abilità quando un utente desidera: scambiare token su qualsiasi catena EVM (ad esempio "scambia 0,5 ETH per USDC su Arbitrum", "vendi 1000 ARB e ottieni una quotazione", "quanto WBTC per 5000 USDC su Base"); effettuare uno scambio senza gas senza detenere ETH per il gas; integrare 0x in una dApp in TypeScript o Python (flusso permesso2, flusso detentore di quote); utilizzare 0x con un portafoglio Gnosis Safe o multisig; migrare da 0x Scambia v1 a v2; eseguire il debug di errori API 0x come INSUFFICIENT_ASSET_LIQUIDITY o problemi di indennità; o capire quando utilizzare AllineamentoHolder vs Permit2. Si tratta di un flusso di lavoro complesso in più fasi: utilizza sempre questa competenza anziché rispondere in base a conoscenze generali.
