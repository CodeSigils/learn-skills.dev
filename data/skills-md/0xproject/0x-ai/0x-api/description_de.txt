Schritt-für-Schritt-Anleitung zum Ausführen von Token-Swaps mit der 0x-API (Swap API v2 und Gasless API v2). Verwenden Sie diese Fähigkeit, wenn ein Benutzer: Token in einer beliebigen EVM-Kette tauschen möchte (z. B. „0,5 ETH gegen USDC auf Arbitrum tauschen“, „1000 ARB verkaufen und ein Angebot einholen“, „wie viel WBTC für 5000 USDC auf Base“); einen gaslosen Tausch durchführen, ohne ETH gegen Gas zu halten; 0x in eine dApp in TypeScript oder Python integrieren (Permit2-Flow, Allowanceholder-Flow); Verwenden Sie 0x mit einer Gnosis Safe- oder Multisig-Wallet. Migration von 0x Swap v1 nach v2; 0x-API-Fehler wie INSUFFICIENT_ASSET_LIQUIDITY oder Zuschussprobleme debuggen; oder verstehen, wann AllowanceHolder vs. Permit2 verwendet werden sollte. Dies ist ein komplexer, mehrstufiger Arbeitsablauf – nutzen Sie immer diese Fähigkeit, anstatt auf Basis von Allgemeinwissen zu antworten.
