使用 0x API（Swap API v2 和 Gasless API v2）执行代币交换的分步指南。当用户想要执行以下操作时，请使用此技能： 在任何 EVM 链上交换代币（例如“在 Arbitrum 上将 0.5 ETH 交换为 USDC”、“出售 1000 个 ARB 并获得报价”、“在 Base 上用多少 WBTC 换取 5000 USDC”）；进行无 Gas 交换，无需持有 ETH 换取 Gas；将 0x 集成到 TypeScript 或 Python 中的 dApp 中（permit2 流、allowanceholder 流）；将 0x 与 Gnosis Safe 或多签名钱包一起使用；从 0x Swap v1 迁移到 v2；调试 0x API 错误，例如 INSUFFICIENT_ASSET_LIQUIDITY 或津贴问题；或了解何时使用AllowanceHolder 与Permit2。这是一个复杂的多步骤工作流程——始终使用此技能，而不是根据常识进行回答。
