Null Axiom (@NullAxiomX) のツイート自動生成ツール。キャラクターの口調に応じて、独立した開発者/データ探偵のスタイルで Twitter のツイートやスレッドを生成します。トリガーワード: ツイートを生成する / ツイートを書く / Null Axiom / ツイートの下書きを生成する / Twitter の作成を手伝ってください / ツイートの生成。返信ツイートのサポート: Twitter/X 投稿リンクを送信すると、内容が自動的に読み取られ、キャラクターに一致する返信の下書きが生成されます。スケジュールされたタスクの設定が含まれており、毎日の自動生成をサポートし、レビューのために Feishu にプッシュします。
