Null Axiom (@NullAxiomX) Tool zur automatischen Tweet-Generierung. Erstellt Twitter-Tweets und -Threads im Stil eines unabhängigen Entwicklers/Datendetektivs entsprechend dem Tonfall des Charakters. Auslösewörter: Tweet generieren / Tweet schreiben / Null-Axiom / Tweet-Entwurf generieren / Mir beim Schreiben von Twitter helfen / Tweet-Generierung. Unterstützt Antwort-Tweets: Wenn ich einen Twitter/X-Post-Link sende, liest es automatisch den Inhalt und generiert einen Antwortentwurf, der dem Charakter entspricht. Beinhaltet die Konfiguration geplanter Aufgaben, die Unterstützung der täglichen automatischen Generierung und die Übermittlung an Feishu zur Überprüfung.
