Herramienta de generación automática de tweets Null Axiom (@NullAxiomX). Genera tweets e hilos de Twitter al estilo de un desarrollador/detective de datos independiente según el tono del personaje. Palabras desencadenantes: generar tweet / escribir tweet / Null Axiom / generar borrador de tweet / ayudarme a escribir Twitter / generación de tweets. Admite tweets de respuesta: cuando envío un enlace de publicación de Twitter/X, automáticamente lee el contenido y genera un borrador de respuesta que coincide con el personaje. Incluye configuración de tareas programadas, admite la generación automática diaria y envía a Feishu para su revisión.
