قم بتحسين أداء واجهة المستخدم مقابل Core Web Vitals — LCP، وINP، وCLS — من خلال إستراتيجية التحميل/تقسيم التعليمات البرمجية، ومنع تغيير التخطيط، وقواعد أداء الرسوم المتحركة. يُستخدم عندما يريد المستخدم تحسين السرعة، أو إصلاح الأخطاء غير المرغوب فيها أو تغيير التخطيط، أو الوصول إلى ميزانيات Web Vitals، أو جعل واجهة المستخدم تبدو سريعة على الأجهزة المنخفضة الجودة.
