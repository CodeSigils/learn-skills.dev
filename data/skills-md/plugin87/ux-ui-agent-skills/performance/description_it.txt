Ottimizza le prestazioni dell'interfaccia utente rispetto ai Core Web Vitals (LCP, INP, CLS) con strategia di caricamento/divisione del codice, prevenzione dello spostamento del layout e regole sulle prestazioni dell'animazione. Utilizzalo quando l'utente desidera migliorare la velocità, correggere errori o cambiamenti di layout, raggiungere i budget di Web Vitals o rendere veloce un'interfaccia utente su dispositivi di fascia bassa.
