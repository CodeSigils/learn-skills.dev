Разработайте спецификацию компонентов пользовательского интерфейса в соответствии с домашней шкалой качества — анатомию, варианты, размеры, 8 состояний, сопоставление токенов и доступность. Используйте, когда пользователь хочет спроектировать или задокументировать компонент (кнопку, ввод, вкладки, всплывающее сообщение, поле со списком, средство выбора даты, модальное окно и т. д.) на уровне спецификации до или рядом с кодом. Для генерации кода платформы используйте дизайн-код.
