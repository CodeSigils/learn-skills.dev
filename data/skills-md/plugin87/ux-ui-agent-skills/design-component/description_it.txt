Progetta le specifiche dei componenti dell'interfaccia utente in base alla barra di qualità della casa: anatomia, varianti, dimensioni, 8 stati, mappatura dei token e accessibilità. Da utilizzare quando l'utente desidera progettare o documentare un componente (pulsante, input, schede, toast, casella combinata, selezione data, modale e così via) a livello di specifica prima o accanto al codice. Per generare codice framework, utilizzare design-code.
