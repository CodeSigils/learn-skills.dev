صمم مواصفات مكون واجهة المستخدم لشريط جودة المنزل - التشريح، والمتغيرات، والأحجام، والحالات الثمانية، ورسم الخرائط المميزة، وإمكانية الوصول. يُستخدم عندما يريد المستخدم تصميم مكون أو توثيقه (زر، أو إدخال، أو علامات تبويب، أو نخب، أو مربع تحرير وسرد، أو منتقي التاريخ، أو مشروط، وما إلى ذلك) على مستوى المواصفات قبل التعليمات البرمجية أو بجانبها. لإنشاء رمز الإطار، استخدم رمز التصميم.
