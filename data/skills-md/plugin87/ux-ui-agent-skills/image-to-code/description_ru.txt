Превратите эталонное изображение, снимок экрана или макет в управляемый токенами доступный код — определите систему дизайна на основе эталона (палитра, масштаб шрифта, интервал, радиус, архетип макета), сопоставьте ее с трехуровневыми токенами, перестройте ее, затем сверьте с воротами комплекта. Используйте, когда пользователь предоставляет дизайн/скриншот и хочет получить соответствующий код пользовательского интерфейса.
