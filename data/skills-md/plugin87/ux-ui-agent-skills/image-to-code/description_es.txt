Convierta una imagen de referencia, una captura de pantalla o una maqueta en un código accesible basado en tokens: infiera el sistema de diseño a partir de la referencia (paleta, escala de texto, espaciado, radio, arquetipo de diseño), asígnelo a los tokens de 3 niveles, reconstrúyalo y luego verifíquelo con las puertas del kit. Úselo cuando el usuario proporciona un diseño/captura de pantalla y desea que coincida el código de UI.
