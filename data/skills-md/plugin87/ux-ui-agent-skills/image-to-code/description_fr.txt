Transformez une image de référence, une capture d'écran ou une maquette en code accessible piloté par des jetons - déduisez le système de conception à partir de la référence (palette, échelle de type, espacement, rayon, archétype de disposition), mappez-le aux jetons à 3 niveaux, reconstruisez-le, puis vérifiez avec les portes du kit. À utiliser lorsque l'utilisateur fournit un design/une capture d'écran et souhaite faire correspondre le code d'interface utilisateur.
