قم بتحويل صورة مرجعية، أو لقطة شاشة، أو نموذج بالحجم الطبيعي إلى رمز مميز يمكن الوصول إليه - واستنتج نظام التصميم من المرجع (لوحة الألوان، ومقياس الكتابة، والتباعد، ونصف القطر، والنموذج الأصلي للتخطيط)، وقم بتعيينه إلى الرموز المميزة المكونة من 3 طبقات، وأعد بناءه، ثم تحقق من خلال بوابات المجموعة. يُستخدم عندما يقدم المستخدم تصميمًا/لقطة شاشة ويريد مطابقة رمز واجهة المستخدم.
