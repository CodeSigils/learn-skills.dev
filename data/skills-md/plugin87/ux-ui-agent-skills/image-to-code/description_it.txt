Trasforma un'immagine di riferimento, uno screenshot o un modello in codice accessibile basato su token: deduci il sistema di progettazione dal riferimento (tavolozza, scala del tipo, spaziatura, raggio, archetipo di layout), mappalo sui token a 3 livelli, ricostruiscilo, quindi verifica con le porte del kit. Da utilizzare quando l'utente fornisce un progetto/uno screenshot e desidera che il codice dell'interfaccia utente corrisponda.
