Mueva una idea hacia arriba en la escala de fidelidad (contenido primero → estructura alámbrica → baja fidelidad → alta fidelidad → código) con un plan de validación en cada nivel, además de mapeo del recorrido del usuario y scripts de prueba de usabilidad. Úselo cuando el usuario quiera crear prototipos, estructurar, mapear un flujo de usuarios o planificar/ejecutar pruebas de usabilidad.
