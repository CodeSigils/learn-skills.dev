انقل فكرة إلى أعلى سلم الدقة (المحتوى أولاً ← الإطار السلكي ← Low-fi ← High-fi ← الكود) مع خطة التحقق من الصحة في كل مستوى، بالإضافة إلى رسم خرائط رحلة المستخدم والبرامج النصية لاختبار قابلية الاستخدام. يُستخدم عندما يريد المستخدم إنشاء نموذج أولي أو إطار سلكي أو رسم خريطة لتدفق المستخدم أو تخطيط/تشغيل اختبار قابلية الاستخدام.
