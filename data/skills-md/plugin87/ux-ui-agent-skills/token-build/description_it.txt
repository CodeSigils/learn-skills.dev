Configura o esegui la pipeline di creazione del token: trasforma i token DTCG/*.json (fonte della verità) in artefatti della piattaforma (variabili CSS, Tailwind @theme, JS/TS, iOS Asset Catalog, Android, Compose) con Style Dictionary/Tokens Studio/esportazione DTCG W3C. Da utilizzare quando l'utente desidera generare file di temi della piattaforma da token, CI token wire o output token multipiattaforma.
