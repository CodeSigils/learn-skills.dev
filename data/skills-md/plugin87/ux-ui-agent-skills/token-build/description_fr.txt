Configurez ou exécutez le pipeline de création de jetons : transformez les jetons DTCG/*.json (source de vérité) en artefacts de plate-forme (variables CSS, Tailwind @theme, JS/TS, iOS Asset Catalog, Android, Compose) avec l'exportation Style Dictionary / Tokens Studio / W3C DTCG. À utiliser lorsque l'utilisateur souhaite générer des fichiers de thème de plate-forme à partir de jetons, de CI de jeton filaire ou d'une sortie de jeton multiplateforme.
