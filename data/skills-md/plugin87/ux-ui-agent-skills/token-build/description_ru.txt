Настройте или запустите конвейер сборки токенов — преобразуйте токены DTCG/*.json (источник истины) в артефакты платформы (переменные CSS, Tailwind @theme, JS/TS, каталог активов iOS, Android, Compose) с помощью словаря стилей/Tokens Studio/экспорта W3C DTCG. Используйте, когда пользователь хочет создать файлы темы платформы на основе токенов, CI токенов проводной связи или вывода многоплатформенных токенов.
