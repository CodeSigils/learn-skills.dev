قم بإنشاء أو توسيع أو تدقيق الرموز المميزة للتصميم بتنسيق DTCG باستخدام بنية ثلاثية الطبقات (بدائية → مكون → دلالي). يُستخدم عندما يريد المستخدم لوحة ألوان، أو مقياس كتابة، أو رموز تباعد/ظل/نصف قطر/حركة، أو سمات متعددة العلامات التجارية، أو يريد التحقق من صحة ملفات الرموز المميزة. يغطي الألوان، الطباعة، التباعد، الظلال، الحدود، نقاط التوقف، الحركة، التدرجات، العتامة، التمويه، التحجيم، الحالات، السمات.
