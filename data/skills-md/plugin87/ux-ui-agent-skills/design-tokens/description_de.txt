Generieren, erweitern oder prüfen Sie Design-Tokens im DTCG-Format mit der 3-Ebenen-Architektur (primitiv → semantisch → Komponente). Verwenden Sie diese Option, wenn der Benutzer eine Farbpalette, einen Schriftmaßstab, Abstands-/Schatten-/Radius-/Bewegungs-Tokens oder ein Design für mehrere Marken wünscht oder Token-Dateien validieren möchte. Deckt Farben, Typografie, Abstände, Schatten, Ränder, Haltepunkte, Bewegung, Farbverläufe, Deckkraft, Unschärfe, Größe, Zustände und Themen ab.
