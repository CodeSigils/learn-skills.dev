Создавайте, расширяйте или проверяйте токены проектирования в формате DTCG с трехуровневой архитектурой (примитивный → семантический → компонент). Используйте, когда пользователю нужна цветовая палитра, масштаб шрифта, токены пространства/тени/радиуса/движения, мультибрендовые темы или он хочет проверить файлы токенов. Охватывает цвета, типографику, интервалы, тени, границы, точки останова, движение, градиенты, непрозрачность, размытие, размер, состояния, темы.
