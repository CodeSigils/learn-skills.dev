Genera, estendi o controlla token di progettazione in formato DTCG con l'architettura a 3 livelli (primitiva → semantica → componente). Utilizzare quando l'utente desidera una tavolozza di colori, una scala di tipo, token di spaziatura/ombra/raggio/movimento, temi multimarca o desidera convalidare file di token. Copre colori, tipografia, spaziatura, ombre, bordi, punti di interruzione, movimento, gradienti, opacità, sfocatura, dimensionamento, stati, temi.
