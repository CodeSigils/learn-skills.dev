Générez, étendez ou auditez des jetons de conception au format DTCG avec l'architecture à 3 niveaux (primitive → sémantique → composant). À utiliser lorsque l'utilisateur souhaite une palette de couleurs, une échelle de caractères, des jetons d'espacement/ombre/rayon/mouvement, un thème multimarque ou souhaite valider des fichiers de jetons. Couvre les couleurs, la typographie, l'espacement, les ombres, les bordures, les points d'arrêt, le mouvement, les dégradés, l'opacité, le flou, le dimensionnement, les états et la thématique.
