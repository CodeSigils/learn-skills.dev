Générez un système de conception de marque complet et accessible à partir d'un bref jeton DTCG — primitif → sémantique → composant (couleur, type, espacement, rayon, ombre, mouvement), clair + foncé, plus un seul thème.css — vérifié pour WCAG. À utiliser lorsque l'utilisateur souhaite une base de marque/conception à partir de zéro, un nouveau système de palette + type ou un kit de jetons thématiques pour un produit.
