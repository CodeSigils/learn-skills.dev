قم بإنشاء نظام تصميم علامة تجارية كامل ويمكن الوصول إليه من رموز DTCG المختصرة - البدائية → الدلالية → المكونة (اللون، النوع، التباعد، نصف القطر، الظل، الحركة)، الفاتح + الداكن، بالإضافة إلى theme.css واحد - تم التحقق منها لـ WCAG. يُستخدم عندما يريد المستخدم أساسًا للعلامة التجارية/التصميم من الصفر، أو لوحة ألوان جديدة + نظام كتابة، أو مجموعة رمزية قابلة للتخصيص لمنتج ما.
