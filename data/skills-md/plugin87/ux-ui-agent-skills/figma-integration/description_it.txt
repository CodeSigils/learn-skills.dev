Mantieni Figma e il codice sincronizzati: mappa i token DTCG a 3 livelli sulle variabili Figma (raccolte + modalità), sincronizza in entrambe le direzioni, utilizza Figma MCP quando connesso e verifica la parità dei componenti (varianti/stati). Utilizzare quando l'utente desidera inviare token/componenti a Figma, inserire un progetto nel codice, impostare la sincronizzazione token↔Variabile o controllare la deriva del codice di progetto.
