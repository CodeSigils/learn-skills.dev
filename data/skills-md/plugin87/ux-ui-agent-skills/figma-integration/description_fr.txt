Gardez Figma et le code synchronisés : mappez les jetons DTCG à 3 niveaux aux variables Figma (collections + modes), synchronisez dans les deux sens, utilisez le Figma MCP lorsqu'il est connecté et vérifiez la parité des composants (variantes/états). À utiliser lorsque l'utilisateur souhaite transférer des jetons/composants vers Figma, intégrer une conception dans le code, configurer la synchronisation jeton↔Variable ou vérifier la dérive du code de conception.
