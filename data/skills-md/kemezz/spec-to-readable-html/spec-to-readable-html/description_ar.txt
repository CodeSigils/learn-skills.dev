قم بتحويل مواصفات Markdown أو النص إلى مستندات HTML يمكن قراءتها بواسطة الإنسان مع ملخصات وبنية مُعاد ترتيبها وتفسيرات مرئية ورسوم بيانية ومخططات وإمكانية التتبع إلى المصدر. يُستخدم عندما يُطلب منك تحويل مواصفات أو مستند متطلبات أو مواصفات واجهة برمجة التطبيقات (API) أو مواصفات منتج أو مستند تصميم أو مستند فني إلى HTML قابل للقراءة، خاصة عندما يريد المستخدم التلخيص أو إعادة الهيكلة أو الرسوم البيانية أو الرسوم البيانية أو الصور أو المساعدات المرئية بدلاً من تحويل Markdown-to-HTML الحرفي.
