Transforme Markdown o especificaciones de texto en documentos HTML legibles por humanos con resúmenes, estructura reordenada, explicaciones visuales, diagramas, tablas y trazabilidad hasta la fuente. Úselo cuando se le solicite convertir una especificación, un documento de requisitos, una especificación de API, una especificación de producto, un documento de diseño o un documento técnico en HTML legible, especialmente cuando el usuario desea resumir, reestructurar, diagramas, gráficos, imágenes o ayudas visuales en lugar de una conversión literal de Markdown a HTML.
