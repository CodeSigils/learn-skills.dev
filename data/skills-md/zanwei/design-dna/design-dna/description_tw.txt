跨三個維度提取、定義和應用設計DNA：設計系統（代幣）、設計風格（定性感覺）和視覺效果（Canvas、WebGL、3D、粒子、著色器、滾動效果等）。在以下情況下使用此技能：(1) 使用者想要查看完整的 3 維設計結構/模式，(2) 使用者提供參考設計的圖像、螢幕截圖或 URL，並希望將它們分析為涵蓋所有三個維度的結構化 JSON 配置文件，(3) 用戶擁有 Design DNA JSON 和內容，並希望從中生成設計，或者 (4) 這些階段的任意組合。觸發「設計 DNA」、「提取設計風格」、「分析設計」、「參考設計標記」、「從 JSON 生成設計」、「從螢幕截圖設計系統」、「設計配置」、「風格指南 JSON」、「視覺效果分析」、「效果設計」、「3D 設計分析」。
