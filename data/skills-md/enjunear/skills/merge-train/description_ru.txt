Последовательный поезд слияния GitLab, управляемый Клодом. Для каждого MR по порядку: перебазировать → подождать → установить автоматическое слияние → опросить до объединения. Устраняет конфликты перебазирования в сеансе с использованием локального рабочего дерева. Используйте, когда пользователь говорит «/merge-train», «запустить поезд слияния», «объединить эти MR по порядку» или передает список/фильтр GitLab MR для последовательной загрузки. Требуются glab, jq и git для PATH; текущий рабочий каталог должен быть репозиторием проекта GitLab.
