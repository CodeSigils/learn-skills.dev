Correggi i falsi positivi nella revisione delle vibrazioni. Leggi i report sui falsi positivi da GitHub Issues, analizza e modifica i file delle regole delle competenze, rivedi il PR originale per verificare la correzione e crea un PR per la revisione umana. Si attiva quando gli utenti menzionano "修复误报", "correggi falsi positivi" o "problema 处理误报".
