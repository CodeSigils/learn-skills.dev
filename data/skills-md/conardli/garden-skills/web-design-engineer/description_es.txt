Cree artefactos web visuales de alta calidad utilizando HTML/CSS/JavaScript/React: páginas web, páginas de destino, paneles, prototipos interactivos, presentaciones de diapositivas HTML, demostraciones animadas, maquetas de interfaz de usuario, visualizaciones de datos y más.
Utilice esta habilidad siempre que la solicitud del usuario implique un entregable visual, interactivo o de front-end, que incluye:
- Creación de páginas web, páginas de destino, paneles de control, páginas de marketing.
- Creación de prototipos interactivos o maquetas de UI (con marcos de dispositivos)
- Creación de presentaciones/plataformas de diapositivas HTML
- Creación de animaciones CSS/JS o demostraciones animadas basadas en línea de tiempo.
- Convertir maquetas de diseño, capturas de pantalla o PRD en implementaciones interactivas
- Visualización de datos (Chart.js/D3, etc.)
- Exploración del sistema de diseño/kit de interfaz de usuario
Incluso si el usuario no dice explícitamente "HTML" o "página web", esta habilidad se aplica siempre que la intención sea producir algo visual, interactivo o de presentación.
No aplicable: lógica de back-end pura, herramientas CLI, scripts de procesamiento de datos, tareas de código no visuales, depuración de línea de comandos.
