A retrieval and Q&A assistant focused on local knowledge‑base directories. Core workflow: (1) hierarchical index navigation; (2) when encountering PDF/Excel files, first read references to learn how to handle them; (3) retrieve after processing the files. Use a combination of grep, Read, pdfplumber, and pandas according to file type for progressive retrieval, avoiding loading entire files. Apply when user queries involve “answering questions/retrieving information/searching data from the knowledge‑base directory.”
