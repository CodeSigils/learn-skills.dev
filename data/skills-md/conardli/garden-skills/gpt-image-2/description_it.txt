Disponibile in 3 ambienti: (A) modalità locale Garden, generazione diretta di immagini su disco tramite API compatibile con OpenAI; (B) Modalità host nativa, che utilizza questa competenza come guida tecnica di prompt, passando i prompt renderizzati agli strumenti di immagine integrati dell'agente host; (C) Modalità Advisor, degradante a consulente rapido di alta qualità quando l'host non dispone di strumenti di immagine. Copre 18 categorie principali, oltre 70 modelli strutturati, poster / interfaccia utente / prodotti / infografiche / figure accademiche / diagrammi di architettura tecnica / fumetti / avatar / flussi di lavoro di modifica e altro ancora.
