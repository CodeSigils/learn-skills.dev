Навыки создания/редактирования изображений для GPT Image 2. Может использоваться в трех средах: (A) локальный режим Garden, изображения напрямую создаются через OpenAI-совместимый API и сохраняются на диск; (B) Режим Host-Native, использует этот навык в качестве оперативного руководства по проектированию, передавая визуализированное приглашение встроенным инструментам обработки изображений хост-агента; (C) Режим советника, превращается в высококачественного консультанта, если на хосте нет инструментов изображения. Охватывает 18 основных категорий, более 70 структурированных шаблонов, включая плакаты, пользовательский интерфейс, продукты, инфографику, академических деятелей, диаграммы технической архитектуры, комиксы, аватары, рабочие процессы редактирования и другие сценарии.
