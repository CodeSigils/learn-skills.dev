Habilidades de generación/edición de imágenes para GPT Image 2. Se puede utilizar en 3 entornos: (A) Modo local de jardín, genera imágenes directamente a través de una API compatible con OpenAI y las guarda en el disco; (B) Modo Host-Native, utiliza esta Habilidad como guía de ingeniería rápida, pasando el mensaje renderizado a las herramientas de imagen integradas del Agente host; (C) Modo asesor, se degrada a asesor rápido de alta calidad cuando el anfitrión no tiene herramientas de imagen. Cubre 18 categorías principales, más de 70 plantillas estructuradas, que abarcan carteles / UI / productos / infografías / figuras académicas / diagramas de arquitectura técnica / cómics / avatares / flujos de trabajo de edición y otros escenarios.
