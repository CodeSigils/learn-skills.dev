Compétences en génération/édition d'images pour GPT Image 2. Peut être utilisé dans 3 environnements : (A) Mode local Jardin, générant et enregistrant directement des images via une API compatible OpenAI ; (B) Mode hôte natif, utilisant cette compétence comme guide d'ingénierie rapide, transmettant l'invite spécialement conçue à l'outil d'image intégré de l'agent hôte pour la génération ; (C) Mode conseiller, retour à un consultant rapide de haute qualité lorsque l'hôte ne dispose pas d'outils d'image. Couvre 18 catégories principales et plus de 70 modèles structurés, couvrant les affiches/interface utilisateur/produits/infographies/personnalités académiques/schémas d'architecture technique/bandes dessinées/avatars/flux de travail d'édition et autres scénarios.
