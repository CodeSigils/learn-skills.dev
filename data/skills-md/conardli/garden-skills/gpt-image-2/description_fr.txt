Compétences en génération/édition d'images pour GPT Image 2. Peut être utilisé dans 3 environnements : (A) Mode local Garden, génère directement des images via l'API compatible OpenAI et les enregistre sur le disque ; (B) Le mode hôte natif utilise cette compétence comme guide d'ingénierie rapide, en transmettant l'invite rendue aux outils d'image intégrés de l'agent hôte ; (C) Mode Conseiller, se dégrade en consultant rapide de haute qualité lorsque l'hôte ne dispose pas d'outils d'image. Couvre 18 catégories principales, plus de 70 modèles structurés, couvrant les affiches/interface utilisateur/produits/infographies/personnalités académiques/schémas d'architecture technique/bandes dessinées/avatars/flux de travail d'édition et autres scénarios.
