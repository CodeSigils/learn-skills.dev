Fähigkeiten zur Bildgenerierung/-bearbeitung für GPT Image 2. Kann in drei Umgebungen verwendet werden: (A) Garden-Lokalmodus, generiert Bilder direkt über OpenAI-kompatible API und speichert sie auf der Festplatte; (B) Host-Native-Modus, nutzt diesen Skill als technische Anleitung für Eingabeaufforderungen und leitet die gerenderte Eingabeaufforderung an die integrierten Bildtools des Host-Agenten weiter; (C) Advisor-Modus, wird auf einen hochwertigen Prompt-Consulter heruntergestuft, wenn der Host über keine Image-Tools verfügt. Deckt 18 Hauptkategorien, über 70 strukturierte Vorlagen ab, die Poster / Benutzeroberfläche / Produkte / Infografiken / akademische Zahlen / technische Architekturdiagramme / Comics / Avatare / Bearbeitungsworkflows und andere Szenarien umfassen.
