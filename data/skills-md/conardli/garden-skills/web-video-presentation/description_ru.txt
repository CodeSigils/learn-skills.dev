Превратите статью или сценарий закадрового голоса в интерактивную веб-презентацию с соотношением сторон 16:9, которая выглядит как видео, с дополнительным синтезированным звуком закадрового голоса. Процесс: исходная статья → **однократный вывод** сценария озвучки + план разработки → пользователь **единое согласование** пяти элементов (сценарий/схема/тема/ресурсы/режим разработки) → веб-разработка (поглавная/последовательная/параллельная) → дополнительный синтез звука (по умолчанию MiniMax CLImmx‑cli). **В плане планируются только ритм и плотность информации, а не анимация** — анимация создается на лету во время разработки главы в соответствии с правилами ПРИНЦИПЫ + АНТИ‑ИИ. Каждый щелчок продвигает текст закадрового голоса на один такт; каждый шаг занимает весь экран, а индикатор выполнения по умолчанию скрыт и появляется только при наведении курсора мыши. Применимые сценарии: создание видеороликов с веб-страницами (динамический PPT, но не PPT), превращение закадровых сценариев/статей в интерактивные объяснения, запись снимков экрана учебных пособий для Bilibili/YouTube/видеоплатформ, создание демонстраций продуктов/обсуждений с кинематографическим ощущением. Этот навык объединяет методологию дизайна + рабочий процесс совместной работы — не привязанный к какому-либо конкретному стилю/шрифту/цвету – поэтому его можно повторно использовать для любой темы или эстетики.
