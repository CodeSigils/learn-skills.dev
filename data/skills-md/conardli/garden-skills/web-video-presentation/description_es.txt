Convierta un artículo o un guión hablado en una presentación web 16:9 basada en clics que parece un vídeo, con audio en off sintetizado opcional. Proceso: artículo original → **producción única** de un guión de voz en off + plan de desarrollo del esquema → usuario **alineación única** de cinco elementos (guión / esquema / tema / material / modo de desarrollo) → desarrollo web (capítulo por capítulo / secuencial / paralelo) → síntesis de audio opcional (MiniMax CLI mmx-cli predeterminado). **El esquema solo planifica el ritmo y la densidad de la información, no la animación**: la animación se diseña sobre la marcha durante el desarrollo del capítulo de acuerdo con las reglas PRINCIPIOS + ANTI-IA. Cada clic avanza el guión de voz en off un tiempo, cada paso ocupa la pantalla completa, la barra de progreso está oculta de forma predeterminada y aparece solo al pasar el mouse. Casos de uso: crear videos con una página web (PPT dinámico pero no como PPT), convertir un guión/artículo de voz en off en una narración interactiva, grabar tutoriales en pantalla para Bilibili/YouTube/cuentas de video, hacer demostraciones de productos/charlas con una sensación cinematográfica. Esta habilidad incorpora una metodología de diseño + flujo de trabajo de colaboración, no ligada a ningún estilo, fuente o color específico, por lo que puede reutilizarse para cualquier tema o estética.
