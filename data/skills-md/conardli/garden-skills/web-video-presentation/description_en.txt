Turn an article or voice‑over script into a click‑driven, 16:9 web presentation that looks like a video, with optional synthesized voice‑over audio. Process: original article → **single output** of voice‑over script + outline development plan → user **single alignment** of five items (script / outline / theme / material / development mode) → web development (chapter‑by‑chapter / sequential / parallel) → optional audio synthesis (default MiniMax CLI mmx-cli). **The outline only plans rhythm and information density, not animation** — animation is designed on the fly during chapter development according to PRINCIPLES + ANTI‑AI rules. Each click advances one beat of the voice‑over script; each step occupies the full screen, with the progress bar hidden by default and shown only on hover. Use cases: creating a video‑like web page (dynamic PPT but not PPT), turning voice‑over scripts/articles into interactive explanations, recording screen tutorials for Bilibili / YouTube / video accounts, making product or talk demos with a cinematic feel. This skill encapsulates a design methodology + collaboration workflow — it isn’t bound to any specific style/font/color, so it can be reused for any theme or aesthetic.
