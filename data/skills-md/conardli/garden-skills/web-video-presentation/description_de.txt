Verwandeln Sie einen Artikel oder ein Voice-Over-Skript in eine klickgesteuerte 16:9-Webpräsentation, die wie ein Video aussieht, mit optionalem synthetischem Voice-Over-Audio. Prozess: Originalartikel → **einzelne Ausgabe** des Voice-Over-Skripts + Entwurf des Entwicklungsplans → Benutzer **einzelne Ausrichtung** von fünf Elementen (Skript / Entwurf / Thema / Material / Entwicklungsmodus) → Webentwicklung (Kapitel für Kapitel / sequentiell / parallel) → optionale Audiosynthese (Standard MiniMax CLImmx-cli). **Die Gliederung plant nur Rhythmus und Informationsdichte, keine Animation** – Animation wird während der Kapitelentwicklung im Handumdrehen gemäß den PRINCIPLES + ANTI-AI-Regeln entworfen. Mit jedem Klick wird das Voice-Over-Skript um einen Takt vorgerückt. Jeder Schritt nimmt den gesamten Bildschirm ein, wobei der Fortschrittsbalken standardmäßig ausgeblendet ist und nur beim Hover angezeigt wird. Anwendungsfälle: Erstellen einer videoähnlichen Webseite (dynamisches PPT, aber kein PPT), Umwandeln von Voice-Over-Skripten/-Artikeln in interaktive Erklärungen, Aufzeichnen von Bildschirm-Tutorials für Bilibili-/YouTube-/Video-Konten, Erstellen von Produkt- oder Talk-Demos mit filmischem Flair. Diese Fähigkeit umfasst eine Designmethodik und einen Arbeitsablauf für die Zusammenarbeit – sie ist nicht an einen bestimmten Stil/eine bestimmte Schriftart/Farbe gebunden und kann daher für jedes Thema oder jede Ästhetik wiederverwendet werden.
