Crea artefatti Web visivi di alta qualità utilizzando HTML/CSS/JavaScript/React: pagine Web, pagine di destinazione, dashboard, prototipi interattivi, presentazioni di diapositive HTML, demo animate, modelli di interfaccia utente, visualizzazioni di dati e altro ancora.
Utilizza questa competenza ogni volta che la richiesta dell'utente implica un risultato visivo, interattivo o front-end, tra cui:
- Creazione di pagine web, landing page, dashboard, pagine di marketing
- Creazione di prototipi interattivi o mockup dell'interfaccia utente (con frame di dispositivo)
- Creazione di diapositive/presentazioni HTML
- Creazione di animazioni CSS/JS o demo animate basate sulla timeline
- Trasformare modelli di progettazione, screenshot o PRD in implementazioni interattive
- Visualizzazione dei dati (Chart.js / D3, ecc.)
- Esplorazione del sistema di progettazione/kit UI
Anche se l'utente non dice esplicitamente "HTML" o "pagina web", questa abilità si applica ogni volta che l'intento è produrre qualcosa di visivo, interattivo o presentazionale.
Non applicabile: logica back-end pura, strumenti CLI, script di elaborazione dati, attività di codice non visivo, debug della riga di comando.
