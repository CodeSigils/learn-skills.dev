使用 HTML/CSS/JavaScript/React 构建高质量的可视化 Web 工件 — 网页、登陆页面、仪表板、交互式原型、HTML 幻灯片、动画演示、UI 模型、数据可视化等。
当用户的请求涉及视觉、交互式或前端可交付成果时，请使用此技能，包括：
- 创建网页、登陆页面、仪表板、营销页面
- 构建交互式原型或 UI 模型（使用设备框架）
- 构建 HTML 幻灯片/演示文稿
- 创建 CSS/JS 动画或时间线驱动的动画演示
- 将设计模型、屏幕截图或 PRD 转化为交互式实现
- 数据可视化（Chart.js / D3等）
- 设计系统/UI Kit探索
即使用户没有明确地说“HTML”或“网页”，只要意图是产生视觉、交互或演示性的内容，此技能就适用。
不适用：纯后端逻辑、CLI 工具、数据处理脚本、非可视化代码任务、命令行调试。
