使用 HTML/CSS/JavaScript/React 建立高品質的視覺化 Web 工件 — 網頁、登陸頁面、儀表板、互動式原型、HTML 投影片、動畫簡報、UI 模型、資料視覺化等。
當使用者的請求涉及視覺、互動或前端可交付成果時，請使用此技能，包括：
- 建立網頁、登陸頁面、儀表板、行銷頁面
- 建立互動式原型或 UI 模型（使用設備框架）
- 构建 HTML 幻灯片/演示文稿
- 建立 CSS/JS 動畫或時間軸驅動的動畫演示
- 將設計模型、螢幕截圖或 PRD 轉換為互動式實現
- 数据可视化（Chart.js / D3等）
- 设计系统/UI Kit探索
即使使用者沒有明確地說“HTML”或“網頁”，只要意圖是產生視覺、互動或演示性的內容，此技能就適用。
不適用：純後端邏輯、CLI 工具、資料處理腳本、非視覺化程式碼任務、命令列偵錯。
