Verwandeln Sie einen Artikel oder ein Voice-Over-Skript in eine klickgesteuerte 16:9-Webpräsentation, die „wie ein Video aussieht“, mit optionalem synthetischem Sprachaudio. Prozess: Originalartikel → **einzelne Ausgabe** des Voice-Over-Skripts + Gliederung des Entwicklungsplans → Benutzer **einzelne Ausrichtung** von fünf Elementen (Skript / Gliederung / Thema / Assets / Entwicklungsmodus) → Webentwicklung (Kapitel für Kapitel / sequentiell / parallel) → optionale Audiosynthese (Standard MiniMax CLImmx-cli). **Die Gliederung sieht nur Tempo und Informationsdichte vor, nicht die Animation** – die Animation wird während der Kapitelentwicklung spontan gemäß den PRINCIPLES+ANTI-AI-Regeln entworfen. Mit jedem Klick wird das Voice-Over-Skript um einen Takt vorgerückt. Jeder Schritt nimmt den gesamten Bildschirm ein und der Fortschrittsbalken ist standardmäßig ausgeblendet und wird nur angezeigt, wenn Sie mit der Maus darüber fahren. Anwendungsfälle: Erstellen von Videos mit einer Webseite (dynamisches PPT, aber nicht wie PPT), Umwandeln von Voice-Over-Skripten/-Artikeln in interaktive Erzählungen, Aufzeichnen von Tutorial-Screenshots für B-Station-/YouTube-/Videokanäle, Erstellen von Produkt- oder Vortragsdemos mit Kinocharakter. Diese Fähigkeit verkörpert einen Arbeitsablauf aus Designmethodik und Zusammenarbeit – sie ist nicht an einen bestimmten Stil/eine bestimmte Schriftart/Farbe gebunden – und kann daher für jedes Thema und jede Ästhetik wiederverwendet werden.
