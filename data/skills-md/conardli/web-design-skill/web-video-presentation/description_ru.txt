Превратите статью или сценарий закадрового голоса в интерактивную веб-презентацию с соотношением сторон 16:9, которая «выглядит как видео» с дополнительным синтезированным голосовым звуком. Процесс: исходная статья → **единый вывод** сценария озвучки + план разработки → пользователь **единое согласование** пяти элементов (сценарий/схема/тема/ресурсы/режим разработки) → веб-разработка (поглавная/последовательная/параллельная) → дополнительный синтез звука (по умолчанию MiniMax CLImmx‑cli). **В схеме планируются только темп и плотность информации, а не анимация** — анимация создается «на лету» во время разработки главы в соответствии с правилами PRINCIPLES+ANTI‑AI. Каждый щелчок продвигает текст закадрового голоса на один такт; каждый шаг занимает весь экран, а индикатор выполнения по умолчанию скрыт и появляется только при наведении курсора. Варианты использования: создание видеороликов с помощью веб-страницы (динамический PPT, но не PPT), преобразование сценариев/статей закадрового текста в интерактивные повествования, запись обучающих снимков экрана для B-Station/YouTube/видеоканалов, создание демонстраций продукта или разговоров с кинематографическим ощущением. Этот навык воплощает в себе методологию дизайна + рабочий процесс совместной работы — не привязанный к какому-либо конкретному стилю/шрифту/цвету – поэтому его можно повторно использовать для любой темы и эстетики.
