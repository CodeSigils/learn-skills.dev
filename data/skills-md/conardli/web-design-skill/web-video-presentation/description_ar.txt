قم بتحويل مقالة أو نص تعليق صوتي إلى عرض تقديمي على الويب يعتمد على النقر بنسبة 16:9 "يبدو مثل الفيديو" مع صوت صوتي مركب اختياري. العملية: المقالة الأصلية → **إخراج فردي** لنص التعليق الصوتي + خطة تطوير مخطط تفصيلي → المستخدم **محاذاة فردية** لخمسة عناصر (النص/المخطط التفصيلي/الموضوع/الأصول/وضع التطوير) → تطوير الويب (فصل بفصل/متسلسل/متوازي) → تركيب صوتي اختياري (افتراضي MiniMax CLImmx‑cli). **يخطط المخطط التفصيلي فقط للوتيرة وكثافة المعلومات، وليس الرسوم المتحركة** — يتم تصميم الرسوم المتحركة بسرعة أثناء تطوير الفصل وفقًا لقواعد PRINCIPLES+ANTI‑AI. تؤدي كل نقرة إلى تقدم إيقاع واحد من نص التعليق الصوتي؛ تشغل كل خطوة الشاشة بأكملها، ويكون شريط التقدم مخفيًا بشكل افتراضي، ولا يظهر إلا عند التمرير. حالات الاستخدام: إنشاء مقاطع فيديو باستخدام صفحة ويب (PPT ديناميكي ولكن ليس مثل PPT)، وتحويل النصوص/المقالات الصوتية إلى روايات تفاعلية، وتسجيل لقطات الشاشة التعليمية لقنوات B‑Station / YouTube / الفيديو، وإنشاء عروض توضيحية للمنتج أو الحديث مع إحساس سينمائي. تجسد هذه المهارة منهجية التصميم + سير عمل التعاون - غير مرتبطة بأي نمط / خط / لون محدد - بحيث يمكن إعادة استخدامها لأي موضوع أو جمالية.
