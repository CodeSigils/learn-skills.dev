Turn an article or voice‑over script into a click‑driven 16:9 web presentation that “looks like a video,” with optional synthesized voice audio. Process: original article → **single output** of voice‑over script + outline development plan → user **single alignment** of five items (script / outline / theme / assets / development mode) → web development (chapter‑by‑chapter / sequential / parallel) → optional audio synthesis (default MiniMax CLI mmx‑cli). **The outline only plans pacing and information density, not animation** — animation is designed on the fly during chapter development according to PRINCIPLES + ANTI‑AI rules. Each click advances one beat of the voice‑over script; each step occupies the full screen, and the progress bar is hidden by default, appearing only on hover. Use cases: creating videos with a web page (dynamic PPT but not like PPT), turning voice‑over scripts/articles into interactive narrations, recording tutorial screen captures for B‑Station / YouTube / video channels, making product or talk demos with a cinematic feel. This skill embodies a design methodology + collaboration workflow — not bound to any specific style/font/color — so it can be reused for any theme and aesthetic.
