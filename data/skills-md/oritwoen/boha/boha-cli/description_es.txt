Utilice la CLI de boha para explorar, buscar, verificar y exportar datos de criptoacertijos. Se activa cuando se ejecutan comandos boha, se realizan secuencias de comandos para búsquedas de acertijos, se canalizan datos de acertijos a otras herramientas o se verifican saldos desde la terminal. No lo utilice para la integración de la biblioteca Rust; en su lugar, consulte la habilidad boha.
