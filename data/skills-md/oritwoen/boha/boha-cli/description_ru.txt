Используйте интерфейс командной строки boha для просмотра, поиска, проверки и экспорта данных крипто-головоломки. Запускается при запуске команд boha, выполнении сценариев поиска головоломок, передаче данных головоломок в другие инструменты или проверке баланса с терминала. Не используйте для интеграции библиотеки Rust — вместо этого см. навык boha.
