Используйте этот навык для задач миграции существующих проектов Customware, которые перемещают загруженные клиентские приложения из других сборщиков в стандартный стек Customware, сохраняя при этом маршруты, рабочие процессы, пользовательский интерфейс, UX и стиль исходного продукта без преднамеренных изменений с точки зрения пользователя и заменяя только основу среды выполнения. Этот навык охватывает как «Сборку миграции», так и «Проверку миграции», а также включает в себя контроль качества самооценки, который должен пройти, прежде чем задача сможет быть завершена.
