هذه المهارة هي تعليمات تنفيذية صارمة، وليست نصًا مرجعيًا استشاريًا. تتعامل هذه المهارة مع HTML كمدخل للاكتشاف فقط، وتفرض التقاط المسار/الحالة التفاعلية للكاتب المسرحي، ثم تنتقل عبر البوابات المسجلة لقبول المصدر، وتخطيط التنفيذ، وإعادة إنتاج واجهة المستخدم المؤلفة، وتكامل التنفيذ، والتحقق المرئي، وإثبات الخصومة قبل التوقيع.
