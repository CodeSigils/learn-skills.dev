Habilidad vertical de configuración de cotización de precio (CPQ) para Customware SPA. Define el diseño de la sección, el esquema de configuración, las plantillas de reglas comerciales y las reglas de asignación deterministas para transformar un DOMAIN.md en un objeto de configuración CPQ. Utilice esta habilidad cuando el Agente Constructor clasifique el dominio de un cliente como un sistema de cotización, fijación de precios o configuración de productos. Señales de activación: productos con dependencias, listas de precios, cálculos de margen/margen, generación de cotizaciones, flujos de trabajo de propuestas, compatibilidad de accesorios, opciones de configuración de productos.
