استخدم هذه المهارة عند إضافة أو تغيير دردشة الذكاء الاصطناعي، أو إنشاء النص، أو الاستدلال، أو الأدوات، أو اختيار النموذج، أو مخرجات JSON المنظمة في تطبيق React Router وتطبيق Hono الذي تم إنشاؤه بواسطة البرامج المخصصة. وهو يغطي بوابة AI المخصصة للخادم فقط، وAI SDK مع محول OpenRouter، وAI Elements UI، وخيارات النماذج المدعومة، والنماذج الحية الإلزامية وفحوصات المخرجات المنظمة.
