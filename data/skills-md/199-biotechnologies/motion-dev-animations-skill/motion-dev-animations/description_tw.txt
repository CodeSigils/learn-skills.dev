使用 Motion.dev（Framer Motion 後繼者）為 React、Next.js、Svelte 和 Astro 專案建立 120fps GPU 加速動畫。當使用者請求動畫、運動、滾動效果、視差、英雄動畫、手勢、拖曳互動、彈簧物理、whileHover 效果、whileInView 動畫、動畫 UI、微互動、頁面轉換或佈局動畫時使用。產生具有可訪問性（首選減少運動）和效能驗證（≥60fps）的生產 TypeScript/JSX 程式碼。支援入口動畫、手勢互動（懸停/點擊/拖曳）、基於滾動的顯示以及使用彈簧物理和自然計時的佈局轉換。請勿用於純 CSS 轉換（使用原生 CSS）、沒有 JavaScript 的靜態網站、Vue 動畫（使用 Motion-v 變體）或 SVG/Canvas 複雜動畫（GSAP 更適合）。
