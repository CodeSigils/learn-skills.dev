React, Next.js, Svelte 및 Astro 프로젝트용 Motion.dev(Framer Motion 후속 버전)를 사용하여 120fps GPU 가속 애니메이션을 생성합니다. 사용자가 애니메이션, 모션, 스크롤 효과, 시차, 히어로 애니메이션, 제스처, 드래그 상호 작용, 스프링 물리학, whileHover 효과, whileInView 애니메이션, 애니메이션 UI, 마이크로 상호 작용, 페이지 전환 또는 레이아웃 애니메이션을 요청할 때 사용합니다. 접근성(모션 감소 선호) 및 성능 검증(≥60fps)을 통해 프로덕션 TypeScript/JSX 코드를 생성합니다. 스프링 물리학과 자연스러운 타이밍을 사용하여 입구 애니메이션, 제스처 상호 작용(호버/탭/드래그), 스크롤 기반 표시 및 레이아웃 전환을 지원합니다. CSS 전용 전환(네이티브 CSS 사용), JavaScript가 없는 정적 사이트, Vue 애니메이션(대신 Motion-V 변형 사용) 또는 SVG/Canvas 복합 애니메이션(GSAP가 더 적합)에는 사용하지 마세요.
