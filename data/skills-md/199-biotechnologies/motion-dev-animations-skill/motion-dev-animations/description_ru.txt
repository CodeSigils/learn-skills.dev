Создает анимацию с ускорением графического процессора 120 кадров в секунду с помощью Motion.dev (преемника Framer Motion) для проектов React, Next.js, Svelte и Astro. Используйте, когда пользователь запрашивает анимацию, движение, эффекты прокрутки, параллакс, анимацию героев, жесты, взаимодействие перетаскивания, пружинную физику, эффекты whileHover, анимацию whileInView, анимированный пользовательский интерфейс, микровзаимодействия, переходы страниц или анимацию макета. Генерирует рабочий код TypeScript/JSX с доступностью (предпочитает пониженное движение) и проверкой производительности (≥60 кадров в секунду). Поддерживает анимацию входа, взаимодействие жестов (наведение/касание/перетаскивание), отображение на основе прокрутки и переходы макета с использованием пружинной физики и естественного времени. НЕ используйте для переходов только с помощью CSS (используйте собственный CSS), статических сайтов без JavaScript, анимации Vue (вместо этого используйте вариант motion-v) или сложных анимаций SVG/Canvas (лучше подходит GSAP).
