Crea animaciones aceleradas por GPU de 120 fps con Motion.dev (sucesor de Framer Motion) para proyectos React, Next.js, Svelte y Astro. Úselo cuando el usuario solicite animación, movimiento, efectos de desplazamiento, paralaje, animaciones de héroe, gestos, interacciones de arrastre, física de resorte, efectos de desplazamiento, animaciones whileInView, interfaz de usuario animada, microinteracciones, transiciones de página o animaciones de diseño. Genera código TypeScript/JSX de producción con accesibilidad (prefiere movimiento reducido) y validación de rendimiento (≥60 fps). Admite animaciones de entrada, interacciones de gestos (desplazar/tocar/arrastrar), revelaciones basadas en desplazamiento y transiciones de diseño utilizando física de primavera y sincronización natural. NO lo use para transiciones solo CSS (use CSS nativo), sitios estáticos sin JavaScript, animaciones Vue (use la variante motion-v en su lugar) o animaciones complejas SVG/Canvas (GSAP es más adecuado).
