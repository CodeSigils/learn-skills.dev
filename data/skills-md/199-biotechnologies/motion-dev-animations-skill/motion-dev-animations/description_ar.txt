ينشئ رسومًا متحركة مسرعة باستخدام وحدة معالجة الرسومات بمعدل 120 إطارًا في الثانية باستخدام Motion.dev (خليفة Framer Motion) لمشروعات React وNext.js وSvelte وAstro. يُستخدم عندما يطلب المستخدم الرسوم المتحركة، أو الحركة، أو تأثيرات التمرير، أو اختلاف المنظر، أو الرسوم المتحركة البطل، أو الإيماءات، أو تفاعلات السحب، أو فيزياء الربيع، أو تأثيرات whileHover، أو الرسوم المتحركة whileInView، أو واجهة المستخدم المتحركة، أو التفاعلات الدقيقة، أو انتقالات الصفحة، أو الرسوم المتحركة للتخطيط. يُنشئ كود TypeScript/JSX للإنتاج مع إمكانية الوصول (يفضل الحركة المنخفضة) والتحقق من صحة الأداء (≥60 إطارًا في الثانية). يدعم الرسوم المتحركة للدخول، وتفاعلات الإيماءات (التمرير/النقر/السحب)، والكشف القائم على التمرير، وانتقالات التخطيط باستخدام فيزياء الربيع والتوقيت الطبيعي. لا تستخدمه في انتقالات CSS فقط (استخدم CSS الأصلي)، أو المواقع الثابتة التي لا تحتوي على JavaScript، أو رسوم Vue المتحركة (استخدم متغيرmotion-v بدلاً من ذلك)، أو الرسوم المتحركة المعقدة SVG/Canvas (GSAP أكثر ملاءمة).
