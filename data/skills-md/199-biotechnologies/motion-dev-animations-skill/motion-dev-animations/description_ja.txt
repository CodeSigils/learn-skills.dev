React、Next.js、Svelte、Astro プロジェクト向けに Motion.dev (Framer Motion の後継) を使用して 120fps の GPU アクセラレーション アニメーションを作成します。ユーザーがアニメーション、モーション、スクロール効果、視差、ヒーロー アニメーション、ジェスチャー、ドラッグ インタラクション、スプリング物理学、whileHover 効果、whileInView アニメーション、アニメーション UI、マイクロ インタラクション、ページ遷移、またはレイアウト アニメーションを要求する場合に使用します。アクセシビリティ (モーションの削減を優先) とパフォーマンス検証 (60fps 以上) を備えたプロダクション TypeScript/JSX コードを生成します。入場アニメーション、ジェスチャー インタラクション (ホバー/タップ/ドラッグ)、スクロール ベースの表示、スプリング物理学と自然なタイミングを使用したレイアウト遷移をサポートします。 CSS のみのトランジション (ネイティブ CSS を使用)、JavaScript を使用しない静的サイト、Vue アニメーション (代わりに motion-v バリアントを使用)、または SVG/Canvas の複雑なアニメーション (GSAP の方が適しています) には使用しないでください。
