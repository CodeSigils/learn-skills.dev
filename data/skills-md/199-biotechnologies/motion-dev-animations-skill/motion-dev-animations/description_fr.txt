Crée des animations accélérées par GPU à 120 ips avec Motion.dev (successeur de Framer Motion) pour les projets React, Next.js, Svelte et Astro. À utiliser lorsque l'utilisateur demande une animation, un mouvement, des effets de défilement, une parallaxe, des animations de héros, des gestes, des interactions de glisser, une physique de ressort, des effets whileHover, des animations whileInView, une interface utilisateur animée, des micro-interactions, des transitions de page ou des animations de mise en page. Génère du code de production TypeScript/JSX avec accessibilité (préfère le mouvement réduit) et validation des performances (≥60 ips). Prend en charge les animations d'entrée, les interactions gestuelles (survol/appui/glisser), les révélations par défilement et les transitions de mise en page utilisant la physique du printemps et le timing naturel. Ne pas utiliser pour les transitions CSS uniquement (utilisez CSS natif), les sites statiques sans JavaScript, les animations Vue (utilisez plutôt la variante motion-v) ou les animations complexes SVG/Canvas (GSAP mieux adapté).
