Convierta los diseños de Figma en HTML+CSS listos para producción a través de un proceso estructurado de cinco fases con control de calidad visual. Úselo cuando el usuario quiera convertir un diseño de Figma en código, dividir una maqueta de Figma en una página web o codificar una URL de Figma. Activadores en: Figma URL (figma.com/design/...), "figma to code", "切版", "slicing", "convertir diseño", "implementar este diseño", "codificar esta maqueta". Requiere conexión al servidor Figma MCP.
