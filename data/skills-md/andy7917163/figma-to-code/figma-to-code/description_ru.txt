Преобразуйте проекты Figma в готовый к использованию HTML+CSS с помощью структурированного пятиэтапного конвейера с визуальным контролем качества. Используйте, когда пользователь хочет преобразовать дизайн Figma в код, разрезать макет Figma на веб-страницу или закодировать URL-адрес Figma. Запускается по: URL Figma (figma.com/design/...), «figma to code», «切版», «нарезка», «конвертировать дизайн», «реализовать этот дизайн», «закодировать этот макет». Требуется подключение к серверу Figma MCP.
