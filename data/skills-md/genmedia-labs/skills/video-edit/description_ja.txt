RunComfy で既存のビデオを編集する — このスキルは、ユーザーの意図を RunComfy カタログ内の適切な編集モデルに一致させるスマート ルーターです。 Wan 2.7 Edit-Video (一般的なリスタイル / 背景スワップ / パッケージング スワップ、アイデンティティ + モーション保存)、Kling 2.6 Pro Motion Control (リファレンス ビデオからターゲット キャラクタに正確なモーションを転送)、または Lucy Edit Restyle (軽量でアイデンティティが安定したリスタイル / 衣装スワップ) を選択します。各モデルの文書化されたプロンプト パターンをバンドルすることで、間違ったモデルでイテレーションを書き込むことなく、スキルがよりシャープに編集できるようになります。ローカルの RunComfy CLI を介して `runco​​mfy run <vendor>/<model>/<endpoint>` を呼び出します。 「ビデオ編集」、「ビデオ編集」、「ビデオのスタイル変更」、「ビデオ背景の交換」、「モーション コントロール」、「ビデオの衣装交換」、またはビデオを変換するための明示的な要求でトリガーされます。
