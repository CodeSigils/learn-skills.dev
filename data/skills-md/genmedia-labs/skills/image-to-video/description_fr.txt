Animez n'importe quelle image fixe sur RunComfy — cette compétence est un routeur intelligent qui fait correspondre l'intention de l'utilisateur au bon modèle i2v dans le catalogue RunComfy. Choisit HappyHorse 1.0 I2V (Arena #1, audio natif, préservation de l'identité) pour les animations générales, Wan 2.7 avec `audio_url` pour la synchronisation labiale de voix off personnalisée, ou Seedance 2.0 Pro pour une animation multimodale à partir d'une image + vidéo de référence + audio de référence. Regroupe les modèles d'invite documentés de chaque modèle afin que l'appelant obtienne un résultat plus précis sans graver d'itérations sur le mauvais modèle. Appelle « runcomfy run <vendor>/<model>/image-to-video » (ou variante de point de terminaison) via la CLI RunComfy locale. Déclencheurs sur "image en vidéo", "image en vidéo", "i2v", "animer l'image", "faire ce mouvement" ou toute demande explicite de transformer une image fixe en vidéo.
