Анимируйте любое неподвижное изображение в RunComfy — этот навык представляет собой интеллектуальный маршрутизатор, который сопоставляет намерение пользователя с нужной моделью i2v в каталоге RunComfy. Выбирает HappyHorse 1.0 I2V (Арена № 1, собственный звук, сохранение идентичности) для общей анимации, Wan 2.7 с `audio_url` для синхронизации губ с настраиваемой озвучкой или Seedance 2.0 Pro для мультимодальной анимации из изображения + эталонного видео + эталонного аудио. Объединяет документированные шаблоны подсказок для каждой модели, чтобы вызывающая сторона получала более четкие выходные данные, не записывая итерации на неправильную модель. Вызывает `runcomfy run <vendor>/<model>/image-to-video` (или вариант конечной точки) через локальный интерфейс командной строки RunComfy. Запускается по «изображению в видео», «изображению в видео», «i2v», «анимации изображения», «сделай этот ход» или любому явному запросу превратить фотографию в видео.
