Композиционный навык, который превращает записи встреч в структурированные протоколы. Поддерживает транскрипцию Step ASR, диаризацию говорящего в pyannote, сопоставление голосовых отпечатков с именами, генерацию структурированных сводок и поэтапную инкрементную обработку для длинных записей.

Условия триггера:
(1) Пользователь отправляет аудиофайл собрания (mp3/wav/ogg/opus/m4a/flac).
(2) Пользователь говорит: «Подведите итоги встречи», «Протокол встречи», «Подведите итоги по этой записи», «Краткий обзор встречи».
(3) Пользователь говорит «зарегистрировать голосовой отпечаток», «запомнить мой голос», «зарегистрировать голосовой отпечаток».
(4) Пользователь говорит «кто говорит», «определить говорящего», «определить говорящего».
(5) Пользователь отправляет аудиофайл и запрашивает транскрипцию с метками говорящих.
(6) Пользователь сначала запрашивает быстрые минуты, а затем уточняет точность динамика.
(7) Пользователь просит создать новое резюме встречи со ссылкой на исторический стиль протокола.

Используемые модели:
- Транскрипция ASR: `step-asr` (конечная точка загрузки файла)
- LLM (оценка численности персонала + генерация минут): `step-3.5-flash` (можно переопределить через env var MEETING_SUMMARY_LLM_MODEL)

Зависимости:
- Ключ API StepFun (ASR + LLM) — подайте заявку по адресу https://platform.stepfun.com/interface-key.
- ffmpeg (предварительная обработка звука)
- Python: numpy, scipy, звуковой файл, onnxruntime
- Необязательно: pyannote.audio (отдельный венв, требуется PyTorch)
- Локальным моделям (wespeaker/pyannote) требуется учетная запись Hugging Face и разрешение на загрузку с https://huggingface.co/.
- См. ссылки/setup-guide.md
