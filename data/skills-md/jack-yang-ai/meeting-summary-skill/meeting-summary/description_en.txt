An orchestration skill that converts meeting recordings into structured minutes. Supports Step ASR transcription, pyannote speaker diarization, voiceprint-to-name matching, structured summary generation, and chunked incremental processing of long recordings.

Trigger conditions:
(1) User sends a meeting audio file (mp3/wav/ogg/opus/m4a/flac)
(2) User says “summarize meeting,” “meeting minutes,” “summarize this recording,” or “meeting summary”
(3) User says “register voiceprint,” “remember my voice,” or “enroll voiceprint”
(4) User says “who’s speaking,” “identify speaker,” or “identify speaker”
(5) User sends an audio file and requests transcription with speaker labels
(6) User asks for quick minutes first, then refined speaker accuracy
(7) User requests new meeting summary styled after historical minutes

Models used:
- ASR transcription: `step-asr` (file-upload endpoint)
- LLM (headcount estimation + minutes generation): `step-3.5-flash` (overridable via env var MEETING_SUMMARY_LLM_MODEL)

Dependencies:
- StepFun API Key (ASR + LLM) — apply at https://platform.stepfun.com/interface-key
- ffmpeg (audio preprocessing)
- Python: numpy, scipy, soundfile, onnxruntime
- Optional: pyannote.audio (separate venv, needs PyTorch)
- Local models (wespeaker / pyannote) require Hugging Face account registration and permission download from https://huggingface.co/
- See references/setup-guide.md
