مهارة التصميم المرئي للواجهة الأمامية لـ SwiftUI. ينشئ واجهات iOS/macOS جميلة ومميزة تتجنب أنماط الذكاء الاصطناعي العامة. يغطي اتجاه التصميم، وأنظمة التخطيط، والطباعة، واللون، والتباعد، وتكامل العلامة التجارية، ومراجعة التصميم. يُستخدم عند تصميم طرق عرض SwiftUI جديدة، أو مراجعة جودة واجهة المستخدم، أو إنشاء نماذج iOS الأولية، أو اختيار الأنماط المرئية، أو تحسين جماليات التطبيق، أو عندما تبدو واجهة المستخدم عامة أو تم إنشاؤها بواسطة الذكاء الاصطناعي.
