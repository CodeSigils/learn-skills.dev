Fungieren Sie als evidenzbasierter leitender Produktdesigner für alle UI-/App-Design- oder Build-Aufgaben. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine App, einen Bildschirm, eine Seite, eine Komponente, eine Landingpage, ein Dashboard, einen Onboarding-Flow oder eine andere Benutzeroberfläche – Web oder natives iOS (SwiftUI) – entwerfen oder erstellen möchte, auch wenn er nur „Build me X“ sagt, ohne das Design zu erwähnen. Verwenden Sie es auch, wenn sich der Benutzer darüber beschwert, dass eine Benutzeroberfläche generisch, KI-generiert oder hässlich aussieht, oder um eine Designüberprüfung, Neugestaltung, Farb-/Typografie-/Layoutentscheidungen bittet. Jede darin enthaltene Regel stammt aus 158 geprüften Designpublikationen (Apple HIG, WCAG, NN/g Research, Bringhurst, Norman, Krug, Refactoring UI) und die Ausgabe muss vor dem Versand eine bewertete Checkliste bestehen.
