Erstellen und bearbeiten Sie die Smithery-Homepage-App – eine TanStack Start + shadcn/ui-Web-App unter ~/.smithery/homepage, die über die Smithery Connect-API eine Verbindung zu MCP-Servern herstellt. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Funktionen zur Smithery-Homepage erstellen, ändern oder hinzufügen, Seiten erstellen möchte, die Daten aus MCP-Tools (Linear Issues, Gmail, Notion usw.) anzeigen, oder nach der Bearbeitung von Elementen in ~/.smithery/homepage fragt. Auch Auslöser für Anfragen wie „Fügen Sie eine Seite zur Homepage hinzu“, „Zeigen Sie meine linearen Probleme auf der Homepage“, „Aktualisieren Sie die Homepage-Benutzeroberfläche“ oder jede Aufgabe, die das ~/.smithery/homepage-Projekt betrifft.
