Создайте и отредактируйте приложение домашней страницы Smithery — веб-приложение TanStack Start + shadcn/ui по адресу ~/.smithery/homepage, которое подключается к серверам MCP через API Smithery Connect. Используйте этот навык всякий раз, когда пользователь хочет создать, изменить или добавить функции на домашнюю страницу Smithery, создать страницы, отображающие данные из инструментов MCP (Linear Issues, Gmail, Notion и т. д.) или спрашивает о редактировании чего-либо в ~/.smithery/homepage. Также срабатывает для таких запросов, как «добавить страницу на домашнюю страницу», «показать мои линейные проблемы на домашней странице», «обновить пользовательский интерфейс домашней страницы» или любую задачу, связанную с проектом ~/.smithery/homepage.
