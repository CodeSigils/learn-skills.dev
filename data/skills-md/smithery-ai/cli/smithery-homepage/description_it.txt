Crea e modifica l'app della home page di Smithery: un'app web TanStack Start + shadcn/ui su ~/.smithery/homepage che si connette ai server MCP tramite l'API Smithery Connect. Utilizza questa competenza ogni volta che l'utente desidera creare, modificare o aggiungere funzionalità alla home page di Smithery, creare pagine che visualizzano dati dagli strumenti MCP (Problemi lineari, Gmail, Notion, ecc.) o chiede di modificare qualsiasi cosa in ~/.smithery/homepage. Si attivano anche richieste come "aggiungi una pagina alla home page", "mostra i miei problemi Linear sulla home page", "aggiorna l'interfaccia utente della home page" o qualsiasi attività che coinvolga il progetto ~/.smithery/homepage.
