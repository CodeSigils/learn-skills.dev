Cree y edite la aplicación de la página de inicio de Smithery: una aplicación web TanStack Start + shadcn/ui en ~/.smithery/homepage que se conecta a los servidores MCP a través de la API Smithery Connect. Utilice esta habilidad siempre que el usuario desee crear, modificar o agregar funciones a la página de inicio de Smithery, crear páginas que muestren datos de herramientas MCP (problemas lineales, Gmail, Notion, etc.) o solicite editar algo en ~/.smithery/homepage. También activa solicitudes como "agregar una página a la página de inicio", "mostrar mis problemas lineales en la página de inicio", "actualizar la interfaz de usuario de la página de inicio" o cualquier tarea que involucre el proyecto ~/.smithery/homepage.
