Créez et modifiez l'application de page d'accueil de Smithery - une application Web TanStack Start + shadcn/ui à ~/.smithery/homepage qui se connecte aux serveurs MCP via l'API Smithery Connect. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer, modifier ou ajouter des fonctionnalités à la page d'accueil de Smithery, créer des pages qui affichent des données à partir des outils MCP (problèmes linéaires, Gmail, Notion, etc.) ou demande comment modifier quoi que ce soit dans ~/.smithery/homepage. Déclenche également des requêtes telles que « ajouter une page à la page d'accueil », « afficher mes problèmes linéaires sur la page d'accueil », « mettre à jour l'interface utilisateur de la page d'accueil » ou toute tâche impliquant le projet ~/.smithery/homepage.
