Die Instrumente kodieren, sodass das Produktionsverhalten sichtbar und diagnostizierbar ist. Verwenden Sie diese Option, wenn Sie Protokollierung, Metriken, Ablaufverfolgung oder Warnungen hinzufügen. Verwenden Sie diese Option, wenn Sie eine Funktion ausliefern, die in der Produktion ausgeführt wird und Sie einen Nachweis benötigen, dass sie funktioniert. Verwenden Sie diese Option, wenn Produktionsprobleme gemeldet werden, Sie anhand der verfügbaren Daten jedoch nicht erkennen können, was passiert ist.
