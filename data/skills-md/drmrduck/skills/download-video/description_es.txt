Descargue un vídeo (o enumere sus URL MP4 directas) desde una publicación de Twitter/X, TikTok, Instagram o YouTube: sin inicio de sesión, sin marca de agua, hasta 1080p. Déle una publicación/tweet/reel/URL corta y devolverá enlaces de descarga CDN directos para cada variante de calidad, además de autor, título, miniatura y metadatos, y puede guardar el archivo directamente en el disco. Úselo cada vez que un usuario diga "descargar este video", "tomar este video de tweet", "guardar este TikTok/Reel/Short", "obtener el MP4", "descargar sin marca de agua", "extraer este video" o pegue un enlace de publicación social y quiera los medios. Desarrollado por la API pública de descarga de drummerduck: funciona como un script de una línea, una simple llamada REST o un servidor MCP.
