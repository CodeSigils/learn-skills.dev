Twitter/X、TikTok、Instagram、または YouTube の投稿からビデオをダウンロード (またはその直接 MP4 URL をリスト) — ログインなし、ウォーターマークなし、最大 1080p。投稿/ツイート/リール/短縮 URL を指定すると、すべての品質バリエーションに加えて、作成者、キャプション、サムネイル、メタデータの直接 CDN ダウンロード リンクが返され、ファイルをディスクに直接保存できます。ユーザーが「このビデオをダウンロード」、「このツイートのビデオを取得」、「この TikTok / リール / ショートを保存」、「MP4 を取得」、「ウォーターマークなしでダウンロード」、「このビデオをリッピング」、またはソーシャル投稿リンクを貼り付けてメディアを要求するときに使用します。パブリック Drummerduck ダウンローダー API を利用して、1 行のスクリプト、プレーンな REST 呼び出し、または MCP サーバーとして機能します。
