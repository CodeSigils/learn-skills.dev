Запустить (или расширить) скретчпад / внутреннюю тестовую площадку, доступную только операторам, внутри приложения — единственная закрытая внутренняя страница, использующая реальные компоненты и функции библиотеки проекта, чтобы вы могли визуально оценивать текущую работу: взглянуть на сгенерированные визуалы (OG/социальные карточки, email‑сообщения, аватары, пустые состояния), сравнивать варианты рядом или с помощью живых ползунков, проверять готовность конфигурации/окружения и исполнять реальные процессы с побочными эффектами на фейковых данных — без доставки этого пользователям и без прохождения через весь продукт. Доски и панели настроек получают кнопку «Copy as JSON», чтобы результат, подогнанный визуально, можно было сразу вернуть в код или передать агенту для применения. Подключается к существующему стеку пользователя: определяет используемый фреймворк, схему аутентификации и конвенции окружения, сначала создаёт закрытый механизм доступа, затем маршрут с переключателем разделов, инициализированным из их собственного кода. Используйте, когда пользователь просит «создать скретчпад», «внутреннюю тестовую площадку / девелоперскую песочницу», «страницу предварительного просмотра для оператора/администратора», «страницу для визуальной проверки моей работы», «предпросмотр моих OG‑карт, email‑сообщений, вариантов компонентов», «добавить тестовую страницу для этих компонентов» или «внутреннюю страницу для отработки потока с фейковыми данными». НЕ предназначена для публичных/пользовательских функций, НЕ заменяет тесты (прохождение/провал проверяется автоматически → пишите тест), НЕ является Storybook (это находится внутри реального приложения) и НЕ место для выполнения критически важных производственных операций.
