يساعد المستخدمين على الترحيل من طبقات Azure Cache for Redis (ACR/OSS) الأساسية والقياسية والمتميزة
إلى Azure Managed Redis (AMR). يوفر خرائط SKU ونصوص التسعير في الوقت الفعلي ومقاييس ذاكرة التخزين المؤقت
التقييم والترحيل الآلي عبر واجهات برمجة تطبيقات ARM REST مع تبديل DNS.
يُستخدم عندما يسأل المستخدمون عن: ترحيل Redis، وACR إلى AMR، وOSS إلى AMR، والترحيل الآلي،
ترحيل تبديل DNS، الموعد النهائي لتقاعد ذاكرة التخزين المؤقت، تاريخ التقاعد ACR، اختيار SKU،
ميزات AMR مقابل ACR، توافق الميزات، دعم وحدة Redis، مقارنة الأسعار،
ترقية ذاكرة التخزين المؤقت، ترحيل الطبقة الأساسية/القياسية/المميزة، ترحيل ذاكرة التخزين المؤقت P1/P2/C3،
توصية AMR SKU، التراجع عن الترحيل، التحقق من صحة الترحيل، تغييرات سلسلة الاتصال،
تغييرات المنفذ، وتقييم ذاكرة التخزين المؤقت ومقاييسها، أو التحقق من تحديثات amr-migration-skill.
لا تستخدم من أجل: عمليات ترحيل طبقة Enterprise (ACRE)، أو إنشاء ذاكرات تخزين مؤقت جديدة لـ Redis، أو عامة
