協助使用者從 Azure Cache for Redis (ACR/OSS) 基本、標準和高階層遷移
到 Azure 託管 Redis (AMR)。提供SKU映射、即時定價腳本、快取指標
評估，以及透過帶有 DNS 切換的 ARM REST API 進行自動遷移。
當使用者詢問以下問題時使用：Redis 遷移、ACR 到 AMR、OSS 到 AMR、自動遷移、
DNS 交換器遷移、快取停用截止日期、ACR 停用日期、SKU 選擇、
AMR 與 ACR 功能、功能相容性、Redis 模組支援、價格比較、
快取升級、基本/標準/高階層遷移、P1/P2/C3 快取遷移、
AMR SKU 建議、遷移回溯、遷移驗證、連接字串變更、
連接埠變更、快取評估和指標或檢查 amr-migration-skill 更新。
請勿用於：企業 (ACRE) 層遷移、建立新的 Redis 快取或一般
Redis 效能調優。
