Aiuta gli utenti a eseguire la migrazione dai livelli Basic, Standard e Premium di Cache Redis di Azure (ACR/OSS).
ad Azure Managed Redis (AMR). Fornisce mappatura SKU, script di prezzi in tempo reale, metriche della cache
valutazione e migrazione automatizzata tramite API ARM REST con commutazione DNS.
Da utilizzare quando gli utenti chiedono informazioni su: migrazione Redis, da ACR ad AMR, da OSS ad AMR, migrazione automatizzata,
Migrazione dello switch DNS, scadenza del ritiro della cache, data del ritiro dell'ACR, selezione dello SKU,
Funzionalità AMR e ACR, compatibilità delle funzionalità, supporto del modulo Redis, confronto dei prezzi,
aggiornamento della cache, migrazione del livello Basic/Standard/Premium, migrazione della cache P1/P2/C3,
Raccomandazione SKU AMR, rollback della migrazione, convalida della migrazione, modifiche alla stringa di connessione,
modifiche delle porte, valutazione e metriche della cache o controllo degli aggiornamenti delle competenze di migrazione amr.
NON utilizzare per: migrazioni del livello Enterprise (ACRE), creazione di nuove cache Redis o operazioni generali
Ottimizzazione delle prestazioni di Redis.
