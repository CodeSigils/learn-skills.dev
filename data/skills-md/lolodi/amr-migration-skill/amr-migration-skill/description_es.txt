Ayuda a los usuarios a migrar desde los niveles Básico, Estándar y Premium de Azure Cache for Redis (ACR/OSS)
a Azure Managed Redis (AMR). Proporciona mapeo de SKU, scripts de precios en tiempo real y métricas de caché
evaluación y migración automatizada a través de API ARM REST con conmutación de DNS.
Úselo cuando los usuarios pregunten sobre: migración de Redis, ACR a AMR, OSS a AMR, migración automatizada,
Migración de conmutador DNS, fecha límite de retiro de caché, fecha de retiro de ACR, selección de SKU,
Funciones AMR vs ACR, compatibilidad de funciones, compatibilidad con módulos Redis, comparación de precios,
actualización de caché, migración de nivel Básico/Estándar/Premium, migración de caché P1/P2/C3,
Recomendación de SKU de AMR, reversión de migración, validación de migración, cambios en la cadena de conexión,
cambios de puerto, evaluación y métricas de caché, o verificación de actualizaciones de habilidades de migración de amr.
NO lo use para: migraciones de nivel Enterprise (ACRE), creación de nuevas cachés de Redis o actividades generales.
Ajuste del rendimiento de Redis.
