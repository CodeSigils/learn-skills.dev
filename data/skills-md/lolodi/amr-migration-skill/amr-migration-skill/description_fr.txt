Aide les utilisateurs à migrer depuis les niveaux Azure Cache for Redis (ACR/OSS) Basic, Standard et Premium
vers Azure Managed Redis (AMR). Fournit un mappage SKU, des scripts de tarification en temps réel et des métriques de cache
évaluation et migration automatisée via les API ARM REST avec commutation DNS.
À utiliser lorsque les utilisateurs posent des questions sur : la migration Redis, ACR vers AMR, OSS vers AMR, migration automatisée,
Migration du commutateur DNS, date limite de retrait du cache, date de retrait de l'ACR, sélection du SKU,
Fonctionnalités AMR vs ACR, compatibilité des fonctionnalités, prise en charge du module Redis, comparaison des prix,
mise à niveau du cache, migration de niveau Basic/Standard/Premium, migration de cache P1/P2/C3,
Recommandation SKU AMR, restauration de la migration, validation de la migration, modifications de la chaîne de connexion,
modifications de port, évaluation du cache et métriques, ou vérification des mises à jour amr-migration-skill.
Ne PAS utiliser pour : les migrations de niveau Entreprise (ACRE), la création de nouveaux caches Redis ou des tâches générales.
Optimisation des performances Redis.
