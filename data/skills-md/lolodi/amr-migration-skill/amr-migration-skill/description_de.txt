Hilft Benutzern bei der Migration von Azure Cache for Redis (ACR/OSS) Basic, Standard und Premium
zu Azure Managed Redis (AMR). Bietet SKU-Zuordnung, Preisskripte in Echtzeit und Cache-Metriken
Bewertung und automatisierte Migration über ARM REST APIs mit DNS-Switching.
Verwenden Sie diese Option, wenn Benutzer Folgendes fragen: Redis-Migration, ACR zu AMR, OSS zu AMR, automatisierte Migration,
DNS-Switch-Migration, Cache-Stilllegungsfrist, ACR-Stilllegungsdatum, SKU-Auswahl,
AMR- und ACR-Funktionen, Funktionskompatibilität, Redis-Modulunterstützung, Preisvergleich,
Cache-Upgrade, Migration der Basis-/Standard-/Premium-Stufe, P1/P2/C3-Cache-Migration,
AMR-SKU-Empfehlung, Migrations-Rollback, Migrationsvalidierung, Änderungen der Verbindungszeichenfolge,
Port-Änderungen, Cache-Bewertung und -Metriken oder die Suche nach amr-migration-skill-Updates.
NICHT verwenden für: Migrationen der Enterprise-Stufe (ACRE), das Erstellen neuer Redis-Caches oder allgemein
Redis-Leistungsoptimierung.
