Borrador de historias de usuarios con formato Jira y criterios de aceptación. Utilice esta habilidad siempre que el usuario quiera escribir, crear, redactar, perfeccionar o mejorar una historia de usuario, una epopeya, un ticket o una solicitud de función, especialmente cuando mencione Jira, criterios de aceptación, agilidad, scrum, sprints o elementos pendientes. Activa incluso frases informales como "escribe una historia para...", "crea un ticket para...", "ayúdame a describir esta función" o "Necesito una edición de Jira para...". También se activa cuando el usuario pega una idea aproximada de una característica y quiere que se convierta en una historia estructurada.
