قم بصياغة قصص المستخدم بتنسيق Jira مع معايير القبول. استخدم هذه المهارة عندما يريد المستخدم كتابة أو إنشاء أو صياغة أو تحسين أو تحسين قصة مستخدم أو ملحمة أو تذكرة أو طلب ميزة - خاصة عندما يذكر Jira أو معايير القبول أو Agile أو Scrum أو Sprints أو العناصر المتراكمة. يمكنك تفعيلها حتى عند استخدام العبارات غير الرسمية مثل "اكتب قصة لـ..." أو "أنشئ تذكرة لـ..." أو "ساعدني في وصف هذه الميزة" أو "أحتاج إلى إصدار Jira لـ...". يتم تشغيله أيضًا عندما يلصق المستخدم فكرة ميزة تقريبية ويريد تحويلها إلى قصة منظمة.
