Entwerfen Sie Jira-formatierte User Stories mit Akzeptanzkriterien. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine User Story, ein Epic, ein Ticket oder eine Feature-Anfrage schreiben, erstellen, entwerfen, verfeinern oder verbessern möchte – insbesondere, wenn er Jira, Akzeptanzkriterien, Agile, Scrum, Sprints oder Backlog-Elemente erwähnt. Triggern Sie sogar bei lockeren Formulierungen wie „Schreiben Sie eine Geschichte für …“, „Erstellen Sie ein Ticket für …“, „Hilf mir, diese Funktion zu beschreiben“ oder „Ich benötige eine Jira-Ausgabe für …“. Wird auch ausgelöst, wenn der Benutzer eine grobe Feature-Idee einfügt und möchte, dass daraus eine strukturierte Geschichte wird.
