Bozza di storie tecniche in formato Jira (sottotipi di infrastruttura e applicazione) con criteri di accettazione, per gli elementi del backlog che descrivono un problema di sistema o di ingegneria piuttosto che un'esperienza utente. Utilizza questa competenza ogni volta che l'utente desidera scrivere, creare, abbozzare, perfezionare o migliorare una storia tecnica, una storia di abilitazione, una storia di progettazione, una storia di infrastruttura o qualsiasi PBI che descriva il provisioning IaC, le azioni GitHub/flussi di lavoro CI-CD, Cloud Run o altra distribuzione di risorse cloud, IAM/configurazione dell'account di servizio, pubblicazione del registro Artifact o logica di servizio/funzione backend. Attiva anche frasi casuali come "scrivi una storia per il provisioning di un servizio Cloud Run", "crea un ticket per il flusso di lavoro di applicazione OpenTofu", "storia per i collegamenti IAM" o "trasforma questa attività infrastruttura in una storia". Utilizza invece la competenza User Story quando il PBI descrive una funzionalità rivolta all'uomo, un'interfaccia utente o un'esperienza utente classica. Se non sei sicuro del tipo di storia applicabile, questa abilità include una guida per decidere.
