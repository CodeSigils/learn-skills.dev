قم بصياغة القصص الفنية بتنسيق Jira (الأنواع الفرعية للبنية التحتية والتطبيقات) مع معايير القبول، للعناصر المتراكمة التي تصف نظامًا أو اهتمامًا هندسيًا بدلاً من تجربة المستخدم. استخدم هذه المهارة عندما يريد المستخدم كتابة أو إنشاء أو صياغة أو تحسين أو تحسين قصة فنية أو قصة تمكينية أو قصة هندسية أو قصة تحت الحمراء أو أي PBI تصف توفير IaC أو سير عمل GitHub / CI-CD أو Cloud Run أو نشر الموارد السحابية الأخرى أو IAM / تكوين حساب الخدمة أو نشر Artifact Registry أو منطق الخدمة/الوظيفة الخلفية. يمكنك تشغيله حتى بالنسبة للصياغة غير الرسمية مثل "اكتب قصة لتوفير خدمة Cloud Run"، أو "إنشاء تذكرة لسير عمل تطبيق OpenTofu"، أو "قصة لروابط IAM"، أو "تحويل مهمة الأشعة تحت الحمراء هذه إلى قصة". استخدم مهارة قصة المستخدم بدلاً من ذلك عندما تصف PBI ميزة تواجه الإنسان، أو واجهة مستخدم، أو تجربة مستخدم كلاسيكية. إذا لم تكن متأكدًا من نوع القصة التي تنطبق، فإن هذه المهارة تتضمن إرشادات لاتخاذ القرار.
