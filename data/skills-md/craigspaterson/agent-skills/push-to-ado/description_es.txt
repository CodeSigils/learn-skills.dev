Carga un borrador de una historia de usuario o una historia técnica en Azure DevOps como un elemento de trabajo, completando el título, la descripción, los criterios de aceptación, los puntos de la historia, la prioridad y las etiquetas, y, opcionalmente, vincula una característica principal. También admite la creación de una jerarquía completa de Epic → Feature → Story a partir de un trabajo pendiente estructurado y la actualización masiva de elementos de trabajo existentes. Úselo cuando el usuario diga "enviar a ADO", "crear en ADO", "cargar a ADO", "agregar a ADO", "actualizar elementos de ADO" o algo similar después de que las historias se hayan redactado en una conversación.
