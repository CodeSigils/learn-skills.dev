ドラフトされたユーザー ストーリーまたはテクニカル ストーリーを作業項目として Azure DevOps にアップロードし、タイトル、説明、受け入れ基準、ストーリー ポイント、優先度、タグを入力し、必要に応じて親機能をリンクします。また、構造化されたバックログから完全なエピック → フィーチャー → ストーリー階層を作成したり、既存の作業項目を一括更新したりすることもサポートされています。会話でストーリーの下書きを作成した後、ユーザーが「ADO にプッシュする」、「ADO で作成する」、「ADO にアップロードする」、「ADO に追加する」、「ADO 項目を更新する」などと言うときに使用します。
