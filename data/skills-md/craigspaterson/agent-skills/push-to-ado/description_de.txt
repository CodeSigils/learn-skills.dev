Lädt eine entworfene User Story oder Technical Story als Arbeitselement in Azure DevOps hoch, füllt Titel, Beschreibung, Akzeptanzkriterien, Story-Punkte, Priorität und Tags aus und verknüpft optional eine übergeordnete Funktion. Unterstützt auch die Erstellung einer vollständigen Epic → Feature → Story-Hierarchie aus einem strukturierten Backlog und die Massenaktualisierung vorhandener Arbeitselemente. Wird verwendet, wenn der Benutzer „Push to ADO“, „Create in ADO“, „Upload to ADO“, „Add to ADO“, „Update ADO Items“ oder ähnliches sagt, nachdem Storys im Gespräch entworfen wurden.
