Développez, modifiez, révisez, déboguer, testez ou déployez des applications Webman PHP construites sur Workerman. À utiliser lorsqu'un projet contient un framework Workerman/Webman ou que la tâche concerne explicitement le routage Webman, les contrôleurs, le middleware, la configuration, les travailleurs de longue durée, les processus personnalisés, les files d'attente, les coroutines, les bases de données ou les plugins. Ne pas utiliser pour des projets Workerman autonomes ou PHP, Laravel ou ThinkPHP ordinaires sans Webman.
