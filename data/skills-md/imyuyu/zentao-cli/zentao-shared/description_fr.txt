Bases partagées de ZenTao CLI : initialisation de la configuration, authentification (basée sur un jeton), priorité de configuration, gestion des erreurs d'autorisation, vérification des mises à jour, règles de sécurité. Déclenché lorsque l'utilisateur dit : « configurer zentao », « initialiser la configuration », « config init », « authentifier », « login zentao », « zen tao login », « jeton », « afficher la configuration », « config show », « config set », « variable d'environnement », « ZENTAO_URL », « ZENTAO_TOKEN », « autorisations insuffisantes », « statut d'authentification ».
