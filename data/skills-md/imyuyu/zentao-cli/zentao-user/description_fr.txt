Gestion des utilisateurs ZenTao – répertorie les utilisateurs, affiche les détails des utilisateurs, interroge les utilisateurs par département/rôle. Déclenchez lorsque l'utilisateur dit : « interroger l'utilisateur », « liste d'utilisateurs », « utilisateur 列表 », « afficher l'utilisateur », « détails de l'utilisateur », « membre de l'équipe », « liste des membres », « qui est responsable », « développeur », « testeur », « utilisateur ZenTao ».
