Gestion des produits ZenTao (ZenTao) : répertorie les produits, récupère les détails du produit, crée un produit, met à jour le produit, ferme le produit. Déclenché lorsque l'utilisateur dit : « rechercher un produit », « liste de produits », « quels sont les produits disponibles », « liste de produits », « afficher le produit », « détails du produit », « créer un produit », « nouveau produit », « informations sur le produit », « gamme de produits », « produit ZenTao ».
