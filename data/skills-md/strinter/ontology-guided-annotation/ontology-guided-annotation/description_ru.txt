Используйте этот навык всякий раз, когда пользователь хочет построить обучающие данные на основе онтологии на основе онтологии OWL/RDF/Turtle, а также исходных документов. Он создает проверяемый человеком файл ontology_profile.md, извлекает текст/OCR из PDF-файлов, изображений, DOCX, HTML или текста, интерактивно аннотирует сущности/классы/отношения/свойства для обучения модели, проверяет метки на соответствие ограничениям онтологии, визуализирует результаты проверки в статическом HTML и объединяет проверенные пакеты в наборы данных JSONL плюс review.md. Используйте его для извлечения информации на основе онтологий, создания набора данных аннотаций, маркировки сущностей/отношений, извлечения схем на основе OWL и рабочих процессов, в которых перед принятием меток требуется проверка человеком.
