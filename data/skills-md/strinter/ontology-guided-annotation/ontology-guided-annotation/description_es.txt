Utilice esta habilidad siempre que el usuario desee crear datos de entrenamiento guiados por ontologías a partir de una ontología OWL/RDF/Turtle más documentos fuente. Crea un ontology_profile.md revisable por humanos, extrae texto/OCR ​​de archivos PDF, imágenes, DOCX, HTML o texto, anota interactivamente entidades/clases/relaciones/propiedades para el entrenamiento de modelos, audita etiquetas contra restricciones de ontología, visualiza resultados de revisión en HTML estático y fusiona lotes revisados ​​en conjuntos de datos JSONL más review.md. Úselo para la extracción de información basada en ontologías, la creación de conjuntos de datos de anotaciones, el etiquetado de entidades/relaciones, la extracción de esquemas impulsados ​​por OWL y los flujos de trabajo donde se requiere revisión humana antes de aceptar etiquetas.
