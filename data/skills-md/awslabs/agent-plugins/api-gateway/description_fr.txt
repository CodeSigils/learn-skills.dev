Créez, gérez et exploitez des API avec Amazon API Gateway (REST, HTTP et WebSocket). Déclencheurs sur des expressions telles que : API Gateway, API REST, API HTTP, API WebSocket, domaine personnalisé, autorisateur Lambda, plan d'utilisation, limitation, CORS, lien VPC, API privée. Couvre également le dépannage des erreurs API Gateway (4xx, 5xx, délai d'attente, échecs CORS) et les modèles IaC contenant des ressources API Gateway. Pour la conception générale de l'API REST sans rapport avec AWS, ne déclenchez pas.
