Amazon API Gateway(REST, HTTP 및 WebSocket)를 사용하여 API를 구축, 관리 및 운영합니다. API 게이트웨이, REST API, HTTP API, WebSocket API, 사용자 지정 도메인, Lambda 권한 부여자, 사용량 계획, 조절, CORS, VPC 링크, 프라이빗 API와 같은 문구에서 트리거됩니다. 또한 API 게이트웨이 오류(4xx, 5xx, 시간 초과, CORS 오류) 문제 해결과 API 게이트웨이 리소스가 포함된 IaC 템플릿도 다룹니다. AWS와 관련되지 않은 일반 REST API 설계의 경우 트리거하지 마십시오.
