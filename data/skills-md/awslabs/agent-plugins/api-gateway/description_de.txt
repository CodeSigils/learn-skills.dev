Erstellen, verwalten und betreiben Sie APIs mit Amazon API Gateway (REST, HTTP und WebSocket). Löst auf Phrasen aus wie: API Gateway, REST API, HTTP API, WebSocket API, benutzerdefinierte Domäne, Lambda-Genehmiger, Nutzungsplan, Drosselung, CORS, VPC-Link, private API. Behandelt außerdem die Fehlerbehebung bei API-Gateway-Fehlern (4xx, 5xx, Zeitüberschreitung, CORS-Fehler) und IaC-Vorlagen, die API-Gateway-Ressourcen enthalten. Für allgemeines REST-API-Design, das nichts mit AWS zu tun hat, nicht auslösen.
