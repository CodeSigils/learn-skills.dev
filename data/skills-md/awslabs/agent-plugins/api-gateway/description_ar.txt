يمكنك إنشاء واجهات برمجة التطبيقات وإدارتها وتشغيلها باستخدام Amazon API Gateway (REST وHTTP وWebSocket). مشغلات على عبارات مثل: API Gateway، وREST API، وHTTP API، وWebSocket API، والمجال المخصص، ومصرح Lambda، وخطة الاستخدام، والاختناق، وCORS، ورابط VPC، وواجهة برمجة التطبيقات الخاصة. يغطي أيضًا استكشاف أخطاء بوابة API وإصلاحها (4xx، 5xx، المهلة، فشل CORS) وقوالب IaC التي تحتوي على موارد بوابة API. بالنسبة لتصميم REST API العام غير المرتبط بـ AWS، لا تقم بتشغيله.
