Amazon API Gateway (REST、HTTP、WebSocket) を使用して API を構築、管理、操作します。 API ゲートウェイ、REST API、HTTP API、WebSocket API、カスタム ドメイン、Lambda オーソライザー、使用量プラン、スロットリング、CORS、VPC リンク、プライベート API などのフレーズでトリガーされます。 API ゲートウェイ エラー (4xx、5xx、タイムアウト、CORS エラー) および API ゲートウェイ リソースを含む IaC テンプレートのトラブルシューティングについても説明します。 AWS に関係のない一般的な REST API 設計の場合は、トリガーしないでください。
