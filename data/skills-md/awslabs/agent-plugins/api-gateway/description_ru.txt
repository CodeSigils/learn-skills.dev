Создавайте, управляйте и эксплуатируйте API с помощью Amazon API Gateway (REST, HTTP и WebSocket). Запускается по таким фразам, как: API-шлюз, REST API, HTTP API, WebSocket API, личный домен, авторизатор Lambda, план использования, регулирование, CORS, ссылка VPC, частный API. Также рассматривается устранение ошибок шлюза API (4xx, 5xx, тайм-аут, сбои CORS) и шаблонов IaC, содержащих ресурсы шлюза API. Для общего дизайна REST API, не связанного с AWS, не запускайте триггер.
