Crea, gestisci e utilizza le API con Amazon API Gateway (REST, HTTP e WebSocket). Trigger su frasi come: API Gateway, API REST, API HTTP, API WebSocket, dominio personalizzato, autorizzazione Lambda, piano di utilizzo, limitazione, CORS, collegamento VPC, API privata. Copre anche la risoluzione dei problemi relativi agli errori API Gateway (4xx, 5xx, timeout, errori CORS) e ai modelli IaC contenenti risorse API Gateway. Per la progettazione generale dell'API REST non correlata ad AWS, non attivare.
