Crea e distribuisci app Web e mobili full-stack con AWS Amplify Gen2 (TypeScript code-first). Copre autenticazione (Cognito), dati (AppSync/DynamoDB inclusi modellazione di schemi, tipi di enumerazione, relazioni, regole di autorizzazione), archiviazione (S3), funzioni, API e intelligenza artificiale (Amplify AI Kit con Bedrock). Supporta React, Next.js, Vue, Angular, React Native, Flutter, Swift e Android. Utilizza sempre questa competenza per gli argomenti di Amplify Gen2, anche per le domande che ritieni di conoscere, poiché contiene modelli convalidati specifici della versione che impediscono errori comuni. SI ATTIVA quando: l'utente menziona Amplify Gen2; il progetto ha la directory amplifica/ o amplifica_outputs; il codice importa i pacchetti @aws-amplify; l'utente chiede informazioni su defineBackend, defineAuth, defineData, defineStorage o npx ampx. SALTA: Amplify Gen1 (amplify CLI v6), SAM/CDK autonomo senza Amplify (usa aws-serverless), Bedrock diretto senza Amplify AI Kit (usa bedrock).
