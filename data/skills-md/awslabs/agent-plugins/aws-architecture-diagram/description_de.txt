Generieren Sie mithilfe offizieller AWS4-Symbolbibliotheken validierte AWS-Architekturdiagramme als draw.io-XML. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer AWS-Architekturdiagramme, Cloud-Infrastrukturdiagramme oder Systemdesign-Visualisierungen erstellen, generieren oder entwerfen möchte. Löst auch Anfragen zur Visualisierung vorhandener Infrastruktur aus CloudFormation-, CDK- oder Terraform-Code aus. Unterstützt zwei Modi: Analyse einer vorhandenen Codebasis zur automatischen Generierung von Diagrammen oder interaktives Brainstorming von Grund auf. Exportiert .drawio-Dateien mit optionalem PNG/SVG/PDF-Export über die Draw.io-Desktop-CLI.
