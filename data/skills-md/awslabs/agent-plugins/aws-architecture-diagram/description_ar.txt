قم بإنشاء مخططات بنية AWS تم التحقق من صحتها مثل draw.io XML باستخدام مكتبات أيقونات AWS4 الرسمية. استخدم هذه المهارة عندما يريد المستخدم إنشاء أو إنشاء أو تصميم مخططات بنية AWS أو مخططات البنية التحتية السحابية أو صور تصميم النظام. يؤدي أيضًا إلى تشغيل طلبات تصور البنية التحتية الحالية من كود CloudFormation أو CDK أو Terraform. يدعم وضعين: تحليل قاعدة التعليمات البرمجية الموجودة لإنشاء الرسوم البيانية تلقائيًا، أو تبادل الأفكار بشكل تفاعلي من البداية. تصدير ملفات .drawio مع تصدير PNG/SVG/PDF اختياري عبر واجهة سطر الأوامر لسطح المكتب draw.io.
