Genere diagramas de arquitectura de AWS validados como XML de draw.io utilizando las bibliotecas de iconos oficiales de AWS4. Utilice esta habilidad siempre que el usuario desee crear, generar o diseñar diagramas de arquitectura de AWS, diagramas de infraestructura de nube o imágenes de diseño de sistemas. También activa solicitudes para visualizar la infraestructura existente desde el código de CloudFormation, CDK o Terraform. Admite dos modos: analizar una base de código existente para generar automáticamente diagramas o intercambiar ideas de forma interactiva desde cero. Exporta archivos .drawio con exportación opcional PNG/SVG/PDF a través de la CLI de escritorio de draw.io.
