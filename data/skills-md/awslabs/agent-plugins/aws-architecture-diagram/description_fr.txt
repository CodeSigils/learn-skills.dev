Générez des diagrammes d'architecture AWS validés au format draw.io XML à l'aide des bibliothèques d'icônes officielles AWS4. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer, générer ou concevoir des diagrammes d'architecture AWS, des diagrammes d'infrastructure cloud ou des visuels de conception de système. Déclenche également des requêtes pour visualiser l'infrastructure existante à partir du code CloudFormation, CDK ou Terraform. Prend en charge deux modes : analyser une base de code existante pour générer automatiquement des diagrammes, ou réfléchir de manière interactive à partir de zéro. Exporte les fichiers .drawio avec l'exportation optionnelle PNG/SVG/PDF via la CLI du bureau draw.io.
