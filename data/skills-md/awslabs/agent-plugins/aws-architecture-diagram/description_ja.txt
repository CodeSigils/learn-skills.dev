公式 AWS4 アイコン ライブラリを使用して、検証済みの AWS アーキテクチャ図をdraw.io XML として生成します。ユーザーが AWS アーキテクチャ図、クラウド インフラストラクチャ図、またはシステム設計ビジュアルを作成、生成、または設計したい場合は常に、このスキルを使用します。 CloudFormation、CDK、または Terraform コードから既存のインフラストラクチャを視覚化するリクエストもトリガーします。既存のコードベースを分析して図を自動生成するモード、またはゼロからインタラクティブにブレインストーミングするモードの 2 つをサポートします。オプションの PNG/SVG/PDF エクスポートを使用して、draw.io デスクトップ CLI 経由で .drawio ファイルをエクスポートします。
