Создавайте проверенные диаграммы архитектуры AWS в виде XML-файла draw.io, используя официальные библиотеки значков AWS4. Используйте этот навык всякий раз, когда пользователь хочет создать, сгенерировать или спроектировать диаграммы архитектуры AWS, диаграммы облачной инфраструктуры или визуальные элементы проектирования системы. Также инициирует запросы на визуализацию существующей инфраструктуры из кода CloudFormation, CDK или Terraform. Поддерживает два режима: анализ существующей базы кода для автоматического создания диаграмм или интерактивный мозговой штурм с нуля. Экспортирует файлы .drawio с возможностью экспорта PNG/SVG/PDF через интерфейс командной строки draw.io для настольных компьютеров.
