Genera diagrammi di architettura AWS convalidati come XML draw.io utilizzando le librerie di icone ufficiali di AWS4. Utilizza questa competenza ogni volta che l'utente desidera creare, generare o progettare diagrammi dell'architettura AWS, diagrammi dell'infrastruttura cloud o elementi visivi di progettazione del sistema. Inoltre attiva le richieste di visualizzazione dell'infrastruttura esistente dal codice CloudFormation, CDK o Terraform. Supporta due modalità: analizzare una base di codice esistente per generare automaticamente diagrammi o fare brainstorming in modo interattivo da zero. Esporta file .drawio con esportazione PNG/SVG/PDF opzionale tramite la CLI desktop draw.io.
