Удаленное выполнение команд и передача файлов на узлах кластера SageMaker HyperPod через AWS Systems Manager (SSM). Это основной интерфейс для доступа к узлам HyperPod — прямой SSH недоступен. Используйте, когда какой-либо навык, рабочий процесс или запрос пользователя требуют выполнения команд на узлах кластера, загрузки файлов на узлы, чтения/загрузки файлов с узлов, запуска диагностики, установки пакетов или выполнения любой операции, требующей доступа оболочки к экземплярам HyperPod. Другие навыки HyperPod зависят от этого навыка для всех операций на уровне узла.
