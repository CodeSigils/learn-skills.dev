Ejecución remota de comandos y transferencia de archivos en nodos del clúster SageMaker HyperPod a través de AWS Systems Manager (SSM). Esta es la interfaz principal para acceder a los nodos HyperPod; SSH directo no está disponible. Úselo cuando cualquier habilidad, flujo de trabajo o solicitud de usuario necesite ejecutar comandos en nodos del clúster, cargar archivos en nodos, leer/descargar archivos de nodos, ejecutar diagnósticos, instalar paquetes o realizar cualquier operación que requiera acceso de shell a instancias de HyperPod. Otras habilidades de HyperPod dependen de esta habilidad para todas las operaciones a nivel de nodo.
