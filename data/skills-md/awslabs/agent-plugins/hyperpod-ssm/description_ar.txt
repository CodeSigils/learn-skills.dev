تنفيذ الأوامر عن بعد ونقل الملفات على عقد مجموعة SageMaker HyperPod عبر AWS Systems Manager (SSM). هذه هي الواجهة الأساسية للوصول إلى عقد HyperPod — SSH المباشر غير متاح. يُستخدم عندما تحتاج أي مهارة أو سير عمل أو طلب مستخدم إلى تنفيذ أوامر على عقد المجموعة، أو تحميل الملفات إلى العقد، أو قراءة/تنزيل الملفات من العقد، أو تشغيل التشخيص، أو تثبيت الحزم، أو تنفيذ أي عملية تتطلب وصول Shell إلى مثيلات HyperPod. تعتمد مهارات HyperPod الأخرى على هذه المهارة لجميع العمليات على مستوى العقدة.
