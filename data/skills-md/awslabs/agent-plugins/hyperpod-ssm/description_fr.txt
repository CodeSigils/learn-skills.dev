Exécution de commandes à distance et transfert de fichiers sur les nœuds du cluster SageMaker HyperPod via AWS Systems Manager (SSM). Il s’agit de l’interface principale pour accéder aux nœuds HyperPod – SSH direct n’est pas disponible. À utiliser lorsqu'une compétence, un flux de travail ou une demande d'utilisateur doit exécuter des commandes sur les nœuds du cluster, télécharger des fichiers sur des nœuds, lire/télécharger des fichiers à partir de nœuds, exécuter des diagnostics, installer des packages ou effectuer toute opération nécessitant un accès shell aux instances HyperPod. D'autres compétences HyperPod dépendent de cette compétence pour toutes les opérations au niveau du nœud.
