Remote-Befehlsausführung und Dateiübertragung auf SageMaker HyperPod-Clusterknoten über AWS Systems Manager (SSM). Dies ist die primäre Schnittstelle für den Zugriff auf HyperPod-Knoten – direktes SSH ist nicht verfügbar. Wird verwendet, wenn eine Fertigkeit, ein Arbeitsablauf oder eine Benutzeranforderung Befehle auf Clusterknoten ausführen, Dateien auf Knoten hochladen, Dateien von Knoten lesen/herunterladen, Diagnosen ausführen, Pakete installieren oder Vorgänge ausführen muss, die Shell-Zugriff auf HyperPod-Instanzen erfordern. Andere HyperPod-Fähigkeiten hängen bei allen Vorgängen auf Knotenebene von dieser Fertigkeit ab.
