Esecuzione di comandi remoti e trasferimento di file sui nodi del cluster SageMaker HyperPod tramite AWS Systems Manager (SSM). Questa è l'interfaccia principale per accedere ai nodi HyperPod: SSH diretto non è disponibile. Da utilizzare quando qualsiasi competenza, flusso di lavoro o richiesta utente deve eseguire comandi sui nodi del cluster, caricare file sui nodi, leggere/scaricare file dai nodi, eseguire la diagnostica, installare pacchetti o eseguire qualsiasi operazione che richieda l'accesso della shell alle istanze HyperPod. Altre competenze HyperPod dipendono da questa competenza per tutte le operazioni a livello di nodo.
