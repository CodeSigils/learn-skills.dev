AWS Systems Manager (SSM) を介した SageMaker HyperPod クラスターノードでのリモートコマンド実行とファイル転送。これは、HyperPod ノードにアクセスするためのプライマリ インターフェイスです。直接 SSH は使用できません。スキル、ワークフロー、またはユーザー リクエストで、クラスター ノードでのコマンドの実行、ノードへのファイルのアップロード、ノードからのファイルの読み取り/ダウンロード、診断の実行、パッケージのインストール、または HyperPod インスタンスへのシェル アクセスが必要な操作の実行が必要な場合に使用します。他の HyperPod スキルは、すべてのノードレベルの操作においてこのスキルに依存します。
