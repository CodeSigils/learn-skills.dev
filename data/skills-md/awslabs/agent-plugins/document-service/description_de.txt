Diese Fähigkeit sollte verwendet werden, wenn der Benutzer auffordert: „Diese Codebasis analysieren“, „Diesen Dienst dokumentieren“, „Technische Dokumente generieren“, „Ich habe diesen Code geerbt“, „Mir helfen, dieses System zu verstehen“, „Dokumente für dieses Projekt erstellen“, „Wie sieht dieses System aus“, „Mich in diese Codebasis integrieren“, „Diese Codebasis enthält keine Dokumente“, „Die Architektur aus Code visualisieren“ oder eine explizite Anfrage zum Erstellen strukturierter Dokumentation oder Architekturdiagramme aus einer vorhandenen Codebasis stellt. Speziell optimiert für AWS-Workloads (CDK, CloudFormation, Terraform) mit Quellenangaben. NICHT für Codeüberprüfungen, Erläuterungen zu einzelnen Funktionen, das Generieren von neuem Code oder allgemeine Codierungsaufgaben aktivieren.
