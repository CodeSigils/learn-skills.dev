Cette compétence doit être utilisée lorsque l'utilisateur demande « analyser cette base de code », « documenter ce service », « générer des documents techniques », « j'ai hérité de ce code », « m'aider à comprendre ce système », « créer des documents pour ce projet », « à quoi ressemble ce système », « m'intégrer à cette base de code », « cette base de code n'a pas de documentation », « visualiser l'architecture à partir du code », ou toute demande explicite de produire une documentation structurée ou des diagrammes d'architecture à partir d'une base de code existante. Spécialement optimisé pour les charges de travail AWS (CDK, CloudFormation, Terraform) avec des citations de source de vérité. Ne pas activer pour les révisions de code, les explications sur une seule fonction, la génération de nouveau code ou les tâches de codage générales.
