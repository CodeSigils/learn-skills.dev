Этот навык следует использовать, когда пользователь просит «проанализировать эту кодовую базу», «задокументировать эту услугу», «создать техническую документацию», «Я унаследовал этот код», «помогите мне понять эту систему», «создать документацию для этого проекта», «как выглядит эта система», «подключить меня к этой кодовой базе», «в этой кодовой базе нет документации», «визуализировать архитектуру из кода» или любой явный запрос на создание структурированной документации или архитектурных диаграмм из существующей кодовой базы. Специально оптимизирован для рабочих нагрузок AWS (CDK, CloudFormation, Terraform) со ссылками на достоверные источники. НЕ активируйте для проверки кода, пояснений к отдельным функциям, создания нового кода или общих задач по кодированию.
