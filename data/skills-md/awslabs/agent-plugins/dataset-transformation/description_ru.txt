Создает блокнот Jupyter, который преобразует наборы данных между схемами машинного обучения для обучения или оценки модели. Используйте, когда пользователь говорит «преобразовать», «конвертировать», «переформатировать», «изменить формат» или когда схему набора данных необходимо изменить, чтобы она соответствовала целевому формату — всегда используйте этот навык для изменения формата, а не для написания встроенного кода преобразования. Поддерживает чат OpenAI, SageMaker SFT/DPO/RLVR, настройки HuggingFace, Bedrock Nova, VERL и пользовательские форматы JSONL из локальных файлов или S3.
