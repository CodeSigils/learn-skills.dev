Проектируйте, создавайте, развертывайте, тестируйте и отлаживайте бессерверные приложения с помощью AWS Lambda. Запускается по таким фразам, как: лямбда-функция, источник событий, бессерверное приложение, шлюз API, EventBridge, пошаговые функции, бессерверный API, архитектура, управляемая событиями, триггер Lambda. Для развертывания несерверных приложений на AWS используйте вместо этого плагин Deploy-on-aws.
