Concevez, créez, déployez, testez et déboguez des applications sans serveur avec AWS Lambda. Déclencheurs sur des expressions telles que : fonction Lambda, source d'événement, application sans serveur, API Gateway, EventBridge, Step Functions, API sans serveur, architecture basée sur les événements, déclencheur Lambda. Pour déployer des applications non sans serveur sur AWS, utilisez plutôt le plug-in de déploiement sur aws.
