Progetta, crea, distribuisci, testa ed esegui il debug di applicazioni serverless con AWS Lambda. Trigger su frasi come: funzione Lambda, origine evento, applicazione serverless, gateway API, EventBridge, funzioni Step, API serverless, architettura basata sugli eventi, trigger Lambda. Per la distribuzione di app non serverless su AWS, utilizza invece il plug-in deploy-on-aws.
