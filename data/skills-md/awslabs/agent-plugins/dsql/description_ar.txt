البناء باستخدام Aurora DSQL - إدارة المخططات، وتنفيذ الاستعلامات، والتعامل مع عمليات الترحيل، وتشخيص خطط الاستعلام، وتطوير التطبيقات باستخدام قاعدة بيانات SQL موزعة بدون خادم. يغطي مصادقة IAM، وأنماط المستأجرين المتعددين، وترحيل MySQL إلى DSQL، وعمليات DDL، وإمكانية شرح خطة الاستعلام، والتحقق من توافق SQL. تشغيل عبارات مثل: DSQL، وAurora DSQL، وإنشاء جدول DSQL، ومخطط DSQL، والانتقال إلى DSQL، وقاعدة بيانات SQL الموزعة، وقاعدة بيانات متوافقة مع PostgreSQL بدون خادم، وخطة استعلام DSQL، وDSQL EXPLAIN ANALYZE، لماذا يكون استعلام DSQL الخاص بي بطيئًا.
