Controlla e confronta le versioni dei componenti software sui nodi del cluster SageMaker HyperPod: driver NVIDIA, toolkit CUDA, cuDNN, NCCL, EFA, AWS OFI NCCL, GDRCopy, MPI, Neuron SDK (Trainium/Inferentia), Python e PyTorch. Da utilizzare quando si controllano le versioni dei componenti, si verifica la compatibilità CUDA/driver, si rilevano mancate corrispondenze di versione tra i nodi, si pianificano aggiornamenti, si documenta la configurazione del cluster o si risolvono problemi relativi alla versione su HyperPod. Attiva richieste relative a versioni, compatibilità, controlli dei componenti o pianificazione dell'aggiornamento per i cluster HyperPod.
