فحص ومقارنة إصدارات مكونات البرنامج على العقد العنقودية SageMaker HyperPod - برامج تشغيل NVIDIA، ومجموعة أدوات CUDA، وcuDNN، وNCCL، وEFA، وAWS OFI NCCL، وGDRCopy، وMPI، وNeuron SDK (Trainium/Inferentia)، وPython، وPyTorch. يُستخدم عند التحقق من إصدارات المكونات، أو التحقق من توافق CUDA/برنامج التشغيل، أو اكتشاف عدم تطابق الإصدارات عبر العقد، أو التخطيط للترقيات، أو توثيق تكوين المجموعة، أو استكشاف المشكلات المتعلقة بالإصدار وإصلاحها على HyperPod. يتم تشغيل الطلبات المتعلقة بالإصدارات أو التوافق أو فحوصات المكونات أو تخطيط الترقية لمجموعات HyperPod.
