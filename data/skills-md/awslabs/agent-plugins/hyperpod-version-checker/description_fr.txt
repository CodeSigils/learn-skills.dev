Vérifiez et comparez les versions des composants logiciels sur les nœuds du cluster SageMaker HyperPod : pilotes NVIDIA, boîte à outils CUDA, cuDNN, NCCL, EFA, AWS OFI NCCL, GDRCopy, MPI, Neuron SDK (Trainium/Inferentia), Python et PyTorch. À utiliser pour vérifier les versions des composants, vérifier la compatibilité CUDA/pilote, détecter les incompatibilités de version entre les nœuds, planifier les mises à niveau, documenter la configuration du cluster ou résoudre les problèmes liés à la version sur HyperPod. Se déclenche sur les demandes concernant les versions, la compatibilité, les vérifications des composants ou la planification de la mise à niveau des clusters HyperPod.
