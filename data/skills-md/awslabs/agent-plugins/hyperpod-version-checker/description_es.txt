Verifique y compare las versiones de los componentes de software en los nodos del clúster SageMaker HyperPod: controladores NVIDIA, kit de herramientas CUDA, cuDNN, NCCL, EFA, AWS OFI NCCL, GDRCopy, MPI, Neuron SDK (Trainium/Inferentia), Python y PyTorch. Úselo al verificar las versiones de los componentes, verificar la compatibilidad CUDA/controlador, detectar discrepancias de versiones entre nodos, planificar actualizaciones, documentar la configuración del clúster o solucionar problemas relacionados con la versión en HyperPod. Se activa ante solicitudes sobre versiones, compatibilidad, comprobaciones de componentes o planificación de actualizaciones para clústeres de HyperPod.
