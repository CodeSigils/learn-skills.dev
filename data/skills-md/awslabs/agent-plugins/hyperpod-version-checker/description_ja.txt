SageMaker HyperPod クラスター ノード上のソフトウェア コンポーネントのバージョン (NVIDIA ドライバー、CUDA ツールキット、cuDNN、NCCL、EFA、AWS OFI NCCL、GDRCopy、MPI、Neuron SDK (Trainium/Inferentia)、Python、および PyTorch) を確認および比較します。コンポーネントのバージョンの確認、CUDA/ドライバーの互換性の検証、ノード間でのバージョンの不一致の検出、アップグレードの計画、クラスター構成の文書化、または HyperPod のバージョン関連の問題のトラブルシューティングを行う場合に使用します。 HyperPod クラスターのバージョン、互換性、コンポーネントのチェック、またはアップグレード計画に関するリクエストをトリガーします。
