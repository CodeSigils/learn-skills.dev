トラブルシューティングや AWS サポート ケース用の診断ログと設定を収集することで、HyperPod クラスター (EKS および Slurm) から包括的な問題レポートを生成します。ユーザーが HyperPod クラスターノードから診断を収集する必要がある場合、AWS サポート向けの問題レポートを生成する必要がある場合、ノードの障害やパフォーマンスの問題を調査する必要がある場合、クラスターの状態を文書化する必要がある場合、または診断スナップショットを作成する必要がある場合に使用します。問題レポート、診断収集、サポート ケースの準備、または複数のノードからログとシステム情報を収集する必要があるクラスターのトラブルシューティングを含むリクエストが発生したときにトリガーされます。
