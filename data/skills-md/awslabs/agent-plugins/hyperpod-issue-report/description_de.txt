Generieren Sie umfassende Problemberichte von HyperPod-Clustern (EKS und Slurm), indem Sie Diagnoseprotokolle und Konfigurationen für die Fehlerbehebung und AWS-Supportfälle sammeln. Wird verwendet, wenn Benutzer Diagnosedaten von HyperPod-Clusterknoten sammeln, Problemberichte für den AWS-Support erstellen, Knotenausfälle oder Leistungsprobleme untersuchen, den Clusterstatus dokumentieren oder Diagnose-Snapshots erstellen müssen. Wird bei Anfragen ausgelöst, die Problemberichte, Diagnoseerfassung, Vorbereitung von Supportfällen oder Cluster-Fehlerbehebung betreffen, die das Sammeln von Protokollen und Systeminformationen von mehreren Knoten erfordern.
