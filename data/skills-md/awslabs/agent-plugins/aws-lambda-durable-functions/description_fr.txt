Créez des applications résilientes, de longue durée et en plusieurs étapes avec les fonctions durables d'AWS Lambda avec persistance automatique de l'état, logique de nouvelle tentative et orchestration pour les exécutions de longue durée. Couvre le modèle de relecture critique, les opérations par étapes, les modèles d'attente/rappel, la gestion des erreurs avec le modèle saga, les tests avec LocalDurableTestRunner. Se déclenche sur des expressions telles que : fonctions durables lambda, orchestration de flux de travail, machines à états, modèles de tentatives/points de contrôle, fonctions Lambda avec état de longue durée, modèle saga, rappels humains dans la boucle et applications sans serveur fiables.
