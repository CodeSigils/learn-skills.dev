أنشئ تطبيقات مرنة وطويلة الأمد ومتعددة الخطوات باستخدام وظائف AWS Lambda المتينة مع استمرار الحالة التلقائي ومنطق إعادة المحاولة والتنسيق لعمليات التنفيذ طويلة الأمد. يغطي نموذج إعادة التشغيل الحرج، وعمليات الخطوة، وأنماط الانتظار/رد الاتصال، ومعالجة الأخطاء باستخدام نمط الملحمة، والاختبار باستخدام LocalDurableTestRunner. تشغيل عبارات مثل: وظائف Lambda الدائمة، وتنسيق سير العمل، وأجهزة الحالة، وأنماط إعادة المحاولة/نقطة التفتيش، ووظائف Lambda ذات الحالة طويلة الأمد، ونمط الملحمة، وعمليات رد الاتصال البشرية داخل الحلقة، والتطبيقات الموثوقة بدون خادم.
