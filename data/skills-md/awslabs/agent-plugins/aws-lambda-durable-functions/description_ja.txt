自動状態永続化、再試行ロジック、および長時間実行のオーケストレーションを備えた AWS Lambda 耐久性関数を使用して、回復力があり、長時間実行されるマルチステップ アプリケーションを構築します。クリティカルなリプレイ モデル、ステップ操作、待機/コールバック パターン、saga パターンによるエラー処理、LocalDurableTestRunner によるテストをカバーします。ラムダ永続関数、ワークフロー オーケストレーション、ステート マシン、再試行/チェックポイント パターン、長時間実行ステートフル Lambda 関数、サガ パターン、人間参加型コールバック、信頼性の高いサーバーレス アプリケーションなどのフレーズでトリガーされます。
