Cree aplicaciones resistentes, de larga ejecución y de varios pasos con funciones duraderas de AWS Lambda con persistencia de estado automática, lógica de reintento y orquestación para ejecuciones de larga duración. Cubre el modelo de reproducción crítica, operaciones de pasos, patrones de espera/devolución de llamada, manejo de errores con el patrón saga y pruebas con LocalDurableTestRunner. Se activan frases como: funciones lambda duraderas, orquestación de flujo de trabajo, máquinas de estado, patrones de reintento/punto de control, funciones Lambda con estado de larga duración, patrón saga, devoluciones de llamada humanas en el bucle y aplicaciones confiables sin servidor.
