Создавайте отказоустойчивые, долговыполняющиеся, многоэтапные приложения с помощью устойчивых функций AWS Lambda с автоматическим сохранением состояния, логикой повторных попыток и оркестрацией для длительных выполнения. Охватывает критическую модель воспроизведения, пошаговые операции, шаблоны ожидания/обратного вызова, обработку ошибок с помощью шаблона саги, тестирование с помощью LocalDurableTestRunner. Запускается по таким фразам, как: устойчивые лямбда-функции, оркестровка рабочего процесса, конечные автоматы, шаблоны повторных попыток и контрольных точек, долговыполняющиеся лямбда-функции с сохранением состояния, шаблон саги, обратные вызовы с участием человека в цикле и надежные бессерверные приложения.
