Déploiement AWS SAM et AWS CDK pour les applications sans serveur. Déclencheurs sur des expressions telles que : utiliser SAM, modèle SAM, init SAM, déploiement SAM, CDK sans serveur, construction CDK Lambda, NodejsFunction, PythonFunction, SAM et CDK ensemble, pipeline CI/CD sans serveur. Pour le déploiement général d'applications avec sélection de services, utilisez plutôt le plugin déployer-on-aws.
