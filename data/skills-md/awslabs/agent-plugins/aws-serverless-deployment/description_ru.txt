Развертывание AWS SAM и AWS CDK для бессерверных приложений. Запускается по таким фразам, как: использовать SAM, шаблон SAM, инициализацию SAM, развертывание SAM, бессерверный CDK, конструкцию CDK Lambda, NodejsFunction, PythonFunction, SAM и CDK вместе, бессерверный конвейер CI/CD. Для общего развертывания приложения с выбором службы вместо этого используйте плагин Deploy-on-aws.
