Génère un bloc-notes Jupyter qui déploie des modèles affinés à partir de la personnalisation du modèle sans serveur SageMaker vers les points de terminaison SageMaker ou Bedrock. À utiliser lorsque l'utilisateur dit « déployer mon modèle », « créer un point de terminaison », « le rendre disponible » ou pose des questions sur les options de déploiement. Identifie le chemin de déploiement correct (Nova vs OSS), génère le code de déploiement et gère la configuration des points de terminaison.
