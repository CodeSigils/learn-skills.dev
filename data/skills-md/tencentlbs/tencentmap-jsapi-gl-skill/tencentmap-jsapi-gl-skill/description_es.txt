Guía de desarrollo de Tencent Maps JavaScript GL (JSAPIGL). Adecuado para desarrollar aplicaciones o herramientas de mapas. Esta habilidad debe emplearse al escribir, revisar o depurar código que utiliza la API de Tencent Maps. Se aplica a tareas que involucran inicialización de mapas, visualización de superposiciones, control de capas, manejo de eventos, interacción de widgets, representación visual, herramientas de mapas, búsqueda, planificación de rutas, búsqueda de direcciones, divisiones administrativas, ubicación de IP, cálculos geométricos, visualización de modelos 3D y optimización del rendimiento. Cuando el usuario menciona Tencent Maps, jsapi, jsapi-gl o requisitos de desarrollo de mapas relacionados, debería activarse automáticamente.
