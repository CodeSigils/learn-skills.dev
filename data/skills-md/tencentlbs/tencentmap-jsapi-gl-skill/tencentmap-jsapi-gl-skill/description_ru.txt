Руководство по разработке Tencent Maps JavaScript GL (JSAPIGL). Подходит для разработки картографических приложений или инструментов. Этот навык следует использовать при написании, проверке или отладке кода, использующего API Tencent Maps. Он применяется к задачам, связанным с инициализацией карты, отображением наложения, управлением слоями, обработкой событий, взаимодействием виджетов, визуальной визуализацией, инструментами карты, поиском, планированием маршрута, поиском адреса, административными подразделениями, IP-расположением, геометрическими расчетами, отображением 3D-моделей и оптимизацией производительности. Когда пользователь упоминает Tencent Maps, jsapi, jsapi-gl или соответствующие требования к разработке карт, это должно срабатывать автоматически.
