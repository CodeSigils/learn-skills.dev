Tencent Maps JavaScript GL (JSAPIGL) Entwicklungshandbuch. Geeignet für die Entwicklung von Kartenanwendungen oder -tools. Diese Fähigkeit sollte beim Schreiben, Überprüfen oder Debuggen von Code eingesetzt werden, der die Tencent Maps API verwendet. Es gilt für Aufgaben wie Karteninitialisierung, Overlay-Anzeige, Ebenensteuerung, Ereignisbehandlung, Widget-Interaktion, visuelles Rendering, Kartentools, Suche, Routenplanung, Adresssuche, Verwaltungsgliederung, IP-Standort, geometrische Berechnungen, 3D-Modellanzeige und Leistungsoptimierung. Wenn der Benutzer Tencent Maps, jsapi, jsapi-gl oder verwandte Kartenentwicklungsanforderungen erwähnt, sollte dies automatisch ausgelöst werden.
