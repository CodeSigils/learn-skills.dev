Guía de desarrollo de Tencent Maps JavaScript GL (JSAPIGL). Adecuado para crear aplicaciones o herramientas de mapas. Utilice esta habilidad al escribir, revisar o depurar código que utilice la API de Tencent Maps. Aplicable a tareas que involucran inicialización de mapas, visualización de superposiciones, control de capas, manejo de eventos, interacción de control, representación visual, herramientas de mapas, búsqueda, planificación de rutas, búsqueda de direcciones, divisiones administrativas, geolocalización de IP, cálculos geométricos, visualización de modelos 3D y optimización del rendimiento. Se activa automáticamente cuando el usuario menciona Tencent Maps, jsapi, jsapi-gl o necesidades de desarrollo de mapas relacionados.
