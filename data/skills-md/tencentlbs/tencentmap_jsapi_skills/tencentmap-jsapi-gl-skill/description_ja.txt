Tencent Maps JavaScript GL (JSAPIGL) 開発ガイド。地図アプリケーションまたはツールを構築するため。 Tencent Maps API を使用するコードを作成、レビュー、またはデバッグするときにこのスキルを使用します。マップの初期化、オーバーレイ表示、レイヤー コントロール、イベント処理、コントロール インタラクション、ビジュアル レンダリング、マップ ツール、検索、ルート計画、住所検索、行政区画、IP 地理位置情報、幾何学的計算、3D モデル表示、およびパフォーマンスの最適化を含むタスクに適用されます。ユーザーが Tencent Maps、jsapi、jsapi-gl、または関連するマップ開発のニーズに言及すると、自動的にトリガーされます。
