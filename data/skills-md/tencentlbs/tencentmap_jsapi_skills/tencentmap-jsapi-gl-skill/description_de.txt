Tencent Maps JavaScript GL (JSAPIGL) Entwicklungshandbuch. Für die Erstellung von Kartenanwendungen oder -tools vorgesehen. Verwenden Sie diese Fähigkeit, wenn Sie Code schreiben, überprüfen oder debuggen, der die Tencent Maps-API verwendet. Anwendbar für Aufgaben wie Karteninitialisierung, Overlay-Anzeige, Ebenensteuerung, Ereignisbehandlung, Steuerungsinteraktion, visuelles Rendering, Kartentools, Suche, Routenplanung, Adresssuche, Verwaltungsabteilungen, IP-Geolokalisierung, geometrische Berechnungen, 3D-Modellanzeige und Leistungsoptimierung. Wird automatisch ausgelöst, wenn Benutzer Tencent Maps, jsapi, jsapi-gl oder verwandte Kartenentwicklungsanforderungen erwähnen.
