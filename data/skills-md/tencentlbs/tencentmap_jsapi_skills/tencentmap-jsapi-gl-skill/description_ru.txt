Руководство по разработке Tencent Maps JavaScript GL (JSAPIGL). Подходит для создания картографических приложений или инструментов. Примените этот навык при написании, проверке или отладке кода, использующего API Tencent Maps. Применимо для задач, связанных с инициализацией карты, отображением наложения, управлением слоями, обработкой событий, взаимодействием элементов управления, визуальной визуализацией, инструментами карты, поиском, планированием маршрута, поиском адреса, административными подразделениями, геолокацией IP, геометрическими расчетами, отображением 3D-моделей и оптимизацией производительности. Автоматически запускается, когда пользователи упоминают Tencent Maps, JSAPI, JSAPI-GL или соответствующие потребности в разработке карт.
