دليل تطوير JavaScript GL (JSAPIGL) لخرائط Tencent. لبناء تطبيقات أو أدوات الخرائط. استخدم هذه المهارة عند كتابة أو مراجعة أو تصحيح التعليمات البرمجية التي تستخدم Tencent Maps API. يغطي تهيئة الخريطة، والتراكبات، والتحكم في الطبقة، ومعالجة الأحداث، وتفاعلات التحكم، وعرض التصور، وأدوات الخريطة، والبحث، وتخطيط الطريق، والبحث عن العناوين، والتقسيمات الإدارية، وتحديد الموقع الجغرافي لـ IP، والحسابات الهندسية، وعرض النماذج ثلاثية الأبعاد، وتحسين الأداء. يتم تشغيله تلقائيًا عندما يذكر المستخدمون احتياجات تطوير الخرائط Tencent Maps أو jsapi أو jsapi-gl أو ذات الصلة.
