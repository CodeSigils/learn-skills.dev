دليل تطوير JavaScript GL (JSAPIGL) لخرائط Tencent. مناسبة لبناء تطبيقات أو أدوات الخرائط. استخدم هذه المهارة عند كتابة أو مراجعة أو تصحيح التعليمات البرمجية التي تستخدم Tencent Maps API. ينطبق على المهام التي تتضمن تهيئة الخريطة، وعرض التراكب، والتحكم في الطبقة، ومعالجة الأحداث، وتفاعل التحكم، والعرض المرئي، وأدوات الخريطة، والبحث، وتخطيط الطريق، والبحث عن العنوان، والتقسيمات الإدارية، وتحديد الموقع الجغرافي لـ IP، والحسابات الهندسية، وعرض النماذج ثلاثية الأبعاد، وتحسين الأداء. يتم تشغيله تلقائيًا عندما يذكر المستخدمون احتياجات تطوير الخرائط Tencent Maps أو jsapi أو jsapi-gl أو ذات الصلة.
