Руководство по разработке Tencent Maps JavaScript GL (JSAPIGL). Используйте этот навык при написании, проверке или отладке кода, использующего API Tencent Maps. Применимо к задачам, связанным с инициализацией карты, отображением наложения, управлением слоями, обработкой событий, взаимодействием элементов управления, визуальной визуализацией, инструментами карты, поиском, планированием маршрута, поиском адреса, административными подразделениями, геолокацией IP, геометрическими расчетами, отображением 3D-моделей и оптимизацией производительности. Автоматически запускается, когда пользователи упоминают Tencent Maps, jsapi, jsapi-gl или соответствующие потребности в разработке карт.
