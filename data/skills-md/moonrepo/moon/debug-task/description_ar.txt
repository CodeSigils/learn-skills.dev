تشخيص وإصلاح مهام القمر المعطلة أو التي تم تكوينها بشكل غير صحيح أو التي تعمل بشكل غير متوقع. استخدم هذه المهارة عند فشل مهمة القمر، أو عدم تشغيلها، أو تخطيها، أو تعليقها، أو إنتاج مخرجات قديمة أو خاطئة، أو تخزينها مؤقتًا عندما لا ينبغي ذلك، أو إعادة التشغيل في كل مرة عندما يجب تخزينها مؤقتًا، أو عندما تكون المخرجات فارغة أو مفقودة بعد الوصول إلى ذاكرة التخزين المؤقت. يغطي أيضًا توقف خط الأنابيب وتجميده، والمهام التي تعمل فقط في CI ولكن ليس محليًا (أو العكس)، والمهام التي تم تخطيها بواسطة --facted، ووراثة المهام التي لا تنطبق على المشروع. قم بالتنشيط عند أي إشارة إلى "تشغيل القمر" أو "مهمة القمر" مصحوبة بمشكلة - أخطاء، أو ذاكرة تخزين مؤقت قديمة، أو مخرجات مفقودة، أو نتائج خاطئة، أو "لا يوجد ما يجب فعله"، أو سلوك غير متوقع. استخدم أيضًا لخيارات المهام مثل المستمر، أو runInCI، أوallowFailure، أو FactedFiles، أو Mutex، أو Timeout، أو CacheLifetime. هذه المهارة مخصصة لتشخيص المهام الحالية، وليس لإنشاء مهام جديدة، أو إعداد مساحات العمل، أو تكوين سلاسل الأدوات، أو تعلم مفاهيم القمر.
