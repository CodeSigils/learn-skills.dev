Diagnostica y repara tareas lunares que no funcionan, están mal configuradas o se comportan de forma inesperada. Utilice esta habilidad cuando una tarea lunar falla, no se ejecuta, se omite, se bloquea, genera resultados obsoletos o incorrectos, se almacena en caché cuando no debería, se vuelve a ejecutar cada vez que debería almacenarse en caché o cuando las salidas están vacías o faltan después de un acceso a caché. También cubre bloqueos y congelaciones de canalizaciones, tareas que solo funcionan en CI pero no localmente (o viceversa), tareas omitidas por --affected y herencia de tareas que no se aplican a un proyecto. Actívelo ante cualquier mención de "ejecución lunar" o "tarea lunar" combinada con un problema: errores, caché obsoleto, resultados faltantes, resultados incorrectos, "nada que hacer" o comportamiento inesperado. Úselo también para opciones de tareas como persistente, runInCI, enableFailure, AFfectFiles, mutex, timeout o cacheLifetime. Esta habilidad es para diagnosticar tareas existentes, no para crear nuevas tareas, configurar espacios de trabajo, configurar cadenas de herramientas o aprender conceptos lunares.
