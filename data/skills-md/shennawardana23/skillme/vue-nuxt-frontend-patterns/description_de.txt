Leitet die Entwicklung mit Vue 3 Composition API und Nuxt 3 – Composables, Reaktivität, SSR‑Datenabruf und Komponenten‑Muster. Verwenden Sie es beim Erstellen von Vue‑ oder Nuxt‑Komponenten, Schreiben von Composables, Abrufen von Daten in einer Nuxt‑Seite oder -Komponente, Verwalten von gemeinsamem Zustand mit Pinia oder Debuggen eines Werts, der nach dem Weitergeben „nicht reaktiv ist“.
