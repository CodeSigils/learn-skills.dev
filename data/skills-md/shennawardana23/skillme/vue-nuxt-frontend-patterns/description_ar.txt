دليل لتطوير Vue 3 باستخدام Composition API وNuxt 3 — القابلات لإعادة الاستخدام (composables)، التفاعل، جلب البيانات في SSR، وأنماط المكوّنات. استخدمه عند بناء مكوّنات Vue أو Nuxt، كتابة القابلات لإعادة الاستخدام، جلب البيانات في صفحة أو مكوّن Nuxt، إدارة الحالة المشتركة باستخدام Pinia، أو تصحيح قيمة “ليس لديها تفاعل” بعد تمريرها.
