Руководствуется разработкой API REST и RPC для серверных частей Go, TypeScript и PHP. Используйте при проектировании новых конечных точек, определении контрактов запросов/ответов, планировании критических или дополнительных изменений схемы или проверке существующего API на предмет единообразия в обработке ошибок, нумерации страниц или именовании.
