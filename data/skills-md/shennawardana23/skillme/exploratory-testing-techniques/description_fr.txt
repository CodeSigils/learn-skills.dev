Cette compétence doit être utilisée lorsque l'utilisateur demande de « faire des tests exploratoires », « d'écrire une charte de test », « d'explorer cette fonctionnalité à la recherche de bogues », « d'exécuter une session de test » ou a besoin d'une approche non scriptée et basée sur le jugement humain pour trouver des bogues dans une fonctionnalité ambiguë ou nouvellement créée qui n'est pas encore suffisamment bien spécifiée pour une automatisation par script. À utiliser pour une enquête manuelle structurée et basée sur une charte - pas pour l'écriture de tests Playwright/unitaires automatisés (voir e2e-testing, test-driven-development).
