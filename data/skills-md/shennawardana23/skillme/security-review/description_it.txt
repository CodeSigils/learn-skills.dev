Esamina il codice per le vulnerabilità della sicurezza su Go, TypeScript, PHP e la configurazione dell'infrastruttura. Da utilizzare quando si aggiunge autenticazione o autorizzazione, si gestisce l'input dell'utente o il caricamento di file, si creano endpoint API, si lavora con segreti o credenziali, si chiamano API di terze parti o si gestiscono pagamenti o altri dati sensibili.
