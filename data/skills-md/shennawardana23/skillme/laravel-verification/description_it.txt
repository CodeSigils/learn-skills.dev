Usa quando ti viene chiesto di verificare un progetto Laravel prima di una PR, dopo un refactoring importante o un aggiornamento di dipendenze, o prima di distribuire su staging/produzione. Esegue una pipeline a fasi env‑check → lint → test → security → migration → deploy‑readiness → queue, fermandosi al primo gate che fallisce invece di riportare l’output di tutte le fasi in una sola volta.
