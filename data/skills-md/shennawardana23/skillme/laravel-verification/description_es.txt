Úsese cuando se solicite verificar un proyecto Laravel antes de un PR, después de una refactorización importante o actualización de dependencias, o antes de desplegar a staging/producción. Ejecuta una tubería de comprobación de entorno → lint → test → seguridad → migración → preparación para despliegue → colas, deteniéndose en la primera puerta que falle en lugar de reportar la salida de todas las fases de una vez.
