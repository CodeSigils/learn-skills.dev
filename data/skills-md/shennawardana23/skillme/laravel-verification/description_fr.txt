À utiliser lorsqu’on demande de vérifier un projet Laravel avant une PR, après une refonte majeure ou une mise à jour de dépendances, ou avant de déployer en staging/production. Exécute une pipeline en phases : vérification d’environnement -> lint -> tests -> sécurité -> migration -> préparation du déploiement -> file d’attente, en s’arrêtant à la première étape qui échoue plutôt qu’en rapportant la sortie de chaque phase d’un coup.
