Utilice cuando configure la infraestructura de autenticación/sesión/CSRF/autorización específica de Laravel: autenticación SPA con Sanctum, endurecimiento de cookies de sesión, configuración de políticas/puertas, guardas de asignación masiva, URLs firmadas o casts encriptados. Para una revisión genérica de seguridad web (inyección, secretos, auth vs authz en cualquier stack) use security‑review; esta habilidad es para configurar correctamente los propios mecanismos del framework Laravel.

Por favor, responda siempre en el idioma del usuario.
