يقود التطوير بالاختبارات المكتوبة قبل كود التنفيذ، سواءً بلغة Go أو TypeScript أو PHP أو أي لغة أخرى. يُستعمل عند تنفيذ منطق أو سلوك جديد، أو عند إصلاح عطل تم الإبلاغ عنه (اكتب اختبار التكرار أولاً)، أو تعديل وظيفة موجودة، أو عندما يُطلب منك "إضافة اختبار"، "تطبيق TDD"، أو "إثبات أن هذا يعمل". استخدمه حتى عندما لا يذكر المستخدم كلمة "اختبار" صراحةً لكنه يصف تقرير عطل أو تغيير سلوك. يرجى دائمًا الرد بلغة المستخدم.
