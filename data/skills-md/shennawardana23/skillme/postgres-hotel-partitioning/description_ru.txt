Этот навык следует использовать, когда пользователь просит «написать запрос для таблицы, секционированной по отелям», «проверить этот SQL на предмет безопасности разделов», «добавить фильтр hotel_id», «проверить сокращение разделов», «написать миграцию для секционированной таблицы», или пишет/проверяет код Go или SQL, касающийся любой таблицы PostgreSQL, секционированной по hotel_id. Предоставляет шаблоны для обеспечения безопасности секционирования запросов, объединений и миграций.
