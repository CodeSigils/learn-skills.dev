Opérations de l'environnement Warden pour Magento 2 : requêtes de base de données, commandes CLI Magento, importation/exportation de base de données, gestion de l'environnement et accès au shell. À utiliser lorsque l'utilisateur demande "exécuter Warden", "vérifier la base de données", "warden db connect", "exécuter la commande magento", "import db", "export db", "warden shell" ou toute tâche impliquant l'environnement de développement local Warden. Ne PAS utiliser pour la génération de code, le frontend ou les environnements non-Warden.
