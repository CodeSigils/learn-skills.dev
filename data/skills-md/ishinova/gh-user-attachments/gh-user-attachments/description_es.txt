Cargue entre 2 y 10 archivos locales compatibles en archivos adjuntos de usuario de GitHub y devuelva las URL canónicas finalizadas en el orden de entrada. Úselo para cargar archivos adjuntos por lotes en problemas de GitHub, solicitudes de extracción, comentarios o debates. No lo use para un archivo, generación de Markdown o edición de contenido de GitHub.
