A template-driven data visualization and report generation skill that can strictly generate HTML charts from the actual implementations of Lupi, Basics, Glance, Maps, and Interactive Gallery, and also create publishable HTML reports from 12 bilingual (Chinese‑English) full‑page report templates; using Mono as a fallback, it can automatically select built‑in color presets based on data semantics while also supporting user‑provided custom color palettes. Maps are enabled only when explicitly requested by the user, and mixing color schemes within the same delivery is prohibited.
