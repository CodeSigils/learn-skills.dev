Используйте REST API с поддержкой агента для сканирования любого общедоступного URL-адреса на предмет читаемости агента AI на соответствие спецификации читаемости агента Vercel, стандарту llmstxt.org и манифестам протокола агента (серверные карты MCP, A2A, Agents.json, Agent-Permissions.json, UCP, x402, NLWeb). Активируется для «сканировать этот сайт на предмет читаемости агента AI», «запустить сканирование готовности агента на {URL}», «проверить оценку готовности агента для {URL}», «каков рейтинг читаемости агента для {URL}» или в любой момент, когда пользователь хочет выполнить программное сканирование читаемости через HTTP. Выбирает этот навык, когда у пользователя НЕ установлен сервер Agent Ready MCP — для MCP вместо этого используйте навык `agent-ready-mcp`.
