Utilice la API REST Agent Ready para escanear cualquier URL pública en busca de legibilidad del agente de IA según la especificación de legibilidad del agente de Vercel, el estándar llmstxt.org y los manifiestos de protocolo del agente (tarjetas de servidor MCP, A2A, agentes.json, agente-permisos.json, UCP, x402, NLWeb). Se activa para "escanear este sitio en busca de legibilidad del agente de IA", "ejecutar un escaneo del agente listo en {URL}", "comprobar la puntuación del agente listo para {URL}", "cuál es la calificación de legibilidad del agente para {URL}" o en cualquier momento en que el usuario desee un escaneo de legibilidad programática a través de HTTP. Elige esta habilidad cuando el usuario NO tiene instalado el servidor Agent Ready MCP; para MCP, use la habilidad `agent-ready-mcp`.
