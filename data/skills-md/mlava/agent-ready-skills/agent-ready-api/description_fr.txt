Utilisez l'API REST Agent Ready pour analyser n'importe quelle URL publique pour vérifier la lisibilité de l'agent IA par rapport à la spécification de lisibilité de l'agent Vercel, à la norme llmstxt.org et aux manifestes de protocole d'agent (cartes de serveur MCP, A2A, agents.json, agent-permissions.json, UCP, x402, NLWeb). S'active pour « analyser ce site pour vérifier la lisibilité de l'agent IA », « exécuter une analyse Agent Ready sur {URL} », « vérifier le score Agent Ready pour {URL} », « quelle est la note de lisibilité de l'agent pour {URL} » ou à tout moment où l'utilisateur souhaite une analyse de lisibilité programmatique via HTTP. Sélectionne cette compétence lorsque l'utilisateur n'a PAS installé le serveur Agent Ready MCP — pour MCP, utilisez plutôt la compétence « agent-ready-mcp ».
