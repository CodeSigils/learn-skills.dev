Agent Ready REST API を使用して、Vercel Agent Readability Spec、llmstxt.org 標準、およびエージェント プロトコル マニフェスト (MCP サーバー カード、A2A、agents.json、agent-permissions.json、UCP、x402、NLWeb) に対して AI エージェントの可読性を確認するためにパブリック URL をスキャンします。 「AI エージェントの可読性についてこのサイトをスキャンする」、「{URL} で Agent Ready スキャンを実行する」、「{URL} の Agent Ready スコアを確認する」、「{URL} のエージェントの可読性評価は何ですか」、またはユーザーが HTTP 経由でプログラムによる可読性スキャンを希望する場合にアクティブ化します。ユーザーが Agent Ready MCP サーバーをインストールしていない場合にこのスキルを選択します。MCP の場合は、代わりに「agent-ready-mcp」スキルを使用します。
