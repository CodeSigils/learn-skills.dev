Verwenden Sie die Agent Ready REST API, um jede öffentliche URL auf AI-Agent-Lesbarkeit anhand der Vercel Agent Readability Spec, des llmstxt.org-Standards und Agent-Protokollmanifesten (MCP-Serverkarten, A2A, Agents.json, Agent-Permissions.json, UCP, x402, NLWeb) zu scannen. Aktiviert für „Diese Website auf AI-Agent-Lesbarkeit scannen“, „Agent-Ready-Scan für {URL} ausführen“, „Agent-Ready-Score für {URL} prüfen“, „Wie lautet die Agent-Lesbarkeitsbewertung für {URL}“ oder jederzeit, wenn der Benutzer einen programmatischen Lesbarkeitsscan über HTTP wünscht. Wählt diesen Skill aus, wenn der Benutzer den Agent Ready MCP-Server NICHT installiert hat – verwenden Sie für MCP stattdessen den Skill „agent-ready-mcp“.
