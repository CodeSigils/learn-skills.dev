使用 Agent Ready REST API 根據 Vercel Agent 可讀性規範、llmstxt.org 標準和代理程式協定清單（MCP 伺服器卡、A2A、agents.json、agent-permissions.json、UCP、x402、NLWeb）掃描任何公用 URL 的 AI 代理可讀性。啟動“掃描此網站的 AI 代理可讀性”、“在 {URL} 上執行代理就緒掃描”、“檢查 {URL} 的代理就緒分數”、“{URL} 的代理可讀性評級是多少”，或在用戶希望透過 HTTP 進行編程可讀性掃描時啟動。當使用者未安裝 Agent Ready MCP 伺服器時選擇此技能 — 對於 MCP，請使用「agent-ready-mcp」技能。
