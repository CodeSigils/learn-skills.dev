Utilizza l'API REST Agent Ready per eseguire la scansione di qualsiasi URL pubblico per la leggibilità dell'agente AI rispetto alle specifiche di leggibilità dell'agente Vercel, allo standard llmstxt.org e ai manifest del protocollo dell'agente (schede server MCP, A2A, agenti.json, agent-permissions.json, UCP, x402, NLWeb). Si attiva per "scansiona questo sito per la leggibilità dell'agente AI", "esegui una scansione Agent Ready su {URL}", "controlla il punteggio Agent Ready per {URL}", "qual è la valutazione di leggibilità dell'agente per {URL}" o ogni volta che l'utente desidera una scansione di leggibilità programmatica tramite HTTP. Scegli questa competenza quando l'utente NON ha il server Agent Ready MCP installato: per MCP, utilizza invece la competenza `agent-ready-mcp`.
