استخدم Agent Ready REST API لفحص أي عنوان URL عام لقابلية قراءة وكيل AI مقابل مواصفات Vercel Agent Readability Spec ومعيار llmstxt.org وبيانات بروتوكول الوكيل (بطاقات خادم MCP وA2A ووكلاء.json وagent-permissions.json وUCP وx402 وNLWeb). يتم التنشيط من أجل "فحص هذا الموقع بحثًا عن إمكانية قراءة وكيل الذكاء الاصطناعي"، أو "تشغيل فحص جاهزية الوكيل على {URL}"، أو "التحقق من درجة جاهزية الوكيل لـ {URL}"، أو "ما هو تصنيف سهولة قراءة الوكيل لـ {URL}"، أو في أي وقت يريد المستخدم إجراء فحص قابلية القراءة برمجيًا عبر HTTP. يتم اختيار هذه المهارة عندما لا يكون لدى المستخدم خادم Agent Ready MCP مثبتًا - بالنسبة لـ MCP، استخدم مهارة "agent-ready-mcp" بدلاً من ذلك.
