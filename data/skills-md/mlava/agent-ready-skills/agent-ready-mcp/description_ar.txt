قم بتثبيت واستخدام خادم Agent Ready MCP لمسح أي عنوان URL لإمكانية قراءة وكيل الذكاء الاصطناعي عبر استدعاءات أداة MCP. يتم التنشيط من أجل "تثبيت وكيل جاهز mcp"، "إعداد وكيل جاهز في Claude Desktop / Cursor / Cline / Goose / متابعة"، "إضافة وكيل جاهز كأداة MCP"، "مسح هذا الموقع عبر وكيل جاهز"، "تشغيل scan_site / get_scan / اسأل عبر MCP". اختر هذه المهارة عندما يريد المستخدم الوصول الأصلي للأداة إلى Agent Ready - بدون لف أو جلب الأسلاك. للوصول المباشر إلى REST بدون MCP، استخدم مهارة "agent-ready-api" بدلاً من ذلك.
