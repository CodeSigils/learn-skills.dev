Agent Ready MCP サーバーをインストールして使用し、MCP ツール呼び出しを通じて AI エージェントが読み取れる URL をスキャンします。 「エージェントレディ mcp をインストールする」、「クロード デスクトップ / カーソル / クライン / グース / 続行でエージェントレディをセットアップする」、「MCP ツールとしてエージェントレディを追加する」、「エージェントレディ経由でこのサイトをスキャンする」、「MCP 経由で scan_site / get_scan / ask を実行する」に対してアクティブ化されます。ユーザーが Agent Ready へのツールネイティブなアクセス (カールやフェッチ ワイヤリングを必要としない) を必要とする場合は、このスキルを選択してください。 MCP を使用せずに直接 REST アクセスするには、代わりに「agent-ready-api」スキルを使用します。
