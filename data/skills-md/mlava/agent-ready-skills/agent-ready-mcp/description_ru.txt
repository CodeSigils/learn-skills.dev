Установите и используйте сервер MCP Agent Ready для сканирования любого URL-адреса на предмет читаемости агента AI с помощью вызовов инструментов MCP. Активируется для «установить готовый к агенту mcp», «настроить готовый к работе агент в Claude Desktop / Cursor / Cline / Goose / Continue», «добавить готовый к агенту в качестве инструмента MCP», «сканировать этот сайт через готовый к агенту», «запустить scan_site / get_scan / спросить через MCP». Выбирайте этот навык, если пользователю нужен встроенный инструментальный доступ к Agent Ready — без скручивания и извлечения данных. Для прямого доступа к REST без MCP используйте вместо этого навык `agent-ready-api`.
