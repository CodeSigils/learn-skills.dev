Installieren und verwenden Sie den Agent Ready MCP-Server, um jede URL über MCP-Tool-Aufrufe auf Lesbarkeit durch KI-Agenten zu scannen. Aktiviert für „Agent-ready mcp installieren“, „Agent-ready in Claude Desktop einrichten / Cursor / Cline / Goose / Continue“, „Agent-ready als MCP-Tool hinzufügen“, „diese Site über Agent-ready scannen“, „scan_site / get_scan / ask über MCP ausführen“. Wählen Sie diese Fähigkeit aus, wenn der Benutzer einen Tool-nativen Zugriff auf Agent Ready wünscht – kein Curl, keine Fetch-Verkabelung. Für direkten REST-Zugriff ohne MCP verwenden Sie stattdessen den Skill „agent-ready-api“.
