Utilizza il client della riga di comando Agent Ready per eseguire la scansione di qualsiasi URL pubblico per la leggibilità dell'agente AI rispetto alle specifiche di leggibilità dell'agente Vercel, allo standard llmstxt.org e ai manifest del protocollo dell'agente (schede server MCP, A2A, agenti.json, agent-permissions.json, UCP, x402, NLWeb). Si attiva per "scansiona questo sito con la CLI pronta per l'agente", "esegui la scansione {URL} pronta per l'agente nel terminale", "ottieni {id} pronto per l'agente", "elenco pronto per l'agente", "chiedi {domanda} pronto per l'agente" o ogni volta che l'utente desidera una scansione del terminale con un solo comando senza cablaggio di recupero e senza installazione MCP. Scegli questa abilità quando l'agente può eseguire comandi shell. Per HTTP non elaborato, utilizza la competenza `agent-ready-api`; per le chiamate agli strumenti nativi di MCP, utilizzare "agent-ready-mcp".
