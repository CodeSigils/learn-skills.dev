Verwenden Sie den Agent Ready-Befehlszeilen-Client, um jede öffentliche URL auf AI-Agent-Lesbarkeit anhand der Vercel Agent Readability Spec, des llmstxt.org-Standards und Agent-Protokoll-Manifesten (MCP-Serverkarten, A2A, Agents.json, Agent-Permissions.json, UCP, x402, NLWeb) zu scannen. Aktiviert für „Diese Site mit der Agent-Ready-CLI scannen“, „Agent-Ready-Scan {URL} im Terminal ausführen“, „Agent-Ready-Abruf {ID}“, „Agent-Ready-Liste“, „Agent-Ready-Frage {Frage}“ oder immer dann, wenn der Benutzer einen Terminalscan mit einem Befehl ohne Abrufverkabelung und ohne MCP-Installation wünscht. Wählen Sie diese Fähigkeit aus, wenn der Agent Shell-Befehle ausführen kann. Verwenden Sie für rohes HTTP den Skill „agent-ready-api“. Verwenden Sie für MCP-native Tool-Aufrufe „agent-ready-mcp“.
