Utilice el cliente de línea de comandos Agent Ready para escanear cualquier URL pública en busca de legibilidad del agente de IA según la especificación de legibilidad del agente de Vercel, el estándar llmstxt.org y los manifiestos de protocolo del agente (tarjetas de servidor MCP, A2A, agentes.json, agente-permissions.json, UCP, x402, NLWeb). Se activa para "escanear este sitio con la CLI de agente listo", "ejecutar escaneo de agente listo {URL} en la terminal", "agente listo obtener {id}", "lista de agente listo", "agente listo preguntar {pregunta}" o en cualquier momento en que el usuario desee un escaneo de terminal de un solo comando sin cableado de recuperación ni instalación de MCP. Elija esta habilidad cuando el agente pueda ejecutar comandos de shell. Para HTTP sin formato, utilice la habilidad `agent-ready-api`; para llamadas a herramientas nativas de MCP, utilice `agent-ready-mcp`.
