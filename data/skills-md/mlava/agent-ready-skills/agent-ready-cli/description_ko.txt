Agent Ready 명령줄 클라이언트를 사용하여 Vercel 에이전트 가독성 사양, llmstxt.org 표준 및 에이전트 프로토콜 매니페스트(MCP 서버 카드, A2A, Agent.json, Agent-permissions.json, UCP, x402, NLWeb)를 기준으로 AI 에이전트 가독성에 대한 공용 URL을 스캔합니다. "에이전트 준비 CLI를 사용하여 이 사이트 스캔", "터미널에서 에이전트 준비 스캔 {URL} 실행", "에이전트 준비 {id} 가져오기", "에이전트 준비 목록", "에이전트 준비 질문 {질문}" 또는 사용자가 가져오기 배선 및 MCP 설치 없이 단일 명령 터미널 스캔을 원할 때마다 활성화됩니다. 에이전트가 셸 명령을 실행할 수 있는 경우 이 기술을 선택하세요. 원시 HTTP의 경우 'agent-ready-api' 기술을 사용하세요. MCP 기본 도구 호출의 경우 `agent-ready-mcp`를 사용하세요.
