Utilisez le client de ligne de commande Agent Ready pour analyser n'importe quelle URL publique pour vérifier la lisibilité de l'agent AI par rapport à la spécification de lisibilité de l'agent Vercel, à la norme llmstxt.org et aux manifestes de protocole d'agent (cartes de serveur MCP, A2A, agents.json, agent-permissions.json, UCP, x402, NLWeb). S'active pour "analyser ce site avec la CLI prête pour l'agent", "exécuter une analyse prête pour l'agent {URL} dans le terminal", "obtenir {id} prêt pour l'agent", "liste prête pour l'agent", "demander {question} prête pour l'agent", ou à tout moment où l'utilisateur souhaite une analyse de terminal à une seule commande sans câblage de récupération et sans installation MCP. Choisissez cette compétence lorsque l'agent peut exécuter des commandes shell. Pour le HTTP brut, utilisez la compétence « agent-ready-api » ; pour les appels d'outils natifs MCP, utilisez « agent-ready-mcp ».
