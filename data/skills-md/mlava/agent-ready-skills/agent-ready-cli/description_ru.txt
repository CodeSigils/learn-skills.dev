Используйте клиент командной строки Agent Ready для сканирования любого общедоступного URL-адреса на предмет читаемости агента AI на предмет соответствия спецификации читаемости агента Vercel, стандарту llmstxt.org и манифестам протокола агента (серверные карты MCP, A2A, Agents.json, Agent-Permissions.json, UCP, x402, NLWeb). Активируется для «сканирования этого сайта с помощью CLI, готового к работе с агентом», «запуска сканирования {URL} с готовностью для агента в терминале», «получения {id} с готовностью для агента», «списка готовности к агенту», «готового к агенту задания {вопроса}» или в любой момент, когда пользователь хочет выполнить сканирование терминала одной командой без подключения к выборке и без установки MCP. Выбирайте этот навык, если агент может выполнять команды оболочки. Для необработанного HTTP используйте навык `agent-ready-api`; для вызовов собственных инструментов MCP используйте `agent-ready-mcp`.
