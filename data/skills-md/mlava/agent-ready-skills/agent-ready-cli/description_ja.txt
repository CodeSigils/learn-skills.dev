Agent Ready コマンド ライン クライアントを使用して、Vercel Agent Readability Spec、llmstxt.org 標準、およびエージェント プロトコル マニフェスト (MCP サーバー カード、A2A、agents.json、agent-permissions.json、UCP、x402、NLWeb) に対して AI エージェントの可読性を確認するためにパブリック URL をスキャンします。 「エージェントレディ CLI を使用してこのサイトをスキャンする」、「ターミナルでエージェントレディスキャン {URL} を実行する」、「エージェントレディ取得 {id}」、「エージェントレディリスト」、「エージェントレディ質問 {質問}」、またはユーザーがフェッチ配線や MCP インストールを行わずに 1 つのコマンドでターミナル スキャンを実行したい場合にアクティブ化されます。エージェントがシェル コマンドを実行できる場合は、このスキルを選択します。生の HTTP の場合は、「agent-ready-api」スキルを使用します。 MCP ネイティブ ツール呼び出しの場合は、「agent-ready-mcp」を使用します。
