استخدم عميل سطر الأوامر Agent Ready لفحص أي عنوان URL عام لقابلية قراءة وكيل AI مقابل مواصفات Vercel Agent Readability Spec ومعيار llmstxt.org وبيانات بروتوكول الوكيل (بطاقات خادم MCP وA2A ووكلاء.json وagent-permissions.json وUCP وx402 وNLWeb). يتم التنشيط من أجل "فحص هذا الموقع باستخدام واجهة سطر الأوامر (CLI) الجاهزة للوكيل"، أو "تشغيل فحص جاهز للوكيل {URL} في الجهاز الطرفي"، أو "الحصول على {id} جاهز للوكيل"، أو "قائمة جاهزة للوكيل"، أو "سؤال جاهز للوكيل {سؤال}"، أو في أي وقت يريد المستخدم إجراء فحص للمحطة الطرفية ذات أمر واحد بدون أسلاك جلب أو تثبيت MCP. اختر هذه المهارة عندما يتمكن الوكيل من تشغيل أوامر shell. بالنسبة لـ HTTP الخام، استخدم مهارة "agent-ready-api"؛ بالنسبة لاستدعاءات أداة MCP الأصلية، استخدم "agent-ready-mcp".
