أتمتة متصفح Stealth Chromium الذي يتجاوز اكتشاف الروبوتات. استخدم هذه المهارة عندما يريد المستخدم استخلاص أو لقطة شاشة أو ملف PDF أو تشغيل موقع يحظر المتصفحات العادية بدون رأس أو تشغيلها تلقائيًا - Cloudflare Turnstile، أو reCAPTCHA v3، أو FingerprintJS، أو ShieldSquare، أو BrowserScan، أو استجابات "تم رفض الوصول"، أو 403/429s المشبوهة على `curl` العادي، أو أي موقع يتم فيه القبض على الكاتب المسرحي/محرك الدمى. يُستخدم أيضًا عندما يذكر المستخدم CloakBrowser، أو Stealth Chromium، أو تجاوز برامج مكافحة الروبوتات، أو "الكشف بدون رأس"، أو "بصمة Chrome الحقيقية"، أو يريد التحقق لمرة واحدة من "ما تعرضه هذه الصفحة بالفعل". تفضل هذه المهارة على مهارة "التجعيد"/"الجلب" الأولية لأي موقع خلف طبقة CDN أو طبقة اكتشاف الروبوتات.
