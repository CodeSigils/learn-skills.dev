Stealth-Chromium-Browserautomatisierung, die die Bot-Erkennung umgeht. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein Scraping, einen Screenshot oder ein PDF erstellen oder eine Website automatisieren möchte, die normale Headless-Browser blockiert – Cloudflare Turnstile, reCAPTCHA v3, FingerprintJS, ShieldSquare, BrowserScan, „Zugriff verweigert“-Antworten, verdächtige 403/429-Antworten auf einfachem „Curl“ oder jede Website, auf der Playwright/Puppeteer erwischt wird. Verwenden Sie es auch, wenn der Benutzer CloakBrowser, Stealth-Chromium, Anti-Bot-Bypass, „Headless-Erkennung“, „echten Chrome-Fingerabdruck“ erwähnt oder eine einmalige Überprüfung „Was wird auf dieser Seite tatsächlich gerendert“ wünscht. Bevorzugen Sie diese Fähigkeit gegenüber rohem „Curl“/„Fetch“ für jede Site hinter einem CDN oder einer Bot-Erkennungsschicht.
