يبني البنية التحتية لاختبار الوحدة والتكامل لـ Node/TS/React - Vitest أو Node: اختيار الاختبار بتكوين صريح، وبوابات تغطية v8 التي تفشل في CI، ومكتبة اختبار React، والانضباط الساخر، وفرز الاختبار غير المستقر. يُستخدم عندما يطلب المستخدم إعداد الاختبارات، أو إضافة حدود التغطية، أو اختيار مشغل اختبار، أو إصلاح إعداد اختبار غير مستقر. ليس لمجموعات متصفح E2E، أو قواعد الوبر، أو تأليف سير عمل CI.
