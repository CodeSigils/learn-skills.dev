Costruisce un'infrastruttura di test di unità e integrazione per Node/TS/React: selezione Vitest o node:test con configurazione esplicita, gate di copertura v8 che non superano CI, libreria di test React, disciplina beffarda, triage di test instabili. Da utilizzare quando l'utente chiede di impostare test, aggiungere soglie di copertura, scegliere un test runner o correggere una configurazione di test instabile. Non per suite browser E2E, regole lint o creazione di flussi di lavoro CI.
