Настраивает TypeScript для библиотек и приложений Node — явный строгий tsconfig, выбор модуля и модуляResolution, verbatimModuleSyntax, изолированные объявления, выпуск объявлений для публикации, шлюзы проверки типов tsc, инкрементная строгость. Используйте, когда пользователь просит настроить TypeScript, ужесточить tsconfig или исправить вывод декларации. Не для правил проверки, объединения или разрешения экспорта пакетов.
