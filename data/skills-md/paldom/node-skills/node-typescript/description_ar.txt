يقوم بتكوين TypeScript لمكتبات وتطبيقات Node - tsconfig الصارمة الصريحة، وخيارات الوحدة النمطية وmoduleResolution، والصيغة الحرفية لـModuleSyntax، والتصريحات المعزولة، وإصدار الإعلان للنشر، وبوابات التحقق من النوع tsc، والتشديد المتزايد. يُستخدم عندما يطلب المستخدم إعداد TypeScript، أو تشديد tsconfig، أو إصلاح مخرجات الإعلان. ليس لقواعد الوبر أو التجميع أو دقة تصدير الحزمة.
