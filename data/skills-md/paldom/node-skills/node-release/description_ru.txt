Сокращает и автоматизирует выпуски npm — наборы изменений, семантический выпуск или выпуск, пожалуйста, доверенная публикация npm (OIDC) с указанием происхождения, начальная загрузка первой публикации, поэтапная публикация, журналы изменений и теги. Используйте, когда пользователь запрашивает выпуск, версию, публикацию в npm или удаление токенов из рабочих процессов публикации. Не для экспорта пакетов/объединения артефактов или проверки происхождения зависимостей.
