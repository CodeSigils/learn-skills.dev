Taglia e automatizza i rilasci npm: set di modifiche, rilascio semantico o rilascio per favore, pubblicazione attendibile npm (OIDC) con provenienza, bootstrap della prima pubblicazione, pubblicazione graduale, log delle modifiche e tag. Da utilizzare quando l'utente richiede il rilascio, la versione, la pubblicazione su npm o la rimozione dei token dai flussi di lavoro di pubblicazione. Non per esportazioni di pacchetti/raggruppamento di artefatti o verifica della provenienza delle dipendenze.
