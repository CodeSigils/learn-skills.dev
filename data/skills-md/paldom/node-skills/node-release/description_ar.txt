قص إصدارات npm وأتمتتها - مجموعات التغييرات، أو الإصدار الدلالي أو الإصدار من فضلك، أو النشر الموثوق بـ npm (OIDC) مع المصدر، أو تمهيد النشر الأول، أو النشر المرحلي، أو سجلات التغيير، أو العلامات. يُستخدم عندما يطلب المستخدم إصدار الرموز المميزة أو إصدارها أو نشرها على npm أو إزالة الرموز المميزة من سير عمل النشر. ليس مخصصًا لتصدير الحزم/تجميع العناصر أو التحقق من مصدر التبعية.
