Corta y automatiza los lanzamientos de npm: conjuntos de cambios, lanzamiento semántico o lanzamiento por favor, publicación confiable de npm (OIDC) con procedencia, arranque de primera publicación, publicación por etapas, registros de cambios y etiquetas. Úselo cuando el usuario solicite liberar, versionar, publicar en npm o eliminar tokens de los flujos de trabajo de publicación. No para exportaciones de paquetes/agrupación de artefactos ni para verificar la procedencia de las dependencias.
