Configura los artefactos del paquete npm: package.json exporta mapas, decisiones entre ESM primero y formato dual, agrupación tsdown/tsup, puertas publint y arethetypeswrong, lista blanca de archivos, motores. Úselo cuando el usuario solicite empaquetar una biblioteca para npm, corregir errores de importación o resolución de tipos del consumidor, o verificar la preparación para la publicación. No para cambios de versión, registros de cambios, lanzamientos o autenticación de registro.
