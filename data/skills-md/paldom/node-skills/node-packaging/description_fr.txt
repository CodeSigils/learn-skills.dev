Configure les artefacts du package npm - package.json exporte des cartes, les décisions ESM-first ou double format, le regroupement tsdown/tsup, la publication et les portes arethetypeswrong, la liste blanche des fichiers, les moteurs. À utiliser lorsque l'utilisateur demande de conditionner une bibliothèque pour npm, de corriger les erreurs d'importation ou de résolution de type du consommateur, ou de vérifier l'état de préparation à la publication. Pas pour les changements de version, les journaux de modifications, les versions ou l'authentification du registre.
