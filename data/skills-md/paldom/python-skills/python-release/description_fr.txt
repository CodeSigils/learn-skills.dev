Coupe et automatise les versions d'un package Python : changements de version, journaux des modifications, balises git, publication sécurisée PyPI (OIDC) et flux de travail de publication déclenché par des balises avec un environnement sécurisé. À utiliser pour « couper une version », « publier sur PyPI », « augmenter la version », « automatiser les versions », « configurer la publication fiable ». Pas pour empaqueter des métadonnées, construire des backends ou des CI non publiés.
