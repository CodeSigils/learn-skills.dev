Schneidet und automatisiert Veröffentlichungen eines Python-Pakets – Versionssprünge, Änderungsprotokolle, Git-Tags, PyPI Trusted Publishing (OIDC) und den durch Tags ausgelösten Veröffentlichungsworkflow mit einer geschlossenen Umgebung. Verwenden Sie diese Option für „ein Release ausschneiden“, „auf PyPI veröffentlichen“, „die Version erhöhen“, „Releases automatisieren“, „vertrauenswürdige Veröffentlichung einrichten“. Nicht zum Packen von Metadaten, Build-Backends oder Nicht-Release-CI.
