Обрезает и автоматизирует выпуск Python‑пакета — увеличение версии, changelog’и, git‑теги, надёжная публикация в PyPI (OIDC) и workflow публикации, запускаемый по тегу, с ограниченной средой. Используйте для «выпустить новую версию», «опубликовать в PyPI», «увеличить номер версии», «автоматизировать релизы», «настроить надёжную публикацию». Не предназначено для метаданных пакетов, сборочных бэкендов или CI, не связанного с релизами.
