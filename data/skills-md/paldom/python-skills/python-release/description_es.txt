Corta y automatiza los lanzamientos de un paquete de Python: mejoras de versiones, registros de cambios, etiquetas git, publicación confiable de PyPI (OIDC) y el flujo de trabajo de publicación activado por etiquetas con un entorno cerrado. Úselo para 'cortar una versión', 'publicar en PyPI', 'mejorar la versión', 'automatizar publicaciones', 'configurar publicaciones confiables'. No para empaquetar metadatos, crear backends o CI que no se publican.
