Taglia e automatizza i rilasci di un pacchetto Python: aggiornamenti di versione, log delle modifiche, tag git, pubblicazione affidabile PyPI (OIDC) e flusso di lavoro di pubblicazione attivato da tag con un ambiente controllato. Utilizzare per "tagliare una versione", "pubblicare su PyPI", "aumentare la versione", "automatizzare le versioni", "impostare la pubblicazione attendibile". Non per il confezionamento di metadati, backend di build o CI non di rilascio.
