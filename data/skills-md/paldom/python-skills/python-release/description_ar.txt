قص إصدارات حزمة Python وتشغيلها تلقائيًا - تحسينات الإصدار، وسجلات التغيير، وعلامات git، والنشر الموثوق في PyPI (OIDC)، وسير عمل النشر الذي يتم تشغيله بواسطة العلامات مع بيئة مسورة. يُستخدم لـ "قص إصدار"، و"النشر على PyPI"، و"رفع الإصدار"، و"أتمتة الإصدارات"، و"إعداد النشر الموثوق". ليس مخصصًا لتغليف البيانات التعريفية أو إنشاء الواجهات الخلفية أو CI غير الخاصة بالإصدار.
