Configure et ajuste le peluchage et le formatage Ruff pour un package Python — sélection de règles pyproject [tool.ruff], migration Black/Flake8/isort — et corrige les échecs de charpie ou de format. À utiliser lorsque l'utilisateur dit « configurer le peluchage », « ajouter des fraises », « corriger les erreurs de charpie », « configurer le formateur ». Pas pour les erreurs de type, le formatage de fichiers non Python, le câblage de pré-validation ou les flux de travail CI.
