Преобразует проекты Figma в готовый к использованию код приложения с визуальной точностью 1:1. Используйте при реализации кода пользовательского интерфейса из файлов Figma, когда пользователь упоминает «реализовать дизайн», «сгенерировать код», «реализовать компонент», предоставляет URL-адреса Figma или просит создать компоненты, соответствующие спецификациям Figma. Для записи холста Figma через use_figma используйте Figma-use.
