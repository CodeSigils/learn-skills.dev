Erstellen Sie ATS-optimierte, menschlich klingende Lebensläufe in LaTeX (Overleaf-ready-Code). Lösen Sie diese Fähigkeit aus, wenn ein Benutzer einen Lebenslauf, einen Lebenslauf oder ein Bewerbungsdokument erstellen, umschreiben, rekonstruieren oder verbessern möchte – auch wenn er einen vorhandenen Lebenslauf hochlädt, Roherfahrungen einfügt oder eine Zielrolle beschreibt. Wird auch ausgelöst, wenn der Benutzer Dinge sagt wie „Meinen Lebenslauf verbessern“, „Meinen Lebenslauf an X anpassen“, „Hilf mir, mich auf eine Stelle zu bewerben“ oder „Meinen Lebenslauf von Grund auf neu schreiben“. Verwenden Sie diese Fähigkeit immer für alle Lebenslauf-/Lebenslaufaufgaben, auch wenn der Benutzer nicht das Wort „LaTeX“ oder „ATS“ verwendet.
