Cree CV optimizados para ATS con sonido humano en LaTeX (código listo al dorso). Active esta habilidad cada vez que un usuario solicite crear, reescribir, reconstruir o mejorar un CV, un currículum vitae o un documento de solicitud de empleo, incluso cuando cargue un CV existente, pegue una experiencia sin procesar o describa un rol objetivo. También se activa cuando el usuario dice cosas como "mejorar mi CV", "adaptar mi currículum para X", "ayúdame a solicitar un trabajo" o "escribir mi CV desde cero". Utilice siempre esta habilidad para cualquier tarea de CV/currículum, incluso si el usuario no utiliza la palabra "LaTeX" o "ATS".
