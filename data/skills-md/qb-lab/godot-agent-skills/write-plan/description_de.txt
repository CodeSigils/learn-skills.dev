Verwandeln Sie eine Funktionsanfrage in einen schriftlichen, phasenweisen Implementierungsplan (.md), bevor Code geschrieben wird – wobei jede Phase eine KI-Coding-Agent-Sitzung ist. Verwenden Sie es immer dann, wenn eine Aufgabe mehr als zwei Dateien betrifft, wenn der Benutzer eine Funktion und nicht eine bestimmte Änderung beschreibt, wenn die Anforderungen nicht eindeutig sind oder wenn der Benutzer „Hinzufügen“, „Erstellen“, „Implementieren“ oder „Lass uns machen“ zu etwas nicht Trivialem sagt. Pläne sind günstig zu ändern; Halbfertige Systeme sind es nicht.
