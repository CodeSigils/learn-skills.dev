Evite que las llamadas a la API de Godot 3 se filtren en el código de Godot 4. Use esto antes de escribir, revisar o depurar cualquier GDScript, y especialmente cuando el código fue copiado de un tutorial, respuesta de StackOverflow, publicación de blog o su propio recuerdo: el material de Godot 3 supera ampliamente al material de Godot 4 en línea, por lo que las alucinaciones de API antiguas son la fuente más frecuente de GDScript generado roto. Utilícelo también cuando vea errores como "Llamada no válida. Función inexistente", "Identificador no encontrado" o "el rendimiento no es una palabra clave válida".
