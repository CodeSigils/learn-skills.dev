منع مكالمات Godot 3 API من التسرب إلى كود Godot 4. استخدم هذا قبل كتابة أو مراجعة أو تصحيح أي GDScript، وخاصة عندما يتم نسخ التعليمات البرمجية من برنامج تعليمي، أو إجابة StackOverflow، أو منشور مدونة، أو الاستدعاء الخاص بك - يفوق عدد مواد Godot 3 بشكل كبير عدد مواد Godot 4 عبر الإنترنت، لذا فإن هلوسات واجهة برمجة التطبيقات القديمة هي المصدر الوحيد الأكثر شيوعًا لـ GDScript المولد المعطوب. استخدمه أيضًا عندما ترى أخطاء مثل "مكالمة غير صالحة. وظيفة غير موجودة" أو "لم يتم العثور على المعرف" أو "العائد ليس كلمة رئيسية صالحة".
