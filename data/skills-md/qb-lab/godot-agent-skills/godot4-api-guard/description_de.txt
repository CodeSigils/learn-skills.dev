Verhindern Sie, dass Godot 3-API-Aufrufe in den Godot 4-Code eindringen. Verwenden Sie dies, bevor Sie GDScript schreiben, überprüfen oder debuggen, und insbesondere, wenn Code aus einem Tutorial, einer StackOverflow-Antwort, einem Blogbeitrag oder Ihrer eigenen Erinnerung kopiert wurde – Godot 3-Material ist weitaus zahlreicher als Godot 4-Material online, sodass Halluzinationen über alte APIs die häufigste Ursache für fehlerhaft generiertes GDScript sind. Verwenden Sie es auch, wenn Fehler wie „Ungültiger Aufruf. Nicht vorhandene Funktion“, „Bezeichner nicht gefunden“ oder „Yield ist kein gültiges Schlüsselwort“ angezeigt werden.
