Предотвратите утечку вызовов API Godot 3 в код Godot 4. Используйте это перед написанием, проверкой или отладкой любого GDScript, и особенно, когда код был скопирован из руководства, ответа StackOverflow, сообщения в блоге или собственного отзыва — количество материалов Godot 3 значительно превосходит количество материалов Godot 4 в Интернете, поэтому галлюцинации старого API являются единственным наиболее частым источником сломанного сгенерированного GDScript. Также используйте, когда вы видите такие ошибки, как «Неверный вызов. Несуществующая функция», «Идентификатор не найден» или «Yield не является допустимым ключевым словом».
