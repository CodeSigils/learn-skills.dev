Godot 3 API 호출이 Godot 4 코드로 누출되는 것을 방지하세요. GDScript를 작성, 검토 또는 디버깅하기 전에, 특히 튜토리얼, StackOverflow 답변, 블로그 게시물 또는 자신의 회상에서 코드를 복사한 경우 이 기능을 사용하세요. Godot 3 자료는 온라인에서 Godot 4 자료보다 훨씬 많기 때문에 오래된 API 환각은 생성된 깨진 GDScript의 가장 빈번한 단일 소스입니다. 또한 "잘못된 호출. 존재하지 않는 함수", "식별자를 찾을 수 없음" 또는 "수익률이 유효한 키워드가 아닙니다"와 같은 오류가 표시되는 경우에도 사용하세요.
