Empêchez les appels de l'API Godot 3 de s'infiltrer dans le code Godot 4. Utilisez-le avant d'écrire, de réviser ou de déboguer un GDScript, et en particulier lorsque le code a été copié à partir d'un didacticiel, d'une réponse StackOverflow, d'un article de blog ou de votre propre rappel - le matériel Godot 3 dépasse largement le matériel Godot 4 en ligne, de sorte que les hallucinations de l'ancienne API sont la source la plus fréquente de GDScript généré cassé. À utiliser également lorsque vous voyez des erreurs telles que « Appel invalide. Fonction inexistante », « Identifiant introuvable » ou « Le rendement n'est pas un mot-clé valide ».
