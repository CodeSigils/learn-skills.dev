Godot 3 API 呼び出しが Godot 4 コードに漏洩するのを防ぎます。 GDScript を作成、レビュー、またはデバッグする前に、特にコードがチュートリアル、StackOverflow の回答、ブログ投稿、または自分自身の思い出からコピーされた場合、これを使用してください。オンラインでは Godot 3 の資料の数が Godot 4 の資料の数を大幅に上回っているため、古い API の幻覚が生成された GDScript の最も頻繁な原因です。 「無効な呼び出しです。関数が存在しません」、「識別子が見つかりません」、または「yield は有効なキーワードではありません」などのエラーが表示された場合にも使用します。
