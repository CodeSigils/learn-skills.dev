Impedisci che le chiamate API Godot 3 penetrino nel codice Godot 4. Usalo prima di scrivere, rivedere o eseguire il debug di qualsiasi GDScript, e soprattutto quando il codice è stato copiato da un tutorial, da una risposta StackOverflow, da un post sul blog o dal tuo richiamo personale: il materiale di Godot 3 supera di gran lunga il materiale di Godot 4 online, quindi le allucinazioni della vecchia API sono l'unica fonte più frequente di GDScript generato in modo non corretto. Da utilizzare anche quando vengono visualizzati errori come "Chiamata non valida. Funzione inesistente", "Identificatore non trovato" o "yield non è una parola chiave valida".
