Führen Sie ein Godot-Projekt kopflos durch und prüfen Sie, ob eine Änderung tatsächlich funktioniert, bevor Sie sie als abgeschlossen melden. Verwenden Sie dies, nachdem Sie ein GDScript, eine Szene oder eine Ressource geschrieben oder bearbeitet haben – und immer bevor Sie dem Benutzer mitteilen, dass etwas fertig, repariert oder funktionsfähig ist. Behandelt den Headless-Import, die Analyseprüfung, GdUnit4/GUT-Testläufe und das ehrliche Lesen von Exit-Codes. Wenn Sie den Godot-Code geändert und dies nicht ausgeführt haben, wissen Sie nicht, ob es funktioniert.
