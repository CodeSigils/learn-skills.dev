Lea, edite y repare archivos Godot .tscn y .tres a mano de forma segura. Úselo siempre que esté a punto de abrir, diferenciar, parchear, fusionar o generar un archivo de escena, un archivo de recursos o un archivo de proyecto .godot, lo que incluye agregar o eliminar nodos, volver a cablear señales, corregir un "recurso no encontrado" o un error de uid:// roto, o resolver un conflicto de git merge en una escena. Los archivos de escena de Godot parecen INI simples y son extremadamente fáciles de corromper, así que consulte esto antes de cualquier edición directa y no después de que algo se rompa.
