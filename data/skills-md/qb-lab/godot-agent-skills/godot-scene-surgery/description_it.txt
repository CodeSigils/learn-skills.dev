Leggi, modifica e ripara in modo sicuro e manuale i file Godot .tscn e .tres. Usalo ogni volta che stai per aprire, creare differenze, applicare patch, unire o generare un file di scena, un file di risorse o un file di progetto .godot, incluso aggiungere o rimuovere nodi, ricablare segnali, correggere un errore "risorsa non trovata" o uid:// non funzionante o risolvere un conflitto di unione git in una scena. I file di scena di Godot sembrano semplici INI e sono estremamente facili da corrompere, quindi consultalo prima di qualsiasi modifica diretta piuttosto che dopo che qualcosa si rompe.
