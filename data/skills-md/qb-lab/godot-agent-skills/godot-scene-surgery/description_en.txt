Safely read, edit, and repair Godot .tscn and .tres files by hand. Use this whenever you are about to open, diff, patch, merge, or generate a scene file, resource file, or .godot project file — including adding or removing nodes, rewiring signals, fixing a "resource not found" or broken uid:// error, or resolving a git merge conflict in a scene. Godot scene files look like plain INI and are extremely easy to corrupt, so consult this before any direct edit rather than after something breaks.
