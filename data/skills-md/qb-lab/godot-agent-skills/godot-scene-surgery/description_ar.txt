قراءة ملفات Godot .tscn و.tres يدويًا وتحريرها وإصلاحها بأمان. استخدم هذا عندما تكون على وشك فتح أو تمييز أو تصحيح أو دمج أو إنشاء ملف مشهد أو ملف مورد أو ملف مشروع .godot - بما في ذلك إضافة العقد أو إزالتها، أو تجديد الإشارات، أو إصلاح خطأ "لم يتم العثور على المورد" أو خطأ uid:// المعطل، أو حل تعارض دمج git في مشهد ما. تبدو ملفات مشهد Godot مثل INI عادي ومن السهل للغاية إتلافها، لذا راجع هذا قبل أي تعديل مباشر وليس بعد حدوث أي انقطاع.
