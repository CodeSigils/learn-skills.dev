Rédigez une note de transfert compacte capturant l'état du projet, les décisions et les prochaines étapes afin que la session suivante reprenne sans redéfinir le contexte. À utiliser lorsque l'utilisateur dit qu'il s'arrête, termine ou continue demain ; lorsqu'une conversation devient suffisamment longue, le contexte peut être perdu ; ou lorsque l'utilisateur demande où en sont les choses ou ce qui reste.
