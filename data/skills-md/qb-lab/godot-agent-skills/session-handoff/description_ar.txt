اكتب مذكرة تسليم مدمجة تسجل حالة المشروع والقرارات والخطوات التالية حتى يتم استئناف الجلسة التالية دون إعادة اشتقاق السياق. يُستخدم عندما يقول المستخدم إنه سيتوقف، أو ينته، ​​أو يستمر غدًا؛ عندما تصبح المحادثة طويلة بما فيه الكفاية، قد يتم فقدان السياق؛ أو عندما يسأل المستخدم أين تقف الأشياء أو ماذا تبقى.
