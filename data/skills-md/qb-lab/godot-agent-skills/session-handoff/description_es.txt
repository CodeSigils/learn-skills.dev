Escriba una nota de transferencia compacta que capture el estado del proyecto, las decisiones y los próximos pasos para que se reanude la siguiente sesión sin volver a derivar el contexto. Úselo cuando el usuario diga que se detendrá, concluirá o continuará mañana; cuando una conversación se vuelve lo suficientemente larga como para perder el contexto; o cuando el usuario pregunta dónde están las cosas o qué queda.
