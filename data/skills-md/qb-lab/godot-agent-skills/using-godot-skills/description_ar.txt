قواعد الفهرس والأسبقية لحزمة godot-agent-skills، وكيفية تكاملها مع حزم مهارات Godot المثبتة الأخرى (GodotPrompter، Awesome-gamedev، Randroids-Dojo). استشر متى يمكن تنفيذ مهمة Godot من خلال أكثر من مهارة مثبتة واحدة، أو عندما تقدم حزمتان نصيحة متعارضة لواجهة برمجة التطبيقات (API)، أو عندما تحتاج إلى معرفة الحزمة التي تمتلك مشكلة معينة. يُستخدم عندما يتضمن الطلب ملفات Godot أو GDScript أو .tscn أو .tres أو إحساس اللعبة أو توازن اللعبة أو التخطيط لأعمال تطوير اللعبة.
