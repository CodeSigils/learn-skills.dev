Index- und Prioritätsregeln für das Godot-Agent-Skills-Paket und wie es sich mit anderen installierten Godot-Skill-Paketen zusammensetzt (GodotPrompter, awesome-gamedev, Randroids-Dojo). Konsultieren Sie, wenn eine Godot-Aufgabe von mehr als einem installierten Skill bedient werden könnte, wenn zwei Pakete widersprüchliche API-Ratschläge geben oder wenn Sie wissen müssen, welches Paket ein bestimmtes Anliegen hat. Verwenden Sie es immer dann, wenn eine Anfrage Godot-, GDScript-, .tscn- oder .tres-Dateien, das Spielgefühl, die Spielbalance oder die Planung von Spielentwicklungsarbeiten betrifft.
