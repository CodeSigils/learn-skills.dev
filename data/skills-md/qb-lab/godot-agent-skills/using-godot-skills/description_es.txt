Reglas de índice y precedencia para el paquete de habilidades de Godot-Agent y cómo se compone con otros paquetes de habilidades de Godot instalados (GodotPrompter, Awesome-gamedev, Randroids-Dojo). Consulte cuándo una tarea de Godot podría ser realizada por más de una habilidad instalada, cuándo dos paquetes brindan consejos de API contradictorios o cuándo necesita saber qué paquete posee una preocupación determinada. Úselo siempre que una solicitud involucre archivos Godot, GDScript, .tscn o .tres, sensación del juego, equilibrio del juego o planificación del trabajo de desarrollo del juego.
