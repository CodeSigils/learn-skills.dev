Regole di indice e precedenza per il pacchetto di abilità Godot-agent e come si compone con altri pacchetti di abilità Godot installati (GodotPrompter, awesome-gamedev, Randroids-Dojo). Consulta quando un'attività Godot potrebbe essere servita da più di una competenza installata, quando due pacchetti forniscono consigli API contrastanti o quando hai bisogno di sapere quale pacchetto possiede una determinata preoccupazione. Da utilizzare ogni volta che una richiesta riguarda file Godot, GDScript, .tscn o .tres, sensazioni di gioco, bilanciamento del gioco o pianificazione del lavoro di sviluppo del gioco.
