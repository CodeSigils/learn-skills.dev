Exécutez une boucle implémentation-vérification-correction disciplinée au lieu d'écrire un gros lot de code non vérifié. À utiliser lors de la mise en œuvre d'un changement en plusieurs étapes, lorsqu'un correctif n'a pas fonctionné du premier coup, lorsque plusieurs éléments échouent en même temps ou lorsque vous êtes tenté d'écrire beaucoup de code avant d'exécuter quoi que ce soit. Applique une modification par cycle de vérification afin que les échecs restent attribuables.
