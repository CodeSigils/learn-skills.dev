Führen Sie eine disziplinierte Implement-Verify-Fix-Schleife aus, anstatt eine große Menge ungeprüften Codes zu schreiben. Verwenden Sie diese Option, wenn Sie eine mehrstufige Änderung implementieren, wenn ein Fix beim ersten Versuch nicht funktioniert hat, wenn mehrere Dinge gleichzeitig fehlschlagen oder wenn Sie versucht sind, viel Code zu schreiben, bevor Sie etwas ausführen. Erzwingt eine Änderung pro Überprüfungszyklus, sodass Fehler weiterhin zurechenbar bleiben.
