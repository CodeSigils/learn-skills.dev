Concevez des écrans de qualité production dans Penpot à partir d'un brief, en tant que concepteur visuel senior - en réutilisant le système de conception existant (jetons + composants) et en assemblant section par section, jamais en une seule fois. Utilisez pour créer un écran/page/atterrissage/tableau de bord à partir d’une description. PAS pour traduire du code existant (utilisez penpot-build-from-code). Déclencheurs : "concevoir un tableau de bord", "créer une page de destination", "concevoir cet écran d'application", "créer une interface utilisateur à partir de ce brief", "concevoir une page de paramètres", "simuler un écran dans Penpot".
