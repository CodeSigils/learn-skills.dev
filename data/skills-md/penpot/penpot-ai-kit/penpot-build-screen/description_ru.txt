Создавайте экраны промышленного уровня в Penpot, начиная с задания старшего визуального дизайнера — повторно используя существующую систему дизайна (токены + компоненты) и собирая по частям, а не по одному. Используйте для создания экрана/страницы/лендинга/панели мониторинга на основе описания. НЕ для перевода существующего кода (используйте penpot-build-from-code). Триггеры: «разработать панель мониторинга», «создать целевую страницу», «разработать экран этого приложения», «создать пользовательский интерфейс на основе этого задания», «разработать страницу настроек», «макет экрана в Penpot».
