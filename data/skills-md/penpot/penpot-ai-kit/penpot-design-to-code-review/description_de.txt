Überprüfen Sie ein Penpot-Design anhand des implementierten Codes (einer Quellkomponente oder einer Storybook-Story) und erstellen Sie einen strukturierten DRIFT-Bericht. Verwenden Sie diese Option, wenn ein Ingenieur bestätigen muss, dass der Build mit dem Design übereinstimmt: Extrahieren Sie HTML/CSS aus einer Auswahl, ordnen Sie seine Token/Struktur/Zustände der Codekomponente zu, unterscheiden Sie sie und listen Sie auf, was auf jeder Seite fehlt, mit Schweregrad und einem Abgleich. Wird ordnungsgemäß zu einer Design-System-Token-Prüfung degradiert, wenn keine Codequelle angegeben wird. Auslöser: „Design-zu-Code-Überprüfung“, „Entspricht mein Code dem Design“, „Design-Code-Parität“, „Vergleiche Penpot mit meiner Komponente“, „vergleiche dies mit Storybook“, „Extrahiere HTML/CSS aus dieser Auswahl“, „Design-Drift finden“, „Design-Implementierungs-Differenz“.
