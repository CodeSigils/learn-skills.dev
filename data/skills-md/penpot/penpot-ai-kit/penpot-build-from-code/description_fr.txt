Traduisez une page d'application, une vue ou un code de composant existant dans un écran Penpot lié au système de conception existant - en mappant les styles de code sur des jetons sémantiques et en réutilisant les composants de la bibliothèque au lieu des formes brutes. À utiliser lorsque l'utilisateur dispose d'un code/balisage réel et souhaite le reconstruire dans Penpot, section par section, sur le système. Déclencheurs : « construire ceci dans Penpot à partir du code », « transformer ce React/HTML/CSS en un écran Penpot », « recréer cette vue dans Penpot », « porter cette page vers Penpot », « traduire ce composant en Penpot lié à nos jetons », « coder vers Penpot ».
