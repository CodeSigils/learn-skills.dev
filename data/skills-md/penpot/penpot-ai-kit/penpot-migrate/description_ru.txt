Перенесите дизайн Figma в Penpot с высокой точностью: Figma Auto Layout → Penpot flex/grid, переменные Figma → токены Penpot, наборы компонентов Figma → варианты Penpot, сохраняя иерархию. Чтение через Figma MCP, запись через Penpot MCP, через промежуточное представление (IR). Деградирует до данных Figma, вставленных вручную, если Figma MCP отсутствует. Триггеры: «перейти из Figma», «импортировать этот файл Figma в Penpot», «переместить нашу библиотеку Figma в Penpot», «воссоздать этот дизайн Figma в Penpot», «Figma в Penpot».
