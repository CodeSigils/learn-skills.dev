Поддерживает постоянные знания базы кода между сеансами с помощью структурированного графа знаний, хранящегося в локальном хранилище Obsidian (.doctrack/). Используйте этот навык всякий раз, когда вы только что внесли существенные изменения в код (новые функции, модифицированные компоненты, рефакторинг, исправления ошибок) для обновления документации проекта. Также используйте его, когда пользователь запрашивает документацию кода, обновление документации, синхронизацию документации, инициализацию документации для существующего проекта или когда вы хотите понять существующую структуру кодовой базы в начале сеанса. Этот навык следует использовать активно после любого существенного изменения кода — не ждите, пока пользователь спросит. Если вы изменили код, обновите документацию. Думайте об этом как о своей системе долговременной памяти: читайте перед работой, записывайте после изменения. Также используйте это, когда пользователь говорит «doctrack init», «инициализировать документы», «документировать этот проект» или хочет загрузить документацию для базы кода, у которой еще нет .doctrack/vault.
