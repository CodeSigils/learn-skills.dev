Flux de travail de développement basé sur les spécifications pour les projets modspec. À utiliser chaque fois que vous créez des spécifications, les modifiez ou implémentez du code dans un projet modspec - chaque changement de code DOIT d'abord passer par la mise à jour des spécifications/fonctionnalités, puis par le TDD rouge/vert par rapport à la suite de fonctionnalités. Remplace les précédentes compétences modspec-fix et modspec-implement.
