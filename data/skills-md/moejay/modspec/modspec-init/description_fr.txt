Générez des fichiers de spécifications modspec et des fonctionnalités Gherkin à partir d'une base de code existante. À utiliser pour l'adoption de friches industrielles : analysez la structure de code existante et créez des spécifications qui reflètent les modules du projet et leurs dépendances. Ajoutez --interactive pour obtenir une vérification et avoir la possibilité d'en discuter
