Используйте при вызове локального искусственного интеллекта на этом Mac — генерация текста, зрение, встраивание, распознавание текста или преобразование речи в текст. Качество LLM/VLM/OCR/Embeddings/ASR через шлюз oMLX на локальном хосте: 18080/v1. Быстрый ASR и конвейер встреч через asr-router на локальном хосте: 18081/v1. Оба используют ключ API sk-mlx. Работает полностью в автономном режиме. Используйте вместо облачных API для обеспечения конфиденциальности или задач с малой задержкой.
