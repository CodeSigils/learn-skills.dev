À utiliser lors de l'appel de l'IA locale sur ce Mac : génération de texte, vision, intégrations, OCR ou synthèse vocale. Qualité LLM/VLM/OCR/Embeddings/ASR via la passerelle oMLX sur localhost :18080/v1. ASR rapide et pipeline de réunions via le routeur asr sur localhost : 18081/v1. Les deux utilisent la clé API sk-mlx. Fonctionne entièrement hors ligne. Utilisez-les à la place des API cloud pour les tâches de confidentialité ou à faible latence.
