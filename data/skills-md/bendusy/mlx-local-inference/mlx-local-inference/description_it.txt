Da utilizzare quando si chiama l'IA locale su questo Mac: generazione di testo, visione, incorporamenti, OCR o sintesi vocale. LLM/VLM/OCR/Embeddings/ASR-qualità tramite gateway oMLX su localhost:18080/v1. ASR veloce e pipeline di riunioni tramite asr-router su localhost:18081/v1. Entrambi utilizzano la chiave API sk-mlx. Funziona completamente offline. Utilizza al posto delle API cloud per la privacy o per attività a bassa latenza.
