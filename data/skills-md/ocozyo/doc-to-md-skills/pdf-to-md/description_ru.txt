Пакетное преобразование PDF-файлов в структурированный Markdown. Автоматическое распознавание PDF-файлов с собственным текстом (прямое извлечение с помощью pymupdf, выполняется за секунды, ключ API не требуется) и отсканированных PDF-файлов с изображениями (облачное распознавание PaddleOCR). Встроенные большие изображения в собственные PDF-файлы сохраняются на диск и описываются агентом Claude с помощью встроенного Vision (ключ API не требуется). Также поддерживаются файлы изображений JPG/PNG/BMP/TIFF/WEBP. Когда пользователь упоминает любой из следующих сценариев, обязательно используйте этот навык: (1) Преобразование документа: «PDF в Markdown», «отсканированный PDF», «изображение PDF», «документ изображения», «извлечение OCR», «обработка пакета PDF-файлов», «документ в Markdown», «документ в заметки»; (2) извлечение/анализ содержимого PDF-файла: «прочитать этот PDF-файл», «проанализировать PDF-файл», «извлечь содержимое PDF-файла», «что находится в PDF-файле», «помочь мне посмотреть этот PDF-файл», «извлечь данные из PDF-файла», «проанализировать этот PDF-файл»; (3) Пользователь указывает путь к файлу PDF или только что загрузил PDF-файл и хочет получить его текстовое или информационное содержимое.

Пожалуйста, всегда отвечайте на языке пользователя.
