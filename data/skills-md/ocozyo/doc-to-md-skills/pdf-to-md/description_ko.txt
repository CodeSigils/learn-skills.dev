PDF 파일을 구조화된 마크다운으로 일괄 변환합니다. 기본 텍스트 PDF(pymupdf로 직접 추출, 몇 초 만에 완료, API 키 필요 없음) 및 스캔/이미지 PDF(PaddleOCR 클라우드 인식)를 자동으로 인식합니다. 기본 PDF에 포함된 대형 이미지는 디스크에 저장되고 내장된 Vision을 사용하는 Claude 에이전트에 의해 설명됩니다(API 키 필요 없음). JPG/PNG/BMP/TIFF/WEBP 이미지 파일도 지원됩니다. 사용자가 다음 시나리오 중 하나를 언급하는 경우 이 기술을 사용하십시오. (1) 문서 변환: "PDF를 Markdown으로", "스캔 PDF", "이미지 PDF", "이미지 문서", "OCR 추출", "PDF 일괄 처리", "Markdown으로 문서", "문서를 메모로"; (2) PDF 컨텐츠 추출/파싱: "이 PDF 읽기", "PDF 구문 분석", "PDF 컨텐츠 추출", "PDF의 내용", "이 PDF를 보는 데 도움이 됩니다", "PDF에서 데이터 추출", "이 PDF 분석"; (3) 사용자가 PDF 파일 경로를 제공하거나 PDF를 방금 다운로드하여 해당 텍스트 또는 데이터 콘텐츠를 얻고 싶어합니다.

항상 사용자의 언어로 응답하시기 바랍니다.
