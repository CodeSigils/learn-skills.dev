Convierta por lotes archivos PDF a Markdown estructurado. Reconozca automáticamente archivos PDF de texto nativo (extracción directa con pymupdf, completado en segundos, no se necesita clave API) y archivos PDF escaneados/de imágenes (reconocimiento en la nube PaddleOCR). Las imágenes grandes incrustadas en archivos PDF nativos se guardan en el disco y un agente de Claude las describe mediante Vision integrado (no se necesita clave API). También se admiten archivos de imagen JPG/PNG/BMP/TIFF/WEBP. Cuando el usuario mencione cualquiera de los siguientes escenarios, asegúrese de utilizar esta habilidad: (1) Conversión de documentos: “PDF a Markdown”, “PDF escaneado”, “PDF de imagen”, “documento de imagen”, “extracción de OCR”, “procesar un lote de archivos PDF”, “documento a Markdown”, “documento a notas”; (2) Extracción/análisis de contenido de PDF: "leer este PDF", "analizar PDF", "extraer contenido de PDF", "qué hay en el PDF", "ayúdame a ver este PDF", "extraer datos de PDF", "analizar este PDF"; (3) El usuario proporciona una ruta de archivo PDF o acaba de descargar un PDF y desea obtener su contenido de texto o datos.

Por favor responda siempre en el idioma del usuario.
