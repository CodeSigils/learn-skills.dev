Convertissez par lots des fichiers PDF en Markdown structuré. Reconnaissez automatiquement les PDF texte natifs (extraction directe avec pymupdf, effectuée en quelques secondes, aucune clé API requise) et les PDF numérisés/images (reconnaissance cloud PaddleOCR). Les grandes images intégrées dans des PDF natifs sont enregistrées sur le disque et décrites par un agent Claude à l'aide de Vision intégrée (aucune clé API requise). Les fichiers image JPG/PNG/BMP/TIFF/WEBP sont également pris en charge. Lorsque l'utilisateur mentionne l'un des scénarios suivants, veillez à utiliser cette compétence : (1) Conversion de documents : « PDF en Markdown », « PDF numérisé », « PDF image », « document image », « extraction OCR », « traiter un lot de PDF », « document en Markdown », « document en notes » ; (2) Extraction/analyse de contenu PDF : « lire ce PDF », « analyser le PDF », « extraire le contenu du PDF », « ce qu'il y a dans le PDF », « aidez-moi à regarder ce PDF », « extraire les données du PDF », « analyser ce PDF » ; (3) L'utilisateur fournit un chemin de fichier PDF ou vient de télécharger un PDF et souhaite obtenir son contenu texte ou données.

Veuillez toujours répondre dans la langue de l'utilisateur.
