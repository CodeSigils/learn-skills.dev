Converti in batch file PDF in Markdown strutturato. Riconosci automaticamente PDF di testo nativi (estrazione diretta con pymupdf, completata in pochi secondi, non è necessaria alcuna chiave API) e PDF scansionati/immagini (riconoscimento cloud PaddleOCR). Le immagini di grandi dimensioni incorporate nei PDF nativi vengono salvate su disco e descritte da un agente Claude utilizzando Vision integrato (non è necessaria alcuna chiave API). Sono supportati anche i file di immagine JPG/PNG/BMP/TIFF/WEBP. Quando l'utente menziona uno dei seguenti scenari, assicurati di utilizzare questa abilità: (1) Conversione del documento: "PDF in Markdown", "PDF scansionato", "PDF immagine", "documento immagine", "estrazione OCR", "elaborazione di un batch di PDF", "documento in Markdown", "documento in note"; (2) Estrazione/analisi del contenuto PDF: "leggi questo PDF", "analizza PDF", "estrai contenuto PDF", "cosa c'è nel PDF", "aiutami a guardare questo PDF", "estrai dati da PDF", "analizza questo PDF"; (3) L'utente fornisce un percorso di file PDF o ha appena scaricato un PDF e desidera ottenerne il contenuto di testo o dati.

Si prega di rispondere sempre nella lingua dell'utente.
