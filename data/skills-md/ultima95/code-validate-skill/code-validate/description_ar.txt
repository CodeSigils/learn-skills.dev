يُستخدم عندما يُطلب منك التحقق من صحة تغيير التعليمات البرمجية أو مراجعته أو التحقق منه - تغييرات مختلفة أو مرحلية أو غير مرحلية أو فرع أو طلب سحب - بحثًا عن عيوب حقيقية مدعومة بالأدلة. مشغلات على "التحقق من صحة هذا الاختلاف"، أو "المراجعة قبل الدمج"، أو "هل هذا آمن للشحن"، أو "مراجعة العلاقات العامة هذه والتعليق عليها"، أو مراجعة الصواب أولاً منخفضة الإيجابية الخاطئة، أو /التحقق من صحة الكود. ليس للتعليقات المتعلقة بالأسلوب فقط أو لإنشاء التعليمات البرمجية.
