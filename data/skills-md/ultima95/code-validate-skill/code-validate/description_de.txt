Verwenden Sie diese Funktion, wenn Sie aufgefordert werden, eine Codeänderung (ein Diff, gestaffelte oder nicht gestaffelte Änderungen, eine Verzweigung oder eine Pull-Anfrage) auf echte, evidenzbasierte Fehler zu validieren, zu überprüfen oder zu verifizieren. Wird ausgelöst bei „Diesen Unterschied validieren“, „Vor dem Zusammenführen überprüfen“, „Ist der Versand sicher“, „Diese PR überprüfen und kommentieren“, „Korrektheit zuerst niedrig-falsch-positiv“-Bewertung oder /code-validieren. Nicht für reines Stil-Feedback oder zum Generieren von Code.
