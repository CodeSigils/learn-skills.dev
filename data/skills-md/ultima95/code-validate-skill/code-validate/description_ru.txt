Используйте, когда вас просят проверить, просмотреть или проверить изменение кода — разницу, проиндексированные или непроиндексированные изменения, ветку или запрос на включение — на предмет реальных, подтвержденных фактами дефектов. Триггеры: «проверить эту разницу», «проверить перед слиянием», «безопасно ли отправлять», «просмотреть и прокомментировать этот PR», проверить правильность с низким уровнем ложноположительных результатов или /code-validate. Не только для обратной связи по стилю или генерации кода.
