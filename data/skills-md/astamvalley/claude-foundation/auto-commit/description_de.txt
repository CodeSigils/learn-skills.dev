Es analysiert den geänderten Code, generiert automatisch eine Commit-Nachricht, die der Commit-Konvention folgt, und führt den Commit aus. Verwenden Sie es, wenn Sie „/auto-commit“, „ein Commit durchführen“, „bitte committen“, „Änderungen committen“ oder „Arbeit übernehmen“ sagen. Es funktioniert auch, wenn Sie einfach „commit“ sagen. Verwenden Sie es, wenn Sie das Festschreiben automatisieren möchten, ohne selbst eine Festschreibungsnachricht zu schreiben. Verwenden Sie diese Fähigkeit für Git-Commit, konventionelles Commit und Commit-Automatisierung.
