Analiza el código modificado y genera automáticamente un mensaje de confirmación que sigue la convención de confirmación, luego ejecuta la confirmación. Úselo cuando diga "/auto-commit", "realizar una confirmación", "confirmar por favor", "confirmar cambios" o "confirmar trabajo". También funciona con sólo decir "comprometer". Úselo cuando desee automatizar la confirmación sin escribir usted mismo un mensaje de confirmación. Utilice esta habilidad para git commit, commit convencional y automatización de commit.
