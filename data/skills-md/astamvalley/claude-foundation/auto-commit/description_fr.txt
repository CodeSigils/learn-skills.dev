Analyse le code modifié et génère automatiquement un message de validation qui suit la convention de validation, puis exécute la validation. Utilisez-le lorsque vous dites « /auto-commit », « make a commit », « commit », « commit changes » ou « commit work ». Cela fonctionne également si vous dites simplement « s'engager ». Utilisez-le lorsque vous souhaitez automatiser la validation sans écrire vous-même le message de validation. Utilisez cette compétence pour le commit git, le commit conventionnel et l'automatisation du commit.
