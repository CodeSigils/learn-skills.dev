Il analyse le code modifié, génère automatiquement un message de validation qui suit la convention de validation et exécute la validation. Utilisez-le lorsque vous dites "/auto-commit", "faire une validation", "valider s'il vous plaît", "valider les modifications" ou "valider le travail". Cela fonctionne également si vous dites simplement « s'engager ». Utilisez-le lorsque vous souhaitez automatiser la validation sans écrire vous-même un message de validation. Utilisez cette compétence pour le commit git, le commit conventionnel et l'automatisation du commit.
