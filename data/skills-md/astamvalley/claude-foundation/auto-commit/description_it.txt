Analizza il codice modificato, genera automaticamente un messaggio di commit che segue le convenzioni di commit ed esegue il commit. Usalo quando dici "/auto-commit", "fai un commit per me", "commit please", "commit change" o "commit work". Funziona anche solo con "commit". Usalo quando vuoi automatizzare il commit senza scrivere tu stesso il messaggio di commit. Per git commit, commit convenzionale o commit automatizzato, usa questa abilità.
