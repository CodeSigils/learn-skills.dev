Библиотека Python для работы с геопространственными векторными данными, включая шейп-файлы, файлы GeoJSON и GeoPackage. Используйте при работе с географическими данными для пространственного анализа, геометрических операций, преобразований координат, пространственных соединений, операций наложения, картографии или любых задач, связанных с чтением/записью/анализом векторных географических данных. Поддерживает базы данных PostGIS, интерактивные карты и интеграцию с matplotlib/folium/cartopy. Используйте для таких задач, как анализ буфера, пространственные соединения между наборами данных, растворение границ, обрезка данных, расчет площадей/расстояний, перепроецирование систем координат, создание карт или преобразование между форматами пространственных файлов.
