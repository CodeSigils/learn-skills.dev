مكتبة Python للعمل مع بيانات المتجهات الجغرافية المكانية بما في ذلك ملفات الأشكال وملفات GeoJSON وGeoPackage. يُستخدم عند العمل مع البيانات الجغرافية للتحليل المكاني، أو العمليات الهندسية، أو التحويلات الإحداثية، أو الروابط المكانية، أو عمليات التراكب، أو رسم الخرائط التصحيحية، أو أي مهمة تتضمن قراءة/كتابة/تحليل البيانات الجغرافية المتجهة. يدعم قواعد بيانات PostGIS والخرائط التفاعلية والتكامل مع matplotlib/folium/cartopy. يُستخدم لمهام مثل تحليل المخزن المؤقت، أو الروابط المكانية بين مجموعات البيانات، أو إذابة الحدود، أو قص البيانات، أو حساب المناطق/المسافات، أو إعادة إسقاط الأنظمة الإحداثية، أو إنشاء الخرائط، أو التحويل بين تنسيقات الملفات المكانية.
