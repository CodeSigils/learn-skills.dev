Комплексный набор инструментов для подготовки документации по сертификации ISO 13485 для систем управления качеством медицинского оборудования. Используйте, когда пользователям нужна помощь с документацией СМК ISO 13485, включая (1) проведение анализа пробелов в существующей документации, (2) создание руководств по качеству, (3) разработку необходимых процедур и рабочих инструкций, (4) подготовку файлов медицинского оборудования, (5) понимание требований ISO 13485 или (6) выявление недостающей документации для сертификации медицинского оборудования. Также используйте, когда пользователи упоминают правила медицинского оборудования, сертификацию QMS, FDA QMSR, EU MDR или нуждаются в помощи с документацией системы качества.
