Accedi a una raccolta di strumenti di progettazione molecolare e biologia strutturale open source sulla piattaforma Tamarind Bio, tramite la sua API REST o il server MCP: non sono necessarie GPU locali. Tamarind raggruppa popolari modelli open source per la previsione della struttura (AlphaFold, Boltz, Chai, ESMFold), progettazione di proteine, leganti e de novo (RFdiffusion, ProteinMPNN, BoltzGen), progettazione e sviluppabilità di anticorpi e nanocorpo, docking proteico-ligando (DiffDock, Autodock Vina), previsione dell'affinità di legame, generazione di MSA e dinamica molecolare. Da utilizzare quando l'utente menziona Tamarind o tamarind.bio, desidera eseguire uno di questi strumenti open source nel cloud, fa riferimento ad app.tamarind.bio/api o all'intestazione x-api-key o deve inviare batch di sequenze per la caratterizzazione strutturale o biofisica.
