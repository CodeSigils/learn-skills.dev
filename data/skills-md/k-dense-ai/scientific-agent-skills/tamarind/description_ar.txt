يمكنك الوصول إلى مجموعة من أدوات التصميم الجزيئي والبيولوجيا الهيكلية مفتوحة المصدر على منصة Tamarind Bio، عبر خادم REST API أو MCP - دون الحاجة إلى وحدات معالجة رسومات محلية. يجمع Tamarind نماذج شائعة مفتوحة المصدر للتنبؤ بالبنية (AlphaFold، وBoltz، وChai، وESMFold)، وتصميم البروتين، والموثق، وde novo (RFdiffusion، وProteinMPNN، وBoltzGen)، وتصميم الأجسام المضادة والأجسام النانوية وقابلية التطوير، وإرساء بروتين يجند (DiffDock، Autodock Vina)، والتنبؤ بتقارب الارتباط، وتوليد MSA، والديناميكيات الجزيئية. يُستخدم عندما يذكر المستخدم Tamarind أو tamarind.bio، أو يريد تشغيل أي من هذه الأدوات مفتوحة المصدر في السحابة، أو يشير إلى app.tamarind.bio/api أو رأس مفتاح x-api، أو يحتاج إلى إرسال دفعات من التسلسلات للتوصيف الهيكلي أو الفيزيائي الحيوي.
