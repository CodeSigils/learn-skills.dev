REST API または MCP サーバーを介して、Tamarind Bio プラットフォーム上のオープンソースの分子設計および構造生物学ツールのコレクションにアクセスします。ローカル GPU は必要ありません。 Tamarind には、構造予測 (AlphaFold、Boltz、Chai、ESMFold)、タンパク質、バインダー、デノボ設計 (RFdiffusion、ProteinMPNN、BoltzGen)、抗体およびナノボディの設計と開発可能性、タンパク質-リガンドのドッキング (DiffDock、Autodock Vina)、結合親和性予測、MSA 生成、および分子動力学のための人気のあるオープンソース モデルがバンドルされています。ユーザーが Tamarind または tamarind.bio について言及する場合、これらのオープンソース ツールのいずれかをクラウドで実行する場合、app.tamarind.bio/api または x-api-key ヘッダーを参照する場合、または構造的または生物物理学的特性評価のために配列のバッチを送信する必要がある場合に使用します。
