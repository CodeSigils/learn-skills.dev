透過其 REST API 或 MCP 伺服器存取 Tamarind Bio 平台上的一系列開源分子設計和結構生物學工具 - 無需本地 GPU。 Tamarind 捆綁了流行的開源模型，用於結構預測（AlphaFold、Boltz、Chai、ESMFold）、蛋白質、結合劑和從頭設計（RFdiffusion、ProteinMPNN、BoltzGen）、抗體和奈米抗體設計和可開發性、蛋白質配體對接（DiffDock、Autodock Vina、Autodock Vina、Auto。當使用者提及 Tamarind 或 tamarind.bio、想要在雲端中運行任何這些開源工具、引用 app.tamarind.bio/api 或 x-api-key 標頭，或需要提交批量序列以進行結構或生物物理表徵時使用。
