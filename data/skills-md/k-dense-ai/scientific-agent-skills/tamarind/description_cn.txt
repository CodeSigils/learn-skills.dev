通过其 REST API 或 MCP 服务器访问 Tamarind Bio 平台上的一系列开源分子设计和结构生物学工具 - 无需本地 GPU。 Tamarind 捆绑了流行的开源模型，用于结构预测（AlphaFold、Boltz、Chai、ESMFold）、蛋白质、结合剂和从头设计（RFdiffusion、ProteinMPNN、BoltzGen）、抗体和纳米抗体设计和可开发性、蛋白质配体对接（DiffDock、Autodock Vina）、结合亲和力预测、MSA 生成和分子动力学。当用户提及 Tamarind 或 tamarind.bio、想要在云中运行任何这些开源工具、引用 app.tamarind.bio/api 或 x-api-key 标头，或者需要提交批量序列以进行结构或生物物理表征时使用。
