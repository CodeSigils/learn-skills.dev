Algoritmos de aprendizaje por refuerzo listos para producción (PPO, SAC, DQN, TD3, DDPG, A2C) con API similar a scikit-learn. Úselo para experimentos de RL estándar, creación rápida de prototipos e implementaciones de algoritmos bien documentadas. Lo mejor para RL de agente único con entornos de gimnasio. Para entrenamiento paralelo de alto rendimiento, sistemas multiagente o entornos vectorizados personalizados, utilice pufferlib en su lugar.
