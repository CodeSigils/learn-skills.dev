Algoritmi di apprendimento per rinforzo pronti per la produzione (PPO, SAC, DQN, TD3, DDPG, A2C) con API tipo scikit-learn. Utilizzare per esperimenti RL standard, prototipazione rapida e implementazioni di algoritmi ben documentate. Ideale per RL con agente singolo con ambienti di palestra. Per l'addestramento parallelo ad alte prestazioni, sistemi multi-agente o ambienti vettoriali personalizzati, utilizzare invece pufferlib.
