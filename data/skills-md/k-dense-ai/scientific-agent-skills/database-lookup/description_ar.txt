ابحث في 78 قاعدة بيانات عامة علمية وطبية حيوية وعلوم المواد واقتصادية عبر REST APIs. يغطي الفيزياء / علم الفلك (NASA، NIST، SDSS، SIMBAD)، الأرض / البيئة (USGS، NOAA، EPA)، الكيمياء / الأدوية (PubChem، ChEMBL، DrugBank، FDA، KEGG، ZINC، BindingDB)، المواد (Materials Project، COD)، علم الأحياء / الجينوم (Reactome، UniProt، STRING، Ensembl، NCBI Gene، GEO، GTEx، PDB، AlphaFold، InterPro، BioGRID، علم الجينات، dbSNP، gnomAD، ENCODE، أطلس البروتين البشري، أطلس الخلايا البشرية)، المرض/السريري (COSMIC، Open Targets، ClinicalTrials.gov، OMIM، ClinVar، GDC/TCGA، cBioPortal، DisGeNET، GWAS Catalog)، التنظيمية (FDA، USPTO، SEC EDGAR)، الاقتصاد/المالية (فريد، البنك الدولي، وزارة الخزانة الأمريكية)، التركيبة السكانية (التعداد السكاني الأمريكي، يوروستات، منظمة الصحة العالمية). يُستخدم عند البحث عن المركبات أو الجينات أو البروتينات أو المسارات أو المتغيرات أو التجارب السريرية أو براءات الاختراع أو المؤشرات الاقتصادية أو أي استعلام عن واجهة برمجة تطبيقات قاعدة البيانات العامة.
