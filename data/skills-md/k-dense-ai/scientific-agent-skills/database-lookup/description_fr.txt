Recherchez dans 78 bases de données publiques scientifiques, biomédicales, scientifiques des matériaux et économiques via les API REST. Couvre la physique/astronomie (NASA, NIST, SDSS, SIMBAD), la terre/environnement (USGS, NOAA, EPA), la chimie/médicaments (PubChem, ChEMBL, DrugBank, FDA, KEGG, ZINC, BindingDB), les matériaux (Materials Project, COD), la biologie/génomique (Reactome, UniProt, STRING, Ensembl, NCBI Gene, GEO, GTEx, PDB, AlphaFold, InterPro, BioGRID, Gene Ontology, dbSNP, gnomAD, ENCODE, Human Protein Atlas, Human Cell Atlas), maladie/clinique (COSMIC, Open Targets, ClinicalTrials.gov, OMIM, ClinVar, GDC/TCGA, cBioPortal, DisGeNET, GWAS Catalog), réglementation (FDA, USPTO, SEC EDGAR), économie/finance (FRED, Banque mondiale, Trésor américain), démographie (États-Unis Recensement, Eurostat, OMS). À utiliser lors de la recherche de composés, de gènes, de protéines, de voies, de variantes, d'essais cliniques, de brevets, d'indicateurs économiques ou de toute requête API de base de données publique.
