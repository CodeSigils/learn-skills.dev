Этот навык следует использовать в начале любой ресурсоемкой научной задачи для обнаружения и сообщения о доступных системных ресурсах (ядра ЦП, графические процессоры, память, дисковое пространство). Он создает файл JSON с информацией о ресурсах и стратегическими рекомендациями, которые помогают принимать решения о вычислительном подходе, например, использовать ли параллельную обработку (joblib, многопроцессорность), внеядерные вычисления (Dask, Zarr), ускорение графического процессора (PyTorch, JAX) или стратегии эффективного использования памяти. Используйте этот навык перед выполнением анализа, обучением моделей, обработкой больших наборов данных или любой задачей, где важны ограничения ресурсов.
