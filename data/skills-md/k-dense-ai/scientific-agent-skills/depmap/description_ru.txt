Запросите карту зависимости рака (DepMap) для получения показателей зависимости генов линий раковых клеток (CRISPR Chronos), данных о чувствительности к лекарствам и профилей эффектов генов. Использование для выявления уязвимостей, специфичных для рака, синтетических летальных взаимодействий и проверки мишеней для онкологических препаратов.
