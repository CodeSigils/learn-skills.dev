Mejore de forma autónoma un artefacto real (código, receta de entrenamiento, aprovechamiento de agentes, canalización de datos, aviso) frente a un objetivo y un evaluador, utilizando el refinamiento del árbol de hipótesis (HTR) del artículo de Arbor. Utilícelo siempre que alguien quiera optimizar algo de forma iterativa a lo largo de muchos experimentos sin sobreajustarlo, p. "aumentar la puntuación de evaluación de mi modelo", "mejorar este agente/arnés", "ajustar este canal", "superar la línea de base en este punto de referencia", "ejecutar una búsqueda de enfoques y mantener lo mejor", "realizar una optimización de estilo MLE-bench/Kaggle" o cualquier tarea a largo plazo de "mejorar este artefacto y no memorizar simplemente el conjunto de desarrollo". Actívelo incluso cuando el usuario no diga "Arbor" o "árbol de hipótesis", sino que describa bucles repetidos de experimento y evaluación, exploración ramificada de ideas en competencia o preocupaciones sobre una brecha entre desarrollo y prueba. Ejecuta a Claude como coordinador con ejecutores de subagente en árboles de trabajo de git aislados; para ver la herramienta CLI independiente `arbor`, consulte references/arbor-upstream.md.
