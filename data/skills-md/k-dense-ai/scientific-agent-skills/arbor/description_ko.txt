Arbor 논문의 HTR(가설 트리 개선)을 사용하여 목표 및 평가자에 대한 실제 아티팩트(코드, 교육 레시피, 에이전트 하네스, 데이터 파이프라인, 프롬프트)를 자동으로 개선합니다. 누군가가 과적합 없이 많은 실험을 통해 무언가를 반복적으로 최적화하고 싶을 때마다 이 기능을 사용하세요. "내 모델의 평가 점수 얻기", "이 에이전트/하네스 개선", "이 파이프라인 조정", "이 벤치마크의 기준 초과", "접근 방식에 대한 검색 실행 및 최상의 상태 유지", "MLE 벤치/Kaggle 스타일 최적화 수행" 또는 장기적인 관점에서 "이 아티팩트를 더 좋게 만들고 개발 세트만 외우지 마세요" 작업. 사용자가 "Arbor" 또는 "가설 트리"라고 말하지 않고 반복되는 실험 및 평가 루프, 경쟁 아이디어의 분기 탐색 또는 개발/테스트 격차에 대한 우려를 설명하는 경우에도 트리거합니다. 격리된 Git 작업 트리에서 하위 에이전트 실행기와 함께 Claude 자체를 코디네이터로 실행합니다. 독립형 'arbor' CLI 도구에 대해서는 reference/arbor-upstream.md를 참조하세요.
