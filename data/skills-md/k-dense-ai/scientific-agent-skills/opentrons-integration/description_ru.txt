Официальный API протокола Opentrons для роботов OT-2 и Flex. Используйте при написании протоколов специально для оборудования Opentron с полным доступом к функциям протокола API v2. Лучше всего подходит для производственных протоколов Opentrons, официальная совместимость API. Для автоматизации работы нескольких поставщиков или более широкого управления оборудованием используйте pylabrobot.
