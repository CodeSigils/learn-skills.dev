API ufficiale del protocollo Opentrons per robot OT-2 e Flex. Da utilizzare durante la scrittura di protocolli specifici per l'hardware Opentrons con accesso completo alle funzionalità Protocol API v2. Ideale per i protocolli Opentrons di produzione, compatibilità API ufficiale. Per l'automazione multi-vendor o un controllo più ampio delle apparecchiature, utilizzare pylabrobot.
