API officielle du protocole Opentrons pour les robots OT-2 et Flex. À utiliser lors de l'écriture de protocoles spécifiquement pour le matériel Opentrons avec un accès complet aux fonctionnalités de l'API de protocole v2. Idéal pour les protocoles Opentrons de production, compatibilité API officielle. Pour une automatisation multi-fournisseurs ou un contrôle d'équipement plus large, utilisez pylabrobot.
