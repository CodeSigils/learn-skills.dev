API oficial del protocolo Opentrons para robots OT-2 y Flex. Úselo al escribir protocolos específicamente para hardware Opentrons con acceso completo a las funciones del Protocolo API v2. Lo mejor para protocolos Opentrons de producción, compatibilidad API oficial. Para la automatización de múltiples proveedores o un control más amplio de equipos, utilice pylabrobot.
