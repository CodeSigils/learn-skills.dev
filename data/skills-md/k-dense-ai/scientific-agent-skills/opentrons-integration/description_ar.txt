واجهة برمجة تطبيقات بروتوكول Opentrons الرسمية لروبوتات OT-2 وFlex. يُستخدم عند كتابة البروتوكولات خصيصًا لأجهزة Opentrons مع إمكانية الوصول الكامل إلى ميزات Protocol API v2. الأفضل لبروتوكولات Opentrons للإنتاج، والتوافق الرسمي لواجهة برمجة التطبيقات (API). من أجل التشغيل الآلي متعدد البائعين أو التحكم الأوسع في المعدات، استخدم pylabrobot.
