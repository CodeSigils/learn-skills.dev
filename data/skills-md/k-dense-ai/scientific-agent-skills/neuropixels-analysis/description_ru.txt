Анализ нейропиксельных нейронных записей. Загрузка данных SpikeGLX/OpenEphys, предварительная обработка, коррекция движения, сортировка спайков Kilosort4, показатели качества, курирование Allen/IBL, визуальный анализ с помощью искусственного интеллекта для внеклеточной электрофизиологии Neuropixels 1.0/2.0. Используйте при работе с нейронными записями, сортировкой спайков, внеклеточной электрофизиологией или когда пользователь упоминает Neuropixels, SpikeGLX, Open Ephys, Kilosort, метрики качества или курирование единиц.
