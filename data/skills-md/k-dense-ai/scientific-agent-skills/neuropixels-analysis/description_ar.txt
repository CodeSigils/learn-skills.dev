تحليل التسجيل العصبي لـ Neuropixels. قم بتحميل بيانات SpikeGLX/OpenEphys، والمعالجة المسبقة، وتصحيح الحركة، وفرز Kilosort4، ومقاييس الجودة، ومعالجة Allen/IBL، والتحليل البصري بمساعدة الذكاء الاصطناعي، لعلم وظائف الأعضاء الكهربية خارج الخلية Neuropixels 1.0/2.0. يُستخدم عند العمل مع التسجيلات العصبية، أو الفرز المتصاعد، أو الفيزيولوجيا الكهربية خارج الخلية، أو عندما يذكر المستخدم Neuropixels، أو SpikeGLX، أو Open Ephys، أو Kilosort، أو مقاييس الجودة، أو تنظيم الوحدات.
