Come utilizzare l'API Adaptyv Bio Foundry e l'SDK Python per la progettazione, l'invio e il recupero dei risultati di esperimenti sulle proteine. Utilizza questa competenza ogni volta che l'utente menziona Adaptyv, API Foundry, test di legame proteico, esperimenti di screening proteico, test BLI/SPR, test di termostabilità o desidera inviare sequenze proteiche per la caratterizzazione sperimentale. Si attiva anche quando il codice importa `adaptyv`, `adaptyv_sdk` o `FoundryClient` o fa riferimento a `foundry-api-public.adaptyvbio.com`.
