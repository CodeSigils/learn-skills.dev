Comment utiliser l'API Adaptyv Bio Foundry et le SDK Python pour la conception, la soumission et la récupération des résultats d'expériences sur les protéines. Utilisez cette compétence chaque fois que l'utilisateur mentionne Adaptyv, Foundry API, des tests de liaison aux protéines, des expériences de criblage de protéines, des tests BLI/SPR, des tests de thermostabilité, ou souhaite soumettre des séquences de protéines pour une caractérisation expérimentale. Se déclenche également lorsque le code importe `adaptyv`, `adaptyv_sdk` ou `FoundryClient`, ou fait référence à `foundry-api-public.adaptyvbio.com`.
