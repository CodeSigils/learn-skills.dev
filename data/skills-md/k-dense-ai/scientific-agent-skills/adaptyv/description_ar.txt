كيفية استخدام Adaptyv Bio Foundry API وPython SDK لتصميم تجربة البروتين وتقديمها واسترجاع النتائج. استخدم هذه المهارة عندما يذكر المستخدم Adaptyv، أو Foundry API، أو فحوصات ربط البروتين، أو تجارب فحص البروتين، أو فحوصات BLI/SPR، أو فحوصات الاستقرار الحراري، أو يريد إرسال تسلسلات البروتين للتوصيف التجريبي. يتم تشغيله أيضًا عند استيراد التعليمات البرمجية `adaptyv` أو `adaptyv_sdk` أو `FoundryClient` أو الإشارة إلى Foundry-api-public.adaptyvbio.com`.
