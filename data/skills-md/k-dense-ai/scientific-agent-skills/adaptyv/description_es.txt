Cómo utilizar la API de Adaptyv Bio Foundry y el SDK de Python para el diseño, envío y recuperación de resultados de experimentos con proteínas. Utilice esta habilidad siempre que el usuario mencione Adaptyv, Foundry API, ensayos de unión a proteínas, experimentos de detección de proteínas, ensayos BLI/SPR, ensayos de termoestabilidad o desee enviar secuencias de proteínas para caracterización experimental. También se activa cuando el código importa `adaptyv`, `adaptyv_sdk` o `FoundryClient`, o hace referencia a `foundry-api-public.adaptyvbio.com`.
