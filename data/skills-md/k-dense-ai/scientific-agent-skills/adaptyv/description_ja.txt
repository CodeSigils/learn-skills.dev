Adaptyv Bio Foundry API と Python SDK を使用してタンパク質実験の設計、送信、結果の取得を行う方法。ユーザーが Adaptyv、Foundry API、タンパク質結合アッセイ、タンパク質スクリーニング実験、BLI/SPR アッセイ、熱安定性アッセイについて言及する場合、または実験による特性評価のためにタンパク質配列を提出したい場合には、このスキルを使用してください。コードが `adaptyv`、`adaptyv_sdk`、または `FoundryClient` をインポートする場合、または `foundry-api-public.adaptyvbio.com` を参照する場合にもトリガーされます。
