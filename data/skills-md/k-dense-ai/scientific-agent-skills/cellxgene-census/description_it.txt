Interroga il censimento CELLxGENE (oltre 61 milioni di celle) a livello di codice. Utilizzalo quando hai bisogno di dati sull'espressione di tessuti, malattie o tipi di cellule dal più grande atlante unicellulare curato. Ideale per query su scala di popolazione, confronti di atlanti di riferimento. Per analizzare i tuoi dati usa scanpy o scvi-tools.
