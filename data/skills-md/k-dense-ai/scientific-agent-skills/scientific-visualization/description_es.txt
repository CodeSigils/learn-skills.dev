Metahabilidad para figuras listas para publicación. Utilícelo al crear figuras de envío de revistas que requieran diseños de varios paneles, anotaciones significativas, barras de error, paletas seguras para daltónicos y formatos de revistas específicos (Naturaleza, Ciencia, Celda). Orquesta matplotlib/seaborn/plotly con estilos de publicación. Para una exploración rápida, utilice seaborn o plotly directamente.
