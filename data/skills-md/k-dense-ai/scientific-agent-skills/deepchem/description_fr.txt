ML moléculaire avec divers fonctionnalités et ensembles de données prédéfinis. À utiliser pour la prédiction de propriétés (ADMET, toxicité) avec des ML ou GNN traditionnels lorsque vous souhaitez des options de caractérisation étendues et des benchmarks MoleculeNet. Idéal pour des expériences rapides avec des modèles pré-entraînés et diverses représentations moléculaires. Pour les flux de travail PyTorch axés sur les graphiques, utilisez torchdrug ; pour les ensembles de données de référence, utilisez pytdc.
