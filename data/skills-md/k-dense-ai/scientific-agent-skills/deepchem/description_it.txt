ML molecolare con diverse funzionalità e set di dati predefiniti. Utilizzalo per la previsione delle proprietà (ADMET, tossicità) con ML o GNN tradizionali quando desideri opzioni di caratterizzazione estese e benchmark MoleculeNet. Ideale per esperimenti rapidi con modelli preaddestrati e diverse rappresentazioni molecolari. Per i flussi di lavoro PyTorch basati sul grafico utilizzare torchdrug; per i set di dati di riferimento utilizzare pytdc.
