Молекулярный МО с разнообразными функциями и готовыми наборами данных. Используйте для прогнозирования свойств (ADMET, токсичность) с помощью традиционных ML или GNN, если вам нужны расширенные возможности определения характеристик и тесты MoleculeNet. Лучше всего подходит для быстрых экспериментов с предварительно обученными моделями и разнообразными молекулярными представлениями. Для рабочих процессов PyTorch с приоритетом графов используйте torchdrug; для контрольных наборов данных используйте pytdc.
