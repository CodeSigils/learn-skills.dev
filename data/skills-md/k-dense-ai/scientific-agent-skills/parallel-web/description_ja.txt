学術的および科学的ソースに重点を置いた、Parallel-cli を利用したオールインワン Web ツールキット。ユーザーが Web を検索したり、URL コンテンツをフェッチ/抽出したり、Web ソースのフィールドでデータを強化したり、詳細な調査レポートを実行したりする必要がある場合には、このスキルを使用します。対象範囲: Web 検索 (高速検索、調査、最新情報 - 査読済み論文、プレプリント、学術データベースの優先順位付け)、URL 抽出 (ページ、論文、学術 PDF の取得)、バルク データ エンリッチメント (Web から CSV/リストにフィールドを追加)、詳細調査 (学術文献に基づいた徹底的なマルチソース レポート)。セットアップ、ステータスの確認、結果の取得も処理します。ユーザーが「並列」または「Web」について明示的に言及していない場合でも、Web 関連のあらゆるタスクにこのスキルを使用してください。何かを調べたり、ページを取得したり、データセットを強化したり、トピックを調査したり、学術論文を検索したり、引用文献を確認したり、科学文献をレビューしたりする場合に、これは使用するスキルです。
