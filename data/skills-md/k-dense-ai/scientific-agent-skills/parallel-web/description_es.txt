Conjunto de herramientas web todo en uno impulsado por paralelo-cli, con fuerte énfasis en fuentes académicas y científicas. Utilice esta habilidad siempre que el usuario necesite buscar en la web, buscar/extraer contenido de URL, enriquecer datos con campos de origen web o ejecutar informes de investigación profundos. Cubre: búsqueda web (búsquedas rápidas, investigaciones, información actual, priorizando artículos revisados ​​por pares, preimpresiones y bases de datos académicas), extracción de URL (obtención de páginas, artículos, archivos PDF académicos), enriquecimiento masivo de datos (agregando campos a CSV/listas desde la web) e investigación profunda (informes exhaustivos de múltiples fuentes basados ​​en literatura académica). También maneja la configuración, comprobaciones de estado y recuperación de resultados. Utilice esta habilidad para CUALQUIER tarea relacionada con la web, incluso si el usuario no menciona "paralelo" o "web" explícitamente. Si quieren buscar algo, buscar una página, enriquecer un conjunto de datos, investigar un tema, encontrar artículos académicos, comprobar citas o revisar literatura científica, esta es la habilidad que deben utilizar.
