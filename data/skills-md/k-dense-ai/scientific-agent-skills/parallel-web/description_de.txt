All-in-One-Web-Toolkit auf Basis von Parallel-Cli mit starkem Schwerpunkt auf akademischen und wissenschaftlichen Quellen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer das Web durchsuchen, URL-Inhalte abrufen/extrahieren, Daten mit aus dem Internet stammenden Feldern anreichern oder umfassende Forschungsberichte erstellen muss. Umfasst: Websuche (schnelle Suche, Recherche, aktuelle Informationen – Priorisierung von peer-reviewten Artikeln, Vorabdrucken und wissenschaftlichen Datenbanken), URL-Extraktion (Abrufen von Seiten, Artikeln, wissenschaftlichen PDFs), Massendatenanreicherung (Hinzufügen von Feldern zu CSV/Listen aus dem Internet) und tiefgreifende Recherche (umfassende Berichte aus mehreren Quellen, die auf wissenschaftlicher Literatur basieren). Übernimmt außerdem die Einrichtung, Statusprüfungen und den Ergebnisabruf. Verwenden Sie diese Fähigkeit für JEDE Web-bezogene Aufgabe – auch wenn der Benutzer „parallel“ oder „Web“ nicht explizit erwähnt. Wenn sie etwas nachschlagen, eine Seite abrufen, einen Datensatz anreichern, ein Thema untersuchen, wissenschaftliche Arbeiten finden, Zitate überprüfen oder wissenschaftliche Literatur durchsehen möchten, ist dies die richtige Fähigkeit.
