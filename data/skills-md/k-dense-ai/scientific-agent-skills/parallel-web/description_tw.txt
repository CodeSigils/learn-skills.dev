由 parallel-cli 提供支援的一體化 Web 工具包，重點關注學術和科學資源。每當使用者需要搜尋網路、取得/擷取 URL 內容、使用網路來源的欄位豐富資料或執行深入的研究報告時，請使用此技能。涵蓋：網路搜尋（快速尋找、研究、當前資訊 - 優先考慮同行評審的論文、預印本和學術資料庫）、URL 提取（獲取頁面、文章、學術 PDF）、大量資料豐富（從網路將欄位新增至 CSV/清單）和深入研究（基於學術文獻的詳盡多來源報告）。也處理設定、狀態檢查和結果檢索。將此技能用於任何與網路相關的任務 - 即使用戶沒有明確提及「並行」或「網路」。如果他們想要尋找內容、取得頁面、豐富資料集、研究主題、尋找學術論文、檢查引文或審查科學文獻，就可以使用此技能。
