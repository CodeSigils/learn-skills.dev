Kit di strumenti web all-in-one basato su parallel-cli, con una forte enfasi sulle fonti accademiche e scientifiche. Utilizza questa competenza ogni volta che l'utente ha bisogno di effettuare ricerche sul Web, recuperare/estrarre contenuti URL, arricchire dati con campi provenienti dal Web o eseguire report di ricerca approfonditi. Copre: ricerca sul Web (ricerche rapide, ricerche, informazioni attuali, dando priorità a documenti sottoposti a revisione paritaria, prestampe e database accademici), estrazione di URL (recupero di pagine, articoli, PDF accademici), arricchimento di dati in blocco (aggiunta di campi a CSV/elenchi dal Web) e ricerca approfondita (rapporti esaustivi da più fonti basati sulla letteratura accademica). Gestisce inoltre la configurazione, i controlli dello stato e il recupero dei risultati. Utilizza questa competenza per QUALSIASI attività relativa al Web, anche se l'utente non menziona esplicitamente "parallelo" o "web". Se vogliono cercare qualcosa, recuperare una pagina, arricchire un set di dati, indagare su un argomento, trovare documenti accademici, controllare citazioni o rivedere la letteratura scientifica, questa è l'abilità da utilizzare.
