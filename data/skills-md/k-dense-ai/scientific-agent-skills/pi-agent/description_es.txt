Construya y utilice Pi, el arnés de codificación de terminales mínimo. Úselo para instalar Pi, configurar proveedores/modelos/configuraciones, crear habilidades/extensiones/paquetes/temas/plantillas de mensajes de Pi, incrustar Pi a través del SDK, integrar flujos de eventos RPC o JSON, analizar sesiones, desarrollar proveedores de Pi personalizados y componentes TUI, o usar paquetes de ecosistema como pi-subagents (delegación/orquestación), pi-mcp-adapter (servidores MCP), pi-interview (interactivo formularios) y pi-web-access (búsqueda web, recuperación, comprensión de vídeos).
