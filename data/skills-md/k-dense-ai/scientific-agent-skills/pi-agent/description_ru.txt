Создавайте и используйте Pi, минимальный набор инструментов для кодирования терминалов. Используется для установки Pi, настройки поставщиков/моделей/настроек, создания навыков/расширений/пакетов/тем/шаблонов подсказок Pi, внедрения Pi через SDK, интеграции через потоки событий RPC или JSON, анализа сеансов, разработки пользовательских поставщиков Pi и компонентов TUI или использования пакетов экосистемы, таких как pi-субагенты (делегирование/оркестрация), pi-mcp-adapter (серверы MCP), pi-интервью (интерактивные формы), и pi-web-access (веб-поиск, извлечение, понимание видео).
