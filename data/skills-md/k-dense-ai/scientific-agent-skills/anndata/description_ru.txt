Структура данных для аннотированных матриц при анализе одной ячейки. Используйте при работе с файлами .h5ad или при интеграции с экосистемой scverse. Это умение форматировать данные — для рабочих процессов анализа используйте scanpy; для вероятностных моделей используйте scvi-инструменты; для запросов в масштабе населения используйте cellxgene-census.
