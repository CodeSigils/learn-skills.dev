Structure de données pour les matrices annotées dans l'analyse monocellulaire. À utiliser lorsque vous travaillez avec des fichiers .h5ad ou lors de l'intégration à l'écosystème scverse. Il s'agit de la compétence de formatage des données : pour les flux de travail d'analyse, utilisez scanpy ; pour les modèles probabilistes, utilisez les outils scvi ; pour les requêtes à l’échelle de la population, utilisez cellxgene-census.
