Struttura dei dati per matrici annotate nell'analisi di una singola cella. Da utilizzare quando si lavora con file .h5ad o si integra con l'ecosistema scverse. Questa è la competenza relativa al formato dei dati: per i flussi di lavoro di analisi utilizzare scanpy; per i modelli probabilistici utilizzare gli strumenti scvi; per le query su scala di popolazione utilizzare cellxgene-census.
