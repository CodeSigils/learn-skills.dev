Informatique distribuée pour les flux de travail pandas/NumPy plus grands que la RAM. À utiliser lorsque vous devez mettre à l'échelle le code pandas/NumPy existant au-delà de la mémoire ou sur plusieurs clusters. Idéal pour le traitement de fichiers parallèles, le ML distribué et l'intégration avec le code pandas existant. Pour des analyses hors cœur sur une seule machine, utilisez vaex ; pour la vitesse en mémoire, utilisez les polaires.
