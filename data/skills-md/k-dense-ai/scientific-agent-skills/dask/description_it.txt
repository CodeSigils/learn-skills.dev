Elaborazione distribuita per flussi di lavoro Panda/NumPy più grandi della RAM. Da utilizzare quando è necessario ridimensionare il codice Panda/NumPy esistente oltre la memoria o tra cluster. Ideale per l'elaborazione di file paralleli, ML distribuito, integrazione con il codice Panda esistente. Per analisi out-of-core su una singola macchina utilizzare vaex; per la velocità in memoria utilizzare i polari.
