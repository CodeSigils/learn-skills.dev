Verteiltes Computing für Pandas/NumPy-Workflows, die größer als RAM sind. Verwenden Sie diese Option, wenn Sie vorhandenen Pandas/NumPy-Code über den Speicher hinaus oder über Cluster hinweg skalieren müssen. Am besten geeignet für parallele Dateiverarbeitung, verteiltes ML und Integration mit vorhandenem Pandas-Code. Für Out-of-Core-Analysen auf einer einzelnen Maschine verwenden Sie vaex; Für die In-Memory-Geschwindigkeit verwenden Sie Polaren.
