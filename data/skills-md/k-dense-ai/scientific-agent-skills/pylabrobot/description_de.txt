Herstellerunabhängiges Laborautomatisierungs-Framework. Verwenden Sie es, wenn Sie mehrere Gerätetypen (Hamilton, Tecan, Opentrons, Plattenlesegeräte, Pumpen) steuern oder eine einheitliche Programmierung verschiedener Anbieter benötigen. Am besten für komplexe Arbeitsabläufe, Multi-Vendor-Setups und Simulation geeignet. Für reine Opentrons-Protokolle mit offizieller API ist die Opentrons-Integration möglicherweise einfacher.
