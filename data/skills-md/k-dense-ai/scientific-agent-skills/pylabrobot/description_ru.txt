Независимая от поставщика система автоматизации лаборатории. Используйте при управлении несколькими типами оборудования (Hamilton, Tecan, Opentrons, планшетные считыватели, насосы) или при необходимости унифицированного программирования для разных поставщиков. Лучше всего подходит для сложных рабочих процессов, установок различных поставщиков и моделирования. Для протоколов Opentrons с официальным API интеграция opentrons может быть проще.
