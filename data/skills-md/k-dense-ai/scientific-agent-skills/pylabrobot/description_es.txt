Marco de automatización de laboratorio independiente del proveedor. Lo mejor para flujos de trabajo complejos, configuraciones de múltiples proveedores y simulación. Para protocolos exclusivos de Opentrons con API oficial, la integración de opentrons puede ser más sencilla.
