Cadre d'automatisation de laboratoire indépendant du fournisseur. À utiliser lors du contrôle de plusieurs types d'équipements (Hamilton, Tecan, Opentrons, lecteurs de plaques, pompes) ou lorsque vous avez besoin d'une programmation unifiée entre différents fournisseurs. Idéal pour les flux de travail complexes, les configurations multifournisseurs et la simulation. Pour les protocoles uniquement Opentrons avec API officielle, l'intégration d'Opentrons peut être plus simple.
