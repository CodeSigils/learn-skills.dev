Framework di automazione del laboratorio indipendente dal fornitore. Da utilizzare quando si controllano più tipi di apparecchiature (Hamilton, Tecan, Opentron, lettori di piastre, pompe) o è necessaria una programmazione unificata tra diversi fornitori. Ideale per flussi di lavoro complessi, configurazioni multi-vendor e simulazione. Per i protocolli solo Opentrons con API ufficiale, l'integrazione di opentrons potrebbe essere più semplice.
