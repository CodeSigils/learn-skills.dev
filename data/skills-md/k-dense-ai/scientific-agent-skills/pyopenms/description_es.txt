Plataforma completa de análisis de espectrometría de masas. Úselo para flujos de trabajo de proteómica, detección de funciones, identificación de péptidos, cuantificación de proteínas y procesos complejos de LC-MS/MS. Admite amplios formatos de archivos y algoritmos. Lo mejor para proteómica, procesamiento integral de datos de MS. Para una comparación espectral simple y la identificación de metabolitos, use matchms.
