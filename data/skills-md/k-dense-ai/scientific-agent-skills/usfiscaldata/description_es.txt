Consulte la API REST de datos fiscales del Tesoro de EE. UU. para obtener datos financieros federales. No se requiere clave API. Úselo para deuda nacional (Deuda al centavo), estados de cuenta diarios del tesoro, estados de cuenta mensuales del tesoro, subastas de valores del tesoro, tasas de interés, tipos de cambio, bonos de ahorro o estadísticas de ingresos y gastos del gobierno de EE. UU.
