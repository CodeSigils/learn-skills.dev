Запросите REST API финансовых данных Казначейства США для получения федеральных финансовых данных. Ключ API не требуется. Используется для государственного долга (долга до пенни), ежедневных отчетов казначейства, ежемесячных отчетов казначейства, аукционов казначейских ценных бумаг, процентных ставок, курсов валют, сберегательных облигаций или статистики доходов и расходов правительства США.
