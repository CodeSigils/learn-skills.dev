Interrogez l’API REST de données fiscales du Trésor américain pour obtenir des données financières fédérales. Aucune clé API requise. À utiliser pour la dette nationale (dette au centime), les relevés quotidiens du Trésor, les relevés mensuels du Trésor, les enchères de titres du Trésor, les taux d'intérêt, les taux de change, les obligations d'épargne ou les statistiques de revenus et de dépenses du gouvernement américain.
