استعلم عن REST API للبيانات المالية لوزارة الخزانة الأمريكية للحصول على البيانات المالية الفيدرالية. لا يوجد مفتاح API مطلوب. يُستخدم للدين الوطني (الدين مقابل القرش)، أو بيانات الخزانة اليومية، أو بيانات الخزانة الشهرية، أو مزادات سندات الخزانة، أو أسعار الفائدة، أو أسعار صرف العملات الأجنبية، أو سندات الادخار، أو إحصاءات إيرادات الحكومة الأمريكية وإنفاقها.
