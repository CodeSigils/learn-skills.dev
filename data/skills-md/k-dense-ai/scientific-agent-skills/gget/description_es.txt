Consultas rápidas CLI/Python a más de 20 bases de datos bioinformáticas. Úselo para búsquedas rápidas: información genética, búsquedas BLAST, estructuras AlphaFold, análisis de enriquecimiento. Lo mejor para exploración interactiva y consultas sencillas. Para procesamiento por lotes o BLAST avanzado, utilice biopython; para flujos de trabajo de Python con múltiples bases de datos, utilice bioservicios.
