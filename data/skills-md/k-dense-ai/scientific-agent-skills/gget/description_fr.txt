Requêtes CLI/Python rapides vers plus de 20 bases de données bioinformatiques. À utiliser pour des recherches rapides : informations sur les gènes, recherches BLAST, structures AlphaFold, analyse d'enrichissement. Idéal pour l’exploration interactive et les requêtes simples. Pour le traitement par lots ou le BLAST avancé, utilisez biopython ; pour les flux de travail Python multi-bases de données, utilisez des bioservices.
