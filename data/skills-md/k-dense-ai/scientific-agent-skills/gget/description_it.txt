Query CLI/Python veloci su oltre 20 database bioinformatici. Utilizzare per ricerche rapide: informazioni sui geni, ricerche BLAST, strutture AlphaFold, analisi di arricchimento. Ideale per l'esplorazione interattiva e le query semplici. Per l'elaborazione batch o BLAST avanzato utilizzare biopython; per i flussi di lavoro Python multi-database utilizzano i bioservizi.
