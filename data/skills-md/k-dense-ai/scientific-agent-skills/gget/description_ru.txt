Быстрые запросы CLI/Python к более чем 20 базам данных биоинформатики. Используйте для быстрого поиска: информацию о генах, поиск BLAST, структуры AlphaFold, анализ обогащения. Лучше всего подходит для интерактивного исследования и простых запросов. Для пакетной обработки или расширенного BLAST используйте biopython; для рабочих процессов Python с несколькими базами данных используйте биосервисы.
