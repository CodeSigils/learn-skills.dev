Прогнозирование временных рядов с нулевым выстрелом с помощью базовой модели Google TimesFM. Используйте для любых одномерных временных рядов (продажи, датчики, энергия, жизненно важные показатели, погода) без обучения специальной модели. Поддерживает входные данные CSV/DataFrame/массив с точечными прогнозами и интервалами прогнозирования. Включает сценарий предполетной проверки системы для проверки ОЗУ/графического процессора перед первым использованием.
