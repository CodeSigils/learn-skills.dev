Pronóstico de series temporales de disparo cero con el modelo básico TimesFM de Google. Úselo para cualquier serie temporal univariada (ventas, sensores, energía, signos vitales, clima) sin entrenar un modelo personalizado. Admite entradas CSV/DataFrame/matriz con pronósticos puntuales e intervalos de predicción. Incluye un script de verificación del sistema de verificación previa para verificar la RAM/GPU antes del primer uso.
