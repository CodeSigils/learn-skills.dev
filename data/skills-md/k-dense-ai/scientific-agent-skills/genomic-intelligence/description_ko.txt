로컬 GPU나 모델 가중치 없이 Genomic Intelligence에서 호스팅하는 변환기 DNA 언어 모델을 사용하여 DNA 서열에서 직접 조절 기능, 유전자 구조 및 발현을 예측합니다. REST API 및 호스팅된 MCP 서버를 통한 6가지 작업(키 없는 공개 데모): 프로모터 영역, 스플라이스 기증자/수용자 사이트, 인핸서 활동, 염색질 상태, 시퀀스-발현(로그 TPM) 및 de-novo 유전자 주석과 복합 유전자 찾기 후 예측 발현 워크플로우. 사용자가 유전자 기호, 게놈 영역 또는 DNA/FASTA 서열을 가지고 있고 이러한 예측을 원할 때 Genomic Intelligence, genomicintelligence.ai, api.genomicintelligence.ai 또는 mcp.genomicintelligence.ai를 언급하는 경우에 사용합니다.
