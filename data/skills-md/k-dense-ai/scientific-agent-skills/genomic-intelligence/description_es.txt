Prediga las características regulatorias, la estructura genética y la expresión directamente a partir de la secuencia de ADN utilizando los modelos de lenguaje de ADN transformador alojados en Genomic Intelligence, sin GPU local ni pesos de modelo. Seis tareas a través de una API REST y un servidor MCP alojado (demostración pública sin llave): regiones promotoras, sitios donantes/aceptores de empalme, actividad potenciadora, estado de cromatina, secuencia a expresión (log TPM) y anotación de genes de novo, además de un flujo de trabajo compuesto de búsqueda de genes y luego predicción de expresión. Úselo cuando el usuario tenga un símbolo genético, una región genómica o una secuencia de ADN/FASTA y quiera cualquiera de estas predicciones, menciona Genomic Intelligence, genomicintelligence.ai, api.genomicintelligence.ai o mcp.genomicintelligence.ai.
