스크린파이프를 통해 사용자의 화면을 관찰하고, 반복되는 연구 워크플로를 감지하고, 이를 기존 과학 에이전트 기술과 일치시키고, 아직 다루지 않은 패턴에 대한 새로운 기술(또는 기존 기술을 연결하는 구성 레시피) 초안을 작성합니다. 사용자가 최근 작업을 분석하고 실제 수행한 작업을 기반으로 기술을 제안하도록 요청할 때 사용합니다. 포트 3030에서 로컬로 실행되는 screenpipe 데몬(https://github.com/screenpipe/screenpipe)이 필요합니다. 이 스킬에는 다른 데이터 소스가 없으며 screenpipe에 연결할 수 없는 경우 실행이 거부됩니다. 모든 탐지는 로컬에서 실행됩니다. 수정된 클러스터 요약만 LLM에 도달합니다.
