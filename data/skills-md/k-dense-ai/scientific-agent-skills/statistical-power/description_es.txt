Cálculos de tamaño de muestra y potencia estadística para estudios de planificación. Úselo siempre que alguien pregunte "cuántos sujetos/muestras/réplicas necesito", quiera un análisis de potencia a priori, un efecto mínimo detectable (MDE), una curva de potencia o necesite justificar un tamaño de muestra para una subvención, un protocolo IRB o un registro previo. Cubre el poder de forma cerrada para pruebas t, ANOVA, proporciones, correlaciones, chi-cuadrado y regresión, además de poder basado en simulación (Monte Carlo) para diseños sin fórmula: regresión logística/Poisson, modelos mixtos, ensayos aleatorios por conglomerados, supervivencia e interacciones. Utilice esta habilidad incluso cuando la solicitud solo mencione un tamaño de efecto, alfa o "80 % de potencia" sin decir "análisis de potencia" explícitamente. Para diseñar el estudio (aleatorización, bloqueo, factorial/DOE, diseños cruzados, secuenciales) utilice un diseño experimental; para analizar los datos ya recopilados y reportarlos se utiliza el análisis estadístico.
