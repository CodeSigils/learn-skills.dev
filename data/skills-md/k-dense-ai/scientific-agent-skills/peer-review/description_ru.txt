Структурированный обзор рукописи/гранта с оценкой на основе контрольного списка. Используйте при написании формальных экспертных оценок с оценкой методологии по конкретным критериям, статистической достоверностью, соответствием стандартам отчетности (CONSORT/STROBE) и конструктивной обратной связью. Лучше всего подходит для написания рецензий и редактирования рукописи. Для оценки качества утверждений/доказательств используйте научно-критическое мышление; для количественной системы оценки используйте ученую оценку.
