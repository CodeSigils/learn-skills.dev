Utilice esta habilidad cuando trabaje con conjuntos de datos de estructura de datos de imágenes cerebrales (BIDS): organizando datos de neurociencia y biomédicos (MRI, EEG, MEG, iEEG, PET, microscopía, NIRS, captura de movimiento, EMG, espectroscopia de resonancia magnética, comportamiento), consultando diseños de BIDS, validando el cumplimiento, convirtiendo DICOM a BIDS, escribiendo complementos de metadatos o creando derivados de BIDS.
