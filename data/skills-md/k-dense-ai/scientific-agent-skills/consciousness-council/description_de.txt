Führen Sie eine multiperspektivische Mind Council-Beratung zu jeder Frage, Entscheidung oder kreativen Herausforderung durch. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer unterschiedliche Standpunkte wünscht, Hilfe bei einer schwierigen Entscheidung benötigt, um eine Rats-/Podiums-/Vorstandsdiskussion bittet, ein Problem aus mehreren Blickwinkeln untersuchen möchte, eine Devil's-Advocacy-Analyse anfordert oder Dinge sagt wie „Was würden verschiedene Experten darüber denken“, „Hilf mir, das von allen Seiten zu durchdenken“, „Ratsmodus“, „Gedankenrat“ oder „Beratung darüber“. Wird auch ausgelöst, wenn der Benutzer vor einem Dilemma, einem Kompromiss oder einer komplexen Entscheidung ohne offensichtliche Antwort steht.
