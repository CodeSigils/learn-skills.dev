Cree, edite, analice o convierta hojas de cálculo de Excel (.xlsx, .xlsm) donde el archivo del libro de trabajo sea el entregable principal. Úselo para fórmulas, formato, modelos financieros, libros de trabajo de varias hojas y limpieza tabular exportados a Excel. También se aplica a .csv/.tsv cuando el usuario desea generar resultados en una hoja de cálculo. NO lo use para documentos de Word, informes HTML, secuencias de comandos Python independientes, canalizaciones de bases de datos o trabajos API de Google Sheets.
