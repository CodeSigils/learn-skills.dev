قم بإنشاء جداول بيانات Excel أو تحريرها أو تحليلها أو تحويلها (.xlsx، .xlsm) حيث يكون ملف المصنف هو التسليم الأساسي. يستخدم للصيغ والتنسيق والنماذج المالية والمصنفات متعددة الأوراق والتنظيف الجدولي المصدر إلى Excel. ينطبق أيضًا على ‎.csv/.tsv عندما يريد المستخدم إخراج جدول البيانات. لا تستخدمه مع مستندات Word، أو تقارير HTML، أو نصوص Python المستقلة، أو خطوط أنابيب قاعدة البيانات، أو عمل Google Sheets API.
