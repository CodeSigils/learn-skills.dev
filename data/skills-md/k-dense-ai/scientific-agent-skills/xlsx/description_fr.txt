Créez, modifiez, analysez ou convertissez des feuilles de calcul Excel (.xlsx, .xlsm) où le fichier de classeur est le principal livrable. À utiliser pour les formules, le formatage, les modèles financiers, les classeurs multi-feuilles et le nettoyage tabulaire exportés vers Excel. S'applique également à .csv/.tsv lorsque l'utilisateur souhaite une sortie de feuille de calcul. Ne PAS utiliser pour les documents Word, les rapports HTML, les scripts Python autonomes, les pipelines de bases de données ou le travail de l'API Google Sheets.
