Создавайте, редактируйте, анализируйте или конвертируйте электронные таблицы Excel (.xlsx, .xlsm), где файл книги является основным результатом. Используйте для формул, форматирования, финансовых моделей, многолистовых книг и очистки таблиц, экспортированных в Excel. Также применяется к .csv/.tsv, когда пользователю нужен вывод электронной таблицы. НЕ используйте для документов Word, отчетов HTML, автономных сценариев Python, конвейеров баз данных или работы API Google Таблиц.
