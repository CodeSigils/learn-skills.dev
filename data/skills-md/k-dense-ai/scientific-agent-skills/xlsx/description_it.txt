Crea, modifica, analizza o converti fogli di calcolo Excel (.xlsx, .xlsm) in cui il file della cartella di lavoro è il risultato finale principale. Utilizzare per formule, formattazione, modelli finanziari, cartelle di lavoro con più fogli e pulizia tabulare esportati in Excel. Si applica anche a .csv/.tsv quando l'utente desidera l'output del foglio di calcolo. NON utilizzare per documenti Word, report HTML, script Python autonomi, pipeline di database o lavoro API di Fogli Google.
