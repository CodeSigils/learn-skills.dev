Платформа квантовых вычислений IBM. Используйте при выборе оборудования IBM Quantum, работе с Qiskit Runtime для производственных рабочих нагрузок или необходимости использования инструментов оптимизации IBM. Лучше всего подходит для аппаратного обеспечения IBM, устранения квантовых ошибок и корпоративных квантовых вычислений. Для оборудования Google используйте cirq; для квантовой МО на основе градиента используйте пеннилан; для моделирования открытой квантовой системы используйте qutip.
