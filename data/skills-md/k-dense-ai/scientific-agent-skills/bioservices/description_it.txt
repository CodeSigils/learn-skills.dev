Interfaccia Python unificata per oltre 40 servizi bioinformatici. Da utilizzare quando si eseguono query su più database (UniProt, KEGG, ChEMBL, Reactome) in un unico flusso di lavoro con API coerenti. Ideale per l'analisi tra database e la mappatura degli ID tra i servizi. Per ricerche rapide in un singolo database utilizzare gget; per la manipolazione di sequenze/file utilizzare biopython.
