Interface Python unifiée vers plus de 40 services bioinformatiques. À utiliser lors de l'interrogation de plusieurs bases de données (UniProt, KEGG, ChEMBL, Reactome) dans un seul flux de travail avec une API cohérente. Idéal pour l’analyse de bases de données croisées et le mappage d’ID entre services. Pour des recherches rapides dans une seule base de données, utilisez gget ; pour la manipulation de séquences/fichiers, utilisez biopython.
