Унифицированный интерфейс Python для более чем 40 сервисов биоинформатики. Используйте при запросе к нескольким базам данных (UniProt, KEGG, ChEMBL, Reactome) в одном рабочем процессе с согласованным API. Лучше всего подходит для анализа между базами данных и сопоставления идентификаторов между службами. Для быстрого поиска в одной базе данных используйте gget; для манипуляций с последовательностями/файлами используйте biopython.
