ابحث عن معلومات البحث الحالية باستخدام البحث المتوازي cli (بحث الويب الأساسي والسريع)، أو Parallel Chat API (بحث عميق)، أو Perplexity sonar-pro-search (عمليات البحث الورقية الأكاديمية). يقوم تلقائيًا بتوجيه الاستعلامات إلى أفضل واجهة خلفية. يُستخدم للعثور على الأوراق وجمع بيانات البحث والتحقق من المعلومات العلمية. ملاحظة: يتم إرسال نص الاستعلام إلى api.parallel.ai (PARALLEL_API_KEY)، وبالنسبة لعمليات البحث الأكاديمية، إلى openrouter.ai (OPENROUTER_API_KEY).
