Cerca informazioni sulla ricerca corrente utilizzando la ricerca CLI parallela (ricerca web primaria e veloce), l'API Parallel Chat (ricerca approfondita) o Perplexity sonar-pro-search (ricerche di documenti accademici). Instrada automaticamente le query al miglior backend. Utilizzare per trovare documenti, raccogliere dati di ricerca e verificare informazioni scientifiche. Nota: il testo della query viene trasmesso a api.parallel.ai (PARALLEL_API_KEY) e, per le ricerche accademiche, a openrouter.ai (OPENROUTER_API_KEY).
