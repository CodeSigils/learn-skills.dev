Ищите текущую исследовательскую информацию, используя поиск в параллельном интерфейсе (первичный быстрый веб-поиск), API параллельного чата (глубокие исследования) или Perplexity sonar-pro-search (поиск научных статей). Автоматически направляет запросы на лучший сервер. Используйте для поиска статей, сбора исследовательских данных и проверки научной информации. Примечание. текст запроса передается на api.parallel.ai (PARALLEL_API_KEY), а для академического поиска — на openrouter.ai (OPENROUTER_API_KEY).
