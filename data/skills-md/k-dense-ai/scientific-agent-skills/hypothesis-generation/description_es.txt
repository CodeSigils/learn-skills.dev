Formulación de hipótesis estructuradas a partir de observaciones. Úselo cuando tenga observaciones o datos experimentales y necesite formular hipótesis comprobables con predicciones, proponer mecanismos y diseñar experimentos para probarlos. Sigue el marco del método científico. Para ideas abiertas, utilice la lluvia de ideas científica; para las pruebas de hipótesis automatizadas impulsadas por LLM en conjuntos de datos, utilice hipogénico.
