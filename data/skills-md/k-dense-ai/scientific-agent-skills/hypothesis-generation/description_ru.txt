Формулирование структурированной гипотезы на основе наблюдений. Используйте его, когда у вас есть экспериментальные наблюдения или данные и вам необходимо сформулировать проверяемые гипотезы с предсказаниями, предложить механизмы и разработать эксперименты для их проверки. Следует структуре научного метода. Для открытого мышления используйте научный мозговой штурм; для автоматического тестирования гипотез на основе LLM на наборах данных используйте гипогенный.
