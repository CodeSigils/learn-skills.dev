À utiliser chaque fois que les coordonnées traversent une limite de format, d'outil ou d'assemblage - conversion entre BED, GFF/GTF, VCF, SAM/BAM, WIG, PSL, genePred, Picard interval_list ou chaînes de région ; concilier la base 0 semi-ouverte avec la base 1 inclusive ; indels alignés ou coupés à gauche ; vérifier si deux enregistrements variantes décrivent le même changement ; cartographier le génomique vers les positions de transcription, de CDS ou de protéines ; auditer un BED/GTF/VCF pour les violations de la convention ; ou diagnostiquer les problèmes GRCh37 vs hg19 vs GRCh38 vs T2T, préfixe chr et liftover.
