Senden und verwalten Sie Protokolle im Ginkgo Bioworks Cloud Lab (cloud.ginkgo.bio), einer webbasierten Schnittstelle für die autonome Laborausführung auf Reconfigurable Automation Carts (RACs). Verwenden Sie es, wenn der Benutzer eine zellfreie Proteinexpression (Validierung oder Optimierung) durchführen, fluoreszierende Pixelkunst erzeugen oder mit Ginkgo Cloud Lab-Diensten interagieren möchte. Deckt Protokollauswahl, Eingabevorbereitung, Preisgestaltung und Bestellabläufe ab.
