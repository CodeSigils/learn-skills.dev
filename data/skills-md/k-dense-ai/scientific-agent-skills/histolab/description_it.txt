Estrazione e preelaborazione di piastrelle WSI leggere. Utilizzare per l'elaborazione di base dei vetrini, il rilevamento dei tessuti, l'estrazione delle piastrelle e la normalizzazione delle macchie per le immagini H&E. Ideale per pipeline semplici, preparazione di set di dati e analisi rapide basate su riquadri. Per la proteomica spaziale avanzata, l'imaging multiplex o le pipeline di deep learning utilizzare pathml.
