Спектральное сходство и идентификация соединений для метаболомики. Используйте для сравнения масс-спектров, расчета показателей сходства (косинус, модифицированный косинус) и идентификации неизвестных соединений из спектральных библиотек. Лучше всего подходит для идентификации метаболитов, спектрального сопоставления, поиска в библиотеках. Для полных конвейеров протеомики LC-MS/MS используйте pyopenms.
