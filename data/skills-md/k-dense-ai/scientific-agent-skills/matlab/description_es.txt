Computación numérica MATLAB y GNU Octave para operaciones matriciales, análisis de datos, visualización e informática científica. Úselo al escribir scripts MATLAB/Octave para álgebra lineal, procesamiento de señales, procesamiento de imágenes, ecuaciones diferenciales, optimización, estadísticas o creación de visualizaciones científicas. Úselo también cuando el usuario necesite ayuda con la sintaxis y las funciones de MATLAB o desee realizar conversiones entre código MATLAB y Python. Los scripts se pueden ejecutar con MATLAB o el intérprete GNU Octave de código abierto.
