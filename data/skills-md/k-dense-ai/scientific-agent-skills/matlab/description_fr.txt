Calcul numérique MATLAB et GNU Octave pour les opérations matricielles, l'analyse de données, la visualisation et le calcul scientifique. À utiliser lors de l'écriture de scripts MATLAB/Octave pour l'algèbre linéaire, le traitement du signal, le traitement d'images, les équations différentielles, l'optimisation, les statistiques ou la création de visualisations scientifiques. À utiliser également lorsque l'utilisateur a besoin d'aide avec la syntaxe et les fonctions MATLAB ou souhaite effectuer une conversion entre le code MATLAB et Python. Les scripts peuvent être exécutés avec MATLAB ou l'interpréteur open source GNU Octave.
