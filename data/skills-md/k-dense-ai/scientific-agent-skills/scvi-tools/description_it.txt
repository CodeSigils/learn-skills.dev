Modelli generativi profondi per omici unicellulari. Da utilizzare quando è necessaria la correzione batch probabilistica (scVI), l'apprendimento del trasferimento, l'espressione differenziale con incertezza o l'integrazione multimodale (TOTALVI, MultiVI). Ideale per modellazione avanzata, effetti batch, dati multimodali. Per le pipeline di analisi standard utilizzare scanpy.
