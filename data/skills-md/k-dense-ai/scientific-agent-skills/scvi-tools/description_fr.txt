Modèles génératifs profonds pour les omiques unicellulaires. À utiliser lorsque vous avez besoin d'une correction probabiliste par lots (scVI), d'un apprentissage par transfert, d'une expression différentielle avec incertitude ou d'une intégration multimodale (TOTALVI, MultiVI). Idéal pour la modélisation avancée, les effets par lots et les données multimodales. Pour les pipelines d'analyse standard, utilisez scanpy.
