Kit di strumenti completo per modelli del linguaggio proteico EvolutionaryScale, tra cui ESM3 (progettazione multimodale generativa attraverso sequenza, struttura e funzione) ed ESM C (incorporamenti efficienti). Utilizzare per attività di sequenza/struttura/funzione proteica, ripiegamento inverso, incorporamenti, progettazione di varianti e previsione della struttura ESMFold2 tramite Biohub. Supporta pesi aperti locali (Python 3.12, esm su PyPI) e API cloud Forge/Biohub con autenticazione ESM_API_KEY.
