Комплексный набор инструментов для моделей белкового языка EvolutionaryScale, включая ESM3 (генеративный мультимодальный дизайн по последовательности, структуре и функциям) и ESM C (эффективное встраивание). Используйте для задач по последовательности/структуре/функции белков, обратному сворачиванию, встраиванию, вариантному дизайну и предсказанию структуры ESMFold2 через Biohub. Поддерживает локальные открытые веса (Python 3.12, esm на PyPI) и облачные API Forge/Biohub с аутентификацией ESM_API_KEY.
