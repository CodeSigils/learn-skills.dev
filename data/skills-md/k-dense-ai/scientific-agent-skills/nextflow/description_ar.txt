قم ببناء وتشغيل وتصحيح خطوط أنابيب بيانات Nextflow ومهام سير العمل الأساسية nf من البداية إلى النهاية. استخدمه عندما يذكر المستخدم ملفات Nextflow، أو nf-core، أو .nf، أو nextflow.config، أو DSL2، أو العمليات/القنوات/المشغلين، أو أوراق العينات، أو يريد تشغيل خط أنابيب مجتمعي (على سبيل المثال nf-core/rnaseq، nf-core/sarek)، أو كتابة أو اختبار وحدة نمطية/سير عمل فرعي باستخدام اختبار nf، أو تكوين المنفذين/الحاويات (Docker، Singularity/Apptainer، Conda، Wave)، أو قياس سير العمل إلى HPC/SLURM أو السحابة (AWS Batch، Google Batch، Azure، Kubernetes)، أو تصحيح أخطاء التشغيل الفاشل/الاستئناف. تأكد من استخدام هذه المهارة لأي عمل سير عمل علمي/معلوماتية حيوية قابل للتكرار حتى إذا لم ينطق المستخدم كلمة "Nextflow"، ولتأليف خطوط الأنابيب والوحدات النمطية والتكوينات والفحص المتوافقة مع nf-core.
