Cree, ejecute y depure canalizaciones de datos de Nextflow y flujos de trabajo nf-core de principio a fin. Úselo siempre que el usuario mencione Nextflow, nf-core, archivos .nf, nextflow.config, DSL2, procesos/canales/operadores, hojas de muestra o quiera ejecutar un canal comunitario (por ejemplo, nf-core/rnaseq, nf-core/sarek), escribir o probar un módulo/subflujo de trabajo con nf-test, configurar ejecutores/contenedores (Docker, Singularity/Apptainer, Conda, Wave), escalar. un flujo de trabajo a HPC/SLURM o a la nube (AWS Batch, Google Batch, Azure, Kubernetes), o depurar una ejecución fallida o reanudada. Asegúrese de utilizar esta habilidad para cualquier trabajo de flujo de trabajo científico/bioinformático reproducible, incluso si el usuario no dice la palabra "Nextflow", y para crear canalizaciones, módulos, configuraciones y linting compatibles con nf-core.
