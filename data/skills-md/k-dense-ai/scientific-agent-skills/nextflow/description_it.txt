Crea, esegui ed esegui il debug di pipeline di dati Nextflow e flussi di lavoro nf-core end-to-end. Da utilizzare ogni volta che l'utente menziona Nextflow, nf-core, file .nf, nextflow.config, DSL2, processi/canali/operatori, fogli campioni o desidera eseguire una pipeline della community (ad esempio nf-core/rnaseq, nf-core/sarek), scrivere o testare un modulo/flusso di lavoro secondario con nf-test, configurare esecutori/contenitori (Docker, Singularity/Apptainer, Conda, Wave), ridimensionare un flusso di lavoro per HPC/SLURM o cloud (AWS Batch, Google Batch, Azure, Kubernetes) o eseguire il debug di un'esecuzione non riuscita/riprendere. Assicurati di utilizzare questa competenza per qualsiasi lavoro riproducibile con flusso di lavoro scientifico/bioinformatico anche se l'utente non pronuncia la parola "Nextflow" e per creare pipeline, moduli, configurazioni e linting conformi a nf-core.
