Modal عبارة عن منصة سحابية بدون خادم لتشغيل Python عند الطلب، بما في ذلك وحدات معالجة الرسومات عند الطلب. يُستخدم عند نشر نماذج الذكاء الاصطناعي/تعلم الآلة أو تقديمها، أو تشغيل أعباء العمل المسرّعة بواسطة وحدة معالجة الرسومات (التدريب، أو الضبط الدقيق، أو الاستدلال)، أو تقديم نقاط نهاية الويب، أو جدولة المهام المجمعة، أو توسيع نطاق كود Python إلى الحاويات السحابية باستخدام Modal SDK.
