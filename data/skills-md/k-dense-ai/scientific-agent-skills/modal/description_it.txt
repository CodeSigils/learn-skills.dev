Modal è una piattaforma cloud serverless per l'esecuzione di Python on demand, incluse GPU on demand. Da utilizzare durante la distribuzione o la fornitura di modelli AI/ML, l'esecuzione di carichi di lavoro accelerati da GPU (addestramento, messa a punto, inferenza), la fornitura di endpoint Web, la pianificazione di processi batch o il ridimensionamento del codice Python su contenitori cloud con Modal SDK.
