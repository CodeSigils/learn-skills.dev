Modal es una plataforma en la nube sin servidor para ejecutar Python bajo demanda, incluidas las GPU bajo demanda. Úselo al implementar o servir modelos de IA/ML, ejecutar cargas de trabajo aceleradas por GPU (entrenamiento, ajuste, inferencia), servir puntos finales web, programar trabajos por lotes o escalar código Python a contenedores en la nube con Modal SDK.
