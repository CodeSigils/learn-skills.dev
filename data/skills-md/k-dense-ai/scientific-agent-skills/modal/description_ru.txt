Modal — это бессерверная облачная платформа для запуска Python по требованию, включая графические процессоры по требованию. Используйте при развертывании или обслуживании моделей AI/ML, выполнении рабочих нагрузок с ускорением на графическом процессоре (обучение, точная настройка, вывод), обслуживании конечных веб-точек, планировании пакетных заданий или масштабировании кода Python в облачные контейнеры с помощью Modal SDK.
