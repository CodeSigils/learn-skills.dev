استخراج الأنماط المعرفية وبصمات التفكير من أي نص. استخدم هذه المهارة عندما يريد المستخدم تحليل كيفية تفكير شخص ما، أو فهم الأسلوب المعرفي، أو كتابة الملف الشخصي أو أنماط الكلام، أو مقارنة أنماط التفكير بين الأشخاص، أو السؤال "ما هو أسلوب تفكيري"، أو "تحليل كيفية تفكير هذا الشخص"، أو "الملف المعرفي"، أو "نمط التفكير"، أو "DHDNA"، أو "الحمض النووي الرقمي"، أو يريد فهم العقل وراء أي نص. يتم تشغيله أيضًا عندما يقدم المستخدم نصًا ويريد رؤية أعمق لأنماط تفكير المؤلف أو أسلوب اتخاذ القرار أو التوقيع المعرفي.
