Запросите и загрузите общедоступные данные изображений рака из NCI Imaging Data Commons с помощью idc-index. Используйте для доступа к крупномасштабным наборам радиологических данных (КТ, МРТ, ПЭТ) и патологий для обучения или исследований ИИ. Никакой аутентификации не требуется. Запрос по метаданным, визуализация в браузере, проверка лицензий.
