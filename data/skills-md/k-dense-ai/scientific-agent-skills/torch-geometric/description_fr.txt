PyTorch Géométrique (PyG) pour les réseaux de neurones graphiques — classification de nœuds/liens/graphes, transmission de messages (GCN, GAT, GraphSAGE, GIN), graphiques hétérogènes, échantillonnage de voisins et ensembles de données personnalisés. À utiliser lorsque vous travaillez avec torch_geometric, pas pour les analyses générales NetworkX ou les modèles PyTorch non graphiques.
