Redes neuronales gráficas nativas de PyTorch para moléculas y proteínas. Úselo al crear arquitecturas GNN personalizadas para el descubrimiento de fármacos, el modelado de proteínas o el razonamiento de gráficos de conocimiento. Lo mejor para el desarrollo de modelos personalizados, predicción de propiedades de proteínas y retrosíntesis. Para modelos previamente entrenados y diversos caracterizadores, utilice deepchem; para conjuntos de datos de referencia utilice pytdc.
