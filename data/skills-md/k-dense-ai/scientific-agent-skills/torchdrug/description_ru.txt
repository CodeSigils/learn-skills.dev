Нативные графовые нейронные сети PyTorch для молекул и белков. Используйте при создании пользовательских архитектур GNN для открытия лекарств, моделирования белков или построения графов знаний. Лучше всего подходит для разработки индивидуальных моделей, прогнозирования свойств белков и ретросинтеза. Для предварительно обученных моделей и разнообразных функций используйте deepchem; для контрольных наборов данных используйте pytdc.
