التفاعل مع مكتبات إدارة المراجع Zotero باستخدام عميل pyzotero Python. يمكنك استرداد العناصر والمجموعات والعلامات والمرفقات وإنشائها وتحديثها وحذفها عبر Zotero Web API v3. استخدم هذه المهارة عند العمل مع مكتبات Zotero برمجيًا، أو إدارة المراجع الببليوغرافية، أو تصدير الاستشهادات، أو البحث في محتويات المكتبة، أو تحميل مرفقات PDF، أو إنشاء سير عمل لأتمتة البحث يتكامل مع Zotero.
