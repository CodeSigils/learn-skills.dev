Interactúe con las bibliotecas de gestión de referencias de Zotero utilizando el cliente pyzotero Python. Recupere, cree, actualice y elimine elementos, colecciones, etiquetas y archivos adjuntos a través de Zotero Web API v3. Utilice esta habilidad cuando trabaje con bibliotecas de Zotero mediante programación, administre referencias bibliográficas, exporte citas, busque contenidos de bibliotecas, cargue archivos adjuntos en PDF o cree flujos de trabajo de automatización de investigación que se integren con Zotero.
