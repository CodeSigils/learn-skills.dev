Взаимодействуйте с библиотеками управления ссылками Zotero с помощью клиента Python pyzotero. Извлекайте, создавайте, обновляйте и удаляйте элементы, коллекции, теги и вложения через Zotero Web API v3. Используйте этот навык при программной работе с библиотеками Zotero, управлении библиографическими ссылками, экспорте цитат, поиске по содержимому библиотеки, загрузке PDF-вложений или создании рабочих процессов автоматизации исследований, интегрируемых с Zotero.
