Interagisci con le librerie di gestione dei riferimenti Zotero utilizzando il client Python pyzotero. Recupera, crea, aggiorna ed elimina elementi, raccolte, tag e allegati tramite Zotero Web API v3. Utilizza questa competenza quando lavori con le librerie Zotero in modo programmatico, gestendo riferimenti bibliografici, esportando citazioni, cercando contenuti di librerie, caricando allegati PDF o creando flussi di lavoro di automazione della ricerca che si integrano con Zotero.
