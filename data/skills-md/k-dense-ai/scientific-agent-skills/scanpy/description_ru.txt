Стандартный конвейер анализа одноклеточной РНК-секвенирования. Используйте для контроля качества, нормализации, уменьшения размерности (PCA/UMAP/t-SNE), кластеризации, дифференциального выражения и визуализации. Лучше всего подходит для исследовательского анализа scRNA-seq с устоявшимися рабочими процессами. Для моделей глубокого обучения используйте scvi-инструменты; для вопросов о формате данных используйте anndata.
