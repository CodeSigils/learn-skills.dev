Pipeline standard d’analyse de séquençage d’ARN unicellulaire. Utilisation pour le contrôle qualité, la normalisation, la réduction de dimensionnalité (PCA/UMAP/t-SNE), le clustering, l'expression différentielle et la visualisation. Idéal pour l’analyse exploratoire scRNA-seq avec des flux de travail établis. Pour les modèles d'apprentissage en profondeur, utilisez les outils scvi ; pour les questions sur le format des données, utilisez Anndata.
