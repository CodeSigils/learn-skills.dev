Tubería de análisis estándar de secuencia de ARN unicelular. Úselo para control de calidad, normalización, reducción de dimensionalidad (PCA/UMAP/t-SNE), agrupación, expresión diferencial y visualización. Lo mejor para el análisis exploratorio de scRNA-seq con flujos de trabajo establecidos. Para modelos de aprendizaje profundo, utilice scvi-tools; para preguntas sobre formato de datos utilice anndata.
