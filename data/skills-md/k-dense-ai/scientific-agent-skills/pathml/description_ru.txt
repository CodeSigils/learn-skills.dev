Полнофункциональный набор инструментов вычислительной патологии. Используйте для расширенного анализа WSI, включая мультиплексную иммунофлуоресценцию (CODEX, Vectra), сегментацию ядер, построение графов тканей и обучение модели ML на данных о патологии. Поддерживает более 160 форматов слайдов. Для простого извлечения плиток из слайдов H&E использование histolab может быть проще.
