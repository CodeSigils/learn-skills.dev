Hugging Science es un catálogo curado de conjuntos de datos científicos, modelos, publicaciones de blogs y espacios interactivos. Esta habilidad ayuda a descubrir y utilizar recursos a través de "conjuntos de datos", "transformadores", la API de inferencia HF, "gradio_client" y citas de metodología.
