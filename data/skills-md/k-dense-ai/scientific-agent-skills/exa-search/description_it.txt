Toolkit web fornito da Exa, ottimizzato per contenuti scientifici e tecnici. Utilizza questa capacità quando l'utente deve effettuare ricerche sul Web o recuperare/estrarre contenuti URL. Copre: ricerca web (ricerche semantiche, ricerche, informazioni attuali - con categoria opzionale di articoli di ricerca e filtro del dominio accademico) ed estrazione URL (recupero di pagine, articoli, PDF accademici in batch). Utilizza questa capacità per attività relative al Web quando l'utente desidera una ricerca di alta qualità o un filtraggio accademico tramite Category=Research Paper. Attiva le richieste di ricerca, ricerca, recupero di una pagina o estrazione di un articolo.
