Exa を利用した Web ツールキット。科学および技術コンテンツ向けに調整されています。ユーザーが Web を検索したり、URL コンテンツをフェッチ/抽出する必要がある場合は、このスキルを使用します。対象範囲: Web 検索 (セマンティック ルックアップ、研究、最新情報 - オプションの研究論文カテゴリおよび学術ドメイン フィルタリング付き) および URL 抽出 (ページ、論文、学術 PDF をバッチで取得)。ユーザーがカテゴリ=研究論文による高品質の検索または学術的なフィルタリングを必要とする場合は、Web 関連タスクにこのスキルを使用します。検索、ルックアップ、ページの取得、または記事の抽出のリクエストをトリガーします。
