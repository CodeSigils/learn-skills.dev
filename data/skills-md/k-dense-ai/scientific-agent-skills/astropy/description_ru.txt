Базовая библиотека Python для рабочих процессов астрономии и астрофизики, которым требуются API-интерфейсы Astropy, включая единицы измерения/величины, координаты, ввод-вывод FITS, таблицы, системы времени, WCS и космологию. Используйте при реализации или отладке кода анализа астрономических данных с помощью Astropy.
