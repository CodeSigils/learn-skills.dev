Bibliothèque Python de base pour les flux de travail d'astronomie et d'astrophysique nécessitant des API Astropy, y compris les unités/quantités, les coordonnées, les E/S FITS, les tables, les systèmes temporels, les WCS et la cosmologie. À utiliser lors de l'implémentation ou du débogage du code d'analyse de données astronomiques avec Astropy.
