Kern-Python-Bibliothek für Arbeitsabläufe in der Astronomie und Astrophysik, die Astropy-APIs benötigen, einschließlich Einheiten/Mengen, Koordinaten, FITS-I/O, Tabellen, Zeitsysteme, WCS und Kosmologie. Wird zum Implementieren oder Debuggen von Code zur Analyse astronomischer Daten mit Astropy verwendet.
