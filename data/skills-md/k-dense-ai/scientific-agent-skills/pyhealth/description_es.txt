Cree canales de aprendizaje profundo clínico/sanitario con PyHealth: cargue conjuntos de datos de EHR/señales/imágenes (MIMIC-III/IV, eICU, OMOP, SleepEDF, ChestXray14, EHRShot), defina tareas (mortalidad, reingreso, duración de la estadía, recomendación de medicamentos, estadificación del sueño, codificación ICD, eventos de EEG), creación de instancias de modelos (Transformer, RETAIN, GAMENet, SafeDrug, MICRON, StageNet, AdaCare, CNN/RNN/MLP), capacitación con PyHealth Trainer, cálculo de métricas clínicas y uso de utilidades de códigos médicos (ICD/ATC/NDC/RxNorm búsqueda y mapeo cruzado). Utilice esta habilidad siempre que el usuario mencione PyHealth, MIMIC, eICU, OMOP, modelado EHR, predicción clínica, recomendación de medicamentos, estadificación del sueño, mapeo de códigos médicos, códigos ICD/ATC o cualquier canal de ML de atención médica que se ajuste al conjunto de datos → tarea → modelo → entrenador → patrón de métricas, incluso si "PyHealth" no se nombra explícitamente.
