Costruisci pipeline di deep learning clinico/sanitario con PyHealth: caricamento di set di dati EHR/segnali/imaging (MIMIC-III/IV, eICU, OMOP, SleepEDF, ChestXray14, EHRShot), definizione di attività (mortalità, riammissione, durata del ricovero, raccomandazione sui farmaci, stadiazione del sonno, codifica ICD, eventi EEG), creazione di istanze di modelli (Transformer, RETAIN, GAMENet, SafeDrug, MICRON, StageNet, AdaCare, CNN/RNN/MLP), formazione con PyHealth Trainer, calcolo di metriche cliniche e utilizzo di utilità di codici medici (ricerca ICD/ATC/NDC/RxNorm e mappatura incrociata). Utilizza questa competenza ogni volta che l'utente menziona PyHealth, MIMIC, eICU, OMOP, modellazione EHR, previsione clinica, raccomandazione di farmaci, stadiazione del sonno, mappatura di codici medici, codici ICD/ATC o qualsiasi pipeline di ML sanitario che si adatti al set di dati → attività → modello → formatore → modello di metrica, anche se "PyHealth" non è nominato esplicitamente.
