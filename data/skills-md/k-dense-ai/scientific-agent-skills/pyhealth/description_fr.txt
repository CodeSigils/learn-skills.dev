Créez des pipelines d'apprentissage profond clinique/soins de santé avec PyHealth : chargement d'ensembles de données DSE/signal/imagerie (MIMIC-III/IV, eICU, OMOP, SleepEDF, ChestXray14, EHRShot), définition de tâches (mortalité, réadmission, durée de séjour, recommandation de médicaments, stadification du sommeil, codage ICD, événements EEG), instanciation de modèles (Transformer, RETAIN, GAMENet, SafeDrug, MICRON, StageNet, AdaCare, CNN/RNN/MLP), formation avec PyHealth Trainer, calcul de métriques cliniques et utilisation d'utilitaires de code médical (recherche et cartographie croisée ICD/ATC/NDC/RxNorm). Utilisez cette compétence chaque fois que l'utilisateur mentionne PyHealth, MIMIC, eICU, OMOP, la modélisation DSE, la prédiction clinique, la recommandation de médicaments, la stadification du sommeil, le mappage de codes médicaux, les codes ICD/ATC ou tout pipeline ML de soins de santé qui correspond à l'ensemble de données → tâche → modèle → entraîneur → modèle de métriques, même si « PyHealth » n'est pas nommé explicitement.
