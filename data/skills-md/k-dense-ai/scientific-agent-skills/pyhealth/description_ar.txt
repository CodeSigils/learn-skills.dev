قم ببناء مسارات التعلم العميق للرعاية الصحية/السريرية باستخدام PyHealth - تحميل مجموعات بيانات السجل الصحي الإلكتروني/الإشارة/التصوير (MIMIC-III/IV، eICU، OMOP، SleepEDF، ChestXray14، EHRShot)، تحديد المهام (الوفيات، إعادة القبول، مدة الإقامة، توصية الدواء، مرحلة النوم، ترميز ICD، أحداث EEG)، إنشاء نماذج (Transformer، RETAIN، GAMENet، SafeDrug، وMICRON، وStageNet، وAdaCare، وCNN/RNN/MLP)، والتدريب باستخدام PyHealth Trainer، وحوسبة المقاييس السريرية، واستخدام الأدوات المساعدة للرموز الطبية (بحث ICD/ATC/NDC/RxNorm ورسم الخرائط المتقاطعة). استخدم هذه المهارة عندما يذكر المستخدم PyHealth، أو MIMIC، أو eICU، أو OMOP، أو نمذجة EHR، أو التنبؤ السريري، أو توصية الدواء، أو مراحل النوم، أو تعيين الكود الطبي، أو رموز ICD/ATC، أو أي خط أنابيب ML للرعاية الصحية يناسب مجموعة البيانات → المهمة → النموذج → المدرب → نمط المقاييس، حتى لو لم يتم تسمية "PyHealth" بشكل صريح.
