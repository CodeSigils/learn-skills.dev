Génération et test automatisés d'hypothèses basés sur LLM sur des ensembles de données tabulaires. À utiliser lorsque vous souhaitez explorer systématiquement des hypothèses sur des modèles dans des données empiriques (par exemple, détection de tromperie, analyse de contenu). Combine des informations sur la littérature avec des tests d'hypothèses basés sur des données. Pour la formulation manuelle d’hypothèses, utilisez la génération d’hypothèses ; pour une idéation créative, utilisez le brainstorming scientifique.
