Accelera il codice Python tramite GPU utilizzando CuPy, Numba CUDA, Warp, cuDF, cuML, cuGraph, KvikIO, cuCIM, cuxfilter, cuVS, cuSpatial e RAFT. Da utilizzare ogni volta che l'utente menziona l'accelerazione GPU/CUDA/NVIDIA o desidera accelerare i carichi di lavoro NumPy, pandas, scikit-learn, scikit-image, NetworkX, GeoPandas o Faiss. Copre simulazione fisica, rendering differenziabile, mesh ray casting, sistemi di particelle (DEM/SPH/fluidi), ricerca di vettori/somiglianze, IO di file di archiviazione GPUDirect, dashboard interattivi, analisi geospaziale, imaging medico e autosolutori sparsi. Da utilizzare anche quando vedi codice Python associato alla CPU (loop, array di grandi dimensioni, pipeline ML, analisi di grafici, elaborazione di immagini) che trarrebbe vantaggio dall'accelerazione GPU, anche se non esplicitamente richiesto.
