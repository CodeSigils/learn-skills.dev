تسريع كود Python باستخدام GPU، وNumba CUDA، وWarp، وcuDF، وcuML، وcuGraph، وKvikIO، وcuCIM، وcuxfilter، وcuVS، وcuSpatial، وRAFT. يُستخدم عندما يذكر المستخدم تسريع GPU/CUDA/NVIDIA، أو يريد تسريع أحمال عمل NumPy أو pandas أو scikit-learn أو scikit-image أو NetworkX أو GeoPandas أو Faiss. يغطي محاكاة الفيزياء، والعرض التفاضلي، وصب الأشعة الشبكية، وأنظمة الجسيمات (DEM/SPH/السوائل)، والبحث عن المتجهات/التشابه، وملف التخزين GPUDirect IO، ولوحات المعلومات التفاعلية، والتحليل الجغرافي المكاني، والتصوير الطبي، والمحللات الذاتية المتفرقة. استخدمه أيضًا عندما ترى كود Python المرتبط بوحدة المعالجة المركزية (الحلقات، والمصفوفات الكبيرة، وخطوط تعلم الآلة، وتحليلات الرسوم البيانية، ومعالجة الصور) التي قد تستفيد من تسريع وحدة معالجة الرسومات، حتى لو لم يتم طلبها صراحةً.
