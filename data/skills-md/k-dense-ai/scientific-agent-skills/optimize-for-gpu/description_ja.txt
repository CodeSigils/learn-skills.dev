CuPy、Numba CUDA、Warp、cuDF、cuML、cuGraph、KvikIO、cuCIM、cuxfilter、cuVS、cuSpatial、RAFT を使用して Python コードを GPU アクセラレーションします。ユーザーが GPU/CUDA/NVIDIA アクセラレーションについて言及する場合、または NumPy、pandas、scikit-learn、scikit-image、NetworkX、GeoPandas、または Faiss ワークロードを高速化したい場合に使用します。物理シミュレーション、微分可能レンダリング、メッシュ レイ キャスティング、粒子システム (DEM/SPH/流体)、ベクトル/類似性検索、GPUDirect ストレージ ファイル IO、インタラクティブ ダッシュボード、地理空間解析、医療画像処理、およびスパース固有ソルバーをカバーします。また、明示的に要求されていない場合でも、GPU アクセラレーションの恩恵を受ける CPU バウンドの Python コード (ループ、大規模な配列、ML パイプライン、グラフ分析、画像処理) を確認した場合にも使用します。
