使用 CuPy、Numba CUDA、Warp、cuDF、cuML、cuGraph、KvikIO、cuCIM、cuxfilter、cuVS、cuSpatial 和 RAFT 對 Python 程式碼進行 GPU 加速。每當使用者提到 GPU/CUDA/NVIDIA 加速，或想要加速 NumPy、pandas、scikit-learn、scikit-image、NetworkX、GeoPandas 或 Faiss 工作負載時使用。涵蓋物理模擬、可微渲染、網格光線投射、粒子系統（DEM/SPH/流體）、向量/相似性搜尋、GPUDirect Storage 檔案 IO、互動式儀表板、地理空間分析、醫學成像和稀疏特徵求解器。當您看到 CPU 密集型 Python 程式碼（循環、大型陣列、機器學習管道、圖形分析、映像處理）時，即使沒有明確請求，也可以使用這些程式碼，這些程式碼將受益於 GPU 加速。
