Code Python accéléré par GPU à l'aide de CuPy, Numba CUDA, Warp, cuDF, cuML, cuGraph, KvikIO, cuCIM, cuxfilter, cuVS, cuSpatial et RAFT. À utiliser chaque fois que l'utilisateur mentionne l'accélération GPU/CUDA/NVIDIA ou souhaite accélérer les charges de travail NumPy, pandas, scikit-learn, scikit-image, NetworkX, GeoPandas ou Faiss. Couvre la simulation physique, le rendu différenciable, la diffusion de rayons maillés, les systèmes de particules (DEM/SPH/fluides), la recherche de vecteurs/similitudes, les E/S de fichiers de stockage GPUDirect, les tableaux de bord interactifs, l'analyse géospatiale, l'imagerie médicale et les solveurs propres clairsemés. À utiliser également lorsque vous voyez du code Python lié au processeur (boucles, grands tableaux, pipelines ML, analyses de graphiques, traitement d'images) qui bénéficierait de l'accélération GPU, même s'il n'est pas explicitement demandé.
