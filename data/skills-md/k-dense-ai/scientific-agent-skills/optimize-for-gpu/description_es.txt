Código Python con aceleración de GPU mediante CuPy, Numba CUDA, Warp, cuDF, cuML, cuGraph, KvikIO, cuCIM, cuxfilter, cuVS, cuSpatial y RAFT. Úselo siempre que el usuario mencione la aceleración GPU/CUDA/NVIDIA o quiera acelerar las cargas de trabajo de NumPy, pandas, scikit-learn, scikit-image, NetworkX, GeoPandas o Faiss. Cubre simulación física, renderizado diferenciable, fundición de rayos de malla, sistemas de partículas (DEM/SPH/fluidos), búsqueda de vectores/similitudes, E/S de archivos de almacenamiento GPUDirect, paneles interactivos, análisis geoespacial, imágenes médicas y solucionadores propios dispersos. Úselo también cuando vea código Python vinculado a la CPU (bucles, matrices grandes, canalizaciones de aprendizaje automático, análisis de gráficos, procesamiento de imágenes) que se beneficiaría de la aceleración de la GPU, incluso si no se solicita explícitamente.
