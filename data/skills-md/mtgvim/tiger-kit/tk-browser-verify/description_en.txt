Used when checking the UI accuracy or interactions of actual pages in a browser. Temporary HTML, prototype, layout, hover, and form exploration is performed in Guard mode to preemptively prevent traps, while source changes visible to the user, explicit calls, and official judgment requests are handled in Verdict mode to verify runtime evidence. It is not automatically applied to passive web research, document reading, URL content extraction, or simple screenshot saving. It does not take ownership of source mutation nor replace sufficient static verification without a browser.
