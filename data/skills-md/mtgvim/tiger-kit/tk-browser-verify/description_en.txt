It is used to verify the UI accuracy and interactions of an actual page in a browser. Temporary HTML, prototype, layout, hover, and form exploration are handled in Guard mode to proactively prevent traps, while source changes visible to the user, explicit calls, and official judgment requests are processed in Verdict mode to validate runtime evidence. It is not applied automatically to passive web research, document reading, URL content extraction, or simple screenshot saving. It does not own source mutation nor replace sufficient static verification without a browser.
