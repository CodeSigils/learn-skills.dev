Se utiliza para verificar la precisión de la interfaz de usuario y las interacciones de una página real en un navegador. El HTML temporal, el prototipo, el diseño, el desplazamiento y la exploración de formularios se manejan en el modo Guardia para evitar trampas de manera proactiva, mientras que los cambios de fuente visibles para el usuario, las llamadas explícitas y las solicitudes de juicio oficiales se procesan en el modo Veredicto para validar la evidencia en tiempo de ejecución. No se aplica automáticamente a la investigación web pasiva, la lectura de documentos, la extracción de contenido de URL o el simple almacenamiento de capturas de pantalla. No posee mutación de fuente ni reemplaza una verificación estática suficiente sin un navegador.
