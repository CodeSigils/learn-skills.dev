GitHub プル リクエストをマージするまで引き継ぎ、採用、またはベビーシッターするよう求められた場合に使用します。レビューのフィードバックを読み、修正し、スレッドを解決し、不当な変更リクエストを却下し、承認されグリーンになったらマージします。 PR をこのセッションでライブで駆動するか、無人のバックグラウンド実行のために Looper デーモンに渡して、不明瞭な場合はユーザーに確認するかを選択します。 「この PR を引き継ぐ」、「接管这个 PR」、「持续修复レビュー直到合并」、または Looper 引き継ぎボットのコメントでトリガーされます。 gh + git を使用する任意のコーディング エージェント (Claude Code、Codex、opencode、Gemini など) で動作します。
