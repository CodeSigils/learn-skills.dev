À utiliser lorsqu'on vous demande de reprendre, d'adopter ou de garder une demande d'extraction GitHub jusqu'à ce qu'elle fusionne : lisez les commentaires de révision, corrigez-les, résolvez les fils de discussion, rejetez les demandes de modification déraisonnables et fusionnez une fois approuvées et vertes. Choisissez entre piloter le PR en direct dans cette session ou le transmettre au démon Looper pour des exécutions en arrière-plan sans surveillance, en confirmant avec l'utilisateur en cas de doute. Se déclenche sur « reprendre ce PR », « 接管这个 PR », « 持续修复 review 直到合并 » ou sur un commentaire de robot de prise de contrôle Looper. Fonctionne dans n'importe quel agent de codage (Claude Code, Codex, opencode, Gemini, …) en utilisant gh + git.
