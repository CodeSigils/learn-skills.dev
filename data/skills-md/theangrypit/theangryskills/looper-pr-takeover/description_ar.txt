استخدمه عندما يُطلب منك تولي طلب سحب GitHub أو تبنيه أو مراقبته حتى يتم دمجه - اقرأ تعليقات المراجعة، وقم بإصلاحها، وحل سلاسل الرسائل، ورفض طلبات التغيير غير المعقولة، والدمج بمجرد الموافقة عليها وتحويلها إلى اللون الأخضر. يمكنك الاختيار بين قيادة العلاقات العامة مباشرة في هذه الجلسة أو تسليمها إلى البرنامج الخفي Looper للتشغيل في الخلفية دون مراقبة، مع التأكيد مع المستخدم عندما يكون الأمر غير واضح. مشغلات "تولي هذه العلاقات العامة" أو "接管这个 PR" أو "مراجعة 持续修复 直到合并" أو تعليق روبوت استحواذ Looper. يعمل في أي وكيل تشفير (Claude Code، Codex، opencode، Gemini، …) باستخدام gh + git.
