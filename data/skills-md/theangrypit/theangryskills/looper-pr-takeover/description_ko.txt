병합될 때까지 GitHub 풀 요청을 인계, 채택 또는 관리하라는 요청을 받을 때 사용합니다. 리뷰 피드백을 읽고, 수정하고, 스레드를 해결하고, 불합리한 변경 요청을 취소하고, 승인되어 녹색이 되면 병합합니다. 이 세션에서 PR을 실시간으로 구동하거나 무인 백그라운드 실행을 위해 Looper 데몬에 전달하는 것 중에서 선택하여 불분명한 경우 사용자에게 확인합니다. "이 PR 인수", "接管这个 PR", "持续修复 검토 直到合并" 또는 Looper 인수 봇 댓글을 트리거합니다. gh + git을 사용하여 모든 코딩 에이전트(Claude Code, Codex, opencode, Gemini 등)에서 작동합니다.
