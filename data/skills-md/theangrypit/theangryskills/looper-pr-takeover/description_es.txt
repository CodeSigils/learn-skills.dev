Úselo cuando se le solicite hacerse cargo, adoptar o cuidar una solicitud de extracción de GitHub hasta que se fusione: lea los comentarios de revisión, corríjalos, resuelva hilos, descarte solicitudes de cambios no razonables y fusione una vez aprobada y en verde. Elige entre conducir el PR en vivo en esta sesión o entregárselo al demonio Looper para ejecuciones en segundo plano desatendidas, confirmando con el usuario cuando no esté claro. Activadores al "hacerse cargo de este PR", "接管这个 PR", "持续修复 revisar 直到合并" o un comentario del bot de adquisición de Looper. Funciona en cualquier agente de codificación (Claude Code, Codex, opencode, Gemini,…) usando gh + git.
