Libreria di abbonamenti WebSocket indipendenti dai tipi per Node/TS, complementare a typesafe-rpc. Definisce WsSchema (gestore entità/operazione/sottoscrizione), createWsHandler (server), createWsServer (handle push di connessione incrociata digitato per altro codice back-end), createWsClient (client), percorso e middleware per le sottoscrizioni. Da utilizzare durante la modifica di typesafe-ws, l'aggiunta di operazioni di sottoscrizione, il collegamento di un server o client WebSocket, l'inserimento di dati nelle sottoscrizioni dall'esterno di un gestore o l'implementazione di gestori e middleware di sottoscrizione in questo repository.
