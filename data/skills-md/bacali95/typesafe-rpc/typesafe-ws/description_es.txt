Biblioteca de suscripciones WebSocket con seguridad de tipos para Node/TS, complementaria de typesafe-rpc. Define WsSchema (entidad/operación/controlador de suscripción), createWsHandler (servidor), createWsServer (controlador de inserción de conexión cruzada escrito para otro código de backend), createWsClient (cliente), Ruta y middlewares para suscripciones. Úselo al editar typesafe-ws, agregar operaciones de suscripción, conectar un servidor o cliente WebSocket, insertar datos en suscripciones desde fuera de un controlador o implementar controladores de suscripción y middlewares en este repositorio.
