使用 Cog 打包和建置自訂 AI 模型，以便在 Replicate 上部署。在以下情況下使用：建立 cog.yaml 或 Predict.py、定義模型輸入和輸出、在設定時載入模型權重、為 ML 模型建立 Docker 映像、使用 cogserve 或 cogpredict 在本機提供服務，或移植 HuggingFace、GitHub 或 ComfyUI 模型以在 Replicate 上執行。在「建立模型」、「打包模型」、「建立 Cog 模型」、「包裝模型」、「容器化 AI 模型」、「predict.py」、「cog.yaml」、「BasePredictor」或「Cog 容器」等短語以及引用 cog.run、github.com/replicate/cog 或 githubpliclescog 時觸發。涵蓋 GPU 和 CUDA 設定、用於快速權重下載的 pget、具有連續批次的非同步預測器、串流輸出以及影像、視訊、音訊和 LLM 模型的冷啟動最佳化。若要將建置的模型推送到複製，請參閱發布模型。要运行现有模型，请参阅运行模型。
