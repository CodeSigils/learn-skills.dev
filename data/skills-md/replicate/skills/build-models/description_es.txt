Empaquete y cree modelos de IA personalizados con Cog para implementarlos en Replicate. Úselo al crear un cog.yaml o predict.py, definir entradas y salidas del modelo, cargar pesos del modelo en el momento de la configuración, crear imágenes de Docker para modelos de aprendizaje automático, servir localmente con cog server o cog predict o portar un modelo HuggingFace, GitHub o ComfyUI para ejecutarlo en Replicate. Active frases como "construir un modelo", "empaquetar un modelo", "crear un modelo Cog", "envolver un modelo", "contener un modelo de IA", "predict.py", "cog.yaml", "BasePredictor" o "contenedor Cog" y al hacer referencia a cog.run, github.com/replicate/cog o github.com/replicate/cog-examples. Cubre la configuración de GPU y CUDA, pget para descargas rápidas de peso, predictores asíncronos con procesamiento por lotes continuo, salidas de transmisión y optimización de arranque en frío para modelos de imagen, video, audio y LLM. Para enviar modelos creados a Replicar, consulte publicar-modelos. Para ejecutar modelos existentes, consulte run-models.
