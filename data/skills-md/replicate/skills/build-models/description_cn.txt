使用 Cog 打包和构建自定义 AI 模型，以便在 Replicate 上部署。在以下情况下使用：创建 cog.yaml 或 Predict.py、定义模型输入和输出、在设置时加载模型权重、为 ML 模型构建 Docker 映像、使用 cogserve 或 cogpredict 在本地提供服务，或者移植 HuggingFace、GitHub 或 ComfyUI 模型以在 Replicate 上运行。在“构建模型”、“打包模型”、“创建 Cog 模型”、“包装模型”、“容器化 AI 模型”、“predict.py”、“cog.yaml”、“BasePredictor”或“Cog 容器”等短语以及引用 cog.run、github.com/replicate/cog 或 github.com/replicate/cog-examples 时触发。涵盖 GPU 和 CUDA 设置、用于快速权重下载的 pget、具有连续批处理的异步预测器、流输出以及图像、视频、音频和 LLM 模型的冷启动优化。要将构建的模型推送到复制，请参阅发布模型。要运行现有模型，请参阅运行模型。
