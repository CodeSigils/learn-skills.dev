Übertragen und veröffentlichen Sie benutzerdefinierte KI-Modelle in Replicate und richten Sie CI/CD für die sichere Veröffentlichung neuer Modellversionen ein. Verwenden Sie diese Option, wenn Sie cog push ausführen, ein Modell für Replicate bereitstellen, eine neue Version veröffentlichen, ein Modell mit cog-safe-push vor der Veröffentlichung validieren, eine Replicate-Bereitstellung konfigurieren, GitHub-Aktionen für Modellveröffentlichungen einrichten oder ein Community-Modell auf ein offizielles Modell portieren. Lösen Sie auf Phrasen wie „ein Modell zum Replizieren übertragen“, „ein Modell veröffentlichen“, „ein Modell bereitstellen“, „eine neue Version veröffentlichen“, „cog push“, „cog-safe-push“, „model CI“, „r8.im“ oder „Schemakompatibilität“ aus und wenn Sie auf github.com/replicate/cog-safe-push oder github.com/replicate/model-ci-template verweisen. Behandelt Cog Push, die vollständige Cog-Safe-Push-Konfiguration (Testfälle, Fuzz, Bereitstellung, offizielles_Modell), GitHub-Aktionsmuster, Matrix-Pushs mit mehreren Modellen und Überwachung nach der Veröffentlichung. Es wird davon ausgegangen, dass Sie bereits über ein funktionierendes Cog-Projekt verfügen. Sehen Sie sich Build-Modelle an, wenn Sie zuerst eines verpacken müssen.
