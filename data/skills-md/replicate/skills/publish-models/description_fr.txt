Poussez et publiez des modèles d'IA personnalisés vers Replicate, et configurez CI/CD pour publier de nouvelles versions de modèles en toute sécurité. À utiliser lors de l'exécution de cog push, du déploiement d'un modèle pour Replicate, de la publication d'une nouvelle version, de la validation d'un modèle avec cog-safe-push avant la publication, de la configuration d'un déploiement Replicate, de la configuration des actions GitHub pour les versions de modèle ou du portage d'un modèle communautaire vers un modèle officiel. Déclenchez des expressions telles que « pousser un modèle à répliquer », « publier un modèle », « déployer un modèle », « publier une nouvelle version », « cog push », « cog-safe-push », « model CI », « r8.im » ou « compatibilité de schéma », et lors de la référence à github.com/replicate/cog-safe-push ou github.com/replicate/model-ci-template. Couvre le cog push, la configuration complète cog-safe-push (cas de test, fuzz, déploiement, official_model), les modèles d'actions GitHub, les push matriciels multi-modèles et la surveillance post-publication. Suppose que vous avez déjà un projet Cog fonctionnel ; consultez les modèles de construction si vous devez d'abord en emballer un.
