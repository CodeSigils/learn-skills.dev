ادفع نماذج الذكاء الاصطناعي المخصصة وانشرها للنسخ المتماثل، وقم بإعداد CI/CD لإصدار إصدارات نماذج جديدة بأمان. يُستخدم عند تشغيل cog-safe-push، أو نشر نموذج للنسخ المتماثل، أو إطلاق إصدار جديد، أو التحقق من صحة النموذج باستخدام cog-safe-push قبل النشر، أو تكوين نشر Replicate، أو إعداد إجراءات GitHub لإصدارات النماذج، أو نقل نموذج المجتمع إلى نموذج رسمي. قم بتشغيل عبارات مثل "ادفع نموذجًا للنسخ المتماثل" أو "نشر نموذج" أو "نشر نموذج" أو "إصدار إصدار جديد" أو "دفع الترس" أو "cog-safe-push" أو "model CI" أو "r8.im" أو "توافق المخطط"، وعند الرجوع إلى github.com/replicate/cog-safe-push أو github.com/replicate/model-ci-template. يغطي الدفع المسنن، وتكوين الدفع الآمن المسنن الكامل (حالات الاختبار، والضباب، والنشر، والنموذج الرسمي)، وأنماط إجراءات GitHub، ودفعات المصفوفة متعددة النماذج، ومراقبة ما بعد النشر. بافتراض أن لديك بالفعل مشروع ترس عامل؛ راجع نماذج البناء إذا كنت بحاجة إلى حزم واحدة أولاً.
