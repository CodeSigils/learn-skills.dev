Configure de forma autónoma un bot OpenClaw en una máquina virtual Yandex Cloud nueva en Kazajstán (kz1-a, Karaganda). Solicita al usuario exactamente dos cosas: un token de bot de Telegram y una de las tres opciones de acceso a LLM (clave API Anthropic, clave API OpenRouter u OpenAI Codex OAuth a través de una suscripción ChatGPT Plus/Pro), luego maneja la creación de VM, el refuerzo, la instalación de OpenClaw, la siembra del espacio de trabajo del CEO AI OS, el emparejamiento de Telegram, la detección automática de chat_id y la verificación de respuesta de bot por sí solo. Las únicas otras acciones que realiza el usuario son presionar /iniciar en Telegram una vez y (si es Codex) confirmar un código de dispositivo en auth.openai.com. Úselo cuando el usuario diga instalar OpenClaw en Yandex Cloud, implementar OpenClaw en YC Kazajstán, configurar mi bot CEO en YC KZ, estoy en el taller de OpenClaw y necesito mi propio bot, crear una máquina virtual de Yandex Cloud para OpenClaw o cualquier paráfrasis cercana. Tiene como objetivo una ejecución de un extremo a otro de aproximadamente 15 minutos para usuarios que no son de DevOps (fundadores, directores ejecutivos, líderes de marketing). Admite dos modos de acceso a Yandex Cloud: Plan A (la propia cuenta de YC Kazajstán del usuario a través de OAuth) y Plan B (un paquete de claves de taller proporcionado por el organizador del taller, para participantes sin su propia cuenta de YC). El modo se detecta automáticamente a partir de las entradas. Para la instalación de OpenClaw en la máquina local, utilice openclaw/install.sh en este repositorio. Se requiere la habilidad complementaria openclaw-guide; prepare-yc-workshop es la habilidad correspondiente del lado del organizador que produce los paquetes consumidos en el Plan B; openclaw-user-onboarding se invoca automáticamente después del Paso 5 para recopilar los cinco datos básicos sobre el usuario (identidad, enfoque, estilo, herramientas, antipatrones) y escribirlos en USER.md para que el bot sea útil desde el mensaje uno.
