在哈萨克斯坦（kz1-a，卡拉干达）的新 Yandex Cloud 虚拟机上自主设置 OpenClaw 机器人。要求用户提供两件事——Telegram 机器人令牌和三个 LLM 访问选项之一（Anthropic API 密钥、OpenRouter API 密钥或通过 ChatGPT Plus/Pro 订阅的 OpenAI Codex OAuth）——然后自行处理 VM 创建、强化、OpenClaw 安装、CEO AI OS 工作区播种、Telegram 配对、chat_id 自动检测和机器人回复验证。用户执行的唯一其他操作是在 Telegram 中按 /start 一次，以及（如果是 Codex）在 auth.openai.com 上确认设备代码。当用户说将 OpenClaw 安装到 Yandex Cloud、将 OpenClaw 部署到 YC Kazakhstan、在 YC KZ 中设置我的 CEO 机器人、我在 OpenClaw 研讨会并需要我自己的机器人、为 OpenClaw 创建 Yandex Cloud VM 或任何接近的释义时使用。目标是为非 DevOps 用户（创始人、首席执行官、营销主管）进行约 15 分钟的端到端运行。支持两种访问 Yandex Cloud 的模式 - 计划 A（用户通过 OAuth 拥有自己的 YC 哈萨克斯坦帐户）和计划 B（研讨会组织者为没有自己的 YC 帐户的参与者提供的研讨会密钥捆绑包）。该模式是根据输入自动检测的。对于本地计算机 OpenClaw 安装，请使用此存储库中的 openclaw/install.sh。需要同伴技能openclaw-guide； prepare-yc-workshop 是匹配的组织者端技能，用于生成 B 计划中消耗的捆绑包； openclaw-user-onboarding 在第 5 步之后自动调用，以收集有关用户的五个基本事实（身份、焦点、风格、工具、反模式）并将其写入 USER.md，以便机器人在消息一中发挥作用。
