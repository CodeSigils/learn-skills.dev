Автономно настройте бота OpenClaw на свежей виртуальной машине Yandex Cloud в Казахстане (kz1-a, Караганда). Запрашивает у пользователя ровно две вещи — токен бота Telegram и один из трех вариантов доступа к LLM (ключ API Anthropic, ключ API OpenRouter или OpenAI Codex OAuth через подписку ChatGPT Plus/Pro) — затем самостоятельно обрабатывает создание виртуальной машины, усиление защиты, установку OpenClaw, заполнение рабочего пространства ОС CEO AI, сопряжение Telegram, автоматическое определение Chat_id и проверку ответов бота. Единственные другие действия, которые выполняет пользователь, — это однократное нажатие /start в Telegram и (если Codex) подтверждение кода устройства на auth.openai.com. Используйте, когда пользователь говорит: установите OpenClaw в Yandex Cloud, разверните OpenClaw в YC Казахстан, настройте моего генерального бота в YC KZ, я нахожусь в мастерской OpenClaw и мне нужен собственный бот, создайте виртуальную машину Yandex Cloud для OpenClaw или любой другой близкий перефраз. Ориентирован на 15-минутное сквозное тестирование для пользователей, не связанных с DevOps (основателей, генеральных директоров, руководителей отдела маркетинга). Поддерживает два режима доступа к Yandex Cloud — План А (собственная учетная запись пользователя YC Казахстан через OAuth) и План Б (пакет ключей для семинара, предоставляемый организатором семинара, для участников без собственной учетной записи YC). Режим автоматически определяется по входам. Для установки OpenClaw на локальном компьютере вместо этого используйте openclaw/install.sh в этом репозитории. Требуется навык компаньона openclaw-guide; Подготовка-yc-workshop — это соответствующий навык на стороне организатора, который создает пакеты, используемые в Плане Б; openclaw-user-onboarding автоматически вызывается после шага 5, чтобы собрать пять основных фактов о пользователе (личность, фокус, стиль, инструменты, антишаблоны) и записать их в USER.md, чтобы бот был полезен с первого сообщения.
