카자흐스탄의 새로운 Yandex Cloud VM(kz1-a, Karaganda)에 OpenClaw 봇을 자동으로 설정합니다. 사용자에게 정확하게 두 가지(Telegram 봇 토큰 및 세 가지 LLM 액세스 옵션(Anthropic API 키, OpenRouter API 키 또는 ChatGPT Plus/Pro 구독을 통한 OpenAI Codex OAuth) 중 하나)를 요청한 다음 VM 생성, 강화, OpenClaw 설치, CEO AI OS 작업 영역 시딩, Telegram 페어링, chat_id 자동 감지 및 봇 응답 확인을 자체적으로 처리합니다. 사용자가 수행하는 유일한 다른 작업은 Telegram에서 /start를 한 번 누르고 (Codex의 경우) auth.openai.com에서 장치 코드를 확인하는 것입니다. 사용자가 Yandex Cloud에 OpenClaw를 설치하고, YC 카자흐스탄에 OpenClaw를 배포하고, YC KZ에 CEO 봇을 설정하고, OpenClaw 워크샵에 있고 나만의 봇이 필요하고, OpenClaw용 Yandex Cloud VM을 생성한다고 말할 때 사용합니다. DevOps가 아닌 사용자(창립자, CEO, 마케팅 책임자)를 대상으로 최대 15분의 엔드투엔드 실행을 목표로 합니다. Yandex Cloud에 액세스하는 두 가지 모드, 즉 플랜 A(OAuth를 통한 사용자 자신의 YC 카자흐스탄 계정)와 플랜 B(자신의 YC 계정이 없는 참가자를 위해 워크숍 주최자가 제공하는 워크숍 키 번들)를 지원합니다. 모드는 입력에서 자동 감지됩니다. 로컬 머신 OpenClaw 설치의 경우 대신 이 저장소에서 openclaw/install.sh를 사용하십시오. 동반자 스킬 openclaw-guide가 필요합니다. prepare-yc-workshop은 플랜 B에서 소비되는 번들을 생성하는 일치하는 주최자 측 기술입니다. openclaw-user-onboarding은 5단계 후에 자동 호출되어 사용자에 대한 5가지 기본 정보(신원, 초점, 스타일, 도구, 안티 패턴)를 수집하고 이를 USER.md에 기록하므로 봇은 메시지 1부터 유용합니다.
