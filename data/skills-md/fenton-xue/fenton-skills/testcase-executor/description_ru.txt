Используйте компьютер для выполнения тестовых примеров вручную, анализа открытого текстового формата «модуль, имя тестового примера, описание шага, ожидаемый результат», создания внутреннего плана выполнения, объединения знаний о страницах проекта для выполнения навигации и записи фактических результатов вместе со скриншотами. Это используется для выполнения тестовых случаев, автоматического завершения функциональной проверки пользовательского интерфейса или генерации результатов выполнения теста.
