Gérer la configuration globale de Konecty Namespace : serveurs de messagerie, configuration de la file d'attente RabbitMQ, stockage, webhooks, paramètres du plan, configuration du portail. À utiliser lorsque l'utilisateur souhaite configurer des serveurs SMTP, ajouter des files d'attente RabbitMQ, configurer le stockage, configurer des webhooks globaux (onCreate/onUpdate/onDelete), gérer les paramètres Konsistent ou afficher la configuration globale des locataires. Nécessite des informations d’identification d’administrateur.
