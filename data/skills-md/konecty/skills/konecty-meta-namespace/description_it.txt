Gestisci la configurazione globale dello spazio dei nomi Konecty: server di posta elettronica, configurazione della coda RabbitMQ, archiviazione, webhook, impostazioni del piano, configurazione del portale. Da utilizzare quando l'utente desidera configurare server SMTP, aggiungere code RabbitMQ, impostare l'archiviazione, configurare webhook globali (onCreate/onUpdate/onDelete), gestire le impostazioni Konsistent o visualizzare la configurazione del tenant globale. Richiede credenziali di amministratore.
