Administre la configuración global de Konecty Namespace: servidores de correo electrónico, configuración de cola RabbitMQ, almacenamiento, webhooks, configuración del plan, configuración del portal. Úselo cuando el usuario desee configurar servidores SMTP, agregar colas RabbitMQ, configurar el almacenamiento, configurar webhooks globales (onCreate/onUpdate/onDelete), administrar configuraciones consistentes o ver la configuración global de inquilinos. Requiere credenciales de administrador.
