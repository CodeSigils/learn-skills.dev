기능 사양 문서(FSD)를 분석하고 Markdown 아티팩트 생성 — API 사양(spec_api.md), ERD(erd.md + dbdiagram.io용 선택적 DBML), UML 다이어그램(시퀀스, 클래스, 활동, 상태, 구성 요소, 사용 사례에 대한 PlantUML), 스토리 포인트가 포함된 개발자 작업 카드(task.md) 및 HTML Gantt 타임라인 차트. 또한 종속성 추적 및 중요 경로 분석을 통해 격차 분석(FSD 대 기존 ERD/API), 아티팩트 간 일관성 검사(ERD 대 API 대 작업), 개발 타임라인 예측을 수행합니다. 사용자가 FSD, 비즈니스 요구 사항을 제공 또는 참조하거나 기술 사양 생성/비교, 현재 데이터베이스 또는 API와의 차이점 찾기, ERD와 사양 간의 일관성 확인, 요구 사항을 개발자가 사용할 수 있는 문서로 변환, 개발 타임라인 추정, 개발자에게 작업 할당을 요청할 때 사용합니다. "FSD" 또는 "시스템 분석가"라는 단어가 없어도 가능합니다.
