تحليل مستندات المواصفات الوظيفية (FSD) وإنتاج عناصر Markdown - مواصفات واجهة برمجة التطبيقات (spec_api.md)، وERD (erd.md + DBML الاختياري لـ dbdiagram.io)، ومخططات UML (PlantUML للتسلسل، والفئة، والنشاط، والحالة، والمكون، وحالة الاستخدام)، وبطاقات مهام المطور (task.md) مع نقاط القصة، ومخططات المخطط الزمني HTML Gantt. قم أيضًا بإجراء تحليل الفجوات (FSD مقابل ERD/API الحالي)، وعمليات التحقق من الاتساق بين العناصر (ERD مقابل API مقابل المهام)، وتقدير الجدول الزمني للتطوير من خلال تتبع التبعية وتحليل المسار الحرج. يُستخدم عندما يقدم المستخدم أو يشير إلى FSD، أو متطلبات العمل، أو يطلب إنشاء/مقارنة المواصفات الفنية، أو العثور على فجوات مقابل قاعدة البيانات الحالية أو واجهة برمجة التطبيقات (API)، أو التحقق من الاتساق بين ERD والمواصفات، أو تحويل المتطلبات إلى وثائق جاهزة للمطور، أو تقدير الجدول الزمني للتطوير، أو تعيين المهام للمطورين - حتى بدون الكلمات "FSD" أو "محلل النظام".
