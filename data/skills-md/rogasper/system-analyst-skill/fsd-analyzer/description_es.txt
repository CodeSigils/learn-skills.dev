Analice documentos de especificaciones funcionales (FSD) y produzca artefactos de Markdown: especificaciones de API (spec_api.md), ERD (erd.md + DBML opcional para dbdiagram.io), diagramas UML (PlantUML para secuencia, clase, actividad, estado, componente, caso de uso), tarjetas de tareas de desarrollador (task.md) con Story Points y gráficos de línea de tiempo HTML de Gantt. También realice análisis de brechas (FSD frente a ERD/API existente), comprobaciones de coherencia entre artefactos (ERD frente a API frente a tareas) y estimación del cronograma de desarrollo con seguimiento de dependencias y análisis de ruta crítica. Úselo cuando el usuario proporciona o hace referencia a un FSD, requisitos comerciales o solicita generar/comparar especificaciones técnicas, encontrar brechas con la base de datos o API actual, validar la coherencia entre ERD y especificaciones, convertir requisitos en documentación lista para desarrolladores, estimar el cronograma de desarrollo o asignar tareas a los desarrolladores, incluso sin las palabras "FSD" o "analista de sistemas".
