分析功能規格文件 (FSD) 並產生 Markdown 工件 — API 規格 (spec_api.md)、ERD（erd.md + dbdiagram.io 的選用 DBML）、UML 圖（用於序列、類別、活動、狀態、元件、使用案例的 PlantUML）、帶有故事點的開發人員任務卡 (task.md) 以及 HTML 甘特時間線。還可以執行差距分析（FSD 與現有 ERD/API）、跨工件一致性檢查（ERD 與 API 與任務）以及透過依賴性追蹤和關鍵路徑分析進行開發時間表估計。當使用者提供或引用 FSD、業務需求或要求產生/比較技術規格、尋找與目前資料庫或 API 的差距、驗證 ERD 和規格之間的一致性、將需求轉換為開發人員就緒文件、估計開發時間表或向開發人員分配任務時使用 - 即使沒有「FSD」或「系統分析師」一詞。
