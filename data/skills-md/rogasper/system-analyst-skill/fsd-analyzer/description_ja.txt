機能仕様ドキュメント (FSD) を分析し、マークダウン アーティファクト - API 仕様 (spec_api.md)、ERD (erd.md + dbdiagram.io のオプションの DBML)、UML 図 (シーケンス、クラス、アクティビティ、状態、コンポーネント、ユースケースの PlantUML)、ストーリー ポイントを含む開発者タスク カード (task.md)、および HTML ガント タイムライン チャートを生成します。また、ギャップ分析 (FSD 対既存の ERD/API)、アーティファクト間の一貫性チェック (ERD 対 API 対タスク)、依存関係の追跡とクリティカル パス分析による開発タイムラインの見積もりも実行します。 「FSD」や「システム アナリスト」という言葉がなくても、ユーザーが FSD、ビジネス要件を提供または参照する場合、または技術仕様の生成/比較、現在のデータベースまたは API とのギャップの発見、ERD と仕様間の一貫性の検証、要件を開発者がすぐに使用できるドキュメントに変換、開発タイムラインの見積もり、または開発者へのタスクの割り当てを依頼する場合に使用します。
