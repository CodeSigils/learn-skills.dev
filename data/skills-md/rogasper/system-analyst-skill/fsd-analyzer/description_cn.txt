分析功能规范文档 (FSD) 并生成 Markdown 工件 — API 规范 (spec_api.md)、ERD（erd.md + dbdiagram.io 的可选 DBML）、UML 图（用于序列、类、活动、状态、组件、用例的 PlantUML）、带有故事点的开发人员任务卡 (task.md) 以及 HTML 甘特时间线图。还可以执行差距分析（FSD 与现有 ERD/API）、跨工件一致性检查（ERD 与 API 与任务）以及通过依赖性跟踪和关键路径分析进行开发时间表估计。当用户提供或引用 FSD、业务需求或要求生成/比较技术规范、查找与当前数据库或 API 的差距、验证 ERD 和规范之间的一致性、将需求转换为开发人员就绪文档、估计开发时间表或向开发人员分配任务时使用 - 即使没有“FSD”或“系统分析师”一词。
