Wenden Sie diese Fähigkeit an, wenn Sie CSS, Tailwind-Klassen oder das Design für React-/Web-Benutzeroberflächen schreiben oder bearbeiten – beim Erstellen von Layouts, Komponenten, Seiten, Dashboards, Formularen oder bei der Themengestaltung eines Projekts. Auslösen bei: Flexbox, Raster, Abstand, Positionierung, responsives Design, Shadcn/UI-Design, Design-Tokens, Dunkelmodus oder immer dann, wenn eine Benutzeroberfläche strukturelles oder visuelles CSS benötigt, auch für ein einzelnes Element. Das Ziel ist CSS, das einfach und wartbar bleibt: Arbeiten Sie von oben nach unten (Thema → Layout → Komponente → Element), stützen Sie sich auf eine Token-Skala anstelle von magischen Zahlen, verwenden Sie relative Einheiten, damit die Benutzeroberfläche skaliert und zugänglich bleibt, und schreiben Sie die wenigsten Eigenschaften, die das richtige Ergebnis liefern. Verwenden Sie dies, um zu verhindern, dass Agenten überentwickelte, mit Hacks beladene und schwer zu debuggende Stile erstellen.
