CSS、Tailwind クラス、または React/Web UI のスタイルを作成または編集するとき (レイアウト、コンポーネント、ページ、ダッシュボード、フォームを構築するとき、またはプロジェクトのテーマを設定するとき) には必ずこのスキルを適用してください。トリガー: フレックスボックス、グリッド、間隔、配置、レスポンシブ デザイン、shadcn/ui テーマ、デザイン トークン、ダーク モード、または単一要素であっても UI に構造的または視覚的な CSS が必要なとき。目標は、シンプルで保守しやすい CSS です。トップダウンで作業し (テーマ → レイアウト → コンポーネント → 要素)、マジック ナンバーではなくトークン スケールを重視し、相対単位を使用して UI がスケーリングされてアクセスしやすい状態を維持し、正しい結果を生成するプロパティを最小限に記述します。これを使用して、エージェントが過剰に設計され、ハッキングが満載で、デバッグが難しいスタイルを生成するのを阻止します。
