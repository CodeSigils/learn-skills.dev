قم بتطبيق هذه المهارة عند كتابة أو تحرير CSS أو فئات Tailwind أو تصميم واجهات مستخدم React/web — إنشاء تخطيطات أو مكونات أو صفحات أو لوحات معلومات أو نماذج أو تصميم مشروع. تشغيل: flexbox، أو الشبكة، أو التباعد، أو تحديد المواقع، أو التصميم سريع الاستجابة، أو سمات shadcn/ui، أو رموز التصميم، أو الوضع المظلم، أو في أي وقت تحتاج فيه واجهة المستخدم إلى CSS هيكلية أو مرئية، حتى بالنسبة لعنصر واحد. الهدف هو أن يظل CSS بسيطًا وقابلاً للصيانة: العمل من أعلى إلى أسفل (السمة → التخطيط → المكون → العنصر)، والاعتماد على مقياس رمزي بدلاً من الأرقام السحرية، واستخدام الوحدات النسبية بحيث يمكن قياس واجهة المستخدم وتبقى قابلة للوصول، وكتابة أقل عدد من الخصائص التي تنتج النتيجة الصحيحة. استخدم هذا لمنع الوكلاء من إنتاج تصميمات مبالغ فيها ومثقلة بالاختراق ويصعب تصحيحها.
