Aplique esta habilidad siempre que escriba o edite CSS, clases de Tailwind o diseñe para React/UI web: cree diseños, componentes, páginas, paneles, formularios o tematice un proyecto. Activar: flexbox, cuadrícula, espaciado, posicionamiento, diseño responsivo, tematización shadcn/ui, tokens de diseño, modo oscuro o cualquier momento en que una interfaz de usuario necesite CSS estructural o visual, incluso para un solo elemento. El objetivo es que CSS sea simple y fácil de mantener: trabajar de arriba hacia abajo (tema → diseño → componente → elemento), apoyarse en una escala simbólica en lugar de números mágicos, usar unidades relativas para que la interfaz de usuario se escale y permanezca accesible, y escriba la menor cantidad de propiedades que produzcan el resultado correcto. Utilice esto para evitar que los agentes produzcan estilos sobrediseñados, cargados de hacks y difíciles de depurar.
