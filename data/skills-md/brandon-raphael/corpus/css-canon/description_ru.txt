Применяйте этот навык при написании или редактировании CSS, классов Tailwind или стилизации для React/веб-интерфейсов — при создании макетов, компонентов, страниц, информационных панелей, форм или при оформлении тем проекта. Запуск по: флексбоксу, сетке, интервалу, позиционированию, адаптивному дизайну, темам Shadcn/UI, токенам дизайна, темному режиму или в любой момент, когда пользовательскому интерфейсу требуется структурный или визуальный CSS, даже для одного элемента. Цель состоит в том, чтобы CSS оставался простым и удобным в сопровождении: работайте сверху вниз (тема → макет → компонент → элемент), опирайтесь на шкалу токенов вместо магических чисел, используйте относительные единицы, чтобы пользовательский интерфейс масштабировался и оставался доступным, и пишите наименьшее количество свойств, которые дают правильный результат. Используйте это, чтобы не дать агентам создавать перегруженные хакерами и сложные для отладки стили.
