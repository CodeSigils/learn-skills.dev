Genere logotipos de mascotas IP personificados altamente simplificados con geometría plana, formas redondeadas y pesadas, dos colores IP más un color de fondo de forma predeterminada y un microvolumen neoesqueuomorfo de gradiente continuo. Úselo al crear un animal, criatura, robot, fantasma, planta, objeto u otro personaje como un logotipo cuadrado mínimo o una obra de arte del ícono de una aplicación, incluso cuando el agente debe inferir tres direcciones relevantes para el producto y proponer seis candidatos independientes para su aprobación.
