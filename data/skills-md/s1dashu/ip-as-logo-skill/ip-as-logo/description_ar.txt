أنشئ شعارات تميمة IP شخصية مبسطة للغاية باستخدام هندسة مسطحة أولية، وأشكال ثقيلة مدورة، ولونين IP بالإضافة إلى لون خلفية واحد بشكل افتراضي، وحجم صغير متدرج متواصل الشكل. يُستخدم عند إنشاء حيوان أو مخلوق أو روبوت أو شبح أو نبات أو كائن أو أي شخصية أخرى كشعار مربع صغير أو عمل فني لرمز التطبيق، بما في ذلك عندما يجب على الوكيل استنتاج ثلاثة اتجاهات ذات صلة بالمنتج واقتراح ستة مرشحين مستقلين للموافقة.
