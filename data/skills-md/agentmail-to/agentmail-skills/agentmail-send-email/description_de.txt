Verfassen, senden, beantworten oder leiten Sie E-Mails über den verbundenen AgentMail MCP-Server weiter. Verwenden Sie diese Option für JEDE Anfrage zum Senden, Beantworten oder Weiterleiten von E-Mails – sogar für einen schnellen einzeiligen Versand oder eine einfache Weiterleitung, die wie ein einzelner Tool-Aufruf aussieht; Die Versandregeln gelten unabhängig von der Aufgabengröße. Verwenden Sie es auch zum Verfassen von Nachrichten, zum Erstellen oder Planen von Entwürfen zur Überprüfung oder zum Senden an benannte Empfänger. Nicht zum Lesen oder Sortieren von E-Mails (agentmail-check-email), zur Posteingangsverwaltung (agentmail-manage-inboxes) oder zum Einrichten von MCP-Verbindungen (agentmail-mcp) verwenden.
