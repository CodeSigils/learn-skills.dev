قم بصياغة البريد الإلكتروني أو إرساله أو الرد عليه أو إعادة توجيهه من خلال خادم AgentMail MCP المتصل. يُستخدم لأي طلب لإرسال البريد أو الرد عليه أو إعادة توجيهه - حتى إرسال سريع من سطر واحد أو إعادة توجيه بسيطة تبدو وكأنها استدعاء أداة واحدة؛ تنطبق قواعد الإرسال بغض النظر عن حجم المهمة. يُستخدم أيضًا لإنشاء رسائل، أو إنشاء مسودات أو جدولتها للمراجعة، أو إرسالها إلى مستلمين محددين؛ لا تستخدمه لقراءة أو فرز البريد (agentmail-check-email)، أو إدارة البريد الوارد (agentmail-manage-inboxes)، أو إعداد اتصال MCP (agentmail-mcp).
