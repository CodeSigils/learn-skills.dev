دليل شامل إلى AgentMail Python وTypeScript SDKs. يُستخدم عند إنشاء وكلاء الذكاء الاصطناعي الذين يحتاجون إلى صناديق البريد الإلكتروني الخاصة بهم، أو إرسال أو استقبال رسائل البريد الإلكتروني برمجيًا، أو إدارة سلاسل الرسائل والمحادثات، أو التعامل مع المرفقات، أو إنشاء مسودات للموافقة البشرية في الحلقة، أو إعداد إشعارات في الوقت الفعلي عبر webhooks أو WebSockets، أو تكوين المجالات المخصصة، أو إدارة قوائم السماح/الحظر، أو استخدام pods لعزل المستأجرين المتعددين، أو دمج البريد الإلكتروني في أي سير عمل لوكيل الذكاء الاصطناعي. يغطي واجهة برمجة تطبيقات AgentMail الكاملة مع أمثلة التعليمات البرمجية وأفضل الممارسات وأنماط الإنتاج.
