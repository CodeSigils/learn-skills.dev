AgentMail Python および TypeScript SDK の包括的なガイド。独自の電子メール受信箱を必要とする AI エージェントの構築、プログラムによる電子メールの送受信、スレッドと会話の管理、添付ファイルの処理、人間参加型承認の下書きの作成、Webhook または WebSocket を介したリアルタイム通知の設定、カスタム ドメインの構成、許可/ブロック リストの管理、マルチテナント分離のためのポッドの使用、または AI エージェント ワークフローへの電子メールの統合を行う場合に使用します。コード例、ベスト プラクティス、運用パターンを含む完全な AgentMail API をカバーします。
