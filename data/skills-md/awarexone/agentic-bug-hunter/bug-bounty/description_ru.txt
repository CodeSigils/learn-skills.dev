Полный рабочий процесс по поиску ошибок — разведка (перечисление поддоменов, обнаружение активов, снятие отпечатков пальцев, область действия HackerOne, аудит исходного кода), обучение перед поиском (раскрытые отчеты, исследование технического стека, интеллект-карты, моделирование угроз), поиск уязвимостей (IDOR, SSRF, XSS, обход аутентификации, CSRF, условия гонки, SQLi, XXE, загрузка файлов, бизнес-логика, GraphQL, контрабанда HTTP, отравление кеша, OAuth, синхронизация) побочные каналы, OIDC, SSTI, захват поддоменов, неправильная конфигурация облака, цепочки ATO, агентный AI), тестирование безопасности LLM/AI (IDOR чат-бота, внедрение подсказки, непрямое внедрение, контрабанда ASCII, каналы exfil, RCE с помощью инструментов кода, извлечение системных подсказок, ASI01-ASI10), цепочка ошибок A-to-B (IDOR→обход аутентификации, SSRF→метаданные облака, XSS→ATO, открытый перенаправление → кража OAuth, S3 → пакет → секрет → OAuth, таблицы обхода (обход IP-адреса SSRF, обход открытого перенаправления, обход загрузки файлов), grep для конкретного языка (загрязнение прототипа JS, рассол Python, жонглирование типами PHP, Go template.HTML, Ruby YAML.load, Rust unwrap) и отчетность (ворота из 7 вопросов, 4 шлюза проверки, написание человеческим тоном, шаблоны по классу vuln, CVSS 3.1, генерация PoC, список всегда отклоненных, таблица условной цепочки, контрольный список отправки).
