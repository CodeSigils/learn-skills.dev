Instala el hardware de ingeniería en este repositorio: principios, habilidades de flujo de trabajo, el verificador de reglas independiente del idioma y un perfil de pila. Utilice esta habilidad una vez por repositorio, justo después de agregar las habilidades, o cada vez que alguien solicite configurar el arnés, agregar el verificador de reglas, elegir un perfil de pila o conectar CI para ello. Pregunta qué pila utiliza el repositorio e instala solo esa.
