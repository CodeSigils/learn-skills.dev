Aktualisieren Sie die Wuji-Geräte-Firmware mit Wuji Upgrade: Überprüfen Sie, welche Geräte Updates haben (--check), aktualisieren Sie ein oder alle Geräte auf die neueste Version, installieren Sie eine bestimmte Version (--to), flashen Sie ein lokales Firmware-Paket (--file) und durchsuchen Sie den Firmware-Katalog (--list). Verwenden Sie diese Option, wenn der Benutzer die Gerätefirmware aktualisieren, herunterstufen oder neu flashen möchte oder fragt, ob Firmware-Updates verfügbar sind.
