Взаимодействуйте с устройствами Wuji (перчатки для передачи данных / ловкие руки) через интерфейс командной строки wuji: сканируйте устройства (устройства), проверяйте соединение с помощью рукопожатия (пинг), читайте и записывайте параметры устройства (получение/установка) и подписывайтесь на данные в реальном времени, такие как ЭМП, тактильные сигналы и IMU (суб). Используйте, когда вам нужно проверить состояние устройства, прочитать данные датчиков, изменить конфигурацию устройства или написать сценарии автоматизации устройства. Для диагностики работоспособности устройства см. wuji-cli-doctor. Для обновления прошивки см. wuji-cli-upgrade.
