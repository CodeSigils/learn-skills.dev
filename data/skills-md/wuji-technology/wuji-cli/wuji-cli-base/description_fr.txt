Interagissez avec les appareils Wuji (gants de données / mains adroites) via la CLI wuji : recherchez des appareils (appareils), sondez la connectivité avec une poignée de main (ping), lisez et écrivez les paramètres de l'appareil (get/set) et abonnez-vous aux données en temps réel telles que EMF, tactiles et IMU (sub). À utiliser lorsque vous devez vérifier l'état de l'appareil, lire les données des capteurs, modifier la configuration de l'appareil ou écrire des scripts d'automatisation de l'appareil. Pour les diagnostics de santé de l’appareil, consultez wuji-cli-doctor. Pour les mises à niveau du micrologiciel, voir wuji-cli-upgrade.
