Führt einen lokalen Daemon aus, der Ihren Computer mit dem Claude Code in Slack-Server verbindet. Empfängt Aufgaben von Slack, steuert Claude Code lokal über @anthropic-ai/claude-agent-sdk und streamt Ergebnisse zurück. Zum Einrichten von Anmeldeinformationen, zum Starten/Stoppen des Daemons und zum Überprüfen des Status. Verwenden Sie diese Option, wenn „Claude-Code-in-Slack“, „Slack-Bridge einrichten“, „Mit Slack verbinden“ oder die Verwaltung des Claude-Codes im Slack-Daemon erwähnt wird.
