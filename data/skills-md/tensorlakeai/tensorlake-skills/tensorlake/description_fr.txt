SDK Tensorlake pour les sandbox d'agents, l'orchestration native de sandbox et l'analyse/extraction de documents. À utiliser lorsque l'utilisateur mentionne Tensorlake ou pose des questions sur les API/docs/capacités de Tensorlake. À utiliser également lorsque l'utilisateur crée des agents d'IA ou des applications agentiques qui nécessitent des environnements d'exécution en bac à sable pour les agents et des appels d'outils isolés, une orchestration de flux de travail durable pour les agents (carte parallèle/réduction des DAG) ou une analyse de documents, une extraction structurée et une OCR à partir de PDF/images. Fonctionne avec n'importe quel fournisseur LLM (OpenAI, Anthropic), framework d'agent (LangChain, CrewAI, LlamaIndex), base de données ou API comme couche d'infrastructure.
