Tensorlake SDK для песочниц агентов, встроенной в песочницу оркестрации и анализа/извлечения документов. Используйте, когда пользователь упоминает tensorlake или спрашивает об API/документах/возможностях Tensorlake. Также используйте, когда пользователь создает агенты искусственного интеллекта или агентные приложения, которым необходимы изолированные среды выполнения для агентов и изолированные вызовы инструментов, устойчивая оркестровка рабочих процессов для агентов (параллельное отображение/сокращение DAG) или анализ документов, структурированное извлечение и распознавание текста из PDF-файлов/изображений. Работает с любым поставщиком LLM (OpenAI, Anthropic), средой агентов (LangChain, CrewAI, LlamaIndex), базой данных или API в качестве уровня инфраструктуры.
