SDK de Tensorlake para entornos sandbox de agentes, orquestación nativa de sandbox y análisis/extracción de documentos. Úselo cuando el usuario mencione tensorlake o pregunte sobre las API/docs/capacidades de Tensorlake. También se utiliza cuando el usuario está creando agentes de IA o aplicaciones de agentes que necesitan entornos de ejecución de espacio aislado para agentes y llamadas de herramientas aisladas, orquestación de flujo de trabajo duradera para agentes (mapa paralelo/reducción de DAG) o análisis de documentos, extracción estructurada y OCR de archivos PDF/imágenes. Funciona con cualquier proveedor de LLM (OpenAI, Anthropic), marco de agente (LangChain, CrewAI, LlamaIndex), base de datos o API como capa de infraestructura.
