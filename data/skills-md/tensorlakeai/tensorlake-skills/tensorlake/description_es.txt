Tensorlake SDK for agent sandboxes, sandbox-native orchestration, and document parsing/extraction. Use when the user mentions tensorlake, or asks about Tensorlake APIs/docs/capabilities. También se utiliza cuando el usuario está creando agentes de IA o aplicaciones de agentes que necesitan entornos de ejecución de espacio aislado para agentes y llamadas de herramientas aisladas, orquestación de flujo de trabajo duradera para agentes (mapa paralelo/reducción de DAG) o análisis de documentos, extracción estructurada y OCR de archivos PDF/imágenes. Works with any LLM provider (OpenAI, Anthropic), agent framework (LangChain, CrewAI, LlamaIndex), database, or API as the infrastructure layer.
