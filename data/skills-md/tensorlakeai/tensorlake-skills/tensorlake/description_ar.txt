Tensorlake SDK لصناديق حماية الوكيل، والتنسيق الأصلي لصندوق الحماية، وتحليل/استخراج المستندات. يُستخدم عندما يذكر المستخدم Tensorlake، أو يسأل عن Tensorlake APIs/docs/capabilities. يُستخدم أيضًا عندما يقوم المستخدم ببناء وكلاء الذكاء الاصطناعي أو تطبيقات الوكلاء التي تحتاج إلى بيئات تنفيذ معزولة للوكلاء واستدعاءات الأدوات المعزولة، أو تنسيق دائم لسير العمل للوكلاء (خريطة متوازية/تقليل DAGs)، أو تحليل المستندات، والاستخراج المنظم، والتعرف الضوئي على الحروف من ملفات PDF/الصور. يعمل مع أي مزود LLM (OpenAI، Anthropic)، أو إطار عمل الوكيل (LangChain، أو CrewAI، أو LlamaIndex)، أو قاعدة البيانات، أو واجهة برمجة التطبيقات (API) كطبقة البنية التحتية.
