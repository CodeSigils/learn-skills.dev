2 つの入力ソースのいずれかから公開された CLI を修正します。(1) ドッグフード モードは、アクティブなクロード コード セッションのトランスクリプトをマイニングして摩擦 (フラグの欠落、ハンドローリング API ペイロード、サイレント null リターン) を確保します。 (2) 直接入力モードは、ユーザー指定の質問 (コマンドの名前変更、コマンドまたはフィードの追加、名前付きバグの修正、オプションでソース サイトの新しいエンドポイントのスニッフィング) を受け入れます。ユーザーに範囲を確認し、修正を自律的に計画および実行し、PII をスクラブし、mvanhorn/printing-press-library に対して PR を開きます。 2 つのユーザーインループ チェックポイント: キャプチャ後のスコープ、オープン前の PR ドラフト。トリガーフレーズ: 「CLI を修正する」、「パッチを送信する」、「ドッグフードした内容を修正する」、「この CLI の PR を開く」、「この CLI にパッチを適用する」、「CLI に機能を追加する」、「このコマンドの名前を変更する」、「これらのフィードを <cli> に追加する」、「<cli> の新しい API を探す」、「これらのアイデアで修正する」、「printing-press-amend を使用する」、「printing-press-amend を実行する」。
