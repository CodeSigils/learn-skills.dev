Запустите ретроспективу после создания CLI. Определяет системные улучшения печатного станка — шаблоны, двоичный файл Go, инструкции по навыкам, каталог — чтобы следующий интерфейс командной строки стал лучше. Создает проблему GitHub с практическими выводами, когда нужно внести исправления в типографию. Используйте после любого запуска /printing-press. Триггерные фразы: «ретро», «ретроспектива», «что пошло не так», «улучшить прессу», «вскрытие», «извлеченные уроки», «что мы можем улучшить», «подать ретроспективу», «представить выводы».
