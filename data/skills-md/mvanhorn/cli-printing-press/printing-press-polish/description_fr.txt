Améliorez une CLI générée pour réussir la vérification et être prête pour la publication. Exécute des diagnostics (dogfood, vérification, scorecard, go vet), corrige automatiquement tous les problèmes (vérification des échecs, code mort, descriptions, README, qualité de l'outil MCP), rapporte le delta avant/après et propose de publier. À utiliser après toute exécution de /printing-press ou sur n'importe quelle CLI dans ~/printing-press/library/. Phrases de déclenchement : « peaufiner », « améliorer la CLI », « corriger la vérification », « le rendre prêt pour la publication », « nettoyer la CLI », « préparer ceci à l'expédition ».
