Erneuern Sie eine vorhandene gedruckte CLI unter der aktuellen Druckmaschine von Grund auf, wobei frühere Recherchen und frühere neuartige Features in den Nachdruckabgleich des Novel-Features-Subagenten übernommen werden, anstatt auf den Boden zu fallen. Ruft die CLI aus der öffentlichen Bibliothek ab, wenn sie nicht lokal ist, empfiehlt die Wiederverwendung oder Wiederholung früherer Recherchen basierend auf dem Alter und übergibt sie dann mit dem richtigen Kontext an /printing-press. Verwenden Sie diese Option, wenn ein Maschinen-Upgrade einer veröffentlichten CLI mehr nützen würde als eine manuelle Politur. Auslösephrasen: „<api> erneut drucken“, „<api> neu generieren“, „die <api>-CLI erneut erstellen“, „<api> von Grund auf neu erstellen“, „diese CLI würde von einem erneuten Druck profitieren“.
