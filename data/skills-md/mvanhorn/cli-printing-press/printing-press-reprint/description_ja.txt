既存の印刷版 CLI を現在の印刷機でゼロから再生成します。事前調査および以前の新規機能は、床に放置されるのではなく、新規機能サブエージェントの再印刷調整に組み込まれます。 CLI がローカルでない場合はパブリック ライブラリから CLI を取得し、経過期間に基づいて以前の調査の再利用とやり直しを推奨し、適切なコンテキストで /printing-press にハンドオフします。マシンのアップグレードが、手動による修正よりも公開された CLI にメリットをもたらす場合に使用します。トリガーフレーズ: 「<api> を再印刷」、「<api> を再生成」、「<api> CLI を再実行」、「<api> を最初から再構築」、「この CLI は再印刷するとメリットが得られます」。
