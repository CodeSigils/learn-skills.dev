Guide de test complet pour le projet LMS avec une stratégie à 4 couches couvrant les tests backend Convex (convex-test), les tests de composants React (Testing Library), les tests de workflow d'intégration et les tests E2E (Playwright). À utiliser lorsque vous travaillez sur des fichiers correspondant à `**/*.test.ts`, `**/*.spec.ts`, `tests/**`, ou lorsqu'on vous demande d'écrire des tests, de tester un composant, de vérifier la couverture, d'implémenter TDD. Se déclenche sur des mots-clés tels que vitest, dramaturge, bibliothèque de tests, test convexe, couverture, TDD, test unitaire, test e2e, test d'intégration.
