Полное руководство по тестированию проекта LMS с четырехуровневой стратегией, охватывающей выпуклые серверные тесты (выпуклый-тест), тесты компонентов React (библиотека тестирования), тесты интеграционных рабочих процессов и тесты E2E (Playwright). Используйте при работе с файлами, соответствующими `**/*.test.ts`, `**/*.spec.ts`, `tests/**`, или когда вас просят написать тесты, протестировать компонент, проверить покрытие, реализовать TDD. Запускается по таким ключевым словам, как vitest, драматург, библиотека тестирования, выпуклый тест, покрытие, TDD, модульный тест, тест e2e, интеграционный тест.
