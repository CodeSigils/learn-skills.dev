Guía de pruebas completa para el proyecto LMS con una estrategia de 4 capas que cubre pruebas de backend Convex (convex-test), pruebas de componentes de React (Testing Library), pruebas de flujo de trabajo de integración y pruebas E2E (Playwright). Úselo cuando trabaje en archivos que coincidan con `**/*.test.ts`, `**/*.spec.ts`, `tests/**`, o cuando se le solicite escribir pruebas, probar un componente, verificar la cobertura o implementar TDD. Se activa con palabras clave como vitest, dramaturgo, biblioteca de pruebas, prueba convexa, cobertura, TDD, prueba unitaria, prueba e2e, prueba de integración.
