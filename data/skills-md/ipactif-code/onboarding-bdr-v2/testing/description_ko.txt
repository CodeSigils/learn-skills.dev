Convex 백엔드 테스트(convex-test), React 구성 요소 테스트(테스트 라이브러리), 통합 워크플로 테스트 및 E2E 테스트(Playwright)를 포괄하는 4계층 전략이 포함된 LMS 프로젝트를 위한 완벽한 테스트 가이드입니다. `**/*.test.ts`, `**/*.spec.ts`, `tests/**`와 일치하는 파일 작업을 할 때 또는 테스트 작성, 구성 요소 테스트, 적용 범위 확인, TDD 구현을 요청받을 때 사용합니다. vitest, 극작가, 테스트 라이브러리, 볼록 테스트, 적용 범위, TDD, 단위 테스트, e2e 테스트, 통합 테스트와 같은 키워드를 트리거합니다.
