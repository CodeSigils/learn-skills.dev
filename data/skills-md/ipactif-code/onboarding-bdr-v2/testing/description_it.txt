Guida completa ai test per il progetto LMS con una strategia a 4 livelli che copre test backend convessi (convex-test), test dei componenti React (libreria di test), test del flusso di lavoro di integrazione e test E2E (Playwright). Da utilizzare quando si lavora su file corrispondenti a `**/*.test.ts`, `**/*.spec.ts`, `tests/**` o quando viene richiesto di scrivere test, testare un componente, verificare la copertura, implementare TDD. Si attiva su parole chiave come vitest, drammaturgo, libreria di test, test convesso, copertura, TDD, test unitario, test e2e, test di integrazione.
