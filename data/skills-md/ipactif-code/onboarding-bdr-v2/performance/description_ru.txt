Шаблоны оптимизации производительности для приложений Next.js 15 + React 19 + Convex. Охватывает основные веб-показатели (LCP, INP, CLS), оптимизацию пакетов, оптимизацию выпуклых запросов с помощью индексов и стратегии кэширования. Используйте при работе с файлами next.config.ts, convex/**/*.ts, app/**/*.tsx. Используйте, когда вас просят оптимизировать, улучшить производительность, уменьшить связку, ускорить работу. Триггеры по ключевым словам: производительность, основные веб-показатели, LCP, CLS, INP, размер пакета, отложенная загрузка, индекс, withIndex, медленный, предоставленный.
