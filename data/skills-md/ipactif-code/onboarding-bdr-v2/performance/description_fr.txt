Modèles d'optimisation des performances pour les applications Next.js 15 + React 19 + Convex. Couvre les Core Web Vitals (LCP, INP, CLS), l'optimisation des bundles, l'optimisation des requêtes convexes avec des index et les stratégies de mise en cache. À utiliser lorsque vous travaillez sur des fichiers dans next.config.ts, convex/**/*.ts, app/**/*.tsx. À utiliser lorsqu'on vous le demande pour optimiser, améliorer les performances, réduire le bundle, accélérer. Déclencheurs sur des mots-clés : performances, Core Web Vitals, LCP, CLS, INP, taille du bundle, chargement différé, index, withIndex, lent, prêté.
