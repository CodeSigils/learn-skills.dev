أنماط TypeScript المتقدمة وأفضل الممارسات لمشروع LMS Next.js/Convex. يوفر الأنواع العامة والأنواع الشرطية والأنواع المعينة وأنواع الأدوات المساعدة وحرس النوع والأنماط الخاصة بالمشروع. يُستخدم عند العمل على ملفات في **/*.ts، **/*.tsx، محدبة/**/*.ts، عند إنشاء الأنواع، أو تحديد الواجهات، أو حل أخطاء TypeScript، أو تحسين أمان الكتابة. مشغلات الكلمات الرئيسية: الأدوية العامة، أنواع المرافق، نوع الحماية، التضييق، النوع الشرطي، النوع المعين، الاستدلال، الممتد، الجزئي، الاختيار، الحذف، نوع الإرجاع، المعرف المحدب، غير معروف، أبدًا، اتحاد تمييزي، فحص شامل.
