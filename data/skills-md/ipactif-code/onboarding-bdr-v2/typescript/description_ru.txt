Расширенные шаблоны TypeScript и лучшие практики для проекта LMS Next.js/Convex. Предоставляет универсальные типы, условные типы, сопоставленные типы, служебные типы, средства защиты типов и шаблоны, специфичные для проекта. Используйте при работе с файлами **/*.ts, **/*.tsx, convex/**/*.ts, при создании типов, определении интерфейсов, устранении ошибок TypeScript или повышении безопасности типов. Триггеры по ключевым словам: дженерики, служебные типы, защита типа, сужение, условный тип, отображаемый тип, вывод, расширение, частичный, выбор, пропущенный, ReturnType, выпуклый идентификатор, неизвестный, никогда, дискриминируемое объединение, исчерпывающая проверка.
