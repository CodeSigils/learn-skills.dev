أنماط الواجهة الخلفية المحدبة وأفضل الممارسات لمشروع LMS. يوفر تعريف المخطط والاستعلامات والطفرات والإجراءات ومصادقة Clerk وأنماط تخزين الملفات. يُستخدم عند العمل على ملفات محدبة/**/*.ts، أو عند إنشاء استعلامات أو تغييرات أو إجراءات أو تعديل المخطط أو إضافة الجداول أو إدارة الملفات. مشغلات الكلمات الأساسية: محدب، مخطط، استعلام، طفرة، إجراء، ctx.db، requireAuth، داخلي.
