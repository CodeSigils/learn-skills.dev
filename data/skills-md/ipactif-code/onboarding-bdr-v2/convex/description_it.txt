Modelli di backend convessi e migliori pratiche per il progetto LMS. Fornisce la definizione dello schema, le query, le mutazioni, le azioni, l'autenticazione dell'impiegato e i modelli di archiviazione dei file. Da utilizzare quando si lavora su file in convex/**/*.ts, quando si creano query, mutazioni, azioni, si modifica schema, si aggiungono tabelle o si gestiscono file. Trigger su parole chiave: Convesso, schema, query, mutazione, azione, ctx.db, requireAuth, interno.
