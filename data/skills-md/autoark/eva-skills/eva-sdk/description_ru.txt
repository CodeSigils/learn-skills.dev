Запустите официальную демо-версию EVA или пропустите демо-версию и сразу выберите выпущенный EVA SDK для интеграции и настройки существующих приложений. Пользователи могут запросить просмотр текущего SDK, запросить официальную общедоступную точку входа, запустить демо-версию, интегрировать SDK, изменить общедоступные возможности или использовать его для проверки и устранения неполадок потребительских проектов SDK; Направляйте выпущенные SDK через локальный каталог SDK и направляйте работоспособные демо-версии через каталог примеров, закрепленных за выпуском, без предварительного определения конкретной цепочки инструментов.
