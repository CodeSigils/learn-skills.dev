Démarrez la démo officielle EVA ou ignorez l'exécution de la démo et choisissez directement le SDK EVA publié pour intégrer et personnaliser les applications existantes. Les utilisateurs peuvent avoir besoin de visualiser le SDK actuel, d'interroger le point d'entrée public officiel, d'exécuter la démo, d'intégrer le SDK, de modifier les fonctionnalités publiques ou de l'utiliser pour la vérification et le dépannage des projets consommateurs du SDK ; utilisez le catalogue SDK local pour acheminer le SDK publié et utilisez le catalogue d'exemples épinglés par la version pour acheminer les démos exécutables, sans prédéfinir une chaîne d'outils spécifique.
