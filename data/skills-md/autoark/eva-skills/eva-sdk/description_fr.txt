Lancez la démo officielle EVA ou ignorez l'exécution de la démo et sélectionnez directement le SDK EVA publié pour intégrer et personnaliser les applications existantes. Les utilisateurs peuvent demander à afficher le SDK actuel, interroger le point d'entrée public officiel, exécuter la démo, intégrer le SDK, modifier les fonctionnalités publiques ou l'utiliser pour la vérification et le dépannage des projets consommateurs du SDK ; acheminez les SDK publiés via un catalogue de SDK local et acheminez les démos exécutables via un catalogue d'exemples épinglés par la version, sans prédéfinir une chaîne d'outils spécifique.
