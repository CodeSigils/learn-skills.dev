Starten Sie die offizielle EVA-Demo oder überspringen Sie die Ausführung der Demo und wählen Sie direkt das veröffentlichte EVA SDK aus, um vorhandene Anwendungen zu integrieren und anzupassen. Benutzer müssen möglicherweise das aktuelle SDK anzeigen, den offiziellen öffentlichen Einstiegspunkt abfragen, die Demo ausführen, das SDK integrieren, öffentliche Funktionen ändern oder es zur Überprüfung und Fehlerbehebung von SDK-Verbraucherprojekten verwenden; Verwenden Sie den lokalen SDK-Katalog, um das veröffentlichte SDK weiterzuleiten, und verwenden Sie den an die Veröffentlichung angehefteten Beispielkatalog, um ausführbare Demos weiterzuleiten, ohne eine bestimmte Toolchain vorauszusetzen.
