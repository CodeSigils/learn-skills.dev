Starten Sie die offizielle EVA-Demo oder überspringen Sie die Ausführung der Demo und wählen Sie direkt das veröffentlichte EVA SDK aus, um vorhandene Anwendungen zu integrieren und anzupassen. Benutzer können anfordern, das aktuelle SDK anzuzeigen, den offiziellen öffentlichen Einstiegspunkt abzufragen, die Demo auszuführen, das SDK zu integrieren, öffentliche Funktionen zu ändern oder es zur Überprüfung und Fehlerbehebung von SDK-Verbraucherprojekten zu verwenden; Leiten Sie veröffentlichte SDKs über einen lokalen SDK-Katalog weiter und leiten Sie ausführbare Demos über einen Release-gepinnten Beispielkatalog weiter, ohne eine bestimmte Toolchain vordefinieren zu müssen.
