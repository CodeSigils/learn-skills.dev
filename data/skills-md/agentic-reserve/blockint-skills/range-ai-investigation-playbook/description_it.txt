Da utilizzare quando l'utente esegue indagini all'interno di un client connesso a MCP con Range abilitato o necessita di una lista di controllo strutturata insieme alla conformità alle indagini crittografiche, non come consulenza legale o come sostituto dei documenti live e degli ambiti API di Range.
