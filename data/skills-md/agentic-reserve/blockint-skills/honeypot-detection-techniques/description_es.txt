Técnicas educativas para evaluar el riesgo de token estilo honeypot a partir de fuentes verificadas, pistas de código de bytes e historial de observación en cadena: patrones EVM ERC-20 (puertas de transferencia, tarifas, listas negras), ganchos Solana SPL y Token-2022, y rutas de validación seguras. Úselo cuando el usuario pregunte cómo detectar honeypots, tokens de venta restringida, mecánicas de tokens de estafa o listas de verificación de revisión estática, no para implementar estafas, robar fondos o asesorar operaciones de prueba de alto riesgo en la red principal sobre contratos desconocidos.
