Points to Impersonator (EVM) e Impersonator Solana: herramientas de código abierto para conectarse a dApps a través de WalletConnect (y flujos relacionados) mientras presentan una dirección arbitraria para la exploración de la interfaz de usuario sin tener que mantener las claves de esa dirección. Úselo cuando el usuario nombra impersonator.xyz, solana.impersonator.xyz o los repositorios de GitHub para desarrolladores locales, no para phishing, fraude de identidad o elusión de controles legales o de dApp.
