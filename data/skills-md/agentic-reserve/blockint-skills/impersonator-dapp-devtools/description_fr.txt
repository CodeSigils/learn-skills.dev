Points to Impersonator (EVM) et Impersonator Solana : outils open source pour se connecter aux dApps via WalletConnect (et les flux associés) tout en présentant une adresse arbitraire pour l'exploration de l'interface utilisateur sans détenir les clés de cette adresse. À utiliser lorsque l'utilisateur nomme impersonator.xyz, solana.impersonator.xyz ou les dépôts GitHub pour les développeurs locaux, et non pour le phishing, la fraude d'identité ou le contournement de dApp ou des contrôles légaux.
