Указывает на Impersonator (EVM) и Impersonator Solana — инструменты с открытым исходным кодом для подключения к децентрализованным приложениям через WalletConnect (и связанные потоки), предоставляя при этом произвольный адрес для исследования пользовательского интерфейса без хранения ключей этого адреса. Используйте, когда пользователь называет impersonator.xyz, solana.impersonator.xyz или репозитории GitHub для локальных разработчиков, а не для фишинга, мошенничества с личными данными или обхода dApp или юридического контроля.
