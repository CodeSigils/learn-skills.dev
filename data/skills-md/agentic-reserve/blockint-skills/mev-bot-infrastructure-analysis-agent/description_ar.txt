يرسم خرائط لسلوك الباحث عن MEV والبنية التحتية التي يمكن ملاحظتها من الحزم والكتل والتتبعات العامة - أنماط إنشاء/ترحيل EVM، وحزم Solana Jito، وبصمات الإستراتيجية، ومسارات توحيد الأرباح، ومقاييس التركيز. يُستخدم عندما يطلب المستخدم تحليل روبوت MEV، أو تجميع الباحثين، أو تعيين الحزمة/المنشئ، أو أسئلة البحث عن تدفق الطلب الخاص، أو دراسات مركزية النظام البيئي - وليس لتشغيل الروبوتات التنافسية، أو معالجة مجمع الذاكرة، أو مضايقة المشغلين.
