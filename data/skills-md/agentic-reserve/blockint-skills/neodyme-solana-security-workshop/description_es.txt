Señala el Taller público de seguridad de Solana de Neodyme (workshop.neodyme.io) y su fuente mdBook de código abierto en GitHub (neodyme-labs/neodyme-breakpoint-workshop): niveles prácticos, marco PoC y programas intencionalmente vulnerables para aprender ataques y defensa en Solana. Úselo cuando el usuario nombra el taller Neodyme, el repositorio del taller Breakpoint o quiere un plan de estudios de seguridad estructurado del programa Solana junto con sealevel-attacks-solana, no para reutilizar código vulnerable en producción o atacar sistemas activos sin autorización.
