Pointe vers l'atelier public de sécurité Solana de Neodyme (workshop.neodyme.io) et sa source mdBook open source sur GitHub (neodyme-labs/neodyme-breakpoint-workshop) : niveaux pratiques, cadre PoC et programmes intentionnellement vulnérables pour apprendre l'attaque et la défense sur Solana. À utiliser lorsque l'utilisateur nomme l'atelier Neodyme, le dépôt de l'atelier Breakpoint ou souhaite un programme structuré de sécurité du programme Solana aux côtés de sealevel-attacks-solana, pas pour réutiliser du code vulnérable en production ou attaquer des systèmes en direct sans autorisation.
