يشير إلى ورشة عمل Solana Security العامة الخاصة بشركة Neodyme (workshop.neodyme.io) ومصدر mdBook مفتوح المصدر الخاص بها على GitHub (neodyme-labs/neodyme-breakpoint-workshop) — مستويات التدريب العملي وإطار عمل PoC والبرامج الضعيفة عمدًا لتعلم الهجوم والدفاع على Solana. يُستخدم عندما يقوم المستخدم بتسمية ورشة عمل Neodyme، أو ورشة عمل Breakpoint repo، أو يريد منهجًا أمنيًا منظمًا لبرنامج Solana إلى جانب هجمات مستوى سطح البحر-solana - وليس لإعادة استخدام التعليمات البرمجية الضعيفة في الإنتاج أو مهاجمة الأنظمة الحية دون ترخيص.
