Указывает на общедоступный семинар Solana Security Workshop от Neodyme (workshop.neodyme.io) и его исходный код mdBook с открытым исходным кодом на GitHub (neodyme-labs/neodyme-breakpoint-workshop) — практические уровни, структуру PoC и намеренно уязвимые программы для изучения атак и защиты на Solana. Используйте, когда пользователь называет мастерскую Neodyme, репозиторий мастерской Breakpoint или хочет, чтобы структурированная учебная программа по безопасности программы Solana наряду с атаками на уровне моря-solana — не для повторного использования уязвимого кода в производстве или атаки на работающие системы без авторизации.
