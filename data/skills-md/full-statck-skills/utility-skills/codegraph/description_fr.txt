Intelligence sémantique du code CodeGraph : requêtes sur la structure du code, traçage des symboles, analyse de l'impact des changements, recherche de chaîne d'appels. Gère les questions de base de code telles que « Comment fonctionne X », « Qu'est-ce qui est affecté par la modification de X », « Qui appelle X ». Prend en charge plus de 20 langues, 100 % local.
