Guía para la configuración de redes Docker y la comunicación entre contenedores. Cubre modos de red (puente/host/superposición/ninguno/macvlan/ipvlan), redes puente personalizadas con resolución DNS, publicación de puertos (-p/--publish), vinculación de contenedores y descubrimiento de servicios, solución de problemas de red (inspect/ping/nslookup), redes superpuestas para Swarm y seguridad de red (redes internas, superposición cifrada). Úselo cuando el usuario pregunte sobre la red Docker, la red de contenedores, el modo puente, el mapeo de puertos, la comunicación entre contenedores, la solución de problemas de red o los modos de red Docker. 使用场景：docker network、容器网络、bridge、overlay、端口映射、容器通信、网络配置、网络排查.
