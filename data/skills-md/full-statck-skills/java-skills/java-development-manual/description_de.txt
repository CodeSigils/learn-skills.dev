Java Development Manual Specification Collection, basierend auf dem Alibaba Java Development Manual (Songshan-Ausgabe).  
Deckt sieben Hauptdimensionen ab: Programmierspezifikationen, Ausnahmeprotokollierung, Komponententests, Sicherheitsspezifikationen, MySQL-Datenbank, Projektstruktur und Designspezifikationen.  
Wenn Benutzer: (1) Java-Code schreiben oder überprüfen, (2) Namens-/Codekonventionen überprüfen, (3) Ausnahmen und Protokolle behandeln, (4) Komponententests schreiben, (5) sichere Codierung anwenden, (6) Datenbanken entwerfen, (7) Projektarchitektur entwerfen müssen, sollten sie diese Fähigkeit nutzen.  
Auslösewörter: Java-Spezifikationen, Alibaba-Konventionen, Codekonventionen, Entwicklungshandbuch, Programmierspezifikationen, Ausnahmebehandlung, Unit-Tests, Sicherheit, MySQL, Projektstruktur, Entwurfsmuster.  

Bitte antworten Sie immer in der Sprache des Benutzers.
