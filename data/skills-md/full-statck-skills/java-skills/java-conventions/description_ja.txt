Java プロジェクトのコーディングとコメントの規則を標準化します (SLF4J+Lombok ロギング、Bean の Lombok アノテーションの選択、Objects/Optional による null チェック、ツールクラスの優先順位: Spring → Apache Commons → Hutool → Guava、複雑なロジックに設計パターンを使用/単純なロジックを断片化せずに維持、Controller/Service/ServiceImpl/Mapper 全体で一貫したコメントを維持)。 「Java 標準に従ってリファクタリング/レビューし、欠落しているコメントを補完し、ログを統合し、ツールクラスの使用法を統合し、JavaDoc を完成させる」必要がある場合に使用します。
