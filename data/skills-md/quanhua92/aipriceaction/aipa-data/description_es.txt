Obtenga datos de precios de OHLCV sin procesar utilizando la CLI de aipa. Utilice esta habilidad siempre que el usuario solicite datos de precios, datos de velas, datos OHLCV, precios históricos, cotizaciones de acciones, precios de criptomonedas, promedios móviles, datos de volumen o cualquier dato de mercado sin procesar sin análisis de IA. También se utiliza para: los de mejor desempeño, los de peor desempeño, las mejores acciones, los que más ganan, los que más pierden, los que mueven el mercado, los tickers de clasificación por cambio de precio / volumen / valor / puntajes MA / flujo de dinero (`artistas de aipa`); perfil de volumen, POC, punto de control, área de valor, soporte/resistencia por volumen, histograma de volumen por precio ("aipa volumen-perfil"). Úselo también cuando el usuario quiera inspeccionar qué datos están disponibles, crear gráficos, realizar sus propios cálculos u obtener números para una hoja de cálculo. Incluso si el usuario no menciona "aipa", active esta habilidad para cualquier solicitud de datos financieros sin procesar o clasificación de mercado.
