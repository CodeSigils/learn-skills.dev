جلب بيانات أسعار OHLCV الخام باستخدام aipa CLI. استخدم هذه المهارة عندما يطلب المستخدم بيانات الأسعار، أو بيانات الشموع، أو بيانات OHLCV، أو الأسعار التاريخية، أو أسعار الأسهم، أو أسعار العملات المشفرة، أو المتوسطات المتحركة، أو بيانات الحجم، أو أي بيانات سوق أولية بدون تحليل الذكاء الاصطناعي. استخدم أيضًا لـ: أصحاب الأداء الأعلى، والأسوأ أداء، وأفضل الأسهم، وأفضل الرابحين، وأكبر الخاسرين، ومحركات السوق، ومؤشرات التصنيف حسب تغير السعر / الحجم / القيمة / درجات MA / تدفق الأموال ("مؤديو AIPA")؛ ملف تعريف الحجم، POC، نقطة التحكم، منطقة القيمة، الدعم/المقاومة من حيث الحجم، الرسم البياني للحجم حسب السعر ('ملف تعريف حجم aipa'). يُستخدم أيضًا عندما يريد المستخدم فحص البيانات المتاحة، أو إنشاء مخططات، أو إجراء حساباته الخاصة، أو الحصول على أرقام لجدول بيانات. حتى إذا لم يذكر المستخدم "aipa"، قم بتشغيل هذه المهارة لأي بيانات مالية أولية أو طلب تصنيف السوق.
