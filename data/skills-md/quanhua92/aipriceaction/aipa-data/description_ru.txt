Получите необработанные данные о ценах на OHLCV с помощью интерфейса командной строки aipa. Используйте этот навык всякий раз, когда пользователь запрашивает данные о ценах, данные свечей, данные OHLCV, исторические цены, котировки акций, цены криптовалют, скользящие средние, данные об объемах или любые необработанные рыночные данные без анализа ИИ. Также используется для: лучших акций, худших акций, лучших акций, лидеров роста, наибольших убытков, движущих сил рынка, ранжирования тикеров по изменению цены/объему/стоимости/показаниям MA/денежному потоку («исполнители AIPA»); профиль объема, POC, точка контроля, область стоимости, поддержка/сопротивление по объему, гистограмма объема по цене («aipa Volume-profile»). Также используйте, когда пользователь хочет проверить, какие данные доступны, построить диаграммы, выполнить собственные расчеты или получить числа для электронной таблицы. Даже если пользователь не упоминает «aipa», активируйте этот навык для любых необработанных финансовых данных или запроса рыночного рейтинга.
