Загружайте локальные изображения и другие файлы (PDF, zip, log и т.д.) на GitHub и встраивайте их в описание пул‑запроса, задачу или комментарий — получая канонические URL вида github.com/user-attachments (загрузки из приватного репозитория остаются приватными). Используйте, когда просят «прикрепить скриншот к PR», «добавить изображение в описание PR», «вставить эту картинку в задачу», «прикрепить этот PDF/log/zip к задаче», «показать результаты тестов в PR», «вставить скриншоты до/после» или любой запрос, требующий визуального документирования или прикрепления файлов к изменениям на GitHub. Работает через расширение `gh-image` для CLI gh.
