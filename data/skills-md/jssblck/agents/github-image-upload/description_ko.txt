로컬 이미지 및 기타 파일(PDF, zip, 로그 등)을 GitHub에 업로드하고 풀 요청 설명, 문제 또는 댓글에 포함하여 표준 github.com/user-attachments URL을 생성합니다(비공개 저장소 업로드는 비공개로 유지됨). "PR에 스크린샷 첨부", "PR 설명에 이미지 추가", "이 이미지를 이슈에 넣기", "이 PDF/로그/zip을 이슈에 첨부", "PR에 테스트 결과 표시", "스크린샷 전후에 삽입" 또는 GitHub의 변경 사항에 시각적으로 문서화하거나 파일을 첨부하라는 요청이 있을 때 사용합니다. `gh-image` gh CLI 확장으로 구동됩니다.
