Lade lokale Bilder und andere Dateien (PDF, zip, Log, …) zu GitHub hoch und bette sie in die Beschreibung eines Pull Requests, eines Issues oder eines Kommentars ein – dabei werden kanonische github.com/user‑attachments‑URLs erzeugt (Uploads in privaten Repositories bleiben privat). Verwende dies, wenn du aufgefordert wirst, „einen Screenshot zum PR hinzuzufügen“, „ein Bild zur PR‑Beschreibung hinzuzufügen“, „dieses Bild ins Issue zu stellen“, „dieses PDF/Log/Zip ins Issue anzuhängen“, „Testresultate im PR zu zeigen“, „Vorher/Nachher‑Screenshots einzubetten“ oder jede andere Bitte, Änderungen auf GitHub visuell zu dokumentieren oder Dateien anzuhängen. Angetrieben von der `gh-image` gh‑CLI‑Erweiterung.
