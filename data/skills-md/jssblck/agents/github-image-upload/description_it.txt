Carica immagini locali e altri file (PDF, zip, log, …) su GitHub e incorporali nella descrizione di una pull request, in un issue o in un commento — generando URL canonici github.com/user-attachments (i caricamenti di repository private rimangono privati). Usa quando ti viene chiesto di “allegare uno screenshot al PR”, “aggiungere un'immagine alla descrizione del PR”, “inserire questa immagine nell'issue”, “allegare questo PDF/log/zip all'issue”, “mostrare i risultati dei test nel PR”, “incorporare screenshot prima/dopo”, o qualsiasi altra richiesta di documentare visivamente o allegare file alle modifiche su GitHub. Alimentato dall’estensione CLI `gh-image` di gh.
