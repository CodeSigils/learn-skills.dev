Cargar imágenes locales y otros archivos (PDF, zip, log, …) a GitHub e incrustarlos en la descripción de una pull request, un issue o un comentario — generando URLs canónicas github.com/user-attachments (las cargas en repositorios privados permanecen privadas). Úsalo cuando te pidan “adjuntar una captura de pantalla al PR”, “añadir una imagen a la descripción del PR”, “colocar esta imagen en el issue”, “adjuntar este PDF/log/zip al issue”, “mostrar resultados de pruebas en el PR”, “incrustar capturas antes/después”, o cualquier solicitud de documentar visualmente o adjuntar archivos a cambios en GitHub. Alimentado por la extensión `gh-image` del CLI gh.
