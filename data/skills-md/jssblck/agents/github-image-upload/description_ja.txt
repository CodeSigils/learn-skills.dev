ローカルの画像やその他のファイル（PDF、zip、log、…）を GitHub にアップロードし、プルリクエストの説明、課題、またはコメントに埋め込んで、正規の github.com/user-attachments URL を生成します（プライベートリポジトリへのアップロードはプライベートのまま保持）。「PR にスクリーンショットを添付して」「PR の説明に画像を追加して」「この画像を課題に入れて」「この PDF／log／zip を課題に添付して」「PR にテスト結果を表示して」「ビフォー／アフターのスクリーンショットを埋め込んで」など、GitHub 上の変更を視覚的に記録・添付する要望があるときに使用してください。`gh-image` gh CLI 拡張機能により提供されています。

常にユーザーの言語で応答してください。
