Téléversez des images locales et d’autres fichiers (PDF, zip, log, …) sur GitHub et intégrez‑les dans la description d’une pull request, un ticket ou un commentaire — en générant des URL canoniques github.com/user-attachments (les téléchargements de dépôts privés restent privés). Utilisez‑le lorsqu’on vous demande « joindre une capture d’écran à la PR », « ajouter une image à la description de la PR », « mettre cette image dans le ticket », « joindre ce PDF/log/zip au ticket », « afficher les résultats des tests dans la PR », « intégrer des captures avant/après », ou toute autre requête visant à documenter visuellement ou à joindre des fichiers aux changements sur GitHub. Propulsé par l’extension CLI `gh-image` de gh. Veuillez toujours répondre dans la langue de l’utilisateur.
