Remettez en question les plans, le code, les conceptions et les décisions générés par l’IA avant de vous engager. Se combine avec toute autre compétence en tant que couche de révision. Utilise l'analyse pré-mortem, la pensée d'inversion et le questionnement socratique pour découvrir ce que l'IA a manqué : les angles morts, les hypothèses cachées, les modes de défaillance et les raccourcis optimistes. La compétence qui demande « êtes-vous sûr de cela ? » donc vous n'êtes pas obligé.
