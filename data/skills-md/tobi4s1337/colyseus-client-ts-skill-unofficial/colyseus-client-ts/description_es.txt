Utilice esta habilidad cuando cree un cliente TypeScript o JavaScript que se conecte a un servidor Colyseus, se una a salas, escuche cambios de estado, envíe mensajes, maneje la reconexión o use @colyseus/sdk. Activador para: cliente Colyseus, unión a sala, devoluciones de llamada de sincronización de estado, Callbacks.get, onAdd, onRemove, escucha, manejo de mensajes, reconexión, SDK de cliente, joinOrCreate, cliente multijugador, cliente de juego en tiempo real, @colyseus/sdk.
