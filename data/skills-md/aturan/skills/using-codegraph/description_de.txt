CodeGraph-First-Code-Exploration. Verwenden Sie diese Option, wenn Sie in einem Repository arbeiten, das möglicherweise von CodeGraph indiziert wird, und Sie Code verstehen, lokalisieren, verfolgen oder lesen müssen, bevor Sie grep/find/rg verwenden oder Dateien öffnen. Suchen Sie im Repository-Stammverzeichnis nach einem .codegraph-Verzeichnis, verwenden Sie das MCP-Tool codegraph_explore, sofern verfügbar, oder den Shell-Befehl codegraph explore und überspringen Sie CodeGraph, wenn kein .codegraph-Verzeichnis vorhanden ist.
