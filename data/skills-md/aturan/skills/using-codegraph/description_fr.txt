Exploration du code CodeGraph-first. À utiliser lorsque vous travaillez dans un référentiel qui peut être indexé par CodeGraph et que vous devez comprendre, localiser, tracer ou lire le code avant d'utiliser grep/find/rg ou d'ouvrir des fichiers. Recherchez un répertoire .codegraph à la racine du référentiel, utilisez l'outil codegraph_explore MCP lorsqu'il est disponible ou la commande shell codegraph explore et ignorez CodeGraph lorsqu'aucun répertoire .codegraph n'existe.
