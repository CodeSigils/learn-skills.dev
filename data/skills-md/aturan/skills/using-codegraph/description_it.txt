Prima esplorazione del codice CodeGraph. Da utilizzare quando si lavora in un repository che può essere indicizzato da CodeGraph ed è necessario comprendere, individuare, tracciare o leggere il codice prima di utilizzare grep/find/rg o aprire file. Verifica la presenza di una directory .codegraph nella root del repository, utilizza lo strumento codegraph_explore MCP quando disponibile o il comando codegraph explore shell e salta CodeGraph quando non esiste alcuna directory .codegraph.
