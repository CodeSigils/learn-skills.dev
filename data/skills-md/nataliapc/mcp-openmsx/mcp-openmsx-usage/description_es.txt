Guía para usar las herramientas mcp-openmsx para controlar y automatizar el emulador openMSX. Úselo cuando interactúe con el emulador openMSX para desarrollar/probar/depurar flujos de trabajo o interacciones que requieran control directo o recuperación de información. Cubre todas las herramientas MCP. NO lo use para tareas generales del agente o cuando no se requiera interacción directa con openMSX.
