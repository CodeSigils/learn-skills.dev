قم بتبسيط وتحسين التعليمات البرمجية لتحقيق الوضوح والاتساق والنمطية وتدفق البيانات ذات النمط الوظيفي وقابلية الصيانة دون تغيير السلوك. يُستخدم عندما يطلب المستخدم التبسيط، أو التنظيف، أو جعل التعليمات البرمجية أكثر أناقة، أو تقليل التعقيد، أو تحسين إمكانية القراءة، أو إعادة بناء الوحدات واحدة تلو الأخرى، أو تقليل الآثار الجانبية، أو تشغيل تمريرة تلميع نهائية على الملفات التي تم لمسها.
