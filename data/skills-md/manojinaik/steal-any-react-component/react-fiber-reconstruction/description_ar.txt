أعد بناء مكونات React من تشغيل مواقع الويب دون الوصول إلى المصدر باستخدام بيانات تعريف React Fiber ولقطات DOM/CSS. يُستخدم لطلبات الاستنساخ/إعادة الإنشاء/الهندسة العكسية في واجهة مستخدم React للإنتاج، بما في ذلك التقاط الدعائم إلى HTML، واستخراج type.toString، والتحقق من النمط الهيكلي والمحسوب، وتكافؤ ورقة الأنماط/الخط، وترتيب التبعية، والخيارات الاحتياطية للرسوم المتحركة أو حالات عدم التطابق التي تعتمد على الحالة.
