Reconstruisez les composants React à partir de sites Web en cours d'exécution sans accès à la source en utilisant les métadonnées React Fiber et les instantanés DOM/CSS. À utiliser pour les requêtes de clonage/recréation/ingénierie inverse sur l'interface utilisateur React de production, y compris la capture d'accessoires vers HTML, l'extraction type.toString, la vérification structurelle et de style calculé, la parité feuille de style/police, l'ordre des dépendances et les solutions de secours pour l'animation ou les incompatibilités basées sur l'état.
