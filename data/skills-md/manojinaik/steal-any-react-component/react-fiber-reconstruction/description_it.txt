Ricostruisci i componenti React dall'esecuzione di siti Web senza accesso alla fonte utilizzando i metadati React Fiber e gli snapshot DOM/CSS. Da utilizzare per richieste di clonazione/ricreazione/reverse engineering sull'interfaccia utente React di produzione, inclusa l'acquisizione da props a HTML, estrazione type.toString, verifica di stile strutturale e computato, parità di fogli di stile/carattere, ordinamento delle dipendenze e fallback per animazioni o mancate corrispondenze guidate dallo stato.
