Créer des métadonnées de l'interface utilisateur ObjectStack : vues (liste/formulaire/kanban/calendrier/gantt), applications (navigation), pages, tableaux de bord, rapports, graphiques, actions. À utiliser lorsque l'utilisateur ajoute des fichiers `*.view.ts` / `*.app.ts` / `*.dashboard.ts` / `*.action.ts` ou conçoit une surface d'interface utilisateur rendue par Studio. Ne pas utiliser pour : le schéma de données (voir objecttack-data), les flux d'écran/assistants interactifs (ceux-ci sont `*.flow.ts` avec `type: 'screen'` — voir objecttack-automation), l'implémentation du moteur de rendu React (vit dans `packages/client-react`, pas dans les métadonnées) ou la propre interface utilisateur d'administration de Studio (fournie avec la plate-forme). Expressions CEL dans les règles de visibilité/conditionnelles : chargez la formule de pile d'objets à côté.
