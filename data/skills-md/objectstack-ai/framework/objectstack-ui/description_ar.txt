البيانات الوصفية لواجهة مستخدم ObjectStack - طرق العرض (قائمة/نموذج/كانبان/تقويم/جانت)، التطبيقات (التنقل)، الصفحات، لوحات المعلومات، التقارير، المخططات، الإجراءات. يُستخدم عندما يقوم المستخدم بإضافة ملفات `*.view.ts` / `*.app.ts` / `*.dashboard.ts` / `*.action.ts` أو تصميم سطح واجهة مستخدم معروض في الاستوديو. لا تستخدمه من أجل: مخطط البيانات (انظر بيانات كائنات)، أو تدفقات/معالجات الشاشة التفاعلية (تلك `*.flow.ts` مع `نوع: 'شاشة'' - راجع أتمتة كائنات مكدس)، أو تنفيذ عارض React (يوجد في `حزم/تفاعل عميل، وليس بيانات وصفية)، أو واجهة المستخدم الإدارية الخاصة بـ Studio (التي تأتي مع النظام الأساسي). تعبيرات CEL في قواعد الرؤية/الشرطية: قم بتحميل صيغة كائنات المكدس جنبًا إلى جنب.
