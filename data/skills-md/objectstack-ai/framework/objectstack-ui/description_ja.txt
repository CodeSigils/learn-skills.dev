ObjectStack UI メタデータの作成 — ビュー (リスト/フォーム/カンバン/カレンダー/ガント)、アプリ (ナビゲーション)、ページ、ダッシュボード、レポート、チャート、アクション。ユーザーが `*.view.ts` / `*.app.ts` / `*.dashboard.ts` / `*.action.ts` ファイルを追加する場合、または Studio でレンダリングされた UI サーフェスを設計する場合に使用します。次の用途には使用しないでください: データ スキーマ (objectstack-data を参照)、インタラクティブな画面フロー/ウィザード (これらは `type: 'screen'` の `*.flow.ts` — objectstack-automation を参照)、React レンダラ実装 (メタデータではなく `packages/client-react` に存在します)、または Studio 独自の管理 UI (プラットフォームに付属)。可視性/条件ルールの CEL 式: objectstack-formula を一緒にロードします。
