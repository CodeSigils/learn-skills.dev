Autor de metadatos de la interfaz de usuario de ObjectStack: vistas (lista/formulario/kanban/calendario/gantt), aplicaciones (navegación), páginas, paneles, informes, gráficos, acciones. Úselo cuando el usuario agrega archivos `*.view.ts` / `*.app.ts` / `*.dashboard.ts` / `*.action.ts` o diseña una superficie de interfaz de usuario renderizada por Studio. No lo use para: esquema de datos (consulte objetostack-data), asistentes/flujos de pantalla interactivos (esos son `*.flow.ts` con `tipo: 'pantalla'`; consulte objectstack-automation), la implementación del renderizador de React (se encuentra en `packages/client-react`, no en metadatos) o la propia interfaz de usuario de administración de Studio (que se incluye con la plataforma). Expresiones CEL en reglas de visibilidad/condicionales: cargar la fórmula de pila de objetos al lado.
