Создание запросов ObjectQL — фильтры, сортировка, разбиение на страницы, агрегирование, объединение/расширение, оконные функции и полнотекстовый поиск. Используйте, когда пользователь пишет выражение DSL запроса, выбирает стратегию разбивки на страницы или разрабатывает спецификацию фильтра представления списка. Не используйте для определения объектов/полей/отношений (см. Objectstack-data) или для разработки конечной точки API, которая предоставляет запрос (см. Objectstack-api).
