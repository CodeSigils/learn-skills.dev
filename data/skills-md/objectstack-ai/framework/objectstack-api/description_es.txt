Diseñe la superficie API del lado del servidor que expone un tiempo de ejecución de ObjectStack: puntos finales REST/GraphQL, proveedores de autenticación, canales en tiempo real, sobres de error, contratos por lotes/versiones. Úselo cuando el usuario agrega `*.endpoint.ts`, configura proveedores de autenticación, define rutas personalizadas o extiende el generador REST/GraphQL. No lo use para: consumir una API ObjectStack de un cliente (que es solo HTTP estándar, no se necesita habilidad); los puntos finales CRUD generados automáticamente (los que se derivan de los datos de la pila de objetos); Sintaxis de consulta del lado de la solicitud (ver consulta de pila de objetos). Expresiones CEL en guardas de ruta o predicados de autenticación: cargue la fórmula de pila de objetos al lado.
