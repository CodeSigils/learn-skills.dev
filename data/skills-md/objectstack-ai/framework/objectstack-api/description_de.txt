Entwerfen Sie die serverseitige API-Oberfläche, die eine ObjectStack-Laufzeit bereitstellt – REST/GraphQL-Endpunkte, Authentifizierungsanbieter, Echtzeitkanäle, Fehlerumschläge, Batch-/Versionierungsverträge. Verwenden Sie diese Option, wenn der Benutzer „*.endpoint.ts“ hinzufügt, Authentifizierungsanbieter konfiguriert, benutzerdefinierte Routen definiert oder den REST/GraphQL-Generator erweitert. Nicht verwenden für: die Nutzung einer ObjectStack-API von einem Client (das ist nur Standard-HTTP – keine Kenntnisse erforderlich); die automatisch generierten CRUD-Endpunkte (die sich aus den Objektstapeldaten ergeben); Anforderungsseitige Abfragesyntax (siehe objecttack-query). CEL-Ausdrücke in Route Guards oder Authentifizierungsprädikaten: Laden Sie die Objectstack-Formel nebenher.
