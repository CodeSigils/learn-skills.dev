صمم سطح واجهة برمجة التطبيقات (API) من جانب الخادم الذي يكشفه وقت تشغيل ObjectStack - نقاط نهاية REST/GraphQL، وموفرو المصادقة، وقنوات الوقت الفعلي، ومغلفات الأخطاء، وعقود الدُفعات/إصدار الإصدارات. يُستخدم عندما يقوم المستخدم بإضافة `*.endpoint.ts` أو تكوين موفري المصادقة أو تعريف المسارات المخصصة أو توسيع منشئ REST/GraphQL. لا تستخدم من أجل: استهلاك ObjectStack API من العميل (وهذا مجرد HTTP قياسي - لا حاجة إلى مهارة)؛ نقاط نهاية CRUD التي يتم إنشاؤها تلقائيًا (تلك التي تتبع بيانات كائنات مكدسة)؛ بناء جملة الاستعلام من جانب الطلب (انظر استعلام الكائنات). تعبيرات CEL في حراس الطريق أو مسندات المصادقة: قم بتحميل صيغة كائنات المكدس جنبًا إلى جنب.
