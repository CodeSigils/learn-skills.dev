Concevez la surface d'API côté serveur exposée par un runtime ObjectStack : points de terminaison REST/GraphQL, fournisseurs d'authentification, canaux en temps réel, enveloppes d'erreur, contrats de lots/versions. À utiliser lorsque l'utilisateur ajoute « *.endpoint.ts », configure des fournisseurs d'authentification, définit des itinéraires personnalisés ou étend le générateur REST/GraphQL. Ne pas utiliser pour : consommer une API ObjectStack à partir d'un client (il s'agit simplement de HTTP standard – aucune compétence requise) ; les points de terminaison CRUD générés automatiquement (ceux qui découlent des données de la pile d'objets) ; Syntaxe de requête côté requête (voir objecttack-query). Expressions CEL dans les gardes de route ou les prédicats d'authentification : chargez la formule de pile d'objets à côté.
