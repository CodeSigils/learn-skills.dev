ObjectStack ランタイムが公開するサーバー側 API サーフェス (REST/GraphQL エンドポイント、認証プロバイダー、リアルタイム チャネル、エラー エンベロープ、バッチ/バージョン管理コントラクト) を設計します。ユーザーが「*.endpoint.ts」を追加する場合、認証プロバイダーを構成する場合、カスタム ルートを定義する場合、または REST/GraphQL ジェネレーターを拡張する場合に使用します。次の用途には使用しないでください: クライアントから ObjectStack API を使用する (これは単なる標準 HTTP であり、スキルは必要ありません)。自動生成された CRUD エンドポイント (objectstack-data から続くもの)。リクエスト側のクエリ構文 (objectstack-query を参照)。ルート ガードまたは認証述語の CEL 式: objectstack-formula を一緒にロードします。
