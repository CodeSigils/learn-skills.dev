Progetta schemi di dati ObjectStack (oggetti, campi, relazioni, convalide, indici, hook del ciclo di vita, autorizzazioni, sicurezza a livello di riga) e i set di dati seed (`defineDataset()`) che caricano dispositivi e fanno riferimento ai dati insieme ad essi. Da utilizzare quando l'utente crea o modifica file `*.object.ts` / `*.seed.ts`, seleziona tipi di campo, modella relazioni, scrive hook `beforeInsert`/`afterUpdate`, configura il controllo di accesso per oggetto o crea dati bootstrap/demo. Non utilizzare per interrogare dati (vedi objectstack-query) o per hook plugin/kernel (vedi objectstack-platform). Espressioni CEL in formule/convalide/regole di condivisione/valori seed dinamici: carica insieme la formula dello stack di oggetti.
