Processus interne pour dogfooding la plate-forme ObjectStack - démarrer un exemple d'application réel (vitrine / CRM) et le piloter dans un navigateur en tant qu'utilisateur ou administrateur réel pour trouver les bogues d'exécution qui manquent les vérifications statiques et les tests unitaires, puis les corriger et les expédier proprement. À utiliser chaque fois que la tâche est « vérifier dans le navigateur », « agir en tant que véritable administrateur/utilisateur », « dogfood l'application Setup/Studio » ou vérifier par le navigateur une modification dans l'application en cours d'exécution. PAS une compétence publiée par le client — il s'agit d'un outil d'agent interne (vit dans .claude/, jamais dans le répertoire `skills/` publié).
