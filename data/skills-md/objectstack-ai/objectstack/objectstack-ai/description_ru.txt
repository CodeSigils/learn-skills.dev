Проектируйте навыки, инструменты, источники знаний, диалоги, записи реестра моделей и интеграцию MCP с помощью ObjectStack AI. Используйте, когда пользователь добавляет `*.skill.ts` / `*.tool.ts`, настраивает поставщика LLM, инструменты агента подключения или индексирует данные ObjectStack в качестве источника знаний для RAG. Сами агенты являются внутренними для платформы («ask» / «build») — третьи стороны расширяют их с помощью навыков и инструментов, а не путем создания «*.agent.ts». Не используйте для общих вопросов LLM, не связанных с метаданными ObjectStack.
