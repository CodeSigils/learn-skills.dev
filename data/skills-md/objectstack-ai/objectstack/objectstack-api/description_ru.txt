Спроектируйте серверную поверхность API, которую предоставляет среда выполнения ObjectStack — конечные точки REST, поставщики аутентификации, каналы реального времени, конверты ошибок, контракты пакетной обработки и управления версиями. Используйте, когда пользователь добавляет `*.endpoint.ts`, настраивает поставщиков аутентификации, определяет собственные маршруты или расширяет генератор REST. Не используйте для: получения API ObjectStack от клиента (это просто стандартный HTTP — никаких навыков не требуется); автоматически сгенерированные конечные точки CRUD (они следуют из данных objectstack); синтаксис запроса на стороне запроса (см. objectstack-query). Выражения CEL в средствах защиты маршрутов или предикатах аутентификации: рядом загружайте формулу стека объектов.
