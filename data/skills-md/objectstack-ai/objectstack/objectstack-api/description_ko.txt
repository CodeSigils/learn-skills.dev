ObjectStack 런타임이 노출하는 서버측 API 표면(REST 끝점, 인증 공급자, 실시간 채널, 오류 봉투, 배치/버전 관리 계약)을 설계합니다. 사용자가 `*.endpoint.ts`를 추가하거나, 인증 공급자를 구성하거나, 사용자 정의 경로를 정의하거나, REST 생성기를 확장할 때 사용합니다. 다음 용도로 사용하지 마십시오: 클라이언트에서 ObjectStack API를 사용하는 경우(단지 표준 HTTP이며 기술이 필요하지 않음) 자동 생성된 CRUD 엔드포인트(objectstack-data를 따르는 엔드포인트) 요청측 쿼리 구문(objectstack-query 참조) 경로 가드 또는 인증 조건자의 CEL 표현식: 개체 스택 공식을 함께 로드합니다.
