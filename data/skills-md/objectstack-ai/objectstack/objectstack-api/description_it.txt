Progetta la superficie API lato server esposta da un runtime ObjectStack: endpoint REST, provider di autenticazione, canali in tempo reale, buste di errore, contratti batch/versioning. Da utilizzare quando l'utente aggiunge `*.endpoint.ts`, configura i provider di autenticazione, definisce percorsi personalizzati o estende il generatore REST. Non utilizzare per: consumare un'API ObjectStack da un client (che è solo HTTP standard, non sono necessarie competenze); gli endpoint CRUD generati automaticamente (quelli seguono da objectstack-data); sintassi della query lato richiesta (vedere objectstack-query). Espressioni CEL nelle guardie del percorso o nei predicati di autenticazione: carica la formula objectstack insieme.
