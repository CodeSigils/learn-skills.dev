GitHub のバックログに対してプロジェクトマネージャーのディスパッチループを実行する：準備ができた課題をトリアージしキューに入れ、各課題を取得して並列開発エージェントにディスパッチし、構造化された JSON レポートを返させ、結果を GitHub と照合して、受理されたプルリクエストをマージへ導く — 人間の判断が本当に必要なものだけをメンテナーにエスカレーションする。ループが各ディスパッチに注入する開発エージェント用の操作テンプレート（カスタムエージェントタイプは不要）と、アプリプロジェクトが検出したプラットフォーム不具合の上流報告手順を提供する。バックログを「処理する」時や「課題をバッチディスパッチする」時、あるいは「派发 issue 给开发 agent」する時、ObjectStack アプリプロジェクトでマルチエージェント配信ループを立ち上げる時、またはアプリ構築中に見つかったプラットフォームバグを報告する時に使用する。ObjectStack のメタデータ作成（ドメインスキルがカバー）や、すでに範囲が決まっている単一の変更を行う場合、あるいはプロジェクト独自の conventions ファイルの代替としては使用しないでください — そのファイルが常に優先されます。
