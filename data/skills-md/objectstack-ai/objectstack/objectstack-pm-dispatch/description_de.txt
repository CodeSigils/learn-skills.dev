Führen Sie eine Projektmanager-Dispatch-Schleife über ein GitHub-Backlog aus: Sortieren Sie Probleme, stellen Sie sie in die Warteschlange, beanspruchen Sie sie, leiten Sie sie an einen parallelen Entwickleragenten weiter, der einen strukturierten JSON-Bericht zurückgibt, prüfen Sie die Ergebnisse mit GitHub und treiben Sie akzeptierte Pull-Anfragen zur Landung – und eskalieren Sie nur das, was wirklich einer menschlichen Entscheidung bedarf, an den Betreuer. Versendet die Entwickler-Agent-Betriebsvorlage, die die Schleife in jeden Versand einfügt (keine benutzerdefinierten Agent-Typen erforderlich) und das Upstream-Berichtsverfahren für Plattformfehler, die ein App-Projekt findet. Wird verwendet, wenn Sie aufgefordert werden, „den Rückstand abzuarbeiten“, „Probleme bei der Stapelverarbeitung zu lösen“, „einen Agenten zu melden“, um eine Multi-Agent-Bereitstellungsschleife in einem ObjectStack-App-Projekt in Gang zu setzen oder um einen Plattformfehler zu melden, der beim Erstellen einer App gefunden wurde. Verwenden Sie es nicht für die Erstellung von ObjectStack-Metadaten (die Domänenkenntnisse decken dies ab), für eine einzelne bereits festgelegte Änderung, die Sie einfach vornehmen können, oder als Ersatz für die projekteigene Konventionsdatei – diese Datei gewinnt immer.
