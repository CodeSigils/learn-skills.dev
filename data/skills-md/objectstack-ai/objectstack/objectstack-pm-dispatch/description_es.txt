Ejecute un ciclo de despacho del administrador de proyectos sobre un trabajo pendiente de GitHub: clasifique y ponga en cola los problemas listos, reclame cada uno, envíelo a un agente desarrollador paralelo que devuelva un informe JSON estructurado, revise los resultados con GitHub y lleve las solicitudes de extracción aceptadas al destino, escalando al mantenedor solo lo que realmente necesita una decisión humana. Envía la plantilla operativa de agente desarrollador que el bucle inyecta en cada envío (no se requieren tipos de agentes personalizados) y el procedimiento de informes ascendentes para los defectos de plataforma que encuentre un proyecto de aplicación. Úselo cuando se le solicite "trabajar en el trabajo pendiente", "problemas de envío de lotes", "problema de problema de agente", para activar un ciclo de entrega de múltiples agentes en un proyecto de aplicación ObjectStack o para informar un error de plataforma encontrado mientras se crea una aplicación. No lo use para crear metadatos de ObjectStack (las habilidades del dominio cubren eso), para un único cambio ya definido que puede simplemente realizar, o como reemplazo del propio archivo de convenciones del proyecto; ese archivo siempre gana.
