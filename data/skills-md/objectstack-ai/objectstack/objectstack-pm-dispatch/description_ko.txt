GitHub 백로그에 대해 프로젝트 관리자 디스패치 루프를 실행합니다. 준비된 문제를 분류 및 큐에 넣고, 각 문제를 요청하고, 구조화된 JSON 보고서를 반환하는 병렬 개발자 에이전트에 디스패치하고, GitHub에 대한 결과를 검토하고, 승인된 풀 요청을 랜딩으로 유도하여 실제로 사람의 결정이 필요한 사항만 유지관리자에게 에스컬레이션합니다. 루프가 모든 디스패치에 주입하는 개발자-에이전트 운영 템플릿(사용자 지정 에이전트 유형 필요 없음)과 앱 프로젝트에서 발견한 플랫폼 결함에 대한 업스트림 보고 절차를 제공합니다. "백로그 작업", "일괄 디스패치 문제", "에이전트 문제", ObjectStack 앱 프로젝트에서 다중 에이전트 전달 루프를 시작하거나 앱을 빌드하는 동안 발견된 플랫폼 버그를 보고하라는 요청을 받을 때 사용합니다. ObjectStack 메타데이터 작성(도메인 기술에서 이를 다루고 있음), 이미 범위가 지정된 단일 변경을 수행하거나 프로젝트 자체 규칙 파일을 대체하는 데 사용하지 마십시오. 해당 파일이 항상 승리합니다.
