Diseñe esquemas de datos de ObjectStack (objetos, campos, reglas condicionales de campo, relaciones, validaciones, índices, enlaces de ciclo de vida, permisos, seguridad a nivel de fila) y las semillas ("defineSeed()`) que cargan elementos fijos y datos de referencia junto con ellos. Úselo cuando el usuario está creando o modificando archivos `*.object.ts`/`*.seed.ts`, seleccionando tipos de campos, modelando relaciones, escribiendo ganchos `beforeInsert`/`afterUpdate`, configurando el control de acceso por objeto o creando datos de arranque/demo. Úselo para las reglas `visibleWhen` / `readonlyWhen` / `requiredWhen` que pertenecen a los campos. No lo utilice para consultar datos (consulte objecttack-query) ni para complementos/enganches de kernel (consulte objecttack-platform). Expresiones CEL en fórmulas/validaciones/reglas para compartir/valores iniciales dinámicos: cargue la fórmula de pila de objetos al lado.
