Cree consultas ObjectQL: filtros, clasificación, paginación, agregación, expansión de relaciones y búsqueda de texto completo. Se utiliza cuando el usuario escribe una expresión DSL de consulta, selecciona una estrategia de paginación o diseña una especificación de filtro de vista de lista. No lo use para definir objetos/campos/relaciones (ver objetostack-data) o para diseñar el punto final de API que expone una consulta (ver objetostack-api).
