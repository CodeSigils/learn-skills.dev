Costruisci query ObjectQL: filtri, ordinamento, impaginazione, aggregazione, espansione delle relazioni e ricerca full-text. Da utilizzare quando l'utente scrive un'espressione DSL di query, sceglie la strategia di impaginazione o progetta le specifiche del filtro di una visualizzazione elenco. Non utilizzare per definire oggetti/campi/relazioni (vedi objectstack-data) o per progettare l'endpoint API che espone una query (vedi objectstack-api).
