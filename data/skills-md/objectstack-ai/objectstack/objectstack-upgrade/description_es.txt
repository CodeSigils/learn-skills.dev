Actualice un proyecto de metadatos de ObjectStack a través de un protocolo principal: ejecute la cadena de conversión determinista, luego trabaje con el residuo semántico que la cadena no puede expresar (elecciones de intención, código personalizado en API retiradas, prosa obsoleta) hasta una decisión con el propietario del proyecto y finalice con una "validación" verde más un informe de actualización legible por humanos. Úselo cuando un proyecto tiene un protocolo principal más antiguo y debe pasar al actual, cuando `@objectstack/spec` se cruzó con un protocolo principal y los metadatos o el código dejaron de analizarse, cuando un error de análisis o `tsc` cita una prescripción `[ELIMINADA]`, o cuando se le solicita "actualizar a v17" / "升级到 v17" / "一键升级元数据项目". No lo utilice para crear nuevos metadatos (las habilidades de dominio cubren eso), para diseñar un retiro en el repositorio de la plataforma ObjectStack (que es el manual interno de la plataforma) o para escribir a mano una reescritura que la cadena de conversión ya aplica; ejecutar la cadena es siempre el primer paso, nunca un respaldo.
