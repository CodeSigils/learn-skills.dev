Autor de metadatos de UI de ObjectStack: vistas (lista/formulario/kanban/calendario/gantt), aplicaciones (navegación), páginas (estructuradas más los niveles de creación de código fuente de HTML y React, ADR-0080/0081), paneles, informes, gráficos, acciones y documentos de paquete (`src/docs/*.md`). Úselo cuando el usuario agrega archivos `*.view.ts` / `*.app.ts` / `*.dashboard.ts` / `*.action.ts` / `src/docs/*.md` o diseña una superficie de interfaz de usuario renderizada por Studio, incluidos widgets de informes/paneles vinculados al conjunto de datos. No lo use para: esquema de datos (ver objetostack-data), flujos de pantalla interactivos/asistentes (esos son `*.flow.ts` con `tipo: 'pantalla'` - ver objectstack-automation), la implementación del renderizador de React (se encuentra en `packages/client-react`, no en metadatos), o la propia interfaz de usuario de administración de Studio (que se envía con la plataforma). Expresiones CEL en reglas de visibilidad/condicionales: cargar la fórmula de pila de objetos al lado.
