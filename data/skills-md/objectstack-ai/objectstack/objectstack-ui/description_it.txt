Autore dei metadati dell'interfaccia utente ObjectStack: visualizzazioni (elenco/modulo/kanban/calendario/gantt), app (navigazione), pagine (strutturate più livelli di creazione di sorgenti HTML e React, ADR-0080/0081), dashboard, report, grafici, azioni e documenti del pacchetto (`src/docs/*.md`). Da utilizzare quando l'utente aggiunge file `*.view.ts` / `*.app.ts` / `*.dashboard.ts` / `*.action.ts` / `src/docs/*.md` o progetta una superficie dell'interfaccia utente renderizzata in Studio, inclusi widget di dashboard/report associati a set di dati. Non utilizzare per: schema di dati (vedi objectstack-data), flussi di schermo interattivi/procedure guidate (quelli sono `*.flow.ts` con `type: 'screen'` — vedi objectstack-automation), l'implementazione del renderer React (risiede in `packages/client-react`, non nei metadati) o l'interfaccia utente di amministrazione di Studio (fornita con la piattaforma). Espressioni CEL nelle regole di visibilità/condizionali: carica la formula dello stack di oggetti insieme.
