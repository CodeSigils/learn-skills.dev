创作 ObjectStack UI 元数据 — 视图（列表/表单/看板/日历/甘特图）、应用程序（导航）、页面（结构化加上 HTML 和 React 源创作层，ADR-0080/0081）、仪表板、报告、图表、操作和包文档 (`src/docs/*.md`)。当用户添加 `*.view.ts` / `*.app.ts` / `*.dashboard.ts` / `*.action.ts` / `src/docs/*.md` 文件或设计 Studio 渲染的 UI 界面（包括数据集绑定的仪表板/报告小部件）时使用。请勿用于：数据模式（请参阅 objectstack-data）、交互式屏幕流程/向导（这些是带有 `type: 'screen'` 的 `*.flow.ts` — 请参阅 objectstack-automation）、React 渲染器实现（位于 `packages/client-react` 中，而不是元数据中）或 Studio 自己的管理 UI（随平台一起提供）。可见性/条件规则中的 CEL 表达式：同时加载对象堆栈公式。
