البيانات الوصفية لواجهة مستخدم ObjectStack - طرق العرض (القائمة/النموذج/kanban/calendar/gantt)، والتطبيقات (التنقل)، والصفحات (منظم بالإضافة إلى طبقات تأليف مصدر HTML وReact، ADR-0080/0081)، ولوحات المعلومات، والتقارير، والمخططات، والإجراءات، ومستندات الحزمة (`src/docs/*.md`). يُستخدم عندما يقوم المستخدم بإضافة ملفات `*.view.ts` / `*.app.ts` / `*.dashboard.ts` / `*.action.ts` / `src/docs/*.md` أو تصميم سطح واجهة مستخدم معروض في الاستوديو، بما في ذلك أدوات لوحة المعلومات/التقرير المرتبطة بمجموعة البيانات. لا تستخدمه من أجل: مخطط البيانات (انظر بيانات كائنات)، أو تدفقات/معالجات الشاشة التفاعلية (تلك هي `*.flow.ts` مع `نوع: 'شاشة'' - راجع أتمتة كائنات مكدس)، أو تنفيذ عارض React (يعيش في `الحزم/تفاعل العميل`، وليس البيانات الوصفية)، أو واجهة المستخدم الإدارية الخاصة بـ Studio (التي تأتي مع النظام الأساسي). تعبيرات CEL في قواعد الرؤية/الشرطية: قم بتحميل صيغة كائنات المكدس جنبًا إلى جنب.
