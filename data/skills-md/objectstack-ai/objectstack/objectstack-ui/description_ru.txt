Создание метаданных пользовательского интерфейса ObjectStack — представления (список/форма/канбан/календарь/гантт), приложения (навигация), страницы (структурированные плюс уровни создания исходного кода HTML и React, ADR-0080/0081), информационные панели, отчеты, диаграммы, действия и документы пакета (`src/docs/*.md`). Используйте, когда пользователь добавляет файлы `*.view.ts` / `*.app.ts` / `*.dashboard.ts` / `*.action.ts` / `src/docs/*.md` или разрабатывает поверхность пользовательского интерфейса, отображаемую в Studio, включая виджеты информационной панели/отчета с привязкой к набору данных. Не используйте для: схемы данных (см. objectstack-data), интерактивных экранных потоков/мастеров (это `*.flow.ts` с `type: 'screen'` — см. Objectstack-automation), реализации средства рендеринга React (находится в `packages/client-react`, а не в метаданных) или собственного пользовательского интерфейса администратора Studio (который поставляется с платформой). Выражения CEL в правилах видимости/условных правилах: рядом загружайте формулу стека объектов.
