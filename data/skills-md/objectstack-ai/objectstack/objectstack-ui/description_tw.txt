建立 ObjectStack UI 元資料 — 視圖（清單/表單/看板/日曆/甘特圖）、應用程式（導覽）、頁面（結構化加上 HTML 和 React 來源創作層，ADR-0080/0081）、儀表板、報表、圖表、操作和套件文件 (`src/docs/*.md`)。當使用者新增 `*.view.ts` / `*.app.ts` / `*.dashboard.ts` / `*.action.ts` / `src/docs/*.md` 檔案或設計 Studio 渲染的 UI 介面（包括資料集綁定的儀表板/報告小工具）時使用。請勿用於：資料模式（請參閱 objectstack-data）、互動式螢幕流程/精靈（這些是帶有 `type: 'screen'` 的 `*.flow.ts` — 請參閱 objectstack-automation）、React 渲染器實作（位於 `packages/client-react` 中，而不是在元資料中的 UI 一起管理）。可見性/條件規則中的 CEL 表達式：同時載入物件堆疊公式。
