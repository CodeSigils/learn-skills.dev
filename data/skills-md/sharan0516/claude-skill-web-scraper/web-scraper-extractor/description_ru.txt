Используйте этот навык для извлечения структурированных данных (контакты, выпускники, посетители, интересы, списки и т. д.) с любого веб-сайта в файл CSV с помощью браузера Playwright MCP. Активируйте этот навык всякий раз, когда пользователь хочет очистить, извлечь, собрать или экспортировать записи с URL-адреса, включая соединения LinkedIn, каталоги выпускников, списки участников конференций, страницы мероприятий, каталоги участников, списки компаний или любые веб-данные с разбивкой на страницы. Используйте этот навык, даже если пользователь просто говорит «сохранить все записи с этой страницы в CSV», «извлечь контактную информацию с этого сайта», «экспортировать эти результаты» или упоминает использование нескольких поисковых запросов в каталоге.
Требуется: Сервер Playwright MCP должен быть подключен и активен.
