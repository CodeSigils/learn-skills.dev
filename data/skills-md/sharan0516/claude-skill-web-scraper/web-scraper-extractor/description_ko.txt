이 기술을 사용하면 Playwright MCP 브라우저를 사용하여 모든 웹 사이트의 구조화된 데이터(연락처, 졸업생, 참석자, 리드, 목록 등)를 CSV 파일로 추출할 수 있습니다. 사용자가 LinkedIn 연결, 동문 디렉터리, 컨퍼런스 참석자 목록, 이벤트 페이지, 회원 디렉터리, 회사 목록 또는 페이지가 매겨진 웹 데이터를 포함하여 URL에서 기록을 스크랩, 추출, 수집 또는 내보내려고 할 때마다 이 기술을 트리거합니다. 사용자가 "이 페이지의 모든 항목을 CSV로 가져오기", "이 사이트에서 연락처 정보 가져오기", "이 결과 내보내기"라고 말하거나 디렉터리에서 여러 검색어를 실행한다고 언급하는 경우에도 이 기술을 사용하세요.
요구 사항: Playwright MCP 서버가 연결되어 활성화되어야 합니다.
