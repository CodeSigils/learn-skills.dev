Utilizza questa competenza per estrarre dati strutturati (contatti, ex studenti, partecipanti, lead, elenchi, ecc.) da qualsiasi sito Web in un file CSV utilizzando il browser Playwright MCP. Attiva questa abilità ogni volta che l'utente desidera recuperare, estrarre, raccogliere o esportare record da un URL, comprese connessioni LinkedIn, directory di ex studenti, elenchi di partecipanti a conferenze, pagine di eventi, directory di membri, elenchi di aziende o qualsiasi dato Web impaginato. Utilizza questa capacità anche se l'utente dice semplicemente "prendi tutte le voci da questa pagina in un CSV", "estrai informazioni di contatto da questo sito", "esporta questi risultati" o menziona l'esecuzione di più termini di ricerca in una directory.
Richiede: il server MCP di Playwright sia connesso e attivo.
