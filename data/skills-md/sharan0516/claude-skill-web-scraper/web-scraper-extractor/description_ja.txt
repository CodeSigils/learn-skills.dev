このスキルを使用すると、Playwright MCP ブラウザを使用して、任意の Web サイトから構造化データ (連絡先、卒業生、出席者、リード、リストなど) を CSV ファイルに抽出できます。ユーザーが URL からレコード (LinkedIn 接続、同窓会ディレクトリ、会議出席者リスト、イベント ページ、メンバーシップ ディレクトリ、企業リスト、ページ分割された Web データなど) をスクレイピング、抽出、収集、またはエクスポートしたいときにこのスキルをトリガーします。ユーザーが単に「このページからすべてのエントリを CSV に取得する」、「このサイトから連絡先情報を取得する」、「これらの結果をエクスポートする」と言っただけの場合、またはディレクトリ全体で複数の検索語を実行することに言及した場合でも、このスキルを使用します。
必要なもの: Playwright MCP サーバーが接続され、アクティブであること。
