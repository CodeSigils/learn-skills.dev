Utilice esta habilidad para extraer datos estructurados (contactos, ex alumnos, asistentes, clientes potenciales, listados, etc.) de cualquier sitio web a un archivo CSV utilizando el navegador Playwright MCP. Active esta habilidad siempre que el usuario quiera extraer, recopilar o exportar registros de una URL, incluidas conexiones de LinkedIn, directorios de ex alumnos, listas de asistentes a conferencias, páginas de eventos, directorios de miembros, listados de empresas o cualquier dato web paginado. Utilice esta habilidad incluso si el usuario simplemente dice "tomar todas las entradas de esta página en un CSV", "extraer información de contacto de este sitio", "exportar estos resultados" o menciona la ejecución de varios términos de búsqueda en un directorio.
Requiere: El servidor Playwright MCP debe estar conectado y activo.
