Utilisez cette compétence pour extraire des données structurées (contacts, anciens élèves, participants, prospects, listes, etc.) de n'importe quel site Web vers un fichier CSV à l'aide du navigateur Playwright MCP. Déclenchez cette compétence chaque fois que l'utilisateur souhaite récupérer, extraire, collecter ou exporter des enregistrements à partir d'une URL, y compris les connexions LinkedIn, les annuaires d'anciens élèves, les listes de participants à une conférence, les pages d'événements, les annuaires de membres, les listes d'entreprises ou toute autre donnée Web paginée. Utilisez cette compétence même si l'utilisateur dit simplement « récupérez toutes les entrées de cette page dans un fichier CSV », « extrayez les informations de contact de ce site », « exportez ces résultats » ou mentionne l'exécution de plusieurs termes de recherche dans un répertoire.
Nécessite : Le serveur Playwright MCP doit être connecté et actif.
