Verwenden Sie diese Fähigkeit, um strukturierte Daten (Kontakte, Alumni, Teilnehmer, Leads, Einträge usw.) von einer beliebigen Website mit dem Playwright MCP-Browser in eine CSV-Datei zu extrahieren. Lösen Sie diesen Skill aus, wann immer der Benutzer Datensätze aus einer URL extrahieren, extrahieren, sammeln oder exportieren möchte – einschließlich LinkedIn-Verbindungen, Alumni-Verzeichnissen, Konferenzteilnehmerlisten, Veranstaltungsseiten, Mitgliederverzeichnissen, Firmeneinträgen oder anderen paginierten Webdaten. Verwenden Sie diese Fähigkeit auch dann, wenn der Benutzer nur sagt: „Alle Einträge dieser Seite in eine CSV-Datei übertragen“, „Kontaktinformationen von dieser Website abrufen“, „Diese Ergebnisse exportieren“ oder die Ausführung mehrerer Suchbegriffe in einem Verzeichnis erwähnt.
Erfordert: Playwright MCP-Server muss verbunden und aktiv sein.
