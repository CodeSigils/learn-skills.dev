노트 관리 및 지식 기반 작업을 지원하는 통합 IMA OpenAPI 기술입니다.  
사용자가 지식 베이스, 데이터 저장소, 메모, 메모, 저널 항목을 언급하거나 파일 업로드, 지식 베이스에 웹 페이지 추가, 지식 베이스 콘텐츠 검색 또는 노트 검색/탐색/생성/편집을 원할 때 이 기술을 사용해야 합니다.  
사용자가 "지식 베이스" 또는 "메모"를 명시적으로 말하지 않더라도 지식 베이스에 파일 업로드, 웹 페이지 북마크 지정, 지식 검색 또는 개인 문서 액세스(예: "이 내용을 기록하도록 도와주세요", "XX에 대한 지식 베이스 검색")와 관련된 의도라면 이 기술이 트리거되어야 합니다.  

항상 사용자의 언어로 응답하시기 바랍니다.
