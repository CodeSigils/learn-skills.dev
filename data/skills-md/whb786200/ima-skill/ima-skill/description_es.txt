Habilidad unificada de IMA OpenAPI, que admite la gestión de notas y las operaciones de la base de conocimientos.  
Cuando un usuario menciona una base de conocimientos, un repositorio de datos, notas, memorandos, entradas de diario o desea cargar archivos, agregar páginas web a la base de conocimientos, buscar contenido de la base de conocimientos o buscar/explorar/crear/editar notas, se debe utilizar esta habilidad.  
Incluso si el usuario no dice explícitamente "base de conocimientos" o "notas", siempre que la intención implique cargar archivos a una base de conocimientos, marcar páginas web, realizar búsquedas de conocimientos o acceder a documentos personales (por ejemplo, "ayúdame a anotar esto", "buscar XX en la base de conocimientos"), se debe activar esta habilidad.  

Por favor responda siempre en el idioma del usuario.
