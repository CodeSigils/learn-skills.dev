Unified IMA OpenAPI skill, supporting note management and knowledge‑base operations.  
When a user mentions a knowledge base, data repository, notes, memos, journal entries, or wants to upload files, add web pages to the knowledge base, search knowledge‑base content, or search/browse/create/edit notes, this skill should be used.  
Even if the user does not explicitly say “knowledge base” or “notes,” as long as the intent involves uploading files to a knowledge base, bookmarking webpages, knowledge search, or personal document access (e.g., “help me note this,” “search the knowledge base for XX”), this skill should be triggered.  

Please always respond in the user's language.
