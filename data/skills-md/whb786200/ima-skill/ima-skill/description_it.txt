Competenza IMA OpenAPI unificata, che supporta la gestione delle note e le operazioni della knowledge base.  
Quando un utente menziona una knowledge base, un archivio di dati, note, promemoria, voci di diario o desidera caricare file, aggiungere pagine Web alla knowledge base, cercare contenuto della knowledge base o cercare/sfogliare/creare/modificare note, è necessario utilizzare questa abilità.  
Anche se l'utente non dice esplicitamente "knowledge base" o "note", purché l'intento implichi il caricamento di file in una knowledge base, l'aggiunta di segnalibri a pagine Web, la ricerca della conoscenza o l'accesso a documenti personali (ad esempio, "aiutami a notare questo", "cerca XX nella knowledge base"), questa abilità dovrebbe essere attivata.  

Si prega di rispondere sempre nella lingua dell'utente.
