Utilice ExStruct CLI para validar, inspeccionar, crear y editar libros de Excel de forma segura. Se activa cuando un agente necesita "parche de exstruct", "make de exstruct", "validación de exstruct", "lista de operaciones de exstruct" o "descripción de operaciones de exstruct", especialmente para decisiones de creación versus edición, flujos de trabajo de prueba, restricciones de backend o orientación segura para la edición de libros.
