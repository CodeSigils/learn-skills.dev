Utilisez ExStruct CLI pour valider, inspecter, créer et modifier des classeurs Excel en toute sécurité. Déclenchez-le lorsqu'un agent a besoin de « exstruct patch », « exstruct make », « exstruct validate », « exstruct ops list » ou « exstruct ops décrivant », en particulier pour les décisions de création ou d'édition, les workflows d'exécution à sec, les contraintes backend ou les conseils d'édition sécurisés des classeurs.
