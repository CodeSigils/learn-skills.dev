**Vue2 フロントエンド コード レビューの専門スキルは、ユーザーが次のいずれかに言及したときにすぐに使用する必要があります。**  
- コードレビュー、コードレビュー、CR  
- 送信前チェック、マージ前レビュー、PR レビュー  
- コード品質チェック、コードスタイルチェック  
- Vue2 コード監査、フロントエンド コード レビュー  
- Git 変更コードレビュー、ステージングエリアコードチェック  

**主な機能:**  
- レビューを「src」ディレクトリに厳密に制限し、それを超えないでください。  
- コード スタイル、ベスト プラクティス、コンポーネント仕様、命名、ネットワーク リクエスト、計算エラー、論理エラー、セキュリティ、絶対禁止項目の 9 つの主要なレビューの側面をカバーします。  
- 3 段階の重大度グレーディング: 🔴 重大 / 🟡 中 / 🟢 軽度  
- レビューチェックリストを生成し、結果をディメンションごとに表示します  
- **コードは決して変更しないでください** (レビューのみ。修正には明示的なユーザーのリクエストが必要です)  
- Vue3/React プロジェクトは自動的に認識され、処理が拒否されます。
