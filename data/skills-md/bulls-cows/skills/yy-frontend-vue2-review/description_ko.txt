**Vue2 프런트 엔드 코드 검토 전문 기술은 사용자가 다음 중 하나를 언급할 때마다 즉시 사용해야 합니다.**  
- 코드리뷰, 코드리뷰, CR  
- 제출 전 확인, 병합 전 검토, PR 검토  
- 코드 품질 점검, 코드 스타일 점검  
- Vue2 코드 감사, 프런트엔드 코드 검토  
- Git 변경 코드 검토, 준비 지역 코드 확인  

**핵심 기능:**  
- 검토를 `src` 디렉토리로 엄격하게 제한하고 그 이상으로 넘어가지 마십시오.  
- 코드 스타일, 모범 사례, 구성 요소 사양, 이름 지정, 네트워크 요청, 계산, 논리적 오류, 보안, 절대 금지 항목 등 9가지 주요 검토 차원을 다룹니다.  
- 3단계 심각도 등급: 🔴심각 / 🟡중간 / 🟢사소함  
- 검토 체크리스트를 생성하여 차원별 결과를 제시합니다.  
- **코드를 수정하지 마세요**(검토만 가능하며 수정하려면 명시적인 사용자 요청이 필요함)  
- Vue3/React 프로젝트는 자동으로 인식되어 처리가 거부됩니다.
