**Специальный навык Vue2 Front-End Code Review: как только пользователь упоминает что-либо из следующего, этот навык должен быть немедленно использован:**  
- Проверка кода, проверка кода, CR  
- Проверка перед принятием решения, проверка перед слиянием, проверка PR  
- Проверка качества кода, проверка стандарта кода  
- Аудит кода Vue2, проверка кода внешнего интерфейса.  
- Проверка кода разницы в Git, поэтапная проверка кода города.  

**Основные характеристики:**  
- Строго ограничен просмотром в каталоге `src` и никогда не выходит за его пределы.  
- Охватывает 9 основных аспектов проверки: стиль кода, лучшие практики, стандарты компонентов, именование, сетевые запросы, вычисления, логические ошибки, безопасность, абсолютно запрещенные элементы.  
- Трехуровневая степень тяжести: 🔴 тяжелая / 🟡 средняя / 🟢 незначительная.  
- Создает контрольный список проверки, представляя результаты по каждому измерению.  
- **Никогда не изменяет код** (только проверка; исправления требуют явного запроса пользователя).  
- Проекты Vue3/React автоматически распознаются и отклоняются для обработки.
