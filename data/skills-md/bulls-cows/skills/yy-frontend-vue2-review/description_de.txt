**Vue2 Front-End Code Review Specialized Skill, muss sofort verwendet werden, wenn der Benutzer eines der folgenden Dinge erwähnt:**  
- Codeüberprüfung, Codeüberprüfung, CR  
- Pre-Submit-Check, Pre-Merge-Review, PR-Review  
- Codequalitätsprüfung, Codestilprüfung  
- Vue2-Code-Audit, Front-End-Code-Überprüfung  
- Git hat die Codeüberprüfung und die Überprüfung des Staging-Bereichscodes geändert  

**Hauptfunktionen:**  
- Beschränken Sie die Überprüfung strikt auf das Verzeichnis „src“ und gehen Sie niemals darüber hinaus  
- Deckt 9 wichtige Überprüfungsdimensionen ab: Codestil, Best Practices, Komponentenspezifikationen, Benennung, Netzwerkanforderungen, berechnet, logische Fehler, Sicherheit, absolut verbotene Elemente  
- Dreistufige Schweregradeinstufung: 🔴 Schwer / 🟡 Mittel / 🟢 Gering  
- Erstellt eine Überprüfungscheckliste, in der die Ergebnisse Dimension für Dimension präsentiert werden  
- **Niemals Code ändern** (nur Überprüfung; Korrekturen erfordern eine explizite Benutzeranfrage)  
- Vue3/React-Projekte werden automatisch erkannt und zur Bearbeitung abgelehnt
