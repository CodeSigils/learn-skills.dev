**Vue2 Front-End Code Review Specialized Skill, must be used immediately whenever the user mentions any of the following:**  
- Code review, Code Review, CR  
- Pre-submit check, pre-merge review, PR review  
- Code quality check, code style check  
- Vue2 code audit, front-end code review  
- Git changed code review, staging area code check  

**Core Features:**  
- Strictly limit the review to the `src` directory, never go beyond it  
- Covers 9 major review dimensions: code style, best practices, component specifications, naming, network requests, computed, logical errors, security, absolutely prohibited items  
- Three-level severity grading: 🔴 Severe / 🟡 Medium / 🟢 Minor  
- Generates a review checklist, presenting results dimension by dimension  
- **Never modify code** (only review; fixes require explicit user request)  
- Vue3/React projects are automatically recognized and rejected for processing
