Aiuta gli utenti a creare commit Git standardizzati. Utilizza questa competenza quando l'utente desidera inviare codice, salvare modifiche, creare un commit o dire cose come "invia codice", "applica queste modifiche", "applica codice", "salva su git", "esegui commit" ecc. Questa abilità analizza le modifiche del codice, comprende l'intento delle modifiche nel contesto della conversazione, genera messaggi di commit cinesi nel formato convenzionale (tipo (ambito): descrizione) e seleziona in modo intelligente i file da mettere in scena. Anche se l'utente dice semplicemente "commit" o "commit", questa abilità dovrebbe essere utilizzata per garantire la qualità del messaggio di commit.
