Aiuta gli utenti a creare commit Git standardizzati. Utilizza questa abilità quando l'utente desidera eseguire il commit del codice, salvare le modifiche, creare un commit o dire cose come "commit codice", "commit queste modifiche", "commit codice", "salva su git", "commit" o simili. Questa competenza analizza le modifiche al codice, comprende l'intento delle modifiche dal contesto della conversazione, genera messaggi di commit cinesi nel formato convenzionale (tipo (ambito): descrizione) e seleziona in modo intelligente i file da mettere in stage. Anche se l'utente dice semplicemente "commit" o "commit", utilizza questa abilità per garantire la qualità del messaggio di commit.
