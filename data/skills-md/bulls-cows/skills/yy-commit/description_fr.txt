Aidez les utilisateurs à créer des commits Git standardisés. Utilisez cette compétence lorsque l'utilisateur souhaite valider du code, enregistrer des modifications, créer une validation ou dire des choses telles que « code de validation », « valider ces modifications », « code de validation », « enregistrer dans git », « valider » ou similaire. Cette compétence analyse les modifications de code, comprend l'intention des modifications à partir du contexte de la conversation, génère des messages de validation chinois au format conventionnel (type (portée) : description) et sélectionne intelligemment les fichiers à mettre en scène. Même si l'utilisateur dit simplement « valider » ou « commit », utilisez cette compétence pour garantir des messages de validation de haute qualité.
