Helfen Sie Benutzern, standardisierte Git-Commits zu erstellen. Verwenden Sie diese Fähigkeit, wenn der Benutzer Code festschreiben, Änderungen speichern, einen Commit erstellen oder Dinge wie „Code festschreiben“, „diese Änderungen festschreiben“, „Code festschreiben“, „in Git speichern“, „festschreiben“ oder ähnliches sagen möchte. Diese Fähigkeit analysiert Codeänderungen, versteht die Absicht der Änderungen aus dem Konversationskontext, generiert chinesische Commit-Nachrichten im herkömmlichen Format (Typ(Bereich): Beschreibung) und wählt auf intelligente Weise Dateien für die Bereitstellung aus. Auch wenn der Benutzer einfach „commit“ oder „commit“ sagt, nutzen Sie diese Fähigkeit, um die Qualität der Commit-Nachricht sicherzustellen.
