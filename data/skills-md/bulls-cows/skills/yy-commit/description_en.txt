Help users create standardized Git commits. Use this skill when the user wants to commit code, save changes, create a commit, or says things like "commit code," "commit these changes," "commit code," "save to git," "commit," or similar. This skill analyzes code changes, understands the intent of the modifications from the conversation context, generates Chinese commit messages in the conventional format (type(scope): description), and intelligently selects files to stage. Even if the user simply says "commit" or "commit," use this skill to ensure the quality of the commit message.
