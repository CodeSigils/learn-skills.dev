Ayude a los usuarios a crear confirmaciones de Git estandarizadas. Utilice esta habilidad cuando el usuario quiera confirmar código, guardar cambios, crear una confirmación o decir cosas como "confirmar código", "confirmar estos cambios", "confirmar código", "guardar en git", "confirmar" o similar. Esta habilidad analiza los cambios de código, comprende la intención de las modificaciones desde el contexto de la conversación, genera mensajes de confirmación en chino en el formato convencional (tipo (alcance): descripción) y selecciona de manera inteligente los archivos para preparar. Incluso si el usuario simplemente dice "confirmar" o "comprometer", utilice esta habilidad para garantizar la calidad del mensaje de confirmación.
