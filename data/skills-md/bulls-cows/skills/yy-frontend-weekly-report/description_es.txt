Habilidad de redacción de informes semanales. Se activa cuando el usuario dice "escribir informe semanal", "generar informe semanal", "informe de trabajo de esta semana" o "resumir el trabajo de esta semana". Lee automáticamente el historial de confirmaciones de git de esta semana, lo clasifica en desarrollo de funciones, optimización de código, corrección de errores, etc., y genera un informe semanal estructurado. Ideal para desarrolladores que necesitan generar rápidamente informes semanales.
