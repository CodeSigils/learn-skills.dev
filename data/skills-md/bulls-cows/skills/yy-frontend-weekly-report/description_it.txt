Abilità nella stesura di report settimanali. Si attiva quando l'utente dice "scrivi rapporto settimanale", "genera rapporto settimanale", "rapporto di lavoro di questa settimana" o "riassumi il lavoro di questa settimana". Legge automaticamente la cronologia dei commit git di questa settimana, la classifica in sviluppo di funzionalità, ottimizzazione del codice, correzioni di bug, ecc. e genera un report settimanale strutturato. Ideale per gli sviluppatori che necessitano di generare rapidamente report settimanali.
