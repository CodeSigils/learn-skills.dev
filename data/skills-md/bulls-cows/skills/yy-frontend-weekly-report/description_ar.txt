مهارة كتابة التقارير الأسبوعية. يتم تشغيله عندما يقول المستخدم "اكتب تقريرًا أسبوعيًا" أو "أنشئ تقريرًا أسبوعيًا" أو "تقرير العمل لهذا الأسبوع" أو "لخص عمل هذا الأسبوع". يقرأ تلقائيًا سجل التزام git لهذا الأسبوع، ويصنفه حسب تطوير الميزات، وتحسين التعليمات البرمجية، وإصلاحات الأخطاء، وما إلى ذلك، وإخراج تقرير منظم. مثالية للمطورين الذين يحتاجون إلى إنشاء تقارير أسبوعية بسرعة.
