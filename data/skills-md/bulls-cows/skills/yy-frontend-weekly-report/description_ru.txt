Навык написания еженедельных отчетов. Срабатывает, когда пользователь говорит «написать еженедельный отчет», «создать еженедельный отчет», «отчет о работе на этой неделе» или «подвести итоги работы на этой неделе». Автоматически считывает историю коммитов git за эту неделю, распределяет ее по категориям разработки функций, оптимизации кода, исправления ошибок и т. д. и выводит структурированный еженедельный отчет. Идеально подходит для разработчиков, которым необходимо быстро создавать еженедельные отчеты.
