Compétence en rédaction de rapports hebdomadaires. Déclenché lorsque l'utilisateur dit « rédiger un rapport hebdomadaire », « générer un rapport hebdomadaire », « le rapport de travail de cette semaine » ou « résumer le travail de cette semaine ». Lit automatiquement l'historique des commits git de cette semaine, le classe en développement de fonctionnalités, optimisation de code, corrections de bogues, etc., et génère un rapport hebdomadaire structuré. Idéal pour les développeurs qui ont besoin de générer rapidement des rapports hebdomadaires.
