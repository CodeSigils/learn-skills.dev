Навыки стандартизации и оптимизации кода внешнего интерфейса Vue2. Используется для: оптимизации кода компонента Vue2, стандартизации кода, рефакторинга стиля BEM, сортировки импорта, семантического именования, оптимизации асинхронного кода, улучшения комментариев, улучшения реквизитов и разъяснения ответственности за компоненты. Поддерживает файлы .vue (API параметров), .js, .css, .scss и .less. Для проектов Vue3 используйте yy-frontend-vue3-code-optimization. Сценарии триггера: когда пользователь упоминает оптимизацию Vue2, рефакторинг кода, стандартизированное именование, стили BEM, сортировку импорта, добавление комментариев, преобразование async/await, уточнение компонентов, настройку структуры API параметров, унификацию стиля кода, украшение файла .vue и т. д.
