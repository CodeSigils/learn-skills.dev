Actualisez la compréhension du code par l'IA. Utilisez cette compétence lorsque l'utilisateur mentionne « actualiser », « re-comprendre », « vider le cache » ou « recharger ». Il compare tous les fichiers modifiés, relit et comprend tout code que les humains auraient pu modifier, garantissant ainsi que le contexte de l'IA reste synchronisé avec le dernier état du code.
