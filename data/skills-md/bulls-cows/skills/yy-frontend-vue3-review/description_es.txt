Asistente de revisión de código front-end de Vue3. Revisa todos los archivos modificados en el directorio src de un proyecto Vue3, verifica cada elemento de acuerdo con los estándares de desarrollo de Vue3 y genera una lista de verificación de revisión. Se utiliza para: cuando un usuario solicita una revisión de código Vue3, una revisión de código o una verificación de cumplimiento con las especificaciones de Vue3.
