Assistente di revisione del codice front-end Vue3. Esamina tutti i file modificati nella directory src di un progetto Vue3, controlla ogni elemento in base agli standard di sviluppo Vue3 e genera un elenco di controllo di revisione. Utilizzato per: quando un utente richiede una revisione del codice Vue3, una revisione del codice o un controllo di conformità con le specifiche Vue3.
