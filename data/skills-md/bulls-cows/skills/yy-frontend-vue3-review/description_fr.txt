Assistant de révision de code frontal Vue3. Examine tous les fichiers modifiés dans le répertoire src d'un projet Vue3, vérifie chaque élément conformément aux normes de développement Vue3 et génère une liste de contrôle de révision. Utilisé pour : lorsqu'un utilisateur demande une révision du code Vue3, une révision du code ou une vérification de conformité avec les spécifications Vue3.
