Generieren Sie einen QR-Code aus einer URL, einem Text, WLAN-Anmeldeinformationen oder einer vCard und speichern Sie ihn als SVG oder PNG. Verwenden Sie diese Option, wenn der Benutzer sagt: „QR-Code erstellen“, „QR für diese URL generieren“, „WLAN-QR erstellen“, „Scanbaren Code erstellen“, „QR mit unserem Logo erstellen“ oder die QR-Code-Erstellung in einem Workflow automatisieren muss.
