كتابة ومراجعة كود SwiftUI WidgetKit للشاشة الرئيسية، وشاشة القفل، والاستعداد، وعناصر واجهة المستخدم للساعة - موفري المخطط الزمني وسياسات إعادة التحميل، والتكوين الثابت / AppIntentConfiguration، والأدوات الذكية القابلة للتكوين من قبل المستخدم، وعائلات الأدوات والحجم، وأوضاع العرض المميزة/الملونة، والأدوات التفاعلية وعناصر التحكم (مركز التحكم)، والأنشطة المباشرة والجزيرة الديناميكية، وملاءمة Smart Stack، والتحديث الفوري الأدوات وأسطح VisionOS / CarPlay / macOS. يُستخدم عند إنشاء ملحق عنصر واجهة مستخدم، أو موفر مخطط زمني، أو شاشة قفل أو عنصر واجهة مستخدم ملحق، أو تعقيدات الساعة، أو زر تفاعلي/عنصر تبديل، أو عنصر تحكم في مركز التحكم، أو نشاط مباشر، أو إصلاح عنصر واجهة مستخدم لن يتم تحديثه أو عرضه بشكل صحيح في الوضع الملون.
