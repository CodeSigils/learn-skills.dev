Leitfaden zum Implementieren, Konfigurieren und Debuggen von React Joyride v3-Führungen. Verwenden Sie diesen Skill immer dann, wenn der Benutzer Spritztour, geführte Tour, Onboarding-Tour, Komplettlösung, Tooltip-Tour, Schritt-für-Schritt-Anleitung oder Produkttour erwähnt oder UI-Elemente nacheinander hervorheben möchte. Auch zum Debuggen von Tourproblemen wie nicht angezeigten Tooltips, nicht gefundenen Zielen oder Problemen mit dem kontrollierten Modus geeignet. Diese Fertigkeit umfasst den useJoyride-Hook, die Joyride-Komponente, die Schrittkonfiguration, Ereignisse, Steuerelemente, benutzerdefinierte Komponenten und das Styling.
