دليل لتنفيذ وتكوين وتصحيح الجولات الإرشادية React Joyride v3. استخدم هذه المهارة عندما يذكر المستخدم رحلة المتعة، أو الجولة الإرشادية، أو جولة الإعداد، أو الإرشادات التفصيلية، أو جولة تلميح الأدوات، أو الدليل خطوة بخطوة، أو جولة المنتج، أو عندما يريد تسليط الضوء على عناصر واجهة المستخدم بشكل تسلسلي. استخدمه أيضًا عند تصحيح مشكلات الجولة مثل عدم ظهور تلميحات الأدوات، أو عدم العثور على الأهداف، أو مشكلات وضع التحكم. تغطي هذه المهارة خطاف useJoyride ومكون Joyride وتكوين الخطوة والأحداث وعناصر التحكم والمكونات المخصصة والتصميم.
