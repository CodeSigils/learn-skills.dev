Руководство по реализации, настройке и отладке экскурсий по React Joyride v3. Используйте этот навык всякий раз, когда пользователь упоминает прогулку, экскурсию, ознакомительную экскурсию, пошаговое руководство, экскурсию по всплывающей подсказке, пошаговое руководство, экскурсию по продукту или хочет последовательно выделить элементы пользовательского интерфейса. Также используйте при отладке проблем обхода, таких как отсутствие всплывающих подсказок, ненайденные цели или проблемы с контролируемым режимом. Этот навык охватывает хук useJoyride, компонент Joyride, конфигурацию шагов, события, элементы управления, пользовательские компоненты и стили.
