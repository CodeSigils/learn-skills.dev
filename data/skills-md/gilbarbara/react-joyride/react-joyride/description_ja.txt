React Joyride v3 のガイド付きツアーの実装、構成、デバッグに関するガイド。ユーザーがジョイライド、ガイド付きツアー、オンボーディング ツアー、ウォークスルー、ツールチップ ツアー、ステップバイステップ ガイド、製品ツアーに言及する場合、または UI 要素を順番に強調表示したい場合は、このスキルを使用します。ツールチップが表示されない、ターゲットが見つからない、制御モードの問題など、ツアーの問題をデバッグするときにも使用します。このスキルは、useJoyride フック、Joyride コンポーネント、ステップ構成、イベント、コントロール、カスタム コンポーネント、およびスタイルをカバーします。
