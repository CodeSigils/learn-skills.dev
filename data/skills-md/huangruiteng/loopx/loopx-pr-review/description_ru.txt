Используйте для `/loopx-pr-review` или проверки очереди PR на основе фактических данных. Сначала запустите «loopx pr-review», выполните план проверки, принадлежащий возможностям, для каждого выбранного конкретного руководителя, затем опубликуйте полные двуязычные PR-обзоры (полный обзор из пяти блоков на китайском языке плюс один краткий вердикт на английском языке), которые соответствуют проверенным результатам. Используйте «loopx-pr-merge» для действий по утверждению или слиянию.
