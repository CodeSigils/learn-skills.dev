Générez un journal des modifications lisible par l'homme entre deux versions de fichier Figma : pages ajoutées/supprimées/renommées ainsi que des modifications par composant, enrichies de poignées d'auteur et d'horodatages, prêtes à être collées dans des notes de version, des relations publiques ou Storybook MDX. À utiliser lorsque l'utilisateur souhaite un historique en prose - déclencheurs : "générer un journal des modifications Figma", "écrire des notes de version à partir de Figma", "ce qui a changé entre ces versions dans le markdown", "résumer les modifications Figma pour le PR", "journal des modifications entre les versions A et B", "concevoir le journal des modifications depuis la dernière version". Utilise l'API Figma REST + un jeton d'accès personnel car l'historique des versions n'est PAS accessible via l'API Plugin / use_figma / le MCP natif Figma. Pour le JSON diff structuré brut, utilisez figma-version-history ; pour trouver quelle version a introduit un changement spécifique, utilisez figma-blame-node.
