Genera un registro delle modifiche markdown leggibile dall'uomo tra due versioni di file Figma: pagine aggiunte/rimosse/rinominate più modifiche per componente, arricchito con handle dell'autore e timestamp, pronto per essere incollato in note di rilascio, PR o Storybook MDX. Da utilizzare quando l'utente desidera una cronologia in prosa: attiva: "genera un registro delle modifiche di Figma", "scrivi note di rilascio da Figma", "cosa è cambiato tra queste versioni nel markdown", "riepiloga le modifiche di Figma per il PR", "registro delle modifiche tra la versione A e B", "registro delle modifiche di progettazione dall'ultima versione". Utilizza l'API REST Figma + un token di accesso personale perché la cronologia delle versioni NON è raggiungibile tramite l'API Plugin / use_figma / il MCP Figma nativo. Per JSON diff strutturato non elaborato utilizzare figma-version-history; per scoprire quale versione ha introdotto una modifica specifica utilizzare figma-blame-node.
