Generieren Sie ein für Menschen lesbares Markdown-Änderungsprotokoll zwischen zwei Figma-Dateiversionen – hinzugefügte/entfernte/umbenannte Seiten sowie Änderungen pro Komponente, angereichert mit Autorenhandles und Zeitstempeln, bereit zum Einfügen in Versionshinweise, PRs oder Storybook MDX. Verwenden Sie diese Option, wenn der Benutzer einen Prosa-Verlauf möchte – Auslöser: „Generieren Sie ein Figma-Änderungsprotokoll“, „Schreiben Sie Versionshinweise von Figma“, „Was hat sich zwischen diesen Versionen im Markdown geändert“, „Zusammenfassen Sie Figma-Änderungen für die PR“, „Änderungsprotokoll zwischen Version A und B“, „Design-Änderungsprotokoll seit der letzten Veröffentlichung“. Verwendet die Figma REST API + ein persönliches Zugriffstoken, da der Versionsverlauf NICHT über die Plugin-API / use_figma / das native Figma MCP erreichbar ist. Für rohes strukturiertes Diff-JSON verwenden Sie figma-version-history; Um herauszufinden, welche Version eine bestimmte Änderung eingeführt hat, verwenden Sie figma-blame-node.
