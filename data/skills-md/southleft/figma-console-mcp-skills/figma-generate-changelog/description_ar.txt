أنشئ سجل تغيير تخفيض السعر يمكن قراءته بواسطة الإنسان بين إصدارين من ملفات Figma - الصفحات المضافة/المحذوفة/المعاد تسميتها بالإضافة إلى التغييرات لكل مكون، المخصبة بمقابض المؤلف والطوابع الزمنية، جاهزة للصقه في ملاحظات الإصدار أو العلاقات العامة أو Storybook MDX. يُستخدم عندما يريد المستخدم سجل النثر - المشغلات: "إنشاء سجل تغيير Figma"، و"كتابة ملاحظات الإصدار من Figma"، و"ما تغير بين هذه الإصدارات في تخفيض السعر"، و"تلخيص تغييرات Figma للعلاقات العامة"، و"سجل التغيير بين الإصدارين A وB"، و"سجل تغيير التصميم منذ الإصدار الأخير". يستخدم Figma REST API + رمز وصول شخصي لأنه لا يمكن الوصول إلى سجل الإصدار عبر Plugin API / use_figma / Figma MCP الأصلي. بالنسبة إلى الاختلافات المنظمة الأولية، استخدم JSON Figma-version-history؛ للعثور على الإصدار الذي أدخل تغييرًا محددًا، استخدم Figma-blame-node.
