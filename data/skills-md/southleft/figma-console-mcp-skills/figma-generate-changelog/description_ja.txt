2 つの Figma ファイル バージョン間で人間が判読できるマークダウン変更ログを生成します。ページの追加/削除/名前変更とコンポーネントごとの変更が含まれ、作成者ハンドルとタイムスタンプで強化され、リリース ノート、PR、または Storybook MDX に貼り付けることができます。ユーザーが散文的な履歴を必要とする場合に使用します。トリガー: 「Figma の変更ログを生成する」、「Figma からリリース ノートを書く」、「マークダウンでこれらのバージョン間で何が変更されたか」、「PR 用に Figma の変更を要約する」、「バージョン A と B の間の変更ログ」、「前回のリリース以降のデザインの変更ログ」。プラグイン API / use_figma / ネイティブ Figma MCP 経由ではバージョン履歴にアクセスできないため、Figma REST API + 個人アクセス トークンを使用します。生の構造化差分 JSON の場合は figma-version-history を使用します。どのバージョンに特定の変更が導入されたかを確認するには、figma-blame-node を使用します。
