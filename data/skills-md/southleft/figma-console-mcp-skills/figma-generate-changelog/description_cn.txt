在两个 Figma 文件版本之间生成人类可读的 Markdown 更改日志 - 添加/删除/重命名的页面以及每个组件的更改，丰富了作者句柄和时间戳，准备粘贴到发行说明、PR 或 Storybook MDX 中。当用户想要散文历史记录时使用 - 触发器：“生成 Figma 变更日志”、“从 Figma 编写发行说明”、“Markdown 中这些版本之间发生的变化”、“总结 PR 的 Figma 变更”、“版本 A 和 B 之间的变更日志”、“自上次发布以来的设计变更日志”。使用 Figma REST API + 个人访问令牌，因为无法通过插件 API / use_figma / 本机 Figma MCP 访问版本历史记录。对于原始结构化 diff JSON，请使用Figma-version-history；要查找哪个版本引入了特定更改，请使用Figma-blame-node。
