Genere un registro de cambios de rebajas legible por humanos entre dos versiones de archivos Figma: páginas agregadas, eliminadas o renombradas más cambios por componente, enriquecido con identificadores de autor y marcas de tiempo, listo para pegar en notas de la versión, relaciones públicas o Storybook MDX. Úselo cuando el usuario quiera un historial en prosa: desencadenantes: 'generar un registro de cambios de Figma', 'escribir notas de la versión de Figma', 'qué cambió entre estas versiones en Markdown', 'resumir los cambios de Figma para el PR', 'registro de cambios entre las versiones A y B', 'registro de cambios de diseño desde la última versión'. Utiliza la API REST de Figma + un token de acceso personal porque NO se puede acceder al historial de versiones a través de la API del complemento/use_figma/el MCP nativo de Figma. Para diferencias JSON estructuradas sin formato, utilice figma-version-history; para encontrar qué versión introdujo un cambio específico, use figma-blame-node.
