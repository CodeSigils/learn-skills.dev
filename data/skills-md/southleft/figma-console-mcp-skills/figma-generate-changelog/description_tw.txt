在兩個 Figma 檔案版本之間產生人類可讀的 Markdown 更改日誌 - 新增/刪除/重新命名的頁面以及每個元件的更改，豐富了作者句柄和時間戳，準備貼上到發行說明、PR 或 Storybook MDX 中。當使用者想要散文歷史記錄時使用 - 觸發器：「產生 Figma 變更日誌」、「從 Figma 編寫發行說明」、「Markdown 中這些版本之間發生的變更」、「總結 PR 的 Figma 變更」、「版本 A 和 B 之間的變更日誌」、「自上次發布以來的設計變更日誌」。使用 Figma REST API + 個人存取令牌，因為無法透過插件 API / use_figma / 本機 Figma MCP 存取版本歷史記錄。對於原始結構化 diff JSON，請使用Figma-version-history；要查找哪個版本引入了特定更改，請使用Figma-blame-node。
