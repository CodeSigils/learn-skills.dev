Создайте удобочитаемый журнал изменений уценки между двумя версиями файла Figma — добавленные/удаленные/переименованные страницы, а также изменения для каждого компонента, обогащенные дескрипторами автора и временными метками, готовые для вставки в примечания к выпуску, PR или Storybook MDX. Используйте, когда пользователю нужна история прозы — триггеры: «создать журнал изменений Figma», «записать примечания к выпуску из Figma», «что изменилось между этими версиями в уценке», «обобщить изменения Figma для PR», «журнал изменений между версиями A и B», «журнал изменений дизайна с момента последнего выпуска». Использует Figma REST API + личный токен доступа, поскольку история версий НЕ доступна через API плагинов / use_figma / собственный Figma MCP. Для необработанного структурированного JSON различий используйте Figma-версию-историю; чтобы узнать, какая версия внесла конкретное изменение, используйте Figma-Brame-Node.
