Encuentre qué versión de Figma introdujo un cambio específico (una propiedad de componente o un nodo secundario) mediante una búsqueda binaria en el historial de versiones (~log2(N) llamadas API en lugar de N). Responde 'quién añadió esto y cuándo'. Úselo cuando el usuario desee una atribución de estilo git-blame para un diseño de Figma: activadores: 'cuándo se agregó esta propiedad de componente', 'qué versión introdujo esta variante', 'quién agregó este nodo', 'culpar a este elemento de Figma', 'buscar cuándo se creó esto', 'culpar a git por Figma', 'cuándo apareció esta propiedad por primera vez'. Utiliza la API REST de Figma + un token de acceso personal porque NO se puede acceder al historial de versiones a través de la API del complemento/use_figma/el MCP nativo de Figma. Para obtener una diferencia completa entre dos versiones, utilice figma-version-history; para notas de la versión en prosa utilice figma-generate-changelog.
