'누가 언제 추가했는지'에 대한 답변입니다. 사용자가 Figma 디자인에 대해 git-blame 스타일 속성을 원할 때 사용합니다. 트리거: '이 구성 요소 속성이 추가된 시기', '이 변형을 도입한 버전', '이 노드를 추가한 사람', '이 Figma 요소를 비난', '이것이 언제 생성되었는지 찾기', 'Figma에 대한 git 비난', '이 속성이 처음 나타난 시기'. 버전 기록은 플러그인 API / use_figma / 기본 Figma MCP를 통해 접근할 수 없기 때문에 Figma REST API + 개인 액세스 토큰을 사용합니다. 두 버전 간의 전체 차이점을 보려면 figma-version-history를 사용하세요. 산문 릴리스 노트를 보려면 figma-generate-changelog를 사용하세요.
