バージョン履歴のバイナリ検索 (N ではなく ~log2(N) API 呼び出し) により、特定の変更 (コンポーネント プロパティまたは子ノード) が導入された Figma バージョンを見つけます。 「誰がいつ追加したか」に答えます。ユーザーが Figma デザインの git-blame スタイルの属性を必要とする場合に使用します。トリガー: 「このコンポーネント プロパティがいつ追加されたか」、「どのバージョンでこのバリアントが導入されたか」、「このノードを追加したのは誰」、「この Figma 要素を非難する」、「これがいつ作成されたかを調べる」、「Figma の git 非難」、「このプロパティが初めて表示されたのはいつ」。プラグイン API / use_figma / ネイティブ Figma MCP 経由ではバージョン履歴にアクセスできないため、Figma REST API + 個人アクセス トークンを使用します。 2 つのバージョン間の完全な差分を確認するには、figma-version-history を使用します。散文的なリリースノートには figma-generate-changelog を使用してください。
