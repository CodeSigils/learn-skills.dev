Найдите, в какой версии Figma произошло конкретное изменение — свойство компонента или дочерний узел — с помощью двоичного поиска по истории версий (вызовы API ~log2(N) вместо N). Отвечает «кто это добавил и когда». Используйте, когда пользователь хочет атрибуцию дизайна Figma в стиле git-blame — триггеры: «когда было добавлено это свойство компонента», «в какой версии появился этот вариант», «кто добавил этот узел», «обвинить этот элемент Figma», «найти, когда это было создано», «git виноват за Figma», «когда это свойство впервые появилось». Использует Figma REST API + личный токен доступа, поскольку история версий НЕ доступна через API плагинов / use_figma / собственный Figma MCP. Для полной разницы между двумя версиями используйте Figma-version-history; для прозаических примечаний к выпуску используйте Figma-generate-changelog.
