Trova quale versione di Figma ha introdotto una modifica specifica - una proprietà del componente o un nodo figlio - tramite una ricerca binaria nella cronologia delle versioni (chiamate API ~ log2 (N) anziché N). Risponde "chi ha aggiunto questo e quando". Da utilizzare quando l'utente desidera un'attribuzione in stile git-blame per un progetto Figma: attiva: "quando è stata aggiunta questa proprietà del componente", "quale versione ha introdotto questa variante", "chi ha aggiunto questo nodo", "incolpa questo elemento Figma", "trova quando è stato creato", "git colpa per Figma", "quando è apparsa per la prima volta questa proprietà". Utilizza l'API REST Figma + un token di accesso personale perché la cronologia delle versioni NON è raggiungibile tramite l'API Plugin / use_figma / il MCP Figma nativo. Per una differenza completa tra due versioni utilizzare figma-version-history; per le note sulla versione in prosa utilizzare figma-generate-changelog.
