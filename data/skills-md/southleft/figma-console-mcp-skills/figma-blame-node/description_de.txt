Finden Sie heraus, welche Figma-Version eine bestimmte Änderung eingeführt hat – eine Komponenteneigenschaft oder einen untergeordneten Knoten – über eine binäre Suche im Versionsverlauf (~log2(N) API-Aufrufe statt N). Antworten: „Wer hat dies hinzugefügt und wann?“ Wird verwendet, wenn der Benutzer eine Zuordnung im Git-Blame-Stil für ein Figma-Design wünscht – löst Folgendes aus: „Wann wurde diese Komponenteneigenschaft hinzugefügt“, „Welche Version hat diese Variante eingeführt“, „Wer hat diesen Knoten hinzugefügt“, „Blame dieses Figma-Element“, „Finde, wann dies erstellt wurde“, „Git Blame für Figma“, „Wann ist diese Eigenschaft zum ersten Mal erschienen“. Verwendet die Figma REST API + ein persönliches Zugriffstoken, da der Versionsverlauf NICHT über die Plugin-API / use_figma / das native Figma MCP erreichbar ist. Für einen vollständigen Unterschied zwischen zwei Versionen verwenden Sie figma-version-history; Für Prosa-Versionshinweise verwenden Sie figma-generate-changelog.
