Recherchez quelle version de Figma a introduit un changement spécifique - une propriété de composant ou un nœud enfant - via une recherche binaire sur l'historique des versions (appels API ~ log2 (N) au lieu de N). Répond « qui a ajouté ceci et quand ». À utiliser lorsque l'utilisateur souhaite une attribution de style git-blame pour une conception Figma - déclencheurs : « quand cette propriété de composant a-t-elle été ajoutée », « quelle version a introduit cette variante », « qui a ajouté ce nœud », « blâmer cet élément Figma », « trouver quand cela a été créé », « git blâme pour Figma », « quand cette propriété est-elle apparue pour la première fois ». Utilise l'API Figma REST + un jeton d'accès personnel car l'historique des versions n'est PAS accessible via l'API Plugin / use_figma / le MCP natif Figma. Pour une différence complète entre deux versions, utilisez figma-version-history ; pour les notes de version en prose, utilisez figma-generate-changelog.
