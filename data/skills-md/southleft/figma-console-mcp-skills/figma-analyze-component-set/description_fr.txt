Analysez un Figma COMPONENT_SET en tant que machine d'état pour la génération de code - extrayez les axes de variantes (état/taille/etc.), mappez les variantes d'état aux pseudo-classes CSS (survol → : survol, focus → : focus-visible, désactivé → : désactivé, erreur → [aria-invalid]) et calculez les différences visuelles par variante (uniquement ce qui change par état). À utiliser lors de la génération d'un composant interactif à partir d'un ensemble de variantes Figma - déclencheurs : « analyser cet ensemble de composants », « transformer ces variantes en états CSS », « générer un bouton/une entrée/une case à cocher à partir des variantes Figma », « ce qui change entre le survol et l'état par défaut », « mapper les variantes Figma aux accessoires du composant », « extraire la machine d'état pour ce composant ». Résout les variables liées en noms de jetons. NON couvert par get_design_context/get_metadata du MCP natif, qui ne vous donne pas de machine à états variant-axis→CSS.
