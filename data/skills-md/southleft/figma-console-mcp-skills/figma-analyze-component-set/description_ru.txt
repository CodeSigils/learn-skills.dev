Анализируйте Figma COMPONENT_SET как конечный автомат для генерации кода — извлекайте варианты осей (состояние/размер/и т. д.), сопоставляйте варианты состояний с псевдоклассами CSS (hover→:hover, focus→:focus-visible, Disabled→:disabled, error→[aria-invalid]) и вычисляйте визуальные различия для каждого варианта (только то, что меняется для каждого состояния). Используйте при создании интерактивного компонента из набора вариантов Figma — триггеры: «проанализировать этот набор компонентов», «превратить эти варианты в состояния CSS», «сгенерировать кнопку/ввод/флажок из вариантов Figma», «какие изменения между состоянием наведения и состоянием по умолчанию», «сопоставить варианты Figma с реквизитами компонента», «извлечь конечный автомат для этого компонента». Преобразует связанные переменные в имена токенов. НЕ покрывается собственными методами get_design_context/get_metadata MCP, которые не дают вам вариантную ось → конечный автомат CSS.
