코드 생성을 위한 상태 머신으로 Figma COMPONENT_SET을 분석합니다. 변형 축(상태/크기/등)을 추출하고 상태 변형을 CSS 의사 클래스(hover→:hover, focus→:focus-visible, 비활성화→:비활성화, 오류→[aria-invalid])에 매핑하고 변형별 시각적 차이를 계산합니다(상태별로 변경되는 사항만).
