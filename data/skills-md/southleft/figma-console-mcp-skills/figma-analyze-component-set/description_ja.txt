Figma COMPONENT_SET をコード生成用のステート マシンとして分析します。バリアント軸 (状態/サイズなど) を抽出し、状態バリアントを CSS 疑似クラス (hover→:hover、focus→:focus-visible、disabled→:disabled、error→[aria-invalid]) にマッピングし、バリアントごとの視覚差分 (状態ごとに変更されるもののみ) を計算します。 Figma バリアント セットからインタラクティブ コンポーネントを生成するときに使用します。トリガー: 「このコンポーネント セットを分析する」、「これらのバリアントを CSS 状態に変換する」、「Figma バリアントからボタン/入力/チェックボックスを生成する」、「ホバー状態とデフォルト状態の間で何が変わるか」、「Figma バリアントをコンポーネント プロップにマッピングする」、「このコンポーネントのステート マシンを抽出する」。バインドされた変数をトークン名に解決します。ネイティブ MCP の get_design_context/get_metadata ではカバーされておらず、バリアント軸→ CSS ステート マシンは提供されません。
