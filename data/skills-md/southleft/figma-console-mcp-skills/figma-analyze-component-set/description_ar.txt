قم بتحليل Figma COMPONENT_SET كجهاز حالة لتوليد التعليمات البرمجية - استخراج محاور متغيرة (الحالة/الحجم/إلخ)، وتعيين متغيرات الحالة إلى فئات CSS الزائفة (تحويم →: تحوم، التركيز →: التركيز مرئي، معطل →: معطل، خطأ → [aria-invalid])، وحساب الفروق المرئية لكل متغير (فقط ما يتغير لكل حالة). استخدمه عند إنشاء مكون تفاعلي من مجموعة متغيرات Figma - المشغلات: "تحليل مجموعة المكونات هذه"، "تحويل هذه المتغيرات إلى حالات CSS"، "إنشاء زر/إدخال/مربع اختيار من متغيرات Figma"، "ما يتغير بين حالة التمرير والحالة الافتراضية"، "تعيين متغيرات Figma إلى دعائم المكونات"، "استخراج آلة الحالة لهذا المكون". يحل المتغيرات المرتبطة بأسماء الرموز المميزة. لا يغطيها get_design_context/get_metadata الخاص بـ MCP الأصلي، والتي لا تمنحك محورًا متغيرًا → جهاز حالة CSS.
