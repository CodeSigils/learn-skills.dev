COMPONENT 또는 COMPONENT_SET에서 Figma 구성 요소 속성(TEXT, BOOLEAN, INSTANCE_SWAP, VARIANT)을 추가, 편집 및 삭제하고 구성 요소를 인스턴스화한 다음 해당 인스턴스 속성을 설정합니다. Figma에서 구성 요소의 API를 작성하거나 연결할 때 사용 — 트리거: '구성 요소 속성 추가', '이 구성 요소에 부울 속성 추가', '이 텍스트를 구성 요소 속성으로 만들기', '인스턴스 스왑 슬롯 추가', '변형 속성 생성', '구성 요소 속성 이름 바꾸기/삭제', '이 구성 요소의 인스턴스 배치', '이 구성 요소를 인스턴스화하고 해당 레이블/상태 설정', '이 인스턴스에 속성 설정'. 개별 변형이 아닌 상위 COMPONENT_SET에 속성을 추가해야 합니다. 기본 MCP의 읽기 전용 get_design_context/get_metadata에서는 다루지 않습니다.
