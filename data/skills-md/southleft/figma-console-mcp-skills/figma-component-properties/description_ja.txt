COMPONENT または COMPONENT_SET で Figma コンポーネント プロパティ (TEXT、BOOLEAN、INSTANCE_SWAP、VARIANT) を追加、編集、削除し、コンポーネントをインスタンス化してからそのインスタンス プロパティを設定します。 Figma でコンポーネントの API を作成または接続するときに使用します — トリガー: 「コンポーネント プロパティを追加する」、「このコンポーネントにブール値プロパティを追加する」、「このテキストをコンポーネント プロパティにする」、「インスタンス スワップ スロットを追加する」、「バリアント プロパティを作成する」、「コンポーネント プロパティの名前変更/削除」、「このコンポーネントのインスタンスを配置する」、「このコンポーネントをインスタンス化し、そのラベル/状態を設定する」、「このコンポーネントにプロパティを設定する」インスタンス」。プロパティは、個々のバリアントではなく、親 COMPONENT_SET に追加する必要があります。ネイティブ MCP の読み取り専用 get_design_context/get_metadata ではカバーされていません。
