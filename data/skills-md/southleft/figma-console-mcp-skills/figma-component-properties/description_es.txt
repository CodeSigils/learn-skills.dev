Agregue, edite y elimine las propiedades del componente Figma (TEXT, BOOLEAN, INSTANCE_SWAP, VARIANT) en un COMPONENT o COMPONENT_SET, cree una instancia de un componente y luego establezca sus propiedades de instancia. Úselo al crear o conectar la API de un componente en Figma: activadores: 'agregar una propiedad de componente', 'agregar una propiedad booleana a este componente', 'convertir este texto en una propiedad de componente', 'agregar una ranura de intercambio de instancia', 'crear una propiedad variante', 'cambiar el nombre/eliminar una propiedad de componente', 'colocar una instancia de este componente', 'crear una instancia de este componente y establecer su etiqueta/estado', 'establecer propiedades en esta instancia'. Las propiedades deben agregarse al COMPONENT_SET principal, no a variantes individuales. NO cubierto por get_design_context/get_metadata de solo lectura del MCP nativo.
