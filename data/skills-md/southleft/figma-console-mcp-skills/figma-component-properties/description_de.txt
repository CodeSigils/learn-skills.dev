Fügen Sie Figma-Komponenteneigenschaften (TEXT, BOOLEAN, INSTANCE_SWAP, VARIANT) für eine COMPONENT oder COMPONENT_SET hinzu, bearbeiten und löschen Sie sie, instanziieren Sie eine Komponente und legen Sie dann ihre Instanzeigenschaften fest. Wird beim Erstellen oder Vernetzen der API einer Komponente in Figma verwendet – löst Folgendes aus: „Eine Komponenteneigenschaft hinzufügen“, „Eine boolesche Requisite zu dieser Komponente hinzufügen“, „Diesen Text zu einer Komponenteneigenschaft machen“, „Einen Instanz-Swap-Slot hinzufügen“, „Eine Varianteneigenschaft erstellen“, „Eine Komponenteneigenschaft umbenennen/löschen“, „Eine Instanz dieser Komponente platzieren“, „Diese Komponente instanziieren und ihre Beschriftung/ihren Status festlegen“, „Eigenschaften für diese Instanz festlegen“. Eigenschaften müssen zum übergeordneten COMPONENT_SET hinzugefügt werden, nicht einzelne Varianten. NICHT durch die schreibgeschützten get_design_context/get_metadata des nativen MCP abgedeckt.
