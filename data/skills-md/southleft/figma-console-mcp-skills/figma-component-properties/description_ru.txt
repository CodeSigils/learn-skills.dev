Добавляйте, редактируйте и удаляйте свойства компонента Figma (TEXT, BOOLEAN, INSTANCE_SWAP, VARIANT) в COMPONENT или COMPONENT_SET, а также создайте экземпляр компонента, а затем установите его свойства экземпляра. Используйте при разработке или подключении API компонента в Figma — триггеры: «добавить свойство компонента», «добавить логическое свойство к этому компоненту», «сделать этот текст свойством компонента», «добавить слот подкачки экземпляра», «создать свойство варианта», «переименовать/удалить свойство компонента», «поместить экземпляр этого компонента», «создать экземпляр этого компонента и установить его метку/состояние», «задать свойства для этого экземпляра». Свойства необходимо добавлять в родительский COMPONENT_SET, а не в отдельные варианты. НЕ покрывается родной функцией get_design_context/get_metadata MCP, доступной только для чтения.
