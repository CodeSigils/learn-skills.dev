単一の Figma コンポーネントまたはコンポーネント セットの詳細なアクセシビリティ スコアカード - 状態カバレッジ (デフォルト/ホバー/フォーカス/無効/エラー/アクティブ/読み込み中)、フォーカス インジケーターの品質とコントラスト、非色の状態の区別、ターゲット サイズ、注釈の完全性、色覚異常シミュレーション (第一色盲/第二色覚/三色覚)、すべてがカテゴリごとに 0 ～ 100 のスコアと優先順位付けされた推奨事項にまとめられます。ユーザーが出荷前に 1 つのコンポーネントを精査したい場合に使用します。「このコンポーネントを監査する」、「このボタンのアクセシビリティ スコア」、「このコンポーネントはアクセス可能に設定されているか」、「このコンポーネントの状態を確認する」、「ボタンにフォーカス状態があるかどうか」、「色盲チェック」、「a11y についてこのコンポーネントを評価する」、「コンポーネント アクセシビリティ スコアカード」をトリガーします。あらゆる Figma プランで動作します。ページ/フレーム全体を広範囲にスイープするには、figma-lint-design を使用します。 CODE 側 (HTML) チェックには figma-scan-code-accessibility を使用します。
