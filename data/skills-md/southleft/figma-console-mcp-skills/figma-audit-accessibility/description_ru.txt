Система показателей глубокой доступности для одного компонента или набора компонентов Figma — охват состояния (по умолчанию/наведение/фокус/отключено/ошибка/активный/загрузка), качество и контрастность индикатора фокуса, дифференциация состояния без цвета, целевой размер, полнота аннотаций и симуляция цветовой слепоты (протанопия/дейтеранопия/тританопия), все это сведено в баллы по каждой категории от 0 до 100 и приоритетные рекомендации. Используйте, когда пользователь хочет проверить ОДИН компонент перед его отправкой: триггеры «проверить этот компонент», «оценка доступности для этой кнопки», «доступен ли этот набор компонентов», «проверить состояния этого компонента», «имеет ли моя кнопка состояние фокуса», «проверка цветовой слепоты», «оценить этот компонент для a11y», «оценочная карта доступности компонента». Работает на ЛЮБОМ плане Figma. Для широкого охвата всей страницы/фрейма используйте Figma-lint-design; для проверок на стороне КОДА (HTML) используйте Figma-scan-code-accessibility.
