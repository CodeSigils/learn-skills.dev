Scorecard für umfassende Barrierefreiheit für eine einzelne Figma-Komponente oder einen Komponentensatz – Zustandsabdeckung (Standard/Hover/Fokus/Deaktiviert/Fehler/Aktiv/Laden), Fokus-Indikator-Qualität und -Kontrast, Nicht-Farbzustandsdifferenzierung, Zielgröße, Anmerkungsvollständigkeit und Farbenblindheitssimulation (Protanopie/Deuteranopie/Tritanopie), alles zusammengefasst in Bewertungen pro Kategorie 0–100 und priorisierten Empfehlungen. Verwenden Sie diese Option, wenn der Benutzer EINE Komponente vor dem Versand überprüfen möchte: löst „Diese Komponente prüfen“, „Bewertung der Barrierefreiheit für diese Schaltfläche“, „Ist dieser Komponentensatz barrierefrei“, „Überprüfen Sie die Zustände dieser Komponente“, „Hat meine Schaltfläche einen Fokusstatus“, „Farbenblindprüfung“, „Diese Komponente für 11 Jahre bewerten“, „Scorecard für die Barrierefreiheit der Komponente“ aus. Funktioniert mit JEDEM Figma-Plan. Für einen breiten Schwung über eine ganze Seite/einen Frame verwenden Sie figma-lint-design; Für CODE-seitige (HTML) Prüfungen verwenden Sie figma-scan-code-accessibility.
