Cuadro de mando de accesibilidad profunda para un único componente o conjunto de componentes de Figma: cobertura de estado (predeterminado/desplazamiento/enfoque/deshabilitado/error/activo/cargando), calidad y contraste del indicador de enfoque, diferenciación de estado sin color, tamaño objetivo, integridad de la anotación y simulación daltónica (protanopia/deuteranopia/tritanopia), todo ello incluido en puntuaciones por categoría de 0 a 100 y recomendaciones priorizadas. Úselo cuando el usuario quiera examinar UN componente antes de enviarlo: activa "auditar este componente", "puntuación de accesibilidad para este botón", "este componente está configurado como accesible", "verificar los estados de este componente", "mi botón tiene un estado de enfoque", "verificación daltónica", "calificar este componente para todos", "cuadro de puntuación de accesibilidad del componente". Funciona en CUALQUIER plan Figma. Para un barrido amplio de una página/marco completo, utilice figma-lint-design; para verificaciones del lado del CÓDIGO (HTML), utilice figma-scan-code-accessibility.
