Découvrez et importez les jetons de conception des bibliothèques de l'équipe Figma SUBSCRIBED dans le fichier actuel. À utiliser lorsque l'utilisateur souhaite réutiliser des jetons qui se trouvent dans une bibliothèque partagée : déclenche "lister les variables de la bibliothèque", "quels jetons se trouvent dans notre bibliothèque partagée", "importer une variable de notre bibliothèque de système de conception", "extraire le jeton de couleur de marque de la bibliothèque". Fonctionne sur N'IMPORTE QUEL plan via les méthodes TeamLibrary de l'API Plugin. Pour les variables LOCAL, utilisez figma-export-tokens / figma-manage-variables.
