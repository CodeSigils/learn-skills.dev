Descubra e importe tokens de diseño de las bibliotecas SUSCRITAS del equipo Figma al archivo actual. Úselo cuando el usuario quiera reutilizar tokens que se encuentran en una biblioteca compartida: activa 'enumerar variables de biblioteca', 'qué tokens hay en nuestra biblioteca compartida', 'importar una variable de nuestra biblioteca de sistema de diseño', 'extraer el token de color de marca de la biblioteca'. Funciona en CUALQUIER plan a través de los métodos de biblioteca del equipo de API del complemento. Para variables LOCALES, utilice figma-export-tokens / figma-manage-variables.
