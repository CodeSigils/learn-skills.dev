Entdecken und importieren Sie Design-Tokens aus ABONNIERTEN Figma-Teambibliotheken in die aktuelle Datei. Verwenden Sie diese Option, wenn der Benutzer Token wiederverwenden möchte, die in einer gemeinsam genutzten Bibliothek gespeichert sind: löst „Bibliotheksvariablen auflisten“, „Welche Token befinden sich in unserer gemeinsam genutzten Bibliothek“, „Variable aus unserer Designsystembibliothek importieren“ und „Markenfarbtoken aus der Bibliothek importieren“ aus. Funktioniert mit JEDEM Plan über die TeamLibrary-Methoden der Plugin-API. Für LOKALE Variablen verwenden Sie figma-export-tokens / figma-manage-variables.
