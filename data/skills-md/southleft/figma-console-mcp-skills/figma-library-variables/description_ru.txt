Находите и импортируйте токены дизайна из ПОДПИСАННЫХ библиотек команды Figma в текущий файл. Используйте, когда пользователь хочет повторно использовать токены, находящиеся в общей библиотеке: триггеры «перечислить переменные библиотеки», «какие токены находятся в нашей общей библиотеке», «импортировать переменную из библиотеки нашей системы дизайна», «извлечь токен цвета бренда из библиотеки». Работает на ЛЮБОМ плане через методы TeamLibrary API плагина. Для ЛОКАЛЬНЫХ переменных используйте Figma-export-tokens/figma-manage-variables.
