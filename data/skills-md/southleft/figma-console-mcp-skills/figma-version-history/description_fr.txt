Répertoriez l'historique des versions d'un fichier Figma, prenez un instantané du fichier à n'importe quelle version précédente et comparez deux versions (pages ajoutées/supprimées/renommées plus modifications profondes par composant). À utiliser lorsque l'utilisateur souhaite inspecter l'historique de Figma - déclencheurs : "lister les versions de Figma", "quelles sont les versions de ce fichier", "afficher l'historique des versions", "prendre un instantané de ce fichier à la version X", "obtenir le fichier tel qu'il était la semaine dernière", "diff deux versions de Figma", "qu'est-ce qui a changé entre ces versions", "comparer les versions A et B", "ce composant a-t-il changé entre les versions". Utilise l'API Figma REST + un jeton d'accès personnel car l'historique des versions n'est PAS accessible via l'API Plugin / use_figma / le MCP natif Figma. Pour une rédaction de notes de version en prose, utilisez figma-generate-changelog ; pour trouver quelle version a introduit un changement, utilisez figma-blame-node.
