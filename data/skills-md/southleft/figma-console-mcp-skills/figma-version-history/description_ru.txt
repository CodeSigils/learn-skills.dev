Просмотрите историю версий файла Figma, сделайте снимок файла в любой предыдущей версии и сравните две версии (добавленные/удаленные/переименованные страницы плюс глубокие изменения для каждого компонента). Используйте, когда пользователь хочет просмотреть историю Figma — триггеры: «перечислить версии Figma», «какие версии имеет этот файл», «показать историю версий», «сделать снимок этого файла в версии X», «получить файл в том виде, в каком он был на прошлой неделе», «сравнить две версии Figma», «что изменилось между этими версиями», «сравнить версии A и B», «изменился ли этот компонент между выпусками». Использует Figma REST API + личный токен доступа, поскольку история версий НЕ доступна через API плагинов / use_figma / собственный Figma MCP. Для описания примечаний к выпуску используйте Figma-generate-changelog; чтобы узнать, в какой версии были внесены изменения, используйте Figma-Brame-Node.
