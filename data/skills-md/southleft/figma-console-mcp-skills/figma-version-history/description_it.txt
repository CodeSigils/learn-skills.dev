Elenca la cronologia delle versioni di un file Figma, esegui lo snapshot del file in qualsiasi versione precedente e confronta due versioni (pagine aggiunte/rimosse/rinominate più modifiche profonde per componente). Da utilizzare quando l'utente desidera ispezionare la cronologia di Figma: attiva: "elenco versioni di Figma", "quali versioni ha questo file", "mostra cronologia delle versioni", "istantanea di questo file alla versione X", "ottieni il file com'era la scorsa settimana", "diff due versioni di Figma", "cosa è cambiato tra queste versioni", "confronta versione A e B", "questo componente è cambiato tra le versioni". Utilizza l'API REST Figma + un token di accesso personale perché la cronologia delle versioni NON è raggiungibile tramite l'API Plugin / use_figma / il MCP Figma nativo. Per un resoconto delle note di rilascio in prosa utilizzare figma-generate-changelog; per scoprire quale versione ha introdotto una modifica utilizzare figma-blame-node.
