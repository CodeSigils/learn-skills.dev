قم بإدراج سجل إصدارات ملف Figma، والتقط لقطة للملف في أي إصدار سابق، وفرق بين الإصدارين (الصفحات المضافة/المحذوفة/المعاد تسميتها بالإضافة إلى التغييرات العميقة لكل مكون). استخدمه عندما يريد المستخدم فحص محفوظات Figma - المشغلات: "قائمة إصدارات Figma"، "ما هي الإصدارات التي يحتوي عليها هذا الملف"، "إظهار محفوظات الإصدار"، "لقطة هذا الملف في الإصدار X"، "احصل على الملف كما كان في الأسبوع الماضي"، "فرق بين نسختين من Figma"، "ما الذي تغير بين هذه الإصدارات"، "قارن الإصدار A و B"، "هل تغير هذا المكون بين الإصدارات". يستخدم Figma REST API + رمز وصول شخصي لأنه لا يمكن الوصول إلى سجل الإصدار عبر Plugin API / use_figma / Figma MCP الأصلي. لكتابة ملاحظات الإصدار النثرية، استخدم Figma-generate-changelog؛ للعثور على الإصدار الذي أدخل التغيير، استخدم Figma-blame-node.
