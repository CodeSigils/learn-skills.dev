Figma 파일의 버전 기록을 나열하고, 이전 버전에서 파일의 스냅샷을 찍고, 두 버전을 비교합니다(추가/제거/이름 변경된 페이지와 구성 요소별 심층적인 변경 사항). 사용자가 Figma 기록을 검사하려고 할 때 사용합니다. 트리거: 'Figma 버전 목록', '이 파일의 버전은 무엇입니까?', '버전 기록 표시', '버전 X에서 이 파일의 스냅샷', '지난 주 파일 가져오기', '두 Figma 버전 비교', '이 버전 간에 변경된 내용', '버전 A와 B 비교', '릴리스 간에 이 구성 요소가 변경되었습니까?' 버전 기록은 플러그인 API / use_figma / 기본 Figma MCP를 통해 접근할 수 없기 때문에 Figma REST API + 개인 액세스 토큰을 사용합니다. 산문 릴리스 노트를 작성하려면 figma-generate-changelog를 사용하세요. 변경 사항이 적용된 버전을 찾으려면 figma-blame-node를 사용하세요.
