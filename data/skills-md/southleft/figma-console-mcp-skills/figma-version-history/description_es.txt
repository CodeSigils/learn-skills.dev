Enumere el historial de versiones de un archivo Figma, tome una instantánea del archivo en cualquier versión anterior y diferencie dos versiones (páginas agregadas/eliminadas/renombradas más cambios profundos por componente). Úselo cuando el usuario quiera inspeccionar el historial de Figma: activadores: 'enumerar las versiones de Figma', 'qué versiones tiene este archivo', 'mostrar el historial de versiones', 'una instantánea de este archivo en la versión X', 'obtener el archivo como estaba la semana pasada', 'diferenciar dos versiones de Figma', 'qué cambió entre estas versiones', 'comparar la versión A y B', 'este componente cambió entre versiones'. Utiliza la API REST de Figma + un token de acceso personal porque NO se puede acceder al historial de versiones a través de la API del complemento/use_figma/el MCP nativo de Figma. Para obtener un resumen de las notas de la versión en prosa, utilice figma-generate-changelog; para encontrar qué versión introdujo un cambio, use figma-blame-node.
