列出 Figma 文件的版本历史记录、任何过去版本的文件快照，以及比较两个版本（添加/删除/重命名的页面以及每个组件的深度更改）。当用户想要检查 Figma 历史记录时使用 - 触发器：“列出 Figma 版本”、“此文件有哪些版本”、“显示版本历史记录”、“在版本 X 上拍摄此文件的快照”、“获取上周的文件”、“比较两个 Figma 版本”、“这些版本之间发生了什么变化”、“比较版本 A 和 B”、“此组件在版本之间是否发生了更改”。使用 Figma REST API + 个人访问令牌，因为无法通过插件 API / use_figma / 本机 Figma MCP 访问版本历史记录。对于散文发行说明写作，请使用Figma-generate-changelog；要查找哪个版本引入了更改，请使用Figma-blame-node。
