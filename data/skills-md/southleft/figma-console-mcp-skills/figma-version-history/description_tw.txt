列出 Figma 檔案的版本歷史記錄、任何過去版本的檔案快照，以及比較兩個版本（新增/刪除/重新命名的頁面以及每個元件的深度變更）。當用戶想要檢查 Figma 歷史記錄時使用 - 觸發器：“列出 Figma 版本”、“此文件有哪些版本”、“顯示版本歷史記錄”、“在版本 X 上拍攝此文件的快照”、“獲取上週的文件”、“比較兩個 Figma 版本”、“這些版本之間發生了什麼變化”、“比較版本 A 和 B”、“此組件在版本之間是否發生了更改”。使用 Figma REST API + 個人存取令牌，因為無法透過插件 API / use_figma / 本機 Figma MCP 存取版本歷史記錄。對於散文發行說明寫作，請使用Figma-generate-changelog；要查找哪個版本引入了更改，請使用Figma-blame-node。
