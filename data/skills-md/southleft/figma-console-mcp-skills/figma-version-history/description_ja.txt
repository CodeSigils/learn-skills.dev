Figma ファイルのバージョン履歴を一覧表示し、過去のバージョンでファイルのスナップショットを作成し、2 つのバージョンの差分 (ページの追加/削除/名前変更とコンポーネントごとの大幅な変更) を比較します。ユーザーが Figma の履歴を調べたいときに使用します。トリガー: 「Figma のバージョンをリストする」、「このファイルのバージョンは何ですか」、「バージョン履歴を表示する」、「このファイルをバージョン X でスナップショットする」、「先週の状態のファイルを取得する」、「2 つの Figma バージョンを比較する」、「これらのバージョン間で何が変更されたか」、「バージョン A と B を比較する」、「このコンポーネントはリリース間で変更されましたか」。プラグイン API / use_figma / ネイティブ Figma MCP 経由ではバージョン履歴にアクセスできないため、Figma REST API + 個人アクセス トークンを使用します。散文的なリリースノートの書き込みには figma-generate-changelog を使用します。どのバージョンに変更が加えられたかを確認するには、figma-blame-node を使用します。
