Listen Sie den Versionsverlauf einer Figma-Datei auf, erstellen Sie einen Snapshot der Datei in einer früheren Version und vergleichen Sie zwei Versionen (hinzugefügte/entfernte/umbenannte Seiten sowie tiefgreifende Änderungen pro Komponente). Wird verwendet, wenn der Benutzer den Figma-Verlauf überprüfen möchte – Auslöser: „Figma-Versionen auflisten“, „Welche Versionen hat diese Datei“, „Versionsverlauf anzeigen“, „Schnappschuss dieser Datei bei Version Verwendet die Figma REST API + ein persönliches Zugriffstoken, da der Versionsverlauf NICHT über die Plugin-API / use_figma / das native Figma MCP erreichbar ist. Für eine ausführliche Beschreibung der Versionshinweise verwenden Sie figma-generate-changelog; Um herauszufinden, welche Version eine Änderung eingeführt hat, verwenden Sie figma-blame-node.
