Organizza le varianti di Figma COMPONENT_SET in una griglia pulita ed etichettata: righe e colonne derivate dalle proprietà della variante, con etichette di riga a sinistra, intestazioni di colonna in alto e un contenitore bianco intitolato. Da utilizzare quando un set di varianti è una pila disordinata e si desidera un layout presentabile e pronto per la documentazione: attiva: "disponi le mie varianti in una griglia", "organizza questo set di componenti", "disponi le varianti con etichette", "crea una matrice di varianti", "ripulisci il layout del mio set di componenti", "aggiungi intestazioni di riga/colonna alle mie varianti". Per impostazione predefinita, seleziona l'ultima proprietà (solitamente State) come colonne e il resto come righe. NON qualcosa che fanno gli strumenti di sola lettura nativi di MCP: scrive un nuovo layout organizzato sull'area di disegno.
