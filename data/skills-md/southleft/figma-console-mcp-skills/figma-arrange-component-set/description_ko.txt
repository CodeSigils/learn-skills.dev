Figma COMPONENT_SET의 변형을 깨끗하고 레이블이 지정된 그리드(변형 속성에서 파생된 행과 열)로 구성합니다. 행 레이블은 왼쪽에, 열 헤더는 상단에, 제목이 있는 흰색 컨테이너가 있습니다. 변형 세트가 지저분하고 표시 가능하고 문서화 가능한 레이아웃을 원할 때 사용합니다. 트리거: '그리드에 내 변형 배열', '이 구성 요소 세트 구성', '레이블을 사용하여 변형 레이아웃', '변형 매트릭스 만들기', '내 구성 요소 세트 레이아웃 정리', '내 변형에 행/열 헤더 추가'. 기본적으로 마지막 속성(일반적으로 State)을 열로 선택하고 나머지는 행으로 선택합니다. 기본 MCP의 읽기 전용 도구가 수행하는 작업이 아닙니다. 이는 캔버스에 새로 구성된 레이아웃을 작성합니다.
