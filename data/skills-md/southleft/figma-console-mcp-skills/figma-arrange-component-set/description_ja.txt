Figma COMPONENT_SET のバリアントをきれいなラベル付きグリッドに整理します。行と列はバリアント プロパティから派生し、左側に行ラベル、上部に列ヘッダー、タイトルの付いた白いコンテナが表示されます。バリアント セットが乱雑に山積みになっており、見栄えの良いドキュメント対応のレイアウトが必要な場合に使用します。トリガー: 「バリアントをグリッドに配置する」、「このコンポーネント セットを整理する」、「バリアントをラベル付きでレイアウトする」、「バリアント マトリックスを作成する」、「コンポーネント セットのレイアウトをクリーンアップする」、「バリアントに行/列ヘッダーを追加する」。デフォルトでは、最後のプロパティ (通常は State) が列として選択され、残りが行として選択されます。ネイティブ MCP の読み取り専用ツールが行うものではありません。これは、整理された新しいレイアウトをキャンバスに書き込みます。
