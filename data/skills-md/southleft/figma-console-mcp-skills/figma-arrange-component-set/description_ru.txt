Организуйте варианты Figma COMPONENT_SET в чистую сетку с метками — строки и столбцы, полученные из свойств варианта, с метками строк слева, заголовками столбцов сверху и белым контейнером с названием. Используйте, когда набор вариантов представляет собой беспорядочную кучу и вам нужен презентабельный, готовый к документации макет — триггеры: «упорядочить мои варианты в сетке», «организовать этот набор компонентов», «разместить варианты с метками», «создать матрицу вариантов», «очистить макет моего набора компонентов», «добавить заголовки строк/столбцов к моим вариантам». По умолчанию выбирает последнее свойство (обычно State) в виде столбцов, а остальные — в виде строк. НЕ то, что делают встроенные инструменты MCP только для чтения — это записывает новый организованный макет на холст.
