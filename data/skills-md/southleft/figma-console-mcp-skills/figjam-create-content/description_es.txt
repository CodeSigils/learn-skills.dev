Cree tableros FigJam con control granular: notas adhesivas (individuales + por lotes), conectores entre nodos, formas con texto, secciones, tablas, bloques de código y organización automática, además de leer el contenido del tablero y el gráfico de conexión. Úselo cuando el usuario quiera construir o editar un tablero FigJam elemento por elemento. Activadores: 'agregar notas adhesivas a FigJam', 'crear un diagrama de flujo/diagrama en FigJam', 'conectar estos nodos', 'crear una sección/tabla/bloque de código en FigJam', 'organizar automáticamente el tablero', 'leer lo que hay en el tablero de FigJam', 'mapear las conexiones'. Más granular que el generate_diagram nativo (que produce un diagrama completo de una sola vez). Solo archivos FigJam (figma.editorType === 'figjam'). Requiere la aplicación Figma Desktop (API de complemento).
