Créez des tableaux FigJam avec un contrôle granulaire — notes autocollantes (uniques + lots), connecteurs entre nœuds, formes avec texte, sections, tableaux, blocs de code et organisation automatique — ainsi que la relecture du contenu du tableau et du graphique de connexion. À utiliser lorsque l'utilisateur souhaite créer ou modifier un tableau FigJam élément par élément. Déclencheurs : « ajouter des stickies à FigJam », « créer un organigramme/diagramme dans FigJam », « connecter ces nœuds », « créer une section/table/bloc de code dans FigJam », « organiser automatiquement le tableau », « lire ce qu'il y a sur le tableau FigJam », « mapper les connexions ». Plus granulaire que le generate_diagram natif (qui produit un diagramme complet en une seule fois). Fichiers FigJam uniquement (figma.editorType === 'figjam'). Nécessite l'application Figma Desktop (API du plugin).
