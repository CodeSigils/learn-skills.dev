Создавайте полную документацию Markdown для компонента Figma — анатомию/дерево слоев, токены дизайна (цвета, интервалы, типографика), матрицу состояний/вариантов, примечания о доступности, рекомендации по содержанию и дополнительную проверку четности кода + заголовок YAML. Используйте, когда пользователю нужна страница документации или спецификация передачи для компонента или набора компонентов. Триггеры: «задокументировать этот компонент», «создать документацию/спецификацию компонента», «создать страницу документации для кнопки», «записать анатомию и варианты», «документ передачи компонента из Figma», «превратить этот компонент в документацию Markdown». Считывает дерево узлов, связанные переменные/токены и аннотации дизайнера, затем агент собирает Markdown. Требуется приложение Figma Desktop (API плагина).
