Générez une documentation Markdown complète pour un composant Figma : anatomie/arbre de couches, jetons de conception (couleurs, espacement, typographie), matrice d'états/variantes, notes d'accessibilité, directives de contenu et parité de code facultative + frontmatter YAML. À utiliser lorsque l'utilisateur souhaite une page de documentation ou une spécification de transfert pour un composant ou un ensemble de composants. Déclencheurs : « documenter ce composant », « générer des documents/spécifications de composant », « créer une page de documentation pour le bouton », « rédiger l'anatomie et les variantes », « document de transfert de composant à partir de Figma », « transformer ce composant en documents Markdown ». Lit l'arborescence des nœuds, les variables/jetons liés et les annotations du concepteur, puis l'agent assemble Markdown. Nécessite l'application Figma Desktop (API du plugin).
