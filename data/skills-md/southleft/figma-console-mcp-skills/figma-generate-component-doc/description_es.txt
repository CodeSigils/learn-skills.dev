Genere documentación de Markdown completa para un componente de Figma: anatomía/árbol de capas, tokens de diseño (colores, espaciado, tipografía), matriz de estados/variantes, notas de accesibilidad, pautas de contenido y paridad de código opcional + contenido frontal YAML. Úselo cuando el usuario desee una página de documentos o una especificación de transferencia para un componente o conjunto de componentes. Activadores: 'documentar este componente', 'generar documentos/especificaciones del componente', 'crear una página de documentos para el botón', 'escribir la anatomía y las variantes', 'documento de transferencia de componentes de Figma', 'convertir este componente en documentos de Markdown'. Lee el árbol de nodos, las variables/tokens vinculados y las anotaciones del diseñador, luego el agente ensambla Markdown. Requiere la aplicación Figma Desktop (API de complemento).
