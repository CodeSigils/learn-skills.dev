Generieren Sie eine vollständige Markdown-Dokumentation für eine Figma-Komponente – Anatomie/Ebenenbaum, Design-Tokens (Farben, Abstände, Typografie), Status-/Variantenmatrix, Hinweise zur Barrierefreiheit, Inhaltsrichtlinien und optionale Codeparität + YAML-Frontmatter. Verwenden Sie diese Option, wenn der Benutzer eine Dokumentationsseite oder eine Übergabespezifikation für eine Komponente oder einen Komponentensatz wünscht. Auslöser: „Diese Komponente dokumentieren“, „Komponentendokumente/-spezifikation generieren“, „Dokumentseite für den Button erstellen“, „Anatomie und Varianten aufschreiben“, „Komponentenübergabedokument von Figma“, „Diese Komponente in Markdown-Dokumente umwandeln“. Liest den Knotenbaum, gebundene Variablen/Tokens und Designeranmerkungen, dann stellt der Agent Markdown zusammen. Erfordert die Figma Desktop-App (Plugin-API).
