Figma コンポーネントの完全な Markdown ドキュメント (解剖学/レイヤー ツリー、デザイン トークン (色、間隔、タイポグラフィ)、状態/バリアント マトリックス、アクセシビリティ ノート、コンテンツ ガイドライン、およびオプションのコード パリティ + YAML フロントマター) を生成します。ユーザーがコンポーネントまたはコンポーネント セットのドキュメント ページまたはハンドオフ仕様を必要とする場合に使用します。トリガー: 「このコンポーネントの文書化」、「コンポーネントのドキュメント/仕様の生成」、「ボタンのドキュメント ページの作成」、「構造とバリアントの作成」、「Figma からのコンポーネントのハンドオフ ドキュメント」、「このコンポーネントの Markdown ドキュメントへの変換」。ノード ツリー、バインドされた変数/トークン、およびデザイナーの注釈を読み取り、エージェントが Markdown をアセンブルします。 Figma デスクトップ アプリ (プラグイン API) が必要です。
