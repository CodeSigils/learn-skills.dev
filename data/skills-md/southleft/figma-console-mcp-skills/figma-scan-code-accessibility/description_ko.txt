JSDOM에서 실행되는 axe-core(Deque)를 사용하여 생성/작성된 HTML에서 접근성 위반을 검사합니다. 구조적 및 의미론적 규칙: ARIA 속성 및 역할, 액세스 가능한 이름, 대체 텍스트, 양식 레이블, 제목 순서, 랜드마크, 의미론적 HTML, tabindex, 중복 ID, lang 속성 등 ~50개 이상. Figma-코드 워크플로의 CODE 측에서 사용: '접근성을 위해 이 HTML 스캔', '내 구성 요소에서 도끼 실행', 'a11y에 대해 생성된 코드 확인', 'axe-core 스캔', '내 마크업 접근성 린트', '코드에서 WCAG 확인', '이 HTML에 액세스할 수 있습니까?'를 트리거합니다. 이것은 독립형 노드 스크립트입니다. Figma 연결이 필요하지 않습니다. JSDOM에는 레이아웃이 없기 때문에 시각적 규칙(색상 대비, 초점 표시, 텍스트 블록 내 링크, 대상 크기)이 비활성화됩니다. 디자인 측면에서 시각적 a11y를 위해 figma-lint-design을 사용하세요. 두 가지를 함께 사용하면 완전한 디자인+코드 적용 범위를 제공합니다.
