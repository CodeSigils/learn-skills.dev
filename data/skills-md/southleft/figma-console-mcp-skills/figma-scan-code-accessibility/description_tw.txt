使用執行在 JSDOM 上的 axe-core (Deque) 掃描產生/創作的 HTML 是否存在可訪問性違規 — 結構和語義規則：ARIA 屬性和角色、可存取名稱、替代文字、表單標籤、標題順序、地標、語義 HTML、tabindex、重複 ID、lang 屬性等約 50 個。在 Figma 到程式碼工作流程的 CODE 端使用：觸發「掃描此 HTML 的可訪問性」、「在我的元件上執行 ax」、「檢查產生的 a11y 程式碼」、「axe-core 掃描」、「可訪問性 lint 我的標記」、「WCAG 檢查程式碼」、「此 HTML 是否可存取」。这是一个独立的 Node 脚本 — 无需 Figma 连接。視覺規則（顏色對比度、焦點可見、連結文字區塊、目標大小）被停用，因為 JSDOM 沒有佈局 - 在設計方面使用Figma-lint-design 進行視覺 a11y。两者一起提供完整的设计+代码覆盖率。
