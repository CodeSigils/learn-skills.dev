Сканируйте сгенерированный/авторский HTML-код на наличие нарушений доступности с помощью axe-core (Deque), работающего поверх JSDOM. Структурные и семантические правила: атрибуты и роли ARIA, доступные имена, замещающий текст, метки форм, порядок заголовков, ориентиры, семантический HTML, tabindex, повторяющиеся идентификаторы, атрибут lang и еще около 50. Используйте на стороне КОДА рабочего процесса преобразования Figma в код: триггеры «сканировать этот HTML на предмет доступности», «запустить ax на моем компоненте», «проверить сгенерированный код на a11y», «сканирование ядра топора», «проверка доступности моей разметки», «проверка кода WCAG», «доступен ли этот HTML». Это автономный скрипт Node — подключение к Figma НЕ требуется. Визуальные правила (цветовой контраст, видимость фокуса, ссылка в текстовом блоке, целевой размер) ОТКЛЮЧЕНЫ, поскольку в JSDOM нет макета — используйте Figma-lint-design для визуального контроля на стороне дизайна. Вместе они обеспечивают полный охват дизайна и кода.
