Сканируйте сгенерированный/авторский HTML-код на наличие нарушений доступности с помощью axe-core (Deque), работающего поверх JSDOM. Структурные и семантические правила: атрибуты и роли ARIA, доступные имена, замещающий текст, метки форм, порядок заголовков, ориентиры, семантический HTML, tabindex, повторяющиеся идентификаторы, атрибут lang и еще около 50. Используйте на стороне КОДА в рабочем процессе преобразования Figma в код: триггеры «сканировать этот HTML на предмет доступности», «запустить ax на моем компоненте», «проверить сгенерированный код на a11y», «сканировать ядро ​​топора», «проверить доступность моей разметки», «проверить код WCAG», «доступен ли этот HTML». Это автономный скрипт Node — подключение к Figma НЕ требуется. Визуальные правила (цветовой контраст, видимость фокуса, ссылка в текстовом блоке, целевой размер) ОТКЛЮЧЕНЫ, поскольку в JSDOM нет макета — используйте Figma-lint-design для визуального контроля на стороне дизайна. Вместе они обеспечивают полный охват дизайна и кода.
