使用运行在 JSDOM 上的 axe-core (Deque) 扫描生成/创作的 HTML 是否存在可访问性违规 — 结构和语义规则：ARIA 属性和角色、可访问名称、替代文本、表单标签、标题顺序、地标、语义 HTML、tabindex、重复 ID、lang 属性等约 50 个。在 Figma 到代码工作流程的 CODE 端使用：触发“扫描此 HTML 的可访问性”、“在我的组件上运行 ax”、“检查生成的 a11y 代码”、“axe-core 扫描”、“可访问性 lint 我的标记”、“WCAG 检查代码”、“此 HTML 是否可访问”。这是一个独立的 Node 脚本 — 无需 Figma 连接。视觉规则（颜色对比度、焦点可见、链接文本块、目标大小）被禁用，因为 JSDOM 没有布局 - 在设计方面使用Figma-lint-design 进行视觉 a11y。两者一起提供完整的设计+代码覆盖率。
