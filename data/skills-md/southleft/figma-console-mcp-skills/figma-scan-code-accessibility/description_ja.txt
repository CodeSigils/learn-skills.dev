JSDOM 上で実行される axe-core (Deque) を使用して、生成/作成された HTML のアクセシビリティ違反をスキャンします。構造ルールとセマンティック ルール: ARIA 属性とロール、アクセシブルな名前、代替テキスト、フォーム ラベル、見出し順序、ランドマーク、セマンティック HTML、tabindex、重複 ID、lang 属性、および最大 50 個以上。 Figma からコードへのワークフローの CODE 側で使用します。トリガーは、「この HTML のアクセシビリティをスキャンする」、「コンポーネントで ax を実行する」、「生成されたコードの a11y をチェックする」、「axe-core スキャン」、「マークアップのアクセシビリティをリントする」、「コードの WCAG チェック」、「この HTML はアクセシビリティ可能か」をトリガーします。これはスタンドアロンのノード スクリプトです。Figma 接続は必要ありません。 JSDOM にはレイアウトがないため、ビジュアル ルール (カラー コントラスト、フォーカスの可視性、テキスト ブロック内のリンク、ターゲット サイズ) が無効になります。デザイン側で視覚的に調整するには figma-lint-design を使用してください。この 2 つを組み合わせると、デザインとコードを完全にカバーできます。
