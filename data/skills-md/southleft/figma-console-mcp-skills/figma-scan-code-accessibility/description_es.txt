Escanee HTML generado/creado en busca de infracciones de accesibilidad con axe-core (Deque) ejecutándose sobre JSDOM: reglas estructurales y semánticas: atributos y funciones ARIA, nombres accesibles, texto alternativo, etiquetas de formulario, orden de encabezados, puntos de referencia, HTML semántico, tabindex, ID duplicados, atributo lang y ~50 más. Úselo en el lado CÓDIGO de un flujo de trabajo de Figma a código: activadores 'escanear este HTML para accesibilidad', 'ejecutar ax en mi componente', 'verificar el código generado para todos los años', 'escaneo de axe-core', 'accesibilidad lint my markup', 'comprobación WCAG en el código', '¿este HTML es accesible'? Este es un script de Nodo independiente: NO se requiere conexión Figma. Las reglas visuales (contraste de color, enfoque visible, enlace en bloque de texto, tamaño de destino) están DESACTIVADAS porque JSDOM no tiene diseño; use figma-lint-design para todo visual en el lado del diseño. Los dos juntos brindan una cobertura completa de diseño y código.
