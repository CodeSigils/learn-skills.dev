WCAG 2.2 のアクセシビリティとデザイン システムの品質 (コントラスト、ターゲット サイズ、フォーカス インジケーター、色のみのシグナリング、ハードコードされた色、欠落しているテキスト スタイル、切り離されたコンポーネントなど) を実現するために、Figma ノード ツリーを lint します。ユーザーがハンドオフの前にデザイン側の監査を希望する場合に使用します。「このフレームをリントする」、「アクセシビリティをチェックする」、「WCAG 監査」、「デザインはアクセス可能か」、「コントラストの問題を見つける」、「カラー コントラストをチェックする」、「ハードコードされたカラーを見つける」、「トークンを使用しているコンポーネントはないか」、「デザイン QA」、「このページでデザインをチェックする」、「デザインの問題を監査する」をトリガーします。ノード (またはページ全体) からツリーをたどって、重大度 (重大/警告/情報) および WCAG レベル (A/AA/AAA/ベストプラクティス) を含む結果を返します。ネイティブの Figma MCP にはデザイン側のリンティングはありません。これはこのコレクションに特有のものです。コンポーネントごとの詳細な a11y スコアカードの場合は、figma-audit-accessibility を使用します。 CODE 側 (HTML) チェックには figma-scan-code-accessibility を使用します。
