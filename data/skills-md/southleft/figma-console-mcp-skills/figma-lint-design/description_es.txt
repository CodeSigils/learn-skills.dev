Conecte un árbol de nodos Figma para accesibilidad WCAG 2.2 Y calidad del sistema de diseño: contraste, tamaño objetivo, indicadores de enfoque, señalización de solo color, colores codificados, estilos de texto faltantes, componentes separados y más. Úselo cuando el usuario desee una auditoría del lado del diseño ANTES de la transferencia: activa 'pelusa este marco', 'verificar accesibilidad', 'auditoría WCAG', 'mi diseño es accesible', 'encontrar problemas de contraste', 'verificar contraste de color', 'buscar colores codificados', 'mis componentes usan tokens', 'control de calidad del diseño', 'verificar en esta página', 'auditar mi diseño para detectar problemas'. Recorre el árbol desde un nodo (o toda la página) y devuelve resultados con gravedad (crítica/advertencia/información) y nivel WCAG (A/AA/AAA/mejores prácticas). El Figma MCP nativo NO tiene pelusas en el lado del diseño; esto es exclusivo de esta colección. Para el cuadro de mando completo por componente, utilice figma-audit-accessibility; para verificaciones del lado del CÓDIGO (HTML), utilice figma-scan-code-accessibility.
