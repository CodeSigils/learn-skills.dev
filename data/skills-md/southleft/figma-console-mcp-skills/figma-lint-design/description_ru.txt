Свяжите дерево узлов Figma для обеспечения доступности WCAG 2.2 И качества системы дизайна — контрастности, целевого размера, индикаторов фокуса, сигнализации только цвета, жестко закодированных цветов, отсутствующих стилей текста, отдельных компонентов и т. д. Используйте, когда пользователь хочет провести аудит на стороне дизайна ПЕРЕД передачей: триггеры «проверить этот кадр», «проверить доступность», «аудит WCAG», «доступен ли мой дизайн», «найти проблемы с контрастностью», «проверить цветовой контраст», «найти жестко запрограммированные цвета», «используют ли мои компоненты токены», «контроль качества дизайна», «проверить на этой странице», «проверить мой дизайн на наличие проблем». Проходит по дереву от узла (или всей страницы) и возвращает результаты с указанием серьезности (критическое/предупреждение/информация) и уровня WCAG (A/AA/AAA/лучшая практика). В родном Figma MCP НЕТ линтинга на стороне дизайна — это уникально для этой коллекции. Для глубокой системы показателей a11y для каждого компонента используйте Figma-audit-accessibility; для проверок на стороне КОДА (HTML) используйте Figma-scan-code-accessibility.
