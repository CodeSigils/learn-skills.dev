Figma 노드의 실제 사양을 코드 사양(구성 요소가 렌더링하는 값)과 비교하고 0~100의 패리티 점수, 불일치 목록 및 수정 제안을 얻습니다. 디자인-코드 DRIFT 감지에 사용: '디자인 패리티 확인', '내 코드가 Figma와 일치합니까', '이 구성 요소를 디자인과 비교', '내 구현이 충실합니까', '디자인과 코드 간의 차이점 찾기', '빌드가 Figma와 일치하는지 확인', '코드에 대한 디자인 QA', '패리티 점수'를 트리거합니다. use_figma(모든 계획)를 통해 노드의 시각적/입력 체계/간격/토큰/접근성 사양을 읽고 이를 제공한 codeSpec과 비교합니다. 기본 get_design_context를 보완합니다. 코드 생성 대신 기존 코드가 디자인과 동기화되어 있는지 확인합니다.
