Comparez les spécifications réelles d'un nœud Figma avec une spécification de code (les valeurs restituées par votre composant) et obtenez un score de parité de 0 à 100, une liste des écarts et des suggestions de correction. Utilisé pour détecter la DRIFT conception-code : déclenche « vérifier la parité de la conception », « mon code correspond-il à Figma », « comparer ce composant à la conception », « mon implémentation est-elle fidèle », « trouver les différences entre la conception et le code », « vérifier que la construction correspond à Figma », « l'assurance qualité de la conception par rapport au code », « le score de parité ». Lit les spécifications visuelles/typographie/espacement/jeton/accessibilité du nœud via use_figma (n'importe quel plan) et les compare à une spécification de code que vous fournissez. Complète le get_design_context natif : au lieu de GÉNÉRER du code, il VALIDE que le code existant est resté synchronisé avec la conception.
