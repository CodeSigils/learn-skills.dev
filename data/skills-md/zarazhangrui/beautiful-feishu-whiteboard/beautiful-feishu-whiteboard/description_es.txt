Una biblioteca de 35 estilos de paleta de colores seleccionados para crear hermosas pizarras blancas Feishu/Lark (飞书) editables a partir de SVG. Úselo siempre que el usuario quiera crear o dibujar una pizarra, una infografía, un diagrama, un póster o una explicación visual de Feishu y quiera que se vea pulido, acorde a la marca o con una estética particular, o cuando nombre un estilo. El agente determina qué tablero quiere el usuario, pregunta sobre el ambiente visual, elige un estilo adecuado del catálogo, genera una pizarra Feishu editable, devuelve el enlace del documento y la imagen renderizada, y ofrece cambiar de estilo. Requiere lark-cli (npm @larksuite/cli) instalado y autenticado, y una cuenta Feishu/Lark.
