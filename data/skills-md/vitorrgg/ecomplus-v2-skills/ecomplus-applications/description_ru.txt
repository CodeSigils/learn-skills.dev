Используйте этот навык для просмотра, проверки и настройки приложений, установленных на платформе E-Com Plus. Сюда входят: список приложений, проверка конфигурации (data/hidden_data), настройка конфигурации приложения, просмотр журналов аудитории API и просмотр журналов выполнения GCP (облачные функции Firebase через gcloud CLI). Доступные сведения: приложение, приложение, интеграция, конфигурация, данные, скрытые_данные, журналы, аудитория, журнал изменений, торговая площадка, модуль, GCP, gcloud, Firebase, облачные функции, ошибки работы, журналы выполнения.
