Captura de memoria estructurada para memoria compartida Ogham. Usar cuando el usuario quiera
almacenar hallazgos, recordar algo, guardar lo aprendido o capturar una decisión.
Activadores de "recordar esto", "almacenar esto", "guardar este hallazgo", "guardar lo que aprendimos",
"capturar esta decisión", "registrar esto" o cualquier solicitud para conservar el conocimiento en Ogham.
Utilícelo también cuando el usuario diga "almacenar en ogham", "guardar en la memoria" o "recordar para más tarde".
Requiere que el servidor Ogham MCP esté conectado.
