Eine Anleitung, die beim Schreiben neuer Fertigkeiten oder beim Ändern vorhandener Fertigkeiten in diesem Repo verwendet wird. Ausgelöst durch Anfragen wie „Erstellen Sie einen Skill für mich“, „Fügen Sie einen neuen Skill hinzu“, „Schreiben Sie SKILL.md“, „Skillstruktur“, „Ändern Sie den Skill“, „Skillleitfaden“, „Beschreibung verfeinern“, „Schreiben Sie den Titeltext“, „Validieren Sie den Skill“ usw. Bietet Skillspezifikationen (Titeltext, Beschreibung, Progressive Disclosure), Verzeichnisstrukturmuster und Schreibprinzipien.
