Конкурентное многоагентное решение проблем: создает несколько субагентов Claude Code в параллельных рабочих деревьях git для независимого решения одной и той же задачи программирования, затем перекрестно обрабатывает их решения посредством раундов улучшения, где каждый агент видит и учится на различиях всех других, и, наконец, выбирает лучшее решение посредством консенсусного голосования подсчета Борда с независимыми судьями. Используйте этот навык всякий раз, когда пользователь говорит «скачки», «гонки», «конкурировать», «мультиагент», хочет сравнить несколько подходов к проблеме или хочет получить более качественные решения посредством конкурентной итерации. Также срабатывает, когда пользователи хотят параллельных реализаций, турниров по решениям или сравнений A/B подходов к коду.
