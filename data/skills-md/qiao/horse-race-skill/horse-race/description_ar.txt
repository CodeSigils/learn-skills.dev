حل المشكلات التنافسي متعدد الوكلاء: إنشاء وكلاء فرعيين متعددين لـ Claude Code في أشجار عمل git متوازية لحل نفس مهمة البرمجة بشكل مستقل، ثم التلقيح المتبادل لحلولهم من خلال جولات التحسين حيث يرى كل وكيل اختلافات الآخرين ويتعلم منها، وأخيرًا يختار الحل الأفضل من خلال التصويت بالإجماع على عدد بوردا مع قضاة مستقلين. استخدم هذه المهارة عندما يقول المستخدم "سباق الخيل"، "سباق"، "تنافس"، "متعدد الوكلاء"، أو يريد مقارنة طرق متعددة لحل مشكلة ما، أو يريد حلولًا عالية الجودة من خلال التكرار التنافسي. يتم تشغيله أيضًا عندما يريد المستخدمون عمليات تنفيذ متوازية، أو دورات حلول، أو مقارنات A/B لأساليب التعليمات البرمجية.
