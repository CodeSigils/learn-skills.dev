2Dキャラクターのスキル蒸留器。キャラクター名+作品タイトルを入力し、ローカルでコアデータを取得→相互検証→動作抽出→実行可能・追跡可能・更新可能なキャラクタースキルを生成。トリガーフレーズ：「○○のスキルを生成する」、「○○を蒸留する」、「○○キャラクターを作る」、「○○をスキルに変える」、「○○を作成する」、「/csp」。 「ツンデレキャラクターについて話したい」「ヤンデレのおすすめがあれば」「○○作品のキャラクターを作るのを手伝ってほしい」など、漠然としたリクエストも発生します。 Python に依存します。コア サイトはローカル スクリプトを優先しますが、Web 検索スキル / MCP / WebFetch は強化とフォールバックとしてのみ使用されます。
