Дистиллятор навыков 2D-персонажа. Введите имя персонажа + должность, локально получите основные данные → перекрестная проверка → анализ поведения → создайте работоспособный, отслеживаемый и обновляемый навык персонажа. Триггерные фразы: «создать навык XX», «очистить XX», «создать персонажа XX», «превратить XX в навык», «создать XX», «/csp». Также вызывают неясные запросы: «хочу поговорить о персонаже цундере», «любые рекомендации яндере», «помогите мне заставить персонажа из ХХ работать». Зависит от Python; основной сайт предпочитает локальные скрипты, в то время как навыки веб-поиска / MCP / WebFetch используются только в качестве усиления и резервного варианта.
