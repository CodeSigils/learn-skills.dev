Distillateur de compétences de personnage 2D. Saisissez un nom de personnage + un titre de travail, récupérez localement les données de base → validation croisée → distillation du comportement → générez une compétence de personnage exécutable, traçable et actualisable. Phrases déclencheurs : "générer la compétence XX", "distiller XX", "créer un personnage XX", "transformer XX en compétence", "créer un XX", "/csp". Des requêtes vagues déclenchent également : "je veux parler d'un personnage tsundere", "des recommandations yandere", "aidez-moi à faire fonctionner un personnage de XX". Dépend de Python ; le site principal préfère les scripts locaux, tandis que la compétence de recherche sur le Web / MCP / WebFetch n'est utilisée qu'à titre de renforcement et de secours.
