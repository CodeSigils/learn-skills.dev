2D-Charakter-Skill-Destiller. Geben Sie einen Charakternamen + Arbeitstitel ein, rufen Sie lokal Kerndaten ab → Kreuzvalidierung → Verhaltensdestillation → generieren Sie eine ausführbare, nachvollziehbare und aktualisierbare Charakterfähigkeit. Auslöserphrasen: „X-Skill generieren“, „XX destillieren“, „einen XX-Charakter erstellen“, „XX in einen Skill umwandeln“, „ein XX erstellen“, „/csp“. Vage Anfragen lösen auch Folgendes aus: „Möchte über einen Tsundere-Charakter sprechen“, „Irgendwelche Yandere-Empfehlungen“, „Hilf mir, einen Charakter aus XX zum Laufen zu bringen“. Hängt von Python ab; Die Kernseite bevorzugt lokale Skripte, während Websuchfähigkeiten/MCP/WebFetch nur als Verstärkung und Fallback verwendet werden.
