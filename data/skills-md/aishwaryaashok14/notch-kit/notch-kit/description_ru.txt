Создавайте приложения с вырезом для macOS, которые размещаются в вырезе для камеры MacBook. Используйте, когда пользователь хочет создать строку меню или служебное приложение Notch для macOS. Предоставляет NotchPanel, NotchShape, возможность развертывания/свертывания при наведении, обнаружение вырезов и шаблон SwiftUI для настройки.
