Module d'examen des données WeWrite : récupérez les mesures de lecture, de partage et similaires pour les articles du compte public WeChat, remplissez les enregistrements historiques et proposez des suggestions pour ajuster les sujets, les titres et la structure.  
Mots clés déclencheurs : « vérifier les données de l'article », « comment sont les données de l'article », « effectuer l'évaluation », « vérifier les performances », « comment est le nombre de vues ».  
Nécessite un compte public/un contexte WeWrite ; ne devrait pas être déclenché par une « analyse de données » générique.
