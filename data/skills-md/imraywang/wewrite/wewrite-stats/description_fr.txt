Module d'examen des données WeWrite : extrait les données de lecture, de partage et d'appréciation des articles du compte public WeChat, remplit les enregistrements historiques et propose des suggestions pour ajuster les sujets, les titres et les structures. Mots-clés déclencheurs : « vérifier les données de l'article », « comment sont les données de l'article », « effectuer l'évaluation », « voir les performances », « comment est le lectorat ». Nécessite un contexte de compte public/WeWrite ; ne devrait pas être déclenché par une « analyse de données » générique.
