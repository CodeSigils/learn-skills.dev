Módulo de autoaprendizaje WeWrite: aprende las preferencias de escritura a partir de las ediciones manuales de los usuarios (volante del libro de estrategias), importa textos ejemplares para crear una biblioteca de estilos y aprende temas de diseño de artículos de cuentas públicas.  

Palabras clave desencadenantes: "conocer mis ediciones", "lo cambié, aprenderlo", "importar ejemplar", "conocer este artículo", "ver biblioteca de ejemplos", "conocer diseño", "estudiar diseño".  

No debe activarse mediante términos genéricos como "aprender" o "resumir este artículo"; requiere contexto de una cuenta pública/WeWrite.
