WeWrite style configuration module: first-use onboarding + resetting the public account writing style configuration (style.yaml). Trigger keywords: reset style, modify style configuration, set public account style, first-time public account setup, change writing persona, adjust layout theme preference. It is also automatically activated by the main entry point wewrite when style.yaml is missing. It should not be triggered by generic terms like “change writing style” or “polish”—those are editing actions, not configuration actions.
