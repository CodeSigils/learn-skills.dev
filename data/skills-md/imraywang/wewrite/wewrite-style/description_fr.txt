Module de configuration de style WeWrite : intégration à la première utilisation + réinitialisation de la configuration du style d'écriture du compte public (style.yaml). Mots-clés déclencheurs : réinitialiser le style, modifier la configuration du style, définir le style du compte public, configurer le compte public pour la première fois, modifier le personnage d'écriture, ajuster les préférences du thème de mise en page. Il est également automatiquement activé par le point d'entrée principal wewrite lorsque style.yaml est manquant. Il ne doit pas être déclenché par des termes génériques tels que « modifier le style d’écriture » ou « peaufiner » : il s’agit d’actions d’édition et non d’actions de configuration.
