Module de configuration du style WeWrite : première intégration + réinitialisation de la configuration du style d'écriture du compte public (style.yaml). Mots-clés déclencheurs : réinitialiser le style, modifier la configuration du style, définir le style du compte public, configurer le compte public pour la première fois, modifier le personnage d'écriture, ajuster les préférences de thème de mise en page. Il est également automatiquement activé par le point d'entrée principal wewrite lorsque style.yaml est manquant. Il ne doit pas être déclenché par le générique « modifier le style d’écriture » ou le « peaufiner » – ce sont des actions d’édition, pas des actions de configuration.
