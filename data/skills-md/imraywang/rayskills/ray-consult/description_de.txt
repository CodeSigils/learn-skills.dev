Enterprise Knowledge Base/KI-Implementierungsberatung aus einer Hand – Vordiagnose + Blueprint. Verwenden Sie in der Diagnosephase das sechsdimensionale GROUND-Modell, um die Bereitschaft zu bewerten, führen Sie eine Bedarfsarchäologie durch, um das „echte Problem“ aufzudecken, gleichen Sie Läsionsmuster ab und geben Sie einen Reifegrad + eine rot-gelb-grüne Machbarkeitsbewertung + Bedingungen für die Umstellung auf grün aus. Bauen Sie in der Lösungsphase auf den Schlussfolgerungen der Diagnose auf und beantworten Sie die vier Fragen der Lösung: Was soll erstellt werden (vier Schichten der Referenzarchitektur), was soll für den Aufbau verwendet werden (Auswahl-Entscheidungsbaum), in welcher Reihenfolge soll erstellt werden (Phase0-3-Staging) und wer wird es verwalten (operative Rollen und Mechanismen). Wenn ein Benutzer beurteilen muss, ob ein Unternehmen eine Wissensdatenbank/einen KI-Assistenten/RAG/Enterprise-Agent einführen, Projektrisiken bewerten, Wissensmanagement-Gesundheitsprüfungen durchführen kann oder über bestehende Diagnoseschlussfolgerungen verfügt, die einen Lösungsentwurf/eine abgestufte Roadmap/Auswahlempfehlungen/Preisstruktur erfordern, oder ob eine Ampeldiagnose in einen Aktionsplan umgewandelt werden soll, der „die Voraussetzungen erfüllt“, verwenden Sie diese Fähigkeit. Auslöser: /ray-consult „Unternehmenssituation oder Anfrage“ (Start mit Diagnose), /ray-consult „Diagnose Fazit“ (direkt zur Lösung gehen). Nicht für: reine technische Auswahl/Vergleich ohne Implementierungsplan, Wissensmanagement für Einzelpersonen/kleine Teams.
