Cree, inspeccione o adapte gradualmente una base de conocimientos de Obsidian almacenada localmente y diseñada para la producción de contenidos y conocimientos a largo plazo, reutilizando los materiales, conocimientos, temas candidatos, tareas de escritura, investigaciones, artículos y borradores de guiones hablados de Ray, comentarios sobre publicaciones y capas de comentarios sobre conocimientos. Se utiliza para solicitudes como "Ayúdame a configurar una base de conocimientos de Obsidian", "Preparar una base de conocimientos local para ray-writer", "Integrar una bóveda existente en el proceso de producción de contenido" o "Verificar si la estructura de la base de conocimientos está completa" y también cuando ray-writer no puede encontrar una base de conocimientos compatible. Solo agrega estructuras faltantes, sin sobrescribir, mover o eliminar las notas existentes del usuario, y no fuerza la instalación de complementos, servicios de sincronización o Git.
