Realizar una división del trabajo mínima y suficiente entre Grok, Claude y Codex según el valor de la tarea, con la sesión actual actuando como el controlador principal para completar la aceptación. Se utiliza cuando el usuario solicita explícitamente "dejar ir a Grok primero", "colaboración multimodelo", "dos partes brindan soluciones independientes", "competencia de modelos", "buscar una segunda opinión", "usar Grok para buscar X/Reddit/páginas web en tiempo real" o cuando la tarea en sí justifica la ejecución, revisión, competencia o investigación en tiempo real entre modelos. Admite cinco modos de entrada: automático, rápido, revisión, carrera, exploración; scout utiliza un proceso de búsqueda aislado de Grok4.5 para descubrir y retener evidencia de X, Reddit y páginas web, mientras que otros modos seleccionan Grok, Claude o Codex según la tarea. De forma predeterminada, no se utiliza para preguntas y respuestas simples sin ningún beneficio obvio, y no permite que varios modelos escriban en el mismo espacio de trabajo simultáneamente, cambien de modelo silenciosamente o utilicen informes propios del modelo en lugar de la verificación real.
