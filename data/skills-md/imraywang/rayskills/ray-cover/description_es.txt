Convierta artículos, paquetes de manuscritos o textos extensos que ya hayan determinado el juicio central en portadas de cuentas públicas de WeChat, imágenes comunes de X y portadas de backend de artículos X. Extraiga una metáfora visual que pueda entenderse de un vistazo, seleccione una dirección adecuada dentro del sistema visual editorial de Ray y, de forma predeterminada, utilice Imagen2 para generar directamente una portada completa de acuerdo con las dimensiones objetivo de cada plataforma; Los principales criterios de aceptación son la composición, las zonas seguras y la legibilidad de las miniaturas, sin tratar los detalles de la fuente china como una condición de bloqueo. Esto se utiliza al “hacer una portada para este artículo”, “tanto la cuenta pública como X necesitan una portada”, “crear una portada de artículo 5:2”, “usar estilos como Adrian o Vox” o “conectar la producción de contenido al proceso de portada”; no se utiliza para la redacción del cuerpo del texto, la publicación automática ni para vídeos explicativos completos.
