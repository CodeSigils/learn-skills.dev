Convierta artículos, paquetes de manuscritos completos o textos largos que ya hayan sido evaluados en publicaciones de cuentas públicas de WeChat, imágenes comunes de X y portadas de backend de artículos X. Extraiga una metáfora visual que pueda entenderse de un vistazo, elija la dirección adecuada dentro del sistema visual editorial de Ray y, de forma predeterminada, genere la portada completa utilizando Image2 para las dimensiones objetivo de cada plataforma; Los principales criterios de aceptación son la composición, las zonas seguras y la legibilidad de las miniaturas, sin que los detalles de las fuentes chinas sean una condición de bloqueo. Se utiliza al “hacer una portada para este artículo”, “tanto la cuenta pública como X necesitan portadas”, “crear una portada de artículo 5:2”, “usar un estilo como Adrian o Vox” o “vincular la producción de contenido al proceso de portada”; no se utiliza para redacción de texto principal, publicación automática ni vídeos explicativos completos.
