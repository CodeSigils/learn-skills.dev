Lassen Sie PDF-Dokumente so aussehen, als wären sie mit einem physischen Scanner gescannt worden. Wendet realistische Effekte an: Graustufenkonvertierung, Gaußsches Rauschen, leichte Drehung, Unschärfe, Kantenschatten und zufälliger Versatz. Extrahieren Sie optional echte handschriftliche Signaturen aus einem Quell-PDF (oder vom Benutzer bereitgestellten Bildern) und ersetzen Sie digitale Signaturen auf bestimmten Seiten. Verwenden Sie diese Option, wenn der Benutzer folgendes wünscht: ein PDF wie gescannt aussehen lassen, einem PDF ein gescanntes Aussehen verleihen, digitale Signaturen durch echte/handschriftliche ersetzen, einen Scan fälschen, Scaneffekte zu einem Dokument hinzufügen oder ein Dokument wie gedruckt und gescannt aussehen lassen.
