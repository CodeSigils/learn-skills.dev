Expertenleitfaden für die effiziente Nutzung des Figma Context MCP (Framelink) bei gleichzeitiger Vermeidung von 429-Rate-Limit-Fehlern. Aktivieren, wenn: (1) Framelink Figma MCP-Tools (get_figma_data, download_figma_images) verwendet werden, (2) Figma-Designs für die Codegenerierung abgerufen werden, (3) der Benutzer 429-Ratengrenzen von der Figma-API erreicht, (4) Design-Tokens oder Komponentendaten aus Figma extrahiert werden, (5) Figma-Assets/Bilder heruntergeladen werden, (6) jeder Design-to-Code-Workflow mit Figma-URLs. Umfasst den Metadaten-First-Abruf, tiefenbegrenzte Knotenbäume, Batch-Image-Downloads, Ratenlimit-Diagnose und Planstufenerkennung.
