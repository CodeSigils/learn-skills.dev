Экспертное руководство по эффективному использованию Figma Context MCP (Framelink), избегая при этом 429 ошибок ограничения скорости. Активируется, когда: (1) используются инструменты Framelink Figma MCP (get_figma_data, download_figma_images), (2) извлекаются проекты Figma для генерации кода, (3) пользователь достигает 429 ограничений скорости из Figma API, (4) извлекает токены дизайна или данные компонентов из Figma, (5) загружает ресурсы/изображения Figma, (6) любой рабочий процесс преобразования дизайна в код, включающий URL-адреса Figma. Охватывает первоначальную выборку метаданных, деревья узлов с ограниченной глубиной, пакетную загрузку изображений, диагностику ограничения скорости и осведомленность на уровне плана.
