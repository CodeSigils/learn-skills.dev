Guía de expertos para utilizar Figma Context MCP (Framelink) de manera eficiente y al mismo tiempo evitar errores de límite de velocidad 429. Actívelo cuando: (1) use las herramientas Framelink Figma MCP (get_figma_data, download_figma_images), (2) obtenga diseños de Figma para la generación de código, (3) el usuario alcance 429 límites de velocidad de Figma API, (4) extraiga tokens de diseño o datos de componentes de Figma, (5) descargue activos/imágenes de Figma, (6) cualquier flujo de trabajo de diseño a código que involucre URL de Figma. Cubre la recuperación de metadatos primero, árboles de nodos de profundidad limitada, descargas de imágenes por lotes, diagnósticos de límite de velocidad y reconocimiento de niveles de plan.
