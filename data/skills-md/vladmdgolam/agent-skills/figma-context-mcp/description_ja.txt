429 レート制限エラーを回避しながら、Figma Context MCP (フレームリンク) を効率的に使用するための専門ガイド。次の場合にアクティブ化します:(1) Framelink Figma MCP ツール (get_figma_data、download_figma_images) を使用する場合、(2) コード生成のために Figma デザインを取得する場合、(3) ユーザーが Figma API から 429 レート制限に達する場合、(4) Figma からデザイン トークンまたはコンポーネント データを抽出する場合、(5) Figma アセット/画像をダウンロードする場合、(6) Figma URL を含むデザインからコードまでのワークフロー。メタデータファーストフェッチ、深さ制限されたノードツリー、バッチイメージダウンロード、レート制限診断、およびプラン層認識をカバーします。
