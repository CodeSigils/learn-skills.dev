Guide d'expert pour utiliser efficacement le Figma Context MCP (Framelink) tout en évitant les erreurs de limite de débit 429. Activez lorsque : (1) vous utilisez les outils Framelink Figma MCP (get_figma_data, download_figma_images), (2) récupérez des conceptions Figma pour la génération de code, (3) l'utilisateur atteint 429 limites de débit à partir de l'API Figma, (4) extrayez des jetons de conception ou des données de composants de Figma, (5) téléchargez des actifs/images Figma, (6) tout flux de travail de conception à code impliquant des URL Figma. Couvre la récupération des métadonnées d'abord, les arborescences de nœuds à profondeur limitée, les téléchargements d'images par lots, les diagnostics de limite de débit et la connaissance des niveaux de plan.
