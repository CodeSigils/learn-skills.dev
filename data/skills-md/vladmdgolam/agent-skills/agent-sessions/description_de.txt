Durchsuchen, Auflisten und Fortsetzen von KI-Agent-Sitzungen in Claude Code, Codex CLI und Gemini CLI. Verwenden Sie diese Option, wenn der Benutzer eine frühere Konversation finden, den Sitzungsverlauf durchsuchen, eine frühere Sitzung fortsetzen, die letzten Agentenaktivitäten auflisten oder überprüfen möchte, was in einer früheren Sitzung besprochen wurde. Verwenden Sie es auch, wenn Sie gefragt werden: „Finde die Konversation, in der ich ...“, „meine letzte Codex-Sitzung fortsetzen“, „Woran habe ich gestern gearbeitet“ oder „meine Claude-Historie nach X durchsuchen“.
