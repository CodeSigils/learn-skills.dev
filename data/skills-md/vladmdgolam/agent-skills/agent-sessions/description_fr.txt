Recherchez, répertoriez et reprenez les sessions d'agent IA dans Claude Code, Codex CLI et Gemini CLI. À utiliser lorsque l'utilisateur demande à retrouver une conversation passée, à rechercher l'historique d'une session, à reprendre une session précédente, à répertorier l'activité récente d'un agent ou à vérifier ce qui a été discuté lors d'une session précédente. Utilisez également lorsqu'on vous demande de "trouver cette conversation où je...", "reprendre ma dernière session de codex", "sur quoi ai-je travaillé hier" ou "rechercher X dans mon historique de Claude".
