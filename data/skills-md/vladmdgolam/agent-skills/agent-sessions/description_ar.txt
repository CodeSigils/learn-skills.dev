ابحث عن جلسات وكيل الذكاء الاصطناعي وأدرجها واستأنفها عبر Claude Code وCodex CLI وGemini CLI. يُستخدم عندما يطلب المستخدم العثور على محادثة سابقة، أو البحث في سجل الجلسة، أو استئناف جلسة سابقة، أو إدراج نشاط الوكيل الحديث، أو التحقق مما تمت مناقشته في جلسة سابقة. استخدم أيضًا عندما يُطلب منك "العثور على تلك المحادثة حيث..." أو "استئناف جلسة المخطوطة الأخيرة" أو "ما الذي عملت عليه بالأمس" أو "البحث في سجل كلود الخاص بي عن X".
