Estrategias de optimización, evaluación comparativa y perfiles de rendimiento de R. Utilice esta habilidad cuando el código se ejecute lentamente, compare implementaciones alternativas, decida entre dplyr/data.table/base R o implemente procesamiento paralelo. Cubre el uso de profvis y banco, flujo de trabajo de rendimiento, procesamiento paralelo con in_parallel(), selección de backend de datos, patrones de ronroneo modernos (list_rbind, walk) y antipatrones de rendimiento comunes que se deben evitar.
