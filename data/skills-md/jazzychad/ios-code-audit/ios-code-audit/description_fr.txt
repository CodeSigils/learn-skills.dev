Exécutez un audit approfondi d'une base de code iOS / macOS Swift (bogues, code mort, duplication, problèmes de concurrence Swift, API obsolètes, sécurité, performances et qualité SwiftUI) et produisez un seul rapport CODE_AUDIT.md navigable avec les résultats file:line-cited. À utiliser lorsque l'utilisateur demande un « audit de code », un « examen complet », « trouver une dette technologique », « que dois-je nettoyer » ou une évaluation similaire à grande échelle d'un projet Swift.
