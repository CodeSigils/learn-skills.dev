Analysiert von Git geänderte Dateien im Arbeitsbereich und führt atomare, funktionale und semantische Commits im herkömmlichen Commit-Format durch. Verwenden Sie diese Option, wenn der Benutzer Änderungen festschreiben, Commits aus bereitgestellten/nicht bereitgestellten Dateien erstellen oder Änderungen im Arbeitsbaum in sinnvolle Commits organisieren möchte.
