Fragen Sie Bewertungen von Forschungsberichten, Leistungsprognosen, ESG, Kreditratings, Unternehmensratings, Fondsratings, Flaggschiffaktien von Brokern und andere institutionelle Standpunktdaten ab; Unterstützen Sie die Eingabe von Fragen in natürlicher Sprache und geben Sie die relevanten Ergebnisse der institutionellen Forschungsdaten zurück. Wenn Benutzer nach Bewertungen von Forschungsberichten, Leistungsprognosen, ESG-Bewertungen, Kreditratings, Unternehmensbewertungen, Fondsbewertungen, Flaggschiffaktien von Brokern oder ähnlichen institutionellen Forschungsdatenabfragen fragen, muss diese Funktion genutzt werden.
