الاستعلام عن تقييمات التقارير البحثية، وتوقعات الأداء، والبيئة البيئية والاجتماعية والحوكمة (ESG)، والتصنيفات الائتمانية، وتقييمات الكيانات، وتقييمات الصناديق، وأسهم الوساطة الرئيسية، وبيانات وجهات النظر المؤسسية الأخرى؛ دعم مدخلات الأسئلة باللغة الطبيعية وإرجاع نتائج بيانات البحوث المؤسسية ذات الصلة. عندما يستفسر المستخدمون عن تصنيفات التقارير البحثية، أو توقعات الأداء، أو تصنيفات الحوكمة البيئية والاجتماعية والحوكمة، أو التصنيفات الائتمانية، أو تصنيفات الكيانات، أو تصنيفات الصناديق، أو أسهم الوساطة الرئيسية، أو أي استعلامات مماثلة عن بيانات الأبحاث المؤسسية، يجب استخدام هذه الإمكانية.
