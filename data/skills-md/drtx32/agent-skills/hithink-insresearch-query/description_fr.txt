Interrogez les notations des rapports de recherche, les prévisions de performances, l'ESG, les notations de crédit, les notations d'entités, les notations de fonds, les actions phares du courtage et d'autres données de point de vue institutionnel ; prendre en charge la saisie de questions en langage naturel et renvoyer les résultats des données de recherche institutionnelles pertinentes.
