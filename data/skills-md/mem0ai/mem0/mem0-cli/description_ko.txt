Mem0 CLI - mem0 메모리 작업을 위한 명령줄 인터페이스입니다. 트리거 시기: 사용자가 "mem0 cli", "mem0 명령줄", "@mem0/cli", "mem0-cli", "pip install mem0-cli", "npm install -g @mem0/cli"를 언급하거나 터미널/셸에서 mem0 명령을 실행하는 경우(mem0 add, mem0 search, mem0 list, mem0 get, mem0 init, mem0 config, mem0 수입). 또한 쿼리에 --user-id, --output, --json, --agent와 같은 CLI 플래그가 포함되거나 bash/zsh/terminal/shell 사용법을 설명하는 경우에도 트리거됩니다. 다음의 경우에는 트리거하지 마세요: 사용자가 Python/TS 코드(mem0 기술 사용) 또는 Vercel AI SDK 공급자(mem0-vercel-ai-sdk 기술 사용)의 프로그래밍 방식 SDK 통합에 대해 질문합니다.
