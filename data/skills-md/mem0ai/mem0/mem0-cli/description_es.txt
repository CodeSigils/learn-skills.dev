Mem0 CLI: la interfaz de línea de comandos para operaciones de memoria mem0. DISPARAR cuando: el usuario menciona "mem0 cli", "mem0 command line", "@mem0/cli", "mem0-cli", "pip install mem0-cli", "npm install -g @mem0/cli", o está ejecutando comandos mem0 en una terminal/shell (mem0 add, mem0 search, mem0 list, mem0 get, mem0 init, mem0 config, mem0 import). También se activa cuando la consulta incluye indicadores CLI como --user-id, --output, --json, --agent o describe el uso de bash/zsh/terminal/shell. NO DISPARAR cuando: el usuario pregunta sobre la integración programática del SDK en el código Python/TS (use la habilidad mem0) o el proveedor de Vercel AI SDK (use la habilidad mem0-vercel-ai-sdk).
