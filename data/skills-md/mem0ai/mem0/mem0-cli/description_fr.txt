Mem0 CLI -- l'interface de ligne de commande pour les opérations de mémoire mem0. DÉCLENCHEMENT lorsque : l'utilisateur mentionne "mem0 cli", "mem0 command line", "@mem0/cli", "mem0-cli", "pip install mem0-cli", "npm install -g @mem0/cli", ou exécute des commandes mem0 dans un terminal/shell (mem0 add, mem0 search, mem0 list, mem0 get, mem0 init, mem0 config, mem0 import). Se déclenche également lorsque la requête inclut des indicateurs CLI tels que --user-id, --output, --json, --agent ou décrit l'utilisation de bash/zsh/terminal/shell. NE PAS DÉCLENCHER lorsque : l'utilisateur pose des questions sur l'intégration du SDK programmatique dans le code Python/TS (utilisez la compétence mem0) ou le fournisseur Vercel AI SDK (utilisez la compétence mem0-vercel-ai-sdk).
