Mem0 CLI — интерфейс командной строки для операций с памятью mem0. ТРИГГЕР, когда: пользователь упоминает «mem0 cli», «командную строку mem0», «@mem0/cli», «mem0-cli», «pip install mem0-cli», «npm install -g @mem0/cli» или запускает команды mem0 в терминале/оболочке (добавление mem0, поиск mem0, список mem0, получение mem0, инициализация mem0, конфигурация mem0, импорт mem0). Также срабатывает, когда запрос включает флаги CLI, такие как --user-id, --output, --json, --agent, или описывает использование bash/zsh/terminal/shell. НЕ АКТИВИРУЙТЕСЬ, когда: пользователь спрашивает об интеграции программного SDK в код Python/TS (используйте навык mem0) или о поставщике Vercel AI SDK (используйте навык mem0-vercel-ai-sdk).
