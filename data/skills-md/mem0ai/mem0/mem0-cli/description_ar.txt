Mem0 CLI - واجهة سطر الأوامر لعمليات ذاكرة mem0. يتم تشغيله عندما: يذكر المستخدم "mem0 cli"، أو "mem0 command line"، أو "@mem0/cli"، أو "mem0-cli"، أو "pip install mem0-cli"، أو "npm install -g @mem0/cli"، أو يقوم بتشغيل أوامر mem0 في محطة طرفية/shell (mem0 add، mem0 search، mem0 list، mem0 get، mem0 init، mem0 config، mem0 import). يتم تشغيله أيضًا عندما يتضمن الاستعلام علامات CLI مثل --user-id، --output، --json، --agent، أو يصف استخدام bash/zsh/terminal/shell. لا تقم بالتشغيل عندما: يسأل المستخدم عن تكامل SDK البرمجي في كود Python/TS (استخدم مهارة mem0)، أو موفر Vercel AI SDK (استخدم مهارة mem0-vercel-ai-sdk).
