Mem0 CLI——mem0 内存操作的命令行界面。触发条件：用户提及“mem0 cli”、“mem0 命令行”、“@mem0/cli”、“mem0-cli”、“pip install mem0-cli”、“npm install -g @mem0/cli”，或者在终端/shell 中运行 mem0 命令（mem0 add、mem0 search、mem0 list、mem0 get、mem0 init、mem0 config、mem0进口）。当查询包含 CLI 标志（例如 --user-id、--output、--json、--agent）或描述 bash/zsh/terminal/shell 用法时也会触发。不要在以下情况下触发：用户询问 Python/TS 代码中的编程 SDK 集成（使用 mem0 技能）或 Vercel AI SDK 提供程序（使用 mem0-vercel-ai-sdk 技能）。
