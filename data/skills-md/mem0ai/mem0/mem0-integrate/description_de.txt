Integrieren Sie Mem0 mithilfe einer zielgerichteten TDD-Pipeline in ein vorhandenes Repository. Erkennt die Sprache des Repos automatisch und fordert den Benutzer auf, zwischen Mem0 Platform (verwaltet) und Mem0 Open Source (selbst gehostet) zu wählen. Schreibt fehlgeschlagene Tests vor jeder Implementierung. Erzeugt einen lokalen Feature-Zweig sowie „.mem0-integration/“-Artefakte, die von der gepaarten Verifizierungskompetenz verbraucht werden. TRIGGER, wenn: Der Benutzer sagt „mem0 integrieren“, „mem0 zu diesem Repo hinzufügen“, „mem0 mit <repo> verbinden“ oder fragt, wie man Speicher zu einem vorhandenen Projekt hinzufügt. NICHT AUSLÖSEN, wenn: der Benutzer eine allgemeine SDK-Nutzung (Skill:mem0 verwenden), CLI-Nutzung (Skill:mem0-cli verwenden) oder das Vercel AI SDK (Skill:mem0-vercel-ai-sdk verwenden) wünscht. Nach Erfolg rufen Sie skills:mem0-test-integration auf, um die Überprüfung im selben Arbeitsbereich durchzuführen (lose Kopplung).
