Поставщик Mem0 для Vercel AI SDK (@mem0/vercel-ai-provider). ЗАПУСКАЕТСЯ, когда: пользователь упоминает "vercel ai sdk", "@mem0/vercel-ai-provider", "createMem0", "getMemories", "addMemories", "getMemories", "searchMemories", "mem0 vercel", "AI SDKProvider", "AI SDK Memory" или используетgenerateText/streamText с mem0. Также срабатывает для приложений Next.js, которым требуется искусственный интеллект с расширенной памятью. НЕ ЗАПУСКАТЬ, когда: пользователь спрашивает о прямых вызовах Python/TS SDK без Vercel (используйте навык mem0) или командах терминала CLI (используйте навык mem0-cli).
