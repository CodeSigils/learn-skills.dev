規劃並執行專案從 mem0 開源/自架 SDK（本機「Memory」類別）到 mem0 平台/託管/託管 SDK（「MemoryClient」類別）的遷移。每當開發人員想要將其 mem0 使用量從 OSS/自託管移動、切換或遷移到託管 API 時，請使用此選項 - 例如「將我的 mem0 設定遷移到平台」、「從自託管 mem0 切換到 MemoryClient」、「使用我的 mem0 API 向量而不是本地端 Qdrant」、「託管 mem 0em」、「使用我的 mem0 API 單元」將「託管 Qdrant」、「本機託管」、「託管」嵌入器配置」。適用於Python（`from mem0 import Memory`→`from mem0 import MemoryClient`）和TypeScript/JavaScript（`import { Memory } from "mem0ai/oss"`→`import MemoryClient from "mem0ai"`）。即使用戶沒有說出「遷移」這個詞，但明確希望他們現有的 mem0 整合在託管平台上運行，也會觸發此操作。它首先制定一個可審查的遷移計劃，然後在開發人員批准後執行。嚴格限制在 mem0 整合範圍內—它不會重構、重組或「改進」任何不相關的程式碼。
