规划并执行项目从 mem0 开源/自托管 SDK（本地“Memory”类）到 mem0 平台/托管/托管 SDK（“MemoryClient”类）的迁移。每当开发人员想要将其 mem0 使用量从 OSS/自托管移动、切换或迁移到托管 API 时，请使用此选项 - 例如“将我的 mem0 设置迁移到平台”、“从自托管 mem0 切换到 MemoryClient”、“使用我的 mem0 API 密钥而不是本地 Qdrant”、“将 mem0 移动到云/托管/托管服务”或“用平台替换我的本地 mem0 矢量存储 + 嵌入器配置”。适用于Python（`from mem0 import Memory`→`from mem0 import MemoryClient`）和TypeScript/JavaScript（`import { Memory } from "mem0ai/oss"`→`import MemoryClient from "mem0ai"`）。即使用户没有说出“迁移”这个词，但明确希望他们现有的 mem0 集成在托管平台上运行，也会触发此操作。它首先制定一个可审查的迁移计划，然后在开发人员批准后执行。严格限制在 mem0 集成范围内——它不会重构、重组或“改进”任何不相关的代码。
