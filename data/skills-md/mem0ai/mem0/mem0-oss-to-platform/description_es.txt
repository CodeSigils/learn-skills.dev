Planifique y luego ejecute una migración de un proyecto desde el SDK de código abierto/autohospedado mem0 (la clase `Memory` local) al SDK de plataforma/alojado/administrado mem0 (la clase `MemoryClient`). Úselo siempre que un desarrollador quiera mover, cambiar o migrar su uso de mem0 desde OSS/autohospedado a la API alojada, por ejemplo. "migrar mi configuración de mem0 a la plataforma", "cambiar de mem0 autohospedado a MemoryClient", "usar mi clave API de mem0 en lugar de un Qdrant local", "mover mem0 a la nube/servicio alojado/administrado" o "reemplazar mi tienda de vectores mem0 local + configuración de incrustación con la plataforma". Se aplica a Python (`desde mem0 importar memoria` → `desde mem0 importar MemoryClient`) y TypeScript/JavaScript (`importar {Memoria} desde "mem0ai/oss"` → `importar MemoryClient desde "mem0ai"`). Se activa incluso cuando el usuario no dice la palabra "migrar", pero claramente quiere que su integración mem0 existente se ejecute en la plataforma alojada. Primero produce un plan de migración revisable y luego lo ejecuta una vez que el desarrollador lo aprueba. Estrictamente enfocado a la integración de mem0: no refactoriza, reestructura ni "mejora" ningún código no relacionado.
