mem0 オープンソース / セルフホスト SDK (ローカル `Memory` クラス) から mem0 プラットフォーム / ホスト / マネージド SDK (`MemoryClient` クラス) へのプロジェクトの移行を計画し、実行します。開発者が mem0 の使用量を OSS/セルフホストからホストされた API に移動、切り替え、または移行したい場合は常にこれを使用します。 「mem0 セットアップをプラットフォームに移行する」、「セルフホスト型 mem0 から MemoryClient に切り替える」、「ローカル Qdrant の代わりに mem0 API キーを使用する」、「mem0 をクラウド/ホスト/マネージド サービスに移動する」、または「ローカル mem0 ベクター ストア + エンベッダー構成をプラットフォームに置き換える」。 Python (`from mem0 import Memory` → `from mem0 import MemoryClient`) および TypeScript/JavaScript (`import { Memory } from "mem0ai/oss"` → `import MemoryClient from "mem0ai"`) に適用されます。ユーザーが「移行」という言葉を言わなくても、ホストされているプラ​​ットフォームに対して既存の mem0 統合を実行することを明らかに望んでいる場合でもトリガーされます。まずレビュー可能な移行計画を作成し、開発者の承認後に実行します。 mem0 統合に厳密に限定されています。無関係なコードのリファクタリング、再構築、または「改善」は行われません。
