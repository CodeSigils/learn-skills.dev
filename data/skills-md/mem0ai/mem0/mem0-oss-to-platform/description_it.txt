Pianifica e quindi esegui la migrazione di un progetto dall'SDK open source/auto-ospitato mem0 (la classe "Memory" locale) all'SDK piattaforma/ospitato/gestito mem0 (la classe "MemoryClient"). Utilizzalo ogni volta che uno sviluppatore desidera spostare, cambiare o migrare il proprio utilizzo di mem0 da OSS/self-hosted all'API ospitata, ad es. "migra la mia configurazione mem0 sulla piattaforma", "passa da mem0 self-hosted a MemoryClient", "usa la mia chiave API mem0 invece di un Qdrant locale", "sposta mem0 nel servizio cloud/ospitato/gestito" o "sostituisci il mio archivio vettoriale mem0 locale + configurazione incorporata con la piattaforma". Si applica a Python (`from mem0 import Memory` → `from mem0 import MemoryClient`) e TypeScript/JavaScript (`import { Memory } from "mem0ai/oss"` → `import MemoryClient from "mem0ai"`). Si attiva anche quando l'utente non pronuncia la parola "migra" ma desidera chiaramente che l'integrazione mem0 esistente venga eseguita sulla piattaforma ospitata. Innanzitutto produce un piano di migrazione rivedibile, quindi lo esegue dopo l'approvazione dello sviluppatore. Rigorosamente limitato all'integrazione mem0: non effettua il refactoring, la ristrutturazione o il "miglioramento" di qualsiasi codice non correlato.
