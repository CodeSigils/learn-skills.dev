验证 /mem0-integrate 生成的 Mem0 集成。在同一分支的同一工作区中运行（松散耦合）——安装依赖项，运行存储库的本机测试套件，然后针对用户的 API 密钥执行真正的端到端烟雾流。生成记分卡。触发时间：用户刚刚运行 /mem0-integrate 并说“验证”、“测试集成”、“运行 /mem0-test-integration”，或者当 .mem0-integration/ 目录存在并且尚未在当前分支上运行测试时。不要在以下情况下触发：用户想要运行常规项目测试（遵循存储库的本机测试命令），或者当前分支中不存在先前的 /mem0-integrate 运行（要求他们首先运行 /mem0-integrate）。此技能仅通过设计捕获编译和运行时错误。逻辑集成错误——存储错误的数据、检索错误的时间、错误的用户范围——由人工审核者承担。
