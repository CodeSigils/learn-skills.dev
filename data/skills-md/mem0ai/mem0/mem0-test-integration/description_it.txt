Viene eseguito nello stesso spazio di lavoro sullo stesso ramo (accoppiamento lento): installa le dipendenze, esegue la suite di test nativa del repository, quindi esercita un vero flusso di fumo end-to-end contro la chiave API dell'utente. Produce una scorecard. SI ATTIVA quando: l'utente ha appena eseguito /mem0-integrate e dice "verifica", "testa l'integrazione", "esegui /mem0-test-integration" o quando esiste una directory .mem0-integration/ e i test non sono stati ancora eseguiti sul ramo corrente. NON ATTIVARE quando: l'utente desidera eseguire test generali del progetto (rimandare al comando di test nativo del repository) o quando non esiste alcuna esecuzione precedente di /mem0-integrate nel ramo corrente (chiedere loro di eseguire prima /mem0-integrate). Questa abilità rileva SOLO bug di compilazione e di runtime in base alla progettazione. Gli errori di integrazione logica (dati errati archiviati, ora errata di recupero, ambito utente errato) sono a carico del revisore umano.
