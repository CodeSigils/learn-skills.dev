/mem0-integrate によって生成された Mem0 統合を確認します。同じブランチ上の同じワークスペースで実行 (疎結合) — 依存関係をインストールし、リポジトリのネイティブ テスト スイートを実行して、ユーザーの API キーに対して実際のエンドツーエンドのスモーク フローを実行します。スコアカードを作成します。トリガーされるタイミング: ユーザーが /mem0-integrate を実行した直後で、「検証する」、「統合をテストする」、「/mem0-test-integration を実行する」と言ったとき、または .mem0-integration/ ディレクトリが存在し、現在のブランチでテストがまだ実行されていないとき。次の場合はトリガーしないでください: ユーザーが一般的なプロジェクト テストを実行したい場合 (リポジトリのネイティブ テスト コマンドに従う)、または現在のブランチに以前の /mem0-integrate 実行が存在しない場合 (最初に /mem0-integrate を実行するように依頼する)。このスキルは、設計上、コンパイル時および実行時のバグのみを検出します。論理統合エラー (保存されたデータが間違っている、取得された時刻が間違っている、ユーザーのスコープが間違っているなど) は、人間のレビュー担当者が担当します。
