驗證 /mem0-integrate 產生的 Mem0 整合。在同一分支的同一工作區中運行（鬆散耦合）－安裝依賴項，運行儲存庫的本機測試套件，然後針對使用者的 API 金鑰執行真正的端對端煙霧流。產生記分卡。觸發時間：用戶剛剛運行 /mem0-integrate 並說“驗證”、“測試集成”、“運行 /mem0-test-integration”，或者當 .mem0-integration/ 目錄存在並且尚未在當前分支上運行測試時。不要在以下情況下觸發：使用者想要執行常規專案測試（遵循儲存庫的本機測試命令），或目前分支中不存在先前的 /mem0-integrate 運行（要求他們先執行 /mem0-integrate）。此技能僅透過設計捕獲編譯和運行時錯誤。邏輯整合錯誤——儲存錯誤的資料、檢索錯誤的時間、錯誤的使用者範圍——由人工審核者承擔。
