Проверьте интеграцию Mem0, созданную с помощью /mem0-integrate. Запускается в той же рабочей области, в той же ветке (слабая связь) — устанавливает зависимости, запускает собственный набор тестов репозитория, а затем выполняет настоящий сквозной поток дыма против ключа API пользователя. Создает оценочную карту. ТРИГГЕР, когда: пользователь только что запустил /mem0-integrate и сказал «проверить», «проверить интеграцию», «запустить /mem0-test-integration» или когда существует каталог .mem0-integration/ и тесты еще не запускались в текущей ветке. НЕ ЗАПУСКАЙТЕ, когда: пользователь хочет запустить общие тесты проекта (подчиниться встроенной тестовой команде репозитория) или когда в текущей ветке не существует предыдущего запуска /mem0-integrate (попросите его сначала запустить /mem0-integrate). Этот навык ТОЛЬКО предназначен для обнаружения ошибок компиляции и выполнения. Логические ошибки интеграции — неправильные сохраненные данные, неправильное время получения, неправильный выбор пользователей — ложатся на человека-рецензента.
