Verifique una integración de Mem0 producida por /mem0-integrate. Se ejecuta en el mismo espacio de trabajo en la misma rama (acoplamiento flexible): instala dependencias, ejecuta el conjunto de pruebas nativo del repositorio y luego ejerce un flujo de humo real de extremo a extremo contra la clave API del usuario. Produce un cuadro de mando. DISPARAR cuando: el usuario acaba de ejecutar /mem0-integrate y dice "verificar", "probar la integración", "ejecutar /mem0-test-integration", o cuando existe un directorio .mem0-integration/ y las pruebas aún no se han ejecutado en la rama actual. NO DISPARAR cuando: el usuario quiera ejecutar pruebas generales del proyecto (diferir al comando de prueba nativo del repositorio), o cuando no exista una ejecución previa de /mem0-integrate en la rama actual (pídale que ejecute /mem0-integrate primero). Esta habilidad SÓLO detecta errores de compilación y tiempo de ejecución por diseño. Los errores de integración lógica (datos incorrectos almacenados, hora incorrecta de recuperación, alcance de usuario incorrecto) son responsabilidad del revisor humano.
