Utilice esta habilidad siempre que el usuario pregunte sobre documentos tributarios, datos contables, movimientos bancarios, conciliaciones, IVA, F29, facturas, compras, ventas, honorarios, obligaciones, asientos contables o cualquier dato financiero/contable para su negocio chileno. Úselo también cuando el usuario solicite clasificar un movimiento bancario, conciliar un movimiento con un documento, crear un asiento de diario o realizar cualquier acción contable. Esta habilidad controla la CLI `fizko` (paquete npm) para consultar y actuar sobre los datos de la API de Fizko. Úselo incluso si el usuario no menciona "fizko" explícitamente: si pregunta sobre los datos financieros de su empresa o quiere hacer algo con un movimiento bancario o un documento fiscal, esta habilidad se aplica.
