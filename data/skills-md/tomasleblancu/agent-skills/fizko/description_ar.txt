استخدم هذه المهارة عندما يسأل المستخدم عن المستندات الضريبية، أو البيانات المحاسبية، أو الحركات المصرفية، أو التسوية، أو IVA، أو F29، أو Facturas، أو compras، أو ventas، أو الأتعاب، أو الالتزامات، أو asientos contables، أو أي بيانات مالية/محاسبية لأعمالهم التجارية في تشيلي. استخدمه أيضًا عندما يطلب المستخدم تصنيف حركة بنكية، أو تسوية حركة مع مستند، أو إنشاء قيد دفتر يومية، أو تنفيذ أي إجراء محاسبي. تتحكم هذه المهارة في `fizko` CLI (حزمة npm) للاستعلام عن البيانات من Fizko API والتصرف بناءً عليها. استخدمها حتى إذا لم يذكر المستخدم "fizko" صراحةً - إذا كانوا يسألون عن البيانات المالية لشركتهم أو يريدون القيام بشيء ما بحركة بنكية أو مستند ضريبي، فسيتم تطبيق هذه المهارة.
