ユーザーが税務書類、会計データ、銀行動向、調整、IVA、F29、ファクトラス、コンプラス、ベンタス、謝金、債務、アシェントス コンタブル、またはチリのビジネスの財務/会計データについて質問するときは常に、このスキルを使用します。また、ユーザーが銀行の移動の分類、移動と文書の調整、仕訳入力の作成、または会計処理の実行を要求する場合にも使用します。このスキルは、「fizko」CLI (npm パッケージ) を制御して、Fizko API からのデータをクエリおよび操作します。ユーザーが「fizko」と明示的に言及していない場合でも、このスキルを使用してください。ユーザーが empresa の財務データについて質問している場合、または銀行口座の移動や税務書類について何かをしたい場合、このスキルは適用されます。
