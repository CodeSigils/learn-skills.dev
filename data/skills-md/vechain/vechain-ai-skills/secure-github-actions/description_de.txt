Sichern Sie GitHub Actions-Workflows vor Lieferketten-, Privilegien- und Shell-Injection-Risiken. Zum Erstellen, Gerüstbauen, Bearbeiten oder Überprüfen von „.github/workflows/*.yml“, wiederverwendbaren Workflows, „action.yml“ oder der Dependabot-Konfiguration für GitHub-Aktionen. Wird auch für vollständige Repository-Sicherheitsüberprüfungen („Meine Arbeitsabläufe prüfen“, „Dieses Repository härten“, „Sicherheitsscan“, „Aktionen an SHA anheften“), zum Scannen von Geheimnissen mit Gitleaks und Trufflehog sowie für Sicherheitsüberprüfungen vor der Veröffentlichung verwendet. Erzwingen Sie das vollständige 40-Zeichen-Commit-SHA-Pinning, vermeiden Sie „pull_request_target“ bei nicht vertrauenswürdigem Code, übergeben Sie GitHub-Kontext über „env:“ an „run:“-Schritte und legen Sie Berechtigungen mit den geringsten Privilegien fest.
