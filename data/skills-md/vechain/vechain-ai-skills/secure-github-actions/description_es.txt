Proteja los flujos de trabajo de GitHub Actions contra los riesgos de la cadena de suministro, los privilegios y la inyección de shell. Úselo al crear, realizar scaffolding, editar o revisar `.github/workflows/*.yml`, flujos de trabajo reutilizables, `action.yml` o configuración de Dependabot para GitHub Actions. Úselo también para auditorías de seguridad completas del repositorio ("auditar mis flujos de trabajo", "reforzar este repositorio", "análisis de seguridad", "fijar acciones a SHA"), escaneo de secretos con gitleaks y trufflehog, y revisiones de seguridad previas al lanzamiento público. Aplique la fijación SHA de confirmación completa de 40 caracteres, evite `pull_request_target` en código que no sea de confianza, pase el contexto de GitHub a los pasos `run:` a través de `env:` y establezca permisos con privilegios mínimos.
