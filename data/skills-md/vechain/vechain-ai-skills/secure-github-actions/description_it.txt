Proteggi i flussi di lavoro di GitHub Actions dai rischi legati alla catena di fornitura, ai privilegi e all'iniezione di shell. Da utilizzare durante la creazione, lo scaffolding, la modifica o la revisione di `.github/workflows/*.yml`, flussi di lavoro riutilizzabili, `action.yml` o configurazione di Dependabot per azioni GitHub. Utilizzare anche per controlli di sicurezza completi del repository ("controlla i miei flussi di lavoro", "rafforzare questo repository", "scansione di sicurezza", "aggiungi azioni a SHA"), scansione di segreti con gitleaks e tartufohog e revisioni di sicurezza prima del rilascio pubblico. Applica il pinning SHA di commit completo di 40 caratteri, evita `pull_request_target` su codice non attendibile, passa il contesto GitHub nei passaggi "run:" tramite "env:" e imposta le autorizzazioni con privilegi minimi.
