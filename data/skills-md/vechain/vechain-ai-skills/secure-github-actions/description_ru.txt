Защитите рабочие процессы GitHub Actions от рисков, связанных с цепочкой поставок, привилегиями и внедрением оболочки. Используйте при создании, формировании, редактировании или просмотре `.github/workflows/*.yml`, повторно используемых рабочих процессов, `action.yml` или конфигурации Dependabot для GitHub Actions. Также используйте для полного аудита безопасности репозитория («проверить мои рабочие процессы», «укрепить это репо», «сканирование безопасности», «закрепить действия в SHA»), сканирования секретов с помощью gitleaks и trufflehog, а также проверок безопасности перед публикацией. Обеспечьте полную фиксацию SHA из 40 символов фиксации, избегайте `pull_request_target` для ненадежного кода, передавайте контекст GitHub в шаги `run:` через `env:` и устанавливайте разрешения с наименьшими привилегиями.
