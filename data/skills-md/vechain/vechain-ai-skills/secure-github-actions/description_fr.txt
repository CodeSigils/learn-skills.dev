Sécurisez les workflows GitHub Actions contre les risques liés à la chaîne d’approvisionnement, aux privilèges et à l’injection de shell. À utiliser lors de la création, de l'échafaudage, de la modification ou de la révision de `.github/workflows/*.yml`, de workflows réutilisables, `action.yml` ou de la configuration Dependabot pour les actions GitHub. À utiliser également pour les audits de sécurité complets du référentiel (« auditer mes flux de travail », « renforcer ce dépôt », « analyse de sécurité », « épingler les actions sur SHA »), l'analyse des secrets avec gitleaks et trufflehog et les examens de sécurité avant la publication publique. Appliquez l'épinglage SHA de validation complet de 40 caractères, évitez « pull_request_target » sur du code non fiable, transmettez le contexte GitHub dans les étapes « run : » via « env : » et définissez les autorisations de moindre privilège.
