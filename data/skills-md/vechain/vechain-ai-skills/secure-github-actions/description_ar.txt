تأمين سير عمل GitHub Actions ضد مخاطر سلسلة التوريد والامتيازات وحقن الصدفة. يُستخدم عند الإنشاء أو السقالات أو التحرير أو المراجعة `.github/workflows/*.yml` أو مسارات العمل القابلة لإعادة الاستخدام أو `action.yml` أو تكوين Dependabot لإجراءات GitHub. استخدم أيضًا لعمليات تدقيق أمان المستودع الكاملة ("تدقيق سير العمل الخاص بي"، و"تقوية هذا الريبو"، و"الفحص الأمني"، و"تثبيت الإجراءات على SHA")، وفحص الأسرار باستخدام gitleaks وtrufflehog، ومراجعات الأمان قبل الإصدار العام. فرض التزام كامل مكون من 40 حرفًا SHA، وتجنب `pull_request_target` على تعليمات برمجية غير موثوقة، وتمرير سياق GitHub إلى خطوات `run:` عبر `env:`، وتعيين أذونات الأقل امتيازًا.
