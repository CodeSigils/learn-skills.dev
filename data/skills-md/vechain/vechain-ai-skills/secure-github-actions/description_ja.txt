サプライチェーン、権限、シェルインジェクションのリスクに対して GitHub Actions ワークフローを保護します。 `.github/workflows/*.yml`、再利用可能なワークフロー、`action.yml`、または GitHub Actions の dependabot 構成を作成、スキャフォールディング、編集、またはレビューするときに使用します。また、リポジトリの完全なセキュリティ監査 (「ワークフローの監査」、「このリポジトリの強化」、「セキュリティ スキャン」、「アクションを SHA に固定する」)、gitleaks と trufflehog を使用したシークレット スキャン、および公開リリース前のセキュリティ レビューにも使用します。完全な 40 文字コミット SHA ピンニングを強制し、信頼できないコードでの `pull_request_target` を回避し、`env:` 経由で GitHub コンテキストを `run:` ステップに渡し、最小権限のアクセス許可を設定します。
