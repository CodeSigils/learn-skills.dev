[Бета-версия] Рабочий процесс агрегирования обучения только для CI с использованием gh-aw (GitHub Agentic Workflows). Сканирует файлы .learning/ по расписанию, группирует записи по ключу_шаблона, определяет готовые к продвижению шаблоны и публикует отчет о пробелах в качестве PR или комментария к проблеме. Используйте, когда: вам нужно автоматическое обнаружение шаблонов между сеансами в CI/безголовых конвейерах без интерактивных подсказок. Для интерактивного использования используйте обучающий агрегатор.
