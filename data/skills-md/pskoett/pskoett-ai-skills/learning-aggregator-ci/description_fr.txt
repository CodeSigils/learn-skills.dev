[Bêta] Workflow d'agrégation d'apprentissage CI uniquement utilisant gh-aw (GitHub Agentic Workflows). Analyse les fichiers .learnings/ selon un calendrier, regroupe les entrées par pattern_key, identifie les modèles prêts pour la promotion et publie un rapport d'écart en tant que PR ou commentaire de problème. À utiliser lorsque : vous souhaitez une détection automatisée des modèles entre sessions dans les pipelines CI/sans tête sans invites interactives. Pour une utilisation interactive, utilisez Learning-Aggregator.
