[Бета] Средство оценки регрессии только для CI с использованием gh-aw (GitHub Agentic Workflows). Запускает все случаи оценки в .evals/ по расписанию или для каждого PR, сообщает о результатах прохождения/неудачи и может блокировать слияния при регрессиях. Также создает новые случаи оценки на основе продвигаемых шаблонов, отмеченных Learning-aggregator-ci. Используйте, когда: вам нужно автоматическое регрессионное тестирование расширенных правил в CI/безголовых конвейерах. Для интерактивного создания и запуска Eval используйте eval-creator.
