編碼代理的主動運行時恢復：當某些東西在任務中中斷時，診斷根本原因，編寫修復程序，通過重新運行損壞的東西進行驗證，然後將“HEAL-”條目與證據一起歸檔到“.learnings/HEALS.md”。每當命令、測試、建置或 lint 失敗或以非零值退出時使用；缺少工具、依賴項/鎖定檔案不匹配、錯誤的運行時版本、venv 或權限錯誤、連接埠衝突、骯髒的 git 狀態或缺少 `.env`；當代理需要尚不存在的幫助程序或一次性腳本時；當外部 API、工具或 MCP 出現時限時出現錯誤；首先透過「Pattern-Key」搜尋「HEALS.md」——大多數治療都是重複的，因此增加「Recurrence-Count」而不是重複。驗證是強制性的：如果在沙箱中，請誠實地標記“待驗證”，如果修復無法發揮作用，則標記為“放棄”。與「自我完善」（促進持久記憶的反覆治癒）配對，但擁有「先驗證後堅持」的紀律，但自我完善卻沒有。
