Erfassen Sie einen Feishu/Lark-Dokument-Link oder einen regulären Webseiten-Link und speichern Sie ihn in einem lokalen Verzeichnis (Feishu-Dokumente unterstützen Markdown/PDF/HTML+Bildanhänge; normale Webseiten unterstützen nur Markdown, wobei Bilder als externe Links beibehalten werden). arXiv-Dokumente (entweder ein Link oder eine bloße ID funktionieren) verwenden ein eigenständiges Skript, um das PDF, den HTML-Code und den konvertierten Markdown zusammen herunterzuladen, ohne auf eine Browsererweiterung angewiesen zu sein. Wenn ein Benutzer ein Feishu-Dokument oder eine beliebige Web-URL in einem Projekt veröffentlicht und es herunterladen/speichern/exportieren/ziehen/auf einen lokalen Pfad erfassen möchte, muss diese Funktion verwendet werden, auch wenn der Benutzer nicht ausdrücklich „larksnap verwenden“ oder „Erweiterung verwenden“ angibt. Unter der Haube stellt ein lokaler Daemon eine Brücke zu einer angemeldeten Larksnap-Browsererweiterung, die den Authentifizierungsstatus und die Export-Engine speichert; Wenn eine nicht angemeldete oder nicht autorisierte Domäne gefunden wird, wird der Benutzer über einen Exit-Code aufgefordert, sich anzumelden oder im Browser zu autorisieren. Diese Funktion ist eigenständig (der Daemon wird mit dem Skill ausgeliefert), kann von jedem Projekt aus aufgerufen werden und ist nicht vom Larksnap-Repository abhängig.
