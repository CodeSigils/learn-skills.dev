Tome el enlace de un documento de Feishu/Lark o el enlace de una página web normal y guárdelo en un directorio local (los documentos de Feishu admiten Markdown/PDF/HTML más archivos adjuntos de imágenes; las páginas web normales solo admiten Markdown, y las imágenes se mantienen como enlaces externos). Para los artículos arXiv (ya sea por enlace o ID simple), utilice un script separado para descargar el PDF, el HTML y el Markdown convertido juntos, sin depender de una extensión del navegador. Cuando un usuario publica un documento Feishu o cualquier URL web en cualquier proyecto y quiere descargarlo/guardarlo/exportarlo/extraerlo/capturarlo en una ruta local, se debe utilizar esta capacidad, incluso si el usuario no dice explícitamente "usar larksnap" o "usar la extensión". Debajo del capó, un demonio local conecta con una extensión del navegador Larksnap en la que se ha iniciado sesión, que contiene el estado de autenticación y el motor de exportación; Si se encuentra un dominio no registrado o no autorizado, le solicitará al usuario mediante un código de salida que inicie sesión o autorice en el navegador. Esta capacidad es autónoma (el demonio se distribuye con la habilidad), se puede invocar desde cualquier proyecto y no depende del repositorio de Larksnap.
