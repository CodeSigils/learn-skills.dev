Capturez un lien de document Feishu/Lark ou un lien de page Web standard et enregistrez-le dans un répertoire local (les documents Feishu prennent en charge les pièces jointes Markdown/PDF/HTML+image ; les pages Web standard ne prennent en charge que Markdown, avec des images conservées sous forme de liens externes). Les articles arXiv (soit un lien, soit un simple identifiant) utilisent un script autonome pour télécharger ensemble le PDF, le HTML et le Markdown converti, sans recourir à une extension de navigateur. Lorsqu'un utilisateur publie un document Feishu ou n'importe quelle URL Web dans n'importe quel projet et souhaite le télécharger/enregistrer/exporter/extraire/capturer vers un chemin local, cette fonctionnalité doit être utilisée, même si l'utilisateur ne dit pas explicitement « utiliser Larksnap » ou « utiliser l'extension ». Sous le capot, un démon local relie une extension de navigateur Larksnap connectée, qui contient l'état d'authentification et le moteur d'exportation ; si un domaine non enregistré ou non autorisé est rencontré, il invitera l'utilisateur via un code de sortie à se connecter ou à autoriser dans le navigateur. Cette fonctionnalité est autonome (le démon est livré avec la compétence), peut être invoquée à partir de n'importe quel projet et ne dépend pas du référentiel larksnap.
