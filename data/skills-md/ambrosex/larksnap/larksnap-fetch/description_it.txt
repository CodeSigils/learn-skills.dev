Cattura il collegamento di un documento Feishu/Lark o il collegamento di una normale pagina Web e salvalo in una directory locale (i documenti Feishu supportano Markdown/PDF/HTML + allegati immagine; le normali pagine Web supportano solo Markdown, con le immagini conservate come collegamenti esterni). I documenti arXiv (link o ID nudo funzionano entrambi) utilizzano uno script autonomo per scaricare insieme PDF, HTML e Markdown convertito, senza fare affidamento su un'estensione del browser. Quando un utente pubblica un documento Feishu o qualsiasi URL web in qualsiasi progetto e desidera scaricarlo/salvarlo/esportarlo/esportarlo/acquisirlo in un percorso locale, è necessario utilizzare questa abilità, anche se l'utente non dice esplicitamente "usa larksnap" o "usa l'estensione". Sotto il cofano, un demone locale si collega a un'estensione del browser larksnap dopo aver effettuato l'accesso, che detiene lo stato di autenticazione e il motore di esportazione; se si incontra un dominio non registrato o non autorizzato, richiederà all'utente tramite un codice di uscita di accedere o autorizzarsi nel browser. Questa competenza è autonoma (il daemon è distribuito con la competenza), richiamabile da qualsiasi progetto e non dipende dal repository larksnap.
