Feishu/Lark ドキュメントのリンクまたは通常の Web ページのリンクをキャプチャし、ローカル ディレクトリに保存します (Feishu ドキュメントは Markdown/PDF/HTML+画像添付ファイルをサポートします。通常の Web ページは Markdown のみをサポートし、画像は外部リンクとして保持されます)。 arXiv 論文 (リンクまたは裸の ID のどちらでも機能します) は、スタンドアロン スクリプトを使用して、ブラウザー拡張機能に依存せずに、PDF、HTML、および変換された Markdown をまとめてダウンロードします。ユーザーが Feishu ドキュメントまたは任意のプロジェクトの Web URL を投稿し、それをローカル パスにダウンロード/保存/エクスポート/プル/キャプチャしたい場合、ユーザーが明示的に「larksnap を使用する」または「拡張機能を使用する」と指定していなくても、この機能を使用する必要があります。内部では、ローカル デーモンがログイン中の Larksnap ブラウザ拡張機能にブリッジし、認証状態とエクスポート エンジンを保持します。ログインされていないドメインまたは無許可のドメインが見つかった場合、終了コードを介してユーザーにログインまたはブラウザでの認証を求めるプロンプトが表示されます。この機能は自己完結型であり (デーモンはスキルに同梱されています)、どのプロジェクトからでも呼び出すことができ、larksnap リポジトリには依存しません。
