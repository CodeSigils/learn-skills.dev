Capture a Feishu/Lark document link or a regular web page link and save it to a local directory (Feishu documents support Markdown/PDF/HTML + image attachments; regular web pages only support Markdown, with images kept as external links). arXiv papers (either a link or a bare ID works) use a standalone script to download the PDF, HTML, and the converted Markdown together, without relying on a browser extension. When a user posts a Feishu document or any web URL in any project and wants to download/save/export/pull/capture it to a local path, this capability must be used, even if the user doesn’t explicitly say “use larksnap” or “use extension”. Under the hood, a local daemon bridges to a logged‑in larksnap browser extension, which holds the authentication state and export engine; if an unlogged or unauthorized domain is encountered, it will prompt the user via an exit code to log in or authorize in the browser. This capability is self‑contained (the daemon is shipped with the skill), can be invoked from any project, and does not depend on the larksnap repository.
