Verwenden Sie diese Option, wenn der Benutzer das Schreiben umschreiben, straffen, vereinfachen oder entgiften möchte – Formulierungen wie „einfaches Englisch“, „machen Sie dies klarer“, „schneiden Sie die KI-Stimme ab“, „korrigieren Sie die Schrift“, „umschreiben Sie klar“, „verschärfen Sie dies“, „entgiften Sie dies“. Führen Sie es auch als Selbstprüfungsdurchgang aus, bevor Sie lange Texte (Aufsätze, Blogbeiträge, Artikel, Berichte, Dokumentationen) liefern, damit die Ausgabe nicht erkennbar von der KI generiert wird.
