Persistenter, wiederherstellbarer GSAP-Workflow für Codierungsagenten. Verwenden Sie diese Option, wenn der Benutzer eine neue Seite oder einen neuen Abschnitt animieren oder eine vorhandene Seite/Komponente mit GSAP verbessern möchte. Leiten Sie neue/Greenfield-Arbeiten an gsap-new und bestehende Code-Verbesserungsarbeiten an gsap-refactor weiter. Verwenden Sie immer .gsap-Artefakte als Quelle der Wahrheit, damit jede neue Agentensitzung ohne Chatverlauf fortgesetzt werden kann.
