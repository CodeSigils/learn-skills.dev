Flux de travail GSAP persistant et récupérable pour les agents de codage. À utiliser lorsque l'utilisateur souhaite animer une nouvelle page ou section, ou améliorer une page/un composant existant avec GSAP. Acheminez les travaux nouveaux/nouveaux vers gsap-new et les travaux d'amélioration du code existant vers gsap-refactor. Utilisez toujours les artefacts .gsap comme source de vérité afin que toute nouvelle session d'agent puisse reprendre sans historique de discussion.
