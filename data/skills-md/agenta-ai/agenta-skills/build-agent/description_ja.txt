Agenta API を通じて、平易な言語のリクエストを、動作するテスト済みの Agenta エージェントに変換します。ユーザーがコーディング エージェント (クロード コード、コーデックス、カーソル) から Agenta エージェントを構築、作成、スケジュール、またはテストする場合に使用します。 1 つの構成を書き込み、バンドルされたいくつかのシェル スクリプトを実行します。 「Agenta エージェントの構築」、「Agenta でのエージェントの作成」、「Agenta エージェントのスケジュール」、または Agenta 経由でエージェントを GitHub や Slack などのツールに接続するとトリガーされます。
