قم بتحويل طلب باللغة البسيطة إلى وكيل Agenta عامل ومختبر من خلال Agenta API. يُستخدم عندما يريد المستخدم إنشاء وكيل Agenta أو إنشائه أو جدولته أو اختباره من وكيل الترميز الخاص به (Claude Code، Codex، Cursor). يكتب تكوينًا واحدًا ويقوم بتشغيل عدد قليل من نصوص shell المجمعة. يتم تشغيلها عند "إنشاء وكيل Agenta"، أو "إنشاء وكيل على Agenta"، أو "جدولة وكيل Agenta"، أو توصيل الوكيل بأداة مثل GitHub أو Slack عبر Agenta.
