Превратите запрос, написанный простым языком, в работающий и протестированный агент Agenta с помощью API Agenta. Используйте, когда пользователь хочет создать, запланировать или протестировать агент Agenta из своего агента кодирования (Claude Code, Codex, Cursor). Записывает одну конфигурацию и запускает несколько встроенных сценариев оболочки. Запускается при «создании агента Agenta», «создании агента на Agenta», «запланировании агента Agenta» или подключении агента к такому инструменту, как GitHub или Slack, через Agenta.
