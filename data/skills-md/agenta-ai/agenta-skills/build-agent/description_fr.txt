Transformez une requête en langage naturel en un agent Agenta fonctionnel et testé via l’API Agenta. À utiliser lorsque l’utilisateur souhaite créer, construire, planifier ou tester un agent Agenta depuis son agent de codage (Claude Code, Codex, Cursor). Écrit une configuration et exécute quelques scripts shell fournis. Se déclenche sur « construire un agent Agenta », « créer un agent sur Agenta », « planifier un agent Agenta », ou lorsqu’on connecte un agent à un outil comme GitHub ou Slack via Agenta.

Veuillez toujours répondre dans la langue de l’utilisateur.
