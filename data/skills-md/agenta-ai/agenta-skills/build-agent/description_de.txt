Verwandeln Sie eine Klartext-Anfrage über die Agenta-API in einen funktionierenden, getesteten Agenta-Agenten. Verwenden Sie diese Option, wenn der Benutzer einen Agenta-Agenten über seinen Coding-Agenten (Claude Code, Codex, Cursor) erstellen, planen oder testen möchte. Schreibt eine Konfiguration und führt einige gebündelte Shell-Skripte aus. Wird ausgelöst bei „Agenta-Agenten erstellen“, „Agenten auf Agenta erstellen“, „Agenta-Agenten planen“ oder bei der Verbindung eines Agenten mit einem Tool wie GitHub oder Slack über Agenta.
