Assistant de configuration guidé pour l'auto-hébergement d'Agenta open source et l'exécution d'un agent dessus. À utiliser lorsque l'utilisateur souhaite auto-héberger Agenta, configurer un agent Agenta sur sa propre machine ou son propre serveur, exécuter un agent localement ou dit « aidez-moi à auto-héberger Agenta », « configurer un agent », « s'auto-héberger et exécuter un agent ». Guide l'utilisateur à travers les décisions, les exécute sur les documents auto-hébergés OSS et termine avec un agent fonctionnel et testé.
