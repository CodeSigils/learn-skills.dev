Implementiert eine zustandslose autonome Agentenschleife, in der Sie wie ein CPU-Zyklus arbeiten: Aufwachen ohne Speicher, Überprüfen eines Task-Managers, Lesen von Speicherprotokollen, Ausführen von Programmen und Markieren aller Ausgaben, damit zukünftige Zyklen nahtlos fortgesetzt werden können. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer möchte, dass Sie sitzungsübergreifend autonom arbeiten, den Status zwischen den Läufen beibehalten, Aufgaben zyklusübergreifend verwalten, mit anderen Agenten zusammenarbeiten oder ein rund um die Uhr verfügbares KI-Agentensystem simulieren möchten. Auslösen bei Phrasen wie „Als Agent ausführen“, „Autonome Schleife“, „Kernel“, „Task-Manager-Zyklus“, „Persistenter Agent“ oder „Von der letzten Ausführung fortfahren“.
