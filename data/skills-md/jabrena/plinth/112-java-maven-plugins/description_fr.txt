À utiliser lorsque vous devez ajouter ou configurer des plugins Maven dans votre pom.xml — y compris des outils de qualité (enforcer, surefire, failsafe, jacoco, pitest, spotbugs, pmd), analyse de sécurité (OWASP), formatage de code (Spotless), gestion des versions, création d'images de conteneur (Jib), suivi des informations de construction et analyse comparative (JMH) — via une approche consultative et modulaire étape par étape qui n'ajoute que ce dont vous avez réellement besoin. Cela devrait déclencher des requêtes telles que Ajouter des plugins Maven dans pom.xml ; Améliorer les plugins Maven dans pom.xml ; Configurez les plugins de qualité Maven dans pom.xml ; Ajoutez des plugins de cycle de vie de build Maven pour la vérification Java ; Passez en revue les versions et les exécutions du plugin Maven.
