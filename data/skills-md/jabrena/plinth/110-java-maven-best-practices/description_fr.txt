À utiliser lorsque vous avez besoin de réviser, d'améliorer ou de dépanner un fichier pom.xml Maven, y compris la gestion des dépendances avec les nomenclatures, la configuration des plugins, la centralisation des versions, la structure de projet multi-modules, les profils de construction ou toute situation dans laquelle vous souhaitez aligner votre configuration Maven sur les meilleures pratiques du secteur. Cela devrait déclencher des requêtes telles que Review pom.xml pour l'améliorer ; Appliquer les meilleures pratiques Maven à pom.xml ; Améliorer la configuration Maven POM ; Examiner la gestion des dépendances Maven et la configuration du plugin ; Modernisez les conventions de build Maven pour un projet Java.
