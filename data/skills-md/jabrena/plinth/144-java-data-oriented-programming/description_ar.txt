استخدمه عندما تحتاج إلى تطبيق أفضل ممارسات البرمجة الموجهة للبيانات في Java - بما في ذلك فصل التعليمات البرمجية (السلوك) عن هياكل البيانات باستخدام السجلات، وتصميم البيانات غير القابلة للتغيير باستخدام وظائف التحويل النقية، والحفاظ على البيانات مسطحة وغير طبيعية باستخدام المراجع المستندة إلى المعرف، بدءًا من بنيات البيانات العامة التي تتحول إلى أنواع محددة عند الحاجة، وضمان تكامل البيانات من خلال وظائف التحقق من الصحة النقية، وإنشاء طبقات عامة مرنة للوصول إلى البيانات. يجب أن يؤدي هذا إلى طلبات مثل تحسين التعليمات البرمجية باستخدام البرمجة الموجهة للبيانات؛ تطبيق البرمجة الموجهة نحو البيانات؛ إعادة بناء الكود باستخدام البرمجة الموجهة للبيانات؛ نموذج بيانات Java باستخدام السجلات والوظائف النقية؛ فصل سلوك Java عن هياكل البيانات غير القابلة للتغيير؛ التحقق من صحة تكامل البيانات باستخدام وظائف Java الخالصة. جزء من مجموعة أدوات القاعدة
