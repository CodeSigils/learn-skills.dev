À utiliser lorsque vous devez appliquer les meilleures pratiques de programmation orientées données en Java, notamment séparer le code (comportement) des structures de données à l'aide d'enregistrements, concevoir des données immuables avec des fonctions de transformation pures, conserver les données plates et dénormalisées avec des références basées sur l'ID, commencer par des structures de données génériques se convertissant en types spécifiques si nécessaire, garantir l'intégrité des données grâce à des fonctions de validation pures et créer des couches d'accès aux données génériques flexibles. Cela devrait déclencher des demandes telles que Améliorer le code avec la programmation orientée données ; Appliquer la programmation orientée données ; Refactoriser le code avec la programmation orientée données ; Modélisez les données Java avec des enregistrements et des fonctions pures ; Séparez le comportement Java des structures de données immuables ; Validez l’intégrité des données avec des fonctions Java pures.
