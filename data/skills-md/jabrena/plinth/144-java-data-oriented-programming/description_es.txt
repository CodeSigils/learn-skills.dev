Úselo cuando necesite aplicar las mejores prácticas de programación orientada a datos en Java, incluida la separación del código (comportamiento) de las estructuras de datos mediante registros, el diseño de datos inmutables con funciones de transformación pura, el mantenimiento de datos planos y desnormalizados con referencias basadas en ID, comenzando con estructuras de datos genéricas que se convierten a tipos específicos cuando sea necesario, garantizando la integridad de los datos a través de funciones de validación pura y creando capas flexibles de acceso a datos genéricos. Esto debería desencadenar solicitudes como Mejorar el código con programación orientada a datos; Aplicar Programación Orientada a Datos; Refactorizar el código con Programación Orientada a Datos; Modelar datos Java con registros y funciones puras; Separe el comportamiento de Java de las estructuras de datos inmutables; Valide la integridad de los datos con funciones Java puras.
