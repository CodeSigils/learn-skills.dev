À utiliser lorsque vous avez besoin de réviser, d'améliorer ou d'écrire des tests unitaires Java, notamment en migrant de JUnit 4 vers JUnit 5, en adoptant AssertJ pour des assertions fluides, en structurant les tests avec Given-When-Then, en garantissant l'indépendance des tests, en appliquant des tests paramétrés, en simulant les dépendances avec Mockito, en vérifiant les conditions aux limites (RIGHT-BICEP, CORRECT, A-TRIP), en exploitant les annotations de sécurité nulle JSpecify ou en éliminant les anti-modèles de test tels que tests basés sur la réflexion ou état mutable partagé. Cela devrait se déclencher pour des requêtes telles que Réviser le code Java pour les tests unitaires ; Appliquer les meilleures pratiques pour les tests unitaires en code Java ; Écrivez des tests unitaires JUnit rapides pour le code Java ; Améliorer les tests unitaires Java basés sur Mockito ; Refactorisez les tests Java pour isoler les collaborateurs.
