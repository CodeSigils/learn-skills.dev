Da utilizzare quando è necessario rivedere, migliorare o scrivere test unitari Java, tra cui la migrazione da JUnit 4 a JUnit 5, l'adozione di AssertJ per asserzioni fluide, la strutturazione dei test con Given-When-Then, la garanzia dell'indipendenza dei test, l'applicazione di test parametrizzati, la simulazione delle dipendenze con Mockito, la verifica delle condizioni al contorno (RIGHT-BICEP, CORRECT, A-TRIP), l'utilizzo delle annotazioni di sicurezza null JSpecify o l'eliminazione di anti-pattern di test come come test basati sulla riflessione o stato mutabile condiviso. Ciò dovrebbe attivarsi per richieste come Review Java code for unit test; Applicare le migliori pratiche per i test unitari nel codice Java; Scrivi test unitari JUnit veloci per il codice Java; Migliorare gli unit test Java basati su Mockito; Refactoring dei test Java per isolare i collaboratori.
