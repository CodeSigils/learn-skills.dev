À utiliser lorsque vous avez besoin de réviser, d'améliorer ou de créer des applications Spring Boot 4.0.x - y compris l'utilisation appropriée de @SpringBootApplication, les annotations de composants (@Controller, @Service, @Repository), la définition et la portée du bean, les classes de configuration et @ConfigurationProperties (avec @Validated), l'analyse des composants, la configuration et les profils conditionnels, l'injection de constructeur, @Primary et @Qualifier pour plusieurs beans du même type, la minimisation du bean, l'arrêt progressif, les threads virtuels, Cohérence de l’espace de noms Jakarta EE et tâches planifiées. Cela devrait se déclencher pour des demandes telles que Réviser le code Java pour l'application Spring Boot ; Appliquer les meilleures pratiques pour l'application Spring Boot en code Java ; Améliorer les propriétés de configuration et les beans de Spring Boot ; Examiner l'analyse et les profils des composants Spring Boot ; Ajustez l’arrêt progressif ou les threads virtuels de Spring Boot.
