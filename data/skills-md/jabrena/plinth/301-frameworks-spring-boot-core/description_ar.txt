استخدمه عندما تحتاج إلى مراجعة أو تحسين أو بناء تطبيقات Spring Boot 4.0.x - بما في ذلك الاستخدام السليم لـSpringBootApplication، والتعليقات التوضيحية للمكونات (@Controller، @Service، @Repository)، وتعريف الفول ونطاقه، وفئات التكوين و @ConfigurationProperties (مع @Validated)، ومسح المكونات، والتكوين الشرطي وملفات التعريف، وحقن المنشئ، و@Primary و @Qualifier لحبوب متعددة من نفس النوع، وفاصوليا التقليل، والإغلاق السلس، والخيوط الافتراضية، واتساق مساحة الاسم Jakarta EE، والمهام المجدولة. يجب أن يؤدي ذلك إلى تشغيل طلبات مثل مراجعة كود Java لتطبيق Spring Boot؛ تطبيق أفضل الممارسات لتطبيق Spring Boot في كود Java؛ تحسين خصائص وفاصوليا تكوين Spring Boot؛ مراجعة فحص مكونات Spring Boot وملفات التعريف؛ ضبط إيقاف التشغيل الرشيق لـ Spring Boot أو الخيوط الافتراضية. جزء من مجموعة أدوات القاعدة
