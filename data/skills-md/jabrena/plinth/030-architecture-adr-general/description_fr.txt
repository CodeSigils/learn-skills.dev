À utiliser lorsque vous devez générer des enregistrements de décision d'architecture (ADR) pour un projet Java via un processus interactif et conversationnel qui rassemble systématiquement le contexte, les parties prenantes, les options et les résultats pour produire des documents ADR bien structurés. Cela devrait se déclencher pour des demandes telles que Générer ADR ; Créer un enregistrement de décision d'architecture ; Décision sur l'architecture du document ; Enregistrement de décision d'architecture pour Java. Fait partie de la boîte à outils Plinth
