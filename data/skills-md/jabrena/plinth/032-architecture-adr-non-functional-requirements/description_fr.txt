Facilite la découverte conversationnelle pour créer des enregistrements de décision architecturale (ADR) pour les exigences non fonctionnelles à l'aide du modèle de qualité ISO/IEC 25010:2023. À utiliser lorsque l'utilisateur souhaite documenter les attributs de qualité, les décisions NFR, l'architecture de sécurité/performance/évolutivité ou concevoir des systèmes avec des critères de qualité mesurables. Cela devrait se déclencher pour des demandes telles que Créer un ADR pour les exigences non fonctionnelles ; Documenter les exigences non fonctionnelles ; Capturer les exigences non fonctionnelles ; Générer des exigences non fonctionnelles dans un ADR ; Créez un ADR pour l’évolutivité des performances ou les exigences de sécurité.
