استخدمه عندما تحتاج إلى إعادة بناء كود Java لاعتماد ميزات Java الحديثة (Java 8+) - بما في ذلك ترحيل الفئات المجهولة إلى lambdas، واستبدال حلقات Iterator بـ Stream API، واعتماد اختياري للسلامة الخالية، والتحويل من التاريخ/التقويم القديم إلى java.time، واستخدام أساليب مصنع التجميع، وتطبيق كتل نصية، واستدلال var، أو الاستفادة من ميزات Java 25 مثل أجسام المنشئ المرنة وإعلانات استيراد الوحدة النمطية. يجب أن يؤدي هذا إلى طلبات مثل مراجعة كود Java لتطوير Java الحديث؛ تطبيق أفضل الممارسات لتطوير Java الحديث في كود Java؛ تحديث تعليمات Java البرمجية من خلال مطابقة أنماط السجلات أو تبديل التعبيرات؛ استبدال التعابير القديمة بميزات Java الحديثة؛ اعتماد ميزات لغة Java 8+ بأمان. جزء من مجموعة أدوات القاعدة
