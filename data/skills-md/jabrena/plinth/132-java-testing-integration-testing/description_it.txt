Da utilizzare quando è necessario impostare, rivedere o migliorare i test di integrazione Java, tra cui la generazione di un BaseIntegrationTest.java con WireMock per stub HTTP, il rilevamento dell'infrastruttura client HTTP dai segnali di importazione, l'inserimento dinamico delle coordinate del servizio tramite System.setProperty(), la creazione di file di mappatura JSON WireMock con bodyFileName, l'isolamento degli stub per metodo di test, la verifica delle interazioni HTTP o l'eliminazione di anti-pattern come client HTTP derisi da Mockito o WireMock registrati a livello globale stub. Ciò dovrebbe attivarsi per richieste come Revisione del codice Java per test di integrazione; Applicare le migliori pratiche per i test di integrazione nel codice Java; Scrivere test di integrazione Java con confini reali dell'infrastruttura; Migliorare i test di integrazione di Testcontainers per il codice Java; Esamina la configurazione e lo smontaggio del test di integrazione nei progetti Java.
