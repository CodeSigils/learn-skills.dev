À utiliser lorsque vous devez ajouter ou réviser les migrations de bases de données Flyway dans une application Spring Boot : dépendances Maven, scripts de base de données/migration, configuration spring.flyway.*, référence et validation, et alignement avec JDBC ou Spring Data JDBC. Cela devrait déclencher des demandes telles que l'ajout ou la révision des migrations Flyway dans un projet Spring Boot ; Configurez la disposition spring.flyway ou db/migration ; Ajoutez des migrations Flyway SQL versionnées pour Spring Boot ; Examinez l’ordre de migration de la base de données Spring Boot ; Correction des migrations Flyway répétables dans un projet Spring.
