Da utilizzare quando è necessario aggiungere o rivedere le migrazioni del database Flyway in un'applicazione Spring Boot: dipendenze Maven, script db/migrazione, configurazione spring.flyway.*, linea di base e convalida e allineamento con JDBC o Spring Data JDBC. Ciò dovrebbe attivare richieste come l'aggiunta o la revisione delle migrazioni Flyway in un progetto Spring Boot; Configurare il layout spring.flyway o db/migration; Aggiungere migrazioni Flyway SQL con versione per Spring Boot; Esaminare l'ordine di migrazione del database Spring Boot; Correggi le migrazioni Flyway ripetibili in un progetto Spring. Parte del kit di strumenti Plinth
