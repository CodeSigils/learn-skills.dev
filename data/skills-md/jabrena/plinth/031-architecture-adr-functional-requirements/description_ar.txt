يسهل اكتشاف المحادثة لإنشاء سجلات القرارات المعمارية (ADRs) للمتطلبات الوظيفية التي تغطي CLI أو REST/HTTP APIs أو كليهما. يُستخدم عندما يريد المستخدم توثيق بنية خدمة HTTP أو سطر الأوامر، أو التقاط المتطلبات الوظيفية، أو إنشاء ADRs لمشروعات CLI أو API، أو تصميم واجهات بقرارات موثقة. يجب أن يؤدي ذلك إلى تشغيل طلبات مثل إنشاء ADR للمتطلبات الوظيفية؛ توثيق المتطلبات الوظيفية؛ التقاط المتطلبات الوظيفية؛ إنشاء المتطلبات الوظيفية في ADR؛ حدد المتطلبات الوظيفية لـ CLI مقابل REST لـ ADR. جزء من مجموعة أدوات القاعدة
