Facilita l'individuazione conversazionale per creare Architectural Decision Records (ADR) per i requisiti funzionali che coprono CLI, API REST/HTTP o entrambi. Utilizzare quando l'utente desidera documentare l'architettura della riga di comando o del servizio HTTP, acquisire requisiti funzionali, creare ADR per progetti CLI o API o progettare interfacce con decisioni documentate. Ciò dovrebbe attivare richieste come Creare ADR per requisiti funzionali; Documentare i requisiti funzionali; Catturare i requisiti funzionali; Generare i requisiti funzionali in un ADR; Decidere i requisiti funzionali CLI e REST per un ADR. Parte del kit di strumenti Plinth
