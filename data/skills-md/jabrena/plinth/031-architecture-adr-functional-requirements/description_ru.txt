Облегчает диалоговое обнаружение для создания записей архитектурных решений (ADR) для функциональных требований, охватывающих CLI, REST/HTTP API или и то, и другое. Используйте, когда пользователь хочет документировать архитектуру службы командной строки или HTTP, фиксировать функциональные требования, создавать ADR для проектов CLI или API или разрабатывать интерфейсы с документированными решениями. Это должно инициировать такие запросы, как «Создать ADR для функциональных требований»; Документировать функциональные требования; Сбор функциональных требований; Генерировать функциональные требования в ADR; Определите функциональные требования CLI и REST для ADR.
