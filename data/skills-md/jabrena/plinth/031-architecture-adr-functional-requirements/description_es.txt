Facilita el descubrimiento conversacional para crear registros de decisiones arquitectónicas (ADR) para requisitos funcionales que cubren CLI, API REST/HTTP o ambos. Úselo cuando el usuario desee documentar la arquitectura de la línea de comandos o del servicio HTTP, capturar requisitos funcionales, crear ADR para proyectos CLI o API, o diseñar interfaces con decisiones documentadas. Esto debería activar solicitudes como Crear ADR para requisitos funcionales; Documentar los requisitos funcionales; Captar requisitos funcionales; Generar requisitos funcionales en un ADR; Decida los requisitos funcionales CLI frente a REST para un ADR. Parte del kit de herramientas del zócalo
