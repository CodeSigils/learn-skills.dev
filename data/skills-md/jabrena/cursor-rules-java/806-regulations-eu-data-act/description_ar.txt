يُستخدم عند مراجعة أو تصميم أو تعديل أنظمة مؤسسة Java التي تعرض أو تتبادل أو تخزن أو تعالج أو تصدر أو تنقل البيانات عبر المستخدمين أو الشركات أو المنتجات المتصلة أو موفري الخدمات السحابية أو واجهات برمجة التطبيقات أو تدفقات الأحداث أو خطوط أنابيب بيانات الذكاء الاصطناعي أو مساحات البيانات أو منصات SaaS وتحتاج إلى ضوابط هندسية لقانون بيانات الاتحاد الأوروبي. يجب أن يؤدي هذا إلى طلبات مثل مراجعة منصة Java لضوابط قانون بيانات الاتحاد الأوروبي؛ تصميم الوصول إلى البيانات وأدلة قابلية النقل؛ إضافة مسارات عمل طلب مشاركة البيانات، أو تنسيقات التصدير، أو إمكانية التشغيل البيني، أو البيانات التعريفية، أو سجلات التدقيق، أو دعم التبديل السحابي، أو ضمانات البيانات غير الشخصية، أو عمليات تسليم الأسرار التجارية؛ تقييم الاستعداد الهندسي لقانون البيانات قبل إصدار الإنتاج. جزء من مشروع cursor-rules-java
