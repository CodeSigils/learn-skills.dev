Da utilizzare durante la revisione, la progettazione o la modifica di sistemi aziendali Java che espongono, scambiano, archiviano, elaborano, esportano o trasferiscono dati tra utenti, aziende, prodotti connessi, fornitori di servizi cloud, API, flussi di eventi, pipeline di dati AI, spazi dati o piattaforme SaaS e necessitano dei controlli tecnici del Data Act dell'UE. Ciò dovrebbe attivare richieste come Revisione di una piattaforma Java per i controlli del Data Act dell'UE; Progettare prove di accesso e portabilità dei dati; Aggiungere flussi di lavoro per le richieste di condivisione dei dati, formati di esportazione, interoperabilità, metadati, registri di controllo, supporto per il passaggio al cloud, tutela dei dati non personali o trasferimento di segreti commerciali; Valutare la preparazione tecnica di Data Act prima del rilascio della produzione.
