À utiliser lorsque vous devez réviser, améliorer ou créer des applications Spring Boot, y compris l'utilisation appropriée de @SpringBootApplication, les annotations de composants (@Controller, @Service, @Repository), la définition et la portée du bean, les classes de configuration et @ConfigurationProperties, l'analyse des composants, la configuration et les profils conditionnels, l'injection de constructeur, la minimisation du bean et les tâches planifiées.
