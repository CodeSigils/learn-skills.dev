Utilisez-le lorsque vous avez besoin de conseils MongoDB indépendants du framework et de requêtes de bases de données non relationnelles (conception de schémas de documents, modélisation de collections, validation de schéma JSON, index, pipelines d'agrégation, performances des requêtes, compromis de cohérence, transactions et sécurité opérationnelle) sans choisir Spring Boot, Quarkus ou Micronaut. Cela devrait se déclencher pour des requêtes telles que les schémas de document Design MongoDB ; Examiner les requêtes et les index MongoDB ; Améliorer les performances du pipeline d'agrégation ; Modéliser des modèles d'accès aux données non relationnels ; Examinez la cohérence NoSQL et les compromis entre les transactions. Une partie du projet curseur-règles-java
