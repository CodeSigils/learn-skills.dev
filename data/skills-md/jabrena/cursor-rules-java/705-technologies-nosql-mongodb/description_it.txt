Utilizzalo quando hai bisogno di guida per le query di database MongoDB indipendente dal framework e non relazionale: progettazione di schemi di documenti, modellazione di raccolte, convalida di schemi JSON, indici, pipeline di aggregazione, prestazioni delle query, compromessi di coerenza, transazioni e sicurezza operativa, senza scegliere Spring Boot, Quarkus o Micronaut. Ciò dovrebbe attivarsi per richieste come schemi di documenti Design MongoDB; Esaminare le query e gli indici MongoDB; Migliorare le prestazioni della pipeline di aggregazione; Modellare modelli di accesso ai dati non relazionali; Esaminare la coerenza NoSQL e i compromessi delle transazioni.
