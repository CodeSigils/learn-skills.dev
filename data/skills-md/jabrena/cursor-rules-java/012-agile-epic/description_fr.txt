Guide la création d'épopées agiles avec une définition complète incluant la valeur commerciale, les critères de réussite et la répartition en user stories. À utiliser lorsque l'utilisateur souhaite créer une épopée agile, définir de grands volumes de travail, décomposer les fonctionnalités en user stories ou documenter des initiatives stratégiques. Une partie du projet skills-for-java
