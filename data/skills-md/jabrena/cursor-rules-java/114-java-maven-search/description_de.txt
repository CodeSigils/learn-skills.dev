Deckt die Maven Central-Suche (Such-API, maven-metadata.xml, Artefakt-URLs) und projektlokale Aktualisierungsberichte über das Versionen-Maven-Plugin (Display-Property-Updates, Display-Dependency-Updates, Display-Plugin-Updates) ab. Verwenden Sie diese Option, wenn Sie Koordinaten suchen oder überprüfen, Central durchsuchen oder überprüfen, welche neueren Versionen für die pom.xml des Benutzers gelten.
