Охватывает центральный поиск Maven (API поиска, maven-metadata.xml, URL-адреса артефактов) и локальные отчеты об обновлениях проекта через подключаемый модуль version-maven (обновления-свойства-обновления, обновления-зависимости-отображения, обновления-плагина-отображения). Используйте при поиске или проверке координат, просмотре Центра или проверке того, какие новые версии применяются к pom.xml пользователя. Часть проекта «Навыки для Java»
