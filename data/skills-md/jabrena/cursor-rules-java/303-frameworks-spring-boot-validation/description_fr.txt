À utiliser lorsque vous devez concevoir, réviser ou améliorer la validation dans les applications Spring Boot, y compris la validation de bean sur demande DTO, @Valid/@Validated aux limites de l'API, les groupes de contraintes, les contraintes personnalisées, la validation @ConfigurationProperties, la validation DTO imbriquée et la gestion cohérente des erreurs de validation. Cela devrait déclencher des demandes telles que Ajouter un support de validation dans Spring Boot ; Examinez les règles de validation de Spring Boot ; Améliorer la validation des requêtes dans les API REST Spring Boot ; Ajoutez des contraintes de validation de bean personnalisées dans Spring Boot ; Validez les propriétés de configuration dans Spring Boot. Une partie du projet curseur-règles-java
