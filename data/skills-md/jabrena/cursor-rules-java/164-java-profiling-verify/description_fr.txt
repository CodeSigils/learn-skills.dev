À utiliser lorsque vous devez vérifier les optimisations des performances Java en comparant les résultats de profilage avant et après le refactoring, y compris la validation de base, la génération de rapports post-refactoring, la comparaison de métriques quantitatives avant/après, l'analyse de flamegraph côte à côte, la détection de régression ou la création d'une documentation d'analyse de comparaison de profilage et de résultats finaux de profilage. Une partie du projet skills-for-java
