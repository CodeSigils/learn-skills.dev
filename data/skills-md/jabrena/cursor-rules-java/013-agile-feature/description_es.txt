Guía la creación de documentación detallada de funciones ágiles a partir de una epopeya existente. Úselo cuando el usuario desee dividir una epopeya en archivos de funciones, derivar funciones con alcance y criterios de aceptación, o planificar la documentación de funciones para las partes interesadas o la ingeniería. Parte del proyecto skills-for-java
