Руководит созданием подробной документации по гибким функциям на основе существующего эпика. Используйте, когда пользователь хочет разделить эпик на файлы функций, получить функции с указанием области применения и критериев приемки или спланировать документацию функций для заинтересованных сторон или разработчиков. Часть проекта «Навыки для Java»
