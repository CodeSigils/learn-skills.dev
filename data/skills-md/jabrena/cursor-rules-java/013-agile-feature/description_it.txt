Guida la creazione di una documentazione dettagliata sulle funzionalità agili da un'epica esistente. Utilizzare quando l'utente desidera dividere un'epica in file di funzionalità, derivare funzionalità con ambito e criteri di accettazione o pianificare la documentazione delle funzionalità per le parti interessate o il team di progettazione.
