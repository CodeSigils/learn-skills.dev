Guide la création d’une documentation détaillée des fonctionnalités agiles à partir d’une épopée existante. À utiliser lorsque l'utilisateur souhaite diviser une épopée en fichiers de fonctionnalités, dériver des fonctionnalités avec des critères de portée et d'acceptation, ou planifier une documentation sur les fonctionnalités pour les parties prenantes ou l'ingénierie. Une partie du projet skills-for-java
