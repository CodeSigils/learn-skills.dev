Используйте, когда вам нужно написать модульные тесты для приложений Micronaut — Mockito-first с @ExtendWith(MockitoExtension.class), @MicronautTest с @MockBean, утверждения HttpClient @Client("/"), переопределения @Property, @ParameterizedTest и *Test vs *IT naming. Для Java, не зависящего от платформы, используйте @131-java-testing-unit-testing. Часть проекта «Навыки для Java»
