Da utilizzare quando è necessario scrivere test unitari per le applicazioni Micronaut: Mockito-first con @ExtendWith(MockitoExtension.class), @MicronautTest con @MockBean, asserzioni HttpClient @Client("/"), override @Property, @ParameterizedTest e denominazione *Test vs *IT. Per Java indipendente dal framework utilizzare @ 131-java-testing-unit-testing. Parte del progetto skills-for-java
