À utiliser lorsque vous devez écrire des tests unitaires pour les applications Micronaut : Mockito-first avec @ExtendWith(MockitoExtension.class), @MicronautTest avec @MockBean, assertions HttpClient @Client("/"), remplacements @Property, @ParameterizedTest et dénomination *Test vs *IT. Pour Java indépendant du framework, utilisez @131-java-testing-unit-testing. Une partie du projet skills-for-java
