Используйте, когда вам нужно написать или просмотреть программный JDBC с помощью Spring, включая JdbcTemplate, NamedParameterJdbcTemplate, JdbcClient (Spring Framework 6.1+), параметризованный SQL, сопоставление RowMapper с записями, пакетные операции, транзакции, безопасную обработку сгенерированных ключей, обработку DataAccessException, транзакции только для чтения, потоковую передачу больших наборов результатов и тестирование срезов @JdbcTest.
