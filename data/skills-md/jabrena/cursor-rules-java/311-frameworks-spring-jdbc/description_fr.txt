À utiliser lorsque vous devez écrire ou réviser du JDBC programmatique avec Spring, notamment JdbcTemplate, NamedParameterJdbcTemplate, JdbcClient (Spring Framework 6.1+), SQL paramétré, le mappage RowMapper aux enregistrements, les opérations par lots, les transactions, la gestion sécurisée des clés générées, la gestion DataAccessException, les transactions en lecture seule, la diffusion en continu de grands ensembles de résultats et les tests de tranche @JdbcTest.
