استخدمه عندما تحتاج إلى كتابة اختبارات وحدة سريعة لتطبيقات Quarkus - بما في ذلك الاختبارات النقية باستخدام @ExtendWith(MockitoExtension.class)، و@QuarkusTest مع @InjectMock لاستبدال محاكاة CDI الكامل، و@InjectSpy للسخرية الجزئية لفاصوليا CDI، وREST Assured للاختبارات التي تركز على الموارد، و@ParameterizedTest مع @CsvSource / @MethodSource، وQuarkusTestProfile للتكوين الخاص بالاختبار. التجاوزات واصطلاحات التسمية (*Test → Surefire، *IT → Failsafe). بالنسبة لـ Java المحايدة لإطار العمل، استخدم @131-java-testing-unit-testing. جزء من مشروع مهارات جافا
