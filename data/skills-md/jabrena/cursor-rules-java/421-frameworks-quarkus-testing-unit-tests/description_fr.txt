À utiliser lorsque vous avez besoin d'écrire des tests unitaires rapides pour les applications Quarkus, y compris des tests purs avec @ExtendWith(MockitoExtension.class), @QuarkusTest avec @InjectMock pour un remplacement simulé CDI complet, @InjectSpy pour une simulation partielle de bean CDI, REST Assured pour les tests axés sur les ressources, @ParameterizedTest avec @CsvSource / @MethodSource, QuarkusTestProfile pour les remplacements de configuration spécifiques aux tests et les conventions de dénomination. (*Test → Surefire, *IT → Failsafe). Pour Java indépendant du framework, utilisez @131-java-testing-unit-testing. Une partie du projet skills-for-java
