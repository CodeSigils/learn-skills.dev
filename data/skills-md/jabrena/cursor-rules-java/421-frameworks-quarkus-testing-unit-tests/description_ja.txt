Quarkus アプリケーションの高速単体テストを作成する必要がある場合に使用します。これには、@ExtendWith(MockitoExtension.class) を使用した純粋なテスト、完全な CDI モック置換用の @InjectMock を使用した @QuarkusTest、部分的な CDI Bean モック用の @InjectSpy、リソース中心のテスト用の REST Assured、@CsvSource / @MethodSource を使用した @ParameterizedTest、テスト固有の構成用の QuarkusTestProfile が含まれます。オーバーライドと命名規則 (*Test → Surefire、*IT → Failsafe)。フレームワークに依存しない Java の場合は、@131-java-testing-unit-testing を使用します。 Skills-for-Java プロジェクトの一部
