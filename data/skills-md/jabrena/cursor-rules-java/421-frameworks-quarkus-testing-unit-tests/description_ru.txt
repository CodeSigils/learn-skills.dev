Используйте, когда вам нужно написать быстрые модульные тесты для приложений Quarkus, включая чистые тесты с @ExtendWith(MockitoExtension.class), @QuarkusTest с @InjectMock для полной замены макета CDI, @InjectSpy для частичного макетирования компонента CDI, REST Assured для тестов, ориентированных на ресурсы, @ParameterizedTest с @CsvSource / @MethodSource, QuarkusTestProfile для настройки конкретного теста переопределения и соглашения об именах (*Test → Surefire, *IT → Failsafe). Для Java, не зависящего от платформы, используйте @131-java-testing-unit-testing. Часть проекта «Навыки для Java»
