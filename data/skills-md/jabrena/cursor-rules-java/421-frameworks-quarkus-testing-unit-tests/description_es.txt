Úselo cuando necesite escribir pruebas unitarias rápidas para aplicaciones Quarkus, incluidas pruebas puras con @ExtendWith(MockitoExtension.class), @QuarkusTest con @InjectMock para un reemplazo simulado de CDI completo, @InjectSpy para una simulación parcial de bean CDI, REST Assured para pruebas centradas en recursos, @ParameterizedTest con @CsvSource/@MethodSource, QuarkusTestProfile para anulaciones de configuración específicas de pruebas y convenciones de nomenclatura. (*Prueba → Infalible, *TI → A prueba de fallos). Para Java independiente del marco, utilice @131-java-testing-unit-testing. Parte del proyecto skills-for-java
