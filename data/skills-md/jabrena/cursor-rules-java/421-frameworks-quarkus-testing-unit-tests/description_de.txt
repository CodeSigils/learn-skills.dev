Verwenden Sie diese Option, wenn Sie schnelle Komponententests für Quarkus-Anwendungen schreiben müssen – einschließlich reiner Tests mit @ExtendWith(MockitoExtension.class), @QuarkusTest mit @InjectMock für den vollständigen CDI-Mock-Ersatz, @InjectSpy für teilweises CDI-Bean-Mocking, REST Assured für ressourcenorientierte Tests, @ParameterizedTest mit @CsvSource / @MethodSource, QuarkusTestProfile für testspezifische Konfigurationsüberschreibungen und Namenskonventionen (*Test → Surefire, *IT → Failsafe). Für Framework-unabhängiges Java verwenden Sie @131-java-testing-unit-testing. Teil des Skills-for-Java-Projekts
