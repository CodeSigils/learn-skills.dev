Da utilizzare quando è necessario scrivere test unitari rapidi per le applicazioni Quarkus, inclusi test puri con @ExtendWith(MockitoExtension.class), @QuarkusTest con @InjectMock per la sostituzione completa del mock CDI, @InjectSpy per il mocking parziale del bean CDI, REST Assured per test incentrati sulle risorse, @ParameterizedTest con @CsvSource / @MethodSource, QuarkusTestProfile per la configurazione specifica del test sostituzioni e convenzioni di denominazione (*Test → Surefire, *IT → Failsafe). Per Java indipendente dal framework utilizzare @ 131-java-testing-unit-testing. Parte del progetto skills-for-java
