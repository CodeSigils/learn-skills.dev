Facilita l'individuazione conversazionale per creare Architectural Decision Records (ADR) per lo sviluppo della CLI. Da utilizzare quando l'utente desidera documentare l'architettura della CLI, acquisire requisiti funzionali per uno strumento da riga di comando, creare ADR per progetti CLI o progettare applicazioni CLI con decisioni documentate.
