Облегчает диалоговое обнаружение для создания записей архитектурных решений (ADR) для разработки CLI. Используйте, когда пользователь хочет документировать архитектуру CLI, зафиксировать функциональные требования для инструмента командной строки, создать ADR для проектов CLI или разработать приложения CLI с документированными решениями. Часть проекта «Навыки для Java»
