Facilite la découverte conversationnelle pour créer des enregistrements de décision architecturale (ADR) pour le développement de CLI. À utiliser lorsque l'utilisateur souhaite documenter l'architecture CLI, capturer les exigences fonctionnelles pour un outil de ligne de commande, créer des ADR pour les projets CLI ou concevoir des applications CLI avec des décisions documentées. Une partie du projet skills-for-java
