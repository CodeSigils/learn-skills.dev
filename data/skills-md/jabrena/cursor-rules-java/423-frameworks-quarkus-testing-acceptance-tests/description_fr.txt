À utiliser lorsque vous devez implémenter des tests d'acceptation à partir d'un fichier Gherkin .feature pour les applications Quarkus, notamment les scénarios @acceptance, @QuarkusTest, BaseAcceptanceTest avec QuarkusTestResourceLifecycleManager pour Testcontainers et WireMock, REST Assured pour les tests complets de pipeline HTTP, les fichiers de mappage WireMock JSON (classpath:wiremock/mappings/), la dénomination du suffixe *AT et Maven Surefire/Failsafe. répartition en trois niveaux. Nécessite le fichier .feature en contexte. Une partie du projet skills-for-java
