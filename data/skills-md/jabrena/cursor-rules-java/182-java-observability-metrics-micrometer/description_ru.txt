Используйте, когда вам нужно реализовать или улучшить наблюдаемость метрик Java с помощью Micrometer, включая проектирование счетчиков, соглашения об именах/тегах, контроль мощности, таймеры/счетчики/датчики/сводки распределения, процентили/гистограммы, интеграцию Actuator/Prometheus и проверку метрик с помощью тестов. Это должно срабатывать для таких запросов, как «Улучшить показатели»; Примените микрометр; Добавьте наблюдаемость метрик; Рефакторинг приборов микрометра. Часть проекта курсора-правил-Java
