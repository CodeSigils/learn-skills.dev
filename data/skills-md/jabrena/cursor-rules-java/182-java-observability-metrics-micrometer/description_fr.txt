À utiliser lorsque vous devez implémenter ou améliorer l'observabilité des métriques Java avec Micrometer, y compris la conception des compteurs, les conventions de dénomination/balise, le contrôle de cardinalité, les minuteries/compteurs/jauges/résumés de distribution, les centiles/histogrammes, l'intégration d'Actuator/Prometheus et la validation des métriques via des tests. Cela devrait déclencher des demandes telles que Améliorer les métriques ; Appliquer un micromètre ; Ajouter l'observabilité des métriques ; Instrumentation micrométrique Refactor. Une partie du projet curseur-règles-java
