Verwenden Sie diese Option, wenn Sie Unit-Tests für Spring Boot-Anwendungen schreiben müssen – einschließlich reiner Unit-Tests mit @ExtendWith(MockitoExtension.class) für @Service/@Component, Slice-Tests mit @WebMvcTest und @MockitoBean für Controller, @JsonTest für JSON-Serialisierung, parametrisierte Tests mit @CsvSource/@MethodSource, Testprofile und @TestConfiguration. Für Framework-unabhängiges Java verwenden Sie @131-java-testing-unit-testing. Für Integrationstests verwenden Sie @322-frameworks-spring-boot-testing-integration-tests.
