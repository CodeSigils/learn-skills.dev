Используйте, когда вам нужно написать модульные тесты для приложений Spring Boot, включая чистые модульные тесты с @ExtendWith(MockitoExtension.class) для @Service/@Component, срезовые тесты с @WebMvcTest и @MockitoBean для контроллеров, @JsonTest для сериализации JSON, параметризованные тесты с @CsvSource/@MethodSource, тестовые профили и @TestConfiguration. Для Java, не зависящего от платформы, используйте @131-java-testing-unit-testing. Для интеграционных тестов используйте @322-frameworks-spring-boot-testing-integration-tests.
