Spring Boot アプリケーションの単体テストを作成する必要がある場合に使用します。これには、@Service/@Component の @ExtendWith(MockitoExtension.class) を使用した純粋な単体テスト、コントローラーの @WebMvcTest および @MockitoBean を使用したスライス テスト、JSON シリアル化の @JsonTest、@CsvSource/@MethodSource を使用したパラメーター化されたテスト、テスト プロファイル、および @TestConfiguration が含まれます。フレームワークに依存しない Java の場合は、@131-java-testing-unit-testing を使用します。統合テストには @322-frameworks-spring-boot-testing-integration-tests を使用します。 Skills-for-Java プロジェクトの一部
