استخدمه عندما تحتاج إلى كتابة اختبارات الوحدة لتطبيقات Spring Boot - بما في ذلك اختبارات الوحدة النقية باستخدام @ExtendWith(MockitoExtension.class) لـ @Service/@Component، واختبارات الشرائح باستخدام @WebMvcTest و@MockitoBean لوحدات التحكم، و@JsonTest لتسلسل JSON، والاختبارات ذات المعلمات مع @CsvSource/@MethodSource، وملفات تعريف الاختبار، و@TestConfiguration. بالنسبة لـ Java المحايدة لإطار العمل، استخدم @131-java-testing-unit-testing. بالنسبة لاختبارات التكامل، استخدم @322-frameworks-spring-boot-testing-integration-tests. جزء من مشروع مهارات جافا
