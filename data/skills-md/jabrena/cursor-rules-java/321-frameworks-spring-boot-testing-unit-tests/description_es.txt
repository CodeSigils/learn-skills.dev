Úselo cuando necesite escribir pruebas unitarias para aplicaciones Spring Boot, incluidas pruebas unitarias puras con @ExtendWith(MockitoExtension.class) para @Service/@Component, pruebas de corte con @WebMvcTest y @MockitoBean para controladores, @JsonTest para serialización JSON, pruebas parametrizadas con @CsvSource/@MethodSource, perfiles de prueba y @TestConfiguration. Para Java independiente del marco, utilice @131-java-testing-unit-testing. Para pruebas de integración, utilice @322-frameworks-spring-boot-testing-integration-tests.
