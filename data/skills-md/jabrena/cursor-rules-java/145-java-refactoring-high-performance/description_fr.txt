À utiliser lorsque vous devez refactoriser le code Java pour des performances élevées, notamment la réduction de la mémoire/de l'allocation, l'optimisation du hot-path du processeur et les améliorations de la syntaxe/API/flux de contrôle. Cela devrait déclencher des requêtes telles que Réviser le code Java pour des performances élevées ; Optimiser le chemin chaud Java ; Réduisez les allocations Java ; Améliorez la latence/le débit Java. Une partie du projet curseur-règles-java
