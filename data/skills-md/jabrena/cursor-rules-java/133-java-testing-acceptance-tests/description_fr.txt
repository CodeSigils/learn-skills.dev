À utiliser lorsque vous devez implémenter des tests d'acceptation à partir d'un fichier Gherkin .feature pour Java indépendant du framework (pas de Spring Boot, Quarkus, Micronaut) - recherche de scénarios @acceptance, chemin heureux avec RestAssured, Testcontainers pour DB/Kafka, WireMock pour REST externe. Nécessite un fichier .feature en contexte. Une partie du projet skills-for-java
