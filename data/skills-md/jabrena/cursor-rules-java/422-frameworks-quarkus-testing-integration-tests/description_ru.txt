Используйте, когда вам нужно написать или улучшить интеграционные тесты для Quarkus, включая @QuarkusTest, Dev Services для автоматической подготовки контейнеров, Testcontainers через QuarkusTestResourceLifecycleManager, WireMock для внешних HTTP-заглушек, @QuarkusIntegrationTest для тестирования «черного ящика» на предмет упакованных артефактов, REST Assured, стратегии изоляции данных (@TestTransaction против очистки @BeforeEach) и трехуровневое разделение Maven Surefire/Failsafe (*Тест, *ИТ, *АТ).
