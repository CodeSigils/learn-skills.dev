À utiliser lorsque vous avez besoin d'écrire ou d'améliorer des tests d'intégration pour Quarkus, notamment @QuarkusTest, Dev Services pour le provisionnement automatique des conteneurs, Testcontainers via QuarkusTestResourceLifecycleManager, WireMock pour les stubs HTTP externes, @QuarkusIntegrationTest pour les tests en boîte noire sur les artefacts packagés, REST Assured, les stratégies d'isolation des données (@TestTransaction vs @BeforeEach cleanup) et la répartition à trois niveaux Maven Surefire/Failsafe. (*Test, *IT, *AT). Une partie du projet skills-for-java
