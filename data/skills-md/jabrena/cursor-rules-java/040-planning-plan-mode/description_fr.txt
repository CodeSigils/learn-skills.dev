À utiliser lors de la création d'un plan à l'aide du modèle Plan et de l'amélioration des plans de conception structurés en mode Cursor Plan pour les implémentations Java. À utiliser lorsque l'utilisateur souhaite créer un plan, concevoir une implémentation, structurer un plan de développement ou utiliser le mode plan pour un TDD externe, une implémentation de fonctionnalités ou un travail de refactorisation.
