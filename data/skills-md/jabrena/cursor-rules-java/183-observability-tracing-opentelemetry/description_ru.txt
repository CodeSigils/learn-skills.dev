Используйте, когда вам нужно реализовать или улучшить распределенную трассировку с помощью OpenTelemetry на Java, включая моделирование трассировки/диапазона, распространение контекста, семантические соглашения, атрибуты/события/статус диапазона, стратегию выборки, использование багажа, меры защиты конфиденциальности и внутреннюю интеграцию со сборщиками OTLP. Это должно срабатывать для таких запросов, как «Улучшение трассировки»; Применить трассировку OpenTelemetry; Добавить распределенную трассировку; Рефакторинг инструментов трассировки.
