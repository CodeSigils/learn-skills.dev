À utiliser lorsque vous devez implémenter ou améliorer le traçage distribué avec OpenTelemetry en Java, y compris la modélisation de trace/span, la propagation du contexte, les conventions sémantiques, les attributs/événements/statuts de span, la stratégie d'échantillonnage, l'utilisation des bagages, les garanties de confidentialité et l'intégration back-end avec les collecteurs OTLP. Cela devrait déclencher des demandes telles que Améliorer le traçage ; Appliquer le traçage OpenTelemetry ; Ajoutez un traçage distribué ; Instrumentation de traçage de refactorisation. Une partie du projet curseur-règles-java
