Da utilizzare quando è necessario impostare la profilazione dell'applicazione Java per rilevare e misurare i problemi di prestazioni, inclusa la configurazione automatizzata del profilatore asincrono v4.0, la profilazione basata sui problemi (CPU, memoria, threading, GC, I/O), script di profilazione interattivi, integrazione JFR con Java 25 (JEP 518, JEP 520) o raccolta di dati di profilazione con flamegraph e registrazioni JFR. Parte del progetto skills-for-java
