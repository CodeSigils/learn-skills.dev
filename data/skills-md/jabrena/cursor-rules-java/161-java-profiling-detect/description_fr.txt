À utiliser lorsque vous devez configurer le profilage d'application Java pour détecter et mesurer les problèmes de performances, y compris la configuration automatisée du profil asynchrone v4.0, le profilage basé sur les problèmes (CPU, mémoire, threading, GC, E/S), les scripts de profilage interactifs, l'intégration JFR avec Java 25 (JEP 518, JEP 520) ou la collecte de données de profilage avec des flamegraphs et des enregistrements JFR.
