À utiliser lorsque vous avez besoin de la messagerie Kafka dans Quarkus avec la messagerie réactive SmallRye — y compris la conception de canal/sujet, la sérialisation, les stratégies d'accusé de réception/échec, les tentatives/DLQ et la gestion des erreurs. Cela devrait se déclencher pour des requêtes telles que Ajouter Kafka dans Quarkus ; Examiner les consommateurs de messagerie réactive ; Améliorer la gestion des échecs pour Quarkus Kafka.
