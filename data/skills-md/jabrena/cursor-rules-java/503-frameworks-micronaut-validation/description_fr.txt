À utiliser lorsque vous devez concevoir, réviser ou améliorer la validation dans les applications Micronaut, notamment la validation Bean sur les méthodes @Controller, @Body @Valid, la validation des paramètres de requête/chemin, la validation @ConfigurationProperties, les contraintes personnalisées, la validation DTO imbriquée et le mappage ExceptionHandler pour les violations de contraintes. Cela devrait déclencher des demandes telles que Ajouter un support de validation dans Micronaut ; Revoir les règles de validation Micronaut ; Améliorer la validation des demandes dans les API REST de Micronaut ; Ajouter des contraintes de validation personnalisées dans Micronaut ; Validez les propriétés de configuration Micronaut. Une partie du projet curseur-règles-java
