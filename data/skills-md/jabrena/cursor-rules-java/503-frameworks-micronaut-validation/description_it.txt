Da utilizzare quando è necessario progettare, rivedere o migliorare la convalida nelle applicazioni Micronaut, tra cui la convalida Bean sui metodi @Controller, @Body @Valid, la convalida dei parametri di query/percorso, la convalida @ConfigurationProperties, i vincoli personalizzati, la convalida DTO nidificata e la mappatura ExceptionHandler per le violazioni dei vincoli. Ciò dovrebbe attivarsi per richieste come Aggiungi supporto di convalida in Micronaut; Rivedere le regole di convalida di Micronaut; Migliorare la convalida delle richieste nelle API REST Micronaut; Aggiungi vincoli di convalida personalizzati in Micronaut; Convalida le proprietà di configurazione di Micronaut.
