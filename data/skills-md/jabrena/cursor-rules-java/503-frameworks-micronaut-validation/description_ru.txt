Используйте, когда вам нужно спроектировать, просмотреть или улучшить проверку в приложениях Micronaut, включая проверку bean-компонентов в методах @Controller, @Body @Valid, проверку параметров запроса/пути, проверку @ConfigurationProperties, пользовательские ограничения, проверку вложенных DTO и сопоставление ExceptionHandler для нарушений ограничений. Это должно срабатывать для таких запросов, как «Добавить поддержку проверки в Micronaut»; Ознакомьтесь с правилами проверки Micronaut; Улучшение проверки запросов в API REST Micronaut; Добавьте пользовательские ограничения проверки в Micronaut; Проверьте свойства конфигурации Micronaut.
