À utiliser lorsque vous devez concevoir, réviser ou améliorer la sécurité dans les applications Micronaut, y compris l'authentification de sécurité Micronaut, les règles @Secured et intercept-url-map, les stratégies JWT/session, les contrôles SecurityService, CORS, la reconnaissance CSRF pour les applications de navigateur, les gestionnaires de rejet et la journalisation sécurisée des données sensibles. Cela devrait déclencher des demandes telles que l'ajout du support de sécurité Micronaut ; Examiner la configuration de sécurité de Micronaut ; Améliorer l'autorisation API dans Micronaut ; Ajouter la sécurité JWT dans Micronaut ; Renforcez les règles d’autorisation d’itinéraire Micronaut. Une partie du projet curseur-règles-java
