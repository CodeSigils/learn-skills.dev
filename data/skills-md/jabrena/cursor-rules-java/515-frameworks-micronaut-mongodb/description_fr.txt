À utiliser lorsque vous avez besoin de la persistance MongoDB dans Micronaut, y compris la conception @MongoRepository, la modélisation de documents, les index, les modèles de requête et la gestion des erreurs. Cela devrait déclencher des requêtes telles que Ajouter MongoDB dans Micronaut ; Examiner la conception de Micronaut Data Mongo ; Améliorez la gestion des erreurs pour les opérations Micronaut Mongo. Une partie du projet curseur-règles-java
