À utiliser lorsque vous devez installer les agents de robot intégrés dans .cursor/agents ou .claude/agents, en sélectionnant la destination de manière interactive et en copiant les définitions d'agent intégré à partir des actifs du projet. Cela devrait se déclencher pour des requêtes telles que Installer des agents intégrés ; Bootstrap .cursor/agents ; Bootstrap .claude/agents ; Copiez les agents robots.
