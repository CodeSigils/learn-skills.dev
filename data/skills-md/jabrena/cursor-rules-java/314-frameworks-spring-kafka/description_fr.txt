À utiliser lorsque vous devez concevoir ou implémenter la messagerie Kafka dans Spring Boot, y compris la conception de sujets, l'implémentation producteur/consommateur avec Spring pour Apache Kafka, les tentatives et les sujets de lettre morte, l'idempotence et la gestion des erreurs. Cela devrait déclencher des requêtes telles que Ajouter Kafka dans Spring Boot ; Examinez les consommateurs de Spring Kafka ; Améliorez les tentatives et le DLT dans Spring Kafka. Une partie du projet curseur-règles-java
