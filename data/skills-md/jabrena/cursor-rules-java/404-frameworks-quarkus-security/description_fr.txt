À utiliser lorsque vous devez concevoir, réviser ou améliorer la sécurité dans les applications Quarkus, notamment la sécurité Quarkus avec JWT/OIDC, l'authentification de base, @RolesAllowed / @Authenticated / @PermitAll, SecurityIdentity, les contrôles d'autorisation, l'autorisation basée sur le chemin dans la configuration, le mappage des exceptions pour les échecs d'authentification et la journalisation sécurisée des données sensibles. Cela devrait déclencher des demandes telles que l'ajout du support de sécurité Quarkus ; Vérifiez la configuration de la sécurité de Quarkus ; Améliorer l'autorisation API dans Quarkus ; Ajoutez la sécurité JWT/OIDC dans Quarkus ; Renforcez les règles d'autorisation de Quarkus. Une partie du projet curseur-règles-java
