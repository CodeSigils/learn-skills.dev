Используйте, когда вам нужен интерфейс командной строки Jira («jira») для проверки установки, настройки доступа к Jira Cloud, перечисления проблем (всех или по JQL) в виде таблиц уценки и получения описаний проблем и комментариев для анализа. Использует интерактивный шлюз установки: если `jira` отсутствует, спросите, показывать ли руководство по установке, прежде чем выполнять какие-либо команды по проблеме.
