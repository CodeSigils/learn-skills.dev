À utiliser lorsque vous avez besoin de Jira CLI (`jira`) pour vérifier l'installation, configurer l'accès à Jira Cloud, répertorier les problèmes (tous ou par JQL) sous forme de tableaux de démarques et récupérer les descriptions des problèmes et les commentaires pour analyse. Utilise une porte d'installation interactive - si « jira » est manquant, demandez s'il faut afficher les instructions d'installation avant d'émettre des commandes.
