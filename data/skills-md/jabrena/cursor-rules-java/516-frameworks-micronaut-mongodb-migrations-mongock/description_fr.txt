À utiliser lorsque vous devez ajouter ou réviser les migrations de données Mongock MongoDB dans une application Micronaut, y compris la sélection du coureur/pilote Mongock, le câblage du bean Micronaut, les packages d'analyse de migration, les classes @ChangeUnit, les paramètres de verrouillage/transaction et la vérification des conteneurs de test. Cela devrait déclencher des demandes telles que les migrations Ajouter Mongock dans Micronaut ; Examiner les migrations de données Micronaut MongoDB ; Configurez les unités de changement Mongock avec Micronaut Data MongoDB. Une partie du projet curseur-règles-java
