Úselo cuando necesite agregar o revisar migraciones de datos de Mongock MongoDB en una aplicación Micronaut, incluida la selección de ejecutores/controladores de Mongock, cableado de beans Micronaut, paquetes de escaneo de migración, clases @ChangeUnit, configuraciones de bloqueo/transacción y verificación de contenedores de prueba. Esto debería activar solicitudes como Agregar migraciones de Mongock en Micronaut; Revisar las migraciones de datos de Micronaut MongoDB; Configurar unidades de cambio Mongock con Micronaut Data MongoDB.
