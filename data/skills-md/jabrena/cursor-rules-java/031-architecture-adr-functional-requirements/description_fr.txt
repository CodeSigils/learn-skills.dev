Facilite la découverte conversationnelle pour créer des enregistrements de décision architecturale (ADR) pour les exigences fonctionnelles couvrant les API CLI, REST/HTTP ou les deux. À utiliser lorsque l'utilisateur souhaite documenter l'architecture de ligne de commande ou de service HTTP, capturer les exigences fonctionnelles, créer des ADR pour des projets CLI ou API, ou concevoir des interfaces avec des décisions documentées. Une partie du projet skills-for-java
