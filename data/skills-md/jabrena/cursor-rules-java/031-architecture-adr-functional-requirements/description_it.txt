Facilita l'individuazione conversazionale per creare Architectural Decision Records (ADR) per i requisiti funzionali che coprono CLI, API REST/HTTP o entrambi. Utilizzare quando l'utente desidera documentare l'architettura della riga di comando o del servizio HTTP, acquisire requisiti funzionali, creare ADR per progetti CLI o API o progettare interfacce con decisioni documentate.
