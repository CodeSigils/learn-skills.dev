Облегчает диалоговое обнаружение для создания записей архитектурных решений (ADR) для функциональных требований, охватывающих CLI, API REST/HTTP или и то, и другое. Используйте, когда пользователь хочет документировать архитектуру службы командной строки или HTTP, фиксировать функциональные требования, создавать ADR для проектов CLI или API или разрабатывать интерфейсы с документированными решениями. Часть проекта «Навыки для Java»
