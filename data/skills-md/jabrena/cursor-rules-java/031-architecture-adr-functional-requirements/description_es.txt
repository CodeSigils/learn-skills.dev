Facilita el descubrimiento conversacional para crear registros de decisiones arquitectónicas (ADR) para requisitos funcionales que cubren CLI, API REST/HTTP o ambos. Úselo cuando el usuario desee documentar la arquitectura de la línea de comandos o del servicio HTTP, capturar requisitos funcionales, crear ADR para proyectos CLI o API, o diseñar interfaces con decisiones documentadas.
