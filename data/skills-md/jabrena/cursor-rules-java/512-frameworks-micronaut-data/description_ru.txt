Используйте, когда вам нужен доступ к данным с помощью данных Micronaut — @MappedEntity, CrudRepository/PageableRepository, @Query с параметрами, @Transactional сервисы, проекции, @Version и @MicronautTest с TestPropertyProvider и Testcontainers. Охватывает данные Micronaut в стиле JDBC/JPA в одном приглашении (без отдельного правила 511 JDBC). Часть проекта «Навыки для Java»
