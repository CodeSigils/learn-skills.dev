À utiliser lorsque vous avez besoin d'accéder aux données avec Micronaut Data : @MappedEntity, CrudRepository/PageableRepository, @Query avec paramètres, @Transactional services, projections, @Version et @MicronautTest avec TestPropertyProvider et Testcontainers. Couvre les données Micronaut de style JDBC/JPA dans une seule invite (pas de règle JDBC 511 distincte). Une partie du projet skills-for-java
