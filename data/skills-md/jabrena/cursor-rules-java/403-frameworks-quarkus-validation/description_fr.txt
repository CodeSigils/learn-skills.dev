À utiliser lorsque vous devez concevoir, réviser ou améliorer la validation dans les applications Quarkus, notamment la validation de bean sur les ressources JAX-RS, @Valid sur les paramètres et les beans CDI, les groupes de contraintes, la validation @ConfigMapping, les contraintes personnalisées, la validation DTO imbriquée et le mappage d'erreurs basé sur ExceptionMapper. Cela devrait déclencher des demandes telles que Ajouter un support de validation dans Quarkus ; Examiner les règles de validation Quarkus ; Améliorer la validation des demandes dans les API Quarkus REST ; Ajoutez des contraintes de validation personnalisées dans Quarkus ; Validez les propriétés Quarkus @ConfigMapping. Une partie du projet curseur-règles-java
