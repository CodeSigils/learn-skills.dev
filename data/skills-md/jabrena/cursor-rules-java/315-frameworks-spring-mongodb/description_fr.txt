À utiliser lorsque vous devez concevoir ou implémenter l'accès aux données MongoDB dans Spring Boot, y compris la modélisation de documents, les référentiels/modèles Spring Data Mongo, l'indexation, la concurrence optimiste et la gestion des erreurs. Cela devrait se déclencher pour des requêtes telles que Ajouter MongoDB au Spring Boot ; Examiner la conception Spring Data Mongo ; Améliorer la gestion des erreurs pour les écritures Mongo. Une partie du projet curseur-règles-java
