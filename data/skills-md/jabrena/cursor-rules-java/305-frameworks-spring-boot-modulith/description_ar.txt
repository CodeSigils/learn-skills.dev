استخدمه عندما تحتاج إلى تصميم وحدات متراصة معيارية أو مراجعتها أو تحسينها باستخدام Spring Modulith في تطبيقات Spring Boot - بما في ذلك بنية حزمة وحدة التطبيق، والتحقق من ApplicationModules، والواجهات المسماة، والتبعيات المسموح بها، وأحداث المجال، وApplicationModuleTest، واختبارات الوحدات المستندة إلى السيناريو، والوثائق التي تم إنشاؤها، وتعرض المشغل، وقابلية المراقبة، واختيارات تسجيل نشر الأحداث. يجب أن يؤدي هذا إلى تشغيل طلبات مثل Add Spring Modulith إلى تطبيق Spring Boot؛ مراجعة حدود وحدة Spring Modulith؛ تحسين البنية المتجانسة المعيارية في Spring Boot؛ إضافة اختباراتApplicationModuleTest؛ إنشاء وثائق Spring Modulith. جزء من مشروع cursor-rules-java
