À utiliser lorsque vous devez concevoir, réviser ou améliorer des monolithes modulaires avec Spring Modulith dans les applications Spring Boot - y compris la structure des packages de modules d'application, la vérification des ApplicationModules, les interfaces nommées, les dépendances autorisées, les événements de domaine, @ApplicationModuleTest, les tests de modules basés sur des scénarios, la documentation générée, l'exposition des actionneurs, l'observabilité et les choix de registre de publication d'événements. Cela devrait déclencher des requêtes telles que Ajouter Spring Modulith à une application Spring Boot ; Examinez les limites du module Spring Modulith ; Améliorer l'architecture monolithique modulaire dans Spring Boot ; Ajoutez des tests @ApplicationModuleTest ; Générez la documentation Spring Modulith. Une partie du projet curseur-règles-java
