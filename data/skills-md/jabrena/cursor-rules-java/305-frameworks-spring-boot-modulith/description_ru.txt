Используйте, когда вам нужно спроектировать, просмотреть или улучшить модульные монолиты с помощью Spring Modulith в приложениях Spring Boot, включая структуру пакета модуля приложения, проверку ApplicationModules, именованные интерфейсы, разрешенные зависимости, события домена, @ApplicationModuleTest, тесты модулей на основе сценариев, сгенерированную документацию, раскрытие исполнительных механизмов, наблюдаемость и выбор реестра публикации событий. Это должно срабатывать для таких запросов, как «Добавить Spring Modulith в приложение Spring Boot»; Обзор границ модуля Spring Modulith; Улучшение модульной монолитной архитектуры в Spring Boot; Добавьте тесты @ApplicationModuleTest; Создайте документацию Spring Modulith.
