À utiliser lorsque vous avez besoin de conseils SQL indépendants du framework (dénomination de schéma, conception de tables relationnelles, lisibilité des requêtes, index, transactions, sécurité des bases de données, migrations, tests et surveillance) sans choisir Spring Boot, Quarkus ou Micronaut. Cela devrait déclencher des demandes telles que Réviser le schéma SQL ou les migrations ; Améliorer les performances et la lisibilité des requêtes SQL ; Concevoir des tables et index relationnels ; Examinez les pratiques de transaction, de sécurité ou de surveillance de la base de données. Une partie du projet curseur-règles-java
