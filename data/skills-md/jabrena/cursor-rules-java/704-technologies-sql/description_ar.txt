استخدمه عندما تحتاج إلى إرشادات SQL غير محددة لإطار العمل - تسمية المخطط، وتصميم الجدول العلائقي، وإمكانية قراءة الاستعلام، والفهارس، والمعاملات، وأمان قاعدة البيانات، وعمليات الترحيل، والاختبار، والمراقبة - دون اختيار Spring Boot، أو Quarkus، أو Micronaut. يجب أن يؤدي ذلك إلى تشغيل طلبات مثل مراجعة مخطط SQL أو عمليات الترحيل؛ تحسين أداء استعلام SQL وسهولة القراءة؛ تصميم الجداول والفهارس العلائقية؛ مراجعة معاملات قاعدة البيانات أو الأمان أو ممارسات المراقبة. جزء من مشروع cursor-rules-java
