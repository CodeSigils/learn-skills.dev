Utilizzalo quando hai bisogno di una guida SQL indipendente dal framework (denominazione degli schemi, progettazione di tabelle relazionali, leggibilità delle query, indici, transazioni, sicurezza dei database, migrazioni, test e monitoraggio) senza scegliere Spring Boot, Quarkus o Micronaut. Ciò dovrebbe attivarsi per richieste come Revisione dello schema SQL o migrazioni; Migliorare le prestazioni e la leggibilità delle query SQL; Progettare tabelle e indici relazionali; Esaminare le transazioni, la sicurezza o le pratiche di monitoraggio del database. Parte del progetto cursor-rules-java
