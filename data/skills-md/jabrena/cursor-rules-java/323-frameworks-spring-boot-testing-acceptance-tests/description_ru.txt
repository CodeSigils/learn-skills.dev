Используйте, когда вам нужно реализовать приемочные тесты из файла .feature Gherkin для приложений Spring Boot, включая поиск сценариев с тегом @acceptance, реализацию тестов счастливого пути с помощью TestRestTemplate, @SpringBootTest, Testcontainers с @ServiceConnection для DB/Kafka и WireMock для внешних заглушек REST. Требуется файл .feature в контексте. Часть проекта «Навыки для Java»
