À utiliser lorsque vous devez implémenter des tests d'acceptation à partir d'un fichier Gherkin .feature pour les applications Spring Boot, notamment la recherche de scénarios marqués @acceptance, l'implémentation de tests de chemin heureux avec TestRestTemplate, @SpringBootTest, Testcontainers avec @ServiceConnection pour DB/Kafka et WireMock pour les stubs REST externes. Nécessite un fichier .feature en contexte. Une partie du projet skills-for-java
