Используйте, когда вам нужен доступ к данным с помощью Quarkus Hibernate ORM Panache, включая PanacheEntity/PanacheEntityBase, PanacheRepository, именованные запросы и запросы HQL, проекции DTO (project(Class)), нумерацию страниц (Page.of()), предотвращение N+1 (JOIN FETCH), оптимистическую блокировку (@Version/OptimisticLockException), @NamedQuery для проверенных повторно используемых запросов, транзакций, @TestTransaction для тестовая изоляция и неизменяемые шаблоны. Это аналог Quarkus Spring Data для реляционной персистентности. Часть проекта «Навыки для Java»
