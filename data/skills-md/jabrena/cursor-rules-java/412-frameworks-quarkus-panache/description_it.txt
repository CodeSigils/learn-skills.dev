Da utilizzare quando è necessario accedere ai dati con Quarkus Hibernate ORM Panache, inclusi PanacheEntity / PanacheEntityBase, PanacheRepository, query denominate e HQL, proiezioni DTO (progetto(Class)), impaginazione (Page.of()), evitamento N+1 (JOIN FETCH), blocco ottimistico (@Version / OptimisticLockException), @NamedQuery per query riutilizzabili convalidate, transazioni, @TestTransaction per l'isolamento dei test e modelli amichevoli immutabili. Questo è l'analogo di Quarkus a Spring Data per persistenza relazionale. Parte del progetto skills-for-java
