À utiliser lorsque vous avez besoin d'accéder aux données avec Quarkus Hibernate ORM Panache - y compris PanacheEntity / PanacheEntityBase, PanacheRepository, requêtes nommées et HQL, projections DTO (project(Class)), pagination (Page.of()), évitement N+1 (JOIN FETCH), verrouillage optimiste (@Version / OptimisticLockException), @NamedQuery pour les requêtes et transactions réutilisables validées, @TestTransaction pour l'isolation des tests et modèles immuables et conviviaux. Il s'agit de l'analogue Quarkus de Spring Data pour la persistance relationnelle. Une partie du projet skills-for-java
