Úselo cuando necesite acceso a datos con Quarkus Hibernate ORM Panache, incluidos PanacheEntity / PanacheEntityBase, PanacheRepository, consultas con nombre y HQL, proyecciones DTO (proyecto (clase)), paginación (Page.of()), evitación N+1 (JOIN FETCH), bloqueo optimista (@Version / OptimisticLockException), @NamedQuery para consultas y transacciones reutilizables validadas, @TestTransaction para aislamiento de pruebas y patrones amigables con inmutables. Este es el análogo de Quarkus a Spring Data para la persistencia relacional. Parte del proyecto skills-for-java
