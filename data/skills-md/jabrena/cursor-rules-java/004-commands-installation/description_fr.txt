À utiliser lorsque vous devez installer les commandes de projet intégrées dans des répertoires de commandes (.github/commands, .claude/commands, .cursor/command, .codex/commands), en sélectionnant la destination de manière interactive et en copiant les définitions de commandes intégrées à partir des actifs du projet.
