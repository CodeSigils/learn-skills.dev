À utiliser lorsque vous devez concevoir, réviser ou améliorer des API REST avec Quarkus REST (Jakarta REST) — y compris les classes de ressources, les méthodes HTTP, les codes d'état, les DTO de requête/réponse, la validation de bean, les mappeurs d'exceptions, OpenAPI avec SmallRye, la négociation de contenu, la pagination, le tri et le filtrage, la gestion des versions d'API, l'idempotence (Idempotency-Key), la concurrence optimiste (ETag / If-Match), la mise en cache HTTP. (Cache-Control), dépréciation de l'API (en-têtes Sunset / Deprecation), détails du problème RFC 7807, ISO-8601 pour la durée des contrats et limites de sécurité. Une partie du projet skills-for-java
