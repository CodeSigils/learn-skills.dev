Используйте, когда вам нужно спроектировать, просмотреть или улучшить API-интерфейсы REST с помощью Quarkus REST (Jakarta REST), включая классы ресурсов, методы HTTP, коды состояния, DTO запросов/ответов, проверку компонентов, средства отображения исключений, OpenAPI с SmallRye, согласование контента, нумерацию страниц, сортировку и фильтрацию, управление версиями API, идемпотентность (Idempotency-Key), оптимистический параллелизм (ETag / If-Match), HTTP-кэширование (Cache-Control), прекращение поддержки API (заголовки Sunset/Deprecation), RFC 7807 «Сведения о проблемах», ISO-8601 для времени в контрактах и границы, учитывающие безопасность.
