Facilita el descubrimiento conversacional para crear registros de decisiones arquitectónicas (ADR) para requisitos no funcionales utilizando el modelo de calidad ISO/IEC 25010:2023. Úselo cuando el usuario desee documentar atributos de calidad, decisiones NFR, arquitectura de seguridad/rendimiento/escalabilidad o sistemas de diseño con criterios de calidad mensurables. Parte del proyecto skills-for-java
