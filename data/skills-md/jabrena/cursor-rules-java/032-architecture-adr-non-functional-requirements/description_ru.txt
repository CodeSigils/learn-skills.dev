Облегчает диалоговое обнаружение для создания записей архитектурных решений (ADR) для нефункциональных требований с использованием модели качества ISO/IEC 25010:2023. Используйте, когда пользователь хочет документировать атрибуты качества, решения NFR, архитектуру безопасности/производительности/масштабируемости или проектировать системы с измеримыми критериями качества. Часть проекта «Навыки для Java»
