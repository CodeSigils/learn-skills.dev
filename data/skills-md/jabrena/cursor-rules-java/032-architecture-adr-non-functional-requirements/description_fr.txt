Facilite la découverte conversationnelle pour créer des enregistrements de décision architecturale (ADR) pour les exigences non fonctionnelles à l'aide du modèle de qualité ISO/IEC 25010:2023. À utiliser lorsque l'utilisateur souhaite documenter les attributs de qualité, les décisions NFR, l'architecture de sécurité/performance/évolutivité ou concevoir des systèmes avec des critères de qualité mesurables. Une partie du projet skills-for-java
