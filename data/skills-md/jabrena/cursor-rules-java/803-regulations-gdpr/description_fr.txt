À utiliser lors de l'examen, de la conception ou de la modification de systèmes d'entreprise Java qui traitent des données personnelles et nécessitent des contrôles techniques compatibles avec le RGPD. Cela devrait déclencher des demandes telles que Examiner un service Java pour les contrôles de confidentialité du RGPD ; Concevoir des flux de travail relatifs aux droits des personnes concernées ; Ajoutez la conservation, la suppression, la pseudonymisation ou la journalisation sécurisée ; Évaluez le transfert de données, la DPIA, les preuves de violation ou les problèmes de limites processeur/contrôleur avant la mise en production.
