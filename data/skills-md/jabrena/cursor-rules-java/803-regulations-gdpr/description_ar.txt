يُستخدم عند مراجعة أو تصميم أو تعديل أنظمة Java Enterprise التي تعالج البيانات الشخصية وتحتاج إلى ضوابط هندسية متوافقة مع القانون العام لحماية البيانات (GDPR). من المفترض أن يؤدي ذلك إلى تشغيل طلبات مثل مراجعة خدمة Java لضوابط خصوصية القانون العام لحماية البيانات؛ تصميم سير عمل حقوق موضوع البيانات؛ إضافة الاحتفاظ أو الحذف أو الاسم المستعار أو التسجيل الآمن للخصوصية؛ قم بتقييم نقل البيانات، أو حماية حماية البيانات (DPIA)، أو أدلة الانتهاك، أو المخاوف المتعلقة بحدود المعالج/وحدة التحكم قبل إصدار الإنتاج. جزء من مشروع cursor-rules-java
