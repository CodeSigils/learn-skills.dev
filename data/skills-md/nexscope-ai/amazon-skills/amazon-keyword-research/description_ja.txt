Amazon のキーワード調査と販売者向けの市場機会分析。オートコンプリートの提案 (ロングテール キーワード) を取得し、競合他社の状況を分析し、12 の Amazon マーケットプレイス (US/UK/DE/FR/IT/ES/JP/CA/AU/IN/MX/BR) であらゆるキーワードの市場機会を評価します。 API キーは必要ありません。ユーザーが Amazon 製品リサーチ、Amazon で販売する商品の検索、Amazon キーワードのアイデア、ニッチ分析、Amazon の競合分析、Amazon での市場機会、Amazon キーワードの比較、商品が販売する価値があるかどうかの評価、Amazon オートコンプリート データ、Amazon 製品の季節的需要、または Amazon で販売する商品のリサーチに関連するものについて言及するときは、たとえ「キーワード リサーチ」と明示的に言わなくても、必ずこのスキルを使用してください。また、ユーザーが「これは販売するのに良い商品ですか?」、「Amazon での X の競争はどうですか?」、「X と Y を売るべきですか?」、または「Amazon で何を検索していますか?」などの漠然とした質問をしたときにもトリガーされます。
