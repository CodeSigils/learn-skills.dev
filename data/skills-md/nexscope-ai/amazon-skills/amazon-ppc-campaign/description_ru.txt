Создатель и оптимизатор кампаний Amazon PPC для продавцов. Два режима: (A) Создание — создавайте полную структуру кампании с нуля с группировкой ключевых слов, расчетом ставок и списками минус-слов. (B) Оптимизация — аудит существующих кампаний с использованием отчетов по поисковым запросам, выявление возможностей воронки ключевых слов, расчет корректировок ставок и создание еженедельного плана действий. Интегрируется с Amazon-keyword-research для ввода ключевых слов. Ключ API не требуется. Используйте при: (1) настройке кампаний Amazon PPC для нового продукта, (2) аудите эффективности существующих кампаний и ACoS, (3) оптимизации ставок ключевых слов и минус-слов, (4) построении автоматических/ручных/точных структур кампаний, (5) анализе отчетов по поисковым запросам на предмет возможностей, (6) расчете безубыточного ACoS и целевого ACoS, (7) масштабировании прибыльных кампаний для спонсируемых брендов или медийной рекламы.
