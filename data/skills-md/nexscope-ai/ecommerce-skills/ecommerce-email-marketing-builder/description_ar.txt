منشئ نظام التسويق عبر البريد الإلكتروني للتجارة الإلكترونية. ينشئ تدفقات كاملة لأتمتة البريد الإلكتروني مع كتابة النصوص الكاملة وسطور الموضوع وتعليمات إعداد ESP وقواعد التجزئة وتقويمات الحملة السنوية. يُنشئ تسلسلات بريد إلكتروني جاهزة للنسخ واللصق لـ Klaviyo أو Omnisend أو Mailchimp أو أي ESP. يغطي سلسلة الترحيب، والتخلي عن سلة التسوق، والتخلي عن التصفح، والشراء اللاحق، وطلبات المراجعة، والبيع المتبادل، والربح الخلفي، وكبار الشخصيات/الولاء، والتجديد، وتدفقات غروب الشمس. يتضمن متغيرات سطر موضوع اختبار A/B، وتوقيت الإرسال، وشروط التشغيل، ومنطق التفرع، وتقويم الحملة الموسمية. لا يوجد مفتاح API مطلوب. يُستخدم عندما: (1) إعداد التسويق عبر البريد الإلكتروني لمتجر تجارة إلكترونية، (2) كتابة تسلسلات وتدفقات البريد الإلكتروني، (3) التخطيط لحملات البريد الإلكتروني الموسمية.
