Создает высококачественные навыки Claude Code и Cowork, используя научно обоснованные принципы: полезные данные экспертного словаря для маршрутизации знаний, описания с двойным регистром для надежного запуска, именованные списки наблюдения против шаблонов для обхода распределительного центра и прогрессивную архитектуру раскрытия для эффективности контекста. Создает файлы SKILL.md со структурированными инструкциями по поведению, каноническими примерами и связанными ссылками.

Используйте этот навык, когда пользователь хочет создать навык, создать пользовательскую возможность, создать многократно используемый шаблон подсказки или говорит: «Я хочу, чтобы Клод всегда делал X». Также срабатывает, когда планировщику миссий или создателю агента необходимо создать JIT предметного навыка. Работает для любого домена.

НЕ используйте для создания определений агентов (используйте Agent Creator) или состава команды (используйте Mission Planner).
