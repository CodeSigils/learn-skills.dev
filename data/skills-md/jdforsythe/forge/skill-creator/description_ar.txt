ينشئ مهارات Claude Code وCowork عالية الجودة باستخدام المبادئ القائمة على الأدلة: حمولات مفردات الخبراء لتوجيه المعرفة، وأوصاف التسجيل المزدوج للتشغيل الموثوق، وقوائم مراقبة مسماة مضادة للأنماط للتوجيه بعد مركز التوزيع، وبنية الكشف التدريجي لكفاءة السياق. يُنتج ملفات SKILL.md مع تعليمات سلوكية منظمة وأمثلة أساسية ومراجع مجمعة.

استخدم هذه المهارة عندما يريد المستخدم إنشاء مهارة، أو بناء قدرة مخصصة، أو إنشاء قالب مطالبة قابل لإعادة الاستخدام، أو عندما يقول "أريد من كلود أن يفعل X دائمًا." يتم تشغيله أيضًا عندما يحتاج مخطط المهمة أو منشئ الوكيل إلى إنشاء مهارة المجال JIT. يعمل لأي مجال.

لا تستخدم لإنشاء تعريفات الوكيل (استخدم Agent Creator) أو تكوين الفريق (استخدم Mission Planner).
