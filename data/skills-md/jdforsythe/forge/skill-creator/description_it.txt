Crea competenze di Claude Code e Cowork di alta qualità utilizzando principi basati sull'evidenza: carichi utili di vocabolario esperto per l'instradamento della conoscenza, descrizioni a doppio registro per un'attivazione affidabile, liste di controllo anti-pattern denominate per superare il centro di distribuzione e architettura di divulgazione progressiva per l'efficienza del contesto. Produce file SKILL.md con istruzioni comportamentali strutturate, esempi canonici e riferimenti in bundle.

Utilizza questa competenza quando l'utente desidera creare una competenza, sviluppare una funzionalità personalizzata, creare un modello di prompt riutilizzabile o dire "Voglio che Claude faccia sempre X." Si attiva anche quando Mission Planner o Agent Creator devono creare una competenza di dominio JIT. Funziona per qualsiasi dominio.

NON utilizzare per creare definizioni di agenti (utilizzare Agent Creator) o composizione del team (utilizzare Mission Planner).
