قم بإنشاء أو كتابة أو تشغيل استعلام مخصص مقابل بيانات إمكانية ملاحظة SigNoz - المقاييس أو السجلات أو التتبعات أو الاستثناءات - دون تغليفها في لوحة معلومات أو تنبيه. تأكد من استخدام هذه المهارة عندما يسأل المستخدم "أظهر لي معدلات الخطأ"، أو "سجلات الاستعلام عن أخطاء المهلة"، أو "ما هو زمن الوصول p99 لخدمة سلة التسوق"، أو "عدد الطلبات التي تصل إلى نقطة نهاية الدفع"، أو "العثور على آثار بطيئة"، أو "أخطاء في الساعة الأخيرة"، أو يسأل بطريقة أخرى سؤالًا استكشافيًا يحتاج إلى بيانات إمكانية المراقبة المباشرة - حتى لو لم يذكر "استعلام" أو "بحث" بشكل صريح.
