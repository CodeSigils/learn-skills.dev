تعديل لوحة معلومات SigNoz موجودة - إضافة اللوحات أو إزالتها، أو تحرير استعلام اللوحة أو حدها أو وحدتها، أو إعادة تسمية لوحة المعلومات، أو تغيير نوع اللوحة (الرسم البياني ↔ الجدول ↔ القيمة)، أو إعادة ترتيب التخطيط، أو إضافة أو تحرير المتغيرات، أو تحديث العلامات. تأكد من استخدام هذه المهارة عندما يقول المستخدم "إضافة لوحة إلى لوحة المعلومات الخاصة بي"، أو "تغيير الاستعلام في هذه اللوحة"، أو "إزالة أداة زمن الاستجابة"، أو "إعادة تسمية لوحة المعلومات"، أو "تحديث عوامل التصفية"، أو "إعادة ترتيب التخطيط"، أو "إضافة متغير"، أو "تغيير نوع اللوحة من رسم بياني إلى جدول"، أو يطلب بخلاف ذلك تغيير شيء ما في لوحة معلومات موجودة بالفعل - حتى إذا لم يذكر "تعديل" أو "تحرير" بشكل صريح.
