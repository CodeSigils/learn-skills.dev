Ändern Sie ein vorhandenes SigNoz-Dashboard – fügen Sie Panels hinzu oder entfernen Sie sie, bearbeiten Sie die Abfrage, den Schwellenwert oder die Einheit eines Panels, benennen Sie das Dashboard um, ändern Sie einen Paneltyp (Grafik ↔ Tabelle ↔ Wert), ordnen Sie das Layout neu an, fügen Sie Variablen hinzu oder bearbeiten Sie sie oder aktualisieren Sie Tags. Stellen Sie sicher, dass Sie diesen Skill verwenden, wenn der Benutzer sagt: „Ein Panel zu meinem Dashboard hinzufügen“, „Abfrage in diesem Panel ändern“, „Latenz-Widget entfernen“, „Mein Dashboard umbenennen“, „Filter aktualisieren“, „Layout neu anordnen“, „Variable hinzufügen“, „Panel-Typ von Diagramm zu Tabelle ändern“ oder auf andere Weise dazu auffordert, etwas an einem bereits vorhandenen Dashboard zu ändern – auch wenn er nicht explizit „Ändern“ oder „Bearbeiten“ sagt.
