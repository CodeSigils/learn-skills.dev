Напишите необработанный SQL-код ClickHouse для панели управления SigNoz — виджеты временных рядов, значений или таблиц, которые пользовательский интерфейс компоновщика не может выразить (пользовательские соединения, оконные функции, извлечение регулярных выражений из тел журналов, агрегаты за пределами синтаксиса компоновщика). Запускается, когда пользователь явно запрашивает «запрос ClickHouse», «необработанную панель SQL», «пользовательский виджет SQL» или описывает панель панели управления SigNoz, для запроса которой требуется SQL, который разработчик не может создать. Специально привязан к SQL панели мониторинга. Для специального исследования данных, которое не обязательно должно отображаться на панели, используйте вместо этого «signoz-generating-queries».
