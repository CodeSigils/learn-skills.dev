اكتب ClickHouse SQL أوليًا للوحة معلومات SigNoz - سلاسل زمنية أو قيمة أو عناصر واجهة مستخدم للجدول لا يمكن لواجهة مستخدم المنشئ التعبير عنها (الصلات المخصصة، ووظائف النوافذ، واستخراج التعبير العادي على أجسام السجل، والتجمعات التي تتجاوز بناء جملة المنشئ). يتم تشغيله عندما يطلب المستخدم صراحةً "استعلام ClickHouse"، أو "لوحة SQL أولية"، أو "عنصر واجهة مستخدم SQL مخصص"، أو يصف لوحة معلومات SigNoz التي يحتاج استعلامها إلى SQL ولا يستطيع المنشئ إنتاجها. ترتكز على لوحة المعلومات SQL على وجه التحديد. لاستكشاف البيانات المخصصة التي لا تحتاج إلى الوصول إلى لوحة، استخدم "signoz-genering-queries" بدلاً من ذلك.
