SigNoz ダッシュボード パネル用の生の ClickHouse SQL を作成します。ビルダー UI では表現できない時系列、値、またはテーブル ウィジェット (カスタム結合、ウィンドウ関数、ログ本体に対する正規表現抽出、ビルダー構文を超えた集計)。ユーザーが「ClickHouse クエリ」、「生 SQL パネル」、「カスタム SQL ウィジェット」を明示的に要求したとき、またはクエリにビルダーが生成できない SQL を必要とする SigNoz ダッシュボード パネルを説明したときにトリガーされます。特にダッシュボード パネルの SQL に固定されています。パネルに到達する必要のないアドホックなデータ探索の場合は、代わりに「signoz-generate-queries」を使用してください。
