Écrivez du SQL ClickHouse brut pour un panneau de tableau de bord SigNoz : des séries temporelles, des valeurs ou des widgets de table que l'interface utilisateur du générateur ne peut pas exprimer (jointures personnalisées, fonctions de fenêtre, extraction d'expressions régulières sur les corps de journaux, agrégations au-delà de la syntaxe du générateur). Déclenchez lorsque l'utilisateur demande explicitement une « requête ClickHouse », un « panneau SQL brut », un « widget SQL personnalisé » ou décrit un panneau de tableau de bord SigNoz dont la requête nécessite du SQL que le constructeur ne peut pas produire. Ancré spécifiquement au SQL du panneau de tableau de bord. Pour une exploration de données ad hoc qui n'a pas besoin d'atterrir dans un panneau, utilisez plutôt « signoz-generating-queries ».
