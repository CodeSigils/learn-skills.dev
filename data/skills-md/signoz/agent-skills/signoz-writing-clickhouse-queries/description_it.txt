Scrivi SQL ClickHouse non elaborato per un pannello dashboard SigNoz: serie temporali, valori o widget di tabelle che l'interfaccia utente del builder non è in grado di esprimere (join personalizzati, funzioni finestra, estrazione regex sui corpi dei log, aggregazioni oltre la sintassi del builder). Si attiva quando l'utente richiede esplicitamente una "query ClickHouse", un "pannello SQL grezzo", un "widget SQL personalizzato" o descrive un pannello dashboard SigNoz la cui query richiede SQL che il costruttore non può produrre. Ancorato specificamente all'SQL del pannello dashboard. Per l'esplorazione dei dati ad hoc che non necessita di finire in un pannello, utilizza invece `signoz-generating-queries`.
