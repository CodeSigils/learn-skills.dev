Escriba SQL sin formato de ClickHouse para un panel de control de SigNoz: widgets de series temporales, valores o tablas que la interfaz de usuario del constructor no puede expresar (uniones personalizadas, funciones de ventana, extracción de expresiones regulares sobre cuerpos de registro, agregaciones más allá de la sintaxis del constructor). Se activa cuando el usuario solicita explícitamente una "consulta de ClickHouse", un "panel de SQL sin formato", un "widget de SQL personalizado" o describe un panel de panel de SigNoz cuya consulta necesita SQL que el constructor no puede producir. Anclado específicamente al SQL del panel de control. Para la exploración de datos ad hoc que no necesita aterrizar en un panel, utilice "consultas generadoras de signos" en su lugar.
