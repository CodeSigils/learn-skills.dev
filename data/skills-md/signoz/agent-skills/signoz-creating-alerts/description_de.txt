Erstellen Sie eine neue SigNoz-Warnungsregel aus einer Absicht in natürlicher Sprache – Schwellenwert-, Anomalie-, Protokollvolumen-, Fehlerraten-, Latenz- oder fehlende Datenwarnungen für Metriken, Protokolle, Ablaufverfolgungen und Ausnahmen. Stellen Sie sicher, dass Sie diesen Skill immer verwenden, wenn der Benutzer „Benachrichtigen Sie mich, wenn…“, „Benachrichtigen Sie mich, wenn…“, „Überwachung einrichten für…“, „Page mich auf…“, „Alarm erstellen für…“ sagt oder nach einer neuen Alarm-/Benachrichtigungsregel fragt, auch wenn er das Wort „Alarm“ nicht explizit sagt. Verwenden Sie es auch, wenn jemand darum bittet, über Fehlerraten, Latenzspitzen, Protokollvolumen, CPU-/Speicherauslastung oder anomales Verhalten bei einem Dienst oder Host benachrichtigt zu werden.
