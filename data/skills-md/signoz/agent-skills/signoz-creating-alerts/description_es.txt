Cree una nueva regla de alerta SigNoz a partir de una intención de lenguaje natural: umbral, anomalía, volumen de registro, tasa de error, latencia o alertas de datos ausentes en métricas, registros, seguimientos y excepciones. Asegúrese de usar esta habilidad cada vez que el usuario diga "avisarme cuando...", "notificarme si...", "configurar el monitoreo para...", "localizarme en...", "crear una alerta para..." o solicite una nueva regla de alerta/notificación, incluso si no dice la palabra "alerta" explícitamente. Úselo también cuando alguien solicite que se le notifique sobre tasas de error, picos de latencia, volumen de registros, presión de CPU/memoria o comportamiento anómalo en un servicio o host.
