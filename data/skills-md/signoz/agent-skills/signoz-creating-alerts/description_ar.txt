قم بإنشاء قاعدة تنبيه SigNoz جديدة من غرض اللغة الطبيعية - تنبيهات العتبة أو الشذوذ أو حجم السجل أو معدل الخطأ أو زمن الاستجابة أو تنبيهات غياب البيانات عبر المقاييس والسجلات والتتبعات والاستثناءات. تأكد من استخدام هذه المهارة عندما يقول المستخدم "نبهني عندما..." أو "أعلمني إذا..." أو "قم بإعداد المراقبة لـ..." أو "أضفني على..." أو "أنشئ تنبيهًا لـ..." أو يطلب قاعدة تنبيه/إشعار جديدة، حتى لو لم ينطق كلمة "تنبيه" صراحة. استخدمه أيضًا عندما يطلب شخص ما أن يتم إعلامه بمعدلات الخطأ، أو ارتفاع زمن الاستجابة، أو حجم السجل، أو ضغط وحدة المعالجة المركزية/الذاكرة، أو السلوك غير الطبيعي على خدمة أو مضيف.
