Assicurati di utilizzare questa competenza ogni volta che l'utente dice "crea un dashboard per...", "imposta il monitoraggio per...", "creami un dashboard...", "Ho bisogno di osservabilità per...", "importa un modello di dashboard" o chiede di monitorare/visualizzare un servizio, un database, un cluster o una piattaforma AI/LLM, anche se non dice esplicitamente "dashboard". Usalo anche quando qualcuno vuole "monitorare", "guardare" o "vedere le metriche per" una tecnologia e la risposta naturale è un dashboard.
