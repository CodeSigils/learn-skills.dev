Erstellen Sie ein neues SigNoz-Dashboard aus einer Absicht in natürlicher Sprache – importieren Sie eine kuratierte Vorlage (PostgreSQL, Redis, JVM, k8s, Hostmetrics, APM, LLM usw.), wenn es passt, oder erstellen Sie ein benutzerdefiniertes Dashboard von Grund auf mit Metrik-/Trace-/Log-Panels. Stellen Sie sicher, dass Sie diese Fähigkeit verwenden, wenn der Benutzer sagt: „Dashboard erstellen für…“, „Überwachung einrichten für…“, „Erstelle mir ein Dashboard…“, „Ich benötige Beobachtbarkeit für…“, „Dashboard-Vorlage importieren“ oder einen Dienst, eine Datenbank, einen Cluster oder eine AI/LLM-Plattform verfolgen/visualisieren möchte – auch wenn er nicht ausdrücklich „Dashboard“ sagt. Verwenden Sie es auch, wenn jemand eine Technologie „überwachen“, „beobachten“ oder „Metriken für sie sehen“ möchte und die natürliche Antwort ein Dashboard ist.
