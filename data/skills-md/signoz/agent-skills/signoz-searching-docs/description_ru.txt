Информацию ищите в документации SigNoz. Обязательно используйте этот навык всякий раз, когда пользователь спрашивает «как мне сделать», «где в документации», «о чем говорят документы», «найти документы» или иным образом нуждается в справочном материале по инструментам SigNoz, настройке OpenTelemetry, самостоятельному развертыванию, конечным точкам API, заголовкам аутентификации или шагам по устранению неполадок — даже если он не произносит слово «документы» явно. Только поиск в документах — для действий внутри SigNoz агент выберет соответствующий навык действия `signoz-*`.
