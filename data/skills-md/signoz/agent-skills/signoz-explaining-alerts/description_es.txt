Describa lo que hace una regla de alerta SigNoz existente en lenguaje sencillo: la señal que observa, el umbral y el comportamiento de evaluación, el enrutamiento de notificaciones y un resumen de una línea de frecuencia de incendio para que el usuario sepa si la alerta ha estado activa. Asegúrese de utilizar esta habilidad siempre que el usuario pregunte "¿qué hace esta alerta?", "explica la alerta X", "guíeme a través de esta regla", "cómo funciona mi alerta [Y]", "esta alerta está configurada correctamente" o solicita una interpretación de la configuración de una alerta existente. Solo explicación estática: para diagnosticar un incidente de disparo específico, utilice "signoz-investigating-alerts".
