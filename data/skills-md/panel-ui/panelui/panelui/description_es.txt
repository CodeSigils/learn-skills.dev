Cree interfaces de usuario de React Native y Expo con PanelUI: agregue componentes, temas, componga superposiciones y formularios, y depure por qué algo no tiene estilo. Se aplica cuando se trabaja en un proyecto Expo o React Native que tiene panelui-native instalado o panelui.json, cuando el usuario menciona PanelUI o cuando solicita una hoja inferior, un cuadro de diálogo, un gráfico, una transcripción de chat, un formulario o cualquier otra interfaz de usuario de pantalla en React Native.
