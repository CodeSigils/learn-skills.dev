بناء واجهات مستخدم React Native و Expo باستخدام PanelUI — إضافة المكونات، وتطبيق السمات، وتكوين الطبقات الفوقية والنماذج، وتصحيح الأخطاء عندما يكون شيء غير منسق. يُطبق ذلك عند العمل في مشروع Expo أو React Native يحتوي على panelui-native مثبت أو ملف panelui.json، عندما يذكر المستخدم PanelUI، أو عندما يطلب ورقة سفلية، أو حوارًا، أو مخططًا، أو نص محادثة، أو نموذجًا أو أي واجهة شاشة أخرى في React Native.
