أنشئ واجهات مستخدم React Native وExpo باستخدام PanelUI - مع إضافة المكونات والسمات وتأليف التراكبات والنماذج وتصحيح الأخطاء التي تجعل شيئًا ما غير مرتب. ينطبق عند العمل في مشروع Expo أو React Native المثبت عليه Panelui-native أو Panelui.json، عندما يذكر المستخدم PanelUI، أو عندما يطلب ورقة سفلية أو مربع حوار أو مخطط أو نص محادثة أو نموذج أو أي واجهة مستخدم شاشة أخرى في React Native.
