Gérez les opérations de l'API eSIM Access, notamment les vérifications de solde, la liste des packages, la création de commandes, la surveillance du statut eSIM, les recharges, les annulations, la gestion des profils, les webhooks et les workflows de remboursement/réémission. À utiliser lorsque l'utilisateur mentionne eSIM, ICCID, forfait de données, itinérance, carte SIM, forfait de données mobiles, connectivité de voyage, utilisation des données cellulaires ou interagit avec l'API d'accès eSIM sur api.esimaccess.com. Se déclenche également lorsque l'utilisateur pose des questions sur le solde, la recharge, l'état de la commande, l'approvisionnement du code QR ou télécharge une liste d'ICCID ou de numéros de commande.
