Управляйте операциями API доступа к eSIM, включая проверки баланса, список пакетов, создание заказов, мониторинг статуса eSIM, пополнения, отмены, управление профилями, веб-перехватчики и рабочие процессы возврата/перевыпуска. Используйте, когда пользователь упоминает eSIM, ICCID, тарифный план, роуминг, SIM-карту, пакет мобильных данных, возможность подключения к путешествиям, использование сотовых данных или взаимодействует с API доступа к eSIM на сайте api.esimaccess.com. Также срабатывает, когда пользователь спрашивает о балансе, пополнении счета, статусе заказа, предоставлении QR-кода или загружает список ICCID или номеров заказов.
