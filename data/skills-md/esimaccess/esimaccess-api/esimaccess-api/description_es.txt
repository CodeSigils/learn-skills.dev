Administre las operaciones de la API de acceso a eSIM, incluidas verificaciones de saldo, listado de paquetes, creación de pedidos, monitoreo del estado de eSIM, recargas, cancelaciones, administración de perfiles, webhooks y flujos de trabajo de reembolso/reemisión. Úselo cuando el usuario mencione eSIM, ICCID, plan de datos, roaming, tarjeta SIM, paquete de datos móviles, conectividad de viajes, uso de datos móviles o interactúe con la API de acceso eSIM en api.esimaccess.com. También se activa cuando el usuario pregunta sobre el saldo, la recarga, el estado del pedido, el aprovisionamiento de códigos QR o carga una lista de ICCID o números de pedido.
