Gestisci le operazioni API di accesso eSIM, inclusi controlli del saldo, elenco dei pacchetti, creazione di ordini, monitoraggio dello stato dell'eSIM, ricariche, cancellazioni, gestione dei profili, webhook e flussi di lavoro di rimborso/riemissione. Da utilizzare quando l'utente menziona eSIM, ICCID, piano dati, roaming, scheda SIM, pacchetto dati mobile, connettività di viaggio, utilizzo dei dati cellulare o interagisce con l'API di accesso eSIM su api.esimaccess.com. Si attiva anche quando l'utente chiede informazioni sul saldo, sulla ricarica, sullo stato dell'ordine, sulla fornitura del codice QR o carica un elenco di ICCID o numeri di ordine.
