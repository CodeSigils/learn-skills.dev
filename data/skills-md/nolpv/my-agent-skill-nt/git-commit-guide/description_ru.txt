Используйте этот навык при фиксации кода, написании сообщений о фиксации или просмотре истории git в этом проекте Next.js. Запускается по: «зафиксировать это», «написать сообщение о фиксации», «что должен сказать мой коммит», «git commit» или любой запрос на подготовку и фиксацию изменений. Предоставляет традиционный формат фиксации для конкретного проекта, соглашения о комментариях на тайском языке и правила области, соответствующие структуре этой кодовой базы.
