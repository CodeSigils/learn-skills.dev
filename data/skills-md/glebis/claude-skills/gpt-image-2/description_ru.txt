Создавайте и редактируйте изображения с помощью API OpenAI GPT Image 2. Интерактивный навык, который помогает пользователям создавать изображения с помощью предустановок стилей, экономичного чернового/окончательного рабочего процесса, режима мышления, каруселей и редактирования фотографий. Этот навык следует использовать, когда пользователь запрашивает создание изображений с помощью OpenAI/GPT Image 2, хочет создавать карусели в социальных сетях, редактировать фотографии в художественных стилях или нуждается в изображениях с читаемым текстом (инфографика, диаграммы, плакаты).
