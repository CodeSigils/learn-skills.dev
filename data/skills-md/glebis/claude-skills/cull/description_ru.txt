Используйте, когда пользователь хочет просмотреть, просмотреть, оценить, систематизировать, найти или экспортировать изображения/генерации AI-искусства с помощью приложения Cull (https://cull.company/ · https://github.com/glebis/cull). Триггер «покажи мне эти изображения», «проверь эту партию», «открой их в Cull», «оцени / внеси в список / собери эти», «найди похожие изображения», «составь умную коллекцию», «проведи проверку качества», «экспортируй хранителей», «опубликуй эту коллекцию». По умолчанию работает через CLI `cull` (MCP не требуется); инструменты `mcp__cull__*` не являются обязательными для более широкого интерактивного управления.
