À utiliser lorsque l'utilisateur souhaite afficher, réviser, noter, organiser, rechercher ou exporter des images/générations d'art IA avec l'application Cull (https://cull.company/ · https://github.com/glebis/cull). Déclenchez sur "montrez-moi ces images", "examinez ce lot", "ouvrez-les dans Cull", "évaluez/présélectionnez/collectez-les", "trouver des images similaires", "créer une collection intelligente", "exécuter un test de qualité", "exporter les gardiens", "publier cette collection". Fonctionne via la CLI `cull` par défaut (aucun MCP requis) ; les outils `mcp__cull__*` sont facultatifs pour un contrôle interactif plus riche.
