أتمتة getSorted.de (مرتبة) لإعداد فواتير المستقلين، وتتبع النفقات، وتقديم الضرائب الألمانية (ضريبة القيمة المضافة، ZM، والعائدات السنوية). يستخدم أتمتة المتصفح الحقيقي عبر متصفح Chrome Beta + Agent. يتم تفعيلها عند "إنشاء فاتورة"، أو "فاتورة مرتبة"، أو "تنزيل الفاتورة"، أو "إرسال ضريبة القيمة المضافة"، أو "تقرير الضريبة"، أو "النفقات المصنفة"، أو "/ مصنفة"، أو أي تفاعل مع getSorted.de.
