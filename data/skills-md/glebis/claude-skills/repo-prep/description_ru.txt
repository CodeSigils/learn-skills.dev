Используйте при настройке нового репозитория для выпуска, добавлении недостающих юридических/мета-файлов/файлов сообщества, написании записи АВТОРСТВА для работы с помощью ИИ или при запросе «подготовьте этот репозиторий для GitHub/открытого исходного кода».
