公開用のコード リポジトリをインタラクティブに準備します — ライセンス、通知、権限、README セクション、パッケージ メタデータ、.gitignore、コミュニティ ドキュメント (CONTRIBUTING/CODE_OF_CONDUCT/SECURITY/CHANGELOG)、.github テンプレート (issues/PR/CI/dependabot)、プロモーションの「作者からの詳細」ブロック、および条件付き EU/ドイツ法コンプライアンス (CRA、AI 法、GDPR、インプレスム、製造物責任)。人間の決定、判断、方向性、アートディレクションを管轄区域を意識した法的枠組みで文書化する専用の著者権限ウィザードが含まれています。リリース用に新しいリポジトリを設定する場合、不足しているリーガル/メタ/コミュニティ ファイルを追加する場合、AI 支援作業用の AUTHORSHIP レコードを書き込む場合、または「このリポジトリを GitHub / オープンソース用に準備してください」と依頼する場合に使用します。
