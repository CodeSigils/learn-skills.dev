Esta habilidad debe usarse para investigaciones de estilo eliminatorio donde el usuario desea elegir de una lista corta de productos, herramientas, servicios, proveedores u otras opciones utilizando criterios explícitos, evidencia numérica, comparación de estilo de torneo, clasificación de fuente/dominio, informes de consumidores respaldados por imágenes, tablas de datos sin procesar y estimaciones de costos de propiedad para piezas reemplazables. Utilice esta habilidad siempre que el usuario solicite comparar opciones, comprar algo, preseleccionar candidatos, clasificar alternativas, generar un informe "No me hagas pensar" o producir un informe de auditoría completo con datos numéricos sin procesar.
