Трехуровневая анонимизация личных данных для стенограмм сеансов (терапия, коучинг, консультирование, наставничество). Последовательно запускает Наташу (российский NER), OpenAI Privacy Filter и локальный LLM (Ollama) для максимального охвата. По умолчанию полностью локальный. Этот навык следует использовать при анонимизации стенограмм сеансов, заметок или любого текста, содержащего личную информацию клиента, перед анализом ИИ. Триггеры «анонимизировать», «удалить PII», «анонимизировать сеанс», «защитить данные клиента», «удалить личные данные», «анонимизировать стенограмму».
