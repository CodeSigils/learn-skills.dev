Recherchieren, bewerten und veröffentlichen Sie einen wöchentlichen Branchenüberblick zu jedem Thema. Wirft über eine Websuche ein weites Netz aus (mehr als 20 Kandidaten), überprüft Quellen auf KI-generierten Slop, bewertet jedes Element anhand von fünf Parametern (Neuheit, Relevanz, Schlamperei, technische Tiefe, Machbarkeit), wählt die Top-Elemente aus und generiert sowohl Markdown-Dateien als auch einen HTML-Bericht im Tufte-Stil. Verwenden Sie diesen Skill immer dann, wenn der Benutzer „/weekly-digest“, „wöchentliche Zusammenfassung ausführen“, „Branchenübersicht“, „Was gibt es Neues in [Thema]“, „wöchentliche Zusammenfassung“, „Nachrichtenübersicht zu [Thema]“, „Untersuchen Sie, was diese Woche in [Thema] passiert ist“ oder eine Anfrage zum Erstellen einer kuratierten, bewerteten Zusammenfassung der jüngsten Entwicklungen in einem Bereich sagt. Verwenden Sie es auch, wenn der Benutzer einen Themenbereich mit Qualitätsfilterung überwachen möchte – die Slopiness-Bewertung ist das wichtigste Unterscheidungsmerkmal zu einer einfachen Nachrichtensuche.
