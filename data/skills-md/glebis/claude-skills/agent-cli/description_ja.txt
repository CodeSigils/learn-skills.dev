エージェントフレンドリーな --json NDJSON 出力を Python CLI スクリプトに追加するか、プロジェクトの完全な cli_utils パッケージをスキャフォールディングします。このスキルは、ユーザーが AI エージェント用にスクリプトを機械読み取り可能にする、--json フラグを追加する、print ステートメントを構造化 JSON に変換する、CLI ヘルパー ライブラリを構築する、オープンソースのエージェント用 CLI パッケージを作成する、構造化ログを追加する、または CLI 出力を機械読み取り可能にする場合に使用します。ユーザーが NDJSON、構造化 CLI 出力、エージェント対応 CLI、非対話型スクリプト、または自動化のための JSON I/O について言及する場合にも使用します。
