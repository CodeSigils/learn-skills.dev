Agregue salida --json NDJSON compatible con agentes a los scripts CLI de Python o cree un paquete cli_utils completo para un proyecto. Utilice esta habilidad cuando el usuario quiera hacer que los scripts sean legibles por máquina para los agentes de IA, agregar indicadores --json, convertir declaraciones de impresión a JSON estructurado, crear una biblioteca auxiliar CLI, crear un paquete CLI de código abierto para agentes, agregar registros estructurados o hacer que la salida CLI sea legible por máquina. Utilícelo también cuando el usuario mencione NDJSON, salida CLI estructurada, CLI compatible con agentes, scripts no interactivos o JSON I/O para automatización.
