أضف مخرجات --json NDJSON سهلة الاستخدام للوكيل إلى نصوص Python CLI النصية، أو قم بدعم حزمة cli_utils كاملة لمشروع. استخدم هذه المهارة عندما يريد المستخدم جعل البرامج النصية قابلة للقراءة آليًا لوكلاء الذكاء الاصطناعي، أو إضافة علامات --json، أو تحويل بيانات الطباعة إلى JSON منظم، أو إنشاء مكتبة مساعد CLI، أو إنشاء حزمة CLI مفتوحة المصدر للوكلاء، أو إضافة تسجيل منظم، أو جعل مخرجات CLI قابلة للقراءة آليًا. يُستخدم أيضًا عندما يذكر المستخدم NDJSON، أو مخرجات CLI المنظمة، أو CLI الصديقة للوكيل، أو البرامج النصية غير التفاعلية، أو JSON I/O للأتمتة.
