Fügen Sie die agentenfreundliche --json NDJSON-Ausgabe zu Python-CLI-Skripten hinzu oder erstellen Sie ein Gerüst für ein vollständiges cli_utils-Paket für ein Projekt. Verwenden Sie diese Fähigkeit, wenn der Benutzer Skripte für KI-Agenten maschinenlesbar machen, --json-Flags hinzufügen, Druckanweisungen in strukturiertes JSON konvertieren, eine CLI-Hilfsbibliothek erstellen, ein Open-Source-CLI-für-Agenten-Paket erstellen, strukturierte Protokollierung hinzufügen oder die CLI-Ausgabe maschinenlesbar machen möchte. Verwenden Sie es auch, wenn der Benutzer NDJSON, strukturierte CLI-Ausgabe, agentenfreundliche CLI, nicht interaktive Skripte oder JSON-E/A zur Automatisierung erwähnt.
