Questa competenza deve essere utilizzata quando si pubblica una competenza nuova o aggiornata sul sito web Astro di claude-skills-site. Utilizza questa competenza sia per aggiungere nuove competenze sia per aggiornare quelle esistenti sul sito. Si attiva su "/pubblica-nome competenza", "aggiungi competenza al sito", "pubblica nome competenza sul sito delle competenze", "aggiorna competenza sul sito", "modifica competenza sul sito", "sincronizza competenza sul sito", "ripubblica competenza". Legge SKILL.md dal repository delle competenze, genera frontmatter e corpo MDX, seleziona il bundle corretto, aggiorna l'array delle competenze del bundle ed esegue il commit/invio di entrambi i repository. Per le competenze esistenti, passa --update per preservare apothecary_name, hero_image e i dati delle attività rigenerando il resto.
