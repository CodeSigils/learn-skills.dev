Dieser Skill sollte verwendet werden, wenn ein neuer oder aktualisierter Skill auf der Astro-Website claude-skills-site veröffentlicht wird. Verwenden Sie diesen Skill sowohl zum Hinzufügen neuer Skills als auch zum Aktualisieren vorhandener Skills auf der Website. Löst aus bei „/publish-skill Skillname“, „Skill zur Site hinzufügen“, „Skillname auf der Skills-Site veröffentlichen“, „Skill auf der Site aktualisieren“, „Skill auf der Site bearbeiten“, „Skill mit der Site synchronisieren“, „Skill erneut veröffentlichen“. Liest SKILL.md aus dem Skills-Repo, generiert MDX-Frontmatter und -Body, wählt das richtige Bundle aus, aktualisiert das Bundle-Skills-Array und schreibt/pusht beide Repos. Übergeben Sie für vorhandene Fertigkeiten --update, um apothecary_name, hero_image und Aktivitätsdaten beizubehalten, während der Rest neu generiert wird.
