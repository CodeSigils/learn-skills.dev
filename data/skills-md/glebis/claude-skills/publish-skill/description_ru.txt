Этот навык следует использовать при публикации нового или обновленного навыка на веб-сайте Claude-skills-site Astro. Используйте этот навык как для добавления новых навыков, так и для обновления существующих на сайте. Запускается по «/publish-skill namename», «добавить навык на сайт», «опубликовать имя навыка на сайте навыков», «обновить навык на сайте», «изменить навык на сайте», «синхронизировать навык с сайтом», «повторно опубликовать навык». Считывает SKILL.md из репозитория навыков, генерирует заголовок и тело MDX, выбирает правильный пакет, обновляет массив навыков пакета и фиксирует/отправляет оба репозитория. Для существующих навыков передайте --update, чтобы сохранить имя_аптекаря, изображение героя и данные о действиях, одновременно восстанавливая остальные.
