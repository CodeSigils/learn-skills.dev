Erstellen Sie ein Gerüst für ein neues Tauri v2-Projekt mit den Cenno/Cull-House-Konventionen – delegieren Sie das Boilerplate an „npm create tauri-app“ und überlagern Sie dann einen eigenwilligen Kern plus Opt-in-Module (CLI+MCP, SQLite, Tray/Updater, Release/Preflight, Swift Sidecar). Verwenden Sie diese Option, wenn der Benutzer eine neue Tauri-Desktop-App starten, „ein Tauri-Projekt initiieren“ oder „eine Tauri-App aufbauen“ möchte.
