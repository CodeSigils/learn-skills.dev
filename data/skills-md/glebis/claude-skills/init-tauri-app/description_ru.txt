Создайте новый проект Tauri v2 с соглашениями cenno/cull house — делегируйте шаблон в `npm create tauri-app`, затем наслаивайте самостоятельную основу и дополнительные модули (CLI+MCP, SQLite, лоток/обновление, выпуск/предварительная проверка, вспомогательный модуль Swift). Используйте, когда пользователь хочет запустить новое настольное приложение Tauri, «инициализировать проект Tauri» или «сформировать приложение Tauri».
