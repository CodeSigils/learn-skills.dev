Armar un nuevo proyecto Tauri v2 con las convenciones de cenno/cull house: delega el texto estándar a `npm create tauri-app`, luego coloca en capas un núcleo obstinado más módulos opcionales (CLI+MCP, SQLite, bandeja/actualizador, lanzamiento/verificación previa, sidecar Swift). Úselo cuando el usuario desee iniciar una nueva aplicación de escritorio Tauri, "iniciar un proyecto tauri" o "desarrollar una aplicación tauri".
