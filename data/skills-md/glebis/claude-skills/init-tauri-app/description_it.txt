Impalca un nuovo progetto Tauri v2 con le convenzioni cenno/cull house: delega il boilerplate a `npm create tauri-app`, quindi sovrappone un nucleo supponente più moduli opt-in (CLI+MCP, SQLite, vassoio/aggiornamento, rilascio/preflight, sidecar Swift). Utilizzare quando l'utente desidera avviare una nuova app desktop Tauri, "init a tauri project" o "scaffold a tauri app".
