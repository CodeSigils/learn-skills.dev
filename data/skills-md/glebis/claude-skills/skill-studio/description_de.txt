Interviewgesteuertes Automatisierungsdesign-Tool. Diese Fertigkeit sollte verwendet werden, wenn der Benutzer eine neue Fertigkeit, einen neuen Agenten, eine neue Automatisierung, eine neue Verknüpfung oder einen anderen automatisierbaren Arbeitsablauf entwerfen möchte. Führt ein abdeckungsgesteuertes JTBD-Interview (Text oder Sprache) durch und exportiert dann eine einseitige Markdown-Spezifikation sowie eine SVG-Designkarte.
