Cree informes de datos y paneles infográficos inspirados en Tufte como archivos HTML independientes. Utiliza EB Garamond para texto, Monaspace Argon para números, Chart.js para gráficos interactivos y minigráficos SVG en línea. Produce informes con calidad de publicación con diseños narrativos y de datos de dos columnas, paneles de estado, animaciones de desplazamiento y soporte móvil responsivo. Utilice esta habilidad siempre que el usuario desee crear un informe de datos, un panel de actividad, una infografía, una página de análisis personal, una visualización de seguimiento de salud o cualquier documento que combine texto narrativo con gráficos y tablas interactivos.
