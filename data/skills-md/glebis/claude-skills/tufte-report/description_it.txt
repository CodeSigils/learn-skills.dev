Crea report di dati e dashboard infografiche ispirati a Tufte come file HTML autonomi. Utilizza EB Garamond per il testo, Monaspace Argon per i numeri, Chart.js per i grafici interattivi e sparkline SVG incorporati. Produce report di qualità editoriale con layout di dati e narrazione a 2 colonne, dashboard di stato, animazioni di scorrimento e supporto mobile reattivo. Utilizza questa competenza ogni volta che l'utente desidera creare un report di dati, un dashboard delle attività, un'infografica, una pagina di analisi personale, una visualizzazione del tracker della salute o qualsiasi documento che combini testo narrativo con grafici e tabelle interattive. Si attiva anche per "creare un report come Tufte", "creare un'infografica", "creare un dashboard", "visualizzare i miei dati" o richieste di splendidi documenti basati sui dati.
