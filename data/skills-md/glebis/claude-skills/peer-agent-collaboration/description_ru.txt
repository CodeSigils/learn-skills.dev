Используйте, когда пользователь хочет, чтобы Claude Code, Codex или другие ИИ-агенты по программированию/бизнесу работали вместе как одноранговые. Этот навык следует использовать всякий раз, когда пользователь упоминает координацию Claude Code и Codex, передачу функций агентов, многоагентные рабочие процессы, равенство, уважение, обратную связь между агентами, решение, какой агент должен руководить, или превращение рабочего процесса бизнеса/кода в двухагентную операционную модель.
