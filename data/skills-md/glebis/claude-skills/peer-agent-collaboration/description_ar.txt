يُستخدم عندما يريد المستخدم أن يعمل كلود كود، أو كوديكس، أو وكلاء أعمال/ترميز الذكاء الاصطناعي الآخرين معًا كأقران. يجب استخدام هذه المهارة عندما يذكر المستخدم تنسيق Claude Code وCodex، أو عمليات تسليم الوكلاء، أو سير العمل متعدد الوكلاء، أو التكافؤ، أو الاحترام، أو المقاومة بين الوكلاء، أو تحديد الوكيل الذي يجب أن يقود، أو تحويل سير عمل الأعمال/الكود إلى نموذج تشغيل ثنائي الوكيل.
