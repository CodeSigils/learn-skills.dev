Verwenden Sie diese Option, wenn der Benutzer möchte, dass Claude Code, Codex oder andere KI-Codierungs-/Geschäftsagenten als Peers zusammenarbeiten. Diese Fähigkeit sollte immer dann verwendet werden, wenn der Benutzer die Koordinierung von Claude Code und Codex, Agentenübergaben, Arbeitsabläufe mit mehreren Agenten, Parität, Respekt, Pushback zwischen Agenten, die Entscheidung, welcher Agent führen soll, oder die Umwandlung eines Geschäfts-/Code-Workflows in ein Betriebsmodell mit zwei Agenten erwähnt.
