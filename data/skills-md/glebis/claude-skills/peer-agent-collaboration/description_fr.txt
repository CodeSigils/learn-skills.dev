À utiliser lorsque l'utilisateur souhaite que Claude Code, Codex ou d'autres agents de codage/affaires d'IA travaillent ensemble en tant que pairs. Cette compétence doit être utilisée chaque fois que l'utilisateur mentionne la coordination de Claude Code et du Codex, les transferts d'agents, les flux de travail multi-agents, la parité, le respect, le refoulement entre les agents, la décision quel agent doit diriger ou la transformation d'un flux de travail métier/code en un modèle opérationnel à deux agents.
