Cette compétence doit être utilisée pour rechercher dans la base de connaissances locale du coffre-fort/markdown Obsidian par signification, et pas seulement par mots-clés, à l'aide du moteur qmd sur l'appareil (BM25 + vecteur + reclassement LLM). Se déclenche lorsque l'utilisateur demande « rechercher dans mon coffre-fort/mes notes », « trouver des notes sur X », « que disent mes notes sur Y », « ai-je quelque chose sur Z », « recherche sémantique dans ma base de connaissances » ou souhaite une récupération de concept/multilingue via démarque. Entièrement local : rien ne quitte la machine.
