Этот навык следует использовать для поиска в локальной базе знаний Obsidian Vault/Markdown по смыслу, а не только по ключевым словам, с использованием механизма qmd на устройстве (BM25 + вектор + переоценка LLM). Запускается, когда пользователь запрашивает «поиск в моем хранилище/заметках», «найти заметки о X», «что мои заметки говорят о Y», «есть ли у меня что-нибудь по Z», «семантический поиск в моей базе знаний» или хочет концептуального/межъязыкового поиска по уценке. Полностью локальный — ничего не покидает машину.
