Cette compétence doit être utilisée pour générer des transcriptions synthétiques de séances de coaching et de thérapie réalistes et cohérentes avec la personnalité pour les évaluations, les démonstrations et les données de formation. Il produit un dialogue coach/client (ou thérapeute/client) fictif mais crédible, fondé sur une modalité choisie (coaching ICF/GROW, CBT, travail partiel IFS, ACT/entretien de motivation) et exporté vers le style de transcription Fathom/Granola, dialogue simple, JSON structuré ou démarque Obsidian. Se déclenche sur des requêtes telles que « générer une session de coaching synthétique », « créer de fausses transcriptions de thérapie pour les évaluations », « créer des transcriptions de session de démonstration », « dialogue CBT synthétique », « transcription de coaching cohérente avec la personnalité », « données de test pour mon résumé de session » ou « appel de coaching simulé ».
