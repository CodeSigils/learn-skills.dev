Сеанс веб-исходного кода PHP и инструмент аудита безопасности файлов cookie. Обнаруживает фиксацию сеанса, небезопасные флаги файлов cookie, недостатки проверки JWT и риски запоминания входа в систему; содержит классификацию рисков, примеры подтверждения концепции и рекомендации по исправлению ситуации (без пропусков).
