Outil d'audit de sécurité de la configuration Web PHP. Identifie CORS, l'exposition aux erreurs, les commutateurs de débogage, les en-têtes de sécurité, les commutateurs d'exécution dangereux, etc., et fournit des recommandations de notation, d'analyse d'exploitabilité, de PoC et de remédiation (aucune omission autorisée).
