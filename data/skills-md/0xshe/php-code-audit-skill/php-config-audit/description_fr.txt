Outil d'audit de sécurité de la configuration Web PHP. Identifie CORS, l'exposition aux erreurs, les commutateurs de débogage, les en-têtes de sécurité, les commutateurs d'exécution dangereux, etc., et fournit une sortie graduée, une analyse d'exploitabilité, un PoC et des recommandations de correction (aucune omission).
