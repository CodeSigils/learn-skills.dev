Herramienta de auditoría de seguridad de configuración web PHP. Identifica CORS, exposición a errores, modificadores de depuración, encabezados de seguridad, modificadores de tiempo de ejecución peligrosos, etc., y proporciona calificación, análisis de explotabilidad, PoC y recomendaciones de corrección (no se permiten omisiones).
