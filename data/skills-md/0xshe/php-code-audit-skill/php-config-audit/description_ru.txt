Инструмент аудита безопасности веб-конфигурации PHP. Идентифицирует CORS, обнаружение ошибок, переключатели отладки, заголовки безопасности, опасные переключатели во время выполнения и т. д., а также предоставляет рейтинг серьезности, анализ возможности использования, PoC и рекомендации по исправлению (без пропусков).
