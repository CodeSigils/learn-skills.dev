Инструмент аудита безопасности веб-конфигурации PHP. Идентифицирует CORS, выявление ошибок, переключатели отладки, заголовки безопасности, опасные переключатели во время выполнения и т. д., а также обеспечивает оценку, анализ возможности использования, PoC и рекомендации по исправлению (упущения не допускаются).
