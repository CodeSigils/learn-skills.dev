Инструмент аудита безопасности веб-конфигурации PHP. Идентифицирует CORS, обнаружение ошибок, переключатели отладки, заголовки безопасности, опасные переключатели во время выполнения и т. д., а также обеспечивает дифференцированный вывод, анализ возможности использования, PoC и рекомендации по исправлению (без упущений).
