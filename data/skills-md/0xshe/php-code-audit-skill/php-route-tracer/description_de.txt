PHP-Webrouting zur Senkung des mehrschichtigen Datenfluss-Tracking-Tools. Basierend auf benutzerdefinierten Routen verfolgt es die Spur vom Handler bis zum letzten sensiblen Betriebspunkt und gibt hierarchische Beweise, Parametervariablenverfolgung und Kontrollierbarkeitsanalyse aus (keine Schlussfolgerung zur Schwachstelle).
