Mehrschichtiger Datenfluss-Tracer vom PHP-Webrouting zur Senke. Verfolgung vom Handler bis zum letzten sensiblen Vorgang gemäß der vom Benutzer angegebenen Route, Ausgabe von Beweisen auf Ebene, Nachverfolgung von Parametervariablen und Kontrollierbarkeitsanalyse (keine Beurteilung der Schwachstelle).
