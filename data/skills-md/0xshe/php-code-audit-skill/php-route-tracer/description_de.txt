Ein mehrschichtiges Datenflussverfolgungstool für PHP-Webrouten zu Senken. Basierend auf benutzerdefinierten Routen verfolgt es die Strecke vom Handler bis zum letzten sensiblen Betriebspunkt und gibt hierarchische Beweise, die Nachverfolgung von Parametervariablen und eine Kontrollierbarkeitsanalyse aus (ohne Rückschlüsse auf Schwachstellen zu ziehen).
