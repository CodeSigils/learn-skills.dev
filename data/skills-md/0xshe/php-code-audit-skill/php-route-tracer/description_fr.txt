Un outil de traçage de flux de données multicouche pour les routes Web PHP vers les récepteurs. Basé sur les itinéraires spécifiés par l'utilisateur, il suit depuis le gestionnaire jusqu'au point d'opération sensible final, produisant des preuves hiérarchiques, un suivi des variables de paramètres et une analyse de contrôlabilité (sans tirer de conclusions de vulnérabilité).
