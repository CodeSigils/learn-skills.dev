PHP Web Routing to Sink Outil de suivi des flux de données multicouches. Basé sur les itinéraires spécifiés par l'utilisateur, il trace depuis le gestionnaire jusqu'au point d'opération sensible final, produisant des preuves hiérarchiques, un suivi des variables de paramètres et une analyse de contrôlabilité (aucune conclusion de vulnérabilité).
