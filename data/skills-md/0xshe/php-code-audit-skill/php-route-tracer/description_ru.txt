Инструмент многоуровневой трассировки потока данных для веб-маршрутов PHP к приемникам. На основе заданных пользователем маршрутов он отслеживает путь от обработчика до конечной чувствительной точки операции, выводя иерархические доказательства, отслеживая переменные параметров и анализ управляемости (без вывода об уязвимости).
