Веб-маршрутизация PHP для приема многоуровневого инструмента отслеживания потоков данных. На основе заданных пользователем маршрутов он отслеживает путь от обработчика до конечной чувствительной точки операции, выводя иерархические доказательства, отслеживая переменные параметров и анализ управляемости (без заключения об уязвимости).
