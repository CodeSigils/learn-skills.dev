Outil d'audit de fractionnement du code source Web PHP CRLF/réponse. Identifie les entrées utilisateur qui atteignent les en-têtes de réponse HTTP, analyse le filtrage et l'encodage des nouvelles lignes/caractères de contrôle, et génère des recommandations d'évaluation de la gravité, de PoC et de correction (aucune omission autorisée).
