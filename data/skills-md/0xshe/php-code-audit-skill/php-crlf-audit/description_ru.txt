Инструмент аудита разделения веб-исходного кода PHP CRLF/ответа. Идентифицирует вводимые пользователем данные, которые достигают заголовков ответов HTTP, анализирует фильтрацию и кодирование символов новой строки/управляющих символов, а также выводит оценку серьезности, PoC и рекомендации по исправлению (пропуски не допускаются).
