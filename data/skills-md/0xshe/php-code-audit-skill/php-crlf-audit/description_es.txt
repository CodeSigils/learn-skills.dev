Código fuente web PHP CRLF/herramienta de auditoría de división de respuestas. Detecte la entrada del usuario que llega a los encabezados de respuesta HTTP, analice el filtrado y la codificación de caracteres de control/nueva línea y la clasificación de gravedad de la salida, la prueba de concepto y las recomendaciones de corrección (se prohíbe la omisión).
