PHP-Web-Quellcode-Prüfungstool für das Schreiben beliebiger Dateien. Identifizieren Sie Ketten, in denen vom Benutzer kontrollierbare Daten eine Schreibsenke erreichen, verfolgen Sie alle Zielschreibvorgänge oder Pfaddurchquerungen bis zum Schreibvorgang und bewerten Sie die Ausführbarkeit des geschriebenen Inhalts (Auslassungen verboten).
