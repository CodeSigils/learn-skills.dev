PHP-Web-Quellcode-Prüfungstool für das Schreiben beliebiger Dateien. Identifizieren Sie Ketten, in denen benutzergesteuerte Daten eine Schreibsenke erreichen, verfolgen Sie beliebige Zielschreibvorgänge/Pfaddurchläufe zum Schreiben und bewerten Sie die Ausführbarkeit nach dem Schreibvorgang (Auslassen verboten).
