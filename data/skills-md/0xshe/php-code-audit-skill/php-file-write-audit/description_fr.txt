Outil d'audit d'écriture de fichiers arbitraires de code source Web PHP. Identifiez les chaînes dans lesquelles les données contrôlées par l'utilisateur atteignent un récepteur d'écriture, tracez les écritures cibles arbitraires/les parcours de chemin à écrire et évaluez l'exécutabilité après l'écriture (omission interdite).
