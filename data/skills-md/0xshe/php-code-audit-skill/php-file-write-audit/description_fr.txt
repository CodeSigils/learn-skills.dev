Un outil d'audit d'écriture de fichiers arbitraires de code source Web PHP. Il identifie les chaînes dans lesquelles les données contrôlables par l'utilisateur atteignent un récepteur d'écriture, suit les écritures cibles arbitraires ou les parcours de chemin à écrire et évalue l'exécutabilité après l'écriture (omission interdite).
