Strumento di controllo dell'iniezione LDAP del codice sorgente Web PHP. Identifica i dati controllabili dall'utente che entrano nella costruzione del filtro LDAP/DN ed eseguiti da ldap_search/ldap_read, la valutazione della sfruttabilità degli output, il PoC e i consigli di correzione (omissione vietata).
