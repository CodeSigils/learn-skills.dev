Outil d'audit de téléchargement de fichiers de code source Web PHP. Identifiez les points d'entrée de téléchargement et les chemins d'enregistrement, la gestion des noms de fichiers et la logique de validation, détectez les risques arbitraires de téléchargement de fichiers/traversée de chemin/téléchargement d'exécutables, les niveaux d'exploitabilité des sorties, les PoC et les suggestions de remédiation (omission interdite).
