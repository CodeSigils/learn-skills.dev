Outil d'audit de téléchargement de fichiers de code source Web PHP. Identifie les points d'entrée de téléchargement et les chemins de stockage, la gestion des noms de fichiers et la logique de validation, détecte les risques arbitraires de téléchargement de fichiers/traversée de chemin/téléchargement d'exécutables, et fournit une évaluation d'exploitabilité, un PoC et des recommandations de correction (aucune omission).
