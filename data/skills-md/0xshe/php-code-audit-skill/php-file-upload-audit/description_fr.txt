Outil d'audit de téléchargement de fichiers de code source Web PHP. Identifie les points d'entrée de téléchargement et les chemins de sauvegarde, la gestion des noms de fichiers et la logique de validation, détecte les risques arbitraires de téléchargement de fichiers/traversée de chemin/téléchargement d'exécutables, produit une évaluation d'exploitabilité, un PoC et des conseils de remédiation (omission interdite).
