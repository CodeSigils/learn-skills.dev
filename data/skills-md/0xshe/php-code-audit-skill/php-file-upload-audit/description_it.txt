Strumento di controllo del caricamento di file del codice sorgente Web PHP. Identifica i punti di ingresso del caricamento e i percorsi di salvataggio, la gestione dei nomi dei file e la logica di convalida, rileva i rischi arbitrari di caricamento/attraversamento del percorso/caricamento di file eseguibili, valutazione di sfruttabilità degli output, PoC e consigli di correzione (omissione vietata).
