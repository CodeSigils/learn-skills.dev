Strumento di controllo del caricamento del file del codice sorgente Web PHP. Identifica i punti di ingresso del caricamento e i percorsi di archiviazione, la gestione dei nomi dei file e la logica di convalida, rileva i rischi arbitrari di caricamento/attraversamento del percorso/caricamento di file eseguibili e fornisce valutazione di sfruttabilità, PoC e consigli di correzione (senza omissioni).
