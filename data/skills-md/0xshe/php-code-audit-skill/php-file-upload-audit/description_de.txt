Audit-Tool zum Hochladen von PHP-Web-Quellcodedateien. Identifiziert Upload-Einstiegspunkte und Speicherpfade, die Handhabung von Dateinamen und die Validierungslogik, erkennt Risiken durch willkürliches Datei-Upload/Pfaddurchquerung/Upload ausführbarer Dateien und bietet Ausnutzbarkeitsbewertung, PoC und Korrekturempfehlungen (keine Auslassungen).
