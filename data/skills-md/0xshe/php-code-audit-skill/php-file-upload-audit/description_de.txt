PHP-Web-Quellcode-Datei-Upload-Prüftool. Identifiziert Upload-Einstiegspunkte und Speicherpfade, die Handhabung von Dateinamen und die Validierungslogik, erkennt Risiken durch willkürliches Datei-Upload/Pfaddurchquerung/Upload ausführbarer Dateien, gibt Ausnutzbarkeitsbewertung, PoC und Korrekturhinweise aus (Auslassen verboten).
