Audit-Tool zum Hochladen von PHP-Web-Quellcodedateien. Identifizieren Sie Upload-Einstiegspunkte und Speicherpfade, die Handhabung von Dateinamen und die Validierungslogik, erkennen Sie Risiken für willkürliches Datei-Upload/Pfaddurchquerung/Upload ausführbarer Dateien, Ausnutzbarkeitsgrade der Ausgabe, PoCs und Korrekturvorschläge (Auslassen verboten).
