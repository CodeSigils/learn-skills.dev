Herramienta de auditoría de carga de archivos de código fuente web PHP. Identifica puntos de entrada de carga y rutas de almacenamiento, manejo de nombres de archivos y lógica de validación, detecta riesgos de carga de archivos arbitrarios/recorrido de ruta/carga de ejecutables y genera calificaciones de explotabilidad, PoC y recomendaciones de corrección (sin omisiones).
