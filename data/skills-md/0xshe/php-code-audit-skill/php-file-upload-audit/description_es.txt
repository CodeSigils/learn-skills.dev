Herramienta de auditoría de carga de archivos de código fuente web PHP. Identifica puntos de entrada de carga y rutas de guardado, manejo de nombres de archivos y lógica de validación, detecta riesgos de carga de archivos arbitrarios/recorrido de ruta/carga ejecutable, genera clasificación de explotabilidad, PoC y consejos de remediación (omisión prohibida).
