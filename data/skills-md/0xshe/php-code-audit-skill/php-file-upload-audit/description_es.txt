Herramienta de auditoría de carga de archivos de código fuente web PHP. Identifique puntos de entrada de carga y rutas de guardado, manejo de nombres de archivos y lógica de validación, detecte riesgos de carga de archivos arbitrarios/recorrido de ruta/carga ejecutable, niveles de explotabilidad de salida, PoC y sugerencias de corrección (omisión prohibida).
