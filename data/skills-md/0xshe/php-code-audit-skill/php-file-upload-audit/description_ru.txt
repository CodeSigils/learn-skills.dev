Инструмент аудита загрузки файлов с исходным кодом PHP. Определяет точки входа для загрузки и пути сохранения, обработку имен файлов и логику проверки, обнаруживает произвольные риски загрузки файлов/путей/загрузки исполняемых файлов, выводит рейтинг уязвимости, PoC и рекомендации по исправлению (упущение запрещено).
