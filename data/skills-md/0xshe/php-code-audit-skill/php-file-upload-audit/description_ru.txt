Инструмент аудита загрузки файлов исходного веб-кода PHP. Определяет точки входа для загрузки и пути хранения, логику обработки и проверки имен файлов, обнаруживает произвольные риски загрузки файлов, обхода путей и загрузки исполняемых файлов, а также выводит рейтинг уязвимости, PoC и рекомендации по исправлению (без пропусков).
