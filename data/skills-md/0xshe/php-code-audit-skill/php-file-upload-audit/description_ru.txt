Инструмент аудита загрузки файлов исходного веб-кода PHP. Определяет точки входа и пути хранения для загрузки, логику обработки и проверки имен файлов, обнаруживает риски произвольной загрузки файлов, обхода путей и загрузки исполняемых файлов, а также предоставляет рейтинг уязвимости, PoC и рекомендации по исправлению (без пропусков).
