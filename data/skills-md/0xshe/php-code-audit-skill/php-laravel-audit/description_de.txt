Laravel Framework Feature Security Audit Tool. Führt eine statische White-Box-Prüfung gängiger Laravel-Funktionen wie Authentifizierung, CSRF, Sitzung, Modellfüllung und Blade-Rendering durch und ordnet die Risiken Ihrem vorhandenen allgemeinen Schwachstellentypsystem zu (AUTH/CSRF/LOGIC/XSS/CFG usw.).
