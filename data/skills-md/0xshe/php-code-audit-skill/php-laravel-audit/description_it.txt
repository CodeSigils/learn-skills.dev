Strumento di controllo della sicurezza del framework Laravel con effetti speciali. Conduce analisi statiche white-box sulle funzionalità comuni di Laravel come autenticazione, CSRF, gestione delle sessioni, assegnazione di massa del modello, rendering Blade, ecc. e mappa i rischi identificati sulla tassonomia delle vulnerabilità generiche esistente (AUTH/CSRF/LOGIC/XSS/CFG, ecc.).
