Outil d'audit de sécurité du framework Laravel avec effets spéciaux. Il effectue une analyse statique en boîte blanche sur les fonctionnalités courantes de Laravel telles que l'authentification, CSRF, la gestion de session, l'attribution en masse de modèles, le rendu Blade, etc., et mappe les risques identifiés à votre taxonomie de vulnérabilité générique existante (AUTH/CSRF/LOGIC/XSS/CFG, etc.).
