Outil d'audit de sécurité des fonctionnalités du framework Laravel. Effectue un audit statique en boîte blanche des fonctionnalités courantes de Laravel telles que l'authentification, CSRF, la session, le remplissage de modèle et le rendu Blade, en mappant les risques sur votre système de type de vulnérabilité général existant (AUTH/CSRF/LOGIC/XSS/CFG, etc.).
