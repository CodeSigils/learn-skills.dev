Outil d'audit de sécurité à effets spéciaux du framework Laravel. Effectue une analyse statique en boîte blanche sur les fonctionnalités courantes de Laravel telles que l'authentification, CSRF, la gestion de session, l'affectation de masse de modèles et le rendu Blade, et mappe les risques identifiés à votre taxonomie de vulnérabilité générique existante (AUTH, CSRF, LOGIC, XSS, CFG, etc.).
