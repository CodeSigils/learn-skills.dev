أداة تدقيق الأمان ذات التأثير الخاص لإطار عمل Laravel. إجراء تحليل ثابت للمربع الأبيض على ميزات Laravel الشائعة مثل المصادقة، وCSRF، ومعالجة الجلسة، وتعيين النماذج الجماعية، وتقديم Blade، وتعيين المخاطر المحددة لتصنيف الثغرات الأمنية العامة الحالي لديك (AUTH، وCSRF، وLOGIC، وXSS، وCFG، وما إلى ذلك).
