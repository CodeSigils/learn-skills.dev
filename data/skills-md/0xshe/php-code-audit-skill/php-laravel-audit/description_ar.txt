أداة التدقيق الأمني ​​لإطار عمل Laravel ذات المؤثرات الخاصة. يقوم بإجراء تحليل ثابت للمربع الأبيض على ميزات Laravel الشائعة مثل المصادقة، وCSRF، ومعالجة الجلسة، والتخصيص الجماعي للنموذج، وتقديم Blade، وما إلى ذلك، ويرسم خريطة للمخاطر المحددة لتصنيف الثغرات الأمنية العامة الحالي لديك (AUTH/CSRF/LOGIC/XSS/CFG، وما إلى ذلك).
