Специальный инструмент аудита безопасности платформы Laravel. Выполняет статический анализ «белого ящика» для общих функций Laravel, таких как аутентификация, CSRF, обработка сеансов, массовое назначение моделей и рендеринг Blade, а также сопоставляет выявленные риски с существующей общей таксономией уязвимостей (AUTH, CSRF, LOGIC, XSS, CFG и т. д.).
