Инструмент аудита безопасности платформы Laravel со специальными эффектами. Он проводит статический анализ «белого ящика» общих функций Laravel, таких как аутентификация, CSRF, обработка сеансов, массовое назначение модели, рендеринг Blade и т. д., и сопоставляет выявленные риски с вашей существующей общей таксономией уязвимостей (AUTH/CSRF/LOGIC/XSS/CFG и т. д.).
