Инструмент аудита безопасности функций Laravel Framework. Выполняет статический аудит «белого ящика» общих функций Laravel, таких как аутентификация, CSRF, сеанс, заполнение модели и рендеринг Blade, сопоставляя риски с вашей существующей общей системой типов уязвимостей (AUTH/CSRF/LOGIC/XSS/CFG и т. д.).
