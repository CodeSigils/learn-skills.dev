PHP-Web-Sicherheitsprotokoll und Überwachungs-Audit-Tool. Identifizieren Sie fehlende Sicherheitsereignisse, in Protokolle geschriebene vertrauliche Informationen, Risiken bei der Protokolleinschleusung/-herstellung sowie Fehler in der Protokollwarnungskette und geben Sie eine Einstufung der Ausnutzbarkeit, einen beobachtbaren PoC und Korrekturempfehlungen aus (keine Auslassungen).
