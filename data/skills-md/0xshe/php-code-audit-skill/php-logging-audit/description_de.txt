PHP-Web-Sicherheitsprotokoll und Überwachungs-Audit-Tool. Es identifiziert fehlende Sicherheitsereignisse, vertrauliche Informationen, die in Protokolle geschrieben werden, Risiken der Protokolleinschleusung/-herstellung sowie Fehler in der Protokollwarnungskette und gibt Ausnutzbarkeitsbewertungen, beobachtbare PoCs und Korrekturempfehlungen aus (keine Auslassungen).
