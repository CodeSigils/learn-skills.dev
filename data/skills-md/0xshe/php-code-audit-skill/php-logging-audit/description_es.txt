Herramienta de auditoría de seguimiento y registro de seguridad web PHP. Identifique eventos de seguridad faltantes, información confidencial escrita en registros, riesgos de inyección/fabricación de registros y defectos en la cadena de alertas de registros, y clasificación de explotabilidad de salida, prueba de concepto observable y recomendaciones de corrección (sin omisiones).
