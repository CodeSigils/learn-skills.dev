Herramienta de auditoría de seguimiento y registro de seguridad web PHP. Identifica eventos de seguridad faltantes, información confidencial escrita en registros, riesgos de inyección/fabricación de registros y defectos en la cadena de alertas de registros, y genera calificaciones de explotabilidad, PoC observables y recomendaciones de solución (sin omisiones).
