Journal de sécurité Web PHP et outil d'audit de surveillance. Il identifie les événements de sécurité manquants, les informations sensibles écrites dans les journaux, les risques d'injection/fabrication de journaux et les défauts dans la chaîne d'alerte des journaux, et génère des évaluations d'exploitabilité, des PoC observables et des recommandations de remédiation (aucune omission).
