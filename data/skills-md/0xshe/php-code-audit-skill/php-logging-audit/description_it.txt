Registro di sicurezza Web PHP e strumento di controllo del monitoraggio. Identifica gli eventi di sicurezza mancanti, le informazioni sensibili scritte nei log, i rischi di log injection/fabrication e i difetti nella catena di avvisi di log e fornisce valutazioni di sfruttabilità, PoC osservabili e raccomandazioni di correzione (senza omissioni).
