Конвейер аудита безопасности кода «белого ящика» PHP Web (многофайловая оркестровка). В качестве основного руководства по оркестрации вызовите навыки субаудита в соответствии с типом приемника (`php-route-mapper/php-auth-audit/php-route-tracer/php-*-audit`) и повторно используйте унифицированный стандарт вывода и оценки.
