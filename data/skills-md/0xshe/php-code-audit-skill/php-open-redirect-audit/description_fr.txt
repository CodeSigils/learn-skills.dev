Outil d'audit de redirection ouverte du code source Web PHP. Identifie les destinations de redirection contrôlables par l'utilisateur transmises aux fonctions de localisation/redirection de l'en-tête, analyse la validation et les listes autorisées, et génère une évaluation de la gravité, des PoC et des recommandations de remédiation (il est interdit d'omettre une partie).
