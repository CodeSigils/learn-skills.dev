Outil d'audit de redirection ouverte du code source Web PHP. Il identifie les destinations de redirection contrôlables par l'utilisateur transmises aux fonctions d'emplacement/redirection de l'en-tête, analyse la validation et les listes autorisées, et génère des niveaux de gravité, des exemples de validation de principe et des recommandations de remédiation (à ne pas omettre).
