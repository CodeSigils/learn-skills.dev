Herramienta de auditoría de redireccionamiento abierto de código fuente web PHP. Identifica destinos de redireccionamiento controlables por el usuario pasados ​​al encabezado Funciones de ubicación/redireccionamiento, analiza la validación y la lista de permitidos, y genera clasificaciones escalonadas, PoC y recomendaciones de corrección (se prohíben las omisiones).
