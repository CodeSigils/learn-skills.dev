Инструмент аудита открытого перенаправления веб-исходного кода PHP. Обнаруживает контролируемые пользователем места назначения перенаправления, которые передаются в заголовок Location/функции перенаправления, анализирует проверку и список разрешений, а также выводит уровни серьезности, PoC и рекомендации по исправлению (упущения запрещены).
