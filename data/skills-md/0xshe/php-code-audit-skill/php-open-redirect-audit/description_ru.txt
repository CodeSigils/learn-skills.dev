Инструмент аудита открытого перенаправления веб-кода PHP. Определяет контролируемые пользователем места назначения перенаправления, передаваемые в заголовок функции местоположения/перенаправления, анализирует проверки и списки разрешенных, а также выводит классификацию серьезности, PoC и рекомендации по исправлению (пропуск какой-либо части запрещен).
