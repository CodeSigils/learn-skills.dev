Open-Redirect-Prüfungstool für PHP-Webquellcode. Identifiziert vom Benutzer steuerbare Weiterleitungsziele, die an Header-Standort-/Umleitungsfunktionen übergeben werden, analysiert Validierungen und Zulassungslisten und gibt Schweregradeinstufungen, PoCs und Korrekturempfehlungen aus (das Weglassen von Teilen ist verboten).
