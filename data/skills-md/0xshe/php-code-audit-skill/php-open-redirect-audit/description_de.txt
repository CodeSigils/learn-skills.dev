PHP-Web-Quellcode-Open-Redirect-Audit-Tool. Es identifiziert vom Benutzer steuerbare Weiterleitungsziele, die an Header-Standort-/Umleitungsfunktionen übergeben werden, analysiert Validierungen und Zulassungslisten und gibt Schweregrade, Proof-of-Concept-Beispiele und Korrekturempfehlungen aus (nicht weglassen).
