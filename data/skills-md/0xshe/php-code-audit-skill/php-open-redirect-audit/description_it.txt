Strumento di controllo del reindirizzamento aperto del codice sorgente Web PHP. Identifica le destinazioni di reindirizzamento controllabili dall'utente che raggiungono le funzioni di posizione/reindirizzamento dell'intestazione, analizza la convalida e gli elenchi consentiti e genera classificazione, PoC e raccomandazioni di correzione (da non omettere).
