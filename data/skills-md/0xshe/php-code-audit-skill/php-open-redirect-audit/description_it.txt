Strumento di controllo del reindirizzamento aperto del codice sorgente Web PHP. Identifica le destinazioni di reindirizzamento controllabili dall'utente passate alle funzioni di posizione/reindirizzamento dell'intestazione, analizza la convalida e le liste consentite e genera livelli di gravità, esempi di prova di concetto e consigli di correzione (da non omettere).
