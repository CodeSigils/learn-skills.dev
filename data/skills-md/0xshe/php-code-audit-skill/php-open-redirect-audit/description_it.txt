Strumento di controllo del reindirizzamento aperto del codice sorgente Web PHP. Identifica le destinazioni di reindirizzamento controllabili dall'utente passate alle funzioni di posizione/reindirizzamento dell'intestazione, analizza la convalida e le liste consentite e genera valutazioni di gravità, PoC e raccomandazioni di correzione (è vietato omettere qualsiasi parte).
