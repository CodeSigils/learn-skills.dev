Strumento di controllo SSRF del codice sorgente web PHP. Identifica gli URL/indirizzi controllabili dall'utente che confluiscono nei sink di richiesta di rete, tiene traccia delle restrizioni e delle risposte interne di rete/protocollo/porta e genera valutazioni di sfruttabilità, PoC e consigli di correzione (non sono consentite omissioni).
