Инструмент аудита SSRF веб-исходного кода PHP. Идентифицирует управляемые пользователем URL-адреса/адреса, которые передаются в приемники сетевых запросов, отслеживает внутренние ограничения и ответы сети/протокола/порта, а также выводит оценку уязвимости, PoC и рекомендации по исправлению (упущения не допускаются).
