Outil d'audit SSRF du code source Web PHP. Identifie les URL/adresses contrôlables par l'utilisateur qui circulent dans les récepteurs de requêtes réseau, suit les restrictions et les réponses du réseau/protocole/port interne, et génère des recommandations d'évaluation de l'exploitabilité, de PoC et de remédiation (aucune omission autorisée).
