Outil d'audit SSRF du code source Web PHP. Identifie les URL/adresses contrôlables par l'utilisateur qui atteignent les récepteurs de requêtes réseau, suit les restrictions et les réponses du réseau/protocole/port interne, et fournit une évaluation de l'exploitabilité, des PoC et des recommandations de correction (aucune omission).
