Herramienta de auditoría SSRF de código fuente web PHP. Identifica las direcciones URL/direcciones controladas por el usuario que ingresan a los receptores de solicitudes de red, rastrea las restricciones y respuestas internas de la red/protocolo/puerto y genera calificaciones de explotabilidad, PoC y recomendaciones de corrección (no se permiten omisiones).
