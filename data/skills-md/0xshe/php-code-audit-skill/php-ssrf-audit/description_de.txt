PHP-Web-Quellcode-SSRF-Prüfungstool. Identifiziert vom Benutzer kontrollierbare URLs/Adressen, die in Netzwerkanforderungssenken fließen, verfolgt interne Netzwerk-/Protokoll-/Portbeschränkungen und -antworten und gibt Ausnutzbarkeitsbewertungen, PoC und Korrekturempfehlungen aus (keine Auslassungen erlaubt).
