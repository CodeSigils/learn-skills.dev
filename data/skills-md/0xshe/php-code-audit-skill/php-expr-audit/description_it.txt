Strumento di controllo per l'inserimento di espressioni di codice sorgente Web PHP (non modello). Identifica le stringhe di espressione controllabili dall'utente che entrano nel motore delle espressioni per la valutazione/compilazione e, infine, portano a un'esecuzione semantica sensibile e restituisce la classificazione dell'exploitability, il PoC e i consigli di correzione (non sono consentite omissioni).
