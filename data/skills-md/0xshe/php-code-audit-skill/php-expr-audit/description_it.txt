Strumento di controllo per l'inserimento di espressioni di codice sorgente Web PHP (non modello). Identifica le stringhe di espressione controllabili dall'utente che entrano nel motore delle espressioni per la valutazione/compilazione e, infine, causano l'esecuzione di semantica sensibile e genera valutazioni di sfruttabilità, PoC e raccomandazioni di correzione (da non omettere).
