Strumento di controllo per l'inserimento di espressioni di codice sorgente Web PHP (non modello). Identifica le stringhe di espressione controllabili dall'utente che entrano in un motore di espressione per la valutazione/compilazione e infine portano a un'esecuzione semantica sensibile, al livello di sfruttabilità degli output, al PoC e ai consigli di correzione (l'omissione è vietata).
