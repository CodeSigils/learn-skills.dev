Outil d'audit d'injection d'expression de code source Web PHP (sans modèle). Identifie les chaînes d'expression contrôlables par l'utilisateur qui entrent dans un moteur d'expression pour évaluation/compilation et conduisent finalement à une exécution sémantique sensible, produisant une évaluation d'exploitabilité, un PoC et des conseils de remédiation (omission interdite).
