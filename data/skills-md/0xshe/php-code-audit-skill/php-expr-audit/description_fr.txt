Outil d'audit par injection d'expression de code source Web PHP (sans modèle). Il identifie les chaînes d'expression contrôlables par l'utilisateur qui entrent dans le moteur d'expression pour évaluation/compilation et provoquent finalement l'exécution de sémantiques sensibles, et génère une évaluation d'exploitabilité, un PoC et des recommandations de remédiation (à ne pas omettre).
