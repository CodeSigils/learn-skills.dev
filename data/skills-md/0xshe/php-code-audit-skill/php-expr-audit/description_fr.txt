Outil d'audit d'injection d'expression de code source Web PHP (sans modèle). Identifie les chaînes d'expression contrôlables par l'utilisateur qui entrent dans le moteur d'expression pour évaluation/compilation et conduisent finalement à une exécution sémantique sensible, et génère des recommandations d'évaluation de l'exploitabilité, de PoC et de remédiation (aucune omission autorisée).
