Инструмент аудита внедрения выражений в исходный код PHP (без шаблонов). Идентифицирует управляемые пользователем строки выражений, которые поступают в механизм выражений для оценки/компиляции и в конечном итоге приводят к чувствительному семантическому выполнению, а также выводит оценку пригодности для использования, PoC и рекомендации по исправлению (упущения не допускаются).
