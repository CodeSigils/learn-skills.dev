Инструмент аудита внедрения выражений (без шаблонов) в исходный код PHP. Идентифицирует управляемые пользователем строки выражений, которые поступают в механизм выражений для оценки/компиляции и в конечном итоге приводят к чувствительному семантическому выполнению, выдаче оценок уязвимости, PoC и рекомендаций по исправлению (упущение запрещено).
