Инструмент аудита внедрения выражений в исходный код PHP (без шаблонов). Он идентифицирует управляемые пользователем строки выражений, которые поступают в механизм выражений для оценки/компиляции и в конечном итоге вызывают выполнение конфиденциальной семантики, а также выводит рейтинг уязвимости, PoC и рекомендации по исправлению (не пропустите).
