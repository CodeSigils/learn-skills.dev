Prüfungstool für PHP-Web-Quellcode-Ausdrucksinjektion (ohne Vorlage). Identifiziert vom Benutzer steuerbare Ausdruckszeichenfolgen, die zur Auswertung/Kompilierung in eine Ausdrucks-Engine eingegeben werden und letztendlich zu einer sensiblen semantischen Ausführung führen, und gibt Ausnutzbarkeitsgrad, PoC und Korrekturempfehlungen aus (Auslassen ist verboten).
