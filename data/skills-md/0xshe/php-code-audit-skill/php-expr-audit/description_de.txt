Prüfungstool für PHP-Web-Quellcode-Ausdrucksinjektion (ohne Vorlage). Identifiziert vom Benutzer steuerbare Ausdruckszeichenfolgen, die zur Auswertung/Kompilierung in eine Ausdrucks-Engine eingegeben werden und letztendlich zu einer sensiblen semantischen Ausführung führen, wobei Ausnutzbarkeitsbewertungen, PoC und Korrekturhinweise ausgegeben werden (Auslassung verboten).
