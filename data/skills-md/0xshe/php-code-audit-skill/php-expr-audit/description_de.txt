Prüfungstool für PHP-Web-Quellcode-Ausdrucksinjektion (ohne Vorlage). Es identifiziert vom Benutzer steuerbare Ausdruckszeichenfolgen, die zur Auswertung/Kompilierung in die Ausdrucks-Engine eingegeben werden und letztendlich die Ausführung sensibler Semantik bewirken, und gibt Ausnutzbarkeitsbewertung, PoC und Korrekturempfehlungen aus (nicht weglassen).
