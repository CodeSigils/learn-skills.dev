Herramienta de auditoría de inyección de expresión de código fuente web PHP (sin plantilla). Identifica cadenas de expresión controlables por el usuario que ingresan al motor de expresión para su evaluación/compilación y, en última instancia, provocan la ejecución de semántica confidencial, y genera una calificación de explotabilidad, PoC y recomendaciones de corrección (no omitir).
