Herramienta de auditoría de inyección de expresión de código fuente web PHP (sin plantilla). Identifica cadenas de expresión controlables por el usuario que ingresan al motor de expresión para evaluación/compilación y, en última instancia, conducen a una ejecución semántica confidencial, y genera calificaciones de explotabilidad, PoC y recomendaciones de corrección (no se permiten omisiones).
