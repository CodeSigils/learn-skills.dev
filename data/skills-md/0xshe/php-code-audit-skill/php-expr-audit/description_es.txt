Herramienta de auditoría de inyección de expresiones (sin plantilla) de código fuente web PHP. Identifica cadenas de expresión controlables por el usuario que ingresan a un motor de expresión para evaluación/compilación y, en última instancia, conducen a una ejecución semántica confidencial, generando calificación de explotabilidad, PoC y consejos de corrección (se prohíbe la omisión).
