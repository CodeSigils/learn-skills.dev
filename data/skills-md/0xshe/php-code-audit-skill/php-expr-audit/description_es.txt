Herramienta de auditoría de inyección de expresiones (sin plantilla) de código fuente web PHP. Identifica cadenas de expresión controlables por el usuario que ingresan a un motor de expresión para evaluación/compilación y, en última instancia, conducen a una ejecución semántica confidencial, nivel de explotabilidad de resultados, PoC y recomendaciones de corrección (está prohibida la omisión).
