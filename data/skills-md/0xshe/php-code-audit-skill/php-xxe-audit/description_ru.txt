Инструмент аудита веб-исходного кода PHP XXE. Идентифицирует точки синтаксического анализа XML и конфигурации обработки сущностей, отслеживает источники входных данных XML и отражения, а также выводит оценку пригодности для использования, PoC и рекомендации по исправлению (упущения не допускаются).
