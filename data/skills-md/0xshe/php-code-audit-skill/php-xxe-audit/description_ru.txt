Инструмент аудита веб-исходного кода PHP XXE. Идентифицирует точки синтаксического анализа XML и конфигурации обработки объектов, отслеживает источники входных данных XML и эхо-сигналы, а также выводит оценку пригодности для использования, PoC и рекомендации по исправлению (упущения не допускаются).
