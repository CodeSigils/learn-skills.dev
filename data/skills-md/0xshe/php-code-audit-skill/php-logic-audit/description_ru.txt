Инструмент аудита уязвимостей веб-бизнес-логики PHP. Идентифицирует логические дефекты, выходящие за рамки аутентификации/авторизации: массовое назначение, обход потока, состояния гонки, дефекты конечного автомата, уязвимости времени оплаты/разрешения и т. д.; выводит цепочку доказательств, классификацию, PoC и рекомендации по исправлению ситуации (без упущений).
