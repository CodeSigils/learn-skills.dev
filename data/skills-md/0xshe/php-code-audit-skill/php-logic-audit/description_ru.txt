Аудитор уязвимостей веб-бизнес-логики PHP. Обнаруживает логические ошибки, выходящие за рамки аутентификации/авторизации: массовое назначение, обход рабочего процесса, состояния гонки, дефекты конечного автомата, проблемы со временем оплаты/разрешения и т. д.; выводит цепочки доказательств, уровни серьезности, PoC и рекомендации по исправлению ситуации (упущения не допускаются).
