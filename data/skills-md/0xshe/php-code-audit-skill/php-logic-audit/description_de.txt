PHP-Tool zur Prüfung von Sicherheitslücken in der Web-Geschäftslogik. Identifiziert logische Fehler, die über die Authentifizierung/Autorisierung hinausgehen: Massenzuweisung, Flussumgehung, Race Conditions, State-Machine-Defekte, Schwachstellen beim Zahlungs-/Berechtigungs-Timing usw.; gibt Evidenzkette, Klassifizierung, PoC und Sanierungsempfehlungen aus (keine Auslassungen).
