PHP-Tool zur Prüfung von Schwachstellen in der Web-Geschäftslogik. Identifiziert logische Fehler, die über die Authentifizierung/Autorisierung hinausgehen, wie z. B. Massenzuweisung, Prozessumgehung, Race Conditions, State-Machine-Defekte, Schwachstellen bei Zahlungs-/Berechtigungszeitpunkten usw., und gibt eine Beweiskette, Schweregradeinstufung, PoC und Korrekturempfehlungen aus (keine Auslassungen erlaubt).
