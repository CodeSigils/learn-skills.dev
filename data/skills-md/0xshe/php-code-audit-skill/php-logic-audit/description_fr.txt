Outil d'audit des vulnérabilités de la logique métier Web PHP. Identifie les défauts logiques au-delà de l'authentification/autorisation : affectation de masse, contournement de flux, conditions de concurrence critique, défauts de la machine à états, vulnérabilités de synchronisation de paiement/autorisation, etc. ; produit la chaîne de preuves, la classification, la PoC et les recommandations de remédiation (aucune omission).
