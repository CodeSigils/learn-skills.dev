Auditor de vulnerabilidades de lógica empresarial web PHP. Detecta fallas lógicas más allá de la autenticación/autorización: asignación masiva, omisión del flujo de trabajo, condiciones de carrera, defectos de estado de la máquina, problemas de tiempo de pago/permiso, etc.; genera cadenas de evidencia, niveles de gravedad, PoC y recomendaciones de remediación (no se permiten omisiones).
