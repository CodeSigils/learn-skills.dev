Herramienta de auditoría de vulnerabilidades de lógica empresarial web PHP. Identifica defectos lógicos más allá de la autenticación/autorización: asignación masiva, derivación de flujo, condiciones de carrera, defectos de la máquina de estado, vulnerabilidades de tiempo de pago/permiso, etc.; produce cadena de evidencia, clasificación, PoC y recomendaciones de remediación (sin omisiones).
