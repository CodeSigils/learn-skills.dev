Herramienta de auditoría de vulnerabilidades de lógica empresarial web PHP. Identifica fallas lógicas más allá de la autenticación/autorización, como asignación masiva, omisión de procesos, condiciones de carrera, defectos de la máquina de estado, vulnerabilidades de tiempo de pago/permiso, etc., y genera una cadena de evidencia, clasificación de gravedad, PoC y recomendaciones de remediación (no se permiten omisiones).
