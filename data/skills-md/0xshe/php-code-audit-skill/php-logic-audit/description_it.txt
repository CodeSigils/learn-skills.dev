Strumento di controllo delle vulnerabilità della logica aziendale Web PHP. Identifica difetti logici oltre l'autenticazione/autorizzazione come assegnazione di massa, bypass dei processi, condizioni di competizione, difetti della macchina statale, vulnerabilità nei tempi di pagamento/autorizzazione, ecc. e genera una catena di prove, classificazione di gravità, PoC e raccomandazioni di correzione (non sono consentite omissioni).
