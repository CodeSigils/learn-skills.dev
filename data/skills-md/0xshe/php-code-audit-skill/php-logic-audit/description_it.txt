Strumento di controllo della vulnerabilità della logica aziendale Web PHP. Identifica difetti logici oltre l'autenticazione/autorizzazione: assegnazione di massa, bypass del flusso, condizioni di competizione, difetti della macchina a stati, vulnerabilità nei tempi di pagamento/autorizzazione, ecc.; fornisce catena di prove, classificazione, PoC e raccomandazioni di riparazione (nessuna omissione).
