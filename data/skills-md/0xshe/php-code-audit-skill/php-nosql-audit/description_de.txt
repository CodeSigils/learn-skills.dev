Ein PHP-Web-Quellcode-NoSQL-Injection-Auditing-Tool. Es identifiziert Benutzereingaben, die in die Abfragekonstruktion von MongoDB/DocumentDB eingehen, analysiert, ob eine Operatorinjektion ($gt/$ne/$where usw.) vorliegt, und gibt eine Schweregradbewertung, PoC und Korrekturempfehlungen (keine Auslassungen) aus.
