Инструмент аудита внедрения NoSQL с веб-исходным кодом PHP. Идентифицирует вводимые пользователем данные при построении запроса MongoDB/DocumentDB, анализирует наличие внедрения оператора ($gt/$ne/$where и т. д.), выводит уровни серьезности, PoC и предложения по исправлению (упущения не допускаются).
