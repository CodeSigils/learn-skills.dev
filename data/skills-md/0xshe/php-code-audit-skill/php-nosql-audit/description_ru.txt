Инструмент аудита NoSQL-инъекций веб-исходного кода PHP. Он идентифицирует ввод пользователя, который входит в конструкцию запроса MongoDB/DocumentDB, анализирует, существует ли внедрение оператора ($gt/$ne/$where и т. д.), и выводит рейтинг серьезности, PoC и рекомендации по исправлению (без пропусков).
