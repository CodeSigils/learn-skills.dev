Инструмент аудита внедрения NoSQL с веб-исходным кодом PHP. Он идентифицирует пользовательский ввод, который входит в конструкцию запроса MongoDB/DocumentDB, анализирует, присутствует ли внедрение операторов ($gt, $ne, $where и т. д.), и выводит рейтинг серьезности, PoC и рекомендации по исправлению (пропуски не допускаются).
