Uno strumento di controllo dell'iniezione NoSQL del codice sorgente Web PHP. Identifica l'input dell'utente che immette la costruzione della query MongoDB/DocumentDB, analizza se esiste l'inserimento dell'operatore ($gt/$ne/$where e così via) e restituisce una valutazione di gravità, un PoC e raccomandazioni di correzione (senza omissioni).
