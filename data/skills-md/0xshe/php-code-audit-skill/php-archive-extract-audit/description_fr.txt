Outil d'audit d'extraction d'archives Web PHP (Zip Slip/path traversal). Identifie la manière dont les noms d'entrées extraits sont concaténés avec le répertoire cible, si une contrainte de répertoire de base est manquante, et génère des évaluations d'exploitabilité, des preuves de concepts observables et des recommandations de correction (aucune omission autorisée).
