Outil d'audit d'extraction d'archives Web PHP (Zip Slip/path traversal). Identifie la manière dont les noms d'entrées extraits sont combinés avec le répertoire cible, vérifie les contraintes manquantes du répertoire de base et génère une évaluation de l'exploitabilité, une preuve de concept observable et des recommandations de correction (aucune omission).
