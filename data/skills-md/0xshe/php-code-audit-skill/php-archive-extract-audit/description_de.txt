Prüfungstool für PHP-Webarchiv-Extraktion (Zip Slip/Path Traversal). Identifiziert, wie extrahierte Eintragsnamen mit dem Zielverzeichnis kombiniert werden, prüft auf fehlende Basisverzeichniseinschränkungen und gibt eine Ausnutzbarkeitsbewertung, einen beobachtbaren Proof-of-Concept und Korrekturempfehlungen aus (keine Auslassungen).
