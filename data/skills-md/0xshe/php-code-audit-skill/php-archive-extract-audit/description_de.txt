Prüftool für PHP-Webarchiv-Extraktion (Zip Slip/Path Traversal). Es identifiziert, wie extrahierte Eintragsnamen mit dem Zielverzeichnis verkettet werden, ob eine Basisverzeichnis-Einschränkung fehlt, und gibt eine Ausnutzbarkeitsklassifizierung, einen beobachtbaren PoC und Korrekturvorschläge aus (Auslassungen verboten).
