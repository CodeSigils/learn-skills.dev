Prüfungstool für die Extraktion von PHP-Webarchiven (Zip Slip/Path Traversal). Identifiziert, wie extrahierte Eintragsnamen mit dem Zielverzeichnis verkettet werden, ob eine Basisverzeichniseinschränkung fehlt, und gibt Ausnutzbarkeitsbewertungen, beobachtbare Proof-of-Concepts und Korrekturempfehlungen aus (keine Auslassungen erlaubt).
