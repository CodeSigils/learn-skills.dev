Prüfungstool für PHP-Webarchiv-Dekomprimierung (Zip Slip/Path Traversal). Erkennt, wie der extrahierte Eintragsname mit dem Zielverzeichnis verkettet ist, ob die Basisverzeichnis-Einschränkung fehlt, und gibt eine Ausnutzbarkeitsbewertung, einen beobachtbaren PoC und eine Behebung (keine Auslassungen) aus.
