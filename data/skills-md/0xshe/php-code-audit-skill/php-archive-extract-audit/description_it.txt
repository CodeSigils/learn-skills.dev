Strumento di controllo dell'estrazione di archivi Web PHP (Zip Slip/percorso trasversale). Identifica il modo in cui i nomi delle voci estratte vengono concatenati con la directory di destinazione, se manca un vincolo della directory di base e genera valutazioni di sfruttabilità, prove di concetto osservabili e raccomandazioni di correzione (non sono consentite omissioni).
