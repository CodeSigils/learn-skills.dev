Strumento di controllo dell'estrazione di archivi Web PHP (Zip Slip/percorso trasversale). Identifica il modo in cui i nomi delle voci estratte vengono concatenati con la directory di destinazione, se manca un vincolo base-dir e restituisce la classificazione di sfruttabilità, PoC osservabile e suggerimenti di correzione (omissioni vietate).
