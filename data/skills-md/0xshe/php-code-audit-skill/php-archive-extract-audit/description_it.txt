Strumento di controllo dell'estrazione di archivi Web PHP (Zip Slip/percorso trasversale). Identifica il modo in cui i nomi delle voci estratte vengono combinati con la directory di destinazione, controlla la mancanza dei vincoli della directory di base e fornisce la classificazione della sfruttabilità degli output, prove di concetto osservabili e raccomandazioni di correzione (nessuna omissione).
