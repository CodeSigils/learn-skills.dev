Herramienta de auditoría de extracción de archivos web PHP (Zip Slip/recorrido de ruta). Identifica cómo se concatenan los nombres de las entradas extraídas con el directorio de destino, si falta una restricción del directorio base y genera calificaciones de explotabilidad, pruebas de conceptos observables y recomendaciones de corrección (no se permiten omisiones).
