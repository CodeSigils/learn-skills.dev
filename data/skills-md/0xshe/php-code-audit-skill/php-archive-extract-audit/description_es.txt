Herramienta de auditoría de extracción de archivos web PHP (Zip Slip/recorrido de ruta). Identifica cómo se combinan los nombres de las entradas extraídas con el directorio de destino, comprueba si faltan restricciones del directorio base y genera calificaciones de explotabilidad, pruebas de concepto observables y recomendaciones de corrección (sin omisiones).
