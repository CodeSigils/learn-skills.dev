Herramienta de auditoría de extracción de archivos web PHP (Zip Slip/recorrido de ruta). Identifica cómo se concatenan los nombres de las entradas extraídas con el directorio de destino, si falta una restricción de directorio base y genera una clasificación de explotabilidad, PoC observable y sugerencias de corrección (se prohíben las omisiones).
