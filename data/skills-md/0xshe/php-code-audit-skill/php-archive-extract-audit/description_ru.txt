Инструмент аудита извлечения веб-архива PHP (Zip Slip / Path Traversal). Он определяет, как извлеченные имена записей объединяются с целевым каталогом, отсутствует ли ограничение базового каталога, а также выводит классификацию уязвимости, наблюдаемый PoC и предложения по исправлению (упущения запрещены).
