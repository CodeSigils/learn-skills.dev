Инструмент аудита извлечения веб-архива PHP (Zip Slip/path). Определяет, как извлеченные имена записей сочетаются с целевым каталогом, проверяет отсутствие ограничений базового каталога и выводит оценку пригодности для использования, наблюдаемое подтверждение концепции и рекомендации по исправлению (без пропусков).
