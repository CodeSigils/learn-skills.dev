Инструмент аудита извлечения веб-архива PHP (Zip Slip / Path Traversal). Определяет, как извлеченные имена записей объединяются с целевым каталогом, отсутствует ли ограничение базового каталога, а также выводит рейтинги возможности использования, наблюдаемые доказательства концепции и рекомендации по исправлению (упущения не допускаются).
