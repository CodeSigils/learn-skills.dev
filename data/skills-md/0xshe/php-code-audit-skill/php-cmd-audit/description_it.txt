Strumento di controllo dell'iniezione di comandi di codice sorgente web PHP. Identifica i sink di esecuzione dei comandi (ad esempio exec, system, shell_exec e così via), tiene traccia dell'input dell'utente che scorre nella concatenazione dei comandi e genera valutazioni di sfruttabilità, PoC e consigli di correzione (non sono consentite omissioni).
