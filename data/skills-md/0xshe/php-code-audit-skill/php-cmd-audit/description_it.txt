Strumento di controllo dell'iniezione di comandi di codice sorgente web PHP. Identifica i sink di esecuzione dei comandi (exec, system, shell_exec e così via), tiene traccia dell'input dell'utente che immette la concatenazione dei comandi e restituisce la classificazione dell'exploitability, il PoC e i consigli di correzione (senza omissioni).
