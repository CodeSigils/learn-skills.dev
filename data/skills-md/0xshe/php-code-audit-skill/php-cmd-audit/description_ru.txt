Инструмент аудита внедрения команд веб-исходного кода PHP. Идентифицирует приемники выполнения команд (например, exec, system, Shell_exec и т. д.), отслеживает вводимые пользователем данные, поступающие в конкатенацию команд, и выводит рейтинги уязвимости, PoC и рекомендации по исправлению (упущения не допускаются).
