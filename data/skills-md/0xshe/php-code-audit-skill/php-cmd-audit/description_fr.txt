Outil d'audit d'injection de commande de code source Web PHP. Identifie les récepteurs d'exécution des commandes (exec, system, shell_exec, etc.), suit les entrées de l'utilisateur entrant dans la concaténation des commandes et génère des recommandations d'évaluation de l'exploitabilité, de PoC et de remédiation (aucune omission).
