Outil d'audit d'injection de commande de code source Web PHP. Identifie les récepteurs d'exécution de commandes (par exemple, exec, system, shell_exec, etc.), suit les entrées de l'utilisateur circulant dans la concaténation des commandes et génère des évaluations d'exploitabilité, des PoC et des recommandations de remédiation (aucune omission autorisée).
