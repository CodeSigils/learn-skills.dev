Strumento di controllo della sicurezza del framework Yii. Esegue il controllo statico white-box del controllo degli accessi Yii (tipicamente Yii2) (AccessControl/RBAC), CSRF, regole di filtraggio dell'input, strategie di codifica dell'output, sicurezza URL/reindirizzamento e mappa i risultati su una tassonomia di vulnerabilità generica (AUTH/CSRF/XSS/CFG/LOGIC, ecc.).
