Strumento di controllo della sicurezza degli effetti speciali del framework Yii. Esegue un controllo statico white-box sul controllo degli accessi Yii (solitamente Yii2) (AccessControl/RBAC), CSRF, regole di filtraggio dell'input, strategie di codifica dell'output, sicurezza URL/reindirizzamento e mappa i risultati su una tassonomia di vulnerabilità comune (AUTH/CSRF/XSS/CFG/LOGIC, ecc.).
