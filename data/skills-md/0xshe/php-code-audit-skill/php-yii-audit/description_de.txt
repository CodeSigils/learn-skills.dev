Yii Framework Special-Effect Security Audit Tool. Führt statisches White-Box-Auditing für Yii (normalerweise Yii2) Zugriffskontrolle (AccessControl/RBAC), CSRF, Eingabefilterregeln, Ausgabecodierungsrichtlinien, URL-/Umleitungssicherheit durch und ordnet Ergebnisse einer allgemeinen Schwachstellentaxonomie (AUTH/CSRF/XSS/CFG/LOGIC usw.) zu.
