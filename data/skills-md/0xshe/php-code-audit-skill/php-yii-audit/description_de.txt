Yii-Framework-Sicherheitsaudit-Tool. Führt eine statische White-Box-Prüfung der Zugriffskontrolle (AccessControl/RBAC) von Yii (normalerweise Yii2), CSRF, Eingabefilterregeln, Ausgabekodierungsstrategien, URL-/Umleitungssicherheit durch und ordnet Ergebnisse einer generischen Schwachstellentaxonomie (AUTH/CSRF/XSS/CFG/LOGIC usw.) zu.
