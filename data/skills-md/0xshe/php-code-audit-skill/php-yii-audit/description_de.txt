Yii-Framework-Sicherheitsaudit-Tool mit Spezialeffekt. Es führt eine statische White-Box-Prüfung der Zugriffskontrolle (AccessControl/RBAC) von Yii (typischerweise Yii2), CSRF, Eingabefilterregeln, Ausgabekodierungsstrategien, URL-/Umleitungssicherheit durch und ordnet die Ergebnisse einer allgemeinen Schwachstellentaxonomie (AUTH/CSRF/XSS/CFG/LOGIC usw.) zu.
