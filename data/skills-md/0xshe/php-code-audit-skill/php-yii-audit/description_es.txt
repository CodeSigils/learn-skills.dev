Herramienta de auditoría de seguridad de efectos especiales del framework Yii. Realiza auditorías estáticas de caja blanca en el control de acceso (AccessControl/RBAC) de Yii (generalmente Yii2), CSRF, reglas de filtrado de entrada, estrategias de codificación de salida, seguridad de URL/redireccionamiento y asigna los hallazgos a una taxonomía de vulnerabilidad común (AUTH/CSRF/XSS/CFG/LOGIC, etc.).
