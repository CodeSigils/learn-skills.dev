Herramienta de auditoría de seguridad del framework Yii. Realiza auditorías estáticas de caja blanca del control de acceso (AccessControl/RBAC) de Yii (normalmente Yii2), CSRF, reglas de filtrado de entrada, estrategias de codificación de salida, seguridad de URL/redireccionamiento y asigna los resultados a una taxonomía de vulnerabilidad genérica (AUTH/CSRF/XSS/CFG/LOGIC, etc.).
