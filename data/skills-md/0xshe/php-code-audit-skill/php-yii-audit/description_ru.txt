Специальный инструмент аудита безопасности Yii Framework. Выполняет статический аудит «белого ящика» для контроля доступа Yii (обычно Yii2) (AccessControl/RBAC), CSRF, правил входной фильтрации, политик выходного кодирования, безопасности URL/перенаправления и сопоставляет результаты с общей таксономией уязвимостей (AUTH/CSRF/XSS/CFG/LOGIC и т. д.).
