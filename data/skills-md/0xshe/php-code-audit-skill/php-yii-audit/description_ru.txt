Инструмент аудита безопасности со специальными эффектами Yii framework. Выполняет статический аудит «белого ящика» для управления доступом Yii (обычно Yii2) (AccessControl/RBAC), CSRF, правил входной фильтрации, стратегий выходного кодирования, безопасности URL/перенаправления и сопоставляет результаты с общей таксономией уязвимостей (AUTH/CSRF/XSS/CFG/LOGIC и т. д.).
