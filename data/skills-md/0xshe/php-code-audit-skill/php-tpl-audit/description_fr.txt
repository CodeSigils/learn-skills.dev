Outil d'injection de modèle de code source Web PHP/d'audit SSTI. Identifie les points de rendu du moteur de modèles et la contrôlabilité des noms/expressions de modèles, les traces des chaînes d'évaluation/d'exécution et génère des évaluations d'exploitabilité, des PoC et des recommandations de remédiation (aucune omission autorisée).
