Outil d'injection de modèle de code source Web PHP/d'audit SSTI. Détecte les points de rendu du moteur de modèle et la contrôlabilité des noms/expressions de modèle, trace la chaîne d'évaluation/d'exécution et génère des recommandations d'évaluation d'exploitabilité, de PoC et de correction (ne doivent pas être omises).
