Инструмент внедрения шаблонов веб-исходного кода PHP/инструмент аудита SSTI. Определяет точки рендеринга механизма шаблонов и управляемость имен/выражений шаблонов, отслеживает цепочки оценки/выполнения и выводит оценку пригодности для использования, PoC и рекомендации по исправлению (упущения не допускаются).
