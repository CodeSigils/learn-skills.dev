Инструмент внедрения шаблонов веб-исходного кода PHP/​инструмент аудита SSTI. Определяет точки рендеринга механизма шаблонов и управляемость имени/выражения шаблона, отслеживает цепочки оценки/выполнения, выводит уровни возможности использования, PoC и предложения по исправлению (упущение запрещено).
