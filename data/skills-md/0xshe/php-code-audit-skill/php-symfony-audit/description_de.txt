Symfony Framework Special-Effect Security Audit Tool. Führt ein statisches White-Box-Audit für gängige Symfony-Mechanismen wie security.yaml, CSRF, Twig/raw, Vorlagenausdrücke und Zugriffskontrolle durch und ordnet Risiken einem universellen Schwachstellentypsystem (AUTH/CS/CFG/XSS/TPL/LOGIC usw.) zu.
