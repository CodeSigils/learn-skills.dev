Spezialeffekt-Sicherheitsüberwachungstool für das Symfony-Framework. Es führt eine statische White-Box-Analyse für gängige Symfony-Mechanismen wie security.yaml, CSRF, Twig/Twig raw, Ausdrücke und Zugriffskontrolle durch und ordnet die Risiken einer generischen Schwachstellentaxonomie zu (AUTH/CSRF/CFG/XSS/TPL/LOGIC usw.).
