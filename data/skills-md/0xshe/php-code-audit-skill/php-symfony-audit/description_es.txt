Herramienta de auditoría de seguridad de efectos especiales del framework Symfony. Realiza auditorías estáticas de caja blanca en mecanismos comunes de Symfony como security.yaml, CSRF, Twig/Twig raw, expresiones y control de acceso, y asigna los riesgos a una taxonomía de vulnerabilidad universal (AUTH/CSRF/CFG/XSS/TPL/LOGIC, etc.).
