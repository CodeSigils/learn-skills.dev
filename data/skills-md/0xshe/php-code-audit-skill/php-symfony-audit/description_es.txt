Herramienta de auditoría de seguridad específica del framework Symfony. Realiza auditorías estáticas de caja blanca de mecanismos comunes de Symfony como security.yaml, CSRF, Twig/Twig raw, expresiones y control de acceso, y asigna riesgos a una taxonomía de vulnerabilidad general (AUTH/CSRF/CFG/XSS/TPL/LOGIC, etc.).
