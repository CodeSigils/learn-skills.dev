Herramienta de auditoría de seguridad de efectos especiales de Symfony Framework. Realiza auditorías estáticas de caja blanca en mecanismos comunes de Symfony como security.yaml, CSRF, Twig/raw, expresiones de plantilla y control de acceso, asignando riesgos a un sistema de tipo de vulnerabilidad universal (AUTH/CS/CFG/XSS/TPL/LOGIC, etc.).
