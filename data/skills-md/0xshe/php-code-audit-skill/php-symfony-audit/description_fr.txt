Outil d'audit de sécurité à effets spéciaux du framework Symfony. Il effectue une analyse statique en boîte blanche sur les mécanismes Symfony courants tels que security.yaml, CSRF, Twig/Twig raw, les expressions et le contrôle d'accès, et mappe les risques à une taxonomie générique de vulnérabilité (AUTH/CSRF/CFG/XSS/TPL/LOGIC, etc.).
