Outil d'audit de sécurité à effets spéciaux Symfony Framework. Effectue un audit statique en boîte blanche sur les mécanismes Symfony courants tels que security.yaml, CSRF, Twig/raw, les expressions de modèles et le contrôle d'accès, en mappant les risques sur un système de type de vulnérabilité universel (AUTH/CS/CFG/XSS/TPL/LOGIC, etc.).
