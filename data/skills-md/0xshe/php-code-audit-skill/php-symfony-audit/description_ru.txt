Специальный инструмент аудита безопасности Symfony Framework. Он выполняет статический анализ «белого ящика» для распространенных механизмов Symfony, таких как Security.yaml, CSRF, Twig/Twig raw, выражения и контроль доступа, и сопоставляет риски с общей таксономией уязвимостей (AUTH/CSRF/CFG/XSS/TPL/LOGIC и т. д.).
