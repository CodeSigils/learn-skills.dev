Специальный инструмент аудита безопасности Symfony Framework. Он выполняет статический аудит «белого ящика» для распространенных механизмов Symfony, таких как security.yaml, CSRF, Twig/Twig raw, выражения и контроль доступа, а также сопоставляет риски с универсальной таксономией уязвимостей (AUTH/CSRF/CFG/XSS/TPL/LOGIC и т. д.).
