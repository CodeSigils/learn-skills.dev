Инструмент аудита безопасности, специфичный для платформы Symfony. Выполняет статический аудит «белого ящика» общих механизмов Symfony, таких как security.yaml, CSRF, Twig/Twig raw, выражения и контроль доступа, а также сопоставляет риски с общей таксономией уязвимостей (AUTH/CSRF/CFG/XSS/TPL/LOGIC и т. д.).
