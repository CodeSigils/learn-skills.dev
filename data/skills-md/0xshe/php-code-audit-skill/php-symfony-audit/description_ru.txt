Специальный инструмент аудита безопасности Symfony Framework. Выполняет статический аудит «белого ящика» для распространенных механизмов Symfony, таких как Security.yaml, CSRF, Twig/raw, выражения шаблонов и контроль доступа, сопоставляя риски с универсальной системой типов уязвимостей (AUTH/CS/CFG/XSS/TPL/LOGIC и т. д.).
