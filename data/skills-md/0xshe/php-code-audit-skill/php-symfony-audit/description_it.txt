Strumento di controllo della sicurezza ad effetti speciali di Symfony Framework. Esegue un controllo statico white-box sui meccanismi comuni di Symfony come security.yaml, CSRF, Twig/raw, espressioni di template e controllo degli accessi, mappando i rischi su un sistema di tipo di vulnerabilità universale (AUTH/CS/CFG/XSS/TPL/LOGIC, ecc.).
