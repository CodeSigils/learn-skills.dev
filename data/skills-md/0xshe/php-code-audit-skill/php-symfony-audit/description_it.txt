Strumento di controllo della sicurezza con effetti speciali del framework Symfony. Esegue un controllo statico white-box sui meccanismi comuni di Symfony come security.yaml, CSRF, Twig/Twig raw, espressioni e controllo degli accessi e mappa i rischi su una tassonomia universale delle vulnerabilità (AUTH/CSRF/CFG/XSS/TPL/LOGIC, ecc.).
