إطار CodeIgniter هو أداة متخصصة للتدقيق الأمني. وهو يجري تدقيقًا ثابتًا للمربع الأبيض لـ CodeIgniter's CSRF وتصفية مخرجات XSS وإنشاء استعلام قاعدة البيانات وتكوين التوجيه والمدقق وأمن ملفات تعريف الارتباط للجلسة وآليات أخرى، ويعينها إلى تصنيف عام للثغرات الأمنية (CSRF/AUTH/XSS/SQL/CFG/SESS، وما إلى ذلك).
