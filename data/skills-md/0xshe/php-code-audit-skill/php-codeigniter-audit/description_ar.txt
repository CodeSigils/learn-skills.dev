أداة تدقيق الأمان الخاصة بإطار عمل CodeIgniter. يقوم بإجراء تدقيق ثابت للمربع الأبيض لـ CodeIgniter's CSRF، وتصفية مخرجات XSS، وإنشاء استعلام قاعدة البيانات، وتكوين التوجيه والمدقق، وأمن ملفات تعريف الارتباط للجلسة، وتعيين النتائج إلى تصنيف الثغرات الأمنية العالمية (CSRF/AUTH/XSS/SQL/CFG/SESS، وما إلى ذلك).
