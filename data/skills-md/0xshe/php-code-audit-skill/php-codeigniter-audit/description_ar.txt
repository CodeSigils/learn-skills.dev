أداة تدقيق الأمان الخاصة بإطار عمل CodeIgniter. وهو يجري عمليات تدقيق ثابتة على شكل مربع أبيض لملفات CSRF الخاصة بـ CodeIgniter، وتصفية مخرجات XSS، وإنشاء استعلام قاعدة البيانات، وتكوين التوجيه والمدقق، وأمن ملفات تعريف الارتباط للجلسة، وآليات أخرى، ويعينها إلى تصنيف عام للثغرات الأمنية (CSRF/AUTH/XSS/SQL/CFG/SESS، وما إلى ذلك).
