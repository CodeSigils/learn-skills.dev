Auf das CodeIgniter-Framework spezialisiertes Sicherheitsaudit-Tool. Es führt eine statische White-Box-Prüfung von CodeIgniters CSRF, XSS-Ausgabefilterung, Datenbankabfragekonstruktion, Routing- und Validatorkonfiguration, Sitzungscookie-Sicherheit und anderen Mechanismen durch und ordnet sie einer generischen Schwachstellentaxonomie zu (CSRF/AUTH/XSS/SQL/CFG/SESS usw.).
