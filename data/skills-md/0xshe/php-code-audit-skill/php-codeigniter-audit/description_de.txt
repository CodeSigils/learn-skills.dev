CodeIgniter Framework-spezifisches Sicherheitsaudit-Tool. Führt eine statische White-Box-Prüfung von CodeIgniters CSRF, XSS-Ausgabefilterung, Datenbankabfragekonstruktion, Routing- und Validatorkonfiguration, Sitzungscookie-Sicherheit durch und ordnet Ergebnisse einer universellen Schwachstellentaxonomie zu (CSRF/AUTH/XSS/SQL/CFG/SESS usw.).
