Инструмент аудита безопасности, специфичный для платформы CodeIgniter. Выполняет статический аудит CSRF CodeIgniter, фильтрацию вывода XSS, построение запросов к базе данных, конфигурацию маршрутизации и валидатора, безопасность файлов cookie сеанса и сопоставляет результаты с универсальной таксономией уязвимостей (CSRF/AUTH/XSS/SQL/CFG/SESS и т. д.).
