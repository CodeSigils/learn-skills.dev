Tool zur Überwachung des PHP-Dateisystembetriebs. Es konzentriert sich auf Sicherheitsrisiken von Vorgängen wie mkdir, chmod, chown, unlink, rmdir, link, symlink, readlink, touch, Berechtigungen und TOCTOU und liefert „erweiterte Ausnutzbarkeitsnachweise“ für Pfadvalidierungsumgehungen und Schreibketten-Exploits (kein Ersatz für Unterprüfungen von FILE/UPLOAD/WRITE-Senken).
