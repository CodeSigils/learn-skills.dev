Strumento di controllo del funzionamento del file system PHP. Si concentra sui rischi per la sicurezza di operazioni come mkdir, chmod, chown, unlink, rmdir, link, symlink, readlink, touch, permessi e TOCTOU, fornendo "prove avanzate di sfruttabilità" per bypass di convalida del percorso e exploit di catena di scrittura (non sostituisce i controlli secondari dei sink FILE/UPLOAD/WRITE).
