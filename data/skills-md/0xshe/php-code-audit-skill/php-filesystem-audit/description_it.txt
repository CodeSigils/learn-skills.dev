Strumento di controllo del funzionamento del file system PHP. Si concentra sui rischi per la sicurezza di mkdir/chmod/chown/unlink/rmdir/link/symlink/readlink/touch/permissions e sui problemi TOCTOU, fornendo "prove di miglioramento dell'exploitability" per bypass di convalida del percorso e sfruttamento della catena di scrittura (non sostituisce i controlli secondari del sink FILE/UPLOAD/WRITE).
