Strumento di controllo del funzionamento del file system PHP. Si concentra sui rischi per la sicurezza di operazioni come mkdir, chmod, chown, unlink, rmdir, link, symlink, readlink, touch, permessi e TOCTOU, fornendo "prove avanzate di sfruttabilità" per il bypass della validazione del percorso e lo sfruttamento della catena di scrittura (non sostituisce i controlli secondari per i sink FILE/UPLOAD/WRITE).
