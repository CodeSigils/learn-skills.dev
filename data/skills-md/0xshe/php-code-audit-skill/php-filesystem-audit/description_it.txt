Strumento di controllo del funzionamento del file system PHP. Si concentra sui rischi per la sicurezza di mkdir/chmod/chown/uninlink/rmdir/link/symlink/readlink/touch/permissions e TO-CTOU, fornendo "prove di miglioramento dell'exploitability" per il bypass del percorso e lo sfruttamento della catena di scrittura (non sostituisce il sub-auditing del sink FILE/UPLOAD/WRITE).
