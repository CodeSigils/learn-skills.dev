Инструмент аудита работы файловой системы PHP. Сосредоточен на рисках безопасности mkdir/chmod/chown/uninlink/rmdir/link/symlink/readlink/touch/permissions и TO-CTOU, предоставляя «доказательства, повышающие возможности использования» для обхода пути и эксплуатации цепочки записи (не заменяет под-аудит приемника FILE/UPLOAD/WRITE).
