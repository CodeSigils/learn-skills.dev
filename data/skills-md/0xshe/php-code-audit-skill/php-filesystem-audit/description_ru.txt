Инструмент аудита работы файловой системы PHP. Он фокусируется на рисках безопасности таких операций, как mkdir, chmod, chown, unlink, rmdir, link, symlink, readlink, touch, Permissions и TOCTOU, предоставляя «расширенные доказательства возможности использования» для обходов проверки пути и эксплойтов цепочки записи (не заменяя субаудиты приемников FILE/UPLOAD/WRITE).
