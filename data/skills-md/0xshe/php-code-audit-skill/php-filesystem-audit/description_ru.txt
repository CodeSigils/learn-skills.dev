Инструмент аудита работы файловой системы PHP. Сосредоточен на рисках безопасности, связанных с mkdir/chmod/chown/unlink/rmdir/link/symlink/readlink/touch/permissions и проблемами TOCTOU, предоставляя «доказательства, повышающие возможности использования» для обходов проверки пути и эксплуатации цепочки записи (не заменяет субаудиты приемников FILE/UPLOAD/WRITE).
