Инструмент аудита работы файловой системы PHP. Он фокусируется на рисках безопасности таких операций, как mkdir, chmod, chown, unlink, rmdir, link, symlink, readlink, touch, Permissions и TOCTOU, предоставляя «расширенные доказательства возможности использования» для обхода проверки пути и эксплуатации цепочки записи (не заменяет субаудиты для приемников FILE/UPLOAD/WRITE).
