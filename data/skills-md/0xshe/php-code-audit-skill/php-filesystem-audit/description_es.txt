Herramienta de auditoría de operación del sistema de archivos PHP. Se centra en los riesgos de seguridad de mkdir/chmod/chown/unlink/rmdir/link/symlink/readlink/touch/permissions y problemas de TOCTOU, proporcionando "evidencia de mejora de la explotabilidad" para omisiones de validación de ruta y explotación de cadena de escritura (no reemplaza las subauditorías de receptores de ARCHIVO/CARGA/ESCRITURA).
