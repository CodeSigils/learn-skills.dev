Herramienta de auditoría del funcionamiento del sistema de archivos PHP. Se centra en los riesgos de seguridad de operaciones como mkdir, chmod, chown, unlink, rmdir, link, symlink, readlink, touch, permisos y TOCTOU, proporcionando “evidencia de explotabilidad mejorada” para eludir la validación de ruta y la explotación de la cadena de escritura (no reemplaza las subauditorías para los receptores de ARCHIVO/CARGA/ESCRITURA).
