Herramienta de auditoría de operación del sistema de archivos PHP. Se centra en los riesgos de seguridad de operaciones como mkdir, chmod, chown, unlink, rmdir, link, symlink, readlink, touch, permisos y TOCTOU, proporcionando “evidencia de explotabilidad mejorada” para omisiones de validación de ruta y exploits de cadena de escritura (no reemplaza las subauditorías de sumideros de ARCHIVO/CARGA/ESCRITURA).
