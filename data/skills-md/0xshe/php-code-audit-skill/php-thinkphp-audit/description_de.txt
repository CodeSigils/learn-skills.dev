ThinkPHP Framework Vulnerability Security Audit Tool. Führt statische White-Box-Prüfungen der allgemeinen Authentifizierungs-/CSRF-/Vorlagen-Escape-/ORM-Schreib- (Massenzuweisungs-)/Debug- und Konfigurations-Offenlegungsmechanismen von ThinkPHP durch und ordnet sie einem universellen Schwachstellentypsystem zu (AUTH/CSRF/TPL/XSS/LOGIC/CFG/SESS/SQL usw.).
