ThinkPHP-Framework-Sicherheitsüberwachungstool. Es führt eine statische White-Box-Analyse gängiger ThinkPHP-Mechanismen wie Authentifizierung, CSRF, Template-Escape, ORM-Schreibvorgänge (Massenzuweisung), Debugging und Konfigurationsoffenlegung durch und ordnet die Ergebnisse einer generischen Schwachstellentaxonomie zu (AUTH/CSRF/TPL/XSS/LOGIC/CFG/SESS/SQL usw.).
