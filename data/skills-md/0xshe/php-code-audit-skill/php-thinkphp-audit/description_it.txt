Strumento di controllo della sicurezza delle vulnerabilità del framework ThinkPHP. Esegue controlli statici white-box sui meccanismi comuni di autenticazione/CSRF/fuga di modelli/scrittura ORM (assegnazione di massa)/debug ed esposizione della configurazione comuni di ThinkPHP e li mappa su un sistema di tipo di vulnerabilità universale (AUTH/CSRF/TPL/XSS/LOGIC/CFG/SESS/SQL, ecc.).
