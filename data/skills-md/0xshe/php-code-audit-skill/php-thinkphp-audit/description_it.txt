Strumento di controllo della sicurezza del framework ThinkPHP. Conduce analisi statiche white-box dei meccanismi ThinkPHP comuni come autenticazione, CSRF, template escaping, scritture ORM (assegnazione di massa), debug ed esposizione della configurazione e mappa i risultati su una tassonomia di vulnerabilità generica (AUTH/CSRF/TPL/XSS/LOGIC/CFG/SESS/SQL, ecc.).
