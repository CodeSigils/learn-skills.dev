Outil d'audit de sécurité spécifique au framework ThinkPHP. Effectue une analyse statique en boîte blanche sur les mécanismes ThinkPHP courants tels que l'authentification/CSRF/échappement de modèle/écriture ORM (affectation de masse)/débogage et exposition de configuration, et les mappe à une taxonomie de vulnérabilité universelle (AUTH/CSRF/TPL/XSS/LOGIC/CFG/SESS/SQL, etc.).
