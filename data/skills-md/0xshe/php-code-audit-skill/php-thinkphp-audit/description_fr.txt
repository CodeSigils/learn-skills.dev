Outil d'audit de sécurité des vulnérabilités du framework ThinkPHP. Effectue des audits statiques en boîte blanche sur les mécanismes communs d'authentification/CSRF/échappement de modèle/écriture ORM (affectation de masse)/débogage et configuration de ThinkPHP, et les mappe à un système de type de vulnérabilité universel (AUTH/CSRF/TPL/XSS/LOGIC/CFG/SESS/SQL, etc.).
