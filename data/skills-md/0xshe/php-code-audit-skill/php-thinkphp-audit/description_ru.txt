Инструмент аудита безопасности, специфичный для платформы ThinkPHP. Выполняет статический анализ «белого ящика» общих механизмов ThinkPHP, таких как аутентификация/CSRF/экранирование шаблонов/запись ORM (массовое назначение)/отладка и раскрытие конфигурации, и сопоставляет их с универсальной таксономией уязвимостей (AUTH/CSRF/TPL/XSS/LOGIC/CFG/SESS/SQL и т. д.).
