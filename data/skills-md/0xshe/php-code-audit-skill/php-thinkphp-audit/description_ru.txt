Инструмент аудита безопасности уязвимостей ThinkPHP Framework. Выполняет статический аудит «белого ящика» общих механизмов аутентификации, CSRF, экранирования шаблонов, записи ORM (массовое назначение) / отладки и раскрытия конфигурации ThinkPHP и сопоставляет их с универсальной системой типов уязвимостей (AUTH/CSRF/TPL/XSS/LOGIC/CFG/SESS/SQL и т. д.).
