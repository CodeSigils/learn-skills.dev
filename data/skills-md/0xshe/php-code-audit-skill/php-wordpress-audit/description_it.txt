Strumento di controllo della sicurezza con effetti speciali del framework WordPress. Esegue un controllo statico white-box sui comuni nonce/capability/check_admin_referer di WordPress, azioni AJAX, escape/sanitize, reindirizzamenti, caricamenti sicuri e meccanismi di richiesta remota e li mappa su un sistema di tipo di vulnerabilità universale (AUTH/CSRF/XSS/SQL/CFG/SSRF, ecc.).
