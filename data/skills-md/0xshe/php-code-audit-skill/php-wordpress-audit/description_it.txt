Strumento di controllo della sicurezza degli effetti speciali del framework WordPress. Conduce controlli statici white-box dei meccanismi WordPress comuni come nonce/capability/check_admin_referer, azioni AJAX, escape/sanitizzazione, reindirizzamenti, caricamenti sicuri e richieste remote e mappa i risultati su una tassonomia di vulnerabilità generica (AUTH/CSRF/XSS/SQL/CFG/SSRF, ecc.).
