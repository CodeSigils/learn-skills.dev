Strumento avanzato di controllo della sicurezza del framework WordPress. Esegue un'analisi statica white-box dei meccanismi WordPress comuni come nonce, funzionalità, check_admin_referer, azioni AJAX, escape/sanificazione, reindirizzamenti, caricamenti sicuri e richieste remote e mappa i risultati su una tassonomia di vulnerabilità generica (AUTH/CSRF/XSS/SQL/CFG/SSRF, ecc.).
