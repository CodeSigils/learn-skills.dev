أداة تدقيق الأمان المتقدمة لإطار عمل WordPress. فهو يقوم بإجراء تحليل ثابت للمربع الأبيض لآليات WordPress الشائعة مثل الأرقام والإمكانات وcheck_admin_referer وإجراءات AJAX والهروب/التعقيم وعمليات إعادة التوجيه والتحميلات الآمنة والطلبات عن بُعد وتعيين النتائج إلى تصنيف عام للثغرات الأمنية (AUTH/CSRF/XSS/SQL/CFG/SSRF، وما إلى ذلك).
