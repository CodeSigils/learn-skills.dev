أداة التدقيق الأمني ​​ذات التأثيرات الخاصة لإطار عمل WordPress. وهو يجري عمليات تدقيق ثابتة على شكل مربع أبيض لآليات WordPress الشائعة مثل nonce/capability/check_admin_referer، وإجراءات AJAX، والهروب/التعقيم، وعمليات إعادة التوجيه، والتحميلات الآمنة، والطلبات عن بُعد، وتعيين النتائج إلى تصنيف عام للثغرات الأمنية (AUTH/CSRF/XSS/SQL/CFG/SSRF، وما إلى ذلك).
