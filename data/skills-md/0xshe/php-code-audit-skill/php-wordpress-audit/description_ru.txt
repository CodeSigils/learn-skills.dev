Инструмент аудита безопасности WordPress Framework Effects. Выполняет статический анализ «белого ящика» для общих номеров Worders nonce/capability/check_admin_referer, действий AJAX, экранирования/очистки, перенаправлений, безопасных загрузок и механизмов удаленных запросов, сопоставляя результаты с общей таксономией типов уязвимостей (AUTH/CSRF/XSS/CFG/SSRF).
