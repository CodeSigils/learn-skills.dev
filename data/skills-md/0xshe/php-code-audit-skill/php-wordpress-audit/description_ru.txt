Специальный инструмент аудита безопасности WordPress Framework. Выполняет статический аудит «белого ящика» для общих nonce/capability/check_admin_referer WordPress, действий AJAX, escape/sanitize, перенаправлений, безопасных загрузок и механизмов удаленных запросов, а также сопоставляет их с универсальной системой типов уязвимостей (AUTH/CSRF/XSS/SQL/CFG/SSRF и т. д.).
