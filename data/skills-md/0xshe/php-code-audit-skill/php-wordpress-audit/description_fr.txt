Outil d'audit de sécurité à effets spéciaux du framework WordPress. Effectue un audit statique en boîte blanche sur les mécanismes nonce/capability/check_admin_referer, AJAX, escape/sanitize, redirections, téléchargements sécurisés et mécanismes de requête à distance courants de WordPress, et les mappe à un système de type de vulnérabilité universel (AUTH/CSRF/XSS/SQL/CFG/SSRF, etc.).
