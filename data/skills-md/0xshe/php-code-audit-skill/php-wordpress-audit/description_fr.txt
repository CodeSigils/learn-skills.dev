Outil d’audit de sécurité avancé du framework WordPress. Il effectue une analyse statique en boîte blanche des mécanismes WordPress courants tels que les noms occasionnels, les capacités, check_admin_referer, les actions AJAX, l'échappement/la désinfection, les redirections, les téléchargements sécurisés et les requêtes à distance, et mappe les résultats à une taxonomie générique de vulnérabilité (AUTH/CSRF/XSS/SQL/CFG/SSRF, etc.).
