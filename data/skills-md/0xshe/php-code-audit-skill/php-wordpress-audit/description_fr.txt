Outil d'audit de sécurité des effets spéciaux du framework WordPress. Il effectue des audits statiques en boîte blanche des mécanismes WordPress courants tels que nonce/capability/check_admin_referer, les actions AJAX, l'échappement/la désinfection, les redirections, les téléchargements sécurisés et les requêtes à distance, et mappe les résultats à une taxonomie générique de vulnérabilité (AUTH/CSRF/XSS/SQL/CFG/SSRF, etc.).
