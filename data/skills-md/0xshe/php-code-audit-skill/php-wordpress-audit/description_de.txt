WordPress Framework Effects Security Audit Tool. Führt eine statische White-Box-Analyse für gängige Wörter wie nonce/capability/check_admin_referer, AJAX-Aktionen, Escape/Sanitize, Weiterleitungen, sichere Uploads und Remote-Request-Mechanismen durch und ordnet die Ergebnisse der allgemeinen Taxonomie der Schwachstellentypen (AUTH/CSRF/XSS/CFG/SSRF) zu.
