Spezialeffekt-Sicherheitsaudit-Tool für das WordPress-Framework. Führt statisches White-Box-Auditing für WordPresss allgemeine Nonce/Capability/check_admin_referer-, AJAX-Aktionen, Escape/Sanitize-, Weiterleitungen, sichere Uploads und Remote-Anforderungsmechanismen durch und ordnet sie einem universellen Schwachstellentypsystem (AUTH/CSRF/XSS/SQL/CFG/SSRF usw.) zu.
