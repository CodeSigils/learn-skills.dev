Outil d'audit XSS du code source Web PHP. Identifie les entrées de l'utilisateur entrant dans les contextes de sortie (HTML/attribut/JS/URL/modèle), analyse les stratégies d'échappement et de protection et fournit des recommandations d'évaluation de l'exploitabilité, de PoC et de remédiation (aucune omission autorisée).
