Инструмент XSS-аудита веб-исходного кода PHP. Идентифицирует вводимые пользователем данные, входящие в выходные контексты (HTML/атрибут/JS/URL/шаблон), анализирует стратегии экранирования и защиты, выводит уровни уязвимости выходных данных, PoC и предложения по исправлению (упущения не допускаются).
