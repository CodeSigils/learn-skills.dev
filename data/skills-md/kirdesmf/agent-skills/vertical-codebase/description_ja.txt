垂直 (ドメインファースト) コードベース アーキテクチャを任意のプロジェクトに適用します。ユーザーがファイルの配置場所、コードベースの構造化方法、機能またはドメインごとにコードを整理する方法、「水平」構造 (components/、hooks/、utils/、types/) をリファクタリングする方法を尋ねる場合、またはコードのコロケーション、モノリポジトリの境界、共有コード、またはモジュールの所有権について尋ねる場合には、このスキルを使用してください。また、ユーザーが新しいモジュールを作成し、それが属する場所を決定する必要があるとき、またはファイル構成に関係する PR を確認するときにもトリガーされます。 React やフロントエンドだけでなく、あらゆる言語やフレームワーク (Python、TypeScript、Go、Rust など) で動作します。
