Applica l'architettura codebase verticale (prima del dominio) a qualsiasi progetto. Utilizza questa competenza ogni volta che un utente chiede dove inserire un file, come strutturare una base di codice, come organizzare il codice per funzionalità o dominio, come eseguire il refactoring di una struttura "orizzontale" (componenti/, hook/, utils/, tipi/) o chiede informazioni sulla coubicazione del codice, sui limiti del monorepo, sul codice condiviso o sulla proprietà del modulo. Si attiva anche quando l'utente crea un nuovo modulo e deve decidere a chi appartiene o quando esamina un PR che tocca l'organizzazione dei file. Funziona con qualsiasi linguaggio o framework (Python, TypeScript, Go, Rust, ecc.), non solo React o frontend.
