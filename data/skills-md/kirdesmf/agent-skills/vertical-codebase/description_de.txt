Wenden Sie eine vertikale (domänenorientierte) Codebasisarchitektur auf jedes Projekt an. Verwenden Sie diese Fähigkeit immer dann, wenn ein Benutzer fragt, wo eine Datei abgelegt werden soll, wie eine Codebasis strukturiert wird, wie Code nach Feature oder Domäne organisiert wird, wie eine „horizontale“ Struktur (Komponenten/, Hooks/, Utils/, Typen/) umgestaltet wird oder nach Code-Colocation, Monorepo-Grenzen, gemeinsam genutztem Code oder Modulbesitz fragt. Wird auch ausgelöst, wenn der Benutzer ein neues Modul erstellt und entscheiden muss, wo es hingehört, oder wenn er eine PR überprüft, die die Dateiorganisation berührt. Funktioniert für jede Sprache oder jedes Framework (Python, TypeScript, Go, Rust usw.) – nicht nur React oder Frontend.
