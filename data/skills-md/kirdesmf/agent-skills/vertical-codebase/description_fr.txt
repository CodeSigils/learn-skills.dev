Appliquez une architecture de base de code verticale (domaine d'abord) à n'importe quel projet. Utilisez cette compétence chaque fois qu'un utilisateur demande où placer un fichier, comment structurer une base de code, comment organiser le code par fonctionnalité ou domaine, comment refactoriser une structure « horizontale » (composants/, hooks/, utils/, types/), ou pose des questions sur la colocalisation du code, les limites du monorepo, le code partagé ou la propriété du module. Déclenchez également lorsque l'utilisateur crée un nouveau module et doit décider à quoi il appartient, ou lors de l'examen d'un PR qui touche à l'organisation des fichiers. Fonctionne pour n'importe quel langage ou framework (Python, TypeScript, Go, Rust, etc.) – pas seulement React ou frontend.
