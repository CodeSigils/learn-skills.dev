Aplique una arquitectura de base de código vertical (primero el dominio) a cualquier proyecto. Utilice esta habilidad siempre que un usuario pregunte dónde colocar un archivo, cómo estructurar una base de código, cómo organizar el código por característica o dominio, cómo refactorizar una estructura "horizontal" (componentes/, ganchos/, utilidades/, tipos/), o pregunte sobre la colocación del código, los límites de monorepo, el código compartido o la propiedad del módulo. También se activa cuando el usuario crea un nuevo módulo y necesita decidir a dónde pertenece, o cuando revisa un PR que afecta a la organización de archivos. Funciona para cualquier lenguaje o marco (Python, TypeScript, Go, Rust, etc.), no solo para React o frontend.
