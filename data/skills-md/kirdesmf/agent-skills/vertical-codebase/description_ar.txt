قم بتطبيق بنية قاعدة التعليمات البرمجية الرأسية (المجال أولاً) على أي مشروع. استخدم هذه المهارة عندما يسأل المستخدم عن مكان وضع ملف، أو كيفية هيكلة قاعدة التعليمات البرمجية، أو كيفية تنظيم التعليمات البرمجية حسب الميزة أو المجال، أو كيفية إعادة بناء بنية "أفقية" (المكونات/، الخطافات/، الأدوات/، الأنواع/)، أو يسأل عن موقع التعليمات البرمجية، أو حدود monorepo، أو التعليمات البرمجية المشتركة، أو ملكية الوحدة النمطية. يتم تشغيله أيضًا عندما يقوم المستخدم بإنشاء وحدة نمطية جديدة ويحتاج إلى تحديد المكان الذي تنتمي إليه، أو عند مراجعة العلاقات العامة التي تمس تنظيم الملفات. يعمل مع أي لغة أو إطار عمل (Python، وTypeScript، وGo، وRust، وما إلى ذلك) - وليس فقط React أو الواجهة الأمامية.
