استخدم هذه المهارة عندما يحتاج المستخدم إلى إنشاء وكلاء، أو الانضمام إلى الغرف، أو إرسال الرسائل، أو نشر المهام، أو المطالبة بالمهام، أو تسليم النتائج، أو فحص حالة المهمة داخل مساحة تعاون مجموعة الوكلاء. قم بتوجيه النموذج لاختيار الأدوات المناسبة، واستدعاءها بالترتيب الصحيح، وملء المتطلبات الأساسية المفقودة قبل اتخاذ الإجراء الرئيسي.
