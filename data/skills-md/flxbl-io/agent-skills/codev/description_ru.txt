Рабочие процессы разработки Salesforce для sf-core, поддерживаемые пулом разработчиков sfp. Три режима: (1) реализация автономной комплексной сборки/исправления в новой песочнице с развертыванием и отчетом; (2) выборка из песочницы, получение новой песочницы для специальной работы, такой как исследование, отладка, ручное тестирование; (3) Открыть песочницу, повторно открыть уже назначенную вам песочницу. Используйте, когда пользователь запрашивает сборку/исправление в этом репозитории, запрашивает песочницу/организацию или просит повторно открыть ту, которая у него уже есть.
