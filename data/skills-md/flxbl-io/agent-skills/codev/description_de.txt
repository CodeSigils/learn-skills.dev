Salesforce-Entwicklungsworkflows für SF-Core, unterstützt durch den SFP-Entwicklerpool. Drei Modi – (1) Implementierung eines autonomen End-to-End-Builds/Fix auf einer neuen Sandbox mit Bereitstellung und Bericht; (2) Sandbox-Abruf: Schnappen Sie sich eine neue Sandbox für Ad-hoc-Arbeiten wie Erkunden, Debuggen und manuelles Testen; (3) sandbox-open: Öffnen Sie eine Ihnen bereits zugewiesene Sandbox erneut. Verwenden Sie diese Option, wenn der Benutzer dieses Repo erstellen/reparieren möchte, nach einer Sandbox/Organisation fragt oder eine bereits vorhandene Sandbox/Organisation erneut öffnen möchte.
