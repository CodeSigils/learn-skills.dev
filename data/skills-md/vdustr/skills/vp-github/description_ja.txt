Git 操作ではない GitHub プラットフォームの動作を操作します。画像、ビデオ、またはファイルを課題、プル リクエスト、コメントに添付します。 GitHub サーフェス上で Markdown がどのようにレンダリングされるかを制御します。そして、エンドポイントに到達できる資格情報を選択します。 GitHub 上でローカル アーティファクトをアップロード、添付、埋め込み、または表示するリクエストに使用します。また、GitHub コンテンツを作成または編集する場合にも積極的に使用し、利用可能なスクリーンショット、記録、図、またはその他のローカル ファイルは、ユーザーが「アップロード」と言わなかった場合でも重要な証拠となります。境界: ローカル Git 作業には vp-git、スタックには vp-stacked-pr、レビュー ワークフローには vp-pr-* スキルを使用します。
