Arbeiten Sie mit dem Verhalten der GitHub-Plattform, das kein Git-Vorgang ist: Anhängen von Bildern, Videos oder Dateien an Issues, Pull Requests und Kommentare; Steuern, wie Markdown auf GitHub-Oberflächen gerendert wird; und Auswahl eines Berechtigungsnachweises, der den Endpunkt erreichen kann. Für jede Anfrage zum Hochladen, Anhängen, Einbetten oder Anzeigen eines lokalen Artefakts auf GitHub verwenden. Verwenden Sie es auch proaktiv, wenn Sie GitHub-Inhalte schreiben oder bearbeiten. Ein verfügbarer Screenshot, eine Aufzeichnung, ein Diagramm oder eine andere lokale Datei würde einen wesentlichen Beweis liefern, selbst wenn der Benutzer nicht „Hochladen“ gesagt hat. Grenze: Verwenden Sie vp-git für lokale Git-Arbeit, vp-stacked-pr für Stacks und die vp-pr-*-Fähigkeiten für Review-Workflows.
