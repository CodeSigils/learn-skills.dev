Travailler avec le comportement de la plateforme GitHub qui n'est pas une opération Git : joindre des images, des vidéos ou des fichiers à des problèmes, des demandes d'extraction et des commentaires ; contrôler le rendu de Markdown sur les surfaces GitHub ; et choisir un identifiant qui peut atteindre le point final. À utiliser pour toute demande de téléchargement, de pièce jointe, d'intégration ou d'affichage d'un artefact local sur GitHub. Utilisez également de manière proactive lors de l'écriture ou de la modification du contenu GitHub et une capture d'écran, un enregistrement, un diagramme ou tout autre fichier local disponible fournirait une preuve matérielle, même lorsque l'utilisateur n'a pas dit « télécharger ». Limite : utilisez vp-git pour le travail Git local, vp-stacked-pr pour les piles et les compétences vp-pr-* pour les workflows de révision.
