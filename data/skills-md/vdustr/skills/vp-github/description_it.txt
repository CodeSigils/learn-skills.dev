Utilizzare il comportamento della piattaforma GitHub che non sia un'operazione Git: allegare immagini, video o file a problemi, richieste pull e commenti; controllare il modo in cui Markdown esegue il rendering sulle superfici GitHub; e scegliendo una credenziale che possa raggiungere l'endpoint. Utilizzare per qualsiasi richiesta di caricare, allegare, incorporare o mostrare un artefatto locale su GitHub. Utilizzalo anche in modo proattivo quando scrivi o modifichi contenuti GitHub e uno screenshot, una registrazione, un diagramma o un altro file locale disponibile fornirà prove materiali, anche quando l'utente non ha detto "carica". Limite: utilizzare vp-git per il lavoro Git locale, vp-stacked-pr per gli stack e le competenze vp-pr-* per i flussi di lavoro di revisione.
