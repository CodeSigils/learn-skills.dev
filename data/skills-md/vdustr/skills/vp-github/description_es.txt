Trabajar con el comportamiento de la plataforma GitHub que no es una operación de Git: adjuntar imágenes, vídeos o archivos a incidencias, solicitudes de extracción y comentarios; controlar cómo se representa Markdown en las superficies de GitHub; y elegir una credencial que pueda llegar al punto final. Úselo para cualquier solicitud para cargar, adjuntar, incrustar o mostrar un artefacto local en GitHub. Úselo también de manera proactiva al escribir o editar contenido de GitHub y una captura de pantalla, grabación, diagrama u otro archivo local disponible proporcionaría evidencia material, incluso cuando el usuario no dijo "cargar". Límite: utilice vp-git para el trabajo de Git local, vp-stacked-pr para pilas y las habilidades vp-pr-* para revisar flujos de trabajo.
