العمل باستخدام سلوك النظام الأساسي GitHub الذي لا يمثل عملية Git: إرفاق الصور أو مقاطع الفيديو أو الملفات بالمشكلات، وسحب الطلبات، والتعليقات؛ والتحكم في كيفية عرض Markdown على أسطح GitHub؛ واختيار بيانات الاعتماد التي يمكنها الوصول إلى نقطة النهاية. يُستخدم لأي طلب لتحميل قطعة أثرية محلية أو إرفاقها أو تضمينها أو إظهارها على GitHub. استخدم أيضًا بشكل استباقي عند كتابة أو تحرير محتوى GitHub وستوفر لقطة الشاشة أو التسجيل أو الرسم التخطيطي أو أي ملف محلي آخر دليلاً ماديًا، حتى عندما لم يقل المستخدم "تحميل". الحدود: استخدم vp-git لعمل Git المحلي، وvp-stacked-pr للمكدسات، ومهارات vp-pr-* لمراجعة سير العمل.
