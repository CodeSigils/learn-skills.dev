Erfassen Sie Software als Datei: einen Standbild-Screenshot einer laufenden Benutzeroberfläche, eine skriptgesteuerte Browser-Komplettlösung mit sichtbarem Cursor und Untertiteln, eine bildgenaue Darstellung generierter oder mathematischer Bewegungen oder eine macOS-Fensteraufnahme. Verwenden Sie diese Option für Screenshots, Vorher-Nachher-Bilder, Demovideos, Screencasts, Komplettlösungen, animierte GIFs, eine Fehlerreproduktion, die als Bild oder Video bereitgestellt werden muss, und jede Anfrage zum Aufzeichnen, Filmen, Screenshots oder Zeigen, was eine Schnittstelle tut, einschließlich einer Benutzeroberfläche hinter einem Login. Jeder Pfad endet an einer Datei auf der Festplatte. Die Browserpfade, Standbild und Video, sowie der Renderpfad sind plattformübergreifend, allerdings benötigt ein Standbild hinter einer Anmeldung eine Anzeige; Das Aufnehmen eines nativen Fensters, Standbild oder Video, ist nur für macOS möglich. Grenze: Verwenden Sie vp-minimal-repro für eine erneut ausführbare Reproduktion, die kein Bild benötigt, und vp-github, um das Ergebnis an ein Issue oder eine Pull-Anfrage anzuhängen.
