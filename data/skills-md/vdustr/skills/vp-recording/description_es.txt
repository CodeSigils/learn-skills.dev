Capture software como un archivo: una captura de pantalla fija de una interfaz en ejecución, un recorrido de navegador escrito con un cursor y subtítulos visibles, una representación con precisión de cuadro de movimiento generado o matemático, o una captura de ventana de macOS. Úselo para capturas de pantalla, imágenes de antes y después, videos de demostración, screencasts, recorridos, GIF animados, una reproducción de errores que debe entregarse como una imagen o un video y cualquier solicitud para grabar, filmar, capturar o mostrar lo que está haciendo una interfaz, incluida una interfaz de usuario detrás de un inicio de sesión. Cada ruta termina en un archivo en el disco. Las rutas del navegador, imágenes fijas y de vídeo, y la ruta de renderizado son multiplataforma, aunque una imagen fija detrás de un inicio de sesión necesita una pantalla; capturar una ventana nativa, fija o de vídeo, es solo para macOS. Límite: use vp-minimal-repro para una reproducción ejecutable nuevamente que no necesita imagen, y vp-github para adjuntar el resultado a una incidencia o solicitud de extracción.
