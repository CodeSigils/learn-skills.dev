Recherchez la documentation ArcGIS auprès de sources autoritaires d’Esri et vérifiez qu’une API existe à une version spécifiée. Utilisez cela lorsque l’utilisateur a besoin d’une référence API ArcGIS, de documents ArcGIS Pro, Enterprise ou Notebook Server, ou lorsqu’une autre compétence doit confirmer qu’une classe, une méthode, un global ou une fonction est disponible dans la version cible.
