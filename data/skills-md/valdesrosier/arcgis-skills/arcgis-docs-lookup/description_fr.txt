Consultez la documentation ArcGIS en vous référant aux sources autorisées d’Esri et vérifiez qu’une API existe à la version spécifiée. Utilisez cette approche lorsque l’utilisateur a besoin d’une référence d’API ArcGIS, de documents ArcGIS Pro, Enterprise ou Notebook Server, ou lorsqu’une autre compétence doit confirmer qu’une classe, une méthode, un global ou une fonction est disponible à la version cible.
