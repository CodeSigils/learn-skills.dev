ابحث في وثائق ArcGIS مقابل المصادر الموثوقة من Esri وتحقق من وجود واجهة برمجة التطبيقات في النسخة المحددة. استخدم ذلك عندما يحتاج المستخدم إلى مرجع API ل‑ArcGIS، أو وثائق ArcGIS Pro، أو Enterprise، أو Notebook Server، أو عندما تحتاج مهارة أخرى إلى التأكد من توفر فئة أو طريقة أو عنصر عالمي أو دالة في النسخة المستهدفة.
