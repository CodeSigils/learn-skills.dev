Cerca la documentazione di ArcGIS nelle fonti autorevoli di Esri e verifica che un’API esista in una versione specificata. Usa queste indicazioni quando l’utente ha bisogno di un riferimento API di ArcGIS, della documentazione di ArcGIS Pro, Enterprise o Notebook Server, o quando un’altra competenza deve confermare che una classe, un metodo, un elemento globale o una funzione siano disponibili nella versione target.

Per favore, rispondi sempre nella lingua dell’utente.
