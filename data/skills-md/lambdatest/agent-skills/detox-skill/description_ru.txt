Генерирует тесты Detox E2E для приложений React Native на JavaScript. Платформа тестирования «серого ящика» с автоматической синхронизацией. Поддерживает локальные симуляторы/эмуляторы и облако TestMu AI. Используйте, когда пользователь упоминает «Детокс», «Тест React Native», «element(by.id())», «device.launchApp». Запускается по: «Детокс», «React Native E2E», «Тест React Native», «element(by.id)», «device.launchApp».
