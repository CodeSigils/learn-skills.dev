Appliquez les normes de développement de l'entreprise Going2 lors de l'écriture, de la révision ou de la génération de code. Utilisez cette compétence chaque fois que l'utilisateur demande à créer un nouveau module, entité, service, contrôleur, composant, hook, page, formulaire, test ou tout autre morceau de code dans un projet backend NestJS ou frontend Next.js. Déclenchez également lorsque l'utilisateur demande d'échafauder une fonctionnalité, de refactoriser le code existant pour qu'il corresponde aux normes ou lorsqu'il fait référence au passe-partout du projet. Même si l'utilisateur ne dit pas explicitement « suivre les normes », appliquez cette compétence chaque fois que vous écrivez du code dans cette base de code : la cohérence est importante dans toute l'équipe.
