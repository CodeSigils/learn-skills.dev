Setzen Sie die Entwicklungsstandards des Unternehmens Going2 durch, wenn Sie Code schreiben, überprüfen oder generieren. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein neues Modul, eine neue Entität, einen neuen Dienst, einen neuen Controller, eine neue Komponente, einen neuen Hook, eine neue Seite, ein neues Formular, einen neuen Test oder einen beliebigen Codeabschnitt in einem NestJS-Backend- oder Next.js-Frontend-Projekt erstellen möchte. Wird auch ausgelöst, wenn der Benutzer ein Gerüst für eine Funktion erstellen, vorhandenen Code so umgestalten möchte, dass er Standards entspricht, oder wenn er auf den Projektbaustein verweist. Auch wenn der Benutzer nicht ausdrücklich „Standards befolgen“ sagt, wenden Sie diese Fähigkeit immer dann an, wenn Sie Code in dieser Codebasis schreiben – Konsistenz ist für das gesamte Team wichtig.
