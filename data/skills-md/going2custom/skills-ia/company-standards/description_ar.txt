فرض معايير تطوير شركة Going2 عند كتابة التعليمات البرمجية أو مراجعتها أو إنشاؤها. استخدم هذه المهارة عندما يطلب المستخدم إنشاء وحدة نمطية جديدة أو كيان أو خدمة أو وحدة تحكم أو مكون أو خطاف أو صفحة أو نموذج أو اختبار أو أي جزء من التعليمات البرمجية في الواجهة الخلفية لـ NestJS أو مشروع الواجهة الأمامية لـ Next.js. يتم التشغيل أيضًا عندما يطلب المستخدم دعم ميزة ما، أو إعادة بناء التعليمات البرمجية الموجودة لمطابقة المعايير، أو عندما يشيرون إلى النموذج المعياري للمشروع. حتى إذا لم يقل المستخدم صراحةً "اتبع المعايير"، فقم بتطبيق هذه المهارة عندما تكتب تعليمات برمجية في قاعدة التعليمات البرمجية هذه - فالاتساق مهم عبر الفريق بأكمله.
