Entretien de conception UX -> Spécification UX (flux, écrans, états, composants, a11y). Déclencheurs : « concevoir l'UX », « quels écrans », « comment les utilisateurs doivent interagir », post-PRD/glossaire. Facultatif : fonctionnalités de l'interface utilisateur uniquement. Pas pour : la conception technique (design-feature), les exigences (write-a-prd), la révision du plan (review-plan).
