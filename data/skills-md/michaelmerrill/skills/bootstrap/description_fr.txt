Initialisez de nouvelles bases de code : projet autonome, monorepo ou nouvelle application/package/service dans le dépôt existant. Entretien + héritage de la convention + échafaudage + documents de fondation. Déclencheurs : « nouveau projet », « bootstrap », « init », « échafaudage », « ajouter une application », « ajouter un package », « nouveau service », greenfield, répertoire vide. Pas pour : l'ajout de fonctionnalités (découverte), le déploiement (déploiement sur Vercel), les hooks sur les dépôts existants (installation-pré-commit).
