Úselo al desarrollar funciones desde problemas de GitHub/GitLab hasta PR/MR fusionados con ciclos de revisión iterativos.
Cubre: investigación de problemas, planificación de implementación, aislamiento del árbol de trabajo, codificación, pruebas, creación de PR/MR,
revisión de código de múltiples revisores (agente actual, ejecutivo de codex, claude -p), bucles de revisión de arreglos hasta APROBAR,
fusionar y limpiar. Componible con TDD, BDD, depuración sistemática y otras habilidades metodológicas.
Utilice esto siempre que: el usuario proporcione un número de problema (#NN), solicite implementar una característica de un problema,
quiere crear un PR/MR revisado o necesita que el código se revise de forma iterativa antes de fusionarlo.
Incluso si el usuario simplemente dice "implementar el número 42" o "trabajar en el problema 15", esta habilidad se aplica.
