Создает структурированные системы показателей найма для любой должности. Учитывает название должности, требования и контекст команды. Создает комплексную систему показателей со взвешенными критериями оценки, вопросами для собеседования по каждой компетенции, матрицей оценок, красными/зелеными флажками и вопросами для проверки рекомендаций.
