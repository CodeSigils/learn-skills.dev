Distribuisce sciami di agenti secondari per massicce attività di elaborazione dati parallela. A differenza di agent-army (che è per le modifiche al codice), questo è per le attività DATA: elaborazione di 1000 documenti, analisi di set di dati, generazione di contenuti in blocco. Dimensioni dello sciame, distribuzione delle attività, aggregazione dei risultati, monitoraggio dei progressi e ripristino degli errori configurabili.
