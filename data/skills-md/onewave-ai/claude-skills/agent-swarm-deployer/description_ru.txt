Развертывает множество субагентов для выполнения массовых задач параллельной обработки данных. В отличие от агентской армии (которая предназначена для изменения кода), это для задач ДАННЫХ — обработка 1000 документов, анализ наборов данных, массовая генерация контента. Настраиваемый размер роя, распределение задач, агрегирование результатов, отслеживание прогресса и устранение ошибок.
