Создает собственную модель оценки потенциальных клиентов для бизнеса. Принимает определение ICP, исторические данные о выигрышах/проигрышах, экспорт CRM. Анализирует, какие атрибуты коррелируют с закрытыми выигранными сделками. Создает файл Lead-scoring-model.md с параметрами оценки, значениями баллов, пороговыми значениями, руководством по внедрению CRM и методологией проверки. Также можно оценить группу текущих потенциальных клиентов по модели.
