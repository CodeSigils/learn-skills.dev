Использует контекстное окно 1M для приема всей базы кода и вывода плана миграции каждого файла. Поддерживает JS в TS, класс React для перехватов, миграцию фреймворков и многое другое. Создает миграцию-plan.md с инвентаризацией файлов, графиком зависимостей, порядком миграции, пофайловыми изменениями, предполагаемыми усилиями и оценкой рисков.
