Utilise la fenêtre contextuelle 1M pour ingérer une base de code entière et générer un plan de migration fichier par fichier. Prend en charge JS vers TS, la classe React vers les hooks, les migrations de framework, etc. Génère migration-plan.md avec l'inventaire des fichiers, le graphique des dépendances, l'ordre de migration, les modifications fichier par fichier, l'effort estimé et l'évaluation des risques.
