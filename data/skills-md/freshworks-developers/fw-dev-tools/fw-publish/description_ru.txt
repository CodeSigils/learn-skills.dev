Публикуйте любое пользовательское приложение Freshworks Platform 3.0 с помощью инструментов MCP: проверка/упаковка fdk, загрузка приложения и отправка/обновление через openai-server. Предварительная публикация: убедитесь, что JWT разработчика соответствует модулям манифеста продукта (Freshdesk support_* или Freshservice service_*; последовательный набор продуктов). Во время публикации спрашивайте новое или существующее объявление; для новых объявлений запрашивайте адрес электронной почты поддержки перед create_app_upload_url (обязательно для submit_custom_app). list_custom_apps для обновлений, поэтому разработчик выбирает appId, а затем передачу MCP (submit_custom_app или add_app_version с uploadId). Используйте, когда пользователь хочет разместить приложение на торговой площадке (тестирование), проверить статус публикации или перечислить существующие приложения. Соединитесь с fw-app-dev для исправлений манифеста или модуля. Работает с Cursor, Claude Code и любым клиентом, совместимым с MCP.
