Publique cualquier aplicación personalizada de Freshworks Platform 3.0 a través de herramientas MCP: validar/empaquetar fdk, cargar aplicaciones y enviar/actualizar a través de openai-server. Publicación previa: confirme que JWT del desarrollador coincida con los módulos de producto manifiesto (soporte de Freshdesk_* frente a servicio Freshservice_*; secuencial multiproducto). En el momento de la publicación, solicite listados nuevos versus existentes; para listados nuevos, solicite soporte por correo electrónico antes de create_app_upload_url (obligatorio para submit_custom_app). list_custom_apps para obtener actualizaciones, de modo que el desarrollador seleccione appId y luego la transferencia de MCP (submit_custom_app o add_app_version con uploadId). Úselo cuando el usuario quiera enviar una aplicación a Marketplace (prueba), verificar el estado de publicación o enumerar aplicaciones existentes. Emparéjelo con fw-app-dev para corregir manifiestos o módulos. Funciona con Cursor, Claude Code y cualquier cliente compatible con MCP.
