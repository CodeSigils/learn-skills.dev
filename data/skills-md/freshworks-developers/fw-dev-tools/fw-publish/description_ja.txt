MCP ツール (fdk validate/pack、app-upload、openai-server を介した送信/更新) を介して Freshworks Platform 3.0 カスタム アプリを公開します。事前公開: 開発者 JWT がマニフェスト製品モジュールと一致することを確認します (Freshdesk support_* と Freshservice service_*、複数製品のシーケンシャル)。公開時に、新しいリストと既存のリストを尋ねます。新しいリストの場合は、create_app_upload_url の前に supportEmail の入力を求めます (submit_custom_app に必要)。更新用の list_custom_apps により、開発者は appId を選択してから、MCP ハンドオーバー (submit_custom_app または UploadId を使用した add_app_version) を選択します。ユーザーがマーケットプレイスにアプリをプッシュ（テスト）する場合、公開ステータスを確認する場合、または既存のアプリを一覧表示する場合に使用します。マニフェストまたはモジュールを修正するには、fw-app-dev と組み合わせます。カーソル、クロード コード、および MCP 準拠のクライアントで動作します。
