Publiez n'importe quelle application personnalisée Freshworks Platform 3.0 via les outils MCP : fdk validate/pack, app-upload et submit/update via openai-server. Pré-publication : vérifiez que Developer JWT correspond aux modules de produit manifestes (support Freshdesk_* vs service Freshservice_* ; séquentiel multiproduit). Au moment de la publication, demandez une nouvelle liste par rapport à une liste existante ; pour les nouvelles annonces, demandez supportEmail avant create_app_upload_url (obligatoire pour submit_custom_app). list_custom_apps pour les mises à jour afin que le développeur sélectionne appId, puis le transfert MCP (submit_custom_app ou add_app_version avec uploadId). À utiliser lorsque l'utilisateur souhaite pousser une application vers Marketplace (test), vérifier l'état de publication ou répertorier les applications existantes. Associez-le à fw-app-dev pour les correctifs de manifeste ou de module. Fonctionne avec Cursor, Claude Code et tout client compatible MCP.
