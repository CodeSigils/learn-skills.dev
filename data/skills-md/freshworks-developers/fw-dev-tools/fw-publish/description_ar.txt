انشر أي تطبيق مخصص لـ Freshworks Platform 3.0 عبر أدوات MCP: التحقق من صحة/حزمة fdk، وتحميل التطبيق، والإرسال/التحديث من خلال خادم openai. النشر المسبق: تأكد من تطابق Developer JWT مع وحدات المنتج الواضحة (Freshdesk support_* مقابل Freshservice Service_*؛ تسلسل متعدد المنتجات). في وقت النشر، اسأل القائمة الجديدة مقابل القائمة الحالية؛ بالنسبة إلى القوائم الجديدة، اطلب الدعم عبر البريد الإلكتروني قبل create_app_upload_url (مطلوب لـ Submit_custom_app). list_custom_apps للحصول على التحديثات بحيث يحدد المطور معرف التطبيق، ثم تسليم MCP (submit_custom_app أو add_app_version مع معرف التحميل). يُستخدم عندما يريد المستخدم دفع تطبيق ما إلى Marketplace (اختبار)، أو التحقق من حالة النشر، أو إدراج التطبيقات الموجودة. قم بالاقتران مع fw-app-dev لإصلاحات البيان أو الوحدة. يعمل مع Cursor وClaude Code وأي عميل متوافق مع MCP.
