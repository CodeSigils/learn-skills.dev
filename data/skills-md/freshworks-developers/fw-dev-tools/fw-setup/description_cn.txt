通过 nvm 使用 Node.js 安装和管理 Freshworks 开发套件 (FDK)，以进行 Platform 3.0 开发。支持 FDK 10.x（节点 24，推荐）和 FDK 9.x（节点 18，已于 2026 年 5 月 31 日弃用）。斜杠命令：/fw-setup-install (--version)、/fw-setup-upgrade (--to)、/fw-setup-downgrade、/fw-setup-uninstall、/fw-setup-status (--verbose)、/fw-setup-troubleshoot (--fix)、/fw-setup-use（工作空间 nvm + .nvmrc）。旧版 `/fdk-install` → 使用 `/fw-setup-install` 等。发布需要 FDK 10.x + Node 24。
