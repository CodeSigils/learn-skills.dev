تثبيت وإدارة Freshworks Development Kit (FDK) مع Node.js عبر nvm لتطوير النظام الأساسي 3.0. يدعم FDK 10.x (العقدة 24، الموصى بها) وFDK 9.x (العقدة 18، ​​التي تم إهمالها في 31 مايو 2026). أوامر الشرطة المائلة: /fw-setup-install (--version)، و/fw-setup-upgrade (--to)، و/fw-setup-downgrade، و/fw-setup-uninstall، و/fw-setup-status (--verbose)، و/fw-setup-troubleshoot (--fix)، و/fw-setup-use (مساحة العمل nvm + .nvmrc). قديم `/fdk-install` → استخدم `/fw-setup-install`، وما إلى ذلك. يتطلب النشر FDK 10.x + Node 24.
