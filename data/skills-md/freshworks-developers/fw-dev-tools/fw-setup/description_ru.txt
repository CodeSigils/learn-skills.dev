Устанавливает и управляет комплектом разработки Freshworks (FDK) с Node.js через nvm для разработки на платформе 3.0. Поддерживает FDK 10.x (узел 24, рекомендуется) и FDK 9.x (узел 18, поддержка прекращена 31 мая 2026 г.). Слэш-команды: /fw-setup-install (--version), /fw-setup-upgrade (--to), /fw-setup-downgrade, /fw-setup-uninstall, /fw-setup-status (--verbose), /fw-setup-troubleshoot (--fix), /fw-setup-use (рабочая область nvm + .nvmrc). Устаревшая `/fdk-install` → используйте `/fw-setup-install` и т. д. Для публикации требуется FDK 10.x + Node 24.
