Instala y administra el kit de desarrollo Freshworks (FDK) con Node.js a través de nvm para el desarrollo de la plataforma 3.0. Admite FDK 10.x (Nodo 24, recomendado) y FDK 9.x (Nodo 18, obsoleto el 31 de mayo de 2026). Comandos de barra diagonal: /fw-setup-install (--version), /fw-setup-upgrade (--to), /fw-setup-downgrade, /fw-setup-uninstall, /fw-setup-status (--verbose), /fw-setup-troubleshoot (--fix), /fw-setup-use (espacio de trabajo nvm + .nvmrc). Legacy `/fdk-install` → use `/fw-setup-install`, etc. La publicación requiere FDK 10.x + Node 24.
