Habilidad de desarrollo de nivel experto para crear, depurar, revisar y migrar aplicaciones del mercado Freshworks Platform 3.0. REQUIERE Node.js 24.x + FDK 10.x instalado ANTES de usarlo: verifica los requisitos previos y se niega a continuar sin ellos. NO instala ni administra FDK/Node; use la habilidad fw-setup. Las nuevas aplicaciones tienen por defecto FDK 10.0.1 y Node.js 24.x; FDK 9.x/Node 18.x se permite cuando se solicita explícitamente con un aviso de obsolescencia. Úselo para: (1) Crear aplicaciones de Platform 3.0 (frontend, sin servidor, híbridas, OAuth), (2) Depurar errores de validación, (3) Migrar aplicaciones de Platform 2.x a 3.0, (4) Revisar manifest.json, request.json, oauth_config.json, (5) Implementar la interfaz de usuario de Crayons, (6) Integrar API externas o proveedores de OAuth, (7) Cualquier Freshworks Platform 3.0 desarrollo de aplicaciones, FDK CLI o tarea de envío al mercado.
