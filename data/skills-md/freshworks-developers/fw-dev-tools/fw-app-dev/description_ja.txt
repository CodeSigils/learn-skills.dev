Freshworks Platform 3.0 マーケットプレイス アプリケーションを構築、デバッグ、レビュー、移行するためのエキスパート レベルの開発スキル。使用前に Node.js 24.x + FDK 10.x がインストールされている必要があります。前提条件を確認し、前提条件なしでは続行を拒否します。 FDK/ノードのインストールや管理は行わず、fw-setup スキルを使用します。新しいアプリのデフォルトは FDK 10.0.1 および Node.js 24.x です。 FDK 9.x/Node 18.x は、非推奨通知で明示的に要求された場合に許可されます。用途: (1) プラットフォーム 3.0 アプリ (フロントエンド、サーバーレス、ハイブリッド、OAuth) の作成、(2) 検証エラーのデバッグ、(3) プラットフォーム 2.x アプリから 3.0 への移行、(4) manifest.json、requests.json、oauth_config.json のレビュー、(5) Crayons UI の実装、(6) 外部 API または OAuth プロバイダーの統合、(7) 任意Freshworks Platform 3.0 アプリ開発、FDK CLI、またはマーケットプレイス送信タスク。
