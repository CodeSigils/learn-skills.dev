Entwicklungskompetenz auf Expertenniveau zum Erstellen, Debuggen, Überprüfen und Migrieren von Marktplatzanwendungen der Freshworks Platform 3.0. ERFORDERT, dass Node.js 24.x + FDK 10.x VOR der Verwendung installiert sein muss – prüft die Voraussetzungen und weigert sich, ohne sie fortzufahren. Installiert oder verwaltet NICHT FDK/Node – verwenden Sie die FW-Setup-Fähigkeit. Neue Apps verwenden standardmäßig FDK 10.0.1 und Node.js 24.x; FDK 9.x/Node 18.x ist zulässig, wenn dies ausdrücklich mit einem Hinweis auf eine veraltete Version angefordert wird. Verwendung für: (1) Erstellen von Platform 3.0-Apps (Frontend, serverlos, Hybrid, OAuth), (2) Debuggen von Validierungsfehlern, (3) Migrieren von Platform 2.x-Apps auf 3.0, (4) Überprüfen von manifest.json, request.json, oauth_config.json, (5) Implementieren der Crayons-Benutzeroberfläche, (6) Integrieren externer APIs oder OAuth-Anbieter, (7) Entwicklung jeglicher Freshworks Platform 3.0-Apps, FDK-CLI oder Marktplatz-Übermittlungsaufgabe.
