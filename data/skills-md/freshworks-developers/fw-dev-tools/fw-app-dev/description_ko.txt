Freshworks Platform 3.0 마켓플레이스 애플리케이션 구축, 디버깅, 검토 및 마이그레이션을 위한 전문가 수준의 개발 기술입니다. 사용하기 전에 Node.js 24.x + FDK 10.x가 설치되어 있어야 합니다. 전제 조건을 확인하고 전제 조건 없이는 진행을 거부합니다. FDK/Node를 설치하거나 관리하지 않습니다. fw-setup 기술을 사용합니다. 새로운 앱은 기본적으로 FDK 10.0.1 및 Node.js 24.x로 설정됩니다. FDK 9.x/Node 18.x는 지원 중단 알림과 함께 명시적으로 요청된 경우 허용됩니다. 사용 용도: (1) Platform 3.0 앱 생성(프런트엔드, 서버리스, 하이브리드, OAuth), (2) 유효성 검사 오류 디버깅, (3) Platform 2.x 앱을 3.0으로 마이그레이션, (4) Manifest.json, 요청.json, oauth_config.json 검토, (5) Crayons UI 구현, (6) 외부 API 또는 OAuth 공급자 통합, (7) Freshworks Platform 3.0 앱 개발, FDK CLI, 또는 마켓플레이스 제출 작업.
