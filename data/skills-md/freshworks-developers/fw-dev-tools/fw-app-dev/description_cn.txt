用于构建、调试、审查和迁移 Freshworks Platform 3.0 市场应用程序的专家级开发技能。使用前需要安装 Node.js 24.x + FDK 10.x — 检查先决条件，如果没有它们，则拒绝继续。不安装或管理 FDK/Node — 使用固件设置技能。新应用程序默认为 FDK 10.0.1 和 Node.js 24.x；当明确请求并附有弃用通知时，允许使用 FDK 9.x/Node 18.x。用于：(1) 创建 Platform 3.0 应用程序（前端、无服务器、混合、OAuth），(2) 调试验证错误，(3) 将 Platform 2.x 应用程序迁移到 3.0，(4) 审查 manifest.json、requests.json、oauth_config.json，(5) 实现 Crayons UI，(6) 集成外部 API 或 OAuth 提供程序，(7) 任何 Freshworks Platform 3.0 应用程序开发、FDK CLI，或市场提交任务。
