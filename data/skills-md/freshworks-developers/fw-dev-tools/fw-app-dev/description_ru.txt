Навыки разработки экспертного уровня для создания, отладки, проверки и миграции приложений Freshworks Platform 3.0 Marketplace. ТРЕБУЕТСЯ установка Node.js 24.x + FDK 10.x ПЕРЕД использованием — проверяет предварительные условия и отказывается продолжать работу без них. НЕ устанавливает и не управляет FDK/Node — используйте навык настройки fw. Новые приложения по умолчанию используют FDK 10.0.1 и Node.js 24.x; FDK 9.x/Node 18.x разрешен по явному запросу с уведомлением об устаревании. Используется для: (1) создания приложений платформы 3.0 (интерфейсных, бессерверных, гибридных, OAuth), (2) отладки ошибок проверки, (3) переноса приложений платформы 2.x на версию 3.0, (4) проверки манифест.json, Requests.json, oauth_config.json, (5) реализации пользовательского интерфейса Crayons, (6) интеграции внешних API или поставщиков OAuth, (7) любой платформы Freshworks 3.0 разработка приложения, FDK CLI или задача отправки на рынок.
