Guía de operación completa de Knowledge Planet CLI (zsxq-cli), que cubre todos los escenarios de gestión de contenido y planeta. Cuando los usuarios mencionan Knowledge Planet, zsxq, Xiao Mi Quan, planet, inicio de sesión/autenticación, publicación, comentarios, respuesta, edición, eliminación de temas, notas, aspectos destacados, etiquetas/hashtag, miembros, huellas, registros de preguntas, compartir enlaces, comentarios NPS, group_id, topic_id, necesitan iniciar sesión/ver el estado de autenticación, ver/buscar/publicar/editar/administrar contenido de Knowledge Planet, realizar patrullaje diario/operación de sección de comentarios/gestión de preguntas/resaltar y etiquetar organización/operación revisión de informes diarios/semanales / generar imágenes de carteles diarios del planeta / generar videos de animación vertical / monitoreo de contenido negativo / etiquetado de lotes / atención de renovación de miembros vencidos / recopilar temas en columnas y otros escenarios operativos, unir enlaces compartidos, llamar directamente a interfaces subyacentes (llamada API / API raw), verificar listas de miembros / tiempos de vencimiento de miembros / listas de columnas, o necesita inspeccionar/migrar/limpiar las habilidades de la versión anterior de Knowledge Planet (zsxq-shared, zsxq-group, etc., actualizadas a una sola zsxq), se debe utilizar esta habilidad.
