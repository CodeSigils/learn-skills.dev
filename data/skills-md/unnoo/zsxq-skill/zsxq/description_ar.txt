دليل التشغيل الكامل لـ Knowledge Planet CLI (zsxq-cli)، الذي يغطي جميع سيناريوهات الكوكب وإدارة المحتوى. عندما يذكر المستخدمون Knowledge Planet، zsxq، Xiao Mi Quan، الكوكب، تسجيل الدخول/المصادقة، النشر، التعليق، الإجابة، التحرير، حذف المواضيع، الملاحظات، التمييزات، العلامات/الهاشتاج، الأعضاء، آثار الأقدام، سجلات الأسئلة، مشاركة الروابط، تعليقات NPS، معرف المجموعة، theme_id، يحتاجون إلى تسجيل الدخول/عرض حالة المصادقة، عرض/بحث/نشر/تحرير/إدارة محتوى Knowledge Planet، إجراء دورية يومية / تشغيل قسم التعليقات / إدارة الأسئلة / تمييز وتنظيم العلامات / تشغيل مراجعة التقارير اليومية / الأسبوعية / إنشاء صور ملصقات يومية للكوكب / إنشاء مقاطع فيديو للرسوم المتحركة العمودية / مراقبة المحتوى السلبي / وضع علامات على الدُفعات / رعاية تجديد الأعضاء منتهية الصلاحية / جمع المواضيع في أعمدة وسيناريوهات تشغيلية أخرى، وربط روابط المشاركة، واستدعاء الواجهات الأساسية مباشرة (استدعاء API / خام API)، والتحقق من قوائم الأعضاء / أوقات انتهاء صلاحية الأعضاء / قوائم الأعمدة، أو الحاجة إلى فحص / ترحيل / تنظيف مهارات Knowledge Planet للإصدار القديم (zsxq المشتركة، zsxq ‑ group، وما إلى ذلك، وترقيتها إلى zsxq واحد)، يجب استخدام هذه المهارة. حتى لو تم تضمين عملية واحدة فقط (على سبيل المثال، الحصول على معرف المجموعة، وعرض تفاصيل المنشور، والرد على التعليقات)، فيجب تشغيلها.

يرجى الرد دائمًا بلغة المستخدم.
