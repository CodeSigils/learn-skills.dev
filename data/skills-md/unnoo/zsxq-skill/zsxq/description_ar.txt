دليل التشغيل الكامل لـ Knowledge Planet CLI (zsxq-cli)، الذي يغطي جميع سيناريوهات الكوكب وإدارة المحتوى. عندما يذكر المستخدمون Knowledge Planet، أو zsxq، أو Xiaomiquan، أو Planet، أو تسجيل الدخول/المصادقة، أو النشر، أو التعليق، أو الإجابة، أو التحرير، أو حذف المواضيع، أو الملاحظات، أو الإبرازات، أو العلامات/الهاشتاج، أو الأعضاء، أو آثار الأقدام، أو سجلات الأسئلة، أو روابط المشاركة، أو تعليقات NPS، أو معرف المجموعة، أو معرف الموضوع، فإنهم بحاجة إلى تسجيل الدخول/التحقق من حالة المصادقة، وعرض/بحث/نشر/تحرير/إدارة محتوى Knowledge Planet، وإجراء دوريات يومية، وعمليات قسم التعليقات، وإدارة الأسئلة، وتمييز و تنظيم العلامات، تشغيل مراجعات التقارير اليومية/الأسبوعية، إنشاء صور ملصقات للتقارير اليومية للكوكب، إنشاء مقاطع فيديو للرسوم المتحركة العمودية، مراقبة المحتوى السلبي، علامة الدفعة، العناية بتجديدات الأعضاء منتهية الصلاحية، جمع المواضيع في أعمدة وسيناريوهات تشغيلية أخرى، روابط مشاركة الوصل، الاتصال مباشرة بالواجهات ذات المستوى المنخفض (استدعاء API / API الخام)، التحقق من قوائم الأعضاء، تواريخ انتهاء صلاحية الأعضاء، قوائم الأعمدة، أو الحاجة إلى فحص/ترحيل/تنظيف مهارات كوكب المعرفة القديمة (zsxq-المشتركة، تمت ترقية مجموعة zsxq، وما إلى ذلك إلى zsxq واحد). ويجب استخدام هذه المهارة. حتى لو كان الأمر يتضمن عملية واحدة فقط (مثل الحصول على معرف المجموعة، أو عرض تفاصيل المنشور، أو الرد على تعليق)، فيجب تشغيله.
