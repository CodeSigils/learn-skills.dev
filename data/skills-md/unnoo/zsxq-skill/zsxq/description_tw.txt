知识星球CLI（zsxq-cli）完整操作指南，涵盖星球和内容管理的所有场景。当用户提及知识星球、zsxq、小米圈、星球、登录/认证、发帖、评论、回答、编辑、删除主题、笔记、亮点、标签/话题标签、会员、足迹、提问记录、分享链接、NPS反馈、group_id、topic_id时，需要登录/查看认证状态，查看/搜索/发布/编辑/管理知识星球内容，进行每日巡检/评论区操作/问题管理/亮点标签整理/每日/每周操作报表审核/生成星球日报海报图片/生成竖动画视频/负面内容监控/批量标签/过期会员续费护理/收集主题入栏等操作场景，拼接分享链接，直接调用底层接口（API call / API raw），查看会员列表/会员过期时间/栏目列表，或需要检查/迁移/清理旧版知识星球技能（zsxq-shared、zsxq-group等，升级为单个zsxq），此技能必须被使用。即使只涉及单个操作（例如获取group_id、查看帖子详细信息、回复评论），也应该被触发。
