Knowledge Planet CLI (zsxq-cli) の完全な操作ガイド。プラネットおよびコンテンツ管理のすべてのシナリオをカバーします。ユーザーが Knowledge Planet、zsxq、XiaoMi Circle、planet、ログイン/認証、投稿、コメント、回答、編集、トピックの削除、メモ、ハイライト、タグ/ハッシュタグ、メンバー、足跡、質問記録、リンクの共有、NPS フィードバック、group_id、topic_id に言及する場合、ログイン/認証ステータスの表示、Knowledge Planet コンテンツの表示/検索/公開/編集/管理、毎日のパトロールの実行/コメント エリアの操作/質問管理/ハイライトとタグの整理が必要になります。 / 運用日次/週次レポートのレビュー / プラネット日次レポートのポスター画像の生成 / 縦型アニメーションビデオの生成 / ネガティブ コンテンツの監視 / バッチタグ付け / 期限切れのメンバー更新ケア / トピックを列およびその他の運用シナリオに収集、共有リンクを連結、低レベル インターフェイス (API 呼び出し / API RAW) を直接呼び出し、メンバー リスト / メンバーの有効期限 / 列リストを確認、または古いバージョンの Knowledge Planet スキル (zsxq-shared、zsxq-shared、 zsxq‑group などを単一の zsxq にアップグレードするには、このスキルを使用する必要があります。関与する操作が 1 つだけの場合でも (group_id の取得、投稿の詳細の表示、コメントへの返信など)、トリガーされる必要があります。
