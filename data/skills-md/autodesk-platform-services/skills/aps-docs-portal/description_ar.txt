انتقل إلى بوابة وثائق Autodesk Platform Services (APS) - واعثر على مستندات API الصحيحة، وفك تشفير المصطلحات، وزحف إلى أشجار جدول المحتويات JSON، واستخرج المحتوى من صفحات HTML الثابتة، وقم بتحويل عناوين URL الخاصة بـ CDN إلى روابط بوابة قابلة للنقر. يغطي ACC وBIM 360 ومشتقات النماذج وإدارة البيانات والعارض وأتمتة التصميم والمصادقة وخطافات الويب وجميع واجهات برمجة تطبيقات APS ذات الصلة.
