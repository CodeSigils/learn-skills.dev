Implemente una tarea para la cual no se esperan diferencias visuales de un extremo a otro, utilizando Meticulous para llevar la implementación a una diferencia visual limpia antes de abrir un PR. Úselo cuando la premisa completa de la tarea sea "la interfaz de usuario no debería cambiar": una actualización de dependencia/versión, una refactorización de código, una migración o algo similar. Meticuloso no es solo una verificación final aquí, es el ciclo que se repite durante la implementación.
