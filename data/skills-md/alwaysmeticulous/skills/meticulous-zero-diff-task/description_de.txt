Implementieren Sie eine Aufgabe, für die keine visuellen Unterschiede zu erwarten sind, von Ende zu Ende, und führen Sie die Implementierung mithilfe von „Peak“ auf einen sauberen visuellen Unterschied aus, bevor Sie eine PR öffnen. Verwenden Sie diese Option, wenn die gesamte Prämisse der Aufgabe lautet: „Die Benutzeroberfläche sollte sich nicht ändern“ – ein Abhängigkeits-/Versions-Upgrade, eine Code-Umgestaltung, eine Migration oder ähnliches. Akribisch ist hier nicht nur eine abschließende Prüfung, sondern die Schleife, die Sie bei der Implementierung durchlaufen.
