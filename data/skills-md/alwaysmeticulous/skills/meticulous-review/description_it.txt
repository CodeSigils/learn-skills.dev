Analizza un test meticoloso completato: recupera il riepilogo delle differenze, esamina gli screenshot rappresentativi, le differenze DOM e le sequenze temporali. Risolve l'esecuzione del test dal commit corrente del repository locale (impostazione predefinita) o da un ID di esecuzione del test o un SHA commit esplicito. Da utilizzare quando viene richiesto di rivedere i risultati del test Meticulous o durante la revisione o il controllo di una richiesta di pull/merge per valutare e correggere un controllo CI Meticulous Tests non riuscito.
