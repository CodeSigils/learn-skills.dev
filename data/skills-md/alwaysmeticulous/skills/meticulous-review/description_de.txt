Löst den Testlauf aus dem aktuellen Commit des lokalen Repos (Standard) oder aus einer expliziten Testlauf-ID oder einem Commit-SHA auf. Verwenden Sie diese Option, wenn Sie aufgefordert werden, die Ergebnisse von Meticulous-Tests zu überprüfen, oder während Sie eine Pull-/Merge-Anfrage überprüfen oder betreuen, um eine fehlgeschlagene CI-Prüfung von Meticulous Tests zu bewerten und zu beheben.
