Augmentez la couverture d'un projet Meticulous en traçant des fichiers spécifiques sous-couverts jusqu'à une action réelle de l'interface utilisateur dans la base de code, en pilotant cette action avec une véritable session de navigateur enregistrée et en validant l'amélioration avec une comparaison de couverture claire. Ouvre également un PR proposant des entrées .meticulousignore pour le code qui, structurellement, ne s'exécute jamais dans le navigateur. À utiliser lorsqu'on vous demande « d'augmenter la couverture », de « trouver du code non testé » ou « d'ajouter des entrées .meticulousignore » pour un projet.
