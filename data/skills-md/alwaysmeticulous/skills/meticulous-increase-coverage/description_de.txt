Erhöhen Sie die Abdeckung für ein Meticulous-Projekt, indem Sie bestimmte nicht abgedeckte Dateien auf eine echte UI-Aktion in der Codebasis zurückführen, diese Aktion mit einer echten aufgezeichneten Browsersitzung steuern und die Verbesserung mit einem sauberen Abdeckungsvergleich validieren. Öffnet außerdem eine PR, die .meticulousignore-Einträge für Code vorschlägt, der strukturell nie im Browser ausgeführt wird. Verwenden Sie diese Option, wenn Sie aufgefordert werden, für ein Projekt „die Abdeckung zu erhöhen“, „nicht getesteten Code zu finden“ oder „.meticulousignore-Einträge hinzuzufügen“.
