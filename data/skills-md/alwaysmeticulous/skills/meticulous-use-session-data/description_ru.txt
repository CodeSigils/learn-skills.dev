Загружайте и используйте структурированные данные сеанса Teticulous (потоки пользователей + сетевые макеты) для локального тестирования изменений кода. Используйте, когда вам нужно понять, какие взаимодействия с пользователем и вызовы API охватывает тест, или когда вам нужны сетевые макеты для написания тестов.
