Riferimento completo per il diario degli incontri di WoW Retail, la modalità Mitica+/Sfida, l'istanza, lo scenario, il blocco raid e le API stagionali. Copre EncounterJournal (database dungeon/raid boss, tabelle di bottino, navigazione nelle sezioni), C_ChallengeMode (M+ chiavi di volta, affissi, timer, tempi migliori), C_MythicPlus (esecuzioni settimanali, dati stagionali, valutazione), ScenarioInfo (esplora/scenari obiettivi e fasi), InstanceLeaverInfo (disertore), RaidLocks (istanze salvate), C_SeasonInfo (informazioni stagionali) ed eventi correlati. Da utilizzare quando si lavora con dati di incontri di dungeon/incursioni, chiavi di volta M+, punteggi mitici più, fasi di scenari, blocchi di incursioni o contenuti stagionali.
