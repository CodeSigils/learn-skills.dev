مرجع كامل لمجلة WoW Retail Encounter Journal ووضع Mythic+/Challenge والمثيل والسيناريو وRaid Lock وSeason APIs. يغطي EncounterJournal (قاعدة بيانات الزنزانات/زعماء الغارة، جداول الغنائم، التنقل بين الأقسام)، C_ChallengeMode (M+ keystones، اللواحق، الموقتات، أفضل الأوقات)، C_MythicPlus (عمليات التشغيل الأسبوعية، البيانات الموسمية، التقييم)، ScenarioInfo (أهداف ومراحل التنقيب/السيناريوهات)، InstanceLeaverInfo (الهارب)، RaidLocks (المثيلات المحفوظة)، C_SeasonInfo (المعلومات الموسمية)، والأحداث ذات الصلة. يُستخدم عند العمل مع بيانات مواجهة الزنزانة/الغارة، أو أحجار المفاتيح M+، أو الدرجات الإضافية الأسطورية، أو مراحل السيناريو، أو عمليات تأمين الغارة، أو المحتوى الموسمي.
