Полный справочник по API журнала розничных встреч WoW, режима Mythic+/Challenge, инстанса, сценария, блокировки рейда и сезона. Охватывает EncounterJournal (база данных боссов подземелий/рейдов, таблицы добычи, навигация по разделам), C_ChallengeMode (ключевые камни M+, аффиксы, таймеры, лучшее время), C_MythicPlus (еженедельные прогоны, сезонные данные, рейтинг), ScenarioInfo (цели и этапы погружений/сценариев), InstanceLeaverInfo (дезертир), RaidLocks (сохраненные экземпляры), C_SeasonInfo (сезонная информация) и связанные с этим события. Используйте при работе с данными о столкновениях в подземельях/рейдах, ключевыми камнями M+, очками мифического плюса, этапами сценария, блокировкой рейдов или сезонным контентом.
