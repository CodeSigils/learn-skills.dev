Referencia completa para las API de WoW Retail Encounter Journal, Mythic+/Challenge Mode, Instancia, Escenario, Raid Lock y Season. Cubre EncounterJournal (base de datos de jefes de incursión/mazmorras, tablas de botín, navegación de secciones), C_ChallengeMode (piedras clave M+, afijos, temporizadores, mejores tiempos), C_MythicPlus (ejecuciones semanales, datos estacionales, clasificación), ScenarioInfo (profundizaciones/escenarios, objetivos y etapas), InstanceLeaverInfo (desertor), RaidLocks (instancias guardadas), C_SeasonInfo (información estacional) y eventos relacionados. Úselo cuando trabaje con datos de encuentros de mazmorras/incursiones, piedras angulares M+, puntuaciones plus míticas, etapas de escenarios, bloqueos de incursiones o contenido de temporada.
