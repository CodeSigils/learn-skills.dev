مرجع كامل لـ WoW Retail Combat، ومقياس الضرر، والتهديد، وفقدان التحكم، ونص القتال، والتنبيه الصوتي للقتال، والقيم السرية، وواجهات برمجة تطبيقات المشاهد. يغطي إزالة سجل القتال 12.0.0 (لم يعد CLEU متاحًا للإضافات)، ومقياس الضرر المدمج في C_DamageMeter، ومسندات C_Secrets السرية، وC_CurveUtil/C_DurationUtil لتصور القيمة السرية، وC_LossOfControl، وC_CombatText، وC_CombatAudioAlert، وENCOUNTER_STATE_CHANGED، ووظائف التهديد، والجديد حدث COMBAT_LOG_MESSAGE. يُستخدم عند العمل مع البيانات القتالية، أو مقاييس الضرر، أو التهديد، أو فقدان السيطرة، أو نص القتال، أو أحداث المواجهة، أو أي وظيفة إضافية متعلقة بالقتال.
