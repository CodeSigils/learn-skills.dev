Полный справочник по розничным боям WoW, счетчику урона, угрозе, потере контроля, боевому тексту, боевому звуковому оповещению, секретным значениям и API-интерфейсам наблюдателей. Охватывает удаление журнала боя версии 12.0.0 (CLEU больше не доступен для надстроек), встроенный счетчик урона C_DamageMeter, секретные предикаты C_Secrets, C_CurveUtil/C_DurationUtil для визуализации секретных значений, C_LossOfControl, C_CombatText, C_CombatAudioAlert, ENCOUNTER_STATE_CHANGED, функции угроз и новые Событие COMBAT_LOG_MESSAGE. Используйте при работе с боевыми данными, счетчиками урона, угрозами, потерей управления, боевым текстом, событиями столкновения или любыми дополнительными функциями, связанными с боем.
