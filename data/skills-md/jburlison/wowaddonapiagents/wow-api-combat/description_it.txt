Riferimento completo per combattimenti WoW Retail, misuratore di danni, minaccia, perdita di controllo, testo di combattimento, avviso audio di combattimento, valori segreti e API per gli spettatori. Copre la rimozione del registro di combattimento 12.0.0 (CLEU non è più disponibile per i componenti aggiuntivi), misuratore di danni integrato C_DamageMeter, predicati segreti C_Secrets, C_CurveUtil/C_DurationUtil per la visualizzazione dei valori segreti, C_LossOfControl, C_CombatText, C_CombatAudioAlert, ENCOUNTER_STATE_CHANGED, funzioni di minaccia e il nuovo COMBAT_LOG_MESSAGE evento. Da utilizzare quando si lavora con dati di combattimento, indicatori di danno, minaccia, perdita di controllo, testo di combattimento, eventi di incontro o qualsiasi funzionalità aggiuntiva relativa al combattimento.
