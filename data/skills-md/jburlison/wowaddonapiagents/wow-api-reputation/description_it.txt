Riferimento completo per le API WoW Retail Reputation, Faction, Major Factions, Paragon e Neighborhood Initiative. Copre C_Reputation (informazioni sulla fazione, classifiche, fazione osservata, intestazioni, rappresentanti dell'amicizia, campione), C_MajorFactions (fazioni di fama di Dragonflight+, livelli di fama, ricompense), C_NeighborhoodInitiative (reputazione del quartiere residenziale 12.0.0), dati sull'espansione delle fazioni ed eventi relativi alla reputazione. Da utilizzare quando si lavora con il monitoraggio della reputazione, le classifiche delle fazioni, i sistemi di fama, le ricompense esemplari, la reputazione dell'amicizia o le iniziative di quartiere.
