WoW Retail Reputation、Faction、Major Faction、Paragon、および Neighborhood Initiative API の完全なリファレンス。 C_Reputation (派閥情報、順位、注目派閥、ヘッダー、友情担当者、パラゴン)、C_MajorFactions (Dragonflight+ 名声派閥、名声レベル、報酬)、C_NeighborhoodInitiative (12.0.0 住宅地区評判)、派閥拡張データ、評判関連イベントをカバーします。評判の追跡、派閥の順位、名声システム、パラゴンの報酬、友情の評判、または近所の取り組みを扱うときに使用します。
