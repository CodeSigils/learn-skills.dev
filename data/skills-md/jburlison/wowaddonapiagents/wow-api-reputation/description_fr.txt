Référence complète pour les API WoW Retail Reputation, Faction, Major Factions, Paragon et Neighbourhood Initiative. Couvre C_Reputation (informations sur la faction, classements, faction surveillée, en-têtes, représentants d'amitié, parangon), C_MajorFactions (factions de renommée Dragonflight+, niveaux de renommée, récompenses), C_NeighborhoodInitiative (réputation du quartier 12.0.0), les données d'expansion de faction et les événements liés à la réputation. À utiliser lorsque vous travaillez avec le suivi de la réputation, le classement des factions, les systèmes de renommée, les récompenses de parangon, les réputations d'amitié ou les initiatives de quartier.
