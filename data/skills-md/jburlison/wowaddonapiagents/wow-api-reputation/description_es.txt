Referencia completa para las API de WoW Retail Reputation, Faction, Major Factions, Paragon y Neighborhood Initiative. Cubre C_Reputation (información de facción, clasificaciones, facción observada, encabezados, representantes de amistad, modelo), C_MajorFactions (facciones de renombre de Dragonflight+, niveles de renombre, recompensas), C_NeighborhoodInitiative (reputación del vecindario de viviendas 12.0.0), datos de expansión de facción y eventos relacionados con la reputación. Úselo cuando trabaje con seguimiento de reputación, clasificación de facciones, sistemas de renombre, recompensas de modelo, reputaciones de amistad o iniciativas vecinales.
