مرجع كامل لواجهات برمجة تطبيقات WoW Retail Reputation، والفصائل، والفصائل الرئيسية، والمثال، ومبادرة الجوار. يغطي C_Reputation (معلومات الفصيل، الترتيب، الفصيل الذي تمت مراقبته، الرؤوس، ممثلو الصداقة، النموذج)، C_MajorFactions (Dragonflight+ الفصائل الشهيرة، مستويات الشهرة، المكافآت)، C_NeighborhoodInitiative (12.0.0 سمعة الحي السكني)، وبيانات توسيع الفصيل، والأحداث المتعلقة بالسمعة. يُستخدم عند العمل مع تتبع السمعة، أو ترتيب الفصائل، أو أنظمة الشهرة، أو المكافآت النموذجية، أو سمعة الصداقة، أو مبادرات الحي.
