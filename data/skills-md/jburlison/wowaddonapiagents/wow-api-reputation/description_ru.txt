Полный справочник по API WoW Retail Reputation, Faction, Major Factions, Paragon и Neighborhood Initiative. Охватывает C_Reputation (информация о фракции, положение, наблюдаемая фракция, заголовки, представители дружбы, идеал), C_MajorFactions (фракции известности Dragonflight+, уровни известности, награды), C_NeighborhoodInitiative (репутация жилого квартала 12.0.0), данные о расширении фракции и события, связанные с репутацией. Используйте при работе с отслеживанием репутации, положением фракций, системами славы, наградами за идеалы, репутацией дружбы или инициативами соседей.
