Руководство по настройке и оптимизации сцены VRCchat World SDK 3. Используйте этот навык при настройке мировых сцен VRChat, размещении компонентов SDK, настройке слоев, оптимизации производительности или загрузке миров. Охватывает VRC_SceneDescriptor, точки появления, VRC_Pickup, VRC_Station, VRC_Mirror, VRC_ObjectSync, VRC_CameraDolly, матрицу слоев/столкновений, запеченное освещение, ограничения Quest/Android и рабочий процесс загрузки. Охват SDK 3.7.1–3.10.2. Запускается по: миру VRChat, VRC SDK, настройке сцены, VRC_SceneDescriptor, точке появления, VRC_Pickup, VRC_Station, VRC_ObjectSync, настройке слоев, оптимизации, поддержке квестов, легкому запеканию, загрузке, улучшению FPS. Связанный: Используйте unity-vrc-udon-sharp для кодирования UdonSharp C#.
