VRChat World SDK 3 シーンのセットアップと最適化ガイド。このスキルは、VRChat ワールド シーンの構成、SDK コンポーネントの配置、レイヤーのセットアップ、パフォーマンスの最適化、またはワールドのアップロード時に使用します。 VRC_SceneDescriptor、スポーン ポイント、VRC_Pickup、VRC_Station、VRC_Mirror、VRC_ObjectSync、VRC_CameraDolly、レイヤー/コリジョン マトリックス、ベイク ライティング、Quest/Android 制限、およびアップロード ワークフローをカバーします。 SDK 3.7.1 ～ 3.10.2 をカバーします。トリガー: VRChat ワールド、VRC SDK、シーン セットアップ、VRC_SceneDescriptor、スポーン ポイント、VRC_Pickup、VRC_Station、VRC_ObjectSync、レイヤー セットアップ、最適化、クエスト サポート、ライト ベイク、アップロード、FPS 改善。関連: UdonSharp C# コーディングにはunity-vrc-udon-sharpを使用してください。
