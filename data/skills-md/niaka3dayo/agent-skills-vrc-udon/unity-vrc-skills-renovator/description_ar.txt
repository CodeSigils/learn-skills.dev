مُجدد مهارات VRChat لملء المعرفة وتحديثها وتحسين الجودة. استخدم هذه المهارة عند تحديث مهارات VRChat إلى إصدارات SDK الجديدة، أو ملء المعرفة المفقودة، أو إصلاح المعلومات القديمة، أو تحسين جودة المهارة. يستهدف مهارات الوحدة-vrc-udon-sharp وUnity-vrc-world-sdk-3. المشغلات على: تحديث المهارات، أحدث SDK، تعبئة المعرفة، صيانة المهارات، تدقيق المعلومات، اللحاق بالركب، التجديد، التحديث، تحسين المهارات، تحديث SDK.
