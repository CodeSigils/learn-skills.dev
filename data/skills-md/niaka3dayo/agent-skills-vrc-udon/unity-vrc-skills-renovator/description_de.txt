VRChat-Skill-Renovator zum Auffüllen, Auffrischen und Qualitätsverbesserung von Wissen. Verwenden Sie diesen Skill, wenn Sie VRChat-Skills auf neue SDK-Versionen aktualisieren, fehlendes Wissen ergänzen, veraltete Informationen reparieren oder die Skill-Qualität verbessern. Zielt auf die Fertigkeiten Unity-VRC-Udon-Sharp und Unity-VRC-World-SDK-3 ab. Auslöser bei: Fertigkeiten aktualisieren, neuestes SDK, Wissensauffüllung, Fertigkeitspflege, Informationsprüfung, Aufholen, Erneuern, Auffrischen, Fertigkeiten verbessern, SDK-Aktualisierung.
