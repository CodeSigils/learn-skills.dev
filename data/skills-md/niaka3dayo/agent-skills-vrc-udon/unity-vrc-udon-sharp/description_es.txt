Habilidad de creación de scripts en UdonSharp (C# a Udon Assembly) para el desarrollo mundial de VRChat. Utilice esta habilidad al escribir, revisar o depurar código UdonSharp C#. Cubre restricciones de compilación (List<T>/async/await/try/catch/LINQ bloqueado), sincronización de red (UdonSynced, RequestSerialization, FieldChangeCallback, NetworkCallable), persistencia (PlayerData/PlayerObject), dinámica (PhysBones, Contacts), carga web y manejo de eventos. Cobertura del SDK 3.7.1 - 3.10.2. Activadores en: UdonSharp, Udon, VRC SDK, UdonBehaviour, UdonSynced, NetworkCallable, VRCPlayerApi, SendCustomEvent, PlayerData, PhysBones, variables sincronizadas, scripting mundial VRChat, C# a Udon.
