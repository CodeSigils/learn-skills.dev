Навыки написания сценариев UdonSharp (от C# до Udon Assembly) для мировой разработки VRChat. Используйте этот навык при написании, проверке или отладке кода UdonSharp C#. Охватывает ограничения компиляции (List<T>/async/await/try/catch/LINQ заблокирован), сетевую синхронизацию (UdonSynced, RequestSerialization, FieldChangeCallback, NetworkCallable), постоянство (PlayerData/PlayerObject), динамику (PhysBones, Контакты), веб-загрузку и обработку событий. Охват SDK 3.7.1–3.10.2. Запускается по: UdonSharp, Udon, VRC SDK, UdonBehaviour, UdonSynced, NetworkCallable, VRCPlayerApi, SendCustomEvent, PlayerData, PhysBones, синхронизированным переменным, мировым сценариям VRChat, C# для Udon.
