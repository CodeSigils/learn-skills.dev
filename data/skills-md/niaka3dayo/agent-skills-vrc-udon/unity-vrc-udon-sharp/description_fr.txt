Compétence de script UdonSharp (C# vers Udon Assembly) pour le développement du monde VRChat. Utilisez cette compétence lors de l'écriture, de la révision ou du débogage du code UdonSharp C#. Couvre les contraintes de compilation (List<T>/async/await/try/catch/LINQ bloqué), la synchronisation réseau (UdonSynced, RequestSerialization, FieldChangeCallback, NetworkCallable), la persistance (PlayerData/PlayerObject), la dynamique (PhysBones, Contacts), le chargement Web et la gestion des événements. Couverture du SDK 3.7.1 à 3.10.2. Déclencheurs sur : UdonSharp, Udon, VRC SDK, UdonBehaviour, UdonSynced, NetworkCallable, VRCPlayerApi, SendCustomEvent, PlayerData, PhysBones, variables synchronisées, scripts mondiaux VRChat, C# vers Udon.
