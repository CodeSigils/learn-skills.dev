Générez une suite de tests E2E complète pour n'importe quelle application Web à l'aide du flux de travail en 4 étapes d'Autonoma : génération de base de connaissances, scénarios de données de test, génération de scénarios de test E2E et implémentation d'Environment Factory. À utiliser lorsque l'utilisateur souhaite configurer des tests Autonoma, générer des tests E2E ou implémenter Environment Factory pour son application.
