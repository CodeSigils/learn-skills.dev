Создайте полный набор тестов E2E для любого веб-приложения, используя четырехэтапный рабочий процесс Autonoma: создание базы знаний, сценарии тестовых данных, создание тестовых сценариев E2E и внедрение Environment Factory. Используйте, когда пользователь хочет настроить тестирование Autonoma, сгенерировать тесты E2E или реализовать фабрику среды для своего приложения.
