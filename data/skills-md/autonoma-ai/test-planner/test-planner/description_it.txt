Genera una suite di test E2E completa per qualsiasi applicazione web utilizzando il flusso di lavoro in 4 fasi di Autonoma: generazione di knowledge base, scenari di dati di test, generazione di casi di test E2E e implementazione di Environment Factory. Utilizzare quando l'utente desidera impostare test Autonoma, generare test E2E o implementare Environment Factory per la propria applicazione.
