Genere un conjunto de pruebas E2E completo para cualquier aplicación web utilizando el flujo de trabajo de 4 pasos de Autonoma: generación de base de conocimientos, escenarios de datos de prueba, generación de casos de prueba E2E e implementación de Environment Factory. Úselo cuando el usuario desee configurar pruebas de Autonoma, generar pruebas E2E o implementar Environment Factory para su aplicación.
