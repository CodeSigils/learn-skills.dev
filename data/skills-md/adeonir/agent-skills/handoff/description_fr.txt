Enregistrez l'état actuel de la conversation sur le disque afin qu'une session ultérieure reprenne avec un contexte complet. Capture l'objectif et l'étape suivante, ainsi que les décisions facultatives, les résultats, les fils de discussion ouverts, les bloqueurs et les références ; ajoute les instantanés les plus récents en haut. À utiliser pour terminer une session avant une perte de contexte, pour établir un point de contrôle en cours de session ou pour démarrer une session qui doit poursuivre un travail antérieur. Déclencheurs : "enregistrer le contexte", "vider la conversation", "point de contrôle", "transfert de session", "enregistrer le transfert", "reprendre la session", "charger le transfert", "continuer à partir du dernier", "effacer le transfert". Pas pour la persistance de fin de session sur les systèmes de mémoire ou pour le contexte de projet à l'échelle du référentiel.
