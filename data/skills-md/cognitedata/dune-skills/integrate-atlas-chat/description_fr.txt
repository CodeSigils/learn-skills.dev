DOIT être utilisé lors de la création d'une interface utilisateur de chat avec des agents Atlas dans une application Dune. N'écrivez PAS manuellement le code d'intégration useAtlasChat - cette compétence gère l'installation, la structure des composants et le câblage des crochets. Déclencheurs : utilisation d'AtlasChat, chat atlas, chat en streaming, chat d'agent, interface de chat, composant de chat, interface utilisateur de chat. Pour une application de chat complète, exécutez les compétences dans l'ordre : (1) integrate-atlas-chat, (2) create-client-tool (par outil), (3) setup-python-tools (si les outils Python sont nécessaires).
