DEBE usarse siempre que se cree una interfaz de usuario de chat con agentes de Atlas en una aplicación de Dune. NO escriba manualmente el código de integración useAtlasChat: esta habilidad se encarga de la instalación, la estructura de los componentes y el cableado del gancho. Activadores: useAtlasChat, chat de atlas, chat de transmisión, chat de agente, interfaz de chat, componente de chat, interfaz de usuario de chat. Para una aplicación de chat completa, ejecute las habilidades en orden: (1) integrar-atlas-chat, (2) crear-herramienta-cliente (por herramienta), (3) configurar-python-tools (si se necesitan herramientas de Python).
