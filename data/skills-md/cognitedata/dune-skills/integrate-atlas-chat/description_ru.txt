ДОЛЖЕН использоваться при создании пользовательского интерфейса чата с агентами Atlas в приложении Dune. НЕ пишите код интеграции useAtlasChat вручную — этот навык отвечает за установку, структуру компонентов и подключение. Триггеры: useAtlasChat, чат атласа, потоковый чат, чат агента, интерфейс чата, компонент чата, пользовательский интерфейс чата. Для полноценного чат-приложения запустите навыки по порядку: (1) интегрировать-атлас-чат, (2) создать-клиент-инструмент (для каждого инструмента), (3) настроить-инструменты-питона (если нужны инструменты Python).
