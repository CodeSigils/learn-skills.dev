Configure un visor de modelos CAD 3D en una aplicación Dune usando Cognite Reveal a través de @cognite/dune-industrial-components/reveal. Utilice esta habilidad siempre que el usuario mencione visor 3D, visualización 3D, revelación, modelo CAD, RevealProvider, RevealCanvas, Reveal3DResources, mapeo 3D FDM, modelo 3D de activos, carga de un modelo 3D o quiera mostrar cualquier contenido 3D de Cognite en una aplicación Dune, incluso si no dice explícitamente "Revelar" o "visor 3D". NO conecte manualmente RevealProvider, RevealCanvas o ganchos de carga de modelos sin consultar primero esta habilidad.
