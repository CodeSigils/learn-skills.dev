ДОЛЖЕН использоваться при создании AtlasTool (клиентского инструмента) для агента Atlas. НЕ записывайте вручную определения AtlasTool и не подключайте их к useAtlasChat — этот навык обрабатывает схему TypeBox, выполняет функцию и связывает перехват. Сюда входят инструменты, которые извлекают данные, отображают пользовательский интерфейс, вызывают API, показывают диаграммы, запрашивают локальное состояние или выполняют любые действия на стороне браузера. Триггеры: AtlasTool, клиентский инструмент, добавление инструмента, создание инструмента, новый инструмент, определение инструмента, инструмент агента.
