MUSS beim Erstellen eines AtlasTool (clientseitiges Tool) für einen Atlas-Agenten verwendet werden. Schreiben Sie AtlasTool-Definitionen NICHT manuell und vernetzen Sie sie NICHT mit useAtlasChat – dieser Skill kümmert sich um das TypeBox-Schema, die Ausführungsfunktion und die Hook-Verknüpfung. Dazu gehören Tools, die Daten abrufen, Benutzeroberflächen rendern, APIs aufrufen, Diagramme anzeigen, den lokalen Status abfragen oder beliebige browserseitige Aktionen ausführen. Auslöser: AtlasTool, Client-Tool, Tool hinzufügen, Tool erstellen, neues Tool, Tool-Definition, Agent-Tool.
