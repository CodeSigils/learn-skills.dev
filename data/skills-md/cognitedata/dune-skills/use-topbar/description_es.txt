Conecta Aura Topbar (@aura/topbar) a las aplicaciones Dune/Fusion como una única barra de navegación superior: rutas de navegación, pestañas centrales opcionales o control segmentado, franja de utilidades derecha (Compartir, notificaciones, menú temático, Atlas, avatar de usuario) y cambio de tema claro/oscuro. Úselo cuando agregue una barra superior, un encabezado de aplicación, una barra de navegación, rutas de navegación o un selector de temas a una aplicación Dune o Fusion, o cuando cree una nueva aplicación Dune/Fusion.
