MUSS verwendet werden, wenn eine Dune-App auf Codequalität, Wartbarkeit oder Probleme mit sauberem Code überprüft wird – vor einer PR-Überprüfung, nach Fertigstellung einer Funktion oder wenn der Benutzer eine Codeüberprüfung anfordert. Überspringen Sie die Schritte zum Flusen NICHT. Auslöser: Codequalität, Codeüberprüfung, sauberer Code, Refaktorierung, Wartbarkeit, technische Schulden, jeder Typ, Benennung, toter Code, Duplizierung, DRY, Einzelverantwortung, Komponentengröße, Lint, Linting, TypeScript streng, Abhängigkeitsinjektion, Dateistruktur.
