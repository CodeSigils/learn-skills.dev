DEBE usarse al agregar compatibilidad con herramientas Pyodide o Python a una aplicación Dune. NO configure manualmente usePyodideRuntime ni conecte pythonRuntime a useAtlasChat: esta habilidad maneja la instalación de pyodide, la configuración del enlace, la carga de la interfaz de usuario y el cableado del enlace de chat. Activadores: Pyodide, herramientas de Python, pythonRuntime, usePyodideRuntime, runPythonCode, ejecución de Python, Python del lado del cliente.
