НЕОБХОДИМО использовать при добавлении поддержки инструментов Pyodide или Python в приложение Dune. НЕ настраивайте вручную usePyodideRuntime и не подключайте pythonRuntime к useAtlasChat — этот навык управляет установкой pyodide, настройкой перехватчика, загрузкой пользовательского интерфейса и подключением перехватчика чата. Триггеры: Pyodide, инструменты Python, pythonRuntime, usePyodideRuntime, runPythonCode, выполнение Python, Python на стороне клиента.
