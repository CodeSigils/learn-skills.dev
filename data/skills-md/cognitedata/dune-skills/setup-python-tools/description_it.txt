DEVE essere utilizzato quando si aggiunge il supporto dello strumento Pyodide o Python a un'app Dune. NON configurare manualmente usePyodideRuntime o collegare pythonRuntime a useAtlasChat: questa abilità gestisce l'installazione di pyodide, la configurazione dell'hook, il caricamento dell'interfaccia utente e il cablaggio dell'hook della chat. Trigger: Pyodide, strumenti Python, pythonRuntime, usePyodideRuntime, runPythonCode, esecuzione Python, Python lato client.
