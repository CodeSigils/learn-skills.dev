Verbindet die Navigationskomponente von @cognite/dune-industrial-components/navigation mit einer Dune-App. Wird verwendet, wenn Sie einer Dune-App einen Navigationsheader, eine obere Navigationsleiste, einen Sticky-Header, Navigationselemente, eine aktive Seite, Navigationslinks, eine Navigationskomponente, eine Designumschaltung oder Unterstützung für den Dunkelmodus hinzufügen.
