DEBE usarse siempre que se integre CogniteFileViewer en una aplicación Dune para obtener una vista previa de archivos CDF (PDF, imágenes, texto). NO conecte manualmente react-pdf o la resolución de archivos: esta habilidad se encarga de la instalación, la configuración de Vite, la configuración del trabajador y el uso de componentes. Activadores: visor de archivos, vista previa de archivos, CogniteFileViewer, visor de PDF, ver archivos CDF, visor de documentos, vista previa de archivos.
