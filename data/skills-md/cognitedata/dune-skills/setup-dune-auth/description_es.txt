DEBE usarse al migrar una aplicación React existente a Dune, o cuando falta DuneAuthProvider en la aplicación. Esta habilidad instala el paquete @cognite/dune, envuelve la aplicación en DuneAuthProvider, configura el complemento Vite y configura el gancho useDune. Activadores: migrar a Dune, agregar autenticación de Dune, DuneAuthProvider, useDune, configuración de Dune, configuración de autenticación, proveedor de autenticación faltante, autenticación CDF, autenticación de iframe Fusion.
