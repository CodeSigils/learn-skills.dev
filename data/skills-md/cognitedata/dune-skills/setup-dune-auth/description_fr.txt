DOIT être utilisé lors de la migration d'une application React existante vers Dune ou lorsque DuneAuthProvider est absent de l'application. Cette compétence installe le package @cognite/dune, encapsule l'application dans DuneAuthProvider, configure le plugin Vite et configure le hook useDune. Déclencheurs : migrer vers Dune, ajouter l'authentification Dune, DuneAuthProvider, useDune, configuration Dune, authentification de configuration, fournisseur d'authentification manquant, authentification CDF, authentification iframe Fusion.
