DEBE usarse siempre que se agregue una función de lista de tareas/cosas por hacer a una aplicación Dune con el chat Atlas. NO cree manualmente la administración del estado de tareas ni definiciones de herramientas: esta habilidad maneja el módulo completo (contexto, proveedor, herramienta, enlaces, componentes de la interfaz de usuario) y todo el cableado de integración. Requisito previo: integrar-atlas-chat ya debe estar configurado. Activadores: lista de tareas pendientes, lista de tareas, seguimiento de tareas, TodoWrite, panel de tareas pendientes, panel de tareas, seguimiento del progreso, agregar todos, agregar tareas.
