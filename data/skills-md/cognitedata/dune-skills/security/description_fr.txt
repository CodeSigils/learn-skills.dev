DOIT être utilisé lors de l'examen d'une application Dune pour des problèmes de sécurité, ou avant d'expédier toute fonctionnalité gérant les informations d'identification, les entrées utilisateur ou les données externes. N'ignorez PAS cette opération lorsque l'utilisateur demande un examen de sécurité, un audit de sécurité ou une vérification de vulnérabilité : exécutez chaque étape dans l'ordre. Déclencheurs : sécurité, examen de sécurité, audit de sécurité, vulnérabilité, XSS, injection, informations d'identification, secrets, authentification, autorisation, jeton, données sensibles, validation d'entrée, CORS, CSP, audit de dépendances.
