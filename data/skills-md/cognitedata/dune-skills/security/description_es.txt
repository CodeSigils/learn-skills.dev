DEBE usarse siempre que se revise una aplicación Dune por problemas de seguridad o antes de enviar cualquier función que maneje credenciales, entradas de usuarios o datos externos. NO omita esto cuando el usuario solicite una revisión de seguridad, una auditoría de seguridad o una verificación de vulnerabilidad; ejecute cada paso en orden. Desencadenantes: seguridad, revisión de seguridad, auditoría de seguridad, vulnerabilidad, XSS, inyección, credenciales, secretos, autenticación, autenticación, autorización, token, datos confidenciales, validación de entrada, CORS, CSP, auditoría de dependencia.
