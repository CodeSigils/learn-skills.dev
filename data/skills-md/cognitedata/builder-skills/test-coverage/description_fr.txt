DOIT être utilisé chaque fois que vous corrigez la couverture de test pour une application Flows afin de répondre à la porte matérielle de couverture de ligne de 80 %. Cette compétence trouve ET corrige les lacunes de couverture : elle configure les outils, écrit les tests manquants, couvre les chemins non testés et refactorise le code pour la testabilité. Il ne s'agit pas seulement de rendre compte. Déclencheurs : couverture de test, correction des tests, écriture de tests, ajout de tests, correction de la couverture, couverture à 80 %, porte de couverture, tests manquants, testabilité, couverture vitest, couverture des plaisanteries.
