DEBE usarse siempre que se solucionen problemas de seguridad en una aplicación Flows o antes de enviar cualquier función que maneje credenciales, entradas de usuarios o datos externos. Esta habilidad encuentra Y soluciona problemas de seguridad; no solo los informa. NO omita esto cuando el usuario solicite una solución de seguridad, un refuerzo de la seguridad o una solución de vulnerabilidad; ejecute cada paso en orden. Desencadenantes: seguridad, corrección de seguridad, refuerzo de seguridad, vulnerabilidad, XSS, inyección, credenciales, secretos, autenticación, autenticación, autorización, token, datos confidenciales, validación de entrada, CORS, CSP, auditoría de dependencia.
