يجب استخدامه عند ترحيل تطبيق React موجود إلى Flows، أو عند عدم توصيل مصادقة Flows. يكتشف تدفق Classic vs Apps API من حقل `app.json` `infra`، ويقوم بتثبيت الحزم المناسبة، وتوصيل ملف الإدخال. لا يمكن تنفيذه عندما يكون إعداد المصادقة الصالح موجودًا بالفعل. المشغلات: الترحيل إلى التدفقات، وإضافة مصادقة التدفقات، وDuneAuthProvider، وAppSdkAuthProvider، وconnectToHostApp، وuseDune، وإعداد التدفقات، ومصادقة الإعداد، وموفر المصادقة المفقود، ومصادقة CDF، ومصادقة Fusion iframe.
