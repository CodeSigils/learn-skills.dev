ДОЛЖЕН использоваться при переносе существующего приложения React в Flows или когда аутентификация Flows не подключена. Обнаруживает поток классического и Apps API из поля `app.json` `infra`, устанавливает нужные пакеты и подключает входной файл. Нет операции, если действительная настройка аутентификации уже установлена. Триггеры: переход на Flows, добавление аутентификации Flows, DuneAuthProvider, AppSdkAuthProvider, ConnectToHostApp, useDune, настройка Flows, настройка аутентификации, отсутствующий поставщик аутентификации, аутентификация CDF, аутентификация Fusion iframe.
