DOIT être utilisé lors de la migration d'une application React existante vers Flows, ou lorsqu'aucune authentification Flows n'est connectée. Détecte le flux API classique vs Apps à partir du champ « app.json » « infra », installe les bons packages et connecte le fichier d'entrée. Aucune opération lorsqu'une configuration d'authentification valide est déjà en place. Déclencheurs : migrez vers Flows, ajoutez l'authentification Flows, DuneAuthProvider, AppSdkAuthProvider, connectToHostApp, useDune, configuration Flows, authentification de configuration, fournisseur d'authentification manquant, authentification CDF, authentification iframe Fusion.
