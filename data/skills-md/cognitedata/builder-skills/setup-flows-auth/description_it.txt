DEVE essere utilizzato durante la migrazione di un'app React esistente a Flows o quando non è collegata alcuna autenticazione di Flows. Rileva il flusso dell'API classica rispetto a quello dell'API Apps dal campo "app.json" "infra", installa i pacchetti corretti e collega il file di ingresso. No-op quando è già in atto una configurazione di autenticazione valida. Trigger: migrazione a Flows, aggiunta autenticazione Flows, DuneAuthProvider, AppSdkAuthProvider, connectToHostApp, useDune, configurazione Flows, configurazione autenticazione, provider di autenticazione mancante, autenticazione CDF, autenticazione iframe Fusion.
