DEBE usarse al migrar una aplicación React existente a Flows, o cuando no hay autenticación de Flows conectada. Detecta el flujo de API clásica frente a Apps desde el campo `app.json` `infra`, instala los paquetes correctos y conecta el archivo de entrada. No operativo cuando ya existe una configuración de autenticación válida. Activadores: migrar a Flows, agregar autenticación de Flows, DuneAuthProvider, AppSdkAuthProvider, connectToHostApp, useDune, configuración de Flows, configuración de autenticación, proveedor de autenticación faltante, autenticación CDF, autenticación de iframe Fusion.
