기존 React 앱을 Flows로 마이그레이션할 때 또는 Flows 인증이 연결되지 않은 경우 반드시 사용해야 합니다. 'app.json' 'infra' 필드에서 클래식 및 Apps API 흐름을 감지하고 올바른 패키지를 설치하고 항목 파일을 연결합니다. 유효한 인증 설정이 이미 설정된 경우 작동하지 않습니다. 트리거: Flows로 마이그레이션, Flows 인증 추가, DuneAuthProvider, AppSdkAuthProvider, connectToHostApp, useDune, Flows 설정, 인증 설정, 인증 공급자 누락, CDF 인증, Fusion iframe 인증.
