DOIT être utilisé lors de l'intégration de CogniteFileViewer dans une application Flows pour prévisualiser les fichiers CDF (PDF, images, texte). Ne connectez PAS manuellement React-PDF ou la résolution de fichier - cette compétence gère l'installation, la configuration de Vite, la configuration des travailleurs et l'utilisation des composants. Déclencheurs : visionneuse de fichiers, aperçu de fichier, CogniteFileViewer, visionneuse PDF, affichage des fichiers CDF, visionneuse de documents, aperçu du fichier.
