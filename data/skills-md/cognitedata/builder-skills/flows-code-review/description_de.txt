Führen Sie eine vollständige Überprüfung der Flows-App-Plattform anhand einer React/TypeScript-CDF-Codebasis durch und befolgen Sie dabei die Bewertungskriterien von cognitedata/dune-app-reviews. Erzeugt drei Artefakte: review-files.md (Bestandsaufnahme pro Datei), review-packages.md (Abhängigkeitsprüfung) und review-report.md (bewerteter Bericht mit Elementen, die unbedingt behoben werden müssen/sollten/sind). Verwenden Sie diese Option, wenn der Benutzer eine Flows-App-Überprüfung, eine Überprüfung vor der Übermittlung, eine Genehmigungsüberprüfung, eine App-Zertifizierungsüberprüfung, ein Codequalitätsaudit, eine CDF-Plattformüberprüfung oder „Dune-Review ausführen“ auf einer Codebasis vor der Übermittlung anfordert.
