cognitedata/dune-app-reviews スコア基準に従って、React/TypeScript CDF コードベースに対して完全な Flows アプリ プラットフォーム レビューを実行します。 review-files.md (ファイルごとのインベントリ)、review-packages.md (依存関係監査)、review-report.md (必須/すべき/適切な修正項目を含むスコア付きレポート) の 3 つのアーティファクトを生成します。ユーザーが Flows アプリのレビュー、送信前レビュー、承認レビュー、アプリ認定レビュー、コード品質監査、CDF プラットフォーム レビュー、または送信前にコードベースでの「砂丘レビューの実行」を要求する場合に使用します。
