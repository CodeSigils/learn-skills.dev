ДОЛЖЕН использоваться при проверке приложения Flows на предмет качества кода, удобства сопровождения или проблем с чистым кодом — перед проверкой PR, после завершения функции или когда пользователь запрашивает проверку кода. НЕ пропускайте этапы линтинга. Триггеры: качество кода, проверка кода, чистый код, рефакторинг, ремонтопригодность, технический долг, любой тип, именование, мертвый код, дублирование, DRY, единая ответственность, размер компонента, проверка, проверка TypeScript, строгий ввод зависимостей, файловая структура.
