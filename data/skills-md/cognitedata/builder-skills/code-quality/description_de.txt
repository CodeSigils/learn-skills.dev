MUSS verwendet werden, wenn eine Flows-App auf Codequalität, Wartbarkeit oder Probleme mit sauberem Code überprüft wird – vor einer PR-Überprüfung, nach Abschluss einer Funktion oder wenn der Benutzer eine Codeüberprüfung anfordert. Überspringen Sie NICHT die Schritte zum Flusen. Auslöser: Codequalität, Codeüberprüfung, sauberer Code, Refaktorierung, Wartbarkeit, technische Schulden, jeder Typ, Benennung, toter Code, Duplizierung, DRY, Einzelverantwortung, Komponentengröße, Lint, Linting, TypeScript streng, Abhängigkeitsinjektion, Dateistruktur.
