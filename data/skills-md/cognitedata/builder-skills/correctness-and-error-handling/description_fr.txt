DOIT être utilisé chaque fois que vous corrigez des problèmes d’exactitude et de gestion des erreurs dans une application Flows. Cette compétence détecte ET corrige les bogues, les états d’erreur manquants, les rejets non gérés et les échecs extrêmes – elle ne se contente pas de les signaler. Déclencheurs : exactitude, gestion des erreurs, correction de bugs, cas extrêmes, crash, non géré, nul, non défini, état vide, état de chargement, limite d'erreur, try catch, erreur asynchrone, nettoyage useEffect, type guard, erreur d'exécution, robustesse.
