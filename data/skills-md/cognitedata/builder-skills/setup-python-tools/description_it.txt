DEVE essere utilizzato quando si aggiunge il supporto dello strumento Pyodide o Python a un'app Flows. NON configurare manualmente usePyodideRuntime o collegare pythonRuntime a useAtlasChat: questa abilità gestisce l'installazione di pyodide, la configurazione dell'hook, il caricamento dell'interfaccia utente e il cablaggio dell'hook della chat. Prerequisito: integral-atlas-chat (src/atlas-agent fornito + cablaggio atlas chat). Trigger: Pyodide, strumenti Python, pythonRuntime, usePyodideRuntime, runPythonCode, esecuzione Python, Python lato client.
