يجب استخدامه عند إضافة دعم أداة Pyodide أو Python إلى تطبيق Flows. لا تقم بتكوين usePyodideRuntime أو توصيل pythonRuntime يدويًا إلى useAtlasChat - فهذه المهارة تتعامل مع تثبيت pyodide، وإعداد الخطاف، وتحميل واجهة المستخدم، وأسلاك ربط الدردشة. المتطلب السابق: دمج atlas-chat (وكيل src/atlas المورّد + أسلاك دردشة atlas). المشغلات: Pyodide، أدوات Python، pythonRuntime، usePyodideRuntime، runPythonCode، تنفيذ Python، Python من جانب العميل.
