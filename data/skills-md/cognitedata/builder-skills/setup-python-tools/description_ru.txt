НЕОБХОДИМО использовать при добавлении поддержки инструментов Pyodide или Python в приложение Flows. НЕ настраивайте вручную usePyodideRuntime и не подключайте pythonRuntime к useAtlasChat — этот навык управляет установкой pyodide, настройкой перехватчика, загрузкой пользовательского интерфейса и подключением перехватчика чата. Предварительное условие: интегрировать-атлас-чат (поставляемый src/atlas-agent + подключение чата атласа). Триггеры: Pyodide, инструменты Python, pythonRuntime, usePyodideRuntime, runPythonCode, выполнение Python, Python на стороне клиента.
