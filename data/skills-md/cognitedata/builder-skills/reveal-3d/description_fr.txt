Intègre un ensemble de visionneuse CAO 3D Cognite Reveal local dans les applications Flows en copiant le code source local de l'application. À utiliser lors de l'ajout d'une visionneuse 3D, d'une visualisation 3D, de Reveal, d'un modèle CAO, de RevealProvider, de RevealCanvas, de Reveal3DResources, d'un mappage 3D FDM, d'un modèle d'actif 3D, d'un navigateur de modèles ou de contenu Cognite 3D à une application Flows.
