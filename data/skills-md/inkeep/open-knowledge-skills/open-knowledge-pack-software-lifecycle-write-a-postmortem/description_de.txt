Schreiben Sie unter „Postmortems“ einen postmortalen Vorfall ohne Schuldzuweisungen und folgen Sie dabei der Google-SRE-Form – evidenzbasierter Zeitplan, Auslöser vs. Grundursache vs. Symptom, beitragende Faktoren, was gut gelaufen ist und eigene, datierte und überprüfbare Maßnahmen. Lesen Sie es, wenn Sie aufgefordert werden, eine Post-Mortem-Analyse zu verfassen, eine Überprüfung des Vorfalls durchzuführen, eine Ursachenanalyse durchzuführen, den Ausfall zu dokumentieren, den Ausfall nachzuprüfen oder wenn der Benutzer angibt, dass wir einen Vorfall hatten und ihn dokumentieren möchten. Lesen Sie NICHT, um einen Vorschlag zu formulieren (verwenden Sie Frame-a-Proposal), schreiben Sie eine Spezifikation (verwenden Sie Write-a-Spec), zeichnen Sie eine Entscheidung auf (verwenden Sie Record-a-Decision) oder überprüfen Sie einen Entwurf (verwenden Sie Review-a-Design) – ein Postmortem dokumentiert einen Vorfall, der bereits stattgefunden hat, es wird keine zukünftige Arbeit vorgeschlagen, spezifiziert, entschieden oder kritisiert.
