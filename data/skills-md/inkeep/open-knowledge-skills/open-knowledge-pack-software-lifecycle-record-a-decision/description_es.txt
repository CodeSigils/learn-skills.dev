Registra una decisión de arquitectura como un ADR en forma de Nygard/MADR bajo decisiones/: captura el contexto que forzó la elección, las opciones sopesadas, la decisión en sí y sus consecuencias en ambas direcciones, además de la cadena de reemplazos que mantiene honesto el registro de decisiones. Lea cuando se le solicite registrar una decisión arquitectónica, escribir un ADR, registrar la decisión que tomamos, documentar por qué elegimos X sobre Y, capturar esta decisión para el registro o reemplazar una decisión anterior por una nueva. NO lea para formular una propuesta o explorar una idea aún no decidida (elaborar una propuesta), para escribir una especificación o un plan de implementación (escribir una especificación), para escribir una autopsia de un incidente (escribir una autopsia) o para juzgar si un diseño es sólido (revisar un diseño). Esta habilidad registra una decisión ya tomada; no lo hace.
