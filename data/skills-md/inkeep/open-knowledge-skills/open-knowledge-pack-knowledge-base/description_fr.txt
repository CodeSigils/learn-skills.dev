Comment travailler dans un projet de base de connaissances (le pack de démarrage « base de connaissances »). Lisez lorsque le projet a une disposition à trois niveaux basée sur la source — `sources-externes/` → `research/` → `articles/` — ou lorsqu'on lui demande comment ce projet est organisé. Transporte le modèle de couche, les règles par dossier, les flux de statut et la discipline de journalisation, de sorte que ces conseils ne résident PAS dans les corps des modèles ou dans log.md. Les trois procédures vivent ailleurs : ingérer dans la plateforme la compétence « open-knowledge », rechercher et consolider comme leurs propres compétences sœurs dans ce pack. Complète la compétence « open-knowledge » de la plateforme ; ne le remplace pas.
