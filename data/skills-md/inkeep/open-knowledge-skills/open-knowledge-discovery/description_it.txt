Leggi quando l'utente chiede cos'è OpenKnowledge, vuole installarlo su un repository, vuole aprire o visualizzare in anteprima un singolo file markdown che non fa parte di un progetto OpenKnowledge, vuole condividere un progetto OpenKnowledge con i collaboratori o chiede come `ok init` / `ok cowork` / OK Desktop imposta un progetto. NON caricare per eseguire letture/scritture OpenKnowledge: la guida di runtime per la modifica del markdown all'interno di un progetto OK inizializzato viene fornita come competenza locale del progetto separata in `.claude/skills/open-knowledge/` ogni volta che viene eseguito `ok init`.
