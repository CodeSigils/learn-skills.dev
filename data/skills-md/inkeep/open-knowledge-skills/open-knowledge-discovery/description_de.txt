Wird gelesen, wenn der Benutzer fragt, was OpenKnowledge ist, es in einem Repository installieren möchte, eine einzelne Markdown-Datei öffnen oder in der Vorschau anzeigen möchte, die nicht Teil eines OpenKnowledge-Projekts ist, ein OpenKnowledge-Projekt mit Mitarbeitern teilen möchte oder fragt, wie „ok init“ / „ok cowork“ / OK Desktop ein Projekt eingerichtet hat. NICHT laden, um OpenKnowledge-Lese-/Schreibvorgänge durchzuführen – die Laufzeitanleitung zum Bearbeiten von Markdown innerhalb eines initialisierten OK-Projekts wird als separater projektlokaler Skill unter „.claude/skills/open-knowledge/“ geliefert, wann immer „ok init“ ausgeführt wird.
