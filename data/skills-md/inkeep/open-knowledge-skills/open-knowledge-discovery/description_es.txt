Lea cuando el usuario pregunta qué es OpenKnowledge, quiere instalarlo en un repositorio, quiere abrir o obtener una vista previa de un único archivo de rebajas que no forma parte de un proyecto de OpenKnowledge, quiere compartir un proyecto de OpenKnowledge con colaboradores o pregunta cómo `ok init`/`ok cowork`/OK Desktop configura un proyecto. NO cargue para realizar lecturas/escrituras de OpenKnowledge: la guía de tiempo de ejecución para editar Markdown dentro de un proyecto OK inicializado se envía como una habilidad local del proyecto independiente en `.claude/skills/open-knowledge/` cada vez que se ejecuta `ok init`.
