Contratto runtime agente autorevole per lavorare all'interno di un progetto OpenKnowledge: una base di conoscenza CRDT markdown esposta su MCP. Da utilizzare ogni volta che si legge, si elenca, si cerca, si modifica o si esegue l'linting di qualsiasi file `.md` o `.mdx` nel progetto e prima di qualsiasi chiamata dello strumento `mcp__open-knowledge__*` (`exec`, `search`, `write`, `edit`, `lint` e il resto). Installato da "ok init", quindi la sua presenza significa che si tratta di un progetto OpenKnowledge e governa ogni file di markdown qui. Copre la superficie dello strumento di lettura/scrittura, le regole di base e di collegamento, le convenzioni di cartelle/modelli, l'anteprima del browser in tempo reale e la regola secondo cui gli strumenti MCP di OK, mai gli strumenti di file nativi, gestiscono il markdown nell'ambito.
