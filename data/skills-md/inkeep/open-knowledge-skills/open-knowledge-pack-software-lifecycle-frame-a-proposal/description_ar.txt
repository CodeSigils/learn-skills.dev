ضع إطارًا لمقترح تصميم جديد (على شكل RFC) ضمن المقترحات/ - المشكلة قبل الحل، والمستفيد المسمى والتغيير الملحوظ، والبدائل الحقيقية، والعيوب الصادقة، وتراكم الأسئلة المفتوحة المباشرة. اقرأ عندما يُطلب منك صياغة اقتراح، أو كتابة RFC، أو اقتراح تصميم، أو اقتراح تغيير، أو صياغة مستند تصميم على طراز PRD، أو فتح مقترح تصميم للمراجعة. لا تقرأ لتسجيل قرار بعد قبوله (استخدم سجل القرار)، أو لكتابة مواصفات التنفيذ (استخدم كتابة المواصفات)، أو لكتابة تقرير تشريحي (استخدم كتابة بعد الوفاة)، أو لمراجعة أو نقد تصميم موجود (استخدم مراجعة التصميم).
