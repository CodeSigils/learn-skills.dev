Gestalten Sie einen neuen Designvorschlag (RFC-Form) unter Vorschläge/ – Problem vor Lösung, benannter Nutznießer und beobachtbare Änderung, echte Alternativen, ehrliche Nachteile und ein Live-Rückstand offener Fragen. Lesen Sie, wenn Sie aufgefordert werden, einen Vorschlag zu formulieren, einen RFC zu schreiben, einen Entwurf vorzuschlagen, eine Änderung vorzuschlagen, ein Designdokument im PRD-Stil zu entwerfen oder einen Designvorschlag zur Überprüfung zu öffnen. Lesen Sie NICHT, um eine Entscheidung aufzuzeichnen, nachdem sie akzeptiert wurde (verwenden Sie „Record-a-Decision“), um eine Implementierungsspezifikation zu schreiben (verwenden Sie „Write-a-Spec“), um eine Post-Mortem-Analyse zu verfassen (verwenden Sie „Write-a-Postmortem“) oder um ein bestehendes Design zu überprüfen oder zu kritisieren (verwenden Sie „Review-a-Design“).
