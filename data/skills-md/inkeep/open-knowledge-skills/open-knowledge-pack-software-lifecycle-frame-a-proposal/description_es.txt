Enmarque una nueva propuesta de diseño (en forma de RFC) en propuestas/problema antes de solución, beneficiario designado y cambio observable, alternativas reales, inconvenientes honestos y una acumulación de preguntas abiertas en vivo. Lea cuando se le solicite formular una propuesta, escribir un RFC, proponer un diseño, proponer un cambio, redactar un documento de diseño estilo PRD o abrir una propuesta de diseño para su revisión. NO lea para registrar una decisión después de ser aceptada (use registrar una decisión), para escribir una especificación de implementación (use escribir una especificación), para escribir una autopsia (use escribir una autopsia) o para revisar o criticar un diseño existente (use revisar un diseño).
