Comment travailler dans un projet Software Lifecycle (le pack de démarrage « Software-Lifecycle ») : propositions → décisions → spécifications → post-mortems, ainsi que des guides. Lisez quand le projet dispose de ces dossiers, ou lorsqu'on vous demande comment ce projet est organisé. Transporte le cycle de vie du document, les flux de statut et les comportements des agents par dossier afin que les instructions ne résident pas dans les corps des modèles ou les descriptions de dossiers. Les cinq flux de travail – formuler une proposition, rédiger une spécification, enregistrer une décision, rédiger une autopsie, réviser une conception – chacun est livré comme sa propre compétence sœur dans ce pack. Complète la compétence « open-knowledge » de la plateforme ; ne le remplace pas.
