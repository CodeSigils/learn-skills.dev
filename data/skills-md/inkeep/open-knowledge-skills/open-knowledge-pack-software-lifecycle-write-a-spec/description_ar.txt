حدد نطاق الميزة من البداية إلى النهاية واكتب مواصفات التنفيذ ضمن المواصفات/من اقتراح مقبول - تعيين النظام الحالي، والأهداف/غير الأهداف، وسجل القرار لاختيارات الباب الواحد، وتراكم الأسئلة المفتوحة المباشرة، وخطة ترحيل + اختبار حقيقية. اقرأ عندما يُطلب منك كتابة مواصفات، أو تحديد نطاق هذه الميزة، أو تحويل هذا الاقتراح إلى مواصفات، أو التخطيط للتنفيذ، أو تقسيم ذلك إلى مهام. لا تقم بإطلاق عرض مقترح أو كتابة PRD (إطار اقتراح للأخوة - يقوم PRD بتأطير التغيير قبل قبوله؛ وتبدأ هذه المهارة بمجرد قبوله)، أو تسجيل قرار أو كتابة ADR (تسجيل قرار)، أو كتابة تقرير ما بعد الوفاة (كتابة ما بعد الوفاة)، أو مراجعة هذا التصميم (مراجعة التصميم) - فهذه مهارات منفصلة. يكمل مهارة المعرفة المفتوحة للمنصة؛ لا يحل محله.
