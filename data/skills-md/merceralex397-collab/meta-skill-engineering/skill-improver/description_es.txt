Mejore un paquete de habilidades existente: ajuste el enrutamiento, afine el procedimiento, agregue o elimine capas de soporte, actualice el paquete. Úselo cuando el usuario diga "mejorar esta habilidad", "esta habilidad es débil/vaga/inflada", "fortalecer este SKILL.md" o "agregar evaluaciones/referencias a este paquete de habilidades". No lo use para crear una nueva habilidad desde cero (use el creador de habilidades), correcciones de solo activación cuando el cuerpo está bien (use optimización de activación de habilidades), portar una habilidad a una pila o contexto diferente (use adaptación de habilidades) o auditorías estructurales rápidas sin reescritura (use antipatrones de habilidades).
