Poussez le projet en un clic vers GitHub. Analysez automatiquement les fichiers volumineux, générez .gitignore, initialisez Git, créez un référentiel et envoyez. Prend en charge les modes de première poussée, de mises à jour quotidiennes et de publication. Déclenché lorsque l'utilisateur dit « pousser vers GitHub », « pousser vers GitHub », « git push », « télécharger sur GitHub », « publier », « créer une version » ou « /git-push ».
