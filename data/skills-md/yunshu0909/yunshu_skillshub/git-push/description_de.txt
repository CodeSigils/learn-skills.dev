Push-Projekt mit einem Klick auf GitHub. Große Dateien automatisch scannen, .gitignore generieren, Git initialisieren, Repository erstellen und pushen. Unterstützt First Push, tägliche Updates und Release-Versionen. Wird ausgelöst, wenn der Benutzer „Push to GitHub“, „Push to GitHub“, „Git Push“, „Upload to GitHub“, „Release“, „Make Release“ oder „/git-push“ sagt.
