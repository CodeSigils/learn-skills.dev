Отправьте проект на GitHub одним щелчком мыши. Автоматически сканируйте большие файлы, генерируйте .gitignore, инициализируйте Git, создайте репозиторий и отправляйте их. Поддерживает режимы первого обновления, ежедневных обновлений и выпуска версий. Срабатывает, когда пользователь говорит «отправить на GitHub», «отправить на GitHub», «git push», «загрузить на GitHub», «выпустить версию», «сделать выпуск», «/git-push».
