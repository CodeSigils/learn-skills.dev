دليل Software Mansion لترحيل تطبيقات Expo SDK إلى Meta Quest باستخدام حزم expo-horizon. يُستخدم عند إضافة دعم Meta Quest أو Meta Horizon OS إلى مشروع Expo أو React Native موجود. تشغيل: Meta Quest، Horizon OS، Quest 2، Quest 3، Quest 3S، تطبيق VR، expo-horizon-core، expo-horizon-location، إشعارات expo-horizon، بناء النكهات لـ Quest، تغيير حجم اللوحة، تتبع الرأس VR، معرف تطبيق Horizon، متغير بناء المهمة، isHorizonDevice، isHorizonBuild، ترحيل موقع المعرض إلى Quest، ترحيل إشعارات المعرض الخاصة بـ Quest أو نشر Meta Horizon Store أو أي مهمة تتضمن تشغيل تطبيق Expo على أجهزة Meta Quest.
