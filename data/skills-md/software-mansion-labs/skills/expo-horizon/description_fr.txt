Guide de Software Mansion pour la migration des applications Expo SDK vers Meta Quest à l'aide des packages expo-horizon. À utiliser lors de l'ajout de la prise en charge de Meta Quest ou Meta Horizon OS à un projet Expo ou React Native existant. Déclenchez sur : Meta Quest, Horizon OS, Quest 2, Quest 3, Quest 3S, application VR, expo-horizon-core, expo-horizon-location, expo-horizon-notifications, versions de build pour Quest, dimensionnement des panneaux, headtracking VR, Horizon App ID, variante de construction de quête, isHorizonDevice, isHorizonBuild, migrer l'emplacement d'exposition vers Quest, migrer les notifications d'expo vers Quest, publication Meta Horizon Store ou toute tâche impliquant l'exécution d'une application Expo sur le matériel Meta Quest.
