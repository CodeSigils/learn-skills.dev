Guía de Software Mansion para migrar aplicaciones Expo SDK a Meta Quest usando paquetes expo-horizon. Úselo al agregar compatibilidad con Meta Quest o Meta Horizon OS a un proyecto Expo o React Native existente. Activar: Meta Quest, Horizon OS, Quest 2, Quest 3, Quest 3S, aplicación de realidad virtual, expo-horizon-core, expo-horizon-location, expo-horizon-notifications, versiones de compilación para Quest, tamaño del panel, seguimiento de cabeza de realidad virtual, ID de aplicación Horizon, variante de compilación de misiones, isHorizonDevice, isHorizonBuild, migrar ubicación de exposición a Quest, migrar notificaciones de exposición a Quest, Meta Horizon Store publicación o cualquier tarea que implique ejecutar una aplicación Expo en el hardware Meta Quest.
