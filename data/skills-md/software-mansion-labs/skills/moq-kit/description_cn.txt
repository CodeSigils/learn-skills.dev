Software Mansion 的 moq-kit — 用于基于 QUIC (moq-lite) 实时流媒体的原生 Swift (iOS) 和 Kotlin (Android) SDK：亚秒级延迟播放、相机/麦克风/屏幕发布以及通过 MoQ 中继的实时数据跟踪。在编写、审查或调试任何导入 MoQKit (Swift) 或 com.swmansion.moqkit (Kotlin) 的代码之前必须使用；对于 React Native 应用程序，请使用react-native-moq 技能。触发：'moq-kit'、'MoQKit'、'Media over QUIC'、'moq-lite'、'MoQ Relay'、'moq-ffi'、'BroadcastSubscription'、'DataTrackEmitter'、'CameraCapture'、'MicrophoneCapture'、'MultiCameraCapture'、'ScreenCapture'、'TrackSubscription'、 'AudioDataStream'、'MoQReplayKitBroadcastSampleHandler' 或 moq-kit 中的会话/播放器/发布者/目录。
