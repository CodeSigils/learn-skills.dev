Moq-kit от Software Mansion — встроенные SDK Swift (iOS) и Kotlin (Android) для потоковой передачи мультимедиа через QUIC (moq-lite): воспроизведение с задержкой менее секунды, публикация с камеры/микрофона/экрана и отслеживание данных в реальном времени через ретранслятор MoQ. ОБЯЗАТЕЛЬНО ИСПОЛЬЗУЙТЕ перед написанием, проверкой или отладкой ЛЮБОГО кода, который импортирует MoQKit (Swift) или com.swmansion.moqkit (Kotlin); для приложений React Native вместо этого используйте навык реагирования-native-moq.
