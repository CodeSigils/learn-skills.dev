Kit moq de Software Mansion : SDK natifs Swift (iOS) et Kotlin (Android) pour la diffusion en direct de médias sur QUIC (moq-lite) : lecture avec une latence inférieure à la seconde, publication par caméra/microphone/écran et pistes de données en temps réel via un relais MoQ. DOIT UTILISER avant d'écrire, de réviser ou de déboguer TOUT code qui importe MoQKit (Swift) ou com.swmansion.moqkit (Kotlin) ; pour les applications React Native, utilisez plutôt la compétence React-Native-moq. Déclenchez sur : 'moq-kit', 'MoQKit', 'Media over QUIC', 'moq-lite', 'MoQ relay', 'moq-ffi', 'BroadcastSubscription', 'DataTrackEmitter', 'CameraCapture', 'MicrophoneCapture', 'MultiCameraCapture', 'ScreenCapture', 'TrackSubscription', « AudioDataStream », « MoQReplayKitBroadcastSampleHandler » ou une session/lecteur/éditeur/catalogue de moq-kit.
