Das Moq-Kit von Software Mansion – native Swift (iOS) und Kotlin (Android) SDKs für Medien über QUIC (moq-lite) Live-Streaming: Wiedergabe mit einer Latenzzeit von weniger als einer Sekunde, Veröffentlichung von Kamera/Mikrofon/Bildschirm und Echtzeit-Datenspuren über ein MoQ-Relay. MUSS vor dem Schreiben, Überprüfen oder Debuggen von Code verwendet werden, der MoQKit (Swift) oder com.swmansion.moqkit (Kotlin) importiert. Verwenden Sie für React Native-Apps stattdessen die Fähigkeit „react-native-moq“.
