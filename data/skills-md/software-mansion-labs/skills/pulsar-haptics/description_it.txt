Implementa, migra, progetta, rivedi e risolvi i problemi del feedback tattile con Software Mansion Pulsar su React Native, iOS, Android, Kotlin Multiplatform, Flutter e Web. Utilizzare quando l'utente nomina Pulsar; un pacchetto Pulsar come react-native-pulsar, com.swmansion:pulsar, com.swmansion:pulsar-kmp, pulsar_haptics o pulsar-haptics; un problema di importazione, preimpostazione, compositore, impostazione, installazione, migrazione o runtime di Pulsar; o richiede esplicitamente la migrazione a Pulsar. Non utilizzare per aptica generica, vibrazione, Core Haptics, API di vibrazione del browser, expo-aptica, animazione, audio, movimento o lavori di perfezionamento dell'interfaccia utente senza prove Pulsar o intenti Pulsar espliciti.
