Implémentez, migrez, concevez, examinez et dépannez le retour haptique avec Software Mansion Pulsar sur React Native, iOS, Android, Kotlin Multiplatform, Flutter et Web. À utiliser lorsque l'utilisateur nomme Pulsar ; un package Pulsar tel que React-native-pulsar, com.swmansion:pulsar, com.swmansion:pulsar-kmp, pulsar_haptics ou pulsar-haptics ; un problème d'importation, de préréglage, de composition, de paramétrage, d'installation, de migration ou d'exécution Pulsar ; ou demande explicitement la migration vers Pulsar. Ne pas utiliser pour des travaux génériques d'haptique, de vibration, de Core Haptics, d'API de vibration du navigateur, d'expo-haptique, d'animation, d'audio, de mouvement ou de polissage de l'interface utilisateur sans preuve Pulsar ou intention explicite de Pulsar.
