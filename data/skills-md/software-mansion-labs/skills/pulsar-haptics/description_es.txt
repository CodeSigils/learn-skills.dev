Implemente, migre, diseñe, revise y solucione problemas de retroalimentación háptica con Software Mansion Pulsar en React Native, iOS, Android, Kotlin Multiplatform, Flutter y Web. Úselo cuando el usuario nombra Pulsar; un paquete Pulsar como react-native-pulsar, com.swmansion:pulsar, com.swmansion:pulsar-kmp, pulsar_haptics o pulsar-haptics; un problema de importación, preajuste, composición, configuración, instalación, migración o tiempo de ejecución de Pulsar; o solicita explícitamente la migración a Pulsar. No lo utilice para hápticos genéricos, vibración, Core Haptics, API de vibración del navegador, expo-hápticos, animación, audio, movimiento o trabajos de pulido de interfaz de usuario sin evidencia de Pulsar o intención explícita de Pulsar.
