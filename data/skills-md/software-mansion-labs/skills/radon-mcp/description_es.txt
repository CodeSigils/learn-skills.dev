Mejores prácticas para utilizar las herramientas MCP de Radon IDE al desarrollar, depurar e inspeccionar aplicaciones React Native y Expo. Úselo al interactuar con una aplicación en ejecución a través de Radon IDE: ver capturas de pantalla, leer registros, inspeccionar el árbol de componentes, depurar solicitudes de red, recargar la aplicación o consultar la documentación y la información de la biblioteca de React Native.
