Best practice per l'utilizzo degli strumenti MCP di Radon IDE durante lo sviluppo, il debug e l'ispezione delle app React Native ed Expo. Da utilizzare quando si interagisce con un'app in esecuzione tramite Radon IDE: visualizzazione di schermate, lettura di registri, ispezione dell'albero dei componenti, debug di richieste di rete, ricaricamento dell'app o query sulla documentazione di React Native e sulle informazioni sulla libreria. Attivazione su: "debug di React Native", "correzione dell'interfaccia utente", "problemi di rete", "problemi di creazione", "Radon IDE", "visualizzazione screenshot", "log app", "albero dei componenti", "ispettore di rete", "ricarica app", "documenti React Native", "descrizione della libreria", "emulatore", "viewport di sviluppo", 'view_screenshot', 'view_application_logs', 'view_component_tree', 'reload_application', 'view_network_logs', 'view_network_request_details', 'query_documentation', 'get_library_description' e ogni richiesta che coinvolge l'ispezione, il debug o lo sviluppo di app live in una sessione IDE Radon.
