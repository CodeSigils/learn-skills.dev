Best Practices für die Verwendung der MCP-Tools von Radon IDE beim Entwickeln, Debuggen und Überprüfen von React Native- und Expo-Apps. Wird verwendet, wenn Sie über Radon IDE mit einer laufenden App interagieren – Screenshots anzeigen, Protokolle lesen, den Komponentenbaum überprüfen, Netzwerkanforderungen debuggen, die App neu laden oder React Native-Dokumentation und Bibliotheksinformationen abfragen.
