React Native および Expo アプリの開発、デバッグ、検査時に Radon IDE の MCP ツールを使用するためのベスト プラクティス。 Radon IDE を介して実行中のアプリを操作するときに使用します。スクリーンショットの表示、ログの読み取り、コンポーネント ツリーの検査、ネットワーク リクエストのデバッグ、アプリのリロード、React Native のドキュメントとライブラリ情報のクエリなどです。トリガー: 「React Native のデバッグ」、「UI の修正」、「ネットワークの問題」、「ビルドの問題」、「Radon IDE」、「スクリーンショットの表示」、「アプリ ログ」、「コンポーネント ツリー」、「ネットワーク インスペクター」、「アプリのリロード」、「React Native ドキュメント」、「ライブラリの説明」、「エミュレータ」、「開発ビューポート」、 「view_screenshot」、「view_application_logs」、「view_component_tree」、「reload_application」、「view_network_logs」、「view_network_request_details」、「query_documentation」、「get_library_description」、および Radon IDE セッションでのライブ アプリ インスペクション、デバッグ、または開発を含むすべてのリクエスト。
