أفضل الممارسات لاستخدام أدوات MCP الخاصة بـ Radon IDE عند تطوير تطبيقات React Native وExpo وتصحيح أخطائها وفحصها. يُستخدم عند التفاعل مع تطبيق قيد التشغيل من خلال Radon IDE - عرض لقطات الشاشة، أو قراءة السجلات، أو فحص شجرة المكونات، أو تصحيح أخطاء طلبات الشبكة، أو إعادة تحميل التطبيق، أو الاستعلام عن وثائق React Native ومعلومات المكتبة. تشغيل: "تصحيح أخطاء React Native"، "إصلاح واجهة المستخدم"، "مشكلات الشبكة"، "مشكلات البناء"، "Radon IDE"، "عرض لقطة الشاشة"، "سجلات التطبيق"، "شجرة المكونات"، "مفتش الشبكة"، "إعادة تحميل التطبيق"، "مستندات React Native"، "وصف المكتبة"، "المحاكي"، "منفذ عرض التطوير"، "view_screenshot"، "view_application_logs"، و"view_component_tree"، و"reload_application"، و"view_network_logs"، و"view_network_request_details"، و"query_documentation"، و"get_library_description"، وكل طلب يتضمن فحص التطبيق المباشر أو تصحيح الأخطاء أو التطوير في جلسة Radon IDE.
