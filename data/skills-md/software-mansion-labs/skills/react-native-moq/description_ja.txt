Software Mansion の React-native-moq — React Native 用の Media over QUIC (MoQ) ライブ ストリーミング: 1 秒未満の遅延ビデオ/オーディオ再生、カメラ/マイク/画面パブリッシング、および MoQ リレーを介したリアルタイム データ トラック。 React-native-moq または React-native-moq-ui を使用するコードを作成、レビュー、またはデバッグする前に使用する必要があります。トリガー: 'react-native-moq'、'MoQ'、'Media over QUIC'、'moqリレー'、'moq-kit'、'useSession'、'useBroadcasts'、'useVideoPlayer'、'useAudioPlayer'、'usePublisher'、'useCamera'、'useMultiCamera'、'useMicrophone'、 'useScreenBroadcast'、'useDataTrack'、'useDataMessages'、'useAudioChunks'、'useAudioSource'、'useVideoSource'、'VideoView'、'PublisherView'、'VideoPlayerView'、'BroadcastPickerView'、'createSession'、'createPublisher'、'subscribeBroadcasts'。
