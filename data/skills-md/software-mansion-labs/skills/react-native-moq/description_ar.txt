برنامج React-Native-moq الخاص بـ Software Mansion - البث المباشر للوسائط عبر QUIC (MoQ) لـ React Native: تشغيل الفيديو/الصوت بزمن وصول أقل من ثانية، ونشر الكاميرا/الميكروفون/الشاشة، وتتبع البيانات في الوقت الفعلي عبر ترحيل MoQ. يجب استخدامه قبل كتابة أو مراجعة أو تصحيح أي كود يستخدم React-Native-moq أو React-Native-moq-ui. تشغيل: "react-native-moq"، "MoQ"، "Media over QUIC"، "moq Relay"، "moq-kit"، "useSession"، "useBroadcasts"، "useVideoPlayer"، "useAudioPlayer"، "usePublisher"، "useCamera"، "useMultiCamera"، "useMicrophone"، "useScreenBroadcast"، "useDataTrack"، "useDataMessages"، "useAudioChunks"، "useAudioSource"، "useVideoSource"، "VideoView"، "PublisherView"، "VideoPlayerView"، "BroadcastPickerView"، "createSession"، "createPublisher"، "subscribeBroadcasts".
