Лучшие практики по интеграции и использованию RNRepo — инфраструктуры Software Mansion для предварительно созданных артефактов библиотеки React Native, которая сокращает время собственной сборки почти в 2 раза. Используйте при установке, настройке или устранении неполадок RNRepo в проекте React Native или Expo.
