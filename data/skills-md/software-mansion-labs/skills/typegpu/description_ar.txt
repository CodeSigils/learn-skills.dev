TypeGPU هو WebGPU آمن للنوع في TypeScript. يُستخدم عندما يكتب المستخدم كود TypeGPU أو يصحح أخطاءه أو يصممه: وظائف تظليل "استخدام gpu"، وtgpu.fn، والمخازن المؤقتة، والأنسجة، ومجموعات الربط، وحساب وعرض خطوط الأنابيب، وتخطيطات قمة الرأس، والفتحات، والملحقات، وأي واجهة برمجة تطبيقات TypeGPU. منطق التظليل وموارد جانب وحدة المعالجة المركزية مقترنتان بإحكام - تعامل مع كلا الجانبين هنا حتى لو ذكر المستخدم واحدًا فقط (على سبيل المثال، "كيف أكتب تظليلًا"، "كيف أقوم بإنشاء مخزن مؤقت"). قم بتشغيل أي إشارة إلى كود typegpu أو tgpu أو "استخدام gpu" أو TypedGPU أو WebGPU المكتوب باستخدام واجهة برمجة تطبيقات مخطط TypeGPU (d.*, tgpu.*, std.*). لا تقم بتشغيل WebGPU الخام (باستخدام GPUDevice/GPURenderPipeline مباشرة بدون tgpu)، أو أسئلة WGSL فقط، أو Three.js، أو Babylon.js، أو WebGL.
