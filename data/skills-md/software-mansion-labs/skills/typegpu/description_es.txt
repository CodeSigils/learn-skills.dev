TypeGPU es WebGPU con seguridad de tipos en TypeScript. Úselo siempre que el usuario escriba, depure o diseñe código TypeGPU: funciones de sombreado 'usar gpu', tgpu.fn, búferes, texturas, grupos de enlace, canalizaciones de cálculo y renderizado, diseños de vértices, ranuras, descriptores de acceso y cualquier API de TypeGPU. La lógica del sombreador y los recursos del lado de la CPU están estrechamente vinculados: maneje ambos lados aquí incluso si el usuario solo menciona uno (por ejemplo, "cómo escribo un sombreador", "cómo creo un búfer"). Se activa ante cualquier mención de código typegpu, tgpu, "use gpu", TypedGPU o WebGPU escrito utilizando la API de esquema de TypeGPU (d.*, tgpu.*, std.*). NO active WebGPU sin procesar (usando GPUDevice/GPURenderPipeline directamente sin tgpu), preguntas solo WGSL, Three.js, Babylon.js o WebGL.
