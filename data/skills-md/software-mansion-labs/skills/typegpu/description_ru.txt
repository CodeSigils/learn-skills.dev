TypeGPU — это типобезопасный WebGPU в TypeScript. Используйте всякий раз, когда пользователь пишет, отлаживает или проектирует код TypeGPU: используйте шейдерные функции «gpu», tgpu.fn, буферы, текстуры, группы привязок, конвейеры вычислений и рендеринга, макеты вершин, слоты, средства доступа и любой API TypeGPU. Логика шейдера и ресурсы на стороне ЦП тесно связаны — здесь обрабатываются обе стороны, даже если пользователь упоминает только одну (например, «как мне написать шейдер», «как мне создать буфер»). Срабатывает при любом упоминании кода typegpu, tgpu, «use gpu», TypedGPU или WebGPU, написанного с использованием API схемы TypeGPU (d.*, tgpu.*, std.*). НЕ запускайте запуск для необработанного WebGPU (с использованием GPUDevice/GPURenderPipeline напрямую без tgpu), вопросов только для WGSL, Three.js, Babylon.js или WebGL.
