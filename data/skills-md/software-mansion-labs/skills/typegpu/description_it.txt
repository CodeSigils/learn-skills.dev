TypeGPU è una WebGPU indipendente dal tipo in TypeScript. Da utilizzare ogni volta che l'utente scrive, esegue il debug o progetta il codice TypeGPU: funzioni shader "usa gpu", tgpu.fn, buffer, texture, gruppi di associazione, pipeline di calcolo e rendering, layout dei vertici, slot, funzioni di accesso e qualsiasi API TypeGPU. La logica dello shader e le risorse lato CPU sono strettamente collegate: qui gestisci entrambi i lati anche se l'utente ne menziona solo uno (ad esempio "come faccio a scrivere uno shader", "come faccio a creare un buffer"). Attivazione su qualsiasi menzione di codice typegpu, tgpu, "usa gpu", TypedGPU o WebGPU scritto utilizzando l'API dello schema TypeGPU (d.*, tgpu.*, std.*). NON attivare per WebGPU non elaborata (utilizzando GPUDevice/GPURenderPipeline direttamente senza tgpu), domande solo WGSL, Three.js, Babylon.js o WebGL.
