TypeGPU 是 TypeScript 中类型安全的 WebGPU。每当用户编写、调试或设计 TypeGPU 代码时使用：“使用 gpu”着色器函数、tgpu.fn、缓冲区、纹理、绑定组、计算和渲染管道、顶点布局、插槽、访问器和任何 TypeGPU API。着色器逻辑和 CPU 端资源紧密耦合 - 即使用户只提到一侧（例如“如何编写着色器”、“如何创建缓冲区”），也要在此处处理两侧。在任何提及 typegpu、tgpu、“使用 gpu”、TypedGPU 或使用 TypeGPU 的架构 API（d.*、tgpu.*、std.*）编写的 WebGPU 代码时触发。不要触发原始 WebGPU（直接使用 GPUDevice/GPURenderPipeline，无需 tgpu）、仅限 WGSL 的问题、Three.js、Babylon.js 或 WebGL。
