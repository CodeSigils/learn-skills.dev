TypeGPU 是 TypeScript 中類型安全的 WebGPU。每當使用者編寫、調試或設計 TypeGPU 程式碼時使用：「使用 gpu」著色器函數、tgpu.fn、緩衝區、紋理、綁定群組、計算和渲染管道、頂點佈局、插槽、存取器和任何 TypeGPU API。著色器邏輯和 CPU 端資源緊密耦合 - 即使使用者只提到一側（例如「如何編寫著色器」、「如何建立緩衝區」），也要在此處處理兩側。在任何提及 typegpu、tgpu、「使用 gpu」、TypedGPU 或使用 TypeGPU 的架構 API（d.*、tgpu.*、std.*）編寫的 WebGPU 程式碼時觸發。不要觸發原始 WebGPU（直接使用 GPUDevice/GPURenderPipeline，無需 tgpu）、僅限 WGSL 的問題、Three.js、Babylon.js 或 WebGL。
