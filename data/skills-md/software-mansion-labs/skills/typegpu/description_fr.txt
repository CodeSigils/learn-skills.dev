TypeGPU est un WebGPU de type sécurisé dans TypeScript. À utiliser chaque fois que l'utilisateur écrit, débogue ou conçoit du code TypeGPU : fonctions de shader « utiliser GPU », tgpu.fn, tampons, textures, groupes de liaison, pipelines de calcul et de rendu, dispositions de sommets, emplacements, accesseurs et toute API TypeGPU. La logique du shader et les ressources côté CPU sont étroitement couplées - gérez les deux côtés ici même si l'utilisateur n'en mentionne qu'un (par exemple "comment écrire un shader", "comment créer un tampon"). Déclenchez sur toute mention de code typegpu, tgpu, "use gpu", TypedGPU ou WebGPU écrit à l'aide de l'API de schéma de TypeGPU (d.*, tgpu.*, std.*). Ne déclenchez PAS le WebGPU brut (en utilisant GPUDevice/GPURenderPipeline directement sans tgpu), les questions WGSL uniquement, Three.js, Babylon.js ou WebGL.
