TypeGPU は、TypeScript のタイプセーフな WebGPU です。ユーザーが TypeGPU コードを作成、デバッグ、または設計するときに使用します: 「GPU を使用する」シェーダー関数、tgpu.fn、バッファー、テクスチャ、バインド グループ、パイプラインの計算とレンダリング、頂点レイアウト、スロット、アクセサー、および TypeGPU API。シェーダー ロジックと CPU 側のリソースは密接に結合されています。ユーザーが一方のみに言及した場合でも、ここでは両方の側面を処理します (例: 「シェーダーの作成方法」、「バッファの作成方法」)。 typegpu、tgpu、「use gpu」、TypedGPU、または TypeGPU のスキーマ API (d.*、tgpu.*、std.*) を使用して記述された WebGPU コードに関する言及をトリガーします。生の WebGPU (tgpu を使用せずに GPUDevice/GPRenderPipeline を直接使用)、WGSL のみの質問、Three.js、Babylon.js、または WebGL に対してトリガーしないでください。
