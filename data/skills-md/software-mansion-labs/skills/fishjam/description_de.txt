Fishjam von Software Mansion – gehostete WebRTC-Plattform für Video, Audio und One-to-Many-Livestreaming. MUSS VERWENDET werden, bevor Code geschrieben, überprüft oder debuggt wird, der von einem Backend (Node, Python) oder einem Client (React Web, React Native/Expo) mit einer Fishjam-Instanz kommuniziert. Wege zu Plattformgrundlagen und der richtigen SDK-Unterkompetenz.
