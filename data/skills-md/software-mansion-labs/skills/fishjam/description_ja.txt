Software Mansion の Fishjam — ビデオ、オーディオ、1 対多のライブストリーミング用のホスト型 WebRTC プラットフォーム。バックエンド (ノード、Python) またはクライアント (React Web、React Native / Expo) から Fishjam インスタンスと通信するコードを作成、レビュー、またはデバッグする前に使用する必要があります。プラットフォームの基礎と適切な SDK サブスキルへのルート。トリガー: 'Fishjam'、'fishjam.io'、'fishjam.swmansion.com'、'fishjam ダッシュボード'、'Fishjam ID'、'管理トークン'、'ピア トークン'、'サンドボックス API'、'ライブストリーム ルーム'、'@fishjam-cloud/js-server-sdk'、 'fishjam-server-sdk'、'@fishjam-cloud/react-client'、'@fishjam-cloud/react-native-client'、'@fishjam-cloud/ts-client'、'FishjamClient'、'FishjamProvider'、'FishjamNotifier'、'FishjamAgent'、'createPeer'、 'createRoom'、'createAgent'、'createLivestreamStreamerToken'、'createMoqToken'、'refreshPeerToken'、'Webhook'、'gemini Fishjam'、'vapi Fishjam'、'fishjam expo plugin'。
