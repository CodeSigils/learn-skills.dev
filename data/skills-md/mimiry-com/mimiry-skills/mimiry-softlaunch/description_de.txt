Early-Access-Fähigkeit für Mimirys Softlaunch-GPU-Rechenplattform. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen GPU-Auftrag ausführen, eine Rechensitzung starten, ein Modell trainieren, einen Container auf einer GPU starten, deren Kontostand überprüfen, laufende Sitzungen verwalten oder ein Rechenauftragsskript in der Mimiry-Softlaunch-Umgebung erstellen möchte. Wird auch ausgelöst, wenn der Benutzer Mimiry-Softlaunch, Mimiry-Computing, GPU-Sitzungen, SSH-Einstieg in eine Sitzung erwähnt oder fragt, „dies auf einer GPU auszuführen“ oder „einen Trainingsjob zu starten“. Deckt sowohl schnelle Einzeiler als auch interaktive Arbeitsabläufe zur Auftragserstellung ab. Dies ist die Softlaunch-Version (frühe Betaversion) – die API und die Funktionen können sich ändern.
