Mimiry의 소프트 런치 GPU 컴퓨팅 플랫폼에 대한 조기 액세스 기술입니다. 사용자가 GPU 작업 실행, 컴퓨팅 세션 시작, 모델 교육, GPU에서 컨테이너 시작, 균형 확인, 실행 중인 세션 관리 또는 Mimiry 소프트 실행 환경에서 컴퓨팅 작업 스크립트 구축을 원할 때마다 이 기술을 사용하세요. 또한 사용자가 Mimiry 소프트 실행, Mimiry 컴퓨팅, GPU 세션, SSH 연결을 세션에 언급하거나 "GPU에서 실행" 또는 "훈련 작업 실행"을 요청하는 경우에도 트리거됩니다. 빠른 단일 라이너와 대화형 작업 구축 워크플로를 모두 다룹니다. 이는 소프트런칭(초기 베타) 버전입니다. API와 기능이 변경될 수 있습니다.
