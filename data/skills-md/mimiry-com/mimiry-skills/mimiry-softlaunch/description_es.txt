Habilidad de acceso temprano para la plataforma informática GPU de lanzamiento suave de Mimiry. Utilice esta habilidad siempre que el usuario desee ejecutar un trabajo de GPU, iniciar una sesión de computación, entrenar un modelo, iniciar un contenedor en una GPU, verificar su saldo, administrar sesiones en ejecución o crear un script de trabajo de computación en el entorno de inicio suave de Mimiry. También se activa cuando el usuario menciona el inicio suave de Mimiry, la computación de Mimiry, las sesiones de GPU, el acceso SSH a una sesión o solicita "ejecutar esto en una GPU" o "iniciar un trabajo de entrenamiento". Cubre tanto frases breves rápidas como flujos de trabajo interactivos de creación de trabajos. Esta es la versión de lanzamiento suave (beta temprana): la API y las funciones pueden cambiar.
