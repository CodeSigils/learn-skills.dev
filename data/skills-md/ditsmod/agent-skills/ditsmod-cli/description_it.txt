Guida all'uso della CLI di Ditsmod (@ditsmod/cli, file binari "ditsmod", "dm") per il bootstrap del progetto (nuovo) e l'esecuzione del monitoraggio dello sviluppo (avvio). Principalmente uno strumento di sviluppo umano; Gli agenti IA devono evitare di eseguire attività di controllo/avvio di lunga durata in background per evitare perdite di risorse.
