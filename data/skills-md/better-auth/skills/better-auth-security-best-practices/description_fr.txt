Configurez la limitation de débit, gérez les secrets d'authentification, configurez la protection CSRF, définissez des origines fiables, sécurisez les sessions et les cookies, chiffrez les jetons OAuth, suivez les adresses IP et implémentez la journalisation d'audit pour une meilleure authentification. À utiliser lorsque les utilisateurs ont besoin de sécuriser leur configuration d'authentification, d'empêcher les attaques par force brute ou de renforcer un déploiement Better Auth.
