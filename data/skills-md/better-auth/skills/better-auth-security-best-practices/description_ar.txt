قم بتكوين تحديد المعدل وإدارة أسرار المصادقة وإعداد حماية CSRF وتحديد الأصول الموثوقة وتأمين الجلسات وملفات تعريف الارتباط وتشفير رموز OAuth المميزة وتتبع عناوين IP وتنفيذ تسجيل التدقيق للحصول على مصادقة أفضل. يُستخدم عندما يحتاج المستخدمون إلى تأمين إعداد المصادقة الخاص بهم، أو منع هجمات القوة الغاشمة، أو تعزيز عملية نشر Better Auth.
