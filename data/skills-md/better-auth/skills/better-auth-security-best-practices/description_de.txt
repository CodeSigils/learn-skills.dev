Konfigurieren Sie Ratenbegrenzung, verwalten Sie Authentifizierungsgeheimnisse, richten Sie CSRF-Schutz ein, definieren Sie vertrauenswürdige Ursprünge, sichern Sie Sitzungen und Cookies, verschlüsseln Sie OAuth-Tokens, verfolgen Sie IP-Adressen und implementieren Sie Audit-Logging für eine bessere Authentifizierung. Verwenden Sie diese Option, wenn Benutzer ihre Authentifizierungseinrichtung sichern, Brute-Force-Angriffe verhindern oder eine Better Auth-Bereitstellung absichern müssen.
