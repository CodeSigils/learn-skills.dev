Utilizza gli strumenti MCP di autenticazione agente per individuare provider, connettere agenti, gestire funzionalità ed eseguire operazioni tramite il protocollo MCP. Da utilizzare quando si lavora all'interno di un ambiente abilitato per MCP (Cursore, Codice Claude, ecc.) ed è necessario autenticare agenti, eseguire funzionalità o interagire con i provider di autenticazione agente.
