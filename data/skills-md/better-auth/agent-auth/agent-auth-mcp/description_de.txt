Verwenden Sie die Agent Auth MCP-Tools, um Anbieter zu erkennen, Agenten zu verbinden, Funktionen zu verwalten und Vorgänge über das MCP-Protokoll auszuführen. Wird verwendet, wenn Sie in einer MCP-fähigen Umgebung (Cursor, Claude Code usw.) arbeiten und Agenten authentifizieren, Funktionen ausführen oder mit Agent-Auth-Anbietern interagieren müssen.
