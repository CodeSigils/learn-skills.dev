Utilisez les outils Agent Auth MCP pour découvrir les fournisseurs, connecter les agents, gérer les fonctionnalités et exécuter des opérations via le protocole MCP. À utiliser lorsque vous travaillez dans un environnement compatible MCP (Curseur, Claude Code, etc.) et que vous devez authentifier des agents, exécuter des fonctionnalités ou interagir avec des fournisseurs d'authentification d'agent.
