Используйте интерфейс командной строки Agent Auth (auth-agent) для обнаружения поставщиков, подключения агентов, управления возможностями и выполнения операций. Используйте, когда пользователь хочет взаимодействовать с поставщиком аутентификации агента с терминала, аутентифицировать агента, выполнять функции или управлять подключениями агента.
