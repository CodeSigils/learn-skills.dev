Utilisez l'Agent Auth CLI (auth-agent) pour découvrir les fournisseurs, connecter les agents, gérer les fonctionnalités et exécuter des opérations. À utiliser lorsque l'utilisateur souhaite interagir avec un fournisseur d'authentification d'agent à partir du terminal, authentifier un agent, exécuter des fonctionnalités ou gérer les connexions d'agent.
