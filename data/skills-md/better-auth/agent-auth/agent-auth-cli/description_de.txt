Verwenden Sie die Agent Auth CLI (auth-agent), um Anbieter zu erkennen, Agenten zu verbinden, Funktionen zu verwalten und Vorgänge auszuführen. Verwenden Sie diese Option, wenn der Benutzer vom Terminal aus mit einem Agent-Auth-Anbieter interagieren, einen Agent authentifizieren, Funktionen ausführen oder Agent-Verbindungen verwalten möchte.
