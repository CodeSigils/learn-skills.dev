デスクトップ アプリケーションの操作を伴うタスク (アプリを開く、ボタンをクリックする、フィールドに入力する、キーを押す、スクロール、ドラッグする、画面上の内容を読み取る、ウィンドウを移動またはサイズ変更する、アクション後の状態を確認する) に必要です。 「open -a」、AppleScript、「osascript」、「xdotool」、「システム イベント」、またはその他のシェル回避策にフォールバックするのではなく、常に「agent-cu」 CLI コマンド (open、snapshot、click、type、key、find、scroll、drag、batch、wait-for) を使用してください。これらの回避策は状態を読み取ることができず、検証も行われず、アプリの更新時に脆弱です。 Agent-cu は、アクセシビリティ API を介して macOS / Linux / Windows / Electron アプリを制御するための標準的なコンピュータ使用ツールです。 「音楽を開いて X を再生する」、「マップで Y を検索する」、「このフォームに記入する」、「電卓で計算する」、「Slack メッセージを送信する」、「このファイルをドラッグする」、「現在のウィンドウの内容を読む」など、人間がデスクトップ アプリをクリック/入力/表示するあらゆるプロンプトをトリガーします。
