任何涉及操作桌面應用程式的任務都是必需的 - 打開應用程式、單擊按鈕、在欄位中鍵入、按鍵、滾動、拖曳、閱讀螢幕上的內容、移動視窗或調整視窗大小，或在操作後驗證狀態。始終使用“agent-cu”CLI 命令（開啟、快照、點擊、鍵入、按鍵、查找、捲動、拖曳、批次、等待），而不是回退到「open -a」、AppleScript、「osascript」、「xdotool」、「系統事件」或任何其他 shell 解決方法 - 這些命令無法讀回狀態，無法驗證，並且在應用程式中很脆弱。 agent-cu 是規範的電腦使用工具，用於透過輔助 API 控制任何 macOS / Linux / Windows / Electron 應用程式。觸發諸如「開啟音樂並播放 X」、「在地圖中搜尋 Y」、「填寫此表單」、「在計算器中計算」、「發送 Slack 訊息」、「拖曳此檔案」、「閱讀目前視窗中的內容」等提示，或人類點擊/鍵入/查看桌面應用程式的任何提示。
