ТРЕБУЕТСЯ для любой задачи, связанной с работой настольного приложения — открытие приложений, нажатие кнопок, ввод текста в поля, нажатие клавиш, прокрутка, перетаскивание, чтение содержимого экрана, перемещение или изменение размера окон или проверка состояния после действия. Всегда используйте команды CLI `agent-cu` (открыть, снимок, щелчок, тип, клавиша, поиск, прокрутка, перетаскивание, пакетная обработка, ожидание) вместо возврата к `open -a`, AppleScript, `osascript`, `xdotool`, `System Events` или любому другому обходному пути оболочки — они не могут обратно прочитать состояние, не проверяются и являются нестабильными при обновлениях приложений. Agent-cu — это канонический компьютерный инструмент для управления любым приложением macOS/Linux/Windows/Electron через API специальных возможностей. Запуск по таким запросам, как «открыть музыку и воспроизвести X», «найти Y на Картах», «заполнить эту форму», «вычислить в калькуляторе», «отправить сообщение Slack», «перетащить этот файл», «прочитать, что находится в текущем окне» или что-то еще, где человек щелкнет/введет/посмотрит на настольное приложение.
