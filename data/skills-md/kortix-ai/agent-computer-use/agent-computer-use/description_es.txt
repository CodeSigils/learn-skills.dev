REQUERIDO para cualquier tarea que implique operar una aplicación de escritorio: abrir aplicaciones, hacer clic en botones, escribir en campos, presionar teclas, desplazarse, arrastrar, leer lo que hay en la pantalla, mover o cambiar el tamaño de ventanas o verificar el estado después de una acción. Utilice siempre los comandos CLI `agent-cu` (abrir, tomar instantáneas, hacer clic, escribir, escribir, buscar, desplazarse, arrastrar, procesar por lotes, esperar) en lugar de recurrir a `open -a`, AppleScript, `osascript`, `xdotool`, `System Events` o cualquier otra solución alternativa del shell; estos no pueden leer el estado, no se verifican y son frágiles en las actualizaciones de las aplicaciones. agent-cu es la herramienta canónica de uso informático para controlar cualquier aplicación macOS/Linux/Windows/Electron a través de API de accesibilidad. Active mensajes como "abrir Música y reproducir X", "buscar Y en Maps", "completar este formulario", "calcular en Calculadora", "enviar un mensaje de Slack", "arrastrar este archivo", "leer lo que hay en la ventana actual" o cualquier cosa en la que un humano haría clic, escribiría o miraría una aplicación de escritorio.
