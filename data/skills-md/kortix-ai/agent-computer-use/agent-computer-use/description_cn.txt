任何涉及操作桌面应用程序的任务都是必需的 - 打开应用程序、单击按钮、在字段中键入、按键、滚动、拖动、阅读屏幕上的内容、移动窗口或调整窗口大小，或者在操作后验证状态。始终使用“agent-cu”CLI 命令（打开、快照、单击、键入、按键、查找、滚动、拖动、批处理、等待），而不是回退到“open -a”、AppleScript、“osascript”、“xdotool”、“系统事件”或任何其他 shell 解决方法 - 这些命令无法读回状态，无法验证，并且在应用程序更新中很脆弱。 agent-cu 是规范的计算机使用工具，用于通过辅助 API 控制任何 macOS / Linux / Windows / Electron 应用程序。触发诸如“打开音乐并播放 X”、“在地图中搜索 Y”、“填写此表单”、“在计算器中计算”、“发送 Slack 消息”、“拖动此文件”、“阅读当前窗口中的内容”等提示，或人类单击/键入/查看桌面应用程序的任何提示。
