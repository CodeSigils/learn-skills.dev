مطلوب لأي مهمة تتضمن تشغيل تطبيق سطح المكتب - فتح التطبيقات، أو النقر على الأزرار، أو الكتابة في الحقول، أو الضغط على المفاتيح، أو التمرير، أو السحب، أو قراءة ما هو موجود على الشاشة، أو نقل النوافذ أو تغيير حجمها، أو التحقق من الحالة بعد إجراء ما. استخدم دائمًا أوامر `agent-cu` CLI (فتح، لقطة، نقر، كتابة، مفتاح، بحث، تمرير، سحب، دفعة، انتظار) بدلاً من الرجوع إلى `open -a`، أو AppleScript، أو osascript، أو `xdotool`، أو `System Events`، أو أي حل بديل آخر - لا يمكن لهذه الأوامر قراءة الحالة مرة أخرى، ولا تتحقق منها، وتكون هشة عبر تحديثات التطبيق. Agent-cu هي أداة استخدام الكمبيوتر الأساسية للتحكم في أي تطبيق macOS / Linux / Windows / Electron عبر واجهات برمجة تطبيقات إمكانية الوصول. قم بتشغيل المطالبات مثل "فتح الموسيقى وتشغيل X" أو "البحث عن Y في الخرائط" أو "املأ هذا النموذج" أو "الحساب في الآلة الحاسبة" أو "إرسال رسالة Slack" أو "اسحب هذا الملف" أو "اقرأ ما هو موجود في النافذة الحالية" أو أي شيء يمكن أن ينقر فيه الإنسان/يكتب/ينظر إلى تطبيق سطح المكتب.
