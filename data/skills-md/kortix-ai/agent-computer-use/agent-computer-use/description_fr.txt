REQUIS pour toute tâche impliquant l'exploitation d'une application de bureau : ouvrir des applications, cliquer sur des boutons, saisir des champs, appuyer sur des touches, faire défiler, faire glisser, lire ce qui est à l'écran, déplacer ou redimensionner des fenêtres ou vérifier l'état après une action. Utilisez toujours les commandes CLI `agent-cu` (ouvrir, instantané, cliquer, saisir, saisir, rechercher, faire défiler, faire glisser, traiter par lots, attendre) au lieu de revenir à `open -a`, AppleScript, `osascript`, `xdotool`, `System Events` ou toute autre solution de contournement du shell - celles-ci ne peuvent pas relire l'état, ne vérifient pas et sont fragiles lors des mises à jour de l'application. agent-cu est l'outil informatique canonique permettant de contrôler n'importe quelle application macOS / Linux / Windows / Electron via des API d'accessibilité. Déclenchez des invites telles que "ouvrir Musique et lire X", "rechercher Y dans Maps", "remplir ce formulaire", "calculer dans la calculatrice", "envoyer un message Slack", "faire glisser ce fichier", "lire ce qu'il y a dans la fenêtre actuelle", ou tout ce sur quoi un humain cliquerait/taperait/regarderait une application de bureau.
