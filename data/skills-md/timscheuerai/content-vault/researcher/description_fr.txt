Le pipeline unique de génération d’idées pour le contenu marketing. Trois modes d’entrée convergent vers les lignes Notion Statut=Idée. Le scan de tendances (X + créateurs LinkedIn + recherche de sujets) trouve ce qui est chaud dans le monde. Le scan de performance (vos propres lignes publiées + leurs métriques d’engagement) trouve ce qui fonctionne pour vous afin que vous puissiez doubler vos efforts. Le scan client (transcriptions d’interviews utilisateurs de la base de données HUMAN NOTES) trouve les mots, les douleurs et les thèmes issus de vraies conversations avec les clients. Le mode hybride exécute les trois, déduplique et produit un backlog équilibré. Utilisez‑le lorsqu’on vous demande « trouver des idées de contenu », « ce qui fonctionne », « ce qui est chaud », « ce que disent les clients », « recherche », « scanner les tendances », « donne‑moi des idées pour la semaine », « /researcher », ou de façon proactive lorsque la file d’attente d’idées Notion est vide.
