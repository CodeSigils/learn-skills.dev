Le pipeline unique de génération d'idées pour le contenu marketing. Trois modes de saisie convergeant sur les lignes Notion Status=Idea. L'analyse des tendances (X + créateurs LinkedIn + recherche par sujet) détecte ce qui est tendance dans le monde. L'analyse des performances (vos propres lignes publiées + leurs mesures d'engagement) détecte ce qui fonctionne pour vous afin que vous puissiez doubler la mise. L'analyse des clients (transcriptions des entretiens avec les utilisateurs de HUMAN NOTES DB) permet de trouver les mots, les douleurs et les thèmes issus de conversations réelles avec des clients. Le mode hybride exécute les trois, dédupe et génère un backlog équilibré. À utiliser lorsqu'on vous demande de « trouver des idées de contenu », « ce qui fonctionne », « ce qui est chaud », « que disent les clients », « rechercher », « analyser les tendances », « me donner des idées pour la semaine », « /chercheur » ou de manière proactive lorsque la file d'attente Notion Idea est vide.
