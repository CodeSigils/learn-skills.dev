Convert Markdown files or content into editable DOCX, supporting theme colors, Chinese fonts, base body font size, hierarchical headings, GFM tables and lists, code highlighting, images, Mermaid, and LaTeX. It is used when users need to convert Markdown/MD to Word/DOCX, export technical documentation, or perform automated conversion. Required dependencies: Markdown>=3.6,<4, beautifulsoup4>=4.12,<5, Pillow>=10,<12, python-docx>=1.2,<2, Pygments>=2.17,<3; optional formula dependency: matplotlib>=3.8,<4; Mermaid can be used via the global mmdc or by invoking @mermaid-js/mermaid-cli through bunx/npx.
