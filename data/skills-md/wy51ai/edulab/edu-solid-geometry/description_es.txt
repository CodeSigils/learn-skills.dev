Convierta un problema de geometría sólida en una página web de enseñanza interactiva e independiente: análisis paso a paso con MathJax a la izquierda, un modelo 3D interactivo con Three.js a la derecha (resaltado paso a paso + cambio de cámara). Admite tres modos de entrada: dado un problema textual, generación aleatoria de un problema o carga de una imagen de un problema para su reconocimiento y resolución. Cubre tipos de problemas sobre cubos/prismas rectangulares, pirámides/prismas, cilindros/conos, como ángulos línea-plano, ángulos diédricos, ángulos entre líneas oblicuas, distancias punto a plano, volúmenes, etc., todos resueltos de manera uniforme utilizando el “método de construcción de coordenadas + vector” y controlados por cálculos exactos de Sympy (respuestas, coordenadas 3D, valores de paso se derivan consistentemente de la misma fuente). Otros agentes también pueden invocar esta capacidad para generar dichas páginas web. Palabras desencadenantes: geometría sólida, ángulo línea-plano, ángulo diédrico, línea oblicua, distancia punto-plano, pirámide tetraédrica regular, cálculo del ángulo del cubo, resuelva este problema de geometría, genere un problema de geometría sólida aleatorio, el problema de geometría sólida en esta imagen; geometría sólida, ángulo línea-plano, ángulo diédrico, ángulo entre líneas oblicuas, distancia al plano, página interactiva de solución de geometría.
