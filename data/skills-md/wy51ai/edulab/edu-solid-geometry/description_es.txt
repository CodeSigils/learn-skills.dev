Convierta un problema de geometría sólida en una página web de enseñanza interactiva independiente: análisis paso a paso con MathJax a la izquierda, un modelo 3D interactivo con Three.js a la derecha (resaltado paso a paso + cambio de cámara). Admite tres métodos de entrada: dado un problema de texto, generación aleatoria de un problema o carga de una imagen del problema para su reconocimiento y resolución. Cubre tipos de problemas sobre cubos/prismas rectangulares, pirámides/prismas, cilindros/conos, como ángulos línea-plano, ángulos diédricos, ángulos entre líneas oblicuas, distancias punto a plano, volúmenes, etc., utilizando uniformemente el “método de construcción de coordenadas+vector”, impulsado por cálculos Sympy precisos (las respuestas, las coordenadas 3D y los valores de los pasos se obtienen de manera consistente). Otros agentes también pueden invocar esta habilidad para generar dichas páginas web. Palabras desencadenantes: geometría sólida, ángulo línea-plano, ángulo diédrico, línea sesgada, distancia punto-plano, pirámide cuadrada regular, cálculo del ángulo del cubo, resuelva este problema de geometría, genere un problema de geometría sólida aleatorio, el problema de geometría sólida en esta imagen; geometría sólida, ángulo línea-plano, ángulo diédrico, ángulo entre líneas oblicuas, distancia al plano, página interactiva de solución de geometría.
