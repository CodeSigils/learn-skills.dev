Превратите задачу аналитической геометрии в самодостаточную интерактивную обучающую веб-страницу: формулировка задачи в левом столбце + динамическая консоль (ползунок с переменными параметрами, который управляет пересчетом геометрической величины в реальном времени + индикатор теоретического диапазона/фиксированного значения), средний столбец — пошаговый анализ KaTeX, правый столбец — доска динамической геометрии 2D Canvas (эллипс/гипербола/парабола/круг + движущаяся линия/движущаяся точка + векторы + аннотации + рисунки кистью). Поддерживает три метода ввода: заданная текстовая проблема, генерация случайной проблемы, загрузка изображения проблемы для распознавания и решения. Охватывает такие типы задач, как поиск стандартных уравнений, длина хорды, диапазон векторного скалярного произведения/фиксированное значение, экстремум площади треугольника, фиксированная точка, фиксированное значение (произведение наклонов), локусы, эксцентриситет и т. д., используя унифицированный подход «установить параметрическую линию x = my + c + система уравнений + Vieta + замена/разделение констант», основанный на точных вычислениях SymPy (ответы, координаты, значения шагов и теоретический диапазон интерактивного механизма — все это последовательно выводятся). Другие агенты также могут использовать эту возможность для создания таких страниц. Макет соответствует геометрии edu-solid-geometry, но использует Canvas-2D + KaTeX (а не Three.js). Триггерные слова: 解析几何, 圆锥曲线, 椭圆, 双曲线, 抛物线, 直线与圆锥曲线, 焦点弦, 弦长,数量积取值范围, 向量数量积, 定点问题, 定值问题, 斜率之积, 三角形面积最值,轨迹方程, 离心率, 解这道解析几何题, 随机出一道圆锥曲线题, 这张图里的解析几何题; аналитическая геометрия, конические сечения, эллипс, гипербола, парабола, длина хорды, диапазон скалярного произведения, фиксированная точка, фиксированное значение, локус, эксцентриситет, интерактивная страница решения аналитической геометрии.
