Convierta un problema de geometría analítica en una página web de enseñanza interactiva e independiente: enunciado del problema en la columna izquierda + consola dinámica (un control deslizante de parámetro variable que impulsa el recálculo en tiempo real de una cantidad geométrica + indicador de rango teórico/valor fijo), análisis paso a paso KaTeX en la columna central, tablero de geometría dinámica Canvas 2D en la columna derecha (elipse/hipérbola/parábola/círculo + línea móvil/punto móvil + vectores + anotaciones + garabatos de pincel). Admite tres métodos de entrada: problema textual dado, generación aleatoria de problemas y carga de una imagen del problema para su reconocimiento y resolución. Cubre tipos de problemas como encontrar ecuaciones estándar, longitud de cuerda, rango de producto escalar vectorial/valor fijo, extremo del área del triángulo, punto fijo, valor fijo (producto de pendientes), lugares geométricos, excentricidad, etc., utilizando un enfoque unificado "establecer una línea paramétrica x = my + c + sistema de ecuaciones + Vieta + sustitución/separación constante", impulsado por cálculos precisos de SymPy (las respuestas, las coordenadas, los valores de paso y el rango teórico del motor interactivo son todos consistentes). derivada). Otros agentes también pueden invocar esta capacidad para generar dichas páginas. El diseño es paralelo a edu‑solid‑geometry, pero utiliza Canvas‑2D + KaTeX (no Three.js). Palabras desencadenantes: 解析几何, 圆锥曲线, 椭圆, 双曲线, 抛物线, 直线与圆锥曲线, 焦点弦, 弦长,数量积取值范围, 向量数量积, 定点问题, 定值问题, 斜率之积, 三角形面积最值,轨迹方程, 离心率, 解这道解析几何题, 随机出一道圆锥曲线题, 这张图里的解析几何题; geometría analítica, secciones cónicas, elipse, hipérbola, parábola, longitud de cuerda, rango de producto escalar, punto fijo, valor fijo, lugar geométrico, excentricidad, página interactiva de solución de geometría analítica.
