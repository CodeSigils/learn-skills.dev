Turn an analytic geometry problem into a self‑contained interactive teaching web page: left column problem statement + dynamic console (a variable‑parameter slider that drives real‑time recomputation of a geometric quantity + theoretical range/fixed‑value indicator), middle column KaTeX step‑by‑step analysis, right column 2D Canvas dynamic geometry board (ellipse/hyperbola/parabola/circle + moving line/moving point + vectors + annotations + brush doodles). Supports three entry methods—given textual problem, random problem generation, uploading a problem image for recognition and solving. Covers problem types such as finding standard equations, chord length, vector dot‑product range/fixed value, extremum of triangle area, fixed point, fixed value (product of slopes), loci, eccentricity, etc., using a unified approach “set a parametric line x = my + c + system of equations + Vieta + substitution/constant separation”, driven by precise SymPy calculations (answers, coordinates, step values, and the interactive engine’s theoretical range are all consistently derived). Other agents can also invoke this capability to generate such pages. The layout parallels edu‑solid‑geometry, but uses Canvas‑2D + KaTeX (not Three.js).
