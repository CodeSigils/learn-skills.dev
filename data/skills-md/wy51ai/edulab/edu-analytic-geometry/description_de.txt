Verwandeln Sie ein analytisches Geometrieproblem in eine eigenständige interaktive Lehrwebseite: linke Spalte Problemstellung + dynamische Konsole (ein Schieberegler mit variablen Parametern, der die Neuberechnung einer geometrischen Größe in Echtzeit + theoretischer Bereich/Festwertindikator steuert), mittlere Spalte KaTeX-Schritt-für-Schritt-Analyse, rechte Spalte 2D Canvas-Board für dynamische Geometrie (Ellipse/Hyperbel/Parabel/Kreis + bewegliche Linie/beweglicher Punkt + Vektoren + Anmerkungen + Pinselkritzeleien). Unterstützt drei Eingabemethoden: vorgegebenes Textproblem, zufällige Problemgenerierung, Hochladen eines Problembilds zur Erkennung und Lösung. Deckt Problemtypen wie das Finden von Standardgleichungen, Sehnenlänge, Vektorskalarproduktbereich/festem Wert, Extremum der Dreiecksfläche, festem Punkt, festem Wert (Produkt von Steigungen), Ortskurven, Exzentrizität usw. ab, unter Verwendung eines einheitlichen Ansatzes „Setzen Sie eine parametrische Linie x = my + c + Gleichungssystem + Vieta + Substitution/konstante Trennung“, basierend auf präzisen SymPy-Berechnungen (Antworten, Koordinaten, Schrittwerte und der theoretische Bereich der interaktiven Engine werden alle konsistent abgeleitet). Auch andere Agenten können diese Funktion nutzen, um solche Seiten zu generieren. Das Layout ähnelt der Edu-Solid-Geometrie, verwendet jedoch Canvas-2D + KaTeX (nicht Three.js). Auslösewörter: 解析几何, 圆锥曲线, 椭圆, 双曲线, 抛物线, 直线与圆锥曲线, 焦点弦, 弦长,数量积取值范围, 向量数量积, 定点问题, 定值问题, 斜率之积, 三角形面积最值,轨迹方程, 离心率, 解这道解析几何题, 随机出一道圆锥曲线题, 这张图里的解析几何题; Analytische Geometrie, Kegelschnitte, Ellipse, Hyperbel, Parabel, Sehnenlänge, Skalarproduktbereich, Festpunkt, Festwert, Ortskurve, Exzentrizität, interaktive Lösungsseite für analytische Geometrie.
