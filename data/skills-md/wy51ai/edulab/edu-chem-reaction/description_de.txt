Erstellen Sie eine eigenständige mikroskopische interaktive 3D-Demonstrationswebseite für eine chemische Reaktion: Auf der linken/oberen Seite wird eine interaktive Molekularanimation von Three.js angezeigt (ziehen Sie die Schieberegler, um Bindungsbruch, Bindungsbildung, Atomumlagerung und schrittweise Hervorhebung zu sehen); Die rechte Seite zeigt eine KaTeX-Reaktionsgleichung + Schritt-für-Schritt-Erklärung + Atomerhaltungszählung + optionale Energiereaktionsverlaufskurve. Unterstützt drei Eingabemethoden: Geben Sie eine Textreaktion/Gleichung ein, generieren Sie eine zufällige Reaktion oder laden Sie ein Bild zur Erkennung hoch und demonstrieren Sie es dann. Behandelt Verbrennung, Synthese/Zersetzung/Verdrängung/Doppelverdrängung, Redox (Visualisierung des Elektronentransfers), organische Mechanismen (z. B. Veresterung mit Katalysatoren und Übergangszustände). Einheitlich gesteuert durch SymPy mit exakter Präzision: Gleichungen automatisch ausgleichen, Atomerhaltung und Atomkartierung überprüfen, Bindungsbruch/-bildung ableiten; Die Antworten sind geometrisch konsistent. Enthält zwei integrierte Engines, die automatisch ausgewählt werden: Morph (atomare Verformung, zeigt Atomerhaltung) und Mechanismus (Mechanismus-Keyframes, zeigt Katalysator-/Übergangszustand). Gemischte Geometrie: Verwendet standardmäßig eine selbst erstellte VSEPR-Molekülbibliothek; Wenn RDKit in der Umgebung installiert ist, kann es Konformationen aus SMILES generieren (wird nie automatisch installiert). Auch andere Agenten können diese Funktion nutzen, um solche Seiten zu generieren. Das Format ähnelt edu-solid-geometry / edu-analytic-geometry, verwendet jedoch Three.js+KaTeX, um molekulare Reaktionen darzustellen. Auslöserwörter: chemische Reaktion, mikroskopische Demonstration, molekulare Animation, Verbrennung, Methanverbrennung, Wasserstoffverbrennung, Wasserelektrolyse, Oxidations-Reduktion, Elektronentransfer, Veresterungsreaktion, Reaktionsmechanismus, Bindungsbruch und -bildung, Atomerhaltung, Massenerhaltung, Ausgleich chemischer Gleichungen, diese chemische Reaktion lösen, eine zufällige chemische Reaktion erzeugen, die chemische Reaktion in diesem Bild; Chemiereaktion, mikroskopische/molekulare Animation, Verbrennung, Elektrolyse, Redox-Elektronentransfer, Veresterungsmechanismus, Bindungsbruch und -bildung, Atomerhaltung, Gleichgewichtsgleichung, interaktive Chemie-Reaktionsseite.
