Создайте автономную микроскопическую 3D-интерактивную демонстрационную веб-страницу химической реакции: слева/вверху показана интерактивная молекулярная анимация Three.js (перетащите ползунок, чтобы увидеть разрыв связей, образование связей, перестановку атомов, пошаговое выделение), правая сторона показывает уравнение реакции KaTeX+пошаговое объяснение+подсчет сохранения атомов+дополнительную кривую хода реакции по энергии. Поддерживает три точки входа — текстовую реакцию/уравнение, генерацию случайных вопросов или распознавание загруженного изображения для демонстрации. Охватывает горение, синтез/разложение/вытеснение/двойное вытеснение, окислительно-восстановительный процесс (визуализация переноса электронов), органические механизмы (например, этерификация с помощью катализаторов и переходные состояния). Единообразно управляется SymPy для точных расчетов: автоматическая балансировка уравнений, проверка сохранения атомов и картографирование атомов, определение разрыва/образования связей с ответами, соответствующими геометрии. Встроенные два механизма с автоматическим выбором: морф (атомная деформация, показывающая сохранение атомов) и механизм (механистические ключевые кадры, показывающие катализаторы/переходные состояния). Смешанная геометрия: по умолчанию создается молекулярная библиотека VSEPR; если в среде установлен RDKit, он может генерировать подтверждения из SMILES (никогда не устанавливается автоматически). Другие агенты также могут использовать эту возможность для создания таких страниц. Формат работает параллельно с edu‑solid‑geometry/edu‑analytic‑geometry, но использует Three.js+KaTeX для демонстрации молекулярных реакций. Триггерные слова: химическая реакция, микроскопическая демонстрация, молекулярная анимация, горение, горение метана, горение водорода, электролиз воды, окисление-восстановление, перенос электронов, реакция этерификации, механизм реакции, разрыв и образование связей, сохранение атомов, сохранение массы, балансирование химического уравнения, решить эту химическую реакцию, вызвать случайную химическую реакцию, химическую реакцию на этой картинке; химическая реакция, микроскопическая/молекулярная анимация, горение, электролиз, окислительно-восстановительный перенос электронов, механизм этерификации, разрыв и образование связей, сохранение атомов, уравнение баланса, страница интерактивной химической реакции.
