Cree una página web de demostración interactiva en 3D microscópica autónoma para una reacción química: la izquierda/arriba muestra una animación molecular interactiva de Three.js (arrastre los controles deslizantes para ver la ruptura de enlaces, la formación de enlaces, el reordenamiento atómico y el resaltado paso a paso), el lado derecho muestra una ecuación de reacción KaTeX+explicación paso a paso+conteo de conservación de átomos+curva de progreso de reacción de energía opcional. Admite tres métodos de entrada: dada una reacción/ecuación textual, generación aleatoria de problemas o cargar una imagen para su reconocimiento y luego demostración. Cubre combustión, síntesis/descomposición/reemplazo simple/reemplazo doble, redox (visualización de transferencia de electrones), mecanismos orgánicos (esterificación, etc. con catalizadores·estados de transición). Impulsado uniformemente por SymPy con aritmética exacta: equilibre ecuaciones automáticamente, verifique la conservación y el mapeo de átomos, derive la ruptura/formación de enlaces; las respuestas son geométricamente consistentes. Dos motores integrados que se seleccionan automáticamente: transformación (deformación del átomo, que muestra la conservación del átomo) y mecanismo (fotogramas clave mecánicos, que muestra el catalizador/estado de transición). Geometría mixta: por defecto, una biblioteca molecular VSEPR de construcción propia; si el entorno tiene RDKit se puede utilizar para generar conformaciones desde SMILES (nunca se instala automáticamente). Otros agentes también pueden invocar esta capacidad para generar dichas páginas web. La forma y la geometría edu-sólida/edu-analítica-geometría son paralelas, pero usan Three.js+KaTeX para demostrar reacciones moleculares.
