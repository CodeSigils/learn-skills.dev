Cree una página web de demostración interactiva en 3D microscópica autónoma para una reacción química: el lado izquierdo/superior muestra una animación molecular interactiva de Three.js (arrastre un control deslizante para ver la ruptura de enlaces, la formación de enlaces, el reordenamiento atómico y el resaltado paso a paso), el lado derecho muestra una ecuación de reacción KaTeX+explicación paso a paso+conteo de conservación de átomos+curva de progreso de reacción de energía opcional. Admite tres puntos de entrada: dada una reacción/ecuación textual, generación de preguntas aleatorias o reconocimiento de imágenes cargadas para demostración. Cubre combustión, síntesis/descomposición/desplazamiento/doble desplazamiento, redox (visualización de la transferencia de electrones), mecanismos orgánicos (por ejemplo, esterificación con catalizadores y estados de transición). Impulsado uniformemente por SymPy para cálculos exactos: equilibrio automático de ecuaciones, verificación de la conservación y mapeo de átomos, derivación de ruptura/formación de enlaces, con respuestas consistentes con la geometría. Dos motores integrados con selección automática: transformación (deformación atómica, que muestra la conservación del átomo) y mecanismo (fotogramas clave mecánicos, que muestra catalizadores/estados de transición). Geometría mixta: de forma predeterminada construye una biblioteca molecular VSEPR; si el entorno tiene instalado RDKit, puede generar conformaciones a partir de SMILES (nunca se instala automáticamente). Otros agentes también pueden invocar esta capacidad para generar dichas páginas. El formato es paralelo a edu‑solid‑geometry / edu‑analytic‑geometry, pero utiliza Three.js+KaTeX para demostrar reacciones moleculares.
