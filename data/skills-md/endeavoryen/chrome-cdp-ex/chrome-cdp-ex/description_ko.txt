사용자의 실시간 Chrome 브라우저와 Electron 앱을 살펴보세요. 이 기술을 사용하면 사용자의 실제 브라우저나 Electron 앱(열린 탭, 로그인된 세션, 라이브 페이지 상태)을 보고 상호작용할 수 있습니다. 사용자의 요청이 어떤 방식으로든 브라우저 콘텐츠 또는 Electron 앱 검사와 관련될 때마다 이 기능을 사용해야 합니다.

사용자가 다음과 같은 경우 이 스킬을 트리거하세요.
- 열려 있는 참조 페이지: 'X가 열려 있습니다.', '내 탭', '열린 탭'
- 브라우저에서 무엇이든 보고, 비교하고, 분석하도록 요청합니다: '이 페이지를 비교하세요', '어느 것이 더 좋아 보이는지', '이 페이지를 확인하세요'
- 라이브 페이지의 UI/시각적 분석 언급: '대시보드', 'UI', '레이아웃', '디자인 품질'
- 스크린샷 또는 페이지 검사 요청: 스크린샷, 검사, 디버그, 페이지 확인
- 어떤 상황에서든 '페이지', '브라우저', '내 탭'을 나타냅니다.
- 콘솔 오류, 페이지 상태 또는 브라우저 액세스가 필요한 모든 사항을 언급합니다.
- Electron 앱 또는 CDP 연결 언급: 'Electron', 'electron app', 'CDP', 'CDP_PORT', 'DevTools Protocol', 'desktop app', 'remote-debugging-port'

중요: 절대로 사용자의 브라우저를 볼 수 없다고 말하거나 사용자에게 스크린샷을 붙여넣도록 요청하지 마세요. 이 스킬을 통해 상대방의 브라우저를 볼 수 있습니다. 'list'를 사용하여 열려 있는 탭을 찾은 다음 'perceive' 또는 'shot'/'scanshot'을 사용하여 페이지 콘텐츠를 확인하세요.

Playwright를 사용하지 마십시오. 사용자의 로그인 상태, 쿠키 또는 열린 탭 없이 격리된 브라우저를 시작합니다.
