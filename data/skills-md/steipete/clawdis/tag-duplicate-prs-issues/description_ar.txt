سير عمل المشرف لتحديد ما إذا كان طلب سحب OpenClaw أو المشكلة مكررة، وجمع الأدلة باستخدام ghreplica وpr-search-cli، وتجميع العمل ذي الصلة في prtags، ومزامنة التجميع المكرر مرة أخرى إلى GitHub من خلال prtags. يُستخدم عندما يحتاج Codex إلى البحث عن علاقات عامة أو مشكلات مكررة، أو إنشاء مجموعة مكررة أو إعادة استخدامها، أو فرض نظام مجموعة واحدة لكل هدف، أو حفظ الأحكام المكررة في العلامات، أو إعداد حالة المجموعة لمزامنة التعليقات.
