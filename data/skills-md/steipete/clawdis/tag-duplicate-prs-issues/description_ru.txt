Рабочий процесс сопровождающего для принятия решения о том, является ли запрос или проблема OpenClaw дубликатом, сбора доказательств с помощью ghreplica и pr-search-cli, группировки связанной работы в prtags и синхронизации дублирующейся группы обратно с GitHub через prtags. Используйте, когда Кодексу необходимо найти повторяющиеся запросы или проблемы, создать или повторно использовать дублирующую группу, обеспечить соблюдение дисциплины «одна группа на цель», сохранить повторяющиеся решения в prtags или подготовить состояние группы для синхронизации комментариев.
