سير عمل المشرف لمراجعة طلبات سحب OpenClaw والمشكلات ذات الصلة أو فرزها أو إعدادها أو إغلاقها أو إرسالها. يُستخدم عندما يحتاج Codex إلى التحقق من صحة مطالبات إصلاح الأخطاء، أو البحث عن المشكلات ذات الصلة أو العلاقات العامة، أو تطبيق تسميات الإغلاق/السبب أو التوصية بها، أو إعداد تعليقات GitHub بأمان، أو التحقق من متابعة سلسلة المراجعة، أو تنفيذ اتخاذ قرار العلاقات العامة بأسلوب المشرف قبل الدمج أو الإغلاق.
