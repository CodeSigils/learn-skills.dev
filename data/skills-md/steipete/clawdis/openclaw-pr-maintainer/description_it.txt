Flusso di lavoro del manutentore per la revisione, la valutazione, la preparazione, la chiusura o l'invio delle richieste pull di OpenClaw e dei problemi correlati. Da utilizzare quando il Codex deve convalidare affermazioni di correzione di bug, cercare problemi o PR correlati, applicare o consigliare etichette di chiusura/motivo, preparare commenti GitHub in modo sicuro, controllare il follow-up del thread di revisione o eseguire processi decisionali in stile PR in stile manutentore prima della fusione o della chiusura.
