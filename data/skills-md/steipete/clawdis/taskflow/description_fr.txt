À utiliser lorsque le travail doit s'étendre sur une ou plusieurs tâches détachées mais se comporter comme un travail avec un contexte de propriétaire unique. TaskFlow est le substrat de flux durable sous les couches de création telles que Lobster, ACPX, les plugins ou le code brut. Conservez la logique conditionnelle dans l’appelant ; utilisez TaskFlow pour l'identité du flux, la liaison entre les tâches enfants, l'état d'attente, les mutations vérifiées par révision et l'émergence face à l'utilisateur.
