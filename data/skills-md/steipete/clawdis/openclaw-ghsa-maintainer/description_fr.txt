Workflow du responsable pour les avis de sécurité OpenClaw GitHub (GHSA). À utiliser lorsque le Codex doit inspecter, corriger, valider ou publier un avis de dépôt, vérifier l'état d'un fork privé, préparer des charges utiles Markdown ou JSON d'avis en toute sécurité, gérer les contraintes de publication spécifiques à l'API GHSA ou confirmer le succès de la publication d'un avis.
