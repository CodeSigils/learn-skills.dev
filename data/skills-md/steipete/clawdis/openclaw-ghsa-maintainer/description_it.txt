Flusso di lavoro del manutentore per OpenClaw GitHub Security Advisories (GHSA). Da utilizzare quando Codex deve ispezionare, applicare patch, convalidare o pubblicare un advisory del repository, verificare lo stato del fork privato, preparare payload consultivi Markdown o JSON in modo sicuro, gestire i vincoli di pubblicazione specifici dell'API GHSA o confermare il successo della pubblicazione dell'advisory.
