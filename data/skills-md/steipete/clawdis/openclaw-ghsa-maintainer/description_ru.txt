Рабочий процесс сопровождающего для рекомендаций по безопасности OpenClaw GitHub (GHSA). Используйте, когда Кодексу необходимо проверить, исправить, проверить или опубликовать рекомендации репо, проверить состояние частной вилки, безопасно подготовить полезные данные Markdown или JSON рекомендаций, обработать ограничения публикации, специфичные для API GHSA, или подтвердить успешную публикацию рекомендаций.
