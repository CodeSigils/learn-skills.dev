سير عمل المشرف لـ OpenClaw GitHub Security Advisories (GHSA). يُستخدم عندما يحتاج Codex إلى فحص نصيحة الريبو أو تصحيحها أو التحقق من صحتها أو نشرها، أو التحقق من حالة الشوكة الخاصة، أو إعداد حمولات Markdown الاستشارية أو حمولات JSON بأمان، أو التعامل مع قيود النشر الخاصة بـ GHSA API، أو تأكيد نجاح النشر الاستشاري.
