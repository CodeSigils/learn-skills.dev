Flujo de trabajo de mantenedor para OpenClaw GitHub Security Advisories (GHSA). Úselo cuando Codex necesite inspeccionar, parchar, validar o publicar un aviso de repositorio, verificar el estado de la bifurcación privada, preparar cargas útiles de Markdown o JSON de aviso de forma segura, manejar restricciones de publicación específicas de la API de GHSA o confirmar el éxito de la publicación del aviso.
