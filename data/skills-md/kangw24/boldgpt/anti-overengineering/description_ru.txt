Два режима. (1) Предотвращает чрезмерную разработку ИИ при выполнении простых задач разработки/исследований — добавление подписей/хэш-блокировок поверх git, запись порогов допуска в 200 строк, требование письменного разрешения для общедоступных наборов данных, чрезмерная проверка ключей конфигурации, вставка try/Exception/fallback в обучающие сценарии, создание тестовых файлов для тестовых файлов, неограниченный рост реестра/библии, распространение копий файлов v1/v2/v3 вместо использования git ветки. (2) Удаляет ошибки искусственного интеллекта из существующего кода — комментарии повествования, широкий перехват исключений, интерфейсы с одним внедрением, фабрика за одну, анти-шаблон GenericButton, именование _v2/enhanced_, совместимые прокладки с нулевыми потребителями, утверждения испытаний на непреодолимый провал, модули увеличенного размера >250 LOC. Используйте этот навык при написании кода эксперимента, конфигураций, обучающих сценариев, тестов, реестров, кода обработки наборов данных, художественной литературы ИЛИ при проверке/очистке существующего кода, сгенерированного ИИ. Автоматически активируется при любой задаче, связанной с управлением версиями, подписями, хэшами, проверкой, обработкой ошибок, воспроизводимостью, наборами данных, именованием файлов ИЛИ когда пользователь говорит «удалить ненужный код», «очистить AI-код», «удалить», «очистить код, сгенерированный ИИ». Если вы сомневаетесь, активируйте его: чрезмерную инженерию труднее обнаружить самостоятельно, чем недостаточную инженерию.
