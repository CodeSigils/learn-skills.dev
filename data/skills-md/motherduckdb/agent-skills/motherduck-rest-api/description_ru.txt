Используйте при автоматизации или консультировании по рабочим процессам плоскости управления MotherDuck REST API для предоставления сервисных учетных записей, поддерживаемых операций жизненного цикла токенов доступа, настройки экземпляра Duckling, проверки активной учетной записи или сеансов внедрения Dive. Не используйте для запросов SQL или плоскости данных.
