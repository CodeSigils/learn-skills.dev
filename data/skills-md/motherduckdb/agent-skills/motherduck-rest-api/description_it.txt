Da utilizzare per l'automazione o la consulenza sui flussi di lavoro del piano di controllo dell'API REST MotherDuck per il provisioning dell'account di servizio, le operazioni del ciclo di vita del token di accesso supportate, la configurazione dell'istanza Duckling, l'ispezione dell'account attivo o le sessioni di incorporamento Dive. Non utilizzare per operazioni di query SQL o sul piano dati.
