À utiliser lors de l'automatisation ou du conseil sur les flux de travail du plan de contrôle de l'API REST MotherDuck pour le provisionnement des comptes de service, les opérations de cycle de vie des jetons d'accès prises en charge, la configuration de l'instance Duckling, l'inspection de compte actif ou les sessions d'intégration Dive. Ne pas utiliser pour le travail de requête SQL ou sur le plan de données.
