Stellen Sie von jeder Anwendung aus eine Verbindung zu MotherDuck her. Verwenden Sie diese Option beim Einrichten der Datenbankkonnektivität über den Postgres-Endpunkt (empfohlen), pg_duckdb, die native DuckDB-API oder JDBC. Behandelt Verbindungszeichenfolgen, Authentifizierung, SSL und Umgebungsvariablenkonfiguration.
