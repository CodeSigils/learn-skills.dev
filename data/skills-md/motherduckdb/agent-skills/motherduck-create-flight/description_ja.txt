MotherDuck フライト (MotherDuck コンピューティングで実行される Python ジョブ) を作成、スケジュール、実行、およびデバッグします。フライトの作成、MotherDuck での Python スクリプトまたは定期的なジョブのスケジュール、Postgres、DLT ソース、S3、BigQuery、Snowflake、または API からのスケジュールされた取り込みの設定、cron での集計または変換の更新、または get_flight_guide、create_flight、run_flight、フライト ログ、シークレット、スケジュール、バージョンを使用したフライトの操作を行う場合に使用します。
