Verwenden Sie es immer dann, wenn jemand einen Flug erstellen, ein Python-Skript oder einen wiederkehrenden Job auf MotherDuck planen, eine geplante Aufnahme von Postgres, DLT-Quellen, S3, BigQuery, Snowflake oder APIs einrichten, Aggregate oder Transformationen auf einem Cron aktualisieren oder Flüge mit get_flight_guide, create_flight, run_flight, Flugprotokollen, Geheimnissen, Zeitplänen und Versionen durchführen möchte.
