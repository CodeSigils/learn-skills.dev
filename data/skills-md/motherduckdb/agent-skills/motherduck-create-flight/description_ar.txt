إنشاء رحلات طيران MotherDuck وجدولتها وتشغيلها وتصحيح أخطاءها - وظائف Python التي يتم تشغيلها على حساب MotherDuck. استخدمه عندما يريد شخص ما إنشاء رحلة طيران، أو جدولة برنامج Python النصي أو مهمة متكررة على MotherDuck، أو إعداد العرض المجدول من Postgres، أو مصادر dlt، أو S3، أو BigQuery، أو Snowflake، أو واجهات برمجة التطبيقات (APIs)، أو تحديث التجميعات أو التحويلات على cron، أو تشغيل الرحلات الجوية باستخدام get_flight_guide، و create_flight، و run_flight، وسجلات الطيران، والأسرار، والجداول الزمنية، والإصدارات.
