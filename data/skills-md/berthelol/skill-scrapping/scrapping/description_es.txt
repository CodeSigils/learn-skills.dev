Utilice esta habilidad siempre que un usuario quiera obtener, extraer, recuperar o buscar datos públicos de plataformas de redes sociales: perfiles, publicaciones, videos, comentarios, seguidores, estadísticas de participación, transcripciones, contenido de tendencias, hashtags o información de creadores de TikTok, Instagram, YouTube, Twitter/X, LinkedIn, Facebook, Reddit, Threads, Bluesky, Pinterest, Snapchat, Twitch, Kick, Truth Social o sitios de enlace en biografía (Linktree, Komi, Pillar). También cubre búsquedas en bibliotecas de anuncios (Meta, Google, LinkedIn, Reddit) y datos de la tienda TikTok. Se activa incluso cuando los usuarios dicen "raspar", "monitorear", "buscar" o "verificar" una plataforma. NO lo active para crear aplicaciones, usar SDK/API de plataformas oficiales (como PRAW, tweepy, YouTube Data API), analizar archivos locales o crear paneles, solo cuando el usuario necesite recuperar datos directamente desde una plataforma social.
