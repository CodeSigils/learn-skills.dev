Realice un cambio en el código existente: decida a qué capa pertenece y luego si la complejidad que agrega vale lo que compra. Úselo al agregar una característica, corrección, indicador, rama, abstracción o ruta paralela al código que ya existe. NO lo use para trabajos totalmente nuevos, para ediciones mecánicas o de una línea, ni para revisar código terminado (use revisión de código).
