Überprüfen Sie den Code auf Gründe, Domänenbegriffe, Einschränkungen und Annahmen, die einem Neuling fehlen, und erstellen Sie einen Dokumentationsrückstand. Verwenden Sie diese Option, wenn Sie um eine Einarbeitungsüberprüfung gebeten werden, was einen neuen Mitarbeiter verwirren würde, was bei einer Übergabe fehlt oder welche Teile einer Codebasis zuerst dokumentiert werden müssen. Verwenden Sie es NICHT, um Fehler zu finden (verwenden Sie Code-Review) oder um Ihr eigenes Verständnis für unbekannten Code aufzubauen (verwenden Sie grok-repo).
