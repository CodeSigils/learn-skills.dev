Utilice esta habilidad cuando el usuario necesite escribir, editar, depurar o comprender una función sin servidor de Taruvi, incluida la lógica de backend que abarca múltiples recursos, activadores controlados por eventos, trabajos cron programados, tareas asíncronas de larga duración, receptores de webhooks o llamadas a API externas con secretos almacenados. Úselo también cuando el usuario tiene operaciones de backend de varios pasos encadenadas en el código de frontend que deben moverse al lado del servidor, incluso si no mencionan "funciones".
