Utilice esta habilidad cuando el usuario desee crear, agregar funciones, depurar o implementar una aplicación web que utilice Taruvi como backend, incluidas páginas CRUD, paneles, carga de archivos, funciones sin servidor, autenticación o control de acceso. Actívelo en cualquier solicitud de creación de aplicaciones cuando el proyecto contenga @taruvi/sdk, @taruvi/refine-providers, TARUVI_API_KEY, sdk_client o taruvi.cloud en sus archivos. También se activa cuando el usuario menciona Taruvi, Refine proveedores, dataProvider, StorageDataProvider, appDataProvider, userDataProvider o sdk_client. Lee siempre esta habilidad primero antes de cargar cualquier otra habilidad de Taruvi.
