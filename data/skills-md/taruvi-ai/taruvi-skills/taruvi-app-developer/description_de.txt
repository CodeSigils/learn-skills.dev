Verwenden Sie diese Fähigkeit, wenn der Benutzer eine Webanwendung erstellen, Funktionen hinzufügen, debuggen oder bereitstellen möchte, die Taruvi als Backend verwendet – einschließlich CRUD-Seiten, Dashboards, Datei-Uploads, serverlose Funktionen, Authentifizierung oder Zugriffskontrolle. Aktivieren Sie diese Option bei jeder App-Erstellungsanfrage, wenn das Projekt @taruvi/sdk, @taruvi/refine-providers, TARUVI_API_KEY, sdk_client oder taruvi.cloud in seinen Dateien enthält. Aktivieren Sie diese Option auch, wenn der Benutzer Taruvi, Anbieter verfeinern, dataProvider, storageDataProvider, appDataProvider, userDataProvider oder sdk_client erwähnt. Lesen Sie diese Fertigkeit immer zuerst, bevor Sie eine andere Taruvi-Fertigkeit laden.
