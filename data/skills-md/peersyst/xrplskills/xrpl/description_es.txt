Aplique reglas obstinadas y patrones de seguridad al código JavaScript y TypeScript que utiliza la biblioteca cliente xrpl.js para interactuar con XRP Ledger. Úselo cuando los usuarios quieran escribir una nueva integración XRPL con xrpl.js, revisar o refactorizar código xrpl.js existente, firmar o enviar una transacción, construir o acreditar un pago, trabajar con monedas emitidas, AMM, NFToken, depósito en garantía o canales de pago, consultar el estado de la cuenta o del libro mayor, o auditar una integración XRPL para problemas de seguridad como inflación de pagos parciales, falta de LastLedgerSequence, falta de DestinationTag o administración de claves inseguras.
