قم بتطبيق قواعد الرأي وأنماط الأمان على تعليمات JavaScript وTypeScript البرمجية التي تستخدم مكتبة عميل xrpl.js للتفاعل مع XRP Ledger. يُستخدم عندما يرغب المستخدمون في كتابة تكامل XRPL جديد مع xrpl.js، أو مراجعة كود xrpl.js الحالي أو إعادة تشكيله، أو التوقيع على معاملة أو إرسالها، أو إنشاء دفعة أو اعتمادها، أو العمل مع العملات الصادرة، أو AMM، أو NFToken، أو الضمان، أو قنوات الدفع، أو حساب الاستعلام أو حالة دفتر الأستاذ، أو تدقيق تكامل XRPL لمشكلات الأمان مثل تضخم الدفع الجزئي، أو فقدان LastLedgerSequence، أو DestinationTag المفقود، أو إدارة المفاتيح غير الآمنة.
