استكشاف وتقييم مكتبة أو أداة أو مستودع GitHub بشكل منهجي في بيئة مؤقتة معزولة. استخدم هذه المهارة عندما يطلب المستخدم "المحاولة" أو "التقييم" أو "الاستكشاف" أو "التوقف عن العمل" في مكتبة/repo/أداة، خاصة عندما يقدم عنوان URL لـ GitHub، أو اسم حزمة npm/pip، أو اختصار الريبو مثل "owner/repo". استخدمه عندما يريدون بدائل حقيقية، وأنماط الفشل، وقابلية التركيب بما يتجاوز البدايات السريعة قبل اتخاذ قرار بشأن التكامل. يُنتج نصوصًا/نصوصًا قابلة للتشغيل توضح الأوليات الأساسية، ونصًا تكوينيًا، وTutorial.md مع نتائج صادقة. هذا ليس للتكامل الكامل في قاعدة التعليمات البرمجية الموجودة.
