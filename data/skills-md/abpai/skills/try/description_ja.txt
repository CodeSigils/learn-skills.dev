分離されたスクラッチ環境でライブラリ、ツール、または GitHub リポジトリを体系的に探索して評価します。ユーザーがライブラリ/リポジトリ/ツールで「試してみる」、「評価する」、「探索する」、または「タイヤを蹴る」ことを要求するときは常に、特に GitHub URL、npm/pip パッケージ名、または「オーナー/リポジトリ」のようなリポジトリの短縮形を指定する場合は、このスキルを使用します。統合を決定する前に、実際のプリミティブ、障害モード、クイックスタートを超えた構成可能性が必要な場合に使用します。主要なプリミティブを示す実行可能なスクラッチ/スクリプト、構成スクリプト、および正直な結果を含む Tutorial.md を生成します。これは、既存のコードベースに完全に統合するためのものではありません。
