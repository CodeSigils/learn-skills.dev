Esplora e valuta sistematicamente una libreria, uno strumento o un repository GitHub in un ambiente scratch isolato. Utilizza questa abilità ogni volta che l'utente chiede di "provare", "valutare", "esplorare" o "dare calci alle gomme" su una libreria/repo/strumento, soprattutto quando fornisce un URL GitHub, un nome di pacchetto npm/pip o una abbreviazione di repository come "proprietario/repo". Usalo quando desiderano primitive reali, modalità di errore e componibilità oltre le partenze rapide prima di decidere sull'integrazione. Produce script/script eseguibili che dimostrano le primitive chiave, uno script di composizione e un Tutorial.md con risultati onesti. Questo NON è per la completa integrazione in una codebase esistente.
