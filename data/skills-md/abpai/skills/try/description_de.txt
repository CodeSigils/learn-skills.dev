Erkunden und bewerten Sie systematisch eine Bibliothek, ein Tool oder ein GitHub-Repository in einer isolierten Scratch-Umgebung. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Bibliothek/einen Repo/ein Tool „ausprobieren“, „bewerten“, „erkunden“ oder „auf die Probe stellen“ möchte, insbesondere wenn er eine GitHub-URL, einen npm/pip-Paketnamen oder eine Repo-Kurzform wie „Besitzer/Repo“ angibt. Verwenden Sie es, wenn Sie echte Grundelemente, Fehlermodi und Zusammensetzbarkeit wünschen, die über Schnellstarts hinausgehen, bevor Sie sich für eine Integration entscheiden. Erstellt ausführbare Scratch-/Skripts, die wichtige Grundelemente demonstrieren, ein Kompositionsskript und eine Tutorial.md mit ehrlichen Ergebnissen. Dies dient NICHT der vollständigen Integration in eine vorhandene Codebasis.
