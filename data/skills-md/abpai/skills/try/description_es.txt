Explore y evalúe sistemáticamente una biblioteca, herramienta o repositorio de GitHub en un entorno temporal aislado. Utilice esta habilidad siempre que el usuario solicite "probar", "evaluar", "explorar" o "patear los neumáticos" en una biblioteca/repositorio/herramienta, especialmente cuando proporciona una URL de GitHub, un nombre de paquete npm/pip o una abreviatura de repositorio como "propietario/repositorio". Úselo cuando quieran primitivas reales, modos de falla y capacidad de composición más allá de los inicios rápidos antes de decidirse por la integración. Produce scripts/Scratch ejecutables que demuestran las primitivas clave, un script de composición y un Tutorial.md con resultados honestos. Esto NO es para una integración completa en una base de código existente.
