Запрашивайте и отвечайте на вопросы о спецификациях API Volcengine. Используйте, когда пользователь спрашивает о параметрах API, кодах ошибок, методах запроса, значениях перечислений, обязательных полях, структурах ответов, нумерации страниц, зависимостях параметров, списках возможностей сервисов, доступности API или сравнениях API, даже если они явно не говорят «API». Типичное намерение включает проверку того, что поддерживает действие, какие поля являются обязательными, какие значения принимает параметр, почему API возвращает конкретную ошибку, как передавать вложенные параметры или параметры тела, как работает разбиение на страницы, что содержит ответ API, существует ли пакетная операция, какие службы или версии предоставляют операцию или чем различаются два API. Используйте данные API Explorer в качестве авторитетного источника и сохраняйте ограничения, примеры и предостережения, содержащиеся в спецификации. Ответьте на китайском или английском языке. Если пользователю нужен работоспособный код SDK, примеры для конкретного языка или конфигурация SDK, обратитесь к volcengine-sdk-generator. Когда им понадобятся операции CLI, передайте их volcengine-cli.
