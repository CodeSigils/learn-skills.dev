Interrogez et répondez aux questions sur les spécifications de l'API Volcengine. À utiliser lorsque l'utilisateur pose des questions sur les paramètres de l'API, les codes d'erreur, les méthodes de requête, les valeurs d'énumération, les champs obligatoires, les structures de réponse, la pagination, les dépendances des paramètres, les listes de fonctionnalités de service, la disponibilité de l'API ou les comparaisons d'API, même s'ils ne disent pas explicitement « API ». L'intention typique consiste à vérifier ce qu'une action prend en charge, quels champs sont obligatoires, quelles valeurs un paramètre accepte, pourquoi une API renvoie une erreur spécifique, comment transmettre des paramètres imbriqués ou de corps, comment fonctionne la pagination, ce que contient une réponse d'API, si une opération par lots existe, quels services ou versions exposent une opération, ou en quoi deux API diffèrent. Utilisez les données d'API Explorer comme source faisant autorité et préservez les contraintes, les exemples et les mises en garde trouvés dans la spécification. Répondez en chinois ou en anglais. Lorsque l'utilisateur a besoin d'un code SDK exécutable, d'exemples spécifiques à un langage ou d'une configuration du SDK, transmettez-le à volcengine-sdk-generator. Lorsqu'ils ont besoin d'opérations CLI, confiez-les à volcengine-cli.
