Volcengine API 사양에 대한 질문을 쿼리하고 답변하세요. 사용자가 명시적으로 "API"라고 말하지 않더라도 API 매개변수, 오류 코드, 요청 방법, 열거형 값, 필수 필드, 응답 구조, 페이지 매김, 매개변수 종속성, 서비스 기능 목록, API 가용성 또는 API 비교에 대해 질문할 때 사용합니다. 일반적인 의도에는 작업이 지원하는 것, 필요한 필드, 매개변수가 허용하는 값, API가 특정 오류를 반환하는 이유, 중첩 또는 본문 매개변수를 전달하는 방법, 페이지 매김 작동 방식, API 응답에 포함된 내용, 일괄 작업이 존재하는지 여부, 작업을 노출하는 서비스 또는 버전, 두 API의 차이점 등이 포함됩니다. API Explorer 데이터를 신뢰할 수 있는 소스로 사용하고 사양에 있는 제약 조건, 예시, 주의 사항을 보존하세요. 중국어나 영어로 대답하세요. 사용자가 실행 가능한 SDK 코드, 언어별 예제 또는 SDK 구성이 필요한 경우 volcengine-sdk-generator에 전달하세요. CLI 작업이 필요한 경우 volcengine-cli에 전달하세요.
