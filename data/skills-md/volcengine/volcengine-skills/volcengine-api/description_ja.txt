Volcengine API 仕様に関する質問と回答。ユーザーが API パラメーター、エラー コード、リクエスト メソッド、列挙値、必須フィールド、応答構造、ページネーション、パラメーターの依存関係、サービス機能リスト、API の可用性、または API の比較について尋ねる場合、たとえ「API」と明示的に言わなくても使用します。一般的な目的には、アクションがサポートする内容、必須のフィールド、パラメーターが受け入れる値、API が特定のエラーを返す理由、ネストされたパラメーターまたは本体パラメーターを渡す方法、ページネーションの仕組み、API 応答に含まれる内容、バッチ操作が存在するかどうか、操作を公開するサービスまたはバージョン、または 2 つの API がどのように異なるかを確認することが含まれます。 API Explorer データを信頼できるソースとして使用し、仕様にある制約、例、および注意事項を保持します。中国語または英語で答えてください。ユーザーが実行可能な SDK コード、言語固有のサンプル、または SDK 構成を必要とする場合は、volcengine-sdk-generator に引き渡します。 CLI 操作が必要な場合は、volcengine-cli に引き渡します。
