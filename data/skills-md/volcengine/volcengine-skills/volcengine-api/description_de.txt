Fragen zu Volcengine-API-Spezifikationen abfragen und beantworten. Verwenden Sie diese Option, wenn der Benutzer nach API-Parametern, Fehlercodes, Anforderungsmethoden, Aufzählungswerten, erforderlichen Feldern, Antwortstrukturen, Paginierung, Parameterabhängigkeiten, Dienstfähigkeitslisten, API-Verfügbarkeit oder API-Vergleichen fragt, auch wenn nicht ausdrücklich „API“ angegeben wird. Zu den typischen Absichten gehört die Prüfung, was eine Aktion unterstützt, welche Felder erforderlich sind, welche Werte ein Parameter akzeptiert, warum eine API einen bestimmten Fehler zurückgibt, wie verschachtelte Parameter oder Hauptparameter übergeben werden, wie die Paginierung funktioniert, was eine API-Antwort enthält, ob ein Stapelvorgang vorhanden ist, welche Dienste oder Versionen einen Vorgang verfügbar machen oder wie sich zwei APIs unterscheiden. Verwenden Sie API Explorer-Daten als maßgebliche Quelle und behalten Sie die in der Spezifikation enthaltenen Einschränkungen, Beispiele und Vorbehalte bei. Antworten Sie auf Chinesisch oder Englisch. Wenn der Benutzer ausführbaren SDK-Code, sprachspezifische Beispiele oder SDK-Konfiguration benötigt, übergeben Sie ihn an volcengine-sdk-generator. Wenn sie CLI-Vorgänge benötigen, übergeben Sie diese an volcengine-cli.
