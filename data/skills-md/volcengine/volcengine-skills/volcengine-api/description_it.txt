Interroga e rispondi a domande sulle specifiche API Volcengine. Da utilizzare quando l'utente richiede informazioni su parametri API, codici di errore, metodi di richiesta, valori enum, campi obbligatori, strutture di risposta, impaginazione, dipendenze dei parametri, elenchi di capacità del servizio, disponibilità API o confronti API, anche se non dicono esplicitamente "API". L'intento tipico include il controllo di cosa supporta un'azione, quali campi sono obbligatori, quali valori accetta un parametro, perché un'API restituisce un errore specifico, come passare parametri annidati o corpo, come funziona l'impaginazione, cosa contiene una risposta API, se esiste un'operazione batch, quali servizi o versioni espongono un'operazione o come differiscono due API. Utilizza i dati di API Explorer come fonte autorevole e preserva i vincoli, gli esempi e le avvertenze presenti nelle specifiche. Rispondi in cinese o inglese. Quando l'utente ha bisogno di codice SDK eseguibile, esempi specifici della lingua o configurazione SDK, passa a volcengine-sdk-generator. Quando hanno bisogno di operazioni CLI, passa a volcengine-cli.
