Generieren Sie genaue Volcengine SDK-Beispiele, indem Sie eine API mit dem gebündelten lokalen Ranking finden, ihren API Explorer-Swagger abrufen und api/common/explorer/make-code mit vom Benutzer bereitgestellten Parametern aufrufen. Verwenden Sie diese Option, wenn der Benutzer fragt, wie er Volcengine-SDK-Code schreibt, SDK-Beispiele generiert oder eine Volcengine-API in Python, Go, Java, PHP, cURL, Node.js aufruft. Unterstützt chinesische und englische API-Namen wie „角色扮演“, „AssumeRole“ oder „STS AssumeRole“. Wird auch für explizite SDK-Konfigurationsfragen zu Wiederholungsversuchen, Timeout, AK/SK, STS, AssumeRole, temporären Anmeldeinformationen, Proxy, Verbindungspooling, SSL, Debugmodus, Anforderungssignierung, Antwortanalyse und Fehlerbehandlung verwendet. Wenn der Benutzer nur API-Parameter, Aufzählungswerte, erforderliche Felder, Fehlercodes, Antwortschemata, Paginierung oder API-Vergleiche benötigt, übergeben Sie diese an volcengine-api. Wenn sie CLI-basierte Vorgänge benötigen, übergeben Sie diese an volcengine-cli.
