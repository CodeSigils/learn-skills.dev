Générez des exemples précis du SDK Volcengine en localisant une API avec le classement local fourni, en récupérant son swagger d'API Explorer et en appelant api/common/explorer/make-code avec les paramètres fournis par l'utilisateur. À utiliser lorsque l'utilisateur demande comment écrire du code du SDK Volcengine, générer des échantillons du SDK ou appeler une API Volcengine en Python, Go, Java, PHP, cURL, Node.js. Prend en charge les noms d'API chinois et anglais tels que « 角色扮演 », « AssumeRole » ou « STS ​​AssumeRole ». À utiliser également pour les questions explicites de configuration du SDK concernant les nouvelles tentatives, le délai d'attente, AK/SK, STS, AssumeRole, les informations d'identification temporaires, le proxy, le regroupement de connexions, SSL, le mode débogage, la signature des demandes, l'analyse des réponses et la gestion des erreurs. Si l'utilisateur n'a besoin que de paramètres API, de valeurs d'énumération, de champs obligatoires, de codes d'erreur, de schémas de réponse, de pagination ou de comparaisons d'API, transmettez-le à volcengine-api. S'ils ont besoin d'opérations basées sur CLI, confiez-les à volcengine-cli.
