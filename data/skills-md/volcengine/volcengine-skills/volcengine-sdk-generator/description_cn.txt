通过使用捆绑的本地排名器定位 API，获取其 API Explorer swagger，并使用用户提供的参数调用 api/common/explorer/make-code，生成准确的 Volcengine SDK 示例。当用户询问如何编写 Volcengine SDK 代码、生成 SDK 示例或使用 Python、Go、Java、PHP、cURL、Node.js 调用 Volcengine API 时使用。支持“角色扮演”、“AssumeRole”、“STS AssumeRole”等中英文API名称。还可用于有关重试、超时、AK/SK、STS、AssumeRole、临时凭证、代理、连接池、SSL、调试模式、请求签名、响应解析和错误处理的显式 SDK 配置问题。如果用户只需要 API 参数、枚举值、必填字段、错误代码、响应模式、分页或 API 比较，请交给 volcengine-api。如果他们需要基于 CLI 的操作，请交给 volcengine-cli。
