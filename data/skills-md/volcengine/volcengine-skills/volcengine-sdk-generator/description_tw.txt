透過使用捆綁的本機排名器定位 API，取得其 API Explorer swagger，並使用使用者提供的參數呼叫 api/common/explorer/make-code，產生準確的 Volcengine SDK 範例。當使用者詢問如何編寫 Volcengine SDK 程式碼、產生 SDK 範例或使用 Python、Go、Java、PHP、cURL、Node.js 呼叫 Volcengine API 時使用。支援「角色扮演」、「AssumeRole」、「STS AssumeRole」等中英文API名稱。也可用於重試、逾時、AK/SK、STS、AssumeRole、臨時憑證、代理程式、連線池、SSL、偵錯模式、請求簽章、回應解析和錯誤處理的明確 SDK 設定問題。如果使用者只需要 API 參數、枚舉值、必填欄位、錯誤代碼、回應模式、分頁或 API 比較，請交給 volcengine-api。如果他們需要基於 CLI 的操作，請交給 volcengine-cli。
