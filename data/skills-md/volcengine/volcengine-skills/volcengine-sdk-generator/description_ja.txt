バンドルされたローカル ランカーを使用して API を見つけ、その API Explorer スワッガーを取得し、ユーザーが提供する Params を使用して api/common/explorer/make-code を呼び出すことにより、正確な Volcengine SDK サンプルを生成します。ユーザーが、Python、Go、Java、PHP、cURL、Node.js で Volcengine SDK コードを記述する方法、SDK サンプルを生成する方法、または Volcengine API を呼び出す方法を尋ねる場合に使用します。 「角色扮演」、「AssumeRole」、「STS AssumeRole」などの中国語と英語の API 名をサポートします。また、再試行、タイムアウト、AK/SK、STS、AssumeRole、一時認証情報、プロキシ、接続プーリング、SSL、デバッグ モード、リクエスト署名、レスポンス解析、エラー処理に関する明示的な SDK 設定の質問にも使用します。ユーザーが API パラメーター、列挙値、必須フィールド、エラー コード、応答スキーマ、ページネーション、または API 比較のみを必要とする場合は、volcengine-api に引き渡します。 CLI ベースの操作が必要な場合は、volcengine-cli に引き渡します。
