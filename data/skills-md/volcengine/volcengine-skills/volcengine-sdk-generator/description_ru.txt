Создавайте точные примеры Volcengine SDK, найдя API с помощью встроенного локального ранкера, получив его API Explorer и вызвав api/common/explorer/make-code с предоставленными пользователем параметрами. Используйте, когда пользователь спрашивает, как написать код Volcengine SDK, сгенерировать образцы SDK или вызвать API Volcengine на Python, Go, Java, PHP, cURL, Node.js. Поддерживает имена API на китайском и английском языках, такие как «角色扮演», «AssumeRole» или «STS AssumeRole». Также используйте для явных вопросов конфигурации SDK о повторной попытке, таймауте, AK/SK, STS, AssumeRole, временных учетных данных, прокси, пуле соединений, SSL, режиме отладки, подписании запроса, анализе ответов и обработке ошибок. Если пользователю нужны только параметры API, значения перечислений, обязательные поля, коды ошибок, схемы ответов, разбиение на страницы или сравнения API, передайте его volcengine-api. Если им нужны операции на основе CLI, передайте их volcengine-cli.
