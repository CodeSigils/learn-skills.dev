قم بإنشاء أمثلة دقيقة لـ Volcengine SDK عن طريق تحديد موقع واجهة برمجة التطبيقات (API) باستخدام أداة التصنيف المحلية المجمعة، وجلب swagger API Explorer الخاص بها، واستدعاء api/common/explorer/make-code باستخدام Params المقدمة من المستخدم. يُستخدم عندما يسأل المستخدم عن كيفية كتابة كود Volcengine SDK، أو إنشاء عينات SDK، أو الاتصال بواجهة برمجة تطبيقات Volcengine في Python، وGo، وJava، وPHP، وcURL، وNode.js. يدعم أسماء واجهة برمجة التطبيقات الصينية والإنجليزية مثل "角色扮演" أو "AssumeRole" أو "STS AssumeRole". استخدم أيضًا لأسئلة تكوين SDK الصريحة حول إعادة المحاولة، والمهلة، وAK/SK، وSTS، وAssumeRole، وبيانات الاعتماد المؤقتة، والوكيل، وتجميع الاتصالات، وSSL، ووضع التصحيح، وتوقيع الطلب، وتحليل الاستجابة، ومعالجة الأخطاء. إذا كان المستخدم يحتاج فقط إلى معلمات واجهة برمجة التطبيقات، أو قيم التعداد، أو الحقول المطلوبة، أو رموز الخطأ، أو مخططات الاستجابة، أو ترقيم الصفحات، أو مقارنات واجهة برمجة التطبيقات، فقم بتسليمها إلى volcengine-api. إذا كانوا بحاجة إلى عمليات تعتمد على CLI، فقم بتسليمها إلى volcengine-cli.
