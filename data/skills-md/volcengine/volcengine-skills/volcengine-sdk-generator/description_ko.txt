"角color扮演", "AssumeRole" 또는 "STS AssumeRole"과 같은 중국어 및 영어 API 이름을 지원합니다. 또한 재시도, 시간 초과, AK/SK, STS, AssumeRole, 임시 자격 증명, 프록시, 연결 풀링, SSL, 디버그 모드, 요청 서명, 응답 구문 분석 및 오류 처리에 대한 명시적인 SDK 구성 질문에도 사용하세요. 사용자에게 API 매개변수, 열거형 값, 필수 필드, 오류 코드, 응답 스키마, 페이지 매김 또는 API 비교만 필요한 경우 volcengine-api에 전달하세요. CLI 기반 작업이 필요한 경우 volcengine-cli에 전달하세요.
