Stellen Sie ein lokales Projektverzeichnis oder Git-Repository als laufenden, erreichbaren Cloud-Dienst in Volcengine bereit. VERWENDEN SIE WANN: Bereitstellung auf Volcengine, Bereitstellung auf 火山引擎/火山, Bereitstellung dieses Repos/Projekts, Veröffentlichung des aktuellen Codes, Starten der App, Ausführen in der Cloud, Offenlegen als Dienst, Bereitstellung auf ECS/VKE/veFaaS, Ausführen auf ECS, Push auf VKE, Bereitstellung als serverlos/FaaS oder der Benutzer möchte, dass der Agent ein Volcengine-Hostingziel auswählt. Wenn der Benutzer nur fragt, welches Volcengine-Bereitstellungsziel er auswählen soll, verwenden Sie zuerst den Skill „volcengine-prepare“. Nicht zum Erstellen einer einzelnen eigenständigen Ressource – verwenden Sie dafür den Skill „volcengine-cli“.
