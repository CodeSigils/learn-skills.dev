Разверните локальный каталог проекта или репозиторий Git в Volcengine как работающую и доступную облачную службу. ИСПОЛЬЗУЙТЕ КОГДА: развертывание в Volcengine, развертывание в 火山引擎/火山, развертывание этого репозитория/проекта, публикация текущего кода, запуск приложения, запуск его в облаке, предоставление его как службы, развертывание в ECS/VKE/veFaaS, запуск в ECS, отправка в VKE, развертывание как бессерверное/FaaS, или пользователь хочет, чтобы агент выбрал целевой хостинг Volcengine. Если пользователь спрашивает только, какую цель развертывания Volcengine выбрать, сначала используйте навык `volcengine-prepare`. Не для создания отдельного автономного ресурса — используйте для этого навык `volcengine-cli`.
