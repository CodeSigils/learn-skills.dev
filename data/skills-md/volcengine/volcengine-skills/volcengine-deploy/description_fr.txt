Déployez un répertoire de projet local ou un référentiel Git sur Volcengine en tant que service cloud en cours d'exécution et accessible. UTILISER QUAND : déployer sur Volcengine, déployer sur 火山引擎/火山, déployer ce dépôt/projet, publier le code actuel, lancer l'application, l'exécuter dans le cloud, l'exposer en tant que service, déployer sur ECS/VKE/veFaaS, exécuter sur ECS, pousser vers VKE, déployer en tant que sans serveur/FaaS, ou l'utilisateur souhaite que l'agent choisisse une cible d'hébergement Volcengine. Si l'utilisateur demande uniquement quelle cible de déploiement Volcengine choisir, utilisez d'abord la compétence « volcengine-prepare ». Pas pour créer une seule ressource autonome — utilisez la compétence `volcengine-cli` pour cela.
