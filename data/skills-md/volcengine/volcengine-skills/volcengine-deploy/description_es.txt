Implemente un directorio de proyecto local o un repositorio Git en Volcengine como un servicio en la nube accesible y en ejecución. UTILIZAR CUÁNDO: implementar en Volcengine, implementar en 火山引擎/火山, implementar este repositorio/proyecto, publicar el código actual, iniciar la aplicación, ejecutarla en la nube, exponerla como un servicio, implementar en ECS/VKE/veFaaS, ejecutar en ECS, enviar a VKE, implementar como sin servidor/FaaS, o el usuario quiere que el agente elija un destino de alojamiento de Volcengine. Si el usuario solo pregunta qué objetivo de implementación de Volcengine elegir, utilice primero la habilidad "volcengine-prepare". No para crear un único recurso independiente; use la habilidad `volcengine-cli` para eso.
