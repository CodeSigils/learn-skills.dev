قم بإنشاء موارد سحابة Volcengine وإدارتها باستخدام Volcengine CLI (الأمر `ve`). يدعم جميع خدمات Volcengine بما في ذلك ECS وVPC وCLB وRDS وRedis والمزيد. قم بتشغيل هذه المهارة عندما يطلب المستخدم إنشاء موارد سحابية أو الاستعلام عنها أو تعديلها أو حذفها على Volcengine، أو يذكر الأمر "ve"، أو يقول "volcengine CLI"، أو يصف مهام البنية التحتية مثل "إنشاء مثيل ECS"، أو "إعداد VPC"، أو "قائمة مجموعات الأمان"، أو "تخصيص EIP". قم أيضًا بتشغيل المطالبات الصينية التي تذكر "火山引擎" أو "火山" (على سبيل المثال، "火山引擎上有哪些 ECS"،"、"查一下我火山的云服务器"،、 "火山引擎创建一个 VPC"、"火山的 Redis 实例列一下"). يتم تشغيله أيضًا عندما يواجه المستخدم أخطاء من أوامر "ve" ويحتاج إلى مساعدة في استكشاف الأخطاء وإصلاحها.
