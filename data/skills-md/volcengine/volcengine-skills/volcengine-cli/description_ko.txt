Volcengine CLI(`ve` 명령)를 사용하여 Volcengine 클라우드 리소스를 생성하고 관리합니다. ECS, VPC, CLB, RDS, Redis 등을 포함한 모든 Volcengine 서비스를 지원합니다. 사용자가 Volcengine에서 클라우드 리소스 생성, 쿼리, 수정 또는 삭제를 요청하거나 've' 명령을 언급하거나 "volcengine CLI"라고 말하거나 "ECS 인스턴스 생성", "VPC 설정", "보안 그룹 나열", "EIP 할당"과 같은 인프라 작업을 설명할 때마다 이 기술을 트리거합니다. 또한 "화산引擎" 또는 "화산"(예: "화산引擎上有哪些 ECS", "查一下我火山的云服务器", "화산引擎创建一个 VPC", "화산적 Redis 实例列一下")을 언급하는 중국어 프롬프트에서 트리거됩니다. 또한 사용자가 `ve` 명령에서 오류를 발견하고 문제 해결 도움이 필요한 경우에도 트리거됩니다.
