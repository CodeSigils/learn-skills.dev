Cree y administre recursos en la nube de Volcengine utilizando la CLI de Volcengine (comando `ve`). Admite todos los servicios de Volcengine, incluidos ECS, VPC, CLB, RDS, Redis y más. Active esta habilidad cada vez que el usuario solicite crear, consultar, modificar o eliminar recursos de la nube en Volcengine, mencione el comando `ve`, diga "volcengine CLI" o describa tareas de infraestructura como "crear una instancia ECS", "configurar una VPC", "enumerar grupos de seguridad", "asignar un EIP". También se activa cuando aparecen indicaciones en chino que mencionan "火山引擎" o "火山" (por ejemplo, "火山引擎上有哪些 ECS"、"查一下我火山的云服务器"、 "火山引擎创建一个 VPC"、"火山的 Redis 实例列一下"). También se activa cuando el usuario encuentra errores en los comandos `ve` y necesita ayuda para solucionar problemas.
