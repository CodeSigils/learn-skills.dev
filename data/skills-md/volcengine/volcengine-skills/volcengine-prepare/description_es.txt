Úselo cuando el usuario desea implementar un directorio local o un repositorio de GitHub en Volcengine y necesita que se analice el proyecto, se comprenda la forma de la aplicación y una recomendación clasificada en ECS, VKE y veFaaS antes de elegir una ruta de ejecución. También se activa cuando el usuario pregunta "qué modo de implementación debo usar", "¿está este repositorio listo para Volcengine" o "verifique mi repositorio antes de implementarlo". Esta habilidad prepara la decisión; La habilidad `volcengine-deploy` realiza la implementación elegida y la habilidad `volcengine-iac` se usa solo cuando el usuario elige Terraform/IaC o la tarea ya tiene un flujo de trabajo de IaC.
