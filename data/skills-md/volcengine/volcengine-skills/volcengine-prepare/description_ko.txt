사용자가 로컬 디렉터리 또는 GitHub 저장소를 Volcengine에 배포하려고 하고 실행 경로를 선택하기 전에 프로젝트 분석, 앱 형태 이해, ECS, VKE 및 veFaaS 전체에 대한 순위 권장 사항이 필요한 경우에 사용합니다. 또한 사용자가 "어떤 배포 모드를 사용해야 하는지", "이 저장소가 Volcengine에 준비되어 있는지" 또는 "배포하기 전에 내 저장소를 확인하세요"라고 묻는 경우에도 트리거됩니다. 이 기술은 결정을 준비합니다. 'volcengine-deploy' 스킬은 선택한 배포를 수행하며 'volcengine-iac' 스킬은 사용자가 Terraform/IaC를 선택하거나 작업에 이미 IaC 워크플로가 있는 경우에만 사용됩니다.
