Управляйте рабочими пространствами базы данных Volcengine AI Native BaaS для Supabase (AIDAP) в качестве поставщика базы данных развертывания. Используйте, когда пользователь запрашивает Volcengine Supabase, AIDAP PostgreSQL, настройку рабочей области базы данных AIDAP, управление филиалами, ключи API, информацию о конечной точке или соединении с базой данных, активацию службы, проверку настоящего имени предприятия, выполнение SQL, миграцию, пограничные функции, сегменты хранилища, генерацию типов TypeScript или использование AIDAP в качестве базы данных для развертывания Volcengine. Предпочитайте `veaidap` для операций на уровне управления; используйте встроенные сценарии только для API-интерфейсов плоскости данных Supabase, отсутствующих в текущем интерфейсе командной строки `ve`.
