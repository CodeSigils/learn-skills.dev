Volcengine AI Native BaaS for Supabase (AIDAP) データベース ワークスペースを展開データベース プロバイダーとして管理します。ユーザーが Volcengine Supabase、AIDAP PostgreSQL、AIDAP データベース ワークスペースのセットアップ、ブランチ管理、API キー、エンドポイントまたはデータベースの接続情報、サービスのアクティベーション、エンタープライズの実名検証、SQL 実行、移行、Edge Functions、ストレージ バケット、TypeScript 型の生成、または Volcengine 導入用のデータベースとしての AIDAP の使用を要求する場合に使用します。コントロールプレーンの操作には「ve aidap」を推奨します。現在の「ve」CLI にない Supabase データプレーン API に対してのみバンドルされたスクリプトを使用します。
