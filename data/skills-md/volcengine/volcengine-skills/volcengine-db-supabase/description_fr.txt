Gérez les espaces de travail de base de données Volcengine AI Native BaaS for Supabase (AIDAP) en tant que fournisseur de base de données de déploiement. À utiliser lorsque l'utilisateur demande Volcengine Supabase, AIDAP PostgreSQL, la configuration de l'espace de travail de la base de données AIDAP, la gestion des succursales, les clés API, les informations de connexion au point de terminaison ou à la base de données, l'activation du service, la vérification du nom réel de l'entreprise, l'exécution SQL, les migrations, les fonctions Edge, les compartiments de stockage, la génération de type TypeScript ou l'utilisation d'AIDAP comme base de données pour un déploiement Volcengine. Préférez « ve aidap » pour les opérations du plan de contrôle ; utilisez des scripts groupés uniquement pour les API du plan de données Supabase manquantes dans la CLI `ve` actuelle.
