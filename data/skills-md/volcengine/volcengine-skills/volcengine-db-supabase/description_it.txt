Gestisci gli spazi di lavoro del database Volcengine AI Native BaaS for Supabase (AIDAP) come provider di database di distribuzione. Da utilizzare quando l'utente richiede Volcengine Supabase, AIDAP PostgreSQL, configurazione dell'area di lavoro del database AIDAP, gestione delle filiali, chiavi API, informazioni sulla connessione all'endpoint o al database, attivazione del servizio, verifica del nome reale aziendale, esecuzione SQL, migrazioni, funzioni Edge, bucket di archiviazione, generazione di tipi TypeScript o utilizzo di AIDAP come database per una distribuzione Volcengine. Preferisco "ve aiap" per le operazioni sul piano di controllo; utilizza gli script in bundle solo per le API del piano dati Supabase mancanti nell'attuale CLI `ve`.
