Administre los espacios de trabajo de bases de datos Volcengine AI Native BaaS for Supabase (AIDAP) como proveedor de bases de datos de implementación. Úselo cuando el usuario solicite Volcengine Supabase, AIDAP PostgreSQL, configuración del espacio de trabajo de la base de datos AIDAP, administración de sucursales, claves API, información de conexión de punto final o base de datos, activación de servicios, verificación del nombre real empresarial, ejecución de SQL, migraciones, funciones perimetrales, depósitos de almacenamiento, generación de tipos TypeScript o uso de AIDAP como base de datos para una implementación de Volcengine. Prefiera `ve Aidap` para operaciones en el avión de control; use scripts incluidos solo para las API del plano de datos de Supabase que faltan en la CLI `ve` actual.
