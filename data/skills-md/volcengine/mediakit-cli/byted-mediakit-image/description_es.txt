Procesamiento de imágenes, que cubre capacidades como compresión de imágenes, mejora de imágenes, procesamiento de IA, etc. Incluye capacidades: imagen-ocr, borrar-imagen, eliminar-imagen-fondo, mejorar-imagen, evaluar-imagen-calidad. Se activa cuando el usuario necesita utilizar las capacidades CLI de MediaKit del dominio de imagen.
