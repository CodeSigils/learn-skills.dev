ARK usage query: `usage stats` (Token / request count, 5‑30 minute delay), `usage plan` / `usage balance --type plan` (plan quota snapshot), `usage plan-details` (by model time series, split inside/outside plan), `usage balance` (balance: free quota / media library / plan), `usage seats --with-usage` (team seat usage by seat). Trigger keywords: usage / how much used / how much quota remains / what proportion of the plan has been used / inside/outside plan / consumption per seat. **List / bind / allocate / rotate seat API keys belong to the management domain, handled by arkcli-plans; this skill only answers usage.** Verb routing: **use / consume / how much** → here; **list / bind / allocate / rotate** → arkcli-plans. Anti‑trigger: TTS/ASR/voice model usage is not supported for query, can only be redirected to models search, indicating the discovered boundary in the plaza.
