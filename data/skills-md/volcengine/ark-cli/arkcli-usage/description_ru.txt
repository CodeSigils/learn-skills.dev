Запрос использования ARK: `статистика использования` (количество токенов/запросов, задержка 5–30 минут), `план использования` / `баланс использования --type plan` (снимок квоты плана), `детали плана использования` (по временным рядам модели, с разделением внутри и вне плана), `баланс использования` (баланс: бесплатная квота/медиабиблиотека/план), `использование мест --with-usage` (использование места командой по месту). Ключевые слова-триггеры: использование / сколько использовано / сколько осталось квоты / какая часть плана использована / внутри плана или вне плана / потребление на одно рабочее место. **Список/привязка/распределение/ротация мест и ключей API подпадают под управление и обрабатываются планами arkcli‑plans; этот навык отвечает только на вопросы об использовании.** Маршрутизация глаголов: **использовать / потреблять / сколько** → здесь; **список/связывание/выделение/поворот** → arkcli‑plans. Антитриггер: использование TTS/ASR/голосовой модели не поддерживается для запросов и должно быть перенаправлено на поиск моделей с указанием обнаруженной границы на площади.
