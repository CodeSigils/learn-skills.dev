Consulta de uso de ARK: `estadísticas de uso` (recuento de tokens/solicitudes, retraso de 5 a 30 minutos), `plan de uso`/`saldo de uso -tipo de plan` (instantánea de cuota del plan), `detalles del plan de uso` (por serie de tiempo del modelo, plan dividido dentro/fuera), `saldo de uso` (saldo: cuota gratuita/biblioteca de medios/plan), `asientos de uso --con-uso` (uso de asiento de equipo por asiento). Palabras clave de activación: uso / cuánto se usó / cuánta cuota queda / qué proporción del plan se ha utilizado / dentro/fuera del plan / consumo por asiento. ** Listar / vincular / asignar / rotar claves API de asiento pertenecen al dominio de administración, manejado por arkcli-plans; esta habilidad solo responde al uso.** Enrutamiento de verbos: **usar / consumir / cuánto** → aquí; **listar/vincular/asignar/rotar** → arkcli-plans. Antidisparador: el uso de TTS/ASR/modelo de voz no se admite para consultas, solo se puede redirigir a la búsqueda de modelos, lo que indica el límite descubierto en la plaza.
