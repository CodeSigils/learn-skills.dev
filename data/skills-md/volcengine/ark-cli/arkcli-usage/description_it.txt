Query sull'utilizzo di ARK: "statistiche di utilizzo" (conteggio token/richieste, ritardo di 5-30 minuti), "piano di utilizzo" / "bilanciamento di utilizzo --tipo piano" (istantanea della quota del piano), "dettagli del piano di utilizzo" (per serie temporali del modello, suddivisione interna/esterna al piano), "saldo di utilizzo" (saldo: quota gratuita/libreria multimediale/piano), "posti di utilizzo - con utilizzo" (utilizzo dei posti del team per postazione). Parole chiave di attivazione: utilizzo / quanto utilizzato / quanta quota rimane / quale percentuale del piano è stata utilizzata / piano interno/esterno / consumo per posto. **Le chiavi API Elenca/associa/alloca/ruota le sedi appartengono al dominio di gestione, gestito da arkcli-plans; questa abilità risponde solo all'utilizzo.** Routing verbale: **usa / consuma / quanto** → qui; **elenca/associa/assegna/ruota** → arkcli-plans. Anti-trigger: l'utilizzo del modello TTS/ASR/vocale non è supportato per le query, può essere reindirizzato solo alla ricerca dei modelli, indicando il confine scoperto nella piazza.
