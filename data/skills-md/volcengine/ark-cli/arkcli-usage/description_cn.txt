ARK 使用情况查询：`使用统计数据`（令牌/请求计数，5-30 分钟延迟），`使用计划`/`使用余额 --type plan`（计划配额快照），`使用计划详细信息`（按模型时间序列，分割内部/外部计划），`使用余额`（余额：免费配额/媒体库/计划），`使用席位 --with-usage`（按席位划分的团队席位使用情况）。触发关键词：使用量/已使用多少/剩余多少配额/已使用计划的比例/内部/外部计划/每个席位的消费。 **列出/绑定/分配/旋转席位 API 密钥属于管理域，由 arkcli-plans 处理；该技能仅回答用法。**动词路由：**使用/消耗/多少**→此处； **列表/绑定/分配/旋转** → arkcli-plans。反触发：不支持TTS/ASR/语音模型使用查询，只能重定向到模型搜索，指示发现的广场边界。
