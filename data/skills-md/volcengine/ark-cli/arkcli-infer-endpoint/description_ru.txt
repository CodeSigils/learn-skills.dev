Возможности **управления** конечной точкой вывода arkcli: выполнение получения, составления списка, запуска, остановки, удаления и обновления **существующих** конечных точек (управление жизненным циклом + запуск/остановка + уничтожение). Предпочитайте использовать команду продукта `arkcli infer endpoint...` вместо прямого вызова Raw API. **Анти-триггер (важно):** когда пользователь говорит «создать / создать / создать / развернуть конечную точку» — т. е. любое намерение создать новую конечную точку — всегда проходите через arkcli-deploy (`+deploy») и не используйте `вывести создание конечной точки` этого навыка; «Создание» этого навыка предназначено только для сценариев / CI /, которые требуют необработанного поведения CRUD без ограничений (без проверок повторного использования, без рендеринга примеров) и где явно необходимо обойти ограничения +deploy рабочего процесса. Для моделей TTS/ASR/голоса не следует использовать даже сырое создание; вместо этого перенаправьте на поиск моделей, указав, что arkcli не поддерживает создание конечных точек.
