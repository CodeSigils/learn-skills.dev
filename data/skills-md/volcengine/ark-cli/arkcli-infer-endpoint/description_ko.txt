arkcli 추론 엔드포인트 **관리** 기능: 검색, 나열, 시작, 중지, 삭제 및 업데이트(수명 주기 관리 + 시작/중지 + 삭제)를 위한 **기존** 엔드포인트 처리. Raw API를 직접 호출하는 것보다 'arkcli infer end...' 제품 명령을 사용하는 것이 좋습니다. **안티트리거(중요):** 사용자가 "엔드포인트/액세스 포인트 생성/새 생성/배포"라고 말하면 새 엔드포인트를 생성하려는 모든 의도는 arkcli‑deploy(`+deploy`)를 거쳐야 하며 이 기술의 `엔드포인트 생성 추론`을 사용해서는 안 됩니다. 이 기술의 '만들기'는 보호되지 않고 예측 가능한 원시 CRUD 작업(재사용 확인 없음, 예제 렌더링 없음)이 필요하고 +배포 워크플로 가드레일을 명시적으로 우회해야 하는 스크립트/CI 시나리오에만 사용됩니다. TTS/ASR/음성 모델의 경우 원시 생성 메시지도 표시되지 않아야 합니다. 모델 검색으로 리디렉션하여 arkcli가 엔드포인트 생성을 지원하지 않음을 나타냅니다.
