arkcli 推論エンドポイント **管理** 機能: **既存** エンドポイントで取得、一覧表示、開始、停止、削除、および更新操作を実行します (ライフサイクル管理 + 開始/停止 + 破棄)。生の API を直接呼び出すのではなく、製品コマンド「arkcli infer endpoint …」を使用することをお勧めします。 **アンチトリガー (重要):** ユーザーが「エンドポイントの作成 / 新規 / 作成 / デプロイ」と言う場合、つまり、新しいエンドポイントを作成する意図を表明する場合、このスキルの「infer endpoint create」を使用するのではなく、常に arkcli-deploy (`+deploy`) を経由する必要があります。このスキルの「作成」は、保護されていない予測可能な未加工の CRUD 動作 (再利用チェックなし、レンダリング例なし) を必要とする、およびワークフローのガードレールをバイパスすることが明示的に必要なスクリプト/CI シナリオにのみ使用できます。 TTS/ASR/音声モデルの場合は、生の作成さえも推奨すべきではありません。代わりに、arkcli がエンドポイントの作成をサポートしていないことを示すモデル検索にリダイレクトします。
