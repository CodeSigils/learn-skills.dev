إمكانات إدارة نقطة نهاية استدلال arkcli: التعامل مع نقاط النهاية **الموجودة** للاسترجاع والإدراج والبدء والإيقاف والحذف والتحديث (إدارة دورة الحياة + البدء/الإيقاف + التدمير). تفضل استخدام أمر المنتج `arkcli infer endpoint...` بدلاً من استدعاء Raw API مباشرة. **مكافحة الزناد (مهم):** عندما يقول المستخدم "إنشاء / جديد / إنشاء / نشر نقطة نهاية / نقطة وصول"، فإن أي نية لإنشاء نقطة نهاية جديدة يجب أن تمر عبر arkcli‑deploy (`+deploy`)، ولا تستخدم `استدلال إنشاء نقطة النهاية` الخاصة بهذه المهارة؛ "إنشاء" هذه المهارة مخصص فقط لسيناريوهات السيناريوهات النصية/CI التي تحتاج إلى إجراءات CRUD أولية غير محمية ويمكن التنبؤ بها (لا توجد عمليات فحص لإعادة الاستخدام، ولا يوجد عرض أمثلة) وتتطلب صراحة تجاوز حواجز حماية سير العمل + النشر. بالنسبة لنماذج TTS/ASR/الصوت، لا ينبغي المطالبة حتى بالإنشاء الأولي — قم بإعادة التوجيه إلى بحث النماذج للإشارة إلى أن arkcli لا يدعم إنشاء نقطة النهاية.
