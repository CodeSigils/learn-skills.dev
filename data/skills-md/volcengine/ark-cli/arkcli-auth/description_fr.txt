Gestion de l'authentification arkcli : connexion interactive, connexion Volc SSO, affichage de l'état, déconnexion, génération de la clé API ARK (apikey) et pour les machines de développement cloud/CI, utilisez `arkcli init-volc` pour guider de manière non interactive le profil de plate-forme à partir des variables d'environnement VOLC_INIT_*. À partir de la version 0.1.16, la connexion SSO passe par Gate1+2 et lie automatiquement les aspects du profil (type/region/project/owner_trn) ; le canal de connexion AK/SK est temporairement désactivé. Utilisez-le lorsque l'utilisateur doit initialiser les informations d'identification, résoudre les problèmes d'authentification, changer de méthode d'authentification, générer ou resélectionner une clé API ARK, ou lorsqu'il n'y a pas de guidage interactif dans un environnement où les informations d'identification ont déjà été injectées. Anti-déclencheur : lorsqu'un utilisateur pose des questions sur les capacités, l'intégration ou l'invocation du modèle TTS/ASR/vocal, ne guidez pas « auth apikey » ; à la place, redirigez vers la recherche de modèles, indiquant qu'arkcli ne prend actuellement en charge que la découverte de places.
