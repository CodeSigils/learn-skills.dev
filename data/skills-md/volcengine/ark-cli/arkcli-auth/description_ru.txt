Управление аутентификацией arkcli: интерактивный вход, вход в систему единого входа Volc, просмотр статуса, выход из системы, генерация ключа API ARK (apikey), а для машин облачной разработки/CI используйте `arkcli init-volc` для неинтерактивного получения профиля платформы из переменных среды VOLC_INIT_*. Начиная с версии 0.1.16, вход в систему SSO проходит через Gate1+2 и автоматически привязывает аспект профиля (тип/регион/проект/owner_trn); канал входа AK/SK временно отключен. Используйте это, когда пользователю необходимо инициализировать учетные данные, устранить проблемы с аутентификацией, переключить методы аутентификации, сгенерировать или повторно выбрать ключ API ARK или когда учетные данные уже внедрены в среду и интерактивное руководство не требуется. Антитриггер: когда пользователь спрашивает о возможностях TTS/ASR/голосовой модели, интеграции или вызове, не запрашивайте `auth apikey`; вместо этого перенаправьте на поиск моделей, указав, что arkcli в настоящее время поддерживает только обнаружение площадей.
