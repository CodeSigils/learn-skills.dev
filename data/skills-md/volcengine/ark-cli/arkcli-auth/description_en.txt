arkcli authentication management: interactive login, Volc SSO login, view status, logout, generate ARK API Key (apikey), and for cloud development machines/CI use `arkcli init-volc` to non‑interactively guide the platform profile from VOLC_INIT_* environment variables. Starting from version 0.1.16, SSO login goes through Gate 1+2 and automatically binds the profile aspect (type/region/project/owner_trn); the AK/SK login channel is temporarily disabled. Use it when the user needs to initialize credentials, troubleshoot authentication issues, switch authentication methods, generate or reselect an ARK API Key, or operate in an environment with injected credentials without interactive guidance. Anti‑trigger: when users ask about TTS/ASR/voice model capabilities, integration, or invocation, do not direct them to `auth apikey`; instead redirect to models search, indicating that arkcli currently only supports plaza discovery.
