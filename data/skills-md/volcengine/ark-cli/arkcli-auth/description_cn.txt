arkcli 身份验证管理：交互式登录、Volc SSO 登录、查看状态、注销、生成 ARK API 密钥 (apikey)，对于云开发机器/CI，使用 `arkcli init-volc` 以非交互方式从 VOLC_INIT_* 环境变量引导平台配置文件。从0.1.16版本开始，SSO登录经过Gate1+2，自动绑定profile切面（type/region/project/owner_trn）； AK/SK登录通道暂时关闭。当用户需要初始化凭证、解决身份验证问题、切换身份验证方法、生成或重新选择 ARK API 密钥，或者在没有交互式指导的情况下在注入凭证的环境中进行操作时，请使用它。防触发：当用户询问 TTS/ASR/语音模型功能、集成或调用时，不要引导他们到“auth apikey”；而是重定向到模型搜索，表明 arkcli 目前仅支持 plaza 发现。
