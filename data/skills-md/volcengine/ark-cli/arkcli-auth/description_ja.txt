arkcli 認証管理: インタラクティブ ログイン、Volc SSO ログイン、ステータスの表示、ログアウト、ARK API キー (apikey) の生成、およびクラウド開発マシン/CI の場合は「arkcli init-volc」を使用して、VOLC_INIT_* 環境変数から非対話的にプラットフォーム プロファイルを取得します。バージョン 0.1.16 以降、SSO ログインは Gate1+2 を経由し、プロファイル ファセット (type/region/project/owner_trn) を自動的にバインドします。 AK/SK ログイン チャネルは一時的に無効になります。ユーザーが認証情報の初期化、認証問題のトラブルシューティング、認証方法の切り替え、ARK API キーの生成または再選択を行う必要がある場合、または認証情報がすでに挿入されており対話型ガイダンスが不可能な環境で操作する必要がある場合に使用します。アンチトリガー: ユーザーが TTS/ASR/音声モデルの機能、統合、または呼び出しについて尋ねたときに、「auth apikey」を要求しません。代わりにモデル検索にリダイレクトします。arkcli は現在プラザ検出のみをサポートしていることに注意してください。
