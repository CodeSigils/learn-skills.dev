إدارة مصادقة arkcli: تسجيل الدخول التفاعلي، وتسجيل الدخول إلى Volc SSO، وعرض الحالة، وتسجيل الخروج، وإنشاء مفتاح ARK API (apikey)، وبالنسبة لأجهزة تطوير السحابة/CI، استخدم `arkcli init-volc` لتوجيه ملف تعريف النظام الأساسي بشكل غير تفاعلي من متغيرات البيئة VOLC_INIT_*. بدءًا من الإصدار 0.1.16، يمر تسجيل الدخول الموحّد (SSO) عبر Gate1+2 ويربط جانب الملف الشخصي تلقائيًا (النوع/المنطقة/المشروع/owner_trn)؛ تم تعطيل قناة تسجيل الدخول AK/SK مؤقتًا. استخدمه عندما يحتاج المستخدم إلى تهيئة بيانات الاعتماد، أو استكشاف مشكلات المصادقة وإصلاحها، أو تبديل طرق المصادقة، أو إنشاء مفتاح ARK API أو إعادة تحديده، أو العمل في بيئة تحتوي على بيانات اعتماد محقونة دون توجيه تفاعلي. مكافحة الزناد: عندما يسأل المستخدمون عن إمكانات نموذج TTS/ASR/الصوت أو التكامل أو الاستدعاء، لا توجههم إلى "auth apikey"؛ بدلاً من ذلك، قم بإعادة التوجيه إلى البحث عن النماذج، مما يشير إلى أن arkcli يدعم حاليًا اكتشاف Plaza فقط.
