arkcli 인증 관리: 대화형 로그인, Volc SSO 로그인, 상태 보기, 로그아웃, ARK API 키(apikey) 생성, 클라우드 개발 시스템/CI의 경우 `arkcli init-volc`를 사용하여 VOLC_INIT_* 환경 변수에서 플랫폼 프로필을 비대화형으로 안내합니다. 버전 0.1.16부터 SSO 로그인은 Gate1+2를 거쳐 프로필 측면(type/region/project/owner_trn)을 자동으로 바인딩합니다. AK/SK 로그인 채널이 일시적으로 비활성화되었습니다. 사용자가 자격 증명을 초기화하고, 인증 문제를 해결하고, 인증 방법을 전환하고, ARK API 키를 생성 또는 다시 선택해야 하거나, 대화형 안내 없이 주입된 자격 증명이 있는 환경에서 작동해야 하는 경우 이 기능을 사용하세요. 안티 트리거: 사용자가 TTS/ASR/음성 모델 기능, 통합 또는 호출에 대해 문의할 때 'auth apikey'로 안내하지 마세요. 대신 모델 검색으로 리디렉션하여 arkcli가 현재 Plaza 검색만 지원함을 나타냅니다.
