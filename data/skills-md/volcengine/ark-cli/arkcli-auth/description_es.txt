Gestión de autenticación de arkcli: inicio de sesión interactivo, inicio de sesión Volc SSO, ver estado, cerrar sesión, generar clave API ARK (apikey) y, para máquinas/CI de desarrollo en la nube, use `arkcli init-volc` para guiar de forma no interactiva el perfil de la plataforma desde las variables de entorno VOLC_INIT_*. A partir de la versión 0.1.16, el inicio de sesión SSO pasa por la Puerta 1+2 y vincula automáticamente el aspecto del perfil (tipo/región/proyecto/propietario_trn); el canal de inicio de sesión AK/SK está temporalmente deshabilitado. Úselo cuando el usuario necesite inicializar credenciales, solucionar problemas de autenticación, cambiar métodos de autenticación, generar o volver a seleccionar una clave API ARK u operar en un entorno con credenciales inyectadas sin guía interactiva. Antidisparo: cuando los usuarios pregunten sobre las capacidades, integración o invocación de TTS/ASR/modelo de voz, no los dirija a `auth apikey`; en su lugar, redirija a la búsqueda de modelos, lo que indica que arkcli actualmente solo admite el descubrimiento de plaza.
