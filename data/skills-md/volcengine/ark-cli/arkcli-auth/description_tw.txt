arkcli 驗證管理：互動式登入、Volc SSO 登入、檢視狀態、登出、產生 ARK API 金鑰 (apikey)，對於雲端開發機器/CI，使用 `arkcli init-volc` 以非互動方式從 VOLC_INIT_* 環境變數引導平台設定檔。從0.1.16版本開始，SSO登入經過Gate1+2，自動綁定profile切面（type/region/project/owner_trn）；AK/SK登入通道暫時關閉。當使用者需要初始化憑證、解決身分驗證問題、切換身分驗證方法、產生或重新選擇 ARK API 金鑰，或在沒有互動式指導的情況下在註入憑證的環境中進行操作時，請使用它。防觸發：當使用者詢問 TTS/ASR/語音模型功能、整合或呼叫時，不要引導他們到「auth apikey」；而是重定向到模型搜索，表明 arkcli 目前僅支援 plaza 發現。
