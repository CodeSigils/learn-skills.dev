Recherchez le prix unitaire des modèles de base Volcano Engine ARK (y compris la remise sur le compte courant) et les prix d'abonnement aux packages AgentPlan / CodingPlan. Le champ **Prix** correspond au prix unitaire final après que le backend applique des remises basées sur les contrats de compte, les campagnes ou les packages, tandis que **OriginalPrice** est le prix d'origine indiqué publiquement. Utilisez-le lorsque les utilisateurs demandent combien coûte un modèle, le prix, le prix unitaire, le prix, le coût du plan d'agent, le coût du plan de codage, le prix du forfait, le prix réduit, la facturation basée sur des jetons, les comparaisons de prix entre différentes modalités ou le quota gratuit du modèle.

**Anti-déclenchement :** Les frais pour les modèles TTS/ASR/vocaux ne sont pas pris en charge pour les requêtes ; n'utilisez pas la « tarification audio ». Au lieu de cela, dirigez-vous vers une recherche de modèles pour expliquer la limite de découverte sur la place.
