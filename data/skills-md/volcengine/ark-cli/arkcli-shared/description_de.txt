Gemeinsames ARKCLI-Ausführungsprotokoll: Einstiegspunkt für die Erstkonfiguration, Authentifizierungsgate vor der Ausführung von Geschäftsbefehlen, Befehlsrouting und Auswahlreihenfolge, Ausgabe-/Sicherheits-/sekundäre Bestätigungsregeln. Detaillierte Details (Identitätsanalyse, AK-SK-Grenzen, API-Schlüsselwiederherstellung, Real-Name-Gate, Standard und Drift von Profilen, globale Flags, Fehlerumleitung) werden bei Bedarf in das Verzeichnis references/ geladen. Wenn ein Benutzer ARKCLI zum ersten Mal verwendet, auf einen Nicht-Anmelde-/Authentifizierungsfehler stößt, feststellen muss, ob Produktbefehle oder eine Roh-API ausgeführt werden sollen oder eine arkcli-*-Fertigkeit einen gemeinsamen Kontext erfordert, wird dieses Protokoll ausgelöst.
