arkcli 共有実行プロトコル: 初回構成エントリ、ビジネス コマンド実行前の認証ゲート、コマンド ルーティングと選択順序、出力/セキュリティ/二次確認ルール。詳細な詳細 (ID 解析、AK‑SK 境界、API キーの回復、実名ゲート、プロファイルのデフォルトとドリフト、グローバル フラグ、障害の迂回) は、references/ にオンデマンドでロードされます。ユーザーが初めて arkcli を使用するとき、未ログイン/認証エラーが発生したとき、製品コマンドまたは生の API に従うかどうかを決定する必要があるとき、または arkcli‑* スキルが共有コンテキストを必要とするときにトリガーされます。
