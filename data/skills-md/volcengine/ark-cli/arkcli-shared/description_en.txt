arkcli shared execution protocol: first‑time configuration entry point, authentication gate before business command execution, command routing and selection order, output/security/secondary confirmation rules. Deep details (identity parsing, AK‑SK boundary, API key recovery, real‑name gate, profile defaults and drift, global flags, fault diversion) are loaded on demand in the references/ directory. It is triggered when a user uses arkcli for the first time, encounters not logged in/authentication failure, needs to decide whether to use product commands or raw API, or when any arkcli-* skill requires a common context.
