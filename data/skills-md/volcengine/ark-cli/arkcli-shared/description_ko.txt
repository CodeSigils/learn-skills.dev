arkcli 공유 실행 프로토콜: 최초 구성 진입점, 비즈니스 명령 실행 전 인증 게이트, 명령 라우팅 및 선택 순서, 출력/보안/보조 확인 규칙. 심층적인 세부 정보(ID 구문 분석, AK-SK 경계, API 키 복구, 실명 게이트, 프로필 기본값 및 드리프트, 전역 플래그, 오류 전환)는 필요에 따라 reference/ 디렉터리에 로드됩니다. 사용자가 처음으로 arkcli를 사용하는 경우, 로그인되지 않은 경우/인증 실패가 발생하는 경우, 제품 명령이나 원시 API를 사용할지 여부를 결정해야 하는 경우, 또는 arkcli-* 기술에 공통 컨텍스트가 필요한 경우에 트리거됩니다.
