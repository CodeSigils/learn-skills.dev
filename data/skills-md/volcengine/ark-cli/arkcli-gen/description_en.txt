Volcano Ark image/video generation entry point: when users want to generate images, draw images, create images/videos, perform image-to-image, video-from-image, generate using reference images/videos/audio, or explicitly use seedream/seedance to create new content, they should use arkcli +gen. +gen generates based on the available resources and model supported_params of the current profile; images are returned synchronously, videos return a task_id/status after submission, and you need to use --wait or arkcli gen get/list to poll and download the result. Anti‑trigger: when users ask about failure reasons, failure rates, model health, persistent slowness/timeout/rate limiting, whether quotas are sufficient, or how to resolve content moderation/sensitive content/PolicyViolation interceptions, route to arkcli‑doctor’s doctor model or doctor error, not this skill. A single video marked as queued or still running usually means the asynchronous task isn’t finished; continue using gen get/list to check the result. Only when there are cross‑task statistical failures or persistent anomalies do we forward to doctor.
