arkcli custom model repository management: import custom models from TOS, query/filter custom models, view details, rename, delete, query available quantization modes, and quantize models that are ready. Use this when a user needs to manage self‑trained/fine‑tuned models (`cm-xxx`) under their account, or to prepare a target custom model for +deploy. Note: queries for Volcano **public foundation models** (e.g., doubao and other foundation models) go through arkcli-models; this skill only handles the custom model repository under the account.
