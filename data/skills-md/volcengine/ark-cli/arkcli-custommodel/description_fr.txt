Gestion du référentiel de modèles personnalisés arkcli : importez des modèles personnalisés à partir du TOS, interrogez/filtrez les modèles personnalisés, affichez les détails, renommez, supprimez, interrogez les modes de quantification disponibles et quantifiez les modèles prêts. Utilisez-le lorsque vous devez gérer des modèles auto-entraînés/affinés (`cm-xxx`) sous votre compte, ou préparer un modèle personnalisé cible pour +deploy. Remarque : les requêtes pour les **modèles fondateurs publics** de Volcano (par exemple, doubao et autres modèles de fondation) passent par les modèles arkcli ; cette compétence gère uniquement le référentiel de modèles personnalisés sous le compte.
