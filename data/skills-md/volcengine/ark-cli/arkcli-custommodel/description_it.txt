Gestione del repository di modelli personalizzati arkcli: importa modelli personalizzati da TOS, interroga/filtra modelli personalizzati, visualizza dettagli, rinomina, elimina, interroga le modalità di quantizzazione disponibili e quantizza i modelli pronti. Utilizzalo quando un utente deve gestire modelli auto-addestrati/perfezionati (`cm-xxx`) nel proprio account o per preparare un modello personalizzato di destinazione per +deploy. Nota: le query per Volcano **modelli di fondazione pubblica** (ad esempio, doubao e altri modelli di fondazione) passano attraverso i modelli arkcli; questa competenza gestisce solo il repository di modelli personalizzati nell'account.
