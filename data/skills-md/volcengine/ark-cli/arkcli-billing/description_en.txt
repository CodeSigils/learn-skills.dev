Query Volcano Engine ARK split billing details (settlement amount, Token usage charges), supporting filtering by billing month, month range, Endpoint, API Key, product code, and other dimensions. Use this when users inquire about bills, how much they spent, reconciliation, billing period, split billing by EP/API Key, split billing by product, monthly bills, or billing details. Note that billing differs from usage stats: stats provide inference volume (near real‑time), while billing provides settlement amounts (issued T+1, financial perspective).
