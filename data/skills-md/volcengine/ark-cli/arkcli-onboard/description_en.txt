arkcli Integration Wizard (workflow): an end‑to‑end guide for integrating a model into your own application/service—from “I want to use a certain model” to obtaining a callable endpoint (with optional sample code). It is triggered when the user says things like “I want to use Doubao/a certain model in my app/service,” “How do I bring the Ark model in,” “Help me integrate model XX,” or “I want to formally use a certain model”—intents that **do not contain the keywords deploy/deployment but essentially involve formal integration**. If the user explicitly says “deploy/create endpoint,” it goes directly to arkcli‑deploy; if the user only wants to try it out or ask a quick question, it goes to +chat/+gen. Negative trigger: TTS/ASR/voice model integration does not use this wizard and should be redirected to models search, indicating that arkcli currently does not support calling/deploying/sample usage/usage fees/integration.
