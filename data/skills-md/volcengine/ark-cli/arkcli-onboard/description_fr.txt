Guide d'intégration arkcli (workflow) : une procédure pas à pas de bout en bout pour intégrer un modèle dans votre propre application/service — de « Je souhaite utiliser un certain modèle » à l'obtention d'un point de terminaison appelable (avec un exemple de code facultatif). Il est déclenché lorsque l'utilisateur dit quelque chose comme « Je souhaite utiliser Doubao/un certain modèle dans mon application/service », « Comment puis-je intégrer le modèle Ark », « Aidez-moi à intégrer le modèleXX » ou « Je souhaite utiliser officiellement un certain modèle » — des intentions qui **ne contiennent pas les mots déployer/déploiement mais visent essentiellement une intégration formelle**. Si l'utilisateur dit explicitement « déployer/créer un point de terminaison », il passe directement à arkcli-deploy ; s'ils veulent seulement essayer l'effet ou poser une seule question, cela va à +chat/+gen. Anti-déclencheur : l'intégration de modèles TTS/ASR/voix ne suit pas ce guide et doit être redirigée vers la recherche de modèles, indiquant qu'arkcli ne prend actuellement pas en charge les appels/déploiement/exemples/usage/frais/intégration pour ceux-ci.
