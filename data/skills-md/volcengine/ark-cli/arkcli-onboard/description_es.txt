Asistente de integración de arkcli (flujo de trabajo): una guía de un extremo a otro para integrar un modelo en su propia aplicación/servicio, desde "Quiero usar un determinado modelo" hasta obtener un punto final invocable (con código de muestra opcional). Se activa cuando el usuario dice cosas como "Quiero usar Doubao/un determinado modelo en mi aplicación/servicio", "¿Cómo introduzco el modelo Ark?", "Ayúdame a integrar modelXX" o "Quiero usar formalmente un determinado modelo": intenciones que **no contienen las palabras clave implementar/implementar pero que esencialmente implican una integración formal**. Si el usuario dice explícitamente "implementar/crear punto final", irá directamente a arkcli-deploy; si el usuario sólo quiere probarlo o hacer una pregunta rápida, va a +chat/+gen. Activador negativo: TTS/ASR/integración de modelo de voz no utiliza este asistente y debe redirigirse a la búsqueda de modelos, lo que indica que arkcli actualmente no admite llamadas/implementación/uso de muestra/tarifas de uso/integración.
