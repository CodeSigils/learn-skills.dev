arkcli +connect: Installiert die in arkcli eingebetteten KI-Fähigkeiten in allen auf dem lokalen Computer erkannten KI-Agenten und unterstützt die Installation, das Auflisten unterstützter Agenten und die Deinstallation. Verwenden Sie dies, wenn ein Benutzer Arkcli-Funktionen mit lokalen Agenten wie Claude Code synchronisieren muss.
