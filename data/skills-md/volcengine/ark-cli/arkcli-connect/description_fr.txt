arkcli +connect : installe les compétences IA intégrées dans arkcli dans tous les agents IA détectés sur la machine locale, prenant en charge l'installation, répertoriant les agents pris en charge et la désinstallation. Utilisez-le lorsqu'un utilisateur a besoin de synchroniser les fonctionnalités d'arkcli avec des agents locaux tels que Claude Code.
