arkcli +deploy: der einheitliche bevorzugte Einstiegspunkt zum Erstellen von Inferenzendpunkten – **Wenn ein Benutzer „Erstellen / Neu / Endpunkt / Zugriffspunkt erstellen“ oder „Bereitstellen / Starten / Bereitstellen eines Modells“ sagt, gehen Sie immer zuerst hierher und verwenden Sie nicht den Befehl „create“ von arkcli-infer-endpoint, sofern die Absicht darin besteht, einen neuen Endpunkt zu erstellen**. Verwenden Sie dies, wenn der Benutzer ein Modell als Online-Inferenzendpunkt bereitstellen muss. Hinweis: Um eine vollständige Lebenszyklusverwaltung (Abrufen, Auflisten, Starten/Stoppen, Aktualisieren usw.) **vorhandener** Endpunkte durchzuführen, sollten Sie arkcli-infer-endpoint; Dieser Skill verarbeitet nur die Erstellung mit einem Klick (kein CRUD über die Erstellung hinaus). Nach erfolgreicher Erstellung werden mehrsprachige Anwendungsbeispiele automatisch in ./ark‑examples/<ep-id>/ gerendert. Anti-Trigger: TTS/ASR/Voice-Modelle können nicht bereitgestellt werden; Sie müssen zur Modellsuche weitergeleitet werden. Dies bedeutet, dass sie auf dem Markt zu finden sind, Arkcli jedoch keine Endpunkterstellung für sie unterstützt.
