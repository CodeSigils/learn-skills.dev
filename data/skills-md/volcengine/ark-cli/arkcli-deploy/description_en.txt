arkcli +deploy: the unified preferred entry point for creating inference endpoints — **When a user says “create a endpoint” or “deploy a model,” as long as the intention is to create a new endpoint, always use this and not the create of arkcli-infer-endpoint**. Use this when the user needs to deploy a model as an online inference endpoint. Note: For full lifecycle management (retrieve/list/start‑stop/update) of **existing** endpoints, use arkcli-infer-endpoint; this skill only handles one‑click creation (no CRUD beyond creation). After successful creation, multilingual usage examples are automatically rendered to ./ark-examples/<ep-id>/. Anti‑trigger: TTS/ASR/voice models cannot +deploy; they must be redirected to models search— they are searchable in the plaza but arkcli does not support endpoint creation for them.
