arkcli +deploy: унифицированная предпочтительная запись для создания конечных точек вывода — **Когда пользователь говорит «создать конечную точку/точку доступа» или «развернуть модель», если целью является создание новой конечной точки, всегда сначала проходите здесь и не используйте команду создания arkcli-infer-endpoint**. Используйте это, когда пользователю необходимо развернуть модель в качестве конечной точки онлайн-вывода. Примечание. Для полного управления жизненным циклом (извлечение/список/старт-стоп/обновление) **существующих** конечных точек используйте arkcli-infer-endpoint; этот навык обрабатывает создание только одним щелчком мыши (кроме создания CRUD не рассматривается). После успешного создания многоязычные примеры вызовов будут автоматически отображены в ./ark-examples/<ep-id>/. Антитриггер: модели TTS/ASR/голоса нельзя +развернуть; их необходимо перенаправить на поиск моделей, указав, что их можно найти на площади, но arkcli не поддерживает создание конечных точек.
