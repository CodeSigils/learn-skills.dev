arkcli +understand: a multimodal understanding workflow that performs specialized comprehension on the Responses API engine of the data layer through 12 task‑type sub‑skills (covering 4 modalities: image, video, audio, file). It includes image captioning/OCR, visual grounding (bbox grounding), GUI operation recognition, PDF/document field extraction, video summarization/video QA, audio‑video joint understanding, speech transcription (ASR), speech translation (AST), SRT subtitle timing, multi‑speaker transcription, and meeting minutes. Each sub‑skill comes with its own expert system prompt and a default model. Use it when the user needs a multimodal understanding task with a clearly defined output, such as “transcribe this audio / box the target in the image / extract fields from this PDF / summarize this video / generate subtitles / recognize meeting minutes / describe this picture.” For open‑ended image‑based dialogue, use +chat; for generating images or videos, use +gen.
