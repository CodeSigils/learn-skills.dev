arkcli+understand: un flujo de trabajo de comprensión multimodal que realiza una comprensión especializada en el motor API de Respuestas de la capa de datos a través de 12 subhabilidades de tipo tarea (que cubren 4 modalidades: imagen, video, audio, archivo). Incluye subtítulos de imágenes/OCR, conexión a tierra visual (conexión a tierra bbox), reconocimiento de operaciones de GUI, extracción de campos de documentos/PDF, resumen de video/control de calidad de video, comprensión conjunta de audio y video, transcripción de voz (ASR), traducción de voz (AST), temporización de subtítulos SRT, transcripción de varios oradores y actas de reuniones. Cada subhabilidad viene con su propio sistema experto y un modelo predeterminado. Úselo cuando el usuario necesite una tarea de comprensión multimodal con un resultado claramente definido, como "transcribir este audio / encuadrar el objetivo en la imagen / extraer campos de este PDF / resumir este video / generar subtítulos / reconocer actas de reuniones / describir esta imagen". Para un diálogo abierto basado en imágenes, utilice+chat; para generar imágenes o vídeos, utilice+gen.
