arkcli +under: 12 のタスク指向のサブスキル (4 つのモダリティ: 画像/ビデオ/オーディオ/ファイル) を通じて、データ層の応答 API エンジンで特殊な理解を実行するマルチモーダルな理解ワークフロー。画像キャプション/OCR、ビジュアル グラウンディング (Bbox グラウンディング)、GUI 操作認識、PDF/ドキュメント フィールド抽出、ビデオ要約/ビデオ Q&A、オーディオとビデオの共同理解、音声転写 (ASR)、音声翻訳 (AST)、SRT 字幕の調整、マルチスピーカーの転写、および会議議事録をカバーします。各サブスキルには、エキスパート システム プロンプトとデフォルト モデルが含まれています。ユーザーが「この録音を文字に起こす / 画像内のターゲットをボックス化する / この PDF からフィールドを抽出する / このビデオを要約する / 字幕を生成する / 会議議事録を認識する / この画像を説明する」必要がある場合に使用します。つまり、明確な出力形式によるマルチモーダルな理解タスク。自由形式の画像ベースの対話には +chat を使用し、画像/ビデオの生成には +gen を使用します。
