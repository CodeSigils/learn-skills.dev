arkcli +understand: мультимодальный рабочий процесс понимания, который выполняет специализированное понимание на механизме Responses API с помощью 12 ориентированных на задачи поднавыков (4 модальности: изображение/видео/аудио/файл). Он охватывает субтитры к изображениям/распознавание текста, визуальное обоснование (bbox grounding), распознавание операций графического пользовательского интерфейса, извлечение полей PDF/документа, обобщение видео/вопросы и ответы по видео, совместное понимание аудио и видео, транскрипцию речи (ASR), перевод речи (AST), выравнивание субтитров SRT, транскрипцию нескольких докладчиков и протоколы встреч. Каждый поднавык сопровождается подсказкой экспертной системы и моделью по умолчанию. Он используется, когда у пользователя есть мультимодальная задача понимания с четкой формой вывода, такая как «расшифровать эту запись/поместить цель в изображение/извлечь поля из этого PDF-файла/обобщить это видео/сгенерировать субтитры/распознать протокол встречи/описать это изображение». Для открытого диалога с изображениями используйте +chat, а для создания изображений/видео используйте +gen.
