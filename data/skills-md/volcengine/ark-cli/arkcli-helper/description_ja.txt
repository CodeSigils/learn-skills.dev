arkcli ヘルパー: ローカル AI エージェント (Claude Code / OpenCode / OpenClaw / Trae) を Volcano Ark Plan に構成します。その中心的な機能は、エージェント プランの組み込み MCP をエージェントに挿入することです (Doubao search mcp‑server‑askecho‑search‑infinity + dataPro‑search + OpenViking openviking‑dataplane + OpenViking コントロール プレーン openviking‑controlplane)。ユーザーが「(私の) MCP / Doubao 検索 / オンライン検索 / dataPro / OpenViking を現在の/特定のエージェントに追加する」、「MCP を Claude Code/OpenCode/OpenClaw/Trae にインストールする」、または「エージェント プランの MCP を設定する」と言った場合、`arkcli helper mcp` を使用します (MCP のみを挿入し、モデルは変更しません)。また、`helper configure` (モデル/プロバイダーの設定も行う)、`helper list` (ステータスの確認)、および `helper replace` (インジェクションの削除) もオーバーライドします。逆トリガー: arkcli スキルをエージェントにインストール → arkcli‑connect;ログイン/401/認証 → arkcli‑auth;画像/ビデオを生成 → arkcli‑gen。注: MCP インジェクションはエージェント プランでのみサポートされます (個人エージェント プランとチーム エージェント プラン チームの両方を構成できます)。ただし、2 つの OpenViking コンポーネント (データ プレーン/コントロール プレーン) は個人エージェント プランでのみ使用できます。チーム エージェント プラン チームは OpenViking とは関係がなく、Doubao 検索 + dataPro でのみ構成できます。これは、claude‑code、opencode、openclaw、または trae にのみ適用できます (Trae は IDE であり、MCP のみを挿入し、モデルを設定せず、プロジェクト レベル ./.trae/mcp.json を記述するための `--scope project` をサポートします)。 「arkcli helper supabase」もあります。これは**MCP**ではありませんが、byted-supabase-cli + スキルをインストールし、Volcano ログイン状態を注入して byted-supabase データベース機能を有効にします (エージェント プランの場合のみ: 個人の大規模/最大 + フル層チーム。個人の小/中はサポートされていません)。ユーザーが「byted-supabase を構成する / データベースを接続する / supabase cli をインストールする / supabase をリンクする」と言った場合、これを使用します。
