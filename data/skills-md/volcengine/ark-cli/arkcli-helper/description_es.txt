Ayudante de arkcli: configure el Agente de IA local (Claude Code / OpenCode / OpenClaw / Trae) en el Plan Volcano Ark. Su capacidad principal es inyectar el MCP integrado del Plan del Agente en el Agente (Doubao search mcp-server-askecho-search-infinity + dataPro-search + OpenViking openviking-dataplane + OpenViking control plane openviking-controlplane). Cuando el usuario dice "agregar (mi) MCP / búsqueda Doubao / búsqueda en línea / dataPro / OpenViking al Agente actual/específico", "instalar MCP en Claude Code/OpenCode/OpenClaw/Trae" o "configurar el MCP del Plan del Agente", use `arkcli helper mcp` (inyecta solo el MCP, no cambia el modelo). También anula la "configuración del asistente" (también establece el modelo/proveedor), la "lista de asistentes" (verificar el estado) y el "restablecimiento del asistente" (eliminar la inyección). Activadores inversos: instalación de habilidades de arkcli en el agente → arkcli‑connect; iniciar sesión/401/autenticación → arkcli‑auth; generar imagen/vídeo → arkcli‑gen. Nota: La inyección de MCP solo es compatible con el plan de agente (se pueden configurar tanto el plan de agente personal como el plan de agente de equipo-plan-equipo), pero los dos componentes de OpenViking (plano de datos/plano de control) están disponibles solo para el plan de agente personal; el equipo-plan de agente-plan-equipo no tiene nada que ver con OpenViking y solo se puede configurar con Doubao search + dataPro; solo se puede aplicar a claude‑code, opencode, openclaw o trae (Trae es un IDE, inyecta solo MCP, no establece un modelo y admite `--scope project` para escribir un ./.trae/mcp.json a nivel de proyecto). También existe `arkcli helper supabase`: **no es un MCP**, pero instala la habilidad byted‑supabase‑cli + e inyecta el estado de inicio de sesión de Volcano para habilitar las capacidades de la base de datos byted‑supabase (solo para el plan de agente: personal grande/máximo + equipo de nivel completo; personal pequeño/mediano no es compatible). Cuando el usuario diga "configurar byted-supabase / conectar la base de datos / instalar supabase cli / vincular supabase", use esto.
