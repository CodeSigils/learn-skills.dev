arkcli 도우미: 로컬 AI 에이전트(Claude Code / OpenCode / OpenClaw / Trae)를 Volcano Ark Plan으로 구성합니다. 핵심 기능은 에이전트 계획의 내장 MCP를 에이전트에 삽입하는 것입니다(Doubao 검색 mcp-server-askecho-search-infinity + dataPro-search + OpenViking openviking-dataplane + OpenViking 제어 평면 openviking-controlplane). 사용자가 "현재/특정 에이전트에 (내) MCP/Doubao 검색/온라인 검색/dataPro/OpenViking 추가", "Claude Code/OpenCode/OpenClaw/Trae에 MCP 설치" 또는 "에이전트 계획의 MCP 설정"이라고 말하면 `arkcli helper mcp`를 사용합니다(MCP만 주입하고 모델을 변경하지 않음). 또한 '도우미 구성'(모델/공급자 설정), '도우미 목록'(상태 확인) 및 '도우미 재설정'(삽입 제거)을 재정의합니다. 역방향 트리거: arkcli 기술을 에이전트에 설치 → arkcli‑connect; 로그인/401/인증 → arkcli‑auth; 이미지/비디오 생성 → arkcli‑gen. 참고: MCP 주입은 에이전트 계획(개인 에이전트 계획 및 팀 에이전트 계획 팀 모두 구성 가능)에서만 지원되지만 두 개의 OpenViking 구성 요소(데이터 플레인/제어 플레인)는 개인 에이전트 계획에만 사용할 수 있습니다. 팀 에이전트 계획 팀은 OpenViking과 관련이 없으며 Doubao 검색 + dataPro로만 구성할 수 있습니다. claude‑code, opencode, openclaw 또는 trae에만 적용할 수 있습니다(Trae는 IDE이고 MCP만 주입하며 모델을 설정하지 않으며 프로젝트 수준 ./.trae/mcp.json을 작성하기 위한 `--scope project`를 지원합니다). `arkcli helper supabase`도 있습니다. **MCP는 아니지만** byted-supabase-cli + 스킬을 설치하고 Volcano 로그인 상태를 주입하여 byte-supabase 데이터베이스 기능을 활성화합니다(에이전트 계획에만 해당: 개인용 대형/최대 + 전체 계층 팀, 개인용 소형/중형은 지원되지 않음). 사용자가 "byted‑supabase 구성/데이터베이스 연결/supabase cli 설치/supabase 링크"라고 말하면 이를 사용합니다.
