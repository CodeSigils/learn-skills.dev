مساعد arkcli: قم بتكوين وكيل الذكاء الاصطناعي المحلي (Claude Code / OpenCode / OpenClaw / Trae) في خطة Volcano Ark Plan. وتتمثل قدرتها الأساسية في حقن MCP المدمج لخطة الوكيل في الوكيل (Doubao search mcp-server-askecho-search-infinity + dataPro-search + OpenViking openviking-dataplane + مستوى التحكم OpenViking openviking-controlplane). عندما يقول المستخدم "أضف (my) MCP / Doubao search / online search / dataPro / OpenViking إلى الوكيل الحالي/المحدد"، "قم بتثبيت MCP في Claude Code/OpenCode/OpenClaw/Trae"، أو "قم بتعيين MCP لخطة الوكيل"، استخدم "arkcli helper mcp" (يقوم بإدخال MCP فقط، ولا يغير النموذج). كما أنه يتجاوز أيضًا "تكوين المساعد" (يقوم أيضًا بتعيين النموذج/الموفر)، و"قائمة المساعد" (التحقق من الحالة)، و"إعادة تعيين المساعد" (إزالة الحقن). المشغلات العكسية: تثبيت مهارات arkcli في الوكيل → arkcli‑connect؛ تسجيل الدخول/401/المصادقة → arkcli‑auth; إنشاء صورة/فيديو → arkcli‑gen. ملاحظة: يتم دعم حقن MCP فقط من خلال خطة الوكيل (يمكن تكوين كل من خطة الوكيل الشخصية وفريق خطة وكيل الفريق)، ولكن مكوني OpenViking (مستوى البيانات/مستوى التحكم) متاحان فقط لخطة الوكيل الشخصية — لا علاقة لفريق خطة وكيل الفريق بـ OpenViking ولا يمكن تهيئتهما إلا باستخدام Doubao search + dataPro؛ لا يمكن تطبيقه إلا على claude‑code أو opencode أو openclaw أو trae (Trae هو IDE، ويحقن MCP فقط، ولا يقوم بتعيين نموذج، ويدعم `--scope project` لكتابة مستوى المشروع ./.trae/mcp.json). يوجد أيضًا `arkcli helper supabase`: **ليس MCP**، ولكنه يقوم بتثبيت مهارة byted‑supabase‑cli + ويحقن حالة تسجيل الدخول Volcano لتمكين إمكانات قاعدة بيانات byted‑supabase (فقط لخطة الوكيل: فريق شخصي كبير/حد أقصى + فريق كامل المستوى؛ شخصي صغير/متوسط ​​غير مدعوم). عندما يقول المستخدم "تكوين byted-supabase / توصيل قاعدة البيانات / تثبيت supabase cli / link supabase"، استخدم هذا.
