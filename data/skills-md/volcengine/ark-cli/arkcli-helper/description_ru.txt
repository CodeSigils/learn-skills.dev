Помощник arkcli: настройте локальный AI-агент (Claude Code / OpenCode / OpenClaw / Trae) в плане Volcano Ark. Его основная возможность заключается во внедрении встроенного MCP плана агента в агент (поиск Doubao mcp-server-askecho-search-infinity + dataPro-search + OpenViking openviking-dataplane + плоскость управления OpenViking openviking-controlplane). Когда пользователь говорит «добавить (мой) MCP/поиск Doubao/онлайн-поиск/dataPro/OpenViking к текущему/конкретному агенту», «установить MCP в Claude Code/OpenCode/OpenClaw/Trae» или «установить MCP плана агента», используйте «arkcli helper mcp» (внедряет только MCP, не изменяет модель). Он также переопределяет `helper configure` (также устанавливает модель/поставщика), `helper list` (проверка статуса) и `helper reset` (удаление внедрения). Обратные триггеры: установка навыков arkcli в агент → arkcli‑connect; вход/401/аутентификация → arkcli‑auth; создать изображение/видео → arkcli‑gen. Примечание. Внедрение MCP поддерживается только планом агента (можно настроить как личный план агента, так и командный план агента-команды), но два компонента OpenViking (плоскость данных/плоскость управления) доступны только для личного плана агента — командный план агента-команды не имеет ничего общего с OpenViking и может быть настроен только с помощью Doubao search + dataPro; его можно применять только к claude-code, opencode, openclaw или trae (Trae — это IDE, внедряет только MCP, не устанавливает модель и поддерживает `--scope project` для записи ./.trae/mcp.json уровня проекта). Существует также `arkcli helper supabase`: она **не MCP**, но устанавливает навык byted-supabase-cli + и вводит состояние входа в Volcano, чтобы включить возможности базы данных byted-supabase (только для плана агента: личный большой/максимальный + полный уровень команды; личный малый/средний не поддерживаются). Когда пользователь говорит: «Настройте byted-supabase/подключите базу данных/установите supabase cli/link supabase», используйте это.
