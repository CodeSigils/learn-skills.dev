arkcli helper：将本地AI Agent（Claude Code / OpenCode / OpenClaw / Trae）配置到火山方舟计划中。其核心能力是将Agent Plan的内置MCP注入到Agent中（豆宝搜索 mcp-server-askecho-search-infinity + dataPro-search + OpenViking openviking-dataplane + OpenViking 控制平面 openviking-controlplane）。当用户说“添加（我的）MCP/豆宝搜索/在线搜索/dataPro/OpenViking到当前/特定Agent”、“将MCP安装到Claude Code/OpenCode/OpenClaw/Trae”或“设置Agent Plan的MCP”时，使用`arkcli helper mcp`（仅注入MCP，不更改模型）。它还覆盖“帮助程序配置”（还设置模型/提供程序）、“帮助程序列表”（检查状态）和“帮助程序重置”（删除注入）。反向触发：将arkcli技能安装到代理→arkcli-connect；登录/401/身份验证 → arkcli-auth;生成图像/视频 → arkcli-gen。注：MCP注入仅Agent Plan支持（个人代理计划和团队代理计划-团队均可配置），但OpenViking的两个组件（数据面/控制面）仅适用于个人代理计划-团队代理计划-团队与OpenViking无关，只能通过豆宝搜索+dataPro进行配置；它只能应用于 claude-code、opencode、openclaw 或 trae（Trae 是一个 IDE，仅注入 MCP，不设置模型，并支持 `--scope project` 编写项目级 ./.trae/mcp.json）。还有`arkcli helper supabase`：它**不是MCP**，但安装byted-supabase-cli +技能并注入Volcano登录状态以启用byted-supabase数据库功能（仅适用于代理计划：个人大/最大+全层团队；不支持个人小/中）。当用户说“配置 byted-supabase / 连接数据库 / 安装 supabase cli / 链接 supabase”时，使用此命令。
