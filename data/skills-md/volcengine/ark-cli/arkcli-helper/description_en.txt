arkcli helper: configure the local AI Agent (Claude Code / OpenCode / OpenClaw / Trae) into the Volcano Ark Plan. Its core capability is to inject the built‑in MCP of the Agent Plan into the Agent (Doubao search mcp‑server‑askecho‑search‑infinity + dataPro‑search + OpenViking openviking‑dataplane + OpenViking control plane openviking‑controlplane). When the user says “add (my) MCP / Doubao search / online search / dataPro / OpenViking to the current/specific Agent”, “install MCP into Claude Code/OpenCode/OpenClaw/Trae”, or “set the Agent Plan’s MCP”, use `arkcli helper mcp` (injects only the MCP, does not change the model). It also overrides `helper configure` (also sets model/provider), `helper list` (check status), and `helper reset` (remove injection). Reverse triggers: installing arkcli skills into the agent → arkcli‑connect; login/401/authentication → arkcli‑auth; generate image/video → arkcli‑gen. Note: MCP injection is supported only by Agent Plan (both personal agent‑plan and team agent‑plan‑team can be configured), but the two OpenViking components (data plane/control plane) are available only for the personal agent‑plan—team agent‑plan‑team has nothing to do with OpenViking and can only be configured with Doubao search + dataPro; it can only be applied to claude‑code, opencode, openclaw, or trae (Trae is an IDE, injects only MCP, does not set a model, and supports `--scope project` to write a project‑level ./.trae/mcp.json). There is also `arkcli helper supabase`: it **is not an MCP**, but installs byted‑supabase‑cli + skill and injects the Volcano login state to enable byted‑supabase database capabilities (only for Agent Plan: personal large/max + full‑tier team; personal small/medium are not supported). When the user says “configure byted‑supabase / connect the database / install supabase cli / link supabase”, use this.
