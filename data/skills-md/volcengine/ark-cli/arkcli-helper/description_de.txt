arkcli-Helfer: Konfigurieren Sie den lokalen KI-Agenten (Claude Code / OpenCode / OpenClaw / Trae) im Volcano Ark-Plan. Seine Kernfunktion besteht darin, das integrierte MCP des Agentenplans in den Agenten einzufügen (Doubao Search mcp-server-askecho-search-infinity + dataPro-search + OpenViking openviking-dataplane + OpenViking-Steuerungsebene openviking-controlplane). Wenn der Benutzer sagt: „Füge (meine) MCP / Doubao-Suche / Online-Suche / dataPro / OpenViking zum aktuellen/spezifischen Agenten hinzu“, „installiere MCP in Claude Code/OpenCode/OpenClaw/Trae“ oder „setze den MCP des Agentenplans fest“, verwende „arkcli helper mcp“ (fügt nur den MCP ein, ändert das Modell nicht). Es überschreibt außerdem „Helper-Konfiguration“ (legt auch Modell/Anbieter fest), „Helper-Liste“ (Status prüfen) und „Helper-Reset“ (Injektion entfernen). Umgekehrte Auslöser: Arkcli-Skills im Agent installieren → arkcli-connect; login/401/authentication → arkcli‑auth; Bild/Video generieren → arkcli‑gen. Hinweis: Die MCP-Injektion wird nur von Agent Plan unterstützt (sowohl Personal Agent-Plan als auch Team Agent-Plan-Team können konfiguriert werden), aber die beiden OpenViking-Komponenten (Datenebene/Steuerungsebene) sind nur für den Personal Agent-Plan verfügbar – Team Agent-Plan-Team hat nichts mit OpenViking zu tun und kann nur mit Doubao Search + dataPro konfiguriert werden; Es kann nur auf Claude-Code, Opencode, Openclaw oder Trae angewendet werden (Trae ist eine IDE, injiziert nur MCP, legt kein Modell fest und unterstützt „--scope project“, um ein ./.trae/mcp.json auf Projektebene zu schreiben). Es gibt auch „arkcli helper supabase“: Es ist **kein MCP**, sondern installiert byted-supabase-cli + Skill und fügt den Volcano-Anmeldestatus ein, um byted-supabase-Datenbankfunktionen zu aktivieren (nur für Agentenplan: Personal Large/Max + Full-Tier-Team; Personal Small/Medium werden nicht unterstützt). Wenn der Benutzer sagt „byted-supabase konfigurieren / Datenbank verbinden / supabase cli installieren / supabase verknüpfen“, verwenden Sie dies.
