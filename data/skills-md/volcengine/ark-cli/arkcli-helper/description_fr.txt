Assistant arkcli : configurez l'agent IA local (Claude Code / OpenCode / OpenClaw / Trae) dans le plan Volcano Ark. Sa capacité principale est d'injecter le MCP intégré du plan d'agent dans l'agent (Doubao search mcp-server-askecho-search-infinity + dataPro-search + OpenViking openviking-dataplane + OpenViking control plane openviking-controlplane). Lorsque l'utilisateur dit « ajouter (ma) recherche MCP / Doubao / recherche en ligne / dataPro / OpenViking à l'agent actuel/spécifique », « installer MCP dans Claude Code/OpenCode/OpenClaw/Trae » ou « définir le MCP du plan d'agent », utilisez `arkcli helper mcp` (injecte uniquement le MCP, ne change pas le modèle). Il remplace également « helper configure » (définit également le modèle/fournisseur), « helper list » (vérifier l'état) et « helper reset » (supprimer l'injection). Déclencheurs inversés : installation des compétences arkcli dans l'agent → arkcli‑connect ; connexion/401/authentification → arkcli‑auth ; générer une image/vidéo → arkcli‑gen. Remarque : L'injection MCP est prise en charge uniquement par Agent Plan (le plan d'agent personnel et le plan d'agent d'équipe peuvent être configurés), mais les deux composants OpenViking (plan de données/plan de contrôle) ne sont disponibles que pour le plan d'agent personnel ; l'équipe de plan d'agent n'a rien à voir avec OpenViking et ne peut être configurée qu'avec Doubao search + dataPro ; il ne peut être appliqué qu'à claude‑code, opencode, openclaw ou trae (Trae est un IDE, injecte uniquement MCP, ne définit pas de modèle et prend en charge le « --scope project » pour écrire un ./.trae/mcp.json au niveau du projet). Il existe également `arkcli helper supabase` : ce **n'est pas un MCP**, mais installe la compétence byted‑supabase‑cli + et injecte l'état de connexion Volcano pour activer les fonctionnalités de la base de données byted‑supabase (uniquement pour le plan Agent : personnel grand/max + équipe complète ; les personnels petits/moyens ne sont pas pris en charge). Lorsque l'utilisateur dit « configurer byted‑supabase / connecter la base de données / installer supabase cli / lier supabase », utilisez ceci.
