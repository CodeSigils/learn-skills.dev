arkcli helper：將本地AI Agent（Claude Code / OpenCode / OpenClaw / Trae）配置到火山方舟計畫中。其核心能力是將Agent Plan的內建MCP注入Agent（豆寶搜尋 mcp-server-askecho-search-infinity + dataPro-search + OpenViking openviking-dataplane + OpenViking 控制平面 openviking-controlplane）。當用戶說「新增（我的）MCP/豆寶搜尋/線上搜尋/dataPro/OpenViking到目前/特定Agent」、「將MCP安裝到Claude Code/OpenCode/OpenClaw/Trae」或「設定Agent Plan的MCP」時，使用`arkcli helper mcp`（僅注入MCP，不更改模型）。它還覆蓋「幫助程式配置」（也設定模型/提供者）、「幫助程式清單」（檢查狀態）和「幫助程式重設」（刪除注入）。反向觸發：將arkcli技能安裝到代理→arkcli-connect；登入/401/身份驗證 → arkcli-auth;產生映像/影片 → arkcli-gen。附註：MCP注入僅Agent Plan支援（個人代理計劃和團隊代理計劃-團隊均可配置），但OpenViking的兩個組件（資料面/控制面）僅適用於個人代理計劃-團隊代理計劃-團隊與OpenViking無關，只能透過豆寶搜尋+dataPro進行配置；它只能應用於 claude-code、opencode、openclaw 程式設定：不支援： project` 撰寫專案級 ./.trae/mcp.json）。還有`arkcli helper supabase`：它**不是MCP**，但安裝byted-supabase-cli +技能並注入Volcano登入狀態以啟用byted-supabase資料庫功能（僅適用於代理計劃：個人大/最大+全層團隊；不支援個人小/中）。當使用者說「設定 byted-supabase / 連線資料庫 / 安裝 supabase cli / 連結 supabase」時，使用此指令。
