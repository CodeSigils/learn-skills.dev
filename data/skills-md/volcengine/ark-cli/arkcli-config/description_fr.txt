Gestion de la configuration locale arkcli. À partir de la version 0.1.16, veuillez utiliser de préférence `arkcli profile <subcmd>` pour les opérations liées au profil (init/list/show/switch/delete sont obsolètes) ; cette compétence peut toujours gérer la « réinitialisation de la configuration arkcli » et le dépannage historique de Yaml.
