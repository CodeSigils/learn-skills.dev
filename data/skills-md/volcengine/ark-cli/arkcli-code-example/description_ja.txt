arkcli +code-example: 指定された基本モデルの多言語 (Python / Go / Java / Node /curl) 呼び出しサンプル コードを生成し、それをローカル ファイルに書き込みます。データ ソースは Volcano Ark OpenTOP OpenGetSampleCode です。これは、ユーザーが特定の基本モデルの SDK/curl 呼び出しサンプルを取得し、それをローカル統合テンプレートとして保存する必要がある場合に使用されます。アンチトリガー: TTS/ASR/音声モデルには arkcli サンプル コード パスがありません。これはバージョンにパッチを当てても解決できないため、モデル検索にリダイレクトして、現在サポートされていないことを示す必要があります。
