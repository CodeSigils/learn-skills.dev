arkcli +code-example: genera código de ejemplo de invocación en varios idiomas (Python/Go/Java/Node/curl) para un modelo base específico y lo escribe en un archivo local. La fuente de datos es Volcano Ark OpenTOP OpenGetSampleCode. Se utiliza cuando un usuario necesita obtener un ejemplo de invocación de SDK/curl para un modelo base particular y guardarlo como una plantilla de integración local. Contradisparador: los modelos TTS/ASR/voz no tienen una ruta de código de ejemplo de arkcli; Esto no se puede resolver agregando una versión y se debe redirigir a la búsqueda de modelos para indicar que actualmente no es compatible.
