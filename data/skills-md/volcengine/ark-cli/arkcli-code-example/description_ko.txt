arkcli +code-example: 지정된 기본 모델에 대한 다중 언어(Python/Go/Java/Node/curl) 호출 예제 코드를 생성하고 로컬 파일에 씁니다. 데이터 소스는 화산방주 OpenTOP OpenGetSampleCode입니다. 사용자가 특정 기본 모델에 대한 SDK/curl 호출 예제를 얻고 이를 로컬 통합 템플릿으로 저장해야 할 때 사용됩니다. 카운터 트리거: TTS/ASR/음성 모델에는 arkcli 예제 코드 경로가 없습니다. 이는 버전을 추가하여 해결할 수 없으며 현재 지원되지 않음을 나타내기 위해 모델 검색으로 리디렉션되어야 합니다.
