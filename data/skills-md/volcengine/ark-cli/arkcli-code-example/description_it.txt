arkcli +code-example: genera un codice di esempio di invocazione multilingue (Python/Go/Java/Node/curl) per un modello base specificato e scrivilo in un file locale. L'origine dati è Volcano Ark OpenTOP OpenGetSampleCode. Viene utilizzato quando un utente deve ottenere un esempio di chiamata SDK/curl per un particolare modello base e salvarlo come modello di integrazione locale. Controtrigger: i modelli TTS/ASR/voice non hanno un percorso del codice di esempio arkcli; questo non può essere risolto aggiungendo una versione e deve essere reindirizzato alla ricerca dei modelli per indicare che attualmente non è supportato.
