arkcli +code-example: сгенерируйте многоязычный (Python/Go/Java/Node/curl) пример кода для вызова указанной базовой модели и запишите его в локальный файл. Источником данных является Volcano Ark OpenTOP OpenGetSampleCode. Он используется, когда пользователю необходимо получить пример вызова SDK/curl для конкретной базовой модели и сохранить его как шаблон локальной интеграции. Резервный вариант: модели TTS/ASR/голос не имеют пути к примеру кода arkcli; Эту проблему нельзя устранить с помощью исправления версии, и ее необходимо перенаправить на поиск моделей, чтобы указать, что в настоящее время она не поддерживается.
