arkcli +code-example: Generieren Sie mehrsprachigen (Python / Go / Java / Node / Curl) Beispielaufrufcode für ein angegebenes Basismodell und schreiben Sie ihn in eine lokale Datei. Die Datenquelle ist Volcano Ark OpenTOP OpenGetSampleCode. Es wird verwendet, wenn ein Benutzer das SDK/Curl-Beispiel für ein bestimmtes Basismodell abrufen und es als lokale Integrationsvorlage speichern muss. Anti-Trigger: TTS/ASR/Voice-Modelle verfügen nicht über einen Arkcli-Beispielcodepfad; Dies kann nicht durch Hinzufügen einer Version behoben werden und muss zur Modellsuche umgeleitet werden, um anzugeben, dass es derzeit nicht unterstützt wird.
