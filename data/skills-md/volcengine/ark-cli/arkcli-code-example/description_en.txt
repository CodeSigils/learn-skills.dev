arkcli +code-example: Generate multi-language (Python / Go / Java / Node / curl) invocation example code for a specified base model and write it to a local file. The data source is Volcano Ark OpenTOP OpenGetSampleCode. It is used when a user needs to obtain a SDK / curl invocation example for a particular base model and save it as a local integration template. Counter‑trigger: TTS/ASR/voice models do not have an arkcli example code path; this cannot be resolved by adding a version and must be redirected to models search to indicate that it is currently unsupported.
