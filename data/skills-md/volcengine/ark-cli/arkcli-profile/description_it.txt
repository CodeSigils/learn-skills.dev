gestione delle sfaccettature del profilo arkcli: elenca, visualizza, crea, cambia, elimina e rinomina i profili; gestire l'elenco delle chiavi API all'interno di un profilo; gestire il modello predefinito (testo/immagine/video) per i profili di tipo piano; impostare l'ID risorsa predefinito per una modalità specifica. Nella versione 0.1.16, tutti i comandi originali `arkcli config init/list/show/switch/delete` sono stati migrati qui, diventando l'unico punto di ingresso per le operazioni del profilo; i vecchi sottocomandi di configurazione sono deprecati.
