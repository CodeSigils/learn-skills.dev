arkcli profile facet management: list, view, create, switch, delete, and rename profiles; manage the API Key list within a profile; manage the default model (text/image/video) for plan-type profiles; set the default resource ID for a specific modality. In version 0.1.16, all original `arkcli config init/list/show/switch/delete` commands were migrated here, becoming the sole entry point for profile operations; the old config subcommands are deprecated.
