Gestion des aspects du profil arkcli : répertorier, afficher, créer, changer, supprimer et renommer les profils ; gérer la liste des clés API dans un profil ; gérer le modèle par défaut (texte/image/vidéo) pour les profils de type plan ; définir l'ID de ressource par défaut pour une modalité spécifique. Dans la version 0.1.16, toutes les commandes originales `arkcli config init/list/show/switch/delete` ont été migrées ici, devenant ainsi le seul point d'entrée pour les opérations de profil ; les anciennes sous-commandes de configuration sont obsolètes.
