gestión de facetas del perfil arkcli: enumerar, ver, crear, cambiar, eliminar y cambiar el nombre de perfiles; administrar la lista de claves API dentro de un perfil; administrar el modelo predeterminado (texto/imagen/video) para perfiles de tipo plan; establezca el ID de recurso predeterminado para una modalidad específica. En la versión 0.1.16, todos los comandos originales `arkcli config init/list/show/switch/delete` se migraron aquí, convirtiéndose en el único punto de entrada para las operaciones de perfil; Los antiguos subcomandos de configuración están en desuso.
