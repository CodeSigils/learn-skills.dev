управление фасетами профилей arkcli: список, просмотр, создание, переключение, удаление и переименование профилей; управлять списком ключей API в профиле; управлять моделью по умолчанию (текст/изображение/видео) для профилей типа плана; установите идентификатор ресурса по умолчанию для определенной модальности. В версии 0.1.16 все исходные команды `arkcli config init/list/show/switch/delete` были перенесены сюда, став единственной точкой входа для операций с профилем; старые подкоманды конфигурации устарели.
