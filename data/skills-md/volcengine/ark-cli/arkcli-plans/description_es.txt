Gestión de paquetes ARK (Plan de agente/Plan de codificación, versión personal + versión empresarial): consultar existencias/compra/renovación/lista de modelos/rotar APIKey, **y todas las operaciones de gestión para puestos de la versión empresarial**: enumerar puestos (`plans team seat-list`), asignar puestos a los empleados (`plans team seat-assign`), verificar quién se unió a qué asiento, rotar APIKey de asiento (`plans team turn-apikey`). Palabras clave: empaquetar / comprar / renovar / enumerar puestos / ver la vinculación de puestos / quién vinculó qué puesto / asignar puestos a los empleados / desvincular / ver el administrador de puestos del equipo / rotar APIKey. **Las preguntas relacionadas con el uso (cuánta cuota queda / qué proporción se ha utilizado / cuánto se usó cada asiento) van a [arkcli-usage](../arkcli-usage/SKILL.md).** Enrutamiento de verbos: **listar / vincular / asignar / rotar / desvincular** → aquí; **usar / consumir / cuánto** → arkcli-usage. También incluye estado del arnés: vista de solo lectura de si el MCP integrado (Doubao Search / dataPro / OpenViking) en el Agente AI local (claude-code / codex / opencode / openclaw / trae) bajo el Plan de Agente está instalado y si la clave está lista; desencadenantes: ¿Está instalado mi MCP? / Verificar el estado de instalación de MCP / Ver MCP en el estado del agente/arnés.
