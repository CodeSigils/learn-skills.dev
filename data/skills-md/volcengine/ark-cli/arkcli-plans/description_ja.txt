ARK パッケージ管理 (エージェント プラン / コーディング プラン、個人バージョン + エンタープライズ バージョン): 保有/購入/更新/モデル リスト/APIKey のクエリ、**およびエンタープライズ エディション シートのすべての管理操作**: シートのリスト (「計画チーム シートリスト」)、従業員へのシート割り当て (「計画チーム シート割り当て」)、誰がどのシートにバインドしているかを確認し、シート APIKey を回転します (「計画チーム 回転 apikey」)。トリガーキーワード: パッケージ化 / 購入 / 更新 / シートのリスト / シートバインドの表示 / 誰がどのシートをバインドしたか / 従業員へのシートの割り当て / バインド解除 / チームシート管理者の表示 / APIKey の回転。 **使用量関連の質問 (クォータの残り量 / 使用率 / 各シートの使用量) については、[arkcli-usage](../arkcli-usage/SKILL.md) を参照してください。** 動詞ルーティング: **list / binding / assign /rotate / unbind** → ここ; **使用/消費/量** → arkcli-usage。ハーネス ステータスも含まれます。エージェント プランの下のローカル AI エージェント (claude-code/codex/opencode/openclaw/trae) の組み込み MCP (Doubao Search / dataPro / OpenViking) がインストールされているかどうか、およびキーの準備ができているかどうかを示す読み取り専用ビュー。トリガー: MCP はインストールされていますか? / MCP のインストール ステータスを確認する / エージェント上の MCP を表示する / ハーネス ステータス。
