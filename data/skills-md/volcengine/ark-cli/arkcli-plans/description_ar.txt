إدارة حزم ARK (خطة الوكيل / خطة الترميز، الإصدار الشخصي + إصدار المؤسسة): مقتنيات الاستعلام / الشراء / التجديد / قائمة النماذج / تدوير APIKey، ** وجميع عمليات الإدارة لمقاعد إصدار المؤسسة **: قائمة المقاعد (`قائمة مقاعد فريق الخطط`)، تعيين مقاعد للموظفين (`تعيين مقعد فريق الخطط`)، تحقق من الشخص الذي يرتبط بالمقعد، قم بتدوير مفتاح API للمقعد (``تدوير فريق الخطط`). الكلمات الرئيسية: الحزمة / الشراء / التجديد / قائمة المقاعد / عرض ربط المقعد / من قام بربط المقعد / تعيين المقاعد للموظفين / فك الارتباط / عرض مسؤول مقعد الفريق / تدوير APIKey. **الأسئلة المتعلقة بالاستخدام (كم الحصة المتبقية / ما هي النسبة التي تم استخدامها / مقدار استخدام كل مقعد) انتقل إلى [arkcli-usage](../arkcli-usage/SKILL.md).** توجيه الفعل: **list / bind / sign / Rotate / unbind ** → هنا؛ **استخدام/استهلاك/كم** → arkcli-usage. يتضمن أيضًا حالة الحزام: عرض للقراءة فقط لمعرفة ما إذا كان MCP المدمج (Doubao Search / dataPro / OpenViking) في وكيل الذكاء الاصطناعي المحلي (claude-code / codex / opencode / openclaw / trae) مثبتًا ضمن Agent Plan وما إذا كان المفتاح جاهزًا؛ المشغلات: هل تم تثبيت MCP الخاص بي؟ / التحقق من حالة تثبيت MCP / عرض MCP على حالة الوكيل / الحزام.
