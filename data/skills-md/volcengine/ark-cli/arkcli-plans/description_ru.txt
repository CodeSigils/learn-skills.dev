Управление пакетами ARK (План агента/План кодирования, персональная версия + корпоративная версия): запрос активов/покупка/обновление/список моделей/ротация APIKey, **и все операции управления для мест корпоративной версии**: составление списка мест (`plans Team Seat-List`), назначение мест сотрудникам (`plans Team Seat-Assign`), проверка того, кто какое место привязал, смена места APIKey (`plans Team Rotate-apikey`). Ключевые слова-триггеры: пакет/купить/обновить/перечислить места/просмотреть привязку мест/кто какое место привязал/назначить места сотрудникам/отменить привязку/просмотр администратора мест группы/повернуть APIKey. **Вопросы, связанные с использованием (сколько осталось квоты / доля использования / сколько использовано каждого места), см. в [arkcli-usage](../arkcli-usage/SKILL.md).** Маршрутизация команд: **list/bind/assign/rotate/unbind** → здесь; **использовать/потреблять/сколько** → arkcli-usage. Также включает статус жгута: доступное только для чтения представление о том, установлен ли встроенный MCP (Doubao Search/dataPro/OpenViking) в локальном агенте AI (claude-code/codex/opencode/openclaw/trae) в плане агента и готов ли ключ; триггеры: установлен ли мой MCP? / Проверка состояния установки MCP / Просмотр MCP в состоянии агента / жгута.
