arkcli Doctor は、診断の全体的なエントリ ポイントです (1 つのスキルで、エラー コード / 推論エンドポイント / モデル / メトリクスの 4 つのドメインが統合されます)。Volcano Ark (Ark) の使用中に発生したエラー、リソース ステータス、使用量クォータ、およびパフォーマンス メトリクスを「arkcli Doctor」コマンド ファミリー (CLI ヘルス / アカウント / 推論エンドポイント / モデル / メトリクス / エラー コード) に集約します。ユーザー/エージェントが Ark エラー コード (ModelAccessDenied / InvalidParameter / RateLimitExceeded / ContentRiskBlocked / OutputVideoSensitiveContentDetected など) を取得するか、Ark エラー JSON、ep-xxx エンドポイント ID、またはモデル名を取得し、「エラーの理由 / 修正方法 / ステータスは何ですか / 使用量 / クォータのプレッシャー / 凍結されていますか / 権限は十分ですか / エンドポイントが遅いです」と尋ねたとき/ ダウン / モデル全体の状況 / どのエンドポイントがモデル クォータを消費したか / ライブ ビデオの傍受を修正する方法 / RPM / エラー率 / P99 レイテンシ / キャッシュ ヒット率」で使用されます。ユーザーが「arkcli ドクター / 診断 / ヘルスチェック / トラブルシューティング / 自己修復 / メトリクスの確認 / 監視データの取得」と言うと、ここにも表示されます。 **モデル名 + 例外/ヘルスチェックのセマンティクスもここに属します**: ユーザーが「<モデル> を使用すると、常に/頻繁に/最近失敗する / 遅い / タイムアウト / スロットルされている / エラーが発生する」、「<モデル> の失敗率が高い / リクエストのバッチがほとんど失敗する / このモデルの何が問題か / まだ使用できるか / スロットルされているか / クォータは十分ですか」、「<モデル> をチェックする / <モデル> を診断する / ヘルスチェック <モデル> 」と言った場合/ <モデル> は健全です / <モデル> の全体的な状況は何ですか」と表示されると、対応するコマンド `arkcli 医師モデル <名前>` が実行されます (ユーザーがエラー コードを詳しく説明しなくても、クロスタスク統計エラー、持続的な感覚異常、クォータ パースペクティブ、明示的な診断動詞はすべてここに表示され、「generate video/seedance/seedream」などのキーワードによって arkcli‑gen にルーティングされるべきではありません)。ライブビデオ傍受エラー コード (入力/出力…SensitiveContentDetected / PrivacyInformation / PolicyViolation) は、このスキルのリファレンスで引き続き取り上げられます。注: 純粋な arkcli のインストール/ログイン/プロファイル/認証の問題は、arkcli‑shared / arkcli‑auth に属します。このスキルは「arkcli Doctor」コマンド ファミリのみを処理します。
