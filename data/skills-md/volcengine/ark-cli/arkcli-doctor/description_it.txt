arkcli doctor è il punto di ingresso generale per la diagnostica (una competenza consolida quattro domini: codici di errore/endpoint di inferenza/modello/metriche): aggrega errori, stato delle risorse, quote di utilizzo e metriche delle prestazioni riscontrate durante l'utilizzo di Volcano Ark (Ark) nella famiglia di comandi `arkcli doctor` (salute CLI/account/endpoint di inferenza/modello/metriche/codici di errore). Quando un utente/agente ottiene un codice di errore Ark (ModelAccessDenied / InvalidParameter / RateLimitExceeded / ContentRiskBlocked / OutputVideoSensitiveContentDetected, ecc.) o riceve un errore Ark JSON, un ID endpoint ep-xxx o un nome di modello e chiede "perché l'errore / come risolverlo / qual è lo stato / quanto utilizzo / pressione sulla quota / è bloccato / le autorizzazioni sono sufficienti / l'endpoint è lento / down / com'è il modello nel complesso / quale endpoint ha consumato la quota del modello / come correggere l'intercettazione video in diretta / RPM / tasso di errore / latenza P99 / tasso di riscontro nella cache", viene utilizzato; anche quando l'utente dice "medico arkcli / diagnosi / controllo dello stato / risoluzione dei problemi / autoriparazione / esamina le metriche / estrae i dati di monitoraggio", va anche qui. **Anche il nome del modello + la semantica dell'eccezione/controllo dello stato appartengono a questo campo**: quando l'utente dice "Uso <modello> costantemente/spesso/recentemente con errori / lento / timeout / limitato / errore", "<modello> ha un'elevata percentuale di errori / un batch di richieste per lo più fallisce / cosa c'è che non va in questo modello / può ancora essere utilizzato / è limitato / la quota è sufficiente", "controlla <modello> / diagnostica <modello> / controllo sanitario <modello> / <modello> è integro / qual è la situazione generale of <model>", viene eseguito il comando corrispondente "arkcli doctor model <name>" (anche se l'utente non specifica un codice di errore, gli errori statistici tra attività incrociate / anomalie sensoriali persistenti / prospettiva di quota / verbi diagnostici espliciti vanno tutti qui e non devono essere indirizzati ad arkcli‑gen da parole chiave come "genera video/seedance/seedream"). I codici di errore di intercettazione video in diretta (Input/Output...SensitiveContentDetected / PrivacyInformation / PolicyViolation) continuano a essere trattati nei riferimenti di questa competenza. Nota: i problemi puri di installazione/accesso/profilo/autenticazione di arkcli appartengono a arkcli‑shared/arkcli‑auth; questa abilità gestisce solo la famiglia di comandi "arkcli doctor".
