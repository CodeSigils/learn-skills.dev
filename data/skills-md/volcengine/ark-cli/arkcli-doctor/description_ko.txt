arkcli doctor는 진단을 위한 전체 진입점입니다(하나의 기술은 오류 코드 / 추론 엔드포인트 / 모델 / 메트릭의 4개 도메인을 통합합니다). 이는 Volcano Ark(Ark)를 사용하는 동안 발생한 오류, 리소스 상태, 사용 할당량 및 성능 메트릭을 `arkcli doctor` 명령 계열(CLI 상태/계정/추론 엔드포인트/모델/메트릭/오류 코드)로 집계합니다. 사용자/에이전트가 Ark 오류 코드(ModelAccessDenied / InvalidParameter / RateLimitExceeded / ContentRiskBlocked / OutputVideoSensitiveContentDetected 등)를 얻거나 Ark 오류 JSON, ep-xxx 엔드포인트 ID 또는 모델 이름을 받고 "오류가 발생한 이유/수정 방법/상태/사용량/할당량 압력/동결 여부/권한이 충분합니까/엔드포인트가 느리거나 다운/상태가 어떻습니까"라고 묻는 경우 모델 전체 / 모델 할당량을 사용한 엔드포인트 / 라이브 비디오 가로채기 수정 방법 / RPM / 오류율 / P99 대기 시간 / 캐시 적중률”이 사용됩니다. 사용자가 "arkcli doctor/진단/상태 점검/문제 해결/자가 수리/메트릭 보기/모니터링 데이터 가져오기"라고 말하면 여기에도 표시됩니다. **모델 이름 + 예외/상태 확인 의미 체계도 여기에 속합니다**: 사용자가 "<모델>을 계속/자주/최근에 실패함/느리게/시간 초과/제한됨/오류"라고 말할 때, "<모델>의 실패율이 높음/일괄 요청이 대부분 실패함/이 모델의 문제점/계속 사용할 수 있는지/제한되었는지/할당량이 충분한지", "<모델> 확인 / <모델> 진단 / <모델> 상태 확인 / <모델> 상태 확인 / <모델>이 정상임 / <모델>의 전반적인 상황은 어떻습니까?”, 해당 명령 `arkcli doctor model <name>`이 실행됩니다(사용자가 오류 코드를 철자하지 않더라도 작업 간 통계 실패/지속적인 감각 이상/할당량 관점/명시적인 진단 동사가 모두 여기에 있으며 "영상 생성/시드/시드림 생성"과 같은 키워드로 arkcli‑gen으로 라우팅되어서는 안 됩니다). 라이브 비디오 차단 오류 코드(입력/출력…SensitiveContentDetected / PrivacyInformation / PolicyViolation)는 이 기술의 참조에서 계속해서 다뤄집니다. 참고: 순수 arkcli 설치/로그인/프로필/인증 문제는 arkcli‑shared/arkcli‑auth에 속합니다. 이 스킬은 'arkcli doctor' 명령 계열만 처리합니다.
