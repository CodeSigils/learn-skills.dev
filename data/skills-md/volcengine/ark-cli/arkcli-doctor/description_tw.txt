arkcli doctor 是診斷的整體入口點（一項技能整合了四個領域：錯誤代碼/推斷端點/模型/指標）：它將使用 Volcano Ark（Ark）時遇到的錯誤、資源狀態、使用配額和性能指標聚合到“arkcli doctor”命令系列（CLI health/account/infer-point/當使用者/Agent取得方舟錯誤代碼（ModelAccessDenied / InvalidParameter / RateLimitExceeded / ContentRiskBlocked / OutputVideoSensitiveContentDetected等），或取得方舟錯誤JSON，ep-xxx端點ID或模型名稱時，並詢問「錯誤原因/如何修復/狀態如何/使用量/配額壓力/是否凍結/權限是否足夠/端點緩慢/緩慢/模型整體情況如何/哪個端點消耗了模型配額/如何延遲/權限是否足夠/端點緩慢/緩慢/模型整體情況如何/哪個端點消耗了模型配額/ doctor/診斷/健康檢查/故障排除/自我修復/查看指標/提取監控數據」時，它也會出現在這裡。 **模型名稱+異常/運行狀況檢查語義也屬於這裡**：當用戶說“我使用<model>不斷/經常/最近失敗/緩慢/超時/節流/錯誤”，“<model>失敗率很高/一批請求大多失敗/這個模型出了什麼問題/它還能使用/是否受到節流/配額/配額（delmodel>”如何檢查“健康狀況的情況”，運行相應的命令 `arkcli doctor model <name>` （即使用戶沒有拼出錯誤代碼，跨任務統計失敗/持續感覺異常/配額透視/顯式診斷動詞都會出現在這裡，並且不應通過“generate video/seedance/seedream”等關鍵字路由到 arkcli-gen）。此技能的參考文獻中繼續涵蓋即時視訊攔截錯誤代碼（輸入/輸出…SensitiveContentDetected / PrivacyInformation / PolicyViolation）。注意：純 arkcli 安裝/登入/設定檔/驗證問題屬於 arkcli-shared / arkcli-auth；此技能僅處理「arkcli doctor」指令系列。
