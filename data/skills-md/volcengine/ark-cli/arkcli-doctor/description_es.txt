arkcli doctor es el punto de entrada general para el diagnóstico (una habilidad consolida cuatro dominios: códigos de error/punto final de inferencia/modelo/métricas): agrega errores, estado de recursos, cuotas de uso y métricas de rendimiento encontradas al usar Volcano Ark (Ark) en la familia de comandos `arkcli doctor` (salud CLI/cuenta/punto final de inferencia/modelo/métricas/códigos de error). Cuando un usuario/Agente obtiene un código de error de Ark (ModelAccessDenied / InvalidParameter / RateLimitExceeded / ContentRiskBlocked / OutputVideoSensitiveContentDetected, etc.), u obtiene un JSON de error de Ark, un ID de punto final ep-xxx o un nombre de modelo, y pregunta "por qué el error/cómo solucionarlo/cuál es el estado/cuánto uso/presión de cuota/está congelado/son suficientes los permisos/punto final es lento / está lento / cómo es el modelo en general / qué punto final consumió la cuota del modelo / cómo arreglar la interceptación de video en vivo / RPM / tasa de error / latencia P99 / tasa de aciertos de caché”, se utiliza esto; cuando el usuario dice "arkcli doctor/diagnóstico/verificación de estado/solución de problemas/autorreparación/ver métricas/extraer datos de monitoreo", también va aquí. **El nombre del modelo + la semántica de excepción/comprobación de estado también pertenecen aquí**: cuando el usuario dice "Uso <modelo> constantemente/a menudo/falla recientemente / lento / tiempo de espera / limitado / error", "<modelo> tiene una alta tasa de fallas / un lote de solicitudes en su mayoría fallan / qué está mal con este modelo / todavía se puede usar / está limitado / es la cuota suficiente", "comprobar <modelo> / diagnosticar <modelo> / chequeo de estado <modelo> / está <modelo> saludable / cuál es la situación general de <modelo>”, se ejecuta el comando correspondiente `arkcli doctor model <nombre>` (incluso si el usuario no detalla un código de error, las fallas estadísticas de tareas cruzadas/anomalías sensoriales persistentes/perspectiva de cuota/verbos de diagnóstico explícitos van aquí y no deben enrutarse a arkcli-gen mediante palabras clave como “generar video/seedance/seedream”). Los códigos de error de interceptación de video en vivo (Entrada/Salida...Contenido sensible detectado/Información de privacidad/Violación de política) continúan abarcándose en las referencias de esta habilidad. Nota: los problemas puros de instalación/inicio de sesión/perfil/autenticación de arkcli pertenecen a arkcli‑shared / arkcli‑auth; esta habilidad solo maneja la familia de comandos "arkcli doctor".
