arkcli doctor ist der allgemeine Einstiegspunkt für die Diagnose (ein Skill konsolidiert vier Domänen: Fehlercodes / Infer-Endpunkt / Modell / Metriken): Es aggregiert Fehler, Ressourcenstatus, Nutzungskontingente und Leistungsmetriken, die bei der Verwendung von Volcano Ark (Ark) auftreten, in der Befehlsfamilie „arkcli doctor“ (CLI-Gesundheit / Konto / Infer-Endpunkt / Modell / Metriken / Fehlercodes). Wenn ein Benutzer/Agent einen Ark-Fehlercode (ModelAccessDenied / InvalidParameter / RateLimitExceeded / ContentRiskBlocked / OutputVideoSensitiveContentDetected usw.) oder einen Ark-Fehler-JSON, eine ep-xxx-Endpunkt-ID oder einen Modellnamen erhält und fragt: „Warum liegt der Fehler vor? ist das Modell insgesamt / welcher Endpunkt das Modellkontingent verbraucht hat / wie man das Abfangen von Live-Videos behebt / RPM / Fehlerrate / P99-Latenz / Cache-Trefferrate“, wird dies verwendet; Wenn der Benutzer „arkcli doctor / diagnostizieren / Gesundheitscheck / Fehlerbehebung / Selbstreparatur / Metriken ansehen / Überwachungsdaten abrufen“ sagt, wird dies auch hier angezeigt. **Modellname + Ausnahme-/Gesundheitsprüfungssemantik gehört ebenfalls hierher**: Wenn der Benutzer sagt: „Ich verwende <Modell> ständig/oft/in letzter Zeit fehlgeschlagen/langsam/Zeitüberschreitung/gedrosselt/Fehler“, „<Modell> hat eine hohe Fehlerrate / eine Reihe von Anforderungen schlagen meistens fehl / was stimmt mit diesem Modell nicht / kann es noch verwendet werden / ist es gedrosselt / ist das Kontingent ausreichend“, „überprüfe <Modell> / diagnose <Modell> / Integritätsprüfung <Modell> / ist <Modell> fehlerfrei / was ist das? „Gesamtsituation von <Modell>“, wird der entsprechende Befehl „arkcli doctor model <Name>“ ausgeführt (auch wenn der Benutzer keinen Fehlercode buchstabiert, gehen hier aufgabenübergreifende statistische Fehler / anhaltende sensorische Anomalien / Quotenperspektive / explizite Diagnoseverben ein und sollten nicht über Schlüsselwörter wie „Video generieren/seedance/seedream“ an arkcli-gen weitergeleitet werden). Fehlercodes beim Abfangen von Live-Videos (Input/Output…SensitiveContentDetected/PrivacyInformation/PolicyViolation) werden weiterhin in den Referenzen dieses Skills behandelt. Hinweis: Reine Arkcli-Installations-/Anmelde-/Profil-/Authentifizierungsprobleme gehören zu arkcli-shared / arkcli-auth; Dieser Skill verwaltet nur die Befehlsfamilie „arkcli doctor“.
