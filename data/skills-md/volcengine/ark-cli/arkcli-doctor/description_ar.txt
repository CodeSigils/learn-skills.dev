arkcli Doctor هو نقطة الدخول الشاملة للتشخيصات (مهارة واحدة تجمع أربعة مجالات: رموز الخطأ / نقطة النهاية الاستدلالية / النموذج / المقاييس): فهي تجمع الأخطاء وحالة الموارد وحصص الاستخدام ومقاييس الأداء التي تمت مواجهتها أثناء استخدام Volcano Ark (Ark) في عائلة أوامر `arkcli doctor` (صحة CLI / الحساب / استنتاج نقطة النهاية / النموذج / المقاييس / رموز الخطأ). عندما يحصل المستخدم/الوكيل على رمز خطأ Ark (ModelAccessDenied / InvalidParameter / RateLimitExceeded / ContentRiskBlocked / OutputVideoSensitiveContentDetected، وما إلى ذلك)، أو يحصل على خطأ Ark JSON، أو معرف نقطة نهاية ep-xxx، أو اسم الطراز، ويسأل "لماذا الخطأ / كيفية إصلاحه / ما هي الحالة / مقدار الاستخدام / ضغط الحصص / هل تم تجميده؟ / هل الأذونات كافية / نقطة النهاية بطيئة / معطلة / كيف هو النموذج بشكل عام / أي نقطة النهاية استهلكت حصة النموذج / كيفية إصلاح اعتراض الفيديو المباشر / عدد الدورات في الدقيقة / معدل الخطأ / زمن الاستجابة P99 / معدل ضربات ذاكرة التخزين المؤقت، "يتم استخدام هذا؛ عندما يقول المستخدم "arkcli doctor / التشخيص / الفحص الصحي / استكشاف الأخطاء وإصلاحها / الإصلاح الذاتي / إلقاء نظرة على المقاييس / سحب بيانات المراقبة"، فإنه يظهر هنا أيضًا. **اسم النموذج + دلالات الاستثناء/التحقق من الصحة تنتمي أيضًا هنا**: عندما يقول المستخدم "أنا أستخدم <model> باستمرار/في كثير من الأحيان/مؤخرًا يفشل / بطيء / مهلة / مخانق / خطأ،" "<model> لديه معدل فشل مرتفع / مجموعة من الطلبات تفشل في الغالب / ما الخطأ في هذا النموذج / هل لا يزال من الممكن استخدامه / هل تم تقييده / هل الحصة كافية، "" تحقق من <model> / تشخيص <model> / تحقق من صحة <model> / هل <model> صحي / ما هو الوضع العام لـ <model>"، يتم تشغيل الأمر المقابل `arkcli doctor model <name>` (حتى لو لم يقم المستخدم بتوضيح رمز الخطأ، فإن حالات الفشل الإحصائي في المهام المشتركة / الشذوذات الحسية المستمرة / منظور الحصص / الأفعال التشخيصية الصريحة كلها تذهب هنا، ولا ينبغي توجيهها إلى arkcli‑gen عن طريق كلمات رئيسية مثل "إنشاء فيديو/بذور/حلم بذور"). تستمر تغطية رموز أخطاء اعتراض الفيديو المباشر (الإدخال/الإخراج...SensitiveContentDetected / PrivacyInformation / PolicyViolation) في مراجع هذه المهارة. ملاحظة: مشكلات تثبيت/تسجيل الدخول/الملف الشخصي/المصادقة الخالصة arkcli تخص arkcli‑shared / arkcli‑auth؛ تتعامل هذه المهارة مع عائلة أوامر "arkcli doctor" فقط.
