arkcli doctor is the overall entry point for diagnostics (one skill consolidates four domains: error codes / infer-endpoint / model / metrics): it aggregates errors, resource status, usage quotas, and performance metrics encountered while using Volcano Ark (Ark) into the `arkcli doctor` command family (CLI health / account / infer-endpoint / model / metrics / error codes). When a user/Agent obtains an Ark error code (ModelAccessDenied / InvalidParameter / RateLimitExceeded / ContentRiskBlocked / OutputVideoSensitiveContentDetected, etc.), or gets an Ark error JSON, an ep-xxx endpoint ID, or a model name, and asks “why the error / how to fix it / what is the status / how much usage / quota pressure / is it frozen / are permissions sufficient / endpoint is slow / down / how is the model overall / which endpoint consumed the model quota / how to fix live video interception / RPM / error rate / P99 latency / cache hit rate,” this is used; when the user says “arkcli doctor / diagnose / health check / troubleshooting / self‑repair / look at metrics / pull monitoring data,” it also goes here. **Model name + exception/health‑check semantics also belong here**: when the user says “I use <model> constantly/often/recently failing / slow / timeout / throttled / error,” “<model> has high failure rate / a batch of requests mostly fail / what’s wrong with this model / can it still be used / is it throttled / is the quota enough,” “check <model> / diagnose <model> / health‑check <model> / is <model> healthy / what’s the overall situation of <model>,” the corresponding command `arkcli doctor model <name>` is run (even if the user does not spell out an error code, cross‑task statistical failures / persistent sensory anomalies / quota perspective / explicit diagnostic verbs all go here, and should not be routed to arkcli‑gen by keywords like “generate video/seedance/seedream”). Live‑video interception error codes (Input/Output…SensitiveContentDetected / PrivacyInformation / PolicyViolation) continue to be covered in this skill’s references. Note: pure arkcli installation/login/profile/authentication issues belong to arkcli‑shared / arkcli‑auth; this skill only handles the `arkcli doctor` command family.
