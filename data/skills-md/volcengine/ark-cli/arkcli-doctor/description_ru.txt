arkcli Doctor — это общая точка входа для диагностики (один навык объединяет четыре домена: коды ошибок/конечная точка вывода/модель/метрики): он объединяет ошибки, состояние ресурсов, квоты использования и показатели производительности, возникающие при использовании Volcano Ark (Ark), в семейство команд `arkcli Doctor` (здоровье CLI/учетная запись/конечная точка вывода/модель/метрики/коды ошибок). Когда пользователь/агент получает код ошибки Ark (ModelAccessDenied/InvalidParameter/RateLimitExceeded/ContentRiskBlocked/OutputVideoSensitiveContentDetected и т. д.) или получает JSON ошибки Ark, идентификатор конечной точки ep-xxx или имя модели и спрашивает: «Почему ошибка/как ее исправить/каков статус/сколько использования/давление квоты/заморожено/являются ли разрешения достаточно/конечная точка работает медленно/медленно/как работает модель в целом/какая конечная точка использовала квоту модели/как исправить перехват живого видео/об/мин/частота ошибок/задержка P99/коэффициент попадания в кэш”, используется это значение; когда пользователь говорит «доктор arkcli / диагностика / проверка работоспособности / устранение неполадок / самостоятельный ремонт / просмотр показателей / получение данных мониторинга», это также идет сюда. **Имя модели + семантика исключения/проверки работоспособности также сюда относится**: когда пользователь говорит: «Я использую <модель> постоянно/часто/недавно сбой/медленно/тайм-аут/регулируется/ошибка», «<модель> имеет высокий процент отказов/пакет запросов в основном завершается неудачей/что не так с этой моделью/может ли она все еще использоваться/регулируется ли она/достаточно ли квоты», «проверьте <модель> / диагностируйте <модель> / проверка работоспособности <модель> / есть <модель> здорова / какова общая ситуация с <моделью>», запускается соответствующая команда `arkcli Doctor model <имя>` (даже если пользователь не указывает код ошибки, статистические сбои перекрестных задач / постоянные сенсорные аномалии / перспектива квоты / явные диагностические глаголы - все это идет сюда и не должно направляться в arkcli-gen по таким ключевым словам, как «сгенерировать видео/посевное задание/посевное состояние»). Коды ошибок перехвата живого видео (Input/Output…SensitiveContentDetected/PrivacyInformation/PolicyViolation) по-прежнему рассматриваются в справочниках по этому навыку. Примечание. Проблемы установки/входа/профиля/аутентификации чистого arkcli относятся к arkcli‑shared/arkcli‑auth; этот навык применим только к семейству команд `arkcli Doctor`.
