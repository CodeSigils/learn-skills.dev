arkcli +chat: يمكنك التحدث أو التفكير بسرعة من خلال واجهة API للاستجابات لمستوى البيانات، ودعم المدخلات متعددة الوسائط (الصور المحلية والفيديو والصوت والملفات العامة عبر @file)، وإخراج البث، وتعليمات النظام، وتعديلات العينات (درجة الحرارة/top‑p/max‑output‑kens)، وضبط جهد الاستدلال، والاستمرار متعدد المنعطفات باستخدام --store + Previous‑response‑id. استخدم هذا عندما يحتاج المستخدم إلى تفاعل فوري مع النموذج للحوار، أو الأسئلة والأجوبة، أو الاستدلال، أو المحادثات متعددة الوسائط المفتوحة مع الصور/الفيديو/الصوت وأسئلة المتابعة، أو تعديل درجة الحرارة/أخذ العينات، أو التحكم في كثافة التفكير، أو الاستمرار متعدد المنعطفات. ملحوظة: مهام الفهم متعددة الوسائط ذات تنسيق مخرجات محدد (نسخ الكلام، واستخراج حقل المستند، وتوقيت الترجمة، واختيار/وضع bbox، وتلخيص فصول الفيديو، وما إلى ذلك) يجب أن تستخدم arkcli‑understand؛ هذه المهارة مخصصة فقط للحوار/الاستدلال المفتوح.
