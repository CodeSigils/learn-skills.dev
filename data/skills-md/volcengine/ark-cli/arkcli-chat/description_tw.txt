arkcli +chat：透過資料平面回應 API 快速對話或推理，支援多模式輸入（本機影像、視訊、音訊、透過 @file 的通用檔案）、串流輸出、系統指令、取樣調整（溫度/top-p/max-output-tokens）、推理工作量調整、使用 --store + previous-response-id 進行多輪延續。當使用者需要立即與模型互動以進行對話、問答、推理、帶有圖像/視訊/音訊的開放式多模式對話以及後續問題、溫度/採樣調整、控制思維強度或多輪延續時，請使用此功能。注意：具有定義輸出格式的多模態理解任務（語音轉錄、文件欄位擷取、字幕計時、bbox 選擇/定位、影片章節摘要等）應使用 arkcli-understand；此技能僅適用於開放式對話/推理。
