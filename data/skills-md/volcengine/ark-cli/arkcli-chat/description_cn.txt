arkcli +chat：通过数据平面响应 API 快速对话或推理，支持多模式输入（本地图像、视频、音频、通过 @file 的通用文件）、流输出、系统指令、采样调整（温度/top-p/max-output-tokens）、推理工作量调整以及使用 --store + previous-response-id 进行多轮延续。当用户需要立即与模型交互以进行对话、问答、推理、带有图像/视频/音频的开放式多模式对话以及后续问题、温度/采样调整、控制思维强度或多轮延续时，请使用此功能。注意：具有定义输出格式的多模态理解任务（语音转录、文档字段提取、字幕计时、bbox 选择/定位、视频章节摘要等）应使用 arkcli-understand；该技能仅适用于开放式对话/推理。
