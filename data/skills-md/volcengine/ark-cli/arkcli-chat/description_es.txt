arkcli +chat: conversa o razona rápidamente a través de la API de respuestas del plano de datos, que admite entradas multimodales (imágenes locales, video, audio, archivos genéricos a través de @file), salida de transmisión, instrucciones del sistema, ajustes de muestreo (temperatura/top-p/max-output-tokens), ajuste del esfuerzo de razonamiento y continuación de múltiples turnos con --store + id-respuesta-anterior. Utilícelo cuando el usuario necesite una interacción inmediata con el modelo para diálogo, preguntas y respuestas, razonamiento, conversaciones multimodales abiertas con imágenes/vídeo/audio y preguntas de seguimiento, ajustes de temperatura/muestreo, control sobre la intensidad del pensamiento o continuación en varios turnos. Nota: las tareas de comprensión multimodal con un formato de salida definido (transcripción de voz, extracción de campos de documentos, sincronización de subtítulos, selección/posicionamiento de bbox, resumen de capítulos de video, etc.) deben usar arkcli-understand; esta habilidad es sólo para diálogo/razonamiento abierto.
