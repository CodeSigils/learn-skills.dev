arkcli +chat: Quickly converse or reason through the data-plane Responses API, supporting multimodal inputs (local images, video, audio, generic files via @file), streaming output, system instructions, sampling adjustments (temperature/top‑p/max‑output‑tokens), reasoning‑effort tuning, and multi‑turn continuation with --store + previous‑response‑id. Use this when the user needs immediate interaction with the model for dialogue, Q&A, reasoning, open‑ended multimodal conversations with images/video/audio and follow‑up questions, temperature/sampling tweaks, control over thinking intensity, or multi‑turn continuation. Note: multimodal understanding tasks with a defined output format (speech transcription, document field extraction, subtitle timing, bbox selection/positioning, video chapter summarization, etc.) should use arkcli‑understand; this skill is only for open‑ended dialogue/reasoning.
