arkcli +chat: быстрый обмен данными и вывод с помощью API ответов на уровне данных, поддержка мультимодальных входных данных (локальные изображения, видео, аудио, общие файлы через @file), потокового вывода, системных инструкций, корректировок выборки (токены температуры/максимального значения/максимального вывода), корректировки усилий по рассуждению и --store + идентификатор предыдущего ответа для многооборотного продолжения. Используйте это, когда пользователям необходимо взаимодействие с моделью в реальном времени, вопросы и ответы, рассуждения, открытый мультимодальный диалог и последующие действия с изображениями/видео/аудио, настройкой температуры/выборки, контролем интенсивности мышления или многооборотным продолжением. Примечание. Задачи мультимодального понимания с определенной формой вывода (транскрипция речи, извлечение полей документа, синхронизация субтитров, выбор и локализация bbox, обобщение глав видео и т. д.) должны использовать arkcli‑understand; этот навык обрабатывает только открытый диалог/вывод.
