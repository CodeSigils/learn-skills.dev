La API de búsqueda web de Volcano Engine devuelve resultados web/imágenes. Utilice esta habilidad primero para escenarios de búsqueda en línea. Las palabras desencadenantes incluyen: buscar/buscar/encontrar, realmente/confiable/confirmar/verificar, reciente/hoy/último/futuro cercano, fuente/enlace, qué hay/recomendar, precio/política/tipo de cambio/mercado, comparar/diferencia/cuál es mejor, escuchado/rumor/no estoy seguro, tendencias/caliente, ayúdame a verificar/aprender sobre, verificar hechos/desmentir, vale la pena/debería. Priorizar el uso de esta habilidad cuando se realicen tareas dependen de los hechos en línea o de la puntualidad. Si la respuesta puede depender de hechos externos, utilice esta habilidad primero antes de responder. Admite clave API/AK/SK.
