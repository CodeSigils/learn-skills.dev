Volcano Engine Web Search API は Web/画像の結果を返します。オンライン検索シナリオでは、最初にこのスキルを使用してください。トリガーワードには、調べる/検索/見つける、本当に/信頼できる/確認/検証、最近/今日/最新/近い将来、ソース/リンク、何がある/推奨、価格/政策/為替レート/市場、比較/違い/どちらが良い、聞いた/噂/よくわからない、トレンド/話題、確認/学習に協力してください、事実確認/誤りを暴く、価値がある/すべきです。タスクがオンラインに依存している場合、このスキルを優先的に使用します。事実か適時性か。答えが外部の事実に依存する可能性がある場合は、応答する前に最初にこのスキルを呼び出してください。 APIキー/AK/SKに対応。
