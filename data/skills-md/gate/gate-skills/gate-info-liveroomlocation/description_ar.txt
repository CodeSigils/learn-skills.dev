وظيفة القائمة الحية وإعادة التشغيل لـ Gate Exchange. استخدم هذه المهارة عندما يطلب المستخدم العثور على مجموعات بث مباشر أو إعادات حسب نوع العمل (العلامة)، أو العملة، أو النوع (الأكثر إثارة/الأحدث)، أو العدد. تتضمن عبارات التشغيل "最热直播" أو "قائمة الغرفة المباشرة" أو "行情分析直播间" أو "5个SOL相关直播" أو "أحدث عمليات الإعادة" أو "إعادة التشغيل المباشر لعملة العلامة" أو أي طلب يتضمن موقع الغرفة المباشرة أو قائمة إعادة التشغيل أو مرشح العلامة/العملة/الفرز.
