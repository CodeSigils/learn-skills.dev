Навык выполнения платежей Gate Pay. Используйте, когда пользователь запрашивает оплату с помощью Gate Pay, оплату торгового сбора или выполнение потоков с приоритетом оплаты (например, HTTP 402). Срабатывает при «Оплате на входе», «Полной оплате», «Оплате заказа». Требуется предварительная авторизация платежа Gate.
