Программа установки в один клик для серверов Gate MCP и навыков ворот в Cursor, Claude Code, Codex или OpenClaw/mcporter. Когда Gate-dex установлен, Gate Verify HTTP MCP также подключается как Gate-dex-sec для инструмента MCP tx_checkin перед подписанием кошелька для каждого кошелька Gate-dex-wallet. Срабатывает при «установке Gate MCP», «Навыках врат», «Проверке ворот», «регистрации передачи данных», «Настройке курсора ворот», «Коде ворот Клода», «Кодексе ворот», «Воротах OpenClaw», «Воротах Макпортера».
