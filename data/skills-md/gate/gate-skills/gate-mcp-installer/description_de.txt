Ein-Klick-Installationsprogramm für Gate MCP-Server und Gate-Skills auf Cursor, Claude Code, Codex oder OpenClaw/mcporter. Wenn Gate-Dex installiert ist, verkabelt Gate Verify HTTP MCP auch als Gate-Dex-Sec für das MCP-Tool tx_checkin, bevor die Wallet-Signatur per Gate-Dex-Wallet erfolgt. Wird ausgelöst bei „Install Gate MCP“, „Gate Skills“, „Gate Verify“, „Tx Check-in“, „Setup Gate Cursor“, „Gate Claude Code“, „Gate Codex“, „OpenClaw Gate“, „mcporter Gate“.
