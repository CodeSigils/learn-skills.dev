Gate Smart Earn (L2) عبر gate-cli: الكسب البسيط والمنتجات المزدوجة والستاكينغ ومقارنة العائدات وأفكار الصناديق الخاملة والاشتراك/الاسترداد مع التأكيد. استخدم هذه المهارة عندما يسأل المستخدم عن كسب APY، أو الربح المرن أو الثابت، أو الاستثمار المزدوج، أو المكافآت المتراكمة، أو المراكز، أو كسب الاشتراك/الاسترداد. تتضمن عبارات التحفيز الكسب، والكسب البسيط، والاستثمار المزدوج، والستاكينغ، والكسب المرن، والكسب الثابت، وكسب الاشتراك، واسترداد الكسب، والتجديد التلقائي، ومقارنة APY.
