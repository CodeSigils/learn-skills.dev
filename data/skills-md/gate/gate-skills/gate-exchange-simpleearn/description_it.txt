Query Gate Simple Earn (Uni) flessibile. Utilizza questa abilità ogni volta che l'utente chiede informazioni su Guadagno semplice, intento di iscrizione o di riscatto, query di posizione, query di interesse o APY superiore. Le frasi trigger includono "Simple Earn", "Uni", "iscriviti", "riscatta", "guadagno flessibile", "posizioni", "interesse", "APY superiore" o qualsiasi richiesta che coinvolga l'iscrizione, il riscatto, le posizioni o gli interessi di Simple Earn.
