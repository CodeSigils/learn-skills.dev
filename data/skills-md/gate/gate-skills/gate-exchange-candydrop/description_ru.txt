Руководство по действиям Gate CandyDrop. Используйте этот навык всякий раз, когда пользователи хотят просмотреть действия CandyDrop, просмотреть правила действий, зарегистрироваться для участия, проверить ход выполнения задач или запросить записи об участии и раздаче. Триггерные фразы включают в себя: candydrop, действия candydrop, список действий, регистрация для candydrop, ход выполнения задачи, записи об участии, записи airdrop.
