Compétences de marché et de données de jetons gate-dex CLI : ligne K, liquidité, statistiques de trading, informations sur les jetons, audit de sécurité, classements, nouvelles inscriptions, configuration de la chaîne et RPC brut. Lecture seule ; pas de signature. Utilisez cette compétence chaque fois que l'utilisateur demande des données de marché en chaîne, des informations sur les jetons ou des audits de sécurité via la CLI gate-dex. Les expressions de déclenchement incluent la ligne K, le prix du jeton, la capitalisation boursière, le risque du jeton, la vérification du pot de miel, le classement des jetons, les nouveaux jetons, la liquidité, les statistiques d'émission, la configuration de la chaîne, le rpc.
