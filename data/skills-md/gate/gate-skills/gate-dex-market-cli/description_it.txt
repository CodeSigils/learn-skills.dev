Competenza sui dati di mercato e token della CLI gate-dex: linea K, liquidità, statistiche di trading, informazioni sui token, controllo di sicurezza, classifiche, nuovi elenchi, configurazione della catena e RPC non elaborato. Sola lettura; nessuna firma. Utilizza questa competenza ogni volta che l'utente richiede dati di mercato on-chain, informazioni sui token o controlli di sicurezza tramite la CLI gate-dex. Le frasi trigger includono linea K, prezzo del token, capitalizzazione di mercato, rischio del token, controllo dell'honeypot, classifica dei token, nuovi token, liquidità, statistiche tx, configurazione della catena, rpc.
