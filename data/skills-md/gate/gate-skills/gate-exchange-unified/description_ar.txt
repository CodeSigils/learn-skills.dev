بوابة مهارة عمليات الحساب الموحد. استخدم هذه المهارة عندما يطلب المستخدم التحقق من رصيد الحساب الموحد، أو الاستعلام عن الحدود القابلة للاقتراض أو التحويل، أو اقتراض/سداد الأموال، أو فحص سجلات القروض أو الفوائد، أو تبديل وضع الحساب الموحد، أو تكوين الرافعة المالية لكل عملة، أو إدارة العملات الإضافية. تتضمن عبارات التحفيز "الحساب الموحد"، أو "حد الاقتراض"، أو "سداد القرض"، أو "وضع التبديل"، أو "تعيين الرافعة المالية"، أو "تعيين الضمانات"، أو أي طلب يجمع بين حالة مخاطر الحساب الموحد وإجراءات التمويل.
