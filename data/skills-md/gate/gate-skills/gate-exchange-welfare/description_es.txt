Centro de bienestar Gate Exchange nueva habilidad de tarea de usuario con integración de herramientas MCP. Utilice esta habilidad siempre que el usuario pregunte sobre beneficios sociales, recompensas para nuevos usuarios, cómo reclamar recompensas o tareas disponibles. Las frases desencadenantes incluyen: qué bienestar, cómo reclamar recompensas, beneficios para nuevos usuarios, tareas para nuevos usuarios, qué tareas puedo hacer, reclamar recompensas. CRÍTICO: Debe utilizar datos MCP reales, nunca proporcionar información de recompensa falsa. Toda la documentación en inglés.
