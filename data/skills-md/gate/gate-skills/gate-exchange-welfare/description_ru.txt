Центр социального обеспечения Gate Exchange, новые навыки выполнения задач пользователя с интеграцией инструментов MCP. Используйте этот навык всякий раз, когда пользователь спрашивает о социальных льготах, новых вознаграждениях для пользователей, о том, как получить вознаграждения или доступных заданиях. Триггерные фразы включают в себя: какое благосостояние, как получить вознаграждение, новые преимущества пользователя, новые задачи пользователя, какие задачи я могу выполнять, требовать вознаграждения. ВАЖНО: необходимо использовать реальные данные MCP, никогда не предоставлять фальшивую информацию о вознаграждении. Вся документация на английском языке.
