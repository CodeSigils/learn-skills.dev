Nouvelle compétence de tâche utilisateur du centre de bien-être Gate Exchange avec intégration des outils MCP. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur les prestations sociales, les récompenses des nouveaux utilisateurs, comment réclamer des récompenses ou les tâches disponibles. Les phrases de déclenchement incluent : quel bien-être, comment réclamer des récompenses, de nouveaux avantages pour les utilisateurs, de nouvelles tâches pour les utilisateurs, quelles tâches puis-je effectuer, réclamer une récompense. CRITIQUE : Doit utiliser de vraies données MCP, ne jamais fournir de fausses informations sur les récompenses. Toute la documentation en anglais.
