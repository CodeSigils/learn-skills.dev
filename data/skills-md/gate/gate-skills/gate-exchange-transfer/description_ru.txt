Навык внутренней передачи Gate Exchange с тем же UID. Используйте, когда пользователь говорит «перевод», «перемещение средств», «спот на фьючерс», «маржа в USDT», «бессрочный», «маржа». Фаза 1: только внутренняя передача (без главного-подчиненного). Для выполнения требуется явное подтверждение пользователя и предварительная проверка исходного баланса.
