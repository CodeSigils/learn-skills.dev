Навык обмена CLI Gate-dex: одноразовый обмен DEX (цитата → проверка GV → знак → трансляция) с помощью команды swap. Проверка GV встроена — никаких внешних двоичных файлов. Поддерживает мультичейн EVM и Solana с потоком утверждения ERC20. Используйте этот навык всякий раз, когда пользователь хочет поменять, обменять, купить, продать, конвертировать или соединить токены через интерфейс командной строки Gate-dex. Триггерные фразы включают обмен, обмен, покупку, продажу, конвертацию, мост, кроссчейн, котировку, историю обмена, детали обмена, токены обмена, токены моста.
