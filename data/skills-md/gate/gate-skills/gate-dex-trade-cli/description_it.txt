Abilità di scambio CLI gate-dex: scambio DEX one-shot (quote → GV check-in → segno → trasmissione) tramite il comando swap. Check-in GV integrato: nessun binario esterno. Supporta EVM multicatena e Solana, con flusso di approvazione ERC20. Utilizza questa abilità ogni volta che l'utente desidera scambiare, scambiare, acquistare, vendere, convertire o collegare token tramite la CLI gate-dex. Le frasi trigger includono swap, scambio, acquisto, vendita, conversione, bridge, cross-chain, quotazione, cronologia degli swap, dettagli dello swap, token di scambio, token di bridge.
