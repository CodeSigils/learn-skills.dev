gate-dex CLI スワップ スキル: swap コマンドによるワンショット DEX スワップ (引用 → GV チェックイン → 署名 → ブロードキャスト)。 GV チェックインが組み込まれており、外部バイナリはありません。 ERC20 承認フローを備えた EVM マルチチェーンと Solana をサポートします。ユーザーがgate-dex CLI経由でトークンを交換、交換、購入、販売、変換、またはブリッジしたい場合は常に、このスキルを使用します。トリガーフレーズには、スワップ、交換、買い、売り、変換、ブリッジ、クロスチェーン、相場、スワップ履歴、スワップ詳細、スワップトークン、ブリッジトークンが含まれます。
