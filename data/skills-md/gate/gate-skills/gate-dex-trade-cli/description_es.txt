Habilidad de intercambio CLI gate-dex: intercambio DEX de una sola vez (cita → registro GV → signo → transmisión) a través del comando de intercambio. Registro GV integrado: sin binario externo. Admite cadenas múltiples EVM y Solana, con flujo de aprobación ERC20. Utilice esta habilidad siempre que el usuario quiera intercambiar, comprar, vender, convertir o conectar tokens a través de la CLI gate-dex. Las frases de activación incluyen intercambio, intercambio, compra, venta, conversión, puente, cadena cruzada, cotización, historial de intercambio, detalle de intercambio, tokens de intercambio, tokens puente.
