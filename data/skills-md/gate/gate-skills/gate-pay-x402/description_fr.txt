Aide aux paiements Gate Pay x402 (HTTP 402), à la recherche de commerçants payants lorsque la découverte est disponible et à la configuration du portefeuille : Quick Wallet, jeton de plug-in Gate, clé EVM locale ou Gate Exchange. À utiliser lorsque l'utilisateur paie ou souhaite payer avec x402 ou 402, configure un portefeuille Gate ou MCP ou un paiement par défaut, répertorie les commerçants ou les services payants, commande quelque chose sans lien marchand, ou dit 快捷钱包, 插件钱包, 私钥, 支付方式, 有哪些商户, Nom d'utilisateur, code d'accès, porte d'entrée, MCP d'achat, client, client, client ou PAYMENT_METHOD_PRIORITY. Ne PAS utiliser pour le trading uniquement ou pour discuter sur le marché sans Gate Pay x402 ou intention de portefeuille, ou pour exécuter le même ordre Gate Pay sur le MCP x402 d'un autre fournisseur.
