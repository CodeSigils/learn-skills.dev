Abilità del portafoglio Gate DEX CLI (REST puro). Autenticazione tramite OAuth, saldo, indirizzi portafoglio/account, elenco token, cronologia tx, trasferimenti e firma. Il check-in GV è integrato nella firma dei comandi. Utilizza questa abilità ogni volta che l'utente desidera accedere, controllare saldo/indirizzo, visualizzare la cronologia tx, trasferire token o firmare messaggi tramite la CLI gate-dex. Le frasi trigger includono accesso, disconnessione, saldo, indirizzo, token, cronologia tx, trasferimento, invio, firma-msg, firma-tx. Per gli swap utilizzare gate-dex-trade-cli; per i dati di mercato utilizzare gate-dex-market-cli.
