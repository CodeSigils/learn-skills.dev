Compétence de portefeuille Gate DEX CLI (pur REST). Authentification via OAuth, solde, adresses de portefeuille/compte, liste de jetons, historique des transmissions, transferts et signature. L'enregistrement GV est intégré aux commandes de signature. Utilisez cette compétence chaque fois que l'utilisateur souhaite se connecter, vérifier le solde/l'adresse, afficher l'historique des émissions, transférer des jetons ou signer des messages via la CLI gate-dex. Les phrases de déclenchement incluent la connexion, la déconnexion, le solde, l'adresse, les jetons, l'historique des transmissions, le transfert, l'envoi, la signature-msg, la signature-tx. Pour les swaps, utilisez gate-dex-trade-cli ; pour les données de marché, utilisez gate-dex-market-cli.
