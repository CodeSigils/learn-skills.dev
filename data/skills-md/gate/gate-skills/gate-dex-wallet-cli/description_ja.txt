Gate DEX CLI ウォレット スキル (純粋な REST)。 OAuth による認証、残高、ウォレット/アカウント アドレス、トークン リスト、TX 履歴、転送、署名。 GV チェックインは署名コマンドに組み込まれています。ユーザーがgate-dex CLI経由でログイン、残高/アドレスの確認、TX履歴の表示、トークンの転送、またはメッセージへの署名を行う場合は、このスキルを使用します。トリガー フレーズには、ログイン、ログアウト、残高、アドレス、トークン、TX 履歴、転送、送信、署名メッセージ、署名 TX が含まれます。スワップの場合は、gate-dex-trade-cli を使用します。市場データには、gate-dex-market-cli を使用します。
