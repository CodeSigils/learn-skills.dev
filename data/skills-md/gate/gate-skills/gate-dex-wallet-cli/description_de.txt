Gate DEX CLI-Wallet-Skill (reines REST). Authentifizierung über OAuth, Guthaben, Wallet-/Kontoadressen, Token-Liste, Sendeverlauf, Übertragungen und Signierung. Das GV-Checkin ist in Signierbefehle integriert. Verwenden Sie diesen Skill immer dann, wenn sich der Benutzer über die Gate-Dex-CLI anmelden, Kontostand/Adresse überprüfen, den Sendeverlauf anzeigen, Token übertragen oder Nachrichten signieren möchte. Zu den Auslösephrasen gehören Anmeldung, Abmeldung, Kontostand, Adresse, Token, Sendeverlauf, Übertragung, Senden, Sign-Msg, Sign-Tx. Für Swaps verwenden Sie gate-dex-trade-cli; Für Marktdaten verwenden Sie Gate-Dex-Market-Cli.
