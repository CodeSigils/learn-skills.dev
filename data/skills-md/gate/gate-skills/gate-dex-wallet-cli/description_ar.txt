مهارة محفظة Gate DEX CLI (الراحة الخالصة). المصادقة عبر OAuth، والرصيد، وعناوين المحفظة/الحساب، وقائمة الرموز المميزة، وسجل الإرسال، والتحويلات، والتوقيع. تم تضمين تسجيل الوصول إلى GV في أوامر التوقيع. استخدم هذه المهارة عندما يريد المستخدم تسجيل الدخول، أو التحقق من الرصيد/العنوان، أو عرض سجل الإرسال، أو نقل الرموز، أو تسجيل الرسائل عبر Gate-dex CLI. تتضمن عبارات التشغيل تسجيل الدخول، وتسجيل الخروج، والرصيد، والعنوان، والرموز المميزة، وسجل الإرسال، والتحويل، والإرسال، وتسجيل الرسائل، وتوقيع الإرسال. بالنسبة للمقايضات، استخدم gate-dex-trade-cli; للحصول على بيانات السوق، استخدم gate-dex-market-cli.
