Навык кошелька Gate DEX CLI (чистый REST). Аутентификация через OAuth, баланс, адреса кошелька/аккаунта, список токенов, история транзакций, переводы и подпись. Проверка GV встроена в команды подписи. Используйте этот навык всякий раз, когда пользователь хочет войти в систему, проверить баланс/адрес, просмотреть историю переводов, передать токены или подписать сообщения через CLI Gate-dex. Триггерные фразы включают вход в систему, выход из системы, баланс, адрес, токены, историю передачи, перевод, отправку, подпись-сообщение, подпись-передачу. Для свопов используйте Gate-dex-trade-cli; для рыночных данных используйте Gate-dex-market-cli.
