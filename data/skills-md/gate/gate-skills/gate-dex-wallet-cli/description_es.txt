Habilidad de billetera Gate DEX CLI (RESTO puro). Autenticación a través de OAuth, saldo, direcciones de billetera/cuenta, lista de tokens, historial de tx, transferencias y firmas. El registro de GV está integrado en los comandos de firma. Utilice esta habilidad siempre que el usuario quiera iniciar sesión, verificar el saldo/dirección, ver el historial de transferencias, transferir tokens o firmar mensajes a través de la CLI gate-dex. Las frases de activación incluyen inicio de sesión, cierre de sesión, saldo, dirección, tokens, historial de transmisión, transferencia, envío, firmar mensaje, firmar transmisión. Para intercambios utilice gate-dex-trade-cli; para datos de mercado utilice gate-dex-market-cli.
