Habilidad de consulta de solo lectura Gate TradFi (finanzas tradicionales) que utiliza herramientas MCP con el prefijo cex_tradfi. Utilice esta habilidad siempre que el usuario solicite consultar la lista de pedidos de TradFi, el historial de pedidos, las posiciones actuales o históricas, la lista de categorías, la lista de símbolos, el ticker, la línea de símbolos, los activos del usuario o la información de la cuenta MT5 en Gate. Las frases de activación incluyen 'órdenes de TradFi', 'historial de órdenes', 'posiciones', 'historial de posiciones', 'lista de categorías', 'lista de símbolos', 'ticker', 'kline', 'mis activos', 'cuenta MT5' o cualquier solicitud para ver datos de TradFi. No lo utilice para realizar pedidos o transferir fondos.
