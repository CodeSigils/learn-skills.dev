Навык выполнения запросов Gate TradFi (традиционные финансы) только для чтения с использованием инструментов MCP с префиксом cex_tradfi. Используйте этот навык всякий раз, когда пользователь запрашивает список заказов TradFi, историю заказов, текущие или исторические позиции, список категорий, список символов, тикер, линию символов, активы пользователя или информацию об учетной записи MT5 в Gate. Триггерные фразы включают «ордера TradFi», «историю заказов», «позиции», «историю позиций», «список категорий», «список символов», «тикер», «клайн», «мои активы», «учетную запись MT5» или любой запрос на просмотр данных TradFi. Не используйте для размещения заказов или перевода средств.
