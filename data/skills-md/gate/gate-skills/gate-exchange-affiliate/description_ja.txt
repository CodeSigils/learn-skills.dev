Gate Exchange アフィリエイト プログラムのデータ クエリと管理スキル。このスキルは、ユーザーがアフィリエイト/パートナー手数料、取引量、正味手数料、顧客数、取引ユーザーについて質問する場合、またはアフィリエイト プログラムへの申し込みを希望する場合に使用します。最大 180 日間のクエリをサポートします (API はリクエストあたり 30 日に制限されており、エージェントは長いクエリを分割する必要があります)。重要: API の user_id パラメータは、「手数料受信者」ではなく「トレーダー」を参照します。明示的に指定されない限り、使用は避けてください。 API リストからの集計データは、単純な合計ではなく、カスタム スクリプトを使用して計算する必要があります。重要な時間制約: すべてのクエリ時間は、UTC+8 タイムゾーンでのユーザーのシステムの現在の日付に基づいて計算されます。相対的な時間の説明 (例: 「過去 7 日間」、「過去 30 日間」、「今週」、「先月」) の場合は、現在の日付から日数を引いて開始日を計算し、開始日と終了日の両方をそれぞれ UTC+8 00:00:00 と 23:59:59 に変換してから、Unix タイムスタンプに変換します。未来のタイムスタンプをクエリ条件として決して使用しないでください。タイムスタンプが必要な場合は、システム関数を使用してタイムスタンプを取得し、手動で生成しないでください。 「to」パラメータは常に現在の Unix タイムスタンプ以下である必要があります。トリガーフレーズには、「私のアフィリエイトデータ」、「今週のコミッション」、「パートナーの収益」、「チームのパフォーマンス」、「顧客の取引高」、「リベート収入」、「アフィリエイトの申請」などがあります。
