Навыки запроса и управления данными партнерской программы Gate Exchange. Используйте этот навык, когда пользователи спрашивают о комиссии своего партнера/партнера, объеме торгов, чистых комиссиях, количестве клиентов, торговых пользователях или хотят подать заявку на участие в партнерской программе. Поддерживает запросы на срок до 180 дней (API ограничен 30 днями на каждый запрос, агент должен разделить более длинные запросы). ВАЖНО: параметр user_id в API относится к «трейдеру», а не к «получателю комиссионных». Не используйте его, если это явно не указано. Агрегированные данные из списков API следует рассчитывать с помощью пользовательских скриптов, а не простого суммирования. КРИТИЧЕСКОЕ ОГРАНИЧЕНИЕ ВРЕМЕНИ: время всех запросов рассчитывается на основе текущей даты системы пользователя в часовом поясе UTC+8. Для описаний относительного времени (например, «последние 7 дней», «последние 30 дней», «на этой неделе», «прошлый месяц») вычислите дату начала, вычитая дни из текущей даты, затем преобразуйте даты начала и окончания в UTC+8 00:00:00 и 23:59:59 соответственно, а затем преобразуйте в временные метки Unix. НИКОГДА не используйте будущие временные метки в качестве условий запроса. Если необходимы временные метки, получайте их с помощью системных функций и никогда не создавайте вручную. Параметр «to» всегда должен быть меньше или равен текущей временной метке Unix. Триггерные фразы включают «мои партнерские данные», «комиссия на этой неделе», «доход партнера», «эффективность команды», «объем торговли клиентов», «доход со скидкой», «подать заявку на партнерство».
