Gate Exchange联盟计划数据查询和管理技能。当用户询问他们的联盟/合作伙伴佣金、交易量、净费用、客户数量、交易用户或想要申请联盟计划时，请使用此技能。支持长达 180 天的查询（API 每个请求限制为 30 天，代理应拆分更长的查询）。重要提示：API 中的 user_id 参数指的是“交易者”而不是“佣金接收者”——除非明确指定，否则避免使用。应使用自定义脚本来计算 API 列表中的聚合数据，而不是简单的求和。关键时间约束：所有查询时间均根据用户系统当前日期（UTC+8 时区）计算。对于相对时间描述（例如，“最近 7 天”、“最近 30 天”、“本周”、“上个月”），通过从当前日期减去天数来计算开始日期，然后将开始日期和结束日期分别转换为 UTC+8 00:00:00 和 23:59:59，然后转换为 Unix 时间戳。切勿使用未来时间戳作为查询条件。当需要时间戳时，通过系统函数获取，不要手动生成。 “to”参数必须始终小于或等于当前 Unix 时间戳。触发短语包括“我的联盟数据”、“本周佣金”、“合作伙伴收益”、“团队绩效”、“客户交易量”、“返利收入”、“申请联盟”。
