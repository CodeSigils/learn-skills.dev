Habilidad de gestión y consulta de datos del programa de afiliados de Gate Exchange. Utilice esta habilidad cuando los usuarios pregunten sobre su comisión de afiliado/socio, volumen de operaciones, tarifas netas, recuento de clientes, usuarios comerciales o quieran solicitar el programa de afiliados. Admite consultas de hasta 180 días (API limitada a 30 días por solicitud, el agente debe dividir las consultas más largas). IMPORTANTE: el parámetro user_id en las API se refiere a 'comerciante', no a 'receptor de comisiones'; evite su uso a menos que se especifique explícitamente. Los datos agregados de las listas de API deben calcularse mediante scripts personalizados, no mediante una simple suma. RESTRICCIÓN DE TIEMPO CRÍTICO: Todos los tiempos de consulta se calculan en función de la fecha actual del sistema del usuario en la zona horaria UTC+8. Para descripciones de tiempo relativo (por ejemplo, 'últimos 7 días', 'últimos 30 días', 'esta semana', 'último mes'), calcule la fecha de inicio restando días de la fecha actual, luego convierta las fechas de inicio y finalización a UTC+8 00:00:00 y 23:59:59 respectivamente, luego convierta a marcas de tiempo Unix. NUNCA utilice marcas de tiempo futuras como condiciones de consulta. Cuando se necesiten marcas de tiempo, obténgalas a través de funciones del sistema, nunca genere manualmente. El parámetro 'to' siempre debe ser menor o igual que la marca de tiempo actual de Unix. Las frases desencadenantes incluyen "datos de mis afiliados", "comisión de esta semana", "ganancias de socios", "rendimiento del equipo", "volumen de operaciones de clientes", "ingresos por reembolsos", "solicitar afiliado".
