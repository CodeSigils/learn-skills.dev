Gate Exchange 제휴 프로그램 데이터 쿼리 및 관리 기술. 사용자가 제휴/파트너 수수료, 거래량, 순수수수료, 고객 수, 거래 사용자에 대해 질문하거나 제휴 프로그램을 신청하고 싶을 때 이 스킬을 사용하세요. 최대 180일 동안 쿼리를 지원합니다(API는 요청당 30일로 제한되며 에이전트는 더 긴 쿼리를 분할해야 함). 중요: API의 user_id 매개변수는 '커미션 수신자'가 아닌 '거래자'를 참조합니다. 명시적으로 지정하지 않는 한 사용하지 마세요. API 목록에서 집계된 데이터는 단순 합계가 아닌 사용자 정의 스크립트를 사용하여 계산해야 합니다. 중요한 시간 제약: 모든 쿼리 시간은 UTC+8 시간대의 사용자 시스템 현재 날짜를 기준으로 계산됩니다. 상대 시간 설명(예: '지난 7일', '지난 30일', '이번 주', '지난 달')의 경우 현재 날짜에서 일수를 빼서 시작 날짜를 계산한 다음 시작 날짜와 종료 날짜를 각각 UTC+8 00:00:00 및 23:59:59로 변환한 다음 Unix 타임스탬프로 변환합니다. 절대 미래 타임스탬프를 쿼리 조건으로 사용하지 마세요. 타임스탬프가 필요한 경우 시스템 기능을 통해 획득하고 수동으로 생성하지 마십시오. 'to' 매개변수는 항상 현재 Unix 타임스탬프보다 작거나 같아야 합니다. 트리거 문구에는 '나의 제휴 데이터', '이번 주 커미션', '파트너 수익', '팀 성과', '고객 거래량', '리베이트 수입', '제휴 신청'이 포함됩니다.
