Datenabfrage- und Verwaltungsfähigkeiten für das Gate Exchange-Partnerprogramm. Nutzen Sie diese Fähigkeit, wenn Benutzer nach ihrer Affiliate-/Partnerprovision, ihrem Handelsvolumen, den Nettogebühren, der Kundenzahl oder den Handelsbenutzern fragen oder sich für das Partnerprogramm bewerben möchten. Unterstützt Abfragen für bis zu 180 Tage (die API ist auf 30 Tage pro Anfrage begrenzt, der Agent sollte längere Abfragen aufteilen). WICHTIG: Der Parameter „user_id“ in APIs bezieht sich auf „Händler“, nicht auf „Provisionsempfänger“ – vermeiden Sie die Verwendung, sofern nicht ausdrücklich angegeben. Aggregierte Daten aus API-Listen sollten mithilfe benutzerdefinierter Skripts und nicht durch einfache Summierung berechnet werden. KRITISCHE ZEITBESCHRÄNKUNG: Alle Abfragezeiten werden basierend auf dem aktuellen Systemdatum des Benutzers in der Zeitzone UTC+8 berechnet. Berechnen Sie für relative Zeitbeschreibungen (z. B. „letzte 7 Tage“, „letzte 30 Tage“, „diese Woche“, „letzter Monat“) das Startdatum, indem Sie die Tage vom aktuellen Datum subtrahieren, konvertieren Sie dann sowohl das Start- als auch das Enddatum in UTC+8 00:00:00 bzw. 23:59:59 und konvertieren Sie es dann in Unix-Zeitstempel. Verwenden Sie NIEMALS zukünftige Zeitstempel als Abfragebedingungen. Wenn Zeitstempel benötigt werden, beziehen Sie diese über Systemfunktionen und generieren Sie sie niemals manuell. Der Parameter „to“ muss immer kleiner oder gleich dem aktuellen Unix-Zeitstempel sein. Zu den Triggerphrasen gehören „Meine Affiliate-Daten“, „Provision diese Woche“, „Partnereinnahmen“, „Teamleistung“, „Kundenhandelsvolumen“, „Rabatteinkommen“, „Affiliate beantragen“.
