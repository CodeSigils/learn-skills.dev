Capacità di query e gestione dei dati del programma di affiliazione di Gate Exchange. Utilizza questa abilità quando gli utenti chiedono informazioni sulla commissione di affiliazione/partner, sul volume degli scambi, sulle commissioni nette, sul conteggio dei clienti, sugli utenti che fanno trading o desiderano richiedere il programma di affiliazione. Supporta query fino a 180 giorni (API limitata a 30 giorni per richiesta, l'agente dovrebbe suddividere le query più lunghe). IMPORTANTE: il parametro user_id nelle API si riferisce a "commerciante" e non a "ricevitore di commissione": evita di utilizzarlo se non esplicitamente specificato. I dati aggregati provenienti dagli elenchi API devono essere calcolati utilizzando script personalizzati e non semplici somme. VINCITO DI TEMPO CRITICO: tutti i tempi di query vengono calcolati in base alla data corrente del sistema dell'utente nel fuso orario UTC+8. Per le descrizioni temporali relative (ad esempio, "ultimi 7 giorni", "ultimi 30 giorni", "questa settimana", "ultimo mese"), calcola la data di inizio sottraendo giorni dalla data corrente, quindi converti entrambe le date di inizio e di fine in UTC+8 rispettivamente 00:00:00 e 23:59:59, quindi converti in timestamp Unix. Non utilizzare MAI timestamp futuri come condizioni di query. Quando sono necessari i timestamp, ottenerli tramite le funzioni di sistema, non generarli mai manualmente. Il parametro "a" deve essere sempre inferiore o uguale al timestamp Unix corrente. Le frasi trigger includono "dati del mio affiliato", "commissioni questa settimana", "guadagni del partner", "prestazioni del team", "volume degli scambi dei clienti", "reddito dello sconto", "richiedi l'affiliazione".
