Verwandelt einen überwältigenden WhatsApp-Rückstand in ein einseitiges tägliches Aktionsboard mit einem bearbeitbaren Antwortentwurf für jede Konversation, die der Benutzer heute tatsächlich benötigt. Alles bleibt auf ihrem Rechner und nichts wird jemals automatisch gesendet. Verwenden Sie diese Option, wenn der Benutzer möchte, dass seine WhatsApp gesichtet wird („Sortierung meiner WhatsApp“, „Hilf mir, WhatsApp zu löschen“ oder sich über Hunderte von ungelesenen Chats beschwert), der einmalige Export eingerichtet werden soll („WhatsApp-Export einrichten“), später am selben Tag um ein Update bittet oder ein auf einem veralteten Export basierendes Board aktualisieren möchte, darum bittet, weiter zurück zu blicken oder eine ältere Konversation einzubeziehen („eine Woche zurückgehen“, „Zeige mir den letzten Monat“), möchte, dass die Entwürfe so klingen („Mein Tonprofil einrichten“), „Mein Tonprofil aktualisieren“), stößt auf einen Lauf, der fehlgeschlagen ist und diagnostiziert werden muss, oder fragt, warum sich das Board so verhält, wie es sich verhält (warum eine Zeile kopiert statt geöffnet wird, wohin ein Gespräch oder eine Sprachnotiz ging). Das Lesefenster bleibt standardmäßig schmal und wird nur auf ausdrücklichen Wunsch des Benutzers erweitert.
