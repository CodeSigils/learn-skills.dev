Moteur de planification de contenu : étant donné un objectif commercial, il génère un plan de contenu complet ; les humains n’examinent qu’une seule feuille de graines tandis que le reste est dérivé mécaniquement. Il couvre FB, IG, de courtes vidéos (TikTok/Reels) et Xiaohongshu, destinés aux propriétaires de petites entreprises sino-malaisiennes. Cinq points d'entrée : planifier un lot de contenu ("Aidez-moi à planifier le contenu de ce mois-ci", "Combien d'éléments ce lot doit-il contenir", "Que dois-je publier", "planifier mon contenu") ; diagnostiquer d'abord sans planifier (« Pourquoi mon contenu n'obtient-il aucune vue » ); collecter les mots exacts des clients dans une bibliothèque de matériaux (« J'ai capturé quelques citations de clients », « Le client a dit quelque chose ») ; enregistrer les performances (« Enregistrer les résultats », « Données pour cet article ») ; bilan (« Faire un bilan », « Comment se sont passées les dernières semaines »). PAS pour : la rédaction unique (qui ne nécessite pas l'ensemble du pipeline, il suffit de l'écrire) ; tests de création publicitaire payants (ce moteur ne gère que le organique, la logique d'allocation est complètement différente) ; la stratégie de marque elle-même (ce moteur consomme les résultats de la stratégie de marque, il ne produit pas de stratégie de marque).
