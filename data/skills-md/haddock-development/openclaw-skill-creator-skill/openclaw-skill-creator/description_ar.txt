قم بإنشاء مهارات متوافقة مع OpenClaw باستخدام البيانات التعريفية والبنية والتعبئة المناسبة. استخدمها عند بناء المهارات لعملاء OpenClaw، بما في ذلك: (1) تهيئة مهارات OpenClaw الجديدة، (2) إضافة بيانات تعريف openclaw (الرموز التعبيرية، المطلوبة، التثبيت)، (3) مهارات التعبئة والتغليف كملفات .skill ZIP، (4) تحويل مهارات Claude Code إلى تنسيق OpenClaw.
