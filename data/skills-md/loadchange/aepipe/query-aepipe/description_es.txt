Interactúe con la API de aepipe Analytics Engine: consulte registros, ingiera eventos, enumere proyectos/almacenes de registros y procese resultados de consultas con Python. Utilice esta habilidad siempre que el usuario mencione aepipe, registros del motor de análisis, consulta de registros, ingesta de eventos, administración del almacén de registros o desee analizar/exportar/visualizar datos desde su instancia de aepipe. También se activa cuando el usuario desea configurar la configuración de aepipe, verificar la conectividad de aepipe o trabajar con datos de eventos estructurados almacenados en Cloudflare Analytics Engine.
