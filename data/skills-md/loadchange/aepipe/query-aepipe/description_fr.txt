Interagissez avec l'API aepipe Analytics Engine : journaux de requêtes, assimilation d'événements, liste de projets/magasins de journaux et traitement des résultats de requêtes avec Python. Utilisez cette compétence chaque fois que l'utilisateur mentionne aepipe, les journaux du moteur d'analyse, les requêtes de journaux, l'ingestion d'événements, la gestion du magasin de journaux ou souhaite analyser/exporter/visualiser les données de son instance aepipe. Se déclenche également lorsque l'utilisateur souhaite configurer la configuration aepipe, vérifier la connectivité aepipe ou travailler avec des données d'événements structurées stockées dans Cloudflare Analytics Engine.
