Interagisci con l'API di aepipe Analytics Engine: esegui query su log, acquisisci eventi, elenca progetti/archivi log ed elabora i risultati delle query con Python. Utilizza questa competenza ogni volta che l'utente menziona aepipe, log del motore di analisi, query di log, inserimento di eventi, gestione dell'archivio log o desidera analizzare/esportare/visualizzare dati dalla propria istanza di aepipe. Si attiva anche quando l'utente desidera impostare la configurazione di aepipe, controllare la connettività di aepipe o lavorare con dati di eventi strutturati archiviati in Cloudflare Analytics Engine.
