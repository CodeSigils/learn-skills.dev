Взаимодействуйте с API-интерфейсом aepipe Analytics Engine — запрашивайте журналы, получайте события, получайте списки проектов/хранилищ журналов и обрабатывайте результаты запросов с помощью Python. Используйте этот навык всякий раз, когда пользователь упоминает aepipe, журналы аналитической системы, запросы журналов, прием событий, управление хранилищем журналов или хочет проанализировать/экспортировать/визуализировать данные из своего экземпляра aepipe. Также срабатывает, когда пользователь хочет настроить конфигурацию aepipe, проверить подключение aepipe или поработать со структурированными данными событий, хранящимися в Cloudflare Analytics Engine.
