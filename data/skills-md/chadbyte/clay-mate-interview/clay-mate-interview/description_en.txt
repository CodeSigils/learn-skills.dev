Deep interview skill for shaping a Clay Mate's identity through conversation. This skill runs automatically when a new Mate is created through the creation wizard, or when a user wants to reshape an existing Mate. The Mate itself conducts the interview, asking questions to understand the user and building its own CLAUDE.md identity file. Use this skill whenever a Mate DM session starts for the first time, when the user says things like "let's redo your personality", "I want to change how you work", "reshape", "re-interview", or "start over". Also triggers on /mate-interview or when Clay's Mate creation flow injects seed data into a new DM session.
