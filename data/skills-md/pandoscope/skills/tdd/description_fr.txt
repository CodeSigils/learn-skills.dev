Développement piloté par les tests via red-green-refactor avec un protocole de validation vérifiable. À utiliser lors de l'implémentation d'une fonctionnalité, d'une correction de bug, d'un refactor ou d'un changement de comportement avant d'écrire le code d'implémentation, ou lorsque l'utilisateur mentionne TDD, red-green-refactor ou test-first development.
