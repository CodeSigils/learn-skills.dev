Ejecute la búsqueda de código semántico de Locus autenticado desde el tiempo de ejecución incluido de esta habilidad, sin necesidad de un servidor MCP. Úselo automáticamente para el descubrimiento de código cuando un archivo, símbolo, implementación, subsistema, flujo de llamadas, ruta de dependencia o comportamiento entre paquetes sea desconocido o deba encontrarse por significado. Úselo también para la configuración de autenticación de Locus, el estado del índice y la actualización. No lo use para un archivo o símbolo exacto ya conocido, ni para trabajos puros de git, compilación, prueba y formateo.
