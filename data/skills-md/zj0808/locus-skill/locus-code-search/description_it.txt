Esegui la ricerca del codice semantico Locus autenticato dal runtime in bundle di questa abilità, senza richiedere un server MCP. Utilizzalo automaticamente per il rilevamento del codice quando un file, un simbolo, un'implementazione, un sottosistema, un flusso chiamante, un percorso di dipendenza o un comportamento tra pacchetti è sconosciuto o deve essere trovato in base al significato. Utilizzare anche per la configurazione dell'autenticazione Locus, lo stato dell'indice e l'aggiornamento. Non utilizzare per un file o un simbolo esatto già noto o per lavori git, build, test e formattazione puri.
