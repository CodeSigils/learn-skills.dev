Exécutez une recherche de code sémantique Locus authentifié à partir du runtime fourni avec cette compétence, sans nécessiter de serveur MCP. À utiliser automatiquement pour la découverte de code lorsqu'un fichier, un symbole, une implémentation, un sous-système, un flux d'appelants, un chemin de dépendance ou un comportement entre packages est inconnu ou doit être trouvé par sa signification. À utiliser également pour la configuration de l'authentification Locus, l'état de l'index et l'actualisation. Ne pas utiliser pour un fichier ou un symbole exact déjà connu, ni pour des travaux purs de git, de construction, de test et de formatage.
