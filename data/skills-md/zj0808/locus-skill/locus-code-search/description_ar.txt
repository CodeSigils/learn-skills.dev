قم بتشغيل بحث الكود الدلالي Locus المعتمد من وقت التشغيل المجمع لهذه المهارة، دون الحاجة إلى خادم MCP. يُستخدم تلقائيًا لاكتشاف التعليمات البرمجية عندما يكون الملف أو الرمز أو التنفيذ أو النظام الفرعي أو تدفق المتصل أو مسار التبعية أو السلوك عبر الحزمة غير معروف أو يجب العثور عليه بالمعنى. استخدمه أيضًا لإعداد مصادقة الموقع وحالة الفهرس والتحديث. لا تستخدمه مع ملف أو رمز محدد معروف بالفعل، أو في أعمال git والبناء والاختبار والتنسيق.
