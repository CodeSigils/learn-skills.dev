Patrones y convenciones avanzados de React para recuperación de datos, tablas, formularios, máquinas de estado, gestión del estado del cliente, validación de esquemas y pruebas. Úselo cuando aborde problemas complejos de React: no preguntas simples sobre componentes, sino tareas de múltiples preocupaciones, como tablas controladas por servidor con filtrado, asistentes de varios pasos, eliminación de useEffect, arquitectura Suspense, elección entre enfoques de administración de estado o diseño de flujo de datos a través del servidor/cliente/URL/estado del formulario. No lo utilice para enrutamiento/SSR específico de la web o navegación/rendimiento específico de React Native.
