أنماط واصطلاحات React المتقدمة لجلب البيانات والجداول والنماذج وأجهزة الحالة وإدارة حالة العميل والتحقق من صحة المخطط والاختبار. يُستخدم عند معالجة مشكلات React المعقدة - ليست أسئلة المكونات البسيطة، ولكن المهام متعددة الاهتمامات مثل الجداول التي يحركها الخادم مع التصفية، أو المعالجات متعددة الخطوات، أو إزالة useEffect، أو بنية Suspense، أو الاختيار بين أساليب إدارة الحالة، أو تصميم تدفق البيانات عبر حالة الخادم/العميل/URL/النموذج. لا تستخدم للتوجيه/SSR الخاص بالويب أو التنقل/الأداء الخاص بـ React Native.
