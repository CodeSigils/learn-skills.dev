Modelli e convenzioni avanzati di React per il recupero dei dati, tabelle, moduli, macchine a stati, gestione dello stato del client, convalida dello schema e test. Da utilizzare quando si affrontano problemi complessi di React: non semplici domande sui componenti, ma attività multi-problema come tabelle guidate dal server con filtri, procedure guidate in più passaggi, eliminazione di useEffect, architettura Suspense, scelta tra approcci di gestione dello stato o progettazione del flusso di dati attraverso lo stato server/client/URL/modulo. Non utilizzare per routing/SSR specifici del Web o navigazione/prestazioni specifiche di React Native.
