Modèles et conventions React avancés pour la récupération de données, les tables, les formulaires, les machines à états, la gestion de l'état des clients, la validation des schémas et les tests. À utiliser pour résoudre des problèmes React complexes : pas de simples questions de composants, mais des tâches multi-préoccupations telles que des tables pilotées par serveur avec filtrage, des assistants en plusieurs étapes, l'élimination de useEffect, l'architecture Suspense, le choix entre des approches de gestion d'état ou la conception de flux de données à travers l'état du serveur/client/URL/formulaire. Ne pas utiliser pour le routage/SSR spécifique au Web ou la navigation/performance spécifique à React Native.
