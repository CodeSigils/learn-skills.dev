Расширенные шаблоны и соглашения React для выборки данных, таблиц, форм, конечных автоматов, управления состоянием клиента, проверки схемы и тестирования. Используйте при решении сложных проблем React — не простых вопросов о компонентах, а комплексных задач, таких как управляемые сервером таблицы с фильтрацией, многошаговые мастера, устранение useEffect, архитектура приостановки, выбор между подходами к управлению состоянием или проектирование потока данных между состоянием сервера/клиента/URL/формы. Не используйте для веб-маршрутизации/SSR или навигации/производительности, специфичной для React Native.
