データのフェッチ、テーブル、フォーム、ステート マシン、クライアント状態管理、スキーマ検証、テストのための高度な React パターンと規則。 React の複雑な問題に取り組むときに使用します。単純なコンポーネントの問題ではなく、フィルタリングを備えたサーバー駆動テーブル、複数ステップのウィザード、useEffect の排除、サスペンス アーキテクチャ、状態管理アプローチの選択、サーバー/クライアント/URL/フォーム状態にわたるデータ フローの設計などの複数の関心事のタスクに対応します。 Web 固有のルーティング/SSR または React Native 固有のナビゲーション/パフォーマンスには使用しないでください。
