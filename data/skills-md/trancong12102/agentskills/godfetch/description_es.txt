Habilidad de investigación externa unificada para documentación, código GitHub y versiones de paquetes. Úselo cuando el usuario necesite buscar documentos de biblioteca o referencias de API, buscar código en un repositorio público de GitHub, verificar la última versión de un paquete o verificar si una dependencia está obsoleta. Se activan frases como "buscar los documentos de X", "cómo funciona X internamente", "qué versión de X debo usar", "X está obsoleto" o cualquier tarea que requiera conocimiento externo más allá del código base local y los datos de entrenamiento.
