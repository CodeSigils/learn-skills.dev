مهارة بحث خارجية موحدة للتوثيق وكود GitHub وإصدارات الحزمة. يُستخدم عندما يحتاج المستخدم إلى البحث عن مستندات المكتبة أو مراجع واجهة برمجة التطبيقات (API)، أو البحث عن التعليمات البرمجية في مستودع GitHub العام، أو التحقق من أحدث إصدار من الحزمة، أو التحقق مما إذا تم إهمال التبعية. يتم تشغيل عبارات مثل "البحث عن المستندات لـ X"، أو "كيف يعمل X داخليًا"، أو "ما هو إصدار X الذي يجب أن أستخدمه"، أو "تم إهمال X"، أو أي مهمة تتطلب معرفة خارجية تتجاوز قاعدة التعليمات البرمجية المحلية وبيانات التدريب.
