Compétence de recherche externe unifiée pour la documentation, le code GitHub et les versions de packages. À utiliser lorsque l'utilisateur a besoin de rechercher des documents de bibliothèque ou des références d'API, de rechercher du code dans un dépôt GitHub public, de vérifier la dernière version d'un package ou de vérifier si une dépendance est obsolète. Se déclenche sur des expressions telles que « rechercher la documentation de X », « comment X fonctionne-t-il en interne », « quelle version de X dois-je utiliser », « X est-il obsolète » ou toute tâche nécessitant des connaissances externes au-delà de la base de code locale et des données de formation.
