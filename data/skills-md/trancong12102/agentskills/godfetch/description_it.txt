Capacità di ricerca esterna unificata per documentazione, codice GitHub e versioni dei pacchetti. Da utilizzare quando l'utente deve cercare documenti di libreria o riferimenti API, cercare codice in un repository GitHub pubblico, controllare la versione più recente di un pacchetto o verificare se una dipendenza è deprecata. Si attivano frasi come "cerca la documentazione di X", "come funziona X internamente", "quale versione di X dovrei usare", "X è deprecato" o qualsiasi attività che richiede conoscenza esterna oltre la base di codice locale e i dati di addestramento.
