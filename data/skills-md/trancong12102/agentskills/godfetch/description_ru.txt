Унифицированные навыки внешнего исследования документации, кода GitHub и версий пакетов. Используйте, когда пользователю нужно найти документацию библиотеки или ссылки на API, выполнить поиск кода в общедоступном репозитории GitHub, проверить последнюю версию пакета или проверить, устарела ли зависимость. Запускается по таким фразам, как «поищите документацию по X», «как X работает внутри», «какую версию X мне следует использовать», «является ли X устаревшим» или по любой задаче, требующей внешних знаний, выходящих за рамки локальной базы кода и данных обучения.
