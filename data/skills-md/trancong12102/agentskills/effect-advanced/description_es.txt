Patrones avanzados de Effect-TS para errores escritos, inyección de dependencia, concurrencia, gestión de recursos, validación de esquemas y transmisión. Úselo al crear programas de Effect: no simples preguntas de Effect.succeed/fail, sino tareas de múltiples preocupaciones, como diseñar capas de servicios con composición de capas, manejar jerarquías de errores escritos con errores etiquetados, administrar fibras concurrentes con simultaneidad estructurada, ciclos de vida de recursos con alcance, contratos de API basados ​​en esquemas o integrar Effect con pilas Express/Hono/base de datos existentes. No lo utilice para TypeScript básico o preguntas de programación funcional general.
