Esamina le differenze TypeScript/JavaScript per le utilità reinventate e il mancato riutilizzo di librerie standard, API native o helper dell'area di lavoro esistenti. Da utilizzare durante la revisione delle modifiche al codice TS/JS, il controllo di una differenza, il controllo di un PR prima dell'unione, la scrittura di nuovi helper di utilità o il refactoring degli helper esistenti. Rileva le librerie di progetto installate e preferisce quelle quando presenti. Riporta i risultati solo come testo: non modifica mai i file. Non utilizzare per codice non JS/TS, documentazione, configurazione o modifiche banali a riga singola.
