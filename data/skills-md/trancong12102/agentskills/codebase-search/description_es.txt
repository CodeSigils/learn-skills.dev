Búsqueda de base de código semántica: utilícela como primer paso al explorar o escanear una base de código de manera amplia. Entiende la intención del código y rastrea los flujos entre archivos. Úselo cuando el usuario necesite comprender cómo funciona el código, rastrear flujos de datos, explorar bases de código desconocidas o responder preguntas conceptuales ("cómo funciona X", "dónde está configurado Y", "rastrear el flujo de Z"). NO lo use para búsquedas específicas de palabras clave/símbolos (use Grep) o búsquedas de archivos (use Glob).
