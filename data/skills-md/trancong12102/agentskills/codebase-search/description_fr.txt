Recherche sémantique de la base de code : à utiliser comme première étape lors de l'exploration ou de l'analyse globale d'une base de code. Comprend l’intention du code et trace les flux entre fichiers. À utiliser lorsque l'utilisateur a besoin de comprendre le fonctionnement du code, de suivre les flux de données, d'explorer des bases de code inconnues ou de répondre à des questions conceptuelles (« comment fonctionne X », « où Y est-il configuré », « tracer le flux de Z »). Ne PAS utiliser pour des recherches ciblées de mots clés/symboles (utilisez Grep) ou des recherches de fichiers (utilisez Glob).
