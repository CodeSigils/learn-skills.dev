Recherche sémantique de dépôts GitHub publics sans clonage. À utiliser lorsque l'utilisateur souhaite comprendre le fonctionnement interne d'une bibliothèque ou d'un framework externe, enquêter sur des bogues en amont, tracer les chemins de code dans un dépôt qu'il n'a pas cloné ou rechercher intentionnellement le code source de GitHub. Ne PAS utiliser pour les questions de base de code locale (utilisez codebase-search), la recherche de documentation (utilisez context7) ou les dépôts privés.
