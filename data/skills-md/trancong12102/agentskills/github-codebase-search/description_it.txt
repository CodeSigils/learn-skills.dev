Ricerca semantica di repository GitHub pubblici senza clonazione. Da utilizzare quando l'utente desidera comprendere come funziona internamente una libreria o un framework esterno, indagare sui bug upstream, tracciare i percorsi del codice in un repository che non ha clonato o cercare il codice sorgente GitHub in base all'intento. NON utilizzare per domande sulla codebase locale (utilizzare codebase-search), ricerca di documentazione (utilizzare context7) o repository privati.
