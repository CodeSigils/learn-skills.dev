Семантический поиск общедоступных репозиториев GitHub без клонирования. Используйте, когда пользователь хочет понять, как внешняя библиотека или платформа работает внутри, исследовать ошибки исходного кода, отслеживать пути кода в репозитории, который он не клонировал, или выполнить поиск исходного кода GitHub по намерению. НЕ используйте для вопросов по локальной базе кода (используйте поиск по кодовой базе), поиска документации (используйте context7) или частных репозиториев.
