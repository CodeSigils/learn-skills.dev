Búsqueda semántica de repositorios públicos de GitHub sin clonación. Úselo cuando el usuario quiera comprender cómo funciona internamente una biblioteca o marco externo, investigar errores ascendentes, rastrear rutas de código en un repositorio que no han clonado o buscar código fuente de GitHub por intención. NO lo use para preguntas sobre la base de código local (use la búsqueda de base de código), búsqueda de documentación (use context7) o repositorios privados.
