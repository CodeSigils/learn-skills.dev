Semantische Suche nach öffentlichen GitHub-Repos ohne Klonen. Verwenden Sie diese Option, wenn der Benutzer verstehen möchte, wie eine externe Bibliothek oder ein Framework intern funktioniert, Upstream-Fehler untersuchen, Codepfade in einem nicht geklonten Repo verfolgen oder GitHub-Quellcode absichtlich durchsuchen möchte. NICHT für Fragen zur lokalen Codebasis (verwenden Sie codebase-search), zur Dokumentationssuche (verwenden Sie context7) oder für private Repos verwenden.
