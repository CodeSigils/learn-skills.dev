Расширенная система типов Master TypeScript, включающая обобщенные типы, условные типы, отображаемые типы, литералы шаблонов и служебные типы для создания типобезопасных приложений. Используйте при реализации сложной логики типов, создании утилит многократного использования типов или обеспечении безопасности типов за пределами базовых аннотаций — распознаваемые объединения с исчерпывающими проверками, фирменные/непрозрачные типы для безопасности домена, решения «удовлетворительно» или «как константа», NoInfer для управления выводом, расширение модулей для сторонних типов или выбор между ручными типами и утилитами проверки типов. Не используйте для базового синтаксиса TypeScript или простых аннотаций типов.
