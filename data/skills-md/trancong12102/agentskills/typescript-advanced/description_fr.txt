Maîtrisez le système de types avancé de TypeScript, comprenant les génériques, les types conditionnels, les types mappés, les littéraux de modèles et les types utilitaires pour créer des applications sécurisées. À utiliser lors de la mise en œuvre d'une logique de type complexe, de la création d'utilitaires de type réutilisables ou de l'application de la sécurité des types au-delà des annotations de base : unions discriminées avec des contrôles exhaustifs, types marqués/opaques pour la sécurité du domaine, décisions satisfaites ou const, NoInfer pour le contrôle d'inférence, augmentation de module pour les types tiers ou choix entre les types générés manuellement et les utilitaires de type-fest. Ne pas utiliser pour la syntaxe TypeScript de base ou les annotations de type simples.
