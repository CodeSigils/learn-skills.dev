Расширенные шаблоны Rust для владения, свойств, асинхронности, обработки ошибок, макросов, трюков с системой типов, небезопасности и производительности. Используйте при решении сложных проблем Rust — не базового синтаксиса, а многозадачных задач, таких как разработка безопасных для отмены асинхронных сервисов, выбор между типажными объектами и дженериками, создание типизированных API, структурирование иерархий ошибок по границам ящиков, написание макросов процедур или оптимизация горячих путей с абстракциями с нулевой стоимостью. Не используйте для базового синтаксиса Rust, простых инструментов CLI или вопросов о владении новичками.
