Patrones avanzados de Rust para propiedad, rasgos, asíncrono, manejo de errores, macros, trucos del sistema de tipos, inseguridad y rendimiento. Úselo cuando aborde problemas complejos de Rust: no sintaxis básica, sino tareas de múltiples preocupaciones, como diseñar servicios asíncronos seguros para cancelaciones, elegir entre objetos de rasgos y genéricos, crear API escritas, estructurar jerarquías de errores a través de los límites de las cajas, escribir macros de proceso u optimizar rutas activas con abstracciones de costo cero. No lo utilice para la sintaxis básica de Rust, herramientas CLI simples o preguntas de propiedad para principiantes.
