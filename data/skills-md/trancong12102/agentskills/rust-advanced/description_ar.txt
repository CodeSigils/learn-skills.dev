أنماط الصدأ المتقدمة للملكية والسمات وعدم المزامنة ومعالجة الأخطاء ووحدات الماكرو ونوع حيل النظام وغير الآمن والأداء. يُستخدم عند معالجة مشكلات Rust المعقدة - ليس بناء الجملة الأساسي، ولكن المهام متعددة الاهتمامات مثل تصميم خدمات غير متزامنة آمنة للإلغاء، أو الاختيار بين كائنات السمات والأسماء العامة، أو إنشاء واجهات برمجة التطبيقات المكتوبة، أو هيكلة تسلسلات هرمية للأخطاء عبر حدود الصناديق، أو كتابة وحدات ماكرو proc، أو تحسين المسارات الفعالة بتجريدات بدون تكلفة. لا تستخدمه في بناء جملة Rust الأساسي، أو أدوات CLI البسيطة، أو أسئلة الملكية للمبتدئين.
