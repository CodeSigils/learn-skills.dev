أنماط React Native وExpo للتنقل، ودورة حياة جلب البيانات، وقوائم التمرير اللانهائية، ومعالجة النماذج، واستمرارية الحالة، وتوجيه المصادقة، والرسوم المتحركة التي تعتمد على الإيماءات، والأوراق السفلية، وإشعارات الدفع، وتحديثات OTA. يُستخدم عند إنشاء تطبيقات Expo/React Native التي تحتاج إلى جلب مسبق للبيانات على مستوى الشاشة، أو حراس مصادقة بمسارات محمية، أو خلاصات تمرير لا نهائية، أو معالجة إدخال النموذج الأصلي، أو استمرارية الحالة غير المتصلة بالإنترنت، أو الإعداد الخاص بالنظام الأساسي (مديري التركيز/الإنترنت)، أو الرسوم المتحركة المرنة وتفاعلات الإيماءات، أو الأوراق السفلية المشروطة، أو تدفقات إشعارات الدفع، أو إستراتيجيات التحديث عبر الهواء. لا تستخدم لتطبيقات الويب React.
