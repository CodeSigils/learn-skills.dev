Patrones React Native y Expo para navegación, ciclo de vida de recuperación de datos, listas de desplazamiento infinito, manejo de formularios, persistencia de estado, enrutamiento de autenticación, animaciones basadas en gestos, hojas inferiores, notificaciones automáticas y actualizaciones OTA. Úselo al crear aplicaciones Expo/React Native que necesitan captura previa de datos a nivel de pantalla, protecciones de autenticación con rutas protegidas, feeds de desplazamiento infinito, manejo de entrada de formulario nativo, persistencia de estado con capacidad fuera de línea, configuración específica de la plataforma (administradores de enfoque/en línea), animaciones fluidas e interacciones de gestos, hojas inferiores modales, flujos de notificaciones push o estrategias de actualización inalámbrica. No lo use para aplicaciones web React.
