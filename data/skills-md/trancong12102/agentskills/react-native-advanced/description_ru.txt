Шаблоны React Native и Expo для навигации, жизненного цикла выборки данных, списков бесконечной прокрутки, обработки форм, сохранения состояния, маршрутизации аутентификации, анимации на основе жестов, нижних листов, push-уведомлений и OTA-обновлений. Используйте при создании приложений Expo/React Native, которым требуется предварительная выборка данных на уровне экрана, защита аутентификации с защищенными маршрутами, бесконечные каналы прокрутки, собственная обработка ввода формы, сохранение состояния в автономном режиме, настройка для конкретной платформы (менеджеры фокуса/онлайн), плавная анимация и взаимодействие жестов, модальные нижние листы, потоки push-уведомлений или стратегии беспроводного обновления. Не используйте для веб-приложений React.
