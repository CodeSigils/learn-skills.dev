Webspezifische Reaktionsmuster für typsicheres dateibasiertes Routing, Laden von Daten auf Routenebene, serverseitiges Rendering, Suchparametervalidierung, Codeaufteilung und Listenvirtualisierung. Verwenden Sie diese Option, wenn Sie React-Webanwendungen mit Routenladern, SSR-Streaming, validierten Suchparametern, verzögerter Routenaufteilung oder der Virtualisierung großer DOM-Listen erstellen. Nicht für React Native-Apps verwenden – verwenden Sie stattdessen „react-native-advanced“.
