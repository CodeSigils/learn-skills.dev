Шаблоны React, специфичные для Интернета, для безопасной по типам маршрутизации на основе файлов, загрузки данных на уровне маршрута, рендеринга на стороне сервера, проверки параметров поиска, разделения кода и виртуализации списков. Используйте при создании веб-приложений React с загрузчиками маршрутов, потоковой передачей SSR, проверенными параметрами поиска, отложенным разделением маршрутов или виртуализацией больших списков DOM. Не используйте для приложений React Native — вместо этого используйте React-native-advanced.
