Modèles React spécifiques au Web pour le routage basé sur des fichiers de type sécurisé, le chargement de données au niveau de l'itinéraire, le rendu côté serveur, la validation des paramètres de recherche, le fractionnement du code et la virtualisation des listes. À utiliser lors de la création d'applications Web React avec des chargeurs de route, du streaming SSR, des paramètres de recherche validés, du fractionnement paresseux de routes ou de la virtualisation de grandes listes DOM. Ne pas utiliser pour les applications React Native – utilisez plutôt React-Native-Advanced.
