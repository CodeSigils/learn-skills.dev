أنماط React الخاصة بالويب للتوجيه الآمن المعتمد على الملفات، وتحميل البيانات على مستوى المسار، والعرض من جانب الخادم، والتحقق من صحة معلمات البحث، وتقسيم التعليمات البرمجية، والمحاكاة الافتراضية للقائمة. يُستخدم عند إنشاء تطبيقات ويب React باستخدام أدوات تحميل المسار، أو تدفق SSR، أو معلمات البحث التي تم التحقق من صحتها، أو تقسيم المسار البطيء، أو إضفاء الطابع الافتراضي على قوائم DOM الكبيرة. لا تستخدمه مع تطبيقات React Native — استخدم رد الفعل الأصلي المتقدم بدلاً من ذلك.
