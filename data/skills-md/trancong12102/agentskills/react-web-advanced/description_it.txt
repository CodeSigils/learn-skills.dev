Modelli React specifici per il Web per routing basato su file indipendente dal tipo, caricamento di dati a livello di percorso, rendering lato server, convalida dei parametri di ricerca, suddivisione del codice e virtualizzazione degli elenchi. Da utilizzare durante la creazione di app Web React con caricatori di percorsi, streaming SSR, parametri di ricerca convalidati, suddivisione lenta del percorso o virtualizzazione di elenchi DOM di grandi dimensioni. Non utilizzare per le app React Native: utilizza invece react-native-advanced.
