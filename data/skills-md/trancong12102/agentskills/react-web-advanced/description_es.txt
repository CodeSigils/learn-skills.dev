Patrones de React específicos de la web para enrutamiento basado en archivos con seguridad de tipos, carga de datos a nivel de ruta, representación del lado del servidor, validación de parámetros de búsqueda, división de código y virtualización de listas. Úselo al crear aplicaciones web React con cargadores de rutas, transmisión SSR, parámetros de búsqueda validados, división diferida de rutas o virtualización de listas DOM grandes. No lo use para aplicaciones React Native; en su lugar, use react-native-advanced.
