Text-to-image tool – Generate images using Alibaba Cloud DashScope API. Supports Qwen-Image and Wan series models.

**Always trigger this Skill when:**
- User says “generate an image,” “draw for me,” “text-to-image,” “use AI to draw”
- User mentions AI painting, image generation, text-to-picture
- User describes a scene and wants to see the corresponding image
- User uses the /tgi command
- User needs to create any type of image (avatar, landscape, illustration, realistic photo, etc.)

**Supported models:**
- Qwen series: qwen-image-2.0-pro, qwen-image-2.0-max, qwen-image-2.0, qwen-image-max, qwen-image-plus
- Wan series: wan2.7-image-pro, wan2.7-image, wan2.6-image, wan2.6-t2i, wan2.5-t2i-preview
