텍스트-이미지 도구 – Alibaba Cloud DashScope API를 사용하여 이미지를 생성합니다. Qwen-Image 및 Wan 시리즈 모델을 지원합니다.

**이 스킬을 적극적으로 발동해야 하는 시나리오:**
- 사용자가 "이미지 생성", "나를 위해 그리기", "텍스트를 이미지로 변환" 또는 "AI로 그리기"라고 말합니다.
- 사용자가 AI 그리기, 이미지 생성 또는 텍스트-이미지 변환을 언급합니다.
- 사용자가 장면을 설명하고 해당 이미지를 보고 싶어함
- 사용자가 /tgi 명령을 사용합니다.
- 사용자는 모든 종류의 그림(아바타, 풍경, 일러스트레이션, 사실적인 사진 등)을 만들어야 합니다.

**지원되는 모델:**
- Qwen 시리즈: qwen-image-2.0-pro, qwen-image-2.0-max, qwen-image-2.0, qwen-image-max, qwen-image-plus
- Wan 시리즈: wan2.7-image-pro, wan2.7-image, wan2.6-image, wan2.6-t2i, wan2.5-t2i-preview
