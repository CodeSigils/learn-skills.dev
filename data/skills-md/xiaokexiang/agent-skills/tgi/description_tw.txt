文字轉圖像工具 – 使用阿里雲 DashScope API 產生圖像。支援 Qwen-Image 和 Wan 模型系列。

**在以下情況下始終啟動此技能：**
- 使用者說“生成圖像”、“為我畫畫”、“文字到圖像”或“用 AI 畫畫”
- 使用者提到人工智慧繪圖、圖像生成或文字轉圖片
- 使用者描述一個場景並希望看到相應的圖像
- 使用者呼叫/tgi指令
- 使用者需要創建任何類型的圖像（頭像、風景、插圖、寫實照片等）

**支援的型號：**
- Qwen系列：qwen-image-2.0-pro、qwen-image-2.0-max、qwen-image-2.0、qwen-image-max、qwen-image-plus
- wan系列：wan2.7-image-pro、wan2.7-image、wan2.6-image、wan2.6-t2i、wan2.5-t2i-preview
