文本转图像工具 – 使用阿里云 DashScope API 生成图像。支持 Qwen-Image 和 Wan 模型系列。

**在以下情况下始终激活此技能：**
- 用户说“生成图像”、“为我画画”、“文本到图像”或“用 AI 画画”
- 用户提到人工智能绘图、图像生成或文本转图片
- 用户描述一个场景并希望看到相应的图像
- 用户调用/tgi命令
- 用户需要创建任何类型的图像（头像、风景、插图、写实照片等）

**支持的型号：**
- Qwen系列：qwen-image-2.0-pro、qwen-image-2.0-max、qwen-image-2.0、qwen-image-max、qwen-image-plus
- wan系列：wan2.7-image-pro、wan2.7-image、wan2.6-image、wan2.6-t2i、wan2.5-t2i-preview
