Инструмент преобразования текста в изображение. Создавайте изображения с помощью API Alibaba Cloud DashScope. Поддерживает модели серий Qwen-Image и Wan.

**Всегда активируйте этот навык, когда:**
- Пользователь говорит «создать изображение», «нарисовать для меня», «преобразовать текст в изображение», «использовать ИИ для рисования».
- Пользователь упоминает рисование с помощью ИИ, генерацию изображений, преобразование текста в изображение.
- Пользователь описывает сцену и хочет увидеть соответствующее изображение
- Пользователь использует команду /tgi
- Пользователю необходимо создать изображение любого типа (аватар, пейзаж, иллюстрация, реалистичное фото и т. д.)

**Поддерживаемые модели:**
- Серия Qwen: qwen-image-2.0-pro, qwen-image-2.0-max, qwen-image-2.0, qwen-image-max, qwen-image-plus
- Серия WAN: wan2.7-image-pro, wan2.7-image, wan2.6-image, wan2.6-t2i, wan2.5-t2i-preview
