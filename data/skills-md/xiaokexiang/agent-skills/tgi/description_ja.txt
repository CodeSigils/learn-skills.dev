Text-to-Image ツール – Alibaba Cloud DashScope API を使用して画像を生成します。 Qwen-Image および Wan シリーズ モデルをサポートします。

**このスキルを積極的に発動しなければならない場面:**
- ユーザーが「画像を生成」、「描いて」、「テキストから画像へ」、または「AI で描いて」と言った
- ユーザーが AI ペインティング、画像生成、またはテキストから画像への変換について言及
- ユーザーはシーンを説明し、対応する画像を見たいと考えています
- ユーザーが /tgi コマンドを使用する
- ユーザーはあらゆる種類の画像 (アバター、風景、イラスト、写実的な写真など) を作成する必要があります。

**サポートされているモデル:**
- Qwen シリーズ: qwen-image-2.0-pro、qwen-image-2.0-max、qwen-image-2.0、qwen-image-max、qwen-image-plus
- WAN シリーズ: wan2.7-image-pro、wan2.7-image、wan2.6-image、wan2.6-t2i、wan2.5-t2i-preview
