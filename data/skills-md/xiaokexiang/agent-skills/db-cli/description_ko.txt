다중 데이터베이스 CLI 도구 – MySQL 및 Dameng 데이터베이스에 대한 SQL 가져오기, 내보내기 및 실행을 지원합니다.

**이 스킬이 적극적으로 발동되어야 하는 장면:**
- 사용자가 데이터베이스 작업, SQL 쿼리, 데이터 가져오기/내보내기를 언급합니다.
- 사용자는 데이터베이스 백업, 데이터 마이그레이션, 일괄 SQL 실행이 필요합니다.
- 사용자가 MySQL 또는 Dameng 데이터베이스 작업에 대해 질문합니다.
- 사용자가 "데이터베이스 확인", "SQL 실행", "데이터 내보내기", "데이터 가져오기"라고 말합니다.
- 사용자가 /db-cli 명령을 사용합니다.
- 운영을 위해 데이터베이스 연결이 필요한 모든 상황

**지원되는 데이터베이스:** MySQL, Dameng 데이터베이스
**지원되는 작업:** 가져오기, 내보내기, 실행
