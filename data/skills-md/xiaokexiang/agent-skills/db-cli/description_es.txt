Herramienta CLI para múltiples bases de datos: admite la importación, exportación y ejecución de SQL para bases de datos MySQL y Dameng.

**Escenas donde esta Habilidad debe activarse activamente:**
- El usuario menciona operaciones de bases de datos, consultas SQL, importación/exportación de datos.
- El usuario necesita hacer una copia de seguridad de las bases de datos, migrar datos y ejecutar SQL por lotes.
- El usuario pregunta sobre las operaciones de la base de datos MySQL o Dameng.
- El usuario dice "verificar la base de datos", "ejecutar SQL", "exportar datos", "importar datos"
- El usuario utiliza el comando /db-cli
- Cualquier situación que requiera conexión a base de datos para operaciones.

**Bases de datos compatibles:** MySQL, base de datos Dameng
**Operaciones admitidas:** importación, exportación, ejecución
