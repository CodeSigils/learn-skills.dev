أداة CLI لقواعد البيانات المتعددة – تدعم استيراد SQL وتصديره وتنفيذه لقواعد بيانات MySQL وDameng.

**المشاهد التي يجب فيها تفعيل هذه المهارة بشكل فعال:**
- يذكر المستخدم عمليات قاعدة البيانات واستعلامات SQL واستيراد/تصدير البيانات
- يحتاج المستخدم إلى عمل نسخة احتياطية من قواعد البيانات، وترحيل البيانات، وتنفيذ دفعة SQL
- يسأل المستخدم عن عمليات قاعدة بيانات MySQL أو Dameng
- يقول المستخدم "التحقق من قاعدة البيانات"، "تنفيذ SQL"، "تصدير البيانات"، "استيراد البيانات"
- يستخدم المستخدم الأمر /db-cli
- أي حالة تتطلب الاتصال بقاعدة البيانات للعمليات

** قواعد البيانات المدعومة: ** MySQL، قاعدة بيانات Dameng
**العمليات المدعومة:** الاستيراد والتصدير والتنفيذ
