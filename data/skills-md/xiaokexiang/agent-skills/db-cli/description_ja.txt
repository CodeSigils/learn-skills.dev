マルチデータベース CLI ツール – MySQL および Dameng データベースの SQL インポート、エクスポート、実行をサポートします。

**このスキルをアクティブにトリガーする必要があるシナリオ:**
- ユーザーはデータベース操作、SQL クエリ、データのインポート/エクスポートについて言及します
- ユーザーはデータベースのバックアップ、データの移行、またはバッチ SQL の実行が必要です
- ユーザーが MySQL または Damen データベースの操作について質問する
- ユーザーが「データベースをチェックする」、「SQL を実行する」、「データをエクスポートする」、「データをインポートする」と言う
- ユーザーが /db-cli コマンドを使用する
- データベース接続と操作が必要なあらゆる状況

**サポートされているデータベース:** MySQL、Dameng データベース
**サポートされている操作:** インポート、エクスポート、実行
