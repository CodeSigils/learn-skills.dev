Инструмент CLI для нескольких баз данных — поддерживает импорт, экспорт и выполнение SQL для баз данных MySQL и Dameng.

**Сцены, в которых этот навык необходимо активно активировать:**
- Пользователь упоминает операции с базой данных, SQL-запросы, импорт/экспорт данных.
- Пользователю необходимо выполнить резервное копирование баз данных, перенести данные, выполнить пакетный SQL.
- Пользователь спрашивает об операциях с базами данных MySQL или Dameng.
- Пользователь говорит: «проверить базу данных», «выполнить SQL», «экспортировать данные», «импортировать данные».
- Пользователь использует команду /db-cli.
- Любая ситуация, требующая подключения к базе данных для работы.

**Поддерживаемые базы данных:** MySQL, база данных Dameng.
**Поддерживаемые операции**: импорт, экспорт, выполнение.
