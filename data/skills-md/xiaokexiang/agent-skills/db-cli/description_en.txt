Multi-database CLI tool – supports SQL import, export, and execution for MySQL and Dameng databases.

**Scenes where this Skill must be actively triggered:**
- User mentions database operations, SQL queries, data import/export
- User needs to back up databases, migrate data, execute batch SQL
- User asks about MySQL or Dameng database operations
- User says “check the database”, “execute SQL”, “export data”, “import data”
- User uses the /db-cli command
- Any situation requiring database connection for operations

**Supported databases:** MySQL, Dameng Database
**Supported operations:** import, export, exec
