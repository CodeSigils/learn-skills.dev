Primitiva de edición de texto segura y fácil de usar para agentes. Inspeccione, edite y convierta archivos de texto existentes mientras conserva la codificación, la lista de materiales, los finales de línea, los permisos y la integridad de escritura. Úselo para cualquier edición de archivos en la que importen mojibake, archivos truncados, operaciones silenciosas sin operaciones o diferencias de Git ruidosas.
