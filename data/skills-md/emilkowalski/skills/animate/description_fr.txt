Créez une animation à partir de zéro, en prenant les décisions dans l'ordre qui détermine si elle semble correcte : doit-elle être animée, dans quel but, quel outil, quelles propriétés, quelle courbe et quelle durée, comment elle s'interrompt, comment elle sort. Écrit l'implémentation. À utiliser lorsqu'on vous demande d'animer quelque chose, d'ajouter du mouvement, de donner l'impression qu'un composant est vivant ou de créer une transition. Pour critiquer un mouvement existant, utilisez des animations de révision ; pour auditer une base de code entière, utilisez des animations d'amélioration.
