Cree una animación desde cero, tomando las decisiones en el orden que determine si se siente bien: si se anima, qué propósito, qué herramienta, qué propiedades, qué curva y duración, cómo se interrumpe, cómo sale. Escribe la implementación. Úselo cuando se le solicite animar algo, agregar movimiento, hacer que un componente se sienta vivo o crear una transición. Para criticar movimientos existentes, utilice animaciones de revisión; para auditar una base de código completa, utilice animaciones mejoradas.
