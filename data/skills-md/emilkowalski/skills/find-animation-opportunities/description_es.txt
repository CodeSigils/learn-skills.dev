Busque en una base de código o interfaz de usuario lugares que no se animen pero que deberían hacerlo, y rechace todo lo que no debería hacerlo. Sólo lectura; propone movimiento con valores exactos, no lo implementa. Úselo cuando el usuario pregunte "¿qué se podría animar aquí?" o quiere "hacer que esto se sienta más vivo". Para corregir animaciones existentes, utilice animaciones mejoradas o animaciones de revisión.
