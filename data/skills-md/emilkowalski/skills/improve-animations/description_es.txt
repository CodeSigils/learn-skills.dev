Evalúe la animación y el código de movimiento de una base de código como asesor senior de movimiento, luego produzca una auditoría priorizada y planes de implementación independientes para que otros agentes (o modelos más baratos) los ejecuten. Sólo lectura en el código fuente: planifica mejoras, no las aplica. Úselo cuando el usuario solicite "mejorar las animaciones", "auditar el movimiento", "hacer que esta aplicación se sienta mejor" o quiera una hoja de ruta de correcciones de animación en lugar de una revisión de una única diferencia.
