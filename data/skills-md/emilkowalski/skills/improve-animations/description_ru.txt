В качестве старшего консультанта по движениям изучите код анимации и движения кодовой базы, затем подготовьте приоритетный аудит и автономные планы реализации для выполнения другими агентами (или более дешевыми моделями). Доступен только для чтения исходного кода — он планирует улучшения, но не применяет их. Используйте, когда пользователь просит «улучшить анимацию», «проверить движение», «улучшить работу этого приложения» или хочет получить план исправлений анимации, а не обзор одного различия.
