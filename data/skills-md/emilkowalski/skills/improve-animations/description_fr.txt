Examinez l'animation et le code de mouvement d'une base de code en tant que conseiller en mouvement principal, puis produisez un audit prioritaire et des plans de mise en œuvre autonomes que d'autres agents (ou des modèles moins chers) pourront exécuter. Lecture seule sur le code source — il prévoit des améliorations, il ne les applique pas. À utiliser lorsque l'utilisateur demande « d'améliorer les animations », « d'auditer le mouvement », de « rendre cette application plus agréable » ou souhaite une feuille de route des correctifs d'animation plutôt qu'un examen d'une seule différence.
