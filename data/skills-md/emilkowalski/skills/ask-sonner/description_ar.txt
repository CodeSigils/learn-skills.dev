دليل Sonner، مكتبة React toast - قم بتثبيت المحمصة وتوصيلها، واختيار استدعاء toast() المناسب، والوعد وتحميل الخبز المحمص، وتحديث الخبز المحمص ورفضه والاستمرار فيه، والتصميم، والسمات والأيقونات، وتحديد المواقع ومحامص الخبز المتعددة. استخدمه عند العمل مع Sonner أو استكشاف الأخطاء وإصلاحها - الخبز المحمص الذي لا يظهر، أو يظهر مرتين، أو يفقد أنماطه، أو يتجاهل فئات Tailwind، أو يجلس خلف نموذج، أو لا يتبع الوضع المظلم.
