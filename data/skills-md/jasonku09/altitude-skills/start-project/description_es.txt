Inicie un proyecto para aprender a codificar construyendo. Entrevista al usuario para encontrar una idea de proyecto adaptada a su experiencia, define un MVP y mapea los componentes principales (el "tronco") que aprenderán de principio a fin. Úselo cuando un principiante quiere comenzar un proyecto de aprendizaje, dice "ayúdame a elegir un proyecto", "Quiero aprender a codificar construyendo algo real" o invoca /start-project.
