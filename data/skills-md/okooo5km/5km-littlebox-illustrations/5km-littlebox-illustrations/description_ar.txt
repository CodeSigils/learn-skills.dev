قم بإنشاء رسوم توضيحية لمقالة Littlebox (小盒) مرسومة يدويًا وخطط توضيحية للمقالات والمشاركات والمدونات والمستندات والتفكير في المنتج وسير العمل والأساليب والمقارنات والمفاهيم المجردة والاستعارات المرئية. يُستخدم عندما يطلب المستخدم Littlebox، أو 小盒، أو الرسوم التوضيحية لـ IP الخاصة بالصناديق الورقية/الكرتون، أو العناصر المرئية للمقالات، أو الرسوم التوضيحية للجسم، أو قوائم اللقطات، أو أفكار الاستعارة المرئية، أو الشروحات المرسومة يدويًا، أو تجديد/تحرير هذا النمط. افتراضي إلى 16:9 رسوم توضيحية تحريرية باللون الأبيض النقي مع Littlebox كمشغل مفاهيمي نشط، باستخدام مربع IP مغلق فقط، وحدود سوداء جريئة إلى حد ما، وأذرع غصين جانبية، وشريط كهرماني متعرج/لمسات مسار، وعلامات تحذير/ختم مرجانية، وتركيبات غير خطية متوازنة. تعتبر البدائل المدعومة كريمي شاحب جدًا، أو أزرق سماوي شاحب، أو لافندر شاحب، أو لون خلفية محدد من قبل المستخدم. وضوح المحتوى له الأولوية على البساطة المصطنعة. يدعم المستخدمين متعددي اللغات عن طريق كتابة المطالبات باللغة الإنجليزية مع الاحتفاظ بالملصقات المرئية بلغة المستخدم.
