استخدم Orchard CLI المحلي للتفاعل مع تطبيقات وخدمات macOS Apple من Codex: التقويم والتذكيرات والساعة والبريد وجهات الاتصال والملاحظات والموسيقى والطقس والرسائل والموقع/الخرائط واختصارات Apple. يحل أمر "orchard" المثبت عالميًا أو الأمر "Orchard.app/Contents/MacOS/orchard-cli" المجمّع. يُستخدم عندما تطلب مهمة قراءة أو إدارة أحداث التقويم المحلية، أو التذكيرات، أو Apple Mail، أو جهات الاتصال، أو الملاحظات، أو iMessage/SMS، أو تشغيل/مكتبة Apple Music، أو الطقس، أو الوقت/المناطق الزمنية الحالية، أو الترميز الجغرافي، أو المسارات، أو الموقع الحالي، أو الاختصارات المحلية.
