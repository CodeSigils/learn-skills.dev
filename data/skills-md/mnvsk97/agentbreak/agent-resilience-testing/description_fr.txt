Orchestre les tests de résilience de bout en bout pour les agents LLM avec AgentBreak, y compris les pannes d'infrastructure LLM, l'injection rapide, le risque de chaîne d'approvisionnement des compétences des agents, la vérification des garde-corps et les pannes de serveur/outil MCP. À utiliser lorsque l'utilisateur demande de « tester la résilience de mon agent », « de tester cet agent dans le chaos », de « trouver des modes de défaillance dans mon application LLM », de « regrouper mes outils MCP » ou d'évaluer la fiabilité, la tolérance aux pannes, la sécurité ou le comportement de récupération de l'agent.
