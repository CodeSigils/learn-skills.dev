Verwaltet Projekt-Roadmaps – geordnete Listen von Arbeitselementen (Work Items, WI), die auf Spezifikationen verweisen. Wird in zwei Situationen aktiviert. (A) Explizite Roadmap-Vorgänge über „/road <action>“ (erstellen/bearbeiten/anzeigen/synchronisieren/verzweigen) oder natürliche Sprache – Roadmaps erstellen/bearbeiten/anzeigen/synchronisieren, Arbeitselemente verwalten. (B) Nebenwirkungen von Spezifikationsänderungen: Wenn der Benutzer eine Aktion ausführt, die eine Spezifikationsdatei verschiebt, archiviert oder erstellt, auf die von einer Roadmap-WI verwiesen werden könnte (z. B. „mv openspec/changes/add-x openspec/changes/archive/“, Abschluss einer Superpowers-Aufgabe, Erstellen eines neuen Spezifikationsverzeichnisses), prüfen Sie, ob eine Roadmap-WI auf diese Spezifikation verweist, und aktualisieren Sie ihren Status entsprechend. Toolneutral – Links zu jedem Tool zum Schreiben von Spezifikationen (OpenSpec, Superpowers, Pläne, Issues, URLs).
