Запрашивайте общедоступный API ESPN для получения результатов в реальном времени, турнирной таблицы, составов, статистики игроков, коэффициентов, игрового процесса, травм, транзакций, новостей и многого другого по 17 видам спорта и 139 лигам. Используйте, когда пользователю нужны спортивные данные из ESPN, он хочет создать спортивное приложение, получить результаты или расписания, просмотреть статистику игроков или команд, узнать коэффициенты ставок или получить любые структурированные спортивные данные. Запускается при упоминании ESPN, спортивных результатов, турнирной таблицы, результатов матчей, статистики игроков, данных игр или данных лиги.
