Consulta la API pública de ESPN para obtener resultados en vivo, clasificaciones, listas, estadísticas de jugadores, probabilidades, jugada por jugada, lesiones, transacciones, noticias y más en 17 deportes y 139 ligas. Úselo cuando el usuario necesite datos deportivos de ESPN, desee crear una aplicación deportiva, obtener resultados o horarios, buscar estadísticas de jugadores o equipos, obtener probabilidades de apuestas o obtener datos deportivos estructurados. Se activa con menciones de ESPN, resultados deportivos, clasificaciones, puntajes, estadísticas de jugadores, datos de juegos o datos de la liga.
