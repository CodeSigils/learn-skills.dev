Interrogez l'API publique d'ESPN pour connaître les scores en direct, les classements, les effectifs, les statistiques des joueurs, les cotes, les play-by-play, les blessures, les transactions, les actualités et bien plus encore dans 17 sports et 139 ligues. À utiliser lorsque l'utilisateur a besoin de données sportives d'ESPN, souhaite créer une application sportive, récupérer des scores ou des horaires, rechercher des statistiques de joueurs ou d'équipes, obtenir des cotes de paris ou extraire des données sportives structurées. Se déclenche lors des mentions d'ESPN, des résultats sportifs, des classements, des scores des box, des statistiques des joueurs, des données de jeu ou des données de ligue.
