الاستعلام عن واجهة برمجة التطبيقات العامة لـ ESPN للحصول على النتائج المباشرة والترتيب والقوائم وإحصائيات اللاعبين والاحتمالات واللعب عن طريق اللعب والإصابات والمعاملات والأخبار والمزيد عبر 17 رياضة و139 دوريًا. يُستخدم عندما يحتاج المستخدم إلى بيانات رياضية من ESPN، أو يريد إنشاء تطبيق رياضي، أو جلب النتائج أو الجداول الزمنية، أو البحث عن إحصائيات اللاعب أو الفريق، أو الحصول على احتمالات المراهنة، أو سحب أي بيانات رياضية منظمة. يتم تشغيلها عند ذكر ESPN، أو النتائج الرياضية، أو الترتيب، أو نتائج الصناديق، أو إحصائيات اللاعب، أو بيانات اللعبة، أو بيانات الدوري.
