Используйте, когда пользователь хочет, чтобы целый пакет уже определенных проблем — дочерние проблемы эпика, веха или набор готовых для агента билетов — были реализованы автономно в одном запросе на включение, без вмешательства человека до тех пор, пока не будет поднят PR. Также охватывает возобновление прерванного пакетного запуска. Ни для одной проблемы, ни для просмотра или открытия PR по готовой работе, ни для создания или сортировки проблем, ни для автономного исправления ошибок.
