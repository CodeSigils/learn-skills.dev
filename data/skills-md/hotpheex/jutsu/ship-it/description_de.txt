Verwenden Sie diese Option, wenn der Benutzer eine ganze Reihe bereits spezifizierter Probleme – untergeordnete Probleme eines Epics, einen Meilenstein oder eine Reihe von Tickets, die für den Agenten bereit sind – autonom in einer einzigen Pull-Anfrage implementieren möchte, ohne dass ein menschlicher Eingriff erforderlich ist, bis die PR abgeschlossen ist. Deckt auch die Wiederaufnahme eines unterbrochenen Batch-Laufs ab. Nicht für ein einzelnes Problem, zum Überprüfen oder Öffnen einer PR für abgeschlossene Arbeiten, zum Erstellen oder Triagieren von Problemen oder zur autonomen Fehlerbehebung.
