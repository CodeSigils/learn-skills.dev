Úselo cuando el usuario quiera que un lote completo de problemas ya especificados (problemas secundarios de una epopeya, un hito o un conjunto de tickets listos para los agentes) se implementen de forma autónoma en una única solicitud de extracción, sin intervención humana hasta que el PR esté activo. También cubre la reanudación de una ejecución por lotes interrumpida. No para un solo problema, ni para revisar o abrir un PR sobre un trabajo terminado, ni para crear o clasificar problemas, ni para corregir errores de forma autónoma.
