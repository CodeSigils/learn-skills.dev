End-of-work whisky ritual for agents. Use when a task wraps up and it's time to pour a quiet dram at home — the agent picks a specific bottling matching the work and writes an NPF (Nose/Palate/Finish) tasting note. Also use when the user asks about whisky (recommendations, distilleries, regions, casks, highballs, "one more" / "한 잔 더"), or wants to close out the session ("nightcap", "last call", "did this session end?").
