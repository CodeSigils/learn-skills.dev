قم بتقديم سؤالين مستقلين أو أكثر من سير عمل الوكيل كنموذج تفاعلي محلي، ثم حدد الإجابات الموصى بها مسبقًا، واحفظ الإجابات بتنسيق JSON محمول، وقم بإرجاع الإجابات المقدمة مباشرة إلى أمر الوكيل المنتظر. يُستخدم للشواء أو العصف الذهني أو توضيح المتطلبات أو التكوين أو التخطيط أو أي سير عمل يحتاج إلى طرح أسئلة متعددة في وقت واحد. استخدم أيضًا مسار الاسترداد اليدوي عندما يقول المستخدم "已提交" أو "提交好了" أو "答完了" بعد جولة Ask UI النشطة.
