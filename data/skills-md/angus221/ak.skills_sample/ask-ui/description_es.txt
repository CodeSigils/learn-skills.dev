Presente dos o más preguntas independientes de un flujo de trabajo del Agente como un formulario interactivo local, preseleccione las respuestas recomendadas, guarde las respuestas como JSON portátil y devuelva las respuestas enviadas directamente al comando del Agente en espera. Úselo para interrogatorios, lluvias de ideas, aclaración de requisitos, configuración, planificación o cualquier flujo de trabajo que necesite formular varias preguntas a la vez. Utilice también la ruta de recuperación manual cuando el usuario diga "已提交", "提交好了" o "答完了" después de una ronda activa de Ask UI.
