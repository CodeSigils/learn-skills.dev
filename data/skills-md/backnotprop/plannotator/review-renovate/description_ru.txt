Просмотрите запросы обновлений для ботов, которые обновляют зависимости GitHub Actions. Проверяет целостность цепочки поставок, сверяя закрепленные SHA фиксации с вышестоящими выпусками с тегами, просматривает журналы изменений на предмет критических изменений и подтверждает совместимость с существующими конфигурациями рабочих процессов. Используйте, когда запрос обновления Renovate обновляет действия GitHub в .github/workflows/.
