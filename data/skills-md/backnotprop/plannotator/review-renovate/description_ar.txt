قم بمراجعة Renovate bot PRs التي تقوم بتحديث تبعيات GitHub Actions. التحقق من تكامل سلسلة التوريد عن طريق التحقق من التزامات SHA المثبتة مقابل الإصدارات الأولية ذات العلامات، ومراجعة سجلات التغيير لكسر التغييرات، وتأكيد التوافق مع تكوينات سير العمل الحالية. يُستخدم عندما يقوم Renovate PR بتحديث إجراءات GitHub في .github/workflows/.
