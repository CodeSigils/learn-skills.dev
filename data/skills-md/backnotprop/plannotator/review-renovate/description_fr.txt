Consultez les PR du bot Renovate qui mettent à jour les dépendances des actions GitHub. Vérifie l'intégrité de la chaîne d'approvisionnement en vérifiant les SHA de validation épinglés par rapport aux versions balisées en amont, examine les journaux de modifications pour détecter les modifications importantes et confirme la compatibilité avec les configurations de flux de travail existantes. À utiliser lorsqu'un PR Renovate met à jour les actions GitHub dans .github/workflows/.
