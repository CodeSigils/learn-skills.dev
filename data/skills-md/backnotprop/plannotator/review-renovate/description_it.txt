Esaminare Rinnovare i PR dei bot che aggiornano le dipendenze di GitHub Actions. Verifica l'integrità della catena di fornitura controllando gli SHA di commit fissati rispetto alle versioni con tag upstream, esamina i log delle modifiche per individuare eventuali modifiche sostanziali e conferma la compatibilità con le configurazioni del flusso di lavoro esistenti. Da utilizzare quando un PR di rinnovamento aggiorna le azioni GitHub in .github/workflows/.
