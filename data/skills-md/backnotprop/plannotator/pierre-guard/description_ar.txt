احذر من كسر تكامل @pierre/diffs في واجهة مستخدم مراجعة التعليمات البرمجية الخاصة بـ Plannotator. استخدم هذه المهارة عند تعديل DiffViewer.tsx، أو ترقية حزمة @pierre/diffs، أو تغيير حقن CSS غير الآمن، أو إضافة دعائم جديدة إلى FileDiff، أو لمس محددات DOM الظل أو متغيرات CSS التي تتقاطع مع حدود الظل الخاصة بـ Pierre. يتم تشغيله أيضًا عندما يسأل شخص ما "هل سيؤدي هذا إلى كسر عارض الاختلاف"، أو "هل هذا آمن للتغيير"، أو عند مراجعة العلاقات العامة التي تلمس حزمة محرر المراجعة.
