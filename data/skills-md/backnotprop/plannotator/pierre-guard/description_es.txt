Evite romper la integración de @pierre/diffs en la interfaz de usuario de revisión de código de Plannotator. Utilice esta habilidad siempre que modifique DiffViewer.tsx, actualice el paquete @pierre/diffs, cambie la inyección de CSS no segura, agregue nuevos accesorios a FileDiff o toque selectores DOM de sombra o variables CSS que crucen el límite de sombra de Pierre. También se activa cuando alguien pregunta "¿esto romperá el visor de diferencias?", "¿es seguro cambiar esto?" o al revisar relaciones públicas que tocan el paquete del editor de revisión.
