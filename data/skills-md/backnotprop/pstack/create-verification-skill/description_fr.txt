Générez une compétence de vérification locale du projet qui pilote votre application comme le fait un utilisateur : n'importe quel langage, framework ou plate-forme. À utiliser pour /create-verification-skill, « créer une compétence de contrôle pour ce dépôt » ou lorsqu'un projet ne dispose d'aucun moyen scripté pour prouver le comportement de l'interface utilisateur/CLI/du service.
