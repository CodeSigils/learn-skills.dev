Wenden Sie es an, wenn Sie Typen entwerfen, eine Funktionssignatur überprüfen oder Code in einer statisch typisierten Sprache schreiben. Machen Sie illegale Zustände nicht darstellbar, markieren Sie semantische Grundelemente, analysieren Sie externe Daten an Grenzen, weigern Sie sich, den Compiler anzulügen, erschöpfen Sie Varianten, leiten Sie von maßgeblichen Schemata ab.
