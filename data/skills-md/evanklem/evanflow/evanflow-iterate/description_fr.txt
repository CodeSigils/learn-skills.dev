Boucle d’auto-évaluation itérative après la mise en œuvre d’un plan. Relisez le code modifié avec un regard neuf, corrigez les problèmes détectés, réexécutez les contrôles de qualité, répétez jusqu'à ce qu'ils soient propres. Pour le travail de l'interface utilisateur, inclut la vérification visuelle (afficher la page rendue). À utiliser une fois les plans d'exécution d'evanflow terminés ; en cas de succès, signalez et arrêtez : l'utilisateur décide de la suite.
