Организуйте параллельную реализацию с помощью пар кодировщик/контролер. Программисты реализуют декомпозированные задачи с помощью evanflow-tdd; контролеры проверяют выходные данные каждого программиста на наличие ошибок, пробелов, ошибок и нарушений целостности в соответствии с общим контрактом. Последний куратор интеграции проверяет согласованность между программистами. Используйте для планов с более чем 3 действительно независимыми задачами, которые используют общий контракт интерфейса.
