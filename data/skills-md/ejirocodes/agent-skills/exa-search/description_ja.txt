Exa.ai 検索 API は、ニューラルおよびキーワード Web 検索とコンテンツ取得を統合します。 Web検索機能の実装、Exa SDK (exa_py、exa-js)の統合、またはWebコンテンツの取得時に使用します。トリガー対象: Exa、exa_py、exa-js、ニューラル検索、Web 検索 API、search_and_contents、searchAndContents、find_similar、findSimilar、ドメイン フィルタリング、日付フィルタリング、テキスト抽出、ページ概要、ハイライト、検索自動モード、高速検索、検索カテゴリ、ライブクロール、ドメインの除外、テキストを含む、テキストの除外、EXA_API_KEY。
