تكامل واجهة برمجة تطبيقات البحث Exa.ai للبحث العصبي والكلمات الرئيسية على الويب مع استرجاع المحتوى. يُستخدم عند تنفيذ ميزات بحث الويب، أو دمج Exa SDK (exa_py، exa-js)، أو استرداد محتوى الويب. المشغلات على: Exa، exa_py، exa-js، البحث العصبي، واجهة برمجة تطبيقات بحث الويب، search_and_contents، searchAndContents، find_similar، findSimilar، تصفية المجال، تصفية التاريخ، استخراج النص، ملخصات الصفحات، الإبرازات، وضع البحث التلقائي، البحث السريع، فئات البحث، الزحف المباشر، باستثناء المجالات، تضمين النص، استبعاد النص، EXA_API_KEY.
