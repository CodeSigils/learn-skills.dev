Exa.ai を使用して RAG パイプラインを構築し、リアルタイムの Web 検索を実現します。検索拡張生成を構築する場合、Exa を LangChain、LlamaIndex、Vercel AI SDK と統合する場合、または Web 検索機能を備えた AI エージェントを実装する場合に使用します。トリガー対象: RAG パイプライン、検索拡張生成、Exa LangChain、Exa LlamaIndex、ExaSearchRetriever、ExaSearchResults、Exa MCP、Exa ツール呼び出し、Claude ツールの使用、AI エージェント Web 検索、グラウンディング生成、引用生成、ファクト チェック、幻覚検出、OpenAI 互換性、チャット完了。
