AI映画・ショートドラマ解説動画自動生成（AIナレーターマスターCLIスキル）。ユーザーが映画の解説ビデオ、短編ドラマの説明、映画の再現、AI ナレーション ビデオ、映画の解説、ビデオ ナレーション、ドラマの吹き替え、または映画のナレーションを作成する必要がある場合にトリガーされます。映画映像ライブラリ、BGM、多言語吹き替え、ナレーションテンプレートを内蔵。 narrator-ai-cliコマンドラインにより、フィルム検索→テンプレート選択→BGM選択→音声選択→スクリプト生成→映像合成までの完全自動化を実現します。 Narrator AI ビデオ ナレーション API の CLI クライアント。
