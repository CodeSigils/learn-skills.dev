التوليد التلقائي لفيديو التعليق على فيلم AI/دراما قصيرة (AI Narrator Master CLI Skill). يتم تشغيله عندما يحتاج المستخدمون إلى إنشاء مقاطع فيديو للتعليق على الفيلم، أو شروحات درامية قصيرة، أو إعادة إنشاء الفيلم، أو روايات التعليق الصوتي بالذكاء الاصطناعي، أو تعليق الفيلم، أو رواية الفيديو، أو دبلجة الدراما، أو رواية الفيلم. مكتبة لقطات الأفلام المضمنة وBGM والدبلجة متعددة اللغات وقوالب التعليقات. يتم تحقيقه عبر سطر أوامر narrator-ai-cli: ابحث عن الفيلم ← اختر القالب ← اختر BGM ← اختر الصوت ← قم بإنشاء نص ← فيديو مركب، أتمتة كاملة لسير العمل. عميل CLI لواجهة برمجة تطبيقات سرد الفيديو Narrator AI.
