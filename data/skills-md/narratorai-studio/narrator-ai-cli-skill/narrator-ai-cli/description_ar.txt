مولد تلقائي لفيديو التعليق على الأفلام/الدراما القصيرة بتقنية الذكاء الاصطناعي (مهارة CLI للراوي بالذكاء الاصطناعي). يتم تشغيله عندما يحتاج المستخدمون إلى إنشاء مقاطع فيديو للتعليق على الفيلم، أو شروحات درامية قصيرة، أو إعادة إنشاء الفيلم، أو مقاطع فيديو سرد صوتي مدعومة بالذكاء الاصطناعي، أو تعليق على الفيلم، أو سرد فيديو، أو دبلجة درامية، أو سرد للفيلم. مكتبة لقطات الأفلام المدمجة وBGM والدبلجة متعددة اللغات وقوالب السرد. يحقق الأتمتة الكاملة — بدءًا من البحث عن الأفلام ← اختيار القوالب ← تحديد BGM ← اختيار الصوت ← إنشاء البرنامج النصي ← تركيب الفيديو - عبر سطر أوامر narrator-ai-cli. عميل CLI لواجهة برمجة تطبيقات سرد الفيديو Narrator AI.
