Автоматический генератор видеокомментариев к фильмам/короткометражным драмам с искусственным интеллектом (навык AI Narrator Master CLI). Срабатывает, когда пользователям необходимо создать видеоролики с комментариями к фильмам, пояснения к коротким драмам, воссоздания фильмов, видеоролики с закадровым голосом с помощью искусственного интеллекта, комментарии к фильмам, видеоповествования, дубляж драмы или повествование фильма. Встроенная библиотека видеоматериалов, фоновая музыка, многоязычное дубляж и шаблоны повествования. Обеспечивает полную автоматизацию — поиск фильмов → выбор шаблонов → выбор фоновой музыки → выбор голоса → создание сценария → компоновка видео — через командную строку Narrator-ai-cli. Клиент CLI для API видеоповторения Narrator AI.
