Compétences de collaboration Git orientées vers le développement basé sur le tronc. Convient aux scénarios tels que « nous utilisons une base basée sur le tronc », « modifier le code en suivant l'approche de développement du tronc », « extraire d'abord une courte branche du tronc », « diviser les modifications en petits morceaux et fusionner rapidement », « synchroniser principal/maître avant d'ouvrir un PR », « doit créer un indicateur de fonctionnalité avant de fusionner des fonctionnalités incomplètes », etc. ; utilisé pour effectuer des tâches de développement dans le référentiel à l'aide de branches courtes, de petits lots et d'une intégration rapide.
