Навыки совместной работы с Git для разработки на базе магистрали. Подходит для таких сценариев, как «мы используем транковый/базовый транковый код», «разрабатываем код, следуя подходу к разработке транков», «сначала извлекаем недолговечную ветку из магистрального канала», «разбиваем изменения на небольшие части и быстро объединяем их», «синхронизируем основной/главный перед открытием PR», «необходимо создать флаг функции перед объединением незавершенных функций» и т. д.; используется для выполнения задач разработки в репозитории с короткими ветвями, небольшими пакетами и быстрой интеграцией.
