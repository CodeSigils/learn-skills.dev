Habilidades de colaboración de Git orientadas al desarrollo basado en troncales. Adecuado para escenarios como "utilizamos una base troncal/troncal", "desarrollamos código siguiendo el enfoque troncal", "sacar primero una rama corta del troncal", "dividemos los cambios en partes pequeñas y los fusionamos rápidamente", "sincronizamos con principal/maestro antes de abrir un PR" y "debemos crear un indicador de función antes de fusionar funciones incompletas". Se utiliza para ejecutar tareas de desarrollo en el repositorio utilizando ramas cortas, lotes pequeños y una integración rápida.
