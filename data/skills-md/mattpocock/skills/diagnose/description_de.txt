Disziplinierte Diagnoseschleife für schwere Fehler und Leistungsrückgänge. Reproduzieren → minimieren → Hypothese aufstellen → instrumentieren → korrigieren → Regressionstest. Wird verwendet, wenn der Benutzer „dies diagnostizieren“/„dieses debuggen“ sagt, einen Fehler meldet, sagt, dass etwas kaputt ist/auslöst/fehlschlägt, oder einen Leistungsrückgang beschreibt.
