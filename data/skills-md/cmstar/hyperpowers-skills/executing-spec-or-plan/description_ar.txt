قم بتنفيذ الخطة الكاملة أو المواصفات المعتمدة، وقبل التنفيذ، تأكد مركزيًا من Git والالتزامات وTDD واستراتيجية الوكيل الفرعي ونموذج الوكيل الفرعي عندما يكون النظام الأساسي مدعومًا. استخدمه فقط عندما يطلب المستخدم صراحةً "تنفيذ المواصفات أو الخطة" أو عندما يحدد صراحةً خيارًا يحمل هذا الاسم؛ لا تعامل السلبيات أو الأسئلة أو المراجع التوثيقية أو مطابقات المهام كتفويض للاستدعاء.
