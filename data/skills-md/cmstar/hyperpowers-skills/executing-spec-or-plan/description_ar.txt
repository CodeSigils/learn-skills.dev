قم بتنفيذ الخطة الكاملة أو المواصفات المعتمدة، وقبل التنفيذ، تأكد مركزيًا من استراتيجية الوكيل الفرعي Git والالتزام وTDD، بالإضافة إلى نموذج الوكيل الفرعي عندما يتعلق الأمر بدعم النظام الأساسي. استخدمه فقط عندما يطلب المستخدم صراحةً تنفيذ المواصفات أو الخطة، أو عندما يحدد صراحةً خيارًا يحمل هذا الاسم؛ لا تعامل النفي أو الاستفسارات أو مراجع التوثيق أو مطابقة المهام كتفويض للاستدعاء.
