/home/node/.claude.json の HappyCapy 環境で複数の MCP サーバー (Composio、Memory、GitHub Copilot) をグローバルに構成します。ユーザーが MCP サーバーのインストール、外部アプリ (Gmail、Slack、GitHub、Notion) へのアクセス、ナレッジ グラフ ストレージのセットアップ、OAuth 統合の構成、またはクロードを外部サービスに接続する方法を尋ねる場合に使用します。トリガーには、「mcp のインストール」、「composio の構成」、「memory mcp のセットアップ」、「gmail へのアクセス」、「github copilot mcp」、またはクロードをサードパーティ アプリに接続することに関する言及が含まれます。
