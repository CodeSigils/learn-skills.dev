Configure múltiples servidores MCP (Composio, Memory, GitHub Copilot) globalmente en el entorno HappyCapy en /home/node/.claude.json. Úselo cuando los usuarios quieran instalar servidores MCP, acceder a aplicaciones externas (Gmail, Slack, GitHub, Notion), configurar el almacenamiento de gráficos de conocimiento, configurar integraciones de OAuth o preguntar cómo conectar Claude a servicios externos. Los activadores incluyen "instalar mcp", "configurar composio", "configurar memoria mcp", "acceder a gmail", "github copilot mcp" o cualquier mención de conectar Claude a aplicaciones de terceros.
