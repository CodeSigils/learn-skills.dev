Configurez plusieurs serveurs MCP (Composio, Memory, GitHub Copilot) globalement dans l'environnement HappyCapy sur /home/node/.claude.json. À utiliser lorsque les utilisateurs souhaitent installer des serveurs MCP, accéder à des applications externes (Gmail, Slack, GitHub, Notion), configurer le stockage de graphiques de connaissances, configurer les intégrations OAuth ou demander comment connecter Claude à des services externes. Les déclencheurs incluent « installer mcp », « configurer composio », « configurer la mémoire mcp », « accéder à gmail », « github copilot mcp » ou toute mention de connexion de Claude à des applications tierces.
