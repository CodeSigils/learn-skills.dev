Konfigurieren Sie mehrere MCP-Server (Composio, Memory, GitHub Copilot) global in der HappyCapy-Umgebung unter /home/node/.claude.json. Verwenden Sie diese Option, wenn Benutzer MCP-Server installieren, auf externe Apps (Gmail, Slack, GitHub, Notion) zugreifen, die Speicherung von Wissensgraphen einrichten, OAuth-Integrationen konfigurieren oder fragen möchten, wie sie Claude mit externen Diensten verbinden können. Zu den Auslösern gehören „mcp installieren“, „composio konfigurieren“, „speicher mcp einrichten“, „auf gmail zugreifen“, „github copilot mcp“ oder jede Erwähnung der Verbindung von Claude mit Apps von Drittanbietern.
