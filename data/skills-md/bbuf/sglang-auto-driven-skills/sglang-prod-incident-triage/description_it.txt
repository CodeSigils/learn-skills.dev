Flusso di debug del primo replay per problemi di servizio SGLang. Da utilizzare quando un server attivo o recente mostra errori di controllo dello stato, regressioni di latenza o velocità effettiva, crescita della coda, timeout, stalli distribuiti, dump di arresti anomali, output errati dopo le distribuzioni o problemi PD/EP/HiCache e il compito è trasformare il problema in una riproduzione più lo strumento di debug successivo.
