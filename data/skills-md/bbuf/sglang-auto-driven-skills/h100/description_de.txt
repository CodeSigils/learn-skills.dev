Stellen Sie eine SSH-Verbindung zum Host „h100_sglang“ her, geben Sie den Docker-Container „sglang_bbuf“ ein, arbeiten Sie in „/sgl-workspace/sglang“ und verwenden Sie die fertige H100-Remote-Umgebung für die SGLang-Entwicklung und -Validierung. Verwenden Sie es, wenn eine Aufgabe Remote-CUDA-Arbeit, GPU-gestützte Smoke-Tests, Diffusionsprüfungen oder eine sichere Remote-Kopie anstelle einer rein lokalen Ausführung erfordert.
