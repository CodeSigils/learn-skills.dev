Triton、CUDA C++/PTX、CUTLASS/CuTe C++、および CuTe DSL カーネルを含む、AKO4ALL 中心のループを通じて AI インフラ GPU カーネルを開発、最適化、デバッグ、または移植するときに使用します。兄弟 AKO4ALL リポジトリのセットアップ、マイクロベンチ ハーネスの作成、nsys/ncu によるプロファイリング、実際のオペレーターまたはモデルのベンチマークに対するカーネルの変更の検証にも使用します。単純な Triton または CUDA API ルックアップではトリガーしないでください。このスキルは、AKO 規律が功を奏する完全な最適化または書き換えタスク用です。
