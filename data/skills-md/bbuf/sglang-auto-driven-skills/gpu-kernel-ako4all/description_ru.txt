Используйте при разработке, оптимизации, отладке или портировании ядер AI-infra GPU через цикл, ориентированный на AKO4ALL, включая ядра Triton, CUDA C++/PTX, CUTLASS/CuTe C++ и CuTe DSL; также используйте при настройке родственного репозитория AKO4ALL, создании жгутов микротестов, профилировании с помощью nsys/ncu и проверке изменений ядра по сравнению с реальными тестами оператора или модели. Не запускайте простой поиск по API Triton или CUDA; этот навык предназначен для полной оптимизации или переписывания задач, где дисциплина AKO окупается.
