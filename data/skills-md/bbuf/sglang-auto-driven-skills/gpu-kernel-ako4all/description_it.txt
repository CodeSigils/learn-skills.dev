Da utilizzare durante lo sviluppo, l'ottimizzazione, il debug o il porting di kernel GPU AI-infra tramite un loop centrato su AKO4ALL, inclusi i kernel Triton, CUDA C++/PTX, CUTLASS/CuTe C++ e CuTe DSL; utilizzare anche durante la configurazione di un repository AKO4ALL fratello, la creazione di cablaggi microbench, la profilazione con nsys/ncu e la convalida delle modifiche del kernel rispetto a benchmark di operatori o modelli reali. Non eseguire l'attivazione su semplici ricerche API Triton o CUDA; questa abilità serve per l'ottimizzazione completa o per le attività di riscrittura in cui la disciplina AKO ripaga.
