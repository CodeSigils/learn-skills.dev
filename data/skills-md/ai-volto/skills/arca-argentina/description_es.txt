Orientación actual y respaldada por fuentes para ARCA (anteriormente AFIP) de Argentina, impuestos federales, Monotributo, IVA/Ganancias/Bienes Personales, autónomos, empleadores, facturación, registros, presentaciones, pagos, deudas, avisos, alquileres, exportaciones, casos transfronterizos y trámites comunes; además de clientes Python protegidos para facturas electrónicas WSAA, WSFEv1 y consultas autorizadas del registro de contribuyentes. Úselo siempre que un usuario pregunte qué significa una norma tributaria argentina, qué debe hacer, cómo completar un trámite ARCA o cómo autenticarse y utilizar un servicio web ARCA compatible.
