Conseils actuels et fondés sur des sources pour l'ARCA (anciennement AFIP) de l'Argentine, les impôts fédéraux, le Monotributo, l'IVA/Ganancias/Bienes Personales, les autonomos, les employeurs, la facturation, les enregistrements, les dépôts, les paiements, les dettes, les avis, les locations, les exportations, les cas transfrontaliers et les tramites communes ; ainsi que des clients Python protégés pour les factures électroniques WSAA, WSFEv1 et les requêtes autorisées du registre des contribuables. À utiliser chaque fois qu'un utilisateur demande ce que signifie une règle fiscale argentine, ce qu'il doit faire, comment remplir un trámite ARCA ou comment s'authentifier et utiliser un service Web ARCA pris en charge.
