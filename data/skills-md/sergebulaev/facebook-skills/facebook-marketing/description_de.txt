Planen, entwerfen, prüfen und veröffentlichen Sie Beiträge für eine Facebook-Seite. Verwenden Sie diese Option, wenn der Benutzer einen kurzen, prägnanten Seitenbeitrag oder einen längeren Story-Beitrag schreiben, KI-Tells aus einem Entwurf entfernen, den Hook aus einem stark geteilten Seitenbeitrag zurückentwickeln, Antworten auf Kommentare auf seiner Seite entwerfen oder eine Woche Facebook-Seiteninhalte planen möchte. Seitenbeiträge werden über die Publora-API veröffentlicht. Der Benutzer stellt Notizen oder eine Facebook-Seitenbeitrags-URL bereit, entwirft den Skill, der Benutzer genehmigt ihn und veröffentlicht ihn dann.
