Unified IMA OpenAPI skill, supporting note management and knowledge base operations.
When users mention knowledge base, document library, notes, memos, reminders, or want to upload files, add web pages to knowledge base,
search knowledge base content, search/browse/create/edit notes, use this skill.
Even if users don't explicitly say "knowledge base" or "notes", as long as the intent involves uploading files to knowledge base, web page collection,
knowledge search, or personal document access (e.g., "help me remember this", "search if there's XX in the knowledge base"), this skill should also be triggered.
