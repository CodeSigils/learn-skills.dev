Habilidad unificada de IMA OpenAPI para gestión de notas y operaciones de base de conocimientos.
Utilice esta habilidad cuando el usuario mencione la base de conocimientos, el repositorio, las notas, la nota o quiera cargar archivos, agregar páginas web a la base de conocimientos, buscar en la base de conocimientos o buscar/explorar/crear/editar notas.
Incluso si el usuario no dice explícitamente "base de conocimientos" o "notas", active esta habilidad siempre que la intención implique cargar archivos a la base de conocimientos, guardar páginas web, buscar conocimientos o acceder a documentos personales (por ejemplo, "anotar esto para mí", "comprobar si XX está en mi base de conocimientos").
