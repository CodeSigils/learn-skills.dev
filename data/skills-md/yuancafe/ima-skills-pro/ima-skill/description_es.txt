Habilidad unificada de IMA OpenAPI, que respalda la gestión de notas y las operaciones de la base de conocimientos.
Cuando los usuarios mencionen la base de conocimientos, la biblioteca de documentos, notas, memorandos, recordatorios o quieran cargar archivos, agregue páginas web a la base de conocimientos,
buscar contenido de la base de conocimientos, buscar/explorar/crear/editar notas, utilizar esta habilidad.
Incluso si los usuarios no dicen explícitamente "base de conocimientos" o "notas", siempre que la intención implique cargar archivos a la base de conocimientos, colección de páginas web,
búsqueda de conocimientos o acceso a documentos personales (por ejemplo, "ayúdame a recordar esto", "busca si hay XX en la base de conocimientos"), esta habilidad también debe activarse.
