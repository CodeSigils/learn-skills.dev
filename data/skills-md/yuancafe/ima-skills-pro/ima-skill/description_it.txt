Competenza IMA OpenAPI unificata, che supporta la gestione delle note e le operazioni della knowledge base.
Quando gli utenti menzionano la knowledge base, la raccolta documenti, le note, i promemoria, i promemoria o desiderano caricare file, aggiungere pagine Web alla knowledge base,
cercare contenuti nella knowledge base, cercare/sfogliare/creare/modificare note, utilizzare questa abilità.
Anche se gli utenti non dicono esplicitamente "knowledge base" o "note", purché l'intento implichi il caricamento di file nella knowledge base, nella raccolta di pagine Web,
ricerca di conoscenza o accesso a documenti personali (ad esempio "aiutami a ricordare questo", "cerca se c'è XX nella base di conoscenza"), anche questa abilità dovrebbe essere attivata.
