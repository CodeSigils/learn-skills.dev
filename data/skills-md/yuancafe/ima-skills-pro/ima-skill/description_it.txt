Competenza IMA OpenAPI unificata che supporta la gestione delle note e le operazioni della knowledge base.
Utilizza questa abilità ogni volta che l'utente menziona knowledge base, repository, note, memo, blocco note o desidera caricare file, aggiungere pagine Web alla knowledge base, eseguire ricerche nel contenuto della knowledge base o cercare/sfogliare/creare/modificare note.
Anche se l'utente non dice esplicitamente "knowledge base" o "note", attiva questa abilità purché l'intento implichi il caricamento di file nella knowledge base, l'aggiunta di segnalibri a pagine web, la ricerca di conoscenze o l'accesso a documenti personali (ad esempio, "aiutami a ricordare questo", "cerca se XX è nella knowledge base").
