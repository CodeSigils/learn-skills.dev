Traitement de données spatiales pour la modélisation géologique avec GemPy. À utiliser lorsque Claude
doit : (1) Préparer les données spatiales pour les modèles GemPy, (2) Extraire l'interface
points issus de cartes géologiques, (3) orientations de processus/mesures de pendage,
(4) Échantillons de DEM le long de profils ou de coupes transversales, (5) Conversion entre SIG
formats et entrées GemPy, (6) Découper/transformer les données vectorielles/raster pour la modélisation,
(7) Créer des étendues de modèle à partir de limites géospatiales.
