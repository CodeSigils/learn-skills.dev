Procesamiento de datos espaciales para modelado geológico con GemPy. Usar cuando Claude
necesita: (1) preparar datos espaciales para los modelos GemPy, (2) extraer la interfaz
puntos de mapas geológicos, (3) orientaciones del proceso/mediciones de inmersión,
(4) DEM de muestra a lo largo de perfiles o secciones transversales, (5) Convertir entre SIG
formatos y entradas GemPy, (6) Recortar/transformar datos vectoriales/rasterizados para modelado,
(7) Crear extensiones de modelo a partir de límites geoespaciales.
