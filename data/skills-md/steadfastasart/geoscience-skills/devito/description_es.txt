Solucionador PDE simbólico con generación automática de código para diferencias finitas
cálculos. Úselo cuando Claude necesite: (1) Realizar la propagación de ondas sísmicas
modelado, (2) Implementar ecuaciones de ondas acústicas o elásticas, (3) Avanzar
modelado para tomas, (4) configurar flujos de trabajo de inversión de forma de onda completa (FWI),
(5) Implementar la migración en tiempo inverso (RTM), (6) Crear un límite absorbente
condiciones, (7) Generar código de plantilla optimizado para CPU/GPU, (8) Resolver
PDE personalizadas con diferencias finitas.
