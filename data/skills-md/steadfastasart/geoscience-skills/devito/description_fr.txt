Solveur PDE symbolique avec génération automatique de code pour les différences finies
calculs. À utiliser lorsque Claude doit : (1) Effectuer la propagation d'ondes sismiques
modélisation, (2) Implémenter des équations d'ondes acoustiques ou élastiques, (3) Avancer
modélisation pour les regroupements de prises de vue, (4) mettre en place des flux de travail d'inversion complète de forme d'onde (FWI),
(5) Mettre en œuvre la migration temporelle inversée (RTM), (6) Créer une limite absorbante
conditions, (7) Générer un code de pochoir optimisé pour les CPU/GPU, (8) Résoudre
PDE personnalisés avec des différences finies.
