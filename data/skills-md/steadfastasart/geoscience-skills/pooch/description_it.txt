Recupero e memorizzazione nella cache di file di dati per applicazioni di geoscienza. Scarica l'esempio
set di dati con memorizzazione nella cache automatica, verifica del checksum e download multipli
fonti. Da utilizzare quando Claude deve: (1) scaricare set di dati da URL o DOI,
(2) Memorizza nella cache i file localmente con verifica automatica, (3) Verifica l'integrità dei file
con hash SHA256/MD5, (4) Estrazione di archivi compressi (ZIP, TAR, GZIP),
(5) Creare registri di dati per flussi di lavoro riproducibili, (6) Recuperare da Zenodo
o altri repository.
