Obtención y almacenamiento en caché de archivos de datos para aplicaciones de geociencia. Descargar muestra
conjuntos de datos con almacenamiento en caché automático, verificación de suma de comprobación y descarga múltiple
fuentes. Úselo cuando Claude necesite: (1) Descargar conjuntos de datos desde URL o DOI,
(2) Almacenar en caché los archivos localmente con verificación automática, (3) Verificar la integridad del archivo
con hash SHA256/MD5, (4) Extraer archivos comprimidos (ZIP, TAR, GZIP),
(5) Crear registros de datos para flujos de trabajo reproducibles, (6) Obtener de Zenodo
u otros repositorios.
