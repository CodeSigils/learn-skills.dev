Análisis y visualización de datos geoquímicos para ígneos, metamórficos y
rocas sedimentarias. Úselo cuando Claude necesite: (1) Crear diagramas ternarios para
datos de composición, (2) Trazar diagramas de araña REE con normalización, (3) Construir
TAS u otros diagramas de clasificación, (4) Aplicar transformaciones de relación logarítmica a
datos de composición, (5) Calcular normas CIPW, (6) Generar variación de Harker
diagramas, (7) Calcular relaciones de elementos y anomalías.
