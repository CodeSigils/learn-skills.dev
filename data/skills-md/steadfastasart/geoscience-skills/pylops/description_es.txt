Operadores lineales para problemas inversos a gran escala con representaciones sin matrices.
Úselo cuando Claude necesite: (1) Definir operadores lineales para operaciones directas/adjuntas,
(2) Resolver problemas inversos (deconvolución, imágenes, tomografía), (3) Aplicar señal
transformaciones de procesamiento (FFT, convolución, derivadas), (4) Componer operadores para
flujos de trabajo complejos, (5) Realizar inversión regularizada con suavidad o escasez
restricciones, (6) Procesar datos sísmicos o de imágenes a escala.
