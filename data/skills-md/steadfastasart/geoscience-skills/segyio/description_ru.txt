Чтение, запись и управление файлами сейсмических данных SEG-Y. Быстрая библиотека C с Python
привязки для трассировки, заголовка, встроенного и перекрестного доступа. Используйте, когда Клоду нужно:
(1) Чтение/проверка файлов SEG-Y, (2) Извлечение данных трассировки или заголовков, (3) Доступ к 3D-съемке
данные по строкам/перекрестиям, (4) Создание новых файлов SEG-Y из массивов, (5) Изменение существующих
Файлы SEG-Y, (6) Извлечение подмножеств сейсмических данных, (7) Чтение/запись формата Seismic Unix.
