Leggere, scrivere e manipolare file di dati sismici SEG-Y. Libreria C veloce con Python
associazioni per l'accesso a traccia, intestazione, in linea e crossline. Utilizzare quando Claude ha bisogno di:
(1) Leggere/esaminare file SEG-Y, (2) Estrarre dati di traccia o intestazioni, (3) Accedere a rilievi 3D
dati per linea/linea incrociata, (4) Crea nuovi file SEG-Y da array, (5) Modifica esistente
File SEG-Y, (6) Estrarre sottoinsiemi di dati sismici, (7) Leggere/scrivere il formato Unix sismico.
