Leer, escribir y manipular archivos de datos sísmicos SEG-Y. Biblioteca C rápida con Python
enlaces para acceso de seguimiento, encabezado, en línea y entre líneas. Úselo cuando Claude necesite:
(1) Leer/inspeccionar archivos SEG-Y, (2) Extraer datos de seguimiento o encabezados, (3) Acceder a levantamientos 3D
datos por línea/línea cruzada, (4) Crear nuevos archivos SEG-Y a partir de matrices, (5) Modificar los existentes
Archivos SEG-Y, (6) Extraer subconjuntos de datos sísmicos, (7) Leer/escribir formato Seismic Unix.
