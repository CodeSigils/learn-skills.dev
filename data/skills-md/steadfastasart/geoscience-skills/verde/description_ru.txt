Построение пространственных данных в сетку и интерполяцию с помощью API в стиле машинного обучения. Процесс
географические и декартовы точечные данные на регулярных сетках. Используйте, когда Клоду нужно:
(1) Разбросанные по сетке пространственные данные на регулярные сетки, (2) Интерполировать точечные данные с помощью
сплайны, линейные или кубические методы, (3) Обработка географических координат с помощью проекций,
(4) Сократить большие наборы данных, используя усреднение по блокам, (5) Удалить полиномиальные тренды из
пространственные данные, (6) Перекрестная проверка параметров сетки, (7) Создание конвейеров обработки
с цепочкой, (8) Векторные данные сетки, такие как скорости GPS.
