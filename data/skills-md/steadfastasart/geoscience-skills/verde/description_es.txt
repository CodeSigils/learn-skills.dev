Cuadriculado e interpolación de datos espaciales con una API de estilo de aprendizaje automático. Proceso
datos de puntos geográficos y cartesianos en cuadrículas regulares. Úselo cuando Claude necesite:
(1) Datos espaciales dispersos en cuadrículas en cuadrículas regulares, (2) Interpolar datos de puntos usando
métodos splines, lineales o cúbicos, (3) Procesar coordenadas geográficas con proyecciones,
(4) Reducir grandes conjuntos de datos utilizando el promedio de bloques, (5) Eliminar tendencias polinómicas de
datos espaciales, (6) validación cruzada de parámetros de cuadrícula, (7) creación de canales de procesamiento
con Cadena, (8) Datos vectoriales de cuadrícula como velocidades de GPS.
