Rasterung und Interpolation räumlicher Daten mit einer API im Stil maschinellen Lernens. Prozess
geografische und kartesische Punktdaten auf regelmäßigen Gittern. Verwenden Sie es, wenn Claude Folgendes benötigt:
(1) Gitterverstreute räumliche Daten auf regelmäßige Gitter, (2) Interpolieren Sie Punktdaten mit
Splines, lineare oder kubische Methoden, (3) Verarbeiten Sie geografische Koordinaten mit Projektionen,
(4) Reduzieren Sie große Datensätze mithilfe der Blockmittelung, (5) Entfernen Sie Polynomtrends aus
räumliche Daten, (6) Gridding-Parameter kreuzvalidieren, (7) Verarbeitungspipelines erstellen
mit Kette, (8) Gittervektordaten wie GPS-Geschwindigkeiten.
