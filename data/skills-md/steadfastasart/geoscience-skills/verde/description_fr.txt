Maillage et interpolation de données spatiales avec une API de style apprentissage automatique. Processus
données de points géographiques et cartésiens sur des grilles régulières. À utiliser lorsque Claude a besoin de :
(1) Grille les données spatiales dispersées sur des grilles régulières, (2) Interpoler les données ponctuelles en utilisant
méthodes splines, linéaires ou cubiques, (3) Traiter les coordonnées géographiques avec des projections,
(4) Réduisez les grands ensembles de données en utilisant la moyenne de blocs, (5) Supprimez les tendances polynomiales de
données spatiales, (6) Validation croisée des paramètres de maillage, (7) Créer des pipelines de traitement
avec Chain, (8) Données vectorielles de grille telles que les vitesses GPS.
