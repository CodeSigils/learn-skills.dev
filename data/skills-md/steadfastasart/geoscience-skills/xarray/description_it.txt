Array etichettati N-dimensionali per dati di geoscienza. Leggi/scrivi NetCDF, lavora con
set di dati climatici e oceanografici, eseguire analisi multidimensionali con
coordinate etichettate. Da utilizzare quando Claude deve: (1) Leggere/scrivere NetCDF o Zarr
file, (2) lavorare con array multidimensionali con dimensioni etichettate, (3)
Analizzare dati su clima, oceano o atmosfera, (4) Calcolare aggregazioni temporali
(medie giornaliere/mensili/annuali), (5) Eseguire statistiche ponderate per area, (6)
Elabora set di dati di grandi dimensioni con Dask, (7) Applica le convenzioni CF ai dati scientifici.
