Geostatistische Analyse mit der API im Scikit-Learn-Stil. Berechnen Sie Variogramme und Kriging
Interpolation und räumliche Korrelationsanalyse. Verwenden Sie es, wenn Claude Folgendes tun muss: (1) Berechnen
experimentelle Variogramme aus räumlichen Daten, (2) Anpassen von Variogrammmodellen (sphärisch,
exponentiell, Gauß, Matern), (3) Führen Sie eine gewöhnliche oder universelle Kriging-Interpolation durch,
(4) Bewerten Sie die räumliche Anisotropie mit Richtungsvariogrammen, (5) Kreuzvalidieren Sie die räumliche Anisotropie
Modelle, (6) räumlich-zeitliche Daten analysieren, (7) Variogrammparameter für andere exportieren
geostatistische Software.
