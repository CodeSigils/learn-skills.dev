Геостатистический анализ с помощью API в стиле scikit-learn. Расчет вариограмм, кригинг
интерполяция и пространственный корреляционный анализ. Используйте, когда Клоду нужно: (1) Вычислить
экспериментальные вариограммы по пространственным данным, (2) Подбор моделей вариограмм (сферических,
экспоненциальный, гауссовский, материнский), (3) выполнить интерполяцию обычного или универсального кригинга,
(4) Оценить пространственную анизотропию с помощью направленных вариограмм, (5) Перекрестная проверка пространственной
моделей, (6) Анализировать пространственно-временные данные, (7) Экспортировать параметры вариограмм для других
геостатистическое программное обеспечение.
