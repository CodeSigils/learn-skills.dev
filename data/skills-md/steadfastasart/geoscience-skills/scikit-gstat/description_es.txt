Análisis geoestadístico con API estilo scikit-learn. Calcular variogramas, kriging
interpolación y análisis de correlación espacial. Úselo cuando Claude necesite: (1) Calcular
variogramas experimentales a partir de datos espaciales, (2) Ajustar modelos de variogramas (esféricos,
exponencial, gaussiano, materno), (3) Realizar interpolación Kriging ordinaria o universal,
(4) Evaluar la anisotropía espacial con variogramas direccionales, (5) Validar cruzadamente la anisotropía espacial.
modelos, (6) analizar datos espacio-temporales, (7) exportar parámetros de variograma para otros
software geoestadístico.
