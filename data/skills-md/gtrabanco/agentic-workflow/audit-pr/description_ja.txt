PR レベルのマージ ゲート。マージ準備コントラクトに対して (差分だけでなく) 全体のプル リクエストを監査します。 SPEC 受け入れ基準が満たされ、すべてのフェーズが完了し、ドキュメントがドキュメント マップに従って更新され、問題が発生したときに存在する #N をクローズし、適切なレイヤーにテストが追加され、CI がグリーンで、デフォルトのブランチから分岐し独立してマージ可能で、レビュー変更軸がクリーン (または追跡された問題に意識的に延期) されています。判定: マージ準備完了、またはブロッカーのランク付けリスト — 常に PR の完全な URL が出力されます。決して編集しないでください。デフォルトではマージしません。文書化された自動マージ ポリシー (または明示的なユーザー指示) を使用すると、フェールクローズされたマージ前チェックリスト (クリーンなツリー、アンプッシュ/アンプルされていないもの、監査済み SHA 上の新鮮な緑色の CI) の後に MERGE-READY PR がマージされます。 Claude Code を使用していて、スキルごとのモデル/努力レベルを手動で調整したいですか?代わりに `#claude` ブランチをインストールします (`npx skill add gtrabanco/agentic-workflow#claude`)。README を参照してください。このブランチはモデルに依存しません。スキルは、エージェント セッションがすでに使用しているモデルと作業を継承します。トリガー: 「この PR はマージする準備ができていますか」、「PR を監査します」、「#N のマージ ゲート」、「この PR を出荷できますか」、「マージ前レビュー」、「監査 pr」。
