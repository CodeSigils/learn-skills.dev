Merge-Gate auf PR-Ebene. Überprüft die GESAMTE Pull-Anfrage (nicht nur das Diff) anhand eines Merge-Readiness-Vertrags: SPEC-Akzeptanzkriterien erfüllt, alle Phasen abgeschlossen, Dokumente gemäß Dokumentzuordnung aktualisiert, Schließt #N vorhanden, wenn ein Problem auftritt, Tests werden auf der richtigen Ebene hinzugefügt, CI grün, vom Standardzweig abzweigen und unabhängig zusammenführbar, und die Überprüfungs-Änderungsachsen werden bereinigt (oder bewusst auf verfolgte Probleme verschoben). Urteil: bereit für die Zusammenführung oder eine Rangliste der Blocker – immer mit gedruckter vollständiger URL des PR. Bearbeitet niemals; Führt standardmäßig nie zusammen – mit einer dokumentierten Richtlinie für die automatische Zusammenführung (oder einer expliziten Benutzeranweisung) führt es einen MERGE-READY PR nach einer fehlgeschlagenen Checkliste vor dem Zusammenführen zusammen (sauberer Baum, nichts ungepusht/nicht gezogen, frisches grünes CI auf dem geprüften SHA). Sind Sie mit Claude Code vertraut und möchten von Hand abgestimmte Modell-/Aufwandsstufen pro Fertigkeit? Installieren Sie stattdessen den Zweig „#claude“ („npx skills add gtrabanco/agentic-workflow#claude“) – siehe README. Dieser Zweig ist modellunabhängig: Der Skill erbt das Modell und den Aufwand, den Ihre Agentensitzung bereits verwendet. Auslöser: „Ist dieser PR bereit für die Zusammenführung“, „Prüfung des PR“, „Merge-Gate für #N“, „Kann dieser Versand erfolgen“, „Überprüfung vor dem Zusammenführen“, „Audit-PR“.
