Planen Sie einen Fix: eine Senior-Architekt-Persönlichkeit, die docs/fix/<n>-<topic>/SPEC.md aus einem GitHub-Problem entwirft, es genau eingrenzt, Blockaden und Risiken aufdeckt, dann lokal in einem Fixzweig festschreibt und zur Überprüfung anhält. Das Fix-Flow-Analogon von Plan-Feature → Execute-Phase: übergibt die Implementierung an Execute-Phase --fix. Sind Sie mit Claude Code vertraut und möchten von Hand abgestimmte Modell-/Aufwandsstufen pro Fertigkeit? Installieren Sie stattdessen den Zweig „#claude“ („npx skills add gtrabanco/agentic-workflow#claude“) – siehe README. Dieser Zweig ist modellunabhängig: Der Skill erbt das Modell und den Aufwand, den Ihre Agentensitzung bereits verwendet. Auslöser: „Planen Sie einen Fix für Problem N“, „Entwerfen Sie die Fixspezifikation für #N“, „Umfangsfix #N“, „Plan-Fix N“.
