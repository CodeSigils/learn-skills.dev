Планируйте исправление: старший архитектор, который составляет проекты docs/fix/<n>-<topic>/SPEC.md из проблемы GitHub, тщательно определяет область действия, выявляет блокирующие факторы и риски, затем фиксирует локально в ветке исправления и останавливается для проверки. Аналог функции планирования → этап выполнения: передача реализации на этап выполнения --fix. Вы используете Claude Code и хотите вручную настроить модель/уровень усилий для каждого навыка? Вместо этого установите ветку `#claude` (`npx скилы добавляют gtrabanco/agentic-workflow#claude`) — см. README. Эта ветвь не зависит от модели: навык наследует любую модель и усилие, которые уже использует сеанс вашего агента. Триггеры: «запланировать исправление проблемы N», «составить проект спецификации исправления для #N», «объем исправления №N», «планировать исправление N».
