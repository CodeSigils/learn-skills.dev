Plan a fix: a senior-architect persona that drafts docs/fix/<n>-<topic>/SPEC.md from a GitHub issue, scopes it tightly, surfaces blockers and risks, then commits locally on a fix branch and stops for review. The fix-flow analogue of plan-feature → execute-phase: hands implementation off to execute-phase --fix. On Claude Code and want hand-tuned per-skill model/effort tiers? Install the `#claude` branch instead (`npx skills add gtrabanco/agentic-workflow#claude`) — see the README. This branch is model-agnostic: the skill inherits whatever model and effort your agent session is already using. Triggers: "plan a fix for issue N", "draft the fix spec for #N", "scope fix #N", "plan-fix N".
