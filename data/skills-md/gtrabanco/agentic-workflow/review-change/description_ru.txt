Адаптивный к платформе оркестратор проверки. Проверяет текущее изменение путем запуска проверки-реализации (найти → классифицировать) И собственного внутреннего пакета проверки рабочего процесса — только те этапы, которые применимы к этому проекту и этому изменению (проверка-код, проверка-безопасность, проверка-проверка, проверка-долг, проверка-дизайн, проверка-a11y, проверка-бренд, проверка-perf, проверка-seo) — никогда не применимые (нет a11y/SEO/бренд для CLI, библиотеки или инфра изменение). Автономность: не требуются навыки внешней проверки; установленные навыки платформы работают как дополнительные дополнения. Синтезирует один секретный отчет и подробный контрольный список для ручной проверки. Только выводы — никогда не рефакторинг. Вы используете Claude Code и хотите вручную настроить модель/уровень усилий для каждого навыка? Вместо этого установите ветку #claude (навыки npx добавляют gtrabanco/agentic-workflow#claude) — см. README. Эта ветвь не зависит от модели: навык наследует любую модель и усилие, которые уже использует сеанс вашего агента. Триггеры: «проверьте это изменение», «полная проверка перед слиянием», «проверка-изменение», «проведите правильные проверки для этого», «что мне следует проверить перед PR».
