Orquestador de revisión adaptable a la plataforma. Revisa el cambio actual ejecutando revisión-implementación (buscar → clasificar) Y el propio paquete de revisión interna del flujo de trabajo, solo los pases que se aplican a este proyecto y este cambio (revisión-código, revisión-seguridad, revisión-verificación, revisión-deuda, revisión-diseño, revisión-a11y, revisión-marca, revisión-perf, revisión-seo) - nunca los no aplicables (no a11y/SEO/marca para un CLI, biblioteca o cambio de infraestructura). Autónomo: no se requieren habilidades de revisión externa; Las habilidades de plataforma instaladas se ejecutan como extras opcionales. Sintetiza un informe clasificado más una lista de verificación manual explícita. Sólo hallazgos, nunca refactorizaciones. ¿Estás en Claude Code y quieres niveles de esfuerzo/modelo por habilidad ajustados manualmente? En su lugar, instale la rama `#claude` (`npx skills add gtrabanco/agentic-workflow#claude`): consulte el archivo README. Esta rama es independiente del modelo: la habilidad hereda cualquier modelo y esfuerzo que la sesión de su agente ya esté utilizando. Activadores: "revisar este cambio", "revisión completa antes de la fusión", "revisar-cambio", "ejecutar las revisiones correctas para esto", "qué debo verificar antes de las relaciones públicas".
