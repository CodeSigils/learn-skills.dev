プラットフォームに適応したレビュー オーケストレーター。 review-implementation (検索→分類) とワークフロー独自の内部レビュー パックを実行して、現在の変更をレビューします。このプロジェクトとこの変更に適用されるパスのみ (review-code、review-security、review-verify、review-debt、review-design、review-a11y、review-brand、review-perf、review-seo) を実行します。適用できないパス (CLI、ライブラリ、またはインフラ変更の a11y/SEO/brand はありません) は決してレビューしません。自己完結型: 外部レビューのスキルは必要ありません。インストールされたプラットフォーム スキルは、オプションのエクストラとして実行されます。 1 つの機密レポートと明示的な手動検証チェックリストを統合します。結果のみを表示し、リファクタリングは行いません。 Claude Code を使用していて、スキルごとのモデル/努力レベルを手動で調整したいですか?代わりに `#claude` ブランチをインストールします (`npx skill add gtrabanco/agentic-workflow#claude`)。README を参照してください。このブランチはモデルに依存しません。スキルは、エージェント セッションがすでに使用しているモデルと作業を継承します。トリガー: 「この変更をレビューする」、「マージ前の完全なレビュー」、「レビュー変更」、「これに対して適切なレビューを実行する」、「PR の前に何を確認する必要があるか」。
