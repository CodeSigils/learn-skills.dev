Auditer la cohérence entre documents : documents ↔ feuille de route ↔ code ↔ index de correction ↔ problèmes. Détecte les dérives : fonctionnalités dans la documentation/pas dans la feuille de route (ou vice versa), correction des entrées d'index déjà fusionnées/fermées, liens de carte de documentation rompus, cycles de dépendance, artefacts dans la mauvaise langue, violations des conventions de dénomination – et les signale classés par gravité, en corrigeant uniquement les éléments à faible risque sur demande. Vous utilisez Claude Code et souhaitez des modèles/niveaux d'effort ajustés manuellement par compétence ? Installez plutôt la branche `#claude` (`npx skills add gtrabanco/agentic-workflow#claude`) — voir le README. Cette branche est indépendante du modèle : la compétence hérite du modèle et de l'effort que votre session d'agent utilise déjà. Déclencheurs : "vérifier la cohérence de la documentation", "les documents sont-ils synchronisés", "auditer la documentation", "révision de la cohérence de la documentation", "la documentation a-t-elle dérivé", "valider la feuille de route".
