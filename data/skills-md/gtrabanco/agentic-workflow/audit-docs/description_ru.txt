Аудит согласованности документов: документы ↔ дорожная карта ↔ код ↔ исправление индекса ↔ проблемы. Находит отклонения — функции в документации/отсутствуют в дорожной карте (или наоборот), уже объединенные/закрытые записи исправленного индекса, неработающие ссылки на карту документации, циклы зависимостей, артефакты на неправильном языке, нарушения соглашений об именах — и сообщает о них, ранжируя их по серьезности, исправляя только элементы с низким уровнем риска по запросу. README. Эта ветвь не зависит от модели: навык наследует любую модель и усилие, которые уже использует сеанс вашего агента.
