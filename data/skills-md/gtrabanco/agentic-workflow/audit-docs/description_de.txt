Prüfen Sie die dokumentübergreifende Kohärenz: Dokumente ↔ Roadmap ↔ Code ↔ Fixindex ↔ Probleme. Findet Abweichungen – Funktionen in Dokumenten/nicht in der Roadmap (oder umgekehrt), Fix-Index-Einträge, die bereits zusammengeführt/geschlossen wurden, defekte Dokumentations-Map-Links, Abhängigkeitszyklen, Artefakte in der falschen Sprache, Verstöße gegen Namenskonventionen – und meldet sie nach Schweregrad geordnet, wobei auf Anfrage nur Elemente mit geringem Risiko behoben werden. Sind Sie mit Claude Code vertraut und möchten von Hand abgestimmte Modell-/Aufwandsstufen pro Fertigkeit? Installieren Sie stattdessen den Zweig „#claude“ („npx skills add gtrabanco/agentic-workflow#claude“) – siehe README. Dieser Zweig ist modellunabhängig: Der Skill erbt das Modell und den Aufwand, den Ihre Agentensitzung bereits verwendet. Auslöser: „Überprüfen Sie die Konsistenz der Dokumente“, „Sind die Dokumente synchron“, „Prüfen Sie die Dokumente“, „Überprüfen Sie die Kohärenz der Dokumente“, „Wurden die Dokumente verschoben“, „Validieren Sie die Roadmap“.
