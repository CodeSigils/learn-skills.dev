Ajoutez une entrée structurée au journal de session du projet (`docs/LOGS.md`) : ce qui a été fait cette session, les fichiers touchés, les décisions prises et l'étape suivante — afin que la session suivante (ou une autre personne) puisse reprendre le fil de discussion sans relire l'historique de git. Exécutez-le avant `/clear`, avant de fermer Claude Code ou à tout point d'arrêt naturel. Vous utilisez Claude Code et souhaitez des modèles/niveaux d'effort ajustés manuellement par compétence ? Installez plutôt la branche `#claude` (`npx skills add gtrabanco/agentic-workflow#claude`) — voir le README. Cette branche est indépendante du modèle : la compétence hérite du modèle et de l'effort que votre session d'agent utilise déjà. Déclencheurs : "enregistrer cette session", "enregistrer la session", "écrire un journal de session", "journaliser ce que nous avons fait", "enregistrer cette session avant d'effacer", "enregistrer le résumé de la session".
