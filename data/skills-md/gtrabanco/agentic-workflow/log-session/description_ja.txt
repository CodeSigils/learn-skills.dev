構造化されたエントリをプロジェクトのセッション ログ (`docs/LOGS.md`) に追加します。このセッションで行われた内容、操作されたファイル、下された決定、次のステップなどです。これにより、次のセッション (または別の人) が git 履歴を再読まずにスレッドを取得できるようになります。 `/clear` の前、クロード コードを閉じる前、または自然な停止ポイントで実行してください。 Claude Code を使用していて、スキルごとのモデル/努力レベルを手動で調整したいですか?代わりに `#claude` ブランチをインストールします (`npx skill add gtrabanco/agentic-workflow#claude`)。README を参照してください。このブランチはモデルに依存しません。スキルは、エージェント セッションがすでに使用しているモデルと作業を継承します。トリガー: 「このセッションをログに記録する」、「log-session」、「セッション ログを書き込む」、「何をしたかを記録する」、「クリアする前にこのセッションを記録する」、「セッションの概要を保存する」。
