Загрузите способ работы проекта: возьмите шаблон документации по агентному рабочему процессу (шаблон/) и адаптируйте его к ЭТОМУ проекту на собеседовании — заполните карту документации CLAUDE.md, команды Gate и архитектуру, удалите ненужные папки документации, сохраните шаблоны SPEC/feature/fix и GitHub — затем предложите установить необходимые навыки. Адаптивный аналог необработанной копии npx degit. Вы используете Claude Code и хотите вручную настроить модель/уровень усилий для каждого навыка? Вместо этого установите ветку `#claude` (`npx скилы добавляют gtrabanco/agentic-workflow#claude`) — см. README. Эта ветвь не зависит от модели: навык наследует любую модель и усилие, которые уже использует сеанс вашего агента. Триггеры: «настройте агентный рабочий процесс здесь», «init-workspace», «подготовьте документацию этого проекта», «адаптируйте шаблон рабочего процесса к этому репозиторию», «загрузите способ работы».
