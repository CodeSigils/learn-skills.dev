Classez un problème et prenez une décision défendable : résoudre maintenant, reporter (différé/basé sur un déclencheur), ne pas résoudre ou promouvoir une fonctionnalité. Lit le « quand résoudre »/le déclencheur et la gravité du problème, vérifie le déclencheur par rapport à la base de code ACTUELLE (compte les consommateurs, vérifie les seuils, les mesures), puis achemine ou rapporte avec un commentaire daté et vérifiable. Vous utilisez Claude Code et souhaitez des modèles/niveaux d'effort ajustés manuellement par compétence ? Installez plutôt la branche `#claude` (`npx skills add gtrabanco/agentic-workflow#claude`) — voir le README. Cette branche est indépendante du modèle : la compétence hérite du modèle et de l'effort que votre session d'agent utilise déjà. Déclencheurs : "triage du problème N", "devrions-nous résoudre #N maintenant", "classer ce problème", "le déclencheur de #N est-il satisfait", "que faisons-nous avec #N".
