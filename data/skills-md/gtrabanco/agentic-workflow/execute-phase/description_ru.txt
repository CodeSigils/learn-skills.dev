Реализация одной фазы функции (по умолчанию), сквозной небольшой функции за один проход (только SPEC, без артефактов планирования) или исправление (--fix). Обеспечивает безопасность филиалов, политику проблем, шлюз проверки проекта и дисциплину документации на каждом этапе. Вы используете Claude Code и хотите вручную настроить модель/уровень усилий для каждого навыка? Вместо этого установите ветку `#claude` (`npx скилы добавляют gtrabanco/agentic-workflow#claude`) — см. README. Эта ветвь не зависит от модели: навык наследует любую модель и усилие, которые уже использует сеанс вашего агента. Триггеры: «выполнение фазы P1 NN», «реализовать функцию NN», «построить NN на основе ее спецификации», «фаза выполнения NN P2», «фаза выполнения --fix».
