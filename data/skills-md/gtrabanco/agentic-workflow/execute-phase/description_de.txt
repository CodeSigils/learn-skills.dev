Implementieren Sie eine Phase eines Features (Standard), ein kleines Feature durchgängig in einem einzigen Durchgang (nur SPEC, keine Planungsartefakte) oder einen Fix (--fix). Erzwingt die Zweigstellensicherheit, die Issue-Richtlinie, das Verifizierungs-Gate des Projekts und die Dokumentendisziplin pro Phase. Sind Sie mit Claude Code vertraut und möchten von Hand abgestimmte Modell-/Aufwandsstufen pro Fertigkeit? Installieren Sie stattdessen den Zweig „#claude“ („npx skills add gtrabanco/agentic-workflow#claude“) – siehe README. Dieser Zweig ist modellunabhängig: Der Skill erbt das Modell und den Aufwand, den Ihre Agentensitzung bereits verwendet. Auslöser: „Phase P1 von NN ausführen“, „NN-Funktion implementieren“, „NN aus seiner Spezifikation erstellen“, „Phase NN P2 ausführen“, „Phase ausführen --fix“.
