Ein Einstiegspunkt zum Planen einer Funktion. Erkennt die Eingabe – eine Rohidee (Interview), ein GitHub-Issue #N (Issue → SPEC mit Gültigkeitsbereich) oder ein Slug/SPEC mit bereits Gültigkeitsbereich (direkt zum Gerüst) – leitet sie zum richtigen internen Schritt weiter, stellt dann den Roadmap-Eintrag sicher und druckt den nächsten Schritt. Erzwingen Sie einen Pfad mit Flags, um die Erkennung zu überspringen. „--next“ plant das nächste geplante Feature aus der Roadmap. Sind Sie mit Claude Code vertraut und möchten von Hand abgestimmte Modell-/Aufwandsstufen pro Fertigkeit? Installieren Sie stattdessen den Zweig „#claude“ („npx skills add gtrabanco/agentic-workflow#claude“) – siehe README. Dieser Zweig ist modellunabhängig: Der Skill erbt das Modell und den Aufwand, den Ihre Agentensitzung bereits verwendet. Auslöser: „Planen Sie ein Feature“, „Planen Sie das Feature ab Issue N“, „Planen Sie das nächste Roadmap-Feature“, „Gerüst-Feature NN“, „Ich habe eine Idee, planen Sie sie“, „Erstellen Sie SPEC und AUFGABEN für NN“.
