Одна точка входа для планирования функции. Обнаруживает входные данные — необработанную идею (интервью), проблему GitHub #N (проблема → SPEC с областью действия) или пул/SPEC с уже заданной областью действия (прямо в строительные леса) — направляет к нужному внутреннему шагу, затем обеспечивает запись в дорожной карте и печатает следующий шаг. Принудительно указать путь с флагами, чтобы пропустить обнаружение; `--next` планирует следующую запланированную функцию из дорожной карты. Вы используете Claude Code и хотите вручную настроить модель/уровень усилий для каждого навыка? Вместо этого установите ветку `#claude` (`npx скилы добавляют gtrabanco/agentic-workflow#claude`) — см. README. Эта ветвь не зависит от модели: навык наследует любую модель и усилие, которые уже использует сеанс вашего агента. Триггеры: «запланировать функцию», «запланировать функцию из проблемы N», «запланировать следующую функцию дорожной карты», «функция каркаса NN», «у меня есть идея, спланируйте ее», «создать СПЕЦИАЛИЗАЦИЯ и ЗАДАЧИ для NN».
