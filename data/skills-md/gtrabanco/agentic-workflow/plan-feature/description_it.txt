Un punto di ingresso per pianificare una funzionalità. Rileva l'input: un'idea grezza (intervista), un problema GitHub n. N (problema → SPEC con ambito) o uno slug/SPEC con ambito già (direttamente allo scaffolding) - indirizza al passaggio interno corretto, quindi garantisce la voce della roadmap e stampa il passaggio successivo. Forza un percorso con flag per ignorare il rilevamento; "--next" pianifica la successiva funzionalità pianificata dalla roadmap. Sei su Claude Code e desideri livelli di modello/impegno ottimizzati manualmente in base alle competenze? Installa invece il ramo `#claude` (`npx skills add gtrabanco/agentic-workflow#claude`) — consulta il file README. Questo ramo è indipendente dal modello: la competenza eredita qualunque modello e sforzo stia già utilizzando la sessione dell'agente.
