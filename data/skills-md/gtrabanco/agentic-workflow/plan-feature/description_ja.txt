機能を計画するための 1 つのエントリ ポイント。入力 (生のアイデア (インタビュー)、GitHub の課題 #N (課題 → スコープ指定された SPEC)、またはすでにスコープ指定されたスラッグ/SPEC (スキャフォールディングへのストレート)) を検出し、適切な内部ステップにルーティングし、ロードマップ エントリを確保して次のステップを出力します。検出をスキップするフラグを持つパスを強制します。 「--next」は、ロードマップから次に計画されている機能を計画します。 Claude Code を使用していて、スキルごとのモデル/努力レベルを手動で調整したいですか?代わりに `#claude` ブランチをインストールします (`npx skill add gtrabanco/agentic-workflow#claude`)。README を参照してください。このブランチはモデルに依存しません。スキルは、エージェント セッションがすでに使用しているモデルと作業を継承します。トリガー: 「機能を計画する」、「課題 N から機能を計画する」、「次のロードマップ機能を計画する」、「スキャフォールド機能 NN」、「アイデアがあるので計画する」、「NN の SPEC と TASKS を作成する」。
