Competenza interna per il repository del flusso di lavoro agentic. Dopo aver modificato uno o più file SKILL.md, aumenta i campi "version:" e aggiorna ogni parte della documentazione nel repository che deve rimanere sincronizzata: CHANGELOG.md, CHANGELOG.es.md, README.md e README.es.md. Corri prima di effettuare qualsiasi cambio di abilità. Sei su Claude Code e desideri livelli di modello/impegno ottimizzati manualmente in base alle competenze? Installa invece il ramo `#claude` (`npx skills add gtrabanco/agentic-workflow#claude`) — consulta il file README. Questo ramo è indipendente dal modello: la competenza eredita qualunque modello e sforzo stia già utilizzando la sessione dell'agente. Frasi trigger: "aumento della versione della competenza", "aggiorna la versione", "aggiorna il registro delle modifiche", "ho appena modificato una competenza", "registra questa modifica", "aumento della versione".
