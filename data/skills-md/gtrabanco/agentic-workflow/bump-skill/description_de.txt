Interner Skill für das Agent-Workflow-Repo. Nach der Bearbeitung einer oder mehrerer SKILL.md-Dateien werden deren „Version:“-Felder erweitert und alle Dokumentationen im Repo aktualisiert, die synchron bleiben müssen: CHANGELOG.md, CHANGELOG.es.md, README.md und README.es.md. Laufen Sie, bevor Sie eine Fertigkeitsänderung vornehmen. Sind Sie mit Claude Code vertraut und möchten von Hand abgestimmte Modell-/Aufwandsstufen pro Fertigkeit? Installieren Sie stattdessen den Zweig „#claude“ („npx skills add gtrabanco/agentic-workflow#claude“) – siehe README. Dieser Zweig ist modellunabhängig: Der Skill erbt das Modell und den Aufwand, den Ihre Agentensitzung bereits verwendet. Auslöserphrasen: „Skill-Version erhöhen“, „Version aktualisieren“, „Änderungsprotokoll aktualisieren“, „Ich habe gerade einen Skill geändert“, „Diese Änderung protokollieren“, „Versions-Upgrade“.
