End-to-End-Autopilot: Finden Sie das Projekt bei Bedarf (ein Vorgespräch – Produkt, Funktionen, Stack, Architektur, Qualitätsindikatoren, Betrieb, Autonomie, Budget), erstellen oder übernehmen Sie die vollständige Roadmap und versenden Sie es dann Feature für Feature durch den gesamten Workflow (Plan → Ausführen → Überprüfen → PR → Merge-Gate), gesteuert von /loop, ohne weitere Fragen. Funktionen erschöpft ≠ überlaufen: Bei einem Issue-Sweep werden dann offene Probleme sowie die dokumentierten Rückstände des Laufs (bekannte Probleme, Kompromisse, verschobene Ergebnisse) inventarisiert, alles selektiert und die jetzt behobenen Probleme durch dieselben Phasen geschickt. Standard: öffnet PRs, der Mensch verschmilzt; --fullauto führt MERGE-READY-PRs unter nicht verhandelbaren Sicherheitsuntergrenzen zusammen. Sind Sie mit Claude Code vertraut und möchten von Hand abgestimmte Modell-/Aufwandsstufen pro Fertigkeit? Installieren Sie stattdessen den Zweig „#claude“ („npx skills add gtrabanco/agentic-workflow#claude“) – siehe README. Dieser Zweig ist modellunabhängig: Der Skill erbt das Modell und den Aufwand, den Ihre Agentensitzung bereits verwendet. Auslöser: „Roadmap versenden“, „Gesamte App anhand der Roadmap erstellen“, „Vollständigen Workflow auf Autopilot ausführen“, „Roadmap versenden“, „Dieses Projekt automatisch steuern“.
