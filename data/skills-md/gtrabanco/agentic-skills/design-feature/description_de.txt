Verwandeln Sie eine Idee oder eine Funktionsanfrage in eine umfassende, überprüfbare Produktdefinition – die Phase vor der technischen Planung. Der Kernmechanismus ist **Fähigkeitsabschluss**: eine Checkliste, die erzwingt, dass jede Entität, Fähigkeit und Rolle, die ein Feature einführt, vollständig umgesetzt wird (CRUD + Zustandsübergänge + UI-Einstiegspunkt + API + Test oder ein explizites Design-Time-„n/a“), sodass Nicht-Frontier-Executor-Modelle die implizite Arbeit nicht mehr stillschweigend weglassen („Authentifizierung mit Dashboard-Verwaltung und ACLs“ darf nicht auf eine Benutzertabelle + eine Listenansicht reduziert werden). Der Abschluss verfügt über drei feste Checklisten: **Entitätsabschluss** (jede Entität auf voller Oberfläche), **Integrationsabschluss** (die Funktion, die mit jedem Subsystem im Fähigkeitsinventar des Projekts abgeglichen wird, „docs/CAPABILITIES.md“ – Authentifizierung, ACL, Navigation, Benachrichtigungen, …) und die **Rollenmatrix** (jede Inventarrolle, die pro Fähigkeit explizit erlaubt/verweigert wird) – plus ein **Erwartungsdurchlauf**, der erzwingt, was ein kompetenter Mensch implizit annehmen würde („a Blog hat Entwürfe“) in „im Geltungsbereich/außerhalb des Geltungsbereichs/aufgeschoben“, niemals unausgesprochen gelassen. Schreibt die **Produkthälfte** der SPEC und stempelt den „## Designstatus: entworfen“-Marker, den „plan-feature“ liest, bevor die technische Hälfte eines Features geplant wird. Bare „design-feature <slug>“ überprüft und fragt, was geändert werden soll; „design-feature <slug> <instruction>“ wendet eine Änderung direkt an. Sind Sie mit Claude Code vertraut und möchten von Hand abgestimmte Modell-/Aufwandsstufen pro Fertigkeit? Installieren Sie stattdessen den Zweig „#claude“ („npx skills add gtrabanco/agentic-workflow#claude“) – siehe README. Dieser Zweig ist modellunabhängig: Der Skill erbt das Modell und den Aufwand, den Ihre Agentensitzung bereits verwendet. Auslöser: „Feature hinzufügen“, „Feature hinzufügen“, „Neues Feature“, „Feature entwerfen“, „die Produkthälfte von NN entwerfen“, „Fähigkeitsabschluss für NN“, „Feature vor der Planung definieren“.
