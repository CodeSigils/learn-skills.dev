Сквозной автопилот: при необходимости найдите проект (одно предварительное собеседование — продукт, функции, стек, архитектура, показатели качества, операции, автономность, бюджет), создайте или примите полную дорожную карту, затем отправьте его по функциям через весь рабочий процесс (план → выполнение → обзор → PR → слияние), управляемый /loop, внешним оркестратором (см. docs/workflow/ORCHESTRATION.md) или повторным вызовом вручную без дополнительных вопросов. Исчерпаны функции ≠ прогон: проверка проблем, затем инвентаризация открытых проблем плюс собственные задокументированные остатки прогона (известные проблемы, компромиссы, отложенные выводы), все сортируется и отправляет исправленные проблемы через те же этапы. По умолчанию: открывает ПР, человек сливается; --fullauto объединяет PR-запросы MERGE-READY в рамках необсуждаемых минимальных уровней безопасности. Вы используете Claude Code и хотите вручную настроить модель/уровень усилий для каждого навыка? Вместо этого установите ветку #claude (навыки npx добавляют gtrabanco/agentic-workflow#claude) — см. README. Эта ветвь не зависит от модели: навык наследует любую модель и усилие, которые уже использует сеанс вашего агента. Триггеры: «отправить дорожную карту», ​​«создать все приложение на основе дорожной карты», «запустить весь рабочий процесс на автопилоте», «отправить дорожную карту», ​​«автопилотировать этот проект».
