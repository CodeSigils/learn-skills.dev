エンドツーエンドの自動操縦: 必要に応じてプロジェクトを見つけ (製品、機能、スタック、アーキテクチャ、品質バー、運用、自律性、予算などの 1 回の事前インタビュー)、完全なロードマップを作成または採用してから、/loop、外部オーケストレーター (docs/workflow/ORCHESTRATION.md を参照)、または手動での再呼び出しによって駆動される完全なワークフロー (計画 → 実行 → レビュー → PR → マージ ゲート) を通じて機能ごとに出荷します。これ以上の質問は必要ありません。使い果たされた機能 ≠ やりすぎた機能: 問題のスイープにより、未解決の問題と実行自体の文書化された残余 (既知の問題、トレードオフ、延期された結果) がインベントリされ、すべてがトリアージされ、同じ段階で今すぐ修正される問題が出荷されます。デフォルト: PR を開き、人間がマージします。 --fullauto は、交渉不可能な安全フロアの下で MERGE-READY PR をマージします。 Claude Code を使用していて、スキルごとのモデル/努力レベルを手動で調整したいですか?代わりに `#claude` ブランチをインストールします (`npx skill add gtrabanco/agentic-workflow#claude`)。README を参照してください。このブランチはモデルに依存しません。スキルは、エージェント セッションがすでに使用しているモデルと作業を継承します。トリガー: 「ロードマップを出荷する」、「ロードマップからアプリ全体を構築する」、「自動操縦で完全なワークフローを実行する」、「ロードマップを出荷する」、「このプロジェクトを自動操縦する」。
