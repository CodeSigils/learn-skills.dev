Pilote automatique de bout en bout : trouvez le projet si nécessaire (un entretien initial - produit, fonctionnalités, pile, architecture, barres de qualité, opérations, autonomie, budget), créez ou adoptez la feuille de route complète, puis expédiez-le fonctionnalité par fonctionnalité via le flux de travail complet (planifier → exécuter → révision → PR → porte de fusion) piloté par /loop, un orchestrateur externe (voir docs/workflow/ORCHESTRATION.md), ou une réinvocation manuelle, sans autres questions. Fonctionnalités épuisées ≠ exécution : un balayage des problèmes, puis inventorie les problèmes ouverts ainsi que les propres résidus documentés de l'exécution (problèmes connus, compromis, résultats reportés), trie tout et expédie les problèmes résolus maintenant à travers les mêmes étapes. Par défaut : ouvre les PR, l'humain fusionne ; --fullauto fusionne les PR MERGE-READY sous des planchers de sécurité non négociables. Vous utilisez Claude Code et souhaitez des modèles/niveaux d'effort ajustés manuellement par compétence ? Installez plutôt la branche `#claude` (`npx skills add gtrabanco/agentic-workflow#claude`) — voir le README. Cette branche est indépendante du modèle : la compétence hérite du modèle et de l'effort que votre session d'agent utilise déjà. Déclencheurs : « expédier la feuille de route », « créer l'intégralité de l'application à partir de la feuille de route », « exécuter le flux de travail complet sur le pilote automatique », « expédier la feuille de route », « piloter automatiquement ce projet ».
