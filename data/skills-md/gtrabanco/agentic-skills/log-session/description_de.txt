Hängen Sie einen strukturierten Eintrag an das Sitzungsprotokoll des Projekts (`docs/LOGS.md`) an: Was wurde in dieser Sitzung getan, welche Dateien wurden berührt, welche Entscheidungen getroffen wurden und was der nächste Schritt ist – damit die nächste Sitzung (oder eine andere Person) den Thread aufgreifen kann, ohne den Git-Verlauf erneut zu lesen. Führen Sie es vor „/clear“, vor dem Schließen von Claude Code oder an einem beliebigen natürlichen Stopppunkt aus. Sind Sie mit Claude Code vertraut und möchten von Hand abgestimmte Modell-/Aufwandsstufen pro Fertigkeit? Installieren Sie stattdessen den Zweig „#claude“ („npx skills add gtrabanco/agentic-workflow#claude“) – siehe README. Dieser Zweig ist modellunabhängig: Der Skill erbt das Modell und den Aufwand, den Ihre Agentensitzung bereits verwendet. Auslöser: „Diese Sitzung protokollieren“, „Sitzung protokollieren“, „Sitzungsprotokoll schreiben“, „Aufzeichnen, was wir getan haben“, „Diese Sitzung aufzeichnen, bevor ich sie lösche“, „Sitzungszusammenfassung speichern“.
