プロジェクトの作業方法をブートストラップします。エージェント ワークフローのドキュメント スキャフォールド (template/) を取得し、インタビューによってそれをこのプロジェクトに適応させます。CLAUDE.md ドキュメント マップを埋め、コマンドとアーキテクチャをゲートし、適用されないドキュメント フォルダーを削除し、SPEC/feature/fix および GitHub テンプレートを保持します。その後、スキルのインストールを提案します。生の `npx degit` コピーに対応する適応型。すでにスキャフォールドがあるリポジトリでは、それを検出して **アップグレード モード**に切り替えます。プロジェクトのサブストレートを現在のテンプレートと比較し、「docs/workflow/MIGRATION.md」を読み取り、プロジェクトに不足しているブロックのみを提案します。カスタマイズされたブロックを壊すことはありません。 Claude Code を使用していて、スキルごとのモデル/努力レベルを手動で調整したいですか?代わりに `#claude` ブランチをインストールします (`npx skill add gtrabanco/agentic-workflow#claude`)。README を参照してください。このブランチはモデルに依存しません。スキルは、エージェント セッションがすでに使用しているモデルと作業を継承します。トリガー: 「ここでエージェント ワークフローをセットアップする」、「init-workspace」、「このプロジェクトのドキュメントをスキャフォールディングする」、「ワークフロー テンプレートをこのリポジトリに適合させる」、「作業方法をブートストラップする」、「スキャフォールドをアップグレードする」、「基板を現在のテンプレートに移行する」、「テンプレートを使用して CLAUDE.md を最新の状態にする」。
