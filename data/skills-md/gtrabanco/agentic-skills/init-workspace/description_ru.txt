Загрузите способ работы проекта: возьмите шаблон документации по агентному рабочему процессу (шаблон/) и адаптируйте его к ЭТОМУ проекту на собеседовании — заполните карту документации CLAUDE.md, команды Gate и архитектуру, удалите ненужные папки документации, сохраните шаблоны SPEC/feature/fix и GitHub — затем предложите установить необходимые навыки. Адаптивный аналог необработанной копии npx degit. В репозитории, в котором уже есть каркас, обнаруживает его и переключается в **режим обновления**: сравнивает подложку проекта с текущим шаблоном, читает `docs/workflow/MIGRATION.md` и предлагает только те блоки, которые отсутствуют в проекте — никогда не затирая адаптированный. Вы используете Claude Code и хотите вручную настроить модель/уровень усилий для каждого навыка? Вместо этого установите ветку #claude (навыки npx добавляют gtrabanco/agentic-workflow#claude) — см. README. Эта ветвь не зависит от модели: навык наследует любую модель и усилие, которые уже использует сеанс вашего агента. Триггеры: «настройте агентный рабочий процесс здесь», «init-workspace», «подготовьте документацию этого проекта», «адаптируйте шаблон рабочего процесса к этому репозиторию», «загрузите способ работы», «обновите мой каркас», «перенесите мой субстрат в текущий шаблон», «обновите мой CLAUDE.md с помощью шаблона».
