Démarrez la méthode de travail d'un projet : récupérez l'échafaudage de documentation du flux de travail agent (template/) et adaptez-le à CE projet par entretien - remplissez la carte de documentation CLAUDE.md, les commandes et l'architecture de la porte, supprimez les dossiers doc qui ne s'appliquent pas, conservez les modèles SPEC/feature/fix et GitHub - puis proposez d'installer les compétences. La contrepartie adaptative d'une copie brute `npx degit`. Sur un dépôt qui possède déjà l'échafaudage, le détecte et passe en **mode de mise à niveau** : compare le substrat du projet au modèle actuel, lit `docs/workflow/MIGRATION.md` et propose uniquement les blocs manquants au projet — sans jamais en écraser un sur mesure. Vous utilisez Claude Code et souhaitez des modèles/niveaux d'effort ajustés manuellement par compétence ? Installez plutôt la branche `#claude` (`npx skills add gtrabanco/agentic-workflow#claude`) — voir le README. Cette branche est indépendante du modèle : la compétence hérite du modèle et de l'effort que votre session d'agent utilise déjà. Déclencheurs : "configurer le workflow agent ici", "init-workspace", "échafauder la documentation de ce projet", "adapter le modèle de workflow à ce dépôt", "amorcer la méthode de travail", "mettre à niveau mon échafaudage", "migrer mon substrat vers le modèle actuel", "mettre mon CLAUDE.md à jour avec le modèle".
