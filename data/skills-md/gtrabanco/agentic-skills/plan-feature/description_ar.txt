جهاز توجيه للتخطيط الهندسي لميزة مصممة بالفعل. نظرًا لميزة لم يتم وضع علامة "مصمم" على نصف منتج SPEC الخاص بها، يتم إيقافها وإعادة توجيهها إلى `/design-feature <slug>` - لا توجد علامة تجاوز. في ضوء ميزة مصممة، إصدار GitHub #N (المشكلة ← نصف المنتج المحدد، إغلاق القدرة المُرضي)، أو سبيكة/SPEC محددة النطاق بالفعل (مباشرة إلى نصف السقالات الهندسية)، يوجه إلى الخطوة الداخلية الصحيحة، ثم يضمن إدخال خريطة الطريق ويطبع الخطوة التالية. فرض مسار باستخدام الأعلام لتخطي الاكتشاف؛ يخطط `--next` للميزة `المحددة` التالية من خريطة الطريق. هل أنت على Claude Code وتريد مستويات نموذج/جهد تم ضبطها يدويًا لكل مهارة؟ قم بتثبيت الفرع `#claude` بدلاً من ذلك (`إضافة مهارات npx gtrabanco/agentic-workflow#claude`) - راجع ملف README. هذا الفرع لا يعتمد على النموذج: ترث المهارة أي نموذج أو جهد تستخدمه جلسة وكيلك بالفعل. المشغلات: "تخطيط ميزة"، "تخطيط الميزة من الإصدار N"، "التخطيط لميزة خريطة الطريق التالية"، "ميزة السقالة NN"، "إنشاء SPEC ومهام لـ NN".
