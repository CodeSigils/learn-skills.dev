すでに設計された機能のエンジニアリングプランニングルーター。 SPEC 製品の半分が「designed」とマークされていないフィーチャーを指定すると、停止して `/design-feature <slug>` にリダイレクトされます (バイパス フラグはありません)。設計された機能が与えられた場合、GitHub の課題 #N (問題→スコープが設定された製品の半分、満足のいく機能のクロージャ)、またはすでにスコープが設定されたスラグ/SPEC (エンジニアリングの半分のスキャフォールディングに直接) は、適切な内部ステップにルーティングされ、ロードマップのエントリが確保されて次のステップが出力されます。検出をスキップするフラグを持つパスを強制します。 「--next」は、ロードマップから次の「定義された」機能を計画します。 Claude Code を使用していて、スキルごとのモデル/努力レベルを手動で調整したいですか?代わりに `#claude` ブランチをインストールします (`npx skill add gtrabanco/agentic-workflow#claude`)。README を参照してください。このブランチはモデルに依存しません。スキルは、エージェント セッションがすでに使用しているモデルと作業を継承します。トリガー: 「機能を計画する」、「課題 N から機能を計画する」、「次のロードマップ機能を計画する」、「スキャフォールド機能 NN」、「NN の SPEC とタスクを作成する」。
