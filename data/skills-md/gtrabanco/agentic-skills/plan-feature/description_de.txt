Engineering-Planungsfräser für ein bereits entworfenes Feature. Bei einer Funktion, deren SPEC-Produkthälfte nicht als „designed“ gekennzeichnet ist, wird STOPP und zu „/design-feature <slug>“ umgeleitet – kein Bypass-Flag. Bei einer entworfenen Funktion, einem GitHub-Issue #N (Issue → Produkthälfte mit Gültigkeitsbereich, Erfüllung der Fähigkeitsschließung) oder einem Slug/SPEC mit bereits Gültigkeitsbereich (direkt zum Scaffolding der Engineering-Hälfte) wird zum richtigen internen Schritt weitergeleitet, dann wird der Roadmap-Eintrag sichergestellt und der nächste Schritt gedruckt. Erzwingen Sie einen Pfad mit Flags, um die Erkennung zu überspringen. „--next“ plant das nächste „definierte“ Feature aus der Roadmap. Sind Sie mit Claude Code vertraut und möchten von Hand abgestimmte Modell-/Aufwandsstufen pro Fertigkeit? Installieren Sie stattdessen den Zweig „#claude“ („npx skills add gtrabanco/agentic-workflow#claude“) – siehe README. Dieser Zweig ist modellunabhängig: Der Skill erbt das Modell und den Aufwand, den Ihre Agentensitzung bereits verwendet. Auslöser: „Planen Sie ein Feature“, „Planen Sie das Feature aus Problem N“, „Planen Sie das nächste Roadmap-Feature“, „Scaffold-Feature NN“, „Erstellen Sie SPEC und TASKS für NN“.
