Router di pianificazione ingegneristica per una funzionalità già progettata. Data una funzionalità la cui metà del prodotto SPEC non è contrassegnata come "progettato", si ARRESTA e reindirizza a "/design-feature <slug>" — senza flag di bypass. Data una funzionalità progettata, un problema GitHub n. N (problema → metà del prodotto con ambito, chiusura di funzionalità soddisfacente) o uno slug/SPEC già con ambito (direttamente alla metà dell'impalcatura di progettazione), instrada al passaggio interno corretto, quindi garantisce la voce della roadmap e stampa il passaggio successivo. Forza un percorso con flag per ignorare il rilevamento; "--next" pianifica la successiva funzionalità "definita" dalla roadmap. Sei su Claude Code e desideri livelli di modello/impegno ottimizzati manualmente in base alle competenze? Installa invece il ramo `#claude` (`npx skills add gtrabanco/agentic-workflow#claude`) — consulta il file README. Questo ramo è indipendente dal modello: la competenza eredita qualunque modello e sforzo stia già utilizzando la sessione dell'agente. Trigger: "pianifica una funzionalità", "pianifica la funzionalità dal problema N", "pianifica la successiva funzionalità della roadmap", "funzionalità impalcatura NN", "crea SPEC e TASKS per NN".
