Инженерно-планировочный маршрутизатор для уже спроектированного объекта. При наличии функции, половина продукта SPEC которой не помечена как «разработанная», ОСТАНАВЛИВАЕТСЯ и перенаправляется на `/design-feature <slug>` — флаг обхода отсутствует. При наличии спроектированной функции, проблемы GitHub #N (проблема → половина продукта с заданной областью, удовлетворяющее завершение возможности) или пула/SPEC с уже заданной областью действия (прямо к полупроектированию) направляется к нужному внутреннему шагу, затем обеспечивает запись в дорожной карте и печатает следующий шаг. Принудительно указать путь с флагами, чтобы пропустить обнаружение; `--next` планирует следующую `определённую` функцию из дорожной карты. Вы используете Claude Code и хотите вручную настроить модель/уровень усилий для каждого навыка? Вместо этого установите ветку #claude (навыки npx добавляют gtrabanco/agentic-workflow#claude) — см. README. Эта ветвь не зависит от модели: навык наследует любую модель и усилие, которые уже использует сеанс вашего агента. Триггеры: «запланировать функцию», «запланировать функцию из проблемы N», «запланировать следующую функцию дорожной карты», «функцию каркаса NN», «создать СПЕЦИАЛИЗАЦИИ и ЗАДАЧИ для NN».
