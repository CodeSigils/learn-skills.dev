Vous utilisez Claude Code et souhaitez des modèles/niveaux d'effort ajustés manuellement par compétence ? Installez plutôt la branche `#claude` (`npx skills add gtrabanco/agentic-workflow#claude`) — voir le README. Cette branche est indépendante du modèle : la compétence hérite du modèle et de l'effort que votre session d'agent utilise déjà.
