Implementieren Sie eine Phase eines Features (Standard) oder ein kleines Feature/einen Fix (--fix) durch das ## Phasen-Ledger seiner SPEC – eine Phase pro Aufruf, die letzte Phase ist immer Hardening & PR (der Abschluss); Legacy-SPECs ohne ##-Phasen werden durchgehend in einem einzigen Durchgang ausgeführt. Erzwingt die Zweigstellensicherheit, die Issue-Richtlinie, das Verifizierungs-Gate des Projekts und die Dokumentendisziplin pro Phase. Sind Sie mit Claude Code vertraut und möchten von Hand abgestimmte Modell-/Aufwandsstufen pro Fertigkeit? Installieren Sie stattdessen den Zweig „#claude“ („npx skills add gtrabanco/agentic-workflow#claude“) – siehe README. Dieser Zweig ist modellunabhängig: Der Skill erbt das Modell und den Aufwand, den Ihre Agentensitzung bereits verwendet. Auslöser: „Phase P1 von NN ausführen“, „NN-Funktion implementieren“, „NN aus seiner Spezifikation erstellen“, „Phase NN P2 ausführen“, „Phase ausführen --fix“.
