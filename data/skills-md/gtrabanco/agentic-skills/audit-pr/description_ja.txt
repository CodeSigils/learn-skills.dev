PR レベルのマージ ゲート。マージ準備コントラクトに対して (差分だけでなく) 全体のプル リクエストを監査します。 SPEC 受け入れ基準が満たされ、すべてのフェーズが完了し、ドキュメントがドキュメント マップに従って更新され、問題発生時にクローズ #N が存在し、テストが適切なレイヤーに追加され、CI がグリーン、デフォルトのブランチから分岐して独立してマージ可能、レビュー変更軸がクリーン (または追跡された問題に意識的に延期)、管理機能 SPEC の機能クロージャが取得および記録されています (クロージャ整合性ゲート) — 従来の SPEC は警告しますが、決してブロックしないでください)。判定: マージ準備完了、またはブロッカーのランク付けされたリスト。常に PR の完全な URL が出力され、MERGE-READY では PR 自体に日付付きの SHA バインドされたコメントが投稿されます。決して編集しないでください。デフォルトではマージしません。文書化された自動マージ ポリシー (または明示的なユーザー指示) を使用すると、フェールクローズされたマージ前チェックリスト (クリーンなツリー、アンプッシュ/アンプルされていないもの、監査済み SHA 上の新鮮な緑色の CI) の後に MERGE-READY PR がマージされます。 Claude Code を使用していて、スキルごとのモデル/努力レベルを手動で調整したいですか?代わりに `#claude` ブランチをインストールします (`npx skill add gtrabanco/agentic-workflow#claude`)。README を参照してください。このブランチはモデルに依存しません。スキルは、エージェント セッションがすでに使用しているモデルと作業を継承します。トリガー: 「この PR はマージする準備ができていますか」、「PR を監査します」、「#N のマージ ゲート」、「この船を出荷できますか」、「マージ前レビュー」、「監査 pr」。
