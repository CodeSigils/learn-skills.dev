Utilizza questa abilità quando l'utente deve gestire gli elementi di lavoro Beans in uno spazio di lavoro Beans: creare, visualizzare, aggiornare, riaprire, archiviare, interrogare o gestire in blocco i bean, modificare file ".beans"/frontmatter o gestire relazioni genitore/blocco. Usalo anche quando l'utente dice ticket/problemi/arretrati invece di "bean". Non utilizzarlo per flussi di lavoro di problemi GitHub generici che non sono supportati da Beans.
