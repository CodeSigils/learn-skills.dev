Utilice esta habilidad cuando el usuario necesite administrar elementos de trabajo de Beans en un espacio de trabajo de Beans: crear, ver, actualizar, reabrir, archivar, consultar o administrar beans de forma masiva, editar archivos `.beans`/frontmatter o administrar relaciones principales/de bloqueo. Úselo incluso cuando el usuario diga tickets/problemas/atrasos en lugar de "frijoles". No lo utilice para flujos de trabajo de problemas genéricos de GitHub que no estén respaldados por Beans.
