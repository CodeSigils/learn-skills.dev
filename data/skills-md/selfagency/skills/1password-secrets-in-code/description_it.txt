Utilizza questa competenza per integrare in modo sicuro i segreti 1Password in codebase, agenti AI o pipeline CI/CD utilizzando riferimenti segreti (op://vault/item/field), il modello op run --env-file, 1Password SDK secrets.resolve() per agenti AI con account di servizio, il wrapper del server MCP con op run per evitare segreti in testo normale in mcp.json o la sfera GitHub Actions load-secrets-action e CircleCI secrets. Da utilizzare anche per controllare una codebase per i segreti hardcoded.
