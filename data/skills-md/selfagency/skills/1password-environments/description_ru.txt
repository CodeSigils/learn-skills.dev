Используйте этот навык при настройке сред 1Password для локальной разработки для монтирования именованных наборов секретов в виде локальных файлов .env через каналы FIFO, настройки файла .1password/environments.toml с путями монтирования, установки перехватчиков агента для проверки файлов среды перед выполнением помощника по кодированию AI (Claude Code, Cursor, GitHub Copilot, Windsurf) или устранения неполадок с доставкой FIFO .env. Не для автоматизации секретов или управления ключами SSH.
