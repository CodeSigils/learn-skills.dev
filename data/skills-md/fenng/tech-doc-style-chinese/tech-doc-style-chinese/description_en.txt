Use when writing, revising, or reviewing Chinese technical documents, document front pages, product copy, interface copy, Markdown files, or API descriptions. Adopt a restrained, precise, and scannable Chinese technical-writing style: avoid the second person and marketing tone, always use full-width quotation marks, add spacing between Chinese and English or numeric characters in visible body text, and leave machine-readable content—such as code literals, JSON keys, URLs, and API paths—unchanged.
