يُستخدم عند كتابة أو مراجعة أو مراجعة المستندات الفنية الصينية أو الصفحات الرئيسية للمستندات أو نسخة المنتج أو نسخة الواجهة أو ملفات Markdown أو أوصاف واجهة برمجة التطبيقات. اعتماد أسلوب كتابة تقني صيني مقيد ودقيق وقابل للمسح: تجنب ضمير المخاطب ونبرة التسويق، واستخدم علامات الاقتباس كاملة العرض باستمرار، وأدخل مسافات بين الأحرف الصينية والنص الإنجليزي أو الرقمي في النثر المرئي، واترك المحتوى القابل للقراءة آليًا - مثل حرفية التعليمات البرمجية، ومفاتيح JSON، وعناوين URL، ومسارات واجهة برمجة التطبيقات - دون تغيير. إذا كان المشروع يحتوي على مصطلحات خاصة أو اصطلاحات إصدار أو قواعد بنية معلومات، فاقرأ المراجع/Project-Overrides.md حسب الحاجة.
