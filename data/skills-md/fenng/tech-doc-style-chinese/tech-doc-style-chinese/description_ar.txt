يُستخدم عند كتابة أو مراجعة أو مراجعة المستندات الفنية الصينية أو الصفحات الأولى للمستندات أو نسخة المنتج أو نسخة الواجهة أو ملفات Markdown أو أوصاف واجهة برمجة التطبيقات. اعتماد أسلوب كتابة تقني صيني مقيد ودقيق وقابل للمسح: تجنب ضمير المخاطب ونبرة التسويق، واستخدم دائمًا علامات الاقتباس ذات العرض الكامل، وأضف مسافات بين الحروف الصينية والإنجليزية أو الأحرف الرقمية في النص الأساسي المرئي، واترك المحتوى القابل للقراءة آليًا - مثل حرفية التعليمات البرمجية، ومفاتيح JSON، وعناوين URL، ومسارات واجهة برمجة التطبيقات - دون تغيير. إذا كان للمشروع مصطلحاته الخاصة، أو عرض الإصدار، أو اصطلاحات بنية المعلومات، فاقرأ المراجع/Project-Overrides.md حسب الحاجة.
