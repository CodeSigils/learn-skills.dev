中国語の技術文書、文書のホームページ、製品コピー、インターフェイス テキスト、マークダウン ファイル、または API の説明を作成、改訂、またはレビューするときに使用します。抑制され、正確で、読みやすい中国語のテクニカル ライティング スタイルを採用します。つまり、二人称やマーケティング口調を避け、一貫して全角の引用符を使用し、目に見える散文内の中国語テキストと英語または数値要素の間のスペースを調整し、コード リテラル、JSON キー、URL、API パス、その他の機械可読コンテンツはそのままにします。プロジェクトに特定の用語、バージョン表示、または情報アーキテクチャの規則がある場合は、必要に応じて参考文献/Project-Overrides.md をお読みください。
