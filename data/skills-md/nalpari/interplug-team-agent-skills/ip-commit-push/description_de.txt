Es teilt Änderungen in absichtsbasierte Commits auf und pusht sie zum Remote-Repository, wobei die koreanische Commit‑Message‑Regel (englisches Typ‑Präfix + koreanischer Betreff/Körper) befolgt wird. Sie wird verwendet, wenn ein Commit/Push angefragt wird, z. B. „commit and push for me“, „commit then push“, „commit and push“ oder „commit for me“. Diese Regel wird auch beachtet, wenn nur eine Commit‑Message geschrieben wird oder nach der Regel gefragt wird.
