Divisez les modifications en commits basés sur l’intention selon la règle coréenne des messages de commit (préfixe de type en anglais + sujet/corps en coréen) et poussez‑les vers le dépôt distant. Utilisez cela lorsque vous demandez un commit/push tel que « commit and push for me », « commit then push », « commit and push » ou « commit for me ». Cette règle s’applique également lorsque vous ne faites que rédiger un message de commit ou que vous vous renseignez sur la règle.

Veuillez toujours répondre dans la langue de l’utilisateur.
