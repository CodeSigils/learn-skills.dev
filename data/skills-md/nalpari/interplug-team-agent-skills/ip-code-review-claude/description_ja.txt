Codex サブスクリプションなしでクロードのみを使用して PR を敵対的にレビューします。 PR 番号とブランチを受け取ってチェックアウトした後、3 人の Opus5 サブエージェントがさまざまな観点から敵対的コード レビューを実施します。リーダーの Opus5 は結果からマージ ブロッカーのみをフィルタリングして除外し、解決策を含む表に整理して PR コメントとして投稿します。これは、「PR をレビューしてください」、「クロードと一緒にレビューしてください」、「Codex を使用せずにレビューしてください」、「マージできるかどうかを確認してください」、「敵対的なコードレビュー」、「レビュー結果をコメントとして投稿してください」などのフレーズでマージ前の PR 検証を要求するときに使用されます。
