Sans abonnement Codex, effectuez une révision adversariale d’une PR en n’utilisant que Claude. Après avoir reçu le numéro de la PR et la branche puis l’avoir récupérée, trois sous‑agents Opus 5 effectuent des revues de code adversariales sous différents angles. Le responsable Opus 5 filtre ensuite uniquement les blocages de fusion parmi les résultats, les organise dans un tableau avec des solutions, et les publie en tant que commentaires de PR. Cela est utilisé lors de la demande de vérification pré‑fusion d’une PR avec des expressions telles que « Review the PR », « Review with Claude », « Review without Codex », « Check if it can be merged », « Adversarial code review » ou « Add the review results as a comment ».
