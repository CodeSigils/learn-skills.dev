Realice una revisión adversarial de un PR usando solo Claude, sin una suscripción a Codex. Después de recibir el número del PR y la rama, revíselos; luego, tres sub‑agentes de Opus 5 realizan revisiones de código adversariales desde diferentes perspectivas, y el líder de Opus 5 filtra solo los bloqueadores de fusión de los resultados, los organiza en una tabla con soluciones y los registra como un comentario del PR. Se utiliza al solicitar la verificación del PR antes de fusionarlo, como “Revisar el PR”, “Revisar con Claude”, “Revisar sin Codex”, “Comprobar si se puede fusionar”, “Revisión de código adversarial”, “Publicar los resultados de la revisión como comentario”.
