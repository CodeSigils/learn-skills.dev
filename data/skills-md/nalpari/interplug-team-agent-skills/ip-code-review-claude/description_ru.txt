Без подписки на Codex мы проводим противоборственные обзоры PR, используя только Claude. После получения номера PR и ветки и их checkout три суб‑агента Opus 5 проводят противоборственные обзоры кода с разных точек зрения, а ведущий Opus 5 отбирает из результатов только блокирующие слияние проблемы, оформляет их с решениями в таблице и публикует в виде комментариев к PR. Это используется при запросе предварительной проверки PR, например «Проверьте PR за меня», «Обзор с Claude», «Обзор без Codex», «Проверьте, можно ли слить», «Противоборственный код‑ревью», «Добавьте результаты обзора в комментарий».
