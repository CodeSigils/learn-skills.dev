We conduct an adversarial review of a PR using only Claude, without a Codex subscription. After receiving the PR number and branch and checking it out, three Opus 5 sub‑agents run adversarial code reviews from different perspectives, and the lead Opus 5 filters out only the merge blockers from the results, organizes them in a table with solutions, and registers them as a PR comment. It is used when requesting pre‑merge PR validation with phrases like “Review the PR,” “Review with Claude,” “Review without Codex,” “Check if it can be merged,” “Adversarial code review,” “Post the review results as a comment.”
