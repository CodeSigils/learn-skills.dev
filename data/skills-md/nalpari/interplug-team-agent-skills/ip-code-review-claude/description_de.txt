Ohne Codex‑Abonnement führen wir eine adversariale Überprüfung eines Pull Requests ausschließlich mit Claude durch. Nachdem wir die PR‑Nummer und den Branch erhalten und ausgecheckt haben, führen drei Opus 5‑Sub‑Agenten aus verschiedenen Perspektiven adversariale Code‑Reviews durch, und der leitende Opus 5 filtert daraus nur die Merge‑Blocker heraus, organisiert sie in einer Tabelle mit Lösungen und hinterlegt sie als PR‑Kommentar. Dies wird verwendet, wenn eine Vor‑Merge‑PR‑Verifikation mit Formulierungen wie „Review the PR“, „Review with Claude“, „Review without Codex“, „Check if it can be merged“, „Adversarial code review“, „Post the review results as a comment“ angefordert wird.
