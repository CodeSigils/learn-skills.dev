When an AI agent writes or edits documentation (README, AGENTS.md, plans, etc.), it is forced to automatically generate and insert VeriContext citations/claims, and at the point of task completion, commit, and push, vctx_verify_workspace checks that all claims are up to date. Three-layer enforcement: (1) hook reminder when writing documentation, (2) batch verification upon task completion, (3) blocking commit/push via a git hook. NOT for: modifying the code itself, writing tests, building.
