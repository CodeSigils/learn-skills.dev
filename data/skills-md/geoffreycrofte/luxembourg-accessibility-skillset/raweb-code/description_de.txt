Schreiben Sie barrierefreies HTML, CSS und JavaScript, das RAWeb 1.1 (Luxembourg Web Accessibility Framework, basierend auf EN 301 549 / WCAG 2.1) entspricht. Zur Verwendung bei der Entwicklung von Webschnittstellen, Komponenten, Formularen, Navigation oder anderen Front-End-Codes, die den luxemburgischen Gesetzen zur Barrierefreiheit entsprechen müssen. Deckt alle 17 RAWeb-Themen mit Anleitungen auf Codeebene, zugänglichen Mustern und Anti-Mustern ab. Standardkonformitätsziel: Stufe AA.
