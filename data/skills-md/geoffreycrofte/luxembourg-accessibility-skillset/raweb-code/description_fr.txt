Écrivez du HTML, CSS et JavaScript accessibles et conformes à RAWeb 1.1 (Luxembourg Web Accessibility Framework, basé sur EN 301 549 / WCAG 2.1). À utiliser lors du développement d'interfaces Web, de composants, de formulaires, de navigation ou de tout code frontal devant respecter la loi luxembourgeoise sur l'accessibilité. Couvre les 17 thèmes RAWeb avec des conseils au niveau du code, des modèles accessibles et des anti-modèles. Cible de conformité par défaut : niveau AA.
