كتابة HTML وCSS وJavaScript يمكن الوصول إليها والتي تتوافق مع RAWeb 1.1 (Luxembourg Web Accessibility Framework، استنادًا إلى EN 301 549 / WCAG 2.1). يُستخدم عند تطوير واجهات الويب أو المكونات أو النماذج أو التنقل أو أي كود للواجهة الأمامية يجب أن يتوافق مع قانون إمكانية الوصول في لوكسمبورغ. يغطي جميع سمات RAWeb السبعة عشر مع إرشادات على مستوى التعليمات البرمجية وأنماط يمكن الوصول إليها وأنماط مضادة. هدف التوافق الافتراضي: المستوى AA.
