Erstellen Sie ein detailliertes Produktspezifikationsdokument aus einer vagen Idee, einer groben Beschreibung oder unterstützenden Materialien (UI-Skizzen, Screenshots, Notizen, vorhandene Dokumente). Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein grobes Konzept in eine strukturierte Spezifikation umwandeln möchte – auch wenn er Dinge sagt wie „Schreiben Sie eine Spezifikation für …“, „Machen Sie diese Idee in ein Anforderungsdokument um“, „Ich habe diese grobe Idee für ein Produkt“, „Helfen Sie mir, dies zu spezifizieren“, „Erstellen Sie eine PRD für ...“ oder lädt Bilder/Dateien hoch und möchte, dass daraus eine Spezifikation geschrieben wird. Deckt alle Produkttypen einschließlich interner Werkzeuge ab. Lösen Sie diese Fähigkeit aus, auch wenn die Anfrage einfach erscheint – eine vage, einzeilige Idee verdient eine genaue Beschreibung ebenso wie eine detaillierte Beschreibung.
