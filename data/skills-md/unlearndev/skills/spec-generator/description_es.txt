Genere un documento de especificación de producto detallado a partir de una idea vaga, una descripción aproximada o materiales de apoyo (bocetos de interfaz de usuario, capturas de pantalla, notas, documentos existentes). Utilice esta habilidad siempre que el usuario quiera convertir un concepto aproximado en una especificación estructurada, incluso si dice cosas como "escriba una especificación para...", "convierta esta idea en un documento de requisitos", "Tengo esta idea aproximada para un producto", "ayúdeme a especificar esto", "cree un PRD para...", o cargue imágenes/archivos y quiera que se escriba una especificación a partir de ellos. Cubre todo tipo de productos, incluidas las herramientas internas. Active esta habilidad incluso si la solicitud parece simple: una idea vaga de una sola línea merece una especificación adecuada tanto como un resumen detallado.
