Triagieren Sie einen Zweig oder ein Diff, indem Sie geänderte Dateien in Funktionsbereiche gruppieren, jedem eine Risikostufe (Hoch/Mittel/Niedrig) zuweisen und eine durchsuchbare Zusammenfassung erstellen, die bei der Entscheidung hilft, wo Sie Zeit für die Überprüfung aufwenden sollten. Verwenden Sie diese Option, wenn der Benutzer eine „Triage“ eines Zweigs, einer PR oder eines Diffs anfordert.
