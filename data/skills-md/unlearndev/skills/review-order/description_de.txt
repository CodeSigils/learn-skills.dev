Bereiten Sie eine strukturierte, durchsuchbare Überprüfungscheckliste für eine Verzweigung oder einen Unterschied vor, gruppieren Sie sie nach Funktionsänderungen und wenden Sie die Überprüfungsreihenfolge in vier Durchgängen (Typen, Datenfluss, Geschäftslogik, Randfälle) innerhalb jeder Funktion an. Verwenden Sie diese Option, wenn der Benutzer „eine Überprüfung vorbereiten“ oder „Überprüfungsauftrag“ wünscht oder eine Checkliste zum manuellen Durchgehen von Änderungen wünscht.
