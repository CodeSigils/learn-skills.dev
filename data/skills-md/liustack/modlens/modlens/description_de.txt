Plug-in-Vision für Nur-Text-Modelle. Verwenden Sie diese Option immer dann, wenn der Benutzer ein Bild teilt (lokaler Pfad, Screenshot, Foto, Diagramm, Dokumentenscan oder Bild-URL) und das aktive Modell keine Bilder sehen kann oder kein Vision-Tool hat. Führt die Modlens-CLI aus, um das Bild in strukturierte JSON-Beweise umzuwandeln: OCR-Text, Layout, Semantik, visuelle Hinweise. Verwenden Sie es auch, wenn der Benutzer fragt, wie Modlens-Anbieter installiert, konfiguriert oder gewechselt werden sollen (Gemini-API-Schlüssel, OpenAI-kompatible Endpunkte, Claude API oder Claude Code CLI).
