テキストのみのモデル用のプラグイン ビジョン。ユーザーが画像 (ローカル パス、スクリーンショット、写真、チャート、ドキュメント スキャン、または画像 URL) を共有し、アクティブなモデルが画像を表示できないか、ビジョン ツールを持たない場合に使用します。 modlens CLI を実行して、画像を構造化された JSON 証拠 (OCR テキスト、レイアウト、セマンティクス、視覚的手がかり) に変換します。また、ユーザーが modlens プロバイダー (Gemini API キー、OpenAI 互換エンドポイント、Claude API または Claude Code CLI) をインストール、構成、または切り替える方法を尋ねる場合にも使用します。
