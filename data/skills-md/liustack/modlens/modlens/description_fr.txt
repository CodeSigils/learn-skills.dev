Vision plug-in pour les modèles texte uniquement. À utiliser chaque fois que l'utilisateur partage une image (chemin local, capture d'écran, photo, graphique, numérisation de document ou URL d'image) et que le modèle actif ne peut pas voir les images ou ne dispose pas d'outil de vision. Exécute la CLI modlens pour convertir l'image en preuves JSON structurées : texte OCR, mise en page, sémantique, indices visuels. À utiliser également lorsque l'utilisateur demande comment installer, configurer ou changer de fournisseur de modules (clé API Gemini, points de terminaison compatibles OpenAI, API Claude ou CLI Claude Code).
