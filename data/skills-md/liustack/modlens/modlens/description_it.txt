Visione plug-in per modelli di solo testo. Da utilizzare ogni volta che l'utente condivide un'immagine (percorso locale, screenshot, foto, grafico, scansione di documento o URL di immagine) e il modello attivo non può vedere le immagini o non dispone di uno strumento di visione. Esegue la CLI modlens per convertire l'immagine in prove JSON strutturate: testo OCR, layout, semantica, indizi visivi. Da utilizzare anche quando l'utente chiede come installare, configurare o cambiare provider modlens (chiave API Gemini, endpoint compatibili con OpenAI, API Claude o CLI Claude Code).
