텍스트 전용 모델을 위한 플러그인 비전. 사용자가 이미지(로컬 경로, 스크린샷, 사진, 차트, 문서 스캔 또는 이미지 URL)를 공유하고 활성 모델이 이미지를 볼 수 없거나 비전 도구가 없을 때마다 사용합니다. modlens CLI를 실행하여 이미지를 구조화된 JSON 증거(OCR 텍스트, 레이아웃, 의미 체계, 시각적 단서)로 변환합니다. 또한 사용자가 Modlens 공급자(Gemini API 키, OpenAI 호환 엔드포인트, Claude API 또는 Claude Code CLI)를 설치, 구성 또는 전환하는 방법을 묻는 경우에도 사용합니다.
