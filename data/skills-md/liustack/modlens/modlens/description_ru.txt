Подключаемый модуль для текстовых моделей. Используйте, когда пользователь делится изображением (локальным путем, снимком экрана, фотографией, диаграммой, отсканированным документом или URL-адресом изображения), а активная модель не видит изображения или не имеет инструмента машинного зрения. Запускает интерфейс командной строки modlens для преобразования изображения в структурированное свидетельство JSON: текст OCR, макет, семантика, визуальные подсказки. Также используйте, когда пользователь спрашивает, как установить, настроить или переключить поставщиков модленов (ключ Gemini API, конечные точки, совместимые с OpenAI, Claude API или Claude Code CLI).
