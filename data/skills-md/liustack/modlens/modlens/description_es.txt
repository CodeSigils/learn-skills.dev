Visión enchufable para modelos de solo texto. Úselo siempre que el usuario comparta una imagen (ruta local, captura de pantalla, foto, gráfico, escaneo de documento o URL de la imagen) y el modelo activo no pueda ver imágenes o no tenga una herramienta de visión. Ejecuta la CLI de modlens para convertir la imagen en evidencia JSON estructurada: texto OCR, diseño, semántica, pistas visuales. Utilícelo también cuando el usuario pregunte cómo instalar, configurar o cambiar de proveedor de modlens (clave API de Gemini, puntos finales compatibles con OpenAI, API de Claude o CLI de Claude Code).
