قم بإعادة إنشاء لعبة ويب صغيرة، ونشرها بشكل اختياري على Cloudflare. عندما يريد المستخدم "إعادة إنشاء/استنساخ/تقليد/القيام بذلك بنفس الطريقة/نسخ/استنساخ" لعبة معينة - تقديم اسم اللعبة، أو رابط منشور X/Twitter، أو صفحة App Store/GooglePlay، أو لقطة شاشة أو مقطع فيديو للعبة - أو يقول "اصنع لعبة مثل XX"، أو "حوّل لعبة الهاتف المحمول/البرنامج الصغير هذه إلى إصدار ويب"، أو "نفذ 2048/NumberWeave/Queens/Tango/Zip/Wordle/Connections/Sudoku/match‑3/combination/card mini‑game"، "اختر لعبة صغيرة مشهورة وأعد إنشائها" - استخدم هذا. حتى لو لم يستخدم المستخدم كلمة "إعادة إنشاء" ولكن فقط أسقط رابط اللعبة وسأل "هل يمكنك إنشاء واحدة؟"، فهذا مهم. يغطي البحث الأصلي ← إعادة إنشاء طريقة اللعب + المظهر الأصلي ← التنفيذ والاختبار باستخدام Vite+React+TS ← التحقق الذاتي من المتصفح ← النشر الاختياري الشامل مع Wrangler. استخدمه عندما يريد المستخدم استنساخ لعبة ويب ألغاز/لوحة/بطاقة عادية أو تكرارها أو إعادة صنعها أو "إنشاء شيء مثل" من اسم أو رابط أو لقطة شاشة.
