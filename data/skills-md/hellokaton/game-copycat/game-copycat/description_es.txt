Recrea un minijuego web, opcionalmente impleméntelo en Cloudflare. Cuando el usuario quiere “recrear/clonar/imitar/hacerlo de la misma manera/copiar/clonar” un determinado juego (proporcionando el nombre del juego, un enlace de publicación X/Twitter, una página de App Store/GooglePlay, una captura de pantalla o video del juego) o dice “crear un juego comoXX”, “convertir este juego móvil/miniprograma en una versión web”, “implementar un 2048/NumberWeave/Queens/Tango/Zip/Wordle/Connections/Sudoku/match‑3/combination/card minigame”, “elige un minijuego popular y recréalo”: usa esto. Incluso si el usuario no usa la palabra "recrear", sino que simplemente deja caer el enlace de un juego y pregunta "¿puedes crear uno?", cuenta. Cubre la investigación del original → recreación del juego + diseño original → implementación y pruebas con Vite+React+TS → autoverificación del navegador → implementación opcional de un extremo a otro con Wrangler. Úselo siempre que el usuario quiera clonar, replicar, rehacer o "construir algo así como" un juego web informal de rompecabezas, tablero o cartas a partir de un nombre, enlace o captura de pantalla.
