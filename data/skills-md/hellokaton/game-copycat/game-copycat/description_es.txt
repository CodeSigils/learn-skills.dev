Recrea minijuegos web, opcionalmente implementa en Cloudflare. Cuando un usuario quiere “reproducir/clonar/imitar/hacer una copia de” un determinado juego (proporcionando el nombre del juego, el enlace de la publicación X/Twitter, la página de App Store/Google Play, capturas de pantalla del juego o video) o dice “crear un juego como XX”, “convertir este juego móvil/applet en una versión web”, “implementar un 2048/Numberweave/Queens/Tango/Zip/Wordle/Connections/Sudoku/match‑3/combination/card minigame”, “busca un minijuego popular para recrear”, esto aplica. Incluso si el usuario no usa la palabra "reproducir" y simplemente deja caer un enlace del juego preguntando "¿puedes hacer uno?", cuenta. Cubre la investigación del original → replicación del juego + reskin original → implementación y prueba con Vite+React+TS → autovalidación del navegador → implementación opcional de Wrangler, un flujo de trabajo de un extremo a otro. Úselo siempre que el usuario quiera clonar, replicar, rehacer o "construir algo así como" un juego web informal de rompecabezas, tablero o cartas a partir de un nombre, enlace o captura de pantalla.
