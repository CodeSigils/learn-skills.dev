Reproduzieren Sie Web-Minispiele und stellen Sie sie optional in Cloudflare bereit. Wenn ein Benutzer ein bestimmtes Spiel „reproduzieren/klonen/nachahmen/auf die gleiche Weise machen/kopieren/klonen“ möchte – indem er den Spielnamen, einen X-/Twitter-Beitragslink, eine App Store-/Google Play-Seite, Spiel-Screenshots oder ein Video bereitstellt – oder sagt: „Erstelle ein Spiel wie XX“, „verwandle dieses mobile App-/Miniprogramm-Spiel in eine Webversion“, „implementiere ein.“ B. 2048/Number Weave/Queens/Tango/Zip/Wordle/Connections/Sudoku/Match-3/Combo/Card-Minispiel“, „Finden Sie ein beliebtes Minispiel und reproduzieren Sie es“ usw., verwenden Sie dies. Selbst wenn der Benutzer nicht das Wort „reproduzieren“ verwendet, sondern einfach einen Spiellink hinterlässt und fragt „Können Sie einen erstellen“, zählt es. Umfasst die Recherche des Originals → Gameplay-Reproduktion + Original-Reskin → Vite+React+TS-Implementierung und -Tests → Browser-Selbstverifizierung → optionaler Wrangler-Bereitstellungs-End-to-End-Prozess. Verwenden Sie es immer dann, wenn der Benutzer anhand eines Namens, eines Links oder eines Screenshots ein lockeres Puzzle-, Brett- oder Karten-Webspiel klonen, replizieren, neu erstellen oder „bauen“ möchte.
