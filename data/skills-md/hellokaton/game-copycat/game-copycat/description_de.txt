Erstellen Sie ein Web-Minispiel neu und stellen Sie es optional in Cloudflare bereit. Wenn der Benutzer ein bestimmtes Spiel „neu erstellen/klonen/nachahmen/auf die gleiche Weise machen/kopieren/klonen“ möchte – indem er den Spielnamen, einen X-/Twitter-Beitragslink, eine App Store-/GooglePlay-Seite, einen Screenshot oder ein Video des Spiels angibt – oder sagt: „Erstelle ein Spiel wie XX“, „verwandle dieses Handy-/Miniprogrammspiel in eine Webversion“, „implementiere ein.“ 2048/NumberWeave/Queens/Tango/Zip/Wordle/Connections/Sudoku/Match-3/Combination/Card Mini-Game“, „Wählen Sie ein beliebtes Mini-Spiel und erstellen Sie es neu“ – verwenden Sie dies. Selbst wenn der Benutzer nicht das Wort „neu erstellen“ verwendet, sondern einfach einen Spiellink hinterlässt und fragt „Können Sie einen erstellen?“, zählt es. Behandelt die Forschung des Originals → Gameplay-Nachbildung + Original-Skins → Implementierung und Tests mit Vite+React+TS → Browser-Selbstverifizierung → optionale End-to-End-Bereitstellung mit Wrangler. Verwenden Sie es immer dann, wenn der Benutzer anhand eines Namens, eines Links oder eines Screenshots ein lockeres Puzzle-, Brett- oder Karten-Webspiel klonen, replizieren, neu erstellen oder „bauen“ möchte.
