Web ミニゲームを再作成し、必要に応じて Cloudflare にデプロイします。ユーザーが特定のゲームを「再作成/クローン/模倣/同じ方法で行う/コピー/クローン」したいとき、ゲーム名、X/Twitter 投稿リンク、App Store/GooglePlay ページ、ゲームのスクリーンショットまたはビデオを提供するか、「XX のようなゲームを作って」、「このモバイル/ミニプログラム ゲームを Web バージョンに」、「 2048/NumberWeave/Queens/Tango/Zip/Wordle/Connections/Sudoku/match-3/combination/card mini-game」、「人気のミニゲームを選んで再現」 - これを使用します。ユーザーが「再作成」という言葉を使わず、単にゲームのリンクをドロップして「作成できますか?」と尋ねたとしても、それは重要です。オリジナルの調査 → ゲームプレイの再現 + オリジナルのスキニング → Vite+React+TS による実装とテスト → ブラウザの自己検証 → Wrangler によるオプションのエンドツーエンド展開をカバーします。ユーザーが名前、リンク、またはスクリーンショットからカジュアルなパズル/ボード/カード Web ゲームのクローン、複製、リメイク、または「似たものを構築」したい場合は常に使用します。
