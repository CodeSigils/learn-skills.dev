Préparez les PR à la fusion : portée étroite, description claire, pas de débogage restant, notes de test honnêtes. À utiliser lors de l'ouverture d'un PR, de la rédaction d'une description de PR, du nettoyage d'une branche avant examen ou lorsque l'utilisateur mentionne une demande d'extraction, un prêt à la fusion ou une hygiène des relations publiques.
