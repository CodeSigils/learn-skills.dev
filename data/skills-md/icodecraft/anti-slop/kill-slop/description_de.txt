Verhindern Sie, dass KI-Coding-Agents schlampigen Code liefern – übermäßige Abstraktion, Drive-by-Refaktoren, offensichtliche Kommentare, zusätzliche Dateien, unaufgeforderte Deps, riesige unlesbare Dateien oder das Suchen nach „Inspiration“ außerhalb des Arbeitsbereichs. Verwenden Sie diese Option, wenn Sie Code schreiben oder bearbeiten, Funktionen implementieren, Fehler beheben, Dateien aufteilen oder organisieren oder wenn der Benutzer „Slop“, „Bereinigung“, „Keep it simple“, „Minimum Diff“, „Datei zu groß, schwer zu navigieren“ oder „im Repository bleiben“ erwähnt.
