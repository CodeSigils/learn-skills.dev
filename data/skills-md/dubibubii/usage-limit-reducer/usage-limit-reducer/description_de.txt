Verwenden Sie diese Option, wenn der Benutzer die Claude-Nutzungsgrenzen erreicht, Token schnell verbraucht, ein langes Gespräch führt oder fragt, wie er Claude Code effizienter nutzen kann. Löst Auslöser bei Sätzen wie „mein Limit erreicht“, „keine Token mehr“, „Nutzungslimit“, „Token speichern“, „Nutzung reduzieren“, „Verschwende ich Token“, „dieser Chat wird länger“, „welches Modell soll ich verwenden“ aus. Diagnostiziert die aktuelle Sitzung, führt einen echten Token-Nutzungsbericht aus lokalen JSONL-Protokollen aus und wendet Dubis 11 Regeln zur Reduzierung der Claude-Nutzung an.
