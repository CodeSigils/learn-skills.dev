Verwenden Sie diese Option, wenn der Benutzer ein WIEDERVERWENDBARES Skript möchte, das alle Daten einer Website (z. B. jeden Eintrag/jedes Produkt/jede Zeile auf allen Seiten) über seine angemeldete Frevana Chrome Extension-Sitzung sammelt. Erkundet die Site einmal, erkennt automatisch ihre JSON-API und gibt ein betriebsbereites Python-Collector-Skript zurück – das Modell schreibt keinen Code und das Skript wird hier nicht ausgeführt.
