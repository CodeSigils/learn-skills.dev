Используйте, когда пользователю нужен сценарий REUSABLE, который собирает все данные веб-сайта (например, каждый список/продукт/строку на страницах) через вошедший в систему сеанс расширения Frevana Chrome. Исследует сайт один раз, автоматически определяет его JSON API и возвращает готовый к запуску скрипт сборщика Python — моделью не пишется код, и скрипт здесь не выполняется.
