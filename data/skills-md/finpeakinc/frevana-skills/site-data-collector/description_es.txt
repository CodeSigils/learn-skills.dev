Úselo cuando el usuario desee un script REUTILIZABLE que recopile todos los datos de un sitio web (por ejemplo, cada listado/producto/fila de las páginas) a través de su sesión de extensión de Chrome Frevana iniciada. Explora el sitio una vez, detecta automáticamente su API JSON y devuelve un script recopilador de Python listo para ejecutar; el modelo no escribe ningún código y el script no se ejecuta aquí.
