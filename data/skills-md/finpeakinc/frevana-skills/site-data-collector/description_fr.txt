À utiliser lorsque l'utilisateur souhaite un script RÉUTILISABLE qui collecte toutes les données d'un site Web (par exemple, chaque liste/produit/ligne sur les pages) via sa session d'extension Frevana Chrome connectée. Explorez le site une fois, détecte automatiquement son API JSON et renvoie un script de collecteur Python prêt à être exécuté : aucun code n'est écrit par le modèle et le script n'est pas exécuté ici.
