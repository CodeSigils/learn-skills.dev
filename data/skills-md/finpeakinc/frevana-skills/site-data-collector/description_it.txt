Da utilizzare quando l'utente desidera uno script RIUTILIZZABILE che raccolga tutti i dati di un sito web (ad esempio ogni elenco/prodotto/riga sulle pagine) attraverso la sessione di Frevana Chrome Extension effettuata. Esplora il sito una volta, rileva automaticamente la sua API JSON e restituisce uno script di raccolta Python pronto per l'esecuzione: nessun codice viene scritto dal modello e lo script non viene eseguito qui.
