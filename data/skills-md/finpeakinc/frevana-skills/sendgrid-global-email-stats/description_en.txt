Use when the user wants to retrieve Twilio SendGrid global email statistics with GET /v3/stats. Supports start/end date ranges, day/week/month aggregation, limit/offset pagination, parent-account on-behalf-of lookups for subusers or customer accounts, global or EU SendGrid API base URLs, dry-run URL preview, and saved SendGrid API key reuse. Do not use for sending email or Email Logs status lookup.
