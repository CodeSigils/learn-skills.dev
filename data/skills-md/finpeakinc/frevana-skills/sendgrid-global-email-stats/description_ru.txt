Используйте, когда пользователь хочет получить глобальную статистику электронной почты Twilio SendGrid с помощью GET /v3/stats. Поддерживает диапазоны дат начала/окончания, агрегирование дней/недель/месяцев, разбиение на страницы по лимитам/смещениям, поиск субпользователей или учетных записей клиентов от имени родительской учетной записи, глобальные или базовые URL-адреса API SendGrid для ЕС, предварительный просмотр URL-адресов пробного запуска и повторное использование сохраненных ключей API SendGrid. Не используйте для отправки электронной почты или поиска статуса журналов электронной почты.
