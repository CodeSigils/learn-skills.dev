Da utilizzare quando l'utente desidera recuperare le statistiche di posta elettronica globali di Twilio SendGrid con GET /v3/stats. Supporta intervalli di date di inizio/fine, aggregazione di giorno/settimana/mese, limite/offset di paginazione, ricerche per conto dell'account principale per subutenti o account cliente, URL di base API SendGrid globali o UE, anteprima URL di prova e riutilizzo della chiave API SendGrid salvata. Non utilizzare per l'invio di e-mail o per la ricerca dello stato dei registri e-mail.
