يُستخدم عندما يريد المستخدم استرداد إحصائيات البريد الإلكتروني العالمية لـ Twilio SendGrid باستخدام GET /v3/stats. يدعم نطاقات تاريخ البدء/الانتهاء، وتجميع اليوم/الأسبوع/الشهر، وترقيم الصفحات للحد/الإزاحة، وعمليات البحث عن الحساب الأصلي نيابةً عن المستخدمين الفرعيين أو حسابات العملاء، وعناوين URL الأساسية لواجهة برمجة تطبيقات SendGrid العالمية أو التابعة للاتحاد الأوروبي، ومعاينة عنوان URL للتشغيل الجاف، وإعادة استخدام مفتاح SendGrid API المحفوظة. لا تستخدم لإرسال البريد الإلكتروني أو البحث عن حالة سجلات البريد الإلكتروني.
