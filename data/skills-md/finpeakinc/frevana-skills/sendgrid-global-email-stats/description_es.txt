Úselo cuando el usuario desee recuperar las estadísticas globales de correo electrónico de Twilio SendGrid con GET /v3/stats. Admite rangos de fechas de inicio/finalización, agregación de día/semana/mes, paginación límite/compensación, búsquedas en nombre de cuentas principales para subusuarios o cuentas de clientes, URL base de la API SendGrid global o de la UE, vista previa de URL de prueba y reutilización de claves API SendGrid guardadas. No lo utilice para enviar correos electrónicos o buscar el estado de los registros de correo electrónico.
