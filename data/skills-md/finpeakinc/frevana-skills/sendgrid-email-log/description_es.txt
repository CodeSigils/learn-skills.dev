Úselo cuando el usuario desee consultar los registros de correo electrónico de Twilio SendGrid o recuperar la actividad por mensaje para un sg_message_id específico, incluido si un correo electrónico se abrió, se hizo clic, se entregó, se rebotó, se aplazó, se abandonó, se informó como spam o se canceló la suscripción. Admite la búsqueda GET /v3/logs/{sg_message_id} por ID y POST /v3/logs por destinatario, asunto opcional, envío en límite inferior, estado, consulta sin formato y coincidencia de ID de mensaje difuso. Admite URL base de la API SendGrid global o de la UE, encabezado de cuenta principal opcional en nombre de la cuenta principal para búsquedas por ID, salida JSON sin procesar, enriquecimiento del resumen de eventos, URL de ejecución en seco o vista previa de la carga útil y reutilización de la clave API SendGrid guardada. No lo utilice para enviar correos electrónicos ni agregar estadísticas de SendGrid.
