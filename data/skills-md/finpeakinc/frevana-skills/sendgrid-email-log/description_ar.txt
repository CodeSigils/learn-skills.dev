يُستخدم عندما يريد المستخدم الاستعلام عن سجلات البريد الإلكتروني لـ Twilio SendGrid أو استرداد نشاط كل رسالة لمعرف sg_message_id محدد، بما في ذلك ما إذا تم فتح رسالة بريد إلكتروني أو النقر عليها أو تسليمها أو ارتدادها أو تأجيلها أو إسقاطها أو الإبلاغ عن البريد العشوائي أو إلغاء الاشتراك فيها. يدعم GET /v3/logs/{sg_message_id} حسب المعرف والبحث POST /v3/logs حسب المستلم، والموضوع الاختياري، والحد الأدنى المرسل، والحالة، والاستعلام الأولي، ومطابقة معرف الرسالة الغامضة. يدعم عناوين URL الأساسية العالمية أو EU SendGrid API، ورأس الحساب الأصلي الاختياري نيابةً عن عمليات البحث حسب المعرف، ومخرجات JSON الأولية، وإثراء ملخص الحدث، وعنوان URL للتشغيل الجاف أو معاينة الحمولة، وإعادة استخدام مفتاح SendGrid API المحفوظة. لا تستخدم لإرسال البريد الإلكتروني أو إحصائيات SendGrid الإجمالية.
