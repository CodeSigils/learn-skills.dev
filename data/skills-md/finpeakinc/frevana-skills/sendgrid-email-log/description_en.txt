Use when the user wants to query Twilio SendGrid Email Logs or retrieve per-message activity for a specific sg_message_id, including whether an email was opened, clicked, delivered, bounced, deferred, dropped, spam-reported, or unsubscribed. Supports GET /v3/logs/{sg_message_id} by ID and POST /v3/logs search by recipient, optional subject, sent-at lower bound, status, raw query, and fuzzy message ID matching. Supports global or EU SendGrid API base URLs, optional on-behalf-of parent-account header for by-ID lookups, raw JSON output, event summary enrichment, dry-run URL or payload preview, and saved SendGrid API key reuse. Do not use for sending email or aggregate SendGrid statistics.
