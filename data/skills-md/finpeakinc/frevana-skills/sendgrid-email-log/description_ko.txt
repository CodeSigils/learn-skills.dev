사용자가 Twilio SendGrid 이메일 로그를 쿼리하거나 이메일 열기, 클릭, 전달, 반송, 지연, 삭제, 스팸 신고 또는 구독 취소 여부를 포함하여 특정 sg_message_id에 대한 메시지별 활동을 검색하려는 경우에 사용합니다. ID별 GET /v3/logs/{sg_message_id} 및 수신자별 POST /v3/logs 검색, 선택적 제목, 보낸 시간 하한, 상태, 원시 쿼리 및 퍼지 메시지 ID 일치를 지원합니다. 글로벌 또는 EU SendGrid API 기본 URL, ID별 조회를 위한 선택적 상위 계정 대신 헤더, 원시 JSON 출력, 이벤트 요약 보강, 테스트 실행 URL 또는 페이로드 미리 보기, 저장된 SendGrid API 키 재사용을 지원합니다. 이메일을 보내거나 SendGrid 통계를 집계하는 데 사용하지 마십시오.
