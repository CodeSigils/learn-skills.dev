ユーザーが Twilio SendGrid 電子メール ログをクエリする場合、または特定の sg_message_id のメッセージごとのアクティビティ (電子メールが開かれたか、クリックされたか、配信されたか、バウンスされたか、延期されたか、削除されたか、スパム報告されたか、購読解除されたかなど) を取得する場合に使用します。 ID による GET /v3/logs/{sg_message_id} と、受信者、オプションの件名、送信時下限、ステータス、生のクエリ、およびあいまいメッセージ ID の一致による POST /v3/logs 検索をサポートします。グローバルまたは EU の SendGrid API ベース URL、ID 検索用のオプションの親アカウントの代理ヘッダー、生の JSON 出力、イベント概要の強化、予行演習 URL またはペイロード プレビュー、および保存された SendGrid API キーの再利用をサポートします。電子メールの送信や SendGrid 統計の集約には使用しないでください。
