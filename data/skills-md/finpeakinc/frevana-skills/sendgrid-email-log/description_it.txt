Da utilizzare quando l'utente desidera eseguire query sui registri e-mail di Twilio SendGrid o recuperare l'attività per messaggio per uno specifico sg_message_id, incluso se un'e-mail è stata aperta, cliccata, recapitata, respinta, rinviata, eliminata, segnalata come spam o annullata l'iscrizione. Supporta la ricerca GET /v3/logs/{sg_message_id} per ID e la ricerca POST /v3/logs per destinatario, oggetto facoltativo, limite inferiore inviato, stato, query non elaborata e corrispondenza ID messaggio fuzzy. Supporta URL di base API SendGrid globali o UE, intestazione opzionale per conto dell'account principale per ricerche per ID, output JSON non elaborato, arricchimento del riepilogo eventi, URL di prova o anteprima del payload e riutilizzo della chiave API SendGrid salvata. Non utilizzare per l'invio di e-mail o per aggregare statistiche SendGrid.
