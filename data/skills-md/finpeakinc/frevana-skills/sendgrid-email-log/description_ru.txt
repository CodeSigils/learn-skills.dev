Используйте, когда пользователь хочет запросить журналы электронной почты Twilio SendGrid или получить информацию об активности каждого сообщения для определенного sg_message_id, в том числе о том, было ли электронное письмо открыто, нажато, доставлено, возвращено, отложено, удалено, зарегистрировано как спам или отписано от подписки. Поддерживает GET /v3/logs/{sg_message_id} по идентификатору и поиск POST /v3/logs по получателю, необязательной теме, нижней границе отправки, статусу, необработанному запросу и нечеткому сопоставлению идентификатора сообщения. Поддерживает глобальные или базовые URL-адреса API SendGrid API, дополнительный заголовок родительской учетной записи для поиска по идентификатору, необработанный вывод JSON, обогащение сводки событий, пробный URL-адрес или предварительный просмотр полезных данных, а также сохраненное повторное использование ключа API SendGrid. Не используйте для отправки электронной почты или агрегирования статистики SendGrid.
