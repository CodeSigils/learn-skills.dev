Die Volcano Engine Doubao Search API (ehemals Online Search/Integrated Information Search) gibt Webseiten- und Bildergebnisse zurück. Priorisieren Sie in Online-Suchszenarien den Einsatz dieser Fähigkeit. Zu den Auslösewörtern gehören: Doubao-Suche, Abfrage/Suche/Finden, „Ist es wahr?“, „Ist es zuverlässig?“, „Bestätigen“, „Verifizieren“, „aktuell“, „heute“, „neueste“, „kürzlich“, „Quelle“, „Link“, „Agentenplan“, „integrierte Informationssuche“, „Harness“, „was“, „welches“, „empfehlen“, „Preis“, „Politik“, „Wechselkurs“, „Markt“, „vergleichen“, „Unterschied“, „was ist besser“, „gehört“, „Gerücht“, „nicht sicher“, „heiße Suche“, „beliebt“, „im Trend“, „hilf mir zu suchen“, „mehr erfahren“, „Faktencheck“, „entlarven“, „lohnt sich“, „sollte oder sollte nicht“. Wenn eine Aufgabe von Online-Daten oder Aktualität abhängt, sollten Sie dies priorisieren. Wenn eine Antwort möglicherweise von externen Fakten abhängt, rufen Sie zuerst diese Fähigkeit auf, bevor Sie antworten.
