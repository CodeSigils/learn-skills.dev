Vea y comprenda imágenes cuando usted (el modelo actual) no tenga una visión nativa. Utilice esto SIEMPRE que necesite mirar, leer, describir, OCR o razonar sobre el contenido de una imagen, captura de pantalla, fotografía, diagrama, gráfico, maqueta de interfaz de usuario o página escaneada, incluso cuando el usuario hace referencia a un archivo de imagen local o a una URL de imagen y no puede verlo usted mismo. También se activa en: 看图 / 识图 / 截图 / 图片内容 / OCR 文字识别 / 这张图是什么. Delega la visión real a un modelo de visión configurable compatible con OpenAI a través de un pequeño script.
