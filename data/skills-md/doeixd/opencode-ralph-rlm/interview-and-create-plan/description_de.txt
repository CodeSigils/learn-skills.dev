Bevor Sie eine Ralph RLM-Schleife starten, befragen Sie den Benutzer, um das Ziel zu präzisieren, testen Sie das Design einem Stresstest und schreiben Sie einen verfassten PLAN.md (Ziel, Definition von erledigt, Meilensteine, offene Fragen, Invarianten), dem die Schleife folgen kann. Verwenden Sie diese Option, wenn ein Benutzer die Arbeit planen, festlegen oder einem Stresstest unterziehen möchte, bevor er sie an den Supervisor/start_loop delegiert, oder wenn PLAN.md immer noch der Platzhalter-Bootstrap ist.
