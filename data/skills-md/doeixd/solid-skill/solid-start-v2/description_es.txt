Guía para crear, revisar y refactorizar aplicaciones SolidStart v2 de alta calidad utilizando patrones idiomáticos de ruta, datos, mutación, servidor e implementación. Utilice esto siempre que el usuario esté trabajando en una aplicación SolidStart o mencione `@solidjs/start`, `@solidjs/router`, ruta `preload`, `query`, `action`, `createAsync`, formularios, sesiones, middleware, rutas API, metadatos o configuración de la aplicación en Start v2. Úselo incluso cuando el usuario no diga explícitamente "SolidStart" si claramente está creando una aplicación Solid de pila completa con mutaciones y datos de servidor basados ​​en rutas.
