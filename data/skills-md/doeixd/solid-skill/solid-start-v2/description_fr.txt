Conseils pour créer, réviser et refactoriser des applications SolidStart v2 de haute qualité à l'aide de modèles d'itinéraire, de données, de mutation, de serveur et de déploiement idiomatiques. Utilisez-le chaque fois que l'utilisateur travaille dans une application SolidStart ou mentionne `@solidjs/start`, `@solidjs/router`, route `preload`, `query`, `action`, `createAsync`, formulaires, sessions, middleware, routes API, métadonnées ou configuration de l'application dans Start v2. Utilisez-le même lorsque l'utilisateur ne dit pas explicitement « SolidStart » s'il crée clairement une application Solid full-stack avec des données de serveur et des mutations basées sur les itinéraires.
