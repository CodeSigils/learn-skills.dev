إرشادات لبناء ومراجعة وإعادة بناء تطبيقات SolidStart v2 عالية الجودة باستخدام أنماط المسار والبيانات والطفرات والخادم والنشر الاصطلاحية. استخدم هذا عندما يعمل المستخدم في تطبيق SolidStart أو يذكر `@solidjs/start` أو `@solidjs/router` أو المسار `التحميل المسبق` أو `الاستعلام` أو `الإجراء` أو `createAsync` أو النماذج أو الجلسات أو البرامج الوسيطة أو مسارات واجهة برمجة التطبيقات أو البيانات التعريفية أو إعداد التطبيق في Start v2. استخدمه حتى عندما لا يقول المستخدم صراحةً "SolidStart" إذا كان من الواضح أنه يقوم بإنشاء تطبيق Solid كامل المكدس مع بيانات الخادم والطفرات المستندة إلى المسار.
