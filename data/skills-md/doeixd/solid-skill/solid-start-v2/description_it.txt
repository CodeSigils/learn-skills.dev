Linee guida per la creazione, la revisione e il refactoring di applicazioni SolidStart v2 di alta qualità utilizzando percorsi idiomatici, dati, mutazioni, server e modelli di distribuzione. Utilizzalo ogni volta che l'utente lavora in un'app SolidStart o menziona `@solidjs/start`, `@solidjs/router`, route `preload`, `query`, `action`, `createAsync`, moduli, sessioni, middleware, percorsi API, metadati o configurazione dell'app in Start v2. Usalo anche quando l'utente non dice esplicitamente "SolidStart" se sta chiaramente creando un'app Solid full-stack con dati e mutazioni del server basati su route.
