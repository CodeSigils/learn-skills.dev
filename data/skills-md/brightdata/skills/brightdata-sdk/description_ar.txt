استخراج بيانات الويب واكتشافها باستخدام Bright Data Python SDK.
يُستخدم عندما يطلب المستخدم "استخراج" أو "الحصول على البيانات من" أو "استخراج" أو "البحث عن"،
أو "البحث" عن معلومات من مواقع الويب. استخدم أيضًا عندما يذكر المستخدم محددًا
منصات مثل Amazon وLinkedIn وInstagram وFacebook وTikTok وYouTube،
Reddit أو Pinterest أو Zillow أو Crunchbase أو DigiKey، أو يطلب "بيانات مجمعة"،
"البيانات التاريخية" أو "مجموعة البيانات". يغطي تجريف، والبحث، ومجموعات البيانات،
وأتمتة المتصفح.
