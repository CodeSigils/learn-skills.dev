就即時網路中的某個主題製作深入的、多來源的、被引用的研究簡介
使用 Bright Data 的 Discover API 取得資料（意圖排名的網路搜尋 + 解析的頁面
內容）。當使用者想要「即時研究」、「深入研究<主題>」時使用，
「研究最新的」、「寫一份報告」、「給我一個簡報/文獻
審查/市場掃描”，“尋找並綜合有關的所有內容”，或其他
想要一個綜合的、基於來源的答案，而不是連結列表。將問題分解為多個按意圖排序的 Discover
查詢、擷取頁面內容、刪除重複內容並依相關性排名，然後
綜合帶有內嵌引文的結構化摘要。建立在
`discover-api` 技能。對於特定於競爭對手的情報，請使用「competitive-intel」；
對於社交/品牌情感，請使用「品牌聆聽」；用於檢索*系統*（不是
一次性報告）使用“rag-pipeline”。
