Integra un agente in Bright Data. Utilizzare quando si utilizza prima un agente di codifica
incontra Bright Data: per il lavoro sul web dal vivo (ricerca, scraping,
dati strutturati), per collegare Bright Data al codice prodotto, per
installare il pacchetto di competenze dell'agente o ottenere una chiave API. Uno
Il comando install configura la CLI, le competenze dell'agente e l'autenticazione.
Indirizza il lettore sulla strada giusta: strumenti live, integrazione di app,
MCP, solo autenticazione o REST diretto senza alcuna installazione.
