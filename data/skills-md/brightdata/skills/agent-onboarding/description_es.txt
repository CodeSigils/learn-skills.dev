Incorporar un agente a Bright Data. Úselo cuando un agente de codificación primero
encuentra Bright Data: para trabajo web en vivo (búsqueda, extracción,
datos estructurados), para conectar Bright Data al código de producto, para
instalar el paquete de habilidades del agente u obtener una clave API. uno
El comando install configura la CLI, las habilidades del agente y la autenticación.
Dirige al lector por el camino correcto: herramientas en vivo, integración de aplicaciones,
MCP, solo autenticación o REST directo sin ninguna instalación.
