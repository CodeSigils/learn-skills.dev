Подключите агента к Bright Data. Используйте, когда агент кодирования сначала
сталкивается с Bright Data — для оперативной работы в Интернете (поиск, очистка,
структурированные данные), для подключения Bright Data к коду продукта, для
установка пакета навыков агента или получение ключа API. Один
Команда install настраивает интерфейс командной строки, навыки агента и аутентификацию.
Направляет читателя на правильный путь: живые инструменты, интеграция приложений,
MCP, только авторизация или прямой REST без установки.
