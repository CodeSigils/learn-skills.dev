تصحيح أخطاء جلسات متصفح Bright Data Scraping باستخدام واجهة برمجة تطبيقات جلسات المتصفح. استخدم هذه المهارة عندما يواجه المستخدم خطأ في جلسة متصفح Bright Data، أو تتبع مكدس محرك الدمى، أو فشل تشغيل الكاشطة، أو يسأل عن النطاق الترددي للجلسة، أو المدة، أو رموز التحقق، أو مشكلات الاتصال. يُستخدم أيضًا عندما تنتج أداة استخراج البيانات الساطعة نتائج غير متوقعة مثل البيانات الفارغة، أو العثور على 0 عنصر، أو المنتجات المفقودة، أو نتائج أقل من المتوقع - يمكن أن تكشف بيانات الجلسة ما إذا كانت المشكلة من جانب الشبكة/الوكيل (الحظر، أو رموز التحقق، أو عمليات إعادة التوجيه، أو المهلات) أو من جانب العميل (المحددات، منطق الاستخراج). تشغيل عبارات مثل "لماذا فشلت جلستي"، أو "تصحيح جلسة البيانات الساطعة الخاصة بي"، أو "التحقق من جلسات استخراج البيانات من المتصفح"، أو "مقدار النطاق الترددي الذي استخدمته أداة الكشط الخاصة بي"، أو "حصلت على 0 نتيجة"، أو "تم العثور على 0"، أو "تم إرجاع المكشطة فارغة"، أو "المكشطة لا تعمل"، أو "البرنامج النصي لا يعمل"، أو عندما يظهر رمز خطأ Bright Data أو تتبع مكدس brd.superproxy.io في المحادثة. يتطلب متغير البيئة BRIGHTDATA_API_KEY.
