Déboguez les sessions du navigateur Bright Data Scraping à l’aide de l’API des sessions du navigateur. Utilisez cette compétence lorsque l'utilisateur rencontre une erreur de session du navigateur Bright Data, une trace de pile de marionnettiste, un échec d'exécution du scraper ou pose des questions sur la bande passante, la durée, les captchas ou les problèmes de connexion de la session. À utiliser également lorsqu'un grattoir Bright Data produit des résultats inattendus tels que des données vides, aucun élément trouvé, des produits manquants ou moins de résultats que prévu — les données de session peuvent révéler si le problème est côté réseau/proxy (blocages, captchas, redirections, délais d'attente) ou côté client (sélecteurs, logique d'extraction). Se déclenche sur des phrases telles que « pourquoi ma session a-t-elle échoué », « déboguer ma session Bright Data », « vérifier mes sessions de navigateur de scraping », « combien de bande passante mon scraper a-t-il utilisé », « j'ai obtenu 0 résultat », « trouvé 0 », « le scraper est revenu vide », « le scraper ne fonctionne pas », « le script n'a pas fonctionné », ou lorsqu'un code d'erreur Bright Data ou une trace de pile brd.superproxy.io apparaît dans la conversation. Nécessite la variable d'environnement BRIGHTDATA_API_KEY.
