ブラウザ セッション API を使用して、Bright Data Scraping ブラウザ セッションをデバッグします。このスキルは、ユーザーが Bright Data ブラウザーのセッション エラー、Puppeteer のスタック トレース、スクレイパーの実行の失敗に遭遇した場合、またはセッションの帯域幅、期間、キャプチャ、または接続の問題について質問した場合に使用します。また、Bright Data スクレーパーが、空のデータ、0 個のアイテムが見つかった、商品が見つからない、または予想より少ない結果など、予期しない結果を生成する場合にも使用します。セッション データにより、問題がネットワーク/プロキシ側 (ブロック、キャプチャ、リダイレクト、タイムアウト) にあるのか、クライアント側 (セレクター、抽出ロジック) にあるのかが明らかになります。 「セッションが失敗した理由」、「ブライト データ セッションをデバッグする」、「スクレイピング ブラウザ セッションを確認する」、「スクレイパーが使用した帯域幅の量」、「取得結果が 0 件」、「検出結果が 0 件」、「スクレイパーが空で返された」、「スクレイパーが動作していない」、「スクリプトが動作しなかった」などのフレーズ、または会話中に Bright Data エラー コードまたは brd.superproxy.io スタック トレースが表示された場合にトリガーされます。 BRIGHTDATA_API_KEY 環境変数が必要です。
