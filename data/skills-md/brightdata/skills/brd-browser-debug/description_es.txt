Depure las sesiones del navegador Bright Data Scraping utilizando la API de sesiones del navegador. Utilice esta habilidad cuando el usuario encuentre un error de sesión del navegador Bright Data, un seguimiento de la pila de titiritero, una ejecución fallida del raspador o pregunte sobre el ancho de banda de la sesión, la duración, los captchas o problemas de conexión. Úselo también cuando un raspador de Bright Data produzca resultados inesperados, como datos vacíos, 0 elementos encontrados, productos faltantes o menos resultados de los esperados; los datos de la sesión pueden revelar si el problema es del lado de la red/proxy (bloques, captchas, redirecciones, tiempos de espera) o del lado del cliente (selectores, lógica de extracción). Se activan frases como "por qué falló mi sesión", "depurar mi sesión de Bright Data", "verificar mis sesiones de raspado del navegador", "cuánto ancho de banda usó mi raspador", "obtuve 0 resultados", "encontré 0", "el raspador devolvió vacío", "el raspador no funciona", "el script no funcionó" o cuando aparece un código de error de Bright Data o un seguimiento de pila de brd.superproxy.io en la conversación. Requiere la variable de entorno BRIGHTDATA_API_KEY.
