使用瀏覽器會話 API 偵錯 Bright Data Scraping 瀏覽器會話。當使用者遇到 Bright Data 瀏覽器會話錯誤、puppeteer 堆疊追蹤、爬蟲運行失敗或詢問會話頻寬、持續時間、驗證碼或連線問題時，請使用此技能。當 Bright Data scraper 產生意外結果（例如空資料、找到 0 個項目、缺少產品或結果少於預期）時也可以使用 - 會話資料可以揭示問題是網路/代理端（區塊、驗證碼、重定向、逾時）還是客戶端（選擇器、提取邏輯）。諸如「為什麼我的會話失敗」、「除錯我的 Bright Data 會話」、「檢查我的抓取瀏覽器會話」、「我的抓取器使用了多少頻寬」、「得到 0 個結果」、「找到 0」、「抓取器返回空」、「抓取器不工作」、「腳本不工作」等短語，或者當對話中出現在對話中 Datardio 配置需要 BRIGHTDATA_API_KEY 環境變數。
