브라우저 세션 API를 사용하여 Bright Data Scraping 브라우저 세션을 디버그합니다. 사용자가 Bright Data 브라우저 세션 오류, Puppeteer 스택 추적, 스크레이퍼 실행 실패를 경험하거나 세션 대역폭, 기간, 보안 문자 또는 연결 문제에 대해 묻는 경우 이 기술을 사용하십시오. 또한 Bright Data 스크레이퍼가 빈 데이터, 발견된 항목 0개, 제품 누락 또는 예상보다 적은 결과와 같은 예상치 못한 결과를 생성하는 경우에도 사용합니다. 세션 데이터는 문제가 네트워크/프록시 측(차단, 보안 문자, 리디렉션, 시간 초과)인지 클라이언트 측(선택기, 추출 논리)인지 여부를 밝힐 수 있습니다. '내 세션이 실패한 이유', '내 브라이트 데이터 세션 디버그', '내 스크래핑 브라우저 세션 확인', '내 스크래퍼가 사용한 대역폭은 얼마입니까?', '결과 0개', '0 발견', '스크래퍼가 비어 있는 것으로 반환됨', '스크레이퍼가 작동하지 않음', '스크립트가 작동하지 않음' 또는 Bright Data 오류 코드 또는 brd.superproxy.io 스택 추적이 대화에 나타날 때와 같은 문구에 대해 트리거됩니다. BRIGHTDATA_API_KEY 환경 변수가 필요합니다.
