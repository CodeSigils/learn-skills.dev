قم بإنشاء كود عمل يوجه طلبات HTTP عبر شبكات وكيل Bright Data (مركز البيانات، ومزود خدمة الإنترنت، والسكني، والمحمول) ومساعدة المستخدمين على تحديد الشبكة ونوع تجمع IP المراد استخدامه (تجمع مشترك، أو عناوين IP مشتركة، أو عناوين IP مخصصة). استخدم هذه المهارة عندما يذكر المستخدم Bright Data، Brightdata.com، BD proxies، brd.superproxy.io، Geo.brdtest.com، اسم مستخدم brd-customer-proxy، منطقة Bright Data، مضيف superproxy، أو يريد استخراج الطلبات أو توجيهها من خلال Bright Data - بما في ذلك أسئلة حول تنسيق عنوان URL للوكيل، أو البلد أو الجلسة أو IP أو استهداف الجلسة الثابتة، وإعداد شهادة SSL للوكلاء السكنيين أو المحمول، والتحقق من KYC، والتجاهل أخطاء SSL، أو الاختيار بين التجمع المشترك وعناوين IP المشتركة وعناوين IP المخصصة، أو دمج Bright Data في طلبات Python/httpx/aiohttp، أو Node fetch/axios، أو Playwright، أو Puppeteer، أو Selenium، أو Scrapy.
