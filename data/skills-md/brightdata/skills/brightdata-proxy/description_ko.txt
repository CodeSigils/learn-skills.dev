Bright Data 프록시 네트워크(데이터 센터, ISP, 주거용, 모바일)를 통해 HTTP 요청을 라우팅하는 작업 코드를 생성하고 사용자가 사용할 네트워크 및 IP 풀 유형(공유 풀, 공유 IP 또는 전용 IP)을 결정하는 데 도움을 줍니다. 사용자가 Bright Data, Brightdata.com, BD 프록시, brd.superproxy.io, geo.brdtest.com, brd-customer-proxy 사용자 이름, Bright Data 영역, 슈퍼 프록시 호스트를 언급하거나 Bright Data를 통해 요청을 스크랩하거나 라우팅하려고 할 때마다 이 기술을 사용하십시오. 여기에는 프록시 URL 형식, 국가 또는 세션 또는 IP 또는 고정 세션 타겟팅, 주거용 또는 모바일 프록시에 대한 SSL 인증서 설정, KYC 확인, SSL 오류 무시, 공유 중 선택 등이 포함됩니다. 풀, 공유 IP 및 전용 IP 또는 Bright Data를 Python 요청/httpx/aiohttp, 노드 가져오기/axios, Playwright, Puppeteer, Selenium 또는 Scrapy에 통합합니다.
