Bright Data プロキシ ネットワーク (データセンター、ISP、住宅、モバイル) 経由で HTTP リクエストをルーティングする実用的なコードを生成し、ユーザーがどのネットワークと IP プール タイプ (共有プール、共有 IP、または専用 IP) を使用するかを決定できるようにします。ユーザーが Bright Data、brightdata.com、BD プロキシ、brd.superproxy.io、geo.brdtest.com、brd-customer-proxy ユーザー名、Bright Data ゾーン、スーパープロキシ ホストについて言及する場合、または Bright Data を介してリクエストをスクレイピングまたはルーティングする場合は必ずこのスキルを使用します。これには、プロキシ URL 形式、国またはセッション、IP またはスティッキー セッションのターゲティング、住宅またはモバイル プロキシの SSL 証明書の設定、KYC 検証、SSL の無視に関する質問が含まれます。エラー、共有プール、共有 IP、専用 IP のいずれかを選択するか、Bright Data を Python リクエスト/httpx/aiohttp、Node fetch/axios、Playwright、Puppeteer、Selenium、または Scrapy に統合します。
