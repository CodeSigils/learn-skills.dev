Crea web scraper pronti per la produzione per qualsiasi sito Web utilizzando l'infrastruttura Bright Data. Ti guida attraverso l'analisi del sito, la selezione dell'API, l'estrazione del selettore, la gestione dell'impaginazione e l'implementazione completa dello scraper. Utilizza questa competenza ogni volta che l'utente desidera creare uno scraper, creare un crawler, estrarre dati da un sito Web, eseguire lo scraping di pagine di prodotti, gestire l'impaginazione, creare una pipeline di dati da una fonte Web o automatizzare la raccolta di dati da qualsiasi sito, anche se non dice esplicitamente "scraper". Si attiva su frasi come "costruisci uno scraper per", "raschia dati da", "estrai prodotti da", "scansione pagine", "ottieni dati da [sito Web]" o "devo estrarre dati da".
