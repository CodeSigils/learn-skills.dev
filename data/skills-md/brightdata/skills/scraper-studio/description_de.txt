Erstellen und führen Sie KI-generierte Bright Data Scraper vom Terminal aus über „bdata scraper create“ und „bdata scraper run“. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen Scraper aus einer Beschreibung in natürlicher Sprache generieren, einen benutzerdefinierten Scraper erstellen möchte, ohne Code schreiben zu müssen, eine URL + Beschreibung in einfachem Englisch in einen wiederverwendbaren Scraper umwandeln, einen vorhandenen Bright Data-Collector für eine URL ausführen oder eine Liste von URLs über einen Collector stapelweise scannen möchte. Wird bei Ausdrücken wie „Baue mir einen Scraper für“, „Erstelle einen Scraper, der extrahiert“, „Generiere einen Scraper aus einer Beschreibung“, „Verwandle diese URL in einen Scraper“, „Führe diesen Scraper aus“, „Führe meinen Collector aus“, „Batch Scrape“, „Scrape dieser URLs“, „Scrape eine Liste von URLs“, „Konkurrenzpreistabelle“, „Scraper Studio“, „Scraper Create“, „Scraper“ aus run“, „--urls“, „--input-file“, „collector_id“, „automate_template“ oder „/dca/“. Deckt den KI-Fluss ab (Vorlage erstellen → AI-Generierung auslösen → Abfragefortschritt), den Einzel-URL-Ausführungsablauf (standardmäßig asynchron + Abfrage, „--sync“ für schnelle Seiten), den Batch-Fluss mit mehreren URLs („--urls“ / „--input-file“ → ein „/dca/trigger“-Aufruf mit Array-Körper) und den stillen automatischen Fallback auf den Batch-Endpunkt, wenn eine URL über das Echtzeit-Seitenlimit hinaus erweitert wird. Erfordert die Bright Data-CLI.
