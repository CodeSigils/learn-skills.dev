قم ببناء وتشغيل أدوات استخراج البيانات الساطعة التي تم إنشاؤها بواسطة الذكاء الاصطناعي من الجهاز الطرفي عبر "إنشاء مكشطة بيانات bdata" و"تشغيل مكشطة بيانات bdata". استخدم هذه المهارة عندما يريد المستخدم إنشاء أداة استخراج بيانات من وصف باللغة الطبيعية، أو إنشاء أداة استخراج بيانات مخصصة دون كتابة تعليمات برمجية، أو تحويل عنوان URL + وصف باللغة الإنجليزية البسيطة إلى أداة استخراج بيانات قابلة لإعادة الاستخدام، أو تشغيل أداة تجميع بيانات Bright Data الموجودة على عنوان URL، أو استخراج قائمة من عناوين URL من خلال أداة تجميع واحدة. تشغيل عبارات مثل "إنشاء أداة استخراج لي"، و"إنشاء أداة استخراج تستخرج"، و"إنشاء أداة استخراج من الوصف"، و"تحويل عنوان URL هذا إلى أداة استخراج"، و"تشغيل أداة استخراج البيانات هذه"، و"تشغيل أداة التجميع الخاصة بي"، و"مسح الدُفعات"، و"مسح عناوين URL هذه"، و"استخلاص قائمة بعناوين URL"، و"جدول الأسعار التنافسية"، و"استوديو أداة النسخ"، و"إنشاء أداة استخراج"، `تشغيل المكشطة` أو `--urls` أو `--input-file` أو `collector_id` أو `automate_template` أو `/dca/`. يغطي تدفق الذكاء الاصطناعي (إنشاء قالب ← تشغيل إنشاء الذكاء الاصطناعي ← تقدم الاستقصاء)، وتدفق تشغيل عنوان URL واحد (غير متزامن + استطلاع بشكل افتراضي، `--sync` للصفحات السريعة)، وتدفق دفعة عناوين URL المتعددة (`--urls` / `--input-file` → استدعاء واحد `/dca/trigger` مع نص المصفوفة)، والرجوع التلقائي الصامت إلى نقطة نهاية الدُفعة عندما يتوسع عنوان URL ليتجاوز حد الصفحة في الوقت الفعلي. يتطلب Bright Data CLI.
