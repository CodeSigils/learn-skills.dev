Создавайте и запускайте сгенерированные искусственным интеллектом парсеры Bright Data с терминала с помощью `bdata Scraper Create` и `bdata Scraper Run`. Используйте этот навык всякий раз, когда пользователь хочет создать парсер из описания на естественном языке, создать собственный парсер без написания кода, превратить URL-адрес + простое английское описание в парсер многократного использования, запустить существующий сборщик Bright Data для URL-адреса или выполнить пакетное парсинг списка URL-адресов с помощью одного сборщика. Запускается по таким фразам, как «создайте мне парсер для», «создайте парсер, который извлекает данные», «создайте парсер из описания», «превратите этот URL-адрес в парсер», «запустите этот парсер», «запустите мой сборщик», «пакетный парсинг», «очистите эти URL-адреса», «очистите список URL-адресов», «таблицу конкурентных цен», «скребок Studio», «скребок создать», «скребок», `--urls`, `--input-file`, `collector_id`, `automate_template` или `/dca/`. Охватывает поток AI (создание шаблона → триггер генерации AI → ход опроса), поток выполнения одного URL-адреса (по умолчанию async + poll, `--sync` для быстрых страниц), пакетный поток с несколькими URL-адресами (`--urls` / `--input-file` → один вызов `/dca/trigger` с телом массива) и автоматический автоматический возврат к конечной точке пакета, когда URL-адрес расширяется за пределы страницы в реальном времени. Требуется интерфейс командной строки Bright Data.
