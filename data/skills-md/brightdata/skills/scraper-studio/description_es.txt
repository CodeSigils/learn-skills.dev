Utilice esta habilidad siempre que el usuario desee generar un raspador a partir de una descripción en lenguaje natural, crear un raspador personalizado sin escribir código, convertir una URL + descripción en inglés simple en un raspador reutilizable, ejecutar un recopilador de Bright Data existente contra una URL o extraer por lotes una lista de URL a través de un recopilador.
