Créez et exécutez des scrapers Bright Data générés par l'IA à partir du terminal via « bdata scraper create » et « bdata scraper run ». Utilisez cette compétence chaque fois que l'utilisateur souhaite générer un scraper à partir d'une description en langage naturel, créer un scraper personnalisé sans écrire de code, transformer une URL + une description en anglais simple en un scraper réutilisable, exécuter un collecteur Bright Data existant sur une URL ou gratter par lots une liste d'URL via un collecteur. Déclencheurs sur des expressions telles que « créez-moi un scraper pour », « créez un scraper qui extrait », « générez un scraper à partir d'une description », « transformez cette URL en un scraper », « exécutez ce scraper sur », « exécutez mon collecteur », « scraper par lots », « scrape ces URL », « scrape une liste d'URL », « tableau de prix compétitifs », « scraper studio », `scraper create`, `scraper run`, `--urls`, `--input-file`, `collector_id`, `automate_template` ou `/dca/`. Couvre le flux AI (création de modèle → déclencher la génération AI → progression du sondage), le flux d'exécution à URL unique (async + sondage par défaut, `--sync` pour les pages rapides), le flux par lots multi-URL (`--urls` / `--input-file` → un appel `/dca/trigger` avec le corps du tableau) et le repli automatique silencieux vers le point de terminaison du lot lorsqu'une URL dépasse la limite de page en temps réel. Nécessite la CLI Bright Data.
