通过“bdata scraper create”和“bdata scraper run”从终端构建并运行人工智能生成的 Bright Data scraper。每当用户想要从自然语言描述生成抓取器、在不编写代码的情况下构建自定义抓取器、将 URL + 简单英语描述转换为可重用抓取器、针对 URL 运行现有的 Bright Data 收集器或通过一个收集器批量抓取 URL 列表时，请使用此技能。触发诸如“为我构建一个抓取工具”、“创建一个可提取的抓取工具”、“根据描述生成一个抓取工具”、“将此 URL 转换为抓取工具”、“运行此抓取工具”、“运行我的收集器”、“批量抓取”、“抓取这些 URL”、“抓取 URL 列表”、“竞争性定价表”、“抓取工作室”等短语`scraper create`、`scraper run`、`--urls`、`--input-file`、`collector_id`、`automate_template` 或 `/dca/`。涵盖 AI 流程（模板创建 → 触发 AI 生成 → 轮询进度）、单 URL 运行流程（默认为异步 + 轮询，用于快速页面的“--sync”）、多 URL 批处理流程（“--urls”/“--input-file” → 使用数组主体的一个“/dca/trigger”调用），以及当 URL 扩展超过实时页面限制时静默自动回退到批处理端点。需要 Bright Data CLI。
