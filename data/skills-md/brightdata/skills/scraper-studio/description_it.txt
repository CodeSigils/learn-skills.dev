Costruisci ed esegui scraper Bright Data generati dall'intelligenza artificiale dal terminale tramite "bdata scraper create" e "bdata scraper run". Utilizza questa abilità ogni volta che l'utente desidera generare uno scraper da una descrizione in linguaggio naturale, creare uno scraper personalizzato senza scrivere codice, trasformare un URL + una descrizione in inglese semplice in uno scraper riutilizzabile, eseguire un raccoglitore Bright Data esistente rispetto a un URL o eseguire lo scraping in batch di un elenco di URL tramite un raccoglitore. Si attiva su frasi come "costruiscimi uno scraper per", "crea uno scraper che estrae", "genera uno scraper da una descrizione", "trasforma questo URL in uno scraper", "esegui questo scraper", "esegui il mio raccoglitore", "scrape batch", "raschia questi URL", "raschia un elenco di URL", "tabella dei prezzi competitivi", "scraper studio", `scraper create`, `scraper run`, `--urls`, `--input-file`, `collector_id`, `automate_template` o `/dca/`. Copre il flusso AI (creazione modello → generazione trigger AI → avanzamento sondaggio), il flusso di esecuzione di URL singolo (asincrono + poll per impostazione predefinita, `--sync` per pagine veloci), il flusso batch multi-URL (`--urls` / `--input-file` → una chiamata `/dca/trigger` con corpo dell'array) e il fallback automatico silenzioso all'endpoint batch quando un URL si espande oltre il limite di pagine in tempo reale. Richiede la CLI Bright Data.
