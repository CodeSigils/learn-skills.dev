AI 生成の Bright Data スクレーパーをビルドし、ターミナルから「bdata Slayer create」および「bdata Slayer run」を介して実行します。このスキルは、ユーザーが自然言語の説明からスクレイパーを生成する場合、コードを書かずにカスタム スクレイパーを構築する場合、URL と平易な英語の説明を再利用可能なスクレイパーに変換する場合、URL に対して既存の Bright Data コレクターを実行する場合、または 1 つのコレクターを通じて URL のリストをバッチ スクレイピングする場合に使用します。 「スクレイパーを作成してください」、「抽出するスクレイパーを作成します」、「説明からスクレイパーを生成します」、「この URL をスクレイパーに変換します」、「このスクレイパーを実行します」、「コレクターを実行します」、「バッチ スクレイピング」、「これらの URL をスクレイピング」、「URL のリストをスクレイピング」、「競争力のある価格表」、「スクレイパー スタジオ」などのフレーズでトリガーされます。 `scraper create`、`scraper run`、`--urls`、`--input-file`、`collector_id`、`automate_template`、または `/dca/`。 AI フロー (テンプレートの作成 → トリガー AI 生成 → ポーリングの進行状況)、単一 URL の実行フロー (デフォルトで非同期 + ポーリング、高速ページの場合は `--sync`)、複数 URL バッチ フロー (`--urls` / `--input-file` → 配列本体を使用した 1 つの `/dca/trigger` 呼び出し)、および URL がリアルタイム ページ制限を超えて拡大した場合のバッチ エンドポイントへのサイレント自動フォールバックについて説明します。 Bright Data CLI が必要です。
