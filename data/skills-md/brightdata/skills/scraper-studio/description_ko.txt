'bdata scraper create' 및 'bdata scraper run'을 통해 터미널에서 AI 생성 Bright Data 스크래퍼를 구축하고 실행합니다. 사용자가 자연어 설명에서 스크레이퍼를 생성하거나, 코드를 작성하지 않고 사용자 정의 스크레이퍼를 구축하거나, URL + 일반 영어 설명을 재사용 가능한 스크레이퍼로 전환하거나, URL에 대해 기존 Bright Data 수집기를 실행하거나, 하나의 수집기를 통해 URL 목록을 일괄 스크랩하려는 경우마다 이 기술을 사용하세요. '다음을 위한 스크레이퍼 구축', '추출하는 스크레이퍼 생성', '설명에서 스크레이퍼 생성', '이 URL을 스크레이퍼로 전환', '이 스크레이퍼 실행', '내 수집기 실행', '일괄 스크래핑', '이 URL 스크레이핑', 'URL 목록 스크랩', '경쟁력 있는 가격표', '스크레이퍼 스튜디오', '스크래퍼 생성', '스크래퍼 실행', `--urls`, `--input-file`, `collector_id`, `automate_template` 또는 `/dca/`. AI 흐름(템플릿 생성 → AI 생성 트리거 → 폴링 진행), 단일 URL 실행 흐름(기본적으로 비동기 + 폴링, 빠른 페이지의 경우 `--sync`), 다중 URL 배치 흐름(`--urls` / `--input-file` → 배열 본문이 있는 하나의 `/dca/trigger` 호출) 및 URL이 실시간 페이지 제한을 초과하여 확장될 때 배치 엔드포인트로의 자동 자동 대체를 다룹니다. Bright Data CLI가 필요합니다.
