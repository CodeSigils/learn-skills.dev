使用 Bright Data CLI（“brightdata”/“bdata”）抓取網站、搜尋網路、從 40 多個平台提取結構化資料、管理代理區域以及檢查帳戶預算的指南。每當用戶想要抓取 URL、搜尋 Google/Bing/Yandex、從 Amazon/LinkedIn/Instagram/TikTok/YouTube/Reddit 或任何其他平台提取資料、檢查其 Bright Data 餘額或區域，或執行任何涉及從終端收集 Web 資料的操作時，請使用此技能。當使用者提及 BrightData、bdata、Web 抓取 CLI、SERP API 或想要將 Bright Data 技能安裝到其編碼代理程式時也會觸發。
