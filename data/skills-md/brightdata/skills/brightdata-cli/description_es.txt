Guía para usar la CLI de Bright Data ("brightdata" / "bdata") para extraer sitios web, realizar búsquedas en la web, extraer datos estructurados de más de 40 plataformas, administrar zonas proxy y verificar el presupuesto de la cuenta. Utilice esta habilidad siempre que el usuario quiera extraer una URL, buscar en Google/Bing/Yandex, extraer datos de Amazon/LinkedIn/Instagram/TikTok/YouTube/Reddit o cualquier otra plataforma, verificar su saldo o zonas de Bright Data, o hacer cualquier cosa que implique la recopilación de datos web desde el terminal. También se activa cuando el usuario menciona brightdata, bdata, web scraping CLI, SERP API o desea instalar habilidades de Bright Data en su agente de codificación.
