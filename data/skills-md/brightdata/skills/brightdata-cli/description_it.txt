Guida per l'utilizzo della CLI Bright Data (`brightdata` / `bdata`) per analizzare siti Web, eseguire ricerche sul Web, estrarre dati strutturati da oltre 40 piattaforme, gestire zone proxy e controllare il budget dell'account. Utilizza questa abilità ogni volta che l'utente desidera recuperare un URL, cercare su Google/Bing/Yandex, estrarre dati da Amazon/LinkedIn/Instagram/TikTok/YouTube/Reddit o qualsiasi altra piattaforma, controllare il saldo o le zone di Bright Data o eseguire qualsiasi cosa che implichi la raccolta di dati web dal terminale. Si attiva anche quando l'utente menziona brightdata, bdata, CLI di web scraping, API SERP o desidera installare competenze Bright Data nel proprio agente di codifica.
