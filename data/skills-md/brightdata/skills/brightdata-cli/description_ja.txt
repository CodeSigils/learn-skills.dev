Bright Data CLI (`brightdata` / `bdata`) を使用して、Web サイトのスクレイピング、Web の検索、40 以上のプラットフォームからの構造化データの抽出、プロキシ ゾーンの管理、アカウント予算の確認を行うためのガイド。ユーザーが URL のスクレイピング、Google/Bing/Yandex の検索、Amazon/LinkedIn/Instagram/TikTok/YouTube/Reddit またはその他のプラットフォームからのデータの抽出、Bright Data のバランスやゾーンの確認、または端末からの Web データ収集に関連する操作を行う場合は常にこのスキルを使用します。また、ユーザーが Brightdata、bdata、Web スクレイピング CLI、SERP API に言及した場合、または Bright Data スキルをコーディング エージェントにインストールしたい場合にもトリガーされます。
