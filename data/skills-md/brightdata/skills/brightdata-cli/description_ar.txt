دليل لاستخدام Bright Data CLI (`brightdata` / `bdata`) لاستخراج مواقع الويب، والبحث في الويب، واستخراج البيانات المنظمة من أكثر من 40 نظامًا أساسيًا، وإدارة مناطق الوكيل، والتحقق من ميزانية الحساب. استخدم هذه المهارة عندما يريد المستخدم استخراج عنوان URL، أو البحث في Google/Bing/Yandex، أو استخراج البيانات من Amazon/LinkedIn/Instagram/TikTok/YouTube/Reddit أو أي نظام أساسي آخر، أو التحقق من رصيد أو مناطق Bright Data الخاصة به، أو القيام بأي شيء يتضمن جمع بيانات الويب من الجهاز. يتم تشغيله أيضًا عندما يذكر المستخدم Brightdata أو bdata أو Web Scraping CLI أو SERP API أو يريد تثبيت مهارات Bright Data في وكيل الترميز الخاص به.
