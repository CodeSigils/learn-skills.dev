Руководство по использованию интерфейса командной строки Bright Data («brightdata» / «bdata») для очистки веб-сайтов, поиска в Интернете, извлечения структурированных данных с более чем 40 платформ, управления прокси-зонами и проверки бюджета аккаунта. Используйте этот навык всякий раз, когда пользователь хочет очистить URL-адрес, выполнить поиск в Google/Bing/Яндексе, извлечь данные из Amazon/LinkedIn/Instagram/TikTok/YouTube/Reddit или любой другой платформы, проверить баланс или зоны Bright Data или сделать что-либо, связанное со сбором веб-данных с терминала. Также срабатывает, когда пользователь упоминает Brightdata, bdata, CLI для очистки веб-страниц, API SERP или хочет установить навыки Bright Data в свой агент кодирования.
