Active frases como "hacer que se vea", "coincidir con el diseño de", "copiar el estilo de", "quiero que mi aplicación se vea como X", "reflejar este diseño", "inspirado en [url]", o cada vez que el usuario señala un sitio web y dice que quiere que su interfaz coincida.
