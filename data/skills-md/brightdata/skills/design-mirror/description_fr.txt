Reproduisez le style visuel de n’importe quel site Web et appliquez-le à votre base de code existante. Utilisez cette compétence chaque fois que l'utilisateur souhaite faire correspondre la conception d'un site, refléter l'esthétique d'une interface utilisateur, faire ressembler son application à un autre site ou reproduire un style visuel spécifique à partir d'une URL. Déclenchez des expressions telles que « faire ressembler », « faire correspondre le design de », « copier le style de », « Je veux que mon application ressemble à X », « refléter ce design », « inspiré par [url] », ou à chaque fois que l'utilisateur pointe sur un site Web et dit qu'il souhaite que son interface y corresponde.
