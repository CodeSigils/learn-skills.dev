الاستماع الاجتماعي وأبحاث سمعة العلامة التجارية باستخدام البنية التحتية لتجميع الويب الخاصة بشركة Bright Data. يجمع ما يقوله الأشخاص الحقيقيون عن علامة تجارية أو منتج أو شخص عبر مواقع Reddit وX/Twitter وInstagram وTikTok وYouTube والأخبار والمراجعة - ثم يصنف المشاعر ويجمع الموضوعات ويقدم ملخصًا مقتبسًا به مع توصيات قابلة للتنفيذ. استخدم هذه المهارة عندما يريد المستخدم معرفة ما يقوله الأشخاص حول علامته التجارية، أو مراقبة الإشارات على وسائل التواصل الاجتماعي، أو قياس المشاعر العامة، أو تتبع السمعة عبر الإنترنت، أو العثور على الشكاوى أو المناصرة، أو قياس المشاركات حول الإطلاق، أو إجراء الاستماع الاجتماعي / مراقبة العلامة التجارية / تحليل المشاعر. استخدمه أيضًا عندما يذكر المستخدم العلامة التجارية، أو صحة العلامة التجارية، أو تتبع السمعة، أو "ما يقوله الإنترنت عنا".
