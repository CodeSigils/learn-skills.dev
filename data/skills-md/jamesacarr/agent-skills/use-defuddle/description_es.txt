Extrae contenido limpio y legible de páginas web utilizando la CLI defuddle: elimina anuncios, navegación y desorden para producir rebajas o JSON. Úselo al guardar contenido web en archivos, recortar artículos en Obsidian, extraer metadatos de artículos o convertir páginas web para limpiar Markdown. NO lo utilice para obtener URL sin formato o contenido que ya esté rebajado; En su lugar, utilice la herramienta de búsqueda/extracción de web sin formato disponible en el arnés.
