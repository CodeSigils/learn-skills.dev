Extrahiert mithilfe der Defuddle-CLI saubere, lesbare Inhalte aus Webseiten – entfernt Anzeigen, Navigation und Unordnung, um Markdown oder JSON zu erstellen. Zum Speichern von Webinhalten in Dateien, zum Ausschneiden von Artikeln in Obsidian, zum Extrahieren von Artikelmetadaten oder zum Konvertieren von Webseiten in sauberes Markdown. NICHT zum Abrufen von Roh-URLs oder bereits markierten Inhalten verwenden; Verwenden Sie stattdessen das verfügbare Raw-Web-Abruf-/Extrahierungstool des Harness.
