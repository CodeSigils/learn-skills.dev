Extrait le contenu propre et lisible des pages Web à l'aide de la CLI defuddle - supprime les publicités, la navigation et l'encombrement pour produire du markdown ou du JSON. À utiliser lors de l'enregistrement de contenu Web dans des fichiers, du découpage d'articles sur Obsidian, de l'extraction de métadonnées d'articles ou de la conversion de pages Web en démarques propres. Ne PAS utiliser pour récupérer des URL brutes ou du contenu déjà markdown ; utilisez plutôt l'outil de récupération/extraction de Web brut disponible dans le harnais.
