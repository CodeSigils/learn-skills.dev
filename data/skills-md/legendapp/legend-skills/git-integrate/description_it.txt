Avvia in modo sicuro nuove o continua le operazioni di integrazione e cronologia Git in corso attraverso il completamento verificato. Utilizzare quando viene richiesto di eseguire o riprendere un rebase, unire, selezionare o ripristinare; quando Git è già nel mezzo di una di quelle operazioni; o per il ripristino in caso di interruzione, la risoluzione dei conflitti, la nostra/loro interpretazione e la decisione quando è necessaria la guida dell'utente. Continuare un'operazione attiva rilevata prima di considerare un nuovo lavoro, non scegliere mai il metodo di integrazione e non indovinare mai un'azione o una risoluzione successiva poco chiara.
