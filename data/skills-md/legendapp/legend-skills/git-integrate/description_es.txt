Inicie de forma segura operaciones nuevas o continúe con la integración de Git y el historial de operaciones en curso mediante la finalización verificada. Úselo cuando se le solicite ejecutar o reanudar una reorganización, fusión, selección o reversión; cuando Git ya está en medio de una de esas operaciones; o para recuperación de interrupciones, resolución de conflictos, interpretación nuestra/de ellos y decidir cuándo se requiere orientación del usuario. Continúe una operación activa detectada antes de considerar un nuevo trabajo, nunca elija el método de integración y nunca adivine una siguiente acción o resolución poco clara.
