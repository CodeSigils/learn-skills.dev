ابدأ عمليات جديدة أو واصل عمليات تكامل Git وسجلها بأمان من خلال الإكمال الذي تم التحقق منه. يُستخدم عندما يُطلب منك تشغيل أو استئناف عملية إعادة الأساس أو الدمج أو الانتقاء أو الرجوع؛ عندما يكون Git بالفعل في منتصف إحدى تلك العمليات؛ أو لاستعادة الانقطاع، وحل النزاعات، وتفسيرنا/تفسيرهم، وتحديد متى يلزم توجيه المستخدم. استمر في عملية نشطة تم اكتشافها قبل التفكير في عمل جديد، ولا تختر أبدًا طريقة التكامل، ولا تخمن أبدًا الإجراء أو القرار التالي غير الواضح.
