Opte por la aprobación primero y el contenedor de todo el árbol de trabajo para la habilidad de confirmación. El valor predeterminado es agrupar todos los cambios y requiere la habilidad de confirmación; Las instalaciones seleccionadas también deben instalar la confirmación. Se activa solo cuando el usuario invoca explícitamente `$commit-confirm` o solicita explícitamente usar la habilidad de confirmación-compromiso nombrada. No lo active simplemente porque el usuario solicite revisar o proponer confirmaciones, pregunte antes de confirmar o espere "ir".
