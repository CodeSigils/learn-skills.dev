Implementa e rivedi l'interfaccia utente di React, React Native e TypeScript per ottenere le massime prestazioni di rendering pratico attraverso aggiornamenti locali foglia, identità stabili, semantica Hook onesta ed effetti minimi. Utilizzare per componenti, hook, callback, contesto, archivi esterni, memorizzazione, righe di elenco, array di dipendenze di grandi dimensioni, callback o fanout di stato, riduzione del re-rendering e lavoro sulle prestazioni compatibile con il compilatore React.
