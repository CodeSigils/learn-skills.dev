Внедряйте и проверяйте пользовательский интерфейс React, React Native и TypeScript для максимальной практической производительности рендеринга за счет локальных обновлений, стабильных идентификаторов, честной семантики хуков и минимальных эффектов. Используйте для компонентов, перехватчиков, обратных вызовов, контекста, внешних хранилищ, мемоизации, строк списков, больших массивов зависимостей, обратного вызова или разветвления состояния, уменьшения повторной отрисовки и работы с производительностью с учетом компилятора React.
