قم بتنفيذ ومراجعة واجهة مستخدم React وReact Native وTypeScript للحصول على أقصى أداء عملي للعرض من خلال التحديثات المحلية للأوراق والهويات المستقرة ودلالات Hook الصادقة والحد الأدنى من التأثيرات. يُستخدم للمكونات، والخطافات، وعمليات الاسترجاعات، والسياق، والمخازن الخارجية، والحفظ، وصفوف القائمة، ومصفوفات التبعية الكبيرة، ورد الاتصال أو الحالة المتفرعة، وتقليل إعادة العرض، وعمل الأداء المدرك لمترجم React.
