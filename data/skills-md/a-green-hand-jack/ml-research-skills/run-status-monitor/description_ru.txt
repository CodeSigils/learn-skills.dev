Используйте при проверке состояния существующего задания — в очереди, зависания, выполнения или завершения — через локальную систему, SLURM, RunAI или SSH. Не для запуска новых заданий (используйте run-experiment). Не для отладки NaN/OOM/инженерных сбоев (используйте отладчик эксперимента). Не для интерпретации действительных, но неожиданных результатов (используйте диагностику результатов).
