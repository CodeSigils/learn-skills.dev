À utiliser pour vérifier l'état d'une tâche existante (en file d'attente, bloquée, en cours d'exécution ou terminée) en local, SLURM, RunAI ou SSH. Pas pour lancer de nouveaux travaux (utilisez run-experiment). Pas pour le débogage des échecs NaN/MOO/ingénierie (utilisez le débogueur expérimental). Pas pour interpréter des résultats valides mais surprenants (utilisez le diagnostic de résultat).
