قم بإعداد حزمة قطع أثرية بحثية لتقييم القطع الأثرية في المؤتمر، أو مراجعة إمكانية التكرار، أو الشارات، أو المواد التكميلية، أو إصدار القطع الأثرية بعد القبول. استخدم هذه المهارة عندما يحتاج المستخدم إلى تعليمات التثبيت، أو أوامر إعادة الإنتاج التي تواجه المراجع، أو فحوصات Docker أو البيئة، أو تعبئة البيانات/نقاط التفتيش، أو تقديرات الأجهزة/وقت التشغيل، أو البيانات التعريفية مجهولة المصدر أو العامة، أو نماذج تقييم العناصر، أو تدقيق إمكانية تكرار نتائج المطالبة بالعناصر لأماكن تعلم الآلة/الذكاء الاصطناعي.
