Examinez les figures, les tableaux, les tracés, les légendes, les récits de résultats et le style visuel du papier avant de les afficher dans un article, une réunion de conseillers, un rapport, un diaporama, une réfutation ou une soumission. Utilisez cette compétence chaque fois que l'utilisateur dispose de résultats expérimentaux, de tracés, de tableaux, de mesures, de captures d'écran, de légendes, de brouillons de sections de résultats ou souhaite vérifier les choix de style de figure tels que la couleur, la typographie, les marqueurs, les symboles, les largeurs de ligne, le dimensionnement et les conventions visuelles cohérentes avec le lieu.
