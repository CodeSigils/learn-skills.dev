Cree una línea de tiempo de trabajo retrospectiva o prospectiva a partir de confirmaciones de git, documentos de proyecto, notas de usuario o registros de chat, luego genere un informe Markdown y/o HTML con un diagrama de Gantt o visualización de línea de tiempo. Úselo cuando el usuario quiera revisar el trabajo anterior en uno o más proyectos, explicar la asignación de tiempo a un mentor, resumir lo que se hizo en un período o planificar la siguiente fase con un cronograma.
