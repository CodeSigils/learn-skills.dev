أنشئ مخططًا زمنيًا للعمل بأثر رجعي أو تطلعي من التزامات git أو مستندات المشروع أو ملاحظات المستخدم أو سجلات الدردشة، ثم قم بإخراج تقرير Markdown و/أو HTML باستخدام مخطط جانت أو تصور المخطط الزمني. يُستخدم عندما يريد المستخدم مراجعة العمل السابق عبر مشروع واحد أو أكثر، أو شرح تخصيص الوقت للمرشد، أو تلخيص ما تم إنجازه خلال فترة ما، أو التخطيط للمرحلة التالية باستخدام جدول زمني.
