تهيئة نظام ذاكرة هرمي وفحصه وصيانته لمشروع بحث تعلم الآلة عبر الورق والتعليمات البرمجية وأشجار العمل والشرائح ومحاكاة المراجع والطعن والتجارب والمطالبات والأدلة والمخاطر والإجراءات. استخدم هذه المهارة عندما يريد المستخدم ذاكرة مشروع عبر الجلسات، أو سياق تمهيد المشروع، أو تتبع حلقة التعليقات، أو محاذاة إجراءات المطالبة والأدلة، أو ذاكرة شجرة العمل، أو الاتساق بين نتائج التعليمات البرمجية، والكتابة الورقية، والشرائح، والمراجعات، والدحض.
