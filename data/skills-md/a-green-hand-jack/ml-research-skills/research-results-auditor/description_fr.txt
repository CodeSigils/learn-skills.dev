À utiliser lors de l'audit des résultats terminés pour les confusions, les dérives de revendications, l'intégrité du protocole ou l'attribution avant de verrouiller les revendications dans le document. Pas pour décider quoi faire après un résultat surprenant (utilisez le diagnostic de résultat). Pas pour les tests de signification ou les tailles d'effet (utilisez le planificateur d'analyse statistique). Pas pour les échecs d'ingénierie (utilisez le débogueur d'expérience).
