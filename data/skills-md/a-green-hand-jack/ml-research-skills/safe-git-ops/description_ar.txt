تنفيذ عمليات Git الشائعة بأمان من خلال التعامل مع حالات الفشل مع مراعاة وضع الحماية. يُستخدم عندما يريد المستخدم فحص حالة git أو تعديلها، خاصة لعمليات انتقاء الكرز أو الدمج أو إعادة التأسيس أو الالتزام أو التفرع أو التخزين أو سير عمل شجرة العمل. استخدم هذه المهارة دائمًا عندما يذكر المستخدم فشل Git، أو الصراع، أو الانتقاء الكرزي، أو مشكلة الدمج، أو شجرة العمل، أو مشكلة الخروج من الفرع، أو ملف القفل، أو رفض الإذن، أو العملية غير مسموح بها، أو أي حالة قد يخلط فيها وكيل وضع الحماية بين قيود البيئة وتعارض الكود الحقيقي. كن استباقيًا: إذا كانت المهمة تشبه حالة Git أو سلوك كتابة Git، فاستخدم هذه المهارة حتى لو لم يطلب المستخدم صراحةً سير عمل "Git".
