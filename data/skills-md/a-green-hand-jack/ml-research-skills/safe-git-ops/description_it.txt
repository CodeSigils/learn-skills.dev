Esegui le operazioni Git comuni in modo sicuro con la gestione degli errori compatibile con sandbox. Da utilizzare ogni volta che l'utente desidera ispezionare o modificare lo stato git, in particolare per flussi di lavoro di selezione, unione, rebase, commit, ramo, stash o albero di lavoro. Utilizza sempre questa competenza quando l'utente menziona un errore Git, un conflitto, una scelta selettiva, un problema di unione, un albero di lavoro, un problema di estrazione del ramo, un file di blocco, un'autorizzazione negata, un'operazione non consentita o qualsiasi caso in cui un agente sandbox potrebbe confondere una restrizione dell'ambiente con un conflitto di codice reale. Sii proattivo: se l'attività assomiglia allo stato Git o al comportamento di scrittura Git, utilizza questa abilità anche se l'utente non ha richiesto esplicitamente un flusso di lavoro "Git".
