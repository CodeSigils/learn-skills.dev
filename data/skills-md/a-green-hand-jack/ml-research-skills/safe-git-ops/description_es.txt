Realice operaciones comunes de Git de forma segura con manejo de fallas compatible con sandbox. Úselo siempre que el usuario quiera inspeccionar o modificar el estado de git, especialmente para flujos de trabajo de selección, fusión, rebase, confirmación, bifurcación, almacenamiento o árbol de trabajo. Utilice siempre esta habilidad cuando el usuario mencione una falla de Git, un conflicto, una selección, un problema de fusión, un árbol de trabajo, un problema de extracción de rama, un archivo bloqueado, un permiso denegado, una operación no permitida o cualquier caso en el que un agente de espacio aislado pueda confundir una restricción de entorno con un conflicto de código real. Sea proactivo: si la tarea huele a estado de Git o comportamiento de escritura de Git, use esta habilidad incluso si el usuario no solicitó explícitamente un flujo de trabajo 'Git'.
