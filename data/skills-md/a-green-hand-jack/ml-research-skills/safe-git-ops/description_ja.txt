サンドボックス対応の障害処理により、一般的な Git 操作を安全に実行します。ユーザーが git の状態を検査または変更する場合、特にチェリーピック、マージ、リベース、コミット、ブランチ、スタッシュ、またはワークツリーのワークフローの場合に使用します。ユーザーが Git の失敗、競合、チェリーピック、マージの問題、ワークツリー、ブランチのチェックアウトの問題、ロック ファイル、アクセス許可の拒否、操作が許可されていないこと、またはサンドボックス エージェントが環境の制限と実際のコードの競合を混同する可能性があることについて言及した場合は、必ずこのスキルを使用してください。積極的に行動してください。タスクが Git の状態または Git の書き込み動作に似ている場合は、ユーザーが明示的に「Git」ワークフローを要求していない場合でも、このスキルを使用してください。
