Выполняйте стандартные операции Git безопасно, используя обработку сбоев в песочнице. Используйте всякий раз, когда пользователь хочет проверить или изменить состояние git, особенно для рабочих процессов выбора, слияния, перебазирования, фиксации, ветвления, хранения или рабочего дерева. Всегда используйте этот навык, когда пользователь упоминает сбой Git, конфликт, выборку, проблему слияния, рабочее дерево, проблему с извлечением ветки, файл блокировки, отказ в разрешении, неразрешенную операцию или любой случай, когда изолированный агент может спутать ограничение среды с реальным конфликтом кода. Будьте активны: если задача пахнет состоянием Git или поведением записи Git, используйте этот навык, даже если пользователь явно не запрашивал рабочий процесс «Git».
