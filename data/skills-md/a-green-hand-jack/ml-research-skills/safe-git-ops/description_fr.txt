Effectuez des opérations Git courantes en toute sécurité grâce à une gestion des échecs compatible sandbox. À utiliser chaque fois que l'utilisateur souhaite inspecter ou modifier l'état de git, en particulier pour les workflows de sélection, de fusion, de rebase, de validation, de branchement, de stockage ou d'arbre de travail. Utilisez toujours cette compétence lorsque l'utilisateur mentionne un échec Git, un conflit, une sélection sélective, un problème de fusion, un arbre de travail, un problème d'extraction de branche, un fichier de verrouillage, une autorisation refusée, une opération non autorisée ou tout autre cas où un agent en bac à sable pourrait confondre une restriction d'environnement avec un véritable conflit de code. Soyez proactif : si la tâche ressemble à l'état de Git ou au comportement d'écriture de Git, utilisez cette compétence même si l'utilisateur n'a pas explicitement demandé un workflow « Git ».
