Gestisci le pipeline di set di dati ML prima dell'addestramento. Da utilizzare quando l'utente ha bisogno di acquisire, preelaborare, dividere o modificare set di dati, progettare protocolli di training/val/test, controllare la qualità dei dati, verificare la contaminazione di training/test o prendere decisioni sui dati che influiscono sulla validità sperimentale e sull'affidabilità dei revisori.
