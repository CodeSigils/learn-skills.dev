قم بمراجعة المهارات الخاصة أو الذكريات أو الملاحظات أو السجلات التشغيلية قبل تحويلها إلى مهارات عامة أو قوالب أو مستندات أو أنماط قابلة لإعادة الاستخدام. يُستخدم عند مسح الذاكرة الشخصية/الخاصة بحثًا عن المعرفة القابلة للنشر، أو احتياجات التنقيح، أو مخاطر الخصوصية، أو تسرب رؤية المصدر، أو المرشحين للمهارات العامة الجاهزة للعلاقات العامة.
