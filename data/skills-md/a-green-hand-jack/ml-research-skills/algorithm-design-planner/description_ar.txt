تحويل فكرة بحثية واعدة في تعلم الآلة/الذكاء الاصطناعي إلى خوارزمية دقيقة أو تصميم طريقة قبل التنفيذ. استخدم هذه المهارة عندما يكون لدى المستخدم فكرة أو اتجاه مشروع ويريد تصميم الطريقة الفعلية أو الهدف أو البنية أو إجراء الاستدلال أو الافتراضات أو أوضاع الفشل أو الاجتثاث أو تسليم التنفيذ أو خطة قسم الطريقة قبل البرمجة أو تصميم التجربة.
