Используйте для отслеживания состояния нелинейного оформления — статуса раздела, зависимостей текста утверждения, устаревшей прозы, стилевых решений и влияния редактирования между сеансами. Не для написания прозы (используйте бумагу-помощник). Не для планирования первоначального письменного контракта (используйте планировщик Paper-writing-contract-planner).
