قم بمراجعة مستودع المهارات أو مجموعة المهارات المثبتة من أجل الاتساق العالمي، وتغطية دورة الحياة، وجودة التوجيه، وانحراف الوثائق، وتغطية إعادة كتابة الذاكرة، ومراجع المهارات المستقبلية التي لا معنى لها، ومسارات المساعدة المعطلة، والاستعداد للتحقق من الصحة. استخدم هذه المهارة عندما يطلب المستخدم إجراء تدقيق تناسق عالمي، أو مراجعة تصنيف المهارات، أو تدقيق دورة الحياة، أو تدقيق التوجيه عبر المهارات، أو التحقق من تناسق مخزون README أو AGENTS، أو تمرير الصيانة عبر مجموعة من مهارات الوكيل.
