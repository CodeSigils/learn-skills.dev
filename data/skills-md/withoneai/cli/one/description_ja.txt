One CLI (「one」) を使用すると、API を通じて 250 以上のサードパーティ プラットフォーム (Gmail、Slack、Shopify、HubSpot、Stripe、GitHub、Notion、Salesforce など) と対話できます。 1 つは、単一の統合インターフェイスを通じて認証、リクエストの構築、および実行を処理します。

ユーザーが次のことを行う場合にトリガーします。
- あらゆるサードパーティのプラットフォームまたは外部サービスと対話します (例: 「メールの送信」、「Shopify 注文の作成」、「HubSpot の連絡先の検索」、「Slack への投稿」)
- 接続されているプラットフォームを一覧表示するか、利用可能な統合を確認します
- プラットフォームで何ができるかを検索します (例: 「Gmail で何ができるか」)
- 接続されたプラットフォームに対して API 呼び出しを実行します
- プラットフォーム間で Webhook 主導の自動化を設定します (例: 「Stripe 支払いが入ったら Slack に通知する」)
- プラットフォーム間でアクションを連鎖させる複数ステップのワークフローを構築します (例: 「Stripe の顧客を取得し、各顧客にメールを送信する」)
- サードパーティの API、統合、または接続されたアプリに関連するもの (名前で「One」について言及していなくても)

以下の場合はトリガーしないでください。
- One のセットアップまたは MCP のインストール (つまり、「one init」)
- 新しい接続の追加 (つまり、「<プラットフォーム> の追加」)
- アクセス制御の構成 (これは「1 つの構成」です)
