One CLI('one')를 사용하면 API를 통해 Gmail, Slack, Shopify, HubSpot, Stripe, GitHub, Notion, Salesforce 등 250개 이상의 타사 플랫폼과 상호 작용할 수 있습니다. 하나는 단일 통합 인터페이스를 통해 인증, 요청 작성 및 실행을 처리합니다.

사용자가 다음을 원할 때 TRIGGER:
- 모든 타사 플랫폼 또는 외부 서비스와 상호 작용(예: "이메일 보내기", "Shopify 주문 생성", "HubSpot 연락처 조회", "Slack에 게시")
- 연결된 플랫폼을 나열하거나 어떤 통합이 가능한지 확인하세요.
- 플랫폼에서 무엇을 할 수 있는지 검색합니다(예: "Gmail로 무엇을 할 수 있나요?")
- 연결된 플랫폼에 대해 모든 API 호출을 실행합니다.
- 플랫폼 간 웹훅 기반 자동화 설정(예: "Stripe 결제가 들어오면 Slack에 알림")
- 플랫폼 전반에 걸쳐 작업을 연결하는 다단계 워크플로 구축(예: "Stripe 고객을 불러와 각 고객에게 이메일 보내기")
- 타사 API, 통합 또는 연결된 앱과 관련된 모든 것 - 이름으로 "One"이 언급되지 않은 경우에도 마찬가지입니다.

다음의 경우에는 트리거하지 마세요:
- One 설정 또는 MCP 설치(`one init`)
- 새로운 연결 추가(`one add <platform>`)
- 액세스 제어 구성('하나의 구성')
