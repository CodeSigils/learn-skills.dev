使用 One CLI（「one」）透過 API 與 250 多個第三方平台（Gmail、Slack、Shopify、HubSpot、Stripe、GitHub、Notion、Salesforce 等）互動。透過一個統一的介面處理身份驗證、請求建置和執行。

當使用者想要執行以下操作時觸發：
- 與任何第三方平台或外部服務互動（例如，「發送電子郵件」、「建立 Shopify 訂單」、「尋找 HubSpot 聯絡人」、「發佈到 Slack」）
- 列出其連接的平台或檢查可用的集成
- 搜尋他們可以在平台上做什麼（例如，「我可以使用 Gmail 做什麼」）
- 針對連接的平台執行任何 API 呼叫
- 在平台之間設定 webhook 驅動的自動化（例如，「當 Stripe 付款進入時，通知 Slack」）
- 建立跨平台連結操作的多步驟工作流程（例如，「取得 Stripe 客戶並向每個客戶發送電子郵件」）
- 任何涉及第三方 API、整合或連接應用程式的內容 - 即使它們沒有提及「One」的名稱

請勿觸發：
- 設定 One 或安裝 MCP（即「one init」）
- 新增連線（即「one add <platform>」）
- 配置存取控制（即「一個配置」）
