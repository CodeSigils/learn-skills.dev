使用 One CLI（“one”）通过 API 与 250 多个第三方平台（Gmail、Slack、Shopify、HubSpot、Stripe、GitHub、Notion、Salesforce 等）进行交互。通过一个统一的接口处理身份验证、请求构建和执行。

当用户想要执行以下操作时触发：
- 与任何第三方平台或外部服务交互（例如，“发送电子邮件”、“创建 Shopify 订单”、“查找 HubSpot 联系人”、“发布到 Slack”）
- 列出其连接的平台或检查可用的集成
- 搜索他们可以在平台上做什么（例如，“我可以使用 Gmail 做什么”）
- 针对连接的平台执行任何 API 调用
- 在平台之间设置 webhook 驱动的自动化（例如，“当 Stripe 付款进入时，通知 Slack”）
- 构建跨平台链接操作的多步骤工作流程（例如，“获取 Stripe 客户并向每个客户发送电子邮件”）
- 任何涉及第三方 API、集成或连接应用程序的内容 - 即使它们没有提及“One”的名称

请勿触发：
- 设置 One 或安装 MCP（即“one init”）
- 添加新连接（即“one add <platform>”）
- 配置访问控制（即“一个配置”）
