Для тестирования WebFlux требуется StepVerifier для реактивных потоков — стандартные утверждения молча передаются на пустой Flux. API WebTestClient отличается от MockMvc. Прочтите перед тестированием реактивных конечных точек. Триггеры: @WebFluxTest, WebTestClient, StepVerifier, Mono, Flux,ockUser(),ockJwt(), mutateWith,verifyComplete,expectBody,expectStatus, @AutoConfigureWebTestClient.
