Le démarrage 4 a renommé @MockBean en @MockitoBean, déplacé les annotations des tranches de test vers de nouveaux packages et modifié le comportement de mise en cache du contexte. Lisez pour connaître les idiomes AssertJ/BDDMockito corrects et la migration Boot 4. Solution de secours par défaut lorsqu'aucune annotation de tranche spécifique n'est présente. Déclencheurs : assertThat, BDDMockito, ArgumentCaptor, @MockitoBean, @MockitoSpyBean, @DirtiesContext, UnnecessaryStubbingException, pyramide de test, cache de contexte.
