Boot 4+ a remplacé les assertions MockMvc par MockMvcTester - API incompatible, vos données de formation sont erronées. Lisez avant d'écrire un @WebMvcTest. Déclencheurs : @WebMvcTest, MockMvc, MockMvcTester, @RestController, jsonPath, @GetMapping, @PostMapping, @AutoConfigureMockMvc, MockMvcRequestBuilders, status().isOk(), @RestControllerAdvice, contentType(APPLICATION_JSON).
