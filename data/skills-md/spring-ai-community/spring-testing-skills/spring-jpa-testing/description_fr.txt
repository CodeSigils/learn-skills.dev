@DataJpaTest nécessite TestEntityManager + flush()/clear() avant les assertions — sans cela, les tests sont lus à partir du cache Hibernate L1 et réussissent faussement. À lire avant d'écrire un test JPA. Déclencheurs : @DataJpaTest, JpaRepository, TestEntityManager, @ServiceConnection, Testcontainers, @Modifying, Hibernate 6/7, @AutoConfigureTestDatabase, vider et effacer dans les tests, @Transactional dans les tests, jakarta.persistence.EntityManager.
