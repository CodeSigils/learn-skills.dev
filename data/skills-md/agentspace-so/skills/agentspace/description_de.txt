Verwenden Sie diesen Skill, wenn der Benutzer einen lokalen Ordner, eine Datei, generierte Artefakte, Protokolle, Screenshots oder einen Projektarbeitsbereich über einen Link mit einem Menschen oder einem anderen Agenten teilen möchte. Wird bei Anfragen wie „Diesen Ordner freigeben“, „Diese Dateien hochladen“, „Mir die Artefakte senden“, „Mir einen Link geben“ oder „Diesen Arbeitsbereich übergeben“ ausgelöst.
