Utilice esta habilidad cuando el usuario quiera compartir una carpeta local, un archivo, artefactos generados, registros, capturas de pantalla o un espacio de trabajo de proyecto con un humano u otro agente a través de un enlace. Activa solicitudes como "compartir esta carpeta", "cargar estos archivos", "enviarme los artefactos", "darme un enlace" o "transferir este espacio de trabajo".
