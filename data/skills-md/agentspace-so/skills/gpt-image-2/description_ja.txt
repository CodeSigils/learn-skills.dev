既存の ChatGPT Plus または Pro サブスクリプションを使用して、Claude Code 内で GPT Image 2 (ChatGPT Images 2.0) を使用して画像を生成します。個別の OpenAI アクセスや画像ごとの課金は必要ありません。ローカル Codex CLI を介したテキストから画像への編集、画像から画像への編集、スタイル転送、および複数参照の構成をサポートします。 「gpt image 2」、「gpt-image-2」、「ChatGPT Images 2.0」、「image 2」、またはユーザーの ChatGPT プランを通じてイメージを生成または編集するための明示的な要求でトリガーされます。
