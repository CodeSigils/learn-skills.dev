RunComfy の「runco​​mfy」CLI を使用して、静止画像を再照明します (照明設定、色温度、方向、雰囲気を変更します)。散文ライティング言語で十分な場合は、アイデンティティを保持する編集エンドポイント (Nano Banana 2 Edit、GPT Image 2 Edit、FLUX Kontext Pro) にフォールバックする、専用の再ライティング用の Qwen Edit 2509 専用の「relight」LoRA エンドポイントにルーティングします。製品の再照明 (スタジオのソフトボックス → 窓の光)、ポートレートの気分の変化 (曇り → ゴールデンアワー)、またはカラーグレードの変更に使用します。 「再照明」、「再照明」、「照明の変更」、「ゴールデンアワーにする」、「スタジオ照明」、「リムライト」、「ブルーアワー」、「柔らかい窓の光」、「光の方向の変更」、「色温度」、または静止画の照明方法を変更するための明示的な要求でトリガーされます。
