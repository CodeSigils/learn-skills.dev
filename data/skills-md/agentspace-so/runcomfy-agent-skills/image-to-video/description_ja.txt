RunComfy 上の任意の静止画像をアニメーション化します。このスキルは、ユーザーの意図を RunComfy カタログ内の適切な i2v モデルに一致させるスマート ルーターです。一般アニメーションには HappyHorse 1.0 I2V (Arena #1、ネイティブ オーディオ、アイデンティティ保持)、カスタム ナレーション リップシンクには `audio_url` を備えた Wan 2.7、または画像 + リファレンス ビデオ + リファレンス オーディオからのマルチモーダル アニメーションには Seedance 2.0 Pro を選択します。各モデルの文書化されたプロンプト パターンをバンドルして、呼び出し元が間違ったモデルで反復を書き込むことなく、より鮮明な出力を取得できるようにします。ローカルの RunComfy CLI を介して「runco​​mfy run <vendor>/<model>/image-to-video」（またはエンドポイントのバリアント）を呼び出します。 「画像からビデオへ」、「画像からビデオへ」、「i2v」、「画像をアニメートする」、「この動きをする」、または静止画をビデオに変換するための明示的な要求でトリガーされます。
