RunComfy에서 이미지 편집 — 이 기술은 사용자의 의도를 RunComfy 카탈로그의 올바른 편집 모델과 일치시키는 스마트 라우터입니다. Nano Banana Edit(최대 20개 배치, ID 보존 기본값), OpenAI GPT Image 2 Edit(다국어 이미지 내 텍스트 재작성, 다중 참조 구성, 레이아웃 정밀도), Flux Kontext Pro(단일 참조 고충실도 로컬 편집) 또는 Z-Image Turbo Inpaint(마스크 기반 정밀 영역 편집)를 선택합니다. 각 모델의 문서화된 프롬프트 패턴을 묶어서 잘못된 모델에 대한 반복 작업을 수행하지 않고도 기술을 더욱 선명하게 편집할 수 있습니다. 로컬 RunComfy CLI를 통해 `runcomfy run <vendor>/<model>/edit`를 호출합니다.
