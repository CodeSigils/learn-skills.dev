Modifier une vidéo existante sur RunComfy — cette compétence est un routeur intelligent qui fait correspondre l'intention de l'utilisateur au bon modèle d'édition dans le catalogue RunComfy. Picks Wan 2.7 Edit-Video (restyle général / échange d'arrière-plan / échange d'emballage, identité + préservation du mouvement), Kling 2.6 Pro Motion Control (transfert de mouvement précis d'une vidéo de référence à un personnage cible) ou Lucy Edit Restyle (restyle / échange de tenue léger et stable). Regroupe les modèles d'invite documentés de chaque modèle afin que la compétence obtienne des modifications plus précises sans graver d'itérations sur le mauvais modèle. Appelle « runcomfy run <vendor>/<model>/<endpoint> » via la CLI RunComfy locale. Déclencheurs sur "modifier la vidéo", "éditer la vidéo", "restyler la vidéo", "échanger l'arrière-plan de la vidéo", "contrôle de mouvement", "échanger la vidéo de tenue" ou toute demande explicite de transformation d'une vidéo.
