RunComfy 上の Flux 2 Klein (Black Forest Labs の Flux 2 の高速バージョン) を使用して画像を生成します。これにはモデルの文書化されたプロンプト パターンがバンドルされているため、同じモデルに対する単純なプロンプトよりもスキルがシャープな出力を得ることができます。 Flux 2 Klein の強み (1 秒未満のレイテンシ、複数の参照ブランド スタイル、宣言的な件名優先プロンプト)、ステップ数戦略 (高速イテレーションの場合は 4 ～ 8、洗練の場合は ~25)、9B と 4B のバリアントのトレードオフ、および代わりに Flux 2 Pro / Seedream 5 / GPT Image 2 にルーティングするタイミングについて文書化します。ローカルの RunComfy CLI を介して `runco​​mfy run blackforestlabs/flux-2-klein/9b/text-to-image` (または `/4b/`) を呼び出します。 「flux 2 klein」、「flux-2-klein」、「flux klein」、「BFL flux 2」、またはこのモデルで生成するための明示的なリクエストでトリガーされます。
