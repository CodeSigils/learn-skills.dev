Редактируйте изображения с помощью Flux 1 Kontext Pro (точная модель локального редактирования изображений от Black Forest Labs) на RunComfy — в комплекте с документированными шаблонами подсказок модели, поэтому навык получает более четкие результаты, чем простые подсказки для той же модели. Документирует сильные стороны Flux Kontext (точное локальное редактирование по одной ссылке, строгий контроль подсказок, последовательные высококачественные выходные данные), схему (одно изображение + подсказка), а также когда вместо этого следует перенаправить к Nano Banana Edit / GPT Image 2 Edit / Flux 2 Klein. Вызывает `runcomfy run blackforestlabs/flux-1-kontext/pro/edit` через локальный CLI RunComfy. Запускается по «контексту потока», «контексту потока», «контексту потока 1», «контексту», «контексту BFL» или любому явному запросу на редактирование этой модели.
