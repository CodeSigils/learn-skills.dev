Generador de mascotas Codex en RunComfy. Cree un spritesheet.webp + pet.json de Codex Pet compatible con Codex a partir de una única imagen de referencia, suéltelo en `${CODEX_HOME:-$HOME/.codex}/pets/<name>/` y Codex lo seleccionará como un Codex Pet personalizado junto a las 8 funciones integradas. Esta habilidad produce el atlas de mascotas del Codex exacto que el Codex espera (1536x1872 PNG/WebP, 8 columnas x 9 filas, 192x208 celdas, 9 estados de animación: inactivo, corriendo hacia la derecha, corriendo hacia la izquierda, agitando, saltando, fallando, esperando, corriendo, revisando). Llama a OpenAI GPT Image 2 edit UNA VEZ a través de la CLI RunComfy local como `runcomfy run openai/gpt-image-2/edit` para producir una pose canónica de Codex Pet, luego ensambla las 9 filas de animación mediante programación con microtransformaciones ImageMagick: sin Codex Pro, sin `$imagegen`, no se requiere OPENAI_API_KEY, solo RUNCOMFY_TOKEN.
