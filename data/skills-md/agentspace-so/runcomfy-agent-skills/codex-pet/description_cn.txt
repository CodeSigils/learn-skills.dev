RunComfy 上的 Codex Pet 生成器。从单个参考图像构建与 Codex 兼容的 Codex Pet spritesheet.webp + pet.json，将其放入 `${CODEX_HOME:-$HOME/.codex}/pets/<name>/` 中，Codex 将其作为 8 个内置插件旁边的自定义 Codex Pet 选取。此技能可生成 Codex 期望的准确 Codex Pet 图集（1536x1872 PNG/WebP、8 列 x 9 行、192x208 单元格、9 种动画状态 - 空闲、向右运行、向左运行、挥手、跳跃、失败、等待、运行、审查）。通过本地 RunComfy CLI 作为“runco​​mfy run openai/gpt-image-2/edit”调用 OpenAI GPT Image 2 edit 一次，以生成规范的 Codex Pet 姿势，然后使用 ImageMagick 微转换以编程方式组装所有 9 个动画行 — 不需要 Codex Pro、不需要“$imagegen”、不需要 OPENAI_API_KEY，只需 RUNCOMFY_TOKEN。在“codex pet”、“create codex pet”、“make codex pet”、“hatch codex pet”、“/hatch image”、“desktop pet codex”、“codex pets”、“spritesheet.webp”或任何为 OpenAI Codex 构建自定义 Pet 的明确要求时触发。
