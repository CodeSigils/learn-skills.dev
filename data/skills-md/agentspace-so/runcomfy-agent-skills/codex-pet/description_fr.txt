Générateur Codex Pet sur RunComfy. Créez un spritesheet.webp + pet.json Codex Pet compatible avec le Codex à partir d'une seule image de référence, déposez-le dans `${CODEX_HOME:-$HOME/.codex}/pets/<name>/` et le Codex le récupère en tant qu'animal Codex personnalisé à côté des 8 éléments intégrés. Cette compétence produit exactement l'atlas Codex Pet que le Codex attend (1536x1872 PNG/WebP, 8 colonnes x 9 lignes, 192x208 cellules, 9 états d'animation - inactif, courant à droite, courant à gauche, agitant, sautant, échoué, attente, courant, révision). Appelle OpenAI GPT Image 2 edit UNE FOIS via la CLI RunComfy locale en tant que « runcomfy run openai/gpt-image-2/edit » pour produire une pose canonique Codex Pet, puis assemble les 9 lignes d'animation par programme avec les micro-transformations ImageMagick — pas de Codex Pro, pas de « $imagegen », pas d'OPENAI_API_KEY requis, seulement RUNCOMFY_TOKEN. Déclencheurs sur "codex pet", "create codex pet", "make codex pet", "hatch codex pet", "/hatch image", "desktop pet codex", "codex pets", "spritesheet.webp", ou toute demande explicite de créer un animal de compagnie personnalisé pour OpenAI Codex.
