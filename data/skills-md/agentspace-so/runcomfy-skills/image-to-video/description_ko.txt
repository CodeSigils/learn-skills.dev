RunComfy의 스틸 이미지에 애니메이션을 적용합니다. 이 기술은 사용자의 의도를 RunComfy 카탈로그의 올바른 i2v 모델과 일치시키는 스마트 라우터입니다. 일반 애니메이션의 경우 HappyHorse 1.0 I2V(아레나 #1, 기본 오디오, 신원 보존)를 선택하고, 맞춤형 음성 해설 립싱크의 경우 'audio_url'이 포함된 Wan 2.7을 선택하거나 이미지 + 참조 비디오 + 참조 오디오의 다중 모달 애니메이션의 경우 Seedance 2.0 Pro를 선택합니다. 각 모델의 문서화된 프롬프트 패턴을 묶어 호출자가 잘못된 모델에서 반복을 반복하지 않고도 더 선명한 출력을 얻을 수 있도록 합니다. 로컬 RunComfy CLI를 통해 `runcomfy run <vendor>/<model>/image-to-video`(또는 엔드포인트 변형)를 호출합니다.
