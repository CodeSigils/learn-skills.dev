Редактировать существующее видео в RunComfy — этот навык представляет собой интеллектуальный маршрутизатор, который сопоставляет намерение пользователя с правильной моделью редактирования в каталоге RunComfy. Выбирает Wan 2.7 Edit-Video (общий рестайл / замена фона / замена упаковки, сохранение идентичности + движения), Kling 2.6 Pro Motion Control (перенос точного движения из эталонного видео на целевой персонаж) или Lucy Edit Restyle (облегченный стабильный стиль идентичности / смена одежды). Объединяет документированные шаблоны подсказок для каждой модели, чтобы навык можно было более точно редактировать, не записывая итерации на неправильную модель. Вызывает `runcomfy run <vendor>/<model>/<endpoint>` через локальный CLI RunComfy. Запускается при «редактировании видео», «редактировании видео», «изменении видео», «замене фона видео», «управлении движением», «замене видео одежды» или любом явном запросе на преобразование видео.
