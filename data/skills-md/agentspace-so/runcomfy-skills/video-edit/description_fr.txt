Modifier une vidéo existante sur RunComfy — cette compétence est un routeur intelligent qui associe l’intention de l’utilisateur au bon modèle d’édition du catalogue RunComfy. Elle sélectionne Wan 2.7 Edit‑Video (restylage général / échange d’arrière‑plan / échange d’emballage, préservation de l’identité + du mouvement), Kling 2.6 Pro Motion Control (transfert précis du mouvement d’une vidéo de référence vers un personnage cible) ou Lucy Edit Restyle (restylage léger, identité stable / échange de tenue). Elle regroupe les schémas d’invite documentés de chaque modèle afin que la compétence produise des éditions plus précises sans gaspiller d’itérations sur le mauvais modèle. Elle exécute `runcomfy run <vendor>/<model>/<endpoint>` via le CLI local RunComfy. Elle se déclenche sur « video edit », « edit video », « restyle video », « swap video background », « motion control », « outfit swap video » ou toute demande explicite de transformation d’une vidéo.
