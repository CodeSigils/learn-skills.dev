在 RunComfy 上編輯現有影片 — 此技能是一個智慧路由器，將使用者的意圖匹配到 RunComfy 目錄中的正確編輯模型。會選擇 Wan 2.7 Edit-Video（通用重新風格化／背景交換／包裝交換，保留身份與運動）、Kling 2.6 Pro Motion Control（將參考影片的精準運動轉移到目標角色）或 Lucy Edit Restyle（輕量化、身份穩定的重新風格化／服裝交換）。將每個模型的文件化提示模式整合，使技能在不浪費迭代於錯誤模型的情況下獲得更銳利的編輯。透過本機 RunComfy CLI 呼叫 `runcomfy run <vendor>/<model>/<endpoint>`。在「video edit」、「edit video」、「restyle video」、「swap video background」、「motion control」、「outfit swap video」或任何明確要求轉換影片的指令時觸發。
