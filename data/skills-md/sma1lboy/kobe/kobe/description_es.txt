Conduce kobe, una TUI local que ejecuta muchas sesiones de codificación de IA en paralelo, desde tu shell a través de "kobe api". Úselo para generar/distribuir intentos paralelos Y para administrar el ciclo de vida completo de la tarea (crear, cambiar el nombre, volver a ramificar, archivar, eliminar, anclar, cambiar el enfoque) sin salir del terminal. Cada tarea es su propia sesión de git worktree + agente. Ejecute "kobe api Scheme" para descubrir toda la superficie.
