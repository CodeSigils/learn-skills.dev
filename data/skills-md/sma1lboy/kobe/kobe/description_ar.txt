قم بقيادة kobe - واجهة TUI محلية تدير العديد من جلسات ترميز الذكاء الاصطناعي المتوازية - من Shell الخاص بك عبر `kobe api`. يُستخدم لنشر/توزيع المحاولات المتوازية، ولإدارة دورة حياة المهمة الكاملة (إنشاء، إعادة تسمية، إعادة فرع، أرشفة، حذف، تثبيت، تبديل التركيز) دون مغادرة الوحدة الطرفية. كل مهمة هي جلسة عمل git + Agent الخاصة بها. قم بتشغيل مخطط kobe api لاكتشاف السطح بأكمله.
