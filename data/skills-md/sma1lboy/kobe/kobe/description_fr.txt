Conduisez Kobe — une TUI locale qui exécute de nombreuses sessions de codage d'IA en parallèle — depuis votre shell via `kobe api`. Utilisez-le pour générer/déployer des tentatives parallèles ET pour gérer le cycle de vie complet des tâches (créer, renommer, rebrancher, archiver, supprimer, épingler, changer de focus) sans quitter le terminal. Chaque tâche est sa propre session git worktree + agent. Exécutez `kobe api schema` pour découvrir toute la surface.
