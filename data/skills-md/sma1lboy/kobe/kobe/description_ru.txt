Управляйте kobe — локальным TUI, который запускает множество параллельных сеансов кодирования ИИ — из вашей оболочки через «kobe api». Используйте для создания/разветвления параллельных попыток, а также для управления полным жизненным циклом задачи (создание, переименование, повторное ветвление, архивирование, удаление, закрепление, переключение фокуса), не выходя из терминала. Каждая задача представляет собой отдельный сеанс git worktree + агента. Запустите `kobe api Schema`, чтобы обнаружить всю поверхность.
