Steuern Sie Kobe – eine lokale TUI, die viele parallele KI-Codierungssitzungen ausführt – von Ihrer Shell aus über „kobe api“. Verwenden Sie diese Option, um parallele Versuche zu erzeugen/aufzufächern UND um den gesamten Aufgabenlebenszyklus (Erstellen, Umbenennen, Neuverzweigen, Archivieren, Löschen, Anheften, Fokus wechseln) zu verwalten, ohne das Terminal zu verlassen. Jede Aufgabe ist eine eigene Git Worktree + Agent-Sitzung. Führen Sie „kobe api schema“ aus, um die gesamte Oberfläche zu entdecken.
