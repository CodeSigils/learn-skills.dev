Carica PR e supporti di convalida su un attach Worker self-hosted tramite la CLI di attach installata (`attach` o `gh attach`): accesso al flusso del dispositivo con ATTACH_GITHUB_CLIENT_ID, inserimento/eliminazione/disconnessione di screenshot e artefatti, anteprima degli URL `/p/…`, incorporamenti `/o/…` non elaborati tramite `--markdown` e output `--json`/`--url`; o l'app GitHub JWT registra quindi `att_` PUT per gli agenti. Da utilizzare quando l'utente chiede di allegare uno screenshot, caricare media PR, inserire un'immagine su attach.uinaf.dev (o ATTACH_API_BASE), condividere un URL di screenshot di convalida, eseguire attach login/put/delete/logout, utilizzare gh attach, host validation media, rimuovere attach media o registrare un agente dell'app per attach. Non utilizzare per la distribuzione, il vault, le operazioni Cloudflare di tipo Worker o per inventare un secondo client di caricamento.
