Загружает PR и проверочный носитель в самостоятельный Attach Worker через установленный Attach CLI (`attach` или `gh Attach`): вход в поток устройства с ATTACH_GITHUB_CLIENT_ID, размещение/удаление/выход из снимков экрана и артефактов, предварительный просмотр URL-адресов `/p/…`, необработанный `/o/…` встраивает через `--markdown` и вывод `--json`/`--url`; или зарегистрируйте JWT приложения GitHub, а затем `att_` PUT для агентов. Используйте, когда пользователь просит прикрепить снимок экрана, загрузить PR-носитель, поместить изображение на Attach.uinaf.dev (или ATTACH_API_BASE), поделиться URL-адресом снимка экрана проверки, выполнить прикрепление для входа/вставки/удаления/выхода, использовать gh Attach, носитель проверки хоста, удалить прикрепленный носитель или зарегистрировать агент приложения для прикрепления. Не используйте для развертывания Worker, хранилища, операций Cloudflare или изобретения второго клиента загрузки.
