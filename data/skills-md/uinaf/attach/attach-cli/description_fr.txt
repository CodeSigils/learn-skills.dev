Télécharge les médias PR et de validation sur un attach Worker auto-hébergé via la CLI d'attache installée (`attach` ou `gh attach`) : connexion au flux de périphérique avec ATTACH_GITHUB_CLIENT_ID, mise/suppression/déconnexion des captures d'écran et des artefacts, aperçu des URL `/p/…`, intégration brute `/o/…` via `--markdown` et sortie `--json`/`--url` ; ou GitHub App JWT inscrivez-vous puis `att_` PUT pour les agents. À utiliser lorsque l'utilisateur demande de joindre une capture d'écran, de télécharger un média PR, de mettre une image sur attach.uinaf.dev (ou ATTACH_API_BASE), de partager une URL de capture d'écran de validation, d'exécuter la connexion/put/delete/logout de pièce jointe, d'utiliser gh attach, d'héberger le média de validation, de supprimer le média de pièce jointe ou d'inscrire un agent d'application pour la pièce jointe. Ne pas utiliser pour le déploiement de Worker, le coffre-fort, les opérations Cloudflare ou l'invention d'un deuxième client de téléchargement.
