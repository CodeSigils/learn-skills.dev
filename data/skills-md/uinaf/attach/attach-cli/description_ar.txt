تحميل العلاقات العامة ووسائط التحقق من الصحة إلى عامل إرفاق مستضاف ذاتيًا عبر واجهة سطر الأوامر المثبتة (`إرفاق` أو `gh إرفاق`): تسجيل الدخول إلى تدفق الجهاز باستخدام ATTACH_GITHUB_CLIENT_ID، ووضع/حذف/تسجيل الخروج من لقطات الشاشة والمصنوعات اليدوية، ومعاينة عناوين URL `/p/...`، والتضمين الخام `/o/...` عبر `--markdown`، و إخراج `--json`/`--url`؛ أو قم بالتسجيل في تطبيق GitHub JWT ثم `att_` PUT للوكلاء. يُستخدم عندما يطلب المستخدم إرفاق لقطة شاشة، أو تحميل وسائط العلاقات العامة، أو وضع صورة على Attach.uinaf.dev (أو ATTACH_API_BASE)، أو مشاركة عنوان URL للقطة شاشة التحقق من الصحة، أو تشغيل إرفاق تسجيل الدخول/الوضع/الحذف/تسجيل الخروج، أو استخدام إرفاق gh، أو وسائط التحقق من صحة المضيف، أو إزالة الوسائط المرفقة، أو تسجيل وكيل تطبيق للإرفاق. لا تستخدم لنشر العمال، أو vault، أو Cloudflare ops، أو اختراع عميل تحميل ثانٍ.
