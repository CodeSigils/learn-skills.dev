설치된 연결 CLI(`attach` 또는 `gh attachment`)를 통해 자체 호스팅 연결 작업자에 PR 및 검증 미디어를 업로드합니다. ATTACH_GITHUB_CLIENT_ID를 사용한 device-flow 로그인, 스크린샷 및 아티팩트의 넣기/삭제/로그아웃, `/p/...` URL 미리 보기, `--markdown`을 통한 원시 `/o/...` 삽입 및 `--json`/`--url` 출력. 또는 GitHub App JWT 등록 후 에이전트용 `att_` PUT을 사용하세요. 사용자가 스크린샷 첨부, PR 미디어 업로드, attachment.uinaf.dev(또는 ATTACH_API_BASE)에 이미지 배치, 유효성 검사 스크린샷 URL 공유, 로그인 연결/입력/삭제/로그아웃 실행, gh 연결 사용, 유효성 검사 미디어 호스트, 연결 미디어 게시 중단, 연결을 위해 앱 에이전트 등록을 요청할 때 사용합니다. 작업자 배포, 보관, Cloudflare 작업 또는 두 번째 업로드 클라이언트 개발에 사용하지 마세요.
