Carga PR y medios de validación a un trabajador adjunto autohospedado a través de la CLI adjunta instalada (`attach` o `gh adjunto`): inicio de sesión de flujo de dispositivo con ATTACH_GITHUB_CLIENT_ID, colocación/eliminación/cierre de sesión de capturas de pantalla y artefactos, vista previa de URL `/p/…`, incrustaciones `/o/…` sin formato a través de `--markdown` y salida `--json`/`--url`; o inscripción JWT de la aplicación GitHub y luego `att_` PUT para agentes. Úselo cuando el usuario solicite adjuntar una captura de pantalla, cargar medios de relaciones públicas, colocar una imagen en adjunto.uinaf.dev (o ATTACH_API_BASE), compartir una URL de captura de pantalla de validación, ejecutar adjuntar inicio de sesión/poner/eliminar/cerrar sesión, usar gh adjunto, alojar medios de validación, eliminar medios adjuntos o inscribir a un agente de la aplicación para adjuntar. No lo use para la implementación de trabajadores, bóveda, operaciones de Cloudflare o para inventar un segundo cliente de carga.
