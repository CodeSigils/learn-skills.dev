Configura o allinea la collaborazione GitHub di un repository e la superficie di distribuzione: impostazioni del repository, policy di ramo o set di regole, modelli, Dependabot, rafforzamento delle azioni, ambienti, versioni, pubblicazione e distribuzione dei flussi di lavoro. Utilizzare per la configurazione di GitHub, i criteri CI/CD, la consegna protetta, i rilasci di pacchetti o la distribuzione di app. Non utilizzare per l'architettura del prodotto, gli interni dell'infrastruttura del provider, la revisione della sicurezza delle applicazioni o il lavoro di avvio/preparazione del repository.
