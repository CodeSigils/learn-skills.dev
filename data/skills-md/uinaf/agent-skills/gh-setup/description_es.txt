Configure o alinee la superficie de colaboración y entrega de GitHub de un repositorio: configuración del repositorio, política de rama o conjunto de reglas, plantillas, Dependabot, refuerzo de acciones, entornos, lanzamientos, publicación e implementación de flujos de trabajo. Úselo para la configuración de GitHub, políticas de CI/CD, entrega protegida, lanzamientos de paquetes o implementación de aplicaciones. No lo utilice para arquitectura de productos, componentes internos de la infraestructura del proveedor, revisión de seguridad de aplicaciones o trabajo de preparación/arranque del repositorio.
