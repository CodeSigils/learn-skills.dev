تنفيذ كود Effect TypeScript أو إعادة تصميمه أو تصحيحه أو مراجعته أو شرحه. يُستخدم عند العمل مع حزم `effect` أو `@effect/*`، خاصة `Context.Tag`، `Effect.Service`، `Layer`، `Schema`، `Schema.TaggedError`، `Config`، `Stream`، `@effect/platform`، `@effect/cli`، `@effect/vitest`، أسلاك وقت التشغيل، أو الترحيل المتزايد للوعد بالنتيجة.
