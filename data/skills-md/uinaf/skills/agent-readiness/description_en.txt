Covers reproducible bootstrap, noninteractive machine identities, real-surface verification, artifacts, CI, observability, isolation, recovery, and result submission. Use when a repository cannot boot or verify reliably, agents still need manual setup, credentials or worktrees block automation, or a devbox or orchestrator must complete tasks without supervision. Do not use for reviewing an existing diff or documentation-only cleanup.
