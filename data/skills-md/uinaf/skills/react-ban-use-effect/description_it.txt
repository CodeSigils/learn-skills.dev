Proibire l'uso diretto di `useEffect` nel codice React. Utilizzare la regola quando si scrivono, rifattano, revisionano o migrano componenti o hook React che importano, chiamano, aggiungono o sostituiscono `useEffect` diretto; quando un agente ricorre a effetti per stato derivato, recupero dati, reazioni a eventi, reset o sincronizzazione esterna; o quando si aggiungono regole lint/agent per una politica di “no‑direct‑useEffect”. Non usarla per lavoro React ordinario senza indizi di effetti, per codice non React o per architetture di effetti legittime al di fuori di React.
