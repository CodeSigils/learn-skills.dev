React コードでの直接の `useEffect` を禁止します。直接「useEffect」をインポート、呼び出し、追加、または置換する React コンポーネントまたはフックを作成、リファクタリング、レビュー、または移行するときに使用します。エージェントが派生状態、フェッチ、イベント反応、リセット、または外部同期のエフェクトに到達したとき。または、no-direct-useEffect ポリシーに lint/agent ルールを追加する場合。エフェクト臭のない通常の React 作業、React 以外のコード、または React 以外の正当なエフェクト アーキテクチャには使用しないでください。
