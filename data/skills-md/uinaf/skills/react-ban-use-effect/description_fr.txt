Interdisez `useEffect` direct dans le code React. À utiliser lors de l'écriture, de la refactorisation, de la révision ou de la migration de composants ou de hooks React qui importent, appellent, ajoutent ou remplacent directement « useEffect » ; lorsqu'un agent recherche des effets pour un état dérivé, une récupération, des réactions aux événements, des réinitialisations ou une synchronisation externe ; ou lors de l'ajout de règles lint/agent pour une stratégie no-direct-useEffect. Ne pas utiliser pour un travail React ordinaire sans odeur d'effet, sans code non React ou avec une architecture d'effet légitime en dehors de React.
