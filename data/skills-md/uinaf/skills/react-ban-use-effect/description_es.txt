Prohibir el `useEffect` directo en el código React. Úselo al escribir, refactorizar, revisar o migrar componentes o enlaces de React que importan, llaman, agregan o reemplazan `useEffect` directo; cuando un agente busca efectos para el estado derivado, la recuperación, las reacciones a eventos, los reinicios o la sincronización externa; o al agregar reglas de pelusa/agente para una política de efecto sin uso directo. No lo utilice para trabajos normales de React sin olor a efectos, código que no sea de React o arquitectura de efectos legítima fuera de React.
