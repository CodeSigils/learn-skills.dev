حظر استخدام "useEffect" المباشر في كود React. يُستخدم عند الكتابة أو إعادة البناء أو المراجعة أو ترحيل مكونات React أو الخطافات التي تستورد أو تستدعي أو تضيف أو تستبدل `useEffect` المباشر؛ عندما يصل الوكيل إلى تأثيرات الحالة المشتقة، أو الجلب، أو تفاعلات الأحداث، أو إعادة التعيين، أو المزامنة الخارجية؛ أو عند إضافة قواعد الوبر/الوكيل لسياسة تأثير عدم الاستخدام المباشر. لا تستخدمه في أعمال React العادية التي لا تحتوي على رائحة تأثير أو تعليمات برمجية غير React أو بنية تأثير شرعية خارج React.
