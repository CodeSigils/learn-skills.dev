Configurez ou alignez la surface de collaboration et de livraison GitHub d'un référentiel : paramètres de dépôt, politique de branche/ensemble de règles, modèles de relations publiques et de sécurité, Dependabot, renforcement des actions, environnements GitHub, workflows de publication et workflows de déploiement. À utiliser lors de la standardisation de la configuration de GitHub pour les dépôts, les mises à jour de dépendances, les CI/CD, les actions GitHub, la protection des branches, les pipelines de publication ou de publication, la publication de packages versionnés ou le déploiement d'applications en cours d'exécution ; acheminez les détails de déploiement de l'application vers les références de déploiement et les détails de publication du package vers les références de publication.
