リポジトリの GitHub コラボレーションおよび配信サーフェス (リポジトリ設定、ブランチ/ルールセット ポリシー、PR およびセキュリティ テンプレート、Dependabot、アクション強化、GitHub 環境、リリース ワークフロー、およびデプロイ ワークフロー) をセットアップまたは調整します。リポジトリ、依存関係の更新、CI/CD、GitHub アクション、ブランチ保護、パイプラインのリリースまたはパブリッシュ、バージョン管理されたパッケージのパブリッシュ、または実行中のアプリのデプロイのための GitHub セットアップを標準化するときに使用します。参照をデプロイするにはアプリのデプロイの詳細をルートし、参照をリリースするにはパッケージの公開の詳細をルートします。
