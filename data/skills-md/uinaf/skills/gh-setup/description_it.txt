Configura o allinea la collaborazione GitHub di un repository e la superficie di distribuzione: impostazioni del repository, policy di rami/set di regole, modelli PR e sicurezza, Dependabot, rafforzamento delle azioni, ambienti GitHub, flussi di lavoro di rilascio e flussi di lavoro di distribuzione. Da utilizzare durante la standardizzazione della configurazione di GitHub per repository, aggiornamenti delle dipendenze, CI/CD, azioni GitHub, protezione dei rami, pipeline di rilascio o pubblicazione, pubblicazione di pacchetti con versione o distribuzione di app in esecuzione; instradare i dettagli di distribuzione dell'app per distribuire i riferimenti e i dettagli di pubblicazione del pacchetto per rilasciare i riferimenti.
