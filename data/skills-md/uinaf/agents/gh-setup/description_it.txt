Configura o allinea la collaborazione GitHub di un repository e la superficie di distribuzione: impostazioni del repository, policy di rami/set di regole, modelli PR e sicurezza, rafforzamento delle azioni, ambienti GitHub, flussi di lavoro di rilascio e flussi di lavoro di distribuzione. Da utilizzare quando si standardizza la configurazione di GitHub per repository, CI/CD, si pubblicano pacchetti con versione o si distribuiscono app in esecuzione; instradare i dettagli di distribuzione dell'app per distribuire i riferimenti e i dettagli di pubblicazione del pacchetto per rilasciare i riferimenti.
