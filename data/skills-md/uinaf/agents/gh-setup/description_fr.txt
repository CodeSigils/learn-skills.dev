Configurez ou alignez la surface de collaboration et de livraison GitHub d'un référentiel : paramètres de dépôt, politique de branche/ensemble de règles, modèles de relations publiques et de sécurité, renforcement des actions, environnements GitHub, flux de travail de publication et flux de déploiement. À utiliser lors de la standardisation de la configuration de GitHub pour les dépôts, CI/CD, la publication de packages versionnés ou le déploiement d'applications en cours d'exécution ; acheminez les détails de déploiement de l'application vers les références de déploiement et les détails de publication du package vers les références de publication.
