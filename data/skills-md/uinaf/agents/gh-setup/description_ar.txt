قم بإعداد أو محاذاة سطح التعاون والتسليم الخاص بمستودع GitHub: إعدادات الريبو، وسياسة الفرع/مجموعة القواعد، وقوالب العلاقات العامة والأمان، وتشديد الإجراءات، وبيئات GitHub، وإصدار سير العمل، ونشر سير العمل. يُستخدم عند توحيد إعداد GitHub لـ Repos، أو CI/CD، أو نشر الحزم ذات الإصدارات، أو نشر التطبيقات قيد التشغيل؛ تفاصيل نشر تطبيق الطريق لنشر المراجع وتفاصيل نشر الحزمة لإصدار المراجع.
