Auditez et créez l'infrastructure dont un dépôt a besoin pour que les agents puissent travailler de manière autonome : scripts de démarrage, tests de fumée, portes CI/CD, configuration de l'environnement de développement, observabilité et isolation. À utiliser lorsqu'un dépôt ne peut pas démarrer, que les tests sont interrompus ou manquants, qu'il n'y a pas d'environnement de développement, que les agents ne peuvent pas vérifier leur travail ou que les agents ont besoin d'une aide humaine pour faire quelque chose. Ne pas utiliser pour examiner une différence existante ou pour le nettoyage de la documentation uniquement.
