Audite y cree la infraestructura que necesita un repositorio para que los agentes puedan trabajar de forma autónoma: scripts de arranque, pruebas de humo, puertas de CI/CD, configuración del entorno de desarrollo, observabilidad y aislamiento. Úselo cuando un repositorio no puede iniciarse, las pruebas no funcionan o faltan, no hay un entorno de desarrollo, los agentes no pueden verificar su trabajo o los agentes necesitan ayuda humana para realizar algo. No lo use para revisar una diferencia existente o para limpiar solo documentación.
