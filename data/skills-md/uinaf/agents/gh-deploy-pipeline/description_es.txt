Configure o alinee una canalización de implementación de GitHub Actions para una aplicación o servicio en ejecución. Úselo al estandarizar repositorios en torno a la forma verificar-luego-implementar: presionar a principal -> detectar carriles afectados -> verificar y construir artefactos -> e2e -> implementar cada carril a través de un entorno GitHub utilizando OIDC o credenciales de ámbito ambiental, con simultaneidad de implementación por entorno no cancelable. Se empareja con `gh-release-pipeline` para paquetes versionados; Úselo para implementar aplicaciones en ejecución, no para publicar artefactos en un registro.
