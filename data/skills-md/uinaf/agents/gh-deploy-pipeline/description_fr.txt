Configurez ou alignez un pipeline de déploiement GitHub Actions pour une application ou un service en cours d'exécution. À utiliser lors de la standardisation des dépôts autour de la forme de vérification puis de déploiement : pousser vers principal -> détecter les voies concernées -> vérifier et créer des artefacts -> e2e -> déployer chaque voie via un environnement GitHub à l'aide d'informations d'identification OIDC ou au niveau de l'environnement, avec une simultanéité de déploiement non annulable par environnement. S'associe à `gh-release-pipeline` pour les packages versionnés ; utiliser pour déployer des applications en cours d’exécution, et non pour publier des artefacts dans un registre.
