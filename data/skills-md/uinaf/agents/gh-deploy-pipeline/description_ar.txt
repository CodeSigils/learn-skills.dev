قم بإعداد أو محاذاة مسار نشر GitHub Actions لتطبيق أو خدمة قيد التشغيل. استخدمه عند توحيد عمليات إعادة الشراء حول شكل التحقق ثم النشر: اضغط إلى الرئيسي -> اكتشاف الممرات المتأثرة -> التحقق من العناصر الأثرية وإنشائها -> e2e -> نشر كل مسار من خلال بيئة GitHub باستخدام OIDC أو بيانات اعتماد نطاق البيئة، مع نشر متزامن غير قابل للإلغاء لكل بيئة. أزواج مع `gh-release-pipeline` للحزم ذات الإصدار؛ يُستخدم لنشر التطبيقات قيد التشغيل، وليس لنشر العناصر في السجل.
