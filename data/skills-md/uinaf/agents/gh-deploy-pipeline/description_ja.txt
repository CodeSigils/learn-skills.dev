実行中のアプリまたはサービスの GitHub Actions デプロイ パイプラインをセットアップまたは調整します。 verify-then-deploy の形状に関するリポジトリを標準化する場合に使用します。メインにプッシュ -> 影響を受けるレーンの検出 -> アーティファクトの検証とビルド -> e2e -> OIDC または環境スコープの資格情報を使用して、GitHub 環境を介して各レーンをデプロイし、キャンセルできない環境ごとのデプロイ同時実行を行います。バージョン管理されたパッケージの場合は `gh-release-pipeline` と組み合わせます。アーティファクトをレジストリに公開するのではなく、実行中のアプリをデプロイするために使用します。
