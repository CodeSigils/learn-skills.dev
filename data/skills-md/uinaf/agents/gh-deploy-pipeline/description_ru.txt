Настройте или настройте конвейер развертывания действий GitHub для работающего приложения или службы. Используйте при стандартизации репозиториев по схеме «проверка-затем-развертывание»: нажмите на главную -> обнаружить затронутые полосы -> проверить и создать артефакты -> e2e -> развернуть каждую полосу через среду GitHub, используя OIDC или учетные данные на уровне среды, с неотменяемым параллелизмом развертывания для каждой среды. Сочетается с `gh-release-pipeline` для версий пакетов; используйте для развертывания запущенных приложений, а не публикации артефактов в реестре.
