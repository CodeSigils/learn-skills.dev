Configura o allinea una pipeline di distribuzione di GitHub Actions per un'app o un servizio in esecuzione. Da utilizzare quando si standardizzano i repository attorno alla forma verifica-poi-distribuisci: push to main -> rileva le corsie interessate -> verifica e crea artefatti -> e2e -> distribuisci ogni corsia attraverso un ambiente GitHub utilizzando OIDC o credenziali con ambito ambientale, con concorrenza di distribuzione per ambiente non annullabile. Si accoppia con `gh-release-pipeline` per i pacchetti con versione; utilizzare per la distribuzione di app in esecuzione, non per la pubblicazione di elementi in un registro.
