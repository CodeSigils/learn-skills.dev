Configura o allinea una pipeline di distribuzione di GitHub Actions per un'app o un servizio in esecuzione. Da utilizzare durante la standardizzazione dei repository attorno alla forma di verifica-poi-distribuzione: push to main -> rileva le corsie interessate -> verifica e crea artefatti -> e2e -> distribuisci ciascuna corsia attraverso un ambiente GitHub utilizzando OIDC o credenziali con ambito ambientale, con concorrenza di distribuzione per ambiente non annullabile. Si accoppia con `gh-release-pipeline` per i pacchetti con versione; utilizzare per la distribuzione di app in esecuzione, non per la pubblicazione di elementi in un registro.
