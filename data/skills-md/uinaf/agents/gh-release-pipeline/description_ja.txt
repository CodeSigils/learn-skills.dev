バージョン管理されたパッケージ、ライブラリ、CLI、またはマーケットプレイス アクション用に GitHub Actions リリース パイプラインをセットアップまたは調整します。 verify-then-release 形式に基づいてリポジトリを標準化する場合に使用します。メインにプッシュ → ガードレール → セマンティック リリース タグ + パブリッシュ → `[skip ci]` でメインにバージョン バンプ コミットを戻します。アプリを実行するには「gh-deploy-pipeline」と組み合わせます。実行中のサービスをデプロイするのではなく、バージョン管理されたアーティファクトをレジストリに公開するために使用します。
