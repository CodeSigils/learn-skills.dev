Configura o allinea una pipeline di rilascio di GitHub Actions per un pacchetto con versione, una libreria, una CLI o un'azione del marketplace. Da utilizzare quando si standardizzano i repository attorno alla forma verify-then-release: push to main → guardrails → tag di rilascio semantico + pubblica → version-bump commit torna a main con `[skip ci]`. Si accoppia con `gh-deploy-pipeline` per l'esecuzione di app; utilizzare per pubblicare elementi con versione in un registro, non per distribuire un servizio in esecuzione.
