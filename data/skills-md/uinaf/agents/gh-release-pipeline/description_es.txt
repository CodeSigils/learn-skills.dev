Configure o alinee una canalización de lanzamiento de GitHub Actions para un paquete, biblioteca, CLI o acción de mercado versionado. Úselo al estandarizar repositorios en torno a la forma verificar-luego-liberar: empujar a principal → barandillas → etiquetas de liberación semántica + publicaciones → confirmar versión-bump nuevamente a principal con `[skip ci]`. Se empareja con `gh-deploy-pipeline` para ejecutar aplicaciones; Úselo para publicar artefactos versionados en un registro, no para implementar un servicio en ejecución.
