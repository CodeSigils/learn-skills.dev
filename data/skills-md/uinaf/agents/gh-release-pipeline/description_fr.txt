Configurez ou alignez un pipeline de publication GitHub Actions pour un package versionné, une bibliothèque, une CLI ou une action de marché. À utiliser lors de la standardisation des dépôts autour de la forme vérifier puis publier : pousser vers principal → garde-corps → balises de libération sémantique + publication → validation de changement de version vers principal avec `[skip ci]`. S'associe à « gh-deploy-pipeline » pour exécuter des applications ; à utiliser pour publier des artefacts versionnés dans un registre, et non pour déployer un service en cours d'exécution.
