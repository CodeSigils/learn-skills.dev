Настройте или настройте конвейер выпуска GitHub Actions для версионного пакета, библиотеки, интерфейса командной строки или действия Marketplace. Используйте при стандартизации репозиториев на основе формы «проверка-затем-релиз»: нажмите на главную → ограждения → теги семантического выпуска + публикации → верните версию-bump обратно в основную с помощью `[skip ci]`. Сопряжено с gh-deploy-pipeline для запуска приложений; используйте для публикации артефактов с версиями в реестре, а не для развертывания работающей службы.
