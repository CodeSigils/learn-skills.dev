قم بإعداد أو محاذاة مسار إصدار GitHub Actions لحزمة ذات إصدار أو مكتبة أو CLI أو إجراء السوق. استخدمه عند توحيد عمليات إعادة الشراء حول شكل التحقق ثم الإصدار: ادفع إلى الصفحة الرئيسية ← حواجز الحماية ← علامات الإصدار الدلالي + النشر ← نسخة نتوء الالتزام بالعودة إلى الصفحة الرئيسية باستخدام `[تخطي ci]`. يقترن بـ gh-deploy-pipeline لتشغيل التطبيقات؛ يُستخدم لنشر العناصر التي تم إصدارها إلى السجل، وليس لنشر خدمة قيد التشغيل.
