Divieto di "useEffect" diretto nel codice React. Da utilizzare durante la scrittura, il refactoring, la revisione o la migrazione di componenti o hook React che importano, chiamano, aggiungono o sostituiscono "useEffect" diretto; quando un agente richiede effetti per stato derivato, recupero, reazioni agli eventi, ripristini o sincronizzazione esterna; o quando si aggiungono regole lint/agente per una policy no-direct-useEffect. Non utilizzare per il normale lavoro di React senza odore di effetto, codice non React o architettura di effetti legittima al di fuori di React.
