Запретить прямое использование UseEffect в коде React. Используйте при написании, рефакторинге, проверке или миграции компонентов React или перехватчиков, которые импортируют, вызывают, добавляют или заменяют прямой `useEffect`; когда агент достигает эффектов для производного состояния, выборки, реакции на события, сброса или внешней синхронизации; или при добавлении правил lint/agent для политики no-direct-useEffect. Не используйте для обычной работы React без запаха эффекта, кода, не относящегося к React, или допустимой архитектуры эффектов вне React.
