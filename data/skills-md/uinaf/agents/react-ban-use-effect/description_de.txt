Direktes „useEffect“ im React-Code verbieten. Wird beim Schreiben, Refactoring, Überprüfen oder Migrieren von React-Komponenten oder Hooks verwendet, die direktes „useEffect“ importieren, aufrufen, hinzufügen oder ersetzen; wenn ein Agent nach Effekten für abgeleiteten Status, Abruf, Ereignisreaktionen, Zurücksetzen oder externe Synchronisierung greift; oder beim Hinzufügen von Lint-/Agent-Regeln für eine No-Direct-UseEffect-Richtlinie. Nicht für normale React-Arbeiten ohne Effektgeruch, Nicht-React-Code oder legitimer Effektarchitektur außerhalb von React verwenden.
