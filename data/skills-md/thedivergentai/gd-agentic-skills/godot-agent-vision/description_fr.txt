Yeux agents pour le travail de Godot : capture d'écran CLI multiplateforme (actif/région/fenêtre/écran) vers WebP budgétisé, pont de fenêtre de l'éditeur TEMP sous .gdskills/ et Taste Receptor Atlas v2 (~ 237 micro-récepteurs × 0–2 : hiérarchie, contraste, typographie × 41, capacité, espace, couleur, icône, composition, lumière/effets, détection de mouvement, anti-inclinaison, originalité, identité). À utiliser lorsque les agents doivent voir l’interface utilisateur, les ressources ou l’éditeur – pas pour les chargements automatiques de captures d’écran dans le jeu. Mots-clés : vision de l'agent, capture d'écran, WebP, assurance qualité visuelle, récepteurs gustatifs, typographie, révision de l'interface utilisateur, fiche d'actifs, fenêtre d'affichage de l'éditeur, anti-slop.
