Kit de herramientas de nivel experto para la automatización modular de CLI de Godot 4.7+ y la orquestación de compilaciones sin cabeza. Úsalo cuando necesites: (1) Construir árboles de escena o diseños de UI complejos de forma programática, (2) Automatizar pipelines expertos de activos 3D (glTF → Colisión), (3) Optimizar geometría procedural sin cabeza (CSG → Malla estática), o (4) Ingeniar pipelines CI/CD de calidad de producción. Configura la variable de entorno GODOT_PATH para la ubicación personalizada del motor. Palabras clave: Godot CLI, headless, CI, export, builder, 4.7.
