Навыки мониторинга общественного мнения в конечном итоге позволяют составить отчет об общественном мнении. Когда пользователь спрашивает: «Каково общественное мнение по определенному событию/теме?», «Каково общественное мнение?», «Провести анализ общественного мнения», «Провести анализ общественного мнения» или выполняет парсинг по ключевому слову/платформе и генерирует отчет об общественном мнении, используется этот навык. Соглашение: любое намерение, связанное с общественным мнением, запускает весь процесс (сканирование → анализ настроений → создание отчета). С помощью этого навыка выполняется ползание; анализ настроений автономно определяется главным Агентом по подсказке; отчет генерируется функциейgenerate_report.
