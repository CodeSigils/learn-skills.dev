Навыки мониторинга общественного мнения; конечный результат: заключение. Когда пользователь спрашивает: «Каково общественное мнение по событию/теме X?» «Какое настроение?» «Анализ общественного мнения» «Проведите анализ мнения» или запросите сбор ключевых слов/платформы и отчет, используйте этот навык. Правило: любое намерение, связанное с общественным мнением, запускает полный конвейер (сбор данных → анализ настроений → создание отчета). С помощью этого навыка выполняется очистка; анализ настроений осуществляется основным Агентом по подсказкам; отчет генерируется функциейgenerate_report.
