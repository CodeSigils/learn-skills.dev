Public opinion monitoring skill, ultimately produces a public opinion report. When the user asks “How is the public opinion on a certain event/topic?”, “What is the public sentiment?”, “Do a public opinion analysis”, “Run a public opinion analysis”, or scrapes by keyword/platform and generates a public opinion report, this skill is used. Agreement: any public‑opinion‑related intent triggers the full process (crawling → sentiment analysis → report generation). Crawling is performed by this skill; sentiment analysis is autonomously determined by the main Agent according to the prompt; the report is generated by generate_report.
