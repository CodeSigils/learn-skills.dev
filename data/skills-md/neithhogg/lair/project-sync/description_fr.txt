Maintient les fichiers contextuels PROJECT.md, JOURNAL.md, README.md et AI (CLAUDE.md, AGENT.md, AGENTS.md) précis et cohérents les uns avec les autres. Lit automatiquement l'historique git récent et les modifications de fichiers pour déterminer ce qui a été terminé et ce qui est prévu. JOURNAL.md est une liste de contrôle légère — [x] pour terminé, [ ] pour planifié. Effectue également une vérification de cohérence dans tous les documents pour détecter le contenu obsolète ou conflictuel. À utiliser chaque fois que la portée, la pile technologique ou la direction change. Invoquez avec /project-sync – ne se déclenche jamais automatiquement.
