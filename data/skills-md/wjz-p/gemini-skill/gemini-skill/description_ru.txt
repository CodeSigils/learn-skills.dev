Используйте официальный сайт Gemini (gemini.google.com) для создания изображений, общения и других операций. Срабатывает, когда пользователи упоминают такие ключевые слова, как «создать изображение/нарисовать/рисовать/нанобанан/нанобанан/создать изображение». Метод работы соответствует трем уровням приоритета: инструмент MCP в качестве первого выбора → сценарий навыка в качестве второго выбора → ручное управление навыками браузера в качестве последнего средства (требуется авторизация пользователя). Запрещен самостоятельный запуск внешних браузеров для доступа к Gemini.
