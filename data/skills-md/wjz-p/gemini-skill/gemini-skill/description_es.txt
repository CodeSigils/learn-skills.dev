Utilice el sitio web oficial de Gemini (gemini.google.com) para realizar generación de imágenes, conversaciones y otras operaciones. Se activa cuando los usuarios mencionan palabras clave como "generar imagen/dibujar/dibujar/nano banana/nanobanana/generar imagen". El método de operación sigue tres niveles de prioridad: herramienta MCP como primera opción → script de habilidades como segunda opción → operación manual del navegador de habilidades como último recurso (requiere autorización del usuario). Se prohíbe iniciar navegadores externos de forma independiente para acceder a Gemini.
