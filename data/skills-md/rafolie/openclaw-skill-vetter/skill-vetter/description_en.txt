Skill Security Review Protocol. Any external skill must be reviewed before installation.

**Trigger Scenarios**:
(1) User requests to install a skill from ClawdHub, GitHub, or another source
(2) User shares or recommends a skill for installation
(3) Another Agent shares skill code
(4) User says "install skill", "install a skill", or "check if this skill is safe"

**Why Review Is Needed**: Skills can access the filesystem, execute commands, and send network requests. Malicious skills may steal credentials, modify system files, or exfiltrate data. Review takes only a few minutes but prevents serious security issues.
