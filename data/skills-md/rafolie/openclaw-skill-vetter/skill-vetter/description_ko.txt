**트리거 시나리오**:
(1) 사용자가 ClawdHub, GitHub 또는 다른 소스에서 스킬 설치를 요청합니다.
(2) 사용자가 설치에 필요한 기술을 공유하거나 추천하는 경우
(3) 다른 에이전트가 스킬 코드를 공유함
(4) 사용자가 "스킬 설치", "스킬 설치", "이 스킬이 안전한지 확인"이라고 말합니다.
