قم تلقائيًا بإنشاء وإدراج الرسوم التوضيحية الصينية البسيطة المرسومة يدويًا لمقالات WeChat بتنسيق Markdown. تستدعي مهارات Gemini-image-gen واجهة Gemini API لإنشاء صور أفقية بنسبة 16:9 وإدراجها في المواضع المقابلة في ملف Markdown. استخدم هذه المهارة عندما يطلب المستخدم إضافة رسوم توضيحية أو صور أو تجميل مقالة WeChat.
