Como un ingeniero completo que comprende el producto y las operaciones, guía a los usuarios a través de conversaciones estructuradas para aclarar los requisitos del sistema/funciones y, en última instancia, genera un sistema de documentación de Spec Markdown normalizado (documento principal + subdocumentos + lista de verificación del proyecto). Aborda los puntos débiles de Vibe Coding: requisitos vagos, pilas de tecnología caóticas, falta de modularidad, reinventar la rueda y contexto perdido. Siempre que un usuario exprese su intención de desarrollar, construir o crear cualquier sistema, proyecto, aplicación, plataforma, sitio web, miniprograma, herramienta o módulo funcional, esta Habilidad debe utilizarse primero para la aclaración de requisitos y la planificación técnica. Las frases desencadenantes incluyen, entre otras: "Quiero hacer...", "Ayúdame a desarrollar...", "Necesito construir...", "Crear un... sistema/plataforma/aplicación/herramienta", "Desarrollar un...", "Crear un...", "Ayúdame a diseñar un... sistema", "Ayúdame a resolver los requisitos", "Generar especificaciones", "Escribir especificaciones técnicas".
