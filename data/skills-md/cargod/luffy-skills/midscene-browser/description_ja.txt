Midscene を使用してヘッドレス Puppeteer ブラウザを駆動するビジョンベースのブラウザ自動化。
純粋にスクリーンショットによって駆動され、DOM やアクセシビリティ ラベルは必要ありません。ページ上に表示される要素はすべて制御できます。
ユーザーのマウスやキーボードを引き継がずにヘッドレス ブラウザーで実行されるため、ユーザーはコンピュータを使い続けることができます。

使用例: Web ページの閲覧、データのスクレイピング、フォームへの入力、ボタンのクリック、フロントエンド UI のテスト、スクリーンショットの取得、Web ワークフローの自動化。

トリガーワード: ブラウザーの自動化、Web ページを開く、Web スクリーンショット、データのスクレイピング、フォームへの入力、Web ページのテスト、フロントエンド テスト、
ブラウザの自動化、URL を開く、Web スクレイピング、フォームへの入力、Web アプリのテスト、スクリーンショットの取得、
Web サイトの閲覧、ページの確認、QA フロントエンド、エンドツーエンドのテスト
