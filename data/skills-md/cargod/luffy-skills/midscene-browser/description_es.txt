Automatización del navegador basada en visión que utiliza Midscene para impulsar un navegador Puppeteer sin cabeza.
Impulsado exclusivamente por capturas de pantalla, no se necesitan DOM ni etiquetas de accesibilidad, puede controlar cualquier elemento visible en la página.
Se ejecuta en un navegador sin cabeza, no controla el mouse o el teclado del usuario, por lo que el usuario puede seguir usando la computadora.

Casos de uso: navegar por páginas web, extraer datos, completar formularios, hacer clic en botones, probar la interfaz de usuario, tomar capturas de pantalla, automatizar flujos de trabajo web.

Palabras desencadenantes: automatización del navegador, página web abierta, captura de pantalla web, extracción de datos, formulario de llenado, página web de prueba, prueba de front-end,
