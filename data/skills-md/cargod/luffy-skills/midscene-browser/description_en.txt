Vision-based browser automation, powered by Midscene driving a headless Puppeteer browser.
Driven purely by screenshots, no DOM or accessibility tags needed, can control any visible element on the page.
Runs in a headless browser, doesn't take over the user's mouse and keyboard, so users can keep using their computer.

Use cases: browse websites, scrape data, fill forms, click buttons, test frontend UI, take webpage screenshots, automate web workflows.
