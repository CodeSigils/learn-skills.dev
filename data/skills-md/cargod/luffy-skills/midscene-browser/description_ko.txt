헤드리스 Puppeteer 브라우저를 구동하는 Midscene을 기반으로 한 비전 기반 브라우저 자동화입니다.
순전히 스크린샷으로 구동되며 DOM이나 접근성 태그가 필요하지 않으며 페이지에 표시되는 모든 요소를 ​​제어할 수 있습니다.
헤드리스 브라우저에서 실행되며 사용자의 마우스와 키보드를 차지하지 않으므로 사용자는 컴퓨터를 계속 사용할 수 있습니다.

사용 사례: 웹사이트 탐색, 데이터 스크랩, 양식 채우기, 버튼 클릭, 프런트엔드 UI 테스트, 웹페이지 스크린샷 찍기, 웹 워크플로 자동화.

실행 단어: 브라우저 자동화, 웹페이지 열기, 웹페이지 스크린샷, 데이터 스크랩, 양식 작성, 웹페이지 테스트, 프런트엔드 테스트,
브라우저 자동화, URL 열기, 웹 스크래핑, 양식 작성, 웹 앱 테스트, 스크린샷 찍기,
웹사이트 탐색, 페이지 확인, QA 프론트엔드, 엔드투엔드 테스트
