Vision-based Android device automation using Midscene to control Android phones/emulators via ADB.  
Driven purely by screenshots—no DOM or accessibility tags needed—manipulate any visible on-screen element.  

Supports: tap, swipe, input text, launch apps, take screenshots, and more.
