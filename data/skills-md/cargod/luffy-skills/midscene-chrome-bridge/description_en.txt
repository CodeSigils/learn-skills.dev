Vision-based Chrome Bridge mode automation connects to the user's real desktop Chrome browser via the Midscene Chrome extension.  
It preserves cookies, sessions, and login states without taking over the mouse or keyboard (operating through the Chrome DevTools Protocol).

Ideal for web operations that require an already-logged-in state, data scraping that keeps the session, and scenarios that need the user's genuine browser environment.
