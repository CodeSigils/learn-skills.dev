Vision-based Chrome Bridge mode automation connects to the user's real desktop Chrome browser via the Midscene Chrome extension.  
Preserves cookies, sessions, and login states without taking over the mouse or keyboard (operates through Chrome DevTools Protocol).

Suited for web tasks that require an already-logged-in state, data scraping while retaining the session, and scenarios that need the user's real browser environment.
