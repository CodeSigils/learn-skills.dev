ビジョンベースの Chrome ブリッジ モードの自動化は、Midscene Chrome 拡張機能を介してユーザーの実際のデスクトップ Chrome ブラウザに接続します。  
マウスやキーボードを引き継がずに、Cookie、セッション、ログイン状態を保持します (Chrome DevTools プロトコルを通じて動作します)。

ログイン済みの状態を必要とする Web タスク、セッションを保持したままのデータ スクレイピング、およびユーザーの実際のブラウザ環境が必要なシナリオに適しています。
