Automatisation du mode Chrome Bridge basée sur la vision, connexion au véritable navigateur Chrome de bureau de l'utilisateur via l'extension Midscene Chrome.  
Préserve les cookies, les sessions et l'état de connexion sans prendre le contrôle de la souris ou du clavier (fonctionne via le protocole Chrome DevTools).  

Idéal pour les opérations de page Web connectées, la récupération de données préservant la session et les scénarios nécessitant l’environnement de navigateur authentique de l’utilisateur.
