Midscene을 사용하여 macOS, Windows 및 Linux 데스크톱 앱에서 키보드와 마우스를 기본적으로 제어하는 ​​비전 기반 데스크톱 자동화입니다.  
순전히 스크린샷으로 구동되며 DOM이나 접근성 라벨이 필요하지 않습니다. 화면에 보이는 모든 요소와 상호 작용할 수 있습니다.  
데스크톱 기본 앱(Electron, Qt, macOS/Windows/Linux 기본 앱)과 함께 작동합니다.

⚠️ 이 스킬은 사용자의 실제 마우스와 키보드를 대신합니다. 자동화 중에는 컴퓨터를 사용할 수 없습니다.  
→ 웹 앱의 경우 미드씬 브라우저 기술을 선호합니다(헤드리스 브라우저, 사용자 작업을 방해하지 않음).

실행 단어: 데스크탑 자동화, 컴퓨터 제어, 앱 열기, 데스크탑 스크린샷, 마우스 클릭, 키보드 단축키, 데스크탑 작동, 데스크탑 테스트, 앱 열기, 데스크탑 자동화, 컴퓨터 제어, 화면 클릭, 텍스트 입력, 애플리케이션 실행, 데스크탑 앱 테스트, Electron 앱 테스트, 네이티브 UI 테스트
