Vision-based desktop automation, driven by Midscene, controls native keyboard and mouse on macOS, Windows, and Linux desktop apps.
Driven purely by screenshots, no DOM or accessibility labels needed, can manipulate any visible element on screen.
Works for desktop native apps (Electron, Qt, macOS/Windows/Linux native apps).

⚠️ This skill takes over the user's real mouse and keyboard; the computer cannot be used during automation.
→ For web apps, please prefer the midscene-browser skill (headless browser, does not affect user operation).
