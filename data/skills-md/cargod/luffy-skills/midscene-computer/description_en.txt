Vision-based desktop automation, driven by Midscene, natively controls mouse and keyboard on macOS, Windows, and Linux desktop applications.  
Driven purely by screenshots, no DOM or accessibility labels needed, can manipulate any visible element on screen.  
Works for desktop native apps (Electron, Qt, macOS/Windows/Linux native apps).

⚠️ This skill takes over the user's real mouse and keyboard; the user cannot operate the computer during automation.  
→ For web apps, prefer the midscene-browser skill (headless browser, does not affect user operation).
