Автоматизация рабочего стола на основе Vision с использованием Midscene для управления встроенными средствами управления с помощью мыши и клавиатуры настольных приложений macOS, Windows и Linux.
Основано исключительно на скриншотах, не требуется DOM или теги доступности; может манипулировать любым видимым элементом на экране.
Работает для настольных приложений (родные приложения Electron, Qt, macOS/Windows/Linux).

⚠️Этот навык берет на себя настоящую мышь и клавиатуру пользователя; пользователь не может управлять компьютером во время работы автоматизации.
→ Для веб-приложений отдавайте предпочтение навыку промежуточного браузера (безголовый браузер, не влияет на работу пользователя).
