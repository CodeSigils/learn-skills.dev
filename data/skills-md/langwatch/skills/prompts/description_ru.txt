Версируйте подсказки вашего агента и управляйте ими с помощью интерфейса командной строки LangWatch Prompts CLI. Используйте как для адаптации (настройка управления версиями приглашений для всей базы кода), так и для целевых операций (версия конкретного приглашения, создание новой версии приглашения). Поддерживает Python и TypeScript.
