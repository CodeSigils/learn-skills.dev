Verfasser, überprüft, installiert und debuggt GitHub Agentic Workflows in Repositorys, einschließlich Workflow-Markdown, Frontmatter, Gaw-Kompilierungs- und Ausführungsflows, sichere Ausgaben, Sicherheitsleitplanken und Betriebsmuster. Zur Verwendung beim Erstellen oder Verwalten der GH-AW-Automatisierung. Nicht für standardmäßige deterministische GitHub-Aktionen (YAML), generische CI-Pipelines oder Nicht-GitHub-Automatisierungssysteme verwenden.
