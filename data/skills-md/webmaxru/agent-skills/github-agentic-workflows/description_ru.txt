Создает, просматривает, устанавливает и отлаживает агентные рабочие процессы GitHub в репозиториях, включая уценку рабочих процессов, оформление, процессы компиляции и запуска, безопасные выходные данные, меры безопасности и рабочие шаблоны. Используйте при создании или поддержке автоматизации GH-AW. Не используйте YAML для стандартных детерминированных действий GitHub, универсальных конвейеров CI или систем автоматизации, отличных от GitHub.
