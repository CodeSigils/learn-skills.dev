Implémente et débogue les intégrations de l'API Proofreader du navigateur dans les applications Web JavaScript ou TypeScript. À utiliser lors de l'ajout de contrôles de disponibilité du correcteur d'épreuves, de téléchargements de modèles surveillés, de flux de relecture, de gestion des métadonnées de correction ou de vérifications de politiques d'autorisations pour la relecture intégrée. Ne pas utiliser pour l'ingénierie d'invites génériques, les SDK LLM côté serveur ou les services d'IA cloud.
