Implementa ed esegue il debug delle integrazioni dell'API Proofreader del browser nelle app Web JavaScript o TypeScript. Da utilizzare quando si aggiungono controlli di disponibilità del correttore di bozze, download di modelli monitorati, flussi di correzione di bozze, gestione dei metadati di correzione o controlli delle politiche di autorizzazione per la correzione di bozze integrata. Non utilizzare per prompt engineering generico, SDK LLM lato server o servizi di intelligenza artificiale cloud.
