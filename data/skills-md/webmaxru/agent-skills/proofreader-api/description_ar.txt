ينفذ ويصحح تكاملات واجهة برمجة تطبيقات Proofreader للمتصفح في تطبيقات الويب JavaScript أو TypeScript. يُستخدم عند إضافة عمليات التحقق من توفر المصحح، أو تنزيلات النماذج المراقبة، أو تدفقات التدقيق اللغوي، أو معالجة بيانات تعريف التصحيح، أو عمليات التحقق من سياسة الأذونات للتدقيق اللغوي المضمن. لا تستخدم للهندسة السريعة العامة، أو LLM SDK من جانب الخادم، أو خدمات الذكاء الاصطناعي السحابية.
