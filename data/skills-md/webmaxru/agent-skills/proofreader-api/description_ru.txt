Реализует и отлаживает интеграцию API корректора браузера в веб-приложения JavaScript или TypeScript. Используйте при добавлении проверок доступности корректора, отслеживаемых загрузок моделей, потоков корректуры, обработки метаданных исправлений или проверок политики разрешений для встроенной корректуры. Не используйте для общего оперативного проектирования, серверные LLM SDK или облачные службы искусственного интеллекта.
