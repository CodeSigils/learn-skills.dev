Implementa y depura integraciones de API de corrección de pruebas del navegador en aplicaciones web JavaScript o TypeScript. Úselo al agregar verificaciones de disponibilidad del corrector, descargas de modelos monitoreadas, flujos de revisión, manejo de metadatos de corrección o verificaciones de políticas de permisos para la revisión integrada. No lo utilice para ingeniería de avisos genérica, SDK de LLM del lado del servidor o servicios de inteligencia artificial en la nube.
