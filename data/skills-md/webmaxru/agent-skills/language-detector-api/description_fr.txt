Implémente et débogue les intégrations de l'API Language Detector du navigateur dans les applications Web JavaScript ou TypeScript. À utiliser lors de l'ajout de vérifications de prise en charge de LanguageDetector, de flux de téléchargement de disponibilité et de modèles, de création de sessions, d'appels detector(), de mesure de l'utilisation des entrées, de gestion des politiques d'autorisations ou de solutions de secours de compatibilité pour la détection de langue intégrée. Ne pas utiliser pour les SDK de détection de langue côté serveur, les services de traduction cloud ou les pipelines NLP génériques.
