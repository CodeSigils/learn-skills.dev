Implementa y depura las integraciones de la API Language Detector del navegador en aplicaciones web JavaScript o TypeScript. Úselo al agregar comprobaciones de soporte de LanguageDetector, flujos de descarga de modelos y disponibilidad, creación de sesiones, llamadas detect(), medición del uso de entradas, manejo de políticas de permisos o reservas de compatibilidad para la detección de idiomas integrada. No lo utilice para SDK de detección de idioma del lado del servidor, servicios de traducción en la nube ni canalizaciones genéricas de PNL.
