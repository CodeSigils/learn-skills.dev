ينفذ ويصحح أخطاء عمليات تكامل واجهة برمجة تطبيقات Language Detector للمتصفح في تطبيقات الويب JavaScript أو TypeScript. يُستخدم عند إضافة فحوصات دعم LanguageDetector، أو تدفقات التوفر وتنزيل النماذج، أو إنشاء الجلسة، أو مكالمات الكشف()، أو قياس استخدام المدخلات، أو معالجة سياسة الأذونات، أو عمليات التراجع عن التوافق لاكتشاف اللغة المضمنة. لا تستخدمه لأدوات تطوير البرامج (SDK) للكشف عن اللغة من جانب الخادم، أو خدمات الترجمة السحابية، أو مسارات البرمجة اللغوية العصبية (NLP) العامة.
