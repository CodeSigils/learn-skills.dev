Implementa ed esegue il debug delle integrazioni dell'API Language Detector del browser nelle app Web JavaScript o TypeScript. Da utilizzare quando si aggiungono controlli di supporto LanguageDetector, disponibilità e flussi di download di modelli, creazione di sessioni, chiamate define(), misurazione dell'utilizzo dell'input, gestione delle policy di autorizzazione o fallback di compatibilità per il rilevamento della lingua integrato. Non utilizzare per SDK di rilevamento della lingua lato server, servizi di traduzione cloud o pipeline NLP generiche.
