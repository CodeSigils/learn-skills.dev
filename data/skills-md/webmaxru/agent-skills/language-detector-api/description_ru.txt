Реализует и отлаживает интеграцию API-интерфейса Language Detector браузера в веб-приложения JavaScript или TypeScript. Используйте при добавлении проверок поддержки LanguageDetector, потоков доступности и загрузки моделей, создания сеансов, вызовов метода обнаружения(), измерения использования ввода, обработки политики разрешений или резервных вариантов совместимости для встроенного определения языка. Не используйте для определения языка на стороне сервера SDK, облачные службы перевода или общие конвейеры NLP.
