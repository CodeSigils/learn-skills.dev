Implementa y depura integraciones de API de avisos del navegador en aplicaciones web JavaScript o TypeScript. Úselo al agregar comprobaciones de disponibilidad de LanguageModel, creación de sesiones, mensajes o flujos de transmisión de mensajes, resultados estructurados, UX de progreso de descarga o manejo de políticas de permisos de iframe. No lo utilice para SDK de LLM del lado del servidor, API de REST AI o proveedores que no sean de navegador.
