Implémente et débogue les intégrations de l'API Prompt du navigateur dans les applications Web JavaScript ou TypeScript. À utiliser lors de l'ajout de contrôles de disponibilité de LanguageModel, de la création de sessions, de flux d'invite ou d'inviteStreaming, de sortie structurée, de progression du téléchargement UX ou de gestion des politiques d'autorisation iframe. Ne pas utiliser pour les SDK LLM côté serveur, les API REST AI ou les fournisseurs autres que les navigateurs.
