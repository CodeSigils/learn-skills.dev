Implementa ed esegue il debug delle integrazioni API Prompt del browser nelle app Web JavaScript o TypeScript. Da utilizzare quando si aggiungono controlli di disponibilità LanguageModel, creazione di sessioni, flussi di prompt o promptStreaming, output strutturato, UX di avanzamento del download o gestione dei criteri di autorizzazione iframe. Non utilizzare per SDK LLM lato server, API REST AI o provider non browser.
