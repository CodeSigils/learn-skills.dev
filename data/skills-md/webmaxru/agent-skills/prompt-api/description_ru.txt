Реализует и отлаживает интеграцию API-интерфейса Prompt браузера в веб-приложения JavaScript или TypeScript. Используйте при добавлении проверок доступности LanguageModel, создании сеанса, потоках приглашения или PromptStreaming, структурированном выводе, пользовательском интерфейсе процесса загрузки или обработке политики разрешений iframe. Не используйте для серверных LLM SDK, REST AI API или поставщиков, не являющихся браузерами.
