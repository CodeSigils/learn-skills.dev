Distribuisce raccolte di competenze dell'agente da qualsiasi repository GitHub con una cartella /skills su una o più superfici di distribuzione: versioni di GitHub, marketplace di Claude Code, marketplace di plug-in VS Code e marketplace di plug-in CLI Copilot. Gestisce la convalida pre-flight, l'analisi del commit convenzionale, il version bumping nelle configurazioni di superficie e la pubblicazione specifica della superficie con supporto di prova. Da utilizzare quando si rilascia, si pubblica o si distribuisce una raccolta di competenze su qualsiasi marketplace supportato o si crea una versione GitHub per un repository di competenze. Non usare per la distribuzione di pacchetti senza competenze, moduli npm, immagini Docker o risorse di Azure.
