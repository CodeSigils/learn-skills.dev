Installa, configura, controlla e gestisce Agent Package Manager (APM) nei repository. Da utilizzare durante l'inizializzazione di apm.yml, l'installazione o l'aggiornamento di pacchetti, la convalida dei manifest, la gestione dei file di lock, la compilazione del contesto dell'agente, l'esplorazione dei server MCP, l'impostazione dei runtime o il confezionamento del contesto risolto per CI e distribuzione del team. Non utilizzare per scrivere manualmente una singola competenza, gestori di pacchetti generici come npm o pip o sistemi di configurazione dell'agente non APM.
