Implementa ed esegue il debug delle integrazioni WebMCP del browser nelle app Web JavaScript o TypeScript. Da utilizzare quando si espongono strumenti imperativi tramite navigator.modelContext, si annotano moduli HTML per strumenti dichiarativi, si gestiscono flussi di moduli richiamati dall'agente o si convalida il comportamento WebMCP nell'anteprima corrente di Chrome. Non utilizzare per server MCP lato server, backend di strumenti REST o provider non browser.
