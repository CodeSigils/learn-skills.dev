Implementa y depura integraciones WebMCP del navegador en aplicaciones web JavaScript o TypeScript. Úselo al exponer herramientas imperativas a través de navigator.modelContext, anotar formularios HTML para herramientas declarativas, manejar flujos de formularios invocados por agentes o validar el comportamiento de WebMCP en la vista previa actual de Chrome. No lo utilice para servidores MCP del lado del servidor, backends de herramientas REST o proveedores que no sean navegadores.
