Implémente et débogue les intégrations WebMCP du navigateur dans les applications Web JavaScript ou TypeScript. À utiliser lors de l'exposition d'outils impératifs via navigator.modelContext, de l'annotation de formulaires HTML pour les outils déclaratifs, de la gestion des flux de formulaires invoqués par l'agent ou de la validation du comportement de WebMCP dans l'aperçu actuel de Chrome. Ne pas utiliser pour les serveurs MCP côté serveur, les backends d'outils REST ou les fournisseurs non-navigateurs.
