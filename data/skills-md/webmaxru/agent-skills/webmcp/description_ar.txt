ينفذ ويصحح أخطاء تكامل WebMCP للمتصفح في تطبيقات الويب JavaScript أو TypeScript. يُستخدم عند الكشف عن الأدوات الضرورية من خلال navigator.modelContext، أو إضافة تعليقات توضيحية لنماذج HTML للأدوات التعريفية، أو التعامل مع تدفقات النماذج التي يستدعيها الوكيل، أو التحقق من صحة سلوك WebMCP في معاينة Chrome الحالية. لا تستخدمه مع خوادم MCP من جانب الخادم، أو الواجهات الخلفية لأداة REST، أو موفري الخدمات غير المستعرضين.
