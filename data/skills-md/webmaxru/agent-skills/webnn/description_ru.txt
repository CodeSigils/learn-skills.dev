Реализует и отлаживает интеграцию API нейронной сети браузера в веб-приложениях JavaScript или TypeScript. Используйте при добавлении проверок navigator.ml, создании MLContext, потоках MLGraphBuilder, выборе устройства, отправке и обратном чтении тензоров или явных резервных путях к сети ONNX Runtime Web или другим локальным средам выполнения. Не используйте для обучения моделей, вывода машинного обучения на стороне сервера или облачных API-интерфейсов искусственного интеллекта.
