Implementa ed esegue il debug delle integrazioni API Web Neural Network del browser nelle app Web JavaScript o TypeScript. Da utilizzare quando si aggiungono controlli navigator.ml, creazione MLContext, flussi MLGraphBuilder, selezione dispositivo, invio e rilettura tensore o percorsi di fallback espliciti a ONNX Runtime Web o altri runtime locali. Non utilizzare per l'addestramento del modello, l'inferenza ML lato server o le API AI cloud.
