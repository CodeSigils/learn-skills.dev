Implementa y depura integraciones de API de red neuronal web del navegador en aplicaciones web JavaScript o TypeScript. Úselo al agregar comprobaciones de navigator.ml, creación de MLContext, flujos de MLGraphBuilder, selección de dispositivos, envío y lectura de tensor, o rutas de respaldo explícitas a ONNX Runtime Web u otros tiempos de ejecución locales. No lo utilice para entrenamiento de modelos, inferencia de aprendizaje automático del lado del servidor ni API de IA en la nube.
