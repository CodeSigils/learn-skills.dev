ينفذ ويصحح أخطاء تكامل Web Neural Network API للمتصفح في تطبيقات الويب JavaScript أو TypeScript. يُستخدم عند إضافة عمليات فحص navigator.ml، أو إنشاء MLContext، أو تدفقات MLGraphBuilder، أو اختيار الجهاز، أو إرسال الموتر والقراءة، أو مسارات احتياطية صريحة إلى ONNX Runtime Web أو أوقات التشغيل المحلية الأخرى. لا تستخدم للتدريب على النماذج، أو استدلال تعلم الآلة من جانب الخادم، أو واجهات برمجة التطبيقات السحابية للذكاء الاصطناعي.
