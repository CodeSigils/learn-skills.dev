Implémente et débogue les intégrations de l'API Web Neural Network du navigateur dans les applications Web JavaScript ou TypeScript. À utiliser lors de l'ajout de vérifications navigator.ml, de la création de MLContext, de flux MLGraphBuilder, de la sélection de périphériques, de la répartition et de la relecture de tenseurs, ou de chemins de secours explicites vers ONNX Runtime Web ou d'autres environnements d'exécution locaux. Ne pas utiliser pour la formation de modèles, l'inférence ML côté serveur ou les API d'IA cloud.
