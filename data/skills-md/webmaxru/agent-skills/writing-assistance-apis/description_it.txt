Implementa ed esegue il debug delle integrazioni del browser Summarizer, Writer e Rewriter nelle app Web JavaScript o TypeScript. Da utilizzare quando si aggiungono controlli di disponibilità, download di modelli UX, creazione di sessioni, riepilogo o scrittura o riscrittura di flussi, output di streaming, gestione delle interruzioni o vincoli di policy di autorizzazione per le API di assistenza alla scrittura integrate. Non utilizzare per prompt engineering generico, SDK LLM lato server o servizi di intelligenza artificiale cloud.
