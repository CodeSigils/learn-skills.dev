Implementa y depura integraciones de Summarizer, Writer y Rewriter del navegador en aplicaciones web JavaScript o TypeScript. Úselo al agregar comprobaciones de disponibilidad, UX de descarga de modelos, creación de sesiones, resumir o escribir o reescribir flujos, transmisión de salida, manejo de abortos o restricciones de políticas de permisos para API de asistencia de escritura integradas. No lo utilice para ingeniería de avisos genérica, SDK de LLM del lado del servidor o servicios de inteligencia artificial en la nube.
