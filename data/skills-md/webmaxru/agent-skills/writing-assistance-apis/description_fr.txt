Implémente et débogue les intégrations de navigateur Summarizer, Writer et Rewriter dans les applications Web JavaScript ou TypeScript. À utiliser lors de l'ajout de contrôles de disponibilité, de téléchargement de modèles UX, de création de sessions, de résumés, d'écritures ou de réécritures de flux, de diffusion en continu de sorties, de gestion d'abandon ou de contraintes de politique d'autorisations pour les API d'aide à l'écriture intégrées. Ne pas utiliser pour l'ingénierie d'invites génériques, les SDK LLM côté serveur ou les services d'IA cloud.
