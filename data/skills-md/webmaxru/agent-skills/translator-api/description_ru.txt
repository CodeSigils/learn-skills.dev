Реализует и отлаживает интеграцию API-интерфейса переводчика браузера в веб-приложения JavaScript или TypeScript. Используйте при добавлении проверок поддержки переводчика, потоков доступности языковых пар, пользовательского интерфейса загрузки модели, создания сеанса, вызовов Translate() или TranslateStreaming(), измерения использования ввода или обработки политики разрешений для перевода на устройстве. Не используйте для серверного перевода SDK, облачные службы перевода или общие конвейеры многоязычного контента.
