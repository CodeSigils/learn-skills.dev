ينفذ ويصحح أخطاء تكامل واجهة برمجة تطبيقات Translator للمتصفح في تطبيقات الويب JavaScript أو TypeScript. يُستخدم عند إضافة فحوصات دعم المترجم، أو تدفقات توفر زوج اللغة، أو تنزيل نموذج UX، أو إنشاء الجلسة، أو ترجمة() أو مكالمات TranslationStreaming()، أو قياس استخدام الإدخال، أو معالجة سياسة الأذونات للترجمة على الجهاز. لا تستخدمه لحزم SDK للترجمة من جانب الخادم، أو خدمات الترجمة السحابية، أو خطوط أنابيب المحتوى العامة متعددة اللغات.
