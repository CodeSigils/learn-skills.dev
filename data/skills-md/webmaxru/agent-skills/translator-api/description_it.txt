Implementa ed esegue il debug delle integrazioni dell'API Translator del browser nelle app Web JavaScript o TypeScript. Da utilizzare quando si aggiungono controlli di supporto del traduttore, flussi di disponibilità di coppie linguistiche, UX di download di modelli, creazione di sessioni, chiamate Translate() o TranslateStreaming(), misurazione dell'utilizzo dell'input o gestione delle policy di autorizzazione per la traduzione sul dispositivo. Non utilizzare per SDK di traduzione lato server, servizi di traduzione cloud o pipeline di contenuti multilingue generici.
