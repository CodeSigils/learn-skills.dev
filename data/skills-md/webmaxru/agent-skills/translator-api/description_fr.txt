Implémente et débogue les intégrations de l'API Translator du navigateur dans les applications Web JavaScript ou TypeScript. À utiliser lors de l'ajout de vérifications de prise en charge du traducteur, de flux de disponibilité de paires de langues, de téléchargement de modèles UX, de création de sessions, d'appels Translate() ou TranslateStreaming(), de mesure de l'utilisation des entrées ou de gestion des politiques d'autorisations pour la traduction sur l'appareil. Ne pas utiliser pour les SDK de traduction côté serveur, les services de traduction cloud ou les pipelines de contenu multilingue génériques.
