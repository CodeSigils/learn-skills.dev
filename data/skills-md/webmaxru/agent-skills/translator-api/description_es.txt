Implementa y depura integraciones de API de traductor del navegador en aplicaciones web JavaScript o TypeScript. Úselo al agregar comprobaciones de compatibilidad con Translator, flujos de disponibilidad de pares de idiomas, descarga de modelos UX, creación de sesiones, llamadas de Translate() o TranslateStreaming(), medición del uso de entradas o manejo de políticas de permisos para la traducción en el dispositivo. No lo utilice para SDK de traducción del lado del servidor, servicios de traducción en la nube ni canalizaciones de contenido multilingüe genérico.
