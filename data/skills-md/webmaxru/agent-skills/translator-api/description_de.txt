Implementiert und debuggt Browser-Übersetzer-API-Integrationen in JavaScript- oder TypeScript-Webanwendungen. Verwenden Sie diese Option, wenn Sie Übersetzer-Unterstützungsprüfungen, Sprachpaar-Verfügbarkeitsabläufe, Modell-Download-UX, Sitzungserstellung, Translate()- oder TranslateStreaming()-Aufrufe, Eingabenutzungsmessung oder Berechtigungsrichtlinienbehandlung für die Übersetzung auf dem Gerät hinzufügen. Nicht für serverseitige Übersetzungs-SDKs, Cloud-Übersetzungsdienste oder generische mehrsprachige Inhaltspipelines verwenden.
