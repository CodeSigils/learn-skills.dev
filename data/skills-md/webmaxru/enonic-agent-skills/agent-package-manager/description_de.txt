Installiert, konfiguriert, prüft und betreibt den Agent Package Manager (APM) in Repositorys. Wird verwendet, wenn Sie apm.yml initialisieren, Pakete installieren oder aktualisieren, Manifeste validieren, Sperrdateien verwalten, Agentenkontext kompilieren, MCP-Server durchsuchen, Laufzeiten einrichten oder aufgelösten Kontext für CI- und Teamverteilung packen. Verwenden Sie zum manuellen Schreiben eines einzelnen Skills keine generischen Paketmanager wie npm oder pip oder Nicht-APM-Agentenkonfigurationssysteme.
