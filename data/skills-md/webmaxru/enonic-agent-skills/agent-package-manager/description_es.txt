Instala, configura, audita y opera Agent Package Manager (APM) en repositorios. Úselo al inicializar apm.yml, instalar o actualizar paquetes, validar manifiestos, administrar archivos de bloqueo, compilar el contexto del agente, explorar servidores MCP, configurar tiempos de ejecución o empaquetar el contexto resuelto para CI y distribución en equipo. No lo utilice para escribir una sola habilidad a mano, administradores de paquetes genéricos como npm o pip, o sistemas de configuración de agentes que no sean APM.
