Génère des définitions de schéma XML de type de contenu Enonic XP à partir de descriptions en langage naturel. Couvre la modélisation de contenu structuré, y compris les types d'entrée, la disposition des formulaires, les jeux d'options, les jeux d'éléments, les mixins, les données X et l'héritage des types de contenu. À utiliser lors de la création, de l'échafaudage ou de la génération de définitions de types de contenu Enonic XP, de l'ajout de champs ou d'ensembles à des types de contenu existants ou de l'interrogation de types d'entrée et de super-types Enonic XP. Ne pas utiliser pour la modélisation de contenu CMS non Enonic, les requêtes GraphQL, les contrôleurs JavaScript/TypeScript ou l'édition XML générique sans rapport avec les schémas Enonic.
