يُنشئ تعريفات مخطط XML لنوع محتوى Enonic XP من أوصاف اللغة الطبيعية. يغطي نمذجة المحتوى المنظم بما في ذلك أنواع الإدخال، وتخطيط النموذج، ومجموعات الخيارات، ومجموعات العناصر، والخلطات، وبيانات x، ووراثة نوع المحتوى. يُستخدم عند إنشاء تعريفات أنواع محتوى Enonic XP أو دعمها أو إنشاؤها، أو إضافة حقول أو مجموعات إلى أنواع المحتوى الموجودة، أو الاستعلام عن أنواع إدخالات Enonic XP والأنواع الفائقة. لا تستخدمه لنمذجة محتوى غير Enonic CMS، أو استعلامات GraphQL، أو وحدات تحكم JavaScript/TypeScript، أو تحرير XML العام غير المرتبط بمخططات Enonic.
