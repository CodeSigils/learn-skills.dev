Genera definizioni di schemi XML del tipo di contenuto Enonic XP da descrizioni in linguaggio naturale. Copre la modellazione del contenuto strutturato inclusi i tipi di input, il layout del modulo, i set di opzioni, i set di elementi, i mixin, i dati x e l'ereditarietà del tipo di contenuto. Da utilizzare durante la creazione, lo scaffolding o la generazione di definizioni di tipi di contenuto di Enonic XP, l'aggiunta di campi o insiemi a tipi di contenuto esistenti o l'esecuzione di query su tipi di input e supertipi di Enonic XP. Non utilizzare per la modellazione di contenuti CMS non Enonic, query GraphQL, controller JavaScript/TypeScript o modifiche XML generiche non correlate agli schemi Enonic.
