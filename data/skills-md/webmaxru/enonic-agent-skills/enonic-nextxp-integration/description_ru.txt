Руководства по настройке, разработке и устранению неполадок автономной интеграции Next.js и Enonic XP (инфраструктура Next.XP). Охватывает конфигурацию адаптера Enonic, сопоставление типа контента с компонентами React, получение данных Guillotine GraphQL, режим предварительного просмотра Content Studio и переключение черновой/основной ветки. Используйте при создании интерфейса Next.js на базе Enonic XP, настройке адаптера Next.XP, сопоставлении типов контента с компонентами, получении контента Enonic через Guillotine в Next.js или отладке предварительного просмотра Content Studio. Не используйте для традиционного рендеринга Enonic XP на стороне сервера автономные запросы Guillotine без Next.js, интерфейсные платформы, отличные от Next.js, с Enonic или встроенный рендеринг React4XP.
