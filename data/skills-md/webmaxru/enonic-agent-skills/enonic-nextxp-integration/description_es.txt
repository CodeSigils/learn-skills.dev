Guía de configuración, desarrollo y solución de problemas de la integración sin cabeza de Next.js y Enonic XP (marco Next.XP). Cubre la configuración del adaptador Enonic, el tipo de contenido para el mapeo de componentes de React, la obtención de datos de Guillotine GraphQL, el modo de vista previa de Content Studio y el cambio de rama borrador/maestro. Úselo al crear una interfaz Next.js con tecnología Enonic XP, configurar el adaptador Next.XP, asignar tipos de contenido a componentes, obtener contenido Enonic a través de Guillotine en Next.js o depurar la vista previa de Content Studio. No lo use para el renderizado tradicional de Enonic XP del lado del servidor, consultas de Guillotina independientes sin Next.js, marcos de interfaz que no sean Next.js con Enonic o renderizado integrado React4XP.
