Guide la configuration, le développement et le dépannage de l’intégration sans tête Next.js et Enonic XP (framework Next.XP). Couvre la configuration de l'adaptateur Enonic, le type de contenu vers le mappage des composants React, la récupération de données Guillotine GraphQL, le mode d'aperçu Content Studio et la commutation de branche brouillon/maître. À utiliser lors de la création d'une interface Next.js optimisée par Enonic XP, de la configuration de l'adaptateur Next.XP, du mappage des types de contenu sur des composants, de la récupération du contenu Enonic via Guillotine dans Next.js ou du débogage de l'aperçu de Content Studio. Ne pas utiliser pour le rendu Enonic XP traditionnel côté serveur, les requêtes Guillotine autonomes sans Next.js, les frameworks frontend non-Next.js avec Enonic ou le rendu intégré React4XP.
