Next.js と Enonic XP のヘッドレス統合 (Next.XP フレームワーク) のセットアップ、開発、トラブルシューティングをガイドします。 Enonic アダプターの構成、コンテンツ タイプから React コンポーネントへのマッピング、Guillotine GraphQL データの取得、Content Studio プレビュー モード、およびドラフト/マスター ブランチの切り替えについて説明します。 Enonic XP を利用した Next.js フロントエンドの構築、Next.XP アダプターの構成、コンテンツ タイプのコンポーネントへのマッピング、Next.js の Guillotine 経由で Enonic コンテンツを取得するとき、または Content Studio プレビューをデバッグするときに使用します。従来のサーバーサイドの Enonic XP レンダリング、Next.js を使用しないスタンドアロンの Guillotine クエリ、Enonic を使用した Next.js 以外のフロントエンド フレームワーク、または React4XP 埋め込みレンダリングには使用しないでください。
