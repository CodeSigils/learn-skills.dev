指导 Next.js 和 Enonic XP 无头集成（Next.XP 框架）的设置、开发和故障排除。涵盖 Enonic 适配器配置、内容类型到 React 组件映射、Guillotine GraphQL 数据获取、Content Studio 预览模式以及草稿/主分支切换。在构建由 Enonic XP 提供支持的 Next.js 前端、配置 Next.XP 适配器、将内容类型映射到组件、通过 Next.js 中的 Guillotine 获取 Enonic 内容或调试 Content Studio 预览时使用。请勿用于传统的服务器端 Enonic XP 渲染、不带 Next.js 的独立 Guillotine 查询、带 Enonic 的非 Next.js 前端框架或 React4XP 嵌入式渲染。
