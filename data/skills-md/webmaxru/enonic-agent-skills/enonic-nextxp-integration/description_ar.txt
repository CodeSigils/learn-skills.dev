يرشد الإعداد والتطوير واستكشاف الأخطاء وإصلاحها للتكامل بدون رأس Next.js وEnonic XP (إطار عمل Next.XP). يغطي تكوين محول Enonic، ونوع المحتوى لتخطيط مكونات React، وجلب بيانات Guillotine GraphQL، ووضع معاينة Content Studio، وتبديل الفرع الرئيسي/المسودة. يُستخدم عند إنشاء واجهة Next.js الأمامية المدعومة بـ Enonic XP، أو تكوين محول Next.XP، أو تعيين أنواع المحتوى إلى المكونات، أو جلب محتوى Enonic عبر Guillotine في Next.js، أو تصحيح أخطاء معاينة Content Studio. لا تستخدم لعرض Enonic XP التقليدي من جانب الخادم، أو استعلامات Guillotine المستقلة بدون Next.js، أو أطر عمل الواجهة الأمامية غير Next.js مع عرض Enonic، أو React4XP المضمن.
