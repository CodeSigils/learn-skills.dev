Guida alla configurazione, allo sviluppo e alla risoluzione dei problemi dell'integrazione headless di Next.js ed Enonic XP (framework Next.XP). Copre la configurazione dell'adattatore Enonic, la mappatura dei componenti dal tipo di contenuto a React, il recupero dei dati GraphQL di Guillotine, la modalità di anteprima di Content Studio e il passaggio al ramo bozza/master. Da utilizzare durante la creazione di un frontend Next.js basato su Enonic XP, la configurazione dell'adattatore Next.XP, la mappatura dei tipi di contenuto sui componenti, il recupero di contenuti Enonic tramite Guillotine in Next.js o il debug dell'anteprima di Content Studio. Non utilizzare per il tradizionale rendering Enonic XP lato server, query Guillotine autonome senza Next.js, framework frontend non Next.js con Enonic o rendering incorporato React4XP.
