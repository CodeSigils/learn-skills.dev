Развертывает коллекции навыков агентов из любого репозитория GitHub с папкой /skills на одной или нескольких поверхностях распространения: выпусках GitHub, торговой площадке Claude Code, торговой площадке подключаемых модулей VS Code и торговой площадке подключаемых модулей Copilot CLI. Выполняет предполетную проверку, обычный анализ фиксации, обмен версиями в конфигурациях поверхности и публикацию для конкретной поверхности с поддержкой пробного запуска. Используйте при выпуске, публикации или развертывании коллекции навыков на любой поддерживаемой торговой площадке или при создании выпуска GitHub для репозитория навыков. Не используйте для развертывания пакетов, не требующих навыков, модулей npm, образов Docker или ресурсов Azure.
