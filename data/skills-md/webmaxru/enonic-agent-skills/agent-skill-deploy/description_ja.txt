/skills フォルダーを持つ任意の GitHub リポジトリから、エージェント スキル コレクションを 1 つ以上のディストリビューション サーフェス (GitHub リリース、Claude Code マーケットプレイス、VS Code プラグイン マーケットプレイス、および Copilot CLI プラグイン マーケットプレイス) にデプロイします。プリフライト検証、従来のコミット分析、サーフェス構成全体でのバージョン バンピング、ドライラン サポートによるサーフェス固有の公開を処理します。サポートされているマーケットプレイスにスキル コレクションをリリース、公開、デプロイする場合、またはスキル リポジトリの GitHub リリースを作成する場合に使用します。非スキル パッケージ、npm モジュール、Docker イメージ、または Azure リソースのデプロイには使用しないでください。
