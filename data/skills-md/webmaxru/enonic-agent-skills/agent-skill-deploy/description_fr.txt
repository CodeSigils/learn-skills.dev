Déploie des collections de compétences d'agent à partir de n'importe quel référentiel GitHub avec un dossier /skills sur une ou plusieurs surfaces de distribution : versions GitHub, marché Claude Code, marché des plugins VS Code et marché des plugins Copilot CLI. Gère la validation avant vol, l'analyse de validation conventionnelle, le remplacement de versions dans les configurations de surface et la publication spécifique à la surface avec prise en charge de l'exécution à sec. À utiliser lors de la publication, de la publication ou du déploiement d'une collection de compétences sur n'importe quelle place de marché prise en charge ou lors de la création d'une version GitHub pour un référentiel de compétences. Ne pas utiliser pour déployer des packages sans compétences, des modules npm, des images Docker ou des ressources Azure.
