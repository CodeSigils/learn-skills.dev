Compone, esegue il debug e ottimizza le query Guillotine GraphQL per la distribuzione di contenuti headless di Enonic XP. Copre la costruzione di query, l'utilizzo delle variabili, il filtraggio, l'aggregazione, l'impaginazione, l'ordinamento e la generazione di tipi TypeScript dallo schema Guillotine generato automaticamente. Non utilizzare per definizioni XML di tipi di contenuto, API GraphQL non Enonic (Apollo, Hasura), query di contenuto lib lato server o distribuzione di Guillotine e configurazione CORS.
