إنشاء استعلامات Guillotine GraphQL وتصحيح أخطائها وتحسينها لتوصيل محتوى Enonic XP بدون رأس. يغطي بناء الاستعلام، والاستخدام المتغير، والتصفية، والتجميع، وترقيم الصفحات، والفرز، وإنشاء نوع TypeScript من مخطط Guillotine الذي تم إنشاؤه تلقائيًا. يُستخدم عند كتابة استعلامات Guillotine أو استكشاف أخطاءها وإصلاحها، أو الاستعلام عن أنواع المحتوى المخصصة من خلال GraphQL، أو إنشاء واجهات مكتوبة من استجابات Guillotine. لا تستخدم لتعريفات XML لنوع المحتوى، أو واجهات برمجة تطبيقات GraphQL غير Enonic (Apollo، Hasura)، أو استعلامات محتوى lib من جانب الخادم، أو نشر Guillotine وتكوين CORS.
