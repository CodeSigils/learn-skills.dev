Enonic XP 헤드리스 콘텐츠 전달을 위한 Guillotine GraphQL 쿼리를 작성, 디버그 및 최적화합니다. 자동 생성된 단두대 스키마에서 쿼리 구성, 변수 사용, 필터링, 집계, 페이지 매김, 정렬 및 TypeScript 유형 생성을 다룹니다. Guillotine 쿼리를 작성하거나 문제를 해결할 때, GraphQL을 통해 사용자 정의 콘텐츠 유형을 쿼리하거나 Guillotine 응답에서 형식화된 인터페이스를 생성할 때 사용합니다. 콘텐츠 유형 XML 정의, Enonic이 아닌 GraphQL API(Apollo, Hasura), 서버 측 lib 콘텐츠 쿼리 또는 Guillotine 배포 및 CORS 구성에는 사용하지 마세요.
