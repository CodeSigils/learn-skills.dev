Compose, débogue et optimise les requêtes Guillotine GraphQL pour la diffusion de contenu sans tête Enonic XP. Couvre la construction de requêtes, l'utilisation des variables, le filtrage, l'agrégation, la pagination, le tri et la génération de types TypeScript à partir du schéma Guillotine généré automatiquement. À utiliser lors de l'écriture ou du dépannage de requêtes Guillotine, de l'interrogation de types de contenu personnalisés via GraphQL ou de la génération d'interfaces typées à partir de réponses Guillotine. Ne pas utiliser pour les définitions XML de types de contenu, les API GraphQL non Enonic (Apollo, Hasura), les requêtes lib-content côté serveur ou le déploiement Guillotine et la configuration CORS.
