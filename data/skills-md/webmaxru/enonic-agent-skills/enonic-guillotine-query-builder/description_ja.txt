Enonic XP ヘッドレス コンテンツ配信用の Guillotine GraphQL クエリを作成、デバッグ、最適化します。クエリの構築、変数の使用法、フィルタリング、集計、ページネーション、並べ替え、自動生成された Guillotine スキーマからの TypeScript 型の生成について説明します。ギロチン クエリの作成またはトラブルシューティング、GraphQL を介したカスタム コンテンツ タイプのクエリ、またはギロチン応答からの型付きインターフェイスの生成を行うときに使用します。コンテンツ タイプ XML 定義、非 Enonic GraphQL API (Apollo、Hasura)、サーバー側の lib-content クエリ、Guillotine デプロイメントおよび CORS 構成には使用しないでください。
