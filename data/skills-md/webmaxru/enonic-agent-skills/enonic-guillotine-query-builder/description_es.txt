Redacta, depura y optimiza consultas Guillotine GraphQL para la entrega de contenido sin cabeza de Enonic XP. Cubre la construcción de consultas, el uso de variables, el filtrado, la agregación, la paginación, la clasificación y la generación de tipos TypeScript a partir del esquema Guillotine generado automáticamente. Úselo al escribir o solucionar problemas de consultas de Guillotine, consultar tipos de contenido personalizados a través de GraphQL o generar interfaces escritas a partir de respuestas de Guillotine. No lo use para definiciones XML de tipo de contenido, API GraphQL que no sean de Enonic (Apollo, Hasura), consultas de contenido de biblioteca del lado del servidor o implementación de Guillotine y configuración CORS.
