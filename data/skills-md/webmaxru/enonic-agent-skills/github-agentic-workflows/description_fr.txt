Crée, examine, installe et débogue les flux de travail agentiques GitHub dans les référentiels, y compris la démarque des flux de travail, les éléments de présentation, la compilation et l'exécution des flux, les sorties sécurisées, les garde-fous de sécurité et les modèles opérationnels. À utiliser lors de la création ou de la maintenance de l'automatisation GH-AW. Ne pas utiliser pour les actions GitHub déterministes standard YAML, les pipelines CI génériques ou les systèmes d'automatisation non GitHub.
