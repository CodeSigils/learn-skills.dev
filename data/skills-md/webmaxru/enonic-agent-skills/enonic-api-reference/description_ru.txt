Справочник по серверному API JavaScript/TypeScript Enonic XP для всех библиотек /lib/xp/*. Предоставляет сигнатуры функций, параметры, типы возвращаемых значений и примеры использования для lib-content, lib-node, lib-auth, lib-portal, lib-context, lib-event, lib-task, lib-repo, lib-io, lib-mail и lib-schema. Используйте при поиске функций библиотеки Enonic XP, форм параметров, типов возвращаемых значений или примеров использования. Не используйте для запросов Guillotine GraphQL, определений схем типов контента, команд Enonic CLI или API-интерфейсов JavaScript, отличных от Enonic.
