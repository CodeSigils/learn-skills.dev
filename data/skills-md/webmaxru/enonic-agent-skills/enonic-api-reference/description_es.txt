Referencia de la API JavaScript/TypeScript del lado del servidor de Enonic XP para todas las bibliotecas /lib/xp/*. Proporciona firmas de funciones, parámetros, tipos de retorno y ejemplos de uso para lib-content, lib-node, lib-auth, lib-portal, lib-context, lib-event, lib-task, lib-repo, lib-io, lib-mail y lib-schema. Utilícelo cuando busque funciones de la biblioteca de Enonic XP, formas de parámetros, tipos de retorno o ejemplos de uso. No lo utilice para consultas Guillotine GraphQL, definiciones de esquemas de tipo de contenido, comandos CLI de Enonic o API de JavaScript que no sean de Enonic.
