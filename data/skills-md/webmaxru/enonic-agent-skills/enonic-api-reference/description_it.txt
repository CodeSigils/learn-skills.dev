Riferimento API JavaScript/TypeScript lato server Enonic XP per tutte le librerie /lib/xp/*. Fornisce firme di funzioni, parametri, tipi restituiti ed esempi di utilizzo per lib-content, lib-node, lib-auth, lib-portal, lib-context, lib-event, lib-task, lib-repo, lib-io, lib-mail e lib-schema. Da utilizzare quando si cercano funzioni della libreria Enonic XP, forme di parametri, tipi restituiti o esempi di utilizzo. Non utilizzare per query GraphQL di Guillotine, definizioni di schemi di tipi di contenuto, comandi CLI Enonic o API JavaScript non Enonic.
