Référence de l'API JavaScript/TypeScript côté serveur Enonic XP pour toutes les bibliothèques /lib/xp/*. Fournit des signatures de fonction, des paramètres, des types de retour et des exemples d'utilisation pour lib-content, lib-node, lib-auth, lib-portal, lib-context, lib-event, lib-task, lib-repo, lib-io, lib-mail et lib-schema. À utiliser lors de la recherche de fonctions de la bibliothèque Enonic XP, de formes de paramètres, de types de retour ou d'exemples d'utilisation. Ne pas utiliser pour les requêtes Guillotine GraphQL, les définitions de schémas de types de contenu, les commandes CLI Enonic ou les API JavaScript non Enonic.
