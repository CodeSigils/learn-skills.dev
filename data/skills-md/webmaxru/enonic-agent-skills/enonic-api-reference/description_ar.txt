مرجع JavaScript/TypeScript API من جانب خادم Enonic XP لجميع مكتبات /lib/xp/*. يوفر توقيعات الوظائف والمعلمات وأنواع الإرجاع وأمثلة الاستخدام لمحتوى lib وعقدة lib وlib-auth وlib-portal وlib-context وlib-event وlib-task وlib-repo وlib-io وlib-mail وlib-schema. استخدمه عند البحث عن وظائف مكتبة Enonic XP، أو أشكال المعلمات، أو أنواع الإرجاع، أو أمثلة الاستخدام. لا تستخدمه لاستعلامات Guillotine GraphQL، أو تعريفات مخطط نوع المحتوى، أو أوامر Enonic CLI، أو واجهات برمجة تطبيقات JavaScript غير Enonic.
