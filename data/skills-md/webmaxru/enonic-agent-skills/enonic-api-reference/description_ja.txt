すべての /lib/xp/* ライブラリの Enonic XP サーバー側 JavaScript/TypeScript API リファレンス。 lib-content、lib-node、lib-auth、lib-portal、lib-context、lib-event、lib-task、lib-repo、lib-io、lib-mail、および lib-schema の関数シグネチャ、パラメーター、戻り値の型、および使用例を提供します。 Enonic XP ライブラリ関数、パラメータの形状、戻り値の型、または使用例を調べるときに使用します。 Guillotine GraphQL クエリ、コンテンツ タイプ スキーマ定義、Enonic CLI コマンド、または非 Enonic JavaScript API には使用しないでください。
