Configure les écouteurs d'événements Enonic XP, les configurations de webhooks et les intégrations de systèmes externes déclenchées par les événements du cycle de vie du contenu. Couvre l'enregistrement de l'écouteur d'événements lib, le filtrage des événements de nœud, la configuration des webhooks sortants via com.enonic.xp.webhooks.cfg, les contrôleurs de service HTTP personnalisés pour les webhooks entrants, le traitement asynchrone basé sur les tâches avec lib-task et les appels HTTP sortants avec lib-httpClient. À utiliser lors de l'écoute d'événements de publication/création/mise à jour/suppression de contenu, de la configuration de webhooks sortants, de la création de points de terminaison de service HTTP pour les webhooks entrants ou du déclenchement d'un traitement asynchrone sur les modifications de contenu. Ne pas utiliser pour les requêtes de contenu, le développement de composants frontaux, les systèmes d'événements non Enonic ou la configuration du webhook GitHub.
