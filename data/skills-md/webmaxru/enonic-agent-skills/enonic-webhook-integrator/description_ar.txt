يقوم بإعداد مستمعي أحداث Enonic XP، وتكوينات خطاف الويب، وعمليات تكامل النظام الخارجية التي يتم تشغيلها بواسطة أحداث دورة حياة المحتوى. يغطي تسجيل مستمع حدث lib، وتصفية حدث العقدة، وتكوين خطاف الويب الصادر عبر com.enonic.xp.webhooks.cfg، ووحدات تحكم خدمة HTTP المخصصة لخطافات الويب الواردة، والمعالجة غير المتزامنة القائمة على المهام باستخدام مهمة lib، ومكالمات HTTP الصادرة باستخدام lib-httpClient. يُستخدم عند الاستماع إلى أحداث نشر/إنشاء/تحديث/حذف المحتوى، أو تكوين خطافات الويب الصادرة، أو إنشاء نقاط نهاية خدمة HTTP لخطافات الويب الواردة، أو تشغيل المعالجة غير المتزامنة لتغييرات المحتوى. لا تستخدم للاستعلام عن المحتوى، أو تطوير مكونات الواجهة الأمامية، أو أنظمة الأحداث غير Enonic، أو تكوين GitHub webhook.
