Настраивает прослушиватели событий Enonic XP, конфигурации веб-перехватчиков и интеграцию с внешними системами, запускаемую событиями жизненного цикла контента. Охватывает регистрацию прослушивателя событий lib, фильтрацию событий узла, настройку исходящего веб-перехватчика через com.enonic.xp.webhooks.cfg, пользовательские контроллеры служб HTTP для входящих веб-перехватчиков, асинхронную обработку на основе задач с помощью lib-task и исходящие HTTP-вызовы с помощью lib-httpClient. Используйте при прослушивании событий публикации, создания, обновления или удаления контента, настройки исходящих веб-перехватчиков, создания конечных точек службы HTTP для входящих веб-перехватчиков или запуска асинхронной обработки при изменении контента. Не используйте для запросов контента, разработки интерфейсных компонентов, систем событий, отличных от Enonic, или настройки веб-перехватчика GitHub.
