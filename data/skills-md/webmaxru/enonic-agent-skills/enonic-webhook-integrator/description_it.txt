Configura ascoltatori di eventi Enonic XP, configurazioni webhook e integrazioni di sistemi esterni attivati ​​da eventi del ciclo di vita del contenuto. Copre la registrazione del listener lib-event, il filtraggio degli eventi del nodo, la configurazione del webhook in uscita tramite com.enonic.xp.webhooks.cfg, i controller del servizio HTTP personalizzati per i webhook in entrata, l'elaborazione asincrona basata su attività con lib-task e le chiamate HTTP in uscita con lib-httpClient. Da utilizzare durante l'ascolto di eventi di pubblicazione/creazione/aggiornamento/eliminazione di contenuti, la configurazione di webhook in uscita, la creazione di endpoint del servizio HTTP per webhook in entrata o l'attivazione dell'elaborazione asincrona sulle modifiche del contenuto. Non utilizzare per query di contenuti, sviluppo di componenti frontend, sistemi di eventi non Enonic o configurazione di webhook GitHub.
