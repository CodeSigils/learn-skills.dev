Configura detectores de eventos de Enonic XP, configuraciones de webhooks e integraciones de sistemas externos activadas por eventos del ciclo de vida del contenido. Cubre el registro del detector de eventos lib, el filtrado de eventos de nodos, la configuración de webhooks salientes a través de com.enonic.xp.webhooks.cfg, controladores de servicio HTTP personalizados para webhooks entrantes, procesamiento asíncrono basado en tareas con lib-task y llamadas HTTP salientes con lib-httpClient. Úselo cuando escuche eventos de publicación/creación/actualización/eliminación de contenido, configure webhooks salientes, cree puntos finales de servicio HTTP para webhooks entrantes o active el procesamiento asíncrono en cambios de contenido. No lo utilice para consultas de contenido, desarrollo de componentes frontend, sistemas de eventos que no sean Enonic o configuración de webhook de GitHub.
