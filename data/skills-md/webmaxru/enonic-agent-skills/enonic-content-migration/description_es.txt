Genera scripts de Enonic XP para operaciones de contenido masivo: creación, actualización, consulta, migración y transformación de contenido utilizando las API lib-content y lib-node. Cubre la consulta DSL (NoQL), agregaciones, procesamiento por lotes, controladores de tareas para operaciones de larga duración y flujos de trabajo de exportación/importación. Úselo al escribir scripts de creación, actualización o eliminación de contenido en masa, realizar consultas con sintaxis NoQL, migrar contenido entre entornos, ejecutar operaciones de tareas de larga duración o trabajar con agregaciones y recuperación paginada. No lo utilice para consultas de interfaz de Guillotine GraphQL, definiciones de esquemas de tipo de contenido, llamadas únicas a contentLib.get() o herramientas de migración de datos que no sean de Enonic.
