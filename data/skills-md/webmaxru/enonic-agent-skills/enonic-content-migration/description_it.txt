Genera script Enonic XP per operazioni di contenuto in blocco: creazione, aggiornamento, query, migrazione e trasformazione di contenuti utilizzando le API lib-content e lib-node. Copre query DSL (NoQL), aggregazioni, elaborazione batch, controller di attività per operazioni di lunga durata e flussi di lavoro di esportazione/importazione. Da utilizzare durante la scrittura di script per la creazione, l'aggiornamento o l'eliminazione di contenuti in blocco, l'esecuzione di query con la sintassi NoQL, la migrazione di contenuti tra ambienti, l'esecuzione di operazioni di attività di lunga durata o l'utilizzo di aggregazioni e recupero impaginato. Non utilizzare per query frontend GraphQL di Guillotine, definizioni di schemi di tipi di contenuto, chiamate singole contentLib.get() o strumenti di migrazione dei dati non Enonic.
