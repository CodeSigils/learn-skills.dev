يُنشئ برامج نصية Enonic XP لعمليات المحتوى المجمع - إنشاء المحتوى وتحديثه والاستعلام عنه وترحيله وتحويله باستخدام واجهات برمجة تطبيقات lib-content وlib-node. يغطي استعلام DSL (NoQL)، والتجميعات، ومعالجة الدُفعات، ووحدات التحكم بالمهام للعمليات طويلة الأمد، وسير عمل التصدير/الاستيراد. يُستخدم عند كتابة البرامج النصية لإنشاء محتوى مجمع أو تحديثه أو حذفه، أو الاستعلام باستخدام بناء جملة NoQL، أو ترحيل المحتوى بين البيئات، أو تشغيل عمليات المهام طويلة الأمد، أو العمل مع التجميعات والاسترداد المرقّم. لا تستخدمه لاستعلامات الواجهة الأمامية لـ Guillotine GraphQL، أو تعريفات مخطط نوع المحتوى، أو استدعاءات contentLib.get() الفردية، أو أدوات ترحيل البيانات غير التابعة لـ Enonic.
