Génère des scripts Enonic XP pour les opérations de contenu en masse : création, mise à jour, interrogation, migration et transformation de contenu à l'aide des API lib-content et lib-node. Couvre les requêtes DSL (NoQL), les agrégations, le traitement par lots, les contrôleurs de tâches pour les opérations de longue durée et les workflows d'exportation/importation. À utiliser lors de l'écriture de scripts de création, de mise à jour ou de suppression de contenu en masse, d'interrogations avec la syntaxe NoQL, de migration de contenu entre environnements, d'exécution d'opérations de tâches de longue durée ou d'utilisation d'agrégations et de récupération paginée. Ne pas utiliser pour les requêtes frontales Guillotine GraphQL, les définitions de schémas de types de contenu, les appels contentLib.get() uniques ou les outils de migration de données non Enonic.
