lib-content および lib-node API を使用したコンテンツの作成、更新、クエリ、移行、変換などの一括コンテンツ操作用の Enonic XP スクリプトを生成します。クエリ DSL (NoQL)、集計、バッチ処理、長時間実行操作用のタスク コントローラー、およびエクスポート/インポート ワークフローをカバーします。一括コンテンツの作成、更新、または削除スクリプトを作成する場合、NoQL 構文を使用したクエリを実行する場合、環境間でコンテンツを移行する場合、長時間実行されるタスク操作を実行する場合、または集計やページ分割された取得を使用する場合に使用します。 Guillotine GraphQL フロントエンド クエリ、コンテンツ タイプ スキーマ定義、単一の contentLib.get() 呼び出し、または Enonic 以外のデータ移行ツールには使用しないでください。
