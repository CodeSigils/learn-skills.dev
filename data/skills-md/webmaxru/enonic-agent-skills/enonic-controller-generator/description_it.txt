Genera file controller Enonic XP (TypeScript/JavaScript) e descrittori XML accoppiati per pagine, parti e layout. Copre le importazioni del portale lib, le esportazioni dei gestori HTTP, le definizioni delle regioni, il rendering di Thymeleaf/Mustache e i processori di risposta. Da utilizzare durante lo scaffolding di controller di pagina con regioni, controller di parte con accesso alla configurazione, controller di layout con supporto multiregione o processori di risposta per siti Enonic XP. Non utilizzare per schemi di tipi di contenuto, frontend Next.js/React headless, query GraphQL Guillotine o framework web non Enonic.
