Enonic XP コントローラ ファイル (TypeScript/JavaScript) と、ページ、パーツ、レイアウト用のペアの XML 記述子を生成します。 lib-portal インポート、HTTP ハンドラー エクスポート、領域定義、Thymeleaf/Mustache レンダリング、および応答プロセッサーについて説明します。リージョンを備えたページ コントローラー、構成アクセスを備えたパーツ コントローラー、マルチリージョン サポートを備えたレイアウト コントローラー、または Enonic XP サイトの応答プロセッサーをスキャフォールディングする場合に使用します。コンテンツ タイプ スキーマ、ヘッドレス Next.js/React フロントエンド、GraphQL ギロチン クエリ、または Enonic 以外の Web フレームワークには使用しないでください。
