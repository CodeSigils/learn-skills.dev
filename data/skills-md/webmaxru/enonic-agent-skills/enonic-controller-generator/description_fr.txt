Génère des fichiers de contrôleur Enonic XP (TypeScript/JavaScript) et des descripteurs XML appariés pour les pages, les parties et les mises en page. Couvre les importations du portail lib, les exportations du gestionnaire HTTP, les définitions de régions, le rendu Thymeleaf/Mustache et les processeurs de réponses. À utiliser lors de l'échafaudage de contrôleurs de page avec des régions, de contrôleurs de pièces avec accès à la configuration, de contrôleurs de mise en page avec prise en charge multi-régions ou de processeurs de réponse pour les sites Enonic XP. Ne pas utiliser pour les schémas de type de contenu, les interfaces Next.js/React sans tête, les requêtes GraphQL Guillotine ou les frameworks Web non Enonic.
