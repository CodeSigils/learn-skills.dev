يُنشئ ملفات وحدة تحكم Enonic XP (TypeScript/JavaScript) وواصفات XML المقترنة للصفحات والأجزاء والتخطيطات. يغطي عمليات استيراد بوابة lib، وصادرات معالج HTTP، وتعريفات المنطقة، وعرض Thymeleaf/Moustache، ومعالجات الاستجابة. يُستخدم عند دمج وحدات تحكم الصفحة مع المناطق، أو وحدات التحكم الجزئية مع الوصول إلى التكوين، أو وحدات التحكم في التخطيط مع دعم متعدد المناطق، أو معالجات الاستجابة لمواقع Enonic XP. لا تستخدم لمخططات نوع المحتوى، أو واجهات Next.js/React الأمامية، أو استعلامات GraphQL Guillotine، أو أطر عمل الويب غير Enonic.
