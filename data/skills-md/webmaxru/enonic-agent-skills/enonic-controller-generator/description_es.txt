Genera archivos de controlador Enonic XP (TypeScript/JavaScript) y descriptores XML emparejados para páginas, piezas y diseños. Cubre las importaciones del portal lib, las exportaciones de controladores HTTP, las definiciones de regiones, la representación de Thymeleaf/Mustache y los procesadores de respuesta. Úselo al crear controladores de página con regiones, controladores de piezas con acceso a configuración, controladores de diseño con soporte para múltiples regiones o procesadores de respuesta para sitios Enonic XP. No lo use para esquemas de tipo de contenido, interfaces sin cabeza Next.js/React, consultas GraphQL Guillotine o marcos web que no sean Enonic.
