Помогает разработчикам использовать команды Enonic CLI для управления песочницей, формирования проектов, локальной разработки, развертывания приложений и создания конвейера CI/CD. Используйте при создании песочниц Enonic XP, запуске или остановке локальных экземпляров, создании проектов с самого начала, запуске режима разработки с горячей перезагрузкой, развертывании приложений или создании рабочих процессов CI/CD для приложений Enonic. Не используйте для написания кода приложения XP (контроллеры, типы контента), выполнения запросов через API-интерфейсы Guillotine или lib-content, настройки сред, отличных от Enonic, или развертывания XP в Docker/Kubernetes.
