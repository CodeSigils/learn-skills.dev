Guía a los desarrolladores a través de los comandos CLI de Enonic para la gestión de sandbox, andamiaje de proyectos, desarrollo local, implementación de aplicaciones y generación de canales de CI/CD. Úselo al crear entornos limitados de Enonic XP, iniciar o detener instancias locales, desarrollar proyectos desde principiantes, ejecutar el modo de desarrollo con recarga en caliente, implementar aplicaciones o generar flujos de trabajo de CI/CD para aplicaciones de Enonic. No lo use para escribir código de aplicación XP (controladores, tipos de contenido), realizar consultas a través de Guillotine o API de contenido lib, configurar entornos que no sean Enonic o implementar Docker/Kubernetes de XP.
