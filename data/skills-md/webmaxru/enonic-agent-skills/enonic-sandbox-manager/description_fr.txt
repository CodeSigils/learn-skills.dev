Guide les développeurs à travers les commandes Enonic CLI pour la gestion du bac à sable, l'échafaudage de projet, le développement local, le déploiement d'applications et la génération de pipeline CI/CD. À utiliser lors de la création de bacs à sable Enonic XP, du démarrage ou de l'arrêt d'instances locales, de l'échafaudage de projets à partir de démarreurs, de l'exécution du mode développement avec rechargement à chaud, du déploiement d'applications ou de la génération de flux de travail CI/CD pour les applications Enonic. Ne pas utiliser pour l'écriture de code d'application XP (contrôleurs, types de contenu), les requêtes via les API Guillotine ou lib-content, la configuration d'environnements non Enonic ou le déploiement Docker/Kubernetes de XP.
