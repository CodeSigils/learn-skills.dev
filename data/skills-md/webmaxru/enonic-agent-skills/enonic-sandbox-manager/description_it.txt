Guida gli sviluppatori attraverso i comandi CLI di Enonic per la gestione sandbox, l'impalcatura dei progetti, lo sviluppo locale, la distribuzione delle app e la generazione di pipeline CI/CD. Da utilizzare durante la creazione di sandbox Enonic XP, l'avvio o l'arresto di istanze locali, lo scaffolding di progetti dall'inizio, l'esecuzione della modalità di sviluppo con ricarica a caldo, la distribuzione di app o la generazione di flussi di lavoro CI/CD per le app Enonic. Non utilizzare per scrivere codice dell'applicazione XP (controller, tipi di contenuto), eseguire query tramite Guillotine o API lib-content, configurare ambienti non Enonic o distribuire Docker/Kubernetes di XP.
