يرشد المطورين من خلال أوامر Enonic CLI لإدارة وضع الحماية، ودعم المشروع، والتطوير المحلي، ونشر التطبيق، وإنشاء خطوط أنابيب CI/CD. يُستخدم عند إنشاء صناديق حماية Enonic XP، أو بدء أو إيقاف المثيلات المحلية، أو دعم المشاريع من البداية، أو تشغيل وضع التطوير مع إعادة التحميل السريع، أو نشر التطبيقات، أو إنشاء مسارات عمل CI/CD لتطبيقات Enonic. لا تستخدم لكتابة كود تطبيق XP (وحدات التحكم، أنواع المحتوى)، أو الاستعلام عبر واجهات برمجة تطبيقات Guillotine أو lib-content، أو تكوين بيئات غير Enonic، أو نشر Docker/Kubernetes لنظام XP.
