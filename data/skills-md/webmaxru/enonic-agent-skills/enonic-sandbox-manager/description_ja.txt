サンドボックス管理、プロジェクト スキャフォールディング、ローカル開発、アプリのデプロイメント、CI/CD パイプライン生成のための Enonic CLI コマンドを開発者にガイドします。 Enonic XP サンドボックスの作成、ローカル インスタンスの開始または停止、スターターからのプロジェクトのスキャフォールディング、ホットリロードを使用した開発モードの実行、アプリのデプロイ、または Enonic アプリの CI/CD ワークフローの生成を行う場合に使用します。 XP アプリケーション コード (コントローラー、コンテンツ タイプ) の作成、Guillotine または lib-content API を介したクエリ、非 Enonic 環境の構成、または XP の Docker/Kubernetes デプロイメントには使用しないでください。
