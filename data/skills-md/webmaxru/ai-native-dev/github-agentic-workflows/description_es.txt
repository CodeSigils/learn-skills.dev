Crea, revisa, instala y depura flujos de trabajo de GitHub Agentic en repositorios, incluyendo rebajas de flujo de trabajo, frontmatter, flujos de compilación y ejecución de gh aw, salidas seguras, barreras de seguridad y patrones operativos. Utilícelo al crear o mantener la automatización GH-AW. No lo use para GitHub Actions YAML deterministas estándar, canalizaciones de CI genéricas o sistemas de automatización que no sean de GitHub.
