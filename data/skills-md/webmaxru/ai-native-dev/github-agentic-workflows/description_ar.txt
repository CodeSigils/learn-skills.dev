المؤلفون، والمراجعة، والتثبيت، وتصحيح مسارات عمل GitHub Agentic في المستودعات، بما في ذلك تخفيض سير العمل، والأمر الأمامي، وتدفقات التجميع والتشغيل، والمخرجات الآمنة، وحواجز الحماية الأمنية، والأنماط التشغيلية. يُستخدم عند إنشاء أتمتة GH-AW أو صيانتها. لا تستخدمه مع إجراءات GitHub الحتمية القياسية YAML، أو خطوط أنابيب CI العامة، أو أنظمة التشغيل الآلي غير التابعة لـ GitHub.
