Stellt Agenten-Skill-Sammlungen aus jedem GitHub-Repository mit einem /skills-Ordner auf einer oder mehreren Verteilungsoberflächen bereit: GitHub-Releases, Claude Code-Marktplatz, VS Code-Plugin-Marktplatz und Copilot CLI-Plugin-Marktplatz. Bewältigt die Preflight-Validierung, die herkömmliche Commit-Analyse, den Versionswechsel zwischen Oberflächenkonfigurationen und die oberflächenspezifische Veröffentlichung mit Trockenlaufunterstützung. Verwenden Sie diese Option, wenn Sie eine Skills-Sammlung auf einem unterstützten Marktplatz veröffentlichen, veröffentlichen oder bereitstellen oder eine GitHub-Version für ein Skills-Repository erstellen. Nicht für die Bereitstellung von Non-Skill-Paketen, NPM-Modulen, Docker-Images oder Azure-Ressourcen verwenden.
