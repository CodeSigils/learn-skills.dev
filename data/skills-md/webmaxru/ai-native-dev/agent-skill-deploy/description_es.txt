Implementa colecciones de habilidades de agentes desde cualquier repositorio de GitHub con una carpeta /skills en una o más superficies de distribución: versiones de GitHub, mercado de Claude Code, mercado de complementos de VS Code y mercado de complementos de Copilot CLI. Maneja la validación previa al vuelo, el análisis de confirmación convencional, la modificación de versiones en configuraciones de superficie y la publicación de superficies específicas con soporte de ejecución en seco. Úselo al lanzar, publicar o implementar una colección de habilidades en cualquier mercado compatible o al crear una versión de GitHub para un repositorio de habilidades. No lo use para implementar paquetes que no sean de habilidades, módulos npm, imágenes de Docker o recursos de Azure.
