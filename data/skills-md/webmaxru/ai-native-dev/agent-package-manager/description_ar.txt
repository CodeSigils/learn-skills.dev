يقوم بتثبيت وتكوين وتدقيق وتشغيل Agent Package Manager (APM) في المستودعات. يُستخدم عند تهيئة apm.yml، أو تثبيت الحزم أو تحديثها، أو التحقق من صحة البيانات، أو إدارة ملفات القفل، أو تجميع سياق الوكيل، أو تصفح خوادم MCP، أو إعداد أوقات التشغيل، أو تعبئة السياق الذي تم حله لـ CI وتوزيع الفريق. لا تستخدم لكتابة مهارة واحدة يدويًا، أو مديري الحزم العامة مثل npm أو pip، أو أنظمة تكوين وكيل غير APM.
