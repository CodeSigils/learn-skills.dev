Этот навык следует использовать при работе с API Apple, разработке iOS/macOS/visionOS или вопросах языка Swift. Охватывает поиск в документации разработчиков Apple, просмотр представлений SwiftUI, поиск API-интерфейсов UIKit, чтение документации Apple, просмотр предложений Swift Evolution, проверку рекомендаций по пользовательскому интерфейсу и изучение примера кода Apple. Поддерживает более 300 фреймворков, включая SwiftUI, UIKit, Foundation и Joint, посредством автономного поиска по более чем 300 000 страницам документации.
