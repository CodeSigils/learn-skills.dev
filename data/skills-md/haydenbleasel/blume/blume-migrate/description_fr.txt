Migrez un site de documentation existant (Mintlify, Docusaurus, Fumadocs, Nextra, Starlight ou tout autre framework de documentation) vers Blume, le framework de documentation markdown first sur Astro. Traduisez la configuration source en blume.config.ts, restructurez le contenu dans la navigation dérivée du système de fichiers de Blume, réécrivez les légendes JSX en directives, convertissez les icônes en Lucide et les extraits de code en ligne. À utiliser lorsque l'utilisateur demande de migrer/convertir/porter un dépôt de documents vers Blume, ou lorsque le dépôt a un docs.json/mint.json, docusaurus.config.*, meta.json avec fumadocs, _meta.* avec nextra ou un astro.config.* avec starlight().
