Синхронизируйте сайт документации Blume с продуктом, который на нем документируется. Проверяйте недавно объединенные запросы на включение, журналы изменений, схемы конфигурации, справку CLI и общедоступные API на соответствие содержимому документации, обновляйте только те страницы, которые фактически устарели, проверяйте сборку документации и открывайте (или обновляйте) запрос на извлечение на обслуживание — или сообщайте об отсутствии операций. Используйте, когда вас просят проверить документацию на предмет отклонений, обновить устаревшую документацию, запустить запланированный аудит документации или поддерживать актуальность документации после выпуска.
