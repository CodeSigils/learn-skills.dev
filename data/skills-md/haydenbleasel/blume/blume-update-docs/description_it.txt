Mantieni un sito di documenti Blume sincronizzato con il prodotto che documenta. Controlla le richieste pull recentemente unite, i log delle modifiche, gli schemi di configurazione, la guida della CLI e le API pubbliche rispetto al contenuto dei documenti, aggiorna solo le pagine che sono effettivamente obsolete, verifica la build dei documenti e apri (o aggiorna) una richiesta pull di manutenzione o segnala una mancata operazione pulita. Da utilizzare quando viene richiesto di controllare la deriva dei documenti, aggiornare la documentazione obsoleta, eseguire un controllo pianificato dei documenti o mantenere aggiornati i documenti dopo un rilascio.
