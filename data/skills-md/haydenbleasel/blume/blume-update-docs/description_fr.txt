Gardez un site de documentation Blume synchronisé avec le produit qu'il documente. Auditez les demandes d'extraction récemment fusionnées, les journaux de modifications, les schémas de configuration, l'aide CLI et les API publiques par rapport au contenu de la documentation, mettez à jour uniquement les pages qui sont factuellement obsolètes, vérifiez la construction de la documentation et ouvrez (ou mettez à jour) une demande d'extraction de maintenance - ou signalez une non-opération propre. À utiliser lorsqu'on vous demande de vérifier les dérives des documents, d'actualiser la documentation obsolète, d'exécuter un audit de documents planifié ou de maintenir les documents à jour après une version.
