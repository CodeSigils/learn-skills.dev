Halten Sie eine Blume-Dokumentenseite mit dem darin dokumentierten Produkt synchron. Überprüfen Sie kürzlich zusammengeführte Pull-Requests, Änderungsprotokolle, Konfigurationsschemata, CLI-Hilfe und öffentliche APIs anhand des Dokumentinhalts, aktualisieren Sie nur Seiten, die faktisch veraltet sind, überprüfen Sie den Build des Dokuments und öffnen (oder aktualisieren) Sie einen Wartungs-Pull-Request – oder melden Sie einen sauberen No-Op. Verwenden Sie diese Option, wenn Sie aufgefordert werden, Dokumente auf Abweichungen zu überprüfen, veraltete Dokumentation zu aktualisieren, eine geplante Dokumentenprüfung durchzuführen oder Dokumente nach einer Veröffentlichung auf dem neuesten Stand zu halten.
