Use files-sdk to add file storage to a TypeScript/JavaScript app with a unified API across S3, R2, GCS, Azure, Vercel Blob, the local filesystem, and ~40 other providers. Triggers when the user wants to upload/download/list/delete files, generate presigned URLs, swap storage providers, expose storage to an AI agent (Vercel AI SDK, OpenAI Responses/Agents, Claude Agent SDK), or asks about "files-sdk", "Files SDK", `new Files(...)`, `files.upload`, `files.url`, `files.signedUploadUrl`, or any `files-sdk/<adapter>` subpath import.
