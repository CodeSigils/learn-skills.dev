Utilizza files-sdk per aggiungere spazio di archiviazione file a un'app TypeScript/JavaScript con un'API unificata su S3, R2, GCS, Azure, Vercel Blob, il file system locale e circa 40 altri provider. Si attiva quando l'utente desidera caricare/scaricare/elencare/eliminare file, generare URL prefirmati, scambiare provider di archiviazione, esporre l'archiviazione a un agente AI (Vercel AI SDK, OpenAI Responses/Agents, Claude Agent SDK) o chiede informazioni su "files-sdk", "Files SDK", `new Files(...)`, `files.upload`, `files.url`, `files.signedUploadUrl` o qualsiasi Importazione del sottopercorso `files-sdk/<adapter>`.
