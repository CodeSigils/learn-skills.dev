Utilisez files-sdk pour ajouter un stockage de fichiers à une application TypeScript/JavaScript avec une API unifiée sur S3, R2, GCS, Azure, Vercel Blob, le système de fichiers local et environ 40 autres fournisseurs. Se déclenche lorsque l'utilisateur souhaite télécharger/télécharger/lister/supprimer des fichiers, générer des URL présignées, échanger des fournisseurs de stockage, exposer le stockage à un agent IA (Vercel AI SDK, OpenAI Responses/Agents, Claude Agent SDK), ou pose des questions sur "files-sdk", "Files SDK", `new Files(...)`, `files.upload`, `files.url`, `files.signedUploadUrl` ou toute importation de sous-chemin `files-sdk/<adapter>`.
