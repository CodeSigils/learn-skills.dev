Utilice files-sdk para agregar almacenamiento de archivos a una aplicación TypeScript/JavaScript con una API unificada en S3, R2, GCS, Azure, Vercel Blob, el sistema de archivos local y ~40 proveedores más. Se activa cuando el usuario desea cargar/descargar/enumerar/eliminar archivos, generar URL prefirmadas, intercambiar proveedores de almacenamiento, exponer el almacenamiento a un agente de IA (Vercel AI SDK, OpenAI Responses/Agents, Claude Agent SDK) o pregunta sobre "files-sdk", "Files SDK", `new Files(...)`, `files.upload`, `files.url`, `files.signedUploadUrl`, o cualquier `files-sdk/<adapter>` importación de subruta.
