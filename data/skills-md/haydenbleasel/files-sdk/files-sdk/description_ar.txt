استخدم files-sdk لإضافة تخزين الملفات إلى تطبيق TypeScript/JavaScript باستخدام واجهة برمجة تطبيقات موحدة عبر S3 وR2 وGCS وAzure وVercel Blob ونظام الملفات المحلي وحوالي 40 موفرًا آخر. يتم تشغيله عندما يريد المستخدم تحميل/تنزيل/سرد/حذف الملفات، أو إنشاء عناوين URL الموقعة مسبقًا، أو تبديل موفري التخزين، أو كشف التخزين لوكيل AI (Vercel AI SDK، أو OpenAI Responses/Agents، أو Claude Agent SDK)، أو يسأل عن "files-sdk"، أو "Files SDK"، أو "new Files(...)"، أو "files.upload"، أو "files.url"، أو `files.signedUploadUrl`، أو أي استيراد للمسار الفرعي `files-sdk/<adapter>`.
