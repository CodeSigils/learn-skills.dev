files-sdk を使用すると、S3、R2、GCS、Azure、Vercel Blob、ローカル ファイル システム、およびその他約 40 のプロバイダーにわたる統合 API を使用して、TypeScript/JavaScript アプリにファイル ストレージを追加できます。ユーザーがファイルのアップロード/ダウンロード/リスト/削除、署名付き URL の生成、ストレージ プロバイダーの交換、AI エージェント (Vercel AI SDK、OpenAI Responses/Agents、Claude Agent SDK) へのストレージの公開を希望する場合、または「files-sdk」、「Files SDK」、「new Files(...)」、「files.upload」、「files.url」、 `files.signedUploadUrl`、または任意の `files-sdk/<adapter>` サブパスのインポート。
