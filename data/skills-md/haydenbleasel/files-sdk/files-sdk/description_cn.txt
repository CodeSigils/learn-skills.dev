使用 files-sdk 通过跨 S3、R2、GCS、Azure、Vercel Blob、本地文件系统和约 40 个其他提供商的统一 API 将文件存储添加到 TypeScript/JavaScript 应用程序。当用户想要上传/下载/列出/删除文件、生成预签名 URL、交换存储提供程序、向 AI 代理（Vercel AI SDK、OpenAI Responses/Agents、Claude Agent SDK）公开存储，或询问“files-sdk”、“Files SDK”、“new Files(...)”、“files.upload”、“files.url”、“files.signedUploadUrl”或任何内容时触发`files-sdk/<adapter>` 子路径导入。
