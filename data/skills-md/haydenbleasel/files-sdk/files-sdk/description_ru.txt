Используйте files-sdk, чтобы добавить хранилище файлов в приложение TypeScript/JavaScript с унифицированным API для S3, R2, GCS, Azure, Vercel Blob, локальной файловой системы и примерно 40 других поставщиков. Срабатывает, когда пользователь хочет загрузить/загрузить/перечислить/удалить файлы, сгенерировать предварительно назначенные URL-адреса, поменять поставщиков хранилищ, предоставить хранилище агенту AI (Vercel AI SDK, OpenAI Responses/Agents, Claude Agent SDK) или спросить о "files-sdk", "Files SDK", `new Files(...)`, `files.upload`, `files.url`, `files.signedUploadUrl` или любой импорт подпути `files-sdk/<adapter>`.
