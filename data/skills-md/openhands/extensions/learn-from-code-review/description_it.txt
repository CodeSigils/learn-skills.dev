Trasforma il feedback sulla revisione del codice dei PR di GitHub in competenze e linee guida riutilizzabili. Questa competenza dovrebbe essere utilizzata quando gli utenti chiedono di "imparare dalle revisioni del codice", "distillare feedback delle pubbliche relazioni", "migliorare gli standard di codifica", "estrarre insegnamenti dalle revisioni" o desiderano generare competenze/linee guida dai commenti delle revisioni storiche.
