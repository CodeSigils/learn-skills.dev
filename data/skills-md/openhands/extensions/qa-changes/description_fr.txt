Cette compétence doit être utilisée lorsque l'utilisateur demande « QA a pull request », « tester les modifications PR », « vérifier qu'un PR fonctionne », « tester fonctionnellement les modifications » ou lorsqu'un flux de travail automatisé déclenche la validation QA des modifications de code. Fournit une méthodologie structurée pour configurer l’environnement, exercer un changement de comportement et rendre compte des résultats.
