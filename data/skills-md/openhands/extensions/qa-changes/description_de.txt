Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „eine Pull-Anfrage einer Qualitätssicherung unterziehen“, „PR-Änderungen testen“, „die Funktionsfähigkeit einer PR überprüfen“, „Änderungen funktional testen“ möchte oder wenn ein automatisierter Workflow eine QA-Validierung von Codeänderungen auslöst. Bietet eine strukturierte Methodik zum Einrichten der Umgebung, zum Üben geänderten Verhaltens und zum Melden von Ergebnissen.
