Vereinfacht und verfeinert den Code für Klarheit, Konsistenz und Wartbarkeit unter Beibehaltung aller Funktionen. Analysiert kürzlich geänderten Code in drei Dimensionen – Code-Wiederverwendung, Code-Qualität und Effizienz – und liefert umsetzbare Verbesserungsvorschläge. Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „Code vereinfachen“, „Code verfeinern“, „Code bereinigen“, „Codequalität verbessern“ oder eine Vereinfachungsüberprüfung der letzten Änderungen anfordert.
