Simplifie et affine le code pour plus de clarté, de cohérence et de maintenabilité tout en préservant toutes les fonctionnalités. Analyse le code récemment modifié selon trois dimensions : réutilisation du code, qualité du code et efficacité, et fournit des suggestions d'amélioration concrètes. Cette compétence doit être utilisée lorsque l'utilisateur demande de « simplifier le code », « d'affiner le code », de « nettoyer le code », « d'améliorer la qualité du code » ou demande une révision de simplification des modifications récentes.
