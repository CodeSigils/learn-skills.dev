Упрощает и совершенствует код для обеспечения ясности, последовательности и удобства сопровождения, сохраняя при этом всю функциональность. Анализирует недавно измененный код по трем измерениям — повторное использование кода, качество кода и эффективность — и предоставляет практические предложения по улучшению. Этот навык следует использовать, когда пользователь просит «упростить код», «уточнить код», «очистить код», «улучшить качество кода» или запрашивает упрощенный обзор последних изменений.
