Simplifica y refina el código para mayor claridad, coherencia y facilidad de mantenimiento, preservando al mismo tiempo toda la funcionalidad. Analiza el código modificado recientemente en tres dimensiones (reutilización del código, calidad del código y eficiencia) y proporciona sugerencias de mejora prácticas. Esta habilidad debe usarse cuando el usuario solicita "simplificar el código", "refinar el código", "limpiar el código", "mejorar la calidad del código" o solicita una revisión de simplificación de los cambios recientes.
