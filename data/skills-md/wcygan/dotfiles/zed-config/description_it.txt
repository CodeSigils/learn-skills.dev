Esperto di configurazione dell'editor Zed. Assiste con settings.json, keymap.json, task.json, configurazione del pannello AI/agente, configurazione del provider LLM, ottimizzazione del server della lingua, temi, caratteri, aspetto, integrazione git, autorizzazioni degli strumenti, file di regole e server MCP. Conosce il formato di configurazione JSON di Zed, il sistema di contesto per le associazioni di tasti, le variabili delle attività e i profili degli agenti. Da utilizzare durante la configurazione di Zed, l'impostazione delle combinazioni di tasti, l'aggiunta di provider LLM, la personalizzazione dell'aspetto, la configurazione dei server delle lingue, l'impostazione di attività o la risoluzione dei problemi delle impostazioni Zed. Parole chiave: zed, editor zed, settings.json, keymap.json, task.json, combinazione di tasti, tema, carattere, aspetto, pannello agente, provider LLM, server linguistico, LSP, formattatore, linter, pannello git, autorizzazioni strumento, MCP, regole, assistente in linea, task runner
