مساعدة النظام الأساسي لـ Yesware - تتبع البريد الإلكتروني، والحملات، والقوالب، وProspector، وجدولة الاجتماعات، وتكامل Salesforce، وإعداد التقارير. يُستخدم عند السؤال "كيف أفعل X في Yesware"، أو تكوين إعدادات Yesware، أو إعداد الحملات، أو إدارة القوالب، أو استخدام Prospector، أو تكوين برنامج جدولة الاجتماعات، أو الاتصال بـ Salesforce. لا تستخدم لبناء قوائم العملاء المحتملين (استخدام / قائمة عملاء محتملين)، أو إثراء جهات الاتصال (استخدام / إثراء المبيعات)، أو تصميم إستراتيجية الإيقاع (استخدام / إيقاع المبيعات)، أو إمكانية التسليم عبر الأنظمة الأساسية (استخدام / إمكانية تسليم المبيعات)، أو استراتيجية جدولة الاجتماعات (استخدام / جدولة اجتماعات المبيعات)، أو استراتيجية تتبع البريد الإلكتروني (استخدام / تتبع المبيعات عبر البريد الإلكتروني).
