تسليم المعاملات والبريد الإلكتروني المُفعَّل - تأكيدات الطلب، وإعادة تعيين كلمة المرور، ورسائل البريد الإلكتروني الترحيبية، والإيصالات، وإشعارات الشحن، وتنبيهات الحساب. يغطي اختيار الموفر، وتصميم القالب، وإمكانية التسليم، وتكامل واجهة برمجة التطبيقات، وترحيل SMTP، والمراقبة عبر SendGrid، وPostmark، وMailgun، وBrevo، وBraze، وIterable، وCustomer.io، وMailchimp/Mandrill، وGetResponse (MAX فقط)، وAmazon SES. يُستخدم عند إنشاء تدفقات البريد الإلكتروني للمعاملات، أو اختيار موفر البريد الإلكتروني للمعاملات، أو تصحيح مشكلات التسليم لرسائل البريد الإلكتروني التي يتم تشغيلها، أو إعداد ترحيل SMTP. لا تستخدمه في حملات البريد الإلكتروني التسويقية (الاستخدام / المبيعات والتسويق عبر البريد الإلكتروني)، أو التسلسلات الصادرة الباردة (الاستخدام / إيقاع المبيعات)، أو استراتيجية التسليم عبر الأنظمة الأساسية (الاستخدام / قابلية تسليم المبيعات)، أو الأسئلة الخاصة بـ SendPulse (استخدم / المبيعات - إرسال النبض). للحصول على مساعدة خاصة بالمنصة، استخدم /sales-braze، أو /sales-iterable، أو /sales-sendgrid، أو /sales-postmark، أو /sales-mailgun، أو /sales-brevo، أو /sales-customerio، أو /sales-mailchimp، أو /sales-getresponse، أو /sales-sendpulse.
