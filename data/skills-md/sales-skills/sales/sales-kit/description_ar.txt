مساعدة النظام الأساسي Kit (المعروف سابقًا باسم ConvertKit) — التسويق عبر البريد الإلكتروني، والأتمتة المرئية، والتسلسلات، والصفحات المقصودة، والنماذج، والملف الشخصي لمنشئ المحتوى، والتجارة (المنتجات الرقمية، والنشرات الإخبارية المدفوعة)، وتوصيات منشئي المحتوى، ووضع علامات على المشتركين وتقسيمهم، ونقاط المشاركة، وواجهة برمجة التطبيقات (API). استخدمه عند السؤال "كيف أفعل X في Kit"، أو "كيف أفعل X في ConvertKit"، أو تكوين إعدادات Kit، أو إعداد عمليات التشغيل الآلي، أو إدارة المشتركين، أو بيع المنتجات الرقمية، أو استخدام Kit API. لا تستخدم لاستراتيجية التسويق عبر البريد الإلكتروني عبر الأنظمة الأساسية (الاستخدام / المبيعات والتسويق عبر البريد الإلكتروني)، وإمكانية التسليم عبر الأنظمة الأساسية (الاستخدام / قابلية تسليم المبيعات)، واستراتيجية التحويل (الاستخدام / مسار المبيعات)، واستراتيجية تحقيق الدخل من الرسائل الإخبارية (الاستخدام / المبيعات - النشرة الإخبارية)، واستراتيجية نمو الجمهور (الاستخدام / نمو جمهور المبيعات)، أو استراتيجية المنتجات الرقمية (الاستخدام / مبيعات المنتجات الرقمية).
