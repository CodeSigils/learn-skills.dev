RudderStack プラットフォームのヘルプ — ウェアハウスネイティブの CDP、イベント ストリーム、リバース ETL、変換、プロファイル、200 以上の宛先、オープンソース。 RudderStack SDK または HTTP API をセットアップする場合、イベントが宛先に到達しない場合、リバース ETL 同期が失敗するか古いデータが返される場合、変換でエラーがスローされるかイベントが削除される場合、訪問者プロファイルがチャネル間でマージされない場合、RudderStack とセグメントのどちらかを選択する場合、または RudderStack API を使用する場合に使用します。一般的な CDP 比較 (/sales-cdp を使用) や、RudderStack を使用しない CRM データの重複除去 (/sales-data-hygiene を使用) には使用しないでください。
