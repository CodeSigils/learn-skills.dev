Cartographie le comité d'achat d'un compte cible : identifiez les décideurs, les influenceurs, les champions et les bloqueurs, puis recommandez une stratégie multithread. À utiliser pour cartographier les parties prenantes d'une transaction, trouver le bon point d'entrée sur un compte cible, multithreader une transaction d'entreprise, comprendre qui est impliqué dans une décision d'achat ou planifier la pénétration d'un compte. Ne pas utiliser pour créer des listes de prospects sur de nombreux comptes (utilisez /sales-prospect-list), pour la recherche générale de comptes (utilisez /sales-research), pour l'évaluation de la santé des transactions (utilisez /sales-deal-inspect) ou pour la configuration d'organigramme spécifique à ZoomInfo (utilisez /sales-zoominfo).
