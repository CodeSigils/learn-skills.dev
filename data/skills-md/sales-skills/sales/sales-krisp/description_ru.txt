Помощь по платформе Krisp — шумоподавление, заметки о встречах с использованием искусственного интеллекта, преобразование акцента, SDK Voice AI, искусственный интеллект колл-центра. Используйте при настройке шумоподавления Krisp для вызовов, настройке транскрипции или сводок совещаний Krisp AI, устранении неполадок приложения Krisp или высокой загрузки ЦП, интеграции веб-перехватчиков Krisp с CRM или Slack, создании с помощью Krisp Voice AI SDK для фильтрации шума или выборе между планами Krisp для команды. НЕ используйте для выбора между ИИ-секретарями для заметок разных поставщиков (используйте /sales-note-taker) или для просмотра звонка на коучинг (используйте /sales-call-review).
