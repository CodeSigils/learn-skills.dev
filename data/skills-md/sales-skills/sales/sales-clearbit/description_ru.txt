Справка по платформе Clearbit (HubSpot) — расширение личности, расширение компании, раскрытие (IP-адрес компании), Prospector, имя в домен, сокращение формы, API рисков, Breeze Intelligence, API и интеграция. Используйте, когда спрашиваете: «Как мне расширить лиды с помощью Clearbit», «Clearbit API», «Clearbit Reveal», «Clearbit Prospector», «Breeze Intelligence», «Сокращение формы Clearbit», «Clearbit HubSpot». НЕ используйте для стратегии обогащения инструментов (используйте /sales-enrich), стратегии идентификации намерений/посетителей (используйте /sales-intent), создания списков потенциальных клиентов с помощью инструментов (используйте /sales-prospect-list) или стратегии оценки потенциальных клиентов (используйте /sales-lead-score).
