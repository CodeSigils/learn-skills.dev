Помощь по платформе RB2B — идентификатор посетителя веб-сайта на уровне человека, идентификатор уровня компании, горячие страницы, горячие лиды, статистика трафика, API разрешения идентификационных данных, интеграция. Используйте, когда спрашиваете: «Как идентифицировать посетителей веб-сайта с помощью RB2B», «Пиксель RB2B», «RB2B API», «RB2B против Clearbit Reveal», «идентификация посетителей на уровне человека», «Горячие страницы RB2B». НЕ используйте для стратегии идентификации посетителей с помощью инструментов (используйте /sales-intent), стратегии обогащения с помощью инструментов (используйте /sales-enrich), создания списков потенциальных клиентов с помощью инструментов (используйте /sales-prospect-list) или стратегии оценки потенциальных клиентов (используйте /sales-lead-score).
