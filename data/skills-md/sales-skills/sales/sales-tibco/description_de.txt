Hilfe zur TIBCO Cloud Integration-Plattform – Unternehmens-iPaaS, das TIBCO Scribe (Connect), Flogo (Develop), BusinessWorks (Integrate), Cloud Live Apps (Automate), Cloud API Management, App-Instance-Abonnementstufen, REST API v1, hybride On-Prem- und Cloud-Bereitstellungen kombiniert. Wird verwendet, wenn ein TIBCO Flogo REST-Trigger fehlschlägt oder ein Feld falsch zuordnet, die TIBCO Scribe-Replikation den gesamten Verlauf ohne Filter abruft, ein Scribe-Job ein Ausführungs-Timeout oder Fehler bei der Schlüsselduplikatur aufweist, der BusinessWorks-Hybrid-Agent keine Verbindung zur TIBCO Cloud herstellt, das Limit von 5 oder 15 App-Instanzen im Basic/Premium-Plan erreicht, TIBCO vs. Boomi vs. MuleSoft vs. Informatica evaluiert oder von einer lokalen Umgebung migriert TIBCO BusinessWorks zu TCI.
