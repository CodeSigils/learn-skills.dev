مساعدة منصة TIBCO Cloud Integration - iPaaS للمؤسسات التي تجمع بين TIBCO Scribe (Connect)، وFlogo (Develop)، وBusinessWorks (Integrate)، وCloud Live Apps (Automate)، وإدارة Cloud API، وطبقات الاشتراك في مثيل التطبيق، وREST API v1، وعمليات النشر السحابية المحلية + المختلطة. يُستخدم عندما يفشل مشغل TIBCO Flogo REST أو يرسم حقلاً بشكل خاطئ، أو يقوم النسخ المتماثل لـ TIBCO Scribe بسحب كل المحفوظات بدون مرشح، أو تؤدي مهمة Scribe إلى انتهاء مهلة التنفيذ أو أخطاء المفتاح المكررة، أو لن يتصل وكيل BusinessWorks المختلط بـ TIBCO Cloud، أو يصل إلى الحد الأقصى لمثيلات التطبيق البالغ 5 أو 15 على الخطة الأساسية/المميزة، أو تقييم TIBCO vs Boomi vs MuleSoft vs Informatica، أو الترحيل من TIBCO BusinessWorks المحلية إلى TCI. لا تستخدمه مع Zapier/Make Automation البسيط (استخدم / تكامل المبيعات) أو الأسئلة الخاصة بـ Informatica (استخدم /sales-informatica).
