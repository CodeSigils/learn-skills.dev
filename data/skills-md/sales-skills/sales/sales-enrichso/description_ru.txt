Справка по платформе Enrich.so — API для обогащения данных B2B в режиме реального времени с более чем 50 точками данных за каждый поиск и выставлением счетов на основе успеха. Ключевые возможности: обратный поиск по электронной почте, пополнение профиля LinkedIn, поиск электронной почты/телефона, данные компании, поиск похожих компаний, поиск сотрудников, IP-адрес компании и массовое пополнение. Используйте при дополнении контактов по электронной почте или URL-адресу LinkedIn, поиске электронных писем/телефонов по имени + компании, поиске данных компании, массовом дополнении или работе с API Enrich.so. НЕ используйте для стратегии кросс-платформенного обогащения (используйте /sales-enrich), стратегии доставки электронной почты (используйте /sales-deliverability) или стратегии списка потенциальных клиентов (используйте /sales-prospect-list).
