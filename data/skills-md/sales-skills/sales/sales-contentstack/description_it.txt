Guida della piattaforma Contentstack: CMS headless, API di gestione dei contenuti, API di distribuzione dei contenuti, GraphQL, avvio di hosting, automatizzazione dei flussi di lavoro, personalizzazione, Brand Kit AI, Knowledge Vault, app del Marketplace, SDK. Da utilizzare quando i tipi di contenuto non vengono pubblicati correttamente, le voci non vengono visualizzate sul frontend, le chiamate API restituiscono errori, i webhook non si attivano, il flusso di lavoro di localizzazione è confuso, la migrazione da un CMS tradizionale è complessa o il generatore di anteprime/visual builder non funziona. NON utilizzare per l'e-mail marketing generale (uso /sales-email-marketing) o sequenze di vendite in uscita (uso /sales-cadenza).
