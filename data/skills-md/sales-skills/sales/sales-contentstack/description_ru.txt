Справка по платформе Contentstack — автономная CMS, API управления контентом, API доставки контента, GraphQL, хостинг для запуска, автоматизация рабочих процессов, персонализация, Brand Kit AI, Knowledge Vault, приложения Marketplace, SDK. Используйте его, когда типы контента публикуются неправильно, записи не отображаются во внешнем интерфейсе, вызовы API возвращают ошибки, веб-перехватчики не срабатывают, рабочий процесс локализации сбивает с толку, миграция с традиционной CMS сложна или предварительный просмотр или визуальный конструктор не работают. НЕ используйте для общего маркетинга по электронной почте (используйте /sales-email-marketing) или для последовательностей исходящих продаж (используйте /sales-cadence).
