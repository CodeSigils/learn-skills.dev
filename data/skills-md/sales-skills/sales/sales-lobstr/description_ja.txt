Lobstr.io プラットフォーム ヘルプ — Google マップ、LinkedIn Sales Navigator、Twitter、YouTube など用の 50 以上の既製スクレイパーを備えたコード不要の Web スクレイピング プラットフォーム。 Cookie ベースのログイン同期、スケジュールされた自動化、マルチスレッド、Python SDK と MCP サーバーを使用した完全な API が特徴です。 Lobstr スクレイパーの構成、Google スプレッドシートまたは S3 へのデータのエクスポート、スケジュールされたスクレイピングの設定、Lobstr API または Python SDK の操作、またはクレジットの管理を行う場合に使用します。一般的な見込み客リスト戦略 (/sales-prospect-list を使用)、クロスプラットフォーム強化戦略 (/sales-enrich を使用)、または統合戦略 (/sales-integration を使用) には使用しないでください。
