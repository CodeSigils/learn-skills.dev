Справка по платформе Lobstr.io — платформа для парсинга веб-страниц без кода с более чем 50 готовыми парсерами для Google Maps, LinkedIn Sales Navigator, Twitter, YouTube и т. д. Имеет синхронизацию входа на основе файлов cookie, автоматизацию по расписанию, многопоточность и полный API с Python SDK и сервером MCP. Используйте при настройке парсера Lobstr, экспорте данных в Google Sheets или S3, настройке запланированного парсинга, работе с Lobstr API или Python SDK или управлении кредитами. НЕ используйте для общей стратегии списка потенциальных клиентов (используйте /sales-prospect-list), стратегии кросс-платформенного обогащения (используйте /sales-enrich) или стратегии интеграции (используйте /sales-integration).
