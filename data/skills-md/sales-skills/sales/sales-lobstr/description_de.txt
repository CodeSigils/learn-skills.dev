Hilfe zur Lobstr.io-Plattform – No-Code-Web-Scraping-Plattform mit über 50 vorgefertigten Scrapern für Google Maps, LinkedIn Sales Navigator, Twitter, YouTube und mehr. Bietet cookiebasierte Anmeldesynchronisierung, geplante Automatisierung, Multithreading und eine vollständige API mit Python SDK und MCP Server. Verwenden Sie diese Funktion, wenn Sie einen Lobstr-Scraper konfigurieren, Daten nach Google Sheets oder S3 exportieren, geplantes Scraping einrichten, mit der Lobstr-API oder dem Python SDK arbeiten oder Credits verwalten. NICHT für eine allgemeine Strategie zur Interessentenliste (verwenden Sie /sales-prospect-list), eine plattformübergreifende Anreicherungsstrategie (verwenden Sie /sales-enrich) oder eine Integrationsstrategie (verwenden Sie /sales-integration) verwenden.
