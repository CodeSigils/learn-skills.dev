Aide de la plateforme Lobstr.io — plateforme de scraping Web sans code avec plus de 50 scrapers prêts à l'emploi pour Google Maps, LinkedIn Sales Navigator, Twitter, YouTube et plus encore. Comprend une synchronisation de connexion basée sur les cookies, une automatisation planifiée, le multithreading et une API complète avec le SDK Python et le serveur MCP. À utiliser lors de la configuration d'un scraper Lobstr, de l'exportation de données vers Google Sheets ou S3, de la configuration du scraping programmé, de l'utilisation de l'API Lobstr ou du SDK Python ou de la gestion des crédits. Ne PAS utiliser pour la stratégie générale de liste de prospects (utilisez /sales-prospect-list), la stratégie d'enrichissement multiplateforme (utilisez /sales-enrich) ou la stratégie d'intégration (utilisez /sales-integration).
