مساعدة منصة Postmark - تسليم البريد الإلكتروني للمعاملات عبر REST API (`POST /email`، `POST /email/batch`)، ترحيل SMTP، تدفقات الرسائل (المعاملات مقابل عزل البث)، قوالب المقاود مع وراثة التخطيط، تحليل البريد الإلكتروني الوارد، خطافات الويب (الارتداد، التسليم، الفتح، النقر، شكوى البريد العشوائي، تغيير الاشتراك، الوارد)، مراقبة DMARC، إدارة الارتداد (الارتداد)، عمليات القمع، الإحصائيات، واجهة برمجة التطبيقات المجمعة، المرسل التوقيعات ومصادقة المجال. يُستخدم عند السؤال "كيف أفعل X في Postmark"، أو إرسال بريد إلكتروني للمعاملات باستخدام Postmark، أو تكوين تدفقات الرسائل، أو إعداد قوالب Postmark، أو معالجة البريد الإلكتروني الوارد عبر Postmark، أو إدارة الارتدادات والقمع، أو استكشاف أخطاء إمكانية تسليم Postmark وإصلاحها. لا تستخدم لإستراتيجية التسويق عبر البريد الإلكتروني العامة (استخدام / مبيعات-تسويق عبر البريد الإلكتروني)، أو إمكانية تسليم البريد الإلكتروني عبر الأنظمة الأساسية (استخدام / مبيعات-تسليم)، أو استراتيجية تتبع فتح/نقر البريد الإلكتروني (استخدام / تتبع مبيعات البريد الإلكتروني)، أو الأسئلة الخاصة بـ SendGrid (استخدم / Sales-sendgrid).
