Справка по платформе Postmark — транзакционная доставка электронной почты через REST API («POST /email», «POST /email/batch»), ретрансляция SMTP, потоки сообщений (транзакционная или широковещательная изоляция), шаблоны Handlebars с наследованием макета, анализ входящей электронной почты, веб-хуки (возврат, доставка, открытие, щелчок, жалоба на спам, изменение подписки, входящий), мониторинг DMARC, управление возвратами (возврат), подавление, статистика, массовый API, Подписи отправителей и аутентификация домена. Используйте, когда спрашиваете «как мне сделать X в Postmark», отправляете транзакционную электронную почту с помощью Postmark, настраиваете потоки сообщений, настраиваете шаблоны Postmark, обрабатываете входящую электронную почту через Postmark, управляете возвратами и подавлением или устраняете неполадки с доставкой Postmark. НЕ используйте для общей маркетинговой стратегии по электронной почте (используйте /sales-email-marketing), кроссплатформенной доставляемости электронной почты (используйте /sales-deliverability), стратегии отслеживания открытий и кликов по электронной почте (используйте /sales-email-tracking) или вопросов, специфичных для SendGrid (используйте /sales-sendgrid).
