مساعدة منصة Omnisend - حملات البريد الإلكتروني، والتسويق عبر الرسائل النصية القصيرة، وإشعارات الويب، وسير عمل أتمتة التسويق، والنوافذ المنبثقة/النماذج، والتجزئة، وتوصيات المنتجات، وإعداد التقارير، وعمليات تكامل Shopify/WooCommerce/BigCommerce، وواجهة برمجة التطبيقات (API). يُستخدم عند السؤال "كيف أفعل X في Omnisend"، أو تكوين إعدادات Omnisend، أو إعداد سير عمل الأتمتة، أو إدارة الحملات، أو توصيل عمليات تكامل التجارة الإلكترونية، أو استخدام Omnisend API. لا تستخدم لاستراتيجية التسويق عبر البريد الإلكتروني عبر الأنظمة الأساسية (الاستخدام / المبيعات والتسويق عبر البريد الإلكتروني)، أو استراتيجية الرسائل القصيرة عبر الأنظمة الأساسية (الاستخدام / المبيعات، التسويق عبر الرسائل القصيرة)، أو إمكانية التسليم عبر الأنظمة الأساسية (الاستخدام / إمكانية تسليم المبيعات)، أو استراتيجية الدفع عبر الأنظمة الأساسية (الاستخدام / إعلام الدفع للمبيعات)، أو أدوات الاتصال (الاستخدام / تكامل المبيعات).
