مساعدة منصة Customer.io - مشاركة العملاء وأتمتة التسويق للمراسلة متعددة القنوات القائمة على السلوك (البريد الإلكتروني، والرسائل النصية القصيرة، والدفع، وداخل التطبيق، وWhatsApp). يُستخدم عند إنشاء أتمتة ناجمة عن السلوك، أو إعداد رسائل المعاملات، أو تكوين المقاطع أو الرحلات، أو دمج خطوط أنابيب البيانات أو ETL العكسي، أو إدارة الكائنات المخصصة، أو العمل مع واجهات برمجة تطبيقات التتبع/التطبيق/المعاملات. لا تستخدم لإستراتيجية التسويق العامة عبر البريد الإلكتروني (الاستخدام / المبيعات والتسويق عبر البريد الإلكتروني)، أو إمكانية تسليم البريد الإلكتروني عبر الأنظمة الأساسية (الاستخدام / إمكانية تسليم المبيعات)، أو استراتيجية تتبع فتح / النقر عبر البريد الإلكتروني (استخدام / تتبع المبيعات عبر البريد الإلكتروني).
