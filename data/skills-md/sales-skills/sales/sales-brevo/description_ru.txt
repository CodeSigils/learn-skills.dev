Помощь по платформе Brevo — кампании по электронной почте/SMS/WhatsApp, автоматизация маркетинга (путешествия), обмен транзакционными сообщениями, CRM для продаж (сделки, конвейеры), разговоры (живой чат, чат-бот), программы лояльности, push-уведомления, электронная коммерция, целевые страницы, управление контактами, Aura AI, API и интеграция. Используйте, когда спрашиваете «как мне сделать X в Brevo», настраивая параметры Brevo, настраивая кампании или средства автоматизации, управляя контактами, используя API Brevo или переходя с Sendinblue. НЕ используйте для создания списков потенциальных клиентов (используйте /sales-prospect-list), расширения контактов (используйте /sales-enrich), разработки стратегии частоты исходящих сообщений (используйте /sales-cadence), кроссплатформенной доставляемости (используйте /sales-deliverability), стратегии транзакционной электронной почты (используйте /sales-transactional-email), стратегии живого чата (используйте /sales-live-chat) или стратегии программы лояльности (используйте /sales-loyalty).
