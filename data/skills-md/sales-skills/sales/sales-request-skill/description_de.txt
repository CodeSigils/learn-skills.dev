Fordern Sie eine neue Vertriebs-/Marketing-/GTM-Fähigkeit an oder tragen Sie sie bei, die noch nicht vorhanden ist. Wird verwendet, wenn kein vorhandener Skill den Bedarf des Benutzers abdeckt – hilft ihm, den Skill aufzubauen und eine PR einzureichen oder ein Problem einzureichen, in dem er darum bittet. Wird auch verwendet, wenn der Benutzer sagt: „Dafür sollte es einen Skill geben“, „Können wir einen Skill erstellen“, „Ich möchte einen Skill beisteuern“ oder „Keiner der Vertriebsskills deckt meinen Anwendungsfall ab“.
