الدردشة المباشرة وchatbot للمبيعات والدعم - إعداد عناصر واجهة المستخدم، والتوجيه، وتدفقات chatbot، وإدارة الوكلاء، وتتبع الزائرين، وتحويل الدردشة إلى قائد، والمراسلة الاستباقية. يغطي الإستراتيجية والتنفيذ عبر Brevo Conversations وDrift (Salesloft) وIntercom وHubSpot وCrisp وLiveChat وZendesk وTidio وFreshdesk وZoomInfo Chat. يُستخدم عند إعداد الدردشة المباشرة، أو إنشاء تدفقات chatbot، أو تحسين تحويل الدردشة إلى القائد، أو توجيه الدردشات إلى الوكلاء، أو اختيار أداة الدردشة المباشرة. لا تستخدم لتسلسلات البريد الإلكتروني (استخدام / إيقاع المبيعات)، أو التسويق عبر البريد الإلكتروني (استخدام / مبيعات، تسويق عبر البريد الإلكتروني)، أو جدولة الاجتماعات (استخدام / جدولة اجتماعات المبيعات). للحصول على مساعدة خاصة بالمنصة، استخدم /sales-brevo أو /sales-salesloft.
