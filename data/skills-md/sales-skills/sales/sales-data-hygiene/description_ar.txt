جودة بيانات إدارة علاقات العملاء (CRM)، وإلغاء البيانات المكررة، وأتمتة التخصيب، ومطابقة السجلات، وإدارة تسوس البيانات. يُستخدم عند تنظيف بيانات CRM، أو إلغاء تكرار جهات الاتصال أو الحسابات، أو إصلاح السجلات القديمة، أو إعداد سير عمل الإثراء التلقائي، أو تسوية المسميات الوظيفية أو الصناعات، أو تدقيق جودة البيانات، أو إدارة تسوس البيانات. لا تستخدم لإثراء قائمة العملاء المحتملين لمرة واحدة (استخدام / إثراء المبيعات)، أو إنشاء قوائم عملاء محتملين جديدة (استخدام / قائمة عملاء محتملين)، أو التكوين الخاص بـ ZoomInfo (استخدام / sales-zoominfo). للحصول على مساعدة خاصة بالمنصة، استخدم /sales-zoominfo.
