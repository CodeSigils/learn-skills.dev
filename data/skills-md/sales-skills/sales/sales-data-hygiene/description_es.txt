Calidad de datos de CRM, deduplicación, automatización de enriquecimiento, comparación de registros y gestión de deterioro de datos. Úselo para limpiar datos de CRM, deduplicar contactos o cuentas, arreglar registros obsoletos, configurar flujos de trabajo de enriquecimiento automático, normalizar puestos de trabajo o industrias, auditar la calidad de los datos o gestionar el deterioro de los datos. NO lo use para enriquecer una lista de prospectos por única vez (use /sales-enrich), para crear nuevas listas de prospectos (use /sales-prospect-list) o para configuraciones específicas de ZoomInfo (use /sales-zoominfo). Para obtener ayuda específica de la plataforma, utilice /sales-zoominfo.
