مساعدة منصة Clay — Waterfall Enrichment (أكثر من 150 موفري بيانات)، Claygent (وكلاء أبحاث الذكاء الاصطناعي)، Sculptor (منشئ سير العمل)، الإشارات (تغييرات الوظائف، النية)، الجماهير، مزامنة الإعلانات (LinkedIn/Meta/Google)، مُسلسِل البريد الإلكتروني، مزامنة CRM (Salesforce/HubSpot/Dynamics)، إجراءات HTTP API، خطافات الويب. استخدمه عند السؤال "كيف أقوم بإعداد Clay"، و"إثراء شلال الطين"، و"Clay Claygent"، و"سير عمل Clay Sculptor"، و"إشارات Clay"، و"جمهور Clay"، و"مزامنة إعلانات Clay"، و"Clay syncer"، و"Clay CRM sync"، و"Clay webhooks"، و"Clay vs Apollo". لا تستخدم لاستراتيجية الإثراء عبر الأدوات (الاستخدام / إثراء المبيعات)، أو استراتيجية الإيقاع / التسلسل عبر الأدوات (الاستخدام / إيقاع المبيعات)، أو استراتيجية إشارة النية عبر الأدوات (الاستخدام / نية المبيعات)، أو استراتيجية الإعلان B2B عبر الأدوات (الاستخدام / المبيعات - b2b - الإعلان)، أو استراتيجية نظافة بيانات إدارة علاقات العملاء عبر الأدوات (الاستخدام / نظافة بيانات المبيعات).
