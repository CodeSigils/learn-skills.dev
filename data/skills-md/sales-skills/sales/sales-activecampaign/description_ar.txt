مساعدة منصة ActiveCampaign - أتمتة التسويق وإدارة علاقات العملاء للبريد الإلكتروني والرسائل النصية القصيرة وWhatsApp والصفحات المقصودة ومسارات المبيعات. يُستخدم عند إنشاء عمليات أتمتة التسويق، أو تكوين مسارات وصفقات CRM، أو إعداد تسجيل العملاء المحتملين، أو إنشاء صفحات أو نماذج مقصودة، أو إدارة حملات البريد الإلكتروني باستخدام اختبار A/B والمحتوى الشرطي، أو العمل مع ActiveCampaign API. لا تستخدم لإستراتيجية التسويق عبر البريد الإلكتروني العامة (الاستخدام / المبيعات والتسويق عبر البريد الإلكتروني)، أو إمكانية تسليم البريد الإلكتروني عبر الأنظمة الأساسية (الاستخدام / قابلية تسليم المبيعات)، أو استراتيجية تتبع البريد الإلكتروني (الاستخدام / تتبع المبيعات عبر البريد الإلكتروني)، أو استراتيجية تسجيل العملاء المحتملين (الاستخدام / نقاط العملاء المحتملين للمبيعات).
