Guida della piattaforma Tableau: Tableau Desktop, Tableau Cloud, Tableau Server, Tableau Prep, Tableau Pulse, API di incorporamento, API REST (v3.28, autenticazione PAT/JWT, oltre 300 endpoint), server MCP e Tableau+. Da utilizzare quando i dashboard sono lenti con set di dati di grandi dimensioni, le espressioni LOD o i campi calcolati non funzionano, i costi di licenza sono confusi o aumentano vertiginosamente, Tableau non si connette a Salesforce o al data warehouse, le analisi incorporate non vengono visualizzate, i flussi di Tableau Prep continuano a fallire o hai bisogno di aiuto per scegliere le licenze Creator, Explorer o Viewer. NON utilizzare per la configurazione CRM generale (utilizzare /sales-salesforce) o per la metodologia di previsione delle vendite (utilizzare /sales-forecast).
