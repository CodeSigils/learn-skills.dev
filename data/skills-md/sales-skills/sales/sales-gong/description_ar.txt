مساعدة منصة Gong - نظام التشغيل AI للإيرادات من خلال تسجيل المكالمات، وتحليلات النصوص، وأجهزة التتبع الذكية، وبطاقات أداء التدريب، ولوحات الصفقات، وتوقعات Gong، وتسلسلات Gong Engage، ووكلاء Gong، وREST API (3 متطلبات في الثانية، 10 آلاف في اليوم)، وقواعد أتمتة webhook مع توقيع JWT، ومزامنة CRM (Salesforce/HubSpot/Dynamics)، ودعم MCP. يُستخدم عند إعداد تسجيل مكالمات Gong أو تحليل النص، أو تقوم Smart Trackers بإرجاع نتائج إيجابية كاذبة أو لحظات رئيسية مفقودة، أو تكامل Gong API لتصدير النصوص أو بيانات الصفقات، أو تكوين قواعد أتمتة webhook، أو عدم تطابق Gong Forecast مع واقع خط الأنابيب، أو تسلسلات Gong Engage بطيئة أو بها أخطاء، أو بطاقات أداء التدريب لا تعكس المنهجية، أو تأخيرات مزامنة CRM. لا تستخدمه لاختيار مُدون ملاحظات (استخدم / مُدون ملاحظات المبيعات) أو لإنشاء برنامج تدريب (استخدم / تدريب المبيعات).
