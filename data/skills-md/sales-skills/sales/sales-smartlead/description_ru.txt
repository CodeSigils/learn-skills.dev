Помощь по платформе Smartlead — кампании, SmartSenders, SmartInfra, SmartAgents, SmartDialer, SmartProspect, SmartDelivery, прогрев, API, интеграции, агентство/white-label. Используйте, когда спрашиваете: «Как мне сделать X в Smartlead», настройке параметров Smartlead, настройке SmartSender, управлении кампаниями/лидами, предоставлении почтовых ящиков, настройке SmartInfra, создании SmartAgents, использовании SmartDialer, тестировании с помощью SmartDelivery, настройке рабочих пространств агентства, белой маркировке или использовании API Smartlead. НЕ используйте для создания списков потенциальных клиентов (используйте /sales-prospect-list), разработки стратегии каденции (используйте /sales-cadence), кросс-платформенной доставляемости (используйте /sales-deliverability) или архитектуры многоклиентского агентства (используйте /sales-agency-outbound).
