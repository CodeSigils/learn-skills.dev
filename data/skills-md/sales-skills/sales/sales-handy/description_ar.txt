مساعدة سهلة للنظام الأساسي - تطبيق سطح مكتب مفتوح المصدر ومتعدد المنصات لتحويل الكلام إلى نص مع محركات Whisper وParakeet STT، والضغط والتحدث، وتحويل الصوت إلى نص، وتسريع GPU، واكتشاف النشاط الصوتي (ترخيص MIT، 20 ألف نجمة على GitHub). استخدمه عند إعداد Handy على نظام التشغيل macOS أو Windows أو Linux لأول مرة، أو الاختيار بين طرازي Whisper وParakeet للدقة مقابل السرعة، أو سماعات الرأس Bluetooth التي تتسبب في تأخير بدء النسخ، أو تعطل Handy عند بدء التشغيل أو بعد تحديث macOS، أو عدم عمل اختصار الضغط والتحدث أو التعارض مع التطبيقات الأخرى، أو مقارنة Handy بـ Amical أو Wispr Flow أو Superwhisper للإملاء في وضع عدم الاتصال، أو تكوين حساسية اكتشاف النشاط الصوتي، أو تشغيل Handy بدون رأس مع علامات CLI للأتمتة. لا تستخدم للاختيار بين مدونين ملاحظات الاجتماع بشكل عام (استخدم /مدون ملاحظات المبيعات) أو مراجعة مكالمة واحدة للتدريب (استخدم /مراجعة مكالمة المبيعات).
