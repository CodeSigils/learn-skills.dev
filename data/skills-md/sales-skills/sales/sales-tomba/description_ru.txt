Справка по платформе Tomba.io — поиск домена, поиск электронной почты, проверка электронной почты, обогащение, поиск автора, поиск LinkedIn, поиск телефона, массовые операции, расширения браузера, API, интеграция. Используйте, когда спрашиваете «как мне сделать X в Tomba», при поиске электронных писем с помощью Tomba, проверке электронных писем в Tomba, расширении контактов с помощью Tomba, использовании API Tomba, настройке интеграции Tomba или управлении потенциальными клиентами/списками Tomba. НЕ используйте для стратегии обогащения инструментов (используйте /sales-enrich), создания списков потенциальных клиентов (используйте /sales-prospect-list), кросс-платформенной доставки (используйте /sales-deliverability) или общего подключения инструментов (используйте /sales-integration).
