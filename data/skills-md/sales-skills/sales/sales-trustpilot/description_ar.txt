مساعدة منصة Trustpilot — مجموعة المراجعات، وعناصر واجهة المستخدم TrustBox، وTrustScore، وتقييمات Google Seller، وInvitation API، وتكاملات التجارة الإلكترونية. استخدمه عندما لا تظهر مراجعات Trustpilot على موقع الويب، أو لا يتم تحميل عنصر واجهة المستخدم TrustBox، أو يسقط TrustScore بشكل غير متوقع، أو إعداد دعوات المراجعة التلقائية، أو تكوين Trustpilot Shopify أو البرنامج المساعد WooCommerce، أو توصيل Trustpilot API بتطبيقك، أو إزالة المراجعات أو وضع علامة عليها بشكل غير عادل، أو تحديد ما إذا كان Trustpilot يستحق التكلفة لشركتك. لا تستخدم لمراجعة إستراتيجية التجميع عبر الأنظمة الأساسية (استخدم /مراجعات العملاء للمبيعات) أو لاستخراج مراجعات Trustpilot (استخدم /المبيعات-ناوت سكريبر).
