OpenWeb Ninja 平台幫助 — 即時公共資料 API 堆疊，具有 30 多個用於網路抓取、豐富和業務資料的 API。主要 API 包括網站聯絡人抓取工具、電子郵件搜尋、本地業務資料（Google 地圖）、即時網路搜尋 (SERP)、JSearch（職缺）和產品資料。從網域中提取電子郵件/聯絡人、在 Google 地圖中搜尋本地企業、透過 API 執行網路搜尋、聚合職位發布、獲取產品資料或使用任何 OpenWeb Ninja API 時使用。請勿用於跨平台豐富策略（使用 /sales-enrich）、潛在客戶清單建立策略（使用 /sales-prospect-list）或連接工具（使用 /sales-integration）。
