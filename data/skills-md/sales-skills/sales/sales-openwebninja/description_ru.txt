Справка по платформе OpenWeb Ninja — стек API общедоступных данных в реальном времени с более чем 30 API-интерфейсами для очистки веб-страниц, их обогащения и бизнес-данных. Ключевые API включают в себя парсер контактов на веб-сайте, поиск по электронной почте, локальные бизнес-данные (Карты Google), веб-поиск в реальном времени (SERP), JSearch (объявления о вакансиях) и данные о продуктах. Используйте при извлечении электронных писем/контактов из доменов, поиске на Картах Google местных предприятий, запуске веб-поиска через API, агрегировании объявлений о вакансиях, получении данных о продуктах или работе с любым API OpenWeb Ninja. НЕ используйте для стратегии кросс-платформенного обогащения (используйте /sales-enrich), стратегии создания списка потенциальных клиентов (используйте /sales-prospect-list) или инструментов подключения (используйте /sales-integration).
