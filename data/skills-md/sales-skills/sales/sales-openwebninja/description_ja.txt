OpenWeb Ninja プラットフォームのヘルプ — Web スクレイピング、エンリッチメント、ビジネス データ用の 30 以上の API を備えたリアルタイム パブリック データ API スタック。主要な API には、Web サイト連絡先スクレイパー、電子メール検索、ローカル ビジネス データ (Google マップ)、リアルタイム Web 検索 (SERP)、JSearch (求人情報)、および製品データが含まれます。ドメインからの電子メール/連絡先の抽出、Google マップで地元のビジネスを検索、API 経由で Web 検索を実行、求人情報を集約、製品データを取得、または OpenWeb Ninja API を操作するときに使用します。クロスプラットフォーム強化戦略 (/sales-enrich を使用)、見込み客リスト構築戦略 (/sales-prospect-list を使用)、または接続ツール (/sales-integration を使用) には使用しないでください。
