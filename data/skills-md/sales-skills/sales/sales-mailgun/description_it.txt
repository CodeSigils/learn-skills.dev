Guida per la piattaforma Mailgun (Sinch): API di posta elettronica transazionale pensata per gli sviluppatori e inoltro SMTP con routing in entrata, webhook e strumenti di consegna Mailgun Optimize. Da utilizzare quando si inviano e-mail transazionali tramite API Mailgun o SMTP, si configurano domini o DNS (DKIM/SPF), si imposta il routing della posta elettronica in entrata, si gestiscono webhook o modelli, si utilizza Mailgun Optimize per test di posizionamento della posta in arrivo o si lavora con l'API REST Mailgun. NON utilizzare per una strategia generale di recapito delle e-mail (uso /sales-deliverability), marketing e-mail multipiattaforma (uso /sales-email-marketing) o strategia di tracciamento delle aperture/clic delle e-mail (uso /sales-email-tracking).
