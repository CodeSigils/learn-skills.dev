مساعدة نظام Mailgun (Sinch) — واجهة برمجة تطبيقات البريد الإلكتروني للمعاملات الخاصة بالمطورين وترحيل SMTP مع التوجيه الداخلي وخطافات الويب وأدوات Mailgun Optimize للتسليم. يُستخدم عند إرسال بريد إلكتروني للمعاملات عبر Mailgun API أو SMTP، أو تكوين المجالات أو DNS (DKIM/SPF)، أو إعداد توجيه البريد الإلكتروني الوارد، أو إدارة خطافات الويب أو القوالب، أو استخدام Mailgun Optimize لاختبار وضع البريد الوارد، أو العمل مع Mailgun REST API. لا تستخدم لإستراتيجية تسليم البريد الإلكتروني العامة (استخدام / قابلية تسليم المبيعات)، أو التسويق عبر البريد الإلكتروني عبر الأنظمة الأساسية (استخدام / مبيعات - تسويق عبر البريد الإلكتروني)، أو استراتيجية تتبع فتح / النقر عبر البريد الإلكتروني (استخدام / تتبع مبيعات البريد الإلكتروني).
