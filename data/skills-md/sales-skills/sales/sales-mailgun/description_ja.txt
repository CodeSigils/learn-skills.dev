Mailgun (Sinch) プラットフォームのヘルプ — 開発者初のトランザクション電子メール API と、インバウンド ルーティング、Webhook、および Mailgun Optimize 配信性ツールを備えた SMTP リレー。 Mailgun API または SMTP 経由でトランザクション電子メールを送信する場合、ドメインまたは DNS (DKIM/SPF) を構成する場合、受信電子メール ルーティングを設定する場合、Webhook またはテンプレートを管理する場合、受信トレイの配置テストに Mailgun Optimize を使用する場合、または Mailgun REST API を操作する場合に使用します。一般的な電子メール到達性戦略 (/sales-deliverability を使用)、クロスプラットフォーム電子メール マーケティング (/sales-email-marketing を使用)、または電子メール開封/クリック追跡戦略 (/sales-email-tracking を使用) には使用しないでください。
