Справка по платформе Mailgun (Sinch) — первый для разработчиков транзакционный API электронной почты и ретрансляция SMTP с входящей маршрутизацией, веб-перехватчиками и инструментами доставки Mailgun Optimize. Используйте при отправке транзакционной электронной почты через Mailgun API или SMTP, настройке доменов или DNS (DKIM/SPF), настройке маршрутизации входящей электронной почты, управлении веб-перехватчиками или шаблонами, использовании Mailgun Optimize для тестирования размещения входящих сообщений или работе с Mailgun REST API. НЕ используйте для общей стратегии доставки электронной почты (используйте /sales-deliverability), кросс-платформенного маркетинга по электронной почте (используйте /sales-email-marketing) или стратегии отслеживания открытий и кликов по электронной почте (используйте /sales-email-tracking).
