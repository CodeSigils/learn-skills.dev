Справка по платформе Attio — CRM на основе искусственного интеллекта с настраиваемыми объектами, базой данных взаимоотношений, конвейерами сделок, последовательностями электронной почты, средствами автоматизации и встроенными возможностями для более чем 80 000 стартапов. Охватывает разработку настраиваемой модели данных (объекты, атрибуты, связи), настройку конвейера, автоматизацию рабочих процессов, последовательность электронной почты, агенты искусственного интеллекта (Ask Attio), отчеты, интеграцию API (REST, OAuth 2.0, более 100 конечных точек, веб-перехватчики, сервер MCP) и уровни цен (Free/Plus/Pro/Enterprise). Используйте при настройке Attio CRM, создании пользовательских объектов, настройке конвейеров сделок, создании автоматизации, использовании Attio API или оценке Attio по сравнению с другими CRM. НЕ используйте для общей стратегии гигиены данных CRM (используйте /sales-data-hygiene), исходящих последовательностей между платформами (используйте /sales-cadence), стратегии обогащения контактов (используйте /sales-enrich) или шаблонов интеграции инструментов (используйте /sales-integration).
