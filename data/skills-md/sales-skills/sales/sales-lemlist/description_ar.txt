مساعدة منصة Lemlist - تسلسلات متعددة القنوات، وقاعدة بيانات العملاء المحتملين، والإثراء، وLemwarm، وصندوق الوارد الموحد، وتخصيص الذكاء الاصطناعي، وأتمتة LinkedIn، والمكالمات، وWhatsApp، وAPI، والتكاملات. استخدمه عند السؤال "كيف أفعل X في Lemlist"، أو تكوين إعدادات Lemlist، أو إعداد التسلسلات، أو إدارة العملاء المتوقعين، أو استخدام Lemwarm Warmup، أو توصيل عمليات التكامل، أو استخدام قاعدة بيانات الأشخاص، أو استخدام Lemlist API. لا تستخدم لبناء قوائم العملاء المحتملين (استخدام / قائمة عملاء محتملين)، أو تصميم استراتيجية الإيقاع (استخدام / إيقاع المبيعات)، أو إمكانية التسليم عبر الأنظمة الأساسية (استخدام / إمكانية تسليم المبيعات)، أو إثراء جهات الاتصال خارج Lemlist (استخدام / إثراء المبيعات).
