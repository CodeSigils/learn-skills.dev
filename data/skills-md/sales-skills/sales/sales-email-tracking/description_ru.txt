Отслеживание взаимодействия по электронной почте для продаж — открытое отслеживание, отслеживание кликов, просмотр вложений, уведомления в реальном времени, время последующих действий и аналитика взаимодействия. Используйте при настройке отслеживания электронной почты, интерпретации данных об открытиях и кликах, отслеживании Mixmax, отслеживании Woodpecker, отслеживании времени на основе взаимодействия, понимании ограничений отслеживания (Apple MPP, блокировка пикселей), отслеживании Reply.io или выборе инструмента отслеживания. Для получения справки по Yesware используйте /sales-yesware. НЕ используйте для доставки электронной почты (используйте /sales-deliverability), оформления каденции (используйте /sales-cadence), сигналов намерения о покупке помимо электронной почты (используйте /sales-intent), конфигурации для SendGrid (используйте /sales-sendgrid), конфигурации для конкретной почтовой марки (используйте /sales-postmark), конфигурации для Customer.io (используйте /sales-customerio), конфигурации для Mailgun (используйте /sales-mailgun), конфигурация, специфичная для Klaviyo (используйте /sales-klaviyo), или конфигурация, специфичная для ActiveCampaign (используйте /sales-activecampaign).
