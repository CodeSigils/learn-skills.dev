مساعدة منصة Klaviyo - إدارة علاقات العملاء B2C الأولى التي تعتمد على الذكاء الاصطناعي وأتمتة التسويق للتجارة الإلكترونية مع التحليلات التنبؤية، وأكثر من 350 عملية تكامل، ومراسلة عبر القنوات. يُستخدم عند إنشاء أتمتة البريد الإلكتروني/الرسائل النصية القصيرة للتجارة الإلكترونية، أو إعداد تدفقات أو شرائح Klaviyo، أو تكوين تكامل Shopify-Klaviyo، أو استخدام التحليلات التنبؤية (CLV، مخاطر الإيقاف)، أو إدارة النماذج أو المراجعات، أو العمل مع واجهة برمجة تطبيقات Klaviyo. لا تستخدم لإستراتيجية التسويق العامة عبر البريد الإلكتروني (الاستخدام / المبيعات والتسويق عبر البريد الإلكتروني)، أو إمكانية تسليم البريد الإلكتروني عبر الأنظمة الأساسية (الاستخدام / إمكانية تسليم المبيعات)، أو استراتيجية تتبع فتح / النقر عبر البريد الإلكتروني (استخدام / تتبع المبيعات عبر البريد الإلكتروني).
