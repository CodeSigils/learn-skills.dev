مساعدة منصة Braze - تنسيق رحلة Canvas Flow، البريد الإلكتروني/الدفع/داخل التطبيق/الرسائل النصية القصيرة/WhatsApp/حملات بطاقات المحتوى، BrazeAI (التنبؤي، التوليدي، الوكيل)، Braze Data Platform (CDI، Currents)، التجزئة في الوقت الفعلي، الكتالوجات، علامات الميزات، واجهة برمجة تطبيقات البريد الإلكتروني للمعاملات، القوالب السائلة، المحتوى المتصل، عمليات تكامل Braze Alloys، SCIM، REST API. يُستخدم عند السؤال "كيف أفعل X في Braze"، أو تكوين تدفقات Canvas، أو إنشاء المقاطع، أو إعداد تدفق بيانات Currents، أو استخدام Braze API، أو الترحيل من Appboy. لا تستخدم لبناء قوائم العملاء المحتملين (استخدام / قائمة عملاء المبيعات المحتملين)، أو تصميم إستراتيجية الإيقاع الصادر (استخدام / إيقاع المبيعات)، أو إمكانية التسليم عبر الأنظمة الأساسية (استخدام / قابلية تسليم المبيعات)، أو استراتيجية البريد الإلكتروني للمعاملات (استخدام / مبيعات - بريد إلكتروني للمعاملات)، أو استراتيجية دفع الإشعارات (استخدام / إعلام دفع المبيعات)، أو استراتيجية المراسلة داخل التطبيق (استخدام / رسائل المبيعات في التطبيق)، أو استراتيجية التسويق عبر البريد الإلكتروني (استخدام /المبيعات-التسويق عبر البريد الإلكتروني).
