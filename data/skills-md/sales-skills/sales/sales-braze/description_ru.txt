Справка по платформе Braze — оркестровка пути Canvas Flow, кампании по электронной почте/push/в приложении/SMS/WhatsApp/карточках контента, BrazeAI (предиктивный, генеративный, агентный), платформа данных Braze (CDI, Currents), сегментация в реальном времени, каталоги, флаги функций, транзакционный API электронной почты, жидкое шаблонирование, подключенный контент, интеграция Braze Alloys, SCIM, REST API. Используйте, когда спрашиваете «как мне сделать X в Braze», настраивая потоки Canvas, создавая сегменты, настраивая потоковую передачу данных Currents, используя API Braze или мигрируя с Appboy. НЕ используйте для создания списков потенциальных клиентов (используйте /sales-prospect-list), разработки стратегии частоты исходящих сообщений (используйте /sales-cadence), кросс-платформенной доставляемости (используйте /sales-deliverability), стратегии транзакционной электронной почты (используйте /sales-transactional-email), стратегии push-уведомлений (используйте /sales-push-notification), стратегии обмена сообщениями в приложении (используйте /sales-in-app-messaging) или стратегии маркетинга по электронной почте (используйте /продажа-электронная почта-маркетинг).
