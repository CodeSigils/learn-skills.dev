مساعدة منصة SendGrid — البريد الإلكتروني للمعاملات عبر واجهة برمجة تطبيقات البريد الإلكتروني (REST + SMTP)، والحملات التسويقية (محرر السحب والإفلات، والتشغيل الآلي، واختبار A/B، ونماذج الاشتراك، والتجزئة)، وواجهة برمجة تطبيقات التحقق من صحة البريد الإلكتروني، والقوالب الديناميكية (المقاود)، وخطافات ويب الأحداث، والتحليل الوارد، ومصادقة المجال (SPF/DKIM/DMARC)، وعناوين IP المخصصة، وعمليات القمع، ومكتبة التصميم، واختبار البريد الإلكتروني، والإحصاءات. يُستخدم عند السؤال "كيف أفعل X في SendGrid"، أو إرسال بريد إلكتروني للمعاملات باستخدام SendGrid، أو إعداد حملات التسويق، أو تكوين Webhooks للأحداث، أو إدارة مصادقة مجال SendGrid، أو استخدام القوالب الديناميكية، أو استكشاف أخطاء إمكانية تسليم SendGrid وإصلاحها. لا تستخدم لإستراتيجية التسويق العامة عبر البريد الإلكتروني (الاستخدام / المبيعات والتسويق عبر البريد الإلكتروني)، أو إمكانية تسليم البريد الإلكتروني عبر الأنظمة الأساسية (الاستخدام / إمكانية تسليم المبيعات)، أو استراتيجية تتبع فتح / النقر عبر البريد الإلكتروني (استخدام / تتبع المبيعات عبر البريد الإلكتروني).
