Справка по платформе SendGrid — транзакционная электронная почта через API электронной почты (REST + SMTP), маркетинговые кампании (редактор перетаскивания, автоматизация, A/B-тестирование, формы регистрации, сегментация), API проверки электронной почты, динамические шаблоны (Handlebars), веб-перехватчики событий, входящий анализ, аутентификация домена (SPF/DKIM/DMARC), выделенные IP-адреса, подавления, библиотека дизайна, тестирование электронной почты, статистика. Используйте, когда спрашиваете «как мне сделать X в SendGrid», отправляете транзакционную электронную почту с помощью SendGrid, настраиваете маркетинговые кампании, настраиваете веб-перехватчики событий, управляете проверкой подлинности домена SendGrid, используете динамические шаблоны или устраняете неполадки доставки SendGrid. НЕ используйте для общей маркетинговой стратегии по электронной почте (используйте /sales-email-marketing), кросс-платформенной доставляемости электронной почты (используйте /sales-deliverability) или стратегии отслеживания открытий и кликов по электронной почте (используйте /sales-email-tracking).
