Guida della piattaforma SendGrid: e-mail transazionale tramite API e-mail (REST + SMTP), campagne di marketing (editor drag-and-drop, automazioni, test A/B, moduli di iscrizione, segmentazione), API di convalida e-mail, modelli dinamici (manubri), webhook eventi, analisi in entrata, autenticazione del dominio (SPF/DKIM/DMARC), IP dedicati, soppressioni, libreria di progettazione, test e-mail, statistiche. Da utilizzare quando si chiede "come faccio a eseguire X in SendGrid", si inviano e-mail transazionali con SendGrid, si impostano campagne di marketing, si configurano webhook di eventi, si gestisce l'autenticazione del dominio SendGrid, si utilizzano modelli dinamici o si risolve il problema della consegna di SendGrid. NON utilizzare per strategie generali di email marketing (usa /sales-email-marketing), consegna di email multipiattaforma (usa /sales-deliverability) o strategia di tracciamento di apertura/clic delle email (usa /sales-email-tracking).
