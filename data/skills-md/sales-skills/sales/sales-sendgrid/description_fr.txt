Aide de la plateforme SendGrid — e-mail transactionnel via API de messagerie (REST + SMTP), campagnes marketing (éditeur glisser-déposer, automatisations, tests A/B, formulaires d'inscription, segmentation), API de validation d'e-mail, modèles dynamiques (guidons), webhooks d'événements, analyse entrante, authentification de domaine (SPF/DKIM/DMARC), adresses IP dédiées, suppressions, bibliothèque de conception, tests d'e-mails, statistiques. À utiliser pour demander « comment faire X dans SendGrid », pour envoyer un e-mail transactionnel avec SendGrid, pour configurer des campagnes marketing, pour configurer des webhooks d'événements, pour gérer l'authentification de domaine SendGrid, pour utiliser des modèles dynamiques ou pour dépanner la délivrabilité de SendGrid. Ne PAS utiliser pour la stratégie générale de marketing par e-mail (utilisez /sales-email-marketing), la délivrabilité des e-mails multiplateformes (utilisez /sales-deliverability) ou la stratégie de suivi des ouvertures/clics des e-mails (utilisez /sales-email-tracking).
