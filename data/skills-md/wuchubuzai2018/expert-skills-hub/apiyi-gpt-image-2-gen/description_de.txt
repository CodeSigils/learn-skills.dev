Fertigkeit zur Bildgenerierung: Verwenden Sie diese Fertigkeit, wenn Benutzer Bilder und visuelle Infografiken generieren, Bilder erstellen oder vorhandene Bilder bearbeiten/ändern/anpassen müssen. Offizieller Dienst zur Generierung von Release-Bildern basierend auf dem ChatGPT Image 2-Modell (gpt-image-2) von der API Yi-Plattform (https://api.apiyi.com/). Dieses Modell unterstützt eine präzise Größen-/Qualitätskontrolle (einschließlich 4K), die per Token abgerechnet wird. Hauptunterschiede zu gpt-image-2-all (offizielle umgekehrte Version): verwendet die Endpunkte /v1/images/generations und /v1/images/edits; hat einen expliziten Größenparameter; hat einen Qualitätsparameter; Abrechnung per Token; verwendet Multipart-/Formulardaten zum Hochladen von Referenzbildern; b64_json ist reines Base64 ohne Präfix.
