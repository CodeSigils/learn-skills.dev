Fähigkeit zur Bildgenerierung – verwenden Sie diese, wenn der Benutzer Bilder oder visuelle Infografiken erstellen oder vorhandene Bilder bearbeiten/ändern/anpassen muss. Offizieller Bildgenerierungsdienst basierend auf dem ChatGPT Image 2-Modell (gpt-image-2) von der APIyi-Plattform (https://api.apiyi.com/). Das Modell unterstützt eine präzise Größen-/Qualitätskontrolle (einschließlich 4K) und wird per Token abgerechnet. Hauptunterschiede zu gpt-image-2-all (inoffizielle umgekehrte Version): verwendet die Endpunkte /v1/images/generations und /v1/images/edits; hat einen expliziten Größenparameter; hat einen Qualitätsparameter; Abrechnung per Token; lädt Referenzbilder über Multipart/Form-Daten hoch; b64_json ist reines Base64 ohne Präfix.
