Image generation skill—use this when the user needs to create images, visual infographics, or edit/modify/adjust existing images. Official image-generation service based on the ChatGPT Image 2 model (gpt-image-2) from the APIyi platform (https://api.apiyi.com/). The model supports precise size/quality control (including 4K) and is billed by token. Key differences from gpt-image-2-all (unofficial reverse version): uses /v1/images/generations and /v1/images/edits endpoints; has explicit size parameter; has quality parameter; billed by token; uploads reference images via multipart/form-data; b64_json is pure base64 without prefix.
