Habilidad de generación de imágenes: utilice esta habilidad cuando los usuarios necesiten generar imágenes, infografías visuales, crear imágenes o editar/modificar/ajustar imágenes existentes. Este es el servicio oficial de generación de imágenes basado en el modelo ChatGPT Image 2 (gpt-image-2) de la plataforma API Easy (https://api.apiyi.com/). El modelo admite un control preciso de tamaño/calidad (incluido 4K) y se factura mediante tokens. Diferencias clave con gpt-image-2-all (versión no oficial): utiliza puntos finales /v1/images/generaciones y /v1/images/edits; tiene un parámetro de tamaño explícito; tiene parámetro de calidad; facturado mediante fichas; utiliza datos multiparte/formularios para cargar imágenes de referencia; b64_json es base64 puro sin prefijo.
