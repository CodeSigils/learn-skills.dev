Habilidad de generación de imágenes de IA, utilizando el último modelo de imágenes de ChatGPT, gpt-image-2-all. Utilice esta habilidad siempre que los usuarios necesiten generar imágenes, infografías visuales, crear imágenes o editar/modificar/ajustar imágenes existentes. El servicio funciona con el modelo gpt-image-2-all de la plataforma API Easy (https://api.apiyi.com/), sin necesidad de acceder a Internet global. El modelo es de pago por uso a 0,03 dólares por imagen, admite texto a imagen, edición de una sola imagen, fusión de múltiples imágenes y edición de lenguaje natural, ofrece alta fidelidad de texto y es compatible con indicaciones en chino. El tamaño se controla describiéndolo en el mensaje (sin parámetro de tamaño explícito). Diferencias clave con NanoBanana2: sin parámetro de tamaño: indique el tamaño al inicio del mensaje; $0.03 fijos por imagen independientemente de la resolución; el punto final conversacional /v1/chat/completions es la recomendación principal.
