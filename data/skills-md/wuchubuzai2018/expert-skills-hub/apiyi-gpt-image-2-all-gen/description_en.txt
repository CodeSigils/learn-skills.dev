AI image generation skill, using ChatGPT’s latest image model gpt-image-2-all. Use this skill whenever users need to generate images, visual infographics, create pictures, or edit/modify/adjust existing images. The service is powered by the gpt-image-2-all model from the API Easy platform (https://api.apiyi.com/), with no need to access the global internet. Size is controlled by describing it in the prompt (no explicit size parameter). Key differences from NanoBanana2: no size parameter—state the size at the start of the prompt; flat $0.03 per image regardless of resolution; the conversational endpoint /v1/chat/completions is the primary recommendation.
