Project knowledge base hierarchical maintenance skill, which generates a standardized project document directory structure based on a four‑layer architecture (project layer → technology layer → asset layer + raw layer). Under the docs/ folder, the four layers use Chinese directory names, each directory must include a corresponding index.md index file, and all documents must carry YAML metadata (document number, title, type, status, date, author). The raw layer, serving as the source of information, is stored separately. Supports initialization and incremental maintenance. Use this skill when users need to create project knowledge management documents, maintain project asset documents, plan a project documentation system, or generate a project document directory.
