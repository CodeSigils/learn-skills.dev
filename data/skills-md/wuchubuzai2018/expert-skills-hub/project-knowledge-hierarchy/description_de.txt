Fähigkeit zur mehrschichtigen Wartung der Projektwissensdatenbank, die eine standardisierte Projektdokumentverzeichnisstruktur basierend auf einer vierschichtigen Architektur (Projektschicht → technische Schicht → Asset-Schicht + Rohschicht) generiert. Unterdokumente/die vier Ebenen verwenden chinesische Verzeichnisnamen, jedes Verzeichnis muss mit einer index.mdindex-Datei gepaart sein und alle Dokumente müssen YAML-Metadaten (Dokumentnummer, Titel, Typ, Status, Datum, Autor) enthalten. Die Rohschicht als Informationsquelle wird separat gespeichert. Unterstützt Initialisierung und inkrementelle Wartung. Verwenden Sie diese Fertigkeit, wenn Benutzer Projekt-Wissensmanagementdokumente erstellen, Projekt-Asset-Dokumente verwalten, ein Projektdokumentationssystem planen oder ein Projektdokumentverzeichnis erstellen müssen.
