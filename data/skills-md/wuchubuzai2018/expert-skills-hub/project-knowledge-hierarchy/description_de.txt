Fähigkeit zur hierarchischen Pflege der Projektwissensdatenbank, die eine standardisierte Projektdokumentverzeichnisstruktur basierend auf einer vierschichtigen Architektur (Projektschicht → Technologieschicht → Asset-Schicht + Rohschicht) generiert. Unter dem Ordner docs/ verwenden die vier Ebenen chinesische Verzeichnisnamen, jedes Verzeichnis muss eine entsprechende index.md-Indexdatei enthalten und alle Dokumente müssen YAML-Metadaten enthalten (Dokumentnummer, Titel, Typ, Status, Datum, Autor). Die Rohschicht, die als Informationsquelle dient, wird separat gespeichert. Unterstützt Initialisierung und inkrementelle Wartung. Verwenden Sie diese Fähigkeit, wenn Benutzer Projektwissensmanagementdokumente erstellen, Projektressourcendokumente verwalten, ein Projektdokumentationssystem planen oder ein Projektdokumentverzeichnis erstellen müssen.
