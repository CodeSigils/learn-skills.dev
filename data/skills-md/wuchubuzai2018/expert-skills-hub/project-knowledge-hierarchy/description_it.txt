Abilità di manutenzione gerarchica della base di conoscenza del progetto, che genera una struttura di directory dei documenti di progetto standardizzata basata su un'architettura a quattro livelli (livello di progetto → livello di tecnologia → livello di risorse + livello grezzo). Sotto la cartella docs/, i quattro livelli utilizzano nomi di directory cinesi, ciascuna directory deve includere un file indice index.md corrispondente e tutti i documenti devono contenere metadati YAML (numero del documento, titolo, tipo, stato, data, autore). Il livello grezzo, che funge da fonte di informazioni, viene archiviato separatamente. Supporta l'inizializzazione e la manutenzione incrementale. Utilizzare questa competenza quando gli utenti devono creare documenti di gestione della conoscenza del progetto, gestire documenti di risorse del progetto, pianificare un sistema di documentazione di progetto o generare una directory di documenti di progetto.
