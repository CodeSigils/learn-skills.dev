Навыки иерархического обслуживания базы знаний проекта, которые создают стандартизированную структуру каталогов документов проекта на основе четырехуровневой архитектуры (уровень проекта → технологический уровень → уровень активов + необработанный уровень). В папке docs/ четыре уровня используют имена каталогов на китайском языке, каждый каталог должен включать соответствующий индексный файл index.md, а все документы должны содержать метаданные YAML (номер документа, название, тип, статус, дата, автор). Необработанный слой, служащий источником информации, хранится отдельно. Поддерживает инициализацию и поэтапное обслуживание. Используйте этот навык, когда пользователям необходимо создавать документы управления знаниями проекта, поддерживать документы активов проекта, планировать систему документации проекта или создавать каталог документов проекта.
