Habilidad de mantenimiento en capas para una base de conocimiento del proyecto, generando una estructura de directorio de documentos de proyecto estandarizada basada en una arquitectura de cuatro capas (capa de proyecto → capa de tecnología → capa de activos + capa sin procesar). En docs/, las cuatro capas usan nombres de directorio chinos, cada directorio debe incluir un archivo de índice index.md y todos los documentos deben contener metadatos YAML (número de documento, título, tipo, estado, fecha, autor). La capa sin procesar, como fuente de información, se almacena por separado. Admite inicialización y mantenimiento incremental. Esta habilidad se utiliza cuando el usuario necesita crear documentos de gestión del conocimiento del proyecto, mantener documentos de activos del proyecto, planificar el sistema de documentos del proyecto o generar el directorio de documentos del proyecto.
