Habilidad de mantenimiento jerárquico de la base de conocimientos del proyecto, que genera una estructura de directorio de documentos de proyecto estandarizada basada en una arquitectura de cuatro capas (capa de proyecto → capa de tecnología → capa de activos + capa sin procesar). En la carpeta docs/, las cuatro capas usan nombres de directorio chinos, cada directorio debe incluir un archivo de índice index.md correspondiente y todos los documentos deben contener metadatos YAML (número de documento, título, tipo, estado, fecha, autor). La capa sin procesar, que sirve como fuente de información, se almacena por separado. Admite inicialización y mantenimiento incremental. Utilice esta habilidad cuando los usuarios necesiten crear documentos de gestión del conocimiento del proyecto, mantener documentos de activos del proyecto, planificar un sistema de documentación del proyecto o generar un directorio de documentos del proyecto.
