バッチ シミュレーション、自動データ生成、およびサーバー側のワークロードのために、「--no-window」を使用して Isaac Sim 6.0 をヘッドレスで実行します。起動モード (ネイティブ ヘッドレス、物理のみ、スタンドアロン Python)、主要な CLI フラグ、アプリ構成、および正規の `SimulationApp` ブートストラップ パターンをカバーします。次の場合に使用します: ディスプレイなしで Isaac Sim を起動する場合、サーバー上でバッチ シミュレーションを実行する場合、ヘッドレスで合成データを生成する場合、またはヘッドレスの `SimulationApp` ライフサイクルでスタンドアロン Python スクリプトをラップする場合。トリガー: ヘッドレス Isaac Sim、--ウィンドウなし、バッチ シミュレーション、SimulationApp、物理のみ、スタンドアロン Python スクリプト。
