Esecuzione headless di Isaac Sim 6.0 con `--no-window` per simulazione batch, generazione automatizzata di dati e carichi di lavoro lato server. Copre le modalità di lancio (headless nativo, solo fisica, Python autonomo), i principali flag CLI, le configurazioni delle app e il modello di bootstrap canonico "SimulationApp". Da utilizzare quando: si avvia Isaac Sim senza display, si eseguono simulazioni batch su un server, si generano dati sintetici headless o si inserisce uno script Python autonomo nel ciclo di vita headless `SimulationApp`. Si attiva su: Isaac Sim senza testa, --no-window, simulazione batch, SimulationApp, solo fisica, script Python autonomo.
