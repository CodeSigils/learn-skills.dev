Exécution d'Isaac Sim 6.0 sans tête avec `--no-window` pour la simulation par lots, la génération automatisée de données et les charges de travail côté serveur. Couvre les modes de lancement (Python natif sans tête, physique uniquement, autonome), les indicateurs CLI clés, les configurations d'application et le modèle d'amorçage canonique « SimulationApp ». À utiliser lorsque : lancer Isaac Sim sans écran, exécuter des simulations par lots sur un serveur, générer des données synthétiques sans tête ou encapsuler un script Python autonome dans le cycle de vie sans tête `SimulationApp`. Se déclenche sur : Isaac Sim sans tête, --no-window, simulation par lots, SimulationApp, script Python autonome uniquement pour la physique.
