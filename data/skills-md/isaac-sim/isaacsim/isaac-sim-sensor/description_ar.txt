محاكاة المستشعر في Isaac Sim 6 / Kit 110 مع جهاز النسخ. المكدس الحديث: `isaacsim.sensors.experimental.rtx` (كاميرات RTX، الليدار، الرادار، الصوتية) و`isaacsim.sensors.experimental.physics` (الاتصال، IMU، الجهد، الحالة المشتركة، raycast). يغطي كتالوج البائعين `SUPPORTED_LIDAR_CONFIGS` (أمثلة Ouster، وHesai، وVelodyne، وRobosense، وSICK، وZvision، وNVIDIA)، ومرفق أصول USDA بحوامل الروبوت، وتأليف نمط المسح المخصص (مصفوفات حالة الباعث)، والمعلقين التوضيحيين `omni.replicator.core`، والكتاب (`BasicWriter`، و`PoseWriter`، "KittiWriter"، و"CosmosWriter"، والتوزيع العشوائي، وسير عمل "isaacsim.replicator.episode_recorder" / "isaacsim.replicator.grasping". يُستخدم عند إعداد مستشعرات RGB / العمق / التجزئة / الليدار / الرادار / الصوتي / IMU / الاتصال، أو ربط جهاز Lidar/الرادار للمورد USD بالروبوت، أو تأليف أنماط المسح، أو إنشاء بيانات تدريب تركيبية مع التوزيع العشوائي للمجال، أو إنشاء خطوط أنابيب إدراك متعددة AOV.
