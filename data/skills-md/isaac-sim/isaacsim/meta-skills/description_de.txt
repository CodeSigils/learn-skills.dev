Muster zum Strukturieren, Verfassen und Verbessern der Fähigkeiten von Agenten sowie das Meta-Skilling Framework (MSF) zur Entwicklung neuer Fähigkeiten von null bis kompetent. Behandelt Skill Routing, Chunked Processing, Kollaborationsprotokolle, Quality Gates, fünf MSF-Phasen (Discovery, Practice, Capture, Validation, Iteration), die SKILL.md-Vorlage und Stapelbarkeitsmuster. Verwenden Sie diese Funktion, wenn Sie neue Fertigkeiten erstellen, bestehende verbessern, Arbeitsabläufe für mehrere Fertigkeiten entwerfen, eine Fertigkeitshierarchie erstellen, überprüfen, ob eine vorhandene Fertigkeit iteriert werden muss, oder entscheiden, wie eine Domäne in Unterfertigkeiten zerlegt werden soll.
