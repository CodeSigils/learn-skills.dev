Преобразуйте описания роботов URDF и MJCF в доллары США для Isaac Sim 6 и Isaac Lab с помощью современных API `isaacsim.asset.importer.urdf` / `isaacsim.asset.importer.mjcf` (`URDFImporter` + `URDFImporterConfig`, `MJCFImporter` + `MJCFImporterConfig`). Охватывает конвейер пост-импорта `isaacsim.asset.transformer`, приложение `usd.schema.isaac.robot_schema` (IsaacRobotAPI, токены типа робота), циклический обмен URDF через `isaacsim.asset.exporter.urdf`, настройку RL против телеоптического привода, `make_instanceable` и Isaac Lab `convert_urdf.py` / `convert_mjcf.py` `config.yaml` поток. XACRO не анализируется ядром импортера URDF; либо импортируйте напрямую из работающего узла robot_description через isaacsim.ros2.urdf (RobotDefinitionReader / File -> Import from ROS2 URDF Node), либо предварительно разверните в автономном режиме с помощью xacro robot.xacro > robot.urdf. Используйте при переносе нового робота из URDF/MJCF в Isaac Sim или Isaac Lab, устранении неполадок с неправильными массами/поведением суставов/самостолкновения или экспорте долларов США обратно в URDF.
