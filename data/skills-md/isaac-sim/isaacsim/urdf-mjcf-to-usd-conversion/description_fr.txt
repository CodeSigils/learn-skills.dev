Convertissez les descriptions de robots URDF et MJCF en USD pour Isaac Sim 6 et Isaac Lab via les API modernes `isaacsim.asset.importer.urdf` / `isaacsim.asset.importer.mjcf` (`URDFImporter` + `URDFImporterConfig`, `MJCFImporter` + `MJCFImporterConfig`). Couvre le pipeline post-importation `isaacsim.asset.transformer`, l'application `usd.schema.isaac.robot_schema` (IsaacRobotAPI, jetons de type robot), l'aller-retour URDF via `isaacsim.asset.exporter.urdf`, la configuration du lecteur RL vs teleop, `make_instanceable` et Isaac Lab `convert_urdf.py` / Flux `convert_mjcf.py` `config.yaml`. XACRO n'est pas analysé par le noyau de l'importateur URDF ; soit importer directement à partir d'un nœud `robot_description` en cours d'exécution via `isaacsim.ros2.urdf` (`RobotDefinitionReader` / `File -> Import from ROS2 URDF Node`), soit pré-développer hors ligne avec `xacro robot.xacro > robot.urdf`. À utiliser lors de l'importation d'un nouveau robot de l'URDF/MJCF dans Isaac Sim ou Isaac Lab, pour résoudre les problèmes de masses/comportements communs/auto-collision incorrects, ou pour réexporter des USD vers URDF.
