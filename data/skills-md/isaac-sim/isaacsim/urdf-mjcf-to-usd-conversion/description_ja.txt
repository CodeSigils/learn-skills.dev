最新の `isaacsim.asset.importer.urdf` / `isaacsim.asset.importer.mjcf` API (`URDFImporter` + `URDFImporterConfig`、`MJCFImporter` + `MJCFImporterConfig`) を介して、Isaac Sim 6 および Isaac Lab の URDF および MJCF ロボット記述を USD に変換します。 「isaacsim.asset.transformer」ポストインポート パイプライン、「usd.schema.isaac.robot_schema」アプリケーション (IsaacRobotAPI、ロボットタイプのトークン)、「isaacsim.asset.exporter.urdf」を介した URDF ラウンドトリップ、RL とテレオプ ドライブのセットアップ、「make_instanceable」、および Isaac Lab をカバーします。 `convert_urdf.py` / `convert_mjcf.py` `config.yaml` フロー。 XACRO は URDF インポーター コアによって解析されません。 `isaacsim.ros2.urdf` を介して実行中の `robot_description` ノードから直接インポートするか (`RobotDefinitionReader` / `File -> Import from ROS2 URDF Node`)、または `xacro robot.xacro > robot.urdf` を使用してオフラインで事前展開します。新しいロボットを URDF/MJCF から Isaac Sim または Isaac Lab に取り込む場合、間違った質量/関節動作/自己衝突のトラブルシューティングを行う場合、または USD を URDF にエクスポートして戻す場合に使用します。
