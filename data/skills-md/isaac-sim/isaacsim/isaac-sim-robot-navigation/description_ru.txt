Навигация робота во время выполнения в NVIDIA Isaac Sim — вождение робота по сцене в реальном времени с помощью специального сценария. Охватывает загрузку политики RL (PolicyController), отслеживание траектории, подходы «физика против запекания против каждого кадра» для тяжелых этапов, предотвращение OOM графического процессора в сценах с разрешением 98K-prim, ошибки, связанные с временной шкалой / физикой Kit 110, и стандартный каталог спотовых маршрутов. Карты занятости, A*, кинематику и математические вычисления камеры см. в разделе `navigation-primitives`. Информацию о SDG для записи датчиков см. в разделе «mobility-gen». Используйте при навигации по роботу в реальном времени в вашем собственном сценарии Isaac Sim, выборе между симуляцией физики и предварительно запеченными преобразованиями для тяжелых этапов, отладке OOM графического процессора на больших сценах или устранении неполадок, связанных с зависанием физики Kit 110 после уничтожения + перезапуска. Запускается по: PolicyController, загрузке политики RL, отслеживанию траектории, запеканию по сравнению с физикой, покадровому преобразованию, навигации OOM на графическом процессоре, Kit 110 timeline.play, среде выполнения навигации робота.
