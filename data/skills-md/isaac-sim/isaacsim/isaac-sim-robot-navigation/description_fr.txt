Navigation du robot d'exécution dans NVIDIA Isaac Sim : piloter un robot à travers une scène en direct dans un script personnalisé. Couvre le chargement de la politique RL (PolicyController), le suivi de trajectoire, les approches physique vs cuit vs par image pour les étapes lourdes, l'évitement du MOO GPU sur les scènes 98K-prim, les pièges de la chronologie/physique spécifiques au Kit 110 et le catalogue d'itinéraires Spot standard. Pour les cartes d'occupation, A*, la cinématique et les calculs de caméra, voir « navigation-primitives ». Pour les ODD d'enregistrement par capteur, voir « mobility-gen ». À utiliser pour naviguer dans un robot en direct dans votre propre script Isaac Sim, choisir entre la simulation physique et les transformations prédéfinies pour les scènes lourdes, déboguer le MOO GPU sur de grandes scènes ou dépanner le blocage physique du Kit 110 après un kill + une relance. Déclencheurs sur : PolicyController, charge de politique RL, suivi de trajectoire, cuit contre physique, transformation par image, navigation GPU MOO, Kit 110 timeline.play, runtime de navigation robot.
