Stellen Sie über den TCP-Socket „isaacsim.code_editor.python_server“ (Port 8226) eine Verbindung zu einem laufenden Isaac Sim her, um Python remote auszuführen. Starten Sie Isaac Sim, senden Sie Code, erstellen/ändern Sie USD-Stufen, führen Sie Simulationen aus, machen Sie Ansichtsfenster- oder vollständige App-Screenshots, inspizieren/ändern Sie Prims, steuern Sie die Kamera, treten Sie in die Physik ein, lesen Sie Konsolenprotokolle, führen Sie Kit-Befehle aus. Funktioniert im Headless-Modus „--no-window“.
