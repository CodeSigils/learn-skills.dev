Trasforma una segnalazione di bug approssimativa, una richiesta di funzionalità, una nota di supporto o una richiesta pull in un breve problema in linguaggio semplice incentrato sul problema e sul comportamento desiderato. Da utilizzare quando un collaboratore chiede di semplificare un problema, spiegare a cosa serve un PR, creare il problema corrispondente per un PR, rimuovere i dettagli di implementazione da un report o richiama /simple-issue-description.
