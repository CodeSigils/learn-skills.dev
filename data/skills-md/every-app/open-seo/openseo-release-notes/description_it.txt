Taglia una versione OpenSEO: aumenta la versione, crea una bozza delle note di rilascio rivolte all'utente dai commit dall'ultimo tag, esegui una revisione + un passaggio di verifica del subagente e apri un PR "versione: vX.X.X". Da utilizzare quando l'utente chiede di preparare una versione, eseguire il bumping della versione o scrivere note di rilascio.
