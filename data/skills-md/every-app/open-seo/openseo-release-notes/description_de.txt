Schneiden Sie ein OpenSEO-Release ab – erhöhen Sie die Version, erstellen Sie benutzerbezogene Versionshinweise aus Commits seit dem letzten Tag, führen Sie einen Überprüfungs- und Subagenten-Verifizierungsdurchlauf durch und öffnen Sie eine „Release: vX.X.X“-PR. Verwenden Sie diese Option, wenn der Benutzer eine Version vorbereiten, die Version verbessern oder Versionshinweise schreiben möchte.
