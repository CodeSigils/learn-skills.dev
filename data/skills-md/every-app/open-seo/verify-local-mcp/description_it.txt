Verifica il server OpenSEO MCP end-to-end su un server di sviluppo locale: correttezza a livello di protocollo rispetto a DataForSEO reale, quindi una sonda consumer con agente headless che verifica l'ergonomia dello strumento (descrizioni, schemi, dimensioni di output, errori, flussi asincroni) senza che il manutentore guidi manualmente un client MCP. Utilizzare dopo aver aggiunto o modificato gli strumenti MCP o quando viene richiesto di verificare che l'MCP "funzioni" o "sia ergonomico".
