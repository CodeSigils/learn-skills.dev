Проверяет различия и PR на предмет корректности, безопасности и командных стандартов, с достоверными выводами по сегментам серьезности (Критический / Предложения / Приятно иметь). Используйте при просмотре запроса на включение, запроса на слияние, патча или различий; перед слиянием; после завершения функции; или когда пользователь говорит: «Просмотрите этот PR», «Проверьте это изменение», «Просмотрите мои различия», «Сделай ревью». Не используйте для ответа на полученные отзывы (используйте Awesome-code-review-feedback) или для внесения изменений только в документацию и только в форматирование.
