Überprüft Unterschiede und PRs auf Korrektheit, Sicherheit und Teamstandards, mit konfidenzbewerteten Ergebnissen in Schweregradbereichen (Kritisch / Vorschläge / Schön zu haben). Wird zum Überprüfen einer Pull-Anfrage, einer Merge-Anfrage, eines Patches oder eines Diffs verwendet. vor dem Zusammenführen; nach Abschluss einer Funktion; oder wenn der Benutzer „Diese PR überprüfen“, „Diese Änderung überprüfen“, „Mein Diff überprüfen“ oder „Rezension überprüfen“ sagt. Nicht verwenden, um auf erhaltenes Rezensions-Feedback zu antworten (verwenden Sie awesome-code-review-feedback) oder für Änderungen, die sich nur auf Dokumente oder nur auf die Formatierung beziehen.
