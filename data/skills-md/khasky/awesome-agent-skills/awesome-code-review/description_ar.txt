مراجعات الاختلافات والعلاقات العامة فيما يتعلق بالصحة والأمان ومعايير الفريق، مع النتائج المسجلة للثقة في مجموعات الخطورة (حرجة / اقتراحات / من الجيد الحصول عليها). يُستخدم عند مراجعة طلب سحب أو طلب دمج أو تصحيح أو فرق؛ قبل الدمج؛ بعد الانتهاء من الميزة؛ أو عندما يقول المستخدم "مراجعة هذه العلاقات العامة"، أو "التحقق من هذا التغيير"، أو "مراجعة الفرق الخاص بي"، أو "сделай евью". لا تستخدم للرد على تعليقات المراجعة التي تلقيتها (استخدم تعليقات مراجعة التعليمات البرمجية الرائعة) أو للمستندات فقط وتغييرات التنسيق فقط.
