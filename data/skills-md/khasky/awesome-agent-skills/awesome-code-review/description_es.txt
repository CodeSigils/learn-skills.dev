Revisa las diferencias y las relaciones públicas para determinar la corrección, la seguridad y los estándares del equipo, con hallazgos calificados con confianza en categorías de gravedad (crítico/sugerencias/es bueno tenerlo). Úselo al revisar una solicitud de extracción, solicitud de fusión, parche o diferenciación; antes de fusionarse; después de completar una función; o cuando el usuario dice "revisar este PR", "verificar este cambio", "revisar mi diferencia", "сделай ревью". No lo use para responder a los comentarios de revisión que recibió (use comentarios de revisión de código increíble) o para cambios solo de documentos y formato.
