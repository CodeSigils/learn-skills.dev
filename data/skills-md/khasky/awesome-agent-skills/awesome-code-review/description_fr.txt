Examine les différences et les PR pour l'exactitude, la sécurité et les normes de l'équipe, avec des résultats notés par niveau de confiance dans des catégories de gravité (Critique/Suggestions/Agréable à avoir). À utiliser lors de l'examen d'une demande d'extraction, d'une demande de fusion, d'un correctif ou d'une différence ; avant de fusionner ; après avoir terminé une fonctionnalité ; ou lorsque l'utilisateur dit « examiner ce PR », « vérifier ce changement », « examiner mon diff », « сделай ревью ». Ne pas utiliser pour répondre aux commentaires que vous avez reçus (utilisez Awesome-code-review-feedback) ou pour des modifications concernant uniquement la documentation et le formatage.
