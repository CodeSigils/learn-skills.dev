Diseña y escribe pruebas que detectan regresiones reales: ubicación (unidad/integración/E2E), fábricas y accesorios, afirmaciones de comportamiento primero, pruebas de caracterización para código heredado, pruebas de propiedad/fuzz para analizadores. Úselo cuando se le solicite 'escribir pruebas', 'agregar cobertura de prueba', 'probar este módulo', 'напиши тесты', cuando una corrección de errores necesita su prueba de regresión, o cuando una corrección de errores increíble, una revisión de código increíble o una auditoría de seguridad increíble requieren una prueba fallida o de regresión. No lo use para juzgar pruebas existentes en una revisión; use awesome-code-review; no para diagnosticar el error en sí: utilice awesome-bug-fix.
