Progetta e scrive test che rilevano regressioni reali: posizionamento (unità/integrazione/E2E), fabbriche e strutture, asserzioni basate sul comportamento, test di caratterizzazione per codice legacy, test di proprietà/fuzz per parser. Da utilizzare quando viene richiesto di "scrivere test", "aggiungere copertura test", "testare questo modulo", "fare test", quando una correzione di bug necessita del test di regressione o quando awesome-bug-fix, awesome-code-review o awesome-security-audit richiede un test di fallimento o di regressione. Non utilizzare per giudicare i test esistenti in una revisione: utilizzare awesome-code-review; non per diagnosticare il bug stesso: usa awesome-bug-fix.
