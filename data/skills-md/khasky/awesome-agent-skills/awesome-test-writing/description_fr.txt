Conçoit et écrit des tests qui détectent les régressions réelles : placement (unité/intégration/E2E), usines et montages, assertions axées sur le comportement d'abord, tests de caractérisation pour le code existant, tests de propriétés/fuzz pour les analyseurs. À utiliser lorsqu'on vous demande d'« écrire des tests », « ajouter une couverture de test », « tester ce module », « effectuer des tests », lorsqu'un correctif de bogue nécessite son test de régression, ou lorsqu'un correctif de bug génial, une révision de code géniale ou un audit de sécurité génial appelle un test d'échec ou de régression. Ne pas utiliser pour juger des tests existants dans une revue – utilisez Awesome-code-review ; pas pour diagnostiquer le bug lui-même – utilisez Awesome-bug-fix.
