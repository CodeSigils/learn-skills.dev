Repo-weite Prüfung und Bereinigung von KI-ähnlichem Code-Rauschen – Kommentare nach einer strengen Best-Practice-Leiste (überflüssige/erläuternde Codes löschen, aufgeblähte Inhalte komprimieren, veraltetes oder irreführendes beheben, nur tragendes Wissen behalten), plus ein schreibgeschützter Audit-Modus und ein Opt-in-Refactoring-Modus für vage Namen, toten/duplizierten/spekulativen Code und Überabstraktion – alles streng verhaltenserhaltend und verifiziert. Verwenden Sie diese Option immer dann, wenn der Benutzer Kommentare bereinigen/beschneiden/prüfen/komprimieren, „offensichtliche“ oder KI-generierte Kommentare entfernen, Code selbstdokumentierend oder für Menschen lesbar machen, Vibe-codierte Dateien (Code, nicht Prosa) entlasten, „Kommentare nur bei Bedarf“ oder YAGNI/KISS-Pass anwenden oder Dinge wie „чистка комментариев“, „убери лишние“ sagen möchte комментарии“, „comment hygiene“, „de-comment“, „почисти код“. Verwenden Sie dies auch, wenn bei einer Codeüberprüfung ein Aufblähen von Kommentaren oder Namensstörungen festgestellt wurde und der Benutzer möchte, dass dies im gesamten Repo und nicht Datei für Datei behoben wird. Nicht verwenden, um Prosa-, Markdown- oder Dokumentationstexte zu entlasten – verwenden Sie dafür awesome-humanize-en oder awesome-document-style.
