Audit et nettoyage à l'échelle du dépôt du bruit de code de type IA - commentaires sur une barre de bonnes pratiques stricte (supprimer les redondances/narrations, condenser les codes gonflés, corriger les informations obsolètes ou trompeuses, conserver uniquement les connaissances porteuses), ainsi qu'un mode d'audit en lecture seule et un mode de refactorisation opt-in pour les noms vagues, le code mort/dupliqué/spéculatif et l'abstraction excessive - tous strictement préservant le comportement et vérifiés. À utiliser chaque fois que l'utilisateur demande de nettoyer/élaguer/auditer/condenser les commentaires, de supprimer les commentaires « évidents » ou générés par l'IA, de rendre le code auto-documenté ou lisible par l'homme, de supprimer les fichiers codés par ambiance (code, pas de prose), d'appliquer un « commentaires uniquement lorsque cela est nécessaire » ou une passe YAGNI/KISS, ou de dire des choses comme « чистка комментариев », « убери лишние комментарии", "hygiène des commentaires", "dé-commentaire", "почисти код". À utiliser également lorsqu'une révision du code a détecté une surcharge des commentaires ou un bruit de nommage et que l'utilisateur souhaite que le problème soit corrigé à l'échelle du dépôt plutôt que fichier par fichier. Ne l'utilisez pas pour supprimer la prose, le Markdown ou le texte de la documentation - utilisez Awesome-humanize-en ou Awesome-document-style pour cela.
