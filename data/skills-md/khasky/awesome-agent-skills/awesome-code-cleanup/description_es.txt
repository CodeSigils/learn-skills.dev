Auditoría y limpieza de ruido de código similar a la IA en todo el repositorio: comentarios a una barra estricta de mejores prácticas (eliminar redundantes/narraciones, condensar inflados, corregir obsoletos o engañosos, mantener solo conocimiento de carga), además de un modo de auditoría de solo lectura y un modo de refactorización opcional para nombres vagos, código inactivo/duplicado/especulativo y abstracción excesiva, todo estrictamente verificado y preservando el comportamiento. Úselo siempre que el usuario solicite limpiar / podar / auditar / condensar comentarios, eliminar comentarios "obvios" o generados por IA, hacer que el código sea autodocumentado o legible por humanos, eliminar archivos codificados en formato vibe (código, no prosa), aplicar "comentarios solo cuando sea necesario" o pase YAGNI/KISS, o diga cosas como "чистка комментариев", "убери лишние комментарии", "comentar higiene", "descomentar", "почисти код". Úselo también cuando una revisión de código encuentre comentarios excesivos o ruido en los nombres y el usuario quiera que se arregle en todo el repositorio en lugar de archivo por archivo. No lo use para eliminar prosa, Markdown o texto de documentación; use awesome-humanize-en o awesome-document-style para eso.
