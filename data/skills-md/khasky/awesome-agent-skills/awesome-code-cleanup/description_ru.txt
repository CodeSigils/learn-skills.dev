Аудит всего репозитория и очистка кода, похожего на искусственный интеллект — комментарии к строгой панели лучших практик (удалять избыточный/повторяющийся код, сокращать раздутый код, исправлять устаревшие или вводящие в заблуждение знания, сохранять только несущую нагрузку информацию), а также режим аудита только для чтения и режим рефакторинга с возможностью выбора для расплывчатых имен, мертвого/дублированного/спекулятивного кода и чрезмерной абстракции — все строго сохраняет поведение и проверяется. Используйте всякий раз, когда пользователь просит очистить / сократить / проверить / сжать комментарии, удалить «очевидные» или созданные искусственным интеллектом комментарии, сделать код самодокументируемым или удобочитаемым, удалить файлы с кодом vibe (код, а не прозу), применить «комментарии только при необходимости» или пройти YAGNI/KISS или сказать такие вещи, как «чистка комментариев», «убери лишние комментарии», «гигиена комментариев», «декомментировать», «почистить код». Также используйте, когда проверка кода обнаружила раздутые комментарии или шум в именах, и пользователь хочет, чтобы это было исправлено для всего репозитория, а не для каждого файла. Не используйте для удаления прозы, Markdown или текста документации — используйте для этого Awesome-humanize-en или Awesome-Document-style.
