Installez ou personnalisez la ligne d'état Claude Code - la barre d'une ligne sous l'invite qui affiche le nom du modèle, l'effort de raisonnement, le répertoire actuel, la branche git et l'indicateur sale, ainsi que le contexte utilisé. Regroupe un script bash colorisé prêt à l'emploi ainsi qu'un programme d'installation à une seule commande qui connecte settings.json et documente le contrat stdin JSON afin que les segments et les couleurs puissent être modifiés en toute confiance. Utilisez-le chaque fois que l'utilisateur mentionne son paramètre statusline / status line / statusLine, demande d'afficher le modèle, le niveau d'effort, le répertoire de travail, la branche git ou le pourcentage de contexte dans sa barre d'invite, souhaite restyler ou réorganiser ce qui est déjà là, souhaite que la même ligne d'état soit configurée sur une autre machine ou partagée avec un dépôt, ou signale que sa ligne d'état est vide, cassée ou affichant des informations obsolètes ou erronées - même s'il ne prononce jamais le mot "statusline".
