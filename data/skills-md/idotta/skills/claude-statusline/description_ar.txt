قم بتثبيت أو تخصيص سطر حالة Claude Code - الشريط المكون من سطر واحد أسفل الموجه الذي يعرض اسم النموذج وجهد الاستدلال والدليل الحالي وفرع git والعلامة القذرة والسياق المستخدم. يجمع برنامج نصي bash ملون جاهز بالإضافة إلى أداة تثبيت بأمر واحد تقوم بتوصيل settings.json، وتوثيق عقد stdin JSON بحيث يمكن تغيير المقاطع والألوان بثقة. استخدم هذا عندما يذكر المستخدم إعداد خط الحالة / خط الحالة / خط الحالة، أو يطلب إظهار النموذج أو مستوى الجهد أو دليل العمل أو فرع git أو النسبة المئوية للسياق في شريط المطالبة الخاص به، أو يريد إعادة تصميم أو إعادة ترتيب ما هو موجود بالفعل، أو يريد إعداد سطر الحالة نفسه على جهاز آخر أو مشاركته مع الريبو، أو الإبلاغ عن أن سطر الحالة الخاص به فارغ أو مكسور أو يعرض معلومات قديمة أو خاطئة - حتى عندما لا يقول كلمة "خط الحالة" مطلقًا.
