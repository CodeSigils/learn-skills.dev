Leggi, modifica, annota, commenta e crea file .docx di Microsoft Word. Utilizzare per compilare o modificare un documento Word, annotare un contratto con modifiche tracciate, aggiungere/risolvere commenti, sostituire il testo mantenendone la formattazione, ridisegnare intestazioni/caratteri, modificare tabelle o leggere/estrarre un .docx come Markdown o testo. COSTRUISCI anche un nuovo .docx, da Markdown o a livello di codice (codice che genera un report Word con intestazioni, tabelle, immagini). Non per PDF, Documenti Google, Excel, PowerPoint o .doc.
