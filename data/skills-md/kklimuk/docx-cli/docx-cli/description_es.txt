Lea, edite, marque, comente y cree archivos .docx de Microsoft Word. Úselo para completar o editar un documento de Word, marcar un contrato con seguimiento de cambios, agregar/resolver comentarios, reemplazar texto manteniendo su formato, cambiar el estilo de los encabezados/fuentes, editar tablas o leer/extraer un .docx como Markdown o texto. También CONSTRUYA un nuevo .docx, desde Markdown o mediante programación (código que genera un informe de Word con encabezados, tablas e imágenes). No para PDF, Google Docs, Excel, PowerPoint o .doc.
