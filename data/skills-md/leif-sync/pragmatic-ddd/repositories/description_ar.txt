[بنية DDD العملية] دليل لإنشاء مستودعات DDD (الواجهات والبنية التحتية). يُستخدم عند إنشاء عقود المستودع أو تنفيذها باستخدام Drizzle ORM وZod وPostgres. يفرض المعاملات المكتوبة بالكامل باستخدام أنواع Drizzle Transaction (بدون "غير معروف")، وإرجاع النتيجة للبرمجة الموجهة للسكك الحديدية عبر Neverthrow، وتعيين أخطاء عقدة pg لأخطاء المجال. يناسب سير عمل الاختبار القياسي الخاص بتركيب عامل الإرساء / طقم الرذاذ.
