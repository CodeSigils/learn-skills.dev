[Прагматичная архитектура DDD] Руководство по созданию репозиториев DDD (интерфейсы и инфраструктура). Используйте при создании контрактов репозитория или их реализации с помощью Drizzle ORM, Zod и Postgres. Обеспечивает полностью типизированные транзакции с типами транзакций Drizzle (без «неизвестных»), возвращает результат для программирования, ориентированного на железную дорогу, через Neverthrow и сопоставляет ошибки узла pg с ошибками домена. Подходит для нашего стандартного рабочего процесса тестирования docker-compose/drill-kit.
