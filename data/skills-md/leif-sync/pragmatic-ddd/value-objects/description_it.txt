[Architettura DDD pragmatica] Guida per la creazione di oggetti valore DDD (VO). Da utilizzare quando si definisce un nuovo oggetto valore in un livello di dominio. Copre modelli di immutabilità, costruttori privati, costruttori casuali/da, gestione degli errori orientata alle ferrovie tramite risultato neverthrow, tipi di errore con marchio TypeScript ed errori di co-localizzazione all'interno del file VO.
