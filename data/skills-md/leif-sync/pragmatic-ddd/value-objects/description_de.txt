[Pragmatische DDD-Architektur] Leitfaden zum Erstellen von DDD Value Objects (VOs). Verwenden Sie diese Option, wenn Sie ein neues Wertobjekt in einer Domänenebene definieren. Behandelt Unveränderlichkeitsmuster, private Konstruktoren, Zufalls-/From-Builder, Railway-orientierte Fehlerbehandlung über Neverthrow Result, TypeScript-Markenfehlertypen und Co-Location-Fehler innerhalb der VO-Datei.
