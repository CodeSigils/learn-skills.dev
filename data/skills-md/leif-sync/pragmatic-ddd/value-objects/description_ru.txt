[Прагматичная архитектура DDD] Руководство по созданию объектов значений DDD (VO). Используйте при определении нового объекта значения на слое домена. Охватывает шаблоны неизменности, частные конструкторы, случайные/от конструкторов, обработку ошибок, ориентированную на железную дорогу, с помощью никогда не выбрасываемого результата, фирменные типы ошибок TypeScript и ошибки совместного размещения в файле VO.
