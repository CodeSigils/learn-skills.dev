[Architecture pragmatique DDD] Guide de création d'objets de valeur DDD (VO). À utiliser lors de la définition d'un nouvel objet de valeur dans une couche de domaine. Couvre les modèles d'immuabilité, les constructeurs privés, les constructeurs aléatoires/depuis, la gestion des erreurs orientée chemin de fer via Neverthrow Result, les types d'erreurs de marque TypeScript et les erreurs de colocalisation dans le fichier VO.
