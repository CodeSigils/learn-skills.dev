[Arquitectura pragmática DDD] Guía para crear errores de infraestructura y validación de dominio estrictamente tipados. Úselo al manejar o crear nuevos errores para garantizar que se ajusten al modelo de programación orientado al ferrocarril (resultado nunca lanzado), la marca de error de TypeScript y las restricciones de los parámetros del constructor. Cubre las reglas de coubicación versus el uso de errores de dominio compartido.
