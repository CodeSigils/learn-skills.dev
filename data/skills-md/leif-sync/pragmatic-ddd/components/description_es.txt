[Arquitectura pragmática DDD] Guía para componentes de servidor y cliente en Next.js App Router. Úselo al crear cualquier archivo .tsx en presentación/componentes/, páginas o diseños, también al decidir si agregar "usar cliente" a un componente existente, pasar datos de un componente de servidor a un componente de cliente, componer contenido de servidor dentro de una ranura de cliente, manejar el límite de serialización de VO, crear componentes compuestos, separar la lógica para pantallas móviles/de escritorio o diseñar con `cva` y `cn`. Cubre: decisión de servidor versus cliente, patrones de componentes de servidor asíncronos, creación de devoluciones de llamada getSession para casos de uso, restricciones de componentes de cliente, patrón de límites toBranded(), composición de ranuras secundarias y reglas de interfaz de accesorios. Depende de los 'casos de uso' y las 'acciones del servidor'.
