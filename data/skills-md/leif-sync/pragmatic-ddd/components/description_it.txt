[Architettura Pragmatic DDD] Guida per i componenti server e client nel router dell'app Next.js. Da utilizzare quando si crea qualsiasi file .tsx in presentazione/componenti/, pagine o layout, anche quando si decide se aggiungere "usa client" a un componente esistente, passando dati da un componente server a un componente client, componendo contenuto server all'interno di uno slot client, gestendo il limite di serializzazione VO, creando componenti composti, separando la logica per schermi mobili/desktop o applicando stili con `cva` e `cn`. Argomenti: decisione server vs client, modelli di componenti server asincroni, creazione di callback getSession per casi d'uso, restrizioni dei componenti client, modello di confine toBranded(), composizione degli slot secondari e regole dell'interfaccia props. Dipende dai "casi d'uso" e dalle "azioni del server".
