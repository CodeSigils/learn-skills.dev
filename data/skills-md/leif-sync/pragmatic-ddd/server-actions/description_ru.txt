[Прагматичная архитектура DDD] Руководство по созданию действий сервера Next.js, точно привязанных к zod, Neverthrow и архитектуре домена. Используйте при создании или редактировании любого файла в презентации/действиях/. Охватывает размещение «использовать сервер», неизвестные параметры, проверяемые с помощью «zod», типы ответов распознаваемого объединения, шаблон аутентификации, проверку объекта значения с сужением TypeScript, сопоставление ошибок варианта использования с помощью «assertNever», вызов serviceContainer и стратегию повторной проверки.
