[Architecture pragmatique DDD] Guide pour créer des actions de serveur Next.js exactement liées à zod, neverthrow et à l'architecture de domaine. À utiliser lors de la création ou de la modification d'un fichier dans présentation/actions/. Couvre le placement « utiliser le serveur », les paramètres inconnus validés avec « zod », les types de réponse d'union discriminés, le modèle d'authentification d'abord, la validation de l'objet de valeur avec le rétrécissement de TypeScript, le mappage des erreurs de cas d'utilisation via « assertNever », l'invocation de serviceContainer et la stratégie de revalidation.
