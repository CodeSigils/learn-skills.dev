Fertigkeit zur vollständigen Erstellung von Langformromanen in chinesischer Sprache (v1.0.0). Wenn ein Benutzer einen Roman schreiben, eine Geschichte erstellen, ein Kapitel fortsetzen, eine Handlung entwerfen, eine Weltanschauung aufbauen, Charakterbeziehungen entwerfen, einen Schreibstil extrahieren oder andere Romane imitieren möchte, muss diese Fähigkeit genutzt werden. Es deckt die gesamte Kette von vagen Ideen bis zu einem fertigen Produkt mit bis zu 3 Millionen Zeichen ab: Ideenfindung, Erstellung von Wissensgraphen, Gliederungsmanagement, Storyboard-Schreiben, Quality Gate, agentenübergreifende Überprüfung, Stilkalibrierung, Gliederungsänderungen in der Mitte des Kurses mit kaskadierenden Aktualisierungen. Selbst wenn der Benutzer einfach sagt „Hilf mir, eine Geschichte zu schreiben“ oder „Ich habe eine Idee für einen Roman“, sollte dieser Skill ausgelöst werden.
