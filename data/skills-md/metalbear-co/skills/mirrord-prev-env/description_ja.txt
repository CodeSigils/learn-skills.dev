ユーザーがミラード プレビュー環境を作成および管理できるようにします。変更されたサービスを共有 Kubernetes クラスター内の分離ポッドとして実行し、環境キーと HTTP/キュー トラフィック フィルタリングによってスコープが設定されるため、チームはライブ サービスに影響を与えることなく、実際のトラフィックに対して変更を検証およびレビューできます。開発者が「ミラード プレビュー」をアドホックに実行する場合、リンク (mirrord-share-ingress) 経由でプレビューを共有する場合、または metalbear-co/mirrord-preview GitHub アクションを使用してプレビュー環境を CI に接続する場合に使用します (例: PR ごとのプレビュー、最小権限のクラスター アクセス)。
