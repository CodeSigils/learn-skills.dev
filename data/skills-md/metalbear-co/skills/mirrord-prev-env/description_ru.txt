Помогите пользователям создавать зеркальные среды предварительного просмотра и управлять ими — запускайте измененный сервис в качестве изолированного модуля в общем кластере Kubernetes с областью действия ключа среды и фильтрацией трафика HTTP/очереди, чтобы команды могли проверять и просматривать изменения в сравнении с реальным трафиком, не затрагивая работающие сервисы. Используйте, когда разработчик хочет запустить «зеркальный предварительный просмотр» для конкретного случая, поделиться предварительным просмотром по ссылке (mirrord-share-ingress) или подключить среды предварительного просмотра к CI с помощью действия GitHub Metalbear-co/mirrord-preview (например, предварительный просмотр по PR, доступ к кластеру с наименьшими привилегиями).
