사용자가 미러링된 미리 보기 환경을 생성하고 관리할 수 있도록 지원합니다. 공유 Kubernetes 클러스터에서 격리된 포드로 수정된 서비스를 실행하고 환경 키와 HTTP/큐 트래픽 필터링으로 범위를 지정하므로 팀은 라이브 서비스에 영향을 주지 않고 실제 트래픽에 대한 변경 사항을 검증하고 검토할 수 있습니다. 개발자가 임시로 "미러 미리 보기"를 실행하거나, 링크(mirrord-share-ingress)를 통해 미리 보기를 공유하거나, metalbear-co/mirrord-preview GitHub Action(예: PR별 미리 보기, 최소 권한 클러스터 액세스)을 사용하여 미리 보기 환경을 CI에 연결하려는 경우에 사용하세요.
