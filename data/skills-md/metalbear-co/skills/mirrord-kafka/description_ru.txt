Помогает инженерам DevOps комплексно настраивать зеркальную функцию разделения очереди Kafka оператора. Создает YAML-файлы MirrordKafkaClientConfig и MirrordKafkaTopicsConsumer Kubernetes CRD, соответствующий раздел Mirrord.json Split_queues и руководство по значениям Helm. Используйте этот навык всякий раз, когда пользователь упоминает разделение Kafka с помощью зеркального отображения, MirrordKafkaClientConfig, MirrordKafkaTopicsConsumer, разделение очереди Kafka, разделение тем Kafka, настройку зеркального отображения с помощью Kafka, настройку Kafka для зеркального оператора или устранение неполадок в сеансах разделения Kafka. Также срабатывает, когда пользователи упоминают Split_queues с помощью Queue_type Kafka или спрашивают о подключении зеркального отображения к кластеру Kafka. Это функция зеркального отображения для команды/предприятия.
