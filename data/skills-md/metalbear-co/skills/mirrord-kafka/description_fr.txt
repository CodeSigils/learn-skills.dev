Aide les ingénieurs DevOps à configurer de bout en bout la fonctionnalité de répartition de file d'attente Kafka de Mirrord Operator. Génère les YAML MirrordKafkaClientConfig et MirrordKafkaTopicsConsumer Kubernetes CRD, la section Mirrord.json split_queues correspondante et les conseils de valeur Helm. Utilisez cette compétence chaque fois que l'utilisateur mentionne le fractionnement de Kafka avec Mirrord, MirrordKafkaClientConfig, MirrordKafkaTopicsConsumer, le fractionnement de file d'attente Kafka, le fractionnement de sujets Kafka, la configuration de Mirrord avec Kafka, la configuration de Kafka pour l'opérateur Mirrord ou le dépannage des sessions de fractionnement Kafka. Déclenchez également lorsque les utilisateurs mentionnent split_queues avec queue_type Kafka, ou demandent comment connecter Mirrord à un cluster Kafka. Il s'agit d'une fonctionnalité Team/Enterprise de Mirrord.
