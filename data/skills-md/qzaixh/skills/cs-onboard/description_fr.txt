Intégrer un nouveau référentiel ou un référentiel avec des documents dispersés dans le système CodeStable ; deux chemins sont automatiquement déterminés : pour un référentiel vide, construire le framework à partir de zéro ; pour les documents existants, effectuez un audit et un mappage de migration. Déclencheur : l'utilisateur dit « utiliser CodeStable dans ce projet », « configurer la structure CodeStable », « initialiser CodeStable » ou « migrer vers CodeStable ».
