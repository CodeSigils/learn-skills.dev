Integrieren Sie ein neues Repository oder ein Repository mit verstreuten Dokumenten in das CodeStable-System. Es werden automatisch zwei Pfade ermittelt: Erstellen Sie für ein leeres Repository das Framework von Grund auf. Führen Sie für vorhandene Dokumente ein Audit und eine Migrationszuordnung durch. Auslöser: Der Benutzer sagt „CodeStable in diesem Projekt verwenden“, „CodeStable-Struktur einrichten“, „CodeStable initialisieren“ oder „zu CodeStable migrieren“.
