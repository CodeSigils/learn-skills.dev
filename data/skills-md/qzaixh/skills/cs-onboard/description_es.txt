Integrar un nuevo repositorio o un repositorio con documentos dispersos en el sistema CodeStable; se determinan automáticamente dos rutas: para un repositorio vacío, construir el marco desde cero; para los documentos existentes, realice una auditoría más un mapeo de migración. Activador: el usuario dice "usar CodeStable en este proyecto", "configurar la estructura de CodeStable", "inicializar CodeStable" o "migrar a CodeStable".
