Ajoutez l'élément de connaissance du projet qui est trop bref pour mériter son propre document mais que l'IA doit connaître à chaque fois que CodeStable est lancé dans une section fixe de « .codestable/attention.md » — par exemple, les indicateurs de compilation spéciaux, les services qui doivent être démarrés avant l'exécution, les pièges de chemin, les alias de commande, les conventions de variables d'environnement. Déclencheur : l'utilisateur dit « prendre une note », « ajouter à attention.md », « le projet nécessite X pour se compiler », « à partir de maintenant, il a toujours besoin de Y » ou rencontre simplement un paramètre spécifique au projet qui peut être expliqué en une phrase.
