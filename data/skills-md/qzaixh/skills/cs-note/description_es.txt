Agregue el conocimiento del proyecto que es demasiado breve para merecer su propio documento, pero que la IA debe conocer cada vez que se inicia CodeStable en una sección fija de `.codestable/attention.md`; por ejemplo, indicadores de compilación especiales, servicios que deben iniciarse antes de ejecutarse, errores de ruta, alias de comandos, convenciones de variables de entorno. Desencadenante: el usuario dice "tomar nota", "agregar a atención.md", "el proyecto requiere X para compilar", "de ahora en adelante siempre necesita Y", o simplemente encuentra una configuración específica del proyecto que se puede explicar en una oración.
