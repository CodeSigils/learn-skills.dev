Intelligenter Git-Commit-Assistent. Verwenden Sie es nur, wenn es manuell vom Benutzer ausgelöst wird (geben Sie /commit ein oder fordern Sie explizit „提交代码“, „commit“ an). Stellen Sie relevante geänderte Dateien automatisch bereit, überprüfen Sie, ob der aktuelle Branch-Name mit dem Commit-Typ übereinstimmt, und erstellen Sie, falls nicht, automatisch einen neuen Branch und generieren Sie eine chinesische Commit-Nachricht, die der Spezifikation für konventionelle Commits entspricht. Rufen Sie diesen Skill nicht proaktiv auf, es sei denn, der Benutzer fordert ausdrücklich ein Commit an.
