Assistente di commit Smart Git. Utilizzato solo quando attivato manualmente dall'utente (inserire /commit o richiedere esplicitamente "codice commit", "commit"). Gestisci automaticamente i file modificati correlati, verifica se il nome del ramo corrente corrisponde al tipo di commit e, se non corrisponde, crea automaticamente un nuovo ramo, genera un messaggio di commit cinese conforme alla specifica Commit convenzionali. Non richiamare in modo proattivo questa abilità a meno che l'utente non richieda esplicitamente un commit.
