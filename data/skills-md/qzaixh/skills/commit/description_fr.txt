Assistant de validation Smart Git. Utilisez-le uniquement lorsqu'il est déclenché manuellement par l'utilisateur (entrez /commit ou demandez explicitement "提交代码", "commit"). Organisez automatiquement les fichiers modifiés pertinents, vérifiez si le nom de la branche actuelle correspond au type de validation et, si ce n'est pas le cas, créez automatiquement une nouvelle branche, générant un message de validation chinois conforme à la spécification Conventional Commits. N'invoquez pas cette compétence de manière proactive, sauf si l'utilisateur demande explicitement une validation.
