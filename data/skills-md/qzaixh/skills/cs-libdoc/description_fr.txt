Générez une documentation de référence entrée par entrée pour la surface publique de la bibliothèque (composants/fonctions/commandes), avec suivi de liste, prenant en charge à la fois les entrées uniques et le traitement par lots. La source d'information est le code source lui-même (différent du guide orienté tâches). Déclencheur : l'utilisateur dit « écrire la documentation de l'API », « la documentation des composants », « libdoc » ou, après acceptation, découvre les interfaces publiques nouvellement ajoutées.
