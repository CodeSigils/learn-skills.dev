Überprüfen Sie den Code auf Lesbarkeit und vereinfachen Sie ihn dann, damit er leicht verständlich und verständlich ist. Verwenden Sie diese Fertigkeit, wenn der Benutzer Code vereinfachen, die Lesbarkeit verbessern, für die Übergabe bereinigen, Code überschaubar machen, die Komplexität reduzieren, Klarheit schaffen, Boilerplates entfernen, Code für zukünftige Betreuer vorbereiten oder eine Codebasis leichter erlernbar machen möchte. Lösen Sie großzügig aus – jede Anfrage, die Lesbarkeit, Vereinfachung, Bereinigung oder „Verständlichkeit erleichtern“ betrifft, sollte diese Fähigkeit nutzen. Wird auch ausgelöst, wenn der Benutzer Dinge sagt wie „Überprüfen Sie dies“, „Bereinigen Sie dies“, „Räumen Sie dies auf“, „Machen Sie dies einfacher“, „Reduzieren Sie die Komplexität“, „Reduzieren Sie dies“, „Entfernen Sie das Rauschen“ oder „Ich möchte diesen Code beim nächsten Öffnen schnell verstehen“.
