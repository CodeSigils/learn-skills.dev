Это руководство по созданию нового содержимого шаблонов вариантов использования для репозитория Adobe Experience Platform Blueprint. Используйте этот метод при добавлении нового шаблона варианта использования, создании содержимого руководства по реализации или когда пользователь упоминает о добавлении шаблона на сайт Blueprint. Он обрабатывает весь рабочий процесс: сбор информации о шаблонах, создание файлов Markdown с правильной структурой шаблонов и обновление всех страниц перекрестных ссылок (TOC.md, обзор.md).
