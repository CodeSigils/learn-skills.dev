Questa è una guida per la creazione di nuovi contenuti di modelli di casi d'uso per il repository Adobe Experience Platform Blueprint. Utilizza questa tecnica quando aggiungi un nuovo modello di caso d'uso, crei contenuti guida all'implementazione o quando un utente menziona l'aggiunta di un modello al sito Blueprint. Gestisce l'intero flusso di lavoro: raccolta di informazioni sul modello, generazione di file Markdown con la struttura del modello corretta e aggiornamento di tutte le pagine di riferimento incrociato (TOC.md, panoramica.md).
