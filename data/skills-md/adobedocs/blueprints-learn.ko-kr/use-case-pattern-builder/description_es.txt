Esta es una guía para crear contenido de patrones de casos de uso nuevos para el repositorio Blueprint de Adobe Experience Platform. Utilice esta técnica cuando agregue un nuevo patrón de caso de uso, cree contenido de guía de implementación o cuando un usuario mencione agregar un patrón al sitio Blueprint. Maneja todo el flujo de trabajo: recopilar información de patrones, generar archivos Markdown con la estructura de plantilla correcta y actualizar todas las páginas de referencias cruzadas (TOC.md, Overview.md).
