Configura, crea e naviga nello standard dotagents: un sottile "router" AGENTS.md nella root del repository più una directory .agents/ nascosta (regole, contesto, memoria, personaggi, competenze, specifiche, registri, attività) che divide il contesto dell'agente in piccoli file per argomento caricati su richiesta (divulgazione progressiva). Usalo QUANDO l'utente menziona dotagents, dotagentsprotocol.com, la directory .agents/ o un "router AGENTS.md"; vuole organizzare, dividere, snellire o migrare un monolitico AGENTS.md / CLAUDE.md / .cursorrules in un contesto strutturato; desidera una configurazione dell'agente indipendente dal fornitore che ogni strumento (Claude, Cursor, Gemini, Copilot, LLM locali) possa leggere; oppure sta lavorando all'interno di un repository che GIÀ contiene una directory AGENTS.md o .agents/ e deve sapere come scoprire e caricare il giusto contesto. Copre anche il superset più ampio del "protocollo .agents" (livello ~/.agents/ globale, mcp.json, agenti secondari/attività/memorie strutturati e l'hub .agents per la condivisione delle configurazioni).
