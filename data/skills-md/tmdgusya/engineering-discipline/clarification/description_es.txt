Úselo cuando la solicitud de un usuario sea vaga, ambigua o poco especificada. Lanza un ciclo iterativo de preguntas y respuestas para resolver ambigüedades mientras un subagente explora el código base en paralelo. Genera un resumen de contexto claro y bien definido para que el usuario pueda planificar con precisión. Activadores de "Quiero...", "Necesito...", "construyamos...", "puedes ayudarme...", "deberíamos..." o cualquier solicitud cuyo alcance completo no esté claro de inmediato.
