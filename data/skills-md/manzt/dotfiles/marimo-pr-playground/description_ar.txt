تحقق من GitHub PR وقم بتدوير دفتر ملاحظات ماريمو تفاعلي يلخص التغيير ويتيح لك ممارسة الميزة الجديدة أو الإصلاح المباشر. استخدم هذه المهارة كلما أراد المستخدم استكشاف العلاقات العامة أو اختبارها أو مراجعتها بشكل تفاعلي - على سبيل المثال. "قم بالخروج من PR 1234 واسمح لي باللعب به"، أو "قم بإعداد ساحة لعب لهذه العلاقات العامة"، أو "أريد تجربة PR #567"، أو "استكشف هذه العلاقات العامة في دفتر ملاحظات"، أو حتى مجرد "مراجعة PR 42" عندما يكون القصد هو الاستكشاف العملي بدلاً من المراجعة على مستوى التعليمات البرمجية. يتم تشغيله أيضًا عندما يلصق المستخدم عنوان URL للعلاقات العامة لـ GitHub ويريد اختبار التغييرات، أو يقول أشياء مثل "دعني أجرب هذه الميزة" في سياق مناقشة العلاقات العامة.
