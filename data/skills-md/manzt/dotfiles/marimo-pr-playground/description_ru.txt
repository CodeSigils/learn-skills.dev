Ознакомьтесь с пиаром на GitHub и создайте интерактивный блокнот marimo, в котором суммируются изменения и который позволит вам протестировать новую функцию или исправить ее в реальном времени. Используйте этот навык всякий раз, когда пользователь хочет изучить, протестировать или просмотреть PR в интерактивном режиме — например, «оформить PR 1234 и позволить мне поиграть с ним», «создать площадку для этого PR», «Я хочу опробовать PR #567», «изучить этот PR в блокноте» или даже просто «пересмотреть PR 42», когда целью является практическое исследование, а не проверка на уровне кода. Также срабатывает, когда пользователь вставляет URL-адрес PR GitHub и хочет протестировать изменения или говорит что-то вроде «дайте мне попробовать эту функцию» в контексте PR-дискуссии.
