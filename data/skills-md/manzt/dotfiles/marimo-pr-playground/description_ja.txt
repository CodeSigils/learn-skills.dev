GitHub PR をチェックして、変更を要約したインタラクティブな marimo ノートブックを起動して、新しい機能を実行したり、ライブで修正したりできるようにします。ユーザーが対話形式で PR を探索、テスト実行、またはレビューしたい場合は常に、このスキルを使用します。 「PR 1234 をチェックアウトして、遊んでみましょう」、「この PR のプレイグラウンドをセットアップします」、「PR #567 を試してみたいです」、「ノートブックでこの PR を調べてください」、あるいは、コード レベルのレビューではなく実践的な探索が目的の場合は、単に「PR 42 をレビューしてください」でも構いません。また、ユーザーが GitHub PR URL を貼り付けて変更をテストしたい場合、または PR ディスカッションのコンテキストで「その機能を試してみましょう」などと言った場合にもトリガーされます。
