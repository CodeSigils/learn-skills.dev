GitHub PR을 확인하고 변경 사항을 요약하고 새로운 기능을 실행하거나 실시간으로 수정할 수 있는 대화형 마리모 노트북을 가동하세요. 사용자가 대화형으로 PR을 탐색, 테스트, 검토하고 싶을 때마다 이 기술을 사용하세요. "PR 1234를 확인하고 가지고 놀자", "이 PR을 위한 놀이터 설정", "PR #567을 시험해 보고 싶습니다", "이 PR을 노트북에서 탐색"하거나 의도가 코드 수준 검토가 아닌 실제 탐색인 경우 "PR 42 검토"도 가능합니다. 또한 사용자가 GitHub PR URL을 붙여넣고 변경 사항을 테스트하려고 하거나 PR 토론의 맥락에서 "해당 기능을 사용해 보겠습니다"와 같은 말을 할 때 트리거됩니다.
