Consulte un PR de GitHub y cree un cuaderno marimo interactivo que resuma el cambio y le permita ejercitar la nueva función o corregirla en vivo. Utilice esta habilidad siempre que el usuario quiera explorar, probar o revisar un PR de forma interactiva, p. "consulte el PR 1234 y déjeme jugar con él", "prepare un campo de juego para este PR", "Quiero probar el PR #567", "explore este PR en un cuaderno" o incluso simplemente "revise el PR 42" cuando la intención es una exploración práctica en lugar de una revisión a nivel de código. También se activa cuando el usuario pega una URL de relaciones públicas de GitHub y quiere probar los cambios, o dice cosas como "déjame probar esa característica" en el contexto de una discusión de relaciones públicas.
