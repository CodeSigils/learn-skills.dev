Dai un'occhiata a un PR di GitHub e avvia un taccuino Marimo interattivo che riassume il cambiamento e ti consente di esercitare la nuova funzionalità o risolverla dal vivo. Utilizza questa competenza ogni volta che l'utente desidera esplorare, testare o rivedere un PR in modo interattivo, ad es. "controlla PR 1234 e lasciami giocare", "crea un parco giochi per questo PR", "Voglio provare PR # 567", "esplora questo PR su un taccuino" o anche semplicemente "rivedi PR 42" quando l'intento è l'esplorazione pratica piuttosto che una revisione a livello di codice. Si attiva anche quando l'utente incolla un URL PR di GitHub e desidera testare le modifiche o dice cose come "fammi provare quella funzionalità" nel contesto di una discussione di pubbliche relazioni.
