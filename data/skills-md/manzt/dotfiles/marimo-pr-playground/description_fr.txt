Consultez un PR GitHub et créez un bloc-notes marimo interactif qui résume le changement et vous permet d'exercer la nouvelle fonctionnalité ou de la corriger en direct. Utilisez cette compétence chaque fois que l'utilisateur souhaite explorer, tester ou réviser un PR de manière interactive, par exemple. "consultez le PR 1234 et laissez-moi jouer avec", "créez un terrain de jeu pour ce PR", "Je veux essayer le PR #567", "explorez ce PR dans un cahier", ou même simplement "révisez le PR 42" lorsque l'intention est une exploration pratique plutôt qu'une révision au niveau du code. Déclenchez également lorsque l'utilisateur colle une URL PR GitHub et souhaite tester les modifications, ou dit des choses comme « laissez-moi essayer cette fonctionnalité » dans le contexte d'une discussion PR.
