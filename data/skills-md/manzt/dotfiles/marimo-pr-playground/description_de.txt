Schauen Sie sich eine GitHub-PR an und erstellen Sie ein interaktives Marimo-Notizbuch, das die Änderung zusammenfasst und es Ihnen ermöglicht, die neue Funktion zu testen oder live zu beheben. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine PR interaktiv erkunden, testen oder überprüfen möchte – z. „Schau dir PR 1234 an und lass mich damit spielen“, „richte einen Spielplatz für diese PR ein“, „Ich möchte PR #567 ausprobieren“, „erkunde diese PR in einem Notizbuch“ oder einfach nur „PR 42 überprüfen“, wenn es eher um praktische Erkundung als um eine Überprüfung auf Codeebene geht. Wird auch ausgelöst, wenn der Benutzer eine GitHub-PR-URL einfügt und die Änderungen testen möchte oder im Kontext einer PR-Diskussion Dinge wie „Lass mich diese Funktion ausprobieren“ sagt.
