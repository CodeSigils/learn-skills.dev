marimo 自体を操作するためのライブ開発環境 (Python ランタイムと React フロントエンドの両方)。 marimo サーバー、Vite dev サーバー、およびヘッド付きブラウザを起動して、コードを編集し、変更をライブで確認し、両側から状態を検査できるようにします。このスキルは、ユーザーがマリモの内部のデバッグ、フロントエンド機能の開発、実行時の動作の視覚的なテスト、UI の反復、またはマリモ コードベースでのハンズオン開発を行う場合に使用します。トリガー: 「marimo のデバッグ」、「開発環境」、「フロントエンドの開始」、「これがどのようなものかを確認したい」、「ビジュアル テスト」、「DOM の検査」、または開発のために marimo と Vite を一緒に実行する必要があるタスク。
