Live-Entwicklungsumgebung für die Arbeit an Marimo selbst – sowohl der Python-Laufzeitumgebung als auch dem React-Frontend. Startet den Marimo-Server, den Vite-Dev-Server und einen Headed-Browser, sodass Sie Code bearbeiten, Änderungen live sehen und den Status von beiden Seiten überprüfen können. Verwenden Sie diese Fähigkeit, wenn der Benutzer Marimo-Interna debuggen, eine Frontend-Funktion entwickeln, das Laufzeitverhalten visuell testen, auf der Benutzeroberfläche iterieren oder praktische Entwicklungen an der Marimo-Codebasis durchführen möchte. Auslösen bei: „Marimo debuggen“, „Entwicklungsumgebung“, „Frontend starten“, „Ich möchte sehen, wie das aussieht“, „Visueller Test“, „DOM prüfen“ oder jede Aufgabe, die die gemeinsame Ausführung von Marimo + Vite für die Entwicklung erfordert.
