Erstellen Sie eine strukturierte Literaturübersicht zu einem beliebigen KI/ML-Thema. Der Agent kuratiert ein Forschungspaket (Taxonomie + Abschnitte + Bibliographie echter Arbeiten) aus einer öffentlichen Ankerressource, dann generiert ein ausgewählter LLM das Umfrageartefakt. Ausgabeziel ist eine Wiki-Seite (Markdown), kein einmaliges HTML – die Umfrage landet in „<wiki>/derived/surveys/<slug>.md“ mit vollständigen Bibliographiezeilen in „sources.md“. Anbieterunabhängig (Anthropic/OpenAI/OpenRouter/Fireworks/benutzerdefinierte OpenAI-kompatibel). Verwenden Sie diese Option, wenn der Benutzer eine „Umfrage“, „Literaturrezension“, „Literaturrezension“ oder „detaillierte Betrachtung“ zu einem technischen Thema anfordert.
