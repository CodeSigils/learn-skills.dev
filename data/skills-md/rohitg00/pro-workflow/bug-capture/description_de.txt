Erfassen Sie einen vom Benutzer gemeldeten Fehler als dauerhaftes GitHub-Problem, das in der projekteigenen Domänensprache geschrieben ist. Durchsucht die Codebasis parallel nach Kontext, lässt jedoch niemals Dateipfade oder Zeilennummern in das Problem einfließen. Verwenden Sie diese Option, wenn der Benutzer im Gespräch einen Fehler meldet, einen QS-Durchlauf durchführt oder sagt: „Ein Problem melden“, „Dies als Fehler protokollieren“ oder „Dies erfassen“.
