التقط عيبًا أبلغ عنه المستخدم باعتباره مشكلة GitHub دائمة مكتوبة بلغة المجال الخاصة بالمشروع. يستكشف قاعدة التعليمات البرمجية بالتوازي مع السياق ولكن لا يسرب مسارات الملفات أو أرقام الأسطر أبدًا في المشكلة. يُستخدم عندما يبلغ المستخدم عن خطأ أثناء المحادثة، أو يقوم بتشغيل تصريح ضمان الجودة، أو يقول "أرسل مشكلة"، أو "سجل هذا كخطأ"، أو "التقط هذا".
