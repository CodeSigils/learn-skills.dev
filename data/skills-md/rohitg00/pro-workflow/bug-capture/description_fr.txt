Capturez un défaut signalé par l'utilisateur en tant que problème GitHub durable écrit dans le langage de domaine propre au projet. Explorez la base de code en parallèle pour le contexte, mais ne divulgue jamais les chemins de fichiers ou les numéros de ligne dans le problème. À utiliser lorsque l'utilisateur signale un bug de manière conversationnelle, exécute une passe d'assurance qualité ou dit « signaler un problème », « enregistrer ceci comme un bug », « capturer ceci ».
