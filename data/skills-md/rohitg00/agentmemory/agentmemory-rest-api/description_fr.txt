Surface de l'API REST HTTP agentmemory, le protocole principal pour communiquer avec le serveur de mémoire. À utiliser lors de l'appel de la mémoire d'agent via HTTP, lorsque MCP n'est pas disponible et que vous avez besoin d'une solution de secours, ou lors de l'intégration d'un hôte qui ne parle pas MCP.
