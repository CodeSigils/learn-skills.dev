Tracez un fichier, une fonction ou une ligne jusqu'à la session d'agent qui a produit sa validation actuelle. À utiliser lorsque l'utilisateur demande « pourquoi ce code est-il ici », « que faisait l'agent lorsque cela a changé », « qui a écrit ceci » ou souhaite obtenir un contexte sur un emplacement spécifique dans la base de code.
