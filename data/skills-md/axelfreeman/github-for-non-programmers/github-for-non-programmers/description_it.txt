Configura un profilo e un repository GitHub per un non programmatore: profilo README, struttura del repository, AGENTS.md, README e primi commit. Da utilizzare quando un operatore di marketing, un imprenditore autonomo o qualsiasi non programmatore desidera creare o perfezionare la propria presenza su GitHub, creare un profilo professionale o pubblicare il proprio primo repository senza toccare un terminale.
