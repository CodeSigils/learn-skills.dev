Configure la configuración del agente de codificación compartida en equipo desde un repositorio de git. Úselo cuando el usuario desee instalar o configurar configuraciones compartidas en equipo para código abierto u otros agentes de codificación. Los activadores incluyen "configurar la configuración del equipo", "instalar la configuración del equipo", "configurar los ajustes del equipo" o "configurar la configuración del agente compartido".
