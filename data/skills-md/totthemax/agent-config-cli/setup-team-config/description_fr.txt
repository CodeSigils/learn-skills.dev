Configurez la configuration de l'agent de codage partagé par l'équipe à partir d'un référentiel git. À utiliser lorsque l'utilisateur souhaite installer ou configurer des paramètres partagés par l'équipe pour l'opencode ou d'autres agents de codage. Les déclencheurs incluent « configurer la configuration de l'équipe », « installer la configuration de l'équipe », « configurer les paramètres de l'équipe » ou « configurer la configuration de l'agent partagé ».
