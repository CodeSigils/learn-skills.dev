استخدم هذه المهارة عند إجراء عمليات تدقيق تحسين محركات البحث، أو تحسين محركات بحث الذكاء الاصطناعي (نظرات عامة حول الذكاء الاصطناعي، أو ChatGPT، أو Perplexity)، أو إنشاء علامات المخطط، أو تشخيص حالات انخفاض حركة المرور، أو إصلاح مؤشرات الويب الأساسية، أو إدارة عمليات ترحيل الموقع، أو إنشاء إستراتيجيات الكلمات الرئيسية. سجلت عمليات التشغيل عمليات تدقيق كاملة للموقع (0-100 نقطة صحية) عبر 21 وحدة بما في ذلك تحسين محركات البحث الفنية، وE-E-A-T، وhreflang، وتحسين محركات البحث الآلي. ثلاثة أوضاع: التدقيق، التخطيط، التنفيذ. ليس مخصصًا للدفع لكل نقرة (PPC)/الإعلانات، أو إدارة وسائل التواصل الاجتماعي، أو استراتيجية التسويق العامة التي لا علاقة لها بالبحث العضوي.
