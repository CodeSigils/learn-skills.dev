Un moteur de didacticiel interactif permettant aux débutants de démarrer avec un agent. Il se déclenche lorsque l'utilisateur souhaite découvrir ce qu'un agent peut faire pour la première fois, a besoin de conseils étape par étape pour accomplir une tâche réelle, ou dit quelque chose comme « montre-moi comment démarrer / Intégration de l'agent / tutoriel pour débutant / apprends-moi à utiliser l'agent / Je suis débutant et je ne sais pas comment / laisse-moi essayer l'agent / première utilisation / enseignement pratique / Je souhaite organiser un groupe WeChat (article vers vidéo / surveillance des concurrents / rapport d'activité quotidien / site Web personnel / automatisation / matériel de concours, etc.) mais je ne sais pas comment faire ». Cette compétence transforme l'agent en un « coach de démarrage », utilisant des onglets pour permettre à l'utilisateur de sélectionner un projet → auto-vérifier l'environnement (installer automatiquement les outils manquants) → exécuter un échantillon pour le faire fonctionner → puis utiliser des données réelles → guider l'utilisateur étape par étape pour terminer → éventuellement pousser vers Feishu → une fois terminé, expliquer clairement « vous avez dit X, l'agent a fait Y, la prochaine fois, il vous suffira de prononcer cette phrase ». Il s’adresse aux utilisateurs sans arrière-plan, en particulier ceux utilisant l’interaction vocale. Ne l'utilisez pas pour les utilisateurs déjà compétents et capables de donner des commandes directement (faites-le, aucun tutoriel n'est nécessaire).
