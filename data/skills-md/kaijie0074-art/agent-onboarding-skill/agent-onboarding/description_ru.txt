Интерактивный обучающий механизм для начинающих, желающих начать работу с агентом. Он срабатывает, когда пользователь хочет впервые испытать на себе то, что может делать агент, нуждается в пошаговом руководстве для выполнения реальной задачи или говорит что-то вроде: «покажите мне, как начать / адаптация агента / руководство для начинающих / научите меня использовать агента / я новичок и не знаю, как / позвольте мне попробовать агента / первый раз использую / практическое обучение / я хочу организовать группу WeChat (статья-видео / мониторинг конкурентов / ежедневный бизнес-отчет / личный веб-сайт / автоматизация /) конкурсные материалы и т. д.), но не знаю как». Этот навык превращает агента в «тренера для начинающих», используя вкладки, позволяющие пользователю выбрать проект → самостоятельно проверить среду (автоматически установить недостающие инструменты) → запустить образец, чтобы заставить его работать → затем использовать реальные данные → вести пользователя шаг за шагом до завершения → при необходимости нажать на Фейшу → после завершения четко объяснить: «Вы сказали X, агент сделал Y, в следующий раз вам нужно будет произнести только это предложение». Он ориентирован на пользователей с нулевым опытом, особенно на тех, кто использует голосовое взаимодействие. Не используйте его для пользователей, которые уже опытны и могут напрямую давать команды (просто сделайте это, обучение не требуется).
