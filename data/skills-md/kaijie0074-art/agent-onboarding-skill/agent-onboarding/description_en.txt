An interactive tutorial engine for beginners to get started with an Agent. It triggers when the user wants to experience what an Agent can do for the first time, needs step‑by‑step guidance to complete a real task, or says something like “show me how to get started / Agent onboarding / beginner tutorial / teach me to use the Agent / I’m a beginner and don’t know how / let me try the Agent / first time using / hands‑on teaching / I want to organize a WeChat group (article‑to‑video / competitor monitoring / daily business report / personal website / automation / competition materials, etc.) but don’t know how”. This skill turns the Agent into a “starter coach”, using tabs to let the user select a project → self‑check the environment (automatically install missing tools) → run a sample to get it working → then use real data → guide the user step by step to finish → optionally push to Feishu → after completion, clearly explain “you said X, the Agent did Y, next time you only need to say this sentence”. It is aimed at users with zero background, especially those using voice interaction. Do not use it for users who are already proficient and can give commands directly (just do it, no tutorial needed).
