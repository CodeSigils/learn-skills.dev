Eine interaktive Tutorial-Engine für Anfänger zum Einstieg in einen Agenten. Es wird ausgelöst, wenn der Benutzer zum ersten Mal erleben möchte, was ein Agent tun kann, eine Schritt-für-Schritt-Anleitung benötigt, um eine echte Aufgabe zu erledigen, oder etwas sagt wie „Zeigen Sie mir, wie ich anfänge / Agent-Onboarding / Anfänger-Tutorial / Bringen Sie mir bei, den Agent zu verwenden / Ich bin Anfänger und weiß nicht wie / Lassen Sie mich den Agent ausprobieren / erstes Mal verwenden / praktisches Unterrichten / Ich möchte eine WeChat-Gruppe organisieren (Artikel-zu-Video / Mitbewerberüberwachung / täglicher Geschäftsbericht / persönliche Website / Automatisierung / Wettbewerbsmaterialien usw.), weiß aber nicht wie“. Diese Fähigkeit verwandelt den Agenten in einen „Starter-Coach“, der es dem Benutzer mithilfe von Registerkarten ermöglicht, ein Projekt auszuwählen → die Umgebung selbst zu überprüfen (fehlende Tools automatisch zu installieren) → ein Beispiel auszuführen, um es zum Laufen zu bringen → dann echte Daten zu verwenden → den Benutzer Schritt für Schritt zum Abschluss zu führen → optional an Feishu weiterzuleiten → nach Abschluss klar zu erklären: „Sie haben X gesagt, der Agent hat Y gesagt, das nächste Mal müssen Sie nur diesen Satz sagen.“ Es richtet sich an Benutzer ohne Hintergrundwissen, insbesondere an Benutzer, die Sprachinteraktion verwenden. Verwenden Sie es nicht für Benutzer, die bereits über Kenntnisse verfügen und Befehle direkt erteilen können (machen Sie es einfach, es ist kein Tutorial erforderlich).
