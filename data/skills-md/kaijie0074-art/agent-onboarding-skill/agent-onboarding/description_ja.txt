初心者がエージェントを使い始めるための対話型チュートリアル エンジン。これは、ユーザーがエージェントができることを初めて体験したい場合、実際のタスクを完了するために段階的なガイダンスが必要な場合、または「開始方法を教えてください / エージェントのオンボーディング / 初心者チュートリアル / エージェントの使い方を教えてください / 初心者なので方法がわかりません / エージェントを試してみます / 初めて使用してください / 実践的な指導 / WeChat グループを組織したいです (記事からビデオへ / 競合他社へ)モニタリング / ビジネス日報 / 個人 Web サイト / 自動化 / 競争資料など）しかし方法がわからない。」このスキルは、エージェントを「スターター コーチ」に変えます。タブを使用してユーザーにプロジェクトを選択させる→環境を自己チェック（欠落しているツールを自動的にインストールする）→サンプルを実行して機能させる→その後、実際のデータを使用する→ユーザーを段階的にガイドして完了する→オプションでフェイシュウにプッシュする→完了後、「あなたはXと言った、エージェントはYをした、次回はこの文だけを言うだけでよい」と明確に説明します。これは、知識のないユーザー、特に音声対話を使用するユーザーを対象としています。すでに熟練しており、コマンドを直接与えることができるユーザーには使用しないでください (チュートリアルは必要なく、ただ実行するだけです)。
