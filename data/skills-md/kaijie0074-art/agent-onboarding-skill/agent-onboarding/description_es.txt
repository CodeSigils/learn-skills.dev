Un motor de tutoriales interactivo para que los principiantes comiencen con un Agente. Se activa cuando un usuario quiere experimentar lo que un Agente puede hacer por primera vez, necesita que lo guíen paso a paso a través de una tarea real o dice frases como "muéstreme cómo comenzar / incorporación del agente / tutorial para principiantes / enséñeme a usar el Agente / Soy un novato, no sé cómo / déjeme probar el Agente / usándolo por primera vez / guíeme a través de él / Quiero organizar un grupo de WeChat (convertir artículos en video / monitoreo de la competencia / informe comercial diario / sitio web personal / tareas automatizadas/materiales de competencia, etc.) pero no sé cómo”. Esta habilidad convierte al Agente en un "entrenador de introducción", que utiliza pestañas para permitir al usuario seleccionar un proyecto → autoverificar el entorno (instalar automáticamente las herramientas que faltan) → ejecutar una muestra para verificar → luego ejecutar con datos reales → guiar al usuario paso a paso para completar la tarea → opcionalmente presionar a Feishu → terminar con un resumen claro: "Dijiste X, el Agente hizo Y; la próxima vez solo necesitas decir esta oración". Está dirigido a usuarios sin experiencia, especialmente aquellos que utilizan la interacción por voz. No debe usarse para usuarios que ya son competentes y pueden emitir comandos directos (simplemente hágalo, no se necesita tutorial).
