Un motor de tutoriales interactivo para que los principiantes comiencen con un Agente. Se activa cuando el usuario quiere experimentar lo que un Agente puede hacer por primera vez, necesita orientación paso a paso para completar una tarea real o dice algo como "muéstrame cómo empezar / incorporación del agente / tutorial para principiantes / enséñame a usar el Agente / Soy principiante y no sé cómo / déjame probar el Agente / uso por primera vez / enseñanza práctica / Quiero organizar un grupo de WeChat (artículo a video / monitoreo de la competencia / informe comercial diario / sitio web personal / automatización / materiales de competencia, etc.) pero no sé cómo”. Esta habilidad convierte al Agente en un “entrenador inicial”, usando pestañas para permitir al usuario seleccionar un proyecto → autoverificar el entorno (instalar automáticamente las herramientas que faltan) → ejecutar una muestra para que funcione → luego usar datos reales → guiar al usuario paso a paso para terminar → opcionalmente presionar a Feishu → después de completar, explique claramente “usted dijo X, el Agente hizo Y, la próxima vez solo necesita decir esta oración”. Está dirigido a usuarios sin antecedentes, especialmente aquellos que utilizan la interacción por voz. No lo use para usuarios que ya son competentes y pueden dar comandos directamente (simplemente hágalo, no se necesita tutorial).
