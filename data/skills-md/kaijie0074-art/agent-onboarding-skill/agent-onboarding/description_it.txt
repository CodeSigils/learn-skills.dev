Un motore di tutorial interattivo per i principianti per iniziare a utilizzare un agente. Si attiva quando l'utente vuole sperimentare cosa può fare un agente per la prima volta, ha bisogno di una guida passo dopo passo per completare un'attività reale o dice qualcosa del tipo "mostrami come iniziare / onboarding dell'agente / tutorial per principianti / insegnami a usare l'agente / sono un principiante e non so come / fammi provare l'agente / primo utilizzo / insegnamento pratico / voglio organizzare un gruppo WeChat (da articolo a video / monitoraggio della concorrenza / rapporto aziendale giornaliero / sito web personale / automazione / materiali del concorso, ecc.) ma non so come”. Questa abilità trasforma l'agente in un "coach iniziale", utilizzando le schede per consentire all'utente di selezionare un progetto → autocontrollare l'ambiente (installa automaticamente gli strumenti mancanti) → eseguire un campione per farlo funzionare → quindi utilizzare dati reali → guidare l'utente passo dopo passo fino al completamento → facoltativamente inviare a Feishu → dopo il completamento, spiegare chiaramente "hai detto X, l'agente ha fatto Y, la prossima volta devi solo dire questa frase". È rivolto agli utenti con zero background, in particolare quelli che utilizzano l'interazione vocale. Non utilizzarlo per utenti che sono già esperti e possono impartire comandi direttamente (fallo e basta, non è necessario alcun tutorial).
