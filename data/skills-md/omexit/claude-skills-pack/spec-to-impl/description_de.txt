Verwenden Sie diese Fähigkeit immer dann, wenn ein Benutzer ein Spezifikationsdokument (PRD, BRD, API-Spezifikation, User Story, Systemdesigndokument oder ein beliebiges strukturiertes Anforderungsdokument) bereitstellt und es aufschlüsseln und in mehrere Ausgabeartefakte implementieren möchte. Zu den Auslösern gehören: „Diese Spezifikation implementieren“, „Dies aus dem PRD erstellen“, „Diese Spezifikation in Code umwandeln“, „Artefakte aus diesem Dokument generieren“, „Diese End-to-End-Implementierung durchführen“, „Diese Spezifikation in Aufgaben aufteilen“, „1 bis N aus diesem Dokument implementieren“, „aus der Spezifikation planen und implementieren“ oder jederzeit, wenn der Benutzer ein Anforderungsdokument bereitstellt und mehrere Implementierungsausgaben erwartet (Codedateien, Testsuiten, API-Verträge, DB-Schemata, Architekturdiagramme usw.). Wird auch ausgelöst, wenn der Benutzer eine Mehrrollen-Aufgabenzuweisung, Implementierungsverfolgung oder Fortschrittsberichte für eine komplexe Lieferung wünscht. Diese Fähigkeit orchestriert ein Team spezialisierter Subagenten (Architekt, Backend, Frontend, Qualitätssicherung, DevOps) parallel, um die Ausführungszeit maximal zu verkürzen.
