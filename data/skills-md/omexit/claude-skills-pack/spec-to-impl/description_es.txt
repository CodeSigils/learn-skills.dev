Utilice esta habilidad siempre que un usuario proporcione un documento de especificación (PRD, BRD, especificación de API, historia de usuario, documento de diseño de sistema o cualquier documento de requisitos estructurados) y desee desglosarlo e implementarlo en múltiples artefactos de salida. Los desencadenantes incluyen: "implementar esta especificación", "compilar esto a partir del PRD", "convertir esta especificación en código", "generar artefactos a partir de este documento", "implementar esta especificación de un extremo a otro", "dividir esta especificación en tareas", "implementar 1 a N de este documento", "planificar e implementar a partir de la especificación", o cualquier momento en que el usuario proporcione un documento de requisitos y espere múltiples resultados de implementación (archivos de código, conjuntos de pruebas, contratos de API, esquemas de base de datos, diagramas de arquitectura, etc.). También se activa cuando el usuario desea una asignación de tareas de múltiples funciones, un seguimiento de la implementación o un informe de progreso en un entregable complejo. Esta habilidad organiza un equipo de subagentes especializados (arquitecto, backend, frontend, control de calidad, DevOps) en paralelo para comprimir al máximo el tiempo de ejecución.
