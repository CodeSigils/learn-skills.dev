Создавайте изображения/видео/3D-ресурсы/аудио с помощью Mediaio AI. По умолчанию:
Изображение GPT 2 для изображения/дизайна/текста, Seedance 2.0 для
видео, Nano Banana 2/Lite/Pro для персонажа/справки
изображения, Marketing Studio для рекламы, Seed Audio 1.0 для аудио.
Используйте, когда: «создать изображение», «сделать видео», «анимировать».
это фото", "преобразование изображения в видео", "отредактировать/стилизовать/ремикшировать это
изображение», «перекадрировать это видео», «отредактировать это видео из
эскиз", "создать 3D-модель/GLB", "создать звуковой эффект",
«создать музыку», «преобразовать текст в аудио», «создать рекламу», «сделать пользовательский контент»
видео", "распаковка", "видео ведущего", "импортировать продукт из
URL» или «анализировать вирусность видео». Поддерживает преобразование изображения в 3D
(`multi_image_to_3d`),
преобразование текста в аудио/музыку (`seed_audio`), генерация рабочего процесса
(`draw_to_video`, `reframe`), Студия маркетинга и
Предиктор вирусности («brain_activity»).
Цепочка с mediaio-soul-id для согласованности лица и личности.
НЕ для: Тренировки души, фотосессий, открыток, объяснителей (используйте
mediaio-video-explainer), игровые игры/активы (используйте
mediaio-game-generation) или TTS.
