生成图像和视频，通过当前已安装的 Media.io CLI。用于文本到图像、图像到图像、文本到视频、图像到视频、参考到视频以及在实时 `mediaio model list` 或 `mediaio workflow list` 中出现的已发布工作流。仅当其参数已独立验证时才能使用效果，因为当前 CLI 暴露 `effect list` 但不提供 `effect get`。在提交前始终发现确切的作业类型和模式。每次提交都会消耗用户的积分，因此务必先运行 `generate estimate`，向用户显示费用，并在用户明确批准前停止。使用可读的发现输出，在生成前上传本地文件，使用 `generate create` 提交，使用单独的 `generate wait` 命令等待，并使用 `generate download` 获取结果文件，而不是重新生成签名的结果 URL。在本地命令网络受沙盒限制的主机上，第一次网络化的 `mediaio` 或 `curl` Shell/Bash 工具调用必须在进程启动前请求主机批准。切勿通过在默认沙盒中运行来探测网络可用性。
