Полнофункциональное управление процессом разработки проекта. Создайте команду разработчиков и следуйте стандартному процессу исследования требований → просмотрите требования → спроектируйте решение → напишите код → протестируйте код → разверните и запустите. Автоматически создавайте каталог журнала разработки проекта, ведите список задач и сохраняйте документы решений в отдельной папке для каждой задачи.
