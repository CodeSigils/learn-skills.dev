Используйте при запуске Playwright через CLI терминала — «npx playwright test» (запуск теста), «codegen» (интерактивная запись), «screenshot» / «pdf» (однократные снимки) и сегментирование CI. НЕ для управления браузером в реальном времени с помощью агента (для этого используйте инструменты MCP `claude-in-chrome`).
