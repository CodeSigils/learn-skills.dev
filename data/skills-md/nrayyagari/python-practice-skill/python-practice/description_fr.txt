Générez des exercices de codage Python adaptatifs pour une maîtrise pratique étendue de Python : principes fondamentaux, POO, bibliothèque standard, tests, CLI, automatisation, services backend, FastAPI, Flask, automatisation AWS, gestion des données et scripts de production. À utiliser chaque fois que l'utilisateur souhaite pratiquer Python, apprendre les concepts Python, réviser le code Python, déboguer des programmes Python, créer des API backend, automatiser AWS avec Python ou mentionner des exercices Python, des défis, pytest, FastAPI, Flask, boto3, des scripts, des CLI ou l'automatisation. Les exercices doivent être créés dans des dossiers datés dans /home/laborant/repos/python-practice. La compétence suit les erreurs récurrentes et clarifie les questions dans la racine learning-log.md ; aucun script de suivi de progression ni base de données de progression dynamique n'est utilisé.
