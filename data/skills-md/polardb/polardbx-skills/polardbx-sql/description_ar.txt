كتابة ومراجعة وتكييف SQL لقواعد بيانات الوضع التلقائي لـ PolarDB-X 2.0 Distributed Edition (Enterprise Edition)، والتعامل بشكل صحيح مع الاختلافات بين PolarDB-X وMySQL (الجداول المقسمة، والفهارس الثانوية العالمية GSI، والفهارس العمودية CCI، والتسلسل، والمعاملات الموزعة، ومجموعات الجدول، وجداول TTL، وما إلى ذلك). مناسب لإنشاء SQL لتشغيله على PolarDB-X، أو ترحيل MySQL SQL إلى PolarDB-X، أو تصحيح مشكلات توافق PolarDB-X SQL.
