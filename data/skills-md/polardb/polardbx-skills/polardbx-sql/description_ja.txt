PolarDB-X 2.0 Distributed Edition (Enterprise Edition) の AUTO モード データベース用に SQL を作成、レビュー、調整し、PolarDB-X と MySQL の間の相違点 (パーティション テーブル、グローバル セカンダリ インデックス GSI、カラムナ インデックス CCI、シーケンス、分散トランザクション、テーブル グループ、TTL テーブルなど) を正しく処理します。 PolarDB-X で実行する SQL の生成、MySQL SQL の PolarDB-X への移行、または PolarDB-X SQL 互換性問題のデバッグに適しています。
