Schreiben, Überprüfen und Anpassen von SQL für PolarDB-X 2.0 Distributed Edition (Enterprise Edition) AUTO-Modus-Datenbanken unter korrekter Handhabung der Unterschiede zwischen PolarDB-X und MySQL (partitionierte Tabellen, globale Sekundärindizes GSI, Spaltenindizes CCI, Sequenz, verteilte Transaktionen, Tabellengruppen, TTL-Tabellen usw.). Geeignet zum Generieren von SQL zur Ausführung auf PolarDB-X, zum Migrieren von MySQL SQL zu PolarDB-X oder zum Debuggen von PolarDB-X SQL-Kompatibilitätsproblemen.
