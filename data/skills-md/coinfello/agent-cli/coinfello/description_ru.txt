Взаимодействуйте с CoinFello, используя @coinfello/agent-cli, чтобы создать интеллектуальную учетную запись, войти в систему с помощью SIWE, управлять делегированием, отправлять запросы с помощью субделегирования токенов ERC-20, управляемого сервером, и проверять статус транзакции. Используйте, когда пользователь хочет отправлять криптотранзакции с помощью подсказок на естественном языке, управлять делегированием смарт-аккаунтов или проверять результаты транзакций CoinFello.
