Interactúe con CoinFello usando @coinfello/agent-cli para crear una cuenta inteligente, iniciar sesión con SIWE, administrar delegaciones, enviar mensajes con subdelegaciones de tokens ERC-20 impulsadas por el servidor y verificar el estado de las transacciones. Úselo cuando el usuario desee enviar transacciones criptográficas a través de indicaciones en lenguaje natural, administrar delegaciones de cuentas inteligentes o verificar los resultados de las transacciones de CoinFello.
