Obligatoire pour le texte et le ton de la voix en néerlandais de la Gemeente Amsterdam. À utiliser pour les étiquettes de l'interface utilisateur, les boutons, les en-têtes, les messages d'erreur, les étiquettes de formulaire, le contenu des pages, les notifications, les descriptions, les info-bulles, le texte d'espace réservé, le contenu Web, les lettres, les e-mails, les documents de politique, les réponses des chatbots et autres écrits destinés à l'utilisateur. Couvre De Stijl van Amsterdam, Heldere Taal (B1), Eenvoudige Taal (A2), le langage inclusif, l'écriture active et le ton d'Amsterdam. À utiliser avec Amsterdam-Design-System lorsque le travail de l'interface utilisateur comprend du texte.
