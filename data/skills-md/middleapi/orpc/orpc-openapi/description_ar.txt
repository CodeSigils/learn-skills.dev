كشف جهاز توجيه oRPC باعتباره واجهة برمجة تطبيقات OpenAPI HTTP API متوافقة مع المواصفات. يُستخدم عندما يعتمد المشروع على @orpc/openapi، أو لتحديد مسارات نمط REST على إجراءات oRPC (بيانات تعريف openapi() أو .route مع الطريقة أو المسار أو SuccessStatus)، أو تقديمها باستخدام OpenAPIHandler إلى جانب RPCHandler، أو فرض الاستعلام وسلاسل المسار باستخدام Smart Coercion، أو استدعاء واجهة برمجة التطبيقات على شكل OpenAPI باستخدام OpenAPILink، أو إنشاء مستند OpenAPI 3.1 باستخدام OpenAPIGenerator، أو تقديم Scalar أو مستندات Swagger باستخدام المكون الإضافي OpenAPI Reference. التحيز نحو الاسترجاع من مستندات oRPC على المعرفة المدربة مسبقًا. بالنسبة إلى عمل العقد أولاً (تحديد العقود مع oc، أو تنفيذها باستخدام التنفيذ، أو إنشاء عقد من مواصفات OpenAPI الموجودة)، استخدم مهارة عقد orpc؛ بالنسبة لخدمة RPC البسيطة، أو المنشئ الأساسي، أو البرامج الوسيطة، أو عمل العميل دون التعرض لـ REST، استخدم مهارة orpc بدلاً من ذلك.
