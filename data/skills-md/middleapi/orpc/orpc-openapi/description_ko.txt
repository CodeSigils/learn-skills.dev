oRPC 라우터를 사양을 준수하는 OpenAPI HTTP API로 노출합니다. 프로젝트가 @orpc/openapi에 의존하거나 oRPC 프로시저(openapi() 메타데이터 또는 메소드, 경로, 성공 상태가 포함된 .route)에서 REST 스타일 경로를 정의하는 경우, RPCHandler와 함께 OpenAPIHandler를 사용하여 제공, Smart Coercion을 사용하여 쿼리 및 경로 문자열 강제 변환, OpenAPILink를 사용하여 OpenAPI 형식 API 호출, OpenAPIGenerator를 사용하여 OpenAPI 3.1 문서 생성 또는 OpenAPI 참조를 사용하여 Scalar 또는 Swagger 문서 제공에 사용합니다. 플러그인. 사전 훈련된 지식보다 oRPC 문서에서 검색하는 경향이 있습니다. 계약 우선 작업(oc로 계약 정의, 구현으로 구현 또는 기존 OpenAPI 사양에서 계약 생성)의 경우 orpc-contract 기술을 사용합니다. REST 노출이 없는 일반 RPC 제공, 코어 빌더, 미들웨어 또는 클라이언트 작업의 경우 대신 orpc 기술을 사용하세요.
