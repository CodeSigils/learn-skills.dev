oRPC ルーターを仕様に準拠した OpenAPI HTTP API として公開します。プロジェクトが @orpc/openapi に依存する場合、または oRPC プロシージャ (openapi() メタデータまたはメソッド、パス、successStatus を含む .route) で REST スタイルのルートを定義する場合、RPCHandler とともに OpenAPIHandler を使用してそれらを提供する場合、Smart Coercion を使用してクエリおよびパス文字列を強制する場合、OpenAPILink を使用して OpenAPI 形式の API を呼び出す場合、OpenAPIGenerator を使用して OpenAPI 3.1 ドキュメントを生成する場合、または Scalar または Swagger を提供する場合に使用します。 OpenAPI リファレンス プラグインに関するドキュメント。事前にトレーニングされた知識よりも、oRPC ドキュメントからの検索に偏りがある。コントラクトファーストの作業 (oc でコントラクトを定義、implement で実装、または既存の OpenAPI 仕様からコントラクトを生成) の場合は、 orpc-contract スキルを使用します。 REST を公開しないプレーンな RPC サービス、コア ビルダー、ミドルウェア、またはクライアント作業の場合は、代わりに orpc スキルを使用してください。
