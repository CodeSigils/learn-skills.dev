Создавайте, обслуживайте и вызывайте сквозные типобезопасные API с помощью oRPC v2. Используйте для любой задачи в проекте, которая зависит от пакетов `@orpc/*`, даже для изменения одной процедуры: определение процедур с помощью компоновщика ОС (.input/.output/.handler, любой валидатор стандартной схемы), сборка маршрутизаторов, промежуточного программного обеспечения и контекста, типобезопасные ошибки с ORPCError, обслуживание через RPCHandler на любом адаптере времени выполнения, вызов от клиентов на стороне сервера (call, createRouterClient) или клиентов на стороне клиента. (createORPCClient с RPCLink), интеграция TanStack Query или потоковая передача через SSE. Предварительно обученные знания oRPC описывают версию v1 и неверны для версии 2, поэтому загружайте этот навык, даже если изменение выглядит тривиальным. Склонность к извлечению из документов oRPC, а не к предварительно обученным знаниям. Для использования REST/OpenAPI отдайте предпочтение навыку orpc-openapi; для дизайна, ориентированного на контракт, — навык орп-контракта; для миграций tRPC или oRPC v1 — навык orpc-migrate.
