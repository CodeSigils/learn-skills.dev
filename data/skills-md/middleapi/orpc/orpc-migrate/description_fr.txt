Migrez les bases de code existantes vers l'oRPC actuel, couvrant le tRPC vers l'oRPC (encapsulage incrémentiel via l'intégration @orpc/trpc ou une réécriture complète avec le mappage de concept) et l'oRPC v1 vers v2 (renommage des packages, modifications avec rupture et ordre sécurisé des opérations). À utiliser lorsqu'on vous demande de migrer de tRPC vers oRPC, de convertir ou d'encapsuler un routeur tRPC, de mettre à niveau oRPC v1 vers v2, de corriger les modifications avec rupture d'oRPC v2 ou d'échanger les packages `@trpc/*` contre des équivalents `@orpc/*`. Biais en faveur de la récupération des documents oRPC par rapport aux connaissances pré-entraînées. Pas pour les nouveaux travaux oRPC ou les nouvelles fonctionnalités dans une base de code déjà migrée : utilisez la compétence orpc pour celles-ci.
