Diseñe el contrato de las API de oRPC v2 primero, definiendo la forma de la API con oc de `@orpc/contract`, implementándola con implement de `@orpc/server` y consumiendo el contrato de clientes con seguridad de tipos. Úselo cuando un proyecto depende de `@orpc/contract`, al definir un contrato con oc, implementar un contrato con implement, compartir un contrato API entre paquetes de servidor y cliente, generar un contrato a partir de una especificación OpenAPI existente o publicar un cliente API escrito en npm. Sesgos hacia la recuperación de documentos oRPC sobre el conocimiento previamente entrenado. Para trabajos de creación de núcleos, servicios y clientes sin contrato, utilice la habilidad orpc; para exposición REST/OpenAPI, generación de especificaciones y detalles de OpenAPILink, utilice la habilidad orpc-openapi.
