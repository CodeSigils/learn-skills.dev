oRPC v2 API를 계약 우선으로 설계하고 `@orpc/contract`에서 oc로 API 형태를 정의하고 `@orpc/server`에서 구현하여 이를 구현하고 형식이 안전한 클라이언트에서 계약을 사용합니다. 프로젝트가 `@orpc/contract`에 의존하는 경우, oc로 계약을 정의할 때, Implement로 계약을 구현할 때, 서버와 클라이언트 패키지 간에 API 계약을 공유할 때, 기존 OpenAPI 사양에서 계약을 생성할 때, 또는 형식화된 API 클라이언트를 npm에 게시할 때 사용합니다. 사전 훈련된 지식보다 oRPC 문서에서 검색하는 경향이 있습니다. 계약 없이 코어 빌더, 서빙 및 클라이언트 작업을 수행하려면 orpc 기술을 사용하세요.
