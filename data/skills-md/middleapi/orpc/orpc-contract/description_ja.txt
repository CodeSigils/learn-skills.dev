oRPC v2 API をコントラクトファーストで設計し、`@orpc/contract` の oc を使用して API シェイプを定義し、`@orpc/server` からのimplement を使用して実装し、タイプセーフなクライアントからコントラクトを消費します。プロジェクトが `@orpc/contract` に依存する場合、oc でコントラクトを定義する場合、implement でコントラクトを実装する場合、サーバーとクライアント パッケージ間で API コントラクトを共有する場合、既存の OpenAPI 仕様からコントラクトを生成する場合、または型指定された API クライアントを npm に公開する場合に使用します。事前にトレーニングされた知識よりも、oRPC ドキュメントからの検索に偏りがある。契約なしでコア ビルダー、サービス、クライアントの作業を行う場合は、orpc スキルを使用します。 REST/OpenAPI の公開、仕様の生成、OpenAPILink の詳細については、 orpc-openapi スキルを使用します。
