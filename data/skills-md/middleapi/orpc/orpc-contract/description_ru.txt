Проектируйте API oRPC v2 сначала по контракту, определяя форму API с помощью oc из `@orpc/contract`, реализуя ее с помощью реализации из `@orpc/server` и получая контракт от типобезопасных клиентов. Используйте, когда проект зависит от `@orpc/contract`, при определении контракта с oc, реализации контракта с внедрением, совместном использовании контракта API между пакетами сервера и клиента, создании контракта из существующей спецификации OpenAPI или публикации типизированного клиента API в npm. Склонность к извлечению из документов oRPC, а не к предварительно обученным знаниям. Для построения ядра, обслуживания и работы с клиентами без контракта используйте навык orpc; для ознакомления с REST/OpenAPI, создания спецификаций и подробностей OpenAPILink используйте навык orpc-openapi.
