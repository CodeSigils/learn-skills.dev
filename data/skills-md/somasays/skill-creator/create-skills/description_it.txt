Utilizza questa competenza ogni volta che l'utente desidera creare una nuova competenza di Claude, scrivere un file SKILL.md, trasformare un flusso di lavoro in una competenza riutilizzabile, creare pacchetti di istruzioni che Claude possa seguire o creare un'automazione personalizzata che Claude possa attivare. Da utilizzare anche quando l'utente dice "rendi questa un'abilità", "crea un'abilità per X", "voglio che Claude faccia sempre X" o chiede come funzionano le abilità. Copre l'anatomia delle competenze, i modelli di scrittura, l'ottimizzazione delle descrizioni, la divulgazione progressiva, i test e il confezionamento. Anche se l'utente menziona semplicemente la volontà di standardizzare un flusso di lavoro o creare istruzioni riutilizzabili, questa abilità si applica.
