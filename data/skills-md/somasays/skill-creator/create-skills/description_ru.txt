Используйте этот навык всякий раз, когда пользователь хочет создать новый навык Клода, написать файл SKILL.md, превратить рабочий процесс в навык многократного использования, упаковать инструкции для Клода, которым он будет следовать, или создать собственную автоматизацию, которую Клод сможет активировать. Также используйте, когда пользователь говорит «сделайте это навыком», «создайте навык для X», «Я хочу, чтобы Клод всегда делал X» или спрашивает, как работают навыки. Охватывает анатомию навыков, шаблоны написания, оптимизацию описаний, постепенное раскрытие информации, тестирование и упаковку. Даже если пользователь просто упоминает о желании стандартизировать рабочий процесс или создать многократно используемые инструкции, этот навык применим.
