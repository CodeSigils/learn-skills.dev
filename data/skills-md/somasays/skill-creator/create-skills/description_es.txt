Utilice esta habilidad siempre que el usuario quiera crear una nueva habilidad de Claude, escribir un archivo SKILL.md, convertir un flujo de trabajo en una habilidad reutilizable, empaquetar instrucciones para que Claude las siga o crear una automatización personalizada que Claude pueda activar. Úselo también cuando el usuario diga "haz de esto una habilidad", "crea una habilidad para X", "Quiero que Claude siempre haga X" o pregunta cómo funcionan las habilidades. Cubre anatomía de habilidades, patrones de escritura, optimización de descripciones, divulgación progresiva, pruebas y empaquetado. Incluso si el usuario simplemente menciona que desea estandarizar un flujo de trabajo o crear instrucciones reutilizables, esta habilidad se aplica.
