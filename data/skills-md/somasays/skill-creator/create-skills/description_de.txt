Verwenden Sie diesen Skill immer dann, wenn der Benutzer einen neuen Claude-Skill erstellen, eine SKILL.md-Datei schreiben, einen Workflow in einen wiederverwendbaren Skill umwandeln, Anweisungen verpacken möchte, denen Claude folgen soll, oder eine benutzerdefinierte Automatisierung erstellen möchte, die Claude auslösen kann. Wird auch verwendet, wenn der Benutzer sagt: „Machen Sie dies zu einer Fertigkeit“, „Erstellen Sie eine Fertigkeit für X“, „Ich möchte, dass Claude immer X ausführt“ oder fragt, wie Fertigkeiten funktionieren. Behandelt die Anatomie der Fertigkeiten, Schreibmuster, Beschreibungsoptimierung, progressive Offenlegung, Tests und Verpackung. Selbst wenn der Benutzer lediglich erwähnt, dass er einen Arbeitsablauf standardisieren oder wiederverwendbare Anweisungen erstellen möchte, ist diese Fähigkeit anwendbar.
