Cree un PRD a través de una entrevista con el usuario, exploración de la base de código y diseño del módulo, luego envíelo como un problema de GitHub después de la aprobación del usuario. Úselo cuando el usuario quiera escribir un PRD, crear un documento de requisitos de producto o planificar una nueva característica. Presente siempre el PRD para la aprobación del usuario antes de enviarlo.
