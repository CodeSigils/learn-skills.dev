Créez un PRD via un entretien avec l'utilisateur, l'exploration de la base de code et la conception de modules, puis soumettez-le en tant que problème GitHub après l'approbation de l'utilisateur. À utiliser lorsque l'utilisateur souhaite rédiger un PRD, créer un document sur les exigences du produit ou planifier une nouvelle fonctionnalité. Présentez toujours le PRD pour approbation de l’utilisateur avant de le soumettre.
