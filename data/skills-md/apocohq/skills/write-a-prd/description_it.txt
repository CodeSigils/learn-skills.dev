Crea un PRD attraverso il colloquio con l'utente, l'esplorazione della base di codice e la progettazione del modulo, quindi invialo come problema GitHub dopo l'approvazione dell'utente. Da utilizzare quando l'utente desidera scrivere un PRD, creare un documento sui requisiti del prodotto o pianificare una nuova funzionalità. Presentare sempre il PRD per l'approvazione dell'utente prima dell'invio.
