يُستخدم عند العمل مع blockchain للشبكة المفتوحة (TON)، أو عندما يذكر المستخدم مصطلحات النظام البيئي TON التي قد لا يتعرف عليها الوكيل - مثل Tact، أو FunC، أو Tolk، أو Fift، أو TL-B، أو TVM، أو cell، أو BoC، أو Jettons، أو TEPs، أو TON Connect، أو سلاسل العمل، أو shardchains، أو liteservers. يوفر سير عمل المستندات أولاً لجلب وثائق TON والتنقل فيها بدقة، ويغطي تطوير العقود الذكية وآليات المعاملات ومعايير المحفظة ومعايير الرموز المميزة وتطبيقات Telegram Mini والبنية التحتية.
