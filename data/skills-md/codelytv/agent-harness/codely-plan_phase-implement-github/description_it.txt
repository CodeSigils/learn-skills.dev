Implementare una fase di un piano archiviato come problemi GitHub nel repository della directory di lavoro corrente. Dato l'URL di un problema di fase (figlio), implementa quella fase; data la questione del piano genitore trova e implementa la fase attuale. Implementa solo una singola fase per invocazione, quindi si interrompe per la revisione dell'utente. Apre una richiesta pull che fa riferimento al problema della fase, quindi l'unione chiude il problema automaticamente. Non unisce mai la richiesta pull.
