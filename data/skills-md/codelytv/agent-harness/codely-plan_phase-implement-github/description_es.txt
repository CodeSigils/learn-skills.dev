Implemente una fase de un plan almacenado como problemas de GitHub en el repositorio del directorio de trabajo actual. Dada la URL de un problema de fase (secundario), implementa esa fase; dado el problema del plan principal, encuentra e implementa la fase actual. Solo implementa una única fase por invocación y luego se detiene para la revisión del usuario. Abre una solicitud de extracción que hace referencia al problema de fase, por lo que al fusionarlo se cierra el problema automáticamente. Nunca fusiona la solicitud de extracción.
