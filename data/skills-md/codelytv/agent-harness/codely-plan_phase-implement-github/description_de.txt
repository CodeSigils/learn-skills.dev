Implementieren Sie eine Phase eines Plans, der als GitHub-Probleme im Repository des aktuellen Arbeitsverzeichnisses gespeichert ist. Anhand der URL eines Phasenproblems (untergeordnetes Problem) wird diese Phase implementiert. Angesichts des übergeordneten Planproblems findet und implementiert es die aktuelle Phase. Implementiert nur eine einzelne Phase pro Aufruf und stoppt dann zur Überprüfung durch den Benutzer. Es öffnet eine Pull-Anfrage, die auf das Phasenproblem verweist, sodass das Problem durch das Zusammenführen automatisch geschlossen wird. Führt die Pull-Anfrage niemals zusammen.
