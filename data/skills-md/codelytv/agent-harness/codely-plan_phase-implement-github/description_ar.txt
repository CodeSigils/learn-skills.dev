قم بتنفيذ مرحلة واحدة من الخطة المخزنة كإصدارات GitHub في مستودع دليل العمل الحالي. بالنظر إلى عنوان URL لمشكلة المرحلة (الفرعية)، فإنه ينفذ تلك المرحلة؛ نظرًا لمشكلة الخطة الأصلية، فإنه يجد المرحلة الحالية وينفذها. ينفذ فقط مرحلة واحدة لكل استدعاء، ثم يتوقف لمراجعة المستخدم. فهو يفتح طلب سحب يشير إلى مشكلة المرحلة، لذا فإن دمجه يؤدي إلى إغلاق المشكلة تلقائيًا. لا تدمج طلب السحب مطلقًا.
