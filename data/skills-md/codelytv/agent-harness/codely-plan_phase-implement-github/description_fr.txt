Implémentez une phase d'un plan stocké sous forme de tickets GitHub dans le référentiel du répertoire de travail actuel. Étant donné l'URL d'un problème de phase (enfant), il implémente cette phase ; étant donné le problème du plan parental, il trouve et met en œuvre la phase actuelle. N'implémente qu'une seule phase par appel, puis s'arrête pour examen par l'utilisateur. Il ouvre une pull request qui fait référence au problème de phase, donc sa fusion ferme automatiquement le problème. Ne fusionne jamais la demande d'extraction.
