Реализуйте один этап плана, хранящегося в виде задач GitHub в репозитории текущего рабочего каталога. Учитывая URL-адрес фазовой (дочерней) проблемы, он реализует эту фазу; учитывая проблему родительского плана, он находит и реализует текущую фазу. Реализует только одну фазу для каждого вызова, а затем останавливается для проверки пользователем. Он открывает запрос на включение, который ссылается на фазовую проблему, поэтому его слияние автоматически закрывает проблему. Никогда не объединяет запрос на извлечение.
