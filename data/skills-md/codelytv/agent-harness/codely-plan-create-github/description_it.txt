Crea un piano per l'attività specificata e archivialo come problemi di GitHub nel repository della directory di lavoro corrente. Dato l'URL di un problema GitHub, trasforma quel problema nel problema del "piano" principale (obiettivo, contesto e un elenco di controllo delle fasi) e crea un problema figlio per fase, collegando ogni fase come un problema secondario GitHub nativo del genitore. Si ferma per l'approvazione dell'utente prima di creare qualsiasi problema. Dopo la creazione, il piano deve essere implementato con la competenza codely-plan_phase-implement-github.
