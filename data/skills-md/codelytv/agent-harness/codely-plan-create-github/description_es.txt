Cree un plan para la tarea especificada y guárdelo como problemas de GitHub en el repositorio del directorio de trabajo actual. Dada la URL de un problema de GitHub, convierte ese problema en el problema principal del "plan" (objetivo, contexto y una lista de verificación de fases) y crea un problema secundario por fase, vinculando cada fase como un subproblema nativo de GitHub del problema principal. Se detiene para la aprobación del usuario antes de crear cualquier problema. Después de la creación, el plan debe implementarse con la habilidad codely-plan_phase-implement-github.
