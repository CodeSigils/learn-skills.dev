Créez un plan pour la tâche spécifiée et stockez-le en tant que problèmes GitHub dans le référentiel du répertoire de travail actuel. Compte tenu de l'URL d'un problème GitHub, il transforme ce problème en problème « plan » parent (objectif, contexte et liste de contrôle des phases) et crée un problème enfant par phase, reliant chaque phase en tant que sous-problème GitHub natif du parent. S'arrête pour l'approbation de l'utilisateur avant de créer un problème. Après la création, le plan est destiné à être implémenté avec la compétence codely-plan_phase-implement-github.
