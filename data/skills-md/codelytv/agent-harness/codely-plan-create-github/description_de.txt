Erstellen Sie einen Plan für die angegebene Aufgabe und speichern Sie ihn als GitHub Issues im Repository des aktuellen Arbeitsverzeichnisses. Anhand der URL eines GitHub-Problems wird dieses Problem in das übergeordnete „Plan“-Problem umgewandelt (Ziel, Kontext und eine Checkliste der Phasen) und ein untergeordnetes Problem pro Phase erstellt, wobei jede Phase als natives GitHub-Unterproblem des übergeordneten Problems verknüpft wird. Hält an, um die Genehmigung des Benutzers einzuholen, bevor ein Problem erstellt wird. Nach der Erstellung soll der Plan mit der Fähigkeit codely-plan_phase-implement-github implementiert werden.
