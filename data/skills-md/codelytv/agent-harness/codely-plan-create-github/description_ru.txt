Создайте план для указанной задачи и сохраните его как задачи GitHub в репозитории текущего рабочего каталога. Учитывая URL-адрес проблемы GitHub, он превращает эту проблему в родительскую задачу «плана» (цель, контекст и контрольный список этапов) и создает одну дочернюю задачу для каждой фазы, связывая каждую фазу как собственную подзадачу родительского элемента GitHub. Останавливается для одобрения пользователя перед созданием какой-либо проблемы. После создания план должен быть реализован с помощью навыка codely-plan_phase-implement-github.
