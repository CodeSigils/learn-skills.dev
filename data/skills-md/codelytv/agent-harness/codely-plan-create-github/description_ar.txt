قم بإنشاء خطة للمهمة المحددة وقم بتخزينها كإصدارات GitHub في مستودع دليل العمل الحالي. بالنظر إلى عنوان URL الخاص بمشكلة GitHub، فإنه يحول هذه المشكلة إلى مشكلة "الخطة" الأصلية (الهدف والسياق وقائمة مراجعة المراحل) وينشئ مشكلة فرعية واحدة لكل مرحلة، ويربط كل مرحلة باعتبارها مشكلة فرعية أصلية لـ GitHub للأصل. يتوقف لموافقة المستخدم قبل إنشاء أي مشكلة. بعد الإنشاء، من المفترض أن يتم تنفيذ الخطة باستخدام مهارة codely-plan_phase-implement-github.
