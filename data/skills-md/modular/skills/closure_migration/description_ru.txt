Переносит код Mojo из устаревших параметрических замыканий (`capturing[_]`, `@__parameter` / `@parameter`, `api[fn](args)`) в унифицированные замыкания, принимающие значения (`api(args, fn)` с `{imm}` / `{mut}` / `{var}` / именованные списки захвата). Используйте при удалении параметрических перегрузок, исправлении ошибок «тонкого» преобразования, переписывании вложенных замыканий запуска/обратного вызова или переносе любого API, который принимал параметр функции Comptime.
