ترحيل كود Mojo من عمليات الإغلاق المعلمية القديمة (`capturing[_]`، `@__parameter` / `@parameter`، `api[fn](args)`) إلى عمليات الإغلاق الموحدة ذات القيمة (`api(args, fn)` مع `{imm}` / `{mut}` / `{var}` / قوائم الالتقاط المسماة). يُستخدم عند إزالة التحميل الزائد للمعلمات، أو إصلاح أخطاء التحويل "التقاط رقيقة"، أو إعادة كتابة عمليات إغلاق التشغيل/رد الاتصال المتداخلة، أو ترحيل أي واجهة برمجة تطبيقات تأخذ معلمة دالة comptime.
