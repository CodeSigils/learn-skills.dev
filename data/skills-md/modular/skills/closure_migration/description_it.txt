Migra il codice Mojo dalle chiusure parametriche legacy (`capturing[_]`, `@__parameter` / `@parameter`, `api[fn](args)`) alle chiusure unificate che assumono valore (`api(args, fn)` con `{imm}` / `{mut}` / `{var}` / elenchi di acquisizione denominati). Da utilizzare durante la rimozione di sovraccarichi parametrici, la correzione di errori di conversione "acquisizione thin", la riscrittura di chiusure di avvio/callback nidificate o la migrazione di qualsiasi API che accettava un parametro della funzione comptime.
