Migriert Mojo-Code von älteren parametrischen Abschlüssen („capturing[_]“, „@__parameter“ / „@parameter“, „api[fn](args)“) auf wertübernehmende einheitliche Abschlüsse („api(args, fn)“ mit „{imm}“ / „{mut}“ / „{var}“ / benannte Erfassungslisten). Verwenden Sie diese Option, wenn Sie parametrische Überladungen entfernen, „Thin Capture“-Konvertierungsfehler beheben, verschachtelte Start-/Callback-Abschlüsse neu schreiben oder eine API migrieren, die einen Comptime-Funktionsparameter verwendet.
