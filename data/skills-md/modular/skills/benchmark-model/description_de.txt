Benchmarken Sie ein auf MAX bereitgestelltes Modell mit dem Befehl „max benchmark“: Messen Sie den Durchsatz (Tokens/Sek.), die Latenz (TTFT, TPOT, Inter-Token-Latenz) und die GPU-Auslastung, indem Sie die Last gegen einen laufenden „Max Serve“-Endpunkt steuern. Verwenden Sie dies immer dann, wenn der Benutzer ein MAX-Modell einem Benchmarking, einem Lasttest oder einer Messung der Leistung unterziehen, Token pro Sekunde / TTFT / TPOT-Zahlen abrufen, einen Parallelitäts- oder Anforderungsraten-Sweep ausführen, Latenz mit Durchsatz vergleichen, eine Bereitstellung dimensionieren oder Benchmark-JSON erstellen möchte, auch wenn der Name „Benchmark“ nicht genannt wird. Wird auch verwendet, wenn bei einem „Max-Benchmark“-Lauf keine Verbindung hergestellt werden kann oder Null-/Müllzahlen gemeldet werden.
