Úselo al importar una nueva arquitectura de modelo a MAX desde una ID de modelo de Hugging Face. Se activa: "importar un modelo a MAX", "agregar modelo a MAX", "abrir <modelo HF> en MAX". Flujo de trabajo: inspeccionar la configuración de Hugging Face y el código de modelado, realizar andamiaje desde una arquitectura MAX similar, implementar cada capa de gráfico para que coincida con HF, servir y luego depurar con la referencia de Hugging Face hasta que los resultados coincidan.
