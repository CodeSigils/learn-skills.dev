Verwenden Sie diese Option, wenn Sie eine neue Modellarchitektur aus einer Hugging Face-Modell-ID in MAX importieren. Wird ausgelöst bei: „ein Modell in MAX importieren“, „Modell zu MAX hinzufügen“, „<HF-Modell> in MAX aufrufen“. Arbeitsablauf: Hugging Face-Konfiguration und Modellierungscode überprüfen, Gerüst aus einer ähnlichen MAX-Architektur erstellen, jede Diagrammebene so implementieren, dass sie mit HF übereinstimmt, bereitstellen und dann anhand der Hugging Face-Referenz debuggen, bis die Ausgaben übereinstimmen.
