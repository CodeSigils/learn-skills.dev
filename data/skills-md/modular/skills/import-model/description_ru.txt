Используйте при импорте новой архитектуры модели в MAX из идентификатора модели Hugging Face. Срабатывает при: «импортировать модель в MAX», «добавить модель в MAX», «вызвать <модель HF> в MAX». Рабочий процесс: проверьте конфигурацию и код моделирования Hugging Face, создайте основу из аналогичной архитектуры MAX, реализуйте каждый слой графа в соответствии с HF, обслуживайте, затем отлаживайте по эталону Hugging Face, пока выходные данные не совпадут.
