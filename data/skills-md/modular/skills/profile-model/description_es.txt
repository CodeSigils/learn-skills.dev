Perfile un modelo que se ejecuta en MAX para saber dónde pasa el tiempo y si la GPU está saturada. Úselo cuando el usuario solicite "perfilar mi modelo", "dónde pasa el tiempo mi modelo", "por qué la inferencia es lenta", "se está utilizando mi GPU", "cuánta GPU estoy usando", "obtener un desglose del kernel", "capturar un rastro nsys/rocprof/ncu del servicio máximo" o desea medir el rendimiento de inferencia MAX. Funciona para cualquier modelo que MAX pueda ejecutar (arquitecturas integradas y personalizadas cargadas con --custom-architectures) desde una instalación pip o pixi (generación máxima, servicio máximo o un script de Python) en GPU NVIDIA o AMD. Primero decida lo más barato: una verificación de utilización de la GPU, luego un desglose del kernel y luego una inmersión profunda de un solo kernel solo cuando un kernel domina.
