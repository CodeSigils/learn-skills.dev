Profilieren Sie ein Modell, das auf MAX läuft, um herauszufinden, wo es Zeit verbringt und ob die GPU ausgelastet ist. Verwenden Sie diese Option, wenn der Benutzer nach „Profil meines Modells“ fragt, „Wo verbringt mein Modell Zeit“, „Warum ist die Inferenz langsam“, „Wird meine GPU ausgelastet“, „Wie viel GPU verwende ich“, „Erhalten Sie eine Kernel-Aufschlüsselung“, „Erfassen Sie eine nsys/rocprof/ncu-Ablaufverfolgung des maximalen Dienstes“ oder möchte Sie die MAX-Inferenzleistung messen. Funktioniert für jedes Modell, das MAX ausführen kann – integrierte Architekturen und benutzerdefinierte Architekturen, die mit --custom-architectures geladen sind – über eine Pip- oder Pixi-Installation (Max Generate, Max Serve oder ein Python-Skript) auf NVIDIA- oder AMD-GPUs. Entscheiden Sie sich zuerst für das günstigste: eine GPU-Auslastungsprüfung, dann eine Kernel-Aufschlüsselung und dann einen einzelnen Kernel-Tieftauchgang, nur wenn ein Kernel dominiert.
