對 MAX 上運行的模型進行分析，以了解其時間消耗以及 GPU 是否飽和。當使用者要求「分析我的模型」、「我的模型在哪裡花費時間」、「為什麼推理很慢」、「我的 GPU 正在使用嗎」、「我使用了多少 GPU」、「取得核心故障」、「捕獲最大服務的 nsys/rocprof/ncu 追蹤」或想要測量 MAX 推理效能時使用。任何適用於 MAX 可以運行的模型 - 內建架構和載入了 --custom-architectures 的自訂架構 - 透過 NVIDIA 或 AMD GPU 上的 pip 或 pixi 安裝（最大生成、最大服務或 Python 腳本）。首先決定最便宜的方式：檢查 GPU 利用率，然後進行核心故障，然後僅當一個核心占主導地位時才進行單核心深入研究。
