Profilez un modèle fonctionnant sur MAX pour savoir où il passe du temps et si le GPU est saturé. À utiliser lorsque l'utilisateur demande « profiler mon modèle », « où mon modèle passe-t-il du temps », « pourquoi l'inférence est-elle lente », « mon GPU est-il utilisé », « quelle quantité de GPU j'utilise », « obtenir une panne du noyau », « capturer une trace nsys/rocprof/ncu du service maximum » ou souhaite mesurer les performances d'inférence MAX. Fonctionne pour n'importe quel modèle MAX peut s'exécuter - architectures intégrées et personnalisées chargées avec --custom-architectures - à partir d'une installation pip ou pixi (max generate, max serve ou un script Python) sur des GPU NVIDIA ou AMD. Décidez d'abord du moins cher : une vérification de l'utilisation du GPU, puis une panne du noyau, puis une analyse approfondie d'un seul noyau uniquement lorsqu'un noyau domine.
