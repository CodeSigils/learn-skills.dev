对 MAX 上运行的模型进行分析，以了解其时间消耗情况以及 GPU 是否饱和。当用户要求“分析我的模型”、“我的模型在哪里花费时间”、“为什么推理很慢”、“我的 GPU 正在使用吗”、“我使用了多少 GPU”、“获取内核故障”、“捕获最大服务的 nsys/rocprof/ncu 跟踪”或想要测量 MAX 推理性能时使用。适用于 MAX 可以运行的任何模型 - 内置架构和加载了 --custom-architectures 的自定义架构 - 通过 NVIDIA 或 AMD GPU 上的 pip 或 pixi 安装（最大生成、最大服务或 Python 脚本）。首先决定最便宜的方式：检查 GPU 利用率，然后进行内核故障，然后仅当一个内核占主导地位时才进行单内核深入研究。
