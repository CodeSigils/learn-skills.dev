Обслуживайте модель с помощью команды MAX «max serve»: настройте среду (pixi или uv с каналом max-nightly conda / индексом Nightly Wheel), укажите серверу репозиторий Hugging Face или локальную контрольную точку, нацельтесь на пользовательскую архитектуру с помощью «--custom-architectures» и выберите правильные флаги обслуживания для модели. Используйте это всякий раз, когда пользователь хочет запустить, запустить или разместить модель на MAX, создать конечную точку, совместимую с OpenAI, обслужить пользовательскую/перенесенную архитектуру, отладить сбой при запуске «максимального обслуживания» или выяснить, какие флаги обслуживания (устройства, кодирование квантования, максимальная длина, задача, доверительный удаленный код) нужны данной модели, даже если они не говорят «максимальное обслуживание» по имени.
