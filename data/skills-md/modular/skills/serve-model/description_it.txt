Servi un modello con il comando "max serve" di MAX: imposta l'ambiente (pixi o uv con il canale conda max-nightly/l'indice della ruota nightly), indirizza il server verso un repository Hugging Face o un checkpoint locale, scegli come target un'architettura personalizzata con "--custom-architectures" e scegli i flag di servizio corretti per il modello. Utilizzalo ogni volta che l'utente desidera eseguire, avviare, avviare o ospitare un modello su MAX, aprire un endpoint compatibile con OpenAI, servire un'architettura personalizzata/portata, eseguire il debug di un errore di avvio "max serve" o capire di quali flag di servizio (dispositivi, codifica di quantizzazione, lunghezza massima, attività, codice attendibile-remoto) ha bisogno un determinato modello, anche se non dice "max serve" per nome.
