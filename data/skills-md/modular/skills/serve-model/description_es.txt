Sirve un modelo con el comando `maxserve` de MAX: configura el entorno (pixi o uv con el canal conda max-nightly/índice de rueda nocturna), apunta el servidor a un repositorio de Hugging Face o punto de control local, apunta a una arquitectura personalizada con `--custom-architectures` y elige los indicadores de servicio correctos para el modelo. Use esto siempre que el usuario quiera ejecutar, iniciar, iniciar o alojar un modelo en MAX, abrir un punto final compatible con OpenAI, ofrecer una arquitectura personalizada/portada, depurar una falla de inicio de "servicio máximo" o determinar qué indicadores de servicio (dispositivos, codificación de cuantificación, longitud máxima, tarea, código remoto de confianza) necesita un modelo determinado, incluso si no dicen "servicio máximo" por nombre.
