قم بخدمة نموذج باستخدام أمر MAX "maxserv": قم بإعداد البيئة (pixi أو uv مع قناة max-nightly conda / مؤشر العجلة الليلية)، وقم بتوجيه الخادم إلى Hugging Face repo أو نقطة تفتيش محلية، واستهدف بنية مخصصة باستخدام `--custom-architectures`، واختر علامات الخدمة المناسبة للنموذج. استخدم هذا عندما يريد المستخدم تشغيل نموذج أو إطلاقه أو بدء تشغيله أو استضافته على MAX، أو إظهار نقطة نهاية متوافقة مع OpenAI، أو تقديم بنية مخصصة/منقولة، أو تصحيح أخطاء فشل بدء تشغيل "الخدمة القصوى"، أو معرفة إشارات الخدمة (الأجهزة، ترميز التكميم، الحد الأقصى للطول، المهمة، رمز الثقة عن بعد) التي يحتاجها نموذج معين، حتى لو لم يذكر "الحد الأقصى للخدمة" بالاسم.
