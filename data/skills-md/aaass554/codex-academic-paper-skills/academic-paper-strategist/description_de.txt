Verwenden Sie diese Option, wenn der Benutzer vor dem endgültigen Schreiben eine Abschlussarbeit im Bereich Softwaretechnik/Informatik auf einer echten Codebasis planen, risikoreduzieren oder begründen muss. Auslöser für Anfragen wie „根据项目写毕业论文“, „先做论文大纲“, „用真实项目材料规划论文“, „检查论文是否脱离代码“, „根据检测报告降查重“, „根据AIGC报告改写定稿“, „继续在手改初稿上改“, oder wenn ein bestehender Entwurf einer Abschlussarbeit anhand eines Musters im Schulformat überarbeitet werden muss. Erstellt eine evidenzbasierte Gliederung, einen Kapitelumschreibungsplan, einen Abbildungsplan und ein Übergabepaket für den Verfasser akademischer Arbeiten.
