Einrichten, Ausführen und Interpretieren von Agent Skill-Bewertungen (evals) mit der skills-up CLI / 使用 skills-up CLI 给 Agent Skill 搭建和运行评测. Wird verwendet, wenn der Benutzer eine Fähigkeit bewerten, testen, zurückentwickeln oder verifizieren möchte. Auswertungen oder Fälle hinzufügen; schreibe eval.yaml/case.yaml; run/validate/list-cases/report/import/init; oder von Anthropic evals.json migrieren. Behandelt die Fähigkeitserkennung, das Evaluierungsgerüst, die Erstellung von Richtern, Anmeldeinformationen, Benutzerkonfiguration, Validierung, Läufe und Berichte.
