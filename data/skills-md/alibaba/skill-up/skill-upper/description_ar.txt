قم بإعداد وتشغيل وتفسير تقييمات مهارات الوكيل (التقييمات) باستخدام CLI / مهارة متابعة CLI - مهارة الوكيل. يُستخدم عندما يطلب المستخدم تقييم إحدى المهارات أو اختبارها أو التراجع عنها أو التحقق منها؛ إضافة التقييمات أو الحالات؛ اكتب eval.yaml/case.yaml; تشغيل مهارات المتابعة/التحقق من صحة/قائمة الحالات/تقرير/استيراد/التهيئة؛ أو الهجرة من Anthropic evals.json. يتعامل مع اكتشاف المهارات وتقييم السقالات وتأليف القاضي وبيانات الاعتماد وتكوين المستخدم والتحقق من الصحة والتشغيل والتقارير.
