Realiza una revisión de código impulsada por IA en cambios de Git utilizando la CLI `ocr` de alibaba/open-code-review. Úselo cuando el usuario solicite revisar el código, revisar una solicitud de extracción, revisar cambios en etapa/no en etapa, revisar una confirmación o comparar ramas para problemas de calidad del código. Produce comentarios de revisión a nivel de línea y puede aplicar correcciones automáticamente cuando se solicita. Con reglas de revisión adecuadas, puede detectar varios tipos de problemas, incluidos errores, vulnerabilidades de seguridad, problemas de rendimiento y problemas de calidad del código.
