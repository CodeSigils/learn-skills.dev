Effectue une révision du code basée sur l'IA sur les modifications Git à l'aide de la CLI `ocr` d'alibaba/open-code-review. À utiliser lorsque l'utilisateur demande à réviser le code, à réviser une demande d'extraction, à réviser les modifications planifiées/non planifiées, à réviser une validation ou à comparer les branches pour les problèmes de qualité du code. Produit des commentaires de révision au niveau de la ligne et peut appliquer automatiquement des correctifs sur demande. Avec des règles d'examen appropriées, peut détecter divers types de problèmes, notamment les bogues, les vulnérabilités de sécurité, les problèmes de performances et les problèmes de qualité du code.
