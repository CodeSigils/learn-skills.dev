Esegue la revisione del codice basata sull'intelligenza artificiale sulle modifiche Git utilizzando la CLI `ocr` di alibaba/open-code-review. Da utilizzare quando l'utente chiede di rivedere il codice, rivedere una richiesta pull, rivedere le modifiche graduali/non graduali, rivedere un commit o confrontare i rami per problemi di qualità del codice. Produce commenti di revisione a livello di riga e può applicare automaticamente le correzioni quando richiesto. Con regole di revisione appropriate, è possibile rilevare vari tipi di problemi tra cui bug, vulnerabilità della sicurezza, problemi di prestazioni e problemi di qualità del codice.
