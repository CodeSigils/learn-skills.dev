Führt eine KI-gestützte Codeüberprüfung von Git-Änderungen mithilfe der „ocr“-CLI von alibaba/open-code-review durch. Verwenden Sie diese Option, wenn der Benutzer darum bittet, Code zu überprüfen, eine Pull-Anfrage zu überprüfen, bereitgestellte/nicht bereitgestellte Änderungen zu überprüfen, einen Commit zu überprüfen oder Zweige auf Probleme mit der Codequalität zu vergleichen. Erstellt Überprüfungskommentare auf Zeilenebene und kann auf Anfrage automatisch Korrekturen anwenden. Mit geeigneten Überprüfungsregeln können verschiedene Arten von Problemen erkannt werden, darunter Fehler, Sicherheitslücken, Leistungsprobleme und Bedenken hinsichtlich der Codequalität.
