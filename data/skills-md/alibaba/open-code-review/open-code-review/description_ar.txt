إجراء مراجعة التعليمات البرمجية المدعومة بالذكاء الاصطناعي على تغييرات Git باستخدام واجهة سطر الأوامر `ocr` من alibaba/open-code-review. يُستخدم عندما يطلب المستخدم مراجعة التعليمات البرمجية، أو مراجعة طلب السحب، أو مراجعة التغييرات المرحلية/غير المرحلية، أو مراجعة الالتزام، أو مقارنة الفروع لمشكلات جودة التعليمات البرمجية. يُنتج تعليقات المراجعة على مستوى السطر ويمكنه تطبيق الإصلاحات تلقائيًا عند الطلب. باستخدام قواعد المراجعة المناسبة، يمكن اكتشاف أنواع مختلفة من المشكلات بما في ذلك الأخطاء ونقاط الضعف الأمنية ومشاكل الأداء والمخاوف المتعلقة بجودة التعليمات البرمجية.
