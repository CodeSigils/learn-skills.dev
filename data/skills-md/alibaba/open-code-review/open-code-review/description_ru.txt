Выполняет проверку кода изменений Git с помощью искусственного интеллекта, используя интерфейс командной строки `ocr` из Alibaba/open-code-review. Используйте, когда пользователь просит просмотреть код, просмотреть запрос на включение, просмотреть проиндексированные/непроиндексированные изменения, просмотреть фиксацию или сравнить ветки на наличие проблем с качеством кода. Создает комментарии к проверке на уровне строки и может автоматически применять исправления по запросу. При наличии соответствующих правил проверки можно обнаружить различные типы проблем, включая ошибки, уязвимости безопасности, проблемы с производительностью и проблемы с качеством кода.
