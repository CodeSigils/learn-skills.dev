Режим делегирования для проверки открытого кода (OCR). Вместо OCR, вызывающего конечную точку LLM, этот навык дает указание хост-агенту выполнить проверку кода самостоятельно, используя OCR только для детерминированного проектирования: выбора файла и разрешения правил. Используйте, когда хост-агент должен проводить проверку, используя собственные возможности LLM.
