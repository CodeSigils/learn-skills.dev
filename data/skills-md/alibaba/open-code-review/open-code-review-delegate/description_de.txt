Delegationsmodus für Open-Code-Review (OCR). Anstelle eines OCR-Aufrufs eines LLM-Endpunkts weist dieser Skill den Host-Agenten an, die Codeüberprüfung selbst durchzuführen, wobei OCR nur für die deterministische Technik verwendet wird: Dateiauswahl und Regelauflösung. Verwenden Sie diese Option, wenn der Host-Agent die Überprüfung mit seinen eigenen LLM-Funktionen vorantreiben soll.
