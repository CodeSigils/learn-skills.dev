Mode de délégation pour la révision de code ouvert (OCR). Au lieu que l'OCR appelle un point de terminaison LLM, cette compétence demande à l'agent hôte d'effectuer lui-même la révision du code, en utilisant l'OCR uniquement pour l'ingénierie déterministe : sélection de fichiers et résolution de règles. À utiliser lorsque l'agent hôte doit piloter la révision avec ses propres fonctionnalités LLM.
