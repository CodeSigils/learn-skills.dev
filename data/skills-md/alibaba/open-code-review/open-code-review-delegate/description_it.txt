Modalità di delega per la revisione del codice aperto (OCR). Invece di chiamare l'OCR un endpoint LLM, questa competenza indica all'agente host di eseguire lui stesso la revisione del codice, utilizzando l'OCR solo per l'ingegneria deterministica: selezione dei file e risoluzione delle regole. Da utilizzare quando l'agente host deve condurre la revisione con le proprie funzionalità LLM.
