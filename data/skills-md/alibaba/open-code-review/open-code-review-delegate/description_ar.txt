وضع التفويض لمراجعة التعليمات البرمجية المفتوحة (OCR). بدلاً من استدعاء OCR لنقطة نهاية LLM، تقوم هذه المهارة بإرشاد الوكيل المضيف لإجراء مراجعة التعليمات البرمجية بنفسه، باستخدام OCR فقط للهندسة الحتمية: اختيار الملف وحل القاعدة. يُستخدم عندما يتعين على الوكيل المضيف أن يقود المراجعة بقدرات LLM الخاصة به.
