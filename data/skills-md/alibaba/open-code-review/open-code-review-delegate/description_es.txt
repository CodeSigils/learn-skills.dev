Modo de delegación para revisión de código abierto (OCR). En lugar de que OCR llame a un punto final de LLM, esta habilidad le indica al agente host que realice la revisión del código por sí mismo, utilizando OCR solo para ingeniería determinista: selección de archivos y resolución de reglas. Úselo cuando el agente anfitrión deba impulsar la revisión con sus propias capacidades LLM.
