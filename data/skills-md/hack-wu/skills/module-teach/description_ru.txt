Система объясняет код, поддерживая два типа целей объяснения — объяснение модуля (схема возможностей → вики-код → функциональное происхождение → сценарии применения → поток данных) и объяснение изменений (фиксация / PR / любой диапазон различий: схема изменения → построчная интерпретация → анализ воздействия → намерения и компромиссы → риски, подлежащие подтверждению). Он различает общие знания и знания, специфичные для проекта, создавая многоразовые учебные материалы Markdown (встроенная Mermaid + сложные диаграммы SVG). Он устанавливает критерии качества проверки правильности и двойную перспективу рецензента курса, поддерживает пакетное объяснение больших модулей, регулирует глубину в соответствии с целями обучения и предлагает дополнительное выравнивание точек знаний (режим множественного выбора, автоматическая оценка + перекрестное отслеживание прогресса). Он используется, когда пользователю необходимо понять, взять на себя управление или объяснить модуль кода или конкретное изменение, или он говорит «объясните этот модуль», «изучите код XXX», «помогите мне понять этот фрагмент кода», «объясните, что делает этот коммит/PR», «что означает это изменение», «опросите меня», «выравнивание точек знаний». Целью объяснения должен быть код из этого проекта; темы общих знаний (k8s/финансы) – тема-обучение; Чтобы обнаружить проблемы или решить, следует ли что-то объединить, используйте проверку кода.
