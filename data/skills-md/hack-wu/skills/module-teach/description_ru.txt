Система объясняет код, поддерживая два типа целей объяснения — объяснение модуля (схема возможностей → вики-код → функциональное происхождение → сценарии применения → поток данных) и объяснение изменений (фиксация / PR / любой диапазон различий: схема изменения → построчная интерпретация → анализ воздействия → намерения и компромиссы → риски, подлежащие подтверждению). Он различает общие знания и знания, специфичные для проекта, создавая многоразовые учебные материалы Markdown (встроенная Mermaid + сложные диаграммы SVG). Он устанавливает критерии качества проверки правильности и двойную оценку рецензентом курса, поддерживает пакетное объяснение больших модулей, регулирует глубину в соответствии с целями обучения и при необходимости выравнивает баллы знаний (режим множественного выбора, автоматическая оценка + перекрестное отслеживание прогресса). Он используется, когда пользователям необходимо понять, принять на себя или объяснить модуль кода или изменение, например, «объяснить этот модуль», «выучить код XXX», «помочь мне понять этот фрагмент кода», «объяснить, что делает этот коммит/PR», «что означает это изменение», «проверить меня» или «выровнять точки знаний». Целью объяснения должен быть код из этого проекта; общие темы знаний (k8s/финансы) используют тематическое обучение; для поиска ошибок или принятия решения о слиянии используйте проверку кода.
