Das System erklärt Code und unterstützt zwei Arten von Erklärungszielen: Modulerklärung (Fähigkeitsübersicht → Code-Wiki → funktionale Ableitung → Anwendungsszenarien → Datenfluss) und Änderungserklärung (Commit / PR / beliebiger Diff-Bereich: Änderungsübersicht → zeilenweise Interpretation → Auswirkungsanalyse → Absicht und Kompromisse → Risiken bis zur Bestätigung). Es unterscheidet zwischen Allgemeinwissen und projektspezifischem Wissen und erstellt Markdown-Lernmaterial, das wiederholt konsultiert werden kann (Mermaid eingebettetes + komplexes Diagramm SVG). Es werden Qualitäts-Gates zur Korrektheitsüberprüfung und eine Überprüfung aus zwei Perspektiven durch einen Kursprüfer festgelegt, die Stapelerklärungen großer Module unterstützen, die Tiefe entsprechend den Lernzielen anpassen und eine optionale Wissenspunktausrichtung (Multiple-Choice-Modus, automatische Bewertung + rundenübergreifende Fortschrittsverfolgung) ermöglichen. B. K8s, Finanzen) verwenden Topic-Teach; Um auf Probleme hinzuweisen oder zu entscheiden, ob eine Zusammenführung erfolgen soll, verwenden Sie die Codeüberprüfung.
