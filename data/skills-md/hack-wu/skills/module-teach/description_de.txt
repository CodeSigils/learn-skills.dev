Das System erklärt Code und unterstützt zwei Arten von Erklärungszielen: Modulerklärung (Fähigkeitsübersicht → Code-Wiki → funktionale Ableitung → Anwendungsszenarien → Datenfluss) und Änderungserklärung (Commit / PR / beliebiger Diff-Bereich: Änderungsübersicht → zeilenweise Interpretation → Auswirkungsanalyse → Absicht und Kompromisse → zu bestätigende Risiken). Es unterscheidet zwischen allgemeinem Wissen und projektspezifischem Wissen und erstellt wiederverwendbare Markdown-Lernmaterialien (eingebettete Mermaid + komplexe SVG-Diagramme). Es legt Qualitätstore für die Richtigkeitsüberprüfung und eine Überprüfung aus zwei Perspektiven durch einen Kursprüfer fest, unterstützt die Stapelerklärung großer Module, passt die Tiefe entsprechend den Lernzielen an und richtet optional Wissenspunkte aus (Multiple-Choice-Modus, automatische Bewertung + rundenübergreifende Fortschrittsverfolgung). Es wird verwendet, wenn Benutzer ein Codemodul oder eine Änderung verstehen, übernehmen oder erklären müssen, z. B. „Erklären Sie dieses Modul“, „Lernen Sie den XXX-Code“, „Hilf mir, diesen Codeabschnitt zu verstehen“, „Erklären Sie, was dieser Commit/PR bewirkt“, „Was bedeutet diese Änderung“, „Testen Sie mich“ oder „Wissenspunktausrichtung“. Das Erklärungsziel muss Code aus diesem Projekt sein; Allgemeine Wissensthemen (k8s/Finanzen) verwenden Topic-Teach; Verwenden Sie zur Fehlersuche oder zur Entscheidung über eine Zusammenführung die Codeüberprüfung.
