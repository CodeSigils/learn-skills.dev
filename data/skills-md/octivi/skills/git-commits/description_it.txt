Crea, riscrivi e rivedi i messaggi di commit Git utilizzando i commit convenzionali e le regole di igiene dei commit. Da utilizzare ogni volta che l'utente richiede testo di commit, correzioni dei messaggi di commit, selezione di tipo/ambito, notazione di modifiche sostanziali, trailer (ad esempio See o Co-authored-by), suddivisione del lavoro in commit atomici o disponibilità di commit prima di un PR, anche se chiedono in termini informali come "perfeziona questo messaggio di commit".
