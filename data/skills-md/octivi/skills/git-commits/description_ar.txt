قم بصياغة وإعادة كتابة ومراجعة رسائل التزام Git باستخدام الالتزامات التقليدية والالتزام بقواعد النظافة. يُستخدم عندما يطلب المستخدم نص الالتزام، أو إصلاحات رسالة الالتزام، أو تحديد النوع/النطاق، أو تدوين التغيير الجذري، أو المقاطع الدعائية (على سبيل المثال، راجع أو تأليف مشترك)، أو تقسيم العمل إلى التزامات ذرية، أو الاستعداد للالتزام قبل العلاقات العامة، حتى لو طلبوا ذلك بعبارات غير رسمية مثل "تلميع رسالة الالتزام هذه".
