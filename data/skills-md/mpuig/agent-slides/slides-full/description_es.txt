Canalización de plataformas de extremo a extremo: extraiga, realice pruebas previas, construya, audite, critique y pula en una sola pasada. Úselo cuando el usuario quiera una presentación completa desde cero con una plantilla, diga "crear una presentación completa", "constrúyame una presentación de principio a fin", "haga una presentación pulida a partir de esta plantilla" o proporcione tanto un resumen como una plantilla y espera un resultado terminado y listo para la presentación. Prefiere esto a encadenar habilidades individuales manualmente.
