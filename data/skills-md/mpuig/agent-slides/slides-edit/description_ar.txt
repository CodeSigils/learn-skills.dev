تحرير مجموعة العرض التقديمي الموجودة. يدعم تعديلات النص، وتحويلات التخطيط، والتصحيحات المستندة إلى العمليات. يُستخدم عندما يريد المستخدم تغيير نص على شريحة، أو تحديث عنوان، أو إصلاح خطأ مطبعي، أو تبديل تخطيط، أو استبدال بيانات المخطط، أو إضافة شرائح أو إزالتها، أو قول أشياء مثل "تغيير عنوان الشريحة 3 إلى X"، أو "تحديث الأرقام الموجودة على المخطط"، أو "نقل شريحة جدول الأعمال".
