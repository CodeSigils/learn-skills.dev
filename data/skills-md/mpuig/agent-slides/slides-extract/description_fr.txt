Extrayez les contrats modèles à partir d'un fichier .pptx. Produit des catalogues de mise en page, des archétypes, un manifeste résolu et un modèle de base propre pour la création de diapositives. À utiliser lorsque l'utilisateur fournit un modèle PowerPoint, dit « utiliser ce modèle », « extraire les mises en page », « analyser ce pptx » ou souhaite préparer un modèle avant de créer des diapositives.
