Führen Sie technische Qualitätsprüfungen an einem vorhandenen Deck durch. Findet und behebt Verstöße gegen die Schriftgröße, Formüberlappungen, Kontrastprobleme, fehlende Quellen und Probleme mit der Layout-Konformität. Verwenden Sie diese Option, wenn der Benutzer sagt: „Überprüfen Sie das Deck auf Probleme“, „Führen Sie eine Qualitätssicherung durch“, „Folien Sie die Folien aus“, „Gibt es Formatierungsprobleme“, „Überprüfen Sie die Präsentation“ oder möchte vor dem Teilen die visuelle Qualität überprüfen.
