Создайте полную презентацию из краткого описания. Создает план повествования, операции со слайдами, визуализирует презентацию и запускает контроль качества. Требуются извлеченные шаблоны контрактов из /slides-extract. Используйте, когда пользователь хочет создать слайды, построить колоду, создать презентацию, написать стратегическую колоду или сказать что-то вроде «сделай мне колоду из 10 слайдов по X», «создай презентацию по Y», «составь слайды для заседания совета директоров».
