Definieren Sie Verhaltensszenarien im Format „Gegeben/Wann/Dann“, bevor Sie Code implementieren, und entwickeln Sie sie mit einem Test-First-Ansatz. Verwenden Sie dies, wenn Sie mit Implementierungsaufgaben für Funktionserweiterungen oder Fehlerbehebungen beginnen, wenn Sie aufgefordert werden, „Tests zu schreiben“, „Szenarien zu schreiben“ oder „BDD zu verwenden“.
