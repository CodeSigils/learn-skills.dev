Cree el documento de diseño para un problema de GitHub mientras realiza una lluvia de ideas. Úselo cuando se invoque el comando `/issue`, o en contextos como "Quiero crear un problema", "Quiero convertir un diseño funcional en un problema" o "Quiero convertir un documento de diseño en un problema". Refine los requisitos y el diseño mediante una lluvia de ideas, genere el cuerpo del problema y, después de la aprobación, cree el problema usando el comando "gh".
