ابحث عن وثائق منصة Coralogix الرسمية واقرأها باستخدام **`cx docs search`** و **`cx docs fetch`**.
يُستخدم عندما يسأل المستخدم عن كيفية عمل ميزات Coralogix، وكيفية تكوين واجهة المستخدم أو استخدامها، وإعداد عمليات التكامل
(OpenTelemetry، الوكلاء، المجمعون، webhooks)، إدارة مفاتيح API، استكشاف الامتدادات/الآثار/السجلات في المنتج،
قم بتكوين التنبيهات/SLOs/لوحات المعلومات، أو تحتاج إلى مستندات منتج موثوقة - وليس القياس المباشر للمستأجر.
