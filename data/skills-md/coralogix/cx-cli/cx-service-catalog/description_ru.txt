Запрашивайте каталог сервисов Coralogix (объекты APM v2) с помощью CLI `cx service-catalog` — обнаруживайте типы сущностей, составляйте список известных сущностей, проверяйте их схему и извлекайте агрегированные или временные данные для сервисов, баз данных, операций, JVM и модулей Kubernetes. Используйте, когда пользователь запрашивает «перечислить сервисы», «какие типы объектов существуют», «показать задержку сервиса», «проверить частоту ошибок для сервиса», «какие модули используют больше всего памяти», «производительность операций базы данных», «пауза JVM GC», «работоспособность сервиса с течением времени», «сравнить сервисы по задержке», «какие столбцы доступны для этого типа объекта», «схема каталога сервисов» или хочет изучить сущности APM и их метрики.
