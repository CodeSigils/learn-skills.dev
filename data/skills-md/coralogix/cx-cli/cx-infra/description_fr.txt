Interrogez les ressources de l'infrastructure Coralogix avec la CLI « cx infra » : découvrez les types de ressources surveillées, répertoriez les ressources, vérifiez les données par ressource. À utiliser lorsque l'utilisateur demande « afficher les types de ressources », « répertorier les ressources d'infrastructure », « quelles ressources de ce type sont surveillées », « répertorier les ressources de ce type », « cette ressource est-elle saine », « l'historique de l'état de la ressource », « quand cette ressource est-elle devenue critique », « obtenir des données brutes sur les ressources », « inventaire de l'infrastructure », « rechercher des ressources par nom », « filtrer les ressources par service ou environnement » ou souhaite explorer les ressources d'infrastructure et leurs données.
