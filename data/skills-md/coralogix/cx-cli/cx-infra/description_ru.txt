Запрашивайте ресурсы инфраструктуры Coralogix с помощью CLI `cx infra` — обнаруживайте отслеживаемые типы ресурсов, составляйте список ресурсов, проверяйте данные для каждого ресурса. Используйте, когда пользователь просит «показать типы ресурсов», «перечислить ресурсы инфраструктуры», «какие ресурсы этого типа отслеживаются», «перечислить ресурсы этого типа», «исправен ли этот ресурс», «история работоспособности ресурса», «когда этот ресурс стал критическим», «получить необработанные данные о ресурсе», «инвентаризация инфраструктуры», «найти ресурсы по имени», «фильтровать ресурсы по службе или среде» или хочет изучить ресурсы инфраструктуры и их данные.
