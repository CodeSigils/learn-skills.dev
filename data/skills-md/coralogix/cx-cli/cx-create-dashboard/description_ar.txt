قم ببناء ونشر لوحة معلومات Coralogix لخدمة معينة من سجلاتها وامتداداتها ومقاييسها ومواصفات الخدمة. يكتشف القياس عن بعد عبر أوامر cx CLI، ويصدر Coralogix JSON القابل للاستيراد، ويتحقق من كل استعلام PromQL وDataPrime مباشرة من خلال `cx` CLI، وينشئ لوحة المعلومات عبر ``إنشاء لوحات معلومات cx``. يُستخدم عندما يطلب المستخدم إنشاء أو إنشاء أو إنشاء أو نشر لوحة معلومات Coralogix أو لوحة معلومات المراقبة أو لوحة معلومات إمكانية المراقبة لخدمة أو تطبيق أو خط أنابيب.
