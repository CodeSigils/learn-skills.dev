Создайте и разверните панель мониторинга Coralogix для конкретной службы на основе ее журналов, диапазонов, показателей и спецификаций службы. Обнаруживает телеметрию с помощью команд CLI cx, генерирует импортируемый JSON Coralogix, проверяет каждый запрос PromQL и DataPrime в реальном времени через CLI cx и создает панель мониторинга с помощью cx Dashboards create. Используйте всякий раз, когда пользователь запрашивает создание, сборку, создание или развертывание информационной панели Coralogix, информационной панели мониторинга или информационной панели наблюдения для службы, приложения или конвейера.
