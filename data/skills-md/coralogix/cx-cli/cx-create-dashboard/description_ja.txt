ログ、スパン、メトリクス、サービス仕様に基づいて、特定のサービスの Coralogix ダッシュボードを構築してデプロイします。 cx CLI コマンドを介してテレメトリを検出し、インポート可能な Coralogix JSON を出力し、「cx」 CLI を介してすべての PromQL および DataPrime クエリをライブで検証し、「cx ダッシュボード作成」を介してダッシュボードを作成します。ユーザーがサービス、アプリ、またはパイプラインの Coralogix ダッシュボード、モニタリング ダッシュボード、または可観測性ダッシュボードの作成、構築、生成、またはデプロイを要求するときは常に使用します。
