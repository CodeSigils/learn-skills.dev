Erstellen und implementieren Sie ein Coralogix-Dashboard für einen bestimmten Dienst anhand seiner Protokolle, Spans, Metriken und Dienstspezifikationen. Erkennt Telemetrie über cx-CLI-Befehle, gibt importierbares Coralogix-JSON aus, überprüft jede PromQL- und DataPrime-Abfrage live über die „cx“-CLI und erstellt das Dashboard über „cx-Dashboards erstellen“. Verwenden Sie es immer dann, wenn der Benutzer ein Coralogix-Dashboard, ein Überwachungs-Dashboard oder ein Observability-Dashboard für einen Dienst, eine App oder eine Pipeline erstellen, erstellen, generieren oder bereitstellen möchte.
