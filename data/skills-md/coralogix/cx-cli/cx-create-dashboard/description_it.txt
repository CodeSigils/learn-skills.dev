Crea e distribuisci un dashboard Coralogix per un determinato servizio a partire dai suoi log, intervalli, parametri e specifiche del servizio. Rileva la telemetria tramite i comandi CLI cx, emette il JSON Coralogix importabile, verifica ogni query PromQL e DataPrime in tempo reale tramite la CLI "cx" e crea il dashboard tramite "cx dashboards create". Da utilizzare ogni volta che l'utente richiede di creare, costruire, generare o distribuire un dashboard Coralogix, un dashboard di monitoraggio o un dashboard di osservabilità per un servizio, un'app o una pipeline.
