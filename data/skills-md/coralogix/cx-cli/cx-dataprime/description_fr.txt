Référence du langage de requête DataPrime pour Coralogix. Il s'agit d'une compétence complémentaire pour une syntaxe détaillée
aider. Il se déclenche lorsque l'utilisateur a besoin d'aide avec la syntaxe DataPrime en particulier - comment écrire
filtres, groupby, agrégations, extraire les champs avec regex, utiliser les conversions de type, regroupement temporel
avec roundTime, arrayContains ou demande "comment écrire une requête DataPrime", "que font les opérateurs
Prise en charge DataPrime", "Comment fonctionne l'extraction dans DataPrime". Cette compétence est la référence linguistique,
pas le guide d'exécution - si l'utilisateur souhaite réellement exécuter une requête sur des données spécifiques
source, utilisez plutôt la compétence spécifique à la source appropriée.
