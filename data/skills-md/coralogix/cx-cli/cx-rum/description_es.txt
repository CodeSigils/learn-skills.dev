Consulta y analiza los datos de Coralogix Real User Monitoring (RUM). Utilice esta habilidad cuando el usuario pregunte sobre
errores de interfaz, tiempos de carga de la página, web vitals, interacciones del usuario, errores del navegador, fallas móviles,
Core Web Vitals (LCP, CLS, FID, INP, TTFB), excepciones de JavaScript, rendimiento de la página, errores de sesión,
Datos RUM, monitoreo de usuarios reales o cualquier pregunta de observabilidad del lado del cliente/frontend, incluso si
No digas explícitamente "RON".
