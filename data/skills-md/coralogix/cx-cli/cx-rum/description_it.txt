Interroga e analizza i dati RUM (Real User Monitoring) di Coralogix. Utilizza questa abilità quando l'utente chiede informazioni
errori frontend, tempi di caricamento della pagina, parametri web vitali, interazioni dell'utente, errori del browser, arresti anomali del dispositivo mobile,
Core Web Vitals (LCP, CLS, FID, INP, TTFB), eccezioni JavaScript, prestazioni della pagina, errori di sessione,
Dati RUM, monitoraggio degli utenti reali o qualsiasi domanda sull'osservabilità frontend/lato client, anche se
non dire esplicitamente "RUM".
