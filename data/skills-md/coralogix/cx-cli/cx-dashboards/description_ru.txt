Создайте и разверните панель мониторинга Coralogix для конкретной службы на основе ее журналов, диапазонов, показателей и спецификаций службы. Обнаруживает телеметрию с помощью команд CLI cx, генерирует импортируемый JSON Coralogix, проверяет каждый запрос PromQL и DataPrime в реальном времени через CLI cx, а также создает или обновляет информационные панели с помощью cx Dashboards Create и CX Dashboards replace. Используйте всякий раз, когда пользователь запрашивает создание, сборку, создание, развертывание, обновление, замену или изменение информационной панели Coralogix, информационной панели мониторинга или информационной панели наблюдения для службы, приложения или конвейера.
