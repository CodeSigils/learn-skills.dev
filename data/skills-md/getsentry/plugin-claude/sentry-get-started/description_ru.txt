Управляемая точка входа для использования Sentry через вашего агента. Ориентирует вас на текущую настройку и для нового проекта комплексно настраивает Sentry с разумными настройками по умолчанию — подготавливает проект, устанавливает SDK (ошибки, трассировка и все, что он включает по умолчанию) и подтверждает, что реальная телеметрия поступает в Sentry. Направляет другие намерения (добавление дополнительных сигналов, устранение проблем) на нужный навык.
