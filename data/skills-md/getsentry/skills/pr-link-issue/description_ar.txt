قم بإلحاق رابط إصدار GitHub والتذكرة الخطية الخاصة به بوصف العلاقات العامة الحالية. يُستخدم عندما يُطلب منك "ربط المشكلة بالعلاقات العامة"، أو "ملء المشكلة والخطية في العلاقات العامة"، أو "إضافة مراجع المشكلة إلى العلاقات العامة"، أو عندما يتم إعطاؤك عنوان URL لمشكلة GitHub ويطلب منك إرفاقه بالعلاقات العامة الحالية. يعمل على حل التذكرة الخطية تلقائيًا من تعليق الرابط الخطي الخاص بالمشكلة.
