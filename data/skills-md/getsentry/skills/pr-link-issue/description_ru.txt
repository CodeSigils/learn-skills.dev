Добавьте ссылку на задачу GitHub и ее линейный билет к описанию текущего PR. Используйте, когда вас просят «связать проблему с PR», «заполнить проблему и линейно в pr», «добавить ссылки на проблемы в pr» или когда дан URL-адрес проблемы GitHub и вас просят прикрепить его к текущему PR. Автоматически разрешает линейную заявку из комментария к задаче с линейной обратной связью.
