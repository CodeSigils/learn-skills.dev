Задокументируйте и введите конечную точку Sentry API. Напишите или исправьте декораторы @extend_schema, укажите TypedDicts ответа, введите параметры запроса, исправьте расхождение типов между объявленной схемой и ответом среды выполнения и проверьте сгенерированную спецификацию. Используйте, когда вас просят «документировать конечную точку», «добавить документы OpenAPI», «добавить/исправить @extend_schema», «ввести ответ конечной точки», «исправить тип ответа», «исправить дрейф типа», «повторно использовать тип ответа», «разделить перегруженную конечную точку», «указать схему ответа», «добавить ответ TypedDict», «перенести устаревший путь API-документов», «исправить тип параметра» или «сделать конечную точку общедоступной» / «продвинуть конечную точку».
