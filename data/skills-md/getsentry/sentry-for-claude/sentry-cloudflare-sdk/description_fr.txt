Configuration complète du SDK Sentry pour Cloudflare Workers et Pages. À utiliser lorsqu'on vous demande d'« ajouter Sentry aux Cloudflare Workers », « d'installer @sentry/cloudflare » ou de configurer la surveillance des erreurs, le traçage, la journalisation, les crons ou la surveillance de l'IA pour les Workers Cloudflare, les pages, les objets durables, les files d'attente, les flux de travail ou Hono sur Cloudflare.
