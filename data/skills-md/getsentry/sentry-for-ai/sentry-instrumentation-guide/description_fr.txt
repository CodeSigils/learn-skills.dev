Décidez quel signal Sentry rechercher lors de l'instrumentation du code : erreur, étendue, attribut d'étendue, journal ou métrique. À utiliser lors de l'ajout d'instruments et lorsque vous ne savez pas si quelque chose doit être un journal, une étendue ou une métrique, pour décider « quoi instrumenter où », lors de l'examen de l'instrumentation pour détecter les lacunes, ou lorsqu'un agent de codage a besoin d'une règle pour choisir entre les erreurs, les traces, les journaux et les métriques. Cette compétence décide QUOI émettre ; les compétences sentry-*-sdk gèrent COMMENT configurer chaque pilier.
