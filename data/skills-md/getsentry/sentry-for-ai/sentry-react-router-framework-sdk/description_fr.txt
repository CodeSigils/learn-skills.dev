Configuration complète du SDK Sentry pour le mode React Router Framework. À utiliser lorsqu'on vous demande d'« ajouter Sentry à React Router Framework », « d'installer @sentry/react-router » ou de configurer la surveillance des erreurs, le traçage, le profilage, la relecture de session, les journaux ou les commentaires des utilisateurs pour une application de framework React Router v7.
