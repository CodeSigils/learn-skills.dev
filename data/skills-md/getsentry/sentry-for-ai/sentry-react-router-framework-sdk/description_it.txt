Configurazione completa dell'SDK Sentry per la modalità React Router Framework. Da utilizzare quando viene richiesto di "aggiungere Sentry a React Router Framework", "installare @sentry/react-router" o configurare il monitoraggio degli errori, la tracciatura, la profilazione, la riproduzione della sessione, i log o il feedback degli utenti per un'app React Router v7 framework.
