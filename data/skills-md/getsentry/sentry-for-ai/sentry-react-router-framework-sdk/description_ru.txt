Полная настройка Sentry SDK для режима React Router Framework. Используйте, когда вас просят «добавить Sentry в React Router Framework», «установить @sentry/react-router» или настроить мониторинг ошибок, трассировку, профилирование, воспроизведение сеанса, журналы или отзывы пользователей для приложения платформы React Router v7.
