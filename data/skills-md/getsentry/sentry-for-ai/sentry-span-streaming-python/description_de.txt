Migrieren Sie das Python SDK zum Sentry-Span-Streaming (Span-First-Trace-Lebenszyklus). Verwenden Sie diese Option, wenn Sie aufgefordert werden, „Span-Streaming zu aktivieren“, „zu Span-Streaming zu migrieren“, „trace_lifecycle-Stream verwenden“ oder in einem Python-Projekt von der transaktionsbasierten zur gestreamten Span-Bereitstellung zu wechseln.
