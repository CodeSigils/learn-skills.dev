Verwenden Sie diese Option, wenn Sie ein VORHANDENES Elastic-Integrationspaket überprüfen, reparieren oder verbessern. Umfasst Qualitätsprüfungen, gezielte Korrekturen (Pipelines, Feldzuordnungen, CEL-Programme, Manifeste, Änderungsprotokolle), vollständige Verbesserungsdurchläufe und kleinere Anpassungen. Verwenden Sie stattdessen „create-integration“, wenn Sie ein neues Paket erstellen oder einen neuen Datenstrom von Grund auf hinzufügen.
