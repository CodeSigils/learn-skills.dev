Configurazione del modello di input per le integrazioni elastiche. Copre i modelli di flusso dell'agente (agent/stream/*.yml.hbs) per tutti i tipi di input non CEL: HTTPJSON, AWS S3, CloudWatch, Azure Blob, Azure EventHub, GCS, GCP Pub/Sub, TCP, UDP, HTTP Endpoint, Filestream, Logfile, Journald, Winlog e WebSocket. Per i programmi di input CEL, utilizzare invece la competenza cel-programs.
