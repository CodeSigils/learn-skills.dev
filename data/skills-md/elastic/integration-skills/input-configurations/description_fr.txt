Configuration du modèle d'entrée pour les intégrations Elastic. Couvre les modèles de flux d'agent (agent/stream/*.yml.hbs) pour tous les types d'entrée non CEL : HTTPJSON, AWS S3, CloudWatch, Azure Blob, Azure EventHub, GCS, GCP Pub/Sub, TCP, UDP, HTTP Endpoint, Filestream, Logfile, Journald, Winlog et WebSocket. Pour les programmes d’entrée CEL, utilisez plutôt la compétence cel-programs.
