Конфигурация входного шаблона для интеграции Elastic. Охватывает шаблоны потока агента (agent/stream/*.yml.hbs) для всех типов входных данных, отличных от CEL: HTTPJSON, AWS S3, CloudWatch, Azure Blob, Azure EventHub, GCS, GCP Pub/Sub, TCP, UDP, конечная точка HTTP, Filestream, Logfile, Journald, Winlog и WebSocket. Для программ ввода CEL вместо этого используйте навык cel-programs.
