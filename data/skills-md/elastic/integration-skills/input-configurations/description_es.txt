Configuración de plantilla de entrada para integraciones Elastic. Cubre plantillas de flujo de agente (agent/stream/*.yml.hbs) para todos los tipos de entrada que no son CEL: HTTPJSON, AWS S3, CloudWatch, Azure Blob, Azure EventHub, GCS, GCP Pub/Sub, TCP, UDP, HTTP Endpoint, Filestream, Logfile, Journald, Winlog y WebSocket. Para programas de entrada CEL, utilice la habilidad de programas cel en su lugar.
