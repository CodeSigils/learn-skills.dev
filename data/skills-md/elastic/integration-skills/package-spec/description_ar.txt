الامتثال لمواصفات الحزمة لحزم التكامل المرنة. يغطي البنية الواضحة (format_version، والشروط، والمتغيرات، وقواعد التوجيه)، ومخطط سجل التغيير ومطبات الإصدار الدلالي، والمحاذاة مع مواصفات الحزمة المرنة/المنبع. يُستخدم عند إنشاء أو مراجعة Manifest.yml، أو Changelog.yml، أو تصحيح أخطاء فحص/فحص الحزمة المرنة في البيانات التعريفية للحزمة.
