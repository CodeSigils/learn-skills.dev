Автономная проверка качества интеграции Elastic. Классифицирует файлы по домену, загружает навыки, специфичные для домена, и проверяет контрольные списки, применяет правила междоменной согласованности, проверку версии CEL, соответствие API и калибровку серьезности. Независимость от ввода: работает с локальными пакетами, PR-дифференциалами или сравнениями ветвей. Используйте при проверке качества интеграции независимо от рабочего процесса сборки или исправления.
