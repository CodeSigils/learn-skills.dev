Revisione della qualità autonoma per le integrazioni elastiche. Classifica i file per dominio, carica competenze specifiche del dominio ed esamina elenchi di controllo, applica regole di coerenza tra domini, verifica della versione CEL, conformità API e calibrazione della gravità. Indipendente dall'input: funziona su pacchetti locali, differenze PR o confronti di rami. Da utilizzare durante la revisione della qualità dell'integrazione indipendentemente da qualsiasi flusso di lavoro di creazione o correzione.
