البدائية الخاصة بالوصول إلى Elastic للوكيل. أربعة أوضاع: الانتظار لحدوث شذوذ ML، استقصاء مقياس ES|QL (عينة حية أو الانتظار لحد عتبة)، قراءة قيمة عددية أحادية، أو إرجاع جدول ES|QL كامل. يُستخدم عندما يقول المستخدم «أخبرني عندما…»، «أعلمني إذا…»، «انتظر حتى ينخفض X عن Y»، «راقب أي شيء غير عادي»، «راقب خلال الدقائق N القادمة», «استقصِ حتى يستقر», «ما هو X الآن», «قائمة …», «أي … هي …», أو يرغب في مراقبة مؤقتة (نطاق جلسة) أو استعلام مخصص دون إنشاء قاعدة Kibana دائمة. كذلك يُفعَّل عند «مراقبة شيء» والتحقق بعد الإصلاح.
