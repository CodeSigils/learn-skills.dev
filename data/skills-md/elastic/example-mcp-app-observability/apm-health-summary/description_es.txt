Obtenga un resumen a nivel de clúster de la salud del servicio a partir de la telemetría APM — el punto de entrada “¿cómo está mi entorno ahora?” para investigaciones de observabilidad. Úselo siempre que el usuario pregunte sobre SALUD, ESTADO o el bienestar general de un entorno / clúster / espacio de nombres (“¿cómo está mi clúster?”, “estado del entorno X”, “qué está roto”, “¿algún problema?”, “muéstrame la salud de …”, “dame un informe de estado”, “qué debería revisar”, “las cosas van lentas”). Esto se aplica sin importar el calificativo de tiempo — “muéstrame la salud de X en la última hora” sigue dirigirse aquí (con lookback=“1h”), NO a observe. observe es para consultas de métricas crudas; esta herramienta es para el resumen. Degrada de forma elegante: incorpora datos de pods de Kubernetes y contexto de anomalías de ML cuando esos backends están disponibles, pero sigue devolviendo una salida útil solo con APM si no lo están. No lo utilice para clientes solo de logs o solo de métricas — esta herramienta requiere Elastic APM.
