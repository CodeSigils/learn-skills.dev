從 APM 遙測取得叢集層級的服務健康彙總 — 觀測性調查的「我的環境現在狀況如何？」切入點。當使用者詢問環境／叢集／命名空間的健康、狀態或整體狀況時使用（例如「我的叢集怎樣？」、「X 環境的狀態如何？」、「哪裡出了問題？」、「有什麼問題嗎？」、「顯示 … 的健康狀況」、『給我一份狀態報告』、『我該查看什麼』、『感覺很慢』）。此規則不受時間限定詞影響 — 即使是「顯示過去一小時 X 的健康狀況」也會路由到此（使用 lookback="1h"），而不是路由到 observe。observe 用於原始度量查詢；此工具則用於彙總。具備優雅降級功能：當存在 Kubernetes Pod 資料與機器學習異常上下文時會加入這些層資訊，若無則仍回傳僅含 APM 的有用輸出。請勿用於僅有日誌或僅有度量的客戶——此工具需要 Elastic APM。請始終以使用者的語言回覆。
