Получите агрегированный на уровне кластера обзор состояния сервисов из телеметрии APM — точку входа «как сейчас моё окружение?» для расследований наблюдаемости. Используйте, когда пользователь спрашивает о ЗДОРОВЬЕ, СТАТУСЕ или общем благополучии окружения/кластера/пространства имён («как мой кластер», «статус среды X», «что сломалось», «есть проблемы», «покажи состояние …», «дай отчет о статусе», «что мне следует посмотреть», «всё работает медленно»). Это применимо независимо от любого временного уточнения — «покажи состояние X за последний час» всё равно направляется сюда (с lookback="1h"), а не в observe. observe предназначен для запросов сырых метрик; этот инструмент — для агрегированного обзора. При наличии соответствующих бэкендов плавно деградирует: добавляет данные о pod‑ах Kubernetes и контекст аномалий ML, но всё равно возвращает полезный вывод только из APM, если их нет. Не используйте для клиентов, работающих только с логами или только с метриками — этот инструмент требует Elastic APM.
