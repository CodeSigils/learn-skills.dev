Evalúe el impacto de que un nodo de Kubernetes se desconecte — qué implementaciones pierden todas sus réplicas (apagón total), cuáles pierden capacidad parcial (degradado), cuáles no se ven afectadas y si el clúster tiene suficiente capacidad de reserva para reprogramar los pods perdidos. Úselo cuando el usuario pregunte «qué pasa si el nodo X se cae», «cuál es el radio de explosión al drenar este nodo», «¿puedo mantener el nodo Y de forma segura?», «qué está ejecutándose en este nodo», «si expulso este nodo, ¿qué se rompe?», o esté planificando mantenimiento de nodos, una actualización del clúster o investigando una falla real de un nodo. Requiere Kubernetes (métricas kubeletstats) y Elastic APM para el impacto en los servicios downstream — no se active para implementaciones que no sean K8s. Por favor, responda siempre en el idioma del usuario.
