Оцените влияние выхода из строя узла Kubernetes — какие развертывания потеряют все реплики (полный отказ), какие потеряют часть мощности (дефицит), какие не пострадают, и хватает ли в кластере свободных ресурсов для переноса потерянных подов. Используйте, когда пользователь спрашивает «что произойдёт, если узел X выйдет из строя», «каков радиус поражения при выводе этого узла из эксплуатации», «могу ли я безопасно обслуживать узел Y», «что работает на этом узле», «что сломается, если я выселю этот узел», или планирует обслуживание узла, обновление кластера или расследует реальный сбой узла. Требует метрик Kubernetes (kubeletstats) и Elastic APM для оценки воздействия на нижестоящие сервисы — не активировать для не‑K8s развертываний.
