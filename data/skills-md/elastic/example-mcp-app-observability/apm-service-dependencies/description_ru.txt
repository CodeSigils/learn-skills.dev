Составьте карту топологии приложения на основе телеметрии APM — какие сервисы вызывают какие, по каким протоколам, с каким объёмом вызовов и задержкой. Используйте, когда пользователь задаёт вопросы «какие вызовы делает X», «от чего зависит X», «покажите топологию», «какие сервисы являются upstream/downstream», «где находится этот сервис», или проводит расследование первопричины и нужно отследить, как проблема распространяется по графу вызовов. Также реагировать на запросы «карта сервисов», «граф зависимостей», «радиус воздействия сервиса X», или «кто зависит от Y». Требуется Elastic APM — не использовать для клиентов, у которых только логи или только метрики.
