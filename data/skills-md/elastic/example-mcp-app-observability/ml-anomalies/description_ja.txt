Elastic ML の異常検出結果をクエリして、何が異常に動作しているのか、なぜ、どの程度悪いのかを理解します。ユーザーが「何が異常なのか」、「何か異常なことが起こっているのか」、「なぜ X が遅い/急上昇しているのか」、「奇妙なところを見せて」と尋ねる場合、またはメモリの増加、CPU スパイク、再起動パターン、異常な遅延、予期しないエラー率、または典型的な動作からの逸脱について言及する場合に使用します。また、「ML の異常」、「異常の検出」、「Elastic ML」、「ML は何を考えているのか」、またはユーザーがベースラインから逸脱した動作を理解したい場合にもトリガーされます。このツールは、重大度ゲージ、わかりやすい英語の説明、エンティティごとの逸脱の内訳を含むインラインの説明ビューを開きます。そのため、エージェントは JSON をダンプするだけでなく、視覚化を使用する必要があります。
