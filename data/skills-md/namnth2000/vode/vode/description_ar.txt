مهارة بناء المنتج للتشفير الحيوي. يقوم بتوجيه عمل المنتج باللغة الطبيعية إلى تبادل الأفكار، أو الفهم، أو اتخاذ القرار، أو التخطيط، أو التنفيذ، أو التصحيح، أو المراجعة، أو التحسين، أو الإطلاق، أو التوزيع، أو التكرار، أو المحور، أو الاستئناف، أو البناء. يدعم الإدخال الفيتنامي والتنفيذ الحيادي للنموذج.
