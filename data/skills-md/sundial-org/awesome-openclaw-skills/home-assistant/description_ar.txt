التحكم في الأجهزة المنزلية الذكية من خلال Home Assistant، وتشغيل عمليات التشغيل الآلي، واستقبال أحداث webhook. يُستخدم عند التحكم في الأضواء أو المفاتيح أو المناخ أو المشاهد أو البرامج النصية أو أي كيان HA. يدعم الاتصال ثنائي الاتجاه عبر REST API (الصادر) وخطافات الويب (المشغلات الواردة من أتمتة HA).
