Преобразование текста в речь с использованием пакета npm node-edge-tts для генерации звука из текста.
Поддерживает несколько голосов, языков, регулировку скорости, управление высотой звука и генерацию субтитров.
Используйте, когда: (1) Пользователь запрашивает аудио/голосовой вывод с помощью триггера или ключевого слова «tts». (2) Контент необходимо произносить, а не читать (многозадачность, доступность, вождение, приготовление пищи). (3) Пользователю нужен определенный голос, скорость, высота или формат для вывода TTS.
