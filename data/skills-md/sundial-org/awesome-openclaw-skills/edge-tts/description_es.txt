Conversión de texto a voz utilizando el paquete npm node-edge-tts para generar audio a partir de texto.
Admite múltiples voces, idiomas, ajuste de velocidad, control de tono y generación de subtítulos.
Úselo cuando: (1) El usuario solicita salida de audio/voz con el activador o palabra clave "tts". (2) El contenido debe ser hablado en lugar de leído (multitarea, accesibilidad, conducir, cocinar). (3) El usuario desea una voz, velocidad, tono o formato específico para la salida TTS.
