Ricerca sul Web e scraping tramite API Firecrawl. Utilizzare quando è necessario eseguire ricerche sul Web, eseguire il scraping di siti Web (comprese le pagine con uso intensivo di JS), eseguire la scansione di interi siti o estrarre dati strutturati da pagine Web. Richiede la variabile di ambiente FIRECRAWL_API_KEY.
