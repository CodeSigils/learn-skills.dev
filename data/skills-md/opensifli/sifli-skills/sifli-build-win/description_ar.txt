أنشئ مشاريع SiFli SDK على نظام التشغيل Windows باستخدام PowerShell. استخدم هذه المهارة عندما يريد المستخدم تجميع/إنشاء برنامج SiFli SDK الثابت، أو تحديد لوحة + مجموعة أمثلة، أو يسأل "编译"، "build"، "编译xxx例程"، "用板子xxx编译". يتعامل مع إعداد البيئة عبر Export.ps1، وإنشاء SCons باستخدام خيار --board، وتحديد موقع عناصر البناء.
