Создавайте проекты SiFli SDK в Windows с помощью PowerShell. Используйте этот навык, когда пользователь хочет скомпилировать/собрать прошивку SiFli SDK, указать комбинацию плата+пример или спросить «编译», «build», «编译xxx例程», «用板子xxx编译». Управляет настройкой среды с помощью файла Export.ps1, сборкой SCons с параметром --board и поиском артефактов сборки.
