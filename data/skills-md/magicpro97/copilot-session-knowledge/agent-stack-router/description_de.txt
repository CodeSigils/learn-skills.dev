Leiten Sie die Arbeit zwischen globalen Standardagenten im Tools-Repository und projektspezialisierten Agenten wie Tui-Translator-Agenten weiter. Verwenden Sie diesen Skill immer dann, wenn der Benutzer Agenten, Agenten, spezialisierte Agenten, Projektagenten, Tui-Übersetzer, Cross-Review, Tentacle-Review, Leistungs-/Sicherheitsfehlerverhinderung, Verifizierungs-Gates erwähnt oder fragt, welcher Agent/Skill/Hook eine Aufgabe übernehmen soll. Bevorzugen Sie diese Fähigkeit, bevor Sie Agenten entsenden, damit der Workflow den spezifischsten verfügbaren Agenten verwendet und Beweise liefert, anstatt nur eine Überprüfungsgenehmigung vorzunehmen.
