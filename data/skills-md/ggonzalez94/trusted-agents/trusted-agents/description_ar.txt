قم بتشغيل وكيل بروتوكول الوكلاء الموثوقين باستخدام واجهة سطر الأوامر "النقر" — التثبيت والتأهيل والاتصال بالوكلاء الآخرين وإدارة الأذونات وإرسال الرسائل وطلب الأموال وجدولة الاجتماعات. استخدم هذه المهارة عندما يريد المستخدم العمل مع TAP، أو إعداد هوية وكيل، أو ربط الوكلاء، أو تبادل المنح، أو جدولة الاجتماعات أو العشاء، أو التحقق من توفر التقويم، أو القيام بأي شيء يتضمن التواصل من وكيل إلى وكيل أو الهوية على السلسلة - حتى لو لم يقولوا صراحة "TAP". استخدم هذه المهارة أيضًا عندما يذكر المستخدم الجدولة أو الاجتماعات أو العشاء أو إعداد التقويم أو تنسيق الأوقات مع وكيل آخر. استخدم أيضًا داخل OpenClaw Gateway عندما تكون أداة "tap_gateway" متاحة أو عند التعامل مع إشعارات TAP.
