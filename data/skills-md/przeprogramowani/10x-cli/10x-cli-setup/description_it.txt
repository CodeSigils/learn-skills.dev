Richiama SEMPRE questa abilità quando l'utente menziona 10x-cli, @przeprogramowani/10x-cli, la CLI 10xDevs o l'ambiente del corso 10xDevs in un contesto di configurazione. Questa abilità recupera il README live: senza di esso Claude non conosce gli attuali passaggi di installazione di 10x-cli. Si applica a: installazione, aggiornamento, riconfigurazione per diversi strumenti di intelligenza artificiale (Cursor, Copilot, Claude Code), errori di autorizzazione/npm, autenticazione e onboarding dopo la registrazione di 10xDevs. Esclude: sviluppo del codice sorgente 10x-cli, contributo al repository, creazione di CLI simili o configurazione generale del progetto.
