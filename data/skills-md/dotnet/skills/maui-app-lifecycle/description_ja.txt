.NET MAUI アプリのライフサイクル ガイダンス - アプリの 4 つの状態、クロスプラットフォームの Windows ライフサイクル イベント (作成、アクティブ化、非アクティブ化、停止、再開、破棄)、プラットフォーム固有のライフサイクル マッピング、バックグラウンドと再開の動作、および状態保持パターン。用途: 「アプリのライフサイクル」、「ウィンドウのライフサイクル イベント」、「バックグラウンドでの状態の保存」、「アプリの再開」、「OnStopped」、「OnResumed」、「バックグラウンド」、「非アクティブ化されたイベント」、「ConfigureLifecycleEvents」、「プラットフォーム ライフサイクル フック」。以下には使用しないでください: ナビゲーション イベント (maui-shell-navigation を使用)、依存関係注入セットアップ (maui-dependency-injection を使用)、プラットフォーム API 呼び出し (条件付きコンパイルと部分クラスを使用)。
