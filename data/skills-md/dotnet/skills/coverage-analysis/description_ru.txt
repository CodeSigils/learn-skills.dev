Автоматизированный охват кода всего проекта и анализ оценок CRAP (Change Risk Anti-Patterns) для проектов .NET с существующими модульными тестами. Автоматически определяет структуру решения, запускает сбор покрытия с помощью «dotnet test» (поддерживает как Microsoft.Testing.Extensions.CodeCoverage, так и Coverlet), генерирует отчеты с помощью ReportGenerator, рассчитывает оценки CRAP для каждого метода и выявляет «горячие точки» риска — сложный код с низким тестовым покрытием, который опасно изменять. Используйте, когда пользователю нужен анализ покрытия в рамках всего проекта с определением приоритетов рисков, выявлением пробелов в покрытии, вычислением оценки CRAP для всего решения или для диагностики того, почему покрытие застопорилось или выходит на плато, и определения того, какие методы блокируют улучшение. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: целевого анализа CRAP с использованием одного метода (используйте навык Crap Score), написания тестов, выполнения общего теста, не связанного с анализом покрытия/CRAP, или составления отчетов о покрытии без контекста CRAP.
