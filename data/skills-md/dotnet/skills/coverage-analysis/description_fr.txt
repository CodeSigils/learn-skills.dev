Couverture de code automatisée à l'échelle du projet et analyse des scores CRAP (Change Risk Anti-Patterns) pour les projets .NET avec les tests unitaires existants. Détecte automatiquement la structure de la solution, exécute la collecte de couverture via « dotnet test » (prend en charge à la fois Microsoft.Testing.Extensions.CodeCoverage et Coverlet), génère des rapports via ReportGenerator, calcule les scores CRAP par méthode et fait apparaître les points chauds de risque - un code complexe avec une faible couverture de test qui est dangereux à modifier. À utiliser lorsque l'utilisateur souhaite une analyse de couverture à l'échelle du projet avec priorisation des risques, identification des écarts de couverture, calcul du score CRAP sur l'ensemble d'une solution, ou pour diagnostiquer pourquoi la couverture est bloquée ou plafonnée et identifier les méthodes qui bloquent l'amélioration. NE PAS UTILISER POUR : l'analyse CRAP ciblée à méthode unique (utiliser la compétence de score de merde), les tests d'écriture, l'exécution de tests généraux sans rapport avec l'analyse de couverture/CRAP ou les rapports de couverture sans contexte CRAP.
