Convertissez les projets et solutions .NET (.sln, .slnx) en NuGet Central Package Management (CPM) à l’aide de Directory.Packages.props. UTILISER POUR : la conversion en CPM, la centralisation ou l'alignement des versions de package NuGet sur plusieurs projets, l'intégration des propriétés de version MSBuild de Directory.Build.props dans Directory.Packages.props, la résolution des conflits ou des incohérences de version dans une solution ou un référentiel, la mise à jour ou le remplacement ou la synchronisation des versions de package entre les projets. Activez également lorsque les packages sont désynchronisés, dérivent ou incohérents, même sans que l'utilisateur ne mentionne le CPM. Fournit une capture de build de base, une résolution des conflits de version, une validation de build avec comparaison de journaux binaires et un rapport post-conversion structuré. NE PAS UTILISER POUR : les projets packages.config (doit d'abord migrer vers PackageReference) ou les référentiels pour lesquels le CPM est déjà entièrement activé.
