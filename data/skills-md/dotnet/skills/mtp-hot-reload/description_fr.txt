Suggère d’utiliser le rechargement à chaud de Microsoft Testing Platform (MTP) pour itérer les correctifs sur les tests ayant échoué sans reconstruire. À utiliser lorsque l'utilisateur dit "tests de rechargement à chaud", "itérer sur le correctif de test", "exécuter des tests sans reconstruction", "accélérer la boucle de test", "réparer le test plus rapidement" ou doit configurer le rechargement à chaud MTP pour itérer rapidement sur les échecs de test. Couvre la configuration (package NuGet, variable d'environnement, launchSettings.json) et le flux de travail itératif pour la correction des tests. NE PAS UTILISER POUR : l'écriture de code de test, le diagnostic des échecs de test, la configuration du pipeline CI/CD ou le rechargement à chaud de Visual Studio Test Explorer (qui est une fonctionnalité différente).
