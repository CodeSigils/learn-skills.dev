Schlägt vor, das Hot-Reload der Microsoft Testing Platform (MTP) zu verwenden, um Korrekturen für fehlgeschlagene Tests ohne Neuerstellung zu wiederholen. Verwenden Sie diese Option, wenn der Benutzer sagt: „Tests im laufenden Betrieb neu laden“, „bei Testbehebung iterieren“, „Tests ohne Neuerstellung ausführen“, „Testschleife beschleunigen“, „Test schneller reparieren“ oder MTP-Hot-Reload einrichten muss, um bei Testfehlern schnell zu iterieren. Behandelt das Setup (NuGet-Paket, Umgebungsvariable, launchSettings.json) und den iterativen Workflow zum Korrigieren von Tests. NICHT VERWENDEN FÜR: das Schreiben von Testcode, die Diagnose von Testfehlern, die CI/CD-Pipeline-Konfiguration oder das Hot-Reload von Visual Studio Test Explorer (was eine andere Funktion ist).
