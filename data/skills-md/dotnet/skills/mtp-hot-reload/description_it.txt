Suggerisce di utilizzare il ricaricamento a caldo di Microsoft Testing Platform (MTP) per ripetere le correzioni sui test non riusciti senza ricompilare. Da utilizzare quando l'utente dice "test di ricaricamento a caldo", "iterazione sulla correzione del test", "esegui test senza ricostruzione", "velocizza il ciclo di test", "correzione del test più veloce" o deve impostare il ricaricamento a caldo MTP per eseguire rapidamente l'iterazione in caso di errori di test. Copre la configurazione (pacchetto NuGet, variabile di ambiente, launchSettings.json) e il flusso di lavoro iterativo per la correzione dei test. NON UTILIZZARE PER: scrittura di codice di test, diagnosi di errori di test, configurazione della pipeline CI/CD o ricaricamento a caldo di Visual Studio Test Explorer (che è una funzionalità diversa).
