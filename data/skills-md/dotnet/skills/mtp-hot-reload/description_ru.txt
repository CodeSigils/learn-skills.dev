Предлагает использовать горячую перезагрузку Microsoft Testing Platform (MTP) для итерации исправлений неудачных тестов без пересборки. Используйте, когда пользователь говорит «тесты с горячей перезагрузкой», «итерация исправления теста», «запустить тесты без перестроения», «ускорить цикл тестирования», «исправить тест быстрее» или ему необходимо настроить горячую перезагрузку MTP для быстрого повторения ошибок теста. Охватывает настройку (пакет NuGet, переменную среды, launchSettings.json) и итеративный рабочий процесс для исправления тестов. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: написания тестового кода, диагностики сбоев тестов, настройки конвейера CI/CD или горячей перезагрузки Visual Studio Test Explorer (это другая функция).
