MTP(Microsoft Testing Platform) 핫 리로드를 사용하여 다시 빌드하지 않고 실패한 테스트에 대한 수정 사항을 반복할 것을 제안합니다. 사용자가 "핫 리로드 테스트", "테스트 수정 시 반복", "재구축 없이 테스트 실행", "테스트 루프 속도 향상", "테스트 더 빠르게 수정"이라고 말하거나 테스트 실패 시 빠르게 반복하기 위해 MTP 핫 리로드를 설정해야 하는 경우에 사용합니다. 설정(NuGet 패키지, 환경 변수, launchSettings.json) 및 테스트 수정을 위한 반복 워크플로를 다룹니다. 사용하지 마십시오: 테스트 코드 작성, 테스트 실패 진단, CI/CD 파이프라인 구성 또는 Visual Studio 테스트 탐색기 핫 다시 로드(다른 기능).
