Détecte les anti-modèles et les odeurs de code dans les suites de tests .NET. À utiliser lorsque l'utilisateur demande à examiner la qualité des tests, à détecter les odeurs des tests, à identifier les indicateurs de test instables ou à auditer les tests pour détecter les erreurs courantes. Couvre la qualité des assertions, l'isolement des tests, la dénomination, les indicateurs de fragilité, la sur-moquerie et les problèmes structurels. Fonctionne avec MSTest, xUnit, NUnit et TUnit.
