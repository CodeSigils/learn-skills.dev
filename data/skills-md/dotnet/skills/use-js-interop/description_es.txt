Agregue, revise o corrija la interoperabilidad de JavaScript en los componentes de Blazor. USO PARA: llamar a JavaScript desde Blazor, llamar a .NET desde JavaScript, módulos .razor.js colocados, IJSRuntime, ciclo de vida de IJSObjectReference, DotNetObjectReference, ElementReference, reglas de tiempo para cuando JS esté disponible, eliminación IAsyncDisposable de referencias de JS, seguridad de interoperabilidad de JS del lado del servidor. NO UTILIZAR PARA: creación general de componentes Blazor sin necesidades de interoperabilidad JS (use componente de autor), formularios (use recopilación de entradas de usuario).
