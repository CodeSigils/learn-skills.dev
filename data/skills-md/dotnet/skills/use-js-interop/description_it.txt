Aggiungere, rivedere o correggere l'interoperabilità JavaScript nei componenti Blazor. UTILIZZARE PER: chiamata JavaScript da Blazor, chiamata .NET da JavaScript, moduli .razor.js collocati, IJSRuntime, ciclo di vita IJSObjectReference, DotNetObjectReference, ElementReference, regole di temporizzazione per quando JS è disponibile, eliminazione IAsyncDisposable dei riferimenti JS, sicurezza di interoperabilità JS lato server. NON UTILIZZARE PER: creazione generale di componenti Blazor senza esigenze di interoperabilità JS (usare autore-componente), moduli (usare raccogli-utente-input).
