Добавьте, проверьте или исправьте взаимодействие JavaScript в компонентах Blazor. ИСПОЛЬЗОВАНИЕ ДЛЯ: вызова JavaScript из Blazor, вызова .NET из JavaScript, совмещенных модулей .razor.js, IJSRuntime, жизненного цикла IJSObjectReference, DotNetObjectReference, ElementReference, правил синхронизации, когда JS доступен, IAsyncDisposable удаления ссылок JS, безопасности взаимодействия JS на стороне сервера. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: общей разработки компонентов Blazor без необходимости взаимодействия с JS (используйте авторский компонент), форм (используйте сбор пользовательского ввода).
