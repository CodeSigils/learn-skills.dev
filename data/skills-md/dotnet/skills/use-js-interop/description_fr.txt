Ajoutez, révisez ou corrigez l'interopérabilité JavaScript dans les composants Blazor. UTILISER POUR : appeler JavaScript depuis Blazor, appeler .NET depuis JavaScript, modules .razor.js colocalisés, IJSRuntime, cycle de vie IJSObjectReference, DotNetObjectReference, ElementReference, règles de synchronisation pour la disponibilité de JS, élimination IAsyncDisposable des références JS, sécurité d'interopérabilité JS côté serveur. NE PAS UTILISER POUR : la création générale de composants Blazor sans besoins d'interopérabilité JS (utilisez le composant auteur), les formulaires (utilisez la saisie par l'utilisateur).
