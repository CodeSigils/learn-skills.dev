Guida per la diagnosi e il miglioramento delle prestazioni di valutazione dei progetti MSBuild. Attivare solo nel contesto di compilazione MSBuild/.NET. UTILIZZO PER: compilazione lenta prima dell'inizio di qualsiasi compilazione, tempo di valutazione elevato nell'analisi binlog, modelli glob costosi che percorrono directory di grandi dimensioni (node_modules, .git, bin/obj), catene di importazione profonde (>20 livelli), output preelaborato >10K righe che indicano una valutazione pesante, funzioni di proprietà con I/O di file ($([System.IO.File]::ReadAllText(...))), valutazioni multiple per progetto. Copre le 5 fasi di valutazione di MSBuild, l'ottimizzazione dei glob tramite DefaultItemExcludes, l'analisi della catena di importazione con la preelaborazione /pp. NON UTILIZZARE PER: lentezza in fase di compilazione (utilizzare build-perf-diagnostics), problemi di compilazione incrementale (utilizzare incremental-build), sistemi di compilazione non MSBuild. RICHIAMA: dotnet msbuild -pp:full.xml per la preelaborazione, /clp:PerformanceSummary.
