Conseils pour la configuration de l'injection de dépendances dans les applications .NET MAUI : enregistrement de service dans MauiProgram.cs, sélection à vie (Singleton/Transient/Scoped), injection de constructeur, résolution automatique de navigation Shell, enregistrements spécifiques à la plate-forme et modèles de testabilité. UTILISER POUR : "injection de dépendances", "configuration DI", "AddSingleton", "AddTransient", "AddScoped", "enregistrement de service", "injection de constructeur", "IServiceProvider", "MauiProgram DI", "registre des services", "injection de BindingContext". NE PAS UTILISER POUR : la liaison de données (utilisez maui-data-binding), la configuration d'itinéraire Shell (utilisez maui-shell-navigation), les frameworks moqueurs de tests unitaires (utilisez les modèles standard xUnit et NSubstitute).
