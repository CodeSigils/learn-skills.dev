優化 MSBuild 建置平行性和多專案調度的指南。僅在 MSBuild/.NET 建置上下文中啟動。用途：不利用所有 CPU 核心進行建置、加速多專案解決方案、評估圖形建置模式 (/graph)、使用 -m 標誌未改善建置時間、了解專案依賴關係拓撲。注意：/maxcpucount 預設為 1（順序）— 始終使用 -m 進行平行建置。涵蓋 /maxcpucount、圖形建置以實現更好的調度和隔離、MSBuild 任務上的 BuildInParallel、減少不必要的 ProjectReferences、用於建立子集的解決方案過濾器 (.slnf)。請勿用於：單一專案建置、增量建置問題（使用增量建置）、專案內的編譯緩慢（使用建置效能診斷）、非 MSBuild 建置系統。呼叫：dotnet build -m、dotnet build /graph、binlog 分析。
