优化 MSBuild 构建并行性和多项目调度的指南。仅在 MSBuild/.NET 构建上下文中激活。用途：不利用所有 CPU 核心进行构建、加速多项目解决方案、评估图形构建模式 (/graph)、使用 -m 标志未改善构建时间、了解项目依赖关系拓扑。注意：/maxcpucount 默认为 1（顺序）— 始终使用 -m 进行并行构建。涵盖 /maxcpucount、图形构建以实现更好的调度和隔离、MSBuild 任务上的 BuildInParallel、减少不必要的 ProjectReferences、用于构建子集的解决方案过滤器 (.slnf)。请勿用于：单项目构建、增量构建问题（使用增量构建）、项目内的编译缓慢（使用构建性能诊断）、非 MSBuild 构建系统。调用：dotnet build -m、dotnet build /graph、binlog 分析。
