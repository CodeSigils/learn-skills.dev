C# SDK および .NET プロジェクト テンプレートを使用して MCP サーバーを作成します。スキャフォールディング、ツール/プロンプト/リソースの実装、標準入出力と HTTP のトランスポート構成について説明します。用途: 新しい MCP サーバー プロジェクトの作成、dotnet new mcpserver によるスキャフォールディング、MCP ツール/プロンプト/リソースの追加、標準入出力と HTTP トランスポートの選択、Program.cs での MCP ホスティングの構成、MapMcp を使用した ASP.NET Core MCP エンドポイントのセットアップ。次の用途には使用しないでください: 既存サーバーのデバッグまたは実行 (mcp-csharp-debug を使用)、テストの作成 (mcp-csharp-test を使用)、公開またはデプロイ (mcp-csharp-publish を使用)、MCP クライアントの構築、非 .NET MCP サーバー。
