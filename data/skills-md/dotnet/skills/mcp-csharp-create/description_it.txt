Crea server MCP utilizzando i modelli di progetto C# SDK e .NET. Copre l'impalcatura, l'implementazione di strumenti/prompt/risorse e la configurazione del trasporto per stdio e HTTP. UTILIZZO PER: creazione di nuovi progetti server MCP, impalcatura con dotnet new mcpserver, aggiunta di strumenti/prompt/risorse MCP, scelta del trasporto stdio vs HTTP, configurazione dell'hosting MCP in Program.cs, configurazione degli endpoint MCP ASP.NET Core con MapMcp. NON UTILIZZARE PER: debug o esecuzione di server esistenti (utilizzare mcp-csharp-debug), scrittura di test (utilizzare mcp-csharp-test), pubblicazione o distribuzione (utilizzare mcp-csharp-publish), creazione di client MCP, server MCP non .NET.
