C# SDK 및 .NET 프로젝트 템플릿을 사용하여 MCP 서버를 만듭니다. stdio 및 HTTP에 대한 스캐폴딩, 도구/프롬프트/리소스 구현, 전송 구성을 다룹니다. 사용 대상: 새 MCP 서버 프로젝트 생성, dotnet new mcpserver를 사용한 스캐폴딩, MCP 도구/프롬프트/리소스 추가, stdio 및 HTTP 전송 선택, Program.cs에서 MCP 호스팅 구성, MapMcp를 사용하여 ASP.NET Core MCP 엔드포인트 설정. 사용하지 마십시오: 기존 서버 디버깅 또는 실행(mcp-csharp-debug 사용), 테스트 작성(mcp-csharp-test 사용), 게시 또는 배포(mcp-csharp-publish 사용), MCP 클라이언트 구축, 비.NET MCP 서버.
