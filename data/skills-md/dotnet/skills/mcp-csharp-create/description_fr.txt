Créez des serveurs MCP à l'aide des modèles de projet C# SDK et .NET. Couvre l'échafaudage, la mise en œuvre d'outils/invites/ressources et la configuration du transport pour stdio et HTTP. UTILISER POUR : créer de nouveaux projets de serveur MCP, échafaudage avec le nouveau serveur mcpserver dotnet, ajouter des outils/invites/ressources MCP, choisir le transport stdio vs HTTP, configurer l'hébergement MCP dans Program.cs, configurer les points de terminaison ASP.NET Core MCP avec MapMcp. NE PAS UTILISER POUR : le débogage ou l'exécution de serveurs existants (utilisez mcp-csharp-debug), l'écriture de tests (utilisez mcp-csharp-test), la publication ou le déploiement (utilisez mcp-csharp-publish), la création de clients MCP, de serveurs MCP non .NET.
