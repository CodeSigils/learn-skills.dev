Создайте серверы MCP, используя шаблоны проектов C# SDK и .NET. Охватывает создание шаблонов, реализацию инструментов/подсказок/ресурсов и конфигурацию транспорта для stdio и HTTP. ИСПОЛЬЗОВАНИЕ ДЛЯ: создания новых проектов серверов MCP, создания шаблонов с помощью нового mcpserver dotnet, добавления инструментов/подсказок/ресурсов MCP, выбора транспорта stdio или HTTP, настройки хостинга MCP в Program.cs, настройки конечных точек ASP.NET Core MCP с помощью MapMcp. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: отладки или запуска существующих серверов (используйте mcp-csharp-debug), написания тестов (используйте mcp-csharp-test), публикации или развертывания (используйте mcp-csharp-publish), создания клиентов MCP, серверов MCP, отличных от .NET.
