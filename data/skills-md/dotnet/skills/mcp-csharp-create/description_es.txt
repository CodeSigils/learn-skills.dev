Cree servidores MCP utilizando el SDK de C# y las plantillas de proyecto .NET. Cubre andamios, implementación de herramientas/indicadores/recursos y configuración de transporte para stdio y HTTP. UTILIZAR PARA: crear nuevos proyectos de servidor MCP, realizar scaffolding con dotnet new mcpserver, agregar herramientas/solicitudes/recursos de MCP, elegir transporte stdio vs HTTP, configurar alojamiento de MCP en Program.cs, configurar puntos finales de ASP.NET Core MCP con MapMcp. NO LO UTILICE PARA: depurar o ejecutar servidores existentes (use mcp-csharp-debug), escribir pruebas (use mcp-csharp-test), publicar o implementar (use mcp-csharp-publish), crear clientes MCP, servidores MCP que no sean .NET.
