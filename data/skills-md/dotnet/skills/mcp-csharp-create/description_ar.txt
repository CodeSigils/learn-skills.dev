قم بإنشاء خوادم MCP باستخدام قوالب مشروع C# SDK و.NET. يغطي السقالات، وتنفيذ الأدوات/المطالبات/الموارد، وتكوين النقل لـ stdio وHTTP. الاستخدام من أجل: إنشاء مشاريع خادم MCP جديدة، والسقالات باستخدام dotnet mcpserver الجديد، وإضافة أدوات/مطالبات/موارد MCP، واختيار نقل stdio مقابل HTTP، وتكوين استضافة MCP في Program.cs، وإعداد نقاط نهاية ASP.NET Core MCP باستخدام MapMcp. لا تستخدمه من أجل: تصحيح الأخطاء أو تشغيل الخوادم الموجودة (استخدم mcp-csharp-debug)، أو كتابة الاختبارات (استخدم mcp-csharp-test)، أو النشر أو النشر (استخدم mcp-csharp-publish)، أو إنشاء عملاء MCP، أو خوادم غير تابعة لـ .NET MCP.
