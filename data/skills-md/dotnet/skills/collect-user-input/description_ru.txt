Создавайте формы, проверяйте данные и реагируйте на вводимые пользователем данные в Blazor. ИСПОЛЬЗУЕТСЯ ДЛЯ добавления форм, полей поиска, панелей фильтров, встроенного редактирования, пользовательского интерфейса для ввода данных, загрузки файлов, проверки (аннотаций или настраиваемых), обработки отправки форм и привязки элементов управления вводом. Охватывает EditForm, встроенные компоненты ввода, DataAnnotationsValidator, пользовательскую проверку, шаблоны форм SSR (SupplyParameterFromForm, FormName, AntiforgeryToken, Enhance) и @bind для простых интерактивных элементов управления. НЕ ИСПОЛЬЗУЙТЕ для создания каркаса проекта (см. create-blazor-project) или проблем с предварительной отрисовкой (см. поддержку предварительной визуализации).
