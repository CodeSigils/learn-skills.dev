Guía la migración del uso de .NET Framework Thread.Abort a la cancelación cooperativa en .NET moderno. UTILIZAR PARA: modernizar el código que llama a Thread.Abort, detectar ThreadAbortException, reemplazar Thread.ResetAbort, reemplazar Thread.Interrupt para la terminación de subprocesos, resolver PlatformNotSupportedException o SYSLIB0006 después de reorientar a .NET 6+, migrar ASP.NET Response.End o Response.Redirect(url, true) que llaman internamente a Thread.Abort. NO UTILIZAR PARA: código que solo usa Thread.Join, Thread.Sleep o Thread.Start sin ningún tipo de aborto, interrupción o uso de ThreadAbortException; estas API funcionan de manera idéntica en .NET moderno y no necesitan migración. Tampoco para proyectos que permanecen en .NET Framework o el uso de Thread.Abort dentro de bibliotecas de terceros que no controla.
