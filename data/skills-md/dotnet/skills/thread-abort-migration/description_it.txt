Guida la migrazione dell'utilizzo di .NET Framework Thread.Abort all'annullamento cooperativo in .NET moderno. UTILIZZARE PER: modernizzare il codice che chiama Thread.Abort, rilevare ThreadAbortException, sostituire Thread.ResetAbort, sostituire Thread.Interrupt per la terminazione del thread, risolvere PlatformNotSupportedException o SYSLIB0006 dopo il retargeting a .NET 6+, migrare ASP.NET Response.End o Response.Redirect(url, true) che chiamano internamente Thread.Abort. NON UTILIZZARE PER: codice che utilizza solo Thread.Join, Thread.Sleep o Thread.Start senza alcun utilizzo di interruzione, interruzione o ThreadAbortException: queste API funzionano in modo identico nel moderno .NET e non necessitano di migrazione. Inoltre, non per i progetti che rimangono su .NET Framework o per l'utilizzo di Thread.Abort all'interno di librerie di terze parti che non controlli.
