Guide la migration de l’utilisation de .NET Framework Thread.Abort vers l’annulation coopérative dans .NET moderne. UTILISER POUR : moderniser le code qui appelle Thread.Abort, intercepter ThreadAbortException, remplacer Thread.ResetAbort, remplacer Thread.Interrupt pour la terminaison du thread, résoudre PlatformNotSupportedException ou SYSLIB0006 après le reciblage vers .NET 6+, migrer ASP.NET Response.End ou Response.Redirect(url, true) qui appelle en interne Thread.Abort. NE PAS UTILISER POUR : le code qui utilise uniquement Thread.Join, Thread.Sleep ou Thread.Start sans aucune utilisation d'abandon, d'interruption ou de ThreadAbortException : ces API fonctionnent de manière identique dans le .NET moderne et ne nécessitent aucune migration. Pas non plus pour les projets restant sur .NET Framework ou pour l'utilisation de Thread.Abort dans des bibliothèques tierces que vous ne contrôlez pas.
