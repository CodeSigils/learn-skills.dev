指导 .NET Framework Thread.Abort 使用迁移到现代 .NET 中的协作取消。用途：现代化调用 Thread.Abort 的代码、捕获 ThreadAbortException、替换 Thread.ResetAbort、替换 Thread.Interrupt 以进行线程终止、重定向到 .NET 6+ 后解决 PlatformNotSupportedException 或 SYSLIB0006、迁移内部调用 Thread.Abort 的 ASP.NET Response.End 或 Response.Redirect(url, true)。请勿用于：仅使用 Thread.Join、Thread.Sleep 或 Thread.Start 而不使用任何中止、中断或 ThreadAbortException 的代码 — 这些 API 在现代 .NET 中的工作方式相同，无需迁移。也不适用于留在 .NET Framework 上的项目，或您无法控制的第三方库中的 Thread.Abort 使用情况。
