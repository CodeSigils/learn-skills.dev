Leitet die Migration der .NET Framework Thread.Abort-Nutzung zum kooperativen Abbruch in modernem .NET. VERWENDUNG FÜR: Modernisieren von Code, der Thread.Abort aufruft, Abfangen von ThreadAbortException, Ersetzen von Thread.ResetAbort, Ersetzen von Thread.Interrupt für die Thread-Beendigung, Auflösen von PlatformNotSupportedException oder SYSLIB0006 nach dem Retargeting auf .NET 6+, Migrieren von ASP.NET Response.End oder Response.Redirect(url, true), die Thread.Abort intern aufrufen. NICHT VERWENDEN FÜR: Code, der nur Thread.Join, Thread.Sleep oder Thread.Start ohne Verwendung von Abort, Interrupt oder ThreadAbortException verwendet – diese APIs funktionieren in modernem .NET identisch und erfordern keine Migration. Auch nicht für Projekte, die auf .NET Framework bleiben, oder für die Verwendung von Thread.Abort in Bibliotheken von Drittanbietern, die Sie nicht kontrollieren.
