Направляет миграцию использования .NET Framework Thread.Abort на совместную отмену в современной .NET. ИСПОЛЬЗОВАНИЕ ДЛЯ: модернизации кода, который вызывает Thread.Abort, перехвата ThreadAbortException, замены Thread.ResetAbort, замены Thread.Interrupt для завершения потока, разрешения PlatformNotSupportedException или SYSLIB0006 после перенацеливания на .NET 6+, миграции ASP.NET Response.End или Response.Redirect(url, true), которые внутренне вызывают Thread.Abort. НЕ ИСПОЛЬЗУЙТЕ FOR: код, который использует только Thread.Join, Thread.Sleep или Thread.Start без каких-либо прерываний, прерываний или использования ThreadAbortException — эти API работают одинаково в современной .NET и не требуют миграции. Также не касается проектов, использующих .NET Framework, или использования Thread.Abort внутри сторонних библиотек, которые вы не контролируете.
