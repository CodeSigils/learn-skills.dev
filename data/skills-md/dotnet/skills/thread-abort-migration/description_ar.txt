يرشد ترحيل استخدام .NET Framework Thread.Abort إلى الإلغاء التعاوني في .NET الحديث. الاستخدام لـ: تحديث التعليمات البرمجية التي تستدعي Thread.Abort، والتقاط ThreadAbortException، واستبدال Thread.ResetAbort، واستبدال Thread.Interrupt لإنهاء مؤشر الترابط، وحل PlatformNotSupportedException أو SYSLIB0006 بعد إعادة الاستهداف إلى .NET 6+، وترحيل ASP.NET Response.End أو Response.Redirect(url, true) الذي يستدعي Thread.Abort داخليًا. لا تستخدمه من أجل: التعليمات البرمجية التي تستخدم Thread.Join أو Thread.Sleep أو Thread.Start فقط دون أي إحباط أو مقاطعة أو استخدام ThreadAbortException - تعمل واجهات برمجة التطبيقات هذه بشكل مماثل في .NET الحديثة ولا تحتاج إلى ترحيل. أيضًا ليس للمشاريع التي تظل على .NET Framework، أو استخدام Thread.Abort داخل مكتبات الجهات الخارجية التي لا تتحكم فيها.
