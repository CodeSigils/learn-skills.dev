指導 .NET Framework Thread.Abort 使用遷移到現代 .NET 中的協作取消。用途：現代化調用 Thread.Abort 的程式碼、捕獲 ThreadAbortException、替換 Thread.ResetAbort、替換 Thread.Interrupt 以進行線程終止、重定向到 .NET 6+ 後解決 PlatformNotSupportedException 或 SYSLIB0006、遷移內部.請勿用於：僅使用 Thread.Join、Thread.Sleep 或 Thread.Start 而不使用任何中止、中斷或 ThreadAbortException 的程式碼 — 這些 API 在現代 .NET 中的工作方式相同，無需遷移。也不適用於留在 .NET Framework 上的項目，或您無法控制的第三方程式庫中的 Thread.Abort 使用情況。
