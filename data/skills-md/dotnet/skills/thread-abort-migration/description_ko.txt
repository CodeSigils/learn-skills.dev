.NET Framework Thread.Abort 사용을 최신 .NET의 협력 취소로 마이그레이션하는 방법을 안내합니다. 사용 대상: Thread.Abort를 호출하는 코드 현대화, ThreadAbortException 포착, Thread.ResetAbort 교체, 스레드 종료를 위한 Thread.Interrupt 교체, .NET 6+로 대상 변경 후 PlatformNotSupportedException 또는 SYSLIB0006 해결, 내부적으로 Thread.Abort를 호출하는 ASP.NET Response.End 또는 Response.Redirect(url, true) 마이그레이션. 사용하지 마십시오: 중단, 인터럽트 또는 ThreadAbortException을 사용하지 않고 Thread.Join, Thread.Sleep 또는 Thread.Start만 사용하는 코드 — 이러한 API는 최신 .NET에서 동일하게 작동하며 마이그레이션이 필요하지 않습니다. 또한 .NET Framework에 머무르는 프로젝트나 제어할 수 없는 타사 라이브러리 내부의 Thread.Abort 사용에는 적합하지 않습니다.
