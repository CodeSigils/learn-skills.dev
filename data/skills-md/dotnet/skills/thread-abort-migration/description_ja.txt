.NET Framework Thread.Abort の使用を最新の .NET での協調キャンセルに移行するガイドです。用途: Thread.Abort を呼び出すコードの最新化、ThreadAbortException のキャッチ、Thread.ResetAbort の置き換え、スレッド終了のための Thread.Interrupt の置き換え、.NET 6 以降への再ターゲット後の PlatformNotSupportedException または SYSLIB0006 の解決、内部で Thread.Abort を呼び出す ASP.NET Response.End または Response.Redirect(url, true) の移行。 FOR: 中止、割り込み、または ThreadAbortException を使用せずに Thread.Join、Thread.Sleep、または Thread.Start のみを使用するコードは使用しないでください。これらの API は最新の .NET で同様に動作するため、移行の必要はありません。また、.NET Framework 上に留まっているプロジェクトや、制御していないサードパーティ ライブラリ内での Thread.Abort の使用も対象外です。
