アプリのレンダリング モードを考慮して、Blazor Web アプリに認証と承認を追加します。ユーザーがページ、AuthorizeView、ロールまたはポリシーベースのアクセス、ログイン/ログアウト ID ページ、または AuthenticationStateProvider で [Authorize] を必要とする場合に使用します。また、WebAssembly のロード後に認証状態が null である場合、SignInManager がインタラクティブ コンポーネントをスローする場合、<NotAuthorized> コンテンツが静的 SSR でレンダリングされない場合、またはインタラクティブ コンポーネントで HttpContext.User が null の場合にも使用します。一般的なコンポーネントのオーサリング (author-component を参照)、認証に関係のない事前レンダリング (support-prerendering を参照)、非認証カスケード状態の管理 (coordine-component を参照) には使用しないでください。
