앱의 렌더링 모드를 고려하여 Blazor Web App에 인증 및 권한 부여를 추가합니다. 사용자가 페이지, AuthorizeView, 역할 또는 정책 기반 액세스, 로그인/로그아웃 ID 페이지 또는 AuthenticationStateProvider에서 [승인]을 요구할 때 사용합니다. 또한 WebAssembly가 로드된 후 인증 상태가 null이거나, SignInManager가 대화형 구성 요소를 발생시키거나, <NotAuthorized> 콘텐츠가 정적 SSR에서 렌더링되지 않거나, HttpContext.User가 대화형 구성 요소에서 null인 경우에도 사용하세요. 일반 구성 요소 작성(작성 구성 요소 참조), 인증과 관련 없는 사전 렌더링 문제(지원 사전 렌더링 참조) 또는 비인증 연속 상태 관리(좌표 구성 요소 참조)에는 사용하지 마세요.
