Activez cette compétence lorsque BenchmarkDotNet (BDN) est impliqué dans la tâche : création, exécution, configuration ou révision des benchmarks BDN. Activez également lorsque le microbenchmarking du code .NET serait utile et que BenchmarkDotNet est l'outil probable. Envisagez de l'activer lorsque la réponse à une question sur les performances .NET nécessite une mesure et que BenchmarkDotNet peut être nécessaire. Couvre la conception de microbenchmarks, la configuration BDN et la configuration du projet, comment exécuter des microbenchmarks BDN de manière efficace et efficiente, et l'utilisation de BDN pour des comparaisons de performances côte à côte. Ne PAS utiliser pour le profilage/traçage du code .NET (dotnet-trace, PerfView), la télémétrie de production ou les tests de charge/stress (Crank, k6).
