Active esta habilidad cuando BenchmarkDotNet (BDN) esté involucrado en la tarea: crear, ejecutar, configurar o revisar puntos de referencia de BDN. Actívelo también cuando el código .NET de microbenchmarking sea útil y BenchmarkDotNet sea la herramienta probable. Considere la posibilidad de activarlo cuando responder una pregunta sobre el rendimiento de .NET requiera una medición y pueda ser necesario BenchmarkDotNet. Cubre el diseño de microbenchmarks, la configuración de BDN y la configuración del proyecto, cómo ejecutar microbenchmarks de BDN de manera eficiente y efectiva, y el uso de BDN para comparaciones de rendimiento en paralelo. NO lo utilice para crear perfiles/rastrear código .NET (dotnet-trace, PerfView), telemetría de producción o pruebas de carga/estrés (Crank, k6).
