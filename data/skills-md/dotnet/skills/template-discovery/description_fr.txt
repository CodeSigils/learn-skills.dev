Aide à trouver, inspecter et comparer les modèles de projets .NET. Résout les descriptions de projets en langage naturel en correspondances de modèles classées avec des paramètres pré-remplis. UTILISER POUR : trouver le nouveau modèle dotnet approprié pour une tâche, comparer les modèles côte à côte, inspecter les paramètres et les contraintes du modèle, comprendre ce qu'un modèle produit avant de créer un projet, résoudre une intention telle que "API Web avec authentification" en modèle + paramètres concrets. NE PAS UTILISER POUR : la création réelle de projets (utilisez l'instanciation de modèle), la création de modèles personnalisés (utilisez la création de modèles), les problèmes MSBuild ou de build (utilisez le plugin dotnet-msbuild), la gestion des packages NuGet sans rapport avec les packages de modèles.
