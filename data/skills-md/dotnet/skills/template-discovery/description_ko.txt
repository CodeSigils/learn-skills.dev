.NET 프로젝트 템플릿을 찾고 검사하고 비교하는 데 도움이 됩니다. 미리 채워진 매개변수를 사용하여 자연어 프로젝트 설명을 순위가 매겨진 템플릿 일치로 해결합니다. 사용 대상: 작업에 적합한 새 dotnet 템플릿 찾기, 템플릿을 나란히 비교, 템플릿 매개변수 및 제약 조건 검사, 프로젝트를 만들기 전에 템플릿이 생성하는 내용 이해, "인증이 포함된 웹 API"와 같은 의도를 구체적인 템플릿 + 매개변수로 해결. 사용하지 마십시오: 실제로 프로젝트 생성(템플릿 인스턴스화 사용), 사용자 지정 템플릿 작성(템플릿 작성 사용), MSBuild 또는 빌드 문제(dotnet-msbuild 플러그인 사용), 템플릿 패키지와 관련 없는 NuGet 패키지 관리.
