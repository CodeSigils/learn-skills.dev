Helps find, inspect, and compare .NET project templates. Resolves natural-language project descriptions to ranked template matches with pre-filled parameters.用途: タスクに適した dotnet 新しいテンプレートを見つける、テンプレートを並べて比較する、テンプレート パラメーターと制約を検査する、プロジェクトを作成する前にテンプレートが生成する内容を理解する、「認証付き Web API」などの意図を具体的なテンプレート + パラメーターに解決する。次の用途には使用しないでください: 実際にプロジェクトを作成する場合 (テンプレート インスタンス化を使用する)、カスタム テンプレートを作成する場合 (テンプレート オーサリングを使用する)、MSBuild またはビルドの問題 (dotnet-msbuild プラグインを使用する)、テンプレート パッケージに関係のない NuGet パッケージ管理。
