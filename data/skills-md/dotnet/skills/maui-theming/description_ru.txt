Руководство по темированию приложений .NET MAUI — светлый/темный режим с помощью AppThemeBinding, переключение тем ResourceDictionary, привязки DynamicResource, определение системной темы и настройки пользовательских тем. Используйте, когда: «темный режим», «светлый режим», «темы», «AppThemeBinding», «переключение темы», «тема ResourceDictionary», «динамические ресурсы», «обнаружение системной темы», «цветовая схема», «тема приложения», «DynamicResource». Не используйте для: локализации или переключения языка (см. документацию по локализации .NET MAUI), визуальной настройки специальных возможностей (см. документацию по специальным возможностям .NET MAUI), значков приложений или заставок (см. документацию по значкам приложений .NET MAUI) или оформления тем класса в стиле Bootstrap (см. пакет NuGet Plugin.Maui.BootstrapTheme).
