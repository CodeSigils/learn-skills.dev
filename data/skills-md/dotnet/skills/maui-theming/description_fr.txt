Guide de thématisation des applications .NET MAUI — mode clair/sombre via AppThemeBinding, changement de thème ResourceDictionary, liaisons DynamicResource, détection de thème système et préférences de thème utilisateur. À utiliser lorsque : "mode sombre", "mode clair", "thème", "AppThemeBinding", "changement de thème", "thème ResourceDictionary", "ressources dynamiques", "détection de thème système", "jeu de couleurs", "thème d'application", "DynamicResource". Ne pas utiliser pour : la localisation ou le changement de langue (voir la documentation de localisation .NET MAUI), les ajustements visuels d'accessibilité (voir la documentation sur l'accessibilité .NET MAUI), les icônes d'application ou les écrans de démarrage (voir la documentation sur les icônes d'application .NET MAUI) ou la thématisation de classe de style Bootstrap (voir le package NuGet Plugin.Maui.BootstrapTheme).
