دليل لإنشاء تطبيقات .NET MAUI - الوضع الفاتح/الداكن عبر AppThemeBinding، وتبديل سمات ResourceDictionary، وربط DynamicResource، واكتشاف سمات النظام، وتفضيلات سمات المستخدم. يُستخدم عندما: "الوضع الداكن"، "الوضع الفاتح"، "theming"، "AppThemeBinding"، "تبديل السمة"، "سمة ResourceDictionary"، "الموارد الديناميكية"، "اكتشاف سمة النظام"، "نظام الألوان"، "سمة التطبيق"، "DynamicResource". لا تستخدم من أجل: الترجمة أو تبديل اللغة (راجع وثائق ترجمة .NET MAUI)، أو التعديلات المرئية لإمكانية الوصول (راجع وثائق إمكانية الوصول إلى .NET MAUI)، أو أيقونات التطبيقات أو شاشات البداية (راجع وثائق أيقونات تطبيقات .NET MAUI)، أو تخصيص فئات نمط Bootstrap (راجع حزمة Plugin.Maui.BootstrapTheme NuGet).
