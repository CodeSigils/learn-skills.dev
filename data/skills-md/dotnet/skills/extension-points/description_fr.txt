Guide pour l’extensibilité MSBuild : hooks CustomBefore/CustomAfter, importations de caractères génériques avec ordre alphabétique, contrôle d’importation avec propriétés de contrôle, disposition de l’extension de build du package NuGet (build/buildTransitive) et protection MicrosoftCommonPropsHasBeenImported. UTILISER POUR : diagnostiquer et corriger les modèles d'importation et de hook MSBuild, examiner et corriger les anti-modèles de point d'extension dans les fichiers Directory.Build, corriger les protections Exists() manquantes sur les importations qui brisent les nouveaux clones, corriger les hooks de package NuGet qui sont supprimés silencieusement au lieu d'être ajoutés, rendre les cibles de build extensibles pour d'autres projets, injecter une logique personnalisée dans le pipeline de build, créer des packages NuGet qui étendent la build, désactiver conditionnellement les importations. NE PAS UTILISER POUR : les modèles de création cible (utiliser la création cible), le placement des accessoires par rapport aux cibles (utiliser l'organisation de construction de répertoire), les anti-modèles généraux (utiliser les anti-modèles msbuild), les systèmes de construction non MSBuild.
