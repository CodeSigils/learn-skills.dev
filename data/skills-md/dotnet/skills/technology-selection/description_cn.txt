使用 ML.NET、Microsoft.Extensions.AI (MEAI)、Microsoft Agent Framework (MAF)、GitHub Copilot SDK、ONNX Runtime 和 OllamaSharp 指导 .NET 8+ 应用程序中 AI 和 ML 功能的技术选择和实现。涵盖从经典 ML 到现代 LLM 编排再到本地推理的全方位。在将分类、回归、聚类、异常检测、推荐、LLM 集成（文本生成、摘要、推理）、带有矢量搜索的 RAG 管道、带有工具调用的代理工作流、Copilot 扩展或通过 ONNX 运行时的自定义模型推理添加到 .NET 项目时使用。请勿用于面向 .NET Framework 的项目（需要 .NET 8+）、任务是纯数据工程或没有 ML/AI 组件的 ETL，或者项目需要自定义深度学习训练循环（将 Python 与 PyTorch/TensorFlow 结合使用，然后导出到 ONNX 进行 .NET 推理）。
