使用 ML.NET、Microsoft.Extensions.AI (MEAI)、Microsoft Agent Framework (MAF)、GitHub Copilot SDK、ONNX Runtime 和 OllamaSharp 指導 .NET 8+ 應用程式中 AI 和 ML 功能的技術選擇和實作。涵蓋從經典 ML 到現代 LLM 編排再到本地推理的全方位。在將分類、回歸、聚類、異常檢測、推薦、LLM 整合（文字生成、摘要、推理）、帶有向量搜尋的 RAG 管道、帶有工具呼叫的代理工作流程、Copilot 擴充或透過 ONNX 執行時間的自訂模型推理新增至 .NET 專案時使用。請勿用於 .NET Framework 的專案（需要 .NET 8+）、任務是純資料工程或沒有 ML/AI 元件的 ETL，或專案需要自訂深度學習訓練循環（將 Python 與 PyTorch/TensorFlow 結合使用，然後匯出到 ONNX 進行 .NET 推理）。
