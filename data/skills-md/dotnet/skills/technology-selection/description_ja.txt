ML.NET、Microsoft.Extensions.AI (MEAI)、Microsoft Agent Framework (MAF)、GitHub Copilot SDK、ONNX ランタイム、および OllamaSharp を使用した .NET 8 以降のアプリケーションでの AI および ML 機能のテクノロジーの選択と実装をガイドします。古典的な ML から最新の LLM オーケストレーション、ローカル推論までの全範囲をカバーします。分類、回帰、クラスタリング、異常検出、推奨、LLM 統合 (テキスト生成、要約、推論)、ベクトル検索を備えた RAG パイプライン、ツール呼び出しを備えたエージェント ワークフロー、コパイロット拡張機能、または ONNX ランタイムを介したカスタム モデル推論を .NET プロジェクトに追加するときに使用します。 .NET Framework をターゲットとするプロジェクト (.NET 8 以降が必要)、タスクが ML/AI コンポーネントを含まない純粋なデータ エンジニアリングまたは ETL である場合、またはプロジェクトにカスタムの深層学習トレーニング ループが必要な場合は使用しないでください (PyTorch/TensorFlow で Python を使用し、.NET 推論のために ONNX にエクスポートします)。
