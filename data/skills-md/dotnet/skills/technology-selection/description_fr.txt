Guide la sélection technologique et la mise en œuvre des fonctionnalités d'IA et de ML dans les applications .NET 8+ à l'aide de ML.NET, Microsoft.Extensions.AI (MEAI), Microsoft Agent Framework (MAF), GitHub Copilot SDK, ONNX Runtime et OllamaSharp. Couvre tout le spectre, du ML classique à l'orchestration LLM moderne en passant par l'inférence locale. À utiliser lors de l'ajout de classification, de régression, de clustering, de détection d'anomalies, de recommandations, d'intégration LLM (génération de texte, résumé, raisonnement), de pipelines RAG avec recherche vectorielle, de flux de travail agents avec appel d'outils, d'extensions Copilot ou d'inférence de modèle personnalisé via ONNX Runtime à un projet .NET. NE PAS UTILISER POUR les projets ciblant .NET Framework (nécessite .NET 8+), la tâche est une pure ingénierie de données ou ETL sans composant ML/AI, ou le projet nécessite une boucle de formation d'apprentissage en profondeur personnalisée (utilisez Python avec PyTorch/TensorFlow, puis exportez vers ONNX pour l'inférence .NET).
