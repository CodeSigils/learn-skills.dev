Leitet die Technologieauswahl und Implementierung von KI- und ML-Funktionen in .NET 8+-Anwendungen mit ML.NET, Microsoft.Extensions.AI (MEAI), Microsoft Agent Framework (MAF), GitHub Copilot SDK, ONNX Runtime und OllamaSharp. Deckt das gesamte Spektrum von klassischem ML über moderne LLM-Orchestrierung bis hin zu lokaler Inferenz ab. Verwendung beim Hinzufügen von Klassifizierung, Regression, Clustering, Anomalieerkennung, Empfehlung, LLM-Integration (Textgenerierung, Zusammenfassung, Argumentation), RAG-Pipelines mit Vektorsuche, Agenten-Workflows mit Tool-Aufruf, Copilot-Erweiterungen oder benutzerdefinierter Modellinferenz über ONNX Runtime zu einem .NET-Projekt. NICHT FÜR Projekte verwenden, die auf .NET Framework abzielen (erfordert .NET 8+), die Aufgabe reines Data Engineering oder ETL ohne ML/AI-Komponente ist oder das Projekt eine benutzerdefinierte Deep-Learning-Trainingsschleife benötigt (verwenden Sie Python mit PyTorch/TensorFlow und exportieren Sie dann nach ONNX für .NET-Inferenz).
