Guida la selezione della tecnologia e l'implementazione delle funzionalità AI e ML nelle applicazioni .NET 8+ utilizzando ML.NET, Microsoft.Extensions.AI (MEAI), Microsoft Agent Framework (MAF), GitHub Copilot SDK, ONNX Runtime e OllamaSharp. Copre l'intero spettro dal classico ML alla moderna orchestrazione LLM fino all'inferenza locale. Da utilizzare quando si aggiungono classificazione, regressione, clustering, rilevamento di anomalie, raccomandazioni, integrazione LLM (generazione di testo, riepilogo, ragionamento), pipeline RAG con ricerca vettoriale, flussi di lavoro agenti con chiamata di strumenti, estensioni Copilot o inferenza di modelli personalizzati tramite ONNX Runtime a un progetto .NET. NON UTILIZZARE PER progetti destinati a .NET Framework (richiede .NET 8+), l'attività è pura ingegneria dei dati o ETL senza componenti ML/AI oppure il progetto necessita di un ciclo di formazione di deep learning personalizzato (usa Python con PyTorch/TensorFlow, quindi esporta in ONNX per l'inferenza .NET).
