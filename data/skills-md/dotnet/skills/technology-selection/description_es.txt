Guía la selección de tecnología y la implementación de funciones de IA y ML en aplicaciones .NET 8+ usando ML.NET, Microsoft.Extensions.AI (MEAI), Microsoft Agent Framework (MAF), GitHub Copilot SDK, ONNX Runtime y OllamaSharp. Cubre todo el espectro, desde el aprendizaje automático clásico hasta la orquestación LLM moderna y la inferencia local. Úselo al agregar clasificación, regresión, agrupamiento, detección de anomalías, recomendación, integración LLM (generación de texto, resumen, razonamiento), canalizaciones RAG con búsqueda vectorial, flujos de trabajo agentes con llamada de herramientas, extensiones Copilot o inferencia de modelo personalizado a través de ONNX Runtime a un proyecto .NET. NO LO UTILICE PARA proyectos dirigidos a .NET Framework (requiere .NET 8+), la tarea es pura ingeniería de datos o ETL sin componente ML/AI, o el proyecto necesita un bucle de entrenamiento de aprendizaje profundo personalizado (use Python con PyTorch/TensorFlow, luego exporte a ONNX para inferencia .NET).
