يرشد اختيار التكنولوجيا وتنفيذ ميزات الذكاء الاصطناعي والتعلم الآلي في تطبيقات .NET 8+ باستخدام ML.NET وMicrosoft.Extensions.AI (MEAI) وMicrosoft Agent Framework (MAF) وGitHub Copilot SDK وONNX Runtime وOllamaSharp. يغطي النطاق الكامل بدءًا من تعلم الآلة الكلاسيكي وحتى تنسيق LLM الحديث وحتى الاستدلال المحلي. يُستخدم عند إضافة التصنيف، أو الانحدار، أو التجميع، أو اكتشاف الحالات الشاذة، أو التوصية، أو تكامل LLM (إنشاء النص، أو التلخيص، أو الاستدلال)، أو خطوط أنابيب RAG مع البحث المتجه، أو سير العمل الوكيل مع استدعاء الأدوات، أو ملحقات Copilot، أو استدلال نموذج مخصص عبر ONNX Runtime إلى مشروع .NET. لا تستخدمه للمشاريع التي تستهدف .NET Framework (تتطلب .NET 8+)، أو المهمة هي هندسة بيانات خالصة أو ETL بدون مكون ML/AI، أو يحتاج المشروع إلى حلقة تدريب مخصصة للتعلم العميق (استخدم Python مع PyTorch/TensorFlow، ثم قم بالتصدير إلى ONNX لاستدلال .NET).
