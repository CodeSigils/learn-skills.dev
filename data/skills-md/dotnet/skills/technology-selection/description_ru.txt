Руководит выбором технологий и реализацией функций искусственного интеллекта и машинного обучения в приложениях .NET 8+ с использованием ML.NET, Microsoft.Extensions.AI (MEAI), Microsoft Agent Framework (MAF), GitHub Copilot SDK, ONNX Runtime и OllamaSharp. Охватывает весь спектр: от классического машинного обучения до современной оркестровки LLM и локального вывода. Используйте при добавлении классификации, регрессии, кластеризации, обнаружения аномалий, рекомендаций, интеграции LLM (генерация текста, обобщение, рассуждение), конвейеров RAG с векторным поиском, агентских рабочих процессов с вызовом инструментов, расширений Copilot или вывода пользовательской модели через среду выполнения ONNX в проект .NET. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ проектов, ориентированных на .NET Framework (требуется .NET 8+), задача — чистая обработка данных или ETL без компонента ML/AI, или проекту требуется собственный цикл обучения глубокому обучению (используйте Python с PyTorch/TensorFlow, затем экспортируйте в ONNX для вывода .NET).
