ML.NET, Microsoft.Extensions.AI(MEAI), Microsoft Agent Framework(MAF), GitHub Copilot SDK, ONNX Runtime 및 OllamaSharp를 사용하여 .NET 8+ 애플리케이션에서 AI 및 ML 기능의 기술 선택 및 구현을 안내합니다. 클래식 ML부터 최신 LLM 오케스트레이션, 로컬 추론까지 전체 스펙트럼을 포괄합니다. 분류, 회귀, 클러스터링, 이상 탐지, 권장 사항, LLM 통합(텍스트 생성, 요약, 추론), 벡터 검색이 포함된 RAG 파이프라인, 도구 호출이 포함된 에이전트 워크플로, Copilot 확장 또는 ONNX Runtime을 통한 사용자 지정 모델 추론을 .NET 프로젝트에 추가할 때 사용합니다. .NET Framework(.NET 8 이상 필요)를 대상으로 하는 프로젝트에는 사용하지 마세요. 작업이 ML/AI 구성 요소가 없는 순수 데이터 엔지니어링 또는 ETL이거나 프로젝트에 사용자 지정 딥 러닝 훈련 루프가 필요합니다(PyTorch/TensorFlow와 함께 Python을 사용한 다음 .NET 추론을 위해 ONNX로 내보내기).
