Diagnostica y corrige habilidades en el repositorio dotnet/skills que pierden su propia línea de base, no se activan, caducan o devuelven "ninguna mejora creíble". Utilícelo cuando un veredicto de evaluación es una regresión o tiene poca potencia, cuando una habilidad retrocede después de un cambio, cuando /evaluate no informa resultados o cuando decide si una habilidad débil debe fortalecerse o retirarse. No lo use para crear una habilidad nueva (use create-skill) o una evaluación nueva (use create-skill-test).
