Diagnostiziert und behebt Fertigkeiten im Dotnet/Skills-Repository, die gegenüber ihrer eigenen Grundlinie verloren gehen, nicht aktiviert werden können, eine Zeitüberschreitung aufweisen oder „keine glaubwürdige Verbesserung“ zurückgeben. Verwenden Sie dies, wenn ein Bewertungsurteil eine Regression oder eine unzureichende Leistung darstellt, wenn eine Fertigkeit nach einer Änderung zurückgegangen ist, wenn /evaluate keine Ergebnisse meldet oder wenn Sie entscheiden, ob eine schwache Fertigkeit gestärkt oder zurückgezogen werden soll. Verwenden Sie als Gerüst nicht eine brandneue Fertigkeit (verwenden Sie „create-skill“) oder eine brandneue Evaluierung (verwenden Sie „create-skill-test“).
