Calcule le score CRAP (Change Risk Anti-Patterns) pour les méthodes, classes ou fichiers .NET. À utiliser lorsque l'utilisateur demande à évaluer la qualité des tests, à identifier le code risqué non testé, à calculer les scores CRAP ou à évaluer si les méthodes complexes ont une couverture de test suffisante. Nécessite des données de couverture de code (Cobertura XML) et une analyse de complexité cyclomatique. NE PAS UTILISER POUR : l'écriture de tests, l'exécution de tests généraux sans rapport avec l'analyse de couverture/CRAP, ou le reporting général de couverture de code sans contexte CRAP.
