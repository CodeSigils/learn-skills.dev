Руководство по оптимизации инкрементальных сборок MSBuild. Активируйте только в контексте сборки MSBuild/.NET. ИСПОЛЬЗОВАНИЕ ДЛЯ: сборка медленнее, чем ожидалось, при последующих запусках, «ничего не изменилось, но все равно перестраивается», диагностика того, почему целевые объекты повторно выполняются без необходимости, исправление неработающих бездействующих сборок. Охватывает 8 распространенных причин: отсутствие входных/выходных данных в пользовательских целевых объектах, изменчивые свойства в путях вывода (временные метки/GUID), запись файлов за пределами отслеживаемых выходных данных, отсутствие регистрации FileWrites, изменения glob, проблемы с быстрой актуальной проверкой Visual Studio (FUTDC). Ключевая диагностика: найдите «Полное построение цели» и «Пропуск цели» в binlog. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: медленной сборки при первом запуске (используйте build-perf-baseline), проблем с параллелизмом (используйте параллелизм сборки), медленности на этапе оценки (используйте eval- Performance), систем сборки, отличных от MSBuild. ВЫЗЫВАЕТ: dotnet build /bl, воспроизведение binlog с подробной диагностикой.
