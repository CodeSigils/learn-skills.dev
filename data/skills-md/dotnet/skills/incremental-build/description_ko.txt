MSBuild 증분 빌드 최적화를 위한 가이드입니다. MSBuild/.NET 빌드 컨텍스트에서만 활성화하세요. 사용 대상: 후속 실행에서 예상보다 느린 빌드, '아무것도 변경되지 않았지만 어쨌든 다시 빌드', 대상이 불필요하게 재실행되는 이유를 진단하고 손상된 무작동 빌드를 수정합니다. 8가지 일반적인 원인을 다룹니다. 사용자 지정 대상의 입력/출력 누락, 출력 경로의 휘발성 속성(타임스탬프/GUID), 추적된 출력 외부의 파일 쓰기, FileWrites 등록 누락, glob 변경, Visual Studio 빠른 최신 확인(FUTDC) 문제. 주요 진단: binlog에서 '대상을 완전히 빌드 중'과 '대상 건너뛰기'를 찾습니다. 사용하지 마십시오: 최초 빌드 속도 저하(build-perf-baseline 사용), 병렬 처리 문제(빌드 병렬 처리 사용), 평가 단계 속도 저하(eval-performance 사용), 비 MSBuild 빌드 시스템. INVOKES: dotnet build /bl, 진단 상세 정보를 포함한 binlog 재생.
