Führt eine Pseudomutationsanalyse des .NET-Produktionscodes durch, um Lücken in vorhandenen Testsuiten zu finden. Verwenden Sie diese Option, wenn der Benutzer schwache Tests finden, ungetestete Randfälle entdecken, prüfen möchte, ob Tests einen Fehler erkennen würden, oder die Testeffektivität durch Argumentation im Mutationsstil bewerten möchte. Analysiert den Produktionscode auf Mutationspunkte (Randbedingungen, boolesche Umkehrungen, Nullrückgaben, Ausnahmeentfernung, arithmetische Änderungen) und prüft, ob vorhandene Tests jede Mutation erkennen würden. Funktioniert mit MSTest, xUnit, NUnit und TUnit. NICHT VERWENDEN FÜR: das Schreiben neuer Tests (verwenden Sie Writing-mstest-tests), das Erkennen von Test-Anti-Patterns (verwenden Sie Test-Anti-Patterns), das Messen der Assertionsvielfalt (verwenden Sie Assertion-Quality) oder das Ausführen tatsächlicher Mutationstest-Tools.
