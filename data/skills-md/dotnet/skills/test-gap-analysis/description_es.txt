Realiza análisis de pseudomutación en código de producción .NET para encontrar lagunas en los conjuntos de pruebas existentes. Úselo cuando el usuario solicite encontrar pruebas débiles, descubrir casos extremos no probados, verificar si las pruebas detectarían un error o evaluar la efectividad de la prueba mediante un razonamiento de estilo mutación. Analiza el código de producción en busca de puntos de mutación (condiciones de límite, cambios booleanos, retornos nulos, eliminación de excepciones, cambios aritméticos) y verifica si las pruebas existentes detectarían cada mutación. Funciona con MSTest, xUnit, NUnit y TUnit. NO UTILIZAR PARA: escribir nuevas pruebas (use escribir-mstest-tests), detectar antipatrones de prueba (usar antipatrones de prueba), medir la diversidad de aserciones (usar calidad de aserción) o ejecutar herramientas de prueba de mutaciones reales.
