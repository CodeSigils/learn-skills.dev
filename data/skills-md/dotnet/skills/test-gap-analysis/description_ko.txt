.NET 프로덕션 코드에 대한 의사 돌연변이 분석을 수행하여 기존 테스트 스위트의 격차를 찾습니다. 사용자가 약한 테스트를 찾거나, 테스트되지 않은 엣지 케이스를 발견하거나, 테스트에서 버그를 잡을 수 있는지 확인하거나, 돌연변이 스타일 추론을 통해 테스트 효과를 평가하도록 요청할 때 사용합니다. 변형 지점(경계 조건, 부울 뒤집기, Null 반환, 예외 제거, 산술 변경)에 대한 프로덕션 코드를 분석하고 기존 테스트가 각 변형을 감지하는지 확인합니다. MSTest, xUnit, NUnit 및 TUnit에서 작동합니다. 사용하지 마십시오: 새 테스트 작성(writing-mstest-tests 사용), 테스트 안티 패턴 감지(테스트 안티 패턴 사용), 어설션 다양성 측정(어설션 품질 사용) 또는 실제 돌연변이 테스트 도구 실행.
