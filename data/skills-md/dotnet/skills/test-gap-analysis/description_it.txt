Esegue analisi di pseudo-mutazioni sul codice di produzione .NET per individuare lacune nelle suite di test esistenti. Da utilizzare quando l'utente chiede di trovare test deboli, scoprire casi limite non testati, verificare se i test rilevano un bug o valutare l'efficacia dei test attraverso un ragionamento in stile mutazione. Analizza il codice di produzione per i punti di mutazione (condizioni al contorno, inversioni booleane, resi nulli, rimozione di eccezioni, modifiche aritmetiche) e controlla se i test esistenti rileverebbero ciascuna mutazione. Funziona con MSTest, xUnit, NUnit e TUnit. NON UTILIZZARE PER: scrivere nuovi test (usare writing-mstest-tests), rilevare anti-pattern di test (usare test-anti-patterns), misurare la diversità delle asserzioni (usare assertion-quality) o eseguire strumenti di test di mutazione effettivi.
