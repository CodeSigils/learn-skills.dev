Effectue une analyse de pseudo-mutation sur le code de production .NET pour trouver des lacunes dans les suites de tests existantes. À utiliser lorsque l'utilisateur demande à trouver des tests faibles, à découvrir des cas extrêmes non testés, à vérifier si les tests détecteraient un bug ou à évaluer l'efficacité des tests grâce à un raisonnement de type mutation. Analyse le code de production pour les points de mutation (conditions aux limites, retournements booléens, retours nuls, suppression d'exceptions, modifications arithmétiques) et vérifie si les tests existants détecteraient chaque mutation. Fonctionne avec MSTest, xUnit, NUnit et TUnit. NE PAS UTILISER POUR : écrire de nouveaux tests (utiliser writing-mstest-tests), détecter des anti-modèles de test (utiliser des anti-modèles de test), mesurer la diversité des assertions (utiliser la qualité des assertions) ou exécuter de véritables outils de test de mutation.
