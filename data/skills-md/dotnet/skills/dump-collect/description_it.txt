Configura e raccogli dump di arresti anomali per le moderne applicazioni .NET. UTILIZZO PER: abilitare i dump di arresto anomalo del sistema automatici per CoreCLR o NativeAOT, acquisire dump dai processi .NET in esecuzione, impostare la raccolta di dump in Docker o Kubernetes, utilizzare dotnet-dump collector o createump. NON UTILIZZARE PER: analisi o debug di dump, indagini post mortem con analisi lldb/windbg/dotnet-dump, profilazione o traccia o per processi .NET Framework.
