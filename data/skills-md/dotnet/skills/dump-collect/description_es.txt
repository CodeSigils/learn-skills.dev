Configure y recopile volcados de memoria para aplicaciones .NET modernas. UTILIZAR PARA: habilitar volcados de volcado automáticos para CoreCLR o NativeAOT, capturar volcados de procesos .NET en ejecución, configurar la recopilación de volcados en Docker o Kubernetes, usar dotnet-dump recolector o creadoump. NO LO UTILICE PARA: analizar o depurar volcados, investigación post-mortem con análisis, creación de perfiles o rastreo de lldb/windbg/dotnet-dump, ni para procesos de .NET Framework.
