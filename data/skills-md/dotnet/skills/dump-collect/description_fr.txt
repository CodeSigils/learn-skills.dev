Configurez et collectez les vidages sur incident pour les applications .NET modernes. UTILISER POUR : activer les vidages sur incident automatiques pour CoreCLR ou NativeAOT, capturer les vidages des processus .NET en cours d'exécution, configurer la collecte de vidages dans Docker ou Kubernetes, à l'aide de dotnet-dump collect ou createump. NE PAS UTILISER POUR : l'analyse ou le débogage des vidages, l'enquête post-mortem avec l'analyse lldb/windbg/dotnet-dump, le profilage ou le traçage, ou pour les processus .NET Framework.
