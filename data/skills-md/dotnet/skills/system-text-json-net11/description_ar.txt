يوفر إرشادات حول واجهات برمجة التطبيقات System.Text.Json الجديدة المقدمة في .NET 11. وهو يغطي الوصول المكتوب إلى JsonTypeInfo عبر GetTypeInfo<T> وTryGetTypeInfo<T> على JsonSerializerOptions، وخاصية JsonNamingPolicy.PascalCase الثابتة الجديدة. يُستخدم عند إجراء تسلسل أو إلغاء تسلسل JSON في تطبيقات .NET 11 والحاجة إلى الوصول إلى بيانات التعريف المكتوبة أو تسمية خاصية PascalCase.
