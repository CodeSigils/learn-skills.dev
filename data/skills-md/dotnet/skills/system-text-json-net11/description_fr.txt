Fournit des conseils sur les nouvelles API System.Text.Json introduites dans .NET 11. Il couvre l’accès JsonTypeInfo typé via GetTypeInfo<T> et TryGetTypeInfo<T> sur JsonSerializerOptions, ainsi que la nouvelle propriété statique JsonNamingPolicy.PascalCase. À utiliser lors de la sérialisation ou de la désérialisation de JSON dans les applications .NET 11 et lorsque vous avez besoin d'un accès aux métadonnées typées ou d'une dénomination de propriété PascalCase.
