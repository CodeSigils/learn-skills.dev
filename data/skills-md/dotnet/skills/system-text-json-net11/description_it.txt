Fornisce indicazioni sulle nuove API System.Text.Json introdotte in .NET 11. Copre l'accesso JsonTypeInfo tipizzato tramite GetTypeInfo<T> e TryGetTypeInfo<T> su JsonSerializerOptions e la nuova proprietà statica JsonNamingPolicy.PascalCase. Da utilizzare quando si serializza o deserializza JSON in applicazioni .NET 11 e si richiede l'accesso ai metadati tipizzati o la denominazione delle proprietà PascalCase.
