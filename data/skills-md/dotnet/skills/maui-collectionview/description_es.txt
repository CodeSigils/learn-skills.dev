Guía para implementar CollectionView en aplicaciones .NET MAUI: visualización de datos, diseños (lista y cuadrícula), selección, agrupación, desplazamiento, vistas vacías, plantillas, carga incremental, acciones de deslizamiento y extracción para actualizar. USO PARA: "CollectionView", "vista de lista", "diseño de cuadrícula", "plantilla de datos", "plantilla de elemento", "agrupación", "tirar para actualizar", "carga incremental", "acciones de deslizamiento", "vista vacía", "modo de selección", "desplazarse al elemento", mostrar datos desplazables, reemplazar ListView. NO LO UTILICE PARA: diseños estáticos simples sin datos desplazables (use Grid o StackLayout), listas de pines de mapas (use Microsoft.Maui.Controls.Maps), formularios de entrada de datos basados ​​en tablas o controles de listas que no sean MAUI.
