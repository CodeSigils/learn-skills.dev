Guida per la modernizzazione e la migrazione dei file di progetto MSBuild nel formato in stile SDK. Attivare solo nel contesto di compilazione MSBuild/.NET. UTILIZZARE PER: conversione di file .csproj/.vbproj legacy con XML dettagliato in stile SDK, migrazione di packages.config in PackageReference, rimozione di Properties/AssemblyInfo.cs a favore della generazione automatica, eliminazione di elenchi <Compile Include> espliciti tramite globbing implicito, consolidamento delle impostazioni condivise in Directory.Build.props. Indicatori di progetti legacy: attributo ToolsVersion, <Import Project="$(MSBuildToolsPath)">, file .csproj > 50 righe per progetti semplici. NON UTILIZZARE PER: progetti già in formato SDK, sistemi di compilazione non .NET (npm, Maven, CMake), progetti .NET Framework che non possono passare allo stile SDK. RICHIAMA: dotnet try-convert, strumenti di assistente all'aggiornamento.
