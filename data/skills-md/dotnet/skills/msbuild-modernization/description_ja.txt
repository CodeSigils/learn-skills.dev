MSBuild プロジェクト ファイルを最新化し、SDK スタイルの形式に移行するためのガイド。 MSBuild/.NET ビルド コンテキストでのみアクティブ化します。用途: 冗長 XML を含む従来の .csproj/.vbproj を SDK スタイルに変換する、packages.config を PackageReference に移行する、自動生成を優先して Properties/AssemblyInfo.cs を削除する、暗黙的なグロビングによる明示的な <Compile Include> リストを排除する、共有設定を Directory.Build.props に統合する。従来のプロジェクトのインジケーター: ToolsVersion 属性、<Import Project="$(MSBuildToolsPath)">、.csproj ファイル > 単純なプロジェクトの場合は 50 行。次の場合には使用しないでください: すでに SDK スタイル形式のプロジェクト、非 .NET ビルド システム (npm、Maven、CMake)、SDK スタイルに移行できない .NET Framework プロジェクト。呼び出し: dotnet try-convert、アップグレード アシスタント ツール。
