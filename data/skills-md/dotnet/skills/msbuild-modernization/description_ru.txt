Руководство по модернизации и переносу файлов проекта MSBuild в формат в стиле SDK. Активируйте только в контексте сборки MSBuild/.NET. ИСПОЛЬЗОВАНИЕ ДЛЯ: преобразования устаревшего файла .csproj/.vbproj с подробным XML в стиль SDK, переноса packages.config в PackageReference, удаления Properties/AssemblyInfo.cs в пользу автоматического создания, устранения явных списков <Compile Include> посредством неявного подстановки, консолидации общих настроек в Directory.Build.props. Индикаторы устаревших проектов: атрибут ToolsVersion, <Import Project="$(MSBuildToolsPath)">, файлы .csproj > 50 строк для простых проектов. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: проектов, уже созданных в формате SDK, систем сборки, отличных от .NET (npm, Maven, CMake), проектов .NET Framework, которые невозможно перейти в формат SDK. ВЫЗЫВАЕТ: dotnet try-convert, инструменты-помощники по обновлению.
