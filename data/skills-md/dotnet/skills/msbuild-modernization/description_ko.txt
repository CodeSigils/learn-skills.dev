MSBuild 프로젝트 파일을 SDK 스타일 형식으로 현대화하고 마이그레이션하기 위한 가이드입니다. MSBuild/.NET 빌드 컨텍스트에서만 활성화하세요. 사용 대상: 자세한 XML이 포함된 레거시 .csproj/.vbproj를 SDK 스타일로 변환, packages.config를 PackageReference로 마이그레이션, 자동 생성을 위해 Properties/AssemblyInfo.cs 제거, 암시적 글로빙을 통해 명시적인 <Compile 포함> 목록 제거, 공유 설정을 Directory.Build.props로 통합. 레거시 프로젝트 표시기: ToolsVersion 특성, <Import Project="$(MSBuildToolsPath)">, .csproj 파일 > 간단한 프로젝트의 경우 50줄. 사용하지 마세요: 이미 SDK 스타일 형식의 프로젝트, .NET이 아닌 빌드 시스템(npm, Maven, CMake), SDK 스타일로 이동할 수 없는 .NET Framework 프로젝트. INVOKES: dotnet try-convert, 업그레이드 지원 도구.
