將 MSBuild 專案檔案現代化並遷移為 SDK 樣式格式的指南。僅在 MSBuild/.NET 建置上下文中啟動。用途：將帶有詳細 XML 的舊版 .csproj/.vbproj 轉換為 SDK 樣式、將 packages.config 遷移到 PackageReference、刪除 Properties/AssemblyInfo.cs 以支援自動生成、透過隱式通配消除顯式 <Compile Include> 清單、將共用設定合併到 Directps.Build.舊專案的指標：ToolsVersion 屬性、<Import Project="$(MSBuildToolsPath)">、.csproj 檔案 > 50 行（對於簡單專案）。請勿用於：已經採用 SDK 樣式格式的專案、非 .NET 建置系統（npm、Maven、CMake）、無法移轉到 SDK 樣式的 .NET Framework 專案。呼叫：dotnet try-convert、升級輔助工具。
