Guide de modernisation et de migration des fichiers de projet MSBuild au format de style SDK. Activez uniquement dans le contexte de build MSBuild/.NET. UTILISER POUR : convertir l'ancien .csproj/.vbproj avec du XML détaillé en style SDK, migrer packages.config vers PackageReference, supprimer Properties/AssemblyInfo.cs en faveur de la génération automatique, éliminer les listes <Compile Include> explicites via une globalisation implicite, consolider les paramètres partagés dans Directory.Build.props. Indicateurs des projets existants : attribut ToolsVersion, <Import Project="$(MSBuildToolsPath)">, fichiers .csproj > 50 lignes pour les projets simples. NE PAS UTILISER POUR : les projets déjà au format de style SDK, les systèmes de construction non .NET (npm, Maven, CMake), les projets .NET Framework qui ne peuvent pas passer au style SDK. INVOKES : dotnet try-convert, outils d'assistant de mise à niveau.
