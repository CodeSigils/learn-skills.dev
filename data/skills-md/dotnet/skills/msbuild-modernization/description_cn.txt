将 MSBuild 项目文件现代化并迁移为 SDK 样式格式的指南。仅在 MSBuild/.NET 构建上下文中激活。用途：将带有详细 XML 的旧版 .csproj/.vbproj 转换为 SDK 样式、将 packages.config 迁移到 PackageReference、删除 Properties/AssemblyInfo.cs 以支持自动生成、通过隐式通配消除显式 <Compile Include> 列表、将共享设置合并到 Directory.Build.props 中。旧项目的指标：ToolsVersion 属性、<Import Project="$(MSBuildToolsPath)">、.csproj 文件 > 50 行（对于简单项目）。请勿用于：已经采用 SDK 样式格式的项目、非 .NET 构建系统（npm、Maven、CMake）、无法迁移到 SDK 样式的 .NET Framework 项目。调用：dotnet try-convert、升级辅助工具。
