Symbolisez les frames d’exécution .NET dans un fichier tombstone Android. Extrait les BuildIds et les décalages PC de la trace native, télécharge les symboles de débogage à partir du serveur de symboles Microsoft et exécute llvm-symbolizer pour produire des noms de fonctions avec le fichier source et les numéros de ligne. À UTILISER POUR trier un crash d'application .NET MAUI ou Mono Android à partir d'une pierre tombale, résoudre les trames de trace natives dans libmonosgen-2.0.so ou libcoreclr.so en code source d'exécution .NET, ou enquêter sur SIGABRT, SIGSEGV ou d'autres signaux natifs provenant du runtime .NET sur Android. NE PAS UTILISER POUR les plantages Java/Kotlin purs, les exceptions .NET gérées déjà capturées dans logcat ou les journaux de plantages iOS. INVOKE le script Symbolicate-Tombstone.ps1, llvm-symbolizer, serveur de symboles Microsoft.
