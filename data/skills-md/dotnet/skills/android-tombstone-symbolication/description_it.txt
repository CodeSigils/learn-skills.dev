Simboleggiare i frame di runtime .NET in un file tombstone Android. Estrae BuildId e offset PC dal backtrace nativo, scarica i simboli di debug dal server dei simboli Microsoft ed esegue llvm-symbolizer per produrre nomi di funzioni con file di origine e numeri di riga. UTILIZZARE PER la valutazione di un arresto anomalo di un'app .NET MAUI o Mono Android da un oggetto contrassegnato per rimozione definitiva, risolvendo frame di backtrace nativi in ​​libmonosgen-2.0.so o libcoreclr.so nel codice sorgente runtime .NET o esaminando SIGABRT, SIGSEGV o altri segnali nativi originati dal runtime .NET su Android. NON UTILIZZARE PER arresti anomali puri di Java/Kotlin, eccezioni .NET gestite già acquisite in logcat o registri di arresti anomali di iOS. INVOCA script Symbolicate-Tombstone.ps1, simbolizzatore llvm, server di simboli Microsoft.
