Android トゥームストーン ファイルで .NET ランタイム フレームをシンボル化します。ネイティブ バックトレースから BuildIds と PC オフセットを抽出し、Microsoft シンボル サーバーからデバッグ シンボルをダウンロードし、llvm-symbolizer を実行してソース ファイルと行番号を含む関数名を生成します。 .NET MAUI または Mono Android アプリのクラッシュを廃棄からトリアージする場合、libmonosgen-2.0.so または libcoreclr.so のネイティブ バックトレース フレームを .NET ランタイム ソース コードに解決する場合、または Android 上の .NET ランタイムから発生する SIGABRT、SIGSEGV、またはその他のネイティブ信号を調査する場合に使用します。純粋な Java/Kotlin のクラッシュ、logcat にすでにキャプチャされているマネージド .NET 例外、または iOS クラッシュ ログには使用しないでください。 Symbolicate-Tombstone.ps1 スクリプト、llvm-symbolizer、Microsoft シンボル サーバーを呼び出します。
