在 Android 逻辑删除文件中对 .NET 运行时框架进行符号化。从本机回溯中提取 BuildIds 和 PC 偏移量，从 Microsoft 符号服务器下载调试符号，并运行 llvm-symbolizer 以生成带有源文件和行号的函数名称。用于从逻辑删除中对 .NET MAUI 或 Mono Android 应用程序崩溃进行分类，将 libmonosgen-2.0.so 或 libcoreclr.so 中的本机回溯帧解析为 .NET 运行时源代码，或调查 SIGABRT、SIGSEGV 或源自 Android 上 .NET 运行时的其他本机信号。请勿用于纯 Java/Kotlin 崩溃、已在 logcat 中捕获的托管 .NET 异常或 iOS 崩溃日志。调用 Symbolicate-Tombstone.ps1 脚本、llvm-symbolizer、Microsoft 符号服务器。
