Android 삭제 표시 파일에서 .NET 런타임 프레임을 기호화합니다. 기본 역추적에서 BuildId 및 PC 오프셋을 추출하고, Microsoft 기호 서버에서 디버그 기호를 다운로드하고, llvm-symbolizer를 실행하여 소스 파일 및 줄 번호가 포함된 함수 이름을 생성합니다. 삭제 표시에서 .NET MAUI 또는 Mono Android 앱 충돌을 분류하고, libmonosgen-2.0.so 또는 libcoreclr.so의 기본 역추적 프레임을 .NET 런타임 소스 코드로 확인하거나, SIGABRT, SIGSEGV 또는 Android의 .NET 런타임에서 발생하는 기타 기본 신호를 조사하는 데 사용됩니다. 순수 Java/Kotlin 충돌, 이미 logcat에 캡처된 관리형 .NET 예외 또는 iOS 충돌 로그에는 사용하지 마세요. INVOKES Symbolicate-Tombstone.ps1 스크립트, llvm-symbolizer, Microsoft 기호 서버.
