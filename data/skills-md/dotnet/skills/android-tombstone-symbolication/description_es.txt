Simbolice los marcos de tiempo de ejecución de .NET en un archivo de desecho de Android. Extrae BuildIds y compensaciones de PC del rastreo nativo, descarga símbolos de depuración del servidor de símbolos de Microsoft y ejecuta llvm-symbolizer para generar nombres de funciones con archivos fuente y números de línea. ÚSELO PARA clasificar una falla de una aplicación .NET MAUI o Mono para Android desde un desecho, resolver marcos de rastreo nativos en libmonosgen-2.0.so o libcoreclr.so al código fuente del tiempo de ejecución de .NET, o investigar SIGABRT, SIGSEGV u otras señales nativas que se originan en el tiempo de ejecución de .NET en Android. NO LO UTILICE PARA fallas puras de Java/Kotlin, excepciones administradas de .NET que ya están capturadas en logcat o registros de fallas de iOS. INVOCA el script Symbolicate-Tombstone.ps1, llvm-symbolizer, servidor de símbolos de Microsoft.
