Укажите символы среды выполнения .NET в файле-захоронении Android. Извлекает BuildIds и смещения ПК из собственной обратной трассировки, загружает символы отладки с сервера символов Microsoft и запускает llvm-symbolizer для создания имен функций с исходным файлом и номерами строк. ИСПОЛЬЗУЕТСЯ ДЛЯ сортировки сбоев приложения .NET MAUI или Mono Android из захоронения, разрешения собственных кадров обратной трассировки в libmonosgen-2.0.so или libcoreclr.so в исходном коде среды выполнения .NET или исследования SIGABRT, SIGSEGV или других собственных сигналов, исходящих из среды выполнения .NET на Android. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ сбоев чистого Java/Kotlin, управляемых исключений .NET, которые уже зафиксированы в logcat, или журналов сбоев iOS. ВЫЗЫВАЕТ сценарий Symbolicate-Tombstone.ps1, llvm-symbolizer, сервер символов Microsoft.
