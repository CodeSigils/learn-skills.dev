在 Android 邏輯刪除檔案中對 .NET 執行時期框架進行符號化。從本機回溯中提取 BuildIds 和 PC 偏移量，從 Microsoft 符號伺服器下載偵錯符號，並執行 llvm-symbolizer 以產生具有來源檔案和行號的函數名稱。用於從邏輯刪除中對 .NET MAUI 或 Mono Android 應用程式崩潰進行分類，將 libmonosgen-2.0.so 或 libcoreclr.so 中的本機回溯幀解析為 .NET 運行時原始程式碼，或調查 SIGABRT、SIGSEGV 或 Android 上 .NET 運行時的其他本機訊號。請勿用於純 Java/Kotlin 崩潰、已在 logcat 中捕獲的託管 .NET 異常或 iOS 崩潰日誌。呼叫 Symbolicate-Tombstone.ps1 腳本、llvm-symbolizer、Microsoft 符號伺服器。
