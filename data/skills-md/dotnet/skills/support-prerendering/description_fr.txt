Faites fonctionner correctement les composants interactifs Blazor avec le prérendu. UTILISER POUR corriger les chargements de données en double, le scintillement de l'interface utilisateur lors du transfert du pré-rendu vers l'interactif, les références nulles pendant le pré-rendu, l'état persistant pendant le pré-rendu, la désactivation du pré-rendu, l'exclusion de pages du routage interactif ou la détection si un composant est actuellement en cours de pré-rendu. NE PAS UTILISER pour choisir le mode de rendu à utiliser (voir create-blazor-project) ou la création générale de composants (voir author-component).
