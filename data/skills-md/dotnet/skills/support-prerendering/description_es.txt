Haga que los componentes interactivos de Blazor funcionen correctamente con el renderizado previo. ÚSELO PARA corregir cargas de datos duplicados, parpadeos de la interfaz de usuario durante la transferencia de prerenderizado a interactivo, referencias nulas durante el prerenderizado, estado persistente durante el prerenderizado, deshabilitar el prerenderizado, excluir páginas del enrutamiento interactivo o detectar si un componente se está prerenderizando actualmente. NO LO USE para elegir qué modo de renderizado usar (ver crear-blazor-proyecto) o creación de componentes generales (ver autor-componente).
