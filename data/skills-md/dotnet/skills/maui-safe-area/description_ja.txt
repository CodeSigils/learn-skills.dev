.NET MAUI セーフ エリアと .NET 10 以降のエッジツーエッジ レイアウト ガイダンス。新しい SafeAreaEdges プロパティ、SafeAreaRegions 列挙、エッジごとのコントロール、キーボード回避、Blazor ハイブリッド CSS セーフ エリア、従来の iOS 専用 API からの移行、Android、iOS、および Mac Catalyst のプラットフォーム固有の動作について説明します。用途: 「セーフ エリア」、「エッジツーエッジ」、「SafeAreaEdges」、「SafeAreaRegions」、「キーボード回避」、「ノッチ インセット」、「ステータス バーのオーバーラップ」、「iOS セーフ エリア」、「Android エッジツーエッジ」、「ステータス バーの後ろのコンテンツ」、「UseSafeArea の移行」、「ソフト入力キーボード」、「IgnoreSafeArea の置換」。次の用途には使用しないでください: 一般的なレイアウトまたはグリッド設計 (Grid および StackLayout を使用)、アプリのライフサイクル処理 (maui-app-lifecycle を使用)、テーマまたはスタイル設定 (maui-theming を使用)、またはシェル ナビゲーション構造。
