适用于 .NET 10+ 的 .NET MAUI 安全区域和边缘到边缘布局指南。涵盖新的 SafeAreaEdges 属性、SafeAreaRegions 枚举、每边缘控制、键盘避免、Blazor 混合 CSS 安全区域、从旧版仅 iOS API 的迁移以及 Android、iOS 和 Mac Catalyst 的平台特定行为。用于：“安全区域”、“边缘到边缘”、“SafeAreaEdges”、“SafeAreaRegions”、“键盘回避”、“凹口插入”、“状态栏重叠”、“iOS 安全区域”、“Android 边缘到边缘”、“状态栏后面的内容”、“UseSafeArea 迁移”、“软输入键盘”、“IgnoreSafeArea 替换”。请勿用于：一般布局或网格设计（使用 Grid 和 StackLayout）、应用程序生命周期处理（使用 maui-app-lifecycle）、主题或样式（使用 maui-theming）或 Shell 导航结构。
