適用於 .NET 10+ 的 .NET MAUI 安全區域和邊緣到邊緣佈局指南。涵蓋新的 SafeAreaEdges 屬性、SafeAreaRegions 枚舉、每個邊緣控制、鍵盤避免、Blazor 混合 CSS 安全區域、從舊版僅 iOS API 的遷移以及 Android、iOS 和 Mac Catalyst 的平台特定行為。用於：「安全區域」、「邊緣到邊緣」、「SafeAreaEdges」、「SafeAreaRegions」、「鍵盤迴避」、「凹口插入」、「狀態列重疊」、「iOS 安全區域」、「Android 邊緣到邊緣」、「狀態列後面的內容」、「UseSafeArea 遷移」、「鍵盤輸入鍵盤」、「軟鍵盤」。請勿用於：一般佈局或網格設計（使用 Grid 和 StackLayout）、應用程式生命週期處理（使用 maui-app-lifecycle）、主題或樣式（使用 maui-theming）或 Shell 導航結構。
