Создавайте интерфейсы-оболочки и регистрируйте DI для труднопроверяемых статических зависимостей в C#. Создает оболочки IFileSystem, IEnvironmentProvider, IConsole, IProcessRunner или направляет внедрение TimeProvider и IHttpClientFactory. ИСПОЛЬЗОВАНИЕ ДЛЯ: создать оболочку для статики, создать оболочку IFileSystem, обернуть DateTime.Now, сделать статическую тестируемой, сделать тестируемым класс, создать абстракцию для File.*, сгенерировать регистрацию DI, принятие TimeProvider, настройку IHttpClientFactory, оболочку тестируемости, удобный интерфейс, время макета в тестах, создать подходящую абстракцию для макетирования, как имитировать DateTime, протестировать код с использованием File.ReadAllText, какая абстракция для среды, как создать статику injectable, внедрить System.IO.Abstractions, сделать вызовы файлов тестируемыми. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: обнаружения статики (используйте обнаружение статических зависимостей), миграции сайтов вызовов (используйтеmigrate-static-to-wrapper), общего дизайна интерфейса, не связанного с тестируемостью.
