Générez des interfaces wrapper et un enregistrement DI pour les dépendances statiques difficiles à tester en C#. Produit des wrappers IFileSystem, IEnvironmentProvider, IConsole, IProcessRunner ou guide l'adoption de TimeProvider et IHttpClientFactory. UTILISER POUR : générer un wrapper pour la statique, créer un wrapper IFileSystem, envelopper DateTime.Now, rendre la statique testable, rendre la classe testable, créer une abstraction pour File.*, générer l'enregistrement DI, adoption de TimeProvider, configuration IHttpClientFactory, wrapper de testabilité, interface conviviale, temps simulé dans les tests, créer la bonne abstraction à se moquer, comment se moquer de DateTime, tester le code à l'aide de File.ReadAllText, quelle abstraction pour l'environnement, comment rendre la statique injectable, adopter System.IO.Abstractions, rend les appels de fichiers testables. NE PAS UTILISER POUR : la détection de statistiques (utilisez détecter les dépendances statiques), la migration des sites d'appel (utilisez migrate-static-to-wrapper), la conception générale de l'interface ne concerne pas la testabilité.
