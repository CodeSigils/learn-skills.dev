dotnet test を使用して .NET テストを実行します。ユーザーが「テストを実行する」、「テストを実行する」、「ドットネット テスト」、「テスト フィルター」、「カテゴリでフィルターする」、「クラスでフィルターする」、「特定のテストのみを実行する」、「テストは実行されていない」と言う場合、またはテスト プラットフォーム (VSTest または Microsoft.Testing.Platform) の検出、テスト フレームワークの特定、テスト フィルターの適用、またはテスト実行の失敗のトラブルシューティングを行う必要がある場合に使用します。 VSTest と MTP の両方のプラットフォームにわたる MSTest、xUnit、NUnit、TUnit をカバーします。また、treenode-filter、--filter-class、--filter-trait、およびその他のフレームワーク固有のフィルター構文にも使用します。テスト コードの作成または生成、CI/CD パイプライン構成、または失敗したテスト ロジックのデバッグには使用しないでください。
