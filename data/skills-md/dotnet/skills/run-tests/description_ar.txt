يقوم بإجراء اختبارات .NET مع اختبار الدوت نت. يُستخدم عندما يقول المستخدم "تشغيل الاختبارات"، أو "تنفيذ الاختبارات"، أو "اختبار dotnet"، أو "عامل التصفية للاختبار"، أو "التصفية حسب الفئة"، أو "التصفية حسب الفئة"، أو "تشغيل اختبارات محددة فقط"، أو "الاختبارات غير قيد التشغيل"، أو يحتاج إلى اكتشاف النظام الأساسي للاختبار (VSTest أو Microsoft.Testing.Platform)، أو تحديد إطار عمل الاختبار، أو تطبيق مرشحات الاختبار، أو استكشاف أخطاء فشل تنفيذ الاختبار وإصلاحها. يغطي MSTest وxUnit وNUnit وTUnit عبر منصات VSTest وMTP. استخدم أيضًا لمرشح Treenode، و--filter-class، و--filter-trait، وتركيبات التصفية الأخرى الخاصة بإطار العمل. لا تستخدمه من أجل: كتابة أو إنشاء رمز اختبار، أو تكوين خط أنابيب CI/CD، أو تصحيح أخطاء منطق الاختبار الفاشل.
