Exécute des tests .NET avec dotnet test. À utiliser lorsque l'utilisateur dit "exécuter des tests", "exécuter des tests", "test dotnet", "filtrer de test", "filtrer par catégorie", "filtrer par classe", "exécuter uniquement des tests spécifiques", "les tests ne sont pas en cours d'exécution" ou doit détecter la plate-forme de test (VSTest ou Microsoft.Testing.Platform), identifier le framework de test, appliquer des filtres de test ou dépanner les échecs d'exécution des tests. Couvre MSTest, xUnit, NUnit et TUnit sur les plates-formes VSTest et MTP. À utiliser également pour treenode-filter, --filter-class, --filter-trait et d'autres syntaxes de filtre spécifiques au framework. NE PAS UTILISER POUR : l’écriture ou la génération de code de test, la configuration de pipeline CI/CD ou le débogage d’une logique de test défaillante.
