Сканируйте исходные файлы C# на наличие статических зависимостей, которые сложно протестировать — DateTime.Now/UtcNow, File.*, Directory.*, Environment.*, HttpClient, Console.*, Process.* и других непроверяемых статических данных. Создает ранжированный отчет о статических сайтах вызовов по частоте. ИСПОЛЬЗОВАНИЕ ДЛЯ: поиска непроверяемой статики, сканирования статических зависимостей, аудита тестируемости, выявления кода, который сложно имитировать, поиска использования DateTime.Now, обнаружения статической связи, отчета о тестируемости, статического анализа тестируемости. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: создания оболочек (используйтеgenerate-testability-wrappers), миграции кода (используйтеmigrate-static-to-wrapper), общего обзора кода или поиска статики, которая уже находится за абстракциями.
