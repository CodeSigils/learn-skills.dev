Durchsuchen Sie C#-Quelldateien nach schwer zu testenden statischen Abhängigkeiten – DateTime.Now/UtcNow, File.*, Directory.*, Environment.*, HttpClient, Console.*, Process.* und andere nicht testbare statische Abhängigkeiten. Erstellt einen nach Häufigkeit sortierten Bericht statischer Anrufseiten. VERWENDUNG FÜR: nicht testbare Statiken finden, nach statischen Abhängigkeiten suchen, Testbarkeitsprüfung, schwer zu simulierenden Code identifizieren, DateTime.Now-Nutzung finden, statische Kopplung erkennen, Testbarkeitsbericht, statische Analyse zur Testbarkeit. NICHT VERWENDEN FÜR: das Generieren von Wrappern (verwenden Sie „generate-testability-wrapper“), das Migrieren von Code (verwenden Sie „migrate-static-to-wrapper“), die allgemeine Codeüberprüfung oder das Suchen nach Statiken, die sich bereits hinter Abstraktionen befinden.
