Esegui la scansione dei file sorgente C# per individuare dipendenze statiche difficili da testare: DateTime.Now/UtcNow, File.*, Directory.*, Environment.*, HttpClient, Console.*, Process.* e altri dati statici non testabili. Produce un report classificato dei siti di chiamata statici in base alla frequenza. UTILIZZARE PER: trovare dati statici non testabili, scansionare dipendenze statiche, controllo di testabilità, identificare codice difficile da simulare, trovare utilizzo di DateTime.Now, rilevare accoppiamento statico, report di testabilità, analisi statica per testabilità. NON UTILIZZARE PER: generazione di wrapper (utilizzare generate-testability-wrappers), migrazione del codice (utilizzare migrate-static-to-wrapper), revisione generale del codice o ricerca di elementi statici che sono già dietro le astrazioni.
