Analysez les fichiers source C# à la recherche de dépendances statiques difficiles à tester : DateTime.Now/UtcNow, File.*, Directory.*, Environment.*, HttpClient, Console.*, Process.* et autres statistiques non testables. Produit un rapport classé des sites d'appels statiques par fréquence. UTILISER POUR : rechercher des statistiques non testables, rechercher des dépendances statiques, audit de testabilité, identifier le code difficile à simuler, rechercher l'utilisation de DateTime.Now, détecter le couplage statique, rapport de testabilité, analyse statique pour la testabilité. NE PAS UTILISER POUR : la génération de wrappers (utilisez generate-testability-wrappers), la migration de code (utilisez migrate-static-to-wrapper), la révision générale du code ou la recherche de statistiques qui se trouvent déjà derrière des abstractions.
