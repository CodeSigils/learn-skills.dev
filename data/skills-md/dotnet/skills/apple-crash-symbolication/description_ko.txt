Apple 플랫폼 .ips 충돌 로그(iOS, tvOS, Mac Catalyst, macOS)에서 .NET 런타임 프레임을 기호화합니다. 기본 역추적에서 UUID와 주소를 추출하고, dSYM 디버그 기호를 찾고, atos를 실행하여 소스 파일과 줄 번호가 포함된 함수 이름을 생성합니다. Mach-O UUID를 사용하여 Microsoft 기호 서버에서 .dwarf 기호를 자동으로 다운로드합니다. Apple 플랫폼의 .ips 파일에서 .NET MAUI 또는 Mono 앱 충돌을 분류하고, libcoreclr 또는 libmonosgen-2.0의 기본 역추적 프레임을 .NET 런타임 소스 코드로 해결하고, 연결된 iOS 장치 또는 iPhone에서 .ips 충돌 로그를 검색하거나, .NET 런타임에서 발생하는 EXC_CRASH, EXC_BAD_ACCESS, SIGABRT 또는 SIGSEGV를 조사하는 데 사용됩니다. .NET 구성 요소 또는 Android 삭제 표시 파일이 없는 순수 Swift/Objective-C 충돌에는 사용하지 마세요. INVOKES Symbolicate-Crash.ps1 스크립트, atos, dwarfdump, idevicecrashreport.
