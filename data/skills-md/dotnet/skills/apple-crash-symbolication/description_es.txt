Simboliza marcos de tiempo de ejecución de .NET en registros de fallos .ips de la plataforma Apple (iOS, tvOS, Mac Catalyst, macOS). Extrae UUID y direcciones del rastreo nativo, localiza símbolos de depuración dSYM y ejecuta atos para producir nombres de funciones con archivos fuente y números de línea. Descarga automáticamente símbolos .dwarf del servidor de símbolos de Microsoft utilizando UUID Mach-O. ÚSELO PARA clasificar una falla de una aplicación .NET MAUI o Mono desde un archivo .ips en cualquier plataforma Apple, resolver marcos de seguimiento nativos en libcoreclr o libmonosgen-2.0 al código fuente del tiempo de ejecución .NET, recuperar registros de fallas .ips desde un dispositivo iOS o iPhone conectado, o investigar EXC_CRASH, EXC_BAD_ACCESS, SIGABRT o SIGSEGV que se originan en el tiempo de ejecución .NET. NO LO UTILICE PARA fallas puras de Swift/Objective-C sin componentes .NET o archivos de desecho de Android. INVOCA el script Symbolicate-Crash.ps1, atos, dwarfdump, idevicecrashreport.
