Simboleggiano i frame di runtime .NET nei registri di arresto anomalo della piattaforma Apple .ips (iOS, tvOS, Mac Catalyst, macOS). Estrae UUID e indirizzi dal backtrace nativo, individua i simboli di debug dSYM ed esegue atos per produrre nomi di funzioni con file sorgente e numeri di riga. Scarica automaticamente i simboli .dwarf dal server dei simboli Microsoft utilizzando gli UUID Mach-O. UTILIZZARE PER la valutazione di un arresto anomalo di un'app .NET MAUI o Mono da un file .ips su qualsiasi piattaforma Apple, risolvendo frame di backtrace nativi in libcoreclr o libmonosgen-2.0 nel codice sorgente runtime .NET, recuperando i registri di arresti anomali .ips da un dispositivo iOS o iPhone connesso o esaminando EXC_CRASH, EXC_BAD_ACCESS, SIGABRT o SIGSEGV originati da .NET tempo di esecuzione. NON UTILIZZARE PER arresti anomali puri di Swift/Objective-C senza componenti .NET o file tombstone Android. INVOCA script Symbolicate-Crash.ps1, atos, dwarfdump, idevicecrashreport.
