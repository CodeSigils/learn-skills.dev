Symbolisez les frames d’exécution .NET dans les journaux de crash .ips de la plateforme Apple (iOS, tvOS, Mac Catalyst, macOS). Extrait les UUID et les adresses de la trace native, localise les symboles de débogage dSYM et exécute atos pour produire des noms de fonctions avec le fichier source et les numéros de ligne. Télécharge automatiquement les symboles .dwarf à partir du serveur de symboles Microsoft à l'aide des UUID Mach-O. À UTILISER POUR trier un crash d'application .NET MAUI ou Mono à partir d'un fichier .ips sur n'importe quelle plate-forme Apple, résoudre les trames de trace natives dans libcoreclr ou libmonosgen-2.0 en code source d'exécution .NET, récupérer les journaux de crash .ips à partir d'un appareil iOS ou iPhone connecté, ou enquêter sur EXC_CRASH, EXC_BAD_ACCESS, SIGABRT ou SIGSEGV provenant du runtime .NET. NE PAS UTILISER POUR les plantages Swift/Objective-C purs sans composants .NET ni fichiers tombstone Android. INVITE le script Symbolicate-Crash.ps1, atos, dwarfdump, idevicecrashreport.
