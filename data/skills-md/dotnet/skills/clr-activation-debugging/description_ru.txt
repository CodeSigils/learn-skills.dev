Диагностирует проблемы активации .NET Framework CLR с помощью журналов активации CLR (журналов CLRLoad), создаваемых mscoree.dll. Используйте, когда: оболочка выбирает неправильную среду выполнения, не может загрузить ни одну среду выполнения, показывает неожиданные диалоговые окна .NET 3.5 Feature-on-Demand (FOD), неожиданно НЕ показывает диалоговые окна FOD, загружает v2 и v4 в один и тот же процесс, вызывающий сбои, или когда кто-то задается вопросом: «Что происходит с активацией .NET Framework?»
