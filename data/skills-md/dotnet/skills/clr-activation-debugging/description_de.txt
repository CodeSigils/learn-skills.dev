Diagnostiziert .NET Framework CLR-Aktivierungsprobleme mithilfe von CLR-Aktivierungsprotokollen (CLRLoad-Protokolle), die von mscoree.dll erstellt werden. Verwenden Sie dies, wenn: das Shim die falsche Laufzeit auswählt, keine Laufzeit laden kann, unerwartete .NET 3.5 Feature-on-Demand (FOD)-Dialoge anzeigt, unerwartet KEINE FOD-Dialoge anzeigt, sowohl v2 als auch v4 in denselben Prozess lädt, was zu Fehlern führt, oder wenn sich jemand fragt: „Was passiert mit der .NET Framework-Aktivierung?“
