.NET 8 프로젝트를 .NET 9로 마이그레이션하고 모든 주요 변경 사항을 해결합니다. 사용 대상: Net8.0에서 net9.0으로 TargetFramework 업그레이드, .NET 9 SDK 업데이트 후 빌드 오류 수정, .NET 9/C# 13/ASP.NET Core 9/EF Core 9의 동작 변경 사항 해결, BinaryFormatter 교체(이제 항상 발생), SYSLIB0054-SYSLIB0057 해결, 매개변수 범위 오버로드 해결에 적용, C# 13 컴파일러 변경 사항 수정, 업데이트 SocketsHttpHandler용 HttpClientFactory 및 EF Core 9 마이그레이션/Cosmos DB 변경 사항을 해결합니다. 사용하지 마십시오: .NET Framework 마이그레이션, .NET 7 이하에서 업그레이드, 그린필드 .NET 9 프로젝트 또는 업그레이드와 관련 없는 외관상 현대화.
