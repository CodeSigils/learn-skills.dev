Diagnostique et corrige les problèmes de l’environnement de développement .NET MAUI. Valide le SDK .NET, les charges de travail, le JDK Java, le SDK Android, Xcode et le SDK Windows. Toutes les exigences de version découvertes dynamiquement à partir de NuGet WorkloadDependencies.json – jamais codées en dur. À utiliser lors de : la configuration du développement MAUI, les erreurs de construction mentionnant SDK/workload/JDK/Android, les erreurs "Android SDK introuvable", les erreurs "Version Java", "Xcode introuvable", la vérification de l'environnement après les mises à jour ou tout problème de chaîne d'outils MAUI. Ne pas utiliser pour : les projets .NET non MAUI, les applications Xamarin.Forms, les plantages d'applications d'exécution sans rapport avec la configuration de l'environnement ou les problèmes de publication sur l'App Store. Fonctionne sur macOS, Windows et Linux.
