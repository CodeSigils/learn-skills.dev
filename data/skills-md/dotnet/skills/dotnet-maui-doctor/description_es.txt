Diagnostica y soluciona problemas del entorno de desarrollo .NET MAUI. Valida .NET SDK, cargas de trabajo, Java JDK, Android SDK, Xcode y Windows SDK. Todos los requisitos de la versión se descubren dinámicamente desde NuGet WorkloadDependencies.json, nunca codificados. Úselo cuando: configure el desarrollo de MAUI, errores de compilación que mencionen SDK/carga de trabajo/JDK/Android, "SDK de Android no encontrado", errores de "versión de Java", "Xcode no encontrado", verificación del entorno después de las actualizaciones o cualquier problema con la cadena de herramientas de MAUI. No lo use para: proyectos .NET que no sean MAUI, aplicaciones Xamarin.Forms, fallas de aplicaciones en tiempo de ejecución no relacionadas con la configuración del entorno o problemas de publicación en la tienda de aplicaciones. Funciona en macOS, Windows y Linux.
