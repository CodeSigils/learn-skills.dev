Диагностирует и устраняет проблемы среды разработки .NET MAUI. Проверяет .NET SDK, рабочие нагрузки, Java JDK, Android SDK, Xcode и Windows SDK. Все требования к версии обнаруживаются динамически из NuGet WorkloadDependologies.json и никогда не записываются жестко. Используйте при: настройке разработки MAUI, ошибках сборки с упоминанием SDK/workload/JDK/Android, «Android SDK не найден», ошибках «версии Java», «Xcode не найден», проверке среды после обновлений или любых проблемах с набором инструментов MAUI. Не используйте для: проектов .NET, отличных от MAUI, приложений Xamarin.Forms, сбоев приложений во время выполнения, не связанных с настройкой среды, или проблем с публикацией в магазине приложений. Работает на macOS, Windows и Linux.
