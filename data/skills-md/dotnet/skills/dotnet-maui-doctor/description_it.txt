Diagnostica e risolve i problemi dell'ambiente di sviluppo .NET MAUI. Convalida .NET SDK, carichi di lavoro, Java JDK, Android SDK, Xcode e Windows SDK. Tutti i requisiti di versione rilevati dinamicamente da NuGet WorkloadDependencies.json, mai codificati. Da utilizzare quando: impostazione dello sviluppo MAUI, errori di creazione che menzionano SDK/carico di lavoro/JDK/Android, "SDK Android non trovato", errori "versione Java", "Xcode non trovato", verifica dell'ambiente dopo gli aggiornamenti o qualsiasi problema relativo alla toolchain MAUI. Non utilizzare per: progetti .NET non MAUI, app Xamarin.Forms, arresti anomali delle app runtime non correlati alla configurazione dell'ambiente o problemi di pubblicazione dell'App Store. Funziona su macOS, Windows e Linux.
