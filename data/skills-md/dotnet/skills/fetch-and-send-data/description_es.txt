Llame a API, cargue datos en componentes y maneje el ciclo de vida asíncrono en Blazor. UTILIZAR PARA recuperar datos de un backend, enviar datos a una API, mostrar estados de carga/error, registrar HttpClient, crear abstracciones de servicios para modos de renderizado Automático/WebAssembly. NO LO UTILICE para validación de formularios (ver recopilación de entradas de usuarios), persistencia de prerenderizado (ver soporte-prerenderizado) o andamiaje de proyectos (ver crear-blazor-project).
