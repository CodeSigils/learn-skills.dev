Appelez des API, chargez des données dans des composants et gérez le cycle de vie asynchrone dans Blazor. UTILISER POUR récupérer des données à partir d'un backend, soumettre des données à une API, afficher les états de chargement/d'erreur, enregistrer HttpClient, créer des abstractions de service pour les modes de rendu Auto/WebAssembly. NE PAS UTILISER pour la validation de formulaire (voir collect-user-input), la persistance du pré-rendu (voir support-prerendering) ou l'échafaudage de projet (voir create-blazor-project).
