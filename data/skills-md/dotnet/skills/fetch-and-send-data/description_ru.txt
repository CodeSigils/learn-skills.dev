Вызывайте API, загружайте данные в компоненты и управляйте асинхронным жизненным циклом в Blazor. ИСПОЛЬЗУЕТСЯ ДЛЯ получения данных из серверной части, отправки данных в API, отображения состояний загрузки/ошибок, регистрации HttpClient, построения абстракций сервисов для режимов рендеринга Auto/WebAssembly. НЕ ИСПОЛЬЗУЙТЕ для проверки формы (см. раздел «collect-user-input»), сохранения предварительной отрисовки (см. «support-prerendering») или формирования каркаса проекта (см. «create-blazor-project»).
