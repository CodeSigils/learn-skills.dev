Catalogue d'anti-modèles MSBuild avec règles de détection et recettes de correctifs. Activez uniquement dans le contexte de build MSBuild/.NET. UTILISER POUR : examiner, auditer ou nettoyer les fichiers .csproj, .vbproj, .fsproj, .props, .targets ou .proj. Chaque anti-modèle a un symptôme, une explication et une transformation concrète MAUVAIS → BON. Couvre les tâches d'exécution au lieu de tâches intégrées, les conditions non citées, les chemins codés en dur, la reformulation des valeurs par défaut du SDK, les versions de packages dispersées, etc. NE PAS UTILISER POUR : les systèmes de build non MSBuild (npm, Maven, CMake, etc.), la migration de projet vers le style SDK (utilisez msbuild-modernization).
