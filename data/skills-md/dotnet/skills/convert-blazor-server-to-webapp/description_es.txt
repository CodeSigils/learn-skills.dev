Guía la conversión de una aplicación Blazor Server anterior a .NET 8 en una aplicación web Blazor .NET 8+. UTILIZAR PARA: migrar aplicaciones que usan AddServerSideBlazor y MapBlazorHub al modelo AddRazorComponents/MapRazorComponents, convertir _Host.cshtml a un componente raíz de App.razor, reemplazar blazor.server.js con blazor.web.js, migrar CascadingAuthenticationState a un servicio, adoptar nuevas características de la aplicación web Blazor como navegación mejorada y renderizado en streaming. NO LO UTILICE PARA: aplicaciones que ya son Blazor Web Apps (ya usan AddRazorComponents y MapRazorComponents), Blazor WebAssembly o aplicaciones Blazor WebAssembly alojadas (ruta de migración diferente), aplicaciones que deben permanecer en el modelo de hospedaje de Blazor Server sin realizar conversiones o aplicaciones que aún tienen como destino .NET Framework.
