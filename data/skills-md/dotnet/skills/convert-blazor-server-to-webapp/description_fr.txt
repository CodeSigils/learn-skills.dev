Guide la conversion d’une application Blazor Server pré-.NET 8 en une application Web .NET 8+ Blazor. UTILISER POUR : migrer des applications qui utilisent AddServerSideBlazor et MapBlazorHub vers le modèle AddRazorComponents/MapRazorComponents, convertir _Host.cshtml en un composant racine App.razor, remplacer blazor.server.js par blazor.web.js, migrer CascadingAuthenticationState vers un service, adopter de nouvelles fonctionnalités de Blazor Web App telles que la navigation améliorée et rendu en streaming. NE PAS UTILISER POUR : les applications qui sont déjà des applications Web Blazor (utilisent déjà AddRazorComponents et MapRazorComponents), Blazor WebAssembly ou des applications Blazor WebAssembly hébergées (chemin de migration différent), les applications qui doivent rester sur le modèle d'hébergement de Blazor Server sans conversion, ou les applications ciblant toujours .NET Framework.
