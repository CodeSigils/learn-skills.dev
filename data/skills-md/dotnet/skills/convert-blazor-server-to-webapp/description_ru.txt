Руководства по преобразованию серверного приложения Blazor до версии .NET 8 в веб-приложение Blazor .NET 8+. ИСПОЛЬЗОВАНИЕ ДЛЯ: миграции приложений, использующих AddServerSideBlazor и MapBlazorHub, в модель AddRazorComponents/MapRazorComponents, преобразования _Host.cshtml в корневой компонент App.razor, замены blazor.server.js на blazor.web.js, миграции CascadingAuthenticationState в службу, внедрения новых функций Blazor Web App, таких как расширенная навигация и потоковая передача. рендеринг. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: приложений, которые уже являются веб-приложениями Blazor (уже используют AddRazorComponents и MapRazorComponents), Blazor WebAssembly или размещенными приложениями Blazor WebAssembly (другой путь миграции), приложениями, которые должны оставаться на модели размещения Blazor Server без преобразования, или приложениями, все еще ориентированными на .NET Framework.
