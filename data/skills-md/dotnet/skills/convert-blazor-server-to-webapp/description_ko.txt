.NET 8 이전 Blazor 서버 앱을 .NET 8+ Blazor 웹 앱으로 변환하는 방법을 안내합니다. 사용 대상: AddServerSideBlazor 및 MapBlazorHub를 사용하는 앱을 AddRazorComponents/MapRazorComponents 모델로 마이그레이션, _Host.cshtml을 App.razor 루트 구성 요소로 변환, blazor.server.js를 blazor.web.js로 교체, CascadingAuthenticationState를 서비스로 마이그레이션, 향상된 탐색 및 스트리밍 렌더링과 같은 새로운 Blazor 웹 앱 기능 채택. 사용하지 마세요: 이미 Blazor Web Apps(이미 AddRazorComponents 및 MapRazorComponents 사용)인 앱, Blazor WebAssembly 또는 호스팅된 Blazor WebAssembly 앱(다른 마이그레이션 경로), 변환하지 않고 Blazor Server 호스팅 모델에 유지되어야 하는 앱 또는 여전히 .NET Framework를 대상으로 하는 앱.
