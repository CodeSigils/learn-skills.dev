Leitet die Konvertierung einer Blazor-Server-App vor .NET 8 in eine Blazor-Web-App mit .NET 8+. VERWENDUNG FÜR: Migration von Apps, die AddServerSideBlazor und MapBlazorHub verwenden, zum AddRazorComponents/MapRazorComponents-Modell, Konvertieren von _Host.cshtml in eine App.razor-Stammkomponente, Ersetzen von blazor.server.js durch blazor.web.js, Migrieren von CascadingAuthenticationState zu einem Dienst, Übernahme neuer Blazor-Web-App-Funktionen wie verbesserte Navigation und Streaming-Rendering. NICHT VERWENDEN FÜR: Apps, die bereits Blazor Web Apps sind (verwenden Sie bereits AddRazorComponents und MapRazorComponents), Blazor WebAssembly oder gehostete Blazor WebAssembly-Apps (anderer Migrationspfad), Apps, die ohne Konvertierung auf dem Blazor Server-Hostingmodell bleiben sollten, oder Apps, die weiterhin auf .NET Framework abzielen.
