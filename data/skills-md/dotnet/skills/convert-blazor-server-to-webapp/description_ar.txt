يرشد تحويل تطبيق ما قبل .NET 8 Blazor Server إلى تطبيق .NET 8+ Blazor Web App. الاستخدام من أجل: ترحيل التطبيقات التي تستخدم AddServerSideBlazor وMapBlazorHub إلى نموذج AddRazorComponents/MapRazorComponents، وتحويل _Host.cshtml إلى مكون جذر App.razor، واستبدال blazor.server.js بـ blazor.web.js، وترحيل CascadingAuthenticationState إلى خدمة، واعتماد ميزات Blazor Web App الجديدة مثل الميزات المحسّنة الملاحة وتقديم التدفق. لا تستخدمه من أجل: التطبيقات التي هي بالفعل Blazor Web Apps (تستخدم بالفعل AddRazorComponents وMapRazorComponents)، أو Blazor WebAssembly أو تطبيقات Blazor WebAssembly المستضافة (مسار ترحيل مختلف)، أو التطبيقات التي يجب أن تظل على نموذج استضافة Blazor Server دون تحويل، أو التطبيقات التي لا تزال تستهدف .NET Framework.
