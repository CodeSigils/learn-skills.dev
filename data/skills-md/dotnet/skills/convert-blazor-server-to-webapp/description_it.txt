Guida la conversione di un'app Blazor Server precedente a .NET 8 in un'app Web Blazor .NET 8+. UTILIZZARE PER: migrazione di app che utilizzano AddServerSideBlazor e MapBlazorHub al modello AddRazorComponents/MapRazorComponents, conversione di _Host.cshtml in un componente root App.razor, sostituzione di blazor.server.js con blazor.web.js, migrazione di CascadingAuthenticationState a un servizio, adozione di nuove funzionalità dell'app Web Blazor come navigazione migliorata e rendering in streaming. NON UTILIZZARE PER: app che sono già Blazor Web Apps (usano già AddRazorComponents e MapRazorComponents), Blazor WebAssembly o app Blazor WebAssembly ospitate (percorso di migrazione diverso), app che devono rimanere nel modello di hosting Blazor Server senza conversione o app ancora destinate a .NET Framework.
