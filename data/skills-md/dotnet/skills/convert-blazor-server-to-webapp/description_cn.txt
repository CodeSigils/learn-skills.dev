指导将 .NET 8 之前的 Blazor Server 应用程序转换为 .NET 8+ Blazor Web 应用程序。用于：将使用 AddServerSideBlazor 和 MapBlazorHub 的应用程序迁移到 AddRazorComponents/MapRazorComponents 模型，将 _Host.cshtml 转换为 App.razor 根组件，用 blazor.web.js 替换 blazor.server.js，将 CascadingAuthenticationState 迁移到服务，采用新的 Blazor Web App 功能（例如增强型导航和流式渲染）。请勿用于：已经是 Blazor Web 应用程序的应用程序（已使用 AddRazorComponents 和 MapRazorComponents）、Blazor WebAssembly 或托管 Blazor WebAssembly 应用程序（不同的迁移路径）、应保留在 Blazor Server 托管模型上而不进行转换的应用程序，或仍面向 .NET Framework 的应用程序。
