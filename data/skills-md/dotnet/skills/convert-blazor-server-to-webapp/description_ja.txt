.NET 8 以前の Blazor サーバー アプリを .NET 8 以降の Blazor Web アプリに変換するガイドです。用途: AddServerSideBlazor と MapBlazorHub を使用するアプリを AddRazorComponents/MapRazorComponents モデルに移行する、_Host.cshtml を App.razor ルート コンポーネントに変換する、blazor.server.js を blazor.web.js に置き換える、CascadingAuthenticationState をサービスに移行する、強化されたナビゲーションやストリーミング レンダリングなどの新しい Blazor Web App 機能を採用する。次の場合には使用しないでください: すでに Blazor Web Apps であるアプリ (すでに AddRazorComponents と MapRazorComponents を使用している)、Blazor WebAssembly またはホストされている Blazor WebAssembly アプリ (別の移行パス)、変換せずに Blazor Server ホスティング モデルに留まる必要があるアプリ、またはまだ .NET Framework をターゲットとしているアプリ。
