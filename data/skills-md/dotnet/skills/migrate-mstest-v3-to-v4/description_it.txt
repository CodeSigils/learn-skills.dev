Migrare un progetto di test MSTest v3 a MSTest v4. Da utilizzare quando l'utente dice "aggiornamento a MSTest v4", "aggiornamento all'ultimo MSTest", "migrazione MSTest 4", "modifiche importanti di MSTest v4", "compatibilità MSTest v4" o presenta errori di creazione dopo l'aggiornamento dei pacchetti MSTest da 3.x a 4.x. Utilizzare anche per la compatibilità del framework di destinazione (ad esempio supporto net6.0/net7.0 con MSTest v4). UTILIZZO PER: aggiornamento dei pacchetti MSTest da 3.x a 4.x, correzione di modifiche importanti all'origine (Esegui -> ExecuteAsync, costruttore CallerInfo, rimozione di ClassCleanupBehavior, TestContext.Properties, modifiche API Assert, rimozione ExpectedExceptionAttribute, rimozione enum TestTimeout), risoluzione di modifiche comportamentali (TreatDiscoveryWarningsAsErrors, ciclo di vita TestContext, modifiche TestCase.Id, Modifiche MSTest.Sdk MTP), gestione dei TFM eliminati (net5.0-net7.0 eliminati, sono supportati solo net8.0+, net462, uap10.0). NON UTILIZZARE PER: migrazione da MSTest v1/v2 a v3 (utilizzare prima migrazione-mstest-v1v2-to-v3), migrazione tra framework di test o aggiornamenti generali di .NET non correlati a MSTest.
