Перенесите тестовый проект MSTest v3 в MSTest v4. Используйте, когда пользователь говорит «обновить до MSTest v4», «обновить до последней версии MSTest», «миграция MSTest 4», «критические изменения MSTest v4», «совместимость MSTest v4» или имеет ошибки сборки после обновления пакетов MSTest с версии 3.x до 4.x. Также используйте для совместимости с целевой платформой (например, поддержка net6.0/net7.0 с MSTest v4). ИСПОЛЬЗОВАНИЕ ДЛЯ: обновления пакетов MSTest с 3.x до 4.x, исправления критических изменений исходного кода (Execute -> ExecuteAsync, конструктор CallerInfo, удаление ClassCleanupBehavior, TestContext.Properties, изменения Assert API, удаление ExpectedExceptionAttribute, удаление перечисления TestTimeout), разрешение поведенческих изменений (TreatDiscoveryWarningsAsErrors, жизненный цикл TestContext, Изменения TestCase.Id, изменения MSTest.Sdk MTP), обработка отброшенных TFM (net5.0-net7.0 отброшены, поддерживаются только net8.0+, net462, uap10.0). НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: миграции с MSTest v1/v2 на v3 (сначала используйтеmigrate-mstest-v1v2-to-v3), миграции между тестовыми платформами или общих обновлений .NET, не связанных с MSTest.
