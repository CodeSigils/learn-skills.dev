Migrieren Sie ein MSTest v3-Testprojekt nach MSTest v4. Verwenden Sie diese Option, wenn der Benutzer „Upgrade auf MSTest v4“, „Update auf den neuesten MSTest“, „MSTest 4-Migration“, „MSTest v4 bricht Änderungen“, „MSTest v4-Kompatibilität“ sagt oder nach der Aktualisierung der MSTest-Pakete von 3.x auf 4.x Buildfehler hat. Auch für die Kompatibilität des Zielframeworks verwenden (z. B. net6.0/net7.0-Unterstützung mit MSTest v4). VERWENDUNG FÜR: Aktualisieren von MSTest-Paketen von 3.x auf 4.x, Beheben von Änderungen an der Quelle (Execute -> ExecuteAsync, CallerInfo-Konstruktor, Entfernen von ClassCleanupBehavior, TestContext.Properties, Assert-API-Änderungen, Entfernen von ExpectedExceptionAttribute, Entfernen der TestTimeout-Enumeration), Beheben von Verhaltensänderungen (TreatDiscoveryWarningsAsErrors, TestContext-Lebenszyklus, TestCase.Id-Änderungen, MSTest.Sdk MTP-Änderungen), Umgang mit gelöschten TFMs (net5.0-net7.0 gelöscht, nur net8.0+, net462, uap10.0 unterstützt). NICHT VERWENDEN FÜR: Migration von MSTest v1/v2 auf v3 (verwenden Sie zuerst migrate-mstest-v1v2-to-v3), Migration zwischen Test-Frameworks oder allgemeine .NET-Upgrades, die nichts mit MSTest zu tun haben.
