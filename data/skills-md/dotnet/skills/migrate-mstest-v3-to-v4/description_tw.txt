將 MSTest v3 測試項目遷移到 MSTest v4。當使用者說「升級到 MSTest v4」、「更新到最新的 MSTest」、「MSTest 4 遷移」、「MSTest v4 重大變更」、「MSTest v4 相容性」或在將 MSTest 套件從 3.x 更新到 4.x 後出現產生錯誤時使用。也用於目標框架相容性（例如 MSTest v4 的 net6.0/net7.0 支援）。用於：將 MSTest 套件從 3.x 升級到 4.x、修復原始程式碼重大變更（Execute -> ExecuteAsync、CallerInfo 建構子、ClassCleanupBehavior 刪除、TestContext.Properties、Assert API 變更、ExpectedExceptionAttribute 刪除、TestTimeout枚舉刪除）、解決行為變更（TreatDiscoveryWarningsAsErrors、TestContext 生命週期、TestCase.Id 變更、MSTest.Sdk MTP 變更）、處理TFM（net5.0-net7.0 已棄用，僅支援 net8.0+、net462、uap10.00）。請勿用於：從 MSTest v1/v2 遷移到 v3（首先使用 migrate-mstest-v1v2-to-v3）、在測試框架之間遷移或與 MSTest 無關的常規 .NET 升級。
