Migre un proyecto de prueba MSTest v3 a MSTest v4. Úselo cuando el usuario diga "actualizar a MSTest v4", "actualizar a la última versión de MSTest", "migración de MSTest 4", "cambios importantes de MSTest v4", "compatibilidad con MSTest v4" o tiene errores de compilación después de actualizar los paquetes de MSTest de 3.x a 4.x. Úselo también para la compatibilidad del marco de destino (por ejemplo, compatibilidad con net6.0/net7.0 con MSTest v4). USO PARA: actualizar paquetes MSTest de 3.x a 4.x, corregir cambios importantes en la fuente (Execute -> ExecuteAsync, constructor CallerInfo, eliminación de ClassCleanupBehavior, TestContext.Properties, cambios de Assert API, eliminación de ExpectedExceptionAttribute, eliminación de enumeraciones TestTimeout), resolver cambios de comportamiento (TreatDiscoveryWarningsAsErrors, ciclo de vida de TestContext, cambios de TestCase.Id, MSTest.Sdk MTP cambios), manejo de TFM eliminados (net5.0-net7.0 eliminado, solo se admiten net8.0+, net462, uap10.0). NO LO UTILICE PARA: migrar de MSTest v1/v2 a v3 (use primero migrar-mstest-v1v2-to-v3), migrar entre marcos de prueba o actualizaciones generales de .NET no relacionadas con MSTest.
