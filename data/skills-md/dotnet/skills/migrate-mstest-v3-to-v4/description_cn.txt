将 MSTest v3 测试项目迁移到 MSTest v4。当用户说“升级到 MSTest v4”、“更新到最新的 MSTest”、“MSTest 4 迁移”、“MSTest v4 重大更改”、“MSTest v4 兼容性”或在将 MSTest 包从 3.x 更新到 4.x 后出现生成错误时使用。还用于目标框架兼容性（例如 MSTest v4 的 net6.0/net7.0 支持）。用于：将 MSTest 包从 3.x 升级到 4.x、修复源代码重大更改（Execute -> ExecuteAsync、CallerInfo 构造函数、ClassCleanupBehavior 删除、TestContext.Properties、Assert API 更改、ExpectedExceptionAttribute 删除、TestTimeout 枚举删除）、解决行为更改（TreatDiscoveryWarningsAsErrors、TestContext 生命周期、TestCase.Id 更改、MSTest.Sdk MTP 更改）、处理丢弃TFM（net5.0-net7.0 已弃用，仅支持 net8.0+、net462、uap10.0）。请勿用于：从 MSTest v1/v2 迁移到 v3（首先使用 migrate-mstest-v1v2-to-v3）、在测试框架之间迁移或与 MSTest 无关的常规 .NET 升级。
