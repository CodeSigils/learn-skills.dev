MSTest v3 테스트 프로젝트를 MSTest v4로 마이그레이션합니다. 사용자가 "MSTest v4로 업그레이드", "최신 MSTest로 업데이트", "MSTest 4 마이그레이션", "MSTest v4 주요 변경 사항", "MSTest v4 호환성"이라고 말하거나 MSTest 패키지를 3.x에서 4.x로 업데이트한 후 빌드 오류가 있는 경우에 사용합니다. 또한 대상 프레임워크 호환성을 위해 사용합니다(예: MSTest v4를 통한 net6.0/net7.0 지원). 사용 대상: MSTest 패키지를 3.x에서 4.x로 업그레이드, 소스 주요 변경 사항 수정(Execute -> ExecuteAsync, CallerInfo 생성자, ClassCleanupBehavior 제거, TestContext.Properties, Assert API 변경, ExpectedExceptionAttribute 제거, TestTimeout 열거형 제거), 동작 변경 해결(TreatDiscoveryWarningsAsErrors, TestContext 수명 주기, TestCase.Id 변경, MSTest.Sdk MTP 변경 사항), 삭제된 TFM 처리(net5.0-net7.0 삭제, net8.0+, net462, uap10.0만 지원됨). 사용하지 마십시오: MSTest v1/v2에서 v3으로 마이그레이션(먼저 migration-mstest-v1v2-to-v3 사용), 테스트 프레임워크 간 마이그레이션 또는 MSTest와 관련 없는 일반 .NET 업그레이드.
