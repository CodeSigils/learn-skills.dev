Configura la pubblicazione attendibile NuGet (OIDC) su un repository GitHub Actions: sostituisce le chiavi API di lunga durata con token di breve durata. UTILIZZARE PER: pubblicazione attendibile, NuGet OIDC, pubblicazione NuGet senza chiave, migrazione dalla chiave API NuGet, NuGet/accesso, pubblicazione NuGet protetta. NON UTILIZZARE PER: pubblicazione su feed privati ​​o Azure Artifacts (OIDC è solo nuget.org). INVOCA: shell (powershell o bash), modifica, crea, ask_user per la configurazione guidata del repository.
