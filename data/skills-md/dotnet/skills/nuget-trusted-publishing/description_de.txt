Richten Sie NuGet Trusted Publishing (OIDC) auf einem GitHub Actions-Repository ein – ersetzt langlebige API-Schlüssel durch kurzlebige Token. VERWENDUNG FÜR: vertrauenswürdige Veröffentlichung, NuGet OIDC, schlüssellose NuGet-Veröffentlichung, Migration vom NuGet-API-Schlüssel, NuGet/Anmeldung, sichere NuGet-Veröffentlichung. NICHT VERWENDEN FÜR: Veröffentlichung in privaten Feeds oder Azure Artifacts (OIDC ist nur für nuget.org). AUFRUFEN: Shell (Powershell oder Bash), Bearbeiten, Erstellen, Ask_User für die geführte Repo-Einrichtung.
