GitHub Actions リポジトリで NuGet の信頼された公開 (OIDC) をセットアップします。有効期間の長い API キーを有効期間の短いトークンに置き換えます。用途: 信頼された公開、NuGet OIDC、キーレス NuGet 公開、NuGet API キーからの移行、NuGet/ログイン、安全な NuGet 公開。以下には使用しないでください: プライベート フィードまたは Azure Artifacts への公開 (OIDC は nuget.org のみ)。呼び出し: シェル (powershell または bash)、編集、作成、ガイド付きリポジトリ設定の ask_user。
