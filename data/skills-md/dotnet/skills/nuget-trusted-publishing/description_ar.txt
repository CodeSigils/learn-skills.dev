قم بإعداد النشر الموثوق لـ NuGet (OIDC) على مستودع GitHub Actions - حيث يستبدل مفاتيح API طويلة الأمد برموز قصيرة العمر. الاستخدام من أجل: النشر الموثوق، NuGet OIDC، نشر NuGet بدون مفتاح، الترحيل من مفتاح NuGet API، NuGet/تسجيل الدخول، نشر NuGet الآمن. لا تستخدم من أجل: النشر إلى الخلاصات الخاصة أو Azure Artifacts (OIDC هو nuget.org فقط). الاستدعاءات: shell (powershell أو bash)، والتحرير، والإنشاء، وask_user لإعداد الريبو الموجه.
