Configure la publicación confiable de NuGet (OIDC) en un repositorio de GitHub Actions: reemplaza las claves API de larga duración con tokens de corta duración. UTILIZAR PARA: publicación confiable, NuGet OIDC, publicación NuGet sin clave, migrar desde la clave API de NuGet, NuGet/iniciar sesión, publicación segura de NuGet. NO UTILIZAR PARA: publicar en fuentes privadas o Azure Artifacts (OIDC es solo nuget.org). INVOCA: shell (powershell o bash), editar, crear, preguntar a usuario para la configuración guiada del repositorio.
