Настройте доверенную публикацию NuGet (OIDC) в репозитории GitHub Actions — замените долгоживущие ключи API кратковременными токенами. ИСПОЛЬЗОВАНИЕ ДЛЯ: доверенной публикации, NuGet OIDC, публикации NuGet без ключа, миграции с ключа API NuGet, NuGet/входа, безопасной публикации NuGet. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: публикации в частных каналах или Azure Artifacts (OIDC предназначен только для nuget.org). ВЫЗЫВАЕТ: оболочка (powershell или bash), редактирование, создание, Ask_user для управляемой настройки репозитория.
