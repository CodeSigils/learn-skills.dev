Configurez la publication sécurisée NuGet (OIDC) sur un dépôt GitHub Actions : remplace les clés API de longue durée par des jetons de courte durée. UTILISER POUR : publication approuvée, NuGet OIDC, publication NuGet sans clé, migration à partir de la clé API NuGet, NuGet/connexion, publication NuGet sécurisée. NE PAS UTILISER POUR : la publication sur des flux privés ou sur Azure Artifacts (OIDC concerne nuget.org uniquement). INVOKES : shell (PowerShell ou bash), modifier, créer, demander à l'utilisateur pour une configuration guidée du dépôt.
