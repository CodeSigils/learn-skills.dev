Détecte les projets MSBuild avec OutputPath ou IntermediateOutputPath en conflit. Activez uniquement dans le contexte de build MSBuild/.NET. UTILISER POUR : les builds échouent avec "Impossible de créer un fichier lorsque ce fichier existe déjà", "Le processus ne peut pas accéder au fichier car il est utilisé par un autre processus", les échecs de build intermittents qui réussissent lors d'une nouvelle tentative, les sorties manquantes dans les builds multi-projets, les builds multi-ciblage où project.assets.json est en conflit. Diagnostique lorsque plusieurs projets ou TFM écrivent dans les mêmes répertoires bin/obj en raison d'un OutputPath partagé, de l'absence de AppendTargetFrameworkToOutputPath ou de propriétés globales supplémentaires telles que PublishReadyToRun créant des évaluations redondantes. NE PAS UTILISER POUR : les erreurs d'accès aux fichiers sans rapport avec MSBuild (verrouillage au niveau du système d'exploitation), les builds TFM à projet unique, les systèmes de build non MSBuild. INVOKES : dotnet msbuild binlog replay, grep pour l'analyse du chemin de sortie.
