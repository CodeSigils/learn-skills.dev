Rileva progetti MSBuild con OutputPath o IntermediateOutputPath in conflitto. Attivare solo nel contesto di compilazione MSBuild/.NET. UTILIZZARE PER: build non riuscite con "Impossibile creare un file quando il file esiste già", "Il processo non può accedere al file perché è utilizzato da un altro processo", errori di build intermittenti che riescono dopo un nuovo tentativo, output mancanti nelle build multi-progetto, build multi-targeting in cui project.assets.json è in conflitto. Diagnostica quando più progetti o TFM scrivono nelle stesse directory bin/obj a causa di OutputPath condiviso, della mancanza di AppendTargetFrameworkToOutputPath o di proprietà globali aggiuntive come PublishReadyToRun che creano valutazioni ridondanti. NON UTILIZZARE PER: errori di accesso ai file non correlati a MSBuild (blocco a livello di sistema operativo), build TFM singolo a progetto singolo, sistemi di build non MSBuild. RICHIAMA: dotnet msbuild binlog replay, grep per l'analisi del percorso di output.
