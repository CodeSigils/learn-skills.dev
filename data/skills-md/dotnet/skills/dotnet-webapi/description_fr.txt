Guide la création et la modification des points de terminaison de l’API Web ASP.NET Core avec une sémantique HTTP correcte, des métadonnées OpenAPI et une gestion des erreurs. UTILISER POUR : ajouter de nouveaux points de terminaison d'API (contrôleurs ou API minimales), câbler OpenAPI/Swagger, créer des fichiers de test .http, configurer un middleware global de gestion des erreurs. NE PAS UTILISER POUR : le style de codage C# général, l'accès aux données EF Core ou l'optimisation des requêtes (utilisez l'optimisation des requêtes ef-core), le travail frontend/Blazor, les services gRPC ou les hubs SignalR.
