يرشد إنشاء وتعديل نقاط نهاية ASP.NET Core Web API باستخدام دلالات HTTP الصحيحة وبيانات تعريف OpenAPI ومعالجة الأخطاء. الاستخدام من أجل: إضافة نقاط نهاية جديدة لواجهة برمجة التطبيقات (وحدات التحكم أو الحد الأدنى من واجهات برمجة التطبيقات)، وتوصيل OpenAPI/Swagger، وإنشاء ملفات اختبار .http، وإعداد البرامج الوسيطة لمعالجة الأخطاء العالمية. لا تستخدمه من أجل: نمط ترميز C# العام، أو الوصول إلى بيانات EF Core أو تحسين الاستعلام (استخدم استعلامات Optimizing-ef-core)، أو عمل الواجهة الأمامية/Blazor، أو خدمات gRPC، أو محاور SignalR.
