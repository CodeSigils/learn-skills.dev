Guida la creazione e la modifica degli endpoint API Web ASP.NET Core con la semantica HTTP, i metadati OpenAPI e la gestione degli errori corretti. UTILIZZO PER: aggiunta di nuovi endpoint API (controller o API minime), cablaggio di OpenAPI/Swagger, creazione di file di test .http, configurazione di middleware di gestione degli errori globale. NON UTILIZZARE PER: stile di codifica C# generale, accesso ai dati EF Core o ottimizzazione delle query (usare optimization-ef-core-queries), lavoro frontend/Blazor, servizi gRPC o hub SignalR.
