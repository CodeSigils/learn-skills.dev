Guía la creación y modificación de puntos finales de ASP.NET Core Web API con semántica HTTP correcta, metadatos de OpenAPI y manejo de errores. UTILIZAR PARA: agregar nuevos puntos finales API (controladores o API mínimas), conectar OpenAPI/Swagger, crear archivos de prueba .http, configurar middleware de manejo de errores globales. NO LO UTILICE PARA: estilo de codificación general de C#, acceso a datos de EF Core u optimización de consultas (use optimización-ef-core-queries), trabajo frontend/Blazor, servicios gRPC o concentradores SignalR.
