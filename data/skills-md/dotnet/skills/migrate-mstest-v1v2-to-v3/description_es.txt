Migre el proyecto de prueba MSTest v1 o v2 a MSTest v3. Úselo cuando el usuario diga "actualizar MSTest", "actualizar a MSTest v3", "migrar a MSTest v3", "actualizar marco de prueba", "modernizar pruebas", "migración de MSTest v3", "compatibilidad con MSTest", "MSTest v2 a v3" o generar errores después de actualizar los paquetes de MSTest de 1.x/2.x a 3.x. UTILIZAR PARA: actualizar desde referencias de ensamblado de MSTest v1 (Microsoft.VisualStudio.QualityTools.UnitTestFramework) o MSTest v2 NuGet (MSTest.TestFramework 1.x-2.x) a MSTest v3, corregir errores de sobrecarga de aserciones (AreEqual/AreNotEqual), actualizar constructores de DataRow, reemplazar .testsettings con .runsettings, cambios en el comportamiento del tiempo de espera, compatibilidad con el marco de destino (se eliminó .NET 5; use .NET 6+; se eliminó .NET Fx anterior a 4.6.2), adopción de MSTest.Sdk. Primer paso hacia MSTest v4; después de esto, use migrar-mstest-v3-to-v4. NO LO UTILICE PARA: migrar a MSTest v4 (use migrar-mstest-v3-to-v4), migrar entre marcos (MSTest a xUnit/NUnit) o ​​actualizaciones generales de .NET no relacionadas con MSTest.
