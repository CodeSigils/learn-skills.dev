Migrieren Sie das MSTest v1- oder v2-Testprojekt nach MSTest v3. Wird verwendet, wenn der Benutzer „MSTest aktualisieren“, „Auf MSTest v3 aktualisieren“, „auf MSTest v3 migrieren“, „Testframework aktualisieren“, „Tests modernisieren“, „MSTest v3-Migration“, „MSTest-Kompatibilität“, „MSTest v2 auf v3“ sagt oder nach der Aktualisierung der MSTest-Pakete von 1.x/2.x auf 3.x Fehler beim Erstellen auftreten. VERWENDUNG FÜR: Upgrade von MSTest v1-Assembly-Referenzen (Microsoft.VisualStudio.QualityTools.UnitTestFramework) oder MSTest v2 NuGet (MSTest.TestFramework 1.x-2.x) auf MSTest v3, Behebung von Assertion-Überladungsfehlern (AreEqual/AreNotEqual), Aktualisierung von DataRow-Konstruktoren, Ersetzen von .testsettings durch .runsettings, Änderungen des Timeout-Verhaltens, Ziel-Framework-Kompatibilität (.NET 5 wurde gelöscht – Verwenden Sie .NET 6+; .NET Fx älter als 4.6.2 wurde gelöscht) und übernimmt MSTest.Sdk. Erster Schritt in Richtung MSTest v4 – danach verwenden Sie migrate-mstest-v3-to-v4. NICHT VERWENDEN FÜR: Migration zu MSTest v4 (verwenden Sie migrate-mstest-v3-to-v4), Migration zwischen Frameworks (MSTest zu xUnit/NUnit) oder allgemeine .NET-Upgrades, die nichts mit MSTest zu tun haben.
