MSTest v1 または v2 テスト プロジェクトを MSTest v3 に移行します。ユーザーが「MSTest のアップグレード」、「MSTest v3 へのアップグレード」、「MSTest v3 への移行」、「テスト フレームワークの更新」、「テストの最新化」、「MSTest v3 への移行」、「MSTest の互換性」、「MSTest v2 から v3 へ」、または MSTest パッケージを 1.x/2.x から 3.x に更新した後のビルド エラーを言った場合に使用します。用途: MSTest v1 アセンブリ参照 (Microsoft.VisualStudio.QualityTools.UnitTestFramework) または MSTest v2 NuGet (MSTest.TestFramework 1.x-2.x) から MSTest v3 へのアップグレード、アサーション オーバーロード エラー (AreEqual/AreNotEqual) の修正、DataRow コンストラクターの更新、.testsettings から .runsettings への置き換え、タイムアウト動作の変更、ターゲット フレームワークの互換性(.NET 5 は廃止されました -- .NET 6+ を使用してください。4.6.2 より古い .NET Fx は廃止されました)、MSTest.Sdk を採用しました。 MSTest v4 に向けた最初のステップ -- この後、merge-mstest-v3-to-v4 を使用します。次の目的には使用しないでください: MSTest v4 への移行 (merge-mstest-v3-to-v4 を使用)、フレームワーク間の移行 (MSTest から xUnit/NUnit)、または MSTest に関係のない一般的な .NET アップグレード。
