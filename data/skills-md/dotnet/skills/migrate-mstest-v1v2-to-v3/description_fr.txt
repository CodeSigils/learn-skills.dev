Migrez le projet de test MSTest v1 ou v2 vers MSTest v3. À utiliser lorsque l'utilisateur dit « mettre à niveau MSTest », « mettre à niveau vers MSTest v3 », « migrer vers MSTest v3 », « mettre à jour le cadre de test », « moderniser les tests », « migration MSTest v3 », « compatibilité MSTest », « MSTest v2 vers v3 » ou générer des erreurs après la mise à jour des packages MSTest de 1.x/2.x vers 3.x. UTILISER POUR : mise à niveau des références d'assembly MSTest v1 (Microsoft.VisualStudio.QualityTools.UnitTestFramework) ou MSTest v2 NuGet (MSTest.TestFramework 1.x-2.x) vers MSTest v3, correction des erreurs de surcharge d'assertion (AreEqual/AreNotEqual), mise à jour des constructeurs DataRow, remplacement de .testsettings par .runsettings, changements de comportement de délai d'attente, framework cible compatibilité (.NET 5 abandonné - utilisez .NET 6+ ; .NET Fx antérieur à 4.6.2 abandonné), en adoptant MSTest.Sdk. Premier pas vers MSTest v4 – après cela, utilisez migrate-mstest-v3-to-v4. NE PAS UTILISER POUR : la migration vers MSTest v4 (utilisez migrate-mstest-v3-to-v4), la migration entre les frameworks (MSTest vers xUnit/NUnit) ou les mises à niveau générales .NET sans rapport avec MSTest.
