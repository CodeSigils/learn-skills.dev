Migre les projets de test .NET de VSTest vers Microsoft.Testing.Platform (MTP). À utiliser lorsque l'utilisateur demande de "migrer vers MTP", "passer de VSTest", "activer Microsoft.Testing.Platform", "utiliser MTP runner" ou mentionne EnableMSTestRunner, EnableNUnitRunner, UseMicrosoftTestingPlatformRunner ou le code de sortie de test dotnet 8. Prend en charge MSTest, NUnit, xUnit.net v2 (via YTest.MTP.XUnit2) et xUnit.net v3 (MTP natif). Couvre également la traduction de la syntaxe du filtre MTP xUnit.net v3 (--filter-class, --filter-trait, --filter-query). Couvre l'activation du programme d'exécution, la traduction des arguments CLI, la configuration Directory.Build.props et global.json, les mises à jour du pipeline CI/CD et les packages d'extension MTP. NE PAS UTILISER POUR : la migration entre les frameworks de test (MSTest/xUnit/NUnit), la migration de l'API xUnit.net v2 vers v3, les mises à niveau de version MSTest (utilisez les compétences migrate-mstest-*), les mises à niveau TFM ou les projets de test UWP/WinUI.
