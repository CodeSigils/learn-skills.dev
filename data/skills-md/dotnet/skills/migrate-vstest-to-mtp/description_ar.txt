ترحيل مشاريع اختبار .NET من VSTest إلى Microsoft.Testing.Platform (MTP). يُستخدم عندما يطلب المستخدم "الترحيل إلى MTP"، أو "التبديل من VSTest"، أو "تمكين Microsoft.Testing.Platform"، أو "استخدام مشغل MTP"، أو يذكر EnableMSTestRunner، أو EnableNUnitRunner، أو UseMicrosoftTestingPlatformRunner، أو رمز الخروج لاختبار dotnet 8. يدعم MSTest، NUnit، xUnit.net v2 (عبر YTest.MTP.XUnit2)، و xUnit.net v3 (الخطة المتوسطة الأجل الأصلية). يغطي أيضًا ترجمة صيغة مرشح xUnit.net v3 MTP (--filter-class، --filter-trait، --filter-query). يغطي تمكين المشغل، وترجمة وسيطة CLI، وتكوين Directory.Build.props وglobal.json، وتحديثات خطوط أنابيب CI/CD، وحزم امتداد MTP. لا تستخدمه من أجل: الترحيل بين أطر عمل الاختبار (MSTest/xUnit/NUnit)، أو ترحيل xUnit.net v2 إلى v3 API، أو ترقيات إصدار MSTest (استخدم مهارات migrate-mstest-*)، أو ترقيات TFM، أو مشاريع اختبار UWP/WinUI.
