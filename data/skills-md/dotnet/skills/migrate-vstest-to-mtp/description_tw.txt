將 .NET 測試項目從 VSTest 遷移到 Microsoft.Testing.Platform (MTP)。當使用者要求「遷移到 MTP」、「從 VSTest 切換」、「啟用 Microsoft.Testing.Platform」、「使用 MTP 執行程式」或提及 EnableMSTestRunner、EnableNUnitRunner、UseMicrosoftTestingPlatformRunner 或 dotnet 測試退出代碼 8 時使用。支援 MSTest、NUnit、xUnit.net v2（透過 YTest.MTP.XUnit2）和 xUnit.net v3（本機 MTP）。也涵蓋翻譯 xUnit.net v3 MTP 過濾器語法（--filter-class、--filter-trait、--filter-query）。涵蓋運行器啟用、CLI 參數轉換、Directory.Build.props 和 global.json 設定、CI/CD 管道更新以及 MTP 擴充包。請勿用於：在測試框架 (MSTest/xUnit/NUnit) 之間遷移、xUnit.net v2 到 v3 API 遷移、MSTest 版本升級（使用 migrate-mstest-* 技能）、TFM 升級或 UWP/WinUI 測試專案。
