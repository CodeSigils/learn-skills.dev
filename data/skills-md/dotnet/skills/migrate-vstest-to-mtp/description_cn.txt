将 .NET 测试项目从 VSTest 迁移到 Microsoft.Testing.Platform (MTP)。当用户要求“迁移到 MTP”、“从 VSTest 切换”、“启用 Microsoft.Testing.Platform”、“使用 MTP 运行程序”或提及 EnableMSTestRunner、EnableNUnitRunner、UseMicrosoftTestingPlatformRunner 或 dotnet 测试退出代码 8 时使用。支持 MSTest、NUnit、xUnit.net v2（通过 YTest.MTP.XUnit2）和 xUnit.net v3（本机 MTP）。还涵盖翻译 xUnit.net v3 MTP 过滤器语法（--filter-class、--filter-trait、--filter-query）。涵盖运行器启用、CLI 参数转换、Directory.Build.props 和 global.json 配置、CI/CD 管道更新以及 MTP 扩展包。请勿用于：在测试框架 (MSTest/xUnit/NUnit) 之间迁移、xUnit.net v2 到 v3 API 迁移、MSTest 版本升级（使用 migrate-mstest-* 技能）、TFM 升级或 UWP/WinUI 测试项目。
