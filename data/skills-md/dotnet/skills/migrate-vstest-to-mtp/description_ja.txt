.NET テスト プロジェクトを VSTest から Microsoft.Testing.Platform (MTP) に移行します。ユーザーが「MTP への移行」、「VSTest からの切り替え」、「Microsoft.Testing.Platform の有効化」、「MTP ランナーの使用」を要求する場合、または EnableMSTestRunner、EnableNUnitRunner、UseMicrosoftTestingPlatformRunner、またはドットネット テスト終了コード 8 に言及する場合に使用します。MSTest、NUnit、xUnit.net v2 (YTest.MTP.XUnit2 経由) をサポートし、 xUnit.net v3 (ネイティブ MTP)。 xUnit.net v3 MTP フィルター構文 (--filter-class、--filter-trait、--filter-query) の変換についても説明します。ランナーの有効化、CLI 引数の変換、Directory.Build.props と global.json の構成、CI/CD パイプラインの更新、MTP 拡張パッケージについて説明します。次の目的には使用しないでください: テスト フレームワーク間の移行 (MSTest/xUnit/NUnit)、xUnit.net v2 から v3 API の移行、MSTest バージョンのアップグレード (mitigate-mstest-* スキルを使用)、TFM アップグレード、または UWP/WinUI テスト プロジェクト。
