Fournit des chemins d'accès aux fichiers de référence spécifiques à la langue pour les compétences d'ANALYSE de test (qualité d'assertion, anti-modèles de test, analyse des écarts de test, détection d'odeur de test, marquage de test). Appelez cette compétence pour découvrir les fichiers d'extension disponibles (par exemple, dotnet.md pour .NET/MSTest/xUnit/NUnit/TUnit, python.md pour pytest/unittest, typescript.md pour Jest/Vitest/Mocha, java.md pour JUnit/TestNG, etc.). Ne pas utiliser directement : invoqué par l'agent d'audit de la qualité des tests et les compétences d'analyse polyglottes qui nécessitent des tables de recherche spécifiques au framework (marqueurs de test, API d'assertion, annotations de saut, modèles de sommeil, indicateurs d'invité mystère, marqueurs d'intégration, configuration/démontage, capacité de prise en charge des balises).
