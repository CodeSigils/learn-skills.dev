Предоставляет пути к справочным файлам для конкретного языка для навыков АНАЛИЗА тестов (качество утверждений, тест-анти-шаблоны, анализ пробелов в тестах, обнаружение тестовых запахов, тестовые теги). Используйте этот навык, чтобы обнаружить доступные файлы расширений (например, dotnet.md для .NET/MSTest/xUnit/NUnit/TUnit, python.md для pytest/unittest, typescript.md для Jest/Vitest/Mocha, java.md для JUnit/TestNG и т. д.). Не используйте напрямую — вызывается агентом-аудитором качества тестирования и навыками многоязычного анализа, которым необходимы таблицы поиска для конкретной платформы (тестовые маркеры, API-интерфейсы утверждений, пропуск аннотаций, шаблоны сна, индикаторы загадочных гостей, маркеры интеграции, настройка/демонтаж, возможность поддержки тегов).
