Proporciona rutas de archivo a archivos de referencia específicos del idioma para las habilidades de ANÁLISIS de la prueba (calidad de aserción, antipatrones de prueba, análisis de brechas de prueba, detección de olores de prueba, etiquetado de prueba). Llame a esta habilidad para descubrir archivos de extensión disponibles (por ejemplo, dotnet.md para .NET/MSTest/xUnit/NUnit/TUnit, python.md para pytest/unittest, typescript.md para Jest/Vitest/Mocha, java.md para JUnit/TestNG, etc.). No lo use directamente: invocado por el agente auditor de calidad de pruebas y habilidades de análisis políglota que necesitan tablas de búsqueda específicas del marco (marcadores de prueba, API de aserción, anotaciones de omisión, patrones de sueño, indicadores de invitados misteriosos, marcadores de integración, configuración/desmontaje, capacidad de soporte de etiquetas).
