Fornisce percorsi di file a file di riferimento specifici della lingua per le competenze di ANALISI del test (qualità dell'asserzione, test-anti-pattern, test-gap-analysis, test-smell-detection, test-tagging). Chiama questa abilità per scoprire i file di estensione disponibili (ad esempio, dotnet.md per .NET/MSTest/xUnit/NUnit/TUnit, python.md per pytest/unittest, typescript.md per Jest/Vitest/Mocha, java.md per JUnit/TestNG e così via). Non utilizzare direttamente: richiamato dall'agente del test-quality-auditor e dalle competenze di analisi poliglotta che necessitano di tabelle di ricerca specifiche del framework (marcatori di test, API di asserzione, annotazioni di salto, modelli di sonno, indicatori di ospiti misteriosi, marcatori di integrazione, configurazione/smontaggio, funzionalità di supporto dei tag).
