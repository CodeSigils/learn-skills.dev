正しいアーキテクチャで Blazor コンポーネント (.razor ファイル) を作成または確認します。用途: JavaScript 相互運用を含まない新しい Blazor コンポーネントの作成、パラメーターと EventCallback の実装、RenderFragment スロット、コンポーネント ライフサイクル (OnInitializedAsync、OnParametersSet)、非同期パターン、IAsyncDisposable、CancelToken、CSS 分離、コード ビハインド。次の用途には使用しないでください: 新しいプロジェクトの作成 (create-blazor-project を使用)、JavaScript 相互運用機能または Blazor からのブラウザー API の呼び出し (use-js-interop を使用)、フォームと検証 (collect-user-input を使用)、事前レンダリングの問題 (support-prerendering を使用)、HTTP データのフェッチ パターン (fetch-and-send-data を使用)、無関係なコンポーネント間の状態の調整 (coordine-components を使用)。
