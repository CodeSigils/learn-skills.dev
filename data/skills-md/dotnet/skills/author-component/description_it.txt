Creare o rivedere i componenti Blazor (file con estensione rasoio) con l'architettura corretta. UTILIZZARE PER: scrittura di nuovi componenti Blazor che NON implicano l'interoperabilità JavaScript, implementazione di parametri ed EventCallback, slot RenderFragment, ciclo di vita del componente (OnInitializedAsync, OnParametersSet), modelli asincroni, IAsyncDisposable, CancellationToken, isolamento CSS, code-behind. NON UTILIZZARE PER: creazione di nuovi progetti (usare create-blazor-project), interoperabilità JavaScript o chiamata di API del browser da Blazor (usare use-js-interop), moduli e convalida (usare collector-user-input), problemi di prerendering (usare support-prerendering), modelli di recupero di dati HTTP (usare fetch-and-send-data), stato di coordinamento tra componenti non correlati (usare coordinate-components).
