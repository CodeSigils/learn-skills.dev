Создайте или проверьте компоненты Blazor (файлы .razor) с правильной архитектурой. ИСПОЛЬЗОВАНИЕ ДЛЯ: написания новых компонентов Blazor, которые НЕ требуют взаимодействия с JavaScript, реализации параметров и EventCallback, слотов RenderFragment, жизненного цикла компонентов (OnInitializedAsync, OnParametersSet), асинхронных шаблонов, IAsyncDisposable, CancellationToken, изоляции CSS, выделенного кода. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: создания новых проектов (используйте create-blazor-project), взаимодействия с JavaScript или вызова API-интерфейсов браузера из Blazor (используйте-js-interop), форм и проверки (используйте сбор пользовательского ввода), проблем предварительного рендеринга (используйте поддержку предварительного рендеринга), шаблонов выборки данных HTTP (используйте выборку и отправку данных), координации состояния между несвязанными компонентами (используйте координатные компоненты).
