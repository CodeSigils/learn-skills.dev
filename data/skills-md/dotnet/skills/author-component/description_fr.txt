Créez ou révisez les composants Blazor (fichiers .razor) avec une architecture correcte. UTILISER POUR : écrire de nouveaux composants Blazor qui n'impliquent PAS l'interopérabilité JavaScript, implémenter des paramètres et EventCallback, les emplacements RenderFragment, le cycle de vie des composants (OnInitializedAsync, OnParametersSet), les modèles asynchrones, IAsyncDisposable, CancellationToken, l'isolation CSS, le code-behind. NE PAS UTILISER POUR : la création de nouveaux projets (utilisez create-blazor-project), l'interopérabilité JavaScript ou l'appel d'API de navigateur à partir de Blazor (utilisez use-js-interop), les formulaires et la validation (utilisez collect-user-input), les problèmes de pré-rendu (utilisez le support-prerendering), les modèles de récupération de données HTTP (utilisez fetch-and-send-data), la coordination de l'état entre des composants non liés (utilisez les composants de coordonnées).
