Cree o revise componentes Blazor (archivos .razor) con la arquitectura correcta. USO PARA: escribir nuevos componentes Blazor que NO involucran interoperabilidad de JavaScript, implementar parámetros y EventCallback, ranuras RenderFragment, ciclo de vida de componentes (OnInitializedAsync, OnParametersSet), patrones asíncronos, IAsyncDisposable, CancellationToken, aislamiento de CSS, código subyacente. NO LO UTILICE PARA: crear nuevos proyectos (use create-blazor-project), interoperabilidad de JavaScript o llamar a las API del navegador desde Blazor (use use-js-interop), formularios y validación (use recopilar-entrada de usuario), problemas de prerenderizado (use soporte-prerendering), patrones de recuperación de datos HTTP (use buscar y enviar datos), estado de coordinación entre componentes no relacionados (use componentes de coordenadas).
