올바른 아키텍처로 Blazor 구성 요소(.razor 파일)를 만들거나 검토합니다. 사용 대상: JavaScript 상호 운용성을 포함하지 않는 새 Blazor 구성 요소 작성, 매개 변수 및 EventCallback 구현, RenderFragment 슬롯, 구성 요소 수명 주기(OnInitializedAsync, OnParametersSet), 비동기 패턴, IAsyncDisposable, CancellationToken, CSS 격리, 코드 숨김. 사용하지 마십시오: 새 프로젝트 만들기(create-blazor-project 사용), JavaScript interop 또는 Blazor에서 브라우저 API 호출(use-js-interop 사용), 양식 및 유효성 검사(collect-user-input 사용), 사전 렌더링 문제(support-prerendering 사용), HTTP 데이터 가져오기 패턴(가져오기 및 보내기 데이터 사용), 관련되지 않은 구성 요소 간 상태 조정(좌표 구성 요소 사용).
