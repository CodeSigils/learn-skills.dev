Planen Sie komplexe Blazor-UI-Funktionen, indem Sie sie in fokussierte Komponenten zerlegen. VERWENDUNG FÜR: Erstellen einer komplexen Blazor-Seite mit mehreren Abschnitten, Planen der Komponentenzerlegung, Entwerfen eines Dashboards oder Layouts mit mehreren Abschnitten, Aufteilen einer großen UI-Funktion in zusammensetzbare Komponenten, Seiten mit Seitenleisten und Inhaltsbereichen, jede Seite mit mehr als drei unterschiedlichen visuellen Abschnitten oder mehreren interagierenden Unterfunktionen, Identifizieren von Eltern-Kind-Beziehungen und Datenfluss. NICHT VERWENDEN FÜR: das Erstellen neuer Blazor-Projekte oder -Apps von Grund auf (verwenden Sie „create-blazor-project“), das Implementieren einer einzelnen einzelnen Komponente (verwenden Sie „author-component“), das Schreiben von Komponentencode mit Parametern und EventCallback (verwenden Sie „author-component“) oder einfache Einzelkomponentenseiten.
