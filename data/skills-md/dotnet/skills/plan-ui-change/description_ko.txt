복잡한 Blazor UI 기능을 집중된 구성 요소로 분해하여 계획합니다. 용도: 여러 섹션이 포함된 복잡한 Blazor 페이지 구축, 구성 요소 분해 계획, 다중 섹션 대시보드 또는 레이아웃 디자인, 대규모 UI 기능을 구성 가능한 구성 요소, 사이드바 및 콘텐츠 패널이 있는 페이지, 3개 이상의 고유한 시각적 섹션 또는 상호 작용하는 여러 하위 기능이 있는 페이지, 상위-하위 관계 및 데이터 흐름 식별. 사용하지 마세요: 처음부터 새 Blazor 프로젝트 또는 앱 만들기(create-blazor-project 사용), 단일 개별 구성 요소 구현(작성자 구성 요소 사용), 매개 변수 및 EventCallback을 사용하여 구성 요소 코드 작성(작성자 구성 요소 사용) 또는 간단한 단일 구성 요소 페이지.
