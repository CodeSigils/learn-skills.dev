複雑な Blazor UI 機能を、焦点を絞ったコンポーネントに分解して計画します。用途: 複数のセクションを含む複雑な Blazor ページの構築、コンポーネントの分解の計画、複数セクションのダッシュボードまたはレイアウトのデザイン、大規模な UI 機能の構成可能なコンポーネントへの分割、サイドバーとコンテンツ パネルのあるページ、3 つ以上の個別のビジュアル セクションまたは相互作用する複数のサブ機能を持つページ、親子関係とデータ フローの識別。次の用途には使用しないでください: 新しい Blazor プロジェクトまたはアプリを最初から作成する (create-blazor-project を使用)、単一の個別コンポーネントを実装する (author-component を使用)、パラメーターと EventCallback を使用したコンポーネント コードを作成する (author-component を使用)、または単純な単一コンポーネント ページ。
