Исправлены целевые объекты MSBuild, которые создают файлы во время сборки, но эти файлы отсутствуют при компиляции или выводе. Активируйте только в контексте сборки MSBuild/.NET. ИСПОЛЬЗОВАНИЕ ДЛЯ: сгенерированные исходные файлы не компилируются (CS0246 для типа, который должен существовать), пользовательские задачи сборки, которые создают файлы, но они невидимы для последующих целей, globs, не захватывающие файлы, сгенерированные сборкой, поскольку они расширяются во время оценки до того, как выполнение создаст их, обеспечение очистки сгенерированных файлов с помощью цели Clean. Охватывает правильное время BeforeTargets (CoreCompile, BeforeBuild, AssignTargetPaths), добавление в группы элементов Compile/FileWrites с использованием $(IntermediateOutputPath) вместо жестко закодированных путей obj/. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: генераторов исходного кода C#, которые уже работают через конвейер Roslyn, генерации во время разработки T4, которая выполняется в Visual Studio, систем сборки, отличных от MSBuild. ПРИЗЫВАЕТ: никаких инструментов — чистое знание, умение.
