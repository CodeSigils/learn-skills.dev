Correggere le destinazioni MSBuild che generano file durante la compilazione ma tali file mancano dalla compilazione o dall'output. Attivare solo nel contesto di compilazione MSBuild/.NET. UTILIZZARE PER: file di origine generati non compilati (CS0246 per un tipo che dovrebbe esistere), attività di compilazione personalizzata che creano file ma sono invisibili alle destinazioni successive, glob che non catturano file generati dalla compilazione perché si espandono al momento della valutazione prima che l'esecuzione li crei, garantendo che i file generati vengano puliti dalla destinazione Pulisci. Copre i tempi corretti di BeforeTargets (CoreCompile, BeforeBuild, AssignTargetPaths), aggiungendo ai gruppi di elementi Compile/FileWrites, utilizzando $(IntermediateOutputPath) invece di percorsi obj/hardcoded. NON UTILIZZARE PER: generatori di codice sorgente C# che funzionano già tramite la pipeline Roslyn, generazione in fase di progettazione T4 eseguita in Visual Studio, sistemi di compilazione non MSBuild. INVOCA: nessuno strumento, pura abilità di conoscenza.
