MSBuild/.NET 빌드 컨텍스트에서만 활성화하세요. 사용 대상: 생성된 소스 파일이 컴파일되지 않음(존재해야 하는 유형의 경우 CS0246), 파일을 생성하지만 후속 대상에 표시되지 않는 사용자 지정 빌드 작업, 실행이 생성되기 전에 평가 시 확장되기 때문에 빌드 생성 파일을 캡처하지 않는 glob, 생성된 파일이 Clean 대상에 의해 정리되도록 보장합니다. 하드코딩된 obj/ 경로 대신 $(IntermediateOutputPath)를 사용하여 Compile/FileWrites 항목 그룹에 추가하여 올바른 BeforeTargets 타이밍(CoreCompile, BeforeBuild, AssignTargetPaths)을 다룹니다. 사용하지 마십시오: 이미 Roslyn 파이프라인을 통해 작동하는 C# 소스 생성기, Visual Studio에서 실행되는 T4 디자인 타임 생성, 비MSBuild 빌드 시스템. 호출: 도구 없음 — 순수한 지식 기술.
