C# 프로젝트에서 null 허용 참조 유형을 활성화하고 모든 경고를 체계적으로 해결합니다. 사용 대상: 기존 코드베이스에서 NRT 채택, 파일별 또는 프로젝트 전체 마이그레이션, CS8602/CS8618/CS86xx 경고 수정, null 허용 여부에 대한 API 주석 달기, null 허용 연산자 정리, 새로운 null 허용 주석으로 종속성 업그레이드. 사용하지 마십시오: 이미 경고 없이 완전히 마이그레이션된 프로젝트(감사 억제 제외), 이미 NRT가 활성화된 코드에서 몇 가지 null 허용 경고 수정, 수정하지 않고 경고 억제, C# 7.3 이하 프로젝트.
