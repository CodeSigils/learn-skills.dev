Abilita i tipi di riferimento nullable in un progetto C# e risolvi sistematicamente tutti gli avvisi. UTILIZZO PER: adozione di NRT in codebase esistenti, migrazione file per file o a livello di progetto, correzione degli avvisi CS8602/CS8618/CS86xx, annotazione delle API per l'annullamento dei valori, pulizia degli operatori che perdonano i valori null, aggiornamento delle dipendenze con nuove annotazioni nullable. NON UTILIZZARE PER: progetti già migrati completamente con zero avvisi (a meno che non si controllino le soppressioni), correzione di una manciata di avvisi nullable nel codice che ha già NRT abilitati, soppressione degli avvisi senza correggerli, C# 7.3 o progetti precedenti. RICHIAMA: script di scansione Get-NullableReadiness.ps1.
