C# プロジェクトで null 許容参照型を有効にし、すべての警告を体系的に解決します。用途: 既存のコードベースでの NRT の導入、ファイルごとまたはプロジェクト全体の移行、CS8602/CS8618/CS86xx 警告の修正、Null 可能性に対する API の注釈付け、Null 許容演算子のクリーンアップ、新しい Null 可能注釈による依存関係のアップグレード。次の場合には使用しないでください: 警告ゼロで既に完全に移行されているプロジェクト (監査抑制を除く)、NRT が既に有効になっているコード内の少数の null 許容警告を修正している場合、警告を修正せずに抑制している場合、C# 7.3 以前のプロジェクト。呼び出し: Get-NullableReadiness.ps1 スキャナー スクリプト。
