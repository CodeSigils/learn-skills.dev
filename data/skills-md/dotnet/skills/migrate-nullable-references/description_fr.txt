Activez les types de référence nullables dans un projet C# et résolvez systématiquement tous les avertissements. UTILISER POUR : adoption de NRT dans les bases de code existantes, migration fichier par fichier ou à l'échelle du projet, correction des avertissements CS8602/CS8618/CS86xx, annotation des API pour la nullité, nettoyage des opérateurs pardonnant les valeurs nulles, mise à niveau des dépendances avec de nouvelles annotations nullables. NE PAS UTILISER POUR : les projets déjà entièrement migrés avec zéro avertissement (sauf suppressions d'audit), la correction d'une poignée d'avertissements nullables dans un code pour lequel les NRT sont déjà activés, la suppression des avertissements sans les corriger, les projets C# 7.3 ou antérieurs. INVOKES : script du scanner Get-NullableReadiness.ps1.
