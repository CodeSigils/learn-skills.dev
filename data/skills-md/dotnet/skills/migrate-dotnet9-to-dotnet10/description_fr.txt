Migrez un projet ou une solution .NET 9 vers .NET 10 et résolvez toutes les modifications avec rupture. UTILISER POUR : mettre à niveau TargetFramework de net9.0 vers net10.0, corriger les erreurs de build après la mise à jour du SDK .NET 10, résoudre les changements de source et de comportement dans .NET 10 / C# 14 / ASP.NET Core 10 / EF Core 10, mettre à jour les Dockerfiles pour les images de base Debian vers Ubuntu, résoudre les avertissements d'obsolescence (SYSLIB0058-SYSLIB0062), s'adapter aux modifications du SDK/NuGet (NU1510, PrunePackageReference), migrer System.Linq.Async vers AsyncEnumerable intégré, corriger les modifications de l'API OpenApi v2, les renommages de cryptographie et les modifications du compilateur C# 14 (mot-clé de champ, mot-clé d'extension, surcharges de span). NE PAS UTILISER POUR : les migrations .NET Framework, la mise à niveau à partir de .NET 8 ou une version antérieure (utilisez d'abord migrate-dotnet8-to-dotnet9), les nouveaux projets .NET 10 ou la modernisation cosmétique. RÉFÉRENCES DE CHARGEMENT : csharp-compiler, core-libraries, sdk-msbuild (toujours) ; aspnet-core, efcore, cryptographie, hébergement d'extensions, mise en réseau de sérialisation, winforms-wpf, conteneurs-interop (sélectif).
