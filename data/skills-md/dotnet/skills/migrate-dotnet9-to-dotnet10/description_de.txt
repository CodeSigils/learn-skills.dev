Migrieren Sie ein .NET 9-Projekt oder eine .NET 9-Lösung auf .NET 10 und beheben Sie alle wichtigen Änderungen. VERWENDUNG FÜR: Upgrade von TargetFramework von net9.0 auf net10.0, Behebung von Build-Fehlern nach der Aktualisierung des .NET 10 SDK, Behebung von Quell- und Verhaltensänderungen in .NET 10 / C# 14 / ASP.NET Core 10 / EF Core 10, Aktualisierung von Dockerfiles für Debian-zu-Ubuntu-Basisimages, Behebung von Veraltungswarnungen (SYSLIB0058-SYSLIB0062), Anpassung an SDK/NuGet-Änderungen (NU1510, PrunePackageReference), Migration von System.Linq.Async auf integriertes AsyncEnumerable, Behebung von OpenApi v2-API-Änderungen, Kryptografie-Umbenennungen und C# 14-Compiler-Änderungen (Feldschlüsselwort, Erweiterungsschlüsselwort, Span-Überladungen). NICHT VERWENDEN FÜR: .NET Framework-Migrationen, Upgrades von .NET 8 oder früher (verwenden Sie zuerst migrate-dotnet8-to-dotnet9), Greenfield-.NET 10-Projekte oder kosmetische Modernisierungen. LÄDT REFERENZEN: csharp-compiler, core-libraries, sdk-msbuild (immer); Aspnet-Core, Efcore, Kryptographie, Erweiterungs-Hosting, Serialisierungsnetzwerk, Winforms-WPF, Container-Interop (selektiv).
