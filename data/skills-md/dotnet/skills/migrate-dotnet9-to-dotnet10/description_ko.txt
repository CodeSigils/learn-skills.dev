.NET 9 프로젝트 또는 솔루션을 .NET 10으로 마이그레이션하고 모든 주요 변경 사항을 해결합니다. 사용 대상: net9.0에서 net10.0으로 TargetFramework 업그레이드, .NET 10 SDK 업데이트 후 빌드 오류 수정, .NET 10/C# 14/ASP.NET Core 10/EF Core 10의 소스 및 동작 변경 사항 해결, Debian-Ubuntu 기본 이미지용 Dockerfile 업데이트, 폐기 경고 해결(SYSLIB0058-SYSLIB0062), 다음에 적응 SDK/NuGet 변경 사항(NU1510, PrunePackageReference), System.Linq.Async를 기본 제공 AsyncEnumerable로 마이그레이션, OpenApi v2 API 변경 사항 수정, 암호화 이름 변경 및 C# 14 컴파일러 변경 사항(필드 키워드, 확장 키워드, 범위 오버로드). 사용하지 마십시오: .NET Framework 마이그레이션, .NET 8 이하에서 업그레이드(먼저 migration-dotnet8-to-dotnet9 사용), 그린필드 .NET 10 프로젝트 또는 외관상 현대화. 로드 참조: csharp-compiler, core-libraries, sdk-msbuild(항상); aspnet-core, efcore, 암호화, 확장 호스팅, 직렬화 네트워킹, winforms-wpf, 컨테이너 상호 운용성(선택적).
