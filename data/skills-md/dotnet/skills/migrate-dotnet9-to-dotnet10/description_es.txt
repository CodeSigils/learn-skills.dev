Migre un proyecto o solución .NET 9 a .NET 10 y resuelva todos los cambios importantes. UTILIZAR PARA: actualizar TargetFramework de net9.0 a net10.0, corregir errores de compilación después de actualizar el SDK de .NET 10, resolver cambios de código fuente y de comportamiento en .NET 10 / C# 14 / ASP.NET Core 10 / EF Core 10, actualizar Dockerfiles para imágenes base de Debian a Ubuntu, resolver advertencias de obsolescencia (SYSLIB0058-SYSLIB0062), adaptación a los cambios de SDK/NuGet (NU1510, PrunePackageReference), migración de System.Linq.Async al AsyncEnumerable integrado, corrección de cambios de API de OpenApi v2, cambios de nombre de criptografía y cambios del compilador de C# 14 (palabra clave de campo, palabra clave de extensión, sobrecargas de intervalo). NO LO UTILICE PARA: migraciones de .NET Framework, actualizaciones desde .NET 8 o versiones anteriores (use primero migrar-dotnet8-a-dotnet9), proyectos totalmente nuevos de .NET 10 o modernizaciones cosméticas. CARGA REFERENCIAS: csharp-compiler, core-libraries, sdk-msbuild (siempre); aspnet-core, efcore, criptografía, alojamiento de extensiones, redes de serialización, winforms-wpf, interoperabilidad de contenedores (selectiva).
