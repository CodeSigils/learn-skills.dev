將 .NET 9 專案或解決方案移轉到 .NET 10 並解決所有重大變更。用途：將 TargetFramework 從 net9.0 升級到 net10.0、更新 .NET 10 SDK 後修復建置錯誤、解決 .NET 10 / C# 14 / ASP.NET Core 10 / EF Core 10 中的來源和行為變更、更新 Debian 到 Ubuntu 基礎映像(SYSLIB0058-SYSLIB0062)、適應SDK/NuGet 更改（NU1510、PrunePackageReference）、將 System.Linq.Async 遷移到內建 AsyncEnumerable、修復 OpenApi v2 API 更改、加密重命名和 C# 14 編譯器（重載）。請勿用於：.NET Framework 遷移、從 .NET 8 或更早版本升級（先使用 migrate-dotnet8-to-dotnet9）、新建 .NET 10 專案或外觀現代化。載入參考：csharp-compiler、core-libraries、sdk-msbuild（始終）；aspnet-core、efcore、加密、擴展託管、序列化網路、winforms-wpf、容器互通（選擇性）。
