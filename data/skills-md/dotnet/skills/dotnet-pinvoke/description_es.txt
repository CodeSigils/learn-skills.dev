Llame correctamente a bibliotecas nativas (C/C++) desde .NET usando P/Invoke y LibraryImport. Cubre firmas de funciones, clasificación de cadenas, duración de la memoria, SafeHandle y patrones multiplataforma. USO PARA: escribir nuevas declaraciones P/Invoke o LibraryImport, revisar o depurar código de interoperabilidad nativo existente, empaquetar una biblioteca C o C++ para usar en .NET, diagnosticar fallas, pérdidas de memoria o corrupción en el límite administrado/nativo. NO LO UTILICE PARA: interoperabilidad COM, ensamblados de modo mixto C++/CLI o código administrado puro sin dependencias nativas.
