Rufen Sie native (C/C++) Bibliotheken aus .NET mit P/Invoke und LibraryImport korrekt auf. Behandelt Funktionssignaturen, String-Marshalling, Speicherlebensdauer, SafeHandle und plattformübergreifende Muster. VERWENDUNG FÜR: Schreiben neuer P/Invoke- oder LibraryImport-Deklarationen, Überprüfen oder Debuggen von vorhandenem nativem Interop-Code, Umschließen einer C- oder C++-Bibliothek zur Verwendung in .NET, Diagnostizieren von Abstürzen, Speicherlecks oder Beschädigungen an der verwalteten/nativen Grenze. NICHT VERWENDEN FÜR: COM-Interop, C++/CLI-Assemblys im gemischten Modus oder rein verwalteten Code ohne native Abhängigkeiten.
