Appelez correctement les bibliothèques natives (C/C++) à partir de .NET à l’aide de P/Invoke et LibraryImport. Couvre les signatures de fonctions, le tri des chaînes, la durée de vie de la mémoire, SafeHandle et les modèles multiplateformes. UTILISER POUR : écrire de nouvelles déclarations P/Invoke ou LibraryImport, réviser ou déboguer le code d'interopérabilité natif existant, encapsuler une bibliothèque C ou C++ pour une utilisation dans .NET, diagnostiquer les plantages, les fuites de mémoire ou la corruption à la limite gérée/native. NE PAS UTILISER POUR : COM Interop, les assemblys en mode mixte C++/CLI ou le code managé pur sans dépendances natives.
