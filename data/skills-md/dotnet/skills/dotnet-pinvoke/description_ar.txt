قم باستدعاء المكتبات الأصلية (C/C++) بشكل صحيح من .NET باستخدام P/Invoce وLibraryImport. يغطي توقيعات الوظائف، وتنظيم السلسلة، وعمر الذاكرة، وSafeHandle، والأنماط عبر الأنظمة الأساسية. الاستخدام من أجل: كتابة إعلانات P/Invoc أو LibraryImport جديدة، أو مراجعة أو تصحيح كود التشغيل المتداخل الأصلي الموجود، أو تغليف مكتبة C أو C++ لاستخدامها في .NET، أو تشخيص الأعطال، أو تسرب الذاكرة، أو الفساد عند الحدود المُدارة/الأصلية. لا تستخدمه من أجل: التشغيل المتداخل لـ COM، أو تجميعات الوضع المختلط C++/CLI، أو التعليمات البرمجية المُدارة الخالصة بدون تبعيات أصلية.
