دليل لاستخدام MSBuild Server لتحسين أداء بناء CLI. التنشيط فقط في سياق بناء MSBuild/.NET. يتم التنشيط عندما يبلغ المطورون عن عمليات إنشاء تزايدية بطيئة من سطر الأوامر، أو عندما تكون إصدارات CLI أبطأ بشكل ملحوظ من إصدارات IDE. يغطي MSBUILDUSESERVER=متغير بيئة واحد للتخزين المؤقت المستمر المعتمد على الخادم. لا تقم بالتنشيط للإصدارات المستندة إلى IDE (يستخدم Visual Studio بالفعل عملية طويلة الأمد).
