Руководство по использованию MSBuild Server для повышения производительности сборки через интерфейс командной строки. Активируйте только в контексте сборки MSBuild/.NET. Активируйте, когда разработчики сообщают о медленных инкрементных сборках из командной строки или когда сборки CLI заметно медленнее, чем сборки IDE. Охватывает переменную среды MSBUILDUSESERVER=1 для постоянного кэширования на сервере. Не активируйте для сборок на основе IDE (Visual Studio уже использует долгоживущий процесс).
