Guide d'utilisation de MSBuild Server pour améliorer les performances de build CLI. Activez uniquement dans le contexte de build MSBuild/.NET. Activez-le lorsque les développeurs signalent des builds incrémentielles lentes à partir de la ligne de commande, ou lorsque les builds CLI sont sensiblement plus lents que les builds IDE. Couvre la variable d'environnement MSBUILDUSESERVER=1 pour la mise en cache persistante basée sur le serveur. Ne pas activer pour les builds basées sur l'IDE (Visual Studio utilise déjà un processus de longue durée).
