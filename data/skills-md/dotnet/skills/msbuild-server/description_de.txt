Leitfaden zur Verwendung von MSBuild Server zur Verbesserung der CLI-Build-Leistung. Nur im MSBuild/.NET-Buildkontext aktivieren. Aktivieren Sie diese Option, wenn Entwickler langsame inkrementelle Builds über die Befehlszeile melden oder wenn CLI-Builds merklich langsamer sind als IDE-Builds. Deckt die Umgebungsvariable MSBUILDUSESERVER=1 für dauerhaftes serverbasiertes Caching ab. Nicht für IDE-basierte Builds aktivieren (Visual Studio verwendet bereits einen langlebigen Prozess).
