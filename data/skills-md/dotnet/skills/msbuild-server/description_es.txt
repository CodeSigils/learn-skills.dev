Guía para usar MSBuild Server para mejorar el rendimiento de la compilación CLI. Activar solo en el contexto de compilación de MSBuild/.NET. Actívelo cuando los desarrolladores informen compilaciones incrementales lentas desde la línea de comandos, o cuando las compilaciones CLI sean notablemente más lentas que las compilaciones IDE. Cubre la variable de entorno MSBUILDUSESERVER=1 para el almacenamiento en caché persistente basado en servidor. No lo active para compilaciones basadas en IDE (Visual Studio ya utiliza un proceso de larga duración).
