Guida per l'utilizzo di MSBuild Server per migliorare le prestazioni della compilazione della CLI. Attivare solo nel contesto di compilazione MSBuild/.NET. Attiva quando gli sviluppatori segnalano build incrementali lente dalla riga di comando o quando le build CLI sono notevolmente più lente delle build IDE. Copre MSBUILDUSESERVER=1 variabile di ambiente per la memorizzazione nella cache persistente basata su server. Non attivare per build basate su IDE (Visual Studio utilizza già un processo di lunga durata).
