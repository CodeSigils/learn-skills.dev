在 .NET MAUI 应用程序中实现基于 Shell 的导航的指南。涵盖 AppShell 设置、视觉层次结构（FlyoutItem、TabBar、Tab、ShellContent）、使用 GoToAsync 的基于 URI 的导航、路由注册、查询参数、后退导航、浮出控件和选项卡配置、导航事件和导航防护。使用场合：设置 Shell 导航、添加选项卡或弹出菜单、使用 GoToAsync 在页面之间导航、在页面之间传递参数、注册路由、自定义后退按钮行为或使用确认对话框保护导航。请勿用于：来自外部 URL 的深度链接（请参阅 .NET MAUI 深度链接文档）、页面上的数据绑定（使用 maui-data-binding）、依赖项注入设置（使用 maui-dependency-injection）或不使用 Shell 的仅 NavigationPage 应用程序。
