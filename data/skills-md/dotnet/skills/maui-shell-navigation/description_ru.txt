Руководство по реализации навигации на основе оболочки в приложениях .NET MAUI. Охватывает настройку AppShell, визуальную иерархию (FlyoutItem, TabBar, Tab, ShellContent), навигацию на основе URI с GoToAsync, регистрацию маршрута, параметры запроса, обратную навигацию, настройку всплывающих окон и вкладок, события навигации и средства защиты навигации. Используйте при настройке навигации оболочки, добавлении вкладок или всплывающих меню, навигации между страницами с помощью GoToAsync, передаче параметров между страницами, регистрации маршрутов, настройке поведения кнопки «Назад» или защите навигации с помощью диалоговых окон подтверждения. Не используйте для: глубоких ссылок с внешних URL-адресов (см. документацию по глубоким ссылкам .NET MAUI), привязки данных на страницах (используйте привязку данных maui), настройки внедрения зависимостей (используйте внедрение maui-зависимости) или приложений только для NavigationPage, которые не используют Shell.
