Guía para implementar la navegación basada en Shell en aplicaciones .NET MAUI. Cubre la configuración de AppShell, la jerarquía visual (FlyoutItem, TabBar, Tab, ShellContent), la navegación basada en URI con GoToAsync, el registro de rutas, los parámetros de consulta, la navegación hacia atrás, la configuración de menús flotantes y pestañas, eventos de navegación y protectores de navegación. Úselo cuando: configure la navegación del Shell, agregue pestañas o menús desplegables, navegue entre páginas con GoToAsync, pase parámetros entre páginas, registre rutas, personalice el comportamiento del botón Atrás o proteja la navegación con cuadros de diálogo de confirmación. No lo use para: enlaces profundos desde URL externas (consulte la documentación de enlaces profundos de .NET MAUI), enlace de datos en páginas (use maui-data-binding), configuración de inyección de dependencia (use maui-dependency-injection) o aplicaciones solo de NavigationPage que no usan Shell.
