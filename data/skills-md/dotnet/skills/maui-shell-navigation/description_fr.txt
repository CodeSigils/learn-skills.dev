Guide d'implémentation de la navigation basée sur Shell dans les applications .NET MAUI. Couvre la configuration d'AppShell, la hiérarchie visuelle (FlyoutItem, TabBar, Tab, ShellContent), la navigation basée sur l'URI avec GoToAsync, l'enregistrement d'itinéraire, les paramètres de requête, la navigation arrière, la configuration des flyouts et des onglets, les événements de navigation et les gardes de navigation. À utiliser lors de : la configuration de la navigation Shell, l'ajout d'onglets ou de menus déroulants, la navigation entre les pages avec GoToAsync, la transmission de paramètres entre les pages, l'enregistrement d'itinéraires, la personnalisation du comportement du bouton de retour ou la protection de la navigation avec des boîtes de dialogue de confirmation. Ne pas utiliser pour : les liens profonds à partir d'URL externes (voir la documentation sur les liens profonds .NET MAUI), la liaison de données sur les pages (utilisez maui-data-binding), la configuration de l'injection de dépendances (utilisez maui-dependency-injection) ou les applications NavigationPage uniquement qui n'utilisent pas Shell.
