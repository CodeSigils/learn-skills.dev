دليل لتنفيذ التنقل المستند إلى Shell في تطبيقات .NET MAUI. يغطي إعداد AppShell، والتسلسل الهرمي المرئي (FlyoutItem، وTabBar، وTab، وShellContent)، والتنقل المستند إلى URI مع GoToAsync، وتسجيل المسار، ومعلمات الاستعلام، والتنقل الخلفي، وتكوين القائمة المنبثقة وعلامة التبويب، وأحداث التنقل، وحراس التنقل. يُستخدم عندما: إعداد التنقل في Shell، أو إضافة علامات التبويب أو القوائم المنبثقة، أو التنقل بين الصفحات باستخدام GoToAsync، أو تمرير المعلمات بين الصفحات، أو تسجيل المسارات، أو تخصيص سلوك زر الرجوع، أو حماية التنقل باستخدام مربعات حوار التأكيد. لا تستخدمه من أجل: الارتباط العميق من عناوين URL الخارجية (راجع وثائق الارتباط العميق .NET MAUI)، أو ربط البيانات على الصفحات (استخدم ربط بيانات maui)، أو إعداد حقن التبعية (استخدم حقن تبعية maui)، أو تطبيقات NavigationPage فقط التي لا تستخدم Shell.
