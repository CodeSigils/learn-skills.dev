.NET MAUI 앱에서 셸 기반 탐색을 구현하기 위한 가이드입니다. AppShell 설정, 시각적 계층 구조(FlyoutItem, TabBar, Tab, ShellContent), GoToAsync를 사용한 URI 기반 탐색, 경로 등록, 쿼리 매개 변수, 뒤로 탐색, 플라이아웃 및 탭 구성, 탐색 이벤트, 탐색 가드를 다룹니다. 사용 시기: 셸 탐색 설정, 탭 또는 플라이아웃 메뉴 추가, GoToAsync를 사용하여 페이지 간 탐색, 페이지 간 매개변수 전달, 경로 등록, 뒤로 버튼 동작 사용자 지정 또는 확인 대화 상자를 통한 탐색 보호. 외부 URL의 딥 링크(.NET MAUI 딥 링크 설명서 참조), 페이지의 데이터 바인딩(maui-data-bind 사용), 종속성 주입 설정(maui-dependent-injection 사용) 또는 Shell을 사용하지 않는 NavigationPage 전용 앱에는 사용하지 마세요.
