在 .NET MAUI 應用程式中實作基於 Shell 的導航的指南。涵蓋 AppShell 設定、視覺層次結構（FlyoutItem、TabBar、Tab、ShellContent）、使用 GoToAsync 的 URI 為基礎的導航、路由註冊、查詢參數、後退導航、浮出控制項和標籤配置、導航事件和導航防護。使用場合：設定 Shell 導覽、新增標籤或彈出式功能表、使用 GoToAsync 在頁面之間導覽、在頁面之間傳遞參數、註冊路由、自訂後退按鈕行為或使用確認對話方塊保護導覽。請勿用於：來自外部 URL 的深度連結（請參閱 .NET MAUI 深度連結文件）、頁面上的資料綁定（使用 maui-data-binding）、依賴項注入設定（使用 maui-dependency-injection）或不使用 Shell 的僅 NavigationPage 應用程式。
