Guide d’interprétation de l’heure ResolveProjectReferences dans les résumés de performances MSBuild. Activez uniquement dans le contexte de build MSBuild/.NET. Activez-le lorsque ResolveProjectReferences apparaît comme la cible la plus chère et que les développeurs tentent de l'optimiser directement. Explique que le temps signalé inclut le temps d’attente pour les builds de projets dépendants et est trompeur. Guide les utilisateurs à se concentrer plutôt sur le temps libre des tâches. Ne pas activer pour les performances générales de build – utilisez plutôt build-perf-diagnostics.
