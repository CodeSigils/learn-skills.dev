Modelli canonici per la scrittura di destinazioni MSBuild personalizzate. Attivare solo nel contesto di compilazione MSBuild/.NET. UTILIZZARE PER: diagnosi e correzione di anti-pattern di creazione di target personalizzati, revisione delle definizioni di target MSBuild per verificarne la correttezza, diagnosi di catene di target SDK non funzionanti tra file (ad esempio, Directory.Build.targets ridefinisce silenziosamente le destinazioni SDK), correzione di target che sostituiscono CompileDependsOn invece di estenderlo con $(CompileDependsOn), correzione di target di query che restituiscono risultati obsoleti a causa di un uso improprio di Output e Restituzioni, correzione di input/output mancanti che causano inutili ricostruisce, correggendo la registrazione FileWrite mancante. Copre DependsOnTargets vs BeforeTargets vs AfterTargets, il pattern a tre livelli Build→CoreBuild, l'aggancio alla pipeline di build, il pattern di estensione della catena $(XxxDependsOn). NON UTILIZZARE PER: ottimizzazione della build incrementale (usare incremental-build), parallelizzazione (usare il parallelismo di build), anti-pattern generali (usare msbuild-antipatterns), sistemi di build non MSBuild.
