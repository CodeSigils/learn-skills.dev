Канонические шаблоны для написания пользовательских целей MSBuild. Активируйте только в контексте сборки MSBuild/.NET. ИСПОЛЬЗОВАНИЕ ДЛЯ: диагностики и исправления антишаблонов разработки пользовательских целевых объектов, проверки правильности определений целевых объектов MSBuild, диагностики нарушенных целевых цепочек SDK в файлах (например, Directory.Build.targets, автоматически переопределяющих целевые объекты SDK), исправления целевых объектов, которые заменяют CompileDependsOn вместо расширения его с помощью $(CompileDependsOn), исправления целевых объектов запроса, которые возвращают устаревшие результаты из-за неправильного использования Outputs vs Returns, исправление отсутствующих входов/выходов, приводящих к ненужным перестройкам, исправление отсутствия регистрации FileWrites. Охватывает DependsOnTargets, BeforeTargets и AfterTargets, трехуровневый шаблон Build→CoreBuild, подключение к конвейеру сборки, шаблон расширения цепочки $(XxxDependsOn). НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: инкрементной настройки сборки (используйте инкрементальную сборку), распараллеливания (используйте параллелизм сборки), общих антишаблонов (используйте msbuild-antipatterns), систем сборки, отличных от MSBuild.
