カスタム MSBuild ターゲットを作成するための正規パターン。 MSBuild/.NET ビルド コンテキストでのみアクティブ化します。用途: カスタム ターゲット オーサリングのアンチパターンの診断と修正、MSBuild ターゲット定義が正しいかどうかのレビュー、ファイル全体にわたる壊れた SDK ターゲット チェーンの診断 (例: Directory.Build.targets が SDK ターゲットをサイレントに再定義する)、$(CompileDependsOn) で拡張する代わりに CompileDependsOn を置き換えるターゲットの修正、出力と戻り値の誤用により古い結果を返すクエリ ターゲットの修正、欠落の修正入力/出力により不必要な再構築が発生し、欠落している FileWrites 登録が修正されます。 dependsOnTargets 対 BeforeTargets 対 AfterTargets、Build→CoreBuild の 3 レベル パターン、ビルド パイプラインへのフック、$(XxxDependsOn) チェーン拡張パターンをカバーします。次の用途には使用しないでください: インクリメンタル ビルド チューニング (incremental-build を使用)、並列化 (build-Parallelism を使用)、一般的なアンチパターン (msbuild-antipatterns を使用)、MSBuild 以外のビルド システム。
