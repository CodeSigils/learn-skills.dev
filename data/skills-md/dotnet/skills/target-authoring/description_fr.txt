Modèles canoniques pour l’écriture de cibles MSBuild personnalisées. Activez uniquement dans le contexte de build MSBuild/.NET. UTILISER POUR : diagnostiquer et corriger les anti-modèles de création de cibles personnalisées, vérifier l'exactitude des définitions de cibles MSBuild, diagnostiquer les chaînes cibles SDK brisées dans les fichiers (par exemple, Directory.Build.targets redéfinissant silencieusement les cibles SDK), corriger les cibles qui remplacent CompileDependsOn au lieu de l'étendre avec $(CompileDependsOn), corriger les cibles de requête qui renvoient des résultats obsolètes en raison d'une mauvaise utilisation de Outputs vs Returns, corriger les entrées/sorties manquantes provoquant reconstructions inutiles, correction de l'enregistrement FileWrites manquant. Couvre DependsOnTargets vs BeforeTargets vs AfterTargets, le modèle à trois niveaux Build → CoreBuild, connecté au pipeline de construction, le modèle d'extension de chaîne $ (XxxDependsOn). NE PAS UTILISER POUR : le réglage de construction incrémentiel (utiliser la construction incrémentielle), la parallélisation (utiliser le parallélisme de construction), les anti-modèles généraux (utiliser msbuild-antipatterns), les systèmes de construction non MSBuild.
