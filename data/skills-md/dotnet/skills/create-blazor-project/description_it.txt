Creare una nuova applicazione Web o un sito Web ASP.NET Core usando Blazor. UTILIZZARE PER: creazione di una nuova app Web Blazor, impalcatura di un nuovo progetto Web, avvio di un nuovo sito Web, scelta delle modalità di rendering (SSR statico, server interattivo, WebAssembly interattivo, automatico), esecuzione di dotnet new Blazor con le opzioni corrette, impostazione della struttura iniziale del progetto. NON UTILIZZARE PER: aggiungere funzionalità a progetti esistenti, modificare il modo in cui viene eseguito il rendering di un'app esistente o creare componenti (usa autore-componente).
