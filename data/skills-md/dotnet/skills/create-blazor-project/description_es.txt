Cree una nueva aplicación web o sitio web ASP.NET Core mediante Blazor. UTILIZAR PARA: crear una nueva aplicación web Blazor, desarrollar un nuevo proyecto web, iniciar un nuevo sitio web, elegir modos de renderizado (Static SSR, Interactive Server, Interactive WebAssembly, Auto), ejecutar dotnet new blazor con las opciones correctas, configurar la estructura inicial del proyecto. NO LO UTILICE PARA: agregar funciones a proyectos existentes, cambiar la forma en que se representa una aplicación existente o crear componentes (use autor-componente).
