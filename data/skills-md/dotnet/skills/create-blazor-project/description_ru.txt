Создайте новое веб-приложение или веб-сайт ASP.NET Core с помощью Blazor. ИСПОЛЬЗОВАНИЕ ДЛЯ: создания нового веб-приложения Blazor, создания нового веб-проекта, запуска нового веб-сайта, выбора режимов рендеринга (статический SSR, интерактивный сервер, интерактивная веб-сборка, автоматически), запуска dotnet new blazor с правильными параметрами, настройки исходной структуры проекта. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: добавления функций в существующие проекты, изменения способа рендеринга существующего приложения или разработки компонентов (используйте авторский компонент).
