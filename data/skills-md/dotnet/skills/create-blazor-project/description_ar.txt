قم بإنشاء تطبيق ويب ASP.NET Core جديد أو موقع ويب جديد باستخدام Blazor. الاستخدام من أجل: إنشاء تطبيق ويب Blazor جديد، ودعم مشروع ويب جديد، وبدء موقع ويب جديد، واختيار أوضاع العرض (Static SSR، Interactive Server، Interactive WebAssembly، Auto)، وتشغيل dotnet new blazor بالخيارات الصحيحة، وإعداد هيكل المشروع الأولي. لا تستخدم من أجل: إضافة ميزات إلى المشاريع الحالية، أو تغيير كيفية عرض تطبيق موجود، أو تأليف المكون (استخدم مكون المؤلف).
