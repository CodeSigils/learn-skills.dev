Blazor を使用して、新しい ASP.NET Core Web アプリケーションまたは Web サイトを作成します。用途: 新しい Blazor Web アプリの作成、新しい Web プロジェクトのスキャフォールディング、新しい Web サイトの開始、レンダリング モード (静的 SSR、対話型サーバー、対話型 WebAssembly、自動) の選択、適切なオプションを使用した dotnet 新しい blazor の実行、初期プロジェクト構造のセットアップ。次の目的には使用しないでください: 既存のプロジェクトへの機能の追加、既存のアプリのレンダリング方法の変更、またはコンポーネントのオーサリング (author-component を使用)。
