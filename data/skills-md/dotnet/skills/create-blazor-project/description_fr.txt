Créez une nouvelle application Web ou un site Web ASP.NET Core à l'aide de Blazor. UTILISER POUR : créer une nouvelle application Web Blazor, échafauder un nouveau projet Web, démarrer un nouveau site Web, choisir les modes de rendu (Static SSR, Interactive Server, Interactive WebAssembly, Auto), exécuter dotnet new blazor avec les bonnes options, configurer la structure initiale du projet. NE PAS UTILISER POUR : l'ajout de fonctionnalités à des projets existants, la modification du rendu d'une application existante ou la création de composants (utilisez le composant auteur).
