Conseils pour les liaisons de données .NET MAUI XAML et C# : liaisons compilées, INotifyPropertyChanged/ObservableObject, convertisseurs de valeurs, modes de liaison, liaisons multiples, liaisons relatives, solutions de secours et meilleures pratiques MVVM. UTILISER POUR : configuration de liaisons compilées avec x:DataType, implémentation de INotifyPropertyChanged ou CommunityToolkit ObservableObject, création de IValueConverter / IMultiValueConverter, choix des modes de liaison, configuration de BindingContext, liaisons relatives, solutions de secours de liaison, StringFormat, code-behind SetBinding avec lambdas et application des avertissements XC0022/XC0025. NE PAS UTILISER POUR : les modèles et mises en page d'éléments CollectionView (utilisez maui-collectionview), la transmission de données de navigation Shell (utilisez maui-shell-navigation), l'injection de dépendances (utilisez maui-dependency-injection) ou les animations déclenchées par des modifications de propriétés (utilisez les API d'animation .NET MAUI).
