.NET MAUI XAML 및 C# 데이터 바인딩에 대한 지침 — 컴파일된 바인딩, INotifyPropertyChanged / ObservableObject, 값 변환기, 바인딩 모드, 다중 바인딩, 상대 바인딩, 대체 및 MVVM 모범 사례. 사용 대상: x:DataType을 사용하여 컴파일된 바인딩 설정, INotifyPropertyChanged 또는 CommunityToolkit ObservableObject 구현, IValueConverter/IMultiValueConverter 생성, 바인딩 모드 선택, BindingContext 구성, 상대 바인딩, 바인딩 폴백, StringFormat, 람다를 사용한 코드 숨김 SetBinding 및 XC0022/XC0025 경고 적용. 사용하지 마십시오: CollectionView 항목 템플릿 및 레이아웃(maui-collectionview 사용), 셸 탐색 데이터 전달(maui-shell-navigation 사용), 종속성 주입(maui-dependent-injection 사용) 또는 속성 변경으로 트리거되는 애니메이션(.NET MAUI 애니메이션 API 사용).
