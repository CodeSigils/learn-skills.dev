إرشادات لروابط بيانات .NET MAUI XAML وC# - الارتباطات المجمعة، وINotifyPropertyChanged / ObservableObject، ومحولات القيمة، وأوضاع الربط، والارتباطات المتعددة، والارتباطات النسبية، والاحتياطيات، وأفضل ممارسات MVVM. الاستخدام لـ: إعداد الارتباطات المترجمة باستخدام x:DataType، وتنفيذ INotifyPropertyChanged أو CommunityToolkit ObservableObject، وإنشاء IValueConverter / IMultiValueConverter، واختيار أوضاع الربط، وتكوين BindingContext، والروابط النسبية، والارتباطات الاحتياطية، وStringFormat، والتعليمة البرمجية الخلفية SetBinding مع lambdas، وفرض XC0022/XC0025 تحذيرات. لا تستخدمه من أجل: قوالب عناصر CollectionView وتخطيطاتها (استخدم maui-collectionview)، أو تمرير بيانات تنقل Shell (استخدم maui-shell-navigation)، أو حقن التبعية (استخدم حقن تبعية maui)، أو الرسوم المتحركة التي يتم تشغيلها بواسطة تغييرات الخصائص (استخدم واجهات برمجة تطبيقات الرسوم المتحركة .NET MAUI).
