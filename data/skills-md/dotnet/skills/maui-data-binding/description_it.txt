Linee guida per associazioni dati .NET MAUI XAML e C#: associazioni compilate, INotifyPropertyChanged/ObservableObject, convertitori di valori, modalità di associazione, associazione multipla, associazioni relative, fallback e procedure consigliate MVVM. UTILIZZARE PER: impostazione di associazioni compilate con x:DataType, implementazione di INotifyPropertyChanged o CommunityToolkit ObservableObject, creazione di IValueConverter/IMultiValueConverter, scelta delle modalità di associazione, configurazione di BindingContext, associazioni relative, associazione di fallback, StringFormat, SetBinding code-behind con lambda e applicazione degli avvisi XC0022/XC0025. NON UTILIZZARE PER: modelli e layout di elementi CollectionView (usare maui-collectionview), passaggio di dati di navigazione della shell (usare maui-shell-navigation), inserimento di dipendenze (usare maui-dependency-injection) o animazioni attivate da modifiche alle proprietà (usare API di animazione .NET MAUI).
