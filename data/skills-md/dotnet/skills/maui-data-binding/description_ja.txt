.NET MAUI XAML および C# データ バインディングに関するガイダンス — コンパイルされたバインディング、INotifyPropertyChanged / ObservableObject、値コンバーター、バインディング モード、マルチバインディング、相対バインディング、フォールバック、MVVM のベスト プラクティス。用途: x:DataType を使用したコンパイル済みバインディングのセットアップ、INotifyPropertyChanged または CommunityToolkit ObservableObject の実装、IValueConverter / IMultiValueConverter の作成、バインディング モードの選択、BindingContext、相対バインディング、バインディング フォールバック、StringFormat、ラムダを使用した分離コード SetBinding の構成、XC0022/XC0025 警告の適用。以下には使用しないでください: CollectionView アイテムのテンプレートとレイアウト (maui-collectionview を使用)、シェル ナビゲーション データの受け渡し (maui-shell-navigation を使用)、依存関係の挿入 (maui-dependency-injection を使用)、またはプロパティの変更によってトリガーされるアニメーション (.NET MAUI アニメーション API を使用)。
