Guía para enlaces de datos .NET MAUI XAML y C#: enlaces compilados, INotifyPropertyChanged/ObservableObject, convertidores de valores, modos de enlace, enlaces múltiples, enlaces relativos, alternativas y mejores prácticas de MVVM. USO PARA: configurar enlaces compilados con x:DataType, implementar INotifyPropertyChanged o CommunityToolkit ObservableObject, crear IValueConverter/IMultiValueConverter, elegir modos de enlace, configurar BindingContext, enlaces relativos, reservas de enlaces, StringFormat, código subyacente SetBinding con lambdas y aplicar advertencias XC0022/XC0025. NO LO UTILICE PARA: plantillas y diseños de elementos de CollectionView (use maui-collectionview), transferencia de datos de navegación de Shell (use maui-shell-navigation), inyección de dependencia (use maui-dependency-injection) o animaciones activadas por cambios de propiedad (use API de animación .NET MAUI).
