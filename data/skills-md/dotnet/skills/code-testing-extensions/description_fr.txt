Fournit des chemins d’accès aux fichiers d’extension spécifiques à la langue pour le pipeline de test de code. Appelez cette compétence pour découvrir les fichiers d'aide aux extensions disponibles (par exemple, dotnet.md pour .NET, cpp.md pour C++). Ne pas utiliser directement : invoqué par des agents de test de code et des compétences nécessitant des références spécifiques au langage.
