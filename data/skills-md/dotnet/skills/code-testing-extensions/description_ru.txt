Предоставляет пути к файлам расширений для конкретного языка для конвейера тестирования кода. Используйте этот навык, чтобы обнаружить доступные файлы руководства по расширениям (например, dotnet.md для .NET, cpp.md для C++). Не используйте напрямую — вызывается агентами и навыками тестирования кода, которым необходимы ссылки на конкретный язык.
