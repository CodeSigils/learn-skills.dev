Konfigurieren Sie die verteilte Ablaufverfolgung, Metriken und Protokollierung von OpenTelemetry in ASP.NET Core mithilfe des .NET OpenTelemetry SDK. Verwenden Sie diese Option, wenn Sie Beobachtbarkeit hinzufügen, OTLP-Exporteure einrichten, benutzerdefinierte Metriken/Spans erstellen oder Probleme bei der Korrelation verteilter Ablaufverfolgungen beheben.
