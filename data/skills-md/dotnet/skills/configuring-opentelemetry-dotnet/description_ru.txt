Настройте распределенную трассировку, метрики и ведение журнала OpenTelemetry в ASP.NET Core с помощью пакета SDK .NET OpenTelemetry. Используйте при добавлении наблюдаемости, настройке экспортеров OTLP, создании пользовательских метрик/диапазонов или устранении неполадок корреляции распределенной трассировки.
