C# MCP サーバーをローカルで実行およびデバッグします。 IDE 構成、MCP Inspector テスト、GitHub Copilot Agent Mode 統合、ログ設定、トラブルシューティングについて説明します。用途: dotnet run を使用したローカルでの MCP サーバーの実行、MCP デバッグ用の VS Code または Visual Studio の構成、MCP Inspector を使用したツールのテスト、GitHub Copilot Agent モードを使用したテスト、ツール登録の問題の診断、mcp.json 構成のセットアップ、MCP プロトコル メッセージのデバッグ、stdio および HTTP サーバーのログの構成。次の用途には使用しないでください: 新しい MCP サーバーの作成 (mcp-csharp-create を使用)、自動テストの作成 (mcp-csharp-test を使用)、運用環境への公開またはデプロイ (mcp-csharp-publish を使用)。
