Запускайте и отлаживайте серверы C# MCP локально. Охватывает настройку IDE, тестирование MCP Inspector, интеграцию режима агента GitHub Copilot, настройку ведения журналов и устранение неполадок. ИСПОЛЬЗОВАНИЕ ДЛЯ: локального запуска серверов MCP с помощью dotnet run, настройки VS Code или Visual Studio для отладки MCP, тестирования инструментов с помощью MCP Inspector, тестирования в режиме агента GitHub Copilot, диагностики проблем с регистрацией инструмента, настройки конфигурации mcp.json, отладки сообщений протокола MCP, настройки ведения журнала для серверов stdio и HTTP. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: создания новых серверов MCP (используйте mcp-csharp-create), написания автоматических тестов (используйте mcp-csharp-test), публикации или развертывания в рабочей среде (используйте mcp-csharp-publish).
