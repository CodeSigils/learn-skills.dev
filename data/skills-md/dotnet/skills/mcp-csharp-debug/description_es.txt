Ejecute y depure servidores C# MCP localmente. Cubre la configuración de IDE, las pruebas de MCP Inspector, la integración del modo GitHub Copilot Agent, la configuración de registros y la solución de problemas. USO PARA: ejecutar servidores MCP localmente con dotnet run, configurar VS Code o Visual Studio para la depuración de MCP, probar herramientas con MCP Inspector, probar con el modo GitHub Copilot Agent, diagnosticar problemas de registro de herramientas, configurar mcp.json, depurar mensajes del protocolo MCP, configurar el registro para servidores stdio y HTTP. NO UTILIZAR PARA: crear nuevos servidores MCP (use mcp-csharp-create), escribir pruebas automatizadas (use mcp-csharp-test), publicar o implementar en producción (use mcp-csharp-publish).
