Führen Sie C#-MCP-Server lokal aus und debuggen Sie sie. Behandelt die IDE-Konfiguration, MCP-Inspector-Tests, die Integration des GitHub Copilot Agent-Modus, die Einrichtung der Protokollierung und die Fehlerbehebung. VERWENDUNG FÜR: Lokales Ausführen von MCP-Servern mit Dotnet Run, Konfigurieren von VS Code oder Visual Studio für MCP-Debugging, Testen von Tools mit MCP Inspector, Testen mit GitHub Copilot Agent Mode, Diagnostizieren von Tool-Registrierungsproblemen, Einrichten der mcp.json-Konfiguration, Debuggen von MCP-Protokollmeldungen, Konfigurieren der Protokollierung für stdio- und HTTP-Server. NICHT VERWENDEN FÜR: Erstellen neuer MCP-Server (verwenden Sie mcp-csharp-create), Schreiben automatisierter Tests (verwenden Sie mcp-csharp-test), Veröffentlichen oder Bereitstellen in der Produktion (verwenden Sie mcp-csharp-publish).
