C# MCP 서버를 로컬에서 실행하고 디버깅합니다. IDE 구성, MCP 검사기 테스트, GitHub Copilot 에이전트 모드 통합, 로깅 설정 및 문제 해결을 다룹니다. 사용 대상: dotnet run을 사용하여 로컬로 MCP 서버 실행, MCP 디버깅을 위한 VS Code 또는 Visual Studio 구성, MCP Inspector를 사용한 도구 테스트, GitHub Copilot 에이전트 모드를 사용한 테스트, 도구 등록 문제 진단, mcp.json 구성 설정, MCP 프로토콜 메시지 디버깅, stdio 및 HTTP 서버에 대한 로깅 구성. 사용하지 마십시오: 새 MCP 서버 생성(mcp-csharp-create 사용), 자동화된 테스트 작성(mcp-csharp-test 사용), 프로덕션에 게시 또는 배포(mcp-csharp-publish 사용).
