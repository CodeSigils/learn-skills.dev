Esegui ed esegui il debug dei server MCP C# localmente. Copre la configurazione IDE, i test di MCP Inspector, l'integrazione della modalità agente GitHub Copilot, la configurazione della registrazione e la risoluzione dei problemi. UTILIZZO PER: esecuzione di server MCP localmente con dotnet run, configurazione di VS Code o Visual Studio per il debug MCP, test degli strumenti con MCP Inspector, test con GitHub Copilot Agent Mode, diagnosi dei problemi di registrazione dello strumento, impostazione della configurazione mcp.json, debug dei messaggi del protocollo MCP, configurazione della registrazione per server stdio e HTTP. NON UTILIZZARE PER: creare nuovi server MCP (usare mcp-csharp-create), scrivere test automatizzati (usare mcp-csharp-test), pubblicare o distribuire in produzione (usare mcp-csharp-publish).
