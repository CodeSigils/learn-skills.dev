在本地运行和调试 C# MCP 服务器。涵盖 IDE 配置、MCP Inspector 测试、GitHub Copilot 代理模式集成、日志记录设置和故障排除。用于：使用 dotnet run 在本地运行 MCP 服务器、配置 VS Code 或 Visual Studio 进行 MCP 调试、使用 MCP Inspector 测试工具、使用 GitHub Copilot 代理模式进行测试、诊断工具注册问题、设置 mcp.json 配置、调试 MCP 协议消息、配置 stdio 和 HTTP 服务器的日志记录。请勿用于：创建新的 MCP 服务器（使用 mcp-csharp-create）、编写自动化测试（使用 mcp-csharp-test）、发布或部署到生产环境（使用 mcp-csharp-publish）。
