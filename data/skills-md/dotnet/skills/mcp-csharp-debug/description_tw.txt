在本地運行和調試 C# MCP 伺服器。涵蓋 IDE 配置、MCP Inspector 測試、GitHub Copilot 代理模式整合、日誌記錄設定和故障排除。用於：使用 dotnet run 在本地運行 MCP 伺服器、配置 VS Code 或 Visual Studio 進行 MCP 偵錯、使用 MCP Inspector 測試工具、使用 GitHub Copilot 代理模式進行測試、診斷工具註冊問題、設定 mcp.json 配置、偵錯 MCP 協定訊息、配置 stdio 和 HTTP 通訊的日誌記錄。請勿用於：建立新的 MCP 伺服器（使用 mcp-csharp-create）、編寫自動化測試（使用 mcp-csharp-test）、發布或部署到生產環境（使用 mcp-csharp-publish）。
