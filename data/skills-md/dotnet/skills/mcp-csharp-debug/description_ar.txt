تشغيل وتصحيح خوادم C# MCP محليًا. يغطي تكوين IDE، واختبار MCP Inspector، وتكامل وضع وكيل GitHub Copilot Agent، وإعداد التسجيل، واستكشاف الأخطاء وإصلاحها. الاستخدام من أجل: تشغيل خوادم MCP محليًا مع تشغيل dotnet، وتكوين VS Code أو Visual Studio لتصحيح أخطاء MCP، واختبار الأدوات باستخدام MCP Inspector، والاختبار باستخدام GitHub Copilot Agent Mode، وتشخيص مشكلات تسجيل الأداة، وإعداد تكوين mcp.json، وتصحيح أخطاء رسائل بروتوكول MCP، وتكوين التسجيل لخوادم stdio وHTTP. لا تستخدم من أجل: إنشاء خوادم MCP جديدة (استخدم mcp-csharp-create)، أو كتابة اختبارات تلقائية (استخدم mcp-csharp-test)، أو النشر أو النشر إلى الإنتاج (استخدم mcp-csharp-publish).
