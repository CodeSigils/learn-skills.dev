Exécutez et déboguez les serveurs C# MCP localement. Couvre la configuration de l'IDE, les tests de l'inspecteur MCP, l'intégration du mode agent GitHub Copilot, la configuration de la journalisation et le dépannage. UTILISER POUR : exécuter des serveurs MCP localement avec dotnet run, configurer VS Code ou Visual Studio pour le débogage MCP, tester les outils avec MCP Inspector, tester avec le mode agent GitHub Copilot, diagnostiquer les problèmes d'enregistrement des outils, configurer la configuration mcp.json, déboguer les messages du protocole MCP, configurer la journalisation pour les serveurs stdio et HTTP. NE PAS UTILISER POUR : la création de nouveaux serveurs MCP (utilisez mcp-csharp-create), l'écriture de tests automatisés (utilisez mcp-csharp-test), la publication ou le déploiement en production (utilisez mcp-csharp-publish).
