Analysez les journaux binaires MSBuild pour diagnostiquer les échecs de build en relisant les journaux binaires dans des journaux de texte consultables. Activez uniquement dans le contexte de build MSBuild/.NET. UTILISER POUR : générer des erreurs qui ne sont pas claires dans la sortie de la console, diagnostiquer les échecs en cascade dans les versions multi-projets, suivre l'ordre d'exécution de la cible MSBuild, enquêter sur les erreurs courantes telles que CS0246 (type introuvable), MSB4019 (projet importé introuvable), NU1605 (rétrogradation du package), MSB3277 (conflits de version) et échecs de ResolveProjectReferences. Nécessite un fichier .binlog existant. NE PAS UTILISER POUR : la génération de binlogs (utilisez la génération binlog), l'analyse des performances de build (utilisez build-perf-diagnostics), les systèmes de build non MSBuild. INVOKES : dotnet msbuild binlog replay, grep, cat, head, tail pour l'analyse du journal.
