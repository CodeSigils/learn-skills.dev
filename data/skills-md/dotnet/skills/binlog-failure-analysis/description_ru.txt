Анализируйте двоичные журналы MSBuild для диагностики сбоев сборки путем преобразования двоичных журналов в текстовые журналы с возможностью поиска. Активируйте только в контексте сборки MSBuild/.NET. ИСПОЛЬЗОВАНИЕ ДЛЯ: ошибок сборки, которые неясны из вывода консоли, диагностики каскадных сбоев в многопроектных сборках, отслеживания целевого порядка выполнения MSBuild, исследования распространенных ошибок, таких как CS0246 (тип не найден), MSB4019 (импортированный проект не найден), NU1605 (понижение версии пакета), MSB3277 (конфликты версий) и сбои ResolveProjectReferences. Требуется существующий файл .binlog. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: создания журналов binlog (используйте генерацию binlog), анализа производительности сборки (используйте диагностику build-perf), систем сборки, отличных от MSBuild. ВЫЗЫВАЕТ: повтор binlog dotnet msbuild, grep, cat, head, Tail для анализа журнала.
