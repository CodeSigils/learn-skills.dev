Testa i server MCP C# a più livelli: test unitari per singoli strumenti e test di integrazione utilizzando l'SDK del client MCP. UTILIZZO PER: test unitari dei metodi dello strumento MCP, test di integrazione con client/server MCP in memoria, test end-to-end tramite protocollo MCP, test di server MCP HTTP con WebApplicationFactory, derisione delle dipendenze nei test dello strumento, creazione di valutazioni per server MCP, scrittura di domande di valutazione, misurazione della qualità dello strumento. NON UTILIZZARE PER: test dei client MCP (si tratta solo di test del server), test del carico o delle prestazioni, test dei server MCP non .NET, debug dei problemi del server (utilizzare mcp-csharp-debug).
