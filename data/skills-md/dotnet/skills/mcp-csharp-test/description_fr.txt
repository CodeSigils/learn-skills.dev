Testez les serveurs C# MCP à plusieurs niveaux : tests unitaires pour des outils individuels et tests d'intégration à l'aide du SDK client MCP. UTILISER POUR : tests unitaires des méthodes des outils MCP, tests d'intégration avec client/serveur MCP en mémoire, tests de bout en bout via le protocole MCP, tests des serveurs HTTP MCP avec WebApplicationFactory, simulation des dépendances dans les tests d'outils, création d'évaluations pour les serveurs MCP, rédaction de questions d'évaluation, mesure de la qualité des outils. NE PAS UTILISER POUR : tester les clients MCP (il s'agit uniquement de tests de serveur), les tests de charge ou de performances, les tests de serveurs MCP non .NET, le débogage des problèmes de serveur (utilisez mcp-csharp-debug).
