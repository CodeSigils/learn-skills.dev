Тестируйте серверы C# MCP на нескольких уровнях: модульные тесты для отдельных инструментов и интеграционные тесты с использованием клиентского SDK MCP. ИСПОЛЬЗОВАНИЕ ДЛЯ: модульного тестирования методов инструмента MCP, интеграционного тестирования с клиентом/сервером MCP в памяти, сквозного тестирования через протокол MCP, тестирования серверов HTTP MCP с помощью WebApplicationFactory, имитации зависимостей в тестах инструмента, создания оценок для серверов MCP, написания оценочных вопросов, измерения качества инструмента. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: тестирования клиентов MCP (это только тестирование сервера), тестирования нагрузки или производительности, тестирования серверов, отличных от .NET MCP, отладки проблем с сервером (используйте mcp-csharp-debug).
