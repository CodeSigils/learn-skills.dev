Pruebe servidores C# MCP en múltiples niveles: pruebas unitarias para herramientas individuales y pruebas de integración utilizando el SDK del cliente MCP. USO PARA: pruebas unitarias de métodos de herramientas MCP, pruebas de integración con cliente/servidor MCP en memoria, pruebas de extremo a extremo a través del protocolo MCP, pruebas de servidores HTTP MCP con WebApplicationFactory, burlarse de dependencias en pruebas de herramientas, crear evaluaciones para servidores MCP, escribir preguntas de evaluación, medir la calidad de la herramienta. NO LO UTILICE PARA: probar clientes MCP (esto es solo prueba de servidor), pruebas de carga o rendimiento, probar servidores MCP que no son .NET, depurar problemas del servidor (use mcp-csharp-debug).
