اختبار خوادم C# MCP على مستويات متعددة: اختبارات الوحدة للأدوات الفردية واختبارات التكامل باستخدام عميل MCP SDK. الاستخدام من أجل: اختبار الوحدة لأساليب أداة MCP، واختبار التكامل مع عميل/خادم MCP في الذاكرة، والاختبار الشامل عبر بروتوكول MCP، واختبار خوادم HTTP MCP باستخدام WebApplicationFactory، والاستهزاء بالتبعيات في اختبارات الأدوات، وإنشاء تقييمات لخوادم MCP، وكتابة أسئلة التقييم، وقياس جودة الأداة. لا تستخدم من أجل: اختبار عملاء MCP (هذا هو اختبار الخادم فقط)، أو اختبار التحميل أو الأداء، أو اختبار خوادم غير تابعة لـ NET MCP، أو تصحيح مشكلات الخادم (استخدم mcp-csharp-debug).
