C# MCP サーバーを複数のレベルでテストします。個々のツールの単体テストと、MCP クライアント SDK を使用した統合テストです。用途: MCP ツール メソッドの単体テスト、メモリ内 MCP クライアント/サーバーとの統合テスト、MCP プロトコルによるエンドツーエンド テスト、WebApplicationFactory を使用した HTTP MCP サーバーのテスト、ツール テストでの依存関係のモック、MCP サーバーの評価の作成、評価質問の作成、ツールの品質の測定。次の目的には使用しないでください: MCP クライアントのテスト (これはサーバー テストのみ)、負荷またはパフォーマンスのテスト、非 .NET MCP サーバーのテスト、サーバーの問題のデバッグ (mcp-csharp-debug を使用)。
