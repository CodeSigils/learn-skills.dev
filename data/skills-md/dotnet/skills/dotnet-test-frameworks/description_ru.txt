Справочные данные для шаблонов обнаружения среды тестирования .NET, API утверждений, пропуска аннотаций, методов настройки и удаления, а также общих индикаторов запаха тестов в MSTest, xUnit, NUnit и TUnit. НЕ ИСПОЛЬЗУЙТЕ напрямую — загружается навыками тестового анализа (тест-анти-шаблоны, опыт-тест-обнаружение запаха, опыт-утверждение-качество, опыт-тест-обслуживаемость, опыт-тест-тегирование), когда им нужны таблицы поиска, специфичные для платформы.
