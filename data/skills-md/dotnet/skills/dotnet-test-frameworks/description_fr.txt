Données de référence pour les modèles de détection du framework de test .NET, les API d'assertion, les annotations de saut, les méthodes de configuration/démontage et les indicateurs d'odeur de test courants dans MSTest, xUnit, NUnit et TUnit. NE PAS UTILISER directement - chargé par les compétences d'analyse de tests (test-anti-modèles, exp-test-smell-detection, exp-assertion-quality, exp-test-maintainability, exp-test-tagging) lorsqu'elles ont besoin de tables de recherche spécifiques au framework.
