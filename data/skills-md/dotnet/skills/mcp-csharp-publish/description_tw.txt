發布和部署 C# MCP 伺服器。涵蓋 stdio 伺服器的 NuGet 打包、HTTP 伺服器的 Docker 容器化、Azure 容器應用程式和應用程式服務部署以及發佈到官方 MCP 註冊表。用途：將 stdio MCP 伺服器打包為 NuGet 工具、為 HTTP MCP 伺服器建立 Dockerfile、部署至 Azure 容器應用程式或應用程式服務、發佈到位於registry.modelcontextprotocol.io 的 MCP 註冊表、為 MCP 包元資料配置 server.json、為 MCP 發佈設定 CI/CD。請勿用於：發布通用 NuGet 程式庫（非 MCP 特定）、與 MCP 無關的通用 Docker 指南、建立新伺服器（使用 mcp-csharp-create）、偵錯（使用 mcp-csharp-debug）、編寫測試（使用 mcp-csharp-test）。
