C# MCP 서버를 게시하고 배포합니다. stdio 서버용 NuGet 패키징, HTTP 서버용 Docker 컨테이너화, Azure 컨테이너 앱 및 App Service 배포, 공식 MCP 레지스트리에 게시를 다룹니다. 사용 대상: stdio MCP 서버를 NuGet 도구로 패키징, HTTP MCP 서버용 Dockerfile 생성, Azure 컨테이너 앱 또는 App Service에 배포, Registry.modelcontextprotocol.io에서 MCP 레지스트리에 게시, MCP 패키지 메타데이터용 server.json 구성, MCP 서버 게시용 CI/CD 설정. 사용하지 마십시오: 일반 NuGet 라이브러리 게시(MCP 관련 아님), MCP와 관련되지 않은 일반 Docker 지침, 새 서버 생성(mcp-csharp-create 사용), 디버깅(mcp-csharp-debug 사용), 테스트 작성(mcp-csharp-test 사용).
