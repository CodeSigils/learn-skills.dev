Publicar e implementar servidores C# MCP. Cubre el empaquetado de NuGet para servidores stdio, la contenedorización de Docker para servidores HTTP, la implementación de Azure Container Apps y App Service, y la publicación en el Registro MCP oficial. USO PARA: empaquetar servidores stdio MCP como herramientas NuGet, crear Dockerfiles para servidores HTTP MCP, implementar en Azure Container Apps o App Service, publicar en el Registro MCP en registro.modelcontextprotocol.io, configurar server.json para metadatos de paquetes MCP, configurar CI/CD para la publicación del servidor MCP. NO LO UTILICE PARA: publicar bibliotecas generales de NuGet (no específicas de MCP), orientación general de Docker no relacionada con MCP, crear nuevos servidores (use mcp-csharp-create), depurar (use mcp-csharp-debug), escribir pruebas (use mcp-csharp-test).
