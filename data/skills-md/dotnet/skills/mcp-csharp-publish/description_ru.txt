Публикация и развертывание серверов C# MCP. Охватывает упаковку NuGet для серверов stdio, контейнеризацию Docker для HTTP-серверов, развертывание приложений-контейнеров Azure и службы приложений, а также публикацию в официальном реестре MCP. ИСПОЛЬЗОВАНИЕ ДЛЯ: упаковки серверов stdio MCP в качестве инструментов NuGet, создания файлов Dockerfile для серверов HTTP MCP, развертывания в приложениях-контейнерах Azure или службе приложений, публикации в реестре MCP по адресу Registry.modelcontextprotocol.io, настройки server.json для метаданных пакета MCP, настройки CI/CD для публикации сервера MCP. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: публикации общих библиотек NuGet (не специфичных для MCP), общего руководства по Docker, не связанного с MCP, создания новых серверов (используйте mcp-csharp-create), отладки (используйте mcp-csharp-debug), написания тестов (используйте mcp-csharp-test).
