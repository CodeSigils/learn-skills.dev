Publiez et déployez des serveurs C# MCP. Couvre le packaging NuGet pour les serveurs stdio, la conteneurisation Docker pour les serveurs HTTP, le déploiement d'Azure Container Apps et d'App Service et la publication dans le registre MCP officiel. UTILISER POUR : empaqueter des serveurs MCP stdio en tant qu'outils NuGet, créer des Dockerfiles pour les serveurs HTTP MCP, déployer sur Azure Container Apps ou App Service, publier dans le registre MCP à l'adresse Registry.modelcontextprotocol.io, configurer server.json pour les métadonnées du package MCP, configurer CI/CD pour la publication du serveur MCP. NE PAS UTILISER POUR : la publication de bibliothèques NuGet générales (non spécifiques à MCP), les conseils généraux de Docker sans rapport avec MCP, la création de nouveaux serveurs (utilisez mcp-csharp-create), le débogage (utilisez mcp-csharp-debug), l'écriture de tests (utilisez mcp-csharp-test).
