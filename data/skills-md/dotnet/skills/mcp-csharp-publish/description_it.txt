Pubblica e distribuisci server MCP C#. Copre il packaging NuGet per server stdio, la containerizzazione Docker per server HTTP, la distribuzione di app contenitore di Azure e del servizio app e la pubblicazione nel registro MCP ufficiale. UTILIZZARE PER: creare pacchetti di server MCP stdio come strumenti NuGet, creare file Docker per server MCP HTTP, distribuire in app contenitore di Azure o nel servizio app, pubblicare nel registro MCP in Registry.modelcontextprotocol.io, configurare server.json per i metadati del pacchetto MCP, impostare CI/CD per la pubblicazione del server MCP. NON UTILIZZARE PER: pubblicazione di librerie NuGet generali (non specifiche di MCP), indicazioni generali su Docker non correlate a MCP, creazione di nuovi server (utilizzare mcp-csharp-create), debug (utilizzare mcp-csharp-debug), scrittura di test (utilizzare mcp-csharp-test).
