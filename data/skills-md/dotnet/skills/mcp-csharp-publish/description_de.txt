Veröffentlichen und Bereitstellen von C#-MCP-Servern. Behandelt NuGet-Paketierung für Standardserver, Docker-Containerisierung für HTTP-Server, Bereitstellung von Azure Container Apps und App Service sowie Veröffentlichung in der offiziellen MCP-Registrierung. VERWENDUNG FÜR: Verpacken von stdio-MCP-Servern als NuGet-Tools, Erstellen von Docker-Dateien für HTTP-MCP-Server, Bereitstellen in Azure Container Apps oder App Service, Veröffentlichen in der MCP-Registrierung unter Registry.modelcontextprotocol.io, Konfigurieren von server.json für MCP-Paketmetadaten, Einrichten von CI/CD für die MCP-Serververöffentlichung. NICHT VERWENDEN FÜR: Veröffentlichung allgemeiner NuGet-Bibliotheken (nicht MCP-spezifisch), allgemeine Docker-Anleitung ohne Bezug zu MCP, Erstellung neuer Server (verwenden Sie mcp-csharp-create), Debuggen (verwenden Sie mcp-csharp-debug), Schreiben von Tests (verwenden Sie mcp-csharp-test).
