نشر ونشر خوادم C# MCP. يغطي تغليف NuGet لخوادم stdio، وحاويات Docker لخوادم HTTP، ونشر تطبيقات Azure Container Apps وخدمة التطبيقات، والنشر إلى سجل MCP الرسمي. الاستخدام من أجل: تعبئة خوادم stdio MCP كأدوات NuGet، وإنشاء ملفات Dockerfiles لخوادم HTTP MCP، والنشر إلى Azure Container Apps أو خدمة التطبيقات، والنشر إلى سجل MCP على السجل.modelcontextprotocol.io، وتكوين server.json لبيانات تعريف حزمة MCP، وإعداد CI/CD لنشر خادم MCP. لا تستخدمه من أجل: نشر مكتبات NuGet العامة (ليست خاصة بـ MCP)، وإرشادات Docker العامة غير المرتبطة بـ MCP، وإنشاء خوادم جديدة (استخدم mcp-csharp-create)، وتصحيح الأخطاء (استخدم mcp-csharp-debug)، وكتابة الاختبارات (استخدم mcp-csharp-test).
