C# MCP サーバーを公開してデプロイします。標準入出力サーバーの NuGet パッケージ化、HTTP サーバーの Docker コンテナー化、Azure Container Apps と App Service のデプロイ、公式 MCP レジストリへの公開について説明します。用途: 標準入出力 MCP サーバーを NuGet ツールとしてパッケージ化する、HTTP MCP サーバー用の Dockerfile を作成する、Azure Container Apps または App Service にデプロイする、registry.modelcontextprotocol.io で MCP レジストリに公開する、MCP パッケージ メタデータ用の server.json を構成する、MCP サーバー公開用の CI/CD を設定する。次の用途には使用しないでください: 一般的な NuGet ライブラリ (MCP 固有ではない) の公開、MCP に関係のない一般的な Docker ガイダンス、新しいサーバーの作成 (mcp-csharp-create を使用)、デバッグ (mcp-csharp-debug を使用)、テストの作成 (mcp-csharp-test を使用)。
