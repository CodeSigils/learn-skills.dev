发布和部署 C# MCP 服务器。涵盖 stdio 服务器的 NuGet 打包、HTTP 服务器的 Docker 容器化、Azure 容器应用程序和应用服务部署以及发布到官方 MCP 注册表。用途：将 stdio MCP 服务器打包为 NuGet 工具、为 HTTP MCP 服务器创建 Dockerfile、部署到 Azure 容器应用程序或应用服务、发布到位于registry.modelcontextprotocol.io 的 MCP 注册表、为 MCP 包元数据配置 server.json、为 MCP 服务器发布设置 CI/CD。请勿用于：发布通用 NuGet 库（非 MCP 特定）、与 MCP 无关的通用 Docker 指南、创建新服务器（使用 mcp-csharp-create）、调试（使用 mcp-csharp-debug）、编写测试（使用 mcp-csharp-test）。
