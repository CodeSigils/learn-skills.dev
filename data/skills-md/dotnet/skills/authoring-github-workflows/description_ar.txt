قم بتأليف ومراجعة سير عمل GitHub Actions YAML بأمان، لذا لا يمكن لـ YAML الصحيح من الناحية النحوية شحن سير عمل ترفض GitHub Actions تشغيله. الاستخدام من أجل: تحرير أو إضافة أو مراجعة أي ملف ضمن .github/workflows/، وكتابة قيم التشغيل/اسم/اسم/if/env/run التي تحتوي على تعبيرات ${{ }}، وتشخيص التشغيل الذي يفشل مع "من المحتمل أن يكون هذا التشغيل قد فشل بسبب مشكلة في ملف سير العمل" وعدم بدء أي مهام، وتحديد متى يجب اقتباس مقياس سير العمل، والتحقق من صحة سير العمل باستخدام actionlint. لا تستخدم من أجل: تأليف تطبيق YAML غير المرتبط بإجراءات GitHub، أو Azure Pipelines، أو GitLab CI، أو YAML غير المتعلق بسير العمل. النطاق: تغطي هذه المهارة الصحة * النحوية/الهيكلية* لسير العمل YAML (الاقتباس، والتحليل، وactionlint)؛ بالنسبة لتصميم سير العمل *الدلالي والوظيفي* (ما يجب أن يفعله سير العمل، سلوك سير العمل الوكيل)، راجع .github/agents/agentic-workflows.agent.md - الاثنان متكاملان. الاستدعاءات: actionlint (الثنائي المثبت الذي تم تنزيله) بالإضافة إلى git/grep للفحص.
