Créez et révisez le workflow YAML de GitHub Actions en toute sécurité afin que YAML syntaxiquement valide ne puisse pas envoyer un workflow que GitHub Actions refuse d'exécuter. UTILISER POUR : modifier, ajouter ou réviser n'importe quel fichier sous .github/workflows/, écrire des valeurs run-name/name/if/env/run qui contiennent des expressions ${{ }}, diagnostiquer une exécution qui échoue avec "Cette exécution a probablement échoué en raison d'un problème de fichier de workflow" et aucun travail ne démarre, décider quand un scalaire de workflow doit être cité, valider les workflows avec actionlint. NE PAS UTILISER POUR : la création d'applications YAML sans rapport avec GitHub Actions, Azure Pipelines, GitLab CI ou YAML sans workflow. PORTÉE : cette compétence couvre l'exactitude *syntaxique/structurelle* du flux de travail YAML (citation, analyse, actionlint) ; pour la conception de flux de travail *sémantique et fonctionnel* (ce qu'un flux de travail doit faire, comportement de flux de travail agentique), voir .github/agents/agentic-workflows.agent.md — les deux sont complémentaires. INVOKES : actionlint (binaire épinglé téléchargé) plus git/grep pour inspection.
