Cree y revise el flujo de trabajo YAML de GitHub Actions de forma segura para que YAML sintácticamente válido no pueda enviar un flujo de trabajo que GitHub Actions se niegue a ejecutar. UTILIZAR PARA: editar, agregar o revisar cualquier archivo en .github/workflows/, escribir valores run-name/name/if/env/run que contengan expresiones ${{ }}, diagnosticar una ejecución que falla con 'Esta ejecución probablemente falló debido a un problema con el archivo de flujo de trabajo' y no se inician trabajos, decidir cuándo se debe citar un escalar de flujo de trabajo y validar flujos de trabajo con actionlint. NO UTILIZAR PARA: creación de aplicaciones YAML no relacionadas con GitHub Actions, Azure Pipelines, GitLab CI o YAML que no sean de flujo de trabajo. ALCANCE: esta habilidad cubre la corrección *sintáctica/estructural* del flujo de trabajo YAML (citas, análisis, actionlint); para el diseño de flujo de trabajo *semántico y funcional* (qué debe hacer un flujo de trabajo, comportamiento del flujo de trabajo agente), consulte .github/agents/agentic-workflows.agent.md: los dos son complementarios. INVOCA: actionlint (binario anclado descargado) más git/grep para inspección.
