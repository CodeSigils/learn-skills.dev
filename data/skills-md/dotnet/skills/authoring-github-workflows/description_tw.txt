安全地編寫和審查 GitHub Actions 工作流程 YAML，以便語法有效的 YAML 無法傳送 GitHub Actions 拒絕運行的工作流程。用途：編輯、新增或檢視 .github/workflows/ 下的任何文件，寫入包含 ${{ }} 表達式的 run-name/name/if/env/run 值，診斷因「此運行可能因工作流程文件問題而失敗」且沒有作業啟動而失敗的運行，決定何時必須引用工作流程標量，使用 actionlint 驗證工作流程。請勿用於：創建與 GitHub Actions、Azure Pipelines、GitLab CI 或非工作流程 YAML 無關的應用程式 YAML。範圍：此技能涵蓋工作流程 YAML 的*語法/結構*正確性（引用、解析、actionlint）；對於*語義和功能*工作流程設計（工作流程應該做什麼，代理工作流行為），請參閱 .github/agents/agentic-workflows.agent.md - 兩者是互補的。呼叫：actionlint（下載的固定二進位）加上 git/grep 進行檢查。
