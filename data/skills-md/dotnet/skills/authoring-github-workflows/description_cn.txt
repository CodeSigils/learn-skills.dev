安全地编写和审查 GitHub Actions 工作流程 YAML，以便语法有效的 YAML 无法传送 GitHub Actions 拒绝运行的工作流程。用途：编辑、添加或查看 .github/workflows/ 下的任何文件，写入包含 ${{ }} 表达式的 run-name/name/if/env/run 值，诊断因“此运行可能因工作流文件问题而失败”且没有作业启动而失败的运行，决定何时必须引用工作流标量，使用 actionlint 验证工作流。请勿用于：创作与 GitHub Actions、Azure Pipelines、GitLab CI 或非工作流 YAML 无关的应用程序 YAML。范围：此技能涵盖工作流程 YAML 的*语法/结构*正确性（引用、解析、actionlint）；对于*语义和功能*工作流设计（工作流应该做什么，代理工作流行为），请参阅 .github/agents/agentic-workflows.agent.md - 两者是互补的。调用：actionlint（下载的固定二进制文件）加上 git/grep 进行检查。
