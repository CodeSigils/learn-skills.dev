GitHub Actions ワークフロー YAML を安全に作成してレビューできるため、構文的に有効な YAML は、GitHub Actions が実行を拒否するワークフローを出荷できません。用途: .github/workflows/ にあるファイルの編集、追加、レビュー、${{ }} 式を含む run-name/name/if/env/run 値の書き込み、「この実行はワークフロー ファイルの問題により失敗した可能性があります」で失敗しジョブが開始されない実行の診断、ワークフロー スカラーをいつ引用する必要があるかを決定する、actionlint でワークフローを検証する。以下には使用しないでください: GitHub Actions、Azure Pipelines、GitLab CI、またはワークフロー以外の YAML に関係のないオーサリング アプリケーション YAML。範囲: このスキルは、ワークフロー YAML (引用、解析、actionlint) の *構文/構造* の正確さをカバーします。 *意味論的および機能的* ワークフロー設計 (ワークフローが行うべきこと、エージェントのワークフローの動作) については、.github/agents/agentic-workflows.agent.md を参照してください。この 2 つは補完的です。呼び出し: actionlint (ダウンロードされた固定バイナリ) と検査用の git/grep。
