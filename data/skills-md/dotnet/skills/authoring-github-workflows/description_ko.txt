GitHub Actions 워크플로 YAML을 안전하게 작성하고 검토하면 구문적으로 유효한 YAML이 GitHub Actions가 실행을 거부하는 워크플로를 제공할 수 없습니다. 사용 대상: .github/workflows/ 아래의 파일 편집, 추가 또는 검토, ${{ }} 표현식이 포함된 run-name/name/if/env/run 값 작성, '이 실행은 워크플로 파일 문제로 인해 실패했을 가능성이 높습니다.' 및 작업이 시작되지 않음으로 실패하는 실행 진단, 워크플로 스칼라를 인용해야 하는 시기 결정, actionlint를 사용하여 워크플로 유효성 검사. 사용하지 마십시오: GitHub Actions, Azure Pipelines, GitLab CI 또는 비워크플로 YAML과 관련 없는 애플리케이션 YAML을 작성합니다. 범위: 이 기술은 워크플로 YAML(인용, 구문 분석, 작업 린트)의 *구문적/구조적* 정확성을 다룹니다. *의미론적 및 기능적* 워크플로 디자인(워크플로가 수행해야 하는 작업, 에이전트 워크플로 동작)에 대해서는 .github/agents/agentic-workflows.agent.md를 참조하세요. 두 가지는 상호 보완적입니다. INVOKES: actionlint(다운로드된 고정 바이너리) 및 검사를 위한 git/grep.
