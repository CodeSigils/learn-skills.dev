Crea ed esamina il flusso di lavoro YAML di GitHub Actions in modo sicuro in modo che YAML sintatticamente valido non possa fornire un flusso di lavoro che GitHub Actions si rifiuta di eseguire. UTILIZZARE PER: modificare, aggiungere o rivedere qualsiasi file in .github/workflows/, scrivere valori run-name/name/if/env/run che contengono espressioni ${{ }}, diagnosticare un'esecuzione che non riesce con "Questa esecuzione probabilmente non è riuscita a causa di un problema con il file del flusso di lavoro" e nessun lavoro avviato, decidere quando deve essere citato uno scalare del flusso di lavoro, convalidare i flussi di lavoro con actionlint. NON UTILIZZARE PER: creazione di YAML di applicazioni non correlate a GitHub Actions, Azure Pipelines, GitLab CI o YAML non correlato al flusso di lavoro. AMBITO: questa abilità copre la correttezza *sintattica/strutturale* del flusso di lavoro YAML (quoting, parsing, actionlint); per la progettazione *semantica e funzionale* del flusso di lavoro (cosa dovrebbe fare un flusso di lavoro, comportamento del flusso di lavoro agente), vedere .github/agents/agentic-workflows.agent.md — i due sono complementari. RICHIAMA: actionlint (binario bloccato scaricato) più git/grep per l'ispezione.
