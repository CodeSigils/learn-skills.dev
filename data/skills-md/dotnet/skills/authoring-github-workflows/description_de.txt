Erstellen und überprüfen Sie den GitHub Actions-Workflow in YAML sicher, sodass syntaktisch gültiges YAML keinen Workflow versenden kann, dessen Ausführung GitHub Actions verweigert. VERWENDUNG FÜR: Bearbeiten, Hinzufügen oder Überprüfen einer beliebigen Datei unter .github/workflows/, Schreiben von run-name/name/if/env/run-Werten, die ${{ }}-Ausdrücke enthalten, Diagnostizieren einer Ausführung, die mit „Diese Ausführung ist wahrscheinlich aufgrund eines Workflow-Dateiproblems fehlgeschlagen“ fehlschlägt und keine Jobs gestartet werden, Entscheiden, wann ein Workflow-Skalar in Anführungszeichen gesetzt werden muss, Validieren von Workflows mit Actionlint. NICHT VERWENDEN FÜR: Erstellen von Anwendungs-YAML, das nichts mit GitHub Actions, Azure Pipelines, GitLab CI oder Nicht-Workflow-YAML zu tun hat. ANWENDUNGSBEREICH: Diese Fertigkeit deckt die *syntaktische/strukturelle* Korrektheit des YAML-Workflows ab (Zitat, Parsing, Actionlint); Informationen zum *semantischen und funktionalen* Workflow-Design (was ein Workflow tun sollte, Agentic-Workflow-Verhalten) finden Sie unter .github/agents/agentic-workflows.agent.md – die beiden ergänzen sich. RUFT AUF: actionlint (heruntergeladene angeheftete Binärdatei) plus git/grep zur Inspektion.
