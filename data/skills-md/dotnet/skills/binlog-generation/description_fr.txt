Générez des journaux binaires MSBuild (binlogs) pour les diagnostics et l'analyse de la build. Activez uniquement dans le contexte de build MSBuild/.NET. UTILISER POUR : ajouter /bl:{} à n'importe quelle commande dotnet de build, test, pack, publication ou restauration pour capturer une trace complète d'exécution de build, condition préalable aux compétences d'analyse d'échec de binlog et de diagnostic de performance de build, permettant une enquête post-build sur les erreurs ou les performances. Nécessite MSBuild 17.8+ / .NET 8 SDK+ pour l'espace réservé {} ; PowerShell a besoin de -bl :{{}}. NE PAS UTILISER POUR : les systèmes de build non MSBuild (npm, Maven, CMake), analysant un binlog existant (utilisez plutôt binlog-failure-analysis). INVOKES : commandes shell (dotnet build /bl:{}).
