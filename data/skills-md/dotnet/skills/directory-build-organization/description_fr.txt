Guide pour organiser l'infrastructure MSBuild avec Directory.Build.props, Directory.Build.targets, Directory.Packages.props et Directory.Build.rsp. Activez uniquement dans le contexte de build MSBuild/.NET. UTILISER POUR : structurer des dépôts multi-projets, centraliser les paramètres de construction, implémenter NuGet Central Package Management (CPM) avec ManagePackageVersionsCentrally, consolider les propriétés dupliquées dans les fichiers .csproj, configurer une hiérarchie Directory.Build à plusieurs niveaux avec GetPathOfFileAbove, comprendre l'ordre d'évaluation (Directory.Build.props → SDK .props → .csproj → SDK .targets → Directory.Build.targets). Piège critique : les conditions $(TargetFramework) dans .props échouent silencieusement pour les projets à ciblage unique – doivent utiliser .targets. NE PAS UTILISER POUR : les systèmes de build non MSBuild, la migration de projets existants vers le style SDK (utiliser msbuild-modernization), les solutions à projet unique sans paramètres partagés. INVOCATIONS : pas d'outils - compétence de connaissance pure.
