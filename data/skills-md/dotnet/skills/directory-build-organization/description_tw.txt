使用 Directory.Build.props、Directory.Build.targets、Directory.Packages.props 和 Directory.Build.rsp 組織 MSBuild 基礎架構的指南。僅在 MSBuild/.NET 建置上下文中啟動。用途：建立多專案儲存庫、集中建置設定、使用 ManagePackageVersionsCentrally 實作 NuGet 中央套件管理 (CPM)、合併 .csproj 檔案中的重複屬性、使用 GetPathOfFileAbove 設定多層 Directory.Build 層次結構、了解評估順序（Directory.Builgetps.Sc. Directory.Build.targets）。嚴重陷阱：對於單目標項目，.props 中的 $(TargetFramework) 條件會默默失敗 — 必須使用 .targets。請勿用於：非 MSBuild 建置系統、將遺留項目移轉到 SDK 樣式（使用 msbuild-modernization）、沒有共用設定的單一項目解決方案。呼叫：沒有工具－純粹的知識技能。
