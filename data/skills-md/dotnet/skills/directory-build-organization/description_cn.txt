使用 Directory.Build.props、Directory.Build.targets、Directory.Packages.props 和 Directory.Build.rsp 组织 MSBuild 基础结构的指南。仅在 MSBuild/.NET 构建上下文中激活。用途：构建多项目存储库、集中构建设置、使用 ManagePackageVersionsCentrally 实施 NuGet 中央包管理 (CPM)、合并 .csproj 文件中的重复属性、使用 GetPathOfFileAbove 设置多级 Directory.Build 层次结构、了解评估顺序（Directory.Build.props → SDK .props → .csproj → SDK .targets → Directory.Build.targets）。严重陷阱：对于单目标项目，.props 中的 $(TargetFramework) 条件会默默失败 — 必须使用 .targets。请勿用于：非 MSBuild 构建系统、将遗留项目迁移到 SDK 样式（使用 msbuild-modernization）、没有共享设置的单项目解决方案。调用：没有工具——纯粹的知识技能。
