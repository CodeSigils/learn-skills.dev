Directory.Build.props, Directory.Build.targets, Directory.Packages.props 및 Directory.Build.rsp를 사용하여 MSBuild 인프라를 구성하기 위한 가이드입니다. MSBuild/.NET 빌드 컨텍스트에서만 활성화하세요. 사용 대상: 다중 프로젝트 저장소 구성, 빌드 설정 중앙 집중화, ManagePackageVersionsCentrally를 사용하여 NuGet 중앙 패키지 관리(CPM) 구현, .csproj 파일 전체에서 중복된 속성 통합, GetPathOfFileAbove를 사용하여 다중 레벨 Directory.Build 계층 구조 설정, 평가 순서 이해(Directory.Build.props → SDK .props → .csproj → SDK .targets → Directory.Build.targets). 중요한 함정: .props의 $(TargetFramework) 조건은 단일 타겟팅 프로젝트에 대해 자동으로 실패합니다. .targets를 사용해야 합니다. 사용하지 마십시오: 비 MSBuild 빌드 시스템, 레거시 프로젝트를 SDK 스타일로 마이그레이션(msbuild-modernization 사용), 공유 설정이 없는 단일 프로젝트 솔루션. 호출: 도구 없음 — 순수한 지식 기술.
