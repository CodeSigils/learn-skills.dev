Guía para organizar la infraestructura de MSBuild con Directory.Build.props, Directory.Build.targets, Directory.Packages.props y Directory.Build.rsp. Activar solo en el contexto de compilación de MSBuild/.NET. USO PARA: estructurar repositorios de múltiples proyectos, centralizar la configuración de compilación, implementar NuGet Central Package Management (CPM) con ManagePackageVersionsCentrally, consolidar propiedades duplicadas en archivos .csproj, configurar una jerarquía Directory.Build de varios niveles con GetPathOfFileAbove, comprender el orden de evaluación (Directory.Build.props → SDK .props → .csproj → SDK .targets → Directorio.Construir.objetivos). Error crítico: las condiciones $(TargetFramework) en .props fallan silenciosamente para proyectos con un solo objetivo; se deben usar .targets. NO LO UTILICE PARA: sistemas de compilación que no sean MSBuild, migración de proyectos heredados al estilo SDK (use msbuild-modernization), soluciones de un solo proyecto sin configuraciones compartidas. INVOCA: sin herramientas, puro conocimiento y habilidad.
