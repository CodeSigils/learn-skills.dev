Directory.Build.props、Directory.Build.targets、Directory.Packages.props、および Directory.Build.rsp を使用して MSBuild インフラストラクチャを編成するためのガイド。 MSBuild/.NET ビルド コンテキストでのみアクティブ化します。用途: マルチプロジェクト リポジトリの構造化、ビルド設定の一元化、ManagePackageVersionsCentrally による NuGet Central Package Management (CPM) の実装、.csproj ファイル全体で重複するプロパティの統合、GetPathOfFileAbove によるマルチレベルの Directory.Build 階層の設定、評価順序の理解 (Directory.Build.props → SDK .props → .csproj → SDK .targets →ディレクトリ.Build.targets)。重大な落とし穴: .props の $(TargetFramework) 条件は、単一ターゲット プロジェクトでは暗黙的に失敗します。.targets を使用する必要があります。次の用途には使用しないでください: MSBuild 以外のビルド システム、レガシー プロジェクトを SDK スタイルに移行する (msbuild-modernization を使用する)、共有設定のない単一プロジェクト ソリューション。発動: ツールは不要 – 純粋な知識スキル。
