دليل لتنظيم البنية التحتية لـ MSBuild باستخدام Directory.Build.props وDirectory.Build.targets وDirectory.Packages.props وDirectory.Build.rsp. التنشيط فقط في سياق بناء MSBuild/.NET. الاستخدام من أجل: هيكلة عمليات إعادة الشراء متعددة المشاريع، ومركزية إعدادات البناء، وتنفيذ إدارة الحزم المركزية لـ NuGet (CPM) مع ManagePackageVersionsCentrally، ودمج الخصائص المكررة عبر ملفات .csproj، وإعداد دليل متعدد المستويات. بناء تسلسل هرمي باستخدام GetPathOfFileAbove، وفهم ترتيب التقييم (Directory.Build.props → SDK .props → .csproj → SDK .targets → Directory.Build.targets). المأزق الحرج: تفشل شروط $(TargetFramework) في ‎.props بصمت في المشاريع ذات الهدف الفردي - يجب استخدام ‎.targets. لا تستخدمه من أجل: أنظمة البناء غير التابعة لـ MSBuild، وترحيل المشاريع القديمة إلى نمط SDK (استخدم تحديث msbuild)، وحلول المشروع الفردي بدون إعدادات مشتركة. يستدعي: لا توجد أدوات - مهارة المعرفة البحتة.
