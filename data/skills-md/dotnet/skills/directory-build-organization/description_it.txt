Guida per l'organizzazione dell'infrastruttura MSBuild con Directory.Build.props, Directory.Build.targets, Directory.Packages.props e Directory.Build.rsp. Attivare solo nel contesto di compilazione MSBuild/.NET. UTILIZZARE PER: strutturare repository multiprogetto, centralizzare le impostazioni di compilazione, implementare NuGet Central Package Management (CPM) con ManagePackageVersionsCentrally, consolidare proprietà duplicate nei file .csproj, impostare una gerarchia Directory.Build multilivello con GetPathOfFileAbove, comprendere l'ordine di valutazione (Directory.Build.props → SDK .props → .csproj → SDK .targets → Directory.Build.targets). Insidia critica: le condizioni $(TargetFramework) in .props falliscono silenziosamente per progetti a targeting singolo: è necessario utilizzare .targets. NON UTILIZZARE PER: sistemi di build non MSBuild, migrazione di progetti legacy in stile SDK (utilizzare msbuild-modernization), soluzioni a progetto singolo senza impostazioni condivise. INVOCA: nessuno strumento, pura abilità di conoscenza.
