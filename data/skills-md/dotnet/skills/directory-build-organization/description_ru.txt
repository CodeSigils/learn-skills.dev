Руководство по организации инфраструктуры MSBuild с помощью Directory.Build.props, Directory.Build.targets, Directory.Packages.props и Directory.Build.rsp. Активируйте только в контексте сборки MSBuild/.NET. ИСПОЛЬЗОВАНИЕ ДЛЯ: структурирования репозиториев нескольких проектов, централизации параметров сборки, реализации центрального управления пакетами NuGet (CPM) с помощью ManagePackageVersionsCentrally, консолидации повторяющихся свойств в файлах .csproj, настройки многоуровневой иерархии Directory.Build с помощью GetPathOfFileAbove, понимания порядка оценки (Directory.Build.props → SDK .props → .csproj → SDK .targets → Directory.Build.targets). Критическая ошибка: условия $(TargetFramework) в .props молча терпят неудачу для проектов с одним таргетингом — необходимо использовать .targets. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: систем сборки, отличных от MSBuild, переноса устаревших проектов в стиль SDK (используйте msbuild-modernization), однопроектных решений без общих настроек. ПРИЗЫВАЕТ: никаких инструментов — чистое знание, умение.
