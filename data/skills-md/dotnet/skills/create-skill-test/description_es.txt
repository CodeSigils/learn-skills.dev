Scaffolding archivos de prueba eval.yaml para las habilidades del agente en el repositorio dotnet/skills. Úselo al crear pruebas de habilidades, escribir escenarios de evaluación, definir afirmaciones y rúbricas o configurar archivos de dispositivos de prueba. Maneja la generación de eval.yaml, la organización de dispositivos y la prevención del sobreajuste. No lo utilice para ejecutar o depurar pruebas existentes ni para la creación de habilidades.
