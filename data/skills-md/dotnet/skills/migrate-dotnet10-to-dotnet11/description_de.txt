Migrieren Sie ein .NET 10-Projekt oder eine .NET 10-Lösung auf .NET 11 und beheben Sie alle wichtigen Änderungen. Dies ist eine MIGRATIONS-Fähigkeit – verwenden Sie sie beim Upgrade von .NET 10 auf .NET 11, NICHT zum Schreiben neuer Programme. VERWENDUNG FÜR: Upgrade von TargetFramework von net10.0 auf net11.0, Behebung von Buildfehlern nach der Aktualisierung des .NET 11 SDK, Behebung von Quellenverstößen und Verhaltensänderungen in der .NET 11-Laufzeit, dem C# 15-Compiler und EF Core 11, Anpassung an aktualisierte Mindesthardwareanforderungen (x86-64-v2, Arm64 LSE) und Aktualisierung von CI/CD-Pipelines und Dockerfiles für .NET 11. NICHT VERWENDEN FÜR: .NET Framework-Migrationen, Upgrades von .NET 9 oder früher, Greenfield-.NET 11-Projekte oder kosmetische Modernisierungen, die nichts mit dem Upgrade zu tun haben. HINWEIS: .NET 11 befindet sich in der Vorschau. Deckt bahnbrechende Änderungen in Vorschau 1 ab.
