Migrez un projet ou une solution .NET 10 vers .NET 11 et résolvez toutes les modifications avec rupture. Il s'agit d'une compétence de MIGRATION : utilisez-la lors de la mise à niveau de .NET 10 vers .NET 11, PAS pour écrire de nouveaux programmes. UTILISER POUR : mettre à niveau TargetFramework de net10.0 vers net11.0, corriger les erreurs de construction après la mise à jour du SDK .NET 11, résoudre les changements de comportement et de rupture de source dans le runtime .NET 11, le compilateur C# 15 et EF Core 11, s'adapter aux exigences matérielles minimales mises à jour (x86-64-v2, Arm64 LSE) et mettre à jour les pipelines CI/CD et les Dockerfiles pour .NET 11. NE PAS UTILISER POUR : les migrations de .NET Framework, la mise à niveau à partir de .NET 9 ou une version antérieure, les nouveaux projets .NET 11 ou la modernisation cosmétique sans rapport avec la mise à niveau. REMARQUE : .NET 11 est en version préliminaire. Couvre les changements majeurs jusqu’à l’aperçu 1.
