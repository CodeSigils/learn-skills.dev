Guía la creación y validación de nuevas plantillas dotnet personalizadas. Genera plantillas a partir de proyectos existentes y valida template.json para problemas de creación. UTILIZAR PARA: crear una nueva plantilla dotnet reutilizable a partir de un proyecto existente, validar archivos template.json para comprobar el cumplimiento del esquema y problemas de parámetros, iniciar .template.config/template.json con la identidad, el nombre corto, los parámetros y las acciones posteriores correctos, y empaquetar plantillas como paquetes NuGet para su distribución. NO UTILIZAR PARA: buscar o usar plantillas existentes (use descubrimiento de plantillas y creación de instancias de plantillas), problemas de archivos de proyectos de MSBuild no relacionados con la creación de plantillas, publicación de paquetes NuGet (solo estructura de empaquetado de plantillas).
