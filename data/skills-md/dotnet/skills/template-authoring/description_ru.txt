Руководства по созданию и проверке новых пользовательских шаблонов dotnet. Создает шаблоны из существующих проектов и проверяет файл template.json на наличие проблем при создании. ИСПОЛЬЗОВАНИЕ ДЛЯ: создания нового шаблона dotnet многократного использования из существующего проекта, проверки файлов template.json на предмет соответствия схемы и проблем с параметрами, начальной загрузки .template.config/template.json с правильным идентификатором, коротким именем, параметрами и последующими действиями, упаковки шаблонов в виде пакетов NuGet для распространения. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: поиска или использования существующих шаблонов (используйте обнаружение шаблонов и создание экземпляров шаблонов), проблем с файлами проекта MSBuild, не связанных с созданием шаблонов, публикации пакетов NuGet (только структура упаковки шаблонов).
