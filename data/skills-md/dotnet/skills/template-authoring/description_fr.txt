Guide la création et la validation de nouveaux modèles dotnet personnalisés. Génère des modèles à partir de projets existants et valide template.json pour les problèmes de création. UTILISER POUR : créer un nouveau modèle dotnet réutilisable à partir d'un projet existant, valider les fichiers template.json pour les problèmes de conformité de schéma et de paramètres, amorcer .template.config/template.json avec l'identité, le nom court, les paramètres et les post-actions corrects, empaqueter les modèles en tant que packages NuGet pour la distribution. NE PAS UTILISER POUR : rechercher ou utiliser des modèles existants (utiliser la découverte de modèles et l'instanciation de modèles), les problèmes de fichiers de projet MSBuild sans rapport avec la création de modèles, la publication de packages NuGet (uniquement la structure d'empaquetage des modèles).
