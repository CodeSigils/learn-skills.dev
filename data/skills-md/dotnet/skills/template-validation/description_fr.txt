Valide l’exactitude des nouveaux modèles dotnet personnalisés avant la publication. Détecte les champs manquants, les bogues de paramètres, les conflits de noms courts, les problèmes de contraintes et les erreurs de création courantes qui provoquent l'échec silencieux des modèles. UTILISER POUR : vérifier les fichiers template.json pour les erreurs avant la publication ou le test, diagnostiquer pourquoi un modèle n'apparaît pas après l'installation, examiner les définitions des paramètres du modèle pour détecter les incompatibilités de type et les valeurs par défaut manquantes, trouver les conflits shortName avec les commandes CLI dotnet, valider la configuration post-action et des contraintes. NE PAS UTILISER POUR : rechercher ou utiliser des modèles existants (utiliser la découverte de modèles), créer des projets à partir de modèles (utiliser l'instanciation de modèles), créer des modèles à partir de projets existants (utiliser la création de modèles).
