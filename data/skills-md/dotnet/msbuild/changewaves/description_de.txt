Verwalten Sie MSBuild-Änderungswellen: Erstellen Sie neue Wellen, bedingen Sie Features hinter Opt-out-Flags, schreiben Sie Tests für Wave-Gate-Funktionen, dokumentieren Sie Änderungswellen in ChangeWaves.md und ziehen Sie abgelaufene Wellen zurück. Verwenden Sie diese Option, wenn Sie Änderungen hinzufügen, die eine Abmeldung erfordern, oder wenn Sie alte Änderungswellen auswechseln. Bei Änderungen, die eine für den Benutzer sichtbare Verhaltensänderung bewirken, sollte darüber nachgedacht werden, ob eine Änderungswelle verwendet werden soll.
