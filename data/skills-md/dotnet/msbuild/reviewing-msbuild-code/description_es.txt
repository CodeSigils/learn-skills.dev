Cubre compatibilidad con versiones anteriores, disciplina ChangeWave, rendimiento, reconocimiento de asignación, cobertura de pruebas, calidad de mensajes de error, registro, comparación de cadenas, superficie API, creación de objetivos, corrección multiplataforma, simplificación de código, simultaneidad, denominación, integración de SDK, integridad del modelo de evaluación, corrección, gestión de dependencias, seguridad y construcción de infraestructura.
