Просматривает изменения кода MSBuild с использованием 24-мерной методологии. Активируется для проверки кода, PR-проверки, анализа запросов на включение, проверки дизайна, проверки архитектуры, оценки качества кода или проверки стиля кода MSBuild. Охватывает обратную совместимость, дисциплину ChangeWave, производительность, осведомленность о распределении, тестовое покрытие, качество сообщений об ошибках, ведение журнала, сравнение строк, поверхность API, целевую разработку, кроссплатформенную корректность, упрощение кода, параллелизм, именование, интеграцию SDK, целостность модели оценки, корректность, управление зависимостями, безопасность и построение инфраструктуры.
