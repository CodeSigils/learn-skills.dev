Aktualisieren Sie das HAL+JSON-Versionsinformationsdiagramm, wenn neue .NET-Versionen ausgeliefert werden. Generiert Indexdateien über die Versionshierarchie (Root → Haupt → Patch), die Zeitachsenhierarchie (Zeitachse → Jahr → Monat), llms.json und Downloads mithilfe von Diagrammgeneratortools neu. VERWENDUNG FÜR: Hinzufügen einer neuen Patch-Version zum Diagramm, Hinzufügen einer neuen Hauptversion, Aktualisieren von Timeline-Einträgen nach einer Veröffentlichung, Aktualisieren des Diagramms nach Änderungen an Quelldaten. NICHT VERWENDEN FÜR: unterstützte-os.json-Änderungen (verwenden Sie den Update-supported-os-Skill), das Abfragen des Diagramms (verwenden Sie den dotnet-releases-Skill im Release-Index-Zweig), das manuelle Bearbeiten generierter Diagrammdateien (Quelldaten aktualisieren und neu generieren).
