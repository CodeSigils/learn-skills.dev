Обновляйте график информации о выпусках HAL+JSON при выпуске новых выпусков .NET. Восстанавливает индексные файлы по иерархии версий (корневой → основной → исправление), иерархии временной шкалы (временная шкала → год → месяц), llms.json и загружает с помощью инструментов генератора графов. ИСПОЛЬЗОВАНИЕ ДЛЯ: добавления нового выпуска патча в график, добавления новой основной версии, обновления записей временной шкалы после выпуска, обновления графика после изменения исходных данных. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: изменений в файле support-os.json (используйте навык update-supported-os), запроса графа (используйте навык dotnet-releases в ветке индекса выпуска), редактирования сгенерированных файлов графиков вручную (обновляйте исходные данные и перегенерируйте).
