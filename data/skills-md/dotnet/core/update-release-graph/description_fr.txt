Mettez à jour le graphique d’informations sur la version HAL+JSON lorsque de nouvelles versions .NET sont livrées. Régénère les fichiers d'index dans la hiérarchie des versions (racine → majeure → correctif), la hiérarchie de la chronologie (chronologie → année → mois), llms.json et les téléchargements à l'aide d'outils générateurs de graphiques. UTILISER POUR : ajouter une nouvelle version de correctif au graphique, ajouter une nouvelle version majeure, mettre à jour les entrées de la chronologie après une version, actualiser le graphique après des modifications des données sources. NE PAS UTILISER POUR : les modifications prises en charge par os.json (utilisez la compétence update-supported-os), l'interrogation du graphique (utilisez la compétence dotnet-releases sur la branche release-index), la modification manuelle des fichiers graphiques générés (mettre à jour les données sources et régénérer).
