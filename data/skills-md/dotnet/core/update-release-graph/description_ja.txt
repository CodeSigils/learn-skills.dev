新しい .NET リリースが出荷されると、HAL+JSON リリース情報グラフを更新します。グラフ ジェネレーター ツールを使用して、バージョン階層 (ルート → メジャー → パッチ)、タイムライン階層 (タイムライン → 年 → 月)、llms.json、およびダウンロードにわたってインデックス ファイルを再生成します。用途: グラフへの新しいパッチ リリースの追加、新しいメジャー バージョンの追加、リリース後のタイムライン エントリの更新、ソース データ変更後のグラフの更新。次の目的には使用しないでください:supported-os.json の変更 (update-supported-os スキルを使用)、グラフのクエリ (release-index ブランチで dotnet-releases スキルを使用)、生成されたグラフ ファイルの手動編集 (ソース データを更新して再生成)。
