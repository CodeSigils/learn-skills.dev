새 .NET 릴리스가 출시되면 HAL+JSON 릴리스 정보 그래프를 업데이트합니다. 버전 계층(루트 → 주요 → 패치), 타임라인 계층(타임라인 → 연도 → 월), llms.json 전반에 걸쳐 인덱스 파일을 재생성하고 그래프 생성 도구를 사용하여 다운로드합니다. 사용 대상: 그래프에 새 패치 릴리스 추가, 새 주요 버전 추가, 릴리스 후 타임라인 항목 업데이트, 소스 데이터 변경 후 그래프 새로 고침. 사용하지 마십시오: support-os.json 변경(update-supported-os 기술 사용), 그래프 쿼리(release-index 분기에서 dotnet-releases 기술 사용), 생성된 그래프 파일을 직접 편집(소스 데이터 업데이트 및 재생성).
