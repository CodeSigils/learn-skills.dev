Aggiorna il grafico delle informazioni sulla versione HAL+JSON quando vengono fornite nuove versioni di .NET. Rigenera i file di indice nella gerarchia delle versioni (root → principale → patch), gerarchia della sequenza temporale (sequenza temporale → anno → mese), llms.json e download utilizzando strumenti di generazione di grafici. UTILIZZARE PER: aggiungere una nuova patch al grafico, aggiungere una nuova versione principale, aggiornare le voci della sequenza temporale dopo un rilascio, aggiornare il grafico dopo le modifiche ai dati di origine. NON UTILIZZARE PER: modifiche Supported-os.json (utilizzare la competenza update-supported-os), eseguire query sul grafico (utilizzare la competenza dotnet-releases sul ramo release-index), modificare manualmente i file del grafico generati (aggiornare i dati di origine e rigenerare).
