Laden Sie .NET-APIs für einen bestimmten Build oder eine bestimmte Version herunter, prüfen Sie sie und vergleichen Sie sie. Verwenden Sie „dotnet-inspect“, um zu überprüfen, ob APIs tatsächlich in den versendeten Paketen vorhanden sind, verpasste Zurücksetzungen zu erkennen und Vorher/Nachher-API-Unterschiede zu generieren. Verwenden Sie „RunApiDiff.ps1“, wenn ein vollständiger Markdown-Diff-Bericht benötigt wird.
