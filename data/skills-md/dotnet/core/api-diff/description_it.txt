Scarica, esamina e confronta le API .NET per una determinata build o versione. Utilizza "dotnet-inspect" per verificare che le API esistano effettivamente nei pacchetti spediti, rilevare ripristini mancati e generare differenze API prima/dopo. Utilizza "RunApiDiff.ps1" quando è necessario un rapporto completo sulle differenze di markdown.
