Descargue, inspeccione y diferencie las API de .NET para una compilación o versión determinada. Utilice `dotnet-inspect` para verificar que las API realmente existan en los paquetes enviados, detectar reversiones perdidas y generar diferencias de API antes/después. Utilice `RunApiDiff.ps1` cuando necesite un informe completo de diferencias de rebajas.
