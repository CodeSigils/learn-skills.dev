Téléchargez, inspectez et comparez les API .NET pour une version ou une version donnée. Utilisez « dotnet-inspect » pour vérifier que les API existent réellement dans les packages expédiés, détecter les retours manqués et générer des différences d'API avant/après. Utilisez « RunApiDiff.ps1 » lorsqu'un rapport de comparaison complet est nécessaire.
