قم بتنزيل واجهات برمجة تطبيقات .NET وفحصها وتمييزها لبناء أو إصدار معين. استخدم "dotnet-inspect" للتحقق من وجود واجهات برمجة التطبيقات (APIs) بالفعل في الحزم التي تم شحنها، واكتشاف عمليات الإرجاع الفائتة، وإنشاء اختلافات قبل/بعد واجهة برمجة التطبيقات (API). استخدم RunApiDiff.ps1 عندما تكون هناك حاجة إلى تقرير فرق تخفيض السعر الكامل.
