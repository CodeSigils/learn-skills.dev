Évalue les tests ajoutés dans un PR pour la couverture, la qualité, les cas extrêmes et la pertinence du type de test. Vérifie si les tests couvrent le correctif, détecte les lacunes et recommande des types de tests plus légers lorsque cela est possible. Préférez les tests unitaires aux tests d’appareils plutôt qu’aux tests d’interface utilisateur. Déclencheurs sur : « évaluer les tests en PR », « examiner la qualité des tests », « ces tests sont-ils assez bons », « vérifier la couverture des tests », « ce test est-il adéquat », « évaluer la couverture des tests en PR ».
