Istruzioni per la modernizzazione e il refactoring dei file di codice C#/VB.NET esistenti. Da utilizzare quando viene richiesto di eseguire il refactoring, modernizzare, pulire, rivedere o migliorare i file di origine esistenti in questo repository. Copre l'aggiornamento agli idiomi C# 14/.NET 10, la qualità dei commenti, le correzioni ortografiche e grammaticali, la documentazione XML e i miglioramenti della leggibilità.
