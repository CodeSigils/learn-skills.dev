قم بتحليل وتطبيق سمات المقالات عالية المستوى المستخرجة من المجموعة المرجعية المقطرة المحلية لكتابة واضحة للأطروحة الأولى. يُستخدم عندما يحتاج المساعد إلى صياغة أو مراجعة المقالات أو منشورات المدونات أو المذكرات أو النثر المليء بالحجج مع وضوح المحادثة والتمييزات الحادة والأمثلة الملموسة والقياسات المدمجة والتحذيرات الاختيارية ذات الحواشي السفلية. تطبيق السمات الهيكلية فقط؛ لا تقلد صوت بول جراهام الدقيق أو تعيد استخدام العبارات المميزة.
