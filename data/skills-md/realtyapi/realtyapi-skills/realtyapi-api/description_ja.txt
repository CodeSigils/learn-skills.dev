RealtyAPI REST API を使用して、世界中の 30 以上の不動産ポータルから不動産データを取得します。 Redfin、Realtor.com、Zillow、Trulia、Homes.com、Apartments.com、HotPads、Auction.com、StreetEasy (米国)、Centris (カナダ)、Rightmove、Zoopla (英国)、Idealista、SeLoger、Imbiliare、Immowelt、ImmoScout24、Funda、Otodom、Cian (欧州)、Bayut、Dubizzle、Property Finder (中) をカバーEast）、99.co（アジア）、Domain、Flatmates（オーストラリア）、Airbnb、Vrbo、Agoda、Trip.com、Tripadvisor（短期/休暇）。ユーザーが、不動産リスト、住宅/賃貸の詳細、価格または納税履歴、評価額と見積り、比較対象、市場と家賃の傾向、代理店、差し押さえ/競売、または住所、エリア、またはポータルの不動産データを検索、検索、フェッチ、または抽出するように要求する場合に使用します。ユーザーが RealtyAPI、不動産 API、MLS データ、または特定の不動産ポータルについて言及する場合にも使用します。
