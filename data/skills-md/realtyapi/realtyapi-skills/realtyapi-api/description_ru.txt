Получайте данные о недвижимости с более чем 30 порталов недвижимости по всему миру с помощью RealtyAPI REST API. Охватывает Redfin, Realtor.com, Zillow, Trulia, Homes.com, Apartments.com, HotPads, Auction.com, StreetEasy (США), Centris (Канада), Rightmove, Zoopla (Великобритания), Idealista, SeLoger, Immobiliare, Immowelt, ImmoScout24, Funda, Otodom, Cian (Европа), Bayut, Dubizzle, Property Finder (Ближний Восток), 99.co (Азия), Domain, Flatmate (Австралия) и Airbnb, Vrbo, Agoda, Trip.com, Tripadvisor (краткосрочный период/отпуск). Используйте, когда пользователь запрашивает поиск, поиск, получение или извлечение списков недвижимости, сведений о доме/аренде, истории цен или налогов, оценок и смет, сопоставимых данных, тенденций рынка и арендной платы, агентов, выкупа/аукционов или любых данных о недвижимости для адреса, района или портала. Также используйте, когда пользователь упоминает RealtyAPI, API недвижимости, данные MLS или конкретный портал недвижимости.
