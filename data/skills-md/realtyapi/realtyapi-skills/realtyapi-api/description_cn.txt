使用 RealtyAPI REST API 从全球 30 多个房地产门户获取房地产数据。涵盖 Redfin、Realtor.com、Zillow、Trulia、Homes.com、Apartments.com、HotPads、Auction.com、StreetEasy（美国）、Centris（加拿大）、Rightmove、Zoopla（英国）、Idealista、SeLoger、Immobiliare、Immowelt、ImmoScout24、Funda、Otodom、Cian（欧洲）、Baut、Dubizzle、Property Finder（中东）、 99.co（亚洲）、Domain、Flatmates（澳大利亚）和 Airbnb、Vrbo、Agoda、Trip.com、Tripadvisor（短期/度假）。当用户要求查找、搜索、获取或提取某个地址、区域或门户的房产列表、房屋/租赁详细信息、价格或税务历史、估价和估计、可比较、市场和租金趋势、代理、取消抵押品赎回权/拍卖或任何房地产数据时使用。当用户提及 RealtyAPI、房地产 API、MLS 数据或特定房地产门户时也可使用。
