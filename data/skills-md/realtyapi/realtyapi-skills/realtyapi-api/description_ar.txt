احصل على بيانات العقارات من أكثر من 30 بوابة عقارية حول العالم باستخدام RealtyAPI REST API. يغطي Redfin، Realtor.com، Zillow، Trulia، Homes.com، Apartments.com، HotPads، Auction.com، StreetEasy (الولايات المتحدة)، Centris (كندا)، Rightmove، Zoopla (المملكة المتحدة)، Idealista، SeLoger، Immobiliare، Immowelt، ImmoScout24، Funda، Otodom، Cian (أوروبا)، Bayut، Dubizzle، Property Finder (الشرق الأوسط)، 99.co (آسيا)، Domain، Flatmate (أستراليا)، وAirbnb، Vrbo، Agoda، Trip.com، Tripadvisor (مدى قصير/إجازة). يُستخدم عندما يطلب المستخدم البحث عن قوائم العقارات أو البحث عنها أو جلبها أو استخراجها، أو تفاصيل المنزل/الإيجار، أو تاريخ الأسعار أو الضرائب، أو التقييمات والتقديرات، أو المقارنات، أو اتجاهات السوق والإيجار، أو الوكلاء، أو حبس الرهن/المزادات، أو أي بيانات عقارية لعنوان أو منطقة أو بوابة. استخدمه أيضًا عندما يذكر المستخدم RealtyAPI، أو واجهة برمجة تطبيقات العقارات، أو بيانات MLS، أو بوابة عقارات محددة.
