Создайте ежедневный отчет о работе. Запускается, когда пользователь говорит «создать ежедневный отчет», «написать ежедневный отчет», «сегодняшний ежедневный отчет», «помогите мне написать рабочий ежедневный отчет» или «создать сегодняшнюю сводку работы». Сканируйте записи дневных коммитов всех репозиториев git в основном каталоге кода и создайте структурированный файл ежедневного отчета на китайском языке Markdown. Даже если пользователь просто упоминает «ежедневный отчет» или «сводку работы», этот навык следует использовать.
