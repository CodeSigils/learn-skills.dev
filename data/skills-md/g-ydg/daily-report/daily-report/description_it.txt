Genera un rapporto giornaliero di lavoro. Si attiva quando l'utente dice "genera report giornaliero", "scrivi report giornaliero", "report giornaliero di oggi", "aiutami a scrivere un report giornaliero di lavoro" o "genera il riepilogo del lavoro di oggi". Esegui la scansione dei record di commit giornalieri di tutti i repository git nella directory principale del codice e genera un file di report giornaliero strutturato in cinese Markdown. Anche se l'utente menziona solo "rapporto giornaliero" o "riepilogo del lavoro", questa abilità dovrebbe comunque essere utilizzata.
