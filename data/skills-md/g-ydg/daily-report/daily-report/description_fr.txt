Générez un rapport quotidien de travail. Déclenchez lorsque l'utilisateur dit « générer un rapport quotidien », « rédiger un rapport quotidien », « le rapport quotidien d'aujourd'hui », « aidez-moi à rédiger un rapport quotidien de travail » ou « générer le résumé du travail d'aujourd'hui ». Analysez les enregistrements de validation de la journée de tous les référentiels git sous le répertoire de code principal et générez un fichier de rapport quotidien structuré en chinois Markdown. Même si l'utilisateur mentionne uniquement « rapport quotidien » ou « résumé du travail », cette fonctionnalité doit être utilisée.
