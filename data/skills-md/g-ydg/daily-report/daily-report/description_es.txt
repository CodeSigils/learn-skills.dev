Generar un informe diario de trabajo. Se activa cuando el usuario dice "generar informe diario", "escribir informe diario", "informe diario de hoy", "ayúdame a escribir un informe diario de trabajo" o "generar resumen de trabajo de hoy". Escanee los registros de confirmación del día de todos los repositorios de git en el directorio de código principal y genere un archivo de informe diario de Markdown chino estructurado. Incluso si el usuario solo menciona "informe diario" o "resumen de trabajo", esta habilidad aún debe usarse.
