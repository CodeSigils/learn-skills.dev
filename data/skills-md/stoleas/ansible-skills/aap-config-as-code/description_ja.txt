AAP コンポーネントのコードとしてのインフラストラクチャ管理のために、infra.aap_configuration コレクションを使用して Ansible Automation Platform をコードとして構成します。このスキルは、ユーザーが「コードとしての AAP の設定」、「AAP 設定管理」、「オートメーション コントローラーの設定」、「Ansible による AAP の管理」、「コードとしての AAP インフラストラクチャ」、「オートメーション ハブの設定」、「EDA コントローラーの設定」を要求する場合、または Red Hat CoP コレクションを使用して AAP プラットフォームの設定を自動化したい場合に使用します。 AAP コードとしての構成ワークフローでは、常にこのスキルを呼び出します。
