Konfigurieren Sie Ansible Automation Platform als Code mithilfe der infra.aap_configuration-Sammlung für die Infrastructure-as-Code-Verwaltung von AAP-Komponenten. Verwenden Sie diese Fähigkeit, wenn der Benutzer Folgendes verlangt: „AAP als Code konfigurieren“, „AAP-Konfigurationsmanagement“, „Automatisierungscontroller konfigurieren“, „AAP mit Ansible verwalten“, „AAP-Infrastruktur als Code“, „Automatisierungshub konfigurieren“, „Eda-Controller konfigurieren“ oder die AAP-Plattformkonfiguration mithilfe der Red Hat CoP-Sammlungen automatisieren möchte. Rufen Sie diese Fähigkeit immer für AAP-Konfigurations-als-Code-Workflows auf.
