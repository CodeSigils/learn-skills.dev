Guider Claude à travers le développement piloté par les tests en utilisant le cycle de refactorisation rouge-vert. Utilisez cette compétence chaque fois que l'utilisateur souhaite écrire du code en premier, mentionne TDD, demande "d'écrire des tests avant l'implémentation", souhaite effectuer un refactor rouge-vert ou vous demande d'implémenter une fonctionnalité en commençant par des tests ayant échoué. Déclenchez également lorsque l'utilisateur dit des choses comme « faisons du TDD », « conduisons ceci avec des tests », « testons d'abord » ou « faisons en sorte que les tests réussissent ». Même s'ils disent simplement "ajouter une fonctionnalité" et que la base de code dispose déjà d'une suite de tests, pensez à suggérer TDD si cela convient naturellement.
