Guíe a Claude a través del desarrollo basado en pruebas utilizando el ciclo de refactor rojo-verde. Utilice esta habilidad siempre que el usuario quiera escribir código primero como prueba, mencione TDD, solicite "escribir pruebas antes de la implementación", quiera realizar una refactorización roja-verde o le pida que implemente una función comenzando con pruebas fallidas. También se activa cuando el usuario dice cosas como "hagamos TDD", "controle esto con pruebas", "prueba primero" o "haga que las pruebas pasen". Incluso si solo dicen "agregar una función" y el código base ya tiene un conjunto de pruebas, considere sugerir TDD si encaja de forma natural.
