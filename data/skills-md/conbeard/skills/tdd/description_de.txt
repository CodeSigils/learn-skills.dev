Führen Sie Claude durch die testgetriebene Entwicklung mithilfe des Rot-Grün-Refaktor-Zyklus. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer den Code zunächst testweise schreiben möchte, TDD erwähnt, darum bittet, „Tests vor der Implementierung zu schreiben“, eine Rot-Grün-Umgestaltung durchführen möchte oder Sie bittet, eine Funktion zu implementieren, indem Sie mit fehlgeschlagenen Tests beginnen. Wird auch ausgelöst, wenn der Benutzer Dinge sagt wie „Lass uns TDD machen“, „Fahre dies mit Tests“, „Teste zuerst“ oder „Lass die Tests bestehen“. Auch wenn sie nur „Funktion hinzufügen“ sagen und die Codebasis bereits über eine Testsuite verfügt, sollten Sie in Betracht ziehen, TDD vorzuschlagen, wenn es natürlich passt.
