Проведите Клода через разработку через тестирование, используя цикл «красный-зеленый-рефакторинг». Используйте этот навык всякий раз, когда пользователь хочет написать код сначала с тестированием, упоминает TDD, просит «написать тесты перед реализацией», хочет выполнить красно-зеленый рефакторинг или просит реализовать функцию, начиная с неудачных тестов. Также срабатывает, когда пользователь говорит такие вещи, как «давайте сделаем TDD», «проведите это с помощью тестов», «сначала тестируйте» или «проведите тесты». Даже если они просто говорят «добавьте функцию», а в базе кода уже есть набор тестов, подумайте о том, чтобы предложить TDD, если это естественно.
