Канонические имена событий и свойства для всей аналитики PostHog в KairoFit. Используйте этот навык, когда: добавляете любой аналитический вызов для отслеживания, реализуете захват событий PostHog, создаете отслеживание удержания, реализуете поток платного доступа или добавляете новые взаимодействия с пользователем, которые необходимо измерить. Задолженность по аналитике быстро растет — противоречивые названия событий в кодовой базе делают когортный анализ невозможным. Эту таксономию необходимо использовать для всех событий. Никогда не вводите необработанные строки имен событий в компонентах.
