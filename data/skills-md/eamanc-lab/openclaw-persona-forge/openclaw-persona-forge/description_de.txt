Schmieden Sie einen kompletten Lobster-Seelen-Plan für den OpenClaw AI Agent. Basierend auf Benutzerpräferenzen oder zufälligen Gacha-Ziehungen werden Identitätspositionierung, Seelenbeschreibung (SOUL.md), grundlegende Rollenregeln, Name und Aufforderung zur Avatar-Generierung ausgegeben. Wenn der Skill „baoyu-image-gen“ installiert ist, kann er automatisch Avatarbilder in einem einheitlichen Stil generieren. Verwenden Sie dies, wenn der Benutzer eine OpenClaw-Hummerseele erstellen, entwerfen oder anpassen muss. Gilt nicht für: Feinabstimmung eines vorhandenen SOUL.md, Charakterdesign auf Nicht-OpenClaw-Plattformen, reine Tool-Agenten ohne Persönlichkeit.
