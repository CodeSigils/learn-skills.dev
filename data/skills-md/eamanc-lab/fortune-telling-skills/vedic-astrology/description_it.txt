Un analizzatore di astrologia vedica (Jyotish) basato sulla tradizione indiana Jyotish, che utilizza il sistema siderale
zodiaco per leggere i temi natali. Copre 27 Nakshatras (lunari dimore), il Vimshottari Dasha
(Periodo Maggiore) e il Navagraha (Nove Pianeti). Attivato quando gli utenti menzionano
"Astrologia vedica", "Jyotish", "Vedica", "Nakshatra", "Dasha" o "Astrologia indiana".
Ragionamento LLM puro per l'interpretazione (i grafici precisi richiedono un motore astronomico).
Non è richiesta alcuna API esterna.
Non applicabile a: oroscopi astrologici occidentali, BaZi, tarocchi, Zi Wei Dou Shu o altro
domini → utilizza invece il router fortune-hub.
