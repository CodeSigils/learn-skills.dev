Un analizador de astrología védica (Jyotish) basado en la tradición india Jyotish, utilizando el Sideral
Zodíaco para leer las cartas natales. Cubre 27 Nakshatras (Mansiones Lunares), el Vimshottari Dasha
(Período Mayor) y el Navagraha (Nueve Planetas). Se activa cuando los usuarios mencionan
"Astrología védica", "Jyotish", "védica", "Nakshatra", "Dasha" o "astrología india".
Razonamiento puro de LLM para interpretación (los gráficos precisos requieren un motor astronómico).
No se requiere API externa.
No aplicable para: horóscopos de astrología occidental, BaZi, tarot, Zi Wei Dou Shu u otros
dominios → utilice el enrutador Fortune-Hub en su lugar.
