Un analyseur d'astrologie védique (Jyotish) basé sur la tradition indienne Jyotish, utilisant le sidéral
zodiaque pour lire les thèmes de naissance. Couvre 27 Nakshatras (demeures lunaires), le Vimshottari Dasha
(Période majeure) et le Navagraha (Neuf Planètes). Déclenché lorsque les utilisateurs mentionnent
«Astrologie védique», «Jyotish», «Védique», «Nakshatra», «Dasha» ou «astrologie indienne».
Raisonnement pur LLM pour l'interprétation (des cartes précises nécessitent un moteur astronomique).
Aucune API externe requise.
Ne s'applique pas aux : horoscopes d'astrologie occidentale, BaZi, tarot, Zi Wei Dou Shu ou autres
domaines → utilisez plutôt le routeur Fortune-Hub.
