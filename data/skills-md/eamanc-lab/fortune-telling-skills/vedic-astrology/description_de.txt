Ein Analysegerät für vedische Astrologie (Jyotish), das auf der indischen Jyotish-Tradition basiert und das Sidereal verwendet
Sternzeichen zum Lesen von Geburtshoroskopen. Umfasst 27 Nakshatras (Mondvillen), die Vimshottari Dasha
(Hauptperioden-)System und die Navagraha (Neun Planeten). Wird ausgelöst, wenn Benutzer etwas erwähnen
„Vedische Astrologie“, „Jyotish“, „Vedisch“, „Nakshatra“, „Dasha“ oder „Indische Astrologie“.
Reine LLM-Argumentation zur Interpretation (präzise Karten erfordern eine astronomische Engine).
Keine externe API erforderlich.
Nicht anwendbar für: Horoskope der westlichen Astrologie, BaZi, Tarot, Zi Wei Dou Shu oder andere
Domänen → Verwenden Sie stattdessen den Fortune-Hub-Router.
