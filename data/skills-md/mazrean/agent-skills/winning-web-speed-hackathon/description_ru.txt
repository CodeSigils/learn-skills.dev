Оптимизирует намеренно медленные веб-приложения для достижения максимальных результатов Lighthouse на хакатоне Web Speed ​​(CyberAgent). Используйте при участии в WSH или при выполнении агрессивной оптимизации производительности внешнего интерфейса в приложениях React/Node.js с серверными модулями SQLite. Охватывает сокращение пакетов, оптимизацию изображений, основные веб-показатели, настройку сервера и известные ловушки конкуренции.
