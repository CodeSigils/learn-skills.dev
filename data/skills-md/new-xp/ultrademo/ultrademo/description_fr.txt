Créez une vidéo de démonstration commentée d'une application Web. À utiliser lorsque l'utilisateur demande une vidéo de démonstration, une vidéo de présentation du produit, une vidéo de lancement ou pour réexécuter/mettre à jour une vidéo existante. Prend une URL d'application + des informations d'identification de test + un résumé de contenu ; produit un MP4 (plus des variantes verticales/GIF) via scout -> point de contrôle de script -> capture -> TTS -> rendu.
