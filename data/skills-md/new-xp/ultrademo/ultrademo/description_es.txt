Cree un vídeo de demostración narrado de una aplicación web. Utilícelo cuando el usuario solicite un vídeo de demostración, un vídeo explicativo del producto, un vídeo de lanzamiento o para volver a ejecutar/actualizar uno existente. Toma la URL de una aplicación + credenciales de prueba + un resumen del contenido; produce un MP4 (más variantes verticales/GIF) mediante exploración -> punto de control del script -> captura -> TTS -> renderizado.
