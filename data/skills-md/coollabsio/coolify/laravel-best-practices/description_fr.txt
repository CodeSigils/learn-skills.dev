Appliquez cette compétence chaque fois que vous écrivez, révisez ou refactorisez du code PHP Laravel. Cela inclut la création ou la modification de contrôleurs, de modèles, de migrations, de demandes de formulaire, de politiques, de tâches, de commandes planifiées, de classes de service et de requêtes éloquentes. Déclencheurs pour les problèmes de performances N+1 et des requêtes, les stratégies de mise en cache, les modèles d'autorisation et de sécurité, la validation, la gestion des erreurs, la configuration des files d'attente et des tâches, les définitions de routes et les décisions architecturales. Utilisez également pour la révision du code Laravel et la refactorisation du code Laravel existant afin de suivre les meilleures pratiques. Couvre toute tâche impliquant des modèles de code PHP backend Laravel.
