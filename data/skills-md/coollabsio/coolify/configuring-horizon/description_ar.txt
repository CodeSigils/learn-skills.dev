استخدم هذه المهارة عندما يذكر المستخدم Horizon بالاسم في سياق Laravel. يغطي دورة حياة Horizon الكاملة: تثبيت Horizon (الأفق: التثبيت، إعداد Sail)، وتكوين config/horizon.php (كتل المشرف، وتعيينات قائمة الانتظار، واستراتيجيات الموازنة، وminProcesses/maxProcesses)، وإصلاح لوحة المعلومات (التفويض عبر Gate::define viewHorizon، والمقاييس الفارغة، والأفق: جدولة اللقطة)، واستكشاف مشكلات الإنتاج وإصلاحها (تعطل العمال، وطلب سلسلة المهلة، إشعارات LongWaitDetected، في انتظار التكوين). ويغطي أيضًا وضع العلامات على الوظائف وإسكاتها. لا تستخدمه مع قوائم انتظار Laravel العامة بدون Horizon أو SQS أو برامج تشغيل قاعدة البيانات، أو إعداد Redis المستقل، أو Linux المشرف، أو Telescope، أو تجميع المهام.
