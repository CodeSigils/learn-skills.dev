Utilisez cette compétence chaque fois que l'utilisateur mentionne Horizon par son nom dans un contexte Laravel. Couvre le cycle de vie complet d'Horizon : installation d'Horizon (horizon : installation, configuration de Sail), configuration de config/horizon.php (blocs de superviseur, affectations de files d'attente, stratégies d'équilibrage, minProcesses/maxProcesses), réparation du tableau de bord (autorisation via Gate : define viewHorizon, métriques vides, horizon : planification d'instantanés) et dépannage des problèmes de production (plantages du travailleur, commande de chaîne de délai d'attente, notifications LongWaitDetected, configuration d'attente). Couvre également le marquage des tâches et la mise sous silence. Ne pas utiliser pour les files d'attente Laravel génériques sans Horizon, SQS ou pilotes de base de données, configuration Redis autonome, superviseur Linux, Telescope ou traitement par lots de tâches.
