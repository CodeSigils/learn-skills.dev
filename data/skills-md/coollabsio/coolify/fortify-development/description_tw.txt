當使用者在 Laravel 中進行身份驗證時啟動。這包括登入、註冊、密碼重設、電子郵件驗證、雙重認證（2FA/TOTP/QR 代碼/恢復代碼）、設定檔更新、密碼確認或任何與驗證相關的路由和控制器。當使用者提及 Fortify、auth、身份驗證、登入、註冊、註冊、忘記密碼、驗證電子郵件、2FA 或引用 app/Actions/Fortify/、CreateNewUser、UpdateUserProfileInformation、FortifyServiceProvider、config/fortify.php 或 auth Guards 時啟動。 Fortify 是 Laravel 的與前端無關的身份驗證後端，用於註冊所有身份驗證路由和控制器。在建置 SPA 或無頭身份驗證、自訂登入重新導向、覆蓋 LoginResponse 等回應契約或設定登入限制時也可啟動。請勿啟動 Laravel Passport（OAuth2 API 令牌）、Socialite（OAuth 社交登入）或非身份驗證 Laravel 功能。
