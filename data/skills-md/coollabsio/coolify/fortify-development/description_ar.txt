يتم التنشيط عندما يعمل المستخدم على المصادقة في Laravel. يتضمن ذلك تسجيل الدخول، والتسجيل، وإعادة تعيين كلمة المرور، والتحقق من البريد الإلكتروني، والمصادقة الثنائية (رموز 2FA/TOTP/QR/رموز الاسترداد)، وتحديثات الملف الشخصي، وتأكيد كلمة المرور، أو أي مسارات ووحدات تحكم متعلقة بالمصادقة. قم بالتنشيط عندما يذكر المستخدم Fortify، أو auth، أو المصادقة، أو تسجيل الدخول، أو التسجيل، أو الاشتراك، أو نسيان كلمة المرور، أو التحقق من البريد الإلكتروني، أو 2FA، أو الإشارة إلى التطبيق/Actions/Fortify/، أو CreateNewUser، أو UpdateUserProfileInformation، أو FortifyServiceProvider، أو config/fortify.php، أو حراس المصادقة. Fortify هي الواجهة الخلفية لمصادقة الواجهة الأمامية لـ Laravel والتي تسجل جميع مسارات المصادقة ووحدات التحكم. يمكنك أيضًا التنشيط عند إنشاء SPA أو مصادقة بدون رأس، أو تخصيص عمليات إعادة توجيه تسجيل الدخول، أو تجاوز عقود الاستجابة مثل LoginResponse، أو تكوين تقييد تسجيل الدخول. لا تقم بالتنشيط لـ Laravel Passport (رموز OAuth2 API المميزة)، أو Socialite (تسجيل الدخول الاجتماعي عبر OAuth)، أو ميزات Laravel غير المصادقة.
