当用户在 Laravel 中进行身份验证时激活。这包括登录、注册、密码重置、电子邮件验证、双因素身份验证（2FA/TOTP/QR 代码/恢复代码）、配置文件更新、密码确认或任何与身份验证相关的路由和控制器。当用户提及 Fortify、auth、身份验证、登录、注册、注册、忘记密码、验证电子邮件、2FA 或引用 app/Actions/Fortify/、CreateNewUser、UpdateUserProfileInformation、FortifyServiceProvider、config/fortify.php 或 auth Guards 时激活。 Fortify 是 Laravel 的与前端无关的身份验证后端，用于注册所有身份验证路由和控制器。在构建 SPA 或无头身份验证、自定义登录重定向、覆盖 LoginResponse 等响应契约或配置登录限制时也可激活。请勿激活 Laravel Passport（OAuth2 API 令牌）、Socialite（OAuth 社交登录）或非身份验证 Laravel 功能。
