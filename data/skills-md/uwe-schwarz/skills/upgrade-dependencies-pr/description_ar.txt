قم بتحديث تبعيات مشروع JavaScript أو TypeScript أو Python إلى أحدث الإصدارات المنشورة، وقم بإزالة مواصفات JS semver المثبتة عندما يكون ذلك مناسبًا، وقم بتقييم تأثير الإصدار مقابل قاعدة التعليمات البرمجية وملاحظات الإصدار الرسمية، وتطبيق إصلاحات الترقية الصغيرة المطلوبة، وفتح مشكلات GitHub لأعمال المتابعة الأكبر أو الاختيارية، والانتهاء من خلال إنشاء فرع، والالتزام، والدفع، والعلاقات العامة. استخدمه عندما يُطلب منك ترقية التبعيات، أو تحديث الحزم، أو إلغاء تثبيت إصدارات التبعية، أو إرسال علاقات عامة لصيانة التبعية الشاملة.
