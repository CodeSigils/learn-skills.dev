Mettez à jour les dépendances d'un projet JavaScript, TypeScript ou Python avec les dernières versions publiées, supprimez les spécifications exactes du semver JS épinglées le cas échéant, évaluez l'impact de la version par rapport à la base de code et aux notes de version officielles, appliquez les petits correctifs de mise à niveau requis, ouvrez les problèmes GitHub pour un travail de suivi plus important ou facultatif, et terminez en créant une branche, une validation, un push et un PR. À utiliser lorsqu'on vous demande de mettre à niveau les dépendances, d'actualiser les packages, de désépingler les versions de dépendances ou d'envoyer un PR de maintenance des dépendances de bout en bout.
