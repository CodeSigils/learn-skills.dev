Aggiorna le dipendenze di un progetto JavaScript, TypeScript o Python alle ultime versioni pubblicate, rimuovi le specifiche esatte del semver JS bloccato quando appropriato, valuta l'impatto del rilascio rispetto alla codebase e alle note di rilascio ufficiali, applica le piccole correzioni di aggiornamento richieste, apri i problemi di GitHub per un lavoro di follow-up più ampio o facoltativo e termina creando un ramo, un commit, un push e un PR. Da utilizzare quando viene richiesto di aggiornare le dipendenze, aggiornare i pacchetti, sbloccare le versioni delle dipendenze o fornire un PR di manutenzione delle dipendenze end-to-end.
