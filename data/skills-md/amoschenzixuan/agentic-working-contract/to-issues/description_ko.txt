사양, 기능 문서, 대화 또는 임시 조사 결과를 통해 에이전트가 사용할 수 있는 GitHub 문제를 생성하세요. 사양 분해(서사시 + 계층화된 하위 문제)와 독립형 문제(단일 버그, 리팩터링, 기능)를 모두 처리합니다. 사용자가 /to-issues 또는 /to-issue를 호출하고 "이것을 문제로 분류", "이 사양에서 문제 만들기", "이 문제에 대한 문제 제출", "백로그로 변환"이라고 말하거나 대화에서 버그, 디자인 격차 또는 캡처할 가치가 있는 지연된 작업이 표면화될 때 사용합니다. 이는 /clear-issues에 대응되는 것으로, /clear-issues가 사용하는 백로그를 생성합니다.
