Überprüfen Sie den geänderten Code auf Wiederverwendung, Qualität und Effizienz und beheben Sie dann alle gefundenen Probleme. Verwenden Sie diese Option, wenn der Benutzer kürzlich geänderten Code bereinigen, vereinfachen oder überprüfen möchte. Startet drei parallele Überprüfungsagenten (Code-Wiederverwendung, Code-Qualität, Effizienz) und aggregiert Ergebnisse.
