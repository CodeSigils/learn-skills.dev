Guide de l'opérateur pour les workflows de création et d'exécution de configuration MCPLab. À utiliser lorsque les utilisateurs ont besoin d'aide pour écrire ou déboguer MCPLab eval YAML, exécuter des scénarios (préférer l'outil MCP `mcplab_run_eval` lorsqu'il est disponible ; repli de la CLI `mcplab run/app/report/results`), dépanner les échecs d'exécution (authentification, configuration, sélection de scénario, indicateurs numériques), interpréter les sorties dans `mcplab/results/evaluation-runs/*` (`results.json`, `summary.md`, `trace.jsonl`, `report.html`), ou comparer les performances de l'agent avec `--agents`.
