Guida operatore per la creazione e l'esecuzione di configurazioni MCPLab. Utilizzare quando gli utenti hanno bisogno di aiuto per scrivere o fare il debug dei file YAML di valutazione MCPLab, eseguire scenari (preferire lo strumento MCP `mcplab_run_eval` quando disponibile; fallback CLI `mcplab run/app/report/results`), risolvere i problemi di esecuzione (autenticazione, configurazione, selezione dello scenario, flag numerici), interpretare i risultati in `mcplab/results/evaluation-runs/*` (`results.json`, `summary.md`, `trace.jsonl`, `report.html`), o confrontare le prestazioni degli agenti con `--agents`. Si prega di rispondere sempre nella lingua dell'utente.
