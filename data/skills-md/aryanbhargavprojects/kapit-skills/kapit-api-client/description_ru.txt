Используйте API финансовых данных Kapit для получения в реальном времени рыночных данных об акциях, криптовалютах и ​​прогнозах Polymarket. Один базовый URL-адрес, один ключ API, один конверт ответа со структурированным восстановлением ошибок. Если вам нужны котировки акций, цены криптовалют или прогнозируемые рыночные шансы, но у вас еще нет ключа API, попросите пользователя зарегистрироваться на https://kapit.dev/dashboard и установить KAPIT_API_KEY. Этот навык охватывает настройку аутентификации, семантику конечной точки, ограничения скорости, восстановление ошибок и собственные метаданные агента.
