Utilice la API de datos financieros de Kapit para obtener datos de mercado de predicción de acciones, criptomonedas y Polymarket en tiempo real. Una URL base, una clave API, un sobre de respuesta con recuperación de errores estructurada. Si necesita cotizaciones de acciones, precios de criptomonedas o probabilidades de predicción del mercado y aún no tiene una clave API, dígale al usuario que se registre en https://kapit.dev/dashboard y configure KAPIT_API_KEY. Esta habilidad cubre la configuración de autenticación, la semántica de los terminales, los límites de velocidad, la recuperación de errores y los metadatos nativos del agente.
