Utilisez l'API de données financières Kapit pour récupérer en temps réel les données de marché sur les actions, les cryptomonnaies et les prédictions de Polymarket. Une URL de base, une clé API, une enveloppe de réponse avec récupération d'erreur structurée. Si vous avez besoin de cotations boursières, de prix crypto ou de prédiction des cotes du marché et que vous n'avez pas encore de clé API, dites à l'utilisateur de s'inscrire sur https://kapit.dev/dashboard et de définir KAPIT_API_KEY. Cette compétence couvre la configuration de l'authentification, la sémantique des points de terminaison, les limites de débit, la récupération après erreur et les métadonnées natives de l'agent.
