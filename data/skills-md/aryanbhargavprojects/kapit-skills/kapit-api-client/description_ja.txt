Kapit 財務データ API を使用して、リアルタイムの株式、仮想通貨、および Polymarket 予測市場データを取得します。 1 つのベース URL、1 つの API キー、構造化されたエラー回復機能を備えた 1 つの応答エンベロープ。株価、暗号通貨の価格、または予測市場オッズが必要で、API キーをまだ持っていない場合は、https://kapit.dev/dashboard にサインアップして KAPIT_API_KEY を設定するようにユーザーに伝えます。このスキルは、認証セットアップ、エンドポイント セマンティクス、レート制限、エラー回復、およびエージェント ネイティブ メタデータをカバーします。
