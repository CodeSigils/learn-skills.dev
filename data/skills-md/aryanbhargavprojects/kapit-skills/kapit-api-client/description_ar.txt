استخدم واجهة برمجة تطبيقات البيانات المالية Kapit لجلب بيانات سوق الأسهم والعملات المشفرة وتوقعات Polymarket في الوقت الفعلي. عنوان URL أساسي واحد، ومفتاح API واحد، ومغلف استجابة واحد مع استرداد الأخطاء المنظمة. إذا كنت بحاجة إلى أسعار الأسهم، أو أسعار العملات المشفرة، أو التنبؤ باحتمالات السوق ولم يكن لديك مفتاح API حتى الآن، فاطلب من المستخدم التسجيل على https://kapit.dev/dashboard وتعيين KAPIT_API_KEY. تغطي هذه المهارة إعداد المصادقة، ودلالات نقطة النهاية، وحدود المعدل، واسترداد الأخطاء، والبيانات التعريفية الأصلية للوكيل.
