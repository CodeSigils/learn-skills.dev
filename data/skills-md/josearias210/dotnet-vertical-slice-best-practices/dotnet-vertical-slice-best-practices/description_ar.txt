قم بتنفيذ وتطوير واجهات .NET الخلفية باستخدام شرائح رأسية، والتحقق الصريح ومعالجة الأخطاء، واستمرارية PostgreSQL، وعمليات ترحيل EF Core المخصصة، وحدود تكوين AppHost/API الواضحة، والإعدادات الافتراضية للحل المركزي من خلال Directory.Build.props وDirectory.Packages.props، وممارسات إنشاء/إصدار إصدارات GitHub لصور الواجهة الخلفية والمرحل. يُستخدم عندما يحتاج مساعد الترميز إلى إنشاء أو تغيير ميزات الواجهة الخلفية، أو نقاط النهاية، أو الأوامر، أو الاستعلامات، أو المعالجات، أو العقود، أو الثبات، أو عمليات الترحيل، أو تكوين بدء التشغيل، أو عناصر GitHub CI، أو سلوك الواجهة الخلفية .NET الحساسة للتحديث.
