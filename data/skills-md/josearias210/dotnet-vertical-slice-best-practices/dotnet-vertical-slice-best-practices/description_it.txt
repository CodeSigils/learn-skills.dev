Implementare ed evolvere backend .NET utilizzando sezioni verticali, convalida esplicita e gestione degli errori, persistenza PostgreSQL, migrazioni EF Core dedicate, confini chiari della composizione AppHost/API, impostazioni predefinite della soluzione centralizzata tramite Directory.Build.props e Directory.Packages.props e pratiche di creazione/versione di GitHub Actions per le immagini backend e di migrazione. Da utilizzare quando un assistente di codifica deve creare o modificare funzionalità di backend, endpoint, comandi, query, gestori, contratti, persistenza, migrazioni, composizione di avvio, artefatti CI GitHub o comportamento del backend .NET sensibile alla modernizzazione.
