Протестируйте полный цикл выставления счетов Credyt для конкретного продукта. Создает тестового клиента, пополняет его кошелек, отправляет событие использования и проверяет правильность взимания комиссий. Используйте это для повторной проверки продукта после внесения изменений на панели мониторинга, для независимого тестирования конкретного продукта или для устранения проблем с выставлением счетов. Обратите внимание, что /credyt:billing-setup автоматически запускает проверку — используйте этот навык, если хотите проверить без повторного запуска полной настройки.
