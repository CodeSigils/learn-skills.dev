Diseñe y desarrolle una NUEVA tarea trapstreet.run para evaluar un agente/habilidad/herramienta determinada: lo contrario de trapstreet-solution-scaffold (que crea una solución en función de una tarea existente). Genera las partes mecánicas (traptask.yaml, Judge.py/grader.py que coinciden con el contrato TRAPTASK_MANIFEST, el proceso de validación y procesamiento de build_cases.py) y guía las partes con mucho juicio a través de una entrevista estructurada (qué hace realmente este agente/habilidad, qué se considera correcto, de dónde viene la verdad sobre el terreno, cómo se hace que la puntuación no se pueda jugar), además de una lista de verificación de vulnerabilidades y trampas reales que ya se encontraron por las malas. Úselo siempre que el usuario quiera crear una nueva tarea de evaluación, convertir un agente/habilidad en un punto de referencia, diseñar casos de prueba para una herramienta o pregunte cosas como "¿podemos hacer una tarea a partir de esto?", "cómo evalúo a mi agente en trapstreet", "diseñar un punto de referencia para X", incluso si no dicen "tarea" o "tareas de trapstreet" por su nombre.
