Entwerfen und gerüsten Sie eine NEUE trapstreet.run-Aufgabe, um einen bestimmten Agenten/eine bestimmte Fähigkeit/ein bestimmtes Werkzeug zu evaluieren – das Gegenteil von trapstreet-solution-scaffold (das eine Lösung für eine vorhandene Aufgabe erstellt). Erzeugt die mechanischen Teile (traptask.yaml, Judge.py/grader.py passend zum TRAPTASK_MANIFEST-Vertrag, build_cases.pys Validate-then-Render-Pipeline) und führt die urteilsintensiven Teile durch ein strukturiertes Interview (was macht dieser Agent/diese Fähigkeit tatsächlich, was gilt als richtig, wo kommt die Grundwahrheit her, wie wird das Scoring unspielbar gemacht) sowie eine Checkliste mit echten Exploits und Fallstricken, die bereits auf die harte Tour gefunden wurden. Verwenden Sie es immer dann, wenn der Benutzer eine neue Bewertungsaufgabe erstellen, einen Agenten/Fähigkeit in einen Benchmark umwandeln, Testfälle für ein Tool entwerfen möchte oder Dinge fragt wie „Können wir daraus eine Aufgabe machen“, „Wie bewerte ich meinen Agenten auf Trapstreet“, „Entwerfen Sie einen Benchmark für X“ – auch wenn „Aufgabe“ oder „Trapstreet-Aufgaben“ nicht namentlich erwähnt werden.
