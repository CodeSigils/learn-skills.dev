Mémoire persistante pour les agents Claude Code avec une architecture agent-audit-rituel. L'utilisateur parle uniquement ; l'agent capture, audite, propose des promotions et écrit. Quatre couches : journaux quotidiens, cache dynamique (MEMORY.md), compétences de référence basées sur les rôles (Anthropic-native, invocable par l'utilisateur : false), règles canoniques. /close-day exécute le rituel d'audit en fin de journée. Isolation multi-projets via projets/<nom>/. Zéro dépendance externe.
