Übersetzen Sie EPUB-E-Books: Lesen Sie zunächst den gesamten Text, um eine einheitliche Terminologiedatenbank aufzubauen, und übersetzen Sie dann Kapitel für Kapitel. Erstellen Sie standardmäßig eine zweisprachige Version (die Übersetzung wird unter dem Original angezeigt). Sie können jedoch auch nur die Übersetzung behalten und diese optional in eine .epub-Datei packen. Verwenden Sie diese Fähigkeit, wenn der Benutzer ein Epub/Ebook übersetzen möchte – z. B. „Dieses Epub übersetzen“, „Dieses Buch ins Chinesische übersetzen“, „Ein zweisprachiges E-Book erstellen“, „E-Book übersetzen“, auch wenn er „epub“ oder „übersetzen“ nicht ausdrücklich erwähnt. Erstellt ein Geschwisterverzeichnis (z. B. book-dual / book-zh), das die Quellstruktur mit übersetzten HTML-Dateien widerspiegelt.

Bitte antworten Sie immer in der Sprache des Benutzers.
