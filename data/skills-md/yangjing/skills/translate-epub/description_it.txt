Traduci ebook EPUB: leggi prima l'intero testo per creare un database terminologico unificato, quindi traduci capitolo per capitolo; per impostazione predefinita, produci una versione bilingue (la traduzione visualizzata sotto l'originale), ma puoi anche conservare solo la traduzione e, facoltativamente, impacchettarla in un file .epub. Utilizza questa abilità quando l'utente desidera tradurre un epub/ebook, ad esempio "traduci questo epub", "traduci questo libro in cinese", "genera un ebook bilingue", "traduci ebook", anche se non menziona esplicitamente "epub" o "traduci". Produce una directory gemella (ad esempio, book-dual / book-zh) che rispecchia la struttura sorgente, con file HTML tradotti.

Si prega di rispondere sempre nella lingua dell'utente.
