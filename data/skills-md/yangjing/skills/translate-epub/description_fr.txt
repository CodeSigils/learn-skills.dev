Traduire des livres électroniques EPUB : lisez d'abord l'intégralité du texte pour créer une base de données terminologique unifiée, puis traduisez chapitre par chapitre ; par défaut, produisez une version bilingue (la traduction affichée sous l'original), mais vous pouvez également conserver uniquement la traduction et éventuellement la conditionner dans un .epub. Utilisez cette compétence lorsque l'utilisateur souhaite traduire un epub/ebook, par exemple « traduire cet epub », « traduire ce livre en chinois », « générer un ebook bilingue », « traduire un ebook », même s'il ne mentionne pas explicitement « epub » ou « traduire ». Produit un répertoire frère (par exemple, book-dual / book-zh) reflétant la structure source, avec les fichiers HTML traduits.

Veuillez toujours répondre dans la langue de l’utilisateur.
