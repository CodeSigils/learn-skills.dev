خبير AWS Bedrock AgentCore الشامل لنشر عملاء الذكاء الاصطناعي وإدارتهم على نطاق واسع. يُستخدم عند العمل مع أي خدمة AgentCore بما في ذلك البوابة، أو وقت التشغيل، أو الذاكرة، أو الهوية، أو مترجم التعليمات البرمجية، أو المتصفح، أو إمكانية المراقبة، أو سجل الوكيل، أو التقييمات. يغطي نشر الوكيل، وتكامل أداة MCP، وإدارة الاعتماد، واكتشاف الوكيل، وسير عمل الحوكمة، وتقييم الجودة الآلي. ضروري عندما يذكر المستخدم AgentCore، أو وقت تشغيل الوكيل، أو تسجيل الوكيل، أو تقييم الوكيل، أو بوابة MCP، أو وكيل النشر، أو تسجيل خادم MCP، أو اكتشاف الوكلاء، أو تقييم جودة الوكيل، أو بيانات اعتماد الوكيل، أو يريد إنشاء وكلاء الذكاء الاصطناعي أو نشرهم أو فهرستهم أو مراقبتهم على AWS.
