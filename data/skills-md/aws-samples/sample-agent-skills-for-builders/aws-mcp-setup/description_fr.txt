Configurez les serveurs AWS MCP pour la recherche de documentation et l'accès aux API. À utiliser lors de la configuration d'AWS MCP, de la configuration des outils de documentation AWS, du dépannage de la connectivité MCP ou lorsque l'utilisateur mentionne aws-mcp, awsdocs, la configuration uvx ou la configuration du serveur MCP. Couvre à la fois le serveur AWS MCP complet (avec informations d'identification uvx +) et la documentation MCP légère (aucune authentification requise).
