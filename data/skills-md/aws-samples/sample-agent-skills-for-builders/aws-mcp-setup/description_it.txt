Configura i server AWS MCP per la ricerca di documentazione e l'accesso API. Da utilizzare durante la configurazione di AWS MCP, la configurazione degli strumenti di documentazione AWS, la risoluzione dei problemi di connettività MCP o quando l'utente menziona aws-mcp, awsdocs, uvx setup o la configurazione del server MCP. Copre sia il server MCP AWS completo (con uvx + credenziali) sia il MCP con documentazione leggera (nessuna autenticazione richiesta).
