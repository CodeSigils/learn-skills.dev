Настройте серверы AWS MCP для поиска документации и доступа к API. Используйте при настройке AWS MCP, настройке инструментов документации AWS, устранении неполадок с подключением MCP или когда пользователь упоминает aws-mcp, awsdocs, настройку uvx или конфигурацию сервера MCP. Охватывает как полный сервер AWS MCP (с учетными данными uvx +), так и облегченную документацию MCP (авторизация не требуется).
