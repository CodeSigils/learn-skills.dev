تقييم مهارات وكيل الذكاء الاصطناعي عبر السلامة والجودة والموثوقية وكفاءة التكلفة. تدقيق المشكلات الأمنية (الأسرار، والحقن، وعمليات التثبيت غير الآمنة)، واختبار الصحة الوظيفية بمهارة مقابل بدون مهارة، وقياس دقة التشغيل، وتصنيف مقايضات فعالية التكلفة، وتتبع دورة حياة الإصدار، وإنشاء درجات موحدة. يُستخدم عند تقييم مهارة ما قبل التثبيت، أو تدقيق مهارات السوق، أو إثبات نجاح مهارتك من خلال الاختبارات الآلية، أو إعداد بوابات جودة CI/CD، أو مقارنة إصدارين من المهارات. ليس من أجل: تقييم أنظمة الوكيل الكاملة، أو اختبار المكونات الإضافية غير المهارية، أو قياس أداء وقت التشغيل، أو مراقبة سلوك وكيل الإنتاج.
