Búsqueda web a través de una puerta de enlace AWS Bedrock AgentCore, llamada con credenciales locales de AWS/IAM (SigV4), sin claves API ni tokens de portador. Úselo cuando el usuario solicite buscar en la web, buscar eventos actuales, encontrar información reciente/en línea o investigar temas que necesiten resultados web actualizados a través de su puerta de enlace AgentCore Web Search. Activadores: 'búsqueda de agentcore', 'buscar en la web con agentcore', 'búsqueda web', 'buscar', 'buscar en línea', 'lo último', 'noticias actuales sobre', 'investigación'. Requiere la CLI de agentcore-websearch instalada y una puerta de enlace ya aprovisionada (consulte README/AGENTS.md del proyecto); Esta habilidad no crea ni elimina recursos de AWS.
