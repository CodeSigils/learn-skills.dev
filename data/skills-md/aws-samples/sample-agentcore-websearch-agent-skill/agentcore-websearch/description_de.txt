Websuche über ein AWS Bedrock AgentCore Gateway, aufgerufen mit lokalen AWS/IAM-Anmeldeinformationen (SigV4) – keine API-Schlüssel oder Bearer-Tokens. Verwenden Sie diese Option, wenn der Benutzer das Web durchsuchen, aktuelle Ereignisse nachschlagen, aktuelle/Online-Informationen finden oder Themen recherchieren möchte, die aktuelle Webergebnisse über sein AgentCore-Websuche-Gateway benötigen. Auslöser – „Agentcore-Suche“, „Mit Agentcore im Internet suchen“, „Websuche“, „Nachschlagen“, „Online finden“, „Was gibt es Neues“, „Aktuelle Nachrichten über“, „Forschung“. Erfordert die Installation der agentcore-websearch-CLI und ein bereits bereitgestelltes Gateway (siehe README/AGENTS.md des Projekts); Dieser Skill erstellt oder löscht keine AWS-Ressourcen.
