Recherche sur le Web via une passerelle AWS Bedrock AgentCore, appelée avec des informations d'identification AWS/IAM locales (SigV4) — pas de clés API ni de jetons de support. À utiliser lorsque l'utilisateur demande à effectuer une recherche sur le Web, à rechercher des événements actuels, à trouver des informations récentes/en ligne ou à rechercher des sujets nécessitant des résultats Web à jour via sa passerelle de recherche Web AgentCore. Déclencheurs : "recherche agentcore", "rechercher sur le Web avec agentcore", "recherche sur le Web", "rechercher", "trouver en ligne", "quelles sont les dernières nouvelles", "actualités actuelles sur", "recherche". Nécessite l'installation de la CLI agentcore-websearch et une passerelle déjà provisionnée (voir le README/AGENTS.md du projet) ; cette compétence ne crée ni ne supprime de ressources AWS.
