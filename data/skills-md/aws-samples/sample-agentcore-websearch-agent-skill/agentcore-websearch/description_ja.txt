AWS Bedrock AgentCore Gateway 経由のウェブ検索。ローカル AWS/IAM 認証情報 (SigV4) を使用して呼び出されます。API キーやベアラー トークンは必要ありません。ユーザーが Web 検索、現在のイベントの検索、最近/オンライン情報の検索、または AgentCore Web Search ゲートウェイを介した最新の Web 結果が必要なトピックの調査を要求する場合に使用します。トリガー - 「agentcore 検索」、「agentcore で Web を検索」、「Web 検索」、「検索」、「オンラインで検索」、「最新情報」、「最新ニュース」、「リサーチ」。 Agentcore-websearch CLI がインストールされており、ゲートウェイがすでにプロビジョニングされている必要があります (プロジェクトの README/AGENTS.md を参照)。このスキルは AWS リソースを作成または削除しません。
