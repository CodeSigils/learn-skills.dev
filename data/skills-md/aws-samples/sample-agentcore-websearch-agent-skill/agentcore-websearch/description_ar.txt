البحث على الويب عبر بوابة AWS Bedrock AgentCore، التي يتم استدعاؤها باستخدام بيانات اعتماد AWS/IAM المحلية (SigV4) - بدون مفاتيح واجهة برمجة التطبيقات أو الرموز المميزة لحاملها. يُستخدم عندما يطلب المستخدم البحث في الويب، أو البحث عن الأحداث الجارية، أو العثور على معلومات حديثة/عبر الإنترنت، أو البحث عن موضوعات تحتاج إلى نتائج ويب محدثة من خلال بوابة بحث الويب AgentCore الخاصة بهم. المشغلات - "بحث Agentcore"، و"البحث في الويب باستخدام Agentcore"، و"بحث الويب"، و"البحث"، و"البحث عبر الإنترنت"، و"ما هو الأحدث"، و"الأخبار الحالية حول"، و"البحث". يتطلب تثبيت Agentcore-websearch CLI وتوفير بوابة بالفعل (راجع README/AGENTS.md الخاص بالمشروع)؛ لا تؤدي هذه المهارة إلى إنشاء موارد AWS أو حذفها.
