Ricerca sul Web tramite un gateway AWS Bedrock AgentCore, chiamato con credenziali AWS/IAM locali (SigV4) — senza chiavi API o token di connessione. Da utilizzare quando l'utente chiede di effettuare ricerche sul Web, cercare eventi attuali, trovare informazioni recenti/online o argomenti di ricerca che necessitano di risultati Web aggiornati tramite il gateway AgentCore Web Search. Trigger: "ricerca agentcore", "cerca sul Web con agentcore", "ricerca web", "cerca", "trova online", "quali sono le ultime novità", "notizie attuali su", "ricerca". Richiede la CLI agentcore-websearch installata e un gateway già predisposto (vedere README/AGENTS.md del progetto); questa competenza non crea né elimina risorse AWS.
