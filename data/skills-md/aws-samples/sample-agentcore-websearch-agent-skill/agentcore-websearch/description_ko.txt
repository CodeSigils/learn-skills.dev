API 키나 전달자 토큰 없이 로컬 AWS/IAM 자격 증명(SigV4)으로 호출되는 AWS Bedrock AgentCore 게이트웨이를 통한 웹 검색. 사용자가 AgentCore 웹 검색 게이트웨이를 통해 웹 검색, 현재 이벤트 조회, 최근/온라인 정보 찾기 또는 최신 웹 결과가 필요한 주제 조사를 요청할 때 사용합니다. 트리거 - 'agentcore 검색', 'agentcore로 웹 검색', '웹 검색', '조회', '온라인 찾기', '최신 소식', '현재 뉴스', '연구'. Agentcore-websearch CLI가 설치되어 있고 게이트웨이가 이미 프로비저닝되어 있어야 합니다(프로젝트의 README/AGENTS.md 참조). 이 기술은 AWS 리소스를 생성하거나 삭제하지 않습니다.
