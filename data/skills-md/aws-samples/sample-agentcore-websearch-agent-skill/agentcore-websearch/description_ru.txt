Поиск в Интернете через шлюз AWS Bedrock AgentCore, вызываемый с использованием локальных учетных данных AWS/IAM (SigV4) — без ключей API или токенов носителя. Используйте, когда пользователь просит выполнить поиск в Интернете, просмотреть текущие события, найти недавнюю/онлайн-информацию или исследовать темы, требующие актуальных веб-результатов через шлюз веб-поиска AgentCore. Триггеры - «поиск в агенте», «поиск в Интернете с помощью агента», «поиск в Интернете», «поиск», «найти в Интернете», «что самое последнее», «текущие новости», «исследования». Требуется установленный CLI Agentcore-websearch и уже подготовленный шлюз (см. README/AGENTS.md проекта); этот навык не создает и не удаляет ресурсы AWS.
