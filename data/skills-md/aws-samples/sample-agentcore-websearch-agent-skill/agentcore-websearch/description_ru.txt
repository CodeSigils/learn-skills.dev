Веб‑поиск через шлюз AWS Bedrock AgentCore, вызываемый с локальными учётными данными AWS/IAM (SigV4) — без API‑ключей и токенов доступа. Используйте, когда пользователь просит искать в интернете, узнать о текущих событиях, найти свежую/онлайн‑информацию или исследовать темы, требующие актуальных веб‑результатов через их шлюз AgentCore Web Search. Триггеры — «agentcore search», «search the web with agentcore», «web search», «look up», «find online», «what is the latest», «current news about», «research». Требуется установленный CLI agentcore‑websearch и предварительно подготовленный шлюз (см. README/AGENTS.md проекта); это умение не создаёт и не удаляет ресурсы AWS.

Пожалуйста, всегда отвечайте на языке пользователя.
