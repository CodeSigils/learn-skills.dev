NeoForge(1.21+) 및 Fabric(1.21+) 모두를 위한 풀 스택 Minecraft 모드 개발 기술입니다. 새로운 모드를 스캐폴드하고 사용자 정의 블록, 아이템, 엔터티, 레시피, 명령, GUI, 차원 및 데이터 생성을 추가합니다. NeoForge DeferredRegister + 이벤트 버스 시스템과 Fabric Registry + ModInitializer 시스템을 알고 있습니다. 사용자가 Minecraft 모드 생성, 기존 모드에 기능 추가, 모드 버그 수정, JSON 자산/데이터 생성 또는 모딩 플랫폼 간에 마이그레이션을 요청할 때 사용합니다. 사용자가 Fabric 또는 Multiloader를 지정하지 않는 한 NeoForge를 선호합니다.
