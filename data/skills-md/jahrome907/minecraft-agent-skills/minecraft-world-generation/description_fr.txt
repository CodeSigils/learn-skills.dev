Créez du contenu de génération mondiale personnalisé pour Minecraft 1.21.x, y compris des biomes personnalisés, des dimensions, des paramètres de bruit, des règles de surface, des fonctionnalités placées/configurées, des sculpteurs, des ensembles de structures et des modificateurs de biome. Couvre à la fois l'approche datapack uniquement (fichiers JSON worldgen) et l'approche mod-code (NeoForge BiomeModifiers, API Fabric BiomeModification, enregistrement worldgen basé sur le code avec DeferredRegister). Comprend des modèles JSON compacts et des vérifications de référence soutenues par un validateur pour les fichiers biome, dimension, placé_feature, configure_feature, structure, structure_set et biome_modifier. Cible Minecraft 1.21.x avec les mappages officiels Mojang. À utiliser lorsque l'utilisateur pose des questions sur la génération mondiale de Minecraft, les biomes personnalisés, le pack de données JSON pour les dimensions ou les fonctionnalités, ou la modification du biome basée sur un mod avec NeoForge ou Fabric.
