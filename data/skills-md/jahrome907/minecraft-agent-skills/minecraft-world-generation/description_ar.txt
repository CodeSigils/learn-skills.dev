قم بإنشاء محتوى عالمي مخصص لـ Minecraft 1.21.x بما في ذلك المناطق الأحيائية المخصصة والأبعاد وإعدادات الضوضاء وقواعد السطح والميزات الموضوعة/المكونة والنحاتين ومجموعات البنية ومعدلات المناطق الأحيائية. يغطي كلاً من منهج حزمة البيانات فقط (ملفات JSON العالمية) ومنهج الكود المعدل (NeoForge BiomeModifiers، وFabric BiomeModification API، وتسجيل Worldgen القائم على التعليمات البرمجية مع DeferredRegister). يتضمن أنماط JSON المدمجة والفحوصات المرجعية المدعومة بالمدقق لملفات المناطق الأحيائية، والأبعاد، والميزات_الموضعة، والميزات_المكونة، والبنية، ومجموعة_الهيكل، وملفات_معدل_الحيوية. يستهدف إصدار Minecraft 1.21.x باستخدام خرائط Mojang الرسمية. يُستخدم عندما يسأل المستخدم عن Minecraftworldgen، أو المناطق الأحيائية المخصصة، أو datapack JSON للأبعاد أو الميزات، أو تعديل المناطق الحيوية القائم على التعديل باستخدام NeoForge أو Fabric.
