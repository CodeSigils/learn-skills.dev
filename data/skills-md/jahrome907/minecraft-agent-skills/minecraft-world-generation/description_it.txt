Crea contenuti personalizzati per la generazione di mondi per Minecraft 1.21.x inclusi biomi personalizzati, dimensioni, impostazioni del rumore, regole di superficie, elementi posizionati/configurati, intagliatori, set di strutture e modificatori di biomi. Copre sia l'approccio solo datapack (file JSON worldgen) sia l'approccio mod-code (NeoForge BiomeModifiers, Fabric BiomeModification API, registrazione worldgen basata su codice con DeferredRegister). Include modelli JSON compatti e controlli di riferimento supportati dal validatore per i file bioma, dimensione, posizionato_feature, configurato_feature, struttura, struttura_set e biome_modifier. Ha come target Minecraft 1.21.x con mappature Mojang ufficiali. Da utilizzare quando l'utente richiede informazioni su Minecraft worldgen, biomi personalizzati, datapack JSON per dimensioni o funzionalità o modifica del bioma basata su mod con NeoForge o Fabric.
