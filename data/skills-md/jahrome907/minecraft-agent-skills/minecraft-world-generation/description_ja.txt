カスタム バイオーム、寸法、ノイズ設定、サーフェス ルール、配置/構成されたフィーチャ、カーバー、構造セット、バイオーム モディファイアーを含む、Minecraft 1.21.x 用のカスタム ワールド生成コンテンツを作成します。データパックのみのアプローチ (JSON worldgen ファイル) と MOD コード アプローチ (NeoForge BiomeModifiers、Fabric BiomeModification API、DeferredRegister によるコード駆動の worldgen 登録) の両方をカバーします。コンパクトな JSON パターンと、biome、dimension、placed_feature、configured_feature、structural、structural_set、および biome_modifier ファイルに対するバリデーターに裏付けられた参照チェックが含まれます。公式 Mojang マッピングを備えた Minecraft 1.21.x をターゲットとします。ユーザーが Minecraft の worldgen、カスタム バイオーム、ディメンションや機能のデータパック JSON、または NeoForge または Fabric を使用した MOD ベースのバイオームの変更について質問するときに使用します。
