Создавайте собственный контент для создания мира для Minecraft 1.21.x, включая собственные биомы, размеры, настройки шума, правила поверхности, размещенные/настроенные объекты, резчики, наборы структур и модификаторы биомов. Охватывает как подход только с пакетами данных (файлы генерации мира JSON), так и подход с мод-кодом (NeoForge BiomeModifiers, Fabric BiomeModification API, регистрацию генерации мира на основе кода с помощью DeferredRegister). Включает компактные шаблоны JSON и проверки ссылок на основе валидатора для файлов биома, измерения, размещенного_объекта, настроенного_объекта, структуры, структурного_набора и биом_модификатора. Ориентирован на Minecraft 1.21.x с официальными сопоставлениями Mojang. Используйте, когда пользователь спрашивает о создании мира Minecraft, пользовательских биомах, пакете данных JSON для размеров или функций или модификации биома на основе модов с помощью NeoForge или Fabric.
