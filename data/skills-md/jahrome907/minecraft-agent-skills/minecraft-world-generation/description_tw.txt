為 Minecraft 1.21.x 創建自訂世界生成內容，包括自訂生物群落、尺寸、噪音設定、表面規則、放置/配置的功能、雕刻者、結構集和生物群落修改器。涵蓋僅資料包方法（JSON worldgen 檔案）和 mod 程式碼方法（NeoForge BiomeModifiers、Fabric BiomeModification API、使用 DeferredRegister 進行程式碼驅動的 worldgen 註冊）。包括緊湊的 JSON 模式和驗證器支援的生物群系、維度、placed_feature、configured_feature、structural、structural_set 和 biome_modifier 文件的參考檢查。使用官方 Mojang 映射以 Minecraft 1.21.x 為目標。當使用者詢問有關 Minecraft 世界生成、自訂生物群落、維度或功能的資料包 JSON 或使用 NeoForge 或 Fabric 進行基於 mod 的生物群落修改時使用。
