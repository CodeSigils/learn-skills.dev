Создавайте и редактируйте пакеты ресурсов Minecraft для 1.21.x, включая пользовательские модели блоков, модели элементов, определения состояний блоков, текстуры (требования к формату PNG), sound.json, пользовательские шрифты, файлы анимации MCMETA, OptiFine CIT (текстуры пользовательских элементов) и формат package.mcmeta. Охватывает полную схему JSON модели блока/элемента (родительский элемент, текстуры, элементы, отображение, переопределения), многослойные элементы, текстуры графического интерфейса, спрайты графического интерфейса, языковые файлы, интеграцию шейдеров (основные шейдеры, Iris) и номера форматов пакетов для каждой версии 1.21.x. Используйте, чтобы настроить внешний вид и звучание Minecraft без модов.
