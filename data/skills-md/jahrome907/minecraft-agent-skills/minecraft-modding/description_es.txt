Habilidad de desarrollo de mods de Minecraft de pila completa para NeoForge (1.21+) y Fabric (1.21+). Crea nuevas modificaciones, agrega bloques personalizados, elementos, entidades, recetas, comandos, GUI, dimensiones y generación de datos. Conoce el sistema NeoForge DeferredRegister + event-bus y el sistema Fabric Registry + ModInitializer. Úselo cuando el usuario solicite crear un mod de Minecraft, agregar una función a un mod existente, corregir un error de mod, generar activos/datos JSON o migrar entre plataformas de modding. Prefiere NeoForge a menos que el usuario especifique Fabric o Multiloader.
