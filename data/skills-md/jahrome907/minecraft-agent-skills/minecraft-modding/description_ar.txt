مهارة تطوير تعديل Minecraft الكاملة لكل من NeoForge (1.21+) والنسيج (1.21+). يدعم التعديلات الجديدة، ويضيف الكتل والعناصر والكيانات والوصفات والأوامر وواجهات المستخدم الرسومية والأبعاد وتوليد البيانات المخصصة. يعرف نظام NeoForge DeferredRegister + ناقل الأحداث ونظام Fabric Registry + ModInitializer. يُستخدم عندما يطلب المستخدم إنشاء تعديل Minecraft، أو إضافة ميزة إلى تعديل حالي، أو إصلاح خطأ تعديل، أو إنشاء أصول/بيانات JSON، أو الترحيل بين منصات التعديل. تفضل NeoForge ما لم يحدد المستخدم Fabric أو Multiloader.
