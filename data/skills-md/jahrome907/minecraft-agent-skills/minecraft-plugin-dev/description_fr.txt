Développez des plugins de serveur Minecraft à l'aide de l'API Paper/Bukkit/Spigot pour Minecraft 1.21.x. Gère la création de plugins Paper avec JavaPlugin, les écouteurs d'événements avec @EventHandler, les commandes, les planificateurs (sync/async/Folia-safe), le conteneur de données persistantes (PDC), les composants de texte Adventure, l'intégration de l'économie Vault, la messagerie BungeeCord/Velocity, la configuration plugin.yml et paper-plugin.yml, la gestion de la configuration YAML et les API d'amélioration spécifiques à Paper. Cible toujours Paper API 1.21.x (Java 21) avec Gradle (Kotlin DSL). Les plugins s'exécutent uniquement côté serveur et ne nécessitent pas d'installation client. À utiliser lors de la création ou de la modification de plugins de serveur Minecraft, de l'utilisation des API Paper/Bukkit/Spigot ou du développement de fonctionnalités côté serveur impliquant des gestionnaires d'événements, des commandes ou une configuration plugin.yml.
