Sviluppa plug-in del server Minecraft utilizzando l'API Paper/Bukkit/Spigot per Minecraft 1.21.x. Gestisce la creazione di plug-in Paper con JavaPlugin, ascoltatori di eventi con @EventHandler, comandi, pianificatori (sync/async/Folia-safe), Persistent Data Container (PDC), componenti di testo Adventure, integrazione di Vault Economy, messaggistica BungeeCord/Velocity, configurazione plugin.yml e paper-plugin.yml, gestione della configurazione YAML e API di miglioramento specifiche di Paper. È sempre rivolto a Paper API 1.21.x (Java 21) con Gradle (Kotlin DSL). I plugin vengono eseguiti solo lato server e non richiedono l'installazione del client. Da utilizzare durante la creazione o la modifica di plug-in del server Minecraft, l'utilizzo delle API Paper/Bukkit/Spigot o lo sviluppo di funzionalità lato server che coinvolgono gestori di eventi, comandi o configurazione plugin.yml.
