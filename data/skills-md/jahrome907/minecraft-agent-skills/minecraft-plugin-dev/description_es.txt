Desarrolle complementos del servidor de Minecraft utilizando la API Paper/Bukkit/Spigot para Minecraft 1.21.x. Maneja la creación de complementos de Paper con JavaPlugin, detectores de eventos con @EventHandler, comandos, programadores (sync/async/Folia-safe), contenedor de datos persistentes (PDC), componentes de texto Adventure, integración económica de Vault, mensajería BungeeCord/Velocity, configuración de plugin.yml y paper-plugin.yml, administración de configuración YAML y API de mejora específicas de Paper. Siempre apunta a Paper API 1.21.x (Java 21) con Gradle (Kotlin DSL). Los complementos se ejecutan únicamente en el lado del servidor y no requieren instalación del cliente. Úselo al crear o modificar complementos del servidor de Minecraft, trabajar con las API de Paper/Bukkit/Spigot o desarrollar funciones del lado del servidor que involucren controladores de eventos, comandos o configuración de plugin.yml.
