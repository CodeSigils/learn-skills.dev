Entwickeln Sie Minecraft-Server-Plugins mit der Paper/Bukkit/Spigot-API für Minecraft 1.21.x. Behandelt die Erstellung von Paper-Plugins mit JavaPlugin, Ereignis-Listenern mit @EventHandler, Befehlen, Planern (sync/async/Folia-safe), Persistent Data Container (PDC), Adventure-Textkomponenten, Vault-Economy-Integration, BungeeCord/Velocity-Messaging, Plugin.yml- und Paper-plugin.yml-Konfiguration, YAML-Konfigurationsverwaltung und Paper-spezifischen Erweiterungs-APIs. Zielt immer auf Paper API 1.21.x (Java 21) mit Gradle (Kotlin DSL) ab. Plugins laufen nur serverseitig und erfordern keine Client-Installation. Wird verwendet, wenn Sie Minecraft-Server-Plugins erstellen oder ändern, mit Paper-/Bukkit-/Spigot-APIs arbeiten oder serverseitige Funktionen entwickeln, die Ereignishandler, Befehle oder die Plugin.yml-Konfiguration umfassen.
