Minecraft 1.21.x の Paper/Bukkit/Spigot API を使用して Minecraft サーバー プラグインを開発します。 JavaPlugin を使用した Paper プラグイン、@EventHandler を使用したイベント リスナー、コマンド、スケジューラー (同期/非同期/Folia セーフ)、永続データ コンテナー (PDC)、Adventure テキスト コンポーネント、Vault エコノミー統合、BungeeCord/Velocity メッセージング、plugin.yml および Paper-plugin.yml 構成、YAML 構成管理、Paper 固有の拡張 API の作成を処理します。 Gradle (Kotlin DSL) では常に Paper API 1.21.x (Java 21) をターゲットとします。プラグインはサーバー側でのみ実行され、クライアントのインストールは必要ありません。 Minecraft サーバー プラグインを作成または変更する場合、Paper/Bukkit/Spigot API を操作する場合、またはイベント ハンドラー、コマンド、または plugin.yml 設定に関連するサーバー側機能を開発する場合に使用します。
