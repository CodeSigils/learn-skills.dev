قم بتطوير المكونات الإضافية لخادم Minecraft باستخدام Paper/Bukkit/Spigot API لـ Minecraft 1.21.x. يتعامل مع إنشاء المكونات الإضافية للورق باستخدام JavaPlugin، ومستمعي الأحداث باستخدام @EventHandler، والأوامر، والمجدولين (sync/async/Folia-safe)، وحاوية البيانات المستمرة (PDC)، ومكونات نص المغامرة، وتكامل اقتصاد Vault، ومراسلة BungeeCord/Velocity، وتكوين plugin.yml وpaper-plugin.yml، وإدارة تكوين YAML، وواجهات برمجة تطبيقات التحسين الخاصة بالورق. يستهدف دائمًا Paper API 1.21.x (Java 21) مع Gradle (Kotlin DSL). تعمل المكونات الإضافية من جانب الخادم فقط ولا تتطلب تثبيت العميل. يُستخدم عند إنشاء المكونات الإضافية لخادم Minecraft أو تعديلها، أو العمل مع واجهات برمجة تطبيقات Paper/Bukkit/Spigot، أو تطوير ميزات من جانب الخادم تتضمن معالجات الأحداث، أو الأوامر، أو تكوين plugin.yml.
