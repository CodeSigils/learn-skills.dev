Minecraft 1.21.x용 Paper/Bukkit/Spigot API를 사용하여 Minecraft 서버 플러그인을 개발하세요. JavaPlugin을 사용한 Paper 플러그인 생성, @EventHandler를 사용한 이벤트 리스너, 명령, 스케줄러(sync/async/Folia-safe), 영구 데이터 컨테이너(PDC), Adventure 텍스트 구성 요소, Vault 경제 통합, BungeeCord/Velocity 메시징, 플러그인.yml 및 paper-plugin.yml 구성, YAML 구성 관리 및 Paper 관련 향상 API 생성을 처리합니다. 항상 Gradle(Kotlin DSL)을 사용하여 Paper API 1.21.x(Java 21)를 대상으로 합니다. 플러그인은 서버 측에서만 실행되며 클라이언트 설치가 필요하지 않습니다. Minecraft 서버 플러그인을 생성 또는 수정하거나, Paper/Bukkit/Spigot API로 작업하거나, 이벤트 핸들러, 명령 또는 플러그인.yml 구성과 관련된 서버 측 기능을 개발할 때 사용합니다.
