Разрабатывайте плагины сервера Minecraft с помощью API Paper/Bukkit/Spigot для Minecraft 1.21.x. Управляет созданием плагинов Paper с помощью JavaPlugin, прослушивателей событий с @EventHandler, команд, планировщиков (sync/async/Folia-safe), контейнера постоянных данных (PDC), текстовых компонентов Adventure, интеграции экономики Vault, обмена сообщениями BungeeCord/Velocity, конфигурации плагинов.yml и paper-plugin.yml, управления конфигурацией YAML и API-интерфейсов улучшения для Paper. Всегда нацелен на Paper API 1.21.x (Java 21) с Gradle (Kotlin DSL). Плагины работают только на стороне сервера и не требуют установки клиента. Используйте при создании или изменении серверных плагинов Minecraft, работе с API-интерфейсами Paper/Bukkit/Spigot или разработке серверных функций, включающих обработчики событий, команды или конфигурацию плагина.yml.
