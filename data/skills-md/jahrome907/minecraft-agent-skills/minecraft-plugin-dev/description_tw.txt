使用適用於 Minecraft 1.21.x 的 Paper/Bukkit/Spigot API 開發 Minecraft 伺服器插件。處理使用 JavaPlugin 建立 Paper 外掛程式、使用 @EventHandler 的事件偵聽器、命令、排程器（同步/非同步/Folia 安全性）、持久性資料容器 (PDC)、Adventure 文字元件、Vault 經濟整合、BungeeCord/Volicity 訊息傳遞、peloin.y 和 YA 配置。始終以 Paper API 1.21.x (Java 21) 和 Gradle (Kotlin DSL) 為目標。插件僅在伺服器端運行，不需要安裝客戶端。在建立或修改 Minecraft 伺服器外掛程式、使用 Paper/Bukkit/Spigot API 或開發涉及事件處理程序、命令或 plugin.yml 配置的伺服器端功能時使用。
