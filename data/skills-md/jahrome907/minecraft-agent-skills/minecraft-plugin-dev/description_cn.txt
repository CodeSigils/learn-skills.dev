使用适用于 Minecraft 1.21.x 的 Paper/Bukkit/Spigot API 开发 Minecraft 服务器插件。处理使用 JavaPlugin 创建 Paper 插件、使用 @EventHandler 的事件侦听器、命令、调度程序（同步/异步/Folia 安全）、持久数据容器 (PDC)、Adventure 文本组件、Vault 经济集成、BungeeCord/Velocity 消息传递、plugin.yml 和 paper-plugin.yml 配置、YAML 配置管理和 Paper 特定的增强 API。始终以 Paper API 1.21.x (Java 21) 和 Gradle (Kotlin DSL) 为目标。插件仅在服务器端运行，不需要安装客户端。在创建或修改 Minecraft 服务器插件、使用 Paper/Bukkit/Spigot API 或开发涉及事件处理程序、命令或 plugin.yml 配置的服务器端功能时使用。
