Installez, configurez et exploitez les serveurs Minecraft Java Edition pour 1.21.x sur les réseaux Paper, Purpur, Folia, Velocity et les déploiements modifiés (Fabric/NeoForge). Couvre la sélection du déploiement, les playbooks de réglage des performances, les opérations de plug-in, la configuration du proxy/transfert, les runbooks de sauvegarde et de récupération, le dépannage des incidents en direct, les modèles Docker/Pterodactyl et le renforcement de la sécurité. À utiliser pour l'infrastructure et les opérations du serveur, et non pour le développement de fonctionnalités de plugin ou de mod.
