Richten Sie Minecraft Java Edition-Server für 1.21.x in Paper-, Purpur-, Folia-, Velocity-Netzwerken und modifizierten (Fabric/NeoForge)-Bereitstellungen ein, konfigurieren und betreiben Sie sie. Behandelt die Bereitstellungsauswahl, Playbooks zur Leistungsoptimierung, Plugin-Vorgänge, Proxy-/Weiterleitungseinrichtung, Backup- und Wiederherstellungs-Runbooks, Live-Fehlerbehebung bei Vorfällen, Docker-/Pterodactyl-Muster und Sicherheitshärtung. Wird für die Serverinfrastruktur und den Serverbetrieb verwendet, nicht für die Entwicklung von Plugins oder Mod-Funktionen.
