Instale, configure y opere servidores Minecraft Java Edition para 1.21.x en redes Paper, Purpur, Folia, Velocity e implementaciones modificadas (Fabric/NeoForge). Cubre la selección de implementación, guías de ajuste del rendimiento, operaciones de complementos, configuración de proxy/reenvío, runbooks de copia de seguridad y recuperación, resolución de problemas de incidentes en vivo, patrones de Docker/Pterodactyl y refuerzo de la seguridad. Úselo para la infraestructura y las operaciones del servidor, no para el desarrollo de complementos o funciones de modificación.
