قم بإعداد وتكوين وتشغيل خوادم Minecraft Java Edition للإصدار 1.21.x عبر شبكات Paper وPurpur وFolia وVelocity وعمليات النشر المعدلة (Fabric/NeoForge). يغطي اختيار النشر، وأدلة تشغيل ضبط الأداء، وعمليات المكونات الإضافية، وإعداد الوكيل/إعادة التوجيه، وسجلات تشغيل النسخ الاحتياطي والاسترداد، واستكشاف أخطاء الحوادث المباشرة وإصلاحها، وأنماط Docker/Pterodactyl، وتشديد الأمان. يُستخدم للبنية الأساسية للخادم وعملياته، وليس لتطوير ميزات المكونات الإضافية أو التعديل.
