Paper、Purpur、Folia、Velocity ネットワーク、および MOD (Fabric/NeoForge) デプロイメント全体で 1.21.x 用の Minecraft Java Edition サーバーをセットアップ、構成、および操作します。デプロイメントの選択、パフォーマンス チューニング プレイブック、プラグインの操作、プロキシ/転送のセットアップ、バックアップとリカバリのランブック、ライブ インシデントのトラブルシューティング、Docker/テロダクティル パターン、セキュリティ強化をカバーします。プラグインや MOD 機能の開発ではなく、サーバー インフラストラクチャと運用に使用します。
