Écrivez des tests automatisés pour les mods et plugins Minecraft pour 1.21.x. Couvre les tests de jeu NeoForge (annotation (@GameTest, assertions GameTestHelper, placement de la structure de test), les tests de jeu Fabric (fabric-gametest-api-v1), les tests unitaires de logique non Minecraft avec JUnit 5, les tests de plug-in MockBukkit for Paper/Bukkit (serveur fictif, lecteur fictif, répartition d'événements, vérification d'inventaire), les tests d'intégration avec un serveur de test via Gradle et les flux de travail GitHub Actions CI qui exécutent GameTests sans tête. Comprend des modèles pour se moquer des registres, tester les gestionnaires d'événements, tester les commandes et le développement piloté par les tests pour les projets Minecraft. À utiliser lorsque l'utilisateur demande comment tester des mods ou des plugins Minecraft, écrire des GameTests, configurer MockBukkit ou configurer CI pour les projets Minecraft.
