1.21.x の Minecraft Mod とプラグインの自動テストを作成します。 NeoForge GameTests (@GameTest アノテーション、GameTestHelper アサーション、テスト構造の配置)、Fabric ゲーム テスト (fabric-gametest-api-v1)、JUnit 5 を使用した Minecraft 以外のロジックの単体テスト、Paper/Bukkit プラグイン テスト用の MockBukkit (モック サーバー、モック プレーヤー、イベント ディスパッチ、インベントリ チェック)、Gradle を介したテスト サーバーとの統合テスト、および実行される GitHub Actions CI ワークフローをカバーします。 GameTests をヘッドレスで実行します。レジストリのモック、イベント ハンドラーのテスト、コマンドのテスト、Minecraft プロジェクトのテスト駆動開発のパターンが含まれています。 Minecraft の MOD やプラグインのテスト、GameTest の作成、MockBukkit のセットアップ、または Minecraft プロジェクトの CI の構成についてユーザーが質問する場合に使用します。
