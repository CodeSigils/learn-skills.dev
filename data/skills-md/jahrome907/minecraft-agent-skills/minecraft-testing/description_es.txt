Escriba pruebas automatizadas para modificaciones y complementos de Minecraft para 1.21.x. Cubre NeoForge GameTests (@GameTest anotación, afirmaciones de GameTestHelper, ubicación de la estructura de prueba), pruebas de juegos de Fabric (fabric-gametest-api-v1), pruebas unitarias de lógica que no es de Minecraft con JUnit 5, pruebas de complementos MockBukkit para Paper/Bukkit (servidor simulado, reproductor simulado, envío de eventos, verificación de inventario), pruebas de integración con un servidor de pruebas a través de Gradle y flujos de trabajo de GitHub Actions CI que ejecutan GameTests. sin cabeza. Incluye patrones para simular registros, probar controladores de eventos, probar comandos y desarrollo basado en pruebas para proyectos de Minecraft. Úselo cuando el usuario pregunte sobre cómo probar mods o complementos de Minecraft, escribir GameTests, configurar MockBukkit o configurar CI para proyectos de Minecraft.
