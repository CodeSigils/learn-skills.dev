Написание автоматических тестов для модов и плагинов Minecraft для версии 1.21.x. Охватывает NeoForge GameTests (@GameTest, утверждения GameTestHelper, размещение тестовых структур), игровые тесты Fabric (fabric-gametest-api-v1), модульное тестирование логики, отличной от Minecraft, с помощью JUnit 5, MockBukkit для тестирования плагинов Paper/Bukkit (макет-сервер, макетный проигрыватель, диспетчеризация событий, проверка инвентаря), интеграционное тестирование с тестовым сервером через Gradle и выполняемые рабочие процессы GitHub Actions CI. GameTests без головы. Включает шаблоны для имитации реестров, обработчиков событий тестирования, команд тестирования и разработки через тестирование для проектов Minecraft. Используйте, когда пользователь спрашивает о тестировании модов или плагинов Minecraft, написании GameTests, настройке MockBukkit или настройке CI для проектов Minecraft.
