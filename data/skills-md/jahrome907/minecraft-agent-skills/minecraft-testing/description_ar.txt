اكتب اختبارات تلقائية لتعديلات Minecraft والمكونات الإضافية للإصدار 1.21.x. يغطي NeoForge GameTests (تعليق توضيحي @GameTest، وتأكيدات GameTestHelper، وموضع هيكل الاختبار)، واختبارات الألعاب النسيجية (fabric-gametest-api-v1)، واختبار الوحدة للمنطق غير الخاص بـMinecraft مع JUnit 5، وMockBukkit لاختبار المكونات الإضافية للورق/Bukkit (خادم وهمي، ومشغل وهمي، وإرسال الأحداث، وفحص المخزون)، واختبار التكامل مع خادم اختبار عبر Gradle، وسير عمل GitHub Actions CI الذي تشغيل GameTests بلا رأس. يتضمن أنماطًا للسجلات الساخرة، واختبار معالجات الأحداث، وأوامر الاختبار، والتطوير القائم على الاختبار لمشاريع Minecraft. يُستخدم عندما يسأل المستخدم عن اختبار تعديلات Minecraft أو المكونات الإضافية، أو كتابة GameTests، أو إعداد MockBukkit، أو تكوين CI لمشاريع Minecraft.
