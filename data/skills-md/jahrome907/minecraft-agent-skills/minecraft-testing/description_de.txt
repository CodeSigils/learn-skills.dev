Schreiben Sie automatisierte Tests für Minecraft-Mods und Plugins für 1.21.x. Behandelt NeoForge GameTests (@GameTest-Annotation, GameTestHelper-Assertionen, Teststrukturplatzierung), Fabric-Spieletests (fabric-gametest-api-v1), Unit-Tests von Nicht-Minecraft-Logik mit JUnit 5, MockBukkit für Paper/Bukkit-Plugin-Tests (Mock-Server, Mock-Player, Event-Dispatching, Inventarprüfung), Integrationstests mit einem Testserver über Gradle und GitHub Actions CI-Workflows, die GameTests kopflos ausführen. Enthält Muster zum Verspotten von Registrierungen, zum Testen von Ereignishandlern, zum Testen von Befehlen und zur testgetriebenen Entwicklung für Minecraft-Projekte. Verwenden Sie diese Option, wenn der Benutzer nach dem Testen von Minecraft-Mods oder -Plugins, dem Schreiben von GameTests, dem Einrichten von MockBukkit oder dem Konfigurieren von CI für Minecraft-Projekte fragt.
