1.21.x용 Minecraft 모드 및 플러그인에 대한 자동화된 테스트를 작성합니다. NeoForge GameTests(@GameTest 주석, GameTestHelper 어설션, 테스트 구조 배치), Fabric 게임 테스트(fabric-gametest-api-v1), JUnit 5를 사용한 비 Minecraft 로직 단위 테스트, Paper/Bukkit 플러그인 테스트용 MockBukkit(모의 서버, 모의 플레이어, 이벤트 디스패칭, 인벤토리 확인), Gradle을 통한 테스트 서버와의 통합 테스트, GameTest를 헤드리스로 실행하는 GitHub Actions CI 워크플로를 다룹니다. Minecraft 프로젝트를 위한 레지스트리 모의, 이벤트 핸들러 테스트, 명령 테스트 및 테스트 기반 개발을 위한 패턴이 포함되어 있습니다. 사용자가 Minecraft 모드 또는 플러그인 테스트, GameTest 작성, MockBukkit 설정 또는 Minecraft 프로젝트용 CI 구성에 관해 질문할 때 사용합니다.
