为 1.21.x 的 Minecraft 模组和插件编写自动化测试。涵盖 NeoForge GameTests（@GameTest 注释、GameTestHelper 断言、测试结构放置）、Fabric 游戏测试 (fabric-gametest-api-v1)、使用 JUnit 5 对非 Minecraft 逻辑进行单元测试、用于 Paper/Bukkit 插件测试的 MockBukkit（模拟服务器、模拟播放器、事件调度、库存检查）、通过 Gradle 与测试服务器进行集成测试，以及无头运行 GameTests 的 GitHub Actions CI 工作流程。包括用于模拟注册表、测试事件处理程序、测试命令和 Minecraft 项目的测试驱动开发的模式。当用户询问测试 Minecraft 模组或插件、编写 GameTests、设置 MockBukkit 或为 Minecraft 项目配置 CI 时使用。
