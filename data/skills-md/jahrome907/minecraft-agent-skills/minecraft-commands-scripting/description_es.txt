Escriba comandos básicos de Minecraft, scripts NBT, marcadores y cadenas de ejecución complejas para usar en bloques de comandos, chat o archivos de funciones .mc. Cubre la referencia completa de subcomandos de ejecución (como/en/en/posicionado/girado/enfrentado/anclado/si/a menos que/almacenar/ejecutar), argumentos del selector con todas las opciones de filtro, objetivos y operaciones del marcador, sintaxis de ruta NBT para entidades/bloques/almacenamiento, comandos de programación y carga forzada, componentes de texto JSON tellraw/título, barra de jefe, administración de equipos, comandos de modificación de elementos, comandos de atributos, efectos de partículas/reproducción de sonido y secuencias de comandos RCON. Apunta a Minecraft 1.21.x Edición Java. Úselo para trabajo solo con comandos; para sistemas completos de funciones/avances/recetas, utilice la habilidad minecraft-datapack en su lugar.
