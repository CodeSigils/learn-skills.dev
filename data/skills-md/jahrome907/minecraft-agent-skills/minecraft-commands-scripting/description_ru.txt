Создавайте стандартные команды Minecraft, сценарии NBT, табло и сложные цепочки выполнения для использования в командных блоках, чатах или файлах .mcfunction. Охватывает полную ссылку на подкоманду выполнения (как/в/в/позиционирован/повернут/лицом/привязана/если/если/сохранить/запустить), аргументы селектора со всеми параметрами фильтра, цели и операции табло, синтаксис пути NBT для сущностей/блоков/хранилища, команды расписания и принудительной загрузки, текстовые компоненты JSON Tellraw/title, босс-бар, управление командой, команды модификации элементов, команды атрибутов, эффекты частиц/воспроизведения звука и сценарии RCON. Предназначен для Minecraft 1.21.x Java Edition. Используйте для работы только с командами; для полнофункциональных систем/продвижений/рецептов вместо этого используйте навык minecraft-datapack.
