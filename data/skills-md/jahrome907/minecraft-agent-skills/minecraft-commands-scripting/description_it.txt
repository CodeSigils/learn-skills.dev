Scrivi comandi vanilla di Minecraft, script NBT, tabelloni segnapunti e catene di esecuzione complesse da utilizzare in blocchi di comandi, chat o file .mcfunction. Copre il riferimento completo ai sottocomandi di esecuzione (come/a/in/posizionato/ruotato/di fronte/ancorato/se/a meno che non/memorizza/esegui), argomenti del selettore con tutte le opzioni di filtro, obiettivi e operazioni del tabellone segnapunti, sintassi del percorso NBT per entità/blocchi/archiviazione, comandi di pianificazione e caricamento forzato, componenti di testo JSON tellraw/titolo, bossbar, gestione del team, comandi di modifica degli elementi, comandi degli attributi, effetti di particelle/riproduzione sonora e script RCON. Ha come target Minecraft 1.21.x Java Edition. Utilizzare per il lavoro basato solo sui comandi; per i sistemi di funzionalità/avanzamento/ricetta completi utilizzare invece l'abilità Minecraft-datapack.
