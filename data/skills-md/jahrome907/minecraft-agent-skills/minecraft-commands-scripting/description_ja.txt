コマンド ブロック、チャット、または .mcfunction ファイルで使用するための Minecraft バニラ コマンド、NBT スクリプト、スコアボード、および複雑な実行チェーンを作成します。完全な実行サブコマンド リファレンス (as/at/in/positioned/rotated/facing/anchored/if/unless/store/run)、すべてのフィルター オプションを含むセレクター引数、スコアボードの目的と操作、エンティティ/ブロック/ストレージの NBT パス構文、スケジュールおよび強制ロード コマンド、Tellraw/title JSON テキスト コンポーネント、ボスバー、チーム管理、アイテム変更コマンド、属性コマンド、パーティクル/プレイサウンド エフェクト、および RCON スクリプトをカバーします。 Minecraft 1.21.x Java Edition が対象です。コマンドのみの作業に使用します。フル機能/進歩/レシピ システムの場合は、代わりに Minecraft-datapack スキルを使用してください。
