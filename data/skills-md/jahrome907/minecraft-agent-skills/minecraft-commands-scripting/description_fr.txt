Écrivez des commandes Minecraft Vanilla, des scripts NBT, des tableaux de bord et des chaînes d'exécution complexes à utiliser dans des blocs de commande, des discussions ou des fichiers .mcfunction. Couvre la référence complète des sous-commandes d'exécution (as/at/in/positioned/rotated/facing/anchored/if/unless/store/run), les arguments du sélecteur avec toutes les options de filtre, les objectifs et les opérations du tableau de bord, la syntaxe du chemin NBT pour les entités/blocs/stockage, les commandes de planification et de chargement forcé, les composants de texte tellraw/title JSON, la barre de patron, la gestion d'équipe, les commandes de modification d'éléments, les commandes d'attribut, les effets de particules/playsound et les scripts RCON. Cible Minecraft 1.21.x Java Edition. À utiliser pour le travail sur commande uniquement ; pour les systèmes complets de fonctions/avancements/recettes, utilisez plutôt la compétence minecraft-datapack.
