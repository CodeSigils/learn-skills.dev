Créez des mods Minecraft ciblant simultanément NeoForge et Fabric à l'aide du framework d'architecture pour Minecraft 1.21.x. Couvre la structure du projet d'architecture (sous-projets communs/neoforge/fabric), l'annotation ExpectPlatform pour les implémentations spécifiques à la plate-forme, le registre partagé via l'API d'enregistrement d'Architectury, les points d'entrée spécifiques à la plate-forme, la configuration du plugin Gradle d'architecture-loom, gradle.properties pour les deux chargeurs, la publication multi-jar sur Modrinth et CurseForge et l'évitement des pièges courants lors du partage de code. Utilisez cette compétence lors de la création d'un mod qui doit s'exécuter à la fois sur NeoForge et Fabric avec une seule base de code partagée.
