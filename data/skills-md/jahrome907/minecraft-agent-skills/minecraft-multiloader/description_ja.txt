Minecraft 1.21.x のアーキテクチャ フレームワークを使用して、NeoForge と Fabric の両方をターゲットとする Minecraft Mod を同時にビルドします。 Architectury プロジェクトの構造 (common/neoforge/fabric サブプロジェクト)、プラットフォーム固有の実装のための ExpectPlatform アノテーション、Architectury の登録 API を介した共有レジストリ、プラットフォーム固有のエントリポイント、Architectury-loom Gradle プラグイン構成、両方のローダーの gradle.properties、Modrinth と CurseForge へのマルチ jar パブリッシュ、およびコード共有時の一般的な落とし穴の回避について説明します。このスキルは、単一の共有コードベースを使用して NeoForge と Fabric の両方で実行する必要がある MOD を構築するときに使用します。
