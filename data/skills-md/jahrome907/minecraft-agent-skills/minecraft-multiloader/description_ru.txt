Создавайте моды Minecraft, ориентированные как на NeoForge, так и на Fabric одновременно, используя платформу Architectury для Minecraft 1.21.x. Охватывает структуру проекта Architectury (подпроекты common/neoforge/fabric), аннотацию ExpectPlatform для реализаций, специфичных для платформы, общий реестр через API регистрации Architectury, точки входа для конкретной платформы, конфигурацию плагина Gradle для архитектуры, gradle.properties для обоих загрузчиков, публикацию нескольких jar-файлов в Modrinth и CurseForge, а также избежание распространенных ошибок при совместном использовании кода. Используйте этот навык при создании мода, который должен работать как на NeoForge, так и на Fabric, с единой общей кодовой базой.
