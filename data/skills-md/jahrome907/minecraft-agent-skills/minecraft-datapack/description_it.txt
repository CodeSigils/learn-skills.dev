Copre il formato completo del datapack: pack.mcmeta, file di funzioni (.mcfunction), avanzamenti, predicati, tabelle di bottino, modificatori di oggetti, sostituzioni di ricette, tag, tipi di danno, tipi di dimensione, sostituzioni di worldgen e set di strutture. Gestisce la sintassi delle funzioni, esegue catene di comandi, funzioni macro (1.20.2+), NBT di archiviazione, operazioni del tabellone segnapunti, trigger di avanzamento, numeri di formato del pacchetto e flusso di lavoro /ricarica. Non è richiesto Java o caricatore di mod: file JSON Vanilla puri e .mcfunction. Da utilizzare durante la creazione o la modifica di pacchetti dati Minecraft, la scrittura di file .mcfunction, la configurazione di tabelle di bottino o avanzamenti o qualsiasi sviluppo di pacchetti dati Vanilla che non necessita di caricatori di mod.
