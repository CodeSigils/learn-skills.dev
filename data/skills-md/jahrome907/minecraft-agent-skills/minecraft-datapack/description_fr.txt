Créez, modifiez et déboguer les packs de données Minecraft Vanilla pour 1.21.x. Couvre le format complet du pack de données : pack.mcmeta, fichiers de fonction (.mcfunction), avancées, prédicats, tables de butin, modificateurs d'objets, remplacements de recettes, balises, types de dégâts, types de dimensions, remplacements de génération mondiale et ensembles de structures. Gère la syntaxe des fonctions, exécute les chaînes de commandes, les fonctions de macro (1.20.2+), le stockage NBT, les opérations du tableau de bord, les déclencheurs d'avancement, les numéros de format de pack et le workflow /reload. Aucun chargeur Java ou mod requis : fichiers JSON et .mcfunction purement vanilla. À utiliser lors de la création ou de la modification de packs de données Minecraft, de l'écriture de fichiers .mcfunction, de la configuration de tables de butin ou d'avancées, ou de tout développement de packs de données Vanilla qui ne nécessite pas de chargeurs de mods.
