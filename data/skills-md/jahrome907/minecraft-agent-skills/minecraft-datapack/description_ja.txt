1.21.x 用の Minecraft バニラ データパックを作成、編集、デバッグします。完全なデータパック形式をカバーします:pack.mcmeta、関数ファイル (.mcfunction)、アドバンスト、述語、ルート テーブル、アイテム モディファイア、レシピ オーバーライド、タグ、ダメージ タイプ、ディメンション タイプ、worldgen オーバーライド、および構造セット。関数構文、コマンド チェーンの実行、マクロ関数 (1.20.2 以降)、ストレージ NBT、スコアボード操作、アドバンスト トリガー、パック フォーマット番号、および /reload ワークフローを処理します。 Java や MOD ローダーは必要ありません。純粋なバニラ JSON ファイルと .mcfunction ファイルが必要です。 Minecraft データパックの作成または編集、.mcfunction ファイルの作成、戦利品テーブルや進捗の構成、または MOD ローダーを必要としないバニラ データパックの開発の場合に使用します。
