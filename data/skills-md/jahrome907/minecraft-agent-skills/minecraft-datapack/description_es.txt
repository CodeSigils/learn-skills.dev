Cree, edite y depure paquetes de datos básicos de Minecraft para 1.21.x. Cubre el formato completo del paquete de datos: pack.mcmeta, archivos de funciones (.mcfunction), avances, predicados, tablas de botín, modificadores de elementos, anulaciones de recetas, etiquetas, tipos de daños, tipos de dimensiones, anulaciones de generación mundial y conjuntos de estructuras. Maneja la sintaxis de funciones, ejecuta cadenas de comandos, funciones macro (1.20.2+), almacenamiento NBT, operaciones de marcador, activadores de avance, números de formato de paquete y flujo de trabajo /recarga. No se requiere Java ni cargador de mods: archivos JSON y .mcfunction puros. Úselo al crear o editar paquetes de datos de Minecraft, escribir archivos de funciones .mc, configurar tablas de botín o avances, o cualquier desarrollo de paquetes de datos básicos que no necesite cargadores de mods.
