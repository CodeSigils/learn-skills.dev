قم بإنشاء وتحرير وتصحيح حزم بيانات Minecraft Vanilla لـ 1.21.x. يغطي تنسيق datapack الكامل: pack.mcmeta، وملفات الوظائف (.mcfunction)، والتطورات، والمسندات، وجداول الغنائم، ومعدلات العناصر، وتجاوزات الوصفات، والعلامات، وأنواع الضرر، وأنواع الأبعاد، وتجاوزات Worldgen، ومجموعات البنية. يتعامل مع بناء جملة الوظيفة، وتنفيذ سلاسل الأوامر، ووظائف الماكرو (1.20.2+)، وتخزين NBT، وعمليات لوحة النتائج، ومشغلات التقدم، وأرقام تنسيق الحزمة، و/إعادة تحميل سير العمل. لا يلزم وجود Java أو أداة تحميل mod - ملفات JSON و.mcfunction خالصة. يُستخدم عند إنشاء حزم بيانات Minecraft أو تحريرها، أو كتابة ملفات .mcfunction، أو تكوين جداول المسروقات أو عمليات التقدم، أو أي تطوير لحزمة بيانات Vanilla لا يحتاج إلى أدوات تحميل التعديل.
