Configurez des pipelines CI/CD, des flux de publication automatisés et de publication pour les mods et plugins Minecraft pour 1.21.x. Couvre les constructions de matrice d'actions GitHub pour NeoForge et Fabric, la publication automatisée sur Modrinth (via le plugin Minotaur Gradle) et CurseForge (via CurseForgegradle), les versions GitHub avec des artefacts JAR, les conventions de version sémantique pour les mods Minecraft, la génération CHANGELOG, Dependabot pour le wrapper Gradle et les mises à jour du plugin, la mise en cache de construction avec gradle/actions/setup-gradle, les vérifications de demandes d'extraction et les flux de travail des balises de publication. Couvre également le plugin Paper CI avec les versions Shadow JAR. À utiliser lorsque la tâche concerne les pipelines CI/CD, l'automatisation des versions, la publication d'artefacts, la gestion des versions ou la gouvernance des versions pour les mods ou plugins Minecraft.
