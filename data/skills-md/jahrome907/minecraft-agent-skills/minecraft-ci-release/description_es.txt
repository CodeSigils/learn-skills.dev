Configure canalizaciones de CI/CD, publicación automatizada y flujos de trabajo de lanzamiento para modificaciones y complementos de Minecraft para 1.21.x. Cubre compilaciones de matrices de acciones de GitHub para NeoForge y Fabric, publicación automatizada en Modrinth (a través del complemento Minotaur Gradle) y CurseForge (a través de curseforgegradle), lanzamientos de GitHub con artefactos JAR, convenciones de control de versiones semánticas para mods de Minecraft, generación de CHANGELOG, Dependabot para actualizaciones de complementos y envoltorios de Gradle, almacenamiento en caché de compilaciones con gradle/actions/setup-gradle, verificaciones de solicitudes de extracción y flujos de trabajo de etiquetas de lanzamiento. También cubre el complemento CI de Paper con compilaciones de JAR ocultos. Úselo cuando la tarea sea canalización de CI/CD, automatización de lanzamientos, publicación de artefactos, control de versiones o control de lanzamientos para mods o complementos de Minecraft.
