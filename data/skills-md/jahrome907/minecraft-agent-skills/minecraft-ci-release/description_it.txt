Configura pipeline CI/CD, pubblicazione automatizzata e flussi di lavoro di rilascio per mod e plug-in di Minecraft per 1.21.x. Copre build di matrici GitHub Actions per NeoForge e Fabric, pubblicazione automatizzata su Modrinth (tramite plugin Gradle minotaur) e CurseForge (tramite curseforgegradle), versioni GitHub con artefatti JAR, convenzioni di controllo delle versioni semantiche per mod Minecraft, generazione CHANGELOG, Dependabot per wrapper Gradle e aggiornamenti plugin, build caching con gradle/actions/setup-gradle, controlli delle richieste pull e flussi di lavoro dei tag di rilascio. Copre anche la CI del plugin Paper con build JAR shadow. Da utilizzare quando l'attività riguarda pipeline CI/CD, automazione dei rilasci, pubblicazione di artefatti, controllo delle versioni o governance dei rilasci per mod o plug-in di Minecraft.
