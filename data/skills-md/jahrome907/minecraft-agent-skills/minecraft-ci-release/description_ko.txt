1.21.x용 Minecraft 모드 및 플러그인에 대한 CI/CD 파이프라인, 자동 게시 및 릴리스 워크플로를 설정합니다. NeoForge 및 Fabric용 GitHub Actions 매트릭스 빌드, Modrinth(minotaur Gradle 플러그인을 통해) 및 CurseForge(curseforgegradle을 통해)에 자동 게시, JAR 아티팩트가 포함된 GitHub 릴리스, Minecraft 모드에 대한 의미 체계 버전 관리 규칙, CHANGELOG 생성, Gradle 래퍼 및 플러그인 업데이트를 위한 종속봇, gradle/actions/setup-gradle을 사용한 빌드 캐싱, 풀 요청 확인 및 릴리스 태그 워크플로를 다룹니다. Shadow JAR 빌드가 포함된 Paper 플러그인 CI도 다룹니다. 작업이 CI/CD 파이프라인, 릴리스 자동화, 아티팩트 게시, 버전 관리 또는 Minecraft 모드 또는 플러그인에 대한 릴리스 거버넌스인 경우에 사용합니다.
