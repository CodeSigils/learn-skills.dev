CI/CD パイプライン、自動公開を設定し、1.21.x 用の Minecraft Mod とプラグインのワークフローをリリースします。 NeoForge および Fabric 用の GitHub Actions マトリックス ビルド、Modrinth (minotaur Gradle プラグイン経由) および CurseForge (curseforgegradle 経由) への自動公開、JAR アーティファクトを使用した GitHub リリース、Minecraft Mod のセマンティック バージョニング規則、CHANGELOG 生成、Gradle ラッパーとプラグインの更新用の依存ボット、gradle/actions/setup-gradle によるビルド キャッシュ、プル リクエストをカバーします。チェックとリリースタグのワークフロー。シャドウ JAR ビルドを使用した Paper プラグイン CI についても説明します。タスクが CI/CD パイプライン、リリースの自動化、アーティファクトの公開、バージョン管理、または Minecraft の MOD やプラグインのリリース ガバナンスである場合に使用します。
