Настройте конвейеры CI/CD, автоматическую публикацию и рабочие процессы выпуска модов и плагинов Minecraft для 1.21.x. Охватывает сборки матрицы действий GitHub для NeoForge и Fabric, автоматическую публикацию в Modrinth (через плагин Minotaur Gradle) и CurseForge (через CurseForgegradle), выпуски GitHub с артефактами JAR, соглашения семантического управления версиями для модов Minecraft, генерацию CHANGELOG, оболочку Dependabot для Gradle и обновления плагинов, кэширование сборок с помощью gradle/actions/setup-gradle, проверки запросов на извлечение и тег выпуска. рабочие процессы. Также рассматривается CI плагина Paper с теневыми сборками JAR. Используйте, когда задачей являются конвейеры CI/CD, автоматизация выпуска, публикация артефактов, управление версиями или управление выпусками модов или плагинов Minecraft.
