قم بإعداد مسارات CI/CD، والنشر الآلي، وإصدار سير العمل لتعديلات Minecraft والمكونات الإضافية للإصدار 1.21.x. يغطي إنشاءات مصفوفة GitHub Actions لـ NeoForge و Fabric، والنشر الآلي إلى Modrinth (عبر المكون الإضافي minotaur Gradle) وCurseForge (عبر Curseforgegradle)، وإصدارات GitHub مع عناصر JAR، واتفاقيات الإصدار الدلالي لتعديلات Minecraft، وتوليد CHANGELOG، وDependabot لـ Gradle المجمع وتحديثات المكونات الإضافية، وبناء التخزين المؤقت باستخدام gradle/actions/setup-gradle، وفحص طلبات السحب، و إطلاق سير عمل العلامة. يغطي أيضًا CI للمكون الإضافي للورق مع إنشاءات JAR الظل. يُستخدم عندما تكون المهمة عبارة عن خطوط أنابيب CI/CD، أو أتمتة الإصدار، أو نشر العناصر، أو تعيين الإصدارات، أو إدارة الإصدار لتعديلات Minecraft أو المكونات الإضافية.
