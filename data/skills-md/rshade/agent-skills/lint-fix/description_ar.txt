اكتشف أدوات فحص المشروع والتحقق من صحته، وقم ببناء مسار التنفيذ، وقم بتشغيل جميع الأدوات حتى لا تكون هناك أخطاء، وأصلح المشكلات باستخدام بروتوكول الإصلاح الذري. يكتشف تلقائيًا أهداف Makefile والبرامج النصية package.json وأدوات Go وأدوات Python وغيرها من أدوات الفحص الشائعة. يُستخدم عند إصلاح أخطاء الفحص، أو تشغيل مسارات التحقق من الصحة، أو ضمان جودة التعليمات البرمجية قبل الالتزام.
