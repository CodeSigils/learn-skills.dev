Проверьте файлы рабочего процесса GitHub Actions на наличие синтаксических ошибок, недопустимых ссылок и распространенных ошибок. Автоматически обнаруживает двоичный файл actionlint или руководит установкой. Проверяет конфигурацию проекта или возвращается к разумным настройкам по умолчанию. Используйте при создании или изменении рабочих процессов GitHub Actions, проверке конвейеров CI/CD или обнаружении ошибок рабочего процесса перед отправкой.
