التحقق من صحة ملفات سير عمل GitHub Actions بحثًا عن أخطاء بناء الجملة والمراجع غير الصالحة والأخطاء الشائعة. يكتشف تلقائيًا تثبيت actionlint الثنائي أو يرشده. يتحقق من تكوين المشروع أو يعود إلى الإعدادات الافتراضية المعقولة. يُستخدم عند إنشاء أو تعديل سير عمل GitHub Actions، أو التحقق من صحة خطوط أنابيب CI/CD، أو اكتشاف أخطاء سير العمل قبل الدفع.
