Auditez une base de code par rapport aux principes de conception de logiciels bien connus : SOLID, DRY, YAGNI, KISS, loi de Déméter, séparation des préoccupations, composition sur héritage et sous-ensemble de 12 facteurs pertinent pour le code. Note les résultats en fonction de l'impact et de l'effort, mène un débat contradictoire sur les violations contestées et génère un DESIGN_AUDIT.md hiérarchisé. À utiliser lors de l'examen de la qualité du code au-delà de ce que les linters détectent, de l'évaluation de l'état de la conception avant une refactorisation ou de l'intégration dans une base de code inconnue. Peut être invoqué de manière autonome ou délégué à partir de la dette technologique.
