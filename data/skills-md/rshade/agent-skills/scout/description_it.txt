Regola dello scout: identifica le 3 principali opportunità di miglioramento di maggiore impatto nei file che stai già toccando. Analizza l'intero contenuto del file, non solo le righe modificate. Si concentra sulla qualità del codice preesistente, non sui bug delle pubbliche relazioni. Da utilizzare durante la preparazione di una PR, durante la revisione del codice o dopo aver completato una funzionalità.
