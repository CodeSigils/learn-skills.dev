Scout Rule : identifiez les 3 principales opportunités d'amélioration à plus fort impact dans les fichiers que vous touchez déjà. Analyse l'intégralité du contenu du fichier, pas seulement les lignes modifiées. Se concentre sur la qualité du code préexistant, et non sur les bogues de relations publiques. À utiliser lors de la préparation d'un PR, pendant la révision du code ou après avoir terminé une fonctionnalité.
