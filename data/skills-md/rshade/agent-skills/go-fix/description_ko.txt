Go 1.26+에서 다시 빌드된 go fix 명령을 사용하여 Go 코드를 현대화하세요. 최신 언어 및 stdlib 관용구에 안전한 버전 인식 재작성을 적용하고(인터페이스는 int 범위, 최소/최대, strings.Cut, new(expr) 및 20개 이상에 대한 3절 루프) 고정 지점까지 반복하고 나중에 빌드를 확인합니다. Go 코드를 현대화하거나 정리하거나 관용적으로 만들어야 할 때마다 사용하세요. go.mod 버전 변경 후, 이전 스타일 또는 AI 생성 패턴이 누적될 때, 더 이상 사용되지 않거나 이름이 변경된 API에서 호출자를 마이그레이션할 때(go:fix 인라인 지시어), 사용자가 go fix 또는 gofix를 언급할 때, 최신 관용어를 CI 게이트로 적용할 때 사용하세요. gofmt 형식 지정, 종속성 업그레이드 또는 수의사 버그 찾기에는 적합하지 않습니다.
