Модернизируйте код Go с помощью перестроенной команды go fix в Go 1.26+. Применяет безопасную перезапись с учетом версии к более новому языку и идиомам stdlib (interface{} к любому, циклы из 3 предложений для диапазона над целым, мин/макс, strings.Cut, new(expr) и еще 20), итерации до фиксированной точки и последующей проверки сборки. Используйте всякий раз, когда код Go необходимо модернизировать, очистить или сделать идиоматическим — после обновления версии go.mod, когда накапливаются старые шаблоны или шаблоны, созданные искусственным интеллектом, при переносе вызывающих объектов с устаревших или переименованных API (встроенные директивы go:fix), когда пользователь упоминает go fix или gofix или для применения современных идиом в качестве шлюза CI. Не для форматирования gofmt, обновления зависимостей или поиска ошибок.
