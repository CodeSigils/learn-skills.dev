Go 1.26 以降で再構築された go fix コマンドを使用して Go コードを最新化します。新しい言語と stdlib イディオム（any へのinterface{}、range-over-int、min/max、strings.Cut、new(expr)、その他 20 個以上への 3 節ループ）に安全なバージョン認識の書き換えを適用し、固定点まで反復し、その後ビルドを検証します。 Go コードを最新化、クリーンアップ、または慣用的にする必要がある場合、go.mod のバージョンアップ後、古いスタイルまたは AI 生成のパターンが蓄積した場合、非推奨または名前変更された API (go:fix インライン ディレクティブ) から呼び出し元を移行する場合、ユーザーが go fix または gofix に言及した場合、または CI ゲートとして最新の慣用句を適用する場合に使用します。 gofmt のフォーマット、依存関係のアップグレード、または精査によるバグ発見には適していません。
