Modernice el código Go con el comando go fix reconstruido en Go 1.26+. Aplica reescrituras seguras y con reconocimiento de versiones a lenguajes más nuevos y modismos stdlib (interfaz{} a cualquiera, bucles de 3 cláusulas a range-over-int, min/max, strings.Cut, new(expr) y más de 20), iterando hasta un punto fijo y verificando la compilación posteriormente. Úselo siempre que el código Go deba modernizarse, limpiarse o volverse idiomático: después de un aumento en la versión de go.mod, cuando se acumulen patrones antiguos o generados por IA, cuando se migren llamadores de API obsoletas o renombradas (directivas en línea go:fix), cuando el usuario mencione go fix o gofix, o para aplicar modismos modernos como puerta de CI. No apto para formatear gofmt, actualizar dependencias o buscar errores veterinarios.
