Диагностика сбоев подключения Tailscale и DNS внутри контейнеров Docker. Обнаруживает пользовательское пространство и режим ядра, конфликты DNS-преобразователей, проблемы интерфейса TUN и несоответствия нескольких хвостовых сетей. Используйте, когда одноранговые узлы Tailscale подключаются по IP-адресу, но имена MagicDNS не работают, или когда контейнеры неожиданно возвращаются в сеть пользовательского пространства. Также используйте, когда клиент развертывает Tailscale в Docker или Podman и сообщает, что DNS не работает, или когда переход с Docker Run на Docker Compose нарушает функциональность TUN.
