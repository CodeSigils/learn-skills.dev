Diagnostiquez les échecs de connectivité Tailscale et DNS dans les conteneurs Docker. Détecte l'espace utilisateur par rapport au mode noyau, les conflits de résolution DNS, les problèmes d'interface TUN et les incompatibilités multi-tailnet. À utiliser lorsque les homologues Tailscale se connectent par IP mais que les noms MagicDNS échouent, ou lorsque les conteneurs reviennent de manière inattendue au réseau de l'espace utilisateur. À utiliser également lorsqu'un client déploie Tailscale dans Docker ou Podman et signale que le DNS ne fonctionne pas, ou lors de la migration de Docker Run vers Docker Compose interrompt la fonctionnalité TUN.
