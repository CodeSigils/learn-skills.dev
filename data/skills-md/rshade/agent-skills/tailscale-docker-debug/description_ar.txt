تشخيص اتصال Tailscale وفشل DNS داخل حاويات Docker. يكتشف مساحة المستخدم مقابل وضع kernel، وتعارضات محلل DNS، ومشكلات واجهة TUN، وعدم تطابق الشبكة المتعددة الأطراف. يُستخدم عندما يتصل أقران Tailscale عبر IP ولكن تفشل أسماء MagicDNS، أو عندما تعود الحاويات إلى شبكة مساحة المستخدم بشكل غير متوقع. يُستخدم أيضًا عندما ينشر العميل Tailscale في Docker أو Podman ويبلغ عن عدم عمل DNS، أو عند الترحيل من docker run إلى docker compose يعطل وظائف TUN.
