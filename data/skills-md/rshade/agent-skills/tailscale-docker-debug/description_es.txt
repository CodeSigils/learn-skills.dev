Diagnostique la conectividad de Tailscale y las fallas de DNS dentro de los contenedores Docker. Detecta el espacio de usuario frente al modo kernel, conflictos de resolución de DNS, problemas de interfaz TUN y discrepancias en múltiples redes finales. Úselo cuando los pares de Tailscale se conectan por IP pero los nombres MagicDNS fallan o cuando los contenedores recurren inesperadamente a la red del espacio de usuario. Úselo también cuando un cliente implementa Tailscale en Docker o Podman e informa que DNS no funciona, o cuando la migración de Docker Run a Docker Compose interrumpe la funcionalidad TUN.
