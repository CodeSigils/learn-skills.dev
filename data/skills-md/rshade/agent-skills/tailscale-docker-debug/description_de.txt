Diagnostizieren Sie Tailscale-Konnektivitäts- und DNS-Fehler in Docker-Containern. Erkennt Userspace- und Kernel-Modus, DNS-Resolver-Konflikte, TUN-Schnittstellenprobleme und Multi-Tailnet-Nichtübereinstimmungen. Wird verwendet, wenn Tailscale-Peers eine Verbindung über IP herstellen, MagicDNS-Namen jedoch fehlschlagen, oder wenn Container unerwartet auf das Userspace-Netzwerk zurückgreifen. Verwenden Sie es auch, wenn ein Kunde Tailscale in Docker oder Podman bereitstellt und meldet, dass DNS nicht funktioniert, oder wenn die Migration von Docker Run zu Docker Compose die TUN-Funktionalität unterbricht.
