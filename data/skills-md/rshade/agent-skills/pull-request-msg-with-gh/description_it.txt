Genera un file PR_MESSAGE.md dal contesto della sessione utilizzando la CLI di GitHub. Rileva i problemi correlati tramite la ricerca per parola chiave del ramo, scrive una descrizione PR strutturata con oggetto di commit, riepilogo, piano di test e registro delle modifiche. Convalida con commitlint e markdownlint. Da utilizzare durante la preparazione di una richiesta pull su GitHub.
