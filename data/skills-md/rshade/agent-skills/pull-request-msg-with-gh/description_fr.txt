Générez un fichier PR_MESSAGE.md à partir du contexte de session à l'aide de GitHub CLI. Détecte les problèmes associés via une recherche par mot-clé de branche, rédige une description structurée des relations publiques avec le sujet de la validation, le résumé, le plan de test et le journal des modifications. Valide avec commitlint et markdownlint. À utiliser lors de la préparation d'une pull request sur GitHub.
