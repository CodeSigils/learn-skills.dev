Generieren Sie mithilfe der GitHub-CLI eine PR_MESSAGE.md-Datei aus dem Sitzungskontext. Erkennt verwandte Probleme über die Zweigstichwortsuche und schreibt eine strukturierte PR-Beschreibung mit Commit-Betreff, Zusammenfassung, Testplan und Änderungsprotokoll. Validiert mit commitlint und markdownlint. Zur Verwendung bei der Vorbereitung einer Pull-Anfrage auf GitHub.
