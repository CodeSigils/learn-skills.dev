Создайте файл PR_MESSAGE.md из контекста сеанса с помощью интерфейса командной строки GitHub. Обнаруживает связанные проблемы с помощью поиска по ключевым словам ветки, пишет структурированное PR-описание с темой фиксации, сводкой, планом тестирования и журналом изменений. Проверяется с помощью commitlint и markdownlint. Используйте при подготовке запроса на включение на GitHub.
