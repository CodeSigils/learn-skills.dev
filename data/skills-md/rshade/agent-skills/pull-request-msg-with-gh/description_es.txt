Genere un archivo PR_MESSAGE.md desde el contexto de la sesión usando GitHub CLI. Detecta problemas relacionados mediante búsqueda de palabras clave, escribe una descripción de relaciones públicas estructurada con asunto de confirmación, resumen, plan de prueba y registro de cambios. Valida con commitlint y markdownlint. Úselo al preparar una solicitud de extracción en GitHub.
