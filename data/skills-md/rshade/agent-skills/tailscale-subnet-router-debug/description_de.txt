Diagnostizieren Sie Konnektivitätsfehler des Tailscale-Subnetz-Routers. Verfolgt den gesamten Routenlebenszyklus: Ankündigung, Genehmigung, Client-Akzeptanz, Richtlinienrouting (Tabelle 52) und IP-Weiterleitung. Verwenden Sie diese Option, wenn Clients Tailscale-Peers über IP erreichen können, aber keine Geräte in angekündigten Subnetzen, oder wenn Subnetzrouten genehmigt erscheinen, aber kein Datenverkehr fließt. Verwenden Sie es auch, wenn Docker-Container keine Routen ankündigen, wenn „ip route“ keine Subnetzroute anzeigt (in Tabelle 52) oder wenn der Datenverkehr in eine Richtung fließt, aber keine Antworten zurückgegeben werden.
