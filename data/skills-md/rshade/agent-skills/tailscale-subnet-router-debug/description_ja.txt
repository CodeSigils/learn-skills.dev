Tailscale サブネット ルーターの接続障害を診断します。ルートのライフサイクル全体 (アドバタイズメント、承認、クライアントの受け入れ、ポリシー ルーティング (表 52)、および IP 転送) をトレースします。クライアントが IP によって Tailscale ピアに到達できるが、アドバタイズされたサブネット上のデバイスには到達できない場合、またはサブネット ルートが承認されているように見えるがトラフィックが流れない場合に使用します。また、Docker コンテナがルートのアドバタイズに失敗した場合、「ip Route」にサブネット ルートが表示されない場合 (テーブル 52 にあります)、またはトラフィックが一方向に流れるが応答が返されない場合にも使用します。
