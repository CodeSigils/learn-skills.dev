Prepara le applicazioni Go per funzionare in modo efficace con gli agenti di codifica AI. Da utilizzare durante l'impostazione di un nuovo progetto Go o l'aggiornamento di uno esistente per garantire: registrazione JSON strutturata (slog/Zap/ZeroLog/Logrus), output dei comandi leggibile dalla macchina, configurazione completa di golangci-lint, progettazione CLI non interattiva con flag --yes, gestione strutturata degli errori con codici di uscita significativi, corretta propagazione del contesto.Contesto, arresto regolare, endpoint di controllo dello stato e Makefile standardizzato. Si attiva quando un utente chiede di rendere la propria app Go "pronta per l'agente", "adatta all'intelligenza artificiale", desidera migliorare gli strumenti/l'osservabilità dell'agente in un progetto Go o deve verificare un progetto Go esistente rispetto alle migliori pratiche di preparazione dell'agente.
