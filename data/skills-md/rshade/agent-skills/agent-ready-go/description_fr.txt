Prépare les applications Go à fonctionner efficacement avec les agents de codage IA. À utiliser lors de la configuration d'un nouveau projet Go ou de la mise à niveau d'un projet existant pour garantir : une journalisation JSON structurée (slog/Zap/ZeroLog/Logrus), une sortie de commande lisible par machine, une configuration golangci-lint approfondie, une conception CLI non interactive avec des indicateurs --yes, une gestion structurée des erreurs avec des codes de sortie significatifs, un contexte approprié. Propagation du contexte, arrêt progressif, points de terminaison de vérification de l'état et un Makefile standardisé. Se déclenche lorsqu'un utilisateur demande à rendre son application Go « prête pour l'agent », « conviviale pour l'IA », souhaite améliorer les outils/l'observabilité de l'agent dans un projet Go, ou doit auditer un projet Go existant par rapport aux meilleures pratiques de préparation des agents.
