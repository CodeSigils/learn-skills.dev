Подготавливает приложения Go для эффективной работы с агентами кодирования AI. Используйте при настройке нового проекта Go или модернизации существующего, чтобы обеспечить: структурированное ведение журнала JSON (slog/Zap/ZeroLog/Logrus), машиночитаемый вывод команд, тщательную настройку golangci-lint, неинтерактивный дизайн CLI с флагами --yes, структурированную обработку ошибок с осмысленными кодами завершения, правильное распространение context.Context, корректное завершение работы, конечные точки проверки работоспособности и стандартизированный Makefile. Срабатывает, когда пользователь просит сделать свое приложение Go «готовым к работе с агентом», «дружественным к искусственному интеллекту», хочет улучшить инструменты агента/наблюдаемость в проекте Go или ему необходимо проверить существующий проект Go на предмет соответствия передовым практикам готовности агента.
