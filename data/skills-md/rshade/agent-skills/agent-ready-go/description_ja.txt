AI コーディング エージェントと効果的に連携するように Go アプリケーションを準備します。新しい Go プロジェクトをセットアップするとき、または既存の Go プロジェクトを改造するときに使用して、構造化された JSON ログ (slog/Zap/ZeroLog/Logrus)、機械可読コマンド出力、完全な golangci-lint 構成、--yes フラグを使用した非対話型 CLI 設計、意味のある終了コードを使用した構造化エラー処理、適切な context.Context の伝播、正常なシャットダウン、ヘルス チェック エンドポイント、および標準化された Makefile を確保します。ユーザーが Go アプリを「エージェント対応」または「AI フレンドリー」にすることを要求した場合、Go プロジェクトでのエージェントのツール/可観測性を向上させたい場合、またはエージェント対応のベスト プラクティスに対して既存の Go プロジェクトを監査する必要がある場合にトリガーされます。
