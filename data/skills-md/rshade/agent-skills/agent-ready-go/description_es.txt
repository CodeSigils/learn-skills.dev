Prepara las aplicaciones Go para que funcionen eficazmente con agentes de codificación de IA. Úselo al configurar un nuevo proyecto Go o actualizar uno existente para garantizar: registro JSON estructurado (slog/Zap/ZeroLog/Logrus), salida de comando legible por máquina, configuración completa de golangci-lint, diseño CLI no interactivo con indicadores --yes, manejo de errores estructurado con códigos de salida significativos, contexto adecuado. Propagación de contexto, cierre elegante, puntos finales de verificación de estado y un Makefile estandarizado. Se activa cuando un usuario solicita que su aplicación Go esté "lista para agentes", "compatible con IA", quiere mejorar las herramientas/observabilidad del agente en un proyecto de Go o necesita auditar un proyecto Go existente según las mejores prácticas de preparación para agentes.
