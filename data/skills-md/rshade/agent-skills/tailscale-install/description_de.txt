Installieren und konfigurieren Sie Tailscale plattformübergreifend. Erkennt Betriebssystem, Distribution und Umgebung (einschließlich WSL2 und Container). Überprüft vorhandene Installationen, führt eine plattformgerechte Installation durch und leitet die Erstverbindung. Verwenden Sie diese Option, wenn Sie Tailscale auf einem neuen Computer einrichten, einen Server in ein Tailnet integrieren oder eine vorhandene Installation überprüfen.
