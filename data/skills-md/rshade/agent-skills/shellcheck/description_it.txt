Convalida gli script di shell per errori di sintassi, bug comuni, problemi di quotazione e problemi di portabilità. Rileva automaticamente il binario Shellcheck o guida l'installazione. Controlla la configurazione del progetto o torna a impostazioni predefinite ragionevoli. Da utilizzare durante la creazione o la modifica di script di shell, la convalida di file bash/sh o l'individuazione di errori di scripting della shell prima del commit.
