Aprobar (enviar una revisión de aprobación) y fusionar un RP dado solo su número, negándose cuando la puerta de control de calidad o una etiqueta de bloqueo lo prohíbe. Opcionalmente, presente un problema de seguimiento al mismo tiempo. Úselo cuando el usuario diga "aprobar y fusionar PR 123", "enviar PR 123" o proporcione un número de PR con la intención de fusionar.
