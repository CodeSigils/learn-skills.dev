Approva (invia una revisione di approvazione) e unisci un PR in base solo al suo numero, rifiutando quando il gate QA o un'etichetta di blocco lo vietano. Facoltativamente, presentare allo stesso tempo un problema di follow-up. Da utilizzare quando l'utente dice "approva e unisci PR 123", "spedisci PR 123" o fornisce un numero PR con l'intento di unire.
