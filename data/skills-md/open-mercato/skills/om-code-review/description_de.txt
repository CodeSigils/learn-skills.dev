Überprüfen Sie ein Diff, einen Zweig oder eine PR auf Richtigkeit, Sicherheit, aktuelle Änderungen und Qualitätsstandards. Führt das konfigurierte Validierungsgate aus, wendet die integrierte Überprüfungscheckliste sowie alle Repository-lokalen Checklisten aus der Pipeline-Konfiguration an und erstellt kategorisierte Ergebnisse mit Schweregraden und einem Urteil zum Genehmigen/Anfordern von Änderungen. Die von om-auto-review-pr, om-review-prs verwendete Überprüfungs-Engine und die Selbstüberprüfungsschritte von om-auto-create-pr und om-auto-continue-pr.
