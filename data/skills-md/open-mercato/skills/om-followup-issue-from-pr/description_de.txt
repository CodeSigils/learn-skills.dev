Verwandeln Sie eine PR in nachverfolgte Folgearbeit. Zwei Modi (beide können für einen PR ausgelöst werden). (1) Kommentarmodus – Fügen Sie einen PR- oder PR-Kommentar-Link ein; Der Skill extrahiert die umsetzbare Frage, sammelt PR-Kontext und öffnet ein Folgeproblem, das der @-Erwähnung des Kommentars zugeordnet ist, falls vorhanden, andernfalls dem PR-Autor. (2) Design-Doc-Modus – Wenn der PR ein Design-/Vorschlagsdokument zum Dokumentationsbereich des Repos hinzufügt, prüft der Skill, ob bereits ein Tracking-Problem für die Implementierung besteht, und öffnet, falls nicht, ein Tracking-Problem „Implementieren:“. Wird während der Codeüberprüfung verwendet, wenn der Benutzer sagt „Ein Folgeproblem erstellen“, „ein Problem dafür erstellen“ oder einen PR-/Kommentarlink mit dieser Absicht einfügt.
