Trasforma un PR in un lavoro di follow-up monitorato. Due modalità (entrambe possono sparare per un PR). (1) Modalità commento: incolla un collegamento PR o commento PR; la competenza estrae la richiesta utilizzabile, raccoglie il contesto PR e apre un problema di follow-up assegnato alla menzione @ del commento, se presente, altrimenti all'autore PR. (2) Modalità Design-doc: se il PR aggiunge un documento di progettazione/proposta all'area documenti del repository, la competenza verifica se esiste già un problema di tracciamento per implementarlo e, in caso contrario, apre un problema di tracciamento "Implement:". Da utilizzare durante la revisione del codice quando l'utente dice "crea un problema di follow-up", "crea un problema per questo" o incolla un collegamento PR/commento con tale intento.
