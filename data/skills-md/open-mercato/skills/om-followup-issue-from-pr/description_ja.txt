PR を追跡されたフォローアップ作業に変えます。 2 つのモード (両方とも 1 つの PR に対して発火可能)。 (1) コメント モード — PR または PR コメント リンクを貼り付けます。このスキルは、実用的な質問を抽出し、PR コンテキストを収集し、コメントの @ メンションが存在する場合はそれに割り当てられたフォローアップの問題を開き、存在しない場合は PR 作成者に割り当てられます。 (2) 設計ドキュメント モード — PR が設計/提案ドキュメントをリポジトリのドキュメント領域に追加する場合、スキルはそれを実装するための追跡問題がすでに存在するかどうかを確認し、存在しない場合は「Implement:」追跡問題を開きます。コードレビュー中に、ユーザーが「フォローアップの問題を作成する」、「これに関する問題を作成する」と言う場合、またはその目的で PR/コメント リンクを貼り付ける場合に使用します。
