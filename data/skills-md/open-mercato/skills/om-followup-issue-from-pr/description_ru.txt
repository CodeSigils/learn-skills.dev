Превратите PR в отслеживаемую последующую работу. Два режима (оба могут стрелять за один ПР). (1) Режим комментариев — вставьте ссылку на PR или PR-комментарий; навык извлекает действенный вопрос, собирает PR-контекст и открывает последующую проблему, назначенную @-упоминанию комментария, если оно присутствует, или автору PR. (2) Режим проектной документации — если PR добавляет документ проекта/предложения в область документации репозитория, навык проверяет, существует ли уже проблема отслеживания для его реализации, и, если нет, открывает проблему отслеживания «Реализовать:». Используйте во время проверки кода, когда пользователь говорит «создайте дополнительную проблему», «создайте проблему для этого» или вставляет ссылку на PR/комментарий с этим намерением.
