PR을 추적된 후속 작업으로 전환하세요. 두 가지 모드(모두 하나의 PR에 대해 실행 가능) (1) 댓글 모드 — PR 또는 PR 댓글 링크를 붙여넣습니다. 이 기술은 실행 가능한 질문을 추출하고, PR 컨텍스트를 수집하고, 댓글의 @-mention(있는 경우)에 할당된 후속 문제를 열고, 그렇지 않으면 PR 작성자를 엽니다. (2) 디자인 문서 모드 — PR이 리포지토리의 문서 영역에 디자인/제안 문서를 추가하는 경우 기술은 이를 구현하기 위한 추적 문제가 이미 존재하는지 확인하고, 그렇지 않은 경우 '구현:' 추적 문제를 엽니다. 코드 검토 중에 사용자가 "후속 문제 만들기", "이 문제에 대한 문제 만들기"라고 말하거나 해당 의도가 포함된 PR/댓글 링크를 붙여넣을 때 사용합니다.
