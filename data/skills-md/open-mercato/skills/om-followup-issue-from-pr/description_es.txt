Convierta un PR en un trabajo de seguimiento rastreado. Dos modos (ambos pueden disparar por un PR). (1) Modo de comentario: pegue un enlace de PR o comentario de PR; la habilidad extrae la pregunta procesable, recopila el contexto de relaciones públicas y abre un problema de seguimiento asignado a la mención @ del comentario si está presente; de ​​lo contrario, al autor de relaciones públicas. (2) Modo de documento de diseño: si el RP agrega un documento de diseño/propuesta al área de documentos del repositorio, la habilidad verifica si ya existe un problema de seguimiento para implementarlo y, si no, abre un problema de seguimiento "Implementar:". Úselo durante la revisión del código cuando el usuario dice "crear un problema de seguimiento", "crear un problema para esto" o pega un enlace de PR/comentario con esa intención.
