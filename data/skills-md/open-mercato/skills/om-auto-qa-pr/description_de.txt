Führen Sie eine QA-Änderung der Benutzeroberfläche eines PR in einem echten Browser über den konfigurierten Browser-Anbieter-Deskriptor durch. Stellen Sie zunächst sicher, dass der PR überprüft wurde (rufen Sie om-auto-review-pr auf, wenn dies nicht der Fall ist), erfassen Sie dann Screenshots und einen Pass/Fail-Bericht und veröffentlichen Sie optional Tracker-Beweise oder Selbst-QA-Kennzeichnungen, ohne die Quelle zu ändern. Läuft auch in einem lokalen Modus ohne Tracker für den aktuellen Arbeitsbaum.
