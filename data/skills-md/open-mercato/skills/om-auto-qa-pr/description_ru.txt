Обеспечение качества изменения пользовательского интерфейса PR в реальном браузере с помощью настроенного дескриптора поставщика браузера — сначала убедитесь, что PR был проверен (вызов om-auto-review-pr, если это не так), затем сделайте снимки экрана и отчет о пройденном/неудачном этапе и, при необходимости, опубликуйте данные отслеживания или метки самостоятельного контроля качества без изменения источника. Также выполняется в локальном режиме без отслеживания для текущего рабочего дерева.
