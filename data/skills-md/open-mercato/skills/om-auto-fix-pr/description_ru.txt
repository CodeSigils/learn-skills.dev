Создайте открытый PR для готовности к слиянию, используя его номер: объединяет последнюю базу, затем циклически повторяет проверку-автоисправление (om-auto-review-pr), встроенную стабилизацию CI и проверку пользовательского интерфейса (om-auto-qa-pr) до тех пор, пока она не будет одобрена, зелена и подтверждена контролем качества. Режим --ci-only отображает только зеленый цвет CI на PR или простой ветке. Файлы отслеживают проблемы с нитами, нормализуют метки, не включаются в om-approve-merge-pr — никогда не сливаются сами. Используйте для «подготовки PR 123 к слиянию».
