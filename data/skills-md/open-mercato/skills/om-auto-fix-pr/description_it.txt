Promuovi un PR aperto per essere pronto per l'unione dal suo numero: unisce la base più recente, quindi esegue il loop di revisione-correzione automatica (om-auto-review-pr), stabilizzazione CI integrata e verifica dell'interfaccia utente (om-auto-qa-pr) fino all'approvazione, al verde e alla prova del QA. Una modalità --ci-only guida solo il verde CI su un PR o un ramo semplice. File di follow-up per problemi di lendini, normalizza le etichette, passa a om-approve-merge-pr: non si unisce mai. Utilizzare per "preparare il PR 123 per l'unione".
