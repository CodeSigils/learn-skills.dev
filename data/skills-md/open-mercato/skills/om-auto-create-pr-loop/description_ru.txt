Расширенный рабочий процесс om-auto-create-pr для длительных, многоэтапных реализаций спецификаций, требующих возможности возобновления и строгого отслеживания шагов. Создает папку запуска в настроенном каталоге запусков с PLAN.md, HANDOFF.md и NOTIFY.md, выполняет одну бережливую фиксацию для каждого шага таблицы задач, группирует проверку в контрольную точку-<N>-checks.md каждые 5 шагов (с целевыми интеграционными тестами и снимками экрана при касании пользовательского интерфейса), запускает полностью настроенный шлюз проверки, а также пакет интеграции репозитория и любой этап соответствия стилю при завершении спецификации и открывает PR с нормализованными метками конвейера. Возобновляется через om-auto-continue-pr-loop. Используйте простой om-auto-create-pr для небольших исправлений.
