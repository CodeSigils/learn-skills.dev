再開可能性と厳格なステップ追跡を必要とする、長時間にわたる複数ステップの仕様実装のための高度な om-auto-create-pr ワークフロー。 PLAN.md、HANDOFF.md、および NOTIFY.md を使用して構成された run ディレクトリの下に run フォルダーを作成し、タスク テーブル ステップごとに 1 つのリーン コミットを実行し、5 つのステップごとに検証を Checkpoint-<N>-checks.md にバッチ処理し (UI がタッチされたときの集中的な統合テストとスクリーンショットを使用)、仕様の完了時に完全に構成された検証ゲートとリポジトリの統合スイートおよびスタイル コンプライアンス パスを実行し、正規化されたパイプラインで PR を開きます。ラベル。 om-auto- continue-pr-loop 経由で再開可能。小さな修正には、プレーンな om-auto-create-pr を使用してください。
