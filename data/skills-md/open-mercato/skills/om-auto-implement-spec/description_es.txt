Resuelve la especificación por ruta, nombre, problema o número de especificación-PR (parada limpia con candidatos cuando no se encuentran), reutiliza una rama de especificación PR cuando existe, delega en om-auto-create-pr/om-auto-continue-pr, luego ejecuta el ciclo de revisión y la verificación de la interfaz de usuario con capturas de pantalla. Úselo para "implementar la especificación X", "compilar especificaciones a partir del número 123".
