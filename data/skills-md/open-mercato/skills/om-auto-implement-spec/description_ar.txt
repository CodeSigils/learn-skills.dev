قم بتنفيذ المواصفات الحالية وشحن العلاقات العامة التي تم التحقق منها ومراجعتها وجاهزة. يحل المواصفات حسب المسار أو الاسم أو المشكلة أو رقم المواصفات PR (توقف نظيفًا مع المرشحين عند عدم العثور عليهم)، ويعيد استخدام فرع PR للمواصفات عند وجوده، ويفوض إلى om-auto-create-pr / om-auto-continue-pr، ثم يقوم بتشغيل حلقة المراجعة والتحقق من واجهة المستخدم باستخدام لقطات الشاشة. استخدم لـ "تنفيذ المواصفات X"، "إنشاء المواصفات من الإصدار 123".
