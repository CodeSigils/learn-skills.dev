Внедрите существующую спецификацию и отправьте проверенный, проверенный и готовый PR. Разрешает спецификацию по пути, имени, проблеме или номеру спецификации-PR (полная остановка с кандидатами, если они не найдены), повторно использует ветку PR спецификации, если таковая существует, делегирует полномочия om-auto-create-pr / om-auto-continue-pr, затем запускает цикл проверки и проверку пользовательского интерфейса с помощью снимков экрана. Используйте для «реализации спецификации X», «сборки спецификации из выпуска 123».
