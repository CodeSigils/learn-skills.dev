Приведите существующие проблемы трекера в соответствие со стандартами, ничего не внедряя — применяет отсутствующие метки SDLC, уточняет лаконичные проблемы (анализируя прикрепленные скриншоты), публикует доступный только для чтения анализ подготовки реализации и помечает проблемы с функциями, для которых отсутствует покрывающая спецификация (возможно создание одной с --write-missing-specs). Одна проблема по идентификатору или пакет (по умолчанию — около 25 последних открытых, худшее описание начинается первым). Идемпотент и осознающий претензии. Используйте для «сортировки невыполненной работы», «очистки проблемы 123».
