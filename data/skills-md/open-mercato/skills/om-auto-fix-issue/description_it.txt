Risolvi un problema del tracker end-to-end (problema di GitHub per impostazione predefinita) da un singolo comando. Guida la catena di correzione automatica in modo interattivo: dimostra che il problema necessita ancora di lavoro (om-verify-in-repo), individua il bug (om-root-cause), implementa la correzione minima con test di regressione (om-fix), apre una bozza PR etichettata (om-open-pr), quindi esegue il loop om-auto-review-pr in modalità di correzione automatica finché non viene pulito. Viene eseguito in un albero di lavoro isolato, rispetta il protocollo di richiesta in corso e si arresta in modo pulito quando il problema è già risolto o già rivendicato.
