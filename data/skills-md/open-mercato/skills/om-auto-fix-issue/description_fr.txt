Résoudre un problème de tracker de bout en bout (problème GitHub par défaut) à partir d'une seule commande. Pilote la chaîne de correction automatique de manière interactive - prouve que le problème doit encore être résolu (om-verify-in-repo), localise le bogue (om-root-cause), implémente le correctif minimal avec des tests de régression (om-fix), ouvre un brouillon de PR étiqueté (om-open-pr), puis boucle om-auto-review-pr en mode de correction automatique jusqu'à ce qu'il soit propre. S'exécute dans une arborescence de travail isolée, respecte le protocole de réclamation en cours et s'arrête proprement lorsque le problème est déjà résolu ou déjà revendiqué.
