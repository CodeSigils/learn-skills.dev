Устраните сквозную проблему трекера (проблема GitHub по умолчанию) с помощью одной команды. Интерактивно управляет цепочкой автоисправлений — доказывает, что проблема все еще требует доработки (om-verify-in-repo), находит ошибку (om-root-cause), реализует минимальное исправление с помощью регрессионных тестов (om-fix), открывает помеченный черновик PR (om-open-pr), затем зацикливает om-auto-review-pr в режиме автоисправления до полной очистки. Запускается в изолированном рабочем дереве, соблюдает протокол текущих претензий и полностью останавливается, когда проблема уже решена или уже заявлена.
