単一のコマンドからトラッカーの問題をエンドツーエンドで修正します (デフォルトでは GitHub の問題)。自動修正チェーンをインタラクティブに駆動します — 問題にまだ作業が必要であることを証明し (om-verify-in-repo)、バグを特定し (om-root-cause)、回帰テストで最小限の修正を実装し (om-fix)、ラベル付きのドラフト PR を開き (om-open-pr)、クリーンになるまで自動修正モードで om-auto-review-pr をループします。分離されたワークツリーで実行され、進行中のクレーム プロトコルが尊重され、問題がすでに解決されているか、すでにクレームされている場合は正常に停止します。
