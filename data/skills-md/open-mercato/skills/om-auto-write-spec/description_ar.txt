تحويل مشكلة موجزة أو FR بشكل مستقل إلى مواصفات وصلت إلى PR جاهزة - تشغيل om-spec-writing --autonomous (الافتراضيات المنشورة للتجاوز)، وإرفاق نماذج بالحجم الطبيعي لواجهة المستخدم ولقطات شاشة التطبيق الحالي كدليل للعلاقات العامة عند وجود موفر متصفح، وتطبيق ملصقات SDLC كاملة، وإصدار علامات PR/spec للتسلسل إلى om-auto-implement-spec. استخدم لـ "اكتب مواصفات لـ X وافتح PR"، "حدد هذه المشكلة".
