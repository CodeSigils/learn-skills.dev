Erstellen Sie einen neuen OM-Skill aus einem Briefing oder teilen Sie ein vorhandenes übergroßes SKILL.md in mehrschichtige Referenzen/Dateien auf – konservativ, hinter einem harten Flusen- und Vollständigkeitstor. Versteht die Layering-Philosophie des Repos (Router-Body + On-Demand-Referenzen), die Lint-Invarianten, die Tracker-Operations-Abstraktion und die gemeinsam genutzten Pipeline-Protokolle, sodass die generierten Fähigkeiten den Hauskonventionen entsprechen. Standardmäßig interaktiv. Wird verwendet, wenn der Benutzer sagt: „Erstellen Sie einen Skill für…“, „Neuer Om-Skill“, „Erstellen Sie einen Skill“, „Teilen Sie diesen Skill auf“, „Refactor SKILL.md in Referenzen“, „Rozbij Skill Na References“, „Stwórz Skill Do…“, „Nowy Om-Skill“, „Podziel Ten Skill“.
