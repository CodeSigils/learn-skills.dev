Configuratore monouso per la pipeline PR dell'agente. Ispeziona il repository (ramo predefinito, script di convalida, etichette del tracker), pone alcune domande, scrive .ai/agentic.config.json — il file letto da ogni altra competenza in questa raccolta — installa il descrittore del provider del tracker (.ai/trackers/<tracker>.md) e genera i documenti del progetto quando mancano — SDLC.md (il documento del processo del flusso del ticket del team), CODE_REVIEW.md (regole di revisione), BACKWARD_COMPATIBILITY.md (superfici contrattuali protette) e uno starter AGENTS.md con una tabella di instradamento delle attività, ciascuno derivato dal repository corrente. Esegui una volta per repository; rieseguire quando la toolchain o la tassonomia delle etichette cambia.
