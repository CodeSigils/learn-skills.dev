Одноразовый конфигуратор агентского PR-конвейера. Проверяет репозиторий (ветвь по умолчанию, сценарии проверки, метки трекера), задает несколько вопросов, записывает .ai/agentic.config.json — файл, который читает каждый другой навык в этой коллекции — устанавливает дескриптор поставщика трекера (.ai/trackers/<tracker>.md) и генерирует документацию проекта в случае его отсутствия — SDLC.md (документ процесса потока заявок команды), CODE_REVIEW.md (проверка) правила), BACKWARD_COMPATIBILITY.md (защищенные поверхности контракта) и стартовый файл AGENTS.md с таблицей маршрутизации задач — каждый из них получен из текущего репозитория. Запускать один раз для каждого репозитория; перезапустите, когда изменится таксономия инструментов или меток.
