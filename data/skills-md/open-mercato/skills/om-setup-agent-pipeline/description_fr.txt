Configurateur unique pour le pipeline PR de l'agent. Inspecte le référentiel (branche par défaut, scripts de validation, étiquettes de suivi), pose quelques questions, écrit .ai/agentic.config.json — le fichier lu par toutes les autres compétences de cette collection — installe le descripteur du fournisseur de suivi (.ai/trackers/<tracker>.md) et génère les documents du projet en cas d'absence — SDLC.md (le document de processus de flux de tickets de l'équipe), CODE_REVIEW.md (règles de révision), BACKWARD_COMPATIBILITY.md (surfaces contractuelles protégées) et un démarreur AGENTS.md avec une table de routage des tâches, chacun dérivé du référentiel actuel. Exécuter une fois par référentiel ; réexécutez lorsque la chaîne d'outils ou la taxonomie des étiquettes change.
