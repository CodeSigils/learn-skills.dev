Stellen Sie sicher, dass der aktuelle Zweig zur Veröffentlichung bereit ist, indem Sie alle konfigurierten Validierungsbefehle der Reihe nach ausführen, einfache Fehler beheben (einschließlich Abweichungen von der Gebietsschemadatei, wenn das Repo dies überprüft) und, sobald alles erfolgreich ist, den aktuellen Zweig festschreiben und pushen. Wird verwendet, wenn der Benutzer die Verzweigung überprüfen, eine Verifizierung im CI-Stil durchführen, dann einen Commit und einen Push durchführen möchte.
