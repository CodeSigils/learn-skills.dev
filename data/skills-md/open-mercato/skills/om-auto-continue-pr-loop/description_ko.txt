`om-auto-create-pr-loop`에 의해 시작된 PR을 위한 고급 `om-auto-continue-pr` 워크플로입니다. PR을 요청하고, 격리된 작업 트리에 다시 들어가고, 실행 폴더의 `PLAN.md` 작업 테이블에서 완료되지 않은 첫 번째 행에서 다시 시작하고, 단계별 린 커밋을 실행하고, 재개된 ~5단계마다 `checkpoint-<N>-checks.md`에 일괄 검증(집중 통합 테스트 + UI 터치 시 스크린샷 포함), 구성된 전체 검증 게이트와 저장소의 전체 통합 제품군 및 사양 완료 시 모든 스타일 준수 패스를 실행합니다. 실행 폴더와 레이블 계약을 유지합니다. 간단한 om-auto-create-pr 실행에는 일반 om-auto-continue-pr을 사용하세요.
