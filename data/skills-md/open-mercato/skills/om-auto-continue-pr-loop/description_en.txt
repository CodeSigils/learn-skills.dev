Advanced `om-auto-continue-pr` workflow for PRs started by `om-auto-create-pr-loop`. Claims the PR, re-enters an isolated worktree, resumes from the first non-done row in the run folder's `PLAN.md` Tasks table, executes lean per-step commits, batches verification into `checkpoint-<N>-checks.md` every ~5 resumed steps (with focused integration tests + screenshots when UI was touched), runs the configured full validation gate plus the repo's full integration suite and any style-compliance pass at spec completion, and preserves the run-folder and label contract. Use the plain om-auto-continue-pr for simple om-auto-create-pr runs.
