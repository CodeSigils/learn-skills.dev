「om-auto-create-pr-loop」によって開始される PR の高度な「om-auto- continue-pr」ワークフロー。 PR を要求し、分離されたワークツリーに再入力し、実行フォルダーの「PLAN.md」タスク テーブルの最初の未完了の行から再開し、ステップごとの無駄のないコミットを実行し、再開された ~5 ステップごとに検証を「checkpoint-<N>-checks.md」にバッチ処理し (集中的な統合テスト + UI がタッチされたときのスクリーンショットを使用)、構成された完全な検証ゲートとリポジトリの完全な統合スイートおよびスタイル コンプライアンス パスを実行します。仕様の完了時に、実行フォルダーとラベルのコントラクトを保存します。単純な om-auto-create-pr の実行には、プレーンな om-auto- continue-pr を使用します。
