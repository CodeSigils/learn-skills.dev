Advanced `om-auto-continue-pr` workflow for PRs started by `om-auto-create-pr-loop`. PR を要求し、分離されたワークツリーに再入力し、実行フォルダーの「PLAN.md」タスク テーブルの最初の未完了の行から再開し、ステップごとの無駄のないコミットを実行し、再開された ~5 ステップごとに検証を「checkpoint-<N>-checks.md」にバッチ処理し (集中的な統合テスト + UI がタッチされたときのスクリーンショットを使用)、構成された完全な検証ゲートとリポジトリの完全な統合スイートおよびスタイル コンプライアンス パスを実行します。 at spec completion, and preserves the run-folder and label contract. Use the plain om-auto-continue-pr for simple om-auto-create-pr runs.
