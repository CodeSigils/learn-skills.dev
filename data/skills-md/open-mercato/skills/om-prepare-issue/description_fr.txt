Déposez un problème de suivi bien formé pour une tâche sans l'implémenter. Recherche d'abord dans le tracker les doublons, lie la spécification correspondante lorsqu'elle existe dans le répertoire des spécifications du dépôt, puis analyse la tâche par rapport à la base de code et écrit des conseils détaillés de correction/mise en œuvre, étape par étape, dans le corps du problème. À utiliser pour « déposer un problème pour X », « garer cette idée », « préparer un problème pour construire X plus tard ».
