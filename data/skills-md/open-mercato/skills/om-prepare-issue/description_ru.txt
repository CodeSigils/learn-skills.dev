Создайте правильно сформированную задачу отслеживания для задачи, не реализуя ее. Сначала ищет в трекере дубликаты, связывает соответствующую спецификацию, если она существует в каталоге спецификаций репозитория, а также анализирует задачу по базе кода и записывает подробные пошаговые инструкции по исправлению/реализации в тело проблемы. Используйте для «сообщить о проблеме для X», «отложить эту идею», «подготовить проблему для сборки X позже».
