Crea con MPP (Machine Payments Protocol): il protocollo aperto per pagamenti da macchina a macchina su HTTP 402. Da utilizzare durante lo sviluppo di API a pagamento, contenuti controllati dai pagamenti, flussi di pagamento degli agenti AI, pagamenti con strumenti MCP, streaming pay-per-token o qualsiasi servizio che utilizza HTTP 402 Payment Required. Copre l'SDK mppx TypeScript con il middleware Hono/Express/Next.js/Elysia, l'SDK pympp Python e l'SDK mpp Rust. Supporta stablecoin Tempo, carte Stripe, Lightning Bitcoin e metodi di pagamento personalizzati. Include intenti di addebito (una tantum) e di sessione (streaming con pagamento in base al consumo). Assicurati di utilizzare questa abilità ogni volta che l'utente menziona mpp, mppx, pagamenti automatici, pagamenti HTTP 402, pagamenti Tempo, canali di pagamento, pagamento per token, endpoint API a pagamento o servizi con pagamento controllato.
