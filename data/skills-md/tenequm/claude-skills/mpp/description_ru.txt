Создайте с помощью MPP (протокол машинных платежей) — открытого протокола для межмашинных платежей через HTTP 402. Используйте при разработке платных API, контента с платежным шлюзом, потоков платежей агентов AI, платежей с помощью инструментов MCP, потоковой передачи с оплатой за токен или любой службы, использующей HTTP 402 Требуется оплата. Охватывает SDK mppx TypeScript с промежуточным программным обеспечением Hono/Express/Next.js/Elysia, pympp Python SDK и mpp Rust SDK. Поддерживает стейблкоины Tempo, карты Stripe, Lightning Bitcoin и пользовательские способы оплаты. Включает намерения по взиманию платы (однократно) и сеансу (потоковое вещание с оплатой по мере использования). Обязательно используйте этот навык всякий раз, когда пользователь упоминает mpp, mppx, машинные платежи, платежи HTTP 402, платежи Tempo, каналы оплаты, оплату за токен, платные конечные точки API или сервисы с ограничением платежей.
