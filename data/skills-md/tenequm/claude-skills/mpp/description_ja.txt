MPP (Machine Payments Protocol) を使用して構築します。これは、HTTP 402 を介したマシン間支払いのためのオープン プロトコルです。有料 API、支払いゲート型コンテンツ、AI エージェント支払いフロー、MCP ツール支払い、トークンごとの支払いストリーミング、または HTTP 402 支払いが必要なサービスを開発する場合に使用します。 mppx TypeScript SDK と Hono/Express/Next.js/Elysia ミドルウェア、pympp Python SDK、および mpp Rust SDK をカバーします。 Tempo ステーブルコイン、Stripe カード、Lightning Bitcoin、およびカスタム支払い方法をサポートします。チャージ (1 回限り) およびセッション (ストリーミング従量課金制) インテントが含まれます。ユーザーが mpp、mppx、マシン支払い、HTTP 402 支払い、Tempo 支払い、支払いチャネル、ペイパートークン、有料 API エンドポイント、または支払いゲート型サービスについて言及するときは必ずこのスキルを使用してください。
