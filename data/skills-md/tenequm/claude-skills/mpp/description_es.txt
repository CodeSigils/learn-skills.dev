Compile con MPP (Protocolo de pagos de máquinas), el protocolo abierto para pagos de máquina a máquina a través de HTTP 402. Úselo al desarrollar API pagas, contenido controlado por pagos, flujos de pago de agentes de IA, pagos de herramientas MCP, transmisión de pago por token o cualquier servicio que utilice HTTP 402 Pago requerido. Cubre el SDK de TypeScript de mppx con el middleware Hono/Express/Next.js/Elysia, el SDK de Python de pympp y el SDK de Rust de mpp. Admite monedas estables Tempo, tarjetas Stripe, Lightning Bitcoin y métodos de pago personalizados. Incluye intentos de cargo (único) y de sesión (transmisión de pago por uso). Asegúrese de utilizar esta habilidad siempre que el usuario mencione mpp, mppx, pagos automáticos, pagos HTTP 402, pagos Tempo, canales de pago, pago por token, puntos finales API pagos o servicios de pago.
