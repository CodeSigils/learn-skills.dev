Erstellen Sie mit MPP (Machine Payments Protocol) – dem offenen Protokoll für Maschine-zu-Maschine-Zahlungen über HTTP 402. Verwendung bei der Entwicklung kostenpflichtiger APIs, zahlungsgesteuerter Inhalte, KI-Agent-Zahlungsflüsse, MCP-Tool-Zahlungen, Pay-per-Token-Streaming oder jedem Dienst, der HTTP 402 verwendet. Zahlung erforderlich. Deckt das mppx TypeScript SDK mit der Middleware Hono/Express/Next.js/Elysia, das pympp Python SDK und das mpp Rust SDK ab. Unterstützt Tempo-Stablecoins, Stripe-Karten, Lightning Bitcoin und benutzerdefinierte Zahlungsmethoden. Beinhaltet Gebührenabsichten (einmalig) und Sitzungsabsichten (Streaming mit nutzungsbasierter Bezahlung). Stellen Sie sicher, dass Sie diesen Skill verwenden, wenn der Benutzer mpp, mppx, maschinelle Zahlungen, HTTP 402-Zahlungen, Tempo-Zahlungen, Zahlungskanäle, Pay-per-Token, kostenpflichtige API-Endpunkte oder zahlungsgesteuerte Dienste erwähnt.
