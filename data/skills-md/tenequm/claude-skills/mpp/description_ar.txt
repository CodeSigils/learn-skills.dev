البناء باستخدام MPP (بروتوكول مدفوعات الآلة) - البروتوكول المفتوح للمدفوعات من آلة إلى آلة عبر HTTP 402. استخدمه عند تطوير واجهات برمجة التطبيقات المدفوعة، أو المحتوى المسور للدفع، أو تدفقات دفع وكيل الذكاء الاصطناعي، أو مدفوعات أداة MCP، أو تدفق الدفع لكل رمز، أو أي خدمة تستخدم HTTP 402 Payment Required. يغطي mppx TypeScript SDK مع البرامج الوسيطة Hono/Express/Next.js/Elysia وpympp Python SDK وmpp Rust SDK. يدعم عملات Tempo المستقرة وبطاقات Stripe وLightning Bitcoin وطرق الدفع المخصصة. يتضمن نوايا الشحن (لمرة واحدة) والجلسة (الدفع مقابل الاستخدام أولاً بأول). تأكد من استخدام هذه المهارة عندما يذكر المستخدم mpp، أو mppx، أو مدفوعات الآلة، أو مدفوعات HTTP 402، أو مدفوعات Tempo، أو قنوات الدفع، أو الدفع لكل رمز مميز، أو نقاط نهاية API المدفوعة، أو خدمات بوابات الدفع.
