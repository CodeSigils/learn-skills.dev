Construisez avec MPP (Machine Payments Protocol) - le protocole ouvert pour les paiements de machine à machine via HTTP 402. À utiliser lors du développement d'API payantes, de contenu soumis à paiement limité, de flux de paiement d'agent IA, de paiements d'outils MCP, de streaming de paiement par jeton ou de tout service utilisant HTTP 402 Paiement requis. Couvre le SDK mppx TypeScript avec le middleware Hono/Express/Next.js/Elysia, le SDK Python pympp et le SDK mpp Rust. Prend en charge les pièces stables Tempo, les cartes Stripe, Lightning Bitcoin et les méthodes de paiement personnalisées. Inclut les intentions de facturation (unique) et de session (diffusion à l'utilisation). Assurez-vous d'utiliser cette compétence chaque fois que l'utilisateur mentionne mpp, mppx, les paiements automatiques, les paiements HTTP 402, les paiements Tempo, les canaux de paiement, le paiement par jeton, les points de terminaison d'API payants ou les services à paiement limité.
