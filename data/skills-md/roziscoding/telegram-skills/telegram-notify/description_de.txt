Senden Sie eine unidirektionale Telegram-Nachricht an konfigurierte Kontakte. Verwenden Sie diese Option, wenn der Benutzer per Telegram eine Nachricht, eine Benachrichtigung, einen Ping oder eine Warnung senden möchte. Verwenden Sie es auch, wenn Sie den Benutzer proaktiv über etwas informieren müssen (z. B. über die Erledigung einer langen Aufgabe). Dieser Skill ist nur zum Senden gedacht und wartet NICHT auf eine Antwort oder empfängt sie nicht. Wenn Sie eine Antwort oder Entscheidung vom Benutzer benötigen, verwenden Sie stattdessen den Telegram-Ask-Skill.
