Pautas de diseño de SAP Fiori para la creación de aplicaciones empresariales. Utilice esta habilidad cuando diseñe, cree o revise aplicaciones de SAP Fiori, implemente componentes web SAPUI5 o UI5, trabaje con patrones de UX empresarial de SAP o necesite orientación sobre botones, formularios, tablas, páginas de objetos, informes de listas, navegación, mensajes, colores, tipografía, accesibilidad, integración de IA/Joule o cualquier elemento de la interfaz de usuario de SAP Fiori. Se activa ante menciones de Fiori, SAPUI5, UI5, SAP UX, sistema de diseño SAP o diseño de aplicaciones empresariales siguiendo los estándares de SAP.
