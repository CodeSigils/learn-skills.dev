Synchronisez le package odata-vocabularies — mettez à jour tous les fichiers de ressources de vocabulaire vers leurs dernières versions publiées et ajoutez éventuellement un nouveau vocabulaire en fonction de son URL JSON. À utiliser lorsqu'on vous demande de mettre à jour les vocabulaires, d'actualiser les ressources de vocabulaire ou d'ajouter un nouveau vocabulaire à @sap-ux/odata-vocabularies.
