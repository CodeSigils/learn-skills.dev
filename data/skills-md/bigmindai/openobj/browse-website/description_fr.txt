Parcourez, recherchez et lisez le contenu de n’importe quel site Web à l’aide d’OpenObj. Utilisez cette compétence lorsque vous devez accéder à de la documentation, rechercher des sites Web, explorer du contenu Web ou rechercher des informations sur n'importe quelle page Web publique. Exécute des commandes via SSH ou HTTP API pour rechercher et lire des pages sous forme de fichiers markdown.
