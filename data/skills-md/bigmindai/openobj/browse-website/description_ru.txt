Просматривайте, ищите и читайте содержимое любого веб-сайта с помощью OpenObj. Используйте этот навык, когда вам нужно получить доступ к документации, исследовать веб-сайты, изучить веб-контент или найти информацию на любой общедоступной веб-странице. Выполняет команды через SSH или HTTP API для поиска и чтения страниц в виде файлов уценки.
