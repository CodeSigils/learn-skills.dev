قم بإنشاء أو مراجعة المادة الأمامية لـ Markdown `description` بحيث تقوم ``docgarden match` بتوجيه الوكلاء إلى مستندات المستودع الصحيحة. يُستخدم عند إضافة مستند Markdown موجه جديد، أو تحديث المادة الأمامية الموجودة، أو إصلاح نتائج المطابقة المزعجة أو المفقودة، أو ضبط المهارات أو اكتشاف المستندات، أو جعل الأوصاف أكثر توافقًا مع الاستعلام دون تحميل نصوص المستندات.
