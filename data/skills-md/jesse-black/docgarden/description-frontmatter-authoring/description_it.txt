Crea o modifica il frontmatter "descrizione" di Markdown in modo che "docgarden match" indirizzi gli agenti ai documenti del repository corretti. Da utilizzare quando si aggiunge un nuovo documento Markdown indirizzato, si aggiorna il frontmatter esistente, si correggono risultati di corrispondenza rumorosi o mancanti, si ottimizzano le competenze o il rilevamento di documenti o si rendono le descrizioni più allineate alle query senza caricare i corpi dei documenti.
