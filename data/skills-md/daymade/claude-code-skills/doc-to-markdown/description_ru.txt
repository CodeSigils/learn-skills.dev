Преобразует DOCX/PDF/PPTX в высококачественный Markdown с автоматической постобработкой. Исправляет таблицы сетки pandoc, простые таблицы, пути к изображениям, жирный интервал CJK, шум атрибутов и блоки кода. Лучший в своем классе (7,6 из 10) по сравнению с Docling, MarkItDown, Pandoc raw и Mammoth. Триггер «конвертировать документ», «документ в уценку», «слово анализа», «документ в уценку», «слово», «слово в уценку».
