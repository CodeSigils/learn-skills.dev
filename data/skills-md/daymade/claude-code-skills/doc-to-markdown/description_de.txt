Konvertiert DOCX/PDF/PPTX in hochwertiges Markdown mit automatischer Nachbearbeitung. Behebt Pandoc-Rastertabellen, einfache Tabellen, Bildpfade, CJK-Fettabstände, Attributrauschen und Codeblöcke. Im Vergleich zu Docling, MarkItDown, Pandoc raw und Mammoth als Klassenbester bewertet (7,6/10). Auslösen bei „Dokument konvertieren“, „docx in Markdown“, „Wort analysieren“, „doc in Markdown“, „解析word“, „转换文档“.
