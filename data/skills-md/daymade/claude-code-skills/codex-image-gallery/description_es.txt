Inicie o reutilice una galería web local independiente para explorar imágenes generadas por Codex. Úselo cuando el usuario solicite explorar imágenes generadas por Codex, abrir una galería de imágenes local, inspeccionar ~/.codex/generated_images, ver una carpeta de salida de imágenes de Codex o explorar archivos de imágenes producidos por Codex.
