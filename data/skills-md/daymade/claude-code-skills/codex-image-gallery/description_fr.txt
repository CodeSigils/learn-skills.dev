Démarrez ou réutilisez une galerie Web locale autonome pour parcourir les images générées par le Codex. À utiliser lorsque l'utilisateur demande à parcourir les images générées par le Codex, à ouvrir une galerie d'images locale, à inspecter ~/.codex/generated_images, à afficher un dossier de sortie d'image du Codex ou à parcourir les fichiers image produits par le Codex.
