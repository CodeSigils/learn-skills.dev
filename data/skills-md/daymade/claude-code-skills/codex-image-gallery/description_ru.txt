Запустите или повторно используйте автономную локальную веб-галерею для просмотра изображений, созданных Кодексом. Используйте, когда пользователь просит просмотреть изображения, созданные Кодексом, открыть локальную галерею изображений, проверить ~/.codex/generated_images, просмотреть папку вывода изображений Кодекса или просмотреть файлы изображений, созданные Кодексом.
