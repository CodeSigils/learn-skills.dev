Avvia o riutilizza una galleria web locale autonoma per sfogliare le immagini generate dal Codex. Da utilizzare quando l'utente chiede di sfogliare le immagini generate dal Codex, aprire una galleria di immagini locale, ispezionare ~/.codex/generated_images, visualizzare una cartella di output delle immagini del Codex o sfogliare i file di immagine prodotti dal Codex.
