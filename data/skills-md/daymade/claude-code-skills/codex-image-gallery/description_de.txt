Starten oder verwenden Sie eine eigenständige lokale Webgalerie zum Durchsuchen von Codex-generierten Bildern. Verwenden Sie diese Option, wenn der Benutzer von Codex generierte Bilder durchsuchen, eine lokale Bildergalerie öffnen, ~/.codex/generated_images überprüfen, einen Codex-Bildausgabeordner anzeigen oder von Codex erstellte Bilddateien durchsuchen möchte.
