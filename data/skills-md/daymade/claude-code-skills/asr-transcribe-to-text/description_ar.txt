قم بنسخ ملفات الصوت والفيديو إلى نص باستخدام خدمة ASR عن بعد (Qwen3-ASR أو نقطة النهاية المتوافقة مع OpenAI). يستخرج الصوت من الفيديو، ويرسله إلى نقطة نهاية ASR قابلة للتكوين، ويخرج نصًا نظيفًا. يُستخدم عندما يريد المستخدم نسخ التسجيلات، أو تحويل الصوت/الفيديو إلى نص، أو تحويل الكلام إلى نص، أو يذكر ASR أو Qwen ASR أو 转录 أو 语音转文字 أو 录音转文字، أو لديه تسجيل اجتماع أو محاضرة أو مقابلة أو تسجيل شاشة للنسخ.
