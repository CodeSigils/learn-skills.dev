Transcriba archivos de audio y video a texto utilizando un servicio ASR remoto (Qwen3-ASR o punto final compatible con OpenAI). Extrae audio del vídeo, lo envía a un punto final ASR configurable y genera texto limpio. Úselo cuando el usuario desee transcribir grabaciones, convertir audio/video a texto, convertir voz a texto o mencione ASR, Qwen ASR, 转录, 语音转文字, 录音转文字, o tenga una grabación de reunión, conferencia, entrevista o grabación de pantalla para transcribir.
