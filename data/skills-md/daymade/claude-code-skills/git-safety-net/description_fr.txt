Audite, préserve, récupère et retire en toute sécurité l'état Git local : validations non poussées ou de mauvaise branche, arbres de travail sales ou détachés, clones en double oubliés du même dépôt, travail non suivi qu'aucun bundle ne peut sauvegarder, caches orphelins, validations en suspens, branches obsolètes et incertitude de fusion d'écrasement/rebase. À utiliser lorsque l'utilisateur craint que son travail ne soit perdu ; demande de récupérer un commit ou une branche ; demande si un répertoire d'arbre de travail, de clone ou de travail peut être supprimé ; veut que tout converge vers une seule branche principale ; ou a besoin d'une preuve que le nettoyage ne fera pas tomber le travail. Utilisez-le même après un audit signalé comme étant propre – la lacune habituelle est la portée : chaque commande dans le dépôt est aveugle à un deuxième clone ailleurs sur le disque. Déclencheurs sur « ai-je perdu du travail », « est-ce que tout a été fusionné », « est-ce que tout le reste est perdu », « supprimer ce clone en toute sécurité », « nettoyer les anciennes branches/caches », « ne garder qu'une seule branche principale », « git reflog », « commits suspendus », « 分支灾难 », « 误删分支/commit », « worktree 能删吗 », "还有没有丢的东西", "只保留一个主分支". Couvre l’investigation Git locale, et non les opérations GitHub PR/API ou la synchronisation de routine.
