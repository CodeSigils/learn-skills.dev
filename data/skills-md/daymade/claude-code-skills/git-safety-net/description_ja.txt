ローカルの Git 状態を監査、保存、回復し、安全にリタイアします。プッシュされていないコミットや間違ったブランチのコミット、汚れたワークツリーや切り離されたワークツリー、同じリポジトリの忘れられた重複クローン、バンドルでバックアップできない追跡されていない作業、孤立したスタッシュ、ダングリングコミット、古いブランチ、スカッシュ/リベースマージの不確実性などです。ユーザーが作業内容が失われるのではないかと心配する場合に使用します。コミットまたはブランチを回復するように要求します。ワークツリー、クローン、またはスクラッチ ディレクトリを削除できるかどうかを尋ねます。すべてを 1 つのメイン ブランチに集中させたいと考えています。または、クリーンアップによって作業が中断されないことを証明する必要があります。監査でクリーンと報告された後でも使用してください。通常のギャップはスコープです。すべてのリポジトリ内コマンドは、ディスク上の別の場所にある 2 番目のクローンに対してブラインドです。トリガーは、「仕事は失われましたか」、「すべてマージされましたか」、「他に失われたものはありますか」、「このクローンは安全に削除できます」、「古いブランチ/スタッシュをクリーンアップ」、「メイン ブランチを 1 つだけ保持する」、「git reflog」、「ダングリング コミット」、「分支灾难」、「误删分支/commit」、「worktree 能删吗」、 「还有有没东西」、「只存一主分支」。 GitHub PR/API 操作や日常的な同期ではなく、ローカル Git フォレンジックをカバーします。
