審核、保留、恢復和安全地退役本地 Git 狀態：未推送或錯誤分支提交、髒或分離的工作樹、同一存儲庫的遺忘重複克隆、無法跟踪的工作，沒有捆綁包可以備份、孤立的存儲、懸空的提交、過時的分支以及壓縮/變基合併不確定性。當使用者擔心工作遺失時使用；要求恢復提交或分支；詢問是否可以刪除工作樹、克隆或臨時目錄；希望一切都匯聚到一個主幹上；或者需要證明清理不會導致工作失敗。即使在審計報告乾淨之後也可以使用它 - 通常的差距是範圍：每個 in-repo 命令對磁碟上其他地方的第二個克隆都是盲目的。觸發「我失去工作了嗎」、「所有東西都合併了嗎」、「還有其他東西丟失嗎」、「安全刪除這個克隆」、「清理舊分支/隱藏」、「只保留一個主分支」、「git reflog」、「懸空提交」、「分支災難」、「誤刪除分支/提交」、「工作樹能刪除涵蓋本機 Git 取證，而不是 GitHub PR/API 操作或例程同步。
