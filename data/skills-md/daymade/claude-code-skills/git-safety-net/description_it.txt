Controlla, preserva, recupera e ritira in modo sicuro lo stato Git locale: commit non inviati o di rami errati, alberi di lavoro sporchi o scollegati, cloni duplicati dimenticati dello stesso repository, lavoro non tracciato di cui nessun bundle può eseguire il backup, stash orfani, commit penzolanti, rami obsoleti e incertezza sull'unione di squash/rebase. Utilizzare quando l'utente teme che il lavoro sia andato perso; chiede di recuperare un commit o un ramo; chiede se è possibile eliminare una directory worktree, clone o scratch; vuole che tutto converga su un ramo principale; o ha bisogno di prove che la pulizia non interromperà il lavoro. Usalo anche dopo che un audit è stato segnalato come pulito: la solita lacuna è l'ambito: ogni comando in-repo è cieco rispetto a un secondo clone altrove sul disco.
