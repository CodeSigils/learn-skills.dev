Запускайте настольное приложение Kimi (Kimi.app) через использование компьютера, чтобы выполнять запросы к встроенным плагинам данных — базе компаний 天眼查, финансовым данным 同花顺 iFinD, 财新数据, S&P Global Market Intelligence, 恒生聚源, SEC, МВФ, открытым данным Всемирного банка, академическим базам, юридическим базам и др. — используя текущую авторизованную сессию Kimi пользователя, без необходимости отдельных API‑ключей. Используйте, когда пользователь говорит «用 Kimi 查» / «操作 Kimi 客户端» / «Kimi 插件», просит получить сведения о акционерах компании, финансовой отчётности, рыночных данных или академических/юридических записях через Kimi, либо нуждается в источнике данных, не имеющем отдельного API, но доступном как плагин Kimi. Охватывает как Claude Code (компьютерное использование MCP), так и Codex (компьютерный плагин), шаблоны запрос‑подсказок, заставляющие давать честные ответы с указанием источника, и дисциплину перекрёстной проверки, требуемую для данных, полученных со скриншотов. Не относится к автоматизации браузера kimi.com (это kimi‑webbridge) или к прямому доступу к iFinD API с учётными данными.
