Управляйте настольным приложением Kimi (Kimi.app) с помощью функции computer-use, чтобы запрашивать его встроенные плагины данных — 天眼查 корпоративные записи, 同花顺 iFinD финансовые данные, 财新数据, 标普全球市场财智, 恒生聚源, SEC, МВФ, общедоступные данные Всемирного банка, академические базы данных, юридические базы данных и прочие — через собственную авторизованную сессию Kimi пользователя, без отдельных API‑ключей. Используйте это каждый раз, когда пользователь говорит «用 Kimi 查» / «操作 Kimi 客户端» / «Kimi 插件», запрашивает информацию о акционерах компании, финансовой отчётности, рыночных данных или академических/юридических записях через Kimi, либо нуждается в источнике данных, у которого нет отдельного API, но который доступен как плагин Kimi. Охватывает как управление Claude Code (computer‑use MCP), так и плагин Codex (computer plugin), шаблоны запросов‑подсказок, заставляющие давать ответы с указанием источника и честностью, а также дисциплину кросс‑проверки, требуемую при транскрибированных с экрана данных. Не предназначено для автоматизации браузера kimi.com (это kimi‑webbridge) и не для прямого доступа к iFinD API с учётными данными.
