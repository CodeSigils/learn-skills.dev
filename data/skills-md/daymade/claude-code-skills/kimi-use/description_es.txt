Utilice la aplicación de escritorio Kimi (Kimi.app) mediante el uso de la computadora para consultar sus complementos de datos integrados: 天眼查 Company Records, 同花顺 iFinD Financials, 财新数据, 标普全球市场财智, 恒生聚源, SEC, IMF,世界银行公开数据, 学术数据库, 法律数据库 y más, a través de la propia sesión de Kimi del usuario, sin claves API separadas. Úselo siempre que el usuario diga "用 Kimi 查" / "操作 Kimi 客户端" / "Kimi 插件", solicite buscar accionistas de la empresa, estados financieros, datos de mercado o registros académicos/legales a través de Kimi, o necesite una fuente de datos que no tenga una API independiente pero que exista como un complemento de Kimi. Cubre tanto la conducción de Claude Code (MCP para uso informático) como Codex (complemento informático), patrones de mensajes de consulta que fuerzan respuestas honestas etiquetadas en la fuente y la disciplina de verificación cruzada que requieren los datos transcritos en pantalla. No para la automatización del navegador kimi.com (es decir, kimi-webbridge) ni para el acceso directo a la API iFinD con credenciales.
