Kimi デスクトップアプリ (Kimi.app) をコンピュータ操作で駆動し、組み込みデータプラグイン — 天眼查 企業レコード、同花順 iFinD 財務情報、财新数据、標準普爾グローバルマーケットインテリジェンス、恒生聚源、SEC、IMF、世界銀行公開データ、学術データベース、法務データベースなど — を、ユーザーが自分の Kimi セッションにログインした状態で、別個の API キーを使用せずに照会します。ユーザーが「用 Kimi 查」や「操作 Kimi 客户端」や「Kimi 插件」と言ったとき、企業の株主、財務諸表、市場データ、学術／法務記録の取得を Kimi 経由で求める場合、またはスタンドアロン API が存在せず Kimi プラグインとして利用できるデータソースが必要な場合に利用します。Claude Code（コンピュータ使用 MCP）と Codex（コンピュータプラグイン）による駆動、ソースラベル付きの正直な回答を強制するクエリ・プロンプトパターン、そして画面転写データが要求するクロスチェックの規律を網羅します。kimi.com のブラウザ自動化（kimi-webbridge）や直接認証された iFinD API アクセス用ではありません。
