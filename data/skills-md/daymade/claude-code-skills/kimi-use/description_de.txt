Führen Sie die Kimi-Desktop-App (Kimi.app) durch Computernutzung aus, um die integrierten Daten-Plugins abzufragen – Unternehmensdatensätze, iFinD-Finanzdaten, Bankenaufsicht, Bankenaufsicht, Börsenaufsicht, SEC, IWF,世界银行公开数据, 学术数据库, 法律数据库 und mehr – über die eigene angemeldete Kimi-Sitzung des Benutzers, ohne separate API-Schlüssel. Wird immer dann verwendet, wenn der Benutzer „用 Kimi 查“ / „操作 Kimi 客户端“ / „Kimi 插件“ sagt, Unternehmensaktionäre, Jahresabschlüsse, Marktdaten oder akademische/juristische Aufzeichnungen über Kimi abrufen möchte oder eine Datenquelle benötigt, die über keine eigenständige API verfügt, sondern als Kimi-Plugin vorliegt. Behandelt sowohl die Steuerung von Claude Code (Computer-MCP) als auch Codex (Computer-Plugin), Abfragemuster, die ehrliche Antworten mit Quellenangabe erzwingen, und die Gegenprüfungsdisziplin, die bildschirmtranskribierte Daten erfordern. Nicht für die Browserautomatisierung von kimi.com (das ist kimi-webbridge) oder für den direkten iFinD-API-Zugriff mit Anmeldeinformationen.
