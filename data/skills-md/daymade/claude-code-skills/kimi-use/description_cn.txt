通过计算机驱动Kimi桌面应用程序（Kimi.app），通过用户自己登录的Kimi会话查询其内置数据插件——天眼查公司记录、同花顺iFinD金融、财新数据、标普全球市场财智、恒生聚源、SEC、IMF、世界银行公开数据、学术数据库、法律数据库等，无需单独的API密钥。每当用户说“用 Kimi 查”/“操作 Kimi 客户端”/“Kimi 插件”时使用，要求通过 Kimi 获取公司股东、财务报表、市场数据或学术/法律记录，或者需要没有独立 API 但作为 Kimi 插件存在的数据源。涵盖 Claude Code（计算机使用的 MCP）和 Codex（计算机插件）驱动、强制源标记诚实答案的查询提示模式，以及屏幕转录数据所需的交叉检查规则。不适用于 kimi.com 浏览器自动化（即 kimi-webbridge）或直接经过认证的 iFinD API 访问。
