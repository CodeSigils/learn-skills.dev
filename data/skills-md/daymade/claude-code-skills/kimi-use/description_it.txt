Guida l'app desktop Kimi (Kimi.app) attraverso l'uso del computer per interrogare i suoi plug-in di dati integrati: record aziendali di 天眼查, dati finanziari iFinD, 财新数据, 标普全球市场财智, 恒生聚源, SEC, FMI,世界银行公开数据, 学术数据库, 法律数据库 e altro ancora, tramite la sessione Kimi dell'utente che ha effettuato l'accesso, senza chiavi API separate. Da utilizzare ogni volta che l'utente dice "用 Kimi 查" / "操作 Kimi 客户端" / "Kimi 插件", chiede di recuperare azionisti dell'azienda, rendiconti finanziari, dati di mercato o documenti accademici/legali tramite Kimi oppure necessita di un'origine dati che non dispone di un'API autonoma ma esiste come plug-in Kimi. Copre sia la guida del Claude Code (MCP per uso del computer) che del Codex (plug-in del computer), i modelli di richiesta di query che impongono risposte oneste etichettate alla fonte e la disciplina del controllo incrociato richiesta dai dati trascritti su schermo. Non per l'automazione del browser kimi.com (ovvero kimi-webbridge) o per l'accesso diretto all'API iFinD con credenziali.
