Pilotez l'application de bureau Kimi (Kimi.app) via l'ordinateur pour interroger ses plug-ins de données intégrés : dossiers d'entreprise, documents financiers iFinD, documents financiers, SEC, FMI,世界银行公开数据, 学术数据库, 法律数据库 et plus encore — via la propre session Kimi connectée de l'utilisateur, sans clé API distincte. À utiliser chaque fois que l'utilisateur dit « 用 Kimi 查 » / « 操作 Kimi 客户端 » / « Kimi 插件 », demande à récupérer les actionnaires de l'entreprise, les états financiers, les données de marché ou les dossiers académiques/juridiques via Kimi, ou a besoin d'une source de données qui n'a pas d'API autonome mais existe en tant que plugin Kimi. Couvre à la fois la conduite de Claude Code (MCP utilisé sur ordinateur) et du Codex (plugin informatique), les modèles d'invite de requête qui forcent des réponses honnêtes étiquetées à la source et la discipline de vérification croisée requise par les données transcrites à l'écran. Pas pour l'automatisation du navigateur kimi.com (c'est-à-dire kimi-webbridge) ou pour un accès direct à l'API iFinD avec accréditation.
