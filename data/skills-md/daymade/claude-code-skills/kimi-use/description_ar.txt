قم بتشغيل تطبيق Kimi لسطح المكتب (Kimi.app) من خلال استخدام الكمبيوتر للاستعلام عن مكونات البيانات الإضافية المضمنة - سجلات الشركة، وبيانات iFinD المالية، وSEC، وصندوق النقد الدولي،世界银行公开数据، 学术数据库، 法律数据库 والمزيد - من خلال جلسة Kimi التي قام المستخدم بتسجيل الدخول بها، بدون مفاتيح API منفصلة. يُستخدم عندما يقول المستخدم "用 Kimi 查" / "操作 Kimi 客户端" / "Kimi 插件"، ويطلب جلب المساهمين في الشركة، أو البيانات المالية، أو بيانات السوق، أو السجلات الأكاديمية/القانونية عبر Kimi، أو يحتاج إلى مصدر بيانات لا يحتوي على واجهة برمجة تطبيقات مستقلة ولكنه موجود كمكون إضافي لـ Kimi. يغطي كلاً من Claude Code (MCP لاستخدام الكمبيوتر) وCodex (المكونات الإضافية للكمبيوتر)، وأنماط الاستعلام الفوري التي تفرض إجابات صادقة مصنفة حسب المصدر، ونظام التحقق المتبادل الذي تتطلبه البيانات المكتوبة على الشاشة. ليس مخصصًا لأتمتة متصفح kimi.com (أي kimi-webbridge) أو للوصول المباشر إلى iFinD API.
