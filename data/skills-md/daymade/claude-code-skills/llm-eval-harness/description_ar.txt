قم بتقييم أي LLM خلف نقطة نهاية متوافقة مع OpenAI أو Anthropic عبر أربعة أبعاد: السرعة (TTFT + الرموز المميزة للتفكير في الثانية)، والتزامن/الاستقرار (معدل النجاح، وزمن الوصول p50/p90، والمستوى الذي ينكسر فيه)، والامتثال للبروتوكول البشري (معدل تحفيز كتلة التفكير)، وانحدار الجودة مقابل حالات الاستخدام المتراكمة الخاصة بك (دقة القاضي الأعمى). استخدمه عندما يرغب شخص ما في قياس نموذج أو اختباره أو التحقق من مطالبة البائع بالرموز المميزة في الثانية، أو مقارنة نموذجين وجهاً لوجه، أو تحديد ما إذا كان النموذج الذي تم إصداره حديثًا سريعًا/مستقرًا/جيدًا بما يكفي قبل اعتماده، أو قياس TTFT أو فك تشفير الإنتاجية، أو التحقق من حدود التزامن قبل ورشة عمل أو مهمة مجمعة، أو التحقق مما إذا كانت نقطة النهاية "المتوافقة مع البشر" تنفذ بالفعل كتل التفكير. مشغلات "قياس هذا النموذج"، "测一下这个模型的速度/ 质量"، "هل X tok/s حقيقي"، "قارن النموذج A vs B"، "这个模型能不能扛住并发"، "接入新模型 先测一下"، حتى بدون كلمة "eval".
