OpenAI または Anthropic と互換性のあるエンドポイントの背後にある LLM を、速度 (TTFT + 思考認識トークン/秒)、同時実行性/安定性 (成功率、p50/p90 レイテンシー、中断レベル)、Anthropic プロトコルへの準拠 (思考ブロックのトリガー率)、および独自の蓄積されたユースケースに対する品質回帰 (ブラインドジャッジの精度) の 4 つの次元で評価します。モデルのベンチマーク、評価、または压测を行いたい場合、ベンダーの 1 秒あたりのトークン数の検証を確認したい場合、2 つのモデルを直接比較したい場合、新しくリリースされたモデルを採用する前に高速/安定/十分に優れているかどうかを判断したい場合、TTFT またはデコードのスループットを測定したい場合、ワークショップやバッチ ジョブの前に同時実行制限を調査したい場合、または「人間互換」エンドポイントが実際に思考ブロックを実装しているかどうかを確認したい場合に使用します。 「eval」という単語がなくても、「このモデルのベンチマーク」、「测一下这个モデルの速度/质量」、「X tok/s real」、「モデル A vs B の比較」、「このモデル能扛住并発行」、「接入新モデル先测一下」でトリガーされます。
