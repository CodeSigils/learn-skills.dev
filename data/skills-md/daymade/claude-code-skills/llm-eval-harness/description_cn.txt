从四个维度评估 OpenAI 或 Anthropic 兼容端点背后的任何 LLM：速度（TTFT + 思考感知令牌/秒）、并发性/稳定性（成功率、p50/p90 延迟、中断级别）、Anthropic 协议合规性（思维块触发率）以及针对您自己积累的用例的质量回归（盲判精度）。每当有人想要对模型进行基准测试、审查或压测时使用，验证供应商的每秒代币声明，正面比较两个模型，在采用新发布的模型之前确定它是否足够快/稳定/足够好，测量 TTFT 或解码吞吐量，在研讨会或批处理作业之前探测并发限制，或者检查“人类兼容”端点是否真正实现了思维块。触发“对这个模型进行基准测试”，“测量一下这个模型的速度/质量”，“X是否真实”，“比较模型A与B”，“这个模型不能承载住住”，“接入新模型先测量一下”，即使没有“评估”一词。
