Esporta e sincronizza le raccolte di libri/film/musica/giochi Douban (豆瓣) in file CSV locali tramite l'API Frodo. Supporta l'esportazione completa (tutta la cronologia) e la sincronizzazione incrementale RSS (elementi recenti). Da utilizzare quando l'utente desidera esportare la cronologia di lettura/visione/ascolto/gioco di Douban, eseguire il backup dei propri dati Douban, impostare la sincronizzazione incrementale o menzionare raccolte 豆瓣/douban. Si attiva su: 豆瓣, douban, 读书记录, 观影记录, 书影音, 导出豆瓣, esportazione, backup, sincronizzazione, raccolta.
