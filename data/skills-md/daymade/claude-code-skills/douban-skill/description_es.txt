Exporte y sincronice colecciones de libros, películas, música y juegos de Douban (豆瓣) a archivos CSV locales a través de la API de Frodo. Admite exportación completa (todo el historial) y sincronización incremental de RSS (elementos recientes). Úselo cuando el usuario desee exportar el historial de lectura, visualización, escucha o juegos de Douban, hacer una copia de seguridad de sus datos de Douban, configurar una sincronización incremental o mencionar colecciones de 豆瓣/douban. Se activa en: 豆瓣, douban, 读书记录, 观影记录, 书影音, 导出豆瓣, exportación, copia de seguridad, sincronización, recopilación.
