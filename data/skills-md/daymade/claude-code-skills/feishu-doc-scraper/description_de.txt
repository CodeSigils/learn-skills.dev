Speichern Sie Feishu Docs- und Feishu Wiki-Seiten als sauberes Markdown aus einer live authentifizierten Browsersitzung. Diese Fähigkeit sollte verwendet werden, wenn der Benutzer nach „Speichern dieses Feishu-Dokuments als Markdown“, „Scrapen/Exportieren eines Feishu-Wikis“, „导出飞书文档“, „保存飞书到 Markdown“, „把 Chrome 里的飞书页面存成 md“ fragt oder eine Feishu-Seite möchte lokal mit hoher Wiedergabetreue archiviert. Verwenden Sie es proaktiv, wenn es sich bei der Quelle um ein Feishu-Dokument handelt und es auf Korrektheit ankommt, auch wenn der Benutzer nur das Ausschneiden, Archivieren oder Konvertieren der Seite angibt.
