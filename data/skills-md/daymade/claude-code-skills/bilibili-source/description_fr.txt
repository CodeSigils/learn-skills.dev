Récupérez des données complètes et sans connexion pour n'importe quelle vidéo Bilibili (B站) : titre, nom UP et nombre de followers, date de publication, partition, tags, cids par partie, statistiques en direct (vue, j'aime, pièce, favori, partage, réponse, danmaku) et texte complet de danmaku (puce-commentaire). Utilisez cette compétence chaque fois que vous travaillez avec une vidéo Bilibili et que vous avez besoin de chiffres ou de métadonnées réels et citables – ingérer une source Bilibili dans une base de connaissances, analyser la raison pour laquelle une vidéo a été réalisée, vérifier les mesures revendiquées par un créateur, créer une étude de cas ou chaque fois qu'un nombre de vues/j'aime/favoris Bilibili est sur le point d'être écrit dans un document – ​​récupérez-le, ne le tapez jamais à la main ni ne l'estimez. Accepte les numéros BVID, AV, les liens courts b23.tv ou les URL complètes. Les sous-titres sont également couverts mais nécessitent la connexion Bilibili de l'utilisateur.
