Rufen Sie umfassende, anmeldefreie Daten für jedes Bilibili (B站)-Video ab – Titel, UP-Name und Follower-Anzahl, Veröffentlichungsdatum, Partition, Tags, CIDs pro Teil, Live-Statistiken (Ansehen, Liken, Coin, Favorit, Teilen, Antworten, Danmaku) und vollständigen Danmaku-Text (Bullet-Kommentar). Verwenden Sie diese Fähigkeit immer dann, wenn Sie mit einem Bilibili-Video arbeiten und echte, zitierfähige Zahlen oder Metadaten benötigen – zum Einbinden einer Bilibili-Quelle in eine Wissensdatenbank, zum Analysieren der Leistung eines Videos, zum Überprüfen der behaupteten Kennzahlen eines Erstellers, zum Erstellen einer Fallstudie oder immer dann, wenn eine Anzahl von Bilibili-Ansichten/Gefällt mir/Favoriten in ein Dokument geschrieben werden soll – rufen Sie sie ab, geben Sie sie niemals von Hand ein oder schätzen Sie sie. Akzeptiert BVID, AV-Nummern, b23.tv-Kurzlinks oder vollständige URLs. Untertitel sind ebenfalls abgedeckt, erfordern jedoch den Bilibili-Login des Benutzers.
