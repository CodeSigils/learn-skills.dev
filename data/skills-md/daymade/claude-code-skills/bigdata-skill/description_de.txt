Ziehen Sie Finanz- und Nachrichtendaten von Bigdata.com (RavenPack) über das offizielle „bigdata-client“-SDK und seine öffentlichen „/v1/*“-REST-Endpunkte, wenn der Bigdata-MCP-Server nur vorsynthetisierte Tearsheets zurückgibt, Sie aber das maschinenlesbare Substrat darunter benötigen. Die MCP-Suche gibt Prosablöcke zurück (nur Text + Relevanz – kein Sentiment pro Block, keine Entitätsspannen); Seine Tearsheets liefern nur aggregierte Werte, keine berechenbaren Zeitreihen oder JSON pro Feld. Dieser Skill bündelt ein verifiziertes, kostengeschütztes Toolkit über die offizielle REST-API: kommentierte Chunk-Suche, Entitäts-/ISIN-Auflösung, Analystenschätzungen, Kalender/Überraschung/Bewertungen/Ziele, Finanzberichte, TTM-Metriken und -Verhältnisse, Preise, Dividenden, Umsatzsegmente, eine tägliche Entitäts-Sentiment-Reihe, Co-Erwähnungsdiagramm, Screener und Batch-Suche. Verwenden Sie es immer dann, wenn der Benutzer Bigdata.com, RavenPack, einen „bd_v2_“-Schlüssel, den Bigdata-MCP, rp_entity_id, chunk/query_unit-Kosten erwähnt oder strukturierte Finanzdaten, Fundamentaldaten, Preise, Stimmung oder kommentierte Nachrichten wünscht.
