当 Bigdata MCP 服务器仅返回预先合成的撕纸但您需要下面的机器可读基材时，通过官方“bigdata-client”SDK 及其公共“/v1/*”REST 端点提取 Bigdata.com (RavenPack) 金融和新闻数据。 MCP 搜索返回散文块（仅文本 + 相关性 — 没有每个块的情感，没有实体跨度）；它的撕样仅提供聚合值，而不提供可计算的时间序列或每个字段的 JSON。该技能在官方 REST API 上捆绑了一个经过验证、成本保护的工具包：带注释的块搜索、实体/ISIN 解析、分析师估计、日历/惊喜/评级/目标、财务报表、TTM 指标和比率、价格、股息、收入细分、每日实体情绪系列、提及图、筛选器和批量搜索。每当用户提及 Bigdata.com、RavenPack、“bd_v2_”密钥、bigdata MCP、rp_entity_id、chunk/query_unit 成本，或者想要结构化财务、基本面、价格、情绪或带注释的新闻时，请使用它。
