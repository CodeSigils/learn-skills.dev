Bigdata MCP 서버가 사전 합성된 테어시트만 반환하지만 아래에 기계 판독 가능한 인쇄물이 필요한 경우 공식 'bigdata-client' SDK 및 공개 '/v1/*' REST 엔드포인트를 통해 Bigdata.com(RavenPack) 금융 및 뉴스 데이터를 가져옵니다. MCP 검색은 산문 청크를 반환합니다(텍스트 + 관련성만 — 청크별 감정 없음, 엔터티 범위 없음). 테어시트는 계산 가능한 시계열이나 필드별 JSON이 아닌 집계 값만 제공합니다. 이 기술은 공식 REST API를 통해 검증되고 비용이 보호되는 툴킷을 번들로 제공합니다. 주석이 달린 청크 검색, 엔터티/ISIN 해결, 분석가 추정, 일정/서프라이즈/등급/목표, 재무제표, TTM 지표 및 비율, 가격, 배당금, 수익 세그먼트, 일일 엔터티 감정 시리즈, 공동 언급 그래프, 스크리너 및 일괄 검색. 사용자가 Bigdata.com, RavenPack, `bd_v2_` 키, 빅데이터 MCP, rp_entity_id, 청크/쿼리_단위 비용을 언급하거나 구조화된 재무, 기본 사항, 가격, 감정 또는 주석이 달린 뉴스를 원할 때마다 이를 사용하십시오.
