Extraiga datos financieros y de noticias de Bigdata.com (RavenPack) a través del SDK oficial `bigdata-client` y sus puntos finales REST públicos `/v1/*` cuando el servidor Bigdata MCP devuelva solo hojas presintetizadas pero necesite el sustrato legible por máquina debajo. La búsqueda de MCP devuelve fragmentos de prosa (solo texto + relevancia, sin sentimiento por fragmento, sin intervalos de entidades); sus hojas impresas solo brindan valores agregados, no series de tiempo computables o JSON por campo. Esta habilidad incluye un conjunto de herramientas verificado y con costos protegidos a través de la API REST oficial: búsqueda de fragmentos anotados, resolución de entidad/ISIN, estimaciones de analistas, calendario/sorpresa/calificaciones/objetivos, estados financieros, métricas y proporciones de TTM, precios, dividendos, segmentos de ingresos, una serie diaria de sentimiento de entidad, gráfico de menciones conjuntas, filtro y búsqueda por lotes. Úselo siempre que el usuario mencione Bigdata.com, RavenPack, una clave `bd_v2_`, el MCP de bigdata, rp_entity_id, el costo de fragmento/query_unit o quiera información financiera estructurada, fundamentos, precios, sentimiento o noticias comentadas.
