اسحب البيانات المالية والأخبار الخاصة بـ Bigdata.com (RavenPack) من خلال SDK الرسمي `bigdata-client` ونقاط نهاية REST العامة `/v1/*` عندما يقوم خادم Bigdata MCP بإرجاع الأوراق المُصنعة مسبقًا فقط ولكنك تحتاج إلى الركيزة التي يمكن قراءتها بواسطة الآلة تحتها. يُرجع بحث MCP قطعًا نثرية (النص + الصلة فقط - لا توجد مشاعر لكل قطعة، ولا توجد امتدادات للكيان)؛ تعطي أوراقها الممزقة قيمًا مجمعة فقط، وليست سلاسل زمنية قابلة للحساب أو JSON لكل حقل. تجمع هذه المهارة مجموعة أدوات تم التحقق منها وحمايتها من حيث التكلفة عبر واجهة برمجة تطبيقات REST الرسمية: البحث عن الأجزاء المشروحة، وحل الكيان/رقم ISIN، وتقديرات المحللين، والتقويم/المفاجأة/ التقييمات/الأهداف، والبيانات المالية، ومقاييس ونسب TTM، والأسعار، وأرباح الأسهم، وقطاعات الإيرادات، وسلسلة يومية من مشاعر الكيان، ورسم بياني للإشارة المشتركة، وأداة الفرز، والبحث المجمع. استخدمه عندما يذكر المستخدم Bigdata.com، أو RavenPack، أو مفتاح `bd_v2_`، أو bigdata MCP، أو rp_entity_id، أو تكلفة القطعة/query_unit، أو يريد البيانات المالية المنظمة، أو الأساسيات، أو الأسعار، أو المشاعر، أو الأخبار المشروحة.
