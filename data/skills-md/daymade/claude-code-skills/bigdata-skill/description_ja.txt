Bigdata MCP サーバーが事前に合成された切り取りシートのみを返すが、その下に機械可読基板が必要な場合は、公式 `bigdata-client` SDK とそのパブリック `/v1/*` REST エンドポイントを通じて Bigdata.com (RavenPack) の財務およびニュース データをプルします。 MCP 検索は散文チャンクを返します (テキスト + 関連性のみ - チャンクごとの感情やエンティティ スパンはありません)。切り取りシートには集計値のみが示されており、計算可能な時系列やフィールドごとの JSON は示されていません。このスキルには、公式 REST API を介した検証済みのコスト保護されたツールキットがバンドルされています。注釈付きチャンク検索、エンティティ/ISIN 解決、アナリストの推定、カレンダー/サプライズ/評価/目標、財務諸表、TTM 指標と比率、価格、配当、収益セグメント、日次エンティティセンチメント シリーズ、コメンション グラフ、スクリーナー、バッチ検索などです。ユーザーが Bigdata.com、RavenPack、「bd_v2_」キー、ビッグデータ MCP、rp_entity_id、chunk/query_unit コストについて言及する場合、または構造化された財務状況、ファンダメンタルズ、価格、センチメント、または注釈付きのニュースを必要とする場合は常に、これを使用します。
