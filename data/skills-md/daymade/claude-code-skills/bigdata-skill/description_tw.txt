當 Bigdata MCP 伺服器僅傳回預先合成的撕紙但您需要下面的機器可讀基材時，透過官方「bigdata-client」SDK 及其公共「/v1/*」REST 端點提取 Bigdata.com (RavenPack) 金融和新聞資料。 MCP 搜尋返回散文區塊（僅文字 + 相關性 — 沒有每個區塊的情感，沒有實體跨度）；它的撕樣僅提供聚合值，而不提供可計算的時間序列或每個欄位的 JSON。該技能在官方 REST API 上捆綁了一個經過驗證、成本保護的工具包：帶註釋的區塊搜尋、實體/ISIN 解析、分析師估計、日曆/驚喜/評級/目標、財務報表、TTM 指標和比率、價格、股息、收入細分、每日實體情緒系列、提及圖、篩選器和批量搜尋。每當使用者提及 Bigdata.com、RavenPack、「bd_v2_」金鑰、bigdata MCP、rp_entity_id、chunk/query_unit 成本，或想要結構化財務、基本面、價格、情緒或帶註釋的新聞時，請使用它。
