Estrai i dati finanziari e le notizie di Bigdata.com (RavenPack) attraverso l'SDK ufficiale "bigdata-client" e i suoi endpoint REST pubblici "/v1/*" quando il server MCP Bigdata restituisce solo i fogli di pubblicazione pre-sintetizzati ma è necessario il substrato leggibile dalla macchina sottostante. La ricerca MCP restituisce blocchi in prosa (solo testo + pertinenza: nessun sentimento per blocco, nessuna estensione di entità); i suoi riscontri di pubblicazione forniscono solo valori aggregati, non serie temporali calcolabili o JSON per campo. Questa competenza raggruppa un kit di strumenti verificato e a costi controllati tramite l'API REST ufficiale: ricerca di blocchi annotati, risoluzione di entità/ISIN, stime degli analisti, calendario/sorpresa/rating/obiettivi, rendiconti finanziari, metriche e rapporti TTM, prezzi, dividendi, segmenti di entrate, una serie giornaliera di sentimenti di entità, grafico delle co-menzioni, screener e ricerca batch. Usalo ogni volta che l'utente menziona Bigdata.com, RavenPack, una chiave `bd_v2_`, MCP bigdata, rp_entity_id, costo Chunk/query_unit o desidera dati finanziari strutturati, fondamentali, prezzi, sentiment o notizie annotate.
