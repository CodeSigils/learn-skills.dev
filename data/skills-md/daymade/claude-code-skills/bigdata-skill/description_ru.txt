Передавайте финансовые и новостные данные Bigdata.com (RavenPack) через официальный SDK bigdata-client и его общедоступные конечные точки REST `/v1/*`, когда сервер Bigdata MCP возвращает только предварительно синтезированные отрывные листы, но вам нужна машиночитаемая подложка под ними. Поиск MCP возвращает фрагменты прозы (только текст + релевантность — без тональности каждого фрагмента, без диапазонов сущностей); его таблицы предоставляют только совокупные значения, а не вычислимые временные ряды или JSON для каждого поля. Этот навык объединяет проверенный набор инструментов с ограниченными затратами через официальный REST API: поиск по аннотированным фрагментам, разрешение сущности/ISIN, оценки аналитиков, календарь/сюрприз/рейтинги/цели, финансовые отчеты, метрики и коэффициенты TTM, цены, дивиденды, сегменты доходов, ежедневная серия настроений компаний, график совместных упоминаний, скрининг и пакетный поиск. Используйте его всякий раз, когда пользователь упоминает Bigdata.com, RavenPack, ключ `bd_v2_`, bigdata MCP, rp_entity_id, стоимость chunk/query_unit или хочет структурировать финансовые показатели, фундаментальные показатели, цены, настроения или аннотированные новости.
