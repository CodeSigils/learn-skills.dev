Découvrez, envoyez des messages et coordonnez les sessions locales d'agents IA sur les profils Claude Code et les fils de discussion OpenAI Codex. À utiliser chaque fois que l'utilisateur demande à contacter un autre terminal/session/agent, indique le protocole de communication agent/agent de session 给另一个 发消息 / 问一下另一个窗口 / 广播给所有, a besoin de Claude et du Codex pour coordonner le travail, ou a besoin d'un hook/script pour publier dans une session en cours. Achemine les cibles de Claude via les outils officiels ListPeers/ListAgents + SendMessage lorsqu'ils sont disponibles et via le même protocole de boîte de réception UDS authentifié comme solution de secours ; achemine les cibles Codex via la « file d'attente codex --thread ». Prend en charge les diffusions explicites entre fournisseurs et la vérification de la livraison côté récepteur. Pas pour générer des agents, déplacer le contexte complet d'une conversation ou traiter un message d'un homologue comme une approbation de l'utilisateur.
