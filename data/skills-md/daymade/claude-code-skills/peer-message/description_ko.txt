Claude Code 프로필과 OpenAI Codex 스레드 전반에 걸쳐 로컬 AI 에이전트 세션을 검색하고, 메시지를 보내고, 조정합니다. 사용자가 다른 터미널/세션/에이전트에 연결하도록 요청할 때마다 사용합니다. 给另一个 session 发消息 / 问一下另一个窗口 / 广播给所有 에이전트/에이전트 통신 프로토콜이라고 말하거나, 작업을 조정하기 위해 Claude 및 Codex가 필요하거나, 실행 중인 세션에 게시하기 위해 후크/스크립트가 필요할 때마다 사용합니다. 사용 가능한 경우 공식 ListPeers/ListAgents + SendMessage 도구를 통해 그리고 대체 수단으로 동일한 인증된 UDS 받은 편지함 프로토콜을 통해 Claude 대상을 라우팅합니다. `codex queue --thread`를 통해 Codex 대상을 라우팅합니다. 명시적인 공급자 간 브로드캐스트 및 수신자 측 전달 확인을 지원합니다. 에이전트 생성, 전체 대화 컨텍스트 이동 또는 피어 메시지를 사용자 승인으로 처리하는 데는 적합하지 않습니다.
