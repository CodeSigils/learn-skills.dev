Claude Code プロファイルと OpenAI Codex スレッドにわたるローカル AI エージェント セッションを検出し、メッセージを送信し、調整します。ユーザーが別の端末/セッション/エージェントへの接続を要求する場合、给另一セッション発行消息 / 问一下另一窗口 / 广播给すべてのエージェント/エージェント通信プロトコルを要求する場合、作業を調整するために Claude と Codex が必要な場合、または実行中のセッションにポストするためのフック/スクリプトが必要な場合に使用します。公式の ListPeers/ListAgents + SendMessage ツール (利用可能な場合) およびフォールバックとして同じ認証された UDS 受信トレイ プロトコルを介して、クロード ターゲットをルーティングします。 Codex ターゲットを「codex queue --thread」を通じてルーティングします。明示的なクロスプロバイダーブロードキャストと受信側配信検証をサポートします。エージェントの生成、完全な会話コンテキストの移動、またはピア メッセージをユーザーの承認として扱うためのものではありません。
