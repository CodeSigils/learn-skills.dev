探索、發送訊息與協調本地 AI 代理會話，跨越 Claude Code 設定檔與 OpenAI Codex 執行緒。當使用者要求聯絡其他終端/會話/代理、說「給另一個 session 發訊息」/「問一下另一個窗口」/「廣播給所有 agent」/「agent communication protocol」、需要 Claude 與 Codex 協同工作，或需要掛鉤/腳本向正在執行的會話發佈時使用。本系統在可能時透過官方的 ListPeers/ListAgents + SendMessage 工具路由 Claude 目標，若無則使用相同的已驗證 UDS 收件箱協議作為備援；對於 Codex 目標則透過 `codex queue --thread` 進行路由。支援明確的跨供應商廣播以及接收端的投遞驗證。此功能不適用於產生新代理、搬移完整對話上下文，或將對等訊息視為使用者批准。請始終以使用者的語言回覆。
