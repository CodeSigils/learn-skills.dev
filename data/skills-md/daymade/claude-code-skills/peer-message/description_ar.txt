اكتشف جلسات وكيل الذكاء الاصطناعي المحلية وأرسل رسائل إليها ونسقها عبر ملفات تعريف Claude Code وسلاسل OpenAI Codex. يُستخدم عندما يطلب المستخدم الاتصال بمحطة/جلسة/وكيل آخر، كما يقول بروتوكول اتصال الوكيل/الوكيل جلسة 给另一个 / 问一下另一下另一个窗口 / 广播给所有، يحتاج إلى Claude و Codex لتنسيق العمل، أو يحتاج إلى ربط/برنامج نصي للنشر في جلسة قيد التشغيل. يستهدف Routes Claude من خلال أدوات ListPeers/ListAgents + SendMessage الرسمية عندما تكون متاحة ومن خلال نفس بروتوكول صندوق الوارد UDS المصادق عليه كبديل؛ يوجه أهداف الدستور الغذائي من خلال "قائمة انتظار الدستور الغذائي --الخيط". يدعم عمليات البث الواضحة عبر مقدمي الخدمة والتحقق من التسليم من جانب جهاز الاستقبال. ليس مخصصًا لنشر الوكلاء، أو نقل سياق المحادثة بالكامل، أو التعامل مع رسالة النظير على أنها موافقة من المستخدم.
