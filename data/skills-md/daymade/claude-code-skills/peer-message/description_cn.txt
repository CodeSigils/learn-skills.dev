跨 Claude Code 配置文件和 OpenAI Codex 线程发现、发送消息并协调本地 AI 代理会话。每当用户要求联系另一个终端/会话/代理时使用，说给另一个会话发消息/问一下另一个窗口/广播给所有代理/代理通信协议，需要 Claude 和 Codex 协调工作，或者需要一个钩子/脚本来发布到正在运行的会话中。通过官方 ListPeers/ListAgents + SendMessage 工具（如果可用）路由 Claude 目标，并通过相同的经过身份验证的 UDS 收件箱协议作为后备；通过“codex queue --thread”路由 Codex 目标。支持显式跨提供商广播和接收方传送验证。不适用于生成代理、移动完整的对话上下文或将对等消息视为用户批准。
