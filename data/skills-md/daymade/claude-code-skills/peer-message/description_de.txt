Entdecken, benachrichtigen und koordinieren Sie lokale KI-Agentensitzungen über Claude Code-Profile und OpenAI Codex-Threads hinweg. Wird immer dann verwendet, wenn der Benutzer Kontakt mit einem anderen Terminal/einer anderen Sitzung/einem anderen Agenten aufnehmen möchte, z. B. „给另一个 session 发消息 / 问一下另一个窗口 / 广播给所有 agent / agent communication Protocol“, Claude und Codex zur Koordinierung der Arbeit benötigt oder einen Hook/ein Skript zum Posten in eine laufende Sitzung benötigt. Leitet Claude-Ziele über die offiziellen ListPeers/ListAgents + SendMessage-Tools weiter, sofern verfügbar, und über dasselbe authentifizierte UDS-Posteingangsprotokoll als Fallback; leitet Codex-Ziele über „codex queue --thread“ weiter. Unterstützt explizite anbieterübergreifende Übertragungen und empfängerseitige Zustellungsüberprüfung. Nicht zum Spawnen von Agenten, zum Verschieben des vollständigen Konversationskontexts oder zum Behandeln einer Peer-Nachricht als Benutzergenehmigung.
