قم بتثبيت Scrapling CLI واستكشاف أخطائه وإصلاحها واستخدامه لاستخراج HTML أو Markdown أو النص من صفحات الويب. استخدم هذه المهارة عندما يذكر المستخدم Scrapling، أو `تثبيت أداة الأشعة فوق البنفسجية`، أو `Scrapling extract`، أو مقالات WeChat/mp.weixin، أو جلب الصفحات المدعومة بالمتصفح، أو عندما يحتاج إلى مساعدة في الاختيار بين الاستخراج الثابت والديناميكي.
