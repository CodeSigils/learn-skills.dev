قم بإجراء فحص صحي كامل سداسي الأبعاد لمستودع سوق مهارات Claude Code - سلامة التعليمات البرمجية/البرنامج النصي، والوثائق/اتساق SSOT، والأمان/تسريبات معلومات تحديد الهوية الشخصية، وفرز العلاقات العامة المفتوحة، وفرز المشكلات المفتوحة، والنزاهة الواضحة للسوق - عبر سير عمل ديناميكي متوازي وموزع، ثم تحقق من النتائج المهمة وقم بالإبلاغ عنها حسب الأولوية. استخدم هذا عندما يطلب المستخدم التحقق من الريبو، أو إجراء فحص صحي، أو إجراء عملية مسح/تدقيق كاملة قبل الإصدار، أو التحقق من صحة البيانات، أو التحقق من الصحة، أو التحقق من صحة البيانات، أو يسأل ما إذا كانت العلاقات العامة / المشكلات / المستندات / الإصدارات / معلومات تحديد الهوية الشخصية (PII) في حالة جيدة في جميع المجالات - حتى لو لم تذكر كلمة "سير العمل" مطلقًا. يمكنك الوصول إليه للحصول على أي طلب واسع النطاق "هل هذا الريبو بأكمله موافق"، وليس فقط عمليات فحص ملف واحد.
