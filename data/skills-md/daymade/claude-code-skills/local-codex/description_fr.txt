Lancez et gérez OpenAI Codex CLI (agent local) en tant que sous-agent de codage non interactif. À utiliser lorsque l'utilisateur souhaite déléguer des tâches de codage au Codex, exécuter des révisions de code, générer ou refactoriser du code, ou utiliser les capacités de l'agent Codex GPT-5.5 via la CLI locale. Se déclenche sur des expressions telles que « codex », « exécuter le codex », « codex exec », « révision du code avec le codex », « déléguer au codex », « utiliser le codex pour le codage » ou toute demande d'invocation de l'agent CLI Codex local. Utilise ChatGPT Pro OAuth (tarif forfaitaire, pas de frais d'API) via ~/.codex/auth.json. N'utilise jamais de clés API.
