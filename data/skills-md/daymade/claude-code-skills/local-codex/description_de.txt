Starten und verwalten Sie OpenAI Codex CLI (lokaler Agent) als nicht interaktiven Coding-Subagent. Verwenden Sie diese Option, wenn der Benutzer Codierungsaufgaben an Codex delegieren, Codeüberprüfungen durchführen, Code generieren oder umgestalten oder Codex GPT-5.5-Agentenfunktionen über die lokale CLI nutzen möchte. Wird bei Ausdrücken wie „Codex“, „Codex ausführen“, „Codex Exec“, „Codeüberprüfung mit Codex“, „an Codex delegieren“, „Codex zum Codieren verwenden“ oder bei jeder Anforderung zum Aufrufen des lokalen Codex-CLI-Agenten ausgelöst. Verwendet ChatGPT Pro OAuth (Flatrate, keine API-Gebühren) über ~/.codex/auth.json. Verwendet niemals API-Schlüssel.
