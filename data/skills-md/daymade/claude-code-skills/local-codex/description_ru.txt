Запускайте и управляйте OpenAI Codex CLI (локальный агент) в качестве неинтерактивного субагента кодирования. Используйте, когда пользователь хочет делегировать задачи кодирования Кодексу, запускать проверки кода, генерировать или рефакторить код или использовать возможности агента Codex GPT-5.5 через локальный интерфейс командной строки. Запускается по таким фразам, как «кодекс», «запустить кодекс», «исполнение кодекса», «проверка кода с помощью кодекса», «делегировать в кодекс», «использовать кодекс для кодирования» или любому запросу на вызов локального агента CLI Кодекса. Использует ChatGPT Pro OAuth (фиксированная ставка, без платы за API) через ~/.codex/auth.json. Никогда не использует ключи API.
