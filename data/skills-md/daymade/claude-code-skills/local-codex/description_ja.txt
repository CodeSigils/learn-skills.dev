OpenAI Codex CLI (ローカル エージェント) を非対話型コーディング サブエージェントとして起動して管理します。ユーザーがコーディング タスクを Codex に委任する場合、コード レビューを実行する場合、コードを生成またはリファクタリングする場合、またはローカル CLI を介して Codex GPT-5.5 エージェント機能を使用する場合に使用します。 「コーデックス」、「コーデックスの実行」、「コーデックス実行」、「コーデックスによるコード レビュー」、「コーデックスへの委任」、「コーディングにコーデックスを使用」などのフレーズ、またはローカルの Codex CLI エージェントを呼び出すリクエストでトリガーされます。 ~/.codex/auth.json 経由で ChatGPT Pro OAuth (定額料金、API 料金なし) を使用します。 API キーは決して使用しません。
