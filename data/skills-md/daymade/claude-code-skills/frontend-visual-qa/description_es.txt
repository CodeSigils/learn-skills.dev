Las revisiones renderizaron interfaces, sitios web, paneles, diapositivas HTML, muestras de sistemas de diseño, sistemas de diseño de artefactos en vivo y UI generadas para detectar defectos de calidad visual que fallan en la generación de pelusas, incluida la desalineación de etiquetas/entradas/ayudantes en la misma fila, desviación del eje de componentes hermanos, estado/rama de renderizado incorrecto y brechas en la recuperación del recorrido del usuario. Úselo al enviar o revisar la interfaz de usuario, especialmente después del trabajo de diseño de interfaz de usuario o de diseñador de interfaz de usuario, o cuando el usuario menciona saltos de línea incómodos, caracteres chinos huérfanos, texto apretado, botones/etiquetas/nav. ajustados, desbordamiento horizontal, barras de desplazamiento dobles, elementos superpuestos, pilas de tarjetas repetidas, tipo de página incorrecto, como un sistema de diseño que se convierte en un panel de aplicación, tipografía pequeña y densa, opciones de fuente/espaciado/ancho/escala de tipo incorrectas, pendiente genérica de IA, control de calidad de captura de pantalla, Chrome DevTools, o "mira la página tú mismo". Da prioridad a la ventana gráfica real de Chrome del usuario cuando está disponible y luego ejecuta barridos de escritorio/móviles programables.
