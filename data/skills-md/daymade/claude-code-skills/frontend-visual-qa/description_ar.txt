المراجعات المقدمة للواجهات الأمامية، ومواقع الويب، ولوحات المعلومات، وشرائح HTML، وعينات نظام التصميم، وأنظمة تصميم العناصر الحية، وواجهات المستخدم التي تم إنشاؤها لعيوب الجودة المرئية التي يفتقدها الوبر/البناء، بما في ذلك عدم محاذاة التسمية/الإدخال/المساعد في نفس الصف، وانجراف محور المكون الشقيق، والحالة/الفرع المعروض بشكل خاطئ، وفجوات استرداد رحلة المستخدم. يُستخدم عند شحن واجهة المستخدم أو مراجعتها، خاصةً بعد تصميم الواجهة الأمامية أو عمل مصمم واجهة المستخدم، أو عندما يذكر المستخدم فواصل أسطر غريبة، أو أحرف صينية يتيمة، أو نص ضيق، أو أزرار/علامات/تنقل ملفوفة، أو تجاوز أفقي، أو أشرطة تمرير مزدوجة، أو عناصر متداخلة، أو أكوام بطاقات متكررة، أو نوع صفحة خاطئ مثل تحول نظام التصميم إلى لوحة تحكم التطبيق، أو طباعة كثيفة صغيرة، أو اختيارات خاطئة للخط/التباعد/العرض/مقياس النوع، أو انحدار الذكاء الاصطناعي العام، أو لقطة الشاشة ضمان الجودة، أو Chrome DevTools، أو "إلقاء نظرة على الصفحة بنفسك". يعطي الأولوية لمنفذ عرض Chrome الحقيقي للمستخدم عندما يكون متاحًا، ثم يقوم بتشغيل عمليات مسح سطح المكتب/الجوال القابلة للبرمجة.
