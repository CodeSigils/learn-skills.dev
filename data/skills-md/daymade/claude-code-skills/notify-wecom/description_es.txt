Envíe un mensaje único a un bot de grupo WeCom (Enterprise WeChat). Utilice esta habilidad siempre que el usuario diga "/notify-wecom", "enviar un mensaje rápido de WeCom", "企微通知一下", "临时发一条企业微信" o cualquier notificación única que no necesite una plantilla reutilizable o un flujo de trabajo de configuración. El mensaje se envía inmediatamente; no se muestra ningún mensaje de confirmación a menos que el mensaje esté vacío o el webhook no esté configurado.
