Envoyez un message unique à un robot de groupe WeCom (Enterprise WeChat). Utilisez cette compétence chaque fois que l'utilisateur dit "/notify-wecom", "envoyer un message WeCom rapide", "企微通知一下", "临时发一条企业微信", ou toute notification ponctuelle qui ne nécessite pas de modèle réutilisable ou de flux de travail de configuration. Le message est envoyé immédiatement ; aucune invite de confirmation ne s'affiche, sauf si le message est vide ou si le webhook n'est pas configuré.
