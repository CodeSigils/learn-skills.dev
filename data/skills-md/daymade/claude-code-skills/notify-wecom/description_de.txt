Senden Sie eine einzelne einmalige Nachricht an einen WeCom-Gruppenbot (Enterprise WeChat). Verwenden Sie diesen Skill immer dann, wenn der Benutzer „/notify-wecom“, „eine schnelle WeCom-Nachricht senden“, „企微通知一下“, „临时发一条企业微信“ oder eine einmalige Benachrichtigung sagt, die keine wiederverwendbare Vorlage oder keinen Setup-Workflow erfordert. Die Nachricht wird sofort versendet; Es wird keine Bestätigungsaufforderung angezeigt, es sei denn, die Nachricht ist leer oder der Webhook ist nicht konfiguriert.
