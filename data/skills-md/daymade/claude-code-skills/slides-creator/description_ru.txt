Создание слайд-колоды с повествованием. Проводит пользователей через структурированный повествовательный дизайн (модель ABCDEFG), а затем делегирует создание визуальной информации baoyu-slide-deck. Запускается при «создании слайдов», «создании презентации», «создании презентации», «презентации слайдов», «PPT» или когда пользователю необходимо превратить контент в визуальные слайды.
