Trappole operative per i provisioner Terraform, isolamento multiambiente e affidabilità zero-to-deployment. Copre gare di timing del provisioner, conflitti di connessione SSH, duplicazione di record DNS, autorizzazioni di volume, lacune di bootstrap del database, contaminazione incrociata di snapshot, errori di formato delle credenziali Cloudflare, domini hardcoded in Caddyfiles/compose e insidie ​​​​di init-data-only-on-first-boot. Attivalo durante la scrittura di provisioner null_resource, la creazione di configurazioni Terraform multi-ambiente, il debug di contenitori che si riavviano/non integri dopo l'applicazione di Terraform, la configurazione di nuove istanze con cloud-init o qualsiasi codice IaC che esegue SSH in host remoti. Si attiva anche quando l'utente menziona errori di pianificazione/applicazione terraform, errori del provisioner, deviazione dell'infrastruttura, errori del certificato TLS o configurazione Caddy/gateway.
