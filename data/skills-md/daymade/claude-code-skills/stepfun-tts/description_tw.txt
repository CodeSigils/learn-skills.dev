使用 StepFun 的 StepAudio 2.5 系列產生語音並轉錄音訊 — stepaudio-2.5-tts（帶有指令 + 內嵌括號的上下文 TTS）和 stepaudio-2.5-asr（SSE 端點，32K 上下文，~100x RTF，在一次呼叫中處理長達 30 分鐘的音訊）。當使用者想要具有情感/韻律控制的中文/日文 TTS、需要轉錄長音訊、從 step-tts-2 遷移到 stepaudio-2.5-tts（voice_label → 指令破壞更改）或遇到 StepFun 審查/端點錯誤時使用。還會觸發諸如階躍 TTS、StepAudio 合成、語音合成、配音、StepFun ASR、解析、語音識別、文本轉語音、TTS 升級、遷移 step-tts-2 等短語。如果使用者的音訊任務提到了 StepFun/階躍/StepAudio 的名稱，或涉及具有情緒/情緒控制的中文 TTS，請在回退到通用音訊處理之前使用此技能。
