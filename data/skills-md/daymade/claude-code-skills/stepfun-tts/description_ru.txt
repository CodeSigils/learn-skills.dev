Генерируйте речь и расшифровывайте аудио с помощью семейства StepAudio 2.5 от StepFun — Stepaudio-2.5-tts (контекстный TTS с инструкциями + строчные круглые скобки) и Stepaudio-2.5-asr (конечная точка SSE, контекст 32 КБ, ~100x RTF, обрабатывает до 30-минутного звука за один вызов). Используйте, когда пользователю нужен китайский/японский TTS с эмоциональным/просодическим контролем, необходимо расшифровать длинный звук, переходит с шага tts-2 на шагаудио-2.5-tts (voice_label → изменение инструкции) или сталкивается с ошибками цензуры/конечной точки StepFun. Также срабатывает по таким фразам, как 阶跃 TTS, StepAudio 合成, 语音合成, 配音, StepFun ASR, 转录, 语音识别, 文本转语音, TTS 升级, 迁移шаг-ттс-2. Если в аудиозадаче пользователя упоминается StepFun/阶跃/StepAudio по имени или используется китайская TTS с управлением 情绪/情感, используйте этот навык, прежде чем вернуться к общей обработке звука.
