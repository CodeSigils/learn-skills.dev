Ändern oder reparieren Sie die Modellkonfiguration einer OpenClaw-Instanz (z. B. Kimi k2p6 → k3): Ändern Sie das Standardmodell, fügen Sie Modelldefinitionen hinzu und beheben Sie Modellkonfigurationsfehler – 401 „Ungültiges Token“, „Kein verfügbarer Kanal/Modell nicht gefunden“, Ablehnungen auf Denkebene („Denkebene X wird nicht unterstützt“) und Konfigurationsänderungen, die nicht wirksam werden. Wird immer dann verwendet, wenn der Benutzer das OpenClaw-Modell wechseln/aktualisieren/ein Rollback durchführen möchte (切换模型/换模型/ 升级模型) oder sagt, dass das Modell des OpenClaw/龙虾-Bots falsch konfiguriert ist (模型配的错了) oder der Bot bei LLM-Aufrufen zurückfällt/Fehler macht.
