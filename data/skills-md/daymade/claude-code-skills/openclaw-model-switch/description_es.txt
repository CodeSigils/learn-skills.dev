Cambie o repare la configuración del modelo de una instancia de OpenClaw (por ejemplo, Kimi k2p6 → k3): cambie el modelo predeterminado, agregue definiciones de modelo y corrija fallas de configuración del modelo: 401 "Token no válido", "No se encontró ningún canal disponible/modelo", rechazos de nivel de pensamiento ("El nivel de pensamiento X no es compatible") y ediciones de configuración que no tienen efecto. Úselo siempre que el usuario quiera cambiar/actualizar/revertir el modelo OpenClaw (切换模型/换模型/ 升级模型), o diga que el modelo del bot OpenClaw/龙虾 está mal configurado (模型配的错了), o el bot retrocede/errores en las llamadas de LLM.
