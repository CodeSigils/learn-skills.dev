OpenClaw インスタンスのモデル構成を切り替えるか修復します (例: Kim k2p6 → k3): デフォルトのモデルを変更し、モデル定義を追加し、モデル構成の失敗を修正します — 401 「無効なトークン」、「利用可能なチャネルがありません / モデルが見つかりません」、思考レベルの拒否 (「思考レベル X はサポートされていません」)、および有効にならない構成編集。ユーザーが OpenClaw モデル (切换モデル/换モデル/ 升级モデル) を切り替え/アップグレード/ロールバックしたい場合、または OpenClaw/龙虾 ボットのモデルの構成が間違っている (モデル的错了) と言う場合、またはボットが LLM 呼び出しでフォールバック/エラーを示す場合に使用します。
