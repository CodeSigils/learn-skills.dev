تبديل أو إصلاح تكوين النموذج لمثيل OpenClaw (على سبيل المثال، Kimi k2p6 → k3): تغيير النموذج الافتراضي، وإضافة تعريفات النموذج، وإصلاح فشل تكوين النموذج - 401 "رمز مميز غير صالح"، "لم يتم العثور على قناة/نموذج متاح"، ورفض مستوى التفكير ("مستوى التفكير X غير مدعوم")، وتحريرات التكوين التي لا تدخل حيز التنفيذ. يُستخدم عندما يريد المستخدم تبديل/ترقية/التراجع عن نموذج OpenClaw (切换模型/换模型/ 升级模型)، أو يقول أن نموذج روبوت OpenClaw/龙虾 قد تم تكوينه بشكل خاطئ (模型配的错了)، أو يتراجع الروبوت / يحدث أخطاء في مكالمات LLM.
