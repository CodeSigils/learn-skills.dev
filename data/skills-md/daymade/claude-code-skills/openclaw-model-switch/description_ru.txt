Переключите или исправьте конфигурацию модели экземпляра OpenClaw (например, Kimi k2p6 → k3): измените модель по умолчанию, добавьте определения модели и исправьте ошибки конфигурации модели — 401 «Неверный токен», «Нет доступного канала / модели не найден», отклонения на уровне мышления («Уровень мышления X не поддерживается») и изменения конфигурации, которые не вступают в силу. Используйте всякий раз, когда пользователь хочет переключить/обновить/откатить модель OpenClaw (切换模型/换模型/升级模型) или говорит, что модель бота OpenClaw/龙虾 неправильно настроена (模型配的错了), или бот откатывается/ошибается при вызовах LLM.
