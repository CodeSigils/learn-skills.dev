Changez ou réparez la configuration du modèle d'une instance OpenClaw (par exemple Kimi k2p6 → k3) : modifiez le modèle par défaut, ajoutez des définitions de modèle et corrigez les échecs de configuration du modèle — 401 « Jeton invalide », « Aucun canal/modèle disponible introuvable », rejets au niveau de la réflexion (« Le niveau de réflexion X n'est pas pris en charge ») et modifications de configuration qui ne prennent pas effet. À utiliser chaque fois que l'utilisateur souhaite changer/mettre à niveau/annuler le modèle OpenClaw (切换模型/换模型/升级模型), ou indique que le modèle du bot OpenClaw/龙虾 est mal configuré (模型配的错了), ou que le bot revient en arrière/erreurs lors des appels LLM.
