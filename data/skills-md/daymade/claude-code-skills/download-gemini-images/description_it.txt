Scarica, esporta, salva o crea pacchetti di immagini da una pagina di conversazione/chat/app di Google Gemini, in particolare immagini caricate o anteprime di immagini generate visibili in un thread Gemini. Da utilizzare quando l'attività richiede l'accesso allo stato Chrome/Gemini, l'apertura di lightbox di immagini Gemini, il download dei file di immagine visualizzati più grandi, la ridenominazione in ordine e la produzione di un archivio ZIP.
