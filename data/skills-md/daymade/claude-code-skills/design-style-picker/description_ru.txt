Пакетное создание и сравнение направлений визуального дизайна, чтобы пользователь мог выбрать тот стиль, который ему действительно нужен. Используйте, когда пользователь говорит, что не может описать абстрактный визуальный стиль, запрашивает множество вариантов стиля, хочет выбрать из созданных изображений пользовательского интерфейса/системы дизайна, отклоняет результаты как слишком красочные/слишком мертвые/слишком общие или нуждается в развитии существующей системы пользовательского интерфейса/дизайна без отказа от текущих ресурсов.
