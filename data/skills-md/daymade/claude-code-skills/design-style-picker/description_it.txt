Genera in batch e confronta le indicazioni di progettazione visiva in modo che un utente possa scegliere lo stile che desidera effettivamente. Da utilizzare quando l'utente afferma di non poter descrivere uno stile visivo astratto, richiede molte opzioni di stile, vuole scegliere tra le immagini generate dell'interfaccia utente/del sistema di progettazione, rifiuta gli output perché troppo colorati/troppo morti/troppo generici o ha bisogno che un sistema di interfaccia utente/progettazione esistente si evolva senza scartare le risorse attuali.
