Générez et comparez par lots les instructions de conception visuelle afin qu'un utilisateur puisse choisir le style qu'il souhaite réellement. À utiliser lorsque l'utilisateur déclare qu'il ne peut pas décrire un style visuel abstrait, demande de nombreuses options de style, souhaite choisir parmi les images générées de l'interface utilisateur/du système de conception, rejette les sorties comme étant trop colorées/trop mortes/trop génériques, ou a besoin d'une interface utilisateur/d'un système de conception existant évolué sans ignorer les actifs actuels.
