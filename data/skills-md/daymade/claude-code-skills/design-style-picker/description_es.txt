Genere por lotes y compare direcciones de diseño visual para que el usuario pueda elegir el estilo que realmente desea. Úselo cuando el usuario dice que no puede describir un estilo visual abstracto, solicita muchas opciones de estilo, quiere elegir entre imágenes generadas de la interfaz de usuario/sistema de diseño, rechaza los resultados por ser demasiado coloridos/muy muertos/demasiado genéricos, o necesita una interfaz de usuario/sistema de diseño existente evolucionado sin descartar los activos actuales.
