共同创建个人投资研究 LLM Wiki（Andrej Karpathy 的模式），其中用户自己的分析框架成为活生生的 CLAUDE.md — 通过采访他们，而不是给他们提供模板。每当用户想要构建复利研究知识库、投研第二大脑、投研知识库或个人投研wiki时使用；实例化 Karpathy 的金融/投资法学硕士 Wiki 要点；将他们的选股、分析师跟踪或收益观察工作流程转变为结构化的降价金库；或建立一个维基跟踪公司/行业/宏观/分析师随着时间的推移。纯 markdown + wikilinks，没有 RAG / 矢量 DB（Karpathy 的核心思想 - 不要过度设计）。还可以触发将研究报告/收益电话会议/专家注释纳入现有维基，以及收益后预测→履行审核。核心价值=将用户的个人投资偏好提取到他们自己的模式中，而不是强加一个标准。
