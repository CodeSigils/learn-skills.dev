Совместно создайте личный LLM Wiki по инвестиционным исследованиям (шаблон Андрея Карпати), где СОБСТВЕННАЯ система анализа пользователя станет живым CLAUDE.md — путем интервьюирования, а НЕ передачи им шаблона. Используйте всякий раз, когда пользователь хочет создать базу знаний для исследования сложных процентов, 投研第二大脑, 投研知识库 или 个人投研 вики; создать экземпляр LLM Wiki Карпати для финансов/инвестирования; превратить свой рабочий процесс выбора акций, отслеживания аналитиков или отслеживания доходов в структурированное хранилище уценок; или создайте вики-сайт, отслеживающий компании/отрасли/макроэкономику/аналитиков с течением времени. Чистая уценка + вики-ссылки, БЕЗ RAG/векторной БД (основная идея Karpathy — не переусердствовать). Также триггеры для добавления исследовательских отчетов, звонков о прибылях и заметок экспертов в существующую вики, а также для прогнозирования прибыли после проверки → проверки выполнения. Основная ценность = извлечение личных инвестиционных предпочтений пользователя в ИХ СОБСТВЕННУЮ схему, без навязывания стандартной.
