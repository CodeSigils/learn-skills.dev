قم باستخراج مقالات حساب WeChat الرسمي، واستخرج النص الأساسي والصور والبيانات الوصفية، وقم بإخراجها بتنسيق Markdown أو JSON. يدعم استراتيجيات التوجيه الذكية (سريع/متكيف/مستقر/موثوق/zero_dep/jina_ai/history)، والزحف المجمع لجميع المقالات التاريخية للحساب، والبيانات الوصفية لـ OG، واستخراج الصور المحملة ببطء، وتنزيلات الصور المحلية، وارتباط فقرة الصورة، واكتشاف بحث Sogou، واستخراج بيانات التفاعل (القراءات/الإعجابات/الأعداد المبهرة)، وواجهة إدارة ويب حديثة. يُستخدم عندما يحتاج المستخدمون إلى تنزيل/حفظ مقالات WeChat، أو محتوى حساب الأرشفة المجمعة، أو استخراج مواد صور نصية من WeChat، أو طلب لوحة معلومات مرئية.
