Scrapen Sie Artikel des offiziellen WeChat-Kontos, extrahieren Sie Textkörper, Bilder und Metadaten und geben Sie sie als Markdown oder JSON aus. Unterstützt intelligentes Strategie-Routing (schnell/adaptiv/stabil/zuverlässig/zero_dep/jina_ai/history), Batch-Crawling aller historischen Artikel aus einem Konto, Fallback-OG-Metadaten, Lazy-Loaded-Bildextraktion, lokaler Bild-Download, Bild-Absatz-Zuordnung, Sogou-Sucherkennung, Interaktionsdatenextraktion (Lesungen, Likes, „Wow“-Anzahl) und eine moderne Web-Management-Schnittstelle. Verwenden Sie diese Funktion, wenn Sie WeChat-Artikel herunterladen/speichern, Kontoinhalte stapelweise archivieren, WeChat-Inhalte extrahieren oder ein visuelles Dashboard benötigen.
