One-Stop-Begleiter und Installer für den offiziellen Tencent IMA-Skill (腾讯 IMA / ima.qq.com). Verwaltet die konfigurationsfreie Installation von Claude Code / Codex / OpenClaw über „npx skills add“, leitet die Einrichtung von API-Schlüsseln, erkennt und behebt bekannte Probleme im Upstream-Paket (einschließlich des fehlenden YAML-Frontmatter-Fehlers in Submodul-SKILL.md-Dateien) und implementiert eine personalisierte Fan-Out-Suchstrategie mit prioritätsbasierter Wissensdatenbank-Boosting. Verwenden Sie diesen Skill immer dann, wenn der Benutzer IMA, IMA, ima.qq.com, ima-skill, Installation oder Konfiguration von ima-skill, Suche in IMA-Wissensdatenbanken, 知识库搜索, 笔记搜索, Fan-Out-Suche mit bevorzugten KBs erwähnt oder Fehler wie „Laden von Skill(s) wegen ungültiger SKILL.md übersprungen“ meldet. Wird auch für jede Anfrage zur Diagnose, Reparatur oder Personalisierung des Verhaltens einer ima-skill-Installation ausgelöst. Dabei handelt es sich um eine Wrapper-Schicht um ima-skill – sie installiert und orchestriert ima-skill, anstatt es zu ersetzen.
