Compagnon unique et installateur pour la compétence officielle Tencent IMA (腾讯 IMA / ima.qq.com). Gère l'installation sans configuration sur Claude Code / Codex / OpenClaw via `npx skills add`, guide la configuration des clés API, détecte et corrige les problèmes connus dans le package en amont (y compris le bogue YAML-frontmatter manquant dans les fichiers du sous-module SKILL.md) et met en œuvre une stratégie de recherche personnalisée avec une amélioration de la base de connaissances basée sur les priorités. Utilisez cette compétence chaque fois que l'utilisateur mentionne IMA, 腾讯 IMA, ima.qq.com, ima-skill, installe ou configure ima-skill, effectue une recherche dans les bases de connaissances IMA, 知识库搜索, 笔记搜索, recherche en éventail avec les bases de connaissances préférées ou signale des erreurs telles que « Chargement ignoré des compétences en raison d'un fichier SKILL.md non valide ». Déclenche également toute demande de diagnostic, de réparation ou de personnalisation du comportement d'une installation ima-skill. Il s'agit d'une couche enveloppe autour d'ima-skill : elle installe et orchestre ima-skill plutôt que de la remplacer.
