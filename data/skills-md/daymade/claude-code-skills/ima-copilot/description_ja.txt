Tencent 公式 IMA スキル (腾讯 IMA / ima.qq.com) のワンストップ コンパニオンおよびインストーラー。 「npx skill add」を介してClaude Code / Codex / OpenClawへのゼロ構成インストールを処理し、APIキー設定をガイドし、アップストリームパッケージの既知の問題（サブモジュールSKILL.mdファイルのYAMLフロントマッター欠落バグを含む）を検出して修正し、優先順位ベースのナレッジベース強化によるパーソナライズされたファンアウト検索戦略を実装します。ユーザーが IMA、腾讯 IMA、ima.qq.com、ima-skill、ima-skill のインストールまたは設定、IMA ナレッジ ベース全体の検索、知识库搜索、笔记搜索、優先 KB でのファンアウト検索について言及した場合、または「無効な SKILL.md によりスキルの読み込みがスキップされました」などのエラーを報告した場合には、このスキルを使用します。また、ima-skill インストールの動作を診断、修復、またはカスタマイズするためのリクエストもトリガーします。これは ima-skill のラッパー層であり、ima-skill を置き換えるのではなく、インストールして調整します。
