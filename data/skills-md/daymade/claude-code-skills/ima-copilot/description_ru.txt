Универсальный помощник и установщик для официального навыка Tencent IMA (腾讯 IMA / ima.qq.com). Осуществляет установку без настройки в Claude Code / Codex / OpenClaw с помощью `npx Skills Add`, управляет настройкой ключей API, обнаруживает и исправляет известные проблемы в исходном пакете (включая ошибку отсутствия YAML-frontmatter в файлах подмодуля SKILL.md) и реализует персонализированную стратегию разветвленного поиска с расширением базы знаний на основе приоритетов. Используйте этот навык всякий раз, когда пользователь упоминает IMA, 腾讯 IMA, ima.qq.com, ima-skill, установку или настройку ima-skill, поиск в базах знаний IMA, 知识库搜索, 笔记搜索, разветвленный поиск с предпочтительными базами знаний или сообщает об ошибках, таких как «Навыки пропущены при загрузке из-за недопустимых значений».
