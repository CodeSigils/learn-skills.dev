針對網路、串流媒體和協定層錯誤的證據驅動調查。在調試連接重置（ECONNRESET、HTTP/2 RST_STREAM、INTERNAL_ERROR）、SSE 或長輪詢停頓、固定時間連接丟失、CDN/代理/CGNAT 空閒逾時或症狀與明顯原因不匹配的任何事件時使用。應用偽造優先的方法－分層隔離實驗來確定負責的網路層，環境門控運行時儀器用於非侵入性觀察，以及反審查代理團隊來挑戰單一原因假設。在「套接字意外關閉」、「流中斷」、「ECONNRESET」、「HTTP/2 INTERNAL_ERROR」、「N 秒後失敗」、「有時有效但不總是」、「上游靜默 X 秒」或調查人員可能在證據出現之前就得出結論的任何情況下強烈觸發。可推廣到任何多層系統調查，其中假設優先思維是故障模式。
