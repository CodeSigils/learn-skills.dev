التحقيق المبني على الأدلة لأخطاء الشبكة والبث وطبقة البروتوكول. يُستخدم عند تصحيح أخطاء إعادة ضبط الاتصال (ECONNRESET، أو HTTP/2 RST_STREAM، أو INTERNAL_ERROR)، أو SSE أو الأكشاك طويلة الاستقصاء، أو انقطاع الاتصال في الوقت المحدد، أو انتهاء مهلات الخمول لـ CDN/proxy/CGNAT، أو أي حادث لا تتطابق فيه الأعراض مع السبب الواضح. يطبق منهجية التزييف أولاً - تجارب عزل الطبقات لتحديد طبقة الشبكة المسؤولة، وأجهزة وقت التشغيل المحسنة للمراقبة غير الغازية، وفرق وكلاء المراجعة المضادة لتحدي الافتراضات ذات السبب الواحد. قم بالتفعيل بقوة عند "إغلاق المقبس بشكل غير متوقع"، أو "مقاطعة الدفق"، أو "ECONNRESET"، أو "HTTP/2 INTERNAL_ERROR"، أو "الفشل بعد N ثانية"، أو "يعمل أحيانًا ولكن ليس دائمًا"، أو "صامت عند المنبع لمدة X ثانية"، أو أي سيناريو قد يقفز فيه المحقق إلى الاستنتاجات قبل الأدلة. يتم تعميمه على أي تحقيق في نظام متعدد الطبقات حيث يكون التفكير بالافتراض أولاً هو وضع الفشل.
