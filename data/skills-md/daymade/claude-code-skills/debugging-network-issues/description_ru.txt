Обоснованное расследование ошибок сети, потоковой передачи и протоколов. Используйте при отладке сброса соединения (ECONNRESET, HTTP/2 RST_STREAM, INTERNAL_ERROR), остановок SSE или длительного опроса, разрывов соединения в фиксированное время, тайм-аутов простоя CDN/прокси/CGNAT или любого инцидента, когда симптомы не соответствуют очевидной причине. Применяет методологию «сначала фальсификация» — эксперименты по многоуровневой изоляции для определения ответственного сетевого уровня, инструменты среды выполнения для неинвазивного наблюдения и команды агентов встречной проверки для проверки предположений об одной причине. Строгий триггер при «неожиданном закрытии сокета», «потоке прерван», «ECONNRESET», «HTTP/2 INTERNAL_ERROR», «сбое через N секунд», «работает иногда, но не всегда», «восходящем молчании в течение X секунд» или любом сценарии, в котором следователь может поторопиться с выводами до получения доказательств. Обобщается на любое исследование многоуровневой системы, где мышление в первую очередь является способом отказа.
