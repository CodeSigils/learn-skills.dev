ネットワーク、ストリーミング、プロトコル層のバグに対する証拠に基づく調査。接続のリセット (ECONNRESET、HTTP/2 RST_STREAM、INTERNAL_ERROR)、SSE または長時間ポーリングのストール、固定時間の接続ドロップ、CDN/プロキシ/CGNAT のアイドル タイムアウト、または症状が明白な原因と一致しないインシデントをデバッグするときに使用します。改ざん優先の方法論を適用します。つまり、責任のあるネットワーク層を特定するための階層化された分離実験、非侵襲的な観察のための暗号化されたランタイム計測器、および単一原因の仮定に異議を唱えるための反レビューエージェントチームです。 「ソケットが予期せず閉じられた」、「ストリームが中断された」、「ECONNRESET」、「HTTP/2 INTERNAL_ERROR」、「N 秒後に失敗する」、「時々動作するが常に動作するとは限らない」、「アップストリームが X 秒間サイレント」、または調査官が証拠の前に結論を急ぐ可能性のあるシナリオで強力にトリガーされます。仮定優先の考え方が故障モードとなるあらゆる多層システムの調査に一般化します。
