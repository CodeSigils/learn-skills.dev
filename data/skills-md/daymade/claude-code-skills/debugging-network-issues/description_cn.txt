针对网络、流媒体和协议层错误的证据驱动调查。在调试连接重置（ECONNRESET、HTTP/2 RST_STREAM、INTERNAL_ERROR）、SSE 或长轮询停顿、固定时间连接丢失、CDN/代理/CGNAT 空闲超时或症状与明显原因不匹配的任何事件时使用。应用伪造优先的方法——分层隔离实验来确定负责的网络层，环境门控运行时仪器用于非侵入性观察，以及反审查代理团队来挑战单一原因假设。在“套接字意外关闭”、“流中断”、“ECONNRESET”、“HTTP/2 INTERNAL_ERROR”、“N 秒后失败”、“有时有效但并不总是”、“上游静默 X 秒”或调查人员可能在证据出现之前就得出结论的任何情况下强烈触发。可推广到任何多层系统调查，其中假设优先思维是故障模式。
