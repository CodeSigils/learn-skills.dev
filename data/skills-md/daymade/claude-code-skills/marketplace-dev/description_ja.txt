Claude Code スキル リポジトリを公式プラグイン マーケットプレイスに変換します。
既存のスキルを分析し、以下に準拠した .claude-plugin/marketplace.json を生成します。
Anthropic 仕様、「claude plugin validate」で検証、実際のインストールをテスト、
そして上流リポジトリへの PR を作成します。実際のアンチパターンから苦労して獲得したアンチパターンをエンコードします
マーケットプレイスの開発 (スキーマの罠、バージョンのセマンティクス、説明の落とし穴)。
ユーザーがマーケットプレイス、プラグインのサポート、ワンクリック インストール、などに言及する場合に使用します。
Marketplace.json、プラグイン配布、自動更新、またはスキル リポジトリが必要
「claude plugin install」経由でインストール可能。ユーザーがスキルを持っている場合にも発動
リポジトリにアクセスし、パッケージ化、配布、またはインストール可能にするかどうかを尋ねます。
