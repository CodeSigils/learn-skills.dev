Преобразует любой репозиторий навыков Claude Code в официальную торговую площадку плагинов.
Анализирует существующие навыки, генерирует .claude-plugin/marketplace.json, соответствующий
спецификация Anthropic, проверка с помощью плагина claude validate, проверка реальной установки,
и создает PR для восходящего репозитория. Кодирует с трудом завоеванные антипаттерны из реальных
развитие рынка (ловушки схемы, семантика версий, подводные камни описания).
Используйте, когда пользователь упоминает: торговую площадку, поддержку плагинов, установку в один клик,
marketplace.json, распространение плагинов, автоматическое обновление или требуется репозиторий навыков
устанавливается через `claude плагин install`. Также срабатывает, когда у пользователя есть навыки
репо и спрашивает об упаковке, распространении или возможности установки.
