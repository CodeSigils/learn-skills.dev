أداة التثبيت الشاملة والرفيق لمجموعة مهارات Gangtise (岗底斯投研) OpenAPI الكاملة - 19 مهارة رسمية تغطي استرجاع البيانات (OHLC 行情، 财务، 估值، 研报، 首席观点، 会议纪要، البحث)، وسير عمل البحث (L1-L4، 观点 PK 对抗性分析، 主题研究، 事件复盘)، والفائدة (股票池管理،公开网页搜索). تثبيت Zero-config على Claude Code / OpenClaw / Codex مع 4 أوضاع محددة مسبقًا (كامل / ورشة عمل / الحد الأدنى / مخصص)، يوجه إعداد AccessKey + SecretAccessKey من خلال مكالمة تحقق مباشرة ضد open.gangtise.com، ويشحن نصًا تشخيصيًا للقراءة فقط. استخدم هذه المهارة عندما يذكر المستخدم Gangtise، أو 岗底斯، أو Gangtise-data، أو Gangtise-kb، أو Gangtise-file، أو Gangtise-data-client، أو Gangtise-KB-client، أو Gangtise-file-client، أو Gangtise-stock-research، أو Gangtise-opinion-pk، أو تثبيت أي مهارة Gangtise-*، أو تكوين بيانات الاعتماد الخاصة بها، أو الإبلاغ عن أخطاء مثل "الرمز المميز غير صالح"، "接口地址错误"، "لا يمكن الوصول إلى عنوان uri". هذا عبارة عن غلاف حول مهارات Gangtise الرسمية - فهو يقوم بتثبيتها وتنسيقها بدلاً من استبدالها.
