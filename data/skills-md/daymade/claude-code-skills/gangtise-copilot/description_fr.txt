Installateur unique et compagnon de la suite complète de compétences OpenAPI Gangtise (岗底斯投研) — 19 compétences officielles couvrant la récupération de données (OHLC 行情, 财务, 估值, 研报, 首席观点, 会议纪要,调研纪要), les flux de travail de recherche (个股研究 L1-L4, 观点 PK 对抗性分析, 主题研究, 事件复盘) et les utilitaires (股票池管理,公开网页搜索). Installation sans configuration sur Claude Code / OpenClaw / Codex avec 4 modes prédéfinis (complet / atelier / minimal / personnalisé), guide la configuration de accessKey + secretAccessKey avec un appel de validation en direct sur open.gangtise.com et fournit un script de diagnostic en lecture seule. Utilisez cette compétence chaque fois que l'utilisateur mentionne Gangtise, 岗底斯, gangtise-data, gangtise-kb, gangtise-file, gangtise-data-client, gangtise-kb-client, gangtise-file-client, gangtise-stock-research, gangtise-opinion-pk, installe une compétence gangtise-*, configure ses informations d'identification ou signale des erreurs telles que « le jeton n'est pas valide », '接口地址错误', 'l'uri n'est pas accessible'. Il s'agit d'un emballage autour des compétences officielles de Gangtise : il les installe et les orchestre plutôt que de les remplacer.
