Programma di installazione completo e compagno per la suite completa di competenze OpenAPI Gangtise (岗底斯投研): 19 competenze ufficiali che coprono il recupero dei dati (OHLC 行情, 财务, 估值, 研报, 首席观点, 会议纪要,调研纪要), flussi di lavoro di ricerca (个股研究 L1-L4, 观点 PK 对抗性分析, 主题研究, 事件复盘) e utilità (股票池管理,公开网页搜索). Installazione zero-config su Claude Code / OpenClaw / Codex con 4 modalità preimpostate (completa / workshop / minima / personalizzata), guida la configurazione di accessKey + secretAccessKey con una chiamata di convalida in tempo reale su open.gangtise.com e fornisce uno script diagnostico di sola lettura. Utilizza questa abilità ogni volta che l'utente menziona Gangtise, 岗底斯, gangtise-data, gangtise-kb, gangtise-file, gangtise-data-client, gangtise-kb-client, gangtise-file-client, gangtise-stock-research, gangtise-opinion-pk, installa qualsiasi abilità gangtise-*, configura le sue credenziali o segnala errori come "token non valido", '接口地址错误', 'non è possibile accedere all'URI'. Questo è un involucro attorno alle competenze ufficiali di Gangtise: le installa e le orchestra invece di sostituirle.
