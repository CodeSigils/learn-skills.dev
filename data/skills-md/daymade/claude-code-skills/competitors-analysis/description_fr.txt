Analysez les référentiels concurrents avec une approche basée sur des preuves. À utiliser pour suivre les concurrents, créer des profils de concurrents ou générer une analyse concurrentielle. CRITIQUE - toute analyse doit être basée sur du code cloné réel, jamais sur des hypothèses. Les déclencheurs incluent « analyser le concurrent », « ajouter un concurrent », « analyse concurrentielle » ou « 竞品分析 ».
