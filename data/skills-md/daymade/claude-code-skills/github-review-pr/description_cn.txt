针对当前基础分支的 GitHub 存储库维护者，审查或重新审查一个贡献者拉取请求（包括明确命名的已关闭 PR 正在重新考虑）或所有开放贡献者 PR 的有界最新到最旧的扫描。使用不可变的 Git 快照、三向合并结果、独立贡献预测、检查、测试和结果优先报告来处理基础漂移、历史不连续性、污染分支、所有权、管理、取代和审查条件修复或着陆。用于 PR URL 或编号，“主要更改，再次审查”，“审查从最新到最旧的所有开放 PR”，“应用我们的维护者原则”，“我们可以合并此内容并自行修复其余部分吗？”或合并准备情况。请勿用于一般 GitHub CRUD、存储库范围的审核、仅 CI 诊断、仅安全差异审核、未推送的本地差异、仅解决现有审核意见或在没有新审核的情况下进行合并。
