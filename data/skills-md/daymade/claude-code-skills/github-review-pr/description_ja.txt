現在のベース ブランチに対する GitHub リポジトリ メンテナ向けに、1 つのコントリビュータ プル リクエスト (再検討中の明示的に指定されたクローズ済み PR を含む)、またはすべてのオープン コントリビュータ PR の制限付きの最新から古いスイープをレビューまたは再レビューします。ベース ドリフト、履歴の不連続性、汚染されたブランチ、所有権、キュレーション、スーパーセッション、および不変の Git スナップショットを使用したレビュー条件付きの修復または着陸、3 方向のマージ結果、分離された寄与予測、チェック、テスト、および結果優先レポートを処理します。 PR URL または番号、「メインが変更されました、もう一度確認します」、「開いているすべての PR を新しいものから古いものまで確認します」、「メンテナーの原則を適用します」、「これをマージして残りを自分で修正できますか?」、またはマージの準備状況に使用します。一般的な GitHub CRUD、リポジトリ全体の監査、CI のみの診断、セキュリティのみの差分監査、プッシュされていないローカルの差分、既存のレビュー コメントへの単なる対処、または新しいレビューを行わないマージには使用しないでください。
