Examine ou réexamine une demande d'extraction d'un contributeur (y compris un PR fermé explicitement nommé en cours de réexamen) ou un balayage limité du plus récent au plus ancien de tous les PR de contributeurs ouverts, pour un responsable du référentiel GitHub par rapport à la branche de base actuelle. Gère la dérive de base, les discontinuités de l'historique, les branches polluées, la propriété, la conservation, le remplacement et la réparation ou l'atterrissage conditionné par la révision à l'aide d'instantanés Git immuables, de résultats de fusion à trois voies, de projection de contributions isolées, de vérifications, de tests et de rapports axés sur les résultats. À utiliser pour une URL ou un numéro de PR, "principal modifié, réviser à nouveau", "examiner tous les PR ouverts du plus récent au plus ancien", "appliquer nos principes de responsable", "pouvons-nous fusionner cela et réparer le reste nous-mêmes ?", ou être prêt à fusionner. Ne pas utiliser pour le GitHub CRUD général, les audits à l'échelle du référentiel, les diagnostics CI uniquement, les audits de différences de sécurité uniquement, les différences locales non poussées, le simple traitement des commentaires de révision existants ou la fusion sans une nouvelle révision.
