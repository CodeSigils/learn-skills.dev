Rivede o riesamina una richiesta pull di un collaboratore, incluso un PR chiuso con nome esplicito che viene riconsiderato, o una scansione delimitata dal più recente al più vecchio di tutti i PR del collaboratore aperti, per un manutentore del repository GitHub rispetto al ramo di base corrente. Gestisce la deriva della base, le discontinuità della cronologia, i rami inquinati, la proprietà, la curation, la sostituzione e la riparazione o l'atterraggio condizionati dalla revisione utilizzando istantanee Git immutabili, risultati di unione a tre vie, proiezione di contributi isolati, controlli, test e report sui risultati. Utilizzare per un URL o un numero PR, "principale modificato, rivedi di nuovo", "rivedi tutti i PR aperti dal più recente al più vecchio", "applica i nostri principi di manutentore", "possiamo unire questo e correggere il resto da soli?" o unire la disponibilità. Non utilizzare per GitHub CRUD generale, controlli a livello di repository, diagnosi solo CI, controlli diff solo di sicurezza, differenze locali non inviate, semplicemente affrontando commenti di revisione esistenti o unendo senza una nuova revisione.
