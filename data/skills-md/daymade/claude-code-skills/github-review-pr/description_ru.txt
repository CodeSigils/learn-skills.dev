Проверяет или повторно проверяет один запрос на включение участника, включая пересматриваемый закрытый PR с явным названием, или ограниченную проверку всех открытых PR участников от самого нового к самому старому для специалиста по сопровождению репозитория GitHub по текущей базовой ветке. Управляет дрейфом базы, разрывами истории, загрязненными ветвями, владением, курированием, заменой, а также восстановлением или посадкой с учетом проверки с использованием неизменяемых снимков Git, результатов трехстороннего слияния, изолированного прогнозирования вклада, проверок, тестов и отчетов о результатах. Используйте для URL-адреса или номера PR-запроса «основное изменение, просмотрите еще раз», «проверьте все открытые PR-запросы, от самых новых до самых старых», «примените принципы нашего сопровождающего», «можем ли мы объединить это и исправить остальное самостоятельно?» или готовность к слиянию. Не используйте для общего CRUD GitHub, аудита всего репозитория, диагностики только CI, аудита различий только по безопасности, неотправленных локальных различий, простого рассмотрения существующих комментариев к обзору или слияния без нового обзора.
