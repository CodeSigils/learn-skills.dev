مراجعة أو إعادة مراجعة طلب سحب واحد للمساهم - بما في ذلك إعادة النظر في العلاقات العامة المغلقة المسماة بشكل صريح - أو عملية مسح محدودة من الأحدث إلى الأقدم لجميع العلاقات العامة للمساهمين المفتوحين، لمشرف مستودع GitHub مقابل الفرع الأساسي الحالي. يتعامل مع الانحراف الأساسي، وانقطاعات التاريخ، والفروع الملوثة، والملكية، والتنظيم، والاستبدال، والإصلاح أو الهبوط المشروط بالمراجعة باستخدام لقطات Git غير القابلة للتغيير، ونتائج الدمج ثلاثية الاتجاهات، وإسقاط المساهمة المعزولة، والفحوصات، والاختبارات، وإعداد التقارير عن النتائج أولاً. استخدم لعنوان URL أو رقم العلاقات العامة، "تم التغيير الرئيسي، قم بالمراجعة مرة أخرى"، "مراجعة جميع العلاقات العامة المفتوحة من الأحدث إلى الأقدم"، "تطبيق مبادئ الصيانة الخاصة بنا"، "هل يمكننا دمج هذا وإصلاح الباقي بأنفسنا؟"، أو دمج الاستعداد. لا تستخدم في عمليات GitHub CRUD العامة، أو عمليات التدقيق على مستوى المستودع، أو تشخيص CI فقط، أو عمليات تدقيق الفروق للأمان فقط، أو الاختلافات المحلية غير المدفوعة، أو مجرد معالجة تعليقات المراجعة الحالية، أو الدمج بدون مراجعة جديدة.
