Überprüft oder überprüft eine Pull-Anfrage eines Mitwirkenden – einschließlich einer ausdrücklich benannten geschlossenen PR, die erneut geprüft wird – oder einen begrenzten Durchlauf aller offenen Mitwirkenden-PRs vom neuesten zum ältesten für einen GitHub-Repository-Betreuer für den aktuellen Basiszweig. Behandelt Basisdrift, Verlaufsdiskontinuitäten, verunreinigte Zweige, Eigentum, Kuration, Ersetzung und prüfungsbedingte Reparatur oder Landung mithilfe unveränderlicher Git-Snapshots, Drei-Wege-Merge-Ergebnisse, isolierter Beitragsprojektion, Prüfungen, Tests und ergebnisorientierter Berichterstattung. Verwenden Sie für eine PR-URL oder -Nummer „Haupt geändert, erneut überprüfen“, „Alle offenen PRs vom neuesten zum ältesten überprüfen“, „Unsere Betreuerprinzipien anwenden“, „Können wir dies zusammenführen und den Rest selbst beheben?“ oder „Zusammenführungsbereitschaft“. Nicht für allgemeines GitHub CRUD, Repository-weite Audits, reine CI-Diagnose, reine Sicherheits-Diff-Audits, nicht übertragene lokale Diffs, lediglich die Bearbeitung vorhandener Review-Kommentare oder Zusammenführungen ohne neue Review verwenden.
