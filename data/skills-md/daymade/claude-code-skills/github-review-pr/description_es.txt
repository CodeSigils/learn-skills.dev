Revisa o vuelve a revisar una solicitud de extracción de un colaborador, incluido un PR cerrado nombrado explícitamente que se está reconsiderando, o un barrido limitado del más nuevo al más antiguo de todos los PR abiertos de un colaborador, para un mantenedor del repositorio de GitHub con respecto a la rama base actual. Maneja la deriva de la base, las discontinuidades del historial, las sucursales contaminadas, la propiedad, la curación, la sustitución y la reparación o aterrizaje condicionado por la revisión utilizando instantáneas inmutables de Git, resultados de fusión de tres vías, proyección de contribución aislada, verificaciones, pruebas e informes de hallazgos primero. Úselo para una URL o número de PR, "cambio principal, revisar nuevamente", "revisar todos los PR abiertos desde los más nuevos hasta los más antiguos", "aplicar nuestros principios de mantenedor", "¿podemos fusionar esto y arreglar el resto nosotros mismos?", o preparación para fusionar. No lo use para GitHub CRUD general, auditorías de todo el repositorio, diagnósticos solo de CI, auditorías de diferencias solo de seguridad, diferencias locales no publicadas, simplemente abordar comentarios de revisión existentes o fusionar sin una nueva revisión.
