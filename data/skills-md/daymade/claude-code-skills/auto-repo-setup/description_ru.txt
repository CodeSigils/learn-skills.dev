Автоматизированная настройка среды репозитория, диагностика и устранение неисправностей. Когда нетехнический персонал (редактирование, бизнес, операции) получает репозиторий и говорит «не могу запустить», «как запустить», «как настроить среду», «помогите мне настроить репозиторий», «инициализировать проект», «зафиксировать код», «что делать в случае конфликта», система автоматически читает ONBOARDING.md, диагностирует пробелы в среде, исправляет зависимости, проверяет возможность запуска и безопасно выполняет операции git. Он также используется техническими пользователями для быстрой стандартизации процесса установки новых репозиториев (перехватчик SessionStart, PII Guard, очистка истории, ключ API изоляции проекта). Всякий раз, когда пользователь упоминает «среду», «конфигурацию», «невозможно запустить», «настройку», «запустить», «клонировать», «как запустить», «зависимость», «установлено ли оно», «фиксировать код», «конфликт слияния», «не удалось отправить», этот навык срабатывает.
