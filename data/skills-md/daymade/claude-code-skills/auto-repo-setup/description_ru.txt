Автоматизированная настройка среды репозитория, диагностика и устранение неисправностей. Когда нетехнический персонал (редактирование, бизнес, операции) получает репозиторий и говорит «он не запустится», «как его запустить», «как настроить среду», «помогите мне настроить репо», «инициализировать проект», «зафиксировать код» или «что мне делать, если возник конфликт», система автоматически считывает ONBOARDING.md, диагностирует пробелы в среде, исправляет зависимости, проверяет возможность запуска и безопасно завершает операции Git. Он также используется техническими пользователями для быстрой стандартизации процесса установки новых репозиториев (перехватчик SessionStart, PII Guard, очистка истории, ключ API для изоляции проекта).

Каждый раз, когда пользователь упоминает «среду», «конфигурацию», «не запускается», «настройка», «запуск», «клон», «как запускать», «зависимость», «установлено ли оно», «фиксировать код», «конфликт слияния» или «не удалось отправить», этот навык срабатывает.
