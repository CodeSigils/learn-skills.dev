リポジトリ環境の構成、障害診断、修復を自動化します。非技術スタッフ (編集、営業、運用) がリポジトリを受け取り、「実行できない」、「起動方法」、「環境の構成方法」、「リポジトリのセットアップを手伝って」、「プロジェクトの初期化」、「コードをコミット」、「競合が発生した場合の対処方法」と言った場合、システムは自動的に ONBOARDING.md を読み取り、環境のギャップを診断し、依存関係を修正し、実行できることを確認し、安全に実行します。 git オペレーション。また、技術ユーザーが新しいリポジトリのセットアップ プロセス (SessionStart フック、PII ガード、履歴のサニタイズ、プロジェクト分離 API キー) を迅速に標準化するためにも使用されます。ユーザーが「環境」、「構成」、「実行できない」、「セットアップ」、「開始」、「クローン」、「実行方法」、「依存関係」、「インストールされているか」、「コードのコミット」、「マージ競合」、「プッシュ失敗」について言及するたびに、このスキルがトリガーされます。
