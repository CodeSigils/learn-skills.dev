Automatisierte Konfiguration, Fehlerdiagnose und Reparatur der Repository-Umgebung. Wenn nichttechnisches Personal (Bearbeitung, Wirtschaft, Betrieb) ein Repository erhält und sagt: „Kann nicht ausgeführt werden“, „Wie starte ich“, „Wie konfiguriere ich die Umgebung“, „Hilf mir beim Einrichten des Repositorys“, „Initialisiere das Projekt“, „Commit-Code“ oder „Was ist zu tun, wenn es einen Konflikt gibt“, liest das System automatisch ONBOARDING.md, diagnostiziert Umgebungslücken, behebt Abhängigkeiten, überprüft, ob es ausgeführt werden kann, und führt Git-Operationen sicher aus. Es wird auch von technischen Benutzern verwendet, um den Einrichtungsprozess neuer Repositorys schnell zu standardisieren (SessionStart-Hook, PII Guard, Verlaufsbereinigung, Projektisolations-API-Schlüssel). Immer wenn ein Benutzer „Umgebung“, „Konfiguration“, „Kann nicht ausgeführt werden“, „Setup“, „Start“, „Klonen“, „Ausführung“, „Abhängigkeit“, „Ist es installiert“, „Code festschreiben“, „Zusammenführungskonflikt“ und „Push fehlgeschlagen“ erwähnt, wird dieser Skill ausgelöst.
