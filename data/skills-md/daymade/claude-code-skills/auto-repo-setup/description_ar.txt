التكوين الآلي لبيئة المستودع وتشخيص الأخطاء وإصلاحها. عندما يتلقى الموظفون غير الفنيين (التحرير، والأعمال التجارية، والعمليات) مستودعًا ويقولون "لا يمكن التشغيل"، و"كيفية البدء"، و"كيفية تكوين البيئة"، و"ساعدني في إعداد المستودع"، و"تهيئة المشروع"، و"رمز الالتزام"، و"ماذا تفعل إذا كان هناك تعارض"، يقرأ النظام تلقائيًا ONBOARDING.md، ويشخص فجوات البيئة، ويصلح التبعيات، ويتحقق من إمكانية تشغيله، وينفذ عمليات git بأمان. كما يتم استخدامه أيضًا للمستخدمين التقنيين لتوحيد عملية إعداد المستودعات الجديدة بسرعة (خطاف SessionStart، وحارس PII، وتعقيم التاريخ، ومفتاح API لعزل المشروع). عندما يذكر المستخدم "البيئة"، "التكوين"، "لا يمكن التشغيل"، "الإعداد"، "البدء"، "الاستنساخ"، "كيفية التشغيل"، "التبعية"، "هل تم تثبيته"، "رمز الالتزام"، "دمج الصراع"، "فشل الدفع"، يتم تشغيل هذه المهارة.
