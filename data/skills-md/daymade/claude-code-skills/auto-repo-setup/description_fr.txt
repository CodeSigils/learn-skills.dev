Configuration automatisée de l'environnement de référentiel, diagnostic des pannes et réparation. Lorsque le personnel non technique (édition, gestion, opérations) reçoit un référentiel et dit « ne peut pas exécuter », « comment démarrer », « comment configurer l'environnement », « aidez-moi à configurer le référentiel », « initialiser le projet », « valider le code », « que faire en cas de conflit », le système lit automatiquement ONBOARDING.md, diagnostique les lacunes de l'environnement, corrige les dépendances, vérifie qu'il peut s'exécuter et exécute en toute sécurité les opérations git. Il est également utilisé par les utilisateurs techniques pour standardiser rapidement le processus de configuration de nouveaux référentiels (hook SessionStart, PII Guard, nettoyage de l'historique, clé API d'isolation de projet). Chaque fois qu'un utilisateur mentionne « environnement », « configuration », « ne peut pas exécuter », « configuration », « démarrer », « cloner », « comment exécuter », « dépendance », « est-il installé », « code de validation », « conflit de fusion », « échec du push », cette compétence est déclenchée.
