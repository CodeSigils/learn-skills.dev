自動化儲存庫環境配置、故障診斷和修復。當非技術人員（編輯、業務、營運）收到倉庫並說「無法運行」、「如何啟動」、「如何配置環境」、「幫我設定倉庫」、「初始化專案」、「提交代碼」、「衝突怎麼辦」時，系統會自動讀取ONBOARDING.md，診斷環境差距，修復依賴，驗證是否可以運行，並安全地進行git操作。它還可用於技術使用者快速標準化新儲存庫的設定流程（SessionStart 掛鉤、PII 防護、歷史清理、專案隔離 API 金鑰）。每當使用者提到「環境」、「設定」、「無法運作」、「安裝」、「啟動」、「複製」、「如何運作」、「依賴」、「是否已安裝」、「提交程式碼」、「合併衝突」、「推送失敗」時，就會觸發此技能。
