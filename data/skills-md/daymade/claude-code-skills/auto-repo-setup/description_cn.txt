自动化存储库环境配置、故障诊断和修复。当非技术人员（编辑、业务、运营）收到仓库并说“无法运行”、“如何启动”、“如何配置环境”、“帮我设置仓库”、“初始化项目”、“提交代码”、“冲突怎么办”时，系统会自动读取ONBOARDING.md，诊断环境差距，修复依赖，验证是否可以运行，并安全地进行git操作。它还可用于技术用户快速标准化新存储库的设置过程（SessionStart 挂钩、PII 防护、历史清理、项目隔离 API 密钥）。每当用户提到“环境”、“配置”、“无法运行”、“安装”、“启动”、“克隆”、“如何运行”、“依赖”、“是否已安装”、“提交代码”、“合并冲突”、“推送失败”时，就会触发该技能。
