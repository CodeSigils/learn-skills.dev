Configuración, diagnóstico y reparación de fallos del entorno de repositorio automatizado. Cuando el personal no técnico (edición, negocios, operaciones) recibe un repositorio y dice "no se puede ejecutar", "cómo comenzar", "cómo configurar el entorno", "ayúdame a configurar el repositorio", "inicializar el proyecto", "confirmar código", "qué hacer si hay un conflicto", el sistema lee automáticamente ONBOARDING.md, diagnostica brechas en el entorno, corrige dependencias, verifica que se puede ejecutar y realiza operaciones de git de forma segura. También se utiliza para que los usuarios técnicos estandaricen rápidamente el proceso de configuración de nuevos repositorios (gancho SessionStart, PII Guard, desinfección del historial, clave API de aislamiento de proyectos). Cada vez que un usuario menciona "entorno", "configuración", "no se puede ejecutar", "configuración", "iniciar", "clonar", "cómo ejecutar", "dependencia", "está instalado", "código de confirmación", "conflicto de fusión", "fallo de inserción", se activa esta habilidad.
