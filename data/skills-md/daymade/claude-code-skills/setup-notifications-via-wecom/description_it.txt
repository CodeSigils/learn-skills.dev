Configura e invia notifiche sullo stato tecnico tramite webhook WeCom (Enterprise WeChat). Utilizza questa competenza ogni volta che l'utente deve inviare notifiche, avvisi, report di completamento del backup o aggiornamenti di stato tramite WeCom; quando menzionano 企业微信, 企微机器人, webhook o avvisi; o quando un messaggio deve essere chiaro, inequivocabile e tecnicamente preciso piuttosto che vago o condiscendente.
