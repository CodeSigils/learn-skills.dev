Escanee y elimine datos confidenciales (secretos, claves API, dominios/IP privados, PII) del historial del repositorio de GitHub. Utilice esta habilidad siempre que el usuario diga "escanear datos confidenciales", "limpiar historial de git", "eliminar secretos del repositorio", "desinfectar el historial de GitHub", "清理敏感数据", "历史重写", "forzar envío", "泄露" o necesite reparar un repositorio público después de una filtración accidental de contexto secreto/privado. Úselo también antes de cualquier envío forzado a un repositorio público para verificar la visibilidad, la copia de seguridad y los resultados del escaneo.
