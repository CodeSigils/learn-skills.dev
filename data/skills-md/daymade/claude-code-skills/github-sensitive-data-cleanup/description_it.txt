Scansiona e rimuovi i dati sensibili (segreti, chiavi API, domini/IP privati, PII) dalla cronologia del repository GitHub. Utilizza questa abilità ogni volta che l'utente dice "scansiona dati sensibili", "pulisci cronologia git", "rimuovi segreti dal repository", "disinfetta la cronologia GitHub", "清理敏感数据", "历史重写", "force push", "泄露" o ha bisogno di riparare un repository pubblico dopo una perdita accidentale di segreto/contesto privato. Da utilizzare anche prima di forzare il push a un repository pubblico per verificare la visibilità, il backup e i risultati della scansione.
