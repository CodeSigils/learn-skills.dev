قم بمسح البيانات الحساسة وإزالتها (الأسرار، ومفاتيح واجهة برمجة التطبيقات، والمجالات الخاصة/عناوين IP، ومعلومات تحديد الهوية الشخصية) من سجل مستودع GitHub. استخدم هذه المهارة عندما يقول المستخدم "مسح البيانات الحساسة"، أو "تنظيف سجل git"، أو "إزالة الأسرار من الريبو"، أو "تطهير سجل GitHub"، أو "مسح البيانات الحساسة"، أو "الضغط بقوة"، أو "الضغط"، أو يحتاج إلى إصلاح الريبو العام بعد تسرب سياق سري/خاص عرضيًا. استخدمه أيضًا قبل أي دفع بالقوة إلى مستودع عام للتحقق من نتائج الرؤية والنسخ الاحتياطي والمسح الضوئي.
