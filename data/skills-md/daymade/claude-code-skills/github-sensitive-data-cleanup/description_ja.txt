GitHub リポジトリ履歴から機密データ (シークレット、API キー、プライベート ドメイン/IP、PII) をスキャンして削除します。ユーザーが「機密データをスキャンする」、「Git 履歴をクリーンアップする」、「リポジトリからシークレットを削除する」、「GitHub 履歴をサニタイズする」、「清理機密データセット」、「历史重写」、「強制プッシュ」、「漏露」、または偶発的なシークレット/プライベート コンテキストの漏洩後にパブリック リポジトリを修復する必要があるときは、このスキルを使用します。また、パブリック リポジトリに強制的にプッシュする前に使用して、可視性、バックアップ、スキャン結果を確認します。
