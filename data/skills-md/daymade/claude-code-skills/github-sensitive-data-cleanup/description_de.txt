Scannen und entfernen Sie sensible Daten (Geheimnisse, API-Schlüssel, private Domänen/IPs, PII) aus dem GitHub-Repository-Verlauf. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer sagt: „Sensible Daten scannen“, „Git-Verlauf bereinigen“, „Geheimnisse aus Repo entfernen“, „GitHub-Verlauf bereinigen“, „清理敏感数据“, „历史重写“, „Push erzwingen“, „泄露“ oder ein öffentliches Repo nach einem versehentlichen Verlust geheimer/privater Kontexte reparieren muss. Verwenden Sie es auch vor jedem erzwungenen Push an ein öffentliches Repository, um Sichtbarkeit, Backup und Scan-Ergebnisse zu überprüfen.
