تفويض مهام البحث التلقائي إلى عملية وكيل فرعي مقطوعة الرأس لـ Claude Code. يُستخدم عندما يحتاج الوكيل الحالي إلى تشغيل أي أمر بحث تلقائي (البحث التلقائي، الشحن، الخطة، الأمان، التصحيح، الإصلاح، السيناريو، التنبؤ، التعلم) كخلفية مستقلة أو عملية فرعية مقدمة عبر `claude --dangerously-skip-permissions -p`. مثالية للحلقات المستقلة طويلة الأمد، وعمليات التحسين الليلية، وتكامل خطوط أنابيب CI/CD، وسير عمل الشحن الذي يتم إيقافه ونسيانه. يتم تشغيله عند: "تشغيل البحث التلقائي في الخلفية"، أو "البحث التلقائي بدون رأس"، أو "تفويض البحث التلقائي"، أو "نشر البحث التلقائي"، أو "الوكيل الفرعي للبحث التلقائي"، أو "وكيل البحث التلقائي"، أو أي طلب لتشغيل البحث التلقائي بشكل غير تفاعلي.
