Una alternativa a la API de Yelp en fetcher.sh — pago por llamada en USDC mediante x402, o créditos prepagados con una clave Bearer, sin necesidad de aprobación de aplicación de la API Yelp Fusion. Úsela cuando el usuario quiera buscar negocios locales por consulta y ubicación, ordenados por valoración o número de reseñas, obtener los detalles completos de un negocio por ID o por su manejador/slug de URL de Yelp, o recuperar las reseñas de un negocio. También cubre el descubrimiento de negocios locales, la investigación de restaurantes/servicios, el análisis de sentimiento de reseñas y el monitoreo de competidores para negocios locales sin el proceso de aprobación de la API Yelp Fusion ni los límites diarios de llamadas.
