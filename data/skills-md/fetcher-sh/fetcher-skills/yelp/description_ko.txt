fetcher.sh의 Yelp API 대안 — x402를 통한 USDC 결제로 호출당 과금하거나 Bearer 키를 사용한 선불 크레딧으로 이용 가능, Yelp Fusion API 앱 승인이 필요 없음. 사용자는 쿼리와 위치로 지역 사업체를 평점 또는 리뷰 수 기준으로 정렬하여 검색하거나, ID 또는 Yelp URL 핸들/슬러그로 사업체의 전체 상세 정보를 가져오고, 사업체 리뷰를 가져올 때 사용할 수 있습니다. 또한 지역 사업체 탐색, 레스토랑·서비스 조사, 리뷰 감성 입력, 그리고 Yelp Fusion API의 앱 승인 절차 및 일일 호출 제한 없이 지역 사업체 경쟁사 모니터링까지 지원합니다.
