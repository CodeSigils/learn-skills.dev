Альтернатива Yelp API на fetcher.sh — оплата за вызов в USDC через x402 или предоплаченные кредиты с Bearer‑ключом, без необходимости одобрения приложения Yelp Fusion API. Используйте, когда пользователь хочет искать местные бизнесы по запросу и местоположению, сортируя результаты по рейтингу или количеству отзывов, получать полные данные о бизнесе по ID или по его Yelp‑URL‑хэндлу/слугу, а также получать отзывы о бизнесе. Также охватывает поиск локальных компаний, исследование ресторанов/услуг, ввод данных о настроениях отзывов и мониторинг конкурентов для местных бизнесов без процесса одобрения приложения Yelp Fusion API и ежедневных ограничений количества вызовов.
