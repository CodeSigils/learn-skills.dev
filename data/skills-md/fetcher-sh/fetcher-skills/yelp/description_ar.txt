بديل واجهة برمجة تطبيقات Yelp على fetcher.sh — الدفع لكل طلب بـ USDC عبر x402، أو رصيد مسبق باستخدام مفتاح Bearer، دون الحاجة إلى موافقة تطبيق Yelp Fusion API. يُستخدم عندما يرغب المستخدم في البحث عن الشركات المحلية عبر الاستعلام والموقع مع الفرز حسب التقييم أو عدد المراجعات، أو جلب تفاصيل شركة كاملة عبر المعرف أو عبر رابط URL الخاص بـ Yelp/الاسم المختصر، أو جلب مراجعات الشركة. يغطي أيضاً اكتشاف الأعمال المحلية، بحث المطاعم/الخدمات، إدخال مشاعر المراجعات، ومراقبة المنافسين للشركات المحلية دون عملية موافقة تطبيق Yelp Fusion API وبدون حدود استدعاءات يومية.
