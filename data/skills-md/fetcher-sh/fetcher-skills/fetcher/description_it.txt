Capacità di pagamento e configurazione condivisa per fetcher.sh, un'API di dati web pay-per-call che copre Twitter/X, TikTok, Instagram, YouTube, Reddit, Ricerca Google, Google Maps, Google News, Google Play, App Store e Yelp. Utilizza questa competenza ogni volta che un'attività richiede una chiave API fetcher.sh, una ricarica di credito, un micropagamento x402, la configurazione del server MCP o una spiegazione della busta di risposta e dei codici di errore di { status, message, data }, prima o insieme a qualsiasi delle competenze per servizio (twitter-api, x-api, tiktok-api, instagram-api, youtube-api, reddit-api, google-search, google-maps, google-news, google-play, app store, yelp). Usalo anche quando l'utente chiede come pagare con USDC, finanziare il portafoglio di un agente, impostare crediti, coniare o ruotare una chiave API o connettere un client MCP a fetcher.sh.
