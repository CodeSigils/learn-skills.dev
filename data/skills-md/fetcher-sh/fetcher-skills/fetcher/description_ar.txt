مهارة مشاركة الدفع والإعداد لـ fetcher.sh، وهي واجهة برمجة تطبيقات بيانات ويب بنظام الدفع لكل استدعاء تغطّي Twitter/X و TikTok و Instagram و YouTube و Reddit و Google Search و Google Maps و Google News و Google Play ومتجر التطبيقات (App Store) و Yelp. استخدم هذه المهارة كلما احتاج أي مهمة إلى مفتاح API من fetcher.sh، أو شحن رصيد، أو دفعة دقيقة x402، أو تكوين خادم MCP، أو شرح هيكل الاستجابة { status, message, data } وأكواد الأخطاء — قبل أو جنبًا إلى جنب مع أي من مهارات الخدمة الفردية (twitter‑api، x‑api، tiktok‑api، instagram‑api، youtube‑api، reddit‑api، google‑search، google‑maps، google‑news، google‑play، app‑store، yelp). استخدمها أيضًا عندما يسأل المستخدم عن طريقة الدفع بـ USDC، أو تمويل محفظة وكيل، أو إعداد الأرصدة، أو إنشاء أو تدوير مفتاح API، أو ربط عميل MCP بـ fetcher.sh.
