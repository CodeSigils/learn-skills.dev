Habilidad compartida de pago y configuración para fetcher.sh, una API web de datos de pago por llamada que cubre Twitter/X, TikTok, Instagram, YouTube, Reddit, Google Search, Google Maps, Google News, Google Play, la App Store y Yelp. Use esta habilidad siempre que una tarea necesite una clave API de fetcher.sh, una recarga de créditos, un micropago x402, configuración del servidor MCP, o una explicación del sobre de respuesta { status, message, data } y códigos de error — antes o junto a cualquiera de las habilidades por servicio (twitter-api, x-api, tiktok-api, instagram-api, youtube-api, reddit-api, google-search, google-maps, google-news, google-play, app-store, yelp). También utilícela cuando el usuario pregunte cómo pagar con USDC, financiar una billetera de agente, configurar créditos, crear o rotar una clave API, o conectar un cliente MCP a fetcher.sh.

Por favor, responda siempre en el idioma del usuario.
