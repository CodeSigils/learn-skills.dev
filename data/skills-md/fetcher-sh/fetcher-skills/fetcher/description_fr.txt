Compétence de paiement et de configuration partagée pour fetcher.sh, une API de données Web de paiement par appel couvrant Twitter/X, TikTok, Instagram, YouTube, Reddit, la recherche Google, Google Maps, Google News, Google Play, l'App Store et Yelp. Utilisez cette compétence chaque fois qu'une tâche nécessite une clé API fetcher.sh, une recharge de crédit, un micropaiement x402, la configuration du serveur MCP ou une explication de l'enveloppe de réponse {statut, message, données} et des codes d'erreur - avant ou à côté de l'une des compétences par service (twitter-api, x-api, tiktok-api, instagram-api, youtube-api, reddit-api, google-search, google-maps, google-news, google-play, app-store, yelp). Utilisez-le également lorsque l'utilisateur demande comment payer avec USDC, financer un portefeuille d'agent, configurer des crédits, créer ou faire pivoter une clé API, ou connecter un client MCP à fetcher.sh.
