Twitter/X、TikTok、Instagram、YouTube、Reddit、Google 検索、Google マップ、Google ニュース、Google Play、App Store、Yelp をカバーするペイパーコール Web データ API である fetcher.sh の共有支払いおよびセットアップ スキル。タスクで fetcher.sh API キー、クレジット トップアップ、x402 マイクロペイメント、MCP サーバー構成、または { status, message, data } 応答エンベロープとエラー コードの説明が必要な場合は常に、サービスごとのスキル (twitter-api、x-api、tiktok-api、instagram-api、youtube-api、reddit-api、google-search、google-maps、 google-news、google-play、app-store、yelp)。また、ユーザーが USDC での支払い、エージェント ウォレットへの資金提供、クレジットの設定、API キーの生成またはローテーション、または MCP クライアントを fetcher.sh に接続する方法を尋ねるときにも使用します。
