بديل لـ Instagram API على fetcher.sh - الدفع لكل مكالمة في USDC عبر x402، أو أرصدة مدفوعة مسبقًا باستخدام مفتاح Bearer، بدون تسجيل دخول وبدون ملفات تعريف ارتباط للجلسة. يُستخدم عندما يريد المستخدم حل ملف تعريف Instagram بواسطة @handle، أو البحث عن المستخدمين حسب الكلمة الرئيسية، أو سحب منشورات الملف الشخصي، أو البكرات، أو القصص، أو المنشورات ذات العلامات، أو المتابعين، أو المتابعات، أو البحث عن منشور واحد من خلال الرمز القصير الخاص به، أو قراءة تعليقات المنشور، أو جلب المنشورات ضمن خلاصة علامة التصنيف أو موجز علامة التصنيف فقط، أو سحب المنشورات من موقع، أو سحب المنشورات باستخدام مسار صوت/موسيقى محدد. يغطي أيضًا تصدير متابعي Instagram ومراقبة الهاشتاج والموقع واكتشاف المؤثرين وتتبع محتوى المنافسين وخطوط بيانات Instagram دون التحقق الرسمي من أعمال Graph API أو متصفح بدون رأس.
