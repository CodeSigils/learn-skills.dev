Una alternativa a la API de búsqueda de Google y a la API de SERP en fetcher.sh: pago por llamada en USDC a través de x402 o créditos prepagos con una clave de portador, sin aplicación de clave API. Úselo cuando el usuario desee resultados de búsqueda programáticos de Google como JSON limpio, incluidos los propios operadores de Google (sitio:, tipo de archivo:, título: y frases exactas entrecomilladas), además de paginación, idioma (hl) y alcance de país/región. También cubre entradas de seguimiento de clasificación, investigación competitiva y monitoreo de resultados de búsqueda sin la cuota y facturación de la API de búsqueda personalizada de Google.
