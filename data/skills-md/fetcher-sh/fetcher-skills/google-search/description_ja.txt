fetcher.sh 上の Google Search API の代替および SERP API の代替 — x402 経由の USDC でのペイパーコール、またはベアラー キーを使用したプリペイド クレジットで、API キーのアプリケーションは不要です。ユーザーがプログラムによる Google 検索結果を、Google 独自の演算子 (site:、filetype:、intitle:、引用符で正確に一致するフレーズ) に加え、ページネーション、言語 (hl)、および国/地域のスコープを含むクリーンな JSON として取得したい場合に使用します。また、Google 独自のカスタム検索 API の割り当てや請求を行わずに、ランク追跡入力、競合調査、検索結果のモニタリングもカバーします。
