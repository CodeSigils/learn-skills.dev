بديل Google Search API وبديل SERP API على fetcher.sh - الدفع لكل مكالمة في USDC عبر x402، أو أرصدة مدفوعة مسبقًا باستخدام مفتاح Bearer، بدون تطبيق مفتاح API. يُستخدم عندما يريد المستخدم الحصول على نتائج بحث Google الآلية بتنسيق JSON نظيف، بما في ذلك عوامل تشغيل Google الخاصة - site:، ونوع الملف:، وintitle:، والعبارات الدقيقة المقتبسة - بالإضافة إلى ترقيم الصفحات، واللغة (hl)، ونطاق البلد/المنطقة. ويغطي أيضًا مدخلات تتبع الترتيب، والأبحاث التنافسية، ومراقبة نتائج البحث دون حصة Google المخصصة وفواتير واجهة برمجة التطبيقات للبحث المخصص.
