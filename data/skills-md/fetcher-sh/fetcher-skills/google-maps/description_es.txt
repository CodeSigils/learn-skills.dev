Una alternativa a la API de Google Maps y a la API de Google Places en fetcher.sh: pago por llamada en USDC a través de x402 o créditos prepagos con una clave Bearer, sin cuenta de facturación de Google Cloud. Úselo cuando el usuario desee buscar lugares mediante consulta de texto o anclar la búsqueda a una coordenada de latitud/longitud, obtener los detalles completos de un lugar por su ID de característica (fid), obtener las reseñas de un lugar ordenadas por relevancia/más reciente/clasificación, o buscar una sola reseña por ID. También cubre el descubrimiento de empresas locales, datos de puntos de interés, entradas de localizadores de tiendas y monitoreo de reseñas sin la configuración de clave API, facturación y precios por solicitud de Google Cloud Platform.
