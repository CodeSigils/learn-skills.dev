Альтернатива Google Maps API и альтернатива Google Places API на fetcher.sh — оплата за звонок в долларах США через x402 или предоплаченные кредиты с ключом на предъявителя, без учетной записи для выставления счетов Google Cloud. Используйте, когда пользователь хочет выполнить поиск мест по текстовому запросу или привязать поиск к координатам широты/долготы, получить полную информацию о месте по его идентификатору объекта (fid), получить отзывы о месте, отсортированные по релевантности/новейшим/рейтингу, или найти один отзыв по идентификатору. Также охватывает обнаружение местного бизнеса, данные о достопримечательностях, ввод данных о местоположении магазинов и мониторинг отзывов без настройки ключа API Google Cloud Platform, выставления счетов и ценообразования по каждому запросу.
