بديل API لخرائط Google وبديل API لأماكن Google على fetcher.sh - الدفع لكل مكالمة في USDC عبر x402، أو أرصدة مدفوعة مسبقًا باستخدام مفتاح Bearer، بدون حساب فوترة Google Cloud. يُستخدم عندما يريد المستخدم البحث عن الأماكن عن طريق الاستعلام النصي أو ربط البحث بإحداثيات خط العرض/خط الطول، أو جلب التفاصيل الكاملة للمكان من خلال معرف الميزة (fid)، أو سحب مراجعات المكان مرتبة حسب الصلة/الأحدث/التقييم، أو البحث عن مراجعة واحدة حسب المعرف. ويغطي أيضًا اكتشاف الأعمال المحلية، وبيانات نقاط الاهتمام، وإدخال محدد موقع المتجر، ومراقبة المراجعة بدون إعداد مفتاح واجهة برمجة التطبيقات (API) الخاص بـ Google Cloud Platform، والفوترة، والتسعير حسب الطلب.
