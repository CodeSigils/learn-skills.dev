بديل YouTube API على fetcher.sh - الدفع لكل مكالمة في USDC عبر x402، أو أرصدة مدفوعة مسبقًا بمفتاح Bearer، بدون OAuth ولا حصة يومية. يُستخدم عندما يريد المستخدم البحث في مقاطع فيديو YouTube باستخدام عوامل التصفية لتاريخ التحميل أو المدة أو ترتيب الفرز، أو البحث في القنوات أو قوائم التشغيل، أو البحث عن قناة حسب المعرف، أو @المعرف، أو مسار عنوان URL المخصص، أو إدراج مقاطع فيديو القناة أو السراويل القصيرة أو البث المباشر، أو جلب تفاصيل وتعليقات مقطع فيديو أو مقطع قصير، أو إدراج مقاطع فيديو في قائمة التشغيل، أو سحب المنشورات أسفل علامة تصنيف، أو التحقق من مقاطع الفيديو الشائعة حسب المنطقة. يغطي أيضًا خطوط أنابيب بيانات YouTube ومراقبة القنوات وإدخال تحليلات الفيديو وتتبع الاتجاه دون حدود الحصص اليومية الرسمية لـ YouTube Data API.
