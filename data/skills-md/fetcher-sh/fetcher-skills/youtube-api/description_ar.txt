بديل YouTube API على fetcher.sh — دفع لكل استدعاء بـ USDC عبر x402، أو رصيد مسبق مع مفتاح Bearer، بلا OAuth ولا حصة يومية. استخدمه عندما يرغب المستخدم في البحث عن مقاطع فيديو على يوتيوب مع فلاتر لتاريخ الرفع، المدة، أو ترتيب العرض، البحث عن القنوات أو القوائم التشغيلية، البحث عن قناة عبر المعرف، @handle، أو مسار URL مخصص، سرد مقاطع الفيديو، الشورتات، أو البثوث المباشرة للقناة، جلب تفاصيل وتعليقات فيديو أو شورت، سرد مقاطع الفيديو في قائمة تشغيل، سحب المشاركات تحت هاشتاغ، أو فحص الفيديوهات الشائعة حسب المنطقة. يشمل أيضًا خطوط بيانات يوتيوب، مراقبة القنوات، إدخال تحليلات الفيديو، وتتبع الاتجاهات دون حدود الحصة اليومية لواجهة YouTube Data الرسمية.
