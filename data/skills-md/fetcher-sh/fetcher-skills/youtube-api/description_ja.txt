fetcher.sh 上の YouTube API の代替 — x402 経由の USDC でのペイパーコール、または Bearer キーを使用したプリペイド クレジット、OAuth なし、日次割り当てなし。ユーザーが、アップロード日、再生時間、または並べ替え順序のフィルターを使用して YouTube 動画を検索する場合、チャンネルまたは再生リストを検索する場合、ID、@ハンドル、またはカスタム URL パスでチャンネルを検索する場合、チャンネルの動画、ショート動画、またはライブ ストリームを一覧表示する場合、動画またはショート動画の詳細とコメントを取得する場合、再生リストの動画を一覧表示する場合、ハッシュタグの下で投稿を取得する場合、または地域ごとのトレンド動画をチェックする場合に使用します。また、公式 YouTube Data API の 1 日あたりの割り当て制限なしで、YouTube データ パイプライン、チャンネル モニタリング、ビデオ分析入力、トレンド トラッキングについてもカバーします。
