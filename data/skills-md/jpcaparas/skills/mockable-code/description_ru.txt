Пассивные навыки качества кодирования для создания макетируемого, ненадежного и удобного для двойного тестирования кода. Используйте при написании, редактировании, рефакторинге, проверке или планировании кода, который затрагивает зависимости, ввод-вывод, время, случайность, внешние службы, конфигурацию или тесты. НЕ используйте для написания кода, одноразовых команд оболочки или намеренно выбрасываемых прототипов.
