مهارة جودة الترميز السلبية من أجل كود قابل للسخرية وقابل للاختبار وقابل للاختبار. يُستخدم عند كتابة أو تحرير أو إعادة بناء أو مراجعة أو تخطيط التعليمات البرمجية التي تلامس التبعيات أو الإدخال/الإخراج أو الوقت أو العشوائية أو الخدمات الخارجية أو التكوين أو الاختبارات. لا تستخدم للكتابة بدون تعليمات برمجية، أو أوامر shell لمرة واحدة، أو النماذج الأولية التي يتم التخلص منها عمدًا.
