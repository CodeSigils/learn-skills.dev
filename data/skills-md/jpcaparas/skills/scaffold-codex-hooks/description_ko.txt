Scaffold Codex는 리포지토리 감사, 라이브 공식 문서 및 스키마 확인, 효과적인 `codex_hooks` 기능 플래그 검사 및 필요한 경우 프로젝트 또는 사용자 구성에서 활성화한 후 실제 프로젝트에 연결됩니다. 사용자가 Codex 후크, `.codex/hooks.json`, 관리형 Codex 후크 새로 고침, repo-local 수명 주기 Bash 후크 또는 `SessionStart`, `PreToolUse`, `PostToolUse`, `UserPromptSubmit` 또는 `Stop`에 대한 도움말을 원할 때 사용합니다. 트리거 대상: Codex 후크, Hooks.json, codex_hooks, .codex/config.toml, 기능 플래그, 관리형 후크 스캐폴드. Claude Code 후크, `.claude/settings.json`, Husky 전용 설정 또는 Codex가 아닌 에이전트에는 사용하지 마십시오.
