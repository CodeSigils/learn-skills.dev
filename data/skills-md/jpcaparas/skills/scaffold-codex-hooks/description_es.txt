Scaffold Codex se conecta a un proyecto real después de auditar el repositorio, verificar los documentos y esquemas oficiales en vivo, inspeccionar el indicador de función efectivo `codex_hooks` y habilitarlo en la configuración del proyecto o del usuario si es necesario. Úselo cuando un usuario desee ganchos de Codex, `.codex/hooks.json`, actualizaciones de ganchos de Codex administrados, ganchos Bash de ciclo de vida local de repositorio o ayuda con `SessionStart`, `PreToolUse`, `PostToolUse`, `UserPromptSubmit` o `Stop`. Activar: ganchos de Codex, ganchos.json, codex_hooks, .codex/config.toml, indicador de función, andamio de gancho administrado. NO lo use para ganchos de Claude Code, `.claude/settings.json`, configuraciones exclusivas de Husky o agentes que no sean Codex.
