Scaffold Codex は、リポジトリを監査し、ライブの公式ドキュメントとスキーマを検証し、有効な `codex_hooks` 機能フラグを検査し、必要に応じてプロジェクトまたはユーザー設定で有効にした後、実際のプロジェクトにフックします。ユーザーが Codex フック、`.codex/hooks.json`、マネージド Codex フック更新、リポジトリ ローカル ライフサイクル Bash フック、または `SessionStart`、`PreToolUse`、`PostToolUse`、`UserPromptSubmit`、または `Stop` のヘルプを必要とする場合に使用します。トリガー: Codex フック、hooks.json、codex_hooks、.codex/config.toml、機能フラグ、マネージド フック スキャフォールド。 Claude Code フック、`.claude/settings.json`、Husky 専用セットアップ、または非 Codex エージェントには使用しないでください。
