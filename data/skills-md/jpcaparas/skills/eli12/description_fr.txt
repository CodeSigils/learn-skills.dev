Expliquez chirurgicalement comment une base de code, un sous-système, un flux de fonctionnalités ou un cluster de fichiers fonctionne dans un langage clair et accessible. À utiliser lorsque l'utilisateur demande « comment ça marche ? », souhaite une présentation du code, a besoin d'une explication simple de l'architecture ou souhaite un modèle mental digeste avec des analogies fondées sur le monde réel. Déclenchez : « expliquez cette base de code », « expliquez-moi le flux », « comment fonctionne X », « que se passe-t-il quand », « eli12 », « expliquez-le simplement », « rendez cette architecture plus facile à comprendre ». Ne PAS utiliser pour le tri des bogues, la révision du code, la narration littérale pour enfants ou les demandes qui nécessitent principalement des modifications de code plutôt qu'une explication.
