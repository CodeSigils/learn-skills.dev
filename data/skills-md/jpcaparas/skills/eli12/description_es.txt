Explique quirúrgicamente cómo funciona una base de código, un subsistema, un flujo de funciones o un grupo de archivos en un lenguaje claro y accesible. Úselo cuando el usuario pregunta "¿cómo funciona esto?", quiere un tutorial del código, necesita una explicación simple de la arquitectura o quiere un modelo mental digerible con analogías fundamentadas del mundo real. Activar: 'explica este código base', 'guíame a través del flujo', 'cómo funciona X', 'qué sucede cuando', 'eli12', 'explícalo de manera simple', 'haz que esta arquitectura sea más fácil de entender'. NO lo use para clasificación de errores, revisión de código, narración literal de cuentos para niños o solicitudes que necesiten principalmente cambios de código en lugar de explicaciones.
