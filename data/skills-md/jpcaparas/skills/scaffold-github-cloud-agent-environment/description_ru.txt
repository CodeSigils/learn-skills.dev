Проведите аудит реального репозитория, проверьте действующую документацию облачного агента GitHub Copilot и создайте резервную копию или восстановите файл .github/workflows/copilot-setup-steps.yml для облачного агента GitHub Copilot. Используйте, когда в проекте еще нет среды облачного агента, когда существующий рабочий процесс установки Copilot требует расширения или очистки или когда запуск агента завершается сбоем из-за проблем с бегунком, брандмауэром, зависимостями, LFS, прокси-сервером или формой рабочего процесса. Запуск по: среде облачного агента GitHub Copilot, `copilot-setup-steps.yml`, настройке среды агента, средству запуска облачного агента, автономному средству запуска, более крупному средству запуска, доктору настройки Copilot, исправлению среды агента Copilot. НЕ используйте для общих действий GitHub Actions, не связанных с облачным агентом Copilot, настройкой только для MCP или платформами агентов, отличными от GitHub.
