Auditez un référentiel réel, vérifiez la documentation de l'agent cloud GitHub Copilot en direct et échafaudez ou réparez `.github/workflows/copilot-setup-steps.yml` pour l'agent cloud GitHub Copilot. À utiliser lorsqu'un projet ne dispose pas encore d'environnement d'agent cloud, lorsqu'un workflow de configuration Copilot existant nécessite un enrichissement ou un nettoyage, ou lorsque l'exécution de l'agent échoue en raison de problèmes d'exécution, de pare-feu, de dépendance, de LFS, de proxy ou de forme de workflow. Déclencheur sur : environnement d'agent cloud GitHub Copilot, `copilot-setup-steps.yml`, personnalisation de l'environnement d'agent, exécuteur d'agent cloud, exécuteur auto-hébergé, exécuteur plus grand, médecin de configuration Copilot, correction de l'environnement d'agent Copilot. Ne PAS utiliser pour le travail d'actions GitHub génériques sans rapport avec l'agent cloud Copilot, la configuration MCP uniquement ou les plates-formes d'agent non GitHub.
