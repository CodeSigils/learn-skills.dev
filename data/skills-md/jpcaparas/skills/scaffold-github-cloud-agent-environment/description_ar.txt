قم بمراجعة مستودع حقيقي، والتحقق من مستندات وكيل السحابة GitHub Copilot المباشرة، والسقالة أو إصلاح `.github/workflows/copilot-setup-steps.yml` لوكيل السحابة GitHub Copilot. يُستخدم عندما لا يكون لدى المشروع بيئة وكيل سحابي حتى الآن، أو عندما يحتاج سير عمل إعداد Copilot الحالي إلى الإثراء أو التنظيف، أو عندما يفشل تشغيل الوكيل بسبب مشاكل في المشغل أو جدار الحماية أو التبعية أو LFS أو الوكيل أو شكل سير العمل. تشغيل: بيئة الوكيل السحابي GitHub Copilot، `copilot-setup-steps.yml`، تخصيص بيئة الوكيل، مشغل وكيل السحابة، عداء مستضاف ذاتيًا، عداء أكبر، طبيب إعداد Copilot، إصلاح بيئة وكيل Copilot. لا تستخدمه في أعمال GitHub Actions العامة التي لا علاقة لها بوكيل Copilot السحابي، أو إعداد MCP فقط، أو الأنظمة الأساسية غير التابعة لوكيل GitHub.
