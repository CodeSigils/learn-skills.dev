Audite un repositorio real, verifique los documentos del agente en la nube de GitHub Copilot en vivo y cree o repare `.github/workflows/copilot-setup-steps.yml` para el agente en la nube de GitHub Copilot. Úselo cuando un proyecto aún no tiene un entorno de agente en la nube, cuando un flujo de trabajo de configuración de Copilot existente necesita enriquecimiento o limpieza, o cuando la ejecución del agente falla debido a problemas de ejecutor, firewall, dependencia, LFS, proxy o forma de flujo de trabajo. Activar: entorno del agente en la nube de GitHub Copilot, `copilot-setup-steps.yml`, personalizar el entorno del agente, ejecutor del agente en la nube, ejecutor autohospedado, ejecutor más grande, médico de configuración de Copilot, arreglar el entorno del agente Copilot. NO lo use para trabajos genéricos de GitHub Actions que no estén relacionados con el agente en la nube Copilot, la configuración solo de MCP o plataformas que no sean del agente GitHub.
