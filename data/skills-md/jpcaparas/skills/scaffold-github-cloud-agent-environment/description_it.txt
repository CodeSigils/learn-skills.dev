Controlla un repository reale, verifica i documenti live dell'agente cloud GitHub Copilot e supporta o ripara `.github/workflows/copilot-setup-steps.yml` per l'agente cloud GitHub Copilot. Da utilizzare quando un progetto non dispone ancora di un ambiente agente cloud, quando un flusso di lavoro di configurazione Copilot esistente necessita di arricchimento o pulizia o quando l'esecuzione dell'agente non riesce a causa di problemi di runner, firewall, dipendenza, LFS, proxy o forma del flusso di lavoro. Attivazione: ambiente dell'agente cloud GitHub Copilot, `copilot-setup-steps.yml`, personalizzazione dell'ambiente dell'agente, runner dell'agente cloud, runner self-hosted, runner più grande, medico di configurazione di Copilot, correzione dell'ambiente dell'agente di Copilot. NON utilizzare per operazioni generiche di GitHub Actions non correlate all'agente cloud Copilot, alla configurazione solo MCP o a piattaforme di agenti non GitHub.
