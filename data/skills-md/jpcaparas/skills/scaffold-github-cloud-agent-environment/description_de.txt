Prüfen Sie ein echtes Repository, überprüfen Sie die Live-Dokumente zum GitHub Copilot-Cloud-Agenten und erstellen oder reparieren Sie „.github/workflows/copilot-setup-steps.yml“ für den GitHub Copilot-Cloud-Agenten. Verwenden Sie diese Option, wenn ein Projekt noch keine Cloud-Agent-Umgebung hat, wenn ein vorhandener Copilot-Setup-Workflow angereichert oder bereinigt werden muss oder wenn Agent-Ausführungen aufgrund von Runner-, Firewall-, Abhängigkeits-, LFS-, Proxy- oder Workflow-Shape-Problemen fehlschlagen. Auslösen bei: GitHub Copilot Cloud-Agent-Umgebung, „copilot-setup-steps.yml“, Anpassen der Agent-Umgebung, Cloud-Agent-Runner, selbstgehosteter Runner, größerer Runner, Copilot-Setup-Doctor, Korrigieren der Copilot-Agent-Umgebung. NICHT für generische GitHub-Aktionen verwenden, die nichts mit dem Copilot-Cloud-Agent, der reinen MCP-Einrichtung oder Nicht-GitHub-Agent-Plattformen zu tun haben.
