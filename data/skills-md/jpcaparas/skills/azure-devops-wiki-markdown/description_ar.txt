يُستخدم عند كتابة أو إصلاح أو مراجعة Azure DevOps wiki Markdown، ومخططات Mermaid، `_TOC_` و`_TOSP_`، كتل قابلة للطي `<details>`، تضمينات جدول الاستعلام، إشارات `@`، روابط عناصر العمل، رياضيات KaTeX، تضمينات فيديو HTML، أسوار التعليمات البرمجية، أو اختلافات الدعم الخاصة بسطح Azure DevOps عبر Wiki، PR، README، القطعة، والحقول "تم". المشغلات على Azure DevOps wiki، وإرشادات تخفيض السعر، وتسلسل حورية البحر/الرسم البياني/المخطط الزمني/مخططات ER، وأشجار قرارات الاقتراح، وجدول الصفحات الفرعية، وجدول الاستعلام، والأسماء المستعارة لسياج التعليمات البرمجية، وأخطاء فاصل الأسطر، وتنسيق صفحة wiki. لا تستخدمه مع GitHub Markdown فقط، أو تأليف Mermaid العام خارج Azure DevOps، أو منصات التوثيق غير التابعة لـ Azure.
