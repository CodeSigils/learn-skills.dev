ユーザーがmarkdown.new、Cloudflare Markdown for Agents、URLからMarkdown変換、ファイルからMarkdown変換、クロールからMarkdown、またはホストされたmarkdown.newエディターを明示的に必要とする場合は、markdown.newを使用します。トリガー: 「markdown.new」、「この URL をマークダウンに変換」、「このドキュメント サイトをマークダウンにクロール」、「ファイルをマークダウンに」、「この PDF をマークダウンにアップロード」、「markdown.new API」、または「マークダウン エディター」。別のツールで十分な場合、または markdown.new サービスを使用せずにローカル Markdown を編集する場合は、一般的な Web 検索/スクレイピングをトリガーしないでください。
