Используйте markdown.new, когда пользователю явно нужен markdown.new, Cloudflare Markdown для агентов, преобразование URL-адреса в Markdown, преобразование файла в Markdown, сканирование в Markdown или размещенный редактор markdown.new. Запуск по: «markdown.new», «конвертировать этот URL в уценку», «сканировать этот сайт документации в уценку», «файл в уценку», «загрузить этот PDF в уценку», «markdown.new API» или «редактор уценки». НЕ запускайте общий веб-поиск/скрапинг, если достаточно другого инструмента, или для редактирования локального Markdown без использования сервиса markdown.new.
