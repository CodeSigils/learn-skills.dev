Создавайте высококачественные цифровые интерфейсы для приложений продуктов, маркетинговых сайтов, информационных панелей и настольного программного обеспечения. Используйте, когда пользователю нужно художественное оформление, критика пользовательского интерфейса, стратегия редизайна, макет, типографика, цвет, движение или упрощенная система дизайна, которая позволяет избежать общих настроек по умолчанию при настройке продукта. Запускается по: вкусу дизайна, редизайну этого пользовательского интерфейса, улучшению иерархии, доработке этого приложения, пользовательскому интерфейсу информационной панели, пользовательскому интерфейсу рабочего стола, направлению целевой страницы, интервалу, масштабу шрифта, визуальному языку. НЕ запускайте запуск для дизайна логотипа, работы только с иллюстрациями, подсказок фотореалистичных изображений или задач только для серверной части без принятия решений по интерфейсу.
