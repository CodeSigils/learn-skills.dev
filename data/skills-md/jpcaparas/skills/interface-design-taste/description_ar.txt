صمم واجهات رقمية عالية الجودة عبر تطبيقات المنتجات ومواقع التسويق ولوحات المعلومات وبرامج سطح المكتب. يُستخدم عندما يريد المستخدم توجيهًا فنيًا، أو نقد واجهة المستخدم، أو استراتيجية إعادة التصميم، أو التخطيط، أو الطباعة، أو اللون، أو الحركة، أو نظام تصميم خفيف الوزن يتجنب الإعدادات الافتراضية العامة أثناء ملاءمة المنتج. المشغلات: ذوق التصميم، إعادة تصميم واجهة المستخدم هذه، تحسين التسلسل الهرمي، تلميع هذا التطبيق، واجهة مستخدم لوحة المعلومات، واجهة مستخدم سطح المكتب، اتجاه الصفحة المقصودة، التباعد، مقياس الكتابة، اللغة المرئية. لا تقم بتشغيل تصميم الشعار، أو العمل على الرسم التوضيحي فقط، أو المطالبة بالصور الحقيقية، أو مهام الواجهة الخلفية فقط بدون قرارات الواجهة.
