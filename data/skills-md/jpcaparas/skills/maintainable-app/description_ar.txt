مهارة مرونة تطبيقات الإنتاج السلبي لتطبيقات الشفاء الذاتي. يُستخدم عند ترميز الميزات أو مراجعتها باستخدام المهام، أو قوائم الانتظار، أو خطافات الويب، أو الثبات، أو واجهات برمجة التطبيقات، أو إعادة المحاولة، أو التزامن، أو التسجيل، أو التتبع، أو إمكانية الملاحظة، أو الحوادث، أو حالات الحافة، أو عمليات الأمان، أو العجز، أو الضغط الخلفي، أو التدهور السلس، أو المهام العالقة. لا تستخدمه للكتابة غير البرمجية أو البرامج النصية أو النماذج المرئية فقط.
