Entwerfen Sie ein lokales Azure DevOps-Arbeitselementpaket aus losem Kontext mit offiziellen Arbeitselementprimitiven von Azure Boards und speichern Sie es dann im aktuellen Verzeichnis des Aufrufers als Ordner mit „work-item.md“, „context.md“, „sources.md“ und „metadata.json“. Verwenden Sie diese Option, wenn Sie aufgefordert werden, ein Azure DevOps-Arbeitselement, ein Feature-Ticket, einen Fehlerbericht, eine User Story, eine Aufgabe, ein Problem oder ein Epic aus Notizen, Chats, Anforderungen oder Fehlerberichten zu erstellen, insbesondere wenn die Ausgabe chirurgisch, kopier- und einfügbar und sowohl für technische als auch für nicht-technische Zielgruppen lesbar sein soll. Auslösen bei: „Eine Azure DevOps-Arbeitsaufgabe erstellen“, „Dies in ein Feature-Ticket umwandeln“, „Eine Fehler-Arbeitsaufgabe entwerfen“, „Eine ADO-User Story erstellen“, „Einen Arbeitsaufgaben-Ordner erstellen“. NICHT für die Live-Erstellung von Azure DevOps REST oder CLI, Massenmigration, Wiki-Erstellung oder Projektstatusberichte verwenden.
