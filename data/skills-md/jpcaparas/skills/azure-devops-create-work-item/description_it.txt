Crea un pacchetto di elementi di lavoro Azure DevOps locale da un contesto libero utilizzando le primitive ufficiali degli elementi di lavoro di Azure Boards, quindi salvalo nella directory corrente del chiamante come cartella con "work-item.md", "context.md", "sources.md" e "metadata.json". Da utilizzare quando viene richiesto di creare un elemento di lavoro di Azure DevOps, un ticket di funzionalità, una segnalazione di bug, una storia utente, un'attività, un problema o un'epica da note, chat, requisiti o report di difetti, soprattutto quando l'output deve essere chirurgico, copiabile e leggibile da un pubblico sia tecnico che non tecnico. Attivazione su: "crea un elemento di lavoro Azure DevOps", "trasformalo in un ticket di funzionalità", "bozza un elemento di lavoro bug", "crea una storia utente ADO", "crea una cartella di elementi di lavoro". NON utilizzare per la creazione REST o CLI di Azure DevOps in tempo reale, la migrazione in blocco, la creazione di wiki o la creazione di report sullo stato del progetto.
