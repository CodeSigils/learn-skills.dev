Redacte un paquete de elementos de trabajo de Azure DevOps local a partir de un contexto flexible utilizando las primitivas de elementos de trabajo oficiales de Azure Boards y luego guárdelo en el directorio actual de la persona que llama como una carpeta con `work-item.md`, `context.md`, `sources.md` y `metadata.json`. Úselo cuando se le solicite crear un elemento de trabajo de Azure DevOps, un ticket de característica, un informe de error, una historia de usuario, una tarea, un problema o una epopeya a partir de notas, chats, requisitos o informes de defectos, especialmente cuando el resultado debe ser quirúrgico, copiable y legible tanto para audiencias técnicas como no técnicas. Activar: 'crear un elemento de trabajo de Azure DevOps', 'convertir esto en un ticket de característica', 'redactar un elemento de trabajo de error', 'crear una historia de usuario de ADO', 'crear una carpeta de elementos de trabajo'. NO lo use para la creación en vivo de Azure DevOps REST o CLI, migración masiva, creación de wiki o informes de estado de proyectos.
