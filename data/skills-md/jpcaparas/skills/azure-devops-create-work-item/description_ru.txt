Создайте локальный пакет рабочих элементов Azure DevOps из свободного контекста, используя официальные примитивы рабочих элементов Azure Boards, а затем сохраните его в текущем каталоге вызывающей стороны как папку с файлами work-item.md, context.md, source.md и Metadata.json. Используйте, когда вас попросят создать рабочий элемент Azure DevOps, заявку на функцию, отчет об ошибках, пользовательскую историю, задачу, проблему или эпопею из заметок, чатов, требований или отчетов о дефектах, особенно когда выходные данные должны быть хирургическими, допускающими копирование и доступными для чтения как технической, так и нетехнической аудиторией. Триггер: «создать рабочий элемент Azure DevOps», «превратить это в заявку на функцию», «составить рабочий элемент об ошибке», «создать пользовательскую историю ADO», «создать папку рабочего элемента». НЕ используйте для создания живых Azure DevOps REST или CLI, массовой миграции, создания вики-сайтов или отчетов о состоянии проекта.
