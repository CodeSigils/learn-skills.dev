Trasforma i commit e le differenze git a partire da una data di inizio esatta in un report cliente non tecnico e copia-incollabile, raggruppato per funzionalità. Da utilizzare quando l'utente desidera un aggiornamento del cliente, un riepilogo dei risultati, una nota settimanale sui progressi, un riepilogo delle parti interessate o un rapporto sullo stato di alto livello basato sulla cronologia git. Attivazione su: report del cliente dai commit, riepilogo delle differenze git da una data, aggiornamento settimanale dal registro git, risultati non tecnici, registro delle modifiche pronto per le parti interessate. NON attivare note di rilascio tecniche, revisione del codice o qualsiasi richiesta in cui la data è ancora ambigua.
