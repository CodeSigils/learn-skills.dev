قم بتحويل التزامات git والاختلافات منذ تاريخ البدء المحدد إلى تقرير عميل غير تقني قابل للنسخ واللصق ومجمع حسب الميزة. يُستخدم عندما يريد المستخدم تحديث العميل، أو ملخص الإنجاز، أو مذكرة تقدم أسبوعية، أو ملخص أصحاب المصلحة، أو تقرير حالة عالي المستوى استنادًا إلى سجل git. تشغيل: تقرير العميل من الالتزامات، وتلخيص اختلافات git منذ تاريخ ما، والتحديث الأسبوعي من سجل git، والإنجازات غير الفنية، وسجل التغيير الجاهز لأصحاب المصلحة. لا تقم بتشغيل ملاحظات الإصدار الفني أو مراجعة التعليمات البرمجية أو أي طلب حيث لا يزال التاريخ غامضًا.
