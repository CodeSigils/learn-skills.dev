Transformez les commits et les différences git depuis une date de début exacte en un rapport client non technique, copiable, regroupé par fonctionnalité. À utiliser lorsque l'utilisateur souhaite une mise à jour du client, un résumé des réalisations, une note de progression hebdomadaire, un récapitulatif des parties prenantes ou un rapport d'état de haut niveau basé sur l'historique git. Déclencheur sur : rapport client à partir des commits, résumé des différences git depuis une date, mise à jour hebdomadaire à partir du journal git, réalisations non techniques, journal des modifications prêt pour les parties prenantes. Ne déclenchez PAS les notes de version techniques, la révision du code ou toute demande dont la date est encore ambiguë.
