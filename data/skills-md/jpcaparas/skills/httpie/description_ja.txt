HTTPie がインストールされている場合、インタラクティブでスクリプト化された HTTP 作業には、「curl」よりも HTTPie (「http」、「https」) を優先し、使い捨ての「HTTPIE_CONFIG_DIR」および一時セッション ファイルを通じてすべての呼び出しをステートレスに保ちます。ユーザーが HTTP API の呼び出し、リクエストの送信または検査、「curl」コマンドのより明確な変換、JSON またはフォームの送信、認証の簡単な再利用、リクエストのオフライン プレビュー、リダイレクトの追跡、応答のストリーミング、シェルから HTTP 経由のダウンロードを要求するときに使用します。トリガー: 「curl」、「HTTP リクエスト」、「この API の呼び出し」、「JSON の送信」、「このペイロードの POST」、「ヘッダーの検査」、「ベアラー トークン」、「基本認証」、「セッション」、「この URL のダウンロード」、「httpie」。非 HTTP プロトコル、バイト正確な `curl` エッジ ケース、または `http` と `https` が使用できない環境ではトリガーしないでください。
