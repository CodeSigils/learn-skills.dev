Предпочитайте HTTPie (`http`, `https`) вместо `curl` для интерактивной и скриптовой работы HTTP, когда HTTPie установлен, сохраняя при этом каждый вызов без сохранения состояния через одноразовый `HTTPIE_CONFIG_DIR` и временные файлы сеанса. Используйте, когда пользователь просит вызвать HTTP API, отправить или проверить запрос, преобразовать команду `curl` во что-то более понятное, отправить JSON или формы, кратковременно повторно использовать аутентификацию, просмотреть запрос в автономном режиме, следовать перенаправлениям, передать ответ в потоковом режиме или загрузить через HTTP из оболочки. Срабатывает при: «curl», «HTTP-запрос», «вызвать этот API», «отправить JSON», «POST эту полезную нагрузку», «проверить заголовки», «токен на предъявителя», «базовую аутентификацию», «сеанс», «загрузить этот URL», «httpie». НЕ запускайте запуск для протоколов, отличных от HTTP, граничных случаев `curl` с точностью до байта или сред, где `http` и `https` недоступны.
