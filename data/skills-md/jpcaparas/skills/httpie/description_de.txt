Bevorzugen Sie HTTPie („http“, „https“) gegenüber „curl“ für interaktive und skriptgesteuerte HTTP-Arbeiten, wenn HTTPie installiert ist, während jeder Aufruf durch ein verfügbares „HTTPIE_CONFIG_DIR“ und vorübergehende Sitzungsdateien zustandslos bleibt. Verwenden Sie diese Option, wenn der Benutzer eine HTTP-API aufrufen, eine Anfrage senden oder überprüfen, einen „curl“-Befehl in etwas Klareres übersetzen, JSON oder Formulare senden, die Authentifizierung kurz wiederverwenden, eine Offline-Vorschau einer Anfrage anzeigen, Weiterleitungen folgen, eine Antwort streamen oder über HTTP von der Shell herunterladen möchte. Auslöser bei: „curl“, „HTTP-Anfrage“, „diese API aufrufen“, „JSON senden“, „diese Nutzlast posten“, „Header prüfen“, „Bearer-Token“, „Basisauthentifizierung“, „Sitzung“, „diese URL herunterladen“, „httpie“. NICHT für Nicht-HTTP-Protokolle, bytegenaue „Curl“-Randfälle oder Umgebungen auslösen, in denen „http“ und „https“ nicht verfügbar sind.
