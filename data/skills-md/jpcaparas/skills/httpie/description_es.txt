Prefiera HTTPie (`http`, `https`) a `curl` para el trabajo HTTP interactivo y con secuencias de comandos cuando HTTPie esté instalado, manteniendo cada invocación sin estado a través de un `HTTPIE_CONFIG_DIR` desechable y archivos de sesión transitorios. Úselo cuando el usuario solicite llamar a una API HTTP, enviar o inspeccionar una solicitud, traducir un comando `curl` a algo más claro, enviar JSON o formularios, reutilizar la autenticación brevemente, obtener una vista previa de una solicitud sin conexión, seguir redirecciones, transmitir una respuesta o descargar a través de HTTP desde el shell. Activadores en: 'curl', 'solicitud HTTP', 'llamar a esta API', 'enviar JSON', 'PUBLICAR esta carga útil', 'inspeccionar encabezados', 'token de portador', 'autenticación básica', 'sesión', 'descargar esta URL', 'httpie'. NO active protocolos que no sean HTTP, casos extremos de `curl` con bytes exactos o entornos donde `http` y `https` no estén disponibles.
