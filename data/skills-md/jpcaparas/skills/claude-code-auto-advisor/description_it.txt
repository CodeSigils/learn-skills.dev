Politica di consulenza passiva solo per Claude Code. Utilizzare in Claude Code per sicurezza, revisioni del codice, progettazione ad alto rischio, convalida di piani di alto livello in più fasi per lavori sostanziali, refactoring complessi, errori ricorrenti o controlli di completamento. Consultare l'advisor configurato senza chiedere conferma all'utente. NON utilizzare al di fuori del Codice Claude, senza un modello/strumento di consulenza, per compiti banali o per la pianificazione ordinaria.
