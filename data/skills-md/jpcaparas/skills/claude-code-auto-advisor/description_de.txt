Claude Code nur passive Beraterrichtlinie. Verwendung in Claude Code für Sicherheit, Codeüberprüfungen, anspruchsvolles Design, mehrstufige Planvalidierung auf hoher Ebene für umfangreiche Arbeiten, komplexe Refaktoren, wiederkehrende Fehler oder Abschlussprüfungen. Konsultieren Sie den konfigurierten Advisor ohne Benutzeraufforderung. Verwenden Sie es NICHT außerhalb von Claude Code, ohne Beratermodell/-tool, für triviale Aufgaben oder für normale Planung.
