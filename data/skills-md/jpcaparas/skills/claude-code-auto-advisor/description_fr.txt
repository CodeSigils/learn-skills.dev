Claude Code Politique de conseiller uniquement passive. Utilisation dans Claude Code pour la sécurité, les révisions de code, la conception à enjeux élevés, la validation de plans de haut niveau en plusieurs étapes pour des travaux substantiels, les refactorisations complexes, les échecs récurrents ou les contrôles d'achèvement. Consultez le conseiller configuré sans invite de l'utilisateur. Ne PAS utiliser en dehors de Claude Code, sans modèle/outil de conseiller, pour des tâches triviales ou pour une planification ordinaire.
