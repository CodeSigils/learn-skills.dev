مهارة جودة الترميز السلبية للحصول على تعليمات برمجية قابلة للصيانة ومتحللة وقابلة للقراءة. يُستخدم عند الكتابة أو التحرير أو إعادة البناء أو المراجعة أو التخطيط للتعليمات البرمجية التي تتضمن التعقيد أو التسمية أو الاختبارات أو الحدود أو الديون التقنية. لا تستخدم للكتابة بدون تعليمات برمجية، أو أوامر shell لمرة واحدة، أو تعليمات برمجية يتم التخلص منها عمدًا.
