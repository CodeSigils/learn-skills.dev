Transformez une ressource lisible en audio Gemini TTS nettoyé. À utiliser lorsque l'utilisateur souhaite audifier une URL, une note de démarque, une page HTML, un DOCX ou un texte brut dans un MP3 tout en supprimant le balisage, le HTML, les barrières de code et les URL nues avant la synthèse. Se déclenche sur : "/audify", "lire ceci à voix haute", "transformer cette page en audio", "faire une narration mp3", "text to Speech cette ressource", ou lorsque Gemini 3.1 Flash TTS avec `GEMINI_API_KEY` est le bon chemin. Ne déclenchez PAS la génération de musique, le chat vocal en direct ou les sources binaires/médias qui ne sont pas destinées à être racontées.
