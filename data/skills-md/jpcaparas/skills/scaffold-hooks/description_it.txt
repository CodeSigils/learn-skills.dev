Impalcatura universale/scaffold-hooks per Claude Code, Codex, GitHub Copilot, Devin CLI e ganci OpenCode - insieme o singolarmente. Controlla un progetto, rileva le superfici dei ganci esistenti, aggiorna solo i cablaggi per impostazione predefinita e collega le configurazioni `.claude`, `.codex`, `.github`, `.devin` e `.opencode` selezionate nelle impalcature "ganci/" di proprietà del repository. NON utilizzare per hook Git o Husky.
