Andamio universal /scaffold-hooks para Claude Code, Codex, GitHub Copilot, Devin CLI y OpenCode, juntos o individualmente. Audita un proyecto, detecta superficies de gancho existentes, actualiza solo esos arneses de forma predeterminada y conecta las configuraciones `.claude`, `.codex`, `.github`, `.devin` y `.opencode` seleccionadas en un andamio `hooks/` propiedad del repositorio. NO lo use para ganchos de Git o Husky.
