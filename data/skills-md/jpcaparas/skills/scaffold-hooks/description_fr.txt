Échafaudage universel / scaffold-hooks pour les hooks Claude Code, Codex, GitHub Copilot, Devin CLI et OpenCode — ensemble ou individuellement. Audite un projet, détecte les surfaces de crochet existantes, actualise uniquement ces faisceaux par défaut et connecte les configurations `.claude`, `.codex`, `.github`, `.devin` et `.opencode` sélectionnées dans des échafaudages `hooks/` appartenant au dépôt. Ne PAS utiliser pour les hooks Git ou Husky.
