Универсальный шаблон /scaffold-hooks для перехватчиков Claude Code, Codex, GitHub Copilot, Devin CLI и OpenCode — вместе или по отдельности. Аудит проекта, обнаруживает существующие поверхности перехватчиков, обновляет только эти жгуты по умолчанию и подключает выбранные конфигурации `.claude`, `.codex`, `.github`, `.devin` и `.opencode` к каркасу `hooks/`, принадлежащему репозиторию. НЕ используйте для хуков Git или Husky.
