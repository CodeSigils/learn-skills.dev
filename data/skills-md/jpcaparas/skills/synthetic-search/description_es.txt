Utilice esta habilidad cuando el usuario desee explícitamente la búsqueda sintética, la API sintética, `api.synthetic.new`, `SYNTHETIC_API_KEY` o una búsqueda web sin retención de datos con ejemplos sin procesar de `curl`/`jq`. Cubre solicitudes de búsqueda verificadas en vivo, verificaciones de cuotas y un asistente de Nodo sin dependencia para resultados legibles. Activadores en: 'Búsqueda sintética', 'API sintética', 'api.synthetic.new', 'SYNTHETIC_API_KEY', 'Cuotas sintéticas'. NO active la automatización general del navegador, el rastreo de sitios completos ni proveedores de búsqueda no relacionados.
