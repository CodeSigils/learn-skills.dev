Verwenden Sie diesen Skill, wenn der Benutzer explizit synthetische Suche, die synthetische API „api.synthetic.new“, „SYNTHETIC_API_KEY“ oder eine Websuche ohne Datenaufbewahrung mit rohen „curl“-/jq-Beispielen wünscht. Es umfasst live verifizierte Suchanfragen, Kontingentprüfungen und einen Node-Helper ohne Abhängigkeit für eine lesbare Ausgabe. Auslöser bei: „Synthetische Suche“, „Synthetische API“, „api.synthetic.new“, „SYNTHETIC_API_KEY“, „Synthetische Quoten“. Lösen Sie NICHT die allgemeine Browserautomatisierung, das vollständige Crawlen der Website oder nicht verwandte Suchanbieter aus.
