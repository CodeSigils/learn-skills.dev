Scaffold Claude Code는 프로젝트 구조를 자세히 감사한 후 실제 프로젝트에 연결됩니다. 사용자가 Claude Code 후크 설정, 후크 리팩터링, 전체 후크 이벤트 스캐폴딩 또는 기존 .claude 후크에 대한 관리형 업데이트를 원할 때 사용합니다. 이 기술은 라이브 공식 Claude Code 후크 문서를 먼저 확인하고 대상 저장소를 감사한 다음 후크 README, 반복 가능한 병합 동작 및 모든 현재 후크 이벤트에 대한 적용 범위를 포함하는 bash 우선 후크 스캐폴드를 생성합니다. 트리거 대상: Claude Code 후크, 스캐폴드 후크, 후크 이벤트, 업데이트 후크, 후크 아키텍처, .claude/settings.json. 일반 Git 후크, Husky 전용 설정 또는 Claude가 아닌 에이전트에는 사용하지 마십시오.
