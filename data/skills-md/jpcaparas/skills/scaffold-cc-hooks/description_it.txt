Lo scaffold Claude Code si aggancia a un progetto reale dopo aver controllato in dettaglio la struttura del progetto. Da utilizzare quando un utente desidera la configurazione degli hook di Claude Code, i refactoring degli hook, l'impalcatura completa degli eventi di hook o gli aggiornamenti gestiti agli hook .claude esistenti. Questa abilità verifica prima i documenti hook ufficiali di Claude Code dal vivo, controlla il repository di destinazione, quindi genera uno scaffold hook bash-first con un README hook, comportamento di unione ripetibile e copertura per ogni evento hook corrente. Attivazione su: hook Claude Code, hook per impalcature, eventi hook, hook di aggiornamento, architettura hook, .claude/settings.json. NON utilizzare per hook Git generici, configurazioni solo Husky o agenti non Claude.
