Scaffold Claude Code s'intègre dans un projet réel après avoir audité la structure du projet en détail. À utiliser lorsqu'un utilisateur souhaite configurer un hook Claude Code, des refactoristes de hook, un échafaudage complet d'événements de hook ou des mises à jour gérées des hooks .claude existants. Cette compétence vérifie d'abord la documentation officielle du hook Claude Code en direct, audite le dépôt cible, puis génère un échafaudage de hook bash-first avec un README de hooks, un comportement de fusion répétable et une couverture pour chaque événement de hook en cours. Déclencheur sur : hooks Claude Code, hooks d'échafaudage, événements de hook, hooks de mise à jour, architecture de hook, .claude/settings.json. Ne PAS utiliser pour les hooks Git génériques, les configurations Husky uniquement ou les agents non Claude.
