Scaffold Claude Code se conecta a un proyecto real después de auditar la estructura del proyecto en detalle. Úselo cuando un usuario desee configurar enlaces de Claude Code, refactorizar enlaces, andamiaje completo de eventos de enlaces o actualizaciones administradas de enlaces .claude existentes. Esta habilidad verifica primero los documentos oficiales de enlace de Claude Code en vivo, audita el repositorio de destino y luego genera una estructura de enlace de bash primero con un archivo README de ganchos, comportamiento de fusión repetible y cobertura para cada evento de enlace actual. Activar: enlaces de Claude Code, enlaces de andamio, eventos de enlace, enlaces de actualización, arquitectura de enlace, .claude/settings.json. NO lo use para ganchos Git genéricos, configuración exclusiva de Husky o agentes que no sean Claude.
