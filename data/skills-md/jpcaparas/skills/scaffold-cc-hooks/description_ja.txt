Scaffold Claude Code は、プロジェクト構造を詳細に監査した後、実際のプロジェクトにフックします。ユーザーが Claude Code のフック設定、フックのリファクタリング、完全なフックイベントのスキャフォールディング、または既存の .claude フックの管理された更新を必要とする場合に使用します。このスキルは、最初にライブの公式 Claude Code フック ドキュメントを検証し、ターゲット リポジトリを監査してから、フック README、反復可能なマージ動作、現在のすべてのフック イベントのカバレッジを備えた bash-first フック スキャフォールドを生成します。トリガー: クロード コード フック、スキャフォールド フック、フック イベント、更新フック、フック アーキテクチャ、.claude/settings.json。汎用の Git フック、Husky のみのセットアップ、または Claude 以外のエージェントには使用しないでください。
