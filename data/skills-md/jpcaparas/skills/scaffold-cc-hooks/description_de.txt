Scaffold Claude Code fügt sich in ein reales Projekt ein, nachdem die Projektstruktur im Detail geprüft wurde. Verwenden Sie diese Option, wenn ein Benutzer die Einrichtung von Claude Code-Hooks, Hook-Refaktoren, ein vollständiges Hook-Event-Gerüst oder verwaltete Aktualisierungen vorhandener .claude-Hooks wünscht. Dieser Skill überprüft zunächst die offiziellen Live-Hook-Dokumente von Claude Code, prüft das Ziel-Repo und generiert dann ein Bash-First-Hook-Gerüst mit einer Hook-README-Datei, wiederholbarem Zusammenführungsverhalten und Abdeckung für jedes aktuelle Hook-Ereignis. Auslöser bei: Claude Code-Hooks, Scaffold-Hooks, Hook-Ereignisse, Update-Hooks, Hook-Architektur, .claude/settings.json. NICHT für generische Git-Hooks, reine Husky-Setups oder Nicht-Claude-Agenten verwenden.
