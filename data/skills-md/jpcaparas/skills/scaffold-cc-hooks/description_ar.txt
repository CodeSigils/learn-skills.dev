يتم ربط Scaffold Claude Code بمشروع حقيقي بعد مراجعة هيكل المشروع بالتفصيل. يُستخدم عندما يريد المستخدم إعداد ربط Claude Code، أو إعادة بناء الخطاف، أو سقالات حدث الربط الكامل، أو التحديثات المُدارة لخطافات .claude الموجودة. تتحقق هذه المهارة من مستندات ربط Claude Code الرسمية المباشرة أولاً، وتدقق الريبو المستهدف، ثم تنشئ سقالة خطاف bash-first مع ملف README للخطافات، وسلوك الدمج القابل للتكرار، وتغطية لكل حدث ربط حالي. تشغيل: خطافات Claude Code، وخطافات السقالة، وأحداث الخطاف، وخطافات التحديث، وبنية الخطاف، و.claude/settings.json. لا تستخدمه مع خطافات Git العامة، أو إعداد Husky فقط، أو وكلاء غير Claude.
