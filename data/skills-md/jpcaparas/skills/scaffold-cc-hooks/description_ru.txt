Scaffold Claude Code подключается к реальному проекту после детального аудита структуры проекта. Используйте, когда пользователю нужна настройка перехватчиков Claude Code, рефакторинг перехватчиков, полная обработка событий перехватчиков или управляемые обновления существующих перехватчиков .claude. Этот навык сначала проверяет действующую официальную документацию по ловушкам Claude Code, проверяет целевой репозиторий, затем генерирует каркас перехватчиков bash с README перехватчиков, повторяемым поведением слияния и покрытием для каждого текущего события перехвата. Запуск по: перехватчикам кода Claude, перехватчикам scaffold, событиям перехвата, перехватчикам обновления, архитектуре перехватчиков, .claude/settings.json. НЕ используйте для общих перехватчиков Git, установки только для Husky или агентов, отличных от Claude.
