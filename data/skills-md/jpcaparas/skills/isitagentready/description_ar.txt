قم بمراجعة المستودع مقابل إشارات جاهزية وكيل Cloudflare من موقع isitagentready.com ومنشور إطلاق Cloudflare بتاريخ 17 أبريل 2026، ثم اكتب حزمة تقرير تفصيلية عن تخفيض السعر. يُستخدم عندما يطلب المستخدم /isitagentready، أو تدقيق جاهزية الوكيل، أو جاهزية وكيل AI، أو جاهزية تفاوض robots.txt/llms.txt/markdown، أو جاهزية اكتشاف كتالوج MCP أو API، أو جاهزية اكتشاف OAuth، أو جاهزية WebMCP، أو مراجعة على مستوى الريبو لمعرفة ما إذا كان الموقع المنشور يعمل بشكل جيد لوكلاء الذكاء الاصطناعي. في حالة وجود عنوان URL للإنتاج وتوافر مهارة متصفح بدون رأس، فاطلب عنوان URL، وقم بتشغيل تصريح المتصفح أولاً، ثم افحص المصدر. لا تقم بتشغيل عمليات تدقيق عامة لتحسين محركات البحث، أو طلبات التنفيذ المباشر فقط، أو الأسئلة ذات المعيار الفردي التي لا تتطلب تدقيق المستودع.
