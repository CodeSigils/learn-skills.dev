Scaffold OpenCode перехватывает путем создания плагинов OpenCode в реальном проекте после аудита репозитория, проверки действующих официальных документов плагинов, проверки приоритета конфигурации и существующего состояния `.opencode/plugins`, а затем создания детерминированного управляемого слоя плагинов с повторяемыми слияниями конфигураций и пакетов. Запуск по перехватчикам OpenCode, плагинам OpenCode, `.opencode/plugins`, `opencode.json`, `tool.execute.before`, `tool.execute.after`, `session.idle`, `shell.env`, пользовательским инструментам или проверкам после поворота. НЕ используйте для перехватчиков Codex, перехватчиков Claude Code или публикации общих пакетов npm без среды выполнения OpenCode.
