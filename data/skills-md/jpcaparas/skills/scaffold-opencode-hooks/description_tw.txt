Scaffold OpenCode 掛鉤透過在審核儲存庫、驗證即時官方插件文件、檢查配置優先順序和現有的「.opencode/plugins」狀態後將 OpenCode 插件產生到真實專案中，然後建立具有可重複配置和套件合併的確定性託管插件層。在 OpenCode 掛鉤、OpenCode 外掛程式、`.opencode/plugins`、`opencode.json`、`tool.execute.before`、`tool.execute.after`、`session.idle`、`shell.env`、自訂工具或事後檢查上觸發。請勿用於 Codex 掛鉤、Claude Code 掛鉤或沒有 OpenCode 運行時的通用 npm 套件發布。
