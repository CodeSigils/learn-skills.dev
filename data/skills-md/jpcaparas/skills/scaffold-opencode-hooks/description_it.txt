L'impalcatura OpenCode si aggancia generando i plugin OpenCode in un progetto reale dopo aver controllato il repository, verificato i documenti ufficiali dei plugin in tempo reale, ispezionato la precedenza della configurazione e lo stato `.opencode/plugins` esistente, quindi costruendo un livello di plugin gestito deterministico con configurazioni ripetibili e fusioni di pacchetti. Attivazione su hook OpenCode, plugin OpenCode, `.opencode/plugins`, `opencode.json`, `tool.execute.before`, `tool.execute.after`, `session.idle`, `shell.env`, strumenti personalizzati o controlli post-turn. NON utilizzare per hook Codex, hook Claude Code o pubblicazione di pacchetti npm generici senza runtime OpenCode.
