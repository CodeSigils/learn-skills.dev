リポジトリを監査し、ライブの公式プラグイン ドキュメントを検証し、設定の優先順位と既存の `.opencode/plugins` 状態を検査した後、実際のプロジェクトに OpenCode プラグインを生成し、反復可能な設定とパッケージのマージを使用して決定論的なマネージド プラグイン レイヤーを構築することで、OpenCode フックを足場にします。 OpenCode フック、OpenCode プラグイン、`.opencode/plugins`、`opencode.json`、`tool.execute.before`、`tool.execute.after`、`session.idle`、`shell.env`、カスタム ツール、またはターン後のチェックでトリガーします。 Codex フック、Claude Code フック、または OpenCode ランタイムを使用しない汎用の npm パッケージ公開には使用しないでください。
