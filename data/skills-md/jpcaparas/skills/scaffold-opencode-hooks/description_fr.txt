Échafaudez les hooks OpenCode en générant des plugins OpenCode dans un projet réel après avoir audité le dépôt, vérifié la documentation officielle du plugin en direct, inspecté la priorité de configuration et l'état `.opencode/plugins` existant, puis construit une couche de plugin gérée déterministe avec des fusions de configuration et de packages répétables. Déclenchez sur les hooks OpenCode, les plugins OpenCode, `.opencode/plugins`, `opencode.json`, `tool.execute.before`, `tool.execute.after`, `session.idle`, `shell.env`, des outils personnalisés ou des vérifications après tour. Ne pas utiliser pour les hooks Codex, les hooks Claude Code ou la publication de packages npm génériques sans environnement d'exécution OpenCode.
