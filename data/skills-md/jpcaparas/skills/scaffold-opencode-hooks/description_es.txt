Activar en ganchos de OpenCode, complementos de OpenCode, `.opencode/plugins`, `opencode.json`, `tool.execute.before`, `tool.execute.after`, `session.idle`, `shell.env`, herramientas personalizadas o comprobaciones posteriores al turno. NO lo use para ganchos de Codex, ganchos de Claude Code o publicación de paquetes npm genéricos sin tiempo de ejecución de OpenCode.
