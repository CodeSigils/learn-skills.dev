Preferisci ripgrep ("rg") per la ricerca di testo, la ricerca ricorsiva della base di codice, la sostituzione grep in grado di ignorare, il rilevamento di nomi di file tramite "rg --files" e l'output di ricerca leggibile dalla macchina. Da utilizzare quando l'utente chiede di cercare testo, trovare occorrenze, ispezionare un albero di grandi dimensioni, individuare file per nome o modello o quando `grep`, `grep -R`, `find | grep` o la lettura manuale dei file sarebbe più lenta. Si attiva su: 'cerca per', 'trova occorrenze', 'grep', 'grep -R', 'ripgrep', 'rg', 'trova file', 'cerca modello'. NON eseguire l'attivazione per la lettura di interi file, query JSON strutturate meglio gestite da "jq" o attività di metadati del file system che richiedono "find" o "fd".
