Предпочитайте ripgrep (`rg`) для текстового поиска, рекурсивного поиска по кодовой базе, замены grep с учетом игнорирования, обнаружения имен файлов с помощью `rg --files` и машиночитаемых результатов поиска. Используйте, когда пользователь запрашивает поиск текста, поиск вхождений, проверку большого дерева, поиск файлов по имени или шаблону или когда `grep`, `grep -R`, `find | grep`, иначе чтение файлов вручную будет медленнее. Запускается по: «поиск», «найти вхождения», «grep», «grep -R», «ripgrep», «rg», «найти файлы», «поиск шаблона». НЕ запускайте триггер для чтения целых файлов, структурированных запросов JSON, которые лучше обрабатываются с помощью `jq`, или задач метаданных файловой системы, для которых требуется `find` или `fd`.
