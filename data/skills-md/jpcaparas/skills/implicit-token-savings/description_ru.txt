Используйте компактные, малошумящие команды оболочки для исследования репозиториев, git status/diff/log, тестов, контейнеров и поиска файлов. Запустите экономию токенов, краткий рабочий процесс оболочки, rg, Tree, pytest, npm test, грузовой тест, go test или docker ps. НЕ используйте, когда требуется полный вывод.
