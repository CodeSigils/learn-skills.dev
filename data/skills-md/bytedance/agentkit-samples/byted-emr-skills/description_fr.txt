byted-emr-skills offre la possibilité de gérer Volcano Engine EMR (Volcano Engine E-MapReduce, ou « EMR » en abrégé, est un système d'analyse Big Data de niveau entreprise construit sur Hadoop open source et entièrement compatible avec celui-ci), y compris l'administration d'EMR sur les clusters ECS, EMR sur les clusters VKE, les files d'attente sans serveur EMR, les groupes de calcul, les modèles/instances de tâches, les journaux, la surveillance et l'offre de diagnostics intelligents et de questions-réponses avec l'agent EMR. Lorsque les utilisateurs mentionnent « EMR sur cluster ECS », « EMR sur cluster VKE », « File d'attente sans serveur », « Travail sans serveur », « Travail SparkSQL/PrestoSQL/Ray/PySpark/SparkJar », « Journal des travaux », « Surveillance des travaux », « Diagnostic des travaux » ou des besoins similaires, cette compétence doit être utilisée en premier.
