Converte e transcodifica formati di file audio e parametri di codifica utilizzando Volcengine LAS. Conversione del formato audio tra wav, mp3, flac, m4a, ogg, aac e altri formati audio. Regola la frequenza di campionamento (ricampionamento, downsample, upsample), bit rate (bitrate), canali (mono, stereo, mixaggio canali), compressione audio e impostazioni di qualità audio tramite i parametri ffmpeg. Supporta percorsi di archiviazione cloud TOS e caricamento di file locali. Utilizza questa abilità quando l'utente desidera convertire il formato audio (wav/mp3/flac/m4a/ogg/aac), transcodificare o ricodificare file audio, regolare la frequenza di campionamento audio, il bitrate, i canali, comprimere file audio, ricampionare o sottocampionare l'audio, preparare l'audio per attività downstream o eseguire qualsiasi preelaborazione audio.
