La capacidad de activar localmente el servidor MCP de ByteHouse e invocar sus herramientas, que se utilizan para conectarse a ByteHouse para consultar datos, interactuar con ByteHouse a través del protocolo MCP, generar catálogos de activos de datos y realizar análisis de linaje. Utilice esta habilidad cuando necesite conectarse a ByteHouse, consultar datos, interactuar a través de MCP o crear catálogos de datos y linaje.
