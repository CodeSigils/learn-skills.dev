Habilidad de búsqueda híbrida de ByteHouse, que admite búsqueda de texto completo + búsqueda vectorial, combinada con el algoritmo de reclasificación RRF para lograr resultados de búsqueda más precisos. Utilice esta habilidad cuando los usuarios necesiten realizar una búsqueda de texto completo + búsqueda vectorial en la base de datos ByteHouse, combinada con el algoritmo de reclasificación RRF para lograr resultados de búsqueda más precisos.
