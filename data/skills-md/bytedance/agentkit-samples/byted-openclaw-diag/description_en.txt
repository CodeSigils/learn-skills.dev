OpenClaw system diagnostics and performance analysis tool. Analyzes agent inference latency, token usage, tool invocation statistics, Run timelines, and Gateway restart history. Supports multiple modes: batch analysis (default), real-time tracing (-f), summary statistics (-s), and advanced diagnostics (--advanced). Allows multi-agent filtering. Use case: triggered when users inquire about OpenClaw operational status, performance bottlenecks, inference latency, token consumption, tool execution statistics, error troubleshooting, or agent activity analysis. Trigger words: diagnostics, performance analysis, inference latency, token statistics, operational status, agent analysis, tool invocation statistics, Run details, Gateway restart. Command trigger: /diag — runs diagnostics directly, with parameter passthrough support.
