Guider les développeurs dans l'intégration et l'utilisation du SDK Viking, couvrant l'installation, l'authentification, les appels API et le dépannage de la base de données vectorielle Viking, de la base de connaissances et de la base de mémoire. Utilisez-le lorsque les utilisateurs doivent appeler le SDK Viking pour le développement de code métier ou ont des questions liées à Viking.
