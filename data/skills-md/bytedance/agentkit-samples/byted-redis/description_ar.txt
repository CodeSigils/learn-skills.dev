مهارة التشغيل والتفاعل مع خادم Volcengine Redis MCP. تتيح هذه المهارة للوكلاء إدارة مثيلات Redis وقواعد البيانات والحسابات والنسخ الاحتياطية والتكوينات باستخدام بروتوكول MCP. إنه يتصل بـ Volcengine عبر بيانات الاعتماد المقدمة. استخدم هذه المهارة عندما يحتاج المستخدم إلى إدارة موارد Volcengine Redis عبر MCP (على سبيل المثال، قائمة المثيلات، وسجلات/مفاتيح الاستعلام، وإدارة الحسابات/القوائم المسموح بها/النسخ الاحتياطية/المعلمات).
