Una habilidad para iniciar e interactuar con el servidor Volcengine Redis MCP. Esta habilidad permite a los agentes administrar instancias, bases de datos, cuentas, copias de seguridad y configuraciones de Redis utilizando el protocolo MCP. Se conecta a Volcengine a través de las credenciales proporcionadas. Utilice esta habilidad cuando el usuario necesite administrar recursos de Volcengine Redis a través de MCP (por ejemplo, enumerar instancias, consultar registros/claves, administrar cuentas/listas permitidas/copias de seguridad/parámetros).
