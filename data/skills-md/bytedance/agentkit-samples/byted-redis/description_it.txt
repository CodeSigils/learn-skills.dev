Una capacità per avviare e interagire con il server MCP Volcengine Redis. Questa competenza consente agli agenti di gestire istanze, database, account, backup e configurazioni Redis utilizzando il protocollo MCP. Si connette a Volcengine tramite le credenziali fornite. Utilizza questa competenza quando l'utente deve gestire le risorse Volcengine Redis tramite MCP (ad esempio, elencare istanze, eseguire query su log/chiavi, gestire account/liste consentite/backup/parametri).
