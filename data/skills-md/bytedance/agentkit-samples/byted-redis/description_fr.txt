Une compétence pour lancer et interagir avec le serveur Volcengine Redis MCP. Cette compétence permet aux agents de gérer les instances Redis, les bases de données, les comptes, les sauvegardes et les configurations à l'aide du protocole MCP. Il se connecte à Volcengine via les informations d'identification fournies. Utilisez cette compétence lorsque l'utilisateur a besoin de gérer les ressources Volcengine Redis via MCP (par exemple, lister les instances, interroger les journaux/clés, gérer les comptes/listes autorisées/sauvegardes/paramètres).
