Навык запуска и взаимодействия с сервером Volcengine Redis MCP. Этот навык позволяет агентам управлять экземплярами Redis, базами данных, учетными записями, резервными копиями и конфигурациями с использованием протокола MCP. Он подключается к Volcengine через предоставленные учетные данные. Используйте этот навык, когда пользователю необходимо управлять ресурсами Volcengine Redis через MCP (например, создавать списки, запрашивать журналы/ключи, управлять учетными записями/списками разрешений/резервными копиями/параметрами).
