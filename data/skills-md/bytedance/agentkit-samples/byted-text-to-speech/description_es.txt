Sintetizar texto en voz (TTS). Utiliza la API de síntesis de voz Volcano Engine Doubao, que admite síntesis de transmisión, múltiples voces, ajuste de velocidad/tono/volumen, filtrado Markdown y lectura de fórmulas LaTeX. Utilice esta habilidad cuando el usuario necesite convertir texto a voz, generar lectura de audio, doblaje, narración, transmisión o mencione "texto a voz", "TTS", "síntesis de voz", "lectura", "doblaje".
