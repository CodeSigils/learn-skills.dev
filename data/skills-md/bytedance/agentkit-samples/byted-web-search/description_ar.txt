استخدم واجهة برمجة تطبيقات Volcano Engine Fusion Information Search لعمليات البحث على الويب، وإرجاع نتائج الويب أو الصور المناسبة لاستخدام الذكاء الاصطناعي. استخدمها عندما يحتاج المستخدمون إلى البحث عن معلومات عبر الإنترنت، أو تأكيد آخر الأخبار، أو البحث عن المقالات، أو إدخالات الموسوعات، أو الإعلانات، أو السياسات، أو الأسعار، أو تحديثات المنتجات، أو المواقع الرسمية أو التوثيقية، أو العثور على روابط المصدر، أو التحقق من الادعاءات، أو مقارنة البيانات عبر مواقع الويب، أو تقييد عمليات البحث على مواقع محددة، أو البحث عن الصور أو الرسوم التوضيحية أو الصور ذات الصلة بالموضوع. تتضمن العبارات الشائعة "ابحث" أو "ابحث عن" أو "تحقق مني" أو "أي آخر الأخبار" أو "أعطني الرابط الرسمي" أو "أكد ما إذا كان صحيحًا" أو "ابحث عن المصدر" أو "ابحث عن بعض الصور" أو "ابحث عن الصور ذات الصلة". حتى لو لم يقل المستخدم صراحةً "البحث على الويب"، قم بإعطاء الأولوية لهذه المهارة عندما تعتمد المهمة على الحقائق في الوقت الفعلي، أو التوقيت المناسب، أو الاستشهاد بالمصدر. يدعم كلاً من طرق المصادقة API Key وAK/SK.
