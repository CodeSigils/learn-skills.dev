استخدم Volcano Engine Fusion Info Search API لعمليات البحث المتصلة بالويب، وإرجاع نتائج الويب أو الصور المحسنة لاستخدام الذكاء الاصطناعي. استخدمها عندما يحتاج المستخدمون إلى البحث عن معلومات عبر الإنترنت، أو تأكيد آخر التحديثات، أو البحث عن الأخبار، أو الإدخالات الموسوعية، أو الإعلانات، أو السياسات، أو الأسعار، أو تطورات المنتجات، أو العثور على مواقع رسمية أو وثائقية، أو تحديد موقع روابط المصدر، أو التحقق من الادعاءات، أو مقارنة البيانات عبر المواقع، أو تقييد عمليات البحث على مواقع محددة، أو العثور على صور أو رسوم توضيحية أو صور ذات صلة بالموضوع. تتضمن عبارات المستخدم الشائعة "ابحث" أو "ابحث عن" أو "تحقق" أو "أي آخر الأخبار" أو "أعطني الرابط الرسمي" أو "أكد ما إذا كان صحيحًا" أو "ابحث عن المصدر" أو "ابحث عن الصور" أو "ابحث عن الصور ذات الصلة". حتى لو لم يذكر المستخدمون صراحةً "البحث على الويب"، قم بإعطاء الأولوية لهذه المهارة عندما تعتمد المهمة على الحقائق عبر الإنترنت أو التوقيت المناسب أو الاستشهادات بالمصادر. يدعم كلاً من مفتاح API ومصادقة AK/SK.
