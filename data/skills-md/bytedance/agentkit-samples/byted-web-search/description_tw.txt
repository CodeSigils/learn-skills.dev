使用 Volcano Engine Fusion 資訊搜尋 API 進行網路連線搜索，傳回適合 AI 使用的網路或影像結果。當使用者需要在線查找資料、確認最新資訊、搜尋新聞、百科全書條目、公告、政策、價格、產品更新、檢查官方或文件網站、查找來源連結、驗證聲明、比較不同網站的聲明、將搜尋限制在特定網站或需要圖像搜尋、插圖或特定主題圖像時。常見的表達包括「查找」、「搜尋」、「檢查我」、「任何最新消息」、「給我官方連結」、「確認是否屬實」、「查找來源」、「搜尋一些圖像」、「尋找相關圖像」。即使用戶沒有明確地說“網路搜尋”，只要任務依賴線上事實、及時性或來源參考，就優先考慮這項技能。支援API Key和AK/SK兩種認證方式。
