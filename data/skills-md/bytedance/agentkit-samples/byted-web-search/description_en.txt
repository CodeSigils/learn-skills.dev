Use the Volcano Engine Fusion Search API to perform web searches and return web pages or images suitable for AI use. Use it when the user needs to look up information online, confirm the latest updates, search for news, encyclopedia entries, announcements, policies, prices, product developments, check official or documentation sites, find source links, verify claims, compare information across different sites, limit searches to specific sites, or search for images, illustrations, or image results on a topic. Common expressions include “look up,” “search,” “help me check,” “is there any latest news,” “give me the official website link,” “confirm if it’s true,” “find the source,” “search for some images,” “find related images.” Even if the user does not explicitly say “web search,” prioritize this skill whenever the task relies on online facts, timeliness, or source citation. Supports both API Key and AK/SK authentication methods.
