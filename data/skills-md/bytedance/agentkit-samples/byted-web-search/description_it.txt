Utilizza l'API Volcano Engine Fusion Info Search per ricerche connesse al Web, restituendo risultati Web o immagini ottimizzati per l'utilizzo dell'intelligenza artificiale. Impiegatelo quando gli utenti hanno bisogno di cercare informazioni online, confermare gli ultimi aggiornamenti, cercare notizie, voci enciclopediche, annunci, politiche, prezzi, sviluppi di prodotti, trovare siti ufficiali o di documentazione, individuare collegamenti alle fonti, verificare affermazioni, confrontare dichiarazioni tra siti, limitare le ricerche a siti specifici o trovare immagini, illustrazioni o immagini correlate ad argomenti. Le frasi più comuni degli utenti includono "cerca", "cerca", "controlla", "qualsiasi ultima notizia", ​​"dammi il collegamento ufficiale", "conferma se è vero", "trova la fonte", "cerca immagini" o "trova immagini correlate". Anche se gli utenti non dicono esplicitamente "ricerca sul Web", dai la priorità a questa abilità ogni volta che l'attività si basa su fatti online, tempestività o citazioni di fonti. Supporta sia la chiave API che l'autenticazione AK/SK.
