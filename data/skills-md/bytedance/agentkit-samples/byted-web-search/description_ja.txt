Web 接続検索には Volcano Engine Fusion Info Search API を使用し、AI での使用に最適化された Web または画像の結果を返します。ユーザーがオンラインで情報を検索する、最新の更新を確認する、ニュース、百科事典の項目、発表、ポリシー、価格、製品開発を検索する、公式サイトまたはドキュメント サイトを検索する、ソース リンクを見つける、主張を検証する、サイト間で記述を比較する、検索を特定のサイトに制限する、または画像、イラスト、またはトピック関連の写真を検索する必要がある場合に使用します。ユーザーの一般的なフレーズには、「調べて」、「検索して」、「チェックして」、「最新ニュースがあれば」、「公式リンクを教えて」、「本当かどうか確認して」、「ソースを見つけて」、「画像を検索して」、「関連する写真を見つけて」などがあります。ユーザーが明示的に「ウェブ検索」と言わなくても、タスクがオンラインの事実、適時性、またはソースの引用に依存する場合は常にこのスキルを優先してください。 API キーと AK/SK 認証の両方をサポートします。
