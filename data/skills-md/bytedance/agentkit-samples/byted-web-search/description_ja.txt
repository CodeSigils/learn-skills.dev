Web 検索には Volcano Engine Fusion Information Search API を使用し、AI での使用に適した Web ページまたは画像を返します。ユーザーが最新情報の検索、最新ニュースの確認、百科事典の項目の検索、発表、ポリシー、価格、製品の更新、公式サイトまたはドキュメント サイト、ソース リンク、主張の確認、ソースの比較、特定のサイトへの絞り込み検索、または画像の検索を行う必要がある場合に使用します。一般的なフレーズには、「調べてください」、「検索してください」、「調べてください」、「最新ニュースがあれば」、「公式リンクを教えてください」、「本当かどうか確認してください」、「ソースを見つけてください」、「画像を検索してください」、または「関連画像を見つけてください」などがあります。ユーザーが明示的に「ウェブ検索」と言っていなくても、タスクがオンラインの事実、適時性、または出典の引用に依存する場合には、このスキルを優先してください。 API キーと AK/SK 認証の両方をサポートします。
