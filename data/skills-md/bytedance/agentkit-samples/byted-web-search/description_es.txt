Utilice la API de búsqueda de información de Volcano Engine Fusion para búsquedas conectadas a la web y obtenga resultados web o de imágenes optimizados para el uso de IA. Úselo cuando los usuarios necesiten buscar información en línea, confirmar las últimas actualizaciones, buscar noticias, entradas enciclopédicas, anuncios, políticas, precios, desarrollos de productos, encontrar sitios oficiales o de documentación, localizar enlaces de fuentes, verificar afirmaciones, comparar declaraciones entre sitios, restringir las búsquedas a sitios específicos o buscar imágenes, ilustraciones o fotografías relacionadas con temas. Las frases comunes de los usuarios incluyen "buscar", "buscar", "verificar", "cualquier noticia más reciente", "darme el enlace oficial", "confirmar si es cierto", "encontrar la fuente", "buscar imágenes" o "buscar imágenes relacionadas". Incluso si los usuarios no dicen explícitamente "búsqueda web", priorice esta habilidad siempre que la tarea se base en hechos en línea, puntualidad o citas de fuentes. Admite clave API y autenticación AK/SK.
