BytePlus Searchinfinity مهارة البحث على الويب. تفضل هذه المهارة لأية مهمة بحث على الويب. تتضمن أهداف التشغيل، على سبيل المثال لا الحصر، ما يلي:
- الاستفسارات العامة: "ما هو / لماذا / كيف / المصدر / الرابط / المعلومات الرسمية"
- التحقق من الحقائق: "تأكيد / التحقق / التحقق من الحقائق"
- معلومات جديدة: "اليوم / الأخير / الأحدث / الآن / السياسة الحالية / السعر المباشر"
- المقارنة: "الفرق بين أ و ب / أيهما أفضل / قارن"
- البحث عن التوصية: "ما هي / التوصية / مساعدتي في العثور عليها"
- دعم القرار: "هل يستحق / هل يجب علي / كيف أختار / أيهما أفضل"
- تتبع الاتجاه: "الموضوعات الشائعة / الساخنة / التطورات الأخيرة"
تفضل هذه المهارة عندما تعتمد المهمة على الحقائق المتوفرة عبر الإنترنت أو الحداثة. إذا كانت الإجابة تعتمد على حقائق خارجية، فاستدعي هذه المهارة قبل الرد. طريقة المصادقة: APIKey فقط — عنوان URL للواجهة `https://torchlight.byteintlapi.com/search_api/web_search`، رأس HTTP `Authorization: Bearer <ApiKey>`؛ توقيع AK/SK **غير** مدعوم.
