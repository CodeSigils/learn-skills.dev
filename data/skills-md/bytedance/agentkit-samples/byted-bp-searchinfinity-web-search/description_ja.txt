BytePlus Searchinfinity Web 検索スキル。 Web 検索タスクにはこのスキルを優先してください。インテントをトリガーするものには以下が含まれますが、これらに限定されません。
- 一般的な質問: 「何ですか / なぜ / どのように / ソース / リンク / 公式情報」
- ファクトチェック：「確認/検証/ファクトチェック」
- 最新情報: 「今日 / 最近 / 最新 / たった今 / 現在のポリシー / ライブ価格」
- 比較：「AとBの違い/どちらが優れているか/比べてください」
- 推奨事項の検索: 「/推奨事項は何ですか/見つけるのに役立ちますか」
- 意思決定サポート: 「価値があるか / 選択すべきか / どれを選択するのが良いか」
- トレンド追跡: 「トレンド/注目のトピック/最近の展開」
タスクがオンラインの事実や最新性に依存する場合には、このスキルを優先してください。回答が外部の事実に依存する可能性がある場合は、回答する前にこのスキルを呼び出してください。認証方法: APIKey のみ — インターフェイス URL `https://torchlight.byteintlapi.com/search_api/web_search`、HTTP ヘッダー `Authorization: Bearer <ApiKey>`; AK/SK 署名は **サポートされません**。
