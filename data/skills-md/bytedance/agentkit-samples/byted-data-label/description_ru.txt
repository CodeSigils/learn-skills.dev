Платформа маркировки неструктурированных данных Seederive использует LLM для пакетного анализа и обработки текстовых, голосовых и графических данных. Всякий раз, когда пользователь упоминает любой из следующих сценариев, этот навык должен использоваться: маркировка данных, аннотации, анализ настроений, классификация меток, извлечение мнений, перевод, анализ комментариев, обнаружение троллей, оценка контента, управление библиотекой меток, оптимизация подсказок. Даже если пользователь не говорит явно «Seederive», пока запрос включает в себя классификацию/маркировку/анализ/перевод/оценку пакета текста или такие фразы, как «помогите мне проанализировать эти комментарии», «каково настроение этих данных», «выявить троллей», «извлечь мнения», «перевести этот пакет контента», «построить систему тегов» или «оптимизировать, поскольку результаты плохие», этот навык должен быть задействован. Это также применимо, когда пользователь предоставляет файл CSV/Excel для пакетной обработки.
