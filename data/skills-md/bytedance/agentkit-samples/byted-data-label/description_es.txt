La plataforma de etiquetado de datos no estructurados Seederive utiliza LLM para el análisis por lotes y el procesamiento de datos de texto, voz e imágenes. Esta habilidad debe usarse cuando los usuarios mencionan cualquiera de los siguientes escenarios: etiquetado de datos, anotación, análisis de sentimientos, clasificación de etiquetas, extracción de opiniones, traducción, análisis de reseñas, detección de bots, puntuación de contenido, gestión de biblioteca de etiquetas, optimización de mensajes. Incluso si los usuarios no mencionan directamente "Seederive", siempre que implique clasificar/etiquetar/analizar/traducir/puntuar un lote de texto, o frases como "ayúdame a analizar estas reseñas", "cuál es el sentimiento de estos datos", "detectar bots", "extraer opiniones", "traducir este contenido", "crear un sistema de etiquetas", "optimizar los resultados", etc., esta habilidad debería activarse. También se aplica cuando los usuarios proporcionan archivos CSV/Excel que requieren procesamiento por lotes.
