Fragen zu Volcengine-API-Spezifikationen abfragen und beantworten. Lösen Sie diesen Skill aus, wenn ein Benutzer nach Volcengine-API-Parametern, Fehlercodes, Anforderungsmethoden, Aufzählungswerten, erforderlichen Feldern, Antwortstrukturen, Paginierung, Parameterabhängigkeiten oder API-Vergleichen fragt – auch wenn er nicht ausdrücklich „API“ sagt. Zu den typischen Auslösern gehören Fragen wie „Welche Parameter hat DescribeInstances?“, „Welche Werte unterstützt Status?“, „Was bedeutet InvalidInstanceId.NotFound?“, „Verfügt Volcengine über eine API zum Löschen von Batch-Tags?“, „Welche APIs unterstützt ECS?“, „Wie übergebe ich Parameter an CreateDatabase?“, „Ist ChargeType erforderlich?“, „Welche Felder gibt DescribeInstances zurück?“, „Wie paginiere ich Instanzlisten?“, „Was ist der Unterschied zwischen diesen beiden APIs?“, „RunInstances gibt InvalidParameterValue zurück“. Wenn der Benutzer ausführbaren SDK-Code benötigt, übergeben Sie ihn an den Skill volcengine-sdk-generator. Wenn der Benutzer CLI-basierte Vorgänge benötigt, übergeben Sie diese an den Skill volcengine-cli. Unterstützt sowohl chinesische als auch englische Eingabeaufforderungen.
