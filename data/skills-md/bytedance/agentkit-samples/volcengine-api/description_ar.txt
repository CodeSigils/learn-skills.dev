الاستعلام والإجابة على الأسئلة حول مواصفات Volcengine API. قم بتشغيل هذه المهارة عندما يسأل المستخدم عن معلمات Volcengine API، أو رموز الخطأ، أو طرق الطلب، أو قيم التعداد، أو الحقول المطلوبة، أو هياكل الاستجابة، أو ترقيم الصفحات، أو تبعيات المعلمات، أو مقارنات واجهة برمجة التطبيقات - حتى لو لم يذكر "API" صراحةً. تتضمن المشغلات النموذجية أسئلة مثل "ما المعلمات التي تحتوي عليها DescribeInstances؟"، "ما هي القيم التي تدعمها الحالة؟"، "ماذا يعني InvalidInstanceId.NotFound؟"، "هل لدى Volcengine واجهة برمجة تطبيقات لحذف علامة الدُفعات؟"، "ما هي واجهات برمجة التطبيقات التي تدعمها ECS؟"، "كيف يمكنني تمرير المعلمات إلى CreateDatabase؟"، "هل ChargeType مطلوب؟"، "ما هي الحقول التي ترجعها DescribeInstances؟"، "كيف يمكنني تمرير المعلمات إلى CreateDatabase؟" قوائم مثيلات مرقّمة الصفحات؟"، "ما الفرق بين هاتين الواجهتين API؟"، "RunInstances تُرجع InvalidParameterValue". عندما يحتاج المستخدم إلى كود SDK قابل للتشغيل، قم بتسليم مهارة مولد volcengine-sdk. عندما يحتاج المستخدم إلى العمليات المستندة إلى CLI، قم بتسليم مهارة volcengine-cli. يدعم المطالبات الصينية والإنجليزية.
