Запрашивайте и отвечайте на вопросы о спецификациях API Volcengine. Активируйте этот навык всякий раз, когда пользователь спрашивает о параметрах API Volcengine, кодах ошибок, методах запроса, значениях перечислений, обязательных полях, структурах ответов, нумерации страниц, зависимостях параметров или сравнениях API — даже если они явно не говорят «API». Типичные триггеры включают такие вопросы, как «Какие параметры имеет DescribeInstances?», «Какие значения поддерживает Status?», «Что означает InvalidInstanceId.NotFound?», «Есть ли в Volcengine API для пакетного удаления тегов?», «Какие API поддерживает ECS?», «Как передать параметры в CreateDatabase?», «Требуется ли ChargeType?», «Какие поля возвращает DescribeInstances?», «Как разбить списки экземпляров?», «В чем разница между этими двумя API?», «RunInstances возвращает InvalidParameterValue». Когда пользователю нужен работоспособный код SDK, передайте его навыку volcengine-sdk-generator. Когда пользователю нужны операции на основе CLI, передайте его навыку volcengine-cli. Поддерживает подсказки на китайском и английском языках.
