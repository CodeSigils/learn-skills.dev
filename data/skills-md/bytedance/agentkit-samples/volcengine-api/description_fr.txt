Interrogez et répondez aux questions sur les spécifications de l'API Volcengine. Déclenchez cette compétence chaque fois qu'un utilisateur pose des questions sur les paramètres de l'API Volcengine, les codes d'erreur, les méthodes de requête, les valeurs d'énumération, les champs obligatoires, les structures de réponse, la pagination, les dépendances des paramètres ou les comparaisons d'API - même s'ils ne disent pas explicitement « API ». Les déclencheurs typiques incluent des questions telles que « Quels sont les paramètres de DescribeInstances ? », « Quelles valeurs sont prises en charge par Status ? », « Que signifie InvalidInstanceId.NotFound ? » lists?", "Quelle est la différence entre ces deux API ?", "RunInstances renvoie InvalidParameterValue". Lorsque l'utilisateur a besoin d'un code SDK exécutable, transmettez-le à la compétence volcengine-sdk-generator. Lorsque l'utilisateur a besoin d'opérations basées sur CLI, transférez-le à la compétence volcengine-cli. Prend en charge les invites en chinois et en anglais.
