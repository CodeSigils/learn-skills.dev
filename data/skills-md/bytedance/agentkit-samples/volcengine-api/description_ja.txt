Volcengine API 仕様に関する質問と回答。ユーザーが Volcengine API パラメーター、エラー コード、リクエスト メソッド、列挙値、必須フィールド、応答構造、ページネーション、パラメーターの依存関係、または API の比較について質問するたびに、たとえ「API」と明示的に言わなくても、このスキルをトリガーします。一般的なトリガーには、「DescribeInstances にはどのようなパラメータがありますか?」、「Status はどのような値をサポートしますか?」、「InvalidInstanceId.NotFound は何を意味しますか?」、「Volcengine にはバッチ タグ削除 API がありますか?」、「ECS はどの API をサポートしますか?」、「CreateDatabase にパラメータを渡すにはどうすればよいですか?」、「ChargeType は必要ですか?」、「DescribeInstances はどのフィールドを返しますか?」などの質問が含まれます。 「インスタンス リストをページ分割するにはどうすればよいですか?」、「これら 2 つの API の違いは何ですか?」、「RunInstances は InvalidParameterValue を返します」。ユーザーが実行可能な SDK コードが必要な場合は、volcengine-sdk-generator スキルに引き渡します。ユーザーが CLI ベースの操作を必要とする場合は、volcengine-cli スキルに引き渡します。中国語と英語の両方のプロンプトをサポートします。
