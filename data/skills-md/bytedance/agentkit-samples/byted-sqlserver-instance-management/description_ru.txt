Используйте SQL-сервер Volcano Engine RDS. Используйте этот навык, когда пользователям необходимо выполнять управление экземплярами, связанными с RDS SQL Server, операции с базами данных, управление учетными записями и задачи эксплуатации и обслуживания. Вы можете напрямую вызвать скрипт uv run ./scripts/call_rds_mssql.py, чтобы получить результаты в реальном времени.
