عند استخدام Volcano Engine RDS SQL Server، يجب على المستخدمين استخدام هذه المهارات عندما يحتاجون إلى تنفيذ إدارة مثيلات RDS SQL Server ذات الصلة وعمليات قاعدة البيانات وإدارة الحساب ومهام التشغيل والصيانة. يمكنهم الاتصال مباشرة بالبرنامج النصي uv run ./scripts/call_rds_mssql.py للحصول على نتائج في الوقت الفعلي.
