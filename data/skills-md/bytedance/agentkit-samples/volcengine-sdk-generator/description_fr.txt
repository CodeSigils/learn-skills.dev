Générez du code SDK Volcengine complet et exécutable et fournissez des conseils de configuration du SDK. Prend en charge Go, Python, PHP, Java et Node.js. Déclenchez cette compétence chaque fois que l'utilisateur souhaite appeler une API Volcengine, générer du code SDK Volcengine ou décrire une opération cloud sur Volcengine (par exemple, "lister les instances ECS", "créer un VPC sur Volcengine", "interroger la facturation Volcengine avec Python"). Déclenchez également lorsque l'utilisateur pose des questions sur la configuration et les meilleures pratiques du SDK Volcengine - y compris la nouvelle tentative, le délai d'attente, l'authentification (AK/SK, STS, AssumeRole), le proxy, le regroupement de connexions, SSL, le mode débogage et la gestion des erreurs (par exemple, "comment configurer la nouvelle tentative pour le SDK Volcengine Go", "configuration du proxy du SDK Volcengine Python"). Déclenchez lorsque l'utilisateur mentionne les noms de services Volcengine tels que ECS, VPC, CDN, CLB, RDS, Redis, Kafka, facturation, IAM, DNS avec génération de code ou intention d'utilisation du SDK. Lorsque l'utilisateur n'a besoin que de requêtes de spécification d'API (paramètres, codes d'erreur, structures de réponse), confiez-le à la compétence volcengine-api. Lorsque l'utilisateur a besoin d'opérations basées sur CLI, transférez-le à la compétence volcengine-cli. Prend en charge les invites en chinois et en anglais.
