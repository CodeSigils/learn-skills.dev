產生完整、可運行的Volcengine SDK程式碼並提供SDK配置指導。支援 Go、Python、PHP、Java 和 Node.js。每當使用者想要呼叫 Volcengine API、產生 Volcengine SDK 程式碼或描述 Volcengine 上的雲端操作（例如「列出 ECS 實例」、「在 Volcengine 上建立 VPC」、「使用 Python 查詢 Volcengine 計費」）時，觸發此技能。當使用者詢問 Volcengine SDK 配置和最佳實踐時也會觸發 - 包括重試、逾時、身份驗證（AK/SK、STS、AssumeRole）、代理、連接池、SSL、調試模式和錯誤處理（例如，“如何為 Volcengine Go SDK 配置重試”、“volcengine python sdk 代理設置”）。當使用者在程式碼產生或 SDK 使用意圖中提及 ECS、VPC、CDN、CLB、RDS、Redis、Kafka、計費、IAM、DNS 等 Volcengine 服務名稱時觸發。當使用者只需要 API 規範查詢（參數、錯誤代碼、回應結構）時，請交給 volcengine-api 技能。當使用者需要基於 CLI 的操作時，請交給 volcengine-cli 技能。支援中英文提示。
