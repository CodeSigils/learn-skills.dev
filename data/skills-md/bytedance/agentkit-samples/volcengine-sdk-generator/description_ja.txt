完全で実行可能な Volcengine SDK コードを生成し、SDK 構成ガイダンスを提供します。 Go、Python、PHP、Java、Node.js をサポートします。ユーザーが Volcengine API を呼び出す場合、Volcengine SDK コードを生成する場合、または Volcengine でのクラウド操作を説明する場合 (例: 「ECS インスタンスのリスト」、「Volcengine での VPC の作成」、「Python を使用した Volcengine の請求のクエリ」)、このスキルをトリガーします。また、ユーザーが、再試行、タイムアウト、認証 (AK/SK、STS、AssumeRole)、プロキシ、接続プーリング、SSL、デバッグ モード、エラー処理などの Volcengine SDK の設定とベスト プラクティスについて質問したときにもトリガーされます (例: 「Volcengine Go SDK の再試行の設定方法」、「volcengine Python SDK プロキシのセットアップ」)。コード生成または SDK の使用目的で、ユーザーが ECS、VPC、CDN、CLB、RDS、Redis、Kafka、課金、IAM、DNS などの Volcengine サービス名に言及するとトリガーされます。ユーザーが API 仕様クエリ (パラメーター、エラー コード、応答構造) のみを必要とする場合は、volcengine-api スキルに引き渡します。ユーザーが CLI ベースの操作を必要とする場合は、volcengine-cli スキルに引き渡します。中国語と英語の両方のプロンプトをサポートします。
