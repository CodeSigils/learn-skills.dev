قم بإنشاء كود Volcengine SDK كامل وقابل للتشغيل وتوفير إرشادات تكوين SDK. يدعم Go، وPython، وPHP، وJava، وNode.js. قم بتشغيل هذه المهارة عندما يريد المستخدم استدعاء Volcengine API، أو إنشاء رمز Volcengine SDK، أو وصف عملية سحابية على Volcengine (على سبيل المثال، "قائمة مثيلات ECS"، "إنشاء VPC على Volcengine"، "الاستعلام عن فواتير Volcengine باستخدام Python"). يتم التشغيل أيضًا عندما يسأل المستخدم عن تكوين Volcengine SDK وأفضل الممارسات - بما في ذلك إعادة المحاولة والمهلة والمصادقة (AK/SK وSTS وAssumeRole) والوكيل وتجميع الاتصالات وSSL ووضع التصحيح ومعالجة الأخطاء (على سبيل المثال، "كيفية تكوين إعادة المحاولة لـ Volcengine Go SDK"، "إعداد وكيل volcengine python sdk"). يتم التشغيل عندما يذكر المستخدم أسماء خدمات Volcengine مثل ECS، أو VPC، أو CDN، أو CLB، أو RDS، أو Redis، أو Kafka، أو Billing، أو IAM، أو DNS مع إنشاء التعليمات البرمجية أو غرض استخدام SDK. عندما يحتاج المستخدم فقط إلى استعلامات مواصفات واجهة برمجة التطبيقات (المعلمات، ورموز الخطأ، وهياكل الاستجابة)، قم بتسليم مهارة volcengine-api. عندما يحتاج المستخدم إلى العمليات المستندة إلى CLI، قم بتسليم مهارة volcengine-cli. يدعم المطالبات الصينية والإنجليزية.
