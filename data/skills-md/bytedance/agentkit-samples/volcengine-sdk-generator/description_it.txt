Genera codice SDK Volcengine completo ed eseguibile e fornisce indicazioni sulla configurazione dell'SDK. Supporta Go, Python, PHP, Java e Node.js. Attiva questa abilità ogni volta che l'utente desidera chiamare un'API Volcengine, generare codice SDK Volcengine o descrivere un'operazione cloud su Volcengine (ad esempio, "elenca istanze ECS", "crea un VPC su Volcengine", "interroga la fatturazione Volcengine con Python"). Si attiva anche quando l'utente chiede informazioni sulla configurazione dell'SDK di Volcengine e sulle migliori pratiche, inclusi tentativi, timeout, autenticazione (AK/SK, STS, AssumeRole), proxy, pool di connessioni, SSL, modalità di debug e gestione degli errori (ad esempio, "come configurare i tentativi per Volcengine Go SDK", "configurazione del proxy volcengine python sdk"). Si attiva quando l'utente menziona nomi di servizi Volcengine come ECS, VPC, CDN, CLB, RDS, Redis, Kafka, fatturazione, IAM, DNS con generazione di codice o intento di utilizzo dell'SDK. Quando l'utente necessita solo di query relative alle specifiche API (parametri, codici di errore, strutture di risposta), passa alla competenza volcengine-api. Quando l'utente necessita di operazioni basate sulla CLI, passa alla competenza volcengine-cli. Supporta sia i prompt in cinese che in inglese.
