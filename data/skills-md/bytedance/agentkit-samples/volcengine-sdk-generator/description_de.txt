Generieren Sie vollständigen, ausführbaren Volcengine SDK-Code und stellen Sie Anleitungen zur SDK-Konfiguration bereit. Unterstützt Go, Python, PHP, Java und Node.js. Lösen Sie diesen Skill immer dann aus, wenn der Benutzer eine Volcengine-API aufrufen, Volcengine-SDK-Code generieren oder einen Cloud-Vorgang auf Volcengine beschreiben möchte (z. B. „ECS-Instanzen auflisten“, „eine VPC auf Volcengine erstellen“, „Volcengine-Abrechnung mit Python abfragen“). Wird auch ausgelöst, wenn der Benutzer nach der Volcengine SDK-Konfiguration und Best Practices fragt – einschließlich Wiederholung, Zeitüberschreitung, Authentifizierung (AK/SK, STS, AssumeRole), Proxy, Verbindungspooling, SSL, Debug-Modus und Fehlerbehandlung (z. B. „So konfigurieren Sie Wiederholungen für Volcengine Go SDK“, „Volcengine Python SDK-Proxy-Setup“). Wird ausgelöst, wenn der Benutzer Volcengine-Dienstnamen wie ECS, VPC, CDN, CLB, RDS, Redis, Kafka, Billing, IAM, DNS mit Codegenerierung oder SDK-Nutzungsabsicht erwähnt. Wenn der Benutzer nur API-Spezifikationsabfragen (Parameter, Fehlercodes, Antwortstrukturen) benötigt, übergeben Sie diese an den volcengine-api-Skill. Wenn der Benutzer CLI-basierte Vorgänge benötigt, übergeben Sie diese an den Skill volcengine-cli. Unterstützt sowohl chinesische als auch englische Eingabeaufforderungen.
