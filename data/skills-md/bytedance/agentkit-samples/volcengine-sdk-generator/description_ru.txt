Сгенерируйте полный работоспособный код Volcengine SDK и предоставьте рекомендации по настройке SDK. Поддерживает Go, Python, PHP, Java и Node.js. Активируйте этот навык всякий раз, когда пользователь хочет вызвать API Volcengine, сгенерировать код Volcengine SDK или описать облачную операцию на Volcengine (например, «составить список экземпляров ECS», «создать VPC на Volcengine», «запросить выставление счетов Volcengine с помощью Python»). Также срабатывает, когда пользователь спрашивает о конфигурации Volcengine SDK и лучших методах, включая повторную попытку, тайм-аут, аутентификацию (AK/SK, STS, AssumeRole), прокси, пул соединений, SSL, режим отладки и обработку ошибок (например, «как настроить повторную попытку для Volcengine Go SDK», «настройка прокси-сервера volcengine python sdk»). Срабатывает, когда пользователь упоминает имена сервисов Volcengine, такие как ECS, VPC, CDN, CLB, RDS, Redis, Kafka, биллинг, IAM, DNS с генерацией кода или намерением использования SDK. Если пользователю нужны только запросы спецификации API (параметры, коды ошибок, структуры ответов), передайте его навыку volcengine-api. Когда пользователю нужны операции на основе CLI, передайте его навыку volcengine-cli. Поддерживает подсказки на китайском и английском языках.
