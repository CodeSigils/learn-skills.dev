Genere código SDK de Volcengine completo y ejecutable y proporcione orientación para la configuración del SDK. Admite Go, Python, PHP, Java y Node.js. Active esta habilidad siempre que el usuario quiera llamar a una API de Volcengine, generar código SDK de Volcengine o describir una operación en la nube en Volcengine (por ejemplo, "enumerar instancias de ECS", "crear una VPC en Volcengine", "consultar facturación de Volcengine con Python"). También se activa cuando el usuario pregunta sobre la configuración y las mejores prácticas del SDK de Volcengine, incluido el reintento, el tiempo de espera, la autenticación (AK/SK, STS, AssumeRole), el proxy, la agrupación de conexiones, SSL, el modo de depuración y el manejo de errores (por ejemplo, "cómo configurar el reintento para el SDK de Volcengine Go", "configuración del proxy del SDK de Python de Volcengine"). Se activa cuando el usuario menciona nombres de servicios Volcengine como ECS, VPC, CDN, CLB, RDS, Redis, Kafka, facturación, IAM, DNS con generación de código o intención de uso de SDK. Cuando el usuario solo necesita consultas de especificación de API (parámetros, códigos de error, estructuras de respuesta), entréguelas a la habilidad volcengine-api. Cuando el usuario necesite operaciones basadas en CLI, transfiéralas a la habilidad volcengine-cli. Admite indicaciones en chino e inglés.
