Administre espacios de trabajo, sucursales, consultas SQL, migraciones, funciones perimetrales, almacenamiento y generación de tipos de TypeScript de Volcengine Supabase a través de una CLI local. Ejecute uv run ./scripts/call_volcengine_supabase.py para obtener resultados en tiempo real. Utilice esta habilidad cuando el usuario necesite crear, inspeccionar o administrar recursos de Volcengine Supabase (espacios de trabajo, bases de datos, sucursales, funciones perimetrales, almacenamiento, claves API o generación de tipos). NO lo use para discusiones generales sobre bases de datos, servicios que no sean de Supabase o codificación pura del lado del cliente no relacionada con la administración de backend de Supabase.
