ローカル CLI を介して、Volcengine Supabase ワークスペース、ブランチ、SQL クエリ、移行、Edge Functions、ストレージ、TypeScript 型生成を管理します。 uv run ./scripts/call_volcengine_supabase.py を実行して、リアルタイムの結果を取得します。ユーザーが Volcengine Supabase リソース (ワークスペース、データベース、ブランチ、エッジ機能、ストレージ、API キー、または型生成) を作成、検査、または管理する必要がある場合は、このスキルを使用します。一般的なデータベースの議論、Supabase 以外のサービス、または Supabase バックエンド管理に関係のない純粋なクライアント側のコーディングには使用しないでください。
