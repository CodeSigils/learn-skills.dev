Gestisci spazi di lavoro, rami, query SQL, migrazioni, funzioni Edge, archiviazione e generazione di tipi TypeScript di Volcengine Supabase tramite una CLI locale. Esegui uv run ./scripts/call_volcengine_supabase.py per ottenere risultati in tempo reale. Utilizza questa competenza quando l'utente deve creare, ispezionare o gestire le risorse Volcengine Supabase (spazi di lavoro, database, rami, funzioni Edge, archiviazione, chiavi API o generazione di tipi). NON utilizzarlo per discussioni generali sui database, servizi non Supabase o pura codifica lato client non correlata alla gestione del backend Supabase.
