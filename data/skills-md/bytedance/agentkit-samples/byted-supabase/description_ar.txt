إدارة مساحات عمل Volcengine Supabase والفروع واستعلامات SQL وعمليات الترحيل ووظائف الحافة والتخزين وإنشاء نوع TypeScript عبر واجهة سطر الأوامر المحلية. قم بتشغيل uv run ./scripts/call_volcengine_supabase.py للحصول على نتائج في الوقت الفعلي. استخدم هذه المهارة عندما يحتاج المستخدم إلى إنشاء موارد Volcengine Supabase أو فحصها أو إدارتها (مساحات العمل أو قواعد البيانات أو الفروع أو وظائف الحافة أو التخزين أو مفاتيح API أو إنشاء النوع). لا تستخدمه في مناقشات قاعدة البيانات العامة، أو الخدمات غير المتعلقة بـ Supabase، أو الترميز النقي من جانب العميل الذي لا علاقة له بإدارة الواجهة الخلفية لـ Supabase.
