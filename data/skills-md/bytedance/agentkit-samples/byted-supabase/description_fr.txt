Gérez les espaces de travail, les branches, les requêtes SQL, les migrations, les fonctions Edge, le stockage et la génération de types TypeScript de Volcengine Supabase via une CLI locale. Exécutez uv run ./scripts/call_volcengine_supabase.py pour obtenir des résultats en temps réel. Utilisez cette compétence lorsque l'utilisateur doit créer, inspecter ou gérer des ressources Volcengine Supabase (espaces de travail, bases de données, branches, fonctions Edge, stockage, clés API ou génération de type). Ne l'utilisez PAS pour des discussions générales sur la base de données, des services non Supabase ou du codage purement côté client sans rapport avec la gestion du backend Supabase.
