Управляйте рабочими пространствами Volcengine Supabase, ветвями, SQL-запросами, миграциями, пограничными функциями, хранилищем и генерацией типов TypeScript через локальный интерфейс командной строки. Используйте этот навык, когда пользователю необходимо создавать, проверять или управлять ресурсами Volcengine Supabase (рабочими пространствами, базами данных, ветвями, пограничными функциями, хранилищем, ключами API или генерацией типов). НЕ используйте его для общих обсуждений баз данных, служб, не относящихся к Supabase, или чистого кодирования на стороне клиента, не связанного с управлением серверной частью Supabase.
