Herramienta de base de datos simplificada para consultas de metadatos, ejecución de SQL, nl2sql y otros escenarios con instancias RDS de Volcano Engine y bases de datos de creación propia. Utilice esta habilidad cuando los usuarios necesiten consultar estructuras de tablas de instancias de Volcano Engine RDS y bases de datos de creación propia, ver datos, ejecutar SQL o convertir lenguaje natural a SQL.
