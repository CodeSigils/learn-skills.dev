Per la gestione dei metadati, l'analisi dei dati, le modifiche allo sviluppo, la diagnostica delle operazioni e le ispezioni dei database Volcengine (MySQL, veDB-MySQL, PostgreSQL, SQL Server, MongoDB, Redis) e dei database autocostruiti della rete pubblica (serie MySQL e PostgreSQL). Copre query su elenchi di istanze, query su elenchi di database sotto istanze, query su elenchi di tabelle, query su struttura di tabella, query di dati, report di analisi e visualizzazione dei dati (inclusa l'analisi di origini dati incrociate/analisi congiunta di file), governance dei dati (inventario delle risorse/profilazione dei dati/qualità dei dati/identificazione dei dati sensibili), diagnostica di query lente, analisi di deadlock e attesa di blocco, risoluzione dei problemi di transazioni e sessioni attive, query di log di errori, analisi di tablespace, ispezioni di integrità, monitoraggio di query di metriche, applicazioni di ticket di modifica e altri scenari. Non supporta i database ByteCloud, come ByteRDS / ByteDoc / ByteRedis.
