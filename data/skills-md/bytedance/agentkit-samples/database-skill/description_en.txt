Used for metadata management, data analysis, development changes, operations diagnosis, and inspection of Volcengine databases (MySQL, veDB-MySQL, PostgreSQL, SQL Server, MongoDB, Redis) and public network self-built databases (MySQL and PostgreSQL series). Covers scenarios including instance list query, database list query under instances, table list query, table structure query, data query, data analysis and visualization reports (including cross-data source/file joint analysis), data governance (asset inventory/data profiling/data quality/sensitive data identification), slow query diagnosis, deadlock and lock wait analysis, transaction and active session troubleshooting, error log query, tablespace analysis, health inspection, monitoring metrics query, and change ticket application. Does not support ByteCloud databases, such as ByteRDS / ByteDoc / ByteRedis.
