Управление метаданными, анализ данных, изменения в разработке, диагностика эксплуатации и обслуживания, а также проверка баз данных Volcengine (MySQL, veDB-MySQL, PostgreSQL, SQL Server, MongoDB, Redis) и самостоятельно созданных общедоступных сетевых баз данных (серии MySQL и PostgreSQL). Охватывает запрос списка экземпляров, запрос списка базы данных под экземплярами, запрос списка таблиц, запрос структуры таблицы, запрос данных, анализ данных и отчеты по визуализации (включая совместный анализ источников данных/файлов), управление данными (инвентаризация активов/профилирование данных/качество данных/идентификация конфиденциальных данных), медленную диагностику запросов, анализ взаимоблокировки и ожидания блокировки, устранение неполадок транзакций и активных сеансов, запрос журнала ошибок, анализ табличного пространства, проверку работоспособности, запрос метрик мониторинга, применение заявки на изменение билета и другие сценарии. Не поддерживает базы данных ByteCloud, такие как ByteRDS/ByteDoc/ByteRedis.
