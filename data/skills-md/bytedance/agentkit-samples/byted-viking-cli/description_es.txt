Asistente de línea de comando oficial de Viking CLI: este CLI cubre la gestión de conjuntos de datos y la lectura/escritura/recuperación de datos para Volcano Engine VikingDB (base de datos vectorial)/Conocimiento (base de conocimientos)/Memoria (base de datos de memoria), y se puede utilizar para ampliar los límites de recuperación de conocimientos del Agente y mejorar las capacidades de memoria del Agente; Cuando los usuarios hagan preguntas sobre la base de conocimientos/base de datos vectorial, utilice esta habilidad; Cuando los usuarios necesiten operar una base de datos/base de conocimientos de vectores o recuperar información de una base de datos/base de conocimientos de vectores, utilice esta habilidad; Cuando los usuarios necesiten recuperación y almacenamiento de memoria, utilice esta habilidad.
