Assistant de ligne de commande officiel Viking CLI : cette CLI couvre la gestion des ensembles de données et la lecture/écriture/recherche de données pour Volcano Engine VikingDB (base de données vectorielle)/Connaissances (base de connaissances)/Mémoire (magasin de mémoire), et peut être utilisée pour étendre les limites de récupération de connaissances d'un agent et améliorer sa capacité de mémoire. Utilisez cette compétence lorsque les utilisateurs interrogent la base de données de connaissances/vecteurs ; utilisez-le lorsque vous devez opérer ou récupérer des informations à partir de la base de données de vecteurs/connaissances ; utilisez-le lorsque les utilisateurs ont besoin d'une récupération ou d'un stockage de mémoire.
