Официальный помощник командной строки Viking CLI: этот интерфейс командной строки охватывает управление наборами данных, чтение/запись и извлечение данных для Volcano Engine VikingDB (база данных векторов)/Knowledge (база знаний)/памяти (база памяти), которые можно использовать для расширения границ поиска знаний агента и расширения возможностей памяти агента; используйте этот навык, когда пользователи задают вопросы о базе знаний/базе данных векторов; использовать этот навык при работе с базой данных/базой знаний по векторам или при получении информации из базы данных/базы знаний по векторам; используйте этот навык, когда пользователям необходимо извлечение и хранение памяти.
