Создавайте и проверяйте длительные задачи оценки видеоматериалов. Используйте этот навык, когда пользователь хочет отправить видео на оценку, проверить существующий список задач по оценке видео или получить результат ранее созданной задачи по оценке видео. Этот навык не является навыком загрузки видео общего назначения, поскольку загрузка разрешена только как внутренний этап создания задачи. Для аутентификации используется ключ API, передаваемый как токен носителя авторизации.
