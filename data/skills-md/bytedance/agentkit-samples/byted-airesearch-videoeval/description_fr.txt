Créez et vérifiez des tâches d'évaluation de matériel vidéo de longue durée. Utilisez cette compétence lorsque l'utilisateur souhaite soumettre des vidéos pour évaluation, vérifier une liste de tâches d'évaluation vidéo existante ou récupérer le résultat d'une tâche d'évaluation vidéo précédemment créée. Cette compétence n'est pas une compétence de téléchargement de vidéo à usage général, car le téléchargement n'est autorisé qu'en tant qu'étape interne de création de tâche. L'authentification utilise une clé API transmise comme jeton du porteur d'autorisation.
