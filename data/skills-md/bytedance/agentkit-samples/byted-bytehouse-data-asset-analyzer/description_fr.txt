Basée sur ByteHouse MCP Server, la compétence de génération de catalogues d'actifs de données et d'analyse de lignage est utilisée pour obtenir des structures de tables de base de données, générer des catalogues d'actifs de données et analyser les relations sanguines entre les tables. Lorsque les utilisateurs ont besoin d'obtenir des structures de tables de la base de données ByteHouse, de générer des catalogues d'actifs de données et d'analyser les relations sanguines entre les tables, utilisez cette compétence.
