На основе сервера ByteHouse MCP он генерирует навыки для каталогизации активов данных и анализа происхождения, используемых для получения структур таблиц базы данных, создания каталогов активов данных и анализа связей происхождения между таблицами. Используйте этот навык, когда пользователям необходимо получить структуры таблиц базы данных ByteHouse, создать каталоги активов данных или проанализировать родственные связи между таблицами.
