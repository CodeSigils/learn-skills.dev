Utilizzando il server MCP ByteHouse, la capacità di generare un catalogo di risorse di dati e un'analisi di derivazione può recuperare strutture di tabelle di database, creare un catalogo di risorse di dati e analizzare la derivazione da tabella a tabella. Utilizza questa competenza quando è necessario ottenere strutture di tabelle del database ByteHouse, generare un catalogo di risorse di dati o analizzare la derivazione delle tabelle.
