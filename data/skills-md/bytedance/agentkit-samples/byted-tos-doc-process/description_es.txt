Genera URL prefirmadas para el procesamiento `doc-preview` de Bytedance TOS para obtener una vista previa y convertir documentos a PDF, imágenes (PNG/JPG) o HTML, y para exportar rangos de páginas. Úselo cuando el usuario necesite vista previa/conversión de documentos TOS, recuento/exportación de páginas o mencione los parámetros doc-preview, x-tos-process o x-tos-doc-*.
