Deep Research Agent System Community Edition, выполняющая многоэтапный итеративный поиск в Интернете и всесторонний анализ по сложным темам. Вариант использования: когда пользователям необходимо углубленное и тщательное исследование по конкретной теме, особенно при создании подробных аналитических отчетов на основе последней онлайн-информации. Поддерживает многораундовый итеративный поиск, интеллектуальную настройку направления поиска и создание комплексных аналитических отчетов. Этот навык представляет собой документ с описанием рабочего процесса без сценариев выполнения, основанный на навыке байтового веб-поиска для веб-поиска.
