Автономная фабрика программного обеспечения для одного линейного билета — планируйте с помощью интеллектуальной модели, слепо критикуйте и уточняйте план, комментируйте его в билете, реализуйте через субагента, открывайте атомарные составные запросы на запросы, наблюдайте за CI/проверкой до тех пор, пока его нельзя будет объединить, а затем объедините, когда пользователю будет дан зеленый свет. Используйте, когда пользователь хочет /фабрика, фабрика или полностью проехать один линейный билет из плана → PR → объединить.
