Utilisez cette compétence chaque fois que l'utilisateur souhaite créer un site Web ou une page de destination. Cela comprend : les pages de produits, les sites de portefeuille, les pages d'événements, les pages à venir, les pages de tarification, les sites de présentation de l'entreprise, les blogs personnels, les pages d'inscription, les pages de téléchargement d'applications et les pages de campagne. Se déclenche également lorsque : l'utilisateur dit 做个网站, 建个落地页, 做个产品页, 做个活动页, 做个个人主页. Si un site Web ou une page Web doit être créé, utilisez cette compétence.
