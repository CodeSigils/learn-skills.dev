Utilice esta habilidad cada vez que el usuario quiera crear un sitio web o una página de destino. Esto incluye: páginas de productos, sitios de cartera, páginas de eventos, páginas de próximamente, páginas de precios, sitios de introducción de la empresa, blogs personales, páginas de registro, páginas de descarga de aplicaciones y páginas de campañas. También se activa cuando: el usuario dice 做个网站, 建个落地页, 做个产品页, 做个活动页, 做个个人主页. Si es necesario crear un sitio web o una página web, utilice esta habilidad.
