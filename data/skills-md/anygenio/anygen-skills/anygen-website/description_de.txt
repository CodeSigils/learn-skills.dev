Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Website oder Zielseite erstellen möchte. Dazu gehören: Produktseiten, Portfolio-Seiten, Veranstaltungsseiten, Coming Soon-Seiten, Preisseiten, Unternehmenseinführungsseiten, persönliche Blogs, Anmeldeseiten, App-Download-Seiten und Kampagnenseiten. Wird auch ausgelöst, wenn: Der Benutzer sagt „做个网站“, „建个落地页“, „做个产品页“, „做个活动页“, „做个个人主页“. Wenn eine Website oder Webseite erstellt werden muss, nutzen Sie diese Fähigkeit.
