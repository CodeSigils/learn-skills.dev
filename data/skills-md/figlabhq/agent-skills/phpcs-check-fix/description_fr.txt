Résolvez les problèmes de style de codage PHP à l’aide de PHPCS et PHPCBF. Utilisez cette compétence chaque fois que l'utilisateur mentionne PHPCS, le style de code, la norme de codage, cs:fix, cs:check, le formatage PHP ou demande de corriger/vérifier le style de code PHP. Activez également lorsque vous remarquez que des fichiers PHP ont été modifiés et nécessitent une conformité de style, ou lorsqu'une vérification CI PHPCS a échoué.
