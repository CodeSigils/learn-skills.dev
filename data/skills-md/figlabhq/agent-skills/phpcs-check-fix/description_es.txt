Solucione problemas de estilo de codificación PHP utilizando PHPCS y PHPCBF. Utilice esta habilidad siempre que el usuario mencione PHPCS, estilo de código, estándar de codificación, cs:fix, cs:check, formato PHP o solicite corregir/verificar el estilo del código PHP. Actívelo también cuando observe que los archivos PHP se han modificado y necesitan cumplir con el estilo, o cuando falló una verificación de CI PHPCS.
