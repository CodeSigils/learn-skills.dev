Beheben Sie Probleme mit dem PHP-Codierungsstil mithilfe von PHPCS und PHPCBF. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer PHPCS, Codestil, Codierungsstandard, cs:fix, cs:check, PHP-Formatierung erwähnt oder darum bittet, den PHP-Codestil zu korrigieren/überprüfen. Aktivieren Sie diese Funktion auch, wenn Sie feststellen, dass PHP-Dateien geändert wurden und eine Stilkonformität erforderlich ist, oder wenn eine CI PHPCS-Prüfung fehlgeschlagen ist.
