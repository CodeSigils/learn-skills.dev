Краткое описание роли инженера по инструментам обработки данных для команды агентов Unity DOTS. Создает инструменты редактора, обработчики данных, валидаторы, инспекторы и утилиты отладки DOTS. Загружается только агентом инструмента обработки данных — никогда не загружается для агентов реализации среды выполнения.
