適用於 UI 設計、Web 應用程式、軟體介面和所有基於螢幕的文字的專業排版規則。強制執行法學碩士經常犯錯的永恆印刷正確性：正確的引號、破折號、間距、層次結構和佈局。執行模式：產生任何包含可見文字的 HTML、CSS、React、JSX 或 UI 程式碼時，自動套用此技能中的每個規則（不詢問、不解釋，只產生正確的排版）。審核模式：在審查或改進現有介面或遺留程式碼時，標記違規行為並提供修復。觸發：任何 HTML/CSS/React 工件建立、「建立登陸頁面」、「建立元件」、「設計 UI」、「修復版式」、「使其看起來專業」、「審查此版面配置」、網頁設計、簡報設計、儀表板建立、文件產生或任何為人類產生可見文字的任務。即使使用者沒有提及排版，只要產生 UI 輸出就套用這些規則。
