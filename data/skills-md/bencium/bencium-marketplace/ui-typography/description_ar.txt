قواعد الطباعة الاحترافية لتصميم واجهة المستخدم وتطبيقات الويب وواجهات البرامج وجميع النصوص المستندة إلى الشاشة. يفرض صحة الطباعة الخالدة التي يخطئ فيها طلاب LLM باستمرار: علامات الاقتباس الصحيحة، والشرطات، والمسافات، والتسلسل الهرمي، والتخطيط. وضع التنفيذ: عند إنشاء أي كود HTML أو CSS أو React أو JSX أو واجهة المستخدم يحتوي على نص مرئي، قم بتطبيق كل قاعدة في هذه المهارة تلقائيًا بصمت - لا تسأل، لا تشرح، فقط قم بإنتاج الطباعة الصحيحة. وضع التدقيق: عند مراجعة أو تحسين الواجهات الحالية أو التعليمات البرمجية القديمة، قم بالإبلاغ عن الانتهاكات وتقديم الإصلاحات. قم بتشغيل: أي إنشاء عناصر HTML/CSS/React، أو "إنشاء صفحة مقصودة"، أو "إنشاء مكون"، أو "تصميم واجهة مستخدم"، أو "إصلاح الطباعة"، أو "جعل هذا يبدو احترافيًا"، أو "مراجعة هذا التخطيط"، أو تصميم الويب، أو تصميم العرض التقديمي، أو إنشاء لوحة المعلومات، أو إنشاء المستندات، أو أي مهمة تنتج نصًا مرئيًا للبشر. حتى لو لم يذكر المستخدم الطباعة، قم بتطبيق هذه القواعد عند إنشاء مخرجات واجهة المستخدم.
