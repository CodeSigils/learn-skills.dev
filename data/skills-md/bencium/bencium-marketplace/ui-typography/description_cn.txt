适用于 UI 设计、Web 应用程序、软件界面和所有基于屏幕的文本的专业排版规则。强制执行法学硕士经常犯错的永恒印刷正确性：正确的引号、破折号、间距、层次结构和布局。执行模式：生成任何包含可见文本的 HTML、CSS、React、JSX 或 UI 代码时，自动应用此技能中的每条规则（不询问、不解释，只生成正确的排版）。审核模式：在审查或改进现有界面或遗留代码时，标记违规行为并提供修复。触发：任何 HTML/CSS/React 工件创建、“构建登陆页面”、“创建组件”、“设计 UI”、“修复版式”、“使其看起来专业”、“审阅此布局”、网页设计、演示文稿设计、仪表板创建、文档生成或任何为人类生成可见文本的任务。即使用户没有提及排版，只要生成 UI 输出就应用这些规则。
