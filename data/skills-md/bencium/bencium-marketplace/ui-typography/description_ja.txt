UI デザイン、Web アプリケーション、ソフトウェア インターフェイス、およびすべての画面ベースのテキスト用のプロフェッショナルなタイポグラフィ ルール。 LLM が常に間違っている、時代を超えたタイポグラフィの正確性、つまり適切な引用符、ダッシュ、スペース、階層、レイアウトを強制します。強制モード: 表示テキストを含む HTML、CSS、React、JSX、または UI コードを生成する場合、このスキルのすべてのルールがサイレントに自動適用されます。尋ねたり説明したりせず、正しいタイポグラフィを生成するだけです。監査モード: 既存のインターフェイスまたは従来のコードをレビューまたは改善する場合、違反にフラグを立てて修正を提供します。トリガー: HTML/CSS/React アーティファクトの作成、「ランディング ページの構築」、「コンポーネントの作成」、「UI のデザイン」、「タイポグラフィの修正」、「プロフェッショナルな外観にする」、「レイアウトの確認」、Web デザイン、プレゼンテーション デザイン、ダッシュボードの作成、ドキュメントの生成、または人間に見えるテキストを作成するタスク。ユーザーがタイポグラフィについて言及していない場合でも、UI 出力を生成するときは常にこれらのルールを適用してください。
