Reglas de tipografía profesionales para diseño de UI, aplicaciones web, interfaces de software y todo el texto basado en pantalla. Impone una corrección tipográfica atemporal que los LLM siempre cometen mal: comillas, guiones, espacios, jerarquía y diseño adecuados. MODO DE APLICACIÓN: Al generar CUALQUIER código HTML, CSS, React, JSX o UI que contenga texto visible, aplique automáticamente todas las reglas de esta habilidad de forma silenciosa; no pregunte, no explique, solo produzca la tipografía correcta. MODO AUDITORÍA: al revisar o mejorar las interfaces existentes o el código heredado, marque las infracciones y proporcione soluciones. Activar: cualquier creación de artefacto HTML/CSS/React, "crear una página de destino", "crear un componente", "diseñar una interfaz de usuario", "arreglar la tipografía", "hacer que esto parezca profesional", "revisar este diseño", diseño web, diseño de presentación, creación de paneles, generación de documentos o cualquier tarea que produzca texto visible para humanos. Incluso si el usuario no menciona la tipografía, aplique estas reglas siempre que genere resultados de UI.
