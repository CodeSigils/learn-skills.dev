Règles de typographie professionnelles pour la conception d'interface utilisateur, les applications Web, les interfaces logicielles et tout le texte sur écran. Applique une exactitude typographique intemporelle que les LLM se trompent constamment : guillemets, tirets, espacement, hiérarchie et mise en page appropriés. MODE D'APPLICATION : lors de la génération de TOUT code HTML, CSS, React, JSX ou UI contenant du texte visible, appliquez automatiquement chaque règle de cette compétence en silence - ne demandez pas, n'expliquez pas, produisez simplement une typographie correcte. MODE AUDIT : lors de la révision ou de l'amélioration des interfaces existantes ou du code existant, signalez les violations et fournissez des correctifs. Déclenchez : toute création d'artefact HTML/CSS/React, "créer une page de destination", "créer un composant", "concevoir une interface utilisateur", "corriger la typographie", "donner à cela un aspect professionnel", "réviser cette mise en page", la conception Web, la conception de présentation, la création de tableaux de bord, la génération de documents ou toute tâche produisant du texte visible pour les humains. Même si l'utilisateur ne mentionne pas la typographie, appliquez ces règles chaque fois que vous générez une sortie de l'interface utilisateur.
