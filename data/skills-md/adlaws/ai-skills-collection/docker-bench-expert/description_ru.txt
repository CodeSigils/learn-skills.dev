Специализированный навык для AMT Docker Bench — многоконтейнерной симуляции автономного грузовика Т264. Используйте, когда вас спросят о контейнерах docker_bench (rpk1, rpk2, rpk3, Platform-sim, avi-radio, test-manager, vas-aht), конфигурации Docker Compose, топологии сети (встроенная/внешняя/CAN/local-fms-network), настройке NAT, выборе версии CIC/RPK, симуляторе T264, интеграции VAS:AHT, профилях DDS QoS, переназначении IP-адреса, наложении файлы, run_tests.sh, совместимость версий Docker Bench, совместимые пары версий FMS/AMT или любые проблемы, связанные со средой Docker Bench. Также используйте для отладки сбоев при запуске контейнера, проблем с сетью, ошибок сборки, сбоев получения образа, проблем с несоответствием версий или проблем с готовностью обслуживания на стенде. Можно получить матрицу совместимости версий Docker Bench из Confluence, чтобы определить совместимые комбинации версий.
