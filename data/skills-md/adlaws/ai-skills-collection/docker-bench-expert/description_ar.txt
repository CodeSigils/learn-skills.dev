مهارة متخصصة لـ AMT Docker Bench - محاكاة متعددة الحاويات لشاحنة T264 المستقلة. استخدمه عند السؤال عن حاويات docker_bench (rpk1 وrpk2 وrpk3 وplatform-sim وavi-radio وtest-manager وvas-aht)، وتكوين Docker Compose، وطوبولوجيا الشبكة (شبكة داخلية/خارجية/CAN/local-fms)، وإعداد NAT، واختيار إصدار CIC/RPK، ومحاكي T264، وتكامل VAS:AHT، وملفات تعريف DDS QoS، وإعادة تعيين عنوان IP، والتراكب الملفات، أو run_tests.sh، أو توافق إصدار Docker Bench، أو أزواج إصدارات FMS/AMT المتوافقة، أو أي مشكلة تتعلق ببيئة Docker Bench. يُستخدم أيضًا لتصحيح أخطاء فشل بدء تشغيل الحاوية، أو مشكلات الشبكات، أو أخطاء البناء، أو فشل سحب الصور، أو مشكلات عدم تطابق الإصدار، أو مشكلات جاهزية الخدمة في البدلاء. يمكن جلب مصفوفة توافق إصدارات Docker Bench من Confluence لتحديد مجموعات الإصدارات المتوافقة.
