Habilidad especializada para AMT Docker Bench: una simulación de múltiples contenedores de un camión autónomo T264. Úselo cuando se le pregunte sobre los contenedores docker_bench (rpk1, rpk2, rpk3, platform-sim, avi-radio, test-manager, vas-aht), configuración de Docker Compose, topología de red (integrada/externa/CAN/local-fms-network), configuración NAT, selección de versión CIC/RPK, simulador T264, integración VAS:AHT, perfiles DDS QoS, reasignación de direcciones IP, archivos superpuestos, run_tests.sh, compatibilidad de la versión de Docker Bench, pares de versiones FMS/AMT compatibles o cualquier problema relacionado con el entorno de Docker Bench. Úselo también para depurar fallas de inicio de contenedores, problemas de red, errores de compilación, fallas de extracción de imágenes, problemas de discrepancia de versiones o problemas de preparación del servicio en el banco. Puede obtener la matriz de compatibilidad de versiones de Docker Bench de Confluence para determinar combinaciones de versiones compatibles.
