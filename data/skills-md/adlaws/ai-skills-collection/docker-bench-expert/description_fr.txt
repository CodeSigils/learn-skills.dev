Compétence spécialisée pour l'AMT Docker Bench — une simulation multi-conteneurs d'un camion autonome T264. À utiliser lorsqu'on vous pose des questions sur les conteneurs docker_bench (rpk1, rpk2, rpk3, platform-sim, avi-radio, test-manager, vas-aht), la configuration Docker Compose, la topologie du réseau (onboard/offboard/CAN/local-fms-network), la configuration NAT, la sélection de version CIC/RPK, le simulateur T264, l'intégration VAS:AHT, les profils DDS QoS, le remappage d'adresse IP, les fichiers de superposition, run_tests.sh, compatibilité des versions Docker Bench, paires de versions FMS/AMT compatibles ou tout problème impliquant l'environnement Docker Bench. Utilisez également pour déboguer les échecs de démarrage du conteneur, les problèmes de réseau, les erreurs de construction, les échecs d'extraction d'image, les problèmes d'incompatibilité de version ou les problèmes de préparation du service dans le banc. Peut récupérer la matrice de compatibilité des versions de Docker Bench à partir de Confluence pour déterminer les combinaisons de versions compatibles.
