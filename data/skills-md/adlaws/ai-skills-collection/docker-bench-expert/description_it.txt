Competenze specializzate per AMT Docker Bench: una simulazione multi-container di un camion autonomo T264. Utilizzare quando richiesto sui contenitori docker_bench (rpk1, rpk2, rpk3, platform-sim, avi-radio, test-manager, vas-aht), configurazione Docker Compose, topologia di rete (onboard/offboard/CAN/local-fms-network), configurazione NAT, selezione della versione CIC/RPK, simulatore T264, integrazione VAS:AHT, profili DDS QoS, rimappatura dell'indirizzo IP, file di sovrapposizione, run_tests.sh, compatibilità della versione Docker Bench, coppie di versioni FMS/AMT compatibili o qualsiasi problema che coinvolga l'ambiente Docker Bench. Utilizzabile anche per il debug di errori di avvio del contenitore, problemi di rete, errori di compilazione, errori di pull di immagini, problemi di mancata corrispondenza delle versioni o problemi di disponibilità del servizio in panchina. Può recuperare la matrice di compatibilità delle versioni Docker Bench da Confluence per determinare le combinazioni di versioni compatibili.
