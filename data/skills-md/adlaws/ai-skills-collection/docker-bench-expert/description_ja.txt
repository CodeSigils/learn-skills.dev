AMT Docker Bench の特殊なスキル - T264 自動運転トラックのマルチコンテナ シミュレーション。 docker_bench コンテナー (rpk1、rpk2、rpk3、platform-sim、avi-radio、test-manager、vas-aht)、Docker Compose 構成、ネットワーク トポロジ (オンボード/オフボード/CAN/ローカル fms ネットワーク)、NAT セットアップ、CIC/RPK バージョンの選択、T264 シミュレーター、VAS:AHT 統合、DDS QoS プロファイル、IP アドレスについて質問された場合に使用します。再マッピング、オーバーレイ ファイル、run_tests.sh、Docker Bench バージョンの互換性、互換性のある FMS/AMT バージョンのペア、または Docker Bench 環境に関連する問題。コンテナーの起動の失敗、ネットワークの問題、ビルド エラー、イメージのプルの失敗、バージョンの不一致の問題、ベンチでのサービスの準備の問題のデバッグにも使用します。 Confluence から Docker Bench バージョン互換性マトリックスを取得して、互換性のあるバージョンの組み合わせを判断できます。
