Experte für die Integration von GhostDDS in eine IRIS-ähnliche Webvisualisierungsplattform, um die Wiedergabe von RTI Connext DDS-Aufzeichnungsdatenbanken ohne RTI-Laufzeit oder -Lizenz zu ermöglichen und gleichzeitig den vorhandenen Live-DDS-Modus beizubehalten. Verwenden Sie diese Option, wenn Sie nach der Integration von GhostDDS, dem Hinzufügen der Aufzeichnungswiedergabe zu IRIS, dem Entfernen der RTI-Wiedergabeabhängigkeit, dem Erstellen einer DataBridge-Abstraktion, dem Hinzufügen von Wiedergabeendpunkten, der Migration des Wiedergabe-Frontends auf eine einheitliche API oder der Fehlerbehebung bei GhostDDS-Integrationsproblemen gefragt werden.
