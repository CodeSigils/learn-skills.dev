Эксперт по интеграции GhostDDS в IRIS-подобную платформу веб-визуализации, позволяющую воспроизводить базы данных записей RTI Connext DDS без какой-либо среды выполнения или лицензии RTI, сохраняя при этом существующий режим реального времени DDS. Используйте, когда вас спросят об интеграции GhostDDS, добавлении воспроизведения записи в IRIS, удалении зависимости воспроизведения RTI, создании абстракции DataBridge, добавлении конечных точек воспроизведения, переносе интерфейса воспроизведения в унифицированный API или устранении проблем с интеграцией GhostDDS.
