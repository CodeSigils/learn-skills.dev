ghostDDS est une application C++17 qui lit les enregistrements RTI Connext DDS à partir de bases de données SQLite et fournit une lecture contrôlable avec filtrage, visualisation QoS, décodage de type et plusieurs options frontales. À utiliser lorsqu'on lui pose des questions sur l'architecture ghostDDS, la couche de stockage, le moteur de lecture, le décodage CDR (XCDR1, XCDR2/D_CDR2, évolution de type, décodage en masse), le système de type, l'analyse de type XML, le filtrage, l'inspection QoS, l'API REST, le serveur Web, le streaming WebSocket, les événements SSE, le décodage CDR côté client, les décodeurs de protocole JavaScript, l'interface graphique native, les sous-commandes CLI, l'enregistrement des bases de données, les fichiers DAT, metadata.db, Discovery.db, build CMake, packaging Debian, bibliothèques statiques (ghostdds_playback, ghostdds_web), exemples ou tests. Explique à tous les niveaux, de l'aperçu non technique aux détails techniques approfondis.
