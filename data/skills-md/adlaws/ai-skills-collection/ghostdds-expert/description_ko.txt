ghostDDS는 SQLite 데이터베이스에서 RTI Connext DDS 녹음을 읽고 필터링, QoS 시각화, 유형 디코딩 및 여러 프런트 엔드 옵션을 통해 제어 가능한 재생을 제공하는 C++17 애플리케이션입니다. ghostDDS 아키텍처, 스토리지 계층, 재생 엔진, CDR 디코딩(XCDR1, XCDR2/D_CDR2, 유형 진화, 대량 디코딩), 유형 시스템, XML 유형 구문 분석, 필터링, QoS 검사, REST API, 웹 서버, WebSocket 스트리밍, SSE 이벤트, 클라이언트 측 CDR 디코딩, JavaScript 프로토콜 디코더, 기본 GUI, CLI 하위 명령, 기록 데이터베이스, dat 파일, 메타데이터.db, discovery.db, CMake에 대해 질문할 때 사용합니다. 빌드, Debian 패키징, 정적 라이브러리(ghostdds_playback, ghostdds_web), 예제 또는 테스트. 비기술적인 개요부터 심층적인 기술 세부 사항까지 모든 수준에서 설명합니다.
