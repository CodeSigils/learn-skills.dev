ghostDDS è un'applicazione C++ 17 che legge le registrazioni DDS RTI Connext dai database SQLite e fornisce una riproduzione controllabile con filtraggio, visualizzazione QoS, decodifica del tipo e molteplici opzioni front-end. Utilizzare quando richiesto su architettura ghostDDS, livello di archiviazione, motore di riproduzione, decodifica CDR (XCDR1, XCDR2/D_CDR2, evoluzione del tipo, decodifica in blocco), sistema di tipo, analisi del tipo XML, filtraggio, ispezione QoS, API REST, server Web, streaming WebSocket, eventi SSE, decodifica CDR lato client, decodificatori di protocollo JavaScript, GUI nativa, sottocomandi CLI, database di registrazione, file dat, metadata.db, discovery.db, build CMake, pacchetti Debian, librerie statiche (ghostdds_playback, ghostdds_web), esempi o test. Spiega a qualsiasi livello, dalla panoramica non tecnica ai dettagli tecnici approfonditi.
