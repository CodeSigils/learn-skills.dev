ghostDDS es una aplicación C++17 que lee grabaciones RTI Connext DDS de bases de datos SQLite y proporciona reproducción controlable con filtrado, visualización de QoS, decodificación de tipos y múltiples opciones de interfaz. Úselo cuando se le pregunte sobre arquitectura GhostDDS, capa de almacenamiento, motor de reproducción, decodificación de CDR (XCDR1, XCDR2/D_CDR2, evolución de tipo, decodificación masiva), sistema de tipos, análisis de tipo XML, filtrado, inspección de QoS, API REST, servidor web, transmisión WebSocket, eventos SSE, decodificación de CDR del lado del cliente, decodificadores de protocolo JavaScript, GUI nativa, subcomandos CLI, bases de datos de grabación, archivos dat, metadata.db, discover.db. Compilación de CMake, empaquetado de Debian, bibliotecas estáticas (ghostdds_playback, ghostdds_web), ejemplos o pruebas. Explica en cualquier nivel, desde una descripción general no técnica hasta detalles técnicos profundos.
