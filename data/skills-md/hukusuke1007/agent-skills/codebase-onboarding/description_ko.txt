복잡한 코드베이스를 체계적으로 분석하고 아키텍처를 시각화 및 문서화하며 새로운 개발자의 온보딩을 지원하는 일반적인 기술입니다. 결과물은 항상 `docs/` 아래에 출력 분할되어야 합니다. 이는 다음 요청에 사용됩니다: (1) "이 코드베이스 분석" 또는 "큰 그림 보여주기"와 같은 개요 이해; (2) "아키텍처 문서 생성" 또는 "C4 다이어그램 생성"과 같은 설계 문서 생성 (3) 신규 개발자를 위한 온보딩 자료 작성 (4) 기술 부채 식별(예: 부채 평가) (5) "기능 목록"과 같은 기능 목록을 생성합니다. (6) "이 기능을 사용할 때 무슨 일이 일어나는지 추적"과 같은 사용자 작업 흐름을 추적합니다. (7) "새로운 기능을 구현하기 위한 단계 제공"과 같이 프런트엔드와 백엔드를 포괄하는 구현 가이드를 생성합니다. 특정 언어, 프레임워크 또는 디렉터리 구조에 의존하지 않으며 모든 저장소에서 사용할 수 있습니다.  

항상 사용자의 언어로 응답하시기 바랍니다.
