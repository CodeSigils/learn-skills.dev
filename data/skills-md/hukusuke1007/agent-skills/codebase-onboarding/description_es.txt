Una habilidad genérica que analiza sistemáticamente bases de código complejas, visualiza y documenta la arquitectura y apoya la incorporación de nuevos desarrolladores. Los entregables siempre deben generarse en archivos separados en el directorio `docs/`. Se utiliza para las siguientes solicitudes: (1) comprender la descripción general, como "Analizar esta base de código" o "Muéstrame el panorama general", (2) generar documentación de diseño, como "Crear un documento de arquitectura" o "Generar un diagrama C4", (3) crear material de incorporación para nuevos desarrolladores, (4) identificar la deuda técnica, (5) producir un inventario de funciones, como "Enumerar las funciones", (6) rastrear lo que sucede cuando se utiliza una función, es decir, rastrear la operación del usuario flujos, (7) generar guías de implementación en el front-end y back-end, como "Proporcionar pasos para implementar una nueva característica". No depende de ningún lenguaje, marco o estructura de directorios específicos y se puede utilizar con cualquier repositorio.
