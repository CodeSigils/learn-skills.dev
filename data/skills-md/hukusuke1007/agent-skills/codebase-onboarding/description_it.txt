Una competenza generica che analizza sistematicamente basi di codice complesse, visualizza e documenta l'architettura e supporta l'onboarding di nuovi sviluppatori. I risultati finali devono sempre essere inviati in file separati nella directory "docs/". Viene utilizzato per le seguenti richieste: (1) comprendere la panoramica, come "Analizzare questa base di codice" o "Mostrami il quadro generale", (2) generare documentazione di progettazione, come "Creare un documento di architettura" o "Generare un diagramma C4", (3) creare materiale di onboarding per i nuovi sviluppatori, (4) identificare il debito tecnico, (5) produrre un inventario delle funzionalità, come "Elencare le funzionalità", (6) tracciare cosa succede quando viene utilizzata una funzionalità, ovvero monitorare il funzionamento dell'utente flussi, (7) generando guide di implementazione tra front‑end e back‑end, come “Fornire passaggi per implementare una nuova funzionalità”. Non dipende da alcun linguaggio, framework o struttura di directory specifica e può essere utilizzato con qualsiasi repository.
