Eine generische Fähigkeit, die komplexe Codebasen systematisch analysiert, die Architektur visualisiert und dokumentiert und das Onboarding neuer Entwickler unterstützt. Die Ergebnisse müssen immer in separaten Dateien im Verzeichnis „docs/“ ausgegeben werden. Es wird für die folgenden Anforderungen verwendet: (1) Verstehen der Übersicht, wie zum Beispiel „Analysieren Sie diese Codebasis“ oder „Zeigen Sie mir das Gesamtbild“, (2) Generieren von Designdokumentationen, wie zum Beispiel „Erstellen Sie ein Architekturdokument“ oder „Generieren Sie ein C4-Diagramm“, (3) Erstellen von Onboarding-Material für neue Entwickler, (4) Identifizieren technischer Schulden, (5) Erstellen eines Feature-Inventars, wie zum Beispiel „Listen Sie die Features auf“, (6) Verfolgen, was passiert, wenn ein Feature verwendet wird, d. h. Verfolgen des Benutzers Betriebsabläufe, (7) Generieren von Implementierungsleitfäden für Front-End und Back-End, z. B. „Stellen Sie Schritte zur Implementierung einer neuen Funktion bereit.“ Es ist nicht von einer bestimmten Sprache, einem Framework oder einer Verzeichnisstruktur abhängig und kann mit jedem Repository verwendet werden.
