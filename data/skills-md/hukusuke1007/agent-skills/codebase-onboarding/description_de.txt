Eine allgemeine Fähigkeit, komplexe Codebasen systematisch zu analysieren, die Architektur zu visualisieren und zu dokumentieren und das Onboarding neuer Entwickler zu unterstützen. Die Ergebnisse müssen immer in separaten Dateien unter „docs/“ ausgegeben werden. Wird für die folgenden Anfragen verwendet: (1) Verstehen der Übersicht, z. B. „Analysieren Sie diese Codebasis“ oder „Erzählen Sie mir das Gesamtbild“; (2) Erstellen einer Designdokumentation, z. B. „Erstellen eines Architekturdokuments“ oder „Generieren eines C4-Diagramms“; (3) Erstellen von Materialien für neue Entwickler, z. B. „Onboarding-Dokumentation erstellen“; (4) Bewertung technischer Schulden, z. B. „Technische Schulden identifizieren“; (5) Erstellen eines Funktionsinventars, z. B. „Listen Sie die Funktionen auf“; (6) Verfolgung von Benutzeraktionsabläufen, z. B. „Verfolgen Sie, was passiert, wenn diese Funktion verwendet wird“; (7) Generieren von Implementierungsleitfäden, die Front-End und Back-End umfassen, wie zum Beispiel „Schritte zur Implementierung einer neuen Funktion bereitstellen“. Es ist nicht von einer bestimmten Sprache, einem Framework oder einer Verzeichnisstruktur abhängig und kann mit jedem Repository verwendet werden.

Bitte antworten Sie immer in der Sprache des Benutzers.
