Une compétence générique qui analyse systématiquement les bases de code complexes, visualise et documente l'architecture et prend en charge l'intégration de nouveaux développeurs. Les livrables doivent toujours être générés dans des fichiers séparés sous le répertoire `docs/`. Il est utilisé pour les requêtes suivantes : (1) comprendre la vue d'ensemble, telle que "Analyser cette base de code" ou "Montrez-moi une vue d'ensemble", (2) générer une documentation de conception, telle que "Créer un document d'architecture" ou "Générer un diagramme C4", (3) créer du matériel d'intégration pour les nouveaux développeurs, (4) identifier la dette technique, (5) produire un inventaire des fonctionnalités, tel que "Liste des fonctionnalités", (6) suivre ce qui se passe lorsqu'une fonctionnalité est utilisée, c'est-à-dire suivre l'utilisateur. flux opérationnels, (7) générant des guides de mise en œuvre sur le front-end et le back-end, tels que « Fournir les étapes pour implémenter une nouvelle fonctionnalité ». Il ne dépend d’aucun langage, framework ou structure de répertoires spécifique et peut être utilisé avec n’importe quel référentiel.
