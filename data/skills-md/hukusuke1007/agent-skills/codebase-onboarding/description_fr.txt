Une compétence générique qui analyse systématiquement les bases de code complexes, visualise et documente l'architecture et prend en charge l'intégration de nouveaux développeurs. Les livrables doivent toujours être générés dans des fichiers séparés sous `docs/`. Il est utilisé pour les requêtes suivantes : (1) comprendre la vue d'ensemble, telle que « Analyser cette base de code » ou « Montrer-moi une vue d'ensemble » ; (2) générer une documentation de conception, telle que « Créer un document d'architecture » ​​ou « Générer un diagramme C4 » ; (3) créer du matériel d'intégration pour les nouveaux développeurs, tel que « Créer des documents d'intégration » ; (4) évaluer la dette technique, telle que « Identifier la dette technique » ; (5) produire un inventaire des fonctionnalités, tel que « Liste des fonctionnalités » ; (6) suivre les flux d'interaction des utilisateurs, tels que « Suivre ce qui se passe lorsque cette fonctionnalité est utilisée » ; (7) générer des guides de mise en œuvre couvrant le front-end et le back-end, tels que « Fournir les étapes pour implémenter une nouvelle fonctionnalité ». Il ne dépend d'aucun langage, framework ou disposition de répertoire spécifique et peut être utilisé avec n'importe quel référentiel.

Veuillez toujours répondre dans la langue de l'utilisateur.
