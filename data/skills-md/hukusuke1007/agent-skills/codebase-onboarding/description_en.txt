A generic skill that systematically analyzes complex code bases, visualizes and documents the architecture, and supports onboarding new developers. The deliverables must always be output in separate files under the `docs/` directory. It is used for the following requests: (1) understanding the overview, such as “Analyze this code base” or “Show me the big picture,” (2) generating design documentation, such as “Create an architecture document” or “Generate a C4 diagram,” (3) creating onboarding material for new developers, (4) identifying technical debt, (5) producing a feature inventory, such as “List the features,” (6) tracing what happens when a feature is used, i.e., tracking user operation flows, (7) generating implementation guides across front‑end and back‑end, such as “Provide steps to implement a new feature.” It does not depend on any specific language, framework, or directory structure and can be used with any repository.
