Eine Fähigkeit, die mehrere angehängte Bilder stapelweise komprimiert und in der Größe ändert. Es wird für Anfragen wie „Bild komprimieren“, „Diesen Screenshot aufhellen“, „Größe ändern“, „Bild verkleinern“ und dergleichen verwendet. Mithilfe von Pillow wird die Größe der längeren Seite auf 1920 Pixel geändert und das Ergebnis als JPEG oder PNG im Ausgabeverzeichnis gespeichert.
