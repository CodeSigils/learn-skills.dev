A skill that generates images using Nano Banana 2 (Google Gemini gemini‑3.1‑flash‑image‑preview). It is used for requests such as “generate an image,” “create an illustration of …,” “make an image with Nano Banana,” “generate a graphic‑recording‑style image,” and the like. It takes a prompt, runs a Python script, and outputs a timestamped PNG to images/generated/.
