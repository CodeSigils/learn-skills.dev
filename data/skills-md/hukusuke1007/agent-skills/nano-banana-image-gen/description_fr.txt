Une compétence qui génère des images à l'aide de Nano Banana2 (Google Gemini gemini‑3.1‑flash‑image‑preview). Il est utilisé pour des requêtes telles que « Générer une image », « Créer une illustration de 〇〇 », « Créer une image avec Nano Banana », « Générer une image de style d'enregistrement graphique », etc. Il reçoit une invite, exécute un script Python et génère un PNG horodaté dans images/generated/.
