Une compétence qui génère des images à l'aide de Nano Banana2 (Google Gemini gemini‑3.1‑flash‑image‑preview). Il est utilisé pour des requêtes telles que « générer une image », « créer une illustration de… », « créer une image avec Nano Banana », « générer une image de style d'enregistrement graphique », etc. Il prend une invite, exécute un script Python et génère un fichier PNG horodaté dans images/generated/.
