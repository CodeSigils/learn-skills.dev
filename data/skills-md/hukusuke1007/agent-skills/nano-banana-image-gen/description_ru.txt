Навык создания изображений с помощью Nano Banana2 (Google Gemini Gemini‑3.1‑flash‑image‑preview). Он используется для таких запросов, как «создать изображение», «создать иллюстрацию…», «создать изображение с помощью Nano Banana», «создать изображение в стиле графической записи» и тому подобное. Он принимает приглашение, запускает сценарий Python и выводит PNG с отметкой времени в файл image/generated/.
