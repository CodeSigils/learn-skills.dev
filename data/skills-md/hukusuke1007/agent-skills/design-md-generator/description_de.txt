Eine Fähigkeit, die aus URL-, Bild- und Textanforderungen ein DESIGN.md für KI-Coding-Agents generiert. Es wird mit Anfragen wie „Example.com in DESIGN.md konvertieren“, „Diese Miniaturansicht in DESIGN.md konvertieren“ oder „Erstellen Sie ein cooles, auffälliges DESIGN.md für eine LP“ verwendet. Bei der Übergabe an Claude Code, Cursor oder Stitch kann eine konsistente Benutzeroberfläche erstellt werden, indem ein Designspezifikationsdokument mit einer Struktur aus neun Abschnitten ausgegeben wird, die getdesign.md / awesome-design-md entspricht. Es unterstützt drei Muster: CSS-Analyse, visuelle Bildextraktion und Anforderungsgenerierung.
