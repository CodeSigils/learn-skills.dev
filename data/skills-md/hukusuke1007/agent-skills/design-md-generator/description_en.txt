A skill that generates a DESIGN.md for AI coding agents from URL, image, and text requirements. It is used with requests such as “Convert example.com into DESIGN.md,” “Convert this thumbnail into DESIGN.md,” or “Create a cool, pop DESIGN.md for an LP.” When passed to Claude Code, Cursor, or Stitch, it can produce a consistent UI by outputting a design specification document with a nine‑section structure that conforms to getdesign.md / awesome-design-md. It supports three patterns: CSS analysis, visual image extraction, and requirement generation.
