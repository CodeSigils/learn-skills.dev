Una habilidad que genera un DESIGN.md para agentes de codificación de IA a partir de requisitos de URL, imágenes y texto. Se utiliza con solicitudes como "Convertir ejemplo.com en DESIGN.md", "Convertir esta miniatura en DESIGN.md" o "Crear un DESIGN.md atractivo y pop para un LP". Cuando se pasa a Claude Code, Cursor o Stitch, puede producir una interfaz de usuario consistente generando un documento de especificación de diseño con una estructura de nueve secciones que se ajusta a getdesign.md / awesome-design-md. Admite tres patrones: análisis CSS, extracción de imágenes visuales y generación de requisitos.
