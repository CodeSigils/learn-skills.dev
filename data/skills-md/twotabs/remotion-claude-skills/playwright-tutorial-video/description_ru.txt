Запишите реальный поток пользователей с помощью Playwright, а затем создайте обучающее видео по Remotion. Три точки входа: захват (отдельные снимки экрана + координаты для каждого шага), запись (непрерывное видео с наложениями, синхронизированными с меткой времени) или из манифеста (повторное создание сцен из существующего манифеста). Новый код пользовательского интерфейса не создан.
