創建精美的設計工件作為獨立的 HTML — UI 模型、互動式原型、線框、登陸頁面、儀表板、應用程式螢幕、行動應用程式和幻燈片。每當使用者想要設計、模擬、原型、線框圖或視覺化任何介面、螢幕、流程或視覺工件時，即使他們沒有說出「設計」這個詞（例如「為我建立一個登陸頁面」、「向我展示設定畫面可能是什麼樣子」、「對入門流程進行原型設計」、「對一些佈局想法進行線框圖」、「製作此技能」），都可以使用此技能。它驱动整个设计过程：澄清问题、收集设计上下文以及生成一个或多个 HTML 可交付成果。在便携式代理工具上运行，包括 Claude Code、Cursor 和 Codex Agent — 工具特定工具从引用/解析。
