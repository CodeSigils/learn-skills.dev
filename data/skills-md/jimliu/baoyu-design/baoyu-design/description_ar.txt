قم بإنشاء عناصر تصميم مصقولة كنماذج HTML قائمة بذاتها لواجهة المستخدم، ونماذج أولية تفاعلية، وإطارات سلكية، وصفحات مقصودة، ولوحات معلومات، وشاشات تطبيقات، وتطبيقات جوال، ومجموعات شرائح. استخدم هذه المهارة عندما يريد المستخدم تصميم أي واجهة أو شاشة أو تدفق أو قطعة أثرية مرئية أو نموذج نموذجي أو نموذج أولي أو إطار سلكي أو تصورها - حتى عندما لا يقول كلمة "تصميم" (على سبيل المثال، "أنشئ لي صفحة مقصودة"، "أرني كيف يمكن أن تبدو شاشة الإعدادات"، "نموذج أولي لتدفق الإعداد"، "إطار سلكي لبعض أفكار التخطيط"، "أنشئ عرضًا تقديميًا مخطّطًا"). إنه يقود عملية تصميم كاملة: توضيح الأسئلة، وجمع سياق التصميم، وإنتاج واحد أو أكثر من تسليمات HTML. يتم تشغيله على أدوات تسخير الوكيل المحمولة بما في ذلك Claude Code، وCursor، وCodex Agent - ويتم حل الأدوات الخاصة بالأدوات من المراجع/.
