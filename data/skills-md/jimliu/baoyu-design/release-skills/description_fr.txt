Flux de travail de publication universel. Détecte automatiquement les fichiers de version et les journaux de modifications. Prend en charge Node.js, Python, Rust, Claude Plugin, les versions GitHub, les balises annotées, le remplissage des versions historiques et les projets génériques. À utiliser lorsque l'utilisateur dit « release », « 发布 », « new version », « Bump version », « push », « 推送 », « release notes », « GitHub Release » ou « 回填 Release ».
