Extrahiert Ressourcen und JavaScript aus jeder installierten Electron-App (Bundle „.asar“), stellt Originalquellen aus „.js.map“-Dateien wieder her, sofern verfügbar, oder formatiert andernfalls minimierten Code mit Prettier. Verwenden Sie diese Option, wenn der Benutzer „Electron-App extrahieren“, „Electron dekompilieren“, „den Quellcode von <app> abrufen“, „app.asar überprüfen“, „Electron 应用源码“ oder „提取 .asar“ verwenden möchte oder fragt, wie eine Desktop-Electron-App erstellt wird. Überspringt „node_modules“ und unterstützt sowohl macOS als auch Windows.
