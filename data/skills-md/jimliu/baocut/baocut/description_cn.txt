从 CLI 驱动 BaoCut 来转录本地媒体或支持的视频 URL、通过 Agent 工作人员润色转录本、创建/翻译字幕、审核说话者分类、使用可逆暂停/填充/重拍剪辑和 B 卷附件编辑一个主讲人源，以及导出 SRT/VTT/ASS/Markdown/视频。用于转录、字幕、字幕校正/翻译、说话人识别、主讲人清理、粗剪、B-roll 和最终导出，包括转写、加字幕、改字幕、翻译字幕、识别说话人、剪口播、去口癖、删停顿、粗剪、加 B-roll、还原成片等中文请求，以及在 BaoCut 存储库中工作时使用。不适用于动态图形、音乐、多机位、生成视频或任意多轨合成。 CLI 从不调用 LLM API；持久代理工作人员回答其声明/提交任务协议。
