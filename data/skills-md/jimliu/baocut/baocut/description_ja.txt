CLI から BaoCut を操作して、ローカル メディアまたはサポートされているビデオ URL を文字起こしし、エージェント ワーカーを通じてトランスクリプトを磨き、字幕の作成/翻訳、話者ダイアライゼーションの確認、可逆一時停止/フィラー/リテイク カットと B ロール添付ファイルを使用した 1 つのトーキングヘッド ソースの編集、および SRT/VTT/ASS/Markdown/ビデオのエクスポートを行います。文字起こし、キャプション、字幕の修正/翻訳、話者の識別、トーキングヘッドのクリーンアップ、ラフカット、B ロール、および最終エクスポート (转写、加字幕、修正字幕、翻译字幕、识别说话人、剪口播、去口癖、删停止顿、粗剪、加 B ロール、导出成片など) や BaoCut リポジトリでの作業時に使用します。モーション グラフィックス、音楽、マルチカム、生成されたビデオ、または任意のマルチトラック合成には使用できません。 CLI は LLM API を呼び出すことはありません。永続的なエージェント ワーカーは、その要求/送信タスク プロトコルに応答します。
