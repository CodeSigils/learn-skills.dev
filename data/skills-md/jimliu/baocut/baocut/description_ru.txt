Управляйте BaoCut из интерфейса командной строки, чтобы расшифровывать URL-адреса локальных мультимедиа или поддерживаемых видео, шлифовать расшифровки с помощью сотрудников агентов, создавать/переводить субтитры, просматривать дневник выступающих, редактировать один источник говорящей головы с обратимыми паузами/заполнителями/повторными нарезками и вложениями B-roll, а также экспортировать SRT/VTT/ASS/Markdown/видео. Используется для транскрипции, титров, исправления/перевода субтитров, идентификации говорящего, очистки говорящих голов, черновых монтажей, B-roll и окончательного экспорта, включая запросы на китайский язык, такие как 转写、加字幕、改字幕、翻译字幕、识别说话人、剪口播、去口癖、删停顿、粗剪、加 B-roll、导出成片，и при каждой работе в репозитории BaoCut. Не для анимационной графики, музыки, многокамерной съемки, сгенерированного видео или произвольного многодорожечного композитинга. CLI никогда не вызывает API LLM; постоянные работники агента отвечают на его протокол задачи утверждения/отправки.
