Verwenden Sie diese Fähigkeit, wenn der Benutzer darum bittet, seine lokalen Git-Änderungen, bereitgestellten oder nicht bereitgestellten Diffs zu überprüfen, oder eine Codeüberprüfung vor dem Festschreiben wünscht. Löst aus bei „Meine Änderungen überprüfen“, „Stufenüberprüfen“, „Mein Diff überprüfen“, „Meinen Code überprüfen“, „Lokale Änderungen am Code überprüfen“, „Nicht bereitgestellt überprüfen“ und „Vor dem Festschreiben überprüfen“.
