Analice una base de código de software en busca de complejidad algorítmica y puntos críticos de rendimiento, luego proponga o implemente optimizaciones seguras sin alterar el comportamiento. Úselo cuando se le solicite a Codex que escanee muchos archivos, encuentre bucles ineficientes, iteraciones anidadas, escaneos repetidos, renderizado/recálculo costoso, consultas N+1, operaciones O(n^2) u O(n) evitables, o reduzca la complejidad como O(n^2) a O(n log n)/O(n), preservando al mismo tiempo las pruebas, las API, los resultados y la capacidad de mantenimiento.
