Evidenzbasierte Bewertung, ob ein SAP-API-/Schnittstellennutzungsszenario mit der SAP-API-Richtlinie (v.4.2026a) übereinstimmt. Wird immer dann verwendet, wenn jemand fragt, ob eine Art des Aufrufs von SAP zulässig/konform ist – z. B. Veröffentlichte API vs. interner/privater/„vertraulicher“ API-Status, „Dokumentierte Verwendung“, ob ein Drittanbieter-Tool/iPaaS/Middleware/RPA-Bot/KI-Agent/MCP-Server SAP-APIs aufrufen kann, agentischer oder generativer KI-Zugriff auf SAP, Massendatenextraktion oder Replikation in einen Lake/Warehouse, benutzerdefinierte Z/Y OData- oder RFC/BAPI-Wrapper und Clean Core, ADT/Entwickler-Tooling-Grenzen, ODP-RFC und andere „nicht zulässige“ Schnittstellen, Partner-Integrationszertifizierung oder RISE-Integrationskorrektur. Wird auch dann ausgelöst, wenn die Richtlinie nicht benannt ist, z. B. „Dürfen wir…“, „Ist es konform mit…“, „Können wir X mit SAP verbinden…“, „Wird dies unter der neuen API-Richtlinie brechen?“ Erstellt eine fundierte technische Bewertung mit einem Vertrauensniveau – ausdrücklich KEINE Rechtsberatung und KEINE endgültige SAP-Compliance-Entscheidung.
