Évaluation fondée sur des preuves pour déterminer si un scénario d'utilisation de l'API/interface SAP est conforme à la politique de l'API SAP (v.4.2026a). À utiliser chaque fois que quelqu'un demande si un moyen d'appeler SAP est autorisé/conforme, par ex. API publiée par rapport au statut de l'API interne/privée/"confidentielle", "Utilisation documentée", si un outil tiers/iPaaS/middleware/bot RPA/agent IA/serveur MCP peut appeler des API SAP, un accès agent ou IA génératif à SAP, une extraction ou une réplication de données en masse dans un lac/un entrepôt, des wrappers Z/Y OData ou RFC/BAPI personnalisés et Clean Core, des limites ADT/outils de développement, ODP-RFC et autres "non autorisées", la certification d'intégration du partenaire ou la correction de l'intégration RISE. Déclenchez même lorsque la stratégie n'est pas nommée, par ex. "Sommes-nous autorisés à…", "est-ce conforme à…", "pouvons-nous connecter X à SAP…", "cela sera-t-il en rupture avec la nouvelle politique API". Produit une évaluation technique sourcée avec un niveau de confiance – explicitement PAS un conseil juridique et PAS une décision finale de conformité SAP.
