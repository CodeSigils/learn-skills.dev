Используйте всякий раз, когда кто-то спрашивает, разрешен ли/совместим ли способ вызова SAP — например. Опубликованный API или внутренний/частный/конфиденциальный статус API, «Документированное использование», может ли сторонний инструмент / iPaaS / промежуточное программное обеспечение / бот RPA / агент AI / сервер MCP вызывать SAP API, агентный или генеративный доступ ИИ к SAP, массовое извлечение или репликация данных в озеро/хранилище, пользовательские оболочки Z/Y OData или RFC/BAPI и Clean Core, границы ADT/инструментов разработчика, ODP-RFC и другие «неразрешенные» интерфейсы, сертификация партнерской интеграции или исправление интеграции RISE. Триггер, даже если политика не названа, например. «разрешено ли нам…», «соответствует ли это…», «можем ли мы подключить X к SAP…», «нарушит ли это новую политику API».
