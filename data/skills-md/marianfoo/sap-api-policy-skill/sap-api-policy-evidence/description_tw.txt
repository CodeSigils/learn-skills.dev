對 SAP API/介面使用情境是否符合 SAP API 政策 (v.4.2026a) 進行基於證據的評估。每當有人詢問呼叫 SAP 的方式是否允許/合規時使用 - 例如已發布的 API 與內部/私有/“機密”API 狀態、“記錄使用”、第三方工具/iPaaS/中間件/RPA 機器人/AI 代理/MCP 伺服器是否可以呼叫 SAP API、對 SAP 的代理或生成式 AI 存取、批次資料提取或複製到資料包裝器/FC/ Core、ADT/開發人員工具邊界、ODP-RFC 等「不允許的」介面、合作夥伴整合認證或 RISE 整合修復。即使策略未命名也會觸發，例如「我們是否可以…」、「它是否符合…」、「我們能否將 X 連接到 SAP…」、「這會在新的 API 政策下被打破嗎」。產生具有可信度的來源技術評估 — 明確不是法律建議，也不是最終的 SAP 合規決策。
