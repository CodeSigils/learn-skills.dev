Valutazione basata sull'evidenza per stabilire se uno scenario di utilizzo dell'API/interfaccia SAP è in linea con la policy API SAP (v.4.2026a). Da utilizzare ogni volta che qualcuno chiede se un modo per chiamare SAP è consentito/conforme, ad es. API pubblicate rispetto allo stato API interno/privato/"confidenziale", "Uso documentato", se uno strumento di terze parti/iPaaS/middleware/bot RPA/agente AI/server MCP può chiamare API SAP, accesso agentico o AI generativo a SAP, estrazione o replica di dati in blocco in un lago/warehouse, wrapper Z/Y OData o RFC/BAPI personalizzati e Clean Core, limiti ADT/strumenti per sviluppatori, ODP-RFC e altri "non" "interfacce consentite", certificazione di integrazione del partner o correzione dell'integrazione RISE. Si attiva anche quando la policy non ha un nome, ad es. "ci è consentito...", "è conforme a...", "possiamo connettere X a SAP...", "questo non sarà conforme alla nuova policy API". Produce una valutazione tecnica fornita con un livello di confidenza: NON esplicitamente una consulenza legale e NON una decisione finale di conformità SAP.
