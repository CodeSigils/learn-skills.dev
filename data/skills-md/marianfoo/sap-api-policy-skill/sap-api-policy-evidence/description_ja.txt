SAP API/インターフェイスの使用シナリオが SAP API ポリシー (v.4.2026a) に準拠しているかどうかの証拠に基づく評価。 SAP への呼び出し方法が許可/準拠しているかどうかを誰かが尋ねるたびに使用します。例:公開 API と内部/プライベート/「機密」 API ステータス、「文書化された使用」、サードパーティ ツール/iPaaS/ミドルウェア/RPA ボット/AI エージェント/MCP サーバーが SAP API を呼び出すことができるかどうか、SAP へのエージェントまたは生成 AI アクセス、レイク/ウェアハウスへの一括データ抽出またはレプリケーション、カスタム Z/Y OData または RFC/BAPI ラッパーとクリーン コア、ADT/開発者ツール境界、ODP-RFC および他の「許可されていない」インターフェイス、パートナー統合認定、または RISE 統合修復。ポリシーに名前が付けられていない場合でもトリガーされます。 「許可されていますか?」、「…に準拠していますか?」、「X を SAP に接続できますか?」、「これは新しい API ポリシーに違反しますか?」。信頼レベルを伴う情報源に基づいた技術評価を生成します。明示的に法的アドバイスではなく、SAP コンプライアンスの最終決定でもありません。
