Используйте, когда кто-то просит изучить вопрос разработки программного обеспечения с помощью проверенной, многоаспектной точки зрения — «следует ли нам использовать X против Y», «оценить библиотеку/фреймворк/базу данных Z», «исследовать, следует ли нам принять…», «написать ADR для…», «всплеск…» или «перейти с X на Y/путь обновления». Запускает конвейер в стиле STORM, специализирующийся на программном обеспечении: автоматически определяет один из пяти режимов исследования (оценка библиотеки, глубокие исследования, архитектура, всплеск, миграция), параллельно создает экспертные линзы этого режима, отображает их противоречия, синтезирует HTML-брифинг и запись Markdown/ADR, затем состязательно проверяет каждое утверждение на основе ПЕРВИЧНЫХ источников программного обеспечения (официальные документы, RFC, выпуски GitHub, OSV/CVE, OpenSSF Scorecard, тесты) с учетом версии. Лучше всего подходит для решений, в которых важны различные точки зрения и верные версии, проверенные фактами утверждения; излишне для быстрого поиска API. Для тем, не связанных с программным обеспечением, используйте глубокие исследования; для чистой матрицы решений используйте анализ компромиссов.
