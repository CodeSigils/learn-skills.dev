À utiliser lorsque quelqu'un demande de rechercher une question de génie logiciel à travers une lentille vérifiée et multiperspective : "devrions-nous utiliser X vs Y", "évaluer la bibliothèque/le framework/la base de données Z", "rechercher si nous devrions adopter…", "écrire un ADR pour…", "augmenter sur…" ou "migrer de X vers Y/chemin de mise à niveau". Exécute un pipeline de style STORM spécialisé pour les logiciels : détecte automatiquement l'un des cinq modes de recherche (évaluation de bibliothèque, recherche approfondie, architecture, pic, migration), génère en parallèle les lentilles expertes de ce mode, cartographie leurs contradictions, synthétise un briefing HTML et un enregistrement Markdown/ADR, puis vérifie de manière contradictoire chaque réclamation par rapport aux sources logicielles PRINCIPALES (documents officiels, RFC, versions GitHub, OSV/CVE, OpenSSF Scorecard, benchmarks) avec détection des versions. Idéal pour les décisions où plusieurs points de vue et des affirmations dont la version est correcte et vérifiée sont importants ; exagéré pour une recherche rapide d'API. Pour les sujets non logiciels, utilisez la recherche approfondie ; pour une matrice de décision notée pure, utilisez une analyse de compromis.
