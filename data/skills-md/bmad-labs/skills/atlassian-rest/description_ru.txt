Взаимодействуйте с Atlassian Jira и Confluence с помощью REST API — сервер MCP не требуется. Используйте этот навык всякий раз, когда пользователь упоминает Jira, Confluence, Atlassian, заявки, проблемы, спринты, невыполненные работы, эпики, истории или любую задачу управления проектом, которая включает в себя создание/редактирование/поиск/переход задач Jira, написание или чтение страниц Confluence, создание отчетов о состоянии, сортировку ошибок, преобразование спецификаций в невыполненные работы, сбор задач из заметок о совещаниях, поиск знаний компании, синхронизацию локальных документов BMAD с Jira или Confluence. отправка документов в Jira, извлечение из Jira или связывание документов с заявками. Также срабатывает, когда пользователь говорит такие вещи, как «переместить эту заявку на выполнение», «каков статус PROJ-123», «создать ошибку для X», «поиск Y в нашей вики», «создать заявку», «проверить наличие дубликатов», «написать обновление статуса», «разбить эту спецификацию на истории», «синхронизировать этот документ», «отправить в jira», «вытащить из jira», «синхронизировать с confluence», «связать это с jira» или «синхронизировать мои эпики». Если есть вероятность, что пользователь захочет взаимодействовать с Jira или Confluence, используйте этот навык.
