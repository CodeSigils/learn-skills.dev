REST API を使用して Atlassian Jira および Confluence と対話します。MCP サーバーは必要ありません。ユーザーが Jira、Confluence、Atlassian、チケット、課題、スプリント、バックログ、エピック、ストーリー、または Jira 課題の作成/編集/検索/移行、Confluence ページの書き込みまたは読み取り、ステータス レポートの生成、バグのトリアージ、バックログへの仕様の変換、会議メモからのタスクのキャプチャ、会社のナレッジの検索、ローカル BMAD ドキュメントの Jira または Confluence との同期、ドキュメントのプッシュを含むプロジェクト管理タスクに言及するたびに、このスキルを使用します。 Jira、Jira からの取得、またはドキュメントとチケットのリンク。また、ユーザーが「そのチケットを完了に移動する」、「PROJ-123 のステータスは何ですか」、「X のバグを作成する」、「Wiki で Y を検索する」、「チケットを提出する」、「重複をチェックする」、「ステータス更新を書く」、「この仕様をストーリーに分割する」、「このドキュメントを同期する」、「JIRA にプッシュする」、「JIRA からプルする」、「Confluence に同期する」、「これをjira」、または「エピックを同期」。ユーザーが Jira または Confluence と対話する可能性がある場合は、このスキルを使用してください。
