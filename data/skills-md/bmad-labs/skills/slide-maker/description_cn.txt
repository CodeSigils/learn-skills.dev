为任何设计系统制作令人印象深刻的、品牌化的端到端演示幻灯片和演示文稿。每当用户想要集思广益、构建、设计、生成、审查或导出幻灯片、幻灯片、演示文稿、推介或公司/产品/销售幻灯片时，请使用此技能。它按照特定于工作的工作流程运行：集体讨论幻灯片的结构，通过审阅循环生成 HTML 幻灯片，然后导出为可编辑的 PPTX、图像 PPTX、独立的 HTML 或 PDF。它与设计系统无关——它使用用户自己的设计系统（如果有的话），“nextlevelbuilder/ui-ux-pro-max-skill”建议（如果已安装），或捆绑的中性默认主题——并从设计令牌（从不硬编码颜色或字体）驱动一切。它提供了一个令牌驱动的品牌套件（令牌、字体、徽标、34 个预制布局）、一个令人惊叹的工艺指南、一个防倾斜验证器、一个现成的 React 甲板模板、指向和评论编辑模式以及一个经过验证的可编辑 PPTX 管道。它还可以仅向另一个幻灯片生成器提供设计层（标记、组件、图案），因此其输出使用真实的设计系统而不是通用主题。
