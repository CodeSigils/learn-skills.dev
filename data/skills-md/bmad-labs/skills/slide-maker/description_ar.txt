قم بإنشاء شرائح وعروض تقديمية مثيرة للإعجاب خاصة بالعلامة التجارية من البداية إلى النهاية لأي نظام تصميم. استخدم هذه المهارة عندما يريد المستخدم تبادل الأفكار أو إنشاء أو تصميم أو إنشاء أو مراجعة أو تصدير شريحة أو مجموعة عرض تقديمي أو عرض تقديمي أو عرض تقديمي للشركة/المنتج/المبيعات. يتم تشغيله كسير عمل خاص بالمهمة: تبادل الأفكار حول بنية المجموعة، وإنشاء مجموعة HTML باستخدام حلقة مراجعة، والتصدير إلى PPTX القابل للتحرير، أو PPTX للصور، أو HTML مستقل، أو PDF. إنه لا يعتمد على نظام التصميم - فهو يستخدم نظام التصميم الخاص بالمستخدم إذا كان لديه واحد، أو اقتراح "nextlevelbuilder/ui-ux-pro-max-skill" إذا كان مثبتًا، أو سمة افتراضية محايدة مجمعة - ويحرك كل شيء بدءًا من رموز التصميم المميزة (وليس الألوان أو الخطوط المشفرة أبدًا). إنه يشحن مجموعة علامات تجارية تعتمد على الرمز المميز (الرموز المميزة، والخطوط، والشعارات، و34 تخطيطًا مُعدًا مسبقًا)، ودليل حرفي "رائع"، ومدقق مضاد للانزلاق، وقالب React Deck جاهز، ووضع تحرير الإشارة والتعليق، وخط أنابيب PPTX قابل للتحرير تم التحقق منه. ويمكنه أيضًا توفير طبقة التصميم فقط (الرموز المميزة والمكونات والأنماط) لمولد شرائح آخر بحيث يستخدم مخرجاته نظام تصميم حقيقي بدلاً من سمة عامة.
