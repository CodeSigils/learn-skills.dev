Cree impresionantes diapositivas y presentaciones de marca de principio a fin, para CUALQUIER sistema de diseño. Utilice esta habilidad siempre que el usuario quiera realizar una lluvia de ideas, crear, diseñar, generar, revisar o exportar una diapositiva, presentación, propuesta o presentación de empresa/producto/ventas. Se ejecuta como FLUJOS DE TRABAJO específicos del trabajo: realice una lluvia de ideas sobre la estructura de una plataforma, genere la plataforma HTML con un bucle de revisión y exporte a PPTX editable, PPTX de imágenes, HTML independiente o PDF. Es independiente del sistema de diseño: utiliza el propio sistema de diseño del usuario si tiene uno, una sugerencia `nextlevelbuilder/ui-ux-pro-max-skill` si está instalado, o un tema neutral predeterminado incluido, y maneja todo desde tokens de diseño (nunca colores o fuentes codificados). Incluye un kit de marca basado en tokens (tokens, fuentes, logotipos, 34 diseños prediseñados), una guía de artesanía "wow", un validador anti-slop, una plantilla de plataforma React lista para usar, modo de edición de apuntar y comentar y un canal PPTX editable validado. También puede suministrar solo la capa de diseño (tokens, componentes, patrones) a otro generador de diapositivas para que su salida utilice un sistema de diseño real en lugar de un tema genérico.
