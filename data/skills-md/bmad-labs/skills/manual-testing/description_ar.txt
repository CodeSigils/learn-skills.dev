تخطيط الاختبار اليدوي وكتابة ومراجعة وتنفيذ وصيانة حالات الاختبار. يُستخدم عندما: يطلب المستخدم كتابة حالات اختبار، أو إنشاء خطة اختبار، أو تشغيل اختبارات يدوية، أو مراجعة تغطية الاختبار، أو تحديث الاختبارات بعد تغيير الميزات، أو يسأل "كيف يمكنني اختبار ذلك". يتم التشغيل أيضًا بعد تنفيذ الميزات التي تغير سلوك النظام - وفقًا لـ CLAUDE.md، يعد تحديث خطة الاختبار اليدوي أمرًا إلزاميًا. يغطي واجهة برمجة التطبيقات/الواجهة الخلفية، والواجهة الأمامية، وخطوط الأنابيب/سير العمل، والذكاء الاصطناعي/LLM، وأنماط اختبار البنية التحتية.
