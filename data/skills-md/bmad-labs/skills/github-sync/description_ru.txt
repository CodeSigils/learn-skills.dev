Двунаправленная синхронизация между артефактами планирования BMAD и GitHub Projects v2. Используйте этот навык всякий раз, когда пользователь говорит «синхронизировать с github», «отправлять истории», «извлекать статус из github», «настраивать проект github», «синхронизировать github», «встроить проект github», «создавать задачи github из историй», «обновлять истории из github», «синхронизировать статус» или хочет управлять артефактами BMAD в проектах GitHub. Также срабатывает, когда пользователь упоминает «проект gh», «доску github», «доску спринта», «дорожную карту проекта», «поле отношений», «заблокировано» или «родительскую проблему» в контексте артефактов BMAD. Запускайте по неявным сигналам, таким как «Я хочу отслеживать истории в github», «давайте создадим доску проекта», «что не синхронизировано», «перенесем спринт на github».
