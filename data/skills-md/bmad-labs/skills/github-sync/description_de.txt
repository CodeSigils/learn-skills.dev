Bidirektionale Synchronisierung zwischen BMAD-Planungsartefakten und GitHub Projects v2. Verwenden Sie diesen Skill immer dann, wenn der Benutzer „Mit Github synchronisieren“, „Stories übertragen“, „Status von Github abrufen“, „Github-Projekt einrichten“, „Github-Synchronisierung“, „Github-Projekt integrieren“, „Github-Probleme aus Storys erstellen“, „Storys von Github aktualisieren“, „Status synchronisieren“ sagt oder BMAD-Artefakte in GitHub-Projekten verwalten möchte. Wird auch ausgelöst, wenn der Benutzer „GH-Projekt“, „Github-Board“, „Sprint-Board“, „Projekt-Roadmap“, „Beziehungsfeld“, „Blockiert von“ oder „Übergeordnetes Problem“ im Kontext von BMAD-Artefakten erwähnt. Lösen Sie auf impliziten Hinweisen wie „Ich möchte Geschichten in Github verfolgen“, „Lassen Sie uns ein Projektboard einrichten“, „Was ist nicht synchron“ oder „Sprint auf Github verschieben“ aus.
