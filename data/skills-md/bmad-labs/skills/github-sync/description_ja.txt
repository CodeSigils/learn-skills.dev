BMAD 計画アーティファクトと GitHub プロジェクト v2 間の双方向同期。ユーザーが「github に同期する」、「ストーリーをプッシュする」、「github からステータスを取得する」、「github プロジェクトをセットアップする」、「github 同期」、「オンボード github プロジェクト」、「ストーリーから github の課題を作成する」、「github からストーリーを更新する」、「ステータスを同期する」と言う場合、または GitHub プロジェクトの BMAD アーティファクトを管理したい場合は、このスキルを使用します。また、ユーザーが BMAD アーティファクトのコンテキストで「gh プロジェクト」、「github ボード」、「スプリント ボード」、「プロジェクト ロードマップ」、「関係フィールド」、「ブロックされている」、または「親問題」に言及したときにもトリガーされます。 「github でストーリーを追跡したい」、「プロジェクトボードをセットアップしよう」、「何が同期していないのか」、「スプリントを github にプッシュする」などの暗黙的な合図をトリガーします。
