أنشئ صفحات ويب احترافية وعالية الجودة متحركة تصور بنية البرنامج أو تصميم النظام أو نماذج البيانات أو فكرة المنتج - باستخدام Three.js (ثلاثي الأبعاد) + GSAP (التمرير/الرسوم المتحركة) + مخططات SVG. يُنتج شيئين، عادةً معًا: (1) صفحة مقصودة لقصة تمرير سينمائية حيث يروي عالم ثلاثي الأبعاد منخفض التضليع كيفية عمل النظام، و(2) خريطة معمارية تفاعلية مع "عدسات" متراكبة قابلة للتحويل، ومخططات مكونات قابلة للنقر، ووحدات ERDs على شكل قدم الغراب. يأتي كل مخرج مزودًا بوضع تحرير مدمج حتى يتمكن الإنسان من النقر فوق المكونات / قص المناطق / اختيار كائنات ثلاثية الأبعاد وجمع التعليقات المرئية مباشرةً إليك. استخدم هذه المهارة عندما يريد المستخدم تصور أو تقديم أو "عرض" أو تحريك أو إنشاء صفحة تفاعلية لهندسة معمارية أو تصميم نظام أو مفهوم تقني أو نموذج بيانات أو خط أنابيب أو قصة منتج - بما في ذلك عبارات مثل "صفحة المقدمة" أو "تصور البنية" أو "المخطط التفاعلي" أو "سرد التمرير" أو "خريطة النظام ثلاثية الأبعاد" أو "صفحة ERD" أو "إرشادات التصميم" أو "اجعل بنيتنا تبدو مثيرة للإعجاب" أو "تقديم هذا التصميم لأصحاب المصلحة". تفضل هذه المهارة على التدوير اليدوي لـ Three.js/GSAP من البداية - فهي تجمع بين القوالب التي تم اختبارها في المعركة، ودليل التصميم/مقاومة الانزلاق، وكتالوج تخطيط المخططات، واتفاقية التعليمات البرمجية القابلة للتعديل بواسطة الذكاء الاصطناعي التي تم تعلمها من بناء حقيقي طويل.
