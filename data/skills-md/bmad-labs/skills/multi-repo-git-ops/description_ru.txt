Управляет операциями git (ветвление, фиксация, отправка) в системах с несколькими репозиториями с помощью подмодулей git. Используйте этот навык всякий раз, когда пользователь хочет создать ветку функции, зафиксировать изменения, отправить код, синхронизировать подмодули или управлять ветвями в родительском репозитории и репозиториях служб. Также используйте при реализации историй BMAD, которые затрагивают одну или несколько служб, или когда пользователь спрашивает о рабочем процессе git в проекте с несколькими репозиториями. Запускается по таким фразам, как «создать ветку», «фиксировать изменения», «отправить на удаленный компьютер», «синхронизировать подмодули», «начать работу над историей», «обновить ветку службы» или любую операцию git, которая охватывает репозитории родительских и подмодулей.
