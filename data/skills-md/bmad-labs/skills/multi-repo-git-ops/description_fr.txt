Gère les opérations git (branchement, validation, push) sur les systèmes multi-dépôts avec des sous-modules git. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer une branche de fonctionnalités, valider des modifications, pousser du code, synchroniser des sous-modules ou gérer des branches dans le dépôt parent et le dépôt de service. À utiliser également lors de la mise en œuvre d'histoires BMAD qui touchent un ou plusieurs services, ou lorsque l'utilisateur pose des questions sur le workflow git dans un projet multi-dépôt. Se déclenche sur des expressions telles que « créer une branche », « valider les modifications », « envoyer à distance », « synchroniser les sous-modules », « commencer à travailler sur l'histoire », « mettre à jour la branche de service » ou toute opération git qui s'étend sur les dépôts parents et sous-modules.
