Verwaltet Git-Operationen (Branching, Commit, Push) über Multi-Repo-Systeme hinweg mit Git-Submodulen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen Feature-Branch erstellen, Änderungen festschreiben, Code pushen, Submodule synchronisieren oder Branches im übergeordneten Repo und Service-Repo verwalten möchte. Verwenden Sie es auch, wenn Sie BMAD-Stories implementieren, die einen oder mehrere Dienste betreffen, oder wenn der Benutzer nach dem Git-Workflow in einem Multi-Repo-Projekt fragt. Wird durch Ausdrücke wie „Zweig erstellen“, „Änderungen festschreiben“, „Auf Remote übertragen“, „Untermodule synchronisieren“, „Mit der Arbeit an der Story beginnen“, „Dienstzweig aktualisieren“ oder jede Git-Operation ausgelöst, die sich über übergeordnete und untergeordnete Modul-Repos erstreckt.
