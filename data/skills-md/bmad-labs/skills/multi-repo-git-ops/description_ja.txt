git サブモジュールを使用して、マルチリポジトリ システム全体での git 操作 (分岐、コミット、プッシュ) を管理します。ユーザーが機能ブランチの作成、変更のコミット、コードのプッシュ、サブモジュールの同期、または親リポジトリとサービス リポジトリにわたるブランチの管理を行う場合は、このスキルを使用します。 1 つ以上のサービスに関わる BMAD ストーリーを実装する場合、またはユーザーがマルチリポジトリ プロジェクトの git ワークフローについて質問する場合にも使用します。 「ブランチの作成」、「変更のコミット」、「リモートへのプッシュ」、「サブモジュールの同期」、「ストーリーの作業開始」、「サービス ブランチの更新」などのフレーズ、または親とサブモジュールのリポジトリにまたがる Git 操作でトリガーされます。
