Gestisce le operazioni git (ramificazione, commit, push) su sistemi multi-repo con sottomoduli git. Utilizza questa competenza ogni volta che l'utente desidera creare un ramo di funzionalità, eseguire il commit di modifiche, eseguire il push del codice, sincronizzare i sottomoduli o gestire i rami nel repository padre e nei repository di servizio. Da utilizzare anche quando si implementano storie BMAD che toccano uno o più servizi o quando l'utente chiede informazioni sul flusso di lavoro git in un progetto multi-repo. Si attiva su frasi come "crea ramo", "salva modifiche", "push to remote", "sincronizza sottomoduli", "inizia a lavorare sulla storia", "aggiorna ramo servizio" o qualsiasi operazione git che si estende su repository padre e sottomodulo.
