يدير عمليات git (التفريع والالتزام والدفع) عبر أنظمة الريبو المتعددة باستخدام وحدات git الفرعية. استخدم هذه المهارة عندما يريد المستخدم إنشاء فرع ميزات، أو الالتزام بالتغييرات، أو دفع التعليمات البرمجية، أو مزامنة الوحدات الفرعية، أو إدارة الفروع عبر مستودعات الريبو الأصلية ومستودعات الخدمة. يُستخدم أيضًا عند تنفيذ قصص BMAD التي تتناول خدمة واحدة أو أكثر، أو عندما يسأل المستخدم عن سير عمل git في مشروع متعدد الريبو. يتم تشغيل عبارات مثل "إنشاء فرع"، أو "إجراء تغييرات"، أو "الدفع إلى جهاز التحكم عن بعد"، أو "مزامنة الوحدات الفرعية"، أو "بدء العمل على القصة"، أو "تحديث فرع الخدمة"، أو أي عملية git تمتد إلى عمليات إعادة الشراء الرئيسية والوحدة الفرعية.
