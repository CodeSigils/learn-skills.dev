Gestiona operaciones de git (ramificación, confirmación, inserción) en sistemas de repositorios múltiples con submódulos de git. Utilice esta habilidad siempre que el usuario quiera crear una rama de funciones, confirmar cambios, enviar código, sincronizar submódulos o administrar ramas en el repositorio principal y en los repositorios de servicios. Utilícelo también al implementar historias de BMAD que afecten a uno o más servicios, o cuando el usuario pregunte sobre el flujo de trabajo de git en un proyecto de repositorios múltiples. Se activan frases como "crear rama", "confirmar cambios", "enviar a control remoto", "sincronizar submódulos", "comenzar a trabajar en la historia", "actualizar rama de servicio" o cualquier operación de git que abarque repositorios principales y de submódulos.
