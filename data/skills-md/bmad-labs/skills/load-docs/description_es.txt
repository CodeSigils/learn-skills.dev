Carga documentos completamente en el contexto del agente principal para que el agente pueda responder preguntas, resumir o trabajar con ese contenido en turnos posteriores. Úselo siempre que el usuario quiera ingerir, leer, estudiar, revisar, absorber o extraer documentos, especialmente cuando dice cosas como "cargar estos documentos", "leer todos estos", "ingerir esta carpeta", "extraer estos PDF", "cargar todos los documentos en X" o pegar una lista de rutas de archivo/URL y pedirle que los lea. Maneja archivos locales (texto, código, rebajas, PDF, cuadernos, imágenes), carpetas completas (recursivamente) y URL remotas. La habilidad es de un solo turno: una vez que el agente informa "HECHO", se desactiva hasta que el usuario la invoca nuevamente.
