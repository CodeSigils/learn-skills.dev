Google のリリースをセットアップして構成します。自動バージョニング、変更ログの生成、GitHub Actions 経由の公開を可能にします。パイプラインの作成、従来のコミットのフォーマット、リリース前ワークフロー、モノリポジトリ構成、リリース パイプラインのトラブルシューティングについて説明します。ユーザーがリリースの自動化、公開用の CI/CD の設定、バージョン バンピングの構成、リリースと互換性のあるコミット メッセージの作成、バージョンの自動タグ付け、npm/PyPI/crates.io/Maven/Docker への公開、またはリリース PR が作成されなかった理由のトラブルシューティングを行う場合は、常にこのスキルを使用します。ユーザーが名前で「リリースしてください」と言及していなくてもアクティブ化します。「npm リリースを自動化する」、「公開用に GitHub Actions を設定する」、「バージョンに自動的にタグを付ける方法」、「変更ログの生成」、「サーバーの自動化」、または「リリース前のワークフロー」などのフレーズはすべて、このスキルを示しています。特にコミット メッセージのガイダンスについては、このスキルはリリースプリーズ互換の規則に焦点を当てています。サブモジュールを使用したより広範なマルチリポジトリの git 操作については、代わりに multi-repo-git-ops に従います。
