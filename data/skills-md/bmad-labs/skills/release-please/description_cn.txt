设置和配置 Google 的发布版本，以便通过 GitHub Actions 进行自动版本控制、变更日志生成和发布。涵盖管道创建、常规提交格式化、预发布工作流程、monorepo 配置以及发布管道故障排除。每当用户想要自动发布、设置 CI/CD 进行发布、配置版本冲突、编写与发布兼容的提交消息、自动标记版本、发布到 npm/PyPI/crates.io/Maven/Docker 或排除未创建发布 PR 的故障时，请使用此技能。即使用户没有提及“release-please”的名称，也可以激活 — 像“自动化我的 npm 版本”、“设置 GitHub Actions 进行发布”、“如何自动标记版本”、“变更日志生成”、“semver 自动化”或“预发布工作流程”等短语都表明了此技能。特别是对于提交消息指导，该技能重点关注发布兼容约定；对于更广泛的带有子模块的多存储库 git 操作，请改为使用 multi-repo-git-ops。
