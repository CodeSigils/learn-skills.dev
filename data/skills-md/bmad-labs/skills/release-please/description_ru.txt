Настройте и настройте выпуск Google для автоматического управления версиями, создания журнала изменений и публикации через GitHub Actions. Охватывает создание конвейера, форматирование обычных коммитов, рабочие процессы предварительной версии, настройку монорепозитория и устранение неполадок конвейеров выпуска. Используйте этот навык всякий раз, когда пользователь хочет автоматизировать выпуски, настроить CI/CD для публикации, настроить обновление версий, написать сообщения о фиксации, совместимые с релизом, автоматически пометить версии, опубликовать в npm/PyPI/crates.io/Maven/Docker или устранить неполадки, почему не был создан PR релиза. Активируйте, даже если пользователь не упоминает «выпустите-пожалуйста» по имени — такие фразы, как «автоматизировать мои выпуски npm», «настроить действия GitHub для публикации», «как автоматически помечать версии», «создание журнала изменений», «автоматизация semver» или «рабочий процесс перед выпуском» — все это указывает на этот навык. В частности, для руководства по сообщениям о фиксации этот навык фокусируется на соглашениях, совместимых с релизом; для более широких операций git с несколькими репозиториями с подмодулями вместо этого отложите использование multi-repo-git-ops.
