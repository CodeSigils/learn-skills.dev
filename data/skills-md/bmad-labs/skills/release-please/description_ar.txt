قم بإعداد وتكوين إصدار Google - من فضلك للإصدار الآلي، وإنشاء سجل التغيير، والنشر عبر GitHub Actions. يغطي إنشاء خط الأنابيب، وتنسيق الالتزامات التقليدية، وسير عمل ما قبل الإصدار، وتكوين monorepo، واستكشاف أخطاء خطوط أنابيب الإصدار وإصلاحها. استخدم هذه المهارة عندما يريد المستخدم أتمتة الإصدارات، أو إعداد CI/CD للنشر، أو تكوين زيادة الإصدار، أو كتابة رسائل الالتزام المتوافقة مع الإصدار، أو وضع علامة على الإصدارات تلقائيًا، أو النشر على npm/PyPI/crates.io/Maven/Docker، أو استكشاف أخطاء سبب عدم إنشاء العلاقات العامة للإصدار وإصلاحها. قم بالتنشيط حتى لو لم يذكر المستخدم "الإصدار من فضلك" بالاسم - عبارات مثل "أتمتة إصدارات npm الخاصة بي"، أو "إعداد إجراءات GitHub للنشر"، أو "كيف أقوم بوضع علامة على الإصدارات تلقائيًا"، أو "إنشاء سجل التغيير"، أو "أتمتة شبه نهائية"، أو "سير عمل ما قبل الإصدار" كلها تشير إلى هذه المهارة. للحصول على إرشادات بشأن رسالة الالتزام على وجه التحديد، تركز هذه المهارة على الاصطلاحات المتوافقة مع الإصدار من فضلك؛ بالنسبة لعمليات git متعددة الريبو الأوسع مع الوحدات الفرعية، قم بالتأجيل إلى عمليات repo-git-ops المتعددة بدلاً من ذلك.
