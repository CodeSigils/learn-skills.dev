Installez et configurez la version de Google pour la gestion automatisée des versions, la génération du journal des modifications et la publication via GitHub Actions. Couvre la création de pipelines, le formatage des commits conventionnels, les workflows de pré-version, la configuration monorepo et le dépannage des pipelines de publication. Utilisez cette compétence chaque fois que l'utilisateur souhaite automatiser les versions, configurer CI/CD pour la publication, configurer le remplacement de version, écrire des messages de validation compatibles avec la version, marquer automatiquement les versions, publier sur npm/PyPI/crates.io/Maven/Docker ou dépanner pourquoi une version PR n'a pas été créée. Activez même si l'utilisateur ne mentionne pas « release-please » par son nom – des expressions telles que « automatiser mes versions npm », « configurer les actions GitHub pour la publication », « comment marquer automatiquement les versions », « génération de journal des modifications », « automatisation semver » ou « workflow de pré-version » indiquent toutes cette compétence. Pour les conseils sur les messages de validation en particulier, cette compétence se concentre sur les conventions compatibles avec la version release please ; pour des opérations git multi-repo plus larges avec des sous-modules, reportez-vous plutôt à multi-repo-git-ops.
