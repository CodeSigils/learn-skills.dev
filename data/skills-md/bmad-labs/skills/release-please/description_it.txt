Imposta e configura la versione di Google per il controllo delle versioni automatico, la generazione del registro delle modifiche e la pubblicazione tramite GitHub Actions. Copre la creazione di pipeline, la formattazione di commit convenzionali, i flussi di lavoro di pre-rilascio, la configurazione di monorepo e la risoluzione dei problemi delle pipeline di rilascio. Utilizza questa competenza ogni volta che l'utente desidera automatizzare i rilasci, impostare CI/CD per la pubblicazione, configurare il bumping della versione, scrivere messaggi di commit release-please-compatibili, taggare automaticamente le versioni, pubblicare su npm/PyPI/crates.io/Maven/Docker o risolvere il motivo per cui un PR di rilascio non è stato creato. Attiva anche se l'utente non menziona "release-please" per nome: frasi come "automatizza i miei rilasci npm", "imposta le azioni GitHub per la pubblicazione", "come taggo automaticamente le versioni", "generazione del changelog", "automazione semver" o "flusso di lavoro pre-rilascio" indicano tutte questa abilità. Nello specifico, per la guida ai messaggi di commit, questa competenza si concentra sulle convenzioni compatibili con il rilascio; per operazioni git multi-repo più ampie con sottomoduli, rimandare invece a multi-repo-git-ops.
