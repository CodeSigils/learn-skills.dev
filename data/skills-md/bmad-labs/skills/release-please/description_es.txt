Instale y configure el lanzamiento de Google para control de versiones automatizado, generación de registros de cambios y publicación a través de GitHub Actions. Cubre la creación de canalizaciones, el formato de confirmaciones convencionales, los flujos de trabajo previos al lanzamiento, la configuración de monorepo y la solución de problemas de canalizaciones de lanzamiento. Utilice esta habilidad siempre que el usuario quiera automatizar lanzamientos, configurar CI/CD para publicación, configurar el aumento de versiones, escribir mensajes de confirmación compatibles con el lanzamiento, etiquetar versiones automáticamente, publicar en npm/PyPI/crates.io/Maven/Docker o solucionar problemas por los que no se creó un PR de lanzamiento. Actívelo incluso si el usuario no menciona "liberar por favor" por su nombre: frases como "automatizar mis lanzamientos de npm", "configurar acciones de GitHub para publicación", "cómo etiqueto las versiones automáticamente", "generación de registros de cambios", "automatización de semver" o "flujo de trabajo previo al lanzamiento" indican esta habilidad. Para obtener orientación sobre mensajes de confirmación específicamente, esta habilidad se centra en convenciones compatibles con la liberación por favor; para operaciones git de múltiples repositorios más amplias con submódulos, difiera a multi-repo-git-ops.
