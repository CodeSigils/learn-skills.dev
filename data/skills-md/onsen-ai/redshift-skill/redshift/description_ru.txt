Используйте всякий раз, когда пользователь упоминает Redshift, DWH, хранилище данных, запросы SQL, исследование схемы, метаданные таблиц, генерацию DDL, список столбцов, использование диска, профилирование данных, бизнес-анализ или хочет изучить объекты базы данных. Также используйте для локальной аналитики ранее сохраненных результатов запроса. Работает в любом кластере Redshift или бессерверной рабочей группе без необходимости просмотра прав администратора. Всегда используйте этот навык для любых задач, связанных с Redshift, даже для простых запросов SELECT.
