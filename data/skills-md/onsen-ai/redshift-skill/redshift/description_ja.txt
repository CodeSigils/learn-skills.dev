Data API を介して AWS Redshift クラスターまたはサーバーレス ワークグループにクエリを実行します。ユーザーが Redshift、DWH、データ ウェアハウス、SQL クエリ、スキーマ探索、テーブル メタデータ、DDL 生成、列リスト、ディスク使用量、データ プロファイリング、ビジネス分析について言及する場合、またはデータベース オブジェクトを探索したい場合に使用します。以前に保存したクエリ結果のローカル分析にも使用します。管理者ビューは必要なく、あらゆる Redshift クラスターまたはサーバーレス ワークグループで動作します。単純な SELECT クエリであっても、Redshift 関連のタスクには常にこのスキルを使用してください。
