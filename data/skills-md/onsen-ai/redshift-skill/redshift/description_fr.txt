Interrogez n'importe quel cluster AWS Redshift ou groupe de travail sans serveur via l'API Data. À utiliser chaque fois que l'utilisateur mentionne Redshift, DWH, l'entrepôt de données, les requêtes SQL, l'exploration de schémas, les métadonnées de table, la génération DDL, la liste des colonnes, l'utilisation du disque, le profilage des données, l'analyse commerciale ou souhaite explorer des objets de base de données. Utilisez également pour l'analyse locale des résultats de requêtes précédemment enregistrés. Fonctionne sur n'importe quel cluster Redshift ou groupe de travail sans serveur sans aucune vue d'administrateur requise. Utilisez toujours cette compétence pour toute tâche liée à Redshift, même pour les simples requêtes SELECT.
