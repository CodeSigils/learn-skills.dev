تطوير Metabase BI الشامل: تصميم وبناء وإدارة لوحات المعلومات والأسئلة (البطاقات) والمقتطفات والمجموعات. استخدم هذه المهارة عندما يذكر المستخدم قاعدة التعريف، أو إنشاء لوحة المعلومات، أو لوحة معلومات BI، أو لوحة معلومات التحليلات، أو سؤال قاعدة التعريف، أو بطاقة قاعدة التعريف، أو استعلام MBQL، أو سؤال SQL الأصلي، أو مقتطف قاعدة التعريف، أو مجموعة قاعدة التعريف، أو إعدادات التمثيل المرئي، أو مرشحات لوحة المعلومات، أو تعيينات المعلمات، أو يريد إنشاء/تحرير/إدارة أي محتوى لقاعدة التعريف. يُستخدم أيضًا عندما يريد المستخدم إنشاء لوحة معلومات إعداد التقارير، أو بطاقة أداء مؤشرات الأداء الرئيسية، أو لوحة معلومات التداول، أو أداة استكشاف البيانات المدعومة بقاعدة بيانات SQL. يغطي تنسيق المخطط، وتنسيق الأرقام، والتنسيق الشرطي، وتخطيط لوحة المعلومات، ودورة الحياة الكاملة: المتطلبات ← التصميم ← تطوير SQL ← التنفيذ ← الاختبار. يعمل مع مثيلات قاعدة التعريف المتعددة. استخدم هذه المهارة دائمًا في أي مهمة متعلقة بقاعدة التعريف.
