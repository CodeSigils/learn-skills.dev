Sviluppo BI metabase end-to-end: progettazione, creazione e gestione di dashboard, domande (schede), frammenti e raccolte. Utilizza questa competenza ogni volta che l'utente menziona metabase, creazione di dashboard, dashboard BI, dashboard di analisi, domanda sulla metabase, scheda metabase, query MBQL, domanda SQL nativa, snippet di metabase, raccolta di metabase, impostazioni di visualizzazione, filtri di dashboard, mappature di parametri o desidera creare/modificare/gestire qualsiasi contenuto della metabase. Da utilizzare anche quando l'utente desidera creare un dashboard di reporting, una scorecard KPI, un dashboard di trading o uno strumento di esplorazione dei dati supportato da un database SQL. Copre la formattazione dei grafici, la formattazione dei numeri, la formattazione condizionale, il layout del dashboard e l'intero ciclo di vita: requisiti → progettazione → sviluppo SQL → implementazione → test. Funziona con più istanze della metabase. Utilizza sempre questa competenza per qualsiasi attività relativa a Metabase.
