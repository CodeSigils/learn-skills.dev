Навык управления задачами проекта в гибридной структуре «task.md (обзор) + каталог задач/ (отдельные файлы задач)». Добавление новых задач, обновление журналов выполнения во время работы и обработка завершения задач (включая обновление флажка в Task.md) выполняются в едином формате. Он всегда будет срабатывать для таких запросов, как «добавить задачу», «задача в Task.md», «создать файл в Tasks/», «записать прогресс», «эта задача выполнена, поэтому процесс завершен», «создать файл задачи». При каждом касании любого файла Task.md, каталога Tasks/ или отдельного файла задачи следует соблюдать правила этого навыка, даже если пользователь не указал их явно.
