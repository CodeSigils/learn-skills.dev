“task.md(개요) + task/디렉토리(개별 작업 파일)”의 하이브리드 구조로 프로젝트 작업 관리를 운영하는 스킬입니다. 새 작업 추가, 작업 중 진행 로그 업데이트, 작업 완료 처리(task.md의 확인란 업데이트 포함)는 일관된 형식으로 수행됩니다. "작업 추가", "task.md의 작업", "tasks/에서 파일 생성", "진행 기록", "이 작업이 완료되었으므로 프로세스 완료", "작업 파일 생성"과 같은 요청에 대해 항상 트리거됩니다. task.md, task/ 디렉터리 또는 개별 작업 파일을 터치할 때마다 사용자가 명시적으로 지정하지 않더라도 이 스킬의 규칙을 따라야 합니다.
