Capacità di gestire la gestione delle attività di progetto in una struttura ibrida di "task.md (panoramica) + directory task/ (file di attività individuali). Gestisce l'aggiunta di nuove attività, l'aggiornamento dei registri di avanzamento durante il lavoro e l'elaborazione del completamento delle attività (incluso l'aggiornamento delle caselle di controllo in task.md) in un formato coerente. Viene sempre attivato da richieste come "aggiungi un'attività", "aggiungi attività a task.md", "crea un file in task/", "registra l'avanzamento", "questa attività è completata, gestisci il completamento" o "crea un file di attività." Ogni volta che viene toccato task.md, la directory task/ o un singolo file di attività, è necessario seguire le regole di questa abilità anche se l'utente non le specifica esplicitamente.
