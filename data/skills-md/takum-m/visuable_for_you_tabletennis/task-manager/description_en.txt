Skill for operating project task management in a hybrid structure of “task.md (overview) + tasks/ directory (individual task files)”. Adding new tasks, updating progress logs during work, and handling task completion (including updating the checkbox in task.md) are performed in a consistent format. It will always be triggered for requests such as “add a task”, “task in task.md”, “create a file in tasks/”, “record progress”, “this task is done, so process completion”, “create task file”. Whenever any of task.md, the tasks/ directory, or an individual task file is touched, this skill’s rules should be followed even if the user does not explicitly specify it.
