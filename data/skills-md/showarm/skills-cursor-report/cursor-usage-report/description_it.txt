Genera un report Excel con stile sull'utilizzo del cursore per sessione per un determinato mese o intervallo di date. Legge i log delle sessioni JSONL da ~/.cursor/projects/**/agent-transcripts/, estrae gli eventi di utilizzo a livello di token da api2.cursor.sh (utilizzando il token di accesso IDE locale in vscdb), attribuisce gli eventi alle sessioni in base al timestamp, riepiloga ogni sessione tramite cursor-agent (Haiku) e genera un XLSX sul desktop. Utilizzalo quando l'utente richiede un rapporto sull'utilizzo del cursore: frasi come "帮我总结X月份我的cursor报告", "总结我X月份的Cursor使用", "出X月Cursor报表", "我这个月在Cursor里做了什么", "riepiloga l'utilizzo del cursore per [periodo]".
