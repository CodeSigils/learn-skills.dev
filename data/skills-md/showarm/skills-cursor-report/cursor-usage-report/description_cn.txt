生成给定月份或日期范围内按会话划分的光标使用情况的样式 Excel 报告。从 ~/.cursor/projects/**/agent-transcripts/ 读取 JSONL 会话日志，从 api2.cursor.sh 中提取令牌级别使用事件（使用 vscdb 中的本地 IDE 访问令牌），按时间戳将事件归属到会话，通过游标代理 (Haiku) 总结每个会话，并将 XLSX 输出到桌面。当用户请求光标使用报告时使用此选项 - 诸如“帮我总结 X 月份我的光标报告”、“总结我 X 月份的光标使用情况”、“出 X 月光标报表”、“我这个月在光标里做了什么”、“总结 [期间] 的光标使用情况”之类的短语。
