Создайте стилизованный отчет Excel об использовании курсора по сеансам за определенный месяц или диапазон дат. Считывает журналы сеансов JSONL из ~/.cursor/projects/**/agent-transcripts/, извлекает события использования на уровне токена из api2.cursor.sh (используя локальный токен доступа IDE в vscdb), приписывает события сеансам по меткам времени, суммирует каждый сеанс через курсор-агент (Haiku) и выводит XLSX на рабочий стол. Используйте это, когда пользователь запрашивает отчет об использовании курсора — такие фразы, как «帮我总结X月份我的cursor报告», «总结我X月份的Cursor使用», «出X月Cursor报表», «我这个月在Cursor里做了什么», «подведите итоги по использованию курсора за [период]».
