Genere un informe Excel con estilo del uso del cursor por sesión para un mes o rango de fechas determinado. Lee registros de sesión JSONL de ~/.cursor/projects/**/agent-transcripts/, extrae eventos de uso a nivel de token de api2.cursor.sh (usando el token de acceso IDE local en vscdb), atribuye eventos a las sesiones por marca de tiempo, resume cada sesión a través del cursor-agent (Haiku) y genera un XLSX en el escritorio. Utilícelo cuando el usuario solicite un informe de uso del cursor: frases como "帮我总结X月份我的cursor报告", "总结我X月份的Cursor使用", "出X月Cursor报表", "我这个月在Cursor里做了什么", "resume el uso del cursor durante [punto]".
