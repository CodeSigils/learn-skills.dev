Erstellen Sie einen formatierten Excel-Bericht über die Cursornutzung pro Sitzung für einen bestimmten Monat oder Datumsbereich. Liest JSONL-Sitzungsprotokolle aus ~/.cursor/projects/**/agent-transcripts/, ruft Nutzungsereignisse auf Token-Ebene aus api2.cursor.sh ab (unter Verwendung des lokalen IDE-Zugriffstokens in vscdb), ordnet Ereignisse Sitzungen anhand eines Zeitstempels zu, fasst jede Sitzung über den Cursor-Agent (Haiku) zusammen und gibt eine XLSX-Datei auf dem Desktop aus. Verwenden Sie dies, wenn der Benutzer einen Cursor-Nutzungsbericht anfordert – Ausdrücke wie „帮我总结X月份我的cursor报告“, „总结我X月份的Cursor使用“, „出X月Cursor报表“, „我这个月在Cursor里做了什么“, „Fasse meine Cursor-Nutzung für [Zeitraum] zusammen“.
