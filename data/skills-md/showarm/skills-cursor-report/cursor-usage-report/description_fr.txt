Générez un rapport Excel stylisé sur l'utilisation du curseur par session pour un mois ou une plage de dates donnée. Lit les journaux de session JSONL à partir de ~/.cursor/projects/**/agent-transcripts/, extrait les événements d'utilisation au niveau du jeton à partir de api2.cursor.sh (en utilisant le jeton d'accès IDE local dans vscdb), attribue les événements aux sessions par horodatage, résume chaque session via l'agent de curseur (Haiku) et génère un XLSX sur le bureau. Utilisez-le lorsque l'utilisateur demande un rapport d'utilisation du curseur - des expressions telles que "帮我总结X月份我的cursor报告", "总结我X月份的Cursor使用", "出X月Cursor报表", "我这个月在Cursor里做了什么", "résumer mon utilisation du curseur pendant [période]".
