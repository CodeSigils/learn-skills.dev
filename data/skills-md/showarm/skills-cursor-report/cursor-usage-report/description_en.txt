Generate a styled Excel report of Cursor usage by session for a given month or date range. Reads JSONL session logs from ~/.cursor/projects/**/agent-transcripts/, pulls token-level usage events from api2.cursor.sh (using the local IDE access token in vscdb), attributes events to sessions by timestamp, summarizes each session via cursor-agent (Haiku), and outputs an XLSX to the Desktop. Use this when the user asks for a Cursor usage report — phrases like "帮我总结X月份我的cursor报告", "总结我X月份的Cursor使用", "出X月Cursor报表", "我这个月在Cursor里做了什么", "summarize my Cursor usage for [period]".
