Utilice el comando ready qiqi para manejar tareas generales de ERP para servicios empresariales. Se utiliza para verificar la identidad y el perfil, descubrir objetos y campos, consultar registros o vistas de trabajo, manejar paginación y resultados de gran tamaño, ejecutar documentos o acciones de aprobación, eliminar registros, manejar archivos adjuntos o escribir cuando los resultados de la verificación no están claros.
