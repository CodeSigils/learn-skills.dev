Utilice el comando ready qiqi para manejar tareas generales de ERP para servicios empresariales. Se utiliza para verificar la identidad y el perfil, descubrir objetos y campos, consultar registros o vistas de trabajo, manejar paginación y resultados grandes, ejecutar documentos o acciones de aprobación, eliminar registros, manejar archivos adjuntos o cuando el resultado de una escritura no está claro.
