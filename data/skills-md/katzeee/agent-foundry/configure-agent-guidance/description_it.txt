Installa, aggiorna o rimuovi le sezioni guida riutilizzabili in un file AGENTS.md globale o di progetto. Da utilizzare quando l'utente richiede esplicitamente di configurare la guida dell'agente persistente, installare uno dei modelli AGENTS.md di questa competenza, scegliere se la guida si applica a tutti i progetti o solo al progetto corrente oppure mantenere una sezione installata in precedenza.
