Utilizza questa competenza ogni volta che l'utente ha bisogno di generare, modificare o integrare immagini o video AIGC con imini Open Platform: testo in immagine, editing di immagini con riferimenti, testo in video, immagine in video, primo/ultimo fotogramma, video di riferimento, controllo del movimento, editing video o generazione multimodale. Due percorsi: (A) generazione one-shot ad hoc adesso tramite script Python in bundle (nessun codegen, nessuna masterizzazione di token per rieseguire la logica di invio/sondaggio); (B) scrivere il codice di integrazione asincrono nel progetto dell'utente. Si attiva quando viene menzionato imini, openapi.imini.ai o qualsiasi ID modello imini (nano-banana, nano-banana-pro, nano-banana-2, gpt-image-2, kling-v3, kling-v3-omni, kling-v3-motion-control, seedance-2.0, seedance-2.0-fast, happyhorse-1.0).
