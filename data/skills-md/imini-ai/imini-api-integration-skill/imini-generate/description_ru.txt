Используйте этот навык всякий раз, когда пользователю необходимо создать, отредактировать или интегрировать изображения или видео AIGC с открытой платформой imini — преобразование текста в изображение, редактирование изображений со ссылками, преобразование текста в видео, изображение в видео, первый/последний кадр, эталонное видео, управление движением, редактирование видео или мультимодальное создание. Два пути — (A) одноразовая генерация прямо сейчас с помощью встроенных скриптов Python (без генерации кода, без записи токенов для повторного получения логики отправки/опроса); (Б) написание кода асинхронной интеграции в собственный проект пользователя. Срабатывает при упоминании imini, openapi.imini.ai или любого идентификатора модели imini (nano-banana, nano-banana-pro, nano-banana-2, gpt-image-2, kling-v3, kling-v3-omni, kling-v3-motion-control, Seedance-2.0, Seedance-2.0-fast, Happyhorse-1.0).
