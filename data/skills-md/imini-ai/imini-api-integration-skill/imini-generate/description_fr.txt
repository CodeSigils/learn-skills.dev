Utilisez cette compétence chaque fois que l'utilisateur a besoin de générer, d'éditer ou d'intégrer des images ou des vidéos AIGC avec imini Open Platform : texte-image, édition d'image avec références, texte-vidéo, image-vidéo, première/dernière image, vidéo de référence, contrôle de mouvement, montage vidéo ou génération multimodale. Deux voies : (A) génération ponctuelle ad hoc dès maintenant via des scripts Python fournis (pas de codegen, pas de gravure de jeton pour re-dériver la logique de soumission/sondage) ; (B) écrire du code d'intégration asynchrone dans le propre projet de l'utilisateur. Se déclenche sur les mentions d'imini, openapi.imini.ai ou de tout identifiant de modèle imini (nano-banana, nano-banana-pro, nano-banana-2, gpt-image-2, kling-v3, kling-v3-omni, kling-v3-motion-control, seedance-2.0, seedance-2.0-fast, happyhorse-1.0).
