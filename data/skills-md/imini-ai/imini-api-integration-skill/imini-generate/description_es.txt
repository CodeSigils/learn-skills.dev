Utilice esta habilidad siempre que el usuario necesite generar, editar o integrar imágenes o videos AIGC con la plataforma abierta imini: texto a imagen, edición de imágenes con referencias, texto a video, imagen a video, primer/último cuadro, video de referencia, control de movimiento, edición de video o generación multimodal. Dos caminos: (A) generación ad-hoc de una sola vez en este momento a través de scripts de Python incluidos (sin generación de código, sin quema de tokens para volver a derivar la lógica de envío/encuesta); (B) escribir código de integración asíncrono en el propio proyecto del usuario. Se activa al mencionar imini, openapi.imini.ai o cualquier identificación de modelo de imini (nano-banana, nano-banana-pro, nano-banana-2, gpt-image-2, kling-v3, kling-v3-omni, kling-v3-motion-control, seedance-2.0, seedance-2.0-fast, happyhorse-1.0).
