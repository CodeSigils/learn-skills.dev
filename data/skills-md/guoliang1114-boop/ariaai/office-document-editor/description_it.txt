Modifica i documenti Office esistenti nello spazio progetto. Utilizzare quando l'utente chiede di (1) modificare il titolo/contenuto/dati di una diapositiva PPT, (2) aggiornare la sezione/paragrafo/tabella di un documento Word, (3) modificare valori/formule/righe/colonne di celle Excel, (4) aggiungere/rimuovere/riordinare diapositive o pagine, (5) correggere la formattazione, aggiornare i dati o apportare correzioni a un file esistente. Copre la modifica PPT, Word, Excel. NON crea nuovi file da zero: utilizza Presentation-Builder o write_project_office_document per questo.
