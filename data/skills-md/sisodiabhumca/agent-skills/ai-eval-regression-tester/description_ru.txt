Используйте для запуска набора регрессионной оценки в приложении LLM — фиксированные тестовые случаи с детерминированными оценщиками (точное совпадение, схема JSON, регулярное выражение, сходство внедрения, LLM-как судья). Сравнивает модель-кандидат/подсказку с базовым уровнем и выдает релиз на основе показателя проходимости + пороговых значений для каждого тега.
