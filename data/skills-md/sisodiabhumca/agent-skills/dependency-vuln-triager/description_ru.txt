Используйте для сортировки результатов сканирования уязвимостей зависимостей (аудит npm, pip-audit, OSV, рекомендации GitHub) и создания ранжированного дедуплицированного списка действий. Сочетает серьезность CVSS с простой эвристикой уязвимости и достижимости, предлагает самую безопасную версию исправления и группирует по пакетам, поэтому один удар закрывает множество CVE. Независимость от поставщика — работает с любыми входными данными, подобными JSON SBOM.
