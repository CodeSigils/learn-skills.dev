Verwenden Sie diese Option, um benutzerbezogene Versionshinweise aus einer Liste zusammengeführter PRs (CSV/JSON) zusammenzustellen oder indem Sie „git log“ zwischen zwei Referenzen lesen. Gruppiert Änderungen in „Features/Verbesserungen/Korrekturen/Breaking“, löscht nur interne Elemente, verknüpft jede Zeile wieder mit ihrer PR und erstellt sowohl einen öffentlichen Markdown als auch eine Slack-fähige Kurzversion. Herstellerneutral.
