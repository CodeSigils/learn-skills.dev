Используйте для сбора примечаний к выпуску для пользователя из списка объединенных PR (CSV/JSON) или путем чтения журнала git между двумя ссылками. Группирует изменения в «Функции/Улучшения/Исправления/Неисправности», удаляет элементы, предназначенные только для внутреннего использования, связывает каждую строку с ее PR и создает как общедоступную Markdown, так и короткую версию, готовую для Slack. Вендор-нейтральный.
