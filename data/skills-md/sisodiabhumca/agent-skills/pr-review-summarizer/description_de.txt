Wird zum Überprüfen einer Code-Pull-Anfrage oder Merge-Anfrage verwendet. Liest einen einheitlichen Diff (oder ruft einen von GitHub/GitLab ab) und erstellt eine strukturierte Überprüfung – risikobewertete Zusammenfassung, geänderte Dateien, Hotspots, empfohlene Testabdeckung und Prüferfragen. Herstellerneutral; Funktioniert mit jeder AI-Agent-Laufzeitumgebung, die Shell-Befehle ausführen kann.
