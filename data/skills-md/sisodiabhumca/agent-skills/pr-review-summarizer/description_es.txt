Úselo al revisar una solicitud de extracción de código o una solicitud de fusión. Lee una diferencia unificada (o obtiene una de GitHub/GitLab) y produce una revisión estructurada: resumen clasificado por riesgo, archivos modificados, puntos de acceso, cobertura de prueba sugerida y preguntas del revisor. Proveedor neutral; funciona con cualquier tiempo de ejecución de agente de IA que pueda ejecutar comandos de shell.
