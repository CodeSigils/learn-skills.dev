Используйте во время инцидента или обычной задачи по вызову для пошагового выполнения Runbook, определенного в YAML. Каждый шаг имеет описание, необязательную команду предварительной проверки, команду действия и ожидаемый результат. Создает журнал выполнения с защитой от несанкционированного доступа. Вендор-нейтральный; работает с любой средой выполнения агента, поддерживающей оболочку.
