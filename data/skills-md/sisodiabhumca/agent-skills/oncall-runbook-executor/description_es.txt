Úselo durante un incidente o una tarea rutinaria de guardia para ejecutar un runbook definido por YAML paso a paso. Cada paso tiene una descripción, un comando de verificación previa opcional, el comando de acción y un resultado esperado. Produce un registro de ejecución a prueba de manipulaciones. Proveedor neutral; funciona con cualquier tiempo de ejecución de agente compatible con shell.
