ينفذ صحة نواة وحدة معالجة الرسومات وتقييم الأداء وقياس استدلال LLM باستخدام Magpie. يحلل نواة مفردة أو متعددة (HIP/CUDA/PyTorch)، ويقارن تطبيقات kernel، ويدير معايير vLLM/SGLang مع ملفات التعريف وTraceLens، ويجري تحليل الفجوات على آثار الشعلة. ينشئ YAMLs لتكوين kernel، ويكتشف النواة في المشروع، ويستعلم عن مواصفات GPU. يُستخدم عندما يذكر المستخدم Magpie، أو تحليل kernel أو مقارنته، أو تقييم kernel HIP/CUDA، أو معيار vLLM/SGLang، أو تحليل الفجوات، أو TraceLens، أو إنشاء تكوينات kernel، أو اكتشاف نواة GPU.
