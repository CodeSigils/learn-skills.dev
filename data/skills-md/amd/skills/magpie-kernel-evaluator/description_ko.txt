Magpie를 사용하여 GPU 커널 정확성과 성능 평가, LLM 추론 벤치마킹을 수행합니다. 단일 또는 다중 커널(HIP/CUDA/PyTorch)을 분석하고, 커널 구현을 비교하고, 프로파일링 및 TraceLens를 사용하여 vLLM/SGLang 벤치마크를 실행하고, 토치 추적에 대한 갭 분석을 실행합니다. 커널 구성 YAML을 생성하고, 프로젝트에서 커널을 검색하고, GPU 사양을 쿼리합니다. 사용자가 Magpie, 커널 분석 또는 비교, HIP/CUDA 커널 평가, vLLM/SGLang 벤치마크, 간격 분석, TraceLens, 커널 구성 생성 또는 GPU 커널 검색을 언급할 때 사용합니다.
