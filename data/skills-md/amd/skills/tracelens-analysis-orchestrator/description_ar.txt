ينسق تحليل تتبع ملف تعريف PyTorch المعياري باستخدام TraceLens: يقوم بإنشاء تقارير الأداء، وإعداد بيانات الفئة، وتشغيل الوكلاء الفرعيين على مستوى النظام وحساب kernel بالتوازي، والتحقق من صحة المخرجات، وكتابة تقرير أصحاب المصلحة ذي الأولوية (analyse.md). يُستخدم عندما يطلب المستخدم متابعة منسق التحليل، أو تشغيل سير عمل التحليل الوكيل، أو تحليل التتبع، أو مقارنة تتبعين، أو الإشارة إلى تحليل TraceLens المستقل أو المقارن.
