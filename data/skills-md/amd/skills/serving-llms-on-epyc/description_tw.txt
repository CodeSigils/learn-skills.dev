使用 vLLM 和 zentorch 後端在容器（Docker 或 Podman）或 conda 環境中在 AMD EPYC CPU 主機上提供語言模型。每當使用者想要在 AMD EPYC、Zen CPU、「CPU 上的 vLLM」、「zentorch 服務」或「在沒有 GPU 的情況下提供模型」上執行、服務、部署、啟動、託管或啟動 LLM 時使用。用於「在 EPYC 上提供 Qwen」、「啟動 CPU vLLM 端點」、「在我的 EPYC 盒子上執行 OpenAI 伺服器」或類似內容。處理完整的單一實例流程：偵測 CPU（包括 EPYC 世代）、驗證執行階段/env、檢查 vLLM 支援模型（透過 vLLM 的登錄，而不是模態封鎖清單）、檢查它是否適合主機 RAM、調整硬體中的 CPU 執行緒/KV/NUMA 大小、與使用者確認計畫、啟動和輪詢，直到端點回應。單一實例、單套接字（固定到一個套接字及其記憶體；vLLM 跨套接字的擴展性很差）。不調試故障也不重試——它報告並停止。請勿用於 GPU/Instinct（使用serving-llms-on-instinct）或多節點。
