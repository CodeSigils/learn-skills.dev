Sirve modelos de IA en hardware GPU AMD Instinct mediante vLLM. Utilice esta habilidad siempre que el usuario quiera ejecutar, servir, implementar, iniciar, alojar o lanzar un modelo de lenguaje en una GPU AMD, AMD Instinct, MI300X, MI325X, MI350X o MI355X. Úselo también cuando el usuario mencione vLLM en ROCm, vLLM en AMD, servicio en HBM o pregunte cómo ejecutar un modelo en el hardware del centro de datos AMD. Úselo cuando el usuario pregunte "ejecutar Qwen3", "servir DeepSeek", "iniciar un punto final vLLM", "ejecutar un modelo en mi máquina AMD" o cualquier frase similar. Maneja el flujo completo: detección de GPU, validación del entorno, configuración de vLLM, lanzamiento y verificación del estado. No lo utilice para GPU NVIDIA, GPU AMD de consumo (serie RX, Radeon), Ryzen AI, NPU, MI250X o MI100.
