Stellt KI-Modelle auf AMD Instinct GPU-Hardware mit vLLM bereit. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein Sprachmodell auf einer AMD-GPU, AMD Instinct, MI300X, MI325X, MI350X oder MI355X ausführen, bereitstellen, bereitstellen, starten, hosten oder starten möchte. Verwenden Sie es auch, wenn der Benutzer vLLM auf ROCm, vLLM auf AMD, die Bereitstellung auf HBM erwähnt oder fragt, wie er ein Modell auf AMD-Rechenzentrumshardware zum Laufen bringt. Verwenden Sie diese Option, wenn der Benutzer fragt: „Qwen3 ausführen“, „DeepSeek bereitstellen“, „vLLM-Endpunkt starten“, „ein Modell auf meinem AMD-Computer ausführen“ oder eine ähnliche Formulierung verwendet. Verarbeitet den gesamten Ablauf: GPU-Erkennung, Umgebungsvalidierung, vLLM-Konfiguration, Start und Integritätsüberprüfung. Nicht für NVIDIA-GPUs, Consumer-AMD-GPUs (RX-Serie, Radeon), Ryzen AI, NPU, MI250X oder MI100 verwenden.
