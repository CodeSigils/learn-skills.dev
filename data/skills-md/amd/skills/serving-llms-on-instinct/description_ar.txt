يقدم نماذج الذكاء الاصطناعي على أجهزة AMD Instinct GPU باستخدام vLLM. استخدم هذه المهارة عندما يريد المستخدم تشغيل نموذج لغة أو تقديمه أو نشره أو تشغيله أو استضافته أو إطلاقه على وحدة معالجة الرسومات AMD أو AMD Instinct أو MI300X أو MI325X أو MI350X أو MI355X. استخدمه أيضًا عندما يذكر المستخدم vLLM على ROCm، أو vLLM على AMD، أو الذي يعمل على HBM، أو يسأل عن كيفية تشغيل نموذج على أجهزة مركز بيانات AMD. يُستخدم عندما يسأل المستخدم "تشغيل Qwen3"، أو "خدمة DeepSeek"، أو "بدء نقطة نهاية vLLM"، أو "الحصول على نموذج يعمل على جهاز AMD الخاص بي"، أو أي عبارة مشابهة. يتعامل مع التدفق الكامل: اكتشاف GPU، والتحقق من البيئة، وتكوين vLLM، والتشغيل، والتحقق من الصحة. لا تستخدمه مع وحدات معالجة الرسومات NVIDIA أو وحدات معالجة الرسومات AMD الاستهلاكية (سلسلة RX أو Radeon) أو Ryzen AI أو NPU أو MI250X أو MI100.
