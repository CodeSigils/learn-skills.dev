Sert les modèles d'IA sur le matériel GPU AMD Instinct à l'aide de vLLM. Utilisez cette compétence chaque fois que l'utilisateur souhaite exécuter, servir, déployer, démarrer, héberger ou lancer un modèle de langage sur un GPU AMD, AMD Instinct, MI300X, MI325X, MI350X ou MI355X. À utiliser également lorsque l'utilisateur mentionne vLLM sur ROCm, vLLM sur AMD, sert sur HBM ou demande comment faire fonctionner un modèle sur le matériel du centre de données AMD. À utiliser lorsque l'utilisateur demande « exécuter Qwen3 », « servir DeepSeek », « démarrer un point de terminaison vLLM », « faire fonctionner un modèle sur ma machine AMD » ou toute autre formulation similaire. Gère le flux complet : détection du GPU, validation de l'environnement, configuration vLLM, lancement et vérification de l'état. Ne pas utiliser pour les GPU NVIDIA, les GPU AMD grand public (série RX, Radeon), Ryzen AI, NPU, MI250X ou MI100.
