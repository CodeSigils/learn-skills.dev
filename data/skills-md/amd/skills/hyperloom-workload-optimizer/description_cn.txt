使用 Hyperloom 多代理优化器，能够自主地在 AMD Instinct GPU 上优化端到端的大语言模型推理吞吐量并报告经验证的提升。给定模型、框架、工作负载（TP/EP、并发、ISL/OSL、精度）、目标和时间预算，它会针对每个工作负载探索应调整的杠杆（服务/配置参数及环境、框架启用和源码补丁、以及热点 GPU 内核重写），对每个候选方案进行基准测试，并返回产生提升的优化堆栈。适用于用户希望让模型更快提供服务、提高 token/秒或吞吐量、在 MI300X/MI325X/MI355X 上优化或调优 vLLM 或 SGLang、运行 Hyperloom、运行 kernel-agent、使用 Quark 进行量化后优化、从头设置 Hyperloom，或恢复 Hyperloom 会话的场景。不要将其用于仅搭建普通服务的服务器、诊断损坏的 ROCm 安装，或在没有优化循环的情况下运行一次性内核/基准测试或跟踪分析。
