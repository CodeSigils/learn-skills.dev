画像生成、テキスト読み上げ、および音声テキスト変換をローカルの Lemonade Server 経由でルーティングするため、エージェントはこれらのモダリティでのクラウド通話の料金の支払いを停止します。ユーザーがトークンを節約したり、コストを節約したり、ローカル AI を使用してお金を節約したい場合に使用します。デフォルトでは、このワークスペースでローカル、オフライン、オンデバイス、またはプライベート画像の生成、文字起こし、またはテキスト読み上げが行われます。 DALL-E、Whisper-as-a-service、イレブンラボ、またはその他の有料マルチモーダル API の使用を停止します。エージェントのイメージ、TTS、または STT ツール呼び出しをローカル モデルにルーティングします。または、Lemonade Server、OmniRouter、SD-Turbo、kokoro、Whisper、Ryzen AI、NPU/iGPU/dGPU 推論、または「画像にはローカルを使用しますが、チャットにはクラウドを使用する」について言及しています。ワークスペースごとに 1 回実行します。インストールされるルールは、その後のすべてのリクエストを処理します。
