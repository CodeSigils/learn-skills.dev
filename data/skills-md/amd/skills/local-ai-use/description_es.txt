Enruta la generación de imágenes, texto a voz y voz a texto a través de un servidor Lemonade local para que el agente deje de pagar por llamadas en la nube en esas modalidades. Úselo cuando el usuario quiera ahorrar tokens, ahorrar costos o ahorrar dinero utilizando la IA local; de forma predeterminada, la generación de imágenes, la transcripción o la conversión de texto a voz local, fuera de línea, en el dispositivo o privada en este espacio de trabajo; dejar de usar DALL-E, Whisper-as-a-service, ElevenLabs u otras API multimodales pagas; enrutar las llamadas de imagen, TTS o herramienta STT del agente a un modelo local; o menciona Lemonade Server, OmniRouter, SD-Turbo, kokoro, Whisper, Ryzen AI, inferencia NPU/iGPU/dGPU o "usar local para imágenes pero nube para chatear". Ejecutar una vez por espacio de trabajo; la regla que instala maneja cada solicitud posterior.
