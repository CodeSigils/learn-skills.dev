Leitet die Bilderzeugung, Text-zu-Sprache und Sprache-zu-Text über einen lokalen Lemonade-Server weiter, sodass der Agent bei diesen Modalitäten nicht mehr für Cloud-Anrufe bezahlen muss. Verwenden Sie diese Option, wenn der Benutzer mithilfe lokaler KI Tokens, Kosten oder Geld sparen möchte. In diesem Arbeitsbereich wird standardmäßig die lokale, Offline-, geräteinterne oder private Bildgenerierung, Transkription oder Text-zu-Sprache-Umwandlung verwendet. die Nutzung von DALL-E, Whisper-as-a-service, ElevenLabs oder anderen kostenpflichtigen multimodalen APIs einstellen; Leiten Sie die Image-, TTS- oder STT-Tool-Aufrufe des Agenten an ein lokales Modell weiter; oder erwähnt Lemonade Server, OmniRouter, SD-Turbo, Kokoro, Whisper, Ryzen AI, NPU/iGPU/dGPU-Inferenz oder „Lokal für Bilder, aber Cloud für Chat verwenden“. Einmal pro Arbeitsbereich ausführen; Die installierte Regel verarbeitet jede spätere Anfrage.
