ルーティング意図の自然言語記述を有効な Lemonade `collection.router` ポリシー JSON に変換します。スキルは JSON の生成と検証のみを行います。JSON の登録やライブサーバーの呼び出しは行いません。ユーザーがモデル間でリクエストをルーティングする場合 (「機密クエリを X にルーティングし、その他すべてを Y にルーティングする」)、ルーター/ハイブリッド ルーター構成またはポリシーの生成、collection.router JSON の作成、小規模なローカル モデルと大規模/クラウド モデル間のトラフィックの分割、PII/ジェイルブレイク/トピック分類子をルーティングに追加する場合、または Lemonade Router、ルーティング ルール、routing.router、候補者/default_model について言及する場合に使用します。キーワード_any、semantic_similarity、またはルーターとしての LLM。ユーザーが指定しなかったすべてのフィールドに安全なデフォルト値を入力します。
