يحول وصف اللغة الطبيعية لنية التوجيه إلى سياسة JSON صالحة لـ Lemonade `collection.router`. تقوم المهارة بإنشاء JSON والتحقق من صحته فقط - ولا تقوم بتسجيله أو الاتصال بالخادم المباشر. يُستخدم عندما يريد المستخدم توجيه الطلبات بين النماذج ("توجيه الاستعلامات الحساسة إلى X وكل شيء آخر إلى Y")، أو إنشاء تكوين أو سياسة لجهاز التوجيه/جهاز التوجيه المختلط، أو تأليف مجموعة.router JSON، أو تقسيم حركة المرور بين نموذج محلي صغير ونموذج كبير/سحابي، أو إضافة مصنفات PII/jailbreak/الموضوع إلى التوجيه، أو الإشارة إلى Lemonade Router، وقواعد التوجيه، وrouting.router، والمرشحين/default_model، والكلمات الأساسية_any، التشابه الدلالي، أو LLM كجهاز توجيه. يملأ كل حقل لم يحدده المستخدم بالإعدادات الافتراضية الآمنة.
