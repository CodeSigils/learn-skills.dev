Catalyst Signals — платформа с событийно-управляемой архитектурой для практически мгновенной связи между разделенными приложениями. Поддерживает издателей Zoho, издателей Catalyst, пользовательских издателей, веб-перехватчиков, функций, схем, фильтрации событий, преобразования, пакетной/плановой отправки и политик повторных попыток. Запуск по «Сигналам», «шине событий», «издателю», «управляемому событиями», «цели веб-перехватчика», «политике отправки», «преобразованию событий», «фильтру правил» или «упорядочению событий». Служба только для консоли — без SDK или программного API.
