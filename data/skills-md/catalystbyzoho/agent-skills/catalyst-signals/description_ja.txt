Catalyst Signals — 分離されたアプリケーション間のほぼ瞬時の通信のためのイベント駆動型アーキテクチャ プラットフォーム。 Zoho パブリッシャー、Catalyst パブリッシャー、カスタム パブリッシャー、Webhook、関数、回路、イベント フィルター、変換、バッチ/スケジュールされたディスパッチ、および再試行ポリシーをサポートします。 「シグナル」、「イベント バス」、「パブリッシャー」、「イベント ドリブン」、「Webhook ターゲット」、「ディスパッチ ポリシー」、「イベント変換」、「ルール フィルター」、または「イベント順序付け」でトリガーします。コンソールのみのサービス — SDK やプログラム API はありません。
