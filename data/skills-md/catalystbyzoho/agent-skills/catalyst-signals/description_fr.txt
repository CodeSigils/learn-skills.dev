Catalyst Signals — plate-forme d'architecture basée sur les événements pour une communication quasi instantanée entre des applications découplées. Prend en charge les éditeurs Zoho, les éditeurs Catalyst, les éditeurs personnalisés, les webhooks, les fonctions, les circuits, le filtrage des événements, la transformation, l'envoi par lots/planifié et les politiques de nouvelle tentative. Déclenchez sur « Signaux », « bus d'événements », « éditeur », « piloté par des événements », « cible du webhook », « politique de répartition », « transformation d'événements », « filtre de règles » ou « ordre des événements ». Service uniquement sur console – pas de SDK ou d’API programmatique.
