Catalyst Signals: piattaforma con architettura basata sugli eventi per comunicazioni quasi istantanee tra applicazioni disaccoppiate. Supporta editori Zoho, editori Catalyst, editori personalizzati, webhook, funzioni, circuiti, filtro eventi, trasformazione, invio batch/pianificato e criteri di ripetizione. Attivazione su "Segnali", "bus eventi", "editore", "guidato dagli eventi", "destinazione webhook", "politica di invio", "trasformazione eventi", "filtro regole" o "ordinamento eventi". Servizio solo console: nessun SDK o API programmatica.
