مصادقة Catalyst — تسجيل دخول/تسجيل المستخدم، وتدفقات مصادقة ZAID، وWeb SDK، وإدارة رمز OAuth عبر الاتصالات. قم بتشغيل "المصادقة" أو "تسجيل الدخول" أو "التسجيل" أو "getCurrentUser" أو "ZAID" أو "isUserAuthenticated" أو "تسجيل الخروج" أو "الاتصالات" أو "getAccessToken". يجب عليك تحميل هذه المهارة عند تنفيذ تسجيل دخول المستخدم أو حماية البيانات - يختلف ZAID بين التطوير والإنتاج وهو السبب الأول لفشل المصادقة بعد تعزيز البيئة. بالنسبة لقواعد الأمان (التحكم في استدعاء الوظيفة)، قم بالتوجيه إلى وظائف المحفز.
