Аутентификация Catalyst — вход/регистрация пользователей, ZAID, потоки аутентификации Web SDK и управление токенами OAuth через Connections. Запуск по «аутентификации», «входу», «регистрации», «getCurrentUser», «ZAID», «isUserAuthenticated», «signOut», «Connections» или «getAccessToken». Вы ДОЛЖНЫ загружать этот навык всякий раз, когда реализуете вход пользователя или защиту данных — ZAID различается для разработки и производства и является причиной № 1 ошибок аутентификации после продвижения среды. Для правил безопасности (управление вызовом функций) перейдите к функциям-катализаторам.
