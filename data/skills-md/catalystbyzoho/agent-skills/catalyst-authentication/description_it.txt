Autenticazione Catalyst: accesso/registrazione utente, ZAID, flussi di autenticazione Web SDK e gestione dei token OAuth tramite Connections. Attiva su "autenticazione", "login", "iscrizione", "getCurrentUser", "ZAID", "isUserAuthenticated", "signOut", "Connessioni" o "getAccessToken". DEVI caricare questa competenza ogni volta che implementi l'accesso utente o proteggi i dati: ZAID differisce tra Sviluppo e Produzione ed è la causa numero 1 di errori di autenticazione dopo la promozione dell'ambiente. Per le regole di sicurezza (controllo delle chiamate di funzione), instradare a funzioni catalyst.
