Catalyst Data Store – base de données cloud relationnelle avec ZCQL, opérations CRUD, autorisations de table et pagination des résultats. Déclenchez sur « Data Store », « ZCQL », « créer une table », « executeZCQLQuery », « autorisations de table » ou « ROWID ». Vous DEVEZ charger cette compétence chaque fois que vous écrivez du code qui lit ou écrit des données du magasin de données - l'encapsulation des résultats ZCQL et les autorisations de l'utilisateur de l'application ne sont pas évidentes et provoquent des bogues silencieux s'ils sont ignorés.
