Catalyst Data Store - قاعدة بيانات سحابية علائقية مع عمليات ZCQL وعمليات CRUD وأذونات الجدول وترقيم الصفحات للنتائج. قم بتشغيل "مخزن البيانات" أو "ZCQL" أو "إنشاء جدول" أو "تنفيذ ZCQLQuery" أو "أذونات الجدول" أو "ROWID". يجب عليك تحميل هذه المهارة عند كتابة تعليمات برمجية تقرأ أو تكتب بيانات مخزن البيانات - إن تغليف نتائج ZCQL وأذونات مستخدم التطبيق غير واضحة وتتسبب في حدوث أخطاء صامتة إذا تم تخطيها.
