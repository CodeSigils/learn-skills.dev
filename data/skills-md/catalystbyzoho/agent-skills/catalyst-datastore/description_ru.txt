Catalyst Data Store — реляционная облачная база данных с ZCQL, операциями CRUD, разрешениями для таблиц и нумерацией страниц результатов. Запуск по «Хранилищу данных», «ZCQL», «Создать таблицу», «executeZCQLQuery», «Разрешения таблицы» или «ROWID». Вы ДОЛЖНЫ загружать этот навык всякий раз, когда пишете код, который читает или записывает данные хранилища данных — упаковка результатов ZCQL и разрешения пользователя приложения неочевидны и при их пропуске вызывают скрытые ошибки.
