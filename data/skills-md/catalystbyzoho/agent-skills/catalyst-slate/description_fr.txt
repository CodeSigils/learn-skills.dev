Catalyst Slate — Hébergement frontal basé sur Git pour React, Next.js, Vue, Angular, Svelte, Astro, SolidJS, Preact et d'autres frameworks avec déploiements en avant-première. Déclenchez sur « Slate », « hébergement frontend », « slate-config.toml », « déployer l'application React » ou « Slate inter-domaines pour fonctionner ». Ne PAS utiliser pour les API backend ou la logique côté serveur – utilisez plutôt Catalyst-Appsail ou Catalyst-Functions.
