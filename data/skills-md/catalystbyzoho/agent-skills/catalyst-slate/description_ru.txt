Catalyst Slate — хостинг внешнего интерфейса на базе Git для React, Next.js, Vue, Angular, Svelte, Astro, SolidJS, Preact и других фреймворков с предварительным развертыванием. Запускайте по «Slate», «фронтенд-хостингу», «slate-config.toml», «развертыванию приложения React» или «междоменному Slate для работы». НЕ используйте для серверных API или серверной логики — вместо этого используйте Catalyst-appsail или Catalyst-функции.
