Catalyst NoSQL - مخزن جدول القيمة الرئيسية مع العناصر المكتوبة التي تم إنشاؤها عبر NoSQLItem builder. مفتاح التقسيم مطلوب. قم بتشغيل "NoSQL" أو "nosql.table" أو "insertItems" أو "fetchItem" أو "updateItems" أو "deleteItems" أو "queryTable" أو "NoSQLItem" أو "تخزين المستندات" أو "المخطط المرن" أو "قاعدة بيانات مستندات Catalyst". لا تستخدمه عندما تحتاج إلى روابط SQL، أو استعلامات ZCQL، أو مخطط علائقي ثابت - استخدم Catalyst-datastore بدلاً من ذلك.
