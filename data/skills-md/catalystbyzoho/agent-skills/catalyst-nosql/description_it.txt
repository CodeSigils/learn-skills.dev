Catalyst NoSQL: archivio di tabelle chiave-valore con elementi tipizzati creati tramite il builder NoSQLItem. Chiave di partizione richiesta. Attivazione su "NoSQL", "nosql.table", "insertItems", "fetchItem", "updateItems", "deleteItems", "queryTable", "NoSQLItem", "archiviazione di documenti", "schema flessibile" o "database di documenti Catalyst". NON utilizzare quando sono necessari join SQL, query ZCQL o uno schema relazionale fisso: utilizzare invece catalyst-datastore.
