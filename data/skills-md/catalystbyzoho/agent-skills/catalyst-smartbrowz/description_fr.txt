Catalyst SmartBrowz — service d'automatisation du navigateur et de génération de documents. Comprend Headless (se connecter à Chrome/Firefox distant avec Puppeteer/Playwright/Selenium), Browser Logic (fonctions sans serveur pour les tâches de navigateur dans Java/Node.js), PDF & Screenshot (générer des documents visuels à partir de HTML/URL/Template), Templates (concevoir des modèles de contenu dynamiques), Browser Grid (navigateurs parallèles sans tête avec mise à l'échelle automatique, accès anticipé) et Dataverse (API de grattage de données). Déclenchez sur « SmartBrowz », « navigateur sans tête », « navigateur sans tête », « marionnettiste », « Selenium », « dramaturge », « logique du navigateur », « génération PDF », « capture d'écran », « génération PDF/capture d'écran », « PDF et capture d'écran », « automatisation du navigateur », « grille du navigateur » ou « web scraping ». Console + SDK (Java/Node.js/Python pour PDF/Capture d'écran + Browser Grid) + CLI (pour les fonctions Browser Logic).
