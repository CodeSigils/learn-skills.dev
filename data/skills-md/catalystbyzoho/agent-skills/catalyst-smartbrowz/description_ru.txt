Catalyst SmartBrowz — сервис автоматизации браузера и создания документов. Включает Headless (подключение к удаленному Chrome/Firefox с помощью Puppeteer/Playwright/Selenium), Browser Logic (бессерверные функции для задач браузера в Java/Node.js), PDF & Screenshot (создание визуальных документов из HTML/URL/шаблона), Templates (разработка шаблонов динамического контента), Browser Grid (параллельные автономные браузеры с автоматическим масштабированием, ранним доступом) и Dataverse (API для очистки данных). Консоль + SDK (Java/Node.js/Python для PDF/Снимок экрана + сетка браузера) + CLI (для функций логики браузера).
