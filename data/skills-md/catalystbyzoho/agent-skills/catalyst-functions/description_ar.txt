وظائف Catalyst بدون خادم — جميع الأنواع السبعة (الإدخال/الإخراج الأساسي، والإدخال/الإخراج المتقدم، والحدث، وCron، والوظيفة، والتكامل، ومنطق المتصفح)، وتوقيعات المعالج، وcatalyst-config.json، وقواعد الأمان، وتوجيه بوابة API، وتحميل الملفات، وbusboy، والبرمجيات الوسيطة السريعة، ومتغيرات البيئة، وعنوان URL للوظيفة، واختبار الوظيفة. قم بتشغيل "كتابة وظيفة"، أو "وظيفة المحفز"، أو "بوابة API"، أو "قواعد الأمان"، أو "لم يتم العثور على الوظيفة"، أو "إرجاع الوظيفة 401"، أو "busboy"، أو "البرامج الوسيطة"، أو "عنوان URL للوظيفة"، أو "متغير البيئة في الوظيفة"، أو أي سؤال عن نوع الوظيفة. لا تستخدمه مع الخوادم المستمرة، أو العمليات طويلة الأمد، أو WebSockets، أو عمليات نشر Docker - استخدم catalyst-appsail بدلاً من ذلك.
