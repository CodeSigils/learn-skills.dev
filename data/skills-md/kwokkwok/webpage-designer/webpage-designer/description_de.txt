Konvertieren Sie den vom Benutzer bereitgestellten Inhalt in eine Webseitendatei. Verstehen Sie zunächst den Inhalt, wählen Sie dann einen Stil aus (oder verwenden Sie den vom Benutzer angegebenen Stil), laden Sie die entsprechende Eingabeaufforderung und generieren Sie schließlich den Webseitencode. Anwendungsfall: Wenn der Benutzer eine Webseite, Landingpage, ein Portfolio oder ein anderes Szenario erstellen muss, das eine Webschnittstelle erfordert.
