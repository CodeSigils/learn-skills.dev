Convertissez le contenu de l'utilisateur en une page Web. Comprenez d'abord le contenu, puis choisissez un style (ou utilisez celui spécifié par l'utilisateur), chargez l'invite correspondante et enfin générez le code Web. Cas d'utilisation : chaque fois que l'utilisateur a besoin d'une page Web, d'une page de destination, d'un portfolio ou de tout autre scénario nécessitant une interface Web.
