Verwenden Sie Truffler, um ähnliche oder bereits vorhandene JavaScript-/TypeScript-Symbole zu finden, bevor Sie neuen Code implementieren, insbesondere Hilfsprogramme, Dienstprogramme, Parser, Formatierer, Scanner, Fuzzy-Matcher und andere wiederverwendbare Funktionen. Agenten sollten diese Fähigkeit immer dann verwenden, wenn sie Funktionalitäten in einem JS/TS-Repository hinzufügen oder umgestalten möchten und die Duplizierung von vorhandenem Code vermeiden müssen, auch wenn der Benutzer die Deduplizierung nicht ausdrücklich erwähnt.
