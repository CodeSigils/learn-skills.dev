قم بمسح قاعدة بيانات React بأكملها بصفتك أحد كبار مهندسي React، باستخدام فحص React Doctor كدليل، ثم قم بإنتاج تدقيق ذي أولوية وخطط تنفيذ قائمة بذاتها ليقوم الوكلاء الآخرون (أو النماذج الأرخص) بتنفيذها. للقراءة فقط على الكود المصدري – فهي تخطط للتحسينات، ولا تطبقها. يُستخدم عندما يطلب المستخدم "تحسين كود React"، أو "تدقيق قاعدة التعليمات البرمجية هذه"، أو "جعل هذا التطبيق أسرع/أكثر قوة"، أو يريد خريطة طريق للإصلاحات بدلاً من مراجعة فرق واحد. للتحقق من الانحدار أو تمرير الإصلاح الآن، استخدم مهارة "react-doctor" بدلاً من ذلك.
