React Doctor のスキャンを証拠として使用して、上級 React エンジニアとして React コードベース全体を調査し、優先順位付けされた監査と他のエージェント (またはより安価なモデル) が実行できる自己完結型の実装計画を作成します。ソース コードは読み取り専用です。改善を計画しますが、適用はしません。ユーザーが「React コードの改善」、「このコードベースの監査」、「このアプリの高速化/堅牢化」を要求する場合、または単一の差分のレビューではなく修正のロードマップが必要な場合に使用します。回帰チェックや今すぐ修正する場合は、代わりに「react-doctor」スキルを使用してください。
