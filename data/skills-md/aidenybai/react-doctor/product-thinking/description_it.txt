Pensa come un product manager prima di modificare la superficie pubblica di React Doctor: comandi/flag CLI, il punteggio 0–100, la configurazione (doctor.config.*), lo schema del report JSON, le API del pacchetto (inspect()/diagnose()), l'azione GitHub, il sito Web e i prompt canonici. Un runbook dettagliato per una modifica rivolta all'utente: individua la superficie, cerca un candidato al riutilizzo, collega una metrica di telemetria, aggiungi gli artefatti di compatibilità (changeset/schemaVersion/action tag), aggiorna i documenti e registra una metrica di kill. Non per le regole di lanugine, che hanno una propria pipeline. Viene eseguito anche quando l'utente digita "/product-thinking".
