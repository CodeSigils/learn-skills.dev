Piense como un gerente de producto antes de cambiar la superficie pública de React Doctor: comandos/indicadores CLI, la puntuación de 0 a 100, configuración (doctor.config.*), el esquema de informe JSON, las API del paquete (inspect()/diagnose()), la acción de GitHub, el sitio web y las indicaciones canónicas. Un runbook paso a paso para un cambio de cara al usuario: localice la superficie, busque un candidato de reutilización, conecte una métrica de telemetría, agregue los artefactos de compatibilidad (conjunto de cambios/versión de esquema/etiqueta de acción), actualice documentos y registre una métrica de eliminación. No para las reglas de pelusa, que tienen su propio proceso. También se ejecuta cuando el usuario escribe `/product-thinking`.
