React Doctor のパブリック サーフェス、つまり CLI コマンド/フラグ、0 ～ 100 のスコア、構成 (doctor.config.*)、JSON レポート スキーマ、パッケージ API (inspect()/diagnose())、GitHub アクション、Web サイト、正規プロンプトを変更する前に、プロダクト マネージャーのように考えてください。ユーザー向けの変更のためのステップバイステップの Runbook — サーフェスの特定、再利用候補の検索、テレメトリ メトリクスの接続、互換性アーティファクト (変更セット / schemaVersion / アクション タグ) の追加、ドキュメントの更新、および Kill メトリクスの記録。独自のパイプラインを持つ lint ルールには対応しません。ユーザーが「/product- Thinking」と入力したときにも実行されます。
