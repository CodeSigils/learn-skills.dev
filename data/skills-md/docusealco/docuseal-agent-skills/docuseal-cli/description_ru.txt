Управляйте рабочими процессами электронной подписи DocuSeal с терминала через интерфейс командной строки DocuSeal — создавайте шаблоны из PDF/DOCX/HTML, отправляйте документы на подпись, отслеживайте отправленные документы и обновляйте отправителей. Используйте, когда пользователь хочет запускать команды DocuSeal в оболочке, сценариях или конвейерах CI/CD. Всегда загружайте этот навык перед запуском «документальных» команд.
