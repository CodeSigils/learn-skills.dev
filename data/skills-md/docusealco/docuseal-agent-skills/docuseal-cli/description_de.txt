Verwalten Sie DocuSeal-E-Signatur-Workflows vom Terminal aus über die DocuSeal-CLI – erstellen Sie Vorlagen aus PDF/DOCX/HTML, senden Sie Dokumente zum Signieren, verfolgen Sie Übermittlungen und aktualisieren Sie Einreicher. Verwenden Sie diese Option, wenn der Benutzer DocuSeal-Befehle in der Shell, in Skripts oder in CI/CD-Pipelines ausführen möchte. Laden Sie diesen Skill immer, bevor Sie „docuseal“-Befehle ausführen.
