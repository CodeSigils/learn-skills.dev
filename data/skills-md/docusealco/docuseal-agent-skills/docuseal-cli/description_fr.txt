Gérez les flux de travail de signature électronique DocuSeal depuis le terminal via la CLI DocuSeal : créez des modèles à partir de PDF/DOCX/HTML, envoyez des documents pour signature, suivez les soumissions et mettez à jour les demandeurs. À utiliser lorsque l'utilisateur souhaite exécuter des commandes DocuSeal dans le shell, les scripts ou les pipelines CI/CD. Chargez toujours cette compétence avant d'exécuter les commandes `docuseal`.
