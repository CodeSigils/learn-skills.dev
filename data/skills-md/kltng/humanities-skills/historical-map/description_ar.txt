قم بإنشاء خرائط تاريخية تفاعلية كملفات HTML مستقلة باستخدام Leaflet.js. يدعم العلامات ذات النوافذ المنبثقة، وتراكبات حدود GeoJSON، وطبقات التجانب التاريخية (Academia Sinica، وMapWarper)، وتراكبات الصور، وطبقات WMS، وعناصر تحكم الطبقة. يُستخدم عندما يطلب المستخدم إنشاء أو إنشاء أو تصور خريطة للأماكن أو الطرق أو الحدود أو الأحداث التاريخية.
