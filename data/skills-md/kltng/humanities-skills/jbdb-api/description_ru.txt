Запросите API японской биографической базы данных (JBDB), чтобы получить биографические данные об исторических японских личностях. Используйте этот навык при поиске информации о японских исторических деятелях, самураях, монахах, художниках, поэтах или других людях. Применимо для запросов о биографических деталях, родственных отношениях, неродственных связях, событиях, личной истории, занятиях или когда пользователи упоминают конкретные японские имена или идентификаторы людей JBDB.
