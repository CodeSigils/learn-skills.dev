Consulte la API de la base de datos biográfica de Japón (JBDB) para recuperar datos biográficos sobre figuras históricas japonesas. Utilice esta habilidad cuando busque información sobre personajes históricos japoneses, samuráis, monjes, artistas, poetas u otras personas. Aplicable para consultas sobre detalles biográficos, relaciones de parentesco, asociaciones sin parentesco, eventos, historia personal, ocupaciones o cuando los usuarios mencionan nombres japoneses específicos o identificaciones de personas de JBDB.
