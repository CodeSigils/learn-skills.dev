استعلم عن واجهة برمجة تطبيقات قاعدة بيانات السيرة الذاتية اليابانية (JBDB) لاسترداد بيانات السيرة الذاتية حول الشخصيات اليابانية التاريخية. استخدم هذه المهارة عند البحث عن معلومات حول الشخصيات التاريخية اليابانية أو الساموراي أو الرهبان أو الفنانين أو الشعراء أو غيرهم من الأفراد. ينطبق على الاستفسارات حول تفاصيل السيرة الذاتية، وعلاقات القرابة، والارتباطات غير المتعلقة بالقرابة، والأحداث، والتاريخ الشخصي، والمهن، أو عندما يذكر المستخدمون أسماء يابانية محددة أو معرفات الأشخاص في JBDB.
