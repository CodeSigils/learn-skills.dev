Spezifikationsgesteuerter Entwicklungs-Workflow-Manager. Wird verwendet, wenn: (1) eine ENTWURF-Spezifikation aus Eingabedateien oder Rohideen erstellt wird, (2) ein Blockplan aus einer ENTWURF-Spezifikation erstellt wird, (3) eine ENTWURF-Spezifikation implementiert wird (Übergang von ENTWURF zu IMPLEMENTIERT) oder (4) Spezifikationsstatusübergänge verwaltet werden. Wird bei „Spezifikation erstellen“, „Spezifikation entwerfen“, „Spezifikation implementieren“, „Chunk-Plan“, „Spezifikationsworkflow“ oder bei Verweisen auf *-spec.md-Dateien ausgelöst.
