Многоуровневый агент проверки кода для проектов Swift и SwiftUI. Анализирует PR, различия и файлы по шести измерениям: безопасность параллелизма Swift 6+, управление состоянием SwiftUI и современные API, производительность (просмотр обновлений, идентификатор ForEach, отложенная загрузка), безопасность (принудительная развертка, связка ключей, проверка ввода), соответствие архитектуры (MVVM/MVI/TCA, внедрение зависимостей) и стандарты для конкретных проектов из .claude/CLAUDE.md. Выводит структурированные отчеты с критической/высокой/средней/низкой степенью серьезности, положительными отзывами и приоритетными действиями со ссылками на файлы:строки. Используйте, когда пользователь говорит: просмотрите этот PR, просмотрите мой код, просмотрите мои изменения, проверьте этот файл, просмотрите код, проверьте эту кодовую базу, проверьте качество кода, просмотрите незафиксированные изменения, просмотрите все модели представления или упоминает просмотр файлов .swift, навигации, листов, тем или асинхронных шаблонов.
