Mehrschichtiger Codeüberprüfungsagent für Swift- und SwiftUI-Projekte. Analysiert PRs, Unterschiede und Dateien in sechs Dimensionen: Swift 6+-Parallelitätssicherheit, SwiftUI-Statusverwaltung und moderne APIs, Leistung (Ansichtsaktualisierungen, ForEach-Identität, verzögertes Laden), Sicherheit (Auspacken erzwingen, Schlüsselbund, Eingabevalidierung), Architekturkonformität (MVVM/MVI/TCA, Abhängigkeitsinjektion) und projektspezifische Standards von .claude/CLAUDE.md. Gibt strukturierte Berichte mit dem Schweregrad „Kritisch/Hoch/Mittel/Niedrig“, positivem Feedback und priorisierten Aktionselementen mit Datei-Zeilen-Referenzen aus. Wird verwendet, wenn der Benutzer sagt: Überprüfen Sie diese PR, überprüfen Sie meinen Code, überprüfen Sie meine Änderungen, überprüfen Sie diese Datei, überprüfen Sie den Code, überprüfen Sie diese Codebasis, überprüfen Sie die Codequalität, überprüfen Sie nicht festgeschriebene Änderungen, überprüfen Sie alle ViewModels oder erwähnt die Überprüfung von .swift-Dateien, Navigation, Blättern, Themen oder asynchronen Mustern.
