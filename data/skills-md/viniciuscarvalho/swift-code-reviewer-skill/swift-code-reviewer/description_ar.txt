وكيل مراجعة التعليمات البرمجية متعدد الطبقات لمشاريع Swift وSwiftUI. يحلل العلاقات العامة والاختلافات والملفات عبر ستة أبعاد: أمان التزامن Swift 6+، وإدارة حالة SwiftUI وواجهات برمجة التطبيقات الحديثة، والأداء (عرض التحديثات، وهوية ForEach، والتحميل البطيء)، والأمان (فرض إلغاء التغليف، وسلسلة المفاتيح، والتحقق من صحة الإدخال)، والامتثال للهندسة المعمارية (MVVM/MVI/TCA، وحقن التبعية)، والمعايير الخاصة بالمشروع من .claude/CLAUDE.md. إخراج تقارير منظمة ذات خطورة حرجة/عالية/متوسطة/منخفضة، وردود فعل إيجابية، وعناصر عمل ذات أولوية مع مراجع الملف: السطر. يُستخدم عندما يقول المستخدم مراجعة هذا العلاقات العامة، أو مراجعة التعليمات البرمجية الخاصة بي، أو مراجعة التغييرات، أو التحقق من هذا الملف، أو مراجعة التعليمات البرمجية، أو تدقيق قاعدة التعليمات البرمجية هذه، أو التحقق من جودة التعليمات البرمجية، أو مراجعة التغييرات غير الملتزم بها، أو مراجعة جميع نماذج ViewModels، أو الإشارة إلى مراجعة ملفات .swift أو التنقل أو الأوراق أو السمات أو الأنماط غير المتزامنة.
