قم بتوضيح مستندات Markdown تلقائيًا عن طريق تحويل علامات الصور إلى لقطات شاشة للمتصفح أو صور تم إنشاؤها بواسطة الذكاء الاصطناعي، ثم كتابة مخرجات Markdown غنية بالصور. يُستخدم عندما يحتاج المستند إلى لقطات شاشة، أو عناصر مرئية تم إنشاؤها، أو وضع صور دلالية، أو أتمتة الرسوم التوضيحية للمستند من طرف إلى طرف.
