Client Python completo per database Redis e archivio di valori-chiave. Da utilizzare durante la creazione di applicazioni Python che richiedono connettività Redis, incluse le modalità standalone, cluster, sentinel e asincrona con supporto per tutti i comandi Redis, pipeline, pub/sub, scripting Lua, moduli Redis (JSON, ricerca, TimeSeries), RESP3, memorizzazione nella cache lato client, pooling di connessioni e blocco distribuito.
