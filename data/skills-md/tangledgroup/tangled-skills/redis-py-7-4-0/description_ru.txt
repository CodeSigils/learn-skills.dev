Комплексный клиент Python для базы данных Redis и хранилища значений ключей. Используйте при создании приложений Python, требующих подключения Redis, включая автономный, кластерный, дозорный и асинхронный режимы с поддержкой всех команд Redis, конвейеров, публикации/подписки, сценариев Lua, модулей Redis (JSON, Search, TimeSeries), RESP3, кэширования на стороне клиента, пула подключений и распределенной блокировки.
