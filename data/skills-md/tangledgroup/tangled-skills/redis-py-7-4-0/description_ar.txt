عميل Python الشامل لقاعدة بيانات Redis ومخزن القيمة الرئيسية. يُستخدم عند إنشاء تطبيقات Python التي تتطلب اتصال Redis، بما في ذلك الأوضاع المستقلة والكتلة والحارسة وغير المتزامنة مع دعم جميع أوامر Redis وخطوط الأنابيب والنشر/الفرع والبرمجة النصية Lua ووحدات Redis (JSON وSearch وTimeSeries) وRESP3 والتخزين المؤقت من جانب العميل وتجميع الاتصالات والقفل الموزع.
