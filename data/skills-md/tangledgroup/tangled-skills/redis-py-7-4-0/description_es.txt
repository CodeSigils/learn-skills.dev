Cliente Python completo para base de datos Redis y almacén de valores clave. Úselo al crear aplicaciones Python que requieren conectividad de Redis, incluidos los modos independiente, de clúster, centinela y asíncrono con soporte para todos los comandos de Redis, canalizaciones, pub/sub, secuencias de comandos Lua, módulos de Redis (JSON, búsqueda, TimeSeries), RESP3, almacenamiento en caché del lado del cliente, agrupación de conexiones y bloqueo distribuido.
