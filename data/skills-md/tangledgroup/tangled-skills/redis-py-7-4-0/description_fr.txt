Client Python complet pour la base de données Redis et le magasin clé-valeur. À utiliser lors de la création d'applications Python nécessitant une connectivité Redis, y compris les modes autonome, cluster, sentinelle et asynchrone avec prise en charge de toutes les commandes Redis, pipelines, pub/sub, scripts Lua, modules Redis (JSON, Search, TimeSeries), RESP3, mise en cache côté client, regroupement de connexions et verrouillage distribué.
