Führen Sie das Cloudinary-Onboarding für neue oder bestehende Projekte durch einen geschlossenen, Stack-erkannten Setup-Ablauf. Verwenden Sie diese Option, wenn der Benutzer mit Cloudinary beginnen, Cloudinary in einem Repository konfigurieren, Cloudinary in einer IDE- oder Agentenumgebung einrichten, eine vorhandene Integration validieren, MCP oder Fähigkeiten konfigurieren, Anmeldeinformationen sicher verarbeiten, das richtige SDK auswählen, Upload-Voreinstellungen validieren, Liefer-URLs testen, die Umgebungseinrichtung dokumentieren oder die nächsten Schritte identifizieren möchte. Erkennen Sie zuerst den Projektstapel. Nehmen Sie niemals React, Python, Node.js oder ein anderes SDK an, es sei denn, es wird erkannt oder explizit ausgewählt.
