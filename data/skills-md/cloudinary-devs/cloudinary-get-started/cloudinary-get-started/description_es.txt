Guíe la incorporación de Cloudinary para proyectos nuevos o existentes a través de un flujo de configuración cerrado y detectado por pila. Úselo cuando el usuario solicite comenzar con Cloudinary, configurar Cloudinary en un repositorio, configurar Cloudinary en un IDE o entorno de agente, validar una integración existente, configurar MCP o habilidades, manejar credenciales de forma segura, elegir el SDK correcto, validar los ajustes preestablecidos de carga, probar las URL de entrega, documentar la configuración del entorno o identificar los próximos pasos. Detecte primero la pila del proyecto; nunca asuma React, Python, Node.js o cualquier otro SDK a menos que se detecte o se elija explícitamente.
