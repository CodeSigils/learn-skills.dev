Conseils pour la création, le débogage et la révision des applications next.js qui utilisent cloudinary via next-cloudinary et le SDK de nœud cloudinary v2. À utiliser pour les tâches impliquant CldImage, CldVideoPlayer, CldUploadWidget, CldUploadButton, CldOgImage, GetCldImageUrl, GetCldOgImageUrl, GetCldVideoUrl, les téléchargements signés, les téléchargements de serveur, les suppressions, les transformations, les images réactives, les superpositions, les cartes sociales, les variables d'environnement et les erreurs Cloudinary courantes.
