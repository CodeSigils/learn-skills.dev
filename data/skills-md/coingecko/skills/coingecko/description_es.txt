Utilice esta habilidad para cualquier solicitud que involucre datos del mercado de criptomonedas, precios de monedas, volumen de operaciones, capitalización de mercado, gráficos OHLC, datos históricos, intercambios, derivados, NFT, DeFi, datos de tokens en cadena, fondos de liquidez, datos DEX o cualquier cosa impulsada por las API de CoinGecko o GeckoTerminal. Active esta habilidad cada vez que el usuario pregunte sobre precios de criptomonedas, datos de tokens, tendencias del mercado o quiera llamar a cualquier punto final de CoinGecko o GeckoTerminal, incluso si no dicen explícitamente "CoinGecko". También se activa cuando el usuario pregunta sobre las claves API, los límites de velocidad o la autenticación para estas API.
