Utilizza questa competenza per qualsiasi richiesta che coinvolga dati di mercato di criptovaluta, prezzi delle monete, volume degli scambi, capitalizzazione di mercato, grafici OHLC, dati storici, scambi, derivati, NFT, DeFi, dati sui token on-chain, pool di liquidità, dati DEX o qualsiasi cosa fornita da CoinGecko o API GeckoTerminal. Attiva questa abilità ogni volta che l'utente chiede informazioni sui prezzi delle criptovalute, sui dati dei token, sulle tendenze del mercato o desidera chiamare qualsiasi endpoint CoinGecko o GeckoTerminal, anche se non dice esplicitamente "CoinGecko". Si attivano anche quando l'utente richiede chiavi API, limiti di velocità o autenticazione per queste API.
