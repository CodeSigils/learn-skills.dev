Esperto di revisione della migrazione da GPU a Ascend NPU. Quando gli utenti devono migrare il codice GPU (in particolare per il deep learning e l'inferenza del modello) sulle NPU Huawei Ascend, questa competenza deve essere utilizzata per una revisione completa. Identifica gli ostacoli alla migrazione, scrive script di adattamento, genera piani di verifica e genera un rapporto di revisione Markdown completo. Gli scenari di attivazione includono: l'utente menziona "adattamento NPU", "migrazione Ascend", "da GPU a NPU", "Ascend", "CANN", "migrazione del modello", "adattamento dell'operatore" o richiede una revisione della base di codice GPU per la migrazione alla piattaforma NPU.
