Se activa cuando los usuarios mencionan palabras clave como "adaptación de NPU", "migración de Ascend", "GPU a NPU", "Ascend", "CANN", "migración de modelo", "adaptación de operador" o solicitan una revisión de una base de código de GPU para la migración a la plataforma NPU.
