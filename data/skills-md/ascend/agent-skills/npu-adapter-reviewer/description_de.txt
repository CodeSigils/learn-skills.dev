Experte für GPU-zu-Ascend-NPU-Migrationsüberprüfungen. Wenn Benutzer Code von der GPU auf die Huawei Ascend NPU portieren müssen – insbesondere Deep-Learning- und Inferenz-Workloads –, muss diese Fähigkeit für eine vollständige Prüfung aufgerufen werden. Es lokalisiert Migrationsblocker, schreibt Anpassungsskripte, entwirft Validierungspläne und gibt einen vollständigen Markdown-Überprüfungsbericht aus. Wird ausgelöst, wenn Benutzer Schlüsselwörter wie „NPU-Anpassung“, „Ascend-Migration“, „GPU-zu-NPU“, „Ascend“, „CANN“, „Modellmigration“, „Operatoranpassung“ erwähnen oder eine Überprüfung der GPU-Codebasis für die NPU-Portierung anfordern.
