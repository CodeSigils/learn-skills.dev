Experte für die Überprüfung der GPU-zu-Ascend-NPU-Portierung. Wenn Benutzer GPU-Code (insbesondere Deep-Learning- und Modellinferenz-Workloads) auf Huawei Ascend NPUs migrieren müssen, muss diese Fähigkeit für eine vollständige Überprüfung aufgerufen werden. Es lokalisiert GPU-zu-NPU-Migrationsblocker, schreibt Anpassungsskripte, entwickelt Validierungspläne und gibt einen vollständigen Markdown-Überprüfungsbericht aus. Wird ausgelöst, wenn Benutzer Schlüsselwörter wie „NPU-Anpassung“, „Ascend-Migration“, „GPU-zu-NPU“, „Ascend“, „CANN“, „Modellmigration“, „Betreiberanpassung“ erwähnen oder eine Überprüfung einer GPU-Codebasis für die Migration auf die NPU-Plattform anfordern.
