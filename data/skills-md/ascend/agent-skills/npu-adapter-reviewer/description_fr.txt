Expert en révision du portage GPU vers Ascend NPU. Chaque fois qu'un utilisateur a besoin de migrer du code initialement écrit pour les GPU (en particulier les charges de travail d'apprentissage profond ou d'inférence) vers les NPU Huawei Ascend, cette compétence doit être invoquée pour un examen complet. Il identifie les goulots d'étranglement de la migration GPU vers NPU, écrit des scripts d'adaptation, génère des plans de validation et génère un rapport d'examen Markdown complet. Déclenché lorsque l'utilisateur mentionne des mots-clés tels que « adaptation NPU », « migration Ascend », « conversion GPU vers NPU », « Ascend », « CANN », « migration de modèle », « adaptation opérateur » ou demande une révision d'une base de code GPU pour le portage sur la plate-forme NPU.
