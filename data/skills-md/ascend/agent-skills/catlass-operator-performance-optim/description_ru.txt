Руководство по настройке производительности оператора Catlass. Процесс: прочтите руководство по оптимизации Catlass, получите/обновите базовые показатели профилировщика, измените мозаику для каждого руководства, перекомпилируйте, **принудительно сгенерируйте и отобразите отчет о сравнении производительности**, повторите и сравните. Стратегия настройки соответствует документации Catlass; попросите разъяснений, если условия неясны.
