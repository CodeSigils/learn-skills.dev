Debug di precisione dell'operatore AscendC e analisi delle cause principali. Utilizzato quando i test di precisione dell'operatore falliscono (allclose fallisce, deviazione del risultato, uscita tutto zero/NaN, ecc.). Flusso di lavoro: analisi della distribuzione degli errori → revisione puntuale del codice soggetto a errori → isolamento sperimentale → strumentazione printf/DumpTensor → correzione e verifica. Parole chiave: debug di precisione, problema di precisione, risultati incoerenti, posizione dell'errore, errore allclose, deviazione dell'output, NaN, tutto zero, debug di precisione.
