Inicialice un proyecto de operador AscendC y genere un esqueleto de operador compilable.  
Escenarios desencadenantes:  
(1) Solicitudes de usuario para crear un nuevo operador;  
(2) Palabras clave: operador ascendc, nuevo operador, directorio de operadores, inicialización del operador;  
(3) Necesita una implementación rápida basada en la plantilla ascend-kernel.  

Esta habilidad no solo crea directorios sino que también genera archivos estándar "listos para continuar con el desarrollo" y una lista de verificación.
