Initialisieren Sie ein AscendC-Operatorprojekt und generieren Sie ein kompilierbares Operatorgerüst.  
Auslöseszenarien:  
(1) Benutzeranfragen zum Erstellen eines neuen Operators;  
(2) Schlüsselwörter: aufsteigender Operator, neuer Operator, Operatorverzeichnis, Operatorinitialisierung;  
(3) Erfordert eine schnelle Implementierung basierend auf der Ascenden-Kernel-Vorlage.  

Dieser Skill erstellt nicht nur Verzeichnisse, sondern gibt auch „ready-to-continue-development“-Standarddateien und eine Checkliste aus.
