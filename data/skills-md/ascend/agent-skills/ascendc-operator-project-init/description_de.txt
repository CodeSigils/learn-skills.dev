Initialisieren Sie ein AscendC-Operatorprojekt und erstellen Sie ein kompilierbares Operatorgerüst.  
Auslöseszenarien:  
(1) Benutzeranfragen zum Erstellen eines neuen Operators;  
(2) Schlüsselwörter: aufsteigender Operator, neuer Operator, Operatorverzeichnis, Operatorinitialisierung;  
(3) Muss schnell basierend auf der Ascenden-Kernel-Vorlage implementiert werden.  
Dieser Skill erstellt nicht nur Verzeichnisse, sondern gibt auch „ready-to-continue-development“-Standarddateien und Checklisten aus.
