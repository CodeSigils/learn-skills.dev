Конфигурация платформы отслеживания экспериментов SwanLab и управление входом в систему. Сценарии срабатывания: (1) Настройка учетных данных для входа в SwanLab (2) Установка/вход в систему SwanLab внутри контейнера (3) Настройка SwanLab для определенного контейнера (4) Проверка состояния подключения SwanLab. Поддерживает несколько способов получения конфигурации: переменные среды, файлы конфигурации, интерактивный ввод. Может быть вызван другими навыками через `source scripts/functions.sh`.
