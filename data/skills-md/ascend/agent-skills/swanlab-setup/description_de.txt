Konfiguration und Anmeldeverwaltung der SwanLab-Experimentverfolgungsplattform. Auslöseszenarien: (1) SwanLab-Anmeldeinformationen konfigurieren (2) SwanLab in einem Container installieren/anmelden (3) SwanLab für einen bestimmten Container konfigurieren (4) SwanLab-Verbindungsstatus überprüfen. Unterstützt mehrere Möglichkeiten zum Abrufen der Konfiguration: Umgebungsvariablen, Konfigurationsdateien, interaktive Eingabe. Kann von anderen Fähigkeiten über „source scripts/functions.sh“ aufgerufen werden.
