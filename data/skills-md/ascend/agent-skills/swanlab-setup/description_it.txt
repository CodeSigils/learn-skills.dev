Configurazione della piattaforma di monitoraggio degli esperimenti SwanLab e gestione degli accessi. Scenari di attivazione: (1) Configurare le credenziali di accesso SwanLab (2) Installare/accedere a SwanLab all'interno di un contenitore (3) Configurare SwanLab per un contenitore specifico (4) Controllare lo stato della connessione SwanLab. Supporta diversi modi per ottenere la configurazione: variabili di ambiente, file di configurazione, input interattivo. Può essere richiamato da altre competenze tramite "source scripts/functions.sh".
