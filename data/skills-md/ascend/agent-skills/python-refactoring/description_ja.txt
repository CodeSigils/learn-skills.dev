Python コードのリファクタリング スキル。コードの匂いの検出、デザイン パターンの適用、可読性の向上、実践経験をカバーします。このスキルは、ユーザーが「コードのリファクタリング」、「リファクタリング」、「コードの最適化」、「コードの品質の向上」、「コードの匂いレビュー」、「デザイン パターンの適用」、「可読性の向上」を要求する場合、またはコード レビューの要求を送信する場合に使用します。完了後の構造化リファクタリングドキュメントの出力をサポートします（「リファクタリングドキュメントの出力」、「リファクタリングレポートの生成」）。 vllm-ascend リポジトリ内の 20 を超える実際のリファクタリング PR から抽出された実用的なパターンが含まれています。
