Навыки рефакторинга кода Python, включая обнаружение запахов кода, применение шаблонов проектирования, улучшение читаемости и практический опыт. Используйте этот навык, когда пользователь запрашивает «рефакторинг кода», «рефакторинг», «оптимизацию кода», «улучшение качества кода», «проверку запаха кода», «применение шаблонов проектирования», «повышение читаемости» или отправляет запрос на проверку кода. Поддерживает вывод структурированного документа рефакторинга после завершения («выходной документ рефакторинга», «создание отчета о рефакторинге»). Включает практические шаблоны, извлеченные из более чем 20 реальных запросов на рефакторинг в репозитории vllm-ascend.
