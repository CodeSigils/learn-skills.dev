Набор инструментов Ascend NPU CANN + ядра + навыки установки и развертывания NNAL. Поддерживает два метода: установку из пакета запуска, загруженного с официального сайта, и извлечение из образа Docker, охватывающего весь процесс проверки драйверов, загрузки пакета, установки, настройки переменных среды и проверки. Он вызывается, когда пользователю необходимо установить полный набор компонентов CANN или указанную версию CANN по пользовательскому пути.
