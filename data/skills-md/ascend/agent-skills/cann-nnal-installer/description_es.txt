Ascend NPU CANN Toolkit + Kernels + habilidad de instalación e implementación de NNAL. Admite dos métodos: instalar desde un paquete de ejecución descargado del sitio web oficial y extraer desde una imagen de Docker, que cubre todo el proceso de verificación del controlador, descarga del paquete, instalación, configuración de variables de entorno y verificación. Se invoca cuando un usuario necesita instalar el conjunto completo de componentes CANN o una versión específica de CANN en una ruta personalizada.
