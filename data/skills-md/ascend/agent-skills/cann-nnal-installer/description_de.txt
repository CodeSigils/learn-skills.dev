Ascend NPU CANN Toolkit + Kernels + NNAL-Installations- und Bereitstellungsfähigkeiten. Unterstützt zwei Methoden: Installation aus einem von der offiziellen Website heruntergeladenen Ausführungspaket und Extrahieren aus einem Docker-Image. Dabei wird der gesamte Prozess der Treiberprüfung, des Paket-Downloads, der Installation, der Konfiguration von Umgebungsvariablen und der Überprüfung abgedeckt. Es wird aufgerufen, wenn ein Benutzer den vollständigen Satz von CANN-Komponenten oder eine bestimmte Version von CANN in einem benutzerdefinierten Pfad installieren muss.
