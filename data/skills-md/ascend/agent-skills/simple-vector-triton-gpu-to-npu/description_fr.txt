Migrez un simple opérateur Triton de type vectoriel du GPU vers Ascend NPU. À utiliser lorsque les utilisateurs doivent migrer le code Triton vers NPU, reportez-vous à la migration GPU vers NPU, à la migration Triton ou à l'adaptation Ascend. Remarque : les opérateurs présentant des problèmes de compilation ne peuvent pas être migrés automatiquement.
