Migrez les opérateurs Triton simples de type vectoriel du GPU vers Ascend NPU. À utiliser lorsque les utilisateurs doivent migrer le code Triton vers NPU, mentionner la migration GPU vers NPU, la migration Triton ou l'adaptation Ascend. Remarque : les opérateurs présentant des problèmes de compilation ne peuvent pas être migrés automatiquement.
