Tests de performances HCCL (Huawei Collective Communication Library) pour les clusters Ascend NPU. À utiliser pour tester la bande passante de communication distribuée, vérifier la fonctionnalité HCCL et évaluer les opérations collectives telles que AllReduce, AllGather. Couvre l'installation de MPI, les vérifications préalables à plusieurs nœuds (version SSH/CANN/état de santé NPU) et les flux de travail de tests de production.
