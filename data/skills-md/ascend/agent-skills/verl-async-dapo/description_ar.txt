مولد تكوين تدريب DAPO فردي غير متزامن من Verl. سيناريوهات التشغيل: (1) بدء تدريب DAPO أحادي غير متزامن (2) إنشاء برنامج نصي للتدريب (3) تكوين معلمات الميزات (4) فحص ما قبل التدريب. **استراتيجية الميزات**: عندما لا يحدد المستخدم، يتم تمكين ميزات الأداء (flash_attn /dynamic_batch / Remove_padding / gradient_checkpointing) بشكل افتراضي، بينما يتم تعطيل ميزات الذاكرة (إلغاء التحميل / إعادة الحساب) بشكل افتراضي. في حالة OOM، تتم إضافة ميزات الذاكرة تلقائيًا لإعادة المحاولة. **مراقبة التدريب**: بعد البدء، قم بإخراج رابط SwanLab ليتمكن المستخدم من رؤية نفسه، مع إعلام المستخدم فقط بالأخطاء. **مهارة التبعية**: يتم توفير تكوين SwanLab عبر مهارة إعداد swanlab.
