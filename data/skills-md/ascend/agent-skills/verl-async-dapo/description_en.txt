Verl single-asynchronous DAPO training configuration generator. Trigger scenarios: (1) start single-asynchronous DAPO training (2) generate training script (3) configure feature parameters (4) pre‑training check. **Feature strategy**: when the user does not specify, performance features (flash_attn, dynamic_batch, remove_padding, gradient_checkpointing) are enabled by default, while memory features (offload, recompute) are disabled by default. In case of OOM, memory features are automatically added for a retry. **Training monitoring**: after launch, output a SwanLab link for the user to view themselves, notifying the user only on errors. **Dependency skill**: SwanLab configuration is provided via the swanlab‑setup skill.
