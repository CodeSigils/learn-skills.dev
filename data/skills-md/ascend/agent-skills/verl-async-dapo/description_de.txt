Verl Single-asynchroner DAPO-Trainingskonfigurationsgenerator. Auslöseszenarien: (1) Einzelasynchrones DAPO-Training starten (2) Trainingsskript generieren (3) Funktionsparameter konfigurieren (4) Prüfung vor dem Training. **Funktionsstrategie**: Wenn der Benutzer nichts angibt, sind Leistungsfunktionen (flash_attn/dynamic_batch/remove_padding/gradient_checkpointing) standardmäßig aktiviert, während Speicherfunktionen (Offload/Recompute) standardmäßig deaktiviert sind. Im Falle von OOM werden automatisch Speicherfunktionen für einen erneuten Versuch hinzugefügt. **Trainingsüberwachung**: Geben Sie nach dem Start einen SwanLab-Link aus, den der Benutzer selbst anzeigen kann, und benachrichtigen Sie den Benutzer nur bei Fehlern. **Abhängigkeits-Skill**: Die SwanLab-Konfiguration wird über den Swanlab-Setup-Skill bereitgestellt.
