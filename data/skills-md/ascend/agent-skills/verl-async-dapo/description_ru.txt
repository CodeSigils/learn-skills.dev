Одноасинхронный генератор конфигурации обучения DAPO Verl. Сценарии триггера: (1) Запуск одноасинхронного обучения DAPO (2) Создание сценария обучения (3) Настройка параметров функции (4) Проверки перед обучением. **Стратегия функций**: если пользователь не указывает, функции производительности (flash_attn, Dynamic_batch, Remove_padding, Gradient_checkpointing) включаются по умолчанию, а функции памяти (разгрузка, перевычисление) по умолчанию отключаются. В случае OOM функции памяти автоматически добавляются при повторной попытке. **Мониторинг обучения**: после запуска выведите ссылку SwanLab, чтобы пользователь мог просмотреть ее самостоятельно, и уведомляйте пользователя только об ошибках. **Навык зависимостей**: конфигурация SwanLab обеспечивается с помощью навыка Swanlab-setup.
