Одноасинхронный генератор конфигураций обучения Verl DAPO. Сценарии триггера: (1) начать одноасинхронное обучение DAPO (2) создать сценарий обучения (3) настроить параметры функции (4) проверку перед обучением. **Стратегия функций**: если пользователь не указывает, функции производительности (flash_attn/dynamic_batch/remove_padding/gradient_checkpointing) включаются по умолчанию, а функции памяти (разгрузка/перевычисление) по умолчанию отключены. В случае OOM функции памяти автоматически добавляются при повторной попытке. **Мониторинг обучения**: после запуска выводит ссылку SwanLab, чтобы пользователь мог просмотреть себя, уведомляя пользователя только об ошибках. **Навык зависимости**: конфигурация SwanLab обеспечивается с помощью навыка настройки Swanlab.
