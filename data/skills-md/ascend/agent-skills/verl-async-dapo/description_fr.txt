Générateur de configuration de formation DAPO mono-asynchrone Verl. Scénarios de déclenchement : (1) démarrer la formation DAPO mono-asynchrone (2) générer un script de formation (3) configurer les paramètres de fonctionnalité (4) vérification préalable à la formation. **Stratégie de fonctionnalités** : lorsque l'utilisateur ne le précise pas, les fonctionnalités de performances (flash_attn / Dynamic_batch / Remove_padding / gradient_checkpointing) sont activées par défaut, tandis que les fonctionnalités de mémoire (déchargement / recalcul) sont désactivées par défaut. En cas de MOO, les fonctionnalités de mémoire sont automatiquement ajoutées pour une nouvelle tentative. **Surveillance de la formation** : après le démarrage, générez un lien SwanLab pour que l'utilisateur puisse se visualiser, en informant l'utilisateur uniquement des erreurs. **Compétence de dépendance** : la configuration de SwanLab est fournie via la compétence swanlab‑setup.
