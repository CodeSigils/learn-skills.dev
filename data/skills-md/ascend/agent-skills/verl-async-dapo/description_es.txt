Generador de configuración de entrenamiento DAPO único asíncrono Verl. Escenarios de activación: (1) iniciar entrenamiento DAPO asincrónico único (2) generar script de entrenamiento (3) configurar parámetros de funciones (4) verificación previa al entrenamiento. **Estrategia de funciones**: cuando el usuario no lo especifica, las funciones de rendimiento (flash_attn/dynamic_batch/remove_padding/gradiente_checkpointing) están habilitadas de forma predeterminada, mientras que las funciones de memoria (descarga/recalculo) están deshabilitadas de forma predeterminada. En el caso de OOM, las funciones de memoria se agregan automáticamente para un reintento. **Monitoreo de capacitación**: después de comenzar, genere un enlace de SwanLab para que el usuario lo vea, notificándole solo los errores. **Habilidad de dependencia**: la configuración de SwanLab se proporciona a través de la habilidad de configuración de swanlab.
