Ascend Transformer Acceleration Library (ATB) Indice del set di abilità principali (abilità indice). Integra otto competenze principali: installazione e implementazione CANN, compilazione del framework di test ATB, generazione di documenti di progettazione per la sostituzione dell'operatore ATB→ACLNN, migrazione dell'operatore ATB→ACLNN, coprendo l'intero flusso di lavoro di sviluppo di Ascend NPU.
