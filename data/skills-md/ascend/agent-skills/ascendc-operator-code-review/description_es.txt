Habilidades de revisión de código Ascend C. Realizar revisiones de seguridad y cumplimiento del código basadas en una metodología de prueba de hipótesis. Cuando se invoca, se debe proporcionar explícitamente lo siguiente: fragmento de código y descripción de la regla de revisión. DISPARAR cuando: el usuario solicita revisión de código, inspección de código, pregunta sobre problemas de seguridad del código, verifica estándares de codificación o necesita examinar problemas de código específicos (como pérdidas de memoria, desbordamiento de enteros, puntero nulo, etc.). Palabras clave: Ascend C, revisión de código, inspección de código, estándares de seguridad, memoria, puntero, desbordamiento, fuga, estándares de codificación.
