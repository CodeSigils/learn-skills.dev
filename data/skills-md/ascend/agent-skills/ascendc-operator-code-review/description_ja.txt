Ascend C コードレビュースキル。仮説検証手法に基づいて、安全性に準拠したコード検査を実施します。呼び出されるときは、コード スニペットとレビュー ルールの説明を明示的に提供する必要があります。トリガーは次の場合に発生します: ユーザーがコード検査、コードレビューを要求した場合、コードの安全性の問題について質問した場合、コーディング標準をチェックした場合、または特定のコードの問題 (メモリ リーク、整数オーバーフロー、NULL ポインタなど) を調査する必要がある場合。キーワード: Ascend C、コード検査、コードレビュー、安全規格、メモリ、ポインタ、オーバーフロー、リーク、コーディング標準。
