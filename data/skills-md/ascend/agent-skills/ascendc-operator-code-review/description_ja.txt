C コードレビュースキルを向上させます。仮説検証手法に基づいて、セキュリティに準拠したコードのレビューを実施します。呼び出すときに、コード スニペットとレビュー ルールの説明を明示的に提供する必要があります。トリガーは次の場合に発生します: ユーザーがコード レビュー、コード レビューを要求した場合、コードのセキュリティ問題について質問した場合、コーディング標準を確認した場合、または特定のコードの問題 (メモリ リーク、整数オーバーフロー、NULL ポインタなど) を確認する必要がある場合。キーワード: Ascend C、コード レビュー、コード レビュー、セキュリティ標準、メモリ、ポインタ、オーバーフロー、リーク、コーディング標準。
