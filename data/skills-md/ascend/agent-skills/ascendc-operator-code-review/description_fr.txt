Améliorez vos compétences en matière d'inspection du code C. Effectuer des examens de sécurité et de conformité du code sur la base de la méthodologie de test d'hypothèses. Lorsqu’il est invoqué, l’extrait de code et la description de la règle d’inspection doivent être explicitement fournis. DÉCLENCHEMENT lorsque : l'utilisateur demande une inspection du code, une révision du code, pose des questions sur les problèmes de sécurité du code, vérifie les normes de codage ou doit vérifier des problèmes de code spécifiques (tels que des fuites de mémoire, un dépassement d'entier, des pointeurs nuls, etc.). Mots clés : Ascend C, inspection du code, révision du code, conformité de sécurité, mémoire, pointeur, débordement, fuite, normes de codage.
