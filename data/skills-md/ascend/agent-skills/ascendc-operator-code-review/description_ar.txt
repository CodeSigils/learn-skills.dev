مهارات مراجعة كود C التصاعدي. قم بإجراء مراجعة التعليمات البرمجية المتوافقة مع معايير السلامة بناءً على منهجية اختبار الفرضيات. يجب توفير ما يلي بشكل صريح: مقتطف الرمز ومراجعة وصف القاعدة عند استدعائها. يتم تشغيله عندما: يطلب المستخدم مراجعة التعليمات البرمجية، أو فحص التعليمات البرمجية، أو يسأل عن مشكلات أمان التعليمات البرمجية، أو يتحقق من معايير الترميز، أو يحتاج إلى فحص مشكلات محددة في التعليمات البرمجية (على سبيل المثال، تسرب الذاكرة، أو تجاوز عدد صحيح، أو مؤشرات فارغة). الكلمات المفتاحية: Ascend C، مراجعة الكود، فحص الكود، معايير السلامة، الذاكرة، المؤشر، الفائض، التسرب، معايير الترميز.
