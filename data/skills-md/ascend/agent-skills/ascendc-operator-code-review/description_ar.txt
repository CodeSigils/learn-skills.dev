مهارات مراجعة كود C التصاعدي. قم بإجراء مراجعة متوافقة مع الأمان للكود بناءً على منهجية اختبار الفرضيات. يجب توفير مقتطف الشفرة بوضوح عند استدعائه ووصف قاعدة المراجعة. يتم تشغيله عندما: يطلب المستخدم مراجعة التعليمات البرمجية، أو مراجعة التعليمات البرمجية، أو يسأل عن مشكلات أمان التعليمات البرمجية، أو يتحقق من معايير الترميز، أو يحتاج إلى التحقق من مشكلات محددة في التعليمات البرمجية (مثل تسرب الذاكرة، أو تجاوز عدد صحيح، أو مؤشرات فارغة، وما إلى ذلك). الكلمات المفتاحية: Ascend C، مراجعة الكود، مراجعة الكود، معايير الأمان، الذاكرة، المؤشرات، التجاوز، التسريبات، معايير الترميز.
