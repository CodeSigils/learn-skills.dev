Сгенерируйте код ядра Triton для Ascend NPU на основе проектной документации оператора. Используется, когда пользователям необходимо реализовать ядра операторов Triton или преобразовать документы с требованиями в исполняемый код. Основные возможности: (1) Анализ документов с требованиями для подтверждения вычислительной логики (2) Разработка стратегий разбиения на плитки (3) Генерация высокопроизводительного кода ядра (4) Генерация тестового кода для проверки правильности.
