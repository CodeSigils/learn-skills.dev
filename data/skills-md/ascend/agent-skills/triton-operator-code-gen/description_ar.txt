قم بإنشاء رمز Triton kernel لـ Ascend NPU استنادًا إلى مستندات تصميم المشغل. يُستخدم عندما يحتاج المستخدمون إلى تنفيذ نواة مشغل Triton أو تحويل مستندات المتطلبات إلى تعليمات برمجية قابلة للتنفيذ. القدرات الأساسية: (1) تحليل مستندات المتطلبات لتأكيد المنطق الحسابي (2) تصميم استراتيجيات تقسيم التبليط (3) إنشاء كود kernel عالي الأداء (4) إنشاء كود اختبار للتحقق من صحته.
