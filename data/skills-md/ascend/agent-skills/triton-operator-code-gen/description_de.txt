Generieren Sie Triton-Kernelcode für Ascend NPU basierend auf Operator-Designdokumenten. Wird verwendet, wenn Benutzer Triton-Operator-Kernel implementieren oder Anforderungsdokumente in ausführbaren Code umwandeln müssen. Kernfunktionen: (1) Analysieren von Anforderungsdokumenten zur Bestätigung der Rechenlogik (2) Entwerfen von Kachelstrategien (3) Generieren von leistungsstarkem Kernelcode (4) Generieren von Testcode zur Überprüfung der Korrektheit.
