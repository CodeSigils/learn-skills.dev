Générez le code du noyau Triton pour Ascend NPU sur la base des documents de conception de l'opérateur. Utilisé lorsque les utilisateurs doivent implémenter les noyaux d'opérateur Triton ou transformer les documents d'exigences en code exécutable. Capacités de base : (1) Analyser les documents d'exigences pour confirmer la logique de calcul (2) Concevoir des stratégies de mosaïque (3) Générer du code de noyau hautes performances (4) Générer du code de test pour vérifier l'exactitude.
