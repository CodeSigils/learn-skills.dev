Genere código del kernel Triton para Ascend NPU basado en documentos de diseño del operador. Se utiliza cuando los usuarios necesitan implementar núcleos de operador Triton o transformar documentos de requisitos en código ejecutable. Capacidades principales: (1) Analizar documentos de requisitos para confirmar la lógica computacional (2) Diseñar estrategias de ordenamiento en mosaico (3) Generar código de kernel de alto rendimiento (4) Generar código de prueba para verificar la corrección.
