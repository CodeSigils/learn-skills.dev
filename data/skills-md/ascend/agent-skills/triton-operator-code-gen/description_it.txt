Genera il codice kernel Triton per Ascend NPU in base ai documenti di progettazione dell'operatore. Utilizzato quando gli utenti devono implementare i kernel degli operatori Triton o trasformare i documenti dei requisiti in codice eseguibile. Funzionalità principali: (1) Analizzare i documenti dei requisiti per confermare la logica computazionale (2) Progettare strategie di affiancamento (3) Generare codice kernel ad alte prestazioni (4) Generare codice di test per verificare la correttezza.
