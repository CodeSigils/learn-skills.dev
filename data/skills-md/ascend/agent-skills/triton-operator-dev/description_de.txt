Orchestrierung der gesamten Prozessentwicklungsaufgabe des Ascend Triton-Operators. Wird verwendet, wenn Benutzer Triton-Operatoren entwickeln müssen, die den gesamten Ablauf der Umgebungseinrichtung → Anforderungsdesign → Codegenerierung → statische Überprüfung → Genauigkeitsüberprüfung → Leistungsbewertung → Dokumentationserstellung → Leistungsoptimierung abdecken.
