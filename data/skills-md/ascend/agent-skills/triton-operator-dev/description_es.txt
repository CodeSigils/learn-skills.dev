Orquestación de tareas de desarrollo de proceso completo del operador de Ascend Triton. Se utiliza cuando los usuarios necesitan desarrollar operadores Triton, cubriendo el flujo de trabajo completo desde la configuración del entorno → diseño de requisitos → generación de código → revisión estática → verificación de precisión → evaluación del rendimiento → generación de documentación → optimización del rendimiento.
