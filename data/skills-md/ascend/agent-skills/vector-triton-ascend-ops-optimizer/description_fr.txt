Compétences approfondies en optimisation des performances pour les opérateurs Triton sur les NPU Ascend, dédiées à la réalisation des améliorations de performances demandées par les utilisateurs pour les opérateurs Triton. Les technologies de base incluent, sans s'y limiter, la planification de la capacité Unified Buffer (UB), le traitement parallèle multi-jetons, le parallélisme des pipelines MTE/Vector et l'optimisation des masques. Cette compétence doit être déclenchée chaque fois que l'utilisateur mentionne : Optimisation des performances de l'opérateur Triton de type vectoriel sur les NPU Ascend.
