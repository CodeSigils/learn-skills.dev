Ascend NPU Triton Operator Deep Performance Optimization Skill, dédiée à la réalisation des améliorations de performances requises par l'utilisateur pour les opérateurs Triton sur Ascend NPU. Les technologies de base incluent, sans s'y limiter : la planification de la capacité Unified Buffer (UB), le traitement parallèle multi-token, le parallélisme des pipelines MTE/Vector, l'optimisation des masques, etc. Cette compétence doit être déclenchée lorsque les utilisateurs mentionnent les éléments suivants : Optimisation des performances de l'opérateur Triton de classe Vector sur Ascend NPU.
