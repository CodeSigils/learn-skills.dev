مراجعة رمز الأمان متعدد اللغات (مراجعة رمز الأمان). الكشف المنهجي عن الثغرات الأمنية وإرشادات معالجتها لملفات Python وC++ وShell وMarkdown. يغطي معايير الترميز الآمن OWASP Top10 وCWE Top25 وCERT. عندما يذكر المستخدم أيًا مما يلي، يجب استخدام هذه الإمكانية: مراجعة الأمان، مراجعة التعليمات البرمجية الآمنة، مراجعة الأمان، فحوصات الأمان في مراجعة الكود، فحص الثغرات الأمنية، فحوصات الامتثال الأمني ​​(CWE/CERT/OWASP)، كتابة التعليمات البرمجية الآمنة، التحقق من أمان التعليمات البرمجية، تدقيق أمان خدمة الاستدلال، التحقق من أمان الرمز المميز متعدد الوسائط، الحماية من هجوم JSON المتداخل. حتى إذا لم يذكر المستخدم صراحةً "مراجعة الأمان"، فإن أي مناقشة حول تقييم أمان التعليمات البرمجية أو اكتشاف الثغرات الأمنية أو أفضل ممارسات الأمان يجب أن تؤدي إلى تفعيل هذه الإمكانية.
