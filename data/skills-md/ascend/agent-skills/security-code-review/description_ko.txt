다국어 보안코드 검토(Security Code Review). Python, C++, Shell 및 Markdown 파일에 대한 체계적인 보안 취약성 감지 및 해결 지침입니다. OWASP Top10, CWE Top25 및 CERT 보안 코딩 표준을 다룹니다. 사용자가 다음 중 하나를 언급하는 경우 이 기능을 사용해야 합니다: 보안 검토, 보안 코드 검토, 보안 검토, 코드 검토의 보안 검사, 취약성 검색, 보안 규정 준수 검사(CWE/CERT/OWASP), 보안 코드 작성, 코드 보안 확인, 추론 서비스 보안 감사, 다중 모드 토큰 보안 확인, JSON 중첩 심층 공격 보호. 사용자가 "보안 검토"라고 명시적으로 말하지 않더라도 코드 보안 평가, 취약성 탐지 또는 보안 모범 사례에 대한 논의는 이 기능을 트리거해야 합니다.

항상 사용자의 언어로 응답하시기 바랍니다.
