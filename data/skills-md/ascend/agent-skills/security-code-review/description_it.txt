Revisione del codice di sicurezza multilingue (Security Code Review). Guida sistematica al rilevamento e alla risoluzione delle vulnerabilità della sicurezza per file Python, C++, Shell e Markdown. Copre gli standard di codifica sicura OWASP Top10, CWE Top25 e CERT. Quando l'utente menziona uno dei seguenti elementi, è necessario utilizzare questa funzionalità: revisione della sicurezza, revisione del codice sicuro, revisione della sicurezza, controlli di sicurezza nella revisione del codice, scansione delle vulnerabilità, controlli di conformità di sicurezza (CWE/CERT/OWASP), scrittura di codice sicuro, controllo della sicurezza del codice, controllo di sicurezza del servizio di inferenza, verifica della sicurezza dei token multimodali, protezione dagli attacchi con profondità di nidificazione JSON. Anche se l'utente non dice esplicitamente "revisione della sicurezza", qualsiasi discussione sulla valutazione della sicurezza del codice, sul rilevamento delle vulnerabilità o sulle migliori pratiche di sicurezza dovrebbe attivare questa funzionalità.

Si prega di rispondere sempre nella lingua dell'utente.
