Révision du code de sécurité multilingue (Security Code Review). Détection systématique des vulnérabilités de sécurité et conseils de correction pour les fichiers Python, C++, Shell et Markdown. Couvre les normes de codage sécurisé OWASP Top10, CWE Top25 et CERT. Lorsque l'utilisateur mentionne l'un des éléments suivants, cette fonctionnalité doit être utilisée : examen de la sécurité, examen du code sécurisé, examen de la sécurité, contrôles de sécurité dans l'examen du code, analyse des vulnérabilités, contrôles de conformité de sécurité (CWE/CERT/OWASP), écriture de code sécurisé, vérification de la sécurité du code, audit de sécurité du service d'inférence, vérification de la sécurité des jetons multimodaux, protection contre les attaques en profondeur d'imbrication JSON. Même si l'utilisateur ne dit pas explicitement « examen de sécurité », toute discussion sur l'évaluation de la sécurité du code, la détection des vulnérabilités ou les meilleures pratiques de sécurité devrait déclencher cette fonctionnalité.

Veuillez toujours répondre dans la langue de l’utilisateur.
