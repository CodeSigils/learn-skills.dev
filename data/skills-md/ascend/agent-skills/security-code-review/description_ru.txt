Многоязычная проверка кода безопасности (Security Code Review). Систематическое руководство по обнаружению и устранению уязвимостей безопасности для файлов Python, C++, Shell и Markdown. Охватывает стандарты безопасного кодирования OWASP Top10, CWE Top25 и CERT. Когда пользователи упоминают что-либо из следующего, необходимо использовать эту возможность: проверка безопасности, проверка кода безопасности, проверки безопасности при проверке кода, сканирование уязвимостей, проверки соответствия требованиям безопасности (CWE/CERT/OWASP), написание безопасного кода, проверка безопасности кода, аудит безопасности службы вывода, проверка безопасности мультимодальных токенов, защита от атак глубины вложения JSON. Даже если пользователь явно не говорит «проверка безопасности», если речь идет об оценке безопасности кода, обнаружении уязвимостей или передовом опыте безопасности, эта возможность должна быть активирована. 

Пожалуйста, всегда отвечайте на языке пользователя.
