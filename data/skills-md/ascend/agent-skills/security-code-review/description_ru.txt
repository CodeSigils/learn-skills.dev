Многоязычная проверка кода безопасности (Security Code Review). Систематическое руководство по обнаружению и устранению уязвимостей безопасности для файлов Python, C++, Shell и Markdown. Охватывает стандарты безопасного кодирования OWASP Top10, CWE Top25 и CERT. Когда пользователь упоминает любое из следующих действий, необходимо использовать эту возможность: проверка безопасности, проверка безопасного кода, проверка безопасности, проверки безопасности при проверке кода, сканирование уязвимостей, проверки соответствия требованиям безопасности (CWE/CERT/OWASP), написание безопасного кода, проверка безопасности кода, аудит безопасности службы вывода, проверка безопасности мультимодальных токенов, защита от атак с глубиной вложения JSON. Даже если пользователь явно не говорит «проверка безопасности», любое обсуждение оценки безопасности кода, обнаружения уязвимостей или лучших практик безопасности должно активировать эту возможность.

Пожалуйста, всегда отвечайте на языке пользователя.
