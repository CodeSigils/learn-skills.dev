Überprüfung des mehrsprachigen Sicherheitscodes (Security Code Review). Systematische Anleitung zur Erkennung und Behebung von Sicherheitslücken für Python-, C++-, Shell- und Markdown-Dateien. Deckt die sicheren Codierungsstandards OWASP Top10, CWE Top25 und CERT ab. Wenn der Benutzer Folgendes erwähnt, muss diese Funktion genutzt werden: Sicherheitsüberprüfung, sichere Codeüberprüfung, Sicherheitsüberprüfung, Sicherheitsprüfungen bei der Codeüberprüfung, Schwachstellenscan, Sicherheitskonformitätsprüfungen (CWE/CERT/OWASP), Schreiben von sicherem Code, Überprüfung der Codesicherheit, Sicherheitsüberprüfung des Inferenzdienstes, multimodale Token-Sicherheitsüberprüfung, JSON-Verschachtelungstiefen-Angriffsschutz. Selbst wenn der Benutzer nicht ausdrücklich „Sicherheitsüberprüfung“ sagt, sollte jede Diskussion über die Bewertung der Codesicherheit, die Erkennung von Schwachstellen oder bewährte Sicherheitspraktiken diese Funktion auslösen.

Bitte antworten Sie immer in der Sprache des Benutzers.
