Полный набор инструментов для преобразования моделей Huawei Ascend NPU и сквозной адаптации вывода. Рабочий процесс 1 автоматически обнаруживает входные формы и параметры из исходного кода пользователя. Рабочий процесс 2 экспортирует модели PyTorch в ONNX. Рабочий процесс 3 преобразует ONNX в .om через ATC с поддержкой нескольких версий CANN. Рабочий процесс 4 адаптирует полный конвейер вывода пользователя (предварительная обработка + модель + постобработка) для сквозной работы на NPU. Рабочий процесс 5 проверяет точность между выходными данными ONNX и OM. Рабочий процесс 6 создает воспроизводимый файл README. Поддерживает любую стандартную модель PyTorch/ONNX. Используйте при преобразовании, тестировании или развертывании моделей на процессорах Ascend AI.
