Boîte à outils complète pour la conversion du modèle Huawei Ascend NPU et l'adaptation de l'inférence de bout en bout. Workflow 1 découvre automatiquement les formes et les paramètres d'entrée à partir du code source de l'utilisateur. Workflow 2 exporte les modèles PyTorch vers ONNX. Workflow 3 convertit ONNX en .om via ATC avec prise en charge de versions multi-CANN. Workflow 4 adapte le pipeline d'inférence complet de l'utilisateur (prétraitement + modèle + post-traitement) pour s'exécuter de bout en bout sur NPU. Workflow 5 vérifie la précision entre les sorties ONNX et OM. Workflow 6 génère un fichier README reproductible. Prend en charge n’importe quel modèle PyTorch/ONNX standard. À utiliser lors de la conversion, du test ou du déploiement de modèles sur les processeurs Ascend AI.
