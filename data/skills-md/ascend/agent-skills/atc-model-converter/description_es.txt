Kit de herramientas completo para la conversión del modelo Huawei Ascend NPU y la adaptación de inferencia de un extremo a otro. El flujo de trabajo 1 descubre automáticamente formas y parámetros de entrada del código fuente del usuario. Workflow 2 exporta modelos de PyTorch a ONNX. Workflow 3 convierte ONNX a .om a través de ATC con soporte para versiones multi-CANN. El flujo de trabajo 4 adapta el proceso de inferencia completo del usuario (preprocesamiento + modelo + posprocesamiento) para ejecutarse de un extremo a otro en NPU. El flujo de trabajo 5 verifica la precisión entre las salidas ONNX y OM. El flujo de trabajo 6 genera un archivo README reproducible. Admite cualquier modelo estándar de PyTorch/ONNX. Úselo al convertir, probar o implementar modelos en procesadores Ascend AI.
