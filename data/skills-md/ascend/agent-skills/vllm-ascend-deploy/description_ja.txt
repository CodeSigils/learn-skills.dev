Ascend NPU プラットフォーム vLLM 大規模モデル推論サービスのワンクリック導入。トリガー: ユーザーが「モデル名をデプロイ」、「NPU デプロイ モデル」、「vllmserve」と発言します。プロセス: SSH チェック → NPU チェック → 構成検出 (検証が必要) → ユーザー確認 → 導入 → cron 監視 → 検証。制約: (1) 構成は公式ドキュメントから検証する必要があり、推測は禁止されています。 (2) バックグラウンド起動は cron で監視する必要があり、手動ポーリングは禁止されています。 Qwen/Qwen3.5、GLM、DeepSeek、Kimiをサポートします。
