Развертывание службы вывода больших моделей платформы Ascend NPU vLLM в один клик. Триггер: пользователь говорит «имя_модели развертывания», «модель развертывания NPU», «обслуживание vllm». Процесс: проверка SSH → проверка NPU → обнаружение конфигурации (должно быть проверено) → подтверждение пользователя → развертывание → мониторинг cron → проверка. Ограничения: (1) конфигурация должна быть проверена на основе официальной документации, догадки запрещены; (2) фоновый запуск должен контролироваться с помощью cron, ручной опрос запрещен. Поддерживает Qwen/Qwen3.5, GLM, DeepSeek, Кими.
