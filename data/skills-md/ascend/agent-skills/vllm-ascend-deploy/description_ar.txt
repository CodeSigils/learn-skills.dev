منصة Ascend NPU vLLM، خدمة الاستدلال للنموذج الكبير، النشر بنقرة واحدة. المشغل: يقول المستخدم "نشر نموذج_اسم"، و"نموذج نشر NPU"، و"خدمة vllm". العملية: فحص SSH ← فحص NPU ← اكتشاف التكوين (يجب التحقق منه) ← تأكيد المستخدم ← النشر ← مراقبة cron ← التحقق. القيود: (1) يجب التحقق من صحة التكوين من الوثائق الرسمية، ويحظر التخمين؛ (2) يجب مراقبة إطلاق الخلفية باستخدام كرون، ويحظر الاقتراع اليدوي. يدعم Qwen/Qwen3.5، GLM، DeepSeek، Kimi.
