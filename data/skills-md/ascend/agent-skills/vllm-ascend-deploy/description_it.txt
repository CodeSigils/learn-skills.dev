Distribuzione con un solo clic del servizio di inferenza di modelli di grandi dimensioni vLLM della piattaforma NPU Ascend. Trigger: l'utente dice "deploy model_name", "NPU deploy model", "vllm serve". Processo: controllo SSH → controllo NPU → rilevamento della configurazione (deve essere verificato) → conferma dell'utente → distribuzione → monitoraggio cron → verifica. Vincoli: (1) la configurazione deve essere convalidata dalla documentazione ufficiale, è vietato indovinare; (2) il lancio in background deve essere monitorato con cron, il polling manuale è vietato. Supporta Qwen/Qwen3.5, GLM, DeepSeek, Kimi.
