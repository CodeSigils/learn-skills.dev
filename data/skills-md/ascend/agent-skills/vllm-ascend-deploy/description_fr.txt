Déploiement en un clic du service d'inférence de grand modèle vLLM de la plateforme NPU Ascend. Déclencheur : l'utilisateur dit « déployer le nom du modèle », « modèle de déploiement NPU », « vllm serve ». Processus : vérification SSH → vérification NPU → découverte de la configuration (doit être vérifiée) → confirmation de l'utilisateur → déploiement → surveillance cron → vérification. Contraintes : (1) la configuration doit être validée à partir de la documentation officielle, il est interdit de deviner ; (2) le lancement en arrière-plan doit être surveillé avec cron, l'interrogation manuelle est interdite. Prend en charge Qwen/Qwen3.5, GLM, DeepSeek, Kimi.
