La solution de secours sans MCP. Pilote un espace de travail Sillage sur l'API REST plain v2 lorsque le MCP Sillage ne peut pas être installé — apprend à Claude comment s'authentifier avec une clé `sk_live_` et appeler chaque point de terminaison (personnage, comptes cibles, couverture/mapping de compte, listes de surveillance, agents, exécutions de signaux, signaux, contenus) pour exécuter la même configuration et modifier les boucles décrites par les compétences MCP. À utiliser lorsqu'il n'y a pas de connexion MCP, lorsqu'un client est sur un éditeur sans support MCP ou lorsque vous devez scripter Sillage à partir de curl/HTTP. À utiliser lorsque vous entendez : "pas de MCP", "impossible d'installer le MCP", "utiliser l'API à la place", "appeler l'API Sillage", "curl Sillage", "REST fallback", "sk_live", "configurer l'espace de travail via HTTP".
