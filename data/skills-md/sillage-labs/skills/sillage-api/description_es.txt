La alternativa sin MCP. Dirige un espacio de trabajo de Sillage a través de la API REST v2 simple cuando no se puede instalar Sillage MCP: le enseña a Claude cómo autenticarse con una clave `sk_live_` y llamar a cada punto final (persona, cuentas de destino, cobertura/mapeo de cuentas, listas de seguimiento, agentes, ejecuciones de señales, señales, contenidos) para ejecutar los mismos bucles de configuración y edición que describen las habilidades de MCP. Úselo cuando no haya conexión MCP, cuando un cliente esté en un editor sin soporte MCP o cuando deba escribir un script de Sillage desde curl/HTTP. Úselo cuando escuche: "no hay MCP", "no se puede instalar el MCP", "use la API en su lugar", "llame a la API de Sillage", "curl Sillage", "respaldo de REST", "sk_live", "configure el espacio de trabajo a través de HTTP".
