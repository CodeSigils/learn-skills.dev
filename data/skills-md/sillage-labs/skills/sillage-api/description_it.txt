Il fallback senza MCP. Gestisce uno spazio di lavoro Sillage sulla semplice API REST v2 quando Sillage MCP non può essere installato: insegna a Claude come autenticarsi con una chiave `sk_live_` e chiamare ogni endpoint (persona, account di destinazione, copertura/mappatura account, watchlist, agenti, esecuzioni di segnali, segnali, contenuti) per eseguire la stessa configurazione e modificare i loop descritti dalle competenze MCP. Da utilizzare quando non è presente alcuna connessione MCP, quando un client si trova su un editor senza supporto MCP o quando è necessario eseguire lo script Sillage da curl/HTTP. Utilizzare quando si sente: "no MCP", "impossibile installare MCP", "usa invece l'API", "chiama l'API Sillage", "curl Sillage", "fallback REST", "sk_live", "imposta l'area di lavoro su HTTP".
