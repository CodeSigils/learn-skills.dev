الإجراء الاحتياطي الأقل لـ MCP. تشغيل مساحة عمل Sillage عبر واجهة برمجة تطبيقات REST v2 العادية عندما لا يمكن تثبيت Sillage MCP - يعلم Claude كيفية المصادقة باستخدام مفتاح `sk_live_` واستدعاء كل نقطة نهاية (الشخصية، والحسابات المستهدفة، والتغطية/رسم خرائط الحساب، وقوائم المراقبة، والوكلاء، وتشغيل الإشارات، والإشارات، والمحتويات) لتشغيل نفس حلقات الإعداد والتحرير التي تصفها مهارات MCP. يُستخدم في حالة عدم وجود اتصال MCP، أو عندما يكون العميل على محرر بدون دعم MCP، أو عندما يتعين عليك كتابة Sillage من curl/HTTP. استخدمه عندما تسمع: "لا يوجد MCP"، "لا يمكن تثبيت MCP"، "استخدم واجهة برمجة التطبيقات بدلاً من ذلك"، "استدعاء Sillage API"، "curl Sillage"، "REST Fallback"، "sk_live"، "إعداد مساحة العمل عبر HTTP".
