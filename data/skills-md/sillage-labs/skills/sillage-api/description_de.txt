Der MCP-freie Fallback. Steuert einen Sillage-Arbeitsbereich über die einfache v2-REST-API, wenn das Sillage MCP nicht installiert werden kann – bringt Claude bei, wie man sich mit einem „sk_live_“-Schlüssel authentifiziert und jeden Endpunkt (Persona, Zielkonten, Abdeckung/Kontozuordnung, Überwachungslisten, Agenten, Signalläufe, Signale, Inhalte) aufruft, um die gleichen Setup- und Bearbeitungsschleifen auszuführen, die die MCP-Fähigkeiten beschreiben. Verwenden Sie diese Option, wenn keine MCP-Verbindung besteht, wenn sich ein Client in einem Editor ohne MCP-Unterstützung befindet oder wenn Sie Sillage über Curl/HTTP skripten müssen. Verwenden Sie diese Option, wenn Sie hören: „kein MCP“, „MCP kann nicht installiert werden“, „stattdessen die API verwenden“, „die Sillage-API aufrufen“, „curl Sillage“, „REST-Fallback“, „sk_live“, „den Arbeitsbereich über HTTP einrichten“.
