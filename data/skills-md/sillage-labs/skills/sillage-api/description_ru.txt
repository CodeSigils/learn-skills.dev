Резервный вариант без MCP. Управляет рабочим пространством Sillage через простой REST API версии 2, когда Sillage MCP не может быть установлен — учит Клода, как аутентифицироваться с помощью ключа `sk_live_` и вызывать каждую конечную точку (персону, целевые учетные записи, покрытие/сопоставление учетных записей, списки наблюдения, агенты, прогоны сигналов, сигналы, содержимое) для запуска тех же циклов настройки и редактирования, которые описаны навыками MCP. Используйте, когда нет соединения MCP, когда клиент находится в редакторе без поддержки MCP или когда вам необходимо написать сценарий Sillage из Curl/HTTP. Используйте, когда слышите: «нет MCP», «невозможно установить MCP», «вместо этого используйте API», «вызовите Sillage API», «curl Sillage», «резервный вариант REST», «sk_live», «настройте рабочую область через HTTP».
