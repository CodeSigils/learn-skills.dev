Richtet einen neuen Sillage-Arbeitsbereich ein und bearbeitet einen vorhandenen sicher über das MCP – die Schreib- und Bearbeitungs-Engine hinter dem Targeting. Führt die Setup-Schleife (Persona → Zielkonten → Abdeckung → Beobachtungslisten → Agenten → Signalläufe) und die Bearbeitungsschleife (aktuellen Status lesen → Diff → Patch) aus und berücksichtigt dabei die Schreibregeln, die jede Änderung sicher machen. Verwenden Sie diese Option, wenn Sie bestätigtes Targeting anwenden, einen Live-Arbeitsbereich ändern oder einen halbkonfigurierten Arbeitsbereich reparieren. Verwenden Sie diese Option, wenn Sie Folgendes hören: „Meinen Arbeitsbereich einrichten“, „Dieses Konto integrieren“, „Meine Persona bearbeiten“, „Mein Targeting aktualisieren“, „Mitbewerber hinzufügen“, „Zielkonten hinzufügen“, „Meine Schlüsselwörter ändern“, „Diesen Agenten anhalten“, „Agenten erneut ausführen“, „Meinen Arbeitsbereich reparieren“, „Mein Setup abgleichen“.
