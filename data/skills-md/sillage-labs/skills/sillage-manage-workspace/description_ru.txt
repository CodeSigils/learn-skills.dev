Создает новое рабочее пространство Sillage и безопасно редактирует существующее через MCP — механизм записи и редактирования, лежащий в основе таргетинга. Запускает цикл настройки (персона → целевые учетные записи → покрытие → списки наблюдения → агенты → прогоны сигналов) и цикл редактирования (чтение текущего состояния → различия → патч), соблюдая правила записи, которые делают каждое изменение безопасным. Используйте при применении подтвержденного таргетинга, изменении действующего рабочего пространства или исправлении наполовину настроенного. Используйте его, когда слышите: «настроить мое рабочее пространство», «подключиться к этой учетной записи», «изменить мою личность», «обновить таргетинг», «добавить конкурента», «добавить целевые учетные записи», «изменить мои ключевые слова», «приостановить работу этого агента», «перезапустить агентов», «исправить мое рабочее пространство», «согласовать мои настройки».
