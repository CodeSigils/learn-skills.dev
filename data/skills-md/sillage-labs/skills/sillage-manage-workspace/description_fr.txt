Crée un nouvel espace de travail Sillage et modifie en toute sécurité un espace existant via le MCP – le moteur d'écriture et d'édition derrière le ciblage. Exécute la boucle de configuration (persona → comptes cibles → couverture → listes de surveillance → agents → exécutions de signaux) et la boucle d'édition (lecture de l'état actuel → diff → patch), en respectant les règles d'écriture qui sécurisent chaque modification. À utiliser lors de l'application d'un ciblage confirmé, de la modification d'un espace de travail actif ou de la correction d'un espace à moitié configuré. À utiliser lorsque vous entendez : « configurer mon espace de travail », « intégrer ce compte », « modifier mon personnage », « mettre à jour mon ciblage », « ajouter un concurrent », « ajouter des comptes cibles », « modifier mes mots clés », « suspendre cet agent », « réexécuter les agents », « corriger mon espace de travail », « réconcilier ma configuration ».
