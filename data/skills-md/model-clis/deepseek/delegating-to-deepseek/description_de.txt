Verwenden Sie DeepSeek für begrenzte, objektive Worker-Aufgaben, wenn die Arbeit eine mehrstufige oder dateiübergreifende Suche, eine wiederholte Inspektion, eine Sammlung umfangreicher Beweise, eine Reproduktion oder Triage von Testfehlern, eine Verifizierung anhand expliziter Kriterien oder eine Implementierung erfordert, deren Verhalten, Dateiumfang und Akzeptanzkriterien bereits festgelegt sind. Verwenden Sie es auch immer dann, wenn der Benutzer DeepSeek, ein zweites Modell, Subagenten, Delegation oder parallele Arbeit erwähnt. Delegieren Sie Empfehlungen, Architektur- oder Produktentscheidungen, Risikobeurteilungen, Genehmigungen oder abschließende Überprüfungen nicht, es sei denn, der Benutzer bittet ausdrücklich um die Meinung von DeepSeek oder um ein Brainstorming mit mehreren Modellen.
