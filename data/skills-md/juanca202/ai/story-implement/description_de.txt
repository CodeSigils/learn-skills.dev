Verwenden Sie das Gerät, um es aus einer Benutzerhistorie des Ortes zu entfernen oder auszugeben. Benutzen Sie einfach die Geschichte oder den Raum, bis er im Status „Bereit“ erscheint. Sie können dies auch tun, wenn der Benutzer „Tareas auswerfen“, „Kodieren“, „in die USA auslagern“, „in die TK eintragen“ oder eine andere Variante nennt, die zwingend einen Code für eine spezifische Geschichte oder einen bestimmten Namen schreiben muss.
