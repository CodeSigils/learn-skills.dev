Erstellen oder Aktualisieren einer Historia de Usuario. Wenn Sie dies tun, müssen Sie Nutzungsgeschichten erstellen, dokumentieren, aktualisieren oder standardisieren. Wenn Sie den Benutzer aktivieren, fordern Sie eine neue Benutzergeschichte an, beschreiben Sie eine notwendige Funktionsbeschreibung, verfeinern Sie die Anforderungen, erstellen Sie funktionale Details oder erstellen Sie eine lineare Historie, die in den Projektkonventionen enthalten ist.
