Erstellen Sie Prüfungsfälle (TC-XXX) unter Berücksichtigung der Kriterien für die Akzeptanz jedes bestimmten Spezifikationsartefakts, das mit einer codierten Kennung versehen sein soll: eine Benutzerhistorie (US-XXX), ein Arbeitselement (WI-XXX), eine implementierte Funktion (FT-XXX) oder jeweils ein anderes Dokument zur Spezifikation dieser Kriterien Anzahl oder Codes (AC-001, 1.1, R-3 usw.), basierend auf dem Standard IEEE 29119-4. Aktivieren Sie die folgenden Benutzerfunktionen: „Testfälle definieren“, „Prüffälle erstellen“, „TCs generieren“, „Prüfungen für US/WI/FT“, „Prüfungen für diese Spezifikation/Dokumentation“, „Prüfungen dokumentieren“, „Prüffälle für Akzeptanzkriterien“ oder eine andere Variante, die die Erstellung von Prüfungsdokumenten erforderlich macht Ein Teil der Anforderungen, die Sie genau kennen. Sie können es auch aktivieren, wenn Sie als Benutzer „test-define“ oder „/test-define“ eingeben.
