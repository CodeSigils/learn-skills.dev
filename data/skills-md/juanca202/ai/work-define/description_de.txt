Erstellen oder Aktualisieren einer Historia de Usuario. Wenn Sie dies tun, ist es erforderlich, Benutzergeschichten zu erstellen, zu dokumentieren, zu aktualisieren oder zu standardisieren. Wenn Sie den Benutzer aktivieren, bitten Sie ihn um eine neue Benutzergeschichte, beschreiben Sie eine notwendige Funktionsbeschreibung, verfeinern Sie die Anforderungen, strukturieren Sie die Funktionalität oder erstellen Sie eine lineare Historie, die zu den Projektkonventionen gehört.
