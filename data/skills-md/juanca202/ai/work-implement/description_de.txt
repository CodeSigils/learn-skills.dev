In einem bestimmten Code implementiert, folgende vier Typen: (1) technische Daten (TK-XXX) aus einer Benutzergeschichte; (2) Wartungspläne (WI-XXX) ohne Historie – Bugs, Refactoring, Deuda Técnica, Abhängigkeiten, Operativas; (3) Prüfungsfälle (TC-XXX) – Automatische Prüfungsdokumentation durch Testdefinition; (4) Funktionen (FT-XXX) – Automatisieren Sie die TC Ihrer Kriterien. Wählen Sie den Typ aus, der als Referenz für das Artefakt dient. Solo-Trabajo im Status: Bereit; Akzeptieren Sie eine Korrekturmethode, übertragen Sie sie zur Qualitätsprüfung, über jedes Ram-Artefakt (US-XXX, WI-XXX, FT-XXX, TC-XXX und Ram-Test/, oder ein externes Plugin-Artefakt), um eine Prüfung oder einen Rojo-Test durchzuführen. Aktivieren Sie immer die folgenden Benutzer: „Implementieren“, „Entfernen“, „Tarife auswerfen“, „Kodieren“, „Testfälle automatisieren“, „Testfälle implementieren“, „in TK/WI/TC/FT übertragen“ oder Varianten, die die Eingabe von Codes aufgrund einer spezifizierten Spezifikation erfordern.
