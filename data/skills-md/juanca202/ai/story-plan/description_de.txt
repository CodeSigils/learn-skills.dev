Erstellung einer technischen Aktualisierung (TK-XXX) im Zusammenhang mit einer bestehenden Nutzungsgeschichte. Aktivieren Sie, sobald der Benutzer eine planmäßige Implementierung einholt, entfernen Sie die Arbeit, definieren Sie den technischen Zugang, strukturieren Sie Unterbereiche oder dokumentieren Sie technische Spezifikationen, indem Sie den Code und die Prüfungen generieren. Aktiviere es auch – wenn der Benutzer nicht in der Lage ist, eine Referenz auf eine Geschichte einzugeben (z. B. „US-004“, „US-007-Plan“, „Geschichtspläne“) – in diesem Fall wird der Vorschlag von der Arbeitsgemeinschaft übernommen, die die Szenarien beschreibt (SC-XX) und unter Berücksichtigung des US-amerikanischen Handelsglases (BR-XX), ohne die TKs vollständig zu redigieren.
