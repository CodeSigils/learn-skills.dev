Identifiez le point de départ d'un projet (sans code / avec code de base / avec implémentation) et initialisez celui qui échoue dans votre harnais multi-agent : repo git, placeholders `AGENTS.md`/`CLAUDE.md`/`.agents/MEMORY.md`/`docs/adr/README.md`/`docs/standards/README.md`, la pile technologique (capturando qué se quiere desarrollar y, si hace falta, investigation con `work-research`), candidats de ADR/estándares (via `arch-discover` si vous avez mis en œuvre) et le calcul de la qualité (consulter le `quality-check` pour savoir ce qui est juste validé par la pile). Mettre à jour la pile et suggérer de continuer avec « work-define » ou « work-plan ». Activez la procédure d'initialisation, démarrez ou préparez un projet pour les agents, configurez votre harnais, créez `AGENTS.md`/`CLAUDE.md`/`MEMORY.md` à partir de zéro, ou mentionnez "arch-init", "/arch-init", "initialiser le harnais".
