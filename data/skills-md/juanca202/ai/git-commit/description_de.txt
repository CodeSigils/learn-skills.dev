Bereiten Sie Git Commit vor und führen Sie es mit konventionellen Commits aus, die sich aus dem Unterschied ergeben (Typ, Umfang, Beschreibung, Staging). Aktivieren Sie, sobald der Benutzer Commit ausgeführt hat, generieren Sie die Nachricht, trennen Sie Wechsel in verschiedene Commits oder verwenden Sie Aufrufe wie „/commit“.
