Возможности режиссера для создания генеративного видео с использованием искусственного интеллекта — музыкальных клипов, брендовых фильмов, витрин недвижимости, повествовательных клипов. Создает полный пакет подготовки к съемкам (покадровое декупаж, подсказки для создания каждого кадра, библию согласованности символов, план обрезки звука ffmpeg и смету затрат API) с нулевой стоимостью в режиме пробного прогона, который используется по умолчанию. Дополнительный уровень исполнения генерирует отснятый материал с помощью собственных ключей API пользователя посредством преобразования изображения в видео и синхронизации губ. Ответы на раскадровку, списки кадров, синхронизацию губ и согласованность персонажей, а также на португальские термины decupagem, клип-мюзикл и видео gerado por IA.
