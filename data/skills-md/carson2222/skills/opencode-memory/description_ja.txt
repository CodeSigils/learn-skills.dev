ユーザーのマシンに保存されている OpenCode ローカル メモリ (ローカル セッション、計画、会話、プロンプト履歴、プロジェクト コンテキスト) を参照して呼び出します。ユーザーが履歴、前のセッション、過去のチャット、前に何をしたか、前回、計画の確認、セッション履歴、思い出す、記憶、覚えている、以前の作業、以前のコンテキスト、または以前にこれを実行したことを確認するように要求した場合に、すぐに使用します。作業の再開、プロジェクトの継続、以前の決定の参照、繰り返される問題のデバッグ、以前の計画の再検討、または以前の OpenCode コンテキストが役立つフォローアップの際に、自動トリガーを積極的に実行します。これは、ChatGPT/Claude クラウド履歴、一般的な Web 検索、または関連のない製品メモリ システムではなく、特に OpenCode ローカル履歴/ファイルを意味します。関連する履歴のない新しいタスク、または現在のファイル/git がすでに質問に答えている場合には使用しないでください。
