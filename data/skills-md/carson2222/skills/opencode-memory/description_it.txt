Sfoglia e richiama la memoria locale OpenCode archiviata sul computer dell'utente: sessioni locali, piani, conversazioni, cronologia dei prompt e contesto del progetto. Utilizzare immediatamente quando l'utente chiede di controllare la cronologia, le sessioni precedenti, le chat passate, cosa abbiamo fatto prima, l'ultima volta, controllare i piani, la cronologia delle sessioni, ricordare, ricordare, ricordare, lavoro precedente, contesto precedente o averlo fatto prima. Attivazione automatica in modo proattivo quando si riprende il lavoro, si continua un progetto, si fa riferimento a decisioni precedenti, si esegue il debug di problemi ripetuti, si rivisitano piani precedenti o qualsiasi follow-up in cui il contesto OpenCode precedente può essere utile. Ciò significa specificamente la cronologia/file locali OpenCode, non la cronologia cloud di ChatGPT/Claude, ricerche Web generiche o sistemi di memoria di prodotti non correlati. NON utilizzare per nuove attività senza cronologia rilevante o quando i file/git correnti rispondono già alla domanda.
