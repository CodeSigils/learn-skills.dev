Cette compétence doit être utilisée lorsque l'utilisateur demande de « vérifier le code STM32 », « vérifier mon micrologiciel », « rechercher des bogues dans le code intégré », « valider l'initialisation du périphérique », « auditer la configuration des interruptions », « vérifier la configuration DMA », « examiner le code HAL », « vérifier la qualité du code » ou a besoin d'un examen de la qualité et de l'exactitude du code spécifique à STM32.
