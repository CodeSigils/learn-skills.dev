Read-only audit of machine-level developer toolchains on macOS (zsh; degraded bash support). Inventories installed SDKs and installation channels for Python, Node, Java/JVM, Go, Rust, Ruby, Swift/Objective-C, PHP, Lua, Zig, Julia, Dart/Flutter, Erlang/Elixir, C/C++, and Git; detects conflicting version managers, stale shell setup, PATH differences across terminal/GUI/script scenarios (including path_helper), and incomplete or broken external-SSD cache relocation. Produces a health report and per-language migration plan based on authoritative/native managers while respecting sound existing setups. Use for whole-machine or single-language audits, SDK inventory, wrong/old command resolution, manager cleanup, PATH/shell conflicts, or cache-relocation checks. Never installs, uninstalls, edits config, or downloads; it only probes and gives reviewable commands for the user to run.
