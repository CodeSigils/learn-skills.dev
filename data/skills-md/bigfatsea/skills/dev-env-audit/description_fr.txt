Audit en lecture seule des chaînes d'outils de développement au niveau machine sur macOS (zsh ; prise en charge de bash dégradé). Inventaires des SDK installés et des canaux d'installation pour Python, Node, Java/JVM, Go, Rust, Ruby, Swift/Objective-C, PHP, Lua, Zig, Julia, Dart/Flutter, Erlang/Elixir, C/C++ et Git ; détecte les gestionnaires de versions en conflit, les configurations de shell obsolètes, les différences de PATH entre les scénarios de terminal/interface graphique/script (y compris path_helper) et la relocalisation du cache SSD externe incomplète ou cassée. Produit un rapport de santé et un plan de migration par langue basé sur des gestionnaires faisant autorité/natifs tout en respectant les bonnes configurations existantes. À utiliser pour les audits de machine entière ou dans une seule langue, l'inventaire du SDK, la résolution de commandes incorrectes/anciennes, le nettoyage du gestionnaire, les conflits PATH/shell ou les vérifications de relocalisation du cache. Ne jamais installer, désinstaller, modifier la configuration ou télécharger ; il sonde et donne uniquement des commandes révisables que l'utilisateur peut exécuter.
