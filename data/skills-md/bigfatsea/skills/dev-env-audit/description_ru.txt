Аудит цепочек инструментов разработчика машинного уровня только для чтения в macOS (zsh; ухудшенная поддержка bash). Инвентаризация установленных SDK и каналов установки для Python, Node, Java/JVM, Go, Rust, Ruby, Swift/Objective-C, PHP, Lua, Zig, Julia, Dart/Flutter, Erlang/Elixir, C/C++ и Git; обнаруживает конфликтующие менеджеры версий, устаревшую настройку оболочки, различия PATH в сценариях терминала, графического пользовательского интерфейса и сценариев (включая path_helper), а также неполное или нарушенное перемещение кэша внешнего SSD. Создает отчет о состоянии и план миграции для каждого языка на основе авторитетных/родных менеджеров с учетом надежных существующих настроек. Используйте для аудита всего компьютера или одного языка, инвентаризации SDK, разрешения неправильных/старых команд, очистки менеджера, конфликтов PATH/оболочки или проверок перемещения кэша. Никогда не устанавливает, не удаляет, не редактирует конфигурацию и не загружает; он только исследует и дает пользователю проверенные команды для запуска.
