تدقيق للقراءة فقط لسلاسل أدوات المطورين على مستوى الجهاز على نظام التشغيل macOS (zsh؛ دعم bash المتدهور). قامت Inventorys بتثبيت حزم SDK وقنوات التثبيت لـ Python وNode وJava/JVM وGo وRust وRuby وSwift/Objective-C وPHP وLua وZig وJulia وDart/Flutter وErlang/Elixir وC/C++ وGit؛ يكتشف مديري الإصدارات المتعارضين، وإعداد الصدفة التي لا معنى لها، واختلافات PATH عبر سيناريوهات المحطة الطرفية/واجهة المستخدم الرسومية/البرنامج النصي (بما في ذلك path_helper)، ونقل ذاكرة التخزين المؤقت الخارجية SSD غير المكتملة أو المعطلة. يُنتج تقريرًا صحيًا وخطة ترحيل لكل لغة بناءً على المديرين المعتمدين/المحليين مع احترام الإعدادات السليمة الموجودة. يُستخدم لعمليات تدقيق الجهاز بالكامل أو لغة واحدة، أو مخزون SDK، أو تحليل الأوامر الخاطئة/القديمة، أو تنظيف المدير، أو تعارضات PATH/Shell، أو عمليات فحص نقل ذاكرة التخزين المؤقت. لا تقم مطلقًا بالتثبيت أو إلغاء التثبيت أو تحرير التكوين أو التنزيلات؛ فهو يقوم فقط بالتحقيق وإعطاء أوامر قابلة للمراجعة ليقوم المستخدم بتشغيلها.
