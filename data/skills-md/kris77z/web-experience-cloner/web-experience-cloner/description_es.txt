Conjunto de habilidades de proceso completo para ingeniería inversa, clonación y experiencias web de alta fidelidad sin conexión. Cubre sitios de motores creativos de desarrollo propio (WebGL/Three.js/GSAP/Rive/Gaussian splash/Light field, etc.) y sitios de exportación de plataformas (Framer/Webflow/Readymag, etc.), así como páginas de experiencia SSR/SPA de tipo aplicación (React Router/Remix/Oxygen/Next/Nuxt, etc.): clasificación de sitios → recopilación de pistas → deofuscación estática/captura en tiempo de ejecución → Documentación de principios basada en componentes → copia local completa del sitio 1:1 → auditoría de circuito cerrado de recursos → conversión completa fuera de línea → reescritura de un único efecto desde cero. Úselo cuando un usuario quiera realizar ingeniería inversa, clonar o diseccionar la animación de un sitio web, crear una copia fuera de línea ejecutable localmente, solucionar problemas de pantalla blanca, hidratación, API o recursos de clonación local, completar recursos cargados de forma diferida o trasladar un efecto particular a una demostración independiente.
