Habilidades de ingeniería inversa, clonación y experiencia web fuera de línea de alta fidelidad de extremo a extremo. Cubre sitios de motores creativos de desarrollo propio (WebGL/Three.js/GSAP/Rive/Gaussian splash/light field, etc.) y sitios de exportación de plataformas (Framer/Webflow/Readymag, etc.), así como páginas de experiencia SSR/SPA de tipo aplicación (React Router/Remix/Oxygen/Next/Nuxt, etc.): clasificación de sitios → colección de pistas → deofuscación estática/captura en tiempo de ejecución → documentación de principios de componenteización → Réplica local 1:1 del sitio completo → auditoría de circuito cerrado de recursos → completa desconexión → reescritura de un único efecto desde cero. Se utiliza cuando los usuarios desean realizar ingeniería inversa, clonar o desensamblar la animación de un sitio web, crear una réplica fuera de línea ejecutable localmente, solucionar problemas de pantalla blanca, hidratación, API o recursos del clon local, completar recursos cargados de forma diferida o trasladar un efecto particular a una demostración independiente.
