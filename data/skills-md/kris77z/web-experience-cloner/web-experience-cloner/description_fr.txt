Compétences complètes en matière de rétro-ingénierie, de clonage et d'expériences Web haute fidélité hors ligne. Couvre les sites de moteurs de création auto-développés (WebGL/Three.js/GSAP/Rive/Gaussian splash/Light field, etc.) et les sites d'exportation de plateformes (Framer/Webflow/Readymag, etc.), ainsi que les pages d'expérience SSR/SPA de type application (React Router/Remix/Oxygen/Next/Nuxt, etc.) : classification des sites → collecte d'indices → désobscurcissement statique/capture d'exécution → documentation des principes de composantisation → Réplique locale 1:1 sur site complet → audit en boucle fermée des ressources → conversion hors ligne complète → réécriture d'un seul effet à partir de zéro. Utilisé lorsqu'un utilisateur souhaite procéder à l'ingénierie inverse/cloner/désassembler l'animation d'un site Web, créer une copie hors ligne exécutable localement, résoudre les problèmes d'écran blanc/d'hydratation/API/de ressources de clone local, remplir des ressources chargées paresseusement ou porter un effet spécifique dans une démo indépendante.
