リバース エンジニアリング、クローン作成、およびオフラインでの高忠実度の Web エクスペリエンスのエンドツーエンドのスキル。自社開発のクリエイティブ エンジン サイト (WebGL/Three.js/GSAP/Rive/Gaussian Splash/Light Field など) およびプラットフォーム エクスポート サイト (Framer/Webflow/Readymag など)、およびアプリケーション タイプの SSR/SPA エクスペリエンス ページ (React Router/Remix/Oxygen/Next/Nuxt など) をカバーします: サイト分類 → 手がかり収集 → 静的難読化解除 / ランタイム キャプチャ → コンポーネント化原則のドキュメント →フルサイトの 1:1 ローカル レプリカ → リソースの閉ループ監査 → 完全なオフライン化 → 単一のエフェクトを最初から書き直す。ユーザーが Web サイトのアニメーションのリバース エンジニアリング/クローン/逆アセンブル、ローカルで実行可能なオフライン レプリカの作成、ローカル クローンのホワイト スクリーン/ハイドレーション/API/リソースの問題のトラブルシューティング、遅延読み込みリソースの入力、または特定のエフェクトのスタンドアロン デモへの移植を行う場合に使用されます。
