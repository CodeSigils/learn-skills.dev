Umfassende Prozesskenntnisse für Reverse Engineering, Klonen und Offline-High-Fidelity-Weberlebnisse. Deckt selbst entwickelte Creative-Engine-Sites (WebGL/Three.js/GSAP/Rive/Gaussian Splatter/Light Field usw.) und Plattformexport-Sites (Framer/Webflow/Readymag usw.) sowie anwendungsorientierte SSR/SPA-Erfahrungsseiten (React Router/Remix/Oxygen/Next/Nuxt usw.) ab: Site-Kategorisierung → Hinweissammlung → statische Entschleierung/Laufzeiterfassung → Komponentisierung Prinzipdokumentation → vollständige 1:1 lokale Nachbildung der Site → Ressourcen-Closed-Loop-Audit → vollständige Offline-Konvertierung → Neuschreiben eines einzelnen Effekts von Grund auf. Wird verwendet, wenn ein Benutzer die Animation einer Website zurückentwickeln/klonen/zerlegen, eine offline ausführbare lokale Kopie erstellen, lokale Klonprobleme wie Whitescreen-/Hydrations-/API-/Ressourcenprobleme beheben, fehlende Lazy-Loaded-Ressourcen ergänzen oder einen bestimmten Effekt in eine unabhängige Demo portieren möchte.
