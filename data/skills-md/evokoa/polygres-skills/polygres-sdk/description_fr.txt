Utilisez le SDK Polygres Python pour créer une récupération d'applications avec des requêtes graphiques, vectorielles, textuelles et hybrides ; configurer des clients API Runtime sécurisés ; enchaîner les identifiants de résultats réels ; paginer les résultats saisis ; concevoir un contexte RAG ancré ; et gérer les erreurs de validation, d'authentification, de limite de débit et d'exécution du SDK. À utiliser lorsqu'un utilisateur demande à écrire, réviser, tester ou dépanner le code d'une application Python qui appelle une API d'exécution de projet Polygres. Ne pas utiliser pour l'administration de projets CLI, les importations, les migrations ou la configuration de récupération.
