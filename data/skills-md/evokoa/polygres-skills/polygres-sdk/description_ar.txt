استخدم Polygres Python SDK لإنشاء استرجاع التطبيق باستخدام استعلامات الرسم البياني والمتجه والنص والاستعلامات المختلطة؛ تكوين عملاء Runtime API الآمنين؛ سلسلة معرفات النتائج الحقيقية؛ النتائج المكتوبة على صفحات؛ تصميم سياق RAG المؤرض؛ والتعامل مع التحقق من صحة SDK والمصادقة والحد الأقصى للمعدل وأخطاء وقت التشغيل. يُستخدم عندما يطلب المستخدم كتابة أو مراجعة أو اختبار أو استكشاف أخطاء كود تطبيق Python الذي يستدعي واجهة برمجة تطبيقات Runtime لمشروع Polygres. لا تستخدم لإدارة مشروع CLI، أو الواردات، أو عمليات الترحيل، أو تكوين الاسترجاع.
