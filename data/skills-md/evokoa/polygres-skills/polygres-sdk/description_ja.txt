Polygres Python SDK を使用して、グラフ、ベクトル、テキスト、ハイブリッド クエリによるアプリケーション検索を構築します。安全なランタイム API クライアントを構成します。実際の結果 ID を連鎖させます。入力された結果のページ付け。根拠のある RAG コンテキストを設計する。 SDK の検証、認証、レート制限、およびランタイム エラーを処理します。ユーザーが、Polygres プロジェクトのランタイム API を呼び出す Python アプリケーション コードの作成、レビュー、テスト、トラブルシューティングを要求する場合に使用します。 CLI プロジェクトの管理、インポート、移行、または構成の取得には使用しないでください。
