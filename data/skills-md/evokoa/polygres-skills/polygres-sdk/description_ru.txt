Используйте Polygres Python SDK для построения извлечения приложений с помощью графовых, векторных, текстовых и гибридных запросов; настройка безопасных клиентов Runtime API; цепочка реальных идентификаторов результатов; результаты с разбивкой по страницам; разработать обоснованный контекст RAG; и обрабатывать проверку SDK, аутентификацию, ограничение скорости и ошибки времени выполнения. Используйте, когда пользователь просит написать, просмотреть, протестировать или устранить неполадки кода приложения Python, который вызывает API среды выполнения проекта Polygres. Не используйте для администрирования проекта CLI, импорта, миграции или получения конфигурации.
