Utilizza Polygres Python SDK per creare il recupero delle applicazioni con query grafiche, vettoriali, di testo e ibride; configurare client API Runtime sicuri; concatenare gli ID dei risultati reali; impaginare i risultati digitati; contesto RAG basato sulla progettazione; e gestire la convalida dell'SDK, l'autenticazione, il limite di velocità e gli errori di runtime. Da utilizzare quando un utente chiede di scrivere, rivedere, testare o risolvere i problemi del codice dell'applicazione Python che chiama un'API runtime del progetto Polygres. Non utilizzare per l'amministrazione di progetti CLI, importazioni, migrazioni o configurazioni di recupero.
