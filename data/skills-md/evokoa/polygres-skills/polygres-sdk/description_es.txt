Utilice el SDK de Polygres Python para crear recuperación de aplicaciones con consultas gráficas, vectoriales, de texto e híbridas; configurar clientes Runtime API seguros; encadenar ID de resultados reales; paginar resultados escritos; diseño del contexto RAG fundamentado; y manejar la validación del SDK, la autenticación, el límite de velocidad y los errores de tiempo de ejecución. Úselo cuando un usuario solicita escribir, revisar, probar o solucionar problemas del código de una aplicación Python que llama a una API en tiempo de ejecución del proyecto Polygres. No lo utilice para la administración de proyectos CLI, importaciones, migraciones o configuración de recuperación.
