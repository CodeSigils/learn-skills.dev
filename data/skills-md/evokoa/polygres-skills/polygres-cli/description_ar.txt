استخدم Polygres CLI لمصادقة المشاريع واختيارها وفحصها، والحصول على معلومات اتصال Postgres الآمنة، وفتح psql، وإدارة مفاتيح Runtime API، واستيراد بيانات CSV، أو TSV، أو JSON، أو JSONL من خلال إعداد محلي آمن وواجهة برمجة تطبيقات استيراد CSV، وتطبيق عمليات الترحيل، وتكوين الرسم البياني، أو المتجه، أو استرجاع النص، والتحقق من جاهزية المشروع أو الاسترجاع. يُستخدم عندما يطلب المستخدم من وكيل ترميز الذكاء الاصطناعي إعداد مشروع Polygres مُدار أو تشغيله أو تشغيله تلقائيًا أو استكشاف أخطائه وإصلاحها.
