Utilice la CLI de Polygres para autenticar, seleccionar e inspeccionar proyectos, obtener información de conexión Postgres segura, abrir psql, administrar claves API de tiempo de ejecución, importar datos CSV, TSV, JSON o JSONL a través de una preparación local segura y la API de importación CSV, aplicar migraciones, configurar la recuperación de gráficos, vectores o texto, y verificar la preparación del proyecto o la recuperación. Úselo siempre que un usuario solicite a un agente de codificación de IA que configure, opere, automatice o solucione problemas de un proyecto administrado de Polygres.
