Análisis profundo de novelas web y ficción de larga duración para crear bases de conocimiento estructuradas de Obsidian. Utilice esta habilidad siempre que el usuario solicite analizar una novela, deconstruir una novela web, extraer relaciones entre personajes, analizar la estructura de la trama, estudiar el estilo de escritura, extraer elementos que construyen el mundo, crear una base de conocimientos a partir de la ficción o desglosar sistemáticamente el contenido de un libro. Esto se aplica independientemente del formato (txt, epub, pdf) o del idioma (novelas web chinas, ficción inglesa, etc.). Utilice siempre esta habilidad cuando el usuario mencione "analizar esta novela", "extracción de personajes", "análisis de la trama", "estudio de estilo de escritura" o quiera comprender cómo funciona una historia.
