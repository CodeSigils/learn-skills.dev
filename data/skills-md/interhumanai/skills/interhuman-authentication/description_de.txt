Wrapper für den Endpunkt Interhuman API POST /v0/auth. Erzeugt kurzlebige Bearer-Zugriffstokens mithilfe von API-Schlüsselanmeldeinformationen. Verwenden Sie diese Option, wenn sich der Benutzer vor dem Aufruf von Interhuman-API-Endpunkten authentifizieren muss. Gibt die genaue JSON-Antwort von der API ohne Änderung zurück.
