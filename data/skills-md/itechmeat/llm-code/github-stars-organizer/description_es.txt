Organizador de listas y estrellas de GitHub. Reutiliza listas existentes, busca repositorios destacados que no figuran en la lista, crea solo listas amplias necesarias y agrega repositorios sin alterar las asignaciones existentes. Úselo cuando el usuario solicite organizar estrellas de GitHub, ordenar repositorios destacados, limpiar listas o archivar estrellas no enumeradas. Palabras clave: estrellas de GitHub, listas de GitHub, repositorios destacados, chrome-cdp.
