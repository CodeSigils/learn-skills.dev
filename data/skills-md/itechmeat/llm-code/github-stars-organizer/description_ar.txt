منظم نجوم وقوائم GitHub. إعادة استخدام القوائم الموجودة، والعثور على المستودعات المميزة بنجمة غير المدرجة، وإنشاء القوائم العريضة الضرورية فقط، وإضافة مستودعات بدون إزعاج المهام الموجودة. يُستخدم عندما يطلب المستخدم تنظيم نجوم GitHub، أو فرز المستودعات المميزة بنجمة، أو تنظيف القوائم، أو حفظ النجوم غير المدرجة. الكلمات الرئيسية: نجوم GitHub، قوائم GitHub، المستودعات المميزة بنجمة، chrome-cdp.
