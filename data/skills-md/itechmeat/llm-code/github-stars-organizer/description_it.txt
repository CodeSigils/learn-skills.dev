GitHub organizza stelle ed elenchi. Riutilizza gli elenchi esistenti, trova repository speciali non elencati, crea solo elenchi ampi necessari e aggiunge repository senza disturbare le assegnazioni esistenti. Da utilizzare quando l'utente chiede di organizzare le stelle di GitHub, ordinare i repository speciali, pulire gli elenchi o archiviare le stelle non elencate. Parole chiave: stelle GitHub, elenchi GitHub, repository stellati, chrome-cdp.
