Organisateur de stars et de listes GitHub. Réutilise les listes existantes, recherche les référentiels favoris non répertoriés, crée uniquement les listes larges nécessaires et ajoute des dépôts sans perturber les affectations existantes. À utiliser lorsque l'utilisateur demande à organiser les étoiles GitHub, à trier les dépôts favoris, à nettoyer les listes ou à classer les étoiles non répertoriées. Mots-clés : étoiles GitHub, listes GitHub, référentiels favoris, chrome-cdp.
