Организатор звезд и списков GitHub. Повторно использует существующие списки, находит не внесенные в список избранные репозитории, создает только необходимые широкие списки и добавляет репозитории, не нарушая существующие назначения. Используйте, когда пользователь просит упорядочить звезды GitHub, отсортировать помеченные репозитории, очистить списки или сохранить в файле звезды, не включенные в список. Ключевые слова: звезды GitHub, списки GitHub, помеченные репозитории, chrome-cdp.
