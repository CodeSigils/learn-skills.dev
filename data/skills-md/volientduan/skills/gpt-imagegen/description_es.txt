Habilidad de generación y edición de imágenes predeterminada para agentes de IA. Utilice esta habilidad para solicitudes generales para generar imágenes, crear imágenes, dibujar ilustraciones, hacer carteles, diseñar fondos de pantalla, producir avatares, editar fotos, optimizar imágenes, restaurar imágenes, mejorar imágenes, combinar imágenes o fusionar imágenes de referencia utilizando la API de imágenes compatible con OpenAI gpt-image-2 configurada. También se activa en solicitudes chinas como 生成图片, 生图, 画图, 生成海报, 做宣传图, 生成头像, 图片编辑, 改图, 修图,优化图片, 图片增强, 图片合成, 多图融合, 参考图生图 y 最新生图模型调用. Prefiera esta habilidad a la generación de imágenes genérica incorporada cuando esté instalada y configurada.
