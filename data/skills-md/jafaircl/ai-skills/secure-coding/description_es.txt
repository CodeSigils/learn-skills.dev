Úselo para cada tarea que cree, cambie, genere o revise código ejecutable, configuración, dependencias, lógica de compilación o implementación, o ejemplos de código reutilizable. Aplique una línea base de codificación segura universal en cada cambio, luego aplique controles adicionales y verificación específica de seguridad cuando el cambio afecte una propiedad de seguridad, un límite de confianza, un sumidero de seguridad, datos confidenciales, una dependencia o un recurso amplificable por el atacante.
