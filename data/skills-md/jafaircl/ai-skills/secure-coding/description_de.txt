Für jede Aufgabe verwenden, die ausführbaren Code, Konfiguration, Abhängigkeiten, Build- oder Bereitstellungslogik oder wiederverwendbare Codebeispiele erstellt, ändert, generiert oder überprüft. Erzwingen Sie bei jeder Änderung eine universelle sichere Codierungsbasis und wenden Sie dann zusätzliche Kontrollen und sicherheitsspezifische Überprüfungen an, wenn die Änderung eine Sicherheitseigenschaft, eine Vertrauensgrenze, eine Sicherheitssenke, vertrauliche Daten, eine Abhängigkeit oder eine durch einen Angreifer verstärkte Ressource betrifft.
