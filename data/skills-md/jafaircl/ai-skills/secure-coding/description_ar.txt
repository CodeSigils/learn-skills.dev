يُستخدم لكل مهمة تقوم بإنشاء أو تغيير أو إنشاء أو مراجعة التعليمات البرمجية القابلة للتنفيذ أو التكوين أو التبعيات أو منطق البناء أو النشر أو أمثلة التعليمات البرمجية القابلة لإعادة الاستخدام. قم بفرض خط أساسي للتشفير الآمن العالمي على كل تغيير، ثم قم بتطبيق عناصر تحكم إضافية وتحقق خاص بالأمان عندما يؤثر التغيير على خاصية الأمان، أو حدود الثقة، أو مصدر الأمان، أو البيانات الحساسة، أو التبعية، أو المورد القابل للتضخيم للمهاجم.
