يُستخدم عند مراجعة طلب السحب أو الفرع أو شجرة العمل أو الاختلاف أو التنفيذ المكتمل أو التغيير المقترح قبل القبول. فرض هدف المراجعة الفعلي وقاعدة المقارنة، والتقييم المدعوم بالمواصفات، وتغطية التغيير الكاملة، واستدلال مستوى التغيير، ونتائج الإشارات العالية المدعومة بالأدلة، والتصرف الصريح، والتحقق المستقل دون اختراع مشكلات.
