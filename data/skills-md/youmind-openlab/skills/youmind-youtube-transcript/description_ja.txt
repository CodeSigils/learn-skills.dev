YouMind API 経由で YouTube ビデオのトランスクリプトを抽出して要約します。yt-dlp やプロキシは必要ありません。
並列処理により最大 5 つのビデオを一度にバッチ抽出します。
マークダウン形式でタイムスタンプ付きのトランスクリプトとともにビデオを YouMind ボードに保存します。
抽出後にビデオコンテンツを自動的に要約します。
あらゆる IP (クラウド、VPS、CI/CD、企業ネットワーク) から動作します。
ユーザーが「YouTube トランスクリプトを取得」、「ビデオ字幕を抽出」したい場合に使用します。
「YouTube ビデオの文字起こし」、「ビデオのバッチ文字起こし」、「ビデオのキャプションの取得」、
"YouTube 動画の概要"、"YouTube 動画の概要"、"この動画の概要"、
"このビデオは何と言っていますか"、"YouTube 字幕"、"YouTube 总结"、"video总结"、
「YouTube 文字起こし」、「YouTube 자막」、または「YouTube トランスクリプトをダウンロード」。
