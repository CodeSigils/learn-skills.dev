Этот навык следует использовать при взаимодействии с API YouMind для управления таким контентом, как доски, поделки, заметки, подборки и материалы. Он предоставляет инструкции по установке и использованию интерфейса командной строки youmind, который позволяет выполнять поиск, проверку и вызов конечных точек OpenAPI YouMind.
