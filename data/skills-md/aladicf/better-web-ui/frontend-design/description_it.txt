Crea interfacce frontend distintive di livello produttivo con una solida gerarchia, sistemi ponderati e un'implementazione raffinata che eviti l'estetica generica dell'IA. Da utilizzare quando l'utente desidera creare o riprogettare pagine Web, flussi, componenti o superfici complete di app oppure quando un'altra competenza di migliore interfaccia utente Web necessita di un contesto di progettazione del progetto condiviso prima di altre competenze di migliore interfaccia utente Web.
