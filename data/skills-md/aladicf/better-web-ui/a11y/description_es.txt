Audite y solucione sistemáticamente problemas de accesibilidad en la interfaz de usuario, centrándose en la navegación con el teclado, la compatibilidad con lectores de pantalla, el contraste de color, el HTML semántico, el uso de ARIA y la sensibilidad al movimiento. Úselo cuando el usuario desee mejorar la accesibilidad, hacer que un componente sea accesible, corregir infracciones de las WCAG, agregar compatibilidad con el teclado o garantizar la compatibilidad del lector de pantalla.
