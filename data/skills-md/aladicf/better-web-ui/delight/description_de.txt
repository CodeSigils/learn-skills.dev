Fügen Sie Momente der Freude, Persönlichkeit und unvergesslichen Details hinzu, die einer Benutzeroberfläche ein angenehmes Gefühl verleihen, sobald die Grundlagen bereits funktionieren. Verwenden Sie es, wenn der Benutzer Freude oder Persönlichkeit wünscht – und nicht, wenn das Hauptbedürfnis eine grundlegende Bereinigung oder eine stärkere visuelle Wirkung ist.
