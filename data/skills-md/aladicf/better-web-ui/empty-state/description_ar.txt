قم بتصميم الحالات الفارغة المركزة لحالات عدم وجود بيانات، أو عدم وجود نتائج، أو الإذن، أو الخطأ باستخدام إطار واضح للقيمة، وعبارات حث على اتخاذ إجراء قوية، ونسبة أقل من الكروم الميت. يُستخدم عندما يذكر المستخدم صفحات فارغة، أو شاشات خالية من البيانات، أو لا توجد نتائج، أو حالات إذن، أو عناصر تحكم معطلة - وليس استراتيجية تأهيل أوسع.
