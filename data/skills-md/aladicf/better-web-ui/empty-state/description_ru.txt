Создавайте целенаправленные пустые состояния для ситуаций отсутствия данных, отсутствия результатов, разрешений и ошибок с четким определением ценностей, сильными призывами к действию и меньшим количеством мертвого хрома. Используйте, когда пользователь упоминает пустые страницы, экраны с нулевыми данными, отсутствие результатов, состояния разрешений или неактивные элементы управления, а не более широкую стратегию адаптации.
