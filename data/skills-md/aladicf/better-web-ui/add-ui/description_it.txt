Genera 5 varianti dell'interfaccia utente distinte e di livello produttivo per una sezione, un componente, una pagina, un flusso o una shell richiesti, quindi aiuta l'utente a visualizzarne l'anteprima e ad applicarne uno. Da utilizzare quando l'utente chiede di aggiungere un'interfaccia utente come un eroe, prezzi, barra di navigazione, flusso di autenticazione, shell del dashboard, superficie di e-commerce o componente dati.
