أنشئ 5 أشكال مختلفة لواجهة المستخدم على مستوى الإنتاج لقسم أو مكون أو صفحة أو تدفق أو غلاف مطلوب، ثم ساعد المستخدم على معاينة أحدها وتطبيقه. يُستخدم عندما يطلب المستخدم إضافة واجهة مستخدم مثل البطل أو التسعير أو شريط التنقل أو تدفق المصادقة أو لوحة المعلومات أو سطح التجارة الإلكترونية أو مكون البيانات.
