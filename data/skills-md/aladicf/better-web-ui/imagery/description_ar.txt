قم بتحسين كيفية استخدام الواجهات للصور ولقطات الشاشة والأيقونات والرسوم التوضيحية والوسائط التي يحمّلها المستخدم بحيث تدعم العناصر المرئية الوضوح بدلاً من تقويضه. يُستخدم عندما يذكر المستخدم الصور، أو لقطات الشاشة، أو صور الخلفية، أو الصور الرئيسية، أو حجم الأيقونات، أو الوسائط المحملة من قبل المستخدم، أو الاقتصاصات، أو التراكبات، أو إمكانية قراءة الصور.
