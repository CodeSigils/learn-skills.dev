قم بتوضيح الأولوية والتركيز من خلال إصلاح الإجراءات الأساسية غير الواضحة، والوزن المرئي المنافس، وعناوين الأقسام الصاخبة، ومعالجة التسمية/القيمة الضعيفة. يُستخدم عندما يذكر المستخدم التسلسل الهرمي، أو تحديد الأولويات، أو وجود منافسة كبيرة جدًا، أو ارتباك التدرج الرمادي، أو العناوين الصاخبة، أو الإجراءات الأساسية غير الواضحة.
