قم بتوضيح الأولوية والتركيز من خلال إصلاح الإجراءات الأساسية غير الواضحة، والوزن المرئي المنافس، وعناوين الأقسام الصاخبة، ومعالجة التسمية/القيمة الضعيفة. يُستخدم عندما يذكر المستخدم التسلسل الهرمي، أو تحديد الأولويات، أو وجود منافسة شديدة، أو ارتباك بتدرج رمادي، أو عناوين عالية الصوت، أو إجراءات أساسية غير واضحة.
