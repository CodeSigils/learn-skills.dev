Cree o mejore una estrategia de prueba de interfaz de usuario que cubra regresión visual, pruebas de interacción y afirmaciones de accesibilidad. Úselo cuando el usuario solicite agregar pruebas, configurar pruebas, corregir pruebas inestables, mejorar la cobertura de las pruebas, validar el comportamiento de la interfaz de usuario, detectar errores visuales o establecer confianza en el envío de cambios en la interfaz.
