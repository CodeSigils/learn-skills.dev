Créez ou améliorez une stratégie de test d'interface utilisateur couvrant la régression visuelle, les tests d'interaction et les assertions d'accessibilité. À utiliser lorsque l'utilisateur demande d'ajouter des tests, de configurer des tests, de corriger des tests instables, d'améliorer la couverture des tests, de valider le comportement de l'interface utilisateur, de détecter des bugs visuels ou d'établir une confiance dans l'expédition des modifications de l'interface utilisateur.
