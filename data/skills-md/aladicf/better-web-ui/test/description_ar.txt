قم ببناء أو تحسين استراتيجية اختبار واجهة المستخدم التي تغطي الانحدار المرئي واختبار التفاعل وتأكيدات إمكانية الوصول. يُستخدم عندما يطلب المستخدم إضافة اختبارات، أو إعداد الاختبار، أو إصلاح الاختبارات غير المستقرة، أو تحسين تغطية الاختبار، أو التحقق من صحة سلوك واجهة المستخدم، أو اكتشاف الأخطاء المرئية، أو تعزيز الثقة في شحن تغييرات الواجهة الأمامية.
