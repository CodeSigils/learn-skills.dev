قم ببناء أو تحسين أنظمة ألوان واجهة المستخدم، والدفء، واللون الدلالي، والتسلسل الهرمي القائم على الألوان في التصميمات الرمادية للغاية، أو أحادية اللون، أو التي تفتقد معنى اللون. يُستخدم عندما يذكر المستخدم الألوان الباهتة، أو واجهة المستخدم الرمادية، أو فقدان الدفء، أو اللون الدلالي الضعيف، أو الحاجة إلى تسلسل هرمي أقوى للألوان.
