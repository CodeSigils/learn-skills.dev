قم باستخراج ودمج المكونات القابلة لإعادة الاستخدام، ورموز التصميم، والأنماط في نظام التصميم الخاص بك، وتحديد فرص إعادة الاستخدام المنهجي وإثراء مكتبة المكونات الخاصة بك. يُستخدم عندما يطلب المستخدم إنشاء مكونات، أو إعادة تصميم أنماط واجهة المستخدم المتكررة، أو إنشاء نظام تصميم، أو استخراج الرموز المميزة.
