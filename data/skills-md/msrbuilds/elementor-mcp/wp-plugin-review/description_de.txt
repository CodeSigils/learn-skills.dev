Umfassende Überprüfung des WordPress-Plugins zu Sicherheitslücken, Einhaltung der WordPress Coding Standards (WPCS), Plugin-Repository-Richtlinien, Unit-Test-Abdeckung und Zugänglichkeit. Führt automatisierte Tools (PHPCS mit WPCS, PHPStan, PHPUnit) sowie eine umfassende manuelle Codeüberprüfung aus. Gibt einen detaillierten Markdown-Überprüfungsbericht mit Problemen, Schweregradbewertungen und umsetzbaren Korrekturen aus. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer „ein Plugin überprüfen“, „ein WordPress-Plugin prüfen“, „Plugin-Sicherheit prüfen“, „Plugin für Repository-Übermittlung prüfen“, „Plugin-Code überprüfen“, „Plugin-Code überprüfen“, „mein Plugin prüfen“ oder jede Anfrage zur Bewertung der Codequalität, des Sicherheitsstatus oder der Repository-Bereitschaft eines WordPress-Plugins auffordert. Wird auch ausgelöst, wenn ein Benutzer eine Plugin-ZIP-Datei oder einen Plugin-Ordner hochlädt und um Feedback, Analyse oder Rezension bittet.
