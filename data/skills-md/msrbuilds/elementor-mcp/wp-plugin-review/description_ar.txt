مراجعة شاملة لمكونات WordPress الإضافية تغطي الثغرات الأمنية، والامتثال لمعايير ترميز WordPress (WPCS)، وإرشادات مستودع المكونات الإضافية، وتغطية اختبار الوحدة، وإمكانية الوصول. تشغيل الأدوات الآلية (PHPCS مع WPCS، PHPStan، PHPUnit) بالإضافة إلى المراجعة اليدوية العميقة للتعليمات البرمجية. يُخرج تقريرًا تفصيليًا لمراجعة Markdown يحتوي على المشكلات وتقييمات الخطورة والإصلاحات القابلة للتنفيذ. استخدم هذه المهارة عندما يطلب المستخدم "مراجعة مكون إضافي"، أو "تدقيق مكون WordPress الإضافي"، أو "التحقق من أمان المكون الإضافي"، أو "التحقق من المكون الإضافي لإرسال المستودع"، أو "مراجعة كود المكون الإضافي"، أو "مراجعة كود البرنامج المساعد"، أو "التحقق من مكون WordPress الإضافي"، أو أي طلب يتضمن تقييم جودة كود مكون WordPress الإضافي، أو الوضع الأمني، أو جاهزية المستودع. يتم تشغيله أيضًا عندما يقوم المستخدم بتحميل ملف مضغوط أو مجلد مكون إضافي ويطلب التعليقات أو التحليل أو المراجعة.
