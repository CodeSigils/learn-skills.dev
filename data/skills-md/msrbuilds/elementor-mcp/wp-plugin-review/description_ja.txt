セキュリティの脆弱性、WordPress コーディング標準 (WPCS) への準拠、プラグイン リポジトリのガイドライン、単体テストの範囲、アクセシビリティを網羅した包括的な WordPress プラグインのレビュー。自動化ツール (WPCS を使用した PHPCS、PHPStan、PHPUnit) と詳細な手動コード レビューを実行します。問題、重大度評価、実用的な修正を含む詳細な Markdown レビュー レポートを出力します。ユーザーが「プラグインのレビュー」、「WordPress プラグインの監査」、「プラグインのセキュリティのチェック」、「リポジトリ送信用のプラグインのチェック」、「プラグイン コードのレビュー」、「プラグイン コード レビュー」、「プラグインのチェック」、または WordPress プラグインのコード品質、セキュリティ体制、リポジトリの準備状況の評価を伴うリクエストを要求する場合は常に、このスキルを使用します。また、ユーザーがプラグインの zip またはフォルダーをアップロードし、フィードバック、分析、またはレビューを求めたときにもトリガーされます。
