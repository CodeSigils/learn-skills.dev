Examen complet des plugins WordPress couvrant les vulnérabilités de sécurité, la conformité aux normes de codage WordPress (WPCS), les directives du référentiel de plugins, la couverture des tests unitaires et l'accessibilité. Exécute des outils automatisés (PHPCS avec WPCS, PHPStan, PHPUnit) ainsi qu'une révision manuelle approfondie du code. Génère un rapport d'examen Markdown détaillé avec les problèmes, les évaluations de gravité et les correctifs exploitables. Utilisez cette compétence chaque fois que l'utilisateur demande de « vérifier un plugin », « auditer un plugin WordPress », « vérifier la sécurité du plugin », « vérifier le plugin pour la soumission au référentiel », « réviser le code du plugin », « vérifier le code du plugin », « vérifier mon plugin » ou toute demande impliquant l'évaluation de la qualité du code, de la posture de sécurité ou de l'état de préparation du référentiel d'un plugin WordPress. Déclenchez également lorsqu'un utilisateur télécharge un zip ou un dossier de plugin et demande des commentaires, une analyse ou un avis.
