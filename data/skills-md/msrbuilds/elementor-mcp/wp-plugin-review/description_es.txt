Revisión completa de complementos de WordPress que cubre vulnerabilidades de seguridad, cumplimiento de los estándares de codificación de WordPress (WPCS), pautas del repositorio de complementos, cobertura de pruebas unitarias y accesibilidad. Ejecuta herramientas automatizadas (PHPCS con WPCS, PHPStan, PHPUnit) además de una revisión manual profunda del código. Genera un informe detallado de revisión de Markdown con problemas, clasificaciones de gravedad y soluciones procesables. Utilice esta habilidad siempre que el usuario solicite "revisar un complemento", "auditar un complemento de WordPress", "verificar la seguridad del complemento", "verificar el envío del complemento al repositorio", "revisar el código del complemento", "revisar el código del complemento", "verificar mi complemento" o cualquier solicitud que implique evaluar la calidad del código de un complemento de WordPress, la postura de seguridad o la preparación del repositorio. También se activa cuando un usuario carga un archivo zip o una carpeta de complemento y solicita comentarios, análisis o una revisión.
