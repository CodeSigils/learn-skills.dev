按照官方 WordPress 编码标准、安全最佳实践和 WordPress.org 目录指南开发 WordPress 插件。每当用户想要创建、搭建或开发 WordPress 插件时，请使用此技能 - 包括标准插件（设置页面、CPT、短代码）、WooCommerce 扩展、Gutenberg 块插件或 REST API/无头插件。当用户提到“WordPress 插件”、“WP 插件”、要求将功能构建为插件、想要添加管理页面、注册自定义帖子类型、创建块、构建 WooCommerce 附加组件或通过插件架构以任何方式扩展 WordPress 时也会触发。即使用户只是说“为我构建一个 X 插件”，也可以使用此技能。
