Sviluppa plugin WordPress seguendo gli standard di codifica ufficiali di WordPress, le migliori pratiche di sicurezza e le linee guida della directory WordPress.org. Utilizza questa competenza ogni volta che l'utente desidera creare, supportare o sviluppare un plug-in WordPress, inclusi plug-in standard (pagine di impostazioni, CPT, codici brevi), estensioni WooCommerce, plug-in di blocco Gutenberg o API REST/plug-in headless. Si attiva anche quando l'utente menziona "plug-in WordPress", "plug-in WP", chiede di creare una funzionalità come plug-in, desidera aggiungere pagine di amministrazione, registrare tipi di post personalizzati, creare blocchi, creare componenti aggiuntivi WooCommerce o estendere WordPress in qualsiasi modo tramite l'architettura del plug-in. Anche se l'utente dice semplicemente "creami un plugin per X", usa questa abilità.
