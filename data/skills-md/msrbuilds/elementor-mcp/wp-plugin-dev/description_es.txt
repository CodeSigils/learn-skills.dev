Desarrolle complementos de WordPress siguiendo los estándares de codificación oficiales de WordPress, las mejores prácticas de seguridad y las pautas del directorio de WordPress.org. Utilice esta habilidad siempre que el usuario quiera crear, desarrollar o desarrollar un complemento de WordPress, incluidos complementos estándar (páginas de configuración, CPT, códigos cortos), extensiones de WooCommerce, complementos de bloques de Gutenberg o API REST/complementos sin cabeza. También se activa cuando el usuario menciona "complemento de WordPress", "complemento de WP", solicita crear una función como complemento, desea agregar páginas de administración, registrar tipos de publicaciones personalizadas, crear bloques, crear complementos de WooCommerce o extender WordPress de cualquier manera a través de la arquitectura de complementos. Incluso si el usuario simplemente dice "constrúyeme un complemento para X", usa esta habilidad.
