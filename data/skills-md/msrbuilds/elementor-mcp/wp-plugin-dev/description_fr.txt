Développez des plugins WordPress en suivant les normes de codage officielles de WordPress, les meilleures pratiques de sécurité et les directives de l'annuaire WordPress.org. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer, échafauder ou développer un plugin WordPress, y compris des plugins standard (pages de paramètres, CPT, shortcodes), des extensions WooCommerce, des plugins de bloc Gutenberg ou des API REST/plugins sans tête. Se déclenche également lorsque l'utilisateur mentionne « plugin WordPress », « plugin WP », demande de créer une fonctionnalité en tant que plugin, souhaite ajouter des pages d'administration, enregistrer des types de publication personnalisés, créer des blocs, créer des modules complémentaires WooCommerce ou étendre WordPress de quelque manière que ce soit via l'architecture de plugin. Même si l'utilisateur dit simplement "créez-moi un plugin pour X", utilisez cette compétence.
