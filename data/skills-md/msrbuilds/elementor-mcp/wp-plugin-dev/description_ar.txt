قم بتطوير مكونات WordPress الإضافية وفقًا لمعايير ترميز WordPress الرسمية وأفضل ممارسات الأمان وإرشادات دليل WordPress.org. استخدم هذه المهارة عندما يريد المستخدم إنشاء مكون WordPress الإضافي أو دعمه أو تطويره - بما في ذلك المكونات الإضافية القياسية (صفحات الإعدادات، CPTs، الرموز القصيرة)، ملحقات WooCommerce، مكونات كتلة Gutenberg الإضافية، أو REST API / المكونات الإضافية بدون رأس. يتم تشغيله أيضًا عندما يذكر المستخدم "مكون WordPress الإضافي"، أو "WP plugin"، أو يطلب إنشاء ميزة كمكون إضافي، أو يريد إضافة صفحات إدارية، أو تسجيل أنواع منشورات مخصصة، أو إنشاء كتل، أو إنشاء وظائف WooCommerce الإضافية، أو توسيع WordPress بأي شكل من الأشكال عبر بنية البرنامج المساعد. حتى لو قال المستخدم فقط "أنشئ لي مكونًا إضافيًا لـ X"، فاستخدم هذه المهارة.
