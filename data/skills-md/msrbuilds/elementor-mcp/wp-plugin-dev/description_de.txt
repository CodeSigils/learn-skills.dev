Entwickeln Sie WordPress-Plugins gemäß den offiziellen WordPress-Codierungsstandards, bewährten Sicherheitspraktiken und den Verzeichnisrichtlinien von WordPress.org. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein WordPress-Plugin erstellen, ein Gerüst erstellen oder entwickeln möchte – einschließlich Standard-Plugins (Einstellungsseiten, CPTs, Shortcodes), WooCommerce-Erweiterungen, Gutenberg-Block-Plugins oder REST-API/Headless-Plugins. Wird auch ausgelöst, wenn der Benutzer „WordPress-Plugin“, „WP-Plugin“ erwähnt, eine Funktion als Plugin erstellen möchte, Admin-Seiten hinzufügen, benutzerdefinierte Beitragstypen registrieren, Blöcke erstellen, WooCommerce-Add-ons erstellen oder WordPress auf irgendeine Weise über die Plugin-Architektur erweitern möchte. Auch wenn der Benutzer nur sagt: „Erstelle mir ein Plugin für X“, nutzen Sie diese Fähigkeit.
