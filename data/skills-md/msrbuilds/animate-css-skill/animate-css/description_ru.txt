Добавляйте CSS-анимацию к элементам HTML, компонентам React/JSX или шаблонам WordPress PHP с помощью Animate.css (v4.1.1). Используйте этот навык всякий раз, когда пользователь хочет анимировать элементы пользовательского интерфейса, добавить эффекты входа/выхода, анимацию привлечения внимания или любое движение на основе CSS в свою разметку. Запускайте такие фразы, как «добавить анимацию», «анимировать это», «заставить его подпрыгивать/затухать/скользить/масштабировать», «добавить переходы», «CSS-анимация» или любой запрос на визуальное оживление элементов. Работает с необработанными фрагментами HTML, полными файлами HTML, React JSX и шаблонами WordPress PHP. Клод выбирает наиболее контекстуально подходящую анимацию — от пользователя не требуется никаких догадок.
