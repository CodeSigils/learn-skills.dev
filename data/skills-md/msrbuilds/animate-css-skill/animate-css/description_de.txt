Fügen Sie CSS-Animationen zu HTML-Elementen, React/JSX-Komponenten oder WordPress-PHP-Vorlagen hinzu, indem Sie Animate.css (v4.1.1) verwenden. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer UI-Elemente animieren, Eingangs-/Ausgangseffekte, aufmerksamkeitsstarke Animationen oder eine beliebige CSS-basierte Bewegung zu seinem Markup hinzufügen möchte. Lösen Sie Phrasen wie „Animation hinzufügen“, „Animieren“, „Hüpfen/Ausblenden/Verschieben/Zoomen“, „Übergänge hinzufügen“, „CSS-Animationen“ oder jede andere Aufforderung aus, Elemente visuell zum Leben zu erwecken. Funktioniert mit rohen HTML-Snippets, vollständigen HTML-Dateien, React JSX und WordPress-PHP-Vorlagen. Claude wählt die kontextbezogen am besten geeignete Animation aus – der Benutzer muss nicht raten.
