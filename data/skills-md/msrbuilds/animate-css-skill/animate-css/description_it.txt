Aggiungi animazioni CSS a elementi HTML, componenti React/JSX o modelli PHP WordPress utilizzando Animate.css (v4.1.1). Utilizza questa abilità ogni volta che l'utente desidera animare elementi dell'interfaccia utente, aggiungere effetti di entrata/uscita, animazioni che attirano l'attenzione o qualsiasi movimento basato su CSS al proprio markup. Attiva frasi come "aggiungi animazione", "anima questo", "fallo rimbalzare/dissolvere/scorrere/zoom", "aggiungi transizioni", "animazioni CSS" o qualsiasi richiesta per dare vita visivamente agli elementi. Funziona con snippet HTML non elaborati, file HTML completi, React JSX e modelli PHP WordPress. Claude sceglie l'animazione più appropriata al contesto: non sono necessarie congetture da parte dell'utente.
