Animate.css (v4.1.1) を使用して、CSS アニメーションを HTML 要素、React/JSX コンポーネント、または WordPress PHP テンプレートに追加します。ユーザーが UI 要素をアニメーション化したり、入場/退場効果、注目を集めるアニメーション、または CSS ベースのモーションをマークアップに追加したりする場合は、常にこのスキルを使用します。 「アニメーションを追加」、「これをアニメーション化」、「バウンス/フェード/スライド/ズームにする」、「トランジションを追加」、「CSS アニメーション」などのフレーズをトリガーして、要素に視覚的に命を吹き込みます。生の HTML スニペット、完全な HTML ファイル、React JSX、WordPress PHP テンプレートで動作します。クロードは状況に応じて最も適切なアニメーションを選択します。ユーザーが推測する必要はありません。
