Ajoutez des animations CSS aux éléments HTML, aux composants React/JSX ou aux modèles WordPress PHP à l'aide d'Animate.css (v4.1.1). Utilisez cette compétence chaque fois que l'utilisateur souhaite animer des éléments de l'interface utilisateur, ajouter des effets d'entrée/sortie, des animations pour attirer l'attention ou tout mouvement basé sur CSS à son balisage. Déclenchez des expressions telles que « ajouter une animation », « animer ceci », « faire rebondir/fondu/glisser/zoomer », « ajouter des transitions », « animations CSS » ou toute demande visant à donner vie à des éléments visuellement. Fonctionne avec des extraits de code HTML bruts, des fichiers HTML complets, des modèles React JSX et WordPress PHP. Claude sélectionne l'animation la plus contextuellement appropriée, sans aucune hypothèse de la part de l'utilisateur.
