Agregue animaciones CSS a elementos HTML, componentes React/JSX o plantillas PHP de WordPress usando Animate.css (v4.1.1). Utilice esta habilidad siempre que el usuario quiera animar elementos de la interfaz de usuario, agregar efectos de entrada/salida, animaciones para llamar la atención o cualquier movimiento basado en CSS a su marcado. Active frases como "agregar animación", "animar esto", "hacer que rebote/se desvanezca/se deslice/zoom", "agregar transiciones", "animaciones CSS" o cualquier solicitud para darle vida visual a los elementos. Funciona con fragmentos de HTML sin formato, archivos HTML completos, React JSX y plantillas PHP de WordPress. Claude elige la animación más apropiada al contexto, sin necesidad de conjeturas por parte del usuario.
