Descubrimiento primero en documentos para una exploración eficiente de la base de código. Úselo antes de Glob/Grep/Explore para obtener ID lógicos y rutas de archivos directamente desde la documentación semántica. Ahorra tokens evitando costosas búsquedas de archivos. Los comandos incluyen `/discover FEATURE` para la búsqueda de funciones, `/discover "search Terms"` para la búsqueda de palabras clave y `/discover --prime` para cargar el índice empresarial.
