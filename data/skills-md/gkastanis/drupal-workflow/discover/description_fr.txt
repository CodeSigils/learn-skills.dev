Découverte Docs-first pour une exploration efficace de la base de code. À utiliser avant Glob/Grep/Explore pour obtenir les ID logiques et les chemins de fichiers directement à partir de la documentation sémantique. Enregistre les jetons en évitant les recherches de fichiers coûteuses. Les commandes incluent `/discover FEATURE` pour la recherche de fonctionnalités, `/discover "searchterms"` pour la recherche par mot clé et `/discover --prime` pour charger l'index professionnel.
