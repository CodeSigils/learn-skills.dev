Открытие «сначала документация» для эффективного исследования кодовой базы. Используйте перед Glob/Grep/Explore, чтобы получить логические идентификаторы и пути к файлам непосредственно из семантической документации. Сохраняет токены, избегая дорогостоящего поиска файлов. Команды включают `/discover FEATURE` для поиска объектов, `/discover "search terms" для поиска по ключевым словам и `/discover --prime` для загрузки бизнес-индекса.
