Depurar problemas de bloqueo en la inferencia distribuida SGLang (TP/PP/DP/EP). Cubre la identificación de ubicaciones de bloqueo mediante py-spy/watchdog/cuda coredump, registro por rango para encontrar divergencia de estado, metodología de búsqueda binaria para localizar el primer punto de divergencia y corrección de patrones. Úselo cuando una ejecución de SGLang de múltiples GPU se bloquea, se congela o se agota el tiempo de espera durante operaciones colectivas.
