Проблемы зависания отладки в распределенном выводе SGLang (TP/PP/DP/EP). Охватывает определение мест зависаний с помощью py-spy/watchdog/cuda coredump, ведение журнала каждого ранга для обнаружения расхождений состояний, методологию двоичного поиска для обнаружения первой точки расхождения и исправление шаблонов. Используйте, когда запуск SGLang с несколькими графическими процессорами зависает, зависает или истекает время ожидания во время коллективных операций.
