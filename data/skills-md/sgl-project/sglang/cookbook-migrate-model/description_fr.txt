Migrez une page de livre de recettes SGLang à modèle hérité (générateur monolithique par modèle sous docs/src/snippets/autoregressive/) vers le modèle piloté par la configuration (moteurs _deployment.jsx / _playground.jsx partagés + configuration par modèle). À utiliser lorsqu'on vous demande de migrer, de convertir ou de porter une page de livre de recettes existante - PAS pour les nouveaux modèles (utilisez Cookbook-add-model pour ceux-ci). Exécutez avec /cookbook-migrate-model <Nom de la page modèle, par ex. GLM-5.1>.
