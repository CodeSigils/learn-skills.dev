Перенесите страницу кулинарной книги SGLang с устаревшим шаблоном (монолитный генератор для каждой модели в docs/src/snippets/autoregressive/) в шаблон, управляемый конфигурацией (общие механизмы _deployment.jsx/_playground.jsx + конфигурация для каждой модели). Используйте, когда вас просят перенести, преобразовать или перенести существующую страницу кулинарной книги — НЕ для совершенно новых моделей (для них используйте Cookbook-Add-Model). Запустите с помощью /cookbook-migrate-model <имя страницы модели, например. ГЛМ-5.1>.
