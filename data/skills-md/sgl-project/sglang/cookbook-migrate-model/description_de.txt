Migrieren Sie eine SGLang-Kochbuchseite mit Legacy-Vorlage (monolithischer pro-Modell-Generator unter docs/src/snippets/autoregressive/) auf die konfigurationsgesteuerte Vorlage (gemeinsame _deployment.jsx-/_playground.jsx-Engines + pro-Modell-Konfiguration). Verwenden Sie diese Option, wenn Sie aufgefordert werden, eine vorhandene Kochbuchseite zu migrieren, zu konvertieren oder zu portieren – NICHT für brandneue Modelle (verwenden Sie dafür „cookbook-add-model“). Führen Sie mit /cookbook-migrate-model <Name der Modellseite aus, z. B. GLM-5.1>.
