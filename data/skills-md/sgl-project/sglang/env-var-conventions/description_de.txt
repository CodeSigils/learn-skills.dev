Konventionen für SGLang-Umgebungsvariablen – wo sie definiert werden, wie auf sie zugegriffen wird, wie sie benannt werden und wie sie veraltet sind. Verwenden Sie diese Option, wenn Sie eine „SGLANG_*“-Umgebungsvariable hinzufügen, umbenennen oder überprüfen (oder einen alten „SGL_*“-Alias ​​migrieren) oder wenn Sie „python/sglang/srt/environ.py“ berühren.
