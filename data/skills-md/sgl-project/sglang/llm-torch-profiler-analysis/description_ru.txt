Унифицированный навык сортировки Torch-Profiler LLM для sglang, vllm, TensorRT-LLM и TokenSpeed. Используйте его для проверки существующего каталога `trace.json(.gz)` или профиля, а также для запуска живого профилирования на работающем сервере, если он поддерживается, и возврата одного отчета из трех таблиц с таблицами ядра, возможностей перекрытия и шаблонов предохранителей.
