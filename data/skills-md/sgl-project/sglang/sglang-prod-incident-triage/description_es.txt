Flujo de depuración de reproducción inicial para problemas de servicio SGLang. Úselo cuando un servidor activo o reciente muestra fallas en las comprobaciones de estado, regresiones de latencia o rendimiento, crecimiento de colas, tiempos de espera, paradas distribuidas, volcados de memoria, resultados incorrectos después de las implementaciones o problemas de PD/EP/HiCache, y el trabajo es convertir el problema en una repetición más la siguiente herramienta de depuración adecuada.
