Conventions de dénomination pour les identifiants de décodage spéculatif SGLang. À utiliser lors de l'ajout, du renommage ou de la révision d'identifiants dans le code de décodage spéculatif — tout ce qui se trouve sous `python/sglang/srt/speculative/`, les backends d'attention associés, les accumulateurs de planificateur, les champs IPC, les métriques d'observabilité ou les indicateurs CLI.
