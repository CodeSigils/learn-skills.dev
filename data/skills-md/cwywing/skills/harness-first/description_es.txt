Esta habilidad debe usarse al comienzo de un proyecto nuevo (greenfield), antes de escribir código de característica o indicaciones, para construir un arnés de ejecución de autoverificación a través de cinco fases cerradas (modelo de realidad → límites → enlace mínimo ejecutable → eval-first → bucle Maker-Checker), cada una de las cuales produce un archivo concreto. Actívelo cuando el usuario diga cosas como "Estoy comenzando un nuevo proyecto", "creemos una aplicación que haga X", "inicie un nuevo agente/aplicación LLM", "ponga en marcha un nuevo backend/CMS/automatización", "arquitecte esto desde cero", "¿debería ser multiagente o una sola llamada?", o "iniciar este repositorio". Se aplica a cualquier tipo de proyecto, no solo a los de IA. Úselo incluso cuando el usuario solo diga "construyamos X" sin mencionar arquitectura o evaluación, porque el primer paso correcto en cualquier proyecto nuevo es construir el arnés, no el mensaje o el código. No lo use para cambios en una base de código existente (una corrección de errores, una característica, una refactorización, una revisión): solo inicio.
