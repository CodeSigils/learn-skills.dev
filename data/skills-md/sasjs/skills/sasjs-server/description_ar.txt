تثبيت وتكوين وتشغيل @sasjs/server - غلاف NodeJS مفتوح المصدر حول ثنائي SAS الذي يوفر REST API ونظام الملفات (SASjs Drive) وتنفيذ البرامج المخزنة وتدفق تطبيقات الويب. يغطي أوضاع سطح المكتب مقابل أوضاع الخادم، وتكوين وقت التشغيل (SAS/JS/Python/R)، ومتغيرات البيئة، والمصادقة (الرموز المميزة، LDAP)، وأنواع الخوادم الوهمية. يُستخدم عند النشر أو استكشاف الأخطاء وإصلاحها أو التطوير ضد sasjs/server.
