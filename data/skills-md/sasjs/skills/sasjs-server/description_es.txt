Instalación, configuración y ejecución de @sasjs/server: el contenedor NodeJS de código abierto alrededor del binario SAS que proporciona una API REST, un sistema de archivos (unidad SASjs), ejecución de programas almacenados y transmisión de aplicaciones web. Cubre los modos de escritorio versus servidor, configuración de tiempo de ejecución (SAS/JS/Python/R), variables de entorno, autenticación (tokens, LDAP) y tipos de servidores simulados. Úselo al implementar, solucionar problemas o desarrollar en sasjs/server.
