Installazione, configurazione ed esecuzione di @sasjs/server: il wrapper NodeJS open source attorno al binario SAS che fornisce un'API REST, un file system (SASjs Drive), l'esecuzione di programmi archiviati e lo streaming di app Web. Copre le modalità desktop e server, la configurazione runtime (SAS/JS/Python/R), le variabili di ambiente, l'autenticazione (token, LDAP) e i tipi di server fittizi. Da utilizzare durante la distribuzione, la risoluzione dei problemi o lo sviluppo su sasjs/server.
