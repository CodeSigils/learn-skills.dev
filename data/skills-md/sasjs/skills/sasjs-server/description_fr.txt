Installation, configuration et exécution de @sasjs/server — le wrapper NodeJS open source autour du binaire SAS qui fournit une API REST, un système de fichiers (lecteur SASjs), l'exécution de programmes stockés et le streaming d'applications Web. Couvre les modes bureau et serveur, la configuration d'exécution (SAS/JS/Python/R), les variables d'environnement, l'authentification (jetons, LDAP) et les types de serveur fictif. À utiliser lors du déploiement, du dépannage ou du développement sur sasjs/server.
