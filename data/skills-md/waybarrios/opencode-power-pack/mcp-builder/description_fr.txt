Guidez la création de serveurs MCP (Model Context Protocol) de haute qualité qui permettent aux LLM d'interagir avec des services externes grâce à des outils bien conçus. À utiliser lorsque l'utilisateur souhaite créer un serveur MCP pour intégrer une API ou un service externe, que ce soit en Python (FastMCP) ou Node/TypeScript (MCP SDK).
