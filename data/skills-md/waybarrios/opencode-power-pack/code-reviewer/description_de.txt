Überprüfen Sie den Code auf Bugs, Logikfehler, Sicherheitslücken, Probleme mit der Codequalität und die Einhaltung von Projektkonventionen und nutzen Sie dabei konfidenzbasierte Filterung, um nur wirklich wichtige Probleme mit hoher Priorität zu melden. Verwenden Sie diese Fähigkeit, wenn Sie einen kleinen Satz von Änderungen lokal überprüfen (z. B. nicht bereitgestellte Unterschiede), wenn sie als Unteraufgabe während der Qualitätsüberprüfung der Feature-Entwicklung verteilt werden oder wenn der Benutzer eine Kritik an einer bestimmten Datei oder Funktion wünscht.
