Examinez le code pour détecter les bogues, les erreurs logiques, les vulnérabilités de sécurité, les problèmes de qualité du code et le respect des conventions du projet, en utilisant un filtrage basé sur la confiance pour signaler uniquement les problèmes hautement prioritaires qui comptent vraiment. Utilisez cette compétence lors de l'examen local d'un petit ensemble de modifications (telles que des différences non mises en scène), lorsqu'elles sont distribuées en tant que sous-tâche lors de l'examen de la qualité du développement de fonctionnalités, ou lorsque l'utilisateur souhaite une critique d'un fichier ou d'une fonction spécifique.
