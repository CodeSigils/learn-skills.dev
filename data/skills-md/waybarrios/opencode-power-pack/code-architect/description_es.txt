Diseñe una arquitectura de características analizando convenciones y patrones de base de código existentes, luego proporcione un plan de implementación integral con archivos específicos para crear o modificar, diseños de componentes, flujos de datos y una secuencia de compilación. Utilice esta habilidad cuando el usuario solicite un diseño de arquitectura, un plan de implementación para una característica no trivial o cuando se envíe como una subtarea durante la fase de arquitectura de desarrollo de características.
