Progetta un'architettura di funzionalità analizzando i modelli e le convenzioni della base di codice esistenti, quindi fornisci un modello di implementazione completo con file specifici da creare o modificare, progetti di componenti, flussi di dati e una sequenza di build. Utilizza questa competenza quando l'utente richiede la progettazione di un'architettura, un piano di implementazione per una funzionalità non banale o quando viene inviata come attività secondaria durante la fase di sviluppo dell'architettura delle funzionalità.
