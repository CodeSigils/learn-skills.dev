صمم بنية الميزات من خلال تحليل أنماط واصطلاحات قاعدة التعليمات البرمجية الموجودة، ثم قم بتوفير مخطط تنفيذ شامل مع ملفات محددة لإنشاء أو تعديل، وتصميمات المكونات، وتدفقات البيانات، وتسلسل البناء. استخدم هذه المهارة عندما يطلب المستخدم تصميمًا معماريًا، أو خطة تنفيذ لميزة غير تافهة، أو عند إرسالها كمهمة فرعية أثناء مرحلة هندسة تطوير الميزات.
