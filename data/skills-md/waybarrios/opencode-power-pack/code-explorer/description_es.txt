Analice en profundidad una característica de base de código existente rastreando rutas de ejecución, mapeando capas de arquitectura, comprendiendo patrones y abstracciones, y documentando dependencias. Utilice esta habilidad cuando necesite comprender cómo funciona una función antes de modificarla o ampliarla, cuando se envíe como una subtarea durante la exploración de desarrollo de funciones o cuando el usuario pregunte "¿cómo funciona X en este código base?".
