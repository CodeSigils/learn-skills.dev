قم بتحليل ميزة قاعدة التعليمات البرمجية الموجودة بعمق من خلال تتبع مسارات التنفيذ، ورسم خرائط لطبقات البنية، وفهم الأنماط والتجريدات، وتوثيق التبعيات. استخدم هذه المهارة عندما تحتاج إلى فهم كيفية عمل الميزة قبل تعديلها أو توسيعها، أو عند إرسالها كمهمة فرعية أثناء استكشاف تطوير الميزات، أو عندما يسأل المستخدم "كيف يعمل X في قاعدة التعليمات البرمجية هذه".
