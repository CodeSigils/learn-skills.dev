Analysez en profondeur une fonctionnalité de base de code existante en traçant les chemins d'exécution, en mappant les couches d'architecture, en comprenant les modèles et les abstractions et en documentant les dépendances. Utilisez cette compétence lorsque vous avez besoin de comprendre le fonctionnement d'une fonctionnalité avant de la modifier ou de l'étendre, lorsqu'elle est distribuée en tant que sous-tâche lors de l'exploration du développement de fonctionnalités, ou lorsque l'utilisateur demande « comment X fonctionne-t-il dans cette base de code ».
