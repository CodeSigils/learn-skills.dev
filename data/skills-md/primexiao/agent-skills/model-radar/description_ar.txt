ابحث عن نماذج LLM وقارنها والتوصية بها على OpenRouter. يُستخدم عند اختيار نموذج حسب الميزانية أو نافذة السياق أو الإمكانيات (استخدام الأداة / الرؤية / الاستدلال / المخرجات المنظمة)، أو الأساليب؛ مقارنة نموذجين أو أكثر جنبًا إلى جنب؛ التوصية بنموذج لأحمال عمل الترميز/الدفعة/الدردشة/الرؤية؛ أو الإجابة على "أرخص نموذج برؤية أقل من $X / MTok"، "ما هو أكثر طراز كلود شيوعًا"، "أسرع نموذج بسياق مليون دولار". تشغيل المهام التي تتضمن اختيار النموذج، أو مقارنة أسعار LLM، أو تصفية القدرات، أو "أي نموذج يجب أن أستخدمه".
