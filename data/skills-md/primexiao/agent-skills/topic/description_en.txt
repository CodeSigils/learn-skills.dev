Initialize or tidy an ideas/topics directory, start or explore a topic in a flat topic archive, or safely audit/fix archive convention drift. Use for /topic init, /topic IDEA, /topic explore, /topic lint, topic archives, idea vaults, and organizing folders of independent exploratory ideas. An explicit /topic command always means a topic-archive workflow. Do not use to generate project task plans, manage issues, or refactor a generic source-code repository.
