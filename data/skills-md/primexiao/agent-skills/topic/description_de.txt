Initialisieren oder bereinigen Sie ein Ideen-/Themenverzeichnis, starten oder erkunden Sie ein Thema in einem flachen Themenarchiv oder prüfen/beheben Sie sicher Abweichungen von Archivkonventionen. Verwendung für /topic init, /topic IDEA, /topic explore, /topic lint, Themenarchive, Ideentresore und das Organisieren von Ordnern unabhängiger explorativer Ideen. Ein expliziter /topic-Befehl bedeutet immer einen Themenarchiv-Workflow. Nicht zum Generieren von Projektaufgabenplänen, zum Verwalten von Problemen oder zum Umgestalten eines generischen Quellcode-Repositorys verwenden.
