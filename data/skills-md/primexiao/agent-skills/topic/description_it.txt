Inizializza o riordina una directory di idee/argomenti, avvia o esplora un argomento in un archivio di argomenti semplici o controlla/correggi in modo sicuro la deviazione delle convenzioni dell'archivio. Utilizzare per /topic init, /topic IDEA, /topic explore, /topic lint, archivi di argomenti, depositi di idee e organizzazione di cartelle di idee esplorative indipendenti. Un comando /topic esplicito indica sempre un flusso di lavoro di archivio di argomenti. Non utilizzare per generare piani di attività del progetto, gestire problemi o effettuare il refactoring di un repository di codice sorgente generico.
