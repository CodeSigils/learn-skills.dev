Cree presentaciones nativas del navegador con un selector de galería de temas obligatorio (inicie la interfaz de usuario local para que el usuario seleccione un tema antes de crear las diapositivas), navegación con el teclado, revelaciones, notas del presentador, datos de Recharts/temas del tablero (datos de órbita/tablero de métricas) y control de calidad estricto. Úselo al crear o mejorar una plataforma de diapositivas interactiva, un paquete de junta ejecutiva, una conferencia, una explicación documental o un micrositio de presentación; También utilícelo cuando el usuario mencione la galería de temas, seleccione el tema, Datos de órbita, Tablero de métricas o "hacer un PPT/plataforma". No lo use para PPTX nativo a menos que se combine con una habilidad de PowerPoint.
