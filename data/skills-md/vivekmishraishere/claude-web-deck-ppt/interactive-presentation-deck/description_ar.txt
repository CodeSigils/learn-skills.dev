أنشئ مجموعات عروض تقديمية أصلية للمتصفح باستخدام منتقي معرض السمات الإلزامي (قم بتشغيل واجهة المستخدم المحلية بحيث يحدد المستخدم سمة قبل إنشاء أي شرائح)، والتنقل عبر لوحة المفاتيح، والكشف، وملاحظات مقدم العرض، وإعادة تخطيط سمات البيانات/اللوحة (بيانات Orbit / Metric Board)، وضمان الجودة الصارمة. يُستخدم عند إنشاء أو تحسين مجموعة شرائح تفاعلية، أو حزمة لوحة تنفيذية، أو محاضرة، أو شرح وثائقي، أو موقع مصغر للعرض التقديمي؛ يُستخدم أيضًا عندما يذكر المستخدم معرض السمات، أو تحديد السمة، أو Orbit Data، أو Metric Board، أو "إنشاء PPT/deck". لا تستخدمه مع PPTX الأصلي إلا إذا كان مقترنًا بمهارة PowerPoint.
