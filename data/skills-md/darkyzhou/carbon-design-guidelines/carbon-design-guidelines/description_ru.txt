Руководства, ссылки и инструменты для создания пользовательских интерфейсов React с помощью системы IBM Carbon Design («@carbon/react» v11). Охватывает основы дизайна (сетка, цвет, интервалы, типографика, темы, движение, доступность), использование компонентов с примерами кода, шаблоны проектирования (формы, диалоговые окна, уведомления, загрузка, пустые состояния) и визуализацию данных с помощью `@carbon/charts-react`. Включает интерфейс командной строки для поиска значков/пиктограмм. Также используйте, когда пользователь запрашивает пользовательский интерфейс, который должен соответствовать визуальному языку IBM, даже без упоминания Carbon по имени.
