IBM の Carbon Design System (`@carbon/react` v11) を使用して React UI を構築するためのガイド、リファレンス、ツール。デザインの基礎 (グリッド、色、間隔、タイポグラフィ、テーマ、モーション、アクセシビリティ)、コード サンプルによるコンポーネントの使用法、デザイン パターン (フォーム、ダイアログ、通知、読み込み、空の状態)、および `@carbon/charts-react` によるデータの視覚化について説明します。アイコン/ピクトグラム検索 CLI が含まれています。また、Carbon の名前を言及しなくても、ユーザーが IBM のビジュアル言語に従う必要がある UI を要求した場合にも使用します。
