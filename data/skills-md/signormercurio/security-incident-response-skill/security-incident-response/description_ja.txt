セキュリティ インシデント対応エキスパート: SIREN 経由で侵害されたホストに対して読み取り専用のリモート フォレンジック調査を実行し、ATT&CK 攻撃チェーンを構築し、中国のインシデント対応レポートを生成します。アラート駆動モード (ユーザーが UID + イベント ID を指定) および自由形式の調査モード (アラートなし、ユーザーが記述した異常な手がかりに基づいて調査) をサポートします。トリガーフレーズ: 「インシデント対応」、「このアラートを確認する」、「このイベントを調査する」、「イベント ID xxx を確認する」、「このホストを確認する」、「イベント トレース」、「Web シェルを調査する」、「マイニングを確認する」、「リバース シェルを調査する」、「ブルート フォースを確認する」、「ホスト上の IR」、「このアラートを調査する」、「インシデント対応」、「この侵入を追跡する」。
