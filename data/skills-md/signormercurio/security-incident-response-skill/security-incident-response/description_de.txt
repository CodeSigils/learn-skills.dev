Experte für Sicherheitsnotfälle: Führen Sie über SIREN eine schreibgeschützte forensische Fernuntersuchung auf dem Host des Opfers durch, erstellen Sie eine ATT&CK-Angriffskette und erstellen Sie einen chinesischen Notfallbericht. Unterstützt den alarmgesteuerten Modus (Benutzer gibt UID + Ereignis-ID an) und den Freiform-Untersuchungsmodus (keine Warnung, Untersuchung basierend auf vom Benutzer beschriebenen abnormalen Hinweisen). Auslöserphrasen: „Notfallreaktion“, „Diese Warnung prüfen“, „Dieses Ereignis untersuchen“, „Ereignis-ID xxx prüfen“, „Diesen Host überprüfen“, „Ereignisverfolgung“, „Webshell untersuchen“, „Mining prüfen“, „Rebound-Shell untersuchen“, „Brute-Force prüfen“, „IR auf Host“, „Diese Warnung untersuchen“, „Reaktion auf den Vorfall“, „Diesen Einbruch verfolgen“.
