Experte für die Reaktion auf Sicherheitsvorfälle: Führen Sie schreibgeschützte forensische Remote-Untersuchungen auf kompromittierten Hosts über SIREN durch, bauen Sie eine ATT&CK-Angriffskette auf und erstellen Sie einen chinesischen Bericht zur Reaktion auf Vorfälle. Unterstützt den alarmgesteuerten Modus (Benutzer gibt UID + Ereignis-ID an) und den Freiform-Untersuchungsmodus (keine Warnung, Untersuchung basierend auf vom Benutzer beschriebenen anomalen Hinweisen). Auslösersätze: „Reaktion auf Vorfall“, „Diese Warnung prüfen“, „Dieses Ereignis untersuchen“, „Ereignis-ID xxx ansehen“, „Diesen Host überprüfen“, „Ereignisverfolgung“, „Webshell untersuchen“, „Mining prüfen“, „Reverse Shell untersuchen“, „Brute Force prüfen“, „IR auf Host“, „Diese Warnung untersuchen“, „Reaktion auf den Vorfall“, „Diesen Einbruch verfolgen“.
