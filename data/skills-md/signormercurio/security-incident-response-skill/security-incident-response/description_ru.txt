Эксперт по реагированию на инциденты безопасности: проводите удаленные судебные расследования только для чтения на скомпрометированных хостах через SIREN, создайте цепочку атак ATT&CK и создайте отчет о реагировании на инциденты в Китае. Поддерживает режим на основе предупреждений (пользователь предоставляет UID + идентификатор события) и режим расследования в свободной форме (без предупреждений, расследование на основе описанных пользователем аномальных признаков). Триггерные фразы: «реакция на инцидент», «проверьте это предупреждение», «расследуйте это событие», «посмотрите на идентификатор события xxx», «проверьте этот хост», «трассировка событий», «исследуйте веб-шелл», «проверьте майнинг», «исследуйте обратную оболочку», «проверьте перебор», «IR на хосте», «расследуйте это предупреждение», «реакция на инцидент», «отследите это вторжение».
