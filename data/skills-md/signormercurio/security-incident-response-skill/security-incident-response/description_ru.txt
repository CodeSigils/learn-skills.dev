Эксперт по реагированию на чрезвычайные ситуации в области безопасности: выполняет удаленное судебное расследование скомпрометированных хостов только для чтения через SIREN, строит цепочку атак ATT&CK и генерирует отчет о реагировании на инциденты в Китае. Поддерживает режим на основе предупреждений (пользователь предоставляет UID + идентификатор события) и режим расследования в свободной форме (без предупреждений, расследование на основе описанных пользователем аномальных признаков). Триггерные фразы: «экстренный ответ», «проверьте это оповещение», «расследуйте это событие», «посмотрите на идентификатор события xxx», «проверьте этот хост», «трассировка событий», «исследуйте веб-шелл», «проверьте майнинг», «исследуйте обратную оболочку», «проверьте брутфорс», «IR на хосте», «расследуйте это оповещение», «реакция на инцидент», «отследите это вторжение».
