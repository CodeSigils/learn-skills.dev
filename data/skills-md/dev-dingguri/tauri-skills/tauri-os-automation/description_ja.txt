Tauri v2 L4 テストの Windows OS レベルの自動化制約 — システム トレイ、レジストリ、グローバル キー フック、ウィンドウ ポーリング。 pywinauto / UIA / winreg を介して自動化できるものと、手動のままにしなければならないものを定義します。 tauri-test-setup (L4 セクション) および tauri-test-generator (L4 のよくある間違い) によって呼び出されます。トリガー: 「L4 テスト」、「pywinauto」、「システム トレイ テスト」、「トレイ メニューの自動化」、「グローバル キー フック テスト」、「LLKHF_INJECTED」、「UIA COM クラッシュ 0x80040155」、「Windows 11 トレイ アイコン」、「TrayIconBuilder ツールチップ」。
