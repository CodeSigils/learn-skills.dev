تعليقات مراجعة رمز العنوان بأمان. يُستخدم عندما يتلقى Codex تعليقات العلاقات العامة، أو سلاسل المراجعة، أو التغييرات المطلوبة، أو تعليقات مراجعة التعليمات البرمجية المضمنة، أو اقتراحات المشرف، ويجب عليه تصنيف التعليقات، وتحديد ما سيتم إصلاحه أو مناقشته، وتطبيق التغييرات المركزة، والتحقق من كل إصلاح، وتجنب عمليات إعادة البناء غير ذات الصلة.
