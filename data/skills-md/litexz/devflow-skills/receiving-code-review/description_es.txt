Dirección de comentarios de revisión de código de forma segura. Úselo cuando Codex reciba comentarios de relaciones públicas, hilos de revisión, cambios solicitados, comentarios de revisión de código en línea o sugerencias de mantenedores y deba clasificar comentarios, decidir qué corregir o discutir, aplicar cambios enfocados, verificar cada corrección y evitar refactores no relacionados.
