Guardrail di confine Spring Web per refactoring Java/Spring Boot. Da utilizzare quando Codex modifica controller, endpoint REST, mappatura di richieste/risposte, convalida, sicurezza, caricamento/download di file, esportazioni o stratificazione di servizio/controller nelle applicazioni Spring. Si tratta di un'architettura opzionale e di uno stack tecnologico complementare alle competenze TDD; non utilizzare come competenza generica della metodologia TDD.
