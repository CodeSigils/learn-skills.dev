Barandillas de límites de Spring Web para refactorizadores de Java/Spring Boot. Úselo cuando Codex cambie controladores, puntos finales REST, mapeo de solicitud/respuesta, validación, seguridad, carga/descarga de archivos, exportaciones o capas de servicio/controlador en aplicaciones Spring. Se trata de un complemento opcional de arquitectura y tecnología para las habilidades TDD; no lo utilice como una habilidad genérica de metodología TDD.
