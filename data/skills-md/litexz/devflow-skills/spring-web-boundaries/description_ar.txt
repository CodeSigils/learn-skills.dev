حواجز الحماية لحدود Spring Web لإعادة بناء Java/Spring Boot. يُستخدم عندما يقوم Codex بتغيير وحدات التحكم، أو نقاط نهاية REST، أو تعيين الطلب/الاستجابة، أو التحقق من الصحة، أو الأمان، أو تحميل/تنزيل الملفات، أو الصادرات، أو طبقات الخدمة/وحدة التحكم في تطبيقات Spring. هذه بنية اختيارية ورفيق مجموعة التكنولوجيا لمهارات TDD؛ لا تستخدم كمهارة منهجية TDD عامة.
