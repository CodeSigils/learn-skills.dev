بوابة الإنجاز الإلزامية للأعمال الهندسية. استخدمه قبل القول بأن مهمة التطوير، أو إعادة البناء، أو إصلاح الأخطاء، أو النمذجة، أو المراجعة، أو التوثيق، أو التكوين، أو الالتزام، أو العلاقات العامة قد اكتملت للتحقق من متطلبات المستخدم، أو الملفات المتغيرة، أو الأوامر التي يتم تشغيلها باستخدام رموز الخروج، أو عمليات التحقق التي تم تخطيها، أو التحقق اليدوي، أو المخاطر المتبقية، أو التغييرات غير ذات الصلة، والاستعداد للالتزام التقليدي الصيني.
