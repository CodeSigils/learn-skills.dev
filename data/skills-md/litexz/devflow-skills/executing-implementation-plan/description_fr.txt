Exécuter un plan de mise en œuvre en toute sécurité. À utiliser lorsque le Codex dispose d'un plan écrit ou est sur le point de suivre les étapes d'ingénierie planifiées : examinez d'abord le plan pour détecter les tests manquants, les étapes surdimensionnées, les ordres erronés ou les hypothèses obsolètes, puis exécutez une tâche à la fois avec des preuves de vérification.
