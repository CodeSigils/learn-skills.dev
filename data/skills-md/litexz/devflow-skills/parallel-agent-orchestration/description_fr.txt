Planifiez le travail d’agents parallèles en toute sécurité pour les tâches d’ingénierie. À utiliser lorsque des modules indépendants, une révision de plan, une implémentation, une vérification ou une révision de code peuvent s'exécuter dans des contextes distincts avec une propriété de fichier qui ne se chevauche pas, ou lorsqu'un nouveau contexte de réviseur est utile pour éviter un travail complexe d'auto-confirmation.
