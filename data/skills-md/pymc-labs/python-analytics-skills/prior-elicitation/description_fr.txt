Se charge lorsque l'utilisateur choisit des priorités, exécute des vérifications prédictives préalables, appelle find_constrained_prior, utilise PreliZ ou obtient d'une autre manière des connaissances du domaine dans un modèle bayésien. Couvre les a priori faiblement informatifs, les a priori contraints, l'analyse de sensibilité et les workflows d'élicitation. Les déclencheurs incluent : la sélection préalable, l'élicitation, find_constrained_prior, PreliZ, les priors prédictifs, experts/informatifs, les priors faiblement informatifs, les priors contraints.
