Carica quando l'utente confronta modelli bayesiani, calcola LOO-CV/ELPD, chiama arviz_stats.loo o arviz_stats.compare, esegue l'impilamento/media dei modelli o calcola i fattori Bayes. Copre esclusivamente le API ArviZ 1.1 LOO/ELPD/stacking (no waic). I trigger includono: confronto dei modelli, LOO, ELPD, confronto, loo_expectations, loo_metrics, loo_r2, Pareto k, stacking, fattore di Bayes, convalida incrociata, accuratezza predittiva, criterio di informazione.
