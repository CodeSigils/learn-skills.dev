Se charge lorsque l'utilisateur compare des modèles bayésiens, calcule LOO-CV / ELPD, appelle arviz_stats.loo ou arviz_stats.compare, effectue un empilement/moyenne de modèles ou calcule des facteurs Bayes. Couvre exclusivement les API ArviZ 1.1 LOO/ELPD/empilage (pas de waic). Les déclencheurs incluent : comparaison de modèles, LOO, ELPD, compare, loo_expectations, loo_metrics, loo_r2, Pareto k, empilement, facteur Bayes, validation croisée, précision prédictive, critère d'information.
