Gère les modèles sémantiques Power BI, notamment les tables, les colonnes, les mesures, les relations, la création et le réglage DAX, l'importation, les conceptions DirectQuery et Direct Lake, les sources, les connexions, les autorisations, l'actualisation et le déploiement. Chargez cette compétence avant d'agir sur un modèle sémantique, sauf si cela fait partie de la publication d'un projet PBIP, dont powerbi-report-management est propriétaire. Pour les questions sur les données en langage naturel, utilisez fabriciq ; pour les visuels, utilisez powerbi-report-authoring.
