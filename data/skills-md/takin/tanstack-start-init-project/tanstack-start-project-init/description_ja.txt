TanStack のブートストラップ Bun、ESLint、Nitro デプロイメント、および CLI アドオン (nitro、table、store、shadcn、form、compiler、drizzle) を使用してアプリを起動します。bunx @tanstack/cli create with --no-examples; を使用します。作成後、プリセット b6Z8GIMhE とテンプレート start を使用して bunx shadcn init を実行し、index.tsx と __root.tsx を除く src/routes の下のすべてのルート モジュールを削除し、インデックス ルートの main をクリアし、__root.tsx からヘッダー/フッターを削除し、ヘッダー、フッター、demo.FormComponent コンポーネントを削除し、demo.FormComponent ファイルを削除します。新しい TanStack Start プロジェクト、このプリセット、または Bun + Nitro + Drizzle + shadcn Start セットアップをスキャフォールディングするときに使用します。
