引导 TanStack 使用 Bunx @tanstack/cli create with --no-examples 启动带有 Bun、ESLint、Nitro 部署和 CLI 附加组件（硝基、表、存储、shadcn、表单、编译器、drizzle）的应用程序；创建后，使用预设的 b6Z8GIMHE 和模板 start 运行 Bunx shadcn init ，然后删除 src/routes 下除 index.tsx 和 __root.tsx 之外的所有路由模块，清除索引路由中的 main，从 __root.tsx 中剥离 Header/Footer，删除 Header、Footer 和 demo.FormComponent 组件，并删除 demo.FormComponent 文件。在搭建新的 TanStack Start 项目时使用此预设，或 Bun + Nitro + Drizzle + shadcn Start 设置。
