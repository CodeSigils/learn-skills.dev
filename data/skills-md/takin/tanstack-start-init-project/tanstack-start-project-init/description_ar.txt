Bootstraps TanStack ابدأ التطبيقات باستخدام إضافات Bun، وESLint، وNitro Publishing، وCLI (nitro، وtable، وstore، وshadcn، وform، وcompiler، وdrizzle) باستخدام Bunx @tanstack/cli الذي يتم إنشاؤه باستخدام --no-examples؛ بعد الإنشاء، يقوم بتشغيل Bunx shadcn init مع الإعداد المسبق b6Z8GIMhE وبدء القالب، ثم يزيل جميع وحدات المسار ضمن src/routes باستثناء Index.tsx و__root.tsx، ويمسح المسار الرئيسي في مسار الفهرس، ويزيل الرأس/التذييل من __root.tsx، ويزيل مكونات الرأس والتذييل وdemo.FormComponent، ويحذف ملف demo.FormComponent. استخدمه عند سقالات مشروع TanStack Start الجديد، أو هذا الإعداد المسبق، أو إعداد Bun + Nitro + Drizzle + shadcn Start.
