Bootstraps TanStack Start apps with Bun, ESLint, Nitro deployment, and CLI add-ons (nitro, table, store, shadcn, form, compiler, drizzle) using bunx @tanstack/cli create with --no-examples; after create, runs bunx shadcn init with preset b6Z8GIMhE and template start, then removes all route modules under src/routes except index.tsx and __root.tsx, clears main in index route, strips Header/Footer from __root.tsx, removes Header, Footer, and demo.FormComponent components, and deletes demo.FormComponent file. Use when scaffolding a new TanStack Start project, this preset, or Bun + Nitro + Drizzle + shadcn Start setup.
