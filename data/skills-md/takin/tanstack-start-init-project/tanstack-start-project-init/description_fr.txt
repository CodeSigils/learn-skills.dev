Bootstraps TanStack Démarrez les applications avec Bun, ESLint, le déploiement Nitro et les modules complémentaires CLI (nitro, table, store, shadcn, form, compiler, drizzle) en utilisant bunx @tanstack/cli create with --no-examples ; après la création, exécute bunx shadcn init avec le préréglage b6Z8GIMhE et le démarrage du modèle, puis supprime tous les modules de route sous src/routes à l'exception de index.tsx et __root.tsx, efface main dans la route d'index, supprime l'en-tête/pied de page de __root.tsx, supprime les composants d'en-tête, de pied de page et demo.FormComponent et supprime le fichier demo.FormComponent. À utiliser lors de l'échafaudage d'un nouveau projet TanStack Start, de ce préréglage ou de la configuration Bun + Nitro + Drizzle + shadcn Start.
