Scrivi strumenti CLI TypeScript pronti per la produzione, script di automazione e processori di file batch con controllo rigoroso del tipo: TypeScript 5.x con modalità rigorosa tsconfig, ESM, analisi degli argomenti type-safe tramite node:util parseArgs (con tipi argv con unione discriminata), registrazione stderr strutturata, sottoclassi di errore tipizzate per modalità di errore distinte, controlli di esaustività tramite "never", node:fs/promises con tipi con marchio ove utile, attesa di alto livello, gestione SIGINT/SIGTERM aggraziata e supporto multipiattaforma (Linux, macOS, Windows). Esegui script tramite tsx (impostazione predefinita), Bun o Deno; costruire per la distribuzione con tsc. Ha come target Node.js 20 LTS e versioni successive più TypeScript 5.4+. Utilizza questa competenza ogni volta che l'utente chiede di creare uno script TypeScript/TS/.ts, uno strumento CLI Node digitato, un'automazione, un processore batch o una pipeline di dati, comprese frasi casuali come "scrivi uno script dattiloscritto che...", "automatizzalo in ts", "creami una CLI digitata" o "Ho bisogno di un processore TS una tantum". Da utilizzare anche durante la revisione o il rafforzamento di uno script TypeScript esistente.
