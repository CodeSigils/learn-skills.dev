編寫生產就緒的 TypeScript CLI 工具、自動化腳本和具有嚴格類型檢查的批次檔處理器 — TypeScript 5.x 具有嚴格模式 tsconfig、ESM、透過節點進行類型安全參數解析：util parseArgs（具有可區分的聯合 argv 類型）、結構化 stderr 日誌記錄、針對不同故障模式以及有用的品牌類型，頂級等待，優雅的 SIGINT/SIGTERM 處理和跨平台支援（Linux、macOS、Windows）。透過 tsx（預設）、Bun 或 Deno 運行腳本；建置用於與 tsc 一起分發。目標為 Node.js 20 LTS 及更高版本以及 TypeScript 5.4+。每當使用者要求建立 TypeScript / TS / .ts 腳本、類型化 Node CLI 工具、自動化、批次處理器或資料管道時，請使用此技能 - 包括諸如“編寫一個 TypeScript 腳本......”、“在 ts 中自動執行此操作”、“讓我成為一個類型化 CLI”或“我需要一個一次性 TS 處理器等隨意的措辭。也可在檢查或強化現有 TypeScript 腳本時使用。
