编写生产就绪的 TypeScript CLI 工具、自动化脚本和具有严格类型检查的批处理文件处理器 — TypeScript 5.x 具有严格模式 tsconfig、ESM、通过节点进行类型安全参数解析：util parseArgs（具有可区分的联合 argv 类型）、结构化 stderr 日志记录、针对不同故障模式的类型化错误子类、通过“never”进行详尽检查、node:fs/promises 以及有用的品牌类型，顶级等待，优雅的 SIGINT/SIGTERM 处理和跨平台支持（Linux、macOS、Windows）。通过 tsx（默认）、Bun 或 Deno 运行脚本；构建用于与 tsc 一起分发。目标为 Node.js 20 LTS 及更高版本以及 TypeScript 5.4+。每当用户要求创建 TypeScript / TS / .ts 脚本、类型化 Node CLI 工具、自动化、批处理器或数据管道时，请使用此技能 - 包括诸如“编写一个 TypeScript 脚本......”、“在 ts 中自动执行此操作”、“让我成为一个类型化 CLI”或“我需要一个一次性 TS 处理器”等随意的措辞。也可在检查或强化现有 TypeScript 脚本时使用。
