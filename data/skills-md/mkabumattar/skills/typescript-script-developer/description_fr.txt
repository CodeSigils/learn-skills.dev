Écrivez des outils CLI TypeScript prêts pour la production, des scripts d'automatisation et des processeurs de fichiers batch avec une vérification de type stricte - TypeScript 5.x avec tsconfig en mode strict, ESM, analyse des arguments de type sécurisé via node:util parseArgs (avec types argv à union discriminée), journalisation stderr structurée, sous-classes d'erreur typées pour des modes de défaillance distincts, vérifications d'exhaustivité via 'jamais', node:fs/promises avec des types de marque lorsque cela est utile, attente de haut niveau, gestion gracieuse de SIGINT/SIGTERM et prise en charge multiplateforme (Linux, macOS, Windows). Exécutez des scripts via tsx (par défaut), Bun ou Deno ; construire pour la distribution avec tsc. Cible Node.js 20 LTS et supérieur ainsi que TypeScript 5.4+. Utilisez cette compétence chaque fois que l'utilisateur demande à créer un script TypeScript / TS / .ts, un outil Node CLI typé, une automatisation, un processeur par lots ou un pipeline de données - y compris des expressions simples telles que « écrire un script dactylographié qui… », « automatiser cela dans ts », « faites-moi une CLI typée » ou « J'ai besoin d'un processeur TS unique ». À utiliser également lors de la révision ou du renforcement d'un script TypeScript existant.
