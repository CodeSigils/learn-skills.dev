Escriba herramientas CLI de TypeScript listas para producción, scripts de automatización y procesadores de archivos por lotes con verificación de tipos estricta: TypeScript 5.x con modo estricto tsconfig, ESM, análisis de argumentos con seguridad de tipos a través de node:util parseArgs (con tipos argv de unión discriminada), registro stderr estructurado, subclases de error escritas para distintos modos de falla, verificaciones exhaustivas a través de 'never', node:fs/promises con tipos de marca cuando sea útil. espera de alto nivel, manejo elegante de SIGINT/SIGTERM y soporte multiplataforma (Linux, macOS, Windows). Ejecute scripts a través de tsx (predeterminado), Bun o Deno; construir para distribución con tsc. Apunta a Node.js 20 LTS y superior más TypeScript 5.4+. Utilice esta habilidad siempre que el usuario solicite crear un script TypeScript/TS/.ts, una herramienta CLI de Nodo mecanografiado, una automatización, un procesador por lotes o una canalización de datos, incluidas frases informales como "escribir un script mecanografiado que...", "automatizar esto en ts", "hacerme un CLI mecanografiado" o "Necesito un procesador TS único". Utilícelo también al revisar o reforzar un script TypeScript existente.
