كتابة أدوات TypeScript CLI الجاهزة للإنتاج، والبرامج النصية للأتمتة، ومعالجات الملفات الدفعية مع فحص صارم للنوع - TypeScript 5.x مع الوضع الصارم tsconfig، وESM، وتحليل الوسيطة الآمنة للنوع عبر العقدة: util parseArgs (مع أنواع argv الاتحاد التمييزية)، وتسجيل stderr المنظم، وفئات الأخطاء المكتوبة لأوضاع فشل متميزة، والتحقق من الشمول عبر "أبدًا"، والعقدة: fs/promises مع الأنواع ذات العلامات التجارية حيث انتظار مفيد وعالي المستوى ومعالجة SIGINT/SIGTERM رائعة ودعم عبر الأنظمة الأساسية (Linux وmacOS وWindows). تشغيل البرامج النصية عبر tsx (افتراضي)، أو Bun، أو Deno؛ بناء للتوزيع مع tsc. يستهدف Node.js 20 LTS وما فوق بالإضافة إلى TypeScript 5.4+. استخدم هذه المهارة عندما يطلب المستخدم إنشاء برنامج نصي TypeScript / TS / .ts، أو أداة Node CLI المكتوبة، أو التشغيل الآلي، أو معالج الدفعات، أو خط أنابيب البيانات - بما في ذلك العبارات غير الرسمية مثل "اكتب برنامج نصي مكتوب على الآلة الكاتبة ..."، أو "أتمتة هذا في ts"، أو "اجعلني CLI مكتوبًا"، أو "أحتاج إلى معالج TS لمرة واحدة". يُستخدم أيضًا عند مراجعة أو تقوية برنامج نصي موجود لـ TypeScript.
