本番環境に対応した TypeScript CLI ツール、自動化スクリプト、厳密な型チェックを備えたバッチ ファイル プロセッサを作成します — 厳密モードの tsconfig、ESM を備えた TypeScript 5.x、node:util parseArgs (識別共用体 argv 型を使用) を介したタイプセーフな引数解析、構造化された stderr ログ、個別の障害モードの型付きエラー サブクラス、「never」による網羅性チェック、ブランド型を使用した node:fs/promises便利なトップレベルの待機、適切な SIGINT/SIGTERM 処理、およびクロスプラットフォームのサポート (Linux、macOS、Windows)。 tsx (デフォルト)、Bun、または Deno 経由でスクリプトを実行します。 tsc を使用して配布用にビルドします。 Node.js 20 LTS 以降と TypeScript 5.4 以降をターゲットとします。ユーザーが TypeScript / TS / .ts スクリプト、型指定された Node CLI ツール、自動化、バッチ プロセッサ、またはデータ パイプラインの作成を要求するときは常にこのスキルを使用します。これには、「... という TypeScript スクリプトを作成する」、「TS でこれを自動化する」、「型指定された CLI にしてください」、または「ワンオフの TS プロセッサが必要です」などのカジュアルな表現が含まれます。既存の TypeScript スクリプトをレビューまたは強化する場合にも使用します。
