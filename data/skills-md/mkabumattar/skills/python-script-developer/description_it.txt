Scrivi strumenti CLI Python pronti per la produzione, script di automazione e processori di file batch con suggerimenti sul tipo, `logging` strutturato (mai `print` per la diagnostica), interfacce `argparse`, `pathlib` per il lavoro del file system, gestione specifica delle eccezioni e supporto multipiattaforma (Linux, macOS, Windows). Usa questa abilità ogni volta che l'utente chiede di creare uno script Python, un'utilità `.py`, uno strumento CLI, un'automazione, un processore batch o una pipeline di dati, comprese frasi casuali come "scrivi uno script Python che...", "automatizzalo in Python", "ho bisogno di un piccolo strumento" o "dammi un processore una tantum". Da utilizzare anche durante la revisione o il rafforzamento di uno script Python esistente.
