Écrivez des outils CLI Python, des scripts d'automatisation et des processeurs de fichiers batch prêts pour la production avec des indications de type, une « journalisation » structurée (jamais « imprimer » pour les diagnostics), des interfaces « argparse », « pathlib » pour le travail du système de fichiers, une gestion des exceptions spécifiques et une prise en charge multiplateforme (Linux, macOS, Windows). Utilisez cette compétence chaque fois que l'utilisateur demande de créer un script Python, un utilitaire « .py », un outil CLI, une automatisation, un processeur par lots ou un pipeline de données — y compris des expressions simples telles que « écrire un script python qui... », « automatiser cela en python », « J'ai besoin d'un petit outil » ou « donnez-moi un processeur unique ». À utiliser également lors de la révision ou du renforcement d'un script Python existant.
