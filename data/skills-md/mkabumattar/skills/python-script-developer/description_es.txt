Escriba herramientas CLI de Python listas para producción, scripts de automatización y procesadores de archivos por lotes con sugerencias de tipo, "registro" estructurado (nunca "imprimir" para diagnóstico), interfaces "argparse", "pathlib" para el trabajo del sistema de archivos, manejo de excepciones específicas y soporte multiplataforma (Linux, macOS, Windows). Utilice esta habilidad siempre que el usuario solicite crear un script de Python, una utilidad `.py`, una herramienta CLI, una automatización, un procesador por lotes o una canalización de datos, incluidas frases informales como "escriba un script de Python que...", "automatice esto en Python", "Necesito una herramienta pequeña" o "dame un procesador único". Utilícelo también al revisar o reforzar un script de Python existente.
