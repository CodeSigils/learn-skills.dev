Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein Python-Skript, ein „.py“-Dienstprogramm, ein CLI-Tool, eine Automatisierung, einen Batch-Prozessor oder eine Datenpipeline erstellen möchte – einschließlich umgangssprachlicher Formulierungen wie „Schreiben Sie ein Python-Skript, das ...“, „Automatisieren Sie dies in Python“, „Ich brauche ein kleines Tool“ oder „Geben Sie mir einen einmaligen Prozessor“. Verwenden Sie es auch, wenn Sie ein vorhandenes Python-Skript überprüfen oder absichern.
