本番環境に対応した Python CLI ツール、自動化スクリプト、タイプ ヒント、構造化された `logging` (診断のための `print` は決して行わない)、`argparse` インターフェイス、ファイル システム作業用の `pathlib`、特定の例外処理、およびクロスプラットフォーム サポート (Linux、macOS、Windows) を備えたバッチ ファイル プロセッサを作成します。ユーザーが Python スクリプト、`.py` ユーティリティ、CLI ツール、自動化、バッチ プロセッサ、またはデータ パイプラインの作成を要求するときは常にこのスキルを使用します。これには、「... という Python スクリプトを作成します」、「これを Python で自動化します」、「小さなツールが必要です」、または「ワンオフのプロセッサをください」などのカジュアルな表現が含まれます。既存の Python スクリプトをレビューまたは強化する場合にも使用します。
