Disegna una modifica di codice come diagramma di architettura o di flusso dati con PR Lens. Crea un documento grafico a partire da un diff, validalo, renderizzalo in SVG e allegalo a una pull request; oppure correggi la mappa del repository in .github/pr-lens.yml. Usalo quando ti viene chiesto di diagrammare, visualizzare o spiegare la forma di una modifica, quando alleghi un diagramma a una pull request che hai aperto, o quando un diagramma PR Lens esistente nomina erroneamente gli elementi.

Rispondi sempre nella lingua dell'utente.
