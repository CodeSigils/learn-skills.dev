Zeichnen Sie eine Codeänderung als Architektur oder Datenflussdiagramm mit PR Lens. Erstellen Sie ein Diagrammdokument aus einem Diff, validieren Sie es, rendern Sie es an SVG und hängen Sie es an eine Pull-Anforderung an; oder korrigieren Sie die Karte eines Repositorys in .github/pr-lens.yml. Verwenden Sie diese Option, wenn Sie aufgefordert werden, die Form einer Änderung zu zeichnen, zu visualisieren oder zu erklären, wenn Sie ein Diagramm an eine von Ihnen geöffnete Pull-Anforderung anhängen oder wenn ein vorhandenes PR-Objektivdiagramm Dinge falsch benennt.
