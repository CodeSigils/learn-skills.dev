Dessinez un changement de code sous forme d'architecture ou de diagramme de flux de données avec PR Lens. Créez un document graphique à partir d'un diff, validez-le, restituez-le au format SVG et joignez-le à une pull request ; ou corrigez la carte d'un référentiel dans .github/pr-lens.yml. À utiliser lorsqu'on vous demande de schématiser, de visualiser ou d'expliquer la forme d'un changement, lorsque vous joignez un diagramme à une demande d'extraction que vous avez ouverte, ou lorsqu'un diagramme PR Lens existant nomme mal les choses.
