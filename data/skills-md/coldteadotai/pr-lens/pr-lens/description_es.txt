Dibuje un cambio de código como una arquitectura o diagrama de flujo de datos con PR Lens. Crear un documento gráfico de un diff, validarlo, procesarlo en SVG y adjuntarlo a una solicitud de extracción; o corregir el mapa de un repositorio en .github/pr-lens.yml. Utilícelo cuando se le solicite diagramar, visualizar o explicar la forma de un cambio, al adjuntar un diagrama a una solicitud de extracción que abrió, o cuando un diagrama de PR Lens existente nombre las cosas incorrectamente.
