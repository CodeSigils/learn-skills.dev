Укрепите письменный план, повторяя его через независимую панель агентов до тех пор, пока он не станет единым. Используйте этот навык всякий раз, когда пользователь хочет, чтобы план неоднократно пересматривался и улучшался — такие фразы, как «зациклить план панели», «переработать этот план с помощью панели», «укрепить этот план», «продолжать использовать панель в моем плане, пока он не станет надежным», «зациклить панель на этом плане», «проверить панелью этот план и исправить его», «пересмотреть и повторить мой план» или любой запрос, подразумевающий более одного прохода проверки с промежуточными изменениями. Он запускает навык планирования панели каждый раунд (свежая панель без общего состояния над планом), затем синтезирует, применяет четкие неоспоримые исправления непосредственно к плану, выдвигает подлинные суждения и открытые вопросы пользователю, обновляет план, регистрирует раунд и повторно запускает панель - циклически до тех пор, пока в раунде не исчезнут новые проблемы, которые необходимо / следует исправить (затем спрашивает пользователя) или не будет достигнут предел раунда. Это аналог повторения PR посредством повторного анализа во время планирования. Для ОДНОГО прохода проверки без изменений используйте вместо этого план панели. НЕ используйте для различий кода/PR (то есть групповой проверки).
