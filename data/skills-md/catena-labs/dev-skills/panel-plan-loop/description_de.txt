Härten Sie einen schriftlichen Plan ab, indem Sie ihn durch ein unabhängiges Agentengremium iterieren, bis er konvergiert. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer möchte, dass ein Plan wiederholt überprüft und verbessert wird – Formulierungen wie „Panel-Planschleife“, „Diesen Plan mit dem Panel wiederholen“, „Diesen Plan festigen“, „Das Panel auf meinem Plan weiter ausführen, bis er stabil ist“, „Das Panel auf diesem Plan wiederholen“, „Diesen Plan vom Panel überprüfen und korrigieren“, „Meinen Plan überprüfen und iterieren“ oder jede Anfrage, die mehr als einen Überprüfungsdurchgang mit dazwischen liegenden Änderungen impliziert. Es führt in jeder Runde den Skill „Panel-Plan“ aus (ein neues Panel ohne gemeinsamen Status über dem Plan), führt dann eine Synthese durch, wendet die klaren, unbestrittenen Korrekturen direkt auf den Plan an, wirft echte Urteilsforderungen und offene Fragen an den Benutzer auf, aktualisiert den Plan, protokolliert die Runde und führt das Panel erneut durch – in einer Schleife, bis in einer Runde keine neuen „Muss/Sollte“-Probleme auftreten (fragt dann der Benutzer) oder eine Rundenobergrenze erreicht wird. Dies ist das planungszeitliche Analogon zur Iteration einer PR durch wiederholte Überprüfung. Für einen EINZIGEN Überprüfungsdurchgang ohne Änderungen verwenden Sie stattdessen „panel-plan“. NICHT für Code-Unterschiede/PRs (d. h. Panel-Review) verwenden.
