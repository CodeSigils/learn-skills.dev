Führen Sie eine autonome Review-Reparatur-Review-Schleife rund um die Fertigkeit „Panel-Review“ durch: Erledigen Sie die Aufgabe, führen Sie eine „Panel-Review“ durch, beurteilen Sie, welche Ergebnisse tatsächlich eine Korrektur wert sind, korrigieren Sie diese, führen Sie dann erneut eine „Panel-Review“ durch – und wiederholen Sie dies, bis nichts mehr zu korrigieren ist, das es wert ist, korrigiert zu werden – und berichten Sie schließlich, was behoben wurde, was absichtlich in Ruhe gelassen wurde (und warum) und alle Abweichungen vom ursprünglichen Ziel. Verwenden Sie diese Option immer dann, wenn der Benutzer nach einer „Panel-Review-Schleife“ / „Panel-Review-Schleife“, einer „Review-Schleife“ fragt, um „Schleife zu machen, bis alles sauber ist“ / „Schleife bis grün“, „Panel-Review durchführen, bis es gut ist“, „mit Panel-Reviews iterieren, bis nichts mehr zu reparieren ist“, eine „Review-and-Fix-Schleife“ oder „Panel-Review durchführen, das Wesentliche korrigieren, dann erneut überprüfen“ – d. h. jede Formulierung, die bei Panel-Reviews *iterieren* bedeutet anstatt einen einzigen auszuführen. Diese Fertigkeit orchestriert die Fertigkeit „Panel-Review“. es ersetzt es nicht. Für eine EINZIGE einmalige Überprüfung ohne Korrektur-/Erneutüberprüfungszyklus verwenden Sie stattdessen direkt „panel-review“.
