Ejecute una única revisión de panel independiente de un plan escrito (un archivo de rebajas de diseño/implementación), antes de escribir cualquier código. Utilice esta habilidad siempre que el usuario solicite "plan de panel" / "plan de panel", "hacer que el panel revise mi plan", "revisar este plan por panel", "obtener segundas opiniones sobre este plan", "obtener la opinión del panel sobre este plan", "desplegar una revisión del plan" o cualquier frase similar que solicite una revisión independiente de múltiples agentes sobre un plan. Distribuye el plan a múltiples agentes de codificación CLI locales (codex, claude, opencode), cada uno en un nuevo subproceso no interactivo sin estado compartido, lee el plan + el repositorio al que apunta como de solo lectura, luego sintetiza sus hallazgos (lagunas, suposiciones erróneas, pasos inviables, riesgos) y abre preguntas en un solo informe. Este es el análogo en tiempo de planificación de la revisión del panel (que revisa el código enviado). Es UNA pasada y NO edita el plan; para que el ciclo iterar-editar-re-revisar converja, use panel-plan-loop. NO lo use para revisar una diferencia de código o PR (es decir, revisión de panel), o cuando el usuario solo quiera que esta sesión critique el plan en sí.
