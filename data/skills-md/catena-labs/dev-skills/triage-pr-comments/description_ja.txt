PR レビューのコメントを分析し、コードと各コメントの懸念事項を深く理解し、修正した場合と修正しなかった場合の影響を評価し、論理的に一連の行動を推奨します。このスキルは、ユーザーが「PR コメントの優先順位付け」、「レビュー コメントの検討」、「レビューへの返信」、「レビュー担当者のフィードバックへの対処」、「どのコメントを修正するかを決定する」、「PR N のレビュー コメントに対処する」、またはプル リクエストのレビュー フィードバックの処理に関する同様の表現を求める場合に使用します。引数が指定されていない場合、デフォルトは現在のブランチの PR になります。 PR 会話のインライン コード コメント、レビュー レベルの概要、ルート レベル (問題) コメントをカバーします。 PR 作成者自身のコメント、解決済み/古いスレッド、作成者がすでに返信したスレッド、ボットのスタイル上のノイズをフィルターで除外します。最初のパス分析のために並列エージェントを生成し、ウォークスルー中に各修正判定を最初から再調査します。
