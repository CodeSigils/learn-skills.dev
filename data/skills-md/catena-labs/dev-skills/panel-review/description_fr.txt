Exécutez une révision de code parallèle sur plusieurs agents de codage CLI locaux (codex, claude, opencode) et synthétisez leurs résultats. Utilisez cette compétence chaque fois que l'utilisateur demande un « examen par comité » / « examen par comité », « un deuxième avis sur ce changement », « examen multi-agents », « examen d'ensemble », demande « à plusieurs agents/LLM d'examiner ceci », « recoupez cela avec le codex/claude/etc », « diffusez une révision de code » ou toute formulation similaire demandant des examens indépendants en dehors de cette conversation. Chaque panéliste s'exécute dans un nouveau sous-processus non interactif sans état partagé - c'est le point. Ne pas utiliser lorsque l'utilisateur souhaite simplement que la session en cours révise le code lui-même ; utilisez l'agent de révision de code habituel pour cela.
