Ejecute una revisión de código paralela en varios agentes de codificación CLI locales (codex, claude, opencode) y sintetice sus hallazgos. Utilice esta habilidad siempre que el usuario solicite una "revisión de panel"/"revisión de panel", "segunda opinión sobre este cambio", "revisión de múltiples agentes", "revisión de conjunto", solicite "que varios agentes/LLM revisen esto", "compruebe esto con codex/claude/etc", "disponga una revisión de código" o cualquier frase similar que solicite revisiones independientes fuera de esta conversación. Cada panelista ejecuta un subproceso nuevo, no interactivo y sin estado compartido: ese es el punto. NO lo use cuando el usuario solo quiera que la sesión actual revise el código; utilice el agente revisor de código habitual para eso.
