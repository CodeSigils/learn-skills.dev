Запустите параллельную проверку кода для нескольких локальных агентов кодирования CLI (codex, claude, opencode) и обобщите полученные результаты. Используйте этот навык всякий раз, когда пользователь запрашивает «групповую проверку» / «групповую проверку», «второе мнение об этом изменении», «многоагентную проверку», «групповую проверку», просит «попросить нескольких агентов/LLM проверить это», «перепроверить это с помощью кодекса/Клода/и т. д.», «развернуть проверку кода» или любую подобную формулировку с просьбой о независимой проверке вне этого разговора. Каждый участник дискуссии работает в новом неинтерактивном подпроцессе без общего состояния — в этом вся суть. НЕ используйте, когда пользователь просто хочет, чтобы текущий сеанс проверил сам код; используйте для этого обычный агент проверки кода.
