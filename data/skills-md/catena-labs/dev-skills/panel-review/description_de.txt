Führen Sie eine parallele Codeüberprüfung für mehrere lokale CLI-Codierungsagenten (Codex, Claude, Opencode) durch und fassen Sie deren Ergebnisse zusammen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer nach einer „Panel-Rezension“/„Panel-Review“, „Zweitmeinung zu dieser Änderung“, „Multi-Agent-Review“, „Ensemble-Review“ fragt, „mehrere Agenten/LLMs dies überprüfen lassen“, „dies mit codex/claude/usw. vergleichen“, „eine Code-Review auffächern“ oder eine ähnliche Formulierung fordert, in der unabhängige Rezensionen von außerhalb dieser Konversation angefordert werden. Jeder Diskussionsteilnehmer läuft in einem neuen, nicht interaktiven Unterprozess ohne gemeinsamen Status – darum geht es. NICHT verwenden, wenn der Benutzer nur möchte, dass die aktuelle Sitzung den Code selbst überprüft; Verwenden Sie dazu den regulären Code-Reviewer-Agenten.
