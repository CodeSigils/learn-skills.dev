Führen Sie ein komplettes DSPy 3.2.x-Projekt End-to-End durch – Spezifikation → Programm → Metrik → Baseline → GEPA-Optimierung → Export → Bereitstellung. Orchestriert die anderen vier DSPy-Fähigkeiten (dspy-fundamentals, dspy-evaluation-harness, dspy-gepa-optimizer, dspy-rlm-module) in der richtigen Reihenfolge. Verwenden Sie dies für alle nicht trivialen DSPy-Builds von Grund auf.
