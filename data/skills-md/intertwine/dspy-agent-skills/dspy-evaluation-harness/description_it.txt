Costruisci strumenti di valutazione DSPy con metriche ricche di feedback essenziali per l'ottimizzazione GEPA. Da utilizzare quando si scrive una funzione metrica, si chiama dspy.Evaluate, si suddividono i set dev/val, si esegue il debug "perché il mio ottimizzatore non migliora?" o si progettano suite di valutazione DSPy predisposte per CI.
