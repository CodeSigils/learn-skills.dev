Оптимизируйте программы DSPy с помощью dspy.GEPA — рефлексивного/эволюционного оптимизатора, который является золотым стандартом для DSPy 2026 года (превосходит MIPROv2 в сложных задачах с гораздо меньшим количеством развертываний, когда метрика дает богатую обратную связь). Используйте, когда пользователь говорит «оптимизировать», «компилировать», «GEPA», «рефлексивную оптимизацию» или «сделать эту программу лучше», и существует программа DSPy + метрика + набор поездов.
