Используйте dspy.RLM (рекурсивная языковая модель) для анализа контекстов, слишком больших, чтобы уместиться в рабочем окне LLM — целых баз кода, длинных журналов, больших документов или многоэтапного исследования данных, для которого требуется изолированный Python REPL. Используйте, когда входные данные составляют > 100 тыс. токенов, требуют рекурсивного разбиения на фрагменты или получают преимущества от написания и запуска кода LLM для проверки данных.
