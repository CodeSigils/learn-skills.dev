Utilisez dspy.RLM (Recursive Language Model) pour raisonner sur des contextes trop grands pour tenir dans la fenêtre de travail d'un LLM : bases de code entières, journaux longs, documents volumineux ou exploration de données en plusieurs étapes nécessitant un REPL Python en bac à sable. À utiliser lorsque l'entrée est supérieure à 100 000 jetons, nécessite un regroupement récursif ou bénéficie de l'écriture et de l'exécution du code LLM pour sonder les données.
