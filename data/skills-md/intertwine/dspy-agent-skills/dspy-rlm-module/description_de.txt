Verwenden Sie dspy.RLM (Recursive Language Model), um über Kontexte nachzudenken, die zu groß sind, um in das Arbeitsfenster eines LLM zu passen – ganze Codebasen, lange Protokolle, umfangreiche Dokumente oder mehrstufige Datenexploration, die eine Sandbox-Python-REPL erfordert. Verwenden Sie diese Option, wenn die Eingabe mehr als 100.000 Token umfasst, rekursives Chunking erforderlich ist oder davon profitiert, dass LLM Code schreibt und ausführt, um Daten zu prüfen.
