Utilice dspy.RLM (modelo de lenguaje recursivo) para razonar sobre contextos demasiado grandes para caber en la ventana de trabajo de un LLM: bases de código completas, registros largos, documentos masivos o exploración de datos de varios pasos que necesita un REPL de Python en espacio aislado. Úselo cuando la entrada sea >100k tokens, necesite fragmentación recursiva o se beneficie de la escritura y ejecución de código LLM para sondear datos.
