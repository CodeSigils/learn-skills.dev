يبني ويدمج DHTMLX JavaScript Gantt الأساسي في تطبيقات JavaScript أو TypeScript. يغطي الإعداد، والتهيئة، ودورة الحياة، gantt.parse/gantt.load، والقوالب، والأحداث، والمكونات الإضافية، ومعالج البيانات، والمهمة/الارتباط CRUD، والمشاريع/المهام الموجزة، والمعالم الرئيسية، والمثيلات المتعددة، والموارد، والتقويمات، والتراجع/الإعادة، وإعادة ترتيب الصفوف، وترتيب الفرز، وخطوط الأساس، والمسار الحرج، والإعدادات المحلية/i18n، والتصميم، والتصميم لـ dhtmlx-gantt (إصدار مجتمع MIT في الإصدار 10+، ومعيار GPL في v9.x)، و@dhx/trial-gantt، و@dhx/gantt (المحترف). ينطبق عند العمل باستخدام مخططات جانت، أو المخططات الزمنية للمشروع، أو تبعيات المهام، أو مهمة CRUD، أو المهام الموجزة، أو المعالم الرئيسية، أو لوحات الموارد، أو تقويمات العمل، أو الصناديق المبسطة، أو طرق عرض عبء العمل، أو الخطوط الأساسية، أو تمييز عطلة نهاية الأسبوع، بغض النظر عما إذا كان "DHTMLX" مذكورًا بالاسم أم لا. يوفر إرشادات واجهة برمجة التطبيقات التي تم التحقق منها بدلاً من تخمين واجهات برمجة تطبيقات جانت الأساسية وحدود إصدار الأسطح قبل السقالات.
