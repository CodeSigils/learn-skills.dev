Costruisce e integra il Gantt JavaScript DHTMLX di base in applicazioni JavaScript o TypeScript. Copre configurazione, inizializzazione, ciclo di vita, gantt.parse/gantt.load, modelli, eventi, plug-in, DataProcessor, CRUD di attività/collegamenti, progetti/attività di riepilogo, traguardi, istanze multiple, risorse, calendari, annulla/ripeti, riordino delle righe, ordinamento, linee di base, percorso critico, locale/i18n, stili e temi per dhtmlx-gantt (edizione della comunità MIT su v10+, GPL Standard su v9.x), @dhx/trial-gantt e @dhx/gantt (Professional). Si applica quando si lavora con diagrammi di Gantt, sequenze temporali del progetto, dipendenze delle attività, attività CRUD, attività di riepilogo, tappe fondamentali, pannelli delle risorse, calendari di lavoro, lightbox, visualizzazioni del carico di lavoro, linee di base o evidenziazione del fine settimana, indipendentemente dal fatto che "DHTMLX" sia menzionato per nome. Fornisce indicazioni API verificate anziché indovinare le API Gantt principali e i limiti dell'edizione delle superfici prima dell'impalcatura.
