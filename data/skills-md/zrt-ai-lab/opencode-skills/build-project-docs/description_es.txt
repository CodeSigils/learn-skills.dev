Cree un sistema de documentación en capas para proyectos compatible con LLM. Proyectos existentes: escanear la estructura del proyecto → clasificación de arquitectura → generar índice maestro CLAUDE.md → documentos del módulo base → API/modelo de datos/documentos de error del módulo de negocios → documentos de configuración → registro de cambios de git (con evaluación de riesgos + guía de reversión) → validación cruzada. Nuevos proyectos: analizar PRD → diseñar arquitectura por especificaciones de andamio → dividir los requisitos en tareas de desarrollo → fusionar estándares de código para generar la guía de desarrollo CLAUDE.md → diseño de API a nivel de módulo + modelo de datos + lista de verificación de desarrollo. Úselo cuando el usuario necesite crear documentos de programación de IA para un proyecto, crear un índice de proyecto, código ordenado, planificar un nuevo proyecto o mencionar llm.txt/CLAUDE.md.
