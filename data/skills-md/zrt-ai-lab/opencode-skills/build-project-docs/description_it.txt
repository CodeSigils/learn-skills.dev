Costruisci un sistema di documentazione a più livelli e compatibile con LLM per i progetti. Progetti esistenti: scansione della struttura del progetto → classificazione dell'architettura → generazione dell'indice master CLAUDE.md → documenti del modulo base → API del modulo aziendale/modello dati/documenti pitfall → documenti di configurazione → registro delle modifiche git (con valutazione del rischio + guida al rollback) → convalida incrociata. Nuovi progetti: analizzare PRD → architettura di progettazione in base alle specifiche dell'impalcatura → suddividere i requisiti in attività di sviluppo → unire gli standard di codice per generare la guida di sviluppo CLAUDE.md → progettazione API a livello di modulo + modello di dati + lista di controllo di sviluppo. Da utilizzare quando l'utente deve creare documenti di programmazione AI per un progetto, creare un indice di progetto, riordinare il codice, pianificare un nuovo progetto o menzionare llm.txt/CLAUDE.md.
