プロジェクト用の階層化された LLM フレンドリーなドキュメント システムを構築します。既存のプロジェクト: プロジェクト構造のスキャン → アーキテクチャ分類 → CLAUDE.md マスター インデックスの生成 → ベース モジュール ドキュメント → ビジネス モジュール API/データ モデル/ピットフォール ドキュメント → 構成ドキュメント → git 変更ログ (リスク評価 + ロールバック ガイド) → 相互検証。新しいプロジェクト: PRD を解析 → スキャフォールディング仕様ごとにアーキテクチャを設計 → 要件を開発タスクに分割 → コード標準をマージして CLAUDE.md 開発ガイドを生成 → モジュールレベルの API 設計 + データ モデル + 開発チェックリスト。ユーザーが AI プログラミング ドキュメントの作成、プロジェクト インデックスの構築、コードの並べ替え、新しいプロジェクトの計画、または llm.txt/CLAUDE.md についての言及が必要な場合に使用します。
