Créez un système de documentation en couches compatible LLM pour le projet.  
Projet existant : analyser la structure du projet → classification de l'architecture → générer l'index principal CLAUDE.md → documents du module de base → documents API/modèle de données/piège du module métier → documents de configuration → journal des modifications git (évaluation des risques + guide de restauration) → validation croisée.  
Nouveau projet : analyser le PRD → concevoir l'architecture par spécification d'échafaudage → diviser les exigences en tâches de développement → fusionner les normes de code pour créer le guide de développement CLAUDE.md → conception d'API au niveau du module + modèle de données + liste de contrôle de développement.  
À utiliser lorsque l'utilisateur a besoin de créer des documents de codage IA pour un projet, de créer un index de projet, de démêler le code, de planifier un nouveau projet ou de mentionner llm.txt/CLAUDE.md.
