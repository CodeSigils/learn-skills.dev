أنشئ نظام توثيق متعدد الطبقات وصديقًا لـ LLM للمشاريع. المشاريع الحالية: مسح هيكل المشروع ← تصنيف البنية ← إنشاء فهرس رئيسي CLAUDE.md ← مستندات الوحدة الأساسية ← واجهة برمجة تطبيقات وحدة الأعمال/نموذج البيانات/مستندات الخلل ← مستندات التكوين ← سجل تغيير git (مع تقييم المخاطر + دليل التراجع) ← التحقق المتبادل. المشاريع الجديدة: تحليل PRD ← بنية التصميم لكل مواصفات السقالة ← تقسيم المتطلبات إلى مهام التطوير ← دمج معايير التعليمات البرمجية لإنشاء دليل تطوير CLAUDE.md ← تصميم واجهة برمجة التطبيقات على مستوى الوحدة النمطية + نموذج البيانات + قائمة مراجعة التطوير. يُستخدم عندما يحتاج المستخدم إلى إنشاء مستندات برمجة الذكاء الاصطناعي لمشروع ما، أو إنشاء فهرس مشروع، أو رمز مرتب، أو التخطيط لمشروع جديد، أو الإشارة إلى llm.txt/CLAUDE.md.
