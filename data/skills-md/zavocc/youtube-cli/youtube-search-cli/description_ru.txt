Используйте локальный автономный двоичный файл CLI поиска YouTube для поиска видео и плейлистов YouTube, составления списка видео из плейлиста или получения метаданных видео через API данных YouTube v3 с выводом JSON. Запускайте задачи обнаружения YouTube и метаданных на основе API, особенно из автоматизации, непрерывной интеграции, автономных систем или облачных сетей, где инструменты очистки, такие как yt-dlp, заблокированы или ненадежны.
