استخدم البرنامج الثنائي المستقل لبحث YouTube CLI المحلي للبحث في مقاطع فيديو وقوائم التشغيل على YouTube، أو إدراج مقاطع فيديو من قائمة تشغيل، أو جلب البيانات الوصفية للفيديو من خلال YouTube Data API v3 مع إخراج JSON. مشغل لاكتشاف YouTube ومهام البيانات الوصفية المستندة إلى واجهة برمجة التطبيقات، خاصة من التشغيل الآلي أو CI أو الأنظمة بدون رأس أو الشبكات السحابية حيث يتم حظر أدوات الاستخراج مثل yt-dlp أو لا يمكن الاعتماد عليها.
