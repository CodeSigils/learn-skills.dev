Utilizza il file binario autonomo della CLI di ricerca di YouTube locale per cercare video e playlist di YouTube, elencare video da una playlist o recuperare metadati video tramite YouTube Data API v3 con output JSON. Attiva attività di rilevamento e metadati di YouTube basate su API, in particolare da automazione, CI, sistemi headless o reti cloud in cui strumenti di scraping come yt-dlp sono bloccati o inaffidabili.
