Cree una o varias confirmaciones convencionales agrupando los archivos modificados en grupos basados ​​en dominios (por ejemplo, código fuente, pruebas, documentos, configuración, infraestructura). Cada grupo obtiene su propia confirmación con un tipo, alcance y mensaje detectados automáticamente. Úselo cuando el usuario solicite confirmar cambios, crear una confirmación de git o mencione "/commit".
