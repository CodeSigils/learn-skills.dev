Créez un ou plusieurs commits conventionnels en regroupant les fichiers modifiés en groupes basés sur le domaine (par exemple, code source, tests, documents, configuration, infrastructure). Chaque groupe obtient son propre commit avec un type, une portée et un message détectés automatiquement. À utiliser lorsque l'utilisateur demande de valider les modifications, crée un commit git ou mentionne "/commit".
