Crea uno o più commit convenzionali raggruppando i file modificati in gruppi basati sul dominio (ad esempio codice sorgente, test, documenti, configurazione, infrastruttura). Ogni gruppo ottiene il proprio commit con tipo, ambito e messaggio rilevati automaticamente. Da utilizzare quando l'utente chiede di confermare modifiche, creare un commit git o menziona "/commit".
