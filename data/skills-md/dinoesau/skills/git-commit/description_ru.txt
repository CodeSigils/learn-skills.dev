Создайте один или несколько обычных коммитов, сгруппировав измененные файлы в группы на основе домена (например, исходный код, тесты, документация, конфигурация, инфраструктура). Каждая группа получает собственную фиксацию с автоматически определенным типом, областью действия и сообщением. Используйте, когда пользователь просит зафиксировать изменения, создать коммит git или упоминает «/commit».
