Erstellen Sie einen oder mehrere herkömmliche Commits, indem Sie geänderte Dateien in domänenbasierten Gruppen gruppieren (z. B. Quellcode, Tests, Dokumente, Konfiguration, Infrastruktur). Jede Gruppe erhält ihr eigenes Commit mit einem automatisch erkannten Typ, Umfang und einer Nachricht. Verwenden Sie diese Option, wenn der Benutzer darum bittet, Änderungen zu übernehmen, einen Git-Commit zu erstellen oder „/commit“ erwähnt.
