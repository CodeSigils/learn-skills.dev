Layers of Trust-Fehlerbehandlungsarchitektur für dieses Repo. Validieren Sie an Kanten mit Result[T,E], analysieren Sie mit Pydantic + Markentypen und behaupten Sie im Kern mit Assert_ok(). Verwenden Sie niemals Bare Assert. Verwenden Sie es, wenn Sie neuen Code schreiben, Code bearbeiten, Fehler beheben oder Fehler-/Validierungsmuster überprüfen. Laden Sie neben dem Coding-Guide für Code-Änderungen.
