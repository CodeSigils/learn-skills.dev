Уровни архитектуры обработки ошибок доверия для этого репозитория. Проверка по краям с помощью Result[T,E], анализ с помощью фирменных типов Pydantic +, утверждение в ядре с помощью Assert_ok(). Никогда не используйте голое утверждение. Используйте при написании нового кода, редактировании кода, исправлении ошибок или просмотре шаблонов ошибок/проверки. Загрузите вместе с руководством по кодированию изменения кода.
