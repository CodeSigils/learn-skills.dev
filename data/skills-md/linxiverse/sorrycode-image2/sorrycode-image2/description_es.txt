Genere o edite y guarde imágenes a través de la API unificada de SorryCode Images. Úselo cuando el usuario solicite generar portadas, carteles, ilustraciones, imágenes de productos, imágenes de artículos, avatares, sprites de juegos o editar/cambiar el estilo de una imagen existente con modelos de imagen SorryCode como gpt-image-2 o modelos de imagen Gemini. La habilidad debe buscar una clave API de SorryCode antes de realizar solicitudes, guiar al usuario para crear o configurar la clave si falta, llamar a /v1/images/generaciones o /v1/images/edits y guardar los resultados en una carpeta local con diagnósticos de avisos y respuestas.
