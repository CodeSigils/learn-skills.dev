統合された SorryCode Images API を通じて画像を生成または編集し、保存します。ユーザーが表紙、ポスター、イラスト、製品ビジュアル、記事画像、アバター、ゲーム スプライトを生成するか、gpt-image-2 や Gemini 画像モデルなどの SorryCode 画像モデルを使用して既存の画像を編集/再スタイルするように要求する場合に使用します。スキルは、リクエストを行う前に SorryCode API キーを確認し、キーがない場合はキーを作成または設定するようにユーザーをガイドし、/v1/images/generations または /v1/images/edits を呼び出し、プロンプトと応答の診断とともに出力をローカル フォルダーに保存する必要があります。
