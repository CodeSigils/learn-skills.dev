قم بإنشاء الصور أو تحريرها وحفظها من خلال واجهة برمجة تطبيقات آسف كود الصور الموحدة. يُستخدم عندما يطلب المستخدم إنشاء أغلفة، أو ملصقات، أو رسوم توضيحية، أو عناصر مرئية للمنتج، أو صور مقالات، أو صور رمزية، أو نقوش متحركة للعبة، أو تحرير/إعادة تصميم صورة موجودة باستخدام نماذج صور آسفي كود، مثل نماذج صور gpt-image-2 أو Gemini. يجب أن تتحقق المهارة من وجود مفتاح آسفي كود API قبل تقديم الطلبات، وتوجيه المستخدم لإنشاء المفتاح أو تعيينه في حالة فقدانه، أو الاتصال بـ /v1/images/generations أو /v1/images/edits، وحفظ المخرجات في مجلد محلي باستخدام تشخيصات سريعة واستجابة.
