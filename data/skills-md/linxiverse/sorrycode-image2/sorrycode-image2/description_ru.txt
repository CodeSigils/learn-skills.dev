Создавайте, редактируйте и сохраняйте изображения с помощью единого API изображений SorryCode. Используйте, когда пользователь просит создать обложки, плакаты, иллюстрации, изображения продуктов, изображения статей, аватары, игровые спрайты или отредактировать/изменить стиль существующего изображения с помощью моделей изображений ИзвинитеКода, таких как модели изображений gpt-image-2 или Gemini. Навык должен проверять наличие ключа API ИзвинитеКода перед отправкой запросов, помогать пользователю создать или установить ключ, если он отсутствует, вызывать /v1/images/generations или /v1/images/edits и сохранять выходные данные в локальную папку с диагностикой запросов и ответов.
