통합 SorryCode 이미지 API를 통해 이미지를 생성하거나 편집하고 저장하세요. 사용자가 표지, 포스터, 일러스트레이션, 제품 시각 자료, 기사 이미지, 아바타, 게임 스프라이트를 생성하거나 gpt-image-2 또는 Gemini 이미지 모델과 같은 SorryCode 이미지 모델을 사용하여 기존 이미지를 편집/스타일 변경하도록 요청할 때 사용합니다. 기술은 요청하기 전에 SorryCode API 키를 확인하고, 누락된 경우 사용자에게 키를 만들거나 설정하도록 안내하고, /v1/images/세대 또는 /v1/images/edits를 호출하고, 프롬프트 및 응답 진단을 통해 출력을 로컬 폴더에 저장해야 합니다.
