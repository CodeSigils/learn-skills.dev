À utiliser lorsque l'utilisateur appelle Pipa et a besoin d'un routage entre les opérations commerciales de services, la configuration/gestion de Pipa ou les outils Pipa. Itinéraires vers les voies commerciales : trouver du travail, définir le travail, exécuter le travail, être payé, fidéliser les clients, améliorer les opérations ; pour gérer Pipa pour la configuration, les outils, les automatisations, la mémoire et les préférences ; ou vers Pipa Tools pour les briefs audio, les réunions, les rappels, le suivi du temps et les utilitaires basés sur Composio.
