يُستخدم عندما يريد المستخدم ملخصًا قابلاً للاستماع للعمل الذي ينتجه وكلاء الذكاء الاصطناعي، أو أدوات الترميز، أو سير عمل المستندات: جلسات الوكيل، أو تغييرات التعليمات البرمجية، أو طلبات السحب، أو الخطط، أو المواصفات، أو تقارير البحث، أو صفحات التوثيق، أو منشورات المدونات، أو عناوين URL، أو الملفات المحلية، أو تخفيض السعر الملصق. استخدمه أيضًا للطلبات غير الرسمية مثل إعطائي الموجز أو الموجز الصوتي أو الإرشادات التفصيلية القابلة للاستماع أو المراجعة الملائمة للهاتف أو صفحة المراجعة الثابتة لفهم عناصر العمل دون قراءة كل شيء سطرًا بسطر. لا تستخدمه لإنشاء تحويل النص إلى كلام (TTS) العام أو إنشاء البودكاست من البداية.
