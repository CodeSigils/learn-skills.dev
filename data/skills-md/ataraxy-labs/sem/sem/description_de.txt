Verwenden Sie sem, um semantische Unterschiede auf Entitätsebene (Funktion/Klasse/Methode), Auswirkungsanalyse, Schuldzuweisungen und Abhängigkeitskontext aus jedem Git-Repository abzurufen. Lösen Sie diese Fähigkeit immer dann aus, wenn der Benutzer fragt, was sich in einem Commit oder PR geändert hat, den Explosionsradius einer Änderung verstehen möchte, wissen möchte, wer zuletzt eine Funktion geändert hat, nachverfolgen möchte, wie sich eine Funktion entwickelt hat, oder einen strukturierten Codekontext für eine LLM-Aufgabe benötigt. Verwenden Sie es auch proaktiv, wenn Sie Code überprüfen, Refaktoren planen oder wenn die Git-Diff-Ausgabe auf Zeilenebene verrauscht oder schwer zu interpretieren wäre.
