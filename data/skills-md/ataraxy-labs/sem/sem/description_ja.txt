sem を使用して、エンティティ レベル (関数/クラス/メソッド) のセマンティック差分、影響分析、責任、および依存関係コンテキストを Git リポジトリから取得します。ユーザーがコミットまたは PR で何が変更されたかを尋ねる場合、変更の影響範囲を理解する必要がある場合、関数を最後に変更した人を知る必要がある場合、関数がどのように進化したかを追跡したい場合、または LLM タスクの構造化されたコード コンテキストが必要な場合は、必ずこのスキルをトリガーします。また、コードのレビュー、リファクタリングの計画、またはタイムラインレベルの git diff 出力にノイズが多かったり解釈が困難な場合にも、積極的に使用してください。
