Carica immagini, video e file statici locali su Zhihu media cloud (知乎媒体云) e restituisce una media_key utilizzata nelle API di pubblicazione di contenuti. Inoltre viene scaricato da un URL pubblico e caricato direttamente. Utilizzare quando l'utente desidera caricare un'immagine, un'immagine, una foto, un video, un clip audio, un documento o qualsiasi file allegato; quando un post, un articolo o un contenuto 知乎 necessita di un'immagine o di un video incorporato; quando l'utente fornisce un URL a un'immagine/video/file online che deve essere caricato; quando qualsiasi operazione a valle richiede una media_key da Zhihu; o quando l'utente chiede informazioni sulla versione di zhihu-mediacloud-uploader, sulla disponibilità degli aggiornamenti, sulla verifica degli aggiornamenti o sull'aggiornamento della competenza. Attiva anche quando l'utente dice上传图foto、上传视频、上传文件、图foto上传、视频上传、文件上传、知乎媒体上传、URL上传、链接上传、检查更新、检查版本、更新zhihu-mediacloud-uploader、升级 abilità di uploader.
