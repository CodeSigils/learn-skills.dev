Carga archivos locales de imágenes, videos y estáticos a la nube multimedia de Zhihu (知乎媒体云) y devuelve una media_key utilizada en las API de publicación de contenido. También descarga desde una URL pública y carga directamente. Úselo cuando el usuario desee cargar una imagen, fotografía, video, clip de audio, documento o cualquier archivo adjunto; cuando una publicación, artículo o contenido necesita una imagen o vídeo incrustado; cuando el usuario proporciona una URL a una imagen/vídeo/archivo en línea que debe cargarse; cuando cualquier operación posterior requiere una media_key de Zhihu; o cuando el usuario pregunta sobre la versión de zhihu-mediacloud-uploader, la disponibilidad de actualizaciones, la búsqueda de actualizaciones o la actualización de la habilidad. También se activa cuando el usuario dice上传图片、上传视频、上传文件、图片上传、视频上传、文件上传、知乎媒体上传、URL上传、链接上传、检查更新、检查版本、更新zhihu-mediacloud-uploader、升级 habilidad de carga.
