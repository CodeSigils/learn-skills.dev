Genere una imagen a partir de un mensaje de texto, eligiendo entre dos backends locales sin cabeza: GPT (Codex CLI imagegen, se ejecuta con su inicio de sesión de ChatGPT) o Gemini (Antigravity agy CLI, se ejecuta con su inicio de sesión de Google). Ambos no tienen clave API y no generan facturación API por imagen. Úselo siempre que el usuario quiera crear, generar, dibujar, hacer o renderizar una imagen, ilustración, ícono, miniatura, logotipo, póster, obra de arte o fondo a partir de una descripción; por ejemplo, "generar una imagen de una montaña al atardecer", "hacerme un ícono de servidor de vector plano" o "dibujar un gato en acuarela". La característica definitoria es la elección del modelo. Si el usuario nombra un backend (GPT, OpenAI, codex OR Gemini, Google, agy, antigravity, nano banana), utilícelo directamente. Si NO nombran uno, PREGUNTE cuál usar antes de generar. Se activa incluso cuando el usuario no dice GPT, Gemini o codex: cualquier solicitud de generación de imágenes de formato libre que no apunte a una herramienta diferente (Midjourney, Stable Diffusion, DALL-E API, OpenAI Images API) pertenece aquí. NO lo use para editar un archivo de imagen existente, eliminar fondos o gráficos renderizados en HTML/CSS puro.
