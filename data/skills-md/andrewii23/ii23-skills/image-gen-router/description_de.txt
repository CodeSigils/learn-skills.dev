Generieren Sie ein Bild aus einer Texteingabeaufforderung und wählen Sie zwischen zwei lokalen Headless-Backends – GPT (Codex CLI imagegen, läuft unter Ihrem ChatGPT-Login) oder Gemini (Antigravity agy CLI, läuft unter Ihrem Google-Login). Beide sind ohne API-Schlüssel und es fällt keine API-Abrechnung pro Bild an. Verwenden Sie dies immer dann, wenn der Benutzer ein Bild, eine Illustration, ein Symbol, eine Miniaturansicht, ein Logo, ein Poster, eine Grafik oder einen Hintergrund aus einer Beschreibung erstellen, generieren, zeichnen, erstellen oder rendern möchte – zum Beispiel „Erzeuge ein Bild eines Berges bei Sonnenuntergang“, „Mach mir ein flaches Vektor-Server-Symbol“ oder „Zeichne eine Katze in Aquarell“. Das entscheidende Merkmal ist die Modellwahl. Wenn der Benutzer ein Backend benennt (GPT, OpenAI, Codex OR Gemini, Google, Agy, Antigravity, Nano Banana), verwenden Sie es direkt. Wenn sie KEINEN Namen nennen, fragen Sie vor der Generierung nach, welcher verwendet werden soll. Wird auch dann ausgelöst, wenn der Benutzer nicht GPT, Gemini oder Codex sagt – hierher gehört jede Freiform-Bildgenerierungsanfrage, die nicht bereits auf ein anderes Tool (Midjourney, Stable Diffusion, DALL-E API, OpenAI Images API) verweist. NICHT zum Bearbeiten einer vorhandenen Bilddatei, zum Entfernen von Hintergründen oder für reine HTML/CSS-gerenderte Grafiken verwenden.
