Genera un'immagine da un messaggio di testo, scegliendo tra due backend headless locali: GPT (Codex CLI imagegen, viene eseguito con il tuo login ChatGPT) o Gemini (Antigravity agy CLI, funziona con il tuo login Google). Entrambi sono privi di chiave API e non comportano alcuna fatturazione API per immagine. Utilizzalo ogni volta che l'utente desidera creare, generare, disegnare, realizzare o eseguire il rendering di un'immagine, illustrazione, icona, miniatura, logo, poster, grafica o sfondo da una descrizione, ad esempio "genera un'immagine di una montagna al tramonto", "creami un'icona del server a vettore piatto" o "disegna un gatto con l'acquerello". La caratteristica distintiva è la scelta del modello. Se l'utente nomina un backend (GPT, OpenAI, codex OR Gemini, Google, agy, antigravity, nano banana), usalo direttamente. Se NON ne nominano uno, CHIEDERE quale utilizzare prima di generare. Si attiva anche quando l'utente non dice GPT, Gemini o codex: qualsiasi richiesta di generazione di immagini in formato libero che non punti già a uno strumento diverso (Midjourney, Stable Diffusion, API DALL-E, API OpenAI Images) appartiene qui. NON utilizzare per modificare un file immagine esistente, rimuovere sfondi o grafica con rendering HTML/CSS puro.
