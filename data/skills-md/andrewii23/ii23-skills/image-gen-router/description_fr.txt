Générez une image à partir d'une invite de texte, en choisissant entre deux backends locaux sans tête - GPT (Codex CLI imagegen, s'exécute sous votre connexion ChatGPT) ou Gemini (Antigravity agy CLI, s'exécute sous votre connexion Google). Les deux sont sans clé API et n’entraînent aucune facturation API par image. Utilisez-le chaque fois que l'utilisateur souhaite créer, générer, dessiner, créer ou restituer une image, une illustration, une icône, une vignette, un logo, une affiche, une illustration ou un arrière-plan à partir d'une description - par exemple "générer une image d'une montagne au coucher du soleil", "faire de moi une icône de serveur à vecteur plat" ou "dessiner un chat à l'aquarelle". La caractéristique déterminante est le choix du modèle. Si l'utilisateur nomme un backend (GPT, OpenAI, codex OU Gemini, Google, agy, antigravity, nano banane), utilisez-le directement. S'ils n'en nomment PAS, DEMANDEZ lequel utiliser avant de générer. Déclenchez même lorsque l'utilisateur ne dit pas GPT, Gemini ou codex - toute demande de génération d'image de forme libre qui ne pointe pas déjà vers un autre outil (Midjourney, Stable Diffusion, API DALL-E, API OpenAI Images) appartient ici. Ne PAS utiliser pour modifier un fichier image existant, supprimer des arrière-plans ou des graphiques purs rendus HTML/CSS.
