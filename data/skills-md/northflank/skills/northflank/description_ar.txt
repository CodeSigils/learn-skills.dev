نشر البنية التحتية وإدارتها وأتمتتها على Northflank - وهي منصة مطورة لبناء ونشر وتوسيع نطاق الخدمات والوظائف وقواعد البيانات وإصدار سير العمل على Kubernetes. يُستخدم عند إدارة مشاريع Northflank، أو الخدمات، أو الوظائف، أو الوظائف الإضافية (قواعد البيانات)، أو الأسرار، أو المجالات، أو القوالب (IaC)، أو البيئات، أو بيئات المعاينة، أو خطوط الأنابيب، أو تدفقات الإصدار، أو مجموعات BYOC/BYOK، أو أعباء عمل GPU، أو صناديق حماية AI، أو التفاعل مع عميل Northflank API/CLI/JS. يغطي REST API وCLI (`أمر northflank`) وعميل JavaScript (`@northflank/js-client`).
