Assistente allo sviluppo di database vettoriali Zvec. Utilizzare questa competenza quando gli utenti devono sviluppare applicazioni di ricerca vettoriale basate su zvec,
costruire sistemi RAG, implementare la ricerca semantica o gestire l'archiviazione e l'interrogazione dei dati vettoriali.
Adatto per ambienti di sviluppo Python e Node.js, fornisce una guida tecnica completa dai concetti di base all'utilizzo avanzato.
Utilizzare in modo proattivo questa capacità quando gli utenti menzionano database vettoriali, ricerca di similarità, archiviazione di incorporamento, indici HNSW/IVF,
ricerca ibrida, query multi-vettore o utilizzo dell'API zvec.
