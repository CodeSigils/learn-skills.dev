Assistant de développement de bases de données vectorielles Zvec. Utilisez cette compétence lorsque les utilisateurs ont besoin de développer des applications de recherche vectorielle basées sur zvec,
créez des systèmes RAG, implémentez une recherche sémantique ou gérez le stockage et les requêtes de données vectorielles.
Convient aux environnements de développement Python et Node.js, fournissant des conseils techniques complets depuis les concepts de base jusqu'à l'utilisation avancée.
Utilisez cette compétence de manière proactive lorsque les utilisateurs mentionnent des bases de données vectorielles, une recherche de similarité, un stockage intégré, des index HNSW/IVF,
recherche hybride, requêtes multivecteurs ou utilisation de l'API zvec.
