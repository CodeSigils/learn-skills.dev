أجب عن الأسئلة المتعلقة بالبيانات المكانية باستخدام DuckDB. يُستخدم عندما يذكر المستخدم المواقع، أو الإحداثيات، أو خطوط الطول/ العرض، أو المسافات، أو الخرائط، أو العناوين، أو "القريب"، أو "الداخل"، أو "الأقرب"، أو الأسماء الجغرافية، أو تنسيقات الملفات المكانية (GeoJSON، أو Shapefile، أو GeoPackage، أو GPX، أو GeoParquet). يتم تشغيله أيضًا عندما يريد المستخدم العثور على أماكن أو مباني أو طرق - توفر Overture Maps بيانات عالمية مجانية على S3 بدون مفاتيح API. يتعامل مع الروابط المكانية وحسابات المسافة وفحوصات الاحتواء وتحليل الكثافة وتحويلات التنسيق للبيانات الجغرافية.
