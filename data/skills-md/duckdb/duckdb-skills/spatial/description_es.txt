Responda preguntas sobre datos espaciales usando DuckDB. Se utiliza cuando el usuario menciona ubicaciones, coordenadas, latitud/longitud, distancias, mapas, direcciones, "cerca", "dentro", "más cercano", nombres geográficos o formatos de archivos espaciales (GeoJSON, Shapefile, GeoPackage, GPX, GeoParquet). También se activa cuando el usuario quiere encontrar lugares, edificios o carreteras: Overture Maps proporciona datos globales gratuitos en S3 sin claves API. Maneja uniones espaciales, cálculos de distancia, comprobaciones de contención, análisis de densidad y conversiones de formato para datos geográficos.
