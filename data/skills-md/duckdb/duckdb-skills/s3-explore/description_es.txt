Explore y consulte datos en S3, Cloudflare R2, GCS, MinIO o cualquier almacenamiento compatible con S3. Úselo cuando el usuario mencione una URL s3://, r2://, gs:// o gcs://, pregunte "qué hay en este depósito", quiera enumerar archivos remotos, obtener una vista previa de Parquet/CSV/JSON remoto o consultar datos sobre el almacenamiento de objetos sin descargarlos. También se activa cuando el usuario desea conocer el tamaño, el esquema o el número de filas de conjuntos de datos remotos.
