Esplora ed esegui query sui dati su S3, Cloudflare R2, GCS, MinIO o qualsiasi spazio di archiviazione compatibile con S3. Da utilizzare quando l'utente menziona un URL s3://, r2://, gs:// o gcs://, chiede "cosa c'è in questo bucket", desidera elencare file remoti, visualizzare in anteprima Parquet/CSV/JSON remoto o eseguire query sui dati sull'archiviazione di oggetti senza scaricarli. Si attiva anche quando l'utente desidera conoscere la dimensione, lo schema o il conteggio delle righe dei set di dati remoti.
