Erkunden und fragen Sie Daten auf S3, Cloudflare R2, GCS, MinIO oder jedem S3-kompatiblen Speicher ab. Verwenden Sie diese Option, wenn der Benutzer eine s3://-, r2://-, gs://- oder gcs://-URL erwähnt, fragt „Was ist in diesem Bucket“, Remote-Dateien auflisten, Remote-Parquet/CSV/JSON in der Vorschau anzeigen oder Daten im Objektspeicher abfragen möchte, ohne sie herunterzuladen. Wird auch ausgelöst, wenn der Benutzer die Größe, das Schema oder die Zeilenanzahl von Remote-Datasets wissen möchte.
