Explorez et interrogez des données sur S3, Cloudflare R2, GCS, MinIO ou tout autre stockage compatible S3. À utiliser lorsque l'utilisateur mentionne une URL s3://, r2://, gs:// ou gcs://, demande « ce qu'il y a dans ce compartiment », souhaite répertorier les fichiers distants, prévisualiser le Parquet/CSV/JSON distant ou interroger des données sur le stockage d'objets sans les télécharger. Se déclenche également lorsque l'utilisateur souhaite connaître la taille, le schéma ou le nombre de lignes des ensembles de données distants.
