استكشف البيانات واستفسر عنها على S3 أو Cloudflare R2 أو GCS أو MinIO أو أي وحدة تخزين متوافقة مع S3. يُستخدم عندما يذكر المستخدم عنوان URL s3://، أو r2://، أو gs://، أو gcs://، أو يسأل "ماذا يوجد في هذه المجموعة"، أو يريد إدراج الملفات البعيدة، أو معاينة Parquet/CSV/JSON عن بعد، أو الاستعلام عن البيانات الموجودة على وحدة تخزين الكائنات دون تنزيلها. يتم تشغيله أيضًا عندما يريد المستخدم معرفة الحجم أو المخطط أو عدد الصفوف لمجموعات البيانات البعيدة.
