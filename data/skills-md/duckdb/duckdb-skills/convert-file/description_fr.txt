Convertissez n'importe quel fichier de données dans un autre format : CSV, Parquet, JSON, Excel, GeoJSON, et plus encore. À utiliser lorsque l'utilisateur dit « convertir en parquet », « enregistrer au format xlsx », « exporter au format JSON », « en faire un CSV », « transformer en parquet » ou toute variante de conversion de format à format pour les fichiers de données. Se déclenche également lorsque l'utilisateur souhaite écrire Parquet, Excel ou d'autres formats binaires que Claude ne peut pas produire nativement.
