Produce, revisa y mejora artefactos HTML independientes de un solo archivo utilizando HTML básico, CSS en línea y JS básico, sin marcos ni CDN. Utilice esta habilidad cuando el usuario solicite "crear una matriz de comparación", "crear un panel interactivo", "crear una hoja de ruta de línea de tiempo", "generar un artefacto HTML", "revisar este HTML", "crear una superficie de revisión", "crear una explicación visual" o "crear una lista de verificación interactiva". No lo utilice para documentación simple, artículos de base de conocimientos, actas de reuniones o cualquier contenido donde Markdown sea suficiente.
