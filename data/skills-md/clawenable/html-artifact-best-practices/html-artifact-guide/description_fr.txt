Produit, révise et améliore des artefacts HTML autonomes à fichier unique à l'aide de HTML Vanilla, de CSS en ligne et de Vanilla JS - sans framework ni CDN. Utilisez cette compétence lorsque l'utilisateur demande de « créer une matrice de comparaison », « créer un tableau de bord interactif », « créer une feuille de route chronologique », « générer un artefact HTML », « réviser ce code HTML », « créer une surface de révision », « créer une explication visuelle » ou « créer une liste de contrôle interactive ». Ne pas utiliser pour une simple documentation, des articles de la base de connaissances, des procès-verbaux de réunions ou tout autre contenu pour lequel Markdown suffit.
