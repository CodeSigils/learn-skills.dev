Создает, проверяет и улучшает отдельные однофайловые HTML-артефакты с использованием стандартного HTML, встроенного CSS и стандартного JS — без фреймворков или CDN. Используйте этот навык, когда пользователь просит «создать матрицу сравнения», «построить интерактивную информационную панель», «составить временную шкалу», «создать HTML-артефакт», «просмотреть этот HTML», «создать поверхность обзора», «создать визуальное пояснение» или «создать интерактивный контрольный список». Не используйте для простой документации, статей базы знаний, протоколов собраний или любого контента, для которого достаточно Markdown.
