Produce, rivede e migliora gli artefatti HTML a file singolo autonomi utilizzando HTML Vanilla, CSS inline e JS Vanilla, senza framework o CDN. Utilizza questa abilità quando l'utente chiede di "creare una matrice di confronto", "costruire una dashboard interattiva", "creare una roadmap della sequenza temporale", "generare un artefatto HTML", "rivedere questo codice HTML", "creare una superficie di revisione", "creare una spiegazione visiva" o "creare una lista di controllo interattiva". Non utilizzare per documentazione semplice, articoli della knowledge base, verbali di riunioni o qualsiasi contenuto per cui sia sufficiente Markdown.
