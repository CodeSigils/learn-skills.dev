Vérifiez le rapport Amazon Payments pour détecter les erreurs de frais. Détecte les frais de traitement Expédié par Amazon incorrects (niveau de taille incorrect), les crédits de frais de référence manquants sur les remboursements, les frais en double et les écarts de stockage Expédié par Amazon, et produit un dossier d'écart de frais Expédié par Amazon par résultat. À utiliser lorsqu'un utilisateur pose des questions sur les erreurs de frais Amazon, les frais surfacturés, le niveau de taille incorrect, les remboursements de référence manquants, l'audit des frais ou l'analyse du rapport de paiement. Phrases déclencheurs : « audit des frais », « surfacturé », « frais erronés », « erreur de niveau de taille », « remboursement des frais de référence », « rapport de paiement », « litige concernant les frais Expédié par Amazon ». Fonctionne avec zéro outil. l'utilisateur colle les lignes du rapport Paiements.
