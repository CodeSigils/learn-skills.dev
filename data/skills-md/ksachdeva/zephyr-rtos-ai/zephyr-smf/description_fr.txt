Conseils d'experts sur Zephyr State Machine Framework (SMF) pour la mise en œuvre de machines à états plates et hiérarchiques. À utiliser lorsque l'utilisateur pose des questions sur les machines à états, les transitions d'état, les actions d'entrée/exécution/sortie, les états hiérarchiques (HSM), les machines à états pilotées par événements, SMF_CREATE_STATE, smf_set_state, smf_run_state ou l'implémentation de diagrammes d'état UML dans Zephyr RTOS.
