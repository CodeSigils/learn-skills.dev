Guida esperta sulla gestione dei thread, sulla pianificazione e sulle code di lavoro di Zephyr RTOS. Da utilizzare durante l'implementazione dei thread (k_thread_create, K_THREAD_DEFINE), la scelta delle priorità dei thread (cooperativo o preventivo), la configurazione del comportamento di pianificazione (divisione del tempo, resa), la gestione del ciclo di vita del thread (avvio, sospensione, ripresa, interruzione, unione) o l'utilizzo delle code di lavoro per l'elaborazione posticipata. I trigger includono domande sugli stack di thread, sull'elusione dell'inversione di priorità, sui thread di sistema (principale, inattivo) e sui modelli di sincronizzazione da thread a thread.
