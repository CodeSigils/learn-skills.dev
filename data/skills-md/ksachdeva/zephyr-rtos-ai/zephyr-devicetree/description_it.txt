Competenza completa di Zephyr Devicetree che include sovrapposizioni, collegamenti, macro API C, controllo dei pin, orologi, interruzioni, DMA e traduzione degli indirizzi. Utilizza questa competenza quando è necessario: (1) comprendere o creare file .dts/.dtsi/.overlay, (2) scrivere o eseguire il debug di collegamenti DeviceTree (.yaml), (3) utilizzare macro DT_* nel codice C/C++, (4) configurare controllo pin, orologi, interrupt o DMA in DeviceTree, (5) risolvere errori di compilazione relativi a DeviceTree, (6) comprendere la traduzione degli indirizzi e le regioni di memoria.
