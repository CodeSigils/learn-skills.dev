Strenge, priorisierte Codeüberprüfung eines Diffs, einer PR oder einer Datei – zuerst Fehlerkorrektur, dann Sicherheit (OWASP/CWE), Leistung, API-Design, Tests und Wartbarkeit. Gibt nach Schweregrad bewertete Ergebnisse mit spezifischen Korrekturen aus, keine Nitpicks. Verwenden Sie diese Option, um eine Pull-Anfrage zu überprüfen, eine Änderung zu prüfen oder eine Prüfung vor dem Zusammenführen durchzuführen.
