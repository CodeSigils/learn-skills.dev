Examen rigoureux et hiérarchisé du code d'un diff, d'un PR ou d'un fichier : correction des bogues d'abord, puis sécurité (OWASP/CWE), performances, conception de l'API, tests et maintenabilité. Produit des résultats classés en termes de gravité avec des correctifs spécifiques, et non des pinailles. À utiliser pour examiner une pull request, auditer une modification ou vérifier avant la fusion.
