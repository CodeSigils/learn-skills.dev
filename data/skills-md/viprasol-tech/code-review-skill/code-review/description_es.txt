Revisión rigurosa y priorizada del código de una diferencia, un PR o un archivo: primero los errores de corrección, luego la seguridad (OWASP/CWE), el rendimiento, el diseño de API, las pruebas y la mantenibilidad. Genera hallazgos clasificados según su gravedad con correcciones específicas, no minucias. Úselo para revisar una solicitud de extracción, auditar un cambio o realizar una verificación previa a la fusión.
