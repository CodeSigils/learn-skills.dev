مراجعة صارمة ومحددة الأولوية للتعليمات البرمجية للفرق أو العلاقات العامة أو الملف - أخطاء الصحة أولاً، ثم الأمان (OWASP/CWE)، والأداء، وتصميم واجهة برمجة التطبيقات (API)، والاختبارات، وقابلية الصيانة. يُخرج نتائج مصنفة حسب الخطورة مع إصلاحات محددة، وليس الأخطاء. يُستخدم لمراجعة طلب السحب، أو تدقيق التغيير، أو فحص الدمج المسبق.
