Тщательная, приоритетная проверка кода различий, PR или файлов — сначала исправление ошибок, затем безопасность (OWASP/CWE), производительность, дизайн API, тесты и удобство обслуживания. Выводит результаты с оценкой серьезности и конкретными исправлениями, а не придирками. Используйте для просмотра запроса на включение, аудита изменений или проверки перед слиянием.
