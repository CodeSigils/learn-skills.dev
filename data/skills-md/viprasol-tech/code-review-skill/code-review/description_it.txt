Revisione rigorosa e prioritaria del codice di un diff, PR o file: prima i bug di correttezza, poi la sicurezza (OWASP/CWE), le prestazioni, la progettazione dell'API, i test e la manutenibilità. Fornisce risultati classificati in base alla gravità con correzioni specifiche, non pignoli. Da utilizzare per rivedere una richiesta pull, controllare una modifica o un controllo pre-unione.
