Moteur de survie DeFi autonome pour les agents IA sur Solana. À utiliser lorsque : l'agent doit gagner de l'argent pour rester en vie, gérer les crédits de calcul, les niveaux de survie, la liquidation d'urgence, l'allocation de capital, la sélection de stratégie, la boucle d'agent autonome. PAS pour : le trading manuel par des humains, les transactions ponctuelles, la spéculation amusante.
