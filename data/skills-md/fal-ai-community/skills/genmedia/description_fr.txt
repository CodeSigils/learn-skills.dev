Utilisez la CLI genmedia pour rechercher, inspecter, exécuter et gérer plus de 1 200 points de terminaison du modèle fal.ai. Déclenchez lorsque l'utilisateur mentionne « genmedia », « fal CLI » ou demande de « rechercher des modèles », « exécuter un modèle », « récupérer un schéma », « vérifier les prix », « télécharger vers fal », « mettre en file d'attente le travail asynchrone », « suivre la demande » ou toute interaction directe avec le catalogue de points de terminaison fal.ai. C’est la compétence fondamentale. Toutes les autres compétences liées à fal.ai dans ce dépôt exécutent leur travail via des commandes genmedia. Utilisez `--json` chaque fois que la sortie sera analysée par un agent.
