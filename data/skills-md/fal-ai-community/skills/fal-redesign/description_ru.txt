Обновите закодированный веб-сайт до престижного редакционного дизайна с помощью fal.ai. Берет локальный HTML-файл или URL-адрес dev-сервера, делает снимок экрана, использует модель видения opus-4.7, пишет приглашение на редактирование gpt-image-2, использует fal-ai/gpt-image-2/edit для создания переработанного эталонного изображения, затем opus-4.7 Vision записывает спецификацию сборки Markdown с разделом «Жесткие ограничения» + tokens.json. Также поддерживает итерацию (снимок экрана → дельта-спецификация или ссылка) и генерацию с нуля (краткое описание → макет → однофайловый HTML). Вызывайте, когда пользователь говорит «улучшите дизайн», «сделайте его мирового класса», «измените дизайн этой целевой страницы», «обновите этот сайт», «проход на дизайн» или указывает на локальный сервер HTML/разработчика для визуального обзора.
