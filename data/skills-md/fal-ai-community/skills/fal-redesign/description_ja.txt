fal.ai を使用して、コード化された Web サイトを受賞レベルの編集者が作成したデザインにアップグレードします。ローカル HTML ファイルまたは開発サーバー URL を取得してスクリーンショットを撮り、opus-4.7 ビジョン モデルに gpt-image-2 編集プロンプトを書き込ませ、fal-ai/gpt-image-2/edit を使用して再設計された参照イメージを生成します。その後、opus-4.7 ビジョンが「ハード制約」セクション + tokens.json を含む Markdown ビルドスペックを書き込みます。また、反復 (スクリーンショット実装サイト → デルタ仕様 vs リファレンス) およびグリーンフィールド生成 (ブリーフ → モックアップ → 単一ファイル HTML) もサポートします。ユーザーが「デザインを改善する」、「世界クラスにする」、「このランディング ページを再デザインする」、「このサイトをアップグレードする」、「デザイン パス」と言った場合、または視覚的なレビューのためにローカル HTML / 開発サーバーを指定した場合に呼び出します。
