Aggiorna un sito Web codificato a un design editoriale di livello superiore utilizzando fal.ai. Prende un file HTML locale o un URL del server di sviluppo, ne esegue lo screenshot, ha un modello di visione opus-4.7, scrive un prompt di modifica gpt-image-2, utilizza fal-ai/gpt-image-2/edit per produrre l'immagine di riferimento riprogettata, quindi la visione opus-4.7 scrive una specifica di build Markdown con una sezione "Vincoli rigidi" + un tokens.json. Supporta anche l'iterazione (screenshot del sito implementato → delta-spec vs riferimento) e la generazione greenfield (breve → mockup → HTML a file singolo). Richiama quando l'utente dice "migliora il design", "rendilo di livello mondiale", "ridisegna questa pagina di destinazione", "aggiorna questo sito", "pass di progettazione" o punta a un server HTML/dev locale per una revisione visiva.
