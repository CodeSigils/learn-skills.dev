Mettez à niveau un site Web codé vers une conception éditoriale de niveau primé à l'aide de fal.ai. Prend un fichier HTML local ou une URL de serveur de développement, le capture d'écran, dispose d'un modèle de vision opus-4.7, écrit une invite de modification gpt-image-2, utilise fal-ai/gpt-image-2/edit pour produire l'image de référence repensée, puis la vision opus-4.7 écrit une spécification de construction Markdown avec une section "Contraintes strictes" + un token.json. Prend également en charge l'itération (capture d'écran du site implémenté → delta-spec vs référence) et la génération de nouveaux champs (bref → maquette → HTML à fichier unique). Invoquer lorsque l'utilisateur dit « améliorer la conception », « le rendre de classe mondiale », « repenser cette page de destination », « mettre à niveau ce site », « passer la conception » ou pointe vers un serveur HTML/dev local pour un examen visuel.
