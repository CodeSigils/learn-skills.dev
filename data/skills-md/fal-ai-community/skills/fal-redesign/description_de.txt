Werten Sie eine codierte Website mit fal.ai auf ein preisgekröntes, redaktionell gestaltetes Design auf. Nimmt eine lokale HTML-Datei oder eine Entwicklungsserver-URL, erstellt einen Screenshot davon, lässt ein Opus-4.7-Vision-Modell eine gpt-image-2-Bearbeitungsaufforderung schreiben, verwendet fal-ai/gpt-image-2/edit, um das neu gestaltete Referenzbild zu erstellen, und schreibt dann eine Markdown-Build-Spezifikation mit einem Abschnitt „Harte Einschränkungen“ + einer tokens.json. Unterstützt auch Iterate (Screenshot der implementierten Site → Delta-Spec vs. Referenz) und Greenfield-Generierung (Brief → Mockup → Single-File-HTML). Wird aufgerufen, wenn der Benutzer „Design verbessern“, „Weltklasse machen“, „Diese Zielseite neu gestalten“, „Diese Website aktualisieren“, „Design bestanden“ sagt oder auf einen lokalen HTML-/Entwicklungsserver verweist, um eine visuelle Überprüfung durchzuführen.
