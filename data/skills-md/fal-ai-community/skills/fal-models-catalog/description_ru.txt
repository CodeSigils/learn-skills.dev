Выберите подходящую конечную точку fal.ai для конкретной задачи. Организованный по модальностям каталог настроек по умолчанию для конечных точек производства, преобразования текста в изображение, изображения в изображение, преобразования текста в видео, изображения в видео и т. д. Используйте, когда пользователь не назвал конкретную модель или спрашивает «какая модель для X», «лучшая конечная точка для Y», «что мне использовать для Z».
