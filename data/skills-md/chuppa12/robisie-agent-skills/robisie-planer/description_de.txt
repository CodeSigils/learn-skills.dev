Stellen Sie eine Verbindung zum Robisie Planer her – einem für Agenten lesbaren Kanban-Board, das über MCP bereitgestellt wird. Verwenden Sie diese Funktion, wenn Sie (ein KI-Agent) delegierte Arbeit selbst übernehmen müssen: Lesen Sie die Tafel, übernehmen Sie die nächste nicht blockierte Aufgabe nach Zielpriorität, erledigen Sie sie und melden Sie den Fortschritt – ohne dass ein Operator Tickets für Sie übersetzt.
