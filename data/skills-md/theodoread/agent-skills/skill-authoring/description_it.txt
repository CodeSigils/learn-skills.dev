Usalo quando scrivi una nuova Skill per l'Agente, modifichi un SKILL.md esistente o desideri che una modifica a una skill venga effettivamente distribuita — dove si trova la fonte rispetto alla copia installata, perché modificare la copia installata non produce alcun effetto, la sequenza modifica → gate → commit → push → reinstallazione → verifica, come pubblicare un repository di skill affinché `skills add` lo trovi, come formulare una `description` in modo che si attivi su richieste reali senza rubare quella di un'altra skill, e quando qualcosa dovrebbe essere una regola di file di istruzioni anziché una skill.
