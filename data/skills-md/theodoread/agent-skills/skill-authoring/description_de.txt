Wird verwendet, wenn Sie einen neuen Agenten-Skill schreiben, einen vorhandenen SKILL.md bearbeiten oder eine Skill-Änderung tatsächlich bereitstellen lassen – wo die Quelle im Vergleich zur installierten Kopie lebt, warum das stille Bearbeiten der installierten Kopie nichts bewirkt, die Reihenfolge Bearbeiten → Gate → Commit → Push → Neuinstallation → Überprüfen, wie man ein Skill-Repo veröffentlicht, damit „Skills Add“ es findet, wie man eine „Beschreibung“ formuliert, damit sie bei echten Anfragen ausgelöst wird, ohne die eines anderen Skills zu stehlen, und wenn etwas eine Anweisungsdateiregel statt eines Skills sein soll überhaupt.
