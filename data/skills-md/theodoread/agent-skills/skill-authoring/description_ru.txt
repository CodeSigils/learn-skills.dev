Используйте при написании нового навыка агента, редактировании существующего SKILL.md или фактическом развертывании изменения навыка - где находится источник, а не установленная копия, почему редактирование установленной копии молча ничего не дает, последовательность редактирования → шлюз → фиксация → push → переустановка → проверка, как опубликовать репозиторий навыков, чтобы `skills add` нашел его, как сформулировать `описание`, чтобы оно запускалось при реальных запросах без кражи других навыков, и когда что-то должно быть правилом файла инструкций вместо умение вообще.
