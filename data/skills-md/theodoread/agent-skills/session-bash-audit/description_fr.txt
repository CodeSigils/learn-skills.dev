À utiliser lorsqu'on vous demande d'auditer, de mesurer ou de revérifier la façon dont les sessions d'agent utilisent l'outil Bash — chaînage de commandes (&&, ;, |), cd dans le propre référentiel de la session, troncature tête/queue, sed -n/cat/heredoc au lieu de Read/Edit, git commit/push à l'intérieur des chaînes ou derrière git -C — ou pour décider s'il s'agit d'une invite d'autorisation, d'une règle de liste autorisée, d'une règle Bash ~/AGENTS.md ou du mode d'autorisation (accepter les modifications vs auto) doit être modifié et veut des preuves provenant de transcriptions réelles plutôt que d'une intuition. Exécute un script stdlib sur ~/.claude/projects/*.jsonl, imprime les tarifs par modèle et par session ainsi que des échantillons, et effectue la recherche datée qui explique pourquoi chaque modèle se produit et où appartient le correctif. C'est également l'endroit où enregistrer un anti-modèle Bash nouvellement remarqué afin que le prochain audit le mesure.
