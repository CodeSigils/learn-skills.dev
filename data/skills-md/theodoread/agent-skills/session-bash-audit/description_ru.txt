Используйте, когда вас просят проверить, измерить или перепроверить, как сеансы агентов используют инструмент Bash — цепочка команд (&&, ;, |), cd в собственный репозиторий сеанса, усечение головы/хвоста, sed -n/cat/heredoc вместо чтения/редактирования, git commit/push внутри цепочек или за git -C — или при принятии решения о том, будет ли запрос разрешения, правило списка разрешений, правило ~/AGENTS.md Bash или режим разрешений (acceptEdits против auto) нуждается в изменении и хочет получить доказательства из реальных стенограмм, а не из догадок. Запускает сценарий stdlib поверх ~/.claude/projects/*.jsonl, распечатывает показатели по модели и за сеанс, а также образцы, а также проводит датированные исследования, которые объясняют, почему происходит каждый шаблон и где находится исправление. Также место для записи недавно замеченного анти-шаблона Bash, чтобы его можно было измерить при следующем аудите.
