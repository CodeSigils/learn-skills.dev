Verwenden Sie diese Option, wenn Sie aufgefordert werden, die Verwendung des Bash-Tools durch Agentensitzungen zu überwachen, zu messen oder erneut zu überprüfen – Befehlsverkettung (&&, ;, |), cd in das eigene Repo der Sitzung, Head/Tail-Kürzung, sed -n/cat/heredoc anstelle von Lesen/Bearbeiten, git commit/push innerhalb von Ketten oder hinter git -C – oder wenn Sie entscheiden, ob es sich um eine Berechtigungsaufforderung, eine Zulassungslistenregel, eine ~/AGENTS.md-Bash-Regel oder den Berechtigungsmodus handelt (acceptEdits vs auto) muss geändert werden und möchte Beweise aus echten Transkripten statt einer Ahnung. Führt ein stdlib-Skript über ~/.claude/projects/*.jsonl aus, druckt die Raten pro Modell und pro Sitzung sowie Beispiele aus und führt die datierte Recherche durch, die erklärt, warum jedes Muster auftritt und wo der Fix hingehört. Auch der Ort, an dem ein neu entdecktes Bash-Anti-Pattern aufgezeichnet werden kann, damit es bei der nächsten Prüfung gemessen wird.
