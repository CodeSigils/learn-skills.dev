استخدمه عند مطالبتك بتدقيق أو قياس أو إعادة التحقق من كيفية استخدام جلسات الوكيل لأداة Bash - تسلسل الأوامر (&&، ;، |)، أو القرص المضغوط في الريبو الخاص بالجلسة، أو اقتطاع الرأس/الذيل، أو sed -n/cat/heredoc بدلاً من القراءة/التحرير، أو التزام git/الدفع داخل السلاسل أو خلف git -C - أو عند تحديد ما إذا كانت هناك مطالبة إذن، أو قاعدة قائمة مسموح بها، أو قاعدة ~/AGENTS.md Bash، أو وضع الإذن (acceptEdits vs auto) يحتاج إلى التغيير ويريد أدلة من نصوص حقيقية بدلاً من الحدس. يقوم بتشغيل برنامج نصي stdlib عبر ~/.claude/projects/*.jsonl، ويطبع معدلات لكل نموذج ولكل جلسة بالإضافة إلى العينات، ويحمل البحث المؤرخ الذي يشرح سبب حدوث كل نمط ومكان الإصلاح. وهو أيضًا المكان المناسب لتسجيل نمط Bash المضاد الذي تمت ملاحظته حديثًا حتى تقيسه المراجعة التالية.
