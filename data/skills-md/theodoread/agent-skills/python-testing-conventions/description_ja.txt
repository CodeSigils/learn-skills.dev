Python テストを作成または再構築するときに使用します。読み取れなくなる前にテストにどの程度の重複を含めるべきか、フィクスチャが何をカバーする必要があるか、どのスコープで行うか、別のテストを作成する代わりにいつパラメータ化するか、依存関係を 2 倍にするか実際に実行するか、高速なデフォルト スイートと低速のマーク層に属するものを決定します。 pytest の詳細についても説明します: フィクスチャ、conftest の配置、パラメータ化 ID、マーカー、およびスイートが実際のホーム ディレクトリに書き込まれないようにします。評価ではなく質問ごとにデフォルトの回答を提供するため、セッションごとに選択肢が変動するのではなく、プロジェクト全体で一貫した選択肢が得られます。また、各エントリには、モデル自体の直感をオーバーライドするか、単にそれを確認するだけであるかが示されます。
