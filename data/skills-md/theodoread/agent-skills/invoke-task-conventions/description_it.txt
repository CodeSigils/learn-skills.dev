Da utilizzare quando si aggiunge, si rinomina o si rivede un'attività di invoke in un task.py o task/ pacchetto — per decidere cosa chiamare `inv <namespace>.<task>`, se un nome deve essere un verbo o un sostantivo, a chi appartiene una nuova attività o se vale la pena modificare un nome esistente. Copre anche il costo effettivo di una ridenominazione (i nomi delle attività sono citati in documenti, CI, Dockerfile e altri repository e il nome della funzione Python cambia con il nome della CLI) e le trappole di cablaggio di invocazione che pubblicano silenziosamente attività che nessuno ha dichiarato. Si applica alla famiglia di repository personali: power-user-linux-setup, attività di repository, progetti generati da scaffoldapy, repository *-polite-mcp.
