À utiliser lors de l'ajout, du renommage ou de la révision d'une tâche d'invocation dans un package Tasks.py ou Tasks/ — pour décider comment appeler « inv <namespace>.<task> », si un nom doit être un verbe ou un nom, à quoi appartient une nouvelle tâche ou si un nom existant mérite d'être modifié. Couvre également ce que coûte réellement un changement de nom (les noms de tâches sont cités dans les documents, CI, Dockerfiles et autres dépôts, et le nom de la fonction Python change avec le nom de la CLI), ainsi que les pièges de câblage d'appel qui publient silencieusement les tâches que personne n'a déclarées. S'applique à toute la famille des dépôts personnels : configuration Linux pour utilisateurs puissants, tâches de dépôt, projets générés par scaffoldapy, les dépôts *-polite-mcp.
