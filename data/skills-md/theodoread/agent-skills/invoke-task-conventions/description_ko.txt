task.py 또는 task/ 패키지에서 호출 작업을 추가, 이름 변경 또는 검토할 때 사용합니다. `inv <namespace>.<task>`를 호출할 항목, 이름이 동사인지 명사인지, 새 작업이 속하는 위치 또는 기존 이름을 변경할 가치가 있는지 여부를 결정합니다. 또한 이름 바꾸기에 실제로 드는 비용(작업 이름은 문서, CI, Dockerfiles 및 기타 저장소에 인용되고 Python 함수 이름은 CLI 이름에 따라 변경됨)과 아무도 선언하지 않은 작업을 자동으로 게시하는 호출 연결 트랩도 다룹니다. 개인 저장소 제품군(power-user-linux-setup, repo-tasks, scaffoldapy 생성 프로젝트, *-polite-mcp 저장소)에 적용됩니다.
