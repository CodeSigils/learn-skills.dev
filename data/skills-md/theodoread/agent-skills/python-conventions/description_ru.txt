Используйте при написании, проверке или рефакторинге кода Python в личном проекте или проекте, поддерживаемом агентом — моделирование данных (Pydantic, dataclass, NamedTuple, TypedDict, attrs или msgspec), даты/время/часовые пояса (только с уведомлением, UTC на границе, сгибы и пробелы в летнее время), управление настройками/секретами, ранние возвраты/защитные положения/отказоустойчивость/EAFP, модульность/DRY/читаемость/инкапсуляция, шаблон модуль-singleton + lazy-property, отсутствие состояния/неизменяемость, структура тестирования (DAMP против DRY, область действия приспособлений), иерархии исключений, гигиена игнорирования типов, структура пакета `src/`-layout, асинхронность/параллелизм и соглашения HTTP-клиент/повторные попытки - плюс соглашения, специфичные для MCP-сервера (дисциплина ведения журнала stdio, обработка ошибок на границах инструментов, обработка LLM строки документации инструмента) для семейства *-polite-mcp. Дает ответ по умолчанию для каждой темы, основанный на авторитетных источниках и прецедентах сообщества, поэтому выбор остается единообразным в разных проектах, а не перемещается от сеанса к сеансу. В каждой теме отмечается, отменяет ли он собственный инстинкт модели по умолчанию или просто документирует уже обоснованный инстинкт, поэтому навык управляет, а не борется с нормальным поведением агента. Охватывает только рекомендации по дизайну/стилю — информацию о проверке типов/линтере/форматтере/оболочке *конфигурации инструмента* см. в файле assets/quality-tooling.md для power-user-linux-setup.
