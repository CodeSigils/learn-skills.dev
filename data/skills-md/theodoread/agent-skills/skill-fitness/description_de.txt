Verwenden Sie diese Option, wenn Sie fragen, ob installierte Fertigkeiten tatsächlich funktionieren – warum eine Fertigkeit niemals oder bei falschen Anfragen ausgelöst wird, welche zwei Fertigkeiten um dieselbe Anforderung konkurrieren, was die Auflistung der Fertigkeiten im Kontext kostet und welche Fertigkeit zuerst ihre Beschreibung verliert, welche Fertigkeiten überhaupt nie aufgerufen wurden oder welche wiederholten einmaligen Skripts, die ein Agent ständig schreibt, in Code innerhalb einer Fertigkeit umgewandelt werden sollen. Auch zur Bewertung einer Fertigkeit anhand der veröffentlichten Qualitätsrubrik vor dem Versand und zur Entscheidung, ob eine Fertigkeit, die zu groß geworden ist oder mehrere verschiedene Dinge gleichzeitig abdeckt, aufgeteilt oder in separate Fertigkeiten aufgeteilt werden sollte. Misst einen installierten Satz aus Frontmatter und dem Sitzungstranskriptspeicher; Es lehrt nicht, wie man eine Fertigkeit schreibt oder einsetzt.
