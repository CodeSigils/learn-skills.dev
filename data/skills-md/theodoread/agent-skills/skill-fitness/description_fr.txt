À utiliser pour demander si les compétences installées fonctionnent réellement : pourquoi une compétence ne se déclenche jamais ou se déclenche sur les mauvaises requêtes, quelles deux compétences sont en compétition pour la même requête, combien coûte la liste de compétences dans le contexte et quelle compétence perd sa description en premier, quelles compétences n'ont jamais été invoquées du tout, ou quels scripts ponctuels répétés qu'un agent continue d'écrire devraient devenir du code dans une compétence. Également pour évaluer une compétence par rapport à la rubrique de qualité publiée avant de l'expédier, et pour décider si une compétence devenue trop importante ou couvrant plusieurs choses différentes à la fois doit être divisée ou divisée en compétences distinctes. Mesure un ensemble installé à partir du frontmatter et du magasin de transcriptions de session ; il n'enseigne pas comment écrire ou déployer une compétence.
