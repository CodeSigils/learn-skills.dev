À utiliser pour écrire Python à l'intérieur d'un serveur MCP et décider comment il doit se comporter - où la sortie du journal peut aller lorsque la sortie standard transporte le cadrage JSON-RPC et pourquoi une impression parasite rompt le protocole, quelle exception à la limite d'un outil devrait se transformer pour le modèle appelant, quelle quantité de détails internes une erreur peut exposer en toute sécurité et comment écrire une docstring d'outil que le modèle lit comme ses instructions plutôt que comme une documentation pour un humain. Adapté aux serveurs de transport stdio. Pour l'empaquetage, l'installation et l'enregistrement d'un serveur plutôt que son code, consultez la compétence d'expédition du serveur MCP ; pour les questions générales de conception Python, consultez la compétence Conventions Python.
