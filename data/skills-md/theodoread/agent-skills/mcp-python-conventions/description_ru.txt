Используйте при написании Python внутри сервера MCP и принятии решения о том, как он должен вести себя — куда могут идти выходные данные журнала, когда стандартный вывод несет кадр JSON-RPC, и почему случайная печать нарушает протокол, чем должно обернуться исключение на границе инструмента для вызывающей модели, сколько внутренних деталей ошибка может безопасно раскрыть, и как написать строку документации инструмента, которую модель будет читать как свои инструкции, а не как документацию для человека. Охватывается серверами stdio-transport. Информацию об упаковке, установке и регистрации сервера, а не о его коде, см. в разделе «Навыки доставки сервера MCP»; общие вопросы по проектированию Python см. в разделе «Конвенции Python».
