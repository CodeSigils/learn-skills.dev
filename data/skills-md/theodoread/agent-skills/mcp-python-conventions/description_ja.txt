MCP サーバー内で Python を記述し、Python がどのように動作するかを決定するときに使用します。標準出力が JSON-RPC フレーミングを伝送するときにログ出力がどこに出力されるか、迷走した印刷がプロトコルを破壊する理由、ツール境界での例外が呼び出し側モデルに対してどのような変化を起こすか、エラーが安全に公開できる内部詳細の範囲、モデルが人間へのドキュメントとしてではなく指示として読み取るツール docstring の書き方などを決定します。 stdio トランスポート サーバーを対象範囲とします。サーバーのコードではなく、サーバーのパッケージ化、インストール、および登録については、MCP サーバーの出荷スキルを参照してください。 Python 設計に関する一般的な質問については、Python の規則スキルを参照してください。
