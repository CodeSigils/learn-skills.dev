Da utilizzare quando si aggiunge la persistenza dei dati locali a un progetto Python: memorizzazione nella cache, archiviazione relazionale (semplice, complessa/OLTP o analitica/OLAP), archiviazione di documenti, ricerca full-text, ricerca vettoriale/incorporamento, code di processi in background, attività cron/pianificate, streaming pub/sub/eventi, dati di grafici, archiviazione BLOB o dati di serie temporali - e non è stata effettuata alcuna richiesta esplicita "valuta il miglior DB per questo". Fornisce la tecnologia predefinita per categoria, scelta per licenze permissive, testabilità pytest-local senza docker/cloud e API LLM-agent-friendly a basso livello, in modo che le scelte rimangano coerenti tra i progetti anziché spostarsi da una sessione all'altra.
