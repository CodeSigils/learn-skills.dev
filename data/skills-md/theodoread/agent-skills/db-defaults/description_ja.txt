ローカル データの永続性を Python プロジェクト (キャッシュ、リレーショナル ストレージ (シンプル、複雑/OLTP、または分析/OLAP)、ドキュメント ストレージ、全文検索、ベクター/埋め込み検索、バックグラウンド ジョブ キュー、cron/スケジュールされたタスク、パブリッシュ/サブスクライブ/イベント ストリーミング、グラフ データ、BLOB ストレージ、または時系列データ) に追加する場合に使用しますが、明示的な「この最適な DB を評価する」リクエストは行われませんでした。カテゴリごとに、寛容なライセンス、ドッカー/クラウドを使用しない pytest ローカルでのテスト容易性、定型句の少ない LLM エージェントに優しい API のために選択されたデフォルトのテクノロジーが提供されるため、選択はセッションごとに変動するのではなく、プロジェクト間で一貫性を保ちます。
