Используйте при добавлении сохраняемости локальных данных в проект Python — кэширования, реляционного хранилища (простого, сложного/OLTP или аналитического/OLAP), хранилища документов, полнотекстового поиска, векторного поиска/поиска по внедрению, очередей фоновых заданий, задач cron/запланированных, потоковой передачи публикаций/подписок/событий, графических данных, хранилища больших двоичных объектов или данных временных рядов – и не было сделано явного запроса «оценить лучшую БД для этого». Предоставляет технологию по умолчанию для каждой категории, выбранную для разрешительного лицензирования, возможности тестирования на локальном уровне pytest без использования Docker/Cloud и простых API-интерфейсов, удобных для LLM-агентов, поэтому выбор остается согласованным между проектами, а не перемещается от сеанса к сеансу.
