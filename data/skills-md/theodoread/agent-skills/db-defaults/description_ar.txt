يُستخدم عند إضافة استمرارية البيانات المحلية إلى مشروع Python - التخزين المؤقت، أو التخزين الارتباطي (بسيط، أو معقد/OLTP، أو تحليلي/OLAP)، أو تخزين المستندات، أو البحث عن النص الكامل، أو البحث المتجه/التضمين، أو قوائم انتظار المهام في الخلفية، أو مهام cron/المجدولة، أو تدفق النشر/الفرعي/الحدث، أو بيانات الرسم البياني، أو تخزين البيانات الثنائية كبيرة الحجم، أو بيانات السلاسل الزمنية - ولم يتم تقديم طلب صريح "لتقييم أفضل قاعدة بيانات لهذا". يمنح التكنولوجيا الافتراضية لكل فئة، والتي تم اختيارها للترخيص المتساهل، وقابلية الاختبار المحلية من خلال pytest بدون وجود عامل إرساء/سحابة، وواجهات برمجة تطبيقات منخفضة المعيارية وصديقة للوكيل LLM، بحيث تظل الاختيارات متسقة عبر المشاريع بدلاً من الانجراف من جلسة إلى أخرى.
