À utiliser lors de l'ajout de la persistance des données locales à un projet Python : mise en cache, stockage relationnel (simple, complexe/OLTP ou analytique/OLAP), stockage de documents, recherche en texte intégral, recherche vectorielle/intégration, files d'attente de tâches en arrière-plan, tâches cron/planifiées, diffusion en continu de publications/sous-événements, données graphiques, stockage d'objets blob ou données de séries chronologiques - et aucune demande explicite "évaluer la meilleure base de données pour cela" n'a été effectuée. Donne la technologie par défaut par catégorie, choisie pour les licences permissives, la testabilité locale pytest sans docker/cloud et les API conviviales pour les agents LLM à faible passe-partout, de sorte que les choix restent cohérents d'un projet à l'autre au lieu de dériver d'une session à l'autre.
