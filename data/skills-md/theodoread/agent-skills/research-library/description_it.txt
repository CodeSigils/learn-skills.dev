Da utilizzare quando si lavora, si aggiunge o si aggiorna la libreria di ricerca condivisa tra progetti su $RESEARCH_HOME (cloni di repository di fornitori, PDF/epub di riferimento, pagine di documenti con mirroring) — prima di recuperare lo stesso materiale dal Web, quando si clona un repository di riferimento per un progetto o quando viene richiesto di aggiornare/aggiornare la libreria.
