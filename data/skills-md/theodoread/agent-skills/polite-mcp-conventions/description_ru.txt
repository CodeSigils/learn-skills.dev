Используйте, когда работаете в одном из репозиториев *-polite-mcp личной автоматизации (olx-polite-mcp, emag-polite-mcp, altex-polite-mcp, freshful-polite-mcp, temu-polite-mcp) или в pipeline исследования продукта — реализуете новый инструмент, проводите живой спайк/исследование CDP на реальном сайте с авторизацией, решаете, требуется ли подтверждение действия перед его выполнением, либо запрашиваете у пользователя несколько небольших решений по каждому элементу (количества, да/нет для каждого товара) в процессе повторного заказа/покупки. Охватывает: подтверждение перед первым живым изменяющим действием в реальном личном аккаунте, пакетирование интерактивных запросов AskUserQuestion вместо запроса списка в виде текста, а также запись результатов спайка/исследования в PLAN.md до или одновременно с реализацией.
