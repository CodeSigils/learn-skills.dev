Verwendung beim Erstellen, Installieren oder Registrieren eines persönlichen MCP-Servers – Hinzufügen seines „[project.scripts]“-Einstiegspunkts, Installieren mit „uv tool install“ von einem lokalen Checkout oder direkt aus Git statt der Veröffentlichung in PyPI, Registrieren mit „claude mcp add“ und Auswählen des lokalen/Projekt-/Benutzerbereichs, Wechseln zwischen einer bearbeitbaren und einer veröffentlichten Entwicklungsinstallation ohne erneute Registrierung und der Pro-Repo-Entwicklungsschleife („inv dev-env.setup`, `inv quality.precommit`, warum die Automatisierung `uv run inv` benötigt) für die Repos, die diese Server produzieren.
