Úselo al crear, instalar o registrar un servidor MCP personal: agregar su punto de entrada `[project.scripts]`, instalarlo con `uv tool install` desde una caja local o directamente desde git en lugar de publicarlo en PyPI, registrarlo con `claude mcp add` y elegir el alcance local/proyecto/usuario, cambiar entre una instalación de desarrollo editable y una publicada sin volver a registrarse, y el bucle de desarrollo por repositorio (`inv dev-env.setup`, `inv quality.precommit`, por qué la automatización necesita `uv run inv`) para los repositorios que producen estos servidores.
