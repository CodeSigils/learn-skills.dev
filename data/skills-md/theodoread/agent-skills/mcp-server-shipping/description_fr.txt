À utiliser lors de la création, de l'installation ou de l'enregistrement d'un serveur MCP personnel — en ajoutant son point d'entrée `[project.scripts]`, en l'installant avec `uv tool install` à partir d'une caisse locale ou directement depuis git au lieu de le publier sur PyPI, en l'enregistrant avec `claude mcp add` et en choisissant la portée locale/projet/utilisateur, en basculant entre une installation de développement modifiable et une installation publiée sans réinscription, et la boucle de développement par dépôt (`inv dev-env.setup`, `inv quality.precommit`, pourquoi l'automatisation a besoin de `uv run inv`) pour les dépôts qui produisent ces serveurs.
