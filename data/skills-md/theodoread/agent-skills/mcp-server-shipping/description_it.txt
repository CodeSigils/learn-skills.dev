Da utilizzare durante la creazione, l'installazione o la registrazione di un server MCP personale: aggiungendo il suo punto di ingresso "[project.scripts]", installandolo con "uv tool install" da un checkout locale o direttamente da git invece di pubblicarlo su PyPI, registrandolo con "claude mcp add" e scegliendo l'ambito locale/progetto/utente, passando da un'installazione di sviluppo modificabile a una rilasciata senza ripetere la registrazione e il ciclo di sviluppo per repository (`inv dev-env.setup`, `inv qualità.precommit`, perché l'automazione necessita di `uv run inv`) per i repository che producono questi server.
