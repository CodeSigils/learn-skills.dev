Используйте при создании, установке или регистрации персонального сервера MCP — добавление его точки входа `[project.scripts]`, установка его с помощью `uvtool install` из локальной проверки или прямо из git вместо публикации в PyPI, регистрация его с помощью `claude mcp add` и выбор области локального/проекта/пользователя, переключение между редактируемой установкой разработчика и выпущенной версией без перерегистрации, а также цикл разработки для каждого репозитория (`inv dev-env.setup`, `invquality.precommit`, почему автоматизация требует `uv run inv`) для репозиториев, которые создают эти серверы.
