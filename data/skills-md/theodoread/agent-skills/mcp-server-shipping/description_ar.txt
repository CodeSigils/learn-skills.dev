يُستخدم عند إنشاء خادم MCP شخصي أو تثبيته أو تسجيله - إضافة نقطة الإدخال `[project.scripts]`، وتثبيته باستخدام `تثبيت أداة uv` من الخروج المحلي أو مباشرة من git بدلاً من النشر إلى PyPI، وتسجيله باستخدام `claude mcp add` واختيار نطاق محلي/مشروع/مستخدم، والتبديل بين تثبيت مطور قابل للتحرير وتثبيت تم إصداره دون إعادة التسجيل، وحلقة التطوير لكل ريبو (`inv dev-env.setup`، `invquality.precommit`، لماذا تحتاج الأتمتة إلى `uv run inv`) لمستودعات إعادة الشراء التي تنتج هذه الخوادم.
