個人の MCP サーバーを構築、インストール、または登録するときに使用します。`[project.scripts]` エントリ ポイントを追加し、PyPI に公開する代わりにローカル チェックアウトまたは git から直接 `uv tool install` を使用してインストールし、`claude mcp add` で登録してローカル/プロジェクト/ユーザー スコープを選択し、再登録せずに編集可能な開発インストールとリリース済みの開発インストールを切り替え、リポジトリごとの開発ループ (`inv) を使用します。これらのサーバーを生成するリポジトリに対して、dev-env.setup`、`invquality.precommit`、自動化に `uv run inv` が必要な理由)。
