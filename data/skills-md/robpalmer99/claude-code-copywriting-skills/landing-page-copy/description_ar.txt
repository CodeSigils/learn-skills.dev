اكتب نسخة قصيرة عالية التحويل من الصفحة المقصودة - الصفحات الوسيطة وصفحات البيع المسبق والصفحات الهبوطية التي تقع بين الإعلانات وVSLs/العروض. استخدم هذه المهارة عندما يطلب المستخدم كتابة أو إعادة كتابة أو طرح أفكار لنسخة الصفحة المقصودة، أو نسخة الهبوط، أو نسخة الصفحة الوسيطة، أو نسخة صفحة البيع المسبق، أو أي صفحة قصيرة مصممة لجذب النقرات إلى VSL أو فيديو أو عرض. قم أيضًا بتشغيل "اكتب لي صفحة مقصودة" أو "مسار لعرضي" أو "نسخة الصفحة الوسيطة" أو أي مهمة تتضمن إنشاء صفحة قصيرة تعمل على زيادة حركة المرور وزيادة النقرات. لا يتعامل مع صفحات المبيعات الطويلة أو VSLs أو الإعلانات الإعلانية - استخدم مهارات/أساليب منفصلة لتلك الصفحات.
