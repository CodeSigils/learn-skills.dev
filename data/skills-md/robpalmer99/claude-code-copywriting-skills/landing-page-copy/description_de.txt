Schreiben Sie hochkonvertierende, kurze Landingpage-Texte – Brückenseiten, Vorverkaufsseiten und Lander, die zwischen Anzeigen und VSLs/Angeboten stehen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Zielseitenkopie, eine Landerkopie, eine Bridgepage-Kopie, eine Pre-Sell-Seitenkopie oder eine Kurzformseite schreiben, neu schreiben oder ein Brainstorming durchführen möchte, die darauf ausgelegt ist, Klicks zu einem VSL, einem Video oder einem Angebot zu generieren. Auch Auslöser für „Schreiben Sie mir eine Landingpage“, „Landingpage für mein Angebot“, „Überbrückungsseitenkopie“ oder jede andere Aufgabe, bei der es darum geht, eine kurze Seite zu erstellen, die den Traffic anregt und die Klickrate steigert. Behandelt KEINE langen Verkaufsseiten, VSLs oder Advertorials – verwenden Sie dafür separate Fähigkeiten/Ansätze.
