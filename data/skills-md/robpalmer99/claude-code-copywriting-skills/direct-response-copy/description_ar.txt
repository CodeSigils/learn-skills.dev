اكتب نسخة المبيعات التي يتم تحويلها - الصفحات المقصودة، وVSLs، ورسائل البريد الإلكتروني، والعناوين الرئيسية، وعبارات الحث على اتخاذ إجراء، والإعلانات الوصفية، وتسلسلات زيادة المبيعات، وأي شيء مقنع. استخدم هذه المهارة عندما يطلب المستخدم كتابة أو إعادة كتابة أو تثقيب أو نقد نسخة المبيعات أو نسخة الاستجابة المباشرة أو VSLs أو TSLs أو تسلسلات البريد الإلكتروني أو تصميم الإعلان أو العناوين الرئيسية أو عبارات الحث على اتخاذ إجراء أو الصفحات المقصودة. يمكنك أيضًا تشغيل طلبات مثل "كتابة نسخة لعرضي" أو "تحسين العنوان الرئيسي" أو "كتابة سطر الموضوع" أو "مساعدتي في بيع X" أو أي مهمة تتضمن كتابة مقنعة لأغراض تجارية. يطبق أطر العمل التي أثبتت جدواها لدى شوارتز، وهوبكنز، وأوجيلفي، وهالبرت، وكابلز، وشوجرمان، وكوليير.
