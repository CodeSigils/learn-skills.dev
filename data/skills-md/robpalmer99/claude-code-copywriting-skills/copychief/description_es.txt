Revisión y redacción de textos de ventas, VSL, correos electrónicos, anuncios y páginas de destino utilizando principios de respuesta directa de los mejores redactores (Carlton, Halbert, Makepeace, Georgi, Schwartz, etc.). Utilice esta habilidad siempre que el usuario solicite revisar el texto, redactar algo, criticar el texto de ventas, mejorar un VSL, verificar una secuencia de correo electrónico, revisar el texto de un anuncio, auditar un embudo o cualquier cosa que implique evaluar y mejorar el texto de marketing de respuesta directa. También se activa cuando el usuario comparte un documento o documento de Google y solicita comentarios sobre material de ventas o marketing.
