قم بمراجعة نسخ المبيعات ونسخ المبيعات وVSLs ورسائل البريد الإلكتروني والإعلانات والصفحات المقصودة باستخدام مبادئ الاستجابة المباشرة من كبار مؤلفي النصوص (Carlton وHalbert وMakepeace وGeorgi وSchwartz وما إلى ذلك). استخدم هذه المهارة عندما يطلب المستخدم مراجعة النسخة، أو نسخ شيء ما، أو نقد نسخة المبيعات، أو تحسين VSL، أو التحقق من تسلسل البريد الإلكتروني، أو مراجعة نسخة الإعلان، أو تدقيق مسار التحويل، أو أي شيء يتضمن تقييم وتحسين نسخة تسويق الاستجابة المباشرة. يتم تشغيله أيضًا عندما يشارك المستخدم مستندًا أو مستند Google ويطلب تعليقات حول المبيعات أو المواد التسويقية.
