Utilizzare questa abilità ogni volta che l'utente desidera utilizzare gli agenti AI per lavorare con i file di progettazione Penpot tramite il server Penpot MCP. I trigger includono: utilizzo di Penpot tramite un agente AI, file di progettazione, sistemi di progettazione, token di progettazione, Penpot MCP, progettazione-codice, generazione di un'interfaccia utente dalla progettazione, controllo di un sistema di progettazione, creazione di componenti/varianti, ridenominazione di livelli, esportazione di risorse da Penpot, aggiunta di flussi, interazioni, animazioni, sovrapposizioni o prototipazione in Penpot o richiesta a un agente AI di leggere/modificare un file Penpot. Si attiva anche quando l'utente desidera configurare Penpot MCP, connettere qualsiasi agente AI o IDE compatibile con MCP a Penpot o produrre HTML/CSS/React pronti per la produzione da un progetto Penpot. Utilizza questa competenza per i flussi di lavoro Penpot-agent: progettazione, codifica, audit, prototipazione o configurazione.
