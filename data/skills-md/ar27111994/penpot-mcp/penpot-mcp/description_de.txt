Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer KI-Agenten verwenden möchte, um über den Penpot MCP-Server mit Penpot-Designdateien zu arbeiten. Zu den Auslösern gehören: Verwendung von Penpot über einen KI-Agenten, Designdateien, Designsysteme, Design-Tokens, Penpot MCP, Design-to-Code, Generierung einer Benutzeroberfläche aus Design, Prüfung eines Designsystems, Erstellen von Komponenten/Varianten, Umbenennen von Ebenen, Exportieren von Assets aus Penpot, Hinzufügen von Flüssen, Interaktionen, Animationen, Überlagerungen oder Prototyping in Penpot oder Aufforderung an einen KI-Agenten, eine Penpot-Datei zu lesen/zu ändern. Wird auch ausgelöst, wenn der Benutzer Penpot MCP einrichten, einen beliebigen MCP-kompatiblen KI-Agenten oder eine IDE mit Penpot verbinden oder produktionsbereites HTML/CSS/React aus einem Penpot-Design erstellen möchte. Nutzen Sie diese Fähigkeit für Penpot-Agent-Workflows – Design, Code, Prüfung, Prototyping oder Einrichtung.
