Utilice esta habilidad siempre que el usuario desee utilizar agentes de IA para trabajar con archivos de diseño de Penpot a través del servidor Penpot MCP. Los desencadenantes incluyen: usar Penpot a través de un agente de IA, archivos de diseño, sistemas de diseño, tokens de diseño, Penpot MCP, diseño a código, generar una interfaz de usuario a partir del diseño, auditar un sistema de diseño, crear componentes/variantes, cambiar el nombre de capas, exportar activos desde Penpot, agregar flujos, interacciones, animaciones, superposiciones o crear prototipos en Penpot, o solicitar a un agente de IA que lea/modifique un archivo de Penpot. También se activa cuando el usuario desea configurar Penpot MCP, conectar cualquier agente de IA o IDE compatible con MCP a Penpot, o producir HTML/CSS/React listo para producción a partir de un diseño de Penpot. Utilice esta habilidad para los flujos de trabajo del agente Penpot: diseño, codificación, auditoría, creación de prototipos o configuración.
