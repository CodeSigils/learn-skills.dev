ユーザーが AI エージェントを使用して Penpot MCP サーバー経由で Penpot デザイン ファイルを操作する場合は常に、このスキルを使用します。トリガーには、AI エージェントを介した Penpot の使用、デザイン ファイル、デザイン システム、デザイン トークン、Penpot MCP、デザインからコードへの変換、デザインから UI の生成、デザイン システムの監査、コンポーネント/バリアントの作成、レイヤーの名前変更、Penpot からのアセットのエクスポート、Penpot でのフロー、インタラクション、アニメーション、オーバーレイ、またはプロトタイピングの追加、または AI エージェントに Penpot ファイルの読み取り/変更を促すことが含まれます。また、ユーザーが Penpot MCP をセットアップする場合、MCP 互換の AI エージェントまたは IDE を Penpot に接続する場合、または Penpot デザインから本番環境に対応した HTML/CSS/React を生成する場合にもトリガーされます。このスキルは、Penpot エージェントのワークフロー (設計、コード、監査、プロトタイピング、セットアップ) に使用します。
