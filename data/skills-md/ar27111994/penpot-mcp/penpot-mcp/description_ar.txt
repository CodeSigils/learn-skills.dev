استخدم هذه المهارة عندما يريد المستخدم استخدام وكلاء الذكاء الاصطناعي للعمل مع ملفات تصميم Penpot عبر خادم Penpot MCP. تتضمن المشغلات: استخدام Penpot من خلال وكيل الذكاء الاصطناعي، أو ملفات التصميم، أو أنظمة التصميم، أو رموز التصميم، أو Penpot MCP، أو التصميم إلى كود، أو إنشاء واجهة مستخدم من التصميم، أو تدقيق نظام التصميم، أو إنشاء مكونات/متغيرات، أو إعادة تسمية الطبقات، أو تصدير الأصول من Penpot، أو إضافة التدفقات، أو التفاعلات، أو الرسوم المتحركة، أو التراكبات، أو النماذج الأولية في Penpot، أو مطالبة وكيل الذكاء الاصطناعي بقراءة/تعديل ملف Penpot. يتم تشغيله أيضًا عندما يريد المستخدم إعداد Penpot MCP، أو توصيل أي وكيل AI أو IDE متوافق مع MCP بـ Penpot، أو إنتاج HTML/CSS/React جاهز للإنتاج من تصميم Penpot. استخدم هذه المهارة لسير عمل Penpot-agent — التصميم أو التعليمات البرمجية أو التدقيق أو النماذج الأولية أو الإعداد.
