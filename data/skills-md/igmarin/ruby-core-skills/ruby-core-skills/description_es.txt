Catálogo de 16 habilidades compartidas de desarrollo de Ruby que cubren TDD, refactorización, revisión de código, revisión de seguridad, DDD, documentación YARD y patrones de diseño comunes (objetos de servicio, calculadoras, clientes API). Rutas hacia habilidades especializadas por categoría. Úselo al crear aplicaciones Ruby, implementar flujos de trabajo TDD, revisar código o necesitar una disciplina de proceso específica de Ruby. Desencadenante: desarrollo de Ruby, habilidad de Ruby, TDD de Ruby, revisión de código de Ruby, patrones de diseño de Ruby.
