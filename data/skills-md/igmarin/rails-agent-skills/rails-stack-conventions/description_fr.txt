À utiliser lors de l'écriture d'un nouveau code Rails pour un projet utilisant la pile CSS PostgreSQL + Hotwire + Tailwind. Couvre uniquement les modèles spécifiques à la pile : structure MVC, conventions de requête ActiveRecord, câblage Turbo Frames/Streams, contrôleurs Stimulus et modèles de composants Tailwind. Pas pour les principes généraux de conception de Rails - cette compétence s'étend aux changements en fonction de cette pile technologique spécifique.
