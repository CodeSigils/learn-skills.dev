Úselo al escribir nuevo código Rails para un proyecto usando la pila CSS PostgreSQL + Hotwire + Tailwind. Cubre solo patrones específicos de pila: estructura MVC, convenciones de consulta ActiveRecord, cableado Turbo Frames/Streams, controladores Stimulus y patrones de componentes Tailwind. No para los principios generales de diseño de Rails: esta habilidad se centra en los cambios en función de esta pila de tecnología específica.
