Используйте при написании нового кода Rails для проекта с использованием стека CSS PostgreSQL + Hotwire + Tailwind. Охватывает только шаблоны, специфичные для стека: структуру MVC, соглашения о запросах ActiveRecord, подключение Turbo Frames/Streams, контроллеры Stimulus и шаблоны компонентов Tailwind. Не для общих принципов проектирования Rails — этот навык ограничен тем, что меняется в зависимости от этого конкретного технологического стека.
