Da utilizzare quando si scrive nuovo codice Rails per un progetto utilizzando lo stack CSS PostgreSQL + Hotwire + Tailwind. Copre solo modelli specifici dello stack: struttura MVC, convenzioni di query ActiveRecord, cablaggio Turbo Frames/Streams, controller di stimolo e modelli di componenti Tailwind. Non per i principi generali di progettazione di Rails: questa competenza riguarda ciò che cambia in base a questo specifico stack tecnologico.
