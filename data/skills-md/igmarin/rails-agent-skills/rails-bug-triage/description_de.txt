Wird zur Untersuchung eines Bugs, Fehlers oder einer Regression in einer Ruby on Rails-Codebasis verwendet. Erstellt einen fehlgeschlagenen RSpec-Reproduktionstest, isoliert den fehlerhaften Codepfad und erstellt einen minimalen Korrekturplan. Auslösewörter: Debuggen, defekt, Fehler, Regression, Stack-Trace, fehlgeschlagener Test, RSpec, Fehlerbericht, Rails-App.
