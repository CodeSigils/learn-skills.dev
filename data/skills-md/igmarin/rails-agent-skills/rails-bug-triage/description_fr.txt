À utiliser lors de l'enquête sur un bogue, une erreur ou une régression dans une base de code Ruby on Rails. Crée un test de reproduction RSpec défaillant, isole le chemin de code défectueux et produit un plan de correctif minimal. Mots déclencheurs : débogage, cassé, erreur, régression, trace de pile, échec du test, RSpec, rapport de bug, application Rails.
