يراجع طلبات سحب Rails، مع التركيز على اصطلاحات وحدة التحكم/النموذج، وسلامة الترحيل، وأداء الاستعلام، والامتثال لـ Rails Way. يغطي وظائف التوجيه وActiveRecord والأمن والتخزين المؤقت والخلفية. يُستخدم عند مراجعة كود Rails الحالي للتأكد من الجودة، أو إجراء مراجعة العلاقات العامة، أو إجراء مراجعة الكود على كود Ruby on Rails (RoR).
