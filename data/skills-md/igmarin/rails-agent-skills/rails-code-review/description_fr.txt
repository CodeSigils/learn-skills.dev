Examine les demandes d'extraction Rails, en se concentrant sur les conventions de contrôleur/modèle, la sécurité de la migration, les performances des requêtes et la conformité Rails Way. Couvre le routage, ActiveRecord, la sécurité, la mise en cache et les tâches en arrière-plan. À utiliser lors de l'examen de la qualité du code Rails existant, de la réalisation d'un examen des relations publiques ou d'un examen du code Ruby on Rails (RoR).
