À utiliser lors de l'écriture, de la révision ou du nettoyage des tests RSpec pour les bases de code Ruby et Rails. Couvre la sélection du type de spécification, la conception d'usine, les correctifs de tests instables, les exemples partagés, les assertions déterministes, la discipline de développement basée sur les tests et le choix de la meilleure première spécification défaillante pour les modifications Rails. S'applique également lors du choix entre le modèle, la demande, le système et les spécifications de travail.
