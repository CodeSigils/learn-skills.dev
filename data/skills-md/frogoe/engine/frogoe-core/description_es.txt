El contrato técnico de Frogoe: cómo se construye un juego. Úselo para el formulario de carpeta (index.html / game.js / BRIEF.md / frogoe.json / .frogoe/), el cierre defineGame y sus cuatro sustantivos (etapa, entrada, bucle, finalización), semántica de puntero dx, el identificador de host window.__frogoe, enlaces de bloques HUD, bibliotecas externas (tres.js, gsap, fuentes) y el paquete que los disuelve, además de verificar reglas y errores de enseñanza. Lea antes de escribir o editar cualquier código de juego.
