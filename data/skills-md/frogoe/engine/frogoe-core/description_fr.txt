Le contrat technique Frogoe – comment un jeu est construit. À utiliser pour le formulaire de dossier (index.html / game.js / BRIEF.md / frogoe.json / .frogoe/), la fermeture finishGame et ses quatre noms (stage, input, loop, finish), la sémantique du pointeur dx, le handle d'hôte window.__frogoe, les liaisons de bloc HUD, les bibliothèques externes (two.js, gsap, fonts) et le bundler qui les dissout, ainsi que les règles de vérification et les erreurs d'enseignement. A lire avant d'écrire ou de modifier un code de jeu.
