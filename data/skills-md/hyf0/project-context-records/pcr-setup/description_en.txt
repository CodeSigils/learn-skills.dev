Set up Project Context Records (PCR) in the current project — put the PCR adoption block into the project's AGENTS.md, create the records folder, and offer to seed the starter records, idempotently. Use when the user runs /pcr-setup, or asks to set up, adopt, install, add, update, or re-sync PCR / Project Context Records in a project. Do NOT use for writing or editing individual records, or for changing the methodology doc itself.
