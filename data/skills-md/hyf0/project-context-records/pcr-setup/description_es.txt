Configure registros de contexto del proyecto (PCR) en el proyecto actual: coloque el bloque de adopción de PCR en AGENTS.md del proyecto, cree la carpeta de registros y ofrezca inicializar los registros iniciales, de forma idempotente. Úselo cuando el usuario ejecuta /pcr-setup o solicita configurar, adoptar, instalar, agregar, actualizar o resincronizar registros de contexto de proyecto/PCR en un proyecto. NO lo utilice para escribir o editar registros individuales, ni para cambiar el documento de metodología en sí.
