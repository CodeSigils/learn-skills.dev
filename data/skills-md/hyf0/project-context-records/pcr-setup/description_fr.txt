Configurez les enregistrements de contexte de projet (PCR) dans le projet en cours : placez le bloc d'adoption du PCR dans le fichier AGENTS.md du projet, créez le dossier d'enregistrements et proposez d'amorcer les enregistrements de démarrage, de manière idempotente. À utiliser lorsque l'utilisateur exécute /pcr-setup ou demande de configurer, adopter, installer, ajouter, mettre à jour ou resynchroniser les enregistrements de contexte PCR/projet dans un projet. Ne PAS utiliser pour rédiger ou modifier des enregistrements individuels, ni pour modifier le document méthodologique lui-même.
