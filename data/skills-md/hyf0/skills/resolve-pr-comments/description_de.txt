Überprüfen und lösen Sie GitHub PR-Bewertungskommentare. Verwenden Sie diese Option, wenn der Benutzer ungelöste Überprüfungskommentare zu einem Pull-Request ansprechen, korrigieren oder auflösen möchte. TRIGGER, wenn: Der Benutzer sagt „PR-Kommentare auflösen“, „PR-Kommentare korrigieren“, „Bewertungskommentare adressieren“, „PR-Feedback bearbeiten“ oder eine PR-URL mit Anweisungen zu ungelösten Kommentaren bereitstellt. NICHT verwenden für: das Erstellen von PRs, das Überprüfen von Code selbst oder allgemeine PR-Vorgänge, bei denen es nicht darum geht, vorhandene Überprüfungskommentare aufzulösen.
