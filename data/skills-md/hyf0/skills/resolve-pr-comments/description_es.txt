Revise y resuelva los comentarios de revisión de relaciones públicas de GitHub. Úselo cuando el usuario quiera abordar, corregir o resolver comentarios de revisión no resueltos en una solicitud de extracción. DISPARAR cuando: el usuario dice "resolver comentarios de relaciones públicas", "corregir comentarios de relaciones públicas", "abordar comentarios de revisión", "manejar comentarios de relaciones públicas" o proporciona una URL de relaciones públicas con instrucciones sobre comentarios no resueltos. NO lo use para: crear relaciones públicas, revisar el código usted mismo u operaciones generales de relaciones públicas que no impliquen resolver comentarios de revisión existentes.
