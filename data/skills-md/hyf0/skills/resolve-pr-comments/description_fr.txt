Examinez et résolvez les commentaires de révision de GitHub PR. À utiliser lorsque l'utilisateur souhaite traiter, corriger ou résoudre les commentaires d'évaluation non résolus sur une demande d'extraction. DÉCLENCHEMENT lorsque : l'utilisateur dit "résoudre les commentaires PR", "corriger les commentaires PR", "adresser les commentaires de révision", "gérer les commentaires PR", ou fournit une URL PR avec des instructions sur les commentaires non résolus. Ne PAS utiliser pour : créer des PR, réviser le code vous-même ou pour des opérations générales de relations publiques qui n'impliquent pas la résolution des commentaires de révision existants.
