Cree, edite, envíe o versione una plantilla de Coder. Úselo para solicitudes como "desarrollar una plantilla de Docker", "crear una plantilla de Kubernetes", "agregar un coder_parameter para la URL del repositorio de Git", "enviar mi plantilla a esta implementación de Coder", "actualizar la plantilla de aws-linux existente para agregar JetBrains" o "desaprobar esta versión de la plantilla". No lo use para instalar o actualizar Coder (use la habilidad de configuración), agregar un solo módulo a una plantilla que ya está compilada (use la habilidad de módulos) o crear proveedores Terraform personalizados no relacionados con Coder.
