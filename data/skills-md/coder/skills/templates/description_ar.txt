قم بإنشاء قالب Coder أو تحريره أو دفعه أو إصداره. يُستخدم لطلبات مثل "سقالة قالب Docker" أو "إنشاء قالب Kubernetes" أو "إضافة معلمة coder_parameter لعنوان URL الخاص بـ Git repo" أو "دفع القالب الخاص بي إلى نشر Coder هذا" أو "تحديث قالب aws-linux الحالي لإضافة JetBrains" أو "إيقاف إصدار القالب هذا". لا تستخدمه لتثبيت Coder نفسه أو ترقيته (استخدم مهارة الإعداد)، أو إضافة وحدة نمطية واحدة إلى قالب تم إنشاؤه بالفعل (استخدم مهارة الوحدات)، أو تأليف موفري Terraform مخصصين لا علاقة لهم بـ Coder.
