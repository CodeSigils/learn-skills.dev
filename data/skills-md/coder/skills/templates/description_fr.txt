Créez, modifiez, envoyez ou versionnez un modèle Coder. À utiliser pour des requêtes telles que « élaborer un modèle Docker », « créer un modèle Kubernetes », « ajouter un paramètre coder_parameter pour l'URL du dépôt Git », « envoyer mon modèle vers ce déploiement Coder », « mettre à jour le modèle aws-linux existant pour ajouter JetBrains » ou « rendre obsolète cette version du modèle ». Ne pas utiliser pour installer ou mettre à niveau Coder lui-même (utilisez la compétence de configuration), pour ajouter un seul module à un modèle déjà construit (utilisez la compétence modules) ou pour créer des fournisseurs Terraform personnalisés sans rapport avec Coder.
