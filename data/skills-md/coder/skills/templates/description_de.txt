Create, edit, push, or version a Coder template. Wird für Anfragen wie „Gerüst für eine Docker-Vorlage“, „Erstellen einer Kubernetes-Vorlage“, „Hinzufügen eines coder_parameters für die Git-Repo-URL“, „Push meiner Vorlage zu dieser Coder-Bereitstellung“, „Aktualisieren der vorhandenen aws-linux-Vorlage zum Hinzufügen von JetBrains“ oder „Diese Vorlagenversion verwerfen“ verwendet. Do not use for installing or upgrading Coder itself (use the setup skill), adding a single module to a template that already builds (use the modules skill), or authoring custom Terraform providers unrelated to Coder.
