Agregue un módulo Coder desde registro.coder.com/modules a una plantilla Coder existente o actualice una que ya esté allí. Úselo para solicitudes como "agregar el IDE del cursor a mi plantilla", "dar acceso a JetBrains a los espacios de trabajo", "configurar el servidor de códigos", "conectar archivos de puntos", "instalar Claude Code en esta plantilla" o "anclar versiones del módulo". No lo use para instalar o actualizar Coder (use la habilidad de configuración), crear una plantilla nueva desde cero (use la habilidad de plantillas) o publicar un módulo personalizado en el registro.
