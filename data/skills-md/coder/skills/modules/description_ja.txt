Add a Coder module from registry.coder.com/modules to an existing Coder template, or update one that is already there. 「Cursor IDE をテンプレートに追加する」、「ワークスペースに JetBrains アクセスを与える」、「コードサーバーをセットアップする」、「ドットファイルに接続する」、「このテンプレートに Claude Code をインストールする」、または「モジュールのバージョンを固定する」などのリクエストに使用します。 Coder 自体のインストールまたはアップグレード (セットアップ スキルを使用)、新しいテンプレートを最初から作成する (テンプレート スキルを使用)、またはカスタム モジュールをレジストリに公開するためには使用しないでください。
