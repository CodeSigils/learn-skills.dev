Ajoutez un module Coder depuis Registry.coder.com/modules à un modèle Coder existant ou mettez à jour celui qui existe déjà. À utiliser pour des requêtes telles que « ajouter l'IDE Cursor à mon modèle », « donner accès aux espaces de travail JetBrains », « configurer le serveur de code », « câbler les fichiers dot », « installer Claude Code dans ce modèle » ou « épingler les versions du module ». Ne pas utiliser pour installer ou mettre à niveau Coder lui-même (utilisez la compétence de configuration), créer un tout nouveau modèle à partir de zéro (utiliser la compétence Modèles) ou publier un module personnalisé dans le registre.
