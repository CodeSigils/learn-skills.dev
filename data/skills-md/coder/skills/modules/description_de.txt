Fügen Sie ein Coder-Modul von Registry.coder.com/modules zu einer vorhandenen Coder-Vorlage hinzu oder aktualisieren Sie ein bereits vorhandenes. Verwenden Sie diese Option für Anfragen wie „Cursor-IDE zu meiner Vorlage hinzufügen“, „JetBrains-Arbeitsbereichen Zugriff gewähren“, „Codeserver einrichten“, „Punktdateien einbinden“, „Claude Code in dieser Vorlage installieren“ oder „Modulversionen anpinnen“. Nicht zum Installieren oder Aktualisieren von Coder selbst (verwenden Sie den Setup-Skill), zum Erstellen einer brandneuen Vorlage von Grund auf (verwenden Sie den Vorlagen-Skill) oder zum Veröffentlichen eines benutzerdefinierten Moduls in der Registrierung verwenden.
