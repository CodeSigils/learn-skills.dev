Instale, implemente o inicie una nueva implementación de Coder (codificador/codificador) de un extremo a otro. Úselo para la configuración inicial en Docker, Kubernetes/Helm, una máquina virtual, nube, configuración HTTPS/dominio, para crear el primer administrador, enviar una plantilla inicial o crear el primer espacio de trabajo. No lo use para actualizaciones, depurar una implementación existente, editar una plantilla existente o configurar OAuth/OIDC en una implementación en ejecución.
