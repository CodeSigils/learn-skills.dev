Comprimi i file di memoria in linguaggio naturale (CLAUDE.md, todos, settings) in un formato primitivo per ridurre i token di input. Il contenuto tecnico, il codice, gli URL e la struttura sono completamente preservati. La versione compressa sovrascrive il file originale e una versione leggibile viene salvata come FILE.original.md. Avviare con "/genshijin-compress<filepath>" o "compressione file di memoria".
