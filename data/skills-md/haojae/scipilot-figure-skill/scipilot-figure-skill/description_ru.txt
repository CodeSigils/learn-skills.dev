Члены семейства SciPilot Skills отвечают за визуализацию научных данных, но позиционирование — это не «инструмент для рисования», а «консультант по визуализации». Сначала проведите анализ данных (типы столбцов, размер выборки, распределение, выбросы, структура группировки, корреляция), затем, в сочетании с аргументативными целями пользователя, порекомендуйте типы диаграмм, активно перехватите классические ошибки научного построения (столбцы малых выборок, которые скрывают распределение, двойные оси Y, круговые диаграммы, неправильное усечение оси Y, радужные цветовые карты, соединение категориальных точек линиями и т. д.) и, наконец, создайте цифры на уровне природы, науки, IEEE, Elsevier, PNAS или основные китайские журналы.  

Охватывает диаграммы чистых данных: линейные, гистограммы, точечные диаграммы, прямоугольники/скрипки, тепловые карты, столбцы ошибок, графики распределения (гистограммы/KDE), корреляционную матрицу/матрицу рассеяния, многопанельные композиты. Технический стек: matplotlib+seaborn+SciencePlots (статический)+plotly (интерактивный). Двуязычный китайский-английский; В китайском режиме автоматически настраиваются NotoSansCJK, SourceHanSans, SimHei, исправляются знаки минус в рамке и поддерживается смешанная раскладка китайских журналов «Songti body+TimesNewRoman Numbers». Палитра по умолчанию, безопасная для дальтоников + избыточное кодирование + предварительный просмотр в оттенках серого. После создания диаграммы выполните «замкнутый цикл визуальной самопроверки»: предварительный просмотр PNG → программа самостоятельно проверяет отсутствующие символы, обрезку текста, перекрытие осей → AI читает диаграмму, чтобы проверить покрытие и выравнивание с подграфиками → выполняет повторную визуализацию до тех пор, пока она не пройдет.  

Активно активируется, когда задача пользователя включает в себя любое из следующих действий: бумажные рисунки, научные построения, визуализация данных, незнание, какую диаграмму использовать, как отображать данные, какая диаграмма лучше всего, цифры, представленные в журнале, рисунки, диаграммы публикации, matplotlib, seaborn,plotly, полосы ошибок, аннотации значимости, палитра, безопасная для дальтоников, векторный экспорт, бумажные диаграммы на китайском языке, несколько панелей. **Даже если пользователь предоставляет только пакет данных и спрашивает «как это построить» или «какая диаграмма подойдет», следует использовать этот навык — его основная способность — «определить, какую диаграмму использовать», с рисованием второстепенного шага.** Не создавайте принципиальные схемы, блок-схемы или архитектурные диаграммы.
