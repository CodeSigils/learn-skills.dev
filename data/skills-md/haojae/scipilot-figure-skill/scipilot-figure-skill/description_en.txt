SciPilot Skills family members are responsible for scientific data visualization—but the positioning is not a “drawing tool,” it is a “visualization consultant.” First conduct data analysis (column types, sample size, distribution, outliers, grouping structure, correlation), then, combined with the user’s argumentative goals, recommend chart types, proactively intercept classic scientific‑plotting errors (small‑sample mean bars that hide distribution, dual Y‑axes, pie charts, improper Y‑axis truncation, rainbow colormaps, connecting categorical points with lines, etc.), and finally produce figures at the level of Nature, Science, IEEE, Elsevier, PNAS, or Chinese core journals.  

Covers pure data charts: line, bar, scatter, box/violin, heatmap, error bars, distribution plots (histogram/KDE), correlation matrix/scatter matrix, multi‑panel composites. Technical stack: matplotlib + seaborn + SciencePlots (static) + plotly (interactive). Bilingual Chinese–English; Chinese mode automatically configures Noto Sans CJK, Source Han Sans, SimHei, fixes boxed minus signs, and supports mixed layout of Chinese journals “Songti body + Times New Roman numbers.” Default color‑blind‑safe palette + redundant encoding + grayscale preview. After chart generation, perform a “visual self‑check closed loop”: render PNG preview → program self‑checks missing characters, text cropping, axis overlap → AI reads the chart to verify coverage and alignment with subplots → re‑render until it passes.  

Actively trigger when the user’s task involves any of the following: paper figures, scientific plotting, data visualization, not knowing which chart to use, how to display data, which chart is best, journal submission figures, figure, publication‑grade charts, matplotlib, seaborn, plotly, error bars, significance annotation, color‑blind‑safe palette, vector export, Chinese paper charts, multi‑panel. **Even if the user only provides a batch of data and asks “how to plot this” or “which chart is good,” this skill should be used—its primary ability is “determine which chart to use,” with drawing a secondary step.** Do not produce schematic diagrams, flowcharts, or architecture diagrams.
