SciPilot Skills family’s literature search and citation insertion capability. Supports two input modes — Mode A: reads the user’s Word (.docx) or LaTeX (.tex) manuscript and inserts citations in the corresponding sections of the text; Mode B: receives a paragraph/a viewpoint/a claim from the user and outputs a list of references that support it (without modifying the document). Both modes perform parallel searches of real literature through three sources—Semantic Scholar, OpenAlex, Crossref—using DOI + multi‑source cross‑verification for authenticity, then output according to the user‑specified format (IEEE/APA/Nature/Vancouver/GB‑T‑7714, etc.). Before each delivery, a mandatory Gate 8 end‑stage hallucination gating audit is run; a FAIL results in refusal to deliver. In Stage 0, the system must proactively ask the user for multiple preferences: number of papers, format, year range, chapter, journal tier, author preferences, institution preferences, whether to include preprints, etc., and must not silently use default values. This skill is triggered whenever the user mentions any of the following: add references, insert citations, find literature, citation, reference, add citation, supplement references, literature search, add references, find papers, insert citations, find literature to support a viewpoint, use literature to support this passage, support claim with literature, validate viewpoint with references, or when the user uploads a paper file and requests added citations, or provides a passage/idea and asks for supporting literature. Even if the user simply says “add a few references to my paper,” “scipilot find me papers,” or “does this viewpoint have literature support,” this skill should be triggered. It belongs to the SciPilot Skills research‑skill family.
