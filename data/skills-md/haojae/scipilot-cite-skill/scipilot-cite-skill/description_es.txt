Capacidad de búsqueda de literatura e inserción de citas de la familia SciPilot Skills. Admite dos modos de entrada: Modo A: lee el manuscrito de Word (.docx) o LaTeX (.tex) del usuario e inserta citas en las secciones correspondientes del texto; Modo B: recibe un párrafo/un punto de vista/una afirmación del usuario y genera una lista de referencias que lo respaldan (sin modificar el documento). Ambos modos realizan búsquedas paralelas de literatura real a través de tres fuentes (Semantic Scholar, OpenAlex, Crossref) utilizando DOI + verificación cruzada de múltiples fuentes para verificar la autenticidad, y luego generan resultados de acuerdo con el formato especificado por el usuario (IEEE/APA/Nature/Vancouver/GB‑T‑7714, etc.). Antes de cada parto, se realiza una auditoría obligatoria de detección de alucinaciones en etapa terminal Gate8; un FALLO resulta en la negativa a entregar. En Stage0, el sistema debe solicitar de forma proactiva al usuario múltiples preferencias: número de artículos, formato, rango de años, capítulo, nivel de revista, preferencias de autor, preferencias de institución, si se incluyen preimpresiones, etc., y no debe utilizar valores predeterminados en silencio. Esta habilidad se activa cada vez que el usuario menciona cualquiera de los siguientes: agregar referencias, insertar citas, buscar literatura, cita, referencia, agregar cita, complementar referencias, buscar literatura, agregar referencias, buscar artículos, insertar citas, encontrar literatura para respaldar un punto de vista, usar literatura para respaldar este pasaje, respaldar una afirmación con literatura, validar un punto de vista con referencias, o cuando el usuario carga un archivo en papel y solicita citas adicionales, o proporciona un pasaje/idea y solicita literatura de respaldo. Incluso si el usuario simplemente dice "agregue algunas referencias a mi artículo", "encuéntreme artículos" o "este punto de vista tiene respaldo bibliográfico", esta habilidad debe activarse. Pertenece a la familia de habilidades de investigación SciPilot Skills.
