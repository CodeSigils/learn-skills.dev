Analysez les bases de code backend existantes et générez des fichiers de règles complets orientés vers l'IA (Markdown) qui permettent aux assistants de codage IA de modifier correctement le code dès la première tentative. Couvre les projets Java/Spring, PHP/ThinkPHP/Laravel, Python/Django/Flask, Node.js/Express/Koa/Egg, Go et .NET. UTILISEZ CETTE COMPÉTENCE chaque fois que l'utilisateur souhaite : générer des règles/instructions pour un projet ancien ou hérité ; créer .cursorrules, .copilot-instructions.md, CLAUDE.md ou des fichiers de règles IA similaires à partir du code existant ; analyser une base de code pour en extraire les conventions, les modèles et les pièges de codage ; documenter un projet non documenté pour la consommation d’IA ; ou préparez une base de code héritée pour que l'IA puisse la modifier en toute sécurité. À utiliser également lorsque l'utilisateur mentionne « 屎山 », « 老项目 », « 遗留代码 », « code hérité », « extraction de règles », « conventions d'extraction » ou souhaite s'assurer que les modifications de l'IA sont compatibles avec le style de code existant.
