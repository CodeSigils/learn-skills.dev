Esamina il codice di test generato o modificato rispetto alle regole di test universali prima della spedizione. È preferibile utilizzarlo in modo reattivo dopo che un agente ha scritto, modificato, generato o effettuato il refactoring dei test, prima di presentarli, eseguirne il commit o unirli. Utilizzare per pytest (test_*.py, *_test.py), PHPUnit/Pest (*Test.php), Jest/Vitest (*.test.ts, *.spec.js), Go (*_test.go), file in tests/, __tests__/ o spec/ e richieste di revisione come 'scrivi test per X', 'aggiungi test', 'prova questo', 'rivedi questi test' o diff PR contenenti test. Può anche guidare la scrittura del test se invocato esplicitamente prima del lavoro. Questa abilità è il cancello di qualità che impedisce il gonfiamento dei test generato dall'intelligenza artificiale.
