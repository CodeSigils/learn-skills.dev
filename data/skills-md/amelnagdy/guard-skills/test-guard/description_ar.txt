قم بمراجعة كود الاختبار الذي تم إنشاؤه أو تغييره وفقًا لقواعد الاختبار العامة قبل شحنه. من الأفضل استخدامه بشكل تفاعلي بعد قيام الوكيل بكتابة الاختبارات أو تحريرها أو إنشائها أو إعادة هيكلتها، قبل تقديمها أو الالتزام بها أو دمجها. استخدمه لـ pytest (test_*.py, *_test.py)، PHPUnit/Pest (*Test.php)، Jest/Vitest (*.test.ts، *.spec.js)، Go (*_test.go)، الملفات ضمن الاختبارات/، __tests__/، أو المواصفات/، وطلبات المراجعة مثل "كتابة اختبارات لـ X"، أو "إضافة اختبارات"، أو "اختبار هذا"، أو "مراجعة هذه الاختبارات"، أو فروق العلاقات العامة التي تحتوي على اختبارات. يمكن أيضًا توجيه كتابة الاختبار عند استدعائه صراحةً قبل العمل. هذه المهارة هي بوابة الجودة التي تمنع تضخم الاختبار الناتج عن الذكاء الاصطناعي.
