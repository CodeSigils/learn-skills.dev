Revise el código de prueba generado o modificado según las reglas de prueba universales antes de enviarlo. Se utiliza mejor de forma reactiva después de que un agente escribe, edita, genera o refactoriza pruebas, antes de presentarlas, confirmarlas o fusionarlas. Úselo para pytest (test_*.py, *_test.py), PHPUnit/Pest (*Test.php), Jest/Vitest (*.test.ts, *.spec.js), Go (*_test.go), archivos bajo tests/, __tests__/ o spec/, y revise solicitudes como 'escribir pruebas para X', 'agregar pruebas', 'probar esto', 'revisar estas pruebas' o diferencias de relaciones públicas que contengan pruebas. También puede guiar la redacción de pruebas cuando se invoca explícitamente antes del trabajo. Esta habilidad es la puerta de calidad que evita el exceso de pruebas generadas por la IA.
