Examinez le code de test généré ou modifié par rapport aux règles de test universelles avant son expédition. Il est préférable de l'utiliser de manière réactive après qu'un agent a écrit, modifié, généré ou refactorisé des tests, avant de les présenter, de les valider ou de les fusionner. À utiliser pour pytest (test_*.py, *_test.py), PHPUnit/Pest (*Test.php), Jest/Vitest (*.test.ts, *.spec.js), Go (*_test.go), les fichiers sous tests/, __tests__/ ou spec/, et examiner les demandes telles que « écrire des tests pour X », « ajouter des tests », « tester ceci », « réviser ces tests » ou des différences PR contenant des tests. Peut également guider l'écriture des tests lorsqu'il est explicitement invoqué avant le travail. Cette compétence est le portail de qualité qui empêche la surcharge des tests générés par l’IA.
