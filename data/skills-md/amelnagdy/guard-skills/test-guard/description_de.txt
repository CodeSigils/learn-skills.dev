Überprüfen Sie den generierten oder geänderten Testcode vor der Auslieferung anhand universeller Testregeln. Wird am besten reaktiv verwendet, nachdem ein Agent Tests geschrieben, bearbeitet, generiert oder umgestaltet hat, bevor er sie präsentiert, festschreibt oder zusammenführt. Verwendung für pytest (test_*.py, *_test.py), PHPUnit/Pest (*Test.php), Jest/Vitest (*.test.ts, *.spec.js), Go (*_test.go), Dateien unter tests/, __tests__/ oder spec/ und Überprüfungsanfragen wie „Tests für X schreiben“, „Tests hinzufügen“, „dies testen“, „diese Tests überprüfen“ oder PR-Diffs, die Tests enthalten. Kann auch das Schreiben von Tests anleiten, wenn dies ausdrücklich vor der Arbeit aufgerufen wird. Diese Fähigkeit ist das Qualitätstor, das eine durch die KI erzeugte Testaufblähung verhindert.
