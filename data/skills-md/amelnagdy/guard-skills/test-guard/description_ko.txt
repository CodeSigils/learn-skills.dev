출시되기 전에 범용 테스트 규칙에 따라 생성되거나 변경된 테스트 코드를 검토하세요. 에이전트가 테스트를 작성, 편집, 생성 또는 리팩터링한 후 테스트를 제시, 커밋 또는 병합하기 전에 반응적으로 사용하는 것이 가장 좋습니다. pytest(test_*.py, *_test.py), PHPUnit/Pest(*Test.php), Jest/Vitest(*.test.ts, *.spec.js), Go(*_test.go), test/, __tests__/ 또는 spec/ 아래의 파일에 사용하고 'X에 대한 테스트 작성', '테스트 추가', '이 테스트', '이 테스트 검토' 또는 테스트가 포함된 PR diff와 같은 요청을 검토합니다. 작업 전에 명시적으로 호출할 때 테스트 작성을 안내할 수도 있습니다. 이 스킬은 AI로 인한 테스트 부풀림을 방지하는 품질 게이트입니다.
