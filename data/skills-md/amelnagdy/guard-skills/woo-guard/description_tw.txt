在發貨之前檢查生成或更改的 WooCommerce 代碼 - 擴展、付款和運輸整合、結帳自訂以及訂單/產品邏輯。最好在代理商編寫、編輯或審查涉及 WooCommerce API 的程式碼後被動使用：wc_get_order、wc_get_orders、wc_get_product、WC() 購物車或會話、woocommerce_* 掛鉤、Store API 端點、支付網關、訂單或產品元、HPOS、訂閱或預訂。用於“查看此 Woo 插件”、“此 HPOS 是否相容”，或在“編寫 WooCommerce 擴充功能”、“新增結帳欄位”、“掛鉤訂單流程”或“更新庫存”等任務之後使用。強制執行 HPOS 安全訂單存取、直接元上的 CRUD、功能相容性聲明、伺服器端結帳驗證、資金處理規則以及範本覆蓋掛鉤。請勿用於沒有 WooCommerce API（使用 wp-guard）、通用程式碼審查（使用 clean-code-guard）、測試審查（使用 test-guard）或商店配置和管理螢幕問題的 WordPress 程式碼。
