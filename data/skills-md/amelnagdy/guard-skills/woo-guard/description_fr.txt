Examinez le code WooCommerce généré ou modifié (extensions, intégrations de paiement et d'expédition, personnalisations de paiement et logique de commande/produit) avant son expédition. Mieux utilisé de manière réactive après qu'un agent a écrit, modifié ou révisé le code touchant les API WooCommerce : wc_get_order, wc_get_orders, wc_get_product, panier ou session WC(), hooks woocommerce_*, points de terminaison de l'API du magasin, passerelles de paiement, méta de commande ou de produit, HPOS, abonnements ou réservations. Utilisez-le pour « examiner ce plugin Woo », « est-ce compatible HPOS » ou après des tâches telles que « écrire une extension WooCommerce », « ajouter un champ de paiement », « vous connecter au flux de commande » ou « mettre à jour le stock ». Applique un accès aux commandes sécurisé par HPOS, CRUD sur les méta directes, les déclarations de compatibilité des fonctionnalités, la validation du paiement côté serveur, la discipline de gestion de l'argent et les crochets sur les remplacements de modèles. NE PAS UTILISER pour le code WordPress sans les API WooCommerce (utilisez wp-guard), la révision de code générique (utilisez clean-code-guard), la révision de test (utilisez test-guard) ou la configuration du magasin et les questions sur l'écran d'administration.
