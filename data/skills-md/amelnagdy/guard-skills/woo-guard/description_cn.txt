在发货之前检查生成或更改的 WooCommerce 代码 - 扩展、付款和运输集成、结账自定义以及订单/产品逻辑。最好在代理编写、编辑或审查涉及 WooCommerce API 的代码后被动使用：wc_get_order、wc_get_orders、wc_get_product、WC() 购物车或会话、woocommerce_* 挂钩、Store API 端点、支付网关、订单或产品元、HPOS、订阅或预订。用于“查看此 Woo 插件”、“此 HPOS 是否兼容”，或在“编写 WooCommerce 扩展”、“添加结帐字段”、“挂钩订单流”或“更新库存”等任务之后使用。强制执行 HPOS 安全订单访问、直接元上的 CRUD、功能兼容性声明、服务器端结账验证、资金处理规则以及模板覆盖挂钩。请勿用于没有 WooCommerce API（使用 wp-guard）、通用代码审查（使用 clean-code-guard）、测试审查（使用 test-guard）或商店配置和管理屏幕问题的 WordPress 代码。
