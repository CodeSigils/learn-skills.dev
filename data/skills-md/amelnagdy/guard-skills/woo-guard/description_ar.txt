قم بمراجعة كود WooCommerce الذي تم إنشاؤه أو تغييره — الامتدادات، وعمليات تكامل الدفع والشحن، وتخصيصات الخروج، ومنطق الطلب/المنتج — قبل شحنه. من الأفضل استخدامه بشكل تفاعلي بعد قيام الوكيل بكتابة أو تحرير أو مراجعة التعليمات البرمجية التي تلامس واجهات برمجة تطبيقات WooCommerce: wc_get_order، أو wc_get_orders، أو wc_get_product، أو عربة التسوق أو الجلسة WC()، أو خطافات woocommerce_*، أو نقاط نهاية Store API، أو بوابات الدفع، أو تعريف الطلب أو المنتج، أو HPOS، أو الاشتراكات، أو الحجوزات. استخدمه في "مراجعة مكون Woo الإضافي"، أو "هل هذا HPOS متوافق"، أو بعد مهام مثل "كتابة ملحق WooCommerce"، أو "إضافة حقل دفع"، أو "الربط بتدفق الطلب"، أو "تحديث المخزون". يفرض الوصول الآمن إلى أوامر HPOS، وCRUD عبر التعريف المباشر، وإعلانات توافق الميزات، والتحقق من صحة الخروج من جانب الخادم، ونظام التعامل مع الأموال، والخطافات فوق تجاوزات القالب. لا تستخدمه مع تعليمات WordPress البرمجية بدون واجهات برمجة تطبيقات WooCommerce (استخدم wp-guard)، أو مراجعة التعليمات البرمجية العامة (استخدم Clean-code-guard)، أو المراجعة الاختبارية (استخدم test-guard)، أو تكوين المتجر وأسئلة شاشة المسؤول.
