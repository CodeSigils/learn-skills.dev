Revise el código WooCommerce generado o modificado (extensiones, integraciones de pago y envío, personalizaciones de pago y lógica de pedido/producto) antes de enviarlo. Se usa mejor de forma reactiva después de que un agente escribe, edita o revisa el código tocando las API de WooCommerce: wc_get_order, wc_get_orders, wc_get_product, carrito o sesión de WC(), ganchos de woocommerce_*, puntos finales de API de tienda, pasarelas de pago, meta de pedidos o productos, HPOS, suscripciones o reservas. Úselo en "revisar este complemento de Woo", "es compatible con HPOS" o después de tareas como "escribir una extensión de WooCommerce", "agregar un campo de pago", "conectarse al flujo de pedidos" o "actualizar stock". Hace cumplir el acceso seguro a pedidos HPOS, CRUD sobre meta directo, declaraciones de compatibilidad de funciones, validación de pago del lado del servidor, disciplina en el manejo de dinero y enlaces sobre anulaciones de plantillas. NO LO USE para código de WordPress sin las API de WooCommerce (use wp-guard), revisión de código genérico (use clean-code-guard), revisión de prueba (use test-guard) o configuración de la tienda y preguntas en la pantalla de administración.
