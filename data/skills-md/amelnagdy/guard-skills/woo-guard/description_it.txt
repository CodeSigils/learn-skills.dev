Controlla il codice WooCommerce generato o modificato (estensioni, integrazioni di pagamento e spedizione, personalizzazioni del checkout e logica di ordine/prodotto) prima che venga spedito. È preferibile utilizzarlo in modo reattivo dopo che un agente ha scritto, modificato o esaminato il codice toccando le API WooCommerce: wc_get_order, wc_get_orders, wc_get_product, carrello o sessione WC(), hook woocommerce_*, endpoint API Store, gateway di pagamento, meta di ordini o prodotti, HPOS, abbonamenti o prenotazioni. Utilizzalo su "rivedi questo plugin Woo", "è compatibile con HPOS" o dopo attività come "scrivi un'estensione WooCommerce", "aggiungi un campo di pagamento", "agganciati al flusso degli ordini" o "aggiorna stock". Applica l'accesso agli ordini sicuro HPOS, CRUD su meta diretta, dichiarazioni di compatibilità delle funzionalità, convalida del checkout lato server, disciplina di gestione del denaro e hook sulle sostituzioni dei modelli. NON UTILIZZARE per il codice WordPress senza API WooCommerce (usa wp-guard), revisione del codice generico (usa clean-code-guard), revisione del test (usa test-guard) o domande sulla configurazione del negozio e sulla schermata di amministrazione.
