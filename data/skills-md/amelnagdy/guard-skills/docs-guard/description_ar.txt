قم بمراجعة الوثائق التي تم إنشاؤها أو تغييرها قبل شحنها - الملفات التمهيدية، ومراجع واجهة برمجة التطبيقات، وسلاسل المستندات، وPHDoc/JSDoc، وسجلات التغيير، والبرامج التعليمية، ومواقع المستندات. من الأفضل استخدامه بشكل تفاعلي بعد قيام الوكيل بكتابة المستندات أو تحريرها، أو بعد تغيير التعليمات البرمجية للسلوك الموثق، أو قبل نشر المستندات. يُستخدم عندما يقول المستخدم "مراجعة المستندات"، أو "هل هذه الوثائق دقيقة"، أو "تحديث المستندات"، أو "اكتب ملف README"، أو "قم بتوثيق واجهة برمجة التطبيقات هذه"، أو "أضف سلسلة مستندات"، أو "أضف إدخال سجل التغيير". المهمة الأساسية: التحقق من كل وظيفة مرجعية وعلامة ونقطة نهاية ومفتاح التكوين ونموذج التعليمات البرمجية مقابل المصدر؛ التقاط انحراف المستندات مقابل التعليمات البرمجية؛ حشو الشريط وادعاءات لا يمكن التحقق منها. لا تستخدمه لمراجعة كود الإنتاج (استخدم حماية الكود النظيف)، أو مراجعة الاختبار (استخدم حماية الاختبار)، أو النسخ التسويقية أو منشورات المدونة، أو تحرير أسلوب النثر للكتابة غير التقنية، أو موضوعات موقع التوثيق.
