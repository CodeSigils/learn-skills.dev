Überprüfen Sie die generierte oder geänderte Dokumentation vor der Auslieferung – READMEs, API-Referenzen, Dokumentzeichenfolgen, PHPDoc/JSDoc, Änderungsprotokolle, Tutorials und Dokumentseiten. Am besten reaktiv verwendet werden, nachdem ein Agent Dokumente schreibt oder bearbeitet, nachdem Code das dokumentierte Verhalten geändert hat oder bevor Dokumente veröffentlicht werden. Wird verwendet, wenn der Benutzer sagt: „Überprüfen Sie die Dokumente“, „Ist diese Dokumentation korrekt“, „Aktualisieren Sie die Dokumente“, „Schreiben Sie eine README-Datei“, „Dokumentieren Sie diese API“, „Fügen Sie eine Dokumentzeichenfolge hinzu“ oder „Fügen Sie einen Änderungsprotokolleintrag hinzu“. Kernaufgabe: Überprüfen Sie alle referenzierten Funktionen, Flags, Endpunkte, Konfigurationsschlüssel und Codebeispiele anhand der Quelle. Dokument-vs-Code-Drift abfangen; Streifenfüller und nicht nachweisbare Behauptungen. NICHT VERWENDEN für die Überprüfung des Produktionscodes (verwenden Sie Clean-Code-Guard), die Testüberprüfung (verwenden Sie Test-Guard), für Marketingtexte oder Blogbeiträge, für die redaktionelle Bearbeitung nicht-technischer Texte oder für die Themengestaltung von Dokumentationsseiten.
