Revise la documentación generada o modificada antes de enviarla: archivos README, referencias de API, cadenas de documentación, PHPDoc/JSDoc, registros de cambios, tutoriales y sitios de documentación. Se utiliza mejor de forma reactiva después de que un agente escribe o edita documentos, después de que el código cambia el comportamiento documentado o antes de publicar documentos. Úselo cuando el usuario diga "revisar los documentos", "esta documentación es precisa", "actualizar los documentos", "escribir un archivo README", "documentar esta API", "agregar una cadena de documentación" o "agregar una entrada de registro de cambios". Trabajo principal: verificar cada función, indicador, punto final, clave de configuración y muestra de código a los que se hace referencia con la fuente; detectar la deriva entre documentos y códigos; relleno de tiras y afirmaciones no verificables. NO LO UTILICE para revisión de código de producción (use clean-code-guard), revisión de prueba (use test-guard), textos de marketing o publicaciones de blog, edición de estilo en prosa de escritos no técnicos o temas de sitios de documentación.
