Überprüfen Sie generierten oder geänderten Produktionscode vor der Auslieferung mithilfe von Clean Code, SOLID, DRY, KISS, YAGNI und LLM-spezifischen Fehlermodusprüfungen in jeder Programmiersprache. Wird am besten reaktiv verwendet, nachdem ein Agent Code geschrieben, bearbeitet, umgestaltet oder korrigiert, bevor das Ergebnis präsentiert, festgeschrieben oder zusammengeführt wird. Wird verwendet, wenn der Benutzer fragt: „Überprüfen Sie diese PR“, „Ist die Zusammenführung sicher?“, „Machen Sie dies sauberer“, „Überprüfen Sie diesen Code“, „Refaktorieren Sie dies“, „Beheben Sie diesen Fehler“ oder nachdem ein Codierungsagent Implementierungscode erstellt hat. Kann auch das Schreiben unterstützen, wenn es vor einer riskanten Bearbeitung explizit aufgerufen wird. NICHT für sachliche/konzeptionelle Fragen, CI/Tooling-Konfiguration, Git-Workflow, Ausführen/Debuggen von Tests, reine Architekturdiskussion, Prosaschreiben, Datenanalyse oder Testcode-Überprüfung verwenden (verwenden Sie test-guard).
