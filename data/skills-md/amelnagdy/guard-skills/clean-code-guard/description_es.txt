Revise el código de producción generado o modificado antes de su envío, utilizando verificaciones de modo de falla específicas de Clean Code, SOLID, DRY, KISS, YAGNI y LLM en cualquier lenguaje de programación. Se utiliza mejor de forma reactiva después de que un agente escribe, edita, refactoriza o corrige el código, antes de presentar, confirmar o fusionar el resultado. Úselo cuando el usuario pregunte "revisar este PR", "¿es seguro fusionarlo?", "hacerlo más limpio", "auditar este código", "refactorizar esto", "corregir este error" o después de que un agente de codificación haya producido un código de implementación. También puede guiar la escritura cuando se invoca explícitamente antes de una edición arriesgada. NO LO UTILICE para preguntas fácticas/conceptuales, configuración de CI/herramientas, flujo de trabajo de git, pruebas de ejecución/depuración, discusión pura de arquitectura, escritura en prosa, análisis de datos o revisión de código de prueba (use test-guard).
