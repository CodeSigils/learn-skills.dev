قم بمراجعة كود الإنتاج الذي تم إنشاؤه أو تغييره قبل شحنه، باستخدام عمليات فحص وضع الفشل الخاصة بـ Clean Code وSOLID وDRY وKISS وYAGNI وLLM بأي لغة برمجة. من الأفضل استخدامه بشكل تفاعلي بعد قيام الوكيل بكتابة التعليمات البرمجية أو تحريرها أو إعادة هيكلتها أو إصلاحها، قبل تقديم النتيجة أو الالتزام بها أو دمجها. يُستخدم عندما يسأل المستخدم "مراجعة هذه العلاقات العامة"، أو "هل هذا آمن للدمج؟"، أو "إجراء هذا التنظيف"، أو "تدقيق هذا الرمز"، أو "إعادة صياغة هذا"، أو "إصلاح هذا الخطأ"، أو بعد أن يقوم وكيل الترميز بإنتاج تعليمات برمجية للتنفيذ. يمكن أيضًا توجيه الكتابة عند استدعائها صراحةً قبل إجراء تعديل محفوف بالمخاطر. لا تستخدمه للأسئلة الواقعية/المفاهيمية، أو تكوين CI/الأدوات، أو سير عمل git، أو اختبارات التشغيل/تصحيح الأخطاء، أو مناقشة البنية البحتة، أو الكتابة النثرية، أو تحليل البيانات، أو مراجعة كود الاختبار (استخدم اختبار الحماية).
