قم بمراجعة كود WordPress الذي تم إنشاؤه أو تغييره - المكونات الإضافية والموضوعات والكتل - قبل شحنه. من الأفضل استخدامه بشكل تفاعلي بعد قيام الوكيل بكتابة أو تحرير أو مراجعة التعليمات البرمجية التي تلامس واجهات برمجة تطبيقات WordPress: add_action/add_filter، أو الرموز القصيرة، أو مربعات التعريف، أو معالجات AJAX، أو مسارات REST، أو WP_Query أو $wpdb، أو عناصر واجهة المستخدم، أو أوامر WP-CLI. استخدمه في "مراجعة هذا المكون الإضافي"، أو "هل هذا آمن للشحن"، أو "اجعل هذا قابلاً للترجمة"، أو "تسريع هذا الاستعلام"، أو بعد مهام مثل "كتابة مكون إضافي" أو "إضافة نقطة نهاية/رمز قصير/مربع تعريف". يفرض الهروب والتعقيم، والأرقام بالإضافة إلى فحوصات القدرة، واستعلامات قاعدة البيانات المعدة، والتطوير الأساسي لواجهة برمجة التطبيقات أولاً، والسلاسل الجاهزة للترجمة، ونظام الاستعلام/التخزين المؤقت. لا تستخدمه مع طلب أو منتج أو منطق سداد خاص بـ WooCommerce (استخدم woo-guard)، أو لغة PHP بخلاف WordPress، أو مراجعة جودة التعليمات البرمجية العامة (استخدم Clean-code-guard)، أو مراجعة كود الاختبار (استخدم test-guard)، أو تكوين الخادم أو الاستضافة، أو أسئلة WordPress المفاهيمية.
