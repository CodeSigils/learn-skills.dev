Controlla il codice WordPress generato o modificato (plugin, temi e blocchi) prima che venga spedito. È preferibile utilizzarlo in modo reattivo dopo che un agente ha scritto, modificato o esaminato il codice toccando le API WordPress: add_action/add_filter, shortcode, metabox, gestori AJAX, percorsi REST, WP_Query o $wpdb, widget o comandi WP-CLI. Utilizzare su "rivedi questo plugin", "è sicuro spedirlo", "rendilo traducibile", "accelera questa query" o dopo attività come "scrivi un plugin" o "aggiungi un endpoint/shortcode/meta box". Applica l'escape e la sanificazione, nonces e controlli di capacità, query di database preparate, sviluppo di API core, stringhe pronte per la traduzione e disciplina di query/caching. NON UTILIZZARE per logica di ordine, prodotto o pagamento specifica di WooCommerce (usa woo-guard), PHP non WordPress, revisione generica della qualità del codice (usa clean-code-guard), revisione del codice di test (usa test-guard), configurazione di server o hosting o domande concettuali su WordPress.
