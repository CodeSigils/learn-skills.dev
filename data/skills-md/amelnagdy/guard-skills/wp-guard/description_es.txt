Revise el código de WordPress generado o modificado (complementos, temas y bloques) antes de su envío. Se usa mejor de forma reactiva después de que un agente escribe, edita o revisa código tocando las API de WordPress: add_action/add_filter, códigos cortos, metaboxes, controladores AJAX, rutas REST, WP_Query o $wpdb, widgets o comandos WP-CLI. Úselo en 'revisar este complemento', 'es seguro enviar esto', 'hacer que esto sea traducible', 'acelerar esta consulta' o después de tareas como 'escribir un complemento' o 'agregar un punto final/código corto/metabox'. Implica escape y desinfección, comprobaciones de capacidad y nonces, consultas de bases de datos preparadas, desarrollo de API central primero, cadenas listas para traducción y disciplina de consulta/almacenamiento en caché. NO LO UTILICE para pedidos, productos o lógica de pago específicos de WooCommerce (use woo-guard), PHP que no sea de WordPress, revisión de calidad de código genérico (use clean-code-guard), revisión de código de prueba (use test-guard), configuración de servidor o hosting, o preguntas conceptuales de WordPress.
