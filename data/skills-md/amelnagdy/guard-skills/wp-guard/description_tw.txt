在發布之前檢查生成或更改的 WordPress 程式碼（外掛程式、主題和區塊）。最好在代理程式編寫、編輯或審查涉及 WordPress API 的程式碼後被動使用：add_action/add_filter、短代碼、元框、AJAX 處理程序、REST 路由、WP_Query 或 $wpdb、小部件或 WP-CLI 命令。用於“查看此插件”、“運送是否安全”、“使其可翻譯”、“加速此查詢”，或在“編寫插件”或“添加端點/短代碼/元框”等任務之後使用。強制轉義和清理、隨機數加功能檢查、準備好的資料庫查詢、核心 API 優先開發、翻譯就緒字串以及查詢/快取規則。請勿用於 WooCommerce 特定訂單、產品或結帳邏輯（使用 woo-guard）、非 WordPress PHP、通用程式碼品質審查（使用 clean-code-guard）、測試程式碼審查（使用 test-guard）、伺服器或主機配置或概念性 WordPress 問題。
