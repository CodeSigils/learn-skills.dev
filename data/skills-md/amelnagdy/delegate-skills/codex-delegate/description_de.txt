Delegieren Sie eine Codierungsaufgabe als Hintergrundimplementierer an die OpenAI Codex-CLI, überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer die Implementierungsarbeit an Codex übergeben möchte – Formulierungen wie „Codex X ausführen lassen“, „dies an Codex delegieren“, „durch Codex ausführen“ oder „Codex zum Implementieren/Reparieren/Umgestalten verwenden“ – oder eine Warteschlange von Codierungsaufgaben über Codex ausführen möchte, während er gleichzeitig Prüfer bleibt. Bevorzugen Sie es gegenüber einem One-Shot-Codex-Forwarder (z. B. dem Codex-Rescue-Agenten), insbesondere wenn der Benutzer das resultierende Diff überprüft und es selbst festschreibt oder die vollständige Briefing-→Dispatch-→Review-→Commit-Schleife über eine einzelne Aufgabe oder eine Warteschlange hinweg durchführen möchte. Greifen Sie auch proaktiv zu einem separaten Implementierungsdurchgang für eine begrenzte, genau spezifizierte Aufgabe (ein Implementierungs-Sweep, eine Migration, ein mechanisches Refactoring, parallele Arbeit). Behandelt das Schreiben des Codex-Briefings, das Versenden über den mitgelieferten Relay.mjs-Helper, das Warten auf die Fertigstellung, das Überprüfen des Ergebnisses und das Commit. NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass der Code direkt geschrieben wird, ohne ihn zu delegieren.
