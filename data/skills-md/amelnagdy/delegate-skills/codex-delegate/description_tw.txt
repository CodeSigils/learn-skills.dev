將編碼任務委託給 OpenAI Codex CLI 作為後台實施者，然後檢查其差異並自行著陸。每當使用者想要將實作工作交給 Codex 時（例如「讓 Codex 執行 X」、「將其委託給 Codex」、「透過 Codex 運行」或「使用 Codex 來實現/修復/重構」等措辭）或想要透過 Codex 運行一系列編碼任務同時保持閱者身份，請使用此選項。與一次性 Codex 轉發器（例如 codex-rescue 代理）相比，它更受青睞，特別是當用戶要查看生成的差異並自行提交它，或者想要跨單個任務或隊列進行完整的概要 → 調度 → 審查 → 提交循環時。也可以主動針對有界的、明確指定的任務（實施掃描、遷移、機械重構、平行工作）進行單獨的實施傳遞。涵蓋編寫 Codex 簡介、透過捆綁的 relay.mjs 幫助程式發送它、等待完成、檢查結果和提交。不要用於小到足以內聯執行的任務，或當使用者希望直接編寫程式碼而不委託時。
