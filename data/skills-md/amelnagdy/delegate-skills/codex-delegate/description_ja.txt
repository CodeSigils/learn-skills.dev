バックグラウンド実装者としてコーディング タスクを OpenAI Codex CLI に委任し、その差分を確認して自分で実行します。ユーザーが実装作業を Codex に渡したいとき (「Codex に X を実行してもらう」、「これを Codex に委任する」、「Codex を通じて実行する」、または「Codex を使用して実装/修正/リファクタリングを行う」などの表現) を希望する場合、またはレビュー担当者でありながら Codex を通じてコーディング タスクのキューを実行したい場合に、これを使用します。特にユーザーが結果の差分を確認して自分でコミットする場合、または単一のタスクまたはキューにわたる完全な概要→ディスパッチ→レビュー→コミットのループを必要とする場合には、ワンショットの Codex フォワーダー (コーデックス レスキュー エージェントなど) よりも優先してください。また、境界があり、明確に指定されたタスク (実装スイープ、移行、機械的リファクタリング、並行作業) での個別の実装パスについても、積極的に取得してください。 Codex概要の作成、バンドルされたrelay.mjsヘルパー経由でのディスパッチ、完了の待機、結果のレビュー、コミットについて説明します。インラインで実行できるほど小さいタスク、またはユーザーが委任せずにコードを直接記述したい場合には使用しないでください。
