Делегируйте задачу кодирования интерфейсу командной строки OpenAI Codex в качестве фонового реализатора, затем просмотрите ее различия и разместите ее самостоятельно. Используйте это всякий раз, когда пользователь хочет передать работу по реализации Кодексу — такие фразы, как «поручить Кодексу сделать X», «делегировать это Кодексу», «запустить это через Кодекс» или «использовать Кодекс для реализации/исправления/рефакторинга» – или хочет запустить очередь задач по кодированию через Кодекс, оставаясь рецензентом. Предпочитайте его однократному пересылку Кодекса (например, агенту спасения кодекса), особенно когда пользователь будет просматривать полученный результат и фиксировать его самостоятельно или хочет выполнить полный цикл краткого описания → отправки → проверки → фиксации для одной задачи или очереди. Также активно используйте его для отдельного прохода реализации ограниченной, четко определенной задачи (проверка реализации, миграция, механический рефакторинг, параллельная работа). Охватывает написание краткого описания Кодекса, его отправку через встроенный помощник реле.mjs, ожидание завершения, проверку результата и фиксацию. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточно небольших, чтобы их можно было выполнять в режиме реального времени, или когда пользователь хочет, чтобы код был написан напрямую, без делегирования.
