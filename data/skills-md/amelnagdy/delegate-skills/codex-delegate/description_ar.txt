قم بتفويض مهمة برمجة إلى OpenAI Codex CLI كمنفذ في الخلفية، ثم قم بمراجعة اختلافاتها وقم بتنفيذها بنفسك. استخدم هذا عندما يريد المستخدم تسليم أعمال التنفيذ إلى Codex - عبارات مثل "Have Codex do X"، أو "تفويض هذا إلى Codex"، أو "تشغيله من خلال Codex"، أو "استخدام Codex للتنفيذ/الإصلاح/إعادة البناء" - أو يريد تشغيل قائمة انتظار من مهام البرمجة من خلال Codex مع البقاء كمراجع. قم بتفضيله على معيد توجيه Codex لمرة واحدة (مثل وكيل إنقاذ المخطوطة) على وجه التحديد عندما يقوم المستخدم بمراجعة الفرق الناتج وتنفيذه بنفسه، أو يريد الموجز الكامل → إرسال → مراجعة → حلقة الالتزام عبر مهمة واحدة أو قائمة انتظار. يمكنك أيضًا الوصول إليه بشكل استباقي من أجل تمرير تنفيذ منفصل لمهمة محددة ومحددة جيدًا (مسح التنفيذ، والترحيل، وإعادة البناء الميكانيكي، والعمل الموازي). يغطي كتابة ملخص الدستور الغذائي، وإرساله عبر مساعد Relay.mjs المجمع، وانتظار الانتهاء، ومراجعة النتيجة، والالتزام. لا تستخدمه للمهام الصغيرة بما يكفي للقيام بها مباشرة، أو عندما يريد المستخدم كتابة التعليمات البرمجية مباشرة دون تفويض.
