将编码任务委托给 OpenAI Codex CLI 作为后台实施者，然后检查其差异并自行着陆。每当用户想要将实现工作交给 Codex 时（例如“让 Codex 执行 X”、“将其委托给 Codex”、“通过 Codex 运行”或“使用 Codex 来实现/修复/重构”等措辞）或者想要通过 Codex 运行一系列编码任务同时保持审阅者身份，请使用此选项。与一次性 Codex 转发器（例如 codex-rescue 代理）相比，它更受青睐，特别是当用户要查看生成的差异并自行提交它，或者想要跨单个任务或队列进行完整的概要 → 调度 → 审查 → 提交循环时。还可以主动针对有界的、明确指定的任务（实施扫描、迁移、机械重构、并行工作）进行单独的实施传递。涵盖编写 Codex 简介、通过捆绑的 relay.mjs 帮助程序发送它、等待完成、检查结果和提交。不要用于小到足以内联执行的任务，或者当用户希望直接编写代码而不委托时。
