Delegue una tarea de codificación a Kimi Code CLI (`kimi`) como implementador en segundo plano, luego revise su diferencia y conéctela usted mismo. Use esto siempre que el usuario quiera entregar el trabajo de implementación a Kimi (frases como "hacer que Kimi implemente X", "delegar esto a Kimi", "ejecutarlo a través del Código Kimi" o "usar Kimi para implementar/arreglar/refactorizar") - o quiera ejecutar una cola de tareas de codificación a través de Kimi mientras sigue siendo el revisor. NO LO UTILICE para tareas lo suficientemente pequeñas como para realizarlas en línea, o cuando el usuario quiera que el código se escriba directamente sin delegar.
