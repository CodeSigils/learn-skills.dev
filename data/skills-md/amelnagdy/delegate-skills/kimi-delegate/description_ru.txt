Делегируйте задачу кодирования Kimi Code CLI («kimi») в качестве фонового реализатора, затем просмотрите его различия и разместите его самостоятельно. Используйте это всякий раз, когда пользователь хочет передать работу по реализации Кими — такие фразы, как «попросить Кими реализовать X», «делегировать это Кими», «запустить это через Kimi Code» или «использовать Кими для реализации/исправления/рефакторинга» – или хочет запустить очередь задач по кодированию через Кими, оставаясь рецензентом. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточно небольших, чтобы их можно было выполнять в режиме реального времени, или когда пользователь хочет, чтобы код был написан напрямую, без делегирования.
