Delegieren Sie eine Codierungsaufgabe als Hintergrundimplementierer an die Kimi Code-CLI („kimi“), überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer die Implementierungsarbeit an Kimi übergeben möchte – Formulierungen wie „Kimi X implementieren lassen“, „dies an Kimi delegieren“, „durch Kimi-Code ausführen“ oder „Kimi zum Implementieren/Reparieren/Umgestalten verwenden“ – oder eine Warteschlange von Codierungsaufgaben über Kimi ausführen möchte, während er der Prüfer bleibt. NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass der Code direkt geschrieben wird, ohne ihn zu delegieren.
