Delegue una tarea de codificación a la CLI del código de comando (`cmd`) como implementador en segundo plano, luego revise su diferencia y conéctela usted mismo. Utilícelo siempre que el usuario quiera entregar el trabajo de implementación al Código de comando (frases como "hacer que el Código de comando haga X", "delegar esto al código de comando", "ejecutarlo a través de cmd" o "usar el Código de comando para implementar/arreglar/refactorizar"), o para ejecutar una cola de tareas de codificación a través del Código de comando sin dejar de ser el revisor. NO LO UTILICE para tareas lo suficientemente pequeñas como para realizarlas en línea, o cuando el usuario quiera que el código se escriba directamente sin delegar.
