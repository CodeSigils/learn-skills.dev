Déléguez une tâche de codage à la CLI Command Code (`cmd`) en tant qu'implémenteur en arrière-plan, puis examinez sa différence et effectuez-la vous-même. Utilisez-le chaque fois que l'utilisateur souhaite confier le travail d'implémentation au code de commande - des expressions telles que "faire en sorte que le code de commande fasse X", "déléguer cela au code de commande", "l'exécuter via cmd" ou "utiliser le code de commande pour implémenter/réparer/refactoriser" - ou pour exécuter une file d'attente de tâches de codage via le code de commande tout en restant le réviseur. NE PAS UTILISER pour des tâches suffisamment petites pour être exécutées en ligne, ou lorsque l'utilisateur souhaite que le code soit écrit directement sans déléguer.
