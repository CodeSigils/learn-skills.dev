قم بتفويض مهمة ترميز إلى Command Code CLI (`cmd`) كمنفذ في الخلفية، ثم قم بمراجعة اختلافاتها وقم بتنفيذها بنفسك. استخدم هذا عندما يريد المستخدم تسليم أعمال التنفيذ إلى Command Code - عبارات مثل "لديك Command Code do X" أو "تفويض هذا إلى Commandcode" أو "تشغيله من خلال cmd" أو "استخدام Command Code للتنفيذ/الإصلاح/إعادة البناء" - أو لتشغيل قائمة انتظار من مهام البرمجة من خلال Command Code مع البقاء كمراجع. لا تستخدمه للمهام الصغيرة بما يكفي للقيام بها مباشرة، أو عندما يريد المستخدم كتابة التعليمات البرمجية مباشرة دون تفويض.
