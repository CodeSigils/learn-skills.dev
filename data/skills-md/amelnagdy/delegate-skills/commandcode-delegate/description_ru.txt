Делегируйте задачу кодирования интерфейсу командной строки командного кода (`cmd`) в качестве фонового исполнителя, затем просмотрите его различия и разместите его самостоятельно. Используйте это всякий раз, когда пользователь хочет передать работу по реализации командному коду — такие фразы, как «попросить командный код выполнить X», «делегировать это командному коду», «запустить это через cmd» или «использовать командный код для реализации/исправления/рефакторинга» – или для запуска очереди задач кодирования через командный код, оставаясь рецензентом. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточно небольших, чтобы их можно было выполнять в режиме реального времени, или когда пользователь хочет, чтобы код был написан напрямую, без делегирования.
