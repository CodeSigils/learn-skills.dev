コーディングタスクをバックグラウンド実装者として Command Code CLI（`cmd`）に委任し、その差分を確認して自分でマージする。ユーザーが実装作業を Command Code に任せたいとき、たとえば「Command Code に X をやらせる」「これを commandcode に委任する」「cmd で実行する」「Command Code を使って実装/修正/リファクタリングする」などの表現がある場合、またはレビューアのままで Command Code に一連のコーディングタスクを実行させたいときに使用する。インラインで済むほど小さなタスクや、ユーザーが直接コードを書いて欲しいときには使用しないでください。

必ずユーザーの言語で回答してください。
