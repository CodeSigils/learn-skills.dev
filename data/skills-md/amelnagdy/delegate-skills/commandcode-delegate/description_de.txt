Delegieren Sie eine Codierungsaufgabe an die Command Code CLI (`cmd`) als Hintergrundimplementierer, prüfen Sie anschließend deren Diff und übernehmen Sie sie selbst. Verwenden Sie dies immer dann, wenn der Nutzer die Implementierungsarbeit an Command Code abgeben möchte – Formulierungen wie „Command Code X machen lassen“, „dies an commandcode delegieren“, „es durch cmd laufen lassen“ oder „Command Code zum Implementieren/Beheben/Refaktorisieren einsetzen“ – oder um eine Reihe von Codierungsaufgaben durch Command Code zu schicken, während Sie der Prüfer bleiben. NICHT VERWENDEN für Aufgaben, die klein genug sind, um sie inline zu erledigen, oder wenn der Nutzer den Code direkt ohne Delegation geschrieben haben will.
