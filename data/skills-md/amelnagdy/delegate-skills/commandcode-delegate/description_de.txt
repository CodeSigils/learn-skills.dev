Delegieren Sie eine Codierungsaufgabe als Hintergrundimplementierer an die Befehlscode-CLI („cmd“), überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer die Implementierungsarbeit an Command Code übergeben möchte – Formulierungen wie „Befehlscode X ausführen lassen“, „dies an Befehlscode delegieren“, „über cmd ausführen“ oder „Befehlscode zum Implementieren/Reparieren/Umgestalten verwenden“ – oder um eine Warteschlange von Codierungsaufgaben über Befehlscode auszuführen, während er der Prüfer bleibt. NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass der Code direkt geschrieben wird, ohne ihn zu delegieren.
