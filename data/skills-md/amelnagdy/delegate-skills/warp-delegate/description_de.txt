Delegieren Sie eine Codierungsaufgabe als Hintergrundimplementierer an die Warp Agent-CLI („oz“), überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer die Implementierungsarbeit an Warp übergeben möchte – Formulierungen wie „Lass Warp NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, wenn der Benutzer möchte, dass der Code direkt ohne Delegierung geschrieben wird, oder für die interaktive „Warp“-TUI (diese Fähigkeit steuert den kopflosen „oz-Agent-Lauf“, nicht die Terminal-App).
