バックグラウンド実装者としてコーディング タスクを Warp Agent CLI (`oz`) に委任し、その差分を確認して自分で実行します。ユーザーが実装作業を Warp に渡したいとき (「Warp に X を実装してもらう」、「これを Warp CLI に委任する」、「Warp を通じて実行する」、「実装/修正/リファクタリングに oz を使用する」などの表現) を希望する場合、またはレビュー担当者のままで Warp を通じてコーディング タスクのキューを実行したい場合に、これを使用します。インラインで実行できるほど小さいタスク、ユーザーが委任せずにコードを直接記述したい場合、または対話型の「ワープ」TUI (このスキルはターミナル アプリではなく、ヘッドレスの「oz エージェント実行」を駆動します)には使用しないでください。
