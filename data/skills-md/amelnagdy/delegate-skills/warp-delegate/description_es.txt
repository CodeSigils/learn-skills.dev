Delegue una tarea de codificación a la CLI de Warp Agent (`oz`) como implementador en segundo plano, luego revise su diferencia y conéctela usted mismo. Use esto siempre que el usuario quiera entregar el trabajo de implementación a Warp (frases como "hacer que Warp implemente X", "delegar esto a la CLI de Warp", "ejecutarlo a través de Warp", "usar oz para implementar/arreglar/refactorizar") - o quiera ejecutar una cola de tareas de codificación a través de Warp mientras sigue siendo el revisor. NO LO UTILICE para tareas lo suficientemente pequeñas como para realizarlas en línea, cuando el usuario desea que el código se escriba directamente sin delegar, o para la TUI interactiva `warp` (esta habilidad impulsa la ejecución del agente oz sin cabeza, no la aplicación de terminal).
