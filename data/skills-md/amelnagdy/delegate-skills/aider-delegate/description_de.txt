Delegieren Sie eine Codierungsaufgabe an Aider („aider“) als Hintergrundimplementierer, überprüfen Sie dann dessen Diff und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer die Implementierungsarbeit an Aider übergeben möchte – Formulierungen wie „Aider soll X machen“, „dies an Aider delegieren“, „durch Aider ausführen“ oder „Aider zum Implementieren/Reparieren/Umgestalten verwenden“ – oder eine Warteschlange von Codierungsaufgaben über Aider ausführen lassen, während er gleichzeitig Prüfer bleibt. Dazu gehört die Aufforderung an Aider, einen lokalen oder selbst gehosteten OpenAI-kompatiblen Endpunkt zu steuern („Aider mein lokales Modell verwenden lassen“, „Aider gegen llama.cpp / Ollama / vLLM / LM Studio ausführen“), den Aider über „--api-base“ erreicht. NICHT für lokale Modell- oder Codierungsanfragen verwenden, die Aider nicht nennen, für Aufgaben, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass der Code direkt ohne Delegierung geschrieben wird.
