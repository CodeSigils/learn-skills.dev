Delegieren Sie eine Codierungsaufgabe an Oh My Pi („omp“) als Hintergrundimplementierer, überprüfen Sie dann dessen Diff und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer die Implementierungsarbeit an Oh My Pi / omp delegieren möchte – Formulierungen wie „omp muss X implementieren“, „dies an oh my pi delegieren“, „durch omp ausführen“, „oh-my-pi zum Implementieren/Reparieren/Umgestalten verwenden“ – oder eine Warteschlange von Codierungsaufgaben über omp ausführen möchte, während er der Prüfer bleibt. NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, wenn der Benutzer möchte, dass der Code direkt ohne Delegierung geschrieben wird, oder wenn er die ursprüngliche Pi-CLI („pi“) meint – das ist pi-delegate.
