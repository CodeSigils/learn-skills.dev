Делегируйте задачу кодирования Oh My Pi (`omp`) в качестве фонового реализатора, затем просмотрите ее различия и реализуйте ее самостоятельно. Используйте это всякий раз, когда пользователь хочет делегировать работу по реализации Oh My Pi / omp - такие фразы, как «попросить omp реализовать X», «делегировать это oh my pi», «запустить это через omp», «использовать oh-my-pi для реализации/исправления/рефакторинга» - или хочет запустить очередь задач по кодированию через omp, оставаясь рецензентом. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточно маленьких, чтобы их можно было выполнять в режиме реального времени, когда пользователь хочет, чтобы код был написан напрямую, без делегирования, или когда он имеет в виду исходный Pi CLI («pi») — то есть pi-delegate.
