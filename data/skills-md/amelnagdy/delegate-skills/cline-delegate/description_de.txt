Delegieren Sie eine Codierungsaufgabe als Hintergrundimplementierer an die Cline-Coding-Agent-CLI („cline“), überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer die Implementierungsarbeit an Cline delegieren möchte – Formulierungen wie „Lass Cline X implementieren“, „delegiere dies an Cline“, „führe es über Cline aus“ oder „verwende Cline zum Implementieren/Reparieren/Umgestalten“ – oder möchte eine Warteschlange von Codierungsaufgaben über Cline ausführen, während er der Prüfer bleibt. NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass der Code direkt geschrieben wird, ohne ihn zu delegieren.
