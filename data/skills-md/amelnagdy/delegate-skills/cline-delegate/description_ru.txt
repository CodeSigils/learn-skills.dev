Делегируйте задачу кодирования CLI агента кодирования Cline («cline») в качестве фонового реализатора, затем просмотрите его различия и разместите его самостоятельно. Используйте это всякий раз, когда пользователь хочет делегировать работу по реализации Cline — такие фразы, как «попросить Cline реализовать X», «делегировать это cline», «запустить это через Cline» или «использовать cline для реализации/исправления/рефакторинга» – или хочет запустить очередь задач кодирования через Cline, оставаясь рецензентом. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточно небольших, чтобы их можно было выполнять в режиме реального времени, или когда пользователь хочет, чтобы код был написан напрямую, без делегирования.
