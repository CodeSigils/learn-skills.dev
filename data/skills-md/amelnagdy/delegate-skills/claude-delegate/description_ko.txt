코딩 작업을 별도의 Claude Code CLI 프로세스 또는 다른 Claude 세션에 구현자로 위임한 다음 차이점을 검토하고 직접 결정하세요. 사용자가 Claude Code, 다른 Claude 세션 또는 `claude` CLI에 구현을 위임하도록 명시적으로 요청하는 경우에만 사용합니다. 예를 들어 "다른 Claude가 이것을 구현하도록 하세요", "이것을 Claude Code에 위임하세요" 또는 "별도의 Claude 세션을 통해 이 대기열을 실행하세요." 단순히 현재 오케스트레이터가 클로드라는 이유만으로 트리거하지 말고, 사용자가 현재 클로드에게 위임 없이 직접 구현해 달라고 요청하는 경우에는 사용하지 마세요.
