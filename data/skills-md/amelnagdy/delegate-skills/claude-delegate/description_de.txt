Delegieren Sie eine Codierungsaufgabe als Implementierer an einen separaten Claude Code-CLI-Prozess oder eine andere Claude-Sitzung, überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies nur, wenn der Benutzer ausdrücklich darum bittet, die Implementierung an Claude Code, eine andere Claude-Sitzung oder die „claude“-CLI zu delegieren – zum Beispiel „Lassen Sie dies von einem anderen Claude implementieren“, „delegieren Sie dies an Claude Code“ oder „führen Sie diese Warteschlange über eine separate Claude-Sitzung aus.“ Nicht nur deshalb auslösen, weil der aktuelle Orchestrator Claude ist, und nicht verwenden, wenn der Benutzer den aktuellen Claude auffordert, direkt ohne Delegierung zu implementieren.
