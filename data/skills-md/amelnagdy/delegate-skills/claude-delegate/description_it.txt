Delega un'attività di codifica a un processo CLI Claude Code separato o a un'altra sessione Claude come implementatore, quindi rivedi le sue differenze e eseguilo tu stesso. Utilizzare solo quando l'utente chiede esplicitamente di delegare l'implementazione a Claude Code, a un'altra sessione di Claude o alla CLI `claude`, ad esempio "chiedi a un altro Claude di implementarlo", "delega questo a Claude Code" o "esegui questa coda attraverso una sessione di Claude separata." Non attivare semplicemente perché l'attuale orchestratore è Claude e non utilizzare quando l'utente chiede all'attuale Claude di implementare direttamente senza delega.
