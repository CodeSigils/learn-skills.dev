Делегируйте задачу кодирования отдельному процессу Claude Code CLI или другому сеансу Claude в качестве исполнителя, затем просмотрите его разницу и разместите его самостоятельно. Используйте только тогда, когда пользователь явно просит делегировать реализацию Claude Code, другому сеансу Claude или CLI `claude` — например, «попросить другого Claude реализовать это», «делегировать это Claude Code» или «запустить эту очередь через отдельный сеанс Claude». Не запускайте только потому, что текущий оркестратор — Claude, и не используйте, когда пользователь просит текущий Claude реализовать напрямую без делегирования.
