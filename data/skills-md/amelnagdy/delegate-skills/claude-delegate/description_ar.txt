قم بتفويض مهمة برمجة إلى عملية Claude Code CLI منفصلة أو إلى جلسة Claude أخرى كمنفذ، ثم قم بمراجعة اختلافاتها وقم بتنفيذها بنفسك. يُستخدم فقط عندما يطلب المستخدم صراحةً تفويض التنفيذ إلى Claude Code، أو جلسة Claude أخرى، أو واجهة سطر الأوامر `clude` - على سبيل المثال، "اجعل Claude آخر ينفذ هذا"، أو "تفويض هذا إلى Claude Code"، أو "تشغيل قائمة الانتظار هذه من خلال جلسة Claude منفصلة." لا تقم بالتشغيل لمجرد أن المنسق الحالي هو Claude، ولا تستخدمه عندما يطلب المستخدم من Claude الحالي التنفيذ مباشرة دون تفويض.
