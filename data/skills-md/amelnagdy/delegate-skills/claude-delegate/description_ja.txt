コーディング タスクを別の Claude Code CLI プロセスまたは実装者としての別の Claude セッションに委任し、その差分を確認して自分で実行します。ユーザーが実装をクロード コード、別のクロード セッション、または「claude」 CLI に委任することを明示的に要求した場合にのみ使用します。たとえば、「別のクロードにこれを実装させる」、「これをクロード コードに委任する」、「別のクロード セッションを通じてこのキューを実行する」などです。現在のオーケストレーターがクロードであるという理由だけでトリガーしないでください。また、ユーザーが現在のクロードに委任せずに直接実装するよう依頼する場合には使用しないでください。
