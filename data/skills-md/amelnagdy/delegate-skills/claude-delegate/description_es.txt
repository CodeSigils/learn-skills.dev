Delegue una tarea de codificación a un proceso CLI de Claude Code separado u otra sesión de Claude como implementador, luego revise su diferencia y conéctela usted mismo. Úselo solo cuando el usuario solicite explícitamente delegar la implementación a Claude Code, a otra sesión de Claude o a la CLI `claude`; por ejemplo, "hacer que otro Claude implemente esto", "delegar esto a Claude Code" o "ejecutar esta cola a través de una sesión de Claude separada". No lo active simplemente porque el orquestador actual sea Claude, y no lo use cuando el usuario le solicite al Claude actual que lo implemente directamente sin delegación.
