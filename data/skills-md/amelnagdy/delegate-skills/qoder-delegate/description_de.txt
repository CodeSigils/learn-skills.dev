Delegieren Sie eine Codierungsaufgabe als Hintergrundimplementierer an die Qoder-CLI („qodercli“), überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer darum bittet, dass Qoder Codierungsaufgaben implementiert, korrigiert, umgestaltet oder eine Warteschlange ausführt, während der Orchestrator der Prüfer bleibt. NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass Code direkt ohne Delegation geschrieben wird.
