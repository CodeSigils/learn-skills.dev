Delegieren Sie eine Codierungsaufgabe als Hintergrundimplementierer an die Google Antigravity CLI („agy“), überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer die Implementierungsarbeit an Antigravity oder Agy übergeben möchte – Formulierungen wie „Antigravity X ausführen lassen“, „dies an Agy delegieren“, „durch Agy ausführen lassen“ oder „Antigravity zum Implementieren/Reparieren/Umgestalten verwenden“ – oder eine Warteschlange von Codierungsaufgaben über Agy ausführen lassen möchte, während er der Prüfer bleibt. NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass der Code direkt geschrieben wird, ohne ihn zu delegieren.
