Delegieren Sie eine Codierungsaufgabe als Hintergrundimplementierer an die Z.AI ZCode-CLI, überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer die Implementierungsarbeit an ZCode übergeben möchte – Formulierungen wie „Lass ZCode NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass der Code direkt geschrieben wird, ohne ihn zu delegieren.
