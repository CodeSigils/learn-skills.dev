Делегируйте задачу кодирования OpenCode CLI в качестве фонового реализатора, затем просмотрите ее различия и реализуйте ее самостоятельно. Используйте это всякий раз, когда пользователь хочет передать работу по реализации OpenCode — такие фразы, как «попросить OpenCode сделать X», «делегировать это OpenCode», «запустить это через OpenCode» или «использовать OpenCode для реализации/исправления/рефакторинга» – или хочет запустить очередь задач кодирования через OpenCode, оставаясь при этом рецензентом. Предпочитайте, чтобы пользователь сам просматривал различия и фиксировал их. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточно небольших, чтобы их можно было выполнять в режиме реального времени, или когда пользователь хочет, чтобы код был написан напрямую, без делегирования.
