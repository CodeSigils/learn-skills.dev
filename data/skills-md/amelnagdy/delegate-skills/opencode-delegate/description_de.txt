Delegieren Sie eine Codierungsaufgabe als Hintergrundimplementierer an die OpenCode-CLI, überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer die Implementierungsarbeit an OpenCode übergeben möchte – Formulierungen wie „OpenCode muss Bevorzugen Sie es, wenn der Benutzer das Diff überprüft und es selbst festschreibt. NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass der Code direkt geschrieben wird, ohne ihn zu delegieren.
