Делегируйте задачу написания кода интерфейсу командной строки Grok Build в качестве фонового исполнителя, затем просмотрите его различия и разместите его самостоятельно. Используйте это всякий раз, когда пользователь хочет передать работу по реализации Grok — такие фразы, как «попросить Grok сделать X», «делегировать это Grok», «запустить это через Grok», «использовать Grok Build для реализации/исправления/рефакторинга» или «попросить Grok CLI сделать это» – или для запуска очереди задач по кодированию через Grok, оставаясь рецензентом. Предпочитайте, чтобы пользователь сам просматривал различия и фиксировал их. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточно небольших, чтобы их можно было выполнять в режиме реального времени, или когда пользователь хочет, чтобы код был написан напрямую, без делегирования.
