バックグラウンド実装者としてコーディング タスクを Grok Build CLI に委任し、その差分を確認して自分で実行します。ユーザーが実装作業を Grok に渡したいときは常にこれを使用します (「Grok に X を実行してもらう」、「これを Grok に委任する」、「Grok を通じて実行する」、「Grok Build を使用して実装/修正/リファクタリングを行う」、または「grok CLI にこれを実行させる」などの表現)、またはレビュー担当者のままで Grok を介してコーディング タスクのキューを実行する場合に使用します。ユーザーが差分を確認して自分でコミットする場合に優先します。インラインで実行できるほど小さいタスク、またはユーザーが委任せずにコードを直接記述したい場合には使用しないでください。
