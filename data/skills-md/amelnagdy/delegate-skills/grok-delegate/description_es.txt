Delegue una tarea de codificación a Grok Build CLI como implementador en segundo plano, luego revise su diferencia y conéctela usted mismo. Use esto siempre que el usuario quiera entregar el trabajo de implementación a Grok (frases como "hacer que Grok haga X", "delegar esto a Grok", "ejecutarlo a través de Grok", "usar Grok Build para implementar/reparar/refactorizar" o "hacer que la CLI de Grok haga esto"), o para ejecutar una cola de tareas de codificación a través de Grok sin dejar de ser el revisor. Prefiere que el usuario revise la diferencia y la confirme él mismo. NO LO UTILICE para tareas lo suficientemente pequeñas como para realizarlas en línea, o cuando el usuario quiera que el código se escriba directamente sin delegar.
