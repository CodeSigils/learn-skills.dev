Delegieren Sie eine Codierungsaufgabe als Hintergrundimplementierer an die GitHub Copilot-CLI („Copilot“), überprüfen Sie dann den Unterschied und landen Sie ihn selbst. Verwenden Sie dies immer dann, wenn der Benutzer Implementierungsarbeiten an Copilot delegieren möchte – Formulierungen wie „Copilot X implementieren lassen“, „dies an Copilot delegieren“, „über Copilot CLI ausführen“ oder „Copilot zum Implementieren/Reparieren/Umgestalten verwenden“ – oder eine Warteschlange von Codierungsaufgaben über Copilot ausführen möchte, während er der Prüfer bleibt. NICHT für Aufgaben verwenden, die klein genug sind, um sie inline auszuführen, oder wenn der Benutzer möchte, dass der Code direkt geschrieben wird, ohne ihn zu delegieren.
