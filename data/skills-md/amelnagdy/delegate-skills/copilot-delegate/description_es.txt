Delegue una tarea de codificación a GitHub Copilot CLI ("copilot") como implementador en segundo plano, luego revise su diferencia y conéctela usted mismo. Utilice esto siempre que el usuario quiera delegar el trabajo de implementación a Copilot (frases como "hacer que Copilot implemente X", "delegar esto a copilot", "ejecutarlo a través de Copilot CLI" o "usar copilot para implementar/arreglar/refactorizar") o quiera ejecutar una cola de tareas de codificación a través de Copilot mientras sigue siendo el revisor. NO LO UTILICE para tareas lo suficientemente pequeñas como para realizarlas en línea, o cuando el usuario quiera que el código se escriba directamente sin delegar.
