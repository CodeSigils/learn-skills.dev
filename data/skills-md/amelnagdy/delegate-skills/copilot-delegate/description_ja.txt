バックグラウンド実装者としてコーディング タスクを GitHub Copilot CLI (「copilot」) に委任し、その差分を確認して自分で実行します。ユーザーが実装作業を Copilot に委任したい場合 (「Copilot に X を実装させる」、「これを copilot に委任する」、「Copilot CLI を介して実行する」、または「copilot を使用して実装/修正/リファクタリングを行う」などの表現) を希望する場合、またはレビュー担当者でありながら Copilot を介してコーディング タスクのキューを実行したい場合に、これを使用します。インラインで実行できるほど小さいタスク、またはユーザーが委任せずにコードを直接記述したい場合には使用しないでください。
