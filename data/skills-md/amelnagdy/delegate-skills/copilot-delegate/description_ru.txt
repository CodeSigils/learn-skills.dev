Делегируйте задачу кодирования GitHub Copilot CLI («copilot») в качестве фонового реализатора, затем просмотрите его различия и разместите его самостоятельно. Используйте это всякий раз, когда пользователь хочет делегировать работу по реализации Copilot — такие фразы, как «попросить Copilot реализовать X», «делегировать это второму пилоту», «запустить это через Copilot CLI» или «использовать второй пилот для реализации/исправления/рефакторинга» – или хочет запустить очередь задач кодирования через Copilot, оставаясь рецензентом. НЕ ИСПОЛЬЗУЙТЕ для задач, достаточно небольших, чтобы их можно было выполнять в режиме реального времени, или когда пользователь хочет, чтобы код был написан напрямую, без делегирования.
