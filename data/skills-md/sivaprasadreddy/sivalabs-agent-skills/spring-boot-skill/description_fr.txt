Créez des applications Spring Boot 4.x en suivant les meilleures pratiques.  Utilisez cette compétence :
  * Lors du développement d'applications Spring Boot à l'aide de Spring MVC, Spring Data JPA, Spring Modulith, Spring Security
  * Pour créer la structure de package Spring Boot recommandée
  * Pour implémenter des API REST, des entités/dépôts, une couche de service, des monolithes modulaires
  * Pour utiliser les modèles de vue Thymeleaf pour créer des applications Web
  * Écrire des tests pour les API REST et les applications Web
  * Pour écrire des tests ArchUnit pour tester l'architecture
  * Pour configurer les plugins et configurations recommandés pour améliorer la qualité du code et tester lors de l'utilisation de Maven.
  * Pour utiliser le support Docker Compose de Spring Boot pour le développement local
  * Pour créer un fichier de tâches pour une exécution plus facile des tâches courantes tout en travaillant avec une application Spring Boot
