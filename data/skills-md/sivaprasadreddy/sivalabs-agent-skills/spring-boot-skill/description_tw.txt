按照最佳實踐建立 Spring Boot 4.x 應用程式。  使用這個技能：
  * 使用 Spring MVC、Spring Data JPA、Spring Modulith、Spring Security 開發 Spring Boot 應用程式時
  * 創建推薦的Spring Boot套件結構
  * 實作 REST API、實體/儲存庫、服務層、模組化整體
  * 使用 Thymeleaf 視圖模板建立 Web 應用程式
  * 為 REST API 和 Web 應用程式編寫測試
  * 編寫ArchUnit測試來測試架構
  * 配置建議的插件和配置以提高程式碼品質，並使用Maven進行測試。
  * 使用Spring Boot的Docker Compose支援進行本地開發
  * 建立任務檔案以便在使用 Spring Boot 應用程式時更輕鬆地執行常見任務
