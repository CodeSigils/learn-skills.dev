Создавайте приложения Spring Boot 4.x, следуя лучшим практикам.  Используйте этот навык:
  * При разработке приложений Spring Boot с использованием Spring MVC, Spring Data JPA, Spring Modulith, Spring Security.
  * Чтобы создать рекомендуемую структуру пакета Spring Boot.
  * Для реализации REST API, сущностей/репозиториев, сервисного уровня, модульных монолитов.
  * Чтобы использовать шаблоны представлений Thymeleaf для создания веб-приложений.
  * Написание тестов для REST API и веб-приложений.
  * Написать тесты ArchUnit для тестирования архитектуры.
  * Для настройки рекомендуемых плагинов и конфигураций для улучшения качества кода и тестирования при использовании Maven.
  * Чтобы использовать поддержку Docker Compose Spring Boot для локальной разработки.
  * Чтобы создать Taskfile для упрощения выполнения общих задач при работе с приложением Spring Boot.
