Crea applicazioni Spring Boot 4.x seguendo le best practice.  Usa questa abilità:
  *Quando si sviluppano applicazioni Spring Boot utilizzando Spring MVC, Spring Data JPA, Spring Modulith, Spring Security
  * Per creare la struttura del pacchetto Spring Boot consigliata
  * Per implementare API REST, entità/repository, livello di servizio, monoliti modulari
  * Per utilizzare i modelli di visualizzazione Thymeleaf per la creazione di applicazioni web
  * Scrivere test per API REST e applicazioni Web
  * Scrivere test ArchUnit per testare l'architettura
  * Per configurare i plug-in e le configurazioni consigliati per migliorare la qualità del codice e testare durante l'utilizzo di Maven.
  * Per utilizzare il supporto Docker Compose di Spring Boot per lo sviluppo locale
  * Per creare Taskfile per un'esecuzione più semplice di attività comuni mentre si lavora con un'applicazione Spring Boot
