Cree aplicaciones Spring Boot 4.x siguiendo las mejores prácticas.  Usa esta habilidad:
  * Al desarrollar aplicaciones Spring Boot utilizando Spring MVC, Spring Data JPA, Spring Modulith, Spring Security
  * Para crear la estructura del paquete Spring Boot recomendada
  * Para implementar API REST, entidades/repositorios, capa de servicio, monolitos modulares
  * Para utilizar plantillas de vista de Thymeleaf para crear aplicaciones web
  * Escribir pruebas para API REST y aplicaciones web.
  * Escribir pruebas de ArchUnit para probar la arquitectura.
  * Configurar los complementos y configuraciones recomendados para mejorar la calidad del código y las pruebas mientras se usa Maven.
  * Para utilizar el soporte Docker Compose de Spring Boot para el desarrollo local
  * Para crear Taskfile para una ejecución más sencilla de tareas comunes mientras se trabaja con una aplicación Spring Boot
