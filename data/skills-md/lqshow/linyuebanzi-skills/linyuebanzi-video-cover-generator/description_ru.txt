На основе видеосценария создайте вертикальную обложку с соотношением сторон 3:4 для видеоаккаунта Линь Юэбаньцзы (LQ)/коротких видеороликов Доуинь/Сяохуншу. Используйте его, когда пользователю нужно создать обложку для короткого видео, добавить миниатюру или создать вертикальное изображение заголовка. Триггерные слова включают в себя: сделать обложку видео, создать обложку видео, обложку видеоаккаунта, обложку Douyin, обложку видео Xiaohongshu, вертикальную обложку, обложку 3:4, короткое изображение заголовка видео. Даже если пользователь говорит только «помогите мне сделать обложку для этого видео» или «обложка еще не готова», если контекст предполагает публикацию короткого видео, она должна сработать. Используйте API Nano Banana2 от MuleRun для создания, используя аватар LQ в качестве эталонного изображения, предлагая 11 дополнительных визуальных стилей (стиль заголовка в стиле темных технологий по умолчанию), создавая вертикальную обложку, соответствующую вирусным шаблонам платформ коротких видео. Не используйте его для широкоформатных заголовков общедоступных аккаунтов (2,35:1), девятисеток WeChat Moments, аватаров, плакатов или других сценариев обложек коротких видео, отличных от 3:4; этот навык обрабатывает только вертикальные обложки коротких видео формата 3:4.
