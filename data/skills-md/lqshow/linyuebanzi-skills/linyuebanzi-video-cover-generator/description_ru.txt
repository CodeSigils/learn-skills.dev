На основе видеосценария создайте вертикальную обложку с соотношением сторон 3:4 для видеоаккаунта Линь Юэ Баньцзы (LQ)/коротких видеороликов Douyin/Redbook. Используйте это, когда пользователю нужна обложка для короткого видео, миниатюра или вертикальное изображение заголовка. Триггерные фразы включают в себя: создать обложку видео, создать обложку видео, обложку видеоаккаунта, обложку Douyin, обложку видео Redbook, вертикальную обложку, обложку 3:4, короткое изображение заголовка видео. Даже если пользователь говорит только «помогите мне сделать обложку для этого видео» или «обложка еще не готова», если контекст предполагает публикацию короткого видео, она должна сработать. Используйте API Nano Banana 2 от MuleRun для создания, используя аватар LQ в качестве эталонного изображения, предлагая 11 выбираемых визуальных стилей (стиль темных технологий по умолчанию), создавая вертикальную обложку, которая соответствует тенденциям популярности платформы коротких видео. Не используйте его для широкоформатных заголовков общедоступных аккаунтов (2,35:1), сеток WeChat Moments, аватаров, плакатов или других сценариев обложек коротких видео, отличных от формата 3:4; этот навык обрабатывает только вертикальные обложки коротких видео формата 3:4.
