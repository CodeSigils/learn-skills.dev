自动识别林月半子（LQ）技术长篇文章中的插图位置，并生成16:9概念图、流程图、对比图和架构图。支持七种视觉风格：手绘网格笔记本风格（notebook）、专业平面信息图表（infographic）、现代高科技商务风格（executive-tech）、温馨手绘卡片风格（cozy-handdrawn）、科技涂鸦风格（tech-doodle）、卡通信息图表风格（cartoon-infographic）和白板草图风格（whiteboard-sketch）。当用户需要向已写好的文章添加插图、添加图片、优化布局或使长文本不那么单调时使用。触发词包括：添加插图、添加图片、添加一些图像、让文章更生动、布局优化、文章太单调、为文章画几张手绘图、手绘原理图、信息图表、商业风格插图、科技商业风格。该技能的核心价值是“智能地识别文章中的哪些段落值得插图”——它优先考虑四种类型的内容：抽象概念、流程循环、比较分类和架构组件，而不是机械地对每个段落进行插图。使用 MuleRun Nano Banana 2 Generation API 生成，支持通过 --style 切换视觉样式。请勿用于封面图像（封面技能）、屏幕截图替换、纯代码显示或模因生成。
