Convert any subject knowledge point into a vertical educational infographic (9:16). The user only needs to input a knowledge point name (e.g., “acoustic phenomena,” “Pythagorean theorem,” “photosynthesis”), and the Skill automatically completes: identifying the subject/grade/chapter, breaking down 3–5 core sub‑concepts, assigning a thematic color scheme, generating specific illustration descriptions for each sub‑concept, constructing a complete prompt, and invoking linyuebanzi‑image‑gen to generate the image. It includes a built‑in two‑layer subject accuracy check: before image generation, self‑check the prompt against a subject‑specific checklist; after generation, read back the PNG for visual verification (text/formula/diagram). If it fails, it automatically retries, ensuring the content delivered to students is accurate. It provides illustration guidelines for physics (sound, light, heat, force, electricity, lenses, mechanical motion), mathematics, chemistry, biology, Chinese language, history, English, and other subjects. Batch generation is supported—e.g., “all chapters of the first semester of eighth‑grade physics” will be generated chapter by chapter, each chapter with a different color scheme but a unified style. Trigger phrases include: make an infographic, knowledge card, subject diagram, physics infographic, chemistry infographic, make a knowledge map, draw a knowledge card, turn this knowledge point into an image.
