Convierta cualquier punto de conocimiento de una materia en una infografía educativa vertical (9:16). El usuario solo necesita ingresar un nombre de punto de conocimiento (por ejemplo, "fenómeno de sonido", "teorema de Pitágoras", "fotosíntesis") y la habilidad se completa automáticamente: identifica el tema/grado/capítulo, lo divide en 3 a 5 subconceptos básicos, asigna una combinación de colores al tema, genera descripciones de ilustraciones específicas para cada subconcepto, construye un mensaje completo y llama a linyuebanzi-image-gen para generar la imagen. Comprobación de precisión del sujeto de doble capa incorporada: antes de generar la imagen, verifique automáticamente el mensaje con una lista de verificación específica del sujeto; después de la generación, vuelva a leer el PNG para verificación visual (texto/fórmulas/diagramas), vuelva a intentarlo automáticamente si falla, asegurando que el contenido entregado a los estudiantes sea preciso. Incluye pautas ilustrativas para física (sonido/luz/calor/fuerza/electricidad/lentes/movimiento mecánico), matemáticas, química, biología, idioma chino, historia, inglés y otras materias. Admite la generación por lotes: "todos los capítulos del primer semestre de física de octavo grado" se generarán capítulo por capítulo, cada capítulo con una combinación de colores diferente pero un estilo unificado. Las frases desencadenantes incluyen: "hacer una infografía", "tarjeta de conocimientos", "diagrama temático", "infografía de física", "infografía de química", "hacer un mapa de conocimientos", "dibujar una tarjeta de conocimientos", "convertir este punto de conocimiento en una imagen". No lo use para presentaciones interactivas dinámicas (use la habilidad de presentación interactiva), imágenes de portada de artículos (use linyuebanzi-cover-generator) o ilustraciones de artículos dibujadas a mano (use linyuebanzi-inline-diagram).
