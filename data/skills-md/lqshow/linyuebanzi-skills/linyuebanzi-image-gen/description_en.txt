General image generation execution layer, supporting three image generation APIs: MuleRun Nano Banana 2, APImart GPT Image 2, and Atlas Cloud GPT Image 2. Switch via --provider. Supports generation (text‑only image generation) and edit (image editing with a reference image) modes, for single or batch execution. This is an infrastructure skill invoked by other skills, not directly facing end users. When other skills (such as cover-hero, inline-diagram) need to call the image‑generation API, they invoke this skill’s scripts/generate.py. Do not use it for: prompt writing, style injection, business validation—these are the responsibility of the calling skill.
