Capa de ejecución de generación de imágenes general, que admite tres API de generación de imágenes: MuleRun Nano Banana 2, APImart GPT Image 2 y Atlas Cloud GPT Image 2. Cambie a través de --provider. Admite los modos de generación (generación de imágenes de solo texto) y edición (edición de imágenes con una imagen de referencia), para ejecución única o por lotes. Esta es una habilidad de infraestructura invocada por otras habilidades, que no se enfrentan directamente a los usuarios finales. Cuando otras habilidades (como cover-hero, inline-diagram) necesitan llamar a la API de generación de imágenes, invocan scripts/generate.py de esta habilidad. No lo use para: redacción rápida, inyección de estilo, validación comercial; estas son responsabilidad de la habilidad de llamada.
