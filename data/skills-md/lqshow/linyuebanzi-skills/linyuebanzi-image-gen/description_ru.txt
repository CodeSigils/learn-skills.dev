Общий уровень выполнения создания изображений, поддерживающий три API создания изображений: MuleRun Nano Banana 2, APImart GPT Image 2 и Atlas Cloud GPT Image 2. Переключение через --provider. Поддерживает режимы генерации (генерация только текстового изображения) и редактирования (редактирование изображения с помощью эталонного изображения) для одиночного или пакетного выполнения. Это инфраструктурный навык, который задействуется другими навыками и не имеет прямого отношения к конечным пользователям. Когда другим навыкам (таким как Cover-Hero, Inline-diagram) необходимо вызвать API генерации изображений, они вызывают скрипты этого навыка/generate.py. Не используйте его для: быстрого написания, внедрения стиля, бизнес-проверки — за это отвечает вызывающий навык.
