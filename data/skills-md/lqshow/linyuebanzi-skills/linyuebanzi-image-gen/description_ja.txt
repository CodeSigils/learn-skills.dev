一般的なイメージ生成実行レイヤー。MuleRun Nano Banana 2、APImart GPT Image 2、Atlas Cloud GPT Image 2 の 3 つのイメージ生成 API をサポートします。 --provider 経由で切り替えます。単一またはバッチ実行の生成 (テキストのみの画像生成) モードと編集 (参照画像を使用した画像編集) モードをサポートします。これは他のスキルによって呼び出されるインフラストラクチャ スキルであり、エンド ユーザーと直接対面するものではありません。他のスキル (カバーヒーロー、インラインダイアグラムなど) が画像生成 API を呼び出す必要がある場合、このスキルの scripts/generate.py を呼び出します。プロンプト作成、スタイル挿入、ビジネス検証には使用しないでください。これらは呼び出し側スキルの責任です。
