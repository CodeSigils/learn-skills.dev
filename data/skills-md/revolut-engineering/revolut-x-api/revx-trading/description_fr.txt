Passation, remplacement et annulation de commande Revolut X. À utiliser lorsque l'utilisateur demande de « passer une commande », « acheter du BTC », « vendre de l'ETH », « un ordre au marché », « un ordre limité », « remplacer l'ordre », « modifier l'ordre », « annuler l'ordre », « annuler tous les ordres », ou exécute les commandes revx order place, revx order replace ou revx order Cancel.
