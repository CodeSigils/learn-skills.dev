Erstellen und schärfen Sie das Domänenmodell und die allgegenwärtige Sprache eines Projekts, während Sie Software planen oder ändern. Verwenden Sie es, wenn der Benutzer Glossararbeit, eine Sprache mit begrenztem Kontext, eine Bereinigung der Domänenterminologie, ADR-würdige Entscheidungen oder Dokumente wünscht, die die Produktsprache mit dem Code in Einklang bringen.
