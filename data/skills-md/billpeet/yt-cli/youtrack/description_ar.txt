يدير مشكلات YouTrack واللوحات الذكية والمشاريع والمستخدمين عبر yt CLI. يُستخدم عند البحث عن مشكلات YouTrack أو إنشائها أو تحديثها أو التعليق عليها، أو إدراج لوحات أو مشروعات Agile، أو تعيين مشكلة إلى لوحة Agile، أو تعيين مشكلة رئيسية لمسارات السباحة القائمة على الميزات. تشغيل عبارات مثل "مشكلة YouTrack"، أو "إنشاء تذكرة"، أو "مشكلات البحث"، أو "تحديث المشكلة"، أو "إضافة تعليق إلى"، أو "قائمة المشاريع"، أو "لوحات القائمة"، أو "لوحة Agile"، أو "المشكلة الرئيسية".
