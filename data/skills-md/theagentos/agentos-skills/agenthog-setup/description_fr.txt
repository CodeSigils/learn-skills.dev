Installez le SDK AgentHog et le traçage des câbles dans le projet : initialisez au démarrage, encapsulez la boucle de l'agent principal, ajoutez des variables d'environnement, vérifiez qu'une première trace atterrit. À utiliser lorsque l'utilisateur demande de « configurer Agenthog », « d'ajouter le traçage d'Agenthog », « d'instrumenter avec Agenthog », « d'ajouter de l'observabilité », de « câbler le traçage » ou « d'ajouter le traçage à cette application ».
