Расширение Vitest с помощью Midscene для тестирования пользовательского интерфейса на основе искусственного интеллекта в Интернете (Playwright), Android (ADB) и iOS (WDA). Создает новые проекты, преобразует существующие проекты и создает/обновляет/отлаживает/запускает E2E-тесты с использованием взаимодействия с пользовательским интерфейсом на естественном языке. Триггеры: тест записи, добавление теста, создание теста, обновление теста, исправление теста, отладка теста, запуск теста, тест e2e, промежуточный тест, новый проект, преобразование проекта, инициализация проекта,调试测试, 运行测试, 新建工程, 转化工程.
