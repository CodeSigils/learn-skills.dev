Tiger Brokers OpenAPI Python SDK – compétences complètes pour les outils de codage d’IA. Couvre la configuration du SDK, les requêtes de données de marché, le trading d'actions/futures/options, les abonnements push en temps réel, l'outil de ligne de commande CLI et l'intégration du serveur MCP. À utiliser lors de la création d'applications de trading, de l'interrogation de données de marché, du passage d'ordres, de l'utilisation de la CLI Tigeropen ou de l'intégration de l'API Tiger Brokers avec des éditeurs d'IA.
Il s'agit de la version OpenAPI Python SDK. Il s'agit d'un serveur MCP et d'une API Tigeropen CLI.集成到 AI 编辑器。
