Tiger Brokers OpenAPI Python SDK – umfassende Kenntnisse für KI-Codierungstools. Umfasst SDK-Einrichtung, Marktdatenabfragen, Aktien-/Futures-/Optionshandel, Echtzeit-Push-Abonnements, CLI-Befehlszeilentool und MCP-Serverintegration. Verwenden Sie es, wenn Sie Handelsanwendungen erstellen, Marktdaten abfragen, Aufträge erteilen, die Tigeropen-CLI verwenden oder die Tiger Brokers API mit KI-Editoren integrieren.
Die Verwendung des OpenAPI Python SDK ist die neueste Version des OpenAPI Python SDK命令行工具、MCP Server 集成。适用于构建交易应用、查询行情数据、下单交易、使用 tigeropen CLI、或将老虎 API集成到 AI 编辑器.
