Tiger Brokers OpenAPI Java SDK - مهارات كاملة لأدوات ترميز الذكاء الاصطناعي. يغطي إعداد SDK، واستعلامات بيانات السوق، وتداول الأسهم/العقود الآجلة/الخيارات، واشتراكات الدفع في الوقت الفعلي، وإدارة الحساب، وأمثلة الإستراتيجية. يُستخدم عند إنشاء تطبيقات تداول Java، أو الاستعلام عن بيانات السوق، أو تقديم الطلبات، أو دمج واجهة برمجة تطبيقات Tiger Brokers.
قم بتنزيل OpenAPI Java SDK واحصل على المزيد من SDK جافا تم إنشاء التطبيق، وتم إنشاءه بواسطة واجهة برمجة التطبيقات (API).
