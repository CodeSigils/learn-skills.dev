Tiger Brokers OpenAPI Java SDK — полные навыки работы с инструментами кодирования ИИ. Охватывает настройку SDK, запросы рыночных данных, торговлю акциями/фьючерсами/опционами, push-подписки в реальном времени, управление учетными записями и примеры стратегий. Используйте при создании торговых приложений Java, запросе рыночных данных, размещении заказов или интеграции API Tiger Brokers.
Загрузите OpenAPI Java SDK и используйте SDK配置、行情查询、股票/期货/期权交易、实时推送订阅、账户管理、策略示例。适用于构建Java-интерфейс API.
