Tiger Brokers OpenAPI Rust SDK - مجموعة أدوات كاملة لأدوات البرمجة بالذكاء الاصطناعي. يتضمن إعداد SDK واستعلامات بيانات السوق غير المتزامنة والتداول والاشتراكات الفورية. يُستخدم عند إنشاء تطبيقات التداول في Rust، أو الاستعلام عن بيانات السوق، أو تقديم الطلبات، أو دمج واجهة برمجة تطبيقات Tiger Brokers.
