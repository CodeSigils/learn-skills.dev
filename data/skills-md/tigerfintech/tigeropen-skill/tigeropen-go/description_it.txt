Tiger Brokers OpenAPI Go SDK: kit di strumenti completo per assistenti di codifica AI. Copre la configurazione dell'SDK, le query sui dati di mercato, il trading di azioni/future/opzioni, le sottoscrizioni push in tempo reale e le chiamate API grezze. Da utilizzare quando si creano app di trading in Go, si recuperano dati di mercato, si effettuano ordini o si integra l'API Tiger Brokers.
