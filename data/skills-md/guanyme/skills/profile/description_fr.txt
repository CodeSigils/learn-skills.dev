À utiliser lorsque vous travaillez sur des projets frontaux, des outils JavaScript/TypeScript, des outils Python, la configuration de projets, l'installation de dépendances, le formatage, le peluchage, les tests, l'exécution de commandes ou la gestion de l'environnement d'exécution. Couvre la pile préférée et les commandes par défaut pour fnm, ni, nr, npx, na, uv, uvx, éditeur, shell, Git, alias et style de code. Préférez la documentation de l'agent local du projet pour les chaînes d'outils spécifiques au projet, fnm pour les versions de nœud, ni pour les installations de dépendances, nr pour les scripts de package, npx pour les outils de nœud uniques courants, na create pour les échafaudages create-* pris en charge en utilisation manuelle, pnpm create pour les échafaudages d'agents non interactifs, sauf indication contraire, et uv/uvx pour les dépendances Python et les outils Python uniques ; évitez les installations globales de pip.
