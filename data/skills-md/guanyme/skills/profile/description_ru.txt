Используйте при работе над внешними проектами, инструментами JavaScript/TypeScript, инструментами Python, настройкой проекта, установкой зависимостей, форматированием, анализом, тестированием, выполнением команд или управлением средой выполнения. Охватывает предпочтительные команды стека и команды по умолчанию для fnm, ni, nr, npx, na, uv, uvx, редактора, оболочки, Git, псевдонимов и стиля кода. Предпочитайте документацию локального агента проекта для цепочек инструментов, специфичных для проекта, fnm для версий Node, ni для установки зависимостей, nr для сценариев пакетов, npx для общих одноразовых инструментов Node, na create для поддерживаемых шаблонов create-* при ручном использовании, pnpm create для неинтерактивных шаблонов агентов, если не указано иное, и uv/uvx для зависимостей Python и одноразовых инструментов Python; избегайте глобальных установок pip.
