يُستخدم عند العمل على مشاريع الواجهة الأمامية، أو أدوات JavaScript/TypeScript، أو أدوات Python، أو إعداد المشروع، أو تثبيت التبعية، أو التنسيق، أو الفحص، أو الاختبار، أو تنفيذ الأوامر، أو إدارة بيئة وقت التشغيل. يغطي المكدس المفضل والأوامر الافتراضية لـ fnm، وni، وnr، وnpx، وna، وuv، وuvx، وeditor، وshell، وGit، والأسماء المستعارة، ونمط التعليمات البرمجية. تفضيل توثيق الوكيل المحلي للمشروع لسلاسل الأدوات الخاصة بالمشروع، وfnm لإصدارات Node، وni لعمليات تثبيت التبعية، وnr للبرامج النصية للحزمة، وnpx لأدوات العقدة الشائعة لمرة واحدة، وإنشاء سقالات إنشاء* مدعومة في الاستخدام اليدوي، وإنشاء pnpm لسقالات الوكيل غير التفاعلية ما لم يُقال خلاف ذلك، وuv/uvx لتبعيات Python وأدوات Python لمرة واحدة؛ تجنب عمليات تثبيت النقاط العالمية.
