استخدم Perplexity API للبحث والبحث في مجال الذكاء الاصطناعي على الويب. يُستخدم عندما يحتاج المستخدم إلى معلومات محدثة، أو تفكير متعدد الخطوات مع اقتباسات الويب، أو بحث شامل مع مراجع المصدر، أو استعلامات واقعية مع الأحداث الجارية، أو تحليل تنافسي. الافتراضي عندما يذكر المستخدم الحيرة، أو يحتاج إلى معلومات حالية، أو يتطلب الاستشهادات بالمصادر.
