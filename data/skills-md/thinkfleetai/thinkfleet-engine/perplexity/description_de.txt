Verwenden Sie die Perplexity API für webbasierte KI-Suche und -Recherche. Verwenden Sie es, wenn der Benutzer aktuelle Informationen, mehrstufige Argumentation mit Web-Zitaten, umfassende Recherchen mit Quellenangaben, sachliche Abfragen zu aktuellen Ereignissen oder Wettbewerbsanalysen benötigt. Standardmäßig, wenn der Benutzer Perplexity erwähnt, aktuelle Informationen benötigt oder Quellenangaben benötigt.
