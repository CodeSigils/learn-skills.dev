Une compétence pour créer et gérer les configurations de Home Assistant. À utiliser lors de l'utilisation de la CLI Home Assistant Builder (`hab`) pour inspecter, créer, mettre à jour, supprimer, exploiter ou dépanner les ressources de Home Assistant ; lorsqu'un utilisateur mentionne hab, l'automatisation CLI de Home Assistant, les modifications Lovelace/dashboard, les aides, les automatisations, les scripts, les sauvegardes, les opérations ESPHome ou Home Assistant à partir d'un terminal.
