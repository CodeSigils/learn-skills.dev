Una habilidad para crear y administrar configuraciones de Home Assistant. Úselo cuando utilice la CLI de Home Assistant Builder (`hab`) para inspeccionar, crear, actualizar, eliminar, operar o solucionar problemas de recursos de Home Assistant; cuando un usuario menciona hab, automatización CLI de Home Assistant, ediciones de Lovelace/panel, ayudantes, automatizaciones, scripts, copias de seguridad, ESPHome u operaciones de Home Assistant desde una terminal.
