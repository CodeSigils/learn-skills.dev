Предоставляет комплексное руководство по базе данных Oracle, включая SQL, PL/SQL, функции, настройку производительности (AWR/ASH), резервное копирование (RMAN), Data Guard и RAC. Используйте, когда пользователь спрашивает об Oracle, ему нужно написать Oracle SQL, работать с PL/SQL или управлять базами данных Oracle.
