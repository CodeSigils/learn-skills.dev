Fournit des conseils complets pour la base de données Oracle, notamment SQL, PL/SQL, les fonctions, le réglage des performances (AWR/ASH), la sauvegarde (RMAN), Data Guard et RAC. À utiliser lorsque l'utilisateur pose des questions sur Oracle, doit écrire Oracle SQL, travailler avec PL/SQL ou gérer des bases de données Oracle.
