يوفر إرشادات شاملة لـ Redis بما في ذلك هياكل البيانات (string/hash/list/set/zset/geo/hyperloglog/bitmap/stream)، والأوامر الشائعة مع الأمثلة، وأنماط التخزين المؤقت، والثبات (RDB/AOF)، والنسخ المتماثل والحارس، والكتلة، والبرمجة النصية لـ Lua، والمعاملات، والنشر/الفرع، وخطوط الأنابيب، وتشديد الأمان، وأفضل ممارسات الإنتاج. يُستخدم عندما يسأل المستخدم عن Redis، أو يحتاج إلى تنفيذ التخزين المؤقت، أو اختيار هياكل بيانات Redis، أو تكوين الثبات أو المجموعة، أو استكشاف أخطاء أداء Redis وإصلاحها.
