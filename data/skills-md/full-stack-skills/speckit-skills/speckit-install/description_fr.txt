Installez la CLI Specify sur la machine hôte (installation de l'outil uv ou uvx unique) ; prend en charge plusieurs systèmes d'exploitation, une installation persistante ou unique, ainsi que des environnements d'entreprise ou de réseau restreint. À utiliser lorsque l'utilisateur dit « installer Spec Kit », « installer Specify CLI » ou « spécifier la commande introuvable ».
