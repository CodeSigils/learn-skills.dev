Pianifica l'installazione del motore Docker con LinuxMirrors su host Linux, sostituisci il repository del software DockerCE e configura i mirror del registro Docker, coprendo la selezione della versione, le installazioni esistenti, la sostituzione del solo registro, più URL mirror, l'unione di daemon.json, la convalida del servizio e il rollback. Gli utenti fanno riferimento a usingdocker.sh, DockerInstallation.sh, accelerazione pull Docker o all'opzione`--only-registry`; le modifiche regolari al repository di sistema non utilizzano questa abilità.
