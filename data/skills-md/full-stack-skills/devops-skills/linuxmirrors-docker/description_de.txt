Planen Sie die Installation der LinuxMirrors Docker Engine, den Austausch des Docker CE-Repositorys und die Docker Registry Mirror-Konfiguration für Linux-Hosts. Dabei werden Versionsauswahl, vorhandene Installationen, reiner Registrierungsaustausch, mehrere Spiegeladressen, Daemon.json-Zusammenführung, Dienstüberprüfung und Rollback abgedeckt. Benutzer erwähnten die Verwendung von docker.sh, DockerInstallation.sh, Docker-Pull-Beschleunigung oder „--only-registry“; Regelmäßige System-Repository-Änderungen nutzen diese Fähigkeit nicht.
