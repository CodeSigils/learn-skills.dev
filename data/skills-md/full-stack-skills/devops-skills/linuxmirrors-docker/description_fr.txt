Planifiez l'installation du moteur Docker de LinuxMirrors, le remplacement du référentiel Docker CE et la configuration de Docker Registry Mirror pour les hôtes Linux, couvrant la sélection de version, les installations existantes, le remplacement du registre uniquement, les adresses miroir multiples, la fusion de daemon.json, la validation du service et la restauration. Les utilisateurs mentionnent l'utiliser avec docker.sh, DockerInstallation.sh, l'accélération Docker pull ou `--only-registry` ; les modifications du référentiel système standard n'utilisent pas cette compétence.
