Спланируйте установку LinuxMirrors Docker Engine на хосты Linux, замените источники программного обеспечения Docker CE и настройте Docker Registry Mirror, включая переопределение выбора версии, существующие установки, замену только реестра, несколько адресов зеркала, объединение daemon.json, проверку службы и откат. Пользователи упоминают использование docker.sh, DockerInstallation.sh, ускорения извлечения Docker или `--only-registry`; обычные изменения исходного кода системного программного обеспечения не используют эту возможность.
