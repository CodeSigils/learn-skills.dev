Linux ホストへの LinuxMirrors Docker エンジンのインストールを計画し、Docker CE ソフトウェア ソースを置き換え、バージョン選択のオーバーライド、既存のインストール、レジストリのみの置換、複数のミラー アドレス、daemon.json のマージ、サービスの検証、ロールバックをカバーする Docker レジストリ ミラーの構成を行います。ユーザーは、docker.sh、Dockerinstallation.sh、Docker pull アクセラレーション、または `--only-registry` の使用について言及しています。通常のシステム ソフトウェア ソースの変更では、この機能は使用されません。
