Cargo for Rust パッケージとワークスペースを構成、操作、診断、自動化します。マニフェストとターゲット、コマンド、依存関係の解決と機能、プロファイル、ビルド スクリプト、構成変数と環境変数、キャッシュとビルド診断、クロスコンパイル、レジストリ、パッケージ化、公開、メタデータ、CI 再現性、安定機能ゲートと夜間機能ゲートをカバーします。 Cargo.toml、Cargo.lock、.cargo/config.toml、cargo build/check/run/tree/metadata/package/publish、リゾルバーまたは機能の問題、ビルド出力とパフォーマンス、プライベート レジストリ、および初心者向け Cargo ワークフローに使用します。クレートの選択とサプライチェーンの監査をrust-依存関係に、ワークスペース・トポロジーをrust-workspaceに、テスト設計をrust-testingに、ドキュメント設計をrust-documentationに、lintポリシーをrust-style-clippyに、API互換性の決定をrust-semverにルーティングします。
