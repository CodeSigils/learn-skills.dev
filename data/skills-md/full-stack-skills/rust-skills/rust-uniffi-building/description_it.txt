Costruisci, genera, testa, crea pacchetti e risolvi i problemi dei componenti Rust condivisi e dei collegamenti multipiattaforma con Mozilla UniFFI. Utilizzalo automaticamente quando gli utenti desiderano scrivere la logica aziendale una volta in Rust e richiamarla o riutilizzarla da Swift, iOS, macOS, Kotlin, Android, JVM, Python, Ruby, JavaScript, browser, app desktop o più piattaforme, anche quando non menzionano UniFFI; quando chiedono di collegare, esporre, connettere o condividere Rust con Swift/Kotlin/Android/iOS; o quando necessitano di selezione di macro procedurali rispetto a UDL, record, enumerazioni, errori, oggetti, tratti, callback, tipi personalizzati, uniffi.toml, uniffi-bindgen, esportazioni asincrone, diagnostica di associazione generata, caricamento della libreria nativa, packaging, ABI o aggiornamenti. Verificare che la release UniFFI bloccata supporti ogni target richiesto; percorso scritto a mano C ABI lavoro per ruggine-unsafe-ffi.
