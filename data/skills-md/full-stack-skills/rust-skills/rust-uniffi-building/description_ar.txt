قم ببناء وإنشاء واختبار وحزم واستكشاف أخطاء مكونات Rust المشتركة والارتباطات عبر الأنظمة الأساسية باستخدام Mozilla UniFFI. يُستخدم تلقائيًا عندما يريد المستخدمون كتابة منطق الأعمال مرة واحدة في Rust واستدعاءه أو إعادة استخدامه من Swift أو iOS أو macOS أو Kotlin أو Android أو JVM أو Python أو Ruby أو JavaScript أو المتصفحات أو تطبيقات سطح المكتب أو منصات متعددة - حتى عندما لا يذكرون UniFFI؛ عندما يطلبون ربط Rust أو كشفه أو الاتصال به أو مشاركته مع Swift/Kotlin/Android/iOS؛ أو عندما يحتاجون إلى تحديد الماكرو الإجرائي مقابل تحديد UDL، أو السجلات، أو التعدادات، أو الأخطاء، أو الكائنات، أو السمات، أو عمليات الاسترجاعات، أو الأنواع المخصصة، أو uniffi.toml، أو uniffi-bindgen، أو الصادرات غير المتزامنة، أو تشخيصات الربط التي تم إنشاؤها، أو تحميل المكتبة الأصلية، أو التعبئة والتغليف، أو ABI، أو الترقيات. التحقق من أن إصدار UniFFI المقفل يدعم كل هدف مطلوب؛ قم بتوجيه عمل C ABI المكتوب بخط اليد إلى Rust-unsafe-ffi.
