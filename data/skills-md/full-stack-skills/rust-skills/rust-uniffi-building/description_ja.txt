Mozilla UniFFI との共有 Rust コンポーネントおよびクロスプラットフォーム バインディングを構築、生成、テスト、パッケージ化、トラブルシューティングします。ユーザーが一度 Rust でビジネス ロジックを作成し、それを Swift、iOS、macOS、Kotlin、Android、JVM、Python、Ruby、JavaScript、ブラウザー、デスクトップ アプリ、または複数のプラットフォームから呼び出したり再利用したりする場合に、UniFFI について言及していなくても、自動的に使用します。 Rust を Swift/Kotlin/Android/iOS とブリッジ、公開、接続、または共有するよう要求されたとき。または、手続き型マクロと UDL の選択、レコード、列挙型、エラー、オブジェクト、特性、コールバック、カスタム タイプ、uniffi.toml、unifi-bindgen、非同期エクスポート、生成されたバインディング診断、ネイティブ ライブラリの読み込み、パッケージ化、ABI、またはアップグレードが必要な場合です。ロックされた UniFFI リリースが要求された各ターゲットをサポートしていることを確認します。手書きの C ABI 作業を Rust-unsafe-ffi にルーティングします。
