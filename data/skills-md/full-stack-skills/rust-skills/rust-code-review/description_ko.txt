Rust API 지침 체크리스트(C-PANIC, C-UNWRAP, C-TRANSMUTE, C-BOOL, C-NEWTYPE, C-COMMON-TRAITS, C-CONVERT, C-SEALED, C-NON-EXHAUSTIVE)를 적용하여 정확성, 메모리 및 스레드 안전성, 오류 의미 체계, 불필요한 할당 또는 복제, 잠금 범위, API 호환성, 테스트 격차, 문서화 및 종속성 위험에 대한 Rust 변경 사항을 검토하세요. Rust 차이점, 끌어오기 요청, 라이브러리, 안전하지 않은 경계 또는 생산 사고를 검토할 때 사용합니다. 요약 전에 심각도별로 실행 가능한 결과를 보고하고, 자동화된 서식 지정 또는 린트 정책을 Rust-style-clippy로 라우팅하고, API 형태 결정(특성 봉인, 오류 분류, 새로운 유형 디자인, 빌더 패턴)을 Rust-api-design으로 라우팅합니다.
