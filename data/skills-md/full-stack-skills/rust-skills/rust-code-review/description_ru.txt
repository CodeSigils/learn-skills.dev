Просмотрите изменения Rust на предмет корректности, безопасности памяти и потоков, семантики ошибок, ненужного выделения или клонирования, области блокировки, совместимости API, пробелов в тестировании, документации и риска зависимостей, применив контрольный список рекомендаций Rust API (C-PANIC, C-UNWRAP, C-TRANSMUTE, C-BOOL, C-NEWTYPE, C-COMMON-TRAITS, C-CONVERT, C-SEALED, C-NON-EXHAUSTIVE). Используйте при просмотре различий Rust, запросов на включение, библиотек, небезопасных границ или производственных инцидентов; сообщайте о практических выводах по степени серьезности перед сводками, направляйте автоматическое форматирование или политику ворса в Rust-style-Clippy и направляйте решения по форме API (запечатывание признаков, таксономию ошибок, дизайн нового типа, шаблоны компоновщика) в Rust-api-design.
