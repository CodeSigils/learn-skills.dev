قم بمراجعة تغييرات Rust للتأكد من صحتها وسلامة الذاكرة والخيط ودلالات الأخطاء والتخصيص أو الاستنساخ غير الضروري ونطاق القفل وتوافق واجهة برمجة التطبيقات وفجوات الاختبار والوثائق ومخاطر التبعية، وتطبيق قائمة التحقق من إرشادات Rust API (C-PANIC وC-UNWRAP وC-TRANSMUTE وC-BOOL وC-NEWTYPE وC-COMMON-TRAITS وC-CONVERT وC-SEALED وC-NON-EXHAUSTIVE). يُستخدم عند مراجعة اختلافات Rust أو طلبات السحب أو المكتبات أو الحدود غير الآمنة أو حوادث الإنتاج؛ قم بالإبلاغ عن النتائج القابلة للتنفيذ حسب الخطورة قبل الملخصات، وتوجيه التنسيق الآلي أو سياسة الوبر إلى نمط الصدأ-قصاصة، وتوجيه قرارات شكل واجهة برمجة التطبيقات (ختم السمات، وتصنيف الأخطاء، وتصميم النوع الجديد، وأنماط البناء) إلى تصميم واجهة برمجة التطبيقات الصدأ.
