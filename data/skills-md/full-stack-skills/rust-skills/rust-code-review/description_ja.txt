Rust API ガイドラインのチェックリスト (C-PANIC、C-UNWRAP、C-TRANSMUTE、C-BOOL、C-NEWTYPE、C-COMMON-TRAITS、C-CONVERT、C-SEALED、C-NON-EXHAUSTIVE) を適用して、正確性、メモリとスレッドの安全性、エラー セマンティクス、不要な割り当てまたはクローン作成、ロック スコープ、API 互換性、テスト ギャップ、ドキュメント、依存関係のリスクについて Rust の変更をレビューします。 Rust の差分、プル リクエスト、ライブラリ、安全でない境界、または運用インシデントをレビューするときに使用します。概要の前に重大度別に実用的な結果を報告し、自動フォーマットまたは lint ポリシーを Rust-style-clippy にルーティングし、API 形状の決定 (トレイト シーリング、エラー分類法、ニュータイプ設計、ビルダー パターン) を Rust-api-design にルーティングします。
