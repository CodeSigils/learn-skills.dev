تصميم وتنفيذ واختبار وتشغيل عملاء Rust Outbound HTTP المرنين مع البرامج الوسيطة reqwest وhyper وTower وتجميع الاتصالات وDNS والوكلاء وTLS وعمليات إعادة التوجيه والمواعيد النهائية وإعادة المحاولة وحدود المعدل والتزامن وأجسام البث والإلغاء وضوابط SSRF واختبارات عقود الخادم الوهمية أو الحقيقية. يُستخدم عندما يطلب المستخدمون الاتصال بواجهات REST APIs، أو تنزيل البيانات أو تحميلها، أو تكوين عميل HTTP، أو تشخيص فشل الاتصال، أو تشديد طلبات خدمة إلى خدمة؛ احتفظ بالخوادم الواردة في شبكة الصدأ.
