Progetta, implementa, testa e gestisci client HTTP in uscita Rust resilienti con reqwest, hyper, middleware Tower, pool di connessioni, DNS, proxy, TLS, reindirizzamenti, scadenze, nuovi tentativi, limiti di velocità e concorrenza, corpi di streaming, cancellazione, controlli SSRF e test dei contratti su server fittizi o reali. Da utilizzare quando gli utenti chiedono di chiamare API REST, scaricare o caricare dati, configurare un client HTTP, diagnosticare errori di connessione o rafforzare le richieste da servizio a servizio; mantieni i server in entrata in Rust-Web.
