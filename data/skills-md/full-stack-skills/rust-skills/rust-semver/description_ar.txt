إدارة الإصدارات الدلالية لصندوق Rust - ما يمكن اعتباره واجهة برمجة تطبيقات عامة (عناصر مرئية + يمكن الوصول إليها من خلال عمليات إعادة التصدير)، وقواعد ما قبل 1.0 (توافق 0.x.y)، وكسر اكتشاف التغيير من خلال عمليات فحص البضائع (أكثر من 270 خطًا)، والنشر المتزامن لمساحة العمل مع مساحات عمل الشحن، وسير عمل السحب/الإيقاف، وإرشادات RustSec، والآثار المترتبة على `#[غير شامل]`، السمات المختومة والوحدات المخفية وأعلام الميزات والإضافات الضمنية للسمات. يُستخدم عندما يسأل المستخدمون عما إذا كان هناك تغيير ما، أو يريدون نشر إصدار جديد بأمان، أو إجراء عمليات فحص البضائع، أو تنسيق إصدارات مساحة عمل متعددة الصناديق، أو التعامل مع موقف انتزاع/استشاري؛ آليات بيان Cargo اليدوية لبناء البضائع الصدأ، وخيارات تصميم API لتصميم Rust-API، وتكوين CI لتصميم الصدأ.
