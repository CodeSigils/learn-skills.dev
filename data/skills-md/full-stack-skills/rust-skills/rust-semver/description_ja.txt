Rust クレートのセマンティック バージョニングの管理 — パブリック API としてカウントされるもの (アイテムの表示 + 再エクスポートを通じてアクセス可能)、1.0 より前のルール (0.x.y 互換性)、カーゴ セマンバー チェックによる重大な変更の検出 (270 以上の lint)、カーゴ ワークスペースを使用したワークスペース ロックステップ パブリッシング、ヤンク/非推奨ワークフロー、RustSec アドバイザリ、およびセマンティック サービスへの影響`#[non_exhaustive]`、封印された特性、隠しモジュール、機能フラグ、および特性実装の追加。ユーザーが、変更が壊れているかどうかを尋ねる場合、新しいバージョンを安全に公開したい場合、カーゴサーバーチェックを実行したい場合、マルチクレートワークスペースのリリースを調整したい場合、またはヤンク/アドバイザリー状況に対処したい場合に使用します。 Cargo マニフェストの仕組みを Rust-cargo-build に、API 設計の選択を Rust-api-design に、CI 構成を Rust-style-clippy に渡します。
