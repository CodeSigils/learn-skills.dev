Gérer la gestion des versions sémantiques de Rust crate - ce qui compte comme une API publique (éléments visibles + accessibles via les réexportations), règles pré-1.0 (compatibilité 0.x.y), détection des changements de rupture via les contrôles cargo-semver (270+ lints), publication verrouillée de l'espace de travail avec les espaces de travail cargo, flux de travail de suppression/dépréciation, avis RustSec et les implications semver de `#[non_exhaustive]`, traits scellés, cachés modules, indicateurs de fonctionnalités et ajouts d'impls de traits. À utiliser lorsque les utilisateurs demandent si une modification est interrompue, souhaitent publier une nouvelle version en toute sécurité, exécuter des vérifications de chargement, coordonner les versions d'espace de travail multi-caisses ou gérer une situation de retrait/de conseil ; confiez la mécanique du manifeste Cargo à rust-cargo-build, les choix de conception d'API à rust-api-design et la configuration CI à rust-style-clippy.
