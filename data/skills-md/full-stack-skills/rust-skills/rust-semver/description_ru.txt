Управление семантическими версиями крейта Rust — что считается общедоступным API (видимые элементы + доступные через реэкспорт), правилами версии до 1.0 (совместимость с 0.x.y), обнаружением критических изменений с помощью проверок груза (270+ lints), пошаговой публикацией рабочего пространства с рабочими пространствами груза, рабочими процессами извлечения/устаревания, рекомендациями RustSec и последствиями семвера `#[non_exhaustive]`, запечатанные черты, скрытые модули, флаги функций и дополнения черт. Используйте, когда пользователи спрашивают, является ли изменение критическим, хотят безопасно опубликовать новую версию, запустить проверку груза, координировать выпуск нескольких ящиков в рабочей области или справиться с ситуацией дергания/консультативной ситуации; передать механику манифеста Cargo в Rust-Cargo-Build, варианты дизайна API в Rust-api-design и конфигурацию CI в Rust-style-Clippy.
