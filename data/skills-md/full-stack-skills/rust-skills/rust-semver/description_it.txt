Gestisci il controllo delle versioni semantico di Rust Crate: ciò che conta come API pubblica (elementi visibili + raggiungibili tramite riesportazioni), regole pre-1.0 (compatibilità 0.x.y), rilevamento delle modifiche di violazione tramite cargo-semver-check (oltre 270 lint), pubblicazione lockstep dell'area di lavoro con cargo-workspaces, flussi di lavoro yank/deprecate, avvisi RustSec e le implicazioni semver di `#[non_exhaustive]`, tratti sigillati, moduli nascosti, flag di funzionalità e aggiunte di impl di tratti. Da utilizzare quando gli utenti chiedono se una modifica si sta interrompendo, desiderano pubblicare una nuova versione in modo sicuro, eseguire controlli del carico-semver, coordinare i rilasci di aree di lavoro con più casse o gestire una situazione di strattone/avviso; mano la meccanica del manifest Cargo in ruggine-cargo-build, le scelte di progettazione API in ruggine-api-design e la configurazione CI in ruggine-stile-clippy.
