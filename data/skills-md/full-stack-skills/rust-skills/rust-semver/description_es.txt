Administre el control de versiones semántico de Rust Crate: lo que cuenta como una API pública (elementos visibles + accesibles a través de reexportaciones), reglas anteriores a 1.0 (compatibilidad 0.x.y), detección de cambios importantes mediante comprobaciones de cargo-semver (más de 270 pelusas), publicación sincronizada del espacio de trabajo con espacios de trabajo de carga, flujos de trabajo de extracción/obsolescencia, avisos de RustSec y las implicaciones más graves de `#[non_exhaustive]`, rasgos sellados, módulos ocultos, indicadores de características y adiciones de implicaciones de rasgos. Úselo cuando los usuarios pregunten si un cambio es importante, desean publicar una nueva versión de forma segura, ejecutar comprobaciones de carga-semver, coordinar lanzamientos de espacios de trabajo de varias cajas o manejar una situación de aviso o retirada; entregue la mecánica del manifiesto de carga a Rust-Cargo-build, las opciones de diseño de API a Rust-API-Design y la configuración de CI a Rust-Style-Clippy.
