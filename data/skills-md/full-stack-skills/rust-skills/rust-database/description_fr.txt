À utiliser lorsque les utilisateurs posent des questions sur le code Rust SQL ou ORM, les migrations, les transactions, l'intégration PostgreSQL ou MySQL, les pools de connexions, la sécurité des requêtes ou la préparation à la production de bases de données.
