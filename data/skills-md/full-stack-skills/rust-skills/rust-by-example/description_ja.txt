短いコンパイル可能な例を通じて Rust パターンを示します — 型変換 (From/Into/TryFrom/as/Deref)、フロー制御 (if let/while let/match/loop)、関数とクロージャ (Fn/FnMut/FnOnce、キャプチャ)、モジュール (mod/use/pub/super/self)、ジェネリックとトレイト (境界/関連型/トレイト オブジェクト)、エラー処理(?/Result/thiserror/anyhow)、属性 (derive/cfg/inline/allow)、安全でない (生のポインター/共用体/ABI)、手続き型マクロ (derive/attribute/function-like)、およびインライン asm。ユーザーが「Rust で X を書くにはどうすればよいか」と尋ねた場合、コピー＆ペースト可能なコードを含む具体的なパターンが必要な場合、または Java/Python/Go/C++ から移行していて Rust と同等のものが必要な場合に使用します。アーキテクチャの決定はrust-api-design/rust-workspaceに、std APIの選択はrust-stdlibに、非同期ランタイムはrust-concurrencyに渡します。
