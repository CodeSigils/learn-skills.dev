通过简短的可编译示例展示 Rust 模式 - 类型转换 (From/Into/TryFrom/as/Deref)、流程控制 (if let/while let/match/loop)、函数和闭包 (Fn/FnMut/FnOnce、捕获)、模块 (mod/use/pub/super/self)、泛型和特征 (bounds/关联类型/特征对象)、错误处理 (?/Result/thiserror/anyhow)、属性（derive/cfg/inline/allow）、不安全（原始指针/联合/ABI）、过程宏（derive/attribute/function-like）和内联汇编。当用户询问“如何在 Rust 中编写 X”、需要具有可复制粘贴代码的具体模式，或者从 Java/Python/Go/C++ 迁移并需要 Rust 等效项时使用；将架构决策交给 rust-api-design/rust-workspace，将 std API 选择交给 rust-stdlib，将异步运行时交给 rust-concurrency。
