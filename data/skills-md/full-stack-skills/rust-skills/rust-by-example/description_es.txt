Muestre patrones de Rust a través de breves ejemplos compilables: conversiones de tipos (From/Into/TryFrom/as/Deref), control de flujo (if let/ while let/match/loop), funciones y cierres (Fn/FnMut/FnOnce, capturas), módulos (mod/use/pub/super/self), genéricos y rasgos (límites/tipos asociados/objetos de rasgos), manejo de errores (?/Result/thiserror/anyhow), atributos (derivar/cfg/en línea/permitir), inseguro (punteros sin formato/uniones/ABI), macros de procedimiento (derivar/atributo/similar a función) y conjunto en línea. Úselo cuando los usuarios pregunten "¿cómo escribo X en Rust?", necesiten un patrón concreto con código que se pueda copiar y pegar, o estén migrando desde Java/Python/Go/C++ y quieran el equivalente de Rust; entregue las decisiones de arquitectura a Rust-api-design/rust-workspace, la selección de API estándar a Rust-stdlib y el tiempo de ejecución asíncrono a Rust-Concurrency.
