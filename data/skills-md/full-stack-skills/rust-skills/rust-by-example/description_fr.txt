Montrez les modèles Rust à travers de courts exemples compilables : conversions de types (From/Into/TryFrom/as/Deref), contrôle de flux (if let/while let/match/loop), fonctions et fermetures (Fn/FnMut/FnOnce, captures), modules (mod/use/pub/super/self), génériques et traits (limites/types associés/objets trait), gestion des erreurs (?/Result/thiserror/anyhow), attributs. (derive/cfg/inline/allow), dangereux (pointeurs bruts/unions/ABI), macros procédurales (derive/attribut/function-like) et asm en ligne. À utiliser lorsque les utilisateurs demandent « comment écrire X dans Rust », ont besoin d'un modèle concret avec du code pouvant être copié, ou migrent depuis Java/Python/Go/C++ et veulent l'équivalent Rust ; confiez les décisions d'architecture à rust-api-design/rust-workspace, la sélection d'API std à rust-stdlib et le runtime asynchrone à rust-concurrency.
