짧은 컴파일 가능한 예제를 통해 Rust 패턴 표시 — 유형 변환(From/Into/TryFrom/as/Deref), 흐름 제어(let/while let/match/loop), 함수 및 클로저(Fn/FnMut/FnOnce, 캡처), 모듈(mod/use/pub/super/self), 제네릭 및 특성(경계/관련 유형/특성 객체), 오류 처리(?/Result/thiserror/anyhow), 속성 (파생/cfg/인라인/허용), 안전하지 않음(원시 포인터/공용체/ABI), 절차적 매크로(파생/속성/함수 유사) 및 인라인 asm. 사용자가 "Rust에서 X를 어떻게 작성하나요?"라고 물을 때, 복사하여 붙여넣을 수 있는 코드가 있는 구체적인 패턴이 필요하거나 Java/Python/Go/C++에서 마이그레이션하고 Rust에 상응하는 것을 원할 때 사용하세요. 아키텍처 결정은 Rust-api-design/rust-workspace에, std API 선택은 Rust-stdlib에, 비동기 런타임은 Rust-동시성에 전달됩니다.
