Покажите шаблоны Rust на коротких компилируемых примерах — преобразования типов (From/Into/TryFrom/as/Deref), управление потоком (if let/ while let/match/loop), функции и замыкания (Fn/FnMut/FnOnce, захваты), модули (mod/use/pub/super/self), дженерики и свойства (границы/связанные типы/объекты свойств), обработка ошибок (?/Result/thiserror/anyhow), атрибуты (извлечение/cfg/inline/allow), небезопасные (необработанные указатели/объединения/ABI), процедурные макросы (извлечение/атрибут/подобие функции) и встроенный ассемблер. Используйте, когда пользователи спрашивают: «Как мне написать X на Rust», им нужен конкретный шаблон с кодом, допускающим копирование, или они переходят с Java/Python/Go/C++ и хотят получить эквивалент Rust; решения по архитектуре вручную — в Rust-api-design/rust-workspace, выбор стандартного API — в Rust-stdlib, а асинхронная среда выполнения — в Rust-Concurrency.
