Design Rust project topology — single-crate packages, multi-crate workspaces (virtual manifests, flat/grouped/nested layouts), workspace-level configuration (shared deps, lints, package metadata), dependency direction DAGs, and crate boundary decisions. Use when users ask how to split a project into crates, configure a workspace, avoid dependency cycles, refactor a mixed root-package workspace (rbatis-style), or decide between modules-in-one-crate vs separate crates. For in-crate src/ layout, see rust-module-layout.
