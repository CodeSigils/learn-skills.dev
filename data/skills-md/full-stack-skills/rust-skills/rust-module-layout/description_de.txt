Entwerfen und erzwingen Sie das interne Layout einer einzelnen Rust-Kiste – lib.rs/main.rs als dünnen Index, semantisch benannte Verzeichnismodule, „mod“-Deklarationen, „pub“-Sichtbarkeit und gezielte Re-Exporte. Wird verwendet, wenn Benutzer fragen, wie sie src/ organisieren, lib.rs schreiben, eine wachsende Kiste in Unterverzeichnisse aufteilen, zwischen „foo.rs“ und „foo/mod.rs“ wählen, Module benennen, flache lib.rs-Anti-Patterns „Index plus Glob Re-Export“ vermeiden oder flache Projekte im Java- oder Python-Stil in idiomatische Rust-Modulbäume migrieren.
