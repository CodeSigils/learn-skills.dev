Concevez et appliquez la disposition interne d'une seule caisse Rust : lib.rs/main.rs en tant qu'index léger, modules de répertoire nommés sémantiquement, déclarations « mod », visibilité « pub » et réexportations ciblées. À utiliser lorsque les utilisateurs demandent comment organiser src/, écrire lib.rs, diviser une caisse croissante en sous-répertoires, choisir entre `foo.rs` et `foo/mod.rs`, nommer des modules, éviter les anti-modèles plats lib.rs "index plus glob re-export", ou migrer des projets plats de style Java ou Python vers des arborescences de modules Rust idiomatiques.
