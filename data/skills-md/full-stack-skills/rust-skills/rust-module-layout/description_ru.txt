Спроектируйте и внедрите внутреннюю структуру одного крейта Rust — lib.rs/main.rs в виде тонкого индекса, модули каталогов с семантическими именами, объявления mod, видимость pub и целевой реэкспорт. Используйте, когда пользователи спрашивают, как организовать src/, писать lib.rs, разбивать растущий ящик на подкаталоги, выбирать между `foo.rs` и `foo/mod.rs`, давать имена модулям, избегать плоских анти-шаблонов lib.rs "index plus glob reexport" или мигрировать плоские проекты в стиле Java или Python в идиоматические деревья модулей Rust.
