قم بتصميم وتنفيذ التخطيط الداخلي لصندوق Rust واحد - lib.rs/main.rs كمؤشر رفيع، ووحدات دليل ذات أسماء دلالية، وإعلانات `mod`، وإمكانية رؤية `pub`، وعمليات إعادة التصدير المستهدفة. يُستخدم عندما يسأل المستخدمون عن كيفية تنظيم src/، أو كتابة lib.rs، أو تقسيم صندوق متزايد إلى أدلة فرعية، أو الاختيار بين `foo.rs` و`foo/mod.rs`، أو تسمية الوحدات النمطية، أو تجنب الأنماط المضادة لـ lib.rs المسطحة "index plus glob re-export"، أو ترحيل المشاريع المسطحة بنمط Java أو Python إلى أشجار وحدات Rust الاصطلاحية.
