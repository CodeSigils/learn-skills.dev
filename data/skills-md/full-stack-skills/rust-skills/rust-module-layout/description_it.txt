Progetta e applica il layout interno di un singolo crate di Rust: lib.rs/main.rs come indice sottile, moduli di directory con nome semantico, dichiarazioni "mod", visibilità "pub" e riesportazioni mirate. Da usare quando gli utenti chiedono come organizzare src/, scrivere lib.rs, dividere un crate in crescita in sottodirectory, scegliere tra `foo.rs` e `foo/mod.rs`, nominare i moduli, evitare anti-pattern flat lib.rs "index plus glob re-export" o migrare progetti flat in stile Java o Python in alberi di moduli Rust idiomatici.
