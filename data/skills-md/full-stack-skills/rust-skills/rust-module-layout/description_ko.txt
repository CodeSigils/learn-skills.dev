단일 Rust 크레이트의 내부 레이아웃(얇은 인덱스인 lib.rs/main.rs, 의미론적으로 명명된 디렉터리 모듈, `mod` 선언, `pub` 가시성 및 대상 재수출)을 설계하고 적용합니다. 사용자가 src/ 구성, lib.rs 작성, 성장하는 상자를 하위 디렉토리로 분할, `foo.rs` 및 `foo/mod.rs` 중에서 선택, 모듈 이름 지정, 플랫 lib.rs "인덱스 + glob 재수출" 안티 패턴 방지, Java 스타일 또는 Python 스타일 플랫 프로젝트를 관용적인 Rust 모듈 트리로 마이그레이션하는 방법을 물을 때 사용합니다.
