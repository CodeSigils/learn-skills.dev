単一の Rust クレートの内部レイアウト (シン インデックスとしての lib.rs/main.rs、意味論的に名前が付けられたディレクトリ モジュール、`mod` 宣言、`pub` 可視性、およびターゲットを絞った再エクスポート) を設計して強制します。 src/ を整理する方法、lib.rs を記述する方法、成長するクレートをサブディレクトリに分割する方法、`foo.rs` と `foo/mod.rs` のどちらかを選択する方法、モジュールに名前を付ける方法、フラット lib.rs の「インデックスとグロブの再エクスポート」アンチパターンを回避する方法、または Java スタイルまたは Python スタイルのフラット プロジェクトを慣用的な Rust モジュール ツリーに移行する方法をユーザーが尋ねるときに使用します。
