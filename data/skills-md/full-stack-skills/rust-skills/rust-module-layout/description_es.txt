Diseñe y aplique el diseño interno de una única caja Rust: lib.rs/main.rs como un índice delgado, módulos de directorio con nombres semánticos, declaraciones `mod`, visibilidad `pub` y reexportaciones específicas. Úselo cuando los usuarios pregunten cómo organizar src/, escribir lib.rs, dividir una caja en crecimiento en subdirectorios, elegir entre `foo.rs` y `foo/mod.rs`, nombrar módulos, evitar los antipatrones de "índice más reexportación global" de flat lib.rs o migrar proyectos planos estilo Java o Python a árboles de módulos idiomáticos de Rust.
