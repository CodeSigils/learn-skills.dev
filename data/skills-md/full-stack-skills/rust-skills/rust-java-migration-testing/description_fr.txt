Concevez, implémentez, auditez et rapportez des tests précieux pour les migrations Java vers Rust sans transformer les tests écologiques en fausses déclarations d'achèvement. À utiliser pour porter des tests JUnit sur Rust, vérifier chaque disposition de test Java, valider un registre de migration d'objet, prouver la réutilisation exacte des dépendances, décider des obligations spécifiques à Rust, comparer la couverture sans jeu ou créer des preuves différentielles, dorées, de propriété, de fuzz, de mutation, de concurrence, d'annulation, de cycle de vie, de conformité de l'adaptateur, de dépendance réelle, d'hôte, de chargement, de sécurité et de restauration. Maintient les objets MANQUANTS, égarés, STUB, PARTIELS et NON VÉRIFIÉS incomplets même lorsque les tests Cargo réussissent.
