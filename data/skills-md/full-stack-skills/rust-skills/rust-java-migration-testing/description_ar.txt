قم بتصميم الاختبارات القيمة وتنفيذها وتدقيقها والإبلاغ عنها لعمليات الترحيل من Java إلى Rust دون الترويج للاختبارات الخضراء في مطالبات إكمال زائفة. يُستخدم عند نقل اختبارات JUnit إلى Rust، والتحقق من كل ترتيب لاختبار Java، والتحقق من صحة دفتر أستاذ ترحيل الكائنات، وإثبات إعادة استخدام التبعية بشكل دقيق، وتحديد الالتزامات الخاصة بـ Rust، ومقارنة التغطية دون اللعب، أو إنشاء أدلة تفاضلية، ذهبية، خاصية، زغب، طفرة، تزامن، إلغاء، دورة حياة، توافق المحول، التبعية الحقيقية، المضيف، التحميل، الأمان، وأدلة التراجع. يبقي العناصر المفقودة، والكائنات في غير مكانها، والأشياء التي لم يتم التحقق منها، والكائنات التي لم يتم التحقق منها، غير مكتملة حتى عند اجتياز اختبارات الشحن.
