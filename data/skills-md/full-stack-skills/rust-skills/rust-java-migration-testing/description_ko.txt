친환경 테스트를 허위 완료 주장으로 승격시키지 않고 Java에서 Rust로의 마이그레이션을 위한 중요한 테스트를 설계, 구현, 감사 및 보고합니다. JUnit 테스트를 Rust로 포팅하고, 모든 Java 테스트 처리를 확인하고, 객체 마이그레이션 원장을 검증하고, 정확한 종속성 재사용을 증명하고, Rust 관련 의무를 결정하고, 게임 없이 적용 범위를 비교하거나, 차등, 골든, 속성, 퍼즈, 돌연변이, 동시성, 취소, 수명 주기, 어댑터 적합성, 실제 종속성, 호스트, 로드, 보안 및 롤백 증거를 구축할 때 사용합니다. Cargo 테스트를 통과하더라도 MISSING, MISPLACED, STUB, PARTIAL 및 UNVERIFIED 개체를 불완전하게 유지합니다.
