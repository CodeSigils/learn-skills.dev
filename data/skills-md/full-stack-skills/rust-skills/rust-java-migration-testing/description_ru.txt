Проектируйте, внедряйте, проверяйте и сообщайте о ценных тестах для миграции с Java на Rust, не превращая зеленые тесты в ложные заявления о завершении. Используйте при портировании тестов JUnit на Rust, проверке каждого варианта теста Java, проверке реестра миграции объектов, подтверждении точного повторного использования зависимостей, принятии решений по специфическим обязательствам Rust, сравнении покрытия без игр или построении дифференциальных, золотых, свойств, нечеткости, мутации, параллелизма, отмены, жизненного цикла, соответствия адаптеру, реальной зависимости, хоста, нагрузки, безопасности и доказательства отката. Сохраняет объекты MISSING, MISPLACED, STUB, PARTIAL и UNVERIFIED неполными, даже если тесты Cargo пройдены.
