グリーン テストを誤った完了要求に誘導することなく、Java から Rust への移行のための貴重なテストを設計、実装、監査、レポートします。 JUnit テストを Rust に移植する場合、すべての Java テストの性質をチェックする場合、オブジェクト移行台帳を検証する場合、正確な依存関係の再利用を証明する場合、Rust 固有の義務を決定する場合、ゲームなしでカバレッジを比較する場合、または差分、ゴールデン、プロパティ、ファズ、突然変異、同時実行性、キャンセル、ライフサイクル、アダプター準拠、実際の依存関係、ホスト、負荷、セキュリティ、およびロールバックの証拠を構築する場合に使用します。 Cargo テストに合格した場合でも、MISSING、MISPLACED、STUB、PARTIAL、および UNVERIFIED オブジェクトが不完全なままになります。
