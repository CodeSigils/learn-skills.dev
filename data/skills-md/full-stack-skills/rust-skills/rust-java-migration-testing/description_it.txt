Progetta, implementa, verifica e segnala test preziosi per le migrazioni da Java a Rust senza promuovere test ecologici in false dichiarazioni di completamento. Da utilizzare durante il porting di test JUnit su Rust, il controllo di ogni disposizione di test Java, la convalida di un registro di migrazione di oggetti, la dimostrazione dell'esatto riutilizzo delle dipendenze, la decisione di obblighi specifici di Rust, il confronto della copertura senza giochi o la creazione di prove differenziali, golden, proprietà, fuzz, mutazione, concorrenza, cancellazione, ciclo di vita, conformità dell'adattatore, dipendenza reale, host, carico, sicurezza e rollback. Mantiene incompleti gli oggetti MANCANTI, PERSO, STUB, PARZIALI e NON VERIFICATI anche quando i test Cargo vengono superati.
