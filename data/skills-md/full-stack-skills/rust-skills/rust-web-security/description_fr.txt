Modélisez les menaces, implémentez, examinez et testez la sécurité Web Rust, y compris l'authentification, l'autorisation des objets et des locataires, les sessions, les cookies, la validation JWT et OIDC, CSRF, CORS, SSRF, les limites d'entrée, les secrets, les limites de dépendance cryptographique, la journalisation d'audit et les tests de sécurité négatifs. À utiliser lorsque les utilisateurs demandent à sécuriser ou auditer les services Web Rust, les jetons, le transport du navigateur, l'accès multi-tenant, la gestion des secrets ou les corrections d'incidents de sécurité.
