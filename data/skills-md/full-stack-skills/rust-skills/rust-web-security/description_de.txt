Bedrohungsmodell, Implementierung, Überprüfung und Test der Rust-Websicherheit, einschließlich Authentifizierung, Objekt- und Mandantenautorisierung, Sitzungen, Cookies, JWT- und OIDC-Validierung, CSRF, CORS, SSRF, Eingabebeschränkungen, Geheimnisse, kryptografische Abhängigkeitsgrenzen, Audit-Protokollierung und negative Sicherheitstests. Wird verwendet, wenn Benutzer die Sicherung oder Prüfung von Rust-Webdiensten, Token, Browsertransport, mandantenfähigem Zugriff, geheimer Handhabung oder Behebung von Sicherheitsvorfällen anfordern.
