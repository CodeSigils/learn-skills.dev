Modella le minacce, implementa, esamina e testa la sicurezza web di Rust, inclusa autenticazione, autorizzazione di oggetti e tenant, sessioni, cookie, convalida JWT e OIDC, CSRF, CORS, SSRF, limiti di input, segreti, limiti delle dipendenze crittografiche, registrazione di controllo e test di sicurezza negativi. Da utilizzare quando gli utenti richiedono di proteggere o controllare i servizi web Rust, i token, il trasporto del browser, l'accesso multi-tenant, la gestione dei segreti o le correzioni degli incidenti di sicurezza.
