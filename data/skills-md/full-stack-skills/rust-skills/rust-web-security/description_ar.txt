نموذج التهديد، وتنفيذ ومراجعة واختبار أمان الويب Rust، بما في ذلك المصادقة، وتفويض الكائن والمستأجر، والجلسات، وملفات تعريف الارتباط، والتحقق من صحة JWT وOIDC، وCSRF، وCORS، وSSRF، وحدود الإدخال، والأسرار، وحدود تبعية التشفير، وتسجيل التدقيق، واختبارات الأمان السلبية. يُستخدم عندما يطلب المستخدمون تأمين أو تدقيق خدمات Rust على الويب، أو الرموز المميزة، أو نقل المتصفح، أو الوصول إلى مستأجرين متعددين، أو المعالجة السرية، أو إصلاحات الحوادث الأمنية.
