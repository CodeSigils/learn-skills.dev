Concevoir, implémenter, tester et publier des applications de ligne de commande Rust de production, y compris les contrats de commande, les sous-commandes, la priorité de configuration, stdin/stdout/stderr, les codes de sortie, la sécurité des fichiers, le démon IPC, la gestion des terminaux, l'empaquetage et les tests au niveau des processus. À utiliser lorsque les utilisateurs demandent une CLI Rust, un analyseur de commandes, une intégration clap, des pipelines de style Unix, des clients démons, un comportement PTY/TUI, l'achèvement du shell ou l'ingénierie de version CLI.
