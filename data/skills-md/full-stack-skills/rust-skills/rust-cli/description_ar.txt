تصميم وتنفيذ واختبار وإصدار تطبيقات سطر أوامر Rust للإنتاج، بما في ذلك عقود الأوامر والأوامر الفرعية وأسبقية التكوين وstdin/stdout/stderr وأكواد الخروج وسلامة الملفات وdaemon IPC والتعامل مع الأجهزة الطرفية والتعبئة والاختبارات على مستوى العملية. يُستخدم عندما يطلب المستخدمون Rust CLI، أو محلل الأوامر، أو تكامل التصفيق، أو خطوط الأنابيب بنمط Unix، أو عملاء البرنامج الخفي، أو سلوك PTY/TUI، أو إكمال الصدفة، أو هندسة إصدار CLI.
