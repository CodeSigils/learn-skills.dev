明示的なツールチェーンと MSRV チェックによる安定した Rust 言語のセマンティクス (所有権、借用、ライフタイム、移動セマンティクス、トレイト、ジェネリックス、関連型、パターン マッチング、クロージャ、エラー伝播、エディションの違い) を実装して説明します。ユーザーが Rust 構文、コンパイラ エラーの修正、所有権/借用の診断、またはバージョンに依存する安定したコードを要求する場合に、コアの Rust 言語スキルとして使用します。 std API の選択 (どのコレクション、どのスマート ポインタ、どの文字列タイプ) を Rust-stdlib に渡し、「X をどのように書くか」パターンの質問を Rust-by-Example に渡し、特殊なドメインを専用のスキルに渡します。
