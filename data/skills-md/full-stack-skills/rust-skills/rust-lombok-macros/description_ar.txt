استخدم وترحيل ومراجعة مشتقات وحدات الماكرو lombok التي تنشئ تطبيقات العرض Rust، و getters القابلة للتغيير، و setters، و المنشئات، و Debug، و Debug-backed Display. يُستخدم عندما يذكر المستخدمون صراحة وحدات الماكرو lombok أو Java Lombok، أو يريدون إزالة أساليب الوصول أو المنشئ المتكررة، أو تكوين الرؤية أو التحويلات التي تم إنشاؤها، أو تنقيح الحقول من Debug، أو مراجعة واجهات برمجة التطبيقات التي تم إنشاؤها. تفضل DTOs وناقلات البيانات؛ رفض الإنشاء الذي يتجاوز ثوابت المجال، أو يكشف الأجزاء الداخلية القابلة للتغيير، أو الذعر عند الوصول إلى الخيار أو النتيجة، أو يحول Debug إلى عقد عرض عام.
