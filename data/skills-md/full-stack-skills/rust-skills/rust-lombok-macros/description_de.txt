Verwenden, migrieren und überprüfen Sie Lombok-Makro-Ableitungen, die Rust-Getter, veränderbare Getter, Setter, Konstruktoren, Debug und Debug-gestützte Anzeigeimplementierungen generieren. Verwenden Sie diese Option, wenn Benutzer ausdrücklich Lombok-Makros oder Java Lombok erwähnen, sich wiederholende Zugriffs- oder Konstruktormethoden entfernen, generierte Sichtbarkeit oder Konvertierungen konfigurieren, Felder aus Debug entfernen oder generierte APIs überprüfen möchten. Bevorzugen Sie DTOs und Datenträger; Lehnen Sie die Generierung ab, die Domäneninvarianten umgeht, veränderbare Interna offenlegt, beim Options- oder Ergebniszugriff in Panik gerät oder Debug in einen öffentlichen Anzeigevertrag umwandelt.
