Utilisez, migrez et examinez les dérivés de macros Lombok qui génèrent des getters Rust, des getters mutables, des setters, des constructeurs, des implémentations de débogage et d'affichage basées sur le débogage. À utiliser lorsque les utilisateurs mentionnent explicitement lombok-macros ou Java Lombok, souhaitent supprimer les méthodes d'accès ou de constructeur répétitives, configurer la visibilité ou les conversions générées, supprimer les champs du débogage ou examiner les API générées. Préférer les DTO et les supports de données ; rejetez la génération qui contourne les invariants de domaine, expose les éléments internes mutables, panique lors de l'accès aux options ou aux résultats, ou transforme le débogage en un contrat d'affichage public.
