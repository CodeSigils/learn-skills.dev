Rust ゲッター、可変ゲッター、セッター、コンストラクター、デバッグ、およびデバッグ支援表示実装を生成する lombok マクロ派生を使用、移行、およびレビューします。ユーザーが lombok マクロまたは Java Lombok について明示的に言及する場合、反復的なアクセサーまたはコンストラクター メソッドを削除する場合、生成された可視性または変換を構成する場合、デバッグからフィールドを編集する場合、または生成された API を確認する場合に使用します。 DTO とデータ キャリアを優先します。ドメイン不変式をバイパスする生成を拒否したり、変更可能な内部を公開したり、オプションまたは結果アクセスでパニックを起こしたり、デバッグをパブリック表示コントラクトに変えたりします。
