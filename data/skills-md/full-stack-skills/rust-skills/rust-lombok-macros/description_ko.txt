Rust getter, 변경 가능한 getter, setter, 생성자, 디버그 및 디버그 지원 디스플레이 구현을 생성하는 lombok-macros 파생물을 사용, 마이그레이션 및 검토합니다. 사용자가 lombok-macros 또는 Java Lombok을 명시적으로 언급하거나, 반복적인 접근자 또는 생성자 메서드를 제거하거나, 생성된 가시성 또는 변환을 구성하거나, 디버그에서 필드를 수정하거나, 생성된 API를 검토하려는 경우에 사용합니다. DTO 및 데이터 매체를 선호합니다. 도메인 불변성을 우회하고, 변경 가능한 내부를 노출하고, 옵션 또는 결과 액세스 시 패닉을 일으키거나, 디버그를 공개 디스플레이 계약으로 전환하는 생성을 거부합니다.
