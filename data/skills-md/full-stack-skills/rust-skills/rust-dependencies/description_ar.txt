إدارة حوكمة تبعية Rust على نطاق واسع - استراتيجية متطلبات الإصدار، واختيار الصناديق والمصدر، وتقليل الميزات، وتحليل التبعية المتعدية، وسياسة رفض البضائع/الحظر/الاستشارات/المصدر، وتدقيق البضائع، والبضائع القديمة، والتجديد/أتمتة Dependabot، وإيقاع تحديث التبعية، وتشخيص الدورة، وأمن سلسلة التوريد. يُستخدم لاستراتيجية التبعية، أو الموافقة على الصناديق، أو الامتثال للترخيص، أو الاستشارات، أو المصادر المسموح بها، أو التحديثات التلقائية، أو إدارة الرسم البياني للتبعية؛ تسليم بيان الشحن وتكوين التسجيل، وميكانيكا ملف القفل، والمحللات، وسلوك أوامر الشحن لبناء حمولة الصدأ، وقرارات التوافق الجزئية مع صدأ سيمفر، وسياسة الوبر لنمط الصدأ كليبي.
