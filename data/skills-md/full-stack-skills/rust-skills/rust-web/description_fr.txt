Concevez, implémentez, testez et exploitez les services HTTP côté serveur Rust de production, notamment axum, Actix Web, le routage, les extracteurs, l'état de l'application, le mappage des erreurs, l'ordre des middlewares, les délais d'attente, les limites du corps, l'observabilité, l'arrêt progressif et les limites de la base de données. À utiliser lorsque les utilisateurs demandent des API Rust REST, des gestionnaires Web, des middlewares, un cycle de vie du serveur, des contrats HTTP ou une architecture de service Web de production ; confiez les contrôles de sécurité à rust-web-security.
