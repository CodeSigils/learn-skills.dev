تصميم وتنفيذ واختبار وتشغيل خدمات HTTP من جانب خادم Rust للإنتاج، بما في ذلك axum، وActix Web، والتوجيه، والمستخرجات، وحالة التطبيق، وتعيين الأخطاء، وترتيب البرامج الوسيطة، والمهلات، وحدود النص، وإمكانية المراقبة، والإغلاق السلس، وحدود قاعدة البيانات. يُستخدم عندما يطلب المستخدمون واجهات برمجة تطبيقات Rust REST أو معالجات الويب أو البرامج الوسيطة أو دورة حياة الخادم أو عقود HTTP أو بنية خدمة الويب الخاصة بالإنتاج؛ تسليم الضوابط الأمنية لأمن الويب الصدأ.
