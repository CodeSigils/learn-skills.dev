Java Maven または Gradle プロジェクトから Rust Cargo ワークスペースへの動作を維持する移行を計画、実行、監査、検証します。 Java と Rust のリポジトリをモジュール、パッケージ、オブジェクト、ファイル、メソッド、パラメータ、ドキュメント、サンプル、テスト、依存関係の再利用、JavaBean ゲッター/セッターまたはスクリプト プロパティの互換性、同時実行性、または実行時動作レベルで比較する場合に使用します。中国語の Rust ドキュメントで Java セマンティクスを維持する。 Rust の依存関係の正確な置換を選択します。ソース モジュールごとに 4 つの詳細なドキュメント セットを 1 つ作成します。または、既存の作業を削除せずに不完全な移植を続行します。ソースと権限のあるオブジェクトの境界、明示的なADAPTED互換レイヤーを備えた慣用的なRust API、実際のRustファイルごとに1つのJavaオブジェクト、厳密な未完了状態、証拠に裏付けられた依存関係の再利用/プラットフォームの除外、凍結された完全なインベントリ、統合監査、および統合検証を強制します。
