Java Maven 또는 Gradle 프로젝트에서 Rust Cargo 작업공간으로의 동작 보존 마이그레이션을 계획, 실행, 감사 및 확인합니다. 모듈, 패키지, 객체, 파일, 메소드, 매개변수, 문서, 예제, 테스트, 종속성 재사용, JavaBean getter/setter 또는 스크립트 속성 호환성, 동시성 또는 런타임 동작 수준에서 Java 및 Rust 저장소를 비교할 때 사용합니다. 중국어 Rust 문서에서 Java 의미를 보존합니다. 정확한 Rust 종속성 대체를 선택합니다. 소스 모듈당 하나의 상세한 4개 문서 세트를 생성합니다. 또는 기존 작업을 삭제하지 않고 불완전한 포트를 계속합니다. 소스 권한이 있는 객체 경계, 명시적인 ADAPTED 호환성 레이어가 있는 관용적 Rust API, 실제 Rust 파일당 하나의 Java 객체, 엄격한 비완료 상태, 증거 지원 종속성 재사용/플랫폼 제외, 동결된 전체 인벤토리, 통합 감사 및 통합 검증을 적용합니다.
