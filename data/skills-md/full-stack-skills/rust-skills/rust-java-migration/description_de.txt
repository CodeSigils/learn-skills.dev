Planen, ausführen, prüfen und überprüfen Sie verhaltenserhaltende Migrationen von Java Maven- oder Gradle-Projekten zu Rust Cargo-Arbeitsbereichen. Verwendung beim Vergleich von Java- und Rust-Repositorys auf Modul-, Paket-, Objekt-, Datei-, Methoden-, Parameter-, Dokumentations-, Beispiel-, Test-, Abhängigkeitswiederverwendungs-, JavaBean-Getter/Setter- oder Skripteigenschaftenkompatibilitäts-, Parallelitäts- oder Laufzeitverhaltensebene; Beibehaltung der Java-Semantik in der chinesischen Rust-Dokumentation; Auswahl exakter Rust-Abhängigkeitsersetzungen; Erstellen eines detaillierten Satzes mit vier Dokumenten pro Quellmodul; oder eine unvollständige Portierung fortsetzen, ohne bestehende Arbeiten zu löschen. Erzwingt quellautoritative Objektgrenzen, idiomatische Rust-APIs mit expliziten ADAPTED-Kompatibilitätsebenen, ein Java-Objekt pro echter Rust-Datei, strikte Nichtvollständigkeitszustände, evidenzbasierte Wiederverwendung von Abhängigkeiten/Plattformausschlüsse, ein eingefrorenes vollständiges Inventar, konsolidierte Prüfung und einheitliche Überprüfung.
