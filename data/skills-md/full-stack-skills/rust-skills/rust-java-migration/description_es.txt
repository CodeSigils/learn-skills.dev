Planifique, ejecute, audite y verifique migraciones que preserven el comportamiento desde proyectos Java Maven o Gradle a espacios de trabajo de Rust Cargo. Úselo al comparar repositorios de Java y Rust a nivel de módulo, paquete, objeto, archivo, método, parámetro, documentación, ejemplo, prueba, reutilización de dependencias, getter/setter de JavaBean o compatibilidad de propiedades de script, concurrencia o comportamiento de tiempo de ejecución; preservar la semántica de Java en la documentación china de Rust; seleccionar reemplazos exactos de dependencia de Rust; producir un conjunto detallado de cuatro documentos por módulo fuente; o continuar una portabilidad incompleta sin eliminar el trabajo existente. Aplica límites de objetos con autoridad de origen, API de Rust idiomáticas con capas de compatibilidad ADAPTADA explícita, un objeto Java por archivo Rust real, estados estrictos de no finalización, reutilización de dependencias/exclusiones de plataforma respaldadas por evidencia, un inventario completo congelado, auditoría consolidada y verificación unificada.
