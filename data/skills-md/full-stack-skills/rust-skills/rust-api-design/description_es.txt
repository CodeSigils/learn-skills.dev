Diseñe las API de la biblioteca de Rust que sigan las pautas de la API de Rust: denominación (C-CASE, C-CONV, C-GETTER), rasgos de interoperabilidad (C-COMMON-TRAITS, C-CONVERT, C-ITER, C-SERDE), previsibilidad (C-INTUITIVE, C-CONST), flexibilidad (C-GENERIC, C-NEWTYPE, C-EXT), seguridad de tipos (C-BOOL, C-NONZERO, C-WRAPPER, C-STR), confiabilidad (C-PANIC, C-UNWRAP), depuración (C-DEBUG) y preparación para el futuro (C-SEALED, C-STRUCT-FIELD, C-NON-EXHAUSTIVE). Úselo cuando los usuarios diseñan una API de caja pública, eligen entre genéricos/concreto/nuevo tipo, deciden límites de rasgos, ocultan la implementación, evitan roturas o preguntan "qué es el diseño idiomático de API de Rust"; Semver manual y flujo de trabajo de publicación en Rust-semver, configuración de pelusa en Rust-style-clippy y diseño en caja en Rust-module-layout.
