Concevoir des API de bibliothèque Rust qui suivent les directives de l'API Rust : nommage (C-CASE, C-CONV, C-GETTER), traits d'interopérabilité (C-COMMON-TRAITS, C-CONVERT, C-ITER, C-SERDE), prévisibilité (C-INTUITIVE, C-CONST), flexibilité (C-GENERIC, C-NEWTYPE, C-EXT), sécurité de type (C-BOOL, C-NONZERO, C-WRAPPER, C-STR), fiabilité (C-PANIC, C-UNWRAP), débogage (C-DEBUG) et pérennité (C-SEALED, C-STRUCT-FIELD, C-NON-EXHAUSTIVE). À utiliser lorsque les utilisateurs conçoivent une API de caisse publique, choisissent entre génériques/béton/nouveau type, décident des limites des traits, masquent l'implémentation, évitent les ruptures ou demandent « qu'est-ce que la conception idiomatique de l'API Rust » ; remettre Semver et publier le flux de travail sur rust-semver, la configuration des peluches sur rust-style-clippy et la mise en page en caisse sur rust-module-layout.
