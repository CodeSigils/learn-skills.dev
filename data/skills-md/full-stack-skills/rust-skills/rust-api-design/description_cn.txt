设计遵循 Rust API 指南的 Rust 库 API — 命名（C-CASE、C-CONV、C-GETTER）、互操作特征（C-COMMON-TRAITS、C-CONVERT、C-ITER、C-SERDE）、可预测性（C-INTUITIVE、C-CONST）、灵活性（C-GENERIC、C-NEWTYPE、C-EXT）、类型安全（C-BOOL、C-NONZERO、 C-WRAPPER、C-STR）、可靠性（C-PANIC、C-UNWRAP）、可调试性（C-DEBUG）和面向未来（C-SEALED、C-STRUCT-FIELD、C-NON-EXHAUSTIVE）。当用户设计公共 crate API、在泛型/具体/新类型之间进行选择、决定特征边界、隐藏实现、避免破坏或询问“什么是惯用的 Rust API 设计”时使用；手动 semver 并将工作流程发布到 rust-semver，将 lint 配置发布到 rust-style-clippy，并将板条箱内布局发布到 rust-module-layout。
