واجهات برمجة تطبيقات مكتبة Rust التي تتبع إرشادات Rust API - التسمية (C-CASE وC-CONV وC-GETTER)، وسمات التشغيل المتداخل (C-COMMON-TRAITS، وC-CONVERT، وC-ITER، وC-SERDE)، وإمكانية التنبؤ (C-INTUITIVE، وC-CONST)، والمرونة (C-GENERIC، وC-NEWTYPE، وC-EXT)، وسلامة النوع (C-BOOL، وC-NONZERO، C-WRAPPER، وC-STR)، والاعتمادية (C-PANIC، وC-UNWRAP)، وقابلية التصحيح (C-DEBUG)، والتحقق من المستقبل (C-SEALED، وC-STRUCT-FIELD، وC-NON-EXHAUSTIVE). يُستخدم عندما يقوم المستخدمون بتصميم واجهة برمجة تطبيقات صندوق عام، أو الاختيار بين الأنواع العامة/الخرسانة/النوع الجديد، أو تحديد حدود السمات، أو إخفاء التنفيذ، أو تجنب الكسر، أو السؤال "ما هو تصميم Rust API الاصطلاحي"؛ قم بتسليم سير العمل ونشره إلى Rust-Semver، وتكوين Lint إلى Rust-style-Clippy، والتخطيط داخل الصندوق إلى تخطيط وحدة الصدأ.
