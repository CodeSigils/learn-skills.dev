Разрабатывайте API-интерфейсы библиотеки Rust, соответствующие рекомендациям Rust API — именование (C-CASE, C-CONV, C-GETTER), особенности взаимодействия (C-COMMON-TRAITS, C-CONVERT, C-ITER, C-SERDE), предсказуемость (C-INTUITIVE, C-CONST), гибкость (C-GENERIC, C-NEWTYPE, C-EXT), безопасность типов (C-BOOL, C-NONZERO, C-WRAPPER, C-STR), надежность (C-PANIC, C-UNWRAP), возможность отладки (C-DEBUG) и перспективность (C-SEALED, C-STRUCT-FIELD, C-NON-EXHAUSTIVE). Используйте, когда пользователи проектируют общедоступный API-интерфейс крейта, выбирают между дженериками/конкретными/новыми типами, определяют границы свойств, скрывают реализацию, избегают поломок или спрашивают: «Что такое идиоматический дизайн Rust API»; вручную Semver и опубликуйте рабочий процесс в Rust-Semver, конфигурацию lint в Rust-style-Clippy и макет в Crate в Rust-Module-Layout.
