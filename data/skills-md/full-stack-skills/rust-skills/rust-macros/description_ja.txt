Rust の宣言型マクロと手続き型マクロを設計、名前付け、実装、デバッグ、テスト、レビューします。 これには、macro_rules マッチャーと繰り返し、ハイジニー、$crate パス、派生、属性および関数のようなマクロ、proc-マクロ クレートの命名、syn 解析、引用生成、診断、cargo-expand、doctest、trybuild が含まれます。ユーザーがコンパイル時のコード生成、Rust DSL、または -derive と -macros を選択するガイダンスが必要な場合に使用します。生成に明確なメンテナンス上のメリットがない限り、通常の特性、汎用 API、または手書き API をマクロの外に保持します。
