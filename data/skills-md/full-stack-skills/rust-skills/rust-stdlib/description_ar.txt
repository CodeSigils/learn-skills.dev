تحديد وإنشاء واجهات برمجة تطبيقات مكتبة Rust القياسية - مجموعات (HashMap/BTreeMap/Vec/VecDeque/LinkedList/BinaryHeap)، والمؤشرات الذكية (Box/Rc/Arc/RefCell/Mutex/OnceLock/LazyLock)، وأنواع السلسلة (String/&str/OsString/PathBuf/Cow)، وقابلية التغيير الداخلي (Cell/RefCell/OnceCell/OnceLock)، وتدفقات الإدخال/الإخراج (قراءة/كتابة/BufRead)، والمكررات، ومجمعات الخيار/النتيجة، والخيوط وقنوات mpsc، والوقت (المدة/اللحظة/SystemTime)، والمسارات، وenv، والعملية، وFS، وnet، وقرارات اختيار الوحدة النمطية. يُستخدم عندما يسأل المستخدمون "ما هو النوع القياسي الذي يجب أن أستخدمه"، أو مقارنة بدائل المجموعة/المؤشر/السلسلة، أو تصميم سلاسل الخيار/النتيجة، أو اختيار الخلية مقابل RefCell مقابل Mutex، أو العمل مع سلاسل الرسائل/القنوات القياسية، أو اختيار الوحدة النمطية المناسبة لمهمة ما؛ قم بتسليم وقت التشغيل غير المتزامن إلى التزامن الصدأ، ودلالات اللغة إلى التزامن الصدأ، ومخاوف طبقة التطبيق لمهارات المجال.
