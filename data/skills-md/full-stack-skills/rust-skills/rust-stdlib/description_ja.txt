Rust 標準ライブラリ API の選択と作成 — コレクション (HashMap/BTreeMap/Vec/VecDeque/LinkedList/BinaryHeap)、スマート ポインター (Box/Rc/Arc/RefCell/Mutex/OnceLock/LazyLock)、文字列型 (String/&str/OsString/PathBuf/Cow)、内部可変性(Cell/RefCell/OnceCell/OnceLock)、I/O ストリーム (Read/Write/BufRead)、イテレーター、オプション/結果コンビネーター、スレッドと mpsc チャネル、時間 (Duration/Instant/SystemTime)、パス、env、プロセス、fs、ネット、およびモジュール選択の決定。ユーザーが「どの std 型を使用すべきか」と尋ねる場合、コレクション/ポインター/文字列の代替を比較する場合、オプション/結果チェーンを設計する場合、Cell か RefCell か Mutex を選択するか、std スレッド/チャネルを操作するか、タスクに適切な std モジュールを選択する場合に使用します。非同期ランタイムは Rust 同時実行性に、言語セマンティクスは Rust Stable に、そしてアプリケーション層の懸念はドメイン スキルに委ねられます。
