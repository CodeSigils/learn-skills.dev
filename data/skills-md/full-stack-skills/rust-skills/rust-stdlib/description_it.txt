Seleziona e componi le API della libreria standard Rust: raccolte (HashMap/BTreeMap/Vec/VecDeque/LinkedList/BinaryHeap), puntatori intelligenti (Box/Rc/Arc/RefCell/Mutex/OnceLock/LazyLock), tipi di stringa (String/&str/OsString/PathBuf/Cow), mutabilità interna (Cell/RefCell/OnceCell/OnceLock), flussi I/O (Lettura/Scrittura/BufRead), iteratori, combinatori di opzioni/risultati, thread e canali mpsc, tempo (Durata/Istantaneo/SystemTime), percorsi, env, processo, fs, net e decisioni di selezione del modulo. Utilizzare quando gli utenti chiedono "quale tipo std dovrei usare", confrontare alternative di raccolta/puntatore/stringa, progettare catene di opzioni/risultati, scegliere Cell vs RefCell vs Mutex, lavorare con thread/canali std o scegliere il modulo std giusto per un'attività; passare il runtime asincrono alla concorrenza ruggine, la semantica del linguaggio a stabile e le preoccupazioni a livello di applicazione alle competenze di dominio.
