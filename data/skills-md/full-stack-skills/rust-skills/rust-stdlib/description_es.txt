Seleccionar y componer API de biblioteca estándar de Rust: colecciones (HashMap/BTreeMap/Vec/VecDeque/LinkedList/BinaryHeap), punteros inteligentes (Box/Rc/Arc/RefCell/Mutex/OnceLock/LazyLock), tipos de cadenas (String/&str/OsString/PathBuf/Cow), mutabilidad interior (Cell/RefCell/OnceCell/OnceLock), flujos de E/S (Lectura/Escritura/BufRead), iteradores, combinadores de opciones/resultados, subprocesos y canales mpsc, tiempo (Duración/Instante/Tiempo del sistema), rutas, entorno, proceso, fs, red y decisiones de selección de módulos. Úselo cuando los usuarios pregunten "qué tipo estándar debo usar", compare alternativas de colección/puntero/cadena, diseñe cadenas de opciones/resultados, elija Cell vs RefCell vs Mutex, trabaje con subprocesos/canales estándar o elija el módulo estándar correcto para una tarea; entregue el tiempo de ejecución asíncrono a la concurrencia oxidada, la semántica del lenguaje a la estabilidad oxidada y las preocupaciones de la capa de aplicación a las habilidades de dominio.
