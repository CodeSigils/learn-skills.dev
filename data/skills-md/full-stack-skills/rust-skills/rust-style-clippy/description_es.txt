Aplique y diagnostique el estilo Rust, Rustfmt, Clippy, diagnósticos del compilador, migraciones de edición, política de pelusa, flujo de control idiomático, manejo de errores, comportamiento de asignación, convenciones de producción de Rust y Directrices de la API de Rust ↔ Mapeo de pelusa de Clippy. Úselo cuando los usuarios soliciten formatear o eliminar Rust, corregir códigos de advertencia o error, migrar ediciones, revisar el uso de desempaquetado o clonación, mejorar modismos, asignar una regla de guía de API C-* a Clippy lint que se aplica o establecer puertas de calidad de CI. Enrute las decisiones sobre la forma de la API (convenciones de nomenclatura, diseño de tipo/rasgo, diseño del módulo, revisión completa de las pautas de C-*) a la habilidad de diseño de API de Rust.
