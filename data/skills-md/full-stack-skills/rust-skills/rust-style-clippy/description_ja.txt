Rust スタイル、rustfmt、Clippy、コンパイラ診断、エディションの移行、lint ポリシー、慣用的な制御フロー、エラー処理、割り当て動作、実稼働 Rust 規約、および Rust API ガイドライン ↔ Clippy lint マッピングを適用および診断します。ユーザーが Rust のフォーマットまたは lint、警告コードまたはエラー コードの修正、エディションの移行、アンラップまたはクローンの使用方法の確認、イディオムの改善、C-* API ガイドライン ルールの適用対象 Clippy lint へのマッピング、または CI 品質ゲートの確立を要求する場合に使用します。 API 形状の決定 (命名規則、型/特性設計、モジュール レイアウト、完全な C-* ガイドライン レビュー) を Rust-API-Design スキルにルーティングします。
