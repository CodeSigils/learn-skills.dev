تطبيق وتشخيص نمط Rust، وrustfmt، وClippy، وتشخيصات المترجم، وترحيلات الإصدار، وسياسة الوبر، وتدفق التحكم الاصطلاحي، ومعالجة الأخطاء، وسلوك التخصيص، واتفاقيات Rust للإنتاج، وإرشادات Rust API ↔ رسم خرائط Clippy lint. يُستخدم عندما يطلب المستخدمون تنسيق Rust أو فحصه، أو إصلاح رموز التحذير أو الخطأ، أو ترحيل الإصدارات، أو مراجعة استخدام إلغاء التغليف أو الاستنساخ، أو تحسين المصطلحات، أو تعيين قاعدة إرشادات C-* API لفرض Clippy Lint، أو إنشاء بوابات جودة CI. قم بتوجيه قرارات شكل واجهة برمجة التطبيقات (اصطلاحات التسمية، وتصميم النوع/السمات، وتخطيط الوحدة، ومراجعة إرشادات C-* الكاملة) إلى مهارة تصميم واجهة برمجة التطبيقات الصدأ.
