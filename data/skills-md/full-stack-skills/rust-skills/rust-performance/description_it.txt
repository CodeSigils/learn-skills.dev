Misura, profila, ottimizza e testa la regressione delle prestazioni di Rust in termini di latenza, throughput, CPU, allocazioni, memoria, dimensioni binarie e tempo di compilazione utilizzando carichi di lavoro rappresentativi, Criterion, iai-callgrind, cargo-flamegraph, samply, DHAT, strumenti heap o pprof, cargo-bloat, cargo-llvm-lines e tempistiche di costruzione. Da utilizzare quando gli utenti segnalano codice Rust lento, memoria o CPU elevata, file binari di grandi dimensioni, benchmark rumorosi, regressioni della latenza della coda o necessitano di budget per le prestazioni e ottimizzazione supportata da prove.
