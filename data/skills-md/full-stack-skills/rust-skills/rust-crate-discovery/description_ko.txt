채택을 위한 Rust 크레이트를 발견, 평가, 점수 매기기 및 비교 — crates.io를 검색하고, 4개 소스(crates.io API, docs.rs, GitHub API, RustSec 자문 DB)에서 메타데이터를 가져오고, 채택/유지 관리/문서화/성숙/커뮤니티/라이선스 전반에 걸쳐 가중치 0-100 점수 모델을 적용하고, 빨간색 문제(유지 관리되지 않음, 권고, 문서 없음, 단일 유지 관리자)에 플래그를 지정하고 가장 적합한 것을 추천합니다. 사용자가 "X에 어떤 크레이트를 사용해야 합니까?", "이 크레이트가 유지 관리/안전/인기 있습니까?", "이 3개 크레이트를 비교"하거나 채택하기 전에 종속성을 선택해야 할 때 사용합니다. 채택 후 거버넌스(화물 거부, 라이센스 정책, 자문 대응)를 Rust-종속성에 전달하고, semver 및 주요 변경 분류를 Rust-semver에, 매니페스트 메커니즘을 Rust-cargo-build에 전달합니다.
