Находите, оценивайте, оценивайте и сравнивайте крейты Rust для внедрения — найдите crates.io, извлекайте метаданные из 4 источников (Crates.io API, docs.rs, GitHub API, консультативная база данных RustSec), применяйте взвешенную модель оценки 0–100 для внедрения/обслуживания/документации/зрелости/сообщества/лицензии, отмечайте красными проблемы (неподдерживаемые, рекомендации, нет документации, единое сопровождение) и рекомендуйте лучшее подходит. Используйте, когда пользователи спрашивают «какой ящик мне следует использовать для X», «поддерживается ли этот ящик/безопасен/популярен», «сравните эти 3 ящика» или нужно выбрать зависимость перед принятием; передать управление после принятия (отказ от загрузки, политика лицензирования, консультативный ответ) на зависимости от ржавчины, классификацию семвера и критических изменений в ржавчину-семвер, а также механику манифеста для ржавчины-грузовой сборки.
