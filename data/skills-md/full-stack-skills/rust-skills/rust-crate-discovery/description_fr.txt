Découvrez, évaluez, notez et comparez les caisses Rust pour l'adoption - recherchez crates.io, récupérez les métadonnées de 4 sources (API crates.io, docs.rs, API GitHub, base de données consultative RustSec), appliquez un modèle de notation pondéré de 0 à 100 pour l'adoption/maintenance/documentation/maturité/communauté/licence, signalez les problèmes en rouge (non maintenus, avis, pas de documentation, responsable unique) et recommandez la meilleure solution. À utiliser lorsque les utilisateurs demandent « quelle caisse dois-je utiliser pour X », « cette caisse est-elle entretenue/sûre/populaire », « comparez ces 3 caisses » ou doivent choisir une dépendance avant l'adoption ; confiez la gouvernance post-adoption (refus de fret, politique de licence, réponse consultative) aux dépendances à la rouille, la classification semver et les changements de rupture à rust-semver, et la mécanique manifeste à la construction de cargo-rouille.
