導入に向けて Rust クレートを発見、評価、スコア付け、比較します。 crates.io を検索し、4 つのソース (crates.io API、docs.rs、GitHub API、RustSec アドバイザリー DB) からメタデータを取得し、採用/メンテナンス/ドキュメント/成熟度/コミュニティ/ライセンス全体で加重 0 ～ 100 のスコアリング モデルを適用し、危険な懸念事項 (メンテナンスされていない、勧告、ドキュメントなし、単一メンテナ) にフラグを立て、ベストフィット。ユーザーが「X にはどのクレートを使用すべきか」、「このクレートは維持されているか、安全か、人気があるか」、「これら 3 つのクレートを比較」、または採用前に依存関係を選択する必要がある場合に使用します。採用後のガバナンス (貨物拒否、ライセンス ポリシー、勧告への対応) を Rust 依存関係に、セムバーと重大な変更の分類を Rust セムバーに、マニフェスト メカニズムを Rust-Cargo-Build に引き渡します。
