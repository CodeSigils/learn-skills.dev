اكتشاف صناديق الصدأ وتقييمها وتسجيلها ومقارنتها - ابحث في صناديق الصدأ وجلب البيانات الوصفية من 4 مصادر (crates.io API وdocs.rs وGitHub API وRustSec الاستشارية DB)، وقم بتطبيق نموذج تسجيل مرجح من 0 إلى 100 عبر الاعتماد/الصيانة/الوثائق/النضج/المجتمع/الترخيص، وضع علامة حمراء على المخاوف (غير الخاضعة للصيانة، الاستشارات، لا توجد مستندات، مشرف واحد)، والتوصية الأفضل. يُستخدم عندما يسأل المستخدمون "أي صندوق يجب أن أستخدمه لـ X"، أو "هل هذا الصندوق محتفظ به/آمن/مشهور"، أو "قارن بين هذه الصناديق الثلاثة"، أو بحاجة إلى اختيار تبعية قبل التبني؛ تسليم حوكمة ما بعد الاعتماد (رفض البضائع، سياسة الترخيص، الاستجابة الاستشارية) لتبعيات الصدأ، وتصنيف التغيير والكسر إلى الصدأ، والميكانيكا الواضحة لبناء البضائع الصدأ.
