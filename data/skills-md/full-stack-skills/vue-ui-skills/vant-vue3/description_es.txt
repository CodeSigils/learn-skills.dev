Proporciona orientación estructurada para Vant of Vue 3.0. Úselo cuando el usuario necesite Vant con Vue 3, pregunte sobre componentes de la interfaz de usuario móvil como Button, Cell, Form, Dialog, Toast, Popup, ConfigProvider, personalización de temas, configuración de proyectos o quiera implementar interfaces móviles primero con componentes `vant` o `van-`. Esta habilidad está alineada con el sitio web oficial de Vant y la guía de uso y debe usarse como entrada de habilidad de Vant Vue 3.
