Предоставляет структурированное руководство по Vant of Vue 3.0. Используйте, когда пользователю нужен Vant с Vue 3, он спрашивает о мобильных компонентах пользовательского интерфейса, таких как кнопка, ячейка, форма, диалог, Toast, всплывающее окно, ConfigProvider, настройке темы, настройке проекта или хочет реализовать мобильные интерфейсы с компонентами `vant` или `van-`. Этот навык соответствует официальному веб-сайту Vant и руководству по использованию и должен использоваться в качестве записи навыка Vant Vue 3.
