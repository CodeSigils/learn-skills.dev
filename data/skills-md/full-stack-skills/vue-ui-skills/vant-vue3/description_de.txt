Bietet strukturierte Anleitungen für Vant of Vue 3.0. Verwenden Sie es, wenn der Benutzer Vant mit Vue 3 benötigt, nach mobilen UI-Komponenten wie Button, Cell, Form, Dialog, Toast, Popup, ConfigProvider, Theme-Anpassung, Projekteinrichtung fragt oder Mobile-First-Schnittstellen mit „vant“- oder „van-“-Komponenten implementieren möchte. Dieser Skill ist auf die offizielle Vant-Website und das Nutzungshandbuch abgestimmt und sollte als Vant Vue 3-Skill-Eintrag verwendet werden.
