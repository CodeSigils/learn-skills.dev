Vant of Vue 3.0 の構造化されたガイダンスを提供します。ユーザーが Vue 3 で Vant を必要とする場合、ボタン、セル、フォーム、ダイアログ、トースト、ポップアップ、ConfigProvider などのモバイル UI コンポーネントについて問い合わせる場合、テーマのカスタマイズ、プロジェクトのセットアップ、または「vant」または「van-」コンポーネントを使用してモバイル ファースト インターフェイスを実装したい場合に使用します。このスキルは Vant の公式 Web サイトおよび使用ガイドに準拠しており、Vant Vue 3 スキル エントリとして使用する必要があります。
