Fournit des conseils structurés pour Vant de Vue 3.0. À utiliser lorsque l'utilisateur a besoin de Vant avec Vue 3, pose des questions sur les composants de l'interface utilisateur mobile tels que Button, Cell, Form, Dialog, Toast, Popup, ConfigProvider, la personnalisation du thème, la configuration du projet ou souhaite implémenter des interfaces mobiles avec des composants `vant` ou `van-`. Cette compétence est alignée sur le site Web officiel de Vant et sur le guide d'utilisation et doit être utilisée comme entrée de compétence Vant Vue 3.
