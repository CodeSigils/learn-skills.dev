يوفر إرشادات منظمة لـ Vant of Vue 3.0. يُستخدم عندما يحتاج المستخدم إلى Vant مع Vue 3، أو يسأل عن مكونات واجهة المستخدم المحمولة مثل Button، أو Cell، أو Form، أو Dialog، أو Toast، أو Popup، أو ConfigProvider، أو تخصيص السمة، أو إعداد المشروع، أو يريد تنفيذ واجهات الهاتف المحمول الأولى مع مكونات `vant` أو `van-`. تتوافق هذه المهارة مع موقع Vant الرسمي ودليل الاستخدام ويجب استخدامها كمدخل لمهارة Vant Vue 3.
