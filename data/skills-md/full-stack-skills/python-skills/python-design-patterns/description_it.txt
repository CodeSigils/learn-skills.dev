Modelli di progettazione Python tra cui KISS, Separation of Concerns, Single Responsibility e composizione sull'ereditarietà. Utilizzare questa competenza quando si progetta un nuovo servizio o componente da zero e si sceglie come stratificare le responsabilità, quando si esegue il refactoring di una classe God o di una funzione monolitica diventata troppo grande, quando si decide se aggiungere una nuova astrazione o convivere con la duplicazione, quando si valuta una richiesta pull per problemi strutturali come accoppiamento stretto o perdita di tipi interni, quando si sceglie tra ereditarietà e composizione per una nuova gerarchia di classi o quando una base di codice sta diventando difficile da testare a causa di I/O e logica di business intricati.
