Patrones de diseño de Python que incluyen KISS, separación de preocupaciones, responsabilidad única y composición sobre herencia. Utilice esta habilidad cuando diseñe un nuevo servicio o componente desde cero y elija cómo asignar responsabilidades en capas, cuando refactorice una clase de Dios o una función monolítica que haya crecido demasiado, cuando decida si agregar una nueva abstracción o vivir con la duplicación, cuando evalúe una solicitud de extracción para problemas estructurales como acoplamiento estrecho o tipos internos con fugas, cuando elija entre herencia y composición para una nueva jerarquía de clases, o cuando una base de código se esté volviendo difícil de probar debido a E/S entrelazadas y lógica de negocios.
