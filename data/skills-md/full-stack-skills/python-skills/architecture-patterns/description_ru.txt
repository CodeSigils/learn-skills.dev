Внедряйте проверенные шаблоны серверной архитектуры, включая чистую архитектуру, шестиугольную архитектуру и доменно-ориентированное проектирование. Используйте этот навык при проектировании чистой архитектуры для нового микросервиса, при рефакторинге монолита для использования ограниченных контекстов, при реализации шаблонов шестиугольной или луковичной архитектуры или при отладке циклов зависимостей между уровнями приложения.
