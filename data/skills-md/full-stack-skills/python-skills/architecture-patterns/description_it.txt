Implementa modelli di architettura backend comprovati, tra cui architettura pulita, architettura esagonale e progettazione basata sul dominio. Utilizza questa competenza quando progetti un'architettura pulita per un nuovo microservizio, quando esegui il refactoring di un monolite per utilizzare contesti limitati, quando implementi modelli di architettura esagonale o a cipolla o quando esegui il debug dei cicli di dipendenza tra i livelli dell'applicazione.
