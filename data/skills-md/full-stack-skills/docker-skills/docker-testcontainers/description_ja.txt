Testcontainers のガイダンス — 自動化された統合テストで Docker コンテナを実行します。 Java (@Testcontainers、@Container、PostgreSQL/Redis/Kafka/Elasticsearch)、Python (testcontainers-python と pytest)、コンテナーのライフサイクル管理 (シングルトン、再利用)、CI/CD 統合 (Docker-in-Docker、Ryuk)、Testcontainer のベスト プラクティス、およびデータベース移行テストをカバーします。ユーザーがテストコンテナ、Docker との統合テスト、データベーステスト、Java テストコンテナ、Python テストコンテナについて質問する場合、または実際の Docker サービスを使用してテストする必要がある場合に使用します。 使用场景：testcontainers、集成测试、docker 测试、データベース库测试、Java Testcontainers、Python Testcontainers。
