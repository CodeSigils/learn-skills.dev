إرشادات لحاويات الاختبار - تشغيل حاويات Docker في اختبارات التكامل الآلية. يغطي Java (@Testcontainers، و@Container، وPostgreSQL/Redis/Kafka/Elasticsearch)، وPython (testcontainers-python with pytest)، وإدارة دورة حياة الحاوية (مفردة، وإعادة الاستخدام)، وتكامل CI/CD (Docker-in-Docker، وRyuk)، وأفضل ممارسات Testcontainer، واختبار ترحيل قاعدة البيانات. يُستخدم عندما يسأل المستخدم عن حاويات الاختبار، أو اختبار التكامل مع Docker، أو اختبار قاعدة البيانات، أو حاويات اختبار Java، أو حاويات اختبار Python، أو يحتاج إلى الاختبار باستخدام خدمات Docker الحقيقية. القائمة: حاويات الاختبار، حاوية الاختبار، حاوية عامل الإرساء، حاوية الاختبار، حاوية اختبار Java، حاوية اختبار بايثون.
