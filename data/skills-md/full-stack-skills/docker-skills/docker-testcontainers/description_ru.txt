Руководство для тестконтейнеров — запуск Docker-контейнеров в автоматических интеграционных тестах. Охватывает Java (@Testcontainers, @Container, PostgreSQL/Redis/Kafka/Elasticsearch), Python (testcontainers-python с pytest), управление жизненным циклом контейнера (singleton, повторное использование), интеграцию CI/CD (Docker-in-Docker, Ryuk), лучшие практики Testcontainer и тестирование миграции базы данных. Используйте, когда пользователь спрашивает о тестовых контейнерах, тестировании интеграции с Docker, тестировании базы данных, тестовых контейнерах Java, тестовых контейнерах Python или ему необходимо протестировать реальные сервисы Docker. Например, тестовые контейнеры, тестовые контейнеры Java, тестовые контейнеры Python, тестовые контейнеры Python.
