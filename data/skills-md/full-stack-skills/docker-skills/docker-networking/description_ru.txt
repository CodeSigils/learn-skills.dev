Руководство по настройке сети Docker и взаимодействию между контейнерами. Охватывает сетевые режимы (мост/хост/оверлей/нет/macvlan/ipvlan), настраиваемые мостовые сети с разрешением DNS, публикацию портов (-p/--publish), связывание контейнеров и обнаружение сервисов, устранение неполадок сети (inspect/ping/nslookup), наложение сетей для Swarm и сетевую безопасность (внутренние сети, зашифрованное наложение). Используйте, когда пользователь спрашивает о сети Docker, сети контейнеров, режиме моста, сопоставлении портов, взаимодействии между контейнерами, устранении неполадок в сети или сетевых режимах Docker. Например: сеть докеров, мост, оверлей, док-станция, сеть докеров, мост, оверлей.
