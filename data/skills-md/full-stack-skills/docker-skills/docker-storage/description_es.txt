Guía para el almacenamiento de Docker y la persistencia de datos. Cubre tipos de almacenamiento (Volumen/Bind Mount/Tmpfs) con comparación y selección de casos de uso, administración del ciclo de vida del volumen (create/ls/inspect/prune), patrones de montaje de enlaces, tmpfs para datos efímeros, estrategias de respaldo y restauración, selección de controladores de almacenamiento (overlay2), mejores prácticas de persistencia de bases de datos (PostgreSQL/MySQL/Redis) e integración de almacenamiento en la nube/NFS. Úselo cuando el usuario pregunte sobre el volumen de Docker, la persistencia de datos, el montaje de enlace, tmpfs, el controlador de almacenamiento, la copia de seguridad, el volumen de datos o necesite almacenamiento persistente para contenedores. 使用场景：docker volume、数据持久化、bind mount、tmpfs、存储驱动、数据卷、备份恢复、数据库持久化.
