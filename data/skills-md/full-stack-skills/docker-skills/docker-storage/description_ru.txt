Руководство по хранению и сохранению данных Docker. Охватывает типы хранилищ (Volume/Bind Mount/Tmpfs) со сравнением и выбором варианта использования, управление жизненным циклом тома (создание/ls/inspect/prune), шаблоны привязки монтирования, tmpfs для эфемерных данных, стратегии резервного копирования и восстановления, выбор драйвера хранилища (overlay2), лучшие практики сохранения базы данных (PostgreSQL/MySQL/Redis) и интеграцию NFS/облачного хранилища. Используйте, когда пользователь спрашивает о томе докера, постоянстве данных, монтировании привязки, tmpfs, драйвере хранилища, резервном копировании, томе данных или о необходимости постоянного хранилища для контейнеров. Например: том Docker, Bind Mount, tmpfs, 存储驱动, 数据卷, 备份恢复, 数据库持久化.
