Docker 스토리지 및 데이터 지속성에 대한 지침입니다. 비교 및 사용 사례 선택, 볼륨 수명 주기 관리(create/ls/inspect/prune), 바인드 마운트 패턴, 임시 데이터용 tmpfs, 백업 및 복원 전략, 스토리지 드라이버 선택(overlay2), 데이터베이스 지속성 모범 사례(PostgreSQL/MySQL/Redis) 및 NFS/클라우드 스토리지 통합을 포함한 스토리지 유형(볼륨/바인드 마운트/Tmpfs)을 다룹니다. 사용자가 Docker 볼륨, 데이터 지속성, 바인드 마운트, tmpfs, 스토리지 드라이버, 백업, 데이터 볼륨에 대해 질문하거나 컨테이너를 위한 영구 스토리지가 필요한 경우 사용합니다. 사용 가능한 도구: 도커 볼륨, 数据持久化, 바인드 마운트, tmpfs, 存储驱动, 数据卷, 备份恢复, 数据库持久化.
