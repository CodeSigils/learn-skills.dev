Docker を CI/CD パイプラインに統合するためのガイダンス。 GitHub アクション (docker/build-push-action、buildx によるマルチプラットフォーム ビルド、cache-from/to)、Jenkins Pipeline (Docker エージェント、ビルド/プッシュ ステージ)、高速ビルドのための Docker Build Cloud、CI のレイヤー キャッシュ戦略、CI/CD のイメージ タグ付け戦略、デプロイ パターン (ローリング アップデート、ブルー グリーン) をカバーします。ユーザーが Docker CI/CD、GitHub Actions Docker、Jenkins Docker パイプライン、buildx マルチプラットフォーム、Docker Build Cloud について質問する場合、または Docker ビルドを自動化する必要がある場合に使用します。 使用场景：docker CI/CD、GitHub Actions docker、Jenkins docker、buildx、多平台构建、Docker Build Cloud、流水線。
