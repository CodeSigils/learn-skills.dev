Linee guida per l'integrazione di Docker nelle pipeline CI/CD. Copre azioni GitHub (docker/build-push-action, build multipiattaforma con buildx, cache-from/to), Jenkins Pipeline (agente Docker, fasi di build/push), Docker Build Cloud per build accelerate, strategie di memorizzazione nella cache dei livelli in CI, strategie di tagging delle immagini per CI/CD, modelli di distribuzione (aggiornamento in sequenza, blu-verde). Da utilizzare quando l'utente chiede informazioni su Docker CI/CD, GitHub Actions Docker, pipeline Jenkins Docker, buildx multipiattaforma, Docker Build Cloud o deve automatizzare le build Docker. Caratteristiche principali: docker CI/CD, docker GitHub Actions, docker Jenkins, buildx, 多平台构建, Docker Build Cloud, 流水线.
