Conseils pour l’intégration de Docker dans les pipelines CI/CD. Couvre les actions GitHub (docker/build-push-action, builds multiplateformes avec buildx, cache-from/to), Jenkins Pipeline (agent Docker, étapes de build/push), Docker Build Cloud pour les builds accélérés, les stratégies de mise en cache des couches dans CI, les stratégies de marquage d'images pour CI/CD, les modèles de déploiement (mise à jour continue, bleu-vert). À utiliser lorsque l'utilisateur pose des questions sur Docker CI/CD, GitHub Actions Docker, le pipeline Jenkins Docker, buildx multi-plateforme, Docker Build Cloud ou a besoin d'automatiser les builds Docker. Il s'agit d'un docker CI/CD, d'un docker GitHub Actions, d'un docker Jenkins, d'un buildx, d'un docker Build Cloud.
