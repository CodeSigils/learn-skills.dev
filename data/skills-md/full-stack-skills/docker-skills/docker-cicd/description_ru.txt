Руководство по интеграции Docker в конвейеры CI/CD. Охватывает действия GitHub (docker/build-push-action, многоплатформенные сборки с buildx, кеширование из/в), Jenkins Pipeline (агент Docker, этапы сборки/отправки), Docker Build Cloud для ускоренных сборок, стратегии кэширования слоев в CI, стратегии маркировки образов для CI/CD, шаблоны развертывания (последовательное обновление, сине-зеленый). Используйте, когда пользователь спрашивает о Docker CI/CD, GitHub Actions Docker, конвейере Jenkins Docker, многоплатформенном buildx, Docker Build Cloud или необходимо автоматизировать сборки Docker. Примеры использования: docker CI/CD, GitHub Actions docker, Jenkins docker, buildx, 多平台构建, Docker Build Cloud.
