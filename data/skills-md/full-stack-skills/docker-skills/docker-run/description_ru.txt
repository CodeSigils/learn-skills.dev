Руководство по запуску и управлению контейнерами Docker. Охватывает полный жизненный цикл контейнера (создание/запуск/остановка/rm/перезапуск), ограничения ресурсов (--memory/--cpus), проверки работоспособности (HEALTHCHECK), политики перезапуска, протоколирование драйверов, проверку контейнера (inspect/stats/top), отладку выполнения и обработку сигналов. Используйте, когда пользователь спрашивает о запуске Docker, управлении контейнерами, ограничениях ресурсов, проверках работоспособности, журналах Docker, выполнении Docker, политиках перезапуска или необходимости управления запущенными контейнерами. 使用场景: docker run, docker logs, docker exec, docker ps.
