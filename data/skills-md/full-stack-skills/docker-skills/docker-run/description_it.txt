Linee guida per l'esecuzione e la gestione dei contenitori Docker. Copre il ciclo di vita completo del contenitore (crea/start/stop/rm/restart), i vincoli delle risorse (--memory/--cpus), i controlli di integrità (HEALTHCHECK), le policy di riavvio, i driver di registrazione, l'ispezione del contenitore (inspect/stats/top), il debug exec e la gestione dei segnali. Da utilizzare quando l'utente richiede informazioni sull'esecuzione di docker, sulla gestione dei contenitori, sui limiti delle risorse, sui controlli di integrità, sui log di docker, su docker exec, sulle policy di riavvio o se deve gestire i contenitori in esecuzione. Elenco dei file: docker run, docker run, docker logs, docker exec, docker ps.
