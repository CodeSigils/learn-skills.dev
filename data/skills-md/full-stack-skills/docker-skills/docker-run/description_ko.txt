Docker 컨테이너 실행 및 관리에 대한 지침입니다. 전체 컨테이너 수명 주기(생성/시작/중지/rm/다시 시작), 리소스 제약 조건(--memory/--cpus), 상태 확인(HEALTHCHECK), 다시 시작 정책, 로깅 드라이버, 컨테이너 검사(inspect/stats/top), 실행 디버깅 및 신호 처리를 다룹니다. 사용자가 docker 실행, 컨테이너 관리, 리소스 제한, 상태 확인, docker 로그, docker exec, 다시 시작 정책에 대해 질문하거나 실행 중인 컨테이너를 관리해야 할 때 사용합니다. 사용 가능한 도구: docker run, 容器管理, 资源限system, 健康检查, 重启策略, docker 로그, docker exec, docker ps.
