Conseils pour exécuter et gérer les conteneurs Docker. Couvre le cycle de vie complet du conteneur (create/start/stop/rm/restart), les contraintes de ressources (--memory/--cpus), les vérifications de l'état (HEALTHCHECK), les politiques de redémarrage, les pilotes de journalisation, l'inspection des conteneurs (inspect/stats/top), le débogage de l'exécution et la gestion des signaux. À utiliser lorsque l'utilisateur pose des questions sur l'exécution de Docker, la gestion des conteneurs, les limites de ressources, les vérifications de l'état, les journaux de Docker, l'exécution de Docker, les politiques de redémarrage ou doit gérer les conteneurs en cours d'exécution. Il s'agit de Docker Run, de fichiers Docker Logs, de Docker Exec, de Docker PS.
