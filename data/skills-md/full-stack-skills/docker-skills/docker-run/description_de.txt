Anleitung zum Ausführen und Verwalten von Docker-Containern. Deckt den gesamten Container-Lebenszyklus (Erstellen/Starten/Stoppen/RM/Neustart), Ressourceneinschränkungen (--memory/--cpus), Gesundheitsprüfungen (HEALTHCHECK), Neustartrichtlinien, Protokollierungstreiber, Containerinspektion (inspect/stats/top), Exec-Debugging und Signalverarbeitung ab. Verwenden Sie diese Option, wenn der Benutzer nach Docker-Ausführung, Containerverwaltung, Ressourcenlimits, Integritätsprüfungen, Docker-Protokollen, Docker-Exec, Neustartrichtlinien fragt oder laufende Container verwalten muss. Beispiele: Docker Run, Docker Run, Docker Exec, Docker PS, Docker Logs, Docker Exec, Docker PS.
