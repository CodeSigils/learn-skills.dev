Docker コンテナの実行と管理に関するガイダンス。完全なコンテナーのライフサイクル (作成/開始/停止/rm/再起動)、リソース制約 (--memory/--cpus)、ヘルスチェック (HEALTHCHECK)、再起動ポリシー、ログドライバー、コンテナー検査 (inspect/stats/top)、実行デバッグ、およびシグナル処理をカバーします。ユーザーが docker run、コンテナー管理、リソース制限、ヘルスチェック、docker ログ、docker exec、再起動ポリシーについて質問する場合、または実行中のコンテナーを管理する必要がある場合に使用します。 使用環境：docker run、コンテナ管理、资源制限、健康检查、重启策略、docker logs、docker exec、docker ps。
