Docker 문제 디버깅 및 문제 해결을 위한 지침입니다. 컨테이너 시작 실패(종료 코드, docker 로그, 검사), 디스크 공간 고갈(시스템 df/prune, 로그 회전), OOM 및 리소스 부족(메모리 제한, 통계), 네트워크 연결 문제(네트워크 검사, iptables, DNS 확인), 스토리지 문제(권한 거부, 볼륨 검사), 데몬 문제(dockerd 시작, 소켓 권한) 및 일반 오류 진단을 다룹니다. 사용자가 Docker 문제 해결, Docker 디버그, OOM, 디스크 가득 참, 네트워크 문제, Docker 시작 안 됨, 컨테이너 충돌 또는 Docker 문제를 조사해야 하는 경우에 사용합니다. 사용 가능한 기능: docker 排查, docker debug, 容器问题, OOM, 磁盘满, 网络不平, 启动失败, 配置问题.
