Docker の問題のデバッグとトラブルシューティングに関するガイダンス。コンテナ起動の失敗 (終了コード、Docker ログ、検査)、ディスク領域の枯渇 (システム DF/プルーン、ログ ローテーション)、OOM とリソースの圧迫 (メモリ制限、統計)、ネットワーク接続の問題 (ネットワーク検査、iptables、DNS 解決)、ストレージの問題 (アクセス許可の拒否、ボリューム検査)、デーモンの問題 (dockerd の起動、ソケットのアクセス許可)、および一般的なエラー診断をカバーします。ユーザーが Docker のトラブルシューティング、Docker デバッグ、OOM、ディスクがいっぱいである、ネットワークの問題、Docker が起動しない、コンテナーのクラッシュについて尋ねた場合、または Docker の問題を調査する必要がある場合に使用します。 使用场景：docker排查、docker debug、コンテナ问题、OOM、磁盘满、网络不通、启动失败、構成问题。
