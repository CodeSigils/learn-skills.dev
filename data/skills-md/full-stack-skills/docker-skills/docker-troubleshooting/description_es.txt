Guía para depurar y solucionar problemas de Docker. Cubre fallas de inicio de contenedores (códigos de salida, registros de Docker, inspección), agotamiento del espacio en disco (sistema df/prune, rotación de registros), OOM y presión de recursos (límites de memoria, estadísticas), problemas de conectividad de red (inspección de red, iptables, resolución de DNS), problemas de almacenamiento (permiso denegado, inspección de volumen), problemas de demonio (inicio de Dockerd, permisos de socket) y diagnóstico de errores comunes. Úselo cuando el usuario pregunte sobre la solución de problemas de Docker, la depuración de Docker, OOM, el disco lleno, problemas de red, Docker que no se inicia, falla del contenedor o necesita investigar problemas de Docker. 使用场景：docker 排查、docker debug、容器问题、OOM、磁盘满、网络不通、启动失败、配置问题.
