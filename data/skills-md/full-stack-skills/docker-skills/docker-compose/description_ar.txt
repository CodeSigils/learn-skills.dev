إرشادات الخبراء لـ Docker Compose - كتابة ملفات compose.yml على مستوى الإنتاج للتطبيقات متعددة الحاويات. يغطي بناء جملة ملف الإنشاء بالكامل (الخدمات، والشبكات، ووحدات التخزين، والأسرار، والتكوينات، والملفات الشخصية، والتوسيع، والتضمين)، وتكوين الخدمة (الصورة/الإنشاء، والمنافذ، والبيئة، وenv_file، ويعتمد على عمليات التحقق من السلامة، ونشر الموارد، وسياسات إعادة التشغيل)، والشبكات في الإنشاء (الشبكات الافتراضية، والشبكات المخصصة، والشبكات الداخلية)، وإدارة الحجم، واستراتيجيات متغيرات البيئة (.env مقابل البيئة مقابل env_file)، وتجاوز الملفات للبيئات المتعددة، وملفات التعريف الاختيارية الخدمات، والهجرة إلى Kubernetes باستخدام kompose. يُستخدم عندما يسأل المستخدم عن إنشاء عامل ميناء، أو docker-compose.yml، أو إنشاء ملف، أو حاويات متعددة، أو تنسيق الخدمة، أو تكوين الإنشاء، أو يحتاج إلى كتابة/تعديل ملف إنشاء. أنواع البيانات: docker compose، docker-compose.yml، compose 文件، 多容器، 服务编排، compose 配置، يعتمد على، ملفات التعريف.
