Docker Compose 专家指南 — 为多容器应用程序编写生产级 compose.yml 文件。涵盖完整的 Compose 文件语法（服务、网络、卷、机密、配置、配置文件、扩展、包含）、服务配置（映像/构建、端口、环境、env_file、depends_on 与运行状况检查、部署资源、重启策略）、Compose 中的网络（默认网络、自定义网络、内部网络）、卷管理、环境变量策略（.env 与环境与 env_file）、多环境覆盖文件、可选服务的配置文件以及使用 kompose 迁移到 Kubernetes。当用户询问 docker compose、docker-compose.yml、compose 文件、多容器、服务编排、compose 配置或需要编写/修改 compose 文件时使用。 使用场景：docker compose、docker-compose.yml、compose文件、多容器、服务编排、compose配置、depends_on、profiles。
