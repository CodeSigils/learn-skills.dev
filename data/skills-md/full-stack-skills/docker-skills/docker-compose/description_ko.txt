Docker Compose에 대한 전문가 지침 — 다중 컨테이너 애플리케이션을 위한 프로덕션 등급 compose.yml 파일 작성. 전체 Compose 파일 구문(서비스, 네트워크, 볼륨, 비밀, 구성, 프로필, 확장, 포함), 서비스 구성(이미지/빌드, 포트, 환경, env_file, 상태 확인을 통한 종속, 리소스 배포, 정책 다시 시작), Compose의 네트워킹(기본 네트워크, 사용자 정의 네트워크, 내부 네트워크), 볼륨 관리, 환경 변수 전략(.env 대 환경 대 env_file), 다중 환경에 대한 파일 재정의, 선택적 서비스에 대한 프로필 및 Kubernetes로의 마이그레이션을 다룹니다. 구성하다. 사용자가 docker compose, docker-compose.yml, compose 파일, 다중 컨테이너, 서비스 오케스트레이션, compose 구성에 대해 질문하거나 compose 파일을 작성/수정해야 할 때 사용합니다. 使用场景：docker compose、docker-compose.yml、文件、多容器、服务编排、compose 配置、dependent_on、profiles를 작성합니다.
