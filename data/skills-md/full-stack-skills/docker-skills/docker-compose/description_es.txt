Guía de expertos para Docker Compose: escritura de archivos compose.yml de nivel de producción para aplicaciones de múltiples contenedores. Cubre la sintaxis completa del archivo Compose (servicios, redes, volúmenes, secretos, configuraciones, perfiles, extensiones, inclusión), configuración del servicio (imagen/compilación, puertos, entorno, env_file, depende de con comprobaciones de estado, implementación de recursos, políticas de reinicio), redes en Compose (redes predeterminadas, redes personalizadas, redes internas), gestión de volúmenes, estrategias de variables de entorno (.env vs entorno vs env_file), anulación de archivos para entornos múltiples, perfiles para servicios opcionales y migración a Kubernetes con kompose. Úselo cuando el usuario pregunta sobre Docker Compose, docker-compose.yml, archivo de redacción, contenedor múltiple, orquestación de servicios, configuración de redacción o necesita escribir/modificar un archivo de redacción. Ejemplos de uso: docker compose, docker-compose.yml, componentes de compose, dependencias_de, perfiles.
