Docker Scout のガイダンス — イメージの脆弱性スキャン、SBOM 生成、およびポリシー評価。 CVE のスカウト クイックビュー、詳細な脆弱性分析のためのスカウト CVE、ソフトウェア部品表のスカウト sbom、カスタム ルールによるポリシー評価、CI/CD 統合 (GitHub Actions/Jenkins)、および修復ガイダンスをカバーします。ユーザーが Docker スカウト、脆弱性スキャン、CVE、SBOM、イメージ分析、セキュリティ脆弱性について質問する場合、またはセキュリティ上の問題について Docker イメージをスキャンする必要がある場合に使用します。 使用场景：docker recruit、漏洞扫描、CVE、SBOM、镜像安全分析、安全漏洞、软件物質材料清单。
