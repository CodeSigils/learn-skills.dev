Руководство для Docker Scout — сканирование образов на уязвимости, создание SBOM и оценка политик. Охватывает быстрый просмотр CVE, поиск CVE для подробного анализа уязвимостей, поиск спецификации программного обеспечения, оценку политики с помощью пользовательских правил, интеграцию CI/CD (GitHub Actions/Jenkins) и рекомендации по исправлению. Используйте, когда пользователь спрашивает о Docker Scout, сканировании уязвимостей, CVE, SBOM, анализе изображений, уязвимостях безопасности или ему необходимо сканировать образы Docker на наличие проблем безопасности. Например: docker scout, CVE, SBOM, 镜像安全分析,安全漏洞,软件物料清单.
