Guía para Docker Scout: escaneo de vulnerabilidades de imágenes, generación de SBOM y evaluación de políticas. Cubre la vista rápida de exploración para CVE, cves de exploración para un análisis de vulnerabilidad detallado, sbom de exploración para la lista de materiales de software, evaluación de políticas con reglas personalizadas, integración de CI/CD (GitHub Actions/Jenkins) y orientación sobre remediación. Úselo cuando el usuario pregunte sobre Docker Scout, escaneo de vulnerabilidades, CVE, SBOM, análisis de imágenes, vulnerabilidades de seguridad o necesite escanear imágenes de Docker en busca de problemas de seguridad. 使用场景：docker scout、漏洞扫描、CVE、SBOM、镜像安全分析、安全漏洞、软件物料清单.
