Linee guida per Docker Scout: scansione delle vulnerabilità delle immagini, generazione di SBOM e valutazione delle policy. Comprende la rapida panoramica dello scout per CVE, lo scout cves per un'analisi dettagliata delle vulnerabilità, lo scout sbom per la distinta base del software, la valutazione delle policy con regole personalizzate, l'integrazione CI/CD (GitHub Actions/Jenkins) e indicazioni sulla correzione. Da utilizzare quando l'utente richiede informazioni su Docker Scout, scansione delle vulnerabilità, CVE, SBOM, analisi delle immagini, vulnerabilità della sicurezza o deve scansionare le immagini Docker per problemi di sicurezza. 使用场景：docker scout、漏洞扫描、CVE、SBOM、镜像安全分析、安全漏洞、软件物料清单.
