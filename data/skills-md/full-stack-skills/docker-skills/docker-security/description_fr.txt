Conseils pour le renforcement de la sécurité de Docker tout au long du cycle de vie : sécurité des images (images de base minimales, utilisateurs non root, versions épinglées), sécurité d'exécution (seccomp/AppArmor/SELinux, fonctionnalités, rootfs en lecture seule, pas de nouveaux privilèges), gestion des secrets (secrets BuildKit, secrets Docker dans Swarm), audit de sécurité Docker Bench, liste de contrôle de conformité CIS et sécurité de la chaîne d'approvisionnement (signature d'image, confiance de contenu, SBOM). À utiliser lorsque l'utilisateur pose des questions sur la sécurité Docker, le renforcement des images, les conteneurs non root, seccomp, AppArmor, Docker Bench, la gestion des secrets ou la sécurisation des conteneurs. Il s'agit d'une application Docker, d'une application Docker, d'une racine racine, de seccomp, d'AppArmor, de sécurité, de Docker Bench, de secret.
