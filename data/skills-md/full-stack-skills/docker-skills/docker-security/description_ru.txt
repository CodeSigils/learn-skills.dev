Руководство по усилению безопасности Docker на протяжении всего жизненного цикла — безопасность образов (минимальные базовые образы, пользователи без полномочий root, закрепленные версии), безопасность во время выполнения (seccomp/AppArmor/SELinux, возможности, rootfs только для чтения, no-new-privileges), управление секретами (секреты BuildKit, секреты Docker в Swarm), аудит безопасности Docker Bench, контрольный список соответствия CIS и безопасность цепочки поставок (подпись изображений, доверие к контенту, SBOM). Используйте, когда пользователь спрашивает о безопасности Docker, усилении защиты образов, контейнерах без полномочий root, seccomp, AppArmor, Docker Bench, управлении секретами или защите контейнеров. Доступные варианты: docker, 镜像安全, 非root, 、seccomp, AppArmor, Security, Docker Bench, secret 管理.
