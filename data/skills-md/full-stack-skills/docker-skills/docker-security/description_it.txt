Linee guida per il rafforzamento della sicurezza Docker durante l'intero ciclo di vita: sicurezza delle immagini (immagini di base minime, utenti non root, versioni aggiunte), sicurezza del runtime (seccomp/AppArmor/SELinux, funzionalità, rootfs di sola lettura, no-new-privileges), gestione dei segreti (segreti BuildKit, segreti Docker in Swarm), controllo della sicurezza di Docker Bench, elenco di controllo della conformità CIS e sicurezza della catena di fornitura (firma delle immagini, attendibilità dei contenuti, SBOM). Da utilizzare quando l'utente richiede informazioni su sicurezza Docker, rafforzamento delle immagini, contenitori non root, seccomp, AppArmor, Docker Bench, gestione dei segreti o protezione dei contenitori. 使用场景：docker 安全、镜像安全、非root运行、seccomp、AppArmor、security、Docker Bench、secret管理.
