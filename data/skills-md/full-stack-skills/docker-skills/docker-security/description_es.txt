Orientación para reforzar la seguridad de Docker durante todo el ciclo de vida: seguridad de imágenes (imágenes base mínimas, usuarios no root, versiones fijadas), seguridad en tiempo de ejecución (seccomp/AppArmor/SELinux, capacidades, rootfs de solo lectura, sin privilegios nuevos), gestión de secretos (secretos de BuildKit, secretos de Docker en Swarm), auditoría de Docker Bench Security, lista de verificación de cumplimiento de CIS y seguridad de la cadena de suministro (firma de imágenes, confianza de contenido, SBOM). Úselo cuando el usuario pregunte sobre la seguridad de Docker, el refuerzo de imágenes, los contenedores no raíz, seccomp, AppArmor, Docker Bench, la administración de secretos o la protección de contenedores. 使用场景：docker 安全、镜像安全、非root运行、seccomp、AppArmor、security、Docker Bench、secret管理.
