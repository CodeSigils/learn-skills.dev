Punto de entrada de Docker: proporciona una guía completa para los conceptos, la arquitectura y las operaciones básicas de Docker. Cubre qué es Docker, comparación entre contenedor y máquina virtual, arquitectura Docker (cliente-servidor, demonio, registro), guía de instalación para Linux/Mac/Windows y tutorial sobre el primer contenedor. Incluye el modelo de objetos de Docker (Imagen/Contenedor/Registro/Motor), conceptos básicos de CLI y descripción general del ecosistema de Docker. Úselo cuando el usuario pregunte sobre los conceptos básicos de Docker, necesite comprender los conceptos de Docker, sea nuevo en Docker o quiera los fundamentos de la contenedorización. Por ejemplo: Docker vs VM, Docker vs Docker, Docker vs VM, Docker vs Docker, Docker vs VM, Docker vs Docker.
