Docker 入口点 — 提供 Docker 概念、架构和基本操作的全面指导。涵盖 Docker 是什么、容器与虚拟机的比较、Docker 架构（客户端-服务器、守护进程、注册表）、Linux/Mac/Windows 安装指南以及第一个容器演练。包括 Docker 对象模型（镜像/容器/注册表/引擎）、CLI 基础知识和 Docker 生态系统概述。当用户询问 Docker 基础知识、需要了解 Docker 概念、不熟悉 Docker 或想要了解容器化基础知识时使用。 使用场景：Docker入门、什么是Docker、容器概念、Docker vs VM、Docker安装、docker基础命令、容器基础知识、Docker架构。
