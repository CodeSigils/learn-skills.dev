Point d'entrée Docker : fournit des conseils complets sur les concepts, l'architecture et les opérations de base de Docker. Couvre ce qu'est Docker, la comparaison conteneur/VM, l'architecture Docker (client-serveur, démon, registre), les conseils d'installation pour Linux/Mac/Windows et la procédure pas à pas du premier conteneur. Comprend le modèle objet Docker (Image/Conteneur/Registre/Engine), les bases de la CLI et la présentation de l'écosystème Docker. À utiliser lorsque l'utilisateur pose des questions sur les bases de Docker, a besoin de comprendre les concepts de Docker, est nouveau sur Docker ou souhaite les principes fondamentaux de la conteneurisation. Nom de l'utilisateur : Docker version, Docker version ultérieure, Docker vs VM, Docker version, docker version base, bases du conteneur, version Docker.
