نقطة دخول Docker - توفر إرشادات شاملة لمفاهيم Docker وبنيتها وعملياتها الأساسية. يغطي تعريف Docker، ومقارنة الحاوية مقابل VM، وبنية Docker (خادم العميل، البرنامج الخفي، التسجيل)، وإرشادات التثبيت لنظام التشغيل Linux/Mac/Windows، وإرشادات الحاوية الأولى. يتضمن نموذج كائن Docker (الصورة/الحاوية/السجل/المحرك)، وأساسيات واجهة سطر الأوامر (CLI)، ونظرة عامة على النظام البيئي لـ Docker. يُستخدم عندما يسأل المستخدم عن أساسيات Docker، أو يحتاج إلى فهم مفاهيم Docker، أو إذا كان جديدًا على Docker، أو يريد أساسيات النقل بالحاويات. دعم: Docker، Docker، Docker، Docker vs VM، Docker، Docker، أساسيات الحاويات، Docker.
