Expertenanleitung für den Befehl „docker build“ – Erstellen von Container-Images, Tagging-Strategien, Build-Argumente, Image-Management und -Inspektion. Behandelt die vollständige Syntax von „Docker Build“, die Verwendung von „--build-arg“, Image-Tagging („Docker Tag“), Image-Inspektion („Docker Inspect“, „Docker History“, „Docker Image ls“), das Pushen in Registrierungen („Docker Push“), das Bereinigen von Images („Docker Image Prune“, „Docker System Prune“) und die Grundlagen von Docker BuildKit. Unterscheidet sich von docker-dockerfile (konzentriert sich auf die Erstellung von Dockerfiles) und docker-buildx (konzentriert sich auf Multiplattform-Builds und erweitertes BuildKit). Verwenden Sie diese Option, wenn der Benutzer nach Docker-Build, Docker-Tag, Docker-Push, Docker-Images, Docker-Image-Verwaltung oder der Erstellung und Verwaltung von Docker-Images fragt. Benutzeroberfläche: Docker-Build-Version, Docker-Tag-Version, Docker-Push-Version, Docker-Image-Version, Docker-Image-Version, Docker-Version --build-arg, Docker-Build-Funktion.
