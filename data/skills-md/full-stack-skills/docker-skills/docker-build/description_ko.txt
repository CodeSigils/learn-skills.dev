'docker build' 명령에 대한 전문가 지침 - 컨테이너 이미지 빌드, 전략 태그 지정, 빌드 인수, 이미지 관리 및 검사. `docker build` 전체 구문, `--build-arg` 사용법, 이미지 태깅(`docker tag`), 이미지 검사(`docker Inspection`, `docker History`, `docker image ls`), 레지스트리로 푸시(`docker push`), 이미지 정리(`docker image prune`, `docker system prune`) 및 Docker BuildKit 기본 사항을 다룹니다. docker-dockerfile(Dockerfile 작성에 중점) 및 docker-buildx(다중 플랫폼 빌드 및 고급 BuildKit에 중점)와는 다릅니다. 사용자가 docker 빌드, docker 태그, docker push, docker 이미지, docker 이미지 관리 또는 Docker 이미지 빌드 및 관리 방법에 대해 질문할 때 사용합니다. 使用场景：docker build 构建镜 Image、docker tag 打标签、docker push 推送镜 Image、docker Images 镜image管理、docker image 命令、构建参数 --build-arg、镜image标签、docker build 정말.
