إرشادات الخبراء لأمر `docker build` - إنشاء صور الحاويات، وإستراتيجيات وضع العلامات، وبناء الوسائط، وإدارة الصور وفحصها. يغطي البنية الكاملة لـ "docker build"، واستخدام `--build-arg`، ووضع علامات على الصور (`علامة عامل الإرساء`)، وفحص الصورة (`فحص عامل الإرساء`، و`سجل عامل الإرساء`، و`صورة عامل الإرساء`)، والدفع إلى السجلات (`دفع عامل الإرساء`)، وتشذيب الصورة (`تقليم صورة عامل الإرساء`، و`تقليم نظام عامل الإرساء`)، وأساسيات Docker BuildKit. يختلف عن docker-dockerfile (يركز على تأليف Dockerfile) وdocker-buildx (يركز على الإصدارات متعددة المنصات وBuildKit المتقدمة). يُستخدم عندما يسأل المستخدم عن إنشاء عامل الإرساء، أو علامة عامل الإرساء، أو دفع عامل الإرساء، أو صور عامل الإرساء، أو إدارة صور عامل الإرساء، أو كيفية إنشاء صور عامل الإرساء وإدارتها. إنشاء عامل ميناء: إنشاء عامل إرساء، إضافة علامة عامل إرساء، دفع عامل الإرساء، تحديد صور عامل الإرساء، تحديد صورة عامل الإرساء، تحديد صورة عامل الإرساء --build-arg، إنشاء قاعدة بيانات، بناء عامل ميناء.
