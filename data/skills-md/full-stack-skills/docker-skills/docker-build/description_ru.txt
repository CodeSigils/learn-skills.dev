Экспертное руководство по команде docker build — создание образов контейнеров, стратегии тегирования, аргументы сборки, управление образами и проверка. Охватывает полный синтаксис `docker build`, использование `--build-arg`, тегирование изображений (`docker tag`), проверку изображений (`docker Inspect`, `Docker History`, `Docker Image ls`), отправку в реестры (`docker push`), обрезку образов (`docker image prune`, `docker system prune`) и основы Docker BuildKit. В отличие от docker-dockerfile (с упором на создание Dockerfile) и docker-buildx (с упором на многоплатформенные сборки и расширенный BuildKit). Используйте, когда пользователь спрашивает о сборке Docker, теге Docker, отправке Docker, образах Docker, управлении образами Docker или о том, как создавать образы Docker и управлять ими. 使用场景: docker build 构建镜像, docker tag 打标签, docker push 推送镜像, docker images 镜像管理, docker image 命令、构建参数--build-arg, сборка docker и сборка.
