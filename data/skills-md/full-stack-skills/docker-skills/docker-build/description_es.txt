Orientación experta para el comando "docker build": creación de imágenes de contenedores, estrategias de etiquetado, creación de argumentos, gestión e inspección de imágenes. Cubre la sintaxis completa de `docker build`, el uso de `--build-arg`, el etiquetado de imágenes (`docker tag`), la inspección de imágenes (`docker inspect`, `docker History`, `docker image ls`), el envío a registros (`docker push`), la poda de imágenes (`docker image prune`, `docker system prune`) y los conceptos básicos de Docker BuildKit. Se diferencia de docker-dockerfile (se centra en la creación de Dockerfile) y docker-buildx (se centra en compilaciones multiplataforma y BuildKit avanzado). Úselo cuando el usuario pregunte sobre la compilación de Docker, la etiqueta de Docker, la inserción de Docker, las imágenes de Docker, la administración de imágenes de Docker o cómo crear y administrar imágenes de Docker. 使用场景：docker build 构建镜像、docker tag 打标签、docker push 推送镜像、docker images 镜像管理、docker image 命令、构建参数--build-arg, configuración de Docker Build.
