Docker 이미지 레지스트리에 대한 지침 — Docker Hub에 이미지 게시, 이미지 가져오기, 태그 관리 전략, 개인 레지스트리 설정(Docker 레지스트리 컨테이너 및 Harbor), 가속을 위한 레지스트리 미러, 이미지 서명 및 콘텐츠 신뢰, 레지스트리 API 사용. 사용자가 docker 허브, 이미지 레지스트리, docker push/pull, 프라이빗 레지스트리, docker 로그인, 태그 관리, Harbor에 대해 질문하거나 레지스트리에서 컨테이너 이미지를 관리해야 할 때 사용합니다. 使用场景：docker 허브、镜image仓库、docker push、docker pull、私有仓库、registry、Harbor、镜image标签管理.
