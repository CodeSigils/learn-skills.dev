Orientación para registros de imágenes de Docker: publicación de imágenes en Docker Hub, extracción de imágenes, estrategias de administración de etiquetas, configuración de registro privado (contenedor de Docker Registry y Harbor), espejos de registro para aceleración, firma de imágenes y confianza en el contenido, y uso de API de registro. Úselo cuando el usuario pregunte sobre Docker Hub, registro de imágenes, Docker push/pull, registro privado, inicio de sesión de Docker, administración de etiquetas, Harbor o necesite administrar imágenes de contenedores en registros. 使用场景：docker hub、镜像仓库、docker push、docker pull、私有仓库、registry、Harbor、镜像标签管理.
