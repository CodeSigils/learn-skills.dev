Conseils pour les registres d'images Docker : publication d'images sur Docker Hub, extraction d'images, stratégies de gestion des balises, configuration de registre privé (conteneur Docker Registry et Harbour), miroirs de registre pour l'accélération, la signature d'images et la confiance du contenu, ainsi que l'utilisation de l'API de registre. À utiliser lorsque l'utilisateur pose des questions sur le hub Docker, le registre d'images, le push/pull Docker, le registre privé, la connexion Docker, la gestion des balises, Harbor ou doit gérer les images de conteneurs dans les registres. Il s'agit d'un docker hub, d'un docker push, d'un docker pull, d'un registre, d'un port.
