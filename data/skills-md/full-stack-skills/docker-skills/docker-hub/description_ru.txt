Руководство для реестров образов Docker — публикация образов в Docker Hub, извлечение образов, стратегии управления тегами, настройка частного реестра (контейнер Docker Registry и Harbour), зеркала реестра для ускорения, подписание образов и доверие к содержимому, а также использование API реестра. Используйте, когда пользователь спрашивает о Docker Hub, реестре образов, push/pull Docker, частном реестре, входе в Docker, управлении тегами, Harbour или необходимости управлять образами контейнеров в реестрах. Примеры: Docker Hub, Docker Push, Docker Pull, Registry, Harbour, Harbor.
