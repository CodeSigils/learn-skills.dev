Docker イメージ レジストリのガイダンス — Docker Hub へのイメージの公開、イメージのプル、タグ管理戦略、プライベート レジストリのセットアップ (Docker Registry コンテナーとハーバー)、高速化のためのレジストリ ミラー、イメージ署名とコンテンツの信頼、レジストリ API の使用法。ユーザーが Docker ハブ、イメージ レジストリ、Docker プッシュ/プル、プライベート レジストリ、Docker ログイン、タグ管理、ハーバーについて質問する場合、またはレジストリ内のコンテナ イメージを管理する必要がある場合に使用します。 使用環境：docker Hub、镜像仓库、docker Push、docker pull、私有仓库、レジストリ、ハーバー、镜像标签管理。
