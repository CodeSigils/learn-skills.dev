إرشادات لسجلات صور Docker - نشر الصور إلى Docker Hub، وسحب الصور، واستراتيجيات إدارة العلامات، وإعداد السجل الخاص (حاوية Docker Registry والميناء)، ومرايا التسجيل للتسريع، وتوقيع الصور والثقة في المحتوى، واستخدام واجهة برمجة تطبيقات التسجيل. يُستخدم عندما يسأل المستخدم عن مركز عامل الإرساء، أو تسجيل الصور، أو دفع/سحب عامل الإرساء، أو التسجيل الخاص، أو تسجيل دخول عامل الإرساء، أو إدارة العلامات، أو الميناء، أو يحتاج إلى إدارة صور الحاوية في السجلات. يتضمن: مركز عامل الإرساء، مركز الإرساء، دفع عامل الإرساء، سحب عامل الإرساء، السجل، المرفأ، مركز الإرساء.
