프로덕션 환경에 Docker를 배포하기 위한 지침입니다. Docker Swarm(초기화, 조인, 스택 배포, 서비스 확장, 롤링 업데이트), Kubernetes 마이그레이션(kompose 변환, Helm 차트, 차이점), 리소스 할당량 및 제한, 가동 중지 시간 없는 배포 패턴, cAdvisor + Prometheus + Grafana를 사용한 모니터링, systemd가 포함된 Docker 및 프로덕션 강화를 다룹니다. 사용자가 프로덕션 Docker, 스웜, 스택 배포, K8s 마이그레이션, 가동 중지 시간 없음, 컨테이너 모니터링에 대해 질문하거나 프로덕션에 Docker를 배포해야 할 때 사용합니다. 使用场景:生产part署, docker swarm, docker stack, K8s迁移, 零停机part署, 容器监控, 生产环境.
