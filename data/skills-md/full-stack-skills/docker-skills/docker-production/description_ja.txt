実稼働環境に Docker をデプロイするためのガイダンス。 Docker Swarm (init、join、スタック デプロイ、サービス スケーリング、ローリング アップデート)、Kubernetes 移行 (kompose 変換、Helm チャート、相違点)、リソース クォータと制限、ゼロ ダウンタイム デプロイ パターン、cAdvisor + Prometheus + Grafana によるモニタリング、systemd による Docker、本番環境の強化をカバーします。ユーザーが本番環境の Docker、swarm、スタック デプロイ、K8s 移行、ゼロ ダウンタイム、コンテナのモニタリングについて尋ねた場合、または本番環境で Docker をデプロイする必要がある場合に使用します。 使用场景：生产配置、docker swarm、docker stack、K8s迁移、零停机配置、容器监控、生产環境。
