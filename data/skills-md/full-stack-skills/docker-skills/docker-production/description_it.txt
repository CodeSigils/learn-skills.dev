Linee guida per la distribuzione di Docker negli ambienti di produzione. Copre Docker Swarm (init, join, distribuzione dello stack, scalabilità del servizio, aggiornamenti in sequenza), migrazione Kubernetes (conversione kompose, grafici Helm, differenze), quote e limiti delle risorse, modelli di distribuzione senza tempi di inattività, monitoraggio con cAdvisor + Prometheus + Grafana, Docker con systemd e rafforzamento della produzione. Da utilizzare quando l'utente richiede informazioni su Docker di produzione, swarm, distribuzione dello stack, migrazione di K8, tempi di inattività pari a zero, monitoraggio dei contenitori o necessità di distribuire Docker in produzione. 使用场景：docker swarm, docker stack, K8s迁移、零停机部署、容器监控、生产环境.
