Guía para implementar Docker en entornos de producción. Cubre Docker Swarm (init, join, implementación de pila, escalado de servicios, actualizaciones continuas), migración de Kubernetes (conversión de kompose, gráficos de Helm, diferencias), cuotas y límites de recursos, patrones de implementación sin tiempo de inactividad, monitoreo con cAdvisor + Prometheus + Grafana, Docker con systemd y refuerzo de producción. Úselo cuando el usuario pregunte sobre Docker de producción, swarm, implementación de pila, migración de K8, tiempo de inactividad cero, monitoreo de contenedores o necesidades de implementar Docker en producción. 使用场景：生产部署、docker swarm、docker stack、K8s迁移、零停机部署、容器监控、生产环境.
