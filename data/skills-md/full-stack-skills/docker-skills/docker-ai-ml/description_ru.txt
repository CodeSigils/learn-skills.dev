Руководство по запуску рабочих нагрузок AI/ML в Docker. Охватывает Docker Model Runner (извлечение/запуск модели Docker для локальных LLM), Docker Agent (мультиагентная оркестровка для задач кодирования), Docker Sandboxs для изолированного выполнения агента AI, ускорение графического процессора (nvidia-container-toolkit, флаг --gpus), обслуживание модели AI с помощью Docker и локальный запуск LLM с открытым исходным кодом (Llama, Gemma, Qwen). Используйте, когда пользователь спрашивает о Docker AI, средстве запуска моделей Docker, локальном LLM, агенте Docker, докере GPU, песочнице, обслуживании моделей или о необходимости развертывания моделей AI с помощью Docker. Доступные варианты: Docker AI, Model Runner, LLM, Docker Agent, GPU Docker, Sandbox, AI.
