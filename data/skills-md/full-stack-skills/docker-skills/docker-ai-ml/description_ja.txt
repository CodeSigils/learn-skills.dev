Docker で AI/ML ワークロードを実行するためのガイダンス。 Docker Model Runner (ローカル LLM の Docker モデルのプル/実行)、Docker Agent (コーディング タスク用のマルチエージェント オーケストレーション)、分離された AI エージェント実行のための Docker サンドボックス、GPU アクセラレーション (nvidia-container-toolkit、--gpus フラグ)、Docker での AI モデルの提供、およびオープンソース LLM (Llama、Gemma、Qwen) のローカルでの実行をカバーします。ユーザーが docker ai、docker モデル ランナー、ローカル LLM、docker エージェント、GPU docker、サンドボックス、モデル サービングについて質問する場合、または Docker を使用して AI モデルをデプロイする必要がある場合に使用します。 使用场景：docker ai、モデルランナー、本地LLM、docker Agent、GPU docker、sandbox、AIモデル配置。
