Guía para ejecutar cargas de trabajo de IA/ML en Docker. Cubre Docker Model Runner (extracción/ejecución de modelo Docker para LLM locales), Docker Agent (orquestación de múltiples agentes para tareas de codificación), Docker Sandboxes para la ejecución aislada de agentes de IA, aceleración de GPU (nvidia-container-toolkit, --gpus flag), servicio de modelo de IA con Docker y ejecución de LLM de código abierto (Llama, Gemma, Qwen) localmente. Úselo cuando el usuario pregunte sobre Docker AI, Docker Model Runner, LLM local, Docker Agent, GPU Docker, Sandbox, Model Server o necesite implementar modelos de IA con Docker. 使用场景: docker ai, model runner, 本地LLM, docker agent, GPU docker, sandbox, AI模型部署.
