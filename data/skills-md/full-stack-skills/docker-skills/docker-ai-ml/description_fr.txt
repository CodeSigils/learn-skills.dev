Conseils pour exécuter des charges de travail AI/ML sur Docker. Couvre Docker Model Runner (modèle Docker pull/run pour les LLM locaux), Docker Agent (orchestration multi-agents pour les tâches de codage), Docker Sandbox pour l'exécution d'agents IA isolés, l'accélération GPU (nvidia-container-toolkit, --gpus flag), le modèle IA servant avec Docker et l'exécution de LLM open source (Llama, Gemma, Qwen) localement. À utiliser lorsque l'utilisateur pose des questions sur Docker ai, Docker Model Runner, LLM local, Docker Agent, GPU Docker, Sandbox, Model Servir ou doit déployer des modèles d'IA avec Docker. Il s'agit d'un docker ai, d'un model runner, d'un LLM, d'un agent docker, d'un docker GPU, d'un bac à sable, d'un AI.
