在 Docker 上运行 AI/ML 工作负载的指南。涵盖 Docker Model Runner（用于本地 LLM 的 Docker 模型拉取/运行）、Docker Agent（用于编码任务的多代理编排）、用于隔离 AI 代理执行的 Docker 沙箱、GPU 加速（nvidia-container-toolkit、--gpus 标志）、使用 Docker 提供 AI 模型以及在本地运行开源 LLM（Llama、Gemma、Qwen）。当用户询问 docker ai、docker model runner、本地 LLM、docker agent、GPU docker、沙箱、模型服务或需要使用 Docker 部署 AI 模型时使用。 使用场景：docker ai、model runner、本地LLM、docker agent、GPU docker、sandbox、AI模型部署。
