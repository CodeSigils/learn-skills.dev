Anleitung zum Ausführen von AI/ML-Workloads auf Docker. Deckt Docker Model Runner (Docker-Modell-Pull/Run für lokale LLMs), Docker Agent (Multi-Agent-Orchestrierung für Codierungsaufgaben), Docker-Sandboxen für isolierte KI-Agentenausführung, GPU-Beschleunigung (nvidia-container-toolkit, --gpus-Flag), KI-Modellbereitstellung mit Docker und die lokale Ausführung von Open-Source-LLMs (Llama, Gemma, Qwen) ab. Verwenden Sie diese Option, wenn der Benutzer nach Docker AI, Docker Model Runner, lokalem LLM, Docker Agent, GPU Docker, Sandbox, Model Serving fragt oder KI-Modelle mit Docker bereitstellen muss. Beispiele: Docker AI, Model Runner, LLM, Docker Agent, GPU Docker, Sandbox, AI.
