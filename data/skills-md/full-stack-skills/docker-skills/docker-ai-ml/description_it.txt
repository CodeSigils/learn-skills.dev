Linee guida per l'esecuzione di carichi di lavoro AI/ML su Docker. Copre Docker Model Runner (pull/run del modello docker per LLM locali), Docker Agent (orchestrazione multi-agente per attività di codifica), Docker Sandbox per l'esecuzione isolata di agenti IA, accelerazione GPU (nvidia-container-toolkit, --gpus flag), modello AI servito con Docker ed esecuzione di LLM open source (Llama, Gemma, Qwen) localmente. Da utilizzare quando l'utente chiede informazioni su docker ai, docker model runner, LLM locale, docker agent, GPU docker, sandbox, modelserving o deve distribuire modelli AI con Docker. 使用场景:docker ai, model runner, 本地LLM, docker agent, GPU docker, sandbox, AI模型部署.
