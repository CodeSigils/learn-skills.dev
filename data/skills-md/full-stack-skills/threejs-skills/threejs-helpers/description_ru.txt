Помощники по отладке и визуализации в основных помощниках Three.js (AxesHelper, GridHelper, CameraHelper, помощниках по освещению, SkeletonHelper, помощниках по ограничительной рамке, PlaneHelper, PolarGridHelper, ArrowHelper) и дополнительных помощниках (VertexNormalsHelper, VertexTangentsHelper, RectAreaLightHelper, LightProbeHelper, ViewHelper, OctreeHelper, TextureHelper, PositionalAudioHelper, AnimationPathHelper, RapierHelper). Используйте только для наложений разработки и редактирования, а не для отправки иллюстраций; для манипуляций в стиле гизмо используйте элементы управления Threejs.
