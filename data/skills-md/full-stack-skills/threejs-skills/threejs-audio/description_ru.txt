пространственное определение звука в Three.js: AudioListener, подключенный к камере, источники Audio и PositionalAudio, AudioAnalyser для данных FFT/временной области и интеграция с контекстами API веб-аудио; AudioLoader используется в Threejs-загрузчиках для декодирования файлов.
