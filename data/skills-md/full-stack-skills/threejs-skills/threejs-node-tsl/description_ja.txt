three.js ノードベースのシェーディング: ノード API サーフェス、Nodematerial および MeshStandardNodematerial スタイル ファミリ、TSL.html の TSL (Three.js Shading Language) エントリ、WebGPURenderer ペアリング、およびコア PostProcessing (クラス) とアドオン EffectComposer の高レベルの比較。 TSL ビルトイン、コンピューティング指向ノード、または最新の WebGPU パイプラインを使用して、シェーダーをグラフとして作成する場合に使用します。クラシックな MeshStandardmaterial、MeshPhysicalmaterial、および文字列ベースの Shadermaterial の場合、GLSL は 3 つの js マテリアルを使用します。ストックの EffectComposer + Pass パスの場合は、threejs-postprocessing を使用します。ノードを使用しない WebGLRenderer のみのチューニングには、threejs-renderers を使用します。
