Затенение на основе узлов Three.js: поверхность Nodes API, семейства стилей NodeMaterial и MeshStandardNodeMaterial, запись TSL (Three.js Shading Language) в TSL.html, соединение WebGPURenderer и базовая PostProcessing (класс) по сравнению с надстройкой EffectComposer на высоком уровне. Используйте при разработке шейдеров в виде графов, используя встроенные функции TSL, вычислительные узлы или современные конвейеры WebGPU; для классического MeshStandardMaterial, MeshPhysicalMaterial и строкового ShaderMaterial GLSL используйте Threejs-materials; для стандартных проходов EffectComposer + Pass используйте постобработку Threejs; для настройки только WebGLRenderer без узлов используйте Threejs-рендереры.
