Three.js 基于节点的着色：Nodes API 表面、NodeMaterial 和 MeshStandardNodeMaterial 样式系列、TSL.html 中的 TSL（Three.js 着色语言）条目、WebGPURenderer 配对以及高级的核心 PostProcessing（类）与插件 EffectComposer。在使用 TSL 内置函数、面向计算的节点或现代 WebGPU 管道将着色器创作为图形时使用；对于经典的 MeshStandardMaterial、MeshPhysicalMaterial 和基于字符串的 ShaderMaterial GLSL 使用 Threejs-material；对于库存 EffectComposer + Pass 通道，请使用 Threejs-postprocessing；对于没有节点的仅 WebGLRenderer 调整，请使用 Threejs 渲染器。
