Bibliothèque mathématique three.js : Vector2/3/4, Matrix3/4, Quaternion, Euler, Color, Box2/Box3, Sphere, Plane, Ray, Line3, Triangle, Frustum, Coordons cylindriques/sphériques, MathUtils et classes de base Interpolant ; utilitaires mathématiques complémentaires tels que OBB, Octree, Capsule, ConvexHull, MeshSurfaceSampler. À utiliser pour les transformations, les tests d'intersection et les requêtes spatiales ; pour l'interpolation d'images clés liée à AnimationMixer, utilisez threejs-animation ; pour la sélection de l'implémentation, utilisez des objets threejs avec Raycaster.
