Objets graphiques de scène three.js : transformations et hiérarchie Object3D, groupe, maillage, InstancedMesh, SkinnedMesh, BatchedMesh, LOD, Line/LineLoop/LineSegments, Points, Sprite, Bone, Skeleton, ClippingGroup ; interaction via Raycaster, les masques de calques et les modèles EventDispatcher. Fusionne l'ancienne portée d'interaction : utilisation pour la sélection et les calques ; pour les mathématiques vectorielles pures sans graphique de scène, utilisez threejs-math ; pour lire des clips squelettiques, utilisez threejs-animation ; pour les composants internes de l'élimination du tronc, voir la documentation de l'appareil photo.
