объекты графа сцены Three.js: преобразования и иерархия Object3D, группа, сетка, InstancedMesh, SkinnedMesh, BatchedMesh, LOD, Line/LineLoop/LineSegments, Points, Sprite, Bone, Skeleton, ClippingGroup; взаимодействие через Raycaster, маски слоев и шаблоны EventDispatcher. Объединяет прежнюю область взаимодействия — используется для выбора и слоев; для чистой векторной математики без графа сцены используйте Threejs-math; для проигрывания скелетных клипов используйте Threejs-анимацию; информацию о внутренних компонентах отсеивания усеченного конуса см. в документации к камере.
