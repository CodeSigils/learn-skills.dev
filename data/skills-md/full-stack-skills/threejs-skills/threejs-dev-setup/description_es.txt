Guía de bootstrap y cadena de herramientas para aplicaciones three.js que utilizan npm, Vite/Webpack/Rollup, mapas de importación de ESM básicos y TypeScript. Cubre rutas de importación canónicas para `tres` núcleos versus `tres/addons/` (ejemplos/reexportaciones de jsm), alineación de versiones con https://tresjs.org/docs/ y corrección de "módulo no encontrado" para cargadores y controles. Úselo al crear un nuevo proyecto 3D, migrar un paquete o depurar la resolución de complementos; no lo use para representar detalles de API (consulte threejs-renderers) o lógica de carga de activos (consulte threejs-loaders).
