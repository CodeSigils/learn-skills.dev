إرشادات Bootstrap وtoolchain لتطبيقات three.js باستخدام npm وVite/Webpack/Rollup وخرائط استيراد ESM العارية وTypeScript. يغطي مسارات الاستيراد الأساسية لـ "ثلاثة" أساسية مقابل "ثلاثة/إضافات/" (أمثلة/إعادة تصدير jsm)، ومحاذاة الإصدار مع https://threejs.org/docs/، وإصلاح "لم يتم العثور على الوحدة" لأدوات التحميل وعناصر التحكم. يُستخدم عند دعم مشروع ثلاثي الأبعاد جديد، أو ترحيل المجمع، أو تصحيح أخطاء الوظائف الإضافية - لا يُستخدم لعرض تفاصيل واجهة برمجة التطبيقات (راجع عارضات threejs) أو منطق تحميل الأصول (راجع أدوات تحميل threejs).
