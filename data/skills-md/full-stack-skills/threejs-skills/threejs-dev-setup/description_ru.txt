Руководство по начальной загрузке и набору инструментов для приложений Three.js с использованием npm, Vite/Webpack/Rollup, карт импорта ESM и TypeScript. Охватывает канонические пути импорта для ядра `three` по сравнению с`three/addons/` (примеры/реэкспорт jsm), выравнивание версий с https://threejs.org/docs/ и исправление «модуль не найден» для загрузчиков и элементов управления. Используйте при создании нового 3D-проекта, миграции сборщика или отладке разрешения надстроек — не используйте для рендеринга деталей API (см. Threejs-рендереры) или логики загрузки ресурсов (см. Threejs-загрузчики).
