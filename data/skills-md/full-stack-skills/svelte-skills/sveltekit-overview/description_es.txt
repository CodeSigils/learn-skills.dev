Descripción general de SvelteKit, creación de proyectos, tipos de proyectos, estructura del proyecto, estándares web, capacidades de enrutamiento. Se utiliza cuando un usuario crea una nueva aplicación SvelteKit, selecciona un modo de representación (SSR/SSG/SPA/MPA), comprende las convenciones de archivos +page.svelte, +page.server.js, +layout, +server.js, +error y necesita usar API web como Fetch, FormData, Stream, URL, etc.
