Présentation de SvelteKit, création de projets, types de projets, structure de projet, normes Web et compétences de routage. Utilisé lorsqu'un utilisateur crée une nouvelle application SvelteKit, sélectionne un mode de rendu (SSR/SSG/SPA/MPA), comprend les conventions de fichiers +page.svelte, +page.server.js, +layout, +server.js et +error, et doit utiliser des API Web telles que Fetch, FormData, Stream, URL, etc.
