Panoramica di SvelteKit, creazione di progetti, tipi di progetto, struttura del progetto, standard web e competenze di routing. Utilizzato quando un utente crea una nuova applicazione SvelteKit, seleziona una modalità di rendering (SSR/SSG/SPA/MPA), comprende le convenzioni dei file +page.svelte, +page.server.js, +layout, +server.js, +error e deve utilizzare API Web come Fetch, FormData, Streams, URL, ecc.
