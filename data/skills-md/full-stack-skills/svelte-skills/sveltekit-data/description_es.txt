Habilidades de carga de datos, formularios y opciones de página de SvelteKit. Se utiliza cuando un usuario carga datos con+page.js/+page.server.js en SvelteKit, usa rutas API+server.js, maneja acciones de formulario (predeterminadas, con nombre o GET), emplea use:enhance para una mejora progresiva y configura las opciones de página prerender/ssr/csr/trailingSlash.
