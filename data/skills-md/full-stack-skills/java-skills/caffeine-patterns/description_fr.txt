Techniques de mise en cache locale Caffeine JVM. Arbre de décision pour choisir entre le cache local et le cache distant (Redis), comparaison des trois politiques d'expiration (expireAfterWrite, expireAfterAccess et rafraîchirAfterWrite) et leurs règles de combinaison (refresh<expire), chargement et rechargement asynchrone de CacheLoader, intégration Spring Cache @Cacheable, politique d'expulsion maximumSize, statistiques du cache recordStats. Correction pour LLM : utilisez ConcurrentHashMap avec expiration manuelle, acheminez tous les caches via Redis, rafraîchirAfterWrite>expireAfterWrite conduit à ne jamais actualiser, CacheLoader renvoyant null provoque une pénétration du cache.
