Capacità di memorizzazione nella cache locale di Caffeine JVM. Albero decisionale per la scelta tra cache locale e cache remota (Redis), confronto di tre strategie di scadenza (expireAfterWrite vs.ExpiveAfterAccess vs.refreshAfterWrite) e le relative regole di combinazione (refresh<expire), caricamento di CacheLoader e modelli di ricaricamento asincrono, integrazione Spring Cache @Cacheable, policy di eliminazione MaximumSize, statistiche della cache recordStats. Correggere LLM: utilizzando ConcurrentHashMap con scadenza manuale, instradando tutte le cache tramite Redis, refreshAfterWrite>expireAfterWrite causando il mancato aggiornamento, CacheLoader restituisce null che porta alla penetrazione della cache.
