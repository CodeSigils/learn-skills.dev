Competenze nella libreria di utilità Java cinese Hutool. Copre una matrice di selezione funzionale rispetto a Guava/Apache Commons, un riferimento rapido per i metodi più comunemente utilizzati per stringhe, raccolte, date, file e HTTP, selezione tra HttpUtil e OkHttp e divisione delle responsabilità tra BeanUtil e MapStruct.  
Dovrebbe essere utilizzato quando gli utenti necessitano di metodi di utilità del contesto cinese (pinyin, carta d'identità, convalida del numero di telefono), richieste HTTP, operazioni sui file, crittografia/decrittografia nei progetti Java. Evita che il LLM reinventi la ruota invece di utilizzare Hutool.
