Hutool is a Chinese Java utility library. It includes a feature selection matrix covering Guava/Apache Commons, a quick reference for the most commonly used methods for strings, collections, dates, files, and HTTP, a comparison between HttpUtil and OkHttp for choosing implementations, and a delineation of responsibilities between BeanUtil and MapStruct. Use it when a Java project needs Chinese‑specific utility methods (pinyin, ID card, mobile number validation), HTTP requests, file operations, or encryption/decryption. This prevents LLMs from reinventing the wheel instead of using Hutool.
