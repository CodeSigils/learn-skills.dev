Hutool es una biblioteca de utilidades Java china. Incluye una matriz de selección de funciones que cubre Guava/Apache Commons, una referencia rápida de los métodos más utilizados para cadenas, colecciones, fechas, archivos y HTTP, una comparación entre HttpUtil y OkHttp para elegir implementaciones y una delimitación de responsabilidades entre BeanUtil y MapStruct. Úselo cuando un proyecto Java necesite métodos de utilidad específicos de China (pinyin, tarjeta de identificación, validación de número de teléfono móvil), solicitudes HTTP, operaciones de archivos o cifrado/descifrado. Esto evita que los LLM reinventen la rueda en lugar de utilizar Hutool.
