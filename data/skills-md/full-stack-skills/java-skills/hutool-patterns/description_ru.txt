Hutool — китайская библиотека утилит Java. Он включает в себя матрицу выбора функций, охватывающую Guava/Apache Commons, краткий справочник наиболее часто используемых методов для строк, коллекций, дат, файлов и HTTP, сравнение HttpUtil и OkHttp для выбора реализаций и разграничение обязанностей между BeanUtil и MapStruct. Используйте его, когда проекту Java требуются служебные методы, специфичные для китайского языка (пиньинь, удостоверение личности, проверка номера мобильного телефона), HTTP-запросы, файловые операции или шифрование/дешифрование. Это не позволяет специалистам LLM изобретать велосипед вместо использования Hutool.
