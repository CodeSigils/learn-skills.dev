Compétences en matière de file d'attente de messages Apache Kafka. Décisions de sélection du producteur de couverture acks=all/1/0, configuration de l'idempotence (enable.idempotence + acks=all), validation de décalage manuelle du consommateur (enable.auto.commit=false), gestion des lettres mortes DLT (@RetryableTopic/@DltHandler), @KafkaListener + gestionnaire d'exceptions (DefaultErrorHandler), messages ordonnés (même clé sur la même partition), messages transactionnels.  
Corrigez le LLM : acks=0 provoque une perte de message, auto.commit entraîne des messages manqués, la consommation en double n'est pas gérée, DLT n'est pas configuré.
