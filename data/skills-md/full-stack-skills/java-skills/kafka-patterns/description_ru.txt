Навыки работы с очередью сообщений Apache Kafka. Охватывает решения о выборе производителя acks=all/1/0, конфигурацию идемпотентности (enable.idempotence+acks=all), ручную фиксацию смещения потребителя (enable.auto.commit=false), обработку недоставленных сообщений DLT (@RetryableTopic/@DltHandler), @KafkaListener+обработчик исключений (DefaultErrorHandler), упорядоченные сообщения (один и тот же ключ для того же раздела), транзакционные сообщения.  
Исправление для LLM: acks=0 может терять сообщения, auto.commit может пропускать сообщения, не обрабатывает дублированное потребление и не настраивает DLT.
