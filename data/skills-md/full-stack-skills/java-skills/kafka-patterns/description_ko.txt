Apache Kafka 메시지 대기열 기술. 표지 생성자 acks=all/1/0 선택 결정, 멱등성(enable.idempotence + acks=all) 구성, 소비자 수동 오프셋 커밋(enable.auto.commit=false), DLT 데드 레터 처리(@RetryableTopic/@DltHandler), @KafkaListener + 예외 처리기(DefaultErrorHandler), 순서가 지정된 메시지(동일한 파티션에 동일한 키), 트랜잭션 메시지. LLM을 수정합니다. acks=0에서 메시지가 손실되고, auto.commit에서 메시지가 누락되고, 중복 사용을 처리하지 않고, DLT를 구성하지 않습니다.
