Habilidades de cola de mensajes de Apache Kafka. Cubre las decisiones de selección del productor acks=all/1/0, configuración de idempotencia (enable.idempotence+acks=all), confirmación de compensación manual del consumidor (enable.auto.commit=false), manejo de mensajes no entregados DLT (@RetryableTopic/@DltHandler), @KafkaListener+controlador de excepciones (DefaultErrorHandler), mensajes ordenados (misma clave para la misma partición), mensajes transaccionales.  
Corrección para LLM: acks=0 puede perder mensajes, auto.commit puede perder mensajes, no maneja el consumo duplicado y no configura DLT.
