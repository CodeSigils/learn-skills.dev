MyBatis ORM-Kernkompetenzen. Behandelt XML vs. Annotation-SQL-Auswahl, ResultMap-Wiederverwendung (erweitert), Assoziationsabfragen (Assoziations-/Sammlungs-Join vs. verschachtelte Auswahl/N+1-Entscheidung), Paginierungs-Plugin-Konfiguration, #- und $-SQL-Injection-Schutz, Best Practices für dynamisches SQL (if/where/set/foreach/choose) und die Verwendung von ColumnPrefix zum Lösen mehrerer Joins in derselben Tabelle.  
Wird verwendet, wenn Benutzer MyBatis Mapper XML schreiben, Zuordnungsabfragen verarbeiten, Paginierung konfigurieren und SQL-Injection verhindern.
