Основные навыки ORM MyBatis. Охватывает выбор XML в сравнении с аннотациями SQL, повторное использование ResultMap (расширяет), ассоциативные запросы (объединение ассоциации/коллекции или вложенное решение выбора/N+1), конфигурацию подключаемого модуля разбиения на страницы, защиту от внедрения # и $ SQL, лучшие практики динамического SQL (if/where/set/foreach/choose) и использование columnsPrefix для решения нескольких объединений в одной таблице. Используется, когда пользователи пишут XML MyBatis Mapper, обрабатывают ассоциативные запросы, настраивают нумерацию страниц и предотвращают внедрение SQL.
