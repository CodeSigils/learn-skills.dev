مهارات MyBatis الأساسية في ORM. يغطي تحديد XML مقابل التعليقات التوضيحية SQL، وإعادة استخدام ResultMap (يمتد)، واستعلامات الاقتران (ارتباط/مجموعة مقابل قرار اختيار/N+1 متداخل)، وتكوين البرنامج المساعد لترقيم الصفحات، وحماية حقن SQL # و$، وأفضل ممارسات SQL الديناميكية (if/where/set/foreach/choose)، واستخدام columnPrefix لحل الصلات المتعددة في نفس الجدول. يُستخدم عندما يكتب المستخدمون MyBatis Mapper XML، ويتعاملون مع استعلامات الاقتران، ويكوّنون ترقيم الصفحات، ويمنعون حقن SQL.
