Compétences ORM de base de MyBatis. Couvre la sélection XML vs annotation SQL, la réutilisation de ResultMap (extensions), les requêtes d'association (association/jointure de collection vs décision imbriquée/N+1), la configuration du plugin de pagination, la protection contre les injections SQL # et $, les meilleures pratiques SQL dynamiques (if/where/set/foreach/choose) et columnPrefix pour gérer plusieurs jointures sur la même table. Utilisé lorsque les utilisateurs écrivent du XML MyBatis Mapper, gèrent les requêtes d'association, configurent la pagination et se protègent contre l'injection SQL.
