MyBatis のコア ORM スキル。 XML と注釈 SQL の選択、ResultMap の再利用 (拡張)、リレーションシップ クエリの関連付け/コレクション結合とネストされた選択/N+1 の決定、ページネーション プラグインの構成、# および $ SQL インジェクション保護、動的 SQL (if/where/set/foreach/choose) のベスト プラクティス、同じテーブル上の複数の結合を解決するための columnPrefix について説明します。ユーザーが MyBatis Mapper XML を作成し、関係クエリを処理し、ページネーションを構成し、SQL インジェクションを防止するときに使用されます。
