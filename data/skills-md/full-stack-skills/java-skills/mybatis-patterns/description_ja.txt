MyBatis のコア ORM スキル。 XML と注釈 SQL 選択、ResultMap の再利用 (拡張)、関連付けクエリ (関連付け/コレクション結合とネストされた選択/N+1 決定)、ページネーション プラグイン構成、# および $ SQL インジェクション保護、動的 SQL (if/where/set/foreach/choose) のベスト プラクティス、および同じテーブル上の複数の結合を解決するための columnPrefix の使用について説明します。ユーザーが MyBatis Mapper XML を作成し、関連付けクエリを処理し、ページネーションを構成し、SQL インジェクションを防止するときに使用されます。
