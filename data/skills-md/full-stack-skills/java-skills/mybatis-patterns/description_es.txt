Habilidades ORM básicas de MyBatis. Cubre la selección de XML frente a anotaciones SQL, la reutilización de ResultMap (extiende), consultas de asociación (unión de asociación/colección frente a selección anidada/decisión N+1), configuración del complemento de paginación, protección de inyección SQL # y $, mejores prácticas para SQL dinámico (if/where/set/foreach/choose), columnPrefix para resolver múltiples uniones en la misma tabla. Se utiliza cuando los usuarios escriben MyBatis Mapper XML, manejan consultas de asociación, configuran la paginación y evitan la inyección de SQL.
