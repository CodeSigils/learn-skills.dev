Apache Commons最佳实践模式。从官方文档提炼，覆盖Commons Lang3(StringUtils千面判空/isEmpty vs isBlank/Validate抛NullPointerException迁移)、Commons IO(IOUtils.toString大文件陷阱/FileUtils.lineIterator逐行读模式/FilenameUtils.normalize路径规范化)、Commons Collections4(CollectionUtils.union/intersection/subtract集合装甲)。
修正 LLM 错误用：不一致 StringUtils.isBlank vs isEmpty、IOUtils.toString 读大文件 OOM、不 LineIterator 逐行读模式、用 lang 或 lang3 包名。
