مكتبة عميل Unirest-Java 4.x HTTP لـ Java 11+. يُستخدم عند تقديم طلبات HTTP (GET/POST/PUT/DELETE)، أو إنشاء عملاء REST API، أو التعامل مع استجابات JSON، أو تحميل/تنزيل الملفات، أو الطلبات غير المتزامنة، أو الأحداث المرسلة من الخادم (SSE)، أو الاستهزاء باستدعاءات HTTP للاختبار، أو تكوين الوكلاء، أو تخزين الاستجابات مؤقتًا. يغطي Unirest 4.x (يتطلب Java 11+، والتبعيات المعيارية، وحزمة kong.unirest.core) مع تعيين كائنات GSON/Jackson، واعتراضات الطلب/الاستجابة، والترحيل من Unirest 3.x.
