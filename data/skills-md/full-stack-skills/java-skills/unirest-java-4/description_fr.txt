Bibliothèque client HTTP Unirest-Java 4.x pour Java 11+. À utiliser lors de l'exécution de requêtes HTTP (GET/POST/PUT/DELETE), de la création de clients API REST, de la gestion des réponses JSON, des téléchargements/téléchargements de fichiers, des requêtes asynchrones, des événements envoyés par le serveur (SSE), de la simulation d'appels HTTP à des fins de test, de la configuration de proxys ou de la mise en cache des réponses. Couvre Unirest 4.x (nécessite Java 11+, dépendances modulaires, package kong.unirest.core) avec mappage d'objets GSON/Jackson, intercepteurs de requête/réponse et migration depuis Unirest 3.x.
