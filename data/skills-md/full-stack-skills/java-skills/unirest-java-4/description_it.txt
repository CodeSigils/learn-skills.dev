Libreria client HTTP Unirest-Java 4.x per Java 11+. Da utilizzare quando si effettuano richieste HTTP (GET/POST/PUT/DELETE), si creano client API REST, si gestiscono risposte JSON, caricamenti/download di file, richieste asincrone, eventi inviati dal server (SSE), chiamate HTTP fittizie per test, configurazione proxy o memorizzazione nella cache delle risposte. Copre Unirest 4.x (richiede Java 11+, dipendenze modulari, pacchetto kong.unirest.core) con mappatura di oggetti GSON/Jackson, intercettori di richiesta/risposta e migrazione da Unirest 3.x.
