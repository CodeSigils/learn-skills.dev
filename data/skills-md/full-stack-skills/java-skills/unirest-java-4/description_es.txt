Biblioteca cliente HTTP Unirest-Java 4.x para Java 11+. Úselo al realizar solicitudes HTTP (GET/POST/PUT/DELETE), crear clientes API REST, manejar respuestas JSON, cargas/descargas de archivos, solicitudes asíncronas, eventos enviados por el servidor (SSE), burlarse de llamadas HTTP para pruebas, configurar servidores proxy o almacenar en caché respuestas. Cubre Unirest 4.x (requiere Java 11+, dependencias modulares, paquete kong.unirest.core) con mapeo de objetos GSON/Jackson, interceptores de solicitud/respuesta y migración desde Unirest 3.x.
