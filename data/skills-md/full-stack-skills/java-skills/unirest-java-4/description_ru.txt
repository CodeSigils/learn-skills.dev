HTTP-клиентская библиотека Unirest-Java 4.x для Java 11+. Используйте при выполнении HTTP-запросов (GET/POST/PUT/DELETE), создании клиентов REST API, обработке ответов JSON, загрузке/загрузке файлов, асинхронных запросах, событиях, отправленных сервером (SSE), имитации HTTP-вызовов для тестирования, настройке прокси-серверов или кэшировании ответов. Охватывает Unirest 4.x (требуется Java 11+, модульные зависимости, пакет kong.unirest.core) с отображением объектов GSON/Jackson, перехватчиками запросов/ответов и миграцией из Unirest 3.x.
