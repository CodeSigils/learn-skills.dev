Unirest-Java 4.x HTTP-Client-Bibliothek für Java 11+. Wird verwendet, wenn Sie HTTP-Anfragen stellen (GET/POST/PUT/DELETE), REST-API-Clients erstellen, JSON-Antworten, Datei-Uploads/-Downloads, asynchrone Anfragen, vom Server gesendete Ereignisse (SSE) verarbeiten, HTTP-Aufrufe zum Testen verspotten, Proxys konfigurieren oder Antworten zwischenspeichern. Deckt Unirest 4.x ab (erfordert Java 11+, modulare Abhängigkeiten, kong.unirest.core-Paket) mit GSON/Jackson-Objektzuordnung, Anforderungs-/Antwort-Interceptoren und Migration von Unirest 3.x.
