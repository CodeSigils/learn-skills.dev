Unirest-Java 4.x Java 11 以降用の HTTP クライアント ライブラリ。 HTTP リクエスト (GET/POST/PUT/DELETE) の作成、REST API クライアントの構築、JSON 応答の処理、ファイルのアップロード/ダウンロード、非同期リクエスト、サーバー送信イベント (SSE)、テストのための HTTP 呼び出しのモック、プロキシの構成、または応答のキャッシュを行うときに使用します。 GSON/Jackson オブジェクト マッピング、リクエスト/レスポンス インターセプター、Unirest 3.x からの移行を備えた Unirest 4.x (Java 11 以降、モジュラー依存関係、kong.unirest.core パッケージが必要) をカバーします。
