Sa-Token API 보안 방어 기능. 변조 방지 및 재생 방지(4단계 진화: 타임스탬프 + nonce + 서명)를 위한 API 매개변수 서명(sa-token-sign), 부분 승인 및 범위 제어(취소 가능/권한 제한)를 위한 API 키(sa-token-apikey), 단기 링크 초대를 위한 임시 토큰(SaTempUtil 코어 패키지에 내장됨)을 다룹니다.  
API 서명은 다중 애플리케이션(다중 비밀 키) 모드와 다양한 다이제스트 알고리즘(MD5/SHA-256/SHA-512)을 지원합니다. API 키는 다중 계정 시스템과 데이터베이스 지속성 모드를 지원합니다. 임시 토큰은 접두사 트리밍, 역방향 조회 및 JWT 통합을 지원합니다.  
기본 로그인 인증을 위해서는 먼저 sa-token 기능을 사용해 주세요.
