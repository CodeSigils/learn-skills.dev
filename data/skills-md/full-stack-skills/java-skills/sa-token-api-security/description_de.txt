Sicherheitsverteidigungsfunktionen der Sa-Token-API. Deckt API-Parametersignierung (sa-token-sign) zur Verhinderung von Manipulation und Wiedergabe (vierstufige Weiterentwicklung von Zeitstempel+Nonce+Sign), teilweise Autorisierung und Bereichskontrolle des API-Schlüssels (sa-token-apikey) (widerruflich/berechtigungsbeschränkt) sowie temporäre Linkeinladungen mit Token (eingebettetes SaTempUtil-Kernpaket) ab. Die API-Signierung unterstützt den Multianwendungsmodus (mehrere geheime Schlüssel) und verschiedene Digest-Algorithmen (md5/sha256/sha512). Der API-Schlüssel unterstützt ein System mit mehreren Konten und einen Datenbankpersistenzmodus. Das temporäre Token unterstützt das Trimmen von Präfixen, die umgekehrte Suche und die JWT-Integration. Für die einfache Login-Authentifizierung verwenden Sie bitte zunächst die Sa-Token-Funktion.
