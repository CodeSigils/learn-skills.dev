Capacités de défense de sécurité de l’API Sa-Token. Couvre la signature des paramètres API (sa-token-sign), l'anti-falsification et l'anti-relecture (évolution en quatre étapes : horodatage + nonce + signe), l'autorisation partielle de la clé API (sa-token-apikey) et le contrôle de la portée (révocable/autorisation limitée), le jeton temporaire (package de base intégré dans SaTempUtil) l'invitation à un lien de courte durée.  
Les signatures API prennent en charge le mode multi-application (plusieurs clés secrètes) et divers algorithmes de résumé (md5/sha256/sha512). Les clés API prennent en charge plusieurs systèmes de comptes et modes de persistance de base de données. Les jetons temporaires prennent en charge la suppression des préfixes, la recherche inversée et l'intégration JWT.  
Pour une authentification de connexion de base, veuillez d'abord utiliser la fonctionnalité sa-token.
