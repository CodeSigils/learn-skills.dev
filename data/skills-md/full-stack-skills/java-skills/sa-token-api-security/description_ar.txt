قدرات الدفاع الأمني ​​Sa-Token API. وهو يغطي توقيع معلمات واجهة برمجة التطبيقات (sa-token-sign) لمكافحة التلاعب ومكافحة إعادة التشغيل (تطور من أربع خطوات: الطابع الزمني + nonce+sign)، ومفتاح واجهة برمجة التطبيقات (sa-token-apikey)، والترخيص الجزئي والتحكم في النطاق (قابل للإلغاء/محدود)، ودعوات الارتباط قصيرة الأجل للرمز المميز (الحزمة الأساسية المضمنة في SaTempUtil).  

يدعم توقيع واجهة برمجة التطبيقات (API) وضع التطبيقات المتعددة (مفاتيح سرية متعددة) وخوارزميات الملخص المتنوعة (md5/sha256/sha512). يدعم API Key الأنظمة متعددة الحسابات ووضع استمرارية قاعدة البيانات. يدعم الرمز المؤقت قطع البادئة والبحث العكسي وتكامل JWT.  

لمصادقة تسجيل الدخول الأساسية، يرجى أولاً استخدام إمكانية sa-token.
