Возможности защиты API Sa-Token. Он охватывает подписание параметров API (sa-token-sign) для защиты от несанкционированного доступа и повторного воспроизведения (четырехэтапная эволюция: метка времени+nonce+sign), частичную авторизацию и контроль области действия ключа API (sa-token-apikey) (отзывной/ограниченный), а также временный токен (встроенный базовый пакет в SaTempUtil) для приглашений на краткосрочные ссылки.  

Подписание API поддерживает режим нескольких приложений (несколько секретных ключей) и различные алгоритмы дайджеста (md5/sha256/sha512). Ключ API поддерживает системы с несколькими учетными записями и режим сохранения базы данных. Временный токен поддерживает обрезку префиксов, обратный поиск и интеграцию JWT.  

Для базовой аутентификации при входе сначала используйте функцию sa-token.
