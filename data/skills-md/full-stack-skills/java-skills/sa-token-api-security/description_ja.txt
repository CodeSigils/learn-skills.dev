Sa-Token API のセキュリティ防御機能。改ざん防止とリプレイ防止のための API パラメーター署名 (sa-token-sign) (4 段階の進化: タイムスタンプ + nonce + 署名)、API キー (sa-token-apikey) の部分承認とスコープ制御 (取り消し可能/制限付き)、および一時トークン (SaTempUtil に埋め込まれたコア パッケージ) の有効期間の短いリンク招待について説明します。  

API 署名は、マルチアプリケーション (複数の秘密キー) モードとさまざまなダイジェスト アルゴリズム (md5/sha256/sha512) をサポートします。 API キーは、マルチアカウント システムとデータベース永続モードをサポートします。一時トークンは、プレフィックスのトリミング、逆引き参照、および JWT 統合をサポートしています。  

基本的なログイン認証の場合は、最初に sa-token 機能を使用してください。
