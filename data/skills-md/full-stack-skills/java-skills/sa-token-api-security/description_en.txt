Sa-Token API security defense capabilities. It covers API parameter signing (sa-token-sign) for anti‑tampering and anti‑replay (four‑step evolution: timestamp + nonce + sign), API Key (sa-token-apikey) partial authorization and scope control (revocable/limited), and temporary Token (embedded core package in SaTempUtil) short‑lived link invitations.  

API signing supports multi‑application (multiple secret keys) mode and various digest algorithms (md5/sha256/sha512). API Key supports multi‑account systems and database persistence mode. Temporary Token supports prefix trimming, reverse lookup, and JWT integration.  

For basic login authentication, please first use the sa-token capability.
