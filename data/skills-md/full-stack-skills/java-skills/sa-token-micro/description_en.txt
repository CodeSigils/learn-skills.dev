Sa-Token microservice authentication capability. It covers the Same-Token internal service external network isolation mechanism, unified authentication for Spring Cloud Gateway (reactive with Reactor), authentication for internal RPC calls via Feign/Dubbo/gRPC, distributed session solutions (Redis session center/JWT stateless), integration with Reactor/WebFlux frameworks, and dependency adaptation for Spring Boot 3/4. Use it when you need inter‑service authentication in a microservice architecture, gateway token forwarding and verification, internal service external network isolation, or distributed session sharing. For basic login authentication, first use the sa-token capability.
