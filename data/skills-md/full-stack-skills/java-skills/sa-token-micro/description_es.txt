Capacidad de autenticación de microservicio Sa-Token. Cubre el mecanismo de aislamiento de red externa del servicio interno Same-Token, autenticación unificada para Spring Cloud Gateway (reactiva con Reactor), autenticación para llamadas RPC internas a través de Feign/Dubbo/gRPC, soluciones de sesión distribuida (Centro de sesiones de Redis/JWT sin estado), integración con marcos de Reactor/WebFlux y adaptación de dependencia para Spring Boot 3/4. Úselo cuando necesite autenticación entre servicios en una arquitectura de microservicio, reenvío y verificación de tokens de puerta de enlace, aislamiento de redes externas de servicios internos o uso compartido de sesiones distribuidas. Para la autenticación de inicio de sesión básica, primero utilice la capacidad sa-token.
