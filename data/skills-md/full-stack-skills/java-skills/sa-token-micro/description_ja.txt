Sa-Token マイクロサービス認証機能。 Same-Token 内部サービスの外部ネットワーク分離メカニズム、Spring Cloud Gateway の統合認証 (Reactor でリアクティブ)、Feign/Dubbo/gRPC を介した内部 RPC 呼び出しの認証、分散セッション ソリューション (Redis セッション センター/JWT ステートレス)、Reactor/WebFlux フレームワークとの統合、Spring Boot 3/4 の依存関係適応について説明します。マイクロサービス アーキテクチャでのサービス間認証、ゲートウェイ トークンの転送と検証、内部サービスの外部ネットワークの分離、または分散セッション共有が必要な場合に使用します。基本的なログイン認証では、最初に sa-token 機能を使用します。
