Возможность аутентификации микросервиса Sa-Token. Он охватывает механизм изоляции внешней сети внутренней службы Same-Token, унифицированную аутентификацию для Spring Cloud Gateway (реактивную с Reactor), аутентификацию для внутренних вызовов RPC через Feign/Dubbo/gRPC, решения для распределенных сеансов (центр сеансов Redis/JWT без сохранения состояния), интеграцию с платформами Reactor/WebFlux и адаптацию зависимостей для Spring Boot 3/4. Используйте его, когда вам нужна межсервисная аутентификация в микросервисной архитектуре, пересылка и проверка токенов шлюза, изоляция внутренней службы от внешней сети или совместное использование распределенных сеансов. Для базовой аутентификации при входе сначала используйте функцию sa-token.
