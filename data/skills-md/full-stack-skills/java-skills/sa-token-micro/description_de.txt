Sa-Token-Microservice-Authentifizierungsfunktion. Es umfasst den Same-Token-Isolationsmechanismus für interne Dienste und externe Netzwerke, die einheitliche Authentifizierung für Spring Cloud Gateway (reaktiv mit Reactor), die Authentifizierung für interne RPC-Aufrufe über Feign/Dubbo/gRPC, verteilte Sitzungslösungen (Redis Session Hub/JWT Stateless), die Integration mit Reactor/WebFlux-Frameworks und die Anpassung für Spring Boot 3/4-Abhängigkeiten. Verwenden Sie es, wenn Sie eine Inter-Service-Authentifizierung in einer Microservice-Architektur, Gateway-Token-Weiterleitung und -Validierung, interne Service-Extern-Netzwerk-Isolation oder verteilte Sitzungsfreigabe benötigen. Verwenden Sie für die grundlegende Anmeldeauthentifizierung zunächst die Sa-Token-Funktion.
