Capacité d’authentification du microservice Sa-Token. Il couvre le mécanisme d'isolation du réseau externe du service interne Same-Token, l'authentification unifiée Spring Cloud Gateway (réactive Reactor), l'authentification des appels RPC internes Feign/Dubbo/gRPC, les solutions de session distribuées (centre de session Redis/JWT sans état), l'intégration du framework Reactor/WebFlux et l'adaptation des dépendances Spring Boot 3/4. Utilisez-le lorsque vous avez besoin d'une authentification interservices dans une architecture de microservices, du transfert et de la vérification de jetons de passerelle, de l'isolation de réseaux externes de services internes ou du partage de sessions distribuées. Pour une authentification de connexion de base, utilisez d'abord la fonctionnalité sa-token.
