Специализированный навык единого входа Sa-Token SSO. Охватывает три полных решения для режима единого входа: режим 1 (один и тот же домен + общий Redis/Cookie), режим 2 (междоменный + одно и то же перенаправление Redis/URL), режим 3 (междоменный + перекрестный билет Redis/HTTP). Создает центр аутентификации SSO-Server, интеграцию SSO-Client, единый выход, настраиваемую страницу входа, SSO с разделением спереди и сзади (решение H5), отправку сообщений, анонимного клиента, проверку домена, интеграцию NoSdk без Java, настраиваемую маршрутизацию API, перенаправление центра платформы. Используйте его, когда пользователям требуется унифицированный вход в систему и выход из системы в нескольких системах, создание единого центра аутентификации или интеграция междоменного единого входа. Для базовой аутентификации при входе сначала используйте навык sa-token.
