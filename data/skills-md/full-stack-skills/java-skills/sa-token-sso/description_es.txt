Habilidad especializada de inicio de sesión único de Sa-Token SSO. Cubre tres soluciones completas de modo SSO: Modo 1 (mismo dominio + Redis/Cookie compartida), Modo 2 (entre dominios + mismo Redis/redireccionamiento URL), Modo 3 (entre dominios + ticket cruzado de Redis/HTTP). Crea el centro de autenticación SSO-Servidor, integración SSO-Cliente, cierre de sesión único, página de inicio de sesión personalizada, SSO de separación frontal-posterior (solución H5), envío de mensajes, Cliente anónimo, verificación de dominio, integración NoSdk sin Java, enrutamiento API personalizado, redirección del centro de plataforma. Utilícelo cuando los usuarios necesiten inicio y cierre de sesión unificados en varios sistemas, crear un centro de autenticación de inicio de sesión único o integrar SSO entre dominios. Para la autenticación de inicio de sesión básica, utilice primero la habilidad sa-token.
