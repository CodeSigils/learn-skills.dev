Sa-Token SSOシングルサインオン特化スキル。 3 つの完全な SSO モード ソリューションをカバーします: モード 1 (同じドメイン + 共有 Redis/Cookie)、モード 2 (クロスドメイン + 同じ Redis/URL リダイレクト)、モード 3 (クロスドメイン + クロス Redis/HTTP チケット)。 SSO サーバー認証センター、SSO クライアント統合、シングル サインアウト、カスタム ログイン ページ、フロントバック分離 SSO (H5 ソリューション)、メッセージ プッシュ、匿名クライアント、ドメイン検証、NoSdk 非 Java 統合、カスタム API ルーティング、プラットフォーム センター リダイレクトを構築します。ユーザーが複数のシステム間で統一されたログイン/ログアウトを必要とする場合、シングル サインオン認証センターを構築する場合、またはクロスドメイン SSO を統合する必要がある場合に使用します。基本的なログイン認証には、最初に sa-token スキルを使用してください。
