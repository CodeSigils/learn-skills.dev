Sa-Token SSO 싱글 사인온 전문 기술. 모드 1(동일 도메인 + 동일한 Redis/쿠키 공유), 모드 2(교차 도메인 + 동일한 Redis/URL 리디렉션), 모드 3(교차 도메인 + 교차 Redis/HTTP 티켓)의 세 가지 SSO 모드에 대한 완전한 솔루션을 다룹니다.  
SSO-서버 인증 센터 설정, SSO-클라이언트 통합, 싱글 사인아웃, 사용자 정의 로그인 페이지, 전후면 분리 SSO(H5 솔루션), 메시지 푸시, 익명 클라이언트, 도메인 확인, NoSdk 비Java 통합, 사용자 정의 API 라우팅, 플랫폼 센터 리디렉션.  
사용자가 여러 시스템에서 통합 로그인/로그아웃을 필요로 하거나 SSO(Single Sign-On) 인증 센터를 구축하거나 도메인 간 SSO 통합이 필요할 때 사용합니다.  
기본 로그인 인증을 위해서는 먼저 sa-token 스킬을 사용해 주세요.
