Compétence spécialisée d’authentification unique Sa-Token SSO. Couvre des solutions complètes pour trois modes SSO : Mode 1 (même domaine + Redis/Cookie partagé), Mode 2 (inter-domaine + même redirection Redis/URL), Mode 3 (inter-domaine + ticket cross Redis/HTTP).  
Configuration du centre d'authentification SSO‑Server, intégration SSO‑Client, déconnexion unique, page de connexion personnalisée, séparation avant‑arrière SSO (solution H5), transmission de messages, client anonyme, vérification de domaine, intégration NoSdk non Java, routage API personnalisé, redirection du centre de plateforme.  
À utiliser lorsque les utilisateurs ont besoin d’une connexion/déconnexion unifiée sur plusieurs systèmes, de la création d’un centre d’authentification unique ou d’une intégration SSO inter-domaines.  
Pour une authentification de connexion de base, veuillez d’abord utiliser la compétence sa‑token.
