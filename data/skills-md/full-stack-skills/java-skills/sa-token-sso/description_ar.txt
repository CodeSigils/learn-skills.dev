Sa-Token SSO هي مهارة متخصصة في تسجيل الدخول الموحد. يغطي ثلاثة حلول كاملة لوضع SSO: الوضع 1 (نفس النطاق + Redis/Cookie المشترك)، الوضع 2 (عبر المجال + نفس إعادة توجيه Redis/URL)، الوضع 3 (عبر النطاق + تذكرة Redis/HTTP المشتركة). ينشئ مركز مصادقة SSO-Server، وتكامل SSO-Client، وتسجيل الخروج الفردي، وصفحة تسجيل الدخول المخصصة، والفصل الأمامي والخلفي SSO (حل H5)، ودفع الرسائل، والعميل المجهول، والتحقق من المجال، وتكامل NoSdk غير Java، وتوجيه واجهة برمجة التطبيقات المخصصة، وإعادة توجيه مركز النظام الأساسي. يُستخدم عندما يحتاج المستخدمون إلى تسجيل دخول/خروج موحد عبر أنظمة متعددة، أو إنشاء مركز مصادقة تسجيل دخول واحد، أو دمج تسجيل الدخول الموحّد (SSO) عبر النطاقات. لمصادقة تسجيل الدخول الأساسية، يرجى استخدام مهارة sa-token أولاً.
