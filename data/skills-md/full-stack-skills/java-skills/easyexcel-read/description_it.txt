Funzionalità di lettura dei dati Excel basate su Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Copre le modalità listener (ReadListener/AnalysisEventListener/PageReadListener), lettura sincrona (doReadSync), lettura di più fogli, corrispondenza @ExcelProperty(indice/nome), intestazioni su più righe (headRowNumber), convertitori personalizzati per date e numeri (@DateTimeFormat/@NumberFormat/Converter), gestione delle eccezioni del listener (onException + ExcelDataConvertException), lettura di informazioni aggiuntive (commenti/collegamenti ipertestuali/merged celle, extraRead + CellExtra), formule e tipi di celle (CellData<T>), lettura senza creare oggetti (ReadListener<Map<Integer,String>>) e lettura caricamento web (MultipartFile → InputStream). Utilizzare questa funzionalità quando gli utenti devono analizzare Excel (importare dati/inserire batch nel database/file di riconciliazione/caricamenti utente/Excel‑to‑object/Excel‑to‑Map); non è adatto per il riempimento in base a un modello predefinito (utilizzare invece easyexcel‑fill) e non è adatto per generare file Excel a livello di codice (utilizzare invece easyexcel‑write).
