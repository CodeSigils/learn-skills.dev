基於阿里巴巴EasyExcel（com.alibaba:easyexcel:4.0.3）的Excel資料讀取功能。涵蓋偵聽器模式 (ReadListener/AnalysisEventListener/PageReadListener)、同步讀取 (doReadSync)、多表讀取、@ExcelProperty(index/name) 匹配、多行標題 (headRowNumber)、日期和數字的自訂轉換器 (@DateTimeFormat/@NumberFormat/Converter) (onException+ExcelDataConvertException)、額外資訊讀取（註解/超連結/合併儲存格、 extraRead+CellExtra)、公式和單元格類型 (CellData<T>)、不建立物件的讀取 (ReadListener<Map<Integer,String>>) 以及 Web 上傳讀取 (MulStreamtipart→InputpStream(MulStreamtipart)。當使用者需要解析 Excel（匯入資料/批次插入資料庫/對帳檔案/使用者上傳/Excel 到物件/Excel 到地圖）時，請使用此功能。它不適合根據預定義模板進行填充（改用easyexcel-fill），也不適合以程式設計方式產生Excel（改用easyexcel-write）。
