Capacité de lecture de données Excel basée sur Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Il couvre les modes d'écoute (ReadListener/AnalysisEventListener/PageReadListener), la lecture synchrone (doReadSync), la lecture multi-feuilles, la correspondance @ExcelProperty (index/nom), les en-têtes multi-lignes (headRowNumber), les convertisseurs personnalisés pour les dates et les nombres (@DateTimeFormat/@NumberFormat/Converter), la gestion des exceptions d'écoute (onException + ExcelDataConvertException), la lecture d'informations supplémentaires (commentaires/hyperliens/cellules fusionnées, extraRead + CellExtra), les formules et les types de cellules (CellData<T>), la lecture sans créer d'objets (ReadListener<Map<Integer,String>>) et la lecture par téléchargement Web (MultipartFile → InputStream). Utilisez cette fonctionnalité lorsque les utilisateurs ont besoin d'analyser Excel (importation de données, insertion groupée, fichiers de rapprochement, téléchargements utilisateur, Excel vers objet, Excel vers carte). Il ne convient pas au remplissage basé sur des modèles prédéfinis (utilisez plutôt easyexcel-fill) ni à la génération de fichiers Excel par programme (utilisez plutôt easyexcel-write).
