Возможности чтения данных Excel на основе Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Охватывает режимы прослушивателя (ReadListener/AnalysisEventListener/PageReadListener), синхронное чтение (doReadSync), чтение нескольких листов, сопоставление @ExcelProperty(index/name), многострочные заголовки (headRowNumber), пользовательские преобразователи дат и чисел (@DateTimeFormat/@NumberFormat/Converter), обработку исключений прослушивателя (onException+ExcelDataConvertException), чтение дополнительной информации. (комментарии/гиперссылки/объединенные ячейки, extraRead+CellExtra), формулы и типы ячеек (CellData<T>), чтение без создания объектов (ReadListener<Map<Integer,String>>) и чтение через Интернет (MultipartFile→InputStream). Используйте эту возможность, когда пользователям необходимо проанализировать Excel (импортировать данные/пакетную вставку в базу данных/файлы согласования/загрузки пользователей/Excel в объект/Excel в карту). Он не подходит для заполнения по предопределенным шаблонам (вместо этого используйте easyexcel‑fill) и не подходит для программного создания Excel (вместо этого используйте easyexcel‑write).
