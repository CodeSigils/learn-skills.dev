Excel data reading capabilities based on Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Covers listener modes (ReadListener/AnalysisEventListener/PageReadListener), synchronous reading (doReadSync), multiple‑sheet reading, @ExcelProperty(index/name) matching, multi‑row headers (headRowNumber), custom converters for dates and numbers (@DateTimeFormat/@NumberFormat/Converter), listener exception handling (onException + ExcelDataConvertException), extra information reading (comments/hyperlinks/merged cells, extraRead + CellExtra), formulas and cell types (CellData<T>), reading without creating objects (ReadListener<Map<Integer,String>>), and web‑upload reading (MultipartFile→InputStream). Use this capability when users need to parse Excel (import data/batch insert to database/reconciliation files/user uploads/Excel‑to‑object/Excel‑to‑Map). It is not suitable for filling according to predefined templates (use easyexcel‑fill instead) and not suitable for programmatically generating Excel (use easyexcel‑write instead).
