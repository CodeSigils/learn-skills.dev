JUnit5 + Mockito 테스트 프레임워크 기술. @RunWith를 대체하는 JUnit5 @ExtendWith, Mockito @Mock/@InjectMocks 규칙, 테스트 격리 원칙(FIRST), @SpringBootTest 사용 여부(@WebMvcTest/@DataJpaTest 슬라이스 테스트), BDDMockito 제공/willReturn 스타일, ArgumentCaptor 매개변수 캡처, 동작 검증 확인 및 @ParameterizedTest 매개변수화된 테스트를 다룹니다. 이 기술은 사용자가 Java 단위/통합 테스트를 작성하고 외부 종속성을 모의할 때 필요합니다.
