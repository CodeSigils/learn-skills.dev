Навыки тестирования JUnit5 + Mockito. Охватывает JUnit5 @ExtendWith в качестве замены @RunWith, правила Mockito @Mock/@InjectMocks, принцип изоляции тестирования (FIRST), когда использовать или не использовать @SpringBootTest (срезовое тестирование с @WebMvcTest/@DataJpaTest), стиль BDDMockito заданный/willReturn, захват параметров ArgumentCaptor, проверку поведения и параметризованное тестирование @ParameterizedTest. Этот навык необходим, когда пользователи пишут модульные/интеграционные тесты Java и имитируют внешние зависимости.
