JUnit5 + Mockito テスト フレームワークのスキル。 @RunWith の代替としての JUnit5 @ExtendWith、Mockito @Mock/@InjectMocks ルール、テスト分離原則 (FIRST)、@SpringBootTest を使用する場合と使用しない場合 (@WebMvcTest/@DataJpaTest によるスライス テスト)、BDDMockito の指定/willReturn スタイル、ArgumentCaptor パラメーター キャプチャ、動作検証の検証、および @ParameterizedTest パラメーター化テストについて説明します。このスキルは、ユーザーが Java 単体テスト/統合テストを作成し、外部依存関係を模擬するときに必要です。
