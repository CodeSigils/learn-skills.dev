Compétences du cadre de test JUnit5 + Mockito. Couvre JUnit5 @ExtendWith en remplacement de @RunWith, les règles Mockito @Mock/@InjectMocks, le principe d'isolation des tests (FIRST), quand utiliser ou non @SpringBootTest (tests de tranche avec @WebMvcTest/@DataJpaTest), le style BDDMockito donné/willReturn, la capture des paramètres ArgumentCaptor, la vérification de la vérification du comportement et les tests paramétrés @ParameterizedTest. Cette compétence est requise lorsque les utilisateurs écrivent des tests unitaires ou d'intégration Java et simulent des dépendances externes.
