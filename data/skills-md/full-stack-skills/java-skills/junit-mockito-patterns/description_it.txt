JUnit5 + Mockito testa le competenze del framework. Copre JUnit5 @ExtendWith in sostituzione di @RunWith, regole Mockito @Mock/@InjectMocks, principio di isolamento del test (FIRST), quando utilizzare e quando non utilizzare @SpringBootTest (test di sezioni con @WebMvcTest/@DataJpaTest), stile BDDMockito fornito/willReturn, acquisizione dei parametri ArgumentCaptor, verifica del comportamento di verifica e test parametrizzato @ParameterizedTest. Questa competenza è richiesta quando gli utenti scrivono unit test/test di integrazione Java e simulano dipendenze esterne.
