Habilidades del marco de prueba JUnit5 + Mockito. Cubre JUnit5 @ExtendWith como reemplazo de @RunWith, reglas de Mockito @Mock/@InjectMocks, principio de aislamiento de pruebas (FIRST), cuándo usar o no usar @SpringBootTest (pruebas de corte con @WebMvcTest/@DataJpaTest), estilo dado/willReturn de BDDMockito, captura de parámetros de ArgumentCaptor, verificación de comportamiento de verificación y pruebas parametrizadas de @ParameterizedTest. Esta habilidad es necesaria cuando los usuarios escriben pruebas unitarias/pruebas de integración de Java y simulan dependencias externas.
