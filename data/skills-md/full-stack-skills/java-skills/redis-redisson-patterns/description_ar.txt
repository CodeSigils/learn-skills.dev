Redis + Redisson ذاكرة التخزين المؤقت وخبرة القفل الموزع. يغطي اصطلاحات تسمية مفتاح ذاكرة التخزين المؤقت، ومبادئ إعداد وقت انتهاء الصلاحية، وخيارات تسلسل RedisTemplate (JSON مقابل JDK مقابل String)، وأوضاع القفل الموزع الثلاثة الرئيسية لـ Redisson (المراقبة / TryLock مع LeaseTime / TryLock بدون قرارات LeaseTime)، والحماية ضد اختراق ذاكرة التخزين المؤقت (مرشح Bloom / التخزين المؤقت للقيمة الخالية)، وانهيار ذاكرة التخزين المؤقت (قفل كائن المزامنة)، وانهيار ذاكرة التخزين المؤقت (TTL العشوائي)، والقرار بين Caffeine وRedis.  

تصحيحات LLM: لا تحذف أوقات انتهاء الصلاحية؛ تجنب الخلط بين StringRedisTemplate وRedisTemplate؛ افتح دائمًا أقفال Redisson في كتلة المحاولة الأخيرة؛ لا تعمل الوكالة الدولية للطاقة عندما يتم تعيين مدة الإيجار بشكل صريح.
