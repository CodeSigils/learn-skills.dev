Опыт Redis + Redisson и распределенной блокировки. Описываются соглашения об именах ключей кэша, принципы установки срока действия, варианты сериализации RedisTemplate (JSON, JDK или String), три основных режима распределенной блокировки Redisson (сторожевой таймер / tryLock с помощью LeesTime / tryLock без решений LeisTime), защита от проникновения в кэш (фильтр Блума / кэширование нулевых значений), разрушение кэша (блокировка мьютекса) и лавина кэша (случайный TTL), а также решение между Caffeine и Redis.  

Исправления для LLM: не пропускать срок действия; избегайте смешивания StringRedisTemplate и RedisTemplate; всегда разблокируйте блокировки Redisson в блоке try-finally; сторожевой таймер не работает, если значение LeaseTime задано явно.
