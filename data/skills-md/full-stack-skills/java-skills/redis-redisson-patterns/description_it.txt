Capacità di memorizzazione nella cache Redis + Redisson e blocco distribuito. Copre le convenzioni di denominazione delle chiavi della cache, i principi di impostazione del tempo di scadenza, le scelte di serializzazione di RedisTemplate (JSON vs JDK vs String), le tre principali modalità di blocco distribuite Redisson (watchdog/tryLock con leaseTime/senza decisioni leaseTime), protezione contro la penetrazione della cache (filtro Bloom/caching di valori vuoti), interruzione della cache (blocco mutex), valanga di cache (TTL casuale) e decisioni di selezione di Caffeine vs Redis.
