Redis + Redisson 캐시 및 분산 잠금 기술. 캐시 키 명명 규칙, 만료 시간 설정 원칙, RedisTemplate 직렬화 선택(JSON 대 JDK 대 문자열), Redisson의 세 가지 주요 분산 잠금 모드(watchdog/tryLock with LeaseTime/leaseTime 결정 없음), 캐시 침투 방지(Bloom 필터/빈 값 캐시), 고장(뮤텍스 잠금) 및 눈사태(임의 TTL), 카페인 대 Redis 선택 결정이 포함됩니다. LLM에 대한 수정 사항: 만료 시간을 설정하지 않음, StringRedisTemplate과 RedisTemplate을 혼합, Redisson 잠금을 잠금 해제하기 위해 try-finally를 사용하지 않음, 임대 시간이 지정된 경우 watchdog이 적용되지 않음.
