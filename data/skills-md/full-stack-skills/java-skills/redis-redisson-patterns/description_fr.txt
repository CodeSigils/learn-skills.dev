Compétences en matière de mise en cache Redis + Redisson et de verrouillage distribué. Couvre les conventions de dénomination des clés de cache, les principes de définition du délai d'expiration, les choix de sérialisation RedisTemplate (JSON vs JDK vs String), les trois principaux modes de verrouillage distribué Redisson (watchdog / tryLock avec leaseTime / sans décisions leaseTime), la protection contre la pénétration du cache (filtre Bloom / cache à valeur nulle), la panne du cache (verrouillage mutex), l'avalanche de cache (TTL aléatoire) et les décisions de sélection Caffeine vs Redis. Corrections pour LLM : non réglage du délai d'expiration, mélange de StringRedisTemplate et RedisTemplate, verrouillage Redisson sans try‑finally unlock, chien de garde non efficace lorsqu'un leaseTime est spécifié.
