Habilidad para completar plantillas de Excel basada en Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Cubre el llenado de objetos simple, el llenado de listas ({.}+forceNewRow), el llenado combinado horizontal de varias columnas (FillWrapper+WriteDirectionEnum.HORIZONTAL), el llenado complejo (incluido el total de filas/filas estadísticas/relleno antes de la escritura), la integración de Spring Boot, las especificaciones de diseño de plantillas, los caracteres de escape, las diferencias entre las versiones de Excel 2003/2007 y las optimizaciones de rendimiento (relleno incremental, almacenamiento en caché de archivos). Utilice esta habilidad cuando los usuarios necesiten completar una plantilla .xlsx prefabricada (sintaxis variable {var}, {.}, {prefix.}) con objetos Java o datos de mapas para generar informes (recibos de pago, contratos, estados de conciliación, facturas, estados financieros, tablas estadísticas, tablas de resumen). No es adecuado para escenarios de "Excel generado mediante programación" sin plantilla (en su lugar, utilice easyexcel-write).
