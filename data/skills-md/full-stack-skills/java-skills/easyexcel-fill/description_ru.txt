Навыки заполнения шаблонов Excel на основе Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Охватывает простое заполнение объектов, заполнение списка ({.}+forceNewRow), горизонтальное комбинированное заполнение нескольких столбцов (FillWrapper+WriteDirectionEnum.HORIZONTAL), сложное заполнение (включая общее количество строк/статистические строки/заполнение перед записью), интеграцию Spring Boot, спецификации дизайна шаблонов, escape-символы, различия между версиями Excel 2003/2007 и оптимизацию производительности (добавочное заполнение, кэширование файлов). Используйте этот навык, когда пользователям необходимо заполнить готовый шаблон .xlsx (синтаксис переменных {var}, {.}, {prefix.}) объектами Java или данными карты для создания отчетов (платёжных квитанций, контрактов, актов сверки, счетов-фактур, финансовых отчетов, статистических таблиц, сводных таблиц). Он не подходит для нешаблонных сценариев «программно созданного Excel» (вместо этого используйте easyexcel‑write).
