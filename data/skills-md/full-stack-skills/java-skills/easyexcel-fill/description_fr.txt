Une capacité de remplissage de modèles Excel basée sur Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Il couvre le remplissage d'objets simples, le remplissage de listes ({.}+forceNewRow), le remplissage combiné multi-colonnes horizontal (FillWrapper+WriteDirectionEnum.HORIZONTAL), le remplissage complexe (y compris le nombre total de lignes/lignes statistiques/remplissage-puis-écriture), l'intégration de Spring Boot, les spécifications de conception de modèles, les caractères d'échappement, les différences entre les formats 03 et 07 et les optimisations de performances (remplissage incrémentiel, mise en cache de fichiers). Utilisez cette fonctionnalité lorsque les utilisateurs doivent remplir un modèle.xlsx prédéfini (syntaxe variable {var}, {.}, {prefix.}) avec des objets Java ou des données cartographiques pour générer des rapports (fiches de paie, contrats, états de rapprochement, factures, rapports financiers, tableaux statistiques, tableaux récapitulatifs). Il ne convient pas aux scénarios de « génération Excel programmatique » sans modèle (utilisez plutôt easyexcel‑write).
