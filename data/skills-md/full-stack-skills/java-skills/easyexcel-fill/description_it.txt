Abilità di riempimento di modelli Excel basata su Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Copre il riempimento semplice di oggetti, riempimento di elenchi ({.}+forceNewRow), riempimento combinato orizzontale di più colonne (FillWrapper+WriteDirectionEnum.HORIZONTAL), riempimento complesso (incluse righe totali/righe statistiche/riempimento prima della scrittura), integrazione Spring Boot, specifiche di progettazione del modello, caratteri di escape, differenze tra le versioni 03 e 07, ottimizzazioni delle prestazioni (riempimento incrementale, memorizzazione nella cache dei file). Utilizzare questa competenza quando gli utenti devono inserire oggetti Java o dati Map in un modello .xlsx predefinito (sintassi variabile {var}, {.}, {prefix.}) per generare report (buste paga, contratti, estratti conto di riconciliazione, fatture, rendiconti finanziari, tabelle statistiche, tabelle riepilogative); non è adatto per scenari di “generazione programmatica di Excel” senza modello (utilizzare invece easyexcel‑write).
