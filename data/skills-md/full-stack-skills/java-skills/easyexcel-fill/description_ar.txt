مهارة ملء قالب Excel بناءً على Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). يغطي التعبئة البسيطة للكائنات، وملء القائمة ({.}+forceNewRow)، والتعبئة الأفقية المجمعة متعددة الأعمدة (FillWrapper+WriteDirectionEnum.HORIZONTAL)، والتعبئة المعقدة (بما في ذلك إجمالي الصفوف/الصفوف الإحصائية/الملء قبل الكتابة)، وتكامل Spring Boot، ومواصفات تصميم القالب، وأحرف الهروب، والاختلافات بين إصدارات Excel 2003/2007، وتحسينات الأداء (التعبئة المتزايدة، والتخزين المؤقت للملفات). استخدم هذه المهارة عندما يحتاج المستخدمون إلى ملء قالب .xlsx معد مسبقًا (بناء الجملة المتغير {var}، {.}، {prefix.}) باستخدام كائنات Java أو بيانات الخريطة لإنشاء التقارير (قسائم الدفع، العقود، بيانات التسوية، الفواتير، البيانات المالية، الجداول الإحصائية، الجداول التلخيصية). إنه غير مناسب لسيناريوهات "Excel التي تم إنشاؤها برمجيًا" غير القالبية (استخدم easyexcel‑write بدلاً من ذلك).
