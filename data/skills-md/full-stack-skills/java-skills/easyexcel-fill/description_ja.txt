Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3) に基づく Excel テンプレート入力スキル。単純なオブジェクトの埋め込み、リストの埋め込み ({.}+forceNewRow)、水平方向の複数列の結合埋め込み (FillWrapper+WriteDirectionEnum.HORIZONTAL)、複雑な埋め込み (総行数/統計行/書き込み前の埋め込みを含む)、Spring Boot の統合、テンプレートの設計仕様、エスケープ文字、Excel 2003/2007 バージョン間の違い、パフォーマンスの最適化 (増分埋め込み、ファイル キャッシュ) について説明します。このスキルは、ユーザーがレポート (給与明細、契約書、調整表、請求書、財務諸表、統計表、要約表) を生成するために Java オブジェクトまたはマップ データを使用して事前に作成された .xlsx テンプレート (変数構文 {var}、{.}、{prefix.}) を設定する必要がある場合に使用します。これは、テンプレート以外の「プログラムで生成された Excel」シナリオには適していません (代わりに easyexcel-write を使用してください)。
