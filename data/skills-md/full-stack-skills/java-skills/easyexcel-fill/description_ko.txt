Alibaba EasyExcel(com.alibaba:easyexcel:4.0.3)을 기반으로 한 Excel 템플릿 작성 기능. 간단한 객체 채우기, 목록 채우기({.}+forceNewRow), 수평 다중 열 결합 채우기(FillWrapper+WriteDirectionEnum.HORIZONTAL), 복잡한 채우기(총 행/통계 행/쓰기 전 채우기 포함), Spring Boot 통합, 템플릿 디자인 사양, 이스케이프 문자, Excel 2003과 2007 버전 간의 차이점, 성능 최적화(증분 채우기, 파일 캐싱)를 다룹니다. 사용자가 보고서(급여 명세서, 계약, 조정 명세서, 송장, 재무 보고서, 통계 테이블, 요약 테이블)를 생성하기 위해 Java 객체를 입력하거나 미리 정의된.xlsx 템플릿(변수 구문 {var}, {.}, {prefix.})에 데이터를 매핑해야 하는 경우 이 기능을 사용합니다. 템플릿 기반이 아닌 "프로그래밍 방식 Excel 생성" 시나리오에는 적용할 수 없습니다(대신 easyexcel-write 사용).
