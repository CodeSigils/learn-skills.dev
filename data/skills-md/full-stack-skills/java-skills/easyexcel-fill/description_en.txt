Excel template-filling skill based on Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Covers simple object filling, list filling ({.}+forceNewRow), horizontal multi‑column combined filling (FillWrapper + WriteDirectionEnum.HORIZONTAL), complex filling (including total rows/statistical rows/fill before write), Spring Boot integration, template design specifications, escape characters, differences between Excel 2003/2007 versions, and performance optimizations (incremental fill, file caching). Use this skill when users need to populate a pre‑made .xlsx template (variable syntax {var}, {.}, {prefix.}) with Java objects or Map data to generate reports (pay slips, contracts, reconciliation statements, invoices, financial statements, statistical tables, summary tables). It is not suitable for non‑template “programmatically generated Excel” scenarios (use easyexcel‑write instead).
