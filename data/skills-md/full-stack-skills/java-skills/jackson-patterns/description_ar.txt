مهارات تسلسل جاكسون JSON. تجاوز تكوين تنسيق التاريخ (غير ISO‑8601)، وقواعد التسلسل الفارغة (الصفيف → []، السلسلة → ""، الرقم → null)، وطبقات @JsonView، وقاعدة ObjectMapper المفردة، وإلغاء التسلسل العام لـ TypeReference، ومبادئ التعليقات التوضيحية @JsonProperty/@JsonFormat/@JsonIgnore، والتكامل مع Spring Boot. يُستخدم عندما يتعامل المستخدمون مع تسلسل/إلغاء تسلسل JSON، أو تكوين ObjectMapper، أو حل تنسيق التاريخ أو مشكلات المعالجة الخالية.
