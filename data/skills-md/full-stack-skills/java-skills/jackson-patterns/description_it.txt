Competenze di serializzazione Jackson JSON: sostituzione della configurazione del formato della data (non‑ISO‑8601), regole di serializzazione null (array → [], stringa → "", numero → null), stratificazione @JsonView, regola singleton ObjectMapper, deserializzazione generica TypeReference, principi delle annotazioni @JsonProperty/@JsonFormat/@JsonIgnore e integrazione con Spring Boot. Utilizzato quando gli utenti gestiscono la serializzazione/deserializzazione JSON, configurano ObjectMapper o risolvono problemi relativi al formato della data o alla gestione dei valori null.
