Kenntnisse in der JSON-Serialisierung von Jackson. Überschreiben Sie die Datumsformatkonfiguration (nicht ISO-8601), Nullserialisierungsregeln (array→[] / string→"" / number→null), @JsonView-Layering, ObjectMapper-Singleton-Regel, generische TypeReference-Deserialisierung, Prinzipien von @JsonProperty/@JsonFormat/@JsonIgnore-Annotationen und Integration mit Spring Boot. Wird verwendet, wenn Benutzer die JSON-Serialisierung/Deserialisierung durchführen, ObjectMapper konfigurieren oder Probleme mit dem Datumsformat oder der Nullverarbeitung beheben.
