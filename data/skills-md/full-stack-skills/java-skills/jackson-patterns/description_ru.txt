Навыки сериализации Джексона JSON. Переопределить конфигурацию формата даты (не ISO-8601), правила нулевой сериализации (массив → [], строка → "", число → нуль), многоуровневое представление @JsonView, одноэлементное правило ObjectMapper, универсальную десериализацию TypeReference, принципы аннотаций @JsonProperty/@JsonFormat/@JsonIgnore и интеграцию со Spring Boot. Используется, когда пользователи обрабатывают сериализацию/десериализацию JSON, настраивают ObjectMapper или решают проблемы с форматом даты или обработкой значений NULL.
