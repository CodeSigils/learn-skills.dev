XXL-JOB best practice pattern. Customized wrapper based on hiwepy/xxljob-spring-boot-starter, covering the @XxlJobCron annotation to replace the native @XxlJob (code as configuration / cron written in code / automatically registered to admin at startup), XxlJobTemplate programming-style task management (CRUD / start‑stop / trigger / session auto‑renewal), executor auto‑configuration (Unirest SSL / port fallback / Nacos adaptation), Micrometer metrics integration, v2/v3 dual-version compatibility. Correct LLM misuse: using @Scheduled instead of distributed scheduling, unaware of XxlJobTemplate's programmatic management, unaware of @XxlJobCron's self‑starting auto‑registration mode.
