Шаблон передового опыта XXL-JOB. Настраиваемая оболочка на основе hiwepy/xxljob-spring-boot-starter, охватывающая аннотацию @XxlJobCron для замены собственной @XxlJob (код в виде конфигурации / cron, записанный в коде / автоматически регистрируемый администратором при запуске), управление задачами в стиле программирования XxlJobTemplate (CRUD / start-stop / триггер / автоматическое продление сеанса), автоматическая настройка исполнителя (Unirest SSL / резервный порт / Nacos) адаптация), интеграция метрик микрометра, совместимость двух версий v2/v3. Правильное неправильное использование LLM: использование @Scheduled вместо распределенного планирования, незнание программного управления XxlJobTemplate, незнание режима самозапускающейся автоматической регистрации @XxlJobCron.
