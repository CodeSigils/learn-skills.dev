XXL-JOB のベスト プラクティス パターン。 hiwepy/xxljob-spring-boot-starter に基づいたカスタマイズされたラッパー。ネイティブの @XxlJob を置き換えるために @XxlJobCron アノテーションをカバー (構成としてのコード / コード内に記述された cron / 起動時に管理者に自動的に登録)、XxlJobTemplate プログラミング スタイルのタスク管理 (CRUD / 開始停止 / トリガー / セッション自動更新)、エグゼキュータ自動構成 (Unirest SSL / ポート)フォールバック / Nacos 適応）、Micrometer メトリック統合、v2/v3 デュアル バージョン互換性。 LLM の誤用を修正します。分散スケジューリングの代わりに @Scheduled を使用し、XxlJobTemplate のプログラムによる管理を認識せず、@XxlJobCron の自動開始自動登録モードを認識しません。
