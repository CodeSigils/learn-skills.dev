Lombok annotation usage rules and skills. Covers combination rules for @Data/@Builder/@Slf4j, inheritance pitfalls of @EqualsAndHashCode(callSuper=true), integration with Jackson/@Builder/@Jacksonized, resolution of conflicts with MyBatis no‑argument constructors, @Value immutable objects, @With object copying, and @SuperBuilder inheritance of Builder. Corrects the most common Lombok misuse by LLMs: omitting callSuper, not adding @Jacksonized, Builder–inheritance conflicts, and loss of default values with @Builder.Default.
