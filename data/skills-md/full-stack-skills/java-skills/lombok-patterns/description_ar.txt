قواعد ومهارات استخدام التعليقات التوضيحية في لومبوك. يغطي قواعد التجميع لـ @Data/@Builder/@Slf4j، ومزالق وراثة @EqualsAndHashCode(callSuper=true)، والتكامل مع Jackson/@Builder/@Jacksonized، وحل التعارضات مع منشئي MyBatis بدون وسيطات، و@Value الكائنات غير القابلة للتغيير، و@With نسخ الكائنات، و@SuperBuilder وراثة Builder. يصحح إساءة استخدام Lombok الأكثر شيوعًا بواسطة LLM: حذف callSuper، وعدم إضافة @Jacksonized، وتعارضات وراثة Builder، وفقدان القيم الافتراضية مع @Builder.Default.
