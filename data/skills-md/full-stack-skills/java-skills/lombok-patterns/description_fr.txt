Directives d'utilisation des annotations de Lombok. Couvre les règles de combinaison pour @Data/@Builder/@Slf4j, les pièges de l'héritage de @EqualsAndHashCode(callSuper=true), l'intégration avec Jackson/@Builder/@Jacksonized, la résolution des conflits avec les constructeurs sans argument MyBatis, les objets immuables @Value, la copie d'objet @With et l'héritage @SuperBuilder de Builder. Corrige les utilisations abusives les plus courantes de Lombok par les LLM : omission de callSuper, @Jacksonized manquant, conflits d'héritage Builder et perte des valeurs par défaut avec @Builder.Default.
