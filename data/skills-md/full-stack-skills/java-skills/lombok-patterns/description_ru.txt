Правила и навыки использования аннотаций Ломбок. Охватывает правила комбинирования для @Data/@Builder/@Slf4j, ошибки наследования @EqualsAndHashCode(callSuper=true), интеграцию с Jackson/@Builder/@Jacksonized, разрешение конфликтов с конструкторами без аргументов MyBatis, неизменяемыми объектами @Value, копированием объектов @With и наследованием Builder @SuperBuilder. Исправляет наиболее распространенное неправильное использование Lombok со стороны LLM: отсутствие callSuper, отсутствие добавления @Jacksonized, конфликты наследования Builder и потерю значений по умолчанию с @Builder.Default.
