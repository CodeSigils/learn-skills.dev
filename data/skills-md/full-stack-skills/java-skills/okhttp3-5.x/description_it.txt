Client HTTP OkHttp 5.x per Java/JVM 8+ e Android 5+. Da utilizzare quando si effettuano richieste HTTP/HTTPS, si creano client API REST, si implementa il pooling di connessioni, la memorizzazione nella cache delle risposte, gli intercettori di richieste/risposte, l'associazione di certificati, il monitoraggio degli eventi, le connessioni WebSocket, il consumo SSE o la configurazione di suite di crittografia/TLS. Copre OkHttp 5.4.0 con HTTP/2, GZIP trasparente, Fast Fallback (Happy Eyeballs), MockWebServer per test e supporto GraalVM Native Image.
