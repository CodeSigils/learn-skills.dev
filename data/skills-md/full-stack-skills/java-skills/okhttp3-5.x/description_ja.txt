OkHttp 5.x Java/JVM 8 以降および Android 5 以降用の HTTP クライアント。 HTTP/HTTPS リクエストの作成、REST API クライアントの構築、接続プーリングの実装、レスポンス キャッシュ、リクエスト/レスポンス インターセプタ、証明書の固定、イベント モニタリング、WebSocket 接続、SSE 消費、または TLS/暗号スイートの構成を行う場合に使用します。 HTTP/2 を備えた OkHttp 5.4.0、透過的な GZIP、高速フォールバック (Happy Eyeballs)、テスト用の MockWebServer、および GraalVM ネイティブ イメージのサポートをカバーします。
