عميل OkHttp 5.x HTTP لـ Java/JVM 8+ وAndroid 5+. يُستخدم عند تقديم طلبات HTTP/HTTPS، أو إنشاء عملاء REST API، أو تنفيذ تجميع الاتصالات، أو التخزين المؤقت للاستجابة، أو اعتراضات الطلب/الاستجابة، أو تثبيت الشهادات، أو مراقبة الأحداث، أو اتصالات WebSocket، أو استهلاك SSE، أو تكوين مجموعات TLS/cipher. يغطي OkHttp 5.4.0 مع HTTP/2، وGZIP الشفاف، وFast Fallback (Happy Eyeballs)، وMockWebServer للاختبار، ودعم GraalVM Native Image.
