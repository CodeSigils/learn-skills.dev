HTTP-клиент OkHttp 5.x для Java/JVM 8+ и Android 5+. Используйте при выполнении запросов HTTP/HTTPS, создании клиентов REST API, реализации пула соединений, кэшировании ответов, перехватчиках запросов/ответов, закреплении сертификатов, мониторинге событий, подключениях WebSocket, использовании SSE или настройке наборов TLS/шифров. Охватывает OkHttp 5.4.0 с HTTP/2, прозрачным GZIP, быстрым резервным копированием (счастливые глазные яблоки), MockWebServer для тестирования и поддержкой собственных изображений GraalVM.
