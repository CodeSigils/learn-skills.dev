Libreria client HTTP Unirest-Java 3.x per Java 8+. Da utilizzare quando si effettuano richieste HTTP (GET/POST/PUT/DELETE), si creano client API REST, si gestiscono risposte JSON, caricamenti/download di file, richieste asincrone, chiamate HTTP fittizie per test, configurazione proxy o memorizzazione nella cache delle risposte. Copre Unirest 3.x (basato su Apache HttpClient, GSON predefinito incluso, pacchetto kong.unirest) con mappatura degli oggetti, intercettatori di richiesta/risposta e indicazioni sulla migrazione.
