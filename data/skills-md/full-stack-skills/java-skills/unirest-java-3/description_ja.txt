Unirest-Java 3.x Java 8 以降用の HTTP クライアント ライブラリ。 HTTP リクエスト (GET/POST/PUT/DELETE) の作成、REST API クライアントの構築、JSON 応答の処理、ファイルのアップロード/ダウンロード、非同期リクエスト、テストのための HTTP 呼び出しのモック、プロキシの構成、または応答のキャッシュを行うときに使用します。 Unirest 3.x (Apache HttpClient ベース、デフォルトの GSON を含む、kong.unirest パッケージ) をオブジェクト マッピング、リクエスト/レスポンス インターセプター、移行ガイダンスとともにカバーします。
