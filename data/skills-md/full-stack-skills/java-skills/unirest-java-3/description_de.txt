Unirest-Java 3.x HTTP-Client-Bibliothek für Java 8+. Wird verwendet, wenn Sie HTTP-Anfragen stellen (GET/POST/PUT/DELETE), REST-API-Clients erstellen, JSON-Antworten verarbeiten, Datei-Uploads/Downloads durchführen, asynchrone Anfragen erstellen, HTTP-Aufrufe zum Testen verspotten, Proxys konfigurieren oder Antworten zwischenspeichern. Deckt Unirest 3.x (Apache HttpClient-basiert, Standard-GSON enthalten, kong.unirest-Paket) mit Objektzuordnung, Anforderungs-/Antwort-Interceptoren und Migrationsanleitungen ab.
