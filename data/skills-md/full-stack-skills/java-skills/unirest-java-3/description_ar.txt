مكتبة عميل Unirest-Java 3.x HTTP لـ Java 8+. يُستخدم عند تقديم طلبات HTTP (GET/POST/PUT/DELETE)، أو إنشاء عملاء REST API، أو التعامل مع استجابات JSON، أو تحميل/تنزيل الملفات، أو الطلبات غير المتزامنة، أو الاستهزاء باستدعاءات HTTP للاختبار، أو تكوين الوكلاء، أو تخزين الاستجابات مؤقتًا. يغطي Unirest 3.x (يعتمد على Apache HttpClient، ويتضمن GSON الافتراضي، وحزمة kong.unirest) مع تعيين الكائنات، واعتراضات الطلب/الاستجابة، وتوجيهات الترحيل.
