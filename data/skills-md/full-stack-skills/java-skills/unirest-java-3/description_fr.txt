Bibliothèque client HTTP Unirest-Java 3.x pour Java 8+. À utiliser lors de l'exécution de requêtes HTTP (GET/POST/PUT/DELETE), de la création de clients API REST, de la gestion des réponses JSON, des téléchargements/téléchargements de fichiers, des requêtes asynchrones, de la simulation d'appels HTTP à des fins de test, de la configuration de proxys ou de la mise en cache des réponses. Couvre Unirest 3.x (basé sur Apache HttpClient, GSON par défaut inclus, package kong.unirest) avec mappage d'objets, intercepteurs de requête/réponse et conseils de migration.
