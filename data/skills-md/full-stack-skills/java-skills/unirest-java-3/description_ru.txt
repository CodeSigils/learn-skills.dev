HTTP-клиентская библиотека Unirest-Java 3.x для Java 8+. Используйте при выполнении HTTP-запросов (GET/POST/PUT/DELETE), создании клиентов REST API, обработке ответов JSON, загрузке/загрузке файлов, асинхронных запросах, имитации HTTP-вызовов для тестирования, настройке прокси-серверов или кэшировании ответов. Охватывает Unirest 3.x (на основе Apache HttpClient, включен GSON по умолчанию, пакет kong.unirest) с сопоставлением объектов, перехватчиками запросов/ответов и руководством по миграции.
