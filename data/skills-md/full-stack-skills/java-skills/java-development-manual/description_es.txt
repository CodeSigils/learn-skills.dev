Colección de especificaciones del manual de desarrollo de Java, basada en el Manual de desarrollo de Java de Alibaba (edición Songshan).  
Cubre siete dimensiones principales: especificaciones de programación, registro de excepciones, pruebas unitarias, especificaciones de seguridad, base de datos MySQL, estructura del proyecto, especificaciones de diseño.  
Cuando los usuarios necesiten: (1) escribir o revisar código Java, (2) verificar convenciones de nomenclatura/código, (3) manejar excepciones y registros, (4) escribir pruebas unitarias, (5) codificación segura, (6) diseño de bases de datos, (7) diseño de arquitectura de proyectos, utilice esta habilidad.  
Palabras desencadenantes: especificación de Java, especificación de Alibaba, convención de código, manual de desarrollo, especificación de programación, manejo de excepciones, pruebas unitarias, seguridad, MySQL, estructura del proyecto, patrones de diseño.
