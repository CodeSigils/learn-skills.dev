Collection de spécifications du manuel de développement Java, basée sur le manuel de développement Java d'Alibaba (édition Songshan).  
Il couvre sept dimensions principales : les spécifications de programmation, la journalisation des exceptions, les tests unitaires, les spécifications de sécurité, la base de données MySQL, la structure du projet et les spécifications de conception.  
Lorsque les utilisateurs doivent (1) écrire ou réviser du code Java, (2) vérifier les conventions de dénomination/code, (3) gérer les exceptions et les journaux, (4) écrire des tests unitaires, (5) pratiquer le codage sécurisé, (6) concevoir des bases de données ou (7) concevoir l'architecture d'un projet, ils doivent utiliser cette compétence.  
Mots déclencheurs : spécification Java, spécification Alibaba, conventions de code, manuel de développement, spécification de programmation, gestion des exceptions, tests unitaires, sécurité, MySQL, structure de projet, modèles de conception.
