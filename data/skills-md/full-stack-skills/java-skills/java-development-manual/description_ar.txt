مجموعة مواصفات دليل تطوير Java، استنادًا إلى دليل تطوير Java الخاص بـ Alibaba (إصدار Songshan).  
يغطي سبعة أبعاد رئيسية: مواصفات البرمجة، تسجيل الاستثناءات، اختبار الوحدة، مواصفات الأمان، قاعدة بيانات MySQL، هيكل المشروع، مواصفات التصميم.  
عندما يحتاج المستخدمون إلى: (1) كتابة كود Java أو مراجعته، (2) التحقق من اصطلاحات التسمية/الكود، (3) التعامل مع الاستثناءات والسجلات، (4) كتابة اختبارات الوحدة، (5) الترميز الآمن، (6) تصميم قاعدة البيانات، (7) تصميم بنية المشروع، استخدم هذه المهارة.  
كلمات التشغيل: مواصفات Java، مواصفات Alibaba، اتفاقية التعليمات البرمجية، دليل التطوير، مواصفات البرمجة، معالجة الاستثناءات، اختبار الوحدة، الأمان، MySQL، هيكل المشروع، أنماط التصميم.
