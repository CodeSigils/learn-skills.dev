Коллекция спецификаций руководств по разработке Java, основанная на Руководстве по разработке Java компании Alibaba (издание Songshan).  
Охватывает семь основных аспектов: спецификации программирования, ведение журнала исключений, модульное тестирование, спецификации безопасности, база данных MySQL, структура проекта, спецификации дизайна.  
Когда пользователям нужно: (1) написать или просмотреть код Java, (2) проверить соглашения об именовании/коде, (3) обрабатывать исключения и журналы, (4) написать модульные тесты, (5) безопасное кодирование, (6) проектировать базу данных, (7) проектировать архитектуру проекта, используйте этот навык.  
Триггерные слова: спецификация Java, спецификация Alibaba, соглашение о коде, руководство по разработке, спецификация программирования, обработка исключений, модульное тестирование, безопасность, MySQL, структура проекта, шаблоны проектирования.
