Основные возможности облегченной платформы аутентификации разрешений Java Sa-Token. Охватывает аутентификацию входа в систему, аутентификацию разрешений/ролей, авторизацию на основе аннотаций, авторизацию перехвата маршрута, обработку сеансов, исключение пользователей из сети, стратегии истечения срока действия токена, конфигурацию платформы, стиль токена и префикс отправки, разделение передней и задней частей, режим «запомнить меня», взаимоисключающий вход в систему на одном и том же терминале и обработку сценариев NotLoginException.

StpUtil — это основной служебный класс фасада, предоставляющий полный набор API-интерфейсов аутентификации, таких как вход в систему, checkLogin, выход из системы, isLogin, getLoginId, getTokenValue и т. д.

Используйте его, когда в веб-проекте Java необходимо интегрировать аутентификацию разрешений, выполнить проверку входа/разрешений с помощью StpUtil и настроить перехватчики маршрутов или авторизацию на основе аннотаций.

Он не требует дополнительных функций, таких как вторичная аутентификация, запрет, несколько учетных записей, единый вход, OAuth2, микросервисы, безопасность API, JWT, Redis и т. д.; пожалуйста, используйте соответствующие специализированные навыки.
