Sa-Token 경량 Java 권한 인증 프레임워크 핵심 기능. 로그인 인증, 권한/역할 인증, 주석 기반 권한 부여, 경로 차단 권한 부여, 세션 처리, 사용자 오프라인 추방, 토큰 만료 전략, 프레임워크 구성, 토큰 스타일 및 제출 접두사, 전면-후면 분리, "기억하기" 모드, 동일 장치 상호 배타적 로그인 및 NotLoginException 시나리오 값 처리를 다룹니다.  
StpUtil은 로그인, checkLogin, 로그아웃, isLogin, getLoginId, getTokenValue 등과 같은 전체 인증 API 세트를 제공하는 핵심 Façade 유틸리티 클래스입니다.  
사용자가 권한 인증을 Java 웹 프로젝트에 통합해야 할 때 이를 사용하고, 로그인/권한 확인을 위해 StpUtil을 사용하고, 경로 인터셉터 또는 주석 기반 권한을 구성해야 합니다.  
보조 인증, 금지, 다중 계정, SSO, OAuth2, 마이크로서비스, API 보안, JWT, Redis 등과 같은 고급 기능은 포함되지 않습니다. 해당 전문 기술을 사용하십시오.
