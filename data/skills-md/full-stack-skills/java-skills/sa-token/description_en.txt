Sa-Token lightweight Java permission authentication framework core capabilities. Covers login authentication, permission/role authentication, annotation-based authorization, route interception authorization, Session handling, kicking users offline, token expiration strategies, framework configuration, token style and submission prefix, front‑back separation, “remember me” mode, mutually exclusive login on the same terminal, and NotLoginException scenario handling.

StpUtil is the core façade utility class, providing the full set of authentication APIs such as login, checkLogin, logout, isLogin, getLoginId, getTokenValue, etc.

Use it when a Java Web project needs to integrate permission authentication, perform login/permission checks with StpUtil, and configure route interceptors or annotation-based authorization.

It does not involve advanced features such as secondary authentication, banning, multiple accounts, SSO, OAuth2, microservices, API security, JWT, Redis, etc.; please use the corresponding specialized skills.
