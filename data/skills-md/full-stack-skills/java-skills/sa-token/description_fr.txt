Sa-Token est une compétence de base du cadre d'authentification des autorisations Java léger. It covers login authentication, permission/role authentication, annotation-based authorization, route interception authorization, Session handling, kicking users offline, Token expiration strategies, framework configuration, Token style and submission prefixes, front‑end and back‑end separation, "remember me" mode, mutual exclusion login on the same client, and handling of NotLoginException scenario values.  
StpUtil is the core facade utility class, providing the full set of authentication APIs such as login, checkLogin, logout, isLogin, getLoginId, getTokenValue, etc.  
Use it when a Java web project needs to integrate permission authentication, perform login/permission checks with StpUtil, and configure route interceptors or annotation-based authorization.  
It does not involve advanced features such as secondary authentication, banning, multiple accounts, SSO, OAuth2, microservices, API security, JWT, Redis, etc.; pour ceux-là, utilisez les compétences spécialisées correspondantes.
