القدرات الأساسية لإطار مصادقة إذن Java خفيف الوزن من Sa-Token. يغطي مصادقة تسجيل الدخول، ومصادقة الأذونات/الأدوار، والتفويض المستند إلى التعليقات التوضيحية، وتفويض اعتراض المسار، ومعالجة الجلسة، وطرد المستخدمين دون الاتصال بالإنترنت، واستراتيجيات انتهاء صلاحية الرمز المميز، وتكوين الإطار، ونمط الرمز المميز وبادئة الإرسال، والفصل الأمامي والخلفي، ووضع "تذكرني"، وتسجيل الدخول الحصري المتبادل على نفس الجهاز الطرفي، ومعالجة سيناريو NotLoginException.

StpUtil هي فئة الأدوات المساعدة للواجهة الأساسية، حيث توفر مجموعة كاملة من واجهات برمجة تطبيقات المصادقة مثل تسجيل الدخول، وcheckLogin، وتسجيل الخروج، وisLogin، وgetLoginId، وgetTokenValue، وما إلى ذلك.

استخدمه عندما يحتاج مشروع Java Web إلى دمج مصادقة الأذونات، وإجراء عمليات التحقق من تسجيل الدخول/الأذونات باستخدام StpUtil، وتكوين اعتراضات المسار أو التفويض المستند إلى التعليقات التوضيحية.

ولا يتضمن ميزات متقدمة مثل المصادقة الثانوية، والحظر، والحسابات المتعددة، وSSO، وOAuth2، والخدمات الصغيرة، وأمن API، وJWT، وRedis، وما إلى ذلك؛ يرجى استخدام المهارات المتخصصة المقابلة.
