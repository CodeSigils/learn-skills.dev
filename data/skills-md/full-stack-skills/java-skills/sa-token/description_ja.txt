Sa-Token の軽量 Java 権限認証フレームワークのコア機能。ログイン認証、権限/ロール認証、アノテーションベースの認可、ルートインターセプト認可、セッション処理、ユーザーのオフライン化、トークン有効期限戦略、フレームワーク設定、トークンスタイルと送信プレフィックス、前後分離、「remember me」モード、同じ端末での相互排他ログイン、NotLoginException シナリオ処理をカバーします。

StpUtil はコア ファサード ユーティリティ クラスであり、login、checkLogin、logout、isLogin、getLoginId、getTokenValue などの認証 API の完全なセットを提供します。

Java Web プロジェクトで権限認証を統合し、StpUtil でログイン/権限チェックを実行し、ルート インターセプタまたはアノテーション ベースの認証を構成する必要がある場合に使用します。

二次認証、禁止、複数アカウント、SSO、OAuth2、マイクロサービス、API セキュリティ、JWT、Redis などの高度な機能は含まれません。対応する専門スキルをご活用ください。
