Funktionen der Sa-Token-Integrationserweiterung. Deckt die JWT-Integration (Vergleichstabelle der drei Modi: Einfach, Mixin, Zustandslos), Redis-Persistenz (JDK-Serialisierung/JSON-Serialisierung), Alone-Redis-unabhängiges Redis (Authentifizierungscache und Business-Cache-Isolierung), AOP-Annotationsautorisierung (in der Serviceschicht verwendete Annotationen), SpEL-Ausdrucksannotation (@SaCheckEL), Quick-Login (Null-Code-Anmeldeseite) und JSON-Serialisierungserweiterungen ab (Jackson/Fastjson/Fastjson2/Snack3), Template-Engine-Integration (Thymeleaf/Freemarker-Tag-Dialekte), RPC-Integration (Dubbo/Dubbo3/gRPC-Kontextweitergabe). Verwenden Sie diese Option, wenn Sie JWT für die zustandslose Authentifizierung integrieren, verteilte Redis-Sitzungen konfigurieren, Caches isolieren, annotationsbasierte Autorisierung in der Serviceschicht durchführen und schnell eine Anmeldeseite erstellen müssen. Für die einfache Anmeldeauthentifizierung verwenden Sie bitte zunächst die Sa-Token-Funktion.
