Возможности расширения интеграции Sa-Token. Он охватывает интеграцию JWT (таблица сравнения режимов Simple, Mixin и Stateless), сохранение Redis (сериализация JDK/сериализация JSON), независимый Redis от Alone-Redis (отделение кэша аутентификации от бизнес-кеша), авторизацию аннотаций AOP (с использованием аннотаций на уровне службы), аннотацию выражений SpEL (@SaCheckEL), быстрый вход (страница входа с нулевым кодом), расширения сериализации JSON. (Jackson/Fastjson/Fastjson2/Snack3), интеграция механизма шаблонов (диалекты тегов Thymeleaf/Freemarker) и интеграция RPC (распространение контекста Dubbo/Dubbo3/gRPC). Используйте его, когда вам нужно интегрировать JWT для аутентификации без отслеживания состояния, настроить распределенные сеансы Redis, изолировать кеши, применить авторизацию на основе аннотаций на уровне службы или быстро настроить страницу входа. Для базовой аутентификации при входе сначала используйте функцию sa-token.
