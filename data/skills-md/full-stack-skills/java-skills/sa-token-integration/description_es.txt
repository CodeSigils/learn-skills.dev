Capacidades de extensión de integración de Sa-Token. Cubre la integración JWT (tabla de comparación de los modos Simple, Mixin y Stateless), persistencia de Redis (serialización JDK/serialización JSON), Redis independiente de Alone-Redis (separación de la caché de autenticación de la caché empresarial), autorización de anotaciones AOP (usando anotaciones en la capa de servicio), anotación de expresión SpEL (@SaCheckEL), Quick-Login (página de inicio de sesión con código cero), extensiones de serialización JSON (Jackson/Fastjson/Fastjson2/Snack3), integración del motor de plantillas (dialectos de etiquetas Thymeleaf/Freemarker) e integración RPC (propagación de contexto Dubbo/Dubbo3/gRPC). Úselo cuando necesite integrar JWT para la autenticación sin estado, configurar sesiones distribuidas de Redis, aislar cachés, aplicar autorización basada en anotaciones en la capa de servicio o configurar rápidamente una página de inicio de sesión. Para la autenticación de inicio de sesión básica, primero utilice la capacidad sa-token.
