Sa-Token 統合拡張機能。 JWT 統合 (Simple、Mixin、および Stateless モードの比較表)、Redis 永続性 (JDK シリアル化/JSON シリアル化)、Alone-Redis に依存しない Redis (ビジネス キャッシュから認証キャッシュを分離)、AOP アノテーション承認 (サービス層のアノテーションを使用)、SpEL 式アノテーション (@SaCheckEL)、Quick-Login (ゼロコード ログイン ページ)、JSON シリアル化拡張機能について説明します。 (Jackson/Fastjson/Fastjson2/Snack3)、テンプレート エンジンの統合 (Thymeleaf/Freemarker タグの方言)、および RPC の統合 (Dubbo/Dubbo3/gRPC コンテキストの伝播)。ステートレス認証のための JWT の統合、Redis 分散セッションの構成、キャッシュの分離、サービス層でのアノテーションベースの認可の適用、またはログイン ページの迅速なセットアップが必要な場合に使用します。基本的なログイン認証の場合は、最初に sa-token 機能を使用してください。
