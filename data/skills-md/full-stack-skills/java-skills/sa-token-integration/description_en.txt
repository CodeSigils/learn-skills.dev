Sa-Token integration extension capabilities. It covers JWT integration (comparison table of Simple, Mixin, and Stateless modes), Redis persistence (JDK serialization/JSON serialization), Alone-Redis independent Redis (separating authentication cache from business cache), AOP annotation authorization (using annotations in the Service layer), SpEL expression annotation (@SaCheckEL), Quick-Login (zero‑code login page), JSON serialization extensions (Jackson/Fastjson/Fastjson2/Snack3), template engine integration (Thymeleaf/Freemarker tag dialects), and RPC integration (Dubbo/Dubbo3/gRPC context propagation). Use it when you need to integrate JWT for stateless authentication, configure Redis distributed sessions, isolate caches, apply annotation‑based authorization in the Service layer, or quickly set up a login page. For basic login authentication, please first use the sa-token capability.
