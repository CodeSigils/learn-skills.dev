قدرات توسيع تكامل Sa-Token. وهو يغطي تكامل JWT (جدول مقارنة للأوضاع البسيطة، وMixin، وعديمة الحالة)، واستمرارية Redis (تسلسل JDK/تسلسل JSON)، وRedis المستقل Alone-Redis (فصل ذاكرة التخزين المؤقت للمصادقة عن ذاكرة التخزين المؤقت للأعمال)، وتفويض التعليق التوضيحي AOP (باستخدام التعليقات التوضيحية في طبقة الخدمة)، والتعليق التوضيحي لتعبير SpEL (@SaCheckEL)، وتسجيل الدخول السريع (صفحة تسجيل الدخول ذات الرمز الصفري)، وملحقات تسلسل JSON. (Jackson/Fastjson/Fastjson2/Snack3)، وتكامل محرك القالب (لهجات علامات Thymeleaf/Freemarker)، وتكامل RPC (انتشار سياق Dubbo/Dubbo3/gRPC). استخدمه عندما تحتاج إلى دمج JWT للمصادقة عديمة الحالة، أو تكوين جلسات Redis الموزعة، أو عزل ذاكرة التخزين المؤقت، أو تطبيق الترخيص المستند إلى التعليقات التوضيحية في طبقة الخدمة، أو إعداد صفحة تسجيل الدخول بسرعة. لمصادقة تسجيل الدخول الأساسية، يرجى أولاً استخدام إمكانية sa-token.
