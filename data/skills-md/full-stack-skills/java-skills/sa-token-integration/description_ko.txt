Sa-Token 통합 확장 기능. JWT 통합(Simple, Mixin 및 Stateless 모드 비교표), Redis 지속성(JDK 직렬화/JSON 직렬화), Alone-Redis 독립 Redis(비즈니스 캐시에서 인증 캐시 분리), AOP 주석 기반 인증(서비스 계층에서 사용되는 주석), SpEL 표현식 주석(@SaCheckEL), Quick-Login 빠른 로그인(제로 코드 로그인 페이지), JSON 직렬화 확장(Jackson, Fastjson, Fastjson2, Snack3), 템플릿 엔진 통합(Thymeleaf, Freemarker 태그 방언) 및 RPC 통합(Dubbo, Dubbo3, gRPC 컨텍스트 전파). 상태 비저장 인증을 위해 JWT를 통합하고, Redis 분산 세션을 구성하고, 캐시를 격리하고, 서비스 계층 주석 인증을 적용하거나, 로그인 페이지를 빠르게 구축해야 하는 경우에 사용하세요. 기본 로그인 인증의 경우 먼저 Sa-Token 기능을 사용하십시오.
