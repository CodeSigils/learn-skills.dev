Funzionalità di sicurezza avanzate Sa-Token. Copre l'autenticazione secondaria (verifica a due fattori di autenticazione sicura), ban dell'account (ban globale / ban di categoria / ban a livelli), impersonificazione e cambio di identità, autenticazione multi-account (StpUserUtil / StpKit), ascoltatori globali (eventi di login / logout / kick / ban / rinnovo token), filtri globali (SaServletFilter / SaReactorFilter), crittografia password (MD5 / SHA1 / SHA256 / AES / RSA / BCrypt / TOTP), query di sessione (elenco terminali/ricerca token globale), autenticazione HTTP Basic/Digest, firewall (whitelist IP/blacklist/limitazione della velocità), annotazioni di autorizzazione personalizzate, autorizzazione di routing dinamico, correzione dell'URI proxy inverso, contesto fittizio asincrono, progettazione di valori-chiave Redis per l'architettura dei dati.  

Da utilizzare quando gli utenti devono implementare la verifica secondaria per operazioni sensibili, divieti gerarchici di account, rappresentazione di utenti, sistemi di account multipli (separazione utente/amministratore), ascolto di eventi globali o strumenti di crittografia delle password.  

Per l'autenticazione di accesso di base, utilizzare la funzionalità sa‑token.
