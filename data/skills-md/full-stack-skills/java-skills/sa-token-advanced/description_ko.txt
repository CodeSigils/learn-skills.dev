Sa-Token 고급 보안 기능 세트. 2차 인증(안전한 인증 2차 확인), 계정 금지(전체 금지/범주화된 금지/계층형 금지), 가장 및 신원 전환, 다중 계정 인증(StpUserUtil/StpKit), 전역 리스너(로그인/로그아웃/킥/금지/토큰 갱신 이벤트), 전역 필터(SaServletFilter/SaReactorFilter), 비밀번호 암호화(MD5/SHA1/SHA256/AES/RSA/ BCrypt/TOTP), 세션 쿼리(터미널 목록/글로벌 토큰 검색), HTTP 기본/다이제스트 인증, 방화벽(IP 블랙리스트/화이트리스트/속도 제한), 사용자 정의 권한 부여 주석, 동적 라우팅 권한 부여, 역방향 프록시 URI 수정, 비동기 모의 컨텍스트 및 데이터 아키텍처를 위한 Redis 키 값 설계.  

민감한 작업, 계층적 계정 금지, 사용자 가장, 다중 계정 시스템(사용자/관리자 분리), 전역 이벤트 수신 또는 비밀번호 암호화 도구에 대한 2차 검증을 구현해야 할 때 사용하세요.  

기본 로그인 인증은 sa-token 기능을 이용해 주세요.
