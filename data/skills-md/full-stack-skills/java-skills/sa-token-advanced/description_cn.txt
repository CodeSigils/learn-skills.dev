Sa-Token 先进的安全特性能力。涵盖二次认证（安全认证双因素验证）、账户封禁（全面封禁/类别封禁/分级封禁）、模拟与身份切换、多账户认证（StpUserUtil / StpKit）、全局监听（登录/注销/踢出/封禁/续订事件）、全局过滤器（SaServletFilter / SaReactorFilter）、密码加密（MD5 / SHA1 / SHA256 / AES / RSA / BCrypt / TOTP）、会话查询（终端列表/全局令牌搜索）、HTTP Basic/Digest 身份验证、防火墙（IP 白名单/黑名单/速率限制）、自定义授权注释、动态路由授权、反向代理 URI 修复、异步模拟上下文、数据架构的 Redis 键值设计。当用户需要对敏感操作进行二次验证、分级账户封禁、用户模拟、多账户系统（用户/管理员分离）、全局事件监听、密码加密工具时使用。对于基本登录身份验证，请使用 sa‑token 功能。
