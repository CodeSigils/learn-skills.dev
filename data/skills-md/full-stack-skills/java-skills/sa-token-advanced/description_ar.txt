قدرات ميزات الأمان المتقدمة لـ Sa-Token. يغطي المصادقة الثانوية (المصادقة الآمنة والتحقق الثنائي)، وحظر الحساب (الحظر الكامل / حظر الفئة / الحظر المتدرج)، وانتحال الشخصية وتبديل الهوية، والمصادقة متعددة الحسابات (StpUserUtil / StpKit)، والمستمعين العالميين (تسجيل الدخول / تسجيل الخروج / الركلة / الحظر / أحداث التجديد)، والمرشحات العالمية (SaServletFilter / SaReactorFilter)، وتشفير كلمة المرور (MD5 / SHA1 / SHA256 / AES / RSA / BCrypt / TOTP)، واستعلامات الجلسة (قائمة الأجهزة الطرفية / البحث عن الرموز المميزة العالمية)، ومصادقة HTTP الأساسية/الملخص، وجدار الحماية (قائمة IP البيضاء/القائمة السوداء/تحديد المعدل)، وتعليقات الترخيص المخصصة، وتفويض التوجيه الديناميكي، وإصلاح URI للوكيل العكسي، وسياق وهمي غير متزامن، وتصميم قيمة مفتاح Redis لهندسة البيانات. يُستخدم عندما يحتاج المستخدمون إلى تنفيذ التحقق الثانوي للعمليات الحساسة، وحظر الحسابات الهرمية، وانتحال هوية المستخدم، وأنظمة الحسابات المتعددة (فصل المستخدم/المسؤول)، والاستماع إلى الأحداث العالمية، وأدوات تشفير كلمة المرور. لمصادقة تسجيل الدخول الأساسية، يرجى استخدام إمكانية sa‑token.
