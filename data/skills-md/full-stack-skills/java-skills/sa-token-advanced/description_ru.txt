Возможности расширенных функций безопасности Sa-Token. Охватывает вторичную аутентификацию (двухфакторную проверку с безопасной аутентификацией), блокировку учетной записи (полный бан / блокировку категории / многоуровневый бан), олицетворение и переключение личности, аутентификацию с несколькими учетными записями (StpUserUtil / StpKit), глобальные прослушиватели (события входа в систему / выхода из системы / кик / бан / продление), глобальные фильтры (SaServletFilter / SaReactorFilter), шифрование пароля (MD5 / SHA1 / SHA256 / AES / RSA / BCrypt). / TOTP), запросы сеанса (список терминалов/поиск глобальных токенов), базовая/дайджест-аутентификация HTTP, брандмауэр (белый список IP-адресов/черный список/ограничение скорости), настраиваемые аннотации авторизации, авторизация динамической маршрутизации, восстановление URI обратного прокси-сервера, асинхронный макет контекста, дизайн значений ключей Redis для архитектуры данных. Используйте, когда пользователям необходимо реализовать вторичную проверку конфиденциальных операций, иерархическую блокировку учетных записей, выдачу себя за пользователя, системы с несколькими учетными записями (разделение пользователя и администратора), глобальное прослушивание событий, инструменты шифрования паролей. Для базовой аутентификации при входе используйте функцию sa‑token.
