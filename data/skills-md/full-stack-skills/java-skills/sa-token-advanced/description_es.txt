Capacidades avanzadas de funciones de seguridad de Sa-Token. Cubre autenticación secundaria (verificación de dos factores de autenticación segura), prohibición de cuenta (prohibición completa/prohibición de categoría/prohibición escalonada), suplantación de identidad y cambio de identidad, autenticación de múltiples cuentas (StpUserUtil/StpKit), oyentes globales (inicio de sesión/cierre de sesión/expulsión/prohibición/eventos de renovación), filtros globales (SaServletFilter/SaReactorFilter), cifrado de contraseña (MD5/SHA1/SHA256/AES/RSA/BCrypt/TOTP), consultas de sesión (terminal lista/búsqueda de token global), autenticación HTTP básica/digest, firewall (lista blanca/lista negra/limitación de velocidad de IP), anotaciones de autorización personalizadas, autorización de enrutamiento dinámico, reparación de URI de proxy inverso, contexto simulado asíncrono, diseño de valor clave de Redis para arquitectura de datos. Úselo cuando los usuarios necesiten implementar una verificación secundaria para operaciones confidenciales, prohibiciones jerárquicas de cuentas, suplantación de usuarios, sistemas de cuentas múltiples (separación usuario/administrador), escucha global de eventos, herramientas de cifrado de contraseñas. Para la autenticación de inicio de sesión básica, utilice la capacidad sa-token.
