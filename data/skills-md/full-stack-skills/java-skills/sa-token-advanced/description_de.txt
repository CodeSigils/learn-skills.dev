Erweiterte Sicherheitsfunktionen von Sa-Token. Umfasst sekundäre Authentifizierung (sichere zweistufige Verifizierung), Kontosperrung (vollständige Sperre / Kategoriesperre / abgestufte Sperre), Identitätswechsel und Identitätswechsel, Authentifizierung mehrerer Konten (StpUserUtil / StpKit), globale Listener (Anmeldung / Abmeldung / Kick / Sperre / Erneuerungsereignisse), globale Filter (SaServletFilter / SaReactorFilter), Kennwortverschlüsselung (MD5 / SHA1 / SHA256 / AES / RSA / BCrypt / TOTP), Sitzungsabfragen (Geräteliste / globales Token). Suche), HTTP Basic/Digest-Authentifizierung, Firewall (IP-Whitelist/Blacklist/Ratenbegrenzung), benutzerdefinierte Autorisierungsanmerkungen, dynamische Routenautorisierung, Reverse-Proxy-URI-Reparatur, asynchroner Scheinkontext, Datenarchitektur Redis-Schlüsselwertdesign.  

Verwenden Sie dies, wenn Benutzer eine sekundäre Überprüfung für vertrauliche Vorgänge, abgestufte Kontosperrungen, Aktionen zur Nachahmung von Benutzernamen, Systeme mit mehreren Konten (Benutzer-/Administrator-Trennung), globale Ereignisüberwachung und Passwortverschlüsselungstools implementieren müssen.  

Für die einfache Anmeldeauthentifizierung verwenden Sie bitte die sa-token-Funktion.
