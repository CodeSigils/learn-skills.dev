Ensemble de fonctionnalités de sécurité avancées Sa-Token. Couvre l'authentification secondaire (vérification sécurisée en deux étapes), le blocage de compte (blocage complet / bloc de catégorie / bloc hiérarchique), l'usurpation d'identité et le changement d'identité, l'authentification multi-comptes (StpUserUtil / StpKit), les écouteurs globaux (événements de connexion / déconnexion / kick / blocage / renouvellement), les filtres globaux (SaServletFilter / SaReactorFilter), le cryptage des mots de passe (MD5 / SHA1 / SHA256 / AES / RSA / BCrypt / TOTP), la session requêtes (liste de terminaux/recherche globale de jetons), authentification HTTP Basic/Digest, pare-feu (liste blanche/liste noire IP/limitation de débit), annotations d'autorisation personnalisées, autorisation de route dynamique, réécriture d'URI de proxy inverse, contexte fictif asynchrone, conception de valeurs-clés Redis pour l'architecture de données.  
Utilisez-le lorsque les utilisateurs doivent mettre en œuvre une vérification secondaire pour les opérations sensibles, le blocage de comptes hiérarchiques, l'usurpation d'identité d'utilisateur, les systèmes de comptes multiples (séparation utilisateur/administrateur), l'écoute d'événements globaux ou les outils de cryptage de mot de passe.  
Pour l’authentification de connexion de base, utilisez la compétence sa‑token.
