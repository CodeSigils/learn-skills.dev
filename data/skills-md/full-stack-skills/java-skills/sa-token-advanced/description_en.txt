Sa-Token advanced security feature capabilities. Covers secondary authentication (safe-auth two‑factor verification), account banning (full ban / category ban / tiered ban), impersonation and identity switching, multi‑account authentication (StpUserUtil / StpKit), global listeners (login / logout / kick / ban / renewal events), global filters (SaServletFilter / SaReactorFilter), password encryption (MD5 / SHA1 / SHA256 / AES / RSA / BCrypt / TOTP), session queries (terminal list / global token search), HTTP Basic/Digest authentication, firewall (IP whitelist/blacklist / rate limiting), custom authorization annotations, dynamic routing authorization, reverse‑proxy URI repair, asynchronous mock context, Redis key‑value design for data architecture. Use when users need to implement secondary verification for sensitive operations, hierarchical account bans, user impersonation, multiple account systems (User/Admin separation), global event listening, password encryption tools. For basic login authentication, please use the sa‑token capability.
