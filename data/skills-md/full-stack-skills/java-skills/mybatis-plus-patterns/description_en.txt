MyBatis-Plus enhances ORM capabilities. It covers selection between LambdaQueryWrapper and QueryWrapper (always use Lambda), configuration of the pagination plugin (PaginationInnerInterceptor), optimistic locking (@Version + OptimisticLockerInnerInterceptor), logical deletion (@TableLogic global/local configuration), automatic filling (@TableField fill + MetaObjectHandler), choice between ActiveRecord and Mapper modes, protection against full‑table updates (BlockAttackInnerInterceptor), and generic PageQuery extraction. It is used when users perform database operations with MyBatis-Plus, configure pagination and optimistic locking, and choose query methods. It complements MyBatis skills: MyBatis focuses on XML/ResultMap/SQL writing, while MyBatis-Plus focuses on enhanced functionality.
