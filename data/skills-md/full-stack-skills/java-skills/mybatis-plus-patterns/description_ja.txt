MyBatis-Plus は ORM 機能を強化します。 LambdaQueryWrapper と QueryWrapper の選択 (常に Lambda を使用)、ページネーション プラグインの構成 (PaginationInnerInterceptor)、楽観的ロック (@Version + OptimisticLockerInnerInterceptor)、論理削除 (@TableLogic グローバル/ローカル構成)、自動入力 (@TableField フィル + MetaObjectHandler)、ActiveRecord モードと Mapper モードの選択、に対する保護について説明します。フルテーブル更新 (Block AttackInnerInterceptor)、および汎用 PageQuery 抽出。これは、ユーザーが MyBatis-Plus でデータベース操作を実行し、ページネーションと楽観的ロックを構成し、クエリ方法を選択するときに使用されます。これは MyBatis のスキルを補完します。MyBatis は XML/ResultMap/SQL の作成に重点を置いているのに対し、MyBatis-Plus は拡張機能に重点を置いています。
