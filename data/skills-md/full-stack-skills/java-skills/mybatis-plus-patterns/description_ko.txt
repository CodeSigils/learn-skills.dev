MyBatis-Plus는 ORM 기능을 강화했습니다. LambdaQueryWrapper와 QueryWrapper(항상 Lambda) 사이의 선택, 페이지 매김 플러그인 구성(PaginationInnerInterceptor), 낙관적 잠금(@Version + OptimisticLockerInnerInterceptor), 논리적 삭제(@TableLogic 전역/로컬 구성), 자동 채우기(@TableField 채우기 + MetaObjectHandler), ActiveRecord와 Mapper 모드 간 선택, 전체 테이블 업데이트에 대한 보호를 다룹니다. (BlockAttackInnerInterceptor) 및 일반 PageQuery 추출. 사용자가 MyBatis-Plus로 데이터베이스 작업을 수행하고 페이지 매김 및 낙관적 잠금을 구성하고 쿼리 방법을 선택할 때 사용됩니다. MyBatis 기술 보완: MyBatis는 XML/ResultMap/SQL 작성에 중점을 두는 반면 MyBatis-Plus는 향상된 기능에 중점을 둡니다.
