Funzionalità del server Sa-Token OAuth2.0. Copre quattro tipi di concessione: codice di autorizzazione, implicita, password e credenziali del cliente. Configurazione completa del server OAuth2, caricatore dati SaOAuth2DataLoader, autorizzazioni di ambito personalizzate e gerarchiche, protocollo OIDC, OpenId/UnionId, tipo di concessione personalizzato, pagina di autorizzazione di accesso personalizzata, convalida dell'annotazione del token di accesso, interoperabilità con le sessioni di accesso, controllo del livello di ambito, routing API personalizzato. Da utilizzare quando è necessario creare un server di autenticazione OAuth2.0, sviluppare una piattaforma aperta o implementare l'autorizzazione di applicazioni di terze parti. Per l'autenticazione di accesso di base, utilizzare prima la funzionalità sa-token.
