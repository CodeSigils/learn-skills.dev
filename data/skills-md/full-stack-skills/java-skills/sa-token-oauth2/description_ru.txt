Возможности сервера Sa-Token OAuth2.0. Охватывает четыре режима авторизации: код авторизации, неявный, пароль и учетные данные клиента. Полная настройка сервера OAuth2, загрузчик данных SaOAuth2DataLoader, настраиваемые и иерархические разрешения области, протокол OIDC, OpenId/UnionId, настраиваемый тип гранта, настраиваемая страница авторизации входа, проверка аннотаций токена доступа, совместимость с сеансами входа в систему, контроль уровня области, настраиваемая маршрутизация API. Используйте, когда пользователю необходимо создать сервер аутентификации OAuth2.0, разработать открытую платформу или реализовать авторизацию сторонних приложений. Для базовой аутентификации при входе сначала используйте функцию sa-token.
