Sa-Token OAuth2.0 서버 기능. 인증 코드, 암시적, 비밀번호 및 클라이언트 자격 증명의 네 가지 부여 유형을 다룹니다. 완전한 OAuth2-Server 설정, SaOAuth2DataLoader 데이터 로더, 사용자 정의 및 계층적 범위 권한, OIDC 프로토콜, OpenId/UnionId, 사용자 정의 grant_type, 사용자 정의 로그인 인증 페이지, 주석 기반 액세스 토큰 검증, 로그인 세션과의 상호 운용성, 범위 수준 제어, 사용자 정의 API 라우팅. 사용자가 OAuth2.0 인증 서버를 구축하거나 개방형 플랫폼을 개발하거나 타사 애플리케이션 인증을 구현해야 할 때 사용합니다. 기본 로그인 인증을 위해서는 먼저 sa-token 기능을 사용해 주세요.
