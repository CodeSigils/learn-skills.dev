Fonctionnalités du serveur Sa-Token OAuth2.0. Couvre quatre modes d'autorisation : code d'autorisation, implicite, mot de passe et informations d'identification client. Configuration complète d'OAuth2-Server, chargeur de données SaOAuth2DataLoader, autorisations de portée personnalisées et hiérarchiques, protocole OIDC, OpenId/UnionId, type de subvention personnalisé, page d'autorisation de connexion personnalisée, validation du jeton d'accès basée sur les annotations, interopérabilité avec les sessions de connexion, contrôle du niveau de portée, routage API personnalisé. À utiliser lorsque vous devez créer un serveur d'authentification OAuth2.0, développer une plateforme ouverte ou mettre en œuvre une autorisation d'application tierce. Pour une authentification de connexion de base, veuillez d'abord utiliser la fonctionnalité sa-token.
