Sa-Token OAuth2.0 server capabilities. Covers four authorization modes: Authorization Code, Implicit, Password, and Client Credentials. Complete OAuth2-Server setup, SaOAuth2DataLoader data loader, custom and hierarchical Scope permissions, OIDC protocol, OpenId/UnionId, custom grant_type, custom login authorization page, annotation validation of Access-Token, interoperability with login sessions, Scope level control, custom API routing. Use when a user needs to build an OAuth2.0 authentication server, develop an open platform, or implement third‑party application authorization. For basic login authentication, please first use the sa-token capability.
