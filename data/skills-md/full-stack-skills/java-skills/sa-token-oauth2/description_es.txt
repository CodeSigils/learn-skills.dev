Capacidades del servidor Sa-Token OAuth2.0. Cubre cuatro modos de autorización: Código de autorización, Implícito, Contraseña y Credenciales de cliente. Configuración completa de OAuth2-Server, cargador de datos SaOAuth2DataLoader, permisos de alcance personalizados y jerárquicos, protocolo OIDC, OpenId/UnionId, tipo de concesión personalizado, página de autorización de inicio de sesión personalizada, validación de anotaciones de Access-Token, interoperabilidad con sesiones de inicio de sesión, control de nivel de alcance, enrutamiento API personalizado. Úselo cuando un usuario necesita crear un servidor de autenticación OAuth2.0, desarrollar una plataforma abierta o implementar autorización de aplicaciones de terceros. Para la autenticación de inicio de sesión básica, primero utilice la capacidad sa-token.
