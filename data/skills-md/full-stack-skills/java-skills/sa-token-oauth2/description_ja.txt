Sa-Token OAuth2.0 サーバー機能。 4 つの認証モード (認証コード、暗黙的、パスワード、クライアント資格情報) をカバーします。完全な OAuth2 サーバー設定、SaOAuth2DataLoader データローダー、カスタムおよび階層スコープ権限、OIDC プロトコル、OpenId/UnionId、カスタム Grant_type、カスタム ログイン認証ページ、アクセス トークンの注釈検証、ログイン セッションとの相互運用性、スコープ レベル制御、カスタム API ルーティング。ユーザーが OAuth2.0 認証サーバーの構築、オープン プラットフォームの開発、またはサードパーティ アプリケーションの承認を実装する必要がある場合に使用します。基本的なログイン認証の場合は、最初に sa-token 機能を使用してください。
