Sa-Token OAuth2.0-Serverfunktionen. Deckt vier Autorisierungsmodi ab: Autorisierungscode, Implizit, Passwort, Client-Anmeldeinformationen.  
Komplettes OAuth2-Server-Setup, SaOAuth2DataLoader-Datenlader, benutzerdefinierte und hierarchische Scope-Berechtigungen, OIDC-Protokoll, OpenId/UnionId, benutzerdefinierter Grant_Type, benutzerdefinierte Anmeldeautorisierungsseite, Anmerkungsvalidierung von Access-Token, Interoperabilität mit Anmeldesitzungen, Steuerung auf Bereichsebene, benutzerdefiniertes API-Routing.  
Verwenden Sie diese Option, wenn Sie einen OAuth2.0-Authentifizierungsserver einrichten, eine offene Plattform entwickeln oder die Anwendungsautorisierung von Drittanbietern implementieren müssen.  
Für die einfache Anmeldeauthentifizierung nutzen Sie bitte zunächst die sa-token-Funktionen.
