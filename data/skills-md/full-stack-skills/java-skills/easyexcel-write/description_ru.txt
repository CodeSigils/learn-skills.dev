Возможности записи данных Excel на основе Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Охватывает простейшее написание (три подхода), сложные заголовки (многоуровневые), аннотации @ExcelProperty/@ExcelIgnore/@DateTimeFormat/@NumberFormat, выбор столбца includeColumn/excludeColumn, аннотации стиля @ColumnWidth/@ContentRowHeight, пользовательские стили @HeadStyle/@ContentStyle, объединенные ячейки. (@ContentLoopMerge/LoopMergeStrategy), экспорт изображений (File/InputStream/URL/byte[]), гиперссылки/комментарии/формулы/форматированный текст (WriteCellData), динамические заголовки, автоматическая ширина столбца, пользовательские перехватчики (CellWriteHandler/SheetWriteHandler/RowWriteHandler), пакетная запись с разбивкой на страницы, прямая загрузка через Интернет в OutputStream и совместимость с Excel 2003/2007 форматы. Используйте эту возможность, когда вам необходимо программно создать Excel (без предопределенного шаблона) для экспорта структурированных данных, таких как заказы, пользователи, финансы, запасы, отчеты, выписки, формы утверждения и т. д. Она не подходит для заполнения на основе предопределенного шаблона (используйте easyexcel‑fill) и не подходит для чтения Excel (используйте easyexcel‑read).
