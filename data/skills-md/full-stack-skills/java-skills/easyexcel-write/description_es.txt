Capacidades de escritura de datos de Excel basadas en Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Cubre la escritura más simple (tres enfoques), encabezados complejos (varios niveles), anotaciones @ExcelProperty/@ExcelIgnore/@DateTimeFormat/@NumberFormat, selección de columnas includeColumn/excludeColumn, anotaciones de estilo @ColumnWidth/@ContentRowHeight, estilos personalizados @HeadStyle/@ContentStyle, celdas fusionadas (@ContentLoopMerge/LoopMergeStrategy), exportación de imágenes (Archivo/InputStream/URL/byte[]), hipervínculos/comentarios/fórmulas/texto enriquecido (WriteCellData), encabezados dinámicos, ancho de columna automático, interceptores personalizados (CellWriteHandler/SheetWriteHandler/RowWriteHandler), escritura por lotes paginada, descarga web directa a OutputStream y compatibilidad con formatos Excel 2003/2007. Utilice esta capacidad cuando necesite generar Excel mediante programación (sin una plantilla predefinida) para exportar datos estructurados como pedidos, usuarios, finanzas, inventario, informes, extractos, formularios de aprobación, etc. No es adecuado para completar basándose en una plantilla predefinida (use easyexcel-fill) y no es adecuado para leer Excel (use easyexcel-read).
