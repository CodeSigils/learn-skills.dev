Capacité d'écriture de données Excel basée sur Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Couvre l'écriture la plus simple (3 méthodes), les en-têtes complexes (multi‑niveaux), les annotations @ExcelProperty/@ExcelIgnore/@DateTimeFormat/@NumberFormat, la sélection de colonnes includeColumn/excludeColumn, les annotations de style @ColumnWidth/@ContentRowHeight, les styles personnalisés @HeadStyle/@ContentStyle, les cellules fusionnées (@ContentLoopMerge/LoopMergeStrategy), l'exportation d'images. (File/InputStream/URL/byte[]), hyperliens/commentaires/formules/texte enrichi (WriteCellData), en-têtes dynamiques, largeur de colonne automatique, intercepteurs personnalisés (CellWriteHandler/SheetWriteHandler/RowWriteHandler), écriture par lots paginée, téléchargement Web direct vers OutputStream, compatibilité avec les versions 03/07. Utilisez cette fonctionnalité lorsque les utilisateurs doivent générer Excel par programmation (sans modèle prédéfini) pour exporter des données structurées telles que les commandes, les utilisateurs, les finances, les stocks, les rapports, les relevés, les formulaires d'approbation, etc. Ne convient pas au remplissage basé sur un modèle prédéfini (utilisez plutôt easyexcel-fill), ne convient pas à la lecture d'Excel (utilisez plutôt easyexcel-read).
