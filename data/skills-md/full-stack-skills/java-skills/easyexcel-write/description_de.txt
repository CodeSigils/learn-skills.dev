Funktionen zum Schreiben von Excel-Daten basierend auf Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Behandelt das einfachste Schreiben (3 Methoden), komplexe Überschriften (mehrstufig), @ExcelProperty/@ExcelIgnore/@DateTimeFormat/@NumberFormat-Anmerkungen, includeColumn/excludeColumn-Spaltenauswahl, @ColumnWidth/@ContentRowHeight-Stilanmerkungen, benutzerdefinierte @HeadStyle/@ContentStyle-Stile, zusammengeführte Zellen (@ContentLoopMerge/LoopMergeStrategy), Bildexport (File/InputStream/URL/byte[]), Hyperlinks/Kommentare/Formeln/Rich-Text (WriteCellData), dynamische Header, automatische Spaltenbreite, benutzerdefinierte Interceptoren (CellWriteHandler/SheetWriteHandler/RowWriteHandler), paginiertes Batch-Schreiben, direkter Web-Download in OutputStream, Kompatibilität mit 03/07-Versionen. Verwenden Sie diese Fähigkeit, wenn Benutzer Excel programmgesteuert generieren müssen (ohne eine vorgefertigte Vorlage), um strukturierte Daten wie Bestellungen, Benutzer, Finanzen, Inventar, Berichte, Kontoauszüge, Genehmigungsformulare usw. zu exportieren. Sie eignet sich nicht zum Ausfüllen vorgefertigter Vorlagen (verwenden Sie stattdessen easyexcel-fill) und nicht zum Lesen von Excel (verwenden Sie stattdessen easyexcel-read).
