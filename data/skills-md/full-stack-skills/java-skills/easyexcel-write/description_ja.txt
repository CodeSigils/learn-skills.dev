Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3) に基づく Excel データ書き込み機能。最も単純な記述 (3 つのアプローチ)、複雑なヘッダー (マルチレベル)、@ExcelProperty/@ExcelIgnore/@DateTimeFormat/@NumberFormat 注釈、includeColumn/excludeColumn 列の選択、@ColumnWidth/@ContentRowHeight スタイル注釈、@HeadStyle/@ContentStyle カスタム スタイル、結合セル (@ContentLoopMerge/LoopMergeStrategy)、画像エクスポートをカバーします。 (File/InputStream/URL/byte[])、ハイパーリンク/コメント/数式/リッチ テキスト (WriteCellData)、動的ヘッダー、自動列幅、カスタム インターセプター (CellWriteHandler/SheetWriteHandler/RowWriteHandler)、ページ分割されたバッチ書き込み、OutputStream への直接 Web ダウンロード、および Excel 2003/2007 形式との互換性。この機能は、注文、ユーザー、財務、在庫、レポート、明細書、承認フォームなどの構造化データをエクスポートするために Excel を (事前定義されたテンプレートなしで) プログラムで生成する必要がある場合に使用します。この機能は、事前定義されたテンプレートに基づく入力 (easyexcel-fill を使用) には適しておらず、Excel の読み取り (easyexcel-read を使用) には適していません。
