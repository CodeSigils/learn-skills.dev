Funzionalità di scrittura dati Excel basata su Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Copre le scritture più semplici (tre approcci), intestazioni multilivello complesse, annotazioni @ExcelProperty/@ExcelIgnore/@DateTimeFormat/@NumberFormat, selezione di colonne con includeColumn/excludeColumn, annotazioni di stile @ColumnWidth/@ContentRowHeight, stili personalizzati con @HeadStyle/@ContentStyle, unione di celle (@ContentLoopMerge/LoopMergeStrategy), esportazione di immagini (File/InputStream/URL/byte[]), collegamenti ipertestuali/commenti/formule/rich text (WriteCellData), intestazioni dinamiche, larghezza colonna automatica, intercettori personalizzati (CellWriteHandler/SheetWriteHandler/RowWriteHandler), scrittura batch impaginata, download Web diretto su OutputStream e compatibilità con Excel 2003/2007 formati. Utilizzare questa funzionalità quando è necessario generare Excel a livello di codice (senza un modello predefinito) per esportare dati strutturati come ordini, utenti, finanza, inventario, report, estratti conto, moduli di approvazione, ecc. Non è adatta per la compilazione basata su un modello predefinito (utilizzare easyexcel-fill) e non per leggere file Excel (utilizzare easyexcel-read).
