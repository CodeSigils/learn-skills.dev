Excel data writing capabilities based on Alibaba EasyExcel (com.alibaba:easyexcel:4.0.3). Covers the simplest writing (three approaches), complex headers (multi‑level), @ExcelProperty/@ExcelIgnore/@DateTimeFormat/@NumberFormat annotations, includeColumn/excludeColumn column selection, @ColumnWidth/@ContentRowHeight style annotations, @HeadStyle/@ContentStyle custom styles, merged cells (@ContentLoopMerge/LoopMergeStrategy), image export (File/InputStream/URL/byte[]), hyperlinks/comments/formulas/rich text (WriteCellData), dynamic headers, auto column width, custom interceptors (CellWriteHandler/SheetWriteHandler/RowWriteHandler), paginated batch writing, direct web download to OutputStream, and compatibility with Excel 2003/2007 formats. Use this capability when you need to programmatically generate Excel (without a predefined template) to export structured data such as orders, users, finance, inventory, reports, statements, approval forms, etc. It is not suited for filling based on a predefined template (use easyexcel‑fill) and not suited for reading Excel (use easyexcel‑read).
