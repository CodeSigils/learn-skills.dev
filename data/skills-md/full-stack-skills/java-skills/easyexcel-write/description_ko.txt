Alibaba EasyExcel(com.alibaba:easyexcel:4.0.3)을 기반으로 엑셀 데이터 쓰기를 처리하는 스킬입니다. 가장 간단한 쓰기(세 가지 접근 방식), 복잡한 다단계 헤더, @ExcelProperty/@ExcelIgnore/@DateTimeFormat/@NumberFormat 주석, includeColumn/excludeColumn 열 선택, @ColumnWidth/@ContentRowHeight 스타일 주석, @HeadStyle/@ContentStyle 사용자 정의 스타일, 셀 병합(@ContentLoopMerge/LoopMergeStrategy), 이미지 내보내기를 다룹니다. (파일/InputStream/URL/바이트[]), 하이퍼링크/설명/공식/서식 있는 텍스트(WriteCellData), 동적 헤더, 자동 열 너비, 사용자 정의 인터셉터(CellWriteHandler/SheetWriteHandler/RowWriteHandler), 페이지 매기기 일괄 쓰기, OutputStream으로 직접 웹 다운로드 및 Excel 2003/2007 형식과의 호환성. 주문, 사용자, 재무 기록, 재고, 보고서, 명세서, 승인 양식 등과 같은 구조화된 데이터를 내보내기 위해 프로그래밍 방식으로 Excel 파일(미리 설정된 템플릿 없이)을 생성해야 하는 경우 이 기술을 사용하십시오. 이 기술은 미리 설정된 템플릿을 기반으로 작성하거나(대신 easyexcel-fill 사용) Excel 파일을 읽는 데(대신 easyexcel-read 사용) 적합하지 않습니다.
