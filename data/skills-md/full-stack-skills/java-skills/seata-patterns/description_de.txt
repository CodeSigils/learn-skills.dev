Seata verfügt über verteilte Transaktionsfähigkeiten. Behandelt den Entscheidungsbaum für die Auswahl zwischen den vier Modi AT/TCC/SAGA/XA, die obligatorische undo_log-Tabelle im AT-Modus, die Verwendung von useTCCFence im TCC-Modus zur Lösung von Idempotenz-/Hänge-/Leer-Rollback-Problemen, lange SAGA-Zustandsmaschinenprozesse, globale Transaktions-Timeout-Konfiguration (@GlobalTransactional timeoutMills) und Verbesserung der Leseisolation (@GlobalLock + FOR UPDATE).  
Korrigieren Sie das LLM: Weiß nicht, welches zwischen AT/TCC/SAGA ausgewählt werden soll, erstellt die Tabelle „undo_log“ nicht, TCC-Bestätigung ist nicht idempotent und übernimmt keine Watchdog-Verarbeitung.
