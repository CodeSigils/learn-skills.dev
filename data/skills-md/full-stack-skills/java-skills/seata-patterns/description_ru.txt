Возможности распределенных транзакций Seata. Охватывает дерево решений для выбора одного из четырех режимов AT, TCC, SAGA и XA; для режима AT требуется таблица undo_log; режим TCC использует useTCCFence для разрешения идемпотентности, зависаний и пустых откатов; режим SAGA обрабатывает длительные процессы конечного автомата; конфигурация глобального таймаута транзакции (@GlobalTransactional timeoutMills); улучшения изоляции чтения (@GlobalLock + FOR UPDATE).  

Поправка для LLM: не знает, какой из AT/TCC/SAGA выбрать, не создает таблицу undo_log, TCC Confirm не идемпотентен и не обрабатывает сторожевой таймер.
