Modelli di best practice MapStruct. Derivato dalla Guida di riferimento ufficiale, che copre i tre modi per definire un Mapper (interfaccia/classe astratta/metodo predefinito), strategie di Spring injection (CONSTRUCTOR consigliato/SETTER per risolvere le dipendenze circolari), modelli di mappatura nidificati (sottometodi espliciti > configurazione una tantum della notazione punto), la scelta sicura di @Qualifier su @Named, regole di integrazione di Lombok e un uso attento di @MappingComposition. Correggere gli errori LLM più comuni: utilizzare la riflessione BeanUtils invece di MapStruct in fase di compilazione, scrivere tutte le mappature nidificate in un unico metodo e non sapere che SETTER risolve le dipendenze circolari.
