MapStruct best practice patterns. Derived from the official Reference Guide, covering the three ways to define a Mapper (interface, abstract class, default method), Spring injection strategies (constructor recommended / setter to resolve circular dependencies), nested mapping patterns (explicit sub‑methods > dot notation one‑time configuration), the safe choice of @Qualifier over @Named, Lombok integration rules, and careful use of @MappingComposition. It also corrects the most common LLM mistakes: using reflective BeanUtils instead of compile‑time MapStruct, writing all nested mappings in a single method, and not knowing that setter injection resolves circular dependencies.
