Modèles de bonnes pratiques MapStruct. Affiné à partir du guide de référence officiel, couvrant les trois façons de définir un mappeur (interface/classe abstraite/méthode par défaut), les stratégies d'injection Spring (constructeur recommandé/setter pour résoudre les dépendances circulaires), les modèles de mappage imbriqués (sous-méthodes explicites > notation par points pour une configuration unique), le choix sûr de @Qualifier plutôt que @Named, les règles d'intégration de Lombok et l'utilisation prudente de @MappingComposition.  

Correction des erreurs LLM les plus courantes : utiliser BeanUtils de réflexion au lieu de MapStruct au moment de la compilation, écrire tous les mappages imbriqués dans une seule méthode et ne pas savoir que l'injection de setter résout les dépendances circulaires.
