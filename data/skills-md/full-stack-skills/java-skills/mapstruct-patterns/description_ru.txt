Шаблоны лучших практик MapStruct. Получено из официального справочного руководства и охватывает три способа определения Mapper (интерфейс, абстрактный класс, метод по умолчанию), стратегии внедрения Spring (рекомендуется конструктор/установщик для разрешения циклических зависимостей), шаблоны вложенных сопоставлений (явные подметоды > одноразовая конфигурация с точечной записью), безопасный выбор @Qualifier вместо @Named, правила интеграции Lombok и осторожное использование @MappingComposition. Он также исправляет наиболее распространенные ошибки LLM: использование рефлексивных BeanUtils вместо MapStruct во время компиляции, запись всех вложенных сопоставлений в одном методе и незнание того, что внедрение установщика разрешает циклические зависимости.
