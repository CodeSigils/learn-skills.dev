MapStruct-Best-Practice-Muster. Abgeleitet aus dem offiziellen Referenzhandbuch behandelt es die drei Möglichkeiten zum Definieren eines Mappers (Schnittstelle, abstrakte Klasse, Standardmethode), Spring-Injection-Strategien (Konstruktor empfohlen, Setter zum Auflösen zirkulärer Abhängigkeiten), verschachtelte Zuordnungsmuster (explizite Untermethoden versus einmalige Konfiguration mit Punktnotation), die sicherere Wahl von @Qualifier gegenüber @Named, Lombok-Integrationsregeln und die vorsichtige Verwendung von @MappingComposition.  

Es korrigiert auch die häufigsten LLM-Fehler: die Verwendung von reflektiven BeanUtils anstelle von MapStruct zur Kompilierungszeit, das Zusammenfassen aller verschachtelten Zuordnungen in einer einzigen Methode und das Nichtwissen, dass Setter-Injection zirkuläre Abhängigkeiten auflöst.
