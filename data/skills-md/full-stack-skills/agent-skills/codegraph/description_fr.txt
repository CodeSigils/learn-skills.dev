Intelligence sémantique du code CodeGraph : requête de structure de code, traçage de symboles, analyse d'impact des changements, recherche de chaîne d'appels. Gère les questions de base de code telles que « Comment fonctionne X », « Qu'est-ce que la modification de X affecte », « Qui appelle X », etc. Prend en charge plus de 20 langues, 100 % locales.
