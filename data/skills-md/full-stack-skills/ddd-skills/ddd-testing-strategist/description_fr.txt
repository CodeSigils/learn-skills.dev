Stratégie de test DDD : tests unitaires de modèle de domaine, tests de racine globale, tests de référentiel avec des simulations, tests d'intégration de services d'application, tests d'adaptateur E2E, pyramide de test pour les architectures DDD en couches/hexagonales/propres et conception de domaine pilotée par les tests (TDDD). À utiliser lorsque l'utilisateur pose des questions sur la stratégie de test, les tests DDD, les tests agrégés, les tests de référentiel, la conception de domaine pilotée par les tests ou lorsqu'il a besoin de tester des applications DDD.
