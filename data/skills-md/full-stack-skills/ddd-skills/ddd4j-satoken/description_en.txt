DDD4J Sa-Token authentication extension skill. It covers the StpKit extended payload mode (writing user/org/role at login and retrieving them with StpUtil.getExtra), SaTempKit one‑time tokens, integration with ApiRestResponse exception handling, cross‑service Same‑Token configuration, and the usage of @SaCheckPermission in DDD4J controllers.

When users employ Sa-Token for authentication in a DDD4J project and need to add extended login payload (uuid/username/orgId) or generate one‑time temporary tokens, this skill is required.

It is used together with ddd4j‑core and the Sa-Token skill.
