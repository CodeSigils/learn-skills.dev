DDD4J MyBatis-Plus persistence layer convention skill. Covers ActiveRecord mode (Entity must extend BaseEntity → Model<T>), @TableLogic logical deletion, automatic filling of audit fields (createBy/createTime/updateBy/updateTime), @Param("model") XML parameter convention, PaginationEntity pagination wrapper (15 items per page, Oracle‑style offset), type‑handler system (BooleanEnum/JSON double wrapper/ListSetArray splitting), and built‑in BaseMapper methods such as getPagedList, setStatus, getCountBy* and others.  
This skill is required when users define Entity/Repository in a DDD4J project, write Mapper XML, use paginated queries, and configure type handlers.  
Used together with the ddd4j‑core skill.
