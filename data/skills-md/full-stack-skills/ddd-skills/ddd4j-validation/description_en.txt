DDD4J custom validation rule capability. It covers four custom constraints (@AllowedValues/@PhoneNumber/@NumberValue/@StringDateValue), a rule that silently passes empty strings for @StringDateValue, disables default message interpolation constraints in the validator, positions the validation layer at (Param/DTO rather than a standalone Validator), and provides libphonenumber international phone number validation. This capability is required when users write parameter validation, phone number/date format validation, or enum value validation in DDD4J projects. It is used together with the ddd4j-core capability.
