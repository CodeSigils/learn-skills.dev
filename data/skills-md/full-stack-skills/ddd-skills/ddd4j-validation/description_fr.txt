Compétence de règle de validation personnalisée DDD4J. Il couvre quatre contraintes personnalisées (@AllowedValues, @PhoneNumber, @NumberValue, @StringDateValue), une règle qui transmet silencieusement les chaînes vides pour @StringDateValue, désactive les contraintes d'interpolation de message par défaut dans le validateur, place la couche de validation au niveau Param/DTO plutôt qu'en tant que validateur séparé et inclut la validation du numéro de téléphone international libphonenumber. Cette compétence est requise lorsque les utilisateurs écrivent la validation de paramètres, la validation de numéro de téléphone/format de date ou la validation de valeur d'énumération dans les projets DDD4J. Il est utilisé avec la compétence ddd4j-core.
