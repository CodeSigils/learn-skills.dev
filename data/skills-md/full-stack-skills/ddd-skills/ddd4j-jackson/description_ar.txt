DDD4J مهارة قاعدة التسلسل جاكسون. يتجاوز تنسيق التاريخ (غير ISO‑8601 yyyy‑MM‑dd HH:mm:ss)، وقواعد تسلسل القيمة الخالية (الصفيف → []، السلسلة → ""، الرقم/المنطقي → الاحتفاظ بالقيمة الخالية)، وإخفاء البيانات الحساسة @Sensitive (5 إستراتيجيات)، والمثيلات المزدوجة لـ JacksonKit وWebObjectMapper (JacksonKit for Redis / ObjectMapper للويب)، وToLongDeserializer (يتعامل مع الدقة) الخسارة في JavaScript للواجهة الأمامية). يُستخدم عندما يستخدم مستخدم في مشروع DDD4J Jackson، ويحتاج إلى تكوين ObjectMapper، والتعامل مع إخفاء البيانات الحساسة، وحل مشكلات تنسيق JSON للواجهة الأمامية/الخلفية. يعمل مع مهارة ddd4j الأساسية.
