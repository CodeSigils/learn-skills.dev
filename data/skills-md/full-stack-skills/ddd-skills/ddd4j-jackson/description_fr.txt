Compétence de règle de sérialisation DDD4J Jackson. Remplace le format de date (non‑ISO‑8601 aaaa‑MM‑jj HH:mm:ss), règles de sérialisation des valeurs nulles (tableau → [], chaîne → "", nombre/booléen → garder nul), désensibilisation des données sensibles @Sensitive (5 stratégies), doubles instances de JacksonKit et WebObjectMapper (JacksonKit pour Redis / ObjectMapper pour Web), ToLongDeserializer (gestion de la perte de précision JS frontale). Utilisé lorsque les utilisateurs emploient Jackson dans un projet DDD4J, doivent configurer ObjectMapper, gérer la désensibilisation des données sensibles et résoudre les problèmes de format JSON front-back. Utilisé avec la compétence ddd4j‑core.
