Abilità della regola di serializzazione di DDD4J Jackson. Sostituisce il formato della data (non‑ISO‑8601 aaaa‑MM‑gg HH:mm:ss), le regole di serializzazione con valore null (array → [], stringa → "", numero/booleano → mantieni null), mascheramento dati sensibili @Sensitive (5 strategie), doppia istanza di JacksonKit e WebObjectMapper (JacksonKit per Redis/ObjectMapper per Web) e ToLongDeserializer (gestione della perdita di precisione JS front-end). Utilizzato quando un utente in un progetto DDD4J impiega Jackson, deve configurare ObjectMapper, gestire il mascheramento dei dati sensibili e risolvere problemi relativi al formato JSON front‑end/back‑end. Funziona insieme all'abilità ddd4j‑core.
