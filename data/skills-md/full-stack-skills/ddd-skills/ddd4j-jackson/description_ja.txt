DDD4J ジャクソンのシリアル化ルール スキル。日付形式 (非 ISO-8601 yyyy-MM-dd HH:mm:ss)、null 値シリアル化ルール (配列 → []、文字列 → ""、数値/ブール値 → null を維持)、@Sensitive 機密データ マスキング (5 つの戦略)、JacksonKit と WebObjectMapper のデュアル インスタンス (JacksonKit for Redis / ObjectMapper for Web) をオーバーライドします。 ToLongDeserializer (フロントエンド JavaScript での精度の損失を処理します)。 DDD4J プロジェクトのユーザーが Jackson を使用し、ObjectMapper を構成し、機密データのマスキングを処理し、フロントエンド/バックエンドの JSON 形式の問題を解決する必要がある場合に使用されます。 ddd4j‑core スキルと連携して動作します。
