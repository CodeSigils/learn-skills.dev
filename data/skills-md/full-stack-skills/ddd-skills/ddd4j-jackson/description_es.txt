Habilidad de regla de serialización de DDD4J Jackson. Anula el formato de fecha (no ISO-8601 aaaa-MM-dd HH:mm:ss), reglas de serialización de valores nulos (matriz → [], cadena → "", número/booleano → mantener nulo), enmascaramiento de datos sensibles @Sensitive (5 estrategias), instancias duales de JacksonKit y WebObjectMapper (JacksonKit para Redis/ObjectMapper para Web) y ToLongDeserializer (maneja la pérdida de precisión en JavaScript front-end). Se utiliza cuando un usuario en un proyecto DDD4J usa Jackson, necesita configurar ObjectMapper, manejar el enmascaramiento de datos confidenciales y resolver problemas de formato JSON de front-end/back-end. Funciona junto con la habilidad ddd4j-core.
