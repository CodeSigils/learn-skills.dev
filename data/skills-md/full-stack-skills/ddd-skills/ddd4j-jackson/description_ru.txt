DDD4J Навык правила сериализации Джексона. Переопределяет формат даты (отличный от ISO‑8601 гггг‑ММ‑дд ЧЧ:мм:сс), правила сериализации нулевых значений (массив → [], строка → «», число/логическое значение → сохранять ноль), маскирование конфиденциальных данных @Sensitive (5 стратегий), двойные экземпляры JacksonKit и WebObjectMapper (JacksonKit для Redis / ObjectMapper для Интернета) и ToLongDeserializer (обрабатывает потерю точности во внешнем интерфейсе). JavaScript). Используется, когда пользователь в проекте DDD4J использует Jackson, ему необходимо настроить ObjectMapper, обрабатывать маскирование конфиденциальных данных и решать проблемы с форматом JSON на интерфейсной и внутренней стороне. Работает вместе с базовым навыком ddd4j.
