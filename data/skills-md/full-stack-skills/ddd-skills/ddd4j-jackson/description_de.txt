DDD4J Jackson-Serialisierungsregelfähigkeit. Überschreibt das Datumsformat (nicht ISO 8601, jjjj, MM, TT, HH: mm: ss), Nullwert-Serialisierungsregeln (Array → [], Zeichenfolge → „“, Zahl/Boolescher Wert → Null behalten), @Sensitive-Maskierung vertraulicher Daten (5 Strategien), doppelte Instanzen von JacksonKit und WebObjectMapper (Redis verwendet JacksonKit / Web verwendet ObjectMapper), ToLongDeserializer (Behandlung von Front-End-JS-Präzisionsverlusten). Wird verwendet, wenn Benutzer in einem DDD4J-Projekt Jackson verwenden, ObjectMapper konfigurieren, die Maskierung vertraulicher Daten handhaben und Probleme mit dem JSON-Format vorne und hinten lösen müssen. Wird zusammen mit dem ddd4j-core-Skill verwendet.
