Создание документации по архитектуре DDD — диаграммы моделей C4 (контекст/контейнер/компонент/код), ADR (записи решений по архитектуре), документация по модели предметной области, документация по API, журнал решений по архитектуре и шаблоны командного общения. Используйте, когда пользователь спрашивает о документации по архитектуре, 架构文档, ADR, диаграмме C4, документе модели предметной области, 架构决策记录 или ему необходимо документировать архитектуру DDD для команды.
