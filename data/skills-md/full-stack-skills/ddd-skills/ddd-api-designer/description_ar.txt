تصميم واجهة برمجة التطبيقات (API) من نموذج المجال - فصل الأمر/الاستعلام CQRS، وتصميم نقطة نهاية REST API، وسلسلة تحويل كائن البيانات (PO→DO→DTO→VO)، وتنسيق الاستجابة الموحد، وتوليد OpenAPI/Swagger، ونمط BFF، وإصدار API، وتصميم الأمان. يُستخدم عندما يسأل المستخدم عن تصميم واجهة برمجة التطبيقات (API)، أو REST API، أو OpenAPI، أو BFF، أو تصميم DTO، أو تحويل كائن البيانات.
