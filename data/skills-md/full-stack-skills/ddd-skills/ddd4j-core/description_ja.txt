DDD4J ブート コア開発コンベンション スキル。エンティティ継承チェーン (BaseEntity → Model<T>/PaginationEntity)、DDD アノテーション ルール (@DomainEntity は SOURCE / @DomainService ≡ @Service)、コントローラー階層 (BaseController → BaseMapperController)、サービス階層 (IBaseService → BaseServiceImpl)、戻り値の規則 (ApiRestResponse の 3 つの状態: 成功/失敗/エラー、ページネーションはデータの代わりに行を返す)、クエリ パラメーターをカバーします。配置 (エンティティの beginTime/endTime/keywords/params)、NestedMessageSource による国際化、監査フィールドの自動入力、および Dozer オブジェクトのマッピング。このスキルは、ユーザーが DDD4J プロジェクトでエンティティ/サービス/コントローラーを作成し、戻り値の形式を処理し、DDD アノテーションを使用するときに必要です。これは、ddd4j-jackson (シリアル化)、ddd4j-mybatis (永続層)、ddd4j-validation (検証)、および ddd4j-satoken (認証/認可) と連携して動作します。
