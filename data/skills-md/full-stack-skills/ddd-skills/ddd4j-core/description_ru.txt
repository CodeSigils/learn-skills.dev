DDD4J Навыки разработки ядра загрузки. Охватывает цепочку наследования объектов (BaseEntity → Model<T>/PaginationEntity), правила аннотаций DDD (@DomainEntity is SOURCE / @DomainService ≡ @Service), иерархию контроллеров (BaseController → BaseMapperController), иерархию служб (IBaseService → BaseServiceImpl), соглашения о возвращаемых значениях (три состояния ApiRestResponse: успех/сбой/ошибка; разбиение на страницы возвращает строки вместо данных), размещение параметров запроса. (beginTime/endTime/keywords/params для сущности), интернационализация с помощью NestedMessageSource, автоматическое заполнение полей аудита и сопоставление объектов Dozer. Этот навык необходим, когда пользователи пишут Entity/Service/Controller в проекте DDD4J, обрабатывают форматы возвращаемых значений и используют аннотации DDD. Он работает вместе с ddd4j-jackson (сериализация), ddd4j-mybatis (уровень сохранения), ddd4j-validation (проверка подлинности) и ddd4j-satoken (аутентификация/авторизация).
