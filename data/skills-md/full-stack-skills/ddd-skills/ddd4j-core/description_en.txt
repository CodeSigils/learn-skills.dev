DDD4J Boot core development convention skill. Covers the entity inheritance chain (BaseEntity → Model<T>/PaginationEntity), DDD annotation rules (@DomainEntity is SOURCE / @DomainService ≡ @Service), Controller hierarchy (BaseController → BaseMapperController), Service hierarchy (IBaseService → BaseServiceImpl), return value conventions (ApiRestResponse three states: success/fail/error; pagination returns rows instead of data), query parameter placement (beginTime/endTime/keywords/params on the Entity), internationalization with NestedMessageSource, automatic filling of audit fields, and Dozer object mapping. This skill is required when users write Entity/Service/Controller in a DDD4J project, handle return value formats, and use DDD annotations. It works together with ddd4j-jackson (serialization), ddd4j-mybatis (persistence layer), ddd4j-validation (validation), and ddd4j-satoken (authentication/authorization).
