DDD4J Boot 核心开发约定技巧。涵盖实体继承链（BaseEntity → Model<T>/PaginationEntity）、DDD注解规则（@DomainEntity为SOURCE / @DomainService ≡ @Service）、Controller层次结构（BaseController → BaseMapperController）、Service层次结构（IBaseService → BaseServiceImpl）、返回值约定（ApiRestResponse三种状态：成功/失败/错误；分页返回行而不是数据）、查询参数放置（beginTime/endTime/keywords/params）在实体上）、使用 NestedMessageSource 进行国际化、自动填充审核字段以及 Dozer 对象映射。当用户在 DDD4J 项目中编写 Entity/Service/Controller、处理返回值格式以及使用 DDD 注解时，需要此技能。它与 ddd4j-jackson（序列化）、ddd4j-mybatis（持久层）、ddd4j-validation（验证）和 ddd4j-satoken（身份验证/授权）配合使用。
