Erstellen und aktualisieren Sie Joplin-Aufgabennotizen – die dauerhafte Aufzeichnung einer Aufgabe (Beschreibung, Arbeitsverzeichnis, Checkliste, Protokoll, Links). Verwenden Sie diese Option, wenn der Benutzer möchte, dass eine Joplin-Notiz eine Aufgabe verfolgt, oder wenn ein anderer Skill das Aufgabennotizformat oder Aktualisierungskonventionen benötigt.
