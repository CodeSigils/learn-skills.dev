Genera un design.md o DESIGN.md riutilizzabile da un sito Web live ispezionando approfonditamente il sito con "agent-browser" e "agent-browser eval", quindi sintetizzandone il linguaggio visivo, il sistema di layout, i modelli di interazione e lo stile dei contenuti in un sistema di progettazione markdown strutturato. Da utilizzare quando vengono forniti uno o più URL di siti Web e viene chiesto di analizzare un sito, effettuare il reverse engineering del suo design, estrarne l'aspetto grafico, scrivere DESIGN.md, creare una guida di stile o acquisire le regole dell'interfaccia utente di un sito per una successiva progettazione o implementazione assistita dall'intelligenza artificiale. Preferisci questa abilità quando l'obiettivo è la documentazione piuttosto che ricostruire la pagina nel codice. Utilizza sempre "agent-browser" come runtime del browser principale; se manca, aiuta l'utente a installarlo o esporlo invece di cambiare piattaforma o stack di browser.
