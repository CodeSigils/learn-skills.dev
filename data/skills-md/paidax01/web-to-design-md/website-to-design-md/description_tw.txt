透過使用「agent-browser」和「agent-browser eval」深入檢查網站，從即時網站產生可重複使用的 design.md 或 DESIGN.md，然後將其視覺語言、佈局系統、互動模式和內容風格綜合到結構化的 Markdown 設計系統中。當給定一個或多個網站 URL 並要求分析網站、對其設計進行逆向工程、提取其外觀和感覺、編寫 DESIGN.md、創建樣式指南或捕獲網站的 UI 規則以供以後的 AI 輔助設計或實施時使用。當目標是文件而不是用程式碼重建頁面時，更喜歡使用此技能。始終使用“agent-browser”作為主要瀏覽器運行時；如果缺少，請幫助用戶安裝或公開它，而不是切換平台或瀏覽器堆疊。
