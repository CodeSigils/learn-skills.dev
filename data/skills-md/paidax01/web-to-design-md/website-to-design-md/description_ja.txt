「agent-browser」および「agent-browser eval」を使用してサイトを詳細に検査し、そのビジュアル言語、レイアウト システム、インタラクション パターン、およびコンテンツ スタイルを構造化マークダウン デザイン システムに合成することにより、ライブ Web サイトから再利用可能な design.md または DESIGN.md を生成します。 1 つ以上の Web サイトの URL を指定し、サイトの分析、デザインのリバース エンジニアリング、外観と操作性の抽出、DESIGN.md の作成、スタイル ガイドの作成、または後の AI 支援設計や実装のためのサイトの UI ルールのキャプチャを依頼された場合に使用します。コードでページを再構築するのではなく、ドキュメント化が目的の場合は、このスキルを優先してください。常に「agent-browser」をプライマリブラウザランタイムとして使用してください。見つからない場合は、プラットフォームやブラウザ スタックを切り替える代わりに、ユーザーがインストールまたは公開できるように支援してください。
