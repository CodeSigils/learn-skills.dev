Crea una nueva habilidad de IA en un proyecto Mini Program existente. Se activa cuando el usuario quiere agregar una capacidad de IA personalizada a un proyecto existente (en lugar de instalar una habilidad de la comunidad ya preparada). El proceso completo: comprender los requisitos → diseñar la interfaz → invocar wxa-skills-generate para generar código → wxa-skills-validate pasa la validación.

Por favor, siempre responde en el idioma del usuario.
