Erstelle eine neue KI‑Skill in einem bestehenden Mini‑Programm‑Projekt. Wird ausgelöst, wenn der Nutzer eine benutzerdefinierte KI‑Fähigkeit zu einem bestehenden Projekt hinzufügen möchte (statt einer vorgefertigten Community‑Skill zu installieren). Vollständiger Ablauf: Anforderungen verstehen → Schnittstelle entwerfen → wxa‑skills‑generate aufrufen, um Code zu generieren → mit wxa‑skills‑validate validieren.
