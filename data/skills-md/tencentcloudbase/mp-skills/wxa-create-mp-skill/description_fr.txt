Créer une nouvelle compétence IA dans un projet Mini Program existant. Cela se déclenche lorsqu’un utilisateur veut ajouter une capacité IA personnalisée à un projet existant (au lieu d’installer une compétence communautaire prête à l’emploi). Le flux de travail complet : comprendre les exigences → concevoir l’interface → appeler wxa-skills-generate pour générer le code → wxa-skills-validate réussit la validation.

Veuillez toujours répondre dans la langue de l’utilisateur.
