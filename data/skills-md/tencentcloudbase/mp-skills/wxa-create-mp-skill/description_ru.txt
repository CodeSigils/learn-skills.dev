Создайте новый AI‑Skill в существующем проекте мини‑программы. Он срабатывает, когда пользователь хочет добавить пользовательскую AI‑функцию в существующий проект (вместо установки готового Skill из сообщества). Полный процесс: понять требования → спроектировать интерфейс → вызвать wxa‑skills‑generate для генерации кода → wxa‑skills‑validate проходит проверку.
