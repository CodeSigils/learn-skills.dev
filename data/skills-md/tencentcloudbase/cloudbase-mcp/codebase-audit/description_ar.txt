قم بإجراء مراجعة كاملة لقاعدة التعليمات البرمجية، وتصنيف النتائج حسب الخطورة، وتقديم مشكلات GitHub، ثم إصلاح كل مشكلة في شجرة عمل git معزولة وإرسال العلاقات العامة. استخدم هذه المهارة عندما يطلب المستخدم تدقيق قاعدة التعليمات البرمجية، أو إجراء مراجعة شاملة للتعليمات البرمجية، أو العثور على مشكلات الأمان/الجودة/الموثوقية وإصلاحها، أو إجراء فحص سلامة استباقي عبر المستودع بأكمله.
