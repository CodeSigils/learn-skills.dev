Clasifique, repare y cierre problemas de atribución de MCP desde la API de informes local con decisiones basadas en evidencia y árboles de trabajo aislados de Worktrunk. Utilice esta habilidad cuando Codex necesite procesar problemas de atribución de "herramientas" y problemas de atribución relacionados con habilidades, inspeccionar ejecuciones relacionadas, decidir si el problema es procesable en "mcp/src" o "config/source/skills", actualizar los campos de atribución como "propietario=codex" y luego completar el ciclo de reparación a través del seguimiento de problemas de GitHub, cambios de código basados ​​en árbol de trabajo, envío de relaciones públicas e iteración de seguimiento cuando el problema sea reparable.
