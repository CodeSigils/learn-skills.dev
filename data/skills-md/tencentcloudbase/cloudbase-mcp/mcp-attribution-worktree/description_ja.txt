証拠に基づいた決定と分離された Worktrunk ワークツリーを使用して、ローカル レポート API から MCP 属性の問題をトリアージ、修復、解決します。 Codex が「ツール」アトリビューションの問題とスキル関連のアトリビューションの問題を処理し、関連する実行を検査し、問題が「mcp/src」または「config/source/skills」で対処可能かどうかを判断し、アトリビューション フィールドを「owner=codex」として更新する必要がある場合に、このスキルを使用します。その後、GitHub の問題追跡、ワークツリーベースのコード変更、PR 送信、および問題が修復可能な場合のフォローアップ反復による修正ループを完了します。
