اُستخدم عند بناء أو تصحيح أو تقييم تطبيقات CloudBase PostgreSQL / CloudBase PG / وضع PG، بما في ذلك إعداد مخطط Postgres، queryPgDatabase/managePgDatabase، JS SDK v3 app.rdb() للعمليات CRUD/RPC، fallback لواجهة HTTP API الخاصة بـ PG، أذونات على نمط RLS، المصادقة باسم المستخدم وكلمة المرور، وتدفقات CRUD لإدارة CMS الويب/الإدارة المدعومة بـ CloudBase PG.
