Habilidad de gestión de recursos de CloudBase CLI (tcb, 云开发CLI, Tencent CloudBase命令行). Esta habilidad debe usarse cuando los usuarios necesitan implementar funciones en la nube, administrar aplicaciones CloudRun, cargar archivos al almacenamiento, consultar bases de datos NoSQL/MySQL, implementar alojamiento estático, establecer permisos de acceso o configurar CORS/dominios/enrutamiento mediante comandos tcb. Úselo también para secuencias de comandos de canalización de CI/CD, operaciones por lotes, administración de CloudBase basada en terminales o cuando el usuario prefiera CLI sobre SDK/MCP.
