CloudBase CLI (tcb, 云开发CLI, Tencent CloudBase命令行) навыки управления ресурсами. Этот навык следует использовать, когда пользователям необходимо развернуть облачные функции, управлять приложениями CloudRun, загружать файлы в хранилище, запрашивать базы данных NoSQL/MySQL, развертывать статический хостинг, устанавливать права доступа или настраивать CORS/домены/маршрутизацию с помощью команд tcb. Также используйте для сценариев конвейера CI/CD, пакетных операций, управления CloudBase на основе терминала или когда пользователь предпочитает CLI вместо SDK/MCP.
