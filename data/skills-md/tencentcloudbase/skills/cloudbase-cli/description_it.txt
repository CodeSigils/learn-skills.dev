Competenza di gestione delle risorse della CLI CloudBase (tcb, 云开发CLI, Tencent CloudBase命令行). Questa competenza deve essere utilizzata quando gli utenti devono distribuire funzioni cloud, gestire app CloudRun, caricare file nello spazio di archiviazione, eseguire query su database NoSQL/MySQL, distribuire hosting statico, impostare autorizzazioni di accesso o configurare CORS/domini/routing tramite comandi tcb. Utilizzabile anche per script di pipeline CI/CD, operazioni batch, gestione CloudBase basata su terminale o quando l'utente preferisce la CLI rispetto a SDK/MCP.
