Compétence en gestion des ressources CloudBase CLI (tcb, 云开发CLI, Tencent CloudBase命令行). Cette compétence doit être utilisée lorsque les utilisateurs doivent déployer des fonctions cloud, gérer des applications CloudRun, télécharger des fichiers vers le stockage, interroger des bases de données NoSQL/MySQL, déployer un hébergement statique, définir des autorisations d'accès ou configurer CORS/domaines/routage via les commandes tcb. À utiliser également pour les scripts de pipeline CI/CD, les opérations par lots, la gestion CloudBase basée sur un terminal ou lorsque l'utilisateur préfère CLI plutôt que SDK/MCP.
