CloudBase CLI (tcb، 云开发CLI، Tencent CloudBase命令行) مهارة إدارة الموارد. يجب استخدام هذه المهارة عندما يحتاج المستخدمون إلى نشر وظائف السحابة، أو إدارة تطبيقات CloudRun، أو تحميل الملفات إلى وحدة التخزين، أو الاستعلام عن قواعد بيانات NoSQL/MySQL، أو نشر استضافة ثابتة، أو تعيين أذونات الوصول، أو تكوين CORS/domains/routing عبر أوامر tcb. يُستخدم أيضًا في البرمجة النصية لخط أنابيب CI/CD، أو العمليات المجمعة، أو إدارة CloudBase المستندة إلى المحطة الطرفية، أو عندما يفضل المستخدم CLI على SDK/MCP.
