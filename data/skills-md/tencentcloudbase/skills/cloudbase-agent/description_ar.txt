قم ببناء وكلاء الذكاء الاصطناعي ونشرهم باستخدام CloudBase Agent SDK (TypeScript وPython). ينفذ بروتوكول AG-UI لاتصالات وكيل واجهة المستخدم المتدفقة. يُستخدم عند نشر خوادم الوكيل، أو استخدام محولات LangGraph/LangChain/CrewAI، أو إنشاء محولات مخصصة، أو فهم أحداث بروتوكول AG-UI، أو إنشاء عملاء واجهة مستخدم الويب/البرامج المصغرة. يدعم كلا من TypeScript (@cloudbase/agent-server) وPython (cloudbase-agent-server عبر FastAPI).
