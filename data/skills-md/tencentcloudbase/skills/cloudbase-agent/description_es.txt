Cree e implemente agentes de IA con CloudBase Agent SDK (TypeScript y Python). Implementa el protocolo AG-UI para la comunicación entre el agente y la UI. Úselo al implementar servidores de agentes, usar adaptadores LangGraph/LangChain/CrewAI, crear adaptadores personalizados, comprender eventos del protocolo AG-UI o crear clientes de UI web/miniprogramas. Admite TypeScript (@cloudbase/agent-server) y Python (cloudbase-agent-server a través de FastAPI).
