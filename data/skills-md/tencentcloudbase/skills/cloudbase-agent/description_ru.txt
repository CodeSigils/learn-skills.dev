Создавайте и развертывайте агенты ИИ с помощью CloudBase Agent SDK (TypeScript и Python). Реализует протокол AG-UI для потоковой передачи данных агента и пользовательского интерфейса. Используйте при развертывании серверов агентов, использовании адаптеров LangGraph/LangChain/CrewAI, создании пользовательских адаптеров, понимании событий протокола AG-UI или создании веб-клиентов или клиентов пользовательского интерфейса мини-программ. Поддерживает как TypeScript (@cloudbase/agent-server), так и Python (cloudbase-agent-server через FastAPI).
