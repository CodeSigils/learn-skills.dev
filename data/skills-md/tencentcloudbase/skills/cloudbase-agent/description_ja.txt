CloudBase エージェント SDK (TypeScript および Python) を使用して AI エージェントを構築およびデプロイします。ストリーミング エージェント-UI 通信用の AG-UI プロトコルを実装します。エージェント サーバーの展開、LangGraph/LangChain/CrewAI アダプターの使用、カスタム アダプターの構築、AG-UI プロトコル イベントの理解、または Web/ミニプログラム UI クライアントの構築時に使用します。 TypeScript (@cloudbase/agent-server) と Python (FastAPI 経由のcloudbase-agent-server) の両方をサポートします。
