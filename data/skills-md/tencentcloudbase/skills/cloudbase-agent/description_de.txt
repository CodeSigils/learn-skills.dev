Erstellen und implementieren Sie KI-Agenten mit dem CloudBase Agent SDK (TypeScript und Python). Implementiert das AG-UI-Protokoll für die Streaming-Agent-UI-Kommunikation. Verwenden Sie diese Option, wenn Sie Agent-Server bereitstellen, LangGraph-/LangChain-/CrewAI-Adapter verwenden, benutzerdefinierte Adapter erstellen, AG-UI-Protokollereignisse verstehen oder Web-/Miniprogramm-UI-Clients erstellen. Unterstützt sowohl TypeScript (@cloudbase/agent-server) als auch Python (cloudbase-agent-server über FastAPI).
