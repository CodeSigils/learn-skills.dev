Cree un proyecto completo de agente de voz Vapi a partir de una especificación ROUGH_DRAFT.md. Genera package.json, .env.example, .gitignore y el marco completo de TypeScript (registro de escenarios, pila de transcripción/voz por idioma, compositor de mensajes, asistente de creación y un script de arranque idempotente), además de un primer borrador de body.md por escenario. Coloque esta habilidad en la carpeta .cursor/skills/ de cualquier proyecto (o ~/.cursor/skills/ para uso global), escriba un ROUGH_DRAFT.md en la raíz del proyecto, asigne un nombre a la habilidad y `bun run bootstrap` colocará toda la flota en vivo en Dashboard.vapi.ai. Úselo cuando el usuario solicite crear un andamiaje o iniciar los agentes de voz de Vapi a partir de un borrador, crear una flota de asistentes de Vapi o invoca esta habilidad por su nombre. Objetivos Bun + TypeScript + @vapi-ai/server-sdk.
