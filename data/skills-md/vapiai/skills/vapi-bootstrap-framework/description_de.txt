Erstellen Sie ein Gerüst für ein vollständiges Vapi-Voice-Agent-Projekt aus einer ROUGH_DRAFT.md-Spezifikation. Generiert package.json, .env.example, .gitignore und das vollständige TypeScript-Framework – Szenario-Registrierung, Sprach-/Transkriptionsstapel pro Sprache, Prompt Composer, Assistant Builder und ein idempotentes Bootstrap-Skript – plus einen groben ersten Entwurf body.md pro Szenario. Legen Sie diesen Skill im .cursor/skills/-Ordner eines beliebigen Projekts ab (oder ~/.cursor/skills/ für die globale Verwendung), schreiben Sie eine ROUGH_DRAFT.md im Projektstammverzeichnis, benennen Sie den Skill und „bun run bootstrap“ schaltet die gesamte Flotte in Dashboard.vapi.ai live. Verwenden Sie diese Option, wenn der Benutzer darum bittet, Vapi-Sprachagenten aus einem Rohentwurf zu gerüsten oder zu booten, eine Vapi-Assistentenflotte aufzubauen oder diese Fähigkeit namentlich aufzurufen. Zielt auf Bun + TypeScript + @vapi-ai/server-sdk.
