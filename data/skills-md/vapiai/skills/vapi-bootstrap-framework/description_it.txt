Impalcatura di un progetto completo di agente vocale Vapi da una specifica ROUGH_DRAFT.md. Genera package.json, .env.example, .gitignore e il framework TypeScript completo: registro degli scenari, stack vocale/trascrittore per lingua, compositore di prompt, assistente alla creazione e uno script di bootstrap idempotente, oltre a un body.md di prima bozza approssimativo per scenario. Rilascia questa competenza nella cartella .cursor/skills/ di qualsiasi progetto (o ~/.cursor/skills/ per uso globale), scrivi un ROUGH_DRAFT.md nella radice del progetto, dai un nome alla competenza e "bun run bootstrap" mette l'intera flotta in live in dashboard.vapi.ai. Da utilizzare quando l'utente chiede di impalcare o avviare gli agenti vocali Vapi da una bozza approssimativa, costruire una flotta di assistenti Vapi o richiama questa abilità per nome. Ha come target Bun + TypeScript + @vapi-ai/server-sdk.
