根據 ROUGH_DRAFT.md 規範建構一個完整的 Vapi 語音代理專案。產生 package.json、.env.example、.gitignore 和完整的 TypeScript 框架 - 場景註冊表、每種語言的語音/轉錄器堆疊、提示編輯器、助理構建器和冪等引導腳本 - 以及每個場景一個粗略的初稿 body.md。將此技能放入任何專案的 .cursor/skills/ 資料夾（或 ~/.cursor/skills/ 以供全局使用）中，在專案根目錄中編寫 ROUGH_DRAFT.md，命名該技能，然後「bun run bootstrap」將整個艦隊置於儀表板.vapi.ai 中。當使用者要求從草稿中建立或引導 Vapi 語音代理、建立 Vapi 助理佇列或透過名稱呼叫此技能時使用。目標 Bun + TypeScript + @vapi-ai/server-sdk。
