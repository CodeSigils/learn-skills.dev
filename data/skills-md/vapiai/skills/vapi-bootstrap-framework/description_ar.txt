قم ببناء مشروع وكيل صوتي كامل لـ Vapi من مواصفات ROUGH_DRAFT.md. يُنشئ package.json، و.env.example، و.gitignore، وإطار عمل TypeScript الكامل - سجل السيناريو، ومكدس الصوت/الناسخ لكل لغة، والملحن الفوري، والباني المساعد، ونص تمهيدي غير فعال - بالإضافة إلى مسودة أولية تقريبية body.md لكل سيناريو. قم بإسقاط هذه المهارة في مجلد .cursor/skills/ الخاص بأي مشروع (أو ~/.cursor/skills/ للاستخدام العالمي)، واكتب ROUGH_DRAFT.md في جذر المشروع، وقم بتسمية المهارة، ثم يقوم `bun run bootstrap` بوضع الأسطول بأكمله مباشرة في Dashboard.vapi.ai. يُستخدم عندما يطلب المستخدم دعم وكلاء Vapi الصوتيين أو تشغيلهم من مسودة تقريبية، أو إنشاء أسطول مساعد Vapi، أو استدعاء هذه المهارة بالاسم. الأهداف كعكة + TypeScript + @vapi-ai/server-sdk.
