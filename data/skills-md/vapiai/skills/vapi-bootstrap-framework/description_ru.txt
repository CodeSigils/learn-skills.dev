Создайте полный проект голосового агента Vapi на основе спецификации ROUGH_DRAFT.md. Создает package.json, .env.example, .gitignore и полную структуру TypeScript — реестр сценариев, стек голоса/транскриптера для каждого языка, компоновщик подсказок, помощник по сборке и идемпотентный сценарий начальной загрузки — плюс один черновой первоначальный вариант body.md для каждого сценария. Поместите этот навык в папку .cursor/skills/ любого проекта (или ~/.cursor/skills/ для глобального использования), напишите ROUGH_DRAFT.md в корне проекта, назовите навык, и `bun run bootstrap` разместит весь парк в Dashboard.vapi.ai. Используйте, когда пользователь просит создать или загрузить голосовые агенты Vapi из черновика, создать группу помощников Vapi или вызывает этот навык по имени. Цели Bun + TypeScript + @vapi-ai/server-sdk.
