ROUGH_DRAFT.md 사양에서 전체 Vapi 음성 에이전트 프로젝트를 스캐폴드합니다. package.json, .env.example, .gitignore 및 전체 TypeScript 프레임워크(시나리오 레지스트리, 언어별 음성/트랜스크라이버 스택, 프롬프트 작성기, 보조 빌더 및 멱등성 부트스트랩 스크립트)와 시나리오당 대략적인 첫 번째 초안 body.md 하나를 생성합니다. 이 스킬을 프로젝트의 .cursor/skills/ 폴더(또는 전역 사용의 경우 ~/.cursor/skills/)에 놓고 프로젝트 루트에 ROUGH_DRAFT.md를 작성하고 스킬 이름을 지정하면 'bun run bootstrap'이 전체 플릿을 Dashboard.vapi.ai에 라이브로 넣습니다. 사용자가 초안에서 Vapi 음성 에이전트를 스캐폴드 또는 부트스트랩하도록 요청하거나, Vapi 보조 플릿을 구축하거나, 이름으로 이 기술을 호출할 때 사용합니다. Bun + TypeScript + @vapi-ai/server-sdk를 대상으로 합니다.
