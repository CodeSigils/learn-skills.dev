ROUGH_DRAFT.md 仕様から完全な Vapi 音声エージェント プロジェクトをスキャフォールディングします。 package.json、.env.example、.gitignore、および完全な TypeScript フレームワーク (シナリオ レジストリ、言語ごとの音声/トランスクライバー スタック、プロンプト コンポーザー、アシスタント ビルダー、べき等ブートストラップ スクリプト) に加えて、シナリオごとに 1 つの大まかな初稿 body.md を生成します。このスキルを任意のプロジェクトの .cursor/skills/ フォルダー (またはグローバルに使用する場合は ~/.cursor/skills/) にドロップし、プロジェクトのルートに ROUGH_DRAFT.md を書き込み、スキルに名前を付けます。その後、「bun run bootstrap」によりフリート全体が dashboard.vapi.ai に公開されます。ユーザーが、ラフ ドラフトから Vapi 音声エージェントをスキャフォールディングまたはブートストラップするか、Vapi アシスタント フリートを構築するか、名前でこのスキルを呼び出すかを要求する場合に使用します。 Bun + TypeScript + @vapi-ai/server-sdk をターゲットとします。
