Crea, migliora o controlla i comandi dell'agente vocale Vapi e del sistema Squad per agenti vocali di produzione telefonici e basati sul Web. Utilizzare quando l'utente desidera aiuto nella progettazione di un prompt dell'assistente Vapi, di un set di prompt di squadra multi-assistente, del perfezionamento di un prompt esistente, della creazione di sezioni di prompt, della creazione di un flusso di lavoro di assunzione o di trasferimento, nel miglioramento delle istruzioni per l'uso degli strumenti, nell'aggiunta di guardrail o nell'ottimizzazione del comportamento dell'agente vocale per brevità, turni, gestione degli errori, raccolta dati del chiamante, escalation, trasferimenti e formattazione vocale.
