إنشاء أو تحسين أو تدقيق وكيل صوت Vapi ومطالبات نظام Squad لهاتف الإنتاج ووكلاء الصوت المستندين إلى الويب. يُستخدم عندما يريد المستخدم المساعدة في تصميم موجه مساعد Vapi، أو مجموعة موجهات Squad متعددة المساعدين، أو تحسين موجه موجود، أو إنشاء أقسام موجهة، أو إنشاء سير عمل الاستيعاب أو التسليم، أو تحسين تعليمات استخدام الأدوات، أو إضافة حواجز حماية، أو تحسين سلوك وكيل الصوت للإيجاز، وأخذ الأدوار، ومعالجة الأخطاء، وجمع بيانات المتصل، والتصعيد، وعمليات التسليم، والتنسيق المنطوق.
