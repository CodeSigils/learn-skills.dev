Проектируйте, создавайте, запускайте, отслеживайте и обслуживайте симуляции Vapi для помощников и отрядов. Используйте для моделирования личностей, сценариев, критериев успеха структурированного вывода, моделирования, пакетов, чата или голосовых запусков, макетов инструментов, целевых переменных, веб-перехватчиков жизненного цикла, покрытия регрессии, ворот качества CI, анализа результатов запуска и ошибок проверки API моделирования. Не используйте Eval для имитационных бесед с фиксированным ходом, если только пользователь не выбирает между Eval и Simulations.
