Concevez, créez, exécutez, surveillez et maintenez des simulations Vapi pour les assistants et les équipes. À utiliser pour les personnalités de simulation, les scénarios, les critères de réussite de sortie structurée, les simulations, les suites, les exécutions de chat ou de voix, les simulations d'outils, les variables cibles, les webhooks de cycle de vie, la couverture de régression, les portes de qualité CI, l'analyse des résultats d'exécution et les erreurs de validation de l'API de simulation. Ne pas utiliser pour des évaluations de conversation simulée à tour fixe, sauf si l'utilisateur décide entre les évaluations et les simulations.
