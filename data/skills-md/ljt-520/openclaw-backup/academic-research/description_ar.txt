ابحث في الأوراق الأكاديمية وقم بإجراء مراجعات الأدبيات باستخدام OpenAlex API (مجاني، لا حاجة إلى مفتاح). يُستخدم عندما يحتاج المستخدم إلى العثور على أوراق بحثية حسب الموضوع/المؤلف/DOI، أو استكشاف سلاسل الاقتباس، أو الحصول على بيانات التعريف الورقية المنظمة (العنوان، المؤلفون، الملخص، الاستشهادات، DOI، عنوان URL للوصول المفتوح)، أو جلب النص الكامل لأوراق الوصول المفتوح، أو إجراء مراجعات الأدبيات الآلية مع تحديد الموضوع والتوليف. يتم تشغيل الطلبات التي تتضمن بحثًا أكاديميًا، أو البحث عن الأوراق، أو تحليل الاستشهادات، أو مراجعة الأدبيات، أو تجميع الأبحاث، أو جمع المراجع العلمية.
