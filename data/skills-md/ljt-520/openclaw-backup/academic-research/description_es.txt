Busque artículos académicos y realice revisiones bibliográficas utilizando la API OpenAlex (gratis, no se necesita clave). Úselo cuando el usuario necesite encontrar artículos académicos por tema/autor/DOI, explorar cadenas de citas, obtener metadatos de artículos estructurados (título, autores, resumen, citas, DOI, URL de acceso abierto), obtener el texto completo de artículos de acceso abierto o realizar revisiones bibliográficas automatizadas con identificación y síntesis de temas. Activadores de solicitudes que involucran búsqueda académica, búsqueda de artículos, análisis de citas, revisión de literatura, síntesis de investigaciones o recopilación de referencias académicas.
