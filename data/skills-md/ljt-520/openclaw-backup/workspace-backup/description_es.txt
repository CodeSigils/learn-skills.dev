Copia de seguridad automatizada del espacio de trabajo en GitHub: basada en git con mensajes de confirmación generados automáticamente, .gitignore adecuado y procedimientos de restauración. Compatible con cron para realizar copias de seguridad con manos libres. Úselo para realizar una copia de seguridad de su espacio de trabajo, habilidades, memoria y configuración de OpenClaw.
