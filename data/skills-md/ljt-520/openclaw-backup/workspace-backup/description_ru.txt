Автоматическое резервное копирование рабочей области на GitHub — на основе git с автоматически генерируемыми сообщениями о фиксации, правильным .gitignore и процедурами восстановления. Поддержка Cron для резервного копирования без помощи рук. Используйте для резервного копирования вашего рабочего пространства, навыков, памяти и конфигурации OpenClaw.
