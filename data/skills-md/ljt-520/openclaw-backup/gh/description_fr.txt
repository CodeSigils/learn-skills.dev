Utilisez la CLI GitHub (gh) pour effectuer les opérations principales de GitHub : statut d'authentification, création/clonage/fork de dépôt, problèmes, demandes d'extraction, versions et gestion de base des dépôts. Déclenchez les demandes d'utilisation de gh, gérez les dépôts GitHub, les PR ou les problèmes à partir de la CLI.
