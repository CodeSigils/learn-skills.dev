Pipeline à commande unique, de l'idée au code validé. Exécute un flux de travail entièrement autonome en 7 étapes : conception basée sur Opus (entretien de clarté socratique + sélection d'approche), planification Opus, mise en œuvre parallèle de Sonnet par rapport aux contrats rédigés par Opus, validation Haiku, examen de sécurité Opus et validation Haiku - avec isolation de l'arbre de travail git et une boucle de nouvelle tentative auto-correctrice qui classe les échecs avant de les escalader. À utiliser lorsque l'utilisateur dit "the-shaman-pipe", "shaman pipe", "tsp", "full pipeline", "end-to-end" ou souhaite qu'une fonctionnalité soit implémentée depuis l'idée jusqu'au code validé sans étapes manuelles.
