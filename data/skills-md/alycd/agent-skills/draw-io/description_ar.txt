قم بإنشاء مخططات XML احترافية لـ Draw.io (diagrams.net) للهندسة المعمارية وتدفقات الشبكة وتصميمات النظام. يُستخدم عندما يطلب المستخدم إنشاء رسوم تخطيطية، أو رسوم تخطيطية للهندسة المعمارية، أو مخططات انسيابية، أو رسوم تخطيطية للشبكة، أو رسوم تخطيطية للنظام، أو يذكر Draw.io/diagrams.net. يدعم أيقونات AWS/GCP والتجميع والتصميم المخصص.
