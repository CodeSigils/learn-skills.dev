مهارة Shark UI للتسجيل بنمط shadcn المستند إلى Ark UI. يُستخدم عند تنفيذ المكونات أو تصحيح أخطائها (التراكبات، والقوائم، والنوافذ المنبثقة، والأوراق، ومربعات الحوار)، أو عناصر التحكم المستندة إلى المجموعة (مربع التحرير والسرد، أو التحديد، أو أنماط القائمة)، أو أنماط الحقول/النماذج، أو الشريط الجانبي أو مستندات المخططات، أو الرموز المميزة لـ Tailwind v4، أو ترحيل أمثلة Radix/shadcn إلى Shark. ينطبق أيضًا عند استخدام واجهة سطر الأوامر shadcn مع `@shark/*` أو `components.json` أو مسارات عمل add/search/diff على نمط التسجيل.
