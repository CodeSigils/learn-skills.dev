Abilità dell'interfaccia utente Shark per il registro in stile shadcn basato sull'interfaccia utente di Ark. Da utilizzare durante l'implementazione o il debug di componenti (sovrapposizioni, menu, popover, fogli, finestre di dialogo), controlli basati su raccolte (casella combinata, selezione, modelli di elenco), campi/moduli, modelli di documenti con barra laterale o grafico, token Tailwind v4 o migrazione di esempi Radix/shadcn su Shark. Si applica anche quando si utilizza la CLI shadcn con `@shark/*`, `components.json` o flussi di lavoro di aggiunta/ricerca/diff in stile registro.
