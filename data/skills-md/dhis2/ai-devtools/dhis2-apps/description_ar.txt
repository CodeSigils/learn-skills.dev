دليل لبناء تطبيقات DHIS2 المخصصة باستخدام منصة تطبيقات DHIS2. استخدم هذه المهارة عندما يريد المستخدم إنشاء تطبيق DHIS2 أو دعمه أو تمهيده، أو تشغيل تطبيق DHIS2 أو بدء تشغيله، أو البناء للإنتاج أو النشر، أو جلب البيانات من واجهة برمجة تطبيقات DHIS2، أو العمل مع البيانات المجمعة، أو بيانات التعقب، أو البيانات التعريفية، أو التحليلات، أو كتابة الطفرات، أو التعامل مع اختلافات الإصدار عبر مثيلات DHIS2. استخدمه أيضًا عندما يذكر المستخدم النظام الأساسي لتطبيق DHIS2 أو d2 أو dhis2 أو أي مصطلحات خاصة بـ DHIS2 - حتى لو لم يذكر "DHIS2 app" صراحةً.
