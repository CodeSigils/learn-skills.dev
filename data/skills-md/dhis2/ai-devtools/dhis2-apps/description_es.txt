Guía para crear aplicaciones personalizadas DHIS2 utilizando la plataforma de aplicaciones DHIS2. Utilice esta habilidad siempre que el usuario quiera crear, desarrollar o iniciar una aplicación DHIS2, ejecutar o iniciar una aplicación DHIS2, compilarla para producción o implementarla, recuperar datos de la API de DHIS2, trabajar con datos agregados, datos de seguimiento, metadatos o análisis, escribir mutaciones o manejar diferencias de versión entre instancias de DHIS2. Úselo también cuando el usuario mencione DHIS2, d2, plataforma de aplicaciones dhis2 o cualquier terminología específica de DHIS2, incluso si no dice explícitamente "aplicación DHIS2".
