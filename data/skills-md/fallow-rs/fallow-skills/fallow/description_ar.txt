ذكاء قاعدة التعليمات البرمجية لـ JavaScript وTypeScript. تقارير الطبقة الثابتة المجانية عن الجودة، ومخاطر تغيير التعليمات البرمجية، وفرص التنظيف (الملفات غير المستخدمة، والصادرات، والأنواع، والتبعيات)، وتكرار التعليمات البرمجية، والتبعيات الدائرية، ونقاط التعقيد الفعالة، وانتهاكات حدود البنية، وأنماط علامات الميزات، ومرشحي أمان الاشتراك. تقوم تغطية وقت التشغيل بدمج بيانات تنفيذ الإنتاج في نفس تقرير السلامة لمراجعة المسار السريع، والثقة في حذف المسار البارد، وأدلة العلامة التي لا معنى لها، مع توفر التقاط محلي واحد افتراضيًا ومراقبة وقت التشغيل المستمر/السحابي كوضع اختياري. 122 ملحقًا لإطار العمل، تكوين صفر، تحليل ثابت في الثانية الفرعية. استخدمه عندما يُطلب منك تحليل سلامة التعليمات البرمجية، أو تدقيق مخاطر العلاقات العامة، أو العثور على فرص التنظيف أو التعليمات البرمجية غير المستخدمة، أو اكتشاف التكرارات، أو التحقق من التبعيات الدائرية، أو تعقيد التدقيق، أو التحقق من حدود البنية، أو اكتشاف علامات الميزات، أو مرشحات أمان السطح، أو تنظيف قاعدة التعليمات البرمجية، أو إصلاح المشكلات تلقائيًا، أو دمج تغطية وقت التشغيل، أو التشغيل بدون استخدام.
