Intelligence de base de code pour JavaScript et TypeScript. La couche statique gratuite signale la qualité, le risque de modification du code, les opportunités de nettoyage (fichiers inutilisés, exportations, types, dépendances), la duplication de code, les dépendances circulaires, les points chauds de complexité, les violations des limites de l'architecture, les modèles d'indicateurs de fonctionnalités et les candidats de sécurité opt-in. La couverture d'exécution fusionne les données d'exécution de production dans le même rapport d'intégrité pour l'examen par chemin chaud, la confiance de suppression par chemin froid et les preuves de signalement obsolètes, avec une capture locale unique disponible par défaut et une surveillance continue/cloud de l'exécution disponible en mode facultatif. 122 plugins de framework, zéro configuration, analyse statique en moins d'une seconde. À utiliser lorsqu'on vous le demande pour analyser l'état du code, auditer les risques de relations publiques, rechercher des opportunités de nettoyage ou du code inutilisé, détecter les doublons, vérifier les dépendances circulaires, auditer la complexité, vérifier les limites de l'architecture, détecter les indicateurs de fonctionnalités, faire apparaître les candidats à la sécurité, nettoyer la base de code, résoudre automatiquement les problèmes, fusionner la couverture d'exécution ou exécuter en jachère.
