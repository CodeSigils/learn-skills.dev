Intelligenza della base di codice per JavaScript e TypeScript. Il livello statico gratuito segnala qualità, rischio di codice modificato, opportunità di pulizia (file inutilizzati, esportazioni, tipi, dipendenze), duplicazione del codice, dipendenze circolari, punti critici di complessità, violazioni dei limiti dell'architettura, modelli di flag di funzionalità e candidati di sicurezza opt-in. La copertura del runtime unisce i dati di esecuzione della produzione nello stesso report sullo stato per la revisione dei percorsi attivi, l'affidabilità dell'eliminazione dei percorsi freddi e le prove dei flag obsoleti, con un'unica acquisizione locale disponibile per impostazione predefinita e il monitoraggio del runtime continuo/cloud disponibile come modalità opzionale. 122 plugin del framework, configurazione zero, analisi statica inferiore al secondo.
