Referencia para AdKit CLI (`adkit-cli` en npm, comando `adkit`). Asigna comandos a operaciones publicitarias: creación de campañas, conjuntos de anuncios y anuncios en Meta, gestión de borradores, carga de medios, búsqueda de intereses. Se carga cuando el usuario desea ejecutar operaciones publicitarias a través de la terminal o cuando `adkit` está instalado y el usuario está listo para publicar. No para estrategia, redacción, consejos creativos o aprendizaje sobre anuncios.
