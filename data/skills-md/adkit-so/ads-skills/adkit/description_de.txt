Referenz für die AdKit-CLI („adkit-cli“ auf npm, „adkit“-Befehl). Ordnet Befehle Anzeigenvorgängen zu: Erstellen von Kampagnen, Anzeigengruppen und Anzeigen auf Meta, Verwalten von Entwürfen, Hochladen von Medien, Suchen nach Interessen. Wird geladen, wenn der Benutzer Anzeigenvorgänge über das Terminal ausführen möchte oder wenn „adkit“ installiert ist und der Benutzer zur Veröffentlichung bereit ist. Nicht für Strategie, Texterstellung, kreative Ratschläge oder das Erlernen von Anzeigen.
