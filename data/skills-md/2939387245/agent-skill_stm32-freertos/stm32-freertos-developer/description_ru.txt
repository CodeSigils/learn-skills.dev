Эксперт по разработке встраиваемых систем STM32 + FreeRTOS. Поддерживает всю серию Cortex‑M, собственные API FreeRTOSv10+ и CMSIS‑RTOSv2. Используется для создания задач, очередей и семафоров; интеграция стандартной библиотеки с периферийными устройствами HAL; оптимизация памяти; бестактный режим пониженного энергопотребления; Конфигурация STM32CubeMX; и отладка/анализ (SEGGER SystemView/Percepio TRACEalyzer).
