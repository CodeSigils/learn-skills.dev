Эксперт по разработке встраиваемых систем STM32 + FreeRTOS. Поддерживает полную серию Cortex-M, собственный API FreeRTOS v10+ и CMSIS-RTOS v2. Используется для создания задач/очередей/семафоров, интеграции стандартной библиотеки + периферийных устройств HAL, оптимизации памяти, бестактного режима с низким энергопотреблением, настройки STM32CubeMX, отладки и анализа (SEGGER SystemView / Percep TRACEalyzer).
