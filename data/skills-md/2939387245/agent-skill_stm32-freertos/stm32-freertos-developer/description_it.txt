Esperto di sviluppo integrato STM32 + FreeRTOS. Supporta la serie completa Cortex-M, le API native FreeRTOS v10+ e CMSIS-RTOS v2. Utilizzato per la creazione di attività/code/semafori, integrazione di librerie standard + periferiche HAL, ottimizzazione della memoria, modalità Tickless a basso consumo, configurazione STM32CubeMX, debug e analisi (SEGGER SystemView / Percepio TRACEalyzer).
