Esperto di sviluppo integrato STM32 + FreeRTOS. Supporta l'intera serie Cortex‑M, le API native FreeRTOSv10+ e CMSIS‑RTOSv2. Utilizzato per creare attività, code e semafori; integrazione della libreria standard con le periferiche HAL; ottimizzazione della memoria; modalità tickless a basso consumo; Configurazione STM32CubeMX; e debug/analisi (SEGGER SystemView / Percepio TRACEalyzer).
