STM32 + FreeRTOS Embedded-Entwicklungsexperte. Unterstützt die vollständige Cortex-M-Serie, native FreeRTOS v10+ und CMSIS-RTOS v2 API. Wird zum Erstellen von Aufgaben/Warteschlangen/Semaphoren, zur Integration von Standardbibliothek + HAL-Peripheriegeräten, zur Speicheroptimierung, zum Tickless-Modus mit geringem Stromverbrauch, zur STM32CubeMX-Konfiguration, zum Debuggen und zur Analyse (SEGGER SystemView / Percep TRACEalyzer) verwendet.
