人間と AI のハイブリッド チームのための組織設計およびタスク管理プラットフォームである Org Studio と対話します。タスクの作成/更新、ロードマップの読み取り/書き込み、ビジョン ドキュメントの管理、エージェント メトリクスのクエリ、またはイベント ドリブンのタスク ディスパッチの仕組みを理解するときに使用します。ストア (タスク/プロジェクト)、ロードマップ (バージョン)、ビジョン ドキュメント、称賛/フラグ、指標、コーチングの洞察、毎週のダイジェストを含むすべての Org Studio REST API をカバーします。また、プッシュベースのトリガー システムについても説明します。タスクの割り当てにより、ポーリングは不要で自動的にエージェントが起動されます。
