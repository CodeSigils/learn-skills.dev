تفاعل مع Org Studio - منصة التصميم المؤسسي وإدارة المهام لفرق العمل البشرية والذكاء الاصطناعي المختلطة. يُستخدم عند إنشاء/تحديث المهام، أو قراءة/كتابة خرائط الطريق، أو إدارة مستندات الرؤية، أو الاستعلام عن مقاييس الوكيل، أو فهم كيفية عمل إرسال المهام المستند إلى الحدث. يغطي جميع واجهات برمجة تطبيقات Org Studio REST بما في ذلك المتجر (المهام/المشاريع)، وخريطة الطريق (الإصدارات)، ومستندات الرؤية، والشهرة/الإشارات، والمقاييس، ورؤى التدريب، والملخصات الأسبوعية. يشرح أيضًا نظام التشغيل القائم على الدفع - تقوم تعيينات المهام بتنشيط العملاء تلقائيًا، دون الحاجة إلى الاستقصاء.
