Взаимодействуйте с Org Studio — платформой организационного проектирования и управления задачами для гибридных команд человека и искусственного интеллекта. Используйте при создании/обновлении задач, чтении/написании планов действий, управлении документами технического зрения, запросе метрик агента или понимании того, как работает диспетчеризация задач на основе событий. Охватывает все API REST Org Studio, включая магазин (задачи/проекты), дорожную карту (версии), документацию по концепции, похвалы/флаги, метрики, рекомендации по коучингу и еженедельные дайджесты. Также объясняется система триггеров на основе push — назначения задач автоматически пробуждают агентов, опрос не требуется.
