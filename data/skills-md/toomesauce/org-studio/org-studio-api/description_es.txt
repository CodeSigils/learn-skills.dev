Interactúe con Org Studio, la plataforma de gestión de tareas y diseño de organización para equipos híbridos humanos + IA. Úselo al crear/actualizar tareas, leer/escribir hojas de ruta, administrar documentos de visión, consultar métricas de agentes o comprender cómo funciona el envío de tareas basado en eventos. Cubre todas las API REST de Org Studio, incluida la tienda (tareas/proyectos), hoja de ruta (versiones), documentos de visión, felicitaciones/banderas, métricas, conocimientos de capacitación y resúmenes semanales. También explica el sistema de activación basado en push: las asignaciones de tareas activan automáticamente a los agentes, sin necesidad de realizar sondeos.
