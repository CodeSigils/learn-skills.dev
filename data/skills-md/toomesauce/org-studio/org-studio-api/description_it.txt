Interagisci con Org Studio: la piattaforma di progettazione dell'organizzazione e di gestione delle attività per team ibridi umani+AI. Da utilizzare durante la creazione/l'aggiornamento di attività, la lettura/scrittura di roadmap, la gestione di documenti visivi, l'esecuzione di query sulle metriche degli agenti o la comprensione del funzionamento dell'invio di attività basate sugli eventi. Copre tutte le API REST di Org Studio, inclusi negozio (attività/progetti), roadmap (versioni), documenti visivi, complimenti/segnalazioni, metriche, approfondimenti sul coaching e riassunti settimanali. Spiega inoltre il sistema di trigger basato su push: le assegnazioni delle attività riattivano automaticamente gli agenti, senza necessità di polling.
