Interagissez avec Org Studio, la plateforme de conception organisationnelle et de gestion des tâches pour les équipes hybrides humain+IA. À utiliser pour créer/mettre à jour des tâches, lire/écrire des feuilles de route, gérer des documents de vision, interroger des métriques d'agent ou comprendre le fonctionnement de la répartition des tâches basée sur les événements. Couvre toutes les API REST d'Org Studio, y compris le magasin (tâches/projets), la feuille de route (versions), les documents de vision, les félicitations/drapeaux, les métriques, les informations de coaching et les résumés hebdomadaires. Explique également le système de déclenchement basé sur le push : les affectations de tâches réveillent automatiquement les agents, aucune interrogation n'est nécessaire.
