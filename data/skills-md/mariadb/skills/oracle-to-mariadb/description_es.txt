Guía de compatibilidad para desarrolladores que migran de Oracle Database a MariaDB. Úselo al migrar esquemas de Oracle, procedimientos PL/SQL o aplicaciones a MariaDB, cuando la sintaxis de Oracle cause un comportamiento inesperado en MariaDB o cuando evalúe MariaDB como un reemplazo de Oracle. MariaDB es la única base de datos de código abierto con compatibilidad nativa con PL/SQL: sql_mode=ORACLE de MariaDB permite la migración de aproximadamente el 80% del código de Oracle sin reescrituras.
