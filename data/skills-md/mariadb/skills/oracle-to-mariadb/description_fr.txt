Guide de compatibilité pour les développeurs migrant d'Oracle Database vers MariaDB. À utiliser lors de la migration de schémas Oracle, de procédures PL/SQL ou d'applications vers MariaDB, lorsque la syntaxe Oracle provoque un comportement inattendu dans MariaDB ou lors de l'évaluation de MariaDB en remplacement d'Oracle. MariaDB est la seule base de données open source avec une compatibilité native PL/SQL : sql_mode=ORACLE de MariaDB permet la migration d'environ 80 % du code Oracle sans réécriture.
