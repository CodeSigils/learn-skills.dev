Руководство по совместимости для разработчиков, переходящих с базы данных Oracle на MariaDB. Используйте при переносе схем Oracle, процедур PL/SQL или приложений в MariaDB, когда синтаксис Oracle вызывает неожиданное поведение в MariaDB или при оценке MariaDB в качестве замены Oracle. MariaDB — единственная база данных с открытым исходным кодом, имеющая встроенную совместимость с PL/SQL: sql_mode=ORACLE в MariaDB позволяет перенести примерно 80 % кода Oracle без переписывания.
