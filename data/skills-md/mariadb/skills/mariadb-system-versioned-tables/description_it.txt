Best practice per le tabelle temporali (con controllo delle versioni) di sistema MariaDB: cronologia automatica delle righe integrata nel database. Da utilizzare quando si tengono traccia delle modifiche dei dati nel tempo, si implementano audit trail, si soddisfano i requisiti GDPR o di conformità, si eseguono query point-in-time o quando l'utente chiede informazioni sulla cronologia delle righe, sul controllo delle versioni dei dati, sulle tabelle temporali o esegue query sugli stati dei dati passati in MariaDB. Questa funzionalità è unica per MariaDB tra i database compatibili con MySQL.
