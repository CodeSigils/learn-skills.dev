Mejores prácticas para tablas (temporales) versionadas por el sistema MariaDB: historial de filas automático integrado en la base de datos. Úselo cuando realice un seguimiento de los cambios de datos a lo largo del tiempo, implemente pistas de auditoría, cumpla con el RGPD o los requisitos de cumplimiento, realice consultas en un momento dado o cuando el usuario pregunte sobre el historial de filas, el control de versiones de datos, las tablas temporales o consulte estados de datos anteriores en MariaDB. Esta característica es exclusiva de MariaDB entre las bases de datos compatibles con MySQL.
