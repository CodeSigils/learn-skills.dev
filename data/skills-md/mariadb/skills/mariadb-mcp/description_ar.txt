كيفية توصيل وكلاء الذكاء الاصطناعي بـ MariaDB باستخدام بروتوكول السياق النموذجي (MCP). يُستخدم عند إعداد MCP مع MariaDB، أو توصيل Claude Code، أو Cursor، أو أدوات الذكاء الاصطناعي الأخرى بقاعدة بيانات MariaDB، أو تمكين استعلامات قاعدة بيانات اللغة الطبيعية، أو إنشاء تطبيقات الذكاء الاصطناعي التي تحتاج إلى الوصول المباشر إلى قاعدة البيانات. يتيح خادم MariaDB MCP للوكلاء الاستعلام عن المخططات وتشغيل SQL للقراءة فقط وإجراء بحث دلالي على MariaDB.
