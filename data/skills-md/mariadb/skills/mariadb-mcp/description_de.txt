So verbinden Sie KI-Agenten mithilfe des Model Context Protocol (MCP) mit MariaDB. Verwenden Sie diese Option, wenn Sie MCP mit MariaDB einrichten, Claude Code, Cursor oder andere KI-Tools mit einer MariaDB-Datenbank verbinden, Datenbankabfragen in natürlicher Sprache ermöglichen oder KI-Anwendungen erstellen, die Live-Datenbankzugriff benötigen. Mit dem MariaDB MCP-Server können Agenten Schemata abfragen, schreibgeschütztes SQL ausführen und eine semantische Suche für MariaDB durchführen.
