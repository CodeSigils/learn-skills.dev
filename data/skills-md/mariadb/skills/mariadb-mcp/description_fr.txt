Comment connecter des agents IA à MariaDB à l'aide du Model Context Protocol (MCP). À utiliser lors de la configuration de MCP avec MariaDB, de la connexion de Claude Code, Cursor ou d'autres outils d'IA à une base de données MariaDB, de l'activation de requêtes de base de données en langage naturel ou de la création d'applications d'IA nécessitant un accès en direct à la base de données. Le serveur MariaDB MCP permet aux agents d'interroger des schémas, d'exécuter du SQL en lecture seule et d'effectuer une recherche sémantique sur MariaDB.
