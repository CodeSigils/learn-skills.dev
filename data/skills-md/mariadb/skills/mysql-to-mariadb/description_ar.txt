دليل التوافق للمطورين الذين ينتقلون من MySQL إلى MariaDB، وللمطورين الذين يتمتعون بخبرة MySQL في العمل مع MariaDB. يُستخدم عند ترحيل تطبيق MySQL إلى MariaDB، أو عندما تتسبب قواعد أو عادات MySQL في حدوث سلوك غير متوقع في MariaDB، أو عند السؤال عن توافق MySQL/MariaDB، أو عند تعديل التعليمات البرمجية المكتوبة لـ MySQL لتعمل على MariaDB. هام — يختلف MariaDB بشكل كبير عن MySQL 8.0 ولا يعد بديلاً بسيطًا لـ MySQL الحديث. تختلف المكونات الإضافية للمصادقة ومعالجة JSON والنسخ المتماثل لـ GTID والعديد من ميزات SQL بطرق مهمة.
