Руководство по совместимости для разработчиков, переходящих с MySQL на MariaDB, а также для разработчиков, имеющих опыт MySQL, работающих с MariaDB. Используйте при переносе приложения MySQL в MariaDB, когда синтаксис или привычки MySQL вызывают неожиданное поведение в MariaDB, при запросе о совместимости MySQL/MariaDB или при адаптации кода, написанного для MySQL, для работы в MariaDB. ВАЖНО. MariaDB существенно отличается от MySQL 8.0 и не является простой заменой современного MySQL. Плагины аутентификации, обработка JSON, репликация GTID и некоторые функции SQL существенно отличаются.
