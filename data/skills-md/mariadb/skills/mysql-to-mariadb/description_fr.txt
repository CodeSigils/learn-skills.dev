Guide de compatibilité pour les développeurs passant de MySQL à MariaDB et pour les développeurs ayant une expérience MySQL travaillant avec MariaDB. À utiliser lors de la migration d'une application MySQL vers MariaDB, lorsque la syntaxe ou les habitudes MySQL provoquent un comportement inattendu dans MariaDB, lorsque vous posez des questions sur la compatibilité MySQL/MariaDB ou lors de l'adaptation du code écrit pour MySQL pour qu'il s'exécute sur MariaDB. IMPORTANT — MariaDB s'écarte considérablement de MySQL 8.0 et ne constitue pas un simple remplacement instantané du MySQL moderne. Les plugins d'authentification, la gestion JSON, la réplication GTID et plusieurs fonctionnalités SQL diffèrent de manière importante.
