MySQL에서 MariaDB로 이동하는 개발자와 MariaDB를 사용한 MySQL 경험이 있는 개발자를 위한 호환성 가이드입니다. MySQL 애플리케이션을 MariaDB로 마이그레이션할 때, MySQL 구문이나 습관으로 인해 MariaDB에서 예기치 않은 동작이 발생하는 경우, MySQL/MariaDB 호환성에 대해 질문할 때 또는 MariaDB에서 실행되도록 MySQL용으로 작성된 코드를 조정할 때 사용합니다. 중요 — MariaDB는 MySQL 8.0과 크게 다르며 최신 MySQL을 간단히 대체할 수는 없습니다. 인증 플러그인, JSON 처리, GTID 복제 및 여러 SQL 기능은 중요한 면에서 다릅니다.
