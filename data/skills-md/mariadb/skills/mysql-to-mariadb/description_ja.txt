MySQL から MariaDB に移行する開発者、および MySQL で MariaDB の使用経験がある開発者を対象とした互換性ガイド。 MySQL アプリケーションを MariaDB に移行する場合、MySQL の構文または習慣により MariaDB で予期しない動作が発生する場合、MySQL/MariaDB の互換性について問い合わせる場合、または MySQL 用に書かれたコードを MariaDB で実行できるように調整する場合に使用します。重要 — MariaDB は MySQL 8.0 とは大きく異なり、最新の MySQL を単純に置き換えるものではありません。認証プラグイン、JSON 処理、GTID レプリケーション、およびいくつかの SQL 機能は、重要な点で異なります。
