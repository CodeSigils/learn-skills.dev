Guía de compatibilidad para desarrolladores que migran de MySQL a MariaDB y para desarrolladores con experiencia en MySQL trabajando con MariaDB. Úselo cuando migre una aplicación MySQL a MariaDB, cuando la sintaxis o los hábitos de MySQL causen un comportamiento inesperado en MariaDB, cuando pregunte sobre la compatibilidad de MySQL/MariaDB o cuando adapte el código escrito para MySQL para que se ejecute en MariaDB. IMPORTANTE: MariaDB difiere significativamente de MySQL 8.0 y no es un simple reemplazo directo del MySQL moderno. Los complementos de autenticación, el manejo de JSON, la replicación de GTID y varias características de SQL difieren en aspectos importantes.
