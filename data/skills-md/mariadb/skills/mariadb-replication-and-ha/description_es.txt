Mejores prácticas para la replicación y alta disponibilidad de MariaDB: Galera Cluster, replicación GTID, replicación semisincrónica, replicación paralela y patrones de aplicación para entornos HA. Úselo al configurar la replicación, diseñar aplicaciones para HA, trabajar con Galera Cluster, preguntar sobre MariaDB GTID, manejar el retraso de replicación en el código de la aplicación o elegir entre topologías de replicación. IMPORTANTE: el formato MariaDB GTID es incompatible con MySQL GTID y Galera Cluster no necesita ningún complemento de servidor para cargarse, pero sí requiere la biblioteca del proveedor galera wsrep separada (galera-4).
