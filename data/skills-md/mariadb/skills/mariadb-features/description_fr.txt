Fonctionnalités et capacités spécifiques à MariaDB qui vont au-delà du MySQL standard. À utiliser lors de l'évaluation de MariaDB, de l'optimisation d'une application MariaDB existante, de la révision du code ou du schéma pour les améliorations de MariaDB, de la demande de ce que MariaDB peut faire que d'autres bases de données ne peuvent pas faire ou de la migration d'Oracle vers MariaDB. À utiliser également lorsque l'utilisateur demande ce qui pourrait être amélioré dans la façon dont une base de code utilise MariaDB, ou pose des questions sur les avantages de MariaDB par rapport à MySQL ou PostgreSQL.
