ميزات وإمكانيات خاصة بـ MariaDB تتجاوز MySQL القياسية. يُستخدم عند تقييم MariaDB، أو تحسين تطبيق MariaDB موجود، أو مراجعة التعليمات البرمجية أو المخطط لتحسينات MariaDB، أو السؤال عما يمكن أن تفعله MariaDB ولا تستطيع قواعد البيانات الأخرى القيام به، أو الترحيل من Oracle إلى MariaDB. يُستخدم أيضًا عندما يسأل المستخدم عما يمكن تحسينه في كيفية استخدام قاعدة التعليمات البرمجية لـ MariaDB، أو يسأل عن مزايا MariaDB مقارنة بـ MySQL أو PostgreSQL.
