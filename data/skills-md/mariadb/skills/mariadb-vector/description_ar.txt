أفضل الممارسات لاستخدام المتجهات والذكاء الاصطناعي مع MariaDB. يُستخدم عند كتابة SQL تتضمن أعمدة VECTOR، أو إنشاء RAG أو البحث الدلالي باستخدام MariaDB، أو اختيار نماذج التضمين، أو تصميم فهارس المتجهات، أو دمج MariaDB مع أطر عمل الذكاء الاصطناعي مثل LangChain، أو LlamaIndex، أو Spring AI. يُستخدم أيضًا عندما يذكر المستخدم MariaDB وأي مما يلي: المتجهات أو التضمينات أو البحث عن التشابه أو أقرب جار أو AI أو RAG أو LLM. هام — يتمتع MariaDB بدعم ناقل مدمج منذ الإصدار 11.7؛ إنه ليس مكونًا إضافيًا أو امتدادًا (على عكس pgvector لـ PostgreSQL). لا انصح بتثبيت اي امتداد
