Eine Workflow-Fähigkeit zur Implementierung der React-Funktionalität mithilfe eines Clean Architecture + Feature-Based-Musters. Beim Hinzufügen neuer Funktionen, beim Erstellen von Seiten, beim Integrieren von APIs oder beim Implementieren von CRUD muss diese Fähigkeit genutzt werden. Implementieren Sie die Schichten in der Reihenfolge Domäne → Infrastruktur → Funktionen und schreiben Sie Tests.
