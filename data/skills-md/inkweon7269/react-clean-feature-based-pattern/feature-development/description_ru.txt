Навыки рабочего процесса для реализации функций React с использованием шаблона Clean Architecture + Feature-Based. Обязательно используйте этот навык при добавлении новых функций, создании страниц, интеграции API или реализации CRUD. Реализуйте уровни в домене заказа → инфраструктура → функции и напишите тесты.
