Générez un système de couverture cognitive pour n'importe quel projet : un manifeste JSON permettant de suivre la compréhension des fichiers, des concepts et des flux de données ; un guide pédagogique HTML interactif avec quiz ; et un tableau de bord HTML montrant l'état de la couverture avec analyse des écarts. Fonctionne pour les bases de code, les collections de documents de recherche, les wikis de documentation et tout domaine de connaissances. À utiliser lorsque quelqu'un souhaite comprendre un projet qu'il n'a pas créé, réduire sa dette cognitive, suivre ce qu'il a compris ou générer un guide d'apprentissage. Déclencheurs : « expliquer cette base de code », « couverture cognitive », « guide d'apprentissage », « guide pédagogique », « dette cognitive », « compréhension du système », « quiz sur la base de code », « tableau de bord de couverture », « aidez-moi à comprendre ce projet », « présentation pas à pas de la base de code », « suivre la compréhension », « carte des connaissances », « couverture de la recherche », « guide de documentation ».
