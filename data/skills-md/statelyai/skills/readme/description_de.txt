Halten Sie README-Dateien mithilfe symbolischer HTML-Kommentare mit dem Repository synchron. Verwenden Sie diese Fähigkeit immer dann, wenn Sie eine Repo-Änderung vornehmen, die Auswirkungen auf die Dokumentation haben könnte – Code (exportierte APIs, Konfiguration, Beispiele, CLI-Befehle, Abhängigkeiten), Repo-Struktur (Hinzufügen/Entfernen/Umbenennen von Dateien, Verzeichnissen, Paketen oder anderen gleichgeordneten Einträgen, auf die in einem Listenkommentar verwiesen wird) oder Metadaten (package.json, Manifeste). Verwenden Sie diese Funktion auch beim Erstellen oder Bearbeiten von README-Dateien, um symbolische Kommentare hinzuzufügen oder zu aktualisieren. Wird bei jeder Änderung – Code oder Struktur – ausgelöst, die ein Konstrukt betrifft, auf das durch einen HTML-Kommentar in einer Markdown-Datei verwiesen wird.
