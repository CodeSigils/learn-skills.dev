Mantenga los archivos README sincronizados con el repositorio mediante comentarios HTML simbólicos. Utilice esta habilidad siempre que realice un cambio en el repositorio que pueda afectar la documentación: código (API exportadas, configuración, ejemplos, comandos CLI, dependencias), estructura del repositorio (agregar, eliminar o cambiar el nombre de archivos, directorios, paquetes u otras entradas hermanas a las que se hace referencia en un comentario de lista) o metadatos (paquete.json, manifiestos). Utilícelo también al crear o editar archivos README para agregar o actualizar comentarios simbólicos. Activa cualquier cambio (de código o estructural) que afecte a una construcción a la que hace referencia un comentario HTML en un archivo de rebajas.
