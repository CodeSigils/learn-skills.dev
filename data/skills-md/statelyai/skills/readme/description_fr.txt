Gardez les fichiers README synchronisés avec le dépôt à l'aide de commentaires HTML symboliques. Utilisez cette compétence chaque fois que vous effectuez une modification du référentiel susceptible d'affecter la documentation : code (API exportées, configuration, exemples, commandes CLI, dépendances), structure du référentiel (ajout/suppression/renommage de fichiers, répertoires, packages ou autres entrées frères référencées par un commentaire de liste) ou métadonnées (package.json, manifestes). À utiliser également lors de la création ou de la modification de fichiers README pour ajouter ou mettre à jour des commentaires symboliques. Déclenchez tout changement (code ou structurel) qui touche une construction référencée par un commentaire HTML dans un fichier markdown.
