Mantieni i file README sincronizzati con il repository utilizzando commenti HTML simbolici. Utilizza questa competenza ogni volta che apporti una modifica al repository che potrebbe influire sulla documentazione: codice (API esportate, configurazione, esempi, comandi CLI, dipendenze), struttura del repository (aggiunta/rimozione/rinomina di file, directory, pacchetti o altre voci di pari livello a cui fa riferimento un commento di elenco) o metadati (package.json, manifest). Utilizzare anche durante la creazione o la modifica di file README per aggiungere o aggiornare commenti simbolici. Si attiva su qualsiasi modifica, di codice o strutturale, che tocca un costrutto a cui fa riferimento un commento HTML in un file markdown.
