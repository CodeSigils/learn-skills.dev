シンボリック HTML コメントを使用して、README ファイルをリポジトリと同期させます。ドキュメント (エクスポートされた API、構成、サンプル、CLI コマンド、依存関係)、リポジトリ構造 (ファイル、ディレクトリ、パッケージ、またはリスト コメントによって参照される他の兄弟エントリの追加/削除/名前変更)、またはメタデータ (package.json、マニフェスト) に影響を与える可能性のあるリポジトリの変更を行う場合は常に、このスキルを使用します。 README ファイルを作成または編集して、シンボリック コメントを追加または更新する場合にも使用します。マークダウン ファイル内の HTML コメントによって参照される構成に関わる変更 (コードまたは構造) が発生するとトリガーされます。
