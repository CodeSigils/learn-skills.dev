Синхронизируйте файлы README с репозиторием, используя символические комментарии HTML. Используйте этот навык всякий раз, когда вносите изменения в репозиторий, которые могут повлиять на документацию — код (экспортированные API, конфигурацию, примеры, команды CLI, зависимости), структуру репозитория (добавление, удаление или переименование файлов, каталогов, пакетов или других одноуровневых записей, на которые ссылается комментарий листинга) или метаданные (package.json, манифесты). Также используйте при создании или редактировании файлов README для добавления или обновления символических комментариев. Запускается при любом изменении кода или структуры, которое затрагивает конструкцию, на которую ссылается комментарий HTML в файле уценки.
