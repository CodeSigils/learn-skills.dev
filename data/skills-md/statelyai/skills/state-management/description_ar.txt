حالة التطبيق النموذجية والمراجعة وإعادة البناء بحيث تظل الحالة المصدر في حدها الأدنى، ويتم حساب الحالة المشتقة بدلاً من المزامنة، ولا تكون الحالات المستحيلة قابلة للتمثيل، وتعيش كل قطعة من الحالة في المكان المناسب. استخدم هذا عندما يذكر المستخدم إدارة الحالة، أو المخفضات، أو المخازن، أو Redux، أو Zustand، أو حالة React، أو حالة Vue، أو Pinia، أو المحددات، أو الحالة المشتقة، أو الحالة المكررة، أو العلامات المنطقية، أو الحالات غير الصالحة، أو الحالة غير المتزامنة، أو حساء useEffect، أو النماذج، أو المعالجات، أو المرشحات، أو حالة URL، أو حالة الخادم، أو منطق واجهة المستخدم المربك، حتى لو لم يطلبوا صراحةً "نموذج الحالة".
