AWS Bedrock-Modell-IDs und regionsübergreifende Inferenzprofile. Verwenden Sie diese Fähigkeit immer dann, wenn Code auf AWS Bedrock-Modell-IDs (modelId), regionsübergreifende Inferenz oder Modellauswahl verweist. Auslöser bei: amazon.nova-*, anthropic.claude-*, cohere.*, deepseek.*, meta.llama*, mistral.*, qwen.*, jedem Bedrock InvokeModel/Converse-Aufruf, BedrockRuntimeClient oder Fragen dazu, welches Modell auf Bedrock verwendet werden soll. Erraten oder erfinden Sie NIEMALS Modell-IDs – sie sind bei allen Anbietern inkonsistent (einige haben Datumsangaben, andere nicht, einige haben das Suffix :0, andere nicht). Überprüfen Sie immer zuerst diese Fähigkeit.
