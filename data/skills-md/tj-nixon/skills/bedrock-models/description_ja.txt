AWS Bedrock モデル ID とクロスリージョン推論プロファイル。コードが AWS Bedrock モデル ID (modelId)、クロスリージョン推論、またはモデル選択を参照する場合は必ずこのスキルを使用します。トリガーの条件: amazon.nova-*、anthropic.claude-*、cohere.*、deepseek.*、meta.llama*、mistral.*、qwen.*、Bedrock InvokeModel/Converse 呼び出し、BedrockRuntimeClient、または Bedrock で使用するモデルに関する質問。モデル ID は決して推測したり考え出したりしないでください。モデル ID はプロバイダー間で一貫性がありません (日付を持つものと持たないもの、接尾辞 :0 を持つものと持たないものがあります)。必ず最初にこのスキルを確認してください。
