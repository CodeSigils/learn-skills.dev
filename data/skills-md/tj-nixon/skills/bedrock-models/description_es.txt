ID de modelo de AWS Bedrock y perfiles de inferencia entre regiones. Utilice esta habilidad siempre que el código haga referencia a los ID de modelo de AWS Bedrock (modelId), a la inferencia entre regiones o a la selección de modelo. Activadores en: amazon.nova-*, anthropic.claude-*, cohere.*, deepseek.*, meta.llama*, mistral.*, qwen.*, cualquier llamada de Bedrock InvokeModel/Converse, BedrockRuntimeClient o preguntas sobre qué modelo usar en Bedrock. NUNCA adivine ni invente ID de modelo: son inconsistentes entre proveedores (algunos tienen fechas, otros no, algunos tienen el sufijo :0, otros no). Siempre revisa esta habilidad primero.
