Richtlinien zur Qualitäts- und Leistungsoptimierung von TypeScript-Code zum Schreiben von typsicherem, wartbarem Code. Verwenden Sie es, wenn Sie neue TypeScript-Dateien schreiben, vorhandenen Code überprüfen, Refactoring durchführen, um die Typsicherheit zu verbessern, die Build-Leistung optimieren oder die TypeScript-Konfiguration einrichten. Wird bei Aufgaben ausgelöst, die TypeScript, tsconfig, Typdefinitionen, Generika oder Typsystemdesign betreffen.
