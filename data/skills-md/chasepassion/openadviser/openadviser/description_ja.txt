手動で作成したコンパクトな意思決定要旨を使用して、外部アドバイザーとして ChatGPT Web、Grok、または OpenAdviser がサポートする別の Web AI プロバイダーに相談します。 AI エージェントが行き詰まっている場合、エンジニアリング/製品/設計の決定に直面している場合、セカンドオピニオンが必要な場合、現在の Web 対応リサーチが必要な場合、ディープ Web リサーチが必要な場合、オンラインのベストプラクティスの発見が必要な場合、問題を解決するために Web 情報を収集する必要がある場合、続行する前にアプローチを検証する必要がある場合、または X/Twitter 上の投稿を検索する必要がある場合に使用します。 ChatGPT をディープ Web リサーチとベスト プラクティス リサーチに使用します。 Grok for X 投稿検索を使用し、プロンプトに「X で投稿を検索」を含めます。呼び出し元は、非表示のセッション ファイルを読み取るのではなく、コンテキスト概要を明示的に書き込む必要があります。
