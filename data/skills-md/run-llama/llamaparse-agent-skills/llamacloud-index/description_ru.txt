Используйте этот навык всякий раз, когда необходимо ответить на вопрос из документов, хранящихся в базе знаний LlamaCloud Index v2 — извлечение фрагментов, поиск индексированных файлов или поиск индексированного контента с помощью инструментов LlamaParse MCP Index v2 (retriveFromIndex, findFilesInIndex, grepFileFromIndex...). Обучает агентному поиску — навигации по индексу как по файловой системе вместо однократного RAG.
