Utilisez cette compétence chaque fois qu'il faut répondre à une question à partir de documents stockés dans une base de connaissances LlamaCloud Index v2 - récupérer des passages, localiser des fichiers indexés ou rechercher du contenu indexé via les outils LlamaParse MCP Index v2 (retrieveFromIndex, findFilesInIndex, grepFileFromIndex...). Enseigne la récupération agentique : naviguer dans un index comme un système de fichiers au lieu d'un RAG unique.
