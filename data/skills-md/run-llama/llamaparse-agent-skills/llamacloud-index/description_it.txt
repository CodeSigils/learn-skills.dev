Utilizza questa abilità ogni volta che è necessario rispondere a una domanda da documenti archiviati in una knowledge base LlamaCloud Index v2: recupero di passaggi, individuazione di file indicizzati o ricerca di contenuti indicizzati tramite gli strumenti LlamaParse MCP Index v2 (retrieveFromIndex, findFilesInIndex, grepFileFromIndex...). Insegna il recupero degli agenti: la navigazione in un indice come un file system anziché RAG one-shot.
