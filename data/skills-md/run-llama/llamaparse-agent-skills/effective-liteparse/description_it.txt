Utilizza questa abilità ogni volta che un'attività coinvolge un file di documento (PDF, DOCX, PPTX, XLSX o immagine) e devi leggerlo o estrarne testo, tabelle o valori specifici, per rispondere a una domanda sul suo contenuto, cercare una figura o estrarre dati. Fornisce un'estrazione rapida, locale e senza modelli tramite la CLI "illuminata" con modelli di ricerca disciplinati e a basso costo.
