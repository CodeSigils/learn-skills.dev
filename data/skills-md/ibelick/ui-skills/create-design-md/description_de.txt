Erstellen oder aktualisieren Sie eine DESIGN.md aus einem vorhandenen Produkt-Repository oder einer öffentlichen Website. Verwenden Sie es, wenn Sie aufgefordert werden, die Designsprache einer Schnittstelle zu dokumentieren, ihr visuelles System zu rekonstruieren, Design-Tokens und Anleitungen aus aktuellen Erkenntnissen zu extrahieren oder Programmieragenten einen dauerhaften UI-Kontext bereitzustellen. Ändern Sie nicht die Produktquelle und fördern Sie keine versehentlichen Implementierungsmuster in Designentscheidungen.
