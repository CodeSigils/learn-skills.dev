قم بمراجعة سطح المنتج الحالي مقابل أدلة التصميم الخاصة به، وتحديد مشكلات واجهة المستخدم التي تم التحقق منها، وكتابة خطط تنفيذ قائمة بذاتها لوكيل آخر. دقة القراءة فقط على مصدر المنتج. يُستخدم عند مطالبتك بمراجعة الواجهة أو تحسينها أو تحسينها أو تنظيفها دون استبدال هويتها؛ التحقيق في انجراف نظام التصميم. أو إعداد تسليم التصميم.
