Windows C : nettoyage du disque du lecteur à l'aide d'outils gratuits/open source et de scripts PowerShell. Remplace le logiciel payant « optimiseur de système ». À utiliser lorsque les utilisateurs demandent : nettoyer le lecteur C, libérer de l'espace disque, nettoyer Windows, supprimer les fichiers temporaires, nettoyer le cache du navigateur, nettoyer les fichiers indésirables du système, réduire l'utilisation du disque, nettoyer WinSxS, désactiver la mise en veille prolongée, rechercher des fichiers volumineux, supprimer les bloatwares ou toute tâche de récupération d'espace disque Windows. Déclenche également les équivalents chinois : C盘清理, 磁盘清理, 清理垃圾, 系统瘦身, 释放空间, 临时文件清理. Couvre : les fichiers temporaires, les caches du navigateur, le cache Windows Update, les journaux système, les caches d'applications (WeChat/QQ/DingTalk/Teams/Discord), les caches des développeurs (npm/pip/yarn/Gradle/JetBrains), l'hibernation, WinSxS, les points de restauration, la corbeille et les recommandations pour les outils d'analyse de disque gratuits.
