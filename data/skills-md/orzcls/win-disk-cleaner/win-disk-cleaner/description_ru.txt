Windows C: очистка диска с помощью бесплатных инструментов с открытым исходным кодом и сценариев PowerShell. Заменяет платное программное обеспечение «оптимизатор системы». Используйте, когда пользователи просят: очистить диск C, освободить место на диске, очистить Windows, удалить временные файлы, очистить кэш браузера, очистить систему от мусора, уменьшить использование диска, очистить WinSxS, отключить спящий режим, найти большие файлы, удалить вредоносное ПО или выполнить любую задачу по восстановлению дискового пространства Windows. Также триггер для китайских эквивалентов: C盘清理, 磁盘清理, 清理垃圾, 系统瘦身, 释放空间, 临时文件清理. Охватывает: временные файлы, кеши браузера, кеш Центра обновления Windows, системные журналы, кеши приложений (WeChat/QQ/DingTalk/Teams/Discord), кеши разработчиков (npm/pip/yarn/Gradle/JetBrains), спящий режим, WinSxS, точки восстановления, корзину и рекомендации по бесплатным инструментам анализа диска.
