Windows C: pulizia del disco dell'unità utilizzando strumenti gratuiti/open source e script PowerShell. Sostituisce il software "ottimizzatore di sistema" a pagamento. Da utilizzare quando gli utenti chiedono di: pulire l'unità C, liberare spazio su disco, pulire Windows, eliminare file temporanei, pulire la cache del browser, pulire la posta indesiderata del sistema, ridurre l'utilizzo del disco, pulire WinSxS, disattivare l'ibernazione, trovare file di grandi dimensioni, rimuovere bloatware o qualsiasi attività di ripristino dello spazio su disco di Windows. Attiva anche gli equivalenti cinesi: C盘清理, 磁盘清理, 清理垃圾, 系统瘦身, 释放空间, 临时文件清理. Copre: file temporanei, cache del browser, cache di Windows Update, registri di sistema, cache delle app (WeChat/QQ/DingTalk/Teams/Discord), cache degli sviluppatori (npm/pip/yarn/Gradle/JetBrains), ibernazione, WinSxS, punti di ripristino, cestino e consigli per strumenti gratuiti di analisi del disco.
