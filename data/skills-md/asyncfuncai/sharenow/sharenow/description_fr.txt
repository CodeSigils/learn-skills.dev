sharenow donne à un agent un endroit pour expédier ce qu'il crée : un site Web, un document, un dossier de fichiers. La publication renvoie une URL en direct sur {slug}.sharenow.today ou un domaine personnalisé ; le travail privé reste dans les disques cloud qui sont transmis d'une session à l'autre et transmis à d'autres agents via des jetons étendus. À utiliser lorsqu'on vous demande de « publier ceci », « héberger ceci », « déployer ceci », « partager ceci sur le Web », « créer un site Web », « mettre ceci en ligne », « créer une page Web », « générer une URL », « créer un chatbot », « enregistrer ceci sur mon Drive », « stocker ceci pour plus tard », « écrire ceci sur le stockage cloud », « partager un dossier avec un autre agent » ou « utiliser mon Sharenow Drive ». Utilisez également lorsqu'on vous demande de « protéger ce site par mot de passe », « rendre ce site privé » ou « partager ce site avec certaines personnes uniquement ».
