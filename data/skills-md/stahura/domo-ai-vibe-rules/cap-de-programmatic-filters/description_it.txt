Controlla quali dati ciascun visualizzatore vede in una dashboard/scheda Domo incorporata tramite filtri programmatici lato server e cambio di set di dati. Copre il flusso di token OAuth → incorporamento, filtri standard, filtri SQL (OR/BETWEEN/LIKE), targeting per set di dati, reindirizzamenti di set di dati per architetture multi-tenant e limiti di dimensione dei token. Utilizzare per eventuali restrizioni sui dati per visualizzatore, ruolo o tenant al momento dell'incorporamento. Non per il filtraggio API JS lato client (utilizzare cap-de-jsapi-filters).
