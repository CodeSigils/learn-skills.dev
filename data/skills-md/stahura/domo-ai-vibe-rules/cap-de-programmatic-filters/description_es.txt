Controle qué datos ve cada espectador en un panel/tarjeta Domo integrado mediante filtros programáticos del lado del servidor y conmutación de conjuntos de datos. Cubre el flujo de token de inserción de OAuth →, filtros estándar, filtros SQL (O/ENTRE/LIKE), segmentación por conjunto de datos, redirecciones de conjunto de datos para arquitecturas multiinquilino y límites de tamaño de token. Úselo para cualquier restricción de datos por espectador, por rol o por inquilino en el momento de la inserción. No para el filtrado de API JS del lado del cliente (use cap-de-jsapi-filters).
