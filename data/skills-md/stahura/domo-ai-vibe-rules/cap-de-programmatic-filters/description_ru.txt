Контролируйте, какие данные каждый зритель видит на встроенной панели управления/карте Domo, с помощью программных фильтров на стороне сервера и переключения наборов данных. Охватывает поток OAuth → внедрение токенов, стандартные фильтры, фильтры SQL (OR/BETWEEN/LIKE), таргетинг на каждый набор данных, datasetRedirects для многопользовательских архитектур и ограничения размера токена. Используйте для любых ограничений данных для каждого зрителя, роли или клиента во время внедрения. Не для фильтрации JS API на стороне клиента (используйте cap-de-jsapi-filters).
