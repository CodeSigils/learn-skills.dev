Contrôlez les données que chaque spectateur voit dans un tableau de bord/une carte Domo intégré via des filtres programmatiques côté serveur et la commutation des ensembles de données. Couvre le flux de jetons OAuth → intégré, les filtres standard, les filtres SQL (OR/BETWEEN/LIKE), le ciblage par ensemble de données, les redirections d'ensembles de données pour les architectures multi-locataires et les limites de taille des jetons. À utiliser pour toutes les restrictions de données par spectateur, par rôle ou par locataire au moment de l'intégration. Pas pour le filtrage de l'API JS côté client (utilisez les filtres cap-de-jsapi).
