Применяйте фильтры времени выполнения к встроенным панелям/карточкам Domo со страницы хоста через JS API (MessagePort). Охватывает динамическую фильтрацию, события детализации, прослушиватели изменений фильтров, изменение размера iframe, параметры URL-адреса pfilter, overrideFilters и appData App Studio. Используйте для любого взаимодействия по внедрению Domo на стороне клиента. Не для программных фильтров на стороне сервера (используйте cap-de-programmatic-filters).
