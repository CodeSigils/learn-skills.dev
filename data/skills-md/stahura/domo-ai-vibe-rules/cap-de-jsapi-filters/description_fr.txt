Appliquez des filtres d'exécution aux tableaux de bord/cartes Domo intégrés à partir de la page hôte via l'API JS (MessagePort). Couvre le filtrage dynamique, les événements d'exploration, les écouteurs de changement de filtre, le redimensionnement d'iframe, les paramètres d'URL de pfilter, les overrideFilters et App Studio appData. À utiliser pour toute interaction d'intégration Domo côté client. Pas pour les filtres programmatiques côté serveur (utilisez les filtres cap-de-programmatic).
