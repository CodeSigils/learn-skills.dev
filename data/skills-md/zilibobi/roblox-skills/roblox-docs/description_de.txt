Schlagen Sie in der offiziellen Roblox-Erstellerdokumentation (Engine API + Erstellerhandbücher) nach und erhalten Sie eine genaue, zitierte Zusammenfassung. Dies ist ein Tool für SIE, den Agenten – nicht nur für den Benutzer. Greifen Sie proaktiv zu: wann immer Sie sich auch nur ein wenig unsicher über eine Roblox/Luau-API (eine Klasse, Methode, Eigenschaft, ein Ereignis, einen Datentyp, eine Aufzählung, global, eine Bibliothek, einen Dienst oder eine Studio-Funktion) sind, wann immer Sie tiefergehende Kenntnisse benötigen, als Sie sich sicher erinnern können, und wann immer Sie alternative APIs für eine Aufgabe vergleichen oder erkunden möchten. Verwenden Sie es insbesondere bei der Planung der Roblox-Arbeit – bevor Sie sich auf einen Ansatz festlegen –, um Ihre Annahmen in echten Dokumenten zu begründen, anstatt zu raten. Da sich die API von Roblox häufig ändert, sollten Sie lieber hier überprüfen, als aus dem Gedächtnis zu antworten. Es ist der zuverlässige Weg, halluzinierte oder veraltete API-Signaturen zu vermeiden. Wird bei jeder Roblox- oder Luau-Entwicklungsaufgabe ausgelöst, auch wenn der Benutzer nie „Dokumente“ sagt.
