Посмотрите официальную документацию создателя Roblox (Engine API + руководства для создателей) и получите точное цитируемое резюме. Это инструмент для ВАС, агента, а не только для пользователя. Используйте это заранее: всякий раз, когда вы хотя бы немного не уверены в API Roblox/Luau (класс, метод, свойство, событие, тип данных, перечисление, глобальный объект, библиотека, сервис или функция Studio), всякий раз, когда вам нужны более глубокие знания, чем вы можете с уверенностью вспомнить, и всякий раз, когда вы хотите сравнить или изучить альтернативные API для задачи. Особенно используйте его во время ПЛАНИРОВАНИЯ работы Roblox — прежде чем приступить к какому-либо подходу — чтобы обосновать свои предположения на реальных документах, а не на догадках. API Roblox часто меняется, поэтому предпочитайте проверять здесь, а не отвечать по памяти; это надежный способ избежать ложных или устаревших подписей API. Запускается при выполнении любой задачи разработки Roblox или Luau, даже если пользователь никогда не говорит «документы».
