ابحث عن وثائق منشئي Roblox الرسمية (Engine API + أدلة منشئي المحتوى) واحصل على ملخص دقيق ومقتبس. هذه أداة لك، أنت الوكيل، وليس المستخدم فقط. يمكنك الوصول إليها بشكل استباقي: عندما تكون غير متأكد ولو قليلاً من واجهة برمجة تطبيقات Roblox/Luau (فئة أو طريقة أو خاصية أو حدث أو نوع بيانات أو تعداد أو عمومي أو مكتبة أو خدمة أو ميزة استوديو)، وعندما تحتاج إلى معرفة أعمق مما يمكنك تذكره بثقة، وعندما تريد مقارنة واجهات برمجة التطبيقات البديلة لمهمة ما أو استكشافها. استخدمه بشكل خاص أثناء عمل التخطيط لـ Roblox - قبل الالتزام بأي نهج - لإثبات افتراضاتك في مستندات حقيقية بدلاً من التخمين. تتغير واجهة برمجة التطبيقات الخاصة بـ Roblox كثيرًا، لذا تفضل التحقق هنا بدلاً من الإجابة من الذاكرة؛ إنها الطريقة الموثوقة لتجنب توقيعات API المهلوسة أو القديمة. يتم تشغيله في أي مهمة تطوير Roblox أو Luau، حتى عندما لا يقول المستخدم كلمة "docs" مطلقًا.
