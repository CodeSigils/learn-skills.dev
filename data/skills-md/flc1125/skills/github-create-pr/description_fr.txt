Créez des demandes d'extraction GitHub à partir d'une branche locale à l'aide d'un flux de travail révisable pour les vérifications de branche, l'analyse des différences, la rédaction du titre/corps du PR et la création de gh CLI. À utiliser lors de l'ouverture d'un PR, de la rédaction ou de l'amélioration d'une description de PR, de la préparation d'une branche pour révision ou de l'ajout de réviseurs sur GitHub.
