Crea richieste pull GitHub da una filiale locale utilizzando un flusso di lavoro revisionabile per controlli delle filiali, analisi delle differenze, scrittura del titolo/corpo PR e creazione della CLI gh. Da utilizzare quando si apre una PR, si redige o si migliora la descrizione di una PR, si prepara un ramo per la revisione o si aggiungono revisori su GitHub.
