Проверяйте, сортируйте, одобряйте и объединяйте запросы на включение GitHub Renovate с помощью gh. Если репозиторий не указан, используйте набор предустановленных репозиториев по умолчанию, создайте план выполнения-кандидат и выполняйте его только после явного подтверждения пользователя. Используйте, когда пользователь запрашивает проверку, пакетную обработку, утверждение или объединение запросов на обновление Renovate.
