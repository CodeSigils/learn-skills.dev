Überprüfen, selektieren, genehmigen und führen Sie GitHub Renovate-Pull-Anfragen mit gh zusammen. Wenn kein Repository bereitgestellt wird, verwenden Sie den standardmäßigen voreingestellten Repository-Satz, erstellen Sie einen möglichen Ausführungsplan und führen Sie ihn erst nach ausdrücklicher Bestätigung durch den Benutzer aus. Verwenden Sie diese Option, wenn der Benutzer Renovate PRs prüfen, stapelweise bearbeiten, genehmigen oder zusammenführen möchte.
