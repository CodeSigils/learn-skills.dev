Ispeziona, valuta, approva e unisci GitHub Rinnova le richieste pull con gh. Quando non viene fornito alcun repository, utilizzare il set di repository preimpostato predefinito, creare un piano di esecuzione candidato ed eseguirlo solo dopo la conferma esplicita dell'utente. Da utilizzare quando l'utente chiede di controllare, gestire in batch, approvare o unire i PR di rinnovamento.
