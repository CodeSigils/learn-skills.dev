El punto de entrada de control central para el conjunto de habilidades de desarrollo integradas. Maneja dos tipos de tareas: (1) Cuando un usuario solicita instalar la habilidad desde este repositorio, guíelo para elegir una instalación completa o una instalación selectiva; (2) Cuando un usuario emite un comando vago (como "flash", "compilar", "depurar") y no puede determinar automáticamente qué habilidad específica usar, enumere las habilidades candidatas dentro de la misma categoría para que el usuario elija.
