Центральная точка входа для встроенного набора навыков разработки. Он решает два типа задач: (1) когда пользователь запрашивает установку навыка из этого репозитория, предложите ему выбрать либо полную установку, либо выборочную установку; (2) Когда пользователь дает расплывчатую команду (например, «прошить», «компилировать», «отладить») и он не может автоматически определить, какой конкретный навык использовать, перечислите возможные навыки в той же категории, чтобы пользователь мог выбрать.
