Le point d’entrée de contrôle central pour l’ensemble des compétences de développement intégré. Il gère deux types de tâches : (1) Lorsqu'un utilisateur demande à installer la compétence à partir de ce référentiel, guidez-le pour choisir soit une installation complète, soit une installation sélective ; (2) Lorsqu'un utilisateur émet une commande vague (telle que « flash », « compiler », « debug ») et qu'il ne peut pas déterminer automatiquement quelle compétence spécifique utiliser, répertoriez les compétences candidates dans la même catégorie pour que l'utilisateur puisse choisir.
