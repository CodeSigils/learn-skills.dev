Der zentrale Kontrolleinstiegspunkt für die eingebetteten Entwicklungskompetenzen. Es erledigt zwei Arten von Aufgaben: (1) Wenn ein Benutzer die Installation des Skills aus diesem Repository anfordert, weisen Sie ihn an, entweder eine vollständige Installation oder eine selektive Installation auszuwählen; (2) Wenn ein Benutzer einen vagen Befehl ausgibt (z. B. „flash“, „compile“, „debug“) und er nicht automatisch bestimmen kann, welche spezifische Fähigkeit verwendet werden soll, listen Sie Kandidatenfähigkeiten innerhalb derselben Kategorie auf, damit der Benutzer sie auswählen kann.
