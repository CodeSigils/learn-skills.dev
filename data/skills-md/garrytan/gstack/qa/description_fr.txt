Testez systématiquement une application Web et corrigez les bugs trouvés. Exécute des tests d'assurance qualité,
puis corrige de manière itérative les bogues dans le code source, en validant chaque correctif de manière atomique et
revérification. À utiliser lorsqu'on vous demande de "qa", "QA", "tester ce site", "trouver des bugs",
"tester et réparer" ou "réparer ce qui est cassé".
Suggérer de manière proactive quand l'utilisateur déclare qu'une fonctionnalité est prête à être testée
ou demande "est-ce que ça marche ?". Trois niveaux : Rapide (critique/élevé uniquement),
Standard (+ moyen), exhaustif (+ cosmétique). Produit des scores de santé avant/après,
réparer les preuves et un résumé de l'état de préparation du navire. Pour le mode rapport uniquement, utilisez /qa-only.
