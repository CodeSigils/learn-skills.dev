Générez à partir de zéro la documentation manquante pour une fonctionnalité, un module ou un projet entier.
Utilise le framework Diataxis (tutoriel / comment faire / référence / explication) pour produire
une documentation complète et structurée. Peut être invoqué de manière autonome ou appelé par
/document-release lorsqu'il trouve des lacunes dans la couverture. À utiliser lorsqu'on vous demande "d'écrire des documents",
« générer de la documentation », « documenter cette fonctionnalité », « créer un didacticiel » ou
"expliquez ce module". (gstack)
