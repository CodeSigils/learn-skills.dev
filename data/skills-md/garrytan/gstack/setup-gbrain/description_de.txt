Richten Sie gbrain für diesen Codierungsagenten ein: Installieren Sie die CLI, initialisieren Sie a
Lokales PGLite- oder Supabase-Gehirn, MCP registrieren, Per-Remote-Vertrauen erfassen
Politik. Ein Befehl von Null an „gbrain läuft, und dieser Agent
kann es nennen. Verwenden Sie Folgendes: „setup gbrain“, „connect gbrain“, „start
gbrain“, „gbrain installieren“, „gbrain für diesen Computer konfigurieren“. (gstack)
