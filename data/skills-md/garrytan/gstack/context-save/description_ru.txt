Сохраните рабочий контекст. Фиксирует состояние git, принятые решения и оставшуюся работу.
поэтому любая будущая сессия может продолжиться без потери ритма.
Используйте, когда вас просят «сохранить прогресс», «сохранить состояние», «сохранить контекст» или
«сохрани мою работу». Соедините с /context-restore, чтобы возобновить работу позже.
Ранее /checkpoint — переименован, потому что Claude Code рассматривает /checkpoint как
собственный псевдоним перемотки в текущих средах, который затенял этот навык.
