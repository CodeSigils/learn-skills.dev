Associez un agent IA distant à votre navigateur. Une commande génère une clé de configuration et
imprime les instructions que l’autre agent peut suivre pour se connecter. Fonctionne avec OpenClaw,
Hermes, Codex, Cursor ou tout agent pouvant effectuer des requêtes HTTP. L'agent distant
obtient son propre onglet avec un accès limité (lecture+écriture par défaut, administrateur sur demande).
À utiliser lorsqu'on vous demande de « jumeler l'agent », « connecter l'agent », « partager le navigateur », « le navigateur distant »,
"laisser un autre agent utiliser mon navigateur" ou "autoriser l'accès au navigateur". (gstack)
Déclencheurs vocaux (alias parole-texte) : "agent de couplage", "agent de connexion", "partager mon navigateur", "accès au navigateur à distance".
