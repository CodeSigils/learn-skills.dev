Sicherheitsleitplanken für destruktive Befehle. Warnt vor rm -rf, DROP TABLE,
Force-Push, Git Reset --Hard, Kubectl-Löschen und ähnliche destruktive Operationen.
Der Benutzer kann jede Warnung überschreiben. Verwendung beim Berühren von Produkten, beim Debuggen von Live-Systemen,
oder in einer gemeinsamen Umgebung arbeiten. Wird verwendet, wenn Sie zu „Vorsicht“ und „Sicherheitsmodus“ aufgefordert werden.
