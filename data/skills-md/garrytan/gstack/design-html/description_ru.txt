Завершение дизайна: генерирует HTML/CSS производственного качества для Pretext.
Работает с утвержденными макетами из /design-shotgun, планами генерального директора из /plan-ceo-review,
контекст проверки дизайна из /plan-design-review или с нуля совместно с пользователем
описание. Текст фактически перестраивается, высота вычисляется, макеты являются динамическими.
Накладные расходы 30 КБ, нулевые задержки. Интеллектуальная маршрутизация API: выбирает правильные шаблоны претекста
для каждого типа конструкции. Используйте, когда: «завершить этот дизайн», «превратить это в HTML»,
«Создайте мне страницу», «реализуйте этот дизайн» или после каких-либо навыков планирования.
Заблаговременно предлагайте, когда пользователь утвердил дизайн или подготовил план. (стек)
Голосовые триггеры (псевдонимы преобразования речи в текст): «создайте дизайн», «напишите код макета», «воплотите его в реальность».
