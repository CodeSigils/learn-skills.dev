Der Meta-Skill. Verwandeln Sie jedes Rohfeature oder Skript in ein entsprechend qualifiziertes,
getestete, auflösbare und bewertete Einheit der für den Agenten sichtbaren Fähigkeit. Verwenden Sie wann
Der Benutzer sagt: „Fähigkeit verbessern“, „Ist das eine Fähigkeit?“, „Machen Sie dies richtig“,
oder nachdem eine neue Funktion ohne die vollständige Kompetenzinfrastruktur erstellt wurde.

In Kombination mit „gbrain check-resolvable“ bietet Skillify eine vom Benutzer kontrollierbare Funktion
Äquivalent zur automatischen Skill-Erstellung von Hermes: Sie erstellen, Skillify überprüft das
Checkliste, check-resolvable stellt sicher, dass nichts verwaist ist. Der Mensch behält
Urteil; Die Werkzeuge sorgen dafür, dass die Checkliste ehrlich bleibt.
