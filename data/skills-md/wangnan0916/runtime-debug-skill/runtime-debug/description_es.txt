Flujo de trabajo de depuración en tiempo de ejecución independiente del agente con recopilación de registros NDJSON local. Úselo cuando el usuario invoca explícitamente la depuración en tiempo de ejecución, el modo de depuración o cuando un error reproducible difícil de diagnosticar necesita evidencia en tiempo de ejecución, sondas temporales, reproducción manual, análisis de registros, una solución mínima, verificación del usuario y limpieza de instrumentación. Para fallas simples de compilación, tipo, pelusa o pruebas obvias, solucione normalmente y solo mencione que la depuración en tiempo de ejecución está disponible. Los desencadenantes incluyen depuración en tiempo de ejecución, modo de depuración, registros en tiempo de ejecución, diagnóstico basado en registros, reproducción antes de corregir, inserción de sondas, errores de estado de interfaz/UI o investigación de un error difícil sin adivinar.
