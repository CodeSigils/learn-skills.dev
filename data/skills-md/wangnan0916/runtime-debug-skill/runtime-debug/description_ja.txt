ローカル NDJSON ログ収集を使用した、エージェントに依存しないランタイム デバッグ ワークフロー。ユーザーがランタイム デバッグ、デバッグ モードを明示的に呼び出す場合、または診断が困難な再現可能なバグで実行時の証拠、一時的なプローブ、手動による再現、ログ分析、最小限の修正、ユーザー検証、およびインストルメンテーションのクリーンアップが必要な場合に使用します。単純なビルド、タイプ、lint、または明らかなテストの失敗の場合は、通常どおり修正し、ランタイム デバッグが利用可能であることのみを記載します。トリガーには、ランタイム デバッグ、デバッグ モード、ランタイム ログ、ログベースの診断、修正前の再現、プローブの挿入、フロントエンド/UI 状態のバグ、または推測を伴わない重大なバグの調査が含まれます。
