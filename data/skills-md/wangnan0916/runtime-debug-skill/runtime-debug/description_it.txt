Flusso di lavoro di debug runtime indipendente dall'agente con raccolta di log NDJSON locale. Da utilizzare quando l'utente richiama esplicitamente il debug runtime, la modalità debug o quando un bug riproducibile difficile da diagnosticare necessita di prove di runtime, sonde temporanee, riproduzione manuale, analisi dei log, una correzione minima, verifica dell'utente e pulizia della strumentazione. Per semplici errori di compilazione, tipo, lanugine o test evidenti, correggere normalmente e menzionare solo che è disponibile il debug in fase di esecuzione. I trigger includono debug di runtime, modalità di debug, log di runtime, diagnosi basata su log, riproduzione prima della correzione, inserimento di sonde, bug di stato frontend/interfaccia utente o analisi di un bug difficile senza indovinare.
