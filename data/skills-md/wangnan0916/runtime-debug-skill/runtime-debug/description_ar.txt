سير عمل تصحيح أخطاء وقت التشغيل غير المتوافق مع الوكيل مع مجموعة سجلات NDJSON المحلية. يتم استخدامه عندما يستدعي المستخدم بشكل صريح تصحيح أخطاء وقت التشغيل، أو وضع تصحيح الأخطاء، أو عندما يحتاج خطأ قابل للتكرار يصعب تشخيصه إلى أدلة وقت التشغيل، وتحقيقات مؤقتة، وإعادة إنتاج يدوية، وتحليل السجل، والحد الأدنى من الإصلاح، والتحقق من المستخدم، وتنظيف الأجهزة. بالنسبة إلى عمليات البناء البسيطة أو الكتابة أو الوبر أو حالات الفشل الواضحة في الاختبار، قم بالإصلاح بشكل طبيعي واذكر فقط أن تصحيح الأخطاء في وقت التشغيل متاح. تتضمن المشغلات تصحيح أخطاء وقت التشغيل، أو وضع تصحيح الأخطاء، أو سجلات وقت التشغيل، أو التشخيص المستند إلى السجل، أو إعادة الإنتاج قبل الإصلاح، أو إدخال مجسات، أو أخطاء حالة الواجهة الأمامية/واجهة المستخدم، أو التحقيق في خطأ فادح دون التخمين.
