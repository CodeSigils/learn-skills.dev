Workflow de débogage d’exécution indépendant de l’agent avec collecte de journaux NDJSON locale. À utiliser lorsque l'utilisateur invoque explicitement le débogage d'exécution, le mode débogage ou lorsqu'un bogue reproductible difficile à diagnostiquer nécessite des preuves d'exécution, des sondes temporaires, une reproduction manuelle, une analyse des journaux, un correctif minimal, une vérification par l'utilisateur et un nettoyage de l'instrumentation. Pour les échecs simples de construction, de type, de lint ou de test évidents, corrigez normalement et mentionnez uniquement que le runtime-debug est disponible. Les déclencheurs incluent le débogage d'exécution, le mode débogage, les journaux d'exécution, le diagnostic basé sur les journaux, la reproduction avant la correction, l'insertion de sondes, les bogues d'état du frontend/UI ou l'enquête sur un bogue majeur sans deviner.
