Créez et révisez les applications Remix 3 à l'aide du package npm `remix` et des importations de sous-chemins. À utiliser lorsque vous travaillez sur la structure de l'application Remix, les itinéraires, les contrôleurs, le middleware, la validation, l'accès aux données, l'authentification, les sessions, les téléchargements de fichiers, la configuration du serveur, les composants de l'interface utilisateur, l'hydratation, la navigation ou les tests.
