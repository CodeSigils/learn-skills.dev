React Hook Form または TanStack Form で @autoform/* パッケージを使用して、任意の UI ライブラリ (shadcn/ui、MUI、Mantine、Ant Design、Chakra UI) で Zod、Yup、または Joi スキーマから React フォームを自動的に生成する方法。ユーザーがスキーマからのフォームの作成、フォーム アダプターの選択、カスタム フィールド コンポーネントを使用したフォームの構築、label/description/inputProps/fieldType の fieldConfig の設定、マルチステップ フォームの作成、オートフォーム インスタンスのネスト、オートフォーム UI コンポーネントのカスタマイズ、またはフィールド/オブジェクト/配列ラッパーのカスタマイズを行う場合には、このスキルを使用します。ユーザーが「オートフォーム」、「オートフォーム」、「オートフォーム」、「オートフォーム」、「スキーマ駆動フォーム」、または「スキーマからフォームを生成」とだけ言及した場合でも、このスキルをトリガーします。
