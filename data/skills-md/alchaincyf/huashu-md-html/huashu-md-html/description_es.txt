La habilidad "canal bidireccional md/html" del tío Hua ofrece tres capacidades en una sola parada: (1) Utilice Microsoft Markitdown para convertir cualquier archivo (PDF/DOCX/PPTX/XLSX/HTML/image/audio/YouTube/EPub/ZIP) en un descuento limpio; (2) Utilice Pandoc + cuatro plantillas cuidadosamente seleccionadas para transformar el descuento en HTML sobresaliente (artículos, informes, modo de lectura, exploración interactiva), heredando la estética descuidada anti-IA de huashu-design; (3) Utilice html‑to‑markdown + trafilatura para convertir HTML o URL sin pérdidas a Markdown. Esto implementa la metodología de "producción con rebajas y consumo de HTML" del tío Hua. Palabras desencadenantes: md a html, html a md, pdf a md, docx a md, pptx a md, xlsx a md, archivo a md, URL a md, documento a md, convertir a markdown, crear html, generar html, página web a md, importar documento, importar md, exportar html, md a html, html a md, cualquiera a md, markitdown, pandoc. Incluso si un usuario simplemente dice "convertir este PDF a md", "convertir este md en una página web" o "guardar esta página web", debería activarse.
