Uncle Huas „md/html bidirektionale Pipeline“-Fähigkeit bietet drei Funktionen aus einer Hand: (1) Verwenden Sie Microsoft Markitdown, um jede Datei (PDF/DOCX/PPTX/XLSX/HTML/Bild/Audio/YouTube/EPub/ZIP) in sauberes Markdown zu konvertieren; (2) Verwenden Sie Pandoc + vier sorgfältig ausgewählte Vorlagen, um Markdown in herausragendes HTML (Artikel, Berichte, Lesemodus, interaktive Erkundung) umzuwandeln und dabei die schlampige Anti-KI-Ästhetik von Huashu-Design zu übernehmen. (3) Verwenden Sie HTML-to-Markdown + Trafilatura, um HTML oder URLs verlustfrei zurück in Markdown zu konvertieren. Dies implementiert die Methodik „Markdown-Produktion, HTML-Verbrauch“ von Onkel Hua. Auslösewörter: md zu html, html zu md, pdf zu md, docx zu md, pptx zu md, xlsx zu md, datei zu md, url zu md, dokument zu md, in markdown konvertieren, html erstellen, html generieren, webseite zu md, dokument importieren, md importieren, html exportieren, md zu html, html zu md, beliebig zu md, markitdown, pandoc. Selbst wenn ein Benutzer einfach „Dieses PDF in MD konvertieren“, „Diese MD in eine Webseite umwandeln“ oder „Diese Webseite speichern“ sagt, sollte es ausgelöst werden.
