Навык дяди Хуа «двунаправленный конвейер md/html» предлагает три возможности за один раз: (1) использовать Microsoft Markitdown для преобразования любого файла (PDF/DOCX/PPTX/XLSX/HTML/image/audio/YouTube/EPub/ZIP) в чистую уценку; (2) Используйте Pandoc + четыре тщательно отобранных шаблона для преобразования уценки в выдающийся HTML (статьи, отчеты, режим чтения, интерактивное исследование), унаследовав небрежную эстетику huashu-design, направленную против искусственного интеллекта; (3) Используйте html‑to‑markdown + trafilatura для преобразования HTML или URL-адресов обратно в уценку без потерь. Это реализует методологию дяди Хуа «производство уценки, потребление HTML». Триггерные слова: md в html, html в md, pdf в md, docx в md, pptx в md, xlsx в md, файл в md, URL в md, документ в md, конвертировать в уценку, сделать html, сгенерировать html, веб-страницу в md, импортировать документ, импортировать md, экспортировать html, md в html, html в md, любой в md, markitdown, pandoc. Даже если пользователь просто говорит «конвертировать этот PDF в md», «превратить этот md в веб-страницу» или «сохранить эту веб-страницу», это должно сработать.
