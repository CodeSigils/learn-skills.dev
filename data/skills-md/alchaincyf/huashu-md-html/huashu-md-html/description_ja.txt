Uncle Hua の「md/html 双方向パイプライン」スキルは、1 つのパッケージで 3 つの機能を提供します。(1) Microsoft Markitdown を使用して、任意のファイル (PDF/DOCX/PPTX/XLSX/HTML/image/audio/YouTube/EPub/ZIP) をクリーンなマークダウンに変換します。 (2) Pandoc と 4 つの慎重に選択されたテンプレートを使用して、マークダウンを印象的な HTML (記事/レポート/読書モード/インタラクティブ探索) に変換し、huashu-design の反 AI スロップ美学を継承します。 (3) html-to-markdown と trafilatura を使用して、HTML または URL をロスレスでマークダウンに変換します。これは、Uncle Hua の「マークダウン生成、HTML 消費」方法論を実装しています。トリガーワード: md から html、html から md、pdf から md、docx から md、pptx から md、xlsx から md、ファイルから md、URL から md、ドキュメントから md、マークダウンに変換、html の作成、html の生成、Web ページから md、ドキュメントのインポート、md のインポート、html のエクスポート、md から html、html から md、任意から md、markitdown、pandoc。ユーザーが「この PDF を md に変換する」、「この md を Web ページに作成する」、または「この Web ページを保存する」とだけ言った場合でも、トリガーされるはずです。
