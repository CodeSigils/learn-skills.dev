La competenza "pipeline bidirezionale md/html" di zio Hua offre tre funzionalità in una volta sola: (1) utilizzare Microsoft Markitdown per convertire qualsiasi file (PDF/DOCX/PPTX/XLSX/HTML/immagine/audio/YouTube/EPub/ZIP) in md pulito; (2) Utilizzare Pandoc + quattro modelli accuratamente selezionati per elaborare md in un eccezionale codice HTML (articolo/report/modalità di lettura/esplorazione interattiva), ereditando l'estetica slop anti-AI di huashu‑design; (3) Utilizza html‑to‑markdown + trafilatura per riconvertire senza perdita di dati html o un URL in md. Ciò implementa la metodologia "produzione md, consumo html" di zio Hua.
