Hua 삼촌의 "md/html 양방향 파이프라인" 기술은 한 번에 세 가지 기능을 제공합니다. (1) Microsoft Markitdown을 사용하여 모든 파일(PDF/DOCX/PPTX/XLSX/HTML/image/audio/YouTube/EPub/ZIP)을 깔끔한 마크다운으로 변환합니다. (2) Pandoc + 엄선된 4가지 템플릿을 사용하여 마크다운을 뛰어난 HTML(기사, 보고서, 읽기 모드, 대화형 탐색)로 변환하고 huashu-design의 안티-AI 조잡한 미학을 계승합니다. (3) html-to-markdown + trafilatura를 사용하여 HTML 또는 URL을 손실 없이 다시 markdown으로 변환합니다. 이는 Hua 삼촌의 "마크다운 생산, HTML 소비" 방법론을 구현합니다. 트리거 단어: md를 html로, html을 md로, pdf를 md로, docx를 md로, pptx를 md로, xlsx를 md로, 파일을 md로, URL을 md로, 문서를 md로, markdown으로 변환, html 생성, html 생성, 웹페이지를 md로, 문서 가져오기, md 가져오기, html 내보내기, md를 html로, html을 md로, 모든 것을 md로, markitdown, pandoc. 사용자가 단순히 "이 PDF를 md로 변환", "이 md를 웹페이지로 만들어" 또는 "이 웹페이지 저장"이라고 말하면 실행됩니다.
