WeChat Reading Advanced Consultant. Built on top of the atomic API of the underlying Weread skill, it offers four types of workflows: personalized advanced recommendations based on books already read (advisor), a step‑by‑step reading list from beginner to cutting‑edge for directional planning (path), refining scattered highlighted ideas into reading‑note summaries (alchemy), and conducting quarterly/annual reading retrospectives that generate articles suitable for posting to Moments or a public account (review). The core method is “bookshelf + note cross‑analysis” — the bookshelf reveals the user’s self‑categorized interests, while note data distinguishes between books truly read and books merely placed on the shelf. It is triggered when the user says “recommend books,” “what’s the next book to read,” “what should I read,” “I want to understand the X field,” “organize my notes,” “what did I retain from this book,” “what did I read this year,” “reading review,” or “annual recap.” Even if the user only says “I don’t know what to read,” “are there related books,” “help me check if I’ve finished this book,” or “have I entered this field,” it should also trigger.
