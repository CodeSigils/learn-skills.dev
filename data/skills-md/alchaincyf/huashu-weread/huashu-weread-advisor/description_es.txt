Consultor avanzado de lectura de WeChat. Construido sobre la API atómica de la habilidad Weread subyacente, ofrece cuatro tipos de flujos de trabajo: recomendaciones avanzadas personalizadas basadas en libros ya leídos (asesor), una lista de lectura paso a paso desde principiante hasta vanguardia para la planificación direccional (ruta), refinando ideas destacadas dispersas en resúmenes de notas de lectura (alquimia) y realización de retrospectivas de lectura trimestrales/anuales que generan artículos adecuados para publicar en Momentos o una cuenta pública (revisión). El método central es el “análisis cruzado de estantería + notas”: la estantería revela los intereses autocategorizados del usuario, mientras que los datos de las notas distinguen entre libros realmente leídos y libros simplemente colocados en la estantería. Se activa cuando el usuario dice "recomendar libros", "cuál es el próximo libro a leer", "qué debo leer", "quiero entender el campo X", "organizar mis notas", "qué conservé de este libro", "qué leí este año", "reseña de lectura" o "resumen anual". Incluso si el usuario solo dice "No sé qué leer", "hay libros relacionados", "ayúdame a verificar si terminé este libro" o "he ingresado a este campo", también debería activarse.
