Автономный оптимизатор навыков, вдохновленный автоисследованиями Карпати. Оценивает файлы SKILL.md по 8-мерному критерию (структура + эффективность), выполняет анализ с помощью контроля версий git и проверяет улучшения с помощью тестовых подсказок. Используйте, когда пользователь упоминает «优化skill», «skill评分», «自动优化», «навыки автоматической оптимизации», «skill质量检查», «这个skill写得不好», «帮我改改skill», «skill怎么样», «提升навык质量», «обзор навыков», «навык打分».
