سير عمل إنشاء البرنامج النصي الفيروسي Douyin. العملية الكاملة بدءًا من تشريح فيديو المنافس إلى إنشاء البرنامج النصي: تنزيل فيديو Douyin ← تحليل فيديو Gemini ← استخراج الصيغة الفيروسية ← إنشاء البرنامج النصي + القصة المصورة ← التدقيق اللغوي باستخدام الذكاء الاصطناعي. استخدم هذه المهارة عندما يذكر المستخدم "نص Douyin"، أو "التشريح الفيروسي"، أو "تحليل المنافسين"، أو "نص المبيعات"، أو "مادة Qianchuan"، أو "نص توصية المنتج"، أو "تشريح الفيديو"، أو "تحليل فيديو Douyin".
