قم بتحويل مستندات Markdown إلى أوراق بيضاء احترافية بتنسيق PDF بأسلوب تصميم Apple.  
يدعم بناء جملة Markdown الكامل (كتل التعليمات البرمجية، والجداول، وعلامات الاقتباس، والقوائم، وما إلى ذلك).  
يقوم تلقائيًا بإنشاء صفحة غلاف وجدول محتويات ورأس وتذييل.  
حالات الاستخدام: الوثائق الفنية، والمستندات التقنية، والبرامج التعليمية، والتقارير، ومستندات Markdown الأخرى التي تتطلب تنضيدًا احترافيًا.
