Convertissez des documents Markdown en livres blancs PDF professionnels avec un style de conception Apple.  
Prend en charge la syntaxe complète de Markdown (blocs de code, tableaux, blockquotes, listes, etc.).  
Génère automatiquement une page de garde, une table des matières, un en-tête et un pied de page.  
Cas d'utilisation : documentation technique, livres blancs, didacticiels, rapports et autres documents Markdown nécessitant une composition professionnelle.
