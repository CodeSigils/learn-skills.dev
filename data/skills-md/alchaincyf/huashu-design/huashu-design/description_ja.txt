Huashu-Design – ハイファイ プロトタイピング、インタラクティブ デモ、スライド、アニメーション、デザイン バリアントの調査、デザイン方向のコンサルティング、専門家によるレビューに HTML を使用する統合デザイン機能。 HTML はツールであり、媒体ではありません。さまざまな専門家 (UX デザイナー、アニメーター、スライド デザイナー、プロトタイプ作成者) をタスクごとに具体化し、Web デザインの決まり文句を回避します。  
トリガーフレーズ: プロトタイプの作成、デザインデモ、インタラクティブプロトタイプ、HTML プレゼンテーション、アニメーションデモ、デザインバリアント、Hi-Fi デザイン、UI モックアップ、プロトタイプ、デザインの探索、HTML ページの構築、ビジュアライゼーションの作成、アプリのプロトタイプ、iOS プロトタイプ、モバイルアプリのモックアップ、MP4 のエクスポート、GIF のエクスポート、60 fps ビデオ、デザインスタイル、デザインの方向性、デザイン哲学、配色、ビジュアルスタイル、スタイルの推奨、スタイルの選択、美しくする、レビュー、良いですか、このデザインをレビューします。  

**コア機能**: ジュニアデザイナーのワークフロー (仮説 + 推論 + プレースホルダーが最初に、その後反復)、AI スロップ対策チェックリスト、React + Babel のベスト プラクティス、Tweaks バリアント スイッチャー、スピーカー ノート プレゼンテーション、スターター コンポーネント (スライド シェル / バリアント キャンバス / アニメーション エンジン / デバイス フレーム)、アプリ プロトタイプ ルール (デフォルトで Wikimedia/Met/Unsplash からの実際の画像、インタラクションのために AppPhone ステート マネージャーでラップされたすべての iPhone、Playwright クリック テストの実行)配信前）、Playwright 検証、HTML アニメーション → MP4/GIF エクスポート（25 fps ベース + 60 fps 補間 + パレット最適化 GIF + 6 つのコンテキスト BGM トラック + 自動フェード）。  

**要件が曖昧な場合のフォールバック**: デザイン ディレクション コンサルタント モード - 5 つの学校 × 20 のデザイン哲学 (ペンタグラムの情報アーキテクチャ、Field.io の運動詩学、原研哉の東洋のミニマリズム、サグマイスターの実験的前衛芸術など) から 3 つの異なる方向性を推奨し、24 の既製のショーケース (8 シーン × 3 スタイル) を表示し、ユーザー向けに 3 つのビジュアル デモを並行して生成します。選択。  

**納品後のオプション**: 専門家による 5 次元レビュー (哲学の一貫性 / 視覚的階層 / 詳細な実行 / 機能性 / イノベーション、各 10 ポイント + 修正リスト)。
