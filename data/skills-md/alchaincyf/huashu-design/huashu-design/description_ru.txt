Huashu-Design — универсальная дизайнерская сила, использующая HTML для создания высококачественных прототипов, интерактивных демонстраций, слайд-шоу, анимации, исследования вариантов дизайна, консультирования по вопросам дизайна и экспертной критики. HTML — это инструмент, а не среда; в нем участвуют разные специалисты (UX-дизайнер / аниматор / дизайнер слайд-шоу / прототипировщик) для каждой задачи, избегая клише веб-дизайна.  
Триггерные слова: создание прототипа, демонстрация дизайна, прототип взаимодействия, HTML-презентация, демонстрация анимации, вариант дизайна, высококачественный дизайн, макет пользовательского интерфейса, прототип, исследование дизайна, создание HTML-страницы, создание визуализации, прототип приложения, прототип iOS, мобильный макет, экспорт MP4, экспорт GIF, видео с частотой 60 кадров в секунду, стиль дизайна, направление дизайна, философия дизайна, цветовая схема, визуальный стиль, рекомендовать стиль, выбрать стиль, сделать его красивым, просмотреть, хорошо ли он выглядит, просмотреть этот дизайн.  

**Основные возможности**: рабочий процесс младшего дизайнера (сначала гипотеза + рассуждение + заполнитель, затем итерация), контрольный список по борьбе с ошибками ИИ, лучшие практики React+Babel, переключатель вариантов Tweaks, заметки докладчика для презентации, начальные компоненты (оболочка слайд-шоу / вариант холста / механизм анимации / кадр устройства), правила прототипирования приложения (автоматическое получение реальных изображений из Wikimedia/Met/Unsplash, каждый iPhone обернут менеджером состояний AppPhone для полная интерактивность, запустите клик-тест Playwright перед передачей), проверка драматурга, HTML-анимация → экспорт в MP4/GIF (базовая версия 25 кадров в секунду + кадровая интерполяция 60 кадров в секунду + GIF с оптимизацией палитры + 6 контекстных фоновых дорожек + автоматическое затухание).  

**Запасной вариант, когда краткое изложение неясно**: режим консультанта по дизайну — рекомендует 3 дифференцированных направления из 5 школ × 20 философий дизайна (информационная архитектура Pentagram, кинетическая поэзия Field.io, восточный минимализм Kenya Hara, экспериментальный авангард Sagmeister и т. д.), представляет 24 готовых демонстрации (8 сценариев × 3 стиля) и одновременно генерирует 3 визуальные демонстрации на выбор пользователя.  

**Дополнительно после поставки**: экспертная 5-мерная критика (последовательность философии/визуальная иерархия/детализация исполнения/функциональность/инновации, по 10 баллов + список исправлений).
