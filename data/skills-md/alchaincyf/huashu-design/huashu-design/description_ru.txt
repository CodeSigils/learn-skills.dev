Huashu Design (Huashu-Design) — интегрированная возможность проектирования, которая использует HTML для создания высококачественных прототипов, интерактивных демонстраций, слайдов, анимации, исследований вариантов дизайна, консультаций по дизайну и обзоров экспертов. HTML — это инструмент, а не среда; в зависимости от задачи в нем участвуют разные специалисты (UX-дизайнер, аниматор, дизайнер слайдов, прототипировщик), чтобы избежать шаблонов веб-дизайна. Триггерные слова: создать прототип, демонстрационный дизайн, интерактивный прототип, HTML-презентация, демонстрационная анимация, вариант дизайна, высококачественный дизайн, макет пользовательского интерфейса, прототип, исследование дизайна, создать HTML-страницу, создать визуализацию, прототип приложения, прототип iOS, макет мобильного приложения, экспортировать MP4, экспортировать GIF, видео с частотой 60 кадров в секунду, стиль дизайна, направление дизайна, философия дизайна, цветовая схема, визуальный стиль, рекомендуемый стиль, выбрать стиль, сделать что-то красивое, просмотреть, хорошо ли это выглядит, просмотреть этот дизайн.  

**Основные возможности**: рабочий процесс младшего дизайнера (сначала выдвигайте предположения+обоснования+заполнители, затем повторяйте), контрольный список ошибок в работе искусственного интеллекта, лучшие практики React+Babel, переключение вариантов настроек, презентация заметок докладчика, начальные компоненты (оболочка слайда/вариант холста/движок анимации/фрейм устройства), правила, специфичные для прототипа приложения (по умолчанию используются реальные изображения из Wikimedia/Met/Unsplash, каждый iPhone включает в себя интерактивный менеджер состояний AppPhone, запуск Клик-тесты драматурга перед доставкой), проверка драматурга, HTML-анимация → экспорт видео MP4/GIF (базовая частота 25 кадров в секунду + интерполяция 60 кадров в секунду + GIF с оптимизацией палитры + шесть фоновых дорожек для конкретных сцен + автоматическое затухание).  

**Резервный вариант, когда требования расплывчаты**: Режим консультирования по направлению дизайна — из пяти школ × двадцати философий дизайна (информационная архитектура Пентаграммы, поэтика движения Field.io, восточный минимализм Кении Хара, экспериментальный авангард Сагмейстера и т. д.) рекомендуются три дифференцированных направления, демонстрируются двадцать четыре готовых демонстрации (8 сценариев × 3 стиля) и одновременно создаются три визуальные демонстрации на выбор пользователя.  

**Дополнительное предложение после поставки**: пятимерная проверка на экспертном уровне (философская последовательность, визуальная иерархия, детальное исполнение, функциональность, инновации – каждый балл по 10 баллам + контрольный список исправлений).
