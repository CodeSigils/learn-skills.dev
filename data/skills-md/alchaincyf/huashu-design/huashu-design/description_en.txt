Huashu Design (Huashu-Design) – an integrated design capability that uses HTML to create high‑fidelity prototypes, interactive demos, slides, animations, design‑variant explorations, design‑direction consulting, and expert reviews. HTML is a tool, not a medium; depending on the task, it embodies different experts (UX designer, animator, slide designer, prototyper) to avoid web‑design tropes. Trigger words: make a prototype, design demo, interactive prototype, HTML presentation, animation demo, design variant, hi‑fi design, UI mockup, prototype, design exploration, create an HTML page, create a visualization, app prototype, iOS prototype, mobile app mockup, export MP4, export GIF, 60 fps video, design style, design direction, design philosophy, color scheme, visual style, recommended style, pick a style, make something good‑looking, review, does it look good, review this design.  

**Core capabilities**: Junior Designer workflow (first provide assumptions + reasoning + placeholders, then iterate), anti‑AI slop checklist, React + Babel best practices, Tweaks variant switching, Speaker Notes presentation, Starter Components (slide shell/variant canvas/animation engine/device frame), App‑prototype‑specific rules (default to real images from Wikimedia/Met/Unsplash, each iPhone includes an interactive AppPhone state manager, run Playwright click tests before delivery), Playwright validation, HTML animation → MP4/GIF video export (base 25 fps + 60 fps interpolation + palette‑optimized GIF + six scene‑specific BGM tracks + automatic fade).  

**Fallback when requirements are vague**: Design‑direction consulting mode – from five schools × twenty design philosophies (Pentagram information architecture, Field.io motion poetics, Kenya Hara Eastern minimalism, Sagmeister experimental avant‑garde, etc.) recommend three differentiated directions, showcase twenty‑four pre‑made showcases (8 scenarios × 3 styles), and concurrently generate three visual demos for the user to choose from.  

**Optional post‑delivery offering**: Expert‑level five‑dimensional review (philosophical consistency, visual hierarchy, detail execution, functionality, innovation – each scored out of 10 + a remediation checklist).
