Huashu-Design – une centrale de conception intégrée qui utilise HTML pour les prototypes hi-fi, les démos interactives, les diaporamas, les animations, l'exploration des variantes de conception, le conseil en direction de la conception et la critique d'experts. HTML est un outil, pas un support ; il incarne différents spécialistes (UX designer / animateur / concepteur de diaporamas / prototypeur) tâche par tâche, évitant les clichés du web design.  

Phrases déclencheurs : créer un prototype, démo de conception, prototype interactif, présentation HTML, démo d'animation, variante de conception, conception hi-fi, maquette d'interface utilisateur, prototype, exploration de conception, créer une page HTML, créer une visualisation, prototype d'application, prototype iOS, maquette d'application mobile, exporter MP4, exporter GIF, vidéo 60 ips, style de conception, direction de conception, philosophie de conception, jeu de couleurs, style visuel, recommander un style, choisir un style, le rendre joli, réviser, est-ce que ça a l'air bien, revoir cette conception.  

**Capacités de base** : workflow de concepteur junior (hypothèse → raisonnement → espace réservé → itération), liste de contrôle anti-IA-slop, meilleures pratiques React + Babel, sélecteur de variantes Tweaks, présentation des notes du conférencier, composants de démarrage (shell de diaporama / canevas de variantes / moteur d'animation / cadre de périphérique), règles de prototype d'application (chargement automatique d'images réelles à partir de Wikimedia/Met/Unsplash, chaque iPhone enveloppé dans le gestionnaire d'état AppPhone pour l'interactivité, exécutez des tests de clic Playwright avant hand-off), validation du dramaturge, animation HTML → export MP4/GIF (base 25 ips + interpolation d'image 60 ips + GIF optimisé par palette + 6 pistes BGM contextuelles + fondu automatique).  

**Retour lorsque les exigences sont vagues** : mode consultant en direction de la conception : recommande 3 directions différenciées de 5 écoles × 20 philosophies de conception (info-architecture Pentagram, poétique cinétique Field.io, minimalisme oriental Kenya Hara, avant-garde expérimentale Sagmeister, etc.), présente 24 vitrines prédéfinies (8 scénarios × 3 styles) et génère 3 démos visuelles en parallèle pour la sélection de l'utilisateur.  

**Après livraison en option** : critique experte en 5 dimensions (cohérence philosophique / hiérarchie visuelle / exécution détaillée / fonctionnalité / innovation, chacune notée 10/10 + liste de correctifs).
