Nuwa schafft Menschen: Geben Sie einen Namen/ein Thema oder sogar ein vages Bedürfnis ein, führen Sie eine automatische Tiefenrecherche durch → destillieren Sie einen Denkrahmen → generieren Sie eine ausführbare Personenkompetenz.
Zwei Einträge: (1) genauer Name → direkte Destillation (2) vager Bedarf → diagnostische Empfehlung → dann destillieren.
Auslöserwörter: „Fähigkeit schaffen“, „XX destillieren“, „Nuwa“, „Menschen schaffen“, „XXs Denkweise“, „eine XX-Perspektive schaffen“, „XXs Fertigkeit aktualisieren“.
Vage Bedürfnisse lösen auch aus: „Ich möchte die Entscheidungsqualität verbessern“, „Gibt es eine Denkweise, die mir helfen kann…“, „Ich brauche einen Denkberater“.
