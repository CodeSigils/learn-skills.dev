Nüwa erschafft Menschen: Geben Sie einen Namen/ein Thema oder auch nur eine vage Anfrage ein, führen Sie automatisch eine eingehende Recherche durch → extrahieren Sie einen Denkrahmen → generieren Sie eine ausführbare Charakterfähigkeit. Zwei Einstiegspunkte: (1) Spezifischer Name → Direktdestillation (2) Vage Anfrage → Diagnoseempfehlung → dann Destillation. Auslöserwörter: „Create Skill“, „destillXX“, „Nüwa“, „create human“, „XX’s way of think“, „take anXX perspective“, „updateXX’s skills“. Auch vage Anfragen lösen aus: „Ich möchte die Entscheidungsqualität verbessern“, „Gibt es eine Denkweise, die mir helfen kann…“, „Ich brauche einen Denkberater“.
