افحص سجل مستودع git قبل قراءة الملفات المصدر. استخدم هذه المهارة عند إدخال قاعدة تعليمات برمجية غير مألوفة، أو إجراء عملية فرز خفيفة للريبو، أو تحديد الكود الذي يجب فحصه أولاً. يقوم بتشغيل خمسة أوامر git-history لتحديد نقاط التغيير الفعالة، وتركيز المساهمين، والملفات المعرضة للأخطاء، وزخم التسليم، وأنماط مكافحة الحرائق.
