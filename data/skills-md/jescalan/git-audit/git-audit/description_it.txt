Esamina la cronologia di un repository git prima di leggere i file sorgente. Utilizza questa abilità quando inserisci una base di codice sconosciuta, esegui un leggero triage di repository o decidi quale codice ispezionare per primo. Esegue cinque comandi git-history per identificare i punti caldi di abbandono, la concentrazione dei contributori, i file soggetti a bug, lo slancio della consegna e i modelli di lotta agli incendi.
