Inspectez l'historique d'un référentiel git avant de lire les fichiers sources. Utilisez cette compétence lorsque vous entrez dans une base de code inconnue, effectuez un tri léger des dépôts ou décidez quel code inspecter en premier. Exécute cinq commandes git-history pour identifier les points chauds de désabonnement, la concentration des contributeurs, les fichiers sujets aux bogues, la dynamique de livraison et les modèles de lutte contre les incendies.
