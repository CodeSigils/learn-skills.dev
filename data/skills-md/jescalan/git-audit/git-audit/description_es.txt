Inspeccione el historial de un repositorio git antes de leer los archivos fuente. Utilice esta habilidad cuando ingrese una base de código desconocida, realice un repositorio ligero o decida qué código inspeccionar primero. Ejecuta cinco comandos git-history para identificar puntos críticos de abandono, concentración de contribuyentes, archivos propensos a errores, impulso de entrega y patrones de extinción de incendios.
