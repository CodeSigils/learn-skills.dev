Überprüfen Sie den Verlauf eines Git-Repositorys, bevor Sie Quelldateien lesen. Verwenden Sie diese Fähigkeit, wenn Sie eine unbekannte Codebasis eingeben, eine leichte Repo-Triage durchführen oder entscheiden, welcher Code zuerst überprüft werden soll. Führt fünf Git-History-Befehle aus, um Abwanderungs-Hotspots, Mitwirkendenkonzentration, fehleranfällige Dateien, Lieferdynamik und Brandbekämpfungsmuster zu identifizieren.
