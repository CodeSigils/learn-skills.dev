قم بإنشاء رسوم متحركة لشخصيات SVG بجودة الإنتاج - أجهزة الحالة التي تتحول بين حالات N SVG (2-10) مع حركة خاملة لكل حالة (التنفس، والوميض، والتأرجح). يُستخدم عندما يريد المستخدم تحريك شخصية أو تميمة بين الأوضاع/العواطف، أو تحويل الرموز/الرسوم التوضيحية بين النماذج، أو إنشاء أجهزة حالة SVG تفاعلية، أو إضافة حركة خاملة محيطة إلى الرسومات المتجهة. تتضمن المشغلات الرسوم المتحركة للشخصية/التميمة، أو استيفاء مسار SVG، أو انتقالات مشاعر الشخصية، أو تبديل الأيقونات مع الرسوم المتحركة، أو الرسوم المتحركة المتجهة متعددة الحالات، أو "اجعل SVG هذا ينبض بالحياة." استخدمه أيضًا عندما يشير المستخدم إلى إطارات Figma التي يريد التحويل بينها، حتى إذا لم يذكر "morph" بشكل صريح، وعندما يريد المستخدم نقل أو تصدير رسوم متحركة لأحرف SVG/Figma إلى SwiftUI أو iOS (تشحن المهارة خط أنابيب التصميم في المستعرض والشحن إلى iOS مع مصدر Swift).
