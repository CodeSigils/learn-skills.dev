Rendern Sie druckbare PDF-Proxys für ein MTG-Deck – ein PDF für die Karten des Decks, eines für jede Token-Art, die diese Karten produzieren. Karten und Token verwenden beide ein Layout, das einen echten MTG-Kartenrahmen widerspiegelt (Namensbanner / ASCII-Grafik / Typbanner / Orakeltext / P/T), wobei alle Daten live von Scryfall abgerufen werden.
