Créez des proxys PDF imprimables pour un jeu MTG : un PDF pour les cartes du jeu, un pour chaque type de jeton produit par ces cartes. Les cartes et les jetons utilisent tous deux une disposition qui reflète un véritable cadre de carte MTG (bannière de nom / art ASCII / bannière de type / texte oracle / P/T) avec toutes les données extraites en direct de Scryfall.
