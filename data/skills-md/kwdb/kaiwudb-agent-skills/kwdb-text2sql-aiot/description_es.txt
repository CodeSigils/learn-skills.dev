Convierta consultas en lenguaje natural a KWDB SQL para datos de series temporales, datos relacionales y análisis entre modelos.
Utilice esta habilidad siempre que los usuarios soliciten consultar bases de datos de KWDB, escribir SQL para KWDB,
o convertir el lenguaje natural a la sintaxis SQL específica de KWDB.
Admite: CREAR BASE DE DATOS/TABLA, reducción de resolución, interpolación, consultas de valores más recientes,
análisis de agregación, consultas entre modelos, análisis de ventana/sesión/evento.
