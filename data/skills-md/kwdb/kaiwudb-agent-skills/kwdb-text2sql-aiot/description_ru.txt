Преобразуйте запросы на естественном языке в KWDB SQL для данных временных рядов, реляционных данных и анализа кросс-моделей.
Используйте этот навык всякий раз, когда пользователи просят выполнить запрос к базам данных KWDB, написать SQL для KWDB,
или преобразовать естественный язык в синтаксис SQL, специфичный для KWDB.
Поддерживает: CREATE DATABASE/TABLE, понижающую дискретизацию, интерполяцию, запросы последних значений,
Агрегационный анализ, кросс-модельные запросы, анализ окон/сессий/событий.
