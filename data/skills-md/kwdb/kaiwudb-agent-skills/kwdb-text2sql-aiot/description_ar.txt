قم بتحويل استعلامات اللغة الطبيعية إلى KWDB SQL لبيانات السلاسل الزمنية والبيانات العلائقية والتحليل عبر النماذج.
استخدم هذه المهارة عندما يطلب المستخدمون الاستعلام عن قواعد بيانات KWDB، أو كتابة SQL لـ KWDB،
أو تحويل اللغة الطبيعية إلى بناء جملة SQL خاص بـ KWDB.
يدعم: إنشاء قاعدة بيانات/جدول، الاختزال، الاستيفاء، أحدث استعلامات القيمة،
تحليل التجميع، والاستعلامات عبر النماذج، وتحليل النافذة/الجلسة/الحدث.
