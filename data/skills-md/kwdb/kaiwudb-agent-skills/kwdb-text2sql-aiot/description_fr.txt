Convertissez les requêtes en langage naturel en KWDB SQL pour les données de séries chronologiques, les données relationnelles et l'analyse inter-modèles.
Utilisez cette compétence chaque fois que les utilisateurs demandent à interroger les bases de données KWDB, à écrire du SQL pour KWDB,
ou convertissez le langage naturel en syntaxe SQL spécifique à KDBB.
Prise en charge : CREATE DATABASE/TABLE, sous-échantillonnage, interpolation, dernières requêtes de valeur,
analyse d'agrégation, requêtes inter-modèles, analyse fenêtre/session/événement.
