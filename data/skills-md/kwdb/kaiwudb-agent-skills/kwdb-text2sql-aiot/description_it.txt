Converti query in linguaggio naturale in SQL KWDB per dati di serie temporali, dati relazionali e analisi tra modelli.
Usa questa abilità ogni volta che gli utenti chiedono di interrogare i database KWDB, scrivere SQL per KWDB,
o convertire il linguaggio naturale nella sintassi SQL specifica di KWDB.
Supporta: CREATE DATABASE/TABLE, downsampling, interpolazione, query sui valori più recenti,
analisi di aggregazione, query tra modelli, analisi di finestre/sessioni/eventi.
