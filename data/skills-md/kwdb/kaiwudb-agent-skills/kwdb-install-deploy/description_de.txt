Wird ausgelöst, wenn der Benutzer KaiwuDB (kwdb, kaiwudb) installieren oder bereitstellen möchte. Hilft Benutzern bei der skriptbasierten Bereitstellung von KaiwuDB-Clustern, einschließlich Änderung der Konfigurationsdatei, Ausführung von Installationsbefehlen, Cluster-Initialisierung und Statusprüfungen.
