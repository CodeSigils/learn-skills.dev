يراجع قواعد تعليمات Java 25 وSpring Boot 4، وطلبات السحب، والملفات، والوحدات النمطية لمخاطر الترحيل، وانتهاكات حدود البنية، ومشكلات السلامة الخالية من JSpecify، والعيوب الأمنية، وتراجعات الأداء، ومزالق Spring Data. يُستخدم عندما تكون المهمة عبارة عن مراجعة محددة لرمز Java أو Spring مع سياق التعليمات البرمجية. لا تستخدمه مع كود Kotlin فقط، أو أطر العمل غير التابعة لـ Spring، أو نصائح المراجعة العامة بدون ملفات أو فروق.
