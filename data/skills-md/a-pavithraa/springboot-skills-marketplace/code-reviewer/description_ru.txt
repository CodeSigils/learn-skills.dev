Анализирует кодовые базы Java 25 и Spring Boot 4, запросы на включение, файлы и модули на предмет рисков миграции, нарушений границ архитектуры, проблем нулевой безопасности JSpecify, недостатков безопасности, снижения производительности и ловушек Spring Data. Используйте, когда задачей является конкретная проверка кода Java или Spring с контекстом кода. Не используйте для кода только Kotlin, фреймворков, отличных от Spring, или общих рекомендаций по проверке без файлов или различий.
