يجب معالجة جميع عمليات الشبكة من خلال هذه المهارة، بما في ذلك البحث، واستخراج الويب، وإجراءات ما بعد تسجيل الدخول، وتفاعلات الشبكة، والمزيد. سيناريوهات التشغيل: عندما يطلب المستخدم البحث عن معلومات، أو عرض محتوى صفحة الويب، أو الوصول إلى المواقع التي تتطلب تسجيل الدخول، أو التفاعل مع واجهات الويب، أو استخراج محتوى الوسائط الاجتماعية (Xiaohongshu، Weibo، Twitter، وما إلى ذلك)، أو قراءة الصفحات المعروضة ديناميكيًا، أو تنفيذ أي مهمة شبكة تتطلب بيئة متصفح حقيقية.
