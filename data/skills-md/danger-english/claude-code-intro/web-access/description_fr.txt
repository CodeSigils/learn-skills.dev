Toutes les opérations réseau doivent être traitées via cette compétence, y compris la recherche, le web scraping, les actions post-connexion, les interactions réseau, etc. Scénarios de déclenchement : lorsqu'un utilisateur demande à rechercher des informations, à afficher le contenu d'une page Web, à accéder à des sites nécessitant une connexion, à interagir avec des interfaces Web, à extraire du contenu de médias sociaux (Xiaohongshu, Weibo, Twitter, etc.), à lire des pages rendues dynamiquement ou à effectuer toute tâche réseau nécessitant un véritable environnement de navigateur.
