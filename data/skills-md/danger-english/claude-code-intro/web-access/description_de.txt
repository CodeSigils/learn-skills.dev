Alle Netzwerkvorgänge müssen über diesen Skill verarbeitet werden, einschließlich Suche, Web Scraping, Post-Login-Aktionen, Netzwerkinteraktionen und mehr. Auslöseszenarien: Wenn ein Benutzer nach Informationen suchen, Webseiteninhalte anzeigen, auf Websites zugreifen möchte, für die eine Anmeldung erforderlich ist, mit Webschnittstellen interagieren, Social-Media-Inhalte (Xiaohongshu, Weibo, Twitter usw.) durchsuchen, dynamisch gerenderte Seiten lesen oder eine Netzwerkaufgabe ausführen möchte, die eine echte Browserumgebung erfordert.
