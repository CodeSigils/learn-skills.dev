Tutte le operazioni di rete devono essere elaborate tramite questa abilità, inclusa la ricerca, il web scraping, le azioni post-accesso, le interazioni di rete e altro ancora. Scenari di attivazione: quando un utente richiede di cercare informazioni, visualizzare il contenuto di una pagina Web, accedere a siti che richiedono l'accesso, interagire con interfacce Web, acquisire contenuti di social media (Xiaohongshu, Weibo, Twitter, ecc.), leggere pagine visualizzate in modo dinamico o eseguire qualsiasi attività di rete che richiede un ambiente browser reale.
