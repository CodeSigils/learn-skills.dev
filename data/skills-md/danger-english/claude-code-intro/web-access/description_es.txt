Todas las operaciones de red deben procesarse a través de esta habilidad, incluidas la búsqueda, el web scraping, las acciones posteriores al inicio de sesión, las interacciones de red y más. Escenarios de activación: cuando un usuario solicita buscar información, ver el contenido de una página web, acceder a sitios que requieren inicio de sesión, interactuar con interfaces web, extraer contenido de redes sociales (Xiaohongshu, Weibo, Twitter, etc.), leer páginas renderizadas dinámicamente o realizar cualquier tarea de red que requiera un entorno de navegador real.
