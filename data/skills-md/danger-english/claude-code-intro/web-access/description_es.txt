Todas las operaciones de red deben manejarse a través de esta habilidad, incluidas la búsqueda, el web scraping, las acciones posteriores al inicio de sesión, las interacciones de red, etc. Escenarios desencadenantes: cuando un usuario solicita buscar información, ver contenido de una página web, acceder a sitios que requieren inicio de sesión, interactuar con una interfaz de página web, extraer contenido de redes sociales (por ejemplo, Xiaohongshu, Weibo, Twitter, etc.), leer páginas renderizadas dinámicamente o realizar cualquier tarea de red que requiera un entorno de navegador real.
