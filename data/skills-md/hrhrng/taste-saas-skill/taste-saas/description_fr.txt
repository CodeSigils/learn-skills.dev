Créez d'un seul coup une interface SaaS de style outil interne/console de gestion savoureuse : coque de barre latérale, pages de liste avec en-tête collant + puces de filtre + filtres côté serveur, pages de détails sans fil, tableaux de bord KPI/graphiques et une palette de commandes globale Cmd+K. Densité Linéaire / Vercel / Notion / Stripe selon l'archétype que vous choisissez. À utiliser lorsque l'utilisateur démarre une console SaaS, un tableau de bord d'administration, un outil interne, une application Web B2B, une vue analytique ou demande une "goût-saas" / "console" / "interface utilisateur de gestion" / "page de statistiques". Indépendant du framework : transfert de modèles vers React (n'importe quel routeur), Vue, Svelte, Solid, etc. Les exemples de code se trouvent dans React pour plus de clarté. Pas pour les pages marketing, les pages de destination ou les vitrines de magasins (utilisez plutôt le goût-compétence/impeccable/frontend-design).
