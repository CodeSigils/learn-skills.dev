Genera test BDD Cucumber basati su Tzatziki (file .feature) da una specifica funzionale. Utilizza questa competenza ogni volta che un utente desidera scrivere test Cucumber, aggiungere scenari BDD, creare file di funzionalità, generare test o testare i comportamenti delle applicazioni con Gherkin, in particolare nei progetti Java/Spring che utilizzano le definizioni dei passaggi Tzatziki per HTTP, JPA, Kafka, MongoDB, OpenSearch, logging o MCP. Da utilizzare anche quando l'utente menziona la scrittura di test di integrazione, test di accettazione o test end-to-end in un progetto che ha già dipendenze Tzatziki/Cucumber, incluse le configurazioni basate su TestNG.
