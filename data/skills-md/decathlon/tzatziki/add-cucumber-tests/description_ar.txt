يُنشئ اختبارات Cucumber BDD المستندة إلى Tzatziki (ملفات .feature) من مواصفات وظيفية. استخدم هذه المهارة عندما يريد المستخدم كتابة اختبارات Cucumber، أو إضافة سيناريوهات BDD، أو إنشاء ملفات ميزات، أو إنشاء اختبارات، أو اختبار سلوكيات التطبيق باستخدام Gherkin - خاصة في مشاريع Java/Spring باستخدام تعريفات خطوة Tzatziki لـ HTTP، أو JPA، أو Kafka، أو MongoDB، أو OpenSearch، أو التسجيل، أو MCP. يُستخدم أيضًا عندما يذكر المستخدم كتابة اختبارات التكامل، أو اختبارات القبول، أو الاختبارات الشاملة في مشروع يحتوي بالفعل على تبعيات Tzatziki/Cucumber، بما في ذلك الإعدادات المستندة إلى TestNG.
