Erzeugt Tzatziki-basierte Cucumber-BDD-Tests (.feature-Dateien) aus einer Funktionsspezifikation. Verwenden Sie diese Fähigkeit immer dann, wenn ein Benutzer Cucumber-Tests schreiben, BDD-Szenarien hinzufügen, Feature-Dateien erstellen, Tests generieren oder Anwendungsverhalten mit Gherkin testen möchte – insbesondere in Java/Spring-Projekten mit Tzatziki-Schrittdefinitionen für HTTP, JPA, Kafka, MongoDB, OpenSearch, Protokollierung oder MCP. Verwenden Sie dies auch, wenn der Benutzer das Schreiben von Integrationstests, Akzeptanztests oder End-to-End-Tests in einem Projekt erwähnt, das bereits Tzatziki/Cucumber-Abhängigkeiten aufweist, einschließlich TestNG-basierter Setups.
