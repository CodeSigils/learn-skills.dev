Генерирует тесты Cucumber BDD на основе Tzatziki (файлы .feature) на основе функциональной спецификации. Используйте этот навык всякий раз, когда пользователь хочет писать тесты Cucumber, добавлять сценарии BDD, создавать файлы функций, генерировать тесты или тестировать поведение приложений с помощью Gherkin — особенно в проектах Java/Spring, использующих определения шагов Tzatziki для HTTP, JPA, Kafka, MongoDB, OpenSearch, ведения журналов или MCP. Также используйте, когда пользователь упоминает о написании интеграционных, приемочных или сквозных тестов в проекте, в котором уже есть зависимости Tzatziki/Cucumber, включая настройки на основе TestNG.
