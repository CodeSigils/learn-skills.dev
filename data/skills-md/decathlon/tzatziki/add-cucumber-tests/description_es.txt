Genera pruebas Cucumber BDD basadas en Tzatziki (archivos .feature) a partir de una especificación funcional. Utilice esta habilidad siempre que un usuario quiera escribir pruebas de Cucumber, agregar escenarios BDD, crear archivos de funciones, generar pruebas o probar comportamientos de aplicaciones con Gherkin, especialmente en proyectos Java/Spring que utilizan definiciones de pasos Tzatziki para HTTP, JPA, Kafka, MongoDB, OpenSearch, registro o MCP. Úselo también cuando el usuario mencione escribir pruebas de integración, pruebas de aceptación o pruebas de un extremo a otro en un proyecto que ya tiene dependencias de Tzatziki/Cucumber, incluidas las configuraciones basadas en TestNG.
