قم بتصميم وكتابة ومراجعة وإعادة تصميم JavaScript وTypeScript الحديثين باستخدام إرشادات TypeScript الأولى للسلامة والصحة والأداء والاتساق ونمذجة الكتابة المتقدمة. الإعداد الافتراضي هو TypeScript 5.9+، وNode.js 24+، وReact 19+، وNext.js 16+ App Router عندما يكون ذلك مناسبًا، والمتصفحات دائمة الخضرة الحالية فقط.
