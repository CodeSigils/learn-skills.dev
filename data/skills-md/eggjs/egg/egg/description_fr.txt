Cette compétence est utilisée pour gérer le framework EGG. Il fournit des conseils de décision pour la sélection parmi les concepts de base, les contrôleurs et les tests unitaires en fonction de l'intention de l'utilisateur, servant de point d'entrée pour tous les problèmes liés à EGG. Il couvre l'architecture des modules, l'injection de dépendances, les tâches en arrière-plan, le bus d'événements EventBus, la programmation orientée aspect AOP, les contrôleurs HTTP/MCP/Schedule, la validation des paramètres Ajv, les tests unitaires, etc.
