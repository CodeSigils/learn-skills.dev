Cette compétence est utilisée pour gérer le framework EGG. Il fournit des conseils de décision pour choisir parmi les concepts de base, les contrôleurs et les tests unitaires en fonction de l'intention de l'utilisateur. Il sert de point d’entrée pour toutes les questions liées à EGG. Il couvre l'architecture des modules, l'injection de dépendances, les tâches en arrière-plan, le bus d'événements EventBus, la programmation orientée aspect AOP, les contrôleurs HTTP/MCP/Schedule, la validation des paramètres Ajv, les tests unitaires, etc.

Veuillez toujours répondre dans la langue de l'utilisateur.
