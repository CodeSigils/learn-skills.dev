Esta habilidad se utiliza para manejar el marco EGG. Proporciona orientación para la toma de decisiones para elegir entre conceptos básicos, controladores y pruebas unitarias según la intención del usuario. Sirve como punto de entrada para todas las preguntas relacionadas con EGG. Cubre la arquitectura del módulo, la inyección de dependencias, las tareas en segundo plano, el bus de eventos EventBus, la programación orientada a aspectos AOP, los controladores HTTP/MCP/Schedule, la validación de parámetros Ajv, las pruebas unitarias y más.
