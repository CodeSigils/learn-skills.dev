Scrivi, modifica e rivedi gli script AEM HTL (HTML Template Language). HTL è il sistema di modelli lato server per i componenti AEM: file HTML con sintassi ${expression} e attributi di blocco data-sly-*. Da utilizzare durante la creazione o la modifica di script di componenti .html, la correzione di errori di contesto XSS, la creazione di markup condizionale/iterazione, il collegamento di modelli Sling tramite utilizzo data-sly o la creazione di modelli HTL riutilizzabili. Si attiva anche quando l'utente menziona il markup del componente HTL, Sightly, data-sly-* o AEM.
