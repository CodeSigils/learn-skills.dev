Escriba, edite y revise scripts AEM HTL (lenguaje de plantilla HTML). HTL es el sistema de plantillas del lado del servidor para componentes AEM: archivos HTML con sintaxis ${expression} y atributos de bloque data-sly-*. Úselo al crear o modificar secuencias de comandos de componentes .html, corregir errores de contexto XSS, crear marcas de iteración/condicionales, conectar modelos Sling mediante el uso inteligente de datos o construir plantillas HTL reutilizables. Actívelo también cuando el usuario mencione el marcado de componentes HTL, Sightly, data-sly-* o AEM.
