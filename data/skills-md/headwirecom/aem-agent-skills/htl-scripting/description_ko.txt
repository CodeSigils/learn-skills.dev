AEM HTL(HTML 템플릿 언어) 스크립트를 작성, 편집 및 검토합니다. HTL은 AEM 구성 요소(${expression} 구문 및 data-sly-* 블록 속성이 포함된 HTML 파일)용 서버측 템플릿 시스템입니다. .html 구성 요소 스크립트 생성 또는 수정, XSS 컨텍스트 오류 수정, 반복/조건부 마크업 작성, 데이터 교활한 사용을 통한 Sling 모델 연결 또는 재사용 가능한 HTL 템플릿 구성 시 사용합니다. 사용자가 HTL, Sightly, data-sly-* 또는 AEM 구성 요소 마크업을 언급할 때도 활성화됩니다.
