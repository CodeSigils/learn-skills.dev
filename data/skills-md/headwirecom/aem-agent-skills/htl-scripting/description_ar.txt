كتابة وتحرير ومراجعة البرامج النصية AEM HTL (لغة قالب HTML). HTL هو نظام القالب من جانب الخادم لمكونات AEM - ملفات HTML ذات بناء جملة ${expression} وسمات كتلة data-sly-*. يُستخدم عند إنشاء أو تعديل البرامج النصية لمكونات .html، أو إصلاح أخطاء سياق XSS، أو إنشاء علامات تكرارية/شرطية، أو توصيل نماذج Sling عبر استخدام البيانات، أو إنشاء قوالب HTL قابلة لإعادة الاستخدام. يتم التنشيط أيضًا عندما يذكر المستخدم علامة مكون HTL أو Sightly أو data-sly-* أو AEM.
