Code Distiller: inserisci un percorso di progetto, esegui un'analisi approfondita automatica → estrai architettura/logica di business/modelli di progettazione/standard di codifica → genera un'abilità di cognizione del progetto eseguibile.
Ciò che viene distillato non è il codice stesso, ma il “sistema operativo cognitivo” dietro di esso: decisioni architettoniche, dominio aziendale, filosofia di progettazione, DNA di codifica.
Frasi trigger: "distilla questo progetto", "distilla codice", "codice distilla", "analizza questa base di codice", "estrai progetto", "genera abilità di progetto".
Supporta anche: "aiutami a capire questo codice", "qual è l'architettura di questo progetto", "il pensiero progettuale di questa base di codice".
