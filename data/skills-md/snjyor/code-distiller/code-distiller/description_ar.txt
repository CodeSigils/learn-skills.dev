أداة تقطير الكود: قم بإدخال مسار المشروع، والتحليل التلقائي العميق ← استخراج الهندسة المعمارية/منطق الأعمال/أنماط التصميم/معايير الترميز ← إنشاء مهارة إدراك المشروع القابلة للتشغيل.
ما يتم استخلاصه ليس الكود نفسه، بل "نظام التشغيل المعرفي" الذي يقف وراءه - القرارات المعمارية، ومجال الأعمال، وفلسفة التصميم، وترميز الحمض النووي.
عبارات التحفيز: "تقطير هذا المشروع"، "تقطير الكود"، "تقطير الكود"، "تحليل قاعدة التعليمات البرمجية هذه"، "استخراج المشروع"، "توليد مهارة المشروع".
يدعم أيضًا: "ساعدني في فهم هذا الكود"، "ما هي بنية هذا المشروع"، "التفكير التصميمي لقاعدة التعليمات البرمجية هذه".
