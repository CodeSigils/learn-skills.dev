Code Distiller: 프로젝트 경로 입력, 자동 심층 분석 → 아키텍처/비즈니스 로직/디자인 패턴/코딩 표준 추출 → 실행 가능한 프로젝트 인식 스킬 생성.
정제되는 것은 코드 자체가 아니라 그 뒤에 있는 "인지 운영 체제"(아키텍처 결정, 비즈니스 영역, 디자인 철학, 코딩 DNA)입니다.
트리거 문구: "이 프로젝트 증류", "코드 증류", "코드 증류", "이 코드베이스 분석", "프로젝트 추출", "프로젝트 기술 생성".
또한 "이 코드를 이해하도록 도와주세요", "이 프로젝트의 아키텍처는 무엇입니까", "이 코드베이스의 디자인 사고"를 지원합니다.
