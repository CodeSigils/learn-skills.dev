コード蒸留器: プロジェクト パスを入力し、自動詳細分析 → アーキテクチャ/ビジネス ロジック/デザイン パターン/コーディング標準を抽出 → 実行可能なプロジェクト認識スキルを生成します。
抽出されるのはコードそのものではなく、その背後にある「認知オペレーティング システム」、つまりアーキテクチャ上の決定、ビジネス ドメイン、設計哲学、コーディング DNA です。
トリガーフレーズ: 「このプロジェクトを抽出する」、「コードを抽出する」、「コードを抽出する」、「このコードベースを分析する」、「プロジェクトを抽出する」、「プロジェクトのスキルを生成する」。
また、「このコードを理解するのを手伝ってください」、「このプロジェクトのアーキテクチャは何ですか」、「このコードベースの設計思想」もサポートされています。
