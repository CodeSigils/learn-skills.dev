Code Distiller: Geben Sie einen Projektpfad ein, führen Sie eine automatische Tiefenanalyse durch → extrahieren Sie Architektur/Geschäftslogik/Designmuster/Codierungsstandards → generieren Sie eine ausführbare Fähigkeit zur Projekterkennung.
Was destilliert wird, ist nicht der Code selbst, sondern das „kognitive Betriebssystem“ dahinter – Architekturentscheidungen, Geschäftsdomäne, Designphilosophie, Codierungs-DNA.
Auslöserphrasen: „Dieses Projekt destillieren“, „Code destillieren“, „Code destillieren“, „Diese Codebasis analysieren“, „Projekt extrahieren“, „Projektfähigkeit generieren“.
Unterstützt auch: „Hilf mir, diesen Code zu verstehen“, „Was ist die Architektur dieses Projekts“, „Das Design Thinking dieser Codebasis“.
