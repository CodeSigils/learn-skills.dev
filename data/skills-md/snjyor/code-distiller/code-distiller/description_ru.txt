Code Distiller: введите путь проекта, выполните автоматический глубокий анализ → извлеките архитектуру/бизнес-логику/шаблоны проектирования/стандарты кодирования → создайте работоспособный навык познания проекта.
Очищается не сам код, а стоящая за ним «когнитивная операционная система» — архитектурные решения, бизнес-сфера, философия дизайна, кодирующая ДНК.
Триггерные фразы: «очистить этот проект», «очистить код», «очистить код», «проанализировать эту кодовую базу», «извлечь проект», «сгенерировать проект Skill».
Также поддерживает: «помогите мне понять этот код», «какова архитектура этого проекта», «дизайнерское мышление этой кодовой базы».
