Úselo al escribir, revisar, corregir u optimizar el código de React Native Skia, incluido el renderizado de Canvas, formas, trazados, degradados, filtros, texto/fuentes, imágenes, videos, Skottie/Lottie, sistemas de partículas o sombreadores SkSL personalizados. También se activa cuando el usuario solicita crear gráficos, lienzos de dibujo, anillos de progreso, efectos de partículas, vidrio esmerilado, brillo de neón, filtros de imagen u otros gráficos acelerados por GPU con React Native Skia.
