React Native Skia (@shopify/react-native-skia) يكمل أفضل الممارسات، ورسومات ثنائية الأبعاد مُسرَّعة بواسطة وحدة معالجة الرسومات، وأنماط رسوم متحركة بمعدل 60 إطارًا في الثانية/120 إطارًا في الثانية، وتظليلات مخصصة، وتحسين الإنتاج لنظامي التشغيل iOS وAndroid. يُستخدم عند كتابة كود React Native Skia أو مراجعته أو إصلاحه أو تحسينه، بما في ذلك عرض Canvas أو الأشكال أو المسارات أو التدرجات أو المرشحات أو النصوص/الخطوط أو الصور أو الفيديو أو Skottie/Lottie أو أنظمة الجسيمات أو تظليل SkSL المخصص. تشغيل المهام التي تتضمن @shopify/react-native-skia، Canvas، Circle، Rect، Path، Group، useImage، useFont، LinearGradient، RadialGradient، RuntimeShader، Blur، BlurMask، Shadow، Atlas، Picture، Skia.Paint، Skia.Path، useDerivedValue with Skia، interpolateColors، usePathInterpolation، useRSXformBuffer، BackdropBlur، ImageShader، FractalNoise، Turbulence، Paragraph، TextPath، TextBlob، Skottie، AnimatedImage، drawAsImage، الوضع الفوري مقابل الوضع المحتفظ به، أو أي رسم/رسوم متحركة تعتمد على Skia. يتم تشغيله أيضًا عندما يطلب المستخدم إنشاء مخططات أو رسم لوحات قماشية أو حلقات تقدم أو تأثيرات جسيمية أو زجاج بلوري أو توهج نيون أو مرشحات صور أو رسومات أخرى مسرعة بواسطة وحدة معالجة الرسومات باستخدام React Native Skia.
