React Native Skia (@shopify/react-native-skia) включает в себя лучшие практики, 2D-графику с графическим ускорением, шаблоны анимации 60/120 кадров в секунду, пользовательские шейдеры и оптимизацию производства для iOS и Android. Используйте при написании, проверке, исправлении или оптимизации кода React Native Skia, включая рендеринг Canvas, фигуры, пути, градиенты, фильтры, текст/шрифты, изображения, видео, Skottie/Lottie, системы частиц или пользовательские шейдеры SkSL. Триггеры для задач, связанных с @shopify/react-native-skia, Canvas, Circle, Rect, Path, Group, useImage, useFont, LinearGradient, RadialGradient, RuntimeShader, Blur, BlurMask, Shadow, Atlas, Picture, Skia.Paint, Skia.Path, useDerivedValue with Skia, interpolateColors, usePathInterpolation, useRSXformBuffer, BackdropBlur, ImageShader, FractalNoise, Turbulence, Paragraph, TextPath, TextBlob, Skottie, AnimatedImage, drawAsImage, немедленный режим и сохраненный режим или любой рисунок/анимация на основе Skia. Также срабатывает, когда пользователь запрашивает создание диаграмм, холстов для рисования, колец прогресса, эффектов частиц, матового стекла, неонового свечения, фильтров изображений или другой графики с графическим ускорением с помощью React Native Skia.
