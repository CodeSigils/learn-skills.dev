React Native Skia (@shopify/react-native-skia) bietet umfassende Best Practices, GPU-beschleunigte 2D-Grafik, 60fps/120fps-Animationsmuster, benutzerdefinierte Shader und Produktionsoptimierung für iOS und Android. Zum Schreiben, Überprüfen, Korrigieren oder Optimieren von React Native Skia-Code, einschließlich Canvas-Rendering, Formen, Pfaden, Verläufen, Filtern, Text/Schriftarten, Bildern, Videos, Skottie/Lottie, Partikelsystemen oder benutzerdefinierten SkSL-Shadern. Löst Aufgaben aus, die @shopify/react-native-skia, Canvas, Circle, Rect, Path, Group, useImage, useFont, LinearGradient, RadialGradient, RuntimeShader, Blur, BlurMask, Shadow, Atlas, Picture, Skia.Paint, Skia.Path, useDerivedValue with Skia, interpolateColors, usePathInterpolation, useRSXformBuffer, BackgroundBlur, ImageShader, betreffen. FractalNoise, Turbulence, Paragraph, TextPath, TextBlob, Skottie, AnimatedImage, drawAsImage, sofortiger Modus vs. beibehaltener Modus oder jede Skia-basierte Zeichnung/Animation. Wird auch ausgelöst, wenn der Benutzer mit React Native Skia Diagramme, Zeichenflächen, Fortschrittsringe, Partikeleffekte, Milchglas, Neonlicht, Bildfilter oder andere GPU-beschleunigte Grafiken erstellen möchte.
