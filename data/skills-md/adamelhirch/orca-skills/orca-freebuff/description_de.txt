Senden Sie eine Aufgabe als terminalgesteuerter TUI-Worker an einen kostenlosen (werbefinanzierten) Freebuff-Codierungsagenten – die CLI von freebuff.com hat keinen Headless-Modus, daher startet der Orchestrator sie in einem Task-Worktree-Terminal, injiziert die Task-Eingabeaufforderung mit einem Fertigstellungsmarker-Vertrag, fragt Terminal-Lesevorgänge für den Marker ab und imitiert worker_done aus dem Cockpit (--from <worker_handle>). Verwenden Sie diese Option, wenn das Arbeitsteam neben Opencode/Claude Code auch kostenlose Agenten (DeepSeek V4 Flash 31.07., unbegrenzt) umfassen soll. Nur Orchestrator-Sitzungen. Mit /orca-freebuff aufrufen.
