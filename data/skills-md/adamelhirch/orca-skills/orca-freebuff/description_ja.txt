ターミナル駆動型 TUI ワーカーとして、無料 (広告サポート) の Freebuff コーディング エージェントにタスクをディスパッチします。freebuff.com CLI にはヘッドレス モードがないため、オーケストレーターはタスク ワークツリー ターミナルでタスクを起動し、タスク プロンプトに完了マーカー コントラクトを挿入し、マーカーのターミナル読み取りをポーリングし、コックピット (--<worker_handle> から) から worker_done を偽装します。ワーカー チームに、opencode/Claude Code とともにゼロコスト エージェント (DeepSeek V4 Flash 07/31、無制限) を含める必要がある場合に使用します。オーケストレーター セッションのみ。 /orca-freebuff で呼び出します。
