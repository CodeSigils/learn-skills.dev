Runbook координатора оркестрации Orca только для сеансов оркестратора: привяжите выполнение, созданное с помощью /orca-tasks, отправьте готовые задачи одно рабочее дерево-одна ветвь, управляйте DAG задач, очистите и разрешите ожидающие шлюзы решений, сторожевую проверку --ожидайте с ограниченной лестницей эскалации, объедините работу, которая удовлетворяет шлюзу слияния маркера установки, и освободите рабочих без утечек терминалов. Также имеется быстрый путь для выполнения 1-2 задач без плана. Вызовите с помощью /orca-orchestrate.
