QMT (Сверхбыстрая торговая система для быстрых инвестиций). Полное руководство по разработке стратегии на Python. Он охватывает написание стратегий, тестирование на истории, торговлю в реальном времени, справочник по API и примеры кода. Используйте этот навык, когда вам нужно разработать количественные стратегии QMT или запросить QMT API.
