دليل تطوير الإستراتيجية الرسمي لـ JoinQuant، والذي يغطي الاختبار الخلفي، وتداول الورق، وواجهات برمجة تطبيقات البيانات، ووظائف التداول، والعوامل، والمؤشرات الفنية. استخدمها عندما يقوم المستخدمون بكتابة استراتيجيات JoinQuant، أو إجراء اختبارات خلفية، أو تشغيل محاكاة التداول، أو الاستعلام عن JoinQuant API، أو استخدام get_price/order/run_daily، أو العمل مع عوامل Alpha أو المؤشرات الفنية، أو ذكر استراتيجيات JoinQuant أو 聚宽 أو jqdata. لاسترداد البيانات المحلية، يرجى استخدام أداة jqdatasdk.
