Capacité de génération de rapports de recherche sur les investissements au niveau organisationnel. Couvre les actions A chinoises, les actions de Hong Kong et les sociétés cotées aux États-Unis. Formats de sortie : 1) Aperçu de l'investissement : 3 à 5 pages, comprenant un aperçu de l'entreprise, les principaux indicateurs financiers, les multiples de valorisation, la logique d'investissement et les facteurs de risque ; 2) Rapport de recherche approfondi : ≥25 pages, comprenant une analyse de l'industrie, une carte de la chaîne industrielle, un modèle à trois déclarations, une évaluation DCF, une analyse de scénarios et des tests de sensibilité. Conditions de déclenchement : 1) Demande directe : « analyser / jeter un œil / rechercher / enquêter / introduire » + nom de l'entreprise ou ticker ; 2) Demande d'investissement : « qu'en pensez-vous / puis-je acheter / est-ce que cela vaut la peine d'investir / aidez-moi à chercher / à creuser » + entreprise ou ticker ; 3) Mots clés : rapport de recherche, résumé d'investissement, instantané d'investissement, entreprise d'une page, rapport de recherche approfondie, recherche approfondie, analyse approfondie, analyse de stock, une page, instantané, instantané d'entreprise, rapport de recherche d'investissement ; 4) Code stock : format standard (par exemple, 600519.SH, 0700.HK, AAPL, TSLA, BYD). Si l'intention n'est pas claire, demandez de manière proactive le format de sortie souhaité ; ne présumez pas par défaut.
