Capacité de génération de rapports de recherche sur les investissements au niveau institutionnel. Couvre les sociétés cotées en actions A chinoises, en actions de Hong Kong et en actions américaines. Formats de sortie : 1) Aperçu de l'investissement : 3 à 5 pages, comprend un aperçu de l'entreprise, les indicateurs financiers clés, les multiples de valorisation, la justification de l'investissement et les facteurs de risque ; 2) Rapport de recherche approfondi : ≥25 pages, comprend une analyse de l'industrie, une carte de la chaîne industrielle, un modèle à trois déclarations, une évaluation DCF, une analyse de scénarios et des tests de sensibilité. Conditions de déclenchement : 1) Demande directe : analyser / jeter un œil / rechercher / enquêter / présenter + nom de l'entreprise ou titre ; 2) Demande d'investissement : qu'en pensez-vous / peut-il être acheté / est-ce que cela vaut la peine d'investir / aidez-moi à chercher / creuser + une entreprise ou une action ; 3) Mots clés : rapport de recherche, briefing d'investissement, aperçu de l'investissement, fiche d'entreprise d'une page, rapport de recherche approfondie, recherche approfondie, analyse approfondie, analyse de titres individuels, une page, aperçu, aperçu de l'entreprise, rapport de recherche d'investissement ; 4) Code stock : format standard (par exemple, 600519.SH, 0700.HK, AAPL, TSLA, BYD). Si l'intention n'est pas claire, demandez de manière proactive le format de sortie souhaité ; ne faites pas d’hypothèses par défaut.
