La interfaz de negociación cuantitativa de inversión rápida MiniQMT, basada en la biblioteca XtQuant Python, admite la obtención de datos de mercado para acciones A/futuros/opciones (líneas K, datos de ticks, datos financieros, etc.) y la ejecución de operaciones (colocación de órdenes, cancelación, consulta de activos/órdenes/posiciones). Se utiliza cuando los usuarios necesitan obtener datos de mercado históricos/en tiempo real de MiniQMT, realizar operaciones cuantitativas o acceder a datos de backtesting.
