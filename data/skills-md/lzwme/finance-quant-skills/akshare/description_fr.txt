AKShare est une bibliothèque d'interface de données financières open source qui fournit des données financières complètes dans toutes les catégories telles que les actions, les contrats à terme, les options, les fonds, les devises, les obligations, les indices et les crypto-monnaies ; il est utilisé lorsque les utilisateurs ont besoin d'obtenir diverses données sur les marchés financiers.
