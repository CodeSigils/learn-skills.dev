Выявляйте и комплексно выполняйте работу по оптимизации репозитория: определите точки оптимизации производительности/надежности/обслуживаемости/безопасности/dx/затрат, расставьте приоритеты по принципу «воздействие-усилия-риск», затем шаг за шагом выполняйте исправления с помощью непрерывного тестирования и явной политики фиксации («final_only», «per_step», «milestone»). По умолчанию для работы по реализации используется значение «per_step», поэтому каждая функция тестируется, а затем фиксируется перед следующей функцией. Поддерживает дополнительный BDD (Дано/Когда/Тогда).
