Flujo de trabajo de contribución de código abierto de extremo a extremo: desde el escaneo de problemas hasta el envío de relaciones públicas. Utilice esta habilidad siempre que el usuario quiera contribuir a un proyecto de código abierto, encontrar problemas que solucionar, enviar una solicitud de extracción, bifurcar un repositorio para contribuir, solucionar un problema de GitHub o mencionar "contribución de código abierto". También se activa cuando proporcionan una URL de repositorio de GitHub y preguntan sobre cómo contribuir, dicen cosas como "ayúdame a enviar un PR", "encuentra buenos primeros números", "Quiero contribuir a X" o mencionan la corrección de errores en el proyecto de otra persona.
