Flusso di lavoro di contributo open source end-to-end: dalla scansione dei problemi all'invio di PR. Utilizza questa competenza ogni volta che l'utente desidera contribuire a un progetto open source, trovare problemi da risolvere, inviare una richiesta pull, eseguire il fork di un repository per contribuire, risolvere un problema GitHub o menzionare "contributo open source". Si attivano anche quando forniscono un URL del repository GitHub e chiedono di contribuire, dicono cose come "aiutami a inviare un PR", "trova buoni primi problemi", "Voglio contribuire a X" o menzionano la correzione di bug nel progetto di qualcun altro.
