Durchgängiger Open-Source-Beitragsworkflow: vom Scannen von Problemen bis zum Einreichen von PRs. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer zu einem Open-Source-Projekt beitragen, Probleme finden möchte, die behoben werden müssen, einen Pull-Request einreichen, ein Repo forken möchten, um einen Beitrag zu leisten, ein GitHub-Problem beheben oder „Open-Source-Beitrag“ erwähnen möchte. Wird auch ausgelöst, wenn sie eine GitHub-Repo-URL angeben und nach Beiträgen fragen, Dinge sagen wie „Helfen Sie mir, eine PR einzureichen“, „Finden Sie gute erste Probleme“, „Ich möchte zu X beitragen“ oder erwähnen Sie die Behebung von Fehlern im Projekt einer anderen Person.
