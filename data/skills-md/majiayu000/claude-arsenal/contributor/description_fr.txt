Flux de travail de contribution open source de bout en bout : de l'analyse des problèmes à la soumission des PR. Utilisez cette compétence chaque fois que l'utilisateur souhaite contribuer à un projet open source, rechercher des problèmes à résoudre, soumettre une demande d'extraction, créer un dépôt pour contribuer, résoudre un problème GitHub ou mentionner une « contribution open source ». Déclenchez également lorsqu'ils fournissent une URL de dépôt GitHub et demandent à contribuer, disent des choses comme « aidez-moi à soumettre un PR », « trouver de bons premiers numéros », « Je veux contribuer à X » ou mentionnez la correction de bugs dans le projet de quelqu'un d'autre.
