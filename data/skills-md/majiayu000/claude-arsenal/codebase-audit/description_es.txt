Auditoría integral de la base de código: análisis profundo paralelo adaptativo (contratos de front-end/back-end, integridad de datos, manejo de excepciones/seguridad, arquitectura/deuda técnica, configuración/almacenamiento en caché), que produce un informe unificado clasificado por gravedad y una hoja de ruta de remediación. Úselo cuando el usuario solicita auditar, analizar o revisar una base de código completa para detectar problemas de diseño, encontrar errores ocultos, verificar el estado de la arquitectura o pregunta '全面审查', '代码库审计', '分析设计问题', 'auditar base de código', 'verificación de estado', '有哪些问题'. También se activa cuando el usuario solicita encontrar degradación silenciosa, puntos de interrupción del flujo de datos, discrepancias de tipos entre el frontend y el backend o quiere comprender la deuda técnica en un proyecto.
