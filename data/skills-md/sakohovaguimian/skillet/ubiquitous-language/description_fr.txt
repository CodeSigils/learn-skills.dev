Créez ou mettez à jour un glossaire de langage omniprésent de style DDD en analysant la conversation et la base de code actuelles, en écrivant « docs/UBIQUITOUS_LANGUAGE.md » fondé sur l'utilisation réelle du modèle. À utiliser lorsque les termes du domaine doivent être définis, le langage doit être regroupé par contexte délimité, le langage du domaine doit être comparé à la dénomination de l'implémentation, ou les ambiguïtés, la dérive des synonymes, les acteurs, les relations, les états du cycle de vie, les commandes et les événements doivent être documentés. Ne pas utiliser pour les règles métier et les invariants ; utilisez `$ubiquitous-business-logic` pour ceux-là.
