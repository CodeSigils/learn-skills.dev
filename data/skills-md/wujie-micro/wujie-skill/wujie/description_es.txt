Guía de integración del framework micro frontend de Wujie (无界). Cubre la integración principal/subaplicaciones, la encapsulación de componentes Vue 2/Vue 3/React, las API startApp/setupApp/preloadApp, la sincronización y navegación de rutas, la precarga de mantenimiento, la comunicación de bus, los complementos y el ciclo de vida, la refactorización desubaplicaciones, la resolución de problemas de implementación y los problemas comunes. Utilice esta opción cuando los usuarios mencionen 无界wujie, micro‑frontend, integración de subaplicaciones o las principales subaplicaciones de carga deaplicaciones.
