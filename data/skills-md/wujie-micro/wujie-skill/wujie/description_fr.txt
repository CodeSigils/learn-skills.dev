Guide d'intégration du framework micro-frontend Wujie. Couvre l'intégration principale/sous-application, l'encapsulation des composants Vue2/Vue3/React, les API startApp/setupApp/preloadApp, la synchronisation et la navigation des itinéraires, le préchargement keep-alive, la communication par bus, les plugins et le cycle de vie, la refactorisation des sous-applications, le dépannage du déploiement et les problèmes courants. À utiliser lorsque les utilisateurs mentionnent wujie, 无界, micro-frontend, intégration de sous-applications ou sous-applications de chargement d'application principale.
