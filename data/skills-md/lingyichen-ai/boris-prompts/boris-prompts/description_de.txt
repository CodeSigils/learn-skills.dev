Schreiben Sie eine hochwertige Eingabeaufforderung für jeden LLM- oder KI-Assistenten – Claude, Claude Code, ChatGPT, Gemini, Cursor, Windsurf, Copilot oder einen beliebigen Programmier-/Chat-Agenten. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Eingabeaufforderung schreiben, verbessern, verfeinern, kürzen oder umschreiben möchte. fragt: „Wie soll ich das für [Modell] formulieren“ oder „Was ist eine gute Eingabeaufforderung für [Aufgabe]“; beschreibt eine Aufgabe, die eine KI erledigen soll, hat sie aber noch nicht als Aufforderung formuliert; oder fügt eine vorhandene Eingabeaufforderung ein und fordert zur Überarbeitung auf. Basierend auf der Prompt-Methodik von Boris (Anthropic, Claude Code-Ersteller) – kurze und genaue Prompts, Plan-before-Code, Feedbackschleifen, persistenter Kontext in Dateien. Die universellen Prinzipien (kurz, Plan zuerst, Rückkopplungsschleife, keine Polsterung) gelten für jedes LLM; Die Claude-Code-spezifischen Anker (CLAUDE.md, @file, Slash-Befehle) gelten nur, wenn das Ziel Claude Code ist. Wenn die Absicht des Benutzers unklar ist (Zielmodell, Ergebnis, Umfang oder ob die KI über eine Möglichkeit zur Selbstverifizierung verfügt, fehlt), stellen Sie 1–3 gezielte klärende Fragen über AskUserQuestion, bevor Sie die Eingabeaufforderung schreiben.
