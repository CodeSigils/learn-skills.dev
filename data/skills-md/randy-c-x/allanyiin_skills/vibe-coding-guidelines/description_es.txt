Se utiliza cuando los no programadores necesitan colaborar con Vibe Coding y un agente de codificación. Los desencadenantes comunes incluyen “ayúdenme a organizar pautas de desarrollo”, “definir límites de entrega” y “planificar métodos de validación”. Declaraciones de requisitos de salida, límites y criterios de gestión de riesgos; no reemplaza directamente la implementación.
