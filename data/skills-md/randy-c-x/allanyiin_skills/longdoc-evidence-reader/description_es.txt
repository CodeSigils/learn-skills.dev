Se utiliza cuando el usuario necesita leer un PDF extremadamente largo, un documento de especificaciones o una base de código grande y recuperar evidencia. Los desencadenantes comunes incluyen "leer este PDF largo", "ayúdame a encontrar evidencia en el código base" y "organizar citas rastreables". Resúmenes de evidencia de salida y cadenas de citas; no es adecuado para resúmenes rápidos de textos breves o contenido puramente libre.
