Используется, когда пользователь хочет спланировать содержимое слайда, сюжетную линию и ключевые моменты для каждого слайда. Общие триггеры включают «создать схему презентации», «спланировать презентацию» и «организовать сообщения по слайдам». Выводит план содержания каждого слайда и список визуальных элементов; не создает файлы PPTX или SVG напрямую.
