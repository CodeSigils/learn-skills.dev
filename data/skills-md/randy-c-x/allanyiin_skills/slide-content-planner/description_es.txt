Se utiliza cuando el usuario necesita planificar el contenido de las diapositivas, la historia y los puntos clave de cada página. Los desencadenantes comunes incluyen "crear un esquema de presentación", "planificar la presentación" y "organizar la información página por página". Genera un plan de contenido página por página y una lista de elementos visuales; no crea directamente archivos PPTX o SVG.
