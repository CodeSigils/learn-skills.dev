مهارة Salesforce Multi-Framework (بيتا) لبناء تطبيقات React التي تعمل على منصة Agentforce 360. يتم تشغيله عندما يقوم المستخدم بإنشاء أو تحرير حزم واجهة المستخدم (`uiBundles/`)، ونشر تطبيقات React للمؤلفين عبر البيانات التعريفية `UIBundle`، وتكوين `ui-bundle.json` / `.uibundle-meta.xml`، ويستخدم `@salesforce/sdk-data` (Data SDK + GraphQL)، ويقوم بتوصيل Agentforce Conversation Client (ACC) في React، وينشئ مخصصًا أسطح الذكاء الاصطناعي/الدردشة المدعومة بـ Apex REST + Models API، تصمم هياكل مساحة عمل ثلاثية اللوحات، أو سقالات مع "قالب sf ينشئ حزمة واجهة المستخدم"، أو تسأل عن اختيار React مقابل LWC على Salesforce. لا تقم بالتشغيل عندما يكون العمل هو LWC خالصًا (استخدم sf-lwc)، أو Apex عامًا (استخدم sf-apex)، أو بيانات تعريف Agentforce المُدارة بواسطة المُنشئ فقط (استخدم sf-ai-agentforce)، أو ملفات البرنامج النصي `.agent` (استخدم sf-ai-agentscript).
