Salesforce 多框架（测试版）技能，用于构建在 Agentforce 360​​ 平台上运行的 React 应用程序。当用户创建或编辑 UI 包 (`uiBundles/`) 时触发，作者通过 `UIBundle` 元数据部署 React 应用程序，配置 `ui-bundle.json` / `.uibundle-meta.xml`，使用 `@salesforce/sdk-data` (Data SDK + GraphQL)，在 React 中连接 Agentforce 对话客户端 (ACC)，构建由 Apex REST + Models API 支持的自定义 AI/聊天界面，设计三面板工作区 shell、带有“sf template generated ui-bundle”的脚手架，或者询问 Salesforce 上的 React 与 LWC 选择。当工作是纯 LWC（使用 sf-lwc）、通用 Apex（使用 sf-apex）、仅由构建器管理的 Agentforce 元数据（使用 sf-ai-agentforce）或“.agent”脚本文件（使用 sf-ai-agentscript）时，请勿触发。
