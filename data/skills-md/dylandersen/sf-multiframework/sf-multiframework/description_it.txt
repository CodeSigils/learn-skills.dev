Competenza Salesforce Multi-Framework (Beta) per la creazione di app React eseguite sulla piattaforma Agentforce 360. SI ATTIVA quando l'utente crea o modifica pacchetti UI (`uiBundles/`), crea app React distribuite tramite metadati `UIBundle`, configura `ui-bundle.json` / `.uibundle-meta.xml`, utilizza `@salesforce/sdk-data` (Data SDK + GraphQL), collega Agentforce Conversation Client (ACC) in React, crea superfici AI/chat personalizzate supportate da Apex REST + Models API, progetta shell dell'area di lavoro a tre pannelli, scaffold con `sf template generate ui-bundle` o chiede informazioni sulla scelta tra React e LWC su Salesforce. NON SI ATTIVA quando il lavoro è puro LWC (usa sf-lwc), Apex generico (usa sf-apex), solo metadati Agentforce gestiti dal Builder (usa sf-ai-agentforce) o file di script `.agent` (usa sf-ai-agentscript).
