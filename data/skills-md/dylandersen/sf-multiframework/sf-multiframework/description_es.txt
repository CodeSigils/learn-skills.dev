Habilidad de Salesforce Multi-Framework (Beta) para crear aplicaciones React que se ejecutan en la plataforma Agentforce 360. DISPARA cuando el usuario crea o edita paquetes de UI (`uiBundles/`), crea aplicaciones React implementadas a través de metadatos `UIBundle`, configura `ui-bundle.json` / `.uibundle-meta.xml`, usa `@salesforce/sdk-data` (SDK de datos + GraphQL), conecta el cliente de conversación Agentforce (ACC) en React, crea superficies personalizadas de IA/chat respaldadas por Apex REST + API de modelos, diseños de espacios de trabajo de tres paneles, andamios con `plantilla sf para generar paquete de interfaz de usuario` o preguntas sobre la opción React vs LWC en Salesforce. NO DISPARE cuando el trabajo sea LWC puro (use sf-lwc), Apex genérico (use sf-apex), solo metadatos de Agentforce administrados por Builder (use sf-ai-agentforce) o archivos de script `.agent` (use sf-ai-agentscript).
