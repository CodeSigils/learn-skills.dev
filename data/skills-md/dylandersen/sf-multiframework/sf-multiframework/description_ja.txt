Agentforce 360​​ プラットフォーム上で実行される React アプリケーションを構築するための Salesforce マルチフレームワーク (ベータ) スキル。ユーザーが UI バンドル (`uiBundles/`) を作成または編集したとき、`UIBundle` メタデータを介してデプロイされた React アプリを作成したとき、`ui-bundle.json` / `.uibundle-meta.xml` を設定したとき、`@salesforce/sdk-data` (データ SDK + GraphQL) を使用したとき、React で Agentforce Conversation Client (ACC) を接続したとき、カスタム AI/チャット サーフェスを構築したときにトリガーします。 Apex REST + モデル API によってサポートされ、3 つのパネルのワークスペース シェルを設計したり、「sf template generated ui-bundle」を使用したスキャフォールドを作成したり、Salesforce で React と LWC の選択について尋ねたりします。作業が純粋な LWC (sf-lwc を使用)、汎用 Apex (sf-apex を使用)、Builder 管理の Agentforce メタデータのみ (sf-ai-agentforce を使用)、または「.agent」スクリプト ファイル (sf-ai-agentscript を使用) の場合はトリガーしないでください。
