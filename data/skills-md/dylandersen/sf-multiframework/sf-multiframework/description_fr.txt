Compétence Salesforce Multi-Framework (bêta) pour créer des applications React qui s'exécutent sur la plateforme Agentforce 360. DÉCLENCHEMENT lorsque l'utilisateur crée ou modifie des bundles d'interface utilisateur (`uiBundles/`), crée des applications React déployées via les métadonnées `UIBundle`, configure `ui-bundle.json` / `.uibundle-meta.xml`, utilise `@salesforce/sdk-data` (Data SDK + GraphQL), connecte le client de conversation Agentforce (ACC) dans React, crée des surfaces d'IA/de chat personnalisées soutenues par L'API Apex REST + Models conçoit des shells d'espace de travail à trois panneaux, des échafaudages avec « sf template generate ui-bundle », ou pose des questions sur le choix React vs LWC sur Salesforce. NE PAS DÉCLENCHER lorsque le travail est du pur LWC (utilisez sf-lwc), du Apex générique (utilisez sf-apex), des métadonnées Agentforce gérées par Builder uniquement (utilisez sf-ai-agentforce) ou des fichiers de script `.agent` (utilisez sf-ai-agentscript).
