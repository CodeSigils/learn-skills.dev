Agentforce 360 ​​플랫폼에서 실행되는 React 앱을 구축하기 위한 Salesforce 다중 프레임워크(베타) 기술입니다. 사용자가 UI 번들(`uiBundles/`)을 생성하거나 편집할 때 트리거, `UIBundle` 메타데이터를 통해 배포된 React 앱 작성, `ui-bundle.json` / `.uibundle-meta.xml` 구성, `@salesforce/sdk-data`(데이터 SDK + GraphQL) 사용, React에서 Agentforce 대화 클라이언트(ACC) 연결, Apex REST + Models API가 지원하는 사용자 정의 AI/채팅 표면 구축, 디자인 3개의 패널로 구성된 작업 공간 셸, 'sf template generate ui-bundle'이 포함된 스캐폴드 또는 Salesforce에서 React와 LWC 선택에 관해 질문합니다. 작업이 순수 LWC(sf-lwc 사용), 일반 Apex(sf-apex 사용), Builder 관리 Agentforce 메타데이터 전용(sf-ai-agentforce 사용) 또는 `.agent` 스크립트 파일(sf-ai-agentscript 사용)인 경우에는 트리거하지 마십시오.
