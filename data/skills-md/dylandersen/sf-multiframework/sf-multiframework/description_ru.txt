Навыки Salesforce Multi Framework (бета) для создания приложений React, работающих на платформе Agentforce 360. ТРИГГЕР, когда пользователь создает или редактирует пакеты пользовательского интерфейса (`uiBundles/`), создает приложения React, развертываемые с помощью метаданных `UIBundle`, настраивает `ui-bundle.json` / `.uibundle-meta.xml`, использует `@salesforce/sdk-data` (Data SDK + GraphQL), подключает клиент диалога Agentforce (ACC) в React, создает пользовательские поддерживаемые поверхности AI/чата. от Apex REST + Models API, разрабатывает трехпанельные оболочки рабочего пространства, каркасы с `sf templategenerate ui-bundle` или спрашивает о выборе React или LWC в Salesforce. НЕ ЗАПУСКАЙТЕ, если работа представляет собой чистый LWC (используйте sf-lwc), общий Apex (используйте sf-apex), только метаданные Agentforce, управляемые Builder (используйте sf-ai-agentforce), или файлы сценариев `.agent` (используйте sf-ai-agentscript).
