Salesforce 多框架（測試版）技能，用於建立在 Agentforce 360​​ 平台上運行的 React 應用程式。當使用者建立或編輯 UI 套件 (`uiBundles/`) 時觸發，作者透過 `UIBundle` 元資料部署 React 應用程序，配置 `ui-bundle.json` / `.uibundle-meta.xml`，使用 `@salesforce/sdk-data` (Data SDK + GraphACC (Data SDK + ​​QL)，客戶連接由 AREST (Data SDK + 1ACC)，客戶連接在 Apforce 端 (DataAREST)， Models API 支援的自訂 AI/聊天介面，設計三面板工作區 shell、帶有「sf template generated ui-bundle」的鷹架，或詢問 Salesforce 上的 React 與 LWC 選擇。當工作是純 LWC（使用 sf-lwc）、通用 Apex（使用 sf-apex）、僅由建構器管理的 Agentforce 元資料（使用 sf-ai-agentforce）或「.agent」腳本檔案（使用 sf-ai-agentscript）時，請勿觸發。
