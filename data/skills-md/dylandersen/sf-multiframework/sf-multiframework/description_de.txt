Salesforce Multi-Framework (Beta)-Skill zum Erstellen von React-Apps, die auf der Agentforce 360-Plattform ausgeführt werden. TRIGGER, wenn Benutzer UI-Bundles („uiBundles/“) erstellt oder bearbeitet, React-Apps erstellt, die über „UIBundle“-Metadaten bereitgestellt werden, „ui-bundle.json“ / „.uibundle-meta.xml“ konfiguriert, „@salesforce/sdk-data“ (Data SDK + GraphQL) verwendet, den Agentforce Conversation Client (ACC) in React verkabelt, benutzerdefinierte KI-/Chat-Oberflächen erstellt, die von unterstützt werden Apex REST + Models API, entwirft Arbeitsbereich-Shells mit drei Panels, Gerüste mit „sf template generic ui-bundle“ oder fragt nach der Wahl zwischen React und LWC in Salesforce. NICHT AUSLÖSEN, wenn es sich bei der Arbeit um reines LWC (verwenden Sie sf-lwc), generisches Apex (verwenden Sie sf-apex), nur vom Builder verwaltete Agentforce-Metadaten (verwenden Sie sf-ai-agentforce) oder „.agent“-Skriptdateien (verwenden Sie sf-ai-agentscript) handelt.
