moviepy 2.x を使用した Python ビデオ合成 — AI で生成されたビデオ (LTX-2、SadTalker) に決定論的なテキストをオーバーレイし、クリップを合成し、単一ファイルの build.py ビデオ プロジェクトを実行します。 LTX-2 または SadTalker 出力にラベル/キャプション/ローワー サードを追加する場合、リモーションなしで純粋な Python で短い広告スタイルのスポットを構築する場合、またはプログラムによるビデオ合成を行う場合に使用します。トリガーには、ビデオ上のテキスト オーバーレイ、ラベル LTX-2 クリップ、キャプション SadTalker 出力、ローワー サード、build.py ビデオ、moviepy、Python ビデオ コンポジション、サブ 30 秒の広告スポットが含まれます。
