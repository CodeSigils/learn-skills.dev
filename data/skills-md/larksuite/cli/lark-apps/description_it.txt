Distribuire file o directory HTML locali su Feishu Miaoda, generando una pagina Web condivisibile e restituendo il relativo URL; gestire la creazione, l'aggiornamento, l'elenco e l'ambito di accesso delle applicazioni. Utilizzalo quando un utente desidera pubblicare HTML, un sito Web statico o una demo Web come collegamento condivisibile o quando menziona Miaoda. Non per: caricare file ordinari nell'archivio cloud (utilizzando lark-drive), modificare il contenuto dei documenti cloud Feishu (utilizzando lark-doc), creare diapositive/presentazioni Feishu native (utilizzando lark-slides).
