Distribuire file o directory HTML locali su Feishu Miaoda, generando una pagina Web condivisibile e restituendo il relativo URL; gestire la creazione, l'aggiornamento, l'elenco e l'ambito di accesso delle applicazioni. Utilizzalo quando un utente desidera pubblicare HTML, siti Web statici o demo Web come collegamenti condivisibili o quando fa riferimento a Miaoda. Non per: caricare file normali nell'archivio cloud (utilizzando lark‑drive), modificare documenti cloud Feishu (utilizzando lark‑doc) o creare diapositive/presentazioni Feishu native (utilizzando lark‑slides).
