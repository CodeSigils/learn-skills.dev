ローカルの HTML ファイルまたはディレクトリを Feishu Miaoda にデプロイし、共有可能な Web ページを生成してその URL を返します。アプリケーションの作成、更新、リスト、およびアクセス範囲を管理します。ユーザーが HTML、静的 Web サイト、Web デモを共有可能なリンクとして公開したい場合、または Miaoda について言及する場合にこれを使用します。対象外: 通常のファイルをクラウド ストレージにアップロードすること (lark-drive を使用)、Feishu クラウド ドキュメント コンテンツの編集 (lark-doc を使用)、ネイティブ Feishu スライド/プレゼンテーションの作成 (lark-slides を使用)。
