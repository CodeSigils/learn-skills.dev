Deploy local HTML files or directories to Feishu Miaoda, generating a shareable web page and returning its URL; manage the creation, updating, listing, and access scope of applications. Use this when a user wants to publish HTML, a static website, or a web demo as a shareable link, or when mentioning Miaoda. Not for: uploading ordinary files to cloud storage (using lark-drive), editing Feishu cloud document content (using lark-doc), creating native Feishu slides/presentations (using lark-slides).
