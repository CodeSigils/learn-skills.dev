Implementar archivos o directorios HTML locales en Feishu Miaoda, generar una página web que se pueda compartir y devolver su URL; Gestionar la creación, actualización, listado y acceso al alcance de las aplicaciones. Úselo cuando un usuario quiera publicar HTML, un sitio web estático o una demostración web como un enlace para compartir, o cuando mencione a Miaoda. No apto para: cargar archivos normales al almacenamiento en la nube (usando lark-drive), editar el contenido del documento en la nube de Feishu (usando lark-doc), crear diapositivas/presentaciones nativas de Feishu (usando lark-slides).
