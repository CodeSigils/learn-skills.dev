Déployer des fichiers ou des répertoires HTML locaux sur Feishu Miaoda, en générant une page Web partageable et en renvoyant son URL ; gérer la création, la mise à jour, le référencement et la portée d'accès des applications. Utilisez-le lorsqu'un utilisateur souhaite publier du HTML, un site Web statique ou une démo Web sous forme de lien partageable, ou lorsqu'il mentionne Miaoda. Pas pour : télécharger des fichiers ordinaires sur le stockage cloud (à l'aide de lark-drive), modifier le contenu du document cloud Feishu (à l'aide de lark-doc), créer des diapositives/présentations Feishu natives (à l'aide de lark-slides).
