Foglio di calcolo Feishu: crea e manipola fogli di calcolo. Crea tabelle e scrivi intestazioni e dati, leggi e scrivi celle, aggiungi dati di righe, cerca il contenuto delle celle in un foglio di calcolo noto, esporta file di tabelle. Utilizzare quando l'utente deve creare fogli di calcolo, leggere/scrivere dati in batch, cercare contenuti in una tabella conosciuta, esportare o scaricare tabelle. Se l'utente desidera cercare file di fogli di calcolo nello spazio cloud per nome o parola chiave, utilizzare docs +search di lark-doc per individuare prima la risorsa.
