Nozioni di base condivise sulla CLI Feishu/Lark: inizializzazione della configurazione dell'app, login di autenticazione (login aut), cambio di identità (--come utente/bot), gestione di permessi e ambiti, gestione degli errori di autorizzazione negata, regole di sicurezza. Si attiva quando l'utente deve effettuare la configurazione per la prima volta (`lark-cli config init`), utilizzare l'autorizzazione di accesso (`lark-cli auth login`), riscontrare autorizzazioni insufficienti, cambiare identità utente/bot, configurare l'ambito o utilizzare lark-cli per la prima volta.
