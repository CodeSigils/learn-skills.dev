Когда вам нужно использовать lark-cli для работы Feishu Bitable (Base): подходит для создания таблиц, управления полями, чтения/записи записей, конфигурации просмотра, запроса истории и управления ролями/формами/панелью мониторинга; также для преобразования старого синтаксиса +table/+field/+record в текущие команды. Требуется для проектирования полей, полей формул, ссылок на поиск, вычислений в перекрестных таблицах, производных показателей на уровне строк и анализа данных.
