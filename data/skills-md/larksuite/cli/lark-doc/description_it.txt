Feishu Cloud Docs: crea e modifica documenti Feishu. Crea documenti da Markdown, recupera il contenuto dei documenti, aggiorna i documenti (aggiungi/sovrascrivi/sostituisci/inserisci/elimina), carica e scarica immagini e file all'interno dei documenti, cerca documenti nello spazio cloud. Utilizzalo quando l'utente deve creare o modificare documenti Feishu, leggere il contenuto del documento, inserire immagini nei documenti o cercare documenti nello spazio cloud. Se l'utente desidera individuare fogli di calcolo, report o altri oggetti dello spazio cloud per nome o parole chiave, dai la priorità all'utilizzo di documenti+ricerca di questa competenza per l'individuazione delle risorse.
