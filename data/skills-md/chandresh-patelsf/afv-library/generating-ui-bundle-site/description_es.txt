DEBE activarse cuando el proyecto contiene un directorio uiBundles/*/src/ y la tarea implica crear o configurar la infraestructura del sitio. Utilice esta habilidad al crear o configurar un sitio de experiencia digital de Salesforce para alojar un paquete de interfaz de usuario. Actívelo cuando existan archivos que coincidan con digitalExperiences/, redes/, customSite/ o DigitalExperienceBundle y necesiten modificación, o cuando el usuario desee publicar, alojar o configurar el acceso de invitados para su aplicación.
