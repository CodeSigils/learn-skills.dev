Entwerfen Sie datengesteuerte Godot 4.x-Spiele mit benutzerdefinierten Ressourcenklassen: Definieren Sie typisierte Daten mit Klassenname + @export, speichern/laden Sie .tres/.res-Dateien, instanzieren und duplizieren Sie Ressourcen und laden Sie sie bei Bedarf mit ResourceLoader (einschließlich Thread-Laden). Verwenden Sie diese Option, wenn Sie Elemente/Statistiken/Konfigurationen als Daten in einem Godot-Projekt modellieren, .tres-Ressourcen erstellen oder mit benutzerdefinierten Ressourcenunterklassen und ResourceLoader/ResourceSaver arbeiten.
