Создавайте управляемые данными игры Godot 4.x с помощью пользовательских классов ресурсов: определяйте типизированные данные с помощью class_name + @export, сохраняйте/загружайте файлы .tres/.res, создайте экземпляры и дублируйте ресурсы, а также загружайте их по требованию с помощью ResourceLoader (включая потоковую загрузку). Используйте при моделировании элементов/статистики/конфигураций как данных в проекте Godot, создании ресурсов .tres или работе с пользовательскими подклассами Resource и ResourceLoader/ResourceSaver.
