Utilisez C#/.NET dans Godot 4.7 : classes partielles étendant les nœuds, le cycle de vie PascalCase (_Ready/_Process/_PhysicsProcess), les champs [Export], les délégués [Signal] en tant qu'événements C#, la recherche de nœuds de type sécurisé et les appels entre C# et GDScript. À utiliser lors de l'écriture de code de jeu Godot en C# (fichiers .cs, .csproj), nécessitant la version Godot .NET, convertissant des modèles GDScript en C# ou câblant des signaux Godot en tant qu'événements C#.
