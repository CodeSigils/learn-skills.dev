Richten Sie ein Phaser 3-Spiel ein und debuggen Sie es: die Spielkonfiguration, den Szenenlebenszyklus (Init/Vorladen/Erstellen/Aktualisieren), den Asset Loader, Kameras und szenenübergreifende Kommunikation. Wird beim Erstellen oder Debuggen eines Phaser 3-Spiels verwendet – wenn der Benutzer Phaser, Phaser.Game, Phaser.Scene, preload/create/update, this.load, this.add oder Szenenübergänge erwähnt. Für Arcade-Physics-Bewegungen/Kollisionen verwenden Sie Phaser-Arcade-Physics.
