Publiez ou mettez à jour un jeu sur Steam avec Steamworks et SteamPipe : configurez les dépôts et les packages, téléchargez des builds avec steamcmd, définissez une build en direct sur une branche et exécutez les listes de contrôle de publication. À utiliser pour la publication Steam, les téléchargements app_build.vdf/steamcmd, les dépôts, les branches bêta ou une version de page de magasin.
