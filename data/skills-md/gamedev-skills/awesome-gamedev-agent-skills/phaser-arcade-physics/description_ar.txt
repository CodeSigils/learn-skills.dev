استخدم فيزياء أركيد Phaser 3: قم بتمكين العالم، وإعطاء أجسام الكائنات المتحركة، وضبط السرعة/التسارع/الجاذبية، وحل الاصطدامات مع المصادمات والتداخلات والمجموعات وحدود العالم. يُستخدم عندما تحتاج لعبة Phaser إلى الحركة أو الاصطدامات - عندما يذكر المستخدم Arcade Physics، أو this.physics، أو setVelocity، أو Collider، أو التداخل، أو الجاذبية، أو onFloor، أو وحدة التحكم في النظام الأساسي/من أعلى إلى أسفل. لتكوين اللعبة والمشاهد والمحمل، استخدمphaser-core.
