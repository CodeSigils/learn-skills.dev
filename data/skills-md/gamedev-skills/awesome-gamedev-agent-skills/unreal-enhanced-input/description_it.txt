Configura l'input del giocatore in Unreal Engine 5 con input avanzato: azioni di input, contesti di mappatura dell'input, modificatori e trigger, aggiunta del contesto di mappatura e azioni vincolanti tramite ETriggerEvent. Da utilizzare quando si collegano input di movimento/aspetto/salto, si creano risorse IA_/IMC_, si esegue l'associazione in C++ o Blueprint o quando l'utente menziona input avanzato, contesto di mappatura input, azione di input, IA_/IMC_ o ETriggerEvent.
