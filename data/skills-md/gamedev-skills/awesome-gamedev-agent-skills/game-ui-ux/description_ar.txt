تصميم وبناء واجهة المستخدم/تجربة المستخدم للعبة - شاشات العرض والقوائم والتراكبات - التي تبقى على قيد الحياة في كل شاشة: تخطيط سريع الاستجابة قائم على المرساة، وقياس الدقة/العرض والمناطق الآمنة، والتنقل البؤري للوحة المفاتيح/لوحة الألعاب، ومكدس حالة الشاشة/القائمة، وتحديثات HUD المستندة إلى الأحداث (غير المقتطفة). أنماط محايدة للمحرك تتوافق مع مهارة واجهة المستخدم الخاصة بالمحرك المكتشف. يُستخدم عندما يذكر المستخدم HUD، أو شريط الصحة، أو القائمة الرئيسية، أو قائمة الإيقاف المؤقت، أو شاشة الإعدادات، أو تخطيط واجهة المستخدم، أو نقاط التثبيت، أو قياس واجهة المستخدم، أو نسبة العرض إلى الارتفاع، أو المنطقة الآمنة، أو التنقل في قائمة وحدة التحكم/لوحة المفاتيح، أو توصيل واجهة المستخدم بحالة اللعبة.
