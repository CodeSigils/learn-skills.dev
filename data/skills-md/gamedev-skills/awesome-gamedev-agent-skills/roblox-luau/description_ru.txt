Создавайте сценарии для Roblox в Luau: получайте сервисы, создавайте и родительские экземпляры, подключайте события, запускайте серверные сценарии вместо клиентских локальных сценариев и общайтесь через границу клиент/сервер с помощью RemoteEvents/RemoteFunctions (авторитетно для сервера). Используйте при создании или отладке сценариев Roblox Studio — когда пользователь упоминает Roblox, Luau, сервисы, RemoteEvent, Instance.new, PlayerAdded или клиент против сервера. Для сохранения данных игрока используйте roblox-datastores.
