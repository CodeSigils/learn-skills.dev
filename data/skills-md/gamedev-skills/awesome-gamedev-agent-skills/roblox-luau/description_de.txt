Erstellen Sie ein Skript für ein Roblox-Erlebnis in Luau: Rufen Sie Dienste ab, erstellen und übergeordnete Instanzen, verbinden Sie Ereignisse, führen Sie Server-Skripts gegenüber Client-LocalScripts aus und kommunizieren Sie über die Client-/Server-Grenze hinweg mit RemoteEvents/RemoteFunctions (serverautorisierend). Wird beim Erstellen oder Debuggen von Roblox Studio-Skripten verwendet – wenn der Benutzer Roblox, Luau, Dienste, RemoteEvent, Instance.new, PlayerAdded oder Client vs. Server erwähnt. Zum Speichern von Spielerdaten verwenden Sie Roblox-Datastores.
