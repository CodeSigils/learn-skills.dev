Luau에서 Roblox 경험 스크립팅: 서비스 가져오기, 인스턴스 생성 및 상위 구성, 이벤트 연결, 서버 스크립트 및 클라이언트 LocalScript 실행, RemoteEvents/RemoteFunctions(서버 권한 부여)를 사용하여 클라이언트/서버 경계를 넘어 통신합니다. Roblox Studio 스크립트를 구축하거나 디버깅할 때 사용합니다. 사용자가 Roblox, Luau, 서비스, RemoteEvent, Instance.new, PlayerAdded 또는 클라이언트 대 서버를 언급할 때 사용합니다. For saving player data use roblox-datastores.
