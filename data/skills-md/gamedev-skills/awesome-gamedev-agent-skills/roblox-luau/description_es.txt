Cree un script para una experiencia de Roblox en Luau: obtenga servicios, cree instancias principales, conecte eventos, ejecute scripts de servidor versus scripts locales de cliente y comuníquese a través del límite cliente/servidor con RemoteEvents/RemoteFunctions (autoridad del servidor). Úselo al crear o depurar scripts de Roblox Studio, cuando el usuario mencione Roblox, Luau, servicios, RemoteEvent, Instance.new, PlayerAdded o cliente vs servidor. Para guardar los datos del jugador, utilice roblox-datastores.
