Prepare una escena three.js: importe mapas y la ruta tres/complementos, el trío Escena/PerspectiveCamera/WebGLRenderer, el bucle de renderizado setAnimationLoop, cambio de tamaño responsivo y OrbitControls. Úselo al iniciar o depurar una aplicación three.js: cuando el usuario menciona three.js, THREE.Scene, WebGLRenderer, PerspectiveCamera, el bucle de renderizado, el cambio de tamaño u OrbitControls. Para los modelos utilice threejs-gltf-loading; para materiales/luces utilice threejs-materials-lighting.
