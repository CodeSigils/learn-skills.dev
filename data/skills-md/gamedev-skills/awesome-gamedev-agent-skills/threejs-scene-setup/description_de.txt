Erstellen Sie eine Three.js-Szene: Importieren Sie Karten und den Three/Addons-Pfad, das Scene/PerspectiveCamera/WebGLRenderer-Trio, die setAnimationLoop-Renderschleife, responsive Größenänderung und OrbitControls. Wird beim Starten oder Debuggen einer Three.js-App verwendet – wenn der Benutzer three.js, THREE.Scene, WebGLRenderer, PerspectiveCamera, die Renderschleife, die Größenänderung oder OrbitControls erwähnt. Für Modelle verwenden Sie threejs-gltf-loading; Verwenden Sie für Materialien/Lichter threejs-materials-lighting.
