Créez une scène three.js : importez des cartes et le chemin three/addons, le trio Scene/PerspectiveCamera/WebGLRenderer, la boucle de rendu setAnimationLoop, le redimensionnement réactif et OrbitControls. À utiliser lors du démarrage ou du débogage d'une application three.js — lorsque l'utilisateur mentionne three.js, THREE.Scene, WebGLRenderer, PerspectiveCamera, la boucle de rendu, le redimensionnement ou OrbitControls. Pour les modèles, utilisez threejs-gltf-loading ; pour les matériaux/lumières, utilisez threejs-materials-lighting.
