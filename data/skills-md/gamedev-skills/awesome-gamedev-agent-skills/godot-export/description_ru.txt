Экспортируйте и создайте проект Godot 4.x для распространения: установите шаблоны экспорта, определите настройки экспорта (Windows/macOS/Linux/Web/Android), запустите автономный экспорт из командной строки для CI и обработайте веб-версию (HTML5) COOP/COEP, а также сборки для выделенного сервера/безголового сервера. Используйте при экспорте игры Godot, настройке файла Export_presets.cfg, сборке для Интернета, настольных компьютеров или мобильных устройств или автоматизации сборок из командной строки.
