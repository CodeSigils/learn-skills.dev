Exporte y cree un proyecto Godot 4.x para su distribución: instale plantillas de exportación, defina ajustes preestablecidos de exportación (Windows/macOS/Linux/Web/Android), ejecute exportaciones de línea de comandos sin cabeza para CI y maneje COOP/COEP web (HTML5) y compilaciones de servidor dedicado/sin cabeza. Úselo al exportar un juego de Godot, configurar export_presets.cfg, compilar para web/escritorio/móvil o automatizar compilaciones desde la línea de comandos.
