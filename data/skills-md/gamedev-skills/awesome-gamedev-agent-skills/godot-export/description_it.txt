Esporta e crea un progetto Godot 4.x per la distribuzione: installa modelli di esportazione, definisci le preimpostazioni di esportazione (Windows/macOS/Linux/Web/Android), esegui esportazioni da riga di comando headless per CI e gestisci COOP/COEP web (HTML5) e build con server dedicato/headless. Da utilizzare quando si esporta un gioco Godot, si configura export_presets.cfg, si crea per web/desktop/mobile o si automatizzano build dalla riga di comando.
