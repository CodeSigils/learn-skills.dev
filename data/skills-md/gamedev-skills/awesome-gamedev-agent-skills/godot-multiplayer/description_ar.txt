أنشئ ألعابًا شبكية باستخدام وضع Godot 4.7 متعدد اللاعبين عالي المستوى: قم بإعداد خادم/عميل ENetMultiplayerPeer، وحدد RPCs باستخدام التعليق التوضيحي @rpc (اتصل عبر rpc()/rpc_id())، وقم بتعيين سلطة متعددة اللاعبين لكل عقدة، وكرر الحالة باستخدام MultiplayerSpawner وMultplayerSynchronizer. يُستخدم عند إضافة لاعبين متعددين/شبكات إلى مشروع Godot، أو كتابة وظائف @rpc، أو مزامنة حالة اللاعب/العالم عبر الأقران.
