Erstellen Sie vernetzte Spiele mit Godot 4.7 High-Level-Multiplayer: Richten Sie einen ENetMultiplayerPeer-Server/-Client ein, definieren Sie RPCs mit der @rpc-Annotation (Aufruf über rpc()/rpc_id()), legen Sie die Multiplayer-Autorität pro Knoten fest und replizieren Sie den Status mit MultiplayerSpawner und MultiplayerSynchronizer. Verwenden Sie diese Option, wenn Sie Multiplayer/Netzwerk zu einem Godot-Projekt hinzufügen, @rpc-Funktionen schreiben oder den Spieler-/Weltstatus über Peers hinweg synchronisieren.
