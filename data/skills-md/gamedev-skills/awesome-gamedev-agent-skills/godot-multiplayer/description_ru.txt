Создавайте сетевые игры с помощью многопользовательской игры высокого уровня Godot 4.7: настройте сервер/клиент ENetMultiplayerPeer, определите RPC с аннотацией @rpc (вызов через rpc()/rpc_id()), установите права многопользовательской игры для каждого узла и реплицируйте состояние с помощью MultiplayerSpawner и MultiplayerSynchronizer. Используйте при добавлении многопользовательской/сетевой игры в проект Godot, написании функций @rpc или синхронизации состояния игрока/мира между узлами.
