Estructura una aplicación Bevy en torno a su sistema de componentes de entidad: crea la aplicación con complementos, define tipos de componentes/recursos, escribe sistemas con consultas/resoluciones/comandos, filtra y ordena sistemas y usa el recurso de tiempo para movimiento independiente de la velocidad de fotogramas. Úselo al crear o depurar un juego de Bevy en Rust, cuando el usuario menciona Bevy, ECS, App::new, add_systems, Query, Commands, componentes/sistemas o Cargo.toml, según el grupo.
