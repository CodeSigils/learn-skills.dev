قم ببناء تطبيق Bevy حول نظام مكونات الكيان الخاص به: أنشئ التطبيق باستخدام المكونات الإضافية، وحدد أنواع المكونات/الموارد، وكتابة الأنظمة باستخدام الاستعلام/الدقة/الأوامر، وأنظمة التصفية والطلب، واستخدم مورد الوقت للحركة المستقلة عن معدل الإطارات. يُستخدم عند إنشاء لعبة Bevy أو تصحيح أخطائها في Rust - عندما يذكر المستخدم Bevy، أو ECS، أو App::new، أو add_systems، أو Query، أو Commands، أو Components/systems، أو Cargo.toml اعتمادًا على bevy.
