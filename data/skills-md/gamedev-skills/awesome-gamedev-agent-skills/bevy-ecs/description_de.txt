Strukturieren Sie eine Bevy-App um ihr Entitätskomponentensystem herum: Erstellen Sie die App mit Plugins, definieren Sie Komponenten-/Ressourcentypen, schreiben Sie Systeme mit Abfragen/Auflösungen/Befehlen, Filter- und Ordnungssystemen und verwenden Sie die Zeitressource für bildratenunabhängige Bewegungen. Wird beim Erstellen oder Debuggen eines Bevy-Spiels in Rust verwendet – wenn der Benutzer je nach Bevy Bevy, ECS, App::new, add_systems, Query, Commands, Components/Systems oder eine Cargo.toml erwähnt.
