Collega l'input del lettore in Unity 6 con il pacchetto Input System: azioni di input, mappe di azioni, componente PlayerInput e lettura di valori tramite callback o polling. Da utilizzare quando il progetto ha una risorsa .inputactions o com.unity.inputsystem oppure quando l'utente menziona Unity Input System, InputAction, mappe di azioni, PlayerInput, schemi di controllo o riassociazione.
