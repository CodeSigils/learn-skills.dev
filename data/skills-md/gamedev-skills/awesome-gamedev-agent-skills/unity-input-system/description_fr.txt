Câblez la saisie du lecteur dans Unity 6 avec le package Input System : actions d'entrée, cartes d'action, composant PlayerInput et lecture des valeurs via des rappels ou des interrogations. À utiliser lorsque le projet possède un actif .inputactions ou com.unity.inputsystem, ou lorsque l'utilisateur mentionne le système d'entrée Unity, InputAction, les cartes d'action, PlayerInput, les schémas de contrôle ou la reliure.
