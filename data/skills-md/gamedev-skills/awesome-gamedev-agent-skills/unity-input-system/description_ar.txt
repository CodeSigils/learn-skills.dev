إدخال المشغل السلكي في Unity 6 باستخدام حزمة نظام الإدخال: إجراءات الإدخال، وخرائط الإجراءات، ومكون PlayerInput، وقراءة القيم عبر عمليات الاسترجاعات أو الاستقصاء. يُستخدم عندما يحتوي المشروع على أصل .inputactions أو com.unity.inputsystem، أو عندما يذكر المستخدم نظام Unity Input System، أو InputAction، أو خرائط الإجراءات، أو PlayerInput، أو أنظمة التحكم، أو إعادة الربط.
