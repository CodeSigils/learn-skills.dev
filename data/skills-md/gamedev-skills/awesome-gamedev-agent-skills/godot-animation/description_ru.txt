Анимируйте в Godot 4.7 тремя способами: AnimationPlayer для клипов с ключевыми кадрами (включая дорожки вызовов и сигналов), AnimationTree с конечными автоматами и пространствами смешивания для анимации персонажей и Tween для коротких процедурных анимаций пользовательского интерфейса с помощью create_tween(). Используйте при работе с узлами AnimationPlayer/AnimationTree в .tscn, смешивании состояний персонажей, анимации спрайт-листа или управляемых кодом твинах.
