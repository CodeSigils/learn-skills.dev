أضف "العصير" وإحساس اللعبة الذي يجعل الإجراءات مُرضية - اهتزاز الشاشة، وإطارات التوقف/التجميد، والحركة المزدوجة/المخففة، والسحق والتمدد، والارتداد، والتعليقات الصوتية والمرئية ذات الطبقات - كتقنيات محايدة للمحرك تقترن مع واجهات برمجة التطبيقات الخاصة بالمحرك المكتشف والجسيمات والكاميرا. يُستخدم عندما يذكر المستخدم إحساس اللعبة، أو العصير، أو "اجعلها تشعر بالارتياح/القوة"، أو اهتزاز الشاشة، أو التوقف عن العمل، أو تجميد الشاشة، أو التخفيف، أو السحق والتمدد، أو إطارات التأثير، أو التعليقات/التحسين على الضربات، والقفزات، والالتقاطات، والوفيات.
