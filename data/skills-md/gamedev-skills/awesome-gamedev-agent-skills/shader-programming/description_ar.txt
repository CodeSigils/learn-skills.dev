اكتب تظليلات اللعبة من أساسيات المحرك المتقاطع - خط الأنابيب vertex→fragment، ومساحات الإحداثيات، ورياضيات الأشعة فوق البنفسجية، والتأثيرات الشائعة ثنائية الأبعاد/ثلاثية الأبعاد (الصبغة، وتمرير الأشعة فوق البنفسجية، والذوبان، والمخطط التفصيلي، وحافة فريسنل، والمقالة القصيرة) في GLSL مع مكافئات HLSL. يُستخدم عندما يذكر المستخدم التظليل، أو تظليل الجزء/البكسل، أو تظليل قمة الرأس، أو الأشعة فوق البنفسجية، أو GLSL، أو HLSL، أو تأثيرات مثل الذوبان، أو المخطط التفصيلي، أو ضوء الحافة.
