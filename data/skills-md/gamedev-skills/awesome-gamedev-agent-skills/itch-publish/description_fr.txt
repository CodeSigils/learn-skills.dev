Publiez et mettez à jour un jeu sur itch.io : créez la page du projet et téléchargez les builds avec la CLI majordome (butler push) sur les canaux nommés. À utiliser pour la publication itch.io, le push majordome, la dénomination de canal pour Windows/macOS/Linux/HTML5, les téléchargements de version ou l'envoi d'un jam ou d'une version de version vers itch.io.
