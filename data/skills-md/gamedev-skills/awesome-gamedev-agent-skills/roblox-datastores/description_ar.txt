استمرار بيانات اللاعب في Roblox باستخدام DataStoreService: GetDataStore وGetAsync/ SetAsync/UpdateAsync/IncrementAsync ملفوفة في pcall والتحميل عند الانضمام والحفظ عند الإجازة بالإضافة إلى BindToClose وإعادة المحاولة ولوحات المتصدرين OrderedDataStore. يُستخدم عند حفظ البيانات المستمرة أو تحميلها في تجربة Roblox - عندما يذكر المستخدم DataStore، أو DataStoreService، أو GetAsync، أو SetAsync، أو UpdateAsync، أو حفظ بيانات اللاعب، أو لوحات الصدارة. بالنسبة للبرمجة النصية العامة لـ Luau، استخدم roblox-luau.
