Conservez les données des joueurs dans Roblox avec DataStoreService : GetDataStore, GetAsync/ SetAsync/UpdateAsync/IncrementAsync enveloppés dans pcall, chargement lors de la jointure et sauvegarde lors du congé, ainsi que BindToClose, les tentatives et les classements OrderedDataStore. À utiliser lors de l'enregistrement ou du chargement de données persistantes dans une expérience Roblox — lorsque l'utilisateur mentionne DataStore, DataStoreService, GetAsync, SetAsync, UpdateAsync, enregistre les données du joueur ou les classements. Pour les scripts Luau généraux, utilisez roblox-luau.
