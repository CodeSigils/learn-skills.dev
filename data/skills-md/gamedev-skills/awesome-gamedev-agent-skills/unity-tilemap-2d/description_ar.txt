قم ببناء خرائط بلاط ثنائية الأبعاد وكتابتها في Unity 6: مكونات Grid + Tilemap، وTile Palette، ومصادمات Tilemap، وقواعد البلاط، وطلاء SetTile/GetTile في وقت التشغيل. يُستخدم عند طلاء مستويات التجانب، أو إضافة TilemapCollider2D، أو استخدام تجانبات القاعدة أو الرسوم المتحركة، أو إنشاء خرائط تجانب من التعليمات البرمجية، أو عندما يذكر المستخدم خريطة تجانب Unity، أو لوحة التجانب، أو تجانب القاعدة، أو الشبكة.
