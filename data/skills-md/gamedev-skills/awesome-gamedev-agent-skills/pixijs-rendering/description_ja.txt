PixiJS v8 レンダー レイヤーを構築します。非同期アプリケーションを作成し、アセットを使用してテクスチャをロードし、コンテナーとスプライトを使用してシーン グラフを構成し、ティッカー ループを駆動し、ポインター イベントを配線し、レンダー グループを使用して描画をグループ化します。 PixiJS v8 をビルドまたはデバッグするとき、つまりユーザーが PixiJS、Pixi、Application、app.stage、Container、Sprite、Assets.load、app.ticker、またはeventModeに言及するときに使用します。 v8 async init() API を固定します。
