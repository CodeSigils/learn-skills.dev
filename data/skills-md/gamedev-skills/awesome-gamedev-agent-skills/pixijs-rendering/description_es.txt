Cree una capa de renderizado PixiJS v8: cree la aplicación asíncrona, cargue texturas con Assets, componga el gráfico de escena con Container y Sprite, controle el ciclo de teletipo, conecte eventos de puntero y agrupe dibujos con grupos de renderizado. Úselo al compilar o depurar PixiJS v8: cuando el usuario mencione PixiJS, Pixi, Application, app.stage, Container, Sprite, Assets.load, app.ticker o eventMode. Fija la API v8 async init().
