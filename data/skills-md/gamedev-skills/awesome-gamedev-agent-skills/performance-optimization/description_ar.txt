ابحث عن مشكلات أداء اللعبة وحلها بطريقة منهجية - قم بالقياس باستخدام ملف تعريف المحرك أولاً، والسبب المتعلق بميزانية وقت الإطار، وحدد موقع عنق الزجاجة بين وحدة المعالجة المركزية ووحدة معالجة الرسومات، ثم قم بتطبيق الإصلاح الصحيح: تجميع الكائنات، وتجميع استدعاءات السحب، وعدد أقل من التخصيصات/ارتفاعات GC، وميزانيات الأصول. طريقة محايدة للمحرك تقترن مع ملف تعريف كل محرك. يُستخدم عندما يذكر المستخدم الأداء، أو التحسين، أو انخفاض/إسقاط FPS، أو انخفاض الإطار، أو التأتأة، أو التأخر، أو ملف التعريف، أو ميزانية الإطار، أو سحب المكالمات، أو التجميع، أو جمع البيانات المهملة/ارتفاعات GC، أو تجميع الكائنات، أو "تعمل اللعبة ببطء".
