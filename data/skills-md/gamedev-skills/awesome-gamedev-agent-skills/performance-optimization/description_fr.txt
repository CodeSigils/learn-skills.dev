Recherchez et corrigez méthodiquement les problèmes de performances du jeu : mesurez d'abord avec le profileur de moteur, raisonnez sur le budget de temps d'image, localisez le goulot d'étranglement CPU contre GPU, puis appliquez la bonne solution : pool d'objets, traitement par lots d'appels, moins d'allocations/pics de GC et budgets d'actifs. Méthode neutre pour le moteur qui s'associe au profileur de chaque moteur. À utiliser lorsque l'utilisateur mentionne les performances, l'optimisation, les FPS faibles/chutes, les pertes d'images, le bégaiement, le décalage, le profileur, le budget d'images, les appels de tirage, le traitement par lots, les pics de garbage collection/GC, le pool d'objets ou "le jeu tourne lentement".
