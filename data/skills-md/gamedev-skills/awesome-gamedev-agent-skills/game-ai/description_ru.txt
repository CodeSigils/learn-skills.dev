Создавайте механизмы принятия решений NPC и противником с помощью конечных автоматов, деревьев поведения, поведения рулевого управления и поиска пути A* — алгоритмов, нейтральных к движку, которые сочетаются с навигационным API обнаруженного движка. Используйте при построении ИИ противника, FSM или дереве поведения, управлении/скоплении или поиске пути, а также когда пользователь упоминает конечный автомат, дерево поведения, классную доску, A*, навигационную сетку, поиск или патрулирование/погоню.
