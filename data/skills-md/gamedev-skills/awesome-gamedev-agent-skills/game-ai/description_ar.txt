قم بتصميم الشخصيات غير القابلة للعب (NPC) وعملية اتخاذ القرار للعدو باستخدام أجهزة الحالة المحدودة وأشجار السلوك وسلوكيات التوجيه وإيجاد المسار A* - خوارزميات محايدة للمحرك تقترن بواجهة برمجة التطبيقات (API) للملاحة الخاصة بالمحرك المكتشف. يُستخدم عند إنشاء الذكاء الاصطناعي للعدو، أو FSM أو شجرة السلوك، أو التوجيه/التدفق، أو اكتشاف المسار، أو عندما يذكر المستخدم جهاز الحالة، أو شجرة السلوك، أو السبورة، أو A*، أو شبكة التنقل، أو البحث، أو الدورية/المطاردة.
