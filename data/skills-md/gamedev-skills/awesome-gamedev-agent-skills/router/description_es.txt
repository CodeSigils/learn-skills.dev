Dirige cualquier solicitud de desarrollo de juegos a las habilidades especializadas adecuadas: detecta el motor (Godot, Unity, Unreal, Bevy, Phaser, PixiJS, three.js, LÖVE, pygame, Roblox) y la tarea, luego lee la habilidad elegida antes de actuar. Úselo para crear un juego o para decidir qué habilidad se aplica: para jugadores, niveles, enemigos, sombreadores, UI/UX, cámaras, sensación del juego, física, entrada, audio, guardado, multijugador, IA, diálogo, generación de procedimientos o rendimiento, para géneros (plataformas, roguelike, RPG, FPS, defensa de torres, juegos de cartas, novela visual, creación de supervivencia, rompecabezas) y para envío (game jam, Steam, itch). Comience aquí cuando no esté seguro de qué habilidad de desarrollador de juegos utilizar.
