Achemine toute demande de développement de jeu vers la ou les compétences spécialisées appropriées : il détecte le moteur (Godot, Unity, Unreal, Bevy, Phaser, PixiJS, three.js, LÖVE, pygame, Roblox) et la tâche, puis lit la compétence choisie avant d'agir. Utilisez-le pour créer un jeu ou pour décider quelle compétence s'applique : pour les joueurs, les niveaux, les ennemis, les shaders, l'interface utilisateur/UX, les caméras, la sensation du jeu, la physique, la saisie, l'audio, la sauvegarde, le multijoueur, l'IA, le dialogue, la génération procédurale ou la performance, pour les genres (plateforme, roguelike, RPG, FPS, tower-defense, jeu de cartes, roman visuel, survie, puzzle) et pour l'expédition (game jam, Steam, itch). Commencez ici si vous ne savez pas quelle compétence de développement de jeu utiliser.
