Ilumine y sombree una escena de three.js: elija materiales (MeshStandardMaterial PBR versus MeshBasicMaterial sin iluminación), agregue luces ambientales/hemisféricas/direccionales/puntuales/focales, active mapas de sombras y use un mapa ambiental (IBL) para reflejos realistas. Úselo cuando un modelo de three.js se vea negro, plano o incorrecto: cuando el usuario mencione materiales de three.js, MeshStandardMaterial, luces, sombras, envMap o PBR. Para la configuración del renderizador/bucle, utilice threejs-scene-setup; para cargar modelos utilice threejs-gltf-loading.
