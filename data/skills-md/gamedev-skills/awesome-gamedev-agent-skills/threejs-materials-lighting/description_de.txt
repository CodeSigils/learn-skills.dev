Beleuchten und schattieren Sie eine Three.js-Szene: Wählen Sie Materialien (MeshStandardMaterial PBR vs. unbeleuchtetes MeshBasicMaterial), fügen Sie Umgebungs-/Halbkugel-/Richtungs-/Punkt-/Spotlichter hinzu, aktivieren Sie Schattenkarten und verwenden Sie eine Umgebungskarte (IBL) für realistische Reflexionen. Verwenden Sie diese Option, wenn ein three.js-Modell schwarz, flach oder falsch aussieht – wenn der Benutzer three.js-Materialien, MeshStandardMaterial, Lichter, Schatten, envMap oder PBR erwähnt. Für die Renderer-/Loop-Einrichtung verwenden Sie threejs-scene-setup; Verwenden Sie zum Laden von Modellen ThreeJS-GLTF-Loading.
