تصميم حفظ/تحميل لحالة اللعبة - اختيار ما تريد إجراء تسلسل له، وتنسيقات الملفات، وفتحات الحفظ، وعمليات الكتابة الذرية الآمنة، وإصدار المخطط وترحيله، والحفظ التلقائي. محايد للمحرك. يُستخدم عندما يذكر المستخدم حفظ النظام، أو الحفظ/التحميل، أو استمرار حالة اللعبة، أو حفظ الفتحات، أو الحفظ التلقائي، أو حفظ تلف الملف، أو ترحيل الحفظ القديم إلى إصدار جديد.
