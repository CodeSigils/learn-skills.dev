قم ببناء وقت تشغيل شجرة سلوك الإنتاج (Blackboard، وأوراق الإجراء/الشرط، والمركبات التسلسلية/المحددة/المتوازية، والديكورات) ونظام الذكاء الاصطناعي المساعد (منحنيات الاستجابة - الاعتبارات الخطية والأسية والسينية والتربيعية ومقيمو الإجراء)، بالإضافة إلى وكلاء المرافق - محركات الأقراص BT المختلطة. يُستخدم عند تنفيذ شجرة سلوك قابلة لإعادة الاستخدام أو نظام قرار قائم على المنفعة، أو ضبط قرارات العدو/الشخصية غير القابلة للعب بما يتجاوز ولايات ميكرونيزيا الموحدة البسيطة، أو عندما يذكر المستخدم شجرة السلوك، أو السبورة، أو مصمم الديكور، أو المحدد، أو التسلسل، أو حالة التجزئة، أو الذكاء الاصطناعي المساعد، أو منحنى الاستجابة/التسجيل، أو الاعتبار. للاختيار بين FSM/BT/التوجيه أو تحديد المسار، استخدم game-ai؛ بالنسبة لأصول Unreal's BehaviorTree/Blackboard، استخدم أشجار السلوك غير الواقعية.
