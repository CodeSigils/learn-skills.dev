قم بإعداد فيزياء ثلاثية الأبعاد في Unity 6: حركة وقوى الجسم الصلب، والمصادمات، والمحفزات مقابل الاصطدامات، والاصطدام القائم على الطبقة، وشعاع الضوء، والمفاصل. يُستخدم عند إضافة جسم صلب، أو التعامل مع OnCollisionEnter/OnTriggerEnter، أو ضبط طبقات الاصطدام، أو إرسال الأشعة، أو عندما يذكر المستخدم فيزياء Unity، أو AddForce، أو isKinematic، أو LinerVelocity.
