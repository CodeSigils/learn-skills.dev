مهندس إدخال اللعبة - رسم خرائط الإجراء (تجريد المفاتيح إلى إجراءات مسماة)، وإعادة الربط مع اكتشاف التعارض والاستمرار، ودعم الأجهزة المتعددة (لوحة المفاتيح، ولوحة الألعاب، واللمس)، والمناطق الميتة التناظرية، والشعور بميزات مثل التخزين المؤقت للإدخال ووقت الذئب، بالإضافة إلى إمكانية الوصول. محايد للمحرك. يُستخدم عندما يذكر المستخدم تعيين الإدخال، أو إعادة ربط عناصر التحكم، أو دعم لوحة الألعاب، أو المنطقة الميتة، أو التخزين المؤقت للإدخال، أو وقت الذئب، أو عناصر التحكم التي يمكن الوصول إليها.
