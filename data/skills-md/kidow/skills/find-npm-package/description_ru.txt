Выполняйте поиск пакетов npm по функциональности с помощью API реестра npm, итеративно уточняя запрос, пока пользователь не найдет нужный. Охватывает только пакеты JavaScript и TypeScript — не распространяется на pip, Cargo, Gems или другие реестры пакетов. Используйте, когда пользователь хочет найти пакет npm, модуль узла или библиотеку JavaScript/TypeScript для определенной цели или говорит что-то вроде «найдите мне пакет npm для X», «есть ли модуль узла, который выполняет Y» или «порекомендуйте библиотеку JS для Z».
