Recherchez les packages npm par fonctionnalité à l'aide de l'API de registre npm, en affinant de manière itérative la requête jusqu'à ce que l'utilisateur trouve la bonne. Couvre uniquement les packages JavaScript et TypeScript – ne couvre pas les registres pip, cargo, gems ou autres registres de packages. À utiliser lorsque l'utilisateur souhaite rechercher un package npm, un module de nœud ou une bibliothèque JavaScript/TypeScript dans un but spécifique, ou dit des choses comme « trouvez-moi un package npm pour X », « existe-t-il un module de nœud qui fait Y » ou « recommande une bibliothèque JS pour Z ».
