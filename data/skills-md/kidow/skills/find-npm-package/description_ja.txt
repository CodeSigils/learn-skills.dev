npm レジストリ API を使用して npm パッケージを機能別に検索し、ユーザーが適切なクエリを見つけるまでクエリを繰り返し調整します。 JavaScript および TypeScript パッケージのみをカバーします。pip、cargo、gem、またはその他のパッケージ レジストリはカバーしません。ユーザーが特定の目的で npm パッケージ、ノード モジュール、または JavaScript/TypeScript ライブラリを見つけたい場合、または「X の npm パッケージを見つけてください」、「Y を実行するノード モジュールはありますか」、または「Z の JS ライブラリをお勧めします」などのことを言う場合に使用します。
