npm 레지스트리 API를 사용하여 기능별로 npm 패키지를 검색하고 사용자가 올바른 항목을 찾을 때까지 쿼리를 반복적으로 구체화합니다. JavaScript 및 TypeScript 패키지만 다루고 pip, 화물, 보석 또는 기타 패키지 레지스트리는 다루지 않습니다. 사용자가 특정 목적을 위해 npm 패키지, 노드 모듈 또는 JavaScript/TypeScript 라이브러리를 찾고 싶거나 "X용 npm 패키지를 찾아주세요", "Y를 수행하는 노드 모듈이 있나요" 또는 "Z용 JS 라이브러리를 추천해 주세요"와 같은 말을 할 때 사용하세요.
