Busque paquetes de npm por funcionalidad utilizando la API de registro de npm, refinando iterativamente la consulta hasta que el usuario encuentre el correcto. Cubre únicamente paquetes de JavaScript y TypeScript; no cubre pip, cargo, gems u otros registros de paquetes. Úselo cuando el usuario quiera encontrar un paquete npm, un módulo de nodo o una biblioteca JavaScript/TypeScript para un propósito específico, o diga cosas como "búsqueme un paquete npm para X", "hay un módulo de nodo que haga Y" o "recomiende una biblioteca JS para Z".
