Copre solo i pacchetti JavaScript e TypeScript: non copre pip, cargo, gems o altri registri di pacchetti. Da utilizzare quando l'utente desidera trovare un pacchetto npm, un modulo del nodo o una libreria JavaScript/TypeScript per uno scopo specifico oppure dice cose come "trovami un pacchetto npm per X", "esiste un modulo del nodo che fa Y" o "consiglia una libreria JS per Z".
