ابحث عن حزم npm حسب الوظيفة باستخدام واجهة برمجة تطبيقات تسجيل npm، وقم بتحسين الاستعلام بشكل متكرر حتى يجد المستخدم الاستعلام الصحيح. يغطي حزم JavaScript وTypeScript فقط - ولا يغطي النقاط أو البضائع أو الأحجار الكريمة أو سجلات الحزم الأخرى. يُستخدم عندما يريد المستخدم العثور على حزمة npm، أو وحدة عقدة، أو مكتبة JavaScript/TypeScript لغرض محدد، أو يقول أشياء مثل "ابحث عن حزمة npm لـ X"، أو "هل هناك وحدة عقدة تعمل بـ Y"، أو "يوصي بمكتبة JS لـ Z".
