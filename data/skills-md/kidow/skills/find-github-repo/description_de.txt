Durchsuchen Sie GitHub-Repositorys nach Funktionalität mithilfe der gh-CLI und verfeinern Sie die Abfrage iterativ, bis der Benutzer die richtige findet. Verwenden Sie diese Option, wenn der Benutzer ein GitHub-Repository, eine GitHub-Bibliothek oder ein Tool für einen bestimmten Zweck finden möchte oder Dinge sagt wie „Gibt es ein Repo, das X kann“, „Such mir eine Bibliothek für Y“ oder „Empfehle ein Tool für Z“.
