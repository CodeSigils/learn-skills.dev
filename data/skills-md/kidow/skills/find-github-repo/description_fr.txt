Recherchez les référentiels GitHub par fonctionnalité à l'aide de gh CLI, en affinant de manière itérative la requête jusqu'à ce que l'utilisateur trouve la bonne. À utiliser lorsque l'utilisateur souhaite rechercher un référentiel, une bibliothèque ou un outil GitHub dans un but spécifique, ou dit des choses comme « existe-t-il un dépôt qui fait X », « trouvez-moi une bibliothèque pour Y » ou « recommandez un outil pour Z ».
