Busque repositorios de GitHub por funcionalidad utilizando gh CLI, refinando iterativamente la consulta hasta que el usuario encuentre la correcta. Úselo cuando el usuario quiera encontrar un repositorio, biblioteca o herramienta de GitHub para un propósito específico, o diga cosas como "¿hay algún repositorio que haga X?", "búsqueme una biblioteca para Y" o "recomiende una herramienta para Z".
