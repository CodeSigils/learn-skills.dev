Cerca nei repository GitHub in base alla funzionalità utilizzando gh CLI, perfezionando in modo iterativo la query finché l'utente non trova quello giusto. Da utilizzare quando l'utente desidera trovare un repository, una libreria o uno strumento GitHub per uno scopo specifico oppure dice cose come "esiste un repository che fa X", "trovami una libreria per Y" o "consiglia uno strumento per Z".
