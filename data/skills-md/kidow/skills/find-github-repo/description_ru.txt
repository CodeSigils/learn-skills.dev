Выполняйте поиск в репозиториях GitHub по функциональности с помощью gh CLI, итеративно уточняя запрос, пока пользователь не найдет нужный. Используйте, когда пользователь хочет найти репозиторий, библиотеку или инструмент GitHub для определенной цели или говорит что-то вроде «есть ли репозиторий, который делает X», «найдите мне библиотеку для Y» или «порекомендуйте инструмент для Z».
