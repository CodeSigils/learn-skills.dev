Supporta le convenzioni dei file Next.js App Router necessarie e i metadati SEO a livello di percorso (page.tsx, layout.tsx, error.tsx, not-found.tsx, load.tsx, default.tsx, global-error.tsx, metadata, generateMetadata, canonical, robots, openGraph, twitter) per un determinato percorso di percorso. Controlla i file esistenti, li legge per contesto e genera solo i file mancanti. Da utilizzare quando l'utente fornisce un percorso di instradamento e desidera aggiungere file speciali mancanti o metadati SEO oppure chiede di "impalcatura", "creare file per" o "impostare file di instradamento" per un instradamento del router dell'app Next.js.
