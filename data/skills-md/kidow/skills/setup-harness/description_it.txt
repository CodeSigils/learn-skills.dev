Costruisci l'infrastruttura di cablaggio degli agenti (vincola, informa, verifica, correggi) su un progetto passo dopo passo. Genera AGENTS.md come file di regole canoniche con uno stub di importazione CLAUDE.md, configura le autorizzazioni del codice Claude e un hook di verifica di fine sessione, supporta porte CI opzionali e avvia una sezione Errori passati per il ciclo "1 errore = 1 regola di prevenzione". Ottimizzato per Claude Code; AGENTS.md è lo standard multistrumento quindi OpenAI Codex legge lo stesso file. Da utilizzare quando l'utente desidera impostare guardrail dell'agente, rafforzare la configurazione di un agente di codifica AI, scrivere o migliorare AGENTS.md/CLAUDE.md, configurare autorizzazioni/hook dell'agente o chiedere "come posso rendere il mio agente più sicuro", "impostare l'ingegneria del cablaggio", "configurare le regole dell'agente per questo progetto".
