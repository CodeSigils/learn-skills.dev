Créez une infrastructure d'exploitation d'agents (Contraindre, Informer, Vérifier, Corriger) sur un projet, étape par étape. Génère AGENTS.md en tant que fichier de règles canoniques avec un stub d'importation CLAUDE.md, configure les autorisations Claude Code et un hook de vérification de fin de session, échafaude les portes CI facultatives et amorce une section Échecs passés pour la boucle « 1 échec = 1 règle de prévention ». Optimisé pour Claude Code ; AGENTS.md est le standard multi-outils, donc OpenAI Codex lit le même fichier. À utiliser lorsque l'utilisateur souhaite configurer des garde-fous d'agent, renforcer la configuration d'un agent de codage IA, écrire ou améliorer AGENTS.md/CLAUDE.md, configurer les autorisations/hooks d'agent ou demande « comment rendre mon agent plus sûr », « configurer l'ingénierie du harnais », « configurer les règles d'agent pour ce projet ».
