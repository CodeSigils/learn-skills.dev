Шаг за шагом создавайте инфраструктуру агентов (ограничивать, информировать, проверять, корректировать) в проекте. Создает AGENTS.md как файл канонических правил с заглушкой импорта CLAUDE.md, настраивает разрешения Claude Code и перехватчик проверки конца сеанса, формирует дополнительные шлюзы CI и заполняет раздел «Прошлые сбои» для цикла «1 сбой = 1 правило предотвращения». Оптимизирован для Claude Code; AGENTS.md — это универсальный стандарт, поэтому OpenAI Codex читает один и тот же файл. Используйте, когда пользователь хочет настроить защитные ограждения агента, усилить настройку агента кодирования AI, написать или улучшить AGENTS.md/CLAUDE.md, настроить разрешения/перехватчики агента или спрашивает «как мне сделать моего агента более безопасным», «настроить разработку жгутов», «настроить правила агента для этого проекта».
