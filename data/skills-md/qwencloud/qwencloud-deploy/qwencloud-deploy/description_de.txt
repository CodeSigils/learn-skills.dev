Mit einem Klick können Sie ein lokales Projekt oder Git-Repository in Alibaba Cloud International (alibabacloud.com) bereitstellen, veröffentlichen und aktualisieren und so einen zugänglichen Onlinedienst mit einer öffentlichen IP erstellen. Unterstützt Full-Stack-ROS-Orchestrierung, automatische Cloud-Ressourcenbereitstellung, Preisbestätigung vor der Bereitstellung, Service-Zustandsprüfungen, Aufzeichnung des Bereitstellungsstatus, Hot-Updates und optionale Domänen- und HTTPS-Einrichtung. Verwenden Sie Folgendes: Der Benutzer möchte ein Projekt in der Cloud bereitstellen, eine App online stellen, eine Website veröffentlichen, eine Zugriffs-URL generieren, ein Git-Repository bereitstellen oder eine Online-Version aktualisieren und KEINE bestimmte Cloud-Plattform genannt haben. oder der Benutzer erwähnt „Alibaba Cloud“, „alibabacloud.com“ oder die internationale Website. Nicht verwenden, wenn: der Benutzer explizit auf Aliyun China (aliyun.com), AWS, GCP, Azure oder eine andere spezifische Cloud-Plattform abzielt.
