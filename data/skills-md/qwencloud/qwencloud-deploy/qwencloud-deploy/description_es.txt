Implemente, publique y actualice con un solo clic un proyecto local o un repositorio Git en Alibaba Cloud International (alibabacloud.com), produciendo un servicio en línea accesible con una IP pública. Admite orquestación ROS de pila completa, aprovisionamiento automático de recursos en la nube, confirmación de precios previa a la implementación, comprobaciones del estado del servicio, registro del estado de implementación, actualizaciones en caliente y configuración opcional de dominio + HTTPS. Úselo cuando: el usuario solicita implementar un proyecto en la nube, poner una aplicación en línea, publicar un sitio web, generar una URL de acceso, implementar un repositorio de Git o actualizar una versión en línea y NO ha nombrado una plataforma en la nube específica; o el usuario menciona "Alibaba Cloud", "alibabacloud.com" o el sitio internacional. No utilizar cuando: el usuario se dirige explícitamente a Aliyun China (aliyun.com), AWS, GCP, Azure u otra plataforma de nube específica.
