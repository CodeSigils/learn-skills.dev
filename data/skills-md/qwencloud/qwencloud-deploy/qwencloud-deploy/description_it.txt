Distribuisci, pubblica e aggiorna con un clic un progetto locale o un repository Git su Alibaba Cloud International (alibabacloud.com), producendo un servizio online accessibile con un IP pubblico. Supporta l'orchestrazione ROS dello stack completo, il provisioning automatico delle risorse cloud, la conferma del prezzo pre-distribuzione, i controlli dello stato del servizio, la registrazione dello stato di distribuzione, gli aggiornamenti rapidi e la configurazione facoltativa di dominio + HTTPS. Utilizzare quando: l'utente chiede di distribuire un progetto nel cloud, mettere un'app online, pubblicare un sito Web, generare un URL di accesso, distribuire un repository Git o aggiornare una versione online e NON ha nominato una piattaforma cloud specifica; oppure l'utente menziona "Alibaba Cloud", "alibabacloud.com" o il sito internazionale. Non utilizzare quando: l'utente prende di mira esplicitamente Aliyun China (aliyun.com), AWS, GCP, Azure o un'altra piattaforma cloud specifica.
