Déployez, publiez et mettez à jour en un clic un projet local ou un référentiel Git sur Alibaba Cloud International (alibabacloud.com), produisant ainsi un service en ligne accessible avec une adresse IP publique. Prend en charge l'orchestration ROS complète, l'approvisionnement automatique des ressources cloud, la confirmation du prix avant le déploiement, les vérifications de l'état du service, l'enregistrement de l'état du déploiement, les mises à jour à chaud et la configuration facultative du domaine + HTTPS. À utiliser lorsque : l'utilisateur demande à déployer un projet sur le cloud, à mettre une application en ligne, à publier un site Web, à générer une URL d'accès, à déployer un dépôt Git ou à mettre à jour une version en ligne et n'a PAS nommé de plateforme cloud spécifique ; soit l'utilisateur mentionne « Alibaba Cloud », « alibabacloud.com », ou le site international. Ne pas utiliser lorsque : l'utilisateur cible explicitement Aliyun China (aliyun.com), AWS, GCP, Azure ou une autre plateforme cloud spécifique.
