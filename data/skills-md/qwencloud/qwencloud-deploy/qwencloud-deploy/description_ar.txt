بنقرة واحدة يمكنك نشر ونشر وتحديث مشروع محلي أو مستودع Git إلى Alibaba Cloud International (alibabacloud.com)، مما يؤدي إلى إنتاج خدمة يمكن الوصول إليها عبر الإنترنت باستخدام عنوان IP عام. يدعم تنسيق ROS الكامل، وتوفير الموارد السحابية تلقائيًا، وتأكيد السعر قبل النشر، وفحوصات سلامة الخدمة، وتسجيل حالة النشر، والتحديثات الساخنة، والمجال الاختياري + إعداد HTTPS. يُستخدم عندما: يطلب المستخدم نشر مشروع على السحابة، أو وضع تطبيق على الإنترنت، أو نشر موقع ويب، أو إنشاء عنوان URL للوصول، أو نشر Git repo، أو تحديث إصدار عبر الإنترنت ولم يقم بتسمية نظام أساسي سحابي محدد؛ أو يذكر المستخدم "Alibaba Cloud" أو "alibabacloud.com" أو الموقع الدولي. لا تستخدمه عندما: يستهدف المستخدم بشكل صريح Aliyun China (aliyun.com)، أو AWS، أو GCP، أو Azure، أو أي نظام أساسي سحابي محدد آخر.
