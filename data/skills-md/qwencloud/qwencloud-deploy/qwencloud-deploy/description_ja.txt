ワンクリックでローカル プロジェクトまたは Git リポジトリを Alibaba Cloud International (alibabacloud.com) にデプロイ、公開、更新し、パブリック IP でアクセス可能なオンライン サービスを作成します。フルスタックの ROS オーケストレーション、自動クラウド リソース プロビジョニング、導入前の価格確認、サービスの健全性チェック、導入状態の記録、ホット アップデート、およびオプションのドメイン + HTTPS セットアップをサポートします。次の場合に使用します: ユーザーがプロジェクトのクラウドへのデプロイ、アプリのオンライン化、Web サイトの公開、アクセス URL の生成、Git リポジトリのデプロイ、またはオンライン バージョンの更新を要求し、特定のクラウド プラットフォームを指定していない場合。または、ユーザーが「Alibaba Cloud」、「alibabacloud.com」、または国際サイトについて言及します。次の場合は使用しないでください: ユーザーが Aliyun China (aliyun.com)、AWS、GCP、Azure、または別の特定のクラウド プラットフォームを明示的にターゲットにしている場合。
