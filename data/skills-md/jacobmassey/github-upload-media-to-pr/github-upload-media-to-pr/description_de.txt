Laden Sie lokale Bilder und Videos auf eine GitHub-PR hoch und betten Sie sie in die Beschreibung oder Kommentare ein. Verwenden Sie diese Option, wenn Sie aufgefordert werden, „Screenshots an PR anzuhängen“, „Bilder zu PR hinzuzufügen“, „Testergebnisse zu PR hochzuladen“, „Screenshots in die PR-Beschreibung einzubetten“, „Vorher/Nachher-Bilder zu PR hinzuzufügen“, „UI-Screenshots anzuhängen“, „Testergebnisse in PR anzuzeigen“, „visuelle Beweise zu PR hinzuzufügen“, „Video zu PR anzuhängen“, „Aufzeichnung zu PR hochzuladen“, „Demovideo zu PR hinzuzufügen“ oder jede Anfrage, die Medien und PRs betrifft. Verwenden Sie diesen Skill immer, wenn der Benutzer Änderungen in einer Pull-Anfrage visuell dokumentieren möchte, auch wenn er das Wort „hochladen“ nicht verwendet – Phrasen wie „den Screenshot in die PR einfügen“ oder „die Aufzeichnung in der PR anzeigen“ sollten diesen Skill auslösen. Unterstützt Bilder (png, jpg, gif, webp) und Videos (mp4, webm, mov). Verwendet den Agent-Browser (vercel-labs/agent-browser) für die Browser-Automatisierung.
