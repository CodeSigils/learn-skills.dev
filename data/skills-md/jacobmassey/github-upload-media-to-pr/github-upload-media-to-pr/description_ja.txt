ローカルの画像やビデオを GitHub PR にアップロードし、説明やコメントに埋め込みます。 「PR にスクリーンショットを添付」、「PR に画像を追加」、「PR にテスト結果をアップロード」、「PR の説明にスクリーンショットを埋め込む」、「PR に前後の画像を追加」、「UI スクリーンショットを添付」、「PR にテスト結果を表示」、「PR に視覚的証拠を追加」、「PR にビデオを添付」、「PR に録画をアップロード」、「PR にデモビデオを追加」、またはメディアと PR が関与するリクエストの場合に使用します。ユーザーがプル リクエストの変更を視覚的に文書化したい場合は、「アップロード」という単語を使用しない場合でも、常にこのスキルを使用してください。「PR にスクリーンショットを入れる」または「PR で記録を表示する」などのフレーズがこのスキルをトリガーする必要があります。画像 (png、jpg、gif、webp) とビデオ (mp4、webm、mov) をサポートします。ブラウザの自動化にはエージェント ブラウザ (vercel-labs/agent-browser) を使用します。
