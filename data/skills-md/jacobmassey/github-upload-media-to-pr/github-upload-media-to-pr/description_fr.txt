Téléchargez des images et des vidéos locales sur un PR GitHub et intégrez-les dans la description ou les commentaires. À utiliser lorsqu'on vous demande de « joindre des captures d'écran au PR », « ajouter des images au PR », « télécharger les résultats des tests au PR », « intégrer des captures d'écran dans la description du PR », « ajouter des images avant/après au PR », « joindre des captures d'écran de l'interface utilisateur », « afficher les résultats des tests dans le PR », « ajouter des preuves visuelles au PR », « joindre une vidéo au PR », « télécharger un enregistrement au PR », « ajouter une vidéo de démonstration au PR », ou toute demande impliquant des médias et des PR. Utilisez toujours cette compétence lorsque l'utilisateur souhaite documenter visuellement les modifications dans une pull request, même s'il n'utilise pas le mot « télécharger » — des expressions telles que « mettre la capture d'écran dans le PR » ou « afficher l'enregistrement dans le PR » devraient déclencher cette compétence. Prend en charge les images (png, jpg, gif, webp) et les vidéos (mp4, webm, mov). Utilise un navigateur d'agent (vercel-labs/agent-browser) pour l'automatisation du navigateur.
