Flujo de trabajo operativo completo para agentes implementadores (Codex, Gemini, etc.) que realizan cambios de código y escriben pruebas. Impulsa todo el trabajo a través de confirmaciones atómicas: cada bucle opera con el cambio completo y revisable más pequeño. Define el proceso de bucle de cambio de código, bucle de escritura de prueba, puerta de pelusa y archivo de problemas con disyuntores, niveles de gravedad y reglas de escalada. Requiere "committer" para todas las confirmaciones. Incluye secuencias de comandos de revisión orientadas al proveedor que mantienen los desembolsos del mismo modelo como último recurso, además de un respaldo del Codex de contexto nuevo para la revisión de código y auditoría de prueba. Utilice esta habilidad al iniciar cualquier tarea de implementación.
