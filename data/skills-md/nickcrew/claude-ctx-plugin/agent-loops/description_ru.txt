Полный рабочий процесс для агентов-исполнителей (Codex, Gemini и т. д.), вносящих изменения в код и записывающих тесты. Управляет всей работой посредством атомарных коммитов — каждый цикл работает с наименьшим полным, проверяемым изменением. Определяет цикл изменения кода, цикл написания тестов, процесс проверки и регистрации проблем с автоматическими выключателями, уровнями серьезности и правилами эскалации. Требуется `committer` для всех коммитов. Включает в себя встроенные сценарии проверки с учетом поставщика, которые сохраняют использование той же модели в качестве крайней меры, а также запасной вариант Кодекса с новым контекстом для проверки кода и аудита тестирования. Используйте этот навык при запуске любой задачи по реализации.
