استخدم هذه المهارة عند اكتمال مهمة المشروع أو عندما يطلب المستخدم تسجيل التقدم أو حفظ السياق أو تحديث ذاكرة المشروع أو كتابة سجل المشروع أو التقاط عملية التسليم. يقوم بإنشاء وتحديث نظام ذاكرة المستندات/التقدم المحلي للمشروع مع سجلات الجلسة وتغييرات التعليمات البرمجية والأوامر والاختبارات والقرارات والمهام وملاحظات البيئة والسياق عبر الأجهزة والتنقيح وملاحظات استرداد الذكاء الاصطناعي المستقبلية.
