Используйте этот навык, когда задача проекта завершена или когда пользователь просит записать ход выполнения, сохранить контекст, обновить память проекта, записать журнал проекта или зафиксировать передачу. Он создает и обновляет локальную систему документации/прогресса проекта с журналами сеансов, изменениями кода, командами, тестами, решениями, задачами, примечаниями к среде, контекстом между устройствами, редактированием и будущими заметками о восстановлении ИИ.
