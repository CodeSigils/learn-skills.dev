Utilizza questa competenza quando un'attività progettuale viene completata o quando l'utente chiede di registrare l'avanzamento, salvare il contesto, aggiornare la memoria del progetto, scrivere un registro del progetto o acquisire un trasferimento. Crea e aggiorna un sistema di memoria di documentazione/avanzamento locale del progetto con registri di sessione, modifiche al codice, comandi, test, decisioni, cose da fare, note sull'ambiente, contesto tra dispositivi, redazione e future note di ripristino dell'IA.
