تصميم النخبة للواجهة الأمامية لبناء واجهات الويب ومراجعتها وصقلها. يُستخدم عندما يريد المستخدم تصميم أي واجهة مستخدم، أو إعادة تصميمها، أو تشكيلها، أو نقدها، أو تدقيقها، أو صقلها، أو تحسينها - الصفحات المقصودة، أو المحافظ، أو لوحات المعلومات، أو واجهة مستخدم المنتج، أو المكونات، أو النماذج، أو الإعداد، أو الحالات الفارغة - أو يطلب جعل شيء ما يبدو أفضل / مميزًا / حديثًا، أو إصلاح التصميم، أو إضافة رسوم متحركة أو إصلاحها، أو جعل التصميم يبدو أقل عمومية ("AI slop"). يغطي الطباعة واللون والتباعد والتخطيط والتسلسل الهرمي المرئي والحركة والتفاعلات الدقيقة وحالات المكونات وإمكانية الوصول والسلوك سريع الاستجابة ونسخ UX والكشف عن الأنماط المضادة.
