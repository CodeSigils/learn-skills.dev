Guía al agente a través del desarrollo de la aplicación Capacitor con React: estructura del proyecto, enlaces para características nativas, patrones de administración de estado, uso de complementos de Capacitor en componentes de React y mejores prácticas específicas de React. No lo use para Ionic Framework con React (use ionic-react), migrando o actualizando aplicaciones o complementos de Capacitor, ni marcos que no sean React.
