يرشد الوكيل خلال تطوير تطبيق Capacitor باستخدام React — بنية المشروع، وربطات للميزات الأصلية، وأنماط إدارة الحالة، واستخدام مكونات Capacitor الإضافية في مكونات React، وأفضل الممارسات الخاصة بـ React. لا تستخدم Ionic Framework مع React (استخدم ionic-react)، أو ترحيل أو ترقية تطبيقات Capacitor أو المكونات الإضافية، أو الأطر غير التابعة لـ React.
