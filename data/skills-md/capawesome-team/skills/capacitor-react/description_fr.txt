Guide l'agent tout au long du développement de l'application Capacitor avec React : structure du projet, hooks pour les fonctionnalités natives, modèles de gestion d'état, utilisation des plugins Capacitor dans les composants React et meilleures pratiques spécifiques à React. Ne pas utiliser pour Ionic Framework avec React (utilisez ionic-react), pour migrer ou mettre à niveau des applications ou des plugins Capacitor, ou pour des frameworks non-React.
