Помогает агенту разрабатывать приложения Capacitor с помощью React — структура проекта, перехватчики для встроенных функций, шаблоны управления состоянием, использование плагинов Capacitor в компонентах React и лучшие практики, специфичные для React. Не используйте Ionic Framework с React (используйте ionic-react), миграцию или обновление приложений или плагинов Capacitor, а также фреймворков, отличных от React.
