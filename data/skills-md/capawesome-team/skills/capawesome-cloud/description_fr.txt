Guide l'agent dans la configuration et l'utilisation des applications Capawesome Cloud for Capacitor. Couvre trois flux de travail principaux : (1) Native Builds – builds cloud pour iOS et Android, signature de certificats, environnements, configuration Trapeze et artefacts de build ; (2) Mises à jour en direct — Mises à jour OTA via le plugin @capawesome/capacitor-live-update, les canaux, la gestion des versions, les restaurations et la signature de code ; (3) Publication sur l'App Store – soumissions automatisées vers l'App Store d'Apple (TestFlight) et le Google Play Store. Inclut l'intégration CI/CD pour tous les flux de travail. Ne pas utiliser pour les frameworks mobiles non-Capacitor.
