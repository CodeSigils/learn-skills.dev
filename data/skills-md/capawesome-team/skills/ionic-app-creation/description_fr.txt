Guide l'agent dans la création d'une nouvelle application Ionic à l'aide de la CLI Ionic. Couvre l'échafaudage de projet avec démarrage ionique, la sélection de framework (Angular, React, Vue), la sélection de modèles (vide, onglets, menu latéral), l'intégration de condensateur et la configuration facultative du CSS Tailwind. Après la création de l'application avec l'intégration du condensateur, délégue à la compétence de création d'application de condensateur pour une configuration ultérieure du condensateur. Ne pas utiliser pour les projets Ionic existants, la migration d'applications Ionic, la mise à niveau des versions de Capacitor ou les frameworks mobiles non Ionic.
