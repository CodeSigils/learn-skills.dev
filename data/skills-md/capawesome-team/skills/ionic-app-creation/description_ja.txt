Ionic CLI を使用して新しい Ionic アプリを作成するまでエージェントをガイドします。 ionic start によるプロジェクトのスキャフォールディング、フレームワークの選択 (Angular、React、Vue)、テンプレートの選択 (空白、タブ、サイドメニュー)、Capacitor の統合、およびオプションの Tailwind CSS セットアップについて説明します。 Capacitor を統合してアプリを作成した後、Capacitor をさらにセットアップするために、capacitor-app-creation スキルに委任します。既存の Ionic プロジェクト、Ionic アプリの移行、Capacitor バージョンのアップグレード、または非 Ionic モバイル フレームワークには使用しないでください。
