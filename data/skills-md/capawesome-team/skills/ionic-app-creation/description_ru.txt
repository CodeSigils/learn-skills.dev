Помогает агенту создать новое приложение Ionic с помощью Ionic CLI. Охватывает структуру проекта с ионным запуском, выбором платформы (Angular, React, Vue), выбором шаблона (пустой, вкладки, боковое меню), интеграцией конденсаторов и дополнительной настройкой Tailwind CSS. После создания приложения с интеграцией конденсатора делегируется навык создания приложения-конденсатора для дальнейшей настройки конденсатора. Не используйте для существующих проектов Ionic, переноса приложений Ionic, обновления версий Capacitor или не-Ionic мобильных платформ.
