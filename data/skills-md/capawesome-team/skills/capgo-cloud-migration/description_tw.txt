指導代理將現有 Capacitor 專案從 Capgo 遷移到 Capawesome Cloud。檢測 Capgo 使用情況（@capgo/capacitor-updater 插件、CapacitorUpdater 配置和 CI/CD 中的 @capgo/cli 命令）並提供分步遷移：用 @capawesome/capacitor-live-update 替換插件、映射配置選項和 API 方法、遷移更新策略、通道、代碼簽名和 CI/CD 管道。參考 capawesome-cloud 技能，了解詳細的 Capawesome Cloud 設定流程。請勿用於在沒有現有 Capgo 專案的情況下從頭開始設定 Capawesome Cloud、從 Ionic Appflow 遷移（改為使用 ionic-appflow-migration 技能）或用於非 Capacitor 行動框架。
