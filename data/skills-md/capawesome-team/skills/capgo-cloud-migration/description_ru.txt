Помогает агенту перенести существующий проект Capacitor из Capgo в Capawesome Cloud. Обнаруживает использование Capgo (плагин @capgo/capacitor-updater, конфигурацию CapacitorUpdater и команды @capgo/cli в CI/CD) и обеспечивает пошаговую миграцию: замену плагина на @capawesome/capacitor-live-update, сопоставление параметров конфигурации и методов API, миграцию стратегий обновления, каналов, подписи кода и конвейеров CI/CD. Ссылается на навык capawesome-cloud для подробной процедуры настройки Capawesome Cloud. Не используйте для настройки Capawesome Cloud с нуля без существующего проекта Capgo, для миграции с Ionic Appflow (вместо этого используйте навык ionic-appflow-migration) или для мобильных платформ, не поддерживающих Capacitor.
