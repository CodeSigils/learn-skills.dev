Guide l'agent tout au long de la migration d'un projet Capacitor existant de Capgo vers Capawesome Cloud. Détecte l'utilisation de Capgo (le plugin @capgo/capacitor-updater, la configuration CapacitorUpdater et les commandes @capgo/cli dans CI/CD) et fournit une migration étape par étape : remplacement du plugin par @capawesome/capacitor-live-update, mappage des options de configuration et des méthodes API, migration des stratégies de mise à jour, des canaux, de la signature de code et des pipelines CI/CD. Fait référence à la compétence capawesome-cloud pour les procédures détaillées de configuration de Capawesome Cloud. Ne pas utiliser pour configurer Capawesome Cloud à partir de zéro sans un projet Capgo existant, pour migrer depuis Ionic Appflow (utilisez plutôt la compétence ionic-appflow-migration) ou pour les frameworks mobiles non-Capacitor.
