既存の Capacitor プロジェクトを Capgo から Capawesome Cloud に移行するまでエージェントをガイドします。 Capgo の使用状況 (@capgo/capacitor-updater プラグイン、CapacitorUpdater 構成、および CI/CD の @capgo/cli コマンド) を検出し、段階的な移行を提供します。プラグインの @capawesome/capacitor-live-update への置き換え、構成オプションと API メソッドのマッピング、更新戦略、チャネル、コード署名、CI/CD パイプラインの移行です。 Capawesome Cloud の詳細なセットアップ手順については、capawesome-cloud スキルを参照します。既存の Capgo プロジェクトを使用せずに Capawesome Cloud を最初からセットアップする場合、Ionic Appflow から移行する場合 (代わりに ionic-appflow-migration スキルを使用する)、または Capacitor 以外のモバイル フレームワークには使用しないでください。
