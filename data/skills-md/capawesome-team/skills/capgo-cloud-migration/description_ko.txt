기존 Capacitor 프로젝트를 Capgo에서 Capawesome Cloud로 마이그레이션하는 과정을 에이전트에게 안내합니다. Capgo 사용(@capgo/capacitor-updater 플러그인, CapacitorUpdater 구성 및 CI/CD의 @capgo/cli 명령)을 감지하고 단계별 마이그레이션을 제공합니다. 즉, 플러그인을 @capawesome/capacitor-live-update로 교체하고, 구성 옵션 및 API 메서드를 매핑하고, 업데이트 전략, 채널, 코드 서명 및 CI/CD 파이프라인을 마이그레이션합니다. 자세한 Capawesome Cloud 설정 절차는 capawesome-cloud 기술을 참조합니다. 기존 Capgo 프로젝트 없이 처음부터 Capawesome Cloud를 설정하거나, Ionic Appflow에서 마이그레이션하거나(대신 ionic-appflow-migration 기술 사용) Capacitor가 아닌 모바일 프레임워크에 사용하지 마세요.
