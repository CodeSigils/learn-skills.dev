指导代理将现有 Capacitor 项目从 Capgo 迁移到 Capawesome Cloud。检测 Capgo 使用情况（@capgo/capacitor-updater 插件、CapacitorUpdater 配置和 CI/CD 中的 @capgo/cli 命令）并提供分步迁移：用 @capawesome/capacitor-live-update 替换插件、映射配置选项和 API 方法、迁移更新策略、通道、代码签名和 CI/CD 管道。参考 capawesome-cloud 技能，了解详细的 Capawesome Cloud 设置过程。请勿用于在没有现有 Capgo 项目的情况下从头开始设置 Capawesome Cloud、从 Ionic Appflow 迁移（改为使用 ionic-appflow-migration 技能）或用于非 Capacitor 移动框架。
