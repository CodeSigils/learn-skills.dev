Führt den Agenten durch die Migration eines vorhandenen Ionic/Capacitor-Projekts von Ionic Appflow zu Capawesome Cloud. Erkennt, welche Appflow-Funktionen verwendet werden (Live-Updates, native Builds, App Store-Veröffentlichung) und bietet eine schrittweise Migration für jede Funktion zu ihrem Capawesome Cloud-Äquivalent. Umfasst SDK-Ersatz, Konfigurationszuordnung, API-Migration, CI/CD-Pipeline-Updates und Überprüfung. Verweist auf den Capawesome-Cloud-Skill für detaillierte Capawesome Cloud-Einrichtungsverfahren. Nicht zum Einrichten von Capawesome Cloud von Grund auf ohne vorhandenes Appflow-Projekt, für Nicht-Capacitor-Mobile-Frameworks oder zum Migrieren von Ionic Enterprise-Plugins verwenden.
