Führt den Agenten durch die Migration eines vorhandenen Ionic/Capacitor-Projekts von Ionic Appflow zu Capawesome Cloud. Erkennt, welche Appflow-Funktionen verwendet werden (Live-Updates, native Builds, App Store-Veröffentlichung) und bietet eine schrittweise Migration für jede Funktion zu ihrem Capawesome Cloud-Äquivalent. Umfasst SDK-Ersatz, Konfigurationszuordnung, API-Migration, CI/CD-Pipeline-Updates und Überprüfung. Verweist auf den Capawesome-Cloud-Skill für detaillierte Capawesome Cloud-Einrichtungsverfahren. Nicht verwenden, um Capawesome Cloud ohne vorhandenes Appflow-Projekt von Grund auf einzurichten, für mobile Frameworks, die nicht von Capacitor stammen, oder für die Migration von Ionic Enterprise-Plugins.
