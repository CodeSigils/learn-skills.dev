既存の Ionic/Capacitor プロジェクトを Ionic Appflow から Capawesome Cloud に移行するまでエージェントをガイドします。使用中の Appflow 機能 (ライブ アップデート、ネイティブ ビルド、App Store 公開) を検出し、各機能を Capawesome Cloud の同等の機能に段階的に移行します。 SDK の置き換え、構成マッピング、API の移行、CI/CD パイプラインの更新、検証について説明します。 Capawesome Cloud の詳細なセットアップ手順については、capawesome-cloud スキルを参照します。既存の Appflow プロジェクトを使用せずに Capawesome Cloud を最初からセットアップする場合、Capacitor 以外のモバイル フレームワークに使用する場合、または Ionic Enterprise プラグインを移行する場合には使用しないでください。
