Guide l'agent tout au long de la migration d'un projet Ionic/Capacitor existant de Ionic Appflow vers Capawesome Cloud. Détecte les fonctionnalités Appflow utilisées (mises à jour en direct, versions natives, publication sur l'App Store) et propose une migration étape par étape pour chaque fonctionnalité vers son équivalent Capawesome Cloud. Couvre le remplacement du SDK, le mappage de configuration, la migration des API, les mises à jour du pipeline CI/CD et la vérification. Fait référence à la compétence capawesome-cloud pour les procédures détaillées de configuration de Capawesome Cloud. Ne pas utiliser pour configurer Capawesome Cloud à partir de zéro sans un projet Appflow existant, pour les frameworks mobiles non-Capacitor ou pour migrer des plugins Ionic Enterprise.
