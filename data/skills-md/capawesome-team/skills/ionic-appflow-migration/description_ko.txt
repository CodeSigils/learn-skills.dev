기존 Ionic/Capacitor 프로젝트를 Ionic Appflow에서 Capawesome Cloud로 마이그레이션하는 과정을 에이전트에게 안내합니다. 사용 중인 Appflow 기능(라이브 업데이트, 기본 빌드, App Store 게시)을 감지하고 각 기능에 대해 Capawesome Cloud에 해당하는 기능으로 단계별 마이그레이션을 제공합니다. SDK 교체, 구성 매핑, API 마이그레이션, CI/CD 파이프라인 업데이트 및 검증을 다룹니다. 자세한 Capawesome Cloud 설정 절차는 capawesome-cloud 기술을 참조합니다. 기존 Appflow 프로젝트 없이 처음부터 Capawesome Cloud를 설정하거나 Capacitor가 아닌 모바일 프레임워크 또는 Ionic Enterprise 플러그인을 마이그레이션하는 데 사용하지 마세요.
