Помогает агенту использовать шаблоны, специфичные для Angular, для разработки приложений Capacitor. Охватывает структуру проекта, добавление Capacitor в проекты Angular, использование плагинов Capacitor в сервисах и компонентах Angular, интеграцию NgZone для прослушивателей событий плагинов, шаблоны перехватчиков жизненного цикла, внедрение зависимостей, маршрутизацию с глубокими ссылками и обнаружение платформы на основе среды. Не используйте для создания нового приложения Capacitor с нуля, обновления версий Capacitor, установки определенных плагинов, настройки Ionic Framework или фреймворков, отличных от Angular.
