Guide l'agent à travers les modèles spécifiques à Vue pour le développement de l'application Capacitor. Couvre l'API de composition Vue 3 avec les plugins Capacitor, les composables personnalisés pour les fonctionnalités natives, l'état réactif du plugin, les modèles de hook de cycle de vie, l'intégration des liens profonds Vue Router, la détection de plate-forme, la configuration des éléments PWA, l'intégration de Quasar Framework et l'intégration de Nuxt. Ne pas utiliser pour créer une nouvelle application Capacitor à partir de zéro, mettre à niveau les versions de Capacitor, installer des plugins spécifiques, Ionic Framework avec la configuration de Vue ou des frameworks non-Vue.
