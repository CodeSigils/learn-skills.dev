Помогает агенту использовать шаблоны, специфичные для Vue, для разработки приложений Capacitor. Охватывает Vue 3 Composition API с плагинами Capacitor, настраиваемыми компонентами для собственных функций, реактивным состоянием плагина, шаблонами перехватчиков жизненного цикла, интеграцией глубоких ссылок Vue Router, обнаружением платформы, настройкой элементов PWA, интеграцией Quasar Framework и интеграцией Nuxt. Не используйте для создания нового приложения Capacitor с нуля, обновления версий Capacitor, установки определенных плагинов, Ionic Framework с настройкой Vue или фреймворков, отличных от Vue.
