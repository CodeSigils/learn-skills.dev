Capacitor アプリ開発の Vue 固有のパターンを通じてエージェントをガイドします。 Capacitor プラグインを使用した Vue 3 コンポーザブル API、ネイティブ機能のカスタム コンポーザブル、リアクティブ プラグインの状態、ライフサイクル フック パターン、Vue Router ディープ リンク統合、プラットフォーム検出、PWA Elements セットアップ、Quasar Framework 統合、および Nuxt 統合をカバーします。新しい Capacitor アプリを最初から作成する場合、Capacitor バージョンをアップグレードする場合、特定のプラグインをインストールする場合、Vue セットアップを使用した Ionic Framework、または Vue 以外のフレームワークを使用する場合には使用しないでください。
