Guía al agente a través de patrones específicos de Vue para el desarrollo de aplicaciones Capacitor. Cubre la API de composición de Vue 3 con complementos de Capacitor, componentes componibles personalizados para funciones nativas, estado de complemento reactivo, patrones de enlace de ciclo de vida, integración de enlaces profundos de Vue Router, detección de plataforma, configuración de elementos PWA, integración de Quasar Framework e integración de Nuxt. No lo use para crear una nueva aplicación Capacitor desde cero, actualizar versiones de Capacitor, instalar complementos específicos, Ionic Framework con configuración de Vue o marcos que no sean Vue.
