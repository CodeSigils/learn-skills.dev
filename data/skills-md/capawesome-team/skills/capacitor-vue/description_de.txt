Führt den Agenten durch Vue-spezifische Muster für die Entwicklung von Capacitor-Apps. Behandelt die Vue 3 Composition API mit Capacitor-Plugins, benutzerdefinierten Composables für native Funktionen, reaktiven Plugin-Status, Lifecycle-Hook-Muster, Vue Router Deep Link-Integration, Plattformerkennung, PWA Elements-Setup, Quasar Framework-Integration und Nuxt-Integration. Nicht verwenden, um eine neue Capacitor-App von Grund auf zu erstellen, Capacitor-Versionen zu aktualisieren, bestimmte Plugins, Ionic Framework mit Vue-Setup oder Nicht-Vue-Frameworks zu installieren.
