Guide l'agent à travers des modèles spécifiques à Angular pour le développement d'applications Ionic. Couvre la structure du projet, la détection de l'architecture autonome par rapport à NgModule, l'intégration du routeur angulaire avec la navigation Ionic (onglets, menu latéral, modaux), le chargement paresseux, les hooks de cycle de vie des pages Ionic, les formulaires réactifs avec les composants d'entrée Ionic, les services angulaires pour la gestion de l'état, les gardes d'itinéraire, l'optimisation des performances et les tests. Ne pas utiliser pour créer une nouvelle application Ionic à partir de zéro, pour mettre à niveau les versions Ionic, pour l'utilisation générale des composants Ionic sans rapport avec Angular, pour l'intégration du plug-in Capacitor ou pour les frameworks non angulaires (React, Vue).
