Помогает агенту использовать шаблоны, специфичные для Angular, для разработки приложений Ionic. Охватывает структуру проекта, обнаружение автономной архитектуры по сравнению с NgModule, интеграцию Angular Router с Ionic-навигацией (вкладки, боковое меню, модальные окна), отложенную загрузку, перехватчики жизненного цикла страниц Ionic, реактивные формы с компонентами ввода Ionic, сервисы Angular для управления состоянием, защиту маршрутов, оптимизацию производительности и тестирование. Не используйте для создания нового приложения Ionic с нуля, обновления версий Ionic, общего использования компонентов Ionic, не связанных с Angular, интеграции плагинов Capacitor или инфраструктур, отличных от Angular (React, Vue).
