Guida l'agente attraverso l'aggiunta del supporto Swift Package Manager (SPM) a un plug-in Capacitor esistente. Riguarda la creazione di un manifest Package.swift, la sostituzione dei file bridge Objective-C con il protocollo CAPBridgedPlugin Swift, l'aggiornamento di .gitignore per gli artefatti SPM, la pulizia del file di progetto Xcode e l'aggiornamento di package.json. Non utilizzare per progetti di app Capacitor, creazione di nuovi plugin da zero o framework di plugin non Capacitor.
