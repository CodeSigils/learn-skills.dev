Guía al agente para agregar compatibilidad con Swift Package Manager (SPM) a un complemento de Capacitor existente. Cubre la creación de un manifiesto Package.swift, la sustitución de archivos puente Objective-C con el protocolo CAPBridgedPlugin Swift, la actualización de .gitignore para artefactos SPM, la limpieza del archivo del proyecto Xcode y la actualización de package.json. No lo utilice para proyectos de aplicaciones de Capacitor, ni para la creación de nuevos complementos desde cero ni para marcos de complementos que no sean de Capacitor.
