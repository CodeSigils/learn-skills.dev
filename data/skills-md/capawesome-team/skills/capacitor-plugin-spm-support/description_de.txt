Führt den Agenten durch das Hinzufügen von Swift Package Manager (SPM)-Unterstützung zu einem vorhandenen Capacitor-Plugin. Behandelt das Erstellen eines Package.swift-Manifests, das Ersetzen von Objective-C-Bridge-Dateien durch das CAPBridgedPlugin-Swift-Protokoll, das Aktualisieren von .gitignore für SPM-Artefakte, das Bereinigen der Xcode-Projektdatei und das Aktualisieren von package.json. Nicht für Capacitor-App-Projekte, die Erstellung neuer Plugins von Grund auf oder Nicht-Capacitor-Plugin-Frameworks verwenden.
