Помогает агенту добавить поддержку Swift Package Manager (SPM) к существующему плагину Capacitor. Охватывает создание манифеста Package.swift, замену файлов моста Objective-C протоколом CAPBridgedPlugin Swift, обновление .gitignore для артефактов SPM, очистку файла проекта Xcode и обновление package.json. Не используйте для проектов приложений Capacitor, создания новых плагинов с нуля или платформ плагинов, не связанных с конденсаторами.
