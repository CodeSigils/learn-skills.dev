Guide l'agent dans la configuration et l'utilisation des notifications push dans les applications Capacitor à l'aide de Firebase Cloud Messaging via le plugin @capacitor-firebase/messaging. Couvre la configuration du projet Firebase, l'installation du plug-in, la configuration spécifique à la plate-forme (Android, iOS, Web), la configuration des certificats APN, la demande d'autorisations, la récupération des jetons FCM, l'écoute des notifications, les abonnements aux sujets, les canaux de notification et les tests. Ne pas utiliser pour les notifications locales, les fournisseurs push non-Firebase, la migration d'applications ou de plugins Capacitor, ou les frameworks mobiles non-Capacitor.
