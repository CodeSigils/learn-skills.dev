Guide l’agent dans la mise à niveau d’un plug-in Capacitor vers une version majeure plus récente. Prend en charge les mises à niveau de Capacitor 4 à 8, y compris les sauts multiversions. Couvre la mise à niveau automatisée via les outils de migration officiels, les cibles du SDK Android, la configuration Gradle, les versions Java/Kotlin, les cibles de déploiement iOS et le repli manuel étape par étape pour chaque version. Ne pas utiliser pour la mise à niveau d'un projet d'application ou pour des frameworks de plugins non-Capacitor.
