Помогает агенту обновить плагин Capacitor до более новой основной версии. Поддерживает обновления с конденсатора 4 по 8, включая переходы на несколько версий. Охватывает автоматическое обновление с помощью официальных инструментов миграции, целей Android SDK, конфигурации Gradle, версий Java/Kotlin, целей развертывания iOS и пошагового возврата вручную для каждой версии. Не используйте для обновления проекта приложения или платформы плагинов без конденсаторов.
