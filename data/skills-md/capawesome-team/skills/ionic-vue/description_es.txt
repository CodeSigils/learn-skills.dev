Guía al agente a través de los patrones de desarrollo de Ionic Vue: estructura del proyecto, componentes Ionic específicos de Vue (IonPage, IonRouterOutlet, IonTabs), navegación con Vue Router y useIonRouter, enlaces del ciclo de vida de Ionic (onIonViewWillEnter, onIonViewDidEnter, onIonViewWillLeave, onIonViewDidLeave), utilidades componibles (useIonRouter, useBackButton, useKeyboard), enrutamiento basado en pestañas, carga diferida, detección de plataforma con isPlatform y solución de problemas comunes específicos de Vue. No lo use para temas generales de componentes Ionic o uso de CLI (use desarrollo de aplicaciones ionic), creación de una nueva aplicación Ionic (use creación de aplicaciones ionic), patrones de Vue específicos de Capacitor sin Ionic (use capacitor-vue), actualización de versiones de Ionic (use actualizaciones de aplicaciones ionic) o marcos que no sean de Vue como Angular o React.
