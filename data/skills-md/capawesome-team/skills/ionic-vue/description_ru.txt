Помогает агенту использовать шаблоны разработки Ionic Vue — структуру проекта, специфичные для Vue компоненты Ionic (IonPage, IonRouterOutlet, IonTabs), навигацию с помощью Vue Router и useIonRouter, перехватчики жизненного цикла Ionic (onIonViewWillEnter, onIonViewDidEnter, onIonViewWillLeave, onIonViewDidLeave), составные утилиты (useIonRouter, useBackButton, useKeyboard), маршрутизация на основе вкладок, отложенная загрузка, обнаружение платформы с помощью isPlatform и устранение распространенных проблем, специфичных для Vue. Не используйте для общего оформления тем Ionic или использования CLI (используйте ionic-app-development), создания нового приложения Ionic (используйте ionic-app-creation), шаблонов Vue для конкретных конденсаторов без Ionic (используйте конденсатор-vue), обновления версий Ionic (используйте обновления ionic-app-upgrade) или фреймворков, отличных от Vue, таких как Angular или React.
