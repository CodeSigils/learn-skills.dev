Ionic Vue 開発パターンを通じてエージェントをガイドします — プロジェクト構造、Vue 固有の Ionic コンポーネント (IonPage、IonRouterOutlet、IonTabs)、Vue Router と useIonRouter によるナビゲーション、Ionic ライフサイクル フック (onIonViewWillEnter、onIonViewDidEnter、onIonViewWillLeave、onIonViewDidLeave)、コンポーザブル ユーティリティ (useIonRouter、useBackButton、 useKeyboard)、タブベースのルーティング、遅延読み込み、isPlatform によるプラットフォーム検出、および Vue 固有の一般的な問題のトラブルシューティング。一般的な Ionic コンポーネントのテーマや CLI の使用 (ionic-app-development を使用)、新しい Ionic アプリの作成 (ionic-app-creation を使用)、Ionic を使用しない Capacitor 固有の Vue パターン (capacitor-vue を使用)、Ionic バージョンのアップグレード (ionic-app-upgrades を使用)、Angular や React などの非 Vue フレームワークには使用しないでください。
