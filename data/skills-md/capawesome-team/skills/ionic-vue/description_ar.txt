يرشد الوكيل من خلال أنماط تطوير Ionic Vue - هيكل المشروع، والمكونات الأيونية الخاصة بـ Vue (IonPage، IonRouterOutlet، IonTabs)، والتنقل باستخدام Vue Router وuseIonRouter، وخطافات دورة الحياة الأيونية (onIonViewWillEnter، onIonViewDidEnter، onIonViewWillLeave، onIonViewDidLeave)، والأدوات المساعدة القابلة للتركيب (useIonRouter، useBackButton، useKeyboard)، والتوجيه المستند إلى علامة التبويب، والتحميل البطيء، واكتشاف النظام الأساسي باستخدام isPlatform، واستكشاف المشكلات الشائعة الخاصة بـ Vue وإصلاحها. لا تستخدمه في استخدام المكونات الأيونية العامة أو استخدام واجهة سطر الأوامر (استخدم تطوير التطبيق الأيوني)، أو إنشاء تطبيق أيوني جديد (استخدم إنشاء التطبيق الأيوني)، أو أنماط Vue الخاصة بالمكثفات بدون Ionic (استخدم capacitor-vue)، أو ترقية الإصدارات الأيونية (استخدم ترقيات التطبيق الأيوني)، أو أطر عمل غير Vue مثل Angular أو React.
