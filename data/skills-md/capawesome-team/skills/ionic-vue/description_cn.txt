通过 Ionic Vue 开发模式指导代理 — 项目结构、Vue 特定的 Ionic 组件（IonPage、IonRouterOutlet、IonTabs）、Vue Router 和 useIonRouter 导航、Ionic 生命周期挂钩（onIonViewWillEnter、onIonViewDidEnter、onIonViewWillLeave、onIonViewDidLeave）、可组合实用程序（useIonRouter、useBackButton、 useKeyboard）、基于选项卡的路由、延迟加载、使用 isPlatform 进行平台检测以及解决常见的 Vue 特定问题。请勿用于一般 Ionic 组件主题或 CLI 用法（使用 ionic-app-development）、创建新的 Ionic 应用程序（使用 ionic-app-creation）、不使用 Ionic 的特定于 Capacitor 的 Vue 模式（使用 Capacitor-vue）、升级 Ionic 版本（使用 ionic-app-upgrades）或非 Vue 框架（如 Angular 或 React）。
