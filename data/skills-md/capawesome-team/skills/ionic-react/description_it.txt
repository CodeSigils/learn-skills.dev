Guida l'agente attraverso lo sviluppo di Ionic Framework con React: struttura del progetto, componenti Ionic specifici di React, IonReactRouter e modelli di navigazione, hook del ciclo di vita Ionic (useIonViewWillEnter, useIonViewDidEnter, useIonViewWillLeave, useIonViewDidLeave), integrazione della gestione dello stato e best practice specifiche di React per le app Ionic. Non utilizzare per semplici app Capacitor React senza Ionic (usa condensatore-reagire), Ionic con Angular o Vue, creando una nuova app Ionic (usa ionic-app-creation), aggiornando Ionic a una versione più recente (usa ionic-app-upgrades) o l'utilizzo generale dei componenti Ionic senza contesto specifico per React (usa ionic-app-development).
