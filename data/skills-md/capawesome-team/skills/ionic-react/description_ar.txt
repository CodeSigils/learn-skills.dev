يرشد الوكيل خلال تطوير Ionic Framework باستخدام بنية المشروع React، والمكونات الأيونية الخاصة بـ React، وIonReactRouter وأنماط التنقل، وخطافات دورة الحياة الأيونية (useIonViewWillEnter، وuseIonViewDidEnter، وuseIonViewWillLeave، وuseIonViewDidLeave)، وتكامل إدارة الحالة، وأفضل الممارسات الخاصة بـ React لتطبيقات Ionic. لا تستخدم مع تطبيقات Capacitor React العادية بدون Ionic (استخدم capacitor-react)، أو Ionic مع Angular أو Vue، أو إنشاء تطبيق Ionic جديد (استخدم إنشاء تطبيق ionic)، أو ترقية Ionic إلى إصدار أحدث (استخدم ترقيات التطبيق الأيوني)، أو الاستخدام العام للمكونات الأيونية بدون سياق خاص بـ React (استخدم تطوير التطبيق الأيوني).
