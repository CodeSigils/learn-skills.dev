React を使用した Ionic Framework 開発を通じてエージェントをガイドします。プロジェクト構造、React 固有の Ionic コンポーネント、IonReactRouter とナビゲーション パターン、Ionic ライフサイクル フック (useIonViewWillEnter、useIonViewDidEnter、useIonViewWillLeave、useIonViewDidLeave)、状態管理の統合、Ionic アプリの React 固有のベスト プラクティスを示します。 Ionic を使用しないプレーン Capacitor React アプリ (capacitor-react を使用)、Angular または Vue を使用した Ionic、新しい Ionic アプリの作成 (ionic-app-creation を使用)、Ionic を新しいバージョンにアップグレードする (ionic-app-upgrades を使用)、または React 固有のコンテキストを使用しない一般的な Ionic コンポーネントの使用 (ionic-app-development を使用) には使用しないでください。
