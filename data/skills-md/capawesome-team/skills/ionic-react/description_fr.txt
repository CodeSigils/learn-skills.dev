Guide l'agent tout au long du développement d'Ionic Framework avec React : structure de projet, composants Ionic spécifiques à React, IonReactRouter et modèles de navigation, hooks de cycle de vie Ionic (useIonViewWillEnter, useIonViewDidEnter, useIonViewWillLeave, useIonViewDidLeave), intégration de gestion d'état et meilleures pratiques spécifiques à React pour les applications Ionic. Ne pas utiliser pour les applications Capacitor React simples sans Ionic (utilisez condensateur-react), Ionic avec Angular ou Vue, la création d'une nouvelle application Ionic (utilisez ionic-app-creation), la mise à niveau d'Ionic vers une version plus récente (utilisez ionic-app-upgrades) ou l'utilisation générale du composant Ionic sans contexte spécifique à React (utilisez ionic-app-development).
