Guía al agente a través del desarrollo de Ionic Framework con React: estructura del proyecto, componentes Ionic específicos de React, IonReactRouter y patrones de navegación, enlaces del ciclo de vida de Ionic (useIonViewWillEnter, useIonViewDidEnter, useIonViewWillLeave, useIonViewDidLeave), integración de administración de estado y mejores prácticas específicas de React para aplicaciones Ionic. No lo use para aplicaciones simples de Capacitor React sin Ionic (use capacitor-react), Ionic con Angular o Vue, no cree una nueva aplicación Ionic (use ionic-app-creation), actualice Ionic a una versión más nueva (use ionic-app-upgrades) o el uso general de componentes Ionic sin contexto específico de React (use ionic-app-development).
