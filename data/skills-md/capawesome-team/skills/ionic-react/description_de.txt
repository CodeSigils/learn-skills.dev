Führt den Agenten durch die Ionic Framework-Entwicklung mit React – Projektstruktur, React-spezifische Ionic-Komponenten, IonReactRouter- und Navigationsmuster, Ionic-Lebenszyklus-Hooks (useIonViewWillEnter, useIonViewDidEnter, useIonViewWillLeave, useIonViewDidLeave), Statusverwaltungsintegration und React-spezifische Best Practices für Ionic-Apps. Nicht verwenden für einfache Capacitor React-Apps ohne Ionic (verwenden Sie „Capacitor-React“), Ionic mit Angular oder Vue, zum Erstellen einer neuen Ionic-App (verwenden Sie „ionic-app-creation“), zum Aktualisieren von Ionic auf eine neuere Version (verwenden Sie „ionic-app-upgrades“) oder für die allgemeine Verwendung von Ionic-Komponenten ohne React-spezifischen Kontext (verwenden Sie „ionic-app-development“).
