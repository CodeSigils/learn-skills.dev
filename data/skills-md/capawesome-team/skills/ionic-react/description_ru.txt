Помогает агенту в разработке Ionic Framework с помощью React — структура проекта, специфичные для React компоненты Ionic, IonReactRouter и шаблоны навигации, перехватчики жизненного цикла Ionic (useIonViewWillEnter, useIonViewDidEnter, useIonViewWillLeave, useIonViewDidLeave), интеграция управления состоянием и лучшие практики, специфичные для React, для приложений Ionic. Не используйте для простых приложений Capacitor React без Ionic (используйте конденсатор-реагировать), Ionic с Angular или Vue, создания нового приложения Ionic (используйте создание ionic-app-creation), обновления Ionic до более новой версии (используйте обновления ionic-app-upgrade) или общего использования компонентов Ionic без контекста, специфичного для React (используйте ionic-app-development).
