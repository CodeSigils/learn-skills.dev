Помогает агенту перенести существующий проект приложения Capacitor из CocoaPods в Swift Package Manager (SPM) для управления зависимостями iOS. Охватывает предварительные проверки, инвентаризацию установленных плагинов Capacitor, резервное копирование настроенных файлов проекта iOS (Info.plist, AppDelegate.swift, Assets.xcassets, Base.lproj, App.entitlements, GoogleService-Info.plist, файлы .xcconfig, конфигурация подписи), удаление существующей папки `ios/`, повторное создание шаблонов с помощью `npx cap add ios --packagemanager SPM`, восстановление сохраненных файлов, повторная синхронизация плагинов и проверка сборки. Выполняет все шаги миграции вручную — не использует интерактивную команду npx cap spm-migration-assistant. Не используйте для проектов подключаемых модулей Capacitor, проектов приложений, уже находящихся в SPM, проектов приложений без существующей папки `ios/` или мобильных платформ, не поддерживающих Capacitor.
