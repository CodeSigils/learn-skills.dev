Guida l'agente attraverso la migrazione di un progetto di app Capacitor esistente da CocoaPods a Swift Package Manager (SPM) per la gestione delle dipendenze iOS. Copre i controlli dei prerequisiti, l'inventario dei plugin Capacitor installati, il backup dei file di progetto iOS personalizzati (Info.plist, AppDelegate.swift, Assets.xcassets, Base.lproj, App.entitlements, GoogleService-Info.plist, file .xcconfig, configurazione della firma), l'eliminazione della cartella `ios/` esistente, il re-scaffolding con `npx cap add ios --packagemanager SPM`, il ripristino di quelli conservati file, risincronizzazione dei plugin e verifica della build. Esegue manualmente tutti i passaggi della migrazione: non utilizza il comando interattivo "npx cap spm-migration-assistant". Non utilizzare per progetti di plug-in Capacitor, progetti di app già su SPM, progetti di app senza una cartella `ios/` esistente o framework mobili non Capacitor.
