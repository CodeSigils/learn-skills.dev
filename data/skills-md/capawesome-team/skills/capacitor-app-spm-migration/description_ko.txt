iOS 종속성 관리를 위해 CocoaPods에서 SPM(Swift Package Manager)으로 기존 Capacitor 앱 프로젝트를 마이그레이션하는 과정을 에이전트에 안내합니다. 전제 조건 검사, 설치된 Capacitor 플러그인 목록 작성, 사용자 정의된 iOS 프로젝트 파일 백업(Info.plist, AppDelegate.swift, Assets.xcassets, Base.lproj, App.entitlements, GoogleService-Info.plist, .xcconfig 파일, 서명 구성), 기존 `ios/` 폴더 삭제, `npx cap add ios --packagemanager SPM`을 사용한 재스캐폴딩, 보존된 복원 등을 다룹니다. 파일, 플러그인 재동기화, 빌드 확인 등이 있습니다. 모든 마이그레이션 단계를 수동으로 수행합니다. 대화형 `npx cap spm-migration-assistant` 명령을 사용하지 않습니다. Capacitor 플러그인 프로젝트, 이미 SPM에 있는 앱 프로젝트, 기존 'ios/' 폴더가 없는 앱 프로젝트 또는 Capacitor가 아닌 모바일 프레임워크에는 사용하지 마세요.
