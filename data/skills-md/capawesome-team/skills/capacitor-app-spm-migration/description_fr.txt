Guide l'agent tout au long de la migration d'un projet d'application Capacitor existant de CocoaPods vers Swift Package Manager (SPM) pour la gestion des dépendances iOS. Couvre les vérifications des prérequis, l'inventaire des plugins Capacitor installés, la sauvegarde des fichiers de projet iOS personnalisés (Info.plist, AppDelegate.swift, Assets.xcassets, Base.lproj, App.entitlements, GoogleService-Info.plist, fichiers .xcconfig, configuration de signature), la suppression du dossier `ios/` existant, le ré-échafaudage avec `npx cap add ios --packagemanager SPM`, restaurer les fichiers conservés, resynchroniser les plugins et vérifier la version. Effectue toutes les étapes de migration manuellement — n'utilise pas la commande interactive `npx cap spm-migration-assistant`. Ne pas utiliser pour les projets de plug-in Capacitor, les projets d'applications déjà sur SPM, les projets d'applications sans dossier `ios/` existant ou les frameworks mobiles non-Capacitor.
