Помогает агенту обновить приложение Ionic Framework до более новой основной версии. Поддерживает обновления с Ionic 4 по 8, включая переходы на несколько версий. Описывает этапы миграции для Angular, React и Vue, специфичные для платформы, критические изменения компонентов, обновления переменных CSS и изменения в поддержке браузеров. Не используйте для обновлений версий конденсаторов (вместо этого используйте обновления конденсаторных приложений), для обновлений библиотек плагинов или для неионных инфраструктур пользовательского интерфейса.
