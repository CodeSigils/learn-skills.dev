يرشد الوكيل من خلال توصيل عميل MCP بخادم Capawesome MCP المستضاف، والذي يكشف عن بحث وثائق Capawesome الحالي دائمًا وواجهة برمجة تطبيقات إدارة Capawesome Cloud. يغطي الإعداد لـ Claude Code، وClaude Desktop، وCursor، وVS Code، وإنشاء رمز API المميز، واختيار مجموعة الأدوات، ووضع القراءة فقط، والمعالجة السرية، والتحقق، واستكشاف الأخطاء وإصلاحها. لا تستخدمه لتثبيت مكونات Capacitor الإضافية، أو ترحيل التطبيقات أو المكونات الإضافية إلى إصدار أحدث، أو تشغيل أوامر Capawesome CLI، أو خوادم MCP بخلاف Capawesome.
