Помогает агенту подключить клиент MCP к размещенному серверу Capawesome MCP, который обеспечивает постоянный поиск документации Capawesome и API управления облаком Capawesome. Охватывает настройку Claude Code, Claude Desktop, Cursor и VS Code, создание токена API, выбор набора инструментов, режим только для чтения, обработку секретов, проверку и устранение неполадок. Не используйте для установки плагинов Capacitor, переноса приложений или плагинов на более новую версию, запуска команд CLI Capawesome или серверов MCP, отличных от Capawesome.
