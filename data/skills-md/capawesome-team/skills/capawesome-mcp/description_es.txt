Guía al agente a través de la conexión de un cliente MCP al servidor MCP alojado de Capawesome, que expone la búsqueda de documentación de Capawesome siempre actualizada y la API de administración de Capawesome Cloud. Cubre la configuración de Claude Code, Claude Desktop, Cursor y VS Code, creación de tokens API, selección de conjuntos de herramientas, modo de solo lectura, manejo de secretos, verificación y solución de problemas. No lo use para instalar complementos de Capacitor, migrar aplicaciones o complementos a una versión más nueva, ejecutar comandos CLI de Capawesome o servidores MCP que no sean Capawesome.
