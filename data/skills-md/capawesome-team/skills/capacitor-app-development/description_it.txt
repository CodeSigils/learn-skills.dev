Non utilizzare per creare nuove app Capacitor, API di plug-in Capacitor, creare plug-in Capacitor, acquisti in-app, aggiornare versioni di Capacitor, migrazione Cordova o PhoneGap o modelli specifici del framework (Angular, React, Vue).
