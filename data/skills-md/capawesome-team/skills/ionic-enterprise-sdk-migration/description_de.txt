Führt den Agenten durch die Migration von Capacitor-Apps von abgekündigten Ionic Enterprise SDK-Plugins (Auth Connect, Identity Vault, Secure Storage) zu ihren Capawesome-Alternativen (OAuth, Biometrics, Secure Preferences, SQLite). Deckt Abhängigkeitserkennung, parallele API-Zuordnung, Code-Ersetzung und plattformspezifische Konfiguration für jedes Plugin-Paar ab. Nicht zum Migrieren von Capacitor-Apps oder -Plugins auf eine neuere Version, zum Einrichten von Capawesome Cloud oder für mobile Frameworks, die nicht von Capacitor stammen, verwenden.
