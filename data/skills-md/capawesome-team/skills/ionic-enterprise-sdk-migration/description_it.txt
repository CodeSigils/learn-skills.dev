Guida l'agente attraverso la migrazione delle app Capacitor dai plug-in Ionic Enterprise SDK fuori produzione (Auth Connect, Identity Vault, Secure Storage) alle loro alternative Capawesome (OAuth, Biometrics, Secure Preferences, SQLite). Copre il rilevamento delle dipendenze, la mappatura delle API affiancate, la sostituzione del codice e la configurazione specifica della piattaforma per ciascuna coppia di plug-in. Non utilizzare per la migrazione di app o plug-in Capacitor a una versione più recente, per la configurazione di Capawesome Cloud o di framework mobili non Capacitor.
