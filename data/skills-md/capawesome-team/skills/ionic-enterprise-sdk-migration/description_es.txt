Guía al agente a través de la migración de aplicaciones de Capacitor desde complementos descontinuados del SDK de Ionic Enterprise (Auth Connect, Identity Vault, Secure Storage) a sus alternativas de Capawesome (OAuth, Biometrics, Secure Preferences, SQLite). Cubre la detección de dependencias, el mapeo de API en paralelo, el reemplazo de código y la configuración específica de la plataforma para cada par de complementos. No lo use para migrar aplicaciones o complementos de Capacitor a una versión más nueva, configurar Capawesome Cloud o marcos móviles que no sean de Capacitor.
