Guide l'agent tout au long de la migration des applications Capacitor depuis les plugins Ionic Enterprise SDK abandonnés (Auth Connect, Identity Vault, Secure Storage) vers leurs alternatives Capawesome (OAuth, Biometrics, Secure Preferences, SQLite). Couvre la détection des dépendances, le mappage d'API côte à côte, le remplacement de code et la configuration spécifique à la plate-forme pour chaque paire de plugins. Ne pas utiliser pour migrer des applications ou des plugins Capacitor vers une version plus récente, configurer Capawesome Cloud ou des frameworks mobiles non-Capacitor.
