중단된 Ionic Enterprise SDK 플러그인(Auth Connect, Identity Vault, Secure Storage)에서 Capawesome 대안(OAuth, Biometrics, Secure Preferences, SQLite)으로 Capacitor 앱을 마이그레이션하는 과정을 에이전트에게 안내합니다. 각 플러그인 쌍에 대한 종속성 감지, 병렬 API 매핑, 코드 교체 및 플랫폼별 구성을 다룹니다.
