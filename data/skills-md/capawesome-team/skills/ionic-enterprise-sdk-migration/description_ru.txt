Помогает агенту перенести приложения Capacitor из прекращенных плагинов Ionic Enterprise SDK (Auth Connect, Identity Vault, Secure Storage) на их альтернативы Capawesome (OAuth, Biometrics, Secure Preferences, SQLite). Охватывает обнаружение зависимостей, параллельное сопоставление API, замену кода и настройку для конкретной платформы для каждой пары плагинов. Не используйте для переноса приложений или плагинов Capacitor в более новую версию, настройки Capawesome Cloud или мобильных платформ, отличных от Capacitor.
