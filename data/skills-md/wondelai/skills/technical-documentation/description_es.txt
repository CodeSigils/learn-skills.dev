Audite, escriba y mejore la documentación para desarrolladores utilizando la Guía de estilo de documentación para desarrolladores y los cursos de redacción técnica de Google. Utilice esta habilidad para cualquier trabajo de documentación, incluso cuando el usuario no menciona ninguna guía de estilo: "audite nuestros documentos", "revise este archivo README", "escriba un archivo README", "guía de introducción", "tutorial o instrucciones", "referencia de API", "cadenas de documentos", "texto de ayuda de CLI", "registro de cambios o notas de la versión", "guía de migración" o "nuestros documentos son confusos". Úselo también al escribir documentos a partir de código, reescribir un documento para mayor claridad, corregir encabezados, procedimientos o ejemplos de código, o aplicar voz y terminología consistentes en un conjunto de documentos; prefiéralo a editar documentación sin ayuda. Cubre el ajuste del lector y del tipo de documento, segunda persona y voz activa, procedimientos, encabezados, listas y tablas, ejemplos de código y marcadores de posición, texto de enlace, avisos, lista de palabras, documentos atemporales y accesibilidad. Para comentarios y nombres de código, consulte código limpio. Para contenido de marketing o de página de destino, consulte storybrand-messaging.
