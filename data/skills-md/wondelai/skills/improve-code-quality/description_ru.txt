Управляемый путь от работающего, но непроверенного прототипа с Vibe-кодом до готового к производству продукта с тестами, чистой структурой, границами бизнес-правил и устойчивостью в масштабе. Поэтапно координирует девять навыков - работа с устаревшим кодом, чистый код, шаблоны рефакторинга, философия проектирования программного обеспечения, чистая архитектура, прагматичный программист, релиз, проектирование системы, ddia-системы - задает вопросы пользователю на каждом этапе принятия решения и записывает результаты в папку docs/ проекта (TESTING.md, TECH-DEBT.md, RELIABILITY.md, IMPROVE-CODE-QUALITY-PLAN.md), чтобы работа возобновлялась между сеансами. Используйте, когда пользователь хочет усилить прототип, созданный ИИ, добавить тесты перед рефакторингом, сделать код безопасным для изменения или говорит: «Это работает на моей машине, но я боюсь к нему прикасаться». Для большой устаревшей кодовой базы используйте команду Remove-Technical-Debt; чтобы определить структуру перед строительством, используйте дизайн-код-архитектуру; для продукта и UX-прохода используйте Improve-App. Для одной изолированной платформы вызовите этот навык напрямую.
