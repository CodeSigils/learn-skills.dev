Viaje guiado desde una idea de aplicación en bruto hasta una primera versión validada y con una arquitectura limpia que se envía con una cadencia sostenible. Orquesta diez habilidades fase por fase: lean-startup, design-sprint, clean-architecture, domain-driven-design, clean-code, pragmatic-programmer, system-design, ios-hig-design, 37signals-way, software-design-philosophy - haciendo preguntas al usuario en cada punto de decisión y registrando los resultados en los documentos/carpeta del proyecto (PRODUCT.md, ARCHITECTURE.md, EXPERIMENTS.md, CREATE-APP-PLAN.md) para que el viaje se reanude entre sesiones. Úselo cuando el usuario quiera crear una nueva aplicación, validar una idea antes de escribir código, diseñar un MVP que no necesitará reescribirse o decir "ayúdame a construir mi aplicación de la manera correcta". La aplicación ya existe: utilice la aplicación de mejora o la aplicación de crecimiento. Idea de negocio aún no validada: primero ejecute create-business. Solo sitio de marketing: use create-website. Pregunta exclusiva de arquitectura: diseño-código-arquitectura. Para un marco de trabajo aislado, invoque esa habilidad directamente.
