Geführte Reise von einer rohen App-Idee zu einer validierten, sauber strukturierten ersten Version, die in einem nachhaltigen Rhythmus ausgeliefert wird. Ordnet zehn Fähigkeiten Phase für Phase zu – Lean-Startup, Design-Sprint, Clean-Architecture, Domain-Driven-Design, Clean-Code, pragmatischer Programmierer, Systemdesign, iOS-Hig-Design, 37Signals-Way, Software-Design-Philosophie – stellt dem Benutzer an jedem Entscheidungspunkt Fragen und zeichnet die Ergebnisse in den Projektdokumenten/Ordnern auf (PRODUCT.md, ARCHITECTURE.md, EXPERIMENTS.md, CREATE-APP-PLAN.md), damit die Reise sitzungsübergreifend fortgesetzt wird. Verwenden Sie diese Option, wenn der Benutzer eine neue App erstellen, eine Idee vor dem Schreiben von Code validieren, ein MVP entwerfen möchte, das nicht neu geschrieben werden muss, oder wenn er sagt: „Helfen Sie mir, meine App richtig zu erstellen“. App existiert bereits: Verbessere-App oder Grow-App verwenden. Geschäftsidee noch nicht validiert: Führen Sie zuerst „create-business“ aus. Nur Marketing-Website: Verwenden Sie „create-website“. Nur-Architektur-Frage: Design-Code-Architektur. Rufen Sie diese Fähigkeit für ein isoliertes Framework direkt auf.
