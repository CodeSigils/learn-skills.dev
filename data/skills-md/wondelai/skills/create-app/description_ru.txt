Управляемый путь от сырой идеи приложения к проверенной, четко спроектированной первой версии, которая выпускается с устойчивым темпом. Поэтапно координирует десять навыков - бережливый запуск, дизайн-спринт, чистая архитектура, предметно-ориентированное проектирование, чистый код, прагматичный программист, системное проектирование, ios-hig-design, 37signals-way, философия проектирования программного обеспечения - задавая вопросы пользователю на каждом этапе принятия решения и записывая результаты в папку docs/ проекта (PRODUCT.md, ARCHITECTURE.md, EXPERIMENTS.md, CREATE-APP-PLAN.md), поэтому путешествие возобновляется между сеансами. Используйте его, когда пользователь хочет создать новое приложение, проверить идею перед написанием кода, разработать MVP, который не нужно будет переписывать, или когда он говорит: «Помогите мне правильно создать мое приложение». Приложение уже существует: используйте приложение Improve-App или Grow-App. Бизнес-идея еще не проверена: сначала запустите create-business. Только маркетинговый сайт: используйте create-website. Вопрос только об архитектуре: дизайн-код-архитектура. Для одной изолированной платформы вызовите этот навык напрямую.
