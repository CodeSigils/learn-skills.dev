Cambie y pruebe de forma segura bases de código no probadas utilizando "Trabajar eficazmente con código heredado" de Michael C. Feathers. Úselo cuando el usuario mencione "código heredado", "sin pruebas", "código base no probado", "cómo pruebo esto", "costuras", "pruebas de caracterización", "método de brote", "miedo de cambiar este código", "método monstruo" o "romper dependencia". También se activa cuando se modifica código sin pruebas de forma segura, se prueba una clase cuando los constructores, los elementos estáticos o los singleton la bloquean, se agregan funciones a módulos enredados o se planifica una cobertura de prueba incremental para una base de código antigua. Cubre el algoritmo de cambio de código heredado, uniones, pruebas de caracterización, germinación/envoltura y técnicas de ruptura de dependencias. Para refactorizar código que ya tiene pruebas, consulte patrones de refactorización. Para conocer la calidad del código del día a día, consulte código limpio.
