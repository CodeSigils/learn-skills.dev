Безопасно меняйте и тестируйте непроверенные кодовые базы, используя книгу Майкла К. Фезерса «Эффективная работа с устаревшим кодом». Используйте, когда пользователь упоминает «устаревший код», «нет тестов», «непроверенная кодовая база», «как это проверить», «швы», «тесты характеристик», «метод ростка», «боюсь изменить этот код», «метод-монстр» или «нарушение зависимостей». Также срабатывает при безопасном изменении кода без тестов, получении тестируемого класса, когда его блокируют конструкторы, статики или синглтоны, добавлении функций в запутанные модули или планировании дополнительного тестового покрытия для старой базы кода. Охватывает устаревший алгоритм изменения кода, швы, характеризационные тесты, развертывание/перенос и методы разрушения зависимостей. Информацию о рефакторинге кода, в котором уже есть тесты, см. в разделе «Шаблоны рефакторинга». Информацию о ежедневном качестве кода см. в разделе «Чистый код».
