Modifica e testa in modo sicuro basi di codice non testate utilizzando "Working Effectively with Legacy Code" di Michael C. Feathers. Da utilizzare quando l'utente menziona "codice legacy", "nessun test", "codebase non testato", "come posso testarlo", "congiunzioni", "test di caratterizzazione", "metodo germoglio", "paura di cambiare questo codice", "metodo mostro" o "interruzione delle dipendenze". Si attiva anche quando si modifica il codice senza test in modo sicuro, si mette una classe sotto test quando costruttori, statici o singleton la bloccano, si aggiungono funzionalità a moduli aggrovigliati o si pianifica la copertura di test incrementali per una vecchia base di codice. Copre l'algoritmo di modifica del codice legacy, le giunzioni, i test di caratterizzazione, il germogliamento/avvolgimento e le tecniche di interruzione delle dipendenze. Per il refactoring del codice che dispone già di test, vedere refactoring-patterns. Per la qualità quotidiana del codice, vedere clean-code.
