يمكنك تغيير قواعد التعليمات البرمجية غير المختبرة واختبارها بأمان باستخدام "العمل بفعالية مع Legacy Code" لمايكل سي. فيذرز. يُستخدم عندما يذكر المستخدم "الكود القديم"، أو "لا توجد اختبارات"، أو "قاعدة التعليمات البرمجية غير المختبرة"، أو "كيف يمكنني اختبار هذا"، أو "الطبقات"، أو "اختبارات التوصيف"، أو "طريقة البرعم"، أو "أخشى تغيير هذا الرمز"، أو "طريقة الوحش"، أو "كسر التبعية". يتم التشغيل أيضًا عند تعديل التعليمات البرمجية دون اختبارات بأمان، أو الحصول على فئة قيد الاختبار عندما يقوم المنشئون أو الإحصائيات أو المفردات بحظرها، أو إضافة ميزات إلى الوحدات المتشابكة، أو التخطيط لتغطية اختبار تزايدية لقاعدة تعليمات برمجية قديمة. يغطي خوارزمية تغيير التعليمات البرمجية القديمة، والطبقات، واختبارات التوصيف، والبراعم/الالتفاف، وتقنيات كسر التبعية. للتعرف على كود إعادة البناء الذي يحتوي بالفعل على اختبارات، راجع أنماط إعادة البناء. للحصول على جودة التعليمات البرمجية اليومية، راجع التعليمات البرمجية النظيفة.
