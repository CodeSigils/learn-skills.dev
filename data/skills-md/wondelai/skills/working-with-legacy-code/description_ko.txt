Feathers의 "Working Effectively with Legacy Code"를 사용하여 테스트되지 않은 코드베이스를 안전하게 변경하고 테스트하세요. 사용자가 "레거시 코드", "테스트 없음", "테스트되지 않은 코드베이스", "이것을 어떻게 테스트합니까?", "이음새", "특성화 테스트", "새싹 방법", "이 코드 변경이 두렵습니다", "괴물 방법" 또는 "종속성 위반"을 언급할 때 사용합니다. 또한 테스트 없이 코드를 안전하게 수정할 때, 생성자, 정적 변수 또는 싱글톤이 이를 차단할 때 테스트 중인 클래스를 가져오거나, 복잡한 모듈에 기능을 추가하거나, 이전 코드베이스에 대한 증분 테스트 적용 범위를 계획할 때 트리거됩니다. 레거시 코드 변경 알고리즘, 이음매, 특성화 테스트, 새싹/랩 및 종속성 해제 기술을 다룹니다. 이미 테스트가 있는 리팩토링 코드는 refactoring-patterns를 참조하세요. 일상적인 코드 품질은 clean-code를 참조하세요.
