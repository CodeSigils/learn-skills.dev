Viaje guiado desde una página en blanco a un sitio web activo y de alta conversión, creado primero el mensaje, luego el diseño y luego la conversión. Orquesta diez habilidades fase por fase: marketing de una página, storybrand-messaging, made-to-stick, top-design, web-typography, refactoring-ui, ux-heuristics, cro-methodology, scorecard-marketing, steve-jobs-design-review - haciendo preguntas al usuario en cada punto de decisión y registrando los resultados en la carpeta docs/carpeta del proyecto (POSITIONING.md, WEBSITE.md, DESIGN.md, CREATE-WEBSITE-PLAN.md) para que el viaje se reanude entre sesiones. Úselo cuando el usuario quiera crear un nuevo sitio web o una página de destino desde cero, convertir una idea validada en una página que convierta o diga "constrúyame una página de destino para mi SaaS". El sitio ya existe: utilice el sitio web mejorado para corregir la conversión/UX o el sitio web de crecimiento para obtener más tráfico; crear un producto de software, no un sitio de marketing: utilice create-app; aún no hay posicionamiento: ejecute create-business primero o la fase de posicionamiento aquí. Para un marco de trabajo aislado, invoque esa habilidad directamente.
