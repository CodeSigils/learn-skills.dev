Geführte Reise von einer leeren Seite zu einer Live-Website mit hoher Conversion-Rate, bei der zuerst die Nachricht erstellt wird, dann das Design und dann die Konvertierung. Orchestriert zehn Fähigkeiten Phase für Phase – One-Page-Marketing, Story-Brand-Messaging, Made-to-Stick, Top-Design, Web-Typografie, Refactoring-UI, UX-Heuristik, Cro-Methodologie, Scorecard-Marketing, Steve-Jobs-Design-Review – stellt dem Benutzer an jedem Entscheidungspunkt Fragen und zeichnet die Ergebnisse in den Projektdokumenten/Ordnern auf (POSITIONING.md, WEBSITE.md, DESIGN.md, CREATE-WEBSITE-PLAN.md), damit die Reise sitzungsübergreifend fortgesetzt wird. Verwenden Sie diese Option, wenn der Benutzer eine neue Website oder Landingpage von Grund auf erstellen, eine validierte Idee in eine konvertierbare Seite umwandeln möchte oder sagt: „Erstellen Sie mir eine Landingpage für mein SaaS“. Die Website existiert bereits: Verwenden Sie Improve-Website, um Konvertierung/UX zu verbessern, oder Grow-Website für mehr Traffic. Erstellen eines Softwareprodukts, nicht einer Marketing-Website: Verwenden Sie „create-app“; Noch keine Positionierung: Führen Sie hier zuerst „create-business“ oder die Positionierungsphase aus. Rufen Sie diese Fähigkeit für ein isoliertes Framework direkt auf.
