رحلة إرشادية من صفحة فارغة إلى موقع ويب مباشر عالي التحويل، يتم إنشاء الرسالة أولاً، ثم التصميم، ثم التحويل. ينسق عشر مهارات مرحلة تلو الأخرى - التسويق من صفحة واحدة، رسائل العلامة التجارية، التصميم الملتصق، التصميم العلوي، طباعة الويب، إعادة بناء واجهة المستخدم، استدلالات ux، منهجية cro، تسويق بطاقة النتائج، مراجعة تصميم ستيف جوبز - طرح أسئلة المستخدم في كل نقطة قرار وتسجيل النتائج في مستندات/مجلد المشروع (POSITIONING.md، WEBSITE.md، DESIGN.md، CREATE-WEBSITE-PLAN.md) بحيث تستأنف الرحلة عبر الجلسات. يُستخدم عندما يريد المستخدم إنشاء موقع ويب جديد أو صفحة مقصودة من البداية، أو تحويل فكرة تم التحقق من صحتها إلى صفحة يتم تحويلها، أو يقول "أنشئ لي صفحة مقصودة لـ SaaS الخاص بي". الموقع موجود بالفعل: استخدم موقع الويب المحسن لإصلاح التحويل/تجربة المستخدم أو قم بتنمية موقع الويب لزيادة عدد الزيارات؛ بناء منتج برمجي، وليس موقع تسويق: استخدم إنشاء التطبيق؛ لا يوجد تحديد موضع بعد: قم بتشغيل إنشاء الأعمال أولاً أو مرحلة تحديد الموضع هنا. بالنسبة لإطار واحد بشكل منفصل، قم باستدعاء تلك المهارة مباشرة.
