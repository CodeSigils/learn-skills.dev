Voyage guidé d'une page vierge à un site Web en direct à fort taux de conversion, construit d'abord avec le message, puis la conception, puis la conversion. Orchestre dix compétences phase par phase - marketing d'une page, message de marque d'histoire, sur mesure, conception de qualité supérieure, typographie Web, refactoring-ui, heuristique ux, cro-méthodologie, scorecard-marketing, steve-jobs-design-review - poser des questions à l'utilisateur à chaque point de décision et enregistrer les résultats dans le dossier docs/du projet (POSITIONING.md, WEBSITE.md, DESIGN.md, CREATE-WEBSITE-PLAN.md) afin que le voyage reprenne au fil des sessions. À utiliser lorsque l'utilisateur souhaite créer un nouveau site Web ou une nouvelle page de destination à partir de zéro, transformer une idée validée en une page qui se convertit ou dit « créez-moi une page de destination pour mon SaaS ». Le site existe déjà : utilisez améliorer le site Web pour corriger la conversion/UX ou développer le site Web pour plus de trafic ; créer un produit logiciel, pas un site marketing : utilisez create-app ; pas encore de positionnement : lancez d'abord la création d'entreprise ou la phase de positionnement ici. Pour un framework isolé, invoquez cette compétence directement.
