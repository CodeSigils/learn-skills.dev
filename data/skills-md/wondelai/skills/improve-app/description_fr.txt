Voyage guidé depuis une application livrée qui fonctionne mais semble difficile jusqu'à un produit qui correspond au travail, se déroule sans friction, lit clairement et persuade honnêtement. Orchestre neuf compétences phase par phase - tâches à accomplir, heuristique ux, conception des choses de tous les jours, refactorisation de l'interface utilisateur, microinteractions, sur mesure, psychologie de l'influence, navigateur haute performance, steve-jobs-design-review - posant des questions à l'utilisateur à chaque point de décision et enregistrant les résultats dans le dossier docs/ du projet (CUSTOMER.md, DESIGN.md, POSITIONING.md, IMPROVE-APP-PLAN.md) pour que le voyage reprenne au fil des sessions. À utiliser lorsque l'utilisateur souhaite réparer un produit encombrant, réduire les frictions UX, affiner la copie et les invites dans l'application, ou dire « l'application fonctionne mais semble difficile ». Ne pas utiliser pour le code, les tests ou le renforcement de la production - utilisez l'amélioration de la qualité du code (nouveau prototype) ou la suppression de la dette technique (base de code ancienne) ; pas encore d'application, créer une application ; a besoin de boucles de croissance, de grow-app ; friction sur le site marketing, amélioration du site Web. Pour un framework isolé, invoquez cette compétence directement.
