Управляемый путь от сырой идеи к проверенному, позиционируемому, ценовому бизнесу с выбранным плацдармом. Поэтапно координирует десять навыков — «задания, которые необходимо выполнить», «мамашнее тестирование», «дизайн-спринт», «бережливый стартап», «хорошая стратегия — плохая стратегия», «стратегия голубого океана», «очевидно-крутые», «стомиллионные предложения», «монетизация-инновации», «преодоление пропасти» — задавая вопросы пользователю на каждом этапе принятия решения и записывая результаты в папку docs/ проекта (CUSTOMER.md, POSITIONING.md, OFFER.md, CREATE-BUSINESS-PLAN.md), чтобы путешествие возобновлялось между сеансами. Используйте, когда пользователь хочет начать новый бизнес, проверить идею стартапа, определить соответствие продукта рынку перед созданием или говорит: «У меня есть идея для компании». Не используйте, если у бизнеса есть платежеспособные клиенты: используйте развитие бизнеса для увеличения доходов и клиентов или улучшение бизнеса для исправления стратегии и операций. Для создания самого продукта используйте create-app или create-website. Для одной изолированной платформы вызовите этот навык напрямую.
