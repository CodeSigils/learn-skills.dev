Viaje guiado desde la idea en bruto hasta un negocio validado, posicionado y valorado con una cabeza de playa elegida. Orquesta diez habilidades fase por fase: trabajos por hacer, prueba de mamá, sprint de diseño, startup lean, buena estrategia-mala estrategia, estrategia de océano azul, obviamente impresionante, ofertas de cien millones, monetización de la innovación, cruzar el abismo, formulando preguntas al usuario en cada punto de decisión y registrando los resultados en la carpeta documentos/del proyecto (CUSTOMER.md, POSITIONING.md, OFERTA.md, CREATE-BUSINESS-PLAN.md) para que el viaje se reanude entre sesiones. Utilícelo cuando el usuario quiera iniciar un nuevo negocio, validar una idea inicial, encontrar un producto adecuado para el mercado antes de crearlo o decir "Tengo una idea para una empresa". No lo use una vez que la empresa tenga clientes de pago: use crecer el negocio para agregar ingresos y clientes, o mejorar el negocio para arreglar la estrategia y las operaciones. Para crear el producto en sí, utilice create-app o create-website. Para un marco de trabajo aislado, invoque esa habilidad directamente.
