Viaje guiado desde una base de código funcional que se volvió lenta y enredada a uno mensurablemente rápido, claramente delimitado y legible. Orquesta ocho habilidades fase por fase: trabajar con código heredado, arquitectura limpia, filosofía de diseño de software, patrones de refactorización, diseño de sistemas, ddia-systems, release-it, programador pragmático. Cada fase lleva su método en línea para que se ejecute de forma independiente, haciendo preguntas al usuario en cada punto de decisión y registrando los resultados en la carpeta docs/del proyecto (PERFORMANCE.md, ARCHITECTURE.md, ARCHITECTURE-OPTIMIZATION-PLAN.md) para que el viaje se reanude entre sesiones. Úselo cuando el usuario quiera hacer que una aplicación sea más rápida, desenredar límites desviados, corregir consultas y puntos finales lentos, o decir "funciona pero es lento y está empeorando". Para un prototipo no probado, mejore la calidad del código; para una base de código antigua que temes tocar, elimina la deuda técnica; para estructura totalmente nueva, diseño-código-arquitectura; para la velocidad de la página del sitio de marketing, mejore el sitio web. Para un marco de trabajo aislado, invoque esa habilidad directamente.
