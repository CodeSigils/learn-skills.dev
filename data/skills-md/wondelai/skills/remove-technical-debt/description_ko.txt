모두가 두려워하는 크고 오래된 코드베이스에서 변경해도 안전하고 읽기 쉽고 제한적이며 탄력성이 있는 코드베이스로의 여정을 안내합니다. 재작성 없이 제자리에 완료됩니다. 레거시 코드 작업, 리팩터링 패턴, 클린 코드, 소프트웨어 디자인 철학, 클린 아키텍처, 실용주의 프로그래머, 릴리스-잇, 도메인 중심 디자인 등 8가지 기술을 단계별로 조율합니다. 모든 결정 지점에서 사용자에게 질문하고 프로젝트 문서/폴더(TESTING.md, TECH-DEBT.md, REMOVE-TECHNICAL-DEBT-PLAN.md)에 결과를 기록합니다. 세션 전체에서 재개됩니다. 사용자가 레거시 코드베이스를 길들이고 싶거나, 기술적 부채를 안전하게 청산하고 싶거나, 대규모 재작성을 피하고 싶거나 '이 코드를 건드리기가 두렵습니다'라고 말할 때 사용하세요. 새로운 프로토타입이나 바이브 코딩된 앱을 제작하려면 Improve-code-quality를 사용하세요. 그린필드 구조의 경우 디자인-코드-아키텍처를 사용합니다. 코드 전용이 아닌 제품 및 UX 패스의 경우 Improve-app을 사용하세요. 격리된 하나의 프레임워크에 대해 해당 기술을 직접 호출합니다.
