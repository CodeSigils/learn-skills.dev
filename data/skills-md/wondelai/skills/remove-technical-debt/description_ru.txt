Управляемый путь от большой устаревшей кодовой базы, которую каждый боится трогать, к базе, которую можно безопасно изменить, разборчивой, ограниченной и отказоустойчивой, которая окупается на месте без переписывания. Поэтапно координирует восемь навыков - работа с устаревшим кодом, шаблоны рефакторинга, чистый код, философия проектирования программного обеспечения, чистая архитектура, прагматичный программист, релиз, проектирование, ориентированное на предметную область - задавая вопросы пользователю на каждом этапе принятия решения и записывая результаты в папку docs/ проекта (TESTING.md, TECH-DEBT.md, REMOVE-TECHNICAL-DEBT-PLAN.md), поэтому путешествие возобновляется между сеансами. Используйте, когда пользователь хочет приручить устаревшую кодовую базу, безопасно погасить технический долг, избежать масштабной переписывания или говорит: «Мы боимся трогать этот код». Для нового прототипа или приложения с vibe-кодом, отправляющегося в производство, используйте улучшение качества кода; для новой структуры используйте дизайн-код-архитектуру; для прохождения продукта и UX, а не только кода, используйте Improve-App. Для одной изолированной платформы вызовите этот навык напрямую.
