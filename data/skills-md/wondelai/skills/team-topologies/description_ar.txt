قم بتنظيم فرق الأعمال والتكنولوجيا لتحقيق التدفق السريع باستخدام "طوبولوجيا الفريق" لماثيو سكيلتون ومانويل بايس. يُستخدم عندما يذكر المستخدم "طوبولوجيات الفريق"، أو "قانون كونواي"، أو "فريق النظام الأساسي"، أو "الفريق المتوافق مع الدفق"، أو "حدود الفريق"، أو "الحمل المعرفي"، أو "كيف يجب تقسيم الفرق"، أو "تصميم المؤسسة"، أو "من يملك هذه الخدمة"، أو "تبعيات الفريق". يتم التشغيل أيضًا عند إعادة تنظيم الفرق الهندسية، أو مواءمة حدود الفريق والخدمة، أو تقسيم وحدة متراصة وتحديد ملكية الفريق، أو تقليل التبعيات وعمليات التسليم بين الفرق، أو تصميم منصة داخلية. يغطي أنواع الفرق الأربعة، وثلاثة أوضاع للتفاعل، ومناورة كونواي العكسية، وطائرات الكسر. بالنسبة للسياقات المحدودة وحدود المجال، راجع التصميم القائم على المجال. لمعرفة اتجاه التبعية داخل قاعدة التعليمات البرمجية، راجع البنية النظيفة.
