Parcours guidé depuis un flux de conversion qui fuit (page de destination, inscription, paiement ou intégration dans l'application) jusqu'à un entonnoir mesuré et testé. Orchestre six compétences phase par phase - analyse Lean, cro-méthodologie, message de marque d'histoire, cent millions d'offres, psychologie de l'influence, conception des choses de tous les jours - chaque phase comporte sa méthode complète en ligne afin qu'elle fonctionne de manière autonome, posant des questions à l'utilisateur à chaque point de décision et enregistrant les résultats dans le dossier docs/du projet (FUNNEL.md, METRICS.md, EXPERIMENTS.md, CONVERSION-OPTIMIZATION-PLAN.md) afin que le voyage reprenne au fil des sessions. À utiliser lorsque l'utilisateur souhaite augmenter la conversion sur un flux spécifique, corriger l'abandon de paiement ou d'inscription, diagnostiquer l'abandon de l'intégration ou dire « les gens commencent mais ne terminent jamais ». Si vous n'avez pas encore de site, utilisez create-website ; pour une apparence, un message et un audit de vitesse de l'ensemble du site, améliorez le site Web ; si le flux se convertit mais a besoin de trafic, développez le site Web ; pour l'engagement et la rétention dans le produit, améliorez l'application. Pour un framework isolé, invoquez cette compétence directement.
