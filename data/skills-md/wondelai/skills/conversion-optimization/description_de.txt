Geführte Reise von einem undichten Conversion-Flow – Landingpage, Anmeldung, Checkout oder In-App-Onboarding – zu einem gemessenen, getesteten Trichter. Orchestriert sechs Fähigkeiten Phase für Phase – Lean-Analyse, Cro-Methodologie, Story-Brand-Messaging, Hundert-Millionen-Angebote, Einflusspsychologie, Design-Alltagsdinge – jede Phase trägt ihre vollständige Methode inline, sodass sie eigenständig läuft, dem Benutzer an jedem Entscheidungspunkt Fragen stellt und die Ergebnisse im Projektdokumente/-Ordner aufzeichnet (FUNNEL.md, METRICS.md, EXPERIMENTS.md, CONVERSION-OPTIMIZATION-PLAN.md), damit die Reise sitzungsübergreifend fortgesetzt wird. Verwenden Sie diese Option, wenn der Benutzer die Konvertierung bei einem bestimmten Ablauf steigern, den Kauf- oder Anmeldeabbruch beheben, einen Onboarding-Abbruch diagnostizieren möchte oder sagt: „Menschen fangen an, werden aber nie fertig“. Wenn Sie noch keine Website haben, verwenden Sie „create-website“. für ein Erscheinungsbild, eine Botschaft und eine Geschwindigkeitsprüfung der gesamten Website: Improve-Website; Wenn der Flow konvertiert, aber Traffic benötigt, Grow-Website; für In-Product-Engagement und -Bindung, Improve-App. Rufen Sie diese Fähigkeit für ein isoliertes Framework direkt auf.
