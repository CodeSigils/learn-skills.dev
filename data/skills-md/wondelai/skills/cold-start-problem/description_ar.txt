ابدأ وتوسيع نطاق المنتجات المتصلة بالشبكة باستخدام إطار عمل "مشكلة البداية الباردة" الخاص بـ Andrew Chen لتأثيرات الشبكة. يُستخدم عندما يذكر المستخدم "تأثيرات الشبكة"، أو "الدجاجة والبيضة"، أو "البداية الباردة"، أو "السوق ذو الوجهين"، أو "الشبكة الذرية"، أو "الجانب الصلب"، أو "السيولة"، أو "الكتلة الحرجة"، أو "الإطلاق بالدعوة فقط"، أو "تعال للحصول على الأداة للبقاء في الشبكة". يتم التشغيل أيضًا عند إطلاق منتج سوقي أو اجتماعي أو تعاوني لا قيمة له بدون مستخدمين آخرين، أو تحديد تسلسل الإطلاق وتكتيكات البذر، أو تشخيص توقف نمو الشبكة أو تدهورها على نطاق واسع. يغطي المراحل الخمس: البداية الباردة، نقطة التحول، سرعة الهروب، الاصطدام بالسقف، والخندق. إذا كنت تريد انتشار الكلام الشفهي، انظر معدي. بالنسبة للاحتفاظ المبني على العادة، راجع Hooked-ux.
