Организуйте полный конвейер из пяти агентов PaperOrchestra (Song et al., 2026, arXiv:2604.05018), чтобы превратить неструктурированные исследовательские материалы (идея, журнал экспериментов, шаблон LaTeX, рекомендации для конференций, дополнительные рисунки) в готовую к отправке рукопись LaTeX и скомпилированный PDF-файл. ТРИГГЕР, когда пользователь просит «написать статью на основе моих экспериментов», «превратить эту идею и эти результаты в статью», «создать материал для конференции», «запустить paper-orchestra на X» или иным образом хочет использовать сквозной конвейер написания статей. Координирует навыки агента по составлению набросков, агента по построению графиков, агента по обзору литературы, агента по написанию разделов и агента по уточнению контента.
