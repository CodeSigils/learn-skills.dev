Выполните реверс-инжиниринг исходных материалов (разреженная идея, плотная идея, журнал экспериментов) из существующей исследовательской работы по искусственному интеллекту, чтобы создать эталонный пример для оценки конвейеров написания статей. Копирует процедуру построения набора данных PaperWritingBench из arXiv:2604.05018 §3/App. C. ТРИГГЕР, когда пользователь просит «построить тестовый пример на основе этой статьи», «перепроектировать исходные материалы» или «оценить мой конвейер с помощью PaperWritingBench».
