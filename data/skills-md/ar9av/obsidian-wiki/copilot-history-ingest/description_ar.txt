استوعب سجل جلسة GitHub Copilot CLI في موقع Obsidian wiki كصفحات معرفية مقطرة. استخدم هذه المهارة عندما يريد المستخدم تسجيل جلسات Copilot CLI الخاصة به في موقع wiki شخصي - واستخراج قرارات التصميم وملاحظات تصحيح الأخطاء والأنماط في صفحات Obsidian القابلة للبحث. تشغيل عبارات مثل "أدخل جلسات مساعد الطيار إلى سبج"، أو "أضف سجل مساعد الطيار الخاص بي إلى موقع wiki الخاص بي"، أو "اسحب سجل جلسات مساعد الطيار الخاص بي إلى الخزنة"، أو "التقط ما تعلمته من مساعد الطيار إلى سبج"، أو "الجلسات الجديدة فقط منذ آخر مرة"، أو "أنماطي عبر جلسات مساعد الطيار". يتم تشغيله أيضًا عندما يذكر المستخدم نصوص session-store.db أو ~/.copilot/session-state أو VS Code copilot-chat في سياق إنشاء wiki أو قاعدة معارف. لا يتم تشغيله للأسئلة العامة حول استخدام مساعد الطيار، أو جلسات البحث، أو النسخ الاحتياطي للسجل.
