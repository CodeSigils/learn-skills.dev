Wenn der Benutzer Bilder, KI-Zeichnungen, Text-zu-Bild, Illustrationen, Bildgenerierung oder Bilder erstellen muss, rufen Sie dies auf. Es leitet automatisch die Erstellung professioneller Eingabeaufforderungen und ruft die API auf, um Bilder zu generieren. Unterstützt eine Vielzahl von Stilen wie Porträts, Poster, Produkte, Landschaften, Anime, Fotografie, Benutzeroberfläche, technische Diagramme und mehr.
