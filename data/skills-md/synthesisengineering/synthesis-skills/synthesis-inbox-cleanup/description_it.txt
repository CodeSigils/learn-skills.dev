Pulizia della casella di posta elettronica basata su manifest su tre stack di strumenti: iCloud/IMAP generico tramite Python + regole YAML; Microsoft 365 + outlook.com tramite Mail.app AppleScript; Gmail tramite API Gmail workspace-mcp e filtri lato server. Il motore è pubblico; le regole per utente risiedono privatamente in ~/. Synthesis/inbox-cleanup/. Fornito con difese a iniezione rapida (modulo di sanificazione + dispositivi di test contraddittori) per qualsiasi percorso potenziato LLM. Utilizzare quando richiesto per: pulire la posta in arrivo, spazzare via email, classificare i mittenti, creare regole email, archiviare promozioni, impostare filtri Gmail, creare automazione della pulizia email.
