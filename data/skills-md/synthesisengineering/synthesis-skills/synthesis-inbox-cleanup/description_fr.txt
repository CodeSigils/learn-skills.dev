Nettoyage de la boîte de réception de courrier électronique basé sur un manifeste sur trois piles d'outils : iCloud / IMAP générique via les règles Python + YAML ; Microsoft 365 + Outlook.com via Mail.app AppleScript ; Gmail via l'API Gmail workspace-mcp et les filtres côté serveur. Le moteur est public ; les règles par utilisateur vivent en privé sur ~/.synthesis/inbox-cleanup/. Livré avec des défenses à injection rapide (module de désinfection + appareils de test contradictoires) pour tout chemin augmenté par LLM. À utiliser lorsque vous y êtes invité pour : nettoyer la boîte de réception, balayer les e-mails, catégoriser les expéditeurs, créer des règles de messagerie, archiver les promotions, configurer des filtres Gmail, créer une automatisation du nettoyage des e-mails.
