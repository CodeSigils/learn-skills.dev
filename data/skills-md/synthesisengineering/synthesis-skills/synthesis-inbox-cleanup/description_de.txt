Manifestgesteuerte Bereinigung des E-Mail-Posteingangs über drei Tool-Stacks hinweg: iCloud / generisches IMAP über Python + YAML-Regeln; Microsoft 365 + Outlook.com über Mail.app AppleScript; Gmail über die Gmail-API workspace-mcp und serverseitige Filter. Engine ist öffentlich; Die Regeln pro Benutzer sind privat unter ~/.synthesize/inbox-cleanup/ verfügbar. Wird mit sofortiger Injektionsverteidigung (Desinfektionsmodul + gegnerische Testvorrichtungen) für jeden LLM-erweiterten Pfad geliefert. Verwenden Sie diese Option, wenn Sie dazu aufgefordert werden: Posteingang bereinigen, E-Mails durchsuchen, Absender kategorisieren, E-Mail-Regeln erstellen, Werbeaktionen archivieren, Gmail-Filter einrichten, E-Mail-Bereinigungsautomatisierung erstellen.
