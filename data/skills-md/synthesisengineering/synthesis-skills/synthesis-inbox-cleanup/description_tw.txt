跨三個工具堆疊的清單驅動的電子郵件收件匣清理：iCloud / 透過 Python + YAML 規則的通用 IMAP； Microsoft 365 + Outlook.com 透過 Mail.app AppleScript； Gmail 透過workspace-mcp Gmail API 和伺服器端過濾器。引擎是公共的；每個使用者的規則私下存在於 ~/.synthesis/inbox-cleanup/ 中。為任何 LLM 增強路徑提供即時注入防禦（清理模組 + 對抗性測試裝置）。在需要時使用：清理收件匣、清理電子郵件、對寄件者進行分類、建立電子郵件規則、歸檔促銷、設定 Gmail 過濾器、建立電子郵件清理自動化。
