Очистка почтового ящика электронной почты на основе манифеста с использованием трех стеков инструментов: iCloud / общий IMAP с помощью правил Python + YAML; Microsoft 365 + Outlook.com через Mail.app AppleScript; Gmail через API Gmail Workspace-mcp и серверные фильтры. Движок публичный; правила для каждого пользователя находятся в частном порядке в ~/.synthesis/inbox-cleanup/. Поставляется с системой мгновенной защиты (модуль дезинфекции + приспособления для состязательных испытаний) для любого пути, дополненного LLM. Используйте, когда вас попросят: очистить почтовый ящик, проверить электронную почту, классифицировать отправителей, создать правила электронной почты, архивировать рекламные акции, настроить фильтры Gmail, автоматизировать очистку электронной почты.
