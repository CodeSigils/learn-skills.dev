Workspace git-sync guard : détecte les dépôts non validés/non poussés, les rapports via des canaux sécurisés en matière de confidentialité (audio/bannière générique + fichiers de rapport détaillés + vignette de console de synthèse) et répare automatiquement les dépôts de contexte privé lors d'événements de flux de travail via checkpoint_sync.py. Fonctionne avec n'importe quel outil de codage d'IA (Claude Code, Codex, Cursor, etc.) ou autonome. À utiliser lorsque vous y êtes invité pour : repo guard, vérifier les dépôts, vérifier la fin de session, vérifier la synchronisation, l'état du dépôt, l'état de l'espace de travail, la synchronisation du point de contrôle, les dépôts de contexte de validation automatique.
