Редактируйте, проверяйте и отправляйте изменения базы знаний Markdown с помощью рабочего процесса, управляемого конфигурацией репозитория. Считывает .agents/knowledge-base.yaml для редактируемого пакета, сгенерированных/отклоненных путей, маршрутизации тем, схемы заголовка, контроля конфиденциальности, хоста Git, ветвления и политики проверки. Используйте, когда пользователь просит обновить базу знаний, отредактировать содержимое базы знаний, исправить устойчивый факт, добавить концепцию, отправить существующее изменение базы знаний, открыть запрос на проверку базы знаний или синхронизировать извлечение локальной базы знаний после публикации.
