Edite, valide y envíe cambios en la base de conocimientos de Markdown a través del flujo de trabajo basado en configuración de un repositorio. Lee .agents/knowledge-base.yaml para el paquete editable, rutas generadas/rechazadas, enrutamiento de temas, esquema de front-matter, control de confidencialidad, host Git, ramificación y política de revisión. Úselo cuando un usuario solicite actualizar una base de conocimientos, editar el contenido de la base de conocimientos, corregir un hecho duradero, agregar un concepto, enviar una edición de la base de conocimientos existente, abrir una solicitud de revisión de la base de conocimientos o sincronizar el pago de una base de conocimientos local después de la publicación.
