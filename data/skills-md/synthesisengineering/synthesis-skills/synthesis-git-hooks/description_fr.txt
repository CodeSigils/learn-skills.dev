Politique de pré-validation déterministe pour le flux de travail d'ingénierie de synthèse. Classifie automatiquement chaque dépôt en fonction de ses télécommandes push (personnelles ou strictes), applique un ensemble de modèles à plusieurs niveaux : informations d'identification de niveau 0 toujours ; Niveau 1 financier/RH/confidentialité/noms des clients uniquement dans les pensions strictes. La politique basée sur YAML se trouve dans ~/.synthesis/git-hook-config.yaml. À utiliser lorsque vous y êtes invité pour : installer des hooks git, configurer une politique de pré-validation, empêcher les fuites d'informations d'identification, empêcher les fuites de noms confidentiels dans les dépôts publics, configurer la couche d'application de l'ingénierie de synthèse.
