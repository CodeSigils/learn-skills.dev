合成エンジニアリング ワークフローの決定論的な事前コミット ポリシー。各リポジトリをプッシュ リモート (個人対厳密) によって自動分類し、階層化されたパターン セットを適用します。階層 0 認証情報は常に適用されます。 Tier 1 財務 / 人事 / 機密保持 / 顧客名は厳密なリポジトリのみに含まれます。 YAML 主導のポリシーは ~/.Synthetic/git-hook-config.yaml にあります。 git フックのインストール、コミット前ポリシーの構成、資格情報の漏洩の防止、パブリック リポジトリでの機密名の漏洩の防止、合成エンジニアリング強制レイヤーのセットアップを求められた場合に使用します。
