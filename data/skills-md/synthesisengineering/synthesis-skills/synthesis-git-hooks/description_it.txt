Politica di pre-impegno deterministica per il flusso di lavoro di ingegneria di sintesi. Classifica automaticamente ogni repository in base ai suoi telecomandi push (personale o rigoroso), applica un set di modelli a più livelli: credenziali di livello 0 sempre; Tier 1 finanziario/risorse umane/riservatezza/nomi dei clienti solo in strict repo. La policy basata su YAML si trova in ~/.sensitive/git-hook-config.yaml. Utilizzare quando richiesto per: installare hook git, configurare policy di pre-commit, prevenire fughe di credenziali, prevenire fughe di nomi riservati nei repository pubblici, impostare il livello di applicazione dell'ingegneria di sintesi.
