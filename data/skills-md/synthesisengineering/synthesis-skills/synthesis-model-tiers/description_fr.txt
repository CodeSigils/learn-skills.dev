Convention de niveau modèle inter-fournisseurs pour le travail agent : trois étiquettes de rôle (jugement, routine, masse - anciennement frontière, efficace, léger) résolues en ID de modèle actuels par fournisseur dans niveaux.yaml, de sorte que les compétences, les documents de projet et la mémoire ne codent jamais en dur les noms de modèle. À utiliser lorsqu'on vous demande : les niveaux de modèle, quel modèle, la sélection de modèle, le modèle de jugement, le modèle de routine, le modèle global, le modèle frontière, le modèle efficace, les modèles de changement, les équivalents de modèle entre les fournisseurs, la mise à jour du tableau des modèles.
