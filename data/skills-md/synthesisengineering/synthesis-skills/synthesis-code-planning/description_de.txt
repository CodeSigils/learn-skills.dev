Strukturierter Ansatz zur Codegenerierung, Implementierung von Funktionen und Schreiben von Code. Verwenden Sie diese Option, wenn Sie aufgefordert werden, Code zu generieren, eine Funktion zu implementieren, Code zu schreiben oder eine Codierungsaufgabe in Angriff zu nehmen. Analysiert die Aufgabe, generiert mehrere Ansätze mit Kompromissen, wählt die optimale Lösung aus und setzt sie um.
