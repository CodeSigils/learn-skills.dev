オープンソースの bkt CLI、PR ライフサイクル (リスト、表示、差分、コメント、承認、マージ)、リポジトリ/ブランチ読み取り、および bkt API エスケープ ハッチを介して Bitbucket Cloud リポジトリを操作します。認証セットアップ、コンテキスト ホストの注意点、gh-to-bkt コマンド マップ、およびライト セーフティ ルールをエンコードして、エージェントが REST 呼び出しを再発明する代わりに 1 つの一貫したコマンド サーフェスを使用できるようにします。 bitbucket、bkt、bitbucket pr、bitbucket pr を開く、bitbucket pr をレビューする、bitbucket cli、bitbucket api を求められた場合に使用します。
