Trabaje con repositorios de Bitbucket Cloud a través de la CLI de bkt de código abierto: ciclo de vida de relaciones públicas (lista, vista, diferenciación, comentario, aprobación, fusión), lecturas de repositorio/rama y la ventana de escape de la API de bkt. Codifica la configuración de autenticación, el gotcha del host de contexto, un mapa de comando gh-to-bkt y reglas de seguridad de escritura para que los agentes usen una superficie de comando consistente en lugar de reinventar las llamadas REST. Úselo cuando se le solicite: bitbucket, bkt, bitbucket pr, abrir bitbucket pr, revisar bitbucket pr, bitbucket cli, bitbucket api.
