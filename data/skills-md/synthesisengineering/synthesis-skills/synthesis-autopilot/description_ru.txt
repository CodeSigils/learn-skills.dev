Режим автономного выполнения для явно делегированной работы. Тонкий слой композиции, который упорядочивает стек синтеза — структура мышления для принятия решений, файл плана + жизненный цикл контекста + контрольная точка для выживания при сжатии, анти-ярлыки для качества решения, целостность реализации для проверки — так что одна фраза делегирования заменяет перепечатанный блок постоянных инструкций. Активируйте ТОЛЬКО при явном делегировании всей задачи: позаботьтесь об этом за меня, выполните это на автопилоте, обработайте это от начала до конца, работайте с ним с минимальными проверками, завершите все этапы автономно, я верю, что вы закончите это без меня. НЕ активируйте при неопределенных совпадениях ключевых слов, при одобрении одного шага «продолжать», при обсуждении автономии или при любых двусмысленных формулировках — пользователи контролируют некоторую работу по своему выбору, а недостаточное активирование требует всего лишь нескольких дополнительных проверок, в то время как чрезмерное активирование удаляет контроль, который хотел пользователь.
