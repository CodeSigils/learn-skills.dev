تدقيق النظام البيئي التوليفي وتثبيته والتحقق منه عبر أوقات تشغيل متعددة لوكلاء الذكاء الاصطناعي. يُستخدم لعمليات تدقيق تكافؤ Claude Code وOpenAI Codex، وعمليات ترحيل تعليمات AGENTS.md وCLAUDE.md، وعمليات التحقق من نشر المهارات أو المكونات الإضافية، وصحة ربط دورة الحياة، والتحقق من صحة تمهيد Mac، وعمليات تسليم المشروع النشط، والاسترداد بعد الضغط، وأي طلب لجعل إدارة المشروع التوليفي قابلة للنقل بين عملاء الوكلاء.
