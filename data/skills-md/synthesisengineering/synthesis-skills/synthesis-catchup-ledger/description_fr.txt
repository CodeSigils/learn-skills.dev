Réconciliez les engagements en attente, manqués et incomplets après tout écart dans la cadence rituelle quotidienne (voyages, visites familiales, semaines cruciales). Balaie les plans quotidiens, les transcriptions et le contexte du projet sur une fenêtre arbitraire ; classe chaque élément apparu (y compris les éléments expirés pour l'apprentissage) ; produit un document de grand livre de rattrapage daté ; achemine les survivants sans inonder le plan quotidien. À utiliser lorsqu'on vous le demande pour : rattraper les tâches manquées, balayer les éléments en attente, rattraper le grand livre, réconcilier le retard, qu'ai-je manqué, rattraper le retard après les vacances, prendre du retard dans la récupération.
