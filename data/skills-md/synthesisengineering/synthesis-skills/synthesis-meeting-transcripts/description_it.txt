Recupera gli appunti delle riunioni generati dall'intelligenza artificiale e le trascrizioni complete (ad esempio, Google Meet + Gemini) da Gmail/Drive dell'utente in file markdown locali. Indipendente dagli strumenti: funziona con qualsiasi MCP Gmail + Drive (connettori ospitati da Anthropic, mcp di area di lavoro self-hosted o altri). Sostituisce l'e-mail manuale → Google Doc → export-markdown → Download → sposta flusso di lavoro. Utilizzare quando richiesto per: recuperare la trascrizione della riunione, eseguire il pull standup, acquisire appunti della riunione, sincronizzare le riunioni, scaricare la trascrizione, ottenere note Gemini, importare la riunione.
