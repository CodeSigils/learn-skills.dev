Twingate Internet Security - تصفية DNS، والخروج من الشبكات، وأمن المتصفح، وDNS-over-HTTPS. يتم التحميل عندما يذكر المستخدم تصفية DNS، أو تصفية المحتوى، أو أمان الإنترنت، أو شبكات الخروج، أو توجيه الخروج، أو أمان المتصفح، أو NextDNS، أو DoH، أو فئات DNS، أو أولوية الملف الشخصي. قم أيضًا بتشغيل "أمان الإنترنت"، أو "ملف تعريف أمان DNS"، أو "عنوان IP للخروج الثابت"، أو "القائمة المسموح بها لـ SaaS" في سياق Twingate. قم أيضًا بالتنشيط لتعارضات DNS واستعلامات DNS على شكل أعراض: مرشح DNS لجهة خارجية أو منتج AV يتعارض مع Twingate (Cisco Umbrella، DNSFilter، AdGuard، Avast Real Site Protection)، تعارضات نطاق CGNAT (`100.96/12`)، مشاكل تحليل DNS لواجهة شبكة متعددة، "فشلت جميع خوادم الأسماء"، تأخيرات طلب DNS على نظام التشغيل Linux، استعلام DNS الثاني لحاوية Docker يعيد عنوان IP الخاطئ، أو خطأ شخصي/DIY شبكة VPN المبنية على Twingate.
