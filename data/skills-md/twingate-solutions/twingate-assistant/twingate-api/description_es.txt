API Twingate GraphQL, herramientas CLI y automatización. Cargue cuando el usuario quiera automatizar Twingate a través de la API, escribir scripts en el punto final GraphQL, generar o administrar tokens API, usar las herramientas CLI de Twingate o crear canales de automatización. También se activa en 'GraphQL', 'X-API-KEY', 'Twingate API', 'api/graphql', 'clave de cuenta de servicio', 'aprovisionamiento de token de conector', 'limitación de velocidad' o cualquier mención de la API de administración de Twingate. Actívelo también para: automatización de recursos basada en etiquetas de AWS (sincronización de etiquetas EC2/ECS/RDS, Lambda, EventBridge/CloudWatch Events), una interfaz de usuario web para la CLI de Twingate (tgcli-web, FastAPI, Docker/Kubernetes), Twingate GitHub Action para ejecutores de CI, tutoriales de API de Jupyter/Python o para generar un informe de información o estado de la red a partir de una exportación de eventos de red.
