Twingate GraphQL API, инструменты CLI и автоматизация. Загружайте, когда пользователь хочет автоматизировать Twingate через API, писать сценарии для конечной точки GraphQL, генерировать токены API или управлять ими, использовать инструменты Twingate CLI или создавать конвейеры автоматизации. Также активируется при «GraphQL», «X-API-KEY», «Twingate API», «api/graphql», «ключе учетной записи службы», «предоставлении токена соединителя», «ограничении скорости» или любом упоминании API администратора Twingate. Также активируйте для: автоматизации ресурсов на основе тегов AWS (синхронизация тегов EC2/ECS/RDS, Lambda, EventBridge/CloudWatch Events), веб-интерфейса для интерфейса командной строки Twingate (tgcli-web, FastAPI, Docker/Kubernetes), действия Twingate GitHub для CI-исполнителей, учебных пособий по API Jupyter/Python или создания отчета о работоспособности сети/информации из экспорта сетевых событий.
