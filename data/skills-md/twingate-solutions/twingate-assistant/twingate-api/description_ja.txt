Twingate GraphQL API、CLI ツール、自動化。ユーザーが API 経由で Twingate を自動化する場合、GraphQL エンドポイントに対してスクリプトを作成する場合、API トークンを生成または管理する場合、Twingate CLI ツールを使用する場合、または自動化パイプラインを構築する場合にロードします。また、「GraphQL」、「X-API-KEY」、「Twingate API」、「api/graphql」、「サービス アカウント キー」、「コネクタ トークン プロビジョニング」、「レート制限」、または Twingate 管理 API に関する言及でもトリガーされます。また、AWS タグ駆動のリソース自動化 (EC2/ECS/RDS タグ同期、Lambda、EventBridge/CloudWatch Events)、Twingate CLI の Web UI (tgcli-web、FastAPI、Docker/Kubernetes)、CI ランナー用の Twingate GitHub アクション、Jupyter/Python API チュートリアル、またはネットワーク イベント エクスポートからのネットワーク健全性/洞察レポートの生成に対してもアクティブ化します。
