API Twingate GraphQL, outils CLI et automatisation. Charger lorsque l'utilisateur souhaite automatiser Twingate via l'API, écrire des scripts sur le point de terminaison GraphQL, générer ou gérer des jetons API, utiliser les outils CLI Twingate ou créer des pipelines d'automatisation. Déclenchez également sur 'GraphQL', 'X-API-KEY', 'API Twingate', 'api/graphql', 'clé de compte de service', 'approvisionnement de jeton de connecteur', 'limitation de débit' ou toute mention de l'API d'administration Twingate. Activez également pour : l'automatisation des ressources basée sur les balises AWS (synchronisation des balises EC2/ECS/RDS, Lambda, EventBridge/CloudWatch Events), une interface utilisateur Web pour la CLI Twingate (tgcli-web, FastAPI, Docker/Kubernetes), l'action Twingate GitHub pour les exécuteurs CI, les didacticiels de l'API Jupyter/Python ou la génération d'un rapport sur l'état/les informations du réseau à partir d'une exportation d'événements réseau.
