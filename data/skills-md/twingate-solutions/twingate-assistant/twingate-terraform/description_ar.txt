يُستخدم عندما يقوم المستخدم بكتابة أو تصحيح الأخطاء أو مراجعة تكوين Twingate Terraform. قم بالتنشيط لأي ملف .tf يمس موارد Twingate، أو موفر Twingate Terraform، أو توفير IaC للشبكات البعيدة، أو الموصلات، أو الموارد، أو المجموعات، أو حسابات الخدمة، وأسئلة إصدار الموفر، وأخطاء تطبيق terraform التي تتضمن Twingate. يتم التشغيل أيضًا عندما تحتاج مجموعات AWS أو Azure أو GCP أو Kubernetes Terraform الموجودة إلى إضافة Twingate. قم أيضًا بتشغيل أسئلة مصدر/مخطط الموفر (`داخلي/موفر/`)، أو `معرفات_المجموعة` / `الوصول`، أخطاء ترحيل الكتلة، أو إصدار إصدار الموفر، وأسئلة سجل التغيير، أو طلبات وحدات Terraform ذات البدء السريع المرجعية لـ SE لكل سحابة.
