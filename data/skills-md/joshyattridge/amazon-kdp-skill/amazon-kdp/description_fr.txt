Automatisation complète d'Amazon KDP via Playwright : connectez-vous, téléchargez les rapports de redevances, synchronisez/mettez à jour les métadonnées des livres, les prix, les téléchargements de contenu, les audits de catalogue. À utiliser lorsque l'utilisateur mentionne KDP, Kindle Direct Publishing, les rapports de redevances, les métadonnées du livre, les mots-clés, les catégories, les prix, KDP Select ou l'automatisation du compte d'auteur Amazon.
