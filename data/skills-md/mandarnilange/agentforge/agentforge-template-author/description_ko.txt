`packages/core/src/templates/<name>/`(또는 플랫폼) 아래에 새로 제공된 AgentForge 템플릿을 추가하는 방법을 기여자에게 안내합니다. 사용자에게 범위 확인, 에이전트 세트, 프롬프트, 스키마, 'template.json' 메타데이터, README 및 테스트를 안내한 다음 PR을 위해 준비된 전체 템플릿 디렉터리를 내보냅니다. 사용자가 "새 템플릿 추가", "X용 템플릿 제공", "템플릿 제공", "Y 워크플로용 스타터 생성"을 요청하거나 다른 AgentForge 사용자가 `agentforge init --template <name>`을 통해 스캐폴드할 수 있는 재사용 가능한 파이프라인 모양을 게시하려고 할 때 트리거됩니다. 최종 사용자 `.agentforge/` 프로젝트에 대해 트리거하지 마십시오(이 경우 `agentforge-workflow` 사용).
