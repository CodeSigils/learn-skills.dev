Guide un contributeur dans l'ajout d'un nouveau modèle AgentForge livré sous `packages/core/src/templates/<name>/` (ou plateforme). Guide l'utilisateur à travers la vérification de la portée, l'ensemble d'agents, les invites, les schémas, les métadonnées « template.json », le README et les tests, puis émet le répertoire de modèles complet prêt pour le PR. Se déclenche lorsque l'utilisateur demande « d'ajouter un nouveau modèle », « d'envoyer un modèle pour X », de « contribuer à un modèle », de « créer un démarreur pour le workflow Y » ou souhaite publier une forme de pipeline réutilisable que d'autres utilisateurs d'AgentForge peuvent échafauder via « agentforge init --template <name> ». Ne déclenchez PAS pour les projets `.agentforge/` de l'utilisateur final (utilisez `agentforge-workflow` pour ceux-là).
