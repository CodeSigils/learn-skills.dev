Guides a contributor through adding a new shipped AgentForge template under `packages/core/src/templates/<name>/` (or platform). Walks the user through scope check, agent set, prompts, schemas, `template.json` metadata, README, and tests, then emits the complete template directory ready for PR. Trigger when the user asks to "add a new template", "ship a template for X", "contribute a template", "create a starter for Y workflow", or wants to publish a reusable pipeline shape that other AgentForge users can scaffold via `agentforge init --template <name>`. Do NOT trigger for end-user `.agentforge/` projects (use `agentforge-workflow` for those).
