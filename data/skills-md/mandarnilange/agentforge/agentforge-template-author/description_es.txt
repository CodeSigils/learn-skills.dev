Guía al colaborador para agregar una nueva plantilla de AgentForge enviada en `packages/core/src/templates/<nombre>/` (o plataforma). Guía al usuario a través de la verificación del alcance, el conjunto de agentes, las indicaciones, los esquemas, los metadatos `template.json`, el archivo README y las pruebas, luego emite el directorio de plantilla completo listo para PR. Se activa cuando el usuario solicita "agregar una nueva plantilla", "enviar una plantilla para X", "contribuir con una plantilla", "crear un iniciador para el flujo de trabajo Y" o desea publicar una forma de canalización reutilizable que otros usuarios de AgentForge puedan implementar a través de `agentforge init --template <nombre>`. NO active proyectos `.agentforge/` de usuario final (use `agentforge-workflow` para esos).
