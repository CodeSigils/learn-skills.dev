Führt einen Mitwirkenden durch das Hinzufügen einer neuen ausgelieferten AgentForge-Vorlage unter „packages/core/src/templates/<name>/“ (oder Plattform). Führt den Benutzer durch die Bereichsprüfung, den Agentensatz, Eingabeaufforderungen, Schemata, „template.json“-Metadaten, README und Tests und gibt dann das vollständige Vorlagenverzeichnis für die PR aus. Wird ausgelöst, wenn der Benutzer „eine neue Vorlage hinzufügen“, „eine Vorlage für NICHT für Endbenutzer-„.agentforge/“-Projekte auslösen (verwenden Sie für diese „agentforge-workflow“).
