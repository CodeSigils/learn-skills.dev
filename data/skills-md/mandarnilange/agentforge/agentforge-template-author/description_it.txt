Guida un collaboratore attraverso l'aggiunta di un nuovo modello AgentForge fornito in "packages/core/src/templates/<name>/" (o piattaforma). Guida l'utente attraverso il controllo dell'ambito, il set di agenti, i prompt, gli schemi, i metadati "template.json", il README e i test, quindi genera la directory completa dei modelli pronta per PR. Si attiva quando l'utente chiede di "aggiungere un nuovo modello", "spedire un modello per X", "contribuire con un modello", "creare un antipasto per il flusso di lavoro Y" o desidera pubblicare una forma di pipeline riutilizzabile che altri utenti AgentForge possono utilizzare tramite `agentforge init --template <name>`. NON eseguire l'attivazione per i progetti `.agentforge/` dell'utente finale (utilizzare `agentforge-workflow` per quelli).
