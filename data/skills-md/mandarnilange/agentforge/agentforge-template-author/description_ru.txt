Помогает участнику добавить новый отправленный шаблон AgentForge в каталог `packages/core/src/templates/<name>/` (или платформу). Проводит пользователя через проверку области, набор агентов, запросы, схемы, метаданные `template.json`, README и тесты, а затем создает полный каталог шаблонов, готовый к PR. Запускается, когда пользователь просит «добавить новый шаблон», «отправить шаблон для X», «предоставить шаблон», «создать стартовый процесс для рабочего процесса Y» или хочет опубликовать многоразовую форму конвейера, которую другие пользователи AgentForge могут создать с помощью `agentforge init --template <name>`. НЕ запускайте триггер для проектов конечного пользователя `.agentforge/` (используйте для них `agentforge-workflow`).
