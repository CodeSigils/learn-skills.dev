يقوم بفرز تشغيل خط أنابيب AgentForge المتوقف أو الفاشل. يرشد المستخدم من الأعراض ← فحص الحالة ← تصنيف السبب الجذري ← مسار الإصلاح. يتم تشغيله عندما يبلغ المستخدم عن تشغيل AgentForge "عالق"، أو "فاشل"، أو "يتكرر"، أو "تستنفد ميزانيته"، أو "لا يتم الالتقاط عند البوابة"، أو "المخطط غير صالح"، أو "لن يتم الإرسال"، أو "العقدة لا تلتقطها"، أو يسأل "لماذا لا ينتهي خط الأنابيب X؟". لا تقم بتشغيل أسئلة تصميم AgentForge العامة (استخدم "agentforge-workflow") أو لتصحيح أخطاء مسارات الذكاء الاصطناعي غير ذات الصلة.
