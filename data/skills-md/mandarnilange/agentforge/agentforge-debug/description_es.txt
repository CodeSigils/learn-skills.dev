Clasifica una ejecución de canalización de AgentForge atascada o fallida. Guía al usuario desde síntoma → inspección de estado → clasificación de causa raíz → ruta de reparación. Se activa cuando el usuario informa que una ejecución de AgentForge está "atascada", "falla", "hace bucles", "desgasta su presupuesto", "no responde en la puerta", "esquema no válido", "no se envía", "el nodo no responde" o pregunta "¿por qué el proceso X no finaliza?". NO lo active para preguntas generales de diseño de AgentForge (use `agentforge-workflow`) o para depurar canales de IA no relacionados.
