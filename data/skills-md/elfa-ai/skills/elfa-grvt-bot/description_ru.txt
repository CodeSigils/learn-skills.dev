Спецификация для автономного бота, который объединяет условия Elfa AUTO (RSI, MACD, цена, LLM athena_condition, cron, любой EQL) с исполнением бессрочных фьючерсов GRVT с атомарным тейк-профитом и стоп-лоссом OTOCO. Овладение этим навыком дает достаточно информации для реализации бота с нуля на любом языке; ни один источник не связан. Запускайте, когда пользователь хочет установить, создать, развернуть или расширить бот Elfa-to-GRVT, разместить сделки с помощью триггеров Elfa AUTO, настроить автоматический вход плюс TP/SL для пользователей GRVT, разработать стратегии, основанные на сигналах RSI/MACD/цены/LLM/cron, создать приемник, который превращает сигналы Elfa в подписанные ордера GRVT или подключить X социальных сигналов к реальным сделкам.
