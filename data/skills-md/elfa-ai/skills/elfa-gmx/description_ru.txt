Торгуйте бессрочными контрактами GMX через Elfa Auto — стратегии, основанные на условиях (цена, TA, cron, LLM, социальные сигналы), которые выполняют рыночные/лимитные ордера с TP/SL на GMX, используя только API Elfa (без API GMX). Охватывает настройку (ключ API, автоматическое включение, HMAC, соединение GMX), параметры действий, специфичные для GMX, а также правила соревнований GMX Masters и ограждения для дисквалификации. Запускается, когда пользователь хочет торговать или создать бота на GMX через Elfa, автоматизировать вход/выход сотрудников GMX или присоединиться или принять участие в соревнованиях GMX Masters / Elfa x GMX или принять участие в них.
