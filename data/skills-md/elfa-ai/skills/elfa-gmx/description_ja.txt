Elfa Auto を介して GMX 永久取引を取引します。Elfa API のみ (GMX API は使用しません) を使用して、GMX 上の TP/SL で成行/指値注文を実行する、条件主導の戦略 (価格、TA、クロン、LLM、ソーシャル シグナル) です。セットアップ (API キー、自動有効化、HMAC、GMX 接続)、GMX 固有のアクション パラメーター、GMX マスターの競技規則と失格ガードレールについて説明します。ユーザーが Elfa 経由で GMX 上で取引またはボットの構築を希望する場合、GMX パープのエントリー/エグジットを自動化する場合、または GMX マスター / Elfa x GMX コンテストに参加または競争する場合にトリガーします。
