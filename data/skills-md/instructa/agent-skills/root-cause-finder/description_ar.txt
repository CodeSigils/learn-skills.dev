يقوم بإجراء تصحيح أخطاء السبب الجذري أولاً ومراجعته من خلال تتبع السلوك المتوقع إلى أول تأثير جانبي غير مقصود قبل تغيير العقود أو التحليل أو الأنواع. يُستخدم عند تصحيح أخطاء البروتوكول، أو فشل إلغاء التسلسل، أو الحمولات الفارغة، أو الحقول المفقودة، أو مشكلات الاستعادة أو الترطيب، أو أخطاء ملكية الحالة، أو الطلبات غير المتوقعة، أو طفرات الخلفية، أو مراجعة التعليمات البرمجية التي تم إنشاؤها بواسطة المبتدئين حيث قد يكون الفشل المرئي عبارة عن ضوضاء في اتجاه المصب.
