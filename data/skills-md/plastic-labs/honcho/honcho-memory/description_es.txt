Conceptos y estrategia para utilizar un Honcho conectado como memoria persistente del usuario: el bucle de recuperación/grabación y el diseño de sesiones y pares. Comience aquí para comprender cómo funciona la memoria Honcho, luego conéctese, a través de una integración de primera clase para su entorno, si existe (preferido), o herramientas MCP sin procesar (que se tratan aquí) o la habilidad honcho-cli (CLI). Para integrar el SDK en una base de código, utilice honcho-integration.
