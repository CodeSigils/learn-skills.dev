Концепции и стратегия использования подключенного Honcho в качестве постоянной памяти пользователя — цикл вызова/записи, а также дизайн сеанса и однорангового узла. Начните здесь, чтобы понять, как работает память Honcho, а затем подключитесь — с помощью первоклассной интеграции с вашей средой, если таковая существует (предпочтительно), или с помощью необработанных инструментов MCP (описанных здесь) или с помощью навыков honcho-cli (CLI). Для встраивания SDK в базу кода используйте хончо-интеграцию.
