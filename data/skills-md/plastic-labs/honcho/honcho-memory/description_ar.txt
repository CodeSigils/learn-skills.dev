مفاهيم وإستراتيجية لاستخدام Honcho المتصل كذاكرة دائمة للمستخدم - حلقة الاستدعاء/التسجيل وتصميم الجلسة والأقران. ابدأ هنا لفهم كيفية عمل ذاكرة Honcho، ثم قم بالاتصال - عبر تكامل من الدرجة الأولى لبيئتك إذا كان موجودًا (مفضل)، أو أدوات MCP الأولية (مغطاة هنا) أو مهارة honcho-cli (CLI). لتضمين SDK في قاعدة التعليمات البرمجية، استخدم تكامل honcho.
