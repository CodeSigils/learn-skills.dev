Maneje un editor o reproductor Unity en vivo con unity-cli. Úselo cuando una tarea deba inspeccionar o cambiar escenas de Unity, GameObjects, componentes, transformaciones, prefabricados, materiales, ScriptableObjects, activos del proyecto, modo de reproducción, capturas de pantalla, grabación del perfilador, ejecuciones de Unity Test Framework o ejecutar C# dentro de Unity; También se utiliza para el mantenimiento de la consola de Unity y la configuración, el estado, la actualización, los fragmentos o los comandos personalizados de unity-cli. No lo use para codificación Unity de fuente exclusiva que no requiera interacción con el editor o reproductor en vivo.
