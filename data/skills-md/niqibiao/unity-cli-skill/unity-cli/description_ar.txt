قم بتشغيل محرر Unity أو المشغل الحي باستخدام unity‑cli. استخدمه عندما تحتاج مهمة إلى فحص أو تعديل مشاهد Unity، أو GameObjects، أو المكونات، أو التحولات، أو الـ prefabs، أو المواد، أو ScriptableObjects، أو أصول المشروع، أو وضع اللعب، أو لقطات الشاشة، أو تسجيل ملفات تعريف الأداء، أو تشغيل اختبارات Unity Test Framework، أو تنفيذ C# داخل Unity؛ واستخدامه أيضاً لصيانة وحدة تحكم Unity وإعداد unity‑cli، الحالة، التحديث، القوالب، أو الأوامر المخصصة. لا تستخدمه للبرمجة في Unity التي تقتصر على الكود فقط ولا تتطلب التفاعل مع المحرر أو المشغل الحي.
