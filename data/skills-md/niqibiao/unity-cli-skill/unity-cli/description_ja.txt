unity‑cliでライブの Unity エディタまたはプレイヤーを操作します。タスクが Unity シーン、GameObject、コンポーネント、トランスフォーム、プレハブ、マテリアル、ScriptableObject、プロジェクトアセット、プレイモード、スクリーンショット、プロファイラ録画、Unity Test Framework の実行、または Unity 内で C# を実行する必要がある場合に使用します。また、Unity コンソールのメンテナンスや unity‑cli の設定、ステータス、リフレッシュ、スニペット、カスタムコマンドにも利用します。ライブのエディタやプレイヤーとの対話を必要としない、ソースだけの Unity コーディングには使用しないでください。
