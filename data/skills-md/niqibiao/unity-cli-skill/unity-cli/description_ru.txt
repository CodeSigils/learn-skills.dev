Управляйте живым Unity Editor или Player с помощью unity-cli. Используйте, когда задача требует инспектировать или изменять сцены Unity, объекты GameObject, компоненты, трансформы, префабы, материалы, ScriptableObject, ресурсы проекта, режим воспроизведения, скриншоты, запись профайлера, запуски Unity Test Framework или выполнение C# внутри Unity; также используйте для обслуживания консоли Unity и настройки unity-cli, статуса, обновления, сниппетов или пользовательских команд. Не используйте для написания кода Unity только в виде исходных файлов, не требующего взаимодействия с живым Editor или Player.

Пожалуйста, всегда отвечайте на языке пользователя.
