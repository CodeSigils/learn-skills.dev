Convenciones de plantilla Blade para cualquier paquete o módulo de Bagisto (Admin, Shop o cualquier paquete personalizado de estilo Webkul). Se activa al crear o editar vistas de Blade, crear componentes de Blade (componentes @props anónimos o componentes de plantilla x respaldados por Vue), conectar formularios, cuadrículas de datos, modales, diseños o ranuras, o hacer coincidir el estilo de marcado, enlace de atributos, sangría y formato del proyecto. Los convenios abarcan todo el marco; sólo difieren los tokens de espacio de nombres por paquete.
