Utilisez-le lors de la rédaction ou de la mise à jour de tout site de documentation Bagisto — la documentation développeur, le guide utilisateur marchand ou tout autre dépôt de documentation Bagisto — couvrant le contenu des pages, les exemples de code, les captures d’écran, la barre latérale, le nommage des images ainsi que le déplacement ou la suppression de pages. Les expressions déclencheuses comprennent « docs », « documentation », « guide utilisateur », « documentation développeur », « dev docs », « documentation marchand », « marketplace docs », « documenter ceci », « mettre à jour les docs », « ajouter une page de doc », « capture d’écran », « ImagePopup », « rediriger une page de doc ».
