À utiliser lors de l'écriture ou de la modification d'un test Bagisto Pest : tests de fonctionnalités ou unitaires, assertions, ensembles de données, simulations, tests d'architecture ou enregistrement de la suite d'un nouveau package. Les expressions de déclenchement incluent « parasite », « test », « test unitaire », « test de fonctionnalités », « assertion », « ensemble de données », « simulation », « suite de tests », « TDD », « couverture ».
