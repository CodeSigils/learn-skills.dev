قم بمراجعة وتقليل تأثير تبعية حزمة JavaScript عبر مشاريع npm وpnpm وYarn وBun. يُستخدم عندما يُطلب منك إزالة التبعيات غير المستخدمة، أو إلغاء تكرار إصدارات تبعية مساحة العمل، أو ملفات القفل أو وحدات العقدة، أو تحليل إغلاق ملف القفل المتعدي للتبعيات المباشرة، أو العثور على ترقيات منخفضة المخاطر تقلل من أشجار التبعية، أو التبعيات التافهة المضمنة، أو تطبيق توصيات استبدال التبعية e18e.
