Controlla e riduci l'impatto delle dipendenze dei pacchetti JavaScript nei progetti npm, pnpm, Yarn e Bun. Da utilizzare quando viene richiesto di rimuovere dipendenze inutilizzate, deduplicare versioni delle dipendenze dell'area di lavoro, file di blocco o moduli_nodo, analizzare la chiusura transitiva del file di blocco delle dipendenze dirette, trovare aggiornamenti a basso rischio che riducono gli alberi delle dipendenze, dipendenze banali in linea o applicare consigli sulla sostituzione delle dipendenze e18e.
