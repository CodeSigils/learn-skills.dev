قم بتوجيه تنفيذ الواجهة الأمامية القابلة للصيانة وإعادة الهيكلة من خلال إعادة الاستخدام الدلالي والتكوين والحدود الواضحة والتجريدات المبررة. يُستخدم لإجراء تغييرات غير تافهة على واجهة المستخدم أو الحالة أو نظام التصميم أو حدود بيانات الواجهة الأمامية؛ لا تستخدمه للهندسة المعمارية الخلفية فقط أو التعديلات التجميلية.
