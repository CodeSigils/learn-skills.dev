Protégez les modifications des applications contre les risques d'ingénierie cachés impliquant les dépendances, les secrets, la confiance client/serveur, l'authentification, l'autorisation, les données persistantes, les modifications de schéma, les hypothèses d'exécution, les opérations destructrices ou la restauration. À utiliser lors de la mise en œuvre ou de la refactorisation du code qui touche ces domaines ; ne pas utiliser pour des modifications ordinaires de présentation uniquement.
