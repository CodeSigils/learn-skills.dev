الحفاظ على النية المعمارية المقيمة في المستودع عبر الوكلاء والنماذج والجلسات والمتعاونين البشريين. يُستخدم عند إدخال نطاق موجود غير تافه، أو تغيير الملكية، أو التبعيات، أو واجهات برمجة التطبيقات العامة، أو الحالة، أو الحدود الخارجية، أو وثائق البنية؛ لا تستخدمه لإجراء تعديلات تافهة أو لسرد كود المصدر.
