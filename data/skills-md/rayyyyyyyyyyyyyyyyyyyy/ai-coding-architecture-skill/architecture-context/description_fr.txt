Préservez l’intention architecturale résidente du référentiel entre les agents, les modèles, les sessions et les collaborateurs humains. À utiliser lors de la saisie d'une portée existante non triviale, de la modification de la propriété, des dépendances, des API publiques, de l'état, des limites externes ou de la documentation d'architecture ; ne pas utiliser pour des modifications triviales ou pour la narration du code source.
