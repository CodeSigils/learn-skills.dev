Créez un agent Copilot Studio « toute nouvelle architecture » (modèle de client) entièrement automatiquement en utilisant uniquement l'API Web Dataverse. Aucune création manuelle d’interface utilisateur n’est nécessaire. La création de robots, la configuration des instructions/modèle/mémoire, l'attachement d'une compétence Python plate, l'enregistrement d'une icône, l'ajout d'un serveur MCP (Dataverse/WorkIQ) et la publication sont tous effectués via un script.
