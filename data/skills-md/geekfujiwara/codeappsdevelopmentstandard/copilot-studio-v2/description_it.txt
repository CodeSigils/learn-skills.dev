Crea un agente con una "nuova architettura" (modello client) di Copilot Studio in modo completamente automatico utilizzando solo l'API Web Dataverse. Non è necessaria la creazione manuale dell'interfaccia utente. La creazione del bot, la configurazione di istruzioni/modello/memoria, il collegamento di una competenza Python semplice, la registrazione di un'icona, l'aggiunta di un server MCP (Dataverse/WorkIQ) e la pubblicazione vengono tutti completati tramite script.
