Automatizza completamente la costruzione di un agente con una “nuova architettura” (modello client) di Copilot Studio utilizzando solo l'API Web Dataverse. Non è necessaria la creazione manuale dell'interfaccia utente. Dalla creazione del bot, alla configurazione di istruzioni/modello/memoria, al collegamento di competenze Python semplici, alla registrazione delle icone, all'aggiunta di server MCP (Dataverse/Work IQ), alla pubblicazione, tutto completato tramite script.
