Automatice completamente la construcción de un agente de “nueva arquitectura” (plantilla de cliente) de Copilot Studio utilizando únicamente la API web de Dataverse. No es necesaria la creación manual de la interfaz de usuario. Desde la creación de bots, la configuración de instrucción/modelo/memoria, la incorporación de habilidades planas de Python, el registro de iconos, la adición de servidores MCP (Dataverse/Work IQ) hasta la publicación, todo completado mediante script.
