Automatice completamente la construcción de un agente de “nueva arquitectura” (plantilla de cliente) de Copilot Studio utilizando únicamente la API web de Dataverse. No es necesaria la creación manual de la interfaz de usuario. La creación de bots, instrucciones/modelo/configuración de memoria, adjuntar una habilidad plana de Python, registro de íconos, agregar un servidor MCP (Dataverse/WorkIQ) y la publicación se realizan completamente mediante script.
