Développer un plugin Copilot Cowork spécifique (package d'application M365). Combinez les compétences d'agent (SKILL.md) avec le connecteur Dataverse MCP, configurez l'authentification du flux de code d'autorisation Entra ID OAuth2.0, obtenez un identifiant d'enregistrement dans le portail de développeur Teams, puis téléchargez-le et publiez-le à partir de l'écran de l'agent dans le centre d'administration M365 afin que Dataverse soit accessible depuis Cowork.
