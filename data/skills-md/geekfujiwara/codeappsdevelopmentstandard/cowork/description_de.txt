Entwickeln Sie ein zweckspezifisches Copilot Cowork-Plugin (M365-App-Paket). Kombinieren Sie Agent Skills (SKILL.md) mit dem Dataverse MCP-Connector, konfigurieren Sie die Entra ID OAuth2.0-Autorisierungscode-Flow-Authentifizierung, rufen Sie eine Registrierungs-ID im Teams Developer Portal ab und laden Sie sie über den Agentenbildschirm im M365 Admin Center hoch und veröffentlichen Sie sie, um den Dataverse-Zugriff von Cowork aus zu ermöglichen.
