Crea o aggiorna il file delle competenze (SKILL.md) e crea o aggiorna una richiesta pull sul remoto. SKILL.md contiene i casi normali (percorso felice); la directory dei riferimenti contiene informazioni di riferimento e casi di errore; la directory scripts memorizza script generalizzati; e i parametri vengono esternalizzati a.env.example (con valori effettivi in.env). Nascondere le informazioni personali e aziendali, garantire la coerenza e l'automazione dell'ID (MCP Learn/Playwright) e rivedere tutto fino all'allineamento con le PR aperte esistenti (dando priorità agli aggiornamenti e suggerendo l'ordine di unione).
