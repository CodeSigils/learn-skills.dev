Bereiten Sie das Code Apps-Beispiel für ein öffentliches Repository vor. Führen Sie Sicherheitsüberprüfungen durch (Entfernen vertraulicher Informationen und Ersetzen durch Platzhalter), generieren Sie ein .env.example zur Anpassung, erstellen Sie eine Funktionsbeschreibung und ein Nutzungshandbuch (README.md) und führen Sie Code-Wiederverwendbarkeitsprüfungen durch (dynamischer PUBLISHER_PREFIX, Funktionsflags, feste Navigation) – alles in einem Arbeitsgang.
