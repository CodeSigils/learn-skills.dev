Préparez l’exemple Code Apps pour un référentiel public. Effectuez des contrôles de sécurité (en supprimant les informations confidentielles et en les remplaçant par des espaces réservés), générez un .env.example pour la personnalisation, créez une description des fonctionnalités et un manuel d'utilisation (README.md) et effectuez des contrôles de réutilisabilité du code (PUBLISHER_PREFIX dynamique, indicateurs de fonctionnalités, navigation fixe) en une seule fois.
