Génère une base de connaissances .ai-context pour les agents de codage. Activer lorsque : (1) la configuration d'un nouveau projet pour le développement assisté par l'IA, (2) l'utilisateur demande de "créer des connaissances sur le projet" ou de "configurer le contexte ai", (3) le contexte .ai existant doit être régénéré. Crée une structure de documentation à plusieurs niveaux optimisée pour la compréhension des agents et l'efficacité des jetons.
