Extraiga materiales de origen académico en un espacio de trabajo local ./papers. Úselo cuando el usuario proporciona un PDF local que es claramente un documento, informe técnico, propuesta, preimpresión u otro documento académico, cuando el usuario proporciona una ID de arXiv explícita o una URL de arXiv, o cuando el usuario proporciona una ID de foro de OpenReview o una URL de foro de OpenReview. Descargue y descomprima fuentes de arXiv LaTeX para entradas explícitas de arXiv, descargue archivos PDF públicos de envío de OpenReview más metadatos para entradas explícitas de OpenReview y maneje MinerU para entradas de PDF que no sean de arXiv en modo manual, en segundo plano o en línea.
