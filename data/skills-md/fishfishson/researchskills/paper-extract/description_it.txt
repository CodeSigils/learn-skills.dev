Estrai materiali di origine accademica in uno spazio di lavoro ./papers locale. Da utilizzare quando l'utente fornisce un PDF locale che è chiaramente un documento, una relazione tecnica, una proposta, una prestampa o un altro documento accademico, quando l'utente fornisce un ID arXiv o un URL arXiv esplicito oppure quando l'utente fornisce un ID del forum OpenReview o un URL del forum OpenReview. Scarica e decomprimi le origini arXiv LaTeX per input arXiv espliciti, scarica i PDF pubblici di invio OpenReview più metadati per input OpenReview espliciti e gestisci MinerU per input PDF non arXiv in modalità manuale, in background o in linea.
