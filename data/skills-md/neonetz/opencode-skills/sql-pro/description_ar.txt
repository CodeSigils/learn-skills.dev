يُستخدم عندما يسأل المستخدم عن سبب بطء استعلامه، أو يحتاج إلى مساعدة في كتابة الصلات أو التجميعات المعقدة، أو يذكر مشكلات في أداء قاعدة البيانات، أو يريد تصميم مخطط أو ترحيله. استدعاء الاستعلامات المعقدة، ووظائف النوافذ، وCTEs، واستراتيجيات الفهرسة، وتحليل خطة الاستعلام، وتغطية إنشاء الفهرس، والاستعلامات العودية، وتفسير التفسير/التحليل، قبل/بعد قياس أداء الاستعلام، أو ترحيل الاستعلامات بين لهجات قاعدة البيانات (PostgreSQL، وMySQL، وSQL Server، وOracle). يعمل على تحسين استعلامات SQL وتصميم مخططات قاعدة البيانات واستكشاف مشكلات الأداء وإصلاحها.
