Полная спецификация для создания интерактивных романов на основе выбора: поддерживает путешествия во времени/самостоятельное создание/создание/случайное начало, со встроенной согласованностью перспективы, диапазоном количества слов, механизмом выбора, системой сохранения и системой карточек персонажей.
