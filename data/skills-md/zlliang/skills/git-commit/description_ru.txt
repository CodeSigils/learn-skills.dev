Выполните git commit с помощью обычного анализа сообщений о фиксации, интеллектуальной подготовки и генерации сообщений. Используйте, когда пользователь просит зафиксировать изменения, создайте git commit. Поддерживает: (1) автоматическое определение типа и объема изменений, (2) генерацию обычных сообщений о фиксации из различий, (3) интерактивную фиксацию с дополнительными переопределениями типа/области/описания, (4) интеллектуальную промежуточную подготовку файлов для логической группировки.
