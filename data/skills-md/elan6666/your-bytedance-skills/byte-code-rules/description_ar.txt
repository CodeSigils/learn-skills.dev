قم بتطبيق قواعد السلوك الهندسي الخاصة بـ ByteDance لكتابة التعليمات البرمجية أو مراجعتها أو إعادة هيكلتها أو تخطيطها أو تنفيذها في Byte OS. استخدم مع إنشاء البايت، أو خطة البايت، أو مراجعة البايت، أو تكرار البايت، أو البايت التلقائي، أو أي مهمة ترميز لتجنب الهندسة المفرطة، والحفاظ على عمليات التحرير الجراحية، وسطح الافتراضات الخطرة، وتحديد معايير النجاح التي يمكن التحقق منها.
