Flux de travail complet pour transformer un texte de vulgarisation scientifique en une page Web visuelle de style PPT. Déclenché lorsque les utilisateurs saisissent du contenu scientifique et souhaitent générer une page de présentation. Deux modes sont pris en charge : (1) Mode par défaut : convertit le contenu scientifique en une animation HTML d'une seule page qui imite un diaporama PPT ; (2) Mode Organigramme : restructure le fichier AI_Animation.html déjà généré en un style d'interface utilisateur plat à l'aide du modèle d'animation. Le modèle est intégré à la compétence. Les expressions déclencheurs incluent « générer un PPT », « générer une page Web de présentation », « générer un organigramme », etc.
