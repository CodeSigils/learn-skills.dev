Un flux de travail complet pour convertir du texte scientifique populaire en une page Web visuelle de style PPT.  
Déclenché lorsque l'utilisateur saisit du contenu scientifique et souhaite générer une page de présentation.  
Prend en charge deux modes :  
(1) Mode par défaut : convertit le contenu scientifique en une animation HTML d'une seule page qui imite un diaporama PPT ;  
(2) Mode organigramme : restructure le fichier AI_Animation.html déjà généré en un style d'interface utilisateur plat à l'aide du modèle d'animation.  
Le modèle est intégré à la compétence.  
Les expressions déclencheurs incluent « générer un PPT », « générer une page Web de présentation », « générer un organigramme », etc.
