Un flujo de trabajo completo para convertir texto de divulgación científica en una página web visual de estilo PPT.  
Se activa cuando el usuario ingresa contenido científico y desea generar una página de presentación.  
Admite dos modos:  
(1) Modo predeterminado: convierte el contenido científico en una animación HTML de una sola página que imita una presentación de diapositivas PPT;  
(2) Modo de diagrama de flujo: reestructura el AI_Animation.html ya generado en un estilo de interfaz de usuario plano utilizando la plantilla de animación.  
La plantilla está integrada en la habilidad.  
Las frases desencadenantes incluyen "generar PPT", "generar página web de presentación", "generar diagrama de flujo", etc.
