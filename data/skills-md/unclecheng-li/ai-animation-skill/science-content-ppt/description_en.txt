A complete workflow for converting popular-science text into a visual, PPT-style web page.  
Triggered when the user inputs science content and wants to generate a presentation page.  
Supports two modes:  
(1) Default mode: converts the science content into a single-page HTML animation that mimics a PPT slideshow;  
(2) Flowchart mode: restructures the already generated AI_Animation.html into a flat UI style using the Animation template.  
The template is built into the Skill.  
Trigger phrases include “generate PPT,” “generate presentation webpage,” “generate flowchart,” etc.
