Un flux de travail automatisé pour générer des animations de démonstration HTML avec l'IA. Utilisé lorsqu'un utilisateur saisit un texte de vulgarisation scientifique et souhaite créer une animation HTML de style PPT. Processus en trois étapes : 1) Générer du HTML de base ; 2) Refactoriser avec le modèle PPT ; 3) (facultatif) Refactorisez les pages dans un style d'organigramme à l'aide du modèle RNN.
