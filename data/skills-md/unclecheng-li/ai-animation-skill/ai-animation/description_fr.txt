Un flux de travail automatisé pour générer des animations de démonstration HTML à l'aide de l'IA. Utilisé lorsqu'un utilisateur saisit un texte de vulgarisation scientifique et souhaite créer une animation HTML de style PPT. Processus en trois étapes : 1) Générer le code HTML de base ; 2) Reconstruire à l'aide d'un modèle PPT ; 3) (Facultatif) Utilisez le modèle RNN pour générer une reconstruction de page de style organigramme.
