Un flujo de trabajo automatizado para generar animaciones de demostración HTML con IA. Se utiliza cuando un usuario ingresa un texto de divulgación científica y desea una animación HTML de estilo PPT. Proceso de tres pasos: 1) generar HTML base; 2) refactorizar con una plantilla PPT; 3) (opcional) refactorice con una plantilla RNN para crear páginas estilo diagrama de flujo.
