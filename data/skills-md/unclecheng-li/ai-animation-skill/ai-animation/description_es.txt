Un flujo de trabajo automatizado para generar animaciones de demostración HTML utilizando IA. Se utiliza cuando un usuario ingresa un texto de divulgación científica y desea crear una animación HTML estilo PPT. Proceso de tres pasos: 1) Generar el HTML base; 2) Reconstruir usando una plantilla PPT; 3) (Opcional) Utilice la plantilla RNN para generar una reconstrucción de página estilo diagrama de flujo.
