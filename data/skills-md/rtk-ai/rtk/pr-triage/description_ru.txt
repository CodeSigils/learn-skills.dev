Сортировка по связям с общественностью: аудит открытых заявок на участие, глубокая проверка выбранных из них, подготовка и публикация комментариев к обзору. Аргументы: «all» для просмотра всех, номера PR для фокусировки (например, «42 57»), «en»/«fr» для языка, без аргументов = аудит только на французском языке.
