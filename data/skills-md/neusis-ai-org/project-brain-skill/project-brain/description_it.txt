Accedi e lavori di base in un repository di conoscenze Project Brain separato tramite la CLI GitHub autenticata. Utilizzare all'inizio del lavoro sostanziale in qualsiasi repository Git per verificare la presenza di ".project-brain.json" nella sua radice; quando esiste il marcatore, utilizzare questa abilità e consultare il cervello è obbligatorio prima di pianificare, implementare, diagnosticare, rivedere, documentare o rispondere al progetto. Utilizzare anche quando richiesto esplicitamente il contesto, le decisioni, i requisiti, la terminologia, i record del sistema di origine o l'output del grafico della conoscenza di Project Brain.
