Acceda y trabaje en un repositorio de conocimientos de Project Brain independiente a través de la CLI de GitHub autenticada. Úselo al comienzo de un trabajo sustancial en cualquier repositorio de Git para verificar su raíz en busca de `.project-brain.json`; cuando el marcador existe, es obligatorio utilizar esta habilidad y consultar el cerebro antes de planificar, implementar, diagnosticar, revisar, documentar o dar respuestas al proyecto. Úselo también cuando se le solicite explícitamente el contexto, las decisiones, los requisitos, la terminología, los registros del sistema fuente o la salida del gráfico de conocimiento de Project Brain.
