Accès et travail de base dans un référentiel de connaissances Project Brain distinct via la CLI GitHub authentifiée. À utiliser au début d'un travail de fond dans n'importe quel référentiel Git pour vérifier sa racine pour `.project-brain.json` ; lorsque le marqueur existe, l'utilisation de cette compétence et la consultation du cerveau sont obligatoires avant la planification, la mise en œuvre, le diagnostic, la révision, la documentation ou les réponses au projet. À utiliser également lorsque le contexte, les décisions, les exigences, la terminologie, les enregistrements du système source ou la sortie du graphique de connaissances sont explicitement demandés.
