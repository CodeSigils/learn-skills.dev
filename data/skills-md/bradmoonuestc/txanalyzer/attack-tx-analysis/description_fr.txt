Analysez les transactions d'attaque blockchain de bout en bout : extrayez les artefacts (trace, code source du contrat, opcodes, mappages de sélecteur), décompilez les contrats non vérifiés via Heimdall, puis effectuez une analyse systématique des causes profondes en 6 phases avec une analyse approfondie des limites de confiance pour produire des rapports de qualité audit. À utiliser lorsque l'utilisateur fournit un hachage de transaction et demande d'analyser un exploit, une attaque, un piratage ou une transaction blockchain suspecte.
