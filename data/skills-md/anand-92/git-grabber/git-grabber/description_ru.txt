Скопируйте определенную общедоступную папку или файл GitHub в текущий рабочий каталог из общего URL-адреса дерева или большого двоичного объекта GitHub. Используйте, когда пользователь делится папкой или ссылкой на файл GitHub и просит клонировать, получить, загрузить или скопировать только этот подпуть, а не весь репозиторий.
