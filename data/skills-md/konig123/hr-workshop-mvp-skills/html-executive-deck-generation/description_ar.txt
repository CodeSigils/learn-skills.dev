مجموعة العروض التقديمية التنفيذية الموجهة المكونة من 6 خطوات من CSV/XLSX أو إدخال النص الحر إلى شرائح HTML بالإضافة إلى مطالبات النسخ واللصق لـ Gamma وKimi AI. النظام البصري الافتراضي هو لوحة المزاج DAYMARK المجمعة (كحلي / أزرق مخضر / ذهبي / عظمي). تقبل الخطوة 5 بشكل اختياري مرجع تخطيط PDF/PPTX/HTML لـ 排版 وبنية العرض فقط - لا تحل محل لون DAYMARK أو النوع أو الشعار مطلقًا. يُستخدم عند إنشاء مجموعات تنفيذية، أو عروض أداء نهاية العام، أو شرائح المسح النبضي، أو أي مجموعة شرائح يقدم فيها المستخدم البيانات كملف أو نص ويريد مخرجات HTML + Gamma + Kimi.
