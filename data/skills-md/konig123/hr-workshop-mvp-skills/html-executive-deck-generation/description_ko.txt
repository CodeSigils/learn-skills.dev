CSV/XLSX 또는 HTML 슬라이드에 대한 자유 텍스트 입력 및 Gamma 및 Kimi AI에 대한 복사-붙여넣기 프롬프트에서 안내되는 6단계 실행 프레젠테이션 데크 파이프라인. 기본 비주얼 시스템은 번들로 제공되는 DAYMARK 무드 보드(네이비/틸/골드/본)입니다. 5단계에서는 선택적으로 排版 및 전시 구조에 대해서만 PDF/PPTX/HTML 레이아웃 참조를 허용합니다. DAYMARK 색상, 유형 또는 로고를 대체하지 않습니다. 사용자가 데이터를 파일이나 텍스트로 제공하고 HTML + Gamma + Kimi 출력을 원하는 임원 데크, 연말 성과 프레젠테이션, 펄스 조사 슬라이드 또는 슬라이드 데크를 구축할 때 사용합니다.
