À utiliser lorsqu'un étudiant d'un atelier RH ne peut pas ouvrir un prototype HTML ou Next.js local, que Node.js est manquant, que npm run dev échoue, que le dossier du projet est incorrect, que localhost ne se charge pas, qu'un port est en cours d'utilisation ou que l'agent est sur le point de créer/exécuter un prototype d'atelier et doit d'abord vérifier l'ordinateur. Utilisez également pour l'aide autonome « ​​Nœud non installé » / « npm run dev 不行 » lorsque l'étudiant n'a pas démarré une compétence produit.
