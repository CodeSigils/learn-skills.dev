Verwenden Sie diese Option, wenn ein HR-Workshop-Student einen lokalen HTML- oder Next.js-Prototyp nicht öffnen kann, Node.js fehlt, npm run dev fehlschlägt, der Projektordner falsch ist, localhost nicht geladen wird, ein Port verwendet wird oder der Agent gerade einen Workshop-Prototyp erstellt/ausführt und zuerst den Computer überprüfen muss. Verwenden Sie es auch für die eigenständige Hilfe „Knoten nicht installiert“ / „npm run dev 不行“, wenn der Schüler einen Produkt-Skill nicht gestartet hat.
