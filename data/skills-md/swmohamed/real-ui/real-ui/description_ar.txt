الويب الواقعي وذكاء واجهة المستخدم/تجربة المستخدم للتطبيق الأصلي. يُستخدم عند تصميم أو إعادة تصميم أو مراجعة أو إنشاء مواقع أو تطبيقات أو صفحات أو مكونات أو أنظمة تصميم لأي صناعة أو منطقة، بما في ذلك اللغة العربية/الشرق الأوسط وشمال أفريقيا/RTL. يستمد النطاق وهندسة المعلومات والتكوين والسلوك سريع الاستجابة وتعبير النظام الأساسي والتوجيه المرئي من مهام المنتج والأدلة - وليس قوالب النوع أو جماليات الذكاء الاصطناعي العامة. يغطي الويب وiOS وAndroid وFlutter وReact Native وإمكانية الوصول والترجمة والأداء والتنفيذ.
