Запуск и сопровождение контекста проекта. Разговорный онбординг, который генерирует структурированные
context docs (.context/) и создает CLAUDE.md для проекта.
6 действий: инициализация, обновление, список дел, анализ, просмотр, создание.
Автоматически активируется: «начало», «начало начала», «обновление начала», «задание начала»,
«Анализ начального этапа», «Обзор начального этапа», «Создание начального этапа», «Начало проекта»,
«настройка проекта», «контекст проекта», «встроенный проект», «контекст настройки»,
«открытые вопросы», «задачи».
