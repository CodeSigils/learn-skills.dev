يرشد جميع قرارات التكامل الأفضل لـ i18n — اختيار SDK (Next.js، وReact، وExpo، وSwift، وFlutter، وRemix)، وسير عمل CDN vs GitHub، وإدارة الترجمة المدعومة بالذكاء الاصطناعي عبر أدوات MCP، وفحوصات صحة CLI (المسح الضوئي، والطبيب، والمزامنة)، وContent CMS (النماذج المترجمة، والإدخالات، والحقول المخصصة)، واصطلاحات تنسيق الملف (مسطحة / متداخلة / مسافة الأسماء)، وتسمية المفاتيح، وتدفقات النشر، وتحليلات الجودة. استخدمه عند إنشاء أي ميزة ترجمة أو تعديلها أو مراجعتها - بما في ذلك إعداد i18n أو إضافة اللغات أو إدارة مفاتيح الترجمة أو النشر أو دمج مسارات عمل الذكاء الاصطناعي.
