Investiga información técnica externa y web actual mediante descubrimiento, recuperación e inspección de repositorios, documentos o medios respaldados por fuentes. Utilice esta habilidad cuando el usuario necesite datos actuales, documentos, artículos, URL, repositorios, archivos PDF, videos, comparaciones o evidencia de biblioteca/API/marco específica de la versión. No utilice esta habilidad únicamente para tareas interactivas del navegador, como inicio de sesión, formularios o inspección del estado de la interfaz de usuario; utilizar una capacidad de automatización del navegador disponible.
