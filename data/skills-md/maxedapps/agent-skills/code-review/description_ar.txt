يراجع اختلافات المستودع، والعلاقات العامة، وقواعد التعليمات البرمجية، والتطبيقات المكتملة للمواد والعيوب المدعومة بالأدلة والامتثال للخطة. استخدم هذه المهارة عندما يُطلب منك المراجعة أو التدقيق أو النقد أو البحث عن مشكلات التعليمات البرمجية أو تقييم عمل الخطة المنفذة. لا تستخدم لمراجعة مسودة الخطة أو تنفيذها ما لم يتم طلب الإصلاحات بشكل صريح.
