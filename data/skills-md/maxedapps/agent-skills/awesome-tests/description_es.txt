Diseña, escribe, mejora y revisa pruebas y estrategias de prueba automatizadas centradas en el comportamiento. Utilice esta habilidad al agregar o reparar pruebas, crear planes de implementación que cambien el tiempo de ejecución o el comportamiento de la aplicación y deban especificar pruebas o validación, evaluar el código de prueba o la calidad de la cobertura, diagnosticar pruebas inestables, frágiles o de falso verde, o realizar revisiones de código que afecten materialmente a las pruebas o la validación. No lo use para implementaciones de producción no relacionadas, planes o revisiones sin trabajo de prueba o validación, ejecutando solo un comando de prueba sin cambios, control de calidad exploratorio manual solo o explicaciones de pruebas conceptuales sin un objetivo concreto.
