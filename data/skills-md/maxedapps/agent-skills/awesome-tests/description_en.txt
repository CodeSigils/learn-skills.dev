Designs, writes, improves, and reviews behavior-focused automated tests and test strategies. Use this skill when adding or repairing tests, creating implementation plans that change runtime or application behavior and must specify tests or validation, assessing test code or coverage quality, diagnosing flaky, brittle, fragile, or false-green tests, or conducting code reviews that materially touch tests or validation. Do not use for unrelated production implementation, plans or reviews with no testing or validation work, running an unchanged test command only, manual exploratory QA alone, or conceptual testing explanations without a concrete target.
