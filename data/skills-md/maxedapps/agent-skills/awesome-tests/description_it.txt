Progetta, scrive, migliora e rivede test automatizzati e strategie di test incentrati sul comportamento. Utilizzare questa competenza quando si aggiungono o riparano test, si creano piani di implementazione che modificano il comportamento di runtime o dell'applicazione e si devono specificare test o convalida, si valuta il codice di test o la qualità della copertura, si diagnosticano test instabili, fragili, fragili o falsi verdi o si conducono revisioni del codice che toccano materialmente test o convalida. Non utilizzare per implementazioni di produzione, piani o revisioni non correlati senza attività di test o convalida, eseguendo solo un comando di test invariato, solo QA esplorativo manuale o spiegazioni di test concettuali senza un obiettivo concreto.
