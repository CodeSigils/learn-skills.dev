Genera imágenes de IA a través de flujos de trabajo de cola HTTP fal.ai desde una CLI de Bun. Utilice esta habilidad cuando una tarea necesite generación de imágenes de IA, inspección de esquemas, carga de imágenes o sondeo de colas a través de fal.ai. No lo utilice para flujos de trabajo de vídeo, audio, 3D o sin imágenes.
