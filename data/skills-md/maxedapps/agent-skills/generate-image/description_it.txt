Genera immagini AI tramite flussi di lavoro della coda HTTP fal.ai da una CLI di Bun. Utilizza questa competenza quando un'attività richiede la generazione di immagini AI, l'ispezione dello schema, il caricamento di immagini o il polling delle code tramite fal.ai. Non utilizzare per flussi di lavoro video, audio, 3D o non basati su immagini.
