Génère des images IA via les workflows de file d'attente HTTP fal.ai à partir d'une CLI Bun. Utilisez cette compétence lorsqu'une tâche nécessite la génération d'images IA, l'inspection de schéma, le téléchargement d'images ou l'interrogation de file d'attente via fal.ai. Ne pas utiliser pour des flux de travail vidéo, audio, 3D ou sans image.
