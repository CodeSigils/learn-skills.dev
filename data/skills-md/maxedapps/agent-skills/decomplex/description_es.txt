Revisa el trabajo propuesto o existente para detectar complejidad innecesaria y clasifica las recomendaciones que aumentan la complejidad sin editar los objetivos revisados. Utilice esta habilidad cuando se le solicite simplificar o descomplejar fuentes, pruebas, configuración, dependencias, planes, diseños o arquitectura; desafiar el exceso de ingeniería; auditar complejidad innecesaria; o recomendaciones de triaje que agregarían complejidad. No lo utilice para revisión general de defectos, implementación o correcciones, limpieza de solo estilo o explicaciones conceptuales que no necesitan un informe de revisión duradero.
