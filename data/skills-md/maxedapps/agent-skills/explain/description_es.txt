Ejecuta un flujo de trabajo de explicación iniciado manualmente que produce Markdown conciso y basado en evidencia y HTML independiente para código, sistemas, relaciones de datos y planes, revisiones o declaraciones de agentes anteriores. Utilice esta habilidad cuando, y sólo cuando, el usuario invoque explícitamente explicar por nombre. No lo utilice para preguntas y respuestas ordinarias, implementación o correcciones, ni para realizar una nueva revisión de código, creación de diapositivas, documentación exhaustiva o conversión de solo renderizado de Markdown suministrado.
