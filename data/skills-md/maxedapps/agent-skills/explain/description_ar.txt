يقوم بتشغيل سير عمل شرح يتم بدؤه يدويًا وينتج Markdown موجزًا ​​ومرتكزًا على الأدلة وHTML مستقل للتعليمات البرمجية والأنظمة وعلاقات البيانات والخطط السابقة أو المراجعات أو بيانات الوكيل. استخدم هذه المهارة فقط عندما يقوم المستخدم باستدعاء الشرح بالاسم بشكل صريح. لا تستخدم للأسئلة والأجوبة العادية، أو التنفيذ أو الإصلاحات، أو إجراء مراجعة جديدة للتعليمات البرمجية، أو إنشاء شرائح، أو وثائق شاملة، أو تحويل العرض فقط لـ Markdown المتوفر.
