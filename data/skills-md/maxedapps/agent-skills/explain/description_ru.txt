Запускает инициируемый вручную рабочий процесс объяснения, который создает краткую, обоснованную Markdown и отдельный HTML-код для кода, систем, связей данных, а также предыдущих планов, обзоров или заявлений агента. Используйте этот навык тогда и только тогда, когда пользователь явно вызывает объяснение по имени. Не используйте для обычных вопросов и ответов, реализации или исправлений, выполнения новой проверки кода, создания слайдов, исчерпывающей документации или преобразования предоставленного Markdown только для рендеринга.
