Manual de estrategias portátil para la delegación local de subagentes en cualquier arnés de agente de codificación. Utilice esta habilidad siempre que considere delegación, descomposición, investigación paralela, revisión o implementación, validación independiente o una solicitud explícita para generar o administrar subagentes. Funciona con las herramientas integradas del subagente, extensiones/complementos o una CLI de agente seguro. No lo utilice para trabajos ordinarios de proceso, servidor o shell en segundo plano.
