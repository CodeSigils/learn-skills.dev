Crea, revisa y mejora planes de implementación lean a través de investigación orquestada, síntesis respaldada por evidencia y cierre de revisión iterativa independiente. Utilice esta habilidad cuando el usuario solicite planificar una característica o un cambio, crear una transferencia de implementación o revisar o mejorar un plan no implementado antes de codificar. No lo utilice para implementar un plan, auditar la implementación completa en comparación con un plan o responder una pequeña pregunta conceptual que no necesita transferencia de implementación.
