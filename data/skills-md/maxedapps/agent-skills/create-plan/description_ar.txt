إنشاء خطط تنفيذ بسيطة ومراجعتها وتحسينها من خلال البحث المنسق والتوليف المدعوم بالأدلة وإغلاق المراجعة المستقلة المتكررة. استخدم هذه المهارة عندما يطلب المستخدم التخطيط لميزة أو تغيير، أو إنشاء عملية تسليم تنفيذ، أو مراجعة خطة غير منفذة أو تحسينها قبل البرمجة. لا تستخدم لتنفيذ خطة، أو تدقيق التنفيذ المكتمل مقابل خطة، أو الإجابة على سؤال مفاهيمي صغير لا يحتاج إلى تسليم التنفيذ.
