Создает, переписывает, проверяет и подкрепляет доказательствами улучшение навыков агента, которые являются краткими, недвусмысленными, постепенно раскрываемыми и пригодными для действий агента. Используйте этот навык при создании или редактировании SKILL.md, его описания маршрутизации, ссылок, ресурсов, сценариев или многократно используемых руководств по рабочему процессу. Не используйте для установки сторонних навыков или одноразовых настроек без возможности повторного использования.
