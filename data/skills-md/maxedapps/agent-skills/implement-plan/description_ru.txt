Полностью реализует существующие планы Markdown посредством делегированных циклов задач, проверки и закрытия проверки. Используйте этот навык, когда вас просят реализовать, выполнить или продолжить существующий план. Не используйте для создания плана с нуля или только для просмотра плана без его реализации.
