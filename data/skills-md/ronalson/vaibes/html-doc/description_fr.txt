Créez un document HTML raffiné dans un seul fichier pour les spécifications, les articles, les résultats, les résumés, les rapports, les comparaisons et les visualisations explicatives. À utiliser chaque fois que l'utilisateur demande explicitement un document HTML, un rapport HTML ou un livrable enregistré au format .html. Ne pas utiliser pour les sites Web, les applications Web, les pages de destination, les composants d'interface utilisateur réutilisables, les extraits HTML, les DOCX, les PDF ou les présentations de diapositives.
