Cree un documento HTML pulido de un solo archivo para especificaciones, reseñas, hallazgos, resúmenes, informes, comparaciones y visualizaciones explicativas. Úselo siempre que el usuario solicite explícitamente un documento HTML, un informe HTML o un entregable guardado como .html. No lo utilice para sitios web, aplicaciones web, páginas de destino, componentes de interfaz de usuario reutilizables, fragmentos de HTML, DOCX, PDF o presentaciones de diapositivas.
