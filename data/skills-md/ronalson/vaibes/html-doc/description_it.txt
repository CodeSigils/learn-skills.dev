Crea un documento HTML raffinato a file singolo per specifiche, commenti, risultati, riepiloghi, report, confronti e visualizzazioni esplicative. Da utilizzare ogni volta che l'utente richiede esplicitamente un documento HTML, un report HTML o un risultato finale salvato come .html. Non utilizzare per siti Web, app Web, pagine di destinazione, componenti dell'interfaccia utente riutilizzabili, snippet HTML, DOCX, PDF o presentazioni di diapositive.
