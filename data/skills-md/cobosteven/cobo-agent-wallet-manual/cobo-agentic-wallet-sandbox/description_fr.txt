Créez et gérez des portefeuilles agents avec Cobo. Utilisation pour une chaîne autonome
opérations via la CLI caw : transferts de tokens, appels de contrats, création de pactes
et approbation, exécution DeFi (Uniswap, Aave, Jupiter) et intégration du portefeuille
sur les chaînes EVM et Solana. Se déclenche sur les requêtes impliquant Caw, le portefeuille MPC,
Nœud TSS, portefeuille d'agent, Cobo, pacte ou toute opération de portefeuille crypto
pour les agents IA. PAS pour les paiements fiduciaires ou les virements bancaires.
