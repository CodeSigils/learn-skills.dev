قم بتقييم جودة وكيل CAW (Cobo Agentic Wallet) في Claude Code المحلي، وإنشاء بيانات النتيجة وتقرير التحليل.  
يُستخدم عندما: يريد المستخدم تشغيل تقييم CAW، وتشغيل التقييم، واختبار المهارة، وتقييم جودة الوكيل،  
إنشاء تقرير تقييم، أو يقول "跑评测"، "测评 CAW"، "eval"، "评分".  
لتقييم النموذج الضعيف / openclaw، يرجى استخدام caw-eval-openclaw (مثبت فقط على خادم openclaw).
