Évaluez la qualité de l'agent CAW (Cobo Agentic Wallet) dans le code Claude local, en générant des données de score et un rapport d'analyse.  
À utiliser lorsque : l'utilisateur souhaite exécuter une évaluation CAW, exécuter une évaluation, tester des compétences, évaluer la qualité de l'agent,  
générer un rapport d'évaluation, ou dit "跑评测", "测评 CAW", "eval", "评分".  
Pour une évaluation de modèle faible/openclaw, veuillez utiliser caw-eval-openclaw (installé uniquement sur le serveur openclaw).
