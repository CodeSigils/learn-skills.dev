Bewerten Sie die Agentenqualität von CAW (Cobo Agentic Wallet) im lokalen Claude Code und erstellen Sie Bewertungsdaten und einen Analysebericht.  
Verwenden Sie diese Option, wenn: der Benutzer eine CAW-Bewertung durchführen, eine Bewertung ausführen, seine Fähigkeiten testen oder die Agentenqualität bewerten möchte.  
Bewertungsbericht erstellen oder „跑评测“, „测评 CAW“, „eval“, „评分“ sagen.  
Für eine schwache Modell-/Openclaw-Bewertung verwenden Sie bitte caw-eval-openclaw (nur auf Openclaw-Server installiert).
