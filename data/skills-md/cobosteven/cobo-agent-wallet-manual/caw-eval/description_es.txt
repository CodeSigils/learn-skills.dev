Evalúe la calidad del agente CAW (Cobo Agentic Wallet) en Claude Code local, generando datos de puntuación e informe de análisis.  
Úselo cuando: el usuario desee ejecutar la evaluación CAW, ejecutar la evaluación, probar la habilidad, evaluar la calidad del agente,  
generar informe de evaluación, o dice "跑评测", "测评 CAW", "eval", "评分".  
Para una evaluación de modelo débil/openclaw, utilice caw-eval-openclaw (instalado solo en el servidor openclaw).
