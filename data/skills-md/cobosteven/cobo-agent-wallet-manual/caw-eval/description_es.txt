Evalúe la calidad del agente CAW (Cobo Agentic Wallet) en Claude Code local, genere datos de puntuación y un informe de análisis.  
Úselo cuando: el usuario desea ejecutar la evaluación CAW, ejecutar la evaluación, probar la habilidad, evaluar la calidad del agente, generar el informe de evaluación o dice "ejecutar la evaluación", "evaluar CAW", "evaluar", "puntuar".  
Para la evaluación de modelo débil/openclaw, utilice caw-eval-openclaw (instalado solo en el servidor openclaw).
