Applicare quando si decide, si progetta o si implementano le personalizzazioni dei temi FastStore in src/themes/ o si lavora con token di progettazione e variabili SCSS. Copre token globali, token di componenti locali, variabili Sass, proprietà personalizzate CSS e architettura Brandless. Utilizzare per qualsiasi personalizzazione visiva delle vetrine FastStore che non richiede la sostituzione dei componenti.
