Aplicar al diseñar o implementar cómo una aplicación backend VTEX IO se integra con servicios VTEX o API externas a través de @vtex/api y @vtex/clients. Cubre la elección del tipo de cliente correcto, el registro de clientes en IOClients, la configuración de InstanceOptions y el consumo de integraciones a través de ctx.clients. Úselo para diseño de cliente personalizado, integraciones de VTEX Core Commerce o revisión de código backend que debe usar patrones de cliente VTEX IO en lugar de bibliotecas HTTP sin formato.
