Применяйте при проектировании или реализации интеграции внутреннего приложения ввода-вывода VTEX со службами VTEX или внешними API через @vtex/api и @vtex/clients. Охватывает выбор правильного типа клиента, регистрацию клиентов в IOClients, настройку InstanceOptions и использование интеграций через ctx.clients. Используйте для индивидуального проектирования клиентов, интеграции VTEX Core Commerce или проверки внутреннего кода, который должен использовать шаблоны клиентов VTEX IO вместо необработанных библиотек HTTP.
