Aplicar al implementar lógica de reintento, manejo de límites de velocidad o patrones de resiliencia en integraciones API de VTEX. Cubre encabezados de límite de velocidad de VTEX (X-RateLimit-Remaining, X-RateLimit-Reset, Retry-After), manejo de estado 429, retroceso exponencial con jitter, patrones de disyuntores y colas de solicitudes. Úselo para cualquier integración del mercado VTEX que deba manejar correctamente la limitación de API y mantener una alta disponibilidad.
