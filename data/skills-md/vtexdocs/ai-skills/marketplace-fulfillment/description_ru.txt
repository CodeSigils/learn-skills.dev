Применяется при реализации логики выполнения, выставления счетов или отслеживания для коннекторов продавцов торговой площадки VTEX. Охватывает API уведомления о счетах-фактурах заказа, структуру полезных данных счета-фактуры, обновления отслеживания, частичное выставление счетов за разделенные поставки и поток авторизации выполнения. Используется для создания системы выполнения заказов на стороне продавца, которая интегрируется с управлением заказами на торговой площадке VTEX, включая тайм-аут моделирования 2,5 с.
