Appliquez-le lors du contrôle de l'accès aux ressources de l'application VTEX IO à l'aide de politiques basées sur les rôles ou les ressources. Couvre les politiques.json pour le contrôle d'accès basé sur les rôles, les politiques service.json pour l'accès basé sur les ressources, la syntaxe VRN pour les principaux, la différence entre l'accès d'application à application et l'accès utilisateur/intégration, et les directives GraphQL @auth. À utiliser pour décider comment sécuriser les itinéraires et restreindre les applications, utilisateurs ou intégrations pouvant accéder à vos points de terminaison.
