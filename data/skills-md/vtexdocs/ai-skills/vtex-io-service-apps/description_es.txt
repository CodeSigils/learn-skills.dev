Aplicar al crear aplicaciones de servicios backend bajo nodo/ en un proyecto VTEX IO o configurar rutas service.json. Cubre la clase de servicio, las funciones de middleware, el patrón ctx.clients, el registro de JanusClient, ExternalClient, MasterDataClient y IOClients. Úselo para implementar API de backend, controladores de eventos o integraciones que deben usar clientes @vtex/api en lugar de bibliotecas HTTP sin formato.
