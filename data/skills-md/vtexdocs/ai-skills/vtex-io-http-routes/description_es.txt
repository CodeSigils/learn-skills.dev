Aplicar al diseñar o implementar endpoints HTTP expuestos por un servicio backend de VTEX IO. Cubre los límites de las rutas, la estructura del controlador, la composición del middleware, la validación de solicitudes y el modelado de respuestas para rutas service.json. Úselo para endpoints de webhook, integraciones de socios, API de devolución de llamada o revisión de controladores de IO de VTEX que deben exponer contratos HTTP explícitos.
