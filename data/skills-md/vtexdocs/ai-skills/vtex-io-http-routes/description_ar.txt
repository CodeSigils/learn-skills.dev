يتم تطبيقه عند تصميم أو تنفيذ نقاط نهاية HTTP المكشوفة بواسطة خدمة الواجهة الخلفية VTEX IO. يغطي حدود المسار، وبنية المعالج، وتكوين البرامج الوسيطة، والتحقق من صحة الطلب، ونمذجة الاستجابة لمسارات Service.json. يُستخدم لنقاط نهاية خطاف الويب أو عمليات تكامل الشركاء أو واجهات برمجة تطبيقات رد الاتصال أو مراجعة معالجات VTEX IO التي يجب أن تعرض عقود HTTP الصريحة.
