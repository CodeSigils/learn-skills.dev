يتم تطبيقه عند إنشاء واجهات React التي تواجه المشرف VTEX IO ضمن منشئ المشرف. يغطي استخدام VTEX Styleguide وShoreline، وتكوين صفحة المسؤول، وتفاعلات المسؤول كثيفة البيانات، والحفاظ على الواجهات الإدارية المتوافقة مع بيئة VTEX Admin. يُستخدم لصفحات الإعدادات أو أدوات الإشراف أو لوحات المعلومات أو واجهات المستخدم التشغيلية داخل VTEX Admin.
