Aplicar cuando se manejan datos de tarjetas de crédito, se implementan flujos de SecureProxyUrl o se trabaja con seguridad de pago y código proxy. Cubre el cumplimiento de PCI DSS, la tokenización de tarjetas Secure Proxy, las reglas de manejo de datos confidenciales, el uso del encabezado X-PROVIDER-Forward-To y la creación de tokens personalizados. Úselo para cualquier conector de pago que procese pagos con tarjeta de crédito, débito o de marca compartida para evitar filtraciones de datos e infracciones de PCI.
