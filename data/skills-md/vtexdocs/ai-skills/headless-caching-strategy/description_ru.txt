Применяется при реализации логики кэширования, конфигурации CDN или оптимизации производительности для автономной витрины VTEX. Описывает, какие API VTEX можно кэшировать (интеллектуальный поиск, каталог), а какие никогда не следует кэшировать (оформление заказа, профиль, OMS), устаревшие шаблоны при повторной проверке, аннулирование кэша и кэширование на уровне BFF. Используйте для любого автономного проекта, которому требуются правила TTL и рекомендации по стратегии кэширования.
