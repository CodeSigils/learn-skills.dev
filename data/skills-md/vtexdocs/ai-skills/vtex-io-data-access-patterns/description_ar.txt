قم بالتطبيق عند تحديد مكان وكيفية قيام تطبيق VTEX IO بتخزين البيانات وقراءتها. يغطي متى يتم استخدام إعدادات التطبيق، أو تطبيقات التكوين، أو البيانات الرئيسية، أو VBase، أو واجهات برمجة تطبيقات VTEX الأساسية، أو المتاجر الخارجية، وكيفية تجنب تكرار مصادر الحقيقة أو إساءة استخدام مخازن التكوين للبيانات التشغيلية. يُستخدم لتدفقات البيانات الجديدة أو قرارات التخزين المؤقت أو إعادة البناء أو مراجعة أنماط التخزين والوصول المشبوهة في تطبيقات VTEX IO.
