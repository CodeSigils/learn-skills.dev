يتم تطبيقه عند إنشاء مكونات واجهة متجر VTEX IO ضمن التفاعل/ لتجارب Store Framework. يغطي بنية مكون واجهة المتجر، ومقابض CSS، وخطافات سياق واجهة المتجر، وجلب البيانات الآمنة للمتصفح، وكيف يجب أن تتصرف المكونات عند استخدامها ككتل سمات. يُستخدم لواجهة المستخدم المخصصة لواجهة المتجر، أو عناصر واجهة المستخدم للمنتج، أو اللافتات، أو النماذج، أو مراجعة كود React الذي يواجه المتسوقين في تطبيقات VTEX IO.
