Applicare quando si implementa un connettore PPP (Payment Provider Protocol) VTEX o si lavora con file endpoint di pagamento/connettore. Copre tutti i nove endpoint richiesti: Manifesta, Crea pagamento, Annulla, Acquisisci/Paga, Rimborso, Richiesta in entrata, Crea token di autenticazione, Reindirizzamento autenticazione fornitore e Ottieni credenziali. Utilizzare per creare o eseguire il debug di qualsiasi connettore di pagamento che si integra con VTEX Payment Gateway.
