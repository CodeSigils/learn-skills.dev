Appliquez-le lorsque vous travaillez avec des entités, des schémas ou MasterDataClient MasterData v2 dans les applications VTEX IO. Couvre les entités de données, les définitions de schéma JSON, les opérations CRUD, le générateur de données principales, les déclencheurs, les opérations de recherche et de défilement et la gestion du cycle de vie des schémas. À utiliser pour stocker, interroger et gérer des données personnalisées dans les applications VTEX IO tout en évitant la limite de 60 schémas grâce à une gestion des versions de schéma appropriée.
