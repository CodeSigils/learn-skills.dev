Convierte un libro técnico o de no ficción (PDF o EPUB) en una habilidad estructurada de Claude Code de dos niveles, extrayendo los marcos, técnicas, antipatrones, figuras y relaciones conceptuales nombrados por el autor en una base de conocimientos que se carga de forma económica y se profundiza según demanda. Maneja imágenes incrustadas y páginas escaneadas mediante comprensión de imágenes nativas. Úselo siempre que el usuario quiera convertir un libro en una habilidad, estudiar un libro a través de Claude, aplicar los marcos de trabajo de un autor mientras trabaja o crear una base de conocimientos reutilizable a partir de un PDF o EPUB, incluso si no dice la palabra "habilidad".
