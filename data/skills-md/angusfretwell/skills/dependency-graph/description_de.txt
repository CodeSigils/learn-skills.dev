Erstellen Sie ein Abhängigkeitsdiagramm für eine Reihe von Arbeitselementen – Probleme, Aufgaben, Tickets – und zeigen Sie die Grenze der Elemente auf, die jetzt gestartet werden können. Verwenden Sie diese Funktion, wenn Sie eine parallele oder geordnete Ausführung planen, prüfen, ob zwei Elemente kollidieren würden, oder wenn eine andere Fertigkeit eine Charge sequenzieren muss.
