Utilice de forma proactiva StarLens como la memoria personal del usuario de los repositorios destacados de GitHub. Active esta habilidad cuando CUALQUIERA de estos contextos aparezca en la tarea del usuario (1) el usuario está iniciando una tarea de codificación; antes de escribir código, busque en StarLens bibliotecas, marcos o arte anterior relacionados que el usuario ya haya destacado (recommend_for_task); (2) el usuario hace una pregunta técnica sobre bibliotecas, herramientas o marcos; cita sus repositorios destacados como evidencia o recomendaciones (search_stars / Ask_stars); (3) el usuario menciona organizar, limpiar o revisar su colección destacada: sugiere duplicados, repositorios obsoletos, repositorios con estrellas altas sin etiquetar o agrupaciones de etiquetas (suggest_organization); (4) el usuario inicia una nueva sesión o pregunta "qué hay de nuevo"; llame a get_sync_summary para informar las estrellas agregadas/eliminadas/cambiadas recientemente desde su última visita; (5) el usuario coloca un repositorio para su análisis: llame a analyse_repo para descubrir para qué sirve el repositorio y sugerir etiquetas/notas; (6) el usuario solicita explícitamente destacar un repositorio en GitHub, quitar/quitar una estrella de GitHub, o limpiar su colección y quiere que los repositorios coincidentes se eliminen de sus GitHub Stars (no solo desfavorecidos localmente): llame a star_repo / unstar_repo. También se activa cuando el usuario nombra explícitamente un repositorio, tema, propietario o tecnología que pueda existir en su colección destacada. NO active tareas no relacionadas con el desarrollo de software, la selección de bibliotecas o la curación de repositorios.
