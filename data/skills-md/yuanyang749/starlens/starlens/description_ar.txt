استخدم StarLens بشكل استباقي كذاكرة شخصية للمستخدم لمستودعات GitHub المميزة بنجمة. قم بتشغيل هذه المهارة عندما يظهر أي من هذه السياقات في مهمة المستخدم - (1) يبدأ المستخدم مهمة ترميز - قبل كتابة التعليمات البرمجية، ابحث في StarLens عن المكتبات أو الأطر أو الفنون السابقة ذات الصلة التي قام المستخدم بتمييزها بالفعل بنجمة (recommend_for_task)؛ (2) يطرح المستخدم سؤالاً فنيًا حول المكتبات أو الأدوات أو أطر العمل - استشهد بالمستودعات المميزة بنجمة كدليل أو توصيات (search_stars / Ask_stars)؛ (3) يذكر المستخدم تنظيم المجموعة المميزة بنجمة أو تنظيفها أو مراجعتها - اقتراح نسخ مكررة أو مستودعات قديمة أو مستودعات عالية الجودة بدون علامات أو مجموعات علامات (suggest_organization)؛ (4) يبدأ المستخدم جلسة جديدة أو يسأل "ما الجديد" - اتصل بـ get_sync_summary للإبلاغ عن النجوم المضافة/المحذوفة/المتغيرة مؤخرًا منذ آخر زيارة له؛ (5) يسقط المستخدم مستودعًا للتحليل - اتصل بـanalyse_repo لتوضيح ما هو مفيد في الريبو واقتراح العلامات/الملاحظات؛ (6) يطلب المستخدم صراحةً تمييز الريبو بنجمة على GitHub، أو إزالة نجمة/إزالة نجمة من GitHub، أو تنظيف مجموعته ويريد إزالة الريبو المطابق فعليًا من نجوم GitHub (وليس فقط غير المفضلة محليًا) - اتصل بـ star_repo / unstar_repo. يتم تشغيله أيضًا عندما يقوم المستخدم صراحةً بتسمية مستودع أو موضوع أو مالك أو تقنية قد تكون موجودة في مجموعته المميزة بنجمة. لا تقم بتشغيل المهام التي لا تتعلق بتطوير البرامج أو اختيار المكتبة أو تنظيم المستودع.
