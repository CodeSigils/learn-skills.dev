Utilizza in modo proattivo StarLens come memoria personale dell'utente dei repository speciali di GitHub. Attiva questa abilità quando QUALSIASI di questi contesti appare nell'attività dell'utente — (1) l'utente sta avviando un'attività di codifica — prima di scrivere il codice, cerca in StarLens le librerie, i framework o la tecnica precedente correlati a cui l'utente ha già aggiunto la stella (recommend_for_task); (2) l'utente pone una domanda tecnica su librerie, strumenti o framework: cita i repository contrassegnati come prove o raccomandazioni (search_stars / ask_stars); (3) l'utente menziona l'organizzazione, la pulizia o la revisione della propria raccolta contrassegnata con stelle: suggerisce duplicati, repository obsoleti, repository high-star senza tag o raggruppamenti di tag (suggest_organization); (4) l'utente avvia una nuova sessione o chiede "cosa c'è di nuovo" - chiama get_sync_summary per segnalare le stelle aggiunte/rimosse/modificate di recente dall'ultima visita; (5) l'utente rilascia un repository per l'analisi: chiama analyze_repo per far emergere a cosa serve il repository e suggerire tag/note; (6) l'utente chiede esplicitamente di aggiungere a Speciali un repository su GitHub, rimuovere da Speciali/rimuovere una Speciale da GitHub o ripulire la propria raccolta e desidera che i repository corrispondenti vengano effettivamente rimossi dalle proprie Stelle GitHub (non solo non preferiti localmente) — chiamare star_repo / unstar_repo. Si attiva anche quando l'utente nomina esplicitamente un repository, un argomento, un proprietario o una tecnologia che potrebbe esistere nella sua raccolta speciale. NON attivare attività non correlate allo sviluppo del software, alla selezione delle librerie o alla cura del repository.
