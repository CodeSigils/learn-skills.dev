主動使用StarLens作為使用者對GitHub加星標儲存庫的個人記憶。當任何這些上下文出現在使用者的任務中時觸發此技能 - (1) 使用者正在開始編碼任務 - 在編寫程式碼之前，在 StarLens 中搜尋相關函式庫、框架或使用者已加星號的現有技術 (recommend_for_task)； (2) 使用者詢問有關庫、工具或框架的技術問題 - 引用他們加星號建議的儲存庫作為證據或建議的技術問題。使用者提到組織、清理或審查他們的加星標集合——建議重複項、過時的存儲庫、未標記的高星存儲庫或標籤分組 (suggest_organization)； (4) 用戶開始一個新會話或詢問“有什麼新內容”——調用 get_sync_summary 報告自上次訪問以來最近添加/刪除/更改的星星；使用者刪除儲存庫進行分析 – 呼叫analyze_repo來顯示該儲存庫的優點並建議標籤/註解； (6) 使用者明確要求在 GitHub 上為某個儲存庫加註星標，從 GitHub 取消星標/刪除星標，或清理其集合並希望將匹配的儲存庫實際從其 GitHub 星標/刪除星標，或清理其集合並希望將匹配的儲存庫實際從其 GitHub 星標/不可以在本地調用中刪除。當使用者明確命名其加星標集合中可能存在的儲存庫、主題、擁有者或技術時也會觸發。不要觸發與軟體開發、庫選擇或儲存庫管理無關的任務。
