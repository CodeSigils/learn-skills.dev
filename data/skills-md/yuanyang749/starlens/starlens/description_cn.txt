主动使用StarLens作为用户对GitHub加星标存储库的个人记忆。当任何这些上下文出现在用户的任务中时触发此技能 - (1) 用户正在开始编码任务 - 在编写代码之前，在 StarLens 中搜索相关库、框架或用户已经加星标的现有技术 (recommend_for_task)； (2) 用户询问有关库、工具或框架的技术问题 - 引用他们加星标的存储库作为证据或建议 (search_stars/ask_stars)； (3) 用户提到组织、清理或审查他们的加星标集合——建议重复项、过时的存储库、未标记的高星存储库或标签分组 (suggest_organization)； (4) 用户开始一个新会话或询问“有什么新内容”——调用 get_sync_summary 报告自上次访问以来最近添加/删除/更改的星星； (5) 用户删除一个存储库进行分析——调用analyze_repo来显示该存储库的优点并建议标签/注释； (6) 用户明确要求在 GitHub 上为某个存储库加注星标，从 GitHub 取消星标/删除星标，或者清理其集合并希望将匹配的存储库实际从其 GitHub 星标中删除（而不仅仅是在本地不喜欢）——调用 star_repo / unstar_repo。当用户明确命名其加星标集合中可能存在的存储库、主题、所有者或技术时也会触发。不要触发与软件开发、库选择或存储库管理无关的任务。
