أفضل الممارسات والأنماط والأمثلة العملية لبناء التطبيقات باستخدام Arkiv - قاعدة بيانات إيثريوم لا مركزية مع مساحة تخزين قابلة للاستعلام ومحددة النطاق. استخدم هذه المهارة عندما يعمل المستخدم مع Arkiv SDK، أو حزمة @arkiv-network/sdk، أو كيانات Arkiv، أو استعلامات Arkiv، أو سمات Arkiv، أو ExpiresIn/expiration، أو Braga testnet، أو إنشاء أي تطبيق يخزن البيانات أو يستعلم عنها أو يديرها على شبكة Arkiv. يُستخدم أيضًا عندما يذكر المستخدم تخزين البيانات اللامركزي على Ethereum، أو قاعدة بيانات blockchain، أو تخزين بيانات Web3، أو البيانات الموجودة على السلسلة، أو عمليات الكيان CRUD مع انتهاء الصلاحية، أو arkiv_query، أو ترحيل مشروع Arkiv من Kaolin إلى Braga.
