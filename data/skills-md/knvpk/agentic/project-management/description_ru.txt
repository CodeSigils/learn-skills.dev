Навыки управления проектами независимо от поставщика. Управляет локальной документацией проекта (docs/prd.md, docs/architecture.md, docs/database.md, docs/tools.md) и подключается к любому поддерживаемому средству отслеживания проблем (GitHub, GitLab, Jira, Plane) через MCP. Десять режимов: init (настройка поставщика, возможности плана проверки), docs (подготовка и редактирование документации проекта; предлагает docker-modular-stack для зависимостей Docker), массовый (создание полного невыполненного журнала из docs/ — читает все файлы документации, создает типизированный манифест билета, упорядоченный по зависимостям, выполняет дедупликацию по существующим билетам, человеческая проверка затем создает за один проход), Ticket (создает обширные готовые для opsx краткие описания заявок с требованиями, сценариями BDD, вариантами использования; CRUD; все типы отношений; интеллектуальное обнаружение ширины области предлагает разбивку на несколько заявок, когда входные данные охватывают широкую область), спринт (управление спринтами/вехами/циклами и метками; гибкие церемонии: планирование, просмотр, ретроспективный подход, закрытие), следующий (алгоритмическая ежедневная рекомендация по билетам на основе графика зависимостей и приоритета), старт (вызов конкретного билета по идентификатору, обогащение контекстом документа проекта, состояние перехода с проверкой лимита незавершенного производства, создание ветки, вызов opsx:explore), статус (доска спринта с сигналом о работоспособности и выгоранием, сгруппированная по каноническому состоянию), стендап (ежедневный стендап: что я сделал / что дальше / блокировщики), отставание (уточнение неоцененных заявок с помощью проверки DoR и подсказок по сюжетным точкам). Ворота качества: определение принудительного выполнения «Готово» при закрытии заявки, принудительное применение лимита незавершенного производства для незавершенных переходов. Контекст для заявок фильтруется по релевантности из документов и возвращается к локальным файлам репозитория или настроенным родственным репозиториям.
