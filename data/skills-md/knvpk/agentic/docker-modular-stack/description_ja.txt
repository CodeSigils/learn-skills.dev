あらゆるプロジェクトの Docker サービスを定義、スキャフォールディング、lint します。 3 つのモード: (1) Scaffold — 厳選されたテンプレート (postgres、valkey、grafana、langfuse、litellm、30 以上) を、生成された docker-compose.yaml、.env、および Taskfile を含む新しいプロジェクトにコピーします。 (2) 追加 — ツールのドキュメントを参照して、準拠する service.yaml を最初から派生します。 (3) Lint — プロジェクトの規約に照らしてサービス定義を検証します。 Docker スタックをセットアップする場合、ドキュメントから新しい Docker サービスを追加する場合、またはサービス定義が正しいかどうかを確認する場合に使用します。
