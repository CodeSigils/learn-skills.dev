جلب عنصر عمل من GitLab أو GitHub أو Jira أو Plane (يتم اكتشافه تلقائيًا من التنسيق المرجعي أو عنوان URL) وبدء تشغيل opsx:explore مع تحميل سياق المشكلة وسياق مستودع التعليمات البرمجية مسبقًا. يُستخدم عندما يذكر المستخدم رقم التذكرة أو مفتاح الإصدار أو عنوان URL للإصدار ويريد استكشاف التنفيذ قبل بدء التغيير. يعمل بشكل صحيح عندما يكون متتبع المشكلات ومضيف الكود نظامين مختلفين (على سبيل المثال، مشكلات Jira + كود GitLab).
