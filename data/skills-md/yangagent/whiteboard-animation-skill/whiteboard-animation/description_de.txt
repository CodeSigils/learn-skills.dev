Erstellen Sie handgezeichnete Animationsvideos auf dem Whiteboard aus Bildern. Wandeln Sie jedes Farbbild in eine Animation um, die eine Strichzeichnungsphase und eine Farbphase mit einem Handüberlagerungseffekt umfasst, und geben Sie ein H.264 MP4-Video aus. Unterstützt sowohl Einzelbild- als auch Stapelmodi. Wird ausgelöst, wenn der Benutzer sagt: „Bild in eine Whiteboard-Animation umwandeln“, „Whiteboard-Animation“ oder „Batch-Whiteboard-Animation“.
