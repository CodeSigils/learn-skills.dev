Генерируйте звук китайской речи из текстового файла с помощью MiniMax TTS API, автоматически обрабатывая частые ошибки произношения, такие как полифонические символы, английские сокращения, смешанные названия моделей и чтение чисел. Это срабатывает, когда пользователь говорит: «Сгенерируйте речевой звук с помощью MiniMax».
