Auditez les applications mobiles iOS et Android par rapport à OWASP MASVS / MASTG : stockage non sécurisé, cryptographie faible, épinglage de certificat, liens profonds, IPC, détection de jailbreak/root, résistance à l'ingénierie inverse. À utiliser lorsque l'utilisateur mentionne « sécurité mobile », « sécurité iOS », « sécurité Android », « audit mobile », « pentest mobile », « MASVS », « MASTG », « épinglage de certificat », « détection de jailbreak », « détection de racine », « lien profond », « schéma d'URL », « sécurité du transport d'application », « porte-clés », « magasin de clés », « ingénierie inverse mobile » ou dispose d'un appareil mobile. application à revoir.
