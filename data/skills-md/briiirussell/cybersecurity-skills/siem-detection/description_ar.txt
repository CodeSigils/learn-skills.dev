مهندس ومراجعة قواعد الكشف عن SIEM - تغطية مصدر السجل، Sigma / KQL / SPL / تأليف الاستعلام المرن، وتخطيط MITRE ATT&CK، والضبط الإيجابي الخاطئ، وسير عمل الاكتشاف كرمز. يُستخدم عندما يذكر المستخدم "SIEM"، أو "هندسة الكشف"، أو "قواعد الكشف"، أو "Sigma"، أو "KQL"، أو "SPL"، أو "Splunk"، أو "Sentinel"، أو "Elastic"، أو "Wazuh"، أو "Chronicle"، أو "detection-as-code"، أو "MITRE ATT&CK mapping"، أو "تغطية السجل"، أو "ضبط التنبيه"، أو "تطوير حالة الاستخدام"، أو يحتاج إلى مساعدة في إنشاء أو تحسين الكشف الأمني.
