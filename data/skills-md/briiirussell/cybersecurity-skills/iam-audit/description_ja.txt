ID とアクセス管理の監査、設計、移行 - クラウド プロバイダー IAM (AWS、GCP、Azure)、ID プロバイダー (Okta、Entra ID / Azure AD、Auth0、Google Workspace)、アプリケーション承認 (RBAC、ABAC、ReBAC)、およびフェデレーション ID。ユーザーが「IAM」、「アイデンティティ」、「アクセス管理」、「最小権限」、「ロール設計」、「SSO」、「SAML」、「OIDC」、「OAuth」、「JIT アクセス」、「ジャストインタイム アクセス」、「ブレークグラス」、「サービス アカウント」、「RBAC」、「ABAC」、「特権クリープ」について言及する場合に使用します。 「ロール爆発」、「アイデンティティ ガバナンス」、「IAM 戦略」、「アイデンティティ移行」、「Okta」、「Entra ID」、「Azure AD」、「Auth0」、「Cognito」、またはアイデンティティ コンサルタント レベルのガイダンスが必要です。
