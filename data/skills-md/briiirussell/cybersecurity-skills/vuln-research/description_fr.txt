Recherchez un CVE ou une divulgation de vulnérabilité spécifique de bout en bout : quelle version est affectée, votre code est-il accessible, existe-t-il un PoC public, existe-t-il un correctif, quelle est la fenêtre d'exposition, quelle est l'atténuation si vous ne pouvez pas appliquer le correctif immédiatement. À utiliser lorsque l'utilisateur mentionne « CVE », « recherche de vulnérabilité », « ce CVE est-il pertinent », « jour zéro », « CISA KEV », « avis de sécurité GitHub », « analyse d'accessibilité », « analyse des correctifs », « disponibilité des exploits », « EPSS », « CVSS » ou « devrions-nous tout abandonner et corriger cela ».
