تطبيقات التدقيق والتعامل مع البنية التحتية المعلومات الصحية المحمية ضد HIPAA - قاعدة الأمان (الضمانات الإدارية والمادية والفنية)، وقاعدة الخصوصية، وقاعدة إشعار الخرق، بالإضافة إلى HITECH. يغطي نطاق ePHI، ومعرفات HIPAA الـ 18، وسلسلة المسؤولية لاتفاقية شركاء الأعمال (BAA)، والحد الأدنى الضروري من المعايير، وتوقيت إشعار الانتهاك. يُستخدم عندما يذكر المستخدم "HIPAA"، أو "قاعدة أمان HIPAA"، أو "قاعدة خصوصية HIPAA"، أو "PHI"، أو "ePHI"، أو "المعلومات الصحية المحمية"، أو "BAA"، أو "اتفاقية شركاء الأعمال"، أو "الكيان المغطى"، أو "شريك الأعمال"، أو "الحد الأدنى الضروري"، أو "خرق قانون HIPAA"، أو "HITECH"، أو "الامتثال للرعاية الصحية"، أو "البيانات الطبية"، أو "بيانات المرضى"، أو يراجع أي نظام ينشئ، يستقبل أو يحتفظ أو ينقل PHI.
