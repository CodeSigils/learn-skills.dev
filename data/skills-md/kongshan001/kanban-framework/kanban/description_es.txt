Utilice el comando /kanban para gestionar el ciclo de vida completo de las tareas kanban: inicializar el tablero, crear tareas TASK-NNN, ejecutar fases (planificar/ejecutar/evaluar), archivar tareas completadas, ver el estado/progreso, restaurar tareas interrumpidas y manejar flujos de trabajo de múltiples iteraciones. Cuando un usuario menciona kanban, tablero, TASK‑NNN, el comando /kanban, creación/archivo/restauración de tareas o cualquier intención de gestión de tareas kanban, aplique esta habilidad.
