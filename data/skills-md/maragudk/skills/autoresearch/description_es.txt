Bucle de experimento autónomo que mejora iterativamente una métrica medible. Dado un objetivo, un comando de verificación y una protección opcional, el agente se bifurca, realiza un cambio, mide el resultado y mantiene o descarta el experimento, repitiéndolo indefinidamente. Utilice esta habilidad cuando el usuario quiera optimizar algo medible mediante experimentación automatizada, ciclos de mejora autónomos o cuando mencione "investigación automática". Funciona para cualquier dominio con una métrica cuantificable (rendimiento del código, entrenamiento de ML, tamaño de compilación, puntajes de pruebas, métricas de calidad del contenido, etc.).
