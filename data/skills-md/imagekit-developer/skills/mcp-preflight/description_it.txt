Guida al routing per i due server MCP di ImageKit (imagekit_api e imagekit_devtools): mappa ciascuna funzionalità sul server e sullo strumento corretti e copre le regole di routing (ad esempio, non caricare mai file locali tramite esecuzione). Utilizzare prima di chiamare qualsiasi strumento ImageKit MCP. Copre la gestione dei file, le operazioni sulle cartelle, l'eliminazione della cache, i metadati, la ricerca di documenti, la creazione di trasformazioni e il routing del caricamento.
