Руководство по маршрутизации для двух серверов MCP ImageKit (imagekit_api и imagekit_devtools) — сопоставляет каждую возможность с правильным сервером и инструментом и описывает правила маршрутизации (например, никогда не загружать локальные файлы посредством выполнения). Используйте перед вызовом любого инструмента ImageKit MCP. Охватывает управление файлами, операции с папками, очистку кэша, метаданные, поиск документов, построение преобразований и маршрутизацию загрузки.
