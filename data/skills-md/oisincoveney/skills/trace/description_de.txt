Verwenden Sie diese Option, wenn Sie einen Fehler, einen Testfehler, einen Absturz, einen Hang, einen fehlerhaften Test oder ein unerwartetes/„seltsames“ Verhalten untersuchen – BEVOR Sie einen Fix vorschlagen oder schreiben. Zwingt dazu, die eigentliche Grundursache zu finden, anstatt zu raten, das Erste, was Sie sehen, auszubessern oder das Symptom zu beheben. Auslösen bei „Warum ist das kaputt“, „Das verhält sich komisch“, „Fehler beheben“, „Der Test schlägt fehl“, „Es funktioniert manchmal“.
