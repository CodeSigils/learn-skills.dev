Wird für schwerwiegende Fehler und Leistungseinbußen verwendet – wenn der Fehler nur sporadisch auftritt, die Ursache unbekannt ist oder die „Reproduktion“ selbst der schwierige Teil ist. Eine disziplinierte Schleife – Erstellen Sie ein schnelles deterministisches Rückkopplungssignal → Reproduzieren → 3–5 falsifizierbare Hypothesen → Instrumentieren Sie jeweils eine Variable → Korrigieren Sie sie mit einem Regressionstest → Post-Mortem. Auslösen bei „Diagnostizieren“, „Warum ist das schuppig“, „Intermittierend“, „Leistungsrückgang“, „Kann nicht reproduziert werden“, „Es funktioniert manchmal“.
