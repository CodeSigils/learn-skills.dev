Orquestador de flujo de trabajo: el único punto de entrada para todo el trabajo del proyecto. Detecta automáticamente dónde lo dejó el usuario al escanear artefactos, lo guía al siguiente paso y lo mantiene encaminado durante todo el flujo de trabajo. Se activa cada vez que el usuario inicia una nueva función, reanuda el trabajo, dice "dónde estaba", "qué sigue", "iniciar", "reanudar", "saltar a X", "volver a X" o menciona cualquier etapa del flujo de trabajo. También se activa cuando el usuario describe una idea o característica sin invocar explícitamente una habilidad específica: la torre de control lo dirigirá a la correcta.
