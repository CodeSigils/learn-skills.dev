Используйте этот навык для управления библиотеками тестовых примеров на естественном языке. Обрабатывает три сценария: (1) прием нового PRD и создание тестовых примеров в первый раз, (2) дополнение существующего модуля дополнительными тестовыми примерами (граничными случаями, потоками ошибок), (3) анализ влияния обновления PRD и выполнение CRUD на затронутых тестовых примерах. Работает с библиотекой тестовых сценариев иерархической файловой системы. Никогда не загружает все тестовые примеры одновременно — использует навигацию по дереву по требованию, чтобы оставаться в пределах токенов. Триггерные фразы: «管理测试用例», «新增测试用例», «补充测试用例», «测试用例影响分析», «PRD变更», «更新测试用例», «Менеджер тестовых сценариев», «新PRD», «初次接入测试用例»
