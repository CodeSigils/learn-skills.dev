Umfassende Websuche mit Codex CLI für komplexe Abfragen, die eine Synthese aus mehreren Quellen erfordern. Verwenden Sie diese Option, wenn web_search (Brave) unzureichende Ergebnisse liefert, wenn der Benutzer eine eingehende Recherche oder eine umfassende Analyse anfordert oder „Deep Search“, „详细搜索“, „帮我查一下“ sagt oder wenn zu einem Thema mehreren Links und Querverweisen auf Quellen gefolgt werden muss. - Fork von @AIsuperdomain
