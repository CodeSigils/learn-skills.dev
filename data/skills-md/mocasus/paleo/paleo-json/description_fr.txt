À utiliser lorsque l'utilisateur dit "compact json", "réduire la sortie", "tight structuré" ou que l'agent doit émettre des données JSON/structurées. Supprimez les espaces insignifiants, réduisez les longs tableaux, raccourcissez les clés là où cela est sûr, gardez-le analysable. Coupe les jetons sur les charges utiles structurées. Désactivé : « joli imprimé » / « lisible par l'homme ».
