Verwenden Sie diese Option, wenn der Benutzer „JSON komprimieren“, „Ausgabe minimieren“ oder „streng strukturiert“ sagt oder der Agent JSON/strukturierte Daten ausgeben muss. Entfernen Sie unbedeutende Leerzeichen, reduzieren Sie lange Arrays, kürzen Sie Schlüssel an sicheren Stellen und halten Sie sie analysierbar. Reduziert Token für strukturierte Nutzlasten. Aus: „schöner Druck“ / „für Menschen lesbar“.
