À utiliser lorsque le produit de l'utilisateur est construit (ou presque construit) et qu'il souhaite le rendre opérationnel et accessible aux clients. Déclencheurs sur des expressions telles que « créer ma liste de contrôle de lancement », « comment puis-je déployer ceci », « aidez-moi à lancer », « mettre ceci en ligne », « mettre cela en production », « l'envoyer aux clients », « que dois-je faire pour passer en ligne » ou toute demande de cheminement étape par étape depuis le code fonctionnel vers un produit que les clients peuvent utiliser. Audite la base de code actuelle - pile, services, variables d'environnement, paiements, configuration de déploiement - puis rédige un guide de lancement étape par étape en anglais simple dans `docs/launch-checklist.md`. Chaque étape est marquée comme quelque chose que l'utilisateur doit faire lui-même, quelque chose que son agent de codage peut faire, ou les deux ensemble, et tous les termes techniques sont expliqués pour les fondateurs non techniques.
