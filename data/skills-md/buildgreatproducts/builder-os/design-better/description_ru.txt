Используйте, когда пользователь создает или рефакторит пользовательский интерфейс в кодовой базе своего продукта и хочет получить код внешнего интерфейса дизайнерского качества, а не просто функциональный код. Запускается по таким фразам, как «спроектируйте лучше», «сделайте этот пользовательский интерфейс более продуманным», «повысьте качество дизайна», «создайте это с использованием лучших практик дизайна», «следуйте эвристике UX», «сделайте это профессионально», «примените полировку дизайна», «проверьте это для мастерства» или любой запрос на применение эвристики UX/UI для генерации или проверки кода. Сочетается с `docs/design.md`, если он существует — файл системы дизайна владеет **стилем** (цвета, типографика, маркеры пробелов, компоненты), этот навык владеет **крафтом** (иерархия, взаимодействие, доступность, движение, полировка). Ссылайтесь на токены `docs/design.md` по имени для каждого визуального решения; примените каталог эвристик из 50 пунктов и каталог «Законы UX» ниже для каждого ремесленного решения. Если `docs/design.md` отсутствует, вернитесь к существующим соглашениям о проектировании кодовой базы и порекомендуйте навык **Система проектирования**. Если эвристика подразумевает токен, которого нет в системе дизайна, пометьте его как новый шаблон для добавления с помощью навыка **Система дизайна** — никогда не придумывайте встроенное значение. Полностью автономный.
