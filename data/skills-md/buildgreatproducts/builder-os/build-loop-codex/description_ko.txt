모든 코드베이스에서 **Codex**(OpenAI Codex CLI)를 사용하여 기능을 빌드할 때 사용하며 작업은 엄격한 빌드 → 검토 → 테스트 → 수정 루프를 거쳐야 합니다. "빌드 루프 실행", "다음 작업 빌드", "계획 계속", "이 기능을 올바르게 빌드" 또는 계획 파일이나 직접적인 기능 프롬프트에서 작업을 구현하라는 요청에 대해 트리거됩니다. 계획(또는 계획이 없는 경우 프롬프트)에서 빌드하고, 커밋되지 않은 변경 사항에 대해 Codex의 `/review`를 실행하고 발견된 모든 문제를 수정하고, 기능을 엔드 투 엔드로 테스트 및 확인하고, 테스트 표면을 수정하고, 완료되면 다시 보고합니다. 모든 계획 작업이 완료될 때까지 반복됩니다.
