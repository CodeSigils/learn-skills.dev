Da utilizzare durante la creazione di funzionalità con **Codex** (CLI OpenAI Codex) in qualsiasi base di codice e il lavoro dovrebbe passare attraverso un ciclo disciplinato di creazione → revisione → test → correzione. Si attiva "esegui il ciclo di creazione", "crea l'attività successiva", "continua il piano", "crea correttamente questa funzionalità" o qualsiasi richiesta di implementazione del lavoro da un file di piano o da una richiesta di funzionalità diretta. Si basa sul piano (o sul prompt se non esiste un piano), esegue "/review" del Codex sulle modifiche non confermate e risolve ogni problema riscontrato, testa e verifica la funzionalità end-to-end, corregge qualsiasi cosa venga testata e restituisce un report una volta completato. Si ripete finché tutte le attività del piano non vengono selezionate.
