Traduce un'immagine (o una serie di riferimenti a immagini: screenshot,
mockup, URL Figma, siti Web live) in un `docs/design.md` di alta qualità
file dopo l'apertura di Google
Formato [design.md](https://github.com/google-labs-code/design.md).
Legge le immagini, pone domande chiarificatrici mirate, deriva YAML
token di progettazione (colori, tipografia, spaziatura, arrotondamento, componenti),
e scrive motivazioni in prosa che qualsiasi agente di codifica AI può utilizzare.
Completamente autonomo: non richiede altri documenti o competenze. Utilizzare quando
il fondatore dice "creare un sistema di design", "progettare dall'immagine",
"traduci immagine in design", "crea design.md", "immagine in design
system", "estrarre token di progettazione" o condividere un'immagine con nessun altro
intento chiaro.
