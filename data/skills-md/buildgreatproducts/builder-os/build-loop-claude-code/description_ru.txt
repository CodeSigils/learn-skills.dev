Используйте при создании функций с помощью **Claude Code** в любой базе кода. Работа должна проходить через дисциплинированный цикл сборки → проверки → тестирования → исправления. Запускается при «запуске цикла сборки», «построении следующей задачи», «продолжении плана», «правильной сборке этой функции» или любом запросе на реализацию работы из файла плана или прямого запроса функции. Создает на основе плана (или приглашения, если план не существует), запускает `/review` Claude Code (плюс `/security-review` для конфиденциальных поверхностей) и исправляет каждую обнаруженную проблему, тестирует и проверяет функцию от начала до конца, исправляет все тестовые поверхности и сообщает после завершения. Повторяется до тех пор, пока все задачи плана не будут отмечены галочками.
