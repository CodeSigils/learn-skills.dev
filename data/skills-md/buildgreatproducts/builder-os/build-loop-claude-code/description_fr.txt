À utiliser lors de la création de fonctionnalités avec **Claude Code** dans n'importe quelle base de code et le travail doit passer par une boucle de construction → révision → test → correction disciplinée. Déclencheurs sur « exécuter la boucle de construction », « créer la tâche suivante », « poursuivre le plan », « créer cette fonctionnalité correctement » ou toute demande d'implémentation de travail à partir d'un fichier de plan ou d'une invite de fonctionnalité directe. Construit à partir du plan (ou de l'invite si aucun plan n'existe), exécute le « /review » de Claude Code (plus « /security-review » pour les surfaces sensibles) et corrige tous les problèmes trouvés, teste et vérifie la fonctionnalité de bout en bout, corrige tout ce qui teste les surfaces et rend compte une fois terminé. Se répète jusqu'à ce que toutes les tâches du plan soient cochées.
