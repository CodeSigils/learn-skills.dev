استخدمه عند إنشاء ميزات باستخدام **Claude Code** في أي قاعدة تعليمات برمجية ويجب أن يمر العمل ببناء منضبط → مراجعة → اختبار → حلقة إصلاح. يتم تشغيلها عند "تشغيل حلقة الإنشاء"، أو "إنشاء المهمة التالية"، أو "مواصلة الخطة"، أو "إنشاء هذه الميزة بشكل صحيح"، أو أي طلب لتنفيذ العمل من ملف خطة أو موجه ميزة مباشر. يتم البناء من الخطة (أو المطالبة في حالة عدم وجود خطة)، وتشغيل `/review` الخاص بـ Claude Code (بالإضافة إلى `/مراجعة الأمان` للأسطح الحساسة) وإصلاح كل مشكلة تم العثور عليها، واختبار الميزة والتحقق منها من البداية إلى النهاية، وإصلاح أي شيء يتم اختباره على الأسطح، وتقديم التقارير بمجرد اكتماله. يتكرر حتى يتم تحديد جميع مهام الخطة.
