Verwenden Sie es beim Erstellen von Features mit **Claude Code** in einer beliebigen Codebasis und die Arbeit sollte eine disziplinierte Build-→Überprüfung-→Test-→Fix-Schleife durchlaufen. Wird ausgelöst bei „Build-Schleife ausführen“, „Nächste Aufgabe erstellen“, „Plan fortsetzen“, „Diese Funktion ordnungsgemäß erstellen“ oder bei jeder Anforderung zur Implementierung von Arbeiten aus einer Plandatei oder einer direkten Funktionsaufforderung. Erstellt den Plan (oder die Eingabeaufforderung, wenn kein Plan vorhanden ist), führt „/review“ von Claude Code aus (plus „/security-review“ für sensible Oberflächen) und behebt jedes gefundene Problem, testet und verifiziert die Funktion durchgängig, behebt alles, was Oberflächen testet, und meldet sich zurück, sobald der Vorgang abgeschlossen ist. Wird wiederholt, bis alle Planaufgaben abgehakt sind.
