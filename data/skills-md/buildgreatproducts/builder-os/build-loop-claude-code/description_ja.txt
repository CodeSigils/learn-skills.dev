任意のコードベースで **クロード コード** を使用して機能を構築する場合に使用します。作業は、規律あるビルド→レビュー→テスト→修正のループを通過する必要があります。 「ビルド ループの実行」、「次のタスクのビルド」、「計画の継続」、「この機能を適切にビルド」、または計画ファイルまたは直接機能プロンプトからの作業を実装するためのリクエストがトリガーされます。計画 (または計画が存在しない場合はプロンプト) から構築し、Claude Code の `/review` (さらに機密面の `/security-review`) を実行して、見つかったすべての問題を修正し、機能をエンドツーエンドでテストおよび検証し、テスト面を修正し、完了したらレポートを返します。すべての計画タスクがチェックオフされるまで繰り返します。
