Da utilizzare quando si creano funzionalità con **Claude Code** in qualsiasi base di codice e il lavoro dovrebbe passare attraverso un ciclo disciplinato di compilazione → revisione → test → correzione. Si attiva "esegui il ciclo di creazione", "crea l'attività successiva", "continua il piano", "crea correttamente questa funzionalità" o qualsiasi richiesta di implementazione del lavoro da un file di piano o da una richiesta di funzionalità diretta. Si basa sul piano (o sul prompt se non esiste un piano), esegue "/review" di Claude Code (più "/security-review" per le superfici sensibili) e risolve ogni problema riscontrato, testa e verifica la funzionalità dall'inizio alla fine, corregge qualsiasi cosa testando le superfici e restituisce un report una volta completato. Si ripete finché tutte le attività del piano non vengono selezionate.
