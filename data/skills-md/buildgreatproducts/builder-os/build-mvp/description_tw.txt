當使用者想要從其 BuilderOS 規格文件建立完整的 MVP 時，在產品儲存庫中使用。觸發諸如「建立我的 MVP」、「建立應用程式」、「執行路線圖」、「開始建置」、「完成整個路線圖」、「建置一切」等短語，或任何實施整個計畫而不是單一任務或階段的請求。需要「docs/prd.md」和「docs/product-roadmap.md」（加上「docs/product-vision.md」和「docs/design.md」作為上下文）。按順序完成每個路線圖任務 - 在繼續之前實現、測試和驗證每個任務，標記複選框並更新狀態行 - 並運行直到所有任務完成並且神奇時刻端到端工作，然後使用初始提交初始化 git 並提供連接遠端存儲庫。
