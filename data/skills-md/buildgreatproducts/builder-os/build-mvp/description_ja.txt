ユーザーが BuilderOS 仕様ドキュメントから構築された完全な MVP を必要とする場合は、製品リポジトリ内で使用します。 「MVP を構築する」、「アプリを構築する」、「ロードマップを実行する」、「構築を開始する」、「ロードマップ全体を実行する」、「すべてを構築する」などのフレーズ、または単一のタスクやフェーズではなく計画全体を実装するためのリクエストによってトリガーされます。 `docs/prd.md` および `docs/product-roadmap.md` (さらに、コンテキスト用の `docs/product-vision.md` および `docs/design.md`) が必要です。すべてのロードマップ タスクを順番に実行し、各タスクを実装、テスト、検証してから次に進み、チェックボックスをオンにしてステータス ラインを更新します。すべてのタスクが完了し、マジック モーメントがエンドツーエンドで機能するまで実行され、その後、最初のコミットで git を初期化し、リモート リポジトリへの接続を提案します。
