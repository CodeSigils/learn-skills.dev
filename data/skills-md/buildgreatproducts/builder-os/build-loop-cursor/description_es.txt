Úselo al crear funciones con **Cursor** en cualquier base de código y el trabajo debe pasar por un bucle disciplinado de compilación → revisión → prueba → reparación. Activadores de "ejecutar el ciclo de compilación", "compilar la siguiente tarea", "continuar el plan", "compilar esta función correctamente" o cualquier solicitud para implementar el trabajo desde un archivo de plan o una solicitud de función directa. Se compila a partir del plan (o el mensaje si no existe ningún plan), ejecuta `/review` del Cursor y soluciona todos los problemas encontrados, prueba y verifica la función de principio a fin, corrige cualquier superficie de prueba y genera informes una vez completado. Se repite hasta que todas las tareas del plan estén marcadas.
