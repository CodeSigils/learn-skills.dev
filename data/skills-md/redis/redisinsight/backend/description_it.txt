Modelli di sviluppo del backend NestJS per l'API RedisInsight: struttura del modulo, servizi, controller, DTO, inserimento delle dipendenze e gestione degli errori. Da utilizzare quando si modifica qualsiasi file in redisinsight/api/**, si scrive o si modificano moduli, controller, servizi, DTO, provider NestJS o quando l'utente menziona il backend, l'API o NestJS.
