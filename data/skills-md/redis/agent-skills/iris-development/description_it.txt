Iris è l'ombrello di Redis per i prodotti incentrati sull'intelligenza artificiale. Utilizza questa competenza durante l'integrazione con il piano dati Iris Redis Agent Memory (RAM) su Redis Cloud: registrazione di eventi di sessione per un agente AI, creazione o ricerca di ricordi a lungo termine, configurazione di un archivio di memoria o ottimizzazione della promozione della memoria in background. Gli esempi di codice utilizzano gli SDK ufficiali "redis-agent-memory" (Python) e "@redis-iris/agent-memory" (TypeScript).
