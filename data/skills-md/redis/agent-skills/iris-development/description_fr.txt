Iris est l'organisme parapluie de Redis pour les produits axés sur l'IA. Utilisez cette compétence lors de l'intégration avec le plan de données Iris Redis Agent Memory (RAM) sur Redis Cloud : enregistrement des événements de session pour un agent IA, création ou recherche de mémoires à long terme, configuration d'un magasin de mémoire ou réglage de la promotion de la mémoire en arrière-plan. Les exemples de code utilisent les SDK officiels `redis-agent-memory` (Python) et `@redis-iris/agent-memory` (TypeScript).
