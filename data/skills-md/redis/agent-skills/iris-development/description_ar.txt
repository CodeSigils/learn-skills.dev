Iris هي مظلة Redis للمنتجات التي تركز على الذكاء الاصطناعي. استخدم هذه المهارة عند التكامل مع مستوى بيانات Iris Redis Agent Memory (RAM) على Redis Cloud - تسجيل أحداث الجلسة لوكيل الذكاء الاصطناعي، أو إنشاء ذكريات طويلة المدى أو البحث عنها، أو تكوين مخزن ذاكرة، أو ضبط ترقية ذاكرة الخلفية. تستخدم أمثلة التعليمات البرمجية حزم SDK الرسمية `redis-agent-memory` (Python) و`@redis-iris/agent-memory` (TypeScript).
