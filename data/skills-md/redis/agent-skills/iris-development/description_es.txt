Iris es el paraguas de Redis para productos centrados en IA. Utilice esta habilidad al integrarse con el plano de datos de Iris Redis Agent Memory (RAM) en Redis Cloud: registrar eventos de sesión para un agente de IA, crear o buscar recuerdos a largo plazo, configurar un almacén de memoria o ajustar la promoción de la memoria en segundo plano. Los ejemplos de código utilizan los SDK oficiales `redis-agent-memory` (Python) y `@redis-iris/agent-memory` (TypeScript).
