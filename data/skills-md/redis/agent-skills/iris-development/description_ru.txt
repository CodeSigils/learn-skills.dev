Iris — это зонтик Redis для продуктов, ориентированных на искусственный интеллект. Используйте этот навык при интеграции с плоскостью данных Iris Redis Agent Memory (RAM) в Redis Cloud — записи событий сеанса для агента ИИ, создании или поиске долговременных воспоминаний, настройке хранилища памяти или настройке расширения фоновой памяти. В примерах кода используются официальные SDK redis-agent-memory (Python) и @redis-iris/agent-memory (TypeScript).
