Iris ist Redis‘ Dach für KI-fokussierte Produkte. Verwenden Sie diese Fähigkeit bei der Integration mit der Iris Redis Agent Memory (RAM)-Datenebene in der Redis Cloud – zum Aufzeichnen von Sitzungsereignissen für einen KI-Agenten, zum Erstellen oder Durchsuchen von Langzeitspeichern, zum Konfigurieren eines Speichers oder zum Optimieren der Hintergrundspeicherförderung. Codebeispiele verwenden die offiziellen SDKs „redis-agent-memory“ (Python) und „@redis-iris/agent-memory“ (TypeScript).
