Guía de Redis Query Engine (RQE) que cubre el diseño de esquema FT.CREATE, selección de tipo de campo (TEXT, TAG, NUMERIC, GEO, GEOSHAPE, VECTOR), sintaxis de consulta DIALECT 2, consultas FT.SEARCH y FT.AGGREGATE eficientes, actualizaciones de índice sin tiempo de inactividad a través de alias y la opción SKIPINITIALSCAN. Úselo al definir un índice de búsqueda en documentos Hash o JSON, elegir entre TEXTO y ETIQUETA para filtrar, escribir consultas FT.SEARCH con filtros y SORTBY, administrar o intercambiar índices en producción o solucionar problemas de búsquedas lentas con FT.PROFILE.
