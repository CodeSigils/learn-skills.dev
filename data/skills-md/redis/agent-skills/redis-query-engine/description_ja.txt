FT.CREATE スキーマ設計、フィールド タイプの選択 (TEXT、TAG、NUMERIC、GEO、GEOSHAPE、VECTOR)、DIALECT 2 クエリ構文、効率的な FT.SEARCH および FT.AGGREGATE クエリ、エイリアスによるダウンタイムなしのインデックス更新、および SKIPINITIALSCAN オプションをカバーする Redis Query Engine (RQE) ガイダンス。ハッシュまたは JSON ドキュメントの検索インデックスを定義する場合、フィルタリングのために TEXT と TAG のどちらかを選択する場合、フィルタと SORTBY を使用して FT.SEARCH クエリを作成する場合、運用環境でインデックスを管理または交換する場合、または FT.PROFILE を使用して遅い検索のトラブルシューティングを行う場合に使用します。
