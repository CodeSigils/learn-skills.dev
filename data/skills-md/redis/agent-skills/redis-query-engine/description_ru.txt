Руководство по Redis Query Engine (RQE), охватывающее проектирование схемы FT.CREATE, выбор типа поля (TEXT, TAG, NUMERIC, GEO, GEOSHAPE, VECTOR), синтаксис запросов DIALECT 2, эффективные запросы FT.SEARCH и FT.AGGREGATE, обновление индексов с нулевым временем простоя через псевдонимы и опцию SKIPINITIALSCAN. Используйте при определении индекса поиска в документах Hash или JSON, выборе между TEXT и TAG для фильтрации, написании запросов FT.SEARCH с фильтрами и SORTBY, управлении или замене индексов в рабочей среде или устранении неполадок медленного поиска с помощью FT.PROFILE.
