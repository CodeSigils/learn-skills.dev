Guida Redis Query Engine (RQE) che copre la progettazione dello schema FT.CREATE, la selezione del tipo di campo (TEXT, TAG, NUMERIC, GEO, GEOSHAPE, VECTOR), la sintassi delle query DIALECT 2, query FT.SEARCH e FT.AGGREGATE efficienti, aggiornamenti dell'indice con tempi di inattività pari a zero tramite alias e l'opzione SKIPINITIALSCAN. Da utilizzare quando si definisce un indice di ricerca su documenti Hash o JSON, si sceglie tra TEXT e TAG per filtrare, si scrivono query FT.SEARCH con filtri e SORTBY, si gestiscono o scambiano indici in produzione o si risolvono problemi di ricerche lente con FT.PROFILE.
