إرشادات Redis Query Engine (RQE) التي تغطي تصميم مخطط FT.CREATE، واختيار نوع الحقل (TEXT، TAG، NUMERIC، GEO، GEOSHAPE، VECTOR)، بناء جملة استعلام DIALECT 2، واستعلامات FT.SEARCH وFT.AGGREGATE الفعالة، وتحديثات فهرس وقت التوقف الصفري عبر الأسماء المستعارة، وخيار SKIPINITIALSCAN. يُستخدم عند تعريف فهرس بحث على مستندات Hash أو JSON، أو الاختيار بين TEXT وTAG للتصفية، أو كتابة استعلامات FT.SEARCH باستخدام عوامل التصفية وSORTBY، أو إدارة الفهارس أو تبديلها في الإنتاج، أو استكشاف أخطاء عمليات البحث البطيئة وإصلاحها باستخدام FT.PROFILE.
