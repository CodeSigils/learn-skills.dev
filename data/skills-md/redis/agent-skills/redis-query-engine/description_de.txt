Anleitung zur Redis Query Engine (RQE) zum FT.CREATE-Schemadesign, zur Feldtypauswahl (TEXT, TAG, NUMERIC, GEO, GEOSHAPE, VECTOR), zur DIALECT 2-Abfragesyntax, zu effizienten FT.SEARCH- und FT.AGGREGATE-Abfragen, zu Indexaktualisierungen ohne Ausfallzeiten über Aliase und zur Option SKIPINITIALSCAN. Verwenden Sie diese Funktion, wenn Sie einen Suchindex für Hash- oder JSON-Dokumente definieren, zwischen TEXT und TAG zum Filtern wählen, FT.SEARCH-Abfragen mit Filtern und SORTBY schreiben, Indizes in der Produktion verwalten oder austauschen oder langsame Suchvorgänge mit FT.PROFILE beheben.
