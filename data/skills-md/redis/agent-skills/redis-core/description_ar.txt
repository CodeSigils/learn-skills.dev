إرشادات النمذجة الأساسية لـ Redis - اختر بنية البيانات الصحيحة (String، Hash، List، Set، Sorted Set، JSON، Stream، Vector Set) واستخدم أسماء مفاتيح متسقة مفصولة بنقطتين. يُستخدم عند تصميم نموذج بيانات Redis، أو تخزين الكائنات مؤقتًا، أو الاختيار بين Hash وJSON، أو بناء العدادات، أو لوحات المتصدرين، أو مجموعات العضوية، أو مخازن الجلسة، أو عند مراجعة/تنظيف تسمية مفتاح Redis.
