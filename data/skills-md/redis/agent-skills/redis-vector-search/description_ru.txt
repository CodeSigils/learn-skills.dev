Руководство по векторному поиску Redis, охватывающее выбор алгоритма HNSW или FLAT, конфигурацию векторного индекса (тусклость, метрика расстояния, тип данных), фильтрованный гибридный поиск, сочетающий сходство векторов с фильтрами TAG или NUMERIC, а также шаблон поиска RAG с RedisVL. Используйте при определении поля VECTOR в FT.CREATE, интеграции внедрений (OpenAI, Cohere, преобразователей предложений), настройке параметров HNSW (M, EF_CONSTRUCTION, EF_RUNTIME), построении конвейера генерации с расширенным поиском или фильтрации результатов вектора по атрибуту.
