Conseils de recherche vectorielle Redis couvrant le choix de l'algorithme HNSW vs FLAT, la configuration de l'index vectoriel (dimensions, métrique de distance, type de données), la recherche hybride filtrée combinant la similarité vectorielle avec les filtres TAG ou NUMERIC et le modèle de récupération RAG avec RedisVL. À utiliser lors de la définition d'un champ VECTOR dans FT.CREATE, de l'intégration d'intégrations (OpenAI, Cohere, transformations de phrases), du réglage des paramètres HNSW (M, EF_CONSTRUCTION, EF_RUNTIME), de la création d'un pipeline de génération augmentée par récupération ou du filtrage des résultats vectoriels par attribut.
