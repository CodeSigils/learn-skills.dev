HNSW と FLAT アルゴリズムの選択、ベクトル インデックス構成 (ディム、距離メトリック、データ型)、ベクトル類似性と TAG または NUMERIC フィルターを組み合わせたフィルター処理されたハイブリッド検索、および RedisVL を使用した RAG 取得パターンをカバーする Redis ベクトル検索ガイダンス。 FT.CREATE で VECTOR フィールドを定義する場合、埋め込み (OpenAI、Cohere、文変換) を統合する場合、HNSW パラメーター (M、EF_CONSTRUCTION、EF_RUNTIME) を調整する場合、検索拡張生成パイプラインを構築する場合、または属性によるベクトル結果をフィルターする場合に使用します。
