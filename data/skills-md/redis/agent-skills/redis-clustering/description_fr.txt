Redis Cluster et conseils de réplication couvrant les balises de hachage pour les opérations multi-clés, évitant les erreurs CROSSSLOT et la lecture à partir de réplicas pour faire évoluer les charges de travail lourdes en lecture. À utiliser lors de la conception de clés pour un cluster Redis partitionné, du débogage des erreurs CROSSSLOT sur MGET/SDIFF/pipelines, de la configuration d'une transaction multi-clés dans un cluster ou du routage des lectures vers des réplicas pour les caches, les analyses ou les tableaux de bord.
