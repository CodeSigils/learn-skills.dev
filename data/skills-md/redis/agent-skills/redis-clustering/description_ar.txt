مجموعة Redis وتوجيهات النسخ المتماثل تغطي علامات التجزئة للعمليات متعددة المفاتيح، وتجنب أخطاء CROSSSLOT، والقراءة من النسخ المتماثلة لقياس أعباء العمل الثقيلة للقراءة. يُستخدم عند تصميم مفاتيح لمجموعة Redis مقسمة، أو تصحيح أخطاء CROSSSLOT على خطوط الأنابيب MGET / SDIFF، أو تكوين معاملة متعددة المفاتيح في مجموعة، أو توجيه عمليات القراءة إلى النسخ المتماثلة لذاكرة التخزين المؤقت أو التحليلات أو لوحات المعلومات.
