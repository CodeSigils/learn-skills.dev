Linee guida sulla sicurezza di Redis che coprono l'autenticazione (richiede pass e utenti ACL), TLS, controllo degli accessi con privilegi minimi basati su ACL, limitazione dell'esposizione della rete tramite associazione e modalità protetta, regole firewall e disabilitazione di comandi pericolosi. Da utilizzare quando si distribuisce Redis in produzione, si definiscono utenti ACL per un'applicazione, si configurano connessioni TLS, si blocca un'istanza Redis dietro un firewall o si controlla una distribuzione Redis per il rafforzamento della sicurezza.
