يغطي التوجيه الأمني ​​لـ Redis المصادقة (يتطلب المرور ومستخدمي ACL)، وTLS، والتحكم في الوصول الأقل امتيازًا المستند إلى ACL، وتقييد تعرض الشبكة عبر الربط والوضع المحمي، وقواعد جدار الحماية، وتعطيل الأوامر الخطيرة. يُستخدم عند نشر Redis في الإنتاج، أو تحديد مستخدمي ACL لأحد التطبيقات، أو تكوين اتصالات TLS، أو تأمين مثيل Redis خلف جدار الحماية، أو تدقيق نشر Redis لتعزيز الأمان.
