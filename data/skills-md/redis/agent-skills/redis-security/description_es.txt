Guía de seguridad de Redis que cubre autenticación (usuarios requirepass y ACL), TLS, control de acceso con privilegios mínimos basado en ACL, restricción de la exposición de la red mediante enlace y modo protegido, reglas de firewall y desactivación de comandos peligrosos. Úselo al implementar Redis en producción, definir usuarios de ACL para una aplicación, configurar conexiones TLS, bloquear una instancia de Redis detrás de un firewall o auditar una implementación de Redis para reforzar la seguridad.
