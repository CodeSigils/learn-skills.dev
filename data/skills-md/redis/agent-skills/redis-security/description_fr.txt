Conseils de sécurité Redis couvrant l'authentification (utilisateurs requis et ACL), TLS, le contrôle d'accès au moindre privilège basé sur ACL, la restriction de l'exposition du réseau via la liaison et le mode protégé, les règles de pare-feu et la désactivation des commandes dangereuses. À utiliser lors du déploiement de Redis en production, de la définition des utilisateurs ACL pour une application, de la configuration des connexions TLS, du verrouillage d'une instance Redis derrière un pare-feu ou de l'audit d'un déploiement Redis pour le renforcement de la sécurité.
