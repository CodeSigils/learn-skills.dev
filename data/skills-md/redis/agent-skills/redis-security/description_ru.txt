Руководство по безопасности Redis, охватывающее аутентификацию (пользователи requirepass и ACL), TLS, управление доступом с наименьшими привилегиями на основе ACL, ограничение воздействия сети с помощью привязки и защищенного режима, правила брандмауэра и отключение опасных команд. Используйте при развертывании Redis в рабочей среде, определении пользователей ACL для приложения, настройке подключений TLS, блокировке экземпляра Redis за брандмауэром или аудите развертывания Redis на предмет усиления безопасности.
