Redis クライアントと接続のガイダンスでは、接続プーリング、多重化、パイプライン化、RESP3 によるクライアント側のキャッシュ、遅いコマンド (KEYS、SMEMBERS、HGETALL) の回避、ソケット タイムアウトの調整について説明します。 Redis クライアント (redis-py、Jedis、Lettuce、NRedisStack) の構成、スループットのためのコマンドのバッチ処理、リクエストごとの接続作成の排除、SCAN による大規模なキースペースの反復、読み取り負荷の高いワークロードに対するクライアント側のキャッシュの有効化、または接続と読み取りのタイムアウトの設定を行う場合に使用します。
