يغطي إرشادات عميل Redis والاتصال تجميع الاتصالات، وتعدد الإرسال، وتوجيه الأنابيب، والتخزين المؤقت من جانب العميل باستخدام RESP3، وتجنب الأوامر البطيئة (KEYS، وSMEMBERS، وHGETALL)، وضبط مهلات مأخذ التوصيل. يُستخدم عند تكوين عميل Redis (redis-py، وJedis، وLettuce، وNRedisStack)، أو تجميع الأوامر للإنتاجية، أو التخلص من إنشاء اتصال لكل طلب، أو تكرار مساحات المفاتيح الكبيرة باستخدام SCAN، أو تمكين التخزين المؤقت من جانب العميل لأحمال عمل القراءة الثقيلة، أو تعيين مهلات الاتصال والقراءة.
