Guida al client Redis e alla connessione che copre pooling di connessioni, multiplexing, pipelining, memorizzazione nella cache lato client con RESP3, evitando comandi lenti (KEYS, SMEMBERS, HGETALL) e ottimizzazione dei timeout del socket. Da utilizzare durante la configurazione di un client Redis (redis-py, Jedis, Lettuce, NRedisStack), l'invio in batch di comandi per la velocità effettiva, l'eliminazione della creazione di connessioni per richiesta, l'iterazione di spazi di chiave di grandi dimensioni con SCAN, l'abilitazione della memorizzazione nella cache lato client per carichi di lavoro pesanti o l'impostazione di timeout di connessione e lettura.
