يغطي توجيه بحث Redis تصميم مخطط FT.CREATE، واختيار نوع الحقل (TEXT، TAG، NUMERIC، GEO، GEOSHAPE، VECTOR، مسار JSON)، بناء جملة استعلام DIALECT 2، اختيار أوامر FT.SEARCH / FT.AGGREGATE / FT.HYBRID، تشابه المتجهات مع HNSW أو FLAT، الاسترجاع المختلط الذي يجمع بين التصنيف المعجمي والمتجه، وخطوط أنابيب RAG، تحديثات الفهرس بدون توقف عبر الأسماء المستعارة وتصحيح الأخطاء باستخدام FT.PROFILE وFT.EXPLAIN. يُستخدم عند تعريف فهرس بحث على مستندات Hash أو JSON، أو كتابة استعلامات FT.SEARCH باستخدام عوامل التصفية، أو الفرز، أو التجميع، أو ناقل KNN، أو ضبط معلمات HNSW، أو إنشاء مسار استرداد RAG، أو استكشاف أخطاء نتائج البحث البطيئة أو الفارغة وإصلاحها.
