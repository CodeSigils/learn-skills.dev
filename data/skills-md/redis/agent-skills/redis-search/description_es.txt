Guía de Redis Search que cubre el diseño del esquema FT.CREATE, selección de tipo de campo (TEXT, TAG, NUMERIC, GEO, GEOSHAPE, VECTOR, ruta JSON), sintaxis de consulta DIALECT 2, selección de comandos FT.SEARCH / FT.AGGREGATE / FT.HYBRID, similitud de vectores con HNSW o FLAT, recuperación híbrida que combina clasificación léxica y vectorial, canalizaciones RAG, actualizaciones de índices sin tiempo de inactividad mediante alias. y depuración con FT.PROFILE y FT.EXPLAIN. Úselo al definir un índice de búsqueda en documentos Hash o JSON, escribir consultas FT.SEARCH con filtros, clasificación, agregación o KNN vectorial, ajustar los parámetros HNSW, crear un canal de recuperación RAG o solucionar problemas de resultados de búsqueda lentos o vacíos.
