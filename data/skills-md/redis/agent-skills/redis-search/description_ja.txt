FT.CREATE スキーマ設計、フィールド タイプの選択 (TEXT、TAG、NUMERIC、GEO、GEOSHAPE、VECTOR、JSON パス)、DIALECT 2 クエリ構文、FT.SEARCH / FT.AGGREGATE / FT.HYBRID コマンドの選択、HNSW または FLAT とのベクトル類似性、字句ランキングとベクトル ランキングを組み合わせたハイブリッド検索、RAG パイプラインを含む Redis Search ガイダンス。エイリアスによるゼロダウンタイムのインデックス更新、および FT.PROFILE および FT.EXPLAIN によるデバッグ。ハッシュまたは JSON ドキュメントで検索インデックスを定義する場合、フィルター、並べ替え、集計、またはベクトル KNN を使用した FT.SEARCH クエリを作成する場合、HNSW パラメーターを調整する場合、RAG 取得パイプラインを構築する場合、または遅い検索結果や空の検索結果のトラブルシューティングを行う場合に使用します。
