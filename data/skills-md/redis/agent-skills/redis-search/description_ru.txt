Руководство по поиску Redis, охватывающее проектирование схемы FT.CREATE, выбор типа поля (TEXT, TAG, NUMERIC, GEO, GEOSHAPE, VECTOR, путь JSON), синтаксис запроса DIALECT 2, выбор команды FT.SEARCH / FT.AGGREGATE / FT.HYBRID, сходство векторов с HNSW или FLAT, гибридный поиск, сочетающий лексическое и векторное ранжирование, конвейеры RAG, обновления индекса с нулевым временем простоя через псевдонимы и отладка с помощью FT.PROFILE и FT.EXPLAIN. Используйте при определении индекса поиска в документах Hash или JSON, написании запросов FT.SEARCH с фильтрами, сортировкой, агрегированием или векторным KNN, настройке параметров HNSW, построении конвейера поиска RAG или устранении неполадок с медленными или пустыми результатами поиска.
