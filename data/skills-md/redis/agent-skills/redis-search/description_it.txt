Guida di Redis Search che copre la progettazione dello schema FT.CREATE, selezione del tipo di campo (TEXT, TAG, NUMERIC, GEO, GEOSHAPE, VECTOR, percorso JSON), sintassi della query DIALECT 2, selezione dei comandi FT.SEARCH / FT.AGGREGATE / FT.HYBRID, somiglianza vettoriale con HNSW o FLAT, recupero ibrido che combina classificazione lessicale e vettoriale, pipeline RAG, aggiornamenti dell'indice con tempi di inattività pari a zero tramite alias e debug con FT.PROFILE e FT.EXPLAIN.
