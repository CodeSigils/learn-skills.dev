Cree un plan de pruebas integral a partir de un PRD, un plan de implementación o un documento de clasificación. Cubre la configuración de datos locales, los servicios requeridos, las pruebas de aceptación de historias de usuario y los casos extremos. Úselo cuando el usuario quiera escribir un plan de prueba, crear un plan de control de calidad, planificar pruebas para una función o mencione "plan de prueba".
