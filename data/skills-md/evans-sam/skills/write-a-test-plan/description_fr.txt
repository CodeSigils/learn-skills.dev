Créez un plan de test complet à partir d'un PRD, d'un plan de mise en œuvre ou d'un document de triage. Couvre la configuration des données locales, les services requis, les tests d'acceptation des user story et les cas extrêmes. À utiliser lorsque l'utilisateur souhaite rédiger un plan de test, créer un plan d'assurance qualité, planifier le test d'une fonctionnalité ou mentionner « plan de test ».
