Настройте перехватчики Claude Code, чтобы блокировать опасные команды CLI git и gh до их выполнения. Используйте, когда пользователь хочет предотвратить деструктивные операции git, заблокировать опасные действия CLI GitHub (удаление репозитория, объединение pr, управление секретами, мутации API) или добавить перехватчики безопасности git/gh в код Claude.
