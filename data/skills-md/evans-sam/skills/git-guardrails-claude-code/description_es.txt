Configure enlaces de Claude Code para bloquear comandos CLI peligrosos de git y gh antes de que se ejecuten. Úselo cuando el usuario desee evitar operaciones destructivas de git, bloquear acciones peligrosas de la CLI de GitHub (eliminación de repositorios, fusión de pr, administración de secretos, mutaciones de API) o agregar ganchos de seguridad de git/gh a Claude Code.
