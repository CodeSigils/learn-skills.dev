NeoData Financial Search — 自然言語を使用したユニバーサル金融データ検索サービス。株式、ファンド、指数、セクター、マクロ経済、外国為替、コモディティ、およびその他の全範囲の財務データを自然言語でクエリし、市場相場、財務諸表（財務報告書）、資本フロー、調査報告書と格付け、イベントの発表などをカバーし、構造化 API データと財務記事という 2 つの検索モードをサポートして、即時の質疑応答を実現します。ユーザーが財務データ、株価、財務諸表、収益レポート、市場データ、ファンド情報、マクロ経済、外国為替、商品について尋ねる場合、または NeoData API をクエリする必要がある場合に使用します。
