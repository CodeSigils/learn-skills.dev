NeoData Financial Search — a universal financial data search service using natural language. Query stocks, funds, indices, sectors, macroeconomics, foreign exchange, commodities and other full‑range financial data with natural language, covering market quotes, financial statements (financial reports), capital flows, research reports and ratings, event announcements, etc., supporting two retrieval modes—structured API data and financial articles—for instant question‑and‑answer. Use when the user asks about financial data, stock quotes, financial statements, earnings reports, market data, fund info, macroeconomics, forex, commodities, or needs to query the NeoData API.
