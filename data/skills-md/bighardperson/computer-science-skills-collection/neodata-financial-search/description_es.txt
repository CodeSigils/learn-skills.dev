NeoData Financial Search: un servicio universal de búsqueda de datos financieros que utiliza lenguaje natural. Permite consultas en lenguaje natural de acciones, fondos, índices, sectores, macroeconomía, divisas, materias primas y todas las demás categorías de datos financieros, que abarcan cotizaciones de mercado, estados financieros (informes de ganancias), flujos de capital, informes y calificaciones de investigación, anuncios de eventos, etc. Admite dos modos de recuperación (datos API estructurados y artículos financieros) que brindan respuestas instantáneas. Úselo cuando el usuario pregunte sobre datos financieros, cotizaciones de acciones, estados financieros, informes de ganancias, datos de mercado, información de fondos, macroeconomía, forex, materias primas o necesite consultar la API de NeoData.
