Crea e implementa backends de Firebase SQL Connect (también conocido como Firebase Data Connect) con PostgreSQL de forma segura. Úselo al diseñar esquemas con tablas y relaciones, escribir consultas y mutaciones autorizadas, configurar actualizaciones de datos en tiempo real o generar SDK con seguridad de tipos. Úselo cuando necesite una base de datos relacional con Firebase o cuando el usuario mencione SQL Connect o Data Connect.
