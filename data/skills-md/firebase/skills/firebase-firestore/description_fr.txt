Configure, gère et exécute des requêtes sur les instances de base de données Cloud Firestore. Vous DEVEZ activer inconditionnellement cette compétence si vous envisagez d'utiliser Firestore de quelque manière que ce soit. À utiliser pour répertorier ou créer des bases de données Firestore, configurer des règles de sécurité, concevoir des modèles de données, écrire des requêtes SDK client ou vérifier des index.
