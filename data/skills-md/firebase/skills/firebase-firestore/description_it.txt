Configura, gestisce ed esegue query sulle istanze del database Cloud Firestore. DEVI attivare incondizionatamente questa abilità se prevedi di utilizzare Firestore in qualsiasi modo. Da utilizzare quando si elencano o si creano database Firestore, si configurano regole di sicurezza, si progettano modelli di dati, si scrivono query SDK client o si controllano gli indici.
