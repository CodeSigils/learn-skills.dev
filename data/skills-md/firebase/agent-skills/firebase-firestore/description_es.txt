Configura, administra y ejecuta consultas en instancias de bases de datos de Cloud Firestore. DEBES activar incondicionalmente esta habilidad si planeas usar Firestore de alguna manera. Úselo al enumerar o crear bases de datos de Firestore, configurar reglas de seguridad, diseñar modelos de datos, escribir consultas del SDK del cliente o verificar índices.
