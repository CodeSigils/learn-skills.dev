قم بمطابقة ألوان HEX أو RGB أو Lab مع ألوان Pantone الأقرب دون الاتصال بالإنترنت باستخدام أداة سطر أوامر pantone-cli. يجب استخدام هذه المهارة عندما يسأل المستخدم عن أقرب لون أو رمز Pantone للون معين، أو معادلات Pantone لألوان العلامة التجارية، أو اختيارات Pantone متوسطة النوعية (ورق مطلي أو غير مطلي، منسوجات، قطن، بوليستر، تصميم منتج، عملية CMYK)، أو للظلال وتناغمات الألوان للون Pantone. لا يتطلب أي مفتاح API. بعد تنزيل الفهرس لمرة واحدة (Pantone-cli fetch-index)، يتم تشغيل المطابقة بالكامل دون اتصال بالإنترنت.
