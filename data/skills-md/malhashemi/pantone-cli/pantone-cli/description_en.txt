Match HEX, RGB, or Lab colors to the closest Pantone colors offline using the pantone-cli command-line tool. This skill should be used when a user asks for the closest Pantone color or code for a given color, Pantone equivalents of brand colors, medium-specific Pantone picks (coated or uncoated paper, textiles, cotton, polyester, product design, CMYK process), or for shades and color harmonies of a Pantone color. Requires no API key; after a one-time index download (pantone-cli fetch-index), matching runs fully offline.
