pantone-cli 명령줄 도구를 사용하여 오프라인에서 HEX, RGB 또는 Lab 색상을 가장 가까운 Pantone 색상과 일치시킵니다. 이 기술은 사용자가 특정 색상에 가장 가까운 Pantone 색상 또는 코드, 브랜드 색상의 Pantone 등가물, 매체별 Pantone 선택(코팅 또는 코팅되지 않은 용지, 직물, 면, 폴리에스터, 제품 디자인, CMYK 프로세스) 또는 Pantone 색상의 음영 및 색상 하모니를 요청할 때 사용해야 합니다. API 키가 필요하지 않습니다. 일회성 인덱스 다운로드(pantone-cli fetch-index) 후에 일치는 완전히 오프라인으로 실행됩니다.
