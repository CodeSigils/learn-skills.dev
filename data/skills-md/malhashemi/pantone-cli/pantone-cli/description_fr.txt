Faites correspondre les couleurs HEX, RVB ou Lab aux couleurs Pantone les plus proches hors ligne à l'aide de l'outil de ligne de commande pantone-cli. Cette compétence doit être utilisée lorsqu'un utilisateur demande la couleur ou le code Pantone le plus proche pour une couleur donnée, les équivalents Pantone des couleurs de marque, les choix Pantone spécifiques à un support (papier couché ou non couché, textiles, coton, polyester, conception de produits, processus CMJN), ou les nuances et harmonies de couleurs d'une couleur Pantone. Ne nécessite aucune clé API ; après un téléchargement d'index unique (pantone-cli fetch-index), la correspondance s'exécute entièrement hors ligne.
