SOLO OPZIONAMENTO. ASP.NET Core MVC, Razor, controller, interfaccia utente con rendering server. Da usare SOLO quando l'utente ha scelto esplicitamente o sta creando un'app MVC/Razor/Controllers+Views o aggiunge un progetto Web MVC separato. NON utilizzare solo per API, API minima, REST o src/Api di questo repository (usa dotnet-api-endpoint). NON utilizzare solo perché il progetto è "ASP.NET Core" o "web".
