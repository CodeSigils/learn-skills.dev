Créez des entités de domaine DDD, des racines agrégées, des objets de valeur et des ID fortement typés selon les modèles d'entreprise. À utiliser lorsque l'utilisateur dit « créer une entité », « ajouter un agrégat », « un nouvel objet de valeur », « un modèle de domaine », « un ID fortement typé » ou demande de modéliser des concepts de domaine. Ne PAS utiliser pour les DTO, les modèles de base de données ou les problèmes d'infrastructure.
