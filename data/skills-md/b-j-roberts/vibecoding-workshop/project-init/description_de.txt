Diese Fähigkeit initialisiert neue Softwareprojekte durch einen strukturierten Erkennungs-, Recherche- und Dokumentationsworkflow. Es sollte verwendet werden, wenn der Benutzer ein neues Projekt erstellen/initialisieren, eine neue App starten, eine neue Codebasis aufbauen oder ein neues Softwareprodukt planen möchte. Ausgelöst durch Anfragen wie „Neues Projekt erstellen“, „Neue App initialisieren“, „Neues Projekt für X starten“, „Ich möchte X erstellen“. Der Skill generiert KEINEN Code – er erstellt ein Projektverzeichnis mit umfassender Dokumentation (SPEC.md, STYLES.md, ROADMAP.md), das als Blaupause für die Implementierung dient.
