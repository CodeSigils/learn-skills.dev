Esta habilidad inicializa nuevos proyectos de software a través de un flujo de trabajo estructurado de descubrimiento, investigación y documentación. Debe usarse cuando el usuario desea crear/inicializar un nuevo proyecto, iniciar una nueva aplicación, desarrollar una nueva base de código o planificar un nuevo producto de software. Activado por solicitudes como "crear un nuevo proyecto", "inicializar una nueva aplicación", "iniciar un nuevo proyecto para X", "Quiero construir X". La habilidad NO genera código: produce un directorio de proyecto con documentación completa (SPEC.md, STYLES.md, ROADMAP.md) que sirve como modelo para la implementación.
