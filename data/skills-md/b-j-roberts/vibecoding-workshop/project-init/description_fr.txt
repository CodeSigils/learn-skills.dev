Cette compétence initialise de nouveaux projets logiciels grâce à un flux de travail structuré de découverte, de recherche et de documentation. Il doit être utilisé lorsque l'utilisateur souhaite créer/initialiser un nouveau projet, démarrer une nouvelle application, échafauder une nouvelle base de code ou planifier un nouveau produit logiciel. Déclenché par des requêtes telles que « créer un nouveau projet », « initialiser une nouvelle application », « démarrer un nouveau projet pour X », « Je veux construire X ». La compétence ne génère PAS de code : elle produit un répertoire de projet avec une documentation complète (SPEC.md, STYLES.md, ROADMAP.md) qui sert de modèle de mise en œuvre.
