Этот навык инициализирует новые программные проекты посредством структурированного рабочего процесса открытий, исследований и документации. Его следует использовать, когда пользователь хочет создать/инициализировать новый проект, запустить новое приложение, создать новую кодовую базу или спланировать новый программный продукт. Запускается такими запросами, как «создать новый проект», «инициализировать новое приложение», «начать новый проект для X», «Я хочу построить X». Этот навык НЕ генерирует код — он создает каталог проекта с подробной документацией (SPEC.md, STYLES.md, ROADMAP.md), который служит основой для реализации.
