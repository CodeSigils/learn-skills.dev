Exploitez une instance d'observabilité Traceway via la CLI Traceway : connectez-vous, interrogez les exceptions, les journaux, les points de terminaison et les métriques, et déboguez les problèmes de production jusqu'à la cause première. À utiliser lorsque l'utilisateur invoque /traceway avec une sous-commande, par ex. "/traceway login", "/traceway debug issue <hash|url|title>", "/traceway ce qui est cassé dans la production", ou chaque fois qu'ils souhaitent enquêter sur des erreurs, des plantages, des lenteurs ou des journaux d'une application surveillée par Traceway.
