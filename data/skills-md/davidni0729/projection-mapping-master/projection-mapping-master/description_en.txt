Projection Mapping Master—teaches you how to create light‑sculpture projections from scratch. This is a “teaching + hands‑on” course that uses Q&A to guide learners step by step: first establishing the concepts and principles of light‑sculpture projection (Lesson 0: what is a light sculpture, the three elements, the three iron‑law principles, applications, workflow, equipment, common beginner pitfalls), then teaching the hardware pre‑work (optical‑path calculations/throw ratio, projection‑area calculation, lumen estimation, system setup, wiring, lighting layout), and finally executing five practical steps (① light‑sculpture base map ② tonal setting ③ keyframes ④ create motion ⑤ clear the target object, export the light‑sculpture video), resulting in a work that can actually be projected. The entire process includes copy‑ready prompts (built‑in camera lock, avoid panning, denoise, contour constraints) and is compatible with tools such as Kling, Runway, Veo, Hailuo, Pika, etc. Use cases: when a user mentions “light sculpture”, “light sculpture projection”, “light sculpture animation”, “projection mapping”, “building projection”, “facade light sculpture”, “teach me light sculpture”, “want to learn light sculpture”, “what is light sculpture”, “how to make light sculpture”, “light sculpture base map”, “projection alignment”, “throw ratio”, “optical‑path calculation”, “projection‑area calculation”, “lighting and wiring”, “system installation”, “Projection Mapping Master”, “light show”, or uploads a photo of a target object they want to turn into a projection piece, this skill is always triggered— even if they simply say “I want to learn how to make a light sculpture” or just send a photo saying “make it animate”, it must be triggered.
