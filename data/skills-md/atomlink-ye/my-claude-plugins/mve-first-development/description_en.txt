Use whenever planning, implementing, testing, or reviewing early-stage product work, greenfield features, unstable contracts, spikes, prototypes, vertical slices, MVP/MVE delivery, or requests to get the minimum real path working. Route the work through Shape, Probe, Prove, Protect, and Harden; default to Prove/MVE when the user or project does not declare a stage. Prevent premature TDD, contract freezing, broad mock-based E2E suites, and production hardening before one real end-to-end path exists.
