Навыки единого рабочего процесса отладки для воспроизведения реальных проблем, особенно проблем браузера/UI/Web3, для которых требуется Playwright, общий Chrome/CDP или кошелек агента. Используйте это всякий раз, когда пользователь хочет подтвердить, может ли рабочий процесс воспроизводить реальные проблемы из пошаговых документов, списков проблем, заметок по обеспечению качества или отчетов об ошибках в реальном времени. Начните с индекса отладки, выберите правильный путь и отдайте предпочтение детерминированному локальному воспроизведению хрупким средам предварительного просмотра.
