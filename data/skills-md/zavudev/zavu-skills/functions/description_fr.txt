Créez des fonctions TypeScript sans serveur sur Zavu Cloud — déclarez les agents + les outils dans le code avec DefinAgent / DefineTool, déployez avec « zavu déployer », déboguer avec « exécutions d'agents zavu ». Utilisez cette compétence chaque fois que l'utilisateur souhaite utiliser des agents d'IA basés sur le code, des gestionnaires d'outils personnalisés ou une logique métier basée sur les événements.
