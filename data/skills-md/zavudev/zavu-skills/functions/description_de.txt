Erstellen Sie serverlose TypeScript-Funktionen in der Zavu Cloud – deklarieren Sie Agenten und Tools im Code mit defineAgent / defineTool, stellen Sie sie mit „zavuploy“ bereit, debuggen Sie mit „zavu Agents Executions“. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer codegesteuerte KI-Agenten, benutzerdefinierte Tool-Handler oder ereignisgesteuerte Geschäftslogik wünscht.
