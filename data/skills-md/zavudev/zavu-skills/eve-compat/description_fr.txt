Déployez un agent construit avec le framework eve (eve.dev / Vercel) sur Zavu, ou importez-le directement depuis GitHub avec `npx zavudev import`. Utilisez cette compétence lorsque l'utilisateur a un projet de mise en page eve (agent/instructions.md, agent/tools/*.ts) et souhaite qu'il réponde sur les canaux de messagerie de Zavu, ou demande si une fonctionnalité eve fonctionne sur Zavu.
