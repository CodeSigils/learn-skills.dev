Разверните агент, созданный с помощью eve framework (eve.dev/Vercel), на Zavu или импортируйте его прямо из GitHub с помощью `npx zavudev import`. Используйте этот навык, когда у пользователя есть проект eve-layout (agent/instructions.md, Agent/tools/*.ts) и он хочет, чтобы он отвечал на каналы обмена сообщениями Zavu, или спрашивает, работает ли возможность eve на Zavu.
