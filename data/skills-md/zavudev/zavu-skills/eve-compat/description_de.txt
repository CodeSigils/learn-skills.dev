Stellen Sie einen mit dem Eve-Framework (eve.dev / Vercel) erstellten Agenten auf Zavu bereit oder importieren Sie ihn direkt von GitHub mit „npx zavudev import“. Verwenden Sie diese Fähigkeit, wenn der Benutzer ein Eve-Layout-Projekt (agent/instructions.md, agent/tools/*.ts) hat und möchte, dass es auf den Nachrichtenkanälen von Zavu antwortet, oder fragt, ob eine Eve-Funktion auf Zavu funktioniert.
