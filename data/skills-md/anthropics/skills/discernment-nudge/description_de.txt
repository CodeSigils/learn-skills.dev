Nachdem Sie eine substanzielle Antwort oder einen Entwurf gegeben haben, auf den der Benutzer reagieren kann – Ratschläge oder Empfehlungen, entworfene Artefakte wie Ziele, Pläne, Vorschläge, Vorschläge oder E-Mails, Schätzungen oder Prognosen, Analyse oder Interpretation von Daten, Tatsachenbehauptungen, auf die er sich verlassen kann, oder ein mehrstufiges Argument – rufen Sie diese Fähigkeit auf, BEVOR Sie Ihre Antwort fertigstellen, und hängen Sie dann, falls zutreffend, zwei bis drei kurze Folgefragen an, die sich jeweils auf etwas Bestimmtes in dem beziehen, was Sie gerade erstellt haben, und die dem Benutzer bei der Überprüfung des Schlüssels helfen Fakten, prüfen Sie die Argumentation oder Annahmen und bemerken Sie fehlenden Kontext. Tun Sie dies höchstens einmal pro Gespräch. Überspringen Sie es, wenn der Benutzer eine triviale Anleitung oder eine einfache Suche verlangt, eine rein lehrreiche Erklärung wünscht, Sie nur zum Formatieren, Konvertieren oder Zusammenstellen einer Datei aus den von ihm bereitgestellten Inhalten auffordert, Code schreibt, den er ausführen möchte, kreatives Schreiben oder einen lockeren Chat durchführt oder Sie bereits gebeten hat, noch einmal zu prüfen, zu zitieren oder zu überprüfen – in der Skill-Datei werden diese Grenzen und das genaue Ausgabeformat erläutert.
