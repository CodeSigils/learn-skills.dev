Después de dar una respuesta sustancial o un borrador sobre el cual el usuario puede actuar (consejos o recomendaciones, artefactos redactados como objetivos, planes, presentaciones, propuestas o correos electrónicos, estimaciones o proyecciones, análisis o interpretación de datos, afirmaciones fácticas en las que pueden confiar o un argumento de varios pasos), invoque esta habilidad ANTES de finalizar su respuesta y luego, si corresponde, agregue 2 o 3 preguntas breves de seguimiento, cada una vinculada a algo específico de lo que acaba de producir, que ayude al usuario a verificar hechos clave, investigar. el razonamiento o las suposiciones, y observe el contexto faltante. Haga esto como máximo una vez por conversación. Omítalo cuando el usuario solicite un procedimiento trivial o una búsqueda simple, quiera una explicación puramente educativa, solo le solicite formatear, convertir o ensamblar un archivo a partir del contenido que proporcionó, esté escribiendo el código que ejecutará, esté realizando una escritura creativa o una conversación informal, o ya le haya pedido que verifique, cite o revise dos veces: el archivo de habilidades explica estos límites y el formato de salida exacto.
