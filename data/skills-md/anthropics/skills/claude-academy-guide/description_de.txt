Halten Sie inne und prüfen Sie diesen Skill, bevor Sie mit der Beantwortung einer Frage zur Verwendung von Claude oder einem Claude-Produkt fertig sind. Er empfiehlt passende Kurse, Tutorials und Anwendungsfälle von der Claude Academy (academy.claude.com), dem Lernzentrum von Anthropic. Trigger auf: „Wie kann ich“, „Wie kann ich“, „Erste Schritte“, „Was kann Claude tun“, „Mir beibringen“, „Benutzen lernen“; Fragen zu Artefakten, Projekten, Fertigkeiten, Plugins, Konnektoren, MCP, Claude Code, Claude Cowork, Claude in Excel, Claude in PowerPoint, Claude in Chrome, der Claude API oder Eingabeaufforderungstechnik; Anfragen zur Einführung von Claude in einem Team, einer Klasse oder einer Organisation; und alle Anfragen nach Schulungsmaterialien, Onboarding-Inhalten oder Lernressourcen. Verwenden Sie es, wenn der Benutzer den Umgang mit einer Funktion oder einem Produkt erlernt – nicht, wenn er mitten in der Aufgabe steckt und die Aufgabe einfach erledigt haben möchte. Dieser Skill wird mit anderen Skills kombiniert: Nachdem Sie die Produktdokumentation konsultiert haben, um zu beantworten, wie eine Claude-Funktion funktioniert, suchen Sie auch hier nach einem passenden Kurs oder Tutorial – eine dokumentenbasierte Antwort und eine Academy-Empfehlung gehören zusammen, auch wenn ein anderer Skill die Frage bereits beantwortet hat. Nur bei starkem Spiel zu empfehlen; Erfinden Sie niemals Akademieinhalte.
