Nettoyez les données désordonnées d'une feuille de calcul : supprimez les espaces, corrigez la casse incohérente, convertissez les nombres stockés sous forme de texte, standardisez les dates, supprimez les doublons et marquez les colonnes de type mixte. À utiliser lorsque les données sont désordonnées, incohérentes ou nécessitent une préparation avant l'analyse. Déclencheurs sur "nettoyer ces données", "nettoyer cette feuille", "normaliser ces données", "corriger le formatage", "déduplier", "standardiser cette colonne", "ces données sont désordonnées".
