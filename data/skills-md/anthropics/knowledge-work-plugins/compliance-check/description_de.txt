Führen Sie eine Compliance-Prüfung für eine vorgeschlagene Aktion, Produktfunktion oder Geschäftsinitiative durch und ermitteln Sie dabei geltende Vorschriften, erforderliche Genehmigungen und Risikobereiche. Verwenden Sie diese Funktion, wenn Sie eine Funktion starten, die personenbezogene Daten berührt, wenn Marketing oder Produkt etwas vorschlägt, das regulatorische Auswirkungen hat, oder wenn Sie wissen müssen, welche Genehmigungen und rechtlichen Anforderungen gelten, bevor Sie fortfahren.
