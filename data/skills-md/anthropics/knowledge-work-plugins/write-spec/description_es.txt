Escriba una especificación de característica o PRD a partir de un planteamiento de problema o idea de característica. Úselo para convertir una idea vaga o una solicitud de un usuario en un documento estructurado, definir el alcance de una característica con objetivos y no objetivos, definir métricas de éxito y criterios de aceptación, o dividir una gran solicitud en una especificación por fases.
