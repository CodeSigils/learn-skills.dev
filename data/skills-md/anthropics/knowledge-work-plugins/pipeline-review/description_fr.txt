Analysez la santé du pipeline : hiérarchisez les transactions, signalez les risques et obtenez un plan d'action hebdomadaire. À utiliser pour effectuer un examen hebdomadaire du pipeline, décider sur quelles transactions se concentrer cette semaine, repérer les opportunités obsolètes ou bloquées, auditer les problèmes d'hygiène tels que les mauvaises dates de clôture ou identifier les transactions à thread unique.
