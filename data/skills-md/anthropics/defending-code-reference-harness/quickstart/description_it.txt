La porta d'ingresso per questo repository. Senza discussioni: un'introduzione di 30 secondi, poi un'offerta per guidarti nella tua prima corsa sul bersaglio canarino. Con una domanda: risponde dai documenti e dalla fonte di questo repository, cita dove è apparso e ti passa il comando successivo. Utilizzare per "come faccio...", "perché...", "dov'è...", "può questo..." o semplicemente "/quickstart" per orientarsi.
