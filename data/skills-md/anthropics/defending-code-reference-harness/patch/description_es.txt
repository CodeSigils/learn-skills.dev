Genere correcciones candidatas para hallazgos de seguridad verificados. Consume TRIAGE.json (preferido), VULN-FINDINGS.json o un directorio de resultados de vuln-pipeline. La entrada de la canalización se delega a la escalera de ejecución "vuln-pipeline patch" verificada; La entrada de análisis estático obtiene un subagente de parche por hallazgo + un revisor independiente y está escrita como diferencias inertes para revisión humana. Escribe PATCHES/bug_NN/{patch.diff,patch_result.json}, PATCHES.md y PATCHES.json. Úselo cuando se le solicite "arreglar los hallazgos", "parchear estas vulnerabilidades", "generar correcciones" o "cerrar el ciclo de clasificación".
