Создавайте возможные исправления для проверенных результатов безопасности. Использует TRIAGE.json (предпочтительно), VULN-FINDINGS.json или каталог результатов vuln-pipeline. Входные данные конвейера делегируются проверенной на выполнение лестнице `vuln-pipeline patch`; Входные данные статического анализа получают субагент исправления для каждого обнаружения + независимый рецензент и записываются в виде инертных различий для проверки человеком. Записывает PATCHES/bug_NN/{patch.diff,patch_result.json}, PATCHES.md и PATCHES.json. Используйте, когда вас просят «исправить результаты», «исправить эти уязвимости», «создать исправления» или «замкнуть цикл сортировки».
