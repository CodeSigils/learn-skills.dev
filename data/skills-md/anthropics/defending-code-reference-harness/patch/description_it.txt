Genera correzioni candidate per risultati di sicurezza verificati. Utilizza TRIAGE.json (preferito), VULN-FINDINGS.json o una directory dei risultati vuln-pipeline. L'input della pipeline è delegato alla ladder `vuln-pipeline patch` con esecuzione verificata; L'input dell'analisi statica ottiene un subagente patch per ricerca + un revisore indipendente ed è scritto come differenze inerti per la revisione umana. Scrive PATCHES/bug_NN/{patch.diff,patch_result.json}, PATCHES.md e PATCHES.json. Da utilizzare quando viene richiesto di "correggere i risultati", "patchare queste vulnerabilità", "generare correzioni" o "chiudere il ciclo del triage".
