検証されたセキュリティ結果に対して修正候補を生成します。 TRIAGE.json (推奨)、VULN-FINDINGS.json、または vuln-pipeline 結果ディレクトリを使用します。パイプライン入力は、実行が検証された「vuln-pipeline patch」ラダーに委任されます。静的分析入力は、検出パッチごとのサブエージェントと独立したレビュー担当者を取得し、人間によるレビューのために不活性な差分として書き込まれます。 PATCHES/bug_NN/{patch.diff,patch_result.json}、PATCHES.md、および PATCHES.json を書き込みます。 「検出結果を修正する」、「これらの脆弱性にパッチを適用する」、「修正を生成する」、または「トリアージのループを閉じる」ように求められた場合に使用します。
