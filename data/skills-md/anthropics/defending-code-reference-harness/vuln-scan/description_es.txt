Escaneo de vulnerabilidades del código fuente estático. Lee un directorio de destino (y THREAT_MODEL.md si está presente), genera subagentes de revisión paralelos por área de enfoque y escribe VULN-FINDINGS.json + .md para que /triage lo consuma. Solo lectura: sin construcción, ejecución ni red. Para fallas verificadas en la ejecución, use vuln-pipeline en su lugar. Úselo cuando se le solicite "buscar vulnerabilidades", "revisar este código para detectar problemas de seguridad", "buscar errores en <dir>" o como paso entre /threat-model y /triage.
