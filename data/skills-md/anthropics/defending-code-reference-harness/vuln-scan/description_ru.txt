Статическое сканирование исходного кода на уязвимости. Считывает целевой каталог (и THREAT_MODEL.md, если он есть), создает субагенты параллельной проверки для каждой области внимания и записывает VULN-FINDINGS.json + .md для /triage для использования. Только для чтения — без создания, работы или сети. Для сбоев с проверкой выполнения вместо этого используйте vuln-pipeline. Используйте, когда вас просят «сканировать уязвимости», «проверить этот код на наличие проблем безопасности», «найти ошибки в <dir>» или в качестве шага между /threat-model и /triage.
