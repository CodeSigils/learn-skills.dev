Analyse statique des vulnérabilités du code source. Lit un répertoire cible (et THREAT_MODEL.md s'il est présent), génère des sous-agents de révision parallèles par zone d'intervention et écrit VULN-FINDINGS.json + .md pour /triage à consommer. Lecture seule : pas de création, d'exécution ou de réseau. Pour les plantages vérifiés par l'exécution, utilisez plutôt vuln-pipeline. À utiliser lorsqu'on vous demande de « rechercher des vulnérabilités », « examiner ce code pour des problèmes de sécurité », « trouver des bogues dans <dir> », ou comme étape entre /threat-model et /triage.
