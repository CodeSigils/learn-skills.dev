Statischer Schwachstellenscan im Quellcode. Liest ein Zielverzeichnis (und THREAT_MODEL.md, falls vorhanden), erzeugt parallele Überprüfungs-Subagenten pro Fokusbereich und schreibt VULN-FINDINGS.json + .md für die Nutzung durch /triage. Schreibgeschützt – kein Erstellen, Ausführen oder Netzwerken. Für ausführungsverifizierte Abstürze verwenden Sie stattdessen vuln-pipeline. Wird verwendet, wenn Sie aufgefordert werden, „nach Schwachstellen zu suchen“, „diesen Code auf Sicherheitsprobleme zu überprüfen“, „Fehler in <Verzeichnis> zu finden“ oder als Schritt zwischen /threat-model und /triage.
