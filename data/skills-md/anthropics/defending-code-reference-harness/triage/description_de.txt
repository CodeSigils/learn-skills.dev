Selektieren Sie eine Reihe roher Sicherheitsergebnisse. Stellen Sie sicher, dass alle Elemente echt sind, reduzieren Sie Duplikate, ordnen Sie sie nach abgeleiteter Ausnutzbarkeit neu und kennzeichnen Sie sie mit einem Besitzer. Nimmt ein Verzeichnis oder eine Datei mit der Scannerausgabe und schreibt TRIAGE.json + TRIAGE.md, sortiert nach dem, was tatsächlich technischer Aufmerksamkeit bedarf. Wird verwendet, wenn Sie aufgefordert werden, „Befunde zu selektieren“, „Scanner-Ausgaben zu validieren“, „Schwachstellen zu priorisieren“ oder „den Rückstand zu überprüfen“. Wird standardmäßig interaktiv ausgeführt; pass --auto, um das Interview zu überspringen.
