Отсортируйте пакет необработанных результатов безопасности. Убедитесь, что каждый из них настоящий, сверните дубликаты, измените рейтинг по полученной возможности использования и отметьте владельца. Берет каталог или файл результатов сканирования и записывает TRIAGE.json + TRIAGE.md, отсортированный по тому, что действительно требует инженерного внимания. Используйте, когда вас просят «сортировать результаты», «проверить результаты сканирования», «приоритизировать уязвимости» или «просмотреть невыполненную работу». По умолчанию работает в интерактивном режиме; pass --auto, чтобы пропустить интервью.
