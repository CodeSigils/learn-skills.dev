Valuta una serie di risultati grezzi sulla sicurezza. Verifica che ciascuno sia reale, comprimi i duplicati, riclassifica in base alla sfruttabilità derivata e tagga con un proprietario. Prende una directory o un file di output dello scanner e scrive TRIAGE.json + TRIAGE.md ordinati in base a ciò che effettivamente necessita di attenzione ingegneristica. Da utilizzare quando viene richiesto di "triage dei risultati", "convalidare l'output dello scanner", "dare priorità alle vulnerabilità" o "esaminare il backlog". Funziona in modo interattivo per impostazione predefinita; pass --auto per saltare l'intervista.
