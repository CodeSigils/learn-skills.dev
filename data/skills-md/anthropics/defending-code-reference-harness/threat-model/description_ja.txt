ターゲットコードベースの脅威モデルを構築します。 3 つのモード: 「インタビュー」では、アプリケーション所有者に 4 つの質問フレームワークを説明し、回答から脅威モデルを作成します。 「ブートストラップ」は、所有者がいない場合、コードと過去の脆弱性 (CVE、git 履歴、侵入テスト レポート) から脅威モデルを導き出します。所有者とコードベースの両方が存在する場合、「bootstrap-then-interview」は 2 つを連鎖させます。すべてが共有スキーマに THREAT_MODEL.md を書き込みます。 「脅威モデル」、「脅威モデルの構築」、「攻撃対象領域のマッピング」、または「このコードベースで何を心配すべきか」を求められた場合に使用します。
