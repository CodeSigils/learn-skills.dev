Erstellen Sie ein Bedrohungsmodell für eine Zielcodebasis. Drei Modi: „Interview“ führt einen Anwendungseigentümer durch das Vier-Fragen-Framework und erstellt aus seinen Antworten ein Bedrohungsmodell; „bootstrap“ leitet ein Bedrohungsmodell aus dem Code und früheren Schwachstellen (CVEs, Git-Verlauf, Pentest-Berichte) ab, wenn kein Eigentümer verfügbar ist; „bootstrap-then-interview“ verkettet die beiden, wenn sowohl Eigentümer als auch Codebasis vorhanden sind. Alle schreiben THREAT_MODEL.md in ein gemeinsames Schema. Verwenden Sie diese Option, wenn Sie nach „Bedrohungsmodell“, „Erstellen eines Bedrohungsmodells“, „Kartierung der Angriffsfläche“ oder „Worüber sollten wir uns in dieser Codebasis Sorgen machen“ gefragt werden.
