Créez un modèle de menace pour une base de code cible. Trois modes : « entretien » guide le propriétaire de l'application à travers le cadre de quatre questions et produit un modèle de menace à partir de ses réponses ; « bootstrap » dérive un modèle de menace à partir du code et des vulnérabilités passées (CVE, historique git, rapports pentest) lorsqu'aucun propriétaire n'est disponible ; "bootstrap-then-interview" enchaîne les deux lorsque le propriétaire et la base de code sont présents. Tous écrivent THREAT_MODEL.md dans un schéma partagé. À utiliser lorsqu'on vous demande de « modèle de menace », « créer un modèle de menace », « cartographier la surface d'attaque » ou « de quoi devrions-nous nous inquiéter dans cette base de code ».
