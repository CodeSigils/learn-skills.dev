Создайте модель угроз для целевой базы кода. Три режима: «интервью» знакомит владельца приложения с системой из четырех вопросов и на основе его ответов создает модель угроз; «начальная загрузка» извлекает модель угроз из кода плюс прошлые уязвимости (CVE, история git, отчеты о пентестах), когда владелец недоступен; «bootstrap-then-interview» связывает их в цепочку, когда присутствуют и владелец, и кодовая база. Все пишут THREAT_MODEL.md в общей схеме. Используйте, когда вас просят «модель угроз», «построить модель угроз», «составить карту поверхности атаки» или «о чем нам следует беспокоиться в этой кодовой базе».
