Cree un modelo de amenaza para una base de código de destino. Tres modos: "entrevista" guía al propietario de una aplicación a través del marco de cuatro preguntas y produce un modelo de amenaza a partir de sus respuestas; "bootstrap" deriva un modelo de amenaza a partir del código más vulnerabilidades pasadas (CVE, historial de git, informes pentest) cuando no hay ningún propietario disponible; "bootstrap-then-interview" encadena los dos cuando tanto el propietario como el código base están presentes. Todos escriben THREAT_MODEL.md en un esquema compartido. Úselo cuando se le solicite "modelo de amenaza", "construir un modelo de amenaza", "mapear la superficie de ataque" o "qué debería preocuparnos en este código base".
