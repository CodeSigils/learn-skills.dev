Cette compétence doit être utilisée lorsque l'utilisateur souhaite créer une « application MCP », ajouter une « interface utilisateur interactive » ou des « widgets » à un serveur MCP, « restituer des composants dans le chat », créer des « ressources d'interface utilisateur MCP », créer un outil qui affiche un « formulaire », un « sélecteur », un « tableau de bord » ou une « boîte de dialogue de confirmation » en ligne dans la conversation, ou mentionne le « SDK d'applications » dans le contexte de MCP. À utiliser APRÈS que la compétence build-mcp-server ait défini le modèle de déploiement ou lorsque l'utilisateur sait déjà qu'il souhaite des widgets d'interface utilisateur.
