このスキルは、ユーザーが「MCP アプリ」を構築する場合、「インタラクティブ UI」または「ウィジェット」を MCP サーバーに追加する場合、「チャットでコンポーネントをレンダリングする」場合、「MCP UI リソース」を構築する場合、会話内でインラインで「フォーム」、「ピッカー」、「ダッシュボード」または「確認ダイアログ」を表示するツールを作成する場合、または MCP のコンテキストで「アプリ SDK」について言及する場合に使用する必要があります。 build-mcp-server スキルがデプロイメント モデルを決定した後、またはユーザーが UI ウィジェットが必要であるとすでにわかっている場合に使用します。
