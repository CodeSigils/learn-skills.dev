Diese Fähigkeit sollte verwendet werden, wenn der Benutzer eine „MCP-App“ erstellen, „interaktive Benutzeroberfläche“ oder „Widgets“ zu einem MCP-Server hinzufügen, „Komponenten im Chat rendern“, „MCP-UI-Ressourcen“ erstellen, ein Tool erstellen möchte, das ein „Formular“, „Auswahl“, „Dashboard“ oder „Bestätigungsdialog“ inline in der Konversation anzeigt oder „Apps SDK“ im Kontext von MCP erwähnt. Verwenden Sie diese Option, NACHDEM der Build-mcp-server-Skill das Bereitstellungsmodell festgelegt hat oder wenn der Benutzer bereits weiß, dass er UI-Widgets benötigt.
