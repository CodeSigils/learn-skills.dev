Этот навык следует использовать, когда пользователь хочет «упаковать сервер MCP», «связать MCP», «создать MCPB», «отправить локальный сервер MCP», «распространить локальный MCP», обсуждает «файлы .mcpb», упоминает объединение среды выполнения Node или Python со своим сервером MCP или нуждается в сервере MCP, который взаимодействует с локальной файловой системой, настольными приложениями или ОС и должен быть установлен без установки пользователем Node/Python. вверх.
