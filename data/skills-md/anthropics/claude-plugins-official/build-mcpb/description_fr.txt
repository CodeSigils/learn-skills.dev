Cette compétence doit être utilisée lorsque l'utilisateur souhaite « empaqueter un serveur MCP », « regrouper un MCP », « créer un MCPB », « expédier un serveur MCP local », « distribuer un MCP local », discute des « fichiers .mcpb », mentionne le regroupement d'un environnement d'exécution Node ou Python avec son serveur MCP, ou a besoin d'un serveur MCP qui interagit avec le système de fichiers local, les applications de bureau ou le système d'exploitation et doit être installable sans que l'utilisateur ait configuré Node/Python.
