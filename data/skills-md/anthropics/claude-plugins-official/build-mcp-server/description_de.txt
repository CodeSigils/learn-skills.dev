Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „einen MCP-Server erstellen“, „einen MCP erstellen“, „eine MCP-Integration erstellen“, „eine API für Claude umschließen“, „Tools für Claude verfügbar machen“, „eine MCP-App erstellen“ auffordert oder den Aufbau von etwas mit dem Model Context Protocol bespricht. Es ist der Einstiegspunkt für die MCP-Serverentwicklung – es befragt den Benutzer zu seinem Anwendungsfall, bestimmt das richtige Bereitstellungsmodell (Remote-HTTP, MCPB, lokales Stdio), wählt ein Tool-Design-Muster aus und übergibt es an spezielle Fähigkeiten.
