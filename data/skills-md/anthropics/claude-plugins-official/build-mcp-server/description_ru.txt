Этот навык следует использовать, когда пользователь просит «создать сервер MCP», «создать MCP», «сделать интеграцию MCP», «создать API для Клода», «открыть инструменты для Клода», «создать приложение MCP» или обсуждает создание чего-либо с помощью протокола контекста модели. Это отправная точка для разработки сервера MCP — он опрашивает пользователя об их сценарии использования, определяет правильную модель развертывания (удаленный HTTP, MCPB, локальное стандартное оборудование), выбирает шаблон проектирования инструментов и передает его специализированным специалистам.
