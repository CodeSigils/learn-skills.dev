يجب استخدام هذه المهارة عندما يطلب المستخدم "إنشاء خادم MCP" أو "إنشاء MCP" أو "إجراء تكامل MCP" أو "تغليف واجهة برمجة التطبيقات لكلود" أو "كشف الأدوات لكلود" أو "إنشاء تطبيق MCP" أو مناقشة إنشاء شيء ما باستخدام بروتوكول السياق النموذجي. إنها نقطة الدخول لتطوير خادم MCP - فهي تستجوب المستخدم حول حالة الاستخدام الخاصة به، وتحدد نموذج النشر الصحيح (عن بعد HTTP، وMCPB، وstdio المحلي)، وتختار نمط تصميم الأداة، وتنتقل إلى المهارات المتخصصة.
