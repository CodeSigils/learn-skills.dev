Cette compétence doit être utilisée lorsque l'utilisateur demande de « créer un serveur MCP », « créer un MCP », « faire une intégration MCP », « envelopper une API pour Claude », « exposer des outils à Claude », « créer une application MCP » ou discute de la création de quelque chose avec le protocole de contexte de modèle. C'est le point d'entrée pour le développement du serveur MCP : il interroge l'utilisateur sur son cas d'utilisation, détermine le bon modèle de déploiement (HTTP distant, MCPB, stdio local), choisit un modèle de conception d'outils et confie à des compétences spécialisées.
