Investiga una tarea o conversación de Jira o Slack. Obtenga contexto de tickets de Jira, subprocesos de Slack, trabajos anteriores y el código base para comprender un problema y planificar los próximos pasos. Esta habilidad se debe utilizar cuando se le pide que investigue, analice o recopile contexto sobre una clave de Jira, una URL de Jira o una URL de hilo/mensaje de Slack.
