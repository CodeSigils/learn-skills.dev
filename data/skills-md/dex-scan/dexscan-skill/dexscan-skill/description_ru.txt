Используйте этот навык для получения рыночных данных внутри сети: информации о рынке токенов, рейтингов ведущих трейдеров, социального ажиотажа, сигналов.  
**Триггерные сценарии**:  
- Пользователь упоминает dexscan  
- Пользователь указывает рыночные данные токена, цену, рыночную капитализацию, объем торгов, ликвидность, процент изменения цены, количество адресов хранения токенов.  
- Пользователь упоминает сигналы токена, начальное нажатие сигнала, максимальное усиление, нажатие сигнала.  
- Пользователь упоминает шумиху вокруг токенов, рейтинг популярности, обсуждения KOL.  
- Пользователь упоминает умные деньги и рейтинги топ-трейдеров.
