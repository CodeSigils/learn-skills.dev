Utilizza questa capacità ogni volta che è coinvolto un file .pptx: come input, output o entrambi. Ciò include: creazione di slide deck, pitch deck o presentazioni; leggere, analizzare o estrarre testo da qualsiasi file .pptx; modificare, modificare o aggiornare presentazioni esistenti; combinare o dividere file di diapositive; lavorare con modelli, layout, note del relatore o commenti. Si attiva ogni volta che l'utente menziona "deck", "slides", "presentation", "pitch" o fa riferimento a un nome di file .pptx.
