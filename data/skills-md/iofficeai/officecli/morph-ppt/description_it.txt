Utilizza questa funzionalità quando l'utente desidera un file .pptx con animazioni fluide tra diapositive: transizioni PowerPoint Morph, movimento continuo in stile Keynote, forme che crescono/si muovono/ruotano man mano che la diapositiva avanza. Attivazione su: 'morph', 'transizione morph', 'transizione fluida', 'animazione continua tra diapositive', 'transizione in stile Keynote', 'sequenza di diapositive animate', 'continuità della forma tra diapositive'. L'output è un singolo file .pptx. Questa abilità è un livello di scena sopra officecli-pptx: eredita ogni regola pptx v2 (pavimento visivo, griglia, tavolozze, canone del connettore, Delivery Gate 1–5a). NON invocare un mazzo generico, un pitch deck o una revisione del tabellone senza movimento di scorrimento incrociato: indirizzali a officecli-pptx base o officecli-pitch-deck.
