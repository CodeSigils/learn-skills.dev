Используйте этот навык для создания заполняемых форм Word (.docx) с реальными элементами управления содержимым (SDT) + устаревшими флажками FormField + заполнителями для слияния почты MERGEFIELD + защитой документов. Запуск по: «заполняемая форма», «поля формы», «элементы управления содержимым», «SDT», «словоформа», «заполнение», «только редактируемые поля», «защита документа», «форма адаптации», «прием кадров», «шаблон опроса», «шаблон контракта/ТЗ», «шаблон слияния почты», «контрольный список соответствия», «анкета приема на медицинское обслуживание». Выходные данные представляют собой один файл .docx, в котором определенные поля доступны для редактирования, а остальные заблокированы. Этот навык НЕЗАВИСИМ, а не слой сцены в docx — полезная нагрузка равна `<w:sdt>` + `<w:ffData>` + `<w:fldChar>` + `documentProtection`, ни один из которых не охватывает базовый навык docx. НЕ запускайте запуск для обычных отчетов, писем, заметок, научных статей, презентаций или любых документов без полей, заполняемых пользователем — направляйте их в Officecli-docx или его слои сцены.
