Utilice esta habilidad cada vez que se trate de un archivo .docx, como entrada, salida o ambos. Esto incluye: crear documentos, informes, cartas, memorandos o propuestas de Word; leer, analizar o extraer texto de cualquier archivo .docx; editar, modificar o actualizar documentos existentes; trabajar con plantillas, seguimiento de cambios, comentarios, encabezados/pies de página o tablas de contenido. Se activa cada vez que el usuario menciona "documento de Word", "documento", "informe", "carta", "nota" o hace referencia a un nombre de archivo .docx.
