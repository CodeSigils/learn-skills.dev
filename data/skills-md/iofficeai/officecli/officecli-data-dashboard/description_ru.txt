Используйте этот навык для создания многоэлементной информационной панели Excel — листа информационной панели на открытых, нескольких карточках ключевых показателей эффективности на основе формул, нескольких диаграмм, спарклайнов и условного форматирования — из CSV или табличных данных. Запуск по: «панель мониторинга», «панель мониторинга ключевых показателей эффективности», «панель аналитики», «панель мониторинга для руководителей», «панель мониторинга показателей», «CSV на панель мониторинга», «визуализация данных». Вывод представляет собой один файл .xlsx. Слой сцены в Officecli-xlsx: наследует все жесткие правила xlsx. НЕ ИСПОЛЬЗУЙТЕ: единый трекер бюджета/один лист в формате CSV с форматированием (используйте xlsx), финансовую модель с тремя отчетами/DCF/LBO (используйте финансовую модель), еженедельный отчет с ≤ 1 диаграммой и < 10 строками (используйте xlsx).
