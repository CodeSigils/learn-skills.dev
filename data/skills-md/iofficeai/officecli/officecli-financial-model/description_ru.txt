Используйте этот навык, когда пользователь хочет построить финансовую модель — модель с тремя отчетами, оценку DCF, LBO, экономику подразделения SaaS, анализ чувствительности/сценария, график долга или прогнозы по сбору средств — в Excel. Запуск по: «финансовая модель», «модель с тремя отчетами», «P&L + BS + CF», «DCF», «WACC», «NPV», «терминальная стоимость», «LBO», «график долга», «обыск», «MOIC», «IRR / XIRR», «таблица чувствительности», «сценарный анализ», «модель ARR», «единичная экономика», «CAC / LTV», «прогноз таблицы капитализации». Выходные данные представляют собой единый файл .xlsx на основе формулы. Этот навык представляет собой слой сцены поверх Officecli-xlsx — он наследует все правила xlsx v2 (4-цветный код, визуальный уровень, числовые форматы, дрейф кэша, известные проблемы, минимальный цикл доставки). НЕ ИСПОЛЬЗУЙТЕ простой трекер бюджета, дамп CSV или операционную таблицу KPI — направьте их в базу Officecli-xlsx.
