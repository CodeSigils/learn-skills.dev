استخدم هذه المهارة عندما يريد المستخدم إنشاء نموذج مالي - نموذج مكون من 3 بيانات، أو تقييم DCF، أو LBO، أو اقتصاديات وحدة SaaS، أو تحليل الحساسية/السيناريو، أو جدول الديون، أو توقعات جمع الأموال - في Excel. تفعيل: "النموذج المالي"، "نموذج البيانات الثلاثة"، "الربح والخسارة + BS + CF"، "DCF"، "WACC"، "NPV"، "القيمة النهائية"، "LBO"، "جدول الديون"، "الاكتساح النقدي"، "MOIC"، "IRR / XIRR"، "جدول الحساسية"، "تحليل السيناريو"، "نموذج ARR"، "اقتصاديات الوحدة"، "CAC / LTV، "توقعات جدول الحد الأقصى". الإخراج هو .xlsx يحركه صيغة واحدة. هذه المهارة عبارة عن طبقة مشهد أعلى officecli-xlsx - فهي ترث كل قاعدة xlsx v2 (رمز ذو 4 ألوان، والأرضية المرئية، وتنسيقات الأرقام، وانجراف ذاكرة التخزين المؤقت، والمشكلات المعروفة، والحد الأدنى لدورة بوابة التسليم). لا تستدعي أداة تعقب بسيطة للميزانية، أو تفريغ ملف CSV، أو ورقة مؤشرات الأداء الرئيسية التشغيلية - قم بتوجيهها إلى قاعدة officecli-xlsx.
