Generieren oder ändern Sie Quicker-Action-JSON-Dateien anhand von Benutzeranforderungen, indem Sie den gebündelten Schrittdefinitions-Markdown verwenden, der aus Quicker-Action-Dokumenten konvertiert wurde. Verwenden Sie diese Option, wenn Codex einen neuen Aktions-JSON erstellen, einen vorhandenen Aktions-JSON überarbeiten, erklären muss, welche integrierten Quicker-Schritte zu einer Anforderung passen, oder eine Quicker-Injector-Aktion direkt aus der aktuellen Umgebung ausführen muss, um den JSON in eine andere Aktion einzuschleusen. Wenn die Anforderungen unzureichend spezifiziert sind, aber die Codegenerierung das Ziel ist, stellen Sie nacheinander nummerierte Klärungsfragen mit beschrifteten Optionen und einer empfohlenen Antwort. Wenn lokale Verweise nicht ausreichen, konsultieren Sie die offizielle Quicker-Hilfe-URL, die im entsprechenden Dokument aufgeführt ist, bevor Sie den Benutzer fragen.
