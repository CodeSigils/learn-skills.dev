Générez ou modifiez des fichiers JSON d'action plus rapide à partir des exigences des utilisateurs, à l'aide de la démarque de définition d'étape groupée convertie à partir de documents d'action plus rapide. À utiliser lorsque le Codex doit créer une nouvelle action JSON, réviser une action JSON existante, expliquer quelles étapes intégrées Quicker correspondent à une exigence ou exécuter directement une action d'injection Quicker à partir de l'environnement actuel pour injecter le JSON dans une autre action. Lorsque les exigences sont sous-spécifiées mais que l'objectif est la génération de code, posez des questions de clarification numérotées une par une avec des options écrites et une réponse recommandée. Si les références locales sont insuffisantes, consultez l'URL d'aide officielle de Quicker enregistrée dans le document concerné avant de demander à l'utilisateur.
