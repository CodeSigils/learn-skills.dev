Genera o modifica file JSON di azioni Quicker in base ai requisiti dell'utente, utilizzando il markdown della definizione dei passaggi in bundle convertito dai documenti di azioni Quicker. Da utilizzare quando Codex deve creare una nuova azione JSON, rivedere un'azione JSON esistente, spiegare quali passaggi integrati Quicker soddisfano un requisito o eseguire direttamente un'azione di iniezione Quicker dall'ambiente corrente per inserire il JSON in un'altra azione. Quando i requisiti sono sottospecificati ma l'obiettivo è la generazione del codice, porre domande di chiarimento numerate una alla volta con opzioni tramite lettere e una risposta consigliata. Se i riferimenti locali non sono sufficienti, consultare l'URL ufficiale della guida Quicker registrata nel relativo documento prima di chiedere all'utente.
