قم بإنشاء ملفات JSON للإجراء الأسرع أو تعديلها من متطلبات المستخدم، باستخدام تخفيض تعريف الخطوة المجمعة المحول من مستندات الإجراء السريع. يُستخدم عندما يحتاج Codex إلى إنشاء إجراء JSON جديد، أو مراجعة إجراء JSON موجود، أو شرح الخطوات المضمنة الأسرع التي تناسب أحد المتطلبات، أو تشغيل إجراء حاقن أسرع مباشرةً من البيئة الحالية لإدخال JSON في إجراء آخر. عندما تكون المتطلبات غير محددة بشكل كافٍ ولكن إنشاء التعليمات البرمجية هو الهدف، اطرح أسئلة توضيحية مرقمة واحدًا تلو الآخر مع خيارات مكتوبة بالحروف وإجابة موصى بها. إذا كانت المراجع المحلية غير كافية، فاستشر عنوان URL الرسمي للمساعدة السريعة المسجل في المستند ذي الصلة قبل سؤال المستخدم.
