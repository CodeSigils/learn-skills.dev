Quicker アクション ドキュメントから変換されたバンドルされたステップ定義マークダウンを使用して、ユーザー要件から Quicker アクション JSON ファイルを生成または変更します。 Codex が新しいアクション JSON を作成する必要がある場合、既存のアクション JSON を修正する必要がある場合、どの Quicker 組み込みステップが要件に適合するかを説明する場合、または現在の環境から Quicker インジェクター アクションを直接実行して JSON を別のアクションに挿入する必要がある場合に使用します。要件が十分に指定されていないが、コード生成が目的である場合は、文字付きの選択肢と推奨される回答を使用して、番号付きの明確な質問を一度に 1 つずつ尋ねます。ローカル参照が不十分な場合は、ユーザーに問い合わせる前に、関連ドキュメントに記録されている公式 Quicker ヘルプ URL を参照してください。
