Genere o modifique archivos JSON de acción de Quicker a partir de los requisitos del usuario, utilizando el descuento de definición de pasos incluido convertido de documentos de acción de Quicker. Úselo cuando Codex necesite crear un nuevo JSON de acción, revisar un JSON de acción existente, explicar qué pasos integrados de Quicker se ajustan a un requisito o ejecutar directamente una acción de inyector Quicker desde el entorno actual para inyectar el JSON en otra acción. Cuando los requisitos no están especificados pero el objetivo es la generación de código, haga preguntas aclaratorias numeradas, una a la vez, con opciones con letras y una respuesta recomendada. Si las referencias locales son insuficientes, consulte la URL de ayuda oficial de Quicker registrada en el documento correspondiente antes de preguntar al usuario.
