قم بإنشاء نماذج وأنسجة وصور وشخصيات ثلاثية الأبعاد وتحريكها باستخدام Meshy AI API. يتعامل مع اكتشاف مفتاح واجهة برمجة التطبيقات (API)، وإعداده، وجميع مسارات عمل الإنشاء عبر مكالمات HTTP المباشرة. يُستخدم عندما يطلب المستخدم إنشاء نماذج ثلاثية الأبعاد، أو تحويل نص/صور إلى نماذج ثلاثية الأبعاد، أو نماذج نسيج، أو تجهيز أو تحريك الشخصيات، أو التفاعل مع Meshy API.
