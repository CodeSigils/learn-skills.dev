قم بإنشاء نماذج وأنسجة وصور وشخصيات ثلاثية الأبعاد وتحريكها والاستعداد للطباعة ثلاثية الأبعاد باستخدام Meshy AI API. يتعامل مع اكتشاف مفتاح واجهة برمجة التطبيقات (API)، وإنشاء المهام، والاستقصاء، والتنزيل، وخط أنابيب الطباعة ثلاثي الأبعاد الكامل مع تكامل أداة التقطيع. يُستخدم عندما يطلب المستخدم إنشاء نماذج ثلاثية الأبعاد، أو تحويل نص/صور إلى نماذج ثلاثية الأبعاد، أو نماذج نسيج، أو تجهيز أو تحريك الشخصيات، أو طباعة نموذج ثلاثي الأبعاد، أو التفاعل مع Meshy API. بالنسبة لـ Claude Code أو Cursor، استخدم مهارات الجيل الشبكي ثلاثي الأبعاد والطباعة الشبكية ثلاثية الأبعاد بدلاً من ذلك.
