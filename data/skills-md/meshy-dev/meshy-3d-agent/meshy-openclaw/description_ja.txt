Meshy AI API を使用して 3D モデル、テクスチャ、画像、リグ キャラクターを生成し、アニメーション化し、3D プリントの準備をします。 API キーの検出、タスクの作成、ポーリング、ダウンロード、およびスライサー統合による完全な 3D プリント パイプラインを処理します。ユーザーが 3D モデルの作成、テキスト/画像の 3D への変換、テクスチャ モデル、キャラクターのリグまたはアニメート、モデルの 3D プリント、または Meshy API との対話を要求する場合に使用します。クロード コードまたはカーソルの場合は、代わりにメッシュ 3D 生成スキルとメッシュ 3D プリント スキルを使用してください。
