Obtenez les types de chambres et les forfaits tarifaires pour un hôtel spécifique. Utilisez cette compétence après la recherche d'hôtel lorsque l'utilisateur souhaite explorer les options de chambre, consulter différents plans tarifaires, comparer les plans de repas (petit-déjeuner inclus ou non), vérifier le remboursement ou choisir une chambre spécifique avant de réserver. Se déclenche sur des expressions telles que « montre-moi les chambres de l'hôtel X », « quels types de chambres sont disponibles », « Je veux un plan tarifaire différent », « le petit-déjeuner est-il inclus ».
