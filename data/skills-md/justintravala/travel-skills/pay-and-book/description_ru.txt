Сквозное бронирование отелей с оплатой на кошелек USDC. Используйте, когда пользователь хочет, чтобы агент искал, бронировал и оплачивал отель в одном автономном потоке — такие фразы, как «забронируйте мне отель в Токио и оплатите с помощью USDC», «найдите место в Париже и заплатите из моего кошелька», «обработайте все бронирование на следующую неделю». Организует: поиск → выберите → аутентифицируйте кошелек → пополните баланс, если необходимо → оплатите через x402 → подтвердите. НЕ используйте для бронирования только для поиска, только для оплаты или бронирования, не связанного с отелем.
