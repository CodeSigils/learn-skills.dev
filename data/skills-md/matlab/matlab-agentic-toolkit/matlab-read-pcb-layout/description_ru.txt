Импортируйте файлы Gerber, ODB++, Allegro .brd, .mcm для печатных плат и пакетов микросхем. Проверяйте сети, слои, формы и стеки. ТРИГГЕР: пользователь просит импортировать, прочитать или открыть файл топологии платы. Файлы Gerber используют gerberRead или PCBReader; ODB++, Allegro .brd, .mcm и собственные форматы используют pcbFileRead. Также при проверке цепей, слоев, компонентов или стеков импортированной платы. Вызовите ПЕРЕД написанием кода импорта — API запросов (cadnet, cadnetList,ComponentList) является специализированным. ПРОПУСК: ЭМ-анализ или извлечение S-параметров (используйте matlab-analyze-em), анализ PDN/IR-drop (используйте matlab-analyze-pcb-pdn), построение пользовательской геометрии (используйте matlab-assemble-pcb-layout), только определение материала/стека (используйте matlab-manage-pcb-material).
