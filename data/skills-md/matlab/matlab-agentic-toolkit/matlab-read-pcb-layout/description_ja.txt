PCB ボードおよび IC パッケージ用の Gerber、ODB++、Allegro .brd、.mcm ファイルをインポートします。ネット、レイヤー、形状、スタックアップを検査します。トリガー: ユーザーは PCB レイアウト ファイルをインポート、読み取り、または開くように要求します。ガーバー ファイルは gerberRead または PCBReader を使用します。 ODB++、Allegro .brd、.mcm、およびネイティブ形式は pcbFileRead を使用します。インポートされたボードのネット、レイヤー、コンポーネント、またはスタックアップを検査する場合にも使用できます。インポート コードを記述する前に呼び出します。クエリ API (cadnet、cadnetList、componentList) は特殊化されています。スキップ: EM 解析または S パラメーター抽出 (matlab-analyze-em を使用)、PDN/IR-ドロップ解析 (matlab-analyze-pcb-pdn を使用)、カスタム ジオメトリの構築 (matlab-assemble-pcb-layout を使用)、材料/スタックアップ定義のみ (matlab-manage-pcb-material を使用)。
