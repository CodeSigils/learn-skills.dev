Importe archivos Gerber, ODB++, Allegro .brd, .mcm para placas PCB y paquetes IC. Inspeccione redes, capas, formas y apilamientos. DISPARADOR: el usuario solicita importar, leer o abrir un archivo de diseño de PCB. Los archivos Gerber utilizan gerberRead o PCBReader; ODB++, Allegro .brd, .mcm y los formatos nativos utilizan pcbFileRead. También al inspeccionar redes, capas, componentes o apilamientos de un tablero importado. Invocar ANTES de escribir el código de importación: la API de consulta (cadnet, cadnetList, componenteList) está especializada. SALTAR: análisis EM o extracción de parámetros S (use matlab-analyze-em), análisis de caída PDN/IR (use matlab-analyze-pcb-pdn), creación de geometría personalizada (use matlab-assemble-pcb-layout), definición de material/apilamiento únicamente (use matlab-manage-pcb-material).
