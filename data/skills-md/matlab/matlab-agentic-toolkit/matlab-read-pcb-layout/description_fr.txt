Importez des fichiers Gerber, ODB++, Allegro .brd, .mcm pour les cartes PCB et les packages IC. Inspectez les filets, les couches, les formes et les empilements. TRIGGER : l'utilisateur demande d'importer, de lire ou d'ouvrir un fichier de configuration de PCB. Les fichiers Gerber utilisent gerberRead ou PCBReader ; ODB++, Allegro .brd, .mcm et les formats natifs utilisent pcbFileRead. Également lors de l'inspection de filets, de couches, de composants ou d'empilements à partir d'une carte importée. Invoquer AVANT d'écrire le code d'importation — l'API de requête (cadnet, cadnetList, componentList) est spécialisée. SAUTER : analyse EM ou extraction de paramètres S (utilisez matlab-analyze-em), analyse PDN/IR-drop (utilisez matlab-analyze-pcb-pdn), création d'une géométrie personnalisée (utilisez matlab-assemble-pcb-layout), définition de matériau/empilement uniquement (utilisez matlab-manage-pcb-material).
