Importa file Gerber, ODB++, Allegro .brd, .mcm per schede PCB e pacchetti IC. Ispeziona reti, strati, forme e pile. TRIGGER: l'utente chiede di importare, leggere o aprire un file di layout PCB. I file Gerber utilizzano gerberRead o PCBReader; ODB++, Allegro .brd, .mcm e i formati nativi utilizzano pcbFileRead. Anche quando si ispezionano reti, strati, componenti o pile da una scheda importata. Richiamare PRIMA di scrivere il codice di importazione: l'API di query (cadnet, cadnetList, componenteList) è specializzata. SALTA: analisi EM o estrazione di parametri S (usa matlab-analyze-em), analisi PDN/IR-drop (usa matlab-analyze-pcb-pdn), creazione di geometrie personalizzate (usa matlab-assemble-pcb-layout), solo definizione materiale/stackup (usa matlab-manage-pcb-material).
