Adopte la arquitectura obstinada de TypeScript en un proyecto existente. Primero ejecuta una revisión y luego propone cambios incrementales que el usuario puede aceptar o descartar. Recuerda propuestas descartadas para no volver a sugerirlas. Activadores de frases como "adoptar la arquitectura", "migrar mi proyecto", "alinear mi proyecto con las reglas", "adoptar tseng" o "hacer que mi proyecto se ajuste". También se puede invocar mediante el comando de barra diagonal /tseng:adopt.
