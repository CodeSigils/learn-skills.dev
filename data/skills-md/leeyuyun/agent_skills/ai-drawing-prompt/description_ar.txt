قم بإنشاء حزم مطالبات صور AI آمنة وجاهزة للإنتاج مع عناصر تحكم خاصة بالنموذج وخطط تكرار لـ OpenAI GPT Image وMidjourney وSDXL وFLUX. يُستخدم عندما تتضمن الطلبات إنشاء مطالبات صور أو تحسينها أو ترجمتها أو تصحيح أخطاءها؛ تحويل الموجز الإبداعي إلى معلمات الموفر؛ إنتاج قيود سلبية أو تجنبية لكل نموذج؛ أو تقديم متغيرات سريعة متعددة من الملخصات النصية والصور المرجعية.
