Shapefile, GeoJSON, GeoPackage 파일을 포함한 지리공간 벡터 데이터 작업을 위한 Python 라이브러리입니다. 공간 분석, 기하학적 작업, 좌표 변환, 공간 조인, 오버레이 작업, 등치 매핑 또는 벡터 지리 데이터 읽기/쓰기/분석과 관련된 모든 작업을 위해 지리 데이터로 작업할 때 사용합니다. PostGIS 데이터베이스, 대화형 지도 및 matplotlib/folium/cartopy와의 통합을 지원합니다. 버퍼 분석, 데이터 세트 간의 공간 조인, 경계 분리, 데이터 자르기, 면적/거리 계산, 좌표계 재투영, 지도 생성 또는 공간 파일 형식 간 변환과 같은 작업에 사용합니다.
