Libreria Python per lavorare con dati vettoriali geospaziali inclusi shapefile, GeoJSON e file GeoPackage. Da utilizzare quando si lavora con dati geografici per analisi spaziali, operazioni geometriche, trasformazioni di coordinate, unioni spaziali, operazioni di sovrapposizione, mappatura coropletica o qualsiasi attività che coinvolga la lettura/scrittura/analisi di dati geografici vettoriali. Supporta database PostGIS, mappe interattive e integrazione con matplotlib/folium/cartopy. Utilizzare per attività quali analisi del buffer, giunzioni spaziali tra set di dati, dissolvenza di confini, ritaglio di dati, calcolo di aree/distanze, riproiezione di sistemi di coordinate, creazione di mappe o conversione tra formati di file spaziali.
