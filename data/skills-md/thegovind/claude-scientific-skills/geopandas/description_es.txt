Biblioteca Python para trabajar con datos vectoriales geoespaciales, incluidos archivos Shapefiles, GeoJSON y GeoPackage. Úselo cuando trabaje con datos geográficos para análisis espacial, operaciones geométricas, transformaciones de coordenadas, uniones espaciales, operaciones de superposición, mapeo de coropletas o cualquier tarea que implique leer, escribir o analizar datos geográficos vectoriales. Admite bases de datos PostGIS, mapas interactivos e integración con matplotlib/folium/cartopy. Úselo para tareas como análisis de zonas de influencia, uniones espaciales entre conjuntos de datos, disolver límites, recortar datos, calcular áreas/distancias, reproyectar sistemas de coordenadas, crear mapas o convertir entre formatos de archivos espaciales.
