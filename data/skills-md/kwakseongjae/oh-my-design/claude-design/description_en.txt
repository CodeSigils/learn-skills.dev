Analyze the current codebase (or folder) and synthesize a “design context brief” (stack/design tokens/components/routes/actual UI copy/curated assets/repo links), then automatically send it to Claude Design (claude.ai/design) to generate a design, and return the result link in a clickable form in the terminal. Perform the transfer of codebase → Claude Design context with a single terminal call. claude.ai/design runs in the user’s logged‑in Chrome (claude‑in‑chrome), but if the interaction layer is blocked (known chrome‑extension conflict bug), it cleanly switches to a manual handoff. No rendering screenshot capture is performed.

Triggers: “/claude-design”, “Move this codebase to Claude Design”, “Analyze the codebase and send to Claude Design”, “Generate landing design”, “Send to claude.ai/design”, “Request a design from Claude Design”, “Create a design with this reference”, “Request a mockup from Claude Design”.
