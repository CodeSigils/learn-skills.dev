Analyze the current codebase (or folder), synthesize a “design context brief” (stack / design tokens / components / routes / actual UI copy / curated assets / repo link), automatically send it to Claude Design (claude.ai/design) to generate a design, and return the result link in the terminal as a clickable item. With a single terminal call, perform the transfer of codebase → Claude Design context. claude.ai/design runs using the user’s logged‑in Chrome (claude‑in‑chrome), but if the interaction layer is blocked (known chrome‑extension conflict bug), it cleanly switches to a manual handoff. No rendering screenshot capture is performed.  
Triggers: “/claude-design”, “Move this codebase to Claude Design”, “Analyze the codebase and deliver to Claude Design”, “Generate landing design”, “Send to claude.ai/design”, “Request a design from Claude Design”, “Create a design with this reference”, “Request a mockup from Claude Design”.
