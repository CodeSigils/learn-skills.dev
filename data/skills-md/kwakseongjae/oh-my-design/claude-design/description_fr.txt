Analysez la base de code actuelle (ou le dossier), synthétisez un « dossier de contexte de conception » (pile / jetons de conception / composants / itinéraires / copie réelle de l'interface utilisateur / actifs organisés / lien de dépôt), envoyez-le automatiquement à Claude Design (claude.ai/design) pour générer une conception et renvoyez le lien de résultat dans le terminal sous forme d'élément cliquable. Avec un seul appel de terminal, effectuez le transfert de la base de code → contexte Claude Design. claude.ai/design s'exécute à l'aide du Chrome connecté de l'utilisateur (claude-in-chrome), mais si la couche d'interaction est bloquée (bogue connu de conflit d'extension Chrome), elle passe proprement à un transfert manuel. Aucune capture d'écran de rendu n'est effectuée.
