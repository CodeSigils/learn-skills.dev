Analysez la base de code actuelle (ou le dossier) et synthétisez un « dossier de contexte de conception » (pile / jetons de conception / composants / itinéraires / copie réelle de l'interface utilisateur / actifs organisés / lien de dépôt), puis envoyez-le automatiquement à Claude Design (claude.ai/design) pour générer une conception et renvoyez le lien de résultat dans le terminal sous forme de lien cliquable. Effectuez le transfert depuis la base de code → le contexte Claude Design avec un seul appel de terminal. claude.ai/design s'exécute dans le Chrome connecté de l'utilisateur (claude-in-chrome), mais si la couche d'interaction est bloquée (bogue connu de conflit d'extension Chrome), elle passe proprement à un transfert manuel. Aucune capture d'écran de rendu n'est effectuée.
