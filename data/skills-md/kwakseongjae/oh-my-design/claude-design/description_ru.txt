Проанализируйте текущую базу кода (или папку), синтезируйте «краткое описание контекста дизайна» (стек / токены дизайна / компоненты / маршруты / фактическую копию пользовательского интерфейса / курируемые ресурсы / ссылку на репозиторий), автоматически отправьте его в Claude Design (claude.ai/design) для создания дизайна и верните ссылку на результат в терминале в виде кликабельного элемента. С помощью одного терминального вызова выполните передачу кодовой базы → контекст Claude Design. claude.ai/design запускается с использованием Chrome, вошедшего в систему пользователя (claude-in-chrome), но если уровень взаимодействия блокируется (известная ошибка конфликта расширений Chrome), он автоматически переключается на передачу вручную. Снимок экрана рендеринга не выполняется.
