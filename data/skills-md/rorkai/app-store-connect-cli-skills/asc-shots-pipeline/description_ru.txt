Организуйте автоматизацию создания снимков экрана iOS с помощью xcodebuild/simctl для запуска сборки, axe для действий пользовательского интерфейса, настроек JSON и файлов плана, кадрирования на основе Koubou («кадр снимков экрана по возрастанию») и загрузки снимков экрана («загрузка снимков экрана по возрастанию»). Используйте, когда пользователи запрашивают автоматический захват снимков экрана, потоки симулятора на основе AXe, композицию кадров или конвейеры создания снимков экрана для загрузки.
