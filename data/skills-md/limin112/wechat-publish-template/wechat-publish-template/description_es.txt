Convierta un artículo de Markdown en un HTML de cuenta pública de WeChat de "estilo de tecnología personal" (estilo cyberpunk naranja-negro). Cuando el usuario proporciona una ruta de archivo .md o pega un bloque de Markdown y dice "convertir a cuenta pública", "formatear para cuenta pública" o "aplicar plantilla de cuenta pública", se activa la conversión. El resultado es un único archivo HTML con todos los estilos en línea, que se puede abrir directamente en un navegador, luego seleccionarlo, copiarlo y pegarlo en el editor de cuentas públicas de WeChat. No active esto cuando el usuario solo esté haciendo preguntas como "cómo escribir un artículo de cuenta pública" o "temas de cuenta pública", que son problemas que no tienen que ver con el formato.
