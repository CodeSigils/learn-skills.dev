Converti un articolo Markdown in un account pubblico WeChat HTML in "stile tecnico personale" (stile cyberpunk arancione-nero). Quando l'utente fornisce un percorso file .md o incolla un blocco di Markdown e dice "converti in account pubblico", "formatta per account pubblico" o "applica modello di account pubblico", attiva la conversione. L'output è un singolo file HTML con tutti gli stili incorporati, che può essere aperto direttamente in un browser, quindi selezionato, copiato e incollato nell'editor dell'account pubblico di WeChat. Non attivare questa opzione quando l'utente pone solo domande come "come scrivere un articolo per un account pubblico" o "argomenti per un account pubblico", che sono problemi di non formattazione.
