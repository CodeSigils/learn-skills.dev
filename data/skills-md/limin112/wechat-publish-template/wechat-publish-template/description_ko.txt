Markdown 기사를 "개인 기술 스타일" WeChat 공개 계정 HTML(오렌지색 검정색 사이버펑크 스타일)로 변환합니다. 사용자가 .md 파일 경로를 제공하거나 Markdown 블록을 붙여넣고 "공용 계정으로 변환", "공용 계정 형식" 또는 "공용 계정 템플릿 적용"이라고 말하면 변환이 트리거됩니다. 출력은 모든 인라인 스타일이 포함된 단일 HTML 파일로, 브라우저에서 직접 연 다음 선택하고 복사하여 WeChat 공개 계정 편집기에 붙여넣을 수 있습니다. 사용자가 형식이 아닌 문제인 "공개 계정 기사 작성 방법" 또는 "공개 계정 주제"와 같은 질문만 하는 경우에는 이 문제를 트리거하지 마세요.
