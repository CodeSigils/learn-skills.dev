Utilice esta habilidad cuando el usuario quiera hacer algo en X con xurl, especialmente cuando habla en lenguaje de tareas como enviar un tweet, crear una publicación X, responder a una publicación, enviar un DM, buscar publicaciones, cargar medios, verificar menciones o cambiar entre cuentas de aplicaciones X. Úselo también para problemas de inicio de sesión de xurl y configuración de aplicaciones, como OAuth, URI de redireccionamiento, verificaciones de quién soy yo o administración de múltiples aplicaciones de xurl. Priorice los objetivos del usuario sobre la redacción técnica: active incluso si el usuario nunca dice CLI, línea de comando, terminal o secuencia de comandos. No lo utilice para el desarrollo general de API X en Python, Node.js, raw curl, aplicaciones móviles o teoría genérica de OAuth.
