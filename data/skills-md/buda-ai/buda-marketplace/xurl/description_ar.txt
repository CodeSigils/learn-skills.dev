استخدم هذه المهارة عندما يريد المستخدم القيام بشيء ما على X باستخدام xurl، خاصة عندما يتحدثون بلغة مهمة مثل إرسال تغريدة، أو إنشاء منشور X، أو الرد على منشور، أو إرسال رسالة مباشرة، أو البحث في المنشورات، أو تحميل الوسائط، أو التحقق من الإشارات، أو التبديل بين حسابات تطبيق X. استخدمه أيضًا في تسجيل الدخول إلى xurl ومشكلات إعداد التطبيق مثل OAuth، أو إعادة توجيه URI، أو التحقق من من أنا، أو إدارة تطبيقات xurl المتعددة. قم بإعطاء الأولوية لأهداف المستخدم على الصياغة الفنية: قم بالتشغيل حتى لو لم يقل المستخدم مطلقًا واجهة سطر الأوامر (CLI) أو سطر الأوامر أو الوحدة الطرفية أو البرنامج النصي. لا تستخدمه لتطوير X API العام في Python أو Node.js أو Raw Curl أو تطبيقات الهاتف المحمول أو نظرية OAuth العامة.
