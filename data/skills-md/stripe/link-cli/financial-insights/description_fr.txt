Lit les données financières Link d'un utilisateur (transactions, soldes et sources de portefeuille) afin que les agents puissent répondre aux questions sur les dépenses et les capacités de source disponibles. À utiliser lorsque l'utilisateur dit « vérifier mon solde », « combien ai-je dépensé », « afficher mes transactions », « quels comptes sont connectés », « résumer mes dépenses », « achats récents » ou pose des questions sur son activité financière, les soldes de ses comptes ou ses sources liées.
