Installa e autentica Link CLI per pagamenti degli agenti, approfondimenti finanziari o entrambi. Da utilizzare quando un utente configura l'interfaccia a riga di comando di Link per la prima volta, chiede di connettersi o accedere a Link oppure deve configurare l'accesso a Link prima di utilizzare le funzionalità di pagamento o di dati finanziari.
