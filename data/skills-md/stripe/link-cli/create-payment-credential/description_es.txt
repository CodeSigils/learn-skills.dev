Obtiene credenciales de pago seguras y de un solo uso (tarjetas, tokens) de una billetera Link para que los agentes puedan completar compras en nombre de los usuarios. Úselo cuando el usuario dice "consígueme una tarjeta", "compra algo", "paga por X", "realiza una compra", "Necesito pagar", "completar el pago" o solicita realizar una transacción en cualquier sitio comercial. Úselo cuando el usuario solicite conectarse, iniciar sesión o registrarse en su cuenta Link.
