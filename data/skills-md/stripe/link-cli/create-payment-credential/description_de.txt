Erhält sichere, einmalige Zahlungsdaten (Karten, Token) aus einer Link-Wallet, damit Agenten Einkäufe im Namen von Benutzern abschließen können. Wird verwendet, wenn der Benutzer sagt: „Besorg mir eine Karte“, „etwas kaufen“, „Zahle für Verwenden Sie diese Option, wenn der Benutzer eine Verbindung herstellen, sich anmelden oder sich für sein Link-Konto anmelden möchte.
