À utiliser lors de la création, de la modification ou de la révision d'une application Stripe — ou lorsque l'utilisateur décrit quelque chose qui en implique une (par exemple, « ajouter un panneau à la page client », « personnaliser mon tableau de bord Stripe », « réagir aux événements Stripe de mon application », « connecter mon service à Stripe sans partager de clés API »). Couvre le flux de travail complet de développement d'applications (échafaudage, aperçu, téléchargement, gestion des versions), l'architecture des extensions d'interface utilisateur (iframe en bac à sable, boîte à outils Stripe UI, fenêtres d'affichage), les types d'extensions (extensions d'interface utilisateur, backend uniquement, interfaces d'extension, applications intégrées), l'authentification (clés de plate-forme, OAuth, clés API restreintes), la configuration du manifeste stripe-app.yaml (autorisations, fenêtres d'affichage, CSP), la configuration du webhook pour les applications, l'API Secret Store, `fetchStripeSignature`. authentification et publication sur le marché. À utiliser lorsque l'utilisateur mentionne les applications Stripe, les extensions d'interface utilisateur, @stripe/ui-extension-sdk, stripe-app.yaml, les extensions du tableau de bord ou la personnalisation du tableau de bord Stripe.
