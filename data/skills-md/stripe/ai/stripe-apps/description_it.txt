Da utilizzare durante la creazione, la modifica o la revisione di un'app Stripe o quando l'utente descrive qualcosa che ne implica una (ad esempio "aggiungi un pannello alla pagina del cliente", "personalizza la mia dashboard Stripe", "reagisci agli eventi Stripe dalla mia app", "connetti il ​​mio servizio a Stripe senza condividere le chiavi API"). Copre l'intero flusso di lavoro di sviluppo dell'app (impalcatura, anteprima, caricamento, controllo delle versioni), architettura dell'estensione dell'interfaccia utente (iframe sandbox, toolkit dell'interfaccia utente Stripe, viewport), tipi di estensione (estensioni dell'interfaccia utente, solo backend, interfacce di estensione, app incorporate), autenticazione (chiavi della piattaforma, OAuth, chiavi API limitate), configurazione del manifest stripe-app.yaml (autorizzazioni, viewport, CSP), configurazione del webhook per le app, API Secret Store, "fetchStripeSignature" autenticazione e pubblicazione sul marketplace. Da utilizzare quando l'utente menziona le app Stripe, le estensioni dell'interfaccia utente, @stripe/ui-extension-sdk, stripe-app.yaml, le estensioni della dashboard o la personalizzazione della dashboard di Stripe.
