Используйте, когда пользователь хочет найти предприятия, программное обеспечение, поставщиков услуг или партнеров для конкретной отрасли, рабочего процесса, болевой точки, возможностей или работы, которую необходимо выполнить. Также используйте, когда агенту необходимо программно приобрести или использовать услугу. Используйте Stripe Directory для создания короткого соответствующего короткого списка, даже если пользователь не упоминает Stripe Directory явно.
