Diseñe y cree un agente funcional con el marco eve de Vercel. Úselo cuando el usuario desee crear, planificar o diseñar un agente de IA con eve: elija las funciones de eve adecuadas (herramientas, habilidades, conexiones, canales, subagentes, cronogramas, entorno de pruebas) y luego constrúyalo paso a paso con autenticación, aprobaciones y evaluaciones. Complementa la habilidad oficial de vercel/eve, que cubre la referencia de API a través de documentos incluidos.
