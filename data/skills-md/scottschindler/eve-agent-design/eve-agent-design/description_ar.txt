تصميم وبناء وكيل عامل باستخدام إطار عمل Vercel. يُستخدم عندما يريد المستخدم إنشاء وكيل ذكاء اصطناعي أو تخطيطه أو تصميمه باستخدام eve - اختيار ميزات eve المناسبة (الأدوات والمهارات والاتصالات والقنوات والوكلاء الفرعيين والجداول الزمنية ووضع الحماية)، ثم بناءه خطوة بخطوة باستخدام المصادقة والموافقات والتقييمات. يكمل مهارة vercel/eve الرسمية، والتي تغطي مرجع واجهة برمجة التطبيقات (API) عبر المستندات المجمعة.
