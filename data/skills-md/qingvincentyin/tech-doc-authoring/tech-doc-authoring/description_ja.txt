Markdown 技術ドキュメントの作成および編集のための作成時ルール。tech-doc-consistency-check (既存のドキュメントを監査する) に相当します。このスキルは、Markdown ドキュメント、特にユーザー ガイド ドキュメント (「Infra Guide to GCP AI Agents.md」、「DevOps Guide to Agents-cli.md」) を作成または編集するとき、または見出し、セクション相互参照 (§X.Y)、リンク、画像、目次エントリ、またはインライン HTML アンカーを追加するときに使用します。トリガー: 「このセクションを作成」、「見出しを追加」、「セクション X へのリンク」、「他のガイドを相互参照」、「アンカーを追加」、「画像を挿入」、「ドキュメントを編集」。ハードラップ ルール、ドキュメント内およびドキュメント間リンクの構築、GFM スラグ アンカー、非見出しおよび画像アンカー、図/図/表参照のハイパーリンク、双方向クロスリンク、タイトルケースの見出し、兄弟見出しの番号付け、空セクションのプリアンブルの許容範囲、リストとインラインの列挙、カラー ブラインド セーフな図の色とパレットの節約、前方参照の脆弱性、埋め込み JSON の整形印刷をカバーします。文字列。完成したドキュメントの監査 (tech-doc-consistency-check を使用) や一般的な散文スタイル (ユーザーのグローバル CLAUDE.md に残る) にはこれを使用しないでください。
