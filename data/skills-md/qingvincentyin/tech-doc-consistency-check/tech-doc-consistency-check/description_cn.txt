审核和自动修复 Markdown 技术文档以确保结构和语言的一致性，然后输出发现和修复的所有问题的汇总表。每当用户想要验证、审查、清理或校对 Markdown 文件时，即使他们没有明确地说“一致性检查”，也可以使用此技能。触发条件：“在发布之前检查此文档”、“目录链接似乎已损坏”、“部分编号中有些内容看起来不对劲”、“校对我的技术文章”、“检查此文档是否有错误”、“确保锚点有效”、“审核此 Markdown”或任何验证或清理 .md 文件的请求。检查章节编号、TOC 完整性、TOC 锚链接（GFM 规则，包括破折号处理）、HTML 锚有效性、技术感知拼写和散文语法 — 自动修复所有可能的内容并标记用户的判断要求。
