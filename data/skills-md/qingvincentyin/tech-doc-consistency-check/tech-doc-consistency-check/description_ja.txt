Markdown 技術文書の構造的および言語的一貫性を監査および自動修正し、検出および修正されたすべての問題の概要表を出力します。ユーザーが Markdown ファイルを検証、レビュー、クリーンアップ、または校正したい場合は常に、「一貫性チェック」と明示的に言わない場合でも、このスキルを使用してください。トリガー: 「公開する前にこのドキュメントを確認してください」、「目次のリンクが壊れているようです」、「セクション番号に何か問題があります」、「技術文書を校正してください」、「このドキュメントに誤りがないかレビューしてください」、「アンカーが機能することを確認してください」、「このマークダウンを監査してください」、または .md ファイルを検証またはクリーンアップするためのリクエスト。セクションの番号付け、目次の完全性、目次アンカー リンク (エムダッシュ処理を含む GFM ルール)、HTML アンカーの有効性、技術を意識したスペル、散文文法をチェックします。可能なものはすべて自動修正し、ユーザーに判断を求めるフラグを付けます。
