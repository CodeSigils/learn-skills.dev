À utiliser lors de la génération, de la refactorisation, de la révision ou du débogage du code API des applications/services Make App et des contrats UI-Service. Couvre la conception des routes de service, apps/docs/api.md, la structure source en couches, les adaptateurs make-client, les API de normalisation de schéma, l'enregistrement CRUD via Make gateway /make/data/v1/record, l'analyse du filtre de liste d'enregistrements et le passage {expression}, les API utilisateur/département/recherche/proxy de fichier, la configuration de l'adaptateur Make, le transfert de contexte de connexion, la validation, la journalisation et les tests de l'API de service. Ne couvre pas la disposition de l'interface utilisateur, la mise en œuvre de l'authentification, la sortie de construction, l'exécution, la modélisation DSL, le déploiement Make CLI ou les éléments internes de la table de canevas.
