Da utilizzare durante la generazione, il refactoring, la revisione o il debug del codice API delle app/servizi Make App e dei contratti di servizio dell'interfaccia utente. Copre la progettazione del percorso del servizio, apps/docs/api.md, struttura di origine a più livelli, adattatori make-client, API di normalizzazione dello schema, record CRUD tramite Make gateway /make/data/v1/record, analisi del filtro dell'elenco di record e pass-through di { espressione }, API proxy utente/dipartimento/ricerca/file, configurazione dell'adattatore Make, inoltro del contesto di accesso delle richieste, convalida, registrazione e test API del servizio. Non copre il layout dell'interfaccia utente, l'implementazione dell'autenticazione, l'output di compilazione, il runtime, la modellazione DSL, la distribuzione della CLI o gli interni della tabella canvas.
