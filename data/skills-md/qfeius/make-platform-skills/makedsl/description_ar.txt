يُستخدم عند تصميم أو إنشاء منصة Make DSL YAML - تحديد التطبيقات أو الكيانات أو الحقول أو العلاقات أو طرق العرض أو مخططات التسجيل. يتم تشغيله أيضًا بطلبات مثل "建模" أو "建表" أو "加字段" أو "定义关联" أو "生成 DSL". لا ينشر الموارد (استخدم makecli)، أو ينشئ واجهة مستخدم أمامية (makeui)، أو ينفذ رمز الخدمة/واجهة برمجة التطبيقات (make-app-service)، أو يعالج المصادقة (make-app-auth)، أو التعبئة في وقت التشغيل (make-app-runtime)، أو تكامل التعرف الضوئي على الحروف (make-integration)، أو سلوك جدول اللوحة.
