يُستخدم عند دمج أو إنشاء أو إعادة هيكلة أو مراجعة تصفية قائمة سجلات Make App باستخدام @qfei-design/make-filter، وربط رأس CanvasTable، وحمولات Service filter.expression. يتم التشغيل بواسطة 筛选، 高级筛选، 条件筛选، 表格/表头/列头/按字段筛选، تعبيرات CEL/DNF، متغيرات النظام، عوامل التصفية الفارغة، عوامل تشغيل نوع الحقل، دعم DateRange/File/Lookup، القيم المرشحة، URL الصدى، والاختبارات. لا يمتلك غلاف/تخطيط الصفحة، أو الأجزاء الداخلية لعرض CanvasTable، أو تنفيذ مسار الخدمة، أو المصادقة، أو تعبئة وقت التشغيل، أو نمذجة DSL، أو تنفيذ CLI، أو تحرير خلايا الجدول.
