يُستخدم عندما يطلب المستخدم التعرف على الفواتير أو الفواتير أو الإيصالات أو التذاكر أو ملفات القسائم الأخرى مع خدمات Make Integration. يتم تشغيله أيضًا من خلال طلبات مثل "发票内容"، أو "识别发票"، أو "票据 OCR"، أو "ocr 这张图片"، أو "验真发票". لا يدير إنشاء الموارد (استخدم makecli)، أو تصميم مخططات DSL (makedsl)، أو إنشاء واجهة مستخدم (makeui)، أو تنفيذ المصادقة (make-app-auth)، أو رمز الخدمة/واجهة برمجة التطبيقات (make-app-service)، أو تعبئة وقت التشغيل (make-app-runtime)، أو تنفيذ أوامر غير Make OCR خارج أوامر تكامل makecli.
