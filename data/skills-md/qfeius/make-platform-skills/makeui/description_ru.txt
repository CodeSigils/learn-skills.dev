Используйте при проектировании, создании, рефакторинге или проверке пользовательского интерфейса Make App и кода пользовательского интерфейса React `apps/ui`. Также вызывается упоминанием makeui или `skills/makeui`. Охватывает пользовательский интерфейс, 界面, оболочку приложения, макет страницы, стиль, размещение компонентов, меню заголовка текущего пользователя, компонентную структуру модуля, 组件化拆分, 模块化拆分, адаптивное поведение, маршруты динамических объектов, рендеринг пользовательского интерфейса на основе метаданных полей, страницы списка, ящики создания/редактирования/детализации, страницы формы/подробности на основе маршрутов, пользователя/отдел. использование источника-кандидата селектора пользовательского интерфейса и состояния пользовательского интерфейса. Требуется создать таблицы записей для использования `@qfei-design/canvas-table` через `canvas-table-integration` и создать расширенные фильтры для использования `@qfei-design/make-filter` через `make-app-filter`. Не охватывает аутентификацию/вход в систему, выходные данные сборки, публикацию/развертывание, среду выполнения службы, разработку бизнес-API, разрешения, сохранение данных, бизнес-моделирование, внутренние компоненты таблицы холста или внутренние компоненты пакета расширенных фильтров.
