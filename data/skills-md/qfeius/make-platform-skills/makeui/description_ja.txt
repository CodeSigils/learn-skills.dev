Make App フロントエンド UI および `apps/ui` React UI コードを設計、生成、リファクタリング、またはレビューするときに使用します。 Makeui または `skills/makeui` の言及によってもトリガーされます。 UI、界面、アプリ シェル、ページ レイアウト、スタイル、コンポーネントの配置、現在のユーザーのヘッダー メニュー、コンポーネント化されたモジュール構造、部品化拆分、模造化拆分、応答動作、動的オブジェクト ルート、フィールド メタデータ駆動型 UI レンダリング、リスト ページ、作成/編集/詳細ドロワー、ルートベースのフォーム/詳細ページ、ユーザー/部門セレクター UI 候補ソースの使用法、UI 状態をカバーします。 `canvas-table-integration` を介して `@qfei-design/canvas-table` を使用するにはレコード テーブルを作成する必要があり、`make-app-filter` を介して `@qfei-design/make-filter` を使用するには高度なフィルターを作成する必要があります。認証/ログイン、ビルド出力、公開/デプロイ、サービス ランタイム、ビジネス API 設計、アクセス許可、データ永続性、ビジネス モデリング、キャンバス テーブルの内部、または高度なフィルター パッケージの内部はカバーされません。
