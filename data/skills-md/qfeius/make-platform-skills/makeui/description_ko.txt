Make App 프런트엔드 UI 및 'apps/ui' React UI 코드를 디자인, 생성, 리팩터링 또는 검토할 때 사용합니다. 또한 makeui 또는 `skills/makeui`에 대한 언급에 의해 트리거됩니다. UI, 인터페이스, 앱 셸, 페이지 레이아웃, 스타일 지정, 구성 요소 배치, 현재 사용자 헤더 메뉴, 구성 요소화된 모듈 구조, 통합화 분할, 분산화, 반응형 동작, 동적 개체 경로, 필드 메타데이터 기반 UI 렌더링, 목록 페이지, 생성/편집/세부 정보 서랍, 경로 기반 양식/세부 정보 페이지, 사용자/부서 선택기 UI 후보 소스 사용 및 UI 상태를 다룹니다. `canvas-table-integration`을 통해 `@qfei-design/canvas-table`을 사용하려면 레코드 테이블 만들기가 필요하고, `make-app-filter`를 통해 `@qfei-design/make-filter`를 사용하려면 고급 필터 만들기가 필요합니다. 인증/로그인, 빌드 출력, 게시/배포, 서비스 런타임, 비즈니스 API 디자인, 권한, 데이터 지속성, 비즈니스 모델링, 캔버스 테이블 내부 또는 고급 필터 패키지 내부는 다루지 않습니다.
