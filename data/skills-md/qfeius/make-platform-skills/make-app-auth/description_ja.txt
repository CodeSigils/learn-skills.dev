Make App の統合ログインと @qfeius/make-app-auth で認証された /api/make リクエストを生成、変更、レビュー、またはデバッグするときに使用します。統合ログイン、OAuth/ngrok モード、401/403 処理、ログアウト、現在のユーザー メニューのログアウト配線、Cookie、セッション、リダイレクト コールバック、および Make App auth のトラブルシューティングについて説明します。 UI レイアウト、アカウント メニューの配置、ページ構造、ビルド出力、サービス API コントラクト、DSL モデリング、またはキャンバス テーブルの内部についてはカバーしません。現在のユーザーのヘッダー メニュー画面には makeui を使用します。
