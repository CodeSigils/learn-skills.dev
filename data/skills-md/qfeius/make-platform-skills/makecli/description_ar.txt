يُستخدم عندما يطلب المستخدم إدارة إنشاء موارد النظام الأساسي باستخدام makecli - إنشاء/نشر التطبيقات أو الكيانات أو العلاقات أو السجلات أو فحص الموارد أو تشغيل أوامر makecli CLI. يتم تشغيله أيضًا بطلبات مثل "部署" أو "apply" أو "查看应用" أو "创建记录" أو "/makecli". لا يمتلك تصميم مخطط DSL (استخدم makedsl)، أو واجهة مستخدم الواجهة الأمامية (makeui)، أو المصادقة (make-app-auth)، أو كود الخدمة/واجهة برمجة التطبيقات (make-app-service)، أو التعبئة في وقت التشغيل (make-app-runtime)، أو تكامل التعرف الضوئي على الحروف (make-integration)، أو سلوك جدول القماش.
