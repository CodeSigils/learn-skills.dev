Навык запроса конфигурации поля контракта-cli: запрос определений конфигурации полей для поставщика, Legal_entity и вендор_риска. Он срабатывает, когда пользователь хочет использовать «список полей контракта-cli mdm» для проверки структуры полей основных данных. В настоящее время идентификатор бота поддерживает только поставщика/юридического лица.
