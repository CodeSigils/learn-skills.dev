Contract-CLI-Anmelde- und Identitätswechselfähigkeit: Initialisieren Sie ein Entwicklerprofil, führen Sie eine Benutzer-OAuth-Anmeldung durch, geben Sie die app_id/app_secret des Bots ein und tauschen Sie sofort ein Tenant_access_token aus, zeigen Sie den Status an, ändern Sie die Standardidentität und beheben Sie lokale Persistenzprobleme bei Konfigurationen/Geheimnissen. Wird ausgelöst, wenn der Benutzer „contract-cli config add“, „contract-cli auth login --as user|bot“, „contract-cli auth status/logout/use“ benötigt oder Anmeldeanomalien behebt.
