Contract-cli ログインと ID 切り替えスキル: 開発プロファイルの初期化、ユーザー OAuth ログインの実行、ボットの app_id/app_secret の入力と即時の tenant_access_token の交換、ステータスの表示、デフォルト ID の切り替え、ローカル構成/シークレットの永続化の問題のトラブルシューティング。ユーザーが `contract-cli config add`、`contract-cli auth login --as user|bot`、`contract-cli auth status/logout/use` を必要とする場合、またはログイン異常のトラブルシューティングを行う場合にトリガーされます。
