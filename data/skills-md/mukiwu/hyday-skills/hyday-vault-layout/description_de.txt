Suchen, durchsuchen und navigieren Sie in einem Hyday-Tresor – lösen Sie das Tresorstammverzeichnis aus der Datei „settings.json“ des Benutzers auf (Schritt 0), führen Sie Listen oder Inventarnotizen auf, finden Sie heraus, wo Hyday etwas speichert, und entscheiden Sie, wo neue Dateien abgelegt werden sollen. Verwenden Sie diese Option immer dann, wenn ein Agent zunächst wissen muss, wo sich der Hyday-Ordner des Benutzers auf der Festplatte befindet, oder wenn der Benutzer fragt: „Wo sind meine Notizen gespeichert“, „Meine Hyday-Ordner auflisten“, „Hyday löschen“, „Hyday löschen“ oder Hyday-Ordner, Datenpfad, Tresor, Journalverzeichnis, Vorlagen, Assets oder Tresorstruktur erwähnt. Jede andere Hyday-Fertigkeit baut auf dieser Stufe 0 auf.
