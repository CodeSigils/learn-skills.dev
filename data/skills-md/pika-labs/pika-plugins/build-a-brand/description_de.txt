Erstellen Sie aus beliebigen Eingaben ein vollständiges Markenidentitäts- und Richtlinien-PDF – eine Idee, eine bestehende Website, eine Liste von Referenzmarken, Produktfotos oder „Ich möchte X umbenennen“. Verwenden Sie diese Option, wenn jemand eine Markenidentität wünscht, aber KEINE vollständige Commerce-Einführung benötigt (kein Shopify, keine Produkteinträge, keine Social-Media-Beiträge). Auslösersätze: „Bauen Sie mir eine Marke auf“, „Machen Sie mich zu einer Marke“, „Entwerfen Sie eine Markenidentität“, „Markenrichtlinien für [X]“, „Ich möchte ein Markenbuch“, „Erstellen Sie eine Marke von Grund auf“, „Marke für [Idee]“, „Ich möchte eine Marke, die sich anfühlt wie [X] + [Y]“, „Mein [Ding] umbenennen“, „Visuelle Identität für [Ding]“, „Eine Marke aufbauen“.
