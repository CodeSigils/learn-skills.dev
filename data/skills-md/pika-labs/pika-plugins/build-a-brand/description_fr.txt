Créez un PDF complet d'identité de marque et de directives à partir de n'importe quelle entrée : une idée, un site Web existant, une liste de marques de référence, des photos de produits ou "Je veux renommer X". À utiliser lorsque quelqu'un souhaite une identité de marque mais n'a PAS besoin d'un lancement commercial complet (pas de Shopify, pas de listes de produits, pas de publication sur les réseaux sociaux). Phrases déclencheurs : « construisez-moi une marque », « faites-moi une marque », « concevez une identité de marque », « directives de marque pour [X] », « je veux un livre de marque », « créer une marque à partir de zéro », « marque pour [idée] », « je veux une marque qui ressemble à [X] + [Y] », « renommer mon [chose] », « identité visuelle pour [chose] », « construire une marque ».
