Объясняющее видео примерно 60–80-х годов для любого URL — репозитория GitHub, страницы продукта, сайта документации, публикации в блоге или запуска. Канонический рабочий процесс для пошаговых руководств по URL. Используйте, когда пользователь просит «объяснить этот URL-адрес / репозиторий / веб-сайт / продукт», «сделать видео с пошаговым описанием для [url]», «демонстрировать этот сайт», «объяснение [url] в стиле Loom», «объяснитель для github.com/...» или «объяснить ссылку на этот продукт». Проводит реальный браузер через URL-адрес, генерирует синхронизацию губ аватара и объединяет кадр macOS Sonoma размером 1280×800 с кружком аватара в левом нижнем углу размером 246 пикселей. URL-адреса GitHub активируют режим поддержки репо (сканирование README + обнаружение живой демонстрации); другие URL-адреса используют общий поток просмотра страниц.
