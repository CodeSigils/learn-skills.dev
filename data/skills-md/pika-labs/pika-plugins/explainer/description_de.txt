Etwa 60–80 Jahre langes Erklärvideo für jede URL – GitHub-Repo, Produktseite, Dokumentationsseite, Blogbeitrag oder Start. Kanonischer Workflow für URL-Komplettlösungen. Wird verwendet, wenn der Benutzer nach „Erklärung dieser URL/Repo/Website/Produkt“, „Erstellen eines Walkthrough-Videos für [URL]“, „Demonstration dieser Website“, „Erklärung von [URL] im Loom-Stil“, „Erklärung für github.com/…“ oder „Erklärung dieses Produktlinkes“ fragt. Steuert einen echten Browser über die URL, generiert eine Avatar-Lippensynchronisation und fügt einen 1280×800 macOS Sonoma-Rahmen mit einem 246 Pixel großen Avatar-Kreis unten links zusammen. GitHub-URLs aktivieren einen Repo-fähigen Modus (README-Scan + Live-Demo-Erkennung); Andere URLs verwenden einen generischen Seiten-Walkthrough-Ablauf.
