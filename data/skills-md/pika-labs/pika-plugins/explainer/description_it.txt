Video esplicativo degli anni '60 e '80 per qualsiasi URL: repository GitHub, pagina di prodotto, sito di documentazione, post di blog o lancio. Flusso di lavoro canonico per le procedure dettagliate sugli URL. Da utilizzare quando l'utente chiede di "spiegare questo URL/repo/sito web/prodotto", "creare un video dettagliato per [url]", "demo questo sito", "spiegatore in stile Loom di [url]", "spiegatore per github.com/..." o "spiegare questo collegamento al prodotto". Gestisce un browser reale attraverso l'URL, genera un avatar lipsync e compone in un frame macOS Sonoma 1280×800 con un cerchio avatar in basso a sinistra da 246 pixel. Gli URL GitHub attivano una modalità repo-aware (scansione README + rilevamento live-demo); altri URL utilizzano un flusso di procedura dettagliata della pagina generico.
