모든 URL에 대한 ~60-80년대 설명 비디오 — GitHub 저장소, 제품 페이지, 문서 사이트, 블로그 게시물 또는 출시. URL 둘러보기를 위한 표준 워크플로입니다. 사용자가 "이 URL/저장소/웹사이트/제품 설명", "[url]에 대한 연습 비디오 만들기", "이 사이트 데모", "[url]의 Loom 스타일 설명", "github.com/...에 대한 설명" 또는 "이 제품 링크 설명"을 요청할 때 사용합니다. URL을 통해 실제 브라우저를 구동하고, 아바타 립싱크를 생성하고, 246픽셀 왼쪽 하단 아바타 원이 있는 1280×800 macOS Sonoma 프레임에 합성합니다. GitHub URL은 저장소 인식 모드(README 스캔 + 라이브 데모 감지)를 활성화합니다. 다른 URL은 일반적인 페이지 둘러보기 흐름을 사용합니다.
