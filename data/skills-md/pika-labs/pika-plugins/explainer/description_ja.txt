60 ～ 80 年代のあらゆる URL の説明ビデオ — GitHub リポジトリ、製品ページ、ドキュメント サイト、ブログ投稿、またはローンチ。 URL ウォークスルーの正規ワークフロー。ユーザーが「この URL / リポジトリ / Web サイト / 製品の説明」、「[URL] のウォークスルー ビデオの作成」、「このサイトのデモ」、「[URL] の Loom スタイルの説明」、「github.com/... の説明」、または「この製品リンクの説明」を求める場合に使用します。 URL を通じて実際のブラウザを駆動し、アバターのリップシンクを生成し、1280×800 macOS Sonoma フレームに 246 ピクセルの左下のアバター円を合成します。 GitHub URL はリポジトリ対応モード (README スキャン + ライブデモ検出) を有効にします。他の URL では、一般的なページウォークスルー フローが使用されます。
