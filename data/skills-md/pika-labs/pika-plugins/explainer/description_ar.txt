فيديو توضيحي يتراوح من 60 إلى 80 ثانية تقريبًا لأي عنوان URL — GitHub repo، أو صفحة المنتج، أو موقع المستندات، أو منشور المدونة، أو الإطلاق. سير العمل الأساسي لإرشادات URL. يُستخدم عندما يطلب المستخدم "شرح عنوان URL / الريبو / موقع الويب / المنتج"، أو "إنشاء مقطع فيديو تفصيلي لـ [url]"، أو "عرض توضيحي لهذا الموقع"، أو "شرح بنمط Loom لـ [url]"، أو "شرح لـ github.com/..."، أو "شرح رابط المنتج هذا". يقود متصفحًا حقيقيًا من خلال عنوان URL، وينشئ صورة رمزية لمزامنة الشفاه، ومركبات في إطار macOS Sonoma بدقة 1280 × 800 مع دائرة صور رمزية سفلية يسارية بحجم 246 بكسل. تقوم عناوين URL لـ GitHub بتنشيط وضع إعادة الشراء (مسح README + الكشف التجريبي المباشر)؛ تستخدم عناوين URL الأخرى مسارًا عامًا للإرشادات التفصيلية للصفحة.
