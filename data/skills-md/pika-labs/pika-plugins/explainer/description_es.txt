~Video explicativo de los años 60 a 80 para cualquier URL: repositorio de GitHub, página de producto, sitio de documentos, publicación de blog o lanzamiento. Flujo de trabajo canónico para tutoriales de URL. Úselo cuando el usuario solicite "explicar esta URL/repositorio/sitio web/producto", "hacer un video tutorial para [url]", "demostrar este sitio", "explicación estilo Loom de [url]", "explicación de github.com/..." o "explicar el enlace de este producto". Gestiona un navegador real a través de la URL, genera una sincronización labial de avatar y compone en un marco macOS Sonoma de 1280×800 con un círculo de avatar inferior izquierdo de 246 píxeles. Las URL de GitHub activan un modo compatible con repositorios (escaneo LÉAME + detección de demostración en vivo); otras URL utilizan un flujo de recorrido de página genérico.
