Vidéo explicative des années 60 à 80 pour n'importe quelle URL : dépôt GitHub, page produit, site de documentation, article de blog ou lancement. Flux de travail canonique pour les visites guidées d'URL. À utiliser lorsque l'utilisateur demande « d'expliquer cette URL/dépôt/site Web/produit », « de faire une vidéo pas à pas pour [url] », « de faire une démonstration de ce site », « d'expliquer de style métier à tisser de [url] », « d'expliquer pour github.com/… » ou « d'expliquer ce lien de produit ». Pilote un véritable navigateur via l'URL, génère une synchronisation labiale d'avatar et des composites dans un cadre macOS Sonoma 1280 × 800 avec un cercle d'avatar en bas à gauche de 246 pixels. Les URL GitHub activent un mode compatible avec les dépôts (analyse README + détection de démonstration en direct) ; d'autres URL utilisent un flux de présentation de page générique.
