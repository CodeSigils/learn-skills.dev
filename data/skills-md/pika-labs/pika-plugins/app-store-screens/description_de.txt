Generieren Sie 5–6 App Store-Screenshots in der Ästhetik einer bestimmten Marke aus einer „brand.md“, rohen Produkt-Screenshots oder einem öffentlichen App Store-Eintrag, der über Pika MCP abgerufen wird. Storybasiert (Hook → Value → Features → Proof → Close), spritzig, markenkonform. Gibt 1290 x 2796 PNGs aus, die sofort in App Store Connect abgelegt werden können. Verwenden Sie diese Option, wenn jemand App Store-/Store-Eintrags-Assets möchte – einschließlich: „App Store-Screenshots für mich erstellen“, „App Store-Bildschirme für [Marke] entwerfen“, „Ich habe eine brand.md und Screenshots, Store-Assets generieren“, „Screenshot-Set für App-Start“, „iOS Store-Bildschirme“, „App Store-Creative“, „Store-Eintragsvisualisierungen“, „spritzige App Store-Bildschirme“, „App-Store-Bildschirme“.
