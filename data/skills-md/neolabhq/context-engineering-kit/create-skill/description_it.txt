Guida per creare competenze efficaci. Questo comando deve essere utilizzato quando gli utenti desiderano creare una nuova competenza (o aggiornare una competenza esistente) che estenda le capacità di Claude con conoscenze specializzate, flussi di lavoro o integrazioni di strumenti. Da utilizzare quando si creano nuove competenze, si modificano competenze esistenti o si verifica il lavoro delle competenze prima della distribuzione: applica TDD alla documentazione di processo testando con agenti secondari prima della scrittura, ripetendo fino a quando non è a prova di bomba contro la razionalizzazione
