Initialisez ou refactorisez un projet avec la chaîne d'outils Python moderne (uv, ruff, ty) : générer/ajuster pyproject.toml, commandes de vérification locales, pré-commit et modèles CI ; à partir de la version 3.12, parcourez les nouveautés de chaque version pour exploiter les nouvelles fonctionnalités, en fonction de la version minimale du projet (par défaut ≥3.12, idéalement le dernier micro stable). Doit être chargé lorsque l'utilisateur dit « nouveau projet Python », « écrire un script autonome maintenable », « unifier les vérifications lint/format/type » ou mentionne l'ingénierie uv/ruff/ty/Python ; s'aligne sur la base de référence Python des préférences techniques, tandis que cette compétence gère les étapes concrètes et le contenu des fichiers.
