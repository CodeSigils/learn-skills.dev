Initialisez ou refactorisez des projets avec la chaîne d'outils Python moderne (uv, ruff, ty) : générer/ajuster pyproject.toml, commandes de vérification locales, pré-commit et modèles CI ; à partir de la 3.12, lisez les nouveautés de chaque version afin d'utiliser les nouvelles fonctionnalités selon la version minimale du projet (par défaut ≥3.12, de préférence la dernière mineure stable). Doit être chargé lors de la « création d'un nouveau projet Python », de « l'écriture de scripts autonomes maintenables », de « l'unification des vérifications lint/format/type », ou lorsque l'utilisateur mentionne l'ingénierie uv/ruff/ty/Python ; Conformément à la base de référence Python dans les préférences techniques, cette compétence est responsable des étapes de mise en œuvre et du contenu des fichiers.
