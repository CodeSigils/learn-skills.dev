Инициализируйте или реорганизуйте проекты с помощью современной цепочки инструментов Python (uv, ruff, ty): сгенерируйте/настройте pyproject.toml, команды локальной проверки, шаблоны предварительной фиксации и CI; начиная с 3.12, читайте раздел «Что нового» для каждой версии, чтобы использовать новые функции в соответствии с минимальной версией проекта (по умолчанию ≥3.12, предпочтительно последняя стабильная минорная версия). Должен загружаться при «создании нового проекта Python», «написании поддерживаемых автономных сценариев», «унификации проверок lint/format/type», или когда пользователь упоминает разработку uv/ruff/ty/Python; В соответствии с базовыми настройками Python в технических настройках этот навык отвечает за этапы реализации и содержимое файлов.
