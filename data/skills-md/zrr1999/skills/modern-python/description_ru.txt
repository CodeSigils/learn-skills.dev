Инициализируйте или перенесите проект с помощью современной цепочки инструментов Python (uv, ruff, ty): сгенерируйте/настройте pyproject.toml, команды локальной проверки, предварительную фиксацию и шаблоны CI; начиная с 3.12, просматривайте раздел «Что нового» в каждой версии, чтобы использовать новые функции, ориентируясь на минимальную версию проекта (по умолчанию ≥3.12, предпочтительно последнюю стабильную микроверсию). Загружается, когда пользователь говорит «новый проект Python», «напишите удобный в сопровождении автономный скрипт», «унифицируйте lint/format/type-check» или упоминает разработку uv/ruff/ty/Python; соответствует базовым показателям Python для технических предпочтений, а этот навык предоставляет конкретные шаги и содержимое файла.
