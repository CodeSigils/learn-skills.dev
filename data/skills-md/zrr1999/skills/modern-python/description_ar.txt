تهيئة مشروع أو إعادة هيكلته باستخدام سلسلة أدوات Python الحديثة (uv، ruff، ty): إنشاء/ضبط pyproject.toml، وأوامر الفحص المحلية، وقوالب الالتزام المسبق وCI؛ بدءًا من 3.12، اقرأ الميزات الجديدة لكل إصدار حتى الحد الأدنى للمشروع (الافتراضي >=3.12، استخدم أحدث إصدار صغير مستقر كلما أمكن ذلك) لاستغلال الميزات الجديدة. يجب أن يتم تحميله عندما يقول المستخدم "مشروع Python جديد"، أو "يكتب نصًا مستقلاً يمكن صيانته"، أو "توحيد فحص الوبر/التنسيق/النوع"، أو يذكر هندسة uv/ruff/ty/Python؛ تتماشى هذه المهارة مع خط Python الأساسي للتفضيلات التقنية، وتتعامل هذه المهارة مع الخطوات الملموسة ومحتويات الملف.
