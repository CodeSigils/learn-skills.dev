Analysieren Sie beliebige Vermögenswerte (Aktien, Kryptowährungen, Devisen) mithilfe von Smart Money Concepts (SMC) und Candle Range Theory (CRT). Verwenden Sie diese Option, wenn der Benutzer eine technische Analyse, Marktstrukturanalyse, Liquiditätsanalyse, Identifizierung von Orderblöcken oder das Lesen von Preisaktionen anfordert. Zu den Auslösern gehören „SMC-Analyse“, „CRT-Analyse“, „Marktstruktur“, „Auftragsblöcke“, „Liquiditäts-Sweep“, „Strukturbruch“, „Charakteränderung“, „Fair-Value-Lücke“, „Ungleichgewicht“, „Prämie/Rabatt“, „Smart Money“, „Institutional Flow“, „POI“, „Sniper Entry“, „Schildkrötensuppe“, „Wo ist Smart Money“, „Wyckoff“, „Elliott Wave“ oder jede Anfrage zur Analyse von Preisdiagrammen mithilfe institutioneller Orderflow-Konzepte. Wird auch bei der Analyse von Ein-/Ausstiegspunkten, der Platzierung von Stop-Loss oder der Identifizierung von Manipulationsmustern in einem beliebigen Zeitrahmen ausgelöst.
