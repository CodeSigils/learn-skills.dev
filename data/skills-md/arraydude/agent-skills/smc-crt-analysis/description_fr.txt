Analysez n'importe quel actif (actions, crypto, forex) à l'aide de Smart Money Concepts (SMC) et de Candle Range Theory (CRT). À utiliser lorsque l'utilisateur demande une analyse technique, une analyse de la structure du marché, une analyse de la liquidité, une identification du bloc d'ordres ou une lecture de l'action des prix. Les déclencheurs incluent « analyse SMC », « analyse CRT », « structure de marché », « blocs d'ordres », « balayage de liquidité », « rupture de structure », « changement de caractère », « écart de juste valeur », « déséquilibre », « prime/remise », « argent intelligent », « flux institutionnel », « POI », « entrée de sniper », « soupe aux tortues », « où est l'argent intelligent », « Wyckoff », « Elliott Wave » ou toute demande d'analyse de graphiques de prix utilisant les concepts de flux d'ordres institutionnels. Se déclenche également lors de l'analyse des points d'entrée/sortie, du placement du stop loss ou de l'identification de modèles de manipulation sur n'importe quelle période.
