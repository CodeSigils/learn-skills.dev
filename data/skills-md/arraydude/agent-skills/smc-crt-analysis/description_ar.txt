قم بتحليل أي أصل (الأسهم والعملات المشفرة والفوركس) باستخدام مفاهيم الأموال الذكية (SMC) ونظرية نطاق الشموع (CRT). يُستخدم عندما يطلب المستخدم التحليل الفني، أو تحليل هيكل السوق، أو تحليل السيولة، أو تحديد كتلة الطلب، أو قراءة حركة السعر. تتضمن المشغلات "تحليل SMC"، "تحليل CRT"، "هيكل السوق"، "كتل الأوامر"، "اجتياح السيولة"، "انهيار الهيكل"، "تغيير الشخصية"، "فجوة القيمة العادلة"، "عدم التوازن"، "علاوة / خصم"، "الأموال الذكية"، "التدفق المؤسسي"، "النقاط المهمة"، "دخول القناصة"، "حساء السلحفاة"، "أين الأموال الذكية"، "Wyckoff"، "موجة إليوت"، أو أي طلب لتحليل الرسوم البيانية للسعر باستخدام مفاهيم تدفق النظام المؤسسي. يتم تفعيله أيضًا عند تحليل نقاط الدخول/الخروج أو وضع إيقاف الخسارة أو تحديد أنماط التلاعب في أي إطار زمني.
