Binance Onchain Payを使用すると、ユーザーは単一フローで法定通貨（ユーロ、米ドルなど）で暗号通貨を購入したり、既存の暗号通貨をBinanceアカウントから外部のオンチェーンウォレットアドレスに直接送信したりできます。手動での出金は必要ありません。

パートナーが暗号通貨購入サービスを統合できるようにします。
-payment-method-list: 法定通貨/暗号通貨ペアの制限付きで利用可能な支払い方法 (カード、P2P、Google Pay、Apple Pay など) を取得します。
- 取引ペア: サポートされているすべての法定通貨と暗号通貨をリストします。
- 見積価格: 為替レート、手数料、仮想通貨の推定金額を含むリアルタイムの価格見積を取得します。
- 事前注文: 購入注文を作成し、Binance 支払いフローへのリダイレクト URL を取得します。
- 注文: 注文のステータスと詳細 (処理中、完了、失敗など) を照会します。
- 暗号ネットワーク: 出金手数料と制限付きでサポートされているブロックチェーン ネットワークを入手します
- p2p/trading-pairs: P2P 固有の取引ペアをリストします。
