Mit Binance Onchain Pay können Benutzer Kryptowährungen mit Fiat (z. B. EUR, USD) kaufen oder vorhandene Kryptowährungen von ihrem Binance-Konto in einem einzigen Vorgang direkt an eine beliebige externe On-Chain-Wallet-Adresse senden – eine manuelle Auszahlung ist nicht erforderlich.

Ermöglicht Partnern die Integration von Krypto-Kaufdiensten:
- Liste der Zahlungsmethoden: Erhalten Sie verfügbare Zahlungsmethoden (Karte, P2P, Google Pay, Apple Pay usw.) mit Limits für ein Fiat/Krypto-Paar
- Handelspaare: Listet alle unterstützten Fiat-Währungen und Kryptowährungen auf
- Geschätztes Angebot: Erhalten Sie ein Preisangebot in Echtzeit, einschließlich Wechselkurs, Gebühren und geschätztem Kryptobetrag
- Vorbestellung: Erstellen Sie eine Kaufbestellung und erhalten Sie eine Weiterleitungs-URL zum Binance-Zahlungsablauf
- Bestellung: Bestellstatus und -details abfragen (Bearbeitung, abgeschlossen, fehlgeschlagen usw.)
- Krypto-Netzwerk: Erhalten Sie unterstützte Blockchain-Netzwerke mit Abhebungsgebühren und -limits
- p2p/trading-pairs: P2P-spezifische Handelspaare auflisten
