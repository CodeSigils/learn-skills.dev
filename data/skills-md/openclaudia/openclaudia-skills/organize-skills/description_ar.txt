تدقيق وإعادة تنظيم مكتبة مهارات Claude Code / Codex - فرض اصطلاح تسمية (ابدأ كل مهارة تلامسها الواجهة الخلفية أو المنتج)، وأعد تسمية المهارات بشكل متسق، وأصلح الارتباطات الرمزية والإسنادات الترافقية لفواصل إعادة التسمية، وأبلغ عن الارتباطات الرمزية المعطلة ومراجع الأسماء القديمة. يُستخدم عندما يقول المستخدم "تنظيم مهاراتي"، أو "إعادة تسمية هذه المهارات"، أو "تنظيف مكتبة المهارات"، أو "فرض اصطلاح تسمية المهارات"، أو "إصلاح الارتباطات الرمزية للمهارات المعطلة".
