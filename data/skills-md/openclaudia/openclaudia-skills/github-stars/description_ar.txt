اعرض نمو النجوم في GitHub repo كمخططات CLI - حسب اليوم والساعة، في أي منطقة زمنية. يُستخدم عندما يطلب المستخدم "التحقق من نجوم GitHub"، أو "النجوم حسب الساعة/اليوم لـ <repo>"، أو "نمو النجوم"، أو "كم عدد النجوم التي حصل عليها <repo> اليوم"، أو يشارك اسم الريبو ويريد نشاط البطولة الخاص به بمرور الوقت.
