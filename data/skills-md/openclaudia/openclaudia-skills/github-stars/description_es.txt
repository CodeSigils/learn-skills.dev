Muestre el crecimiento de estrellas de un repositorio de GitHub como gráficos CLI, por día y por hora, en cualquier zona horaria. Úselo cuando el usuario solicite "verificar las estrellas de GitHub", "estrellas por hora/día para <repo>", "crecimiento de estrellas", "cuántas estrellas obtuvo <repo> hoy" o comparte un nombre de repositorio y desea que su actividad destacada se desarrolle a lo largo del tiempo.
