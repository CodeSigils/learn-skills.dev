Affichez la croissance des étoiles d'un dépôt GitHub sous forme de graphiques CLI, par jour et par heure, dans n'importe quel fuseau horaire. À utiliser lorsque l'utilisateur demande de « vérifier les étoiles GitHub », « les étoiles par heure/jour pour <repo> », « la croissance des étoiles », « combien d'étoiles <repo> a-t-il obtenu aujourd'hui », ou partage un nom de dépôt et souhaite son activité vedette au fil du temps.
