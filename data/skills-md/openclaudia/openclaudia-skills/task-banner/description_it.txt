Imposta (o attiva) un banner sul desktop macOS che appare ogni volta che Claude Code termina un'attività, mostrando un riepilogo di una riga di ciò che è stato fatto. Da utilizzare quando l'utente dice "avvisami quando Claude ha finito", "notifica sul desktop al completamento", "imposta il banner dell'attività", "disattiva il banner" o "riattiva il banner".
