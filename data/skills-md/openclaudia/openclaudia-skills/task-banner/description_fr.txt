Configurez (ou activez) une bannière de bureau macOS qui apparaît chaque fois que Claude Code termine une tâche, affichant un résumé d'une ligne de ce qui a été fait. À utiliser lorsque l'utilisateur dit « avertissez-moi lorsque Claude a terminé », « notification sur le bureau à la fin », « configurer la bannière de tâche », « désactiver la bannière » ou « réactiver la bannière ».
