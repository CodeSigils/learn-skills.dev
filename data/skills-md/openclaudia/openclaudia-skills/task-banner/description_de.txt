Richten Sie ein macOS-Desktop-Banner ein (oder schalten Sie es ein), das immer dann angezeigt wird, wenn Claude Code eine Aufgabe abschließt, und eine einzeilige Zusammenfassung dessen anzeigt, was erledigt wurde. Wird verwendet, wenn der Benutzer sagt: „Benachrichtige mich, wenn Claude fertig ist“, „Desktop-Benachrichtigung bei Abschluss“, „Aufgabenbanner einrichten“, „Banner stummschalten“ oder „Stummschaltung des Banners aufheben“.
