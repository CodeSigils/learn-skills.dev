Proporciona una guía de desarrollo integral para el motor de juego Cocos Creator 2.4, que cubre el sistema de componentes (cc.Class, cc._decorator), devoluciones de llamadas del ciclo de vida, sistema de eventos, manejo de recursos de Asset Manager, sistema de interpolación/acción, grupos de objetos, sistema de interfaz de usuario, colisiones físicas y optimización de anuncios reproducibles. Se activa cuando los usuarios escriben o refactorizan código TypeScript/JavaScript de Cocos Creator 2.x, implementan funciones del juego, manejan la carga y liberación de recursos, optimizan el rendimiento/tamaño del paquete, revisan cambios de código o configuran una arquitectura de proyecto publicitario reproducible. También se aplica cuando los usuarios mencionan API 2.x como cc.Class, cc.Component, cc.Node, cc.resources, cc.assetManager, cc.tween, etc.
