Fournit des conseils de développement complets pour le moteur de jeu Cocos Creator 2.4, couvrant le système de composants (cc.Class, cc._decorator), les rappels du cycle de vie, le système d'événements, la gestion des ressources Asset Manager, le système d'interpolation/action, le pool d'objets, le système d'interface utilisateur, les collisions physiques et l'optimisation des publicités jouables. Déclenché lorsque les utilisateurs écrivent ou refactorisent le code TypeScript/JavaScript de Cocos Creator 2.x, implémentent des fonctionnalités de jeu, gèrent le chargement et la publication des ressources, optimisent les performances/la taille du package, révisent les modifications de code ou créent une architecture de projet publicitaire jouable. Applicable également lorsque les utilisateurs mentionnent des API 2.x telles que cc.Class, cc.Component, cc.Node, cc.resources, cc.assetManager, cc.tween, etc.
