Fornisce una guida completa allo sviluppo per il motore di gioco Cocos Creator 2.4, coprendo il sistema di componenti (cc.Class, cc._decorator), callback del ciclo di vita, sistema di eventi, gestione delle risorse di Asset Manager, sistema di interpolazione/azione, pool di oggetti, sistema di interfaccia utente, collisione fisica e ottimizzazione degli annunci riproducibili. Si attiva quando gli utenti scrivono o effettuano il refactoring del codice TypeScript/JavaScript di Cocos Creator 2.x, implementano funzionalità di gioco, gestiscono il caricamento e il rilascio delle risorse, ottimizzano le prestazioni/dimensioni del pacchetto, esaminano le modifiche al codice o impostano l'architettura del progetto di annunci riproducibili. Applicabile anche quando gli utenti menzionano API 2.x come cc.Class, cc.Component, cc.Node, cc.resources, cc.assetManager, cc.tween e così via.
