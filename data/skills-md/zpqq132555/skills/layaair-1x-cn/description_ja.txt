LayaAir 1.0 ゲーム エンジンの包括的な開発ガイダンスを提供し、スプライト表示オブジェクト、EventDispatcher イベント システム、Laya.loader リソースの読み込み、トゥイーン イージング、タイマー タイマー、テキストおよび UI システム、パフォーマンスの最適化をカバーします。ユーザーが LYAAIR 1.0 TypeScript コードを作成またはリファクタリングしたり、イベント リスニング、リソースの読み込み、アニメーションのイージングを実装したり、再生可能な広告を最適化したりするとトリガーされます。 Laya.init、Laya.stage、Laya.loader、Laya.Tween、laya.display.Sprite、laya.utils.Handler、laya.events.EventDispatcher などの LYAAIR 1.x API について言及する場合にも適用されます。
