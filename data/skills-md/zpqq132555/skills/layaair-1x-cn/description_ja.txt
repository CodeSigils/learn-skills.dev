LayaAir 1.0 ゲーム エンジンの包括的な開発ガイダンスを提供し、スプライト表示オブジェクト、EventDispatcher イベント システム、Laya.loader リソースの読み込み、トゥイーン イージング、タイマー タイマー、テキストおよび UI システム、パフォーマンスの最適化をカバーします。ユーザーが LayaAir 1.0 TypeScript コードを作成またはリファクタリングするとき、イベント リスナー、リソースの読み込み、アニメーションのトゥイーンを実装するとき、または再生可能な広告を最適化するときにトリガーされます。 Laya.init、Laya.stage、Laya.loader、Laya.Tween、laya.display.Sprite、laya.utils.Handler、laya.events.EventDispatcher、およびその他の LayaAir 1.x API について言及する場合にも適用されます。
