Fournit des conseils de développement complets pour le moteur de jeu LayaAir 1.0, couvrant les objets d'affichage Sprite, le système d'événements EventDispatcher, le chargement des ressources Laya.loader, l'assouplissement Tween, la minuterie, les systèmes de texte et d'interface utilisateur et l'optimisation des performances. Déclenché lorsque les utilisateurs écrivent ou refactorisent le code TypeScript LayaAir 1.0, mettent en œuvre l'écoute d'événements, le chargement de ressources, interpolent des animations ou optimisent les publicités lisibles. Applicable également lorsque l'on mentionne les API LayaAir 1.x telles que Laya.init, Laya.stage, Laya.loader, Laya.Tween, laya.display.Sprite, laya.utils.Handler, laya.events.EventDispatcher.
