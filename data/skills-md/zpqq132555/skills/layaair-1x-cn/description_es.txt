Proporciona una guía de desarrollo integral para el motor de juego LayaAir 1.0, que cubre objetos de visualización Sprite, sistema de eventos EventDispatcher, carga de recursos Laya.loader, facilitación de interpolación, temporizadores, sistemas de texto y UI, y optimización del rendimiento. Se activa cuando los usuarios escriben o refactorizan código TypeScript LYAAIR 1.0, implementan escucha de eventos, carga de recursos, facilitan animaciones u optimizan anuncios reproducibles. También se aplica cuando se mencionan API de LYAAIR 1.x como Laya.init, Laya.stage, Laya.loader, Laya.Tween, laya.display.Sprite, laya.utils.Handler, laya.events.EventDispatcher.
