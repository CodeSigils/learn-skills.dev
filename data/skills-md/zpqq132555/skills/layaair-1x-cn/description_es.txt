Proporciona una guía de desarrollo integral para el motor de juego LayaAir 1.0, que cubre objetos de visualización Sprite, sistema de eventos EventDispatcher, carga de recursos Laya.loader, facilitación de interpolación, temporizadores, sistemas de texto y UI, y optimización del rendimiento. Se activa cuando los usuarios escriben o refactorizan código TypeScript de LayaAir 1.0, implementan detectores de eventos, carga de recursos, interpolan animaciones u optimizan anuncios reproducibles. También se aplica cuando se menciona Laya.init, Laya.stage, Laya.loader, Laya.Tween, laya.display.Sprite, laya.utils.Handler, laya.events.EventDispatcher y otras API de LayaAir 1.x.
