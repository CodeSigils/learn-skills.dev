Fornisce una guida completa allo sviluppo per il motore di gioco LayaAir 1.0, coprendo gli oggetti di visualizzazione Sprite, il sistema di eventi EventDispatcher, il caricamento delle risorse Laya.loader, l'easing Tween, i timer del timer, i sistemi di testo e interfaccia utente e l'ottimizzazione delle prestazioni. Si attiva quando gli utenti scrivono o effettuano il refactoring del codice TypeScript LYAAIR 1.0, implementano l'ascolto di eventi, il caricamento di risorse, facilitano le animazioni o ottimizzano gli annunci riproducibili. Applicabile anche quando si menzionano le API LYAAIR 1.x come Laya.init, Laya.stage, Laya.loader, Laya.Tween, laya.display.Sprite, laya.utils.Handler, laya.events.EventDispatcher.
