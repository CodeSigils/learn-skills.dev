スクリプト/コンポーネント システム (スクリプト/コンポーネント ライフサイクル)、EventDispatcher イベント システム、Laya.loader リソースの読み込み、トゥイーン イージング、タイマー タイマー、表示オブジェクト (スプライト/テキスト/画像)、UI システム、プレイアブル広告の最適化をカバーする、LayaAir 2.0 ゲーム エンジンの包括的な開発ガイダンスを提供します。ユーザーが LayaAir 2.0 TypeScript コードの作成またはリファクタリング、スクリプト コンポーネントの実装、イベント リスナーの処理、リソースの読み込み、トゥイーン アニメーション、パフォーマンスの最適化、再生可能な広告プロジェクトを行うときにトリガーされます。 Laya.init、Laya.stage、Laya.loader、Laya.Tween、laya.display.Sprite、laya.utils.Handler、laya.events.EventDispatcher などの LayaAir 2.x API に言及する場合にも適用されます。
