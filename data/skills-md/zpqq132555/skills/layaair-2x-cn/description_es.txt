Proporciona una guía de desarrollo integral para el motor de juego LayaAir 2.0, que cubre el sistema de componentes de secuencia de comandos (ciclo de vida de secuencia de comandos/componente), el sistema de eventos EventDispatcher, la carga de recursos de Laya.loader, la facilitación de interpolación, el temporizador, los objetos de visualización (Sprite/Texto/Imagen), el sistema de interfaz de usuario y la optimización de anuncios reproducibles. Se activa cuando los usuarios escriben o refactorizan código TypeScript de LayaAir 2.0, implementan componentes de script, manejan detectores de eventos, cargan recursos, crean animaciones de interpolación, optimizan el rendimiento o trabajan en proyectos publicitarios reproducibles. También se aplica cuando se mencionan API de LayaAir 2.x como Laya.init, Laya.stage, Laya.loader, Laya.Tween, laya.display.Sprite, laya.utils.Handler y laya.events.EventDispatcher.
