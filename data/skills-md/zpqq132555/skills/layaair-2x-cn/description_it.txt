Fornisce una guida completa allo sviluppo per il motore di gioco LayaAir 2.0, coprendo il sistema dei componenti di script (ciclo di vita dello script/componente), il sistema di eventi EventDispatcher, il caricamento delle risorse Laya.loader, l'easing Tween, il timer, gli oggetti di visualizzazione (Sprite/Testo/Immagine), il sistema di interfaccia utente e l'ottimizzazione degli annunci riproducibili. Si attiva quando gli utenti scrivono o effettuano il refactoring del codice LayaAir 2.0 TypeScript, implementano componenti di script, gestiscono listener di eventi, caricano risorse, creano animazioni di interpolazione, ottimizzano le prestazioni o lavorano su progetti pubblicitari riproducibili. Applicabile anche quando si menzionano API LayaAir 2.x come Laya.init, Laya.stage, Laya.loader, Laya.Tween, laya.display.Sprite, laya.utils.Handler e laya.events.EventDispatcher.
