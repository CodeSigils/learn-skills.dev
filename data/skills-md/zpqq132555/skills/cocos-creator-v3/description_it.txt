Fornisce una guida completa allo sviluppo per il motore di gioco Cocos Creator 3.8, incluso il sistema di componenti (_decorator, Component), callback del ciclo di vita, sistema di eventi (EventTarget, input), gestione delle risorse, sistema di interpolazione, pool di oggetti, sistema di interfaccia utente, collisioni fisiche e ottimizzazione degli annunci riproducibili. Viene attivato quando gli utenti scrivono o effettuano il refactoring del codice TypeScript di Cocos Creator 3.x, implementano la funzionalità del gioco, gestiscono il caricamento e lo scaricamento delle risorse, ottimizzano le prestazioni/dimensioni del pacchetto, rivedono le modifiche al codice o creano un'architettura di progetto pubblicitario riproducibile. Si applica anche quando gli utenti menzionano API 3.x come importazione da "cc", componente, nodo, risorse, interpolazione, direttore, ecc.
