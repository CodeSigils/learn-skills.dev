Fournit des conseils de développement complets pour le moteur de jeu Cocos Creator 3.8, y compris le système de composants (_decorator, Component), les rappels du cycle de vie, le système d'événements (EventTarget, input), la gestion des ressources, le système d'interpolation, le pool d'objets, le système d'interface utilisateur, les collisions physiques et l'optimisation des publicités jouables. Il est déclenché lorsque les utilisateurs écrivent ou refactorisent le code Cocos Creator 3.x TypeScript, implémentent des fonctionnalités de jeu, gèrent le chargement et le déchargement des ressources, optimisent les performances/taille du package, révisent les modifications de code ou créent une architecture de projet publicitaire jouable. Cela s'applique également lorsque les utilisateurs mentionnent des API 3.x telles que l'importation depuis 'cc', un composant, un nœud, des ressources, une interpolation, un directeur, etc.
