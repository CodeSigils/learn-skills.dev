يوفر إرشادات تطوير شاملة لمحرك اللعبة Cocos Creator 3.8، بما في ذلك نظام المكونات (_decorator، Component)، وعمليات رد الاتصال لدورة الحياة، ونظام الأحداث (EventTarget، الإدخال)، وإدارة الموارد، ونظام التخفيف المزدوج، وتجمع الكائنات، ونظام واجهة المستخدم، والتصادمات الفيزيائية، وتحسين الإعلانات القابلة للتشغيل. يتم تشغيله عندما يقوم المستخدمون بكتابة كود Cocos Creator 3.x TypeScript أو إعادة تصميمه، أو تنفيذ وظائف اللعبة، أو التعامل مع تحميل الموارد وتفريغها، أو تحسين الأداء/حجم الحزمة، أو مراجعة تغييرات التعليمات البرمجية، أو إنشاء بنية مشروع إعلاني قابل للتشغيل. وينطبق أيضًا عندما يذكر المستخدمون واجهات برمجة التطبيقات 3.x مثل الاستيراد من 'cc'، أو Component، أو Node، أو Resources، أو tween، أو Director، وما إلى ذلك.
