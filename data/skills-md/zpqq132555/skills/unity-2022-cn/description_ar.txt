يوفر إرشادات التطوير الشاملة لمحرك اللعبة Unity 2022.3 LTS، الذي يغطي دورة حياة MonoBehaviour، ونظام GameObject/Component، والتحويل، والتصادمات الفيزيائية (Rigidbody/Collider)، وأنظمة الإدخال (Input Manager/Input System)، وأنظمة واجهة المستخدم (uGUI/UI Toolkit)، وإدارة الأصول (Resources/Addressables/AssetBundle)، وcoroutines، ونظام الرسوم المتحركة (Animator/Animation)، ScriptableObject، وأنظمة الأحداث (UnityEvent/C# Event/Action)، وتجميع الكائنات، وإدارة المشهد، وتحسين الأداء. يتم تشغيله عندما يقوم المستخدمون بكتابة كود Unity 2022.x C# أو إعادة تصميمه، أو تنفيذ ميزات اللعبة، أو التعامل مع تحميل الأصول وتفريغها، أو تحسين الأداء، أو مراجعة تغييرات التعليمات البرمجية، أو تصميم مشاريع Unity. ينطبق أيضًا عندما يذكر المستخدمون Unity APIs مثل MonoBehaviour، وGameObject، وTransform، وRigidbody، وCollider، وCanvas، وSerializeField، وInstantiate، وDestroy، وSceneManager، وAddressables، وما إلى ذلك.
