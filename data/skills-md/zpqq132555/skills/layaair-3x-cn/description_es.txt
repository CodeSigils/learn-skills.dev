Proporciona una guía de desarrollo integral para el motor de juego LayaAir 3.x, incluido el sistema de componentes ECS (@regClass/@property decoradors, ciclo de vida del script), sistema de eventos (EventDispatcher, mouse/teclado/eventos físicos), carga de activos basada en promesas (Laya.loader.load), el nuevo sistema de facilitación de interpolación (cadena/paralelo), temporizador, agrupación de objetos (Laya.Pool), visualización de objetos 2D/3D, sistema de componentes UI, gestión de escenas (Scene.open/close), sistemas de física 2D/3D, adaptación de pantalla y optimización del rendimiento. Se activa cuando los usuarios escriben o refactorizan código TypeScript de LayaAir 3.x, implementan componentes de script, manejan detectores de eventos, carga de activos, interpolación de animaciones, optimización del rendimiento y proyectos publicitarios reproducibles. También se aplica cuando se menciona @regClass, @property, Laya.Script, Laya.loader.load (Promise), Laya.Tween.create, Laya.Scene.open, Laya.Pool, Sprite3D, Camera y otras API de LayaAir 3.x. Se activa incluso si el usuario solo menciona archivos de escena LayaAir, motor Laya o .ls.
