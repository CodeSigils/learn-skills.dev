Fornire una guida completa allo sviluppo per il motore di gioco LayaAir 3.x, incluso il sistema di componenti ECS (@regClass/@property decorators, ciclo di vita degli script), sistema di eventi (EventDispatcher, eventi mouse/tastiera/fisici), caricamento delle risorse basato su Promise (Laya.loader.load), il nuovo sistema di easing Tween (catena/parallelo), timer, pool di oggetti (Laya.P), oggetti di visualizzazione 2D/3D, sistema di componenti dell'interfaccia utente, gestione delle scene (Scene.open/close), sistemi fisici 2D/3D, adattamento dello schermo e ottimizzazione delle prestazioni. Si attiva quando gli utenti scrivono o effettuano il refactoring del codice L·Air 3.x TypeScript, implementano componenti di script, gestiscono l'ascolto di eventi, il caricamento di risorse, animazioni di interpolazione, ottimizzazione delle prestazioni o progetti di annunci riproducibili. Si applica anche quando si menzionano API LayaAir 3.x come @regClass, @property, Laya.Script, Laya.loader.load (Promise), Laya.Tween.create, Laya.Scene.open, Laya.P, Sprite3D, Camera, ecc. Anche se gli utenti menzionano solo LayaAir, Laya engine o file di scena .ls, questa abilità dovrebbe essere attivata.
