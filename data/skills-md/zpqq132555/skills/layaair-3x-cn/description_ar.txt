توفير إرشادات التطوير الشاملة لمحرك اللعبة LayaAir 3.x، بما في ذلك نظام مكونات ECS (@regClass/@propertydecorators، دورة حياة البرنامج النصي)، ونظام الأحداث (EventDispatcher، أحداث الماوس/لوحة المفاتيح/الفيزياء)، وتحميل الموارد المستندة إلى الوعد (Laya.loader.load)، ونظام تسهيل Tween الجديد (السلسلة/الموازية)، والمؤقت، وتجمع الكائنات (Laya.P)، وكائنات العرض ثنائية/ثلاثية الأبعاد، ومكون واجهة المستخدم النظام وإدارة المشهد (Scene.open/Close)، وأنظمة الفيزياء ثنائية وثلاثية الأبعاد، وتكييف الشاشة، وتحسين الأداء. يتم تشغيله عندما يقوم المستخدمون بكتابة كود L·Air 3.x TypeScript أو إعادة تصميمه، أو تنفيذ مكونات البرنامج النصي، أو التعامل مع الاستماع إلى الأحداث، أو تحميل الموارد، أو الرسوم المتحركة، أو تحسين الأداء، أو المشاريع الإعلانية القابلة للتشغيل. تنطبق أيضًا عند ذكر واجهات برمجة التطبيقات LayaAir 3.x مثل @regClass، و@property، وLaya.Script، وLaya.loader.load (Promise)، وLaya.Tween.create، وLaya.Scene.open، وLaya.P، وSprite3D، وCamera، وما إلى ذلك. حتى إذا ذكر المستخدمون فقط LayaAir، أو محرك Laya، أو ملفات المشهد .ls، فيجب تشغيل هذه المهارة.
