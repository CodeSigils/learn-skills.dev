Wird automatisch aktiviert, wenn der Benutzer Codeänderungen, Refactoring, Fehlerbehebungen oder neue Skripte anfordert; erzwingt Einzelverantwortung und Größen-/Komplexitätsbeschränkungen und führt eine sofortige Codeüberprüfung durch, sobald die Änderungen abgeschlossen sind. Beherrscht außerdem das erweiterte Typsystem von TypeScript (Generika, bedingte Typen, zugeordnete Typen, Vorlagenliteraltypen, Dienstprogrammtypen) und löst aus, wenn der Benutzer komplexe Typlogik implementiert, wiederverwendbare Typdienstprogramme erstellt oder die Typsicherheit zur Kompilierungszeit gewährleistet. Anwendbare Schlüsselwörter: Generisch, bedingte Typen, zugeordnete Typen, Infer, Keyof, Extends, Partial, Pick, Omit, Record, Code Review, Refactoring, Single Responsibility.
