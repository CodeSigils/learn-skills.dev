Wird automatisch aktiviert, wenn Benutzer Codeänderungen, Refactoring, Korrekturen oder neue Skripte anfordern, wodurch das Prinzip der Einzelverantwortung und Größen-/Komplexitätsbeschränkungen durchgesetzt werden, und führt eine sofortige Codeüberprüfung durch, sobald die Änderungen abgeschlossen sind. Beherrscht außerdem das erweiterte Typsystem von TypeScript (Generika, bedingte Typen, zugeordnete Typen, Vorlagenliteraltypen, Dienstprogrammtypen) und löst aus, wenn Benutzer komplexe Typlogik implementieren, wiederverwendbare Typdienstprogramme erstellen oder die Typsicherheit zur Kompilierungszeit gewährleisten.  
Anwendbare Schlüsselwörter: Generisch, bedingte Typen, zugeordnete Typen, Infer, Keyof, Extends, Partial, Pick, Omit, Record, Code Review, Refactoring, Single Responsibility.
