Se activa automáticamente cuando el usuario solicita modificaciones de código, refactorización, corrección de errores o nuevos scripts; aplica límites de responsabilidad única y de tamaño/complejidad, y realiza una revisión inmediata del código una vez que se completan los cambios. También domina el sistema de tipos avanzado de TypeScript (genéricos, tipos condicionales, tipos mapeados, tipos literales de plantilla, tipos de utilidades) y se activa cuando el usuario implementa lógica de tipos compleja, crea utilidades de tipos reutilizables o garantiza la seguridad de tipos en tiempo de compilación. Palabras clave aplicables: genérico, tipos condicionales, tipos mapeados, inferir, clave de, extensiones, parcial, seleccionar, omitir, registrar, revisión de código, refactorización, responsabilidad única.
