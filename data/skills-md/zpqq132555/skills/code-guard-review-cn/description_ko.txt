사용자가 코드 수정, 리팩토링, 버그 수정 또는 새 스크립트를 요청하면 자동으로 활성화됩니다. 단일 책임 및 크기/복잡성 제한을 적용하고 변경이 완료되면 즉시 코드 검토를 수행합니다. 또한 TypeScript의 고급 유형 시스템(제네릭, 조건부 유형, 매핑된 유형, 템플릿 리터럴 유형, 유틸리티 유형)에 능숙하며 사용자가 복잡한 유형 논리를 구현하거나 재사용 가능한 유형 유틸리티를 생성하거나 컴파일 타임 유형 안전성을 보장할 때 트리거됩니다. 적용 가능한 키워드: 일반, 조건부 유형, 매핑된 유형, 추론, 키, 확장, 부분, 선택, 생략, 기록, 코드 검토, 리팩토링, 단일 책임.
