Si attiva automaticamente quando l'utente richiede modifiche al codice, refactoring, correzioni o nuovi script, applicando limiti di singola responsabilità e dimensioni/complessità ed esegue immediatamente una revisione del codice dopo le modifiche. Competente anche nel sistema di tipi avanzato di TypeScript (generici, tipi condizionali, tipi mappati, tipi letterali di modello, tipi di utilità), attivato quando gli utenti implementano logica di tipo complessa, creano utilità di tipo riutilizzabili o garantiscono la sicurezza del tipo in fase di compilazione.  
Parole chiave applicabili: generico, tipi condizionali, tipi mappati, infer, keyof, extends, Partial, Pick, Omit, Record, revisione del codice, refactoring, responsabilità singola.
