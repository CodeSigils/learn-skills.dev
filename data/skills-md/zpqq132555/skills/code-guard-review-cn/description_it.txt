Si attiva automaticamente quando l'utente richiede modifiche al codice, refactoring, correzioni di bug o nuovi script; impone limiti di singola responsabilità e dimensioni/complessità ed esegue una revisione immediata del codice una volta completate le modifiche. È inoltre esperto nel sistema di tipi avanzato di TypeScript (generici, tipi condizionali, tipi mappati, tipi letterali di modello, tipi di utilità) e si attiva quando l'utente implementa una logica di tipo complessa, crea utilità di tipo riutilizzabili o garantisce la sicurezza del tipo in fase di compilazione. Parole chiave applicabili: generico, tipi condizionali, tipi mappati, infer, keyof, extends, Partial, Pick, Omit, Record, revisione del codice, refactoring, responsabilità singola.
