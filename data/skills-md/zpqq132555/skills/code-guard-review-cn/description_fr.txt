S'active automatiquement lorsque l'utilisateur demande des modifications de code, une refactorisation, des corrections de bogues ou de nouveaux scripts ; applique des limites de responsabilité unique et de taille/complexité, et effectue une révision immédiate du code une fois les modifications terminées. Maîtrise également le système de types avancé de TypeScript (génériques, types conditionnels, types mappés, types littéraux de modèles, types d'utilitaires) et se déclenche lorsque l'utilisateur implémente une logique de type complexe, crée des utilitaires de type réutilisables ou assure la sécurité des types au moment de la compilation. Mots-clés applicables : Générique, Types conditionnels, Types mappés, inférer, keyof, extends, Partial, Pick, Omit, Record, révision de code, refactoring, responsabilité unique.
