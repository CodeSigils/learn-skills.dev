Betreiben Sie die Eisenbahninfrastruktur: Erstellen Sie Projekte, stellen Sie Dienste und Datenbanken bereit, verwalten Sie Objektspeicher-Buckets, stellen Sie Code bereit, konfigurieren Sie Umgebungen und Variablen, verwalten Sie Domänen, beheben Sie Fehler, überprüfen Sie den Status und die Metriken und fragen Sie Eisenbahndokumente ab. Verwenden Sie diesen Skill immer dann, wenn der Benutzer Railway, Bereitstellungen, Dienste, Umgebungen, Buckets, Objektspeicher, Build-Fehler oder Infrastrukturvorgänge erwähnt, auch wenn er nicht explizit „Railway“ sagt.
