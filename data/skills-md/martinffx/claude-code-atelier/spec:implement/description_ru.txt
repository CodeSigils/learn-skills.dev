Выполняйте задачи внедрения из утвержденного plan.json. Используйте, когда spec:plan создал утвержденные задачи и человек готов приступить к кодированию. Отслеживает прогресс с помощью шариков, обеспечивает соблюдение TDD, составляет отчеты между пакетами. Запускается, когда пользователь говорит «внедрить», «идти», «начать», «сделать это» или после того, как spec:plan завершает создание задачи. НЕ используйте без утвержденного плана — сначала вызовите spec:plan.
