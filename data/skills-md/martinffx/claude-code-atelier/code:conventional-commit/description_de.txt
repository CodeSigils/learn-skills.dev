Generieren und validieren Sie konventionelle Commit-Nachrichten gemäß der Spezifikation „conventionalcommits.org“. Verwenden Sie es immer dann, wenn der Benutzer Code festschreiben möchte, Festschreibungsnachrichten erwähnt, Git-Festschreibungen vornimmt oder um die Erstellung einer Festschreibung bittet. Wird bei „Commit“, „Git Commit“, „Konventionell“ oder beim Überprüfen des Commit-Nachrichtenformats ausgelöst.
