Создавайте и проверяйте обычные сообщения о фиксации в соответствии со спецификацией Conventionalcommits.org. Используйте всякий раз, когда пользователь хочет зафиксировать код, упоминает сообщения о фиксации, git commit или просит создать фиксацию. Запускается при «фиксации», «git commit», «обычном» или при просмотре формата сообщения о фиксации.
