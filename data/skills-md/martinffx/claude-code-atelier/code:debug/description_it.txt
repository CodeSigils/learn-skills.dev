Flusso di lavoro e tecniche di debug sistematico. Da utilizzare quando qualcosa è rotto, non funziona come previsto o genera errori. Copre la riproduzione, l'isolamento, la formazione di ipotesi, l'implementazione delle correzioni e la verifica. Si attiva anche su "perché X fallisce", "debug di questo", "questo è rotto" o quando si riscontrano errori o comportamenti imprevisti.
