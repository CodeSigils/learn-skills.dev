Técnicas y flujo de trabajo de depuración sistemática. Úselo cuando algo esté roto, no funcione como se esperaba o arroje errores. Cubre la reproducción, el aislamiento, la formación de hipótesis, la implementación de correcciones y la verificación. También se activa cuando "por qué falla X", "depura esto", "esto no funciona" o cuando se encuentran errores o comportamientos inesperados.
