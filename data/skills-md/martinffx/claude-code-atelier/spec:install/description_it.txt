Installa questo plug-in Claude Code in un altro strumento di codifica AI (opencode, Claude Code, Gemini CLI, Codex CLI, Windsurf, ecc.). Da utilizzare quando l'utente chiede di installare, trasferire, migrare o sincronizzare questo plugin con un altro strumento oppure chiede "come posso usarlo in X". Attivato da frasi come "installa atelier", "porta su opencode", "sincronizza su Claude", "come posso usarlo nel cursore" o "aggiungi al Codex".
