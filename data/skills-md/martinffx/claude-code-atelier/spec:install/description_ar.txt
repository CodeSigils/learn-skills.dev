قم بتثبيت البرنامج الإضافي Claude Code في أداة ترميز أخرى تعمل بالذكاء الاصطناعي (opencode، Claude Code، Gemini CLI، Codex CLI، Windsurf، وما إلى ذلك). يُستخدم عندما يطلب المستخدم تثبيت هذا المكون الإضافي أو نقله أو ترحيله أو مزامنته مع أداة أخرى، أو يسأل "كيف يمكنني استخدام هذا في X". يتم تشغيلها بواسطة عبارات مثل "تثبيت ورشة عمل"، أو "منفذ إلى كود مفتوح"، أو "مزامنة مع Claude"، أو "كيف يمكنني استخدام هذا في المؤشر"، أو "إضافة إلى Codex".
