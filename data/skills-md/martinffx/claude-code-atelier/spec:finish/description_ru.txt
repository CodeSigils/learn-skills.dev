Рабочий процесс после завершения реализации. Используйте после завершения spec:implement для проверки, просмотра, создания составных коммитов и подготовки к PR. Срабатывает, когда реализация завершена, когда пользователь говорит «Готово», «Готово», «Завершено» или после завершения задач реализации.
