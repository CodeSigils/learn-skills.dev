أنماط إرسال الوكيل الفرعي لمهام التنفيذ. يُستخدم عندما يكون لدى spec:implement مهام متعددة للتنفيذ ويكون الوكلاء الفرعيون متاحين. يغطي الإرسال الموازي للعمل المستقل، ودورة المراجعة المكونة من مرحلتين (الامتثال للمواصفات ثم جودة الكود)، والبناء الفوري المركز، وتكامل النتائج. يتم التشغيل عند تنفيذ مهام الخطة بدعم الوكيل الفرعي، أو عند مواجهة أكثر من مشكلتين مستقلتين، أو عندما يطلب المستخدم استخدام الوكلاء الفرعيين للتنفيذ.
