Patrones de despacho de subagentes para tareas de implementación. Utilícelo cuando spec:implement tenga varias tareas que ejecutar y haya subagentes disponibles. Cubre el envío paralelo para trabajo independiente, el ciclo de revisión de dos etapas (cumplimiento de especificaciones y luego calidad del código), construcción rápida enfocada e integración de resultados. Se activa cuando se ejecutan tareas del plan con soporte de subagente, cuando se enfrentan a más de 2 problemas independientes o cuando el usuario solicita utilizar subagentes para la implementación.
