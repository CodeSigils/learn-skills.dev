Subagenten-Versandmuster für Implementierungsaufgaben. Verwenden Sie diese Option, wenn spec:implement mehrere Aufgaben ausführen muss und Subagenten verfügbar sind. Umfasst den parallelen Versand für unabhängige Arbeit, den zweistufigen Überprüfungszyklus (Spezifikationskonformität, dann Codequalität), gezielte zeitnahe Konstruktion und Integration der Ergebnisse. Wird ausgelöst, wenn Planaufgaben mit Subagentenunterstützung ausgeführt werden, wenn zwei oder mehr unabhängige Probleme auftreten oder wenn der Benutzer die Verwendung von Subagenten für die Implementierung anfordert.
