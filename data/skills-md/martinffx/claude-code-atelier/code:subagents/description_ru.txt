Шаблоны отправки субагентов для задач реализации. Используйте, когда spec:implement нужно выполнить несколько задач и доступны подагенты. Охватывает параллельную отправку для независимой работы, двухэтапный цикл проверки (соответствие спецификациям, затем качество кода), целенаправленное оперативное создание и интеграцию результатов. Триггер срабатывает при выполнении плановых задач с поддержкой субагентов, при возникновении 2+ независимых проблем или когда пользователь просит использовать субагенты для реализации.
