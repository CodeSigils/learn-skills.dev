Управляйте составными коммитами с помощью Graphite. Используйте, когда пользователь хочет создать несколько сложенных коммитов, управлять стеком коммитов, синхронизировать их с удаленным устройством или отправлять PR из стека. Срабатывает при «stacked», «stack», «gt», «graphite» или при работе с несколькими связанными коммитами.
