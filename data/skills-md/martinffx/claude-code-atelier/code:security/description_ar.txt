التدقيق الأمني ​​واكتشاف الثغرات الأمنية. يُستخدم عند مراجعة التعليمات البرمجية لمشكلات الأمان، أو فحص التبعيات، أو معالجة المخاوف الأمنية. يتم تشغيلها عند "الأمان"، أو "الضعف"، أو "التدقيق"، أو "CVE"، أو "الحقن"، أو "XSS"، أو "حقن SQL"، أو "المصادقة"، أو عندما يطلب المستخدم التحقق من مشكلات الأمان.
