専門のレビュー担当者によるマルチエージェントのコード レビュー、アーキテクチャの検証、およびチャレンジの検証を並行して実行します。 `rq` を使用して diff のレビュー (デフォルトは main ブランチ) をリクエストし、`rs` を使用して PR フィードバックに応答します。 PR、プル リクエスト、ブランチ、または差分を調べるときに、「これをレビューする」、「コードをレビューする」、「コード レビュー」、「バグを確認する」、「これを監査する」でトリガーされます。重大度プレフィックス (Blocker/Issue/Suggestion/Nit) を含む gfreview を介した行ごとの PR コメントをサポートします。修正を適用したり応答を投稿したりする前に、常にユーザーに質問します。
