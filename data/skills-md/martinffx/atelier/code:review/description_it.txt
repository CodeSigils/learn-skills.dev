Revisione del codice multi-agente con revisori specializzati paralleli, convalida dell'architettura e convalida delle sfide. Utilizza `rq` per richiedere una revisione di diffs (per impostazione predefinita il ramo principale), "rs" per rispondere al feedback delle PR. Si attiva su "rivedi questo", "rivedi il mio codice", "revisione del codice", "verifica la presenza di bug", "controlla questo", quando si esaminano PR, richieste pull, rami o differenze. Supporta commenti PR riga per riga tramite gfreview con prefissi di gravità (Blocker/Issue/Suggestion/Nit). Chiede sempre all'utente prima di applicare correzioni o pubblicare risposte.
