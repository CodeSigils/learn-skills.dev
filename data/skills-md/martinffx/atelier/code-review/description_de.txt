Multi-Agent-Codeüberprüfung mit parallelen spezialisierten Prüfern, Architekturvalidierung und Challenge-Validierung. Verwenden Sie „rq“, um eine Überprüfung der Unterschiede anzufordern (standardmäßig im Hauptzweig), und „rs“, um auf Überprüfungsergebnisse zu antworten. Wird bei „Überprüfe dies“, „Überprüfe meinen Code“, „Codeüberprüfung“, „Überprüfe auf Fehler“, „Überprüfe dies“ ausgelöst, wenn PRs, Pull Requests, Branches oder Diffs untersucht werden. Fragt den Benutzer immer, bevor er Korrekturen anwendet.
