Mentalidad universal de desarrollador y guía de flujo de trabajo de proyectos para proyectos de programación. Úselo al crear un nuevo proyecto, elegir o revisar una pila tecnológica, modificar una base de código existente, implementar funciones, corregir errores, escribir o actualizar documentación, diseñar arquitectura o estructura de carpetas, mejorar la coherencia de UI/UX, agregar pruebas, depurar errores, mejorar el rendimiento, preparar la implementación o trabajar en múltiples repositorios. Útil para desarrolladores experimentados, principiantes, no desarrolladores, fundadores y cualquier persona que necesite asistencia de IA para crear, mantener, documentar, probar, depurar o implementar software de forma segura.
