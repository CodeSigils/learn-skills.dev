Web サイト、モバイル アプリ、デスクトップ アプリの固定キャンバス HTML モックアップを作成して、AI エージェントが実装前に UI の方向を検証できるようにします。ユーザーがレイアウトのアイデア、ワイヤーフレーム、視覚的な比較、HTML プレビュー、モックアップを要求する場合、またはサイドバー、ナビゲーションバー、モーダル、ダッシュボード セクション、モバイル画面、またはデスクトップ パネルがどのように見えるかを確認したい場合に使用します。このスキルは常に、オプション A、オプション B、およびオプション C を 1 つの推奨オプションとともに提案し、レビューでユーザーの言語を反映し、Svelte CDN と TailwindCSS CDN テンプレートを使用し、ローカル プレビュー サーバーを起動し、モックアップ領域のみのスクリーンショット チェックポイントをキャプチャし、承認されたオプションを実装可能な計画に変換します。
