Crea modelli HTML a tela fissa per siti Web, app mobili e app desktop in modo che un agente AI possa verificare la direzione dell'interfaccia utente prima dell'implementazione. Da utilizzare quando un utente richiede idee per il layout, wireframe, confronti visivi, anteprime HTML, prototipi o desidera vedere come potrebbero apparire una barra laterale, una barra di navigazione, una sezione modale, una dashboard, uno schermo mobile o un pannello desktop. Questa competenza propone sempre l'Opzione A, l'Opzione B e l'Opzione C con un'opzione consigliata, rispecchia la lingua dell'utente nella revisione, utilizza i modelli CDN Svelte CDN più TailwindCSS, avvia un server di anteprima locale, acquisisce punti di controllo screenshot solo della regione del mockup e trasforma un'opzione approvata in un piano pronto per l'implementazione.
