Erstellen Sie HTML-Modelle mit festem Canvas für Websites, mobile Apps und Desktop-Apps, damit ein KI-Agent die UI-Richtung vor der Implementierung überprüfen kann. Verwenden Sie diese Option, wenn ein Benutzer nach Layout-Ideen, Wireframes, visuellen Vergleichen, HTML-Vorschauen oder Modellen fragt oder sehen möchte, wie eine Seitenleiste, eine Navigationsleiste, ein Modal, ein Dashboard-Abschnitt, ein mobiler Bildschirm oder ein Desktop-Panel aussehen könnte. Dieser Skill schlägt immer Option A, Option B und Option C mit einer empfohlenen Option vor, spiegelt die Sprache des Benutzers in der Rezension wider, verwendet Svelte CDN plus TailwindCSS CDN-Vorlagen, startet einen lokalen Vorschauserver, erfasst nur Screenshot-Prüfpunkte der Mockup-Region und wandelt eine genehmigte Option in einen umsetzungsbereiten Plan um.
