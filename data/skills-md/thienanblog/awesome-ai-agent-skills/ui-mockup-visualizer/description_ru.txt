Создавайте HTML-макеты с фиксированным холстом для веб-сайтов, мобильных и настольных приложений, чтобы агент ИИ мог проверить направление пользовательского интерфейса перед реализацией. Используйте, когда пользователь запрашивает идеи макета, каркасы, визуальное сравнение, предварительный просмотр HTML, макеты или хочет увидеть, как может выглядеть боковая панель, панель навигации, модальное окно, раздел информационной панели, экран мобильного телефона или панель рабочего стола. Этот навык всегда предлагает вариант A, вариант B и вариант C с одним рекомендуемым вариантом, отражает язык пользователя в обзоре, использует шаблоны CDN Svelte CDN и TailwindCSS, запускает локальный сервер предварительного просмотра, записывает контрольные точки снимков экрана только для региона макета и превращает утвержденный вариант в план, готовый к реализации.
