قم بإنشاء نماذج HTML ذات لوحة ثابتة لمواقع الويب وتطبيقات الأجهزة المحمولة وتطبيقات سطح المكتب حتى يتمكن وكيل الذكاء الاصطناعي من التحقق من اتجاه واجهة المستخدم قبل التنفيذ. يُستخدم عندما يطلب المستخدم أفكارًا للتخطيط، أو إطارات سلكية، أو مقارنة مرئية، أو معاينات HTML، أو نماذج بالحجم الطبيعي، أو يريد رؤية الشكل الذي يمكن أن يبدو عليه الشريط الجانبي، أو شريط التنقل، أو قسم الوسائط، أو قسم لوحة المعلومات، أو شاشة الهاتف المحمول، أو لوحة سطح المكتب. تقترح هذه المهارة دائمًا الخيار أ والخيار ب والخيار ج مع خيار واحد موصى به، وتعكس لغة المستخدم في المراجعة، وتستخدم قوالب Svelte CDN بالإضافة إلى TailwindCSS CDN، وتبدأ خادم معاينة محلي، وتلتقط نقاط فحص لقطة الشاشة لمنطقة النموذج فقط، وتحول الخيار المعتمد إلى خطة جاهزة للتنفيذ.
