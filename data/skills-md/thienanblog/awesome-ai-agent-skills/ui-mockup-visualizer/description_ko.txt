AI 에이전트가 구현 전에 UI 방향을 확인할 수 있도록 웹사이트, 모바일 앱, 데스크톱 앱을 위한 고정 캔버스 HTML 모형을 만듭니다. 사용자가 레이아웃 아이디어, 와이어프레임, 시각적 비교, HTML 미리보기, 모형을 요청하거나 사이드바, 탐색바, 모달, 대시보드 섹션, 모바일 화면 또는 데스크톱 패널이 어떻게 생겼는지 확인하려는 경우에 사용하세요. 이 기술은 항상 하나의 권장 옵션과 함께 옵션 A, 옵션 B 및 옵션 C를 제안하고, 검토에서 사용자의 언어를 미러링하고, Svelte CDN과 TailwindCSS CDN 템플릿을 사용하고, 로컬 미리 보기 서버를 시작하고, 목업 영역의 스크린샷 체크포인트만 캡처하고, 승인된 옵션을 구현 준비 계획으로 전환합니다.
