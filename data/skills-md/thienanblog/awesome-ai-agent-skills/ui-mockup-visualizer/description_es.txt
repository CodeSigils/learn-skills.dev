Cree maquetas HTML de lienzo fijo para sitios web, aplicaciones móviles y aplicaciones de escritorio para que un agente de IA pueda verificar la dirección de la interfaz de usuario antes de la implementación. Úselo cuando un usuario solicite ideas de diseño, estructuras alámbricas, comparaciones visuales, vistas previas HTML, maquetas o quiera ver cómo podría verse una barra lateral, una barra de navegación, un modal, una sección de panel, una pantalla móvil o un panel de escritorio. Esta habilidad siempre propone la Opción A, la Opción B y la Opción C con una opción recomendada, refleja el idioma del usuario en la revisión, utiliza plantillas CDN Svelte CDN más TailwindCSS, inicia un servidor de vista previa local, captura puntos de control de captura de pantalla de la región de la maqueta únicamente y convierte una opción aprobada en un plan listo para implementar.
