تصميم ومراجعة CLIs لاستهلاك وكيل الذكاء الاصطناعي. يغطي المخرجات المقروءة آليًا، وتقوية المدخلات ضد الهلوسة، واستبطان المخطط، وانضباط نافذة السياق، وقضبان الأمان الجافة، وتغليف ملفات المهارات. يُستخدم عند إنشاء واجهات سطر الأوامر (CLI) جديدة، أو إضافة دعم الوكيل إلى واجهات سطر الأوامر (CLI) الموجودة، أو مراجعة تصميمات واجهة سطر الأوامر (CLI) للتأكد من توافق الوكيل، أو تغليف واجهات برمجة التطبيقات كأدوات واجهة سطر الأوامر (CLI). المشغلات: وكيل CLI، CLI للوكلاء، CLI المقروء آليًا، CLI للوكيل الأول، وكيل CLI DX.
