Разрабатывайте и проверяйте интерфейсы командной строки для использования агентов ИИ. Охватывает машиночитаемый вывод, защиту ввода от галлюцинаций, самоанализ схемы, дисциплину контекстных окон, защитные ограждения при сухом запуске и упаковку файлов навыков. Используйте при создании новых интерфейсов командной строки, добавлении поддержки агентов к существующим интерфейсам командной строки, проверке проектов интерфейса командной строки на предмет совместимости агентов или превращении API в инструменты интерфейса командной строки. Триггеры: CLI агента, CLI для агентов, машиночитаемый CLI, CLI агента, CLI агента DX.
