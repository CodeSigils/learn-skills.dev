Concevoir et réviser les CLI pour la consommation des agents IA. Couvre les sorties lisibles par machine, le renforcement des entrées contre les hallucinations, l'introspection des schémas, la discipline des fenêtres contextuelles, les rails de sécurité à sec et l'empaquetage des fichiers de compétences. À utiliser lors de la création de nouvelles CLI, de l'ajout de la prise en charge d'agents aux CLI existantes, de la révision des conceptions CLI pour vérifier la compatibilité des agents ou de l'encapsulation des API en tant qu'outils CLI. Déclencheurs : CLI de l'agent, CLI pour les agents, CLI lisible par machine, CLI agent-first, CLI agent DX.
