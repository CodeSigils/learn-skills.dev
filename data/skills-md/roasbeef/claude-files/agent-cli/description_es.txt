Diseñar y revisar CLI para el consumo de agentes de IA. Cubre salidas legibles por máquina, protección de entradas contra alucinaciones, introspección de esquemas, disciplina de ventana de contexto, rieles de seguridad de ejecución en seco y empaquetado de archivos de habilidades. Úselo al crear nuevas CLI, agregar soporte de agente a las CLI existentes, revisar diseños de CLI para determinar la compatibilidad de los agentes o empaquetar API como herramientas CLI. Activadores: CLI de agente, CLI para agentes, CLI legible por máquina, CLI de agente primero, CLI de agente DX.
