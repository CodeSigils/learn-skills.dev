يراجع الكود تكاملات Pluggy API مقابل الوثائق الرسمية لـ Pluggy (يتم الاستعلام عنها في الوقت الفعلي عبر Pluggy MCP، مع الرجوع إلى الويب إلى docs.pluggy.ai عندما لا يكون MCP متصلاً) ويعيد تقرير تشخيصي (✅/❌/⚠️) مع الملف والسطر وإصلاح الكود لكل مشكلة. استخدم عندما يقوم المطور بتحميل ملفات التكامل ويطلب مراجعة تكامل Pluggy أو تحليله أو تشخيصه أو التحقق من صحته - أو يقول أشياء مثل "مراجعة التكامل الخاص بي" أو "التحقق من كود Pluggy الخاص بي" أو "هل هذا جاهز للإنتاج؟" أو "Pluggy Doctor" أو "التحقق من خطافات الويب الخاصة بي" أو "هل التكامل الخاص بي آمن؟" pra produção؟"، "checa meus webhooks"، "minha integração tá segura؟". يتم تشغيله أيضًا عندما يقوم المطور بلصق/تحميل التعليمات البرمجية التي تستدعي بوضوح واجهة برمجة تطبيقات Pluggy (connect_token، GET /items، العنصر/خطافات الويب التي تم إنشاؤها، ClientUserId، وما إلى ذلك) ويريد معرفة ما إذا كان صحيحًا، حتى بدون قول "Pluggy Doctor". هذه المهارة مخصصة لمراجعة التعليمات البرمجية الموجودة، وليس لكتابة عملية تكامل من البداية.
