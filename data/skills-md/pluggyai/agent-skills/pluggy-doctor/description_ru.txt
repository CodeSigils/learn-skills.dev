Код проверяет интеграцию Pluggy API на соответствие официальной документации Pluggy (запрашивается в режиме реального времени через Pluggy MCP, с веб-переходом к docs.pluggy.ai, когда MCP не подключен) и возвращает диагностический отчет ( ✅/❌/⚠️) с файлом, строкой и исправлением кода для каждой проблемы. Используйте ВСЕГДА, ВСЕГДА разработчик загружает файлы интеграции и просит просмотреть, проанализировать, диагностировать или проверить интеграцию Pluggy или говорит что-то вроде «проверьте мою интеграцию», «проверьте мой код Pluggy», «готов ли он к производству?», «Pluggy Doctor», «проверьте мои веб-перехватчики», «безопасна ли моя интеграция?» или португальские варианты «analisa minha integração», «revisa meu código da Pluggy», «tá tudo certo». Pra ir pra produção?», «проверьте мои веб-перехватчики», «хочу интегрироваться и убедиться?». Также срабатывает, когда разработчик вставляет/загружает код, который явно вызывает Pluggy API (connect_token, GET/items, item/created webhooks, clientUserId и т. д.) и хочет знать, правильно ли он, даже не говоря «Pluggy Doctor». Этот навык предназначен для ПРОВЕРКИ существующего кода, а не для написания интеграции с нуля.
