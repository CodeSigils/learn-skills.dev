根據 Pluggy 的官方文件對 Pluggy API 整合進行程式碼審查（透過 Pluggy MCP 即時查詢，當 MCP 未連接時，Web 回退到 docs.pluggy.ai），並傳回診斷報告 (✅/❌/⚠️)，其中包含每個問題的文件、行和程式碼修復。每當開發人員上傳整合文件並要求審查、分析、診斷或驗證其 Pluggy 整合時使用 - 或者說「檢查我的整合」、「檢查我的 Pluggy 代碼」、「這是否已準備好用於生產？」、「Pluggy Doctor」、「檢查我的 webhooks」、「我的整合安全性嗎？ Pluggy」、「tá tudo certo pra ir pra produção？」、「checa meus webhooks」、「minha integração tá segura？當開發人員貼上/上傳明確呼叫 Pluggy API 的程式碼（connect_token、GET /items、item/created webhooks、clientUserId 等）並想知道它是否正確（即使沒有說「Pluggy Doctor」）時也會觸發。該技能用於審查現有程式碼，而不是從頭開始編寫整合。
