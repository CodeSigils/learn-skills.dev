El código revisa las integraciones de la API de Pluggy con la documentación oficial de Pluggy (consultada en tiempo real a través del MCP de Pluggy, con un respaldo web a docs.pluggy.ai cuando el MCP no está conectado) y devuelve un informe de diagnóstico (✅/❌/⚠️) con el archivo, la línea y la corrección del código para cada problema. Úselo SIEMPRE que el desarrollador cargue archivos de integración y solicite revisar, analizar, diagnosticar o validar su integración de Pluggy, o diga cosas como "revisar mi integración", "verificar mi código de Pluggy", "¿está listo para producción?", "Pluggy Doctor", "revisar mis webhooks", "¿es segura mi integración?", o las variantes portuguesas "analisa minha integração", "revisa meu código da Pluggy", "tá tudo certo pra ir pra produção?", "checa meus webhooks", "¿minha integração tá segura?". También se activa cuando el desarrollador pega/carga código que llama claramente a la API de Pluggy (connect_token, GET /items, item/webhooks creados, clientUserId, etc.) y quiere saber si es correcto, incluso sin decir "Pluggy Doctor". Esta habilidad es para REVISAR el código existente, no para escribir una integración desde cero.
