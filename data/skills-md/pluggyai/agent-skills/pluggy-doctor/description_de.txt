Der Code überprüft Pluggy-API-Integrationen anhand der offiziellen Dokumentation von Pluggy (Abfrage in Echtzeit über den Pluggy-MCP, mit einem Web-Fallback auf docs.pluggy.ai, wenn der MCP nicht verbunden ist) und gibt einen Diagnosebericht (✅/❌/⚠️) mit Datei, Zeile und dem Code-Fix für jedes Problem zurück. Verwenden Sie es, WENN der Entwickler Integrationsdateien hochlädt und darum bittet, seine Pluggy-Integration zu überprüfen, zu analysieren, zu diagnostizieren oder zu validieren – oder Dinge sagt wie „meine Integration überprüfen“, „meinen Pluggy-Code prüfen“, „ist dieser für die Produktion bereit?“, „Pluggy Doctor“, „überprüfen Sie meine Webhooks“, „ist meine Integration sicher?“ oder die portugiesischen Varianten „analisa minha integração“, „revisa meu código da Pluggy“, „tá tudo certo pra ir pra“. „Produktion?“, „Prüfe meine Webhooks“, „Minha Integration tá segura?“. Wird auch ausgelöst, wenn der Entwickler Code einfügt/hochlädt, der eindeutig die Pluggy-API aufruft (connect_token, GET /items, item/created Webhooks, clientUserId usw.) und wissen möchte, ob er korrekt ist, auch ohne „Pluggy Doctor“ zu sagen. Diese Fertigkeit dient der ÜBERPRÜFUNG von vorhandenem Code und nicht dem Schreiben einer Integration von Grund auf.
