根据 Pluggy 的官方文档对 Pluggy API 集成进行代码审查（通过 Pluggy MCP 实时查询，当 MCP 未连接时，Web 回退到 docs.pluggy.ai），并返回诊断报告 (✅/❌/⚠️)，其中包含每个问题的文件、行和代码修复。每当开发人员上传集成文件并要求审查、分析、诊断或验证其 Pluggy 集成时使用 - 或者说“检查我的集成”、“检查我的 Pluggy 代码”、“这是否已准备好用于生产？”、“Pluggy Doctor”、“检查我的 webhooks”、“我的集成安全吗？”或葡萄牙语变体“analisa minha integração”、“revisa meu código da Pluggy”、“tá tudo certo pra ir pra produção？”、“checa meus webhooks”、“minha integração tá segura？”。当开发人员粘贴/上传明确调用 Pluggy API 的代码（connect_token、GET /items、item/created webhooks、clientUserId 等）并想知道它是否正确（即使没有说“Pluggy Doctor”）时也会触发。该技能用于审查现有代码，而不是从头开始编写集成。
