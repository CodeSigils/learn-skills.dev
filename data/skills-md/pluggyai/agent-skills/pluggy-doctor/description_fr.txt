Le code examine les intégrations de l'API Pluggy par rapport à la documentation officielle de Pluggy (interrogée en temps réel via le Pluggy MCP, avec un repli Web vers docs.pluggy.ai lorsque le MCP n'est pas connecté) et renvoie un rapport de diagnostic (✅/❌/⚠️) avec le fichier, la ligne et le correctif de code pour chaque problème. À utiliser CHAQUE fois que le développeur télécharge des fichiers d'intégration et demande de vérifier, d'analyser, de diagnostiquer ou de valider leur intégration Pluggy - ou dit des choses comme "examiner mon intégration", "vérifier mon code Pluggy", "est-ce prêt pour la production ?", "Pluggy Doctor", "vérifier mes webhooks", "mon intégration est-elle sécurisée ?", ou les variantes portugaises "analyse minha integração", "revisa meu código da Pluggy", "tá tudo certo pra ir pra produção?", "checa meus webhooks", "minha integração ta segura?". Déclenchez également lorsque le développeur colle/télécharge du code qui appelle clairement l'API Pluggy (connect_token, GET /items, item/created webhooks, clientUserId, etc.) et veut savoir s'il est correct, même sans dire "Pluggy Doctor". Cette compétence sert à RÉVISER le code existant, et non à écrire une intégration à partir de zéro.
