Interpretation und Analyse der ersten Prinzipien. Reduzieren Sie jeden komplexen Tech-Stack, jedes neue Konzept/Feld, jedes vage Problem oder jeden Inhalt auf seine unteilbare „grundlegende Frage“ und erstellen Sie so ein übertragbares mentales Modell. Verwenden Sie dies, wenn der Benutzer wirklich das Wesentliche von etwas „verstehen“ möchte und nicht nur seine oberflächliche Verwendung – z. B. um zu verstehen, welche grundlegenden Probleme die Bibliotheken/Frameworks eines Projekts jeweils lösen, um schnell ein kognitives Framework aufzubauen, wenn er eine neue Domäne betritt, um das Wesentliche zu finden, wenn er mit einem komplexen Problem konfrontiert ist, oder um die zugrunde liegende Logik eines Artikels oder Buches zu extrahieren. Immer wenn der Benutzer „erste Prinzipien“, „Essenz“, „Warum“, „grundlegend“, „zugrunde liegende Logik“, „Zerlegung“, „Verstehen von Null an“, „mentales Modell“ erwähnt oder zum Ausdruck bringt „Ich kann eine Reihe von Begriffen nicht verstehen und möchte sie klären“, wird diese Fähigkeit ausgelöst.
