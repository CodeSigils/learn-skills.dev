استخدم هذه المهارة في أي مهمة هندسة برمجيات جوهرية تتضمن التصميم أو التنفيذ أو تصحيح الأخطاء أو المراجعة أو إعادة البناء أو الاختبار أو تغييرات البناء أو التكوين أو واجهات برمجة تطبيقات HTTP أو الثبات أو الحدود الأمنية أو التزامن أو التوازي أو أنظمة Java أو Kotlin أو JVM. قم بتحميله حتى عندما يطلب المستخدم إصلاحًا صغيرًا، أو تحليل السبب الجذري، أو تغيير الأداء، أو العمل غير المتزامن أو الخلفية، أو مراجعة سلامة سلسلة الرسائل، أو تغيير coroutine، أو ترحيل قاعدة البيانات، أو قرار اتفاقية المستودع؛ استخدم الأدلة المرجعية ذات الصلة والاستنتاجات الأساسية بشأن أدلة المستودع التي تم التحقق منها.
