Legen Sie fest, pushen Sie und eröffnen Sie eine PR mit einer anpassungsfähigen, wertorientierten Beschreibung, die sich in der Tiefe an die Veränderung anpasst. Wird verwendet, wenn der Benutzer „Commit und PR“, „Versenden“, „PR erstellen“ oder „Pull-Anfrage öffnen“ sagt. Behandelt auch reine Beschreibungsabläufe („PR-Beschreibung schreiben“, „PR-Körper neu schreiben“, „diese PR beschreiben“) ohne Commit oder Push.
