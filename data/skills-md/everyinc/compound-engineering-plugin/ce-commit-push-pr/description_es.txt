Comprometa, impulse y abra un PR con una descripción adaptable que priorice el valor y que se amplíe en profundidad con el cambio. Úselo cuando el usuario diga "comprometer y PR", "enviar esto", "crear un PR" o "abrir una solicitud de extracción". También maneja flujos de solo descripción ("escribir una descripción de PR", "reescribir el cuerpo del PR", "describir este PR") sin comprometerse ni presionar.
