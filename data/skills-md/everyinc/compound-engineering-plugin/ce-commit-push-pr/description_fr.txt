Engagez, poussez et ouvrez un PR avec une description adaptative, axée sur la valeur, qui évolue en profondeur avec le changement. À utiliser lorsque l'utilisateur dit « valider et PR », « envoyer ceci », « créer un PR » ou « ouvrir une pull request ». Gère également les flux de description uniquement (« écrire une description du PR », « réécrire le corps du PR », « décrire ce PR ») sans validation ni poussée.
