Подтвердите, отправьте и откройте PR с адаптивным, ориентированным на ценность описанием, которое масштабируется по мере изменений. Используйте, когда пользователь говорит «зафиксировать и PR», «отправить это», «создать PR» или «открыть запрос на включение». Также обрабатывает потоки только для описания («написать описание PR», «переписать тело PR», «описать этот PR») без фиксации или отправки.
