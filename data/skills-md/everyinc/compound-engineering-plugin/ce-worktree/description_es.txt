Asegúrese de que el trabajo se realice en un árbol de trabajo de Git aislado sin alterar el proceso de pago actual. Úselo cuando comience un trabajo que deba permanecer aislado, o cuando `ce-work` o `ce-code-review` ofrezcan una opción de árbol de trabajo. Detecta primero el aislamiento existente, prefiere la herramienta de árbol de trabajo nativa del arnés y recurre a git simple.
