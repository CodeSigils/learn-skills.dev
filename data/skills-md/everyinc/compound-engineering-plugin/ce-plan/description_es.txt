Cree planes estructurados para tareas de varios pasos: funciones de software, flujos de trabajo de investigación, eventos, planes de estudio o cualquier objetivo que se beneficie del desglose. También profundiza los planes existentes con una revisión interactiva de subagentes. Úselo cuando el usuario diga "planificar esto", "crear un plan", "cómo deberíamos construir", "desglosar esto" o cuando un documento de lluvia de ideas esté listo para la planificación. Utilice 'profundizar el plan' o 'pase de profundización' para el flujo de profundización. Para solicitudes exploratorias, prefiera realizar una lluvia de ideas primero.
