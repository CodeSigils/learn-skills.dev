Veröffentlichen, Anzeigen, Kommentieren und Bearbeiten von Markdowns über Proof (proofeditor.ai) – Erstellen Sie ein gemeinsam nutzbares Dokument, lesen Sie ein freigegebenes Dokument und nehmen Sie Kommentare/Vorschläge/Blockierungsänderungen über die API vor. Verwenden Sie diese Option, wenn der Benutzer sagt: „In Proof anzeigen“, „Zu Proof teilen“, „Zu Proof veröffentlichen“ oder eine gemeinsam nutzbare Markdown-Oberfläche für eine Spezifikation, einen Plan oder einen Entwurf wünscht, einschließlich Veröffentlichungsübergaben von ce-brainstorm, ce-ideate oder ce-plan. Lösen Sie nicht auf „Beweis“ aus, was Beweise, mathematische Beweise, Proof-of-Concept oder „Korrekturlesen“ bedeutet.
