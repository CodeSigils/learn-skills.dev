Wendet den Skill-Authoring-Standard dieses Repositorys als Verfahren an. Wird für jede Änderung oder Beurteilung einer Datei unter skills/** verwendet – eine SKILL.md, eine Referenz, eine Persona-Eingabeaufforderung, die Anweisungen eines gebündelten Skripts: Erstellen einer Fertigkeit, Bearbeiten einer Fertigkeit, Überprüfen einer Fertigkeitsänderung oder Reagieren auf Bewertungsfeedback (menschlich oder bot) zu einer Fertigkeit. Nicht für src/-, tests/- oder scripts/-Code.
