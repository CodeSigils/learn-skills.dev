Aplica el estándar de creación de habilidades de este repositorio como procedimiento. Úselo para cualquier cambio o juicio sobre un archivo en skills/**: un SKILL.md, una referencia, un mensaje de persona, instrucciones de un script incluido: crear una habilidad, editar una, revisar un cambio de habilidad o actuar según los comentarios de la revisión (humano o robot) sobre una. No para src/, tests/ o scripts/code.
