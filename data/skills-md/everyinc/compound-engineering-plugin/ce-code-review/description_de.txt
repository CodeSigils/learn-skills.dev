Strukturierte Codeüberprüfung mit abgestuften Persona-Agenten, vertrauenswürdigen Ergebnissen und einer Merge-/Dedup-Pipeline. Im interaktiven Modus wendet es sichere, verifizierte Fixes an und schreibt sie fest, wenn der Arbeitsbaum sauber ist (es wird nie gepusht); im mode:agent meldet es sich nur und der Anrufer meldet sich. Verwenden Sie diese Option, wenn Sie Codeänderungen überprüfen, bevor Sie eine PR erstellen.
