Révision structurée du code à l'aide d'agents personnels à plusieurs niveaux, de résultats sécurisés et d'un pipeline de fusion/dédoublement. En mode interactif, il applique des correctifs sûrs et vérifiés et les valide lorsque l'arborescence de travail est propre (il ne pousse jamais) ; en mode:agent, il signale uniquement et l'appelant postule. À utiliser lors de l'examen des modifications de code avant de créer un PR.
