Cree un compromiso de git con un mensaje claro que comunique valores. Úselo cuando el usuario diga "confirmar", "confirmar esto", "guardar mis cambios", "crear una confirmación" o quiera confirmar un trabajo preparado o no preparado. Produce mensajes de confirmación bien estructurados que siguen las convenciones de repositorio cuando existen y, de lo contrario, utiliza de forma predeterminada el formato de confirmación convencional.
