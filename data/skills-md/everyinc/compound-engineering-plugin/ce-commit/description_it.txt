Crea un commit git con un messaggio chiaro e di valore. Da utilizzare quando l'utente dice "commit", "commit this", "salva le mie modifiche", "crea un commit" o desidera confermare il lavoro in fase o non in fase. Produce messaggi di commit ben strutturati che seguono le convenzioni del repository quando esistono e altrimenti utilizza per impostazione predefinita il formato di commit convenzionale.
