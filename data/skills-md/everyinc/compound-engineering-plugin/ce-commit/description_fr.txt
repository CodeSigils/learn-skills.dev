Créez un commit git avec un message clair et porteur de valeur. À utiliser lorsque l'utilisateur dit « valider », « valider ceci », « enregistrer mes modifications », « créer une validation » ou souhaite valider un travail préparé ou non. Produit des messages de validation bien structurés qui suivent les conventions de dépôt lorsqu'elles existent, et utilisent par défaut le format de validation conventionnel dans le cas contraire.
