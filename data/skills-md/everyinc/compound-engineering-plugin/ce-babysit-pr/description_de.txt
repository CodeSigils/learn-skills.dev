Betreut oder beobachtet einen geöffneten GitHub-PR, bis er zur Zusammenführung bereit ist, und reagiert während der gesamten Lebensdauer des PR kontinuierlich auf neue Bewertungskommentare und CI-Fehler. Verwenden Sie es, wenn Sie gebeten werden, „die PR zu betreuen“, „die PR zu beobachten“, zu überwachen oder eine PR im Laufe der Zeit im Auge zu behalten – keine einmalige Anfrage, um Bewertungskommentare zu klären oder einen CI-Fehler zu beheben (das sind separate Fähigkeiten). Nur GitHub, einschließlich GitHub Enterprise.
