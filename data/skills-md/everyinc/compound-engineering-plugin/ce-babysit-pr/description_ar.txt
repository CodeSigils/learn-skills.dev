مجالسة الأطفال أو مشاهدة GitHub PR مفتوحًا حتى يصبح جاهزًا للدمج، والتفاعل المستمر مع تعليقات المراجعة الجديدة وإخفاقات CI طوال حياة العلاقات العامة. استخدم عندما يُطلب منك "مجالسة العلاقات العامة"، أو "مشاهدة العلاقات العامة"، أو مراقبته، أو مراقبته مع مرور الوقت - وليس طلبًا لمرة واحدة لحل تعليقات المراجعة أو تصحيح فشل CI واحد (تلك مهارات منفصلة). GitHub فقط، بما في ذلك GitHub Enterprise.
