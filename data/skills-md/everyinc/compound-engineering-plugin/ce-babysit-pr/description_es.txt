Cuida o vigila un PR de GitHub abierto hasta que esté listo para la fusión, reaccionando continuamente a nuevos comentarios de revisión y fallas de CI a lo largo de la vida del PR. Úselo cuando se le solicite "cuidar al PR", "observar el PR", monitorear o vigilar un PR a lo largo del tiempo; no es una solicitud única para resolver comentarios de revisión o depurar una falla de CI (esas son habilidades separadas). Solo GitHub, incluido GitHub Enterprise.
