Geben Sie ein entscheidendes, projektbasiertes Urteil über einen externen Input ab – beurteilt am aktuellen Projekt, nicht abstrakt. Verwenden Sie diese Option, um zu entscheiden, ob Sie eine Technologie, Bibliothek, ein Muster, eine Plattform oder eine Architektur übernehmen, wechseln oder erneut besuchen möchten. um einen Kandidaten mit dem zu vergleichen, was das Projekt bereits nutzt; um zu beurteilen, ob sich eine externe Änderung (ein CVE, eine Abwertung, eine Ökosystemverschiebung) tatsächlich auf dieses Projekt auswirkt; oder für eine zweite Meinung während der Sitzung. Gibt immer ein projektspezifisches Urteil zurück, daher ist es nicht für neutrale Erklärungen oder Generierungsoptionen gedacht.
