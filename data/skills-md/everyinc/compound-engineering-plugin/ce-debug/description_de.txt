Finden Sie systematisch die Ursachen und beheben Sie Fehler. Verwenden Sie es beim Debuggen von Fehlern, beim Untersuchen von Testfehlern, beim Reproduzieren von Fehlern aus Issue-Trackern (GitHub, Linear, Jira) oder wenn Sie nach fehlgeschlagenen Korrekturversuchen bei einem Problem hängen bleiben. Wird auch verwendet, wenn der Benutzer sagt: „Fehler beheben“, „Warum schlägt das fehl“, „Diesen Fehler beheben“, „Diesen Fehler verfolgen“ oder Stack-Traces, Fehlermeldungen oder Problemverweise einfügt.
