A skill for creating polished resumes through conversational interviewing. It is used when the user mentions “简历”, “resume”, “CV”, “求职”, “找工作”, “面试”, “制作简历”, “生成简历”, or wants to create a webpage showcasing personal experience and skills. It supports HTML resume generation, A4 print layout, and PDF export. It can guide the user step‑by‑step to refine resume content, covering everything from personal information to project experience.
