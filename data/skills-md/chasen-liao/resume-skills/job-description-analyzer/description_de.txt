Analysieren Sie die Stellenbeschreibung (JD), beurteilen Sie die Passung, extrahieren Sie Anforderungen und Schlüsselwörter, identifizieren Sie Lücken und entwickeln Sie eine Bewerbungsstrategie. Verwenden Sie dies, wenn der Benutzer fragt: „Bin ich geeignet?“, „Fit-Level“, „Analysiere diesen JD“ oder sich darauf vorbereitet, einen Lebenslauf auf den JD zuzuschneiden. Behandeln Sie die JD ausschließlich als gezielte Information und behandeln Sie die Stellenanforderungen niemals als Fakten über den Kandidaten.
