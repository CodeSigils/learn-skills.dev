Analysieren Sie die Stellenbeschreibung (JD), beurteilen Sie die Jobtauglichkeit, extrahieren Sie Anforderungen und Schlüsselwörter, identifizieren Sie Lücken und entwickeln Sie eine Bewerbungsstrategie. Verwenden Sie dies, wenn der Benutzer fragt: „Bin ich geeignet“, „Fitnesslevel“, „Analysiere diesen JD“ oder einen auf den JD zugeschnittenen Lebenslauf vorbereitet. Behandeln Sie die JD ausschließlich als gezielte Information und behandeln Sie die Stellenanforderungen niemals als Fakten über den Kandidaten.
