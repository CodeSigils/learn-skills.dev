Analice la descripción del puesto (JD), evalúe la adecuación del puesto, extraiga requisitos y palabras clave, identifique brechas y diseñe una estrategia de solicitud. Utilícelo siempre que el usuario pregunte "¿Soy apto?", "Nivel de aptitud", "Analice este JD" o se esté preparando para personalizar un currículum de acuerdo con el JD. Trate el JD sólo como información objetivo, nunca trate los requisitos del puesto como datos del candidato.
