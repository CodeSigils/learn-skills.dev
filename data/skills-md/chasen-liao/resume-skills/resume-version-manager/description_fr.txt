Gérez le modèle principal de CV et les versions personnalisées pour différentes entreprises, postes et descriptions de poste. Utilisez-le lorsque les utilisateurs doivent enregistrer plusieurs versions de CV, comparer les différences, nommer des fichiers, suivre les versions soumises ou conserver la source des faits de CV. Protégez le modèle principal et n'écrasez pas les versions existantes ou les faits non vérifiés.
