Compétences pour personnaliser un curriculum vitae basé sur une description de poste (JD). Utilisez-le lorsque l'utilisateur mentionne « JD », « description de poste », « correspondance de poste », « réviser son CV pour… », « soumission », « recherche d'emploi », « exigences de recrutement », « description de poste » ou fournit un lien/texte de poste spécifique demandant des modifications de CV. Prend en charge le téléchargement ou le collage de texte JD, effectue automatiquement la correspondance des mots clés et l'optimisation du contenu, et génère une version HTML et PDF personnalisée du CV pour le poste en fonction du CV existant.
