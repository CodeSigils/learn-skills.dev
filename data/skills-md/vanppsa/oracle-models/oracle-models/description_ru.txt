Классифицирует сложность задач разработки (ЛЕГКАЯ/СРЕДНЯЯ/СЕРЬЕЗНАЯ) и предлагает наиболее экономичную модель ИИ для каждого поставщика (Claude, Gemini, GLM, Grok, GPT). Активируется только в режиме планирования. Модели ранжированы по индексу интеллекта искусственного анализа.ai. Обновляется любым ИИ без ручной реконфигурации. Работает как навык (поведенческие инструкции) и как сервер MCP (живые инструменты).
