Revisione del design di sola lettura rispetto alla barra dei prodotti di Danny White. Da utilizzare quando l'utente dice revisione del progetto, revisione dell'interfaccia utente o /design-review oppure quando una differenza PR modifica un'interfaccia visibile all'utente, un'interazione, un comportamento reattivo o un testo. Non utilizzare per lavori di solo backend, infrastruttura, database, API o solo test senza modifiche all'interfaccia.
