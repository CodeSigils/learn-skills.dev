مراجعة تصميم للقراءة فقط مقابل شريط منتجات داني وايت. استخدمها عندما يقول المستخدم "مراجعة تصميم"، أو "مراجعة الواجهة"، أو "/design-review"، أو عندما يغيّر فرق طلب السحب (PR) واجهة مستخدم مرئية، أو تفاعلًا، أو سلوكًا استجابياً، أو نصًا. لا تستخدمها للأعمال الخاصة بالخلفية فقط، أو البنية التحتية، أو قاعدة البيانات، أو واجهة برمجة التطبيقات (API)، أو الاختبارات فقط دون تغيّر الواجهة. يرجى دائمًا الرد بلغة المستخدم.
