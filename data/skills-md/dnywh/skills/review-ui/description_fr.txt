Examen de conception en lecture seule de la barre de produit de Danny White. Utilisez-le lorsque l'utilisateur mentionne « design review », examine l’interface utilisateur, ou utilise /design-review, ou lorsqu’un diff de PR modifie une interface visible par l’utilisateur, une interaction, un comportement réactif ou le texte. Ne l’utilisez pas pour du travail uniquement backend, infrastructure, base de données, API ou uniquement de test sans changement d’interface.
