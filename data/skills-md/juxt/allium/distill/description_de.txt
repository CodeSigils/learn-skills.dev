Extrahieren Sie eine Allium-Spezifikation aus einer vorhandenen Codebasis. Verwenden Sie diese Option, wenn der Benutzer über vorhandenen Code verfügt und Verhalten in eine Spezifikation destillieren, eine Spezifikation aus der Implementierung zurückentwickeln, eine Spezifikation aus Code generieren, die Implementierung in eine Verhaltensspezifikation umwandeln oder dokumentieren möchte, was eine Codebasis in Allium-Begriffen tut.
