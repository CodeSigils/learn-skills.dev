RunComfy での Kling 3.0 ビデオ生成。 Kling 3.0 (Kling V3.0 とも呼ばれる) は、Kuaishou Technology の第 3 世代マルチショット ビデオ モデルで、ネイティブ同期オーディオとショット全体で一貫したキャラクターのアイデンティティを備えています。 This skill covers all six Kling 3.0 endpoints, spanning three rendering tiers (Standard, Pro, 4K) and two modes (text-to-video, image-to-video). Calls runcomfy run kling/kling-3.0/<tier>/<mode> through the local RunComfy CLI. 「kling」、「kling 3.0」、「kling v3」、「kling pro」、「kling 4k」、「kling text to video」、「kling image to video」、または Kling 3.0 で生成またはアニメーション化するための明示的な要求でトリガーされます。
