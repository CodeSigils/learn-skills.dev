RunComfy での Kling 3.0 ビデオ生成。 Kling 3.0 (Kling V3.0 とも呼ばれる) は、Kuaishou Technology の第 3 世代マルチショット ビデオ モデルで、ネイティブ同期オーディオとショット全体で一貫したキャラクターのアイデンティティを備えています。このスキルは、3 つのレンダリング層 (Standard、Pro、4K) と 2 つのモード (テキストからビデオ、画像からビデオ) にわたる 6 つの Kling 3.0 エンドポイントすべてをカバーします。ローカル RunComfy CLI を介して runco​​mfy run kling/kling-3.0/<tier>/<mode> を呼び出します。 「kling」、「kling 3.0」、「kling v3」、「kling pro」、「kling 4k」、「kling text to video」、「kling image to video」、または Kling 3.0 で生成またはアニメーション化するための明示的な要求でトリガーされます。
