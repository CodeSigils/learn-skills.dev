Anima cualquier imagen fija en RunComfy: esta habilidad es un enrutador inteligente que hace coincidir la intención del usuario con el modelo i2v correcto en el catálogo RunComfy. Elige HappyHorse 1.0 I2V (Arena #1, audio nativo, preservación de identidad) para animaciones generales, Wan 2.7 con `audio_url` para sincronización de labios con voz en off personalizada, o Seedance 2.0 Pro para animación multimodal a partir de imagen + video de referencia + audio de referencia. Agrupa los patrones de indicaciones documentados de cada modelo para que la persona que llama obtenga un resultado más nítido sin grabar iteraciones en el modelo incorrecto. Llama a `runcomfy run <proveedor>/<modelo>/image-to-video` (o variante de punto final) a través de la CLI RunComfy local. Activadores de "imagen a video", "imagen a video", "i2v", "animar imagen", "hacer este movimiento" o cualquier solicitud explícita para convertir una imagen fija en video.
