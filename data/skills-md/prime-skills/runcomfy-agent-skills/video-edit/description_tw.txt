編輯 RunComfy 上的現有影片 - 該技能是一個智慧路由器，可將使用者的意圖與 RunComfy 目錄中的正確編輯模型相匹配。選擇 Wan 2.7 Edit-Video（一般重新設計/背景交換/包裝交換、身份+運動保留）、Kling 2.6 Pro Motion Control（將參考視頻的精確運動轉移到目標角色）或 Lucy Edit Restyle（輕量級身份穩定重新設計/服裝交換）。捆綁每個模型記錄的提示模式，以便技能得到更清晰的編輯，而無需在錯誤的模型上進行迭代。透過本地 RunComfy CLI 呼叫 `runco​​mfy run <vendor>/<model>/<endpoint>`。在「影片編輯」、「編輯影片」、「重新設計影片」、「交換影片背景」、「運動控制」、「服裝交換影片」或任何明確的影片轉換要求時觸發。
