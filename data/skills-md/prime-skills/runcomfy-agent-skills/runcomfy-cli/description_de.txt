Führen Sie ein beliebiges Modell auf RunComfy über die Befehlszeile aus. Die „runcomfy“-CLI ist eine Binärdatei, eine Authentifizierung, Hunderte von Modellendpunkten – Bildgenerierung, Bildbearbeitung, Videogenerierung, Bild-zu-Video, Lippensynchronisation, Gesichtsaustausch, Videobearbeitung, Inpainting, Outpainting, Extend, ControlNet, Relight, Upscale, LoRA-Training und mehr. Senden Sie eine Anfrage, fragen Sie den Status ab und laden Sie die Ausgabe herunter. Mit dieser Fertigkeit lernt der Agent, wie man Modellschemata installiert, authentifiziert, erkennt, Modelle aufruft, streamt/abfragt/nicht wartet, Skripts im JSON-Ausgabemodus erstellt und mit Fehlern umgeht. Wird bei „runcomfy cli“, „install runcomfy“, „runcomfy login“, „runcomfy run“, „runcomfy whoami“, „runcomfy api“ oder einer expliziten Aufforderung zum Aufrufen eines RunComfy-Modells von einem Skript oder Terminal aus ausgelöst. Geschwisterfähigkeiten (KI-Bildgenerierung, KI-Videogenerierung, Bildbearbeitung, Videobearbeitung, Gesichtswechsel, Lippensynchronisation, Bild-zu-Video, Bild-Inpainting, Bild-Outpainting, Video-Erweiterung, Controlnet-Pose, Relight) werden alle über diese CLI bereitgestellt.
