RunComfy 上的 Codex Pet 產生器。從單一參考影像建立與 Codex 相容的 Codex Pet spritesheet.webp + pet.json，將其放入 `${CODEX_HOME:-$HOME/.codex}/pets/<name>/` 中，Codex 將其作為 8 個內建插件旁的自訂 Codex Pet 選取。此技能可產生 Codex 期望的準確 Codex Pet 圖集（1536x1872 PNG/WebP、8 列 x 9 行、192x208 單元格、9 種動畫狀態 - 空閒、向右運行、向左運行、揮手、跳躍、失敗、等待、運行、審查）。透過本地 RunComfy CLI 作為“runco​​mfy run openai/gpt-image-2/edit”調用 OpenAI GPT Image 2 edit 一次，以生成規範的 Codex Pet 姿勢，然後使用 ImageMagick 微轉換以編程方式組裝所有 9 個動畫行 — 無需 Codex Pro，在「codex pet」、「create codex pet」、「make codex pet」、「hatch codex pet」、「/hatch image」、「desktop pet codex」、「codex pets」、「spritesheet.webp」或任何為 OpenAI Codex 構建時觸發自訂時觸發。
