Генератор Codex Pet на RunComfy. Создайте совместимый с Кодексом Codex Pet spritesheet.webp + pet.json из одного эталонного изображения, поместите его в `${CODEX_HOME:-$HOME/.codex}/pets/<name>/`, и Кодекс подберет его как собственный Codex Pet рядом с 8 встроенными модулями. Этот навык дает именно тот атлас Codex Pet, который ожидает Кодекс (1536x1872 PNG/WebP, 8 столбцов x 9 строк, 192x208 ячеек, 9 состояний анимации — бездействие, бег вправо, бег влево, размахивание руками, прыжок, неудача, ожидание, бег, просмотр). Вызывает редактирование OpenAI GPT Image 2 ОДИН РАЗ через локальный интерфейс командной строки RunComfy как `runcomfy run openai/gpt-image-2/edit` для создания канонической позы Codex Pet, затем программно собирает все 9 строк анимации с помощью микропреобразований ImageMagick — ни Codex Pro, ни `$imagegen`, ни OPENAI_API_KEY, не требуется, только RUNCOMFY_TOKEN. Срабатывает по «питомцу кодекса», «создать питомца кодекса», «создать питомца кодекса», «вылупить питомца кодекса», «/hatch image», «кодексу домашнего любимца рабочего стола», «питомцу кодекса», «spritesheet.webp» или любому явному запросу создать собственного питомца для Кодекса OpenAI.
