Open a GitHub pull request from the current branch using a fixed template (ticket, Problem, Solution, Before, After, Test plan). Use this skill whenever the user types `/submit-pull-request`, asks to "submit a PR", "open a PR", "create a pull request", "push this up as a PR", or otherwise wants a pull request created from the current branch — even if they don't explicitly mention the template. Always prefer this skill over writing an ad-hoc PR description.
