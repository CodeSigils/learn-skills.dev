Откройте запрос на извлечение GitHub из текущей ветки, используя фиксированный шаблон (заявка, Проблема, Решение, До, После, План тестирования). Используйте этот навык всякий раз, когда пользователь вводит `/submit-pull-request`, просит «отправить PR», «открыть PR», «создать запрос на включение», «отправить это как PR» или иным образом хочет, чтобы запрос на включение был создан из текущей ветки — даже если они явно не упоминают шаблон. Всегда отдавайте предпочтение этому навыку написанию специального PR-описания.
