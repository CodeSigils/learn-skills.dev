Apri una richiesta pull GitHub dal ramo corrente utilizzando un modello fisso (ticket, problema, soluzione, prima, dopo, piano di test). Utilizza questa abilità ogni volta che l'utente digita `/submit-pull-request`, chiede di "inviare un PR", "aprire un PR", "creare una richiesta pull", "inviarlo come PR" o altrimenti desidera che una richiesta pull venga creata dal ramo corrente, anche se non menziona esplicitamente il modello. Preferisci sempre questa abilità rispetto alla scrittura di una descrizione PR ad hoc.
