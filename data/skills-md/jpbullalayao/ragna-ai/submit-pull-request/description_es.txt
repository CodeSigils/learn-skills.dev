Abra una solicitud de extracción de GitHub desde la rama actual usando una plantilla fija (ticket, Problema, Solución, Antes, Después, Plan de prueba). Utilice esta habilidad siempre que el usuario escriba `/submit-pull-request`, solicite "enviar un PR", "abrir un PR", "crear una solicitud de extracción", "enviar esto como un PR" o, de otro modo, desee crear una solicitud de extracción a partir de la rama actual, incluso si no menciona explícitamente la plantilla. Prefiera siempre esta habilidad a escribir una descripción de relaciones públicas ad hoc.
