Ouvrez une pull request GitHub depuis la branche actuelle à l'aide d'un modèle fixe (ticket, Problème, Solution, Avant, Après, Plan de test). Utilisez cette compétence chaque fois que l'utilisateur tape « /submit-pull-request », demande de « soumettre un PR », « ouvrir un PR », « créer une pull request », « pousser ceci en tant que PR » ou souhaite créer une pull request à partir de la branche actuelle – même s'il ne mentionne pas explicitement le modèle. Préférez toujours cette compétence à la rédaction d’une description de relations publiques ad hoc.
