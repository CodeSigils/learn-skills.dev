Öffnen Sie eine GitHub-Pull-Anfrage aus dem aktuellen Zweig mit einer festen Vorlage (Ticket, Problem, Lösung, Vorher, Nachher, Testplan). Verwenden Sie diesen Skill immer dann, wenn der Benutzer „/submit-pull-request“ eingibt, auffordert, „eine PR einzureichen“, „eine PR zu öffnen“, „eine Pull-Anfrage zu erstellen“, „dies als PR hochzuschieben“ oder auf andere Weise eine Pull-Anfrage aus dem aktuellen Zweig erstellen möchte – auch wenn er die Vorlage nicht explizit erwähnt. Ziehen Sie diese Fähigkeit immer dem Schreiben einer Ad-hoc-PR-Beschreibung vor.
