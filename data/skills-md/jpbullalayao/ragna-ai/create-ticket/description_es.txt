Cree un ticket bien estructurado en el rastreador de problemas preferido del usuario (el valor predeterminado es Lineal). Los tickets incluyen una sección de Contexto (cómo funciona el sistema actual) y una sección de Requisitos (qué se debe hacer), escritas tanto para humanos como para agentes. Úselo cuando el usuario escribe /create-ticket o solicita "crear un ticket", "presentar un problema", "escribir un ticket", "abrir un problema lineal" o "registrar esto como un ticket".
