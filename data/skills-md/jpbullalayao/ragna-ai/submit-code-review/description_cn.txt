将当前对话的 /self-code-review 输出的结果发布为当前分支拉取请求的 GitHub PR 评论。在运行 /self-code-review 之后，当用户键入 /submit-code-review 或要求“提交评论”、“将评论发布到 GitHub”或“将评论推送到 PR”时使用。不重新分析差异 - 它读取对话中已经存在的发现。可以选择按用户提供的焦点区域进行过滤。在存在 file:line 引用的情况下，优先考虑内联 PR 审核评论（附加到特定文件和行）；当没有可用的引用或内嵌帖子失败时，会退回到常规的公关对话评论。每条评论都以斜体字“_Comment from Claude Code agent · [Model]_”开头（其中 [Model] 是当前运行的 Claude 模型的简称，例如“Sonnet 4.6”、“Opus 4.7”、“Haiku 4.5”），两个空行，然后是“非阻塞”（默认）或“阻塞”（仅当用户明确这么说时），然后是新行上的发现。需要通过 GitHub 身份验证的“gh” CLI。
