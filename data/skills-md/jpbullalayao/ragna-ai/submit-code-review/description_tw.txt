將目前對話的 /self-code-review 輸出的結果發佈為目前分支拉取請求的 GitHub PR 評論。在執行 /self-code-review 之後，當使用者鍵入 /submit-code-review 或要求「提交評論」、「將評論發佈到 GitHub」或「將評論推送到 PR」時使用。不重新分析差異 - 它讀取對話中已經存在的發現。可選擇按使用者提供的焦點區域進行篩選。在存在 file:line 引用的情況下，優先考慮內聯 PR 審核評論（附加到特定文件和行）；當沒有可用的引用或內嵌貼文失敗時，會退回到常規的公關對話評論。每個評論都以斜體字“_Comment from Claude Code agent · [Model]_”開頭（其中 [Model] 是當前運行的 Claude 模型的簡稱，例如“Sonnet 4.6”、“Opus 4.7”、“Haiku 4.5”），兩個空行，然後是“非阻塞”（當用戶上的預設時僅當）。需要透過 GitHub 驗證的「gh」 CLI。
