현재 대화의 /self-code-review 출력에서 ​​찾은 결과를 현재 분기의 풀 요청에 대한 GitHub PR 댓글로 게시합니다. 사용자가 /submit-code-review를 입력하거나 "리뷰 제출", "GitHub에 댓글 게시" 또는 "PR에 리뷰 푸시"를 요청할 때 /self-code-review를 실행한 후 사용하세요. 차이점을 다시 분석하지 않습니다. 대화에 이미 존재하는 결과를 읽습니다. 선택적으로 사용자가 제공한 초점 영역을 기준으로 필터링합니다. 파일:줄 인용이 존재하는 인라인 PR 검토 주석(특정 파일 및 줄에 첨부됨)에 우선순위를 둡니다. 인용이 불가능하거나 인라인 게시물이 실패하면 일반 PR 대화 댓글로 대체됩니다. 각 주석은 기울임꼴의 "_Comment from Claude Code Agent · [Model]_"로 시작합니다(여기서 [Model]은 현재 실행 중인 Claude 모델의 짧은 이름입니다(예: "Sonnet 4.6", "Opus 4.7", "Haiku 4.5")). 두 개의 빈 줄, "non-blocking"(기본값) 또는 "blocking"(사용자가 명시적으로 말한 경우에만), 그리고 새로운 줄에 결과가 표시됩니다. GitHub에 인증된 'gh' CLI가 필요합니다.
