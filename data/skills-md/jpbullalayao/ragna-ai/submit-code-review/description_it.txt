Pubblica i risultati dell'output /self-code-review della conversazione corrente mentre GitHub PR commenta la richiesta pull del ramo corrente. Utilizzare DOPO aver eseguito /self-code-review, quando l'utente digita /submit-code-review o chiede di "inviare la recensione", "pubblicare i commenti su GitHub" o "inviare la recensione al PR". NON rianalizza la differenza: legge i risultati già presenti nella conversazione. Facoltativamente filtra in base a un'area di interesse fornita dall'utente. Dà la priorità ai commenti di revisione PR in linea (allegati al file e alla riga specifici) dove esiste una citazione file:line; si ricorre ai normali commenti di conversazione PR quando non è disponibile alcuna citazione o il post in linea fallisce. Ogni commento inizia con "_Comment from Claude Code agent · [Model]_" in corsivo (dove [Model] è il nome breve del modello Claude attualmente in esecuzione, ad esempio "Sonnet 4.6", "Opus 4.7", "Haiku 4.5"), due righe vuote, quindi "non bloccante" (predefinito) o "bloccante" (solo quando l'utente lo dice esplicitamente), quindi il risultato su una nuova riga. Richiede la CLI `gh` autenticata su GitHub.
