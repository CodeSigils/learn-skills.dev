Опубликуйте результаты вывода /self-code-review текущего разговора в виде PR-комментариев GitHub к запросу на включение текущей ветки. Используйте ПОСЛЕ запуска /self-code-review, когда пользователь вводит /submit-code-review или просит «отправить обзор», «опубликовать комментарии на GitHub» или «отправить отзыв в PR». НЕ анализирует разницу повторно — он считывает результаты, уже присутствующие в диалоге. При необходимости фильтруется по предоставленной пользователем области фокусировки. Отдает приоритет встроенным комментариям обзора PR (прикрепленным к конкретному файлу и строке), где существует ссылка file:line; возвращается к обычным комментариям в PR-разговорах, когда цитирование недоступно или встроенный пост не работает. Каждый комментарий начинается с «_Комментарий от агента кода Клода · [Модель]_», выделенного курсивом (где [Модель] — это короткое имя работающей в данный момент модели Клода, например «Sonnet 4.6», «Opus 4.7», «Haiku 4.5»), две пустые строки, затем «неблокирующий» (по умолчанию) или «блокирующий» (только если пользователь явно указывает это), а затем результат поиска в новой строке. Требуется CLI `gh`, аутентифицированный на GitHub.
