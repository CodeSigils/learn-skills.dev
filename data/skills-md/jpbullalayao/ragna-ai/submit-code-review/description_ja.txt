現在の会話の /self-code-review 出力から得られた結果を、現在のブランチのプル リクエストに対する GitHub PR コメントとして投稿します。ユーザーが /submit-code-review と入力するか、「レビューを送信する」、「コメントを GitHub に投稿する」、「レビューを PR にプッシュする」を要求する場合、/self-code-review の実行後に使用します。差分を再分析するのではなく、会話にすでに存在する結果を読み取ります。必要に応じて、ユーザーが指定したフォーカス領域によってフィルタリングします。 file:line 引用が存在するインライン PR レビュー コメント (特定のファイルおよび行に添付) を優先します。引用が利用できない場合、またはインライン投稿が失敗した場合は、通常の PR 会話のコメントに戻ります。各コメントは、イタリック体の「_Comment from Claude Code Agent · [Model]_」 ([Model] は現在実行中のクロード モデルの短縮名です。例: 「Sonnet 4.6」、「Opus 4.7」、「Haiku 4.5」) で始まり、2 行の空白行、次に「ノンブロッキング」 (デフォルト) または「ブロッキング」 (ユーザーが明示的に指定した場合のみ)、そして新しい行に結果が表示されます。 GitHub に対して認証された `gh` CLI が必要です。
