現在のブランチとそのベース ブランチの差分を確認します。オープン PR のベース ブランチが存在する場合はそれ、それ以外の場合はリポジトリのデフォルト ブランチです。新たに導入されたバグ (ロジック エラー、null/未定義の逆参照、逆条件、未処理の非同期、オフバイ ワン)、機能の回帰、不要な一般的ではないフック (useRef/useEffect/useMemo/useCallback)、既存の共有ユーティリティ/ヘルパー/コンポーネントを複製する機能 (名前付きの重複とインライン再実装)、コードベース内の確立された規則/アーキテクチャ/構文から逸脱したコードにフラグを立てます。反復で残った古いコード。ユーザーが /self-code-review を実行する場合、または現在のブランチのレビュー、事前 PR チェック、または「変更のレビュー」を要求する場合に使用します。
