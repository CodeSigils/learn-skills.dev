Analysez la différence de la branche actuelle par rapport à sa branche de base - une branche spécifiée par l'utilisateur si elle est donnée, sinon la branche de base du PR ouvert, sinon la branche par défaut du dépôt - et corrigez automatiquement les opportunités de nettoyage dans trois domaines : la brièveté et la qualité du code, les régressions potentielles et la santé CI/build. À utiliser lorsque l'utilisateur exécute /code-cleanup [<branch>] ou demande de « nettoyer le code », de « simplifier ces modifications » ou de « peaufiner cette branche ». Présente les résultats par domaine à l'utilisateur avant d'appliquer les correctifs. Les correctifs automatiques répondent à la barre qu'un ingénieur de niveau personnel approuverait : conservateurs, préservant le comportement et clairement motivés. Pour les grandes différences (> 300 lignes ou > 15 fichiers), invoque d'abord /simplify. Pour les fichiers React dans le diff, invoque /react-doctor avant d'appliquer les correctifs.
