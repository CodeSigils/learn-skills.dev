Scrive documentazione di markdown concisa ed efficiente in termini di token su qualsiasi argomento nella query dell'utente: un argomento, una funzione, un modulo, un progetto o materiale online inclusi gli URL forniti. I documenti sono leggibili sia dagli esseri umani che dagli agenti, vengono posizionati automaticamente in base all'architettura del progetto e la query dell'utente può sovrascrivere le impostazioni predefinite. Da utilizzare quando l'utente richiama /write-docs o chiede di "documentare questo", "scrivere documenti per" o "scrivere documentazione su".
