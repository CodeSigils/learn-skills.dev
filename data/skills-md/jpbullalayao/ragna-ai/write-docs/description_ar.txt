يكتب وثائق تخفيض السعر موجزة وفعالة حول أي موضوع في استعلام المستخدم - موضوع أو وظيفة أو وحدة نمطية أو مشروع أو مادة عبر الإنترنت بما في ذلك عناوين URL المتوفرة. يمكن لكل من البشر والوكلاء قراءة المستندات، ويتم وضعها تلقائيًا بواسطة بنية المشروع، ويمكن لاستعلام المستخدم تجاوز الإعدادات الافتراضية. يُستخدم عندما يستدعي المستخدم /write-docs، أو يطلب "توثيق هذا"، أو "كتابة مستندات لـ"، أو "كتابة وثائق حول".
