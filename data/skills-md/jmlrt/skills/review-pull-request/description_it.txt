Esamina le richieste pull di GitHub in modo completo. Valuta i commenti di revisione esistenti, esegue una revisione indipendente del codice, esegue test, convalida test manuali, controlla la copertura di Jira/problemi. Da utilizzare quando l'utente chiede di rivedere una PR, verificare una PR o verificare la disponibilità della PR.
