Всесторонне проверяет запросы на извлечение GitHub. Сортирует существующие комментарии к обзорам, выполняет независимую проверку кода, запускает тесты, проверяет ручное тестирование, проверяет покрытие Jira/проблем. Используйте, когда пользователь просит просмотреть PR, проверить PR или проверить готовность PR.
