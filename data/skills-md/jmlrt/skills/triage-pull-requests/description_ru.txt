Организует проверку одного или нескольких запросов на GitHub параллельно с помощью субагентов. Создает сводную таблицу сортировки с выводами критических/предложений/NIT по каждому PR, а затем публикует отзывы (утверждение/комментарии/запрос изменений) на основе решений пользователей. Используйте, когда пользователь просит просмотреть несколько PR, просмотреть запросы параллельно или выполнить пакетную проверку запросов в разных репозиториях.
