Orchestriert die Überprüfung eines oder mehrerer GitHub-PRs parallel mithilfe von Subagenten. Erstellt eine Triage-Zusammenfassungstabelle mit kritischen/Vorschlags-/NIT-Ergebnissen pro PR und veröffentlicht dann Bewertungen (Genehmigung/Kommentar/Änderungsanfragen) basierend auf Benutzerentscheidungen. Verwenden Sie diese Option, wenn der Benutzer die Überprüfung mehrerer PRs, die parallele Überprüfung von PRs oder die Batch-Überprüfung von PRs über mehrere Repos hinweg anfordert.
