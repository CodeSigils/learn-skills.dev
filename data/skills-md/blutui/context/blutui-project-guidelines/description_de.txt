Blutui-Projektrichtlinien vom Blutui Engineering-Team. Nutzen Sie diese Fähigkeit immer dann, wenn Sie an JEDEM Blutui-Projekt arbeiten – beim Schreiben oder Bearbeiten von Vorlagen, Layouts, Komponenten oder Teilen; Sammlungen erstellen oder abfragen; Erstellen oder Bearbeiten von Formularen; Konfigurieren von Routing oder Courier; Arbeiten mit Canopy oder Kassetten; Verwendung des Blutui MCP; oder ein neues Blutui-Projekt von Grund auf einrichten. Wenn der Benutzer Blutui, Canopy, Cassettes, Courier oder ein anderes Blutui-spezifisches Konzept erwähnt, laden und befolgen Sie immer diesen Skill, bevor Sie Code oder Konfiguration schreiben.
