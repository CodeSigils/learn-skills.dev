Agregue una interfaz web (React/Vite SPA) a un backend Go existente con un bucle de desarrollo de dos procesos (servidor de desarrollo Vite + proxy para Go) y una compilación binaria única de producción (vaya a generar compilaciones/copias activos de la interfaz + go:embed los empaqueta). Úselo cuando necesite servir un SPA desde Go en / con /api y /ws opcional, conectar objetivos Makefile y hacer que CI (GitHub Actions) construya/integre de manera confiable la interfaz de usuario.
