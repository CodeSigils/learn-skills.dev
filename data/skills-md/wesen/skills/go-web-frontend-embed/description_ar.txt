أضف واجهة ويب أمامية (React/Vite SPA) إلى واجهة Go الخلفية الحالية مع حلقة تطوير ذات عمليتين (Vite dev server + proxy to Go) وبناء ثنائي فردي للإنتاج (اذهب لإنشاء إصدارات/نسخ أصول الواجهة الأمامية + go:embed حزمها). استخدمه عندما تحتاج إلى خدمة SPA من Go on / with /api و/ws الاختياري، وأهداف Makefile السلكية، وجعل CI (إجراءات GitHub) تقوم ببناء/تضمين واجهة المستخدم بشكل موثوق.
