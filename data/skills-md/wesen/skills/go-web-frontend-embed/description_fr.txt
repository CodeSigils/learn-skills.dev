Ajoutez une interface Web (React/Vite SPA) à un backend Go existant avec une boucle de développement à deux processus (serveur de développement Vite + proxy vers Go) et une version de production monobinaire (go générer des builds/copies des actifs frontend + go: les intégrer dans les packages). À utiliser lorsque vous devez servir un SPA à partir de Go on / avec /api et /ws facultatif, câbler des cibles Makefile et faire en sorte que CI (GitHub Actions) construise/intègre de manière fiable l'interface utilisateur.
