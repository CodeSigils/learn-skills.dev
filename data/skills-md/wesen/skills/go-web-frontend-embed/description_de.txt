Fügen Sie ein Web-Frontend (React/Vite SPA) zu einem vorhandenen Go-Backend mit einer Entwicklungsschleife mit zwei Prozessen (Vite-Entwicklungsserver + Proxy für Go) und einem Produktions-Single-Binary-Build hinzu (go generiert Builds/kopiert Frontend-Assets + go:embed packt sie). Verwenden Sie diese Option, wenn Sie eine SPA von Go on / mit /api und optional /ws bereitstellen, Makefile-Ziele verbinden und dafür sorgen müssen, dass CI (GitHub Actions) die Benutzeroberfläche zuverlässig erstellt/einbettet.
