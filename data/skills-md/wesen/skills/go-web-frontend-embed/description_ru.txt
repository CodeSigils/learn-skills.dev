Добавьте веб-интерфейс (React/Vite SPA) к существующему серверу Go с двухпроцессным циклом разработки (сервер разработки Vite + прокси для Go) и производственную однодвоичную сборку (go генерировать сборки/копировать ресурсы интерфейса + go:embed упаковывает их). Используйте, когда вам нужно обслуживать SPA из Go on / с /api и необязательным /ws, подключать целевые объекты Makefile и обеспечивать CI (действия GitHub) для надежного построения/встраивания пользовательского интерфейса.
