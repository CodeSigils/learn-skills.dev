النظافة العملية لـ Git للتنفيذ المرحلي والالتزام: مراجعة الاختلافات، والتخطيط المتعمد، وتجنب ارتكاب الضوضاء/بناء القطع الأثرية/الأسرار، والتعافي من التدريج العرضي أو الالتزام. يُستخدم عندما يسأل المستخدم عن كيفية تنفيذ التغييرات، أو كتابة قائمة التحقق من سير عمل الالتزام، أو إلغاء تنظيم/إزالة الملفات غير المقصودة، أو التحقق من سلوك `.gitignore`.
