Igiene pratica di Git per lo staging e il commit: rivedere le differenze, mettere in stage intenzionalmente, evitare di commettere rumore/creare artefatti/segreti e recuperare da staging o commit accidentali. Da utilizzare quando un utente chiede come eseguire il commit delle modifiche, scrivere un elenco di controllo del flusso di lavoro di commit, rimuovere dallo stage/rimuovere file accidentali o verificare il comportamento di ".gitignore".
