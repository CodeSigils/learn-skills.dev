Практическая гигиена Git при подготовке и фиксации: просматривайте различия, выполняйте подготовку намеренно, избегайте создания шума/сборки артефактов/секретов и восстанавливайтесь после случайной постановки или фиксации. Используйте, когда пользователь спрашивает, как зафиксировать изменения, написать контрольный список рабочего процесса фиксации, удалить/удалить случайные файлы или проверить поведение `.gitignore`.
