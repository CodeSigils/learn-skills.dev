Higiene práctica de Git para la puesta en escena y la confirmación: revise las diferencias, realice la puesta en escena intencionalmente, evite cometer ruido/construya artefactos/secretos y recupérese de una puesta en escena o confirmación accidental. Úselo cuando un usuario pregunta cómo confirmar cambios, escribir una lista de verificación de flujo de trabajo de confirmación, cancelar/eliminar archivos accidentales o verificar el comportamiento de `.gitignore`.
