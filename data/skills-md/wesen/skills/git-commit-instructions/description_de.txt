Praktische Git-Hygiene für Staging und Commit: Überprüfen Sie Unterschiede, stellen Sie sie absichtlich bereit, vermeiden Sie Commit-Rauschen/Build-Artefakte/Geheimnisse und erholen Sie sich nach versehentlichem Staging oder Commit. Verwenden Sie diese Option, wenn ein Benutzer fragt, wie er Änderungen festschreibt, eine Checkliste für den Festschreibungsworkflow schreibt, versehentliche Dateien aus der Bereitstellung/Entfernung entfernt oder das Verhalten von „.gitignore“ überprüft.
