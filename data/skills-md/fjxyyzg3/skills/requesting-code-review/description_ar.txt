يُستخدم عند مراجعة تغييرات التنفيذ المحلي، أو اختلافات العلاقات العامة، أو المشكلات المكتملة، أو التعليمات البرمجية التي تم إنشاؤها، أو إضافات الاختبار، أو مخرجات الوكيل الفرعي للامتثال للمواصفات، أو تغطية معايير القبول، أو جودة التعليمات البرمجية، أو مخاطر الانحدار، أو الاختبارات المفقودة، أو قابلية الصيانة قبل الإعلان عن اكتمال التنفيذ.
