Clarifier les problèmes ambigus dans la base de code ; lorsque des détails peuvent être trouvés dans le code source, la documentation, la configuration, les tests ou l'historique, vérifiez d'abord la source plutôt que de demander plus ; basé sur l'emplacement du code source, les explications du code, les diagrammes et organigrammes d'architecture Mermaid et la documentation HTML facultative pour produire des conclusions. À utiliser lorsque l'utilisateur demande comment fonctionne le code, où se situe le comportement, ce qui appelle quoi, comment une fonctionnalité se déroule, ou demande une analyse détaillée du code, des diagrammes, des rapports ou une documentation générée.
