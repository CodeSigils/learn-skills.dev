Utilisez cette compétence chaque fois que vous travaillez dans un référentiel qui utilise Effect, même si la tâche en cours se trouve dans un nouveau fichier ou si l'utilisateur ne demande pas explicitement l'aide d'Effet. Appliquez-le à tout travail qui doit suivre les modèles d'effets, les conventions, l'architecture ou les outils de support du référentiel. Utilisez-le également pour des questions sur les modèles d'effets, les services, les couches, les schémas, les flux, les environnements d'exécution ou la gestion des erreurs typées.
