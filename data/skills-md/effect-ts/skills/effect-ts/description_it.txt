Utilizza questa abilità ogni volta che lavori in un repository che utilizza Effect, anche se l'attività corrente è in un nuovo file o l'utente non richiede esplicitamente l'aiuto di Effect. Applicalo a qualsiasi lavoro che dovrebbe seguire i modelli di effetti, le convenzioni, l'architettura o gli strumenti di supporto del repository. Utilizzalo anche per domande su modelli di effetti, servizi, livelli, schemi, flussi, tempi di esecuzione o gestione degli errori digitati.
