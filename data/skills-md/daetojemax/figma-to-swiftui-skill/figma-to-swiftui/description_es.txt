Traduzca los diseños de Figma a código SwiftUI listo para producción con fidelidad visual 1:1 utilizando el flujo de trabajo Figma MCP. Se activa cuando el usuario proporciona URL de Figma o ID de nodo y desea una implementación de iOS/SwiftUI, solicita implementar un diseño o componente de Figma para una aplicación de iOS o hace referencia a selecciones de Figma en el contexto de un proyecto de Xcode/SwiftUI. También se activa cuando el usuario solicita inspeccionar los diseños de Figma para la planificación de iOS, buscar tokens de diseño para SwiftUI o convertir activos de Figma para Xcode. Requiere una conexión al servidor Figma MCP que funcione. NO active implementaciones web/React.
