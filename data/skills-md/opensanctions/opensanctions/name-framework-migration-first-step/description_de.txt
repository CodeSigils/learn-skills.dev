Migrieren Sie die Ad-hoc-Namensbereinigung in einem Crawler nach h.review_names (Schritt 1 der Namensframework-Migration). Wird verwendet, wenn eine crawler.py Trennzeichenaufteilungen, Regex-Ersetzungen, das Entfernen von Klammern oder bedingte Logik enthält, die auf Namenszeichenfolgen angewendet wird, bevor der Name hinzugefügt oder angewendet wird.
