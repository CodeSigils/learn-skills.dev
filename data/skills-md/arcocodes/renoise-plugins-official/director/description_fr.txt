Directeur créatif vidéo IA : le point d'entrée unique pour TOUTES les créations vidéo. Gère les publicités de produits, les drames, les comédies, les films de marque, les bandes dessinées animées, les séquences d'action, le contenu de commerce électronique TikTok, les courts métrages multi-clips, les adaptations de romans/scénarios et les productions de montage/MV. Analyse les matériaux, suggère des orientations de style, génère des ressources visuelles, rédige des invites et soumet des tâches de génération vidéo. À utiliser lorsque l'utilisateur dit « faire une vidéo », « idée vidéo », « direction créative », « vidéo produit TikTok », « vidéo de commerce électronique », « vidéo produit », « vidéo de vente », « court métrage », « multi-clip », « vidéo d'histoire », « vidéo d'une minute », « générer une vidéo », « storyboard », « aidez-moi à filmer », « adapter ce script », « faire un montage », « MV ». Ne PAS utiliser pour télécharger des vidéos ou éditer des séquences existantes.
