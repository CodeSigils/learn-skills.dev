Guía para usar Netlify Database: el producto Postgres administrado por GA integrado en Netlify. Úselo cuando un proyecto necesite cualquier tipo de datos dinámicos, estructurados o relacionales. Cubre el aprovisionamiento a través de @netlify/database, configuración de Drizzle ORM (@beta), migraciones, ramificación de vista previa y manejo seguro de datos de producción. Blobs es solo para almacenamiento de archivos/activos: cualquier dato dinámico pertenece a la base de datos.
