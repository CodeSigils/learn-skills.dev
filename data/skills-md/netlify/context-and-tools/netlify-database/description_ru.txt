Руководство по использованию базы данных Netlify — управляемого продукта Postgres, встроенного в Netlify. Используйте, когда проекту нужны какие-либо динамические, структурированные или реляционные данные. Охватывает подготовку через @netlify/database, настройку Drizzle ORM (@beta), миграцию, предварительное ветвление и безопасную обработку производственных данных. Большие двоичные объекты предназначены только для хранения файлов/активов — любые динамические данные принадлежат базе данных.
