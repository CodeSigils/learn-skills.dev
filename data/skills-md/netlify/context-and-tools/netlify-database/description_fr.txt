Guide d'utilisation de Netlify Database — le produit Postgres géré par GA intégré à Netlify. À utiliser lorsqu'un projet nécessite tout type de données dynamiques, structurées ou relationnelles. Couvre le provisionnement via @netlify/database, la configuration de Drizzle ORM (@beta), les migrations, le branchement en prévisualisation et la gestion sécurisée des données de production. Les blobs sont uniquement destinés au stockage de fichiers/actifs : toutes les données dynamiques appartiennent à la base de données.
