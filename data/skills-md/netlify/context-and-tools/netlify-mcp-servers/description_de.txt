Erstellen, implementieren und sichern Sie Model Context Protocol (MCP)-Server auf Netlify. Verwenden Sie es immer dann, wenn die Aufgabe das Erstellen eines MCP-Servers, das Bereitstellen einer App oder API für KI-Agenten als MCP-Tools, das Aufrufen eines benutzerdefinierten Remote-Servers durch Claude/Cursor/Claude Code oder das Hinzufügen von MCP-Tools zu einer vorhandenen Netlify-Site umfasst. Deckt den MCP SDK + Streamable HTTP-Transport auf einer Netlify-Funktion, Authentifizierung (einzelnes gemeinsames Geheimnis vs. benutzerspezifische API-Schlüssel mit Netlify Identity), Lese-/Schreibsicherheit, Datei-Uploads und das Verbinden von Clients ab. Verwenden Sie dies auch, wenn der Benutzer nur „MCP“, „Tool-Server für einen Agenten“ oder „Eine KI meine API verwenden lassen“ sagt.
