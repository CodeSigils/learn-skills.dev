Cree, implemente y proteja servidores Model Context Protocol (MCP) en Netlify. Úselo siempre que la tarea implique crear un servidor MCP, exponer una aplicación o API a agentes de IA como herramientas MCP, permitir que Claude/Cursor/Claude Code llame a un servidor remoto personalizado o agregar herramientas MCP a un sitio Netlify existente. Cubre el transporte HTTP SDK de MCP + Streamable en una función Netlify, autenticación (secreto único compartido versus claves API por usuario con Netlify Identity), seguridad de lectura/escritura, carga de archivos y conexión de clientes. Úselo incluso cuando el usuario simplemente diga "MCP", "servidor de herramientas para un agente" o "dejar que una IA use mi API".
