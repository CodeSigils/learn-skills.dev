Créez, déployez et sécurisez des serveurs MCP (Model Context Protocol) sur Netlify. À utiliser chaque fois que la tâche implique de créer un serveur MCP, d'exposer une application ou une API à des agents IA en tant qu'outils MCP, de laisser Claude/Curseur/Claude Code appeler un serveur distant personnalisé ou d'ajouter des outils MCP à un site Netlify existant. Couvre le transport HTTP MCP SDK + Streamable sur une fonction Netlify, l'authentification (secret partagé unique ou clés API par utilisateur avec Netlify Identity), la sécurité en lecture/écriture, les téléchargements de fichiers et la connexion des clients. À utiliser même lorsque l'utilisateur dit simplement « MCP », « serveur d'outils pour un agent » ou « laisser une IA utiliser mon API ».
