Netlify で Model Context Protocol (MCP) サーバーを構築、展開、保護します。タスクに MCP サーバーの作成、MCP ツールとしてアプリまたは API を AI エージェントに公開すること、クロード / カーソル / クロード コードにカスタム リモート サーバーを呼び出すこと、または既存の Netlify サイトへの MCP ツールの追加が含まれる場合は常に使用します。 Netlify 機能での MCP SDK + ストリーミング可能な HTTP トランスポート、認証 (単一の共有シークレットと Netlify Identity を使用したユーザーごとの API キー)、読み取り/書き込みの安全性、ファイルのアップロード、およびクライアントの接続について説明します。ユーザーが単に「MCP」、「エージェント用のツール サーバー」、または「AI に API を使用させよう」と言う場合でも使用します。
