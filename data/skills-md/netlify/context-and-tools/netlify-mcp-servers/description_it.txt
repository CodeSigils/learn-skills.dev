Costruisci, distribuisci e proteggi i server MCP (Model Context Protocol) su Netlify. Da utilizzare ogni volta che l'attività prevede la creazione di un server MCP, l'esposizione di un'app o un'API agli agenti AI come strumenti MCP, il permesso a Claude/Cursor/Claude Code di chiamare un server remoto personalizzato o l'aggiunta di strumenti MCP a un sito Netlify esistente. Copre l'SDK MCP + trasporto HTTP streaming su una funzione Netlify, autenticazione (singolo segreto condiviso rispetto alle chiavi API per utente con identità Netlify), sicurezza in lettura/scrittura, caricamenti di file e connessione di client. Utilizzare anche quando l'utente dice semplicemente "MCP", "server degli strumenti per un agente" o "consenti a un'intelligenza artificiale di utilizzare la mia API".
