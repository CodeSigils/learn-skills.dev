إنشاء ونشر وتأمين خوادم بروتوكول السياق النموذجي (MCP) على Netlify. استخدمه عندما تتضمن المهمة إنشاء خادم MCP، أو تعريض تطبيق أو واجهة برمجة تطبيقات لوكلاء الذكاء الاصطناعي كأدوات MCP، أو السماح لـ Claude / Cursor / Claude Code بالاتصال بخادم بعيد مخصص، أو إضافة أدوات MCP إلى موقع Netlify موجود. يغطي نقل MCP SDK + HTTP القابل للتدفق على وظيفة Netlify، والمصادقة (سر واحد مشترك مقابل مفاتيح API لكل مستخدم مع Netlify Identity)، وأمان القراءة/الكتابة، وتحميل الملفات، وتوصيل العملاء. يُستخدم حتى عندما يقول المستخدم فقط "MCP" أو "خادم الأدوات للوكيل" أو "السماح للذكاء الاصطناعي باستخدام واجهة برمجة التطبيقات الخاصة بي".
