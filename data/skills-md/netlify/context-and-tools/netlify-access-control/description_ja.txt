タスクに Netlify サイトにアクセスできるユーザーを制御すること、または Netlify Identity と Secure Access を区別することが含まれる場合に使用します。ユーザーがサイトのロックや会社/チームへの展開、従業員のみへのアクセスの制限、社内または従業員のみのアプリの構築、パスワード保護、SSO、または SAML のセットアップを希望する場合、「誰がサイトにアクセスできるか」を尋ねる場合、または Netlify ID とセキュア アクセス、チーム ログインと OAuth プロバイダーについて混乱する場合にトリガーします。リクエストを適切なレイヤー (アプリレベルの ID、サイト訪問者のパスワード保護、Auth0 拡張機能、またはチーム/組織 SAML SSO) にルーティングし、2 層 (境界 + アプリ内 ID) パターンとその二重ログインのトレードオフについて説明します。アプリレベルの認証自体を構築するには、netlify-identity スキルを使用します。
