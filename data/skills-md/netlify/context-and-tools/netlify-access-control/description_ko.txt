작업에 Netlify 사이트에 접속할 수 있는 사람을 제어하거나 보안 액세스와 Netlify ID를 구분하는 작업이 포함될 때 사용합니다. 사용자가 사이트를 잠그거나 회사/팀에 배포하고, 직원에게만 액세스를 제한하고, 내부 또는 직원 전용 앱을 구축하고, 비밀번호 보호, SSO 또는 SAML을 설정하고, "내 사이트에 액세스할 수 있는 사람"을 묻거나, Netlify ID, 보안 액세스, 팀 로그인, OAuth 공급자에 대해 혼동할 때마다 트리거됩니다. 요청을 올바른 계층(앱 수준 ID, 사이트 방문자 비밀번호 보호, Auth0 확장 또는 팀/조직 SAML SSO)으로 라우팅하고 2계층(경계 + 인앱 ID) 패턴과 이중 로그인 장단점을 설명합니다. 앱 수준 인증 자체를 구축하려면 netlify-identity 기술을 사용하세요.
