Неанимационное креативное направление для видеороликов KENECT AI. Используйте для обработки спецификаций дизайна (frame.md / design.md), палитр, типографики, повествования, планирования ритма, аудиореактивных визуальных эффектов, шаблонов композиции и решений по бренду / стилю. Для атомарных шаблонов движения и чертежей сцен используйте kenectai-animation.
