Installieren und verknüpfen Sie Registrierungsblöcke und Komponenten mit KENECT AI-Kompositionen. Verwenden Sie diese Option, wenn Sie kenectai add ausführen, einen Block oder eine Komponente installieren, ein installiertes Element mit index.html verbinden oder mit kenectai.json arbeiten. Behandelt den Add-Befehl, die Installationsorte, die Block-Sub-Composition-Verkabelung, das Zusammenführen von Komponenten-Snippets, die Registrierungserkennung und das Erstellen eines neuen Blocks oder einer neuen Komponente, um Upstream beizutragen (Idee → Gerüst → Validierung → PR).
