Importieren Sie Fertigkeiten von Drittanbietern aus einem Git-Repository in das Home-Agent-System, indem Sie sie in ~/.agents/vendor klonen, ausgewählte Fertigkeiten über ~/.agents/skills verfügbar machen und gleichnamige Befehls-Wrapper in ~/.agents/commands erstellen. Verwenden Sie diese Option, wenn der Benutzer eine Skill-Repository-URL bereitstellt oder externe Skills in das lokale kanonische Layout integrieren möchte.
