Импортируйте сторонние навыки из репозитория git в домашнюю систему агентов, клонировав их в ~/.agents/vendor, открыв выбранные навыки через ~/.agents/skills и создав оболочки команд с тем же именем в ~/.agents/commands. Используйте, когда пользователь предоставляет URL-адрес хранилища навыков или хочет добавить внешние навыки в локальный канонический макет.
