Importe habilidades de terceros desde un repositorio git al sistema de agente local clonando en ~/.agents/vendor, exponiendo habilidades seleccionadas a través de ~/.agents/skills y creando contenedores de comandos con el mismo nombre en ~/.agents/commands. Úselo cuando el usuario proporciona una URL del repositorio de habilidades o desea incorporar habilidades externas al diseño canónico local.
