Importez des compétences tierces depuis un référentiel git dans le système d'agent d'accueil en les clonant dans ~/.agents/vendor, en exposant les compétences sélectionnées via ~/.agents/skills et en créant des wrappers de commandes du même nom dans ~/.agents/commands. À utiliser lorsque l'utilisateur fournit une URL de référentiel de compétences ou souhaite intégrer des compétences externes dans la présentation canonique locale.
