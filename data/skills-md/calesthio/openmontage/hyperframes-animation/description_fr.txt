Toutes les connaissances en animation pour HyperFrames : règles de mouvement atomique, plans de scènes multiphases, transitions de scène, techniques de conception de mouvement plus larges ET les sept adaptateurs d'exécution (GSAP par défaut, plus Lottie, Three.js, Anime.js, images clés CSS, API d'animations Web, TypeGPU). À utiliser pour toute tâche de mouvement ou d'animation : choisissez 2 à 4 règles et composez, ou chargez un plan, ou recherchez une API spécifique à l'exécution (par exemple, les facilités GSAP / le lecteur Lottie / le mélangeur Three.js). Natif HyperFrames : chronologie en pause unique, recherche sécurisée, déterministe.
