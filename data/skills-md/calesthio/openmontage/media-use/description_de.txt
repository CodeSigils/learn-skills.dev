Agent Media OS – löst alle Medienanforderungen (Hintergrundmusik, SFX, Bild, Symbol) in eine eingefrorene lokale Datei + einen Hauptbucheintrag auf. Ein Verb („resolve“) übernimmt die gesamte Kaskade – Projekt-Cache, globaler Cache, HeyGen-Katalogsuche, Einfrieren, Registrieren. Hält Suchgeräusche auf der Festplatte und gibt dem Agenten einen Pfad. Verwenden Sie diese Option, wenn eine Komposition Hintergrundmusik, Soundeffekte, Bilder oder Symbole benötigt.
