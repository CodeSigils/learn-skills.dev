يرشد المستخدمين من خلال إعداد مفتاح ElevenLabs API لأدوات ElevenLabs MCP. يُستخدم عندما يحتاج المستخدم إلى تكوين مفتاح واجهة برمجة تطبيقات ElevenLabs، أو عندما تفشل أدوات ElevenLabs بسبب فقدان مفتاح واجهة برمجة التطبيقات، أو عندما يذكر المستخدم حاجته إلى الوصول إلى ElevenLabs. يتحقق أولاً مما إذا كان ELEVENLABS_API_KEY قد تم تكوينه وصلاحيته بالفعل، ولا يقوم بتشغيل الإعداد الكامل إلا عند الحاجة.
