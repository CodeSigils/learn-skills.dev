Führt Benutzer durch die Einrichtung eines ElevenLabs-API-Schlüssels für ElevenLabs MCP-Tools. Verwenden Sie diese Option, wenn der Benutzer einen ElevenLabs-API-Schlüssel konfigurieren muss, wenn ElevenLabs-Tools aufgrund eines fehlenden API-Schlüssels fehlschlagen oder wenn der Benutzer angibt, dass er Zugriff auf ElevenLabs benötigt. Prüft zunächst, ob ELEVENLABS_API_KEY bereits konfiguriert und gültig ist, und führt das vollständige Setup nur bei Bedarf aus.
