Guía a los usuarios a través de la configuración de una clave API de ElevenLabs para las herramientas MCP de ElevenLabs. Úselo cuando el usuario necesite configurar una clave API de ElevenLabs, cuando las herramientas de ElevenLabs fallen debido a que falta una clave API o cuando el usuario mencione que necesita acceso a ElevenLabs. Primero verifica si ELEVENLABS_API_KEY ya está configurado y es válido, y solo ejecuta la configuración completa cuando sea necesario.
