Guida gli utenti attraverso la configurazione di una chiave API ElevenLabs per gli strumenti MCP ElevenLabs. Da utilizzare quando l'utente deve configurare una chiave API ElevenLabs, quando gli strumenti ElevenLabs falliscono a causa della chiave API mancante o quando l'utente menziona la necessità di accedere a ElevenLabs. Innanzitutto controlla se ELEVENLABS_API_KEY è già configurato e valido ed esegue la configurazione completa solo quando necessario.
