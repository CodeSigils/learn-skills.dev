Помогает пользователям настроить ключ API ElevenLabs для инструментов ElevenLabs MCP. Используйте, когда пользователю необходимо настроить ключ API ElevenLabs, когда инструменты ElevenLabs выходят из строя из-за отсутствия ключа API или когда пользователь упоминает о необходимости доступа к ElevenLabs. Сначала проверяет, настроен ли уже ELEVENLABS_API_KEY и действителен, и запускает полную настройку только при необходимости.
