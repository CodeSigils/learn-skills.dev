Genere videos de IA a partir de mensajes de texto utilizando múltiples puertas de enlace de proveedores. Úselo cuando: (1) Generar videos a partir de descripciones de texto, (2) Crear videoclips generados por IA para la producción de contenido, (3) Generar imagen a video con una imagen de referencia, (4) Elegir entre proveedores de generación de video (VEO, Kling, Sora, Runway, Seedance, MiniMax). Admite dos puertas de enlace: API HeyGen y API fal.ai.
