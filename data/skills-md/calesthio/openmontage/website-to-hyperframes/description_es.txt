Capture un sitio web y cree un vídeo HyperFrames a partir de él. Úselo cuando: (1) un usuario proporciona una URL y quiere un video, (2) alguien dice "capturar este sitio", "convierta esto en un video", "haga una promoción desde mi sitio", (3) el usuario quiere un anuncio social, un recorrido por el producto o cualquier video basado en un sitio web existente, (4) el usuario comparte un enlace y solicita cualquier tipo de contenido de video. Incluso si el usuario simplemente pega una URL, esta es la habilidad que debe utilizar.
