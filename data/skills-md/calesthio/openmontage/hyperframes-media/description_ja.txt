1 つの共有オーディオ エンジン (`scripts/audio.mjs`) によって生成される、HyperFrames コンポジション用のオーディオおよびメディア アセット — マルチプロバイダー TTS (HeyGen / イレブンラボ / Koko ローカル)、バックグラウンド ミュージック + サウンド エフェクト (デフォルトで HeyGen オーディオ ライブラリの取得、ローカルの Lyria / MusicGen BGM 生成と資格情報なしのフォールバックとしてバンドルされた SFX ライブラリを使用)、Whisper の文字起こし、背景の削除、およびキャプションのオーサリング。ナレーション / TTS、BGM、SFX / サウンドエフェクト、文字起こし、キャプション / 字幕 / 歌詞 / カラオケ / 単語ごとのスタイル設定、音声 + プロバイダーの選択、および音楽ムードのプロンプトに使用します。
