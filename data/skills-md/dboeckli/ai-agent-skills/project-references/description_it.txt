Cerca convenzioni, modelli e implementazioni concrete dai tuoi repository GitHub controllati localmente in ~/projects/referenzen/. Usa questa abilità ogni volta che c'è incertezza su come viene fatto qualcosa nella tua famiglia di codebase, ad es. Struttura del grafico Helm, manifest Kubernetes, modelli di configurazione del framework, convenzioni Docker Compose, configurazione della pipeline CI/CD o qualsiasi altra decisione architetturale ricorrente. Invocatelo in modo proattivo prima di indovinare una convention; citare sempre il progetto e il percorso di origine quando viene adottato un modello. Da utilizzare anche quando l'utente chiede di estrarre, aggiornare o cercare repository di riferimento.
