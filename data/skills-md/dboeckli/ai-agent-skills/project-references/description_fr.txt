Recherchez des conventions, des modèles et des implémentations concrètes à partir de vos propres référentiels GitHub extraits localement sous ~/projects/referenzen/. Utilisez cette compétence chaque fois qu'il existe une incertitude sur la façon dont quelque chose est fait dans votre famille de bases de code - par ex. Structure du graphique Helm, manifestes Kubernetes, modèles de configuration du framework, conventions Docker Compose, configuration du pipeline CI/CD ou toute autre décision architecturale récurrente. Invoquez-le de manière proactive avant de deviner lors d’un congrès ; citez toujours le projet source et le chemin lorsqu’un modèle est adopté. À utiliser également lorsque l'utilisateur demande à extraire, mettre à jour ou rechercher des référentiels de référence.
