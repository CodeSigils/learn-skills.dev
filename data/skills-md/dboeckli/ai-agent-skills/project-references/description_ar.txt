ابحث عن الاتفاقيات والأنماط والتطبيقات الملموسة من مستودعات GitHub الخاصة بك والتي تم سحبها محليًا ضمن ~/projects/referenzen/. استخدم هذه المهارة عندما يكون هناك عدم يقين بشأن كيفية عمل شيء ما في عائلة قاعدة التعليمات البرمجية الخاصة بك - على سبيل المثال. هيكل مخطط Helm، أو بيانات Kubernetes، أو أنماط تكوين إطار العمل، أو اصطلاحات Docker Compose، أو إعداد خط أنابيب CI/CD، أو أي قرار معماري متكرر آخر. استدعائها بشكل استباقي قبل التخمين في أي مؤتمر؛ استشهد دائمًا بالمشروع المصدر والمسار عند اعتماد النمط. يُستخدم أيضًا عندما يطلب المستخدم سحب المستودعات المرجعية أو تحديثها أو البحث فيها.
