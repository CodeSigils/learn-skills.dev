~/projects/referenzen/ の下でローカルにチェックアウトされた独自の GitHub リポジトリから、規則、パターン、および具体的な実装を検索します。コードベース ファミリ内で何かがどのように行われるかが不確実な場合には、このスキルを使用してください。 Helm チャートの構造、Kubernetes マニフェスト、フレームワーク構成パターン、Docker Compose の規則、CI/CD パイプラインのセットアップ、またはその他の繰り返し発生するアーキテクチャ上の決定。規則を推測する前に、積極的に呼び出してください。パターンを採用する場合は、必ずソース プロジェクトとパスを引用してください。ユーザーが参照リポジトリのチェックアウト、更新、または検索を要求する場合にも使用します。
