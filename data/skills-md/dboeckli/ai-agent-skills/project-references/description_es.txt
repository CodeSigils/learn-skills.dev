Busque convenciones, patrones e implementaciones concretas de sus propios repositorios de GitHub extraídos localmente en ~/projects/referenzen/. Utilice esta habilidad siempre que haya incertidumbre sobre cómo se hace algo en su familia de código base, por ejemplo. Estructura del gráfico de timón, manifiestos de Kubernetes, patrones de configuración del marco, convenciones de Docker Compose, configuración de canalización de CI/CD o cualquier otra decisión arquitectónica recurrente. Invocarlo proactivamente antes de adivinar una convención; Siempre cite el proyecto fuente y la ruta cuando se adopte un patrón. Utilícelo también cuando el usuario solicite consultar, actualizar o buscar repositorios de referencia.
