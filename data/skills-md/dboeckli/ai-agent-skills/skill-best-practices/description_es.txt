Guía para crear, estructurar y mejorar las habilidades de Claude (SKILL.md). Úselo al desarrollar una nueva habilidad, revisar una habilidad existente, escribir el contenido de SKILL.md, definir condiciones de activación, solucionar problemas de habilidades (no activar, activar demasiado, no seguir instrucciones) o planificar la distribución de habilidades. Cuando trabaje en cualquier habilidad en este repositorio: cargue también la habilidad cc-best-practices y siempre actualice las tablas de habilidades CLAUDE.md y README.md después de cualquier cambio de habilidad. NO lo use para la configuración general de Claude Code ni para la configuración de enlaces.
