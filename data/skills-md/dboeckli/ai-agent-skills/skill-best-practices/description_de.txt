Leitfaden zum Erstellen, Strukturieren und Verbessern von Claude-Fähigkeiten (SKILL.md). Verwenden Sie es, wenn Sie einen neuen Skill erstellen, einen vorhandenen Skill überprüfen, SKILL.md Frontmatter schreiben, Triggerbedingungen definieren, Skillprobleme beheben (keine Triggerung, Übertriggerung, Anweisungen nicht befolgt) oder die Skillverteilung planen. Wenn Sie an einem Skill in diesem Repository arbeiten: Laden Sie auch den cc-best-practices-Skill und aktualisieren Sie nach jeder Skill-Änderung immer die Skill-Tabellen CLAUDE.md und README.md. NICHT für die allgemeine Claude-Code-Konfiguration oder Hook-Einrichtung verwenden.
