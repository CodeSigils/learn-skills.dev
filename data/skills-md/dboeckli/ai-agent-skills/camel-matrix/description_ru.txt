Создает матрицу совместимости AsciiDoc для версий Apache Camel Spring Boot, Spring Boot и Apache CXF путем запуска сценария Camel-springboot-matrix.sh. Используйте, когда пользователь запрашивает создание или обновление матрицы совместимости Camel, проверку совместимости версий Camel Spring Boot или запуск сценария Camel-springboot-matrix. Поддерживает дополнительные аргументы диапазона версий (минимум, максимум).
