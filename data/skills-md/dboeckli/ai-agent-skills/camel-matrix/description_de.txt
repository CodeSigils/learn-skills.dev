Erstellt eine AsciiDoc-Kompatibilitätsmatrix für die Versionen Apache Camel Spring Boot, Spring Boot und Apache CXF, indem das Skript „camel-springboot-matrix.sh“ ausgeführt wird. Verwenden Sie diese Option, wenn der Benutzer die Camel-Kompatibilitätsmatrix generieren oder aktualisieren, die Kompatibilität der Camel Spring Boot-Version überprüfen oder das Skript „camel-springboot-matrix“ ausführen möchte. Unterstützt optionale Versionsbereichsargumente (Min. Max).
