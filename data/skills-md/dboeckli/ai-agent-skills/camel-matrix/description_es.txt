Genera una matriz de compatibilidad AsciiDoc para las versiones Apache Camel Spring Boot, Spring Boot y Apache CXF ejecutando el script camel-springboot-matrix.sh. Úselo cuando el usuario solicite generar o actualizar la matriz de compatibilidad de Camel, verificar la compatibilidad de la versión de Camel Spring Boot o ejecutar el script camel-springboot-matrix. Admite argumentos de rango de versión opcionales (mínimo máximo).
