Genera una matrice di compatibilità AsciiDoc per le versioni Apache Camel Spring Boot, Spring Boot e Apache CXF eseguendo lo script camel-springboot-matrix.sh. Da utilizzare quando l'utente richiede di generare o aggiornare la matrice di compatibilità Camel, verificare la compatibilità della versione Camel Spring Boot o eseguire lo script camel-springboot-matrix. Supporta argomenti opzionali per l'intervallo di versioni (min max).
