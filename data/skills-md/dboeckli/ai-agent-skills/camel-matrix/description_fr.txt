Génère une matrice de compatibilité AsciiDoc pour les versions Apache Camel Spring Boot, Spring Boot et Apache CXF en exécutant le script camel-springboot-matrix.sh. À utiliser lorsque l'utilisateur demande de générer ou de mettre à jour la matrice de compatibilité Camel, de vérifier la compatibilité des versions de Camel Spring Boot ou d'exécuter le script camel-springboot-matrix. Prend en charge les arguments facultatifs de plage de versions (min max).
