إرشادات حول كيفية استخدام Claude Code بفعالية - تغطي إدارة السياق، واستراتيجيات التحقق، وسير عمل خطة الاستكشاف والتنفيذ، وتقنيات المطالبة، وإدارة الجلسة، والجلسات الموازية، وأنماط الفشل الشائعة. استخدم هذه المهارة عندما يسأل المستخدم عن كيفية تحقيق أقصى استفادة من Claude Code، أو كيفية كتابة مطالبات أفضل، أو كيفية إدارة السياق، أو متى يتم استخدام وضع الخطة، أو كيفية أتمتة المهام، أو عندما يصف نمطًا محبطًا مثل تكرار Claude للأخطاء أو فقدان مسار التعليمات.
