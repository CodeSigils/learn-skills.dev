Writer Writing System Distiller. Geben Sie den Namen eines berühmten Autors oder eines literarischen Stils ein und es werden automatisch eine Werkkorpussammlung, stilistische Analyse, linguistische Analyse, narratologische Analyse und Extraktion von Schreibmechanismen durchgeführt, wodurch letztendlich eine ausführbare Schreibfähigkeit generiert wird. Auslösersätze: „Destillieren Sie das Schreiben vonXX“, „Schaffen Sie eine XX-Schreibfähigkeit“, „Analysieren Sie, wie XX schreibt“, „XXs Schreibmethode“, „Schreiber-Nuwa“, „Generieren Sie XX-Schreibfähigkeiten“, „Analysieren Sie den literarischen Stil von XX“.
