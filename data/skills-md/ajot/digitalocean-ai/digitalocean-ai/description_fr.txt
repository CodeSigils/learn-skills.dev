Créez et déployez des applications avec le moteur d'inférence DigitalOcean. Fournit l'authentification, les modèles disponibles (OpenAI, Anthropic, Meta, DeepSeek, Qwen, NVIDIA, etc.), l'intégration via cURL et le SDK OpenAI, la génération d'images/audio/vidéo, les agents IA avec bases de connaissances, le Model Playground, l'inférence par lots, le routeur d'inférence, les évaluations, les bases de données gérées (PostgreSQL avec pgvector, MongoDB), le stockage d'objets Spaces et le déploiement sur DigitalOcean App Platform avec déploiement continu à partir de GitHub. À utiliser lors de la création ou du déploiement d'applications basées sur l'IA sur DigitalOcean.
