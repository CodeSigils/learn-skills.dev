Claude Desktop, Cursor 또는 MCP Inspector와 같은 MCP 클라이언트에 AG2 `에이전트`(및 프롬프트 및 리소스 포함)를 노출하는 MCP 서버를 호스팅합니다. 에이전트를 `MCPServer(agent)`로 래핑합니다. 이는 `Agent.ask()`를 단일 대화 도구로 표면화하고 stdio(`run_stdio()`) 또는 스트리밍 가능한 HTTP(그 자체가 uvicorn용 ASGI 앱임)를 통해 서비스됩니다. `MCPServer`, `SessionConfig`(다중 턴 기록), `Prompt`/`PromptArgument`/`PromptMessage`, `Resource`/`ResourceTemplate`, `AskContext`/`ContextProvider`(요청별 삽입), `build_ask_tool`, OAuth2 `security=` 및 프로세스 내 `testing.connect`/`testing.serve` 도우미를 다룹니다. 다른 MCP 클라이언트가 귀하의 에이전트에 전화하도록 하려는 경우에 사용하십시오. 이는 서버 측입니다. 에이전트(클라이언트 측)에서 외부 MCP 서버를 사용하려면 `ag2-use-builtin-tools`(`MCPServerTool`)를 참조하세요.
