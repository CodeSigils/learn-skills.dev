Aloje un servidor MCP que exponga un "Agente" AG2 (más solicitudes y recursos) a clientes MCP como Claude Desktop, Cursor o MCP Inspector. Envuelva el agente con `MCPServer(agent)`: presenta `Agent.ask()` como una única herramienta conversacional y sirve a través de stdio (`run_stdio()`) o HTTP transmitible (es en sí misma una aplicación ASGI para uvicorn). Cubre `MCPServer`, `SessionConfig` (historial de múltiples turnos), `Prompt`/`PromptArgument`/`PromptMessage`, `Resource`/`ResourceTemplate`, `AskContext`/`ContextProvider` (inyección por solicitud), `build_ask_tool`, OAuth2 `security=` y `testing.connect`/`testing.serve` en proceso ayudantes. Úselo cuando desee que OTROS clientes de MCP llamen a SU agente. Este es el lado del SERVIDOR: para CONSUMIR servidores MCP externos desde un agente (lado del cliente), consulte `ag2-use-builtin-tools` (`MCPServerTool`).
