استضيف خادم MCP يُظهر وكيل AG2 `Agent` (بالإضافة إلى التعليمات والموارد) لعملاء MCP مثل Claude Desktop أو Cursor أو MCP Inspector. قم بلف الوكيل باستخدام `MCPServer(agent)` — فهو يُعرِّض `Agent.ask()` كأداة محادثة واحدة ويخدم عبر stdio (`run_stdio()`) أو HTTP قابل للبث (وهو نفسه تطبيق ASGI لـ uvicorn). يغطي `MCPServer`، `SessionConfig` (سجل متعدد الجولات)، `Prompt`/`PromptArgument`/`PromptMessage`، `Resource`/`ResourceTemplate`، `AskContext`/`ContextProvider` (حقن لكل طلب)، `build_ask_tool`، OAuth2 `security=`، ومساعدي `testing.connect`/`testing.serve` داخل العملية. استخدمه عندما تريد أن يستدعي عملاء MCP الآخرين الوكيل الخاص بك. هذا هو جانب الخادم — لاستهلاك خوادم MCP الخارجية من وكيل (جانب العميل) انظر `ag2-use-builtin-tools` (`MCPServerTool`).

يرجى دائمًا الرد بلغة المستخدم.
