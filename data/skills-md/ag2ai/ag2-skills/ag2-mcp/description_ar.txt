قم باستضافة خادم MCP الذي يعرض AG2 `Agent` (بالإضافة إلى المطالبات والموارد) لعملاء MCP مثل Claude Desktop، أو Cursor، أو MCP Inspector. قم بتغليف الوكيل بـ `MCPServer(agent)` - فهو يظهر `Agent.ask()` كأداة محادثة واحدة ويعمل عبر stdio (`run_stdio()`) أو HTTP القابل للتدفق (وهو في حد ذاته تطبيق ASGI لـ uvicorn). يغطي `MCPServer`، و`SessionConfig` (سجل متعدد المنعطفات)، و`Prompt`/`PromptArgument`/`PromptMessage`، و`Resource`/`ResourceTemplate`، و`AskContext`/`ContextProvider` (إدخال لكل طلب)، و`build_ask_tool`، وOAuth2 `security=`، وقيد المعالجة مساعدات `testing.connect`/`testing.serve`. استخدمه عندما تريد من عملاء MCP الآخرين الاتصال بوكيلك. هذا هو جانب الخادم - بالنسبة لاستهلاك خوادم MCP الخارجية من وكيل (جانب العميل) راجع `ag2-use-builtin-tools` (`MCPServerTool`).
