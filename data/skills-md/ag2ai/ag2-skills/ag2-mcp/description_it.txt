Ospita un server MCP che espone un "agente" AG2 (più prompt e risorse) a client MCP come Claude Desktop, Cursor o MCP Inspector. Avvolgi l'agente con `MCPServer(agent)`: presenta `Agent.ask()` come un singolo strumento di conversazione e funziona su stdio (`run_stdio()`) o HTTP streaming (è essa stessa un'app ASGI per uvicorn). Copre `MCPServer`, `SessionConfig` (cronologia multi-turno), `Prompt`/`PromptArgument`/`PromptMessage`, `Resource`/`ResourceTemplate`, `AskContext`/`ContextProvider` (iniezione per richiesta), `build_ask_tool`, OAuth2 `security=` e gli helper in-process `testing.connect`/`testing.serve`. Utilizzalo quando vuoi che ALTRI client MCP chiamino il TUO agente. Questo è il lato SERVER: per CONSUMARE server MCP esterni da un agente (lato client) vedere `ag2-use-builtin-tools` ("MCPServerTool").
