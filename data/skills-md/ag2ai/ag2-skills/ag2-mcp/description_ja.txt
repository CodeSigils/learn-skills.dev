Claude Desktop、Cursor、MCP Inspector などの MCP クライアントに AG2 「エージェント」 (およびプロンプトとリソース) を公開する MCP サーバーをホストします。エージェントを `MCPServer(agent)` でラップします。これは `Agent.ask()` を単一の会話ツールとして表示し、stdio (`run_stdio()`) またはストリーミング可能な HTTP (それ自体が uvicorn の ASGI アプリです) 上で機能します。 `MCPServer`、`SessionConfig` (マルチターン履歴)、`Prompt`/`PromptArgument`/`PromptMessage`、`Resource`/`ResourceTemplate`、`AskContext`/`ContextProvider` (リクエストごとのインジェクション)、`build_ask_tool`、OAuth2 `security=`、およびインプロセスをカバーします。 `testing.connect`/`testing.serve` ヘルパー。他の MCP クライアントからあなたのエージェントに電話をかけたい場合に使用します。これはサーバー側です。エージェント (クライアント側) からの外部 MCP サーバーの消費については、`ag2-use-builtin-tools` (`MCPServerTool`) を参照してください。
