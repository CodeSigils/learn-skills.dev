托管一个 MCP 服务器，该服务器向 Claude Desktop、Cursor 或 MCP Inspector 等 MCP 客户端公开 AG2“代理”（以及提示和资源）。用“MCPServer(agent)”包装代理——它将“Agent.ask()”表面为单个对话工具，并通过 stdio (“run_stdio()”) 或流式 HTTP（它本身是 uvicorn 的 ASGI 应用程序）提供服务。涵盖`MCPServer`、`SessionConfig`（多轮历史记录）、`Prompt`/`PromptArgument`/`PromptMessage`、`Resource`/`ResourceTemplate`、`AskContext`/`ContextProvider`（每个请求注入）、`build_ask_tool`、OAuth2 `security=`和进程内`testing.connect`/`testing.serve`帮助器。当您希望其他 MCP 客户呼叫您的代理时使用。这是服务器端 - 要从代理（客户端）使用外部 MCP 服务器，请参阅“ag2-use-builtin-tools”（“MCPServerTool”）。
