Разверните MCP‑сервер, который открывает AG2‑`Agent` (включая подсказки и ресурсы) для MCP‑клиентов, таких как Claude Desktop, Cursor или MCP Inspector. Оберните агента в `MCPServer(agent)` — это делает `Agent.ask()` доступным как единый диалоговый инструмент и обслуживает запросы через stdio (`run_stdio()`) или потоковый HTTP (сам являясь ASGI‑приложением для uvicorn). Поддерживает `MCPServer`, `SessionConfig` (история многократных обменов), `Prompt`/`PromptArgument`/`PromptMessage`, `Resource`/`ResourceTemplate`, `AskContext`/`ContextProvider` (внедрение per‑request), `build_ask_tool`, OAuth2 `security=`, а также вспомогательные функции в‑процессе `testing.connect`/`testing.serve`. Используйте, когда хотите, чтобы ДРУГИЕ MCP‑клиенты вызывали ВАШЕГО агента. Это СТОРОНА СЕРВЕРА — для ПОЛУЧЕНИЯ доступа к внешним MCP‑серверам из агента (клиентская сторона) см. `ag2-use-builtin-tools` (`MCPServerTool`).
