Hébergez un serveur MCP qui expose un « agent » AG2 (plus des invites et des ressources) aux clients MCP comme Claude Desktop, Cursor ou MCP Inspector. Enveloppez l'agent avec `MCPServer(agent)` — il fait apparaître `Agent.ask()` comme un outil conversationnel unique et sert via stdio (`run_stdio()`) ou HTTP diffusable (c'est lui-même une application ASGI pour uvicorn). Couvre `MCPServer`, `SessionConfig` (historique multi-tours), `Prompt`/`PromptArgument`/`PromptMessage`, `Resource`/`ResourceTemplate`, `AskContext`/`ContextProvider` (injection par requête), `build_ask_tool`, OAuth2 `security=` et en cours Aides `testing.connect`/`testing.serve`. À utiliser lorsque vous souhaitez que d'AUTRES clients MCP appellent VOTRE agent. Il s'agit du côté SERVEUR — pour CONSOMMER des serveurs MCP externes à partir d'un agent (côté client), voir `ag2-use-builtin-tools` (`MCPServerTool`).
