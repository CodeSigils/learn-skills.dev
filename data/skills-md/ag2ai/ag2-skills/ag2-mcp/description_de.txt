Hosten Sie einen MCP-Server, der MCP-Clients wie Claude Desktop, Cursor oder dem MCP Inspector einen AG2-„Agenten“ (plus Eingabeaufforderungen und Ressourcen) zur Verfügung stellt. Wickeln Sie den Agenten mit „MCPServer(agent)“ ein – er zeigt „Agent.ask()“ als einzelnes Konversationstool an und dient über stdio („run_stdio()“) oder streambares HTTP (es ist selbst eine ASGI-App für uvicorn). Deckt „MCPServer“, „SessionConfig“ (Multi-Turn-Verlauf), „Prompt“/„PromptArgument“/„PromptMessage“, „Resource“/„ResourceTemplate“, „AskContext“/„ContextProvider“ (Injektion pro Anfrage), „build_ask_tool“, „OAuth2 „security=“ und „testing.connect“/„testing.serve“ im Prozess ab Helfer. Verwenden Sie diese Option, wenn Sie möchten, dass ANDERE MCP-Kunden IHREN Agenten anrufen. Dies ist die SERVER-Seite – Informationen zum VERBRAUCH externer MCP-Server von einem Agenten (Client-Seite) finden Sie unter „ag2-use-builtin-tools“ („MCPServerTool“).
