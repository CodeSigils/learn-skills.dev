託管一個 MCP 伺服器，該伺服器向 Claude Desktop、Cursor 或 MCP Inspector 等 MCP 用戶端公開 AG2「代理」（以及提示和資源）。用「MCPServer(agent)」包裝代理程式－它將「Agent.ask()」表面為單一對話工具，並透過 stdio (「run_stdio()」) 或串流 HTTP（它本身是 uvicorn 的 ASGI 應用程式）提供服務。涵蓋`MCPServer`、`SessionConfig`（多輪歷史記錄）、`Prompt`/`PromptArgument`/`PromptMessage`、`Resource`/`ResourceTemplate`、`AskContext`/`ContextProvider`（每個請求注入）、`build_OAs、`build_OA `security=`和進程內`testing.connect`/`testing.serve`幫助器。當您希望其他 MCP 客戶呼叫您的代理商時使用。這是伺服器端 - 若要從代理程式（客戶端）使用外部 MCP 伺服器，請參閱「ag2-use-builtin-tools」（「MCPServerTool」）。
