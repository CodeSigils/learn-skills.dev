Управление многоагентной сетью AG2 — идентификаторы («Passport», «Resume»), «Правило» для каждого агента с двумя блоками верхнего уровня «доступ» («AccessBlock») и «лимиты» («LimitsBlock», который включает в себя «RateBlock» + «InboxBlock»), заменяемый шов доступа и маршрутизации «HubArbiter» / «RuleBasedArbiter», регистрация `AuthAdapter`/`AuthRegistry`,``Expectation`` на уровне канала с обработчиками нарушений`audit`/`notify_channel`/`auto_close`, журнал аудита концентратора, предназначенный только для добавления, и константы `AUDIT_KIND_*`, живая наблюдаемость `HubListener` / `BaseHubListener` плюс перехватчики `Hub` `on_*` и `register_sweeper`, а также наблюдение за задачей через `agent.task(...)` + `TaskMirror` (обновляется `Resume.observed` для ранжирования одноранговых объектов). Используйте, когда пользователю нужны ограничения скорости, политика доступа, соглашения об уровне обслуживания, отслеживание соответствия, оперативные метрики/оповещения, ранжирование одноранговых узлов на основе возможностей или для проверки того, что на самом деле произошло в сети. Загрузите это после `ag2-network-quickstart`. Информацию о поверхности на стороне агента (настраиваемые обработчики, представления, инструменты LLM, HumanClient) см. в `ag2-network-tools-and-views`.
