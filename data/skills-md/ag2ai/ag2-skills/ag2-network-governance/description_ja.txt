AG2 マルチエージェント ネットワークを管理します — ID (`Passport`、`Resume`)、2 つのトップレベル ブロックである `access` (`AccessBlock`) および `limits` (`RateBlock` + `InboxBlock` をネストする `LimitsBlock`) を含むエージェントごとの `Rule`、交換可能な `HubArbiter` / `RuleBasedArbiter`アクセスとルーティングのシーム、`AuthAdapter` / `AuthRegistry` 登録、`audit` / `notify_channel` / `auto_close` 違反ハンドラーによるチャネルレベルの `Expectation`、ハブの追加専用監査ログと `AUDIT_KIND_*` 定数、ライブ `HubListener` / `BaseHubListener` の可観測性と `Hub` `on_*` フックと `register_sweeter`、および `agent.task(...)` + `TaskMirror` によるタスク監視 (ピア ランキングの `Resume.observed` を更新します)。ユーザーがレート制限、アクセス ポリシー、SLA、コンプライアンス トレイル、ライブ メトリクス/アラート、機能主導のピア ランキングを必要とする場合、またはネットワーク上で実際に何が起こったかを検査する場合に使用します。これを「ag2-network-quickstart」の後にロードします。エージェント側のサーフェス (カスタム ハンドラー、ビュー、LLM ツール、`HumanClient`) については、「ag2-network-tools-and-views」を参照してください。
