Управляйте внешними агентами кодирования CLI (Claude Code, Codex, OpenCode) в качестве первоклассных агентов AG2 через клиентский протокол агента (ACP): укажите агенту предустановку ClaudeCodeConfig / CodexConfig / OpenCodeConfig из ag2.acp и используйте его, как любой другой агент, с его мышлением, вызовами инструментов, планами и запросами разрешений, вынесенными наружу в поток событий AG2. Используйте при оркестрации, наблюдении или шлюзовании агентов кодирования CLI из Python — разрешение_политики, запрос/автоматическое/запретить шлюзование HITL, ограничение fs_root, таймауты поворота, внутрипроцессное тестирование через fake_acp_config. Чтобы вместо этого предоставить агент AG2 другим системам, см. ag2-a2a или ag2-mcp; одобрение сантехнических работ см. в аг2-хитл.
