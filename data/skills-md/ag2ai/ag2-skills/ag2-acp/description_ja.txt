外部 CLI コーディング エージェント (Claude Code、Codex、OpenCode) をエージェント クライアント プロトコル (ACP) 経由でファーストクラスの AG2 エージェントとして駆動します。ag2.acp からプリセットされた ClaudeCodeConfig / CodexConfig / OpenCodeConfig でエージェントをポイントし、他のエージェントと同様に ask()/run() します。その思考、ツール呼び出し、計画、許可プロンプトは AG2 のイベント ストリームに外部化されます。 Python から CLI コーディング エージェントをオーケストレーション、監視、またはゲートするときに使用します。permission_policy ask/auto/deny HITL ゲート、fs_root 制限、ターン タイムアウト、fake_acp_config によるインプロセス テストです。代わりに AG2 エージェントを他のシステムに公開するには、ag2-a2a または ag2-mcp を参照してください。承認配管については、ag2-hitl を参照してください。
