Pilotez des agents de codage CLI externes (Claude Code, Codex, OpenCode) en tant qu'agents AG2 de première classe via le protocole client agent (ACP) : pointez un agent vers un préréglage ClaudeCodeConfig / CodexConfig / OpenCodeConfig à partir d'ag2.acp et demandez-lui()/run() comme n'importe quel agent, avec sa réflexion, ses appels d'outils, ses plans et ses invites d'autorisation externalisés sur le flux d'événements d'AG2. À utiliser lors de l'orchestration, de l'observation ou du contrôle des agents de codage CLI à partir de Python : autorisation_policy request/auto/deny HITL gating, confinement fs_root, délais d'attente, tests en cours via fake_acp_config. Pour exposer un agent AG2 à d'autres systèmes, consultez ag2-a2a ou ag2-mcp ; pour l'approbation de la plomberie, voir ag2-hitl.
