Steuern Sie externe CLI-Coding-Agenten (Claude Code, Codex, OpenCode) als erstklassige AG2-Agenten über das Agent Client Protocol (ACP): Richten Sie einen Agenten auf eine ClaudeCodeConfig-/CodexConfig-/OpenCodeConfig-Voreinstellung aus ag2.acp und ask()/run() ihn wie jeden anderen Agenten, wobei sein Denken, Toolaufrufe, Pläne und Berechtigungsaufforderungen in den Ereignisstrom von AG2 externalisiert werden. Wird zum Orchestrieren, Beobachten oder Gating von CLI-Coding-Agents aus Python verwendet – Permission_policy ask/auto/deny HITL-Gating, fs_root-Beschränkung, Turn-Timeouts, In-Process-Tests über fake_acp_config. Um stattdessen einen AG2-Agenten anderen Systemen zugänglich zu machen, siehe ag2-a2a oder ag2-mcp; Für die Zulassung von Sanitärinstallationen siehe ag2-hitl.
