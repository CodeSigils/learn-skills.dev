在 Agent Client Protocol（ACP）上将外部 CLI 编码代理（Claude Code、Codex、OpenCode）作为一等的 AG2 代理来驱动：将代理指向 ag2.acp 中的 ClaudeCodeConfig / CodexConfig / OpenCodeConfig 预设，然后像使用任何代理一样调用 ask() / run()，其思考过程、工具调用、计划以及权限提示都会外部化到 AG2 的事件流中。当从 Python 编排、观察或对 CLI 编码代理进行门控时使用——permission_policy 的 ask / auto / deny HITL 门控、fs_root 隔离、回合超时、通过 fake_acp_config 进行进程内测试。若要将 AG2 代理暴露给其他系统，请参阅 ag2‑a2a 或 ag2‑mcp；批准流水线请参阅 ag2‑hitl。
