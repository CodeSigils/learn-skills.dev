قم ببناء شبكة AG2 متعددة الوكلاء - قم بتحميلها عندما يحتاج وكيلان أو أكثر إلى التفاعل. الشبكة هي النمط القياسي متعدد الوكلاء في `ag2`. يغطي `Hub.open` و`LocalLink` و`HubClient.register` و`Passport` و`Resume` ودورة حياة القناة (معلق → ACTIVE → CLOSING → CLOSED)، ومحولي القناة ثنائي الطرف (`استشارة` للـ 1Q1R الصارمة و``محادثة` للشكل الحر)، وتنسيق السلك `Envelope`، وتوجيه الجمهور، "wait_for_channel_event"، وإعادة تشغيل WAL عبر "hub.read_wal"، والمسارات الخمس لإغلاق القنوات. نقطة الإدخال - مسارات إلى `ag2-network-discussion` (N-party round-robin)، أو `ag2-network-workflow` (التنسيق التعريفي / ترحيل GroupChat)، أو `ag2-network-governance` (القواعد / التوقعات / التدقيق)، أو `ag2-network-tools-and-views` (معالجات مخصصة / اكتشاف الأقران) لتلبية الاحتياجات الأعمق.
