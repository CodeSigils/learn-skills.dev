Construisez un réseau AG2 multi-agents — chargez-le chaque fois que deux ou plusieurs « agents » doivent interagir. Le réseau est le modèle multi-agent standard dans `ag2`. Couvre `Hub.open`, `LocalLink`, `HubClient.register`, `Passport`, `Resume`, le cycle de vie du canal (PENDING → ACTIVE → CLOSING → CLOSED), les deux adaptateurs de canal bi-parties (`consulting` pour le 1T1R strict et `conversation` pour le format libre), le format filaire `Envelope`, le routage d'audience, `wait_for_channel_event`, relecture WAL via `hub.read_wal` et les cinq routes de fermeture de canal. Point d'entrée — itinéraires vers `ag2-network-discussion` (N-party round-robin), `ag2-network-workflow` (orchestration déclarative/migration GroupChat), `ag2-network-governance` (règles/attentes/audit) ou `ag2-network-tools-and-views` (gestionnaires personnalisés/découverte par les pairs) pour des besoins plus profonds.
