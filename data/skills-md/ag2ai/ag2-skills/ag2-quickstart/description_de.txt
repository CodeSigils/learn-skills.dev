Erstellen Sie einen minimalen AG2 `Agent` Ende-zu-Ende — wählen Sie einen Modellanbieter, setzen Sie eine Eingabeaufforderung, rufen Sie `agent.ask ()` an und setzen Sie dann das Gespräch mit `reply.ask()` (multi-turn) fort. Wird verwendet, wenn der Benutzer ein neues AG2-Projekt startet, noch keinen funktionierenden "Agenten" hat oder das Multi-Turn-Kettenmuster benötigt. Umfasst `OpenAIConfig`, `AnthropicConfig`, 'GeminiConfig`,` OllamaConfig` usw. und env-var Fallback für API-Schlüssel.
