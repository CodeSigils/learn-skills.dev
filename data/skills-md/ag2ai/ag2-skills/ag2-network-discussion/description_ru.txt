Откройте «дискуссионный» канал сети AG2 — циклический алгоритм N-party (2+), где каждый участник говорит в фиксированном порядке, циклически повторяя до явного закрытия или TTL. Используйте, когда пользователь хочет провести мозговой штурм с фиксированным составом участников, групповую дискуссию или круговой обзор рецензентов. Охватывает `agent_client.open(type="discussion", target=[...], buttons={"ordering": ORDERING_ROUND_ROBIN})`, вращение `expected_next_speaker`, шаблон проверки `hc.can_send(...)` (обработчики по умолчанию пропускают вызовы LLM, когда не их очередь), `DiscussionState`, ожидания `turn_within` по умолчанию («предупреждать» на 120 с / «скрыть» на 600 с), размер окна просмотра для N участников и четыре шаблона закрытия, которые работают с этим адаптером. Загрузите это после `ag2-network-quickstart`. Для условной передачи обслуживания или декларативной оркестровки см. `ag2-network-workflow`.
