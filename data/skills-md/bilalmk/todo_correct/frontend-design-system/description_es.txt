Habilidad integral de diseño UI/UX para crear aplicaciones web modernas y responsivas con Tailwind CSS, shadcn/ui, Material UI, Chakra UI, Ant Design y Mantine. Úselo cuando los usuarios necesiten: (1) elegir un sistema de diseño para su proyecto, (2) crear diseños y componentes responsivos, (3) implementar formularios con validación, (4) crear interfaces de usuario accesibles, (5) diseñar interfaces de usuario de administración de tareas (aplicaciones de tareas pendientes, paneles), (6) aplicar patrones de diseño responsivo, (7) implementar el modo oscuro o (8) crear bibliotecas de componentes. Los activadores incluyen solicitudes como "diseñar una aplicación de tareas pendientes", "crear un diseño responsivo", "qué biblioteca de interfaz de usuario debo usar", "implementar el modo oscuro", "crear un formulario con validación" o "hacer que esto sea compatible con dispositivos móviles".
