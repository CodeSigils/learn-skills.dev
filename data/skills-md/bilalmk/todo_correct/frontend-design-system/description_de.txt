Umfassende UI/UX-Designfähigkeiten zum Erstellen moderner, reaktionsfähiger Webanwendungen mit Tailwind CSS, shadcn/ui, Material UI, Chakra UI, Ant Design und Mantine. Verwenden Sie diese Option, wenn Benutzer: (1) ein Designsystem für ihr Projekt auswählen, (2) responsive Layouts und Komponenten erstellen, (3) Formulare mit Validierung implementieren, (4) barrierefreie Benutzeroberflächen erstellen, (5) Benutzeroberflächen für die Aufgabenverwaltung entwerfen (Todo-Apps, Dashboards), (6) responsive Designmuster anwenden, (7) den Dunkelmodus implementieren oder (8) Komponentenbibliotheken erstellen müssen. Zu den Auslösern gehören Anfragen wie „Entwerfen Sie eine Aufgaben-App“, „Erstellen Sie ein responsives Layout“, „Welche UI-Bibliothek soll ich verwenden“, „Implementieren Sie den Dunkelmodus“, „Erstellen Sie ein Formular mit Validierung“ oder „Machen Sie dies für Mobilgeräte geeignet“.
