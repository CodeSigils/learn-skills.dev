Tailwind CSS、shadcn/ui、マテリアル UI、Chakra UI、Ant Design、Mantine を使用して最新の応答性の高い Web アプリケーションを構築するための包括的な UI/UX デザイン スキル。ユーザーが必要な場合に使用します - (1) プロジェクトのデザイン システムを選択する、(2) レスポンシブなレイアウトとコンポーネントを構築する、(3) 検証付きのフォームを実装する、(4) アクセシブルなユーザー インターフェイスを作成する、(5) タスク管理 UI (ToDo アプリ、ダッシュボード) をデザインする、(6) レスポンシブ デザイン パターンを適用する、(7) ダーク モードを実装する、または (8) コンポーネント ライブラリを構築する。トリガーには、「ToDo アプリをデザインする」、「レスポンシブ レイアウトを作成する」、「どの UI ライブラリを使用する必要があるか」、「ダーク モードを実装する」、「検証付きのフォームを構築する」、または「これをモバイル フレンドリーにする」などのリクエストが含まれます。
