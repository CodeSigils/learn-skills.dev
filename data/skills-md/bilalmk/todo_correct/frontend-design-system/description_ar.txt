مهارة تصميم واجهة المستخدم/تجربة المستخدم الشاملة لبناء تطبيقات ويب حديثة وسريعة الاستجابة باستخدام Tailwind CSS وshadcn/ui وMaterial UI وChakra UI وAnt Design وMantine. يُستخدم عندما يحتاج المستخدمون إلى - (1) اختيار نظام تصميم لمشروعهم، (2) إنشاء تخطيطات ومكونات سريعة الاستجابة، (3) تنفيذ النماذج مع التحقق من الصحة، (4) إنشاء واجهات مستخدم يمكن الوصول إليها، (5) تصميم واجهات مستخدم لإدارة المهام (تطبيقات المهام ولوحات المعلومات)، (6) تطبيق أنماط تصميم سريعة الاستجابة، (7) تنفيذ الوضع المظلم، أو (8) إنشاء مكتبات المكونات. تتضمن المشغلات طلبات مثل "تصميم تطبيق المهام"، أو "إنشاء تخطيط سريع الاستجابة"، أو "أي مكتبة واجهة مستخدم يجب أن أستخدمها"، أو "تنفيذ الوضع المظلم"، أو "إنشاء نموذج مع التحقق من الصحة"، أو "جعل هذا مناسبًا للجوال".
