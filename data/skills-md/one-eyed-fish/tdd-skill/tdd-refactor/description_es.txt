Flujo de trabajo TDD puro para desarrollo de funciones totalmente nuevas, corrección de errores, refactores que preservan el comportamiento, pruebas de caracterización y trabajo de caracterizar y luego corregir. Úselo cuando Codex necesite una disciplina de prueba primero para crear un nuevo comportamiento desde cero o cambiar el código existente sin desviar el comportamiento. Se aplica en todos los lenguajes y arquitecturas. No lo utilice para reglas de capas específicas de tecnología, ediciones solo de documentación, cambios triviales solo de formato o prototipos puramente exploratorios donde no se espera ningún comportamiento ejecutable.
