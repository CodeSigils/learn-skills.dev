Рабочий процесс на чистом TDD для разработки функций с нуля, исправления ошибок, рефакторинга, сохраняющего поведение, тестирования характеристик и работы по определению характеристик и исправлению. Используйте его, когда Кодексу требуется дисциплина «сначала тестирование», чтобы создать новое поведение с нуля или изменить существующий код без изменения поведения. Применяется ко всем языкам и архитектурам. Не используйте для правил наложения, специфичных для технологии, редактирования только документации, тривиальных изменений только форматирования или чисто исследовательских прототипов, где не ожидается никакого исполняемого поведения.
