Garde-corps Spring Web pour les refactors Java/Spring Boot. À utiliser lorsque Codex modifie les contrôleurs, les points de terminaison REST, le mappage requête/réponse, la validation, la sécurité, le téléchargement/téléchargement de fichiers, les exportations ou la superposition de services/contrôleurs dans les applications Spring. Il s'agit d'un compagnon facultatif d'architecture et de pile technologique pour les compétences TDD ; ne pas utiliser comme compétence générique de méthodologie TDD.
