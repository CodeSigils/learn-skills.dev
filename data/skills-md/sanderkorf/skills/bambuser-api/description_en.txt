Bambuser Live Shopping REST API — shows, products, highlights, webhooks, stats, users, tags, channels. Server-side only. Auth is Authorization: Token (not Bearer). Use when calling liveshopping-api, BamHub API keys/scopes, show webhooks, or syncing Bambuser shows into a CMS. Distinct from bambuser-live (embed/player cart bridge) and product catalog feeds used for BamHub ingest.
