Bambuser Live Shopping REST API – Shows, Produkte, Highlights, Webhooks, Statistiken, Benutzer, Tags, Kanäle. Nur serverseitig. Auth ist Autorisierung: Token (nicht Bearer). Wird verwendet, wenn Sie liveshopping-api, BamHub-API-Schlüssel/-Bereiche aufrufen, Webhooks anzeigen oder Bambuser-Shows mit einem CMS synchronisieren. Unterscheidet sich von bambuser-live (Einbettung/Player-Cart-Bridge) und Produktkatalog-Feeds, die für die BamHub-Aufnahme verwendet werden.
