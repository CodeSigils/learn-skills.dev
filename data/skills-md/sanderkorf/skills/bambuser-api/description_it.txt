API REST di Bambuser Live Shopping: spettacoli, prodotti, highlights, webhook, statistiche, utenti, tag, canali. Solo lato server. L'autenticazione è l'autorizzazione: token (non portatore). Da utilizzare quando si chiama liveshopping-api, chiavi/ambiti API BamHub, si mostrano webhook o si sincronizzano spettacoli Bambuser in un CMS. Distinto da bambuser-live (bridge carrello incorporato/giocatore) e dai feed del catalogo prodotti utilizzati per l'acquisizione di BamHub.
