REST API Bambuser Live Shopping — шоу, продукты, основные моменты, веб-перехватчики, статистика, пользователи, теги, каналы. Только на стороне сервера. Аутентификация — это авторизация: токен (не носитель). Используйте при вызове liveshopping-api, ключей/областей API BamHub, показа веб-перехватчиков или синхронизации показов Bambuser с CMS. В отличие от bambuser-live (мост для встраивания/корзины игрока) и каналов каталога продуктов, используемых для загрузки BamHub.
