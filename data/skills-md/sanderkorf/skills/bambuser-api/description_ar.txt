Bambuser Live Shopping REST API - العروض والمنتجات والميزات وخطافات الويب والإحصائيات والمستخدمين والعلامات والقنوات. Server-side only. المصادقة هي التفويض: الرمز المميز (وليس حامله). يُستخدم عند الاتصال بـliveshopping-api، أو مفاتيح/نطاقات BamHub API، أو إظهار خطافات الويب، أو مزامنة عروض Bambuser في نظام إدارة المحتوى (CMS). يختلف عن bambuser-live (جسر التضمين/عربة المشغل) وخلاصات كتالوج المنتجات المستخدمة لاستيعاب BamHub.
