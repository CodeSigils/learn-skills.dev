API REST de Bambuser Live Shopping: programas, productos, aspectos destacados, webhooks, estadísticas, usuarios, etiquetas, canales. Sólo del lado del servidor. La autenticación es autorización: token (no portador). Úselo al llamar a liveshopping-api, claves/ámbitos de API de BamHub, mostrar webhooks o sincronizar programas de Bambuser en un CMS. Distinto de bambuser-live (puente de carrito de inserción/reproductor) y feeds de catálogo de productos utilizados para la ingesta de BamHub.
