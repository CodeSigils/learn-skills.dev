Genera animazioni HTML/CSS autonome delle funzionalità dell'app per procedure dettagliate, demo e onboarding. Ricerca l'app di destinazione tramite Chrome, intervista l'utente, genera un brief strutturato e un file HTML di animazione, quindi entra in un ciclo iterativo di revisione di blocco-ispezione-feedback finché l'utente non approva. Da utilizzare quando l'utente dice "animazione CSS", "anima questa funzionalità", "crea una procedura dettagliata CSS", "procedura dettagliata dell'animazione" o desidera creare una demo visiva basata su CSS di una funzionalità dell'app.
