Создает автономную HTML/CSS-анимацию функций приложения для пошаговых руководств, демонстраций и ознакомления. Исследует целевое приложение через Chrome, опрашивает пользователя, генерирует структурированное краткое описание и анимационный HTML-файл, затем вводит итеративный цикл проверки «заморозка-проверка-обратная связь» до тех пор, пока пользователь не одобрит. Используйте, когда пользователь говорит «анимация CSS», «анимировать эту функцию», «создать пошаговое руководство CSS», «пошаговое руководство по анимации» или хочет создать визуальную демонстрацию функции приложения на основе CSS.
