Génère des animations HTML/CSS autonomes des fonctionnalités de l'application pour les procédures pas à pas, les démos et l'intégration. Recherche l'application cible via Chrome, interroge l'utilisateur, génère un fichier HTML de présentation et d'animation structuré, puis entre dans une boucle itérative de gel-inspection-révision des commentaires jusqu'à ce que l'utilisateur approuve. À utiliser lorsque l'utilisateur dit « animation CSS », « animer cette fonctionnalité », « créer une procédure pas à pas CSS », « procédure pas à pas d'animation » ou souhaite créer une démo visuelle basée sur CSS d'une fonctionnalité d'application.
