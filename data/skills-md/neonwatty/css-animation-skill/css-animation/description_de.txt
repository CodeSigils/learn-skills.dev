Erzeugt eigenständige HTML/CSS-Animationen von App-Funktionen für Komplettlösungen, Demos und Onboarding. Recherchiert die Ziel-App über Chrome, interviewt den Benutzer, generiert eine strukturierte Kurz- und Animations-HTML-Datei und führt dann eine iterative Überprüfungsschleife aus Einfrieren, Prüfen und Feedback durch, bis der Benutzer zustimmt. Verwenden Sie diese Option, wenn der Benutzer „CSS-Animation“, „Diese Funktion animieren“, „CSS-Komplettlösung erstellen“, „Animations-Komplettlösung“ sagt oder eine CSS-basierte visuelle Demo einer App-Funktion erstellen möchte.
