يُنشئ رسومًا متحركة بتنسيق HTML/CSS لميزات التطبيق من أجل الإرشادات التفصيلية والعروض التوضيحية والإعداد. يبحث في التطبيق المستهدف عبر Chrome، ويجري مقابلة مع المستخدم، وينشئ ملف HTML مختصرًا ومتحركًا، ثم يدخل في حلقة مراجعة متكررة للتجميد والفحص والتعليقات حتى موافقة المستخدم. يُستخدم عندما يقول المستخدم "رسوم متحركة css"، أو "تحريك هذه الميزة"، أو "إنشاء دليل تفصيلي لـ css"، أو "شرح تفصيلي للرسوم المتحركة"، أو يريد إنشاء عرض توضيحي مرئي يستند إلى CSS لميزة تطبيق.
