Audite les SaaS et les applications Web basées sur l'utilisation pour détecter les modèles d'utilisation contradictoires : accidentels, opportunistes et délibérés. Utilisez-le lorsque l'utilisateur dit «audit contradictoire», «audit de cas d'abus», «protéger cette application contre les idiots», «trouver des exploits d'utilisation», «audit de logique métier» ou «comment les utilisateurs pourraient-ils casser cela». Explorez la base de code pour cartographier la surface économique (niveaux de tarification, limites d'utilisation, essais gratuits, ressources coûteuses), puis génère des cas d'abus dans lesquels le comportement de l'utilisateur – intentionnel ou non – pourrait briser les hypothèses, contourner les limites, amplifier les coûts ou corrompre l'État. Produit un rapport de démarque hiérarchisé avec les résultats, les emplacements de code et les recommandations de correctifs, puis vérifie éventuellement les résultats de manière interactive dans un navigateur.
