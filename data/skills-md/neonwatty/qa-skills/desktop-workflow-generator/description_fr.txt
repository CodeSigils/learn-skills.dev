Génère une documentation sur le flux de travail du navigateur de bureau en explorant la base de code de l'application, puis en parcourant l'application en direct avec l'utilisateur étape par étape via Playwright pour co-écrire les vérifications. À utiliser lorsque l'utilisateur dit « générer des workflows de bureau », « créer des workflows de bureau », « mettre à jour les workflows de bureau » ou « générer des workflows de navigateur ».
