Создает документацию по рабочему процессу мобильного браузера, исследуя кодовую базу приложения, а затем шаг за шагом просматривая действующее приложение вместе с пользователем через Playwright в области просмотра мобильного устройства (393x852) для совместного редактирования проверок. Используйте, когда пользователь говорит «создать рабочие процессы для мобильных устройств», «создать рабочие процессы для мобильных устройств», «обновить рабочие процессы для мобильных устройств» или «создать рабочие процессы для мобильных браузеров». Создает пронумерованные файлы уценки рабочего процесса, которые передаются в мобильный конвертер и программу Playwright Runner. Включает в себя HIG-распознавание iOS и обнаружение анти-шаблонов мобильного UX.
