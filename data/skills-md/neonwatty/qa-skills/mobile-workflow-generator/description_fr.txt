Génère une documentation sur le flux de travail du navigateur mobile en explorant la base de code de l'application, puis en parcourant l'application en direct avec l'utilisateur étape par étape via Playwright dans une fenêtre d'affichage mobile (393 x 852) pour co-rédiger les vérifications. À utiliser lorsque l'utilisateur dit « générer des workflows mobiles », « créer des workflows mobiles », « mettre à jour les workflows mobiles » ou « générer des workflows de navigateur mobile ». Produit des fichiers de démarques de flux de travail numérotés qui alimentent le convertisseur mobile et le programme d'exécution Playwright. Inclut la sensibilisation iOS HIG et la détection anti-modèle UX mobile.
