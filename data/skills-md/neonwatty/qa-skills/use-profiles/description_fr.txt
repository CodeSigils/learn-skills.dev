Chargez les profils d’authentification Playwright StorageState enregistrés avant l’automatisation du navigateur. S'active lorsque `.playwright/profiles.json` existe et que le travail du navigateur commence sur les pages authentifiées. Les expressions de déclenchement incluent « utiliser le profil », « charger le profil », « navigateur en tant que [rôle] », « navigateur authentifié », « session de navigateur connectée ».
