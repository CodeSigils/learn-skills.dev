Создает документацию по многопользовательскому рабочему процессу, опрашивая пользователя о персонажах, исследуя кодовую базу для многопользовательских шаблонов, а затем проходя по действующему приложению с помощью индивидуальных сеансов Playwright CLI для совместного создания чередующихся рабочих процессов с тегами персонажей. Используйте, когда пользователь говорит «создать многопользовательские рабочие процессы», «создать многопользовательские рабочие процессы» или «создать параллельные пользовательские рабочие процессы». Создает уценку рабочего процесса с персональными тегами, которая передается в многопользовательский конвертер и средство запуска Playwright.
