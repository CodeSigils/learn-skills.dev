Полный рабочий процесс по стратегии бренда для агентств и консультантов по бренду. Выступает в роли старшего специалиста по стратегии бренда — собирает информацию о клиентах с помощью структурированной анкеты, а затем составляет полный, отточенный отчет о стратегии бренда. Используйте этот навык всякий раз, когда пользователь говорит: «Стратегия бренда», «Создать отчет о бренде», «Разработать стратегию бренда для моего клиента», «Анкета бренда», «У меня новый клиент по брендингу», «Помогите мне разработать стратегию бренда», «Стратегия бренда», «Написать документ о стратегии бренда» или делится кратким описанием клиента и хочет получить результаты стратегии. Также срабатывает, когда пользователь загружает или вставляет заполненную анкету бренда и просит превратить ее в отчет. Всегда используйте этот навык для решения любой задачи по стратегии бренда — даже при случайных упоминаниях типа «Мне нужно разработать стратегию для этого бренда» или «клиент заполнил форму, сделайте отчет».
