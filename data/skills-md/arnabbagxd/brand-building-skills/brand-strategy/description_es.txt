Flujo de trabajo completo de estrategia de marca para agencias y consultores de marca. Actúa como estratega de marca senior: recopila información del cliente a través de un cuestionario estructurado y luego genera un informe de estrategia de marca completo y pulido. Utilice esta habilidad cada vez que un usuario diga "estrategia de marca", "crear un informe de marca", "crear una estrategia de marca para mi cliente", "cuestionario de marca", "Tengo un nuevo cliente de marca", "ayúdame a hacer una estrategia de marca", "estrategia de identidad de marca", "escribir un documento de estrategia de marca" o comparte un resumen de un cliente y quiere un resultado de la estrategia. También se activa cuando un usuario carga o pega un cuestionario de marca completo y solicita convertirlo en un informe. Utilice siempre esta habilidad para cualquier tarea de estrategia de marca, incluso menciones casuales como "Necesito hacer una estrategia para esta marca" o "el cliente completó el formulario, haga el informe".
