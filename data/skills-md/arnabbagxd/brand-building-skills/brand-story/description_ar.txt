قم بصياغة قصة أصل العلامة التجارية، وسرد المؤسس، وبيان "لماذا نحن موجودون". يُستخدم عندما يقول المستخدم "قصة العلامة التجارية"، أو "قصة الأصل"، أو "قصة المؤسس"، أو "لماذا نحن موجودون"، أو "نبذة عنا"، أو "قصتنا"، أو "سرد الشركة"، أو "سرد العلامة التجارية"، أو "اكتب صفحتنا حول"، أو "أخبر قصتنا"، أو "قصة التأسيس"، أو "تاريخ العلامة التجارية"، أو عندما يريد توضيح الهدف الأعمق والقصة الإنسانية وراء العلامة التجارية. استخدمه أيضًا عندما تبدو صفحة "نبذة عنا" عامة أو مؤسسية وتحتاج إلى إعادة كتابتها.
