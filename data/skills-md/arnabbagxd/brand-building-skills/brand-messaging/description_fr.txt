Créez la hiérarchie des messages d'une marque : slogans, propositions de valeur, messages clés et arguments pour chaque public. À utiliser lorsque l'utilisateur dit « message de marque », « cadre de messagerie », « proposition de valeur », « slogan », « slogan de marque », « messages clés », « hiérarchie de messagerie », « que devrions-nous dire de notre marque », « fondement de la copie de marque », « architecture de messagerie », « argumentaire d'ascenseur », « one-liner », « déclaration de marque » ou a besoin d'un langage cohérent dans toutes les communications. À utiliser également lorsque la messagerie semble incohérente entre les canaux ou les équipes.
