Faites fonctionner des hôtes VPS Linux distants via la CLI vpsctl, y compris l'inventaire des hôtes SSH, les profils de déploiement de projet, les commandes, les transferts, les tunnels, les hôtes de saut, les clés, le contexte local, les instantanés et les modifications enregistrées. Utilisation pour les tâches d'administration ou de déploiement de VPS à distance ; ne pas utiliser pour un travail uniquement localhost.
