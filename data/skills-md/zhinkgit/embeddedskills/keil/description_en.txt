Keil MDK project build tool for scanning .uvprojx/.uvmpw projects, enumerating Targets, executing build/rebuild/clean and parsing build logs, returning artifact paths reusable by jlink/openocd. The flash subcommand is only retained as a compatibility entry. Automatically triggered when users mention Keil, MDK, uVision, UV4, Target enumeration, compile, rebuild, clean, flash, download firmware, or flash, also compatible with explicit /keil invocation. Even if the user simply says "compile it" or "flash to the board", this skill should be triggered as long as the context involves an embedded Keil project.
