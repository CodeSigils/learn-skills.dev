Eine dünne Orchestrierungsschicht für eingebettete Fähigkeiten, die zum Erkennen von Projekten im aktuellen Arbeitsbereich, zum Auswählen von Build-/Flash-/Debug-/Beobachtungs-Backends, zur Verkettung von .embeddedskills/state.json und zum Aggregieren von Ergebnissen aus zugrunde liegenden Fähigkeiten verwendet wird. Wird ausgelöst, wenn Benutzer „One-Click Build and Flash“, „Auto Diagnostic“, „String Together Build -> Flash -> Debug -> Observe“ erwähnen oder /workflow explizit aufrufen.
