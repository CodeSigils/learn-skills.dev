Herramienta de creación de proyectos integrados de GCC (CMake + arm-none-eabi-gcc) para escanear proyectos integrados basados ​​en CMake, enumerar ajustes preestablecidos, configurar, construir, reconstruir, limpiar y analizar el tamaño de ELF. Se activa automáticamente cuando el usuario menciona GCC, arm-none-eabi, compilación integrada de CMake, compilación Ninja, análisis de tamaño ELF, arm-gcc, compilación cruzada, cmake --build, cmake --preset y también admite la invocación explícita a través de /gcc. Incluso si el usuario simplemente dice "compílelo" o "verifique qué tan grande es el firmware", siempre que el contexto involucre un proyecto GCC integrado de CMake, esta habilidad debe activarse.
