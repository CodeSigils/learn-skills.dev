GCC embedded project build tool (CMake + arm-none-eabi-gcc) for scanning CMake-based embedded projects, listing presets, configuring, building, rebuilding, cleaning, and analyzing ELF size. Automatically triggered when the user mentions GCC, arm-none-eabi, CMake embedded compilation, Ninja build, ELF size analysis, arm-gcc, cross-compilation, cmake --build, cmake --preset, and also supports explicit invocation via /gcc. Even if the user simply says "compile it" or "check how big the firmware is," as long as the context involves a CMake embedded GCC project, this skill should be activated.
