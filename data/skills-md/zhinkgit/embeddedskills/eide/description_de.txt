EIDE-Projekt-Build-Tool (Embedded IDE), das zum Scannen des .eide/eide.yml-Projekts, zum Aufzählen von Build-Konfigurationen (ConfigName), zum Ausführen von Build/Rebuild/Clean und zum Analysieren von Build-Protokollen sowie zum Zurückgeben von Artefaktpfaden verwendet wird, die von jlink/openocd wiederverwendet werden können. Es wird automatisch ausgelöst, wenn der Benutzer EIDE, Embedded IDE, eide.yml, unify_builder, VS Code EIDE-Erweiterung, Cl.eide erwähnt, und unterstützt auch explizite /eide-Aufrufe. Selbst wenn der Benutzer nur „Mit EIDE kompilieren“ oder „EIDE-Flash auf die Platine“ sagt, sollte diese Fähigkeit ausgelöst werden, sofern der Kontext ein in EIDE eingebettetes Projekt betrifft.
