أداة إنشاء مشروع EIDE (IDE المضمنة)، تُستخدم لفحص مشاريع .eide/eide.yml، وتعداد تكوينات البناء (ConfigName)، وتنفيذ سجلات البناء/إعادة البناء/التنظيف والتحليل، وإرجاع المسارات الاصطناعية التي يمكن إعادة استخدامها بواسطة jlink/openocd. يتم تشغيله تلقائيًا عندما يذكر المستخدم EIDE، أو Embedded IDE، أو eide.yml، أو unify_builder، أو ملحق VS Code EIDE، أو Cl.eide، ويدعم أيضًا مكالمات /eide الصريحة. حتى لو قال المستخدم فقط "ترجمة باستخدام EIDE" أو "وميض EIDE على اللوحة"، طالما أن السياق يتضمن مشروعًا مضمنًا لـ EIDE، فيجب تفعيل هذه المهارة.
