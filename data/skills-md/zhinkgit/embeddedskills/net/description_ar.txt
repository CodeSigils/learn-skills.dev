أداة تصحيح أخطاء الشبكة المضمنة لاكتشاف الواجهات والتقاط الحزم وتحليل pcap/pcapng واختبار الاتصال ومسح المنافذ وإحصائيات حركة المرور. يتم تشغيله تلقائيًا عندما يذكر المستخدمون Wireshark، أو tshark، أو Npcap، أو التقاط الحزم، أو تصحيح أخطاء الشبكة المشتركة، أو فحص المنافذ، أو استكشاف أخطاء الاتصال وإصلاحها، أو تحليل pcap، أو واجهات الشبكة، أو اختبارات ping، أو التتبع، أو إحصائيات حركة المرور، أو Modbus TCP، أو EtherNet/IP، أو موضوعات تصحيح أخطاء بروتوكول الشبكة الأخرى؛ يدعم أيضًا الاستدعاء الصريح /net. حتى لو قال المستخدم ببساطة "التقاط حزمة"، أو "مسح المنافذ"، أو "هل يمكن الوصول إلى الشبكة"، أو "تحليل pcap"، يتم تنشيط المهارة عندما يتعلق الأمر بتصحيح أخطاء اتصالات الشبكة.
