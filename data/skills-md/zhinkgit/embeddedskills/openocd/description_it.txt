Strumento di download e debug OpenOCD, utilizzato per rilevamento sonda, aggiornamento firmware, cancellazione flash, avvio server GDB, controllo ripristino target, debug online Telnet (arresto/ripresa/passaggio/registri/memoria/punti di interruzione), debug GDB a livello di origine, nonché acquisizione di output Semihosting/ITM e query di basso livello. Si attiva automaticamente quando gli utenti menzionano OpenOCD, ST-Link, CMSIS-DAP, DAPLink, FTDI, firmware flash, cancellazione Flash, server GDB, ripristino, configurazione interfaccia/destinazione/scheda, openocd.cfg, debug online, passaggio singolo, punti di interruzione, visualizzazione registro, lettura/scrittura memoria, semihosting e compatibile anche con l'invocazione esplicita di /openocd. Anche se gli utenti dicono semplicemente "flash it", "avvia GDB Server", "cancella chip", "controlla registri", "step debug" o "cattura semihosting", questa abilità dovrebbe essere attivata purché il contesto coinvolga debugger open source supportati da OpenOCD.
