Strumento di download e debug OpenOCD per rilevamento sonda, aggiornamento firmware, cancellazione flash, avvio server GDB, controllo ripristino target, debug online Telnet (arresto/ripresa/passaggio/registri/memoria/punti di interruzione), debug GDB a livello di origine e acquisizione di output Semihosting/ITM e query di basso livello. Si attiva automaticamente quando gli utenti menzionano OpenOCD, ST-Link, CMSIS-DAP, DAPLink, FTDI, flashing del firmware, cancellazione Flash, server GDB, ripristino, configurazione interfaccia/destinazione/scheda, openocd.cfg, debug online, passaggio singolo, punti di interruzione, visualizzazione registro, lettura/scrittura memoria, semihosting e compatibile anche con l'invocazione esplicita di /openocd. Anche se l'utente dice semplicemente "flash it", "avvia GDB Server", "cancella chip", "controlla i registri", "step debug" o "cattura semihosting", questa abilità dovrebbe attivarsi ogni volta che il contesto coinvolge un debugger open source supportato da OpenOCD.
