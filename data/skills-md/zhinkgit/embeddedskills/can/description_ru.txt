Встроенный инструмент отладки CAN/CAN-FD для сканирования интерфейса, мониторинга сообщений, передачи тестовых кадров, ведения журнала, декодирования файлов базы данных и статистики шины. Автоматически срабатывает, когда пользователи упоминают CAN, CAN-FD, декодирование DBC, захват пакетов шины, совместную отладку USB-CAN, передачу сообщений, статистику шины, PCAN, Vector, slcan, сканирование интерфейса CAN, фильтрацию CAN ID, журналы ASC, файлы BLF, также совместимо с явным вызовом /can. Даже если пользователи просто говорят «проверить сообщения CAN», «отправить кадр для попытки» или «декодировать этот DBC», при условии, что контекст включает связь по шине CAN, этот навык должен сработать.
