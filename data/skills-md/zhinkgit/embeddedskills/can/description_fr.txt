Outil de débogage CAN/CAN-FD intégré pour l'analyse d'interface, la surveillance des messages, la transmission de trames de test, l'enregistrement de journaux, le décodage de fichiers de base de données et les statistiques de bus. Déclenché automatiquement lorsque les utilisateurs mentionnent CAN, CAN-FD, décodage DBC, capture de bus, débogage conjoint USB-CAN, transmission de messages, statistiques de bus, PCAN, Vector, slcan, analyse d'interface CAN, filtrage d'identification CAN, journal ASC, fichier BLF ou invocation explicite de /can. Même si l'utilisateur dit simplement « vérifier les messages CAN », « envoyer une trame » ou « décoder le DBC », tant que le contexte implique une communication sur le bus CAN, cette compétence doit être déclenchée.
