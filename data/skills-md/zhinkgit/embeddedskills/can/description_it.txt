Strumento di debug CAN/CAN-FD integrato per la scansione dell'interfaccia, il monitoraggio dei messaggi, la trasmissione dei frame di test, la registrazione dei registri, la decodifica dei file di database e le statistiche del bus. Si attiva automaticamente quando gli utenti menzionano CAN, CAN-FD, decodifica DBC, acquisizione bus, debug congiunto USB-CAN, trasmissione di messaggi, statistiche bus, PCAN, Vector, slcan, scansione interfaccia CAN, filtraggio ID CAN, registro ASC, file BLF o invocano esplicitamente /can. Anche se l'utente dice semplicemente "controlla i messaggi CAN", "invia un frame" o "decodifica DBC", purché il contesto coinvolga la comunicazione del bus CAN, questa abilità dovrebbe essere attivata.
