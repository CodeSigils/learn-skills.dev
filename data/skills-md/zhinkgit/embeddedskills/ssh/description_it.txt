Assistente operativo SSH/Server. Utilizzato per attività quali server remoti, utente@host, configurazione SSH, caricamento e download, distribuzione, jump host, tunnel, port forwarding, esecuzione di comandi server, ecc.; utilizza gli alias host in~/.ssh/config come inventario del server univoco, preferisce l'autenticazione con chiave e racchiude le operazioni OpenSSH tramite script Python in questa abilità.
