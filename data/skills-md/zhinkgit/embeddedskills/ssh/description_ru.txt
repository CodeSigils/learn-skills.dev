Помощник по работе с SSH/сервером. Используется для таких задач, как удаленные серверы, пользователь@хост, настройка SSH, загрузка и выгрузка, развертывание, переход к хостам, туннели, переадресация портов, выполнение команд сервера и т. д.; он использует псевдонимы хоста в ~/.ssh/config в качестве уникального реестра сервера, предпочитает аутентификацию по ключу и переносит операции OpenSSH через сценарии Python в этот навык.
