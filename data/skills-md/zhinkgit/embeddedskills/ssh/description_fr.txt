Assistant d'exploitation SSH/Serveur. Utilisé pour des tâches telles que les serveurs distants, utilisateur @ hôte, la configuration SSH, le téléchargement et le téléchargement, le déploiement, les hôtes de saut, les tunnels, la redirection de port, l'exécution de commandes de serveur, etc. ; il utilise les alias d'hôte dans ~/.ssh/config comme inventaire de serveur unique, préfère l'authentification par clé et encapsule les opérations OpenSSH via des scripts Python dans cette compétence.
