Skill to extract consecutive frames from a video and then perform visual, frame‑by‑frame analysis of the image content, specifically designed for embedded software development debugging.

When a user needs to analyze device recordings and identify logical anomalies on the display (such as value jumps, state anomalies, interface errors, etc.), this skill is used.

Trigger scenarios (activate if any one of these is met; do not wait for the user to say “use video analysis skill”):
- The user provides a video path and requests analysis, problem detection, or locating anomalies.
- The user mentions phenomena in the video such as “value jump,” “number jump,” “report discontinuity,” “state anomaly,” “data erratic jump,” etc.
- The user wants to find the exact time point at which a specific problem occurred from the recording.
- The user describes an abnormality on the embedded device’s display or UI and attaches a video.

Note: This skill does not rely on preset rules—abnormality detection is performed entirely by Claude’s visual analysis, judged each time based on the specific phenomena described by the user.
