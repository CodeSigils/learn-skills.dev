Habilidad para extraer cuadros consecutivos de un video y luego realizar un análisis visual cuadro por cuadro del contenido de la imagen, diseñado específicamente para la depuración del desarrollo de software integrado.

Cuando un usuario necesita analizar grabaciones de dispositivos e identificar anomalías lógicas en la pantalla (como saltos de valores, anomalías de estado, errores de interfaz, etc.), se utiliza esta habilidad.

Escenarios desencadenantes (actívelos si se cumple alguno de estos; no espere a que el usuario diga "usar habilidad de análisis de video"):
- El usuario proporciona una ruta de vídeo y solicita análisis, detección de problemas o localización de anomalías.
- El usuario menciona fenómenos en el vídeo como “salto de valor”, “salto de número”, “discontinuidad de informe”, “anomalía de estado”, “salto errático de datos”, etc.
- El usuario desea encontrar el momento exacto en el que ocurrió un problema específico a partir de la grabación.
- El usuario describe una anomalía en la pantalla o la interfaz de usuario del dispositivo integrado y adjunta un vídeo.

Nota: esta habilidad no depende de reglas preestablecidas: la detección de anomalías se realiza completamente mediante el análisis visual de Claude, juzgado cada vez en función de los fenómenos específicos descritos por el usuario.
