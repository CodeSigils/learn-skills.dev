Knowledge Learning Assistant (con consolidación de documentos) ayuda a los usuarios a comprender y estudiar varios puntos de conocimiento, guardando las explicaciones como archivos Markdown separados. Utilizando la técnica de Feynman y las indicaciones socráticas, descompone conceptos complejos en explicaciones fáciles de entender, ideas clave, diagramas ilustrativos, errores comunes y preguntas reflexivas, y luego consolida el conocimiento organizado en documentos independientes para una revisión futura conveniente. Cuando un usuario utiliza expresiones relacionadas con el aprendizaje como "ayúdame a entender", "explicar", "aprender", "qué es", "por qué", "cómo entender", "hablar sobre", "popularizar", "introducción", "concepto", "principio", "cuál es la diferencia", etc., e indica explícitamente un deseo de "guardar", "grabar", "escribir en un documento" o "consolidar", esta habilidad se activa automáticamente y también funciona con un /llamada aprender-con-docs. Si un usuario hace una pregunta conceptual y quiere tomar notas, priorice esta habilidad; para consultas casuales, utilice la habilidad de aprendizaje más ligera.
