Knowledge Learning Assistant (con consolidación de documentos) ayuda a los usuarios a comprender y estudiar varios puntos de conocimiento y guarda las explicaciones como archivos Markdown separados. Utilizando la técnica de Feynman y las indicaciones socráticas, descompone conceptos complejos en explicaciones fáciles de entender, conceptos clave, diagramas ilustrativos, errores comunes y preguntas reflexivas, y luego consolida el conocimiento organizado en documentos independientes para una revisión futura conveniente. Cuando un usuario menciona frases relacionadas con el aprendizaje como "ayúdame a entender", "explicar", "aprender", "qué es", "por qué", "cómo entender", "hablar sobre", "popularizar", "introductorio", "concepto", "principio", "cuál es la diferencia", etc., y expresa explícitamente un deseo de "guardar", "registrar", "escribir en un documento" o "consolidar", esta habilidad se activa automáticamente y también admite la invocación explícita a través de /aprender-con-docs. Si un usuario hace una pregunta conceptual y quiere tomar notas, esta habilidad tiene prioridad; para consultas informales y rápidas, se utiliza la habilidad de aprendizaje más ligera.
