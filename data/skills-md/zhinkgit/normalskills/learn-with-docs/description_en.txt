Knowledge Learning Assistant (with document consolidation) helps users understand and study various knowledge points, and saves the explanations as separate Markdown files. Using the Feynman technique and Socratic prompting, it breaks down complex concepts into easy-to-understand explanations, key concepts, illustrative diagrams, common pitfalls, and reflective questions, then consolidates the organized knowledge into independent documents for convenient future review. When a user mentions learning-related phrases such as “help me understand,” “explain,” “learn,” “what is,” “why,” “how to understand,” “talk about,” “popularize,” “introductory,” “concept,” “principle,” “what’s the difference,” etc., and explicitly expresses a desire to “save,” “record,” “write into a document,” or “consolidate,” this skill is automatically triggered, and it also supports explicit invocation via /learn-with-docs. If a user asks a conceptual question and wants to keep notes, this skill takes priority; for casual, quick queries, the lighter-weight learn skill is used.
