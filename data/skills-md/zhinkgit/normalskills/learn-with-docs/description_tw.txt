知識學習助理（帶文件整合）幫助使用者理解和學習各種知識點，並將解釋保存為單獨的Markdown文件。運用費曼技巧和蘇格拉底式提示，將複雜的概念分解為簡單易懂的解釋、關鍵概念、說明圖、常見陷阱和思考問題，最後將整理好的知識點整合成獨立的文檔，方便日後複習。當使用者提到「幫我理解」、「解釋一下」、「學習」、「是什麼」、「為什麼」、「如何理解」、「談論」、「普及」、「介紹」、「概念」、「原理」、「有什麼區別」等與學習相關的表達方式，並明確想要「儲存」、「記錄」、「寫入文件」或「鞏固」時，它會自動進行 doc If a user asks conceptual questions and wants to keep notes, this skill is prioritized; if it’s just a casual query, the learn skill is used for a lighter approach.
