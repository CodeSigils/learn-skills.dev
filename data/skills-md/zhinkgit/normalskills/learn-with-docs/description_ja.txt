Knowledge Learning Assistant (ドキュメント統合機能付き) は、ユーザーがさまざまな知識ポイントを理解して学習するのに役立ち、説明を個別の Markdown ファイルとして保存します。ファインマン手法とソクラテス的促しを使用して、複雑な概念をわかりやすい説明、重要な概念、説明図、よくある落とし穴、熟考した質問に分解し、整理された知識を独立した文書に統合して、将来のレビューに便利にします。ユーザーが「理解するのを手伝ってください」、「説明してください」、「学ぶ」、「何ですか」、「なぜ」、「理解する方法」、「話す」、「普及する」、「入門」、「概念」、「原理」、「違いは何ですか」などの学習関連のフレーズに言及し、「保存」、「記録」、「文書に書き込む」、または「統合」したいという欲求を明示的に表現すると、このスキルは役に立ちます。は自動的にトリガーされ、/learn-with-docs を介した明示的な呼び出しもサポートされます。ユーザーが概念的な質問をし、メモを残しておきたい場合は、このスキルが優先されます。カジュアルで素早いクエリの場合は、軽量の学習スキルが使用されます。
