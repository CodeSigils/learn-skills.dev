Knowledge Learning Assistant (ドキュメント統合付き) は、ユーザーがさまざまな知識ポイントを理解し学習するのに役立ち、説明コンテンツを独立した Markdown ファイルとして保存します。ファインマン説明法とソクラテス的ガイダンスを使用して、複雑な概念をわかりやすい説明、重要な概念、図解、よくある落とし穴、示唆に富む質問に分解し、最後に整理された知識ポイントを将来のレビューに便利な個別の文書に統合します。ユーザーが「理解するのを手伝ってください」、「説明してください」、「学ぶ」、「とは何ですか」、「なぜ」、「理解する方法」、「話す」、「広める」、「紹介」、「概念」、「原理」、「違いは何ですか」などの学習関連の表現に言及し、明示的に「保存」、「記録」、「文書に書き込む」、または「統合」したい場合、このスキルは自動的にトリガーされます。また、/learn-with-docs による明示的な呼び出しもサポートしています。ユーザーが概念的な質問をし、メモを残しておきたい場合は、このスキルの使用を優先します。単なるカジュアルなクエリの場合は、学習スキルを使用して軽量なアプローチをとります。
