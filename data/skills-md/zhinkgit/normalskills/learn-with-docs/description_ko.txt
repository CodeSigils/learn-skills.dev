Knowledge Learning Assistant(문서 통합 포함)는 사용자가 다양한 지식 포인트를 이해하고 학습하도록 돕고 설명을 독립적인 Markdown 파일로 저장합니다. 파인만의 설명 방법과 소크라테스식 지침을 사용하여 복잡한 개념을 이해하기 쉬운 설명, 핵심 개념, 예시 다이어그램, 일반적인 함정, 사고 질문으로 분류하고, 마지막으로 정리된 지식 포인트를 별도의 문서로 통합하여 편리한 향후 검토를 제공합니다. 사용자가 "이해하도록 도와주세요", "설명합니다", "학습합니다", "무엇입니까", "왜", "이해하는 방법", "이야기하다", "대중화", "시작하다", "개념", "원리", "차이점은 무엇입니까"와 같은 학습 관련 표현을 사용하고 "저장", "기록", "문서 작성" 또는 "통합"에 대한 욕구를 명시적으로 표현하면 자동으로 트리거되고 명시적 호출도 지원합니다. /learn-with-docs를 통해. 사용자가 개념적인 질문을 하고 메모를 유지하려는 경우 이 기술이 우선적으로 적용됩니다. 단순한 쿼리인 경우 학습 기술이 더 가볍습니다.
