지식 학습 도우미(문서 통합 포함)는 사용자가 다양한 지식 포인트를 이해하고 학습할 수 있도록 돕고 설명을 별도의 마크다운 파일로 저장합니다. 파인만 기법과 소크라테스식 프롬프트를 사용하여 복잡한 개념을 이해하기 쉬운 설명, 핵심 개념, 예시적 다이어그램, 일반적인 함정, 성찰 질문으로 분류한 다음 정리된 지식을 독립적인 문서로 통합하여 편리한 향후 검토를 제공합니다. 사용자가 "이해하도록 도와주세요", "설명합니다", "배우다", "무엇입니까", "왜", "이해하는 방법", "이야기하다", "대중화", "소개", "개념", "원리", "차이점은 무엇입니까" 등과 같은 학습 관련 문구를 언급하고 "저장", "기록", "문서에 작성" 또는 "통합"하려는 의사를 명시적으로 표현하는 경우 기술은 자동으로 트리거되며 /learn-with-docs를 통한 명시적 호출도 지원합니다. 사용자가 개념적인 질문을 하고 메모를 유지하려는 경우 이 기술이 우선적으로 적용됩니다. 일상적이고 빠른 쿼리의 경우 더 가벼운 학습 기술이 사용됩니다.
