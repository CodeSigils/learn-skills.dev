كتابة النصوص المتخصصة لبرامج SaaS الإندونيسية والمنتجات التقنية وبرامج B2B/B2C التي تستهدف الجيل Z وجيل الألفية باللغة البهاسا الإندونيسية. استخدم هذه المهارة عندما يطلب المستخدم كتابة أو مراجعة أو تحسين نسخة لأي منتج SaaS أو تطبيق تقني أو برنامج يستهدف السوق الإندونيسية - بما في ذلك الصفحات المقصودة أو تدفقات الإعداد أو النسخة المصغرة لتجربة المستخدم داخل التطبيق أو صفحات التسعير أو إعلانات الميزات أو تسلسلات البريد الإلكتروني أو إعلانات الوسائط الاجتماعية أو أي نسخة منتج باللغة البهاسا الإندونيسية. تشغيل: "tulis Copy SaaS" أو "copy aplikasi" أو "copy produk tech" أو "الصفحة المقصودة Bahasa" أو "UX Writing Indonesia" أو الإشارات إلى العلامات التجارية الإندونيسية SaaS (Mekari وXendit وMajoo وBibit وStockbit وGoBiz وما إلى ذلك)، أو أي طلب يتضمن كتابة نصوص برمجية للجمهور الإندونيسي. يتم تشغيله أيضًا عندما يذكر المستخدم "صفحة التسعير" أو "نسخة الإعداد" أو "نسخة الميزة" أو "نسخة المنتج" أو "نسخة داخل التطبيق" في سياق إندونيسي، حتى إذا لم يذكر "SaaS" صراحةً.
