دليل لاستخدام مكونات React المصممة والتي يمكن الوصول إليها مع متغير واجهة المستخدم الأساسية لـ shadcn/ui، والذي يستخدم @base-ui/react كطبقة أولية بدلاً من Radix UI. يغطي تثبيت المكونات، والتخصيص باستخدام متغيرات Tailwind CSS v4 وoklch CSS، والنماذج باستخدام React Hook Form وZod، وأنماط واجهة المستخدم مثل الأزرار ومربعات الحوار والقوائم المنسدلة وجداول البيانات والبطاقات والمزيد. استخدم هذه المهارة عندما يعمل المستخدم مع shadcn/ui مدعومًا بـ @base-ui/react، أو يستورد من @/components/ui/، أو ينشئ مكونات React نمطية في مشروع باستخدام إعداد shadcn المستند إلى واجهة المستخدم الأساسية. يتم تشغيله أيضًا عندما يذكر المستخدم shadcn باستخدام Base UI، أو يستخدم خاصية العرض بدلاً من asChild، أو يشير إلى سمات فتحة البيانات. حتى لو لم يذكر المستخدم صراحةً shadcn/ui، فاستخدم هذه المهارة عند إنشاء واجهة مستخدم React في مشروع تم تثبيت كل من shadcn/ui و@base-ui/react عليه.
