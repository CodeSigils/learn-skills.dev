Guide d'utilisation de composants React stylisés et accessibles avec la variante Base UI de shadcn/ui, qui utilise @base-ui/react comme couche primitive au lieu de Radix UI. Couvre l'installation des composants, la création de thèmes avec Tailwind CSS v4 et les variables CSS oklch, les formulaires avec React Hook Form et Zod, ainsi que les modèles d'interface utilisateur tels que les boutons, les boîtes de dialogue, les listes déroulantes, les tableaux de données, les cartes, etc. Utilisez cette compétence chaque fois que l'utilisateur travaille avec shadcn/ui soutenu par @base-ui/react, importe depuis @/components/ui/ ou crée des composants React stylisés dans un projet à l'aide de cette configuration shadcn basée sur l'interface utilisateur de base. Se déclenche également lorsque l'utilisateur mentionne shadcn avec l'interface utilisateur de base, utilise la propriété render au lieu de asChild ou fait référence aux attributs d'emplacement de données. Même si l'utilisateur ne mentionne pas explicitement shadcn/ui, utilisez cette compétence lorsqu'il crée React UI dans un projet sur lequel shadcn/ui et @base-ui/react sont installés.
