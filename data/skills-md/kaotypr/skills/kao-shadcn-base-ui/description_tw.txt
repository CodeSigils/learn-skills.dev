使用帶有 shadcn/ui 的 Base UI 變體的樣式化、可存取的 React 元件的指南，該變體使用 @base-ui/react 作為其原始層而不是 Radix UI。涵蓋元件安裝、Tailwind CSS v4 和 oklch CSS 變數的主題、React Hook Form 和 Zod 的表單，以及按鈕、對話方塊、下拉式選單、資料表、卡片等 UI 模式。每當使用者使用 @base-ui/react 支援的 shadcn/ui、從 @/components/ui/ 匯入或使用此基於 Base UI 的 shadcn 設定在專案中建立樣式化的 React 元件時，請使用此技能。當使用者在 Base UI 中提及 shadcn、使用 render prop 而不是 asChild 或引用資料槽屬性時也會觸發。即使使用者沒有明確提及 shadcn/ui，當他們在安裝了 shadcn/ui 和 @base-ui/react 的專案中建立 React UI 時，也可以使用此技能。
