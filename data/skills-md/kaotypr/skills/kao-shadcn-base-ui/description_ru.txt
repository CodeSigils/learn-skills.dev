Руководство по использованию стилизованных доступных компонентов React с вариантом базового пользовательского интерфейса shadcn/ui, который использует @base-ui/react в качестве примитивного уровня вместо пользовательского интерфейса Radix. Охватывает установку компонентов, оформление тем с помощью переменных CSS Tailwind CSS v4 и oklch CSS, формы с помощью React Hook Form и Zod, а также шаблоны пользовательского интерфейса, такие как кнопки, диалоговые окна, раскрывающиеся списки, таблицы данных, карточки и многое другое. Используйте этот навык всякий раз, когда пользователь работает с shadcn/ui, поддерживаемым @base-ui/react, импортирует из @/comComponents/ui/ или создает стилизованные компоненты React в проекте, используя эту настройку shadcn на основе базового пользовательского интерфейса. Также срабатывает, когда пользователь упоминает shadcn в базовом пользовательском интерфейсе, использует свойство render вместо asChild или ссылается на атрибуты слота данных. Даже если пользователь явно не упоминает shadcn/ui, используйте этот навык при создании пользовательского интерфейса React в проекте, в котором установлены как shadcn/ui, так и @base-ui/react.
