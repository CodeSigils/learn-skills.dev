Leitfaden zur Verwendung gestalteter, zugänglicher React-Komponenten mit der Base-UI-Variante von shadcn/ui, die @base-ui/react als primitive Ebene anstelle der Radix-UI verwendet. Behandelt die Komponenteninstallation, die Themengestaltung mit Tailwind CSS v4- und oklch-CSS-Variablen, Formulare mit React Hook Form und Zod sowie UI-Muster wie Schaltflächen, Dialoge, Dropdowns, Datentabellen, Karten und mehr. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer mit shadcn/ui arbeitet, das von @base-ui/react unterstützt wird, aus @/components/ui/ importiert oder gestaltete React-Komponenten in einem Projekt mit diesem Base-UI-basierten shadcn-Setup erstellt. Wird auch ausgelöst, wenn der Benutzer shadcn mit Base UI erwähnt, die Render-Requisite anstelle von asChild verwendet oder auf Datenslot-Attribute verweist. Auch wenn der Benutzer shadcn/ui nicht explizit erwähnt, verwenden Sie diese Fähigkeit, wenn er die React-Benutzeroberfläche in einem Projekt erstellt, in dem sowohl shadcn/ui als auch @base-ui/react installiert sind.
