使用带有 shadcn/ui 的 Base UI 变体的样式化、可访问的 React 组件的指南，该变体使用 @base-ui/react 作为其原始层而不是 Radix UI。涵盖组件安装、Tailwind CSS v4 和 oklch CSS 变量的主题、React Hook Form 和 Zod 的表单，以及按钮、对话框、下拉菜单、数据表、卡片等 UI 模式。每当用户使用 @base-ui/react 支持的 shadcn/ui、从 @/components/ui/ 导入或使用此基于 Base UI 的 shadcn 设置在项目中构建样式化的 React 组件时，请使用此技能。当用户在 Base UI 中提及 shadcn、使用 render prop 而不是 asChild 或引用数据槽属性时也会触发。即使用户没有明确提及 shadcn/ui，当他们在安装了 shadcn/ui 和 @base-ui/react 的项目中构建 React UI 时，也可以使用此技能。
