Guía para usar componentes de React accesibles y con estilo con la variante Base UI de shadcn/ui, que usa @base-ui/react como su capa primitiva en lugar de Radix UI. Cubre la instalación de componentes, temas con Tailwind CSS v4 y variables CSS oklch, formularios con React Hook Form y Zod, y patrones de interfaz de usuario como botones, cuadros de diálogo, menús desplegables, tablas de datos, tarjetas y más. Utilice esta habilidad siempre que el usuario esté trabajando con shadcn/ui respaldado por @base-ui/react, importando desde @/components/ui/ o creando componentes de React con estilo en un proyecto usando esta configuración de shadcn basada en Base UI. También se activa cuando el usuario menciona shadcn con la interfaz de usuario base, usa el accesorio de renderizado en lugar de asChild o hace referencia a atributos de ranura de datos. Incluso si el usuario no menciona explícitamente shadcn/ui, use esta habilidad cuando esté creando React UI en un proyecto que tenga instalados shadcn/ui y @base-ui/react.
