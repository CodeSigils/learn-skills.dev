Radix UI の代わりに @base-ui/react をプリミティブ層として使用する、shadcn/ui の Base UI バリアントでスタイル付きのアクセス可能な React コンポーネントを使用するためのガイド。コンポーネントのインストール、Tailwind CSS v4 と oklch CSS 変数を使用したテーマ、React Hook Form と Zod を使用したフォーム、ボタン、ダイアログ、ドロップダウン、データ テーブル、カードなどの UI パターンをカバーします。このスキルは、ユーザーが @base-ui/react によってサポートされる shadcn/ui を操作する場合、@/components/ui/ からインポートする場合、またはこの Base UI ベースの shadcn セットアップを使用してプロジェクト内でスタイル付き React コンポーネントを構築する場合に使用します。また、ユーザーが Base UI で shadcn に言及した場合、asChild の代わりに render prop を使用した場合、またはデータスロット属性を参照した場合にもトリガーされます。ユーザーが shadcn/ui に明示的に言及していない場合でも、shadcn/ui と @base-ui/react の両方がインストールされているプロジェクトで React UI を構築するときにこのスキルを使用します。
