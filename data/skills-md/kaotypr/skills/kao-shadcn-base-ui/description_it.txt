Guida per l'utilizzo di componenti React accessibili e con stile con la variante Base UI di shadcn/ui, che utilizza @base-ui/react come livello primitivo invece di Radix UI. Copre l'installazione dei componenti, la creazione di temi con Tailwind CSS v4 e le variabili CSS oklch, i moduli con React Hook Form e Zod e i modelli di interfaccia utente come pulsanti, finestre di dialogo, menu a discesa, tabelle dati, schede e altro ancora. Utilizza questa competenza ogni volta che l'utente lavora con shadcn/ui supportato da @base-ui/react, importa da @/components/ui/ o crea componenti React con stile in un progetto utilizzando questa configurazione shadcn basata sull'interfaccia utente di Base. Si attiva anche quando l'utente menziona shadcn con l'interfaccia utente di base, utilizza la prop di rendering anziché asChild o fa riferimento agli attributi dello slot di dati. Anche se l'utente non menziona esplicitamente shadcn/ui, utilizza questa competenza quando sta creando l'interfaccia utente di React in un progetto in cui sono installati sia shadcn/ui che @base-ui/react.
