Radix UI 대신 @base-ui/react를 기본 레이어로 사용하는 shadcn/ui의 기본 UI 변형과 함께 스타일이 지정되고 액세스 가능한 React 구성 요소를 사용하기 위한 가이드입니다. 구성 요소 설치, Tailwind CSS v4 및 oklch CSS 변수를 사용한 테마 지정, React Hook Form 및 Zod를 사용한 양식, 버튼, 대화 상자, 드롭다운, 데이터 테이블, 카드 등과 같은 UI 패턴을 다룹니다. 사용자가 @base-ui/react가 지원하는 shadcn/ui로 작업하거나, @/comComponents/ui/에서 가져오거나, 이 기본 UI 기반 shadcn 설정을 사용하여 프로젝트에서 스타일이 지정된 React 구성 요소를 빌드할 때마다 이 기술을 사용하세요. 또한 사용자가 기본 UI로 shadcn을 언급하거나 asChild 대신 render prop을 사용하거나 데이터 슬롯 속성을 참조할 때 트리거됩니다. 사용자가 shadcn/ui를 명시적으로 언급하지 않더라도 shadcn/ui와 @base-ui/react가 모두 설치된 프로젝트에서 React UI를 빌드할 때 이 기술을 사용하세요.
