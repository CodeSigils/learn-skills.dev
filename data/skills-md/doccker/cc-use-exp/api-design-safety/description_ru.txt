Запускается при разработке или изменении структур ответов REST API, обработке возвращаемых значений API или создании последующих продуктов, таких как файлы Excel/CSV/PDF/выверки. Это предотвращает такие проблемы, как несовпадение полей, неоднозначность типов, вызванная дефектами конструкции API, и молчаливый успех, когда ключевые поля отсутствуют в сгенерированных выходных данных.
