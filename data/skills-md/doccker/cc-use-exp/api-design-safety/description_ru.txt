Он запускается при разработке или изменении структур ответов REST API, обработке возвращаемых значений API или создании последующих артефактов, таких как файлы Excel/CSV/PDF/выверки. Это предотвращает проблемы, вызванные дефектами проектирования API, такими как несовпадение полей, неоднозначность типов и проблема отсутствия ключевых полей в сгенерированных артефактах, в то время как процесс выполняется автоматически.
