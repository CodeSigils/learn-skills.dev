يتم تشغيله عند تصميم أو تعديل بنيات استجابة REST API، أو التعامل مع قيم إرجاع API، أو إنشاء عناصر المصب مثل Excel، أو CSV، أو PDF، أو ملفات التسوية. فهو يمنع حدوث مشكلات مثل اختلال الحقل وغموض الكتابة الناتج عن عيوب تصميم واجهة برمجة التطبيقات (API)، بالإضافة إلى مشكلة فقدان الحقول المهمة في العناصر التي تم إنشاؤها والتي تنجح بصمت.
