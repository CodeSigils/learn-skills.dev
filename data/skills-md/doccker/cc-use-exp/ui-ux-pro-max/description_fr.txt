Directives de conception UI/UX de niveau professionnel, déclenchées manuellement lorsqu'une conception d'interface de haute qualité est nécessaire ou déclenchées automatiquement lors de la description de « l'ambiance de conception/interface utilisateur professionnelle ». Ils couvrent la hiérarchie visuelle, les systèmes de couleurs, le rythme typographique, les micro-animations interactives, l'adaptation réactive, etc. Le développement front-end de routine est couvert par la compétence frontend-dev.
