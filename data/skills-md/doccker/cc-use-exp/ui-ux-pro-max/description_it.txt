Linee guida per la progettazione UI/UX di livello professionale, attivate manualmente quando è necessaria una progettazione dell'interfaccia di alta qualità o attivate automaticamente quando si descrive "sensazione di design/interfaccia utente professionale". Copre la gerarchia visiva, il sistema di colori, il ritmo tipografico, le microanimazioni interattive, l'adattamento reattivo, ecc. Lo sviluppo front-end di routine è coperto dalla competenza frontend-dev.
