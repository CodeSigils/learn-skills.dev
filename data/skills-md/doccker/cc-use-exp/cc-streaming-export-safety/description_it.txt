Si attiva quando si implementa l'esportazione di file di grandi dimensioni guidata dall'utente o la serializzazione batch (Excel/CSV/JSON/JSONL/PDF, con dimensioni dei dati sconosciute o superiori a 10.000 righe/10 MB); i normali download di file di piccole dimensioni, i download di risorse statiche e le classi Writer/Report non esportabili non si attivano. Previeni OOM, residui di file temporanei, blocco dell'esportazione sincrona dei thread HTTP e inserimento di formule nel foglio di calcolo.
