Cuando el código contiene llamadas como LocalDate.now() / LocalDateTime.now() / Instant.now() / new Date() / Date.now() / time.Now() para la "hora actual", o involucra puntos de inicio de semana/mes/día, comparaciones entre zonas horarias o campos de hora de base de datos, se debe activar. Esto evita errores estadísticos causados ​​por la desviación de la zona horaria en el entorno de producción.
