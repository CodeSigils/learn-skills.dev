Wenn der Code Aufrufe wie LocalDate.now() / LocalDateTime.now() / Instant.now() / new Date() / Date.now() / time.Now() enthält, die die „aktuelle Zeit“ abrufen oder Startpunkte für Woche/Monat/Tag, zeitzonenübergreifende Vergleiche oder Datenbankzeitfelder umfassen, sollte er ausgelöst werden. Dies verhindert statistische Fehler, die durch Zeitzonenabweichungen in der Produktionsumgebung verursacht werden.
