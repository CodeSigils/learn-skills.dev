Lorsque le code contient des appels tels que LocalDate.now() / LocalDateTime.now() / Instant.now() / new Date() / Date.now() / time.Now() qui récupèrent « l'heure actuelle » ou impliquent des points de départ semaine/mois/jour, des comparaisons entre fuseaux horaires ou des champs horaires de base de données, il doit être déclenché. Cela évite les erreurs statistiques causées par la dérive du fuseau horaire dans l’environnement de production.
