統合地質解析 – 堆積学、層序学、構造地質学、古環境および古気候の復元、地形学、鉱物資源評価、地球化学などの分野をカバーする専門的な地質成因解析です。ユーザーが、堆積相/環境の解釈、構造応力場の再構築と地殻変動の分析、花粉、粒径、磁化率、地球化学などの代替指標を使用した古環境の再構築、露頭の岩石や鉱物の記述、起源推定のための掘削コア、薄片の記述、鉱物鉱床の種類の特定と鉱物探査の可能性の評価、地域の再構築などの複雑な地質学的作業を実行する必要がある場合地殻変動の歴史や堆積物の進化の歴史、または活動的な地殻変動の地形を分析するには、このスキルを使用する必要があります。複数の証拠の相互検証と体系的な起源推論を必要とするシナリオに適用できます。注: 鉱物の定義/岩石の分類、工学地質学/地盤工学/地盤災害評価/建築材料の同定/栄養と健康の状況に関する簡単な事実に基づく Q&A は、このスキルをトリガーするべきではありません。
