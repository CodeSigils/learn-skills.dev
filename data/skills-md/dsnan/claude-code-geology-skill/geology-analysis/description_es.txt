Análisis geológico integral: análisis profesional del origen geológico que cubre ramas como sedimentología, estratigrafía, geología estructural, reconstrucción de paleoambiente y paleoclima, geomorfología, evaluación de recursos minerales, geoquímica, etc. Cuando el usuario necesita realizar trabajos geológicos complejos como la interpretación de facies sedimentarias/entornos de depósito, la reconstrucción de campos de tensión tectónicos y la evolución tectónica, la reconstrucción de paleoambientes utilizando indicadores indirectos como esporas/polen, granos Se debe utilizar esta habilidad. Es aplicable a escenarios que requieren validación cruzada de múltiples evidencias e inferencia sistemática del origen. Nota: Las simples preguntas y respuestas sobre hechos, como definiciones de minerales, clasificaciones de rocas, ingeniería geológica, ingeniería geotécnica, evaluación de peligros geológicos, identificación de materiales de construcción, salud nutricional, etc., no deberían desencadenar esta habilidad.
