Hace cumplir el marketing y el texto web fundamentados y sin contrastes. Cada propuesta de valor debe establecer lo que el sujeto ES o HACE usando sustantivos, verbos y detalles concretos, nunca negación, contraste o vocabulario exagerado. Utilice esta habilidad siempre que escriba, edite, traduzca, revise o localice CUALQUIER texto para el usuario: titulares, lemas, propuestas de valor, páginas de destino, descripciones de productos, páginas Acerca de, CTA, etiquetas de botones, meta/descripciones OG, texto alternativo, asuntos y cuerpos de correos electrónicos, publicaciones en redes sociales, textos de anuncios, folletos o archivos de cadenas locales/i18n, incluso si el usuario no menciona las reglas de estilo. Úselo también cuando el usuario diga "de marca", "nuestro estilo de escritura", "sin clichés de IA" o solicite revisar el texto.
