يفرض تسويقًا ونسخة ويب مرتكزة وخالية من التباين. يجب أن يوضح كل عرض قيمة ما هو الموضوع أو ما يفعله باستخدام الأسماء والأفعال والتفاصيل الملموسة - لا يتم أبدًا النفي أو التباين أو المفردات الضجيج. استخدم هذه المهارة عند كتابة أو تحرير أو ترجمة أو مراجعة أو تعريب أي نسخة يواجهها المستخدم - العناوين الرئيسية، أو خطوط العلامات، أو عروض القيمة، أو الصفحات المقصودة، أو أوصاف المنتج، أو حول الصفحات، أو عبارات الحث على اتخاذ إجراء، أو تسميات الأزرار، أو أوصاف التعريف/OG، أو النص البديل، أو موضوعات ونصوص البريد الإلكتروني، أو المنشورات الاجتماعية، أو نسخة الإعلان، أو الكتيبات، أو ملفات سلسلة الإعدادات المحلية/i18n - حتى لو لم يذكر المستخدم قواعد النمط. يُستخدم أيضًا عندما يقول المستخدم "حسب العلامة التجارية"، أو "أسلوب الكتابة الخاص بنا"، أو "لا توجد كليشيهات للذكاء الاصطناعي"، أو يطلب التحقق من النسخة.
