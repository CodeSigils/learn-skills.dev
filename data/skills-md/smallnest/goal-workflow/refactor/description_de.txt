Fachmännisches Code-Refactoring basierend auf dem Katalog von Martin Fowler – verbessern Sie die Wartbarkeit, ohne das Verhalten zu ändern. Behandelt Code-Smells, das Verfassen von Methoden, das Verschieben von Features, das Organisieren von Daten, das Vereinfachen von Bedingungen, Methodenaufrufe und die Verallgemeinerung. Löst aus: umgestalten, ändern, bereinigen, Code verbessern, Code riechen, Methode extrahieren, umbenennen, vereinfachen.
