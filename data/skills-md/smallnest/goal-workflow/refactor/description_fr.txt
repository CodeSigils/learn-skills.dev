Refactorisation experte du code basée sur le catalogue de Martin Fowler : améliorez la maintenabilité sans modifier le comportement. Couvre les odeurs de code, la composition de méthodes, le déplacement de fonctionnalités, l'organisation des données, la simplification des conditions, les appels de méthodes et la généralisation. Déclencheurs sur : refactoriser, supprimer, nettoyer, améliorer le code, odeur de code, extraire la méthode, renommer, simplifier.
