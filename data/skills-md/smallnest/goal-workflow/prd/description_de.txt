Erstellen Sie ein Produktanforderungsdokument (PRD) für eine neue Funktion und zerlegen Sie es dann in umsetzbare Probleme. Verwenden Sie diese Funktion, wenn Sie eine Funktion planen, ein neues Projekt starten oder wenn Sie aufgefordert werden, ein PRD zu erstellen. Auslöser für: Erstellen eines PRD, Schreiben eines PRD für, Planen dieser Funktion, Anforderungen für, Spezifizieren, 写PRD, 需求文档, 需求分析, 规格说明.
