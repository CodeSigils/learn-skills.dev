Рабочий процесс фиксации кода, создания PR, слияния и закрытия проблем через интерфейс командной строки GitHub (gh). Запускается после завершения реализации цели (проблемы GitHub) — фиксация кода, отправка ветки, создание PR, слияние, затем закрытие задачи. Используйте, когда пользователь говорит «提交代码», «зафиксировать и объединить», «创建PR», «合入», «关闭issue», «отправить» или когда реализация цели завершена и необходимо отправить код.
