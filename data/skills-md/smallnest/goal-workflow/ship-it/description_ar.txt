الالتزام بالكود وإنشاء العلاقات العامة والدمج وإغلاق سير العمل عبر GitHub CLI (gh). يتم التشغيل بعد اكتمال تنفيذ الهدف (مشكلة GitHub) - تنفيذ التعليمات البرمجية، ودفع الفرع، وإنشاء العلاقات العامة، والدمج، ثم إغلاق المشكلة. يُستخدم عندما يقول المستخدم "提交代码"، أو "الالتزام والدمج"، أو "创建PR"، أو "合入"، أو "إصدار جديد"، أو "ship-it"، أو عندما يتم تنفيذ الهدف ويلزم شحن التعليمات البرمجية.
