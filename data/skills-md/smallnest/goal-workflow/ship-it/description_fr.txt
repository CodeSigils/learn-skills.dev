Workflow de validation de code, de création de relations publiques, de fusion et de clôture de problèmes via GitHub CLI (gh). Déclencheurs une fois la mise en œuvre d'un objectif (problème GitHub) terminée : valider le code, pousser la branche, créer un PR, fusionner, puis fermer le problème. À utiliser lorsque l'utilisateur dit « 提交代码 », « commit and merge », « 创建PR », « 合入 », « 关闭issue », « ship-it » ou lorsqu'une implémentation d'objectif est effectuée et que le code doit être expédié.
