Flujo de trabajo de confirmación de código, creación de relaciones públicas, fusión y cierre de problemas a través de GitHub CLI (gh). Activadores después de que se completa la implementación de un objetivo (Problema de GitHub): confirmar código, impulsar rama, crear PR, fusionar y luego cerrar el problema. Úselo cuando el usuario diga "提交代码", "commit and merge", "创建PR", "合入", "关闭issue", "ship-it", o cuando se haya realizado la implementación de un objetivo y sea necesario enviar el código.
