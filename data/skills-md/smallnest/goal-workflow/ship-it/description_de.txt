Code-Commit-, PR-Erstellungs-, Merge- und Issue-Closing-Workflow über GitHub CLI (gh). Wird ausgelöst, nachdem die Implementierung eines Ziels (GitHub-Problem) abgeschlossen ist – Code festschreiben, Zweig pushen, PR erstellen, zusammenführen und dann das Problem schließen. Wird verwendet, wenn der Benutzer „提交代码“, „commit and merge“, „创建PR“, „合入“, „关闭issue“, „ship-it“ sagt oder wenn eine Zielimplementierung abgeschlossen ist und Code versendet werden muss.
