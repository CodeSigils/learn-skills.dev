Genere diagramas UML, diagramas de arquitectura y diagramas de flujo para cualquier proyecto. Después de analizar el código base, permita que el usuario elija el tipo de diagrama a generar, use la habilidad de diagrama de arquitectura para representarlo como HTML+SVG y guárdelo en el directorio docs/. Adecuado para la visualización de documentación de cualquier proyecto de software.
