Ingénierie graphique pour l'exécution de tâches parallèles : convertissez une tâche, un PRD, un SPEC ou un ensemble de problèmes en un graphe de dépendances (DAG), superposez-le en superétapes, puis implémentez chaque nœud indépendant simultanément avec des sous-agents - chaque nœud exécute /goal → /review-it → /ship-it dans un arbre de travail git isolé, avec une barrière de fan-in entre les vagues. Déclencheurs sur : graphique, ingénierie graphique, création d'un graphique, graphique de tâches, graphique de dépendances, DAG, implémentation parallèle, fan-out fan-in, superstep, flux de travail dynamique.
