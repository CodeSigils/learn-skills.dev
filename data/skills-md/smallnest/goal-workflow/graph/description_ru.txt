Разработка графов для параллельного выполнения задач: преобразуйте задачу, PRD, SPEC или набор проблем в граф зависимостей (DAG), разбивайте его на супершаги, затем реализуйте каждый независимый узел одновременно с подагентами — каждый узел выполняет /goal → /review-it → /ship-it в изолированном рабочем дереве git с барьером между волнами. Запускается по: графу, проектированию графов, построению графа, графу задач, графу зависимостей, DAG, параллельной реализации, 并发实现, 并行实现, 任务图, 把任务变成图, разветвлению разветвления, супершагу, динамическому рабочему процессу.
