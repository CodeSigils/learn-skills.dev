Utilice la API ListenHub para convertir texto a voz (TTS). Admite tres modos: síntesis rápida (/v1/tts), secuencia de comandos de varios caracteres (/v1/voz) y síntesis de transmisión de texto largo (/v1/flow-speech/episodes). Si no se especifica ningún tono de voz, la lista de voces se recupera automáticamente para que el usuario elija, de forma predeterminada chat‑girl‑105‑cn (Xiaoman). Úselo cuando el usuario diga: “tts”, “texto a voz”, “语音合成”, “文字转语音”, “朗读”, “生成语音”, “生成音频”, “转音频”, “texto a audio”.
