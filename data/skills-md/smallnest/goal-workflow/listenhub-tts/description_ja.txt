ListenHub API を使用してテキストを音声に変換します (TTS)。高速合成 (/v1/tts)、マルチ文字スクリプト (/v1/speech)、および長文ストリーミング合成 (/v1/flow-speech/episodes) の 3 つのモードをサポートします。声のトーンが指定されていない場合、音声リストが自動的に取得され、ユーザーが選択できます。デフォルトは chat‑girl‑105‑cn (Xiaoman) です。ユーザーが「tts」、「text to speech」、「语音合成」、「文字转语音」、「朗读」、「生成语音」、「生成音声」、「转音オーディオ」、「text to audio」と言うときに使用します。
