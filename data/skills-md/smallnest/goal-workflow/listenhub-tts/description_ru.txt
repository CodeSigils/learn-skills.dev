Используйте API ListenHub для преобразования текста в речь (TTS). Поддерживает три режима: быстрый синтез (/v1/tts), многосимвольный сценарий (/v1/speech) и потоковый синтез длинного текста (/v1/flow-speech/episodes). Если тон голоса не указан, список голосов автоматически извлекается для выбора пользователем, по умолчанию используется болтовня-105-cn (Xiaoman). Используйте, когда пользователь говорит: «tts», «текст в речь», «синтез голоса», «текст в голос», «читать вслух», «генерировать голос», «генерировать аудио», «конвертировать в аудио», «текст в аудио».
