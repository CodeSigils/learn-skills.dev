Capacità di integrazione API Atlas Cloud: richiama rapidamente oltre 300 modelli di generazione di immagini e video AI tramite un'API unificata. Utilizza questa competenza quando l'utente deve integrare la generazione di immagini AI (ad esempio, Flux, Seedream, DALL-E), la generazione di video AI (ad esempio, Kling, Sora, Seedance) o chiamare API LLM (formato compatibile con OpenAI) nel proprio progetto. Gli scenari applicabili includono: generazione di immagini, generazione di video, chiamata di modelli linguistici di grandi dimensioni, utilizzo dell'API Atlas Cloud, configurazione di ATLASCLOUD_API_KEY, query sugli elenchi di modelli disponibili, ricerca di modelli per parola chiave, caricamento di immagini/file multimediali locali, generazione rapida in un unico passaggio, da immagine a video, da testo a immagine, da testo a video, integrazione dello strumento di creazione di contenuti AI. Anche se l'utente non menziona esplicitamente Atlas Cloud, questa competenza deve essere presa in considerazione ogni volta che è coinvolto lo sviluppo dell'integrazione dell'API per la generazione di contenuti multimediali AI.
