مهارة تكامل Atlas Cloud API - يمكنك الاتصال سريعًا بأكثر من 300 نموذج لإنشاء صور الذكاء الاصطناعي وإنشاء الفيديو ونماذج LLM من خلال واجهة برمجة تطبيقات موحدة. استخدم هذه المهارة عندما يحتاج المستخدم إلى دمج إنشاء صور الذكاء الاصطناعي (على سبيل المثال، Flux، Seedream، DALL-E)، أو إنشاء فيديو الذكاء الاصطناعي (على سبيل المثال، Kling، Sora، Seedance)، أو استدعاء LLM APIs (تنسيق متوافق مع OpenAI) في مشروعهم. تتضمن السيناريوهات القابلة للتطبيق: إنشاء الصور، وإنشاء مقاطع الفيديو، واستدعاء نماذج اللغات الكبيرة، باستخدام Atlas Cloud API، وتكوين ATLASCLOUD_API_KEY، والاستعلام عن قوائم النماذج المتاحة، والبحث عن النماذج حسب الكلمات الرئيسية، وتحميل الصور/ملفات الوسائط المحلية، والتوليد السريع بخطوة واحدة، وتحويل الصورة إلى فيديو، وتحويل النص إلى صورة، وتحويل النص إلى فيديو، وتكامل أدوات إنشاء محتوى الذكاء الاصطناعي. حتى إذا لم يذكر المستخدم Atlas Cloud صراحةً، فيجب أخذ هذه المهارة في الاعتبار عندما يتعلق الأمر بتطوير تكامل واجهة برمجة تطبيقات إنشاء وسائط الذكاء الاصطناعي.
