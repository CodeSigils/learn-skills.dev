Навыки интеграции Atlas Cloud API — быстро вызывайте более 300 ИИ-изображений, генерацию видео и модели LLM с помощью унифицированного API. Используйте этот навык, когда пользователю необходимо интегрировать создание изображений AI (например, Flux, Seedream, DALL-E), создание видео AI (например, Kling, Sora, Seedance) или вызвать API-интерфейсы LLM (формат, совместимый с OpenAI) в свой проект. Применимые сценарии включают в себя: генерацию изображений, генерацию видео, вызов больших языковых моделей, использование Atlas Cloud API, настройку ATLASCLOUD_API_KEY, запрос списков доступных моделей, поиск моделей по ключевому слову, загрузку локальных изображений/медиа-файлов, одношаговую быструю генерацию, преобразование изображения в видео, преобразование текста в изображение, преобразование текста в видео, интеграцию инструментов создания контента AI. Даже если пользователь явно не упоминает Atlas Cloud, этот навык следует учитывать всякий раз, когда речь идет о разработке интеграции API генерации мультимедиа с помощью искусственного интеллекта.
