Compétence d'intégration de l'API Atlas Cloud : appelez rapidement plus de 300 modèles de génération d'images IA, de génération de vidéos et LLM via une API unifiée. Utilisez cette compétence lorsque l'utilisateur doit intégrer la génération d'images IA (par exemple, Flux, Seedream, DALL-E), la génération de vidéos IA (par exemple, Kling, Sora, Seedance) ou appeler des API LLM (format compatible OpenAI) dans son projet. Les scénarios applicables incluent : la génération d'images, la génération de vidéos, l'appel de grands modèles de langage, l'utilisation de l'API Atlas Cloud, la configuration d'ATLASCLOUD_API_KEY, l'interrogation des listes de modèles disponibles, la recherche de modèles par mot-clé, le téléchargement d'images/fichiers multimédias locaux, la génération rapide en une étape, l'image vers la vidéo, le texte vers l'image, le texte vers la vidéo, l'intégration d'un outil de création de contenu IA. Même si l'utilisateur ne mentionne pas explicitement Atlas Cloud, cette compétence doit être prise en compte chaque fois que le développement de l'intégration d'API de génération de médias IA est impliqué.
