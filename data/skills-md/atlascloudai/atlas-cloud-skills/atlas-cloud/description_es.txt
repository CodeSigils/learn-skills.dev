Habilidad de integración de API de Atlas Cloud: llame rápidamente a más de 300 modelos de LLM, generación de imágenes y videos de IA a través de una API unificada. Utilice esta habilidad cuando el usuario necesite integrar la generación de imágenes de IA (por ejemplo, Flux, Seedream, DALL-E), la generación de videos de IA (por ejemplo, Kling, Sora, Seedance) o llamar a las API de LLM (formato compatible con OpenAI) en su proyecto. Los escenarios aplicables incluyen: generar imágenes, generar videos, llamar a modelos de lenguaje grandes, usar Atlas Cloud API, configurar ATLASCLOUD_API_KEY, consultar listas de modelos disponibles, buscar modelos por palabra clave, cargar imágenes/archivos multimedia locales, generación rápida en un solo paso, imagen a video, texto a imagen, texto a video, integración de herramientas de creación de contenido de IA. Incluso si el usuario no menciona explícitamente Atlas Cloud, esta habilidad debe considerarse siempre que se trate del desarrollo de integración de API de generación de medios de IA.
