Agentenübergreifende Aufruffähigkeit für das ANP-Protokoll. Rufen Sie mithilfe der dezentralen Identität did:wba jeden Agenten im ANP-Netzwerk auf (z. B. Gaode Map, Hotelbuchung, Kurierverfolgung usw.). Diese Fähigkeit wird ausgelöst, wenn der Benutzer ANP erwähnt, einen Agenten anruft, ein Hotel bucht, einen Kurierdienst überprüft, eine Karte überprüft oder eine Routenplanung durchführt.
