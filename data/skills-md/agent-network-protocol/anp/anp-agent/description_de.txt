Das ANP-Protokoll ermöglicht den agentenübergreifenden Skill-Aufruf. Unter Verwendung der dezentralen Identität did:wba ruft es jeden Agenten im ANP-Netzwerk an (z. B. Amap, Hotelbuchung, Express-Lieferanfrage usw.). Diese Fähigkeit wird ausgelöst, wenn Benutzer ANP erwähnen, einen Agenten anrufen, ein Hotel buchen, die Expresszustellung überprüfen, Karten überprüfen oder eine Routenplanung durchführen.
