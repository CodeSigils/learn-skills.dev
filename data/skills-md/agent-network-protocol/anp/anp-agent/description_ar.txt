يتيح بروتوكول ANP استدعاء المهارات عبر الوكيل. باستخدام الهوية اللامركزية did:wba، فإنه يستدعي أي وكيل في شبكة ANP (مثل Amap، وحجز الفنادق، والاستعلام عن التسليم السريع، وما إلى ذلك). يتم تشغيل هذه المهارة عندما يذكر المستخدمون ANP، أو استدعاء وكيل، أو حجز فندق، أو التحقق من التسليم السريع، أو التحقق من الخرائط، أو تخطيط الطريق.
