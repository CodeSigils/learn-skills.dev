مهارة الاستدعاء عبر الوكيل لبروتوكول ANP. باستخدام الهوية اللامركزية did:wba، قم باستدعاء أي وكيل في شبكة ANP (مثل خريطة Gaode، وحجز الفنادق، وتتبع البريد السريع، وما إلى ذلك). يتم تشغيل هذه المهارة عندما يذكر المستخدم ANP، أو يستدعي وكيلًا، أو يحجز فندقًا، أو يفحص البريد السريع، أو يفحص الخريطة، أو تخطيط الطريق.
