Compétence d’invocation inter-agents du protocole ANP. À l'aide de l'identité décentralisée did:wba, invoquez n'importe quel agent du réseau ANP (tel que Gaode Map, réservation d'hôtel, suivi de messagerie, etc.). Cette compétence est déclenchée lorsque l'utilisateur mentionne ANP, appelle un agent, réserve un hôtel, vérifie un coursier, vérifie une carte ou planifie un itinéraire.
