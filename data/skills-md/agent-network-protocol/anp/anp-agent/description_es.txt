El protocolo ANP permite la invocación de habilidades entre agentes. Utilizando la identidad descentralizada did:wba, llama a cualquier Agente de la red ANP (como Amap, reserva de hotel, consulta de entrega urgente, etc.). Esta habilidad se activa cuando los usuarios mencionan ANP, invocan a un agente, reservan un hotel, consultan entrega urgente, consultan mapas o planifican rutas.
