Habilidad de invocación entre agentes del protocolo ANP. Usando la identidad descentralizada did:wba, invoque cualquier Agente en la red ANP (como Gaode Map, reserva de hotel, seguimiento de mensajería, etc.). Esta habilidad se activa cuando el usuario menciona ANP, invoca a un agente, reserva un hotel, consulta a un mensajero, consulta un mapa o planifica una ruta.
