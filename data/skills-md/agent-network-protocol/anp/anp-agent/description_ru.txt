Навык межагентного вызова протокола ANP. Используя децентрализованную идентификацию Did:wba, вызовите любого агента в сети ANP (например, карту Gaode, бронирование отелей, отслеживание курьеров и т. д.). Этот навык срабатывает, когда пользователь упоминает ANP, вызывает агента, бронирует отель, проверяет курьера, проверяет карту или планирует маршрут.
