Créez une pull request à partir des modifications mises en œuvre avec une divulgation, une attribution, des étiquettes et des liens de problème appropriés en matière d'IA. Écrit l'artefact pr-record.yml. Nécessite TOUJOURS un examen humain de la description complète du diff et du PR avant la soumission (Porte 2). Déclencheurs sur : « soumettre un PR », « créer un PR », « ouvrir une demande d'extraction », « modifier par poussée », « soumettre une contribution », « faire un PR », « envoyer une PR », « créer une demande d'extraction ». Utilisez cette compétence chaque fois que l'utilisateur souhaite soumettre ses modifications mises en œuvre sous forme de demande d'extraction à un projet open source.
