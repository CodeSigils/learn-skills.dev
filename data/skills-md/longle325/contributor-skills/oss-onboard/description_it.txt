Clona un repository open source, estrai architettura, convenzioni e norme di contributo, quindi localizza il problema di destinazione nel codice pertinente. Crea un artefatto repo-context.yml completo per le competenze downstream. Si attiva su: "repo integrato", "comprendi la base di codice", "convenzioni di estrazione", "localizza problema", "analisi del repository", "configurazione del contributo", "analisi della base di codice", "impostazione del contributo", "lettura del contributo". Utilizza questa competenza ogni volta che l'utente desidera comprendere una base di codice open source non familiare, anche se non dice "onboard".
