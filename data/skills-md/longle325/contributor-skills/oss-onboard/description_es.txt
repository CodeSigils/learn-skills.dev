Clone un repositorio de código abierto, extraiga la arquitectura, las convenciones y las normas de contribución y luego localice el problema de destino en el código relevante. Crea un artefacto repo-context.yml completo para habilidades posteriores. Activadores en: 'repositorio integrado', 'comprender la base del código', 'extraer convenciones', 'localizar el problema', 'análisis del repositorio', 'configurar la contribución', 'analizar la base del código', 'configurar la contribución', 'leer la contribución'. Utilice esta habilidad siempre que el usuario quiera comprender una base de código abierto desconocida, incluso si no dice "integrado".
