Clonez un référentiel open source, extrayez l'architecture, les conventions et les normes de contribution, puis localisez le problème cible dans le code pertinent. Crée un artefact repo-context.yml complet pour les compétences en aval. Déclencheurs sur : « dépôt intégré », « comprendre la base de code », « extraire les conventions », « localiser le problème », « analyse du référentiel », « configurer la contribution », « analyser la base de code », « configuration de la contribution », « lire la contribution ». Utilisez cette compétence chaque fois que l'utilisateur souhaite comprendre une base de code open source inconnue, même s'il ne dit pas « intégré ».
