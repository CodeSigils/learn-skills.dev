Implementieren Sie einen Fix oder eine Funktion in einem gespaltenen Open-Source-Repository gemäß den extrahierten Konventionen und der Architektur. Führt eine Verifizierungsschleife aus (lint, typecheck, test, build), überprüft das Diff selbst und schreibt change-summary.md. Wird ausgelöst bei: „Fix implementieren“, „Funktion implementieren“, „Code schreiben“, „Fehler beheben“, „Änderung vornehmen“, „Code beisteuern“, „Problem lösen“, „Fix codieren“. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Änderungen für ein von ihm identifiziertes Open-Source-Problem implementieren möchte.
