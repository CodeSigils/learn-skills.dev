Orchestrator für offene Analyseanfragen. Verwenden Sie diese Option, wenn der Benutzer eine Geschäftsfrage und einen Datensatz hat, aber nicht festgelegt hat, welcher Analysetyp ausgeführt werden soll. Führt immer zuerst die Datenqualitätsprüfung → explorative Datenanalyse durch, wählt dann dynamisch eine beliebige Kombination von Diagnosefähigkeiten basierend auf den EDA-Ergebnissen aus und schließt mit einem Stakeholder-Memo ab.
