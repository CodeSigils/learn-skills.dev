Оркестратор для запросов открытой аналитики. Используйте, когда у пользователя есть бизнес-вопрос и набор данных, но он не определил, какой тип анализа запускать. Всегда сначала запускает проверку качества данных → исследовательский анализ данных, затем динамически выбирает любую комбинацию диагностических навыков на основе результатов EDA и завершает памяткой для заинтересованных сторон.
