Boucle de diagnostic disciplinée pour les bugs majeurs et les régressions de performances. Reproduire → minimiser → émettre une hypothèse → instrument → corriger → test de régression. À utiliser lorsque l'utilisateur dit "diagnostiquer ceci" / "déboguer ceci", signale un bug, dit que quelque chose est cassé/lance/échoue, ou décrit une régression des performances.
