Habilidad idiomática de Rust para wgpu, programación de GPU básica, motores de juegos, renderizadores y código de sistemas de alto rendimiento. Aplica principios de programación funcional (pureza, composición, tipos algebraicos, abstracciones de costo cero) sin sacrificar nunca el rendimiento del tiempo de ejecución. Utilice esta habilidad siempre que el usuario solicite escribir código Rust que involucre wgpu, canalizaciones de GPU, pases de renderizado, sombreadores de cómputo, ECS, bucles de juegos, sistemas en tiempo real, código de rendimiento básico o cualquier proyecto de Rust donde el rendimiento sea una limitación estricta. También se activa cuando el usuario solicita revisiones de código Rust, refactorizaciones o consejos de arquitectura donde los modismos funcionales y el rendimiento deben coexistir. Se activa incluso cuando el usuario no menciona explícitamente "funcional": si pega código Rust que toca wgpu::Device, wgpu::Queue, wgpu::CommandEncoder o cualquier tipo de recurso de GPU, use esta habilidad. Se activa en menciones de: wgpu, winit, WGSL, canalización de procesamiento, canalización de cómputo, grupo de enlace, búfer de GPU, ECS, grupo (bajo nivel), Rust sin sistema operativo, copia cero, SIMD, diseño orientado a datos, compatible con caché, motor de juego, renderizador, bucle de cuadros, sombreador, búfer de vértices, búfer de índice, textura, muestreador, búfer de profundidad, despacho de cómputo, sistema de partículas, gráfico de escena, selección de frustum, renderizado instanciado, dibujo indirecto, creación de perfiles de GPU o cualquier Rust. sistema crítico para el rendimiento. También se activa cuando el usuario solicita "hacer esto más rápido", "reducir asignaciones", "optimizar este Rust", "revisar mi código Rust" o pega código Rust con asignaciones clone(), unwrap(), Box<dyn> o Vec en rutas activas que podrían beneficiarse de la refactorización funcional.
