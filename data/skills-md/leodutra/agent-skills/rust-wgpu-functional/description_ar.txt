مهارة الصدأ الاصطلاحية لـ wgpu، وبرمجة GPU المعدنية العارية، ومحركات الألعاب، والعارضين، ورموز الأنظمة عالية الأداء. يطبق مبادئ البرمجة الوظيفية - النقاء، والتركيب، والأنواع الجبرية، والتجريدات بدون تكلفة - مع عدم التضحية أبدًا بالأداء في وقت التشغيل. استخدم هذه المهارة عندما يطلب المستخدم كتابة كود Rust الذي يتضمن wgpu، أو خطوط أنابيب GPU، أو تمريرات العرض، أو تظليل الحوسبة، أو ECS، أو حلقات اللعبة، أو أنظمة الوقت الفعلي، أو كود الأداء المعدني، أو أي مشروع Rust حيث يكون الأداء قيدًا صعبًا. يتم التشغيل أيضًا عندما يطلب المستخدم مراجعات كود Rust، أو إعادة البناء، أو نصيحة حول الهندسة المعمارية حيث يجب أن تتعايش المصطلحات الوظيفية والأداء. يتم التشغيل حتى عندما لا يذكر المستخدم صراحةً "وظيفي" - إذا قام بلصق رمز Rust الذي يمس wgpu::Device، أو wgpu::Queue، أو wgpu::CommandEncoder، أو أي نوع من موارد GPU، فاستخدم هذه المهارة. تشغيل الإشارات إلى: wgpu، winit، WGSL، خط أنابيب العرض، خط أنابيب الحساب، مجموعة الربط، مخزن GPU المؤقت، ECS، السرب (المستوى المنخفض)، الصدأ المعدني العاري، نسخة صفرية، SIMD، صديق ذاكرة التخزين المؤقت، تصميم موجه نحو البيانات، محرك اللعبة، العارض، حلقة الإطار، التظليل، المخزن المؤقت الرأسي، المخزن المؤقت للفهرس، الملمس، العينات، المخزن المؤقت العميق، إرسال الحساب، نظام الجسيمات، الرسم البياني للمشهد، إعدام الإحباط، العرض المثبت، السحب غير المباشر، أو ملفات تعريف GPU، أو أي نظام مهم للأداء من Rust. يتم التشغيل أيضًا عندما يطلب المستخدم "جعل هذا أسرع"، أو "تقليل التخصيصات"، أو "تحسين هذا الصدأ"، أو "مراجعة كود Rust الخاص بي"، أو لصق كود Rust باستخدام تخصيصات clone() أو unwrap() أو Box<dyn> أو Vec في المسارات الساخنة التي يمكن أن تستفيد من إعادة البناء الوظيفية.
