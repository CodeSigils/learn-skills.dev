Идиоматические навыки Rust для wgpu, программирования графических процессоров, игровых движков, рендереров и высокопроизводительного системного кода. Применяет принципы функционального программирования — чистоту, композицию, алгебраические типы, абстракции с нулевой стоимостью — не жертвуя при этом производительностью во время выполнения. Используйте этот навык всякий раз, когда пользователь просит написать код Rust, включающий wgpu, конвейеры графического процессора, проходы рендеринга, вычислительные шейдеры, ECS, игровые циклы, системы реального времени, код производительности «голого железа» или любой проект Rust, где производительность является жестким ограничением. Также срабатывает, когда пользователь запрашивает обзоры кода Rust, рефакторинг или советы по архитектуре, где функциональные идиомы и производительность должны сосуществовать. Срабатывает, даже если пользователь явно не упоминает «функциональность» — если он вставляет код Rust, который касается wgpu::Device, wgpu::Queue, wgpu::CommandEncoder или любого типа ресурса графического процессора, используйте этот навык. Триггер при упоминании: wgpu, winit, WGSL, конвейер рендеринга, вычислительный конвейер, группа привязки, буфер графического процессора, ECS, bevy (низкоуровневый), голое железо Rust, нулевое копирование, SIMD, дружественный к кэшу, ориентированный на данные дизайн, игровой движок, рендеринг, цикл кадров, шейдер, буфер вершин, буфер индексов, текстура, сэмплер, буфер глубины, диспетчеризация вычислений, система частиц, граф сцены, отсечение по усеченному принципу, экземплярный рендеринг, непрямая отрисовка, Профилирование графического процессора или любая другая система Rust, критичная к производительности. Также срабатывает, когда пользователь просит «сделать это быстрее», «уменьшить выделение», «оптимизировать этот Rust», «проверить мой код Rust» или вставить код Rust с помощью clone(), unwrap(), Box<dyn> или выделений Vec в горячие пути, которые могут выиграть от функционального рефакторинга.
