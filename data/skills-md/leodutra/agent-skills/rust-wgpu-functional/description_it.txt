Abilità Idiomatic Rust per wgpu, programmazione GPU bare metal, motori di gioco, renderer e codice di sistemi ad alte prestazioni. Applica i principi di programmazione funzionale (purezza, composizione, tipi algebrici, astrazioni a costo zero) senza mai sacrificare le prestazioni di runtime. Usa questa abilità ogni volta che l'utente chiede di scrivere codice Rust che coinvolga wgpu, pipeline GPU, passaggi di rendering, shader di calcolo, ECS, loop di gioco, sistemi in tempo reale, codice di prestazioni bare metal o qualsiasi progetto Rust in cui le prestazioni sono un vincolo difficile. Si attiva anche quando l'utente richiede revisioni del codice Rust, refactoring o consigli sull'architettura in cui idiomi funzionali e prestazioni devono coesistere. Si attiva anche quando l'utente non menziona esplicitamente "funzionale" — se incolla il codice Rust che tocca wgpu::Device, wgpu::Queue, wgpu::CommandEncoder o qualsiasi tipo di risorsa GPU, usa questa abilità. Attivazione su menzioni di: wgpu, winit, WGSL, pipeline di rendering, pipeline di calcolo, gruppo di associazione, buffer GPU, ECS, bevy (basso livello), bare-metal Rust, zero-copy, SIMD, cache-friendly, progettazione orientata ai dati, motore di gioco, renderer, frame loop, shader, vertex buffer, buffer indice, texture, campionatore, buffer di profondità, invio di calcolo, sistema di particelle, grafico della scena, frustum culling, rendering istanziato, disegno indiretto, GPU profilazione o qualsiasi sistema Rust critico per le prestazioni. Si attiva anche quando l'utente chiede di "renderlo più veloce", "ridurre le allocazioni", "ottimizzare questo Rust", "rivedere il mio codice Rust" o incolla il codice Rust con le allocazioni clone(), unwrap(), Box<dyn> o Vec in percorsi attivi che potrebbero trarre vantaggio dal refactoring funzionale.
