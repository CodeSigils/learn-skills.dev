wgpu、ベアメタル GPU プログラミング、ゲーム エンジン、レンダラ、および高性能システム コードのための慣用的な Rust スキル。実行時のパフォーマンスを決して犠牲にすることなく、関数型プログラミングの原則 (純粋性、合成、代数型、ゼロコスト抽象化) を適用します。ユーザーが、wgpu、GPU パイプライン、レンダー パス、コンピューティング シェーダー、ECS、ゲーム ループ、リアルタイム システム、ベアメタル パフォーマンス コード、またはパフォーマンスが厳しい制約となる Rust プロジェクトを含む Rust コードの作成を要求する場合は常に、このスキルを使用します。また、機能的イディオムとパフォーマンスが共存する必要がある Rust コードのレビュー、リファクタリング、またはアーキテクチャのアドバイスをユーザーが要求したときにもトリガーされます。ユーザーが「機能的」と明示的に言及していない場合でもトリガーします。wgpu::Device、wgpu::Queue、wgpu::CommandEncoder、または任意の GPU リソース タイプに触れる Rust コードを貼り付ける場合は、このスキルを使用します。次の言及でトリガー: wgpu、winit、WGSL、レンダー パイプライン、コンピューティング パイプライン、バインド グループ、GPU バッファー、ECS、bevy (低レベル)、ベアメタル Rust、ゼロコピー、SIMD、キャッシュ フレンドリー、データ指向設計、ゲーム エンジン、レンダラー、フレーム ループ、シェーダー、頂点バッファー、インデックス バッファー、テクスチャ、サンプラー、深度バッファー、コンピューティング ディスパッチ、パーティクル システム、シーン グラフ、錐台カリング、インスタンス化レンダリング、間接描画、GPU プロファイリング、または Rust のパフォーマンスが重要なシステム。また、ユーザーが「これを高速化する」、「割り当てを減らす」、「この Rust を最適化する」、「Rust コードを確認する」などの要求をした場合、または関数リファクタリングの恩恵を受ける可能性があるホット パスに clone()、unwrap()、Box<dyn>、または Vec 割り当てを使用して Rust コードを貼り付けた場合にもトリガーされます。
