Compétence Idiomatic Rust pour wgpu, la programmation GPU nue, les moteurs de jeu, les moteurs de rendu et le code des systèmes hautes performances. Applique les principes de programmation fonctionnelle (pureté, composition, types algébriques, abstractions sans coût) sans jamais sacrifier les performances d'exécution. Utilisez cette compétence chaque fois que l'utilisateur demande à écrire du code Rust impliquant wgpu, des pipelines GPU, des passes de rendu, des shaders de calcul, ECS, des boucles de jeu, des systèmes en temps réel, du code de performance nu ou tout projet Rust où les performances sont une contrainte importante. Se déclenche également lorsque l'utilisateur demande des révisions de code Rust, des refactors ou des conseils d'architecture où les idiomes fonctionnels et les performances doivent coexister. Déclenchez même lorsque l'utilisateur ne mentionne pas explicitement "fonctionnel" - s'il colle du code Rust qui touche wgpu::Device, wgpu::Queue, wgpu::CommandEncoder ou tout autre type de ressource GPU, utilisez cette compétence. Déclenchement sur les mentions de : wgpu, winit, WGSL, pipeline de rendu, pipeline de calcul, groupe de liaison, tampon GPU, ECS, bevy (bas niveau), Rust bare-metal, zéro copie, SIMD, compatible avec le cache, conception orientée données, moteur de jeu, moteur de rendu, boucle d'image, shader, tampon de sommet, tampon d'index, texture, échantillonneur, tampon de profondeur, répartition de calcul, système de particules, graphique de scène, élimination de frustum, rendu instancié, dessin indirect, profilage GPU ou tout Rust système critique en termes de performances. Se déclenche également lorsque l'utilisateur demande de "rendre cela plus rapide", "réduire les allocations", "optimiser ce Rust", "revoir mon code Rust" ou colle le code Rust avec les allocations clone(), unwrap(), Box<dyn> ou Vec dans des chemins chauds qui pourraient bénéficier d'une refactorisation fonctionnelle.
