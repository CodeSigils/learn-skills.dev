应用现代架构蓝图（2026），这是一种用于设计长期软件系统的务实的领域优先方法。涵盖模块化整体、垂直切片功能文件夹、类型驱动的域建模（新类型、值对象、解析不验证、使非法状态不可表示）、策略、域事件、显式一致性模型、幂等性、功能核心/命令外壳、架构适应度函数和 ADR。每当用户设计、搭建、构建、重构或审查后端或全栈系统的架构时，都可以使用此技能；决定文件夹或模块布局；权衡存储库、CQRS、微服务或事件源等抽象概念；建模业务领域；或决定模块应如何通信。即使从未使用过“架构”一词，也可以针对“我应该如何构建此服务”、“此代码应该放在哪里”或“这是过度设计的”等问题触发它。尤其与 TypeScript/Node、Rust 和 Python 服务相关。
