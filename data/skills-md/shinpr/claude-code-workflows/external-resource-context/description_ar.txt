يلتقط ويستمر في الوصول إلى طرق الوصول للموارد خارج المستودع (مصدر التصميم، نظام التصميم، مخطط واجهة برمجة التطبيقات، مصدر IaC، المتجر السري) حتى يتمكن العمل النهائي من الوصول إليها بشكل حتمي. يُستخدم عندما يعتمد العمل على موارد خارجية، أو عندما يذكر المستخدم مصدر التصميم، أو نظام التصميم، أو مخطط واجهة برمجة التطبيقات، أو مصدر IaC، أو المتجر السري، أو المصدر الأساسي.
