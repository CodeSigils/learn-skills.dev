Captura y mantiene los métodos de acceso a recursos fuera del repositorio (fuente de diseño, sistema de diseño, esquema API, fuente IaC, almacén secreto) para que el trabajo posterior pueda llegar a ellos de manera determinista. Úselo cuando el trabajo dependa de recursos externos o cuando el usuario mencione la fuente de diseño, el sistema de diseño, el esquema de API, la fuente de IaC, el almacén secreto o la fuente canónica.
