Test Guardian setzt die Testdisziplin durch. Verwenden Sie es, wenn Sie Code ändern, Fehler beheben, Funktionen hinzufügen oder vor der PR-Einreichung. Löst einen 4-Phasen-Testworkflow aus und verhindert den Versand von ungetestetem Code. Auslösen bei „Fix“, „Feature hinzufügen“, „Refactor“, „修复“, „新增功能“, „重构“.
