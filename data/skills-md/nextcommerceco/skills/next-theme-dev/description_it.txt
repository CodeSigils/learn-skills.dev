Successivo Sviluppo di temi commerciali per Spark, Intro Bootstrap e personalizzati
temi del negozio. Da utilizzare durante la creazione, la modifica o il debug di temi con
Linguaggio modello Django, Impostazioni tema, CLI ntk, GraphQL vetrina,
Componenti Web Tailwind/Spark o modelli Intro Bootstrap/SCSS. Anche usare
dopo che next-theme-figma ha preparato un pacchetto di consegna della vetrina Figma.
Si attiva quando si lavora in una directory di temi con manifest.json, config.yml o
directory standard come asset/, configs/, layout/, templates/ e
parziali/.
