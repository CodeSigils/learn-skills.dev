تطوير سمة التجارة التالية لـ Spark وIntro Bootstrap والتخصيص
موضوعات واجهة المتجر. يُستخدم عند إنشاء السمات أو تعديلها أو تصحيح أخطائها باستخدام
لغة قالب Django، إعدادات السمة، ntk CLI، واجهة المتجر GraphQL،
مكونات الويب Tailwind/Spark، أو أنماط مقدمة Bootstrap/SCSS. استخدم أيضًا
بعد أن قامت Next-theme-Figma بإعداد حزمة التسليم لواجهة متجر Figma.
يتم تشغيله عند العمل في دليل السمات باستخدام البيان.json، أو config.yml، أو
الدلائل القياسية مثل الأصول/، والتكوينات/، والتخطيطات/، والقوالب/، و
جزئيات/.
