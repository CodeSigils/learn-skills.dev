Используйте, если вам нужна авторизованная неразрушающая проверка безопасности репозиториев, API и облачных приложений. Запуск проверок OWASP, аудитов зависимостей/секретов, консолидации сканеров и отчетов о безопасности. Используйте для сортировки AppSec. НЕ используйте для несанкционированного использования или несанкционированного тестирования.
