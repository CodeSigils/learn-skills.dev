Gérer le système de documentation eo-doc/côté code (init / modifier / sync) : maintenir changes/INDEX.md, la section de spécification de l'agent-handbook/ et des modèles/ ; lorsque `state.enabled`, effectuez une régénération incrémentielle du curseur pour la section état/statut. Toutes les opérations de maintenance documentaire sous eo-doc doivent passer par cette compétence. Déclencheurs : initialiser la documentation / modifier la documentation / organiser la documentation / synchroniser la documentation / /eo-doc-manager. PAS POUR : interroger ou expliquer le contenu d’un document (utilisez /eo-recall).
