El único punto de entrada para la metodología de reparación de defectos: informar verbalmente un error, localizarlo y solucionarlo directamente; Las correcciones de retroalimentación dentro del ciclo de implementación-prueba-revisión también pasan por esta habilidad (ramificación dentro del ciclo, realizada por el trabajador impl original). Desencadenantes: corregir un error / hay un error / ocurrió un error / el comportamiento es incorrecto / corregir / /eo-fix. NO PARA: cambios comerciales explícitos (use /eo-change).
