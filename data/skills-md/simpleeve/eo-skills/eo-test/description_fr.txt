Perspective de test indépendant à la demande : lorsqu'un signal de risque est déclenché ou qu'un utilisateur signale spécifiquement un problème, effectuez un audit de test, comblez les lacunes et revalidez le changement mis en œuvre, produisant ainsi un test.md concis. La modification du code commercial est strictement interdite. Déclencheurs : trouver une deuxième paire d'yeux pour exécuter des tests/vérification indépendante/ajouter des tests pour ce changement//eo-test.  

PAS POUR : exécutions de tests de routine ou tests unitaires supplémentaires sans rapport avec le changement (faites-les simplement directement, aucun rapport n'est nécessaire) ; autovérification principale par défaut (classée sous eo-implement).
