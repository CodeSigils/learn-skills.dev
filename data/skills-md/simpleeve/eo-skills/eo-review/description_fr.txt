Examen du code à la demande : lorsqu'un signal de risque est déclenché ou qu'un utilisateur l'appelle, effectuez une vérification ligne par ligne du code implémenté par rapport aux critères d'acceptation ainsi qu'un examen de la qualité du code et produisez un review.md concis (P0/P1/P2). Déclencheurs : révision / révision du code / demander à une autre paire d'yeux de regarder / /eo-review.  
PAS POUR : la révision du plan de changement (/eo-change-review, utilisé lorsque le code n'a pas encore été écrit) ; chemin principal par défaut (pas obligatoire lorsqu'il n'y a pas de signal).
