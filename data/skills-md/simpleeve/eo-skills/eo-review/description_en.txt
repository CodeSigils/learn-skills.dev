On-demand code review: when a risk signal is triggered or a user calls it out, perform a line‑by‑line verification of the implemented code against the acceptance criteria plus a code quality review, and produce a concise review.md (P0/P1/P2). Triggers: review / code review / ask another pair of eyes to look / /eo-review.  
NOT FOR: change plan review (/eo-change-review, used when the code hasn't been written yet); default main path (not mandatory when there is no signal).
