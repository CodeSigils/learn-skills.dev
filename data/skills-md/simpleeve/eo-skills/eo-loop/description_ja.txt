eo プロセス マスター コントロール: ユーザーの意図に基づいて、セグメント (エントリ ノード → 出口ノード → 収束基準) をカプセル化し、eo-change / eo-implement / eo-archive およびオプションのゲート (eo-change-review / eo-test / eo-review) をプラガブル実行ベースにディスパッチして、ウィンドウ化された進行状況レポートを使用して収束に向けて進みます。トリガー: eo-loop / チェーン実行 / 収束へのループの進行 / マスター スケジューリング / /eo-loop。

対象外: シングルポイント アクション (対応する eo-* スキルを直接呼び出す)。さらなる監視なしで完全にハンドオフします (orca-cli フルハンドオフ)。バグスプレー (/eo-fix)。
