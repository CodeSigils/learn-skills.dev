Используйте этот навык для получения рыночных данных внутри сети: цен на токены, рейтингов лучших трейдеров, социальных сетей и сигналов. **Триггерные сценарии**:  
- Пользователь упоминает dexscan  
- Пользователь упоминает цены токенов, цену, рыночную капитализацию, объем, ликвидность, изменение, количество держателей.  
- Пользователь упоминает сигналы токена, максимальное усиление с момента первого сигнала, нажатие сигнала.  
- Пользователь упоминает новости о токенах, рейтинги новостей, обсуждения KOL.  
- Пользователь упоминает умные деньги и рейтинги лучших трейдеров.
