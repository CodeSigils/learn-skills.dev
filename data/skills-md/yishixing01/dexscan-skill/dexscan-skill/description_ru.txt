Используйте этот навык для получения рыночных данных внутри сети: цен на токены, списка лидеров лучших трейдеров, социальных сетей и сигналов. **Сценарии срабатывания**: - Пользователь упоминает dexscan - Пользователь упоминает цены токенов, цену, рыночную капитализацию, объем, ликвидность, изменение цены, количество держателей - Пользователь упоминает сигналы токенов, максимальную прибыль с момента первого сигнала, толчок сигнала - Пользователь упоминает шумиху о токенах, рейтинги новостей, обсуждения KOL - Пользователь упоминает умные деньги, таблицу лидеров лучших трейдеров
