مساعدة الأساتذة والباحثين في كتابة مقترحات المنح ومراجعتها وتكييفها وصقلها للوكالات الأمريكية (NSF، NIH، DOE، DARPA، NASA) والوكالات الصينية (NSFC 国自然). استخدم هذه المهارة عندما يذكر المستخدم منحًا، أو مقترحات، أو طلبات تمويل، أو مشاريع، أو R01، أو R21، أو CAREER، أو 面上، أو 青年基金، أو أهداف محددة، أو تأثيرات أوسع، أو يريد تخطيط أو صياغة أو مراجعة أو إعادة تقديم أي مقترح لتمويل بحث - حتى لو كانوا لا تقل "منحة" صراحةً. استخدم هذه المهارة أيضًا عندما يريد المستخدم تعديل اقتراح سابق لتقديم جديد. سير العمل على ست مراحل: التنميط ← التخطيط ← الصياغة ← مراجعة الجودة ← محاكاة مراجعة النظراء ← إعداد التقديم.
