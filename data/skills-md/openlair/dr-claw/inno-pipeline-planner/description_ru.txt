Проводит пользователя через интерактивный диалог, чтобы определить его исследовательский проект, затем генерирует Research_brief.json и Tasks.json. Используйте при запуске нового проекта, когда файл Research_brief.json не существует, когда пользователь хочет начать с определенного этапа конвейера или когда пользователь хочет переопределить свой конвейер исследований.
