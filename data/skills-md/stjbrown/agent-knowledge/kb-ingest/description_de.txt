Nehmen Sie eine Quelle in das Wissensbündel auf. Verwenden Sie diese Option, wenn der Benutzer dies – eine Notiz, ein Transkript, eine E-Mail, ein PDF, ein Bild, eine Webseite oder eine beliebige Rohquelle – in einem Wissens-/Bundle erfassen, aufnehmen, ablegen, verarbeiten oder „hinzufügen“ möchte oder Inhalte zur Verarbeitung ablegt. Liest die Quelle einmal, extrahiert ihr Signal und integriert es im gesamten Paket unter dem Vertrauensmodell, sodass Wissen zusammengeführt wird, anstatt pro Abfrage neu abgeleitet zu werden.
