استيعاب مصدر في حزمة المعرفة. يُستخدم عندما يريد المستخدم التقاط أو استيعاب أو ملف أو معالجة أو "إضافة هذا" - ملاحظة أو نص أو بريد إلكتروني أو ملف PDF أو صورة أو صفحة ويب أو أي مصدر أولي - إلى معرفة/حزمة، أو يسقط المحتوى للمعالجة. يقرأ المصدر مرة واحدة، ويستخرج إشارته، ويدمجها عبر الحزمة ضمن نموذج الثقة بحيث يتم تجميع المعرفة بدلاً من إعادة اشتقاقها لكل استعلام.
