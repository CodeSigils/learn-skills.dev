Ingérez une source dans l’ensemble de connaissances. À utiliser lorsque l'utilisateur souhaite capturer, ingérer, classer, traiter ou « ajouter ceci » (une note, une transcription, un e-mail, un PDF, une image, une page Web ou toute source brute) dans une connaissance/un ensemble, ou supprimer du contenu pour le traitement. Lit la source une fois, extrait son signal et l'intègre dans l'ensemble sous le modèle de confiance afin que les connaissances se composent au lieu d'être redirigées par requête.
