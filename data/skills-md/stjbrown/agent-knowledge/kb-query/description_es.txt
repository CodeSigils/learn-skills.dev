Respuesta del paquete de conocimientos. Úselo cuando el usuario pregunta qué sabe él o el proyecto sobre algo, quiere buscar algo, explorar conexiones o comparar cosas que se encuentran en un conocimiento/paquete, y cuando cualquier tarea se base en un paquete existente, consúltelo aquí antes de responder desde cero. Navega mediante divulgación progresiva y archiva respuestas valiosas para que el paquete se complique.
