Paquete de conocimientos OKF portátil para memoria de agente de codificación y wikis LLM. Úselo cuando el usuario quiera iniciar una wiki, ingerir una fuente, documentar un repositorio, consultar el conocimiento del proyecto con citas, buscar derivas o visualizar conexiones; siempre que un repositorio tenga un conocimiento/paquete que deba informar la tarea; y cuando otra habilidad kb-* necesita la especificación, el glosario, las plantillas o el modelo de confianza compartidos.
