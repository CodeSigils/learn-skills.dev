Documente y actualice un repositorio de software en un paquete de conocimientos OKF. Úselo cuando el usuario solicite documentar este repositorio, código base, arquitectura, flujos de trabajo del desarrollador o comportamiento operativo; crear conocimiento de repositorio; o actualizar la documentación del repositorio existente después de cambios de código. Trata el repositorio como evidencia viva de solo lectura en lugar de material fuente para copiar o retirar.
