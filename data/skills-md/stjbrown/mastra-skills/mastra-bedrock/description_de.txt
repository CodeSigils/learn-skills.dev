Verwenden Sie Amazon Bedrock als Modellanbieter für einen Mastra-Agenten und stellen Sie Mastra-Agenten auf AWS Bedrock AgentCore bereit. Verwenden Sie diese Option, wenn jemand möchte, dass ein Mastra-Agent auf Bedrock/AWS ausgeführt wird, Claude auf Bedrock, createAmazonBedrock, fromNodeProviderChain oder AgentCore-Bereitstellung erwähnt.
