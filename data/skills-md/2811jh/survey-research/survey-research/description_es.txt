Realice un análisis automatizado de proceso completo de los datos sin procesar del cuestionario, incluidas estadísticas básicas (distribución de frecuencia + descripción general demográfica), análisis cruzado (comparación de diferencias entre diferentes grupos) y análisis de texto (que resumen temas de preguntas abiertas). Admite dos fuentes de datos: los usuarios proporcionan archivos CSV/Excel locales o los descargan directamente desde el sistema de cuestionarios utilizando el ID/nombre del cuestionario (con soporte de limpieza) para el análisis. Genere un informe resumido de Markdown + un informe de análisis de Word (predeterminado), con soporte para conversión al formato Excel/TXT. Se activa cuando el usuario solicita el análisis de los datos del cuestionario, la generación de informes de investigación del cuestionario, la comparación de diferencias entre diferentes grupos o el análisis de contenido de texto abierto. Incluso si el usuario no menciona explícitamente "cuestionario", siempre que involucre escenarios como análisis de datos de investigación, análisis de comentarios de usuarios, análisis de satisfacción, análisis NPS, etc., esta habilidad debe activarse. Cuando el usuario dice "descargar y analizar el cuestionario", "limpiar el cuestionario y luego generar el informe", "ayúdame a descargar el cuestionario 90450", "descargar datos del cuestionario nacional", "extraer datos del sistema de cuestionarios" u otros escenarios que impliquen descarga + análisis, también debería activarse. Asegurar el uso cuando el usuario diga "ayúdame a analizar este cuestionario", "analizar diferencias por género", "por favor incorporar análisis de preguntas de texto", "descargar cuestionario 90450 y luego analizar", "limpiar y exportar cuestionario", o expresiones similares.
