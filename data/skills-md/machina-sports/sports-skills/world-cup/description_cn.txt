高级 FIFA 2026 世界杯市场和比赛情报 — 托管、只读
融合官方比赛真相的层（赛程、积分榜、球队、伤病情况、
玩家表现）和实时预测市场（Kalshi + Polymarket：价格，
订单簿、价格历史记录、移动者、跨场地边缘）和基于人工智能的背景
（赛前简报、动作解释、球迷/社交脉搏）。每个实体都携带一个
规范的机器 URN 横跨 api-football、sportradar、opta、entain
和 ESPN，因此一个市场决定一场比赛，决定两支球队。

该技能仅限提示且高级：它将代理引导至主办的世界杯
通过“machina-cli”的情报项目（每个项目的 Machina MCP 服务器）。它运行
本地没有代码，也没有 API 密钥。

使用时间：用户想要将 2026 年世界杯赔率 + 比赛上下文放在一起，询问“什么”
感动以及为什么”，想要一份接地气的市场简报或球迷情绪读物，
或者需要一个稳定的 ID 来加入市场 ↔ 赛程 ↔ 跨提供商的团队。
不要在以下情况下使用：用户想要从公共 API 获取免费快照数据（使用
“足球数据”、“kalshi”、“polymarket”或“markets”技能），或者想要放置
投注/交易——这一层是只读情报层，从不执行订单。
