高級 FIFA 2026 世界盃市場與比賽情報 — 託管、唯讀
融合官方比賽真相的層次（賽程、積分榜、球隊、傷兵狀況、
玩家表現）和即時預測市場（Kalshi + Polymarket：價格，
訂單簿、價格歷史記錄、移動者、跨場地邊緣）和基於人工智慧的背景
（賽前簡報、動作解釋、球迷/社交脈搏）。每個實體都攜帶一個
規範的機器 URN 橫跨 api-football、sportradar、opta、entain
和 ESPN，因此一個市場決定一場比賽，決定兩支球隊。

該技能僅限提示且高級：它將代理引導至主辦的世界杯
透過「machina-cli」的情報項目（每個項目的 Machina MCP 伺服器）。它運行
本機沒有程式碼，也沒有 API 金鑰。

使用時間：用戶想要將 2026 年世界盃賠率 + 比賽上下文放在一起，詢問“什麼”
感動以及為什麼”，想要一份接地氣的市場簡報或球迷情緒讀物，
或需要一個穩定的 ID 來加入市場 ↔ 賽程 ↔ 跨提供者的團隊。
不要在以下情況下使用：使用者想要從公共 API 取得免費快照資料（使用
「足球數據」、「kalshi」、「polymarket」或「markets」技能），或想要放置
投注/交易－這一層是唯讀情報層，從不執行訂單。
