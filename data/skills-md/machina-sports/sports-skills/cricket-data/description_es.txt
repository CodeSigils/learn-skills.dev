Datos de cricket a través de puntos finales públicos de ESPN y datos abiertos de Cricsheet: marcadores de series en vivo, clasificaciones, resúmenes de partidos y noticias (ESPN), además de historial histórico bola por bola, estadísticas de jugadores y registro de jugadores (Cricsheet, ODC-BY 1.0). Configuración cero, sin claves API.

Úselo cuando: el usuario pregunta sobre puntajes de cricket, IPL/BBL/PSL/series internacionales, tablas de puntos, detalles de partidos, noticias de cricket, historial bola por bola o estadísticas de carrera de jugador.
No lo use cuando: el usuario pregunta sobre otros deportes: use datos de fútbol (fútbol), datos de nfl (NFL), datos de nba (NBA), datos de wnba (WNBA), datos de nhl (NHL), datos de mlb (MLB), datos de tenis (tenis), datos de golf (golf), datos de cfb (fútbol universitario), datos de cbb (baloncesto universitario) o fastf1 (F1). Para las probabilidades de apuestas, utilice Polymarket o Kalshi. Para noticias generales utilice noticias deportivas. No lo utilice para clasificaciones ICC: no existe una fuente gratuita (limitación de v1).
