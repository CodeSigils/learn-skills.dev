透過 ESPN 公共端點和 Cricsheet 開放資料提供的板球資料 — 即時系列記分板、排名、比賽摘要和新聞 (ESPN)，以及歷史逐球資料、球員統計資料和球員註冊表（Cricsheet、ODC-BY 1.0）。零配置，無 API 金鑰。

使用場合：使用者詢問板球比分、IPL/BBL/PSL/國際系列賽、積分錶、比賽詳細資訊、板球新聞、逐球歷史或球員職業統計數據。
不要在以下情況下使用：使用者詢問其他運動 — 使用 Football-data（英式足球）、nfl-data（NFL）、nba-data（NBA）、wnba-data（WNBA）、nhl-data（NHL）、mlb-data（MLB）、tennis-data（網球）、golf-data（高爾夫）、cfb-data（大學橄欖球）。對於投注賠率，請使用 Polymarket 或 kalshi。對於一般新聞，請使用體育新聞。請勿用於 ICC 排名 - 不存在免費來源（v1 限制）。
