Données de cricket via les points de terminaison publics ESPN et les données ouvertes Cricsheet : tableaux de bord des séries en direct, classements, résumés et actualités des matchs (ESPN), ainsi que l'historique balle par balle, les statistiques des joueurs et le registre des joueurs (Cricsheet, ODC-BY 1.0). Zéro configuration, pas de clés API.

À utiliser lorsque : l'utilisateur pose des questions sur les scores de cricket, les séries IPL/BBL/PSL/internationales, les tableaux de points, les détails des matchs, les actualités du cricket, l'historique balle par balle ou les statistiques de carrière des joueurs.
Ne pas utiliser lorsque : l'utilisateur pose des questions sur d'autres sports - utilisez les données de football (soccer), les données de nfl (NFL), les données de nba (NBA), les données de wnba (WNBA), les données de nhl (NHL), les données de mlb (MLB), les données de tennis (tennis), les données de golf (golf), les données de cfb (football universitaire), les données de cbb (basketball universitaire) ou fastf1 (F1). Pour les cotes de paris, utilisez Polymarket ou Kalshi. Pour les actualités générales, utilisez les actualités sportives. Ne pas utiliser pour les classements ICC — aucune source gratuite n'existe (limitation de la version v1).
