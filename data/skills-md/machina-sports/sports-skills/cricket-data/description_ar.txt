بيانات الكريكيت عبر نقاط النهاية العامة ESPN وبيانات Cricsheet المفتوحة - لوحات النتائج المتسلسلة الحية والترتيب وملخصات المباريات والأخبار (ESPN)، بالإضافة إلى الكرة التاريخية وإحصائيات اللاعب وسجل اللاعبين (Cricsheet, ODC-BY 1.0). تكوين صفر، لا توجد مفاتيح API.

يُستخدم عندما: يسأل المستخدم عن نتائج لعبة الكريكيت، أو سلسلة IPL/BBL/PSL/الدولية، أو جداول النقاط، أو تفاصيل المباراة، أو أخبار لعبة الكريكيت، أو تاريخ الكرة تلو الأخرى، أو إحصائيات مسيرة اللاعب.
لا تستخدم عندما: يسأل المستخدم عن الرياضات الأخرى - استخدم بيانات كرة القدم (كرة القدم)، أو بيانات nfl (NFL)، أو بيانات nba (NBA)، أو بيانات wnba (WNBA)، أو بيانات nhl (NHL)، أو بيانات mlb (MLB)، أو بيانات التنس (التنس)، أو بيانات الجولف (الجولف)، أو بيانات cfb (كرة القدم الجامعية)، أو بيانات cbb (كرة السلة الجامعية)، أو fastf1 (F1). للمراهنة على الاحتمالات، استخدم polymarket أو kalshi. للحصول على الأخبار العامة، استخدم الأخبار الرياضية. لا تستخدمه لتصنيفات ICC — لا يوجد مصدر مجاني (حدود الإصدار الأول).
