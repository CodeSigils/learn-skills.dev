通过 ESPN 公共端点和 Cricsheet 开放数据提供的板球数据 — 实时系列记分牌、排名、比赛摘要和新闻 (ESPN)，以及历史逐球数据、球员统计数据和球员注册表（Cricsheet、ODC-BY 1.0）。零配置，无 API 密钥。

使用场合：用户询问板球比分、IPL/BBL/PSL/国际系列赛、积分表、比赛详细信息、板球新闻、逐球历史或球员职业统计数据。
不要在以下情况下使用：用户询问其他运动 — 使用 Football-data（英式足球）、nfl-data（NFL）、nba-data（NBA）、wnba-data（WNBA）、nhl-data（NHL）、mlb-data（MLB）、tennis-data（网球）、golf-data（高尔夫）、cfb-data（大学橄榄球）、cbb-data（大学篮球）或 fastf1（F1）。对于投注赔率，请使用 Polymarket 或 kalshi。对于一般新闻，请使用体育新闻。请勿用于 ICC 排名 - 不存在免费来源（v1 限制）。
