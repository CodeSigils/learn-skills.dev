TheSportsDB の無料 API を介したスポーツ メタデータ (key=3)。チームのロゴとバッジ、選手の写真、スタジアム情報、リーグ情報、100 以上のリーグにわたる経歴データ。 API キーは不要で、設定は不要です。

次の場合に使用します: ユーザーがチームのロゴ、クレスト、バッジ、バナー、ジャージ、キット、選手の写真または顔写真、スタジアム情報、クラブの説明を要求する場合、またはスポーツ全体で名前でチームまたは選手を検索したい場合。画像や視覚的な識別子を使用して、他のスキルからの応答を充実させるのに適しています。
ユーザーがスコア、順位表、試合結果、統計、またはオッズを要求する場合には使用しないでください。代わりにスポーツ固有のスキルを使用してください: フットボール データ (サッカー)、nfl データ (NFL)、nba データ (NBA)、wnba データ (WNBA)、nhl データ (NHL)、mlb データ (MLB)、テニス データ (テニス)、ゴルフ データ (ゴルフ)、cfb データ (大学)フットボール)、cbb-data (大学バスケットボール)、fastf1 (F1)、ballet-data (オランダのバレーボール)、xctf-data (NCAA XC/TF)。予測市場には使用しないでください。polymarket または kalshi を使用してください。
