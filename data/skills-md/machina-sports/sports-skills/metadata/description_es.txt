Metadatos deportivos a través de la API gratuita de TheSportsDB (clave=3). Logotipos e insignias de equipos, fotografías de jugadores, información del estadio, información de la liga y datos biográficos de más de 100 ligas. No se requiere clave API, cero configuración.

Úselo cuando: el usuario solicita el logotipo de un equipo, escudo, insignia, pancarta, camiseta, uniforme, foto o retrato de un jugador, información del estadio, descripción del club o desea buscar equipos o jugadores por nombre en todos los deportes. Bueno para enriquecer respuestas de otras habilidades con imágenes e identificadores visuales.
No lo use cuando: el usuario solicite puntajes, clasificaciones, partidos, estadísticas o probabilidades; en su lugar, use la habilidad específica del deporte: datos de fútbol (soccer), datos de nfl (NFL), datos de nba (NBA), datos de wnba (WNBA), datos de nhl (NHL), datos de mlb (MLB), datos de tenis (tenis), datos de golf (golf), datos de cfb (fútbol universitario), datos de cbb (baloncesto universitario), fastf1 (F1), volleyball-data (voleibol holandés), xctf-data (NCAA XC/TF). No lo utilice para mercados de predicción; utilice polimercado o kalshi.
