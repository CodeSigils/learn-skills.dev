Métadonnées sportives via l'API gratuite TheSportsDB (clé = 3). Logos et badges d'équipe, photos de joueurs, informations sur le stade, informations sur la ligue et données biographiques sur plus de 100 ligues. Aucune clé API requise, aucune configuration.

À utiliser lorsque : l'utilisateur demande un logo d'équipe, un écusson, un badge, une bannière, un maillot, un kit, une photo ou une photo d'un joueur, des informations sur le stade, une description du club, ou souhaite rechercher des équipes ou des joueurs par nom dans tous les sports. Idéal pour enrichir les réponses d'autres compétences avec des images et des identifiants visuels.
Ne pas utiliser lorsque : l'utilisateur demande des scores, des classements, des calendriers, des statistiques ou des cotes – utilisez plutôt la compétence spécifique au sport : données de football (soccer), données de nfl (NFL), données de nba (NBA), données de wnba (WNBA), données de nhl (NHL), données de mlb (MLB), données de tennis (tennis), données de golf (golf), données cfb (football universitaire), données cbb (basketball universitaire), fastf1 (F1), données de volley-ball (volley-ball néerlandais), données xctf (NCAA XC/TF). Ne pas utiliser pour les marchés de prédiction – utilisez polymarket ou kalshi.
