體育元資料透過 TheSportsDB 免費 API (key=3)。 100 多個聯賽的球隊徽標和徽章、球員照片、體育場資訊、聯賽資訊和傳記資料。無需 API 金鑰，零配置。

使用場合：使用者要求提供球隊徽標、徽章、徽章、橫幅、球衣、球衣、球員照片或頭像、體育場資訊、俱樂部描述，或想要按運動項目名稱搜尋球隊或球員。適合透過影像和視覺標識符豐富其他技能的反應。
不要在以下情況下使用：使用者詢問分數、排名、賽程、統計數據或賠率 - 請使用特定於運動的技能：football-data (英式足球)、nfl-data (NFL)、nba-data (NBA)、wnba-data (WNBA)、nhl-data (NHL)、mlb-data (MLB)、Pten-data（網球）、25-data） （大學籃球）、fastf1 (F1)、排球數據（荷蘭排球）、xctf-數據 (NCAA XC/TF)。不要用於預測市場——使用 Polymarket 或 kalshi。
