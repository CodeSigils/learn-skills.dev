体育元数据通过 TheSportsDB 免费 API (key=3)。 100 多个联赛的球队徽标和徽章、球员照片、体育场信息、联赛信息和传记数据。无需 API 密钥，零配置。

使用场合：用户要求提供球队徽标、徽章、徽章、横幅、球衣、球衣、球员照片或头像、体育场信息、俱乐部描述，或者想要按运动项目名称搜索球队或球员。适合通过图像和视觉标识符丰富其他技能的反应。
不要在以下情况下使用：用户询问分数、排名、赛程、统计数据或赔率 - 请使用特定于运动的技能：football-data (英式足球)、nfl-data (NFL)、nba-data (NBA)、wnba-data (WNBA)、nhl-data (NHL)、mlb-data (MLB)、tennis-data（网球）、golf-data（高尔夫）、cfb-data（大学橄榄球）、cbb-data （大学篮球）、fastf1 (F1)、排球数据（荷兰排球）、xctf-数据 (NCAA XC/TF)。不要用于预测市场——使用 Polymarket 或 kalshi。
