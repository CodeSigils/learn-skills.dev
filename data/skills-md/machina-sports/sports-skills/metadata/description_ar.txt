البيانات الوصفية الرياضية عبر واجهة برمجة التطبيقات المجانية TheSportsDB (المفتاح=3). شعارات الفريق وشاراته، وصور اللاعبين، ومعلومات الاستاد، ومعلومات الدوري، وبيانات السيرة الذاتية عبر أكثر من 100 دوري. لا يوجد مفتاح API مطلوب، تكوين صفر.

يُستخدم عندما: يطلب المستخدم شعار الفريق، أو الشعار، أو الشارة، أو اللافتة، أو القميص، أو المجموعة، أو صورة اللاعب أو لقطة الرأس، أو معلومات الملعب، أو وصف النادي، أو يريد البحث عن الفرق أو اللاعبين بالاسم عبر الألعاب الرياضية. جيد لإثراء الاستجابات من المهارات الأخرى بالصور والمعرفات المرئية.
لا تستخدم عندما: يطلب المستخدم النتائج أو الترتيب أو المباريات أو الإحصائيات أو الاحتمالات - استخدم المهارة الخاصة بالرياضة بدلاً من ذلك: بيانات كرة القدم (كرة القدم)، بيانات nfl (NFL)، بيانات nba (NBA)، بيانات wnba (WNBA)، بيانات nhl (NHL)، بيانات mlb (MLB)، بيانات التنس (التنس)، بيانات الجولف (الجولف)، بيانات cfb (كرة القدم الجامعية)، بيانات cbb (كرة السلة الجامعية)، fastf1 (F1)، بيانات الكرة الطائرة (الكرة الطائرة الهولندية)، بيانات xctf (NCAA XC/TF). لا تستخدم لأسواق التنبؤ — استخدم polymarket أو kalshi.
