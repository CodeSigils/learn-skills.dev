TheSportsDB 무료 API(키=3)를 통한 스포츠 메타데이터. 100개 이상의 리그에 걸쳐 팀 로고 및 배지, 선수 사진, 경기장 정보, 리그 정보 및 약력 데이터를 제공합니다. API 키가 필요하지 않으며 구성도 없습니다.

사용 시기: 사용자가 팀 로고, 문장, 배지, 배너, 저지, 키트, 선수 사진 또는 얼굴 사진, 경기장 정보, 클럽 설명을 요청하거나 스포츠 전체에서 팀이나 선수를 이름으로 검색하려고 합니다. 이미지와 시각적 식별자를 사용하여 다른 기술의 응답을 풍부하게 하는 데 좋습니다.
다음의 경우에는 사용하지 마세요: 사용자가 점수, 순위, 일정, 통계 또는 배당률을 요청하는 경우 — 대신에 스포츠별 기술을 사용하세요: football-data(soccer), nfl-data(NFL), nba-data(NBA), wnba-data(WNBA), nhl-data(NHL), mlb-data(MLB), Tennis-data(테니스), 골프 데이터(golf), cfb-data(대학 축구), cbb-data(대학 농구), fastf1(F1), volleyball-data(네덜란드 배구), xctf-data(NCAA XC/TF). 예측 시장에는 사용하지 마십시오. 폴리마켓이나 kalshi를 사용하십시오.
