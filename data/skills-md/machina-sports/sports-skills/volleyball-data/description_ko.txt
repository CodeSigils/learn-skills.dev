Nevobo API를 통한 네덜란드 배구 데이터(Eredivisie, Topdivisie, Superdivisie 및 전체 네덜란드 피라미드). 순위, 일정, 결과, 클럽, 토너먼트 및 뉴스. 구성이 없고 API 키가 없습니다.

사용 시기: 사용자가 네덜란드 배구, Eredivisie 배구, Nevobo, 배구 순위, 배구 경기 결과, 배구 일정 또는 네덜란드 배구 클럽에 관해 질문합니다.
다음 경우에는 사용하지 마세요: 사용자가 다른 스포츠에 대해 질문하는 경우 — football-data(축구), nfl-data(NFL), nba-data(NBA), wnba-data(WNBA), nhl-data(NHL), mlb-data(MLB), 골프 데이터(골프), cfb-data(대학 축구), cbb-data(대학 농구), Tennis-data(테니스) 또는 fastf1(F1)을 사용합니다. 베팅 확률은 폴리마켓이나 칼시를 사용하세요. 일반 뉴스의 경우 스포츠 뉴스를 사용하세요.
