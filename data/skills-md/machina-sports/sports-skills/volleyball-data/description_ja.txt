Nevobo API を介したオランダのバレーボール データ (エールディビジ、トップディビジ、スーパーディビジ、およびオランダのピラミッド全体)。順位表、スケジュール、結果、クラブ、トーナメント、ニュース。設定不要、API キーなし。

使用する場合: ユーザーがオランダのバレーボール、エールディビジのバレーボール、ネボボ、バレーボールの順位表、バレーボールの試合結果、バレーボールのスケジュール、またはオランダのバレーボール クラブについて質問する場合。
ユーザーが他のスポーツについて尋ねる場合には使用しないでください。フットボール データ (サッカー)、nfl データ (NFL)、nba データ (NBA)、wnba データ (WNBA)、nhl データ (NHL)、mlb データ (MLB)、ゴルフ データ (ゴルフ)、cfb データ (大学フットボール)、cbb データ (大学バスケットボール)、テニス データ (テニス)、または fastf1 (F1) を使用します。オッズを賭ける場合は、polymarket または kalshi を使用してください。一般的なニュースについてはスポーツニュースを使用してください。
