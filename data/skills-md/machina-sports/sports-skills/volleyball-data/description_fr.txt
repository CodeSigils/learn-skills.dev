Données de volleyball néerlandais (Eredivisie, Topdivisie, Superdivisie et pyramide néerlandaise complète) via l'API Nevobo. Classements, horaires, résultats, clubs, tournois et actualités. Zéro configuration, pas de clés API.

À utiliser lorsque : l'utilisateur pose des questions sur le volleyball néerlandais, l'Eredivisie volleyball, Nevobo, le classement du volleyball, les résultats des matchs de volleyball, les horaires de volleyball ou les clubs de volleyball néerlandais.
Ne pas utiliser lorsque : l'utilisateur pose des questions sur d'autres sports - utilisez les données de football (soccer), les données de nfl (NFL), les données de nba (NBA), les données de wnba (WNBA), les données de nhl (NHL), les données de mlb (MLB), les données de golf (golf), les données de cfb (football universitaire), les données de cbb (basketball universitaire), les données de tennis (tennis) ou fastf1 (F1). Pour les cotes de paris, utilisez Polymarket ou Kalshi. Pour les actualités générales, utilisez les actualités sportives.
