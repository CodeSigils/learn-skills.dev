بيانات الكرة الطائرة الهولندية (Eredivisie، Topdivisie، Superdivisie، والهرم الهولندي الكامل) عبر Nevobo API. الترتيب والجداول الزمنية والنتائج والأندية والبطولات والأخبار. تكوين صفر، لا توجد مفاتيح API.

يُستخدم عندما: يسأل المستخدم عن الكرة الطائرة الهولندية، أو الكرة الطائرة الهولندية، أو نيفوبو، أو ترتيب الكرة الطائرة، أو نتائج مباريات الكرة الطائرة، أو جداول الكرة الطائرة، أو أندية الكرة الطائرة الهولندية.
لا تستخدم عندما: يسأل المستخدم عن الرياضات الأخرى - استخدم بيانات كرة القدم (كرة القدم)، أو بيانات nfl (NFL)، أو بيانات nba (NBA)، أو بيانات wnba (WNBA)، أو بيانات nhl (NHL)، أو بيانات mlb (MLB)، أو بيانات الجولف (الجولف)، أو بيانات cfb (كرة القدم الجامعية)، أو بيانات cbb (كرة السلة الجامعية)، أو بيانات التنس (التنس)، أو fastf1 (F1). للمراهنة على الاحتمالات، استخدم polymarket أو kalshi. للحصول على الأخبار العامة، استخدم الأخبار الرياضية.
