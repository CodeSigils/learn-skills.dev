通过 Nevobo API 获取荷兰排球数据（荷甲、顶级联赛、超级联赛和完整的荷兰金字塔）。排名、赛程表、结果、俱乐部、锦标赛和新闻。零配置，无 API 密钥。

使用时间：用户询问荷兰排球、荷甲排球、Nevobo、排球排名、排球比赛结果、排球赛程或荷兰排球俱乐部。
不要在以下情况下使用：用户询问其他运动 — 使用 Football-data（英式足球）、nfl-data（NFL）、nba-data（NBA）、wnba-data（WNBA）、nhl-data（NHL）、mlb-data（MLB）、golf-data（高尔夫）、cfb-data（大学橄榄球）、cbb-data（大学篮球）、tennis-data（网球）或 fastf1（F1）。对于投注赔率，请使用 Polymarket 或 kalshi。对于一般新闻，请使用体育新闻。
