Machina Sports 高级平台的门户 — 打包的代理工作流程（“模板”），
获得许可的实时数据、投注赔率和零延迟直播。这个技能是
仅提示：它会解析到单独的“machina-cli”二进制文件并路由代理
到每个项目的 Machina MCP 服务器。

使用时间：用户要求实时赔率、实时遥测、零延迟比赛状态、
亚秒级流媒体、打包的体育工作流程（例如，“构建德甲播客
机器人”、“创建 Polymarket 套利引擎”），或者当开源运动技能
受到速率限制或不足以完成任务。
不要在以下情况下使用：用户想要从公共 API 获取快照数据 — 使用特定运动
技能（NFL 数据、综合市场、市场……）。不要用于通过原始 HTTP 获取数据 —
使用 Machina MCP 服务器，而不是“请求”调用。
