Machina Sports 高級平台的入口網站 — 打包的代理工作流程（「範本」），
獲得許可的即時數據、投注賠率和零延遲直播。這個技能是
僅提示：它會解析到單獨的“machina-cli”二進位檔案並路由代理
到每個專案的 Machina MCP 伺服器。

使用時間：使用者要求即時賠率、即時遙測、零延遲比賽狀態、
亞秒級串流媒體、打包的體育工作流程（例如，「建構德甲播客
機器人」、「創造 Polymarket 套利引擎」），或當開源運動技能
受到速率限製或不足以完成任務。
不要在以下情況下使用：使用者想要從公共 API 取得快照資料 — 使用特定運動
技能（NFL 數據、綜合市場、市場…）。不要用於透過原始 HTTP 取得資料 —
使用 Machina MCP 伺服器，而不是「請求」呼叫。
