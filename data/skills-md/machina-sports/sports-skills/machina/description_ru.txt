Переход к премиальной платформе Machina Sports — упакованные рабочие процессы агентов («шаблоны»),
лицензированные данные в реальном времени, коэффициенты ставок и прямые трансляции с нулевой задержкой. Этот навык
только подсказка: он передается в отдельный двоичный файл machina-cli и маршрутизирует агента
на сервер Machina MCP для каждого проекта.

Используйте, когда: пользователь запрашивает текущие коэффициенты, телеметрию в реальном времени, состояния матчей с нулевой задержкой,
субсекундные тик-стримы, пакетные спортивные рабочие процессы (например, «Создайте подкаст Бундеслиги»).
bot», «Создать арбитражную систему Polymarket») или когда открытый исходный код спортивных навыков
ограничены по скорости или недостаточны для выполнения задачи.
Не используйте, когда: пользователю нужны данные моментального снимка из общедоступных API — используйте специфичный для спорта
навыки (нфл-данные, полирынок, рынки, …). Не используйте для получения данных через необработанный HTTP —
используйте сервер Machina MCP, а не вызов запросов.
