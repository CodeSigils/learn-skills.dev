NCAA 越野和田徑運動員數據透過 TFRRS (tfrrs.org) 提供，新聞透過 The Stride Report 提供。取得運動員資料，包括所有個人記錄 (PR)、資格年份、學校、完整的賽季成績歷史記錄以及 XC/TF 新聞。零配置，無 API 金鑰。

使用場合：使用者詢問 NCAA 越野、NCAA 田徑、大學跑步、TFRRS 運動員資料、個人記錄、PR、XC 或 TF 賽季成績、個人運動員表現歷史或 XC/TF 新聞。
不要在以下情況下使用：使用者詢問職業田徑、鑽石聯賽或其他運動 — 使用 nfl-data、nba-data、wnba-data、nhl-data、mlb-data、golf-data、cfb-data、cbb-data、tennis-data、fastf1 或 volleyball-data。對於投注，請使用 Polymarket 或 kalshi。
