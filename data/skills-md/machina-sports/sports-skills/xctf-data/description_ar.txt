بيانات رياضيي NCAA عبر البلاد وألعاب المضمار والميدان عبر TFRRS (tfrrs.org) والأخبار عبر The Stride Report. جلب ملفات تعريف الرياضي بما في ذلك جميع السجلات الشخصية (PRs)، وسنة الأهلية، والمدرسة، وتاريخ النتائج الكامل لكل موسم، وأخبار XC/TF. تكوين صفر، لا توجد مفاتيح API.

يُستخدم عندما: يسأل المستخدم عن NCAA عبر البلاد، أو المسار والميدان NCAA، أو الجري الجامعي، أو ملفات تعريف الرياضيين TFRRS، أو السجلات الشخصية، أو PRs، أو نتائج موسم XC أو TF، أو سجل أداء الرياضي الفردي، أو أخبار XC/TF.
لا تستخدم عندما: يسأل المستخدم عن المسار الاحترافي، أو الدوري الماسي، أو الرياضات الأخرى - استخدم بيانات nfl، أو بيانات nba، أو بيانات wnba، أو بيانات nhl، أو بيانات mlb، أو بيانات الجولف، أو بيانات cfb، أو بيانات cbb، أو بيانات التنس، أو fastf1، أو بيانات الكرة الطائرة. للمراهنة استخدم polymarket أو kalshi.
