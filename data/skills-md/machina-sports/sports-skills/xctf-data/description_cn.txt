NCAA 越野和田径运动员数据通过 TFRRS (tfrrs.org) 提供，新闻通过 The Stride Report 提供。获取运动员资料，包括所有个人记录 (PR)、资格年份、学校、完整的赛季成绩历史记录以及 XC/TF 新闻。零配置，无 API 密钥。

使用场合：用户询问 NCAA 越野、NCAA 田径、大学跑步、TFRRS 运动员资料、个人记录、PR、XC 或 TF 赛季成绩、个人运动员表现历史或 XC/TF 新闻。
不要在以下情况下使用：用户询问职业田径、钻石联赛或其他运动 — 使用 nfl-data、nba-data、wnba-data、nhl-data、mlb-data、golf-data、cfb-data、cbb-data、tennis-data、fastf1 或 volleyball-data。对于投注，请使用 Polymarket 或 kalshi。
