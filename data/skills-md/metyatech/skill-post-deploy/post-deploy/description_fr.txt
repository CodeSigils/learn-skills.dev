À utiliser lors de la vérification du déploiement après des modifications de code sur des packages liés globalement (lien npm), des services en cours d'exécution, des démons ou des tâches planifiées. Se déclenche lorsque les modifications de code affectent une CLI installée globalement ou un service en cours d'exécution. Ne pas utiliser pour le développement général, la configuration de CI ou les déploiements initiaux.
