Подготавливает артефакт воспроизводимости (код/данные) для отправки и присвоения бейджей. Используйте, когда исследователь говорит: «оценка артефакта», «приложение к артефакту», «воспроизводимость», «значок», «артефакты доступны/оценены/функциональны/повторно использованы», «воспроизведены/реплицированы результаты», «значок ACM», «USENIX/OSDI/SOSP AE», «SIGMOD ARI», «код/контрольный список NeurIPS», «контрольный список воспроизведения ACL», «Zenodo DOI», «Наследие программного обеспечения», «анонимизировать мой код/репозиторий» или «упаковать мой код». Создает приложение README + артефакта, инструкции по зависимостям/запуску, анонимный репозиторий для двойного слепого анализа и архивный DOI (версия Zenodo или концепция) / руководство по SWHID программного обеспечения; решает таксономию значков ACM и обмен эпохами воспроизводства и репликации; и сверяет каталог артефакта с контрольным списком полноты кода ML с помощью встроенных сценариев только для стандартной библиотеки. Выводит контрольный список готовности к артефактам + план упаковки. Повторно проверяет текущие правила использования артефактов в реальном времени. Только консультативный; никогда не подчиняется.
