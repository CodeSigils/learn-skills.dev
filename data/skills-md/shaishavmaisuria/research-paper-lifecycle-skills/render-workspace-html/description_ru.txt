Преобразует бумажное рабочее пространство (результаты + ход жизненного цикла) в единую автономную панель HTML, которую автор может открыть в браузере, и обновляет ее по запросу. Используйте, когда исследователь говорит: «покажите мне HTML-представление», «дайте мне панель мониторинга», «могу ли я увидеть свой прогресс в браузере», «визуализировать то, что было сделано», «создать HTML-отчет» или «обновить панель мониторинга». Предлагается в качестве опции всякий раз, когда может помочь визуальный обзор (он создается по согласию, а не создается без запроса) и повторно запускается после каждого значительного изменения, чтобы страница оставалась актуальной. Результатом является один локальный файл Dashboard.html со встроенным CSS — без сети, без внешних ресурсов, с учетом света и тьмы — со списком каждого сгенерированного артефакта по этапам с кликабельными ссылками и временной шкалой недавних действий. Триггерные слова — HTML, панель мониторинга, просмотр браузера, визуализация прогресса, отчет HTML, обновление HTML.
