将纸张工作空间（输出 + 生命周期进度）呈现为一个独立的 HTML 仪表板，作者可以在浏览器中打开，并根据请求刷新它。当研究人员说“向我显示 HTML 视图”、“给我一个仪表板”、“我可以在浏览器中查看我的进度吗”、“可视化已完成的工作”、“制作 HTML 报告”或“更新仪表板”时使用。每当视觉概述有帮助时就作为一个选项提供（它是选择加入，不会自动生成），并在每次重大更改后重新运行，以便页面保持最新状态。输出是一个带有内联 CSS 的本地仪表板.html — 无网络、无外部资产、亮/暗感知 — 按阶段列出每个生成的工件，并带有可点击的链接和最近的活动时间线。触发词 - html、仪表板、浏览器视图、可视化进度、html 报告、更新 html。
