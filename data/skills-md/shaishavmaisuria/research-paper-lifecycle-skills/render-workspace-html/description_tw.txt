將紙張工作空間（輸出 + 生命週期進度）呈現為一個獨立的 HTML 儀表板，作者可以在瀏覽器中打開，並根據請求刷新它。當研究人員說「向我顯示 HTML 視圖」、「給我一個儀表板」、「我可以在瀏覽器中查看我的進度嗎」、「可視化已完成的工作」、「製作 HTML 報告」或「更新儀表板」時使用。每當視覺概述有幫助時就作為一個選項提供（它是選擇加入，不會自動生成），並在每次重大更改後重新運行，以便頁面保持最新狀態。輸出是一個帶有內聯 CSS 的本機儀表板.html — 無網路、無外部資產、亮/暗感知 — 按階段列出每個產生的工件，並帶有可點擊的連結和最近的活動時間軸。觸發詞 - html、儀表板、瀏覽器視圖、視覺化進度、html 報告、更新 html。
