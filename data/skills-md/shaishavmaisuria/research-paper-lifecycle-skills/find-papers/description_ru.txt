Ищет научную литературу без ключей API в DBLP, Crossref, Semantic Scholar и arXiv. Используйте, когда пользователь хочет найти статьи, выполнить поиск в литературе, составить список материалов конференции (например, «все статьи SIGSPATIAL 2025»), просмотреть работы, связанные с темой, найти статьи по автору/месту/году, получить DOI или количество цитирований или проверить последние препринты arXiv. Поставляет таблицу псевдонимов мест, которая решает вопросы именования мест между API (DBLP «conf/gis» против Semantic Scholar «SIGSPATIAL/GIS» против заголовков процедур Crossref), а также вежливые, кэшированные, устойчивые к 429 сценарии поиска. Триггерные слова — поиск статей, поиск литературы, связанные работы, материалы, DBLP, Crossref, Semantic Scholar, arXiv, подсчет цитирований, поиск DOI, поиск места проведения.
