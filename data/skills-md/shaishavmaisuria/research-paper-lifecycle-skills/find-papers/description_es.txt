Busca literatura académica sin claves API en DBLP, Crossref, Semantic Scholar y arXiv. Úselo cuando el usuario desee buscar artículos, buscar literatura, enumerar las actas de una conferencia (por ejemplo, "todos los artículos de SIGSPATIAL 2025"), realizar una encuesta sobre trabajos relacionados con un tema, buscar artículos por autor/lugar/año, obtener DOI o recuentos de citas, o consultar preimpresiones recientes de arXiv. Incluye una tabla de alias de lugar que resuelve la denominación de lugares entre API (DBLP "conf/gis" vs Semantic Scholar "SIGSPATIAL/GIS" vs títulos de procedimientos Crossref) además de scripts de búsqueda educados, almacenados en caché y resistentes a 429. Palabras desencadenantes: búsqueda de artículos, búsqueda de literatura, trabajos relacionados, actas, DBLP, Crossref, Semantic Scholar, arXiv, recuento de citas, búsqueda de DOI, búsqueda de lugares.
