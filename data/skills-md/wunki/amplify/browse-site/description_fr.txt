Navigue et interagit avec les sites Web à l'aide de la CLI agent-navigateur, notamment en cliquant sur des éléments, en remplissant des formulaires, en prenant des captures d'écran, en extrayant le contenu de la page et en automatisant les flux de travail du navigateur en plusieurs étapes. À utiliser lorsque l'utilisateur demande à ouvrir une URL, à cliquer sur quelque chose sur une page, à remplir un formulaire Web, à prendre une capture d'écran d'une page, à récupérer ou à extraire des données d'un site Web ou à automatiser une tâche de navigateur. Ne pas utiliser pour les scripts Playwright, Puppeteer ou Selenium ; ne pas utiliser pour le développement d'extensions de navigateur ; ne pas utiliser pour des questions sur les API du navigateur, JavaScript ou le code frontal qui ne nécessitent pas d'interaction en direct avec le navigateur.
