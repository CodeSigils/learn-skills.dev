Naviga e interagisce con i siti Web utilizzando la CLI del browser dell'agente, inclusi clic sugli elementi, compilazione di moduli, acquisizione di schermate, estrazione del contenuto della pagina e automazione dei flussi di lavoro del browser in più fasi. Da utilizzare quando l'utente chiede di aprire un URL, fare clic su qualcosa in una pagina, compilare un modulo Web, acquisire uno screenshot di una pagina, acquisire o estrarre dati da un sito Web o automatizzare un'attività del browser. Non utilizzare per script di drammaturgo, burattinaio o selenio; non utilizzare per lo sviluppo di estensioni del browser; non utilizzare per domande su API del browser, JavaScript o codice frontend che non richiedono l'interazione live del browser.
