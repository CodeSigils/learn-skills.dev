Navigiert und interagiert mit Websites mithilfe der Agent-Browser-CLI, einschließlich Klicken auf Elemente, Ausfüllen von Formularen, Erstellen von Screenshots, Extrahieren von Seiteninhalten und Automatisieren mehrstufiger Browser-Workflows. Verwenden Sie diese Option, wenn der Benutzer eine URL öffnen, auf etwas auf einer Seite klicken, ein Webformular ausfüllen, einen Seiten-Screenshot erstellen, Daten von einer Website scrapen oder extrahieren oder eine Browseraufgabe automatisieren möchte. Nicht für Dramatiker-, Puppenspieler- oder Selenium-Skripte verwenden; Nicht für die Entwicklung von Browsererweiterungen verwenden; Nicht für Fragen zu Browser-APIs, JavaScript oder Frontend-Code verwenden, die keine Live-Interaktion mit dem Browser erfordern.
