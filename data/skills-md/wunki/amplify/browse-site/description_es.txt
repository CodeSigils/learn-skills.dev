Navega e interactúa con sitios web utilizando la CLI del agente-navegador, lo que incluye hacer clic en elementos, completar formularios, tomar capturas de pantalla, extraer contenido de la página y automatizar flujos de trabajo de navegador de varios pasos. Úselo cuando el usuario solicita abrir una URL, hacer clic en algo en una página, completar un formulario web, tomar una captura de pantalla de la página, extraer o extraer datos de un sitio web o automatizar una tarea del navegador. No lo utilice para guiones de Dramaturgo, Titiritero o Selenium; no lo utilice para el desarrollo de extensiones del navegador; no lo utilice para preguntas sobre las API del navegador, JavaScript o código de interfaz que no requieran interacción en vivo con el navegador.
