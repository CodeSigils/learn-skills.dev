Навигация и взаимодействие с веб-сайтами с помощью интерфейса командной строки агента-браузера, включая нажатие элементов, заполнение форм, создание снимков экрана, извлечение содержимого страниц и автоматизацию многоэтапных рабочих процессов браузера. Используйте, когда пользователь просит открыть URL-адрес, щелкнуть что-нибудь на странице, заполнить веб-форму, сделать снимок экрана страницы, очистить или извлечь данные с веб-сайта или автоматизировать задачу браузера. Не используйте для сценариев Playwright, Puppeteer или Selenium; не используйте для разработки расширений браузера; не используйте для вопросов об API браузера, JavaScript или коде внешнего интерфейса, который не требует взаимодействия с браузером в реальном времени.
