Déboguez un test Playwright ayant échoué en l'exécutant avec le traçage, puis en analysant la trace à l'aide de l'outil de trace Playwright CLI (« npx playwright trace »). Utilisez cette compétence chaque fois que l'utilisateur demande de déboguer, de réparer ou d'enquêter sur un test Playwright défaillant ou instable, ou lorsqu'une exécution de test produit une erreur. Se déclenche également lorsque l'utilisateur dit des choses telles que « ce test est interrompu », « pourquoi ce test échoue-t-il », « répare ce test » ou « enquête sur l'échec du test ».
