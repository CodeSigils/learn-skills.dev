قم بتصحيح أخطاء اختبار Playwright الفاشل عن طريق تشغيله مع تشغيل التتبع، ثم تحليل التتبع باستخدام أداة التتبع Playwright CLI (`npx playwright Trace`). استخدم هذه المهارة عندما يطلب المستخدم تصحيح أو إصلاح أو التحقيق في اختبار الكاتب المسرحي الفاشل أو غير المستقر، أو عندما يؤدي تنفيذ الاختبار إلى حدوث خطأ. يتم تشغيله أيضًا عندما يقول المستخدم أشياء مثل "هذا الاختبار معطل"، أو "لماذا يفشل هذا الاختبار"، أو "أصلح هذا الاختبار"، أو "التحقيق في فشل الاختبار".
