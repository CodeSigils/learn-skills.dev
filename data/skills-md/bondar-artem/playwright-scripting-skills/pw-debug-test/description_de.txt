Debuggen Sie einen fehlgeschlagenen Playwright-Test, indem Sie ihn mit aktivierter Ablaufverfolgung ausführen und dann die Ablaufverfolgung mit dem Playwright-CLI-Ablaufverfolgungstool („npx playwright Trace“) analysieren. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen fehlgeschlagenen oder fehlerhaften Playwright-Test debuggen, reparieren oder untersuchen möchte oder wenn eine Testausführung einen Fehler erzeugt. Wird auch ausgelöst, wenn der Benutzer Dinge wie „Dieser Test ist fehlerhaft“, „Warum ist dieser Test fehlgeschlagen“, „Diesen Test beheben“ oder „Testfehler untersuchen“ sagt.
