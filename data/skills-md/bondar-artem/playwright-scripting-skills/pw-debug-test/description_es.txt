Depure una prueba fallida de Playwright ejecutándola con el rastreo activado y luego analice el rastreo usando la herramienta de rastreo de Playwright CLI (`npx playwright trace`). Utilice esta habilidad siempre que el usuario solicite depurar, corregir o investigar una prueba de Playwright fallida o inestable, o cuando la ejecución de una prueba produzca un error. También se activa cuando el usuario dice cosas como "esta prueba no funciona", "por qué falla esta prueba", "arreglar esta prueba" o "investigar la falla de la prueba".
