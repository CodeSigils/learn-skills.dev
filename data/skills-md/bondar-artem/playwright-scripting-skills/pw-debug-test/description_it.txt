Eseguire il debug di un test di Playwright fallito eseguendolo con la traccia attiva, quindi analizzando la traccia utilizzando lo strumento di traccia della CLI di Playwright (`npx playwright trace`). Utilizza questa abilità ogni volta che l'utente chiede di eseguire il debug, correggere o indagare su un test di Playwright fallito o instabile o quando l'esecuzione di un test produce un errore. Si attiva anche quando l'utente dice cose come "questo test non funziona", "perché questo test non riesce", "correggi questo test" o "indaga sull'esito negativo del test".
