Напишите новый тест Playwright E2E на основе предоставленных пользователем этапов тестирования, когда исходный код приложения НЕ доступен. Использует интерфейс командной строки Playwright (`@playwright/cli`) для проверки действующего URL-адреса с помощью снимков и `generate-locator`, затем пишет тест, запускает и отлаживает его, если необходимо.
