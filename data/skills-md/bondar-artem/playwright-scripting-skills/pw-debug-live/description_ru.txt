Отладка теста Playwright в интерактивном режиме с помощью `--debug=cli` и `playwright-cli`. Приостанавливает тест на выбранной пользователем строке с помощью «pause-at» (без изменений исходного кода), затем запускает действующую приостановленную страницу с помощью «снимка», «eval», «generate-locator», «console», «requests» для диагностики условий гонки, ошибок синхронизации и сбоев, зависящих от состояния, которые не может показать статическая трассировка. Используйте, когда пользователь просит «пройти тест», «отладку в реальном времени», «присоединиться к приостановленному тесту», «отладку из строки N» или когда `pw-debug-test` (на основе трассировки) было недостаточно, поскольку сбой зависит от состояния активной страницы.
