Depurar una prueba de Playwright que falló en GitHub Actions. Utiliza la CLI `gh` para localizar la ejecución fallida del flujo de trabajo, descarga su artefacto `test-results` (que contiene el rastro de Playwright), analiza el rastro a través de `npx playwright trace`, identifica la causa raíz y aplica una solución a la especificación siguiendo las reglas de secuencias de comandos de Playwright del proyecto, dejando el cambio sin confirmar para que el usuario pueda revisarlo, confirmarlo y enviarlo. Utilice esta habilidad cuando el usuario solicite depurar, corregir o investigar una prueba de Playwright que falló en GitHub Actions/CI (por ejemplo, "la prueba pw falló en CI", "depurar las acciones fallidas ejecutadas", "por qué falló el trabajo de GitHub Actions Playwright", "arreglar la prueba de CI fallida").
