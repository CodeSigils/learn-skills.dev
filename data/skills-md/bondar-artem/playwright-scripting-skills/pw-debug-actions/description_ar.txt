تصحيح أخطاء اختبار Playwright الذي فشل في إجراءات GitHub. يستخدم `gh` CLI لتحديد موقع تشغيل سير العمل الفاشل، وتنزيل عنصر ``نتائج الاختبار`` الخاص به (الذي يحتوي على تتبع Playwright)، ويحلل التتبع عبر `npx Playwright Trace`، ويحدد السبب الجذري، ويطبق إصلاحًا على المواصفات التي تتبع قواعد البرمجة النصية لـ Playwright الخاصة بالمشروع - مع ترك التغيير غير ملتزم به حتى يتمكن المستخدم من المراجعة والالتزام والدفع. استخدم هذه المهارة عندما يطلب المستخدم تصحيح أخطاء اختبار Playwright أو إصلاحه أو التحقيق فيه الذي فشل في GitHub Actions / CI (على سبيل المثال، "فشل اختبار pw في CI"، "تصحيح أخطاء تشغيل الإجراءات الفاشلة"، "لماذا فشلت مهمة GitHub Actions Playwright"، "إصلاح اختبار CI الفاشل").
