Debuggen Sie einen Playwright-Test, der in GitHub Actions fehlgeschlagen ist. Verwendet die „gh“-CLI, um die fehlgeschlagene Workflow-Ausführung zu lokalisieren, lädt ihr „test-results“-Artefakt herunter (das den Playwright-Trace enthält), analysiert den Trace über „npx playwright Trace“, identifiziert die Grundursache und wendet einen Fix auf die Spezifikation gemäß den Playwright-Skriptregeln des Projekts an – wobei die Änderung nicht übernommen wird, sodass der Benutzer sie überprüfen, festschreiben und pushen kann. Verwenden Sie diesen Skill, wenn der Benutzer darum bittet, einen Playwright-Test zu debuggen, zu reparieren oder zu untersuchen, der auf GitHub Actions/CI fehlgeschlagen ist (z. B. „der PW-Test ist auf CI fehlgeschlagen“, „die fehlgeschlagenen ausgeführten Aktionen debuggen“, „Warum ist der GitHub Actions Playwright-Job fehlgeschlagen“, „den fehlgeschlagenen CI-Test beheben“).
