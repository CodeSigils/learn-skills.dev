GitHub Actions에서 실패한 Playwright 테스트를 디버그합니다. `gh` CLI를 사용하여 실패한 워크플로 실행을 찾고, 해당 `test-results` 아티팩트(Playwright 추적 포함)를 다운로드하고, `npx playwright 추적`을 통해 추적을 분석하고, 근본 원인을 식별하고, 프로젝트의 Playwright 스크립팅 규칙에 따라 사양에 수정 사항을 적용합니다. 변경 사항을 커밋되지 않은 상태로 남겨 사용자가 검토, 커밋 및 푸시할 수 있도록 합니다. 사용자가 GitHub Actions/CI에서 실패한 Playwright 테스트를 디버그, 수정 또는 조사하도록 요청할 때 이 기술을 사용합니다(예: "CI에서 비밀번호 테스트 실패", "실패한 작업 실행 디버그", "GitHub Actions Playwright 작업이 실패한 이유", "실패한 CI 테스트 수정").
