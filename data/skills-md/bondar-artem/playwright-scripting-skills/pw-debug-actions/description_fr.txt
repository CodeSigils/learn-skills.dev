Déboguez un test Playwright qui a échoué dans les actions GitHub. Utilise la CLI `gh` pour localiser l'exécution du flux de travail ayant échoué, télécharge son artefact `test-results` (contenant la trace Playwright), analyse la trace via `npx playwright trace`, identifie la cause première et applique un correctif à la spécification en suivant les règles de script Playwright du projet — en laissant la modification non validée afin que l'utilisateur puisse réviser, valider et pousser. Utilisez cette compétence lorsque l'utilisateur demande de déboguer, de réparer ou d'enquêter sur un test Playwright qui a échoué sur GitHub Actions / CI (par exemple, "le test pw a échoué sur CI", "déboguer les actions ayant échoué", "pourquoi le travail GitHub Actions Playwright a-t-il échoué", "corriger l'échec du test CI").
