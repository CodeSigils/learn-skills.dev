Отладка теста драматурга, который завершился неудачей в действиях GitHub. Использует интерфейс командной строки `gh` для обнаружения неудачного запуска рабочего процесса, загружает его артефакт `test-results` (содержащий трассировку Playwright), анализирует трассировку с помощью `npx playwright Trace`, определяет основную причину и применяет исправление к спецификации в соответствии с правилами сценариев Playwright проекта, оставляя изменение незафиксированным, чтобы пользователь мог просмотреть, зафиксировать и отправить его. Используйте этот навык, когда пользователь просит отладить, исправить или исследовать тест Playwright, который не удался на GitHub Actions/CI (например, «тест pw не удался на CI», «отладка неудачного запуска действий», «почему задание GitHub Actions Playwright завершилось неудачно», «исправить неудачный тест CI»).
