調試 GitHub Actions 中失敗的 Playwright 測試。使用“gh”CLI 定位失敗的工作流程運行，下載其“測試結果”工件（包含 Playwright 跟踪），通過“npx playwright 跟踪”分析跟踪，確定根本原因，並按照項目的 Playwright 腳本規則對規範應用修復 - 保留更改未提交，以便用戶可以查看、提交和推送。當使用者要求調試、修復或調查在 GitHub Actions / CI 上失敗的 Playwright 測試（例如「CI 上的 pw 測試失敗」、「調試失敗的操作運行」、「為什麼 GitHub Actions Playwright 作業失敗」、「修復失敗的 CI 測試」）時，請使用此技能。
