GitHub Actions で失敗した Playwright テストをデバッグします。 「gh」 CLI を使用して、失敗したワークフロー実行を特定し、その「テスト結果」アーティファクト (Playwright トレースを含む) をダウンロードし、「npx playwright トレース」を介してトレースを分析し、根本原因を特定し、プロジェクトの Playwright スクリプト ルールに従って仕様に修正を適用します。変更はコミットされないままにし、ユーザーがレビュー、コミット、プッシュできるようにします。このスキルは、GitHub Actions / CI で失敗した Playwright テストのデバッグ、修正、調査をユーザーが要求した場合に使用します (例: 「CI で pw テストが失敗しました」、「失敗したアクションの実行をデバッグ」、「GitHub Actions Playwright ジョブが失敗した理由」、「失敗した CI テストを修正」)。
