Personalización del tema visual de una aplicación SGDS: colores de la marca del producto, modo día/noche y fuente. Úselo cuando los usuarios pregunten sobre cómo cambiar el color primario, tematizar su aplicación, habilitar el modo oscuro, el modo nocturno, anular tokens CSS o personalizar la fuente. Aplique esta habilidad siempre que se mencionen temas, marcas o anulaciones de tokens CSS.
