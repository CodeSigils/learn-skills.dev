قوالب صفحات كاملة جاهزة للاستخدام تم إنشاؤها باستخدام مكونات وأدوات مساعدة SGDS. استخدم هذه المهارة عندما يطلب المستخدم إنشاء صفحة، أو لوحة معلومات، أو صفحة تسجيل دخول، أو صفحة نموذج، أو صفحة إعدادات، أو صفحة قائمة، أو أي واجهة مستخدم بصفحة كاملة - حتى لو لم يذكر "قالب". يتم تطبيقه عند بدء تطبيق جديد، أو إنشاء أدوات داخلية، أو لوحات معلومات، أو بوابات إدارية، أو تدفقات المصادقة، أو طرق عرض جدول البيانات.
