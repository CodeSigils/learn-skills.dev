설치 및 프레임워크 통합을 포함한 모든 SGDS 웹 구성 요소에 대한 전체 참조입니다. 사용자가 <sgds-*> 구성 요소(아코디언, 경고, 배지, 이동 경로, 버튼, 카드, 체크박스, 닫기 버튼, 콤보 상자, 날짜 선택기, 설명 목록, 구분선, 서랍, 드롭다운, 파일 업로드, 바닥글, 아이콘, 아이콘 버튼, 아이콘 카드, 아이콘 목록, 이미지 카드, 입력, 링크, 메인 탐색, 마스트헤드, 모달, 오버플로 메뉴, 페이지 매김, 진행률 표시줄, 수량 전환 등)에 대해 질문할 때 사용합니다. 라디오, 선택, 사이드바, 사이드 탐색, 스켈레톤, 스피너, 스테퍼, 하위 탐색, 스위치, 시스템 배너, 탭, 테이블, 목차, 텍스트 영역, 썸네일 카드, 토스트 또는 도구 설명. 또한 React 19+, React ≤18, Vue, Angular 및 Next.js 통합을 다룹니다.
