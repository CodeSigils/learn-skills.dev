Полный справочник по всем веб-компонентам SGDS, включая установку и интеграцию с платформой. Используйте, когда пользователи спрашивают о любом компоненте <sgds-*> — аккордеоне, оповещении, значке, хлебной крошке, кнопке, карточке, флажке, кнопке закрытия, поле со списком, средстве выбора даты, списке описаний, разделителе, ящике, раскрывающемся списке, загрузке файла, нижнем колонтитуле, значке, кнопке значка, карточке значка, списке значков, карточке изображения, вводе, ссылке, основной навигации, заголовке, модальном, меню переполнения, нумерации страниц, индикатор выполнения, переключатель количества, радио, выбор, боковая панель, боковая навигация, скелет, счетчик, степпер, дополнительная навигация, переключатель, системный баннер, вкладка, таблица, оглавление, текстовая область, миниатюра, всплывающее сообщение или подсказка. Также охватывает интеграцию React 19+, React ≤18, Vue, Angular и Next.js.
