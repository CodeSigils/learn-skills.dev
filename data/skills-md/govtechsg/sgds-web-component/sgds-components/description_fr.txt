Référence complète pour tous les composants Web SGDS, y compris l'installation et l'intégration du framework. À utiliser lorsque les utilisateurs posent des questions sur un composant <sgds-*> : accordéon, alerte, badge, fil d'Ariane, bouton, carte, case à cocher, bouton de fermeture, zone de liste déroulante, sélecteur de date, liste de description, séparateur, tiroir, liste déroulante, téléchargement de fichier, pied de page, icône, bouton d'icône, carte d'icône, liste d'icônes, carte d'image, entrée, lien, navigation principale, tête de masthead, modal, menu de débordement, pagination, barre de progression, bascule de quantité, radio, sélection, barre latérale, navigation latérale, squelette, spinner, stepper, subnav, commutateur, bannière système, onglet, table, table des matières, zone de texte, carte miniature, toast ou info-bulle. Couvre également l'intégration de React 19+, React ≤18, Vue, Angular et Next.js.
