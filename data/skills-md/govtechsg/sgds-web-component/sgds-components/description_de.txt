Vollständige Referenz für alle SGDS-Webkomponenten einschließlich Installation und Framework-Integration. Wird verwendet, wenn Benutzer nach einer <sgds-*>-Komponente fragen – Akkordeon, Warnung, Abzeichen, Breadcrumb, Schaltfläche, Karte, Kontrollkästchen, Schaltfläche „Schließen“, Kombinationsfeld, Datumsauswahl, Beschreibungsliste, Trennlinie, Schublade, Dropdown, Datei-Upload, Fußzeile, Symbol, Symbolschaltfläche, Symbolkarte, Symbolliste, Bildkarte, Eingabe, Link, Hauptnavigation, Impressum, Modal, Überlaufmenü, Paginierung, Fortschrittsbalken, Mengenumschaltung, Radio, Auswählen, Seitenleiste, Seitennavigation, Skelett, Spinner, Stepper, Unternavigation, Schalter, Systembanner, Registerkarte, Tabelle, Inhaltsverzeichnis, Textbereich, Miniaturbildkarte, Toast oder Tooltip. Deckt auch die Integration von React 19+, React ≤18, Vue, Angular und Next.js ab.
