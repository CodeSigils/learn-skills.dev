Отправная точка для любого нового приложения, созданного с использованием библиотеки веб-компонентов SGDS. Применяйте этот навык в первую очередь всякий раз, когда пользователь загружает новый проект SGDS, настраивает новое приложение или спрашивает, с чего начать работу с SGDS. Описывает настройку шрифтов, базовый CSS, утилиты, компоненты и макет приложения в правильном порядке.
