Punto di partenza per qualsiasi nuova applicazione creata con la libreria di componenti web SGDS. Applica questa competenza per prima ogni volta che un utente avvia un nuovo progetto SGDS, configura una nuova app o chiede da dove iniziare con SGDS. Copre la configurazione dei caratteri, i CSS di base, le utilità, i componenti e il layout dell'app nell'ordine corretto.
