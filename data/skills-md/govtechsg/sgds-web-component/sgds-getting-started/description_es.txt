Punto de partida para cualquier aplicación nueva creada con la biblioteca de componentes web SGDS. Aplique esta habilidad primero cada vez que un usuario esté iniciando un nuevo proyecto SGDS, configurando una nueva aplicación o preguntando por dónde empezar con SGDS. Cubre la configuración de fuentes, CSS básico, utilidades, componentes y diseño de aplicaciones en el orden correcto.
