Vollständige, gebrauchsfertige Seitenvorlagen, die mit SGDS-Komponenten und -Dienstprogrammen erstellt wurden. Verwenden Sie diesen Skill immer dann, wenn ein Benutzer eine Seite, ein Dashboard, eine Anmeldeseite, eine Formularseite, eine Einstellungsseite, eine Listenseite oder eine ganzseitige Benutzeroberfläche erstellen möchte – auch wenn er nicht „Vorlage“ sagt. Wenden Sie es an, wenn Sie eine neue App starten, interne Tools, Dashboards, Admin-Portale, Authentifizierungsflüsse oder Datentabellenansichten erstellen.
