Flux de travail complet pour migrer une application frontend existante vers les composants web SGDS. Utilisez cette compétence lorsqu’un utilisateur souhaite migrer d’une autre bibliothèque UI (MUI, Chakra UI, shadcn/ui, Ant Design, Vuetify, Angular Material, Bootstrap, etc.) vers SGDS, ou demande comment commencer à utiliser SGDS dans un projet existant. Couvre quatre phases : (1) analyser la pile technologique frontend actuelle, (2) installer et configurer SGDS avec la police, le CSS de base et les utilitaires, (3) migrer les tests (Chemin A : Vitest + Playwright, ou Chemin B : corriger les Jest/RTL existants), (4) remplacer les anciens systèmes de style par les utilitaires SGDS v3, plus une checklist de vérification post‑migration. React entièrement pris en charge.
