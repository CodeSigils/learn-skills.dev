Workflow completo per migrare un'applicazione frontend esistente ai componenti web SGDS. Usa questa competenza quando un utente vuole migrare da un'altra libreria UI (MUI, Chakra UI, shadcn/ui, Ant Design, Vuetify, Angular Material, Bootstrap, ecc.) a SGDS, o chiede come iniziare a usare SGDS in un progetto esistente. Copre quattro fasi: (1) analizza lo stack tecnologico frontend attuale, (2) installa e configura SGDS con font, CSS di base e utility, (3) migra i test (Percorso A: Vitest + Playwright, o Percorso B: patch dei test Jest/RTL esistenti), (4) sostituisci i vecchi sistemi di styling con le utility SGDS v3, più una checklist di verifica post‑migrazione. React è pienamente supportato.
