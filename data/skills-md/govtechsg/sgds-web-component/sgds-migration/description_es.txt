Flujo de trabajo completo para migrar una aplicación frontend existente a los componentes web de SGDS. Utiliza esta habilidad cuando un usuario quiere migrar desde otra biblioteca de UI (MUI, Chakra UI, shadcn/ui, Ant Design, Vuetify, Angular Material, Bootstrap, etc.) a SGDS, o pregunta cómo empezar a usar SGDS en un proyecto existente. Cubre cuatro fases: (1) escanear la pila tecnológica frontend actual, (2) instalar y configurar SGDS con tipografía, CSS base y utilidades, (3) migrar pruebas (Ruta A: Vitest + Playwright, o Ruta B: parchear Jest/RTL existentes), (4) reemplazar los sistemas de estilo antiguos con las utilidades de SGDS v3, más una lista de verificación de verificación post‑migración. React totalmente compatible.
