Полный рабочий процесс миграции существующего фронтенд‑приложения к веб‑компонентам SGDS. Используйте это руководство, когда пользователь хочет перейти с другой UI‑библиотеки (MUI, Chakra UI, shadcn/ui, Ant Design, Vuetify, Angular Material, Bootstrap и т.д.) на SGDS, либо спрашивает, как начать использовать SGDS в уже существующем проекте. Охватывает четыре этапа: (1) сканировать текущий стек технологий фронтенда, (2) установить и настроить SGDS с шрифтами, базовым CSS и утилитами, (3) мигрировать тесты (Путь A: Vitest + Playwright, или Путь B: адаптировать существующие Jest/RTL), (4) заменить старые системы стилизации утилитами SGDS v3, плюс чек‑лист проверки после миграции. Полная поддержка React.
