기존 프런트엔드 응용 프로그램을 SGDS 웹 구성 요소로 마이그레이션하기 위한 전체 작업 흐름입니다. 사용자가 다른 UI 라이브러리(MUI, Chakra UI, shadcn/ui, Ant Design, Vuetify, Angular Material, Bootstrap 등)에서 SGDS로 마이그레이션하고 싶거나 기존 프로젝트에서 SGDS 사용을 시작하는 방법을 문의할 때 이 스킬을 사용하세요. 4단계를 다룹니다. (1) 현재 프런트엔드 기술 스택 스캔, (2) 글꼴, 기초 CSS 및 유틸리티를 사용하여 SGDS 설치 및 구성, (3) 테스트 마이그레이션(경로 A: Vitest + Playwright 또는 경로 B: 기존 Jest/RTL 패치), (4) 이전 스타일 시스템을 SGDS v3 유틸리티로 교체 및 마이그레이션 후 확인 체크리스트. 반응이 완벽하게 지원됩니다.
