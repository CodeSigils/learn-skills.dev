既存のフロントエンドアプリケーションを SGDS Web コンポーネントへ移行するための完全なワークフロー。ユーザーが別の UI ライブラリ（MUI、Chakra UI、shadcn/ui、Ant Design、Vuetify、Angular Material、Bootstrap など）から SGDS に移行したい、または既存プロジェクトで SGDS の使用を開始したいときにこのスキルを使用してください。4 つのフェーズで構成されます：（1）現在のフロントエンド技術スタックをスキャンする、（2）フォント、基礎 CSS、ユーティリティと共に SGDS をインストールおよび設定する、（3）テストを移行する（パス A：Vitest + Playwright、またはパス B：既存の Jest/RTL をパッチ適用）、（4）古いスタイリングシステムを SGDS v3 ユーティリティに置き換える、さらに移行後の検証チェックリストを含みます。React は完全にサポートされています。
