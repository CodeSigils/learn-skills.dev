Kompletter Arbeitsablauf für die Migration einer bestehenden Frontend‑Anwendung zu SGDS‑Web‑Components. Verwenden Sie diese Fähigkeit, wenn ein Nutzer von einer anderen UI‑Bibliothek (MUI, Chakra UI, shadcn/ui, Ant Design, Vuetify, Angular Material, Bootstrap usw.) zu SGDS migrieren möchte oder wissen will, wie man SGDS in einem bestehenden Projekt einsetzt. Deckt vier Phasen ab: (1) Scan des aktuellen Frontend‑Tech‑Stacks, (2) Installation und Konfiguration von SGDS mit Schriftart, Basis‑CSS und Utilities, (3) Migration von Tests (Pfad A: Vitest + Playwright oder Pfad B: Patch der bestehenden Jest/RTL), (4) Ersetzen alter Styling‑Systeme durch SGDS v3‑Utilities sowie eine Checkliste zur Verifizierung nach der Migration. React wird vollständig unterstützt.
