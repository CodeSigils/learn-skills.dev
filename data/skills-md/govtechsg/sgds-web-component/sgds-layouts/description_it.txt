Catalogo completo di modelli di impaginazione per applicazioni SGDS. Utilizza questa abilità ogni volta che un utente chiede informazioni sui layout di pagina, sulla disposizione dei contenuti, sui pannelli laterali, sulle visualizzazioni divise, sui layout della barra laterale, sui layout breadcrumb o sui layout dell'altezza del viewport, anche se dice semplicemente "come dovrei disporre la mia pagina" o "Ho bisogno di un layout a due colonne". Copre i layout a larghezza intera (pagine rivolte al pubblico con sgds-container) e i layout con barra laterale (dashboard/strumenti interni con sgds-container-sidebar). Attivazione su: layout, a parte, vista divisa, layout della barra laterale, a due colonne, a tre colonne, disposizione dei contenuti, struttura della pagina a parte.
