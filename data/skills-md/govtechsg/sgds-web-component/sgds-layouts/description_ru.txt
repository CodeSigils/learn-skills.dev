Полный каталог шаблонов макетов страниц для приложений SGDS. Используйте этот навык всякий раз, когда пользователь спрашивает о макетах страниц, расположении контента, боковых панелях, разделенных представлениях, макетах боковых панелей, макетах хлебных крошек или макетах по высоте области просмотра — даже если они просто говорят: «Как мне расположить мою страницу» или «Мне нужен макет из двух столбцов». Охватывает макеты полной ширины (общедоступные страницы с sgds-container) и макеты с боковой панелью (панели мониторинга/внутренние инструменты с sgds-container-sidebar). Триггер по: макету, сбоку, разделенному представлению, макету боковой панели, двум столбцам, трем столбцам, расположению контента, структуре страницы с боковым расположением.
