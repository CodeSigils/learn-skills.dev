SGDS 애플리케이션을 위한 페이지 레이아웃 패턴의 전체 카탈로그입니다. 사용자가 페이지 레이아웃, 콘텐츠 정렬, 측면 패널, 분할 보기, 사이드바 레이아웃, 탐색경로 레이아웃 또는 뷰포트 높이 레이아웃에 대해 물을 때마다 이 기술을 사용하세요. 단순히 '페이지 레이아웃을 어떻게 해야 하나요?' 또는 '2열 레이아웃이 필요해요'라고 말하는 경우에도 마찬가지입니다. 전체 너비 레이아웃(sgds-container가 포함된 공개 페이지) 및 사이드바 포함 레이아웃(sgds-container-sidebar가 포함된 대시보드/내부 도구)을 다룹니다. 트리거 대상: 레이아웃, 옆으로, 분할 보기, 사이드바 레이아웃, 2열, 3열, 콘텐츠 정렬, 옆으로 페이지 구조.
