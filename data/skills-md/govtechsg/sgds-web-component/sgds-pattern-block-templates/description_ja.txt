SGDS コンポーネントとユーティリティで構築された再利用可能な UI ブロックは、任意のページ テンプレート内で組み合わせることができます。ユーザーがアプリ レイアウト、アプリケーション シェル、ページ構造、スティッキー ヘッダー、マストヘッドの配置、mainnav の配置、フッターの配置、sgds-container、sgds-container-sidebar、シンプル アプリ レイアウト、サイドバー アプリ レイアウト、ダッシュボード レイアウト、フィルター パネル、サイドバー フィルター、カテゴリ フィルター、チェックボックス フィルター、または自己完結型 UI セクションについて質問するときは、たとえ「ブロック」という名前を付けていなくても、このスキルを使用してください。これらはドロップイン セクションとシェル構造であり、フル ページではありません。 sgds-pattern-page-templates を使用してそれらを構成し、完全なページを構築します。
