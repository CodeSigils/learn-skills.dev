Многоразовые блоки пользовательского интерфейса, созданные с использованием компонентов и утилит SGDS, которые можно смешивать и сопоставлять внутри любого шаблона страницы. Используйте этот навык всякий раз, когда пользователь спрашивает о макете приложения, оболочке приложения, структуре страницы, прикрепленном заголовке, размещении верхнего колонтитула, размещении основной навигации, размещении нижнего колонтитула, sgds-container, sgds-container-sidebar, простом макете приложения, макете приложения боковой панели, макете информационной панели, панели фильтров, фильтре боковой панели, фильтре категорий, фильтре флажков или любом автономном разделе пользовательского интерфейса — даже если он не называет его «блоком». Это раскрывающиеся разделы и структуры-оболочки, а не полноценные страницы. Составляйте их с помощью шаблонов sgds-pattern-page-templates для создания полноценных страниц.
