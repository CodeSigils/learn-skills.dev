كتل واجهة المستخدم القابلة لإعادة الاستخدام والتي تم إنشاؤها باستخدام مكونات وأدوات مساعدة SGDS والتي يمكن مزجها ومطابقتها داخل أي قالب صفحة. استخدم هذه المهارة عندما يسأل المستخدم عن تخطيط التطبيق، أو غلاف التطبيق، أو بنية الصفحة، أو الرأس الثابت، أو موضع إعلان التسمية الرئيسية، أو موضع التنقل الرئيسي، أو موضع التذييل، أو حاوية sgds، أو الشريط الجانبي لحاوية sgds، أو تخطيط التطبيق البسيط، أو تخطيط تطبيق الشريط الجانبي، أو تخطيط لوحة المعلومات، أو لوحة التصفية، أو مرشح الشريط الجانبي، أو مرشح الفئة، أو مرشح خانة الاختيار، أو أي قسم مستقل لواجهة المستخدم - حتى لو لم يسموه "كتلة". هذه أقسام منسدلة وهياكل صدفية، وليست صفحات كاملة. قم بتأليفها باستخدام قوالب sgds-pattern-page-templates لإنشاء صفحات كاملة.
