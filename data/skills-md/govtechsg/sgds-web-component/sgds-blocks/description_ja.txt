完全な SGDS ページおよびセクションを構築するための再利用可能な UI ブロック。ユーザーがページの構築、レイアウトのデザイン、セクションの作成、または複数のセクションを一緒に構成する場合は常に、このスキルを使用します。アプリ レイアウト、アプリケーション シェル、ページ構造、ヒーロー セクション、CTA (コールトゥアクション)、カード、カード グリッド、機能セクション、製品の利点、統計表示、メトリクス、ページ ヘッダー、ページ タイトル、フィルター インターフェイス、検索フィルター、データ テーブル、詳細カード、セッションの詳細、アプリケーションの詳細、フォーム、ランディング ページ、ダッシュボード、サイドバー ナビゲーション、または主要なページ コンポーネントに関するあらゆる言及でトリガーされます (「ブロック」という名前が付いていなくても)。 「フィルターが必要」、「フォームの構築」、「行動喚起の作成」、「ランディング ページのデザイン」、「統計情報の表示」、「詳細の表示」、「サイドバーのレイアウト」、またはページレベル UI の同様のリクエストにも使用します。これらはドロップイン セクションとシェル構造であり、フル ページではありません。 sgds-template を使用してそれらを構成し、完全なページを構築します。
