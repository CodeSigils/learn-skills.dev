كتل واجهة المستخدم القابلة لإعادة الاستخدام لإنشاء صفحات وأقسام SGDS كاملة. استخدم هذه المهارة عندما يريد المستخدم إنشاء صفحات أو تصميم تخطيطات أو إنشاء أقسام أو إنشاء أقسام متعددة معًا. قم بتشغيل أي ذكر لما يلي: تخطيط التطبيق، غلاف التطبيق، بنية الصفحة، أقسام البطل، عبارات الحث على اتخاذ إجراء، البطاقات، شبكات البطاقات، أقسام الميزات، فوائد المنتج، عروض الإحصائيات، المقاييس، رؤوس الصفحات، عناوين الصفحات، واجهات التصفية، عوامل تصفية البحث، جداول البيانات، بطاقات التفاصيل، تفاصيل الجلسة، تفاصيل التطبيق، النماذج، الصفحات المقصودة، لوحات المعلومات، التنقل في الشريط الجانبي، أو أي مكون رئيسي للصفحة - حتى لو لم يطلقوا عليها اسم "كتلة". استخدمه أيضًا من أجل: "أحتاج إلى مرشح"، أو "إنشاء نموذج"، أو "إنشاء عبارة تحث المستخدم على اتخاذ إجراء"، أو "تصميم صفحة مقصودة"، أو "إظهار الإحصائيات"، أو "عرض التفاصيل"، أو "تخطيط الشريط الجانبي"، أو طلبات مماثلة لواجهة المستخدم على مستوى الصفحة. هذه أقسام منسدلة وهياكل صدفية، وليست صفحات كاملة. قم بتأليفها باستخدام قوالب sgds لإنشاء صفحات كاملة.
