Многоразовые блоки пользовательского интерфейса для создания полных страниц и разделов SGDS. Используйте этот навык всякий раз, когда пользователь хочет создавать страницы, разрабатывать макеты, создавать разделы или составлять несколько разделов вместе. Срабатывает при ЛЮБОМ упоминании: макета приложения, оболочки приложения, структуры страницы, разделов-героев, призывов к действию (CTA), карточек, сеток карточек, разделов функций, преимуществ продукта, отображения статистики, показателей, заголовков страниц, заголовков страниц, интерфейсов фильтров, поисковых фильтров, таблиц данных, карточек с подробными сведениями, сведений о сеансе, сведений о приложении, форм, целевых страниц, информационных панелей, навигации на боковой панели или любого основного компонента страницы — даже если они не называют это «блоком». Также используйте для: «Мне нужен фильтр», «создать форму», «создать призыв к действию», «разработать целевую страницу», «показать статистику», «отобразить детали», «макет боковой панели» или подобных запросов для пользовательского интерфейса на уровне страницы. Это раскрывающиеся разделы и структуры оболочки, а не полные страницы. Составляйте их с помощью шаблонов sgds для создания полноценных страниц.
