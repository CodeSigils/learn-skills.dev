Catálogo completo de tipografías y patrones de texto reutilizables para aplicaciones SGDS. Utilice esta habilidad siempre que el usuario necesite aplicar estilo al texto, crear jerarquías tipográficas, dar formato a encabezados, diseñar listas o necesite diseños de texto consistentes. Úselo también cuando el usuario mencione encabezados, títulos de páginas, texto del cuerpo, listas, párrafos, texto para mostrar, encabezados de contenido o cualquier estilo de tipografía, incluso si solo dice "hacer un título bonito" o "darle estilo a mi texto". Los patrones actuales incluyen encabezados (H1-H6), tipografía de visualización (texto grande y destacado), encabezados de contenido, listas (ordenadas y desordenadas) y párrafos. Cada patrón se vincula directamente a la plantilla HTML sin formato para su implementación.
