كتالوج كامل للطباعة وأنماط النص القابلة لإعادة الاستخدام لتطبيقات SGDS. استخدم هذه المهارة عندما يحتاج المستخدم إلى تصميم النص، أو إنشاء تسلسلات هرمية للطباعة، أو تنسيق العناوين، أو قوائم الأنماط، أو يحتاج إلى تخطيطات نصية متسقة. يُستخدم أيضًا عندما يذكر المستخدم العناوين، أو عناوين الصفحات، أو النص الأساسي، أو القوائم، أو الفقرات، أو نص العرض، أو رؤوس المحتوى، أو أي نمط طباعة - حتى لو قال فقط "اصنع عنوانًا لطيفًا" أو "صمم النص الخاص بي". تتضمن الأنماط الحالية العناوين (H1-H6)، وطباعة العرض (نص بارز كبير)، ورؤوس المحتوى، والقوائم (مرتبة وغير مرتبة)، والفقرات. يرتبط كل نمط مباشرة بقالب HTML الخام للتنفيذ.
