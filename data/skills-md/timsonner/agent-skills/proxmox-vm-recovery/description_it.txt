Gestisce la risoluzione dei problemi e il ripristino delle macchine virtuali (VM) bloccate durante l'avvio sugli host Proxmox VE. Attiva questa abilità quando un utente segnala che una VM (in particolare guest Windows 11/UEFI) non si avvia, si blocca sul logo OVMF o mostra le schermate di caricamento "Avvia opzione di avvio".
