Maneja la solución de problemas y la recuperación de máquinas virtuales (VM) atascadas durante el arranque en hosts Proxmox VE. Active esta habilidad cuando un usuario informe que una máquina virtual (especialmente Windows 11/invitado UEFI) no arranca, se cuelga en el logotipo de OVMF o muestra las pantallas de carga "Iniciar opción de arranque".
