Échafaudez et configurez entièrement un nouveau projet de kit de démarrage de codage agent : un modèle Next.js 16 + TypeScript + Better Auth + Drizzle + PostgreSQL + AI SDK. Utilisez cette compétence chaque fois que l'utilisateur demande à configurer, échafauder, créer, initialiser ou amorcer un « kit de démarrage de codage agent », une « application agent », un « passe-partout agent », une « application Next.js avec auth et db », ou mentionne « create-agentic-app » / « npx create-agentic-app ». Guide l'utilisateur à travers la stratégie de dossier, le choix du gestionnaire de packages, la configuration de Postgres (Docker / Neon / Vercel / BYO), la configuration d'OpenRouter AI, les migrations, une vérification de build et une vérification du serveur de développement - en terminant par un http://localhost:3000 fonctionnel.
