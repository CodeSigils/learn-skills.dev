Создайте и полностью настройте новый проект стартового комплекта агентского кодирования — шаблон Next.js 16 + TypeScript + Better Auth + Drizzle + PostgreSQL + AI SDK. Используйте этот навык всякий раз, когда пользователь запрашивает настройку, создание, инициализацию или начальную загрузку «агентного стартового набора для кодирования», «агентского приложения», «агентского шаблона», «приложения Next.js с аутентификацией и базой данных» или упоминает `create-agentic-app` / `npx create-agentic-app`. Проводит пользователя через стратегию папок, выбор менеджера пакетов, настройку Postgres (Docker/Neon/Vercel/BYO), настройку OpenRouter AI, миграцию, проверку сборки и проверку dev-сервера — заканчивая рабочим http://localhost:3000.
