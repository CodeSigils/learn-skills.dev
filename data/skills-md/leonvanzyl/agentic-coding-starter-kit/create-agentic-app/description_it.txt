Impalca e configura completamente un nuovo progetto Agentic Coding Starter Kit: un boilerplate Next.js 16 + TypeScript + Better Auth + Drizzle + PostgreSQL + AI SDK. Utilizza questa skill ogni volta che l'utente chiede di configurare, impalcare, creare, inizializzare o avviare un "starter kit di codifica agenti", "app agentic", "boilerplate agenti", una "app Next.js con autenticazione e db" o menziona `create-agentic-app` / `npx create-agentic-app`. Guida l'utente attraverso la strategia delle cartelle, la scelta del gestore dei pacchetti, la configurazione di Postgres (Docker/Neon/Vercel/BYO), la configurazione AI di OpenRouter, le migrazioni, un controllo della build e la verifica del server di sviluppo, terminando con un http://localhost:3000 funzionante.
