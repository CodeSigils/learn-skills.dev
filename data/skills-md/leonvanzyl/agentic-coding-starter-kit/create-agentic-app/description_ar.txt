Scaffold وتكوين مشروع Agentic Coding Starter Kit الجديد بالكامل - نموذج Next.js 16 + TypeScript + Better Auth + Drizzle + PostgreSQL + AI SDK النموذجي. استخدم هذه المهارة عندما يطلب المستخدم إعداد أو دعم أو إنشاء أو تهيئة أو تمهيد "مجموعة أدوات بدء ترميز الوكيل" أو "تطبيق وكيل" أو "نموذج وكيل" أو "تطبيق Next.js مع auth وdb"، أو يذكر "create-agentic-app" / "npx create-agentic-app". يرشد المستخدم عبر استراتيجية المجلد، واختيار مدير الحزم، وإعداد Postgres (Docker / Neon / Vercel / BYO)، وتكوين OpenRouter AI، وعمليات الترحيل، وفحص البناء، والتحقق من خادم التطوير - وينتهي بـ http://localhost:3000 العامل.
