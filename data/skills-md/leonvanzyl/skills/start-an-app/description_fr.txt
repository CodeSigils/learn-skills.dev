Interrogez l'utilisateur en profondeur sur ce qu'il souhaite réellement créer, puis élaborez une application Web complète fonctionnelle autour de celui-ci. À utiliser lorsque l'utilisateur souhaite démarrer une nouvelle application, un nouveau site Web, un prototype ou un SaaS ; quand ils ne savent pas quelle pile technologique choisir ; ou lorsqu'ils veulent rapidement un point de départ solide. Couvre la découverte des exigences, la configuration du projet, la base de données (SQLite ou Postgres dans Docker), la connexion, les téléchargements de fichiers, les paiements, les fonctionnalités d'IA, ainsi qu'une véritable page de destination et un tableau de bord.
