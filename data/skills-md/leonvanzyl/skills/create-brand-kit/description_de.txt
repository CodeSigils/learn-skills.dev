Führen Sie einen strukturierten, kritikorientierten Markenidentitätsprozess von jedem Ausgangspunkt aus – einer Unternehmenswebsite, einem schriftlichen Briefing, einer Produktliste oder einfach nur einem Namen und einem Konzept – bis hin zu einem kompletten Markenpaket und Designsystem durch: Logomarke, umrissene Wortmarke, Lockups, Round-Safe-Symbole, selbstthematisierendes Favicon, PNG-Raster, eine generierte Richtlinienseite, eine README-Datei und optionale AI-Merch-Mockups (Shirts, Mützen, Visitenkarten). Verwenden Sie dies immer dann, wenn der Benutzer ein Logo, eine Marke, eine visuelle Identität, ein Rebranding, eine Logomarke, Markenwerte oder einen Favicon/Icon-Satz möchte oder Dinge sagt wie „Entwerfen Sie ein Logo für mein Unternehmen“, „Wir brauchen Branding“, „Machen Sie uns ein Markenkit“ oder teilt eine Unternehmenswebsite mit der Bitte um Identitätsarbeit. Auch wenn sie nur nach „einem Logo“ fragen, nutzen Sie diese Fähigkeit – ein Logo, das ohne seine Varianten, kleine Tests und Richtlinien ausgeliefert wird, ist nicht fertig.
