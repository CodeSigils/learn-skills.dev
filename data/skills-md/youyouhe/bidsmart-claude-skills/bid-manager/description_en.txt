Bid full-process manager. Orchestrates all bid skills to execute automatically in a pipeline, supporting one-click bidding, breakpoint resume, and stage-specific start. Ten stages: analysis → verification → information collection → commercial bid → technical bid → charts → scanned documents → quality inspection → automatic repair → Word generation. Triggered when the user requests one-click bidding, full-process bidding, managing bidding progress, or continuing the bidding process. Precondition: bidding/negotiation/purchasing documents are required.
