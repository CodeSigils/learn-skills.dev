Bieten Sie einen Full-Process-Manager. Orchestriert alle Gebotsfähigkeiten zur automatischen Ausführung in einer Pipeline und unterstützt Gebote mit einem Klick, Breakpoint-Fortsetzung und phasenspezifischen Start. Zehn Stufen: Analyse → Verifizierung → Informationssammlung → kommerzielles Angebot → technisches Angebot → Diagramme → gescannte Dokumente → Qualitätsprüfung → automatische Reparatur → Wortgenerierung. Wird ausgelöst, wenn der Benutzer eine Ein-Klick-Gebotsabgabe, eine Gebotsabgabe im gesamten Prozess, die Verwaltung des Gebotsfortschritts oder die Fortsetzung des Gebotsvorgangs anfordert. Voraussetzung: Angebots-/Verhandlungs-/Kaufunterlagen sind erforderlich.
