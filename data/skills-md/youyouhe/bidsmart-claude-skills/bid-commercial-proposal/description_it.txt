Invia file in formato Markdown alla directory/file di risposta. Attivalo quando l'utente richiede di scrivere sezioni aziendali, documenti aziendali, allegati di offerte o file di preventivi. Supporta anche una modalità di riparazione: si attiva quando l'utente richiede di correggere/aumentare i documenti aziendali o gestire il feedback del controllo qualità. Prerequisito: l'analisi delle offerte deve aver già prodotto un rapporto di analisi.
