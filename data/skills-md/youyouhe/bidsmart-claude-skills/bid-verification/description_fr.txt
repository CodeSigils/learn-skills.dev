Effectuer une vérification article par article du rapport d'analyse du document d'appel d'offres, recouper chaque point de données clé avec les documents de marché originaux. Vérifiez si les montants, les scores, les critères de qualification, les délais, les règles de notation, etc., dans le rapport d'analyse sont cohérents avec le texte original et identifiez les données hallucinées, les informations manquantes et les erreurs numériques. Déclenchez-le lorsque l'utilisateur demande la vérification/validation/audit du rapport d'analyse.
