Convert the Markdown files in the response files/directory into formatted Word (.docx) documents. Automatically extract information such as project name and company name from analysis reports and business documents, and generate the Word file by invoking the generate_docx.js script via command‑line parameters. This is triggered when the user requests to generate a Word document, convert MD to docx, or export response files. Precondition: completed .md files already exist in the response files/directory.
