Erstellen Sie ein Toolkit zum Ersetzen von Platzhaltern für generierte Word-Ausschreibungsdokumente. Extrahieren Sie automatisch alle „InsertXXhere“-Platzhalter im Dokument, generieren Sie eine Excel-Inventarvorlage, kopieren Sie das Python-Ersetzungsskript und detaillierte Nutzungsanweisungen und packen Sie alles in ein einziges ZIP-Archiv. Wird ausgelöst, wenn der Benutzer „Toolkit generieren“, „Platzhaltertool erstellen“ oder „Paketersetzungstool“ anfordert. Voraussetzung: In den Antwortdateien/im Antwortverzeichnis ist bereits ein fertiges Word-Dokument (.docx) vorhanden.
