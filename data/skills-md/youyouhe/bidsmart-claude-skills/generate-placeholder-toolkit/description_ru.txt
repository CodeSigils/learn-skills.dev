Создайте набор инструментов для замены заполнителей для созданных документов предложений Word. Автоматически извлеките все заполнители 【InsertXXhere】 в документе, создайте шаблон инвентаризации Excel, скопируйте сценарий замены Python и подробные инструкции по использованию и упакуйте все в один ZIP-архив. Запускается, когда пользователь запрашивает «создать набор инструментов», «создать инструмент-заполнитель» или «инструмент замены пакета». Предварительное условие: завершенный документ Word (.docx) уже существует в каталоге/файлах ответов.
