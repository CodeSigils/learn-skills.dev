Создавайте креативные, запоминающиеся названия проектов с помощью смайлов для веб-проектов. Использует шаблон PROMPT_FOR_PROJECT_NAME BuildFlow для создания коротких (до 6 слов), уникальных и запоминающихся названий, отражающих цель проекта.
Условия триггера: - Вызывается web-builder-initial во время создания проекта. - Пользователь явно запрашивает: «дайте этому проекту имя», «命名这个项目». - Создается автоматически при создании новых веб-проектов.
Входные данные: описание проекта или запрос пользователя. Выходные данные: название проекта (не более 6 слов) + смайлики.
