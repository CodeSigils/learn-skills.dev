Web プロジェクト用に、絵文字を使用してクリエイティブでキャッチーなプロジェクト名を生成します。 BuildFlow の PROMPT_FOR_PROJECT_NAME テンプレートを使用して、プロジェクトの目的を反映した短くて (6 単語以下)、一意で覚えやすい名前を作成します。
トリガー条件: - プロジェクトの作成中に web-builder-initial によって呼び出されます - ユーザーが明示的に要求: 「このプロジェクトに名前を付けます」、「命名这个项目」 - 新しい Web プロジェクトの作成時に自動生成されます
入力: プロジェクトの説明またはユーザーのリクエスト 出力: プロジェクト名 (≤6 単語) + 絵文字
