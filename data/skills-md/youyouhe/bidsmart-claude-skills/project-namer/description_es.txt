Genere nombres de proyectos creativos y atractivos con emojis para proyectos web. Utiliza la plantilla PROMPT_FOR_PROJECT_NAME de BuildFlow para crear nombres cortos (≤6 palabras), únicos y memorables que reflejen el propósito del proyecto.
Condiciones de activación: - Llamado por web-builder-initial durante la creación del proyecto - El usuario solicita explícitamente: "dale un nombre a este proyecto", "命名这个项目" - Se genera automáticamente al crear nuevos proyectos web
Entradas: descripción del proyecto o solicitud del usuario Salidas: nombre del proyecto (≤6 palabras) + emoji
