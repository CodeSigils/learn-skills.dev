入札文書取得スキル (MCP リファクタリング バージョン) – マテリアル検索、データ抽出、およびプレースホルダー置換のために、MaterialHub API を直接呼び出します。古いバージョンと比較して、FastAPI 中間層が削除され、アーキテクチャが簡素化され、パフォーマンスが向上しました。ユーザーが入札文書 (営業許可証、証明書、契約書、実績記録など) をクエリする必要がある場合、企業または従業員に関する構造化情報を抽出する必要がある場合、または応答ファイル内のプレースホルダー [ここに XX スキャンされたコピーを挿入] を置き換える必要がある場合にトリガーされます。前提条件: MaterialHub API サービスが実行されており (.mcp.json 経由で構成)、マテリアルが MaterialHub にアップロードされています。
