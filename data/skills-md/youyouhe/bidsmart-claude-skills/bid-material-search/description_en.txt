Bid document retrieval skill (MCP refactored version) – directly calls the MaterialHub API for material search, data extraction, and placeholder replacement. Compared to the old version, the FastAPI middle layer has been removed, simplifying the architecture and improving performance. Triggered when the user needs to query bid documents (business licenses, certificates, contracts, performance records, etc.), extract structured information about a company or personnel, or replace the placeholder 【Insert XX scanned copy here】 in response files. Prerequisite: MaterialHub API service is running (configured via .mcp.json), and materials have been uploaded to MaterialHub.
