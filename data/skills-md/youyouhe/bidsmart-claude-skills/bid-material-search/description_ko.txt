입찰 문서 검색 기술(MCP 리팩터링 버전) – 재료 검색, 데이터 추출 및 자리 표시자 교체를 위해 MaterialHub API를 직접 호출합니다. 이전 버전에 비해 FastAPI 미들웨어가 제거되어 아키텍처가 단순화되고 성능이 향상되었습니다. 사용자가 입찰 문서(사업 허가증, 인증서, 계약서, 성과 기록 등)를 쿼리해야 하거나, 회사 또는 직원에 대한 구조화된 정보를 추출해야 하거나, 응답 파일에서 자리 표시자 【여기에 XX 스캔 삽입】을 교체해야 할 때 트리거됩니다. 전제 조건: MaterialHub API 서비스가 실행 중이고(.mcp.json을 통해 구성됨) 자료가 MaterialHub에 업로드되었습니다.
