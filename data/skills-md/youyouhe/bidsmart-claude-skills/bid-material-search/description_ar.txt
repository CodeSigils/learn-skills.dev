مهارة استرجاع مستندات العطاء (إصدار MCP المُعاد هيكلته) - تستدعي واجهة برمجة تطبيقات MaterialHub مباشرةً للبحث عن المواد واستخراج البيانات واستبدال العنصر النائب. بالمقارنة مع الإصدار القديم، تمت إزالة الطبقة الوسطى لـ FastAPI، مما أدى إلى تبسيط البنية وتحسين الأداء. يتم تشغيله عندما يحتاج المستخدم إلى الاستعلام عن مستندات العطاء (تراخيص الأعمال، والشهادات، والعقود، وسجلات الأداء، وما إلى ذلك)، أو استخراج معلومات منظمة حول شركة أو موظفين، أو استبدال العنصر النائب 【أدخل نسخة ممسوحة ضوئيًا XX هنا】 في ملفات الاستجابة. المتطلبات الأساسية: خدمة MaterialHub API قيد التشغيل (تم تكوينها عبر .mcp.json)، وتم تحميل المواد إلى MaterialHub.
