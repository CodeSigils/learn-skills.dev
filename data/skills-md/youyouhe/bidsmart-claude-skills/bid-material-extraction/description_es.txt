Extraer material reutilizable de los documentos de oferta/respuesta. Canalización de tres pasos: (1) Extraer el esquema del documento → toc.json (2) LLM determina qué secciones necesitan extracción → extract_plan.json (3) Extraer texto e imágenes de acuerdo con el plan → sistema de archivos. Se activa cuando un usuario necesita extraer material de documentos de licitación existentes para crear una biblioteca de reutilización. Una vez completada la extracción, el servicio de recuperación lo proporciona la habilidad de búsqueda de material de oferta.
