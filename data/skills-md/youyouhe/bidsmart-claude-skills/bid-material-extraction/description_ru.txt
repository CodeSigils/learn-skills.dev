Извлеките материалы многократного использования из тендерной/ответной документации. Трехэтапный конвейер: (1) Извлечение структуры документа → toc.json (2) LLM определяет, какие разделы необходимо извлечь → extract_plan.json (3) Извлечение текста и изображений в соответствии с планом → файловая система. Срабатывает, когда пользователю необходимо извлечь материал из существующих тендерных документов для создания библиотеки повторного использования. После завершения извлечения услуга поиска предоставляется навыком поиска материалов для торгов.
