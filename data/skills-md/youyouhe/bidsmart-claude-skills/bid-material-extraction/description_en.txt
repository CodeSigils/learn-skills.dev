Extract reusable material from tender/response documents. Three-step pipeline: (1) Extract document outline → toc.json (2) LLM determines which sections need extraction → extraction_plan.json (3) Extract text and images according to the plan → file system. Triggered when the user needs to extract material from existing tender documents to build a reuse library. After extraction is complete, the retrieval service is provided by the bid‑material‑search skill.
