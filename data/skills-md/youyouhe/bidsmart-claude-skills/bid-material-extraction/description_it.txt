Estrarre materiale riutilizzabile dalle offerte/risposte. Pipeline in tre fasi: (1) Estrai la struttura del documento → toc.json (2) LLM determina quali sezioni necessitano di estrazione → Extraction_plan.json (3) Estrai testo e immagini in base al piano → file system. Si attiva quando l'utente deve estrarre materiale dai documenti di offerta esistenti per creare un repository di riutilizzo. Dopo l'estrazione, il servizio di recupero è fornito dalla skill bid-material-search.
