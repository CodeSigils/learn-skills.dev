カテゴリ (ビジネス、電子商取引、ポートフォリオ、ブログなど) ごとに編成された 60 以上の事前構築済み Web テンプレート プロンプトを提供します。ユーザーがカテゴリとテンプレートを選択すると、このスキルにより詳細な開始プロンプトが表示され、これを web-builder-initial で使用して、プロフェッショナルな Web サイトを瞬時に生成できます。
トリガー条件: - ユーザーのリクエスト: 「テンプレート カテゴリを表示」、「利用可能なテンプレートを教えて」、「生成型板」 - ユーザーが特定の種類のサイトを希望: 「e コマース サイトを作成」、「レストランの Web サイトを作成」 - インタラクティブなテンプレート選択ワークフロー
出力: 選択したテンプレート カテゴリの詳細なプロンプト
