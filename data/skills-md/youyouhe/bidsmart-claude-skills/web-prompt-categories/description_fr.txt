Fournissez plus de 60 invites de modèles Web prédéfinis organisées par catégorie (entreprise, commerce électronique, portefeuille, blog, etc.). Les utilisateurs sélectionnent une catégorie + un modèle, et cette compétence fournit une invite de démarrage détaillée qui peut être utilisée avec web-builder-initial pour une génération instantanée et professionnelle de sites Web.
Conditions de déclenchement : - Demandes de l'utilisateur : "montrer les catégories de modèles", "quels modèles sont disponibles", "生成模板" - L'utilisateur souhaite un type de site spécifique : "créer un site de commerce électronique", "créer un site Web de restaurant" - Workflow interactif de sélection de modèles
Résultats : invite détaillée pour la catégorie de modèle sélectionnée
