Предоставьте более 60 готовых веб-шаблонов, сгруппированных по категориям (Бизнес, Электронная коммерция, Портфолио, Блог и т. д.). Пользователи выбирают категорию + шаблон, и этот навык предоставляет подробную стартовую подсказку, которую можно использовать с web-builder-initial для мгновенного профессионального создания веб-сайта.
Условия срабатывания: - Запросы пользователя: «покажи мне категории шаблонов», «какие шаблоны доступны», «生成模板» - Пользователь хочет определенный тип сайта: «создать сайт электронной коммерции», «создать веб-сайт ресторана» - Интерактивный рабочий процесс выбора шаблона
Выходные данные: Подробная подсказка для выбранной категории шаблонов.
