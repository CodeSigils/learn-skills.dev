Convertissez le rapport d'évaluation des offres du format Markdown vers un format JSON structuré. Lisez l'intégralité du fichier `投标评估报告.md` et extrayez-le directement sous la forme d'un `投标评估报告.json` lisible par le front-end. Déclenchez cette opération lorsque l'utilisateur demande de convertir le rapport d'évaluation, de générer le JSON d'évaluation ou de formater les données d'évaluation. Condition préalable : le rapport Markdown d'évaluation des offres doit déjà être complété.
