Converti il ​​report di valutazione dell'offerta dal formato Markdown a un formato JSON strutturato. Leggi l'intero `投标评估报告.md` ed estrailo direttamente in un `投标评估报告.json` leggibile front-end. Precondizione: la valutazione dell'offerta deve aver già generato il report Markdown.
