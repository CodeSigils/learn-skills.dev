Convierta el informe de evaluación de ofertas del formato Markdown a un formato JSON estructurado. Lea el `投标评估报告.md` completo y extráigalo directamente como un `投标评估报告.json` legible desde el front-end. Active esto cuando el usuario solicite convertir el informe de evaluación, generar JSON de evaluación o formatear datos de evaluación. Requisito previo: la evaluación de la oferta ya debe haber generado el informe Markdown.
