Utilice la API de OCR ZhipuBigModel para reconocer texto en imágenes y páginas PDF. Admite una combinación de chino e inglés, escritura a mano y texto impreso, con almacenamiento en caché de nivel de contenido integrado para evitar solicitudes duplicadas. El resultado es un JSON estructurado (que incluye texto por página, estimaciones de tokens y detección de tablas). Se activa cuando un usuario necesita reconocimiento de texto OCR para escaneos de PDF, imágenes de certificados o páginas escaneadas de contratos. También funciona para extraer texto de imágenes de licencias comerciales, certificados de calificación, tarjetas de identificación y otros materiales documentales.
