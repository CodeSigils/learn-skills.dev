Use the ZhiPu BigModel OCR API to perform text recognition on images and PDF pages. It supports mixed Chinese and English, handwritten and printed text, and includes built-in content-level caching to prevent duplicate requests. The output is a structured JSON (containing per‑page text, token estimates, and table detection). This is triggered when a user needs OCR for PDF scans, certificate images, or contract scan pages. It is also suitable for extracting text from images of business licenses, qualification certificates, ID cards, and similar documents.
