Bid business dedicated experience learner. Extract bid-related errors, issues, and lessons learned from the conversation and automatically inject them into the gotchas.md file of bid-* skills. Strictly limited scope: only handle bid business (tender analysis, response document drafting, quality inspection, etc.), and do not learn generic programming or other domain knowledge. Trigger conditions: 1. User says “remember this error” / “remember this lesson” / “summarize experience” / “learn this case”. 2. User explicitly requests “update bid-XXX’s gotchas”. 3. User says “bid experience record” / “tender document issue record”. Preconditions: – The current conversation must be in the context of a bid project (with tender documents, analysis reports, response documents, etc.). – At least one bid-* skill has been invoked recently. Non-trigger conditions: ❌ Non‑bid‑related conversation. ❌ User only complains without explicitly requesting a record. ❌ Issue unrelated to bid business (e.g., generic code errors).
