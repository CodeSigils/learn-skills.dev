正確な検索/置換編集パターンを使用して、既存の Web プロジェクトを変更します。柔軟な HTML マッチングを備えた BuildFlow の実績のある FOLLOW_UP_SYSTEM_PROMPT テンプレートを使用します。
トリガー条件: - ユーザーリクエスト: 「修正网页」、「更新样式」、「追加機能」、「Web サイトの更新」、「色の変更」、「セクションの追加」 - web-output/ ディレクトリに存在する既存の Web ファイル (HTML/CSS/JS) - 記述された特定の変更または拡張機能
入力: 現在のファイルの内容 + 変更リクエスト 出力: 対象となる変更の SEARCH/REPLACE パターンを含む UPDATE_FILE ブロック
