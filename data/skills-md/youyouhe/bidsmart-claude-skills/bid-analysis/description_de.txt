Analysieren Sie Ausschreibungs-/Beratungsdokumente für das öffentliche Beschaffungswesen (PDF, Word, Excel), extrahieren Sie wichtige Informationen wie Bewertungskriterien, technische Anforderungen, kommerzielle Anforderungen, Qualifikationsbedingungen, Budget usw. und erstellen Sie eine strukturierte Gliederung und ein Antwortdokumentverzeichnis. Unterstützt mehrere Dateieingaben (Ausschreibungsbekanntmachung+technisches Datenblatt+Vertragsvorlage usw.). Anwendbar auf Wettbewerbsverhandlungen, offene Ausschreibungen, Einladungsausschreibungen und andere Szenarien. Wird ausgelöst, wenn der Benutzer Ausschreibungs-/Beratungs-/Kaufunterlagen bereitstellt und eine Analyse, ein Verständnis der Anforderungen, eine Extraktion von Bewertungskriterien und die Erstellung einer Angebotsskizze anfordert.
