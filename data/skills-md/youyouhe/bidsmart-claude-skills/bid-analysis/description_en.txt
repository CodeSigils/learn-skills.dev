Analyze government procurement bidding/consultation documents (PDF, Word, Excel), extract key information such as scoring criteria, technical requirements, commercial requirements, qualification conditions, budget, etc., and generate a structured outline and a response document directory. Supports multiple file inputs (tender announcement + technical specification sheet + contract template, etc.). Applicable to competitive negotiations, open tenders, invitation tenders, and other scenarios. Triggered when the user provides bidding/consultation/purchase documents and requests analysis, understanding of requirements, extraction of scoring criteria, and generation of a bid outline.
