요구 사항 사양을 기반으로 소프트웨어 고급 설계 및 세부 설계 문서를 작성합니다. 요구사항 메타데이터와 각 시스템의 요구사항 사양에서 비즈니스 개체, 인터페이스, 사용 사례 등을 읽고 데이터베이스 설계, API 설계, 모듈 설계 등 엔지니어링 수준의 설계 문서를 생성합니다. 3단계 아키텍처를 사용합니다. Phase0은 설계 메타데이터를 생성하고, Phase1은 시스템당 상위 수준 설계를 생성하고, Phase2는 하위 모듈당 세부 설계를 생성합니다. 핵심 기능: 대용량 문서 자동 분할, 시스템 크기(소형/중형/대형)에 따른 계층적 처리로 단일 출력이 지나치게 커지는 것을 방지합니다. 사용자가 소프트웨어 디자인, 상위 수준 디자인, 세부 디자인, 데이터베이스 디자인 또는 API 디자인을 요청할 때 트리거됩니다. 또한 사용자가 설계 문서 수정 또는 보완을 요청할 때 실행되는 복구 모드도 지원합니다. 전제조건: 입찰 요구사항이 요구사항 사양 파일을 이미 생성했어야 합니다.
