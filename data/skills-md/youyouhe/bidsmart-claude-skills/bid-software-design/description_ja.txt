要求仕様に基づいて、ソフトウェアの概要設計書と詳細設計書を作成します。要件メタデータや各システムの要件仕様からビジネスオブジェクト、インターフェース、ユースケースなどの情報を読み取り、データベース設計、API設計、モジュール設計などのエンジニアリングレベルの設計文書を生成します。 3 フェーズ アーキテクチャを使用します。フェーズ 0 は設計メタデータを生成し、フェーズ 1 はシステムごとに高レベルの設計を作成し、フェーズ 2 はサブモジュールごとに詳細な設計を作成します。主な機能: 大きなドキュメントの自動分割、システム サイズ (小/中/大) に基づいた階層処理により、大きすぎる単一出力を回避します。ユーザーがソフトウェア設計、上位設計、詳細設計、データベース設計、または API 設計を要求したときにトリガーされます。また、修復モードもサポートしています。ユーザーが設計ドキュメントの修正または補足を要求したときにトリガーされます。前提条件: 入札要件では要件仕様ファイルがすでに生成されている必要があります。
