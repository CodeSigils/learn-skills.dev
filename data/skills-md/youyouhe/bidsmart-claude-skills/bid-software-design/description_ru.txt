На основе технического задания напишите высокоуровневый проект программного обеспечения и документацию детального проектирования. Считывайте бизнес-объекты, интерфейсы, варианты использования и другую информацию из метаданных требований и спецификаций требований каждой системы, а также создавайте проектные документы инженерного уровня, такие как проект базы данных, проект API и проект модуля. Используйте трехэтапную архитектуру: Фаза 0 генерирует метаданные проекта, Фаза 1 создает проект высокого уровня для каждой системы, Фаза 2 создает детальное проектирование для каждого подмодуля. Основные функции: автоматическое разделение больших документов, иерархическая обработка в зависимости от размера системы (маленькая/средняя/большая), чтобы избежать слишком больших отдельных выходных данных. Срабатывает, когда пользователь запрашивает проектирование программного обеспечения, высокоуровневое проектирование, детальное проектирование, проектирование базы данных или проектирование API. Он также поддерживает режим ремонта: активируется, когда пользователь запрашивает исправление или дополнение проектной документации. Предварительное условие: требования к тендеру должны уже сгенерировать файл спецификации требований.
