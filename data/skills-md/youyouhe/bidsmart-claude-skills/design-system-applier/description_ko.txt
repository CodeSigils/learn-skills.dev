웹 프로젝트에 일관된 디자인 시스템(색상, 테마, 타이포그래피, 간격)을 적용합니다. 사용자 요청에서 디자인 기본 설정을 추출하고 검색/교체 패턴을 생성하여 CSS 변수, Tailwind 클래스 및 테마 구성을 업데이트합니다.
트리거 조건: - 사용자 요청: "색 구성표 변경", "다크 모드 적용", "파란색 테마 사용", "更改配color" - 언급된 디자인 기본 설정(색상, 글꼴, 간격 비율) - 명시적인 디자인 시스템 요구 사항
입력: 디자인 기본 설정 + 기존 웹 파일 출력: 디자인 시스템 변경 사항이 포함된 UPDATE_FILE 블록
