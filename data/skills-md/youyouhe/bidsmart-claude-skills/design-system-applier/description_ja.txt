一貫したデザイン システム (色、テーマ、タイポグラフィ、間隔) を Web プロジェクトに適用します。ユーザーのリクエストからデザイン設定を抽出し、CSS 変数、Tailwind クラス、テーマ設定を更新するための SEARCH/REPLACE パターンを生成します。
トリガー条件: - ユーザーリクエスト: 「カラースキームの変更」、「ダークモードの適用」、「青のテーマの使用」、「変更変更」 - 言及されたデザイン設定 (色、フォント、間隔スケール) - 明示的なデザインシステム要件
入力: デザイン設定 + 既存の Web ファイル 出力: デザイン システムの変更を含む UPDATE_FILE ブロック
