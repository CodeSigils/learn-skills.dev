Conditions de déclenchement : - Demandes des utilisateurs : "changer le jeu de couleurs", "appliquer le mode sombre", "utiliser le thème bleu", "更改配色" - Préférences de conception mentionnées (couleurs, polices, échelle d'espacement) - Exigences explicites du système de conception
Entrées : préférences de conception + fichiers Web existants Sorties : blocs UPDATE_FILE avec modifications du système de conception
