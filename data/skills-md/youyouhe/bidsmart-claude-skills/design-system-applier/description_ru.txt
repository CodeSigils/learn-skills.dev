Применяйте согласованную систему дизайна (цвета, тему, типографику, интервалы) к веб-проектам. Извлекает предпочтения дизайна из запросов пользователей и генерирует шаблоны ПОИСК/ЗАМЕНА для обновления переменных CSS, классов Tailwind и конфигураций тем.
Условия срабатывания: - Запросы пользователя: «изменить цветовую схему», «применить темный режим», «использовать синюю тему», «更改配色» - Указаны предпочтения дизайна (цвета, шрифты, масштаб интервалов) - Явные требования к системе дизайна
Входные данные: настройки дизайна + существующие веб-файлы. Выходные данные: блоки UPDATE_FILE с изменениями в системе дизайна.
