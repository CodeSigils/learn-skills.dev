A universal engineering-grade requirement specification writing paradigm. Applicable to any industry and any tender for requirement refinement. It adopts a two-stage architecture: Phase 0 analyzes the tender to generate project metadata (industry domain, roles, terminology, data conventions, etc.); Phase 1 applies the metadata to a generic writing template, generating detailed requirement specifications system by system. Triggered when the user requests the writing of requirement analysis, requirement specifications, requirement refinement, or the elaboration of functional requirements. It also supports a repair mode: triggered when the user requests to fix/ supplement requirement documents or handle review feedback. Prerequisite: a tender response document or functional requirement list must already exist.
