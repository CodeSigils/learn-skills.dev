Un paradigma universal de redacción de especificaciones de requisitos a nivel de ingeniería. Adecuado para refinar los requisitos en cualquier industria y cualquier documento de licitación. Utiliza una arquitectura de dos etapas: Phase0 analiza la oferta para generar metadatos del proyecto (dominio de la industria, roles, terminología, convenciones de datos, etc.) y Phase1 conecta los metadatos en una plantilla de escritura genérica, generando especificaciones detalladas de requisitos para cada sistema individualmente. Se activa cuando el usuario solicita escribir un análisis de requisitos, especificaciones de requisitos, refinamiento de requisitos o ampliación de requisitos funcionales. También admite un modo de reparación: se activa cuando el usuario solicita corregir/complementar documentos de requisitos o manejar comentarios de revisión. Condiciones previas: ya debe existir un documento de respuesta a la oferta o una lista de requisitos funcionales.
