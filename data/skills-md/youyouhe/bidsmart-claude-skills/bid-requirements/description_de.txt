Ein universelles Paradigma für das Schreiben von Anforderungsspezifikationen auf Ingenieursniveau. Gilt für jede Branche und jede Ausschreibung zur Anforderungsverfeinerung. Es verwendet eine zweistufige Architektur: Phase0 analysiert die Ausschreibung, um Projektmetadaten zu generieren (Branchendomäne, Rollen, Terminologie, Datenkonventionen usw.); Phase1 wendet die Metadaten auf eine generische Schreibvorlage an und generiert System für System detaillierte Anforderungsspezifikationen. Wird ausgelöst, wenn der Benutzer das Schreiben von Anforderungsanalysen, Anforderungsspezifikationen, Anforderungsverfeinerungen oder die Ausarbeitung funktionaler Anforderungen anfordert. Es unterstützt auch einen Reparaturmodus: Dieser wird ausgelöst, wenn der Benutzer eine Korrektur/Ergänzung von Anforderungsdokumenten oder die Bearbeitung von Überprüfungsrückmeldungen anfordert. Voraussetzung: Es muss bereits ein Tender-Response-Dokument oder eine Funktionsanforderungsliste vorliegen.
