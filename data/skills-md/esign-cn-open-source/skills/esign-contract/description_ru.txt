Навыки электронной подписи eSign — поддерживает создание ИИ любого типа контракта/соглашения и форматирует его в формате PDF; загружает существующие файлы для инициирования электронной подписи и возвращает ссылку для подписи.  
Триггерные сценарии: пользователь запрашивает создание, составление или написание любого типа контракта или соглашения (например, «написать кредитный договор», «подготовить для меня соглашение о неразглашении», «создать договор аренды») или запросить инициировать подписание существующего файла контракта, проверить статус подписания, отменить подписание, загрузить подписанный файл или проверить электронную подпись.  
Триггерные слова: написание контракта, создание контракта, проект контракта, создание контракта, форматирование контракта, проект контракта, инициирование подписания, электронная подпись, статус подписания, отмена подписи, загрузка подписанного файла, проверка подписи, проверка подписи, ссылка для подписи, eSign, esign  
Нетриггерные сценарии: пользователь спрашивает только о значении юридических положений контракта, консультируется по выбору платформы для подписи или обсуждает другие продукты электронной подписи, не связанные с eSign.
