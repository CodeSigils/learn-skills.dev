eSign Electronic Signature Skill — поддерживает контракты/соглашения любого типа, созданные с помощью искусственного интеллекта, и форматирует их в PDF-файлы; загружает существующие файлы для инициирования электронной подписи и возвращает ссылку для подписи. Триггерные сценарии: пользователь запрашивает создание, составление или написание любого контракта или соглашения (например, «написать кредитный договор», «составить для меня соглашение о неразглашении», «создать договор аренды») или запросы инициировать подписание существующего файла контракта, проверить ход подписания, отменить подписание, загрузить подписанные файлы или проверить электронные подписи. Триггерные слова: написание контракта, создание контракта, проект контракта, создание контракта, форматирование контракта, проект контракта, инициирование подписания, электронная подпись, ход подписания, отмена подписания, загрузка подписанного файла, проверка подписи, проверка подписи, ссылка для подписи, электронная подпись, дизайн. Нетриггерные сценарии: пользователь только спрашивает о значении юридических положений контракта, консультируется по выбору платформы для подписи или обсуждает другие продукты электронной подписи, не связанные с eSign.
