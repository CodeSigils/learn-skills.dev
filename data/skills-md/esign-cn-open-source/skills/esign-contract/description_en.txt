eSign Electronic Signature Skill — Supports AI-generated contracts/agreements of any type and formats them into PDFs; uploads existing files to initiate electronic signing and returns the signing link. Trigger scenarios: user requests generation, drafting, or writing of any contract or agreement (e.g., “write a loan contract,” “draft an NDA for me,” “create a lease agreement”), or requests to initiate signing on an existing contract file, check signing progress, cancel signing, download signed files, or verify electronic signatures. Trigger words: write contract, generate contract, draft contract, create contract, contract formatting, contract draft, initiate signing, electronic signature, signing progress, cancel signing, download signed file, verify signature, validate signature, signing link, eSign, esign. Non-trigger scenarios: user only asks about the meaning of contract legal clauses, consults on choosing a signing platform, or discusses other e-signature products unrelated to eSign.
