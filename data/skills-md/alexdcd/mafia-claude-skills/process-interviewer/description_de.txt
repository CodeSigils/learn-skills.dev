Unerbittlicher Prozessinterviewer, der vor Baubeginn einen vollständigen, eindeutigen Plan aus dem Kopf des Benutzers extrahiert. Verwenden Sie diese Option, wenn der Benutzer eine komplexe Aufgabe planen, einen Prozess entwerfen, eine Fertigkeit aufbauen, einen Arbeitsablauf erstellen, den Umfang eines Projekts festlegen oder Dinge sagen möchte wie „Ich möchte bauen“, „Lass uns planen“, „Hilf mir beim Durchdenken“, „Ich habe eine Idee für“, „Dies ausarbeiten“, „Befragen Sie mich“, „Hilf mir, den Prozess herauszufinden“, „Ich brauche eine Fertigkeit dafür“ oder jede Variation, bei der der Benutzer eine unscharfe Idee hat, die in einen konkreten Plan umgesetzt werden muss. Verwenden Sie es auch, wenn der Benutzer einen Plan einem Stresstest unterziehen, sein Denken bestätigen oder seine Annahmen in Frage stellen möchte. Wenn das Ziel des Benutzers darin besteht, eine Fertigkeit aufzubauen, erstellt dieser Interviewer diese automatisch, nachdem das Interview abgeschlossen ist. Benutzen Sie diese Fähigkeit IMMER, bevor Sie mit dem Bau von etwas Komplexem beginnen. Selbst wenn der Benutzer zuversichtlich wirkt, offenbart das Interview Lücken, von denen er nicht wusste, dass sie sie haben.
