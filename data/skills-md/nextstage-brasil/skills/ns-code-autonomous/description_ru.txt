(NS) Механизм автономного выполнения с учетом использования — самостоятельно определяет глубину планирования, разрешает сомнения относительно документации/контекста и документации/спецификаций перед эскалацией, отправляет многоагентную реализацию в изолированное рабочее дерево. Используйте в качестве автономной точки входа для локального файла плана, вставленного плана выполнения или специального запроса «запустить это автономно» без каких-либо проблем с GitLab. Также действует как механизм выполнения фазы 2 при вызове ns-execution-gitlab-issue — в этом случае не запускайте автономный конвейер. Не для простых одношаговых изменений (используйте ns-code-coder) и не для непосредственных проблем GitLab (используйте ns-execution-gitlab-issue, который вызывает этот навык внутри себя).
