(NS) Старший технический руководитель анализирует SOLID, чистый код, производительность, безопасность и тестируемость. Используйте упреждающе после написания или изменения кода, перед открытием PR, после закрытия реализации или когда пользователь запрашивает проверку кода, PR-проверку или контрольную точку проверки проблемы — даже если он не называет этот навык. Для выполнения задачи GitLab с ISSUE_URL используйте режим проверки задачи. НЕ используйте для отладки первопричин (используйте ns-code-investigator).
