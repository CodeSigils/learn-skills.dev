(NS) Genera e adatta .gitlab-ci.yml per prodotti SaaS con backend e frontend: test, creazione, gate E2E, distribuzione per filiale. Da utilizzare quando l'utente richiede GitLab CI, configurazione della pipeline o bootstrap CI/CD per un prodotto monorepo. Utilizza references/templates/gitlab-ci.template.yml come base. Fuori dall'ambito dei repository runtime dell'agente puri senza layout backend+frontend.
