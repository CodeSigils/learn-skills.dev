(NS) Специальный агент кодирования для целенаправленной реализации без полного планирования SDD — исправления ошибок, изолированные компоненты, небольшие рефакторинги, сценарии, миграции. Используйте, когда пользователь говорит «просто реализуйте это», «быстрое исправление», «добавьте поле в форму» или дает конкретную задачу по написанию кода без передачи выполнения — даже без указания имени агента. Если в запланированной версии есть файлexecution-handoff.md, следуйте рабочему процессу выполнения-передачи-генератора выполнения-реализации вместо специального цикла этого навыка. Перенаправьте большие многодневные функции на планирование. НЕ создавайте файл require.md, файлы задач или передачу управления выполнением.
