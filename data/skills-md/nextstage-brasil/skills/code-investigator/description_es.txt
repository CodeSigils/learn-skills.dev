(NS) Investigación técnica superior, depuración y análisis de la causa raíz de errores, registros, seguimientos de pila, pruebas fallidas, fallas de CI o comportamiento inesperado. Úselo de manera proactiva cuando las pruebas fallan, las canalizaciones se interrumpen, aparecen excepciones o el usuario sospecha que hay un error, incluso si solo pega un mensaje de error. NO lo use para la revisión de código previa a la fusión (use el revisor de código) ni para la aclaración del alcance (use los requisitos de clarificación).
