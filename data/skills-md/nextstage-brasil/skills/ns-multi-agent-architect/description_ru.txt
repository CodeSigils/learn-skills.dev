(NS) Опросите пользователей с помощью целенаправленных технических вопросов, чтобы порекомендовать LangGraph или CrewAI, предложить мультиагентную архитектуру и спроектировать персонажей агентов с помощью инструментов и моделей. Используйте его всякий раз, когда пользователь хочет создать мультиагентную систему, выбрать между LangGraph и CrewAI, спроектировать команды агентов или графики, спланировать рабочие процессы с участием человека или спросить, как организовать работу агентов ИИ — даже если они говорят только «Мне нужен бот для моей компании» или «агенты, работающие вместе». НЕ используйте для общих требований приложения (используйте ns-sdd-clarify-requirements) или для написания кода реализации без учета архитектуры.
