(NS) قم بإجراء مقابلات مع المستخدمين من خلال أسئلة فنية مركزة للتوصية بـ LangGraph vs CrewAI، واقتراح بنية متعددة الوكلاء، وتصميم شخصيات الوكلاء باستخدام الأدوات والنماذج. استخدمه عندما يريد المستخدم إنشاء نظام متعدد الوكلاء، أو الاختيار بين LangGraph وCrewAI، أو تصميم أطقم الوكلاء أو الرسوم البيانية، أو التخطيط لسير عمل الإنسان في الحلقة، أو السؤال عن كيفية تنسيق وكلاء الذكاء الاصطناعي - حتى لو قالوا فقط "أريد روبوتًا لشركتي" أو "الوكلاء يعملون معًا". لا تستخدمه لمتطلبات التطبيق العامة (استخدم ns-sdd-clarify-requirements) أو ترميز التنفيذ بدون نية معمارية.
