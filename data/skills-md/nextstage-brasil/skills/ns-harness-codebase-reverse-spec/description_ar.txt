(NS) إجراء هندسة عكسية لقاعدة تعليمات برمجية حالية أو قديمة أو غير تقليدية إلى وصف أعمال لا يعتمد على التكنولوجيا لما يفعله النظام فعليًا - قواعد العمل، والجهات الفاعلة، والأذونات، والتسلسلات الهرمية، ودورات حياة الحالة، وعمليات التكامل الخارجية، بدون تفاصيل التنفيذ. استخدم هذه المهارة عندما يذكر المستخدم المجال البنيوي، أو التعليمات البرمجية القديمة، أو التحديث، أو الهندسة العكسية، أو تحليل قاعدة التعليمات البرمجية، أو استخلاص قواعد العمل من التعليمات البرمجية، أو النسخ العكسي، أو توثيق النظام المنتشر، أو تحديد مواصفات من جزء من الكود، أو يريد وصفًا وظيفيًا مطابقًا للمنتج الحالي لدعم إعادة الكتابة أو الترحيل أو الإعداد أو التدقيق - حتى لو لم يذكر هذه المهارة. لا تستخدمه لمراجعة التعليمات البرمجية البسيطة، أو إصلاحات الأخطاء، أو عندما يريد المستخدم صراحةً مستند البنية الفنية.
