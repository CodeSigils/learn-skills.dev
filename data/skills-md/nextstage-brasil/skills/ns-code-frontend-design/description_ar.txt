(NS) واجهة مستخدم إنتاجية مميزة - التخطيط والطباعة والحركة وصقل المكونات التي تتجنب جماليات الذكاء الاصطناعي العامة. يُستخدم عندما يقوم المستخدم بإنشاء أو تحسين الصفحات أو المكونات أو لوحات المعلومات أو النماذج أو أعمال التصميم الموجزة، أو عندما يطلب واجهة مستخدم/تجربة أفضل - حتى لو لم يذكر "تصميم". قم بتحميل docs/context/design-brief.md عند وجوده. لا تستخدمه للعمل على الواجهة الخلفية فقط، أو كتابة المتطلبات، أو تنسيق SDD الكامل (استخدم ns-spec-driven).
