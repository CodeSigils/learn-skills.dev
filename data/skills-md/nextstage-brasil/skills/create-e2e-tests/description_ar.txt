(NS) قم بإنشاء وصيانة اختبارات Cypress E2E باستخدام TypeScript باستخدام بنية الأوامر المدركة للجهاز DRY (مشتركة/صفحات/جهاز). يُستخدم عند كتابة أو إعادة هيكلة مواصفات Cypress أو الأوامر المخصصة أو تنفيذ مهام E2E - وليس عند التخطيط لتخفيض مهمة E2E (استخدم مولد اختبار e2e). اقرأ قواعد تسخير e2e عند وجودها. اكتشاف إلزامي قبل كتابة المواصفات.
