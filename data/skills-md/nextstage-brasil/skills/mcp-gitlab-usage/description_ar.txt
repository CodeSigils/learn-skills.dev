(NS) يرشد الاستخدام الصحيح لأدوات GitLab MCP للتخطيط والمعالم الرئيسية والمشكلات وطلبات الدمج وتقارير التسليم ومزامنة اللوحة. استخدمها عندما يذكر المستخدم GitLab، أو MCP GitLab، أو إنشاء مشكلات، أو بدء التخطيط في GitLab، أو تقرير التسليم، أو تعليقات الإصدار، أو set_issue_labels، أو طلبات الدمج، أو مزامنة التنفيذ - حتى لو لم يذكروا هذه المهارة. لا تقم بإصدار الحمولات يدويًا أو تخطي بوابات التأكيد. لا تستخدم لإدارة المشاريع غير GitLab.
