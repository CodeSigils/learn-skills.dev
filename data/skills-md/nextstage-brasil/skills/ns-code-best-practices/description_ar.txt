(NS) الأمان والتوافق وجودة الويب الحديثة - الرؤوس ومزود خدمة العملاء (CSP) والتبعيات وخطوط الأساس لإمكانية الوصول والتحديث العملي. يُستخدم عندما يطلب المستخدم تشديد الأمان، أو إصلاح CSP/CORS/الرؤوس، أو تحسين التوافق، أو تحديث جودة المكدس - حتى بدون قول "أفضل الممارسات". متعامد مع بوابة SOLID/MR لمراجع الكود ns. لا تستخدم لمراجعة MR الكاملة (استخدم ns-code-reviewer) أو تنفيذ الميزة (استخدم ns-code-coder / ns-spec-driven).
