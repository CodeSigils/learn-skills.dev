(NS) Seguridad, compatibilidad y calidad web moderna: encabezados, CSP, dependencias, líneas base de accesibilidad y modernización pragmática. Úselo cuando el usuario solicite reforzar la seguridad, corregir CSP/CORS/encabezados, mejorar la compatibilidad o modernizar la calidad de la pila, incluso sin decir "mejores prácticas". Ortogonal a la puerta SOLID/MR de ns-code-reviewer. NO lo use para una revisión completa de MR (use ns-code-reviewer) o para la implementación de funciones (use ns-code-coder/ns-spec-driven).
