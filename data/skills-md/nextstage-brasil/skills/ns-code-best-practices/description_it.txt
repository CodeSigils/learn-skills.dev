(NS) Sicurezza, compatibilità e pass di qualità Web moderno: intestazioni, CSP, dipendenze, linee di base per l'accessibilità e modernizzazione pragmatica. Da utilizzare quando l'utente chiede di rafforzare la sicurezza, correggere CSP/CORS/intestazioni, migliorare la compatibilità o modernizzare la qualità dello stack, anche senza menzionare le "migliori pratiche". Porta SOLID/MR ortogonale al revisore di codice ns. NON utilizzare per la revisione MR completa (utilizzare ns-code-reviewer) o per l'implementazione di funzionalità (utilizzare ns-code-coder / ns-spec-driven).
