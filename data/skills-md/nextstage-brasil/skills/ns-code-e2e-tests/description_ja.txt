(NS) 製品ルートにある独立した testing-e2e/Node パッケージで Cypress E2E テストを作成および維持します (欠落している場合はブートストラップ)。 DRY デバイス対応コマンド アーキテクチャ (shared/pages/device)。 Cypress 仕様、カスタム コマンド、グリーンフィールド プロジェクトでの E2E のスキャフォールディング、または E2E タスクの実装を作成またはリファクタリングするときに使用します。E2E タスクのマークダウンを計画するときは使用しません (ns-pm-e2e-test-task-generator を使用します)。ハーネス e2e ルールが存在する場合は、それを読みます。仕様を記述する前に必須の検出。
