(NS) الأمان/التوافق/نظافة a11y + مراجعة إرشادات Vercel Web Interface (العناوين، CSP، deps، إمكانية الوصول). يُستخدم عند تشديد الأمان، أو إصلاح CSP/CORS/الرؤوس، أو مراجعة واجهة المستخدم/التحقق من a11y/تدقيق تجربة المستخدم، أو تطبيق إرشادات واجهة الويب - حتى بدون قول "أفضل الممارسات"؛ أيضًا عند إغلاق ns-proto-creator. لا تستخدم لمراجعة MR/SOLID (مراجع ns)، أو إعادة التصميم المرئي (تصميم الواجهة الأمامية)، أو تنفيذ الميزات (ns-coder / ns-spec-driven).
