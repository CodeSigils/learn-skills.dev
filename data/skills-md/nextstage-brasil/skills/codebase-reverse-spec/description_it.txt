(NS) Eseguire il reverse engineering di una codebase esistente, legacy o brownfield in una descrizione aziendale indipendente dalla tecnologia di ciò che fa effettivamente il sistema: regole aziendali, attori, autorizzazioni, gerarchie, cicli di vita dello stato e integrazioni esterne, senza dettagli di implementazione. Utilizza questa competenza ogni volta che l'utente menziona brownfield, codice legacy, modernizzazione, reverse engineering, analisi della base di codice, estrazione di regole aziendali dal codice, engenharia reversa, documentar sistema legato, gerar spec a partir do código o desidera una descrizione funzionale fedele al prodotto corrente per supportare la riscrittura, la migrazione, l'onboarding o l'audit, anche se non nomina questa competenza. NON utilizzare per semplici revisioni del codice, correzioni di bug o quando l'utente desidera esplicitamente un documento di architettura tecnica.
