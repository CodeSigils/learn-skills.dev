Use this skill whenever the user mentions brownfield, legacy code, modernization, reverse engineering, codebase analysis, extracting business rules from code, engenharia reversa, documentar sistema legado, gerar spec a partir do código, or wants a functional description faithful to the current product to support rewrite, migration, onboarding, or audit — even if they do not name this skill.
