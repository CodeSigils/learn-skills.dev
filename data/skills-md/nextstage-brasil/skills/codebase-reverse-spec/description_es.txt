(NS) Realice ingeniería inversa de una base de código existente, heredada o antigua para convertirla en una descripción empresarial independiente de la tecnología de lo que realmente hace el sistema: reglas comerciales, actores, permisos, jerarquías, ciclos de vida estatales e integraciones externas, sin detalles de implementación. Utilice esta habilidad siempre que el usuario mencione brownfield, código heredado, modernización, ingeniería inversa, análisis de base de código, extracción de reglas comerciales del código, ingeniería inversa, documentar sistema legado, gerar spec a partir del código, o quiera una descripción funcional fiel al producto actual para respaldar la reescritura, la migración, la incorporación o la auditoría, incluso si no menciona esta habilidad. NO lo use para revisiones simples de código, corrección de errores o cuando el usuario desee explícitamente un documento de arquitectura técnica.
