(NS) Créer et maintenir les tests unitaires et d'intégration PHPUnit dans le package backend (tests de démarrage/en cas d'absence). Exécution obligatoire de Docker uniquement avec phpunit --testdox --stop-on-failure --stop-on-error et délai d'attente de 120 secondes. À utiliser lors de l'écriture ou de la refactorisation de tests PHPUnit, de l'implémentation de tâches de tests unitaires ou de l'échafaudage de tests backend sur des projets Laravel/PHP inédits - pas lors de la planification de la démarque des tâches de test (utilisez le générateur de tâches de test unitaire). Lisez les règles de tests backend du harnais lorsqu'elles sont présentes.
