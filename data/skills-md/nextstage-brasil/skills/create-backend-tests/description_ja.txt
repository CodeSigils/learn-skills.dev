(NS) バックエンド パッケージで PHPUnit 単体テストと統合テストを作成および維持します (ブートストラップ テスト/欠落している場合)。 phpunit --testdox --stop-on-failure --stop-on-error および 120 秒のタイムアウトを使用した、必須の Docker のみの実行。テスト タスクのマークダウンを計画するとき (unit-test-task-generator を使用する) ではなく、PHPUnit テストを作成またはリファクタリングするとき、単体テスト タスクを実装するとき、またはグリーンフィールド Laravel/PHP プロジェクトでバックエンド テストをスキャフォールディングするときに使用します。ハーネス バックエンド テスト ルールが存在する場合は、それを読み取ります。
