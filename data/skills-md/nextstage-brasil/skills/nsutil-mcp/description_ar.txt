(NS) إنشاء خوادم MCP وتوسيعها باستخدام NsUtil (`NsUtil\MCP` على `NsUtil\Api`): الأداة، والموجه، وفئات الخادم، والسمات، وأسلاك نقطة نهاية HTTP، وطرق JSON-RPC، واختبارات Docker PHPUnit. يُستخدم عندما يقوم المستخدم بإنشاء أو توسيع خوادم MCP أو أدواته أو مطالباته أو نقاط نهاية MCP أو إرسال JSON-RPC أو اختبارات MCP في التطبيقات التي تعتمد على nextstage-brasil/ns-util - حتى لو لم يذكروا هذه المهارة. لا تخترع واجهات برمجة تطبيقات addTool بطلاقة أو تشغل PHPUnit على المضيف.
