(NS) График поставки тройной производительности — одна скидка с тремя таблицами PERT + Монте-Карло для сценариев производительности P100 (текущий час/FP), P85 (на 50 % быстрее → ×0,50), P50 (на 85 % быстрее → ×0,15). Раздел 0 = коммерческое описание + ключевые даты поставки. Календарные процентили P50/P85/P95 только из pert_montecarlo.py. Используйте, когда человек запрашивает cronograma, prazo, когда мы доставим, P50–P85–P95 de entrega, тройной график, P100/P85/P50 produtividade, FP × мощность в часах/день или даты поставки после коммерческого определения размера FP — даже если они говорят «прогноз», но предоставляют FP + производительность (а не RICE/спринт на уровне истории). НЕ изобретайте R$. НЕ заменяйте ns-commercial-budget. НЕ используйте PERT только для истории без FP (то есть ns-project-manager Phase 5).
