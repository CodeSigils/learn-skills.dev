(NS) إنشاء عملية GraphRAG كاملة - علم الوجود المغلق، وحدات النص الدلالي، الاستخراج المقفل بالمخطط مع الاستشهادات، تحليل الكيان، الحواف المنطقية مع الأدلة والإشارات، المجموعات المصفاة والإجابات المجمعة مع استشهادات لكل صف، اجتياز المسار، فرضيات الاكتشاف الاختيارية، التضمينات المزدوجة (الوحدات + أوصاف الكيانات)، قائمة التحكم بالوصول (ACL) قبل البحث، الإجابات المستشهد بها. استخدمه عندما يريد المستخدم GraphRAG، أو رسم بياني معرفي على المستندات، أو استرجاع متعدد القفزات، أو مستخرجات الكيانات/العلاقات، أو الارتباط غير المباشر أو تحليلات التجميع، أو الاستخراج المنظم من ملفات غير منظمة - حتى لو كانوا يقولون فقط RAG، أو NER، أو الرسم البياني المعرفي، أو الأسئلة والأجوبة المستشهد بها. لا تستخدمه لاختيار مخطط/وضع Postgres وحده (`ns-postgres-rag` أولاً). لا تستخدمه مع متاجر المتجهات المتنافسة، أو لغات استعلام الرسم البياني المجانية، أو التصميمات المتزامنة كحواف.
