(NS) قم بمسح قاعدة التعليمات البرمجية وإنشاء أو تحديث دستور بسيط للهندسة المعمارية-rules.md لوكلاء الذكاء الاصطناعي - التكديس والتخطيط والأنماط والقيود والمؤشرات إلى قواعد أعمق. استخدمه عندما يطلب المستخدم إنشاء قواعد معمارية، أو إنشاء .nextstage-harness/rules/architecture-rules.md، أو سياق وكيل التمهيد، أو تدوين اصطلاحات المشروع، أو تجميع المستندات وتخطيط الوحدة النمطية للوكلاء، أو إعداد قواعد المشروع التي تعمل دائمًا - حتى لو كانوا يقولون "توثيق كيفية عمل هذا الريبو للذكاء الاصطناعي" أو "إنشاء قواعد يقرأها الوكيل في كل جلسة". لا تستخدم للمواصفات التجارية/الوظيفية (harness-codebase-reverse-spec)، أو خرائط SDD brownfield (harness-bootstrap-brownfield)، أو قواعد المؤشر المخصصة ذات الموضوع الواحد دون تمرير بنية كاملة.
