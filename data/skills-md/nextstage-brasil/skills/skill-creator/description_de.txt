(NS) Erstellen oder verbessern Sie projektlokale Agentenfähigkeiten in einem NextStage-Harness-Projekt – entwerfen Sie SKILL.md unter .agents/skills/, führen Sie Evals durch und nutzen Sie dann die Synchronisierung. Verwenden Sie es immer dann, wenn der Benutzer einen Skill erstellen, diesem Projekt einen benutzerdefinierten Skill hinzufügen, SKILL.md erstellen, Skill-Bewertungen/Benchmarks iterieren oder Skill-Beschreibungen optimieren möchte – auch wenn er sagt: „Erstelle einen Skill für unser Repo“ oder „Skill-Creator“. NICHT für Beiträge zum nextstage-brasil/skills-Katalog verwenden (dieses Repo verfügt über einen eigenen Betreuer-Workflow in AGENTS.md).
