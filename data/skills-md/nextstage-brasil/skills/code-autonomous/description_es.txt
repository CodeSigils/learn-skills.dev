(NS) Motor de ejecución autónomo con reconocimiento de arnés: decide por sí mismo la profundidad de la planificación, resuelve dudas sobre documentos/contexto y documentos/especificaciones antes de escalar, envía la implementación de múltiples agentes en un árbol de trabajo aislado. Úselo como punto de entrada independiente para un archivo de plan local, un plan de ejecución pegado o una solicitud ad-hoc de "ejecutar esto de forma autónoma" sin ningún problema de GitLab involucrado. También actúa como motor de ejecución de Fase 2 cuando lo invoca ejecutar-gitlab-issue; en ese caso, no ejecute la canalización independiente. No para ediciones simples de un solo paso (use el codificador de código) y no para problemas de GitLab directamente (use ejecutar-gitlab-issue, que llama a esta habilidad internamente).
