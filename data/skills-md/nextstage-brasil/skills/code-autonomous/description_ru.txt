(NS) Механизм автономного выполнения с учетом использования — самостоятельно определяет глубину планирования, разрешает сомнения относительно документации/контекста и документации/спецификаций перед эскалацией, отправляет многоагентную реализацию в изолированное рабочее дерево. Используйте в качестве автономной точки входа для локального файла плана, вставленного плана выполнения или специального запроса «запустить это автономно» без каких-либо проблем с GitLab. Также действует как механизм выполнения фазы 2 при вызове Execute-gitlab-issue — в этом случае не запускайте автономный конвейер. Не для простого одношагового редактирования (используйте кодировщик) и не для непосредственных проблем GitLab (используйте Execute-gitlab-issue, который вызывает этот навык внутри).
