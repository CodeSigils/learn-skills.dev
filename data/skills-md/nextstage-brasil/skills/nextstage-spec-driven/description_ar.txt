(NS) واجهة التسليم المستندة إلى المواصفات - توضيح النطاق، أو كتابة المتطلبات، أو إنشاء المهام، أو تنفيذ إصدار، أو الإصلاح السريع، أو استئناف العمل المتوقف مؤقتًا. استخدمه عندما يريد المستخدم تحديد ميزة، أو بدء إصدار أو متابعته، أو التنفيذ من المهام، أو إرسال حل سريع، أو استئناف SDD، أو القول "دعونا نبني X" دون تسمية مهارات PM/code الفردية - حتى لو قاموا بتخطي كلمات التخطيط الرسمية. الأحجام التلقائية صغيرة/متوسطة/كبيرة وتفويض مهارات العمال. لا تستخدمه في الإعداد الأساسي، أو تعيين قاعدة التعليمات البرمجية، أو قواعد الهندسة المعمارية، أو الإعداد الكامل للمشروع (استخدم /التحضير اليدوي). لا تقم بتشغيل أداة الاستعداد تلقائيًا أو قم بإدراج الإعداد في خط الأنابيب.
