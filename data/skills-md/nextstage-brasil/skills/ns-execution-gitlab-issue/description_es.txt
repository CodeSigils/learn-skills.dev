(NS) Ejecute un problema de GitLab de extremo a extremo: estado de primer acto, reutilización de ramas y puertas de rama de origen, aislamiento de un único árbol de trabajo, entrega atómica, ciclo de vida de MR, puerta de revisión de código obligatoria con bucle de reparación limitado. Úselo cuando el usuario proporcione un ISSUE_URL de GitLab o solicite implementar un problema de GitLab directamente, no para codificación ad-hoc solo local (use ns-code-coder) o ejecuciones autónomas que no sean de GitLab (use ns-code-autonomous independiente). Delega la codificación real al motor autónomo de código ns. Requiere mcp-gitlab-usage para MCP y ns-code-reviewer para la puerta de revisión.
