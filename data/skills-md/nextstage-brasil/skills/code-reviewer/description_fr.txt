(NS) Révision du code du responsable technique senior sur SOLID, code propre, performances, sécurité et testabilité. Utilisez-le de manière proactive après avoir écrit ou modifié du code, avant d'ouvrir des PR, après la clôture de l'implémentation ou lorsque l'utilisateur demande une révision du code, une révision des PR ou une porte de révision des problèmes, même s'il ne nomme pas cette compétence. Pour l’exécution d’un problème GitLab avec ISSUE_URL, utilisez le mode de révision des problèmes. Ne PAS utiliser pour le débogage de la cause première (utilisez code-investigator).
