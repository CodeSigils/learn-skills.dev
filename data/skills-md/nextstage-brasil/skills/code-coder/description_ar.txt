(NS) وكيل ترميز مخصص للتنفيذ المركّز دون التخطيط الكامل لـ SDD - إصلاحات الأخطاء والمكونات المعزولة وعمليات إعادة البناء الصغيرة والبرامج النصية وعمليات الترحيل. يُستخدم عندما يقول المستخدم "فقط قم بتنفيذ هذا"، أو "إصلاح سريع"، أو "أضف حقلاً إلى النموذج"، أو يعطي مهمة ترميز محددة دون تسليم التنفيذ - حتى بدون تسمية وكيل. عندما يحتوي الإصدار المخطط على Execution-handoff.md، اتبع سير عمل تنفيذ تشغيل مولد التنفيذ بدلاً من الدورة المخصصة لهذه المهارة. إعادة توجيه الميزات الكبيرة متعددة الأيام إلى التخطيط. لا تقم بإنشاء require.md أو ملفات المهام أو تسليم التنفيذ.
