(NS) التحقيق الفني الأول وتصحيح الأخطاء وتحليل السبب الجذري من الأخطاء أو السجلات أو تتبعات المكدس أو الاختبارات الفاشلة أو فشل CI أو السلوك غير المتوقع. يُستخدم بشكل استباقي عند فشل الاختبارات، أو انقطاع المسارات، أو ظهور الاستثناءات، أو عندما يشتبه المستخدم في وجود خطأ - حتى لو قام بلصق رسالة خطأ فقط. لا تستخدم لمراجعة التعليمات البرمجية قبل الدمج (استخدم ns-code-reviewer) أو توضيح النطاق (استخدم ns-sdd-clarify-requirements).
