(NS) Indagine tecnica senior, debug e analisi delle cause principali di errori, log, analisi dello stack, test non riusciti, errori CI o comportamenti imprevisti. Utilizzalo in modo proattivo quando i test falliscono, le pipeline si interrompono, vengono visualizzate eccezioni o l'utente sospetta un bug, anche se si limita a incollare un messaggio di errore. NON utilizzare per la revisione del codice pre-unione (utilizzare ns-code-reviewer) o per chiarimenti sull'ambito (utilizzare ns-sdd-clarify-requirements).
