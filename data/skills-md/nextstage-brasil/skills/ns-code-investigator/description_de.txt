Verwenden Sie es proaktiv, wenn Tests fehlschlagen, Pipelines unterbrochen werden, Ausnahmen auftreten oder der Benutzer einen Fehler vermutet – selbst wenn er nur eine Fehlermeldung einfügt. NICHT zur Codeüberprüfung vor dem Zusammenführen (ns-code-reviewer verwenden) oder zur Klärung des Bereichs (ns-sdd-clarify-requirements verwenden) verwenden.
