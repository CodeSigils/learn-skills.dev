(NS) إثراء المتطلبات قبل التنفيذ الذاتي - مشكلة GitLab أو سياق الدردشة. **وضع المشكلة:** بالنظر إلى ISSUE_URL، اقرأ المشكلة والتعليقات عبر MCP، وتحقق من قاعدة التعليمات البرمجية، وقم بتشغيل تحليل فجوة Grill-me، وانشر تعليقًا داخليًا واحدًا يحتوي على أسئلة مرقمة لمؤلف المشكلة. **وضع الدردشة:** عندما يقوم المستخدم بلصق أو وصف المتطلبات/النطاق في المحادثة (لا توجد مشكلة)، قم بتشغيل نفس التحليل وعرض الأسئلة المرقمة في الدردشة فقط - بدون ملفات، ولا منشورات GitLab. يُستخدم عندما يطلب المستخدم إثراء/تحسين المتطلبات، أو توضيح النطاق، أو الاستعداد للتنفيذ، أو تشغيل Grill-me، أو إنشاء أسئلة حظر - مع أو بدون مشكلة GitLab. لا تستخدم لتنفيذ المشكلة بالكامل (ns-execution-gitlab-issue)، أو مراجعة التعليمات البرمجية (ns-code-reviewer)، أو تخطيط الإصدار (start_execution_planning)، أو إنشاء require.md (ns-sdd-requirements-generator).
