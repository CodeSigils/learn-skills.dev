Используйте, когда ЛЮБАЯ команда завершается с ошибкой с сообщением «команда не найдена», при установке инструментов CLI (ripgrep, fd, jq, yq, bat и т. д.), аудите сред проекта или инструментов пакетного обновления. Срабатывает при: команда не найдена, инструмент установки, отсутствующий двоичный файл, аудит среды, инструменты обновления, которые, apt install, Brew install.
