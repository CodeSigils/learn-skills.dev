Según la información de confirmación, el resumen de cambios o la diferencia proporcionada por el usuario, o las diferencias y el historial del repositorio Git actual, genere, reescriba o verifique un mensaje de confirmación preciso y consistente. Los usuarios pueden usar esto para escribir mensajes de confirmación, modificar mensajes de confirmación, resumir cambios para una confirmación o verificar el formato del mensaje antes de confirmar; También se puede utilizar cuando no se puede acceder a ningún repositorio.
