En fonction des informations de validation, du résumé des modifications ou des différences fournies par l'utilisateur, ou des différences et de l'historique du référentiel Git actuel, générez, réécrivez ou vérifiez un message de validation précis et cohérent. Les utilisateurs peuvent l'utiliser pour écrire des messages de validation, modifier des messages de validation, résumer les modifications d'une validation ou vérifier le formatage des messages avant de valider ; il peut également être utilisé lorsqu'aucun référentiel n'est accessible.
