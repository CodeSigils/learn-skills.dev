استنادًا إلى معلومات الالتزام، أو ملخص التغيير، أو الاختلافات المقدمة من قبل المستخدم، أو الاختلافات وتاريخ مستودع Git الحالي، يمكنك إنشاء رسالة التزام دقيقة ومتسقة أو إعادة كتابتها أو التحقق منها. يمكن للمستخدمين استخدام هذا لكتابة رسائل الالتزام، أو تعديل رسائل الالتزام، أو تلخيص التغييرات الخاصة بالالتزام، أو التحقق من تنسيق الرسالة قبل الالتزام؛ ويمكن استخدامه أيضًا عندما لا يمكن الوصول إلى أي مستودع.
