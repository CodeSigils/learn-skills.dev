На основе информации о фиксации, сводки изменений или различий, предоставленных пользователем, или различий и истории текущего репозитория Git сгенерируйте, перепишите или проверьте точное и согласованное сообщение о фиксации. Пользователи могут использовать это для написания сообщений о фиксации, изменения сообщений о фиксации, обобщения изменений для фиксации или проверки форматирования сообщения перед фиксацией; его также можно использовать, когда репозиторий недоступен.
