In base alle informazioni sul commit, al riepilogo delle modifiche o alle differenze fornite dall'utente, oppure alle differenze e alla cronologia dell'attuale repository Git, genera, riscrivi o verifica un messaggio di commit accurato e coerente. Gli utenti possono utilizzarlo per scrivere messaggi di commit, modificare messaggi di commit, riepilogare le modifiche per un commit o controllare la formattazione dei messaggi prima del commit; può essere utilizzato anche quando nessun repository è accessibile.
