Basierend auf den vom Benutzer bereitgestellten Commit-Informationen, der Änderungszusammenfassung oder dem Diff oder den Unterschieden und dem Verlauf des aktuellen Git-Repositorys können Sie eine genaue und konsistente Commit-Nachricht generieren, umschreiben oder überprüfen. Benutzer können damit Commit-Nachrichten schreiben, Commit-Nachrichten ändern, Änderungen für einen Commit zusammenfassen oder die Nachrichtenformatierung vor dem Commit überprüfen; Es kann auch verwendet werden, wenn kein Repository verfügbar ist.
