Convenciones y patrones de TypeScript para cualquier código TypeScript en Phoenix monorepo, incluidos js/packages/, app/ y cualquier otro directorio de TS. Utilice esta habilidad siempre que escriba, revise o modifique código TypeScript: nuevas funciones, tipos, exportaciones, pruebas o refactorizaciones. También se activa cuando el usuario pregunta sobre patrones de TS, convenciones de nomenclatura o mejores prácticas para este proyecto.
