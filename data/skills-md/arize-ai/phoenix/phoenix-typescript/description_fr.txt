Conventions et modèles TypeScript pour tout code TypeScript dans le monorepo Phoenix, y compris js/packages/, app/ et tout autre répertoire TS. Utilisez cette compétence chaque fois que vous écrivez, révisez ou modifiez du code TypeScript : nouvelles fonctions, types, exportations, tests ou refactors. Déclenchez également lorsque l'utilisateur pose des questions sur les modèles TS, les conventions de dénomination ou les meilleures pratiques pour ce projet.
