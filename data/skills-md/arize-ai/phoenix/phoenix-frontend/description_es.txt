Directrices de desarrollo frontend para la plataforma de observabilidad Phoenix AI. Úselo al escribir, revisar o modificar componentes de React, código TypeScript, estilos o funciones de UI en el directorio app/. Activadores de cualquier tarea de frontend: nuevos componentes, cambios en la interfaz de usuario, estilos, correcciones de accesibilidad, manejo de formularios, visualización de errores, trabajo de diseño o refactorización de componentes. Úselo también cuando el usuario pregunte sobre convenciones de interfaz, patrones de componentes o estándares de diseño para este proyecto.
