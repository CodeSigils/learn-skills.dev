Génère des extraits de code d'intégration pour les intégrations de traçage Phoenix et les connecte à l'interface utilisateur d'intégration du projet. Produit des dépendances d'installation et des sections d'implémentation pour les SDK tels qu'OpenAI, LangChain, Vercel AI SDK et autres. Prend en charge Python et TypeScript. À utiliser lorsqu'on vous demande de créer du code d'intégration, de tracer des extraits de configuration, des exemples de démarrage rapide ou du code de démarrage pour une intégration de framework.
