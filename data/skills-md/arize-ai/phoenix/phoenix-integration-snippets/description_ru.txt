Создает фрагменты кода адаптации для интеграции трассировки Phoenix и подключает их к пользовательскому интерфейсу адаптации проекта. Создает зависимости установки и разделы реализации для таких SDK, как OpenAI, LangChain, Vercel AI SDK и других. Поддерживает Python и TypeScript. Используйте, когда вас просят создать вводный код, фрагменты настройки трассировки, примеры быстрого запуска или начальный код для интеграции с платформой.
