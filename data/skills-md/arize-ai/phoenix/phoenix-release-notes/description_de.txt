Erstellen Sie eine Phoenix-Release-Dokumentation, die auf tatsächlichen Codeänderungen basiert. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Versionshinweise schreiben, eine Version dokumentieren, die Versionsdokumentation aktualisieren oder undokumentierte Versionen erwähnen möchte. Wird auch ausgelöst, wenn der Benutzer GitHub-Versionsbeschreibungen aktualisieren, Einträge zur Seite mit Versionshinweisen hinzufügen oder fragen möchte, was sich in einer aktuellen Phoenix-Version geändert hat.
