Créez une documentation de version Phoenix fondée sur les modifications réelles du code. Utilisez cette compétence chaque fois que l'utilisateur demande à rédiger des notes de version, à documenter une version, à mettre à jour la documentation d'une version ou à mentionner des versions non documentées. Déclenchez également lorsque l'utilisateur souhaite mettre à jour les descriptions de version de GitHub, ajouter des entrées à la page des notes de version ou demander ce qui a changé dans une version récente de Phoenix.
