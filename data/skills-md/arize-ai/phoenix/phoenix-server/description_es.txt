Guía de desarrollo de backend para la plataforma de observabilidad Phoenix AI (Strawberry GraphQL, SQLAlchemy async, FastAPI). Utilice esta habilidad al escribir o modificar el código del servidor Python en el repositorio de Phoenix: agregando mutaciones, tipos, migraciones o pruebas. Activa cualquier tarea de backend que toque src/phoenix/server/, src/phoenix/db/ o tests/unit/server/.
