Руководство по внутренней разработке для платформы наблюдения за искусственным интеллектом Phoenix (Strawberry GraphQL, SQLAlchemy async, FastAPI). Используйте этот навык при написании или изменении кода сервера Python в репозитории Phoenix — добавлении мутаций, типов, миграций или тестов. Запускается при любой серверной задаче, касающейся src/phoenix/server/, src/phoenix/db/ илиtests/unit/server/.
