Pflegen Sie den Phoenix llms.txt-Dokumentationsindex unter docs/phoenix/llms.txt – die maschinenlesbare Dokumentenzuordnung, die von KI-Agenten und der „px docs fetch“-CLI verwendet wird. Verwenden Sie diese Fähigkeit immer dann, wenn Sie llms.txt-Einträge hinzufügen, prüfen oder neu organisieren. Wird ausgelöst, wenn der Benutzer llms.txt, docs index, px docs oder LLM-freundliche Dokumentation erwähnt.
