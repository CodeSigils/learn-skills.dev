Conservez l'index de documentation Phoenix llms.txt dans docs/phoenix/llms.txt — la carte de documents lisible par machine utilisée par les agents IA et la CLI « px docs fetch ». Utilisez cette compétence chaque fois que vous ajoutez, auditez ou réorganisez des entrées llms.txt. Déclenchez lorsque l'utilisateur mentionne llms.txt, docs index, px docs ou une documentation compatible LLM.
