Python OpenInference インストルメンテーション コードの正確さと完全性を確認します。このスキルは、Python インスツルメンタ パッケージをレビューするときに使用します。新しいインストゥルタ、PR を変更する場合、またはユーザーが既存のインスツルメンタのコード品質の監査/レビュー/チェックを要求する場合に使用します。 「インストルメンタをレビューする」、「コードをチェックする」、「パッケージを監査する」、「このインストルメンタは正しいか」などのフレーズ、またはプロジェクト標準に照らして OpenInference Python インストルメンテーション パッケージを検証するリクエストをトリガーします。
