Esaminare il codice della strumentazione Python OpenInference per verificarne la correttezza e la completezza. Usa questa abilità durante la revisione di un pacchetto Instrumentor Python, che si tratti di un nuovo Instrumentor, di un PR che ne modifica uno o quando l'utente chiede di verificare/revisionare/controllare la qualità del codice di un Instrumentor esistente. Attivazione di frasi come "rivedere lo strumento", "controllare il codice", "controllare il pacchetto", "questo strumento è corretto" o qualsiasi richiesta di convalida di un pacchetto di strumentazione Python OpenInference rispetto agli standard del progetto.
