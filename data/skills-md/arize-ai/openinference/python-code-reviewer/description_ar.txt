قم بمراجعة كود أدوات Python OpenInference للتأكد من صحتها واكتمالها. استخدم هذه المهارة عند مراجعة حزمة أدوات بايثون - سواء كانت أداة جديدة، أو علاقات عامة تقوم بتعديل واحدة، أو عندما يطلب المستخدم تدقيق/مراجعة/التحقق من جودة كود أداة موجودة. قم بتشغيل عبارات مثل "مراجعة الأداة"، أو "التحقق من الكود"، أو "تدقيق الحزمة"، أو "هل هذه الأداة صحيحة"، أو أي طلب للتحقق من صحة حزمة أدوات OpenInference Python مقابل معايير المشروع.
