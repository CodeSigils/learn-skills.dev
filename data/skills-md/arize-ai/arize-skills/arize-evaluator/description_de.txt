FÜHREN SIE DIESE FÄHIGKEIT für LLM-als-Richter-Bewertungsworkflows auf Arize an: Erstellen/Aktualisieren von Evaluatoren, Ausführen von Bewertungen für Spannen oder Experimente, Aufgaben, Trigger-Lauf, Spaltenzuordnung und kontinuierliche Überwachung. Wird verwendet, wenn der Benutzer sagt: Erstellen Sie einen Evaluator, einen LLM-Richter, Halluzination/Treue/Korrektheit/Relevanz, führen Sie eine Evaluierung durch, bewerten Sie meine Spannen oder mein Experiment, streichen Sie Aufgaben, Trigger-Lauf, Triggerevaluierung, Spaltenzuordnung, kontinuierliche Überwachung, Abfragefilter für Evaluierungen, Evaluatorversion oder verbessern Sie eine Evaluator-Eingabeaufforderung.
