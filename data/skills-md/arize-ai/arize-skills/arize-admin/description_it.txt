Gestisce utenti, organizzazioni, spazi, ruoli, associazioni di ruoli, restrizioni sulle risorse e chiavi API di Arize tramite la CLI ax. Utilizzo per flussi di lavoro di amministrazione aziendale: invito e rimozione di utenti, inserimento di nuovi team, creazione di ruoli personalizzati per mappature SAML/SSO, assegnazione di ruoli agli utenti, limitazione dell'accesso a livello di progetto e gestione delle chiavi di servizio per architetture multi-tenant. Copre gli utenti axe, le organizzazioni axe, gli spazi axe, i ruoli axe, le associazioni dei ruoli axe, le restrizioni alle risorse axe e le chiavi API axe.
