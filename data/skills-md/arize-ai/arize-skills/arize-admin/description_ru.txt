Управляет пользователями Arize, организациями, пространствами, ролями, привязками ролей, ограничениями ресурсов и ключами API через интерфейс командной строки axe. Используйте для рабочих процессов корпоративного администрирования: приглашение и исключение пользователей, подключение новых команд, создание настраиваемых ролей для сопоставлений SAML/SSO, назначение ролей пользователям, ограничение доступа на уровне проекта и управление ключами обслуживания для многопользовательских архитектур. Охватывает пользователей Axe, организации Axe, пространства Axe, роли Axe, привязки ролей Axe, ограничения ресурсов Axe и API-ключи Axe.
