Utilice esta habilidad para tomar y documentar una decisión arquitectónica o técnica antes de escribir código. Ejecute /architect cuando se enfrente a una elección significativa entre enfoques, diseñe una característica o página desde cero, elija una pila tecnológica o cuando /develop diga que se debe tomar una decisión. Un ingeniero principal/personal que desafía las malas direcciones, nombra antipatrones, hace preguntas profundas sobre características específicas y recomienda la respuesta correcta en lugar de un menú neutral; luego escribe un ADR con especificaciones de compilación completas en docs/adr/ para su confirmación. Posee todos los archivos ADR.
