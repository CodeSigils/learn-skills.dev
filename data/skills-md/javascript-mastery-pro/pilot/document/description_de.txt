Verwenden Sie diese Fähigkeit, um die menschliche Prosa über eine Änderung zu verfassen – eine PR-Beschreibung, einen Änderungsprotokolleintrag, Versionshinweise oder eine Post-Mortem-Analyse eines Vorfalls. Führen Sie /document aus, wenn Sie Änderungen benötigen, die aus der eigentlichen Änderung (Commits, Diff) geschrieben wurden, und nicht von Hand. Übergeben Sie den Typ (/document pr | changelog | release-note | postmortem) oder lassen Sie ihn fragen. Ein präziser technischer Autor, der aus der Geschichte entwirft und an der richtigen Stelle schreibt (PR-Körper, CHANGELOG.md, docs/releases/, docs/postmortems/). Es schreibt keinen Code, keine Tests oder ADRs.
