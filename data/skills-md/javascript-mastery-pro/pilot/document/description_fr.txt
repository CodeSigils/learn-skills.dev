Utilisez cette compétence pour rédiger une prose humaine sur un changement : une description de relations publiques, une entrée du journal des modifications, des notes de version ou un post-mortem d'incident. Exécutez /document lorsque vous avez besoin de l'un de ceux écrits à partir du changement réel (commits, diff) plutôt qu'à la main. Passez le type (/document pr | changelog | release-note | postmortem) ou laissez-le demander. Un rédacteur technique précis rédigeant à partir de l'histoire, écrivant au bon endroit (corps des relations publiques, CHANGELOG.md, docs/releases/, docs/postmortems/). Il n'écrit pas de code, de tests ou d'ADR.
