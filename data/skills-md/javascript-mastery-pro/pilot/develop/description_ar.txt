استخدم هذه المهارة لإنشاء ميزة — واجهة مستخدم أو واجهة منطقية/خلفية — من تصميم معتمد. قم بتشغيل /develop لتنفيذ صفحة أو مكون أو واجهة برمجة تطبيقات أو خدمة أو طبقة بيانات أو أي شريحة. إنها أول بوابة لاتخاذ القرار: إذا كان البناء يتطلب اختراع شيء لم يتم تحديده بعد (نظام تصميم، أو تكوين صفحة، أو موفر، أو نموذج بيانات، أو سلوك الميزة) ولم يسجله ADR، /develop توقفات وتوجيهك إلى /architect. وإلا فإنه يقرأ ADR + AGENTS.md (+ design.md لواجهة المستخدم) ويبني خريطة الطريق ويطورها. لا يتخذ قرارات تتعلق بالهندسة المعمارية أو يكتب ADRs (/architect).
