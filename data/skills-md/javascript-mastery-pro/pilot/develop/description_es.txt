Utilice esta habilidad para crear una función (UI o lógica/backend) a partir de un diseño aprobado. Ejecute /develop para implementar una página, componente, API, servicio, capa de datos o cualquier segmento. Primero se dirige a la decisión: si la construcción requeriría inventar algo indeciso (un sistema de diseño, composición de página, un proveedor, modelo de datos o el comportamiento de una característica) y ningún ADR lo registra, /develop se detiene y lo dirige a /architect. De lo contrario, lee ADR + AGENTS.md (+ design.md para UI) y compila, avanzando en la hoja de ruta. No toma decisiones de arquitectura ni escribe ADR (/arquitecto).
