Verwenden Sie diese Fähigkeit, um eine Funktion – UI oder logisch/Backend – aus einem genehmigten Design zu erstellen. Führen Sie /develop aus, um eine Seite, Komponente, API, einen Dienst, eine Datenschicht oder ein beliebiges Segment zu implementieren. Es geht zunächst um die Entscheidung: Wenn für die Erstellung etwas Unentschlossenes erfunden werden müsste (ein Designsystem, eine Seitenzusammensetzung, ein Anbieter, ein Datenmodell oder das Verhalten einer Funktion) und kein ADR dies aufzeichnet, stoppt /develop und leitet Sie an /architect weiter. Andernfalls liest es ADR + AGENTS.md (+ design.md für UI) und erstellt, um die Roadmap voranzutreiben. Es trifft keine Architekturentscheidungen und schreibt keine ADRs (/architect).
