Используйте этот навык для создания функции — пользовательского интерфейса или логической/серверной части — на основе утвержденного проекта. Запустите команду /develop, чтобы реализовать страницу, компонент, API, службу, уровень данных или любой фрагмент. Сначала он принимает решение: если для сборки потребуется изобрести что-то нерешенное (систему дизайна, композицию страниц, поставщика, модель данных или поведение функции), и никакой ADR не записывает это, /develop останавливается и направляет вас в /architect. В противном случае он читает ADR + AGENTS.md (+ design.md для пользовательского интерфейса) и строит, продвигая дорожную карту. Он не принимает архитектурные решения и не пишет ADR (/architect).
