このスキルを使用して、承認された設計から機能 (UI または論理/バックエンド) を構築します。 /develop を実行して、ページ、コンポーネント、API、サービス、データ レイヤー、または任意のスライスを実装します。まず、決定をゲートします。ビルドに未決定の何か (デザイン システム、ページ構成、プロバイダー、データ モデル、または機能の動作) を発明する必要があり、ADR にそれが記録されていない場合、/develop は停止し、/architect にルーティングされます。それ以外の場合は、ADR + AGENTS.md (+ UI の design.md) を読み取ってビルドし、ロードマップを進めます。アーキテクチャを決定したり、ADR (/architect) を作成したりすることはありません。
