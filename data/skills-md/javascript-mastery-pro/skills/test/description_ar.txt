قم بتشغيل /test لكتابة مجموعة اختبار للتعليمات البرمجية التي قمت بإنشائها أو تغييرها للتو، بعد تنفيذ ميزة أو مسار أو إصلاح. يستهدف التغييرات غير الملتزم بها تلقائيًا، ويقرأ تفضيلات الاختبار.json لإطار العمل الخاص بك (يسأله ويحفظه في حالة غيابه)، ويختار الإستراتيجية الصحيحة لكل ملف: المسار السعيد، وحالات الحافة، وحالات الخطأ، وإمكانية الوصول.
