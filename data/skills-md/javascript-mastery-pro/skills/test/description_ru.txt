Запустите /test, чтобы написать набор тестов для кода, который вы только что создали или изменили, после реализации функции, маршрута или исправления. Автоматически определяет незафиксированные изменения, считывает тестовый файл Preferences.json для вашей платформы (запрашивает и сохраняет его, если он отсутствует) и выбирает правильную стратегию для каждого файла: счастливый путь, крайние случаи, состояния ошибок, доступность.
