Esegui /test per scrivere una suite di test per il codice appena creato o modificato, dopo aver implementato una funzionalità, un percorso o una correzione. Prende di mira automaticamente le modifiche non confermate, legge le preferenze di test.json per il tuo framework (lo chiede e lo salva se assente) e sceglie la giusta strategia per file: percorso felice, casi limite, stati di errore, accessibilità.
