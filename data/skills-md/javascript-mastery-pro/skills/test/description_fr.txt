Exécutez /test pour écrire une suite de tests pour le code que vous venez de créer ou de modifier, après avoir implémenté une fonctionnalité, un itinéraire ou un correctif. Cible automatiquement les modifications non validées, lit le test préférences.json pour votre framework (le demande et l'enregistre en cas d'absence) et choisit la bonne stratégie par fichier : chemin heureux, cas extrêmes, états d'erreur, accessibilité.
