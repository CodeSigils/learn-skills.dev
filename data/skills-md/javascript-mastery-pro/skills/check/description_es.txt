Ejecute /check antes de fusionar para confirmar que el cambio es correcto. Dos modos: `/verificar verificar` impulsa la aplicación real y demuestra el comportamiento según las especificaciones (se cumple cada criterio de aceptación, se construye cada superficie especificada); `/check review` ejecuta una revisión de código senior en un modelo diferente al que escribió el código. Verificar después de/desarrollar, revisar antes de un PR. Escribe los resultados en docs/reviews/; nunca edita tu código.
