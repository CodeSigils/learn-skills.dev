Ejecute /develop para crear una función, interfaz de usuario o backend, a partir de un diseño aprobado, una página, componente, API, servicio o segmento de datos. Si algo que soporta carga está indeciso y ninguna especificación lo registra, se detiene y lo dirige a /architect; de lo contrario, lee la especificación más AGENTS.md, construye y avanza el alcance.
