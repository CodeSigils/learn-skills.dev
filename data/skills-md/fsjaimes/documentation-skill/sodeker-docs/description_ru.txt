Общая документация по проектам программного обеспечения с идентификацией визуального стиля (белый + турецкая + без засечек) и интерактивными диаграммами/фигурами в стиле Distill. Функционирование куба возобновлено, техническая документация, установка, поддержка и руководство пользователя. Добавлен HTML из-за ошибки, а также петиция Markdown. Макет с контентом для поиска и боковой панелью навигации по адресу.
