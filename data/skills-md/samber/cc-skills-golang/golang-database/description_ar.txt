دليل شامل للوصول إلى قاعدة بيانات Go. يغطي الاستعلامات ذات المعلمات، ومسح البنية، ومعالجة الأعمدة الخالية، وأنماط الأخطاء، والمعاملات، ومستويات العزل، وSELECT FOR UPDATE، وتجمع الاتصال، ومعالجة الدُفعات، ونشر السياق، وأدوات الترحيل. استخدم هذه المهارة عند كتابة أو مراجعة أو تصحيح أخطاء كود Golang الذي يتفاعل مع PostgreSQL أو MariaDB أو MySQL أو SQLite. مشغلات أيضًا لاختبار قاعدة البيانات أو أي سؤال حول استعلامات قاعدة البيانات/sql أو sqlx أو pgx أو SQL في Golang. لا تؤدي هذه المهارة بشكل صريح إلى إنشاء مخططات قاعدة بيانات أو ترحيل SQL.
