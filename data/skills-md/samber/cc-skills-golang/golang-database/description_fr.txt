Guide complet pour l’accès à la base de données Go. Couvre les requêtes paramétrées, l'analyse des structures, la gestion des colonnes NULLable, les modèles d'erreur, les transactions, les niveaux d'isolement, SELECT FOR UPDATE, le pool de connexions, le traitement par lots, la propagation du contexte et les outils de migration. Utilisez cette compétence chaque fois que vous écrivez, révisez ou déboguez du code Golang qui interagit avec PostgreSQL, MariaDB, MySQL ou SQLite. Déclenche également des tests de base de données ou toute question sur les requêtes base de données/sql, sqlx, pgx ou SQL dans Golang. Cette compétence ne génère explicitement PAS de schémas de base de données ni de SQL de migration.
