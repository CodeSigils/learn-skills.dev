Guía completa para el acceso a la base de datos Go. Cubre consultas parametrizadas, escaneo de estructuras, manejo de columnas anulables, patrones de error, transacciones, niveles de aislamiento, SELECCIONAR PARA ACTUALIZAR, grupo de conexiones, procesamiento por lotes, propagación de contexto y herramientas de migración. Utilice esta habilidad siempre que escriba, revise o depure código Golang que interactúe con PostgreSQL, MariaDB, MySQL o SQLite. También desencadena pruebas de bases de datos o cualquier pregunta sobre bases de datos/sql, sqlx, pgx o consultas SQL en Golang. Esta habilidad explícitamente NO genera esquemas de bases de datos ni migración SQL.
