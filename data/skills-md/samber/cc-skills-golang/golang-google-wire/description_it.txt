Iniezione di dipendenze in fase di compilazione in Golang utilizzando google/wire: wire.NewSet, wire.Build, wire.Bind (interfaccia→concrete), wire.Struct, wire.Value, wire.InterfaceValue, wire.FieldsOf, funzioni di pulizia, //go:build wireinject file injector e generato wire_gen.go. Applicare quando si utilizza o si adotta google/wire, quando la base di codice importa `github.com/google/wire` o quando si collega un grafico dell'applicazione in fase di compilazione tramite "wire.Build". Per DI runtime con riflessione, vedere la skill `samber/cc-skills-golang@golang-uber-dig`.
