Guía de documentación completa para proyectos de Golang, que cubre comentarios de godoc, README, CONTRIBUTING, CHANGELOG, Go Playground, pruebas de ejemplo, documentos API y llms.txt. Úselo al escribir o revisar comentarios de documentos, documentación, agregar ejemplos de código, configurar sitios de documentos o discutir las mejores prácticas de documentación. Activadores tanto para bibliotecas como para aplicaciones/CLI.
