Guida completa alla documentazione per i progetti Golang, che copre commenti godoc, README, CONTRIBUTING, CHANGELOG, Go Playground, test di esempio, documenti API e llms.txt. Da utilizzare quando si scrivono o si revisionano commenti a documenti, documentazione, si aggiungono esempi di codice, si configurano siti di documenti o si discutono le migliori pratiche sulla documentazione. Trigger sia per le librerie che per le applicazioni/CLI.
