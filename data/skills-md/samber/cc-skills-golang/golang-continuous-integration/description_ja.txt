Provides CI/CD pipeline configuration using GitHub Actions for Golang projects.テスト、リンティング、SAST、セキュリティ スキャン、コード カバレッジ、Dependabot、Renovate、GoReleaser、コード レビューの自動化、リリース パイプラインをカバーします。これは、Go プロジェクトの CI のセットアップ、ワークフローの構成、リンターまたはセキュリティ スキャナーの追加、Dependabot または Renovate のセットアップ、リリースの自動化、または既存の CI パイプラインの改善を行うときに常に使用します。 Also use when the user wants to add quality gates to their Go project.
