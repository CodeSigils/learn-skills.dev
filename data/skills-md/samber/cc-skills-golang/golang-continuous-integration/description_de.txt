Bietet CI/CD-Pipeline-Konfiguration mit GitHub Actions für Golang-Projekte. Deckt Tests, Linting, SAST, Sicherheitsscans, Codeabdeckung, Dependabot, Renovate, GoReleaser, Code-Review-Automatisierung und Release-Pipelines ab. Verwenden Sie dies, wenn Sie CI für ein Go-Projekt einrichten, Workflows konfigurieren, Linters oder Sicherheitsscanner hinzufügen, Dependabot oder Renovate einrichten, Releases automatisieren oder eine bestehende CI-Pipeline verbessern. Verwenden Sie es auch, wenn der Benutzer seinem Go-Projekt Qualitäts-Gates hinzufügen möchte.
