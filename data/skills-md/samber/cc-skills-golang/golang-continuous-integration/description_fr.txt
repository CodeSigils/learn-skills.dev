Fournit la configuration du pipeline CI/CD à l’aide des actions GitHub pour les projets Golang. Couvre les tests, le peluchage, SAST, l'analyse de sécurité, la couverture du code, Dependabot, Renovate, GoReleaser, l'automatisation de la révision du code et les pipelines de versions. Utilisez-le lors de la configuration de CI pour un projet Go, de la configuration de flux de travail, de l'ajout de linters ou de scanners de sécurité, de la configuration de Dependabot ou de Renovate, de l'automatisation des versions ou de l'amélioration d'un pipeline CI existant. À utiliser également lorsque l'utilisateur souhaite ajouter des portes de qualité à son projet Go.
