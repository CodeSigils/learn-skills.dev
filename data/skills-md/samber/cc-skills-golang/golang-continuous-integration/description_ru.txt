Обеспечивает настройку конвейера CI/CD с помощью действий GitHub для проектов Golang. Охватывает тестирование, анализ, SAST, сканирование безопасности, покрытие кода, Dependabot, Renovate, GoReleaser, автоматизацию проверки кода и конвейеры выпуска. Используйте это при настройке CI для проекта Go, настройке рабочих процессов, добавлении линтеров или сканеров безопасности, настройке Dependabot или Renovate, автоматизации выпусков или улучшении существующего конвейера CI. Также используйте, когда пользователь хочет добавить элементы качества в свой проект Go.
