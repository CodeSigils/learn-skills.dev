Bietet eine umfassende Anleitung zum Schreiben produktionsbereiter Golang-Tests. Behandelt tabellengesteuerte Tests, Testsuiten mit testify, Mocks, Unit-Tests, Integrationstests, Benchmarks, Codeabdeckung, parallele Tests, Fuzzing, Fixtures, Goroutine-Leckerkennung mit Goleak, Snapshot-Tests, Speicherlecks, CI mit GitHub Actions und idiomatische Namenskonventionen. Verwenden Sie dies, wenn Sie Tests schreiben, nach Testmustern fragen oder CI für Go-Projekte einrichten. Unverzichtbar für JEDES testbezogene Gespräch in Go.
