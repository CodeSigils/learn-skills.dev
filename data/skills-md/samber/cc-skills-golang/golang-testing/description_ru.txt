Содержит подробное руководство по написанию готовых к использованию тестов Golang. Охватывает табличные тесты, наборы тестов с testify, макеты, модульные тесты, интеграционные тесты, тесты, покрытие кода, параллельные тесты, фаззинг, фикстуры, обнаружение утечек горутины с помощью goleak, тестирование моментальных снимков, утечки памяти, CI с действиями GitHub и идиоматические соглашения об именах. Используйте это при написании тестов, вопросах о шаблонах тестирования или настройке CI для проектов Go. Необходим для ЛЮБОГО разговора, связанного с тестированием, в Go.
