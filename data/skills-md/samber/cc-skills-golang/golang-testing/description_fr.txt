Fournit un guide complet pour écrire des tests Golang prêts pour la production. Couvre les tests basés sur des tables, les suites de tests avec testify, les simulations, les tests unitaires, les tests d'intégration, les benchmarks, la couverture de code, les tests parallèles, le fuzzing, les montages, la détection de fuites de goroutines avec goleak, les tests d'instantanés, les fuites de mémoire, le CI avec les actions GitHub et les conventions de dénomination idiomatiques. Utilisez-le lorsque vous rédigez des tests, posez des questions sur les modèles de test ou configurez des projets CI pour Go. Indispensable pour TOUTE conversation liée aux tests dans Go.
