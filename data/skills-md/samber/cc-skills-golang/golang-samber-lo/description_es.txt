Ayudantes de programación funcional para Golang usando samber/lo: más de 500 funciones genéricas con seguridad de tipos para sectores, mapas, canales, cadenas, matemáticas, tuplas y concurrencia (Map, Filter, Reduce, GroupBy, Chunk, Flatten, Find, Uniq, etc.). Paquete central inmutable (lo), variantes concurrentes (lo/parallel también conocido como lop), mutaciones in situ (lo/mutable también conocido como lom), iteradores diferidos (lo/it también conocido como loi para Go 1.23+) y SIMD experimental (lo/exp/simd). Se aplica cuando se usa o se adopta samber/lo, cuando el código base importa github.com/samber/lo o cuando se implementan transformaciones de datos de estilo funcional en Go. No para canalizaciones de transmisión (→ Ver habilidad golang-samber-ro).
