Aides à la programmation fonctionnelle pour Golang utilisant samber/lo — Plus de 500 fonctions génériques de type sécurisé pour les tranches, les cartes, les canaux, les chaînes, les mathématiques, les tuples et la concurrence (Map, Filter, Reduction, GroupBy, Chunk, Flatten, Find, Uniq, etc.). Package immuable de base (lo), variantes concurrentes (lo/parallel aka lop), mutations sur place (lo/mutable aka lom), itérateurs paresseux (lo/it aka loi pour Go 1.23+) et SIMD expérimental (lo/exp/simd). Appliquer lors de l'utilisation ou de l'adoption de samber/lo, lorsque la base de code importe github.com/samber/lo ou lors de la mise en œuvre de transformations de données de style fonctionnel dans Go. Pas pour les pipelines de streaming (→ Voir la compétence golang-samber-ro).
