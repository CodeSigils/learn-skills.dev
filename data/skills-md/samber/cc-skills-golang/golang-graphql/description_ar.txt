تنفيذ واجهات برمجة تطبيقات GraphQL في Golang باستخدام gqlgen أو graphql-go. يتم تطبيقه عند إنشاء خوادم GraphQL، أو تصميم المخططات، أو كتابة وحدات الحل، أو التعامل مع الاشتراكات، أو دمج GraphQL مع خدمات Go HTTP الحالية. ينطبق أيضًا عند استيراد قاعدة التعليمات البرمجية `github.com/99designs/gqlgen` أو `github.com/graph-gophers/graphql-go`.
