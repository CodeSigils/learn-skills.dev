Содержит руководство по настройке макетов и рабочих пространств проекта Golang. Используйте это при запуске нового проекта Go, организации существующей базы кода, настройке монорепозитория с несколькими пакетами, создании инструментов CLI с несколькими основными пакетами или выборе структуры каталогов. Примените это для любой работы по инициализации или реструктуризации проекта Go.
