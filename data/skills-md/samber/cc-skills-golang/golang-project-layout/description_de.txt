Bietet eine Anleitung zum Einrichten von Golang-Projektlayouts und Arbeitsbereichen. Verwenden Sie dies immer dann, wenn Sie ein neues Go-Projekt starten, eine vorhandene Codebasis organisieren, ein Monorepo mit mehreren Paketen einrichten, CLI-Tools mit mehreren Hauptpaketen erstellen oder sich für die Verzeichnisstruktur entscheiden. Wenden Sie dies für alle Go-Projektinitialisierungs- oder Umstrukturierungsarbeiten an.
