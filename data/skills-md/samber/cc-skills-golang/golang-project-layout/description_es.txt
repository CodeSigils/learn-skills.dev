Proporciona una guía para configurar espacios de trabajo y diseños de proyectos de Golang. Úselo siempre que inicie un nuevo proyecto de Go, organice una base de código existente, configure un monorepo con múltiples paquetes, cree herramientas CLI con múltiples paquetes principales o decida la estructura del directorio. Aplique esto para cualquier trabajo de inicialización o reestructuración de proyectos Go.
