Bietet Best Practices für Linting und Golangci-Lint-Konfiguration für Go-Projekte. Behandelt das Ausführen von Linters, das Konfigurieren von .golangci.yml, das Unterdrücken von Warnungen mit Nolint-Anweisungen, das Interpretieren der Lint-Ausgabe und das Verwalten von Linter-Einstellungen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Linters ausführt, golangci-lint konfiguriert, nach Lint-Warnungen oder -Unterdrückungen fragt, Codequalitätstools einrichtet oder fragt, welche Linters für ein Go-Projekt aktiviert werden sollen. Verwenden Sie es auch, wenn der Benutzer Golangci-Lint, Go Vet, Staticcheck, Revive oder ein anderes Linting-Tool von Go erwähnt.
