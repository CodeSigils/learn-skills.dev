Conventions de dénomination Go (Golang) : couvrent les packages, les constructeurs, les structures, les interfaces, les constantes, les énumérations, les erreurs, les booléens, les récepteurs, les getters/setters, les options fonctionnelles, les acronymes, les fonctions de test et les noms de sous-tests. Utilisez cette compétence lors de l'écriture d'un nouveau code Go, de la révision ou de la refactorisation, du choix entre des alternatives de dénomination (New vs NewTypeName, isConnected vsconnected, ErrNotFound vs NotFoundError, StatusReady vs StatusUnknown à iota 0), du débat sur les noms de packages Go (anti-modèles utils/helpers) ou de questions sur les meilleures pratiques de dénomination Go. Se déclenche également lorsque l'utilisateur mentionne MixedCaps vs Snake_case, les constantes ALL_CAPS, Get-prefix sur les getters ou la casse de la chaîne d'erreur. Ne PAS utiliser pour les questions générales de mise en œuvre de Go qui n'impliquent pas de décisions de dénomination.
