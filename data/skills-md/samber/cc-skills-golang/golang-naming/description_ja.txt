Go (Golang) の命名規則 — パッケージ、コンストラクター、構造体、インターフェイス、定数、列挙型、エラー、ブール値、レシーバー、ゲッター/セッター、関数オプション、頭字語、テスト関数、およびサブテスト名をカバーします。このスキルは、新しい Go コードを作成するとき、レビューまたはリファクタリングをするとき、命名方法の選択 (New と NewTypeName、isConnected と Connected、ErrNotFound と NotFoundError、iota 0 での StatusReady と StatusUnknown) の選択、Go パッケージ名 (utils/helpers のアンチパターン) について議論するとき、または Go の命名ベスト プラクティスについて尋ねるときに使用します。また、ユーザーが MixedCaps とsnake_case、ALL_CAPS 定数、ゲッターの Get-prefix、またはエラー文字列の大文字と小文字について言及したときにもトリガーされます。名前の決定に関係しない一般的な Go 実装の質問には使用しないでください。
