Refactorisation Golang — le processus sûr et à grande échelle pour restructurer le code Go existant : un filet de sécurité adaptatif à la couverture, des transformations préservant le comportement pilotées par des outils (gopls Rename/Inline/Extract, `gofmt -r`, `eg`, `gopatch`, `go/analysis` fixateurs), le catalogue Fowler mappé sur Go, rompant les cycles d'importation, déplaçant les types entre les packages et un flux de travail humain dans la boucle de petits empilés PR sur une branche de refactoring. Appliquer lorsque le code est difficile à maintenir, qu'une fonction/un type est devenu trop volumineux, qu'une odeur de code doit être corrigée, que l'ajout d'une fonctionnalité est bloqué par la structure actuelle ou que l'utilisateur demande de nettoyer, de refactoriser ou d'améliorer le code Go - également pour renommer à grande échelle, extraire des fonctions/interfaces, déplacer du code entre des packages, diviser des packages ou planifier une refactorisation en plusieurs étapes.
