swaggo/swag가 포함된 Golang OpenAPI/Swagger 문서 — 주석 주석(@Summary, @Param, @Success, @Router, @Security), swag 초기화 코드 생성, 프레임워크 통합(gin, echo, Fiber, chi, net/http), 보안 정의(Bearer/JWT, OAuth2, API 키) 및 구조체 태그(swaggertype, enums, example, swaggerignore). Go 프로젝트에서 Swagger/OpenAPI 문서를 추가 또는 유지 관리할 때 또는 코드베이스가 github.com/swaggo/swag, github.com/swaggo/gin-swagger, github.com/swaggo/echo-swagger, github.com/swaggo/http-swagger 또는 github.com/swaggo/files를 가져올 때 적용합니다.
