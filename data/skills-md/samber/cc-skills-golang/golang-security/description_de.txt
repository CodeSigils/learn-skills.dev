Best Practices für Sicherheit und Schwachstellenprävention für Golang. Behandelt Injektion (SQL, Befehl, XSS), Kryptografie, Dateisystemsicherheit, Netzwerksicherheit, Cookies, Geheimnisverwaltung, Speichersicherheit und Protokollierung. Bewerben Sie sich, wenn Sie Go-Code aus Sicherheitsgründen schreiben, überprüfen oder prüfen oder wenn Sie an riskantem Code arbeiten, der Krypto, I/O, Geheimnisverwaltung, Benutzereingabeverarbeitung oder Authentifizierung betrifft. Beinhaltet die Konfiguration von Sicherheitstools.
