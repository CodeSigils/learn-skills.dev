Libreria di configurazione Golang che utilizza spf13/viper: precedenza a più livelli (flag > env > file > KV > default), BindPFlag/BindPFlags, SetEnvPrefix + SetEnvKeyReplacer + AutomaticEnv, ReadInConfig + ConfigFileNotFoundError, Unmarshal + tag struct mapstructure, Sub per sottoalberi, WatchConfig + OnConfigChange per il ricaricamento a caldo, viper.New() per l'isolamento del test e integrazione KV remota. Applicare quando si utilizza o si adotta spf13/viper o quando la codebase importa `github.com/spf13/viper`. Per la struttura dei comandi CLI insieme a viper, vedere la skill `samber/cc-skills-golang@golang-spf13-cobra`. Per l'architettura CLI generale, vedere `samber/cc-skills-golang@golang-cli`.
