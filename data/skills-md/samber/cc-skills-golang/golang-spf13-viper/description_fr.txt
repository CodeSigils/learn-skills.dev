Bibliothèque de configuration Golang utilisant spf13/viper — priorité en couches (flag > env > file > KV > default), BindPFlag/BindPFlags, SetEnvPrefix + SetEnvKeyReplacer + AutomaticEnv, ReadInConfig + ConfigFileNotFoundError, Unmarshal + balises de structure mapstructure, Sub pour les sous-arborescences, WatchConfig + OnConfigChange pour le rechargement à chaud, viper.New() pour l'isolation des tests et à distance Intégration KV. Appliquer lors de l'utilisation ou de l'adoption de spf13/viper, ou lorsque la base de code importe `github.com/spf13/viper`. Pour la structure des commandes CLI aux côtés de viper, consultez la compétence `samber/cc-skills-golang@golang-spf13-cobra`. Pour l'architecture générale de la CLI, voir `samber/cc-skills-golang@golang-cli`.
