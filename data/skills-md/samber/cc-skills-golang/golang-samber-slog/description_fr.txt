Extensions de journalisation structurée pour Golang utilisant les packages samber/slog-**** — pipelines multi-gestionnaires (slog-multi), échantillonnage de journaux (slog-sampling), formatage des attributs (slog-formatter), middleware HTTP (slog-fiber, slog-gin, slog-chi, slog-echo) et routage backend (slog-datadog, slog-sentry, slog-loki, slog-syslog, slog-logstash, slog-graylog...). Appliquer lors de l'utilisation ou de l'adoption de slog, ou lorsque la base de code importe déjà un package github.com/samber/slog-*.
