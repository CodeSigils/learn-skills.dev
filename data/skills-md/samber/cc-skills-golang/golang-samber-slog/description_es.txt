Extensiones de registro estructuradas para Golang que utilizan paquetes samber/slog-****: canalizaciones de múltiples controladores (slog-multi), muestreo de registros (slog-sampling), formato de atributos (slog-formatter), middleware HTTP (slog-fiber, slog-gin, slog-chi, slog-echo) y enrutamiento de backend (slog-datadog, slog-sentry, slog-loki, slog-syslog, slog-logstash, slog-graylog...). Aplicar cuando se usa o adopta slog, o cuando el código base ya importa cualquier paquete github.com/samber/slog-*.
