Marco de aplicación de Golang que utiliza uber-go/fx: fx.New, fx.Provide, fx.Invoke, fx.Module, fx.Lifecycle hooks, fx.Annotate (nombre/grupo/As), fx.Decorate, fx.Supply, fx.Replace, fx.WithLogger y Run() con reconocimiento de señales. Se aplica cuando se usa o adopta uber-go/fx, cuando el código base importa `go.uber.org/fx` o cuando se conectan servicios con fx.New. Para DI sin formato sin ciclo de vida, consulte la habilidad `samber/cc-skills-golang@golang-uber-dig`.
