公式 Go 言語サーバーである「gopls」を介した Golang セマンティック コード インテリジェンス - 定義への移動、参照の検索、呼び出し/実装階層、ワークスペース シンボルの検索、パッケージ API の検出、診断、安全な名前変更、リファクタリング (抽出/インライン/フィル/リライト コード アクション)、フォーマット、および生成されたテスト。 gopls 独自の MCP サーバー (`go_*` ツール)、Claude Code のネイティブ `LSP` ツール、または `gopls` CLI を介してエージェントに到達します。 Go コードのナビゲートまたはリファクタリングを行うときに使用します。定義へのジャンプ、名前変更前の呼び出しサイトの検索、ファイルまたはパッケージの依存関係の理解、編集後の診断の実行、抽出/インライン化/名前変更などです。公開されたエコシステム用ではありません — `go.mod` にないパッケージ、バージョン、ライセンス、インポーター — → `samber/cc-skills-golang@golang-pkg-go-dev` スキル (`godig`) を参照してください。ツリー全体の脆弱性監査ではありません → `samber/cc-skills-golang@golang-security` スキル (`govulncheck`) を参照してください。
