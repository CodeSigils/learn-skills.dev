Inteligencia de código semántico de Golang a través de `gopls`, el servidor de lenguaje oficial de Go: acceso a la definición, búsqueda de referencias, jerarquía de llamadas/implementación, búsqueda de símbolos del espacio de trabajo, descubrimiento de API de paquetes, diagnóstico, cambio de nombre seguro, refactores (acciones de extracción/en línea/relleno/reescritura de código), formato y pruebas generadas. Llega a un agente a través del propio servidor MCP de gopls (herramientas `go_*`), la herramienta `LSP` nativa de Claude Code o la CLI `gopls`. Úselo al navegar o refactorizar el código Go: saltar a una definición, buscar sitios de llamadas antes de cambiar el nombre, comprender las dependencias de un archivo o paquete, ejecutar diagnósticos después de una edición o extraer/incorporar/cambiar el nombre. No para el ecosistema publicado (paquetes que no están en su `go.mod`, versiones, licencias, importadores) → Consulte la habilidad `samber/cc-skills-golang@golang-pkg-go-dev` (`godig`). No para una auditoría de vulnerabilidad de todo el árbol → Consulte la habilidad `samber/cc-skills-golang@golang-security` (`govulncheck`).
