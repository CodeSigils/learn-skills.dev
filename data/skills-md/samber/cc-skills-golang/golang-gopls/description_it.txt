Intelligenza del codice semantico Golang tramite `gopls`, il server ufficiale del linguaggio Go: go-to-definition, ricerca di riferimenti, gerarchia di chiamate/implementazione, ricerca di simboli dell'area di lavoro, rilevamento di API di pacchetti, diagnostica, ridenominazione sicura, refactoring (azioni di codice di estrazione/inline/riempimento/riscrittura), formattazione e test generati. Raggiunge un agente tramite il server MCP di gopls (strumenti `go_*`), lo strumento `LSP` nativo di Claude Code o la CLI `gopls`. Da utilizzare durante la navigazione o il refactoring del codice Go: passaggio a una definizione, ricerca di siti di chiamata prima di una ridenominazione, comprensione delle dipendenze di un file o di un pacchetto, esecuzione della diagnostica dopo una modifica o estrazione/incorporamento/rinomina. Non per l'ecosistema pubblicato — pacchetti non presenti nel tuo `go.mod`, versioni, licenze, importatori — → Vedi la skill `samber/cc-skills-golang@golang-pkg-go-dev` (`godig`). Non per un controllo delle vulnerabilità dell'intero albero → Vedi la skill `samber/cc-skills-golang@golang-security` (`govulncheck`).
