Intelligence du code sémantique Golang via `gopls`, le serveur officiel du langage Go — accès à la définition, recherche de références, hiérarchie d'appel/implémentation, recherche de symboles d'espace de travail, découverte d'API de package, diagnostics, renommage sécurisé, refactorisations (actions d'extraction/inline/remplir/réécriture de code), formatage et tests générés. Atteint un agent via le propre serveur MCP de gopls (outils `go_*`), l'outil `LSP` natif de Claude Code ou la CLI `gopls`. À utiliser lors de la navigation ou de la refactorisation du code Go : accéder à une définition, rechercher des sites d'appel avant un changement de nom, comprendre les dépendances d'un fichier ou d'un package, exécuter des diagnostics après une modification ou extraire/insérer/renommer. Pas pour l'écosystème publié — packages ne figurant pas dans votre `go.mod`, versions, licences, importateurs — → Voir la compétence `samber/cc-skills-golang@golang-pkg-go-dev` (`godig`). Pas pour un audit de vulnérabilité de l'arbre entier → Voir la compétence `samber/cc-skills-golang@golang-security` (`govulncheck`).
