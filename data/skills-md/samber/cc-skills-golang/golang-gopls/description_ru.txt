Анализ семантического кода Golang через gopls, официальный сервер языка Go — переход к определению, поиск ссылок, иерархия вызовов/реализации, поиск символов рабочей области, обнаружение API пакетов, диагностика, безопасное переименование, рефакторинг (действия извлечения/встраивания/заполнения/перезаписи кода), форматирование и сгенерированные тесты. Доступ к агенту осуществляется через собственный MCP-сервер gopls (инструменты go_*), собственный инструмент LSP от Claude Code или интерфейс командной строки gopls. Используйте при навигации или рефакторинге кода Go — переход к определению, поиск сайтов вызовов перед переименованием, понимание зависимостей файла или пакета, запуск диагностики после редактирования или извлечение/встраивание/переименование. Не для опубликованной экосистемы — пакеты, которых нет в вашем `go.mod`, версии, лицензии, импортеры — → См. навык `samber/cc-skills-golang@golang-pkg-go-dev` (`godig`). Не для аудита уязвимостей всего дерева → См. навык `samber/cc-skills-golang@golang-security` (`govulncheck`).
