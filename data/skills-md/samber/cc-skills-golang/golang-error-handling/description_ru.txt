Идиоматическая обработка ошибок Golang — создание, перенос с помощью %w, error.Is/As, error.Join, пользовательские типы ошибок, дозорные ошибки, паника/восстановление, единое правило обработки, структурированное ведение журнала с помощью slog, промежуточное программное обеспечение для ведения журнала HTTP-запросов и samber/oops для производственных ошибок. Создано для возможности использования журналов в любом масштабе с помощью сторонних инструментов агрегирования журналов. Применяется при создании, упаковке, проверке или регистрации ошибок в коде Go.
