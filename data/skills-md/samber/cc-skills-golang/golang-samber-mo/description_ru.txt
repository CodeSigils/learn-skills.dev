Монадические типы для Golang с использованием samber/mo — типы Option, Result, Once, Future, IO, Task и State для типобезопасных значений, допускающих значение NULL, обработки ошибок и функциональной композиции с подпакетами конвейера. Применяется при использовании или принятии samber/mo, когда база кода импортирует github.com/samber/mo или при рассмотрении шаблонов функционального программирования в качестве конструкции безопасности для Golang.
