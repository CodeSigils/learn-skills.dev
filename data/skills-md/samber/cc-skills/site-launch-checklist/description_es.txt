Lista de verificación previa al lanzamiento de un nuevo sitio web. Orquesta la configuración de análisis (GA4, PostHog, Google Search Console, Ahrefs), cumplimiento legal, encabezados y auditorías de seguridad, SEO y GEO con investigación de palabras clave validadas contra Google Trends (robots.txt, mapas de sitio, llms.txt, política de IA, marcado de esquema, hreflang), consistencia de redacción a través de TONE.md y un pase de humanizador en el lenguaje coincidente, OpenGraph y vistas previas sociales, conjunto de favicon completo con manifiesto y puertas de calidad. (Lighthouse, Core Web Vitals, accesibilidad WCAG, pruebas móviles) y configuración de un agente SEO semanal. Utilice esta habilidad siempre que el usuario mencione el lanzamiento de un sitio/aplicación, la implementación de un dominio en producción, una auditoría previa al lanzamiento, el envío de un sitio de marketing/docs/SaaS o un imán de clientes potenciales, o diga "lista de verificación para el sitio", "listo para enviar", "antes de publicar", "auditoría antes del lanzamiento", "listo para producción" o solicite una revisión del sitio.
