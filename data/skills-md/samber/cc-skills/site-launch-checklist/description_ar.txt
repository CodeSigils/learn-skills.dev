قائمة مرجعية قبل الإطلاق لشحن موقع ويب جديد. ينسق إعداد التحليلات (GA4، وPostHog، وGoogle Search Console، وAhrefs)، والامتثال القانوني، والترويسات الأمنية والتدقيق، وتحسين محركات البحث (SEO) وGEO مع البحث عن الكلمات الرئيسية التي تم التحقق من صحتها وفقًا لمؤشرات Google (robots.txt، وsitemaps، وllms.txt، وسياسة الذكاء الاصطناعي، وترميز المخطط، وhreflang)، واتساق كتابة النصوص عبر TONE.md وتمرير إنساني باللغة المطابقة، وOpenGraph والمعاينات الاجتماعية، ومجموعة الأيقونات المفضلة الكاملة مع البيان، وبوابات الجودة (Lighthouse، وCore Web Vitals، وإمكانية الوصول إلى WCAG، واختبار الهاتف المحمول)، وإعداد وكيل SEO أسبوعي. استخدم هذه المهارة عندما يذكر المستخدم إطلاق موقع/تطبيق، أو نشر نطاق للإنتاج، أو تدقيق ما قبل الإطلاق، أو شحن موقع تسويق/مستندات/SaaS أو مغناطيس رئيسي، أو يقول "قائمة مرجعية للموقع"، أو "جاهز للشحن"، أو "قبل بدء البث المباشر"، أو "التدقيق قبل الإطلاق"، أو "جاهز للعمل"، أو يطلب مراجعة الموقع.
