Esperto di conformità per snyk-agent-scan, lo scanner dei file delle competenze dell'agente, NON per altri strumenti Snyk CLI (snyk test, snyk code SAST, snyk iac, snyk container). Corregge gli avvisi attraverso la ristrutturazione dei contenuti, mai sopprimendo o eliminando le informazioni. Copre ogni file in una directory di abilità: SKILL.md, references/, asset/ e qualsiasi ribasso secondario. Applicare durante la creazione di una nuova competenza, la modifica di una esistente, la valutazione di una scansione snyk-agent non riuscita eseguita localmente o in CI o lo sblocco di un PR bloccato da errori di scansione dell'agente. Non applicabile a vulnerabilità delle dipendenze, risultati sulla sicurezza del codice o configurazioni errate dell'infrastruttura: questi non rientrano nell'ambito.
