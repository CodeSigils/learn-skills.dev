CLI per interrogare motori compatibili con Prometheus e PromQL (Thanos, Cortex, VictoriaMetrics, Grafana Mimir, Grafana Tempo...) — query istantanee, query su intervalli, rilevamento di metriche (metriche/etichette/meta sottocomandi), formati di output (tabella/csv/json/grafico). Applicare durante l'esecuzione di query PromQL, la risoluzione di problemi di prestazioni su un software con osservabilità, l'analisi di latenza/tassi di errore/saturazione o l'analisi di dati di serie temporali.
