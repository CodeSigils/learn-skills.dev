Genere ganchos de apertura y títulos de publicaciones para artículos extensos en EN o FR: publicaciones de blog, Substack/Medium/dev.to, LinkedIn de formato largo, boletines informativos pagos, ensayos de opinión, características informadas, inmersiones técnicas profundas. Se activa cada vez que el usuario solicita un gancho, apertura, comienzo, introducción, primera oración/párrafo, apertura, acceso, ataque, frase de acceso o frase de estreno, lo que incluye hacer una introducción plana más impactante o reescribir un borrador de apertura. También se activa cuando el usuario solicita el título de una publicación, un título de artículo, un titular o cuando las habilidades de escritura fantasma llegan al paso de apertura o título. Propone 3-4 ganchos que accionan distintas palancas psicológicas (brecha de curiosidad, contradicción, escena, promesa, autoridad), 2 candidatos cada uno, espera a que el usuario elija. NO active publicaciones sociales (LinkedIn feed, Twitter/X, TikTok, Bluesky, Threads), archivos README o primeras líneas de documentos, eslóganes, asuntos de correo electrónico o introductorios, textos de anuncios (Google/Meta Ads), titulares de páginas de destino, comunicados de prensa, metadatos de SEO, aperturas de ficción, introducciones de guiones de charlas/podcasts/videos ni reescrituras de cuerpos.
