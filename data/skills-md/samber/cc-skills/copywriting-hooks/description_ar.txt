أنشئ روابط افتتاحية وعناوين منشورات للمقالات الطويلة باللغة الإنجليزية أو الفرنسية - منشورات المدونة، Substack/Medium/dev.to، LinkedIn الطويلة، النشرات الإخبارية المدفوعة، مقالات الرأي، الميزات المبلغ عنها، التعمق الفني. يتم تشغيله عندما يطلب المستخدم ربطًا أو افتتاحًا أو مقدمة أو مقدمة أو جملة/فقرة أولى أو افتتاحية أو أكروش أو هجوم أو عبارة داكروش أو العبارة الأولى - بما في ذلك إنشاء مقدمة مسطحة أو إعادة كتابة مسودة افتتاحية. يتم تشغيله أيضًا عندما يطلب المستخدم عنوانًا للمنشور، أو عنوان المقالة، أو العنوان الرئيسي، أو عندما تصل مهارات الكتابة الخفية إلى خطوة الافتتاح أو العنونة. يقترح 3-4 خطافات تسحب روافع نفسية متميزة (فجوة الفضول، المتناقض، المشهد، الوعد، السلطة)، مرشحان لكل منهما، وينتظر حتى يختار المستخدم. لا تقم بتشغيل المنشورات الاجتماعية (موجز LinkedIn، Twitter/X، TikTok، Bluesky، Threads)، أو READMEs أو الأسطر الأولى للمستندات، أو سطور العلامات، أو موضوعات البريد الإلكتروني أو الافتتاحيات، أو نسخة الإعلان (Google/Meta Ads)، أو عناوين الصفحة المقصودة، أو النشرات الصحفية، أو تعريف SEO، أو الافتتاحيات الخيالية، أو مقدمات نصوص الحديث/البودكاست/الفيديو، أو إعادة كتابة النص الأساسي.
