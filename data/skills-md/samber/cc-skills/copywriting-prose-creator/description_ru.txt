Кодифицирует то, как пишет кто-то или бренд — механика прозы (лексикон, синтаксис, ритм, структура, фирменные движения), независимая от эмоционального тона. Выход: PROSE.md. Три режима: СОЗДАЙТЕ новое руководство из SOUL.md + TONE.md + открывающее интервью; АДАПТИРОВАТЬ существующее руководство под новый канал; ПРОВЕРЬТЕ корпус на наличие образцов прозы перед кодификацией. Используйте, когда: написание правил для фабрики контента, кодификация голосового написания для обеспечения согласованности нескольких авторов, определение запрещенных слов и целевой длины предложения, создание собственного руководства по стилю, реверс-инжиниринг прозы из корпуса, перенос стиля по каналам. Запустите: PROSE.md, руководство по стилю письма, руководство по прозе, домашний стиль, стиль писателя-призрака, сборник сценариев написания, механика написания бренда, фирменные приемы. НЕ для: написания реального контента (→ linkedin-ghostwriting, автора технических статей, автора пресс-релизов), удаления шаблонов ИИ (→ гуманизатор), тональных решений (→ копирайтинг-тон голоса), зацепок (→ зацепки копирайтинга), призывов к действию (→ копирайтинг-cta).
