Codifie la façon dont quelqu'un ou une marque écrit - la mécanique de la prose (lexique, syntaxe, rythme, structure, mouvements de signature) indépendamment du ton émotionnel. Sortie : PROSE.md. Trois modes : CONSTRUIRE un nouveau guide à partir de SOUL.md + TONE.md + interview de découverte ; ADAPTER un guide existant à une nouvelle chaîne ; AUDITER un corpus pour les modèles de prose avant la codification. À utiliser dans les cas suivants : rédaction de règles pour une usine de contenu, codification de la voix d'écriture fantôme pour une cohérence entre plusieurs auteurs, définition de mots interdits et de longueurs de phrases cibles, création d'un guide de style maison, rétro-ingénierie de la prose à partir d'un corpus, portage du style sur plusieurs canaux. Déclenchez : PROSE.md, guide de style d'écriture, guide de prose, style maison, style ghostwriter, manuel d'écriture, mécanismes d'écriture de marque, mouvements de signature. PAS pour : écrire du contenu réel (→ linkedin-ghostwriting, rédacteur d'articles techniques, rédacteur de communiqués de presse), supprimer les modèles d'IA (→ humanizer), les décisions de ton (→ copywriting-tone-of-voice), les crochets (→ copywriting-hooks), les CTA (→ copywriting-cta).
