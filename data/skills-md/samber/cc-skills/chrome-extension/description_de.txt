Umfassende Anleitung zum Erstellen von Chrome-Erweiterungen mit Manifest V3. Verwenden Sie diesen Skill immer dann, wenn der Benutzer Chrome-Erweiterung, Browser-Erweiterung, manifest.json, Inhaltsskript, Service Worker (im Erweiterungskontext), Popup, Seitenbereich, chrome.runtime, chrome.tabs, chrome.storage, chrome.scripting, Hintergrundskript, MV3, Manifest V3 oder eine beliebige Chrome-Erweiterungs-API erwähnt. Wird auch ausgelöst, wenn der Benutzer Skripte in Webseiten einfügen, zwischen Seite und Hintergrund kommunizieren, CSP aus einem Inhaltsskript umgehen, eine RPC-Ebene über Chrome Messaging erstellen oder im Chrome Web Store veröffentlichen möchte. Deckt sowohl neue Erweiterungsprojekte als auch das Hinzufügen von Funktionen zu bestehenden Projekten ab. NICHT für Framework-spezifische Fragen verwenden.
