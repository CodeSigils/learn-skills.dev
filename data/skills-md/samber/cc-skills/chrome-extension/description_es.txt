Guía completa para crear extensiones de Chrome con Manifest V3. Utilice esta habilidad siempre que el usuario mencione la extensión de Chrome, la extensión del navegador, manifest.json, el script de contenido, el trabajador de servicio (en el contexto de la extensión), la ventana emergente, el panel lateral, chrome.runtime, chrome.tabs, chrome.storage, chrome.scripting, el script de fondo, MV3, Manifest V3 o cualquier API de extensión de Chrome. También se activa cuando el usuario desea inyectar scripts en páginas web, comunicarse entre la página y el fondo, omitir CSP de un script de contenido, crear una capa RPC sobre mensajería Chrome o publicar en Chrome Web Store. Cubre tanto nuevos proyectos de extensión como la adición de funciones a los existentes. NO lo use para preguntas específicas del marco.
