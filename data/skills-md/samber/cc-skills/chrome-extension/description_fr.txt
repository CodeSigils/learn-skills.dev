Comprehensive guide for building Chrome extensions with Manifest V3. Utilisez cette compétence chaque fois que l'utilisateur mentionne l'extension Chrome, l'extension de navigateur, manifest.json, le script de contenu, le service worker (dans le contexte de l'extension), la fenêtre contextuelle, le panneau latéral, chrome.runtime, chrome.tabs, chrome.storage, chrome.scripting, le script d'arrière-plan, MV3, Manifest V3 ou toute API d'extension Chrome. Se déclenche également lorsque l'utilisateur souhaite injecter des scripts dans des pages Web, communiquer entre la page et l'arrière-plan, contourner le CSP à partir d'un script de contenu, créer une couche RPC sur la messagerie Chrome ou publier sur le Chrome Web Store. Covers both new extension projects and adding features to existing ones. Do NOT use for framework-specific questions.
