Подробное руководство по созданию расширений Chrome с помощью Manifest V3. Используйте этот навык всякий раз, когда пользователь упоминает расширение Chrome, расширение браузера, манифест.json, скрипт контента, сервис-воркера (в контексте расширения), всплывающее окно, боковую панель, chrome.runtime, chrome.tabs, chrome.storage, chrome.scripting, фоновый скрипт, MV3, манифест V3 или любой API расширения Chrome. Также срабатывает, когда пользователь хочет внедрить сценарии в веб-страницы, обмениваться данными между страницей и фоном, обойти CSP из сценария контента, создать уровень RPC поверх обмена сообщениями Chrome или опубликовать в Интернет-магазине Chrome. Охватывает как новые проекты расширения, так и добавление функций к существующим. НЕ используйте для вопросов, специфичных для платформы.
