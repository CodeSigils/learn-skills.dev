دليل شامل لإنشاء ملحقات Chrome باستخدام Manifest V3. استخدم هذه المهارة عندما يذكر المستخدم ملحق Chrome، أو ملحق المتصفح، أو البيان.json، أو البرنامج النصي للمحتوى، أو عامل الخدمة (في سياق الامتداد)، أو النافذة المنبثقة، أو اللوحة الجانبية، أو chrome.runtime، أو chrome.tabs، أو chrome.storage، أو chrome.scripting، أو البرنامج النصي للخلفية، أو MV3، أو Manifest V3، أو أي واجهة برمجة تطبيقات لملحق Chrome. يتم التشغيل أيضًا عندما يريد المستخدم إدخال البرامج النصية في صفحات الويب، أو التواصل بين الصفحة والخلفية، أو تجاوز CSP من البرنامج النصي للمحتوى، أو إنشاء طبقة RPC عبر مراسلة Chrome، أو النشر إلى سوق Chrome الإلكتروني. يغطي كلاً من مشاريع التوسعة الجديدة وإضافة ميزات إلى المشاريع الحالية. لا تستخدم للأسئلة الخاصة بإطار العمل.
