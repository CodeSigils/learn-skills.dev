Commit convenzionali v1.0.0 denominazione dei rami e standard dei messaggi di commit per progetti GitHub e GitLab. Da utilizzare durante la creazione di rami, la scrittura di commit, la generazione di messaggi di commit, la revisione delle convenzioni dei rami o l'impostazione dell'automazione del registro delle modifiche. Applica quando il tuo progetto necessita di una cronologia git coerente, versioni guidate da SemVer, generazione di log delle modifiche analizzabili o chiusura automatica dei problemi.
