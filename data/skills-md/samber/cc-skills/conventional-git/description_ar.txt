الالتزامات التقليدية v1.0.0 لتسمية الفروع ومعايير رسائل الالتزام لمشروعات GitHub وGitLab. يُستخدم عند إنشاء الفروع، أو كتابة الالتزامات، أو إنشاء رسائل الالتزام، أو مراجعة اصطلاحات الفروع، أو إعداد أتمتة سجل التغيير. يتم تطبيقه عندما يحتاج مشروعك إلى سجل git متسق، أو إصدارات تعتمد على SemVer، أو إنشاء سجل تغيير قابل للتحليل، أو إغلاق المشكلات تلقائيًا.
