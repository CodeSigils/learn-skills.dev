Обычные коммиты версии 1.0.0 для именования ветвей и стандартов сообщений о фиксации для проектов GitHub и GitLab. Используйте при создании ветвей, написании коммитов, генерации сообщений о коммитах, проверке соглашений о ветках или настройке автоматизации журнала изменений. Применяйте, когда вашему проекту требуется согласованная история git, выпуски на основе SemVer, создание анализируемого журнала изменений или автоматическое закрытие проблем.
