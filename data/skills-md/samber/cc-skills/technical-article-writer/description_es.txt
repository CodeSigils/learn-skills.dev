Escriba artículos técnicos y publicaciones de blog atractivos para audiencias de desarrolladores. Utilice esta habilidad siempre que el usuario solicite escribir una publicación de blog, un artículo técnico o cualquier contenido técnico extenso. También se activa cuando el usuario dice "escribir sobre [tema técnico]", "ayúdame a redactar un artículo", "convertir esto en una publicación de blog", "escribir una publicación sobre", "Quiero publicar algo sobre" o menciona escribir para una audiencia de desarrolladores. Cubre todo el proceso: perfeccionamiento de ideas, generación de ganchos/títulos, estructura del artículo, redacción del cuerpo y edición. Incluso si el usuario simplemente dice "Quiero escribir sobre X" sin especificar el formato, utilice esta habilidad. NO lo utilice para optimización de plataformas específicas, estrategia de boletines ni coincidencia de voz de escritura fantasma.
