Développement d'extensions CRXJS Chrome — véritable HMR pour les fenêtres contextuelles, les options, les scripts de contenu, les panneaux latéraux, les versions pilotées par manifeste, les importations de scripts de contenu dynamiques (`?script`, `?script&module`) et `defineManifest` pour les manifestes de type sécurisé. Utilise Vite comme outil de construction. À utiliser lorsque l'utilisateur mentionne CRXJS, crxjs, @crxjs/vite-plugin, « extension avec rechargement à chaud », « HMR pour extension Chrome » ou souhaite configurer un projet d'extension Chrome basé sur CRXJS avec n'importe quel framework (React, Vue, Svelte, Solid, Vanilla). Déclenchez également lorsque l'utilisateur a un projet CRXJS existant et souhaite ajouter des fonctionnalités, résoudre des problèmes HMR ou configurer des scripts de contenu avec CRXJS. Pour l'architecture générale de l'extension Chrome (messagerie, CSP, stockage, autorisations) -> Voir la compétence `samber/cc-skills@chrome-extension`.
