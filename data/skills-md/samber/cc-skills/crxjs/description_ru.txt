Разработка расширений CRXJS Chrome — настоящий HMR для всплывающих окон, параметров, сценариев контента, боковых панелей, сборок на основе манифестов, импорта сценариев динамического контента (`?script`, `?script&module`) и `defineManifest` для типобезопасных манифестов. Использует Vite в качестве инструмента сборки. Используйте, когда пользователь упоминает CRXJS, crxjs, @crxjs/vite-plugin, «расширение с горячей перезагрузкой», «HMR для расширения Chrome» или хочет настроить проект расширения Chrome на основе CRXJS с любой платформой (React, Vue, Svelte, Solid, Vanilla). Также срабатывает, когда у пользователя есть существующий проект CRXJS и он хочет добавить функции, исправить проблемы HMR или настроить сценарии контента с помощью CRXJS. Для общей архитектуры расширений Chrome (обмен сообщениями, CSP, хранилище, разрешения) -> см. навык `samber/cc-skills@chrome-extension`.
