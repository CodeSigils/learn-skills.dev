Desarrollo de extensión CRXJS Chrome: verdadero HMR para ventanas emergentes, opciones, scripts de contenido, paneles laterales, compilaciones basadas en manifiestos, importaciones de scripts de contenido dinámico (`?script`, `?script&module`) y `defineManifest` para manifiestos con seguridad de tipos. Utiliza Vite como herramienta de construcción. Úselo cuando el usuario mencione CRXJS, crxjs, @crxjs/vite-plugin, 'extensión con recarga en caliente', 'HMR para extensión de Chrome' o quiera configurar un proyecto de extensión de Chrome basado en CRXJS con cualquier marco (React, Vue, Svelte, Solid, Vanilla). También se activa cuando el usuario tiene un proyecto CRXJS existente y desea agregar funciones, solucionar problemas de HMR o configurar scripts de contenido con CRXJS. Para conocer la arquitectura general de la extensión de Chrome (mensajería, CSP, almacenamiento, permisos) -> Consulte la habilidad `samber/cc-skills@chrome-extension`.
