قم بإنتاج تطبيقات واجهة مستخدم وتصميم مميزة وغير عامة بشكل جيد، مع وضع استراتيجية العمل أولاً. حدد المشروع (الصفحة المقصودة، تطبيق SaaS، لوحة المعلومات، التجارة الإلكترونية، العرض التقديمي، المستندات، المحفظة...) وموقعه وشخصيته، والتزم بصفات العلامة التجارية، وترجمه إلى نظام الطباعة والألوان، ثم قم بتطبيق الطبقة الحرفية (التخطيط، والمكونات والحالات، والحركة، والأيقونات، والصور، والوضع المظلم والسمات، وإمكانية الوصول)، وتجنب الوضع الافتراضي AI-slop / Claude-esque. تعد هذه مهارة في إزالة الانحدار ومهارة متخصصة في تصميم التطبيقات. استخدم هذا عند إنشاء أو تصميم أي واجهة ويب أمامية أو تطبيق أو لوحة معلومات أو صفحة مقصودة أو مجموعة أدوات أو قطعة أثرية، أو عندما يقول المستخدم "اجعلها لا تبدو مثل الذكاء الاصطناعي" أو "إزالة الانحدار" أو "إزالة الانحدار" أو "أقل عمومية" أو "منحها طابعًا" أو "تصميم واجهة مستخدم لـ X" أو "تصميم تطبيق" أو "تحديث DESIGN.md" أو الشكوى من أن المخرجات تبدو مثل أي موقع آخر يعمل بالذكاء الاصطناعي. يتم تشغيله حتى عندما يقول المستخدم فقط "إنشاء واجهة مستخدم لـ X" دون تسمية جمالية، لأن الإعداد الافتراضي بدون هذه المهارة هو الانحدار.
