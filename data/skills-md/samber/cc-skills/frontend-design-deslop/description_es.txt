Produzca bien aplicaciones de diseño y UI distintivas y no genéricas, trabajando primero la estrategia. Identifique el proyecto (página de destino, aplicación SaaS, panel de control, comercio electrónico, presentación, documentos, cartera...) y su posicionamiento y personalidad, comprométase con los adjetivos de la marca, tradúzcalos a un sistema de tipografía y color, luego aplique la capa artesanal (diseño, componentes y estados, movimiento, iconografía, imágenes, modo oscuro y tematización, accesibilidad), evitando el valor predeterminado de AI-slop/Claude-esque. Esta es una habilidad de diseño de aplicaciones tanto para expertos como para expertos. Utilízalo siempre que crees o diseñes cualquier interfaz web, aplicación, panel de control, página de inicio, presentación o artefacto, o cuando el usuario diga "haz que no parezca IA", "deslopify", "deslop", "menos genérico", "dale carácter", "diseña una interfaz de usuario para X", "diseña una aplicación", "actualiza DESIGN.md" o se queja de que el resultado se parece a cualquier otro sitio de IA. Se activa incluso cuando el usuario simplemente dice "construir una interfaz de usuario para X" sin nombrar una estética, porque el valor predeterminado sin esta habilidad es basura.
