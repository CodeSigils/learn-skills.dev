特徴的で非汎用的な UI を作成し、戦略を第一に考えてアプリケーションを適切に設計します。プロジェクト (ランディング ページ、SaaS アプリ、ダッシュボード、e コマース、プレゼンテーション、ドキュメント、ポートフォリオなど) とそのポジショニングと個性を特定し、ブランドの形容詞にコミットし、タイポグラフィーとカラー システムに変換してから、クラフト レイヤー (レイアウト、コンポーネントと状態、モーション、図像、画像、ダーク モードとテーマ、アクセシビリティ) を適用して、AI スロップ/クロード風のデフォルトを回避します。これは、デスロップであると同時に、熟練したアプリ設計スキルでもあります。 Web フロントエンド、アプリ、ダッシュボード、ランディング ページ、デッキ、またはアーティファクトを構築またはスタイル設定するとき、またはユーザーが「AI っぽくないようにする」、「緩みをなくす」、「汎用性を下げる」、「個性を与える」、「X 用の UI をデザインする」、「アプリをデザインする」、「DESIGN.md を更新する」と言ったとき、または出力が他の AI サイトと同じように見えると不満を言ったときに、これを使用します。ユーザーが美学の名前を付けずに「X 用の UI を構築する」とだけ言った場合でもトリガーされます。これは、このスキルなしのデフォルトはだらしないためです。
