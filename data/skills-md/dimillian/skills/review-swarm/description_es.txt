Revisión paralela de múltiples agentes de solo lectura de un git diff actual o del alcance de un archivo explícito para encontrar regresiones de comportamiento, riesgos de seguridad o privacidad, problemas de rendimiento o confiabilidad y lagunas en la cobertura de contratos o pruebas. Úselo cuando el usuario solicita una revisión enjambre, una revisión paralela, una revisión de diferencias, una revisión de regresión, una revisión de seguridad o desea problemas de señal alta además de una ruta de solución priorizada sin editar archivos.
