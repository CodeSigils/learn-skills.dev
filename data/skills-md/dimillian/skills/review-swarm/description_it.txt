Revisione multi-agente parallela di sola lettura di un git diff corrente o di un ambito di file esplicito per individuare regressioni comportamentali, rischi per la sicurezza o la privacy, problemi di prestazioni o affidabilità e lacune di copertura di contratti o test. Da utilizzare quando l'utente richiede uno sciame di revisione, una revisione parallela, una revisione delle differenze, una revisione della regressione, una revisione della sicurezza o desidera problemi con segnali elevati oltre a un percorso di correzione con priorità senza modificare i file.
