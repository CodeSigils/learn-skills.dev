Проверьте git diff или явную область файла на наличие проблем с повторным использованием, качеством кода, эффективностью, ясностью и стандартами, а затем при необходимости примените безопасные исправления на основе Кодекса. Используйте, когда пользователь просит «упростить код», «просмотреть измененный код», «проверить повторное использование кода», «проверить качество кода», «проверить эффективность», «упростить изменения», «очистить код», «рефакторить изменения» или «запустить упрощение».
