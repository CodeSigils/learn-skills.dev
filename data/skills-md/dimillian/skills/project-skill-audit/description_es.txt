Analice las sesiones anteriores del Codex, los archivos de memoria y las habilidades locales existentes de un proyecto para recomendar las habilidades de mayor valor para crear o actualizar. Úselo cuando un usuario pregunta qué habilidades necesita un proyecto, quiere ideas de habilidades basadas en el historial real del proyecto, quiere una auditoría de las habilidades locales del proyecto actual o quiere recomendaciones para actualizar habilidades obsoletas o incompletas en lugar de crear duplicados.
