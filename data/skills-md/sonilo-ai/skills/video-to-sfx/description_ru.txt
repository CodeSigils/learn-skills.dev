Создавайте звуковые эффекты, соответствующие видео, с помощью Sonilo — шаги, удары, атмосфера, фоли — при необходимости запрограммированные для определенных временных сегментов, возвращая либо звук, либо новое видео с мультиплексированием SFX. Используйте, когда у пользователя есть кадры, требующие звукового оформления. Для SFX только из текстового описания используйте навык преобразования текста в SFX; для музыки используйте видео в музыку.
