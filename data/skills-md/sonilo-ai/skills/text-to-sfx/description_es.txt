Genere un efecto de sonido a partir de una descripción de texto usando Sonilo (un timbre de interfaz de usuario, un silbido, un impacto, un ambiente, una señal estilizada) cuando no haya un video que coincida. Úselo cuando el usuario describe el sonido que desea con palabras y le da una duración. Para SFX que coincida con el metraje, use la habilidad de video a sfx; para música, utilice texto a música.
