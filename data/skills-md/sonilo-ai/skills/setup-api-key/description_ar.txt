يرشد المستخدمين من خلال الاتصال بـ Sonilo — تسجيل الدخول باستخدام `تسجيل دخول sonilo` (OAuth، بدون مفتاح)، أو مكون OAuth Claude Code الإضافي، أو مفتاح API لـ CI والاستخدام بدون رأس. يُستخدم عندما يحتاج المستخدم إلى تكوين Sonilo، أو يريد تسجيل الدخول أو الاتصال بحساب Sonilo الخاص به، أو عندما تكون أدوات Sonilo مفقودة، أو عندما تفشل مكالمة بسبب عدم توفر مفتاح أو بيانات اعتماد. يتحقق أولاً مما يعمل بالفعل، ولا يقوم بتشغيل الإعداد الكامل إلا عند الحاجة.
