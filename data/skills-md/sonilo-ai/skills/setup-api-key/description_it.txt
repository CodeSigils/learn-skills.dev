Guida gli utenti attraverso la connessione a Sonilo: accesso con "sonilo login" (OAuth, nessuna chiave), il plug-in OAuth Claude Code remoto o una chiave API per CI e utilizzo headless. Da utilizzare quando l'utente deve configurare Sonilo, desidera accedere o connettere il proprio account Sonilo, quando mancano gli strumenti Sonilo o quando una chiamata non riesce perché non sono disponibili chiavi o credenziali. Innanzitutto controlla ciò che già funziona ed esegue la configurazione completa solo quando necessario.
