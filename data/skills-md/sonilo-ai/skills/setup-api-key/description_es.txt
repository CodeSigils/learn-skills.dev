Guía a los usuarios a través de la conexión a Sonilo: iniciando sesión con `sonilo login` (OAuth, sin clave), el complemento remoto OAuth Claude Code o una clave API para CI y uso sin cabeza. Úselo cuando el usuario necesita configurar Sonilo, desea iniciar sesión o conectar su cuenta de Sonilo, cuando faltan herramientas de Sonilo o cuando falla una llamada porque no hay una clave o credencial disponible. Primero comprueba lo que ya funciona y sólo ejecuta la configuración completa cuando sea necesario.
