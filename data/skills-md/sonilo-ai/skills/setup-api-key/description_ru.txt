Помогает пользователям подключиться к Sonilo — войти в систему с помощью входа в систему sonilo (OAuth, без ключа), удаленного плагина OAuth Claude Code или ключа API для CI и автономного использования. Используйте, когда пользователю необходимо настроить Sonilo, он хочет войти в систему или подключить свою учетную запись Sonilo, когда инструменты Sonilo отсутствуют или когда вызов завершается неудачно из-за отсутствия ключа или учетных данных. Сначала проверяется то, что уже работает, и выполняется полная настройка только при необходимости.
