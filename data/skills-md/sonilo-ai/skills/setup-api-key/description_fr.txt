Guide les utilisateurs dans la connexion à Sonilo — en se connectant avec « sonilo login » (OAuth, pas de clé), le plug-in distant OAuth Claude Code ou une clé API pour une utilisation CI et sans tête. À utiliser lorsque l'utilisateur doit configurer Sonilo, souhaite se connecter ou connecter son compte Sonilo, lorsque les outils Sonilo sont manquants ou lorsqu'un appel échoue car aucune clé ou identifiant n'est disponible. Vérifie d’abord ce qui fonctionne déjà et n’exécute la configuration complète qu’en cas de besoin.
