Genere o edite imágenes con gpt-image-2, facturadas a la suscripción ChatGPT del usuario a través de Codex CLI OAuth; no se necesita OPENAI_API_KEY. Úselo siempre que el usuario quiera generar, crear, dibujar, editar o modificar una imagen, foto, logotipo, icono, ilustración, foto de producto, maqueta de interfaz de usuario, fondo de pantalla o infografía, incluidos archivos PNG de fondo transparente o recortados. Activa frases como "hazme una imagen de X", "dibuja un logotipo para Y", "genera una imagen de Z", "ahora hazla más oscura", "elimina el fondo" o una invocación explícita de /codex-image.
