Videoconferencia Feishu: permita que un bot se una o abandone una reunión en curso en nombre del usuario actual y lea eventos en tiempo real durante la reunión (participantes que entran y salen, hablan, chatean, comparten pantalla, etc.). 1. El usuario proporciona una identificación de reunión de 9 dígitos; para solicitar que el bot se una o se vaya, use+meeting-join/+meeting-leave; esto generará registros reales de entrada/salida. 2. Mientras la reunión está en curso, si el usuario quiere saber “quién se unió”, “quién se fue”, “quién está hablando”, “hay alguien que comparte una pantalla”, etc., el bot se une a la reunión y usa+meeting-events para leer la línea de tiempo del evento. 3. Escenarios típicos: robot participante, asistente en una reunión, asistir como oyente, asistir en nombre de alguien. Requisito previo: el bot solo puede leer eventos de reuniones a las que se ha unido y que aún están en curso; Para consultar la lista de participantes, las actas o la transcripción de una reunión finalizada, utilice thelark‑vcskill.
