Lark Spreadsheet: create and manipulate spreadsheets. Supports creating spreadsheets, managing worksheets and row/column structures (add/delete/merge/adjust size/hide/freeze), reading and writing cells (values/formulas/styles/comments/cell images), find and replace, multiple operations with atomic batch updates, as well as creating and maintaining objects such as charts, pivot tables, conditional formatting, filters, sparklines, floating images, and more. Use this when a user needs to create spreadsheets, manage worksheets, batch read/write or edit data, perform statistical aggregation and visualization, beautify tables, compute formulas (including Excel formula migration), etc. If the user wants to search for spreadsheet files by name or keyword in cloud space (cloud drive/cloud storage), switch to lark-drive’s drive +search to locate the resource first. When a user provides a doubao.com /sheets/ URL/token, this skill should be used directly; do not fall back to WebFetch just because the domain isn’t Lark—the routing is based on the URL path pattern and token, not the domain. This applies only to Lark online spreadsheets and is not suitable for local Excel files.
