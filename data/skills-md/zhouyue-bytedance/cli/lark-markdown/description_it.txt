Feishu Markdown: visualizza, crea, carica, modifica e confronta file Markdown. Utilizzato quando un utente deve creare o modificare file Markdown, leggere, modificare, applicare patch parziali o confrontare le differenze. Non gestisce l'importazione di Markdown nei documenti online Feishu, né gestisce la ricerca di file, le autorizzazioni, i commenti, lo spostamento, l'eliminazione o altre operazioni di gestione dello spazio cloud.
