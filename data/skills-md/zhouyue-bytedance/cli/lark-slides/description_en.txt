Feishu Slides: create and edit slides. Create presentations, read slide content, manage slide pages (create, delete, read, partially replace). Use this when the user needs to create or edit slides, or read or modify an individual page. When the user provides a doubao.com /slides/ URL/token, this skill should be used directly; do not fall back to WebFetch just because the domain is not Feishu. Routing is based on the URL path pattern and token, not on the domain. Not responsible for: editing cloud‑document content (handled by lark‑doc), independent whiteboard objects within cloud documents (handled by lark‑whiteboard; note that flowcharts/architecture diagrams embedded in slides still belong to this skill), uploading or downloading regular files (handled by lark‑drive).
