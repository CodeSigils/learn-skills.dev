Utilisez cette compétence pour créer des documents Word (.docx) professionnels et entièrement modifiables — rapports, lettres, contrats, notes, manuels. Concevez le document sous forme de HTML/CSS fluide (prévisualisez‑le comme un Artifact pour itérer visuellement avec l'utilisateur), puis exécutez le pipeline Playwright + python-docx inclus pour convertir le HTML en contenu Word natif et éditable (vrais titres, paragraphes avec mise en forme par run, listes, tableaux, images) — pas un simple dump d’image. Déclenchez‑le avec « make a Word document », « build a docx », « write a report », « draft a letter/contract », « create documentation ».

Veuillez toujours répondre dans la langue de l'utilisateur.
