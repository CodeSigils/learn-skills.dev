Комплексная система разработки на основе спецификаций для структурированного планирования и реализации проектов. Слэш-команды: /new-project, /plan, /execute, /verify, /health, /help, /next, /quick, /transition, /map-codebase. Используйте при запуске новых проектов, управлении сложными задачами или обеспечении качества кода. ОБЕСПЕЧИВАЕТ строгий рабочий процесс «Задать-Планировать-Выполнить», где ТРЕБУЕТСЯ подтверждение пользователя перед генерацией кода.
