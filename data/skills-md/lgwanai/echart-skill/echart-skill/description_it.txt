Un assistente dedicato alla gestione dell'analisi e dell'elaborazione di dati complessi e ad alta frequenza negli scenari quotidiani dell'ufficio. Utilizza una modalità di esecuzione del codice locale (SQL o Python + DuckDB) per gestire l'importazione, la pulizia, l'interrogazione, l'estrazione, l'unione, la suddivisione e la generazione di report dei dati, supportando grandi volumi di dati garantendo al contempo la privacy e la sicurezza dei dati. Questa competenza viene utilizzata quando gli utenti devono lavorare con file Excel/CSV, eseguire query tra tabelle, generare grafici o produrre report di analisi dei dati.
