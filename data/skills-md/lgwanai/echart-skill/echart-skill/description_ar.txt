مساعد مخصص للتعامل مع تحليل ومعالجة البيانات المعقدة وعالية التردد في سيناريوهات المكتب اليومية. ويستخدم وضع تنفيذ التعليمات البرمجية المحلية (SQL أو Python + DuckDB) لإدارة استيراد البيانات وتنظيفها والاستعلام عنها واستخراجها ودمجها وتقسيمها وإنشاء التقارير، ودعم كميات كبيرة من البيانات مع ضمان خصوصية البيانات وأمانها. يتم استخدام هذه المهارة عندما يحتاج المستخدمون إلى العمل مع ملفات Excel/CSV، أو إجراء استعلامات عبر الجداول، أو إنشاء مخططات، أو إنتاج تقارير تحليل البيانات.
