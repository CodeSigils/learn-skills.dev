Помощник, предназначенный для высокочастотного сложного анализа и обработки данных в повседневных офисных сценариях. Он использует режим локального выполнения кода (SQL или Python + DuckDB) для управления импортом, очисткой, запросом, извлечением, объединением, разделением и созданием отчетов данных, поддерживая большие объемы данных, обеспечивая при этом конфиденциальность и безопасность данных. Этот навык используется, когда пользователям необходимо работать с файлами Excel/CSV, выполнять запросы к перекрестным таблицам, создавать диаграммы или отчеты по анализу данных.
