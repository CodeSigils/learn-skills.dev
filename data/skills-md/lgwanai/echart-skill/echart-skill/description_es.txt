Un asistente dedicado a manejar análisis y procesamiento de datos complejos y de alta frecuencia en escenarios de oficina cotidianos. Utiliza un modo de ejecución de código local (SQL o Python + DuckDB) para gestionar la importación, limpieza, consulta, extracción, fusión, división y generación de informes de datos, lo que admite grandes volúmenes de datos y al mismo tiempo garantiza la privacidad y seguridad de los datos. Esta habilidad se utiliza cuando los usuarios necesitan trabajar con archivos Excel/CSV, realizar consultas entre tablas, generar gráficos o producir informes de análisis de datos.
