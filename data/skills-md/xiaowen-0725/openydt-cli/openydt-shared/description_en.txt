openydt (Aike Zhipo Parking Open Platform CLI) shared foundation: profile/credential configuration, multiple environments (test/dev/prod), v2/v3 signing, response envelope and status/resultCode, exit codes, rate‑limit retries, write‑operation safety rules, parking‑lot experience accumulation (park‑notes). When using openydt for the first time, configuring/switching profiles, troubleshooting signing/authentication/rate‑limit issues, or performing any write operation, first read this foundation; all openydt domain skills should read it before execution.
