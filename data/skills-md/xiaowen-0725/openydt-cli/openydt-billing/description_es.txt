Dominio de transacciones de pago de estacionamiento (comercio): búsqueda de tarifas estimadas/en tiempo real para vehículos de estacionamiento temporal, retroalimentación de información de pago, pagos vencidos por lotes y prepagos preestablecidos con puntos operativos. Se utiliza cuando un usuario necesita calcular tarifas de estacionamiento, devolver/sincronizar órdenes de pago, pagar por lotes montos vencidos o deducir automáticamente del saldo prepago de un vehículo. Este dominio pertenece a “búsqueda/pago de tarifas en tiempo real”; para consultas de registros históricos de facturas/pagos, utilice el dominio de estacionamiento (openydt-record).
