Pass mensuel/domaine VIP (ticket) : types de pass mensuels et cycle de vie du pass mensuel (créer un type / activation / renouvellement / remboursement / annulation / gel / dégel), création et requête de types de véhicules spéciaux (visiteur / groupes VIP sur liste noire), identité du véhicule / propriétaire / requête VIP. Utilisé lorsqu'un utilisateur souhaite activer ou renouveler un pass mensuel, vérifier si un pass mensuel est sur le point d'expirer/est déjà vendu, ou créer des groupes VIP de visiteurs/liste noire. Les relevés de paiement/déduction des abonnements mensuels appartiennent à ce domaine ; pour le calcul des frais de stationnement temporaires en temps réel, veuillez utiliser le domaine commercial (openydt‑billing).
