Pase Mensual/dominio VIP (boleto): tipos de pases mensuales y ciclo de vida del pase mensual (crear tipo / activación / renovación / reembolso / cancelación / congelar / descongelar), creación y consulta de tipos de vehículos especiales (visitante / lista negra de grupos VIP), identidad del vehículo / propietario / consulta VIP. Se utiliza cuando un usuario desea activar o renovar un pase mensual, comprobar si un pase mensual está a punto de caducar o ya está vendido, o crear grupos VIP de visitantes o de lista negra. Los registros de pago/deducción de abonos mensuales pertenecen a este dominio; para calcular la tarifa de estacionamiento temporal en tiempo real, utilice el dominio comercial (openydt-billing).
