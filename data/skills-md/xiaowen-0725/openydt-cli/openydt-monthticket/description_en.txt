Monthly Pass/VIP domain (ticket): monthly pass types and the monthly pass lifecycle (create type / activation / renewal / refund / cancellation / freeze / unfreeze), creation and query of special vehicle types (visitor / blacklist VIP groups), vehicle identity / owner / VIP query. Used when a user wants to activate or renew a monthly pass, check whether a monthly pass is about to expire / already sold, or create visitor / blacklist VIP groups. The payment/deduction records of monthly passes belong to this domain; for real‑time temporary parking fee calculation, please use the trade domain (openydt‑billing).
