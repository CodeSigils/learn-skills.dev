Общий запасной вариант API и исследование интерфейса. Если для конкретного интерфейса отсутствует выделенная основная команда, используйте `openydt api <cmd> --body` для прямого вызова любого вызываемого интерфейса и обратитесь к `catalog.json` за командой и параметрами, различая вызываемые объекты, которые могут быть активно вызваны, и веб-перехватчики, которые могут быть получены только пассивно. Применяйте это, когда команда не может найти выделенную подкоманду в навыках предметной области, ей необходимо вызвать интерфейс неосновного уровня (например, ваучеры на городские операции, сторонние парковки, общественный контроль доступа, ежемесячное бронирование билетов, авторизованные посетители, правила учетных данных, метки транспортных средств и т. д.) или при вопросе «как вызвать эту команду / перезвонит ли мне платформа».
