General API fallback and interface exploration: When a particular interface lacks a dedicated primary command, use `openydt api <cmd> --body` to directly invoke any callable interface, and refer to `catalog.json` for the command and parameters, distinguishing between callables that can be actively invoked and webhooks that can only be passively received. Apply this when a command cannot find a dedicated subcommand within domain skills, needs to call a non‑primary-level interface (e.g., city operation vouchers, third‑party parking lots, community access control, monthly ticket reservations, authorized visitors, credential rules, vehicle tags, etc.), or when asking “how to invoke this command / will the platform callback me.”
