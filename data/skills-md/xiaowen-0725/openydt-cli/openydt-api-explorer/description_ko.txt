일반 API 대체 및 인터페이스 탐색: 특정 인터페이스에 전용 기본 명령이 없는 경우 `openydt api <cmd> --body`를 사용하여 호출 가능한 인터페이스를 직접 호출하고 명령/매개변수에 대해 `catalog.json`을 참조하여 사전에 호출할 수 있는 호출 가능 항목과 수동적으로만 수신할 수 있는 웹후크를 구분합니다. 이는 명령이 도메인 기술에서 전용 하위 명령을 찾을 수 없는 경우, 기본 수준이 아닌 인터페이스(예: 도시 운영 쿠폰, 제3자 주차장, 주택 액세스 제어, 월간 티켓 예약, 승인된 방문자, 자격 증명 규칙, 차량 태그 등)를 호출할 때 또는 "이 명령을 호출하는 방법" 또는 "플랫폼이 나를 콜백할 것인가"를 물을 때 사용됩니다.
