Fallback generale dell'API ed esplorazione dell'interfaccia: quando a una particolare interfaccia manca un comando primario dedicato, utilizzare `openydt api <cmd> --body` per richiamare direttamente qualsiasi interfaccia richiamabile e fare riferimento a `catalog.json` per il comando e i parametri, distinguendo tra richiamabili che possono essere richiamati attivamente e webhook che possono essere ricevuti solo passivamente. Applicalo quando un comando non riesce a trovare un sottocomando dedicato all'interno delle competenze del dominio, deve chiamare un'interfaccia di livello non primario (ad esempio, voucher per le operazioni cittadine, parcheggi di terze parti, controllo degli accessi della comunità, prenotazioni di biglietti mensili, visitatori autorizzati, regole sulle credenziali, tag dei veicoli, ecc.) o quando chiedi "come invocare questo comando/la piattaforma mi richiamerà".
