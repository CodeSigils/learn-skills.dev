احتياطي واجهة برمجة التطبيقات العامة واستكشاف الواجهة: عندما تفتقر واجهة معينة إلى أمر أساسي مخصص، استخدم "openydt api <cmd> --body" لاستدعاء أي واجهة قابلة للاستدعاء مباشرة، والإشارة إلى "catalog.json" للأمر والمعلمات، مع التمييز بين العناصر القابلة للاستدعاء التي يمكن استدعاؤها بشكل نشط وخطافات الويب التي لا يمكن تلقيها إلا بشكل سلبي. قم بتطبيق ذلك عندما لا يتمكن الأمر من العثور على أمر فرعي مخصص ضمن مهارات المجال، ويحتاج إلى استدعاء واجهة غير المستوى الأساسي (على سبيل المثال، قسائم تشغيل المدينة، ومواقف السيارات التابعة لجهات خارجية، والتحكم في الوصول إلى المجتمع، وحجوزات التذاكر الشهرية، والزوار المعتمدين، وقواعد الاعتماد، وعلامات المركبات، وما إلى ذلك)، أو عند السؤال "كيفية استدعاء هذا الأمر / هل ستقوم المنصة برد الاتصال بي."
