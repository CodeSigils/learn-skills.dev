一般的な API フォールバックとインターフェイスの探索: 特定のインターフェイスに専用のファーストクラス コマンドがない場合は、「openydt api <cmd> --body」を使用して呼び出し可能なインターフェイスを直接呼び出し、コマンドのパラメーターについては「catalog.json」を参照して、プロアクティブに呼び出すことができる呼び出し可能インターフェイスとパッシブにのみ受信できる Webhook を区別します。これは、コマンドがドメイン スキル内で専用のサブコマンドを見つけられない場合、ファースト クラス以外のインターフェイス (例: 都市運営バウチャー、サードパーティの駐車場、コミュニティ アクセス制御、月次チケットの予約、許可された訪問者、文書ルール、車両タグなど) を呼び出す必要がある場合、または「このコマンドをどのように呼び出すか / プラットフォームからコールバックされるか」を尋ねる場合に使用します。
