一般的な API フォールバックとインターフェイスの探索: 特定のインターフェイスに専用のプライマリ コマンドがない場合は、「openydt api <cmd> --body」を使用して呼び出し可能なインターフェイスを直接呼び出します。また、コマンドとパラメーターについては「catalog.json」を参照して、アクティブに呼び出すことができる呼び出し可能オブジェクトと受動的にのみ受信できる Webhook を区別します。これは、コマンドがドメイン スキル内で専用のサブコマンドを見つけられない場合、非プライマリ レベルのインターフェイス (例: 都市運営バウチャー、サードパーティの駐車場、コミュニティ アクセス制御、月次チケット予約、許可された訪問者、資格情報ルール、車両タグなど) を呼び出す必要がある場合、または「このコマンドを呼び出す方法 / プラットフォームからコールバックされるか」を尋ねる場合に適用します。
