Respaldo general de API y exploración de interfaz: cuando una interfaz en particular carece de un comando primario dedicado, use `openydt api <cmd> --body` para invocar directamente cualquier interfaz invocable y consulte `catalog.json` para conocer el comando y los parámetros, distinguiendo entre invocables que se pueden invocar activamente y webhooks que solo se pueden recibir pasivamente. Aplique esto cuando un comando no puede encontrar un subcomando dedicado dentro de las habilidades del dominio, necesita llamar a una interfaz de nivel no primario (por ejemplo, vales de operación de la ciudad, estacionamientos de terceros, control de acceso comunitario, reservas de boletos mensuales, visitantes autorizados, reglas de credenciales, etiquetas de vehículos, etc.) o cuando pregunte "cómo invocar este comando/la plataforma me devolverá la llamada".
