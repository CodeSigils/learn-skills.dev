Repli général de l'API et exploration de l'interface : lorsqu'une interface particulière ne dispose pas d'une commande principale dédiée, utilisez `openydt api <cmd> --body` pour appeler directement toute interface appelable, et référez-vous à `catalog.json` pour la commande et les paramètres, en faisant la distinction entre les appelables qui peuvent être activement invoqués et les webhooks qui ne peuvent être reçus que passivement. Appliquez-le lorsqu'une commande ne parvient pas à trouver une sous-commande dédiée dans les compétences du domaine, doit appeler une interface de niveau non principal (par exemple, bons d'exploitation de la ville, parkings tiers, contrôle d'accès communautaire, réservations de billets mensuels, visiteurs autorisés, règles d'identification, étiquettes de véhicule, etc.), ou lorsque vous demandez « comment appeler cette commande / la plateforme me rappellera-t-elle ».
