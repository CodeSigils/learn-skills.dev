Repli général de l'API et exploration de l'interface : lorsqu'une interface particulière ne dispose pas d'une commande dédiée de première classe, utilisez `openydt api <cmd> --body` pour appeler directement toute interface appelable, et consultez `catalog.json` pour la commande et ses paramètres, en faisant la distinction entre les appelables qui peuvent être invoqués de manière proactive et les webhooks qui ne peuvent être reçus que passivement. Utilisez-le lorsqu'une commande ne parvient pas à trouver une sous-commande dédiée dans les compétences du domaine, doit appeler une interface autre que de première classe (par exemple, coupons d'exploitation de la ville, parkings tiers, contrôle d'accès communautaire, réservations de billets mensuels, visiteurs autorisés, règles d'identification, étiquettes de véhicule, etc.), ou lorsque vous demandez « comment appeler cette commande / la plateforme me rappellera-t-elle ».
