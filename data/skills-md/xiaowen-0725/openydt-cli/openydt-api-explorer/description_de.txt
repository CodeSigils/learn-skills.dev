Allgemeines API-Fallback und Schnittstellenerkundung: Wenn einer Schnittstelle ein dedizierter primärer Befehl fehlt, verwenden Sie „openydt api <cmd> --body“, um jede aufrufbare Schnittstelle direkt aufzurufen, und konsultieren Sie „catalog.json“ für den Befehl und die Parameter. Dabei unterscheiden Sie zwischen aufrufbaren Elementen, die aktiv aufgerufen werden können, und Webhooks, die nur passiv empfangen werden können. Verwenden Sie diesen Ansatz, wenn ein Cmd einen bestimmten Unterbefehl innerhalb eines Domänenskills nicht finden kann, wenn Sie eine nicht primäre Schnittstelle aufrufen müssen (z. B. städtische Betriebsgutscheine, Parkplätze Dritter, Zugangskontrolle für die Gemeinde, monatliche Ticketreservierungen, autorisierte Besucher, Zugangsregeln, Fahrzeugkennzeichnungen usw.) oder wenn Sie fragen: „Wie rufe ich diesen Cmd auf? Wird mich die Plattform zurückrufen?“
