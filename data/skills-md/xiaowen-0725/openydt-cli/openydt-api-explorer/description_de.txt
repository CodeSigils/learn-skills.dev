Allgemeines API-Fallback und Schnittstellenerkundung: Wenn einer bestimmten Schnittstelle ein dedizierter primärer Befehl fehlt, verwenden Sie „openydt api <cmd> --body“, um jede aufrufbare Schnittstelle direkt aufzurufen, und beziehen Sie sich für den Befehl und die Parameter auf „catalog.json“. Dabei unterscheiden Sie zwischen aufrufbaren Elementen, die aktiv aufgerufen werden können, und Webhooks, die nur passiv empfangen werden können. Wenden Sie dies an, wenn ein Befehl keinen dedizierten Unterbefehl innerhalb der Domänenkompetenzen finden kann, eine Schnittstelle auf nicht primärer Ebene aufrufen muss (z. B. städtische Betriebsgutscheine, Parkplätze Dritter, Zugangskontrolle für die Gemeinde, monatliche Ticketreservierungen, autorisierte Besucher, Zugangsregeln, Fahrzeugkennzeichnungen usw.) oder wenn Sie gefragt werden: „Wie rufe ich diesen Befehl auf bzw. ruft mich die Plattform zurück?“
