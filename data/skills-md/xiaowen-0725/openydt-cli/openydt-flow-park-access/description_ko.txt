Ekotech Parking 개방형 플랫폼 “Vehicle Entry/Exit” 운영 프로세스 SOP(End-to-End Orchestration for Entry and Exit). 사용자가 차량의 완전 입출차를 원할 경우, 실제 물리적 입출차 과정을 시뮬레이션하고, “보충기록/스냅샷 입력 → 수정” 또는 “출차 스냅샷 → 수정 → 요금조회 → 결제”의 전체 체인을 실행하고, “차량 입/출차/출입 과정/입출차 SOP/주차장 출입 방법/차량 입출차 시뮬레이션”을 묻거나, 막힘/문제 해결 단계에 직면하게 됩니다. 출입 과정 중(예: 스냅샷 또는 수정 후 차량이 진입하지 않은 경우, 스냅샷 보고 908, 진행 방법을 알 수 없는 경우) 이 스킬이 사용됩니다. 이 스킬은 주차(보충 기록/수정/재고) + 장치(스냅샷) + 거래(수수료 조회/지불) 전반에 걸쳐 여러 명령을 연결하는 도메인 간 오케스트레이션 레이어이며, 명령(페어링 종료, 스냅샷 장치, 채널 해제 모드, 토큰 유효성) 및 실패 처리 전반에 걸쳐 하드 제약 조건을 명확히 합니다. 범위: 단일 기록/현재 부지에 있는 차량/잠긴 차량/단일 명령 호출에 대해 쿼리하려면 해당 도메인 기술 openydt-record/openydt-device/openydt-billing을 직접 사용하고 이 프로세스 기술을 사용하지 마십시오.
