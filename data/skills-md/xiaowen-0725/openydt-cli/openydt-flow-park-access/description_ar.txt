عملية تشغيل Ekotech Parking Open Platform "دخول/خروج السيارة" SOP (تنسيق شامل للدخول والخروج). عندما يريد المستخدم أن تدخل السيارة أو تخرج منها بالكامل، قم بمحاكاة عملية الدخول/الخروج المادية الحقيقية، وتشغيلها عبر السلسلة الكاملة من "السجل التكميلي/إدخال اللقطة ← التصحيح" أو "لقطة الخروج ← التصحيح ← الاستعلام عن الرسوم ← الدفع"، ويسأل "كيف تدخل السيارة / تخرج / عملية الدخول والخروج / الدخول والخروج SOP / كيفية إدخال السيارة إلى (خارج) موقف السيارات / محاكاة سيارة تدخل وتخرج"، أو يواجه خطوة الانسداد/استكشاف الأخطاء وإصلاحها أثناء عملية الدخول/الخروج (على سبيل المثال، بعد لقطة أو تصحيح لم تدخل السيارة، تقارير لقطة 908، غير متأكد من كيفية المتابعة)، يتم استخدام هذه المهارة. هذه المهارة عبارة عن طبقة تنسيق عبر المجالات، تربط أوامر متعددة عبر مواقف السيارات (السجل/التصحيح/المخزون التكميلي) + الجهاز (لقطة) + التجارة (استعلام الرسوم/الدفع)، وتوضح القيود الصعبة عبر الأوامر (الخروج المقترن، جهاز اللقطة، وضع تحرير القناة، صلاحية الرمز المميز) ومعالجة الفشل. النطاق: للاستعلام عن سجل واحد / مركبة موجودة حاليًا في المجموعة / مركبة مقفلة / استدعاء أمر واحد، يرجى استخدام مهارات المجال المقابلة مباشرة openydt-record / openydt-device / openydt-billing، ولا تستخدم مهارة العملية هذه.
