Device Control Domain (device): remote opening/closing of gates, changing gate mode (normally open/normal), sending text and voice announcements to display screens, issuing default screen displays, manual snapshots, cloud scanner operations (scan/stop/voice/update configuration), and checking cloud device online status. It is used when users need to issue commands or check the status of barriers/booths/screens/scanners on site—high‑risk on‑site operations; write actions require --yes and are recommended to be preceded by --dry‑run. Note: this domain handles “pushing” screen displays/announcements to devices; determining what a particular vehicle “should display” belongs to the park domain.
