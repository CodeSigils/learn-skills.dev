License plate list management domain: addition, deletion, and query of blacklist (blacklist: prohibited entry/high fees), whitelist (redlist: free pass rules), and visitor (visitor: limited-time visit registration). Used when users need to blacklist/unblacklist, configure release rules such as police vehicles, or register/cancel visitor vehicles. The “special vehicle type ID (specialCarTypeId)” referenced by the list is created by the ticket domain (openydt-monthticket); this domain only references it as an input parameter and does not create it.
