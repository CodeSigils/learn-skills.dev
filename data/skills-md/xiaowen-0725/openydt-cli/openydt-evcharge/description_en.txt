Electric vehicle charging domain (evcharge): charging station list/detail, charging pile (including gun nozzle) list, station business data statistics, charging order list/detail, all read‑only. Used when the user wants to query charging stations, charging piles, gun nozzle status, charging orders, operator (agent) business data/charging revenue/electricity consumption and fees, or to query charging assets by operator account, phone number, or station identifier. Trigger words: charging station, charging pile, charging gun/nozzle, charging order, operator account, agent, charging revenue, charging electricity amount, electricity fee/service fee, evcharge, plotCode, useraccount. Note: charging is an independent platform module, reusing the same signature authentication; the order status measured in practice is a dual dimension of chargeStatus (charging status) + orderState (order status), which does not match the orderStatus English enumeration in the integration documentation (the platform's actual measurement prevails). For parking (non‑charging) fee queries/records/monthly tickets/coupons, please use other openydt domain skills.
