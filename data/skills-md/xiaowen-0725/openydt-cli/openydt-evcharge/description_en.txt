EV charging domain (evcharge): charging station list/detail, charging pile (including gun head) list, site operation data statistics, charging order list/detail – all read‑only. Used when a user wants to look up charging stations, charging piles, gun head status, charging orders, operator (agent) business data/charging revenue/electricity consumption and fees, or to query charging assets by operator account, phone number, or site ID. Trigger words: charging station, charging pile, charging gun/gun head, charging order, operator account, agent, charging revenue, electricity consumption, electricity fee/service fee, evcharge, plotCode, useraccount. Note: charging is an independent platform module that reuses the same signature authentication; order status is actually a two‑dimensional combination of chargeStatus (charging status) + orderState (order status), which differs from the orderStatus English enum in the integration documentation (refer to the platform’s actual measurements). For parking (non‑charging) fee inquiries/records/month tickets/coupons, use other openydt domain skills.
