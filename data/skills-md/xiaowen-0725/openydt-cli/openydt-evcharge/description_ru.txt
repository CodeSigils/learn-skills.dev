Домен зарядки электромобилей (evcharge): список/подробные сведения о зарядных станциях, список зарядных станций (включая сопло пистолета), статистика бизнес-данных станции, список/подробные сведения о заказе зарядки, все — только для чтения. Используется, когда пользователь хочет запросить зарядные станции, зарядные батареи, состояние пистолетных сопел, заказы на зарядку, бизнес-данные оператора (агента), доходы от зарядки, потребление электроэнергии и сборы, или запросить зарядные активы по учетной записи оператора, номеру телефона или идентификатору станции. Триггерные слова: зарядная станция, зарядная свая, зарядный пистолет/форсунка, порядок зарядки, учетная запись оператора, агент, доход от зарядки, количество зарядной электроэнергии, плата за электроэнергию/плата за услугу, evcharge,plotCode,useraccount. Примечание: тарификация представляет собой независимый модуль платформы, повторно использующий ту же аутентификацию по подписи; статус заказа, измеряемый на практике, представляет собой двойное измерение chargeStatus (статус зарядки) + orderState (статус заказа), что не соответствует английскому перечислению orderStatus в документации по интеграции (фактическое измерение платформы имеет преимущественную силу). Для запросов/записей/месячных билетов/купонов за парковку (бесплатную) используйте другие навыки работы с доменом openydt.
