Домен зарядки электромобилей (evcharge): список/подробные сведения о зарядных станциях, список зарядных устройств (включая головку пистолета), статистика бизнес-данных станции, список/подробные сведения о заказе зарядки, все только для чтения. Используется, когда пользователь хочет найти зарядные станции, зарядные батареи, состояние головки пистолета, заказы на зарядку, бизнес-данные оператора (агента)/доходы от зарядки/потребление и сборы за электроэнергию или запросить зарядные активы по учетной записи оператора, номеру телефона или идентификатору станции. Триггерные слова: зарядная станция, зарядная свая, зарядный пистолет/головка пистолета, порядок зарядки, учетная запись оператора, агент, доход от зарядки, потребление электроэнергии для зарядки, плата за электроэнергию/плата за обслуживание, evcharge,plotCode, useraccount. Примечание: тарификация — это независимый модуль платформы, который повторно использует ту же подпись аутентификации; наблюдаемый на практике статус заказа представляет собой двумерную комбинацию chargeStatus (статус зарядки) + orderState (статус заказа), которая не соответствует английскому перечислению orderStatus в документации по интеграции (преобладает фактическое наблюдение платформы). Для запросов/записей/месячных пропусков/купонов за парковку (бесплатную) используйте другие навыки в области openydt.
