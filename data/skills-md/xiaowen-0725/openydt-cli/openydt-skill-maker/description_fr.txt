Créez ou standardisez la méta-compétence pour les compétences personnalisées d'openydt (AiKe Smart Parking Open Platform CLI). Utilisez-le lorsqu'un utilisateur souhaite créer une nouvelle compétence de domaine openydt, encapsuler une API ou un processus métier en plusieurs étapes dans une compétence réutilisable, ou standardiser un SKILL.md existant (frontmatter / table de commandes / mots déclencheurs / opération d'écriture - oui garde). Il est comparable au créateur d’alouettes de Feishu.
