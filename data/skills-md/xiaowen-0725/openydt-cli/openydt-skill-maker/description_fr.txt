Créez ou standardisez la méta-compétence pour les compétences personnalisées d'openydt (Aikou Smart Parking Open Platform CLI). Il est utilisé lorsqu'un utilisateur souhaite créer une nouvelle compétence de domaine openydt, solidifier une API spécifique ou un processus métier en plusieurs étapes dans une compétence réutilisable, ou normaliser un SKILL.md existant (frontmatter / table de commandes / mots déclencheurs / opération d'écriture - oui garde). Cela correspond au créateur d’alouettes de Feishu.
