Cree o estandarice la meta‑habilidad para las habilidades personalizadas de openydt (CLI de plataforma abierta de estacionamiento inteligente de Aikou). Se utiliza cuando un usuario desea crear una nueva habilidad de dominio openydt, solidificar una API específica o un proceso comercial de varios pasos en una habilidad reutilizable, o normalizar un SKILL.md existente (frontmatter/tabla de comandos/palabras desencadenantes/operación de escritura, sí, guardia). Se alinea con el creador de habilidades de alondra de Feishu.
