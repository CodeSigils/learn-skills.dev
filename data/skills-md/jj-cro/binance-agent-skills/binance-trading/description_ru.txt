Торгует на Binance через пакет binance npm. Поддерживается спот, фьючерсы USD-M, фьючерсы COIN-M и портфельная маржа. Используйте, когда пользователь просит купить, продать, разместить заказы, проверить баланс, управлять позициями, перевести средства или торговать на Binance. Только для рыночных данных (цены, книга заказов) загружайте модули/market.md. Требуется Node.js и установка npm binance.
