Negocia en Binance a través del paquete binance npm. Admite al contado, futuros de USD-M, futuros de COIN-M y margen de cartera. Úselo cuando el usuario solicita comprar, vender, realizar pedidos, consultar saldo, administrar posiciones, transferir fondos o comerciar en Binance. Solo para datos de mercado (precios, libro de pedidos), cargue módulos/market.md. Requiere Node.js y npm install binance.
