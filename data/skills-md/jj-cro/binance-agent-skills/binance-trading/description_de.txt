Handelt auf Binance über das binance npm-Paket. Unterstützt Spot-, USD-M-Futures, COIN-M-Futures und Portfolio-Marge. Wird verwendet, wenn der Benutzer auf Binance kaufen, verkaufen, Bestellungen aufgeben, den Kontostand überprüfen, Positionen verwalten, Geld überweisen oder handeln möchte. Nur für Marktdaten (Preise, Orderbuch) laden Sie module/market.md. Erfordert Node.js und npm install binance.
