Produci e utilizza una knowledge base in stile wiki per un repository di codice tramite la CLI `zread` e il suo output su disco in `./.zread/wiki/`. Utilizzare questa competenza ogni volta che l'utente desidera comprendere, eseguire l'onboarding, esplorare, riassumere, mappare o ottenere una panoramica di una codebase sconosciuta; richiede documenti di architettura, un wiki di progetto, una procedura dettagliata del repository, spiegazioni su moduli/pacchetti o "cosa fa questo repository"; vuole generare, rigenerare, riprendere, sfogliare o fornire la documentazione del codice localmente; o menziona direttamente zread / zread.ai. Usalo anche in modo proattivo prima di immergerti in un grande repository sconosciuto: se esiste `./.zread/wiki/current`, leggi le pagine generate invece di eseguire la scansione del codice sorgente file per file; in caso contrario, considera l'offerta di eseguire `zread generate`. Il trigger è l'intento (comprendere una base di codice attraverso i documenti generati), non la parola letterale "zread".
