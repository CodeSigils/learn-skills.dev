Produisez et consommez une base de connaissances de style wiki pour un référentiel de code via la CLI `zread` et sa sortie sur disque sous `./.zread/wiki/`. Utilisez cette compétence chaque fois que l'utilisateur souhaite comprendre, intégrer, explorer, résumer, cartographier ou obtenir un aperçu d'une base de code inconnue ; demande des documents d'architecture, un wiki de projet, une présentation pas à pas du dépôt, des explications sur les modules/paquets ou « à quoi sert ce dépôt » ; souhaite générer, régénérer, reprendre, parcourir ou servir la documentation du code localement ; ou mentionne directement zread / zread.ai. Utilisez-le également de manière proactive avant de plonger dans un grand dépôt inconnu — si `./.zread/wiki/current` existe, lisez les pages générées au lieu d'explorer la source fichier par fichier ; si ce n'est pas le cas, envisagez de proposer d'exécuter « zread generate ». Le déclencheur est l'intention (comprendre une base de code grâce aux documents générés), et non le mot littéral "zread".
