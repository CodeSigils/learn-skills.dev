`zread` CLI와 `./.zread/wiki/` 아래의 디스크 출력을 통해 코드 저장소에 대한 위키 스타일 지식 기반을 생성하고 사용합니다. 사용자가 익숙하지 않은 코드베이스를 이해하고, 온보딩하고, 탐색하고, 요약하고, 매핑하거나, 개요를 얻고 싶을 때마다 이 기술을 사용하십시오. 아키텍처 문서, 프로젝트 위키, 저장소 연습, 모듈/패키지 설명 또는 "이 저장소의 기능"을 요청합니다. 코드 문서를 로컬에서 생성, 재생성, 재개, 탐색 또는 제공하려고 합니다. 또는 zread / zread.ai를 직접 언급합니다. 또한 알려지지 않은 대규모 저장소에 들어가기 전에 사전에 사용하십시오. `./.zread/wiki/current`가 존재하는 경우 소스 파일을 파일별로 크롤링하는 대신 생성된 페이지를 읽으십시오. 그렇지 않은 경우 'zread generate' 실행을 제안해 보세요. 트리거는 문자 그대로 "zread"라는 단어가 아니라 의도(생성된 문서를 통해 코드베이스 이해)입니다.
