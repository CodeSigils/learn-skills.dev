Produzca código de mayor calidad dividiendo una característica en tareas pequeñas y enfocadas que el agente de codificación pueda realizar una a la vez. Funciona como un equipo de ingeniería: función → hitos (entregables del producto) → tareas de ~30 minutos con archivos específicos, criterios de aceptación y dependencias. Cada tarea se ejecuta en un contexto nuevo: alcance limitado, atención total, un compromiso de git por tarea. Úselo al iniciar cualquier característica no trivial, refactorización compleja o cuando desee que el agente se concentre en una cosa pequeña a la vez en lugar de hacer malabarismos con una característica completa en una sesión. Soporta /loop para ejecución autónoma.
