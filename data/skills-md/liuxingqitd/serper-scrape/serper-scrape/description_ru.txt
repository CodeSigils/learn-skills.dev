Вызовите Serper API для поиска и очистки веб-контента. Он поддерживает два режима: (1) режим поиска – поиск веб-страниц по ключевым словам с фильтрацией по временному диапазону; (2) Режим очистки — получение содержимого уценки указанного URL-адреса. Используйте этот навык, когда пользователь говорит «поиск», «найти», «поиск», «очистить веб-страницу», «получить веб-контент» или «очистить».
