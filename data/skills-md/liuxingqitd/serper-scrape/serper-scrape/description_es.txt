Invoque la API de Serper para buscar y extraer contenido web. Admite dos modos: (1) modo de búsqueda: busca páginas web según palabras clave, con filtrado por rango de tiempo; (2) Modo raspado: recupera el contenido de rebajas de una URL específica. Utilice esta habilidad cuando el usuario diga "buscar", "encontrar", "buscar", "extraer página web", "obtener contenido web" o "raspar".
