Invoquez l'API Serper pour rechercher et extraire du contenu Web. Il prend en charge deux modes : (1) Mode de recherche : recherche de pages Web en fonction de mots-clés, avec filtrage par plage temporelle ; (2) Mode Scrape – récupère le contenu markdown d’une URL spécifiée. Utilisez cette compétence lorsque l'utilisateur dit « rechercher », « trouver », « rechercher », « gratter une page Web », « obtenir du contenu Web » ou « gratter ».
