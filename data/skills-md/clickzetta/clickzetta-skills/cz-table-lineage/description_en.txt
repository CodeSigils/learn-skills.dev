Table lineage visualization tool. Retrieves table dependency and cost data from ClickZetta information_schema.job_history, exports to CSV, then embeds it into an HTML template to generate an interactive lineage diagram. Triggered when the user says "表血缘", "table lineage", "依赖关系图", "数据流向", "上下游分析", "血缘可视化", or "pipeline 可视化".
