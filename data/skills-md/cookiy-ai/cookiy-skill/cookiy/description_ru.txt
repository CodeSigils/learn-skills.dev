Исследование пользователей на основе искусственного интеллекта с помощью естественного языка. Устанавливает сервер Cookiy MCP и организует рабочие процессы инструментов для создания исследований, интервью с искусственным интеллектом, редактирования руководств по обсуждениям, набора участников и создания отчетов.
