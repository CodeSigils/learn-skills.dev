Exploitation d'ingénierie indépendante du fournisseur pour le codage, les corrections de bugs, les refactorisations, le débogage, les tests, les versions et autres travaux logiciels en plusieurs étapes. À utiliser lorsqu'un agent doit conserver une spécification légère, définir un contrat terminé, isoler les modifications, contrôler les actions risquées, valider les résultats avec des preuves proportionnées, préserver le travail de l'utilisateur et quitter l'état récupérable.
