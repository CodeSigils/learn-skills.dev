Используйте этот навык, когда пользователь хочет выполнять операции Atlassian с терминала с помощью инструмента командной строки acli. Запускается, когда пользователь хочет фактически запускать команды в Jira или Confluence (создавать задачи, перемещать рабочие элементы, выполнять поиск с помощью JQL, управлять спринтами, экспортировать данные, выполнять массовые операции), настраивать аутентификацию acli или интеграцию конвейера CI или использовать управление пользователями с правами администратора Rovo Dev или Atlassian через CLI. НЕ активируйте: концептуальные вопросы о конфигурации Jira/Confluence (столбцы доски, дизайн рабочего процесса, настройка единого входа), общие рекомендации Atlassian, чтение веб-URL-адресов или написание пользовательских сценариев API на Python и т. д. Ключевым сигналом является намерение запускать команды терминала для Atlassian, а не просто обсуждать, разрабатывать или понимать продукты Atlassian.
