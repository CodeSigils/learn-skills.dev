사용자가 'acli' 명령줄 도구를 사용하여 터미널에서 Atlassian 작업을 실행하려는 경우 이 기술을 사용하세요. 사용자가 Jira 또는 Confluence에 대해 실제로 명령을 실행(문제 생성, 작업 항목 전환, JQL로 검색, 스프린트 관리, 데이터 내보내기, 대량 작업)하거나, acli 인증 또는 CI 파이프라인 통합을 설정하거나, CLI를 통해 Rovo Dev 또는 Atlassian 관리자 사용자 관리를 사용하려고 할 때 트리거됩니다. 다음의 경우에는 트리거하지 마세요: Jira/Confluence 구성(보드 열, 워크플로 디자인, SSO 설정)에 대한 개념적 질문, 일반적인 Atlassian 모범 사례, 웹 URL 읽기 또는 Python/등에서 사용자 정의 API 스크립트 작성. 핵심 신호는 Atlassian 제품에 대해 단순히 토론, 설계 또는 이해하는 것이 아니라 Atlassian에 대해 터미널 명령을 실행하려는 의도입니다.
