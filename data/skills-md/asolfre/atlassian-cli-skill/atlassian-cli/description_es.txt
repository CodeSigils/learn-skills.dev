Utilice esta habilidad cuando el usuario quiera ejecutar operaciones de Atlassian desde la terminal usando la herramienta de línea de comandos `acli`. Se activa cuando el usuario realmente desea ejecutar comandos contra Jira o Confluence (crear problemas, realizar transiciones de elementos de trabajo, buscar con JQL, administrar sprints, exportar datos, operaciones masivas), configurar la autenticación acli o la integración de canalización de CI, o usar Rovo Dev o la administración de usuarios administradores de Atlassian a través de CLI. NO active para: preguntas conceptuales sobre la configuración de Jira/Confluence (columnas del tablero, diseño de flujo de trabajo, configuración de SSO), mejores prácticas generales de Atlassian, lectura de URL web o escritura de scripts API personalizados en Python/etc. La señal clave es la intención de ejecutar comandos de terminal contra Atlassian, no solo discutir, diseñar o comprender los productos de Atlassian.
