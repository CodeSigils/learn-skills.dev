Utilizza questa competenza quando l'utente desidera eseguire operazioni Atlassian dal terminale utilizzando lo strumento da riga di comando "acli". Si attiva quando l'utente desidera eseguire effettivamente comandi su Jira o Confluence (creare problemi, trasferire elementi di lavoro, eseguire ricerche con JQL, gestire sprint, esportare dati, operazioni in blocco), impostare l'autenticazione acli o l'integrazione della pipeline CI oppure utilizzare Rovo Dev o la gestione degli utenti amministratori Atlassian tramite CLI. NON attivare per: domande concettuali sulla configurazione di Jira/Confluence (colonne della scheda, progettazione del flusso di lavoro, configurazione SSO), best practice generali di Atlassian, lettura di URL Web o scrittura di script API personalizzati in Python/ecc. Il segnale chiave è l’intenzione di eseguire comandi terminali contro Atlassian, non solo discutere, progettare o comprendere i prodotti Atlassian.
