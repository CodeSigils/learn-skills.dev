ユーザーが「acli」コマンドライン ツールを使用してターミナルからアトラシアン操作を実行する場合は、このスキルを使用します。ユーザーが実際に Jira または Confluence に対してコマンドを実行する場合 (課題の作成、作業項目の移行、JQL による検索、スプリントの管理、データのエクスポート、一括操作)、ACI 認証または CI パイプライン統合の設定、または CLI を介した Rovo Dev または Atlassian 管理者ユーザー管理の使用を希望するときにトリガーします。次の場合はトリガーしないでください: Jira/Confluence 構成 (ボード列、ワークフロー設計、SSO セットアップ)、一般的な Atlassian ベスト プラクティス、Web URL の読み取り、または Python でのカスタム API スクリプトの作成などに関する概念的な質問。重要なシグナルは、Atlassian 製品について議論、設計、理解するだけではなく、Atlassian に対してターミナル コマンドを実行することを目的としています。
