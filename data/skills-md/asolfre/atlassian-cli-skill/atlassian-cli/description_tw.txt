當使用者想要使用「acli」命令列工具從終端執行 Atlassian 操作時，請使用此技能。當使用者想要實際針對 Jira 或 Confluence 執行命令（建立問題、轉換工作項目、使用 JQL 搜尋、管理衝刺、匯出資料、批次操作）、設定 acli 驗證或 CI 管道集成，或透過 CLI 使用 Rovo Dev 或 Atlassian 管理員使用者管理時觸發。請勿觸發：有關 Jira/Confluence 配置（板列、工作流程設計、SSO 設定）、一般 Atlassian 最佳實踐、讀取 Web URL 或用 Python 等編寫自訂 API 腳本的概念性問題。關鍵訊號是針對 Atlassian 運行終端命令的意圖 - 而不僅僅是討論、設計或理解 Atlassian 產品。
