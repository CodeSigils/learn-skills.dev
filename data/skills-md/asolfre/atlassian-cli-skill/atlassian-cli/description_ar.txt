استخدم هذه المهارة عندما يريد المستخدم تنفيذ عمليات Atlassian من الوحدة الطرفية باستخدام أداة سطر الأوامر `acli`. يتم التشغيل عندما يريد المستخدم تشغيل الأوامر فعليًا ضد Jira أو Confluence (إنشاء مشكلات، أو نقل عناصر العمل، أو البحث باستخدام JQL، أو إدارة الدورات السريعة، أو تصدير البيانات، أو العمليات المجمعة)، أو إعداد مصادقة acli أو تكامل خط أنابيب CI، أو استخدام إدارة مستخدم Rovo Dev أو Atlassian عبر CLI. لا تثير الأسئلة التالية: أسئلة مفاهيمية حول تكوين Jira/Confluence (أعمدة اللوحة، تصميم سير العمل، إعداد SSO)، أفضل ممارسات Atlassian العامة، قراءة عناوين URL على الويب، أو كتابة نصوص برمجة API مخصصة في Python/إلخ. الإشارة الرئيسية هي نية تشغيل الأوامر الطرفية ضد Atlassian - وليس فقط مناقشة منتجات Atlassian أو تصميمها أو فهمها.
