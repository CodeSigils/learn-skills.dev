Создает документацию по API с использованием спецификаций OpenAPI/Swagger с интерактивной документацией, примерами кода и генерацией SDK. Используйте, когда пользователи запрашивают «документацию API», «спецификацию OpenAPI», «документы Swagger», «конечные точки API документа» или «создание ссылки на API».
