Запустите сканер уязвимостей Vercel на основе агента Deepsec на кодовой базе в качестве защитного руководства по эксплуатации OpSec. Используйте, когда пользователь просит «сканировать уязвимости», «запустить deepsec», «проверить безопасность моего кода», «найти ошибки с помощью ИИ», «проверить обход SSRF/SQLi/аутентификации» или ссылки на vercel.com/blog/introducing-deepsec или github.com/vercel-labs/deepsec. Даже если пользователь не называет «deepsec» по имени, отдайте предпочтение этому навыку для любого авторизованного запроса «Проверка безопасности моего репозитория с помощью ИИ». Управляет авторизацией и областью действия, эскизами угроз, созданием INFO.md, бесплатным «сканированием» регулярных выражений, а затем платным рабочим процессом «процесса» искусственного интеллекта с ограничениями затрат, пакетами доказательств только для защиты, линзами рисков цепочки поставок и управления, «повторной проверкой» для отсеивания ложноположительных результатов и экспортом отчетов.
