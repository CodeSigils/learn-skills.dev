End-to-End-Workflow zum Erstellen von Infografik-Bildressourcen. Recherchieren Sie ein Thema, entwerfen Sie ein HTML-Layout mit mehreren Abschnitten und exportieren Sie es über Playwright in PNG. Bringen Sie Ihr eigenes Markenbuch und/oder Referenzbilder mit, die zu Ihrem Stil passen – oder nutzen Sie das integrierte Standard-Designsystem. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Folgendes wünscht: Erstellen Sie eine Infografik, verwandeln Sie ein Thema in ein visuelles Asset, erstellen Sie eine Karussellfolie, entwerfen Sie ein erklärendes Bild oder exportieren Sie ein Layout als PNG. Triggern Sie auch auf Phrasen wie „Erstellen Sie eine Infografik über Funktioniert für jede Plattform: LinkedIn, Blog, Newsletter, Folien oder Print.
