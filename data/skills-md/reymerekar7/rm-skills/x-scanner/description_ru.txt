Сканируйте X/Twitter на предмет последних публикаций из курируемого списка создателей искусственного интеллекта и новостных аккаунтов с помощью API Grok от xAI с инструментом x_search. Используйте этот навык всякий раз, когда пользователь просит: проверить, что происходит в ИИ-Твиттере, сканировать X на предмет новостей, получить последние твиты от создателей, получить дайджест новостей ИИ, найти актуальные темы ИИ или сгенерировать идеи контента из X. Также срабатывает при запуске запланированной задачи сканирования ИИ-новостей. Для этого навыка требуется ключ API xAI.
