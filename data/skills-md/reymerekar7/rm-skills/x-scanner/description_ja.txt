xAI の Grok API と x_search ツールを使用して、X/Twitter をスキャンして、AI クリエイターとニュース アカウントの厳選されたリストから最近の投稿を探します。 AI Twitter で何が起こっているかを確認する、X をスキャンしてニュースを探す、クリエイターから最近のツイートを取得する、AI ニュース ダイジェストを取得する、トレンドの AI トピックを見つける、または X からコンテンツのアイデアを生成するなど、ユーザーが要求するたびにこのスキルを使用します。また、スケジュールされた ai-news-scan タスクが実行されるときにもトリガーされます。このスキルには xAI API キーが必要です。
