Инструмент развития агентских навыков и обеспечения качества. Обеспечивает инициализацию навыков, уточнение требований, проверку спецификаций, структурный анализ, предложения по рефакторингу и создание шаблонов с помощью инструментов MCP.

Когда использовать:
- Уточнение требований: собрать информацию, необходимую для создания навыков, посредством диалога с ИИ.
- Создать новую структуру проекта Agent-Skill.
- Проверить, соответствуют ли навыки требованиям постепенного раскрытия информации.
- Анализировать эффективность токенов и структурное качество навыков.
- Получите предложения по рефакторингу, основанные на лучших практиках.
- Получите доступ к шаблонам навыков и руководствам по передовому опыту.

Триггерные слова:
- Уточнение требований
- Создание навыков
- Инициализация навыков
- Проверка навыков
- Анализ навыков
- Навыки рефакторинга
- Шаблон навыков
