Führen Sie eine formelle, mehrdimensionale Codeüberprüfung einer Pull-Anfrage durch. Liest den PR-Diff, klassifiziert Änderungstypen, entsendet parallele Prüfer nach Dimension (Spezifikationskonformität, Korrektheit inkl. Testqualität, Dokumentensynchronisierung sowie bedingte Robustheit/UX/Leistung/Struktur und Codequalität für nicht triviale Änderungen) und fasst die Ergebnisse in einer umsetzbaren Fehlerliste zusammen. Verwenden Sie diese Option, wenn der Benutzer darum bittet, eine PR zu überprüfen, /deep-review auszuführen, eine PR als zur Überprüfung bereit zu markieren oder eine formelle/gründliche Codeüberprüfung anfordert.
