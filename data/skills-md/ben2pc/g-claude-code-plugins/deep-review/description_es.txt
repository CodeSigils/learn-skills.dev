Ejecute una revisión de código formal y multidimensional de una solicitud de extracción. Lee la diferencia de relaciones públicas, clasifica los tipos de cambios, envía revisores paralelos por dimensión (conformidad con las especificaciones, corrección, incluida la calidad de las pruebas, sincronización de documentos, además de solidez condicional/UX/rendimiento/estructura y calidad del código para cambios no triviales) y sintetiza los hallazgos en una lista de tareas procesables. Úselo cuando el usuario solicita revisar un PR, ejecutar/revisión profunda, marcar un PR como listo para revisión o solicita una revisión de código formal/completa.
