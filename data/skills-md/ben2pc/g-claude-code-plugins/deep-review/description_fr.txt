Exécutez une révision formelle et multidimensionnelle du code d’une pull request. Lit les différences PR, classe les types de modifications, répartit les réviseurs parallèles par dimension (conformité aux spécifications, exactitude, y compris la qualité des tests, synchronisation des documents, plus robustesse conditionnelle/UX/performances/structure et qualité du code pour les modifications non triviales) et synthétise les résultats dans une liste de points exploitables. À utiliser lorsque l'utilisateur demande à réviser un PR, à exécuter une révision approfondie, à marquer un PR comme prêt à être révisé ou à demander une révision formelle/approfondie du code.
