Su macOS e Chrome, diagnostica l'uscita IPv4/IPv6 pubblica, il paese/regione, l'ASN/l'organizzazione, il DNS, il percorso predefinito, lo stato utun, la risposta del server lato browser e l'esposizione WebRTC. Per gli utenti che richiedono coerenza IP/regione, acquisizione di VPN/proxy, problemi IPv6 o esposizione alla rete del browser e output di un report operativo dettagliato con collegamento di ricontrollo.
