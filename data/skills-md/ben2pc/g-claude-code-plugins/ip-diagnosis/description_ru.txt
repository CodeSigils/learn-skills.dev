В macOS + Chrome диагностируйте исходящий общедоступный IPv4/IPv6, страну/регион, ASN/организацию, DNS, маршрут по умолчанию, состояние utun, а также ответ сервера на стороне браузера и воздействие WebRTC. Для пользователей, которым требуется согласованность IP/региона, перехват VPN/прокси, проблемы IPv6 или уязвимость сети браузера, а также вывод подробного отчета об операциях со ссылкой для повторной проверки.
