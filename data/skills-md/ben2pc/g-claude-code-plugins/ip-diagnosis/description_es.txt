En macOS + Chrome, diagnostique la salida pública de IPv4/IPv6, el país/región, ASN/organización, DNS, ruta predeterminada, estado de utun y respuesta del servidor del lado del navegador y exposición a WebRTC. Para usuarios que solicitan coherencia de IP/región, toma de control de VPN/proxy, problemas de IPv6 o exposición de la red del navegador, y generar un informe de operaciones detallado con un enlace de nueva verificación.
