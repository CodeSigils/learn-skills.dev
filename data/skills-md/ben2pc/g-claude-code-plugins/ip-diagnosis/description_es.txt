En macOS + Chrome, inspeccione la salida pública de IPv4/IPv6, el país/región, ASN/org, DNS, ruta predeterminada, estado de utun, además de la respuesta del servidor del lado del navegador y la exposición a WebRTC. Para usuarios que necesitan verificar la coherencia de IP/región, toma de control de VPN/proxy, problemas de IPv6 o fugas de red del navegador, y generar un informe de operaciones detallado con un enlace de nueva verificación.
