Delegue tareas de codificación, revisión, diagnóstico, planificación, resultados estructurados e investigación del navegador nativo a sesiones independientes de Codex a través de Codex CLI. Los casos de uso incluyen `codex exec` para nuevas tareas, `codex exec resume` para continuar sesiones de varios turnos, `codex exec review` para revisión de solo lectura y cuando se necesitan secuencias de eventos `--json`, `-o` persistencia de mensajes finales, entrada de imágenes u operaciones de navegador de uso de computadora.
