Déléguez les tâches de codage, de révision, de diagnostic, de planification, de sortie structurée et de recherche dans le navigateur natif à des sessions Codex autonomes via Codex CLI. Les cas d'utilisation incluent « codex exec » pour les nouvelles tâches, « codex exec curriculum vitae » pour continuer les sessions à plusieurs tours, « codex exec review » pour une révision en lecture seule et lorsque vous avez besoin de flux d'événements « --json », la persistance du message final « -o », la saisie d'image ou les opérations de navigateur d'utilisation de l'ordinateur.
