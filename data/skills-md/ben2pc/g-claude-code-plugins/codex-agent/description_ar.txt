تفويض مهام البرمجة والمراجعة والتشخيص والتخطيط والمخرجات المنظمة ومهام البحث في المتصفح الأصلي إلى جلسات Codex المستقلة عبر Codex CLI. تتضمن حالات الاستخدام `codex exec` للمهام الجديدة، و`codex exec استئناف` لمواصلة الجلسات متعددة الأدوار، و`مراجعة codex exec` للمراجعة للقراءة فقط، وعند الحاجة إلى تدفقات أحداث `--json`، و`-o` ثبات الرسالة النهائية، أو إدخال الصور، أو عمليات المتصفح لاستخدام الكمبيوتر.
