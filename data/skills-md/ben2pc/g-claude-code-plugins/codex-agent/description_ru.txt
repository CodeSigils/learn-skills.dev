Делегируйте кодирование, проверку, диагностику, планирование, структурированный вывод и исследования в браузере автономным сеансам Кодекса через интерфейс командной строки Codex. Варианты использования включают `codex exec` для новых задач, `codex exec возобновить` для продолжения многоходовых сеансов, `codex exec review` для просмотра только для чтения, а также при необходимости потоков событий `--json`, сохранения окончательного сообщения `-o`, ввода изображений или операций браузера с использованием компьютера.
