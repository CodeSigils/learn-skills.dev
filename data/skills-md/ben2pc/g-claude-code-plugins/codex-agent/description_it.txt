Delega attività di codifica, revisione, diagnosi, pianificazione, output strutturato e ricerca del browser nativo a sessioni Codex autonome tramite la CLI Codex. I casi d'uso includono `codex exec` per nuove attività, `codex exec curriculum` per continuare le sessioni a più turni, `codex exec review` per la revisione in sola lettura e quando sono necessari flussi di eventi `--json`, `-o` persistenza del messaggio finale, input di immagini o operazioni del browser per l'uso del computer.
