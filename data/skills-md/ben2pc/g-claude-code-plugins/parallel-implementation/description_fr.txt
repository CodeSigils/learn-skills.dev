Planifiez comment répartir une tâche de codage non triviale entre des sous-agents parallèles. Renvoie un plan de répartition (affectations de fichiers, dépendances, contrats de format de sortie) — l'agent principal l'exécute ensuite avec l'outil Agent + `isolation : "worktree"`. À invoquer uniquement lorsque le travail justifie une surcharge multi-agent : (a) greenfield 0 → 1 sur plusieurs modules indépendants, (b) le changement touche ≥ 3 modules, ou (c) ≥ 5 fichiers chacun avec > 50 lignes de diff. Les petits changements sont écrits en ligne.
