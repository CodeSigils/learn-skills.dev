並列サブエージェント間で重要なコーディング タスクをスライスする方法を計画します。ディスパッチ プラン (ファイルの割り当て、依存関係、出力形式のコントラクト) を返します。その後、メイン エージェントがエージェント ツール + `isolation: "worktree"` を使用してそれを実行します。作業がマルチエージェントのオーバーヘッドを正当化する場合にのみ呼び出します: (a) 複数の独立したモジュールにわたるグリーンフィールド 0→1、(b) 変更タッチ ≥3 モジュール、または (c) それぞれの差分行が 50 行を超える 5 ファイル以上。小さな変更はインラインで書き込まれます。
