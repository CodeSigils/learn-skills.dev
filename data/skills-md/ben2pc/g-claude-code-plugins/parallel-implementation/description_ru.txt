Спланируйте, как разделить нетривиальную задачу кодирования на параллельные субагенты. Возвращает план отправки (назначения файлов, зависимости, контракты выходного формата) — затем основной агент выполняет его с помощью инструмента агента + `isolation: "worktree"`. Вызывайте только тогда, когда работа оправдывает накладные расходы нескольких агентов: (a) новое поле 0 → 1 для нескольких независимых модулей, (b) изменение касается ≥3 модулей или (c) ≥5 файлов, каждый из которых содержит >50 строк различий. Небольшие изменения пишите в строке.
