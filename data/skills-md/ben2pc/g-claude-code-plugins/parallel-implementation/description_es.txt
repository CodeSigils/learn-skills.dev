Planifique cómo dividir una tarea de codificación no trivial entre subagentes paralelos. Devuelve un plan de distribución (asignaciones de archivos, dependencias, contratos de formato de salida); luego, el Agente principal lo ejecuta con la herramienta Agente + `aislamiento: "árbol de trabajo"`. Invoque solo cuando el trabajo justifique la sobrecarga de múltiples agentes: (a) greenfield 0→1 en múltiples módulos independientes, (b) el cambio toca ≥3 módulos, o (c) ≥5 archivos cada uno con >50 líneas de diferencia. Los pequeños cambios se escriben en línea.
