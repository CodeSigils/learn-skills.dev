Planen Sie, wie Sie eine nicht triviale Codierungsaufgabe auf parallele Subagenten aufteilen. Gibt einen Dispatch-Plan zurück (Dateizuweisungen, Abhängigkeiten, Verträge im Ausgabeformat) – der Hauptagent führt ihn dann mit dem Agent-Tool + „Isolation: „worktree““ aus. Nur aufrufen, wenn die Arbeit den Mehragenten-Overhead rechtfertigt: (a) Greenfield 0→1 über mehrere unabhängige Module hinweg, (b) Änderung berührt ≥3 Module oder (c) ≥5 Dateien mit jeweils >50 Zeilen Differenz. Kleine Änderungen werden inline geschrieben.
