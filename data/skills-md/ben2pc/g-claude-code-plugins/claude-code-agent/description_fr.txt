Grâce au point d'entrée du SDK Agent `claude -p` de la CLI Claude Code, déléguez les tâches de codage, de révision, de diagnostic, de planification et de sortie structurée à une session Claude Code distincte. Les cas d'utilisation incluent `--resume` / `--continue` pour la poursuite des conversations à plusieurs tours, `--output-format json` pour la sortie à résultat unique, les flux d'événements `stream-json` et les invocations scriptées/CI qui nécessitent `--worktree`, des listes blanches d'outils, `--bare` ou une sortie JSON structurée.
