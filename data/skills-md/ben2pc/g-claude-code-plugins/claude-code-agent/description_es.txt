A través del punto de entrada del SDK del agente `claude -p` de la CLI de Claude Code, delegue tareas de codificación, revisión, diagnóstico, planificación y salida estructurada a una sesión separada de Claude Code. Los casos de uso incluyen `--resume`/`--continue` para continuar conversaciones de varios turnos, `--output-format json` para salida de resultado único, secuencias de eventos `stream-json` e invocaciones con script/CI que requieren `--worktree`, listas blancas de herramientas, `--bare` o salida JSON estructurada.
