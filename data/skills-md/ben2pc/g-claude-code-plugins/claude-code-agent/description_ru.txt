С помощью точки входа `claude -p` Agent SDK CLI Claude Code делегируйте задачи кодирования, проверки, диагностики, планирования и структурированного вывода в отдельный сеанс Claude Code. Варианты использования включают `--resume` / `--continue` для продолжения многоходового диалога, `--output-format json` для вывода одного результата, потоки событий `stream-json` и вызовы сценариев/CI, для которых требуется `--worktree`, белые списки инструментов, `--bare` или структурированный вывод JSON.
