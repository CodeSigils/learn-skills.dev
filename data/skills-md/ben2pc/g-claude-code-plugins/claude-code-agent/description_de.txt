Über den Agent-SDK-Einstiegspunkt „claude -p“ der Claude Code-CLI können Sie Codierungs-, Überprüfungs-, Diagnose-, Planungs- und strukturierte Ausgabeaufgaben an eine separate Claude Code-Sitzung delegieren. Zu den Anwendungsfällen gehören „--resume“ / „--continue“ für die Fortsetzung von Konversationen mit mehreren Runden, „--output-format json“ für die Ausgabe einzelner Ergebnisse, „stream-json“-Ereignisströme und Skript-/CI-Aufrufe, die „--worktree“, Tool-Whitelists, „--bare“ oder strukturierte JSON-Ausgabe erfordern.
