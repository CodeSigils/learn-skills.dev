Attraverso il punto di ingresso `claude -p` Agent SDK della CLI di Claude Code, delega le attività di codifica, revisione, diagnostica, pianificazione e output strutturato a una sessione di Claude Code separata. I casi d'uso includono "--resume" / "--continue" per conversazioni multi-turn continue, "--output-format json" per output con risultato singolo, flussi di eventi "stream-json" e invocazioni con script/CI che richiedono "--worktree", whitelist di strumenti, "--bare" o output JSON strutturato.
