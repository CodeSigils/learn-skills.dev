Through the `claude -p` Agent SDK entry point of the Claude Code CLI, delegate coding, review, diagnostics, planning, and structured output tasks to a separate Claude Code session. Use cases include `--resume` / `--continue` for continuing multi‑turn conversations, `--output-format json` for single‑result output, `stream-json` event streams, and scripted/CI invocations that require `--worktree`, tool whitelists, `--bare`, or structured JSON output.
