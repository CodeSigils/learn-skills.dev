من خلال نقطة دخول Agent SDK `clude -p` في Claude Code CLI، قم بتفويض مهام البرمجة والمراجعة والتشخيص والتخطيط ومهام الإخراج المنظمة إلى جلسة Claude Code منفصلة. تتضمن حالات الاستخدام `--resume` / `--continue` لاستمرار المحادثات متعددة المنعطفات، و`--output-format json` لمخرجات النتيجة الفردية، وتدفقات الأحداث `stream-json`، واستدعاءات CI المكتوبة التي تتطلب `-worktree`، أو القوائم البيضاء للأداة، أو `--bare`، أو مخرجات JSON المنظمة.
