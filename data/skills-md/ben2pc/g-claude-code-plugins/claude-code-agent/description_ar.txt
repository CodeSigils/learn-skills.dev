من خلال نقطة دخول Agent SDK الخاصة بـ Claude Code CLI، قم بتفويض الترميز والمراجعة والتشخيص والتخطيط ومهام الإخراج المنظمة لجلسات Claude Code المستقلة. تتضمن حالات الاستخدام `--resume`/`--continue` لاستئناف المحادثات متعددة المنعطفات، و`--output-format json` لمخرجات النتيجة الفردية، وتدفقات الأحداث `stream-json`، واستدعاءات CI المكتوبة التي تتطلب `--worktree`، أو القائمة البيضاء للأداة، أو `--bare`، أو مخرجات JSON المنظمة.
