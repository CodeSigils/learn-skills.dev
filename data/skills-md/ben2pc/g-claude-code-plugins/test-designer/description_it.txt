Progetta test di fallimento per funzionalità complesse utilizzando la valutazione indipendente: invia un agente libero dal contesto che vede solo le specifiche dei requisiti e i percorsi del codice (non l'approccio di implementazione), quindi restituisce test di fallimento eseguibili. Da utilizzare quando si avvia TDD per una funzionalità non banale, quando il requisito è sufficientemente ambiguo da comportare un rischio di test distorti o quando l'utente richiede una progettazione di test indipendente.
