Concevez des tests d'échec pour des fonctionnalités complexes à l'aide de l'évaluation indépendante : distribue un agent sans contexte qui voit uniquement les spécifications des exigences et les chemins de code (pas l'approche d'implémentation), puis renvoie les tests d'échec exécutables. À utiliser lors du démarrage de TDD pour une fonctionnalité non triviale, lorsque l'exigence est suffisamment ambiguë pour que des tests biaisés constituent un risque, ou lorsque l'utilisateur demande une conception de test indépendante.
