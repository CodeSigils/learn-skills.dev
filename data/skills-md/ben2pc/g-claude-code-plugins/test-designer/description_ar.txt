تصميم اختبارات فاشلة للميزات المعقدة باستخدام التقييم المستقل - يرسل وكيلًا خاليًا من السياق يرى فقط مواصفات المتطلبات ومسارات التعليمات البرمجية (وليس نهج التنفيذ)، ثم يُرجع اختبارات الفشل القابلة للتنفيذ. يُستخدم عند بدء تشغيل TDD لميزة غير تافهة، أو عندما يكون المتطلبات غامضًا بدرجة كافية بحيث تمثل الاختبارات المتحيزة خطرًا، أو عندما يطلب المستخدم تصميم اختبار مستقل.
