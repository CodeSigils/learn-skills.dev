Entwerfen Sie fehlgeschlagene Tests für komplexe Funktionen mithilfe der unabhängigen Bewertung – sendet einen kontextfreien Agenten, der nur die Anforderungsspezifikation und Codepfade (nicht den Implementierungsansatz) sieht, und gibt dann ausführbare fehlgeschlagene Tests zurück. Verwenden Sie diese Option, wenn Sie TDD für eine nicht triviale Funktion starten, wenn die Anforderung mehrdeutig genug ist, dass voreingenommene Tests ein Risiko darstellen, oder wenn der Benutzer ein unabhängiges Testdesign anfordert.
