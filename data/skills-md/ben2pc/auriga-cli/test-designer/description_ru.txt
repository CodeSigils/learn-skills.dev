Создавайте неудавшиеся тесты для сложных функций с помощью независимой оценки — отправляет контекстно-свободный агент, который видит только спецификацию требований и пути к коду (а не подход к реализации), а затем возвращает исполняемые неудачные тесты. Используйте при запуске TDD для нетривиальной функции, когда требование достаточно неоднозначно, и необъективные тесты представляют собой риск, или когда пользователь запрашивает независимую разработку теста.
