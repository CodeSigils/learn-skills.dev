Questa abilità dovrebbe essere utilizzata quando l'utente chiede di "复盘 / 总结 / 沉淀 / concludere questa sessione", "整理一下这次会话" o "estrarre informazioni da questa sessione". Composta una singola sessione CLI di Claude Code o Codex in un report HTML interattivo autonomo (sequenza temporale narrativa + token/cache/integrità dello strumento + un pannello di gioco con elementi candidati controllabili per installazioni di competenze dell'ecosistema/modifiche di AGENTS.md/lacune di nuove competenze) in modo che l'utente possa rivedere, selezionare e copiare un prompt che colloca ciascun elemento nel posto giusto.
