Diese Fähigkeit sollte verwendet werden, wenn der Benutzer auffordert, „diese Sitzung abzuschließen“, „整理一下这次会话“ oder „Imbiss aus dieser Sitzung zu extrahieren“. Es fügt eine einzelne Claude Code- oder Codex-CLI-Sitzung zu einem eigenständigen interaktiven HTML-Bericht zusammen (narrative Zeitleiste + Token / Cache / Tool-Zustand + ein Playground-Panel mit überprüfbaren Kandidatenelementen für Ökosystem-Skill-Installationen / AGENTS.md-Änderungen / neue Skill-Lücken), sodass der Benutzer eine Eingabeaufforderung überprüfen, ankreuzen und zurückkopieren kann, die jedes Element an der richtigen Stelle landet.
