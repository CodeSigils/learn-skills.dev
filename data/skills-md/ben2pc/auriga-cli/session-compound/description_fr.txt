Cette compétence doit être utilisée lorsque l'utilisateur demande « 复盘 / 总结 / 沉淀 / conclure cette session », « 整理一下这次会话 » ou « extraire les points à retenir de cette session ». Il regroupe une seule session Claude Code ou Codex CLI en un rapport HTML interactif autonome (chronologie narrative + jeton/cache/santé de l'outil + un panneau de terrain de jeu avec des éléments candidats vérifiables pour les installations de compétences de l'écosystème/modifications AGENTS.md/lacunes de nouvelles compétences) afin que l'utilisateur puisse examiner, cocher et recopier une invite qui place chaque élément au bon endroit.
