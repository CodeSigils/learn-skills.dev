Optimiza las aplicaciones de Atlassian Forge para reducir el consumo de la plataforma y evitar costos innecesarios utilizando la guía "Optimizar los costos de la plataforma Forge" de Atlassian. Úselo cuando el usuario solicite optimizar los costos de la aplicación Forge, reducir las invocaciones de Forge, reducir los GB-segundo, reducir el almacenamiento o el uso de registros, ajustar la memoria, reemplazar el sondeo, mejorar los activadores programados, reducir las escrituras KVS, mover el trabajo al frontend, usar API puente, llamadas API por lotes, agregar almacenamiento en caché o evaluar las compensaciones de Forge Remote. De forma predeterminada, realice primero una auditoría y ofrezca realizar los cambios recomendados después de presentar la auditoría. Modifique archivos únicamente inmediatamente cuando el usuario solicite explícitamente al agente que implemente o aplique optimizaciones.
