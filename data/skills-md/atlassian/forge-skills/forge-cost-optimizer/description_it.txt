Ottimizza le app Atlassian Forge per ridurre il consumo della piattaforma ed evitare costi inutili utilizzando la guida "Ottimizza i costi della piattaforma Forge" di Atlassian. Da utilizzare quando l'utente richiede di ottimizzare i costi dell'app Forge, ridurre le chiamate Forge, ridurre i GB-secondi, ridurre l'utilizzo dello spazio di archiviazione o del registro, ottimizzare la memoria, sostituire il polling, migliorare i trigger pianificati, ridurre le scritture KVS, spostare il lavoro sul frontend, utilizzare API bridge, chiamate API batch, aggiungere memorizzazione nella cache o valutare i compromessi di Forge Remote. Per impostazione predefinita, esegui prima un audit e offriti di apportare le modifiche consigliate dopo aver presentato l'audit. Modificare i file immediatamente solo quando l'utente chiede esplicitamente all'agente di implementare o applicare ottimizzazioni.
