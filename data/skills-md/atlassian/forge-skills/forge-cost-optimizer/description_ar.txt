يعمل على تحسين تطبيقات Atlassian Forge لتقليل استهلاك النظام الأساسي وتجنب التكاليف غير الضرورية باستخدام إرشادات "تكاليف النظام الأساسي Optimise Forge" الخاصة بـ Atlassian. يُستخدم عندما يطلب المستخدم تحسين تكاليف تطبيق Forge، أو تقليل استدعاءات Forge، أو تقليل غيغابايت من الثواني، أو تقليل التخزين أو استخدام السجل، أو ضبط الذاكرة، أو استبدال الاستقصاء، أو تحسين المشغلات المجدولة، أو تقليل عمليات كتابة KVS، أو نقل العمل إلى الواجهة الأمامية، أو استخدام واجهات برمجة التطبيقات الجسرية، أو استدعاءات API المجمعة، أو إضافة التخزين المؤقت، أو تقييم مقايضات Forge Remote. بشكل افتراضي، قم بإجراء التدقيق أولاً واعرض إجراء التغييرات الموصى بها بعد تقديم التدقيق. قم بتعديل الملفات على الفور فقط عندما يطلب المستخدم صراحةً من الوكيل تنفيذ التحسينات أو تطبيقها.
