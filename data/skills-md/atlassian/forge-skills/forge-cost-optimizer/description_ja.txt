Atlassian の「Forge プラットフォーム コストの最適化」ガイダンスを使用して、Atlassian Forge アプリを最適化し、プラットフォームの消費量を削減し、不必要なコストを回避します。ユーザーが、Forge アプリのコストの最適化、Forge 呼び出しの削減、GB 秒の削減、ストレージまたはログの使用量の削減、メモリの調整、ポーリングの置き換え、スケジュールされたトリガーの改善、KVS 書き込みの削減、フロントエンドへの作業の移動、ブリッジ API の使用、バッチ API 呼び出し、キャッシュの追加、または Forge Remote のトレードオフの評価を要求する場合に使用します。デフォルトでは、最初に監査を実行し、監査の提示後に推奨される変更を加えるように提案します。ユーザーがエージェントに最適化の実装または適用を明示的に要求した場合にのみ、ただちにファイルを変更してください。
