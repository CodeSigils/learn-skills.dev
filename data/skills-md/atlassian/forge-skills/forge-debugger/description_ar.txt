تشخيص وإصلاح المشكلات في تطبيقات Atlassian Forge. استخدم هذه المهارة عندما يكون لدى تطبيق Forge أخطاء، أو يتعطل، أو يظهر واجهة مستخدم فارغة، أو يفشل في النشر، أو لا يظهر بعد التثبيت، أو به مشكلات في الأذونات، أو ينتج مخرجات غير متوقعة. قم بتشغيل أي ذكر لسجلات التزوير، أو أخطاء نشر التزوير، أو أخطاء المحلل، أو اللوحات الفارغة، أو النطاقات المفقودة، أو عدم عرض واجهة المستخدم المخصصة، أو تناقضات الإنتاج مقابل التطوير، أو أي تطبيق Jira/Confluence "توقف عن العمل". يتم التشغيل أيضًا عندما يطلب المستخدم تصحيح مشكلة في تطبيق Forge أو استكشاف الأخطاء وإصلاحها أو التحقيق فيها أو إصلاحها - حتى لو لم يستخدموا كلمة "Forge" ولكنهم يصفون لوحة Jira أو وحدة ماكرو Confluence التي تعمل.
