Guías para crear e implementar aplicaciones de conector Atlassian Forge Teamwork Graph que incorporan datos externos en Teamwork Graph de Atlassian, lo que permite buscarlos en Rovo Search y aparecer en Rovo Chat. Úselo cuando el usuario desee crear un conector Forge, ingerir datos externos en Atlassian, conectar una herramienta de terceros (por ejemplo, Google Drive, ServiceNow, Salesforce) a Atlassian, hacer que se pueda buscar contenido externo en Rovo, crear un módulo gráfico: conector, usar el SDK @forge/teamwork-graph o implementar funciones onConnectionChange/validateConnection.
