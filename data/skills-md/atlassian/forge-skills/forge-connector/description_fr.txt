Guide la création et le déploiement d'applications de connecteur Atlassian Forge Teamwork Graph qui ingèrent des données externes dans Teamwork Graph d'Atlassian, les rendant consultables dans Rovo Search et apparaissant dans Rovo Chat. À utiliser lorsque l'utilisateur souhaite créer un connecteur Forge, ingérer des données externes dans Atlassian, connecter un outil tiers (par exemple Google Drive, ServiceNow, Salesforce) à Atlassian, rendre le contenu externe consultable dans Rovo, créer un module graph:connector, utiliser le SDK @forge/teamwork-graph ou implémenter les fonctions onConnectionChange / validateConnection.
