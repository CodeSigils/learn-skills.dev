Atlassian Forge アプリの構築、デプロイ、トラブルシューティング、インストールのガイド — Forge CLI で構築されたカスタム拡張機能 (forge create、forgedeploy、forge install)。ユーザーが Forge アプリ (問題パネル、ダッシュボード ガジェット、Confluence マクロ、グローバル ページ) を作成したい場合、Forge CLI エラーやデプロイメントの問題 (例: Forge インストールの失敗、環境エラー) が発生した場合、またはリゾルバー、UI キット、マニフェスト スコープ、開発者スペースなどの Forge 固有の概念に関するヘルプが必要な場合に使用します。一般的な Jira 構成、自動化ルール、JQL クエリ、または Forge アプリ コンテキスト外の Atlassian REST API の使用には使用しないでください。
