Руководства по созданию, развертыванию, устранению неполадок и установке приложений Atlassian Forge — пользовательских расширений, созданных с помощью Forge CLI (создание forge, развертывание forge, установка forge). Используйте, когда пользователь хочет создать приложение Forge (панели задач, гаджеты информационной панели, макросы Confluence, глобальные страницы), сталкивается с ошибками CLI или проблемами развертывания Forge (например, сбои установки Forge, ошибки среды) или нуждается в помощи по специфичным для Forge концепциям, таким как преобразователи, набор пользовательского интерфейса, области манифеста или пространства разработчика. Не используйте для общей конфигурации Jira, правил автоматизации, запросов JQL или использования Atlassian REST API вне контекста приложения Forge.
