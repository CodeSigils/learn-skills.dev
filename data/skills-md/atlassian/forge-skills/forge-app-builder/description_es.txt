Guías para crear, implementar, solucionar problemas e instalar aplicaciones de Atlassian Forge: extensiones personalizadas creadas con la CLI de Forge (creación de forge, implementación de forge, instalación de forge). Úselo cuando el usuario quiera crear una aplicación de Forge (paneles de problemas, gadgets de panel, macros de Confluence, páginas globales), encuentre errores de CLI de Forge o problemas de implementación (por ejemplo, fallas de instalación de Forge, errores de entorno) o necesite ayuda con conceptos específicos de Forge como solucionadores, kit de interfaz de usuario, alcances de manifiesto o espacios de desarrollador. No lo use para la configuración general de Jira, reglas de automatización, consultas JQL o uso de la API REST de Atlassian fuera del contexto de una aplicación Forge.
