أدلة إنشاء تطبيقات Atlassian Forge ونشرها واستكشاف الأخطاء وإصلاحها وتثبيتها - ملحقات مخصصة تم إنشاؤها باستخدام Forge CLI (إنشاء إنشاء، نشر، تثبيت، تثبيت). يُستخدم عندما يريد المستخدم إنشاء تطبيق Forge (لوحات المشاكل، أدوات لوحة المعلومات، وحدات ماكرو Confluence، الصفحات العامة)، أو عندما يواجه أخطاء Forge CLI أو مشكلات النشر (على سبيل المثال، فشل تثبيت Forge، أو أخطاء البيئة)، أو يحتاج إلى مساعدة في مفاهيم خاصة بـ Forge مثل أدوات الحل، أو مجموعة أدوات واجهة المستخدم، أو نطاقات البيان، أو مساحات المطورين. لا تستخدمه لتكوين Jira العام، أو قواعد التشغيل الآلي، أو استعلامات JQL، أو استخدام Atlassian REST API خارج سياق تطبيق Forge.
