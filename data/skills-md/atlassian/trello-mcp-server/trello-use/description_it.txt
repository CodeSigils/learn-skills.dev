**Prerequisito OBBLIGATORIO**: caricalo PRIMA di chiamare qualsiasi strumento MCP Trello (`trelloRead*`, `trelloWrite*`, `trelloSearch`). Copre il formato ID ARI richiesto da ogni strumento e le regole trasversali (ricerca dell'utente corrente, gestione della data UTC, posta in arrivo e schede, creazione ordinata, impaginazione). Saltarlo causa errori di ID non valido e risultati errati di data di scadenza/fuso orario.
