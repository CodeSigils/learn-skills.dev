Bypass automatico per i siti Web bloccati: prova tutti i metodi finché non ne funziona uno. Da utilizzare quando WebFetch restituisce 402/403/blocked o quando si accede a X/Twitter, Reddit, YouTube, GitHub, Mastodon, Medium, Substack, Stack Overflow, Threads, Naver, Coupang, LinkedIn o qualsiasi piattaforma con protezione WAF/bot. Sfrutta yt-dlp (1.858 siti multimediali), Jina Reader, API pubbliche (HN, Bluesky, arXiv) e una catena di recupero generica basata sul profilo WAF (imitazione TLS curl_cffi, trasformazioni URL mobili, Playwright real-Chrome) con installazione automatica delle dipendenze.
