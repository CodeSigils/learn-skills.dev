Автоматический обход заблокированных веб-сайтов — пробует каждый метод, пока один не сработает. Используйте, когда WebFetch возвращает 402/403/заблокировано или при доступе к X/Twitter, Reddit, YouTube, GitHub, Mastodon, Medium, Substack, Stack Overflow, Threads, Naver, Coupang, LinkedIn или любой платформе с защитой WAF/ботов. Использует yt-dlp (1858 медиа-сайтов), Jina Reader, общедоступные API (HN, Bluesky, arXiv) и общую цепочку выборки на основе профиля WAF (олицетворение TLS curl_cffi, преобразование мобильных URL-адресов, Playwright Real-Chrome) с автоматической установкой зависимостей. Корейские триггеры: 트위터/X 못 열어, 레딧 안 읽혀, 유튜브 자막 뽑아줘, 깃헙 검색, 사이트 차단됨, 스레드 안 열려, 마스토돈, 미디엄, 서브스택, 스택오버플로우, 네이버 블로그, 디시인사이드, 에펨코리아, 요즘IT, 긱뉴스, 클리앙, 쿠팡, 링크드인, 당근마켓. Триггеры на английском языке: доступ к Твиттеру, блокировка Reddit, субтитры на YouTube, поиск на GitHub, документы arxiv, темы, mastodon, medium, substack, stackoverflow, блог Naver, dcinside, fmkorea, coupang, linkedin, yozm,ishket. НЕ запускайте простой поиск в Интернете, который WebSearch может обрабатывать напрямую.
