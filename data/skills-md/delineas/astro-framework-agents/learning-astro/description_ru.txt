Загружается автоматически, когда пользователь просит изучить разработку платформы Astro (например, «научите меня создавать с помощью Astro», «проведите меня через Astro», «Я хочу изучить Astro», «quiero aprender Astro», «как мне начать работу с Astro»). Интерактивное руководство, в котором Клод выступает в роли второго пилота, шаг за шагом помогая пользователю создать настоящий личный блог с помощью Astro. Активируйте этот навык всякий раз, когда пользователь выражает интерес к изучению Astro с нуля, даже если он явно не говорит «учебник».
