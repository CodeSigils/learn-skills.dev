Kamae (構え) – conception TypeScript robuste côté serveur. Modélisation de domaine fonctionnel avec
unions discriminées, transitions d'état pur, types de résultats, limites validées par schéma,
et protection des informations personnelles.

DÉCLENCHEUR lorsque : l'écriture de modèles de domaine TypeScript, de cas d'utilisation, de référentiels, de transitions d'état,
gestion des erreurs, validation des limites ou gestion des informations personnelles côté serveur ; concevoir des types
pour la logique métier ; implémentant la sémantique entité/valeur-objet dans TS.
SKIP : composants frontend React/Vue, code du navigateur, outils de construction, scripts de génération de code,
infrastructure pure en tant que code ; code sans rapport avec la logique du domaine.
