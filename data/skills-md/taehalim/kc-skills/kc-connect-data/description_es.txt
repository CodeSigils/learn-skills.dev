Diseñe y conecte las estructuras de datos permanentes y las operaciones seguras de lectura/escritura necesarias para el flujo central del proyecto actual. Se utiliza para solicitudes en las que los datos deben persistir durante las ejecuciones, como "almacenar los datos", "conectarse a la base de datos", "conectarse a Supabase", "Quiero ver el historial de la aplicación". No se utiliza para solicitudes que solo requieren datos estáticos, temporales o virtuales.
