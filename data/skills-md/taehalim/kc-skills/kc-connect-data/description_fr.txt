Concevez et connectez les structures de données permanentes et les opérations de lecture/écriture sécurisées nécessaires au flux principal du projet en cours. Il est utilisé pour les requêtes où les données doivent persister au fil des exécutions, telles que « stocker les données », « se connecter à la base de données », « se connecter à Supabase », « Je souhaite afficher l'historique de l'application ». Il n'est pas utilisé pour les requêtes qui nécessitent uniquement des données statiques, temporaires ou virtuelles.
