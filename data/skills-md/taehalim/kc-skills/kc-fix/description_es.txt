Según las acciones del usuario, el resultado real y el resultado deseado, reproduzca el problema del proyecto actual y solucione su causa. Se utiliza para solicitudes que corrigen comportamientos que difieren de las expectativas, como "Hice A pero obtuve B", "Ocurre un error", "Funciona localmente pero no cuando se implementa", "No se guardan los datos", "Solucionarlo". No se utiliza para solicitudes que sólo vuelven a un estado anterior sin solucionar la causa.
