تنفيذ المتطلبات المؤكدة للمشروع الحالي في الميزات والشاشات والسلوك الفعلي وإجراء الاختبارات الأساسية المناسبة لنطاق التنفيذ. يتم استخدامه لطلبات إنشاء أو تعديل التعليمات البرمجية مثل "تقديم خدمة"، أو "مواصلة التطوير"، أو "تنفيذ الميزة التالية"، أو "إكمالها وفقًا لهذه المادة". ولا يتم استخدامه عند طلب تعريف اتجاه المنتج أو إنشاء بيانات نموذجية أو اتصال دائم بالبيانات أو إصلاح المشكلات الموجودة أو التحقق أو النشر فقط.
