يقوم بتنفيذ المتطلبات المؤكدة للمشروع الحالي مثل الوظائف والشاشات والسلوك الفعلي، ويقوم بإجراء الاختبارات الأساسية المناسبة لنطاق التنفيذ. يتم استخدامه لطلبات إنشاء أو تعديل التعليمات البرمجية، مثل "إنشاء خدمة"، أو "مواصلة التطوير"، أو "تنفيذ الميزة التالية"، أو "إكمالها وفقًا لهذه المادة". ولا يتم استخدامه عندما يكون الطلب مخصصًا فقط لتحديد اتجاه المنتج، أو إنشاء بيانات نموذجية، أو توصيل البيانات الدائمة، أو إصلاح المشكلات الموجودة، أو التحقق، أو النشر.
