Implementa los requisitos verificados del proyecto actual como funciones, pantallas y comportamientos reales, y realiza pruebas básicas apropiadas para el alcance de la implementación. Se utiliza para solicitudes que implican la creación o modificación de código, como "crear un servicio", "seguir desarrollando", "implementar la siguiente característica" o "completarlo de acuerdo con este material". No se utiliza cuando la solicitud es solo para definir la dirección del producto, generar datos de muestra, conectar datos permanentes, solucionar problemas existentes, validación o implementación.
