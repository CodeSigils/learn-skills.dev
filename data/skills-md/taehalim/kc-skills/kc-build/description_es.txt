Implementa los requisitos confirmados del proyecto actual como funciones, pantallas y comportamiento reales, y realiza pruebas básicas apropiadas para el alcance de la implementación. Se utiliza para solicitudes para crear o modificar código, como "crear un servicio", "seguir desarrollando", "implementar la siguiente característica" o "completarlo de acuerdo con este material". No se utiliza cuando la solicitud es solo para definir la dirección del producto, generar datos de muestra, conectar datos permanentes, solucionar problemas existentes, verificación o implementación.
