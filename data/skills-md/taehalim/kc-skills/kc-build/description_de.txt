Implementiert die bestätigten Anforderungen des aktuellen Projekts in tatsächliche Funktionen, Bildschirme und Verhalten und führt grundlegende Tests im Rahmen der Implementierung durch. Es wird für Anfragen verwendet, die das Erstellen oder Ändern von Code beinhalten, z. B. „Erstellen Sie einen Dienst für mich“, „Entwickeln Sie weiter“, „Implementieren Sie die nächste Funktion“ oder „Beenden Sie gemäß diesem Material“. Es wird nicht verwendet, wenn die Anfrage nur der Definition der Produktrichtung, der Generierung von Beispieldaten, der Verbindung permanenter Daten, der Behebung bestehender Probleme, der Validierung oder der Bereitstellung dient.
