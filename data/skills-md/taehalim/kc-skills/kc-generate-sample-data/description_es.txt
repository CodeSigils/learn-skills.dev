Genere datos de muestra virtuales seguros y consistentes que se ajusten al esquema y las reglas comerciales del proyecto actual. Se utiliza para solicitudes que requieren verificar pantallas, flujos o pruebas sin datos reales, como "crear datos ficticios", "completar datos de prueba" o "crear un caso de demostración". No se utiliza para solicitudes que impliquen modificar información personal real o datos confidenciales de la empresa, ni para el uso de datos operativos.
