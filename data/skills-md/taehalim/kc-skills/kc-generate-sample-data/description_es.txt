Genere datos de muestra virtuales seguros y consistentes que se ajusten al esquema y las reglas comerciales del proyecto actual. Se utiliza para solicitudes como "crear datos ficticios", "completar datos de prueba" o "crear un caso de demostración", donde es necesario verificar pantallas, flujos y pruebas sin datos reales. No se utiliza para solicitudes que impliquen transformar información personal real o datos confidenciales de la empresa, ni utilizar datos operativos.
