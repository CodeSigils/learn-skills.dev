Efectivamente, prepare el repositorio Git para un nuevo proyecto, junto con AGENTS.md, CLAUDE.md y la confirmación inicial en una carpeta vacía. Úselo para solicitudes como "Configurar el proyecto por mí", "Crear un nuevo proyecto", "Preparar un nuevo espacio de trabajo del proyecto" o "Inicializar esta carpeta vacía". No lo utilice en carpetas que ya contengan código o configuración del proyecto.
