En effet, il prépare le référentiel Git, AGENTS.md, CLAUDE.md et le commit initial d'un nouveau projet dans un dossier vide. Il est utilisé pour des requêtes telles que « Configurer le projet pour moi », « Créer un nouveau projet », « Préparer le nouvel environnement de travail du projet » ou « Initialiser ce dossier vide ». Il n'est pas utilisé pour les dossiers contenant déjà du code ou des paramètres de projet.
