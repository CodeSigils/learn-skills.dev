Úselo cuando configure o inicie un proyecto y desee instalar la pila de habilidades óptima para ello. Activadores de frases como: "configurar habilidades para este proyecto", "instalar habilidades del proyecto", "qué habilidades debo usar", "configuración de ingeniero de energía", "configurar mi conjunto de habilidades" o cualquier solicitud para configurar habilidades de Claude Code para un proyecto nuevo o existente. Hace 8 preguntas sobre el tipo de proyecto, la pila, las necesidades de diseño, los documentos, la nube y la fase; luego genera un archivo install-skills.sh y un archivo PLUGIN_INSTALLS.md listos para ejecutar.
