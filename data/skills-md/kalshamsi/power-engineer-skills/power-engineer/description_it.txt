Da utilizzare quando si imposta o si avvia un progetto e si desidera installare lo stack di competenze ottimale per esso. Si attiva su frasi come: "imposta le competenze per questo progetto", "installa le competenze del progetto", "quali competenze dovrei utilizzare", "configura il tecnico energetico", "configura il mio stack di competenze" o qualsiasi richiesta di impostare le competenze del Codice Claude per un progetto nuovo o esistente. Pone 8 domande su tipo di progetto, stack, esigenze di progettazione, documenti, cloud e fase, quindi genera un file install-skills.sh pronto per l'esecuzione e un file PLUGIN_INSTALLS.md.
