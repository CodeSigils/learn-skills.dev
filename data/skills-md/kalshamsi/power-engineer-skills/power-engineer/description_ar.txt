استخدمه عند إعداد مشروع أو بدء تشغيله وتريد تثبيت مجموعة المهارات المثالية له. تشغيل عبارات مثل: "إعداد المهارات لهذا المشروع"، أو "تثبيت مهارات المشروع"، أو "ما المهارات التي يجب أن أستخدمها"، أو "إعداد مهندس الطاقة"، أو "تكوين مجموعة المهارات الخاصة بي"، أو أي طلب لإعداد مهارات Claude Code لمشروع جديد أو حالي. يطرح 8 أسئلة حول نوع المشروع والمكدس واحتياجات التصميم والمستندات والسحابة والمرحلة - ثم يقوم بإنشاء ملف تثبيت جاهز للتشغيل وملف PLUGIN_INSTALLS.md.
