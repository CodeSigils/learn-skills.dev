À utiliser lors de la configuration ou du démarrage d'un projet et que vous souhaitez installer la pile de compétences optimale pour celui-ci. Se déclenche sur des phrases telles que : « configurer des compétences pour ce projet », « installer des compétences de projet », « quelles compétences dois-je utiliser », « configuration d'ingénieur électricien », « configurer ma pile de compétences » ou toute demande de configuration de compétences Claude Code pour un projet nouveau ou existant. Pose 8 questions sur le type de projet, la pile, les besoins de conception, les documents, le cloud et la phase, puis génère un fichier install-skills.sh prêt à l'emploi et un fichier PLUGIN_INSTALLS.md.
