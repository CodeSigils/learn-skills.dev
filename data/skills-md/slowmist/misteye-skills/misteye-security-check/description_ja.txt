MistEyeのセキュリティゲートスキルです。これは、特に「このアドレス/Web サイトを見てください」などの一般的なリクエストに対して、インストール前のリスク チェック (スキル/MCP 依存関係マニフェストを含む)、ドメインまたは URL のアクセス前セキュリティ チェック、IoC の悪意のある検出、サプライ チェーンのリスク ブロックによってトリガーされます。 「https://app-api.misteye.io/functions/v1/detect」を使用する必要があります。依存関係および外部リンクのシナリオでは、これが最も高い優先度を持ちます。 API が `safe=false` または任意の `matches` を返した場合、アクションはブロックされ、明示的に「ブロックされた」と報告される必要があります。最初のインストールが完了した後でのみ、OpenClaw または Hermes を使用して毎日のパトロールを有効にできることをユーザーに通知する必要があります (デフォルトは 1 日 1 回)。
