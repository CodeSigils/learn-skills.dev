Esta es la habilidad de la puerta de seguridad de MistEye. Se activa mediante comprobaciones de riesgos previas a la instalación (incluidos los manifiestos de dependencia de Skill/MCP), comprobaciones de seguridad previas al acceso para dominios o URL, detección de IoC maliciosos y bloqueo de riesgos de la cadena de suministro, especialmente para solicitudes comunes como "eche un vistazo a esta dirección/sitio web". Debe utilizar `https://app-api.misteye.io/functions/v1/detect`; en escenarios de dependencia y vínculos externos tiene la máxima prioridad. Si la API devuelve `safe=false` o cualquier `coincidencia`, la acción debe bloquearse e informarse explícitamente como "bloqueada". Solo después de completar la primera instalación se le debe recordar al usuario que se pueden habilitar patrullas diarias con OpenClaw o Hermes (predeterminado una vez al día).
