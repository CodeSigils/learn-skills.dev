Generador general de sistemas multisubagente. Construye rápidamente sistemas multiagente para cualquier negocio basados ​​en un modelo de interacción maestro-subordinado. Analiza procesos de negocio, recomienda tipos de agentes y genera plantillas de avisos. Casos de uso: (1) Se activa cuando el usuario dice "crear un sistema de múltiples subagentes" o "construir un sistema de múltiples agentes"; (2) Flujos de trabajo automatizados que requieren una arquitectura maestro-subordinado; (3) Escenarios como canalizaciones de procesamiento de datos, generación de contenido, revisión de código, etc.; (4) Necesidad de orquestar múltiples subtareas en paralelo o secuencialmente.
