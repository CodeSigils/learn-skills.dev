Costruttore di sistemi multi-agente universale. Crea rapidamente sistemi multi-agente per qualsiasi azienda in base al modello di interazione master-subordinato. Analizza i flussi di lavoro aziendali, consiglia i tipi di agenti e genera modelli di prompt. Casi d'uso: (1) Attivato quando l'utente dice "Crea un sistema multi-agente" o "Costruisci un sistema multi-agente" (2) Flussi di lavoro automatizzati che richiedono un'architettura master-subordinata (3) Pipeline di elaborazione dati, generazione di contenuti, revisione del codice e scenari simili (4) Orchestrazione parallela/sequenziale di più attività secondarie
