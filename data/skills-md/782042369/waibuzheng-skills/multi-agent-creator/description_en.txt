General Multi-Sub-Agent System Builder. Quickly constructs multi-agent systems for any business based on a master‑subordinate interaction model. Analyzes business processes, recommends agent types, and generates prompt templates. Use cases: (1) Triggered when the user says “create a multi-sub-agent system” or “build a multi-agent system”; (2) Automated workflows that require a master‑subordinate architecture; (3) Scenarios such as data processing pipelines, content generation, code review, etc.; (4) Need to orchestrate multiple sub‑tasks in parallel or sequentially.
