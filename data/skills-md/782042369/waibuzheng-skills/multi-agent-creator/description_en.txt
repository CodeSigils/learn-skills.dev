Universal multi-agent system builder. Quickly construct multi-agent systems for any business based on a master‑slave interaction model. Analyzes business processes, recommends agent types, generates prompt templates. Use cases: (1) Triggered when the user says "create a multi-agent system" or "build a multi-agent system"; (2) Automated processes that require a master‑slave architecture; (3) Scenarios such as data processing pipelines, content generation, code review, etc.; (4) Need to orchestrate multiple sub‑tasks in parallel or sequentially.
