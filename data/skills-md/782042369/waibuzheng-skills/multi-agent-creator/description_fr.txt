Générateur de systèmes multi-sous-agents général. Construit rapidement des systèmes multi-agents pour toute entreprise sur la base d'un modèle d'interaction maître-subordonné. Analyse les processus métier, recommande des types d'agents et génère des modèles d'invite. Cas d'utilisation : (1) Déclenché lorsque l'utilisateur dit « créer un système multi-sous-agents » ou « construire un système multi-agents » ; (2) Flux de travail automatisés nécessitant une architecture maître-subordonné ; (3) Scénarios tels que les pipelines de traitement de données, la génération de contenu, la révision de code, etc. ; (4) Nécessité d'orchestrer plusieurs sous-tâches en parallèle ou séquentiellement.
