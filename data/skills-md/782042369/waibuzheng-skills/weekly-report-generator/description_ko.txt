Git 커밋 기록에서 전문적인 주간 작업 보고서를 생성합니다. 단일 주 또는 다중 주 배치 생성, 여러 프로젝트 집계 및 사용자 정의 템플릿(Markdown/Word)을 지원합니다. 기술 용어를 비즈니스 언어로 자동 변환하고 다음 주 계획, 이번 주 요약, 문제 및 위험에 대한 섹션을 추가합니다. 사용 사례: (1) Git 로그에서 이번 주의 작업 보고서 생성 (2) 여러 프로젝트의 커밋 기록을 하나의 주간 보고서로 통합합니다. (3) 사용자 정의 Word 템플릿을 기반으로 리더십에 필요한 형식을 생성합니다. (4) 한 달 또는 여러 주에 대한 주간 보고서를 일괄 생성합니다.
