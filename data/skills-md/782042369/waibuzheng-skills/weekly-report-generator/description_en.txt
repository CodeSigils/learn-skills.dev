Generate professional weekly work reports from Git commit records. Support single‑week or multi‑week batch generation, multi‑project aggregation, and custom templates (Markdown/Word). Automatically convert technical terms into business language, and add sections for next‑week plans, this‑week summary, and issues and risks. Use cases: (1) Generate this week’s work report from Git logs (2) Consolidate commit records from multiple projects into one weekly report (3) Produce a leader‑required format based on a custom Word template (4) Batch‑generate weekly reports for a month or multiple weeks.
