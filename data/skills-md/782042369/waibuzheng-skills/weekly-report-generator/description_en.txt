Generate professional weekly work reports from Git commit records. Supports single-week or multi-week batch generation, aggregation of multiple projects, and custom templates (Markdown/Word). Automatically converts technical terms into business language and adds sections for next week's plan, this week's summary, and issues and risks. Use cases: (1) Generate this week's work report from Git logs (2) Consolidate commit records from multiple projects into one weekly report (3) Produce a leadership-required format based on a custom Word template (4) Batch-generate weekly reports for a month or multiple weeks.
