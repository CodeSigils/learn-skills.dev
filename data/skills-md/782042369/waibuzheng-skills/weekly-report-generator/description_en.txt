Generate professional weekly work reports from Git commits. Supports single/batch generation for multiple weeks, multi-project aggregation, and custom templates (Markdown/Word). Automatically translates technical terms into business language and adds sections for next week’s plan, this week’s summary, issues, and risks. Use cases: (1) Generate this week’s work report from Git logs (2) Combine commit records from multiple projects into one weekly report (3) Create reports in the format required by management based on custom Word templates (4) Batch generate weekly reports for a month or multiple weeks
