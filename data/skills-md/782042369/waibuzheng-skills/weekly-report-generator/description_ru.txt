Создавайте профессиональные еженедельные отчеты о работе на основе коммитов Git. Поддерживает однократное/пакетное создание на несколько недель, агрегацию нескольких проектов и пользовательские шаблоны (Markdown/Word). Автоматически переводит технические термины на деловой язык и добавляет разделы для плана на следующую неделю, итогов этой недели, проблем и рисков. Варианты использования: (1) Создание отчета о работе за эту неделю из журналов Git (2) Объединение записей коммитов из нескольких проектов в один еженедельный отчет (3) Создание отчетов в формате, требуемом руководством, на основе пользовательских шаблонов Word (4) Пакетное создание еженедельных отчетов за месяц или несколько недель.
