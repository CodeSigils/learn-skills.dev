Создавайте профессиональные еженедельные отчеты о работе на основе записей коммитов Git. Поддерживает создание пакетов на одну или несколько недель, агрегацию нескольких проектов и пользовательские шаблоны (Markdown/Word). Автоматически преобразует технические термины в деловой язык и добавляет разделы для плана на следующую неделю, итогов этой недели, а также проблем и рисков. Варианты использования: (1) Создание отчета о работе за эту неделю из журналов Git (2) Объединение записей коммитов из нескольких проектов в один еженедельный отчет (3) Создание необходимого для руководства формата на основе пользовательского шаблона Word (4) Пакетное создание еженедельных отчетов за месяц или несколько недель.
