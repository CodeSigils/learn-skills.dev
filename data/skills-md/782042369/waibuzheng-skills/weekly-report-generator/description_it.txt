Genera report di lavoro settimanali professionali dai record di commit Git. Supporta la generazione batch di una o più settimane, l'aggregazione di più progetti e modelli personalizzati (Markdown/Word). Converti automaticamente i termini tecnici nel linguaggio aziendale e aggiungi sezioni per i piani della prossima settimana, il riepilogo di questa settimana e problemi e rischi. Casi d'uso: (1) Genera il report di lavoro di questa settimana dai log Git (2) Consolida i record di commit di più progetti in un report settimanale (3) Produci un formato richiesto dal leader basato su un modello Word personalizzato (4) Genera in batch report settimanali per un mese o più settimane.
