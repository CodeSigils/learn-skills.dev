Genera report di lavoro settimanali professionali dai commit Git. Supporta la generazione singola/batch per più settimane, aggregazione di più progetti e modelli personalizzati (Markdown/Word). Traduce automaticamente i termini tecnici nel linguaggio aziendale e aggiunge sezioni per il piano della prossima settimana, il riepilogo, i problemi e i rischi di questa settimana. Casi d'uso: (1) Generare il report di lavoro di questa settimana dai log Git (2) Combinare record di commit di più progetti in un report settimanale (3) Creare report nel formato richiesto dal management in base a modelli Word personalizzati (4) Generare in batch report settimanali per un mese o più settimane
