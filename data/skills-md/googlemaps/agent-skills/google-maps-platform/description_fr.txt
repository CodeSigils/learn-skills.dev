Un ensemble de compétences pour concevoir et mettre en œuvre du code prêt à la production à l'aide des API et des SDK de Google Maps Platform pour toute carte, lieu, adresse, géocodage, routage/ETA (y compris le routage respectueux de l'environnement), recherche à proximité, 3D/Street View/carte statique, regroupement de marqueurs, style personnalisé, dessin, géorepérage, carte thermique ou fonctionnalité environnementale (qualité de l'air/pollen/solaire/météo) — sur les API Web, Android, iOS et de services Web. Pour le prototypage, utilisez la clé de démonstration publique Maps : aucune configuration de facturation ni projet Cloud requis, couvrant un ensemble croissant d'API Google Maps Platform les plus populaires. Pour la production, la compétence vous invite à créer et à restreindre votre propre clé. Tout le code non trivial est basé sur des documents fraîchement récupérés via le service Google Maps Platform Code Assist (aucune dépendance à l'égard de la mémoire des données d'entraînement).
