مجموعة من المهارات لتصميم التعليمات البرمجية الجاهزة للإنتاج وتنفيذها باستخدام Google Maps Platform APIs وSDKs لأي خريطة أو مكان أو عنوان أو ترميز جغرافي أو توجيه/ETA (بما في ذلك التوجيه الصديق للبيئة)، أو بحث قريب، أو عرض ثلاثي الأبعاد / Street View / خريطة ثابتة، أو تجميع العلامات، أو التصميم المخصص، أو الرسم، أو تحديد الموقع الجغرافي، أو خريطة الحرارة، أو الميزة البيئية (جودة الهواء / حبوب اللقاح / الطاقة الشمسية / الطقس) - عبر واجهات برمجة تطبيقات الويب، وAndroid، وiOS، وخدمات الويب. لإنشاء النماذج الأولية، استخدم المفتاح التجريبي للخرائط العام - لا يلزم إعداد الفوترة ولا يتطلب مشروع سحابي، مما يغطي مجموعة متزايدة من واجهات برمجة تطبيقات Google Maps Platform الأكثر شيوعًا. بالنسبة للإنتاج، تطالبك المهارة بإنشاء مفتاحك الخاص وتقييده. يتم إنشاء جميع التعليمات البرمجية غير التافهة في المستندات التي تم استردادها حديثًا عبر خدمة مساعدة التعليمات البرمجية لمنصة Google Maps (دون الاعتماد على ذاكرة بيانات التدريب).
