Набор навыков для разработки и реализации готового кода с использованием API и SDK платформы Google Maps для любой карты, места, адреса, геокодирования, маршрутизации/расчетного времени прибытия (включая экологически безопасный маршрут), поиска поблизости, 3D-просмотра улиц/статической карты, кластеризации маркеров, пользовательского стиля, рисования, геозонирования, тепловой карты или функции окружающей среды (качество воздуха/пыльцы/солнечная энергия/погода) — через API веб-сайтов, Android, iOS и веб-служб. Для создания прототипа используйте общедоступный демонстрационный ключ Карт – не требуется настройка платежных систем и облачный проект. Он охватывает растущий набор самых популярных API платформы Google Карт. Для производства навык предложит вам создать и ограничить свой собственный ключ. Весь нетривиальный код основан на недавно полученных документах через службу Code Assist платформы Google Maps (без использования памяти обучающих данных).
