Una colección de habilidades para diseñar e implementar código listo para producción utilizando las API y los SDK de Google Maps Platform para cualquier mapa, lugar, dirección, codificación geográfica, enrutamiento/ETA (incluidas las rutas ecológicas), búsqueda cercana, mapa 3D/Street View/estático, agrupación de marcadores, estilo personalizado, dibujo, geocercas, mapa de calor o función ambiental (calidad del aire/polen/solar/clima), en API web, Android, iOS y servicios web. Para crear prototipos, utilice la clave de demostración de Maps pública: no requiere configuración de facturación ni proyecto en la nube, y cubre un conjunto cada vez mayor de las API de Google Maps Platform más populares. Para producción, la habilidad le solicita que cree y restrinja su propia clave. Todo el código no trivial se basa en documentos recién recuperados a través del servicio Google Maps Platform Code Assist (no depende de la memoria de datos de entrenamiento).
