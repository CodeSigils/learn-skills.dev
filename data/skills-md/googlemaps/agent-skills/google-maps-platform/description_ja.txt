Web、Android、iOS、Web サービス API 全体で、Google Maps Platform API と SDK を使用して、あらゆる地図、場所、住所、ジオコーディング、ルート検索/ETA (環境に優しいルートを含む)、近隣検索、3D / ストリート ビュー / 静的地図、マーカー クラスタリング、カスタム スタイル、描画、ジオフェンシング、ヒートマップ、または環境 (大気質 / 花粉 / 太陽光 / 天気) 機能を対象とした、本番環境に対応したコードを構築および実装するためのスキルの集合体。プロトタイピングには、公開されている Maps Demo Key を使用します。請求設定やクラウド プロジェクトは不要で、ますます人気のある Google Maps Platform API のセットをカバーします。本番環境の場合、スキルは独自のキーを作成して制限するように求めます。すべての重要なコードは、Google Maps Platform Code Assist サービスを介して新たに取得したドキュメントに基づいています (トレーニング データ メモリには依存しません)。
