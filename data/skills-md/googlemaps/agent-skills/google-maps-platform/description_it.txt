Una raccolta di competenze per progettare e implementare codice pronto per la produzione utilizzando API e SDK di Google Maps Platform per qualsiasi mappa, luogo, indirizzo, geocodifica, routing/ETA (compreso il routing ecologico), ricerca nelle vicinanze, 3D/Street View/mappa statica, clustering di indicatori, stile personalizzato, disegno, geofencing, mappa termica o funzionalità ambientale (qualità dell'aria/polline/solare/meteo) su API Web, Android, iOS e servizi Web. Per la prototipazione, utilizza la chiave demo pubblica di Maps: non sono necessarie configurazioni di fatturazione né progetti cloud e copre un set crescente delle API di Google Maps Platform più popolari. Per la produzione, la competenza richiede di creare e limitare la propria chiave. Tutto il codice non banale si basa su documenti appena recuperati tramite il servizio Code Assist di Google Maps Platform (nessuna dipendenza dalla memoria dei dati di addestramento).
