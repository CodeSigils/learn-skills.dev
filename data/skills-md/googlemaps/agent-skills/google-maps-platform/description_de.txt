Eine Sammlung von Fähigkeiten zum Entwerfen und Implementieren von produktionsreifem Code mithilfe von APIs und SDKs der Google Maps Platform für jede Karte, jeden Ort, jede Adresse, Geokodierung, Routing/ETA (einschließlich umweltfreundlicher Routing), Suche in der Nähe, 3D/Street View/statische Karte, Marker-Clustering, benutzerdefiniertes Styling, Zeichnen, Geofencing, Heatmap oder Umweltfunktionen (Luftqualität/Pollen/Sonne/Wetter) – über Web-, Android-, iOS- und Webservices-APIs hinweg. Verwenden Sie für die Prototypenerstellung den öffentlichen Maps-Demoschlüssel – keine Abrechnungseinrichtung und kein Cloud-Projekt erforderlich, der eine wachsende Anzahl der beliebtesten Google Maps Platform-APIs abdeckt. Für die Produktion fordert Sie der Skill auf, Ihren eigenen Schlüssel zu erstellen und einzuschränken. Der gesamte nicht-triviale Code basiert auf neu abgerufenen Dokumenten über den Google Maps Platform Code Assist-Dienst (keine Abhängigkeit vom Trainingsdatenspeicher).
