Verfeinert rohe Ideen durch strukturiertes divergentes und konvergentes Denken in klare, umsetzbare Konzepte. Verwenden Sie diese Option, wenn eine Idee noch vage ist, wenn Sie Annahmen einem Stresstest unterziehen müssen, bevor Sie sich auf einen Plan festlegen, oder wenn Sie Optionen erweitern möchten, bevor Sie sich auf einen Plan einigen. Wird ausgelöst bei „Idee entwickeln“, „Diese Idee verfeinern“ oder „Meinen Plan einem Stresstest unterziehen“.
