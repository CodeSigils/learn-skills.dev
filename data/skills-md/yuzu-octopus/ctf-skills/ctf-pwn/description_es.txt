Proporciona técnicas de explotación binaria para desafíos CTF. Úselo cuando ya tenga un objetivo o servicio nativo vulnerable y necesite convertir la corrupción de la memoria o las primitivas de bajo nivel en ejecución de código o escalada de privilegios, como desbordamientos de búfer, cadenas de formato, errores de montón, ROP, ret2libc, shellcode, explotación del kernel, derivación de seccomp, escape de sandbox o cadenas de exploits de Windows/Linux. No lo use cuando el bloqueador principal esté entendiendo lo que hace el binario; Utilice primero la ingeniería inversa. No lo utilice exclusivamente para errores web, análisis forense de discos o paquetes, o desafíos criptográficos/matemáticos independientes.
