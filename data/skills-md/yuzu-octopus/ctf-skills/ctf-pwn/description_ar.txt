يوفر تقنيات استغلال ثنائية لتحديات CTF. يُستخدم عندما يكون لديك بالفعل هدف أو خدمة أصلية ضعيفة وتحتاج إلى تحويل تلف الذاكرة أو العناصر الأولية ذات المستوى المنخفض إلى تنفيذ التعليمات البرمجية أو تصعيد الامتيازات، مثل تجاوز سعة المخزن المؤقت، أو سلاسل التنسيق، أو أخطاء الكومة، أو ROP، أو ret2libc، أو كود القشرة، أو استغلال kernel، أو تجاوز seccomp، أو هروب وضع الحماية، أو سلاسل استغلال Windows/Linux. لا تستخدمه عندما يكون المانع الرئيسي يفهم ما يفعله الثنائي؛ استخدم الهندسة العكسية أولاً. لا تستخدمه في أخطاء الويب الخالصة، أو التحاليل الجنائية للأقراص أو الحزم، أو تحديات التشفير/الرياضيات المستقلة.
