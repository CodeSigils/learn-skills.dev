Используйте этот навык при добавлении программы чтения с экрана и навигации с помощью клавиатуры в приложения PixiJS v8. Охватывает параметры AccessibilitySystem (enabledByDefault, debug, activeOnTab, deactivateOnMouseMove), свойства доступности для каждого контейнера, наложение теневого DOM, мобильную активацию сенсорного крючка. Запускается по: специальным возможностям, a11y, программе чтения с экрана, ARIA, навигации с помощью клавиатуры, порядку вкладок, AccessibilitySystem,accessTitle,accessHint, tabIndex,accessibleChildren.
