Используйте этот навык при запуске PixiJS v8 вне стандартного браузера: Web Workers, OffscreenCanvas, Node/SSR или контексты с ограниченным доступом CSP. Охватывает DOMAdapter.set, BrowserAdapter, WebWorkerAdapter, пользовательский интерфейс адаптера, pixi.js/unsafe-eval для строгого CSP. Запускается по: DOMAdapter, BrowserAdapter, WebWorkerAdapter, Web Worker, OffscreenCanvas, Node, headless, SSR, CSP, unsafe-eval, Adaptor.
