Utilisez cette compétence lorsque vous dessinez des images dans PixiJS v8. Couvre Sprite avec ancre/teinte/texture, AnimatedSprite pour l'animation de cadre, NineSliceSprite pour les panneaux d'interface utilisateur redimensionnables, TilingSprite pour le défilement/répétition d'arrière-plans. Déclencheurs sur : Sprite, AnimatedSprite, NineSliceSprite, TilingSprite, Sprite.from, Anchor, Tint, TilePosition, animationSpeed, gotoAndPlay, leftWidth, topHeight, options du constructeur, SpriteOptions, AnimatedSpriteOptions, NineSliceSpriteOptions, TilingSpriteOptions.
