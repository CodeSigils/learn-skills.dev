Utilice esta habilidad al dibujar imágenes en PixiJS v8. Cubre Sprite con anclaje/tinte/textura, AnimatedSprite para animación de fotogramas, NineSliceSprite para paneles de interfaz de usuario redimensionables, TilingSprite para desplazamiento/repetición de fondos. Activadores de: Sprite, AnimatedSprite, NineSliceSprite, TilingSprite, Sprite.from, Anchor, Tint, TilePosition, AnimationSpeed, gotoAndPlay, leftWidth, topHeight, opciones de constructor, SpriteOptions, AnimatedSpriteOptions, NineSliceSpriteOptions, TilingSpriteOptions.
