Используйте этот навык при рисовании изображений в PixiJS v8. Охватывает Sprite привязкой/оттенком/текстурой, AnimatedSprite для кадровой анимации, NineSliceSprite для панелей пользовательского интерфейса с изменяемым размером, TilingSprite для прокрутки/повторения фона. Запускается по: Sprite, AnimatedSprite, NineSliceSprite, TilingSprite, Sprite.from, привязке, оттенку, tilePosition, анимацииSpeed, gotoAndPlay, leftWidth, topHeight, параметрам конструктора, SpriteOptions, AnimatedSpriteOptions, NineSliceSpriteOptions, TilingSpriteOptions.
