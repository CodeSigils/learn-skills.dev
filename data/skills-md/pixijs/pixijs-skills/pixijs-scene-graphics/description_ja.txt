PixiJS v8 でベクター シェイプとパスを描画する場合は、このスキルを使用します。グラフィックス API をカバーします: シェイプしてから塗りつぶすメソッド (rect/circle/ellipse/poly/roundRect/star/regulatoryPoly/roundPoly/roundShape/filletRect/chamferRect)、パス メソッド (moveTo/lineTo/bezierCurveTo/quadraticCurveTo/arc/arcTo/arcToSvg/closePath)、fill/stroking/cut、holes、FillGradient (リニア/ラジアル)、FillPattern、GraphicsContext 共有、SVG インポート/エクスポート、containsPoint ヒット テスト、クローン作成、クリア、境界、fillStyle/ストロークスタイル、描画時の変換 (rotateTransform/scaleTransform/translateTransform/setTransform/save/restore)、デフォルト スタイル、GraphicsPath の再利用。トリガー対象: Graphics、GraphicsContext、rect、circle、poly、roundRect、fill、stroke、cut、hole、beginHole、FillGradient、FillPattern、moveTo、bezierCurveTo、svg、graphicsContextToSvg、svg export、GraphicsOptions、containsPoint、clone、clear、bounds、rotateTransform、translateTransform、setFillStyle、setStrokeStyle、GraphicsPath。
