Используйте этот навык при рендеринге текста в PixiJS v8. Охватывает текст для меток в стиле холста, BitmapText для дешевых покадровых обновлений через атлас глифов, HTMLText для разметки HTML/CSS через SVG, SplitText и SplitBitmapText для посимвольной анимации, TextStyle, tagStyles, параметры конструктора, TextOptions, HTMLTextOptions, BitmapText, SplitTextOptions, SplitBitmapTextOptions. Запускается по: Text, BitmapText, HTMLText, SplitText, SplitBitmapText, TextStyle, HTMLTextStyle, BitmapFont.install, tagStyles, fontFamily, wordWrap.
