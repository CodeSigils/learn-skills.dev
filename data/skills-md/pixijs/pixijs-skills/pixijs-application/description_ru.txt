Используйте этот навык при создании и настройке приложения PixiJS v8. Охватывает новые параметры Application() + async app.init() (ширина, высота, фон, сглаживание, разрешение, autoDensity, предпочтение, resizeTo, autoStart,sharedTicker, холст, useBackBuffer, powerPreference, eventFeatures, accessibilityOptions, gcActive, bezierSmoothness, переопределения для каждого рендерера webgl/webgpu/canvasOptions), Доступ к app.stage/renderer/canvas/screen/domContainerRoot, ResizePlugin, TickerPlugin, CullerPlugin (cullable, cullArea), создание пользовательского плагина ApplicationPlugin через ExtensionType.Application, запуск/остановку жизненного цикла и app.destroy() с помощью ReleaseGlobalResources. Запускается по: Application, app.init, app.stage, app.renderer, app.canvas, app.screen, app.domContainerRoot, ApplicationOptions, ApplicationPlugin, ExtensionType.Application, resizeTo, Preference, autoStart, ShareTicker, useBackBuffer, PowerPreference, SkipExtensionImports, PreferWebGLVersion, PreserveDrawingBuffer, cullable, CullerPlugin, app.start, app.stop, app.destroy, ReleaseGlobalResources.
