Utilisez cette compétence lors du rendu d'une géométrie personnalisée dans PixiJS v8. Couvre le maillage avec MeshGeometry (positions, UV, indices, topologie), MeshSimple pour l'animation de sommet par image, MeshPlane pour la déformation subdivisée, MeshRope pour les textures de suivi de chemin, PerspectiveMesh pour les coins 2,5D. Déclencheurs sur : Mesh, MeshGeometry, MeshSimple, MeshPlane, MeshRope, PerspectiveMesh, positions, uvs, indices, topologie, setCorners, options du constructeur, MeshOptions, MeshPlaneOptions, MeshRopeOptions, SimpleMeshOptions, PerspectivePlaneOptions.
