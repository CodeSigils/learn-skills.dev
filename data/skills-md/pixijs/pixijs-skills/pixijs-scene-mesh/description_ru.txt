Используйте этот навык при рендеринге пользовательской геометрии в PixiJS v8. Охватывает сетку MeshGeometry (позиции, UV, индексы, топология), MeshSimple для покадровой анимации вершин, MeshPlane для разделенной деформации, MeshRope для текстур, следующих по пути, PerspectiveMesh для 2,5D углов. Срабатывает по: Mesh, MeshGeometry, MeshSimple, MeshPlane, MeshRope, PerspectiveMesh, позициям, uvs, индексам, топологии, setCorners, опциям конструктора, MeshOptions, MeshPlaneOptions, MeshRopeOptions, SimpleMeshOptions, PerspectivePlaneOptions.
