Используйте этот навык при создании нового проекта PixiJS v8 с помощью интерфейса командной строки create-pixi или при добавлении PixiJS в существующий проект. Охватывает команды создания npm/yarn/pnpm/bun, интерактивные и неинтерактивные потоки, категории шаблонов связывания и создания, доступные предустановки шаблонов (bundler-vite, Bundler-Webpack, Bundler-esbuild, Bundler-import-map, Creation-Web, Framework-React, Extension-default), Требования к версии Node, `npm install pixi.js` для существующих проектов, поток разработки после scaffold и Vite верхнего уровня-ожидание производственно-строительная ошибка. Запускается при: create pixi.js, npm create, npm install pixi.js, scaffold, шаблоне, Bundler-Vite, Bundler-WebPack, Creation-Web, Framework-React, новом проекте, существующем проекте, начале работы, быстром запуске.
