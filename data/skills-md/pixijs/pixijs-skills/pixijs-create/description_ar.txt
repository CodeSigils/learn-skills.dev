استخدم هذه المهارة عند دعم مشروع PixiJS v8 جديد باستخدام واجهة سطر الأوامر create-pixi أو إضافة PixiJS إلى مشروع حالي. يغطي أوامر إنشاء npm/yarn/pnpm/bun، والتدفقات التفاعلية مقابل غير التفاعلية، وفئات قوالب الإنشاء مقابل الحزم، والإعدادات المسبقة للقالب المتوفرة (bundler-vite، Bundler-webpack، Bundler-esbuild، Bundler-import-map، create-web، Framework-react، Extension-default)، ومتطلبات إصدار العقدة، و`npm install pixi.js` للمشاريع الحالية، وتدفق تطوير ما بعد السقالة، وVite المستوى الأعلى في انتظار إنتاج وبناء مسكتك. المشغلات على: إنشاء pixi.js، إنشاء npm، تثبيت npm pixi.js، سقالة، قالب، Bundler-vite، Bundler-webpack، create-web، Framework-react، مشروع جديد، مشروع حالي، البدء، بداية سريعة.
