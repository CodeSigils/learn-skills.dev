Utilisez cette compétence lors de l'échafaudage d'un nouveau projet PixiJS v8 avec la CLI create-pixi ou lors de l'ajout de PixiJS à un projet existant. Couvre les commandes de création npm/yarn/pnpm/bun, les flux interactifs et non interactifs, les catégories de modèles de bundler et de création, les préréglages de modèles disponibles (bundler-vite, bundler-webpack, bundler-esbuild, bundler-import-map, creation-web, framework-react, extension-default), les exigences de version de nœud, `npm install pixi.js` pour les projets existants, le flux de développement post-échafaudage et Vite un piège de production et de construction en attente de haut niveau. Déclencheurs sur : créer pixi.js, npm create, npm install pixi.js, échafaudage, modèle, bundler-vite, bundler-webpack, création-web, framework-react, nouveau projet, projet existant, mise en route, démarrage rapide.
