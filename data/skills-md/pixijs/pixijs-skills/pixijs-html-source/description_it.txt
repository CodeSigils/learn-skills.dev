Utilizza questa abilità durante il rendering di elementi HTML/DOM live (o di istantanee congelate di essi) come texture PixiJS v8 tramite le API del browser HTML-in-Canvas SPERIMENTALI. Copre l'importazione degli effetti collaterali pixi.js/html-source, il rilevamento delle funzionalità con canvas.requestPaint, HTMLSource per un elemento live e ridipinto mantenuto interattivo nel browser (autoLayout/autoUpdate/autoRequestPaint, requestPaint, isReady, il requisito direct-child-of-canvas + layoutsubtree), ElementImageSource per uno snapshot immutabile captureElementImage() (autoClose, pronto immediatamente), utilizzando la sorgente su uno Sprite/Texture/Mesh, rilevamento automatico solo fallback tramite Texture.from con priorità -10 e distruzione/pulizia. Si attiva su: HTMLSource, ElementImageSource, pixi.js/html-source, requestPaint, captureElementImage, ElementImage, layoutsubtree, autoRequestPaint, autoUpdate, autoClose, HTML in canvas, rendering DOM in texture, HTMLSourceOptions, ElementImageSourceOptions, HTMLSourceCanvas, sperimentale.
