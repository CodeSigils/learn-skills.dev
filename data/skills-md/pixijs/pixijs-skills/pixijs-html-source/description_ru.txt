Используйте этот навык при рендеринге живых элементов HTML/DOM (или их замороженных снимков) в виде текстур PixiJS v8 с помощью ЭКСПЕРИМЕНТАЛЬНЫХ API-интерфейсов браузера HTML-in-Canvas. Охватывает импорт побочных эффектов pixi.js/html-source, обнаружение функций с помощью Canvas.requestPaint, HTMLSource для живого перерисовываемого элемента, который остается интерактивным в браузере (autoLayout/autoUpdate/autoRequestPaint, requestPaint, isReady, требование прямого дочернего элемента холста + поддерева макета), ElementImageSource для неизменяемого моментального снимка captureElementImage() (автозакрытие, готово немедленно), с использованием источника Sprite/Texture/Mesh, автоматическое обнаружение только в качестве резервного варианта через Texture.from с приоритетом -10 и уничтожение/очистка. Запускается по: HTMLSource, ElementImageSource, pixi.js/html-source, requestPaint, captureElementImage, ElementImage, Layoutsubtree, autoRequestPaint, autoUpdate, autoClose, HTML в холсте, рендеринг DOM в текстуру, HTMLSourceOptions, ElementImageSourceOptions, HTMLSourceCanvas, экспериментальный.
