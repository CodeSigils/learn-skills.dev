Utilisez cette compétence lors du rendu d'éléments HTML/DOM en direct (ou de leurs instantanés figés) sous forme de textures PixiJS v8 via les API du navigateur EXPERIMENTAL HTML-in-Canvas. Couvre l'importation des effets secondaires pixi.js/html-source, la détection de fonctionnalités avec canvas.requestPaint, HTMLSource pour un élément de repeinture en direct maintenu interactif dans le navigateur (autoLayout/autoUpdate/autoRequestPaint, requestPaint, isReady, l'exigence direct-child-of-canvas + layoutsubtree), ElementImageSource pour un instantané immuable captureElementImage() (autoClose, prêt immédiatement), en utilisant la source sur un Sprite/Texture/Mesh, détection automatique de secours uniquement via Texture.from à la priorité -10 et destruction/nettoyage. Déclencheurs sur : HTMLSource, ElementImageSource, pixi.js/html-source, requestPaint, captureElementImage, ElementImage, layoutsubtree, autoRequestPaint, autoUpdate, autoClose, HTML dans le canevas, rendu du DOM en texture, HTMLSourceOptions, ElementImageSourceOptions, HTMLSourceCanvas, expérimental.
