このスキルは、実験的な HTML-in-Canvas ブラウザ API を介して、ライブ HTML/DOM 要素 (またはその凍結スナップショット) を PixiJS v8 テクスチャとしてレンダリングするときに使用します。 pixi.js/html-source の副作用インポート、canvas.requestPaint による機能検出、ブラウザ内でインタラクティブに維持されるライブ再描画要素の HTMLSource (autoLayout/autoUpdate/autoRequestPaint、requestPaint、isReady、canvas の直接の子 + レイアウトサブツリーの要件)、ソースを使用した不変の CaptureElementImage() スナップショットの ElementImageSource (autoClose、すぐに準備完了) をカバーします。スプライト/テクスチャ/メッシュでは、優先度 -10 の Texture.from によるフォールバックのみの自動検出、および破棄/クリーンアップ。トリガー対象: HTMLSource、ElementImageSource、pixi.js/html-source、requestPaint、captureElementImage、ElementImage、layoutsubtree、autoRequestPaint、autoUpdate、autoClose、キャンバス内の HTML、DOM をテクスチャにレンダリング、HTMLSourceOptions、ElementImageSourceOptions、HTMLSourceCanvas、実験的。
