Utilisez cette compétence lors de l'écriture de shaders, d'uniformes, de filtres ou de batchers personnalisés dans PixiJS v8. Couvre Shader.from({gl, gpu, resources}), GlProgram/GpuProgram, UniformGroup avec des uniformes typés (f32, vec2, mat4x4), le mode UBO, les textures comme ressources, le filtre personnalisé via Filter.from, les conventions GLSL ES 3.0 (in/out, finalColor, texture()), l'échantillonnage uBackTexture, pixi.js/unsafe-eval pour CSP strict, Batcher personnalisé via des extensions. Déclencheurs sur : Shader, GlProgram, GpuProgram, UniformGroup, Batcher, Filter, Filter.from, GLSL, WGSL, UBO, uniform, custom shader, finalColor, uBackTexture, blendRequired, unsafe-eval.
