Nettoyez, optimisez et personnalisez une installation Claude Code - guidée, étape par étape, entièrement annulable. À utiliser chaque fois que l'utilisateur mentionne claude-tuneup, ou souhaite nettoyer/désencombrer/mincir son installation Claude Code ou ~/.claude, libérer de l'espace disque, supprimer les compétences/plugins/hooks/serveurs MCP inutilisés, corriger l'intégrité de la configuration, améliorer ou réduire CLAUDE.md en fonction de l'utilisation réelle, câbler ou dédupliquer AGENTS.md avec CLAUDE.md, créer un profil SOUL.md ou annuler une mise au point précédente. ("restauration claude-tuneup"). Se déclenche également sur "mon code Claude est gonflé/lent/désordonné" et des phrases pt-BR comme "limpar/otimizar o Claude Code".
