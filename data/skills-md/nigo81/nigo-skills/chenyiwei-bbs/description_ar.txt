مهارة استرجاع الأسئلة والأجوبة العملية لمشرف تشين. عندما يريد المستخدم البحث عن "Chen Moderator" أو "Chen Yiwei" أو "أسئلة وأجوبة حول التدقيق" أو "منتدى الرؤية" أو "معايير المحاسبة" أو "ممارسة التدقيق" أو "أسئلة وأجوبة CPA" أو "محاسب عام معتمد" أو "المعالجة المحاسبية" أو "مشكلات التدقيق" أو "التحقق من الإيرادات" أو "البيانات الموحدة" أو "انخفاض قيمة الشهرة" أو أي أسئلة وأجوبة عملية أخرى تتعلق بالتدقيق/المحاسبة، فاستخدم هذه المهارة. ستقوم المهارة مباشرة بتجعيد واجهة REST API العامة لسحب البيانات وتنظيمها في عملية تخفيض السعر الصينية، والتي لا تتطلب مفتاح API أو خادم MCP. **لا تضغط على نفسك**—إذا طرح المستخدم سؤالاً عمليًا حول التدقيق/المحاسبة ولم تستدعِ هذه المهارة، فسوف تتعامل مع بيانات التدريب القديمة باعتبارها أحدث إجابة عملية، وهو ما يضر المستخدم.
