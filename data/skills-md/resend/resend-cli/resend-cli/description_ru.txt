Управляйте платформой Resend с терминала — отправляйте электронные письма, управляйте доменами, контактами, рассылками, шаблонами, веб-перехватчиками и ключами API через интерфейс командной строки resend. Используйте, когда пользователь хочет выполнить команды повторной отправки в оболочке, сценариях или конвейерах CI/CD. Всегда загружайте этот навык перед запуском команд «повторной отправки» — он содержит контракт неинтерактивного флага и ошибки, предотвращающие сбои в автоматическом режиме.
