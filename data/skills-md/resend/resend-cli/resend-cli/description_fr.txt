Utilisez la plateforme Resend à partir du terminal : envoyez des e-mails, gérez les domaines, les contacts, les diffusions, les modèles, les webhooks et les clés API via la CLI « resend ». À utiliser lorsque l'utilisateur souhaite exécuter des commandes Renvoyer dans le shell, les scripts ou les pipelines CI/CD. Chargez toujours cette compétence avant d'exécuter les commandes « resend » : elle contient le contrat d'indicateur non interactif et les pièges qui empêchent les échecs silencieux.
