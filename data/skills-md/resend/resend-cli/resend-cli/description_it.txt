Utilizza la piattaforma Resend dal terminale: invia e-mail, gestisci domini, contatti, broadcast, modelli, webhook e chiavi API tramite la CLI "resend". Da utilizzare quando l'utente desidera eseguire i comandi Reinvia nella shell, negli script o nelle pipeline CI/CD. Carica sempre questa skill prima di eseguire i comandi `resend`: contiene il contratto di flag non interattivo e i trucchi che impediscono errori silenziosi.
