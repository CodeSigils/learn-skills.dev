Управляйте платформой Resend с терминала — отправляйте электронные письма (включая шаблоны React Email .tsx через --react-email), управляйте доменами, контактами, рассылками, шаблонами, веб-перехватчиками и ключами API через CLI `resend`. Используйте, когда пользователь хочет выполнить команды повторной отправки в оболочке, сценариях или конвейерах CI/CD, а также отправить или просмотреть шаблоны электронной почты React. Всегда загружайте этот навык перед выполнением команд «повторной отправки» — он содержит контракт неинтерактивного флага и ошибки, предотвращающие сбои в автоматическом режиме.
