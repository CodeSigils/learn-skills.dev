ターミナルから再送信プラットフォームを操作します。電子メール (--react-email を介した React Email .tsx テンプレートを含む) を送信し、「resend」 CLI を介してドメイン、連絡先、ブロードキャスト、テンプレート、Webhook、および API キーを管理します。ユーザーがシェル、スクリプト、または CI/CD パイプラインで再送信コマンドを実行する場合、または React Email テンプレートを送信/プレビューする場合に使用します。 「再送信」コマンドを実行する前に必ずこのスキルをロードしてください。これには、非対話型のフラグ コントラクトとサイレント エラーを防ぐ注意事項が含まれています。
