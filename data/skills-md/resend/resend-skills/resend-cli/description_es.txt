Opere la plataforma Resend desde la terminal: envíe correos electrónicos (incluidas las plantillas React Email .tsx a través de --react-email), administre dominios, contactos, transmisiones, plantillas, webhooks y claves API a través de la CLI "resend". Úselo cuando el usuario desee ejecutar comandos de reenvío en el shell, scripts o canalizaciones de CI/CD, o enviar/obtener una vista previa de las plantillas de correo electrónico de React. Cargue siempre esta habilidad antes de ejecutar comandos "reenviar": contiene el contrato de bandera no interactivo y trampas que evitan fallas silenciosas.
