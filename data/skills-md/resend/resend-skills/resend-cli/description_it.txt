Utilizza la piattaforma Resend dal terminale: invia e-mail (inclusi i modelli React Email .tsx tramite --react-email), gestisci domini, contatti, broadcast, modelli, webhook e chiavi API tramite la CLI "resend". Da utilizzare quando l'utente desidera eseguire comandi Resend nella shell, negli script o nelle pipeline CI/CD oppure inviare/visualizzare in anteprima i modelli React Email. Carica sempre questa skill prima di eseguire i comandi `resend`: contiene il contratto di flag non interattivo e i trucchi che impediscono errori silenziosi.
