Utilisez la plateforme Resend depuis le terminal : envoyez des e-mails (y compris les modèles React Email .tsx via --react-email), gérez les domaines, les contacts, les diffusions, les modèles, les webhooks et les clés API via la CLI « resend ». À utiliser lorsque l'utilisateur souhaite exécuter des commandes Renvoyer dans le shell, des scripts ou des pipelines CI/CD, ou envoyer/prévisualiser des modèles d'e-mails React. Chargez toujours cette compétence avant d'exécuter les commandes « resend » : elle contient le contrat d'indicateur non interactif et les pièges qui empêchent les échecs silencieux.
