Automatise la maintenance de l'application de documentation (apps/docs). À utiliser lorsqu'on vous demande de mettre à jour les documents, d'ajouter un nouveau point de terminaison d'API aux documents, de synchroniser les types de SDK avec la documentation, de régénérer les métadonnées de navigation ou d'ajouter une nouvelle page de document. Déclencheurs sur les tâches mentionnant « mettre à jour les documents », « ajouter un point de terminaison aux documents », « synchroniser les documents avec le SDK », « nouvelle page de document » ou « régénérer la navigation ».
