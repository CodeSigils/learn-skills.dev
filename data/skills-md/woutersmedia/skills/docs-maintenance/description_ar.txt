أتمتة صيانة تطبيق التوثيق (التطبيقات/المستندات). استخدمه عندما يُطلب منك تحديث المستندات، أو إضافة نقطة نهاية API جديدة إلى المستندات، أو مزامنة أنواع SDK مع الوثائق، أو إعادة إنشاء بيانات تعريف التنقل، أو إضافة صفحة مستند جديدة. تشغيل المهام التي تشير إلى "تحديث المستندات"، أو "إضافة نقطة نهاية إلى المستندات"، أو "مزامنة المستندات مع SDK"، أو "صفحة مستند جديدة"، أو "إعادة إنشاء التنقل".
