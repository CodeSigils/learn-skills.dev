Automatiza el mantenimiento de la aplicación de documentación (apps/docs). Úselo cuando se le solicite actualizar documentos, agregar un nuevo punto final API a los documentos, sincronizar tipos de SDK con la documentación, regenerar metadatos de navegación o agregar una nueva página de documento. Activadores de tareas que mencionan "actualizar documentos", "agregar punto final a documentos", "sincronizar documentos con SDK", "nueva página de documentos" o "regenerar navegación".
