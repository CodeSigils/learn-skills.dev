أنشئ تطبيقات ويب Docyrus React TypeScript شاملة، وتجمع بين المصادقة والوصول إلى واجهة برمجة التطبيقات (API) والمجموعات التي تم إنشاؤها وأنماط الاستعلام/النموذج TanStack وتنفيذ واجهة المستخدم على مستوى الإنتاج مع مكتبات المكونات المفضلة. يُستخدم عند إنشاء أو تعديل التطبيقات المدعومة من Docyrus والتي تستخدم @docyrus/api-client أو @docyrus/signin أو مجموعات Docyrus أو الاستعلامات أو لوحات المعلومات أو النماذج أو الجداول أو التخطيطات أو مكونات Docyrus UI.
