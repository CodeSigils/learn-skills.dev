Connectez-vous à un atelier de graphiques IA local (http://localhost:3001) pour CRÉER des modèles de graphiques, APPLIQUER des données réelles pour restituer des graphiques, EXPORTER des images et CONSTRUIRE des rapports d'analyse illustrés/des résumés périodiques, le tout via HTTP. À utiliser lorsque l'utilisateur souhaite « créer un graphique/un tableau de bord/une visualisation/un graphique à barres/un graphique linéaire/un diagramme circulaire/un diagramme de Sankey », « générer des modèles de graphique », « répliquer un graphique », « dessiner un graphique à partir de données / générer un graphique en utilisant des données / créer un graphique d'analyse », « générer un graphique par lots », « exporter un graphique/SVG/PNG », « générer un rapport d'analyse / un rapport d'activité / un rapport de données », « produire un rapport hebdomadaire / un rapport mensuel / un rapport périodique ». Vous générez vous-même des fichiers modèles et les écrivez via l'API ; vous n’appelez PAS l’IA intégrée du workbench.

Veuillez toujours répondre dans la langue de l'utilisateur.
