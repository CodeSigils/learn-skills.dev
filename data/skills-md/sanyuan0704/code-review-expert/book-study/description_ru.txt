Тренер по чтению: систематически направляет пользователей через книги с помощью обобщения знаний, проверки усвоения, интервального повторения и запроса знаний. Используйте, когда пользователь говорит «прочитайте эту книгу со мной», «изучите книгу», «начните изучать X», «план чтения», «проглотите эту главу», «просмотрите то, что я прочитал», «проверьте меня по книге», «что в книге сказано об X» или вызывает /book-study. Поддерживает подкоманды: прием, запрос, просмотр, сравнение, статус. Триггеры: книга, изучение, чтение, глава, проглатывание, обзор, викторина, план чтения, заметки к книге.
