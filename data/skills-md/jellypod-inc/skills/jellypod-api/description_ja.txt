Jellypod API を使用して AI を活用したポッドキャストをプログラムで作成する方法 (ホストの作成、ソースのアップロード、エピソードの生成、公開)。 Jellypod API を使用して構築する場合、Jellypod をアプリケーションに統合する場合、プログラムでポッドキャスト コンテンツを生成する場合、ポッドキャスト制作を自動化する場合、または Jellypod エンドポイントと対話する場合は、必ずこのスキルを使用してください。 AI ポッドキャスト、ポッドキャスト生成 API、またはコードを介してテキストをポッドキャスト エピソードに変換することについて誰かが言及した場合にも使用します。
