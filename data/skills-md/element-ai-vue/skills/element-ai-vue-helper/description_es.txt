Ayude a los usuarios a integrar y utilizar componentes element-ai-vue para crear interfaces de chat de IA, renderizado de Markdown, resaltado de código, efectos de máquina de escribir y otras funciones de interacción de IA. Active esta habilidad cada vez que el usuario mencione el chat de IA, las interfaces de conversación, la visualización de Markdown, el resaltado de código, las cadenas de pensamiento, las burbujas de mensajes, la carga de archivos en el chat o cualquier nombre de componente específico de element-ai-vue (como ElAMarkdown, ElABubble, ElASender, ElAThinking, ElATypewriter, etc.). Utilice también esta habilidad cuando el usuario esté trabajando dentro del proyecto element-ai-vue y desee agregar o modificar componentes. Asegúrese de utilizar activamente esta habilidad siempre que el usuario mencione cualquier necesidad relacionada con conversaciones de IA, interfaces de chat, efectos de máquina de escribir, renderizado de Markdown o visualización de procesos de pensamiento.
