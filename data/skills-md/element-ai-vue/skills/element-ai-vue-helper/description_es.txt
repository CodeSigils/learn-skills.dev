Ayude a los usuarios a integrar y utilizar los componentes de element-ai-vue para crear interfaces de chat de IA, renderizado de Markdown, resaltado de código, efectos de máquina de escribir y otras funciones de interacción de IA. Active esta habilidad cada vez que el usuario mencione el chat de IA, la interfaz de usuario conversacional, la visualización de Markdown, el resaltado de código, la cadena de pensamiento, las burbujas de mensajes, la carga de archivos en el chat o cualquier nombre de componente específico de element-ai-vue (como ElAMarkdown, ElABubble, ElASender, ElAThinking, ElATypewriter, etc.). Utilice también esta habilidad cuando el usuario esté trabajando dentro del proyecto element-ai-vue y desee agregar o modificar componentes. Aplique siempre esta habilidad de manera proactiva cada vez que el usuario mencione cualquier requisito relacionado con la conversación de IA, la interfaz de chat, el efecto de máquina de escribir, la representación de Markdown o la visualización del proceso de pensamiento.
