ساعد المستخدمين على دمج واستخدام مكونات element-ai-vue لإنشاء واجهات دردشة AI، وعرض Markdown، وتمييز التعليمات البرمجية، وتأثيرات الآلة الكاتبة، وميزات تفاعل الذكاء الاصطناعي الأخرى. قم بتشغيل هذه المهارة عندما يذكر المستخدم دردشة الذكاء الاصطناعي، أو واجهات المحادثة، أو عرض Markdown، أو تمييز التعليمات البرمجية، أو سلاسل التفكير، أو فقاعات الرسائل، أو تحميلات الملفات في الدردشة، أو أي أسماء مكونات محددة من element-ai-vue (مثل ElAMarkdown، وElABubbble، وElASender، وElAThinking، وElATypewriter، وما إلى ذلك). استخدم هذه المهارة أيضًا عندما يعمل المستخدم ضمن مشروع element-ai-vue نفسه ويريد إضافة مكونات أو تعديلها. تأكد من استخدام هذه المهارة بشكل فعال عندما يذكر المستخدم أي احتياجات تتعلق بمحادثات الذكاء الاصطناعي أو واجهات الدردشة أو تأثيرات الآلة الكاتبة أو عرض Markdown أو عرض عمليات التفكير.
