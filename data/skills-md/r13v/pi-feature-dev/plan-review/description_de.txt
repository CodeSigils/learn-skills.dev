Überprüfen Sie die Implementierungspläne vor der Ausführung. Verwenden Sie diese Option, nachdem ein Plan erstellt wurde oder wenn der Benutzer darum bittet, einen Plan auf Richtigkeit, Umfang, Überentwicklung, fehlende Tests, unklare Aufgaben oder Übereinstimmung mit Projektkonventionen zu überprüfen. Überprüft Plandateien wie docs/plans/*.md oder einen vom Benutzer bereitgestellten Planpfad. Bevorzugen Sie eine isolierte schreibgeschützte Überprüfung, wenn der Host und die Richtlinie Subagenten, Fresh-Context-Worker oder schreibgeschützte Agenten unterstützen.
