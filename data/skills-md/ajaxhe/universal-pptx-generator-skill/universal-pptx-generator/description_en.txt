General PPT generation capability. It can automatically create a unified‑style presentation based on any PPT template specified by the user, combined with provided image‑and‑text materials (documents, pictures, etc.). It supports automatic analysis of the template structure, extraction of background images/background colors, parsing of color schemes and font specifications, and then generates a complete PPT according to the material content. It supports data visualization of various chart types (bar charts, line charts, pie charts, radar charts, etc.). Keywords: PPT generation, template analysis, presentation, slides, image‑text layout, automation, charts, data visualization.
