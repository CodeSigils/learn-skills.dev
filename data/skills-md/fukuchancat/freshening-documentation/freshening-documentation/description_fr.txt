Coupez et actualisez les documents techniques, les README, les notes de conception, les descriptions de relations publiques, les messages internes et les commentaires ou docstrings du code source. Utilise des critiques indépendantes de nouveaux lecteurs pour exposer les préjugés liés au contexte de l'auteur, puis supprime les répétitions, les mises en garde défensives, les éléments de remplissage, la structure décorative et les reformulations de code tout en préservant les faits, les décisions, les actions, les contraintes et la justification nécessaire. À utiliser lorsque le texte est surexpliqué, répétitif, difficile à numériser, écrit pendant la réflexion, ou lorsque les commentaires reformulent le code ou sont désynchronisés avec celui-ci.
