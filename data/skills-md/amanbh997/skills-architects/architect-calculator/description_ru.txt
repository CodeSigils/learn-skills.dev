Семь архитектурных калькуляторов на базе Python для общих проектных расчетов: расчеты площади и плотности (GFA, NGA, количество единиц, численность населения, парковка), анализ теплового коэффициента U для многослойных конструкций, оценка коэффициента дневного света с использованием методологии BRE, проверка соответствия требованиям по выходу (нагрузка жильцов, ширина выхода, расстояние проезда), расчеты структурной гравитационной нагрузки и площади притоков, оценка годовой потребности в энергии с помощью метода градусо-дней и оценка стоимости строительства по типу здания, качеству и региону.
