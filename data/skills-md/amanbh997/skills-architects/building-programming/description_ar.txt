تطوير البرامج المعمارية، وتحليلات احتياجات المساحة، ومصفوفات الجوار، وجداول المناطق، وملخصات المشروع. يُستخدم عندما يسأل المستخدم عن برمجة مبنى، أو تحديد حجم المساحات، أو تحديد متطلبات المنطقة، أو إنشاء مخططات مجاورة، أو بناء برنامج مساحة، أو تطوير ملخص، أو حساب النسب الصافية إلى الإجمالي، أو تحليل معايير المساحة، أو مقارنة معايير المنطقة، أو إنشاء مخططات تكديس، أو التحقق من صحة البرنامج مقابل سعة الموقع والميزانية. استخدمها أيضًا عندما يحتاج المستخدم إلى جداول مناطق لأنواع المباني السكنية أو المكتبية أو الرعاية الصحية أو التعليمية أو الضيافة أو البيع بالتجزئة أو الثقافية، أو عند التحقق من التوافق مع معايير NDSS أو Neufert أو NHS HBN أو BB103 أو ASHRAE.
