Desarrollar programas de uso del suelo y optimizar la combinación de usos para distritos urbanos, vecindarios y edificios individuales. Úselo cuando el usuario pregunte sobre la programación del uso del suelo, las proporciones de combinación de uso, la distribución del programa, el tamaño de las tiendas minoristas, los requisitos de espacio para oficinas, el equilibrio residencial-comercial, la estrategia del inquilino ancla, la planificación de las instalaciones comunitarias o cuando se desarrolle un programa de desarrollo para un sitio. Utilícelo también cuando el usuario necesite determinar qué usos van y dónde, cuánto de cada uso se necesita o cómo crear entornos vibrantes de uso mixto.
