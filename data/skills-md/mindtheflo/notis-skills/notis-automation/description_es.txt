Úselo cuando el usuario desee programar, automatizar, activar o que se le recuerde algo: "recordarme...", "cada mañana...", "en dos horas...", "cuando llegue un nuevo Gmail", "cuando cambie este registro", "publicar un resumen semanal". Decide entre un recordatorio, una automatización y una habilidad, y crea las cargas útiles correctas.
