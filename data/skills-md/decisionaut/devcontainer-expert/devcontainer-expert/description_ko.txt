VS Code의 개발 컨테이너(devcontainers)에 대한 전문가 지침입니다. devcontainer.json 파일을 생성, 구성 및 관리하고, 템플릿 및 기능을 사용하고, Docker/Docker Compose와 통합하고, 일반적인 문제를 해결합니다. devcontainer, 컨테이너화된 개발 환경으로 작업할 때 또는 사용자가 devcontainer.json, dev 컨테이너, VS Code 컨테이너 또는 Docker 개발을 언급할 때 사용합니다. Docker(Mac/Windows의 Docker Desktop 또는 Linux의 Docker CE/EE) 및 Dev Containers 확장이 포함된 VS Code가 필요합니다.
