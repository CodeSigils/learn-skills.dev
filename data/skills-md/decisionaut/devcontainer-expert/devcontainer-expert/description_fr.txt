Conseils d'experts pour les conteneurs de développement (devcontainers) dans VS Code. Créez, configurez et gérez les fichiers devcontainer.json, utilisez des modèles et des fonctionnalités, intégrez à Docker/Docker Compose et résolvez les problèmes courants. À utiliser lorsque vous travaillez avec des devcontainers, des environnements de développement conteneurisés ou lorsque l'utilisateur mentionne devcontainer.json, des conteneurs de développement, des conteneurs VS Code ou le développement Docker. Nécessite Docker (Docker Desktop sur Mac/Windows ou Docker CE/EE sur Linux) et VS Code avec l'extension Dev Containers.
