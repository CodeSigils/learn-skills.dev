VS Code の開発コンテナ (devcontainers) に関する専門家によるガイダンス。 devcontainer.json ファイルの作成、構成、管理、テンプレートと機能の使用、Docker/Docker Compose との統合、一般的な問題のトラブルシューティングを行います。 devcontainer、コンテナ化された開発環境を操作する場合、またはユーザーが devcontainer.json、dev コンテナ、VS Code コンテナ、または Docker 開発について言及する場合に使用します。 Docker (Mac/Windows の Docker Desktop または Linux の Docker CE/EE) および Dev Containers 拡張機能を備えた VS Code が必要です。
