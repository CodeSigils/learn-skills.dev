Expertenberatung für Entwicklungscontainer (Devcontainer) in VS Code. Erstellen, konfigurieren und verwalten Sie devcontainer.json-Dateien, verwenden Sie Vorlagen und Funktionen, integrieren Sie sie in Docker/Docker Compose und beheben Sie häufige Probleme. Verwenden Sie diese Option, wenn Sie mit Devcontainern, containerisierten Entwicklungsumgebungen arbeiten oder wenn der Benutzer devcontainer.json, Dev-Container, VS-Code-Container oder Docker-Entwicklung erwähnt. Erfordert Docker (Docker Desktop unter Mac/Windows oder Docker CE/EE unter Linux) und VS Code mit Dev Containers-Erweiterung.
