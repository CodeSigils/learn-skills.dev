Guía de expertos para contenedores de desarrollo (devcontainers) en VS Code. Cree, configure y administre archivos devcontainer.json, use plantillas y funciones, integre con Docker/Docker Compose y solucione problemas comunes. Úselo cuando trabaje con contenedores de desarrollo, entornos de desarrollo en contenedores o cuando el usuario mencione devcontainer.json, contenedores de desarrollo, contenedores de VS Code o desarrollo Docker. Requiere Docker (Docker Desktop en Mac/Windows o Docker CE/EE en Linux) y VS Code con extensión Dev Containers.
