Комплексная система проектирования UI/UX для проектов Next.js + Tailwind CSS + Shadcn UI. Обеспечивает визуальную иерархию, интервальные сетки, теорию цвета, темный режим, типографику, состояния кнопок, действия micro plusJakartaSansactions и стандарты доступности. Используйте при создании компонентов пользовательского интерфейса, создании страниц, стилизации макетов, реализации темного режима, разработке форм, добавлении кнопок, работе над адаптивным дизайном или любой визуальной работе с интерфейсом.
