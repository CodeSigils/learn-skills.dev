Sistema integral de diseño UI/UX para proyectos Next.js + Tailwind CSS + Shadcn UI. Hace cumplir la jerarquía visual, las cuadrículas de espaciado, la teoría del color, el modo oscuro, la tipografía, los estados de los botones, las micro plusJakartaSansactions y los estándares de accesibilidad. Úselo al crear componentes de interfaz de usuario, crear páginas, diseñar diseños, implementar el modo oscuro, diseñar formularios, agregar botones, trabajar en un diseño responsivo o cualquier trabajo visual de interfaz.
