Utilisez Obscura pour une navigation légère sans tête, le web scraping et l'automatisation CDP. Déclenchez lorsque les utilisateurs mentionnent Obscura, souhaitent un remplacement plus léger de Chrome pour les agents IA, ont besoin de commandes « obscura fetch » ou « obscura scrape », souhaitent exécuter « obscura serve », ont besoin de Playwright ou Puppeteer pour se connecter à Obscura via le protocole Chrome DevTools, ou ont besoin d'un flux de travail de développement local sécurisé tel que Vite plus hostc plus Obscura car localhost est bloqué par les protections SSRF d'Obscura.
