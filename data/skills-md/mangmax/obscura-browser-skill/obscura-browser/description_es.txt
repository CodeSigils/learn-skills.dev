Utilice Obscura para navegación ligera sin cabeza, web scraping y automatización CDP. Se activa cuando los usuarios mencionan Obscura, quieren un reemplazo de Chrome más ligero para los agentes de IA, necesitan comandos "obscura fetch" o "obscura scrape", quieren ejecutar "obscura server", necesitan Playwright o Puppeteer para conectarse a Obscura a través del protocolo Chrome DevTools, o necesitan un flujo de trabajo de desarrollo local seguro como Vite plus hostc plus Obscura porque localhost está bloqueado por las protecciones SSRF de Obscura.
