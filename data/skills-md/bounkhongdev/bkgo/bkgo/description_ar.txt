يفرض سير عمل bkgo CLI لمشاريع Go الخلفية باستخدام الهندسة السداسية. استخدم هذه المهارة عند العمل على مشروع قائم على bkgo - إنشاء مشروع جديد، أو إضافة وحدة نمطية، أو إزالة وحدة نمطية، أو إنشاء طبقات فردية (معالج، خدمة، مستودع)، كتابة أو تحرير التعليمات البرمجية في أي ملف/<module>/ داخلي، أو مراجعة بنية المشروع. قم بتشغيل هذا حتى لو قال المستخدم فقط "أضف وحدة مستخدم" أو "أنشئ خدمة جديدة" أو "أزل وحدة الدفع" أو "دعم مشروع Go جديد" دون ذكر bkgo بالاسم - أي تغيير هيكلي لمشروع bkgo يجب أن يمر عبر واجهة سطر الأوامر (CLI)، وليس إنشاء الملف يدويًا.
