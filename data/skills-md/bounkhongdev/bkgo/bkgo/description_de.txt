Erzwingt den bkgo CLI-Workflow für Go-Backend-Projekte mit Hexagonal Architecture. Verwenden Sie diese Fähigkeit, wenn Sie an einem bkgo-basierten Projekt arbeiten – ein neues Projekt erstellen, ein Modul hinzufügen, ein Modul entfernen, einzelne Ebenen (Handler, Dienst, Repository) generieren, Code in einer internen/<module>/-Datei schreiben oder bearbeiten oder die Projektstruktur überprüfen. Lösen Sie dies auch dann aus, wenn der Benutzer nur „Benutzermodul hinzufügen“, „Neuen Dienst erstellen“, „Zahlungsmodul entfernen“ oder „Neues Go-Projekt erstellen“ sagt, ohne bkgo namentlich zu erwähnen – jede strukturelle Änderung an einem bkgo-Projekt muss über die CLI erfolgen, nicht über die manuelle Dateierstellung.
