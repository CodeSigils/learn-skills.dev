À utiliser lorsque vous travaillez avec git town pour des flux de travail de branches empilées, créez ou parcourez des piles de branches, synchronisez des modifications empilées, proposez des PR pour des branches empilées ou rencontrez des commandes git town telles que pirater, ajouter, monter, descendre, proposer, synchroniser, expédier, ajouter, compresser, annuler, changer.
