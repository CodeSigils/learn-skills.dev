Lovrabet runtime CLI — une suite d'opérations d'IA adaptée aux scénarios commerciaux, à la gestion des répertoires d'applications, des requêtes d'ensembles de données, des opérations de données API instantanées, de l'exécution SQL et des appels BFF via la commande lovrabet. Mots déclencheurs : YunTu, lovrabet, lovrabet-cli, liste d'applications, ensemble de données, filtre de données, data getOne, créer, mettre à jour, supprimer, sql exec, bff exec, accessKey, compresser, jq.
