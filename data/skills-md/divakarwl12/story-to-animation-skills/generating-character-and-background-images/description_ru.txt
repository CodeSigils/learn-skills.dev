Считывает символы.json и backgrounds.json, затем генерирует эталонные изображения для каждого персонажа и фона с помощью API kie.ai nano-banana-pro. Изображения персонажей (соотношение сторон 1:1) сохраняются в ./characters/, а фоновые изображения (16:9) — в ./backgrounds/, именуемые по своим идентификаторам (char_001.png, bg_001.png и т. д.). Затем каждое изображение загружается в imgbb для постоянного общедоступного хостинга, а URL-адрес imgbb записывается обратно как поле image_url в обоих файлах JSON — эти URL-адреса требуются для файлаgenerate_videos.py. Часть конвейера преобразования истории в анимацию (шаг 3 из 5). Запустите скрипты/generate_images.py для выполнения. Используйте, когда существуют оба файла приглашения JSON и пользователь хочет создать фактические эталонные изображения. После создания всех изображений ВСЕГДА представляйте результат и ждите явного одобрения пользователя. НЕ запускайте автоматически следующий шаг конвейера.
