Legge i file characters.json e backgrounds.json, poi genera immagini di riferimento per ogni personaggio e sfondo usando l’API kie.ai nano‑banana‑pro. Le immagini dei personaggi (rapporto d’aspetto 1:1) vengono salvate in ./characters/ e le immagini di sfondo (16:9) in ./backgrounds/, con nomi basati sui loro ID (char_001.png, bg_001.png, ecc.). Ogni immagine viene quindi caricata su imgbb per l’hosting pubblico permanente, e l’URL di imgbb è scritta nuovamente nel campo image_url di entrambi i file JSON — questi URL sono richiesti da generate_videos.py. Fa parte della pipeline Story‑to‑Animation (Passo 3 di 5). Esegui scripts/generate_images.py per avviare. Da utilizzare quando entrambi i file JSON di prompt esistono e l’utente desidera generare le immagini di riferimento reali. Dopo aver generato tutte le immagini, PRESENTA SEMPRE l’output e attendi l’approvazione esplicita dell’utente. NON attivare automaticamente il passo successivo della pipeline.
