Lit Characters.json et backgrounds.json, puis génère des images de référence pour chaque personnage et arrière-plan à l'aide de l'API kie.ai nano-banana-pro. Les images de personnages (rapport hauteur/largeur 1:1) sont enregistrées dans ./characters/ et les images d'arrière-plan (16:9) dans ./backgrounds/, nommées par leurs identifiants (char_001.png, bg_001.png, etc.). Chaque image est ensuite téléchargée sur imgbb pour un hébergement public permanent, et l'URL imgbb est réécrite sous forme de champ image_url dans les deux fichiers JSON — ces URL sont requises par generate_videos.py. Une partie du pipeline Story-to-Animation (étape 3 sur 5). Exécutez scripts/generate_images.py pour exécuter. À utiliser lorsque les deux fichiers d'invite JSON existent et que l'utilisateur souhaite générer les images de référence réelles. Après avoir généré toutes les images, présentez TOUJOURS la sortie et attendez l'approbation explicite de l'utilisateur. Ne déclenchez PAS automatiquement l’étape suivante du pipeline.
