讀取characters.json和backgrounds.json，然後使用kie.ai nano-banana-pro API為每個角色和背景產生參考圖像。角色圖像（1:1 寬高比）儲存到 ./characters/，背景圖像 (16:9) 儲存到 ./backgrounds/，並按其 ID 命名（char_001.png、bg_001.png 等）。然後，每個圖像都會上傳到 imgbb 進行永久公共託管，並且 imgbb URL 會作為 image_url 字段寫回兩個 JSON 文件中 — 這些 URL 是generate_videos.py 所需要的。故事到動畫流程的一部分（第 3 步，共 5 步）。運行scripts/generate_images.py來執行。當兩個 JSON 提示檔案都存在並且使用者想要產生實際的參考圖像時使用。生成所有圖像後，始終顯示輸出並等待明確的用戶批准。不要自動觸發下一個管道步驟。
