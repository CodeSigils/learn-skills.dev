Lee caracteres.json y backgrounds.json, luego genera imágenes de referencia para cada personaje y fondo usando la API kie.ai nano-banana-pro. Las imágenes de personajes (relación de aspecto 1:1) se guardan en ./characters/ y las imágenes de fondo (16:9) en ./backgrounds/, nombradas por sus ID (char_001.png, bg_001.png, etc.). Luego, cada imagen se carga en imgbb para su alojamiento público permanente, y la URL de imgbb se vuelve a escribir como un campo image_url en ambos archivos JSON; estas URL son requeridas por generate_videos.py. Parte del proceso de Story-to-Animation (Paso 3 de 5). Ejecute scripts/generate_images.py para ejecutar. Úselo cuando existan ambos archivos de solicitud JSON y el usuario desee generar las imágenes de referencia reales. Después de generar todas las imágenes, SIEMPRE presente el resultado y espere la aprobación explícita del usuario. NO active automáticamente el siguiente paso de la canalización.
