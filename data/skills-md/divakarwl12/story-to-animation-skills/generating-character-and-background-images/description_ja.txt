characters.json とbackgrounds.json を読み取り、kie.ai nano-banana-pro API を使用して各キャラクターと背景の参照画像を生成します。キャラクター画像 (アスペクト比 1:1) は ./characters/ に、背景画像 (16:9) は ./backgrounds/ に保存され、ID によって名前が付けられます (char_001.png、bg_001.png など)。次に、各画像は永続的なパブリック ホスティングのために imgbb にアップロードされ、imgbb URL が両方の JSON ファイルの image_url フィールドとして書き戻されます。これらの URL はgenerate_videos.py で必要です。ストーリーからアニメーションへのパイプラインの一部 (ステップ 3/5)。 scripts/generate_images.py を実行して実行します。両方の JSON プロンプト ファイルが存在し、ユーザーが実際の参照画像を生成したい場合に使用します。すべてのイメージを生成した後は、必ず出力を提示し、明示的なユーザーの承認を待ちます。次のパイプライン ステップを自動的にトリガーしないでください。
