Figma Desktop MCP(get_metadata, get_variable_defs, create_design_system_rules, get_design_context, get_screenshot)를 사용하여 Figma에서 Android Jetpack Compose UI를 생성합니다. Figma에서 아이콘/벡터 노드를 자동으로 감지하고, 가능한 경우 SVG/경로 데이터를 얻고, Android MCP 툴킷(convert-svg-to-android-drawable)을 사용하여 아이콘을 Android VectorDrawable XML로 변환합니다. 사용자가 Figma 링크/노드 ID를 공유하고 Figma에서 Compose에 UI를 구현하도록 요청할 때 사용합니다.
