Создайте пользовательский интерфейс Android Jetpack Compose из Figma с помощью Figma Desktop MCP (get_metadata, get_variable_defs, create_design_system_rules, get_design_context, get_screenshot). Автоматически обнаруживайте узлы значков/векторов в Figma, получайте данные SVG/пути, если они доступны, и конвертируйте значки в Android VectorDrawable XML с помощью Android MCP Toolkit (convert-svg-to-android-drawable). Используйте, когда пользователь делится ссылкой/идентификатором узла Figma и просит реализовать пользовательский интерфейс в Compose из Figma.
