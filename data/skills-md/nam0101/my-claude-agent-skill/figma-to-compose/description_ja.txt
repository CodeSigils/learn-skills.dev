Figma Desktop MCP (get_metadata、get_variable_defs、create_design_system_rules、get_design_context、get_screenshot) を使用して、Figma から Android Jetpack Compose UI を生成します。 Figma でアイコン/ベクター ノードを自動的に検出し、利用可能な場合は SVG/パス データを取得し、Android MCP Toolkit (convert-svg-to-android-drawable) を使用してアイコンを Android VectorDrawable XML に変換します。ユーザーが Figma リンク/ノード ID を共有し、Figma から Compose に UI を実装するよう要求する場合に使用します。
