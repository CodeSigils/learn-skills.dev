أنشئ واجهة مستخدم Android Jetpack Compose من Figma باستخدام Figma Desktop MCP (get_metadata، get_variable_defs، create_design_system_rules، get_design_context، get_screenshot). اكتشف عقد الأيقونات/المتجهات في Figma تلقائيًا، واحصل على بيانات SVG/المسار عند توفرها، وقم بتحويل الأيقونات إلى Android VectorDrawable XML باستخدام Android MCP Toolkit (convert-svg-to-android-drawable). يُستخدم عندما يشارك المستخدم رابط/معرف عقدة Figma ويطلب تنفيذ واجهة المستخدم في Compose from Figma.
