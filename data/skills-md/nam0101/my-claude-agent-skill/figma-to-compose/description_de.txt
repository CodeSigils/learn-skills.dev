Generieren Sie die Android Jetpack Compose-Benutzeroberfläche von Figma mit Figma Desktop MCP (get_metadata, get_variable_defs, create_design_system_rules, get_design_context, get_screenshot). Erkennen Sie automatisch Symbol-/Vektorknoten in Figma, erhalten Sie SVG-/Pfaddaten, sofern verfügbar, und konvertieren Sie Symbole mit dem Android MCP Toolkit (convert-svg-to-android-drawable) in Android VectorDrawable XML. Wird verwendet, wenn der Benutzer einen Figma-Link/eine Figma-Knoten-ID teilt und darum bittet, die Benutzeroberfläche in Compose von Figma aus zu implementieren.
