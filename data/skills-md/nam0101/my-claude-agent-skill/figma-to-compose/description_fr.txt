Générez l'interface utilisateur Android Jetpack Compose à partir de Figma à l'aide de Figma Desktop MCP (get_metadata, get_variable_defs, create_design_system_rules, get_design_context, get_screenshot). Détectez automatiquement les nœuds d'icônes/vecteurs dans Figma, obtenez les données SVG/chemin lorsqu'elles sont disponibles et convertissez les icônes en XML Android VectorDrawable à l'aide d'Android MCP Toolkit (convert-svg-to-android-drawable). À utiliser lorsque l'utilisateur partage un lien/identifiant de nœud Figma et demande d'implémenter l'interface utilisateur dans Compose from Figma.
