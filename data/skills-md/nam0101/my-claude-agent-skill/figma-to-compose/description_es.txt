Genere la interfaz de usuario de Android Jetpack Compose desde Figma usando Figma Desktop MCP (get_metadata, get_variable_defs, create_design_system_rules, get_design_context, get_screenshot). Detecte automáticamente nodos de íconos/vectores en Figma, obtenga datos SVG/de ruta cuando estén disponibles y convierta íconos a Android VectorDrawable XML utilizando Android MCP Toolkit (convertir-svg-a-android-drawable). Úselo cuando el usuario comparte un enlace/ID de nodo de Figma y solicita implementar la interfaz de usuario en Compose desde Figma.
