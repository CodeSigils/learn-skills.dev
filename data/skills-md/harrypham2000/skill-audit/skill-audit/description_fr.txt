Cette compétence doit être utilisée lorsque l'utilisateur demande « d'auditer les compétences de l'agent IA pour détecter les vulnérabilités de sécurité », « d'évaluer les compétences de tiers avant l'installation », « de vérifier l'injection rapide ou la fuite de secrets », « d'analyser les compétences pour détecter l'exposition des informations personnelles », « de valider la conformité aux réglementations en matière d'IA », « d'analyser les compétences pour détecter les risques d'exécution de code », « de valider les compétences par rapport aux spécifications des compétences d'agent » ou « d'évaluer la posture de sécurité des compétences avec l'intelligence CVE/GHSA/KEV/EPSS/NVD ».
