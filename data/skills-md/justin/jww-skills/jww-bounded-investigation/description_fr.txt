Tenez un registre des preuves écrites et déléguez les recherches dans l’ensemble du référentiel au cours d’une enquête portant sur de nombreux dossiers. À utiliser pour le débogage, les audits et l'archéologie où l'emplacement du code pertinent est inconnu. Ne pas utiliser lorsque les fichiers concernés sont déjà identifiés ou pour des modifications ordinaires d'un code connu.
