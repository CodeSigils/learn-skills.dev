Создавайте локальные агенты с ограниченным браузером с помощью инструмента Safe_browser, который владеет CDP, обеспечивает соблюдение белого списка домена с помощью перехвата Fetch и позволяет агенту Claude Agent SDK во время выполнения выполнять задачи просмотра без доступа к непосредственному браузеру, оболочке или CDP. Используйте, когда пользователь хочет, чтобы агент просматривал или очищал данные, оставаясь в одобренных доменах, демонстрируя заблокированную навигацию за пределами домена или создавая безопасный клиент браузера.
