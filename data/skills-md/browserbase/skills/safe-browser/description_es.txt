Cree agentes de navegador restringido locales con una herramienta safe_browser que posee CDP, aplica una lista de dominios permitidos con interceptación Fetch y permite que un agente Claude Agent SDK en tiempo de ejecución complete tareas de navegación sin acceso directo al navegador, shell o CDP. Úselo cuando el usuario desee que un agente navegue o raspe mientras permanece en dominios aprobados, realice una demostración de navegación fuera del dominio bloqueada o genere un cliente de navegador seguro.
