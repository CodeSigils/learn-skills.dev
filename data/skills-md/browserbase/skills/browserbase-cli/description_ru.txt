Используйте интерфейс командной строки Browserbase («bb») для функций браузера и рабочих процессов API платформы. Используйте, когда пользователь запрашивает запуск bb, развертывание или вызов функций, управление сеансами, проектами, контекстами или расширениями, получение страницы через API-интерфейс Browserbase Fetch, поиск в Интернете через Browserbase Search API или открытие панели управления Browserbase из командной строки. Предпочитайте навык «Браузер» для интерактивного просмотра; используйте `bb Browse` только тогда, когда пользователю явно нужен путь CLI к базе браузера.
