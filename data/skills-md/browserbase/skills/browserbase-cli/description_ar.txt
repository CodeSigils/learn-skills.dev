استخدم Browserbase CLI (`bb`) لوظائف Browserbase وسير عمل واجهة برمجة تطبيقات النظام الأساسي. يُستخدم عندما يطلب المستخدم تشغيل `bb`، أو نشر الوظائف أو استدعائها، أو إدارة الجلسات، أو المشروعات، أو السياقات، أو الامتدادات، أو جلب صفحة من خلال Browserbase Fetch API، أو البحث في الويب من خلال Browserbase Search API، أو فتح لوحة معلومات Browserbase من سطر الأوامر. تفضل مهارة المتصفح للتصفح التفاعلي؛ استخدم "تصفح bb" فقط عندما يريد المستخدم صراحةً مسار واجهة سطر الأوامر لـ Browserbase.
