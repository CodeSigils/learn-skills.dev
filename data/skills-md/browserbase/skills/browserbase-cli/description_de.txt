Verwenden Sie die Browserbase-CLI („bb“) für Browserbase-Funktionen und Plattform-API-Workflows. Verwenden Sie diese Option, wenn der Benutzer „bb“ ausführen, Funktionen bereitstellen oder aufrufen, Sitzungen, Projekte, Kontexte oder Erweiterungen verwalten, eine Seite über die Browserbase Fetch API abrufen, das Web über die Browserbase Search API durchsuchen oder das Browserbase Dashboard über die Befehlszeile öffnen möchte. Bevorzugen Sie die Browser-Fähigkeit für interaktives Surfen; Verwenden Sie „bb browse“ nur, wenn der Benutzer ausdrücklich den Browserbase-CLI-Pfad möchte.
