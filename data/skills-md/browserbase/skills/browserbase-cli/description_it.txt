Utilizza la CLI Browserbase (`bb`) per le funzioni Browserbase e i flussi di lavoro API della piattaforma. Da utilizzare quando l'utente chiede di eseguire `bb`, distribuire o richiamare funzioni, gestire sessioni, progetti, contesti o estensioni, recuperare una pagina tramite l'API Browserbase Fetch, eseguire ricerche sul Web tramite l'API Browserbase Search o aprire la dashboard di Browserbase dalla riga di comando. Preferire la skill Browser per la navigazione interattiva; utilizzare `bbbrowse` solo quando l'utente desidera esplicitamente il percorso CLI di Browserbase.
