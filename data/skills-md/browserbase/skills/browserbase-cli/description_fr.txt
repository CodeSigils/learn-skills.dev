Utilisez la CLI Browserbase (`bb`) pour les fonctions Browserbase et les workflows de l'API de la plateforme. À utiliser lorsque l'utilisateur demande d'exécuter `bb`, de déployer ou d'invoquer des fonctions, de gérer des sessions, des projets, des contextes ou des extensions, de récupérer une page via l'API Browserbase Fetch, de rechercher sur le Web via l'API de recherche Browserbase ou d'ouvrir le tableau de bord Browserbase à partir de la ligne de commande. Préférer la compétence Navigateur pour une navigation interactive ; utilisez `bb parcourir` uniquement lorsque l'utilisateur souhaite explicitement le chemin CLI Browserbase.
