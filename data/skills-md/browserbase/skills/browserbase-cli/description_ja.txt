Browserbase 関数とプラットフォーム API ワークフローには、Browserbase CLI (`bb`) を使用します。ユーザーが「bb」の実行、関数のデプロイまたは呼び出し、セッション、プロジェクト、コンテキスト、または拡張機能の管理、Browserbase Fetch API を介してページを取得する、Browserbase Search API を介して Web を検索する、またはコマンド ラインから Browserbase ダッシュボードを開くように要求する場合に使用します。インタラクティブなブラウジングにはブラウザ スキルを推奨します。ユーザーが明示的に Browserbase CLI パスを必要とする場合にのみ、「bbBrowse」を使用してください。
