Utilice la CLI de Browserbase (`bb`) para las funciones de Browserbase y los flujos de trabajo API de la plataforma. Úselo cuando el usuario solicite ejecutar `bb`, implementar o invocar funciones, administrar sesiones, proyectos, contextos o extensiones, buscar una página a través de Browserbase Fetch API, buscar en la web a través de Browserbase Search API o abrir el panel de Browserbase desde la línea de comando. Prefiere la habilidad Navegador para navegación interactiva; use `bb Browse` solo cuando el usuario desee explícitamente la ruta CLI de Browserbase.
