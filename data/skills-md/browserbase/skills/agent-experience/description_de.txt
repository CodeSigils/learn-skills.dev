Überprüfen Sie die Entwicklererfahrung eines Produkts, eines SDK, einer Dokumentationsseite oder von SKILL.md, indem Sie mehrere Claude-Subagenten mit nur einer winzigen Task-Eingabeaufforderung und echten Tools (WebFetch, Bash, Write) darauf platzieren. Agenten müssen die Dokumente selbst entdecken, Deps installieren, bei Bedarf nach Anmeldeinformationen fragen und eine echte Ausführung versuchen. Der Skill erfasst die Ablaufverfolgung jedes Agenten – Werkzeugaufrufe, Wiederholungsversuche, Wartezeit, Fehler – und bewertet Setup-Reibung, Geschwindigkeit, Effizienz, Fehlerbehebung und Dokumentqualität. Anschließend wird ein HTML-Bericht mit der Note A–F und konkreten Korrekturen ausgegeben. Verwenden Sie diese Option, wenn der Benutzer die Agentenerfahrung prüfen, einen Skill testen, Dokumente für Agenten prüfen, prüfen möchte, ob ein SDK agentenfreundlich ist, ein SKILL.md validieren, die Agenten-DX messen oder vergleichen möchte, wie schmerzhaft das Onboarding für einen KI-Agenten ist. Auslöser: „Agentenerfahrung prüfen“, „Diese Fertigkeit testen“, „Dokumente für Agenten prüfen“, „Ist mein SDK agentenfreundlich“, „DX-Audit durchführen“, „Agentenerfahrungstest“, „Meine Dokumente testen“, „Wie gehen Agenten mit meinem Produkt um?“.
