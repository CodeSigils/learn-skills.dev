Проведите аудит опыта разработки продукта, SDK, сайта документации или SKILL.md, подключив к нему несколько субагентов Claude, используя лишь небольшую подсказку задачи и реальные инструменты (WebFetch, Bash, Write). Агенты должны сами обнаружить документы, установить deps, запросить учетные данные, если это необходимо, и попытаться выполнить реальное выполнение. Этот навык фиксирует трассировку каждого агента — вызовы инструментов, повторные попытки, время ожидания, ошибки — и оценки по трудностям при настройке, скорости, эффективности, устранению ошибок и качеству документа, а затем выдает отчет в формате HTML с оценкой A–F и конкретными исправлениями. Используйте, когда пользователь просит провести аудит работы агента, проверить навыки, проверить документацию для агентов, проверить, удобен ли SDK для агентов, проверить SKILL.md, измерить DX агента или оценить, насколько болезненной является адаптация для агента ИИ. Триггеры: «проверить опыт агента», «проверить этот навык», «проверить документы для агентов», «удобен ли мой SDK для агентов», «провести DX-аудит», «проверить опыт агента», «проверить мои документы», «как агенты справляются с моим продуктом».
