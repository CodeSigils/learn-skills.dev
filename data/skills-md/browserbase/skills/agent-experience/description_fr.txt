Auditez l'expérience du développeur d'un produit, d'un SDK, d'un site de documentation ou de SKILL.md en y déposant plusieurs sous-agents Claude avec seulement une petite invite de tâche et de vrais outils (WebFetch, Bash, Write). Les agents doivent découvrir les documents eux-mêmes, installer les services, demander des informations d'identification si nécessaire et tenter une véritable exécution. La compétence capture la trace de chaque agent (appels d'outils, tentatives, temps passé sur le mur, erreurs) et les scores en matière de friction de configuration, de vitesse, d'efficacité, de récupération d'erreur et de qualité de document, puis émet un rapport HTML avec une note A à F et des correctifs concrets. À utiliser lorsque l'utilisateur demande à auditer l'expérience d'un agent, à tester une compétence, à auditer des documents pour les agents, à vérifier si un SDK est convivial pour les agents, à valider un SKILL.md, à mesurer le DX d'un agent ou à évaluer à quel point l'intégration est pénible pour un agent IA. Déclencheurs : « auditer l'expérience de l'agent », « tester cette compétence », « auditer les documents pour les agents », « mon SDK est-il convivial pour les agents », « exécuter un audit DX », « tester l'expérience de l'agent », « tester mes documents », « comment les agents utilisent mon produit ».
