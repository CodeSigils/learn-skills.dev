Trasforma il traffico HTTP osservabile di un sito web in una specifica OpenAPI 3.1 ottimale analizzando un'acquisizione di "traccia del browser". Da utilizzare quando l'utente desidera individuare/estrarre endpoint API da una sessione del browser, creare un documento OpenAPI dal traffico di rete o documentare la superficie XHR/recupero di un sito di terze parti per l'integrazione del client.
