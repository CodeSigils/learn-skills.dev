Превратите наблюдаемый HTTP-трафик веб-сайта в максимально эффективную спецификацию OpenAPI 3.1, проанализировав запись трассировки браузера. Используйте, когда пользователь хочет обнаружить или извлечь конечные точки API из сеанса браузера, создать документ OpenAPI на основе сетевого трафика или задокументировать поверхность XHR/выборки стороннего сайта для интеграции клиента.
