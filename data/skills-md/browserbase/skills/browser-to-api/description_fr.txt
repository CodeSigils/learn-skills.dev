Transformez le trafic HTTP observable d'un site Web en une spécification OpenAPI 3.1 au mieux en analysant une capture de « trace du navigateur ». À utiliser lorsque l'utilisateur souhaite découvrir/extraire les points de terminaison d'API d'une session de navigateur, créer un document OpenAPI à partir du trafic réseau ou documenter la surface XHR/récupérer d'un site tiers pour l'intégration client.
