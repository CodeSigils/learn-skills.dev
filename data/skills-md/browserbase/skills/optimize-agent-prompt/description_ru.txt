Создает и улучшает демонстрационные версии API агента Browserbase с помощью внешнего цикла в стиле автоматического просмотра: запускает фиксированную задачу, собирает сообщения агента и журналы сеансов, оценивает результат, проверяет одну эвристику системного запроса и подтверждает сходимость. Используйте при создании демо-версии агентов базы браузера или POC, оптимизации системного приглашения агента, диагностике нестабильного запуска агента или применении автоматического исследования/автообзора к API агентов базы браузера.
