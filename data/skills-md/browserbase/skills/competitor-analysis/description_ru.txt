Навыки исследования конкурентов и разведки. Принимает компанию пользователя (с дополнительным
URL-адреса конкурентов), автоматически обнаруживает дополнительных конкурентов через API поиска в базе браузера,
глубоко исследует каждый из них, используя четырехполосную схему (маркетинговая поверхность, внешний сигнал,
общедоступные тесты, стратегические различия по сравнению с компанией пользователя) и компилирует результаты
в отчет HTML с четырьмя представлениями: обзор, подробное описание каждого конкурента, параллельное представление.
матрица функций/цен и хронологическая лента упоминаний (новости, обзоры,
социальные сети, страницы сравнения и общедоступные тесты).
Используйте, когда пользователь хочет: (1) проанализировать конкурентов, (2) построить конкурентную матрицу,
(3) извлечь цены/функции конкурентов, (4) найти страницы сравнения и в Интернете.
упоминания конкурентов, (5) поверхностные публичные ориентиры. Триггеры: «анализ конкурентов»,
«анализ конкурентов», «конкурентная информация», «исследования конкурентов», «цены конкурентов»,
«Сравнение функций», «Сравнение цен», «Найти сравнения», «Кто нас сравнивает»,
«упоминания конкурентов», «оценки конкурентов».
