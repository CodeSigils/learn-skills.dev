Test dell'interfaccia utente antagonista basato sull'intelligenza artificiale tramite la CLI di navigazione. Analizza le differenze git per testare solo ciò che è cambiato o esplora l'app completa per trovare bug. Verifica la correttezza funzionale, l'accessibilità, il layout reattivo e l'euristica UX. Da utilizzare quando l'utente chiede di testare le modifiche dell'interfaccia utente, eseguire il QA di una richiesta pull, controllare l'accessibilità o eseguire test esplorativi. Supporta browser locale (localhost) e Browserbase remoto (siti distribuiti).
