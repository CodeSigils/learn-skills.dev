Analice una aplicación web existente, identifique capacidades visibles para el usuario seguras en rutas, formularios, acciones del servidor, controladores y esquemas, luego implemente herramientas WebMCP propias y valide el descubrimiento y la invocación con Stagehand. Úselo cuando el usuario solicite preparar un agente de base de código, exponer las características del sitio web como herramientas WebMCP o agregar WebMCP directamente a una aplicación en lugar de generar un script de inyección independiente desde una URL.
