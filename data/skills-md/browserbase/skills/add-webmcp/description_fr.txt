Analysez une application Web existante, identifiez les fonctionnalités sécurisées visibles par l'utilisateur à travers les itinéraires, les formulaires, les actions du serveur, les gestionnaires et les schémas, puis implémentez les outils WebMCP propriétaires et validez la découverte et l'invocation avec Stagehand. À utiliser lorsque l'utilisateur demande de préparer un agent de base de code, d'exposer les fonctionnalités d'un site Web en tant qu'outils WebMCP ou d'ajouter WebMCP directement à une application plutôt que de générer un script d'injection autonome à partir d'une URL.
