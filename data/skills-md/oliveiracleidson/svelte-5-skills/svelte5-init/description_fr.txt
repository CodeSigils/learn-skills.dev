Élabore une nouvelle application Svelte 5 ou SvelteKit avec Tailwind CSS v4, TypeScript et la configuration de l'adaptateur de déploiement. À utiliser lorsque l'utilisateur souhaite créer, initialiser ou démarrer un nouveau projet Svelte 5, une application SvelteKit ou pose des questions sur la configuration du projet avec Tailwind. Prend en charge les cibles de déploiement telles que Cloudflare, Vercel, Netlify, Node et les sites statiques.
