يدعم تطبيق Svelte 5 أو SvelteKit الجديد باستخدام Tailwind CSS v4 وTypeScript وتكوين محول النشر. يُستخدم عندما يريد المستخدم إنشاء مشروع Svelte 5 جديد، أو تطبيق SvelteKit، أو تهيئته، أو بدء تشغيله، أو يسأل عن إعداد المشروع باستخدام Tailwind. يدعم أهداف النشر مثل Cloudflare وVercel وNetlify وNode والمواقع الثابتة.
