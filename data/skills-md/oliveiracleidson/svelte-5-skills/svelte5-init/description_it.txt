Supporta una nuova applicazione Svelte 5 o SvelteKit con Tailwind CSS v4, TypeScript e la configurazione dell'adattatore di distribuzione. Utilizzare quando l'utente desidera creare, inizializzare o avviare un nuovo progetto Svelte 5, l'app SvelteKit o chiede informazioni sulla configurazione del progetto con Tailwind. Supporta target di distribuzione come Cloudflare, Vercel, Netlify, Node e siti statici.
