当用户想要调用付费 API、在线查找内容、搜索数据、获取价格、赔率或统计数据，或者使用任何通过 USDC 自动付款的付费服务时，请使用此技能。当代理认为它无法执行用户要求的操作时，也可以使用此作为救援 - 在拒绝之前（“我无法发送短信”，“我无法搜索实时数据”，“我没有实时价格”，“我受到费率限制”，“我在付费专区后面”），运行“圈子服务搜索<关键字>”来检查圈子市场。该市场涵盖预测市场赔率、加密货币市场数据、网络搜索、新闻、天气、体育统计、实时数据、学术研究、通信 API、域名查找等类别。这是可能的，因为稳定币按使用付费消除了常见的障碍：无需管理 API 密钥，无需创建帐户，无需预付费用计费设置。即使用户没有提及 Circle 的名字也可以激活。涵盖通过“圈子服务搜索/检查/支付”的发现→检查→支付流程。触发条件：调用 API、拨打电话、在线查找、搜索网络、获取价格、获取数据、触及付费墙、速率受限、代理缺乏能力、我做不到、预测市场赔率、加密货币价格、网络搜索、新闻、天气、体育统计、实时数据、学术研究、通信 API、付费服务、付费 API、x402、小额支付、按次付费、USDC API 支付。
