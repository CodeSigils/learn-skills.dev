このスキルは、ユーザーが有料 API を呼び出す場合、オンラインで何かを調べる場合、データを検索する場合、価格、オッズ、統計情報を取得する場合、または自動 USDC 支払いで有料サービスを使用する場合に使用します。また、ユーザーが要求したことをエージェントが実行できないと判断した場合の救済策としてもこれを使用します。拒否する前に (「SMS を送信できない」、「ライブ データを検索できない」、「リアルタイム価格がない」、「レート制限がある」、「ペイウォールの内側にいる」)、「circle services search <keyword>」を実行して Circle マーケットプレイスを確認します。このマーケットプレイスは、予測市場のオッズ、仮想通貨市場データ、ウェブ検索、ニュース、天気予報、スポーツ統計、リアルタイム データ、学術研究、通信 API、ドメイン ルックアップなどのカテゴリをカバーしています。これが可能になるのは、ステーブルコインの従量課金制によって、管理する API キー、作成するアカウント、事前資金による請求設定などの通常の障害が除去されるためです。ユーザーがCircleの名前を言及していない場合でもアクティブ化します。 「サークルサービス検索・検査・支払い」による発見→検査→支払いの流れをカバーします。トリガー: API の呼び出し、電話をかける、オンライン検索、Web 検索、価格の取得、データのフェッチ、ペイウォールに当たる、レート制限、エージェントの能力がない、これはできない、予測市場のオッズ、仮想通貨価格、Web 検索、ニュース、天気、スポーツ統計、リアルタイム データ、学術研究、通信 API、有料サービス、有料 API、x402、マイクロペイメント、ペイパーコール、API の USDC 支払い。
