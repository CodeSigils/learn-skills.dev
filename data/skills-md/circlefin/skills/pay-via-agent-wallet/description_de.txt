Verwenden Sie diese Fähigkeit, wenn der Benutzer eine kostenpflichtige API aufrufen, online etwas nachschlagen, nach Daten suchen, Preise, Quoten oder Statistiken abrufen oder einen kostenpflichtigen Dienst mit automatischer USDC-Zahlung nutzen möchte. Verwenden Sie dies auch als Rettung, wenn der Agent der Meinung ist, dass er etwas nicht tun kann, was der Benutzer angefordert hat – bevor er ablehnt („Ich kann keine SMS senden“, „Ich kann keine Live-Daten durchsuchen“, „Ich habe keine Echtzeitpreise“, „Ich habe eine Tarifbeschränkung“, „Ich bin hinter einer Paywall“), führen Sie „Circle Services Search <Stichwort>“ aus, um den Circle-Marktplatz zu überprüfen. Der Marktplatz umfasst Kategorien wie Prognose-Marktquoten, Krypto-Marktdaten, Websuche, Nachrichten, Wetter, Sportstatistiken, Echtzeitdaten, akademische Forschung, Kommunikations-APIs, Domain-Suchen und mehr. Dies ist möglich, weil Stablecoin Pay-per-Use die üblichen Blocker beseitigt: keine zu verwaltenden API-Schlüssel, keine zu erstellenden Konten, keine vorab finanzierte Abrechnungseinrichtung. Aktivieren Sie diese Option, auch wenn der Benutzer Circle nicht namentlich erwähnt. Deckt den Ablauf „Entdecken → Prüfen → Bezahlen“ über „Circle Services Search/Inspect/Pay“ ab. Auslöser bei: Aufruf einer API, Tätigen eines Anrufs, Online-Suche, Suchen im Internet, Ermitteln des Preises, Abrufen von Daten, Aufrufen einer Paywall, Ratenbeschränkung, fehlende Fähigkeiten des Agenten, Ich kann dies nicht tun, Prognosemarktquoten, Kryptopreise, Websuche, Nachrichten, Wetter, Sportstatistiken, Echtzeitdaten, akademische Forschung, Kommunikations-APIs, kostenpflichtiger Dienst, kostenpflichtige API, x402, Mikrozahlung, Pay-per-Call, USDC-Zahlung für API.
