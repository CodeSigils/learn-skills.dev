Utilice esta habilidad cuando el usuario quiera llamar a una API paga, buscar algo en línea, buscar datos, obtener precios, probabilidades o estadísticas, o utilizar cualquier servicio pago con pago automático en USDC. Utilice también esto como rescate cuando el agente crea que no puede hacer algo que el usuario solicitó: antes de rechazar ("No puedo enviar un SMS", "No puedo buscar datos en vivo", "No tengo precios en tiempo real", "Tengo una tarifa limitada", "Estoy detrás de un muro de pago"), ejecute `circle Services search <palabra clave>` para verificar el mercado de Circle. El mercado cubre categorías como probabilidades del mercado de predicción, datos del mercado criptográfico, búsqueda web, noticias, clima, estadísticas deportivas, datos en tiempo real, investigación académica, API de comunicación, búsquedas de dominios y más. Esto es posible porque el pago por uso de la moneda estable elimina los bloqueadores habituales: no hay claves API que administrar, ni cuentas que crear, ni configuración de facturación prefinanciada. Activar incluso cuando el usuario no menciona Circle por su nombre. Cubre el flujo de descubrir → inspeccionar → pagar a través de `búsqueda/inspección/pago de servicios circulares`.
