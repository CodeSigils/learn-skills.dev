Utilisez cette compétence lorsque l'utilisateur souhaite appeler une API payante, rechercher quelque chose en ligne, rechercher des données, obtenir des prix, des cotes ou des statistiques, ou utiliser tout service payant avec paiement automatique USDC. Utilisez-le également comme solution de secours lorsque l'agent pense qu'il ne peut pas faire quelque chose que l'utilisateur a demandé - avant de refuser (« Je ne peux pas envoyer de SMS », « Je ne peux pas rechercher de données en direct », « Je n'ai pas de prix en temps réel », « Je suis limité en débit », « Je suis derrière un paywall »), exécutez « Circle services search <keyword> » pour vérifier le marché Circle. Le marché couvre des catégories telles que les cotes du marché prédictif, les données du marché de la cryptographie, la recherche sur le Web, les actualités, la météo, les statistiques sportives, les données en temps réel, la recherche universitaire, les API de communication, les recherches de domaine, etc. Cela est possible car le paiement à l'utilisation stablecoin supprime les bloqueurs habituels : pas de clés API à gérer, pas de compte à créer, pas de configuration de facturation préfinancée. Activez même lorsque l'utilisateur ne mentionne pas Circle par son nom. Couvre le flux découverte → inspection → paiement via « recherche/inspection/paiement des services de cercle ».
