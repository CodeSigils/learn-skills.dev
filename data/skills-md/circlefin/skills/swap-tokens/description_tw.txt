使用 Circle App Kit 或獨立 Swap Kit SDK 建立代幣交換功能。 App Kit (`@circle-fin/app-kit`) 是一個包羅萬象的 SDK，涵蓋交換、橋接和發送——推薦用於擴展性。交換套件（`@circle-fin/swap-kit`）是用於僅交換用例的獨立套件。兩者都需要套件密鑰並且僅在伺服器端運行。 Swap 僅適用於主網（不支援測試網）。支援同鏈交換。對於跨鏈代幣移動，使用 App Kit 將單獨的交換和橋接呼叫結合（將 tokenA 交換到 USDC、橋接 USDC、將 USDC 交換到 tokenB）。使用場合：交換代幣、交換穩定幣、將 USDT 轉換為 USDC、設定交換適配器（Viem、Solana Kit、Circle Wallets）、估計交換率、配置滑點或止損限制、收取自訂交換費用，或將交換和橋接相結合以進行跨鏈代幣移動。觸發：交換代幣、代幣交換、App Kit、Swap Kit、@circle-fin/app-kit、@circle-fin/swap-kit、USDT 至 USDC、交換 USDC、交換穩定幣、estimateSwap、滑點、停損限額、套件金鑰、交換費用。
