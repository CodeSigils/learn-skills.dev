أنشئ وظيفة مبادلة الرمز المميز باستخدام Circle App Kit أو مجموعات Swap Kit SDK المستقلة. مجموعة التطبيقات (`@circle-fin/app-kit`) عبارة عن حزمة SDK شاملة تغطي المبادلة والجسر والإرسال - يوصى بها للتوسع. Swap Kit (`@circle-fin/swap-kit`) عبارة عن حزمة مستقلة لحالات استخدام المبادلة فقط. كلاهما يتطلب مفتاح مجموعة ويعملان من جانب الخادم فقط. المبادلة مخصصة للشبكة الرئيسية فقط (لا يوجد دعم لشبكة الاختبار). يدعم مقايضات نفس السلسلة. بالنسبة لحركة الرمز المميز عبر السلسلة، اجمع بين مكالمات المبادلة والجسر المنفصلة باستخدام App Kit (مبادلة الرمز A إلى USDC، وجسر USDC، ومبادلة USDC إلى tokenB). يُستخدم عندما: مبادلة الرموز المميزة، أو تبادل العملات المستقرة، أو تحويل USDT إلى USDC، أو إعداد محولات المبادلة (Viem، أو Solana Kit، أو Circle Wallets)، أو تقدير معدلات المبادلة، أو تكوين حدود الانزلاق أو التوقف، أو جمع رسوم المبادلة المخصصة، أو الجمع بين المبادلة والجسر لحركة الرمز المميز عبر السلسلة. يتم تشغيلها على: مبادلة الرموز المميزة، وتبادل الرموز المميزة، ومجموعة التطبيقات، ومجموعة Swap، و@circle-fin/app-kit، و@circle-fin/swap-kit، وUSDT إلى USDC، ومبادلة USDC، ومبادلة العملة المستقرة، وتخمين Swap، والانزلاق، وحد التوقف، ومفتاح المجموعة، ورسوم المبادلة.
