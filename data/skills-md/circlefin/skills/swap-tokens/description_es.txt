Cree una funcionalidad de intercambio de tokens con Circle App Kit o SDK de Swap Kit independientes. App Kit (`@circle-fin/app-kit`) es un SDK con todo incluido que cubre intercambio, puente y envío, recomendado para extensibilidad. Swap Kit (`@circle-fin/swap-kit`) es un paquete independiente para casos de uso de solo intercambio. Ambos requieren una clave de kit y se ejecutan únicamente en el lado del servidor. El intercambio es solo para la red principal (no es compatible con la red de prueba). Admite intercambios en la misma cadena. Para el movimiento de tokens entre cadenas, combine llamadas de intercambio y puente separadas usando el App Kit (intercambie tokenA por USDC, intercambie USDC, intercambie USDC por tokenB). Úselo cuando: intercambie tokens, intercambie monedas estables, convierta USDT a USDC, configure adaptadores de intercambio (Viem, Solana Kit, Circle Wallets), calcule tasas de intercambio, configure límites de deslizamiento o detención, cobre tarifas de intercambio personalizadas o combine intercambio y puente para el movimiento de tokens entre cadenas.
