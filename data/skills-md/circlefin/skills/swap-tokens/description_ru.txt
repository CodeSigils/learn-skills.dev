Создайте функцию обмена токенов с помощью Circle App Kit или отдельных SDK Swap Kit. App Kit (@circle-fin/app-kit`) — это комплексный SDK, охватывающий обмен, мост и отправку. Рекомендуется для расширения. Swap Kit (@circle-fin/swap-kit`) — это отдельный пакет, предназначенный только для случаев использования подкачки. Оба требуют ключа комплекта и работают только на стороне сервера. Swap предназначен только для основной сети (без поддержки тестовой сети). Поддерживает обмены в одной цепочке. Для перемещения токенов между цепочками объедините отдельные вызовы свопа и моста с помощью App Kit (замена токена A на USDC, соединение USDC, замена USDC на токен B). Используйте, когда: обмениваете токены, обмениваете стейблкоины, конвертируете USDT в USDC, настраиваете адаптеры свопа (Viem, Solana Kit, Circle Wallets), оцениваете курсы свопа, настраиваете лимиты проскальзывания или стопа, взимаете специальные комиссии за своп или объединяете своп и мост для перемещения токенов между цепочками.
