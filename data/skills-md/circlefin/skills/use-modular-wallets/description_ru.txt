Создавайте криптокошельки с помощью Circle Modular Wallets SDK с аутентификацией по паролю, безгазовыми транзакциями и расширяемой архитектурой модулей. Используйте при: создании криптокошельков с регистрацией и входом на основе ключа доступа (WebAuthn), отправке безгазовых транзакций с помощью платежного мастера Circle Gas Station, группировании нескольких транзакций в одну пользовательскую операцию, реализации восстановления ключа доступа с использованием мнемонических фраз BIP-39, создании расширенных сетевых кошельков с настраиваемыми модулями (мультиподписи, подписки, сеансовые ключи). Запускается по: модульному кошельку, смарт-аккаунту, MSCA, аутентификации по ключу доступа, WebAuthn, без газа, платежному мастеру, заправочной станции, клиенту пакета, операциям пользователя, userOp, ERC-4337, ERC-6900, абстракции учетной записи, toCircleSmartAccount, toPasskeyTransport, toModularTransport, sendUserOperation, пакетным транзакциям, 2D nonce, восстановлению пароля, поставщику EIP-1193.
