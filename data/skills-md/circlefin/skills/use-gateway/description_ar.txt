قم بدمج Circle Gateway للاحتفاظ برصيد USDC موحد عبر العديد من سلاسل الكتل ونقل USDC على الفور (أقل من 500 مللي ثانية) عبر عمليات الإيداع والحرق وسك العملة بدون إذن. متوفر في 11 سلسلة EVM + Solana (الشبكة الرئيسية وشبكة الاختبار)، بالإضافة إلى شبكة اختبار Arc. يُستخدم عندما: تمكين تجارب المستخدم غير المرتبطة بالسلسلة، أو الحاجة إلى زمن وصول منخفض أو نهائية الكتلة التالية الفورية، أو الحاجة إلى تجميع رأس المال عبر السلاسل لزيادة كفاءة رأس المال، أو إنشاء تطبيقات بأرصدة سلسلة مشتركة موحدة. المشغلات على: البوابة، الرصيد الموحد، Crosschain USDC، التحويل الفوري، تجريد السلسلة، Gateway Wallet، Gateway Minter، GatewayMint، نية الحرق، سيولة crosschain، توجيه الدفع، كفاءة رأس المال، التحويل بدون إذن.
