Cree una gestión unificada del saldo USDC entre cadenas con el SDK de Circle Unified Balance Kit a través del App Kit (`@circle-fin/app-kit`) o de forma independiente (`@circle-fin/unified-balance-kit`). Consultas de depósitos, gastos y saldos de Abstracts Gateway en llamadas SDK simples: no se requiere interacción directa con el contrato, firma EIP-712 ni sondeo de certificación. Se recomienda App Kit para lograr extensibilidad entre intercambio, puente, envío y saldo unificado. El kit de equilibrio unificado independiente proporciona la misma superficie API en un paquete más liviano. Ninguno de los dos requiere una clave de kit para operaciones de saldo unificado. Admite cadenas EVM y Solana mediante paquetes de adaptadores. Úselo cuando: deposite USDC en un saldo unificado, gaste desde un saldo unificado en cualquier cadena admitida, verifique el saldo unificado entre cadenas, configure adaptadores del kit de saldo unificado (Viem, Solana, Circle Wallets), administre delegados para la separación de cuentas o cree flujos de pago de USDC abstractos en cadena.
