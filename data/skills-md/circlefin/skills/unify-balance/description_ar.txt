أنشئ إدارة موحدة لرصيد USDC عبر السلسلة باستخدام Circle Unified Balance Kit SDK عبر App Kit (`@circle-fin/app-kit`) أو مستقل (`@circle-fin/unified-balance-kit`). استعلامات الإيداع والإنفاق والتوازن في بوابة الملخصات في مكالمات SDK البسيطة - لا يلزم تفاعل عقد مباشر أو توقيع EIP-712 أو استقصاء التصديق. يوصى باستخدام App Kit للتوسيع عبر المبادلة والجسر والإرسال والرصيد الموحد. توفر مجموعة Unified Balance Kit المستقلة نفس سطح API في حزمة أخف. ولا يتطلب أي منهما مفتاح مجموعة لعمليات التوازن الموحدة. يدعم سلاسل EVM وSolana عبر حزم المحولات. يُستخدم عندما: إيداع USDC في رصيد موحد، أو الإنفاق من رصيد موحد إلى أي سلسلة مدعومة، أو التحقق من الرصيد الموحد عبر السلاسل، أو إعداد محولات Unified Balance Kit (Viem، أو Solana، أو Circle Wallets)، أو إدارة المفوضين لفصل الحساب، أو بناء تدفقات دفع USDC مجردة من السلسلة. يتم التشغيل على: الرصيد الموحد، Unified Balance Kit، UnifiedBalanceKit، @circle-fin/unified-balance-kit، إيداع USDC موحد، إنفاق رصيد موحد، getBalances، Cross-chain USDC SDK، سلسلة SDK التجريدية، محول viem، محول solana، DepositFor، addDelegate، USDC الموحد.
