Créez une gestion unifiée des soldes USDC inter-chaînes avec le SDK Circle Unified Balance Kit via App Kit (`@circle-fin/app-kit`) ou de manière autonome (`@circle-fin/unified-balance-kit`). Abstracts Gateway dépose des requêtes de dépôt, de dépenses et de solde dans de simples appels SDK : aucune interaction contractuelle directe, signature EIP-712 ou interrogation d'attestation n'est requise. App Kit est recommandé pour l’extensibilité sur les échanges, les ponts, les envois et l’équilibre unifié. Le kit autonome Unified Balance fournit la même surface API dans un package plus léger. Aucun des deux ne nécessite de clé de kit pour les opérations de balance unifiées. Prend en charge les chaînes EVM et Solana via des packages d'adaptateurs. À utiliser lorsque : déposer de l'USDC sur un solde unifié, dépenser à partir d'un solde unifié vers n'importe quelle chaîne prise en charge, vérifier le solde unifié entre les chaînes, configurer des adaptateurs Unified Balance Kit (Viem, Solana, Circle Wallets), gérer les délégués pour la séparation des comptes ou créer des flux de paiement USDC extraits de la chaîne. Déclencheurs sur : solde unifié, Unified Balance Kit, UnifiedBalanceKit, @circle-fin/unified-balance-kit, dépôt USDC unifié, dépenser un solde unifié, getBalances, SDK USDC inter-chaînes, SDK d'abstraction de chaîne, adaptateur-viem, adaptateur-solana, depositFor, addDelegate, USDC unifié.
