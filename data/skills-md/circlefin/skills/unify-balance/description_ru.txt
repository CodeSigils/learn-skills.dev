Создайте унифицированное межсетевое управление балансом USDC с помощью Circle Unified Balance Kit SDK через App Kit («@circle-fin/app-kit») или автономно («@circle-fin/unified-balance-kit»). Запросы Abstracts Gateway по депозитам, расходам и балансировке преобразуются в простые вызовы SDK — не требуется прямого взаимодействия с контрактом, подписания EIP-712 или опроса аттестации. App Kit рекомендуется для расширения возможностей обмена, моста, отправки и единого баланса. Автономный унифицированный балансовый комплект обеспечивает ту же поверхность API в более легком корпусе. Ни одному из них не требуется ключ комплекта для унифицированных операций с балансом. Поддерживает цепи EVM и Solana через пакеты адаптеров. Используйте, когда: вносите USDC в единый баланс, тратите деньги из единого баланса в любую поддерживаемую цепочку, проверяете единый баланс между цепочками, настраиваете адаптеры Unified Balance Kit (Viem, Solana, Circle Wallets), управляете делегатами для разделения счетов или строите абстрактные потоки платежей в USDC. Запускается по: единый баланс, Unified Balance Kit, UnifiedBalanceKit, @circle-fin/unified-balance-kit, единый депозит USDC, единый баланс расходов, getBalances, межсетевой SDK USDC, SDK абстракции цепочки, адаптер-вием, адаптер-солана, депозитФор, addDelegate, единый USDC.
