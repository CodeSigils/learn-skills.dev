通过 App Kit (`@circle-fin/app-kit`) 或独立 (`@circle-fin/unified-balance-kit`) 使用 Circle Unified Balance Kit SDK 构建统一的跨链 USDC 余额管理。将网关存款、支出和余额查询抽象为简单的 SDK 调用——无需直接合约交互、EIP-712 签名或证明轮询。建议使用 App Kit 来实现交换、桥接、发送和统一余额的可扩展性。独立统一平衡套件在更轻的包中提供相同的 API 表面。两者都不需要用于统一平衡操作的套件密钥。通过适配器包支持 EVM 链和 Solana。使用场合：将 USDC 存入统一余额、从统一余额支出到任何支持的链、检查跨链的统一余额、设置统一余额套件适配器（Viem、Solana、Circle Wallets）、管理账户分离的委托，或构建链抽象的 USDC 支付流程。触发条件：统一余额、统一余额套件、UnifiedBalanceKit、@circle-fin/unified-balance-kit、统一存入USDC、支出统一余额、getBalances、跨链USDC SDK、链抽象SDK、adapter-viem、adapter-solana、depositFor、addDelegate、统一USDC。
