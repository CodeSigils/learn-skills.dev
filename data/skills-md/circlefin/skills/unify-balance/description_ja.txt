アプリキット (`@circle-fin/app-kit`) またはスタンドアロン (`@circle-fin/unified-balance-kit`) 経由で Circle Unified Balance Kit SDK を使用して、統合されたクロスチェーン USDC 残高管理を構築します。ゲートウェイのデポジット、支出、バランスのクエリを単純な SDK 呼び出しに抽象化します。直接の契約対話、EIP-712 署名、または構成証明ポーリングは必要ありません。 App Kit は、スワップ、ブリッジ、送信、および統合バランスにわたる拡張性を実現するために推奨されます。スタンドアロンの Unified Balance Kit は、同じ API サーフェスを軽量のパッケージで提供します。どちらも、統合された天びん操作にキットキーを必要としません。アダプター パッケージを介して EVM チェーンと Solana をサポートします。次の場合に使用します: USDC を統合残高に入金する、統合残高からサポートされているチェーンへの支出、チェーン間の統合残高の確認、統合バランス キット アダプター (Viem、Solana、Circle Wallet) のセットアップ、アカウント分離のためのデリゲートの管理、またはチェーンで抽象化された USDC 支払いフローの構築。トリガー対象: 統合残高、統合バランスキット、UnifiedBalanceKit、@circle-fin/unified-balance-kit、統合されたUSDC の入金、統合残高の支出、getBalances、クロスチェーン USDC SDK、チェーン抽象化 SDK、adapter-viem、adapter-solana、depositFor、addDelegate、unified USDC。
