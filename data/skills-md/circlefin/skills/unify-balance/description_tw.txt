透過 App Kit (`@circle-fin/app-kit`) 或獨立 (`@circle-fin/unified-balance-kit`) 使用 Circle Unified Balance Kit SDK 建立統一的跨鏈 USDC 餘額管理。將網關存款、支出和餘額查詢抽象化為簡單的 SDK 呼叫—無需直接合約互動、EIP-712 簽章或證明輪詢。建議使用 App Kit 來實現交換、橋接、發送和統一餘額的可擴展性。獨立統一平衡套件在更輕的套件中提供相同的 API 表面。兩者都不需要用於統一平衡操作的套件密鑰。透過適配器包支援 EVM 鍊和 Solana。使用場合：將 USDC 存入統一餘額、從統一餘額支出到任何支援的鏈、檢查跨鏈的統一餘額、設定統一餘額套件適配器（Viem、Solana、Circle Wallets）、管理帳戶分離的委託，或構建鏈抽象的 USDC 支付流程。觸發條件：統一餘額、統一餘額套件、UnifiedBalanceKit、@circle-fin/unified-balance-kit、統一存入USDC、支出統一餘額、getBalances、跨鏈USDC SDK、鏈抽象SDK、adapter-viem、adapter-solana、depositFor、addDelegate、統一USDC。
