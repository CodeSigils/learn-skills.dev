Financez un portefeuille d'agent Circle avec USDC via la CLI « circle ». les paiements sont prélevés sur le gaz. les utilisateurs peuvent payer uniquement avec USDC, aucun ETH n'est requis. Couvre deux chemins de niveau supérieur : la rampe d'accès fiduciaire (acheter de l'USDC avec USD/carte de crédit) et le transfert cryptographique (envoyer l'USDC existant au portefeuille via QR ou adresse directe). Couvre également les dépôts Gateway (sous-chemins écologiques ou directs) pour le solde Nanopayments utilisé par les services payants. À utiliser lorsque l'utilisateur souhaite ajouter de l'USDC à son portefeuille d'agent, recharger après un solde faible, effectuer un dépôt sur Gateway ou choisir la bonne méthode de financement. Déclencheurs sur : portefeuille d'agent de fonds, portefeuille Fund Circle, fonds USDC, dépôt USDC, ajouter USDC, rampe d'accès fiat, acheter USDC, dépôt crypto, transfert de code QR, dépôt Gateway, dépôt écologique, dépôt direct, solde faible, recharger le portefeuille, retirer USDC, nanopaiements.
