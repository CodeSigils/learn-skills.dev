Richten Sie eine Circle-Agent-Wallet über die „Circle“-CLI ein und verwalten Sie sie. Das Agent Wallet ist das programmatische USDC-Wallet von Circle für KI-Agenten – es wird zur Authentifizierung, zum Halten von USDC und zum Bezahlen von x402-Diensten verwendet. Diese Fähigkeit umfasst die Überprüfung der CLI-Installation, die Annahme der Nutzungsbedingungen, die E-Mail- und OTP-Anmeldung, die Erstellung von Wallets, die Überprüfung des Sitzungsstatus und die Überprüfung des Kontostands. Verwenden Sie es immer dann, wenn der Benutzer sein Circle-Agent-Wallet einrichten, sich anmelden oder den Status überprüfen möchte, oder wenn eine nachgelagerte Fähigkeit (z. B. das Bezahlen eines x402-Dienstes oder die Finanzierung des Wallets) zuerst einen Bootstrapping des Wallets erfordert. Auslöser bei: Circle CLI, Agent Wallet, Circle Wallet-Status, Circle Wallet-Anmeldung, Circle Wallet erstellen, Circle Wallet-Liste, Circle Wallet-Guthaben, Circle einrichten, bei Circle anmelden, x402-Setup, Circle Agent Wallet, USDC für Agenten, Bedingungen akzeptieren, Circle CLI installieren.
