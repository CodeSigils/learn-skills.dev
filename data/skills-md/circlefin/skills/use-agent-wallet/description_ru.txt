Настройте и управляйте кошельком агента Circle через интерфейс командной строки «circle». Кошелек агента — это программный кошелек USDC компании Circle для агентов искусственного интеллекта, который используется для аутентификации, хранения долларов США и оплаты услуг x402. Этот навык охватывает проверку установки CLI, принятие условий использования, вход в систему по электронной почте + OTP, создание кошелька, проверку статуса сеанса и проверку баланса. Используйте всякий раз, когда пользователь хочет настроить, войти в систему или проверить состояние своего кошелька агента Circle, или когда для последующего навыка (например, оплаты услуги x402 или финансирования кошелька) требуется сначала загрузить кошелек. Запускается при: Circle CLI, кошельке агента, статусе кошелька Circle, входе в кошелек Circle, создании кошелька Circle, списке кошельков Circle, балансе кошелька Circle, настройке Circle, входе в Circle, настройке x402, кошельке Circle Agent, USDC для агентов, принятии условий, установке Circle CLI.
