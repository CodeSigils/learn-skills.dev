'circle' CLI를 통해 Circle 에이전트 지갑을 설정하고 관리하세요. 에이전트 지갑은 AI 에이전트를 위한 Circle의 프로그래밍 방식 USDC 지갑으로, USDC를 인증하고 보유하며 x402 서비스 비용을 지불하는 데 사용됩니다. CLI 설치 확인, 이용약관 동의, 이메일 + OTP 로그인, 지갑 생성, 세션 상태 확인, 잔액 조회 등을 담당하는 스킬입니다. 사용자가 Circle 에이전트 지갑 상태를 설정, 로그인 또는 검사하려고 할 때마다 또는 다운스트림 기술(예: x402 서비스 비용 지불 또는 지갑 자금 조달)에 지갑 부트스트랩이 먼저 필요할 때마다 사용합니다. 트리거: Circle CLI, 에이전트 지갑, 서클 지갑 상태, 서클 지갑 로그인, 서클 지갑 생성, 서클 지갑 목록, 서클 지갑 잔액, Circle 설정, Circle에 로그인, x402 설정, Circle Agent Wallet, 에이전트용 USDC, 약관 동의, Circle CLI 설치.
