Просматривайте политику расходов в кошельке агента Circle — ограничения USDC на каждую транзакцию, ежедневно, еженедельно и ежемесячно через интерфейс командной строки «circle». Используйте, когда пользователь хочет проверить текущие ограничения. Для установки или сброса лимитов требуется подтверждение OTP в интерактивном сеансе терминала — агент передает пользователю дословную команду для самостоятельного запуска; OTP никогда не должен проходить через хранилище агента. Только для основной сети — цепочки тестовой сети отклоняются. Срабатывает при: лимите расходов, политике расходов, лимите кошелька, пределе каждой транзакции, дневном лимите, еженедельном лимите, месячном лимите, установке лимита расходов, сбросе лимита расходов, правилах кошелька, лимите расходов, подтверждении OTP.
