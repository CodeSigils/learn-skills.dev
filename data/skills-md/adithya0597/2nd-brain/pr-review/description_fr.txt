Utilisez cette compétence lors de l'examen des modifications de code avant de vous engager dans main - toute demande d'examen d'une différence, d'audit des modifications récentes ou de validation du fait que les modifications respectent les conventions du projet. Cela inclut l'analyse du rayon d'explosion (quels modules importent le code modifié), l'analyse de sécurité (injection SQL dans les requêtes SQLite, exposition des informations d'identification, évaluation non sécurisée), le delta de couverture de test avec pytest, la détection des modifications de rupture (migrations de schéma de base de données, suppressions de clés de configuration, modifications de la hiérarchie ICOR) et l'évaluation de l'impact sur les performances (requêtes N+1, boucles illimitées, recalcul d'intégration). Produit une révision structurée avec les niveaux DOIT FIX, SHOULD FIX et SUGGESTIONS ainsi qu'une liste de contrôle spécifique au projet. Se distingue de l'audit de sécurité (qui analyse un répertoire entier pour vérifier la sécurité de l'installation, pas une différence de validation) et de l'agent simplificateur de code (qui refactorise pour plus de clarté, pas d'exactitude ou de sécurité).
