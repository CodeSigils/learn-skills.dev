Utilice esta habilidad al revisar cambios de código antes de comprometerse con main: cualquier solicitud para revisar una diferencia, auditar cambios recientes o validar que las modificaciones sigan las convenciones del proyecto. Esto incluye análisis del radio de explosión (qué módulos importan el código modificado), escaneo de seguridad (inyección de SQL en consultas SQLite, exposición de credenciales, evaluación insegura), delta de cobertura de prueba con pytest, detección de cambios importantes (migraciones de esquemas de base de datos, eliminaciones de claves de configuración, cambios en la jerarquía ICOR) y evaluación del impacto en el rendimiento (consultas N+1, bucles ilimitados, recálculo de incrustación). Produce una revisión estructurada con niveles DEBE REPARAR, DEBE REPARAR y SUGERENCIAS, además de una lista de verificación específica del proyecto. Se distingue de la auditoría de seguridad (que escanea un directorio completo para comprobar la seguridad de la instalación, no una diferencia de confirmación) y del agente simplificador de código (que refactoriza para mayor claridad, no corrección o seguridad).
