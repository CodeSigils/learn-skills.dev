Verwenden Sie diese Fähigkeit, wenn Sie Codeänderungen überprüfen, bevor Sie sie an main übergeben – jede Anfrage zur Überprüfung eines Diffs, zur Prüfung aktueller Änderungen oder zur Validierung, dass Änderungen den Projektkonventionen entsprechen. Dazu gehören die Blast-Radius-Analyse (welche Module den geänderten Code importieren), Sicherheitsscans (SQL-Injection in SQLite-Abfragen, Offenlegung von Anmeldeinformationen, unsichere Auswertung), Testabdeckungsdelta mit Pytest, Erkennung von Breaking Changes (DB-Schema-Migrationen, Entfernung von Konfigurationsschlüsseln, ICOR-Hierarchieänderungen) und Leistungsauswirkungsbewertung (N+1-Abfragen, unbegrenzte Schleifen, Einbettungsneuberechnung). Erstellt eine strukturierte Überprüfung mit den Stufen MUST FIX, SOLLD FIX und SUGGESTIONS sowie einer projektspezifischen Checkliste. Unterscheidet sich vom Sicherheitsaudit (das ein gesamtes Verzeichnis auf Installationssicherheit überprüft, nicht auf einen Commit-Diff) und vom Code-Simplifier-Agenten (der die Umgestaltung auf Klarheit und nicht auf Korrektheit oder Sicherheit ausrichtet).
