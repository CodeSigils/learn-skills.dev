Обновите CHANGELOG.md пакета Dart/Flutter, вычислив изменения между предыдущим выпущенным тегом git и текущей веткой/HEAD. Используйте это всякий раз, когда пользователь просит «найти изменения с момента последнего тега выпуска», «создать/обновить примечания к выпуску», «обновить CHANGELOG.md» или «что изменилось между версиями» для папки пакета в репозитории git (особенно пакетов Flutter/Dart).
