Mettez à jour le fichier CHANGELOG.md d'un package Dart/Flutter en calculant les modifications entre la balise git publiée précédemment et la branche/HEAD actuelle. Utilisez-le chaque fois que l'utilisateur demande « rechercher les modifications depuis la dernière balise de version », « générer/mettre à jour les notes de version », « mettre à jour CHANGELOG.md » ou « ce qui a changé entre les versions » pour un dossier de package dans un dépôt git (en particulier les packages Flutter/Dart).
