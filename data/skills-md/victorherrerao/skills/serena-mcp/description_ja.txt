セマンティック コード分析、インテリジェントなコード編集、リファクタリング、アーキテクチャ分析、またはコードベース プロジェクト作業のために Serena MCP ツールを使用して作業するときは常に、このスキルを使用してください。ユーザーがコード構造の理解、シンボルや参照の検索、コードベース全体でのパターンの検索、コードの名前変更またはリファクタリングの安全な実行、モジュールの依存関係の分析、コード品質チェックの実行、アーキテクチャのマップ、コードからドキュメントの生成、または Serena を使用したコード プロジェクトでの複数ステップのワークフローの実行を行う場合に、このスキルをトリガーします。 Serena MCP ツールが利用可能で、タスクにコードの探索、理解、または編集が含まれる場合は、ユーザーが明示的に「Serena を使用する」と言わなくても、常にこのスキルを使用してください。
