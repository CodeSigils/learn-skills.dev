استخدم هذه المهارة عند العمل باستخدام أدوات Serena MCP لتحليل التعليمات البرمجية الدلالية، أو التحرير الذكي للتعليمات البرمجية، أو إعادة البناء، أو تحليل البنية، أو أي عمل في مشروع قاعدة التعليمات البرمجية. قم بتشغيل هذه المهارة عندما يريد المستخدم فهم بنية التعليمات البرمجية، أو العثور على رموز أو مراجع، أو أنماط البحث عبر قاعدة تعليمات برمجية، أو إعادة تسمية التعليمات البرمجية أو إعادة تصميمها بأمان، أو تحليل تبعيات الوحدة، أو تشغيل فحوصات جودة التعليمات البرمجية، أو هندسة الخرائط، أو إنشاء وثائق من التعليمات البرمجية، أو تنفيذ أي سير عمل متعدد الخطوات في مشروع تعليمات برمجية باستخدام Serena. استخدم هذه المهارة دائمًا عندما تكون أدوات Serena MCP متاحة وكانت المهمة تتضمن استكشاف التعليمات البرمجية أو فهمها أو تحريرها - حتى لو لم يقل المستخدم صراحةً "استخدم Serena".
