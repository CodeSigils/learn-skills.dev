Utilice esta habilidad siempre que trabaje con las herramientas de Serena MCP para análisis de código semántico, edición de código inteligente, refactorización, análisis de arquitectura o cualquier trabajo de proyecto de base de código. Active esta habilidad cuando el usuario desee comprender la estructura del código, encontrar símbolos o referencias, buscar patrones en una base de código, cambiar el nombre o refactorizar el código de forma segura, analizar las dependencias de los módulos, ejecutar comprobaciones de calidad del código, mapear la arquitectura, generar documentación a partir del código o realizar cualquier flujo de trabajo de varios pasos en un proyecto de código utilizando Serena. Utilice siempre esta habilidad cuando las herramientas de Serena MCP estén disponibles y la tarea implique explorar, comprender o editar código, incluso si el usuario no dice explícitamente "use Serena".
