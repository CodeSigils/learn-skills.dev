Интегрируйте бронирование/захват потенциальных клиентов и отслеживание конверсий Apointoo в любой веб-проект. Используйте при добавлении формы для потенциальных клиентов Apointoo, вызове API приема Apointoo или подключении отслеживания конверсий GTM для клиента Apointoo. Независимый от языка (HTTP) с рецептом GTM/dataLayer.
