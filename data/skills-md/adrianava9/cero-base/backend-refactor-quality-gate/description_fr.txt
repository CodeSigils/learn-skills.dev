Porte de qualité pour les refactors backend Fintrack.Server dans CeroBase : vérifiez l'encapsulation du domaine, la disposition des dossiers CQRS, la messagerie d'application basée sur les résultats, FluentValidation, les migrations EF, la cohérence des API et les tests obligatoires avant de marquer le travail comme terminé. À utiliser chaque fois que vous refactorisez des agrégats (par exemple, les migrations de Guid), que vous restructurez les commandes/requêtes d'application, que vous alignez une fonctionnalité sur un modèle établi tel que les budgets ou que vous modifiez le backend multicouche où des « correctifs rapides » laisseraient la base de code incohérente : chargez d'abord cette compétence, puis ouvrez uniquement les fichiers de compétences référencés nécessaires à la tâche plutôt que de dupliquer leur texte.
