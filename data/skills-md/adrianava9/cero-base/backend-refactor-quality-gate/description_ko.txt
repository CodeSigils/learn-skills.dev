CeroBase의 Fintrack.Server 백엔드 리팩터링을 위한 품질 게이트: 작업 완료로 표시하기 전에 도메인 캡슐화, CQRS 폴더 레이아웃, 결과 기반 애플리케이션 메시징, FluentValidation, EF 마이그레이션, API 일관성 및 필수 테스트를 확인합니다. 집계 리팩토링(예: Guid 마이그레이션), 애플리케이션 명령/쿼리 재구성, 예산과 같은 설정된 패턴에 기능 정렬 또는 "빠른 수정"으로 인해 코드베이스가 일관되지 않은 다층 백엔드 변경이 있을 때마다 사용합니다. 먼저 이 기술을 로드한 다음 텍스트를 복제하는 대신 작업에 필요한 참조 기술 파일만 엽니다.
