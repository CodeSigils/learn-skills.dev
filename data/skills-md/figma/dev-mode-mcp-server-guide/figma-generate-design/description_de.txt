Nutzen Sie diese Fähigkeit zusammen mit figma-use, wenn die Aufgabe darin besteht, eine Anwendungsseite, Ansicht oder ein Layout mit mehreren Abschnitten in Figma zu übersetzen. Auslöser: „In Figma schreiben“, „In Figma aus Code erstellen“, „Seite an Figma senden“, „Diese App/Seite übernehmen und in Figma erstellen“, „Bildschirm erstellen“, „Landingpage in Figma erstellen“, „Figma-Bildschirm aktualisieren, damit er mit dem Code übereinstimmt“, „Dieses Modal/Dialog/Schublade/Panel in Figma konvertieren“. Dies ist die bevorzugte Workflow-Fähigkeit, wenn der Benutzer aus Code oder einer Beschreibung eine ganze Seite, ein Modal, einen Dialog, eine Schublade, eine Seitenleiste, ein Panel oder eine beliebige zusammengesetzte Ansicht mit mehreren Abschnitten in Figma erstellen oder aktualisieren möchte. Erkennt Design-Systemkomponenten, Variablen und Stile aus Code Connect-Dateien, vorhandenen Bildschirmen und der Bibliothekssuche, importiert sie dann und stellt Ansichten schrittweise Abschnitt für Abschnitt zusammen, wobei Design-System-Token anstelle von fest codierten Werten verwendet werden.
