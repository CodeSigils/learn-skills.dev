タスクにアプリケーション ページ、ビュー、または複数セクションのレイアウトを Figma に変換することが含まれる場合は、このスキルを figma の使用と並行して使用します。トリガー: 「Figma に書き込む」、「コードから Figma で作成する」、「Figma にページをプッシュする」、「このアプリ/ページを取得して Figma で構築する」、「画面を作成する」、「Figma でランディング ページを構築する」、「コードと一致するように Figma 画面を更新する」、「このモーダル/ダイアログ/ドロワー/パネルを Figma に変換する」。これは、ユーザーがコードまたは説明から Figma で完全なページ、モーダル、ダイアログ、ドロワー、サイドバー、パネル、または任意の構成されたマルチセクション ビューを構築または更新したい場合に常に推奨されるワークフロー スキルです。 Code Connect ファイル、既存の画面、ライブラリ検索からデザイン システム コンポーネント、変数、スタイルを検出し、それらをインポートし、ハードコードされた値の代わりにデザイン システム トークンを使用してセクションごとにビューを段階的に組み立てます。
