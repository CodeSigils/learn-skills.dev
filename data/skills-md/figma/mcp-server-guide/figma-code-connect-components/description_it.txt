Collega i componenti di progettazione Figma ai componenti di codice utilizzando gli strumenti di mappatura Code Connect. Utilizzare quando l'utente dice "connessione codice", "collega questo componente al codice", "mappa questo componente", "collega componente al codice", "crea mappatura connessione codice" o desidera stabilire mappature tra i progetti Figma e le implementazioni del codice. Per le scritture su tela tramite `use_figma`, utilizzare `figma-use`.
