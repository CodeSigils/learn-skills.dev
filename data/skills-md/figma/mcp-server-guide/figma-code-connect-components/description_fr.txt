Connecte les composants de conception Figma aux composants de code à l'aide des outils de mappage Code Connect. À utiliser lorsque l'utilisateur dit « code connecter », « connecter ce composant au code », « mapper ce composant », « lier le composant au code », « créer un mappage de connexion de code » ou souhaite établir des mappages entre les conceptions Figma et les implémentations de code. Pour les écritures sur canevas via `use_figma`, utilisez `figma-use`.
