Соединяет компоненты дизайна Figma с компонентами кода с помощью инструментов сопоставления Code Connect. Используйте, когда пользователь говорит «подключить код», «подключить этот компонент к коду», «сопоставить этот компонент», «связать компонент с кодом», «создать сопоставление соединения кода» или хочет установить сопоставления между проектами Figma и реализациями кода. Для записи холста через use_figma используйте Figma-use.
