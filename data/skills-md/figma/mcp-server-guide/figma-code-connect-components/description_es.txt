Conecta los componentes de diseño de Figma con los componentes de código utilizando las herramientas de mapeo Code Connect. Úselo cuando el usuario diga "conectar código", "conectar este componente al código", "asignar este componente", "vincular componente al código", "crear mapeo de conexión de código" o desea establecer asignaciones entre los diseños de Figma y las implementaciones de código. Para escrituras en lienzo a través de `use_figma`, use `figma-use`.
