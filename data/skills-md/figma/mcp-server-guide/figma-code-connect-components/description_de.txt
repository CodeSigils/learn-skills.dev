Verbindet Figma-Designkomponenten mithilfe von Code Connect-Zuordnungstools mit Codekomponenten. Wird verwendet, wenn der Benutzer „Code verbinden“, „Diese Komponente mit Code verbinden“, „Diese Komponente zuordnen“, „Komponente mit Code verknüpfen“, „Code-Verbindungszuordnung erstellen“ sagt oder Zuordnungen zwischen Figma-Designs und Code-Implementierungen herstellen möchte. Für Canvas-Schreibvorgänge über „use_figma“ verwenden Sie „figma-use“.
