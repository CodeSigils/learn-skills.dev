يربط مكونات تصميم Figma بمكونات التعليمات البرمجية باستخدام أدوات تعيين Code Connect. يُستخدم عندما يقول المستخدم "اتصال الكود"، أو "توصيل هذا المكون بالرمز"، أو "تعيين هذا المكون"، أو "ربط المكون بالرمز"، أو "إنشاء تعيين توصيل التعليمات البرمجية"، أو يريد إنشاء تعيينات بين تصميمات Figma وتنفيذ التعليمات البرمجية. بالنسبة للكتابة على القماش عبر `use_figma`، استخدم `Figma-use`.
