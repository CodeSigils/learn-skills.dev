Costruisci o aggiorna un sistema di progettazione di livello professionale in Figma da una base di codice. Utilizzare quando l'utente desidera creare variabili/token, creare librerie di componenti, impostare temi (modalità chiaro/scuro), documentare le basi o riconciliare le lacune tra codice e Figma. Questa abilità insegna COSA costruire e IN QUALE ORDINE: integra l'abilità "figma-use" che insegna COME chiamare l'API del plugin. Entrambe le abilità dovrebbero essere caricate insieme.
