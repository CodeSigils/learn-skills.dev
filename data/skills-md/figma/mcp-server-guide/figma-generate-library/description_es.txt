Cree o actualice un sistema de diseño de nivel profesional en Figma desde una base de código. Úselo cuando el usuario desee crear variables/tokens, crear bibliotecas de componentes, configurar temas (modos claro/oscuro), documentar las bases o reconciliar las brechas entre el código y Figma. Esta habilidad enseña QUÉ construir y en QUÉ ORDEN; complementa la habilidad "figma-use" que enseña CÓMO llamar a la API del complemento. Ambas habilidades deben cargarse juntas.
