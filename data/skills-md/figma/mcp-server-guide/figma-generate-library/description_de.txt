Erstellen oder aktualisieren Sie ein professionelles Designsystem in Figma aus einer Codebasis. Verwenden Sie diese Option, wenn der Benutzer Variablen/Tokens erstellen, Komponentenbibliotheken erstellen, Themen (helle/dunkle Modi) einrichten, Grundlagen dokumentieren oder Lücken zwischen Code und Figma schließen möchte. Dieser Skill lehrt, WAS in WELCHER REIHENFOLGE zu erstellen ist – er ergänzt den Skill „figma-use“, der lehrt, WIE man die Plugin-API aufruft. Beide Fähigkeiten sollten gemeinsam geladen werden.
