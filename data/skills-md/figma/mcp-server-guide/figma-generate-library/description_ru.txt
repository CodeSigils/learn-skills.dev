Создайте или обновите систему дизайна профессионального уровня в Figma из базы кода. Используйте, когда пользователь хочет создавать переменные/токены, создавать библиотеки компонентов, настраивать темы (светлый/темный режимы), документировать основы или устранять пробелы между кодом и Figma. Этот навык учит, ЧТО создавать и в КАКОМ ПОРЯДКЕ — он дополняет навык «figma-use», который учит, КАК вызывать API плагинов. Оба навыка следует загружать вместе.
