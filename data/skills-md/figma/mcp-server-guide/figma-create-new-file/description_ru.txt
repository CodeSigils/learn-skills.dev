Создайте новый пустой файл Figma. Используйте, когда пользователь хочет создать новый дизайн Figma или файл FigJam, или когда вам нужен новый файл перед вызовом use_figma. При необходимости обрабатывает разрешение плана через whoami. Использование — /figma-create-new-file [editorType] [fileName] (например, /figma-create-new-file figjam My Whiteboard)
