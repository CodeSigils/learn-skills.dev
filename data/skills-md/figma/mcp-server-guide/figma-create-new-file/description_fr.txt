Créez un nouveau fichier Figma vierge. À utiliser lorsque l'utilisateur souhaite créer un nouveau design Figma ou un fichier FigJam, ou lorsque vous avez besoin d'un nouveau fichier avant d'appeler use_figma. Gère la résolution du plan via whoami si nécessaire. Utilisation — /figma-create-new-file [editorType] [fileName] (par exemple /figma-create-new-file figjam My Whiteboard)
