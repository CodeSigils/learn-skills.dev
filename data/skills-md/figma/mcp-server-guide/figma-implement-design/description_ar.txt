يترجم تصميمات Figma إلى كود تطبيق جاهز للإنتاج بدقة بصرية 1:1. يُستخدم عند تنفيذ كود واجهة المستخدم من ملفات Figma، عندما يذكر المستخدم "تنفيذ التصميم"، أو "إنشاء التعليمات البرمجية"، أو "تنفيذ المكون"، أو توفير عناوين URL لـ Figma، أو يطلب إنشاء مكونات مطابقة لمواصفات Figma. بالنسبة إلى لوحة Figma للكتابة عبر `use_figma`، استخدم `Figma-use`.
