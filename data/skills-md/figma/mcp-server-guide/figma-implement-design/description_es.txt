Traduce los diseños de Figma en código de aplicación listo para producción con fidelidad visual 1:1. Úselo al implementar código de interfaz de usuario a partir de archivos Figma, cuando el usuario menciona "implementar diseño", "generar código", "implementar componente", proporciona URL de Figma o solicita crear componentes que coincidan con las especificaciones de Figma. Para el lienzo de Figma escribe a través de `use_figma`, use `figma-use`.
