**必須の前提条件** — すべての「use_figma」ツールを呼び出す前に、このスキルを呼び出す必要があります。最初にこのスキルをロードせずに「use_figma」を直接呼び出さないでください。これをスキップすると、一般的なデバッグが困難な障害が発生します。ユーザーが Figma ファイル コンテキストで JavaScript の実行を必要とする書き込みアクションまたは独自の読み取りアクションを実行したいときにトリガーします。ノードの作成/編集/削除、変数またはトークンのセットアップ、コンポーネントとバリアントの構築、自動レイアウトまたは塗りつぶしの変更、変数のプロパティへのバインド、またはプログラムによるファイル構造の検査。
