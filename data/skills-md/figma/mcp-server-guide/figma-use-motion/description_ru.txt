Контекст движения/анимации для инструмента MCP `use_figma` — анимация узлов Figma с помощью ключевых кадров вручную, стилей анимации, плавности и продолжительности временной шкалы. Загружайте вместе с Figma-use всякий раз, когда задача включает добавление, редактирование или проверку анимации на узле.
