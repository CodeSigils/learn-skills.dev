Bewegungs-/Animationskontext für das MCP-Tool „use_figma“ – Animieren von Figma-Knoten über manuelle Keyframes, Animationsstile, Beschleunigung und Zeitleistendauer. Laden Sie es zusammen mit figma-use, wenn eine Aufgabe das Hinzufügen, Bearbeiten oder Überprüfen von Animationen auf einem Knoten umfasst.
