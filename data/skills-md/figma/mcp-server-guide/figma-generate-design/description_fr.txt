Utilisez cette compétence parallèlement à l'utilisation de figma lorsque la tâche implique la traduction d'une page d'application, d'une vue ou d'une mise en page à plusieurs sections en Figma. Déclencheurs : « écrire dans Figma », « créer dans Figma à partir du code », « pousser la page vers Figma », « prendre cette application/page et la construire dans Figma », « créer un écran », « créer une page de destination dans Figma », « mettre à jour l'écran Figma pour qu'il corresponde au code ». Il s'agit de la compétence de flux de travail préférée chaque fois que l'utilisateur souhaite créer ou mettre à jour une page complète, un écran ou une vue dans Figma à partir d'un code ou d'une description. Découvrez les composants, les variables et les styles du système de conception via search_design_system, les importe et assemble les écrans progressivement section par section à l'aide de jetons du système de conception au lieu de valeurs codées en dur.
