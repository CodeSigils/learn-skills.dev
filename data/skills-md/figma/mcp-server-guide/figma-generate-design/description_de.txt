Nutzen Sie diese Fähigkeit zusammen mit figma-use, wenn die Aufgabe darin besteht, eine Anwendungsseite, Ansicht oder ein Layout mit mehreren Abschnitten in Figma zu übersetzen. Auslöser: „in Figma schreiben“, „aus Code in Figma erstellen“, „Seite an Figma senden“, „diese App/Seite nehmen und in Figma erstellen“, „einen Bildschirm erstellen“, „eine Zielseite in Figma erstellen“, „den Figma-Bildschirm so aktualisieren, dass er mit dem Code übereinstimmt“. Dies ist die bevorzugte Workflow-Fähigkeit, wenn der Benutzer aus Code oder einer Beschreibung eine ganze Seite, einen ganzen Bildschirm oder eine ganze Ansicht in Figma erstellen oder aktualisieren möchte. Erkennt Komponenten, Variablen und Stile des Designsystems über search_design_system, importiert sie und stellt Bildschirme schrittweise Abschnitt für Abschnitt zusammen, wobei Designsystem-Token anstelle von fest codierten Werten verwendet werden.
