Utilice esta habilidad al implementar un diseño de Figma como código (diseño → código): la dirección de lectura DESDE Figma. Activadores: 'implementar este diseño de Figma', 'construir esta pantalla a partir de Figma', 'convertir este Figma en código', 'codificar esto desde Figma', 'diseñar a código' o una URL de diseño de figma.com proporcionada junto con una base de código. Codifica el flujo de trabajo para leer un nodo de Figma con get_design_context y adaptar su salida de referencia al proyecto de destino, reutilizando componentes, tokens y convenciones existentes, y respetando las asignaciones de Code Connect, documentos de componentes, anotaciones de diseño y tokens de diseño por prioridad. Complementa figma-code-connect (mapeo de componentes) y figma-generate-design / figma-use (lo contrario, código → dirección de diseño).
