このスキルは、Figma デザインをコードとして実装する場合 (デザイン → コード)、つまり read-FROM-Figma の方向で使用します。トリガー: 「この Figma デザインを実装する」、「Figma からこの画面を構築する」、「この Figma をコードに変換する」、「Figma からこれをコード化する」、「デザインからコードへ」、またはコードベースとともに提供される figma.com デザインの URL。 get_design_context を使用して Figma からノードを読み取り、その参照出力をターゲット プロジェクトに適合させるためのワークフローをエンコードします。これにより、既存のコンポーネント、トークン、規約が再利用され、Code Connect マッピング、コンポーネント ドキュメント、設計注釈、および設計トークンが優先順位に従って尊重されます。 figma-code-connect (コンポーネント マッピング) と figma-generate-design / figma-use (逆、コード → デザインの方向) を補完します。
