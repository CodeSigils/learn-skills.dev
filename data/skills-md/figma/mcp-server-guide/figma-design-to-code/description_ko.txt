Figma 디자인을 코드(디자인 → 코드), 즉 FROM-Figma 읽기 방향으로 구현할 때 이 기술을 사용하세요. 트리거: '이 Figma 디자인 구현', 'Figma에서 이 화면 구축', '이 Figma를 코드로 변환', 'Figma에서 코드 작성', '코드로 디자인' 또는 코드베이스와 함께 제공되는 figma.com 디자인 URL. get_design_context를 사용하여 Figma에서 노드를 읽고 해당 참조 출력을 대상 프로젝트에 적용하기 위한 워크플로를 인코딩합니다. 즉, 기존 구성 요소, 토큰 및 규칙을 재사용하고 Code Connect 매핑, 구성 요소 문서, 디자인 주석 및 디자인 토큰을 우선 순위에 따라 적용합니다. figma-code-connect(컴포넌트 매핑) 및 figma-generate-design/figma-use(역방향, 코드 → 디자인 방향)를 보완합니다.
