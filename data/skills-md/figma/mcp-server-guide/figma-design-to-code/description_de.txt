Nutzen Sie diese Fähigkeit, wenn Sie ein Figma-Design als Code implementieren (Design → Code) – die Read-FROM-Figma-Richtung. Auslöser: „Implementieren Sie dieses Figma-Design“, „erstellen Sie diesen Bildschirm aus Figma“, „wandeln Sie dieses Figma in Code um“, „codieren Sie dies aus Figma“, „Design-to-Code“ oder eine figma.com-Design-URL, die zusammen mit einer Codebasis bereitgestellt wird. Codiert den Workflow zum Lesen eines Knotens aus Figma mit get_design_context und zum Anpassen seiner Referenzausgabe an das Zielprojekt – unter Wiederverwendung vorhandener Komponenten, Token und Konventionen und unter Berücksichtigung von Code Connect-Zuordnungen, Komponentendokumenten, Designanmerkungen und Designtokens nach Priorität. Ergänzt figma-code-connect (Komponentenzuordnung) und figma-generate-design / figma-use (umgekehrt, Code → Designrichtung).
