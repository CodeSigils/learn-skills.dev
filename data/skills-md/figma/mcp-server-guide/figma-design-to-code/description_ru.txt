Используйте этот навык при реализации дизайна Figma как кода (дизайн → код) — направление чтения ИЗ Figma. Триггеры: «реализовать этот дизайн Figma», «создать этот экран из Figma», «превратить этот Figma в код», «закодировать это из Figma», «спроектировать для кода» или URL-адрес дизайна Figma.com, предоставленный вместе с базой кода. Кодирует рабочий процесс для чтения узла из Figma с помощью get_design_context и адаптации его справочного вывода к целевому проекту — повторное использование существующих компонентов, токенов и соглашений, а также соблюдение сопоставлений Code Connect, документации компонентов, аннотаций дизайна и токенов дизайна по приоритету. Дополняет Figma-code-Connect (сопоставление компонентов) и Figma-generate-design/figma-use (обратное: код → направление проектирования).
