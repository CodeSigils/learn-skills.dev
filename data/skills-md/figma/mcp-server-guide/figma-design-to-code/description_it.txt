Usa questa abilità quando implementi un progetto Figma come codice (design → codice) - la direzione di lettura DA-Figma. Trigger: "implementa questo design Figma", "crea questa schermata da Figma", "trasforma questo Figma in codice", "codificalo da Figma", "progetta per codificare" o un URL di progettazione figma.com fornito insieme a una base di codice. Codifica il flusso di lavoro per leggere un nodo da Figma con get_design_context e adattare il suo output di riferimento al progetto di destinazione, riutilizzando componenti, token e convenzioni esistenti e rispettando le mappature di Code Connect, i documenti dei componenti, le annotazioni di progettazione e i token di progettazione in base alla priorità. Complementa figma-code-connect (mappatura dei componenti) e figma-generate-design / figma-use (il contrario, codice → direzione di progettazione).
