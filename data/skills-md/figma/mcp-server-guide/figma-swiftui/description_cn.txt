SwiftUI ↔ Figma 翻译。每当用户提到 Swift、SwiftUI、iOS、iPhone 或 iPad（无论是哪个方向）时使用，将 Figma 设计转换为 SwiftUI（设计 → 代码），或将 SwiftUI 视图/屏幕/令牌推回 Figma 文件（代码 → 设计）。触发诸如“在 SwiftUI 中实现此 Figma 设计”、“在 Swift 中构建此屏幕”、“将此 SwiftUI 视图推送到 Figma”、“在 Figma 文件中镜像我的 Swift 代码”等短语，或者每当 Figma URL 出现在“.swift”文件/“.xcodeproj”旁边时触发。路由至特定方向的参考文档；与代码→设计路径的“figma-use”一起加载。
