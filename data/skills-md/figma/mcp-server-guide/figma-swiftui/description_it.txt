Traduzione SwiftUI ↔ Figma. Utilizzare ogni volta che l'utente menziona Swift, SwiftUI, iOS, iPhone o iPad - in ENTRAMBE le direzioni - traducendo un progetto Figma in SwiftUI (design → codice) o reinserindo visualizzazioni/schermate/token SwiftUI in un file Figma (codice → design). Si attiva su frasi come "implementa questo progetto Figma in SwiftUI", "crea questa schermata in Swift", "invia questa vista SwiftUI a Figma", "specchia il mio codice Swift in un file Figma" o ogni volta che un URL Figma appare accanto ai file ".swift" / un ".xcodeproj". Percorsi verso un documento di riferimento specifico per la direzione; viene caricato insieme a `figma-use` per il codice → percorso di progettazione.
