SwiftUI ↔ Figma の翻訳。ユーザーが Swift、SwiftUI、iOS、iPhone、または iPad に言及するときはいつでも、Figma デザインを SwiftUI に変換する (デザイン → コード) か、SwiftUI のビュー / 画面 / トークンを Figma ファイルにプッシュする (コード → デザイン) かのいずれかの方向で使用します。 「この Figma デザインを SwiftUI に実装する」、「この画面を Swift で構築する」、「この SwiftUI ビューを Figma にプッシュする」、「Swift コードを Figma ファイルにミラーリングする」などのフレーズ、または Figma URL が `.swift` ファイル / `.xcodeproj` と一緒に表示されるたびにトリガーされます。方向固有の参照ドキュメントにルーティングします。コード→デザインパスの「figma-use」と一緒にロードされます。
