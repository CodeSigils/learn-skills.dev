SwiftUI ↔ Figma 翻譯。每當使用者提到 Swift、SwiftUI、iOS、iPhone 或 iPad（無論是哪個方向）時使用，將 Figma 設計轉換為 SwiftUI（設計 → 程式碼），或將 SwiftUI 視圖/螢幕/令牌推回 Figma 檔案（程式碼 → 設計）。諸如“在 SwiftUI 中實現此 Figma 設計”、“在 Swift 中構建此畫面”、“將此 SwiftUI 視圖推送到 Figma”、“在 Figma 文件中鏡像我的 Swift 代碼”等短語，或者每當 Figma URL 出現在“.swift”文件/“.xcodeproj”旁邊時觸發。路由至特定方向的參考文件；與程式碼→設計路徑的「figma-use」一起載入。
