Traduction SwiftUI ↔ Figma. À utiliser chaque fois que l'utilisateur mentionne Swift, SwiftUI, iOS, iPhone ou iPad - dans l'une ou l'autre direction - en traduisant une conception Figma en SwiftUI (conception → code), ou en repoussant les vues/écrans/jetons SwiftUI dans un fichier Figma (code → conception). Se déclenche sur des phrases telles que « implémenter cette conception Figma dans SwiftUI », « créer cet écran dans Swift », « pousser cette vue SwiftUI vers Figma », « refléter mon code Swift dans un fichier Figma », ou chaque fois qu'une URL Figma apparaît à côté des fichiers « .swift » / un « .xcodeproj ». Itinéraires vers un document de référence spécifique à une direction ; se charge à côté de `figma-use` pour le code → chemin de conception.
