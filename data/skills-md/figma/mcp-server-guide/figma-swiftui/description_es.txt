Traducción SwiftUI ↔ Figma. Úselo siempre que el usuario mencione Swift, SwiftUI, iOS, iPhone o iPad, en CUALQUIER dirección, traduciendo un diseño de Figma a SwiftUI (diseño → código), o empujando vistas/pantallas/tokens de SwiftUI nuevamente a un archivo Figma (código → diseño). Se activan frases como "implementar este diseño de Figma en SwiftUI", "construir esta pantalla en Swift", "enviar esta vista de SwiftUI a Figma", "reflejar mi código Swift en un archivo Figma" o cada vez que aparece una URL de Figma junto a archivos `.swift`/un `.xcodeproj`. Rutas a un documento de referencia de dirección específica; se carga junto con `figma-use` para el código → ruta de diseño.
