SwiftUI ↔ Figma-Übersetzung. Verwenden Sie es immer dann, wenn der Benutzer Swift, SwiftUI, iOS, iPhone oder iPad erwähnt – in JEDER Richtung – um ein Figma-Design in SwiftUI zu übersetzen (Design → Code) oder SwiftUI-Ansichten/Bildschirme/Tokens zurück in eine Figma-Datei zu verschieben (Code → Design). Wird bei Phrasen wie „Implementieren Sie dieses Figma-Design in SwiftUI“, „Erstellen Sie diesen Bildschirm in Swift“, „Übertragen Sie diese SwiftUI-Ansicht auf Figma“, „Spiegeln Sie meinen Swift-Code in einer Figma-Datei“ oder wann immer eine Figma-URL neben „.swift“-Dateien / einem „.xcodeproj“ erscheint, ausgelöst. Leitet zu einem richtungsspezifischen Referenzdokument; wird zusammen mit „figma-use“ für den Code → Designpfad geladen.
