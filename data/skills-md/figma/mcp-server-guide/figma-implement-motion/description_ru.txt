Преобразует движение и анимацию Figma в готовый к использованию код приложения. Используйте при реализации анимации/движения из дизайна Figma — пользователь упоминает «реализовать это движение», «добавить анимацию из Figma», «анимировать этот компонент», предоставляет URL-адрес Figma, узел которого анимирован, или когда `get_design_context` возвращает данные движения или инструктирует вас вызвать `get_motion_context`.
