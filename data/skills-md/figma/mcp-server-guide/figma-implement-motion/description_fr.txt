Traduit le mouvement et les animations Figma en code d'application prêt pour la production. À utiliser lors de l'implémentation d'une animation/mouvement à partir d'une conception Figma — l'utilisateur mentionne « implémenter ce mouvement », « ajouter une animation à partir de Figma », « animer ce composant », fournit une URL Figma dont le nœud est animé, ou lorsque « get_design_context » renvoie des données de mouvement ou vous demande d'appeler « get_motion_context ».
