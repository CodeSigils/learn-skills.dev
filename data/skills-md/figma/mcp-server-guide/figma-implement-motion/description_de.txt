Übersetzt Figma-Bewegungen und -Animationen in produktionsbereiten Anwendungscode. Wird verwendet, wenn Animation/Bewegung aus einem Figma-Design implementiert wird – der Benutzer erwähnt „diese Bewegung implementieren“, „Animation aus Figma hinzufügen“, „diese Komponente animieren“, stellt eine Figma-URL bereit, deren Knoten animiert ist, oder wenn „get_design_context“ Bewegungsdaten zurückgibt oder Sie anweist, „get_motion_context“ aufzurufen.
