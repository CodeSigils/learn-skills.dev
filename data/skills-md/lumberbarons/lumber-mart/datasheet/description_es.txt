Extraiga información estructurada de hojas de datos de componentes y circuitos integrados (archivos PDF o URL) y genere resúmenes de rebajas coherentes. Úselo cuando el usuario solicita extraer, resumir, analizar o documentar información de hojas de datos de componentes/CI, o cuando proporciona una hoja de datos y desea documentación estructurada. Se activa con frases como "extraer esta hoja de datos", "resumir esta hoja de datos", "analizar [nombre del componente]", "documentar este IC" o cuando se trabaja con hojas de datos para el diseño de hardware.
