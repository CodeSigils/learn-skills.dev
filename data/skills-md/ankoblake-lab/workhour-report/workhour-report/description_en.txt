为当前 Git 项目的未提交改动生成规范 of commit message（含逐条工时预估）， 或根据指定分支/时间段的已有提交记录生成一份含工时评估的工作报告（work report）。 当用户提到"生成 commit message"、"提交信息"、"工时预估"、"工时报告"、"work report"、 "生成工作报告"、"统计一下工时"、"这些改动花了多久"、"帮我写提交信息"等关键词时， 必须触发此技能。即使用户只说"生成 commit message"而未明确提及工时，也应触发本技能， 因为工时预估是本技能的核心附加价值。 如果工作区包含多个 Git 项目且用户未指定，需要提示用户明确目标项目。
