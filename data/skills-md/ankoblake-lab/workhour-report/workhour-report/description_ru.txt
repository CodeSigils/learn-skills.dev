Сгенерируйте стандартизированное сообщение о фиксации для незафиксированных изменений в текущем проекте Git (включая оценки времени по каждому элементу) или создайте отчет о работе (отчет о работе) с оценками времени на основе существующих записей коммитов для указанной ветки или периода времени. Когда пользователь упоминает такие ключевые слова, как «создать сообщение о фиксации», «информация о фиксации», «оценка времени», «отчет о времени», «отчет о работе», «создать отчет о работе», «рассчитать время», «сколько времени заняли эти изменения», «помогите мне написать сообщение о фиксации» и т. д., этот навык должен сработать. Даже если пользователь говорит только «создать сообщение о фиксации», не ссылаясь явно на время, навык все равно должен активироваться, поскольку оценка времени является основной дополнительной ценностью этой возможности. Если рабочая область содержит несколько проектов Git и пользователь не указал, какой из них, предложите пользователю уточнить целевой проект.
