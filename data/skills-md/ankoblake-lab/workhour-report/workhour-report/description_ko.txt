현재 Git 프로젝트의 커밋되지 않은 변경 사항(항목별 예상 시간 포함)에 대해 표준화된 커밋 메시지를 생성하거나 지정된 분기/기간에 대한 기존 커밋 기록을 기반으로 예상 시간이 포함된 작업 보고서(작업 보고서)를 생성합니다. 사용자가 "커밋 메시지 생성", "커밋 정보", "시간 추정", "시간 보고서", "작업 보고서", "작업 보고서 생성", "시간 요약", "이 변경에 걸린 시간", "커밋 정보 작성 도움말"과 같은 키워드를 언급하면 ​​이 스킬이 트리거되어야 합니다. 사용자가 시간을 명시적으로 언급하지 않고 "커밋 메시지 생성"만 말하더라도 이 스킬은 여전히 ​​발동되어야 합니다. 시간 추정이 이 스킬의 핵심 부가 가치이기 때문입니다. 작업공간에 여러 Git 프로젝트가 포함되어 있고 사용자가 지정하지 않은 경우 사용자에게 대상 프로젝트를 지정하라는 메시지를 표시해야 합니다.
