Genere un mensaje de confirmación estandarizado para los cambios no confirmados en el proyecto Git actual (incluidas estimaciones de tiempo por elemento) o cree un informe de trabajo con evaluaciones de tiempo basadas en confirmaciones existentes de una rama o período de tiempo específico. Cuando el usuario menciona palabras clave como "generar mensaje de confirmación", "información de confirmación", "estimación de tiempo", "informe de tiempo", "informe de trabajo", "generar informe de trabajo", "tiempo de recuento", "cuánto tiempo tardaron estos cambios" o "ayúdame a escribir información de confirmación", se debe activar esta capacidad. Incluso si el usuario solo dice "generar mensaje de confirmación" sin hacer referencia explícita al tiempo, la habilidad aún debería activarse, ya que la estimación del tiempo es el valor agregado principal. Si el espacio de trabajo contiene varios proyectos de Git y el usuario no ha especificado uno, solicite al usuario que aclare el proyecto de destino.
