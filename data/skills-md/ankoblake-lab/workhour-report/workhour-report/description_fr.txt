Générez un message de validation standardisé pour les modifications non validées dans le projet Git actuel (y compris une estimation du temps pour chaque élément) ou créez un rapport de travail (rapport de travail) avec des estimations de temps basées sur les enregistrements de validation existants d'une branche ou d'une période spécifiée. Lorsque l'utilisateur mentionne des mots-clés tels que « générer un message de validation », « informations de validation », « estimation du temps », « rapport de temps », « rapport de travail », « générer un rapport de travail », « compter le temps », « combien de temps ont pris ces modifications », « aidez-moi à rédiger des informations de validation », etc., cette fonctionnalité doit être déclenchée. Même si l’utilisateur dit seulement « générer un message de validation » sans mentionner explicitement le temps, la compétence doit quand même être activée, car l’estimation du temps est la principale valeur ajoutée. Si l'espace de travail contient plusieurs projets Git et que l'utilisateur n'en a pas spécifié, demandez-lui de clarifier le projet cible.
