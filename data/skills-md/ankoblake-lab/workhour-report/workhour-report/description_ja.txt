現在の Git プロジェクトのコミットされていない変更に対する標準化されたコミット メッセージ (各項目の時間見積もりを含む) を生成するか、指定されたブランチまたは期間からの既存のコミット レコードに基づいて時間見積もりを含む作業レポート (作業レポート) を作成します。ユーザーが「コミット メッセージの生成」、「コミット情報」、「推定時間」、「時間レポート」、「作業レポート」、「作業レポートの生成」、「時間を集計する」、「これらの変更にどれくらい時間がかかりましたか」、「コミット情報の作成を手伝ってください」などのキーワードに言及すると、この機能がトリガーされる必要があります。ユーザーが時間について明示的に言及せずに「コミット メッセージを生成する」とだけ言った場合でも、時間の推定が付加価値の中核となるため、スキルはアクティブ化される必要があります。ワークスペースに複数の Git プロジェクトが含まれており、ユーザーがプロジェクトを指定していない場合は、ユーザーにターゲット プロジェクトを明確にするよう依頼します。
