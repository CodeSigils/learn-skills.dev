قم بإنشاء رسالة التزام موحدة للتغييرات غير الملتزم بها في مشروع Git الحالي (بما في ذلك تقديرات الوقت لكل عنصر)، أو قم بإنشاء تقرير عمل (تقرير عمل) مع تقييمات تكلفة الوقت بناءً على سجلات الالتزام الحالية من فرع أو فترة زمنية محددة. عندما يذكر المستخدم كلمات رئيسية مثل "إنشاء رسالة التزام"، و"معلومات الالتزام"، و"تقدير الوقت"، و"تقرير الوقت"، و"تقرير عمل"، و"إنشاء تقرير عمل"، و"تلخيص الوقت"، و"المدة التي استغرقتها هذه التغييرات"، و"ساعدني في كتابة رسالة التزام"، وما إلى ذلك، يجب تفعيل هذه الإمكانية. حتى لو قال المستخدم فقط "إنشاء رسالة التزام" دون الإشارة إلى الوقت بشكل صريح، فيجب أن تظل المهارة مفعلة، لأن تقدير الوقت هو القيمة المضافة الأساسية لهذه الميزة. إذا كانت مساحة العمل تحتوي على مشاريع Git متعددة ولم يحدد المستخدم أيًا منها، فيجب مطالبة المستخدم بتوضيح المشروع المستهدف.
