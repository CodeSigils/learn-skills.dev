Standardisierter Workflow für die Prüfung, Bereinigung und Organisation von Agentenfähigkeiten in Agentenentwicklungsumgebungen wie Antigravity. Verwenden Sie diese Option, wenn Sie installierte Skills überprüfen, den Token-Overhead bereinigen, von Meta-Skills verwaltete Unter-Skills deaktivieren oder On-Demand-Aktivierungsregeln zu GEMINI.md oder AGENTS.md hinzufügen.
