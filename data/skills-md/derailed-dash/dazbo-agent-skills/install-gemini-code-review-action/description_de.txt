Installiert, konfiguriert oder aktualisiert Dazbos GitHub-Aktion zur PR-Codeüberprüfung und Problemtriage (gemini-review-action) in einem Ziel-Repository. Verwenden Sie diese Option, wenn der Benutzer automatisierte KI-Codeüberprüfungen, Issue-Triaging oder Gemini-Modell-Workflows für sein GitHub-Repository einrichten, konfigurieren oder aktualisieren möchte.
