Estrae e converte le istantanee dell'albero di accessibilità di BrowserMCP in immagini pulite e 
documenti Markdown ad alta fedeltà con strutture corrette (intestazioni, elenchi, 
tabelle, virgolette, formattazione e collegamenti). Utilizzare quando l'utente chiede di creare un documento di markdown
da una pagina web; soprattutto se chiedono di farlo con BrowserMCP.
