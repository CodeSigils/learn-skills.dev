Extrait et convertit les instantanés de l'arborescence d'accessibilité BrowserMCP en images propres et 
des documents Markdown haute fidélité avec des structures correctes (titres, listes, 
tableaux, guillemets, formatage et liens). À utiliser lorsque l'utilisateur demande à créer un document markdown
à partir d'une page Web ; surtout s'ils demandent de le faire avec BrowserMCP.
