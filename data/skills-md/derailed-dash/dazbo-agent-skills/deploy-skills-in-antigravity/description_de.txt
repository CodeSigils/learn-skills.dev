Lädt neue Agent-Skills herunter, installiert sie und verschiebt sie in das globale gemeinsame Antigravity-Verzeichnis (`~/.gemini/skills/`), um sie für alle Tools verfügbar zu machen. Verwenden Sie diese Option, wenn der Benutzer das Herunterladen, Installieren, Importieren oder Aktualisieren neuer Agentenkenntnisse anfordert.
