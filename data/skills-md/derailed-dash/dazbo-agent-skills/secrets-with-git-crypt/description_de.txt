Verwaltet die Verschlüsselung und Entschlüsselung von Repository-Geheimnissen (z. B. .env oder *.tfvars) mithilfe von git-crypt und schützt die Anmeldeinformationen durch parallel verschlüsselte Dateien. Wird zum Verwalten von Geheimnissen, zum Einrichten von Git-Crypt oder zum Verschlüsseln/Entschlüsseln von Umgebungsdateien verwendet.
