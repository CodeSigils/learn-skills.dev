Автоматизированный конвейер проверки кода Figma для компонентов пользовательского интерфейса. Извлекает спецификации дизайна из Figma по всем точкам останова, сопоставляет их с токенами системы проектирования (Tailwind, Styled Components или vanilla CSS), генерирует адаптивный код с подходом, ориентированным на мобильные устройства, и проверяет с помощью Playwright. Предоставляет предложения по автовосстановлению и подробные отчеты о проверке. Используйте этот навык при реализации компонентов пользовательского интерфейса из проектов Figma, проверке существующих компонентов на соответствие проектам или обеспечении идеальной отзывчивости реализаций. Ключевые слова: проверка Figma, отображение системы дизайна, адаптивный дизайн, драматургическое тестирование, компоненты пользовательского интерфейса, пиксельная оптимизация, ориентация на мобильные устройства, Tailwind, стилизованные компоненты, проверка внешнего интерфейса.
