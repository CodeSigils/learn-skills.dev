Da utilizzare quando viene richiesto di creare un commit git, dividere le modifiche in commit o scrivere un messaggio di commit. Preferisci commit di piccole dimensioni facili da rivedere. Segui il modello di messaggio di commit di questo repository quando viene cancellato dalla cronologia recente o dalla cronologia dei percorsi toccati; altrimenti imposta come predefinito i commit convenzionali. Non eseguire mai il commit di file gitignored, temporanei, generati, solo locali o segreti.
