À utiliser lorsqu'on vous demande de créer un commit git, de diviser les modifications en commits ou d'écrire un message de commit. Préférez les petits commits faciles à réviser. Suivez le modèle de message de validation de ce référentiel lorsqu'il est effacé de l'historique récent ou de l'historique des chemins touchés ; sinon, par défaut, les commits conventionnels. Ne commettez jamais de fichiers gitignorés, éphémères, générés, locaux uniquement ou secrets.
