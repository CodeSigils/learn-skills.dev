Procédure opérationnelle standard pour la recherche de littérature universitaire. Couvre la recherche dans les bibliothèques locales, 18 API de bases de données universitaires (L1), l'accès direct web_fetch (L1.5), le RPA du navigateur pour CNKI/Google Scholar (L2) et les services API facultatifs (L3). Comprend le routage de domaine, le protocole de récence, le protocole d'itération de recherche (évaluer → affiner → rechercher jusqu'à 3 tours) et les ponts d'importation Zotero/EndNote.
