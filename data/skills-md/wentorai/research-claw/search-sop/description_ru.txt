Стандартная процедура поиска научной литературы. Охватывает поиск в локальной библиотеке, 18 API академических баз данных (L1), прямой доступ web_fetch (L1.5), RPA браузера для CNKI/Google Scholar (L2) и дополнительные службы API (L3). Включает маршрутизацию домена, протокол недавности, протокол итерации поиска (оценка → уточнение → повторный поиск до 3 раундов) и мосты импорта Zotero/EndNote.
