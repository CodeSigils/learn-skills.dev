Procedimiento operativo estándar para la búsqueda de literatura académica. Cubre la búsqueda en bibliotecas locales, 18 API de bases de datos académicas (L1), acceso directo web_fetch (L1.5), RPA del navegador para CNKI/Google Scholar (L2) y servicios API opcionales (L3). Incluye enrutamiento de dominio, protocolo reciente, protocolo de iteración de búsqueda (evaluar → refinar → investigar hasta 3 rondas) y puentes de importación Zotero/EndNote.
