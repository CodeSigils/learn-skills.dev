قم ببناء CLIs مبهجة وقابلة للتركيب وأولية من قبل الإنسان باستخدام إرشادات clig.dev. يُستخدم عند كتابة أو مراجعة أو إعادة هيكلة أدوات واجهة سطر الأوامر، أو الأوامر، أو الأوامر الفرعية، أو العلامات، أو نص المساعدة، أو المطالبات، أو توجيه stdout/stderr، أو عندما يذكر المستخدم clig، أو إرشادات CLI، أو تجربة المستخدم الطرفية. لا تستخدمه مع الأوامر التي تقوم بتشغيل TUIs بملء الشاشة.
