Lea un archivo Markdown grande de manera eficiente usando md2idx: primero busque el índice numerado (tabla de contenido), luego recupere solo las secciones relevantes para la tarea actual, en lugar de cargar todo el archivo en contexto. Utilice esta habilidad siempre que se le solicite leer, analizar, resumir o responder preguntas sobre un archivo Markdown que probablemente sea grande (más de 200 líneas o 10 KB), o cuando el usuario mencione explícitamente md2idx o solicite "leer a través del índice", "leer selectivamente", "verificar el TOC primero". Considere también esta habilidad de manera proactiva cuando encuentre un archivo .md grande y no necesite todas las secciones: la recuperación parcial guarda tokens y mantiene el contexto enfocado. NO utilice esta habilidad para archivos pequeños, archivos que necesita editar por completo o archivos que no sean Markdown.
