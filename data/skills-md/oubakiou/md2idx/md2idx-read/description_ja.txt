md2idx を使用して大きな Markdown ファイルを効率的に読み取ります。ファイル全体をコンテキストにロードするのではなく、最初に番号付きインデックス (目次) をフェッチし、次に現在のタスクに関連するセクションのみを取得します。サイズが大きくなる可能性がある (200 行または 10 KB を超える) Markdown ファイルについての読み取り、分析、要約、または質問への回答を求められたとき、またはユーザーが明示的に md2idx に言及したとき、または「インデックス経由で読み取る」、「選択的に読み取る」、「最初に目次を確認する」ように求められたときは、必ずこのスキルを使用してください。また、大きな .md ファイルに遭遇し、すべてのセクションが必要ない場合には、このスキルを積極的に検討してください。部分的な取得によりトークンが節約され、コンテキストに焦点が当てられます。このスキルは、小さなファイル、完全に編集する必要があるファイル、または Markdown 以外のファイルには使用しないでください。
