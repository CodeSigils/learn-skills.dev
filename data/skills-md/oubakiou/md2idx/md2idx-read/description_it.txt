Leggi un file Markdown di grandi dimensioni in modo efficiente utilizzando md2idx: recupera prima l'indice numerato (sommario), quindi recupera solo le sezioni pertinenti all'attività corrente, invece di caricare l'intero file nel contesto. Utilizza questa capacità ogni volta che ti viene chiesto di leggere, analizzare, riassumere o rispondere a domande su un file Markdown che potrebbe essere di grandi dimensioni (più di 200 righe o 10 KB) o quando l'utente menziona esplicitamente md2idx o chiede di "leggere tramite indice", "leggere selettivamente", "controlla prima il sommario". Considera anche questa abilità in modo proattivo quando incontri un file .md di grandi dimensioni e non hai bisogno di tutte le sezioni: il recupero parziale salva i token e mantiene il contesto focalizzato. NON utilizzare questa Skill per file di piccole dimensioni, file che devi modificare completamente o file non Markdown.
