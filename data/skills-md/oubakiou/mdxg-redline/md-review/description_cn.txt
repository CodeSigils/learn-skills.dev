使用 mdxg-redline CLI 端到端运行标准 Markdown 审阅循环：将 Markdown 文档发送给人工审阅者，等待（通过 Bash 轮询）他们导出的 Feedback.json，然后将其位置感知内联注释应用回 Markdown 并进行修改。当用户想要通过结构化 JSON 反馈对 Markdown 进行人机循环审查时，请始终使用此技能 - 例如“将此规范发送出去进行审查”，“在我们继续之前请人审查此内容”，“让某人对这份文档进行红线修改”，“在此草稿上留下内联评论”。即使没有明确的文件名或工具名称，对于涉及文档的人工审阅、人工循环检查、红线或结构化审阅者反馈的任何请求，也要积极考虑此技能。当用户作为斜线命令（如“/md-review <path>”）启动它时，适用相同的工作流程。
