使用 mdxg-redline CLI 端對端執行標準 Markdown 審閱循環：將 Markdown 文件傳送給人工審閱者，等待（透過 Bash 輪詢）他們匯出的 Feedback.json，然後將其位置感知內嵌註解套用回 Markdown 並進行修改。當用戶想要透過結構化 JSON 回饋對 Markdown 進行人機循環審查時，請始終使用此技能 - 例如“將此規範發送出去進行審查”，“在我們繼續之前請人審查此內容”，“讓某人對這份文檔進行紅線修改”，“在此草稿上留下內聯評論”。即使沒有明確的文件名稱或工具名稱，對於涉及文件的人工審閱、人工循環檢查、紅線或結構化審閱者回饋的任何請求，也要積極考慮此技能。当用户作为斜线命令（如“/md-review <path>”）启动它时，适用相同的工作流程。
