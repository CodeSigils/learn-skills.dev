Skill that delegates code/document review (identifying differences) to a sub‑agent of a model with a high decision‑weighting, with the primary goal of reducing the main's context consumption (context isolation). Use it for relatively large diffs, changes that span multiple files, or when having the main read the entire diff would make for a heavy first‑pass review. Do not use it for a diff of only a few lines, for diffs that the main has already read, or for light reviews such as style or typo corrections. When delegating review work, use this skill. Do not replace it with a generic sub‑agent. If the change involves code modifications, use delegate‑implement.
