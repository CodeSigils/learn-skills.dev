As the top priority is reducing the main’s context consumption (context isolation), this skill delegates code/document review (identifying differences) to a sub‑agent of a model with a high decision weight. It is used for larger diffs, changes that span multiple files, or any situation where having the main read the entire diff would constitute a heavy primary review. It is not used for a few lines of diff, diffs the main has already read, or minor reviews such as style or typo fixes. When delegating review work, use this skill; do not replace it with a generic sub‑agent. If the change involves code modifications, use delegate‑implement.
