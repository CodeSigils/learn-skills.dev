Habilidad que delega la revisión de código/documento (identificando diferencias) a un subagente de un modelo con una alta ponderación de decisión, con el objetivo principal de reducir el consumo de contexto del principal (aislamiento de contexto). Úselo para diferencias relativamente grandes, cambios que abarcan varios archivos o cuando hacer que el principal lea la diferencia completa supondría una revisión exhaustiva del primer paso. No lo utilices para una diferenciación de sólo unas pocas líneas, para diferencias que el principal ya ha leído o para revisiones ligeras como correcciones de estilo o errores tipográficos. Al delegar el trabajo de revisión, utilice esta habilidad. No lo reemplace con un subagente genérico. Si el cambio implica modificaciones de código, utilice delegado-implementar.
