Навык, который делегирует проверку кода/документа (выявление различий) субагенту модели с высоким весом решения, с основной целью снижения потребления основного контекста (изоляция контекста). Используйте его для относительно больших различий, изменений, которые охватывают несколько файлов, или при чтении основного файла весь файл различий потребует тяжелой проверки при первом проходе. Не используйте его для различий, состоящих всего из нескольких строк, для различий, которые уже прочитал главный редактор, или для легких обзоров, таких как исправление стиля или опечаток. Используйте этот навык при делегировании работы по проверке. Не заменяйте его универсальным субагентом. Если изменение связано с модификациями кода, используйте реализацию делегата.
