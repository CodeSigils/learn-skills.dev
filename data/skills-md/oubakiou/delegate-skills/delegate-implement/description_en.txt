Reducing token cost is the primary goal, and this skill delegates code implementation and modification to a low‑cost model sub‑agent. Use it when you want to handle implementation tasks that involve multiple files or investigation of existing patterns (e.g., feature additions, bug fixes, refactoring) without contaminating the parent agent’s context. Do not use it for small changes to a single file, clear bulk replacements, a few‑line edits in sections the main has already read, or implementations where design decisions are still undecided. Read‑only investigations should be done with delegate‑explore, and git/PR operations should be handled directly by the parent agent. When delegating implementation work, use this skill; do not replace it with a generic sub‑agent.
