As a top priority to reduce token cost, this skill delegates code implementation and modification to a low‑cost model subagent. Use it when you want to handle implementation tasks that involve multiple files or investigation of existing patterns (such as adding features, fixing bugs, refactoring, etc.) without contaminating the parent agent’s context. Do not use it for small changes to a single file, clear bulk replacements, a few‑line edits in sections the main has already read, or implementations whose design decisions are still undecided. Read‑only investigations should be done with delegate‑explore, and git/PR operations should be handled directly by the parent agent. When delegating implementation work, use this skill. Do not replace it with a generic subagent.
