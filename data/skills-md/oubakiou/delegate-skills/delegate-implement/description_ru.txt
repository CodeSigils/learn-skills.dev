Снижение стоимости токена является основной целью, и этот навык делегирует реализацию и модификацию кода субагенту недорогой модели. Используйте его, когда вы хотите выполнять задачи реализации, включающие несколько файлов или исследование существующих шаблонов (например, добавление функций, исправление ошибок, рефакторинг), не затрагивая контекст родительского агента. Не используйте его для небольших изменений в одном файле, явных массовых замен, редактирования нескольких строк в уже прочитанных разделах или реализаций, в которых проектные решения еще не приняты. Расследования, доступные только для чтения, должны выполняться с помощью делегата-исследования, а операции git/PR должны обрабатываться непосредственно родительским агентом. Используйте этот навык при делегировании работы по реализации; не заменяйте его общим субагентом.
