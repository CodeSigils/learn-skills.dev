В качестве основной цели по снижению стоимости токенов это навык, который делегирует реализацию и модификацию кода субагенту недорогой модели. Используйте его, когда вы хотите выполнять задачи реализации (например, добавление функций, исправление ошибок, рефакторинг и т. д.), которые включают несколько файлов или исследование существующих шаблонов, не затрагивая контекст родительского агента. Не используйте его для небольших изменений в одном файле, простых массовых замен, нескольких строк редактирования в разделах, которые основной пользователь уже прочитал, или для реализаций, в которых проектные решения еще не приняты. Для расследований только для чтения используйте Delegate-Explore, а операции git/PR должны обрабатываться непосредственно родительским агентом. Используйте этот навык при делегировании работы по реализации. Не заменяйте его универсальным субагентом.
