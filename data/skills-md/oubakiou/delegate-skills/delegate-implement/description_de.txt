Eine Fähigkeit, die Code-Implementierung und -Änderung an einen kostengünstigen Modell-Subagenten delegiert, wobei das Hauptziel die Reduzierung der Token-Kosten ist. Verwenden Sie es, wenn Sie Implementierungsaufgaben erledigen möchten, die mehrere Dateien umfassen, oder die Untersuchung bestehender Muster (z. B. Hinzufügen von Funktionen, Beheben von Fehlern, Refactoring usw.), ohne den Kontext des übergeordneten Agenten zu beeinträchtigen. Verwenden Sie es nicht für kleine Änderungen an einer einzelnen Datei, klare Massenersetzungen, ein paar Bearbeitungszeilen in Abschnitten, die der Hauptteil bereits gelesen hat, oder Implementierungen, bei denen Entwurfsentscheidungen noch unentschieden sind. Für schreibgeschützte Untersuchungen verwenden Sie „delegate-explore“. Bei Git/PR-Vorgängen sollte der übergeordnete Agent diese direkt verarbeiten. Nutzen Sie diese Fähigkeit, wenn Sie Implementierungsarbeiten delegieren. Ersetzen Sie ihn nicht durch einen generischen Subagenten.
