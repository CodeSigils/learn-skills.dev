As the primary goal is to reduce token cost, this fallback skill delegates miscellaneous tasks that do not clearly fit into explore/implement/review and require reading the target content to make a judgment, to a cheap subagent so as not to bloat the parent agent's context. Minor formatting, renaming, batch replacement, and execution of standard commands that can be handled with a single command are, in principle, executed directly by the main agent without using this skill. If a dedicated skill applies, it takes priority. When delegating chore tasks, this skill is used. It should not be replaced by a generic subagent.
