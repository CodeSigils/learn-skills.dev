With reducing token cost as the primary goal, this is a fallback skill that delegates miscellaneous tasks that do not clearly fall under explore, implement, or review—tasks that require reading the target content to make a judgment and that we do not want to bloat the parent agent’s context—to a cheap sub‑agent. Minor formatting, renaming, batch replacement, and execution of standard commands that can be handled with a single command are, in principle, executed directly by the main agent, and this skill is not used. When a dedicated skill applies, it takes precedence. When delegating chore work, use this skill. Do not replace it with a generic sub‑agent.
