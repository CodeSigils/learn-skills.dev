Como máxima prioridad para reducir el costo de los tokens, se trata de una habilidad que delega la exploración y comprensión de solo lectura a un subagente de modelo de bajo costo. El alcance incluye no solo bases de código y documentos, sino también investigaciones de especificaciones de bibliotecas, OSS e información técnica en la web a través de WebSearch/WebFetch, así como investigaciones de documentos internos y tickets a través de herramientas MCP como Notion, Confluence y Jira. Se utiliza para investigar definiciones, referencias y comportamiento de código; verificar, resumir y señalar secciones relevantes de especificaciones, archivos README y materiales de diseño; y realizar una investigación preliminar de la web y del conocimiento interno. Úselo cuando desee procesar investigaciones de forma económica que impliquen la lectura de varios archivos, documentos extensos o varias páginas web sin contaminar el contexto del agente principal. No lo utilice para comprobar un único archivo corto o investigaciones que puedan manejarse con un único comando rg. Cuando se trate de cambios de código, utilice delegado-implementar. La delegación de exploración debe utilizar esta habilidad y no sustituirse por un subagente genérico.
