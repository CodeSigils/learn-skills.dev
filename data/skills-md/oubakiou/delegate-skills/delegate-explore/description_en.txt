As a top priority to reduce token cost, this is a skill that delegates read‑only exploration and comprehension to a low‑cost model sub‑agent. The scope includes not only code bases and documents, but also investigations of library specifications, OSS, and technical information on the web via WebSearch/WebFetch, as well as internal document and ticket investigations through MCP tools such as Notion, Confluence, and Jira. It is used for investigating code definitions, references, and behavior; verifying, summarizing, and pinpointing relevant sections of specifications, READMEs, and design materials; and conducting preliminary research of web and internal knowledge. Use it when you want to cheaply process investigations that involve reading multiple files, long documents, or multiple web pages without contaminating the parent agent’s context. Do not use it for checking a single short file or investigations that can be handled with a single rg command. When code changes are involved, use delegate‑implement. Delegation of explore should use this skill and not be substituted with a generic sub‑agent.
