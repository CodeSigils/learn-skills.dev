As a primary goal to reduce token cost, this skill delegates read‑only exploration and comprehension to a low‑cost model sub‑agent. The scope includes not only code‑base documents but also investigations of library specifications, OSS, and technical information on the web via WebSearch/WebFetch, as well as internal document and ticket investigations via MCP tools such as Notion, Confluence, and Jira. It is used for researching code definitions, references, behavior, verifying, summarizing, and pinpointing relevant sections of specifications, README, design documents, and for preliminary research of web and internal knowledge. Use it when you want to cheaply process investigations that involve reading multiple files, long documents, or several web pages without contaminating the parent agent’s context. Do not use it for checking a single short file or investigations that can be done with a single rg command. When code changes are involved, use delegate‑implement. Delegation of explore should use this skill and not be replaced by a generic sub‑agent.
