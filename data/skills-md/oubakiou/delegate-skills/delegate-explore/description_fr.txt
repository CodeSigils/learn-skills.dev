En tant que priorité absolue pour réduire le coût des jetons, il s'agit d'une compétence qui délègue l'exploration et la compréhension en lecture seule à un sous-agent de modèle à faible coût. La portée comprend non seulement les bases de code et les documents, mais également les enquêtes sur les spécifications des bibliothèques, les logiciels libres et les informations techniques sur le Web via WebSearch/WebFetch, ainsi que les enquêtes sur les documents internes et les tickets via des outils MCP tels que Notion, Confluence et Jira. Il est utilisé pour étudier les définitions de code, les références et le comportement ; vérifier, résumer et identifier les sections pertinentes des spécifications, des README et des documents de conception ; et effectuer des recherches préliminaires sur le Web et les connaissances internes. Utilisez-le lorsque vous souhaitez traiter à moindre coût des enquêtes impliquant la lecture de plusieurs fichiers, documents longs ou plusieurs pages Web sans contaminer le contexte de l'agent parent. Ne l'utilisez pas pour vérifier un seul fichier court ou pour des enquêtes qui peuvent être traitées avec une seule commande rg. Lorsque des modifications de code sont impliquées, utilisez délégué-implémenter. La délégation d'exploration doit utiliser cette compétence et ne pas être remplacée par un sous-agent générique.
