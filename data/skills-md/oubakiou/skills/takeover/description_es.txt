El archivo de entrega (defaultdocs/handover.md, configurable mediante la variable de entorno HANDOVER_FILE) se lee para restaurar el contexto de trabajo de la sesión anterior y reanudar la tarea; esta es una habilidad. Cuando el usuario dice cosas como "tomar el control", "leer el traspaso", "reanudar desde donde lo dejamos", "continuar la sesión anterior", "leer el traspaso", "hacerse cargo del trabajo", etc., o cuando se le pide que continúe una tarea interrumpida mientras existe docs/handover.md, esta habilidad siempre debe usarse. El lado que escribe usa la habilidad de traspaso.
