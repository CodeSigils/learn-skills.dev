Le fichier de handover (defaultdocs/handover.md, configurable via la variable d'environnement HANDOVER_FILE) est lu pour restaurer le contexte de travail de la session précédente et reprendre la tâche : c'est une compétence. Lorsque l'utilisateur dit des choses comme « reprise », « lire le transfert », « reprendre là où nous l'avons laissé », « continuer la session précédente », « lire le transfert », « reprendre le travail », etc., ou lorsqu'il est invité à continuer une tâche interrompue pendant que docs/handover.md existe, cette compétence doit toujours être utilisée. Le côté qui écrit utilise la compétence de transfert.
