The handover file (default docs/handover.md, changeable via the HANDOVER_FILE environment variable) is read to restore the work context from the previous session and resume work. It is always used when the user says “takeover,” “read the handover,” “resume from where we left off,” “continue from the last time,” “read the handover,” “pick up the work,” etc., or when asked to continue interrupted work while docs/handover.md exists. The output side uses the handover skill.
