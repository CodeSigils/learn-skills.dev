The handover file (default docs/handover.md, configurable via the HANDOVER_FILE environment variable) is read to restore the work context from the previous session and resume the task—this is a skill. When the user says things like “takeover,” “read the handover,” “resume from where we left off,” “continue the previous session,” “read the handover,” “take over the work,” etc., or when asked to continue an interrupted task while docs/handover.md exists, this skill must always be used. The side that writes out uses the handover skill.
