代理以非交互方式安全使用 GitHub CLI (gh) 的实用模式集合。它涵盖创建、审查和合并拉取请求；问题管理；创建版本；检查 GitHub Actions 运行情况并调查故障；通过ghapi调用REST/GraphQL；存储库操作；在 GitHub 上搜索；以及安装和发布代理技能 (ghskill)。当用户引用 GitHub 操作（例如“创建 PR”、“打开问题”、“发布版本”、“查看 CI 结果”、“在 GitHub 上搜索”或“安装技能”）时，请在构建 gh 命令之前查阅此技能。由于 gh 会挂在交互提示上，而且其人性化的输出不稳定，所以即使是看似简单的 gh 操作也应该由发起命令的一方来处理，以避免出现问题。
