代理以非交互方式安全使用 GitHub CLI (gh) 的实用模式集合。它涵盖创建、审查和合并拉取请求；管理问题；创建版本；检查 GitHub Actions 运行情况并调查故障；使用ghapi 进行 REST/GraphQL 调用；存储库操作；在 GitHub 上搜索；以及安装/发布代理技能 (ghskill)。当用户提及 GitHub 操作（例如“创建 PR”、“打开问题”、“发布版本”、“查看 CI 结果”、“在 GitHub 上搜索”或“安装技能”）时，请在构建 gh 命令之前查阅此技能。由于 gh 可能会停留在交互提示上，并且其以人为本的输出可能不稳定，因此即使看似简单的 gh 操作也应该通过此技能来处理。
