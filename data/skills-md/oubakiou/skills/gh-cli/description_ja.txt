エージェントが非対話型の方法で GitHub CLI (gh) を安全に使用するための実践的なパターンのコレクション。 PR の作成、レビュー、マージについて説明します。問題管理。リリースの作成。 GitHub Actions の実行を確認し、障害を調査します。 gh API を使用して REST/GraphQL 呼び出しを行う。リポジトリ操作。 GitHub で検索する。エージェント スキル (gh スキル) をインストールして公開します。ユーザーが「PR の作成」、「問題を開く」、「リリースの作成」、「CI 結果の表示」、「GitHub での検索」、または「スキルのインストール」などの GitHub アクションを参照する場合は、gh コマンドを作成する前にこのスキルを参照してください。 gh は対話型プロンプトにハングアップする可能性があり、その人間指向の出力が不安定になる可能性があるため、一見単純な gh 操作であっても、呼び出す側では避けるべきです。
