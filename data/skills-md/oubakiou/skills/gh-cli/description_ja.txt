エージェントが非対話型の方法で GitHub CLI (gh) を安全に使用するための実践的なパターンのコレクション。プル リクエストの作成、レビュー、マージについて説明します。問題の管理。リリースの作成。 GitHub Actions の実行を確認し、障害を調査します。 ghapi で REST/GraphQL 呼び出しを行う;リポジトリ操作。 GitHub で検索する。およびエージェント スキル (ghskill) のインストール/公開。ユーザーが「PR の作成」、「問題を開く」、「リリースの作成」、「CI 結果の表示」、「GitHub での検索」、「スキルのインストール」などの GitHub アクションに言及した場合は、gh コマンドを作成する前にこのスキルを参照してください。 gh は対話型プロンプトにハングアップする可能性があり、人間指向の出力が不安定になる可能性があるため、一見単純な gh 操作であっても、このスキルを通じて処理する必要があります。
