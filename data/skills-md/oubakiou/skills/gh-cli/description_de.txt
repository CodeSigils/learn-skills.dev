Eine Sammlung praktischer Muster für Agenten zur sicheren und nicht interaktiven Verwendung der GitHub-CLI (gh). Es umfasst das Erstellen, Überprüfen und Zusammenführen von PRs; Issue-Management; Erstellen von Veröffentlichungen; Überprüfung der Ausführung und Behebung von Fehlern von GitHub-Aktionen; REST/GraphQL-Aufrufe mit „gh api“ durchführen; Repository-Operationen; Suche auf GitHub; und Fähigkeiten zum Installieren und Veröffentlichen von Agenten („GH Skill“). Wenn ein Benutzer GitHub-Aktionen wie „PR erstellen“, „Problem öffnen“, „Veröffentlichung erstellen“, „CI-Ergebnisse anzeigen“, „Auf GitHub suchen“ oder „Skill installieren“ erwähnt, beziehen Sie sich auf diesen Skill, bevor Sie den Befehl „gh“ erstellen. Da „gh“ in interaktiven Eingabeaufforderungen hängen bleiben oder eine instabile, auf den Menschen zugeschnittene Ausgabe erzeugen kann, sollten selbst scheinbar einfache „gh“-Operationen so früh wie möglich abgefangen und bearbeitet werden.
