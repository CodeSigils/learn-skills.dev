A collection of practical patterns for agents to use the GitHub CLI (gh) safely in a non‑interactive manner. It covers creating, reviewing, and merging pull requests; managing issues; creating releases; checking GitHub Actions runs and investigating failures; making REST/GraphQL calls with gh api; repository operations; searching on GitHub; and installing/publishing agent skills (gh skill). When a user mentions GitHub actions such as “create a PR,” “open an issue,” “make a release,” “view CI results,” “search on GitHub,” or “install a skill,” consult this skill before constructing the gh command. Because gh can hang on interactive prompts and its human‑oriented output can be unstable, even seemingly simple gh operations should be handled through this skill.
