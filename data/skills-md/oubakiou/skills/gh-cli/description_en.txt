A collection of practical patterns for agents to use the GitHub CLI (gh) safely in a non‑interactive way. It covers creating, reviewing, and merging pull requests; issue management; creating releases; checking GitHub Actions runs and investigating failures; calling REST/GraphQL via gh api; repository operations; searching on GitHub; and installing and publishing agent skills (gh skill). When a user refers to GitHub actions such as “create a PR,” “open an issue,” “make a release,” “view CI results,” “search on GitHub,” or “install a skill,” consult this skill before constructing the gh command. Because gh can hang on interactive prompts and its human‑oriented output is unstable, even seemingly simple gh operations should be handled by the side that initiates the command to avoid problems.
