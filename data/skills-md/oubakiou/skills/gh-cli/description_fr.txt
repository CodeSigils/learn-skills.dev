Une collection de modèles pratiques permettant aux agents d'utiliser la CLI GitHub (gh) en toute sécurité et de manière non interactive. Il couvre la création, la révision et la fusion des demandes d'extraction ; gérer les problèmes ; créer des versions ; vérifier les exécutions des actions GitHub et enquêter sur les échecs ; passer des appels REST/GraphQL avec ghapi ; opérations de dépôt ; recherche sur GitHub ; et compétences d'agent d'installation/publication (ghskill). Lorsqu'un utilisateur mentionne des actions GitHub telles que « créer un PR », « ouvrir un ticket », « créer une version », « afficher les résultats CI », « rechercher sur GitHub » ou « installer une compétence », consultez cette compétence avant de construire la commande gh. Étant donné que gh peut se bloquer sur des invites interactives et que sa sortie orientée vers l'humain peut être instable, même les opérations gh apparemment simples doivent être gérées via cette compétence.
