مجموعة من الأنماط العملية للوكلاء لاستخدام GitHub CLI (gh) بأمان وبطريقة غير تفاعلية. ويغطي إنشاء طلبات السحب ومراجعتها ودمجها؛ إدارة القضايا؛ إنشاء الإصدارات؛ التحقق من تشغيل إجراءات GitHub والتحقيق في حالات الفشل؛ إجراء مكالمات REST/GraphQL باستخدام ghapi؛ عمليات المستودع؛ البحث على جيثب؛ وتثبيت/نشر مهارات الوكيل (ghskill). عندما يذكر المستخدم إجراءات GitHub مثل "إنشاء علاقات عامة" أو "فتح مشكلة" أو "إصدار إصدار" أو "عرض نتائج CI" أو "البحث في GitHub" أو "تثبيت مهارة"، راجع هذه المهارة قبل إنشاء الأمر gh. نظرًا لأن gh يمكن أن يعلق على المطالبات التفاعلية وقد يكون ناتجه الموجه نحو الإنسان غير مستقر، فحتى عمليات gh التي تبدو بسيطة يجب التعامل معها من خلال هذه المهارة.
