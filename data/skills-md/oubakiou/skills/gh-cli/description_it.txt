Una raccolta di modelli pratici che consentono agli agenti di utilizzare la CLI GitHub (gh) in modo sicuro e non interattivo. Copre la creazione, la revisione e l'unione delle richieste pull; gestione dei problemi; creazione di versioni; controllare le esecuzioni di GitHub Actions e indagare sugli errori; effettuare chiamate REST/GraphQL con ghapi; operazioni di deposito; cercando su GitHub; e installazione/pubblicazione delle competenze dell'agente (ghskill). Quando un utente menziona azioni GitHub come "crea una PR", "apri un problema", "crea una versione", "visualizza risultati CI", "cerca su GitHub" o "installa una competenza", consulta questa competenza prima di costruire il comando gh. Poiché gh può rimanere bloccato su prompt interattivi e il suo output orientato all'uomo può essere instabile, anche le operazioni gh apparentemente semplici dovrebbero essere gestite tramite questa abilità.
