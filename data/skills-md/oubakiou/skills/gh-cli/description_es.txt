Una colección de patrones prácticos para que los agentes utilicen GitHub CLI (gh) de forma segura y no interactiva. Cubre la creación, revisión y combinación de solicitudes de extracción; gestionar problemas; crear lanzamientos; verificar las ejecuciones de GitHub Actions e investigar fallas; realizar llamadas REST/GraphQL con ghapi; operaciones de repositorio; buscando en GitHub; y habilidades de agente de instalación/publicación (ghskill). Cuando un usuario menciona acciones de GitHub como "crear un PR", "abrir un problema", "realizar un lanzamiento", "ver resultados de CI", "buscar en GitHub" o "instalar una habilidad", consulte esta habilidad antes de construir el comando gh. Debido a que gh puede depender de indicaciones interactivas y su salida orientada a humanos puede ser inestable, incluso las operaciones de gh aparentemente simples deben manejarse a través de esta habilidad.
