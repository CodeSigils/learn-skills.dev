代理以非交互方式安全使用 GitHub CLI (gh) 的实用模式集合。它涵蓋創建、審查和合併拉取請求；管理問題；創建版本；檢查 GitHub Actions 運行情況並調查故障；使用ghapi 進行 REST/GraphQL 呼叫；存儲庫操作；在 GitHub 上搜尋；以及安裝/發布代理技能 (ghskill)。當使用者提及 GitHub 操作（例如「建立 PR」、「開啟問題」、「發布版本」、「查看 CI 結果」、「在 GitHub 上搜尋」或「安裝技能」）時，請在建立 gh 指令之前查閱此技能。由於 gh 可能會停留在互動提示上，並且其以人為本的輸出可能不穩定，因此即使看似簡單的 gh 操作也應該透過此技能來處理。
