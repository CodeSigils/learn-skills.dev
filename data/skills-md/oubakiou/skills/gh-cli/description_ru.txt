Коллекция практических шаблонов, позволяющих агентам безопасно использовать интерфейс командной строки GitHub (gh) в неинтерактивном режиме. Он охватывает создание, проверку и объединение запросов на включение; управление проблемами; создание релизов; проверка выполнения и расследование сбоев GitHub Actions; вызов API REST/GraphQL через `gh api`; операции с хранилищем; поиск на GitHub; и навыки установки/публикации агента («gh навык»). Когда пользователь упоминает действия GitHub, такие как «создать PR», «открыть задачу», «выпустить релиз», «просмотреть результаты CI», «поиск на GitHub» или «установить навык», обратитесь к этому навыку перед сборкой команды `gh`. Поскольку `gh` может зависать в интерактивных подсказках, а его ориентированный на пользователя вывод иногда нестабильен, даже, казалось бы, простые операции `gh` должны обрабатываться инициирующей стороной.
