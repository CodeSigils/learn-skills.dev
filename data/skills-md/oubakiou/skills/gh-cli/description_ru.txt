Коллекция практических шаблонов, позволяющих агентам безопасно использовать интерфейс командной строки GitHub (gh) в неинтерактивном режиме. Он охватывает создание, проверку и объединение запросов на включение; управление проблемами; создание релизов; проверка запуска GitHub Actions и расследование сбоев; выполнение вызовов REST/GraphQL с помощью ghapi; операции с хранилищем; поиск на GitHub; и навыки установки/публикации агента (ghskill). Когда пользователь упоминает действия GitHub, такие как «создать PR», «открыть задачу», «выпустить релиз», «просмотреть результаты CI», «поиск на GitHub» или «установить навык», проконсультируйтесь с этим навыком перед созданием команды gh. Поскольку gh может зависать на интерактивных подсказках, а его ориентированный на пользователя вывод может быть нестабильным, даже, казалось бы, простые операции gh следует выполнять с помощью этого навыка.
