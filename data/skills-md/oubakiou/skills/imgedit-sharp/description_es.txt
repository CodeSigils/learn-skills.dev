Se utiliza para todas las tareas que implican editar y convertir archivos de imágenes existentes (fotos, capturas de pantalla, pancartas, íconos, etc.). Operaciones de destino: cambio de tamaño/creación de miniaturas (especificando ancho o px, incluyendo “reducir” o “reducir”), recortar, rotar/voltear, conversión de formato (entre PNG/JPEG/WebP/AVIF/GIF/TIFF, por ejemplo, tiff→png, png→jpg), compresión/reducción de tamaño (reducir el tamaño del archivo, reducir el tamaño de las imágenes grandes), composición de logotipo/marca de agua, ajuste de tono/brillo y anotación de capturas de pantalla (entorno). áreas específicas con cuadros rojos, flechas, resaltados, creación de imágenes para informes de errores). Cuando un usuario señala una ruta de archivo de imagen específica o dice "esta imagen" o "esta captura de pantalla" y solicita cualquiera de los cambios anteriores (en japonés o inglés, incluso expresiones como "redimensionar", "recortar", "rotar", "comprimir", "reducir", "convertir a webp/png/jpg"), se activa. Generar nuevas imágenes desde cero (crear ilustraciones o elementos visuales similares a fotografías) está fuera de alcance y se debe utilizar delegado-imagegen. Al generar tablas/gráficos a partir de SVG y rasterizarlos, utilice dataviz-svg.
