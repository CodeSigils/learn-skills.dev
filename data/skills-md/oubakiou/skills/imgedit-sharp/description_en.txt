Used for all tasks involving editing and converting existing image files (photos, screenshots, banners, icons, etc.). Target operations: resizing/thumbnail creation (specifying width or px, including “shrink” or “make smaller”), cropping, rotation/flip, format conversion (between PNG/JPEG/WebP/AVIF/GIF/TIFF, e.g., tiff→png, png→jpg), compression/size reduction (lowering file size, making large images smaller), logo/watermark compositing, hue/brightness adjustment, and annotating screenshots (surrounding specific areas with red boxes, arrows, highlights, creating images for bug reports). When a user points to a specific image file path or says “this image” or “this screenshot” and requests any of the above changes (in Japanese or English, even expressions like “resize”, “crop”, “rotate”, “compress”, “shrink”, “convert to webp/png/jpg”), it is triggered. Generating new images from scratch (creating illustrations or photo‑like visuals) is out of scope and should use delegate‑imagegen. When generating charts/graphs from SVG and rasterizing them, use dataviz‑svg.
