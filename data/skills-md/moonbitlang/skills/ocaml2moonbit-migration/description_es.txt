Guía para migrar proyectos, bibliotecas, módulos y conjuntos de pruebas de OCaml al idiomático MoonBit. Úselo al traducir código OCaml a MoonBit, planificar un puerto grande de OCaml a MoonBit, preservar el comportamiento de bytes/cadenas pesadas, reemplazar variantes/registros/excepciones/referencias/matrices de OCaml, asignar API de OCaml a paquetes MoonBit o crear una estrategia de verificación y prueba para una migración.
