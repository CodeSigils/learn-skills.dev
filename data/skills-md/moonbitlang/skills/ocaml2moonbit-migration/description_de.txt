Leitfaden für die Migration von OCaml-Projekten, Bibliotheken, Modulen und Testsuiten zu idiomatischem MoonBit. Verwenden Sie es, wenn Sie OCaml-Code in MoonBit übersetzen, einen großen OCaml-zu-MoonBit-Port planen, Byte-/String-lastiges Verhalten beibehalten, OCaml-Varianten/Datensätze/Ausnahmen/Refs/Arrays ersetzen, OCaml-APIs MoonBit-Paketen zuordnen oder eine Verifizierungs- und Teststrategie für eine Migration erstellen.
