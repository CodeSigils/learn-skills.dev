Extrayez les spécifications formelles et les suites de tests complètes des implémentations MoonBit existantes. À utiliser lorsqu'on vous demande « d'extraire les spécifications de l'implémentation », de « générer des tests à partir du code » ou de « créer des tests basés sur les spécifications pour un package existant ». Analyse le code existant pour produire spec.mbt avec des talons de mots-clés « declare » et des fichiers de test organisés (valides/invalides).
