Извлеките формальные спецификации и комплексные наборы тестов из существующих реализаций MoonBit. Используйте, когда вас просят «извлечь спецификацию из реализации», «создать тесты из кода» или «создать тесты на основе спецификаций для существующего пакета». Анализирует существующий код для создания файла spec.mbt с заглушками ключевых слов Declare и организованными тестовыми файлами (действительными/недействительными).
