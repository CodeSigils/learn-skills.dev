Utilisez cette compétence lorsque l'utilisateur a besoin d'aide pour résoudre le langage, le code, le diagnostic du compilateur, le package, la chaîne d'outils, le backend, le FFI, le test ou "MoonBit a-t-il X ?" questions. Utilisez-le même lorsque MoonBit n'est impliqué que par les fichiers .mbt, moon.mod.json, moon.pkg.json, les commandes moon, les cibles wasm/js/native ou les packages mooncakes. Cette compétence permet de choisir la bonne source de vérité MoonBit, de découvrir des API avec Moon ide, d'éviter les hypothèses obsolètes et de valider les correctifs.
