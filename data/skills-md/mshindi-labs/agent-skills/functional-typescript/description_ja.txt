TypeScript と JavaScript の関数型プログラミング パターン。このスキルは、FP 原則 (純粋関数、不変性、クロージャ、部分適用、カリー化、関数合成、高階関数、モジュール パターン) に従う必要があるコードを作成またはレビューするときに使用します。 FP をサポートする TypeScript 型にも使用します: Result、Option、判別共用体、Readonly、および汎用 HOF 署名。コードベースが fp-ts/* からインポートされる場合は、fp-ts ライブラリ ルール (パイプ/フロー構成、オプション、どちらか、TaskEither、および Do 表記) も適用します。 「ミューテーションを回避するにはどうすればよいか」、「これをどのようにカレーにすればよいか」、「このモジュールをどのように構成すればよいか」、「高階関数をどのように入力すればよいか」、「try-catch を使用せずに非同期エラーを処理するにはどうすればよいか」、またはコードをより機能的にするためのリクエストなどの質問をトリガーします。
