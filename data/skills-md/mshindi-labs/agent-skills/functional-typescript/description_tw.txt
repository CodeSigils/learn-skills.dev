TypeScript 和 JavaScript 的函數式程式設計模式。在編寫或審查應遵循 FP 原則的程式碼時使用此技能：純函數、不變性、閉包、部分應用、柯里化、函數組合、高階函數和模組模式。也可用於支援 FP 的 TypeScript 類型：結果、選項、可區分聯合、唯讀和通用 HOF 簽章。當程式碼庫從 fp-ts/* 匯入時，也套用 fp-ts 函式庫規則：管道/流組合、Option、Either、TaskEither 和 Do 表示法。觸發諸如「我如何避免突變」、「我如何柯里化這個」、「我應該如何建構這個模組」、「如何輸入高階函數」、「如何在沒有 try-catch 的情況下處理非同步錯誤」或任何使程式碼更實用的請求等問題。
