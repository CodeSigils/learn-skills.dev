Modèles de programmation fonctionnelle pour TypeScript et JavaScript. Utilisez cette compétence lors de l'écriture ou de la révision de code qui doit suivre les principes de FP : fonctions pures, immuabilité, fermetures, application partielle, curry, composition de fonctions, fonctions d'ordre supérieur et modèle de module. À utiliser également pour les types TypeScript qui prennent en charge FP : résultat, option, unions discriminées, lecture seule et signatures HOF génériques. Lorsque la base de code importe depuis fp-ts/*, appliquez également les règles de la bibliothèque fp-ts : composition de canal/flux, Option, Soit, TaskEither et notation Do. Déclenchez des questions telles que "comment puis-je éviter la mutation", "comment puis-je curry ceci", "comment dois-je structurer ce module", "comment saisir une fonction d'ordre supérieur", "comment gérer les erreurs asynchrones sans try-catch", ou toute demande visant à rendre le code plus fonctionnel.
