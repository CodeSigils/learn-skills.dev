Funktionale Programmiermuster für TypeScript und JavaScript. Verwenden Sie diese Fähigkeit, wenn Sie Code schreiben oder überprüfen, der den FP-Prinzipien folgen sollte: reine Funktionen, Unveränderlichkeit, Abschlüsse, teilweise Anwendung, Currying, Funktionszusammensetzung, Funktionen höherer Ordnung und das Modulmuster. Auch für TypeScript-Typen verwenden, die FP unterstützen: Result, Option, diskriminierte Unions, Readonly und generische HOF-Signaturen. Wenn die Codebasis aus fp-ts/* importiert wird, wenden Sie auch die Regeln der fp-ts-Bibliothek an: Pipe/Flow-Komposition, Option, Entweder, TaskEither und Do-Notation. Triggern Sie auf Fragen wie „Wie vermeide ich Mutationen“, „Wie kürze ich das“, „Wie soll ich dieses Modul strukturieren“, „Wie tippe ich eine Funktion höherer Ordnung“, „Wie gehe ich mit asynchronen Fehlern ohne Try-Catch um“ oder auf jede Anfrage, um den Code funktionsfähiger zu machen.
