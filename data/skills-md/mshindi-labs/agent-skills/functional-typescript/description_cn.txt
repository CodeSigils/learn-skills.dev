TypeScript 和 JavaScript 的函数式编程模式。在编写或审查应遵循 FP 原则的代码时使用此技能：纯函数、不变性、闭包、部分应用、柯里化、函数组合、高阶函数和模块模式。也可用于支持 FP 的 TypeScript 类型：结果、选项、可区分联合、只读和通用 HOF 签名。当代码库从 fp-ts/* 导入时，还应用 fp-ts 库规则：管道/流组合、Option、Either、TaskEither 和 Do 表示法。触发诸如“我如何避免突变”、“我如何柯里化这个”、“我应该如何构建这个模块”、“如何输入高阶函数”、“如何在没有 try-catch 的情况下处理异步错误”或任何使代码更实用的请求等问题。
