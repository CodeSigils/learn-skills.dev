Шаблоны функционального программирования для TypeScript и JavaScript. Используйте этот навык при написании или проверке кода, который должен следовать принципам ФП: чистые функции, неизменность, замыкания, частичное применение, каррирование, композиция функций, функции высшего порядка и шаблон модуля. Также используйте для типов TypeScript, поддерживающих FP: Result, Option, дискриминируемые объединения, только для чтения и общие сигнатуры HOF. При импорте базы кода из fp-ts/* также примените правила библиотеки fp-ts: композицию канала/потока, нотацию Option, либо, TaskEither и Do. Запускайте такие вопросы, как «как мне избежать мутации», «как мне это каррировать», «как мне структурировать этот модуль», «как мне ввести функцию высшего порядка», «как мне обрабатывать асинхронные ошибки без try-catch» или любой запрос, чтобы сделать код более функциональным.
