Patrones de programación funcional para TypeScript y JavaScript. Utilice esta habilidad al escribir o revisar código que deba seguir los principios de FP: funciones puras, inmutabilidad, cierres, aplicación parcial, curry, composición de funciones, funciones de orden superior y el patrón del módulo. Utilícelo también para tipos de TypeScript que admitan FP: resultado, opción, uniones discriminadas, solo lectura y firmas HOF genéricas. Cuando el código base se importe desde fp-ts/*, aplique también las reglas de la biblioteca fp-ts: composición de tubería/flujo, Opción, Cualquiera, TareaCualquiera y Notación Do. Activa preguntas como "cómo evito la mutación", "cómo soluciono esto", "cómo debo estructurar este módulo", "cómo escribo una función de orden superior", "cómo manejo los errores asíncronos sin try-catch" o cualquier solicitud para hacer que el código sea más funcional.
