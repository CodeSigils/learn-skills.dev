Ejecute tareas de escritorio multiplataforma a través de una habilidad pura de OpenClaw que guía al agente principal para observar la pantalla, enfocar aplicaciones/ventanas, llamar a scripts de ayuda para capturas de pantalla y acciones de entrada, verificar cada paso, limpiar el contexto de la tarea y solo escalar a colaboración entre múltiples agentes cuando las tareas se vuelven claramente de múltiples ventanas o múltiples aplicaciones. Úselo cuando el usuario desee control de la GUI del escritorio, operación de aplicaciones nativas, enfoque de ventana, capturas de pantalla, flujos de clic/escriba o flujos de trabajo de escritorio multiplataforma en macOS, Windows o Linux.
