純粋な OpenClaw スキルを通じてクロスプラットフォーム デスクトップ タスクを実行します。このスキルは、メイン エージェントに画面の観察、アプリ/ウィンドウのフォーカス、スクリーンショットと入力アクションのヘルパー スクリプトの呼び出し、各ステップの確認、タスク コンテキストのクリーンアップを指示し、タスクが明らかにマルチ ウィンドウまたはマルチ アプリになった場合にのみマルチ エージェント コラボレーションにエスカレーションします。ユーザーがデスクトップ GUI コントロール、ネイティブ アプリ操作、ウィンドウ フォーカス、スクリーンショット、クリック/タイプ フロー、または macOS、Windows、または Linux 上のクロスプラットフォーム デスクトップ ワークフローを必要とする場合に使用します。
