Esegui attività desktop multipiattaforma attraverso una pura competenza OpenClaw che guida l'agente principale a osservare lo schermo, focalizzare app/finestre, chiamare script di supporto per screenshot e azioni di input, verificare ogni passaggio, ripulire il contesto dell'attività e passare alla collaborazione multi-agente solo quando le attività diventano chiaramente multi-finestra o multi-app. Da utilizzare quando l'utente desidera il controllo della GUI desktop, il funzionamento delle app native, lo stato attivo della finestra, screenshot, flussi di clic/tipo o flussi di lavoro desktop multipiattaforma su macOS, Windows o Linux.
