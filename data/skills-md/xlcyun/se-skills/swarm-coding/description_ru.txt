Групповая разработка, используемая для быстрого продвижения крупномасштабной разработки требований, требует первоначального уточнения требований с последующим использованием режима передачи субагентов для быстрого продвижения вперед разработки. Его следует использовать только тогда, когда пользователь явно этого требует.
