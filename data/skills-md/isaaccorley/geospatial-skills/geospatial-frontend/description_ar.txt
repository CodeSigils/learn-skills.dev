أنشئ تطبيقات ويب تجريبية جغرافية مكانية مذهلة بصريًا باستخدام MapLibre Globe وDuckDB-WASM وجمالية HUD الداكنة الدافئة. يُستخدم عند إنشاء عروض توضيحية لاسترجاع صور القمر الصناعي، أو تضمين أدوات التصور، أو واجهات مستخدم البحث الجغرافي المكاني، أو أي واجهة أمامية لاستكشاف البيانات تتمحور حول الخريطة. يتم تشغيل الطلبات لدعم عرض توضيحي جغرافي جديد، أو إنشاء واجهة مستخدم قائمة على الخريطة، أو إنشاء تصور استرجاع/بحث عبر بيانات القمر الصناعي.
