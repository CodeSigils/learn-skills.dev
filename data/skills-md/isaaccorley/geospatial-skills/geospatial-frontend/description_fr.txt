Créez des applications Web de démonstration géospatiales visuellement époustouflantes avec le globe MapLibre, DuckDB-WASM et une esthétique HUD sombre et chaleureuse. À utiliser lors de la création de démos de récupération d'images satellite, de l'intégration d'outils de visualisation, d'interfaces utilisateur de recherche géospatiale ou de toute interface d'exploration de données cartographiques. Se déclenche sur les demandes pour échafauder une nouvelle démo géographique, créer une interface utilisateur basée sur une carte ou créer une visualisation de récupération/recherche sur des données satellite.
