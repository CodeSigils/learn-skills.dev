التحقق من صحة أو تحليل أي مواصفات أو خطة أو قائمة متطلبات باستخدام إطار عمل MECE (الحصري المتبادل والشامل بشكل جماعي). يُستخدم عند مراجعة PRDs، أو قوائم الميزات، أو قصص المستخدمين، أو تصميمات واجهة برمجة التطبيقات (API)، أو إدارة الحالة، أو خرائط الطريق، أو أي تفاصيل منظمة. يُستخدم أيضًا عندما يقول المستخدم "تحقق من هذا"، أو "هل هناك أي شيء مفقود؟"، أو "هل هذا مكتمل؟"، أو "قم بتفكيك هذا".
