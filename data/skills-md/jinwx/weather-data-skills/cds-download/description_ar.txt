قم بتنزيل بيانات المناخ/الطقس من مخزن بيانات المناخ كوبرنيكوس (CDS) باستخدام CDS API. استخدم هذه المهارة عندما يريد المستخدم تنزيل ERA5 أو ERA5-Land أو التنبؤات الموسمية أو أي مجموعة بيانات CDS أخرى. استخدمه أيضًا عندما يذكر المستخدم CDS، أو Climate Data Store، أو ECMWF reana Analysis، أو cdsapi، أو .cdsapirc، أو يسأل عن تنزيل بيانات إعادة تحليل المناخ/الطقس - حتى لو لم يذكر "CDS" صراحة. الأغطية: كتابة نصوص برمجية فعالة للتنزيل، واختيار مجموعة البيانات الصحيحة، وتكوين الوصول إلى واجهة برمجة التطبيقات (API)، وتحسين تقسيم الطلبات، واختيار تنسيقات البيانات (NetCDF vs GRIB).
