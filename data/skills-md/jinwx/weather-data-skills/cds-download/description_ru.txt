Загрузите данные о климате/погоде из хранилища климатических данных Copernicus (CDS) с помощью API CDS. Используйте этот навык всякий раз, когда пользователь хочет загрузить ERA5, ERA5-Land, сезонные прогнозы или любой другой набор данных CDS. Также используйте его, когда пользователь упоминает CDS, хранилище климатических данных, реанализ ECMWF, cdsapi, .cdsapirc или спрашивает о загрузке данных реанализа климата/погоды — даже если он не говорит «CDS» явно. Охватывает: написание эффективных сценариев загрузки, выбор правильного набора данных, настройку доступа к API, оптимизацию разделения запросов и выбор форматов данных (NetCDF или GRIB).
