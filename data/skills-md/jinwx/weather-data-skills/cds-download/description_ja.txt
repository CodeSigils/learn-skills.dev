CDS API を使用して、Copernicus Climate Data Store (CDS) から気候/気象データをダウンロードします。ユーザーが ERA5、ERA5-Land、季節予報、またはその他の CDS データセットをダウンロードする場合は、このスキルを使用します。また、ユーザーが CDS、気候データ ストア、ECMWF 再分析、cdsapi、.cdsapirc について言及したり、気候/気象再分析データのダウンロードについて尋ねたりする場合にも、明示的に「CDS」と言わなくても使用します。内容: 効率的なダウンロード スクリプトの作成、適切なデータセットの選択、API アクセスの構成、リクエスト分割の最適化、データ形式の選択 (NetCDF と GRIB)。
