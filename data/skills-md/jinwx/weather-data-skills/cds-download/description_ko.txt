CDS API를 사용하여 Copernicus Climate Data Store(CDS)에서 기후/날씨 데이터를 다운로드하세요. 사용자가 ERA5, ERA5-Land, 계절별 예측 또는 기타 CDS 데이터세트를 다운로드하려고 할 때마다 이 스킬을 사용하세요. 또한 사용자가 명시적으로 "CDS"라고 말하지 않더라도 CDS, 기후 데이터 저장소, ECMWF 재분석, cdsapi, .cdsapirc를 언급하거나 기후/날씨 재분석 데이터 다운로드에 대해 묻는 경우에도 사용하세요. 다루는 내용: 효율적인 다운로드 스크립트 작성, 올바른 데이터 세트 선택, API 액세스 구성, 요청 분할 최적화, 데이터 형식 선택(NetCDF 및 GRIB).
