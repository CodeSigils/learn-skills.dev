Scarica i dati climatici/meteo dal Copernicus Climate Data Store (CDS) utilizzando l'API CDS. Utilizza questa competenza ogni volta che l'utente desidera scaricare ERA5, ERA5-Land, previsioni stagionali o qualsiasi altro set di dati CDS. Usalo anche quando l'utente menziona CDS, Climate Data Store, rianalisi ECMWF, cdsapi, .cdsapirc o chiede di scaricare dati di rianalisi climatica/meteo, anche se non dice esplicitamente "CDS". Copre: scrivere script di download efficienti, scegliere il set di dati corretto, configurare l'accesso API, ottimizzare la suddivisione delle richieste e selezionare i formati dei dati (NetCDF vs GRIB).
