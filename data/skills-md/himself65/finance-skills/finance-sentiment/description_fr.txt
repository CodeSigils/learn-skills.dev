Récupérez le sentiment boursier structuré sur Reddit, X.com, News et Polymarket à l'aide de l'API Adanos Finance. Utilisez cette compétence chaque fois que l'utilisateur demande combien de personnes parlent d'une action, quelle est la popularité d'un ticker sur les plateformes sociales, combien de paris Polymarket existent pour une entreprise, si les sources sont alignées ou pour comparer le sentiment boursier sur plusieurs tickers. Les déclencheurs incluent : « le sentiment social sur TSLA », « quelle est la popularité de NVDA sur X.com », « combien de mentions Reddit AAPL a-t-il », « comparer le sentiment sur AMD vs NVDA », « combien de paris Polymarket sur Microsoft », « Reddit est-il aligné avec X sur META », « buzz boursier », « pourcentage haussier » et toute mention de recherche multi-sources sur le sentiment boursier. Cette compétence est en LECTURE SEULE et ne place aucune transaction ni ne modifie quoi que ce soit.
