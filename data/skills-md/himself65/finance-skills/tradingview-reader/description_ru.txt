Прочтите настольное приложение TradingView для получения рыночных данных, новостей, оповещений, списков наблюдения и результатов проверки с помощью opencli (только для чтения). Используйте этот навык всякий раз, когда пользователю нужны котировки, цепочки опционов, истечение срока действия опционов, результаты проверки акций/криптовалют/форекс/фьючерсов/облигаций, прибыльных/убыточных/движущихся акций, заголовки новостей или полные тексты статей, оповещения (активный список, журнал пожаров, автономные пожары), списки наблюдения, включая списки цветных флагов, поиск символов/автозаполнение, состояние диаграммы или снимки экрана из их локального приложения TradingView. Триггеры включают в себя: «цепочка опционов для X», «IV на Y», «покажи мне пут SNDK», «телевизионный скринер для сектора Y», «экран перепроданных акций», «TV-выигрыш», «крипто по рыночной капитализации», «новости TradingView на AAPL», «показать мои списки наблюдения», «список красных флагов», «перечислить мои оповещения», «какие оповещения сработали», «поиск ТВ для nvidia», «какой символ находится на моем графике», «скриншот диаграммы NVDA», «Перекос в TradingView IV», «Срок действия ТВ для X». Этот навык доступен ТОЛЬКО ДЛЯ ЧТЕНИЯ — он НЕ размещает сделки, не изменяет списки наблюдения и не меняет макеты графиков.
