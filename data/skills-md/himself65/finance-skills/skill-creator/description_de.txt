Erstellen Sie neue Fähigkeiten, ändern und verbessern Sie bestehende Fähigkeiten und messen Sie die Fähigkeitsleistung. Verwenden Sie diese Funktion, wenn Benutzer eine Fertigkeit von Grund auf neu erstellen, eine vorhandene Fertigkeit aktualisieren oder optimieren, Evaluierungen durchführen möchten, um eine Fertigkeit zu testen, die Fertigkeitsleistung mit einer Varianzanalyse vergleichen oder die Fertigkeitsqualität iterieren möchten. Auslöser: „Eine Fertigkeit erstellen“, „Eine neue Fertigkeit erstellen“, „Eine Fertigkeit erstellen für“, „Eine Fertigkeit schreiben, die“, „Fertigkeit zum Ausführen von „Qualität dieser Fertigkeit“, „Fertigkeitsqualität“, „Fertigkeitsleistung“. Wird auch ausgelöst, wenn ein Benutzer einen wiederholbaren Workflow beschreibt, den er automatisieren möchte, indem er sagt: „Ich mache X weiterhin manuell“, „Können Sie sich erinnern, wie man X macht“ oder „Machen Sie daraus eine Fähigkeit aus“.
