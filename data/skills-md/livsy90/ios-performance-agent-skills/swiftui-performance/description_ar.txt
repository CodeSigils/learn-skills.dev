استخدم هذه المهارة عند مراجعة مشكلات أداء SwiftUI أو إصلاحها، بما في ذلك الإبطال غير الضروري، أو الهوية غير المستقرة، أو تبعيات الحالة الواسعة، أو العمل الجسدي الباهظ الثمن، أو الصفوف الثقيلة، أو عقبات التمرير، أو تكلفة التخطيط/الرسم، أو العمل غير المتزامن في دورة الحياة. لا تستخدمه لبناء جملة SwiftUI العامة، أو التصميم، أو أداء UIKit فقط، أو ملفات التعريف العامة ما لم يكن سلوك تحديث SwiftUI أمرًا أساسيًا.
