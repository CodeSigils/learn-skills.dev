Verwenden Sie diese Fähigkeit, wenn Sie SwiftUI-Leistungsprobleme überprüfen oder beheben, einschließlich unnötiger Invalidierung, instabiler Identität, weitreichender Zustandsabhängigkeiten, teurer Textverarbeitung, umfangreicher Zeilen, Problemen beim Scrollen, Layout-/Zeichnungskosten oder asynchroner Lebenszyklusarbeit. Verwenden Sie es nicht für die allgemeine SwiftUI-Syntax, das Styling, die reine UIKit-Leistung oder die generische Profilerstellung, es sei denn, das Aktualisierungsverhalten von SwiftUI ist von zentraler Bedeutung.
