Используйте этот навык при проверке или исправлении проблем с производительностью SwiftUI, включая ненужную инвалидацию, нестабильную идентификацию, широкие зависимости состояний, дорогостоящую работу с телом, тяжелые строки, заминки при прокрутке, стоимость макета/отрисовки или асинхронную работу жизненного цикла. Не используйте его для общего синтаксиса SwiftUI, стилизации, производительности только для UIKit или общего профилирования, если только поведение обновления SwiftUI не является центральным.
