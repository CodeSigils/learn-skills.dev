Verwenden Sie diese Fähigkeit, wenn Sie die Startleistung von iOS-Apps, Startregressionen, die Bereitschaft für den ersten Frame oder die frühe Reaktionsfähigkeit diagnostizieren. Deckt Pre-Main/Dyld-Arbeit, AppDelegate/SceneDelegate, SwiftUI-App-Start, Start-Orchestrierung, SDK-Initialisierung und Startmessung ab. Nicht für allgemeine Leistungszwecke verwenden, es sei denn, der Code wird im Startpfad ausgeführt.
