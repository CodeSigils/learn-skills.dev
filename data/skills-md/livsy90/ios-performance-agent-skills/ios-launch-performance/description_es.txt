Utilice esta habilidad al diagnosticar el rendimiento del inicio de aplicaciones de iOS, las regresiones de inicio, la preparación para el primer fotograma o la capacidad de respuesta temprana. Cubre el trabajo previo a principal/dyld, AppDelegate/SceneDelegate, inicio de la aplicación SwiftUI, orquestación de lanzamiento, inicialización de SDK y medición de lanzamiento. No lo utilice para rendimiento general a menos que el código se ejecute en la ruta de inicio.
