استخدم هذه المهارة عند اختيار سير عمل ملفات تعريف أداء iOS أو تشغيله أو تفسيره، بما في ذلك تتبعات الأجهزة أو الإشارات أو مقاييس XCTest أو MetricKit أو Xcode Organizer أو حالات التعليق أو العوائق أو وحدة المعالجة المركزية أو التخصيصات أو الرسوم البيانية للذاكرة أو إدخال/إخراج القرص أو الشبكات أو الطاقة أو إشارات أداء الإنتاج. لا تستخدمها كمهارة المجال العميق للإطلاق أو SwiftUI أو التزامن أو الأداء الملموس أو مشكلات وقت التشغيل ما لم تكن المهمة تتعلق بالقياس أو اختيار الأداة أو تفسير التتبع أو التحقق.
