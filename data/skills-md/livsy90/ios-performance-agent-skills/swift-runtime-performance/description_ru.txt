Используйте этот навык при анализе кода Swift на предмет затрат на производительность на уровне выполнения, включая распределение кучи, трафик ARC, хранение стека и кучи, контексты захвата замыкания, отправку метода, отправку свидетеля протокола, экзистенциальные и обобщенные типы, непрозрачные типы, копирование при записи, выходные данные оптимизатора SIL, небезопасные границы памяти или видимость оптимизатора границ модуля. Не используйте его для планирования Swift Concurrency, рендеринга SwiftUI, запуска приложений или рабочих процессов профилирования, если только вопрос не касается затрат времени выполнения Swift.
