Utilisez cette compétence lors de l'examen du code Swift pour les coûts de performances au niveau de l'exécution, y compris l'allocation de tas, le trafic ARC, le stockage pile ou tas, les contextes de capture de fermeture, la répartition des méthodes, la répartition des témoins de protocole, les existentiels par rapport aux génériques, les types opaques, la copie sur écriture, la sortie de l'optimiseur SIL, les limites de mémoire non sécurisées ou la visibilité de l'optimiseur de limite de module. Ne l'utilisez pas pour la planification Swift Concurrency, le rendu SwiftUI, le lancement d'applications ou les workflows de profilage, sauf si la question concerne spécifiquement les coûts d'exécution de Swift.
