قم بترجمة ملخص واجهة المستخدم (صفحة، شاشة، مكون واحد، ميزة) إلى مطالبة جاهزة لللصق لـ Nano Banana Pro / gpt-image-2 / Ideogram / Flux 2 / Midjourney التي تنتج نموذجًا بالحجم الطبيعي على مستوى المصمم كمصدر إلهام بصري - وليس واجهة مستخدم بمواصفات البكسل، وليس انحدارًا للذكاء الاصطناعي. استخدمه عندما يطلب المستخدم "تخيل صفحة X"، أو "محاكاة شاشة Y"، أو "أعطني مطالبة لصورة nanoban/gpt 2 للتصميم"، أو "وصف واجهة المستخدم هذه لنموذج صورة"، أو "صياغة مطالبة للمصمم ليستلهم منها"، أو في أي وقت يحتاج فيه الوكيل إلى إنتاج مطالبة لصورة واجهة المستخدم لسطح منتج حقيقي (صفحة التسعير، لوحة المعلومات، الإعدادات، الإعداد، شاشة الهاتف المحمول، بطل التسويق، المكون الفردي). كن انتهازيًا - قم بالتفعيل حتى عندما يقول المستخدم "تصميم" بدون "مطالبة"، أو "أرني كيف يمكن أن يبدو X" - يجب على الوكيل الوصول إلى هذه المهارة قبل تسليم الموجز يدويًا.
