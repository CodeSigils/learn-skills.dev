UI 概要 (ページ、画面、単一コンポーネント、機能) を Nano Banana Pro / gpt-image-2 / Ideogram / Flux 2 / Midjourney 用の貼り付け可能なプロンプトに変換し、ピクセル仕様の UI や AI のスロップではなく、視覚的なインスピレーションとしてデザイナー グレードのモックアップを生成します。ユーザーが「X ページを想像してください」、「Y スクリーンのモックアップを作成してください」、「nano Banana / gpt image 2 をデザインするためのプロンプトをください」、「画像モデルのこの UI について説明してください」、「デザイナーがインスピレーションを得るためのプロンプトを下書きしてください」、またはエージェントが実際の製品表面 (価格設定ページ、ダッシュボード、設定、オンボーディング、モバイル画面、マーケティング ヒーロー、単一コンポーネント) の UI イメージ生成プロンプトを作成する必要があるときはいつでも使用します。ユーザーが「プロンプト」なしで「デザイン」または「X がどのように見えるかを見せて」と言った場合でも、強引に押しましょう。エージェントはブリーフを手でロールする前に、このスキルに到達する必要があります。
