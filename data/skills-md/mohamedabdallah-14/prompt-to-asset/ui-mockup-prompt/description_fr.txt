Traduisez un brief d'interface utilisateur (une page, un écran, un composant unique, une fonctionnalité) en une invite prête à coller pour Nano Banana Pro / gpt-image-2 / Ideogram / Flux 2 / Midjourney qui produit une maquette de qualité designer comme inspiration visuelle - pas une interface utilisateur aux spécifications de pixels, pas une slop d'IA. À utiliser chaque fois que l'utilisateur demande « imaginez la page X », « simulez l'écran Y », « donnez-moi une invite pour que l'image nano banane / gpt 2 soit conçue », « décrivez cette interface utilisateur pour un modèle d'image », « rédigez une invite dont le concepteur doit s'inspirer », ou chaque fois que l'agent a besoin de produire une invite de génération d'image d'interface utilisateur pour une surface de produit réelle (page de tarification, tableau de bord, paramètres, intégration, écran mobile, héros marketing, composant unique). Soyez insistant – déclenchez même lorsque l'utilisateur dit « concevoir » sans « invite » ou « montre-moi à quoi X pourrait ressembler » — l'agent doit atteindre cette compétence avant de rédiger manuellement un brief.
