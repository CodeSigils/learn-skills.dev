Réécrit les commentaires de révision du code afin qu'ils se lisent comme si un coéquipier humain les avait écrits. Coupe la gorge de l'IA d'entreprise ("J'ai remarqué...", "Je me demandais si peut-être...", "Cela vaut peut-être la peine d'y réfléchir..."). Chaque commentaire est direct : localisation, problème, solution concrète. À utiliser lorsque l'utilisateur dit « humaniser la révision », « supprimer le commentaire PR », « faire en sorte que ce retour sonne humain », « réviser ce PR », « révision du code », « /review », « /unslop-review ». Se déclenche automatiquement lors de l'examen des PR.
