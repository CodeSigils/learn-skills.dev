Schreibt Codeüberprüfungskommentare so um, dass sie sich lesen, als ob ein menschlicher Teamkollege sie geschrieben hätte. Reduziert das Räuspern der Unternehmens-KI („Mir ist aufgefallen …“, „Ich habe mich gefragt, ob vielleicht …“, „Es könnte eine Überlegung wert sein …“). Jeder Kommentar ist direkt: Standort, das Problem, eine konkrete Lösung. Wird verwendet, wenn der Benutzer „Bewertung humanisieren“, „PR-Kommentar entfernen“, „Dieses Feedback menschlich klingen lassen“, „Diese PR überprüfen“, „Codeüberprüfung“, „/review“, „/unslop-review“ sagt. Automatische Auslösung beim Überprüfen von PRs.
