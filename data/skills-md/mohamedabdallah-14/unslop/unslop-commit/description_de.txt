Schreibt Commit-Nachrichten so um, dass sie klingen, als hätte sie ein sorgfältiger menschlicher Ingenieur geschrieben. Beseitigt KI-/Marketing-Schwachsinn („umfassende Lösung“, „robuste Implementierung“, „Hebelwirkung“, „Verbesserung“, „nahtlos“, „Dieser Commit…“). Behält das herkömmliche Commits-Format bei. Betreff ≤72 Zeichen (Ziel ≤50), zwingende Stimmung. Text nur dann, wenn das „Warum“ aus dem Betreff nicht ersichtlich ist. Wird verwendet, wenn der Benutzer „Commit humanisieren“, „Commit-Nachricht entfernen“, „Diesen Commit menschlich klingen lassen“, „/unslop-commit“, „/commit“, „einen Commit schreiben“ sagt oder einen Commit-Entwurf zum Bereinigen einfügt. Automatische Auslösung beim Staging von Änderungen.
