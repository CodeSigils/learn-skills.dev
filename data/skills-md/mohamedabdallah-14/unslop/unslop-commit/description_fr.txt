Supprime les slops d'IA/marketing ("solution complète", "implémentation robuste", "effet de levier", "améliorer", "de manière transparente", "Ce commit..."). Conserve le format de validation conventionnel. Sujet ≤72 caractères (objectif ≤50), mode impératif. Corps uniquement lorsque le « pourquoi » n'est pas évident d'après le sujet. À utiliser lorsque l'utilisateur dit "humaniser le commit", "de-slop commit message", "make this commit sound human", "/unslop-commit", "/commit", "write a commit" ou colle un brouillon de commit pour le nettoyer. Se déclenche automatiquement lors des changements de mise en scène.
