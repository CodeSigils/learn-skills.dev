Очеловечьте файлы памяти на естественном языке (CLAUDE.md, задачи, настройки, документы), удалив AI-измы и добавив пакетный подход, сохраняя при этом каждый блок кода, URL-адрес, путь, команду и заголовок. Два режима: --deterministic (быстрый, на основе регулярных выражений, без API) и LLM (по умолчанию, вызывает Клода для перезаписи). Гуманизированная версия перезаписывает исходный файл. Обычная резервная копия сохранена как FILE.original.md. Триггер: /unslop-file <путь к файлу> или «очеловечить файл памяти»
