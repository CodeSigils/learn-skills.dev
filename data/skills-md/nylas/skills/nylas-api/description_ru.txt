Интегрируйте электронную почту, календарь и контакты с помощью Nylas v3 API. Используйте, когда код импортирует nylas, @nylas/nylas, nylas-python или пользователь спрашивает об API Nylas, интеграции API электронной почты, API календаря, API контактов, разрешениях OAuth, веб-перехватчиках, планировщике, блокноте, интеллектуальном составлении или отправке транзакций. НЕ используйте команды Nylas CLI.
