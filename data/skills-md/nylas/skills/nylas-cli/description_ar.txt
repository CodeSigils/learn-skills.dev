استخدم Nylas CLI لإدارة البريد الإلكتروني والتقويم وجهات الاتصال وSlack وNotetaker من الجهاز. يُستخدم عندما يسأل المستخدم عن أوامر Nylas CLI، أو nylas init، أو nylas email، أو nylas Calendar، أو جهات اتصال nylas، أو nylas auth، أو nylas mcp، أو nylas chat، أو nylas slack، أو nylas notemaker، أو nylas tui، أو nylas air، أو nylas Audit، أو إدارة البريد الإلكتروني/التقويم المستندة إلى المحطة الطرفية. لا تستخدمه لتكامل Nylas API SDK.
