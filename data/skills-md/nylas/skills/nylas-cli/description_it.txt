Utilizza la CLI Nylas per gestire e-mail, calendario, contatti, Slack e Notetaker dal terminale. Da utilizzare quando l'utente richiede informazioni sui comandi CLI di Nylas, nylas init, nylas email, nylas calendar, nylas contatti, nylas auth, nylas mcp, nylas chat, nylas slack, nylas notetaker, nylas tui, nylas air, nylas audit o gestione e-mail/calendario basata su terminale. NON utilizzare per l'integrazione dell'SDK API Nylas.
