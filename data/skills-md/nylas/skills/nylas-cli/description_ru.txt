Используйте Nylas CLI для управления электронной почтой, календарем, контактами, Slack и Notetaker с терминала. Используйте, когда пользователь спрашивает о командах Nylas CLI, nylas init, nylas email, nylas Calendar, nylas Contacts, nylas auth, nylas mcp, nylas Chat, nylas Slack, nylas Notetaker, nylas Tui, nylas Air, nylas Audit или управлении электронной почтой/календарем на базе терминала. НЕ используйте для интеграции Nylas API SDK.
