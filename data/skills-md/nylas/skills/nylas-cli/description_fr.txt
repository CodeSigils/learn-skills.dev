Utilisez la CLI Nylas pour gérer les e-mails, le calendrier, les contacts, Slack et Notetaker depuis le terminal. À utiliser lorsque l'utilisateur pose des questions sur les commandes Nylas CLI, nylas init, nylas email, nylas Calendar, nylas contacts, nylas auth, nylas mcp, nylas chat, nylas slack, nylas notetaker, nylas tui, nylas air, nylas audit ou la gestion des e-mails/calendriers sur terminal. NE PAS utiliser pour l'intégration du SDK API Nylas.
