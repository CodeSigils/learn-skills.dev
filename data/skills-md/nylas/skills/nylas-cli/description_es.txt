Utilice la CLI de Nylas para gestionar el correo electrónico, el calendario, los contactos, Slack y Notetaker desde el terminal. Úselo cuando el usuario pregunte sobre los comandos CLI de Nylas, nylas init, nylas email, nylas calendar, nylas contacts, nylas auth, nylas mcp, nylas chat, nylas slack, nylas notetaker, nylas tui, nylas air, nylas audit o administración de calendario/correo electrónico basada en terminal. NO lo utilice para la integración del SDK API de Nylas.
