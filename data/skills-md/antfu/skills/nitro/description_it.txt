Nitro è il toolkit server indipendente dal framework (che alimenta Nuxt) per creare e distribuire server Web ovunque. Da utilizzare quando si lavora con nitro.config, percorsi server/gestori di eventi, regole di percorso, memorizzazione nella cache, archiviazione, attività, websocket o distribuzione su Node/Bun/Deno/Cloudflare/Vercel.
