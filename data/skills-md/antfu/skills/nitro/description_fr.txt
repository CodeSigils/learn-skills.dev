Nitro est la boîte à outils serveur indépendante du framework (qui alimente Nuxt) pour créer et déployer des serveurs Web n'importe où. À utiliser lorsque vous travaillez avec nitro.config, les routes de serveur/gestionnaires d'événements, les règles de routage, la mise en cache, le stockage, les tâches, les websockets ou le déploiement sur Node/Bun/Deno/Cloudflare/Vercel.
