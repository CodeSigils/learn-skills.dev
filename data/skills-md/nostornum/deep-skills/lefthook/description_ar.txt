تكوين وإدارة خطافات git باستخدام الخطاف الأيسر. يُستخدم عند إعداد خطافات الالتزام المسبق أو الدفع المسبق أو خطافات git الأخرى، أو إضافة الفحص/التنسيق/التحقق من النوع إلى سير عمل الالتزام، أو كتابة أو تحرير lefthook.yml، أو استكشاف أخطاء تنفيذ الخطاف وإصلاحها. يغطي المهام، والتنفيذ المتوازي، وتصفية الملفات المرحلية، و Stage_fixed، وشروط التخطي/فقط، والتجاوزات المحلية ذات الخطاف الأيسر.
