Найдите и реорганизуйте компоненты бога, слишком большие модули, запутанные скрипты и файлы JavaScript или TypeScript с множественной ответственностью. Используйте для безопасной декомпозиции, разделения ответственности и извлечения дублированной логики внутри кодовой базы. Для повторяющихся компонентов пользовательского интерфейса используйте компонентизацию; для извлечения пакета используйте «апертуру».
