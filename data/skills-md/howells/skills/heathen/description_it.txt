Trova ed esegui il refactoring di componenti divine, moduli di grandi dimensioni, script aggrovigliati e file JavaScript o TypeScript multiresponsabilità. Utilizzare per la scomposizione sicura, la suddivisione delle responsabilità e l'estrazione della logica duplicata all'interno di una base di codice. Per i componenti dell'interfaccia utente ripetuti utilizzare "componentize"; per l'estrazione dei pacchetti utilizzare "aperture".
