Encuentre y refactorice componentes divinos, módulos de gran tamaño, scripts enredados y archivos JavaScript o TypeScript de responsabilidad múltiple. Úselo para descomposición segura, división de responsabilidades y extracción de lógica duplicada dentro de una base de código. Para componentes de interfaz de usuario repetidos, utilice `componentize`; para la extracción del paquete utilice `aperture`.
