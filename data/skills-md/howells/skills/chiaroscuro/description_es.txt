Cree una dirección de diseño de interfaz de usuario distintiva y no genérica, estructuras alámbricas, sistemas visuales Tailwind v4, tokens @theme y especificaciones de diseño, además de pulido de interfaz de usuario, modo oscuro, adaptación responsiva y comparación de variantes en vivo. Úselo cuando se le solicite diseñar una interfaz de usuario, establecer una dirección visual, producir una especificación de diseño, eliminar muebles decorativos de la interfaz de usuario o fugas del sistema, hacer que una pantalla sea memorable o limpiar el trabajo de Tailwind/React con apariencia de IA. Asume Tailwind v4. Para auditorías de reutilización o extracción de componentes compartidos, utilice componentes.
