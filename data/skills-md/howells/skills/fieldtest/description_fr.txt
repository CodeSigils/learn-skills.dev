Testez une application Web rendue dans un vrai navigateur et renvoyez des résultats d’assurance qualité étayés par des preuves. À utiliser pour le dogfooding, l'examen de l'hôte local, les défauts réactifs ou mobiles, les vérifications de console ou d'accessibilité, les procédures pas à pas de personnalité et la validation frontale qui doivent exercer l'interface en cours d'exécution plutôt que d'inspecter le code seul.
