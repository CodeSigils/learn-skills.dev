Elimine el código escrito por máquina de una diferencia sin cambiar el comportamiento: comentarios narrativos, envoltorios de una sola persona, guardias imposibles, opciones no utilizadas, registros decorativos y andamios sobrantes. Úselo antes de confirmar o revisar. Para una limpieza alternativa que cambie el comportamiento, utilice `fail-fast`; para prosa utilice `deslop`.
