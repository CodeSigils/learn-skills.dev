Комплексный помощник по командам Git и руководство по рабочему процессу. Срабатывает всякий раз, когда пользователь спрашивает, как выполнить определенную операцию Git, хочет знать, что делает команда Git, нуждается в помощи в исправлении ошибки Git или хочет получить рекомендации по лучшим практикам Git (например, ветвление, перебазирование или сжатие).
