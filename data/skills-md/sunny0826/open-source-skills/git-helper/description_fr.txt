Un assistant de commande Git complet et un guide de workflow. Déclenchez chaque fois que l'utilisateur demande comment effectuer une opération Git spécifique, veut savoir ce que fait une commande Git, a besoin d'aide pour corriger une erreur Git ou souhaite des conseils sur les meilleures pratiques Git (comme le branchement, le rebasage ou l'écrasement).
