Anleitung, Auswahl, Compliance-Überprüfung und Ausarbeitung von Open-Source-Lizenzen. Verwenden Sie diese Fähigkeit, wenn Benutzer Fragen zur Auswahl von Open-Source-Lizenzen, zur Überprüfung der Lizenzkompatibilität, zur Überprüfung von Projekten auf OSS-Konformität, zur Generierung von LIZENZ-/HINWEIS-Dateien oder zum Verständnis bestimmter Lizenzbedingungen stellen. Zu den Auslösern gehören Fragen zu MIT, Apache, GPL, BSD, LGPL, AGPL, MPL, Copyleft, permissiven Lizenzen, Lizenzkompatibilität, SPDX-Kennungen, 木兰宽松许可证, Mulan PSL v2 oder einem beliebigen OSS-Lizenzierungsthema.
