Создавайте стандартную, красиво оформленную документацию `--help` для инструментов интерфейса командной строки (CLI) на основе необработанных аргументов, флагов и описаний. Срабатывает, когда пользователь просит написать текст справки, отформатировать параметры CLI или сгенерировать текст вывода руководства/терминала.
