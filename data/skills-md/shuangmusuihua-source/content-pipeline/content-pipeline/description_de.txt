Inhaltsverarbeitungspipeline: Übersetzung → Entfernen des KI-Geschmacks → Multiplattform-Layout. Wird verwendet, wenn ein Benutzer einen englischen Weblink oder lokalen Text bereitstellt, der ins Chinesische übersetzt und auf Plattformen wie offiziellen WeChat-Konten, Toutiao usw. veröffentlicht werden muss. Unterstützter Workflow: Inhalte erfassen → übersetzen → humanisieren → für mehrere Plattformen formatieren → Vorschau anzeigen.
