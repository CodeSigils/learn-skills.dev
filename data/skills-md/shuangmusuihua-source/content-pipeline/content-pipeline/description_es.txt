Canal de procesamiento de contenido: traducción → eliminación del sabor de IA → diseño multiplataforma.  
Se utiliza cuando un usuario proporciona un enlace a una página web en inglés o un texto local que debe traducirse al chino y publicarse en plataformas como las cuentas oficiales de WeChat, Toutiao, etc.  
Flujo de trabajo admitido: buscar contenido → traducir → humanizar → formatear para múltiples plataformas → vista previa.
