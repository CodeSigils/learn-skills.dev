Canal de procesamiento de contenido: traducción → eliminación del sabor de IA → diseño multiplataforma. Se utiliza cuando un usuario proporciona un enlace web en inglés o un texto local que debe traducirse al chino y publicarse en plataformas como cuentas oficiales de WeChat, Toutiao, etc. Flujo de trabajo admitido: adquirir contenido → traducir → humanizar → formatear para múltiples plataformas → vista previa.
