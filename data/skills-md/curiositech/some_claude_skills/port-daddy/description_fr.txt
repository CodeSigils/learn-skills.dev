Démon de coordination multi-agents pour les agents de codage. À utiliser pour les réclamations de ports déterministes, le suivi de session, la récupération, les réclamations de fichiers, les notes, la publication/sous-marin, la coordination d'espaces tuples, les flottes d'arrière-plan et le débogage des échecs multi-agents dans Claude Code, Codex, Gemini CLI, Cursor ou Windsurf. PAS pour l'orchestration de déploiement de production, la mise en réseau Docker ou Kubernetes ou la découverte de services cloud.
