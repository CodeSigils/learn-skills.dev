برنامج التنسيق متعدد الوكلاء لوكلاء الترميز. يُستخدم لمطالبات المنفذ الحتمية، وتتبع الجلسة، والإنقاذ، ومطالبات الملفات، والملاحظات، والنشر/الفرع، وتنسيق مساحة الصف، وأساطيل الخلفية، وتصحيح أخطاء حالات الفشل المتعددة الوكلاء عبر Claude Code، أو Codex، أو Gemini CLI، أو Cursor، أو Windsurf. ليس لتنسيق نشر الإنتاج أو شبكات Docker أو Kubernetes أو اكتشاف الخدمة السحابية.
