「dq」CLI の使用ガイド — 構造化データ ファイル (YAML、JSON、JSONL、TOML、HCL/Terraform、INI、dotenv、CSV/TSV、XML、Markdown、Dockerfile、ignore-lists) 用のシングルバイナリ Rust ツールとその上にある lint + autofix エンジン。ユーザーがターミナルから構造化データ (Kubernetes マニフェスト、Helm 値、GitHub Actions ワークフロー、Terraform `.tf`、`package.json`、`Cargo.toml`、`pyproject.toml`、`.env`、CSV、Markdown Frontmatter など) をクエリ、インプレース編集、変換、差分、パッチ、lint、または自動修正したい場合は常にこのスキルを使用します。 「pom.xml」。また、ユーザーが「dq」を名前で言及する場合、構造化ファイルに対する JSON Pointer / JSONPath / jq クエリを要求する場合、CI 用の SARIF / JUnit / TAP lint 出力が必要な場合、またはラウンドトリップ保存編集 (YAML/TOML コメントとキー順序を維持する) が必要な場合にも使用します。ユーザーが単に「このマニフェストのイメージ タグをバンプする」、「2 未満のレプリカ数をすべて見つける」、「CI でこれらの YAML をリントする」、または「imagePullPolicy を修正する」と言った場合でも、「dq」がインストールされている場合、このスキルは適用されます。
