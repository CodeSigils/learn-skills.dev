دليل لاستخدام `dq` CLI - أداة Rust ثنائية واحدة لملفات البيانات المنظمة (YAML، JSON، JSONL، TOML، HCL/Terraform، INI، dotenv، CSV/TSV، XML، Markdown، Dockerfile، قوائم التجاهل) ومحرك lint + autofix في الأعلى. استخدم هذه المهارة عندما يريد المستخدم الاستعلام عن البيانات المنظمة أو تحريرها في مكانها أو تحويلها أو تمييزها أو تصحيحها أو فحصها أو إصلاحها تلقائيًا من الوحدة الطرفية - بما في ذلك بيانات Kubernetes أو قيم Helm أو سير عمل GitHub Actions أو Terraform `.tf` أو `package.json` أو `Cargo.toml` أو `pyproject.toml` أو `.env` أو CSV أو Markdown frontmatter أو "بوم.xml". استخدمه أيضًا عندما يذكر المستخدم `dq` بالاسم، أو يطلب استعلامات JSON Pointer / JSONPath / jq على الملفات المنظمة، أو يريد إخراج SARIF / JUnit / TAP lint لـ CI، أو يحتاج إلى عمليات تحرير ذهابًا وإيابًا (الاحتفاظ بتعليقات YAML/TOML وترتيب المفاتيح). حتى عندما يقول المستخدم فقط "احذف علامة الصورة في هذا البيان" أو "اعثر على كل عدد نسخ متماثل أقل من 2" أو "قم بفحص YAMLs هذه في CI" أو "أصلح imagePullPolicy"، تنطبق هذه المهارة عند تثبيت `dq`.
