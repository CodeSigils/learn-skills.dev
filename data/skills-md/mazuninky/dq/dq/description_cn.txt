使用 `dq` CLI 的指南 — 用于结构化数据文件（YAML、JSON、JSONL、TOML、HCL/Terraform、INI、dotenv、CSV/TSV、XML、Markdown、Dockerfile、忽略列表）的单二进制 Rust 工具和顶部的 lint + 自动修复引擎。每当用户想要从终端查询、就地编辑、转换、比较、修补、lint 或自动修复结构化数据时，请使用此技能 - 包括 Kubernetes 清单、Helm 值、GitHub Actions 工作流程、Terraform `.tf`、`package.json`、`Cargo.toml`、`pyproject.toml`、`.env`、CSV、Markdown frontmatter 或 `pom.xml`。当用户通过名称提及“dq”、要求对结构化文件进行 JSON 指针/JSONPath/jq 查询、需要 CI 的 SARIF/JUnit/TAP lint 输出，或者需要往返保留编辑（保留 YAML/TOML 注释和键顺序）时，也可使用。即使用户只是说“在此清单中添加图像标签”、“查找每个低于 2 的副本计数”、“在 CI 中检查这些 YAML”或“修复 imagePullPolicy”，此技能在安装了“dq”时也适用。
