使用 `dq` CLI 的指南 — 用於結構化資料檔案（YAML、JSON、JSONL、TOML、HCL/Terraform、INI、dotenv、CSV/TSV、XML、Markdown、Dockerfile、忽略清單）的單二進位 Rust 工具和頂部的 lint + 自動修復引擎。每當使用者想要從終端查詢、就地編輯、轉換、比較、修補、lint 或自動修復結構化資料時，請使用此技能 - 包括 Kubernetes 清單、Helm 值、GitHub Actions 工作流程、Terraform `.tf`、`package.json`、`Cargo.toml`、`pyproject.stf`、`package.json`、`Cargo.Fatterl`、`pyproject.l`、`py.xml、`R.當使用者透過名稱提及「dq」、要求對結構化檔案進行 JSON 指標/JSONPath/jq 查詢、需要 CI 的 SARIF/JUnit/TAP lint 輸出，或需要往返保留編輯（保留 YAML/TOML 註解和按鍵順序）時，也可使用。即使使用者只是說“在此清單中新增圖像標籤”、“查找每個低於 2 的副本計數”、“在 CI 中檢查這些 YAML”或“修復 imagePullPolicy”，此技能在安裝了“dq”時也適用。
