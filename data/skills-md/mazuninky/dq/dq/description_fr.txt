Guide d'utilisation de la CLI `dq` — un outil Rust monobinaire pour les fichiers de données structurées (YAML, JSON, JSONL, TOML, HCL/Terraform, INI, dotenv, CSV/TSV, XML, Markdown, Dockerfile, ignore-lists) et un moteur lint + autofix en plus. Utilisez cette compétence chaque fois que l'utilisateur souhaite interroger, modifier sur place, convertir, comparer, corriger, lint ou corriger automatiquement des données structurées à partir du terminal - y compris les manifestes Kubernetes, les valeurs Helm, les flux de travail GitHub Actions, Terraform `.tf`, `package.json`, `Cargo.toml`, `pyproject.toml`, `.env`, CSV, Markdown frontmatter ou `pom.xml`. À utiliser également lorsque l'utilisateur mentionne « dq » par son nom, demande des requêtes JSON Pointer / JSONPath / jq sur des fichiers structurés, souhaite une sortie SARIF / JUnit / TAP lint pour CI ou a besoin de modifications aller-retour préservant (en conservant les commentaires YAML/TOML et l'ordre des clés). Même lorsque l'utilisateur dit simplement « ajouter la balise d'image dans ce manifeste », « trouver chaque nombre de répliques inférieur à 2 », « peler ces YAML dans CI » ou « corriger l'imagePullPolicy », cette compétence s'applique lorsque « dq » est installé.
