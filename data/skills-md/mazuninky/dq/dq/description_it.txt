Guida per l'utilizzo della CLI `dq`: uno strumento Rust a binario singolo per file di dati strutturati (YAML, JSON, JSONL, TOML, HCL/Terraform, INI, dotenv, CSV/TSV, XML, Markdown, Dockerfile, ignore-list) e un motore lint + autofix in cima. Utilizza questa competenza ogni volta che l'utente desidera eseguire query, modificare sul posto, convertire, diff, applicare patch, lint o correggere automaticamente dati strutturati dal terminale, inclusi manifest Kubernetes, valori Helm, flussi di lavoro GitHub Actions, Terraform `.tf`, `package.json`, `Cargo.toml`, `pyproject.toml`, `.env`, CSV, Markdown frontmatter o `pom.xml`. Da utilizzare anche quando l'utente menziona `dq` per nome, richiede query JSON Pointer/JSONPath/jq su file strutturati, desidera l'output lint SARIF/JUnit/TAP per CI o necessita di modifiche che preservino il andata e ritorno (mantenendo i commenti YAML/TOML e l'ordine delle chiavi). Anche quando l'utente dice semplicemente "alza il tag immagine in questo manifest", "trova ogni numero di repliche inferiore a 2", "intreccia questi YAML in CI" o "correggi imagePullPolicy", questa abilità si applica quando è installato `dq`.
