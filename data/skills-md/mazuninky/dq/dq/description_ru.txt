Руководство по использованию CLI `dq` — однодвоичного инструмента Rust для файлов структурированных данных (YAML, JSON, JSONL, TOML, HCL/Terraform, INI, dotenv, CSV/TSV, XML, Markdown, Dockerfile, игнор-листов) и движка lint + autofix сверху. Используйте этот навык всякий раз, когда пользователь хочет запросить, отредактировать на месте, преобразовать, сравнить, исправить, проверить или автоматически исправить структурированные данные из терминала, включая манифесты Kubernetes, значения Helm, рабочие процессы GitHub Actions, Terraform `.tf`, `package.json`, `Cargo.toml`, `pyproject.toml`, `.env`, CSV, Markdown Frontmatter или `pom.xml`. Также используйте, когда пользователь упоминает `dq` по имени, запрашивает запросы JSON Pointer/JSONPath/jq к структурированным файлам, хочет получить результаты SARIF/JUnit/TAP lint для CI или нуждается в двустороннем сохранении изменений (с сохранением комментариев YAML/TOML и порядка ключей). Даже когда пользователь просто говорит «увеличить тег изображения в этом манифесте», «найти каждое количество реплик меньше 2», «проверить эти YAML-файлы в CI» или «исправить imagePullPolicy», этот навык применяется, когда установлен `dq`.
