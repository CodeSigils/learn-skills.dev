'dq' CLI 사용 가이드 - 구조화된 데이터 파일(YAML, JSON, JSONL, TOML, HCL/Terraform, INI, dotenv, CSV/TSV, XML, Markdown, Dockerfile, 무시 목록)과 Lint + 자동 수정 엔진을 위한 단일 바이너리 Rust 도구입니다. 사용자가 Kubernetes 매니페스트, Helm 값, GitHub Actions 워크플로, Terraform `.tf`, `package.json`, `Cargo.toml`, `pyproject.toml`, `.env`, CSV, Markdown frontmatter 또는 `pom.xml`을 포함하여 터미널에서 구조화된 데이터를 쿼리, 내부 편집, 변환, diff, 패치, 린트 또는 자동 수정을 원할 때마다 이 기술을 사용하세요. 또한 사용자가 이름으로 `dq`를 언급하거나 구조화된 파일에 대한 JSON 포인터/JSONPath/jq 쿼리를 요청하거나 CI에 대한 SARIF/JUnit/TAP Lint 출력을 원하거나 왕복 보존 편집(YAML/TOML 주석 및 키 순서 유지)이 필요한 경우에도 사용합니다. 사용자가 "이 매니페스트에서 이미지 태그 범프", "2 미만의 모든 복제본 수 찾기", "CI에서 이 YAML 린트" 또는 "imagePullPolicy 수정"이라고 말하는 경우에도 `dq`가 설치되면 이 기술이 적용됩니다.
