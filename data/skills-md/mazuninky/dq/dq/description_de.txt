Anleitung zur Verwendung der „dq“-CLI – einem einzelnen binären Rust-Tool für strukturierte Datendateien (YAML, JSON, JSONL, TOML, HCL/Terraform, INI, dotenv, CSV/TSV, XML, Markdown, Dockerfile, Ignorierlisten) und einer Lint + Autofix-Engine an der Spitze. Verwenden Sie diesen Skill immer dann, wenn der Benutzer strukturierte Daten vom Terminal aus abfragen, direkt bearbeiten, konvertieren, vergleichen, patchen, linten oder automatisch reparieren möchte – einschließlich Kubernetes-Manifesten, Helm-Werten, GitHub Actions-Workflows, Terraform „.tf“, „package.json“, „Cargo.toml“, „pyproject.toml“, „.env“, CSV, Markdown Frontmatter oder „pom.xml“. Verwenden Sie es auch, wenn der Benutzer „dq“ namentlich erwähnt, nach JSON-Zeiger-/JSONPath-/jq-Abfragen für strukturierte Dateien fragt, eine SARIF-/JUnit-/TAP-Lint-Ausgabe für CI wünscht oder Round-Trip-erhaltende Bearbeitungen benötigt (Beibehaltung von YAML/TOML-Kommentaren und Schlüsselreihenfolge). Selbst wenn der Benutzer nur sagt: „Das Image-Tag in diesem Manifest verschieben“, „Jede Replikatanzahl unter 2 finden“, „Diese YAMLs in CI linten“ oder „imagePullPolicy reparieren“, wird diese Fähigkeit angewendet, wenn „dq“ installiert ist.
