Guía para usar la CLI `dq`: una herramienta Rust de binario único para archivos de datos estructurados (YAML, JSON, JSONL, TOML, HCL/Terraform, INI, dotenv, CSV/TSV, XML, Markdown, Dockerfile, ignore-lists) y un motor lint + autofix en la parte superior. Utilice esta habilidad siempre que el usuario quiera consultar, editar en el lugar, convertir, diferenciar, parchear, lint o corregir automáticamente datos estructurados desde la terminal, incluidos manifiestos de Kubernetes, valores de Helm, flujos de trabajo de GitHub Actions, Terraform `.tf`, `package.json`, `Cargo.toml`, `pyproject.toml`, `.env`, CSV, Markdown frontmatter o `pom.xml`. Úselo también cuando el usuario mencione `dq` por su nombre, solicite consultas JSON Pointer / JSONPath / jq en archivos estructurados, quiera salida de pelusa SARIF / JUnit / TAP para CI o necesite ediciones que preserven el ida y vuelta (manteniendo los comentarios YAML/TOML y el orden de las claves). Incluso cuando el usuario simplemente dice "cambiar la etiqueta de imagen en este manifiesto", "buscar cada recuento de réplicas por debajo de 2", "eliminar estos YAML en CI" o "arreglar imagePullPolicy", esta habilidad se aplica cuando se instala `dq`.
