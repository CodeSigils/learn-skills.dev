استدعاء LLMs المستضافة (OpenAI GPT وAnthropic Claude وGoogle Gemini ونماذج الأوزان المفتوحة) من خلال بوابة API / LLM لنماذج Lightning AI - الدردشة والبث والمحادثات متعددة المنعطفات والصور والبيانات الوصفية النموذجية؛ بالإضافة إلى تسجيل نقطة تفتيش طراز Teamspace. يُستخدم عندما يريد المستخدم تشغيل الاستدلال من خلال Lightning.ai، أو مقارنة نماذج البوابة، أو إدارة عناصر النموذج على النظام الأساسي.
