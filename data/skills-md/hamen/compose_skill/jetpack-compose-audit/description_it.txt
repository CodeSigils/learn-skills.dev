Controlla i repository Android Jetpack Compose per prestazioni, gestione dello stato, effetti collaterali e qualità delle API componibili. Esegue la scansione del codice sorgente, assegna un punteggio a ciascuna categoria da 0 a 10, scrive un rigoroso rapporto di riduzione dei costi e riassume le correzioni più importanti. Da utilizzare durante la revisione di una base di codice Compose, la valutazione della qualità del repository, l'ispezione di problemi di ricomposizione/stato o l'esecuzione di un controllo Compose.
