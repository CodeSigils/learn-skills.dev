Orchestrieren Sie die vollständige Implementierung einer Funktion, indem Sie die Aufgabenliste „issues.json“ durchlaufen und „simple-implement“ für jede Aufgabe nacheinander aufrufen, bis alle Aufgaben erledigt sind. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Funktion automatisch vervollständigen, alle Aufgaben durchlaufen, die Implementierung automatisieren oder die gesamte Aufgabenwarteschlange ohne manuelles Eingreifen ausführen möchte. Lösen Sie auf Phrasen wie „Alle Aufgaben ausführen“, „Automatisch implementieren“, „Funktion abschließen“, „Probleme durchgehen“, „Alles implementieren“, „Aufgabenliste ausführen“ oder jede Anforderung aus, die das automatische Durchlaufen von Aufgaben impliziert.
