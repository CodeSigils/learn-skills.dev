Schreiben Sie ein klar definiertes Produkt-/Feature-Spezifikationsdokument (docs/<feature-name>/spec.md) aus der Nachricht, der Eingabedatei oder dem Codebasiskontext eines Benutzers. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Spezifikation erstellen, Anforderungen definieren, Akzeptanzkriterien schreiben, eine Funktion festlegen oder dokumentieren möchte, was vor Beginn der Implementierung erstellt werden muss. Triggern Sie auf Formulierungen wie „Schreiben Sie eine Spezifikation“, „Erstellen Sie Anforderungen“, „Definieren Sie die Funktion“, „Skalieren Sie dies aus“, „Was sollen wir erstellen“, „Spezifizieren Sie dies“ oder jede Anfrage, bei der eine vage Idee in eine strukturierte, umsetzungsreife Spezifikation umgewandelt wird. Wird auch ausgelöst, wenn der Benutzer eine Funktionsbeschreibung bereitstellt und um Dokumentation bittet, die ein KI-Agent vor dem Codieren benötigen würde.
