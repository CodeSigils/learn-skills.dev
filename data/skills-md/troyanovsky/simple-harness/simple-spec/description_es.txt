Escriba un documento de especificación de producto/característica bien definido (docs/<feature-name>/spec.md) a partir de un mensaje de usuario, un archivo de entrada o un contexto de base de código. Utilice esta habilidad siempre que el usuario desee crear una especificación, definir requisitos, escribir criterios de aceptación, determinar el alcance de una característica o documentar lo que se debe crear antes de que comience la implementación. Active frases como "escribir una especificación", "crear requisitos", "definir la característica", "examinar esto", "qué deberíamos construir", "especificar esto" o cualquier solicitud que implique convertir una idea vaga en una especificación estructurada y lista para implementar. También se activa cuando el usuario proporciona una descripción de la función y solicita la documentación que un agente de IA necesitaría antes de codificar.
