Schreiben Sie ein klar definiertes technisches Designdokument (docs/<Feature-Name>/design.md) aus einer Spezifikationsdatei, einer Benutzernachricht oder einem Codebasiskontext. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen technischen Entwurf erstellen, einen Implementierungsansatz planen, Architekturentscheidungen dokumentieren oder beschreiben möchte, wie eine Funktion erstellt werden soll. Triggern Sie auf Formulierungen wie „ein Designdokument schreiben“, „dieses Feature entwerfen“, „die Implementierung planen“, „wie sollen wir das bauen“, „technischer Ansatz“, „Architektur für“ oder jede Anfrage, bei der es darum geht, eine Spezifikations- oder Feature-Idee in ein strukturiertes, umsetzungsbereites technisches Design umzuwandeln. Wird auch ausgelöst, wenn der Benutzer eine spec.md-Datei in einem Feature-Ordner hat und das entsprechende Designdokument haben möchte oder wenn er um Dokumentation bittet, die ein KI-Agent zum Implementieren einer Funktion benötigen würde.
