Escriba un documento de diseño técnico bien definido (docs/<feature-name>/design.md) a partir de un archivo de especificaciones, un mensaje de usuario o un contexto de base de código. Utilice esta habilidad siempre que el usuario quiera crear un diseño técnico, planificar un enfoque de implementación, documentar decisiones de arquitectura o describir cómo se debe construir una característica. Active frases como "escribir un documento de diseño", "diseñar esta característica", "planificar la implementación", "cómo deberíamos construir esto", "enfoque técnico", "arquitectura para" o cualquier solicitud que implique convertir una especificación o idea de característica en un diseño técnico estructurado y listo para la implementación. También se activa cuando el usuario tiene un archivo spec.md en una carpeta de funciones y desea el documento de diseño correspondiente, o cuando solicita documentación que un agente de IA necesitaría para implementar una función.
