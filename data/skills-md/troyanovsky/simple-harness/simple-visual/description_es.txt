Escriba un documento de sistema de diseño visual bien definido (docs/visual.md) a partir de documentación, mensaje de usuario o contexto de base de código. Este es un documento a nivel de aplicación: uno por proyecto, no por función. Utilice esta habilidad siempre que el usuario desee crear un sistema de diseño coherente para su aplicación (que abarque colores, tipografía, espaciado, componentes y pautas visuales) que pueda documentarse y aplicarse en desarrollos futuros. Active frases como "crear un sistema de diseño", "definir el estilo visual", "documentar la apariencia", "pautas visuales", "guía de estilo", "tokens de diseño de interfaz de usuario", "lenguaje de diseño" o cualquier solicitud que implique establecer o extraer una identidad visual coherente para una aplicación. También se activa cuando el usuario quiere reforzar los patrones visuales de una base de código existente en un sistema de diseño formal, o cuando quiere definir la dirección visual antes de que comience la implementación.
