Implemente la siguiente tarea desde la cola de trabajo issues.json de una característica. Esta habilidad lee todos los documentos de características (especificaciones, diseño, elementos visuales, problemas, registro de progreso) en docs/<feature-name>/, selecciona la tarea desbloqueada de mayor prioridad, la implementa, la verifica y actualiza el estado del problema y el registro de progreso. Utilice esta habilidad siempre que el usuario quiera implementar una tarea, trabajar en el siguiente problema, continuar creando una función o avanzar en una lista de tareas. Active frases como "implementar la siguiente tarea", "trabajar en el siguiente problema", "continuar la implementación", "continuar donde lo dejamos", "realizar la siguiente tarea" o cualquier solicitud que implique ejecutar trabajo desde un archivo issues.json. También se activa cuando el usuario señala una ID de tarea específica para implementar.
