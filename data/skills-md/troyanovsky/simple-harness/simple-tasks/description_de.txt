Teilen Sie eine Funktionsspezifikation und ein technisches Design in eine geordnete Liste umsetzbarer Aufgaben (issues-<feature-name>.json) in docs/<feature-name>/ auf. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Aufgabenliste erstellen, eine Funktion in Probleme aufteilen, eine Arbeitswarteschlange erstellen, Implementierungsschritte planen oder eine Spezifikation und einen Entwurf in umsetzbare Aufgaben umwandeln möchte. Lösen Sie auf Phrasen wie „Aufschlüsseln“, „Aufgaben erstellen“, „Probleme generieren“, „Aufgabenliste“, „Arbeitsgliederung“, „Was muss gebaut werden“, „Planen Sie die Arbeit“ oder jede Anforderung aus, die die Konvertierung von Planungsdokumenten in einen geordneten Satz umsetzbarer Einheiten beinhaltet.
