Générateur de modèles de rémotion de livre Buyi. Grâce à un entretien étape par étape fortement guidé, il aide les utilisateurs (y compris les novices en codage) à créer un duo de production vidéo Remotion utilisable à long terme : ① un « Universal Prompt Template.md » dédié (il suffit de copier et de remplir pour chaque vidéo pour commencer) et ② une base de projet _starter/de style personnalisé (palette de couleurs centralisée, composants génériques, blocs de scène, scripts de sous-titres SRT, directives de style). Lorsque l'utilisateur dit « initialiser BuYi Book Remotion Template Generator », « initialiser bys-remotion-template », « Je veux créer mon propre modèle/base/starter Remotion », « aidez-moi à créer un modèle vidéo », « mettre en place un flux de travail Remotion à long terme pour la production vidéo » ou « créer un modèle vidéo dans mon propre style », il doit être déclenché ; même une vague déclaration telle que « Je souhaite utiliser Remotion pour créer des vidéos à long terme, aidez-moi à obtenir un modèle » devrait également le déclencher. Pas pour : la création directe d'un épisode vidéo spécifique (c'est ce que l'utilisateur fait avec le modèle généré) ou les problèmes de codage Remotion sans rapport avec les modèles vidéo.
