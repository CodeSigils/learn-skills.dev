Генератор шаблонов Buyi Book Remotion. Посредством подробного пошагового интервью он помогает пользователям (в том числе новичкам в программировании) создать долгосрочный дуэт для производства видео Remotion: ① специальный «Universal Prompt Template.md» (просто скопируйте и заполните для каждого видео, чтобы начать) и ② основу _starter/проекта в индивидуальном стиле (централизованная цветовая палитра, общие компоненты, блоки сцен, сценарии субтитров SRT, рекомендации по стилю). Когда пользователь говорит «инициализировать генератор шаблонов BuYi Book Remotion», «инициализировать bys-remotion-template», «я хочу создать свой собственный шаблон/базу/стартер Remotion», «помогите мне создать шаблон видео», «настроить долгосрочный рабочий процесс Remotion для производства видео» или «создать шаблон видео в моем собственном стиле», это должно быть запущено; даже расплывчатое заявление типа «Я хочу использовать Remotion для долгосрочного создания видео, помогите мне получить шаблон» также должно спровоцировать его. Не для: непосредственного создания видео определенного эпизода (это то, что пользователь делает с сгенерированным шаблоном) или проблем с кодированием Remotion, не связанных с шаблонами видео.
