Generador de plantillas remotas de libros Buyi. A través de una entrevista paso a paso fuertemente guiada, ayuda a los usuarios (incluidos los novatos en codificación) a crear un dúo de producción de video Remotion utilizable a largo plazo: ① un “Universal Prompt Template.md” dedicado (solo copie y complete cada video para comenzar) y ② una base de proyecto/iniciador de estilo personalizado (paleta de colores centralizada, componentes genéricos, bloques de escena, guiones de subtítulos SRT, pautas de estilo). Cuando el usuario dice “inicializar BuYi Book Remotion Template Generator”, “inicializar bys-remotion-template”, “Quiero crear mi propia plantilla/base/inicio de Remotion”, “ayúdame a crear una plantilla de video”, “configurar un flujo de trabajo de Remotion a largo plazo para la producción de video” o “crear una plantilla de video con mi propio estilo”, se debe activar; Incluso una declaración vaga como "Quiero usar Remotion para hacer videos a largo plazo, ayúdame a conseguir una plantilla" también debería activarlo. No para: crear directamente un episodio de vídeo específico (eso es lo que hace el usuario con la plantilla generada) o problemas de codificación remota no relacionados con las plantillas de vídeo.
