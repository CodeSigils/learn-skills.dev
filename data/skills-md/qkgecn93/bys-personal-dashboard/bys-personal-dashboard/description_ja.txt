Bys パーソナル ダッシュボード ジェネレーター。ガイド付きインタビューを通じて、ユーザー (コーディングの知識がないユーザーも含む) が独自のモバイル個人ダッシュボードを作成するのに役立ちます。左側には永続的な機能バー、右側にはカード ストリームがあり、今日の計画、チェックイン、簿記、体重追跡、スケジュール、語彙、「ツリー ホール」、および実際に毎日使用するその他の項目に直接アクセスできます。これは、アプリのように機能して、携帯電話のホーム画面に展開、公開、追加することができます。

ユーザーが「Bys Personal Dashboard Generator を初期化して」、「bys-personal-dashboard を初期化して」、「自分の個人用ダッシュボードを作りたい」、「Douyin で見たような個人用ダッシュボードが欲しい」、または「毎日のスケジュールをモバイル ページに変えて」と言ったときに、システムがトリガーされる必要があります。ユーザーが他の人のダッシュボードのスクリーンショットを共有して「こういうものが欲しい」と言っただけでも、トリガーされるはずです。

ユーザーがすでにダッシュボードを持っていて、「ダッシュボードに XX 機能を追加する」、「ダッシュボードの配色を変更する」、または「ダッシュボードを変更する」と言った場合は、再初期化するのではなく、反復ワークフローに従います。

ユーザーが「ダッシュボード」という言葉を使用しない場合は、①電話で使用する、②毎日開く、③ユーザーの個人データ (体重、財務状況、チェックイン、To-Do、日記) を保存するという 3 つの特性に基づいて決定します。 3 つすべてが当てはまる場合は、プロセスをトリガーします。たとえば、「体重、簿記、やるべきことを 1 か所に統合​​し、スマートフォンで開くことができるようにしたいと考えています。」ユーザーがその用語を知らなくても、それはダッシュボードです。 3 つのいずれかが欠けている場合は、トリガーしないでください。

単一の機能も重要です。「薬を飲むのをよく忘れるので、毎日携帯電話で薬をチェックしたい」というニーズはシードです。小さな機能のように聞こえるからといって読み飛ばさないでください。

基準は、データがどこに存在するかではなく、データの所有者です。携帯電話で毎日表示したいユーザーの個人簿記 Excel シートはダッシュボードです。レポートに使用される企業の売上データはそうではありません。

適用されないもの: 個人データを保存しない使い捨てツール (宝くじ、電卓、イベント画面やライブストリームに表示されるカウントダウン タイマー)、バックエンド管理システム、チーム用のマルチユーザー コラボレーション ツール、一般公開を目的とした個人のブログ/ポートフォリオ/個人 Web サイト、企業またはビジネスの KPI ダッシュボード (Excel などで構築)、または個人ダッシュボードに関係のない通常の HTML コーディングの質問。
