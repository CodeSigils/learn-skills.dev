ヘッドレス Chrome (Puppeteer) を使用して HTML ファイルを PDF に変換します。これは、atypica が AI 生成の調査レポートに使用しているのと同じアプローチです。ユーザーが HTML ファイル、レポート、または Web ページのスナップショットを PDF にエクスポートする場合は、このスキルを使用します。 「PDF に変換」、「PDF としてエクスポート」、「レポートを PDF として保存」、「HTML から PDF」、「HTML から PDF を生成」などのフレーズ、またはユーザーが .html ファイルを渡してダウンロード可能なドキュメントを要求したときにトリガーされます。ユーザーが「これを PDF にしてください」と言った場合でも、ソースが HTML の場合はこのスキルを使用します。
