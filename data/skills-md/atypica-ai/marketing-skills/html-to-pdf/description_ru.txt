Преобразуйте HTML-файл в PDF-файл с помощью Headless Chrome (Puppeteer) — тот же подход, который компания Atypica использует для своих исследовательских отчетов, созданных с помощью искусственного интеллекта. Используйте этот навык всякий раз, когда пользователь хочет экспортировать HTML-файл, отчет или снимок веб-страницы в PDF. Запускается по таким фразам, как «конвертировать в PDF», «экспортировать в PDF», «сохранить отчет в формате PDF», «из HTML в PDF», «создать PDF из HTML» или когда пользователь передает вам файл .html и просит документ для загрузки. Даже если пользователь просто говорит: «Сделайте это в формате PDF», используйте этот навык, если источником является HTML.
