قم بتحويل ملف HTML إلى ملف PDF باستخدام Chrome بدون رأس (محرك الدمى) - وهو نفس الأسلوب الذي تستخدمه atypica لتقاريرها البحثية التي تم إنشاؤها بواسطة الذكاء الاصطناعي. استخدم هذه المهارة عندما يريد المستخدم تصدير ملف HTML أو تقرير أو لقطة صفحة ويب إلى PDF. قم بتشغيل عبارات مثل "التحويل إلى PDF"، أو "التصدير بتنسيق PDF"، أو "حفظ التقرير بتنسيق PDF"، أو "html إلى pdf"، أو "إنشاء ملف PDF من HTML"، أو عندما يسلمك المستخدم ملفًا بتنسيق .html ويطلب منك مستندًا قابلاً للتنزيل. حتى لو قال المستخدم فقط "قم بإنشاء ملف PDF لهذا"، فاستخدم هذه المهارة إذا كان المصدر HTML.
