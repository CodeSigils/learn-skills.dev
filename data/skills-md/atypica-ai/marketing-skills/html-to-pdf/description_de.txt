Konvertieren Sie eine HTML-Datei mit Headless Chrome (Puppeteer) in eine PDF-Datei – derselbe Ansatz, den Atypica für seine KI-generierten Forschungsberichte verwendet. Verwenden Sie diesen Skill immer dann, wenn der Benutzer eine HTML-Datei, einen Bericht oder einen Webseiten-Snapshot in PDF exportieren möchte. Lösen Sie bei Phrasen wie „in PDF konvertieren“, „als PDF exportieren“, „Bericht als PDF speichern“, „HTML in PDF“, „PDF aus HTML generieren“ aus oder wenn ein Benutzer Ihnen eine .html-Datei überreicht und nach einem herunterladbaren Dokument fragt. Selbst wenn der Benutzer nur sagt: „Erstellen Sie daraus ein PDF“, verwenden Sie diese Fähigkeit, wenn die Quelle HTML ist.
