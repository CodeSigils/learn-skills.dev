Squash all Prisma migrations into a single clean init migration. Use this skill whenever the user wants to squash, collapse, consolidate, or clean up Prisma migrations — even if they say things like "too many migrations", "clean up migration history", "reset migration files", "create a fresh init migration", or "start fresh with Prisma". Trigger on any mention of Prisma + squash/collapse/consolidate/clean/reset/fresh. This skill handles the full workflow: detecting your schema, generating a timestamp, running migrate diff, flagging manual fixes needed (e.g., pgvector HNSW indexes), and marking the migration as applied across environments.
