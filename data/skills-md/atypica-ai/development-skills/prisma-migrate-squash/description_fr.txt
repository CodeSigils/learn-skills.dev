Réduisez toutes les migrations Prisma en une seule migration d’initialisation propre. Utilisez cette compétence chaque fois que l'utilisateur souhaite écraser, réduire, consolider ou nettoyer les migrations Prisma, même s'il dit des choses comme « trop de migrations », « nettoyer l'historique des migrations », « réinitialiser les fichiers de migration », « créer une nouvelle migration d'initialisation » ou « recommencer avec Prisma ». Déclenchez sur toute mention de Prisma + squash/collapse/consolidate/clean/reset/fresh. Cette compétence gère l'intégralité du flux de travail : détecter votre schéma, générer un horodatage, exécuter migrate diff, signaler les correctifs manuels nécessaires (par exemple, les index pgvector HNSW) et marquer la migration comme appliquée dans tous les environnements.
