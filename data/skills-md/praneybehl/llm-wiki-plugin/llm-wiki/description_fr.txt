Créez et maintenez une base de connaissances personnelle organisée par LLM - le modèle "LLM Wiki" de l'essentiel d'Andrej Karpathy d'avril 2026. Utilisez cette compétence chaque fois que l'utilisateur souhaite ingérer une source (papier, article, transcription, PDF, notes) dans une base de connaissances composée persistante, poser une question sur les notes accumulées, pelucher ou auditer une telle base, ou en initialiser une nouvelle. Déclenchez des expressions telles que « ajouter ceci à mon wiki », « ingérer ce document », « compiler ceci dans la base de connaissances », « que dit mon wiki à propos de X », « pelucher le wiki », « construire une base de connaissances à partir de ces documents », « notes de recherche », « deuxième cerveau », « base de connaissances personnelle » ou toute référence au LLM Wiki / OmegaWiki. Déclenchez même lorsque l'utilisateur ne dit pas « wiki » — s'il accumule des sources au fil du temps et souhaite les organiser, cela s'applique. Les échelles de compétences - index fragmentés, pages atomiques, frontmatter YAML et script de recherche intégré empêchent le wiki de devenir un goulot d'étranglement contextuel sur des centaines ou des milliers de pages.
