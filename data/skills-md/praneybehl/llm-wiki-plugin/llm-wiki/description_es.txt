Cree y mantenga una base de conocimientos personales seleccionada por LLM: el patrón "LLM Wiki" de la esencia de abril de 2026 de Andrej Karpathy. Utilice esta habilidad siempre que el usuario quiera ingerir una fuente (artículo, artículo, transcripción, PDF, notas) en una base de conocimiento compuesta persistente, hacer una pregunta sobre notas acumuladas, pelusa o auditar dicha base, o inicializar una nueva. Active frases como "agregar esto a mi wiki", "ingerir este documento", "compilar esto en la base de conocimientos", "¿qué dice mi wiki sobre X?", "limpiar el wiki", "construir una base de conocimientos a partir de estos documentos", "notas de investigación", "segundo cerebro", "base de conocimientos personales" o cualquier referencia a LLM Wiki/OmegaWiki. Se activa incluso cuando el usuario no dice "wiki"; si está acumulando fuentes a lo largo del tiempo y quiere organizarlas, esto se aplica. Las escalas de habilidades (índices fragmentados, páginas atómicas, front-matter YAML y un script de búsqueda incluido evitan que el wiki se convierta en un cuello de botella de contexto en cientos o miles de páginas).
