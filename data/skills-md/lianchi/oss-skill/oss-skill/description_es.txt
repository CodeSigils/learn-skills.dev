A partir del código y los rastros de mantenimiento de los autores, repositorios o equipos de mantenimiento de código abierto, extraiga criterios de ingeniería ejecutables.  
Entrada: (1) Especificar autor/repositorio/equipo → destilación directa; (2) Describa un desafío de desarrollo de software → candidatos a recomendación de diagnóstico.  
Producto: una habilidad de consultor de ingeniería destinada a tareas de codificación (escribir código, revisar, diseñar API, refactorizar, depurar).  
Frases de activación: “DistillXXauthor”, “CreateXXrepository skills”, “AnalyzeXXrepository’s ingeniería style”, “Revisar según el XXstandard”, “UpdateXXskill”.  
Sólo para fines de desarrollo de software; no apto para imitación de tonos, charlas informales, planificación profesional o dominios que no sean de software.  
Se activa solo cuando el usuario desea explícitamente resolver un problema de desarrollo de software desde la perspectiva de un autor, repositorio o equipo de mantenimiento de código abierto.
