Из кода и следов обслуживания авторов открытого исходного кода, репозиториев или групп обслуживания извлекайте работоспособные инженерные решения.  
Ввод: (1) Укажите автора/репозиторий/команду → прямая перегонка; (2) Опишите задачу разработки программного обеспечения → кандидаты на рекомендации по диагностике.  
Результат: навыки инженера-консультанта, направленные на решение задач кодирования (написание кода, рецензирование, проектирование API, рефакторинг, отладка).  
Триггерные фразы: «ДистиллироватьХХавтора», «Навык создания ХХрепозитория», «Анализ инженерного стиля ХХрепозитория», «Проверка в соответствии со стандартом XX», «ОбновитьXXнавык».  
Только для целей разработки программного обеспечения; не для имитации тона, случайной беседы, планирования карьеры или непрограммных областей.  
Активируется только тогда, когда пользователь явно хочет решить проблему разработки программного обеспечения с точки зрения автора открытого исходного кода, репозитория или группы обслуживания.
