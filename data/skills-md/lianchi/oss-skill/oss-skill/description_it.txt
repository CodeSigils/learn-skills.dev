Dal codice e dalle tracce di manutenzione di autori, repository o team di manutenzione open source, estrai giudizi ingegneristici eseguibili.  
Voce: (1) Specificare autore/repository/team → distillazione diretta; (2) Descrivere una sfida di sviluppo software → candidati alla raccomandazione diagnostica.  
Risultato: competenza di consulente tecnico finalizzata ad attività di codifica (scrittura di codice, revisione, progettazione API, refactoring, debug).  
Frasi trigger: "DistillXXauthor", "CreateXXrepository skill", "AnalyzeXXrepository's engineering style", "Review secondo XXstandard", "UpdateXXskill".  
Solo per scopi di sviluppo software; non per imitazione del tono, chat casuale, pianificazione della carriera o domini non software.  
Attivato solo quando l'utente desidera esplicitamente risolvere un problema di sviluppo software dal punto di vista di un autore, repository o team di manutenzione open source.
