Kit de herramientas de publicación automática de Xiaohongshu: utiliza AutoGLM para controlar la automatización móvil para la publicación de notas de Xiaohongshu. Utilice esta habilidad cuando los usuarios soliciten publicar contenido, crear publicaciones o automatizar el flujo de trabajo de publicación en Xiaohongshu. Proporciona orientación paso a paso para dos modos de publicación (notas regulares y publicaciones de formato largo), lo que garantiza un formato de contenido correcto y una navegación precisa en la interfaz de usuario.
