Набор инструментов для автоматической публикации сообщений Xiaohuli: использует AutoGLM для автоматизации публикации заметок на Xiaohuli с помощью управления телефоном. Используйте эту функцию, когда пользователь просит опубликовать контент, создать публикацию или выполнить автоматическую публикацию на Xiaohuli. Он предлагает пошаговые инструкции для двух режимов публикации — обычной заметки и подробной публикации — обеспечивая правильное форматирование и точную навигацию по пользовательскому интерфейсу.
