Instrada le richieste di ricerca empirica attraverso il catalogo delle competenze di ricerca empirica automatica quando l'intero repository è installato come una competenza in Codex, CodeBuddy, Claude Code o un altro IDE. Utilizzalo per scegliere e caricare la competenza AERS giusta per l'inferenza causale, l'econometria, la replica, la scrittura di manoscritti, il controllo delle citazioni, la modifica de-AIGC o flussi di lavoro completi di documenti empirici senza leggere l'intero repository in una sola volta.
