Psychoéducation complète sur les problèmes de santé mentale, les modalités thérapeutiques, les techniques d'adaptation fondées sur des données probantes, les médicaments psychiatriques et les cadres d'auto-évaluation. Ressource éducative uniquement – ​​pas de conseil médical, de diagnostic ou de traitement. À utiliser pour découvrir les concepts de santé mentale, comprendre les options thérapeutiques, explorer les stratégies d'adaptation ou reconnaître quand demander l'aide d'un professionnel. Déclenchez sur « santé mentale », « types de thérapie », « stratégies d'adaptation », « anxiété », « dépression », « TDAH », « médicaments psychiatriques », « quand dois-je consulter un thérapeute ».
