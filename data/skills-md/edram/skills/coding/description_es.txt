Restricciones para escribir y editar código con disciplina: favorezca el código mínimo, el alcance quirúrgico, los nombres que se explican por sí mismos y los comentarios con propósito. Úselo al implementar una característica, escribir o editar código, refactorizar, simplificar, limpiar, agregar una función o revisar cambios para detectar exceso de ingeniería y desplazamiento del alcance.
