Discipline pour écrire du code en testant d'abord - refactor rouge-vert, regardez le test échouer, pas de code de production sans échec du test. À utiliser lors de l'implémentation d'une fonctionnalité ou de la correction d'un test de bogue en premier, de la pratique du TDD, de l'écriture d'un test ayant échoué avant le code ou de la vérification si le travail a réellement été piloté par des tests.
