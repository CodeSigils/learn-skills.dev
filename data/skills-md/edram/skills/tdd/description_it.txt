Disciplina per scrivere il codice test-first: refactoring rosso-verde, guarda il test fallire, nessun codice di produzione senza un test fallito. Da utilizzare quando si implementa una funzionalità o si corregge prima un test di bug, si pratica TDD, si scrive un test fallito prima del codice o si verifica se il lavoro è stato effettivamente basato sui test.
