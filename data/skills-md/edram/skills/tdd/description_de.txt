Disziplin beim Schreiben von Code: Test zuerst – Rot-Grün-Refaktor, zusehen, wie der Test fehlschlägt, kein Produktionscode ohne einen fehlgeschlagenen Test. Verwenden Sie diese Funktion, wenn Sie zuerst eine Funktion implementieren oder einen Fehlertest beheben, TDD üben, einen fehlgeschlagenen Test vor dem Code schreiben oder überprüfen, ob die Arbeit tatsächlich testgetrieben war.
