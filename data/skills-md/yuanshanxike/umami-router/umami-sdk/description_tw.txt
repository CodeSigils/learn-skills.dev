@umami_router/sdk 整合指南 - 用於 Umami Analytics 的 TypeScript SDK。
當用戶詢問以下問題時使用此技能：
- 如何將 @umami_router/sdk 與 Vue 3 或 Next.js 集成
- 如何使用 SDK 追蹤頁面瀏覽量和事件
- 如何配置 Umami 追蹤器選項
- 如何在Vue中使用createUmamiPlugin、useTracker、usePageTrack、useEventTrack
- 如何在 Next.js 中使用 useUmami、usePageviewTracking、useEventTracking
- 有關 TrackerConfig、HealthStatus、TrackOptions 類型的問題
- 如何為 Umami 設定代理伺服器
- 追蹤器初始化或追蹤失敗故障排除
