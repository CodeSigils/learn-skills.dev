دليل التكامل لـ @umami_router/sdk - TypeScript SDK لـ Umami Analytics.
استخدم هذه المهارة عندما يسأل المستخدمون عن:
- كيفية دمج @umami_router/sdk مع Vue 3 أو Next.js
- كيفية تتبع مشاهدات الصفحة والأحداث باستخدام SDK
- كيفية تكوين خيارات تعقب Umami
- كيفية استخدام createUmamiPlugin وuseTracker وusePageTrack وuseEventTrack في Vue
- كيفية استخدام useUmami، وusePageviewTracking، وuseEventTracking في Next.js
- أسئلة حول أنواع TrackerConfig وHealthStatus وTrackOptions
- كيفية إعداد الخادم الوكيل لـ Umami
- استكشاف أخطاء تهيئة المتعقب أو فشل التتبع وإصلاحها
