@umami_router/sdk 통합 가이드 - Umami Analytics용 TypeScript SDK.
사용자가 다음에 관해 질문할 때 이 기술을 사용하세요.
- @umami_router/sdk를 Vue 3 또는 Next.js와 통합하는 방법
- SDK를 사용하여 페이지뷰 및 이벤트를 추적하는 방법
- Umami 추적기 옵션을 구성하는 방법
- Vue에서 createUmamiPlugin, useTracker, usePageTrack, useEventTrack을 사용하는 방법
- Next.js에서 useUmami, usePageviewTracking, useEventTracking을 사용하는 방법
- TrackerConfig, HealthStatus, TrackOptions 유형에 관한 질문
- Umami용 프록시 서버를 설정하는 방법
- 추적기 초기화 또는 추적 실패 문제 해결
