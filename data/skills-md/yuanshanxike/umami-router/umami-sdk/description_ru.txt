Руководство по интеграции @umami_router/sdk — TypeScript SDK для Umami Analytics.
Используйте этот навык, когда пользователи спрашивают о:
- Как интегрировать @umami_router/sdk с Vue 3 или Next.js
- Как отслеживать просмотры страниц и события с помощью SDK
- Как настроить параметры трекера Umami
- Как использовать createUmamiPlugin, useTracker, usePageTrack, useEventTrack в Vue
- Как использовать useUmami, usePageviewTracking, useEventTracking в Next.js.
- Вопросы о типах TrackerConfig, HealthStatus, TrackOptions.
- Как настроить прокси-сервер для Умами
- Устранение неполадок при инициализации трекера или сбоев отслеживания.
