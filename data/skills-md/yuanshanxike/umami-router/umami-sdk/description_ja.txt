@umami_router/sdk - Umami Analytics 用の TypeScript SDK の統合ガイド。
ユーザーが次のことについて質問する場合は、このスキルを使用します。
- @umami_router/sdk を Vue 3 または Next.js と統合する方法
- SDK を使用してページビューとイベントを追跡する方法
- Umami トラッカー オプションの設定方法
- Vue での createUmamiPlugin、useTracker、usePageTrack、useEventTrack の使用方法
- Next.jsでのuseUmami、usePageviewTracking、useEventTrackingの使い方
- TrackerConfig、HealthStatus、TrackOptions タイプに関する質問
- Umamiのプロキシサーバーの設定方法
- トラッカーの初期化または追跡の失敗のトラブルシューティング
