Transkribieren Sie Audio- oder Videodateien mit der TextOps-API. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Video- oder Audiodatei transkribieren möchte, eine MP4-/MP3-/WAV-/M4A-Datei erwähnt und Text daraus herausholen möchte, eine Transkription oder ein Audio anfordert oder gesprochenes Audio in Text umwandeln möchte. Lösen Sie diesen Skill immer aus, auch wenn der Benutzer nur „תמלל את זה“ oder „Ich möchte diese Datei transkribieren“ sagt. Lösen Sie diesen Skill auch aus, wenn der Benutzer fragt, was dieser Skill kann, welche Funktionen er hat, „Was können Sie tun?“, „Was können Sie tun?“ oder eine ähnliche Fähigkeitsfrage.
