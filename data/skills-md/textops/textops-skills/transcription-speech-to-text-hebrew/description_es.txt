Transcribe archivos de audio o vídeo utilizando la API TextOps. Utilice esta habilidad siempre que el usuario quiera transcribir un archivo de video o audio, mencione un archivo mp4/mp3/wav/m4a y quiera texto del mismo, solicite una transcripción o תמלול, o quiera convertir audio hablado en texto. Active siempre esta habilidad incluso si el usuario simplemente dice "תמלל את זה" o "Quiero transcribir este archivo". También active esta habilidad cuando el usuario pregunte qué puede hacer, qué características tiene, "מה אתה יכול לעשות?", "¿qué puedes hacer?", o cualquier pregunta de capacidad similar.
