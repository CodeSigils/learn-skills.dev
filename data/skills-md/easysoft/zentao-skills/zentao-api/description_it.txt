Chiama l'API Zen（ZenTao）RESTful v2.0 per soddisfare le richieste degli utenti, tra cui l'esecuzione di query su progetti, esecuzioni, requisiti, bug, attività, casi di test ed esecuzione di operazioni di scrittura come creazione, modifica ed eliminazione. Utilizza questa abilità quando l'utente menziona Zen（禅/ZenTao), l'avanzamento del progetto, gli elenchi di bug, gli aggiornamenti dello stato dei requisiti o la creazione di attività.
