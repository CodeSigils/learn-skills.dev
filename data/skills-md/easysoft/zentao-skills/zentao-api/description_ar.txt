اتصل بـ Zen(ZenTao)RESTful API v2.0 لتلبية طلبات المستخدم، بما في ذلك الاستعلام عن المشاريع وعمليات التنفيذ والمتطلبات والأخطاء والمهام وحالات الاختبار وتنفيذ عمليات الكتابة مثل الإنشاء والتحرير والحذف. استخدم هذه المهارة عندما يذكر المستخدم Zen(禅/ZenTao)، أو تقدم المشروع، أو قوائم الأخطاء، أو تحديثات حالة المتطلبات، أو إنشاء المهام.
