Вызовите Zen（ZenTao）RESTful API v2.0 для выполнения пользовательских запросов, включая запросы проектов, выполнение, требования, ошибки, задачи, тестовые примеры и выполнение операций записи, таких как создание, редактирование и удаление. Используйте этот навык, когда пользователь упоминает Zen（禅/ZenTao), ход проекта, списки ошибок, обновления статуса требований или создание задач.
