Wird verwendet, wenn das Blueprint-Ausführungs-Gate eine unabhängige Second-Harness-Überprüfung des kumulativen Diffs eines Strikethroo-Plans in diesem Repository anfordert. Zu den Auslösern gehören das Code-Review-Gate, die Überprüfung des Plan-Diffs, die Überprüfung des zweiten Modells, der CODE_REVIEW-Hook und die Überprüfung des kumulativen Diffs. Nicht verwenden, um eine einzelne Aufgabe zu überprüfen, Code außerhalb eines Strikethroo-Plans zu überprüfen oder allgemeine Meinungen zur Codequalität oder zum Stil abzugeben.
