Wird verwendet, wenn der Benutzer darum bittet, einen neuen Strikethroo-Plan für einen Arbeitsauftrag, eine Funktion oder eine Initiative in diesem Repository zu entwerfen, festzulegen oder zu verfassen. Zu den Auslösern gehören „Plan erstellen“, „Neuer Plan“, „Dies planen“, „Einen Plan festlegen“, „Strikethroo-Plan“. Nicht verwenden, um einen bestehenden Plan in Aufgaben zu zerlegen, einen Plan auszuführen oder für allgemeines Brainstorming außerhalb von Strikethroo.
