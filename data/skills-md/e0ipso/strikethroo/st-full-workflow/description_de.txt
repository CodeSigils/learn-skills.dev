Verwenden Sie diese Option, wenn der Benutzer den vollständigen End-to-End-Workflow von Strikethroo für einen Arbeitsauftrag auf einmal in diesem Repository ausführen möchte. Zu den Auslösern gehören vollständiger Workflow, End-to-End, Planen und Ausführen, alles erledigen und Ausführen des gesamten Strikethroo-Workflows. Nicht verwenden, wenn der Benutzer nur eine Phase wünscht (einen Plan erstellen, Aufgaben generieren oder einen Entwurf ausführen); Verwenden Sie stattdessen die entsprechende Fertigkeit für diese Phase.
