Ein Tool für Produktanforderungen über den gesamten Lebenszyklus, das Personas, User Journey Maps, Product Backlogs/User Stories und PRD-Schreiben abdeckt. Immer wenn der Benutzer Zielbenutzer definieren, Personas erstellen, Benutzerreisen abbilden, Schwachstellen identifizieren, Funktionen aufschlüsseln, Benutzergeschichten schreiben, ein Backlog erstellen, ein PRD entwerfen, Akzeptanzkriterien festlegen oder Produktarbeiten von der Benutzerrecherche bis zu Anforderungsdokumenten durchführen muss, muss diese Fähigkeit verwendet werden – auch wenn der Benutzer nur einen Schritt erwähnt (z. B. nur das Schreiben eines PRD oder das Erstellen von Personas).
