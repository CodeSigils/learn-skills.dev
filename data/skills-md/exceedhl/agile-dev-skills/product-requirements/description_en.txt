A full-link product-requirements tool covering Persona, User Journey Map, Backlog/User Stories, and PRD writing. Whenever the user needs to define target users, create personas, map user journeys, identify pain points, break down features, write user stories, build a backlog, draft a PRD, set acceptance criteria, or perform any product work from user research to requirement documents, this skill must be used. Even if only one step is mentioned (e.g., writing a PRD or creating a persona), apply this skill.
