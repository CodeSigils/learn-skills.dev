A full-lifecycle product-requirements tool covering Personas, User Journey Maps, Product Backlogs / User Stories, and PRD writing. Whenever users need to define target users, create personas, draw journey maps, identify pain points, break down features, write user stories, build backlogs, draft PRDs, set acceptance criteria, or perform any product work from user research to requirement documents, always use this skill. Even if the user mentions only one step (e.g., writing a PRD or creating a persona), still use this skill.
