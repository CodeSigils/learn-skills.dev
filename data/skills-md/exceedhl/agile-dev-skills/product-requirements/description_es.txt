Una herramienta de requisitos de producto de ciclo de vida completo que cubre personas, mapas de viaje de usuario, trabajos pendientes de producto/historias de usuario y redacción de PRD. Siempre que los usuarios necesiten definir usuarios objetivo, crear personas, dibujar mapas de viaje, identificar puntos débiles, desglosar características, escribir historias de usuarios, crear trabajos pendientes, redactar PRD, establecer criterios de aceptación o realizar cualquier trabajo de producto, desde investigación de usuarios hasta documentos de requisitos, utilice siempre esta habilidad. Incluso si el usuario menciona solo un paso (por ejemplo, escribir un PRD o crear una persona), utilice esta habilidad.
