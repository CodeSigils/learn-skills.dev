أداة دورة حياة كاملة لمتطلبات المنتج تغطي الأشخاص وخرائط رحلة المستخدم وتراكمات المنتجات/قصص المستخدمين وتأليف PRD. عندما يحتاج المستخدمون إلى تحديد المستخدمين المستهدفين، أو إنشاء شخصيات، أو رسم خريطة لرحلات المستخدم، أو تحديد نقاط الألم، أو تقسيم الميزات، أو كتابة قصص المستخدم، أو إنشاء الأعمال المتراكمة، أو صياغة PRDs، أو تعيين معايير القبول، أو تنفيذ أي عمل منتج بدءًا من بحث المستخدم وحتى توثيق المتطلبات، قم دائمًا باستدعاء هذه المهارة. استخدمه حتى إذا ذكر المستخدم خطوة واحدة فقط (على سبيل المثال، كتابة بيان تعريف المنتج أو إنشاء شخصية فقط).
