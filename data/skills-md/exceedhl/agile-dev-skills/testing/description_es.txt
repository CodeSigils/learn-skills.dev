Redacte y organice pruebas automatizadas, incluidas pruebas unitarias, de integración, E2E y de rendimiento. Siempre que el usuario necesite escribir pruebas, diseñar datos de prueba, organizar archivos de prueba, discutir estrategias de prueba, crear un conjunto de datos dorado o garantizar la cobertura de flujos normales y anormales, utilice siempre esta habilidad. Incluso si el usuario menciona solo un tipo de prueba (por ejemplo, solo E2E), use esta habilidad para garantizar el cumplimiento de los principios de prueba del proyecto.
