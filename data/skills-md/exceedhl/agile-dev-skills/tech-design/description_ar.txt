تصميم البنية التقنية بناءً على المتطلبات، بما في ذلك اختيار التكنولوجيا، ومخططات بنية النظام، وتصميم قاعدة البيانات، وتصميم واجهة برمجة التطبيقات (API)، وتصميم مكونات الواجهة الأمامية، وهندسة النشر، وإعداد بيئة التطوير المحلية. استخدم هذه المهارة دائمًا عندما يحتاج المستخدمون إلى تحويل قصص المستخدم أو PRDs إلى حلول تقنية، أو تحديد اختيارات تقنية، أو تصميم بنية النظام، أو رسم مخططات ER، أو مخططات قاعدة بيانات التصميم، أو تخطيط واجهات API، أو مكونات الواجهة الأمامية الأساسية، أو تخطيط استراتيجيات النشر، أو كتابة أدلة الإعداد، أو التعامل مع المتطلبات غير الوظيفية (الأمان/الأداء/قابلية المراقبة)، أو تحديث الوثائق الفنية لتعكس تغييرات التعليمات البرمجية.
