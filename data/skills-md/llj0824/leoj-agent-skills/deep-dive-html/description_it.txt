Crea spiegazioni approfondite e autonome in HTML per ricerche, indagini, architettura, strategia e comunicazione tecnica. Trasforma un'attività, un sistema, un piano, un'indagine sul repository o una spiegazione tecnica in un artefatto HTML a file singolo con una forte progettazione delle informazioni, diagrammi SVG in linea e un'estetica da pubblicazione tecnica. Da utilizzare quando l'output merita più di un ribasso ma meno di un'app completa.
