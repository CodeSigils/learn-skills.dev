Referenz zur Arco Design Vue UI-Komponentenbibliothek, die auf Vue 3 und „@arco-design/web-vue“ abzielt. Wird verwendet, wenn ein Benutzer die Erstellung von Vue-Seiten, die Erstellung einer Vue-Benutzeroberfläche, das Schreiben von Frontend-Code mit Arco Vue, die Entwicklung von Vue-Dashboards oder -Anwendungen anfordert oder Arco Design Vue, „@arco-design/web-vue“, „a-button“, „a-table“, „a-form“, „a-modal“, „a-select“, „Message“ oder einen beliebigen Arco Vue-Komponentennamen erwähnt. Behandelt Installation, globale Registrierung, On-Demand-Laden, Design, Internationalisierung, Vue 3 Composition API-Konventionen, Komponenten-Requisiten/Ereignisse/Slots, Beispiele, Formulare, Tabellen, Modalitäten, Navigation, Dateneingabe, Datenanzeige, Feedback und responsives Layout.
