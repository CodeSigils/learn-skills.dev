Referencia de la biblioteca de componentes de UI de Arco Design Vue, dirigida a Vue 3 y `@arco-design/web-vue`. Úselo cuando un usuario solicita crear páginas de Vue, crear una interfaz de usuario de Vue, escribir código de interfaz de usuario con Arco Vue, desarrollar paneles o aplicaciones de Vue, o menciona Arco Design Vue, `@arco-design/web-vue`, `a-button`, `a-table`, `a-form`, `a-modal`, `a-select`, `Message` o cualquier nombre de componente de Arco Vue. Cubre la instalación, el registro global, la carga bajo demanda, la temática, la internacionalización, las convenciones de la API de composición de Vue 3, los accesorios/eventos/espacios de los componentes, ejemplos, formularios, tablas, modales, navegación, entrada de datos, visualización de datos, comentarios y diseño responsivo.
