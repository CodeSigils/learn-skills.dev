Riferimento alla libreria dei componenti dell'interfaccia utente di Arco Design Vue, destinata a Vue 3 e "@arco-design/web-vue". Utilizzare quando un utente richiede la creazione di pagine Vue, la creazione dell'interfaccia utente Vue, la scrittura di codice front-end con Arco Vue, lo sviluppo di dashboard o applicazioni Vue o menziona Arco Design Vue, `@arco-design/web-vue`, `a-button`, `a-table`, `a-form`, `a-modal`, `a-select`, `Message` o qualsiasi nome di componente Arco Vue. Copre installazione, registrazione globale, caricamento su richiesta, temi, internazionalizzazione, convenzioni API Vue 3 Composition, oggetti di scena/eventi/slot dei componenti, esempi, moduli, tabelle, modalità, navigazione, immissione dati, visualizzazione dati, feedback e layout reattivo.
