Référence de la bibliothèque de composants d'interface utilisateur Arco Design Vue, ciblant Vue 3 et `@arco-design/web-vue`. À utiliser lorsqu'un utilisateur demande la création de pages Vue, la création d'une interface utilisateur Vue, l'écriture de code frontal avec Arco Vue, le développement de tableaux de bord ou d'applications Vue, ou mentionne Arco Design Vue, `@arco-design/web-vue`, `a-button`, `a-table`, `a-form`, `a-modal`, `a-select`, `Message` ou tout autre nom de composant Arco Vue. Couvre l'installation, l'enregistrement global, le chargement à la demande, la thématique, l'internationalisation, les conventions de l'API de composition Vue 3, les accessoires/événements/emplacements de composants, les exemples, les formulaires, les tableaux, les modaux, la navigation, la saisie de données, l'affichage des données, les commentaires et la mise en page réactive.
