قم بإنشاء مجموعة باستخدام Deckx. يُستخدم عندما يذكر المستخدم "deckx" أو "deck" أو "slides"، أو يطلب إنشاء مجموعة شرائح من MDX، أو يطلب تحويل لوحة ألوان العلامة التجارية إلى ورقة أنماط مجموعة، أو يسأل عن كيفية تحويل مجموعة Deckx HTML إلى ملف PDF. يغطي تخطيط المشروع، وتكوين Deckx.toml، وتأليف Deck.mdx، ومكونات React المخصصة، وعقد الرمز المميز style.css، وأمر Chrome بدون رأس PDF.
