Scegli il modulo di pianificazione per un nuovo lavoro e pianificalo prima dell'esecuzione. Utilizza questa abilità per decidere se il lavoro è senza attività, solo chat, un file di attività, un file di attività con attività secondarie o più file di attività/elementi di backlog e per creare il piano necessario per il lavoro di implementazione non banale o il lavoro di indagine che necessita di una propria attività.
