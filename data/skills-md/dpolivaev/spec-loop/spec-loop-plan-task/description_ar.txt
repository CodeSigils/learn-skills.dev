اختيار نموذج التخطيط للعمل الجديد والتخطيط له قبل التنفيذ. استخدم هذه المهارة لتحديد ما إذا كان العمل بدون مهام، أو للدردشة فقط، أو ملف مهمة، أو ملف مهمة بمهام فرعية، أو ملفات مهام متعددة/عناصر متراكمة، ولإنشاء الخطة المطلوبة لأعمال التنفيذ غير التافهة أو أعمال التحقيق التي تحتاج إلى مهمة خاصة بها.
