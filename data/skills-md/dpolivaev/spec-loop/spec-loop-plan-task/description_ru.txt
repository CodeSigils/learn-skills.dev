Выберите форму планирования новой работы и спланируйте ее перед выполнением. Используйте этот навык, чтобы решить, является ли работа беззадачной, только для чата, файлом задачи, файлом задачи с подзадачами или несколькими файлами задач/элементами невыполненной работы, а также создать необходимый план для нетривиальной работы по реализации или исследовательской работы, для которой требуется отдельная задача.
