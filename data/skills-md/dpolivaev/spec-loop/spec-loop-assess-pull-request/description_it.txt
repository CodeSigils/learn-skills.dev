Abilità facoltativa. Ricostruisci un file di preparazione alla revisione umana da una richiesta pull esistente, una richiesta di unione, un branch diff o un intervallo di commit in un repository di cui l'utente si fida. Da utilizzare quando l'utente desidera una comprensione retrospettiva delle modifiche già implementate, valutazioni e raccomandazioni dal lato dell'intelligenza artificiale e una variante di condivisione facoltativa specifica del provider scritta in un file locale quando necessario.
