Optionale Fähigkeit. Rekonstruieren Sie eine Datei zur Vorbereitung der menschlichen Überprüfung aus einem vorhandenen Pull-Request, Merge-Request, Branch-Diff oder Commit-Bereich in einem Repository, dem der Benutzer vertraut. Verwenden Sie diese Option, wenn der Benutzer ein nachträgliches Verständnis bereits implementierter Änderungen, eine KI-seitige Bewertung und Empfehlungen sowie eine optionale anbieterspezifische Freigabevariante wünscht, die bei Bedarf in eine lokale Datei geschrieben wird.
