Compatta un file di attività attivo senza cambiarne il significato. Da utilizzare quando si converte un'attività senza sottoattività in un modulo di sottoattività, quando si aggiunge una nuova attività secondaria dopo che le sottoattività precedenti contengono già il contenuto della sezione completa, quando il contenuto della sezione duplicata deve essere compattato prima della richiesta di approvazione o quando un file di attività è diventato troppo grande per essere utilizzato in sicurezza.
