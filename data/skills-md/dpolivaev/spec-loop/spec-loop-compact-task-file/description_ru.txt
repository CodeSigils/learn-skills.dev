Сжать файл активной задачи, не меняя значения. Используйте при преобразовании задачи без подзадач в форму подзадачи, при добавлении новой подзадачи после того, как предыдущие подзадачи уже содержат полное содержимое раздела, когда дублированное содержимое раздела необходимо сжать перед запросом утверждения или когда файл задачи стал слишком большим для безопасного использования.
