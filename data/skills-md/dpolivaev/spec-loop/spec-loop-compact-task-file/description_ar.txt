ضغط ملف مهمة نشط دون تغيير المعنى. يُستخدم عند تحويل مهمة ليست فرعية إلى نموذج مهمة فرعية، أو عند إضافة مهمة فرعية جديدة بعد أن تحتوي المهام الفرعية السابقة بالفعل على محتوى القسم الكامل، أو عندما يجب ضغط محتوى القسم المكرر قبل طلب الموافقة، أو عندما يصبح ملف المهمة كبيرًا جدًا بحيث لا يمكن استخدامه بأمان.
