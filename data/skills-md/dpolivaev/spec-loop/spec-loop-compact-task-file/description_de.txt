Komprimieren Sie eine aktive Aufgabendatei, ohne ihre Bedeutung zu ändern. Verwenden Sie diese Option, wenn Sie eine Aufgabe ohne Unteraufgabe in eine Unteraufgabenform konvertieren, wenn Sie eine neue Unteraufgabe hinzufügen, nachdem frühere Unteraufgaben bereits den vollständigen Abschnittsinhalt enthalten, wenn duplizierte Abschnittsinhalte vor der Genehmigungsanfrage komprimiert werden sollten oder wenn eine Aufgabendatei zu groß geworden ist, um sicher verwendet zu werden.
