Compacte un archivo de tarea activo sin cambiar su significado. Úselo cuando convierta una tarea sin subtarea a un formato de subtarea, cuando agregue una nueva subtarea después de que subtareas anteriores ya contengan contenido de sección completo, cuando el contenido de la sección duplicada deba compactarse antes de buscar aprobación o cuando un archivo de tarea se haya vuelto demasiado grande para usarlo de manera segura.
