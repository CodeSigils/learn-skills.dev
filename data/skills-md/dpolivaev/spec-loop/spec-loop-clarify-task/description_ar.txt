قم بإشراك المستخدم لحل القرارات المفتوحة المهمة في عمل Spec Loop، بما في ذلك المهام والخطط وتحديثات التصميم وتفاصيل العمل ونقاط تفتيش التنفيذ وصياغة ADR. يُستخدم عندما يطلب المستخدم التوضيح، أو مقارنة الخيارات، أو مناقشة المعايير، أو اختبار الضغط، أو عندما يمكن للإجابات المختلفة أن تغير بشكل جوهري النطاق أو السلوك أو السياسة أو القيود أو المسار أو التصميم أو مواصفات الاختبار أو محتوى ADR. يوفر فحصًا إلزاميًا للقرارات بالنسبة لسير العمل الذي يتطلب ذلك قبل كتابة محتوى Spec Loop التابع أو مراجعته. استخدمه أيضًا للشواء العام عند تحديده بشكل صريح.
