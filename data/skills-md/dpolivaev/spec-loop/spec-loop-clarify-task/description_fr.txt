Engagez l'utilisateur pour résoudre les décisions ouvertes importantes dans le travail de Spec Loop, y compris les tâches, les plans, les mises à jour de conception, les répartitions du travail, les points de contrôle de mise en œuvre et la rédaction ADR. À utiliser lorsque l'utilisateur demande des éclaircissements, compare des options, discute de critères ou de tests de résistance, ou lorsque différentes réponses pourraient modifier sensiblement la portée, le comportement, la politique, les contraintes, l'itinéraire, la conception, la spécification de test ou le contenu de l'ADR. Fournit un contrôle de décision obligatoire pour les flux de travail qui le nécessitent avant que le contenu dépendant de Spec Loop ne soit écrit ou révisé. Également utilisé pour les grillades générales lorsqu'il est explicitement sélectionné.
