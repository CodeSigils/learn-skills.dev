Coinvolgere l'utente nella risoluzione di importanti decisioni aperte nel lavoro Spec Loop, tra cui attività, piani, aggiornamenti di progettazione, suddivisioni del lavoro, punti di controllo dell'implementazione e redazione di ADR. Utilizzare quando l'utente chiede di chiarire, confrontare opzioni, discutere criteri o eseguire stress test o quando risposte diverse potrebbero modificare materialmente l'ambito, il comportamento, la politica, i vincoli, il percorso, la progettazione, le specifiche del test o il contenuto ADR. Fornisce lo screening decisionale obbligatorio per i flussi di lavoro che lo richiedono prima che il contenuto Spec Loop dipendente venga scritto o rivisto. Utilizzare anche per grigliate generali quando selezionato esplicitamente.
