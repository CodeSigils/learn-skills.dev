Involucrar al usuario para resolver decisiones abiertas importantes en el trabajo de Spec Loop, incluidas tareas, planes, actualizaciones de diseño, desgloses del trabajo, puntos de control de implementación y redacción de ADR. Úselo cuando el usuario solicite aclarar, comparar opciones, discutir criterios o realizar pruebas de estrés, o cuando diferentes respuestas podrían cambiar materialmente el alcance, el comportamiento, la política, las restricciones, la ruta, el diseño, la especificación de la prueba o el contenido del ADR. Proporciona una evaluación de decisiones obligatoria para los flujos de trabajo que lo requieren antes de escribir o revisar el contenido dependiente de Spec Loop. Úselo también para asar a la parrilla en general cuando se seleccione explícitamente.
