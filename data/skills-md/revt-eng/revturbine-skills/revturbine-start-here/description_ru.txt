Входная дверь для интеграции RevTurbine. Используйте сразу после того, как `npm create revturbine` создает приложение, или всякий раз, когда кто-то говорит: «Добавьте RevTurbine», «настройте монетизацию», «начните интеграцию RevTurbine» или «что мне делать дальше с RevTurbine». Маршрутизирует весь первый сеанс по порядку — установка и поставщик, запуск локального Playbook, выполнение одного платного действия, затем запуск в эксплуатацию — путем передачи целевых навыков для каждого шага. Это последовательность; он не выполняет работу сам по себе. Пропустите, если приложение уже выполняет платное действие и вам нужен только один конкретный шаг (непосредственно вызвать навык этого шага).
