Gate una acción paga detrás de un derecho con <Gate>, que muestra una superficie de actualización cuando se deniega. Úselo para "abrir una función premium", "agregar un muro de pago", "poner un modo de actualización en X" o para reemplazar una verificación de plan codificada como `user.plan === 'pro'`. Escribe código de aplicación: envuelve un sitio de llamada en <Gate> y mantiene la interfaz de usuario existente como los hijos otorgados. Requisito previo: el proveedor está montado y un Playbook cargado (local o alojado). Para cualquier cosa que gaste dinero o cómputo, agregue también una nueva verificación del servidor (consulte la sección Verificar).
