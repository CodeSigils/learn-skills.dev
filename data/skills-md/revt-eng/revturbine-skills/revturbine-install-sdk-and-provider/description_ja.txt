@revturbine/sdk をインストールし、ユーザーを指定してアプリのルートに <RevTurbineProvider> をマウントします。初めて RevTurbine をアプリに追加するとき、「プロバイダーがセットアップされていない」とき、またはプロバイダーがマウントされていないために RevTurbine フック/コンポーネントがスローされるときに使用します。アプリコード (プロバイダーラッパーとユーザーコンテキスト) を書き込みます。 <RevTurbineProvider> がすでにアプリをラップしている場合はスキップします。 Playbook の配線またはゲートの追加に直接進みます。
