Install @revturbine/sdk and mount <RevTurbineProvider> at the app root with a user identified. Use when adding RevTurbine to an app for the first time, when "the provider isn't set up", or when RevTurbine hooks/components throw because no provider is mounted. Writes app code — a provider wrapper and a user context. Skip if <RevTurbineProvider> already wraps the app; go straight to wiring the Playbook or adding a gate.
