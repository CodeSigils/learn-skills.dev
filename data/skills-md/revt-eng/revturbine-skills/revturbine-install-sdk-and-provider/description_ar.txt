قم بتثبيت @revturbine/sdk وقم بتثبيت <RevTurbineProvider> على جذر التطبيق مع تحديد المستخدم. يُستخدم عند إضافة RevTurbine إلى تطبيق لأول مرة، أو عندما "لا يتم إعداد الموفر"، أو عندما يتم طرح خطافات/مكونات RevTurbine بسبب عدم تثبيت أي موفر. يكتب كود التطبيق - غلاف الموفر وسياق المستخدم. تخطي إذا كان <RevTurbineProvider> يغلف التطبيق بالفعل؛ انتقل مباشرة إلى توصيل قواعد اللعبة التي تمارسها أو إضافة بوابة.
