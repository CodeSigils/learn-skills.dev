Utilizza questa Skill quando devi controllare un browser Chrome tramite CDP (Chrome DevTools Protocol) per riutilizzare le sessioni di accesso esistenti. Copre: avvio di Chrome in modalità debug, apertura di URL, attesa del caricamento della pagina, valutazione di JavaScript, acquisizione di istantanee ed estrazione di token di autenticazione. Frasi trigger: automazione del browser, CDP, browser agente, 浏览器操作, 操作浏览器, Chrome CDP, 复用登录态, estrai token dal browser.
