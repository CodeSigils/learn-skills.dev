Implementación de la infraestructura para el conjunto de herramientas de redacción de literatura en línea. Proporciona adaptadores integrados para Claude Code, OpenCode, Codex, ZCode, OpenClaw y Reasonix; La IA web y los agentes genéricos pueden operar utilizando el modo de archivo skills+AGENTS.md. Métodos de activación: /story-setup, $story-setup, "prepararme para escribir un libro", "ayúdame a configurar el entorno", "configurar el proyecto de escritura".
