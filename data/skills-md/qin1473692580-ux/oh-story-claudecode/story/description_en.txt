The main entry point of the web novel toolbox. It automatically routes to ranking sweep, text parsing, writing, removing AI flavor, cover creation, import and review skills based on user needs, and can launch a local dashboard to browse the text parsing library and writing projects. Trigger commands: /story, $story, /story dashboard, $story dashboard, /netnovel, “I want to write a novel,” “Help me write a book,” “Write web fiction,” “Open the workspace,” “Check for updates,” “Is there a new version?”.
