Herramienta de generación de código y comprobación estándar de componentes de interfaz de usuario (adaptable a la versión). Utilice esta habilidad cuando el usuario solicite una revisión del "estándar de componente de interfaz de usuario", "verificación de color", "estándar de fuente/tipografía", "estándar de botón", "estándar de tabla", "estándar de entrada", "muestras de componentes" o "generar un componente" (tabla, formulario, panel de consulta) en una interfaz Vue 3 + TypeScript. Selecciona el conjunto de reglas versionado correspondiente del proyecto `package.json` `version` (admite `3.6.0-SNAPSHOT`, `3.6.1-SNAPSHOT`, `3.7.0-SNAPSHOT`).
