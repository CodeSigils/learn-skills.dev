Strumento di controllo standard dei componenti dell'interfaccia utente frontend e di generazione del codice (adattabile alla versione). Utilizzare questa competenza quando l'utente richiede una revisione del "componente UI standard", "controllo del colore", "standard di carattere/tipografia", "standard dei pulsanti", "standard della tabella", "standard di input", "esempi di componenti" o per "generare un componente" (tabella, modulo, pannello di query) su un frontend Vue 3 + TypeScript. Seleziona il set di regole con versione corrispondente dal progetto `package.json` `version` (supporta `3.6.0-SNAPSHOT`, `3.6.1-SNAPSHOT`, `3.7.0-SNAPSHOT`). Questo è il passaggio 3 di 5 della corsia di governance del frontend nel bundle della catena di refactoring.
