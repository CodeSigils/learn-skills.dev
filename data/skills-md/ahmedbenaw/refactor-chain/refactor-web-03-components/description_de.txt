Tool zur Überprüfung und Codegenerierung von Frontend-UI-Komponentenstandards (versionsadaptiv). Verwenden Sie diese Fähigkeit, wenn der Benutzer eine Überprüfung des „UI-Komponentenstandards“, „Farbprüfung“, „Schriftart-/Typografiestandard“, „Schaltflächenstandard“, „Tabellenstandard“, „Eingabestandard“, „Komponentenbeispiele“ oder „eine Komponente generieren“ (Tabelle, Formular, Abfragefeld) auf einem Vue 3 + TypeScript-Frontend anfordert. Es wählt den passenden versionierten Regelsatz aus der „Version“ des Projekts „package.json“ aus (unterstützt „3.6.0-SNAPSHOT“, „3.6.1-SNAPSHOT“, „3.7.0-SNAPSHOT“). Dies ist Schritt 3 von 5 der Frontend-Governance-Spur im Refactor-Chain-Bundle.
