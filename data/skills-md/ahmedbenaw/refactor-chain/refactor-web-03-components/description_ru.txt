Инструмент проверки стандартов компонентов пользовательского интерфейса и создания кода (адаптивный к версии). Используйте этот навык, когда пользователь запрашивает проверку «стандарта компонента пользовательского интерфейса», «проверку цвета», «стандарт шрифта/типографики», «стандарт кнопок», «стандарт таблицы», «стандарт ввода», «образцы компонентов» или «создать компонент» (таблицу, форму, панель запросов) во внешнем интерфейсе Vue 3 + TypeScript. Он выбирает соответствующий версионный набор правил из проекта package.json `version` (поддерживает `3.6.0-SNAPSHOT`, `3.6.1-SNAPSHOT`, `3.7.0-SNAPSHOT`). Это шаг 3 из 5 этапа управления интерфейсом в пакете цепочки рефакторинга.
