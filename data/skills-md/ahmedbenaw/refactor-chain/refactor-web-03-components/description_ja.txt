フロントエンド UI コンポーネントの標準チェックおよびコード生成ツール (バージョン対応)。このスキルは、ユーザーが「UI コンポーネント標準」レビュー、「カラー チェック」、「フォント/タイポグラフィ標準」、「ボタン標準」、「テーブル標準」、「入力標準」、「コンポーネント サンプル」、または Vue 3 + TypeScript フロントエンドでの「コンポーネントの生成」(テーブル、フォーム、クエリ パネル) を要求する場合に使用します。プロジェクト `package.json` `version` から一致するバージョン管理されたルールセットを選択します (`3.6.0-SNAPSHOT`、`3.6.1-SNAPSHOT`、`3.7.0-SNAPSHOT` をサポートします)。これは、リファクタリング チェーン バンドルのフロントエンド ガバナンス レーンのステップ 3/5 です。
