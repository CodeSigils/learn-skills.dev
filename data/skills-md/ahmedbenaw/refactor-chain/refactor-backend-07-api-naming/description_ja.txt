このスキルは、バックエンド プロジェクトの REST API と命名規則 (エンドポイント パス構造、HTTP メソッドの使用法、クラスとプロパティの命名規則、リクエスト パラメーターの規則、応答ラッパーの規則、Bean 名の競合など) をチェックまたは修正するときに使用します。 「API 命名チェック」、「命名規則の修正」、「エンドポイント規則のチェック」、「クラスの名前を標準サフィックスに変更」、「Bean 名の競合」などのフレーズでトリガーされます。リファクタリング チェーン バックエンド レーンのステップ 7/9 (作業フェーズ)。動作の保持: 名前変更と再アノテーションを行いますが、コードの動作を変更したり、公開された API コントラクトを破ったりすることはありません。
