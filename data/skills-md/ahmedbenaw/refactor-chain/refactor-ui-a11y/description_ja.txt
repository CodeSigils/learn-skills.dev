このスキルは、UI のアクセシビリティとレスポンシブな監査と修正に使用します。ユーザーが「アクセシビリティ対応にする」、「コントラストを修正する」、「ARIA / ロール / ラベルを追加する」、「キーボードでナビゲートできるようにする」、「フォーカス順序を修正する」、「WCAG を確認する」、「スクリーン リーダーで動作するようにする」、「レスポンシブなレイアウト / ブレークポイントを修正する」、または「モバイルで壊れる / リフローしない」を要求した場合に使用します。 WCAG 2.2 AA と照合して、カラー コントラスト、フォーカス順序と表示フォーカス、セマンティック ロールと ARIA、キーボード ナビゲーション、レスポンシブ ブレークポイント/リフロー、モバイル ダイナミック タイプを監査して修正します。これは、リファクタリング チェーン パイプラインの作業 UI レーンのアクセシビリティ ゲートです。 refactor-ui-components の後、refactor-code-solid の前に実行されます。コンテンツと動作を維持しながらアクセシビリティの欠陥を修正し、ゲートが通過するまでレーンが完了と呼ばれることをブロックします。
