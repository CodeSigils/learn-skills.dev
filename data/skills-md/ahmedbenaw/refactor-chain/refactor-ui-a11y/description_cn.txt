使用此技能来实现 UI 的可访问性和响应式审核和修复 - 当用户要求“使其可访问”、“修复对比度”、“添加 ARIA/角色/标签”、“使其可键盘导航”、“修复焦点顺序”、“检查 WCAG”、“使其与屏幕阅读器一起使用”、“修复响应式布局/断点”或“它在移动设备上中断/不回流”时。它审核并修复颜色对比度、焦点顺序和可见焦点、语义角色和 ARIA、键盘导航、响应断点/重排以及移动动态类型，并根据 WCAG 2.2 AA 进行检查。这是重构链管道中实际工作 UI 通道的可访问性 GATE；它在 refactor-ui-components 之后和 refactor-code-solid 之前运行。它修复了可访问性缺陷，同时保留内容和行为，并阻止通道在门通过之前被称为完成。
