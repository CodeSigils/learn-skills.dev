Use this skill for an accessibility and responsive audit-and-fix of a UI — when the user asks to "make this accessible", "fix the contrast", "add ARIA / roles / labels", "make it keyboard-navigable", "fix the focus order", "check WCAG", "make it work with a screen reader", "fix the responsive layout / breakpoints", or "it breaks on mobile / doesn't reflow". It audits and fixes color contrast, focus order and visible focus, semantic roles and ARIA, keyboard navigation, responsive breakpoints/reflow, and mobile dynamic-type, checking against WCAG 2.2 AA. This is the accessibility GATE of the do-the-work UI lane in the refactor-chain pipeline; it runs after refactor-ui-components and before refactor-code-solid. It fixes accessibility defects while preserving content and behavior, and it blocks the lane from being called done until the gate passes.
