使用此技能來實現 UI 的可訪問性和響應式審核和修復 - 當使用者要求“使其可訪問”、“修復對比度”、“添加 ARIA/角色/標籤”、“使其可鍵盤導航”、“修復焦點順序”、“檢查 WCAG”、“使其與螢幕閱讀器一起使用佈局”、“修復式響應式/斷點”或“它在移動設備上中斷/關閉設備時中斷/關閉設備。它審核並修復顏色對比度、焦點順序和可見焦點、語義角色和 ARIA、鍵盤導航、響應斷點/重排以及移動動態類型，並根據 WCAG 2.2 AA 進行檢查。這是重構鏈管道中實際工作 UI 通道的可訪問性 GATE；它在 refactor-ui-components 之後和 refactor-code-solid 之前運行。它修復了可訪問性缺陷，同時保留內容和行為，並阻止通道在門通過之前被稱為完成。
