Estrae i pacchetti di codice condiviso dai moduli del livello di capacità in un modulo `grp-{module}-common`, adattando il set di regole alla linea di prodotti rilevata. Utilizzare questa abilità quando l'utente chiede di "estrarre il modulo comune", "eseguire Step8", "controllare i pacchetti comuni", "estrarre comune" o "consolidare util/cache/costante/enums/eccezione/config" in un servizio Java Maven. È il passo 8 di 9 della corsia dell'architettura a strati Java nel bundle della catena di refactoring e seleziona il set di regole della linea di prodotto da `pom.xml` `<groupId>` (`grp.pt`, `grp.budget`, `gfmis.bgtex` / `com.ctjsoft.gfmis`).
