Extrait les packages de code partagés des modules de couche de capacités dans un module `grp-{module}-common`, en adaptant l'ensemble de règles à la gamme de produits détectée. Utilisez cette compétence lorsque l'utilisateur demande « extraire le module commun », « exécuter Step8 », « vérifier les packages communs », « extraire le commun » ou « consolider util/cache/constant/enums/exception/config » dans un service Java Maven. Il s'agit de l'étape 8 sur 9 de la voie d'architecture en couches Java dans le bundle de chaîne de refactorisation et sélectionne l'ensemble de règles de la ligne de produits dans `pom.xml` `<groupId>` (`grp.pt`, `grp.budget`, `gfmis.bgtex` / `com.ctjsoft.gfmis`).
