Извлекает пакеты общего кода из модулей уровня возможностей в модуль grp-{module}-common, адаптируя набор правил к обнаруженной линейке продуктов. Используйте этот навык, когда пользователь просит «извлечь общий модуль», «запустить Step8», «проверить общие пакеты», «извлечь общий» или «объединить util/cache/constant/enums/Exception/config» в службе Maven Java. Это шаг 8 из 9 этапа многоуровневой архитектуры Java в пакете цепочки рефакторинга, на котором выбирается набор правил линейки продуктов из `pom.xml` `<groupId>` (`grp.pt`, `grp.budget`, `gfmis.bgtex` / `com.ctjsoft.gfmis`).
