Оптимизирует качество инженерного кода Java в классах @Service и @Repository, адаптируя набор правил к обнаруженной линейке продуктов. Используйте этот навык, когда пользователь просит «оптимизировать код модуля», «исправить SQL-инъекцию», «улучшить ведение журнала», «очистить код», «запустить Step9» или «оптимизировать проверку кода» в службе Maven Java. Это шаг 9 из 9 этапа многоуровневой архитектуры Java в пакете цепочки рефакторинга, на котором выбирается набор правил линейки продуктов из `pom.xml` `<groupId>` (`grp.pt`, `grp.budget`, `gfmis.bgtex` / `com.ctjsoft.gfmis`).
