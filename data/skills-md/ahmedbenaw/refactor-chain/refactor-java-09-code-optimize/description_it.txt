Ottimizza la qualità del codice tecnico Java sulle classi `@Service` e `@Repository`, adattando il set di regole alla linea di prodotti rilevata. Utilizzare questa competenza quando l'utente chiede di "ottimizzare il codice del modulo", "correggere SQL injection", "migliorare la registrazione", "ripulire il codice", "eseguire Step9" o "ottimizzazione della revisione del codice" su un servizio Java Maven. È il passaggio 9 di 9 della corsia dell'architettura a strati Java nel bundle della catena di refactoring e seleziona il set di regole della linea di prodotto da `pom.xml` `<groupId>` (`grp.pt`, `grp.budget`, `gfmis.bgtex` / `com.ctjsoft.gfmis`).
