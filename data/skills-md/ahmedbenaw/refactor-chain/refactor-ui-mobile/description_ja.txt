ネイティブまたはクロスプラットフォームのモバイル UI (SwiftUI、UIKit、Jetpack Compose、React Native、または Flutter) のビジュアル デザインをリファクタリングするときにこのスキルを使用すると、ユーザーは「この iOS/Android 画面をネイティブっぽくする」、「タップ ターゲットが小さすぎる」、「コンテンツがノッチ/ホーム インジケーターの下に隠れる」、「これは Apple/マテリアルのガイドラインに従っていない」、「モバイル ナビゲーションを修正する」、または「このアプリの画面を磨く」などと言います。プラットフォームの HIG/マテリアル規則を適用します: ≥44pt (iOS) / 48dp (Android) タッチ ターゲット、セーフ エリアおよびノッチ/ホーム インジケーター インセット、プラットフォームに適したナビゲーション パターン、およびダイナミック タイプ/スケーラブル テキスト。これは、リファクタリング チェーン パイプラインの作業 UI レーンのモバイル ブランチです。これは、refactor-ui-tokens の後、refactor-ui-components の前に実行されます。コンテンツ、データ、動作を維持しながらプレゼンテーションのスタイルを変更します。
