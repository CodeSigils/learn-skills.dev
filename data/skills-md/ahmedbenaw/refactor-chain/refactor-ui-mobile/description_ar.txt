استخدم هذه المهارة عند إعادة تصميم التصميم المرئي لواجهة مستخدم الهاتف المحمول الأصلية أو عبر الأنظمة الأساسية - SwiftUI أو UIKit أو Jetpack Compose أو React Native أو Flutter - ويقول المستخدم أشياء مثل "اجعل شاشة iOS/Android هذه تبدو أصلية"، أو "أهداف النقر صغيرة جدًا"، أو "المحتوى مخفي أسفل مؤشر الشق/الصفحة الرئيسية"، أو "هذا لا يتبع إرشادات Apple/المواد"، أو "أصلح التنقل عبر الهاتف المحمول"، أو "صقل شاشة التطبيق هذه". إنه يفرض اصطلاحات HIG/Material للنظام الأساسي: أهداف اللمس ≥44pt (iOS) / 48dp (Android)، وإدراجات المنطقة الآمنة والمؤشر الرئيسي/الصفحة الرئيسية، وأنماط التنقل الصحيحة للنظام الأساسي، والنوع الديناميكي / النص القابل للتطوير. هذا هو الفرع المتنقل لممر واجهة المستخدم الخاص بتنفيذ العمل في خط أنابيب سلسلة إعادة البناء؛ يتم تشغيله بعد رموز refactor-ui-tokens وقبل مكونات refactor-ui-components. فهو يعيد تصميم العرض التقديمي مع الحفاظ على المحتوى والبيانات والسلوك.
