Инструмент аудита и управления подразделениями внешнего бизнес-модуля (адаптивный к версии). Используйте этот навык, когда пользователь запрашивает «проверку разделения модулей», «управление структурой модулей», «разделение бизнес-модулей», «проверку зависимостей модулей», проверку «структуры подмодулей» или «создание бизнес-модулей» во внешнем интерфейсе Vue 3 + TypeScript. Он выбирает соответствующий версионный набор правил из проекта package.json `version` (поддерживает `3.6.0-SNAPSHOT`, `3.6.1-SNAPSHOT`, `3.7.0-SNAPSHOT`). Это второй из пятых этапов управления интерфейсом в пакете цепочки рефакторинга.
