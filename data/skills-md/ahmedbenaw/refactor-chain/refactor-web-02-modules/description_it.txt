Strumento di controllo e governance della divisione del modulo aziendale frontend (versione adattativa). Utilizzare questa competenza quando l'utente richiede un "controllo della divisione del modulo", una "governance della struttura del modulo", una "suddivisione del modulo aziendale", un "controllo della dipendenza del modulo", una revisione della "struttura del sottomodulo" o un'impalcatura "crea modulo aziendale" su un frontend Vue 3 + TypeScript. Seleziona il set di regole con versione corrispondente dal progetto `package.json` `version` (supporta `3.6.0-SNAPSHOT`, `3.6.1-SNAPSHOT`, `3.7.0-SNAPSHOT`). Questo è il passaggio 2 di 5 della corsia di governance del frontend nel bundle della catena di refactoring.
