Используйте этот навык, когда объем памяти продолжает увеличиваться с течением времени или при повторяющихся действиях, и пользователь хочет найти и устранить утечку — простые триггеры, такие как «память приложения продолжает расти», «через некоторое время происходит сбой», «чем дольше я ее использую, тем медленнее вкладка становится», «происходит утечка памяти», «куча продолжает расти», «отсоединенные узлы DOM», «процесс RSS растет и никогда не возвращается». Он диагностирует утечки, делая снимки кучи до и после повторяющегося действия, сравнивая их с объектами, которые должны были быть освобождены, но не были освобождены, и отслеживая рост сохраняемого размера до ссылки, которая закрепляет их в памяти. Работает как для браузера (куча DevTools), так и для Node.js. Это рабочий этап линии DEBUG цепочки рефакторинга, который достигается, когда система классифицирует случай как отладочную/кодовую память. Использует инструмент кучи браузера/DevTools, если он доступен; в противном случае — собственные API моментальных снимков кучи Node.
