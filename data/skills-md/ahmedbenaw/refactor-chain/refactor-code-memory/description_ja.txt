このスキルは、時間の経過や繰り返しのアクションでメモリが増加し続け、ユーザーがリークを見つけて修正したい場合に使用します。これは、「アプリのメモリが増加し続ける」、「しばらくすると OOM になる」、「長く使うほどタブが遅くなる」、「メモリ リークがある」、「ヒープが増加し続ける」、「DOM ノードが切断される」、「プロセス RSS が増加し、戻らない」などの単純なトリガーです。繰り返されるアクションの前後でヒープ スナップショットを取得し、解放されるべきで解放されなかったオブジェクトの差分を取得し、メモリに固定する参照に対する保持サイズの増加を追跡することで、リークを診断します。ブラウザ (DevTools ヒープ) と Node.js の両方で動作します。これは、リファクタリング チェーンの DEBUG レーンの作業ステップであり、ハーネスがケースをデバッグ/コードメモリとして分類したときに到達します。利用可能な場合はブラウザ/DevTools ヒープ ツールを使用します。それ以外の場合は、ノード独自のヒープ スナップショット API。
