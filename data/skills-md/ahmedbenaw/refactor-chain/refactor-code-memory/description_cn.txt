当内存随着时间的推移或重复操作而不断攀升并且用户希望发现并修复泄漏时，请使用此技能 - 简单的触发器，例如“应用程序的内存不断增长”，“一段时间后 OOM”，“选项卡使用时间越长，速度就越慢”，“存在内存泄漏”，“堆不断攀升”，“分离的 DOM 节点”，“进程 RSS 增长并且永远不会回来”。它通过在重复操作之前和之后拍摄堆快照来诊断泄漏，将它们与应该释放但没有释放的对象进行比较，并跟踪将它们固定在内存中的引用的保留大小增长。适用于浏览器（DevTools 堆）和 Node.js。这是重构链调试通道的实际工作步骤，当线束将案例分类为调试/代码内存时到达。使用浏览器/DevTools 堆工具（如果可用）；否则是 Node 自己的堆快照 API。
