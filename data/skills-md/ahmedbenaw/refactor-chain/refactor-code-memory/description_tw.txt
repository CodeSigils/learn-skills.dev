當記憶體隨著時間的推移或重複操作而不斷攀升並且用戶希望發現並修復洩漏時，請使用此技能 - 簡單的觸發器，例如“應用程式的內存不斷增長”，“一段時間後 OOM”，“選項卡使用時間越長，速度就越慢”，“存在內存洩漏”，“堆不斷攀升”，“分離的 DOM 節點”，進程 RSS它透過在重複操作之前和之後拍攝堆快照來診斷洩漏，將它們與應該釋放但沒有釋放的物件進行比較，並追蹤將它們固定在記憶體中的引用的保留大小增長。適用於瀏覽器（DevTools 堆）和 Node.js。這是重構鏈調試通道的實際工作步驟，當線束將案例分類為調試/程式碼記憶體時到達。使用瀏覽器/DevTools 堆工具（如果可用）；否則是 Node 自己的堆快照 API。
