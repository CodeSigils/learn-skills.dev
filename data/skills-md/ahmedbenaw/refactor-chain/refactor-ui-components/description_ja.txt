このスキルは、Web UI が手動のオーダーメイドのプリミティブ (カスタム <button> マークアップ、div ベースのドロップダウン、アドホック モーダル、自家製入力/タブ/ダイアログ) でいっぱいで、ユーザーが「shadcn/ui を採用」、「実際のコンポーネント ライブラリを使用」、「カスタム コンポーネントをレジストリで置き換え」、「ボタンの再発明をやめる」、または「UI コンポーネントを標準化」したい場合に使用します。レジストリ コンポーネントのオーダーメイドのプリミティブを交換し (shadcn/ui が最初)、テーマをプロジェクトのデザイン トークンに接続し、動作を同一に保ちます。これは、リファクタリング チェーン パイプラインの UI レーンの作業ステップです。これは、refactor-ui-tokens の後 (およびビジュアル/モバイル パスの後)、refactor-ui-a11y の前に実行されます。利用可能な場合は shadcn MCP を使用する場合があります。プレゼンテーションと構造のリファクタリング: 同じ動作、標準化されたコンポーネント。
