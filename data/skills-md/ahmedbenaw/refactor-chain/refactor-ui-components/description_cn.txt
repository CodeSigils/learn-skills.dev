当 Web UI 充满手工定制的基元（自定义 <button> 标记、基于 div 的下拉菜单、临时模式、自制输入/选项卡/对话框）并且用户想要“采用 shadcn/ui”、“使用真正的组件库”、“用注册表替换我们的自定义组件”、“停止重新发明按钮”或“标准化我们的 UI 组件”时，请使用此技能。它将定制基元替换为注册表组件（首先是 shadcn/ui），将它们的主题连接到项目的设计令牌，并保持行为相同。这是重构链管道中 UI 通道的执行工作步骤；它在 refactor-ui-tokens 之后（以及在视觉/移动通道之后）和 refactor-ui-a11y 之前运行。如果可用，它可能会使用 shadcn MCP。表示和结构重构：相同的行为，标准化的组件。
