Utilizza questa abilità quando un'interfaccia utente è piena di colori, spaziature, dimensioni dei caratteri, raggi o ombre codificate in modo fisso e l'utente desidera "estrarre token di progettazione", "smettere di usare numeri magici nei CSS", "impostare una scala del sistema di progettazione", "utilizzare variabili CSS/un tema Tailwind invece di codici esadecimali" o "rendere coerente lo stile". Estrae valori visivi una tantum in una piccola scala di token semantici, migra i siti di chiamata per fare riferimento a tali token e segnala la deriva (valori che non si adattano a nessun passaggio di scala). Questo è il primo passaggio della corsia dell'interfaccia utente di lavoro nella pipeline della catena di refactoring; viene eseguito prima di refactor-ui-visual / refactor-ui-mobile e fornisce loro un vocabolario di token stabile. Preservazione del comportamento e dei pixel per impostazione predefinita.
