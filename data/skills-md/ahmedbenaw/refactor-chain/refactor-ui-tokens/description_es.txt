Utilice esta habilidad cuando una interfaz de usuario esté llena de colores codificados, espacios, tamaños de fuente, radios o sombras dispersas en línea y el usuario quiera "extraer tokens de diseño", "dejar de usar números mágicos en CSS", "configurar una escala del sistema de diseño", "usar variables CSS/un tema Tailwind en lugar de códigos hexadecimales" o "hacer que el estilo sea consistente". Extrae valores visuales únicos en una pequeña escala de token semántica, migra sitios de llamadas para hacer referencia a esos tokens e informa la deriva (valores que no se ajustan a ningún paso de escala).
