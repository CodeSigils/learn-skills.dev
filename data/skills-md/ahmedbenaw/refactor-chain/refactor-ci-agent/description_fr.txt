Utilisez cette compétence lorsque la chaîne de refactorisation s'exécute dans CI — en configurant, en expliquant ou en déboguant l'action GitHub composite du dépôt (`action.yml`), qui publie un rapport de préparation au refactor (classification + audit des directives + médecin) dans le résumé du travail et éventuellement sous forme de commentaire PR. Les phrases de déclenchement incluent « exécuter la chaîne de refactorisation dans CI », « ajouter le rapport de préparation à nos PR », « configurer l'action GitHub », « pourquoi le bot commente-t-il deux fois », « mode agent dans le pipeline » ou un fichier de workflow faisant référence à l'action de la chaîne de refactorisation. Couvre les deux modes – déterministe (clés zéro, scripts d'analyse uniquement) et mode agent opt-in (PROPRE agent CLI et informations d'identification de l'utilisateur, rapport uniquement) – ainsi que l'hygiène des secrets et l'étiquette des commentaires PR. Phase : expédition/vérification ; conditionnel - s'applique uniquement lorsque la chaîne s'exécute à l'intérieur de CI plutôt que dans une session de discussion.
