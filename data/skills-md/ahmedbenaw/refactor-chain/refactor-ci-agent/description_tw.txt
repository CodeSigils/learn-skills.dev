當重構鏈在 CI 中運行時使用此技能 — 設定、解釋或調試存儲庫的複合 GitHub Action (`action.yml`)，該操作將重構準備報告（分類 + 指南審計 + 醫生）發佈到工作摘要中，也可以選擇作為 PR 評論。觸發短語包括「在 CI 中運行重構鏈」、「將準備報告新增至我們的 PR」、「設定 GitHub 操作」、「為什麼機器人評論兩次」、「管道中的代理模式」或引用重構鏈操作的工作流程檔案。涵蓋兩種模式 - 確定性（零密鑰，僅分析腳本）和選擇代理模式（用戶自己的代理 CLI 和憑證，僅報告） - 以及秘密衛生和 PR 評論禮儀。階段：發貨/驗證；有條件的——僅當鏈在 CI 內部運行而不是在聊天會話中時適用。
