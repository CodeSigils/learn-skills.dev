このスキルは、CI でリファクタリング チェーンを実行する場合、つまりリポジトリの複合 GitHub アクション (「action.yml」) を設定、説明、またはデバッグするときに使用します。これにより、リファクタリング準備レポート (分類 + ガイドライン監査 + 医師) がジョブの概要に公開され、オプションで PR コメントとして公開されます。トリガー フレーズには、「CI でリファクタ チェーンを実行する」、「PR に準備状況レポートを追加する」、「GitHub アクションを設定する」、「ボットが 2 回コメントするのはなぜですか」、「パイプラインのエージェント モード」、またはリファクタ チェーン アクションを参照するワークフロー ファイルが含まれます。決定的 (ゼロ キー、分析スクリプトのみ) とオプトイン エージェント モード (ユーザー自身のエージェント CLI と資格情報、レポートのみ) の 2 つのモードに加えて、機密衛生と PR コメント エチケットもカバーします。フェーズ: 出荷/検証。条件付き — チェーンがチャット セッションではなく CI 内で実行される場合にのみ適用されます。
