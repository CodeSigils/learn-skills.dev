Utilisez cette compétence pour examiner le DIFF du refactor pour détecter les problèmes de performances au niveau du code avant sa livraison : lecture du code modifié (sans exécuter de profileur) pour les points chauds algorithmiques (O(n^2 accidentel), travail dans une boucle), requêtes de base de données N+1, travail inutile ou répété (recalcul, récupération, sérialisation redondante) et coût ajouté au bundle ou au chemin de requête. Les phrases de déclenchement incluent « est-ce que cela l'a rendu plus lent », « vérifier N+1 », « examen des performances de ce changement », « des points chauds dans la différence », « est-ce O(n^2) maintenant », « avons-nous ajouté une forte dépendance ». Il s'agit de l'examinateur des performances dans la phase d'examen/vérification du pipeline de chaîne de refactorisation ; refactor-review-gate l'appelle et intègre ses conclusions dans le rapport final classé. Consultatif - il rapporte les résultats classés avec file:line et une esquisse de correctif ; il ne modifie jamais le code tout seul.
