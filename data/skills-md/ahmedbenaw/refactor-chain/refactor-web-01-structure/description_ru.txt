Инструмент аудита и управления структурой каталогов внешнего проекта (адаптивный к версии). Используйте этот навык, когда пользователь запрашивает «проверку структуры проекта», «проверку соглашения о каталогах», «аудит многоуровневой архитектуры», «инициализацию проекта», «генерацию каркаса» или «управление структурой проекта» интерфейса Vue 3 + TypeScript. Он выбирает соответствующий версионный набор правил из проекта package.json `version` (поддерживает `3.6.0-SNAPSHOT`, `3.6.1-SNAPSHOT`, `3.7.0-SNAPSHOT`). Это шаг 1 из 5 этапа управления внешним интерфейсом в пакете цепочки рефакторинга.
