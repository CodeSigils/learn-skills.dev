このスキルは、レジストリで検出されたスタック内のバックエンド プロジェクトのサービスおよびリポジトリ クラスに対してコード品質パスを実行するときに使用します。これにより、文字列連結された SQL をパラメータ化されたクエリに強化し、構造化ログを採用し、冗長コードや無効なコードをクリーンアップし、リソース処理を強化できます。 「サービス コードの最適化」、「SQL インジェクションの修正」、「ログの追加」、「デッド コードのクリーンアップ」、「コード品質パス」などのフレーズでトリガーされます。これは、リファクタリング チェーン バンドルの階層化されたバックエンド ガバナンス レーンのステップ 9/9 です。レジストリで検出された言語のバックエンド コードベースで動作します。製品、組織、言語に限定されたルールはありません。
