Utilisez cette compétence lors de l'extraction du code partagé des modules de fonctionnalités dans le module commun partagé d'un projet (utilitaires, cache, constantes, énumérations, exceptions et packages de configuration) dans un projet backend en couches multi-modules dans n'importe quelle pile détectée par le registre. Se déclenche sur des expressions telles que "extraire le module commun", "consolider le code partagé", "déplacer les utilitaires vers le commun", "vérifier les packages communs". Étape 8 sur 9 dans la voie backend de la chaîne de refactorisation (phase de travail). Préservation du comportement : les fichiers se déplacent entre les modules et les fichiers de construction gagnent des dépendances, mais aucune classe n'est renommée et aucune logique ne change. Idempotent : une réexécution sur un projet terminé ne migre rien.
