Restructure le code existant et fonctionnel en une architecture en couches propre avec un SOLID précis — améliorant de manière agressive la structure tout en gardant le comportement identique. Utilisez cette compétence lorsqu'on vous demande de refactoriser, nettoyer, appliquer SOLID, découpler, diviser une classe ou un composant divin, supprimer la duplication, introduire l'injection de dépendances ou réorganiser le code en couches appropriées. Il s'agit de la passe SOLID/superposition indépendante du repo dans le bundle de chaîne de refactorisation, et elle s'exécute AUSSI par défaut comme étape de consolidation finale de chaque voie. Il restructure le code qui fonctionne déjà – SANS ajouter de fonctionnalités, corriger des bogues ou écrire des suites de tests.
