Strukturiert vorhandenen, funktionierenden Code in eine saubere Schichtarchitektur mit präzisem SOLID um – eine deutliche Verbesserung der Struktur bei gleichzeitig identischem Verhalten. Verwenden Sie diese Fertigkeit, wenn Sie aufgefordert werden, Code umzugestalten, zu bereinigen, SOLID anzuwenden, zu entkoppeln, eine Klasse oder Komponente aufzuteilen, Duplikate zu entfernen, eine Abhängigkeitsinjektion einzuführen oder Code in die richtigen Ebenen umzustrukturieren. Dies ist der Repo-agnostische SOLID-/Layering-Durchlauf im Refactor-Chain-Bundle und wird AUCH standardmäßig als letzter Konsolidierungsschritt jeder Lane ausgeführt. Es restrukturiert Code, der bereits funktioniert – KEINE Funktionen hinzuzufügen, Fehler zu beheben oder Testsuiten zu schreiben.
