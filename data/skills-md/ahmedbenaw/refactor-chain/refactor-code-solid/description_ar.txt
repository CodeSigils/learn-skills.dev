يعيد هيكلة التعليمات البرمجية العاملة الحالية إلى بنية ذات طبقات نظيفة باستخدام SOLID الدقيق - مما يؤدي إلى تحسين البنية بقوة مع الحفاظ على تطابق السلوك. استخدم هذه المهارة عندما يُطلب منك إعادة البناء، أو التنظيف، أو تطبيق SOLID، أو فصل، أو تقسيم فئة أو مكون إلهي، أو إزالة التكرار، أو إدخال حقن التبعية، أو إعادة تنظيم التعليمات البرمجية إلى طبقات مناسبة. هذا هو ممر SOLID/الطبقات الملحد لإعادة الشراء في حزمة سلسلة إعادة التصنيع، ويتم تشغيله أيضًا افتراضيًا كخطوة الدمج النهائية لكل حارة. فهو يعيد هيكلة التعليمات البرمجية التي تعمل بالفعل - وليس إضافة ميزات أو إصلاح الأخطاء أو كتابة مجموعات الاختبار.
