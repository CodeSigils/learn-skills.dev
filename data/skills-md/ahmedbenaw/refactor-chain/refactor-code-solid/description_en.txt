Restructures existing, working code into clean layered architecture with accurate SOLID — aggressively improving structure while keeping behavior identical. Use this skill when asked to refactor, clean up, apply SOLID, decouple, split a god class or component, remove duplication, introduce dependency injection, or reorganize code into proper layers. This is the repo-agnostic SOLID/layering pass in the refactor-chain bundle, and it ALSO runs by default as the final consolidating step of every lane. It restructures code that already works — NOT adding features, fixing bugs, or writing test suites.
