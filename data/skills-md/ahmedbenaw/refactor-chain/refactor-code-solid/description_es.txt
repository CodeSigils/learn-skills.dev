Reestructura el código funcional existente en una arquitectura en capas limpia con SOLID preciso, mejorando agresivamente la estructura y manteniendo el comportamiento idéntico. Utilice esta habilidad cuando se le solicite refactorizar, limpiar, aplicar SOLID, desacoplar, dividir una clase o componente divino, eliminar duplicaciones, introducir inyección de dependencias o reorganizar el código en capas adecuadas. Este es el paso SOLID/capas independiente del repositorio en el paquete de cadena de refactorización, y TAMBIÉN se ejecuta de forma predeterminada como el paso de consolidación final de cada carril. Reestructura el código que ya funciona, SIN agregar funciones, corregir errores ni escribir conjuntos de pruebas.
