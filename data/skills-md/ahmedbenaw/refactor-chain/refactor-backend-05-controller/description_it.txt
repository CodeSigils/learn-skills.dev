Utilizza questa capacità quando organizzi il livello controller di un servizio web backend in qualsiasi stack rilevato dal registro, suddividendo i controller in un sottopacchetto API esterno e un sottopacchetto API interno (nomi configurabili, ad esempio `external/`/`internal/`), con il posizionamento deciso dalle annotazioni del controller attivo e da una catena di classificazione deterministica a tre livelli, mai in base a nomi di file o congetture. Si attiva su frasi come "controllo del livello del controller", "correzione del livello del controller", "divisione dei controller esterni ed interni", "organizzazione dei controller per pubblico API". Questo è il passaggio 5 di 9 nella corsia di governance del backend a più livelli del bundle della catena di refactoring. Funziona su qualsiasi base di codice backend in qualsiasi lingua rilevata dal registro; nessuna regola vincolata al prodotto, all'organizzazione o alla lingua.
