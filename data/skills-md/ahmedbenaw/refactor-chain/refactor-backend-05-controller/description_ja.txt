このスキルは、レジストリで検出されたスタック内のバックエンド Web サービスのコントローラー層を編成するときに使用します。コントローラーを外部 API サブパッケージと内部 API サブパッケージ (構成可能な名前、例: 「external/」/「internal/」) に分割します。配置は、ファイル名や推測ではなく、アクティブなコントローラーの注釈と 3 レベルの決定論的な分類チェーンによって決定されます。 「コントローラー層のチェック」、「コントローラー層の修正」、「外部コントローラーと内部コントローラーの分割」、「API オーディエンスごとにコントローラーを整理」などのフレーズでトリガーされます。これは、リファクタリング チェーン バンドルの階層化されたバックエンド ガバナンス レーンのステップ 5/9 です。レジストリで検出された言語のバックエンド コードベースで動作します。製品、組織、言語に限定されたルールはありません。
