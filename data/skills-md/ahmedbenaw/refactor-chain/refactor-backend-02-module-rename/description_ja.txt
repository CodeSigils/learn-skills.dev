このスキルは、階層化された再構築後、モジュール名がモジュールの役割を示さなくなり、ユーザーがセマンティックな名前の変更を要求する場合に使用します。トリガー フレーズには、「モジュールの名前変更」、「役割に合わせてモジュールの名前変更」、「サーバーからコントローラーへの名前変更」、「モジュールの名前付けパス」、「アーキテクチャの微調整」などがあります。プロジェクトで選択されたマッピング (例: `{module}-server` → `{module}-controller`、`{module}-server-com` → `{module}-service`) に従ってモジュールの名前を変更し、ディレクトリ、アーティファクト ID、コンテナ モジュール リスト、dependencyManagement、すべての依存関係参照、および Java パッケージ/インポート行を通じて変更を伝播します。リファクタリング チェーン バンドルの階層化されたバックエンド ガバナンス レーンのステップ 2/9。階層化されたバックエンド プロジェクト (レジストリから検出されたビルド システム) で動作します。べき等 — すでに名前が変更されているモジュールはスキップされます。
