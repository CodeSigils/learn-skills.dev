當分層重組之後，模組名稱不再說明模組的功能並且使用者要求進行語義重命名時，請使用此技能 - 觸發短語包括“模組重命名”、“重命名模組以匹配其角色”、“將伺服器重命名為控制器”、“模組上的命名傳遞”或“架構微調”。它根據專案選擇的映射重新命名模組（例如約定“{module}-server”→“{module}-controller”、“{module}-server-com”→“{module}-service”），並透過目錄、artifactIds、容器模組列表、dependencyManagement、每個依賴項參考和 Java 包/導入行引用和 Java 包/導入行引用。重構鏈捆綁中分層後端治理通道的第 2 步（共 9 步）；適用於任何分層後端項目（從註冊表檢測到的構建系統）；冪等 - 已重新命名的模組將被跳過。
