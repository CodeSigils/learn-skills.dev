このスキルは、ユーザーがコードベースを深く敵対的で多視点からレビューしたい場合に使用します。トリガー フレーズには、「すべてをレビューする」、「このコードベースを監査する」、「すべての間違いを見つける」、「不機嫌なレビュー」、「取締役会を招集する」、「パネル レビュー」、「これをバラバラにする」などがあります。それは、機能的役割レンズ (アーキテクチャ、ハーネス、正確性、セキュリティ、文書と真実) に結び付けられた、指名されたエンジニアのペルソナ (権威者としてのラトナー、発見者としてのアペル/ニューウェル/カーマック、敵対的検証者としてのサツケヴァー/ルカン/カルパシー) のパネルである審査委員会を招集します。それぞれの発見はリードによって作成され、重要になる前にコーディネーターの反論に耐える必要があります。デフォルトでは読み取り専用のレビューになります。これはレーンではなく、レビュー機能です。 Claude Code / Cowork / Codex 全体で移植可能。
