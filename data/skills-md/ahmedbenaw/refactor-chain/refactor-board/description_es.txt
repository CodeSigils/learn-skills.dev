Utilice esta habilidad cuando el usuario quiera una revisión profunda, contradictoria y de múltiples perspectivas de una base de código; las frases desencadenantes incluyen "revisar todo", "auditar esta base de código", "encontrar todo mal", "revisión de mal humor", "convocar a la junta", "revisión del panel", "destrozar esto". Convoca a la Junta de Revisión: un panel de ingenieros nombrados (Lattner como autoridad; Appel/Newell/Carmack como buscadores; Sutskever/LeCun/Karpathy como verificadores adversarios) vinculados a lentes de roles funcionales (arquitectura, aprovechamiento, corrección, seguridad, verdad de los documentos). Cada hallazgo es elaborado por un líder y debe sobrevivir a la refutación de un coordinador antes de que cuente. Revisión de solo lectura de forma predeterminada; es una capacidad de revisión, no un carril. Portátil en Claude Code / Cowork / Codex.
