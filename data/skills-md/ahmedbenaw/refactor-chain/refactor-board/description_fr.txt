Utilisez cette compétence lorsque l'utilisateur souhaite un examen approfondi, contradictoire et multiperspectif d'une base de code - les phrases de déclenchement incluent « tout examiner », « auditer cette base de code », « trouver tout ce qui ne va pas », « examen grincheux », « convoquer le conseil d'administration », « examen par un panel », « déchirer cela ». Il convoque le comité d'examen : un panel de personnalités d'ingénieurs nommées (Lattner comme autorité ; Appel/Newell/Carmack comme chercheurs ; Sutskever/LeCun/Karpathy comme vérificateurs contradictoires) liées à des lentilles de rôle fonctionnelles (architecture, harnais, exactitude, sécurité, documents-vérité). Chaque découverte est produite par un responsable et doit survivre à la réfutation d'un coordinateur avant de compter. Révision en lecture seule par défaut ; c'est une capacité de révision, pas une voie. Portable sur Claude Code / Cowork / Codex.
