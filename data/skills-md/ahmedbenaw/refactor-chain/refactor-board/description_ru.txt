Используйте этот навык, когда пользователь хочет провести глубокий, состязательный, многоаспектный обзор кодовой базы — триггерные фразы включают «проверить все», «проверить эту кодовую базу», «найти все неправильно», «раздраженный обзор», «созвать совет», «групповой обзор», «разорвать это на части». Он созывает Наблюдательный совет: группу из названных инженеров (Латтнер в качестве авторитета; Аппель/Ньюэлл/Кармак в качестве искателей; Суцкевер/ЛеКун/Карпати в качестве состязательных проверяющих), привязанных к функциональным ролевым линзам (архитектура, оборудование, корректность, безопасность, достоверность документов). Каждый вывод делается Лидером и должен пережить опровержение Координатора, прежде чем он будет засчитан. По умолчанию обзор доступен только для чтения; это возможность обзора, а не полоса.
