当用户想要对代码库进行深入、对抗性、多角度的审查时，请使用此技能 - 触发短语包括“审查所有内容”、“审核此代码库”、“发现所有错误”、“脾气暴躁的审查”、“召集董事会”、“小组审查”、“将其拆开”。它召集了审查委员会：一个由指定工程师角色组成的小组（Lattner 作为权威；Appel/Newell/Carmack 作为发现者；Sutskever/LeCun/Karpathy 作为对抗性验证者）绑定到功能角色镜头（架构、利用、正确性、安全性、文档真相）。每项发现均由主管提出，并且必须经受协调员的反驳后才算数。默认只读审核；这是一种审查能力，而不是一条车道。可跨 Claude Code / Cowork / Codex 移植。
