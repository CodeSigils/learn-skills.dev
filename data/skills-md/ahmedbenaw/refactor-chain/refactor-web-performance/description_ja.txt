Web ページやアプリの読み込みが遅い、または動作が不安定で、ユーザーがそれを測定して修正したい場合にこのスキルを使用します。これは、「ページの読み込みが遅い」、「ラグがある」、「最初のペイントに永遠に時間がかかる」、「Lighthouse スコアを改善する」、「LCP/CLS/TBT を修正する」、「サイトが遅いのはなぜ」、「レイアウトが飛び回る」などの単純なトリガーです。 Core Web Vitals (LCP、CLS、TBT/INP) のトレース/Lighthouse スタイルの監査を実行し、最大の違反者を 1 つ見つけて修正し、再測定して勝利を証明します。これは、リファクタリング チェーンの DEBUG レーンの作業ステップであり、ハーネスがケースをデバッグ/Web パフォーマンスとして分類したときに到達します。ブラウザ/DevTools トレース ツールが利用可能な場合はそれを使用します。それ以外の場合は、静的な証拠に戻ります。
