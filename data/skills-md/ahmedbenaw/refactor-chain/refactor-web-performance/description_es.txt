Utilice esta habilidad cuando una página web o aplicación se carga lentamente o tiene problemas y el usuario quiere medirla y arreglarla: desencadenantes simples como "la página se carga lentamente", "tiene retraso", "la primera pintura tarda una eternidad", "mejorar mi puntaje de Lighthouse", "arreglar LCP/CLS/TBT", "por qué el sitio es lento", "el diseño salta". Ejecuta una auditoría de seguimiento/estilo Lighthouse de Core Web Vitals (LCP, CLS, TBT/INP), encuentra el mayor infractor, lo soluciona y vuelve a medir para demostrar la victoria. Es el paso de hacer el trabajo del carril DEBUG de la cadena de refactorización, que se alcanza cuando el arnés clasifica un caso como depuración/rendimiento web. Utiliza una herramienta de seguimiento de navegador/DevTools cuando hay una disponible; de lo contrario, se recurre a la evidencia estática.
