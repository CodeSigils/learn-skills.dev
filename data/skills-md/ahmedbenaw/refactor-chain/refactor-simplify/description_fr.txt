Utilisez cette compétence pour une simplification de qualité uniquement sur le code modifié - améliorant la réutilisation, supprimant le code mort, corrigeant l'altitude (sur/sous-abstraction) et améliorant la clarté - tout en préservant EXACTEMENT le comportement. Il applique les correctifs. Les phrases de déclenchement incluent "simplifier ceci", "nettoyer cela", "réduire le passe-partout", "c'est sur-conçu", "supprimer le code mort", "dé-dupliquer ceci", "le rendre plus clair", "trop ​​de couches ici". Il ne recherche PAS les bogues, les problèmes de sécurité ou les problèmes de performances – uniquement la qualité ; utilisez refactor-review-gate / refactor-security / refactor-performance pour ceux-là. Il s'agit d'une passe de qualité qui s'exécute pendant la phase d'exécution du travail (ou en tant que nettoyage de la phase de révision) du pipeline de la chaîne de refactorisation. Préservation du comportement par contrat : il modifie le code, mais uniquement par incréments vérifiés et réversibles qui maintiennent le comportement identique.
