Use this skill for a quality-only simplification pass over changed code — improving reuse, removing dead code, fixing altitude (over/under-abstraction), and sharpening clarity — while preserving behavior EXACTLY. It applies the fixes. Trigger phrases include "simplify this", "clean this up", "reduce the boilerplate", "this is over-engineered", "remove the dead code", "de-duplicate this", "make it clearer", "too many layers here". It does NOT hunt for bugs, security issues, or performance problems — quality only; use refactor-review-gate / refactor-security / refactor-performance for those. This is a quality pass that runs in the do-the-work phase (or as a review-phase cleanup) of the refactor-chain pipeline. Behavior-preserving by contract — it edits code, but only in verified, reversible increments that keep behavior identical.
