Используйте этот навык для упрощения только качества измененного кода — улучшения повторного использования, удаления мертвого кода, исправления высоты (чрезмерная/недостаточная абстракция) и повышения четкости — при ТОЧНО сохраняя поведение. Он применяет исправления. Триггерные фразы включают в себя «упростить это», «очистить это», «уменьшить шаблонность», «это слишком сложно», «удалить мертвый код», «дедублировать это», «сделать это понятнее», «здесь слишком много слоев». Он НЕ ищет ошибки, проблемы безопасности или проблемы с производительностью — только качество; для них используйте refactor-review-gate/refactor-security/refactor-performance. Это этап проверки качества, который выполняется на этапе выполнения работы (или в качестве очистки на этапе проверки) конвейера цепочки рефакторинга. Сохранение поведения по контракту — он редактирует код, но только проверенными, обратимыми шагами, которые сохраняют идентичность поведения.
