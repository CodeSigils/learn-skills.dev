Utilice esta habilidad para pasar una simplificación de calidad sobre el código modificado (mejorar la reutilización, eliminar el código inactivo, corregir la altitud (abstracción excesiva o insuficiente) y mejorar la claridad) mientras se preserva el comportamiento EXACTAMENTE. Aplica las correcciones. Las frases desencadenantes incluyen "simplificar esto", "limpiar esto", "reducir el texto repetitivo", "esto está sobredimensionado", "eliminar el código inactivo", "desduplicar esto", "hacerlo más claro", "demasiadas capas aquí". NO busca errores, problemas de seguridad o problemas de rendimiento: solo calidad; utilice refactor-review-gate / refactor-security / refactor-rendimiento para aquellos. Este es un pase de calidad que se ejecuta en la fase de realización del trabajo (o como limpieza en la fase de revisión) de la cadena de refactorización. Preservación del comportamiento por contrato: edita el código, pero solo en incrementos verificados y reversibles que mantienen el comportamiento idéntico.
