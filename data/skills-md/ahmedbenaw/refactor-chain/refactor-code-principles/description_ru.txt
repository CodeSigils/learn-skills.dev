Используйте этот навык, когда рабочий код нуждается в улучшении структуры без изменения того, что он делает — триггерные фразы включают «рефакторинг этого», «очистка этого», «применить SOLID», «разделить эти модули», «разделить этот класс бога», «распутать этот файл», «ввести внедрение зависимостей», «реорганизовать слои». Это управляемый принципами структурный механизм конвейера цепочки рефакторинга — он обнаруживает стек, извлекает рекомендуемый набор принципов разработки программного обеспечения из реестра, открывает ОКНО РЕШЕНИЯ (контрольная точка в середине чата, где пользователь принимает рекомендацию, смешивает и сопоставляет или намеренно выбирает нетрадиционную комбинацию с четко указанными рисками), а затем применяет выбранные принципы через цикл контрольная точка → применить → проверить. Он также выполняется по умолчанию как последний этап консолидации каждой полосы. Жесткий контракт - он реструктурирует РАБОЧИЙ код, сохраняя идентичное поведение; он НЕ предназначен для добавления функций, исправления ошибок или написания наборов тестов.
