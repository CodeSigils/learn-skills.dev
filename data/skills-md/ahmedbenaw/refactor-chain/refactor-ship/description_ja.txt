このスキルは、リファクタリング チェーンの実行の確定的な仕上げとして使用します。明確な従来のメッセージでリファクタリングをコミットし、変更の記録と監査証跡から PR 概要を草案し、プッシュして CI を実行します。これはソース管理に依存せず、単一のホストの API ではなく、プレーンな git (GitHub、GitLab、または任意のリモートで動作) を使用します。これは、refactor-publish-checklist からの GO でのみ出荷されます。トリガーフレーズ: 「PR をコミットして開く」、「出荷する」、「このリファクタリングをプッシュする」、「プルリクエストを作成する」、「これを完了してマージリクエストする」、「まとめて送信する」。これは、リファクタリング チェーン パイプラインの出荷段階です。 refactor-publish-checklist が GO を返した後に実行されます。 git アクション (コミット/ブランチ/プッシュ) を実行します。製品コードは編集されません。また、単独でマージや強制プッシュを行うこともありません。
