使用此技能作為重構鏈運行的確定性結束 - 使用清晰的常規訊息提交重構，從變更記錄和審計追蹤中起草 PR 摘要，推送並讓 CI 運行。它與原始碼控制無關：它使用普通的 git（與 GitHub、GitLab 或任何遠端版本一起使用）而不是任何一台主機的 API。它僅在重構發布檢查清單的 GO 上發布。觸發短語：「提交並開啟 PR」、「傳送它」、「推播此重構」、「建立拉取請求」、「完成並合併請求此」、「將其打包並傳送」。這是重構鏈管道的交付階段；它在 refactor-publish-checklist 返回 GO 之後運行。它執行 git 操作（提交/分支/推送）—它不會編輯產品程式碼，也不會自行合併或強制推送。
