Utilice esta habilidad como final determinista de una ejecución de la cadena de refactorización: confirme la refactorización con un mensaje convencional claro, redacte un resumen de relaciones públicas a partir de la redacción de cambios y el registro de auditoría, presione y deje que se ejecute la CI. Es independiente del control de fuente: utiliza git simple (funciona con GitHub, GitLab o cualquier control remoto) en lugar de la API de cualquier host. Solo se envía en un GO desde refactor-publish-checklist. Frases de activación: "confirmar y abrir un PR", "enviarlo", "impulsar esta refactorización", "crear la solicitud de extracción", "terminar y fusionar-solicitar esto", "concluirlo y enviarlo". Esta es la fase de envío de la cadena de refactorización; se ejecuta después de que refactor-publish-checklist devuelva GO. Realiza acciones de git (commit/branch/push): no edita el código del producto y nunca fusiona ni fuerza el push por sí solo.
