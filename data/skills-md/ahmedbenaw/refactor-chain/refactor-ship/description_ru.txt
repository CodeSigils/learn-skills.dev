Используйте этот навык в качестве детерминированного завершения цепочки рефакторинга — зафиксируйте рефакторинг с четким стандартным сообщением, составьте сводку по связям с общественностью на основе записи изменений и журнала аудита, отправьте его и дайте запустить CI. Он не зависит от системы управления исходным кодом: он использует простой git (работает с GitHub, GitLab или любым удаленным устройством), а не API какого-либо одного хоста. Он поставляется только после GO из контрольного списка refactor-publish-checklist. Триггерные фразы: «зафиксировать и открыть PR», «отправить», «продвинуть этот рефакторинг», «создать запрос на включение», «завершить и выполнить мерж-реквест», «завершить и отправить». Это этап поставки конвейера цепочки рефакторинга; он запускается после того, как refactor-publish-checklist возвращает GO. Он выполняет действия git (commit/branch/push) — он не редактирует код продукта и никогда не выполняет слияние или принудительное нажатие самостоятельно.
