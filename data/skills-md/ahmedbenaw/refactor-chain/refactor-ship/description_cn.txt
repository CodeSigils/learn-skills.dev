使用此技能作为重构链运行的确定性结束 - 使用清晰的常规消息提交重构，从变更记录和审计跟踪中起草 PR 摘要，推送并让 CI 运行。它与源代码控制无关：它使用普通的 git（与 GitHub、GitLab 或任何远程版本一起使用）而不是任何一台主机的 API。它仅在重构发布检查列表的 GO 上发布。触发短语：“提交并打开 PR”、“发送它”、“推送此重构”、“创建拉取请求”、“完成并合并请求此”、“将其打包并发送”。这是重构链管道的交付阶段；它在 refactor-publish-checklist 返回 GO 之后运行。它执行 git 操作（提交/分支/推送）——它不会编辑产品代码，也不会自行合并或强制推送。
