Use this skill when the user reports a reproducible bug and wants the real cause found and fixed — plain triggers like "why is this broken", "it crashes when I…", "this throws an error", "it stopped working", "fix this bug", "there's a regression", "the test fails". It is the do-the-work step of the refactor-chain DEBUG lane (the fix→verify chain), reached when the harness classifies a case as debug/whats-wrong. It traces the symptom backward to its true origin via an evidence chain rather than patching where the error surfaces. Conditional add-on: when an Airflow `dags/` directory is detected, it also applies DAG-specific root-cause tactics.
