Utilice esta habilidad cuando un paso de refactorización toque la base de datos: esquema, migraciones, semillas, accesorios, modelos ORM o código de acceso a datos. Ejecuta comprobaciones de seguridad de los datos (recuento de filas, forma del esquema, integridad referencial) como una afirmación de verificación EXTRA durante la fase de verificación, por lo que una refactorización nunca puede mutar, eliminar o corromper datos silenciosamente mientras afirma que se conserva el comportamiento. Es CONDICIONAL: solo se activa cuando el arnés o el paso actual reporta un toque de capa de datos; en una refactorización pura de código/UI, permanece inactivo. Frases de activación: "cambiamos una migración", "esto toca el esquema", "la refactorización alteró los datos", "asegurarse de que las tablas aún coincidan", "cambió el nombre de una columna".
