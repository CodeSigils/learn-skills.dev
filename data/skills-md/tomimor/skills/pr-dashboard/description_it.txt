Esamina i PR aperti creati dall'utente per un determinato repository, mostrando titolo, stato, stato di revisione, commenti aperti, controlli CI e passaggi successivi consigliati. Da utilizzare quando l'utente menziona la revisione PR, i miei PR, i PR aperti, lo stato PR, il dashboard PR o desidera una panoramica delle proprie richieste pull.
