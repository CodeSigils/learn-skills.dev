Examine les PR ouvertes rédigées par l'utilisateur pour un dépôt donné, en affichant le titre, le statut, l'état de la révision, les commentaires ouverts, les vérifications CI et les prochaines étapes recommandées. Utilisez‑le lorsque l'utilisateur mentionne la révision de PR, mes PR, les PR ouvertes, le statut des PR, le tableau de bord des PR ou souhaite un aperçu de ses pull requests.

Veuillez toujours répondre dans la langue de l'utilisateur.
