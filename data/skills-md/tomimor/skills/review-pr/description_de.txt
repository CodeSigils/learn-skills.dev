Überprüfen Sie die PR eines Teamkollegen und erstellen Sie eine kleine Liste aussagekräftiger Bewertungskommentare auf Senior-Ingenieur-Ebene, die Sie in GitHub einfügen können. Lässt aggressiv Nitpicks, Stilvorlieben und „wäre schön“-Vorschläge fallen. Die Ausgabe erfolgt nur als Text, es werden keine automatischen Beiträge veröffentlicht. Verwenden Sie diese Option, wenn der Benutzer „review-pr“ erwähnt, die PR eines Teamkollegen überprüft, PR-Kommentare hinterlässt oder eine Veröffentlichung von Feedback auf höchster Ebene wünscht.
