Amorcez un système complet de guide d'agent pour un dépôt : génère AGENTS.md (toujours actif), .agents/{domain}.md (chargé à la demande), CLAUDE.md (redirection) et .agents/design-decisions.md en utilisant la divulgation progressive et des références canoniques au lieu du code intégré obsolète. À utiliser lorsque l'utilisateur mentionne la configuration d'AGENTS.md, le démarrage d'un guide d'agent, la configuration de CLAUDE.md pour un dépôt, la « configuration du contexte d'agent » ou l'intégration d'un nouveau dépôt pour les agents de codage IA.
