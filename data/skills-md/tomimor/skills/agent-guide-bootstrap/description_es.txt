Arranca un sistema completo de guía de agentes para un repositorio: genera AGENTS.md (siempre activo), .agents/{domain}.md (cargado bajo demanda), CLAUDE.md (redireccionamiento) y .agents/design-decisions.md utilizando divulgación progresiva y referencias canónicas en lugar de código incrustado obsoleto. Úselo cuando el usuario mencione configurar AGENTS.md, iniciar una guía de agente, configurar CLAUDE.md para un repositorio, "configurar el contexto del agente" o incorporar un nuevo repositorio para agentes de codificación de IA.
