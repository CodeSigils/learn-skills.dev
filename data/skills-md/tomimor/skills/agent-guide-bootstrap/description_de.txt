Bootstrap eines vollständigen Agentenleitfadensystems für ein Repo – generiert AGENTS.md (immer aktiv), .agents/{domain}.md (bei Bedarf geladen), CLAUDE.md (Umleitung) und .agents/design-decisions.md unter Verwendung progressiver Offenlegung und kanonischer Referenzen anstelle von veraltetem eingebettetem Code. Wird verwendet, wenn der Benutzer das Einrichten von AGENTS.md, das Bootstrapping eines Agentenleitfadens, das Konfigurieren von CLAUDE.md für ein Repo, das „Einrichten des Agentenkontexts“ oder das Onboarding eines neuen Repos für KI-Coding-Agents erwähnt.
