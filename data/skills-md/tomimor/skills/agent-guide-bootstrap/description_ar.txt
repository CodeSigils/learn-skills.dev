Bootstrap هو نظام دليل وكيل كامل لمستودعات الريبو - يُنشئ AGENTS.md (متاح دائمًا)، و.agents/{domain}.md (يتم تحميله عند الطلب)، وCLAUDE.md (إعادة توجيه)، و.agents/design-decisions.md باستخدام الكشف التدريجي والمراجع الأساسية بدلاً من التعليمات البرمجية المضمنة التي لا معنى لها. يُستخدم عندما يذكر المستخدم إعداد AGENTS.md، أو تمهيد دليل الوكيل، أو تكوين CLAUDE.md لمستودع الريبو، أو "إعداد سياق الوكيل"، أو إعداد مستودع جديد لوكلاء ترميز الذكاء الاصطناعي.
