Загрузите полную систему управления агентами для репозитория — генерирует AGENTS.md (всегда включен), .agents/{domain}.md (загружается по требованию), CLAUDE.md (перенаправление) и .agents/design-decisions.md, используя постепенное раскрытие и канонические ссылки вместо устаревшего встроенного кода. Используйте, когда пользователь упоминает настройку AGENTS.md, загрузку руководства агента, настройку CLAUDE.md для репозитория, «настройку контекста агента» или подключение нового репозитория для агентов кодирования ИИ.
