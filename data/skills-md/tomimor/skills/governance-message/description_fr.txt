Générez un message de proposition de gouvernance prêt pour Slack à partir d'une seule URL de proposition (post sur le forum, vote Tally, instantané, etc.). Récupère la page, extrait le proposant, le résumé, le contexte et le risque, puis rédige le message à l'aide du modèle de gouvernance fixe. À utiliser lorsque l'utilisateur mentionne un message de gouvernance, une proposition gouvernementale, un message gouvernemental, une gobernanza, un message Slack pour une proposition, un résumé de proposition ZKsync, un résumé de vote Tally, ou colle un lien de proposition et demande une rédaction.
