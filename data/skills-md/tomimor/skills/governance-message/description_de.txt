Generieren Sie eine Slack-fähige Governance-Vorschlagsnachricht aus einer einzigen Vorschlags-URL (Forumsbeitrag, Tally-Abstimmung, Snapshot usw.). Ruft die Seite ab, extrahiert den Antragsteller, die Zusammenfassung, den Kontext und das Risiko und erstellt dann die Nachricht mithilfe der festen Governance-Vorlage. Verwenden Sie diese Option, wenn der Benutzer Governance-Nachricht, Regierungsvorschlag, Regierungsnachricht, Gobernanza, Slack-Nachricht für einen Vorschlag, ZKsync-Vorschlagszusammenfassung, Tally-Abstimmungszusammenfassung erwähnt oder einen Vorschlagslink einfügt und um eine Beschreibung bittet.
