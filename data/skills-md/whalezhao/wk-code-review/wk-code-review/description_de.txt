Durch den Vergleich des aktuellen Zweigs mit dem Basiszweig während der Codeüberprüfung können Sie einen vollständigen Prüfplan erstellen und ihn Element für Element ausführen. Dabei werden alle geänderten Dateien abgedeckt, EliteForge-Konformitätsprüfungen, Sicherheitstests, Überprüfung der Geschäftslogik, Zuverlässigkeit und Machbarkeitsbewertung der Lösung integriert, die Wiederherstellung nach Unterbrechungen unterstützt und die Ergebnisse im Verzeichnis „{OUTPUT_DIR}“ gespeichert.
