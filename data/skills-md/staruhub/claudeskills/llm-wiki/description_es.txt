Cree y mantenga una wiki estructurada generada por LLM para cualquier base de código. Úselo cuando el usuario solicite analizar/comprender/documentar una base de código, crear un wiki de código, crear documentación de proyecto desde la fuente o actualizar un .llm-wiki existente. Se activan frases como "construir wiki", "analizar este código base", "documentar este proyecto", "actualizar wiki", "llm-wiki" o al ingresar a un proyecto desconocido que aún no tiene .llm-wiki.
