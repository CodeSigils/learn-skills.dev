Konvertierung und Anpassung der SQL-Syntax von MySQL-, Dameng- und Kingbase-Datenbanken. Unterstützt sechs Konvertierungsrichtungen: MySQL↔Dameng, MySQL↔Kingbase, Dameng↔Kingbase. Auslösewörter: SQL konvertieren, SQL-Konvertierung, Dialektkonvertierung, MySQL zu Dameng, Dameng zu MySQL, MySQL zu Kingbase, Kingbase zu MySQL, Dameng zu Kingbase, Kingbase zu Dameng, SQL anpassen, SQL-Migration.
