Esamina una o tutte le richieste pull aperte in saadeghi/daisyui utilizzando il server MCP GitHub e la verifica base-versus-PR isolata. Da utilizzare quando il Codex deve verificare i fatti di un PR daisyUI, verificare che risolva il problema dichiarato o il problema collegato, testare rischi concreti di regressione, spiegare l'esperienza dello sviluppatore prima e dopo, decidere se è sicuro unire e scrivere un rapporto conciso in tmp/pr/. Basare ogni dichiarazione del rapporto su fonti collegate, codice ispezionato o output di comandi osservato; non inventare mai affermazioni, rischi, risultati o deduzioni di fiducia.
