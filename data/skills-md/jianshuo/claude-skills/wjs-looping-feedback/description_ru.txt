Используйте, когда пользователь хочет добавить внутренний цикл обратной связи в репозиторий веб-сайта — плавающую кнопку «提个建议», с помощью которой посетители из разрешенного списка отправляют предложения, которые становятся проблемой GitHub, которые GitHub Actions превращает в автоматическое изменение кода с помощью Claude Code, автоматически объединяет и развертывает, а также записывает на панель управления /_feedback с помощью возврата одним щелчком мыши. Триггеры — «给网站加个反馈对话框», «提一句话就自动改网站», «装上反馈闭环», «цикл обратной связи», «/wjs-loping-feedback».
