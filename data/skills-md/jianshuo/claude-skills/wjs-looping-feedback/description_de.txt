Verwenden Sie diese Option, wenn der Benutzer eine In-Site-Feedback-Schleife zu einem Website-Repo hinzufügen möchte – eine schwebende „提个建议“-Schaltfläche, über die Besucher auf der Zulassungsliste Vorschläge einreichen, die zu einem GitHub-Problem werden, das GitHub Actions über Claude Code in eine automatische Codeänderung umwandelt, automatisch zusammenführt und bereitstellt und auf einem /_feedback-Dashboard mit Wiederherstellung mit einem Klick aufzeichnet. Auslöser – „给网站加个反馈对话框“, „提一句话就自动改网站“, „装上反馈闭环“, „feedback loop“, „/wjs-looping-feedback“.
