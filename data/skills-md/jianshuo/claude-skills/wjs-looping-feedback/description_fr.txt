À utiliser lorsque l'utilisateur souhaite ajouter une boucle de rétroaction sur le site à un dépôt de site Web : un bouton flottant "提个建议" où les visiteurs inscrits sur la liste d'autorisation soumettent des suggestions qui deviennent un problème GitHub, que les actions GitHub transforment en un changement de code automatique via Claude Code, fusionne et déploie automatiquement, et enregistre sur un tableau de bord /_feedback avec un retour en un clic. Déclencheurs — "给网站加个反馈对话框", "提一句话就自动改网站", "装上反馈闭环", "feedback loop", "/wjs-looping-feedback".
