Используйте, когда 王建硕 хочет систематически увеличивать количество своих подписчиков X (Twitter), проводя пронумерованные эксперименты по росту, поддающиеся A/B-тестированию, и отслеживая, какие из них действительно работают. Каждое действие получает число, гипотезу, целевую метрику, предыдущее состояние (для отката) и вердикт. Метрика North-Star — это соотношение новых подписчиков и посещений профиля (конверсия). По нему оценивается каждое изменение профиля. Ежедневно он принимает экспортированный CSV-файл X Analytics, оценивает каждый запущенный эксперимент и рекомендует сохранить/откатить результаты. Триггеры — «涨粉», «增加 X 粉丝», «X 涨粉实验», «рост подписчиков», «A/B-тест моего профиля», «今天的涨粉检查», «/wjs-x-increasing-follower».
