當王建碩想要透過迭代內容產生提示（prompts/x/prompt.md，由 every-6h tweet Action 使用）並查找哪個提示版本產生最高影響力的推文來系統地改進他的 X (Twitter) 內容時使用。每個提示編輯都是一個 git-SHA 版本、帶有假設的編號實驗；推文歸因於發佈時的即時版本，並根據每條推文的中位數進行判斷。也挖掘每條推文的印象數據，以獲取提供下一個提示編輯的內容特徵訊號（角度/長度/主題）。北極星 = 每條推文的展示次數。觸發器 — 「改變 X 的提示」、「X 內容改進」、「哪版提示最好」、「什麼內容印像很高」、「改進我的推文」、「A/B 測試 X 提示」、「/wjs-x-improving-content」。
