Используйте, когда 王建硕 хочет систематически улучшать свой контент X (Twitter), перебирая подсказку для создания контента (prompts/x/prompt.md, используемую действием каждые 6 часов твита) и определяя, какая версия подсказки создает твиты с наибольшим охватом. Каждое редактирование подсказки представляет собой пронумерованный эксперимент с версией git-SHA и гипотезой; твиты относят к текущей версии на момент публикации и оцениваются по среднему количеству показов на твит. Также анализируются данные о показах каждого твита для определения сигналов функций контента (угол/длина/тема), которые используются при следующем редактировании подсказки. Полярная звезда = количество показов на твит. Триггеры — «подсказка 改 X 的», «X 内容改进», «哪版 подсказка 最好», «什么内容 впечатление 高», «улучшить мои твиты», «A/B-тестирование подсказки X», «/wjs-x-improving-content».
