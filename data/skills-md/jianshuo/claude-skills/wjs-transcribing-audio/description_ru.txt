Используйте, когда у пользователя есть аудио или видео и ему нужна расшифровка с отметкой времени (SRT) на исходном языке. Маршруты по исходному языку — по умолчанию для китайского языка используется Volcano (豆包) ASR; другие языки (испанский, английский, португальский, французский, итальянский, японский, корейский и т. д.) используют OpenAI Whisper API с временными метками на уровне слов и самособираемыми репликами. Выводит SRT с подсказками, ограниченными пунктуацией и ограниченными для чтения на экране. Триггеры — «转写», «转成字幕», «做 SRT», «расшифровать», «создать субтитры», «речь в текст», «出字幕».
