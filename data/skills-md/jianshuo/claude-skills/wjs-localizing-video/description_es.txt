Orquestador ligero para el proceso de localización de vídeo de un extremo a otro. Rutas hacia las cuatro subhabilidades enfocadas: /wjs-transcribing-audio, /wjs-translating-subtitles, /wjs-dubbing-video, /wjs-burning-subtitles. Se utiliza cuando el usuario solicita la localización completa de una sola vez ("帮我把这个西班牙语视频做成中文字幕+配音", "traducir y doblar este vídeo", "做完整的本地化"). Para cualquier paso individual (simplemente transcribir, simplemente traducir, simplemente copiar, simplemente grabar), invoque la subhabilidad directamente: es más rápido y el límite es más claro.
