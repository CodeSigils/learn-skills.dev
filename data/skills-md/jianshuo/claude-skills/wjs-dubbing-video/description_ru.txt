Используйте, когда у пользователя есть видео + SRT на целевом языке и он хочет, чтобы видео действительно говорило на этом языке — генерирует синхронизированную по времени голосовую дубляж TTS. Маршруты по голосовому идентификатору — Volcano (豆包) TTS для китайского языка, нейронная сеть Edge-TTS для любого языка. По умолчанию один голос (один динамик); подключить несколько динамиков посредством визуального дневника. Выводит `*_<lang>_dub.mp4` с дублированным звуком вместо оригинала. Окончательное микширование (аудио + запись) передается в /wjs-burning-subtitles. Триггеры — «配音», «中文配音», «Китайский дубляж», «озвучка», «дублировать видео», «TTS this SRT», «разный голос для каждого говорящего».
