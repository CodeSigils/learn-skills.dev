استخدم هذه المهارة عندما يريد المستخدم تصميم كائن مادي قابل للطباعة ثلاثية الأبعاد ينوي تصنيعه. المشغلات: أي ذكر لـ "الطباعة ثلاثية الأبعاد"، أو "STL"، أو "النموذج البارامتري"، أو "Gridfinity"، أو "العلبة"، أو "القوس"، أو "التركيب"، أو "الحالة"، أو "الإسكان"، أو "CadQuery"، أو "OpenSCAD"، أو طابعة FDM محددة (Bambu Lab، أو Prusa، أو Ender)؛ أسئلة حول التصميم المناسب للطباعة، أو الملاءمة، أو التفاوتات، أو سمك الجدار؛ وطلبات الأجزاء الوظيفية مثل حاويات Arduino أو منظمات الكابلات أو حوامل الحائط أو المحولات أو المكونات الميكانيكية. يتم إطلاقه أيضًا عندما يصف المستخدم شيئًا ماديًا حقيقيًا يجب تصنيعه، بشرط أن يكون الهدف هو تصنيعه. لا تستخدمه في: العرض ثلاثي الأبعاد، أو الرسوم المتحركة، أو أصول الألعاب، أو الفن الرقمي فقط، أو التصوير المساحي، أو النحت، أو تحرير ملف STL موجود لدى المستخدم بالفعل، أو أي عمل ثلاثي الأبعاد لا يتجه نحو الطابعة.
