Проанализируйте исходный код проекта мини-программы (включая сжатый/обфусцированный код), определите основные бизнес-шаги, извлеките сетевые интерфейсы и вызовы JSAPI, сгенерируйте подпакеты навыков, соответствующие спецификации wx.modelContext (включая атомарные интерфейсы и атомарные компоненты), и завершите интеграцию конфигураций app.json/project.config.json. Запускается в следующих сценариях: преобразование возможностей страницы мини-программы в атомарные интерфейсы ИИ мини-программы, создание кода навыков/подпакета, получение инструментов MCP из исходного проекта и создание кода режима разработки для ИИ мини-программы. Эта задача ограничивается статической генерацией; после завершения генерации выходные данные должны быть переданы в wxa-skills-validate для проверки.
