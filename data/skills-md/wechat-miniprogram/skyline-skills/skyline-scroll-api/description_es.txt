Habilidades API de control de desplazamiento de Skyline. Cubre ScrollViewContext (desplazamiento programático para actualizar, arrastrar a secundario, posicionamiento de desplazamiento), DraggableSheetContext (desplazamiento programático del panel de media pantalla), worklet.scrollViewContext (control de desplazamiento directo del hilo de la interfaz de usuario). Úselo para activar mediante programación la actualización/secundaria, controlar la posición de DraggableSheet y manipular el desplazamiento dentro de los worklets. Palabras clave de activación: ScrollViewContext, DraggableSheetContext, scrollTo, triggerRefresh, triggerTwoLevel, API de extracción para actualizar, API de extracción a secundaria, API de desplazamiento, worklet scrollViewContext.
