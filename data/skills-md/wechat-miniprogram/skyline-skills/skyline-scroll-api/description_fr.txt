Compétences de l'API de contrôle de défilement Skyline. Couvre ScrollViewContext (extraction programmée pour actualiser, extraction secondaire déroulante, positionnement du défilement), DraggableSheetContext (défilement programmé d'un demi-panneau), worklet.scrollViewContext (contrôle de défilement direct sur le fil de l'interface utilisateur). Utilisé pour les déclencheurs d'actualisation/secondaires programmatiques, le contrôle de la position de DraggableSheet et la manipulation du défilement dans les worklets. Mots-clés de déclenchement : ScrollViewContext, DraggableSheetContext, scrollTo, triggerRefresh, triggerTwoLevel, API pull-to-refresh, API secondaire déroulante, API de défilement, worklet scrollViewContext.
