Competenze API di controllo scorrimento Skyline. Copre ScrollViewContext (pull-to-refresh programmatico, pulldown secondario, posizionamento scorrimento), DraggableSheetContext (scorrimento programmatico di pannelli a metà schermo), worklet.scrollViewContext (controllo scorrimento diretto del thread dell'interfaccia utente). Adatto per attivare a livello di codice aggiornamento/secondario, controllare la posizione di DraggableSheet e manipolare lo scorrimento nei worklet. Parole chiave di attivazione: ScrollViewContext, DraggableSheetContext, scrollTo, triggerRefresh, triggerTwoLevel, API pull-to-refresh, API secondaria pulldown, API di scorrimento, worklet scrollViewContext.
