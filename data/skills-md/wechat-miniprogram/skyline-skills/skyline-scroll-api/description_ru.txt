Навыки API управления прокруткой Skyline. Охватывает ScrollViewContext (программное вытягивание для обновления, вторичное раскрывающееся меню, позиционирование прокрутки), DraggableSheetContext (программная прокрутка полуэкранной панели), worklet.scrollViewContext (управление прямой прокруткой пользовательского интерфейса). Подходит для программного запуска обновления/вторичного обновления, управления положением DraggableSheet, управления прокруткой в ​​рабочем документе. Ключевые слова триггера: ScrollViewContext, DraggableSheetContext, ScrollTo, триггерРефреш, триггерТвоЛевел, API обновления по запросу, вторичный API раскрывающегося списка, API прокрутки, рабочий элемент ScrollViewContext.
