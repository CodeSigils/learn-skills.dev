스카이라인 스크롤 제어 API 기술. ScrollViewContext(프로그래밍 방식으로 새로 고침, 두 번째 수준으로 당김, 스크롤 위치 지정), DraggableSheetContext(절반 화면 패널 프로그래밍 방식 스크롤) 및 worklet.scrollViewContext(UI 스레드 직접 스크롤 제어)를 다룹니다. 프로그래밍 방식으로 새로 고침/두 번째 수준을 트리거하고, DraggableSheet 위치를 제어하고, worklet에서 스크롤을 조작하는 데 사용됩니다. 트리거 키워드: ScrollViewContext, DraggableSheetContext, scrollTo, TriggerRefresh, TriggerTwoLevel, 당겨서 새로 고침 API, 두 번째 수준으로 끌어오기 API, 스크롤 API, worklet scrollViewContext.
