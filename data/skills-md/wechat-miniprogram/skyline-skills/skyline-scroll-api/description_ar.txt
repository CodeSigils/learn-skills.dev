مهارات واجهة برمجة التطبيقات للتحكم في التمرير في Skyline. يغطي ScrollViewContext (السحب للتحديث البرمجي، والسحب على مستويين، وتحديد موضع التمرير)، وDraggableSheetContext (التمرير البرمجي للوحة نصف الشاشة)، وworklet.scrollViewContext (التحكم المباشر في التمرير لموضوع واجهة المستخدم). مناسب لبدء إجراءات التحديث/الثانوية برمجيًا، والتحكم في موضع DraggableSheet، ومعالجة التمرير في أوراق العمل. الكلمات الرئيسية للتشغيل: ScrollViewContext، DraggableSheetContext، التمرير إلى، TriggerRefresh، TriggerTwoLevel، API السحب للتحديث، واجهة برمجة تطبيقات السحب ذات المستويين، API التمرير، Worklet ScrollViewContext.
