Habilidades de transición de página y enrutamiento personalizado de Skyline. Cubre animaciones de ruta personalizadas (routeBuilder), rutas preestablecidas (7 tipos wx://), gestos de retroceso de página, animaciones de transición de contenedor (contenedor abierto), API de enrutador. Ideal para ventanas emergentes de media pantalla, escalado de páginas, hojas inferiores, expansiones de tarjetas, etc. Palabras clave de activación: enrutamiento personalizado, ruta personalizada, routeBuilder, navegar a, transición de página, media pantalla, ruta preestablecida, gesto hacia atrás, contenedor abierto.
