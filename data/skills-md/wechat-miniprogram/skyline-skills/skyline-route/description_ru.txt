Навыки индивидуальной маршрутизации Skyline и перехода между страницами. Охватывает пользовательскую анимацию маршрутов (routeBuilder), предустановленные маршруты (7 типов wx://), жесты возврата страницы, переходы между контейнерами (open-container) и API Router API. Используйте его для реализации всплывающих окон на половину экрана, масштабирования страниц, нижних листов, расширения карточек и других эффектов перехода. Ключевые слова-триггеры: пользовательская маршрутизация, пользовательский маршрут, RouteBuilder, NavigationTo, переход страницы, полуэкран, заданный маршрут, жест назад, открытый контейнер.
