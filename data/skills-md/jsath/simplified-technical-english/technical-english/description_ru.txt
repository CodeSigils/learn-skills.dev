Перепишите или проверьте любой текст, используя принципы ASD-STE100 Simplified Технический английский, стандарт аэрокосмического письма, созданный для летных руководств. Убивает ИИ силой - короткие предложения, одно утвержденное значение для каждого слова, активный залог, без заполнителя. Используйте, когда вас просят «упростить это», «убрать это», «сделать это более понятным», «переписать на простом английском языке», «применить STE» или когда документация, инструкции, файлы README или текст, сгенерированный искусственным интеллектом, должны быть удобочитаемы для каждого носителя английского языка, включая тех, кто не является родным.
