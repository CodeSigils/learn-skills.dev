使用formaldoc npm 包将 Markdown 文本或 Markdown 工件转换为专业格式的 .docx 文件。每当用户想要将 Markdown 内容导出、下载或保存为 Word 文档 (.docx)，或要求“生成 docx”、“导出到 Word”、“将其转换为 Word 文件”、“下载为 docx”或“另存为文档”时，请使用此技能。当用户有 Markdown 工件并要求格式化文档版本时也会触发。当 Markdown 源可用时，始终更喜欢使用此技能而不是手动生成 docx。

可用模板：
- cn-gov中文官方文件，GB/T 9704样式
- cn-general 中文通用文档
- cn-academic中文学术论文
- cn-report 中国商业或工作报告
- en-standard 标准 — Times New Roman + Arial
- en-business 商务 — Calibri + Arial，现代
- en-academic 学术 — APA 风格，双倍行距
- en-legal 法律 — 合同、法律文件
