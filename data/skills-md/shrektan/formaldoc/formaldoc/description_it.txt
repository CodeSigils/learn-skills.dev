Converti testo Markdown o elementi Markdown in file .docx formattati professionalmente utilizzando il pacchetto formaldoc npm. Utilizza questa capacità ogni volta che l'utente desidera esportare, scaricare o salvare contenuti Markdown come documento Word (.docx) o chiede di "generare un docx", "esportare in Word", "trasformarlo in un file Word", "scarica come docx" o "salva come documento". Si attiva anche quando l'utente ha un artefatto Markdown e richiede una versione del documento formattato. Preferisci sempre questa abilità rispetto alla generazione manuale di documenti quando è disponibile la fonte Markdown.

- cn-general Documento cinese di uso generale
- articolo accademico cinese cn-academic
