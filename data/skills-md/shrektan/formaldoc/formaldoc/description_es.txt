Convierta texto de Markdown o artefactos de Markdown en archivos .docx con formato profesional utilizando el paquete formaldoc npm. Utilice esta habilidad siempre que el usuario quiera exportar, descargar o guardar contenido de Markdown como un documento de Word (.docx), o solicite "generar un docx", "exportar a Word", "convertirlo en un archivo de Word", "descargar como docx" o "guardar como documento". También se activa cuando el usuario tiene un artefacto Markdown y solicita una versión del documento formateado. Prefiera siempre esta habilidad a la generación manual de docx cuando la fuente Markdown esté disponible.

Plantillas disponibles:
- Documento oficial chino cn-gov, estilo GB/T 9704
- documento de propósito general chino cn-general
- artículo académico chino cn-académico
- cn-report informe de negocios o trabajo chino
- Estándar estándar: Times New Roman + Arial
- es-business Business — Calibri + Arial, moderno
- en-académico Académico - estilo APA, doble espacio
- es-legal Legal — Contratos, documentos legales
