使用formaldoc npm 套件將 Markdown 文字或 Markdown 工件轉換為專業格式的 .docx 檔案。每當使用者想要將 Markdown 內容匯出、下載或儲存為 Word 文件 (.docx)，或要求「產生 docx」、「匯出到 Word」、「將其轉換為 Word 文件」、「下載為 docx」或「另存為文件」時，請使用此技能。當使用者有 Markdown 工件並要求格式化文件版本時也會觸發。當 Markdown 來源可用時，總是偏好使用此技能而不是手動產生 docx。

可用模板：
- cn-gov中文官方文件，GB/T 9704樣式
- cn-general 中文通用文檔
- cn-academic中文學術論文
- cn-report 中國商業或工作報告
- en-standard 標準 — Times New Roman + Arial
- en-business 商務 — Calibri + Arial，現代
- en-academic 學術 — APA 風格，雙倍行距
- en-legal 法律 — 合約、法律文件
