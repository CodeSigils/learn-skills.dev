Esegui la scansione dei file del flusso di lavoro di GitHub Actions per individuare eventuali vulnerabilità della sicurezza leggendo il file YAML e segnalando direttamente i risultati: senza strumenti esterni, senza installazione, senza esecuzione della shell. Utilizza questa competenza ogni volta che l'utente condivide un file `.github/workflows/`, incolla il flusso di lavoro YAML, richiede una revisione della sicurezza CI/CD, menziona `pull_request_target`, `workflow_run`, blocco di azioni, autorizzazioni `GITHUB_TOKEN`, richieste pwn, iniezione di modelli, avvelenamento della cache, esfiltrazione di segreti, rischio della catena di fornitura o qualsiasi argomento di rafforzamento di GitHub Actions. Si attiva anche quando l'utente sta rafforzando un repository OSS, eseguendo una valutazione del team rosso CI/CD, valutando un obiettivo per la scansione della catena di fornitura o scrivendo pubblicamente sulla sicurezza CI/CD. Pregiudizio verso l’attivazione di questa abilità piuttosto che la risposta dalla memoria: le impostazioni predefinite di sicurezza CI/CD sono sbagliate quasi ovunque e le regole non sono intuitive.
