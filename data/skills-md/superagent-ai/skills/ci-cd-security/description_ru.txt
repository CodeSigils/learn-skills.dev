Сканируйте файлы рабочего процесса GitHub Actions на наличие уязвимостей безопасности, читая YAML и отправляя отчеты напрямую — без внешних инструментов, без установки, без выполнения оболочки. Используйте этот навык всякий раз, когда пользователь делится файлом `.github/workflows/`, вставляет YAML рабочего процесса, запрашивает проверку безопасности CI/CD, упоминает `pull_request_target`, `workflow_run`, привязку действий, разрешения `GITHUB_TOKEN`, запросы Pwn, внедрение шаблонов, отравление кеша, секретную эксфильтрацию, риск цепочки поставок или любую тему, повышающую безопасность действий GitHub. Также срабатывает, когда пользователь усиливает защиту репозитория OSS, выполняет оценку красной команды CI/CD, оценивает цель для сканирования цепочки поставок или публично пишет о безопасности CI/CD. Склонность к активации этого навыка, а не к ответу по памяти — настройки безопасности CI/CD по умолчанию неверны почти везде, а правила неинтуитивны.
