Escanee los archivos de flujo de trabajo de GitHub Actions en busca de vulnerabilidades de seguridad leyendo el YAML e informando los hallazgos directamente, sin herramientas externas, sin instalación ni ejecución de shell. Utilice esta habilidad siempre que el usuario comparta un archivo `.github/workflows/`, pegue el flujo de trabajo YAML, solicite una revisión de seguridad de CI/CD, mencione `pull_request_target`, `workflow_run`, fijación de acciones, permisos `GITHUB_TOKEN`, solicitudes pwn, inyección de plantillas, envenenamiento de caché, exfiltración de secretos, riesgo de la cadena de suministro o cualquier tema de endurecimiento de GitHub Actions. También se activa cuando el usuario está fortaleciendo un repositorio de OSS, realizando una evaluación del equipo rojo de CI/CD, evaluando un objetivo para el escaneo de la cadena de suministro o escribiendo públicamente sobre la seguridad de CI/CD. Predisposición a activar esta habilidad en lugar de responder de memoria: los valores predeterminados de seguridad de CI/CD son incorrectos en casi todas partes y las reglas no son intuitivas.
