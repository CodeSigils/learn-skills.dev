YAML を読み取り、結果を直接報告することで、GitHub Actions ワークフロー ファイルをスキャンしてセキュリティの脆弱性を検出します。外部ツール、インストール、シェルの実行は必要ありません。ユーザーが `.github/workflows/` ファイルを共有するとき、ワークフロー YAML を貼り付けるとき、CI/CD セキュリティ レビューを要求するとき、`pull_request_target`、`workflow_run`、アクションの固定、`GITHUB_TOKEN` 権限、pwn リクエスト、テンプレート インジェクション、キャッシュ ポイズニング、シークレットの漏洩、サプライ チェーンのリスク、または GitHub Actions の強化に関するトピックについて言及するときは常に、このスキルを使用します。また、ユーザーが OSS リポジトリを強化しているとき、CI/CD レッド チーム評価を行っているとき、サプライ チェーン スキャンの対象を評価しているとき、または CI/CD セキュリティについて公的に執筆しているときにもトリガーされます。記憶に基づいて答えるのではなく、このスキルをトリガーすることへのバイアス — CI/CD セキュリティのデフォルトはほとんどどこでも間違っており、ルールは直感的ではありません。
