قم بفحص ملفات سير عمل GitHub Actions بحثًا عن الثغرات الأمنية من خلال قراءة YAML والإبلاغ عن النتائج مباشرة - بدون أدوات خارجية، بدون تثبيت، بدون تنفيذ Shell. استخدم هذه المهارة عندما يقوم المستخدم بمشاركة ملف `.github/workflows/`، أو لصق سير العمل YAML، أو طلب مراجعة أمان CI/CD، أو ذكر pull_request_target، أو `workflow_run`، أو تثبيت الإجراء، أو أذونات `GITHUB_TOKEN`، أو طلبات pwn، أو حقن القالب، أو تسميم ذاكرة التخزين المؤقت، أو الترشيح السري، أو مخاطر سلسلة التوريد، أو أي موضوع يتعلق بإجراءات GitHub. يتم تشغيله أيضًا عندما يقوم المستخدم بتعزيز مستودع OSS، أو إجراء تقييم للفريق الأحمر لـ CI/CD، أو تقييم هدف لفحص سلسلة التوريد، أو الكتابة علنًا عن أمان CI/CD. الانحياز نحو تحفيز هذه المهارة بدلاً من الاستجابة من الذاكرة - الإعدادات الافتراضية لأمن CI/CD خاطئة في كل مكان تقريبًا والقواعد غير بديهية.
