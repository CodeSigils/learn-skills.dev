Überprüfen Sie einen KI-Agenten-Skill auf Sicherheitsrisiken, bevor Sie ihn installieren oder ihm vertrauen. Führt einen deterministischen Scanner aus (Regex-Muster, Python-AST-Analyse, Source-to-Sink-Taint-Tracking und YARA-Signaturen) und begründet dann die Absicht – Erkennung von Prompt-Injection, Credential-Exfiltration, Persistenz, Memory Poisoning, bösartigem Code, Lieferkettenrisiken und Nichtübereinstimmung von Beschreibung und Verhalten. Stellen Sie sicher, dass Sie diesen Skill immer dann verwenden, wenn der Benutzer einen Skill, ein Plugin, SKILL.md oder ein Agent-Tool scannen, prüfen, prüfen, überprüfen oder die Sicherheit überprüfen möchte – sei es ein lokaler Ordner, eine ZIP-/.skill-Datei oder ein geklontes Repo – und wenn jemand fragt: „Ist die Installation dieses Skills sicher?“
