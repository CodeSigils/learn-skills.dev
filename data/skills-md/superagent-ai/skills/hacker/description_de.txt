Cursor-nativer Autoresearch-Orchestrator für offensives Sicherheitsengagement und Ausnutzbarkeit, inspiriert von Offensive-Claude. Verwendung für einen autorisierten Offensiveinsatz, einen Red-Team- oder Pentest-Workflow, eine Bewertung im Kill-Chain-Stil, einen bereichsbezogenen Web-/Netzwerk-/Cloud-/Mobil-/AD-/Bug-Bounty-Offensivplan oder eine Ausnutzbarkeitsvalidierung von Defensivergebnissen. Im Modus „Befunde validieren“ wird eine begrenzte, benutzergesteuerte automatische Forschungsschleife über deduplizierte Ergebnisse ausgeführt: mehrere Hypothesendurchgänge/Zyklen von Hypothesenstellen, Experimentieren, Beobachten, Verfeinern. Verwenden Sie es immer dann, wenn der Benutzer eine Autoresearch-Schleife, eine iterative oder mehrstufige Hypothesenschleife ausführen oder Ergebnisse für eine festgelegte Anzahl von Zyklen schleifen oder iterieren möchte. Unterstützt den Engagement-Modus und den Validierungsmodus. Nur Anleitung: Enthält keine Scanner, Exploit-Runner, Payload-Builder oder lokalen Skripte.
