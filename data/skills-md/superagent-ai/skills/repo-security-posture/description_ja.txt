GitHub リポジトリのセキュリティ体制を監査し、ブランチ保護、CODEOWNERS、GitHub アクション、パブリッシュ/リリースの整合性、コラボレーター アクセス、セキュリティ機能、依存関係のレビューにわたるギャップの強化を監査します。リポジトリのレビューまたは強化、GitHub 構成の評価、CI/CD またはアクションのセキュリティのチェック、サプライ チェーンの態勢の評価、メンテナ向けのセキュリティ Todo の準備をするとき、またはユーザーが「リポジトリのセキュリティ態勢」、「リポジトリを監査する」、「この GitHub リポジトリを強化する」、「アクションのセキュリティ」、「侵害されたメンテナから保護する」と言うとき、または GitHub URL を指して何を修正するかを尋ねるときに使用します。
