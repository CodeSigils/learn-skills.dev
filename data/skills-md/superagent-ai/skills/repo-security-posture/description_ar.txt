قم بمراجعة الوضع الأمني ​​لمستودع GitHub وسد الفجوات عبر حماية الفروع، ومالكي الكود، وإجراءات GitHub، وسلامة النشر/الإصدار، ووصول المتعاون، وميزات الأمان، ومراجعة التبعية. يُستخدم عند مراجعة الريبو أو تقويته، أو تقييم تكوين GitHub، أو التحقق من أمان CI/CD أو أمان الإجراءات، أو تقييم وضع سلسلة التوريد، أو إعداد مهام الأمان التي تواجه المشرف، أو عندما يقول المستخدم "وضع أمان الريبو"، أو "تدقيق الريبو الخاص بي"، أو "تقوية مستودع GitHub هذا"، أو "أمان الإجراءات"، أو "الحماية من مشرف مخترق"، أو يشير إلى عنوان URL لـ GitHub ويسأل عما يجب إصلاحه.
