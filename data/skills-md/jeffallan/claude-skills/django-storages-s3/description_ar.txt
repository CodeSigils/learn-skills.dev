استخدمه عند تكوين Django لتخزين الملفات الثابتة وملفات الوسائط على AWS S3 باستخدام مخازن django. يتم الاستدعاء عند العمل باستخدام إعداد STORAGES أو مجموعات S3 أو عناوين URL الموقعة مسبقًا أو CloudFront أو تخزين الملفات المدعومة من boto3 في settings.py. يقوم بتكوين أمر Django 4.2+ STORAGES، والواجهات الخلفية المخصصة العامة/الخاصة، وعناوين URL الخاصة بـ GET/POST، وسياسات IAM، ومحاكاة S3 للاختبارات. مصطلحات التشغيل: django-storages، S3، boto3، S3Boto3Storage، STORAGES، عنوان URL المحدد مسبقًا، CloudFront، ملفات الوسائط، Collectstatic، AWS_STORAGE_BUCKET_NAME.
