Da utilizzare quando si configura Django per archiviare file statici e multimediali su AWS S3 con archivi django. Richiamalo quando lavori con l'impostazione STORAGES, i bucket S3, gli URL prefirmati, CloudFront o l'archiviazione di file supportata da boto3 in settings.py. Configura il dict Django 4.2+ STORAGES, backend personalizzati pubblici/privati, URL GET/POST prefirmati, policy IAM e mocking S3 per i test. Termini di attivazione: django-storages, S3, boto3, S3Boto3Storage, STORAGES, URL prefirmato, CloudFront, file multimediali, collectorstatic, AWS_STORAGE_BUCKET_NAME.
