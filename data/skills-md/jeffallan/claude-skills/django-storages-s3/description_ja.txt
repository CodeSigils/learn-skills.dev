django-storages を使用して AWS S3 に静的ファイルとメディア ファイルを保存するように Django を設定する場合に使用します。 settings.py の STORAGES 設定、S3 バケット、署名付き URL、CloudFront、または boto3 ベースのファイル ストレージを操作するときに呼び出します。 Django 4.2 以降の STORAGES dict、パブリック/プライベート カスタム バックエンド、署名付き GET/POST URL、IAM ポリシー、テスト用の S3 モックを構成します。トリガー用語: django-storages、S3、boto3、S3Boto3Storage、STORAGES、署名付き URL、CloudFront、メディア ファイル、collectstatic、AWS_STORAGE_BUCKET_NAME。
