Используйте при настройке Django для хранения статических и медиафайлов на AWS S3 с помощью хранилищ django. Вызов при работе с настройкой STORAGES, корзинами S3, заранее назначенными URL-адресами, CloudFront или файловым хранилищем на базе boto3 в settings.py. Настраивает Django 4.2+ STORAGES dict, общедоступные/частные пользовательские серверные части, заранее назначенные URL-адреса GET/POST, политики IAM и макет S3 для тестов. Условия триггера: django-storages, S3, boto3, S3Boto3Storage, STORAGES, заданный URL-адрес, CloudFront, медиа-файлы, Collectstatic, AWS_STORAGE_BUCKET_NAME.
