À utiliser lors de la configuration de Django pour stocker des fichiers statiques et multimédias sur AWS S3 avec Django-storages. Invoquez lorsque vous travaillez avec le paramètre STORAGES, les compartiments S3, les URL présignées, CloudFront ou le stockage de fichiers sauvegardé par boto3 dans settings.py. Configure le dict Django 4.2+ STORAGES, les backends personnalisés publics/privés, les URL GET/POST présignées, les politiques IAM et la simulation S3 pour les tests. Termes déclencheurs : django-storages, S3, boto3, S3Boto3Storage, STORAGES, URL présignée, CloudFront, fichiers multimédias, collectstatic, AWS_STORAGE_BUCKET_NAME.
