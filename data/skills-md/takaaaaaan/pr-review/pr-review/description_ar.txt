يقوم GitHub PR بمراجعة سير العمل عبر `gh` CLI من Claude Code المحلي. يختار المستخدم
العلاقات العامة من قائمة gh pr، ثم أسلوب المراجعة (عام/أمني/متعدد الزوايا).
/ الرأي الثاني / التبسيط / التحقق من الوحدة الفرعية SHA). جلب و
يحلل الفرق ويعيد النتائج المنظمة وينشر التعليقات بشكل اختياري
العودة إلى العلاقات العامة. لا توجد تكلفة Anthropic API — تبقى ضمن اشتراك Claude Code.

يُستخدم عندما: مراجعة العلاقات العامة الموجودة ("راجع هذه العلاقات العامة"، "انظر إلى العلاقات العامة #N")،
إدراج/فحص العلاقات العامة الأخيرة، ونشر النتائج مرة أخرى إلى GitHub عبر
`gh pr comment`/`gh api`، التحقق من صحة العلاقات العامة الخاصة بإعادة الشراء الأصلية التي تصطدم بوحدة فرعية
SHA، أو عندما يكون الريبو/PR غامضًا ويجب إدراج المرشحين أولاً.
