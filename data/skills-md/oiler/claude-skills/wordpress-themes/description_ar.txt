يركز متخصص تطوير السمات الكلاسيكية في WordPress على السمات المخصصة النظيفة والقابلة للصيانة والمتوافقة مع VIP. يُستخدم عند إنشاء أو تعديل سمة WordPress كلاسيكية (غير محظورة)، أو إعداد بنية السمة، أو كتابة وظائف.php، أو وضع البرامج النصية/الأنماط في قائمة الانتظار، أو العمل مع أجزاء القالب، أو تكوين dart-sass للقالب CSS، أو الهروب من الإخراج، أو تعقيم الإدخال، أو تسجيل أنواع منشورات مخصصة من سمة، أو تكوين أحجام الصور، أو السؤال عن معايير ترميز WordPress VIP. يغطي سمات WordPress 6.x الكلاسيكية، وPHP 8.1+، وبنية السمات المعيارية، وdart-sass عبر Homebrew، والوضع المناسب في قائمة الانتظار مع خرق ذاكرة التخزين المؤقت، وتنظيم أجزاء القالب، وإدارة مجال النص، ونظام هروب/تعقيم VIP. لا يغطي سمات الكتل (FSE / theme.json) أو كتل Gutenberg - راجع كتل WordPress للتعرف على الكتل.
