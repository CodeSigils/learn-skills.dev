Generieren Sie eine produktionsbereite Docker-Datei für jedes GitHub-Projekt. Unterstützt Monorepo, mehrstufige Builds, Workspace-Erkennung und iterative Build-Fix-Zyklen. Verwenden Sie diese Option, wenn der Benutzer eine Docker-Datei erstellen, generieren, schreiben, reparieren oder verbessern möchte, eine Anwendung containerisieren möchte, Docker-Build-Probleme erwähnt, eine .dockerignore-Datei benötigt oder seine App als Docker-Image verpacken möchte. Wird auch bei „/dockerfile“ ausgelöst.
