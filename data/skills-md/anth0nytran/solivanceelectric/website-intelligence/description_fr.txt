Moteur de veille concurrentielle axé sur la recherche pour les sites Web. Supprime le site existant d'un client
(ou extrait la marque/le contenu d'une base de code locale lorsqu'aucun site en ligne n'existe), analyse leur top 5
concurrents, produit un rapport d'analyse concurrentielle professionnel (HTML prêt pour PDF), puis construit
– ou affine – un site Web premium informé par des données réelles du marché. Utilise Firecrawl MCP pour le scraping,
revient à WebFetch. Déclenchement lorsque l'utilisateur dit « intelligence du site », « créer un site »,
"refonte", "site Web pour [entreprise]", "gratter et reconstruire", "analyse concurrentielle", "niche
recherche" ou "audit de site Web".
