Motor de inteligencia competitiva para sitios web basado en investigaciones. Elimina el sitio existente de un cliente
(o extrae la marca/contenido de una base de código local cuando no existe un sitio activo), analiza sus 5 principales
competidores, produce un informe de análisis competitivo profesional (HTML listo para PDF) y luego construye
(o perfecciona) un sitio web premium basado en datos reales del mercado. Utiliza Firecrawl MCP para raspar,
recurre a WebFetch. Se activa cuando el usuario dice "inteligencia del sitio web", "crear un sitio",
"rediseño", "sitio web para [negocios]", "eliminación y reconstrucción", "análisis competitivo", "nicho
"investigación" o "auditoría de sitios web".
