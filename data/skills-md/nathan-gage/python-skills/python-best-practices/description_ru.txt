Рекомендации по разработке программного обеспечения Python на основе реальных шаблонов PR-обзоров. Этот навык следует использовать при написании, проверке или рефакторинге кода Python, особенно классов данных, сервисных интерфейсов, обработки ошибок и аннотаций типов. Запускается по задачам, связанным с модулями Python, проектированием API, моделированием данных, безопасностью типов, обработкой исключений или рефакторингом для удобства обслуживания.
