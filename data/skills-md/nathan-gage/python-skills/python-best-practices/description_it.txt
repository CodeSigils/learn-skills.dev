Linee guida per l'ingegneria del software Python da modelli di revisione PR reali. Questa competenza dovrebbe essere utilizzata durante la scrittura, la revisione o il refactoring del codice Python, in particolare classi di dati, interfacce di servizio, gestione degli errori e annotazioni di tipo. Trigger su attività che coinvolgono moduli Python, progettazione API, modellazione dei dati, indipendenza dai tipi, gestione delle eccezioni o refactoring per la manutenibilità.
