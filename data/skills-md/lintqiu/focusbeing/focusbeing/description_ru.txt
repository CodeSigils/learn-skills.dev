Инструмент CLI цифрового поколения людей, вызывает серверный API с помощью accessKeyId/accessKeySecret, поддерживает отправку задач (MP3/MP4/текст → видео) и запрос результатов задач (orderNo); не сохраняет бизнес-данные в этом хранилище; учетные данные используются только внутри процесса для заголовков запросов; данные отправляются на серверную часть, настроенную пользователем.
