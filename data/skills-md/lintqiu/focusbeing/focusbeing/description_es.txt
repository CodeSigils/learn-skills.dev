Herramienta CLI de generación humana digital, utiliza accessKeyId/accessKeySecret para llamar a la API backend, admite el envío de tareas (MP3/MP4/texto→video) y la consulta de resultados de tareas (orderNo); no conserva datos comerciales en este repositorio; credenciales utilizadas sólo durante el proceso para los encabezados de solicitud; datos enviados al backend configurado por el usuario.
