Herramienta CLI de generación humana digital, llama a la API backend con accessKeyId/accessKeySecret, admite el envío de tareas (MP3/MP4/texto→video) y la consulta de resultados de tareas (orderNo); no conserva datos comerciales en este repositorio; las credenciales se utilizan sólo durante el proceso para los encabezados de solicitud; los datos se envían al backend configurado por el usuario.
