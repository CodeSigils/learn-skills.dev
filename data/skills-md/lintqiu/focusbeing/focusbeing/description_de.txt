Digitales CLI-Tool für die menschliche Generation, verwendet accessKeyId/accessKeySecret zum Aufrufen der Backend-API, unterstützt das Senden von Aufgaben (MP3/MP4/Text→Video) und das Abfragen von Aufgabenergebnissen (orderNo); speichert keine Geschäftsdaten in diesem Repo; Anmeldeinformationen werden nur prozessintern in Anforderungsheadern verwendet. Daten werden an das vom Benutzer konfigurierte Backend gesendet.
