Digitales CLI-Tool zur menschlichen Generierung, ruft die Backend-API mit accessKeyId/accessKeySecret auf, unterstützt das Senden von Aufgaben (MP3/MP4/Text→Video) und das Abfragen von Aufgabenergebnissen (orderNo); speichert keine Geschäftsdaten in diesem Repository; Anmeldeinformationen werden nur prozessintern für Anforderungsheader verwendet. Die Daten werden an das vom Benutzer konfigurierte Backend gesendet.
