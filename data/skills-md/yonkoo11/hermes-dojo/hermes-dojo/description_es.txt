Sistema de superación continua para Hermes Agent. Analiza sus sesiones pasadas para encontrar fallas recurrentes y brechas de habilidades, luego crea o parchea automáticamente habilidades y ejecuta la autoevolución para solucionarlas. Configúrelo para que se ejecute durante la noche y despierte con un mejor agente. Utilice /dojo para comenzar.
