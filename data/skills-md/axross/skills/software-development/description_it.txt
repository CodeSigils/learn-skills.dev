Every task that touches a project — implementing, refactoring, running a project command, or writing a pull request body. La disciplina di base al di sotto delle competenze specializzate: mantenere l'ambito della modifica, eseguire il ciclo di formato e lanugine, mappare ciò che il cambiamento mette a rischio e scoprire come viene effettivamente gestito il progetto. Si applica anche quando la richiesta non menziona mai formattazione, linting, commenti, dipendenze, documenti o descrizioni e quando hai bisogno di una delle operazioni del progetto (test, server di sviluppo, compilazione, lint, distribuzione) e devi trovarla documentata o chiedere. Not for a session that touches nothing, where the conduct baseline applies instead.
