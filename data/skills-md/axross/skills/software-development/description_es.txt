Cada tarea relacionada con un proyecto: implementar, refactorizar, ejecutar un comando de proyecto o escribir el cuerpo de una solicitud de extracción. La disciplina básica subyacente a las habilidades especializadas: mantener el alcance del cambio, ejecutar el formato y el bucle de pelusa, mapear lo que el cambio pone en riesgo y descubrir cómo se ejecuta realmente el proyecto. Se aplica incluso cuando la solicitud nunca menciona formato, linting, comentarios, dependencias, documentos o descripciones, y cuando necesita una de las operaciones del proyecto (pruebas, servidor de desarrollo, compilación, lint, implementación) y debe encontrarla documentada o preguntar. No para una sesión que no toca nada, donde en cambio se aplica la línea de base de conducta.
