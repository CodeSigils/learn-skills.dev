رسم بياني للمعرفة الشخصية للوكيل يتم تخزينه كملفات تخفيض السعر باستخدام YAML frontmatter. استخدمه عندما تحتاج إلى سياق مستمر حول حياة المستخدم أو مشاريعه أو أدواته أو أشخاصه أو مفاهيمه أو قراراته - خاصة عبر عمليات إعادة تعيين الوكيل أو التبديل. يُستخدم أيضًا عند تسجيل نشاط مهم، أو البحث عن السياق قبل بدء العمل، أو إنشاء عقد معرفة لموضوعات جديدة، أو اكتشاف الاتصالات بين العقد الموجودة (الملء)، أو إعادة بناء الفهارس. تتضمن المشغلات الحاجة إلى سياق المستخدم، وتسجيل العمل، و"تذكر هذا"، و"ماذا أعرف عن X"، وإنشاء/تحديث إدخالات المعرفة، وصيانة الذاكرة بشكل دوري.
