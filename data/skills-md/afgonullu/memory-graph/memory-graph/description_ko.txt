YAML 프론트매터와 함께 마크다운 파일로 저장된 에이전트 독립적 개인 지식 그래프입니다. 특히 에이전트 재설정이나 전환 전반에 걸쳐 사용자의 생활, 프로젝트, 도구, 사람, 개념 또는 결정에 대한 지속적인 컨텍스트가 필요할 때 사용합니다. 또한 중요한 활동을 기록하고, 작업을 시작하기 전에 컨텍스트를 검색하고, 새로운 주제에 대한 지식 노드를 생성하고, 기존 노드 간의 연결을 검색하거나(백필) 인덱스를 다시 작성하는 경우에도 사용합니다. 트리거에는 사용자 컨텍스트 필요, 작업 로깅, "기억하기", "X에 대해 내가 아는 것", 지식 항목 생성/업데이트 및 주기적인 메모리 유지 관리가 포함됩니다.
