Grafico della conoscenza personale indipendente dall'agente archiviato come file di markdown con frontmatter YAML. Utilizzalo quando hai bisogno di un contesto persistente sulla vita, i progetti, gli strumenti, le persone, i concetti o le decisioni dell'utente, in particolare durante il ripristino o il cambio dell'agente. Utilizzare anche per registrare attività significative, cercare contesto prima di iniziare il lavoro, creare nodi di conoscenza per nuovi argomenti, scoprire connessioni tra nodi esistenti (backfill) o ricostruire indici. I trigger includono la necessità del contesto utente, la registrazione del lavoro, "ricorda questo", "cosa so di X", la creazione/aggiornamento di voci di conoscenza e la manutenzione periodica della memoria.
