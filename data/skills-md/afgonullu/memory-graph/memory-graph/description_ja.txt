エージェントに依存しない個人のナレッジ グラフは、YAML フロントマターを使用してマークダウン ファイルとして保存されます。ユーザーの生活、プロジェクト、ツール、人々、概念、意思決定に関する永続的なコンテキストが必要な場合、特にエージェントのリセットまたは切り替えの際に使用します。また、重要なアクティビティのログ記録、作業開始前のコンテキストの検索、新しいトピックのナレッジ ノードの作成、既存のノード間の接続の検出 (バックフィル)、またはインデックスの再構築にも使用します。トリガーには、ユーザー コンテキストの必要性、作業のログ記録、「これを覚えておいてください」、「X について何を知っていますか」、ナレッジ エントリの作成/更新、および定期的なメモリのメンテナンスが含まれます。
