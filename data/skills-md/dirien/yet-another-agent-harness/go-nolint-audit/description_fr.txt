Auditez les directives Go Nolint pour l'obsolescence et les justifications paresseuses. Vérifie mécaniquement chaque suppression avec golangci-lint, puis lance des débats contradictoires Rouge/Bleu/Blanc sur les meilleurs candidats à la suppression. À utiliser lors de l'héritage d'une base de code Go, lors d'un nettoyage périodique ou lorsque le nombre de nolint augmente sans contrôle.
