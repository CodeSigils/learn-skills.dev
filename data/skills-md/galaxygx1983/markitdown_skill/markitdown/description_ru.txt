Инструмент преобразования документа в Markdown (markitdown). Используйте немедленно, когда пользователям необходимо преобразовать различные форматы файлов в Markdown (PDF/Word/Excel/PPT/изображение/аудио/HTML/CSV/JSON/XML/ZIP/видео YouTube/электронную книгу EPub в Markdown), выполнить распознавание текста с помощью Azure Document Intelligence, создать описания изображений с помощью LLM, преобразовать документы через CLI или Python API или обработать дополнительные подключаемые модули зависимостей. Установите с помощью pip install 'markitdown[all]', Python >= 3.10.
