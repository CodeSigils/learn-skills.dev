Outil de conversion de document en Markdown (markitdown). À utiliser immédiatement lorsque les utilisateurs ont besoin de convertir divers formats de fichiers en Markdown (PDF en Markdown / Word en Markdown / Excel en Markdown / PPT en Markdown / image en Markdown / audio en Markdown / HTML en Markdown / CSV en Markdown / JSON en Markdown / XML en Markdown / ZIP en Markdown / vidéo YouTube en Markdown / livre électronique EPub en Markdown), effectuer la reconnaissance OCR avec Azure Document Intelligence, générer des descriptions d'images avec LLM, convertir des documents via la ligne de commande CLI ou l'API Python, gérer en option plugins de dépendance et tâches associées. Prend en charge l'installation avec pip install 'markitdown[all]', Python >= 3.10.
