Herramienta de conversión de documento a Markdown (markitdown). Úselo inmediatamente cuando los usuarios necesiten convertir varios formatos de archivos a Markdown (PDF a Markdown / Word a Markdown / Excel a Markdown / PPT a Markdown / imagen a Markdown / audio a Markdown / HTML a Markdown / CSV a Markdown / JSON a Markdown / XML a Markdown / ZIP a Markdown / video de YouTube a Markdown / libro electrónico EPub a Markdown), realice reconocimiento OCR con Azure Document Intelligence, genere descripciones de imágenes con LLM, convierta documentos a través de la línea de comandos CLI o API de Python. manejar complementos de dependencia opcionales y tareas relacionadas. Admite la instalación con pip install 'markitdown[all]', Python >= 3.10.
