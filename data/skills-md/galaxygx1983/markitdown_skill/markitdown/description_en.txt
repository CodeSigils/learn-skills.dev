Document-to-Markdown conversion tool (markitdown). Use immediately when users need to convert various file formats to Markdown (PDF to Markdown / Word to Markdown / Excel to Markdown / PPT to Markdown / image to Markdown / audio to Markdown / HTML to Markdown / CSV to Markdown / JSON to Markdown / XML to Markdown / ZIP to Markdown / YouTube video to Markdown / EPub e-book to Markdown), perform OCR recognition with Azure Document Intelligence, generate image descriptions with LLM, convert documents via CLI command line or Python API, handle optional dependency plugins, and related tasks. Supports installation with pip install 'markitdown[all]', Python >= 3.10.
