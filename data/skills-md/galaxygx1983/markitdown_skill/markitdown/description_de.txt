Tool zur Konvertierung von Dokumenten in Markdown (Markitdown). Sofort verwenden, wenn Benutzer verschiedene Dateiformate in Markdown konvertieren müssen (PDF in Markdown / Word in Markdown / Excel in Markdown / PPT in Markdown / Bild in Markdown / Audio in Markdown / HTML in Markdown / CSV in Markdown / JSON in Markdown / XML in Markdown / ZIP in Markdown / YouTube-Video in Markdown / EPub-E-Book in Markdown), OCR-Erkennung mit Azure Document Intelligence durchführen, Bildbeschreibungen mit LLM generieren, Dokumente über die CLI-Befehlszeile oder die Python-API konvertieren, Behandeln Sie optionale Abhängigkeits-Plugins und damit verbundene Aufgaben. Unterstützt die Installation mit pip install 'markitdown[all]', Python >= 3.10.
