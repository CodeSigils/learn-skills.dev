문서를 마크다운으로 변환 도구(markitdown). 사용자가 다양한 파일 형식을 Markdown으로 변환(PDF를 Markdown으로 / Word를 Markdown으로 / Excel을 Markdown으로 / PPT를 Markdown으로 / 이미지를 Markdown으로 / audio를 Markdown으로 / HTML을 Markdown으로 / CSV를 Markdown으로 / JSON을 Markdown으로 / XML을 Markdown으로 / ZIP을 Markdown으로 / YouTube 비디오를 Markdown으로 / EPub 전자책을 Markdown으로), Azure Document Intelligence로 OCR 인식 수행, LLM으로 이미지 설명 생성, CLI 명령줄 또는 Python API를 통해 문서 변환, 선택적 종속성 처리가 필요할 때 즉시 사용하세요. 플러그인 및 관련 작업. pip install 'markitdown[all]', Python >= 3.10을 사용한 설치를 지원합니다.
