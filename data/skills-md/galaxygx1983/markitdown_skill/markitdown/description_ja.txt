ドキュメントからマークダウンへの変換ツール (markitdown)。ユーザーがさまざまなファイル形式を Markdown に変換する必要がある場合 (PDF から Markdown / Word から Markdown / Excel から Markdown / PPT から Markdown / 画像から Markdown / 音声から Markdown / HTML から Markdown / CSV から Markdown / JSON から Markdown / XML から Markdown / ZIP から Markdown / YouTube ビデオから Markdown / EPub 電子書籍から Markdown)、Azure Document Intelligence による OCR 認識の実行、LLM による画像説明の生成、CLI コマンド ラインによるドキュメントの変換が必要な場合にすぐに使用できます。 Python API、オプションの依存関係プラグイン、および関連タスクを処理します。 pip install 'markitdown[all]'、Python >= 3.10 によるインストールをサポートします。
