Strumento di conversione da documento a Markdown (markitdown). Utilizzalo immediatamente ogni volta che gli utenti devono convertire vari formati di file in Markdown (PDF in Markdown / Word in Markdown / Excel in Markdown / PPT in Markdown / immagine in Markdown / audio in Markdown / HTML in Markdown / CSV in Markdown / JSON in Markdown / XML in Markdown / ZIP in Markdown / video YouTube in Markdown / EPub e-book in Markdown), eseguire l'OCR con Azure Document Intelligence, generare descrizioni di immagini con LLM, convertire documenti tramite CLI o API Python o gestire opzioni facoltative plug-in di dipendenza. Installa con pip install 'markitdown[all]', Python >= 3.10.
