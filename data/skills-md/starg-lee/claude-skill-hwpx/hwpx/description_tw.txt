使用 Python 程式碼建立、讀取、編輯和轉換北韓文文檔 (.hwpx)。建立支援表格、儲存格合併、背景顏色、文字樣式、圖像、頁首/頁尾、頁碼和縱向/橫向頁面。讀取從現有 .hwp/.hwpx 檔案（不含朝鮮文）中提取正文和表格，並處理軌道變更（分離插入/刪除並提取前後版本）。編輯會取代模板 hwpx 檔案中的佔位符並新增表格行。轉換包括hwp→hwpx和→pdf/docx/md。當使用者要求諸如“輸出/保存/轉換/創建為 hwpx”、“製作 Hangul 文件/文檔”、“讀取/提取 hwp 內容”、“顯示更改跟踪/糾正內容”、“將 hwp 轉換為 hwpx”、“將內容填充到模板中”、“安排/會議要/表格到 hwp紀x”等操作時，會觸發該操作。 （需安裝 Windows + Hangul Office；讀取/編輯/部分轉換無需安裝韓文）。
