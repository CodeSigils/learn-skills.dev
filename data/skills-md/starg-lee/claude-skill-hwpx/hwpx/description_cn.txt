使用 Python 代码创建、读取、编辑和转换朝鲜文文档 (.hwpx)。创建支持表格、单元格合并、背景颜色、文本样式、图像、页眉/页脚、页码和纵向/横向页面。读取从现有 .hwp/.hwpx 文件（无需 Hangul 软件）中提取正文和表格，并处理轨道更改（插入/删除）并提取更改前和更改后版本。编辑包括替换模板 hwpx 中的占位符和添加表行。转换支持hwp→hwpx，然后到pdf/docx/md。当用户请求“输出/保存/转换/制作为 hwpx”、“制作朝鲜文文件/文档”、“读取/提取 hwp 内容”、“显示更改详细信息/跟踪更改/纠正内容”、“将 hwp 转换为 hwpx”、“将内容填充到模板中”、“创建时间表/分钟/表为 hwpx”等时，会触发该功能。（需要安装 Windows 和 Hangul Office；读取/编辑/部分转换无需韩文即可工作）。
