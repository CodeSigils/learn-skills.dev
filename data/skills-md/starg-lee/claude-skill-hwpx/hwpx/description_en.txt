Create, read, edit, and convert Hangul documents (.hwpx) using Python code. Creation supports tables, cell merging, background colors, text styling, images, headers/footers, page numbers, and portrait/landscape pages. Reading extracts body text and tables from existing .hwp/.hwpx files (without Hangul software) and handles track changes (insertions/deletions) and extracts pre‑ and post‑change versions. Editing includes replacing placeholders in a template hwpx and adding table rows. Conversion supports hwp → hwpx, then to pdf/docx/md. The functionality is triggered when the user requests things like “output/save/convert/make as hwpx”, “make a Hangul file/document”, “read/extract hwp content”, “show change details/track changes/what was corrected”, “convert hwp to hwpx”, “fill content into a template”, “create a timetable/minutes/table as hwpx”, etc. (Requires Windows and Hangul Office installed; reading/editing/partial conversion works without Hangul).
