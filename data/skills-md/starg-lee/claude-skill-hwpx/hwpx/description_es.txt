Cree, lea, edite y convierta documentos Hangul (.hwpx) con código Python. La creación admite tablas, combinación de celdas, color de fondo, estilo de fuente, imágenes, encabezados/pies de página, números de página y páginas horizontales/verticales. La lectura extrae el texto del cuerpo y las tablas de archivos .hwp/.hwpx existentes (sin Hancom) y maneja el seguimiento de cambios (insertar/eliminar modificaciones) y extrae versiones anteriores y posteriores. La edición incluye reemplazar marcadores de posición en archivos de plantilla hwpx y agregar filas de tabla. La conversión admite hwp → hwpx y pdf/docx/md. Se activa cuando un usuario solicita acciones como "generar/guardar/convertir/crear como hwpx", "crear un archivo/documento Hangul", "leer/extraer contenido de hwp", "mostrar detalles de cambios/seguimiento de cambios/lo que se corrigió", "convertir hwp a hwpx", "rellenar plantilla con contenido", "hacer programación/minutos/tabla como hwpx", etc. (Requiere instalación de Windows + Hancom Office; la lectura/edición/conversión parcial funciona sin Hancom).
