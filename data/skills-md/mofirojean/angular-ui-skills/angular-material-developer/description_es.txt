Genera código de Angular Material y orientación para proyectos de Angular utilizando `@angular/material` con el sistema de temas Material 3 (M3). Cubre la instalación, temas basados ​​en Sass a través de `mat.theme()` y las paletas prediseñadas, personalización de densidad y tipografía, uso de componentes en todas las categorías (controles de formulario, botones, superposiciones, diseño, visualización de datos, navegación), primitivas `@angular/cdk` (Superposición, Portal, Arrastrar y soltar, Desplazamiento virtual, A11y), integración de ReactiveForms/Signal Forms a través de `mat-form-field`, accesibilidad y migración M2 → M3. Úselo cuando el usuario mencione Angular Material, `@angular/material`, componentes `mat-*`, M3/Material 3, tokens de diseño, O cuando el `package.json` del proyecto Angular contenga `@angular/material`. Se combina con "angular-developer" para los fundamentos de Angular.
