يُنشئ كود Angular Material وإرشادات لمشاريع Angular باستخدام `@angular/material` مع نظام السمات Material 3 (M3). يغطي التثبيت، والسمات المستندة إلى Sass عبر `mat.theme()` واللوحات المعدة مسبقًا، وتخصيص الكثافة والطباعة، واستخدام المكونات عبر جميع الفئات (عناصر التحكم في النماذج، والأزرار، والتراكبات، والتخطيط، وعرض البيانات، والتنقل)، والأولويات `@angular/cdk` (Overlay، Portal، Drag-Drop، Virtual Scroll، A11y)، تكامل ReactiveForms / Signal Forms عبر `mat-form-field`، إمكانية الوصول، والهجرة M2 → M3. يُستخدم عندما يذكر المستخدم Angular Material، أو `@angular/material`، أو `mat-*`، أو M3 / Material 3، أو الرموز المميزة للتصميم، أو عندما يحتوي `package.json` الخاص بالمشروع Angular على `@angular/material`. أزواج مع "المطور الزاوي" للأساسيات الزاويّة.
