Génère du code Angular Material et des conseils pour les projets Angular en utilisant `@angular/material` avec le système de thème Material 3 (M3). Couvre l'installation, la thématique basée sur Sass via `mat.theme()` et les palettes prédéfinies, la personnalisation de la densité et de la typographie, l'utilisation des composants dans toutes les catégories (contrôles de formulaire, boutons, superpositions, mise en page, affichage des données, navigation), les primitives `@angular/cdk` (Overlay, Portal, Drag-Drop, Virtual Scroll, A11y), l'intégration de ReactiveForms / Signal Forms via `mat-form-field`, l'accessibilité et la migration M2 → M3. À utiliser lorsque l'utilisateur mentionne Angular Material, `@angular/material`, les composants `mat-*`, M3 / Material 3, les jetons de conception, OU lorsque le `package.json` du projet Angular contient `@angular/material`. S'associe à « angular-developer » pour les principes fondamentaux d'Angular.
