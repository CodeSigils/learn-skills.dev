マテリアル 3 (M3) テーマ システムで `@angular/material` を使用して、Angular プロジェクトの Angular マテリアル コードとガイダンスを生成します。インストール、`mat.theme()` および事前構築済みパレットによる Sass ベースのテーマ設定、密度とタイポグラフィーのカスタマイズ、すべてのカテゴリにわたるコンポーネントの使用法 (フォーム コントロール、ボタン、オーバーレイ、レイアウト、データ表示、ナビゲーション)、`@angular/cdk` プリミティブ (オーバーレイ、ポータル、ドラッグ ドロップ、仮想スクロール、A11y)、`mat-form-field` による ReactiveForms / Signal Forms の統合をカバーします。アクセシビリティ、および M2 → M3 への移行。ユーザーが Angular マテリアル、`@angular/material`、`mat-*` コンポーネント、M3 / マテリアル 3、デザイン トークンに言及する場合、または Angular プロジェクトの `package.json` に `@angular/material` が含まれる場合に使用します。 Angular の基礎については「angular-developer」と組み合わせます。
