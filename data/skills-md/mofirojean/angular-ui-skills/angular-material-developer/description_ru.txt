Генерирует код Angular Material и руководство для проектов Angular, используя @angular/material с системой тем Material 3 (M3). Охватывает установку, оформление тем на основе Sass через `mat.theme()` и готовые палитры, настройку плотности и типографики, использование компонентов во всех категориях (элементы управления формами, кнопки, наложения, макет, отображение данных, навигация), примитивы `@angular/cdk` (Overlay, Portal, Drag-Drop, Virtual Scroll, A11y), интеграцию ReactiveForms / Signal Forms через `mat-form-field`, специальные возможности и M2 → M3. миграция. Используйте, когда пользователь упоминает Angular Material, `@angular/material`, компоненты `mat-*`, M3/Material 3, токены дизайна, ИЛИ когда `package.json` проекта Angular содержит `@angular/material`. Сочетается с angular-developer для изучения основ Angular.
