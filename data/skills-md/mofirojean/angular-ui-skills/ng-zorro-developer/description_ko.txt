'ng-zorro-antd'를 사용하여 Angular 프로젝트에 대한 NG-ZORRO 코드 및 지침을 생성합니다. 설치, LESS 변수 테마 지정(기본값, 어두운 색, 컴팩트, aliyun 사전 설정), 실험적인 동적 CSS 변수 테마, 모든 범주에 걸친 구성 요소 사용(일반, 레이아웃, 탐색, 데이터 입력, 데이터 표시, 피드백), `nz-form`을 통한 ReactiveForms/Signal Forms 통합, 국제화(`provideNzI18n`), 접근성 및 모듈 → 독립 실행형 마이그레이션을 다룹니다. 사용자가 NG-ZORRO, ng-zorro, ng-zorro-antd, Ant Design for Angular, `nz-*` 구성 요소, `Nz*Module`을 언급할 때 또는 Angular 프로젝트의 `package.json`에 `ng-zorro-antd`가 포함된 경우에 사용합니다. Angular 기본 사항을 위해 'angular-developer'와 쌍을 이룹니다.
