Génère du code NG-ZORRO et des conseils pour les projets angulaires à l'aide de `ng-zorro-antd`. Couvre l'installation, la thématique des variables LESS (préréglages par défaut, sombres, compacts, aliyun), le thème dynamique expérimental des variables CSS, l'utilisation des composants dans toutes les catégories (général, mise en page, navigation, saisie de données, affichage des données, commentaires), l'intégration de ReactiveForms / Signal Forms via `nz-form`, l'internationalisation (`provideNzI18n`), l'accessibilité et le module → migration autonome. À utiliser lorsque l'utilisateur mentionne NG-ZORRO, ng-zorro, ng-zorro-antd, Ant Design for Angular, les composants `nz-*`, `Nz*Module`, OU lorsque le `package.json` du projet Angular contient `ng-zorro-antd`. S'associe à « angular-developer » pour les principes fondamentaux d'Angular.
