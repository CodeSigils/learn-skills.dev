使用“ng-zorro-antd”為 Angular 專案產生 NG-ZORRO 程式碼和指南。涵蓋安裝、LESS 變數主題（預設、深色、緊湊、阿里雲預設）、實驗性動態 CSS 變數主題、所有類別的元件使用（常規、佈局、導航、資料輸入、資料顯示、回饋）、透過 `nz-form` 進行 ReactiveForms / Signal Forms 整合、國際化 (`provideNzI18n`)、可存取性和模組。當使用者提及 NG-ZORRO、ng-zorro、ng-zorro-antd、Ant Design for Angular、`nz-*` 元件、`Nz*Module` 時使用，或當 Angular 專案的 `package.json` 包含 `ng-zorro-antd` 時使用。與 Angular 基礎知識的“Angular-Developer”配對。
