使用“ng-zorro-antd”为 Angular 项目生成 NG-ZORRO 代码和指南。涵盖安装、LESS 变量主题（默认、深色、紧凑、阿里云预设）、实验性动态 CSS 变量主题、所有类别的组件使用（常规、布局、导航、数据输入、数据显示、反馈）、通过 `nz-form` 进行 ReactiveForms / Signal Forms 集成、国际化 (`provideNzI18n`)、可访问性和模块 → 独立迁移。当用户提及 NG-ZORRO、ng-zorro、ng-zorro-antd、Ant Design for Angular、`nz-*` 组件、`Nz*Module` 时使用，或者当 Angular 项目的 `package.json` 包含 `ng-zorro-antd` 时使用。与 Angular 基础知识的“Angular-Developer”配对。
