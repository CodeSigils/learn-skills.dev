「ng-zorro-antd」を使用して、Angular プロジェクトの NG-ZORRO コードとガイダンスを生成します。インストール、LESS 変数テーマ (デフォルト、ダーク、コンパクト、aliyun プリセット)、実験的な動的 CSS 変数テーマ、すべてのカテゴリにわたるコンポーネントの使用法 (一般、レイアウト、ナビゲーション、データ入力、データ表示、フィードバック)、`nz-form` による ReactiveForms / Signal Forms の統合、国際化 (`provideNzI18n`)、アクセシビリティ、およびモジュール→スタンドアロン移行について説明します。ユーザーが NG-ZORRO、ng-zorro、ng-zorro-antd、Ant Design for Angular、`nz-*` コンポーネント、`Nz*Module` に言及する場合、または Angular プロジェクトの `package.json` に `ng-zorro-antd` が含まれる場合に使用します。 Angular の基礎については「angular-developer」と組み合わせます。
