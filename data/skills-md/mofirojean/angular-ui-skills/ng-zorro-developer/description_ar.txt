يُنشئ كود NG-ZORRO وإرشادات لمشاريع Angular باستخدام ng-zorro-antd. يغطي التثبيت والسمات ذات المتغير الأقل (افتراضي، داكن، مضغوط، إعدادات مسبقة Aliyun)، سمة CSS الديناميكية التجريبية المتغيرة، استخدام المكونات عبر جميع الفئات (عام، تخطيط، تنقل، إدخال البيانات، عرض البيانات، التعليقات)، تكامل ReactiveForms / Signal Forms عبر `nz-form`، والتدويل (`provideNzI18n`)، وإمكانية الوصول، والوحدة النمطية → الترحيل المستقل. يُستخدم عندما يذكر المستخدم NG-ZORRO، وng-zorro، وng-zorro-antd، وAnt Design for Angular، ومكونات `nz-*`، و`Nz*Module`، أو عندما يحتوي `package.json` الخاص بالمشروع Angular على ng-zorro-antd. أزواج مع "المطور الزاوي" للأساسيات الزاويّة.
