Genera código NG-ZORRO y guía para proyectos Angular usando `ng-zorro-antd`. Cubre la instalación, temas con MENOS variables (predeterminado, oscuro, compacto, ajustes preestablecidos de aliyun), el tema dinámico experimental de variables CSS, uso de componentes en todas las categorías (general, diseño, navegación, entrada de datos, visualización de datos, retroalimentación), integración de ReactiveForms/Signal Forms a través de `nz-form`, internacionalización (`provideNzI18n`), accesibilidad y el módulo → migración independiente. Úselo cuando el usuario mencione NG-ZORRO, ng-zorro, ng-zorro-antd, Ant Design for Angular, componentes `nz-*`, `Nz*Module`, O cuando el `package.json` del proyecto Angular contenga `ng-zorro-antd`. Se combina con "angular-developer" para los fundamentos de Angular.
