Генерирует код NG-ZORRO и руководство для проектов Angular с использованием ng-zorro-antd. Охватывает установку, тематизацию с переменными LESS (предустановки по умолчанию, темная, компактная, aliyun), экспериментальную динамическую тему с переменными CSS, использование компонентов во всех категориях (общие, макет, навигация, ввод данных, отображение данных, обратная связь), интеграцию ReactiveForms / Signal Forms через nz-form, интернационализацию (provideNzI18n), специальные возможности и модуль → автономную миграцию. Используйте, когда пользователь упоминает NG-ZORRO, ng-zorro, ng-zorro-antd, Ant Design for Angular, компоненты `nz-*`, `Nz*Module`, ИЛИ когда `package.json` проекта Angular содержит `ng-zorro-antd`. Сочетается с angular-developer для изучения основ Angular.
