使用“primeng”和“@primeuix/themes”和“@primeuix/styles”為 Angular 專案產生 PrimeNG 代碼和指南。涵蓋安裝、設計令牌主題（Aura / Lara / Nora / Material 預設）、Styled 與 Unstyled 模式、PassThrough (`pt`) 自訂 API、跨所有類別的元件使用（表單控制項、按鈕、覆蓋、佈局、資料顯示、顯示、功能表）、ReactiveForms / Signal Forms 整合、可存取性、佈局、資料顯示、顯示、功能表）、ReactiveForms / Signal Forms 1821/ Signal Forms 18、可訪問性。當使用者提到 PrimeNG、`primeng`、`p-*` 組件、Aura/Lara/Nora 主題預設時使用，或當 Angular 項目的 `package.json` 包含 `primeng` 或 `@primeuix/*` 依賴項時使用。與 Angular 基礎知識的“Angular-Developer”配對。
