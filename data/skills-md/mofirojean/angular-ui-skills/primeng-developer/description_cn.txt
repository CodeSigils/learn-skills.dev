使用“primeng”和“@primeuix/themes”和“@primeuix/styles”为 Angular 项目生成 PrimeNG 代码和指南。涵盖安装、设计令牌主题（Aura / Lara / Nora / Material 预设）、Styled 与 Unstyled 模式、PassThrough (`pt`) 自定义 API、跨所有类别的组件使用（表单控件、按钮、覆盖、布局、数据显示、显示、菜单）、ReactiveForms / Signal Forms 集成、可访问性以及 v18→v21 迁移重命名。当用户提到 PrimeNG、`primeng`、`p-*` 组件、Aura/Lara/Nora 主题预设时使用，或者当 Angular 项目的 `package.json` 包含 `primeng` 或 `@primeuix/*` 依赖项时使用。与 Angular 基础知识的“Angular-Developer”配对。
