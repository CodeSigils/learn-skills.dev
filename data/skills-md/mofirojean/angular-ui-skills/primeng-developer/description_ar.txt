يُنشئ كود PrimeNG وإرشادات لمشاريع Angular باستخدام `primeng` مع `@primeuix/themes` و`@primeuix/styles`. يغطي التثبيت، وميزات التصميم المميزة (Aura / Lara / Nora / الإعدادات المسبقة للمواد)، والأوضاع Styled vs Unstyled، وواجهة برمجة تطبيقات التخصيص PassThrough (`pt`)، واستخدام المكونات عبر جميع الفئات (عناصر التحكم في النماذج، والأزرار، والتراكبات، والتخطيط، وعرض البيانات، والعرض، والقوائم)، وتكامل ReactiveForms / Signal Forms، وإمكانية الوصول، وإعادة تسمية ترحيل v18 → v21. يُستخدم عندما يذكر المستخدم مكونات PrimeNG و`primeng` و`p-*` والإعدادات المسبقة لموضوع Aura/Lara/Nora، أو عندما يحتوي `package.json` الخاص بالمشروع Angular على تبعيات `primeng` أو `@primeuix/*`. أزواج مع "المطور الزاوي" للأساسيات الزاويّة.
