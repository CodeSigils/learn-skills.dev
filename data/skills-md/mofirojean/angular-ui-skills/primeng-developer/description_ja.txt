`primeng` と `@primeuix/themes` および `@primeuix/styles` を使用して、Angular プロジェクトの PrimeNG コードとガイダンスを生成します。インストール、デザイン トークン テーマ (Aura / Lara / Nora / マテリアル プリセット)、スタイル モードとスタイルなしモード、パススルー (「pt」) カスタマイズ API、すべてのカテゴリにわたるコンポーネントの使用法 (フォーム コントロール、ボタン、オーバーレイ、レイアウト、データ表示、ディスプレイ、メニュー)、ReactiveForms / Signal Forms の統合、アクセシビリティ、v18→v21 移行の名前変更について説明します。ユーザーが PrimeNG、`primeng`、`p-*` コンポーネント、Aura/Lara/Nora テーマのプリセットに言及する場合、または Angular プロジェクトの `package.json` に `primeng` または `@primeuix/*` の依存関係が含まれる場合に使用します。 Angular の基礎については「angular-developer」と組み合わせます。
