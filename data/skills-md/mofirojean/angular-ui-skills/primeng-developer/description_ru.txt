Генерирует код PrimeNG и руководство для проектов Angular, используя primeng с @primeuix/themes и @primeuix/styles. Охватывает установку, оформление тем дизайна (пресеты Aura / Lara / Nora / Material), режимы Styled и Unstyled, API настройки PassThrough («pt»), использование компонентов во всех категориях (элементы управления формами, кнопки, наложения, макет, отображение данных, отображение, меню), интеграцию ReactiveForms / Signal Forms, специальные возможности и переименования миграции v18 → v21. Используйте, когда пользователь упоминает компоненты PrimeNG, `primeng`, `p-*`, пресеты тем Aura/Lara/Nora ИЛИ когда `package.json` проекта Angular содержит зависимости `primeng` или `@primeuix/*`. Сочетается с angular-developer для изучения основ Angular.
