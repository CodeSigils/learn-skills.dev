Génère du code PrimeNG et des conseils pour les projets Angular en utilisant `primeng` avec `@primeuix/themes` et `@primeuix/styles`. Couvre l'installation, la thématique des jetons de conception (préréglages Aura / Lara / Nora / Material), les modes Styled vs Unstyled, l'API de personnalisation PassThrough (`pt`), l'utilisation des composants dans toutes les catégories (contrôles de formulaire, boutons, superpositions, mise en page, affichage des données, affichage, menus), l'intégration de ReactiveForms / Signal Forms, l'accessibilité et les renommages de migration v18 → v21. À utiliser lorsque l'utilisateur mentionne les composants PrimeNG, `primeng`, `p-*`, les préréglages de thème Aura/Lara/Nora, OU lorsque le `package.json` du projet Angular contient des dépendances `primeng` ou `@primeuix/*`. S'associe à « angular-developer » pour les principes fondamentaux d'Angular.
