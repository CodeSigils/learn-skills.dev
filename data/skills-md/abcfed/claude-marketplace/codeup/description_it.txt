Set di strumenti per la gestione del repository di codici Aliyun Cloud Efficiency Codeup. I casi d'uso includono: (1) Operazioni del repository di codici: gestione delle filiali, operazioni sui file, confronto dei codici, richiesta di unione/gestione MR (2) Gestione dell'organizzazione: gestione dei dipartimenti, ricerca dei membri, gestione dei ruoli (3) Utilizzo di repository Codeup, filiali, MR, richieste di unione (4) Membri dell'organizzazione ed elenchi di dipartimenti di Query Cloud Efficiency.
