Ensemble d'outils de gestion du référentiel de code Alibaba Cloud CloudEffect Codeup. Les scénarios d'utilisation incluent : (1) Opérations de référentiel de code – gestion des branches, opérations de fichiers, comparaison de code, gestion des demandes de fusion/MR (2) Gestion de l'organisation – gestion des départements, recherche de membres, gestion des rôles (3) Exploiter les référentiels Codeup, les branches, les MR, les demandes de fusion (4) Interroger les membres de l'organisation et les listes de départements Codeup.
