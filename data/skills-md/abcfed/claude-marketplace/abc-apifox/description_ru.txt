Инструмент запроса документации ABC Medical Cloud API. Считывает и запрашивает спецификацию OpenAPI ABC API (более 5000 конечных точек), поддерживая поиск по модулю, пути и методу с автоматическим разрешением $ref. Использует структуру кэширования с разделением модулей для быстрых запросов. Варианты использования: (1) запрос определений конечных точек API (2) поиск конечных точек конкретных функций (3) запрос определений схемы (4) просмотр статистики конечных точек
