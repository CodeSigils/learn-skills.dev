Инструмент запроса документации ABC Medical Cloud API. Считывает и запрашивает документы спецификации ABC API OpenAPI (более 5000 конечных точек), поддерживает поиск по модулю, пути и методу, а также автоматически разрешает ссылки $ref. Он использует структуру кэширования с разделением модулей для обеспечения высокой скорости запросов. Варианты использования: (1) Определения конечных точек API запросов (2) Поиск конкретных функциональных конечных точек (3) Определения схем запросов (4) Просмотр статистики конечных точек.
