Strumento di query sulla documentazione dell'API ABC Medical Cloud. Legge ed esegue query sui documenti delle specifiche OpenAPI dell'API ABC (oltre 5000 endpoint), supporta la ricerca per modulo, percorso e metodo e risolve automaticamente i riferimenti $ref. Utilizza una struttura della cache divisa per modulo per una maggiore velocità delle query. Casi d'uso: (1) Query sulle definizioni degli endpoint API (2) Ricerca di endpoint funzionali specifici (3) Query sulle definizioni dello schema (4) Visualizzazione delle statistiche degli endpoint.
