Strumento di query sulla documentazione API di ABC Medical Cloud. Legge ed esegue query sui documenti delle specifiche OpenAPI dell'API ABC (oltre 5000 endpoint), supporta la ricerca per modulo, percorso e metodo e risolve automaticamente i riferimenti $ref. Utilizza una struttura di memorizzazione nella cache suddivisa in moduli per una velocità di query elevata. Casi d'uso: (1) Query sulle definizioni degli endpoint API (2) Ricerca di endpoint funzionali specifici (3) Definizioni degli schemi di query (4) Visualizzazione delle statistiche degli endpoint.
