Strumento di query sulla documentazione API di ABC Medical Cloud. Legge ed esegue query sulla specifica OpenAPI dell'API ABC (oltre 5.000 endpoint), supportando ricerche per modulo, percorso e metodo, con risoluzione automatica $ref. Utilizza una struttura di memorizzazione nella cache suddivisa in moduli per query veloci. Casi d'uso: (1) eseguire query sulle definizioni degli endpoint API (2) cercare endpoint con funzioni specifiche (3) eseguire query sulle definizioni degli schemi (4) visualizzare le statistiche degli endpoint
