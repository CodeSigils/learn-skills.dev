مهارة نشر مشروع ABC Jenkins. يدعم الاستدلال الذكي للمعلمات والتشغيل التفاعلي لبنيات Jenkins، واسترداد معلومات فرع Git ومعلومات العلامة تلقائيًا. يتم تشغيل هذه المهارة عندما يطلب المستخدم "نشر Jenkins" أو "إنشاء المشغل" أو "نشر المشروع" أو "نشر Jenkins" أو إجراءات مماثلة. يتطلب متغيرات البيئة JENKINS_USER وJENKINS_TOKEN.
