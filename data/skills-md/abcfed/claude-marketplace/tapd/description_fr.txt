Intégration de la plateforme de gestion du développement agile TAPD. Utilisez des scripts pour appeler l'API TAPD afin de gérer des entités telles que les exigences, les défauts, les tâches, les itérations, les scénarios de test et le wiki. Les cas d'utilisation incluent : (1) interroger/créer/mettre à jour les exigences, les défauts, les tâches, les itérations (2) gérer les cas de test et le wiki (3) gérer les commentaires et les heures de travail (4) associer les exigences aux défauts (5) récupérer les mots-clés de validation du code source.
