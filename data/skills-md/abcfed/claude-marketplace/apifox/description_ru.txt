Инструмент запроса документации ABC Medical Cloud API. Считывает и запрашивает спецификацию OpenAPI ABC API (4209 конечных точек), поддерживает поиск по модулю, пути и методу, а также автоматически разрешает ссылки $ref. Варианты использования: (1) Определения конечных точек API запросов (2) Поиск конечных точек с определенной функциональностью (3) Экспорт сводки документации по конечным точкам (4) Просмотр статистики конечных точек
