Инструмент запроса документации ABC Medical Cloud API. Считывает и запрашивает документы спецификации OpenAPI ABC API (4209 конечных точек), поддерживает поиск по модулю, пути и методу, а также автоматически разрешает ссылки $ref. Варианты использования: (1) Определения конечных точек API запросов (2) Поиск конкретных функциональных конечных точек (3) Экспорт сводки документации API (4) Просмотр статистики API.
