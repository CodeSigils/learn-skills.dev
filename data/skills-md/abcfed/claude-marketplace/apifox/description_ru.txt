Инструмент запроса документации ABC Medical Cloud API. Считывает и запрашивает документы спецификации OpenAPI API ABC (4209 конечных точек), поддерживает поиск по модулю, пути и методу, а также автоматически разрешает ссылки $ref. Варианты использования: (1) Определения интерфейсов API запросов (2) Поиск конкретных функциональных интерфейсов (3) Экспорт сводной документации API (4) Просмотр статистики интерфейса.
