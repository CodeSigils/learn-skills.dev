Strumento di query sulla documentazione API di ABC Medical Cloud. Legge ed esegue query sui documenti delle specifiche OpenAPI dell'API ABC (4.209 endpoint), supporta la ricerca per modulo, percorso e metodo e risolve automaticamente i riferimenti $ref. Casi d'uso: (1) Eseguire query sulle definizioni degli endpoint API (2) Cercare endpoint funzionali specifici (3) Esportare riepiloghi della documentazione API (4) Visualizzare statistiche API.
