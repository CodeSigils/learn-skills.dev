OpenHarmony PR 전체 수명주기 워크플로. 5가지 모드:
- 커밋: DCO 승인 및 문제 연결을 통한 표준화된 커밋
- PR 생성: 커밋 + 포크로 푸시 + 이슈 생성 + 업스트림에서 PR 생성
- Codecheck 수정: PR에서 게이트 CI 코드 검사 결함을 가져와 자동 수정합니다.
- PR 검토: 코드 검토를 위해 PR의 변경 사항을 로컬로 가져옵니다.
- 수정 검토: PR에서 해결되지 않은 검토 의견을 가져와 자동 수정합니다.
