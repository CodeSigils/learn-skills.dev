OpenHarmony PR 完整生命周期工作流程。五种模式：
- 提交：带有 DCO 签核和问题链接的标准化提交
- 创建 PR：提交 + 推送到 fork + 创建问题 + 在上游创建 PR
- 修复代码检查：从 PR 中获取门 CI 代码检查缺陷并自动修复它们
- 审查 PR：将 PR 的更改获取到本地以进行代码审查
- 修复评论：从 PR 中获取未解决的评论评论并自动修复它们
