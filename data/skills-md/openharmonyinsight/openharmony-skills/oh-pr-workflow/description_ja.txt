OpenHarmony PR の全ライフサイクル ワークフロー。 5つのモード:
- コミット: DCO サインオフと問題リンクを備えた標準化されたコミット
- PR の作成: コミット + フォークへのプッシュ + 問題の作成 + 上流で PR を作成
- コードチェックを修正: ゲート CI コードチェックの欠陥を PR から取得し、自動修正します
- PR のレビュー: コード レビューのために PR の変更をローカルにフェッチします。
- レビューの修正: PR から未解決のレビュー コメントを取得し、自動修正します。
