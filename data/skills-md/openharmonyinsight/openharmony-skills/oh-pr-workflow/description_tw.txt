OpenHarmony PR 完整生命週期工作流程。五種模式：
- 提交：帶有 DCO 簽核和問題連結的標準化提交
- 建立 PR：提交 + 推送到 fork + 建立問題 + 在上游建立 PR
- 修復程式碼檢查：從 PR 中取得門 CI 程式碼檢查缺陷並自動修復它們
- 審查 PR：將 PR 的變更獲取到本地以進行程式碼審查
- 修復評論：從 PR 中獲取未解決的評論評論並自動修復它們
