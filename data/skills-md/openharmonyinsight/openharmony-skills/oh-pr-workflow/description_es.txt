Flujo de trabajo del ciclo de vida completo de OpenHarmony PR. Cinco modos:
- Compromiso: compromiso estandarizado con aprobación de DCO y vinculación de problemas
- Crear relaciones públicas: confirmar + empujar a la bifurcación + crear problema + crear relaciones públicas en sentido ascendente
- Reparar Codecheck: recupera los defectos de verificación del código CI de la puerta de un PR y los corrige automáticamente
- Revisar PR: recupera los cambios de un PR a local para revisar el código
- Corregir revisión: obtenga comentarios de revisión no resueltos de un PR y corríjalos automáticamente
