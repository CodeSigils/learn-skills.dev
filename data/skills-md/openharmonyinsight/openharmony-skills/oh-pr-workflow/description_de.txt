OpenHarmony PR-Workflow für den gesamten Lebenszyklus. Fünf Modi:
- Commit: Standardisiertes Commit mit DCO-Abzeichnung und Issue-Verknüpfung
- PR erstellen: Commit + Push-to-Fork + Issue erstellen + PR im Upstream erstellen
- Codecheck beheben: Gate-CI-Codecheckfehler von einem PR abrufen und automatisch beheben
- PR überprüfen: Rufen Sie die Änderungen eines PR zur lokalen Codeüberprüfung ab
- Korrektur der Bewertung: Rufen Sie ungelöste Bewertungskommentare von einem PR ab und korrigieren Sie sie automatisch
