Рабочий процесс полного жизненного цикла OpenHarmony PR. Пять режимов:
- Фиксация: стандартизированная фиксация с подписанием DCO и связыванием проблем.
- Создать PR: зафиксировать + отправить в ответвление + создать проблему + создать PR в апстриме.
- Исправить проверку кода: получить дефекты проверки кода CI шлюза из PR и автоматически исправить их.
- Просмотр PR: получение изменений PR на локальном компьютере для проверки кода.
- Исправление обзора: получение неразрешенных комментариев к обзору от PR и автоматическое их исправление.
Запускается по: /oh-pr-workflow, "提交代码", "创建PR", "提个PR", "commit",
«修复告警», «修复门禁», «修复проверка кода», «исправить проверку кода»,
"обзор PR", "обзор 这个pr", "看下这个pr", "检视pr",
«修复обзор», «修复检视意见», «исправить обзор»,
или URL-адрес GitCode PR с намерением исправить/пересмотреть.
