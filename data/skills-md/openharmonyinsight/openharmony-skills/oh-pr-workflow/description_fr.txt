Flux de travail du cycle de vie complet d'OpenHarmony PR. Cinq modes :
- Commit : commit standardisé avec approbation du DCO et liaison des problèmes
- Créer un PR : valider + pousser vers le fork + créer un problème + créer un PR en amont
- Correction de Codecheck : récupérez les défauts de vérification de code CI de porte à partir d'un PR et corrigez-les automatiquement
- Review PR : récupérez les modifications d'un PR en local pour la révision du code
- Fix Review : récupérez les commentaires d'évaluation non résolus d'un PR et corrigez-les automatiquement
