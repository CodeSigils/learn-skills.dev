Implementieren Sie In-App-Käufe, Abonnements und Berechtigungen auf Apple-Plattformen mit StoreKit 2 (und den SwiftUI StoreKit-Ansichten). Deckt das Laden des Produkts (Product, Products.for), den Kaufablauf (purchase(), PurchaseResult, Optionen), die Transaktionsüberprüfung (VerificationResult, Transaction.updates, currentEntitlements, finish()), das Berechtigungs-/Freischalt-Gating, Abonnements (automatische Verlängerung, SubscriptionInfo, RenewalState, Status, Kulanzzeitraum, erneuter Abrechnungsversuch), Angebote (Einführung/Promo/Rückgewinnung, Angebotscodes), die Wiederherstellung von Einkäufen (AppStore.sync) und Rückerstattungen ab (beginRefundRequest), die SwiftUI-Ansichten (StoreView, SubscriptionStoreView, ProductView, .storeProductsTask), App Store Server Notifications V2 / Server API und signierte JWS-Transaktionen sowie StoreKit-Tests (.storekit-Konfigurationsdateien, StoreKitTest, Sandbox). Verwenden Sie diese Option, wenn Sie eine Paywall erstellen, Premium-Funktionen freischalten, eine Abonnementstufe hinzufügen, Käufe wiederherstellen, Belege/Transaktionen serverseitig validieren oder IAP testen. Deckt NICHT das SwiftUI-Layout (verwenden Sie Swiftui-Expert-Skill), Benachrichtigungen/App-Absichten (verwenden Sie Apple-Notifications-Appintents) oder die allgemeine Backend-Infrastruktur ab.
