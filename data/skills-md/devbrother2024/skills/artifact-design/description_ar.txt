دليل تصميم يساعدك على تصميم لوحة الألوان والطباعة والتخطيط بشكل متعمد، وتجنب التصميمات المشابهة للقالب أو الذكاء الاصطناعي عند إنشاء تسليم HTML مستقل بذاته (صفحة مقصودة، مستند/تقرير ثابت، لوحة معلومات مستقلة، عرض توضيحي/لعبة، نموذج مقارنة بديل UX/UI قبل التطوير). قم بتحميله قبل استخدام HTML/CSS. يتم تنشيطه للطلبات التي تنشئ أو تقارن عناصر HTML المستقلة مثل "إنشاء صفحة مقصودة"، و"عرض هذا المحتوى بشكل جيد في ملف HTML واحد"، و"مقارنة بدائل UX في HTML"، و"التعامل مع التصميم"، ولا يتم استخدامه لتعديل المكونات داخل التطبيق للتطبيقات الموجودة (React، Vue، وما إلى ذلك) أو للعمل المنطقي/الواجهة الخلفية الخالصة.
