Guía de diseño que ayuda a diseñar intencionalmente la paleta, la tipografía y el diseño y, al mismo tiempo, evita diseños similares a plantillas o con estilo de IA al crear entregables HTML independientes y autónomos (páginas de destino, documentos/informes estáticos, paneles independientes, demostraciones/juegos, maquetas de comparación alternativas de UX/UI previas al desarrollo). Cárguelo antes de usar HTML/CSS. Se activa para solicitudes para crear o comparar un artefacto HTML independiente, como "crear una página de destino", "presentar este contenido de manera agradable como un solo HTML", "comparar alternativas de UX en HTML", "manejar el diseño" y no se utiliza para modificar componentes integrados en la aplicación de aplicaciones existentes (React, Vue, etc.) ni para trabajo de backend/lógico puro.
