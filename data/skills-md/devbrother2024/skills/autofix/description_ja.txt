GitHub PR の未解決のレビュー スレッドを取得し、各コメントの有効性を確認して、修正してコミットする適切なコメントのみを選択します。  
すべてのレビュー担当者 (ボットと人間) からのコメントを処理します。  
「コード レビューの適用」、「レビュー コメントの処理」、「PR レビューの適用」、「PR レビュー コメントの適用」、「レビュー フィードバックの処理」、「autofix」、「/autofix」などのリクエストでアクティブ化します。  
レビュー コメントをそのまま適用するのではなく、検証後に適切と判断されたコメントのみがユーザーの承認 (デフォルト) または自動的 (`--auto`) で適用されます。
