GitHub PR の未解決のレビュー スレッドを取得し、各コメントの有効性を確認して、修正してコミットする適切なコメントのみを選択します。  
すべてのレビュー担当者 (ボットと人間) からのコメントを処理します。  
「コード レビューを適用する」、「レビュー コメントを処理する」、「PR レビューを適用する」、「PR レビュー コメントを適用する」、「レビュー フィードバックを処理する」、「autofix」、または「/autofix」などのリクエストでアクティブ化します。  
レビュー コメントをそのまま適用するのではなく、検証後に適切と判断されたコメントのみが、ユーザーの承認 (デフォルト) または自動的 (`--auto`) で適用されます。
