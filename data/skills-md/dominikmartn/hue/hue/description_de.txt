Meta-Fähigkeit, die neue Fähigkeiten in der Designsprache generiert. Arbeitet an Claude Code und Codex. Wird verwendet, wenn der Benutzer „Design-Skill erstellen“, „Designsprache generieren“, „Neuer Design-System-Skill“, „Von X inspirierter Design-Skill“, „Design-Skill aus diesem Screenshot“, „/hue“ oder „Farbton verwenden“ sagt. Löst auch „Meine Designfähigkeiten neu mischen“ oder „Meine Fähigkeiten mehr X machen“ aus.
