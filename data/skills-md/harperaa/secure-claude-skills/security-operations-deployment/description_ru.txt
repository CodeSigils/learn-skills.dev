Руководство по оперативной безопасности для развертывания, мониторинга и обслуживания. Используйте этот навык, когда вам нужно понять, какое промежуточное программное обеспечение следует применить, настроить переменные среды, отслеживать безопасность после развертывания или следовать контрольному списку перед развертыванием. Триггеры включают «операции безопасности», «безопасность развертывания», «мониторинг безопасности», «переменные среды», «когда использовать промежуточное программное обеспечение», «перед развертыванием», «контрольный список безопасности», «производственную безопасность».
