Utilizza questa competenza quando implementi comportamenti o risolvi bug nella logica pura, nelle regole aziendali, nel comportamento API o nella logica build/CI, ovunque una regressione possa essere costosa. L'abilità impone la disciplina TDD: prima il test fallito, il testimone fallisce, implementa minimamente, PRUNE dopo il verde. Le frasi includono TDDで, テストから書いて, テスト先行. Da attivare quando si corregge un bug che necessita di una protezione dalla regressione o si aggiunge logica a codice non testato, anche senza la dicitura "TDD" esplicita.
