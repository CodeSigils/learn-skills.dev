Используйте этот навык, когда пользователь хочет отправить запрос на включение или составить текст тела PR, включая фразы PR出す, PR提出, PR готов, PR открыт する, PR文書いて, PR описание, отправить. Управляет черновиком тела PR и полным потоком отправки: удаленная проверка состояния, упорядочивание субмодулей, родительская фиксация, создание gh pr с поддержкой cwd. Активируется после завершения реализации и готовности к отправке, даже если пользователь просто произносит 提出する или 出す без явных PR-формулировок.
