Utilice esta habilidad cuando el usuario quiera ayuda para decidir cómo construir algo, evaluar si mantener/eliminar/girar un enfoque, redactar un plan de implementación o ejecutar un plan aprobado, incluidas las frases 設計どうする, 方針決めたい, どうやって直す,やり方どっち, やる価値ある, 採用すべきか, matar か conservar か, 計画実行, 進めて, 着手. Actívelo cuando se discutan ventajas y desventajas técnicas, o cuando el usuario acaba de obtener aprobación y desea implementación, incluso sin una redacción explícita de "diseño" o "plan".
