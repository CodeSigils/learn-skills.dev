Маршруты явно требовали сотрудничества агентов при прямой работе, целенаправленного делегирования безголового Грока, субагентов Пи и Хердра. Используйте, когда пользователь просит делегировать полномочия, координировать агентов, запускать параллельных рецензентов или исследователей, использовать субагенты Herdr или Pi или выбирать серверную часть для совместной работы. Не используйте для обычных задач с одним агентом.
