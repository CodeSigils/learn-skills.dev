Delegiert die gezielte Softwareimplementierung im Headless-Modus an Grok Build CLI und überprüft und verifiziert dann das Ergebnis. Verwenden Sie diese Option, wenn der Benutzer Grok, Grok Build, grok -p oder einen Grok-Subagenten verwenden möchte, um Code zu implementieren, umzugestalten, zu testen oder zu untersuchen.
