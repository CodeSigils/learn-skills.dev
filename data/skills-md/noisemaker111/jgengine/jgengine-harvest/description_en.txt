Use at the end of a JGengine build — the moment a "make ___ with jgengine" game is "done" after several QA passes of hand-fixing camera feel, icons, health bars, damage numbers, death screens, loot toasts, first-person feel, or terrain clipping. Also on "harden the engine", "turn these fixes into primitives", or any postmortem asking why a fix had to be hand-written or how the next build could go faster. Every hand-fix is a system the engine could have owned; this extracts each to its game-agnostic core and files it as its own typed GitHub issue (`[Gap]` `[Primitive]` `[Component]` `[Scaffold]` `[Speed]` `[Doc]`) — one system per issue, so the next game of this shape reuses it instead of rebuilding it.
