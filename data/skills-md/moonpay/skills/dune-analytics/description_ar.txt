تحليلات Blockchain عبر Dune REST API - تنفيذ استعلامات DuneSQL مقابل البيانات المباشرة الموجودة على السلسلة، واكتشاف جداول العقود التي تم فك تشفيرها، ومراقبة استخدام الائتمان. يُستخدم عندما يسأل المستخدم عن البيانات الموجودة على السلسلة، أو نشاط المحفظة، أو تداولات DEX، أو عمليات نقل الرمز المميز، أو أحداث العقود الذكية، أو يقول "الاستعلام عن Dune"، أو "تشغيل استعلام Dune"، أو "البحث في مجموعات بيانات Dune". يقترن مع MoonPay لتحليل المحافظ التي تقوم بإنشائها وتمويلها.
