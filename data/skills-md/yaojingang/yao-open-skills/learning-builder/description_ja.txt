学習者のプロフィールと権威第一の調査に基づいて、パーソナライズされた学習チュートリアルを作成します。ユーザーが目標、背景、制約、望ましい結果を明確にするためのガイド付きの摂取を希望し、その後、公式ドキュメント、標準、メンテナードキュメント、規制当局のガイダンス、またはその他の主要な情報源から組み立てられた構造化されたチュートリアルまたはスタディガイドを希望する場合に使用します。ユーザーがチュートリアルを Word または PDF にエクスポートしたい場合、または完成したチュートリアルをパーソナライズされた学習 Web ページに拡張したい場合にも使用します。 1 回限りの事実に基づく回答、一般的なブログの執筆、チュートリアルの成果物のない広範な Web 調査、または学習パケットのないスタンドアロンの Web ページのデザインには使用しないでください。
