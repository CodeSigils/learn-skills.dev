Crea tutorial di apprendimento personalizzati a partire dal profilo dello studente e da una ricerca basata sull'autorità. Da utilizzare quando l'utente desidera un'assunzione guidata per chiarire obiettivi, background, vincoli e risultati desiderati, quindi desidera un tutorial strutturato o una guida allo studio raccolta da documenti ufficiali, standard, documenti del manutentore, indicazioni di regolamentazione o altre fonti primarie. Utilizzabile anche quando l'utente desidera che il tutorial venga esportato in Word o PDF o desideri estendere il tutorial finito in una pagina Web di apprendimento personalizzata. Non utilizzare per risposte concrete una tantum, scrittura di blog generici, ricerche sul Web su vasta scala senza un tutorial o progettazione di pagine Web autonome senza pacchetto di apprendimento.
