Cree tutoriales de aprendizaje personalizados a partir de un perfil de alumno e investigación centrada en las autoridades. Úselo cuando el usuario desee una entrada guiada para aclarar objetivos, antecedentes, limitaciones y resultados deseados, y luego desee un tutorial estructurado o una guía de estudio recopilada a partir de documentos oficiales, estándares, documentos de mantenimiento, orientación de reguladores u otras fuentes primarias. Utilícelo también cuando el usuario quiera exportar el tutorial a Word o PDF, o quiera ampliar el tutorial terminado a una página web de aprendizaje personalizada. No lo utilice para respuestas objetivas únicas, redacción de blogs genéricos, investigación web amplia sin un tutorial entregable o diseño de página web independiente sin paquete de aprendizaje.
