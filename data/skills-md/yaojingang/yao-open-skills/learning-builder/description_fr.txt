Créez des didacticiels d'apprentissage personnalisés à partir d'un profil d'apprenant et d'une recherche axée sur l'autorité. À utiliser lorsque l'utilisateur souhaite un apport guidé pour clarifier les objectifs, le contexte, les contraintes et les résultats souhaités, puis souhaite un didacticiel structuré ou un guide d'étude assemblé à partir de documents officiels, de normes, de documents du responsable, de conseils de régulateur ou d'autres sources primaires. À utiliser également lorsque l'utilisateur souhaite exporter le didacticiel vers Word ou PDF, ou souhaite étendre le didacticiel terminé dans une page Web d'apprentissage personnalisée. Ne pas utiliser pour des réponses factuelles ponctuelles, pour la rédaction d'un blog générique, pour une recherche approfondie sur le Web sans livrable de didacticiel ou pour la conception de pages Web autonomes sans paquet d'apprentissage.
