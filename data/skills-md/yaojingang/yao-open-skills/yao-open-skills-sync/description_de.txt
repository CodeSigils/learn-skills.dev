Verwalten Sie die öffentliche Sammlung „yao-open-skills“. Verwenden Sie diesen Skill immer dann, wenn der Benutzer bewerten möchte, ob ein lokaler Skill Open Source sein sollte, einen lokalen Skill in das yao-open-skills-Repository importieren, registrieren möchte, welche Skills bereits öffentlich sind, den GitHub-Synchronisierungsstatus verfolgen oder die README-Datei und den Katalog der Sammlung aktualisieren möchte, nachdem er einen Skill hinzugefügt oder aktualisiert hat.
