Cree paquetes de tutoriales independientes para principiantes a partir de un tema o referencias proporcionadas, con investigación adaptativa, diseño de esquema estilo curso, imágenes de capítulos y exportaciones Markdown/DOCX/PDF/HTML. Úselo para tutoriales similares a libros de texto, guías de cursos, documentos didácticos o guías largas para principiantes; no para respuestas rápidas, resúmenes de enlaces, diagramas puros o conversión de archivos.
