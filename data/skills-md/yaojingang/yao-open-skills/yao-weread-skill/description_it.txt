Utilizzato quando l'utente deve analizzare la cronologia di lettura di WeChat, generare report di lettura, visualizzare statistiche di lettura, note, scaffali, nuvole di parole, mappe di calore, grafici radar o esportare un report HTML finemente formattato. Si applica anche alla creazione di report di lettura di esempio per gli imprenditori dell’IA. Non è per consigli generali sui libri o query grezze dell'API WeChat Reading che non producono report.
