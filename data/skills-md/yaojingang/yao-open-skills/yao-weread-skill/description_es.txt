Se utiliza cuando el usuario necesita analizar el historial de lectura de WeChat, generar informes de lectura, visualizar estadísticas de lectura, notas, estanterías, nubes de palabras, mapas de calor, gráficos de radar o exportar un informe HTML con formato fino. También se aplica a la creación de informes de lectura de muestra para emprendedores de IA. No es para recomendaciones generales de libros ni consultas sin procesar de la API de lectura de WeChat que no generan informes.
