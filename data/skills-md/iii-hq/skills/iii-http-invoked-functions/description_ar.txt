يسجل نقاط نهاية HTTP الخارجية كوظائف iii باستخدام RegisterFunction(meta, HttpInvocationConfig). يُستخدم عند تكييف واجهات برمجة التطبيقات القديمة أو خطافات الويب التابعة لجهات خارجية أو الخدمات غير القابلة للتغيير في وظائف iii قابلة للتشغيل، خاصة عندما تطلب المطالبات خرائط نقاط النهاية مثل { path, id } التي يتم تكرارها في استدعاءات RegisterFunction.
