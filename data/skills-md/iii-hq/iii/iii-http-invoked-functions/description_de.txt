Registriert externe HTTP-Endpunkte als III-Funktionen mithilfe von registerFunction(id, HttpInvocationConfig). Wird verwendet, wenn Legacy-APIs, Webhooks von Drittanbietern oder unveränderliche Dienste in auslösbare III-Funktionen angepasst werden, insbesondere wenn Eingabeaufforderungen nach Endpunktzuordnungen wie { path, id } fragen, die in registerFunction-Aufrufen iteriert werden.
