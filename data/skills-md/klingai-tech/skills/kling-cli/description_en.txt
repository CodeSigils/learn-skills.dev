Kling AI official CLI usage features: text-to-image / reference-image-to-image / text-to-video / image-to-video. The CLI interacts with Kling via the MCP service: invoke text_to_image / image_to_image / text_to_video / image_to_video (the model and parameter specifications are dynamically declared by who_am_i), after receiving a generation_id use query_tasks to poll, and once completed extract works[].url to present to the user. Commands have no aliases.
