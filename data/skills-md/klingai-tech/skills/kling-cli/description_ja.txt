Kling AI 公式 CLI の使用機能: テキストから画像へ / 参照画像から画像へ / テキストからビデオへ / 画像からビデオへ。 CLI は MCP サービスを介して Kling と対話します。text_to_image / image_to_image / text_to_video / image_to_video を呼び出します (モデルとパラメーターの仕様は who_am_i によって動的に宣言されます)。generation_id を受け取った後、query_tasks を使用してポーリングし、完了したら works[].url を抽出してユーザーに提示します。コマンドにはエイリアスがありません。トリガーワード：Kling、text-to-image、reference-image-to-image、text-to-video、image-to-video、Omni、omni、MCP、generation_id、polling、インスピレーションバリュー、text_to_image、image_to_image、text_to_video、image_to_video、query_tasks、who_am_i、file_upload、画像生成、ビデオ生成、kling コマンド、.credentials、国内サイト、海外サイト、グローバル、海外版、地域、インストール。
