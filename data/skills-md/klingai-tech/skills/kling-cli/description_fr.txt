Fonctionnalités d'utilisation officielles de la CLI de Kling AI : texte vers image / référence-image vers image / texte vers vidéo / image vers vidéo. La CLI interagit avec Kling via le service MCP : invoquez text_to_image / image_to_image / text_to_video / image_to_video (les spécifications du modèle et des paramètres sont déclarées dynamiquement par who_am_i), après avoir reçu un Generation_id, utilisez query_tasks pour interroger, et une fois terminé, extrayez works[].url pour présenter à l'utilisateur. Les commandes n'ont pas d'alias.
