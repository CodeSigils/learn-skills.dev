El punto de entrada para la creación y edición de imágenes. Maneja solicitudes de imágenes, carteles, logotipos, retratos, escenas, ilustraciones, portadas, imágenes de referencia y dirección visual, y las enruta entre "dirección de arte", "imagen-póster", "imagen-logo", "asset-reference" o "image-prompt". Cuando utilice SeaArt para generación real, llame al adaptador opcional `seaart-execute` después de que se complete el mensaje.
