Punto de entrada para la creación y edición de imágenes. Maneja solicitudes de imágenes, carteles, logotipos, retratos, escenas, ilustraciones, portadas, imágenes de referencia y dirección visual, dirigiéndolas entre "dirección de arte", "imagen-póster", "imagen-logo", "asset-reference" o "image-prompt". Cuando utilice SeaArt para generación real, invoque el adaptador opcional `seaart-execute` después de que se complete el mensaje.
