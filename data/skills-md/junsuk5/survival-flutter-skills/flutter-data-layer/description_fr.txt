Modèle de couche de données d'un projet Flutter — Interface et implémentation DataSource, mappage de modèles de référentiel, DTO et de domaine, « fromJson » du modèle gelé et un référentiel réactif construit avec le « BehaviorSubject » de « rxdart ». Il déclenche des expressions telles que « Création d'une source de données », « Implémentation d'un référentiel », « Référentiel », « Source de données locale/distante », « BehaviorSubject », « Stream Repository », « DTO Mapping » et « fromJson ».
