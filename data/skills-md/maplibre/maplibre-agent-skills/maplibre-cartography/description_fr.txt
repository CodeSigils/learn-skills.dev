Principes cartographiques pour MapLibre GL JS : lisibilité des étiquettes et des symboles sur les images par rapport aux fonds de carte vectoriels, fond de figure pour les icônes de points, style des routes vectorielles sur les images aériennes, hiérarchie visuelle, typographie (glyphes/piles de polices), sprites et boucliers d'itinéraire, ordre des couches pour l'injection de données et accessibilité. À utiliser pour styliser une carte, choisir les couleurs du texte ou des symboles, rendre les marqueurs ou les routes lisibles sur les images satellite/aériennes, configurer les polices ou les icônes, déboguer les boucliers ou ordonner correctement les couches.
