مبادئ رسم الخرائط لـ MapLibre GL JS — وضوح التسمية والرمز على الصور مقابل خرائط الأساس المتجهة، والأرض الشكلية لأيقونات النقاط، وتصميم الطرق المتجهة على الصور الجوية، والتسلسل الهرمي المرئي، والطباعة (الحروف الرسومية/مجموعات الخطوط)، والعفاريت المتحركة ودروع المسار، وترتيب الطبقات لحقن البيانات، وإمكانية الوصول. يُستخدم عند تصميم خريطة، أو اختيار ألوان النص أو الرمز، أو جعل العلامات أو الطرق قابلة للقراءة على صور القمر الصناعي/الجوية، أو إعداد الخطوط أو الأيقونات، أو تصحيح أخطاء الدروع، أو ترتيب الطبقات بشكل صحيح.
