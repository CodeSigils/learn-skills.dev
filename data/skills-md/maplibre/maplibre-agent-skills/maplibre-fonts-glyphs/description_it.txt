Configurazione di caratteri e glifi per MapLibre GL JS e MapLibre Native: URL "glifi" dello stile, PBF di caratteri auto-hosting o generazione, fallback dei caratteri locali GL JS ("glifi" omessi o recupero di glifi non riuscito), proprietà "font-faces" di MapLibre Native e gestione degli script Noto/CJK/RTL/Devanagari. Da utilizzare quando le etichette di testo non vengono visualizzate nel carattere previsto, quando si configura un server di glifi, si sceglie tra l'hosting autonomo e la generazione di PBF di caratteri o si gestiscono script non latini.
