Configuración de fuentes y glifos para MapLibre GL JS y MapLibre Native: la URL de `glifos` del estilo, autohospedaje o generación de fuentes PBF, el recurso de fuente local GL JS (`glifos` omitidos o una búsqueda de glifo fallida), la propiedad `font-faces` de MapLibre Native y manejo de scripts Noto/CJK/RTL/Devanagari. Úselo cuando las etiquetas de texto no se muestran en la fuente deseada, configurando un servidor de glifos, eligiendo entre autohospedaje y generando fuentes PBF, o manejando escrituras no latinas.
