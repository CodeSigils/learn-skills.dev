تكوين الخطوط والصور الرمزية لـ MapLibre GL JS وMapLibre Native - عنوان URL الخاص بالحروف الرسومية للنمط، والاستضافة الذاتية أو إنشاء خطوط PBF، والاحتياطي للخط المحلي GL JS (تم حذف "الحروف الرسومية" أو جلب الحروف الرسومية الفاشلة)، وخاصية "font-faces" الخاصة بـ MapLibre Native، ومعالجة البرنامج النصي Noto/CJK/RTL/Devanagari. يُستخدم عندما لا يتم عرض التسميات النصية بالخط المقصود، أو إعداد خادم الحروف الرسومية، أو الاختيار بين الاستضافة الذاتية وإنشاء خطوط PBF، أو التعامل مع البرامج النصية غير اللاتينية.
