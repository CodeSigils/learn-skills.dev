WeCom CLI All-in-One Suite, die 6 wichtige Geschäftsbereiche abdeckt: Kontakte, Messaging, Dokumente (einschließlich drei Kategorien: Dokumente/Intelligente Blätter/Intelligente Dokumente, früher bekannt als Smart Home), Kalender, Besprechungen und Aufgaben. Unterstützt die Suche nach Kontakten nach Namen/Alias, das Senden und Empfangen von Nachrichten (Text/Bild/Datei/Sprache/Video), das Erstellen/Lesen/Bearbeiten von Dokumenten im Markdown-Format, das Verwalten der Struktur und Datensätze von Intelligent Sheets, das Erstellen von Intelligent Docs und das Exportieren von Intelligent Docs-Inhalten nach Markdown, das Erstellen/Ändern/Stornieren von Kalenderereignissen und die Überprüfung der Verfügbarkeit, das Buchen/Verwalten von Besprechungen, das Erstellen/Verfolgen/Zuweisen von Aufgaben. Auch wenn der Benutzer „WeCom“ nicht explizit erwähnt, sollte dieser Skill ausgelöst werden, sofern es sich um Szenarien wie Messaging/Kalender/To-Dos handelt.
