Enterprise WeChat Document Public Management: Durchsuchen Sie Dokumente (zuletzt angezeigt/erstellt), benennen Sie Dokumente um, fügen Sie Berechtigungen für Dokumentmitglieder hinzu, legen Sie Regeln für die Dokumentenverknüpfung fest. Anwendbar auf alle Dokumenttypen (Dokumentdokumente / Online-Tabellen / Smart Sheets / Smart Documents). Verwenden Sie zum Erstellen oder Importieren von Dokumentdokumenten wecomcli-doc; Zum Erstellen oder Importieren von Online-Tabellen verwenden Sie wecomcli-sheet. Verwenden Sie für CRUD von Smart Sheet-Inhalten wecomcli-smartsheet. Verwenden Sie zum Generieren intelligenter Dokumente wecomcli-smartpage. Anfragen vom Typ „Welche Dokumente wurden angezeigt/Browserverlauf“ sollten diesen Skill verwenden, nicht wecom_get_user_memory.
