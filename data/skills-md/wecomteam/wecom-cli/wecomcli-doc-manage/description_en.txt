Enterprise WeChat Document Public Management: search documents (recently viewed/created), rename documents, add document member permissions, set document joining rules. Applicable to all document types (doc documents / online spreadsheets / smart sheets / smart documents). For creating or importing doc documents, use wecomcli-doc; for creating or importing online spreadsheets, use wecomcli-sheet; for CRUD of smart sheet content, use wecomcli-smartsheet; for generating smart documents, use wecomcli-smartpage. Requests of the “which documents have been viewed/browsing history” type should use this skill, not wecom_get_user_memory.
