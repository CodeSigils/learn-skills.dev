Enterprise WeChat document public management: search documents (recently viewed/created), rename documents, add document member permissions, set document joining rules. Applicable to all document types (doc documents / online sheets / smart sheets / smart documents). Use wecomcli-doc to create or import doc documents; use wecomcli-sheet to create or import online sheets; use wecomcli-smartsheet for CRUD operations on smart sheet content; and use wecomcli-smartpage to generate smart documents. Requests of the “which documents have been viewed / browsing history” type should be handled by this skill, not by wecom_get_user_memory.
