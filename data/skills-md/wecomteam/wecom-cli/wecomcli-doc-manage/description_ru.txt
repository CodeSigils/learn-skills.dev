Публичное управление корпоративными документами WeChat: поиск документов (недавно просмотренных/созданных), переименование документов, добавление разрешений для участников документа, установка правил объединения документов. Применимо ко всем типам документов (документы/онлайн-таблицы/умные таблицы/умные документы). Используйте wecomcli-doc для создания или импорта документов; используйте wecomcli-sheet для создания или импорта онлайн-таблиц; используйте wecomcli-smartsheet для операций CRUD над содержимым смарт-таблиц; используйте wecomcli-smartpage для создания смарт-документов. Запросы типа «какие документы были просмотрены/история просмотров» должны проходить через этот навык, а не через wecom_get_user_memory.
