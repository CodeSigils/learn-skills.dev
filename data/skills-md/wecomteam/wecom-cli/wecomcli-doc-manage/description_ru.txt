Публичное управление корпоративными документами WeChat: поиск документов (недавно просмотренных/созданных), переименование документов, добавление разрешений для участников документа, установка правил объединения документов. Применимо ко всем типам документов (документы / онлайн-листы / смарт-листы / смарт-документы). Используйтеwecomcli-doc для создания или импорта документов; используйте wecomcli-sheet для создания или импорта онлайн-листов; используйте wecomcli-smartsheet для операций CRUD над содержимым смарт-листа; и используйте wecomcli-smartpage для создания смарт-документов. Запросы типа «какие документы были просмотрены/история просмотров» должны обрабатываться этим навыком, а не wecom_get_user_memory.
