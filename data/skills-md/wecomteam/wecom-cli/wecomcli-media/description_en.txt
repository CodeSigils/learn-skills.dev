Enterprise WeChat media file upload/download capability. It handles two types of operations: downloading a media file to local storage using a media_id, and uploading a local file to obtain a media_id. When other capabilities (e.g., Weipan, email, etc.) return a media_id that needs to be materialized as a local file, or when an existing local file needs to be converted into a media_id for use by other capabilities, you must first consult this skill's complete guide and not rely on memory. This skill does not parse or recognize file contents; it is solely responsible for the transport of the file itself.
