Competenza di caricamento/download di file multimediali Enterprise WeChat. Gestisce due tipi di operazioni: il download di file multimediali nella memoria locale in base a un media_id e il caricamento di file locali per ottenere un media_id. Quando altre competenze (come WeDrive, email, ecc.) restituiscono un media_id che deve essere materializzato come file locale, o quando un file locale esistente deve essere convertito in un media_id per essere utilizzato da altre competenze, è necessario prima leggere questa competenza per ottenere le linee guida complete e non agire a memoria. Questa abilità non analizza/riconosce il contenuto dei file; gestisce solo il trasporto dei file stessi.
