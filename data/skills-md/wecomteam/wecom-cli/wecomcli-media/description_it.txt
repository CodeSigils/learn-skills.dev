Funzionalità di caricamento/download di file multimediali Enterprise WeChat. Gestisce due tipi di operazioni: il download di un file multimediale nella memoria locale utilizzando un media_id e il caricamento di un file locale per ottenere un media_id. Quando altre funzionalità (ad esempio Weipan, email, ecc.) restituiscono un media_id che deve essere materializzato come file locale o quando un file locale esistente deve essere convertito in media_id per essere utilizzato da altre funzionalità, devi prima consultare la guida completa di questa competenza e non fare affidamento sulla memoria. Questa abilità non analizza né riconosce il contenuto dei file; è l'unico responsabile del trasporto del file stesso.
