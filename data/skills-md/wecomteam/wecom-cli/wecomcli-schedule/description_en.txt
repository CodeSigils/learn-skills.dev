Enterprise WeChat calendar management skill.  
Suits all user needs for managing Enterprise WeChat calendars. Use it when the user wants to:  
(1) Query the schedule list within a specified time range or get details of an event (title, time, location, participants, etc.);  
(2) Create a new event and set reminders and attendees;  
(3) Modify an existing event’s title, time, location, or cancel the event;  
(4) Add or remove event participants;  
(5) Check multiple members’ free/busy status and analyze common free slots to arrange meetings.
