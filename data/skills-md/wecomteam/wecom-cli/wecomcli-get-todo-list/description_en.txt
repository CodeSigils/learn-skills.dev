Enterprise WeChat to-do list query skill, supporting filtering by creation time and reminder time, with pagination support. Use this when the user says "check my to-do list", "what to-dos do I have", "this week’s to-dos", "recent to-dos", "look up my to-dos", "list all to-dos", or any scenario requiring a to-do overview. Note: this skill returns only summary information (excluding content and assignee); for full details, use wecomcli-get-todo-detail.
