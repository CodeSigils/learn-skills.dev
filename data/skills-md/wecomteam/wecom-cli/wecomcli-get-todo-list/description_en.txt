Enterprise WeChat to-do list query skill, supports filtering by creation time and reminder time, and supports pagination. Use it when the user says "check my to-do list," "what are my to-dos," "what are this week's to-dos," "what are the recent to-dos," "look up my to-dos," "list all to-dos," etc., for browsing the overview of to-dos. Note: this skill only returns summary information of to-dos (excluding content and assignee); for full details, use wecomcli-get-todo-detail in conjunction.
