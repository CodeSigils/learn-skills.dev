Habilidad de consulta de lista de tareas pendientes de Enterprise WeChat, admite filtrado por hora de creación y hora de recordatorio, y admite paginación. Úselo cuando el usuario diga "revisar mi lista de tareas pendientes", "cuáles son mis tareas pendientes", "cuáles son las tareas pendientes de esta semana", "cuáles son las tareas pendientes recientes", "buscar mis tareas pendientes", "enumerar todas las tareas pendientes", etc., para explorar la descripción general de las tareas pendientes. Nota: esta habilidad solo devuelve información resumida de las tareas pendientes (excluyendo el contenido y el responsable); para obtener detalles completos, use wecomcli-get-todo-detail en conjunto.
