Habilidad de consulta de lista de tareas pendientes de WeChat empresarial, que admite filtrado por hora de creación y hora de recordatorio, con soporte de paginación. Utilice esto cuando el usuario diga "revisar mi lista de tareas pendientes", "qué tareas pendientes tengo", "las tareas pendientes de esta semana", "tareas pendientes recientes", "buscar mis tareas pendientes", "enumerar todas las tareas pendientes" o cualquier escenario que requiera una descripción general de las tareas pendientes. Nota: esta habilidad devuelve solo información resumida (excluyendo el contenido y el responsable); Para obtener todos los detalles, utilice wecomcli-get-todo-detail.
