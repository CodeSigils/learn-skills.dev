WeChat Work-Messaging-Fähigkeiten. Bietet Konversationslistenabfragen, das Abrufen des Nachrichtenverlaufs (unterstützt Text/Bild/Datei/Sprache/Video), das Abrufen von Multimediadateien und das Senden von Textnachrichten. Wird ausgelöst, wenn der Benutzer „Nachrichten anzeigen“, „Chat-Verlauf überprüfen“, „eine Nachricht an jemanden senden“, „letzte Nachrichten anzeigen“, „eine Nachricht an eine Gruppe senden“ oder „sehen muss, welche Bilder/Dateien gesendet wurden“.
