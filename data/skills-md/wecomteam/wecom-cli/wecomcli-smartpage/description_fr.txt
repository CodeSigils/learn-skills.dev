Compétence de gestion de WeChat Work Smart Document (anciennement connu sous le nom de Smart Page, smartpage). Offre la possibilité de créer des documents intelligents (publier des fichiers Markdown locaux en tant que documents intelligents) et d'exporter du contenu (exporter de manière asynchrone vers Markdown). Scénarios applicables : (1) Créez un ou plusieurs fichiers Markdown locaux en tant que documents intelligents ; (2) Exportez de manière asynchrone le contenu du document intelligent vers Markdown. Prend en charge la localisation de documents via docid ou URL de document. La compétence est déclenchée lorsque l'utilisateur mentionne explicitement « document intelligent » ou « page intelligente », ou fournit un lien sous la forme « https://doc.weixin.qq.com/smartpage/xxx ». Remarque : Pour les documents normaux (`/doc/*`), utilisez `wecomcli-doc` ; pour les feuilles en ligne (`/sheet/*`), utilisez `wecomcli-sheet` ; pour les feuilles intelligentes (`/smartsheet/*`), utilisez `wecomcli-smartsheet`.
