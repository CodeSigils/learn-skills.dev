Compétence de gestion de documents intelligents Enterprise WeChat (anciennement Smart Page, smartpage). Fournit des fonctionnalités pour créer des documents intelligents (publier des fichiers Markdown locaux en tant que documents intelligents) et pour exporter du contenu (exporter de manière asynchrone vers Markdown). Cas d'utilisation : (1) Créez un ou plusieurs fichiers Markdown locaux en tant que documents intelligents (2) Exportez de manière asynchrone le contenu du document intelligent vers Markdown. Prend en charge la localisation de documents via docid ou URL de document. La compétence se déclenche lorsque l'utilisateur mentionne explicitement « document intelligent » ou « page intelligente », ou lorsqu'un lien du formulaire `https://doc.weixin.qq.com/smartpage/xxx` est présent. Remarque : Pour les documents normaux (`/doc/*`), utilisez `wecomcli-doc` ; pour les feuilles en ligne (`/sheet/*`), utilisez `wecomcli-sheet` ; pour les feuilles intelligentes (`/smartsheet/*`), utilisez `wecomcli-smartsheet`.
