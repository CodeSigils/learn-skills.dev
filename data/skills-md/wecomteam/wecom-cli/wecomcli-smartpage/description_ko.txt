위챗워크 스마트문서(구 스마트페이지, 스마트페이지) 관리 스킬. 스마트 문서 생성(로컬 Markdown 파일을 스마트 문서로 게시) 및 콘텐츠 내보내기(비동기적으로 Markdown으로 내보내기) 기능을 제공합니다. 적용 가능한 시나리오: (1) 하나 이상의 로컬 Markdown 파일을 스마트 문서로 만듭니다. (2) 스마트 문서 콘텐츠를 Markdown으로 비동기식으로 내보냅니다. docid 또는 문서 URL을 통해 문서 찾기를 지원합니다. 이 기술은 사용자가 "스마트 문서" 또는 "스마트 페이지"를 명시적으로 언급하거나 `https://doc.weixin.qq.com/smartpage/xxx` 형식의 링크를 언급할 때 트리거됩니다. 참고: 일반 문서(`/doc/*`)의 경우 `wecomcli-doc`를 사용하세요. 온라인 시트(`/sheet/*`)의 경우 `wecomcli-sheet`를 사용하세요. 스마트 시트(`/smartsheet/*`)의 경우 `wecomcli-smartsheet`를 사용하세요.
