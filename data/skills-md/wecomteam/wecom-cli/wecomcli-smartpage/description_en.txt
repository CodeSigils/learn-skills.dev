WeChat Work Smart Document (formerly known as Smart Page, smartpage) management skill. Provides the ability to create smart documents (publish local Markdown files as smart documents) and export content (asynchronously export to Markdown). Applicable scenarios: (1) Create one or multiple local Markdown files as smart documents; (2) Asynchronously export smart document content to Markdown. Supports locating documents via docid or document URL. The skill is triggered when the user explicitly mentions “smart document” or “smart page”, or provides a link in the form `https://doc.weixin.qq.com/smartpage/xxx`. Note: For regular documents (`/doc/*`) use `wecomcli-doc`; for online sheets (`/sheet/*`) use `wecomcli-sheet`; for smart sheets (`/smartsheet/*`) use `wecomcli-smartsheet`.
