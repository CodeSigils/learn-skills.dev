Навыки управления WeChat Work Smart Document (ранее известные как Smart Page, smartpage). Предоставляет возможность создавать смарт-документы (публиковать локальные файлы Markdown как смарт-документы) и экспортировать контент (асинхронный экспорт в Markdown). Применимые сценарии: (1) Создайте один или несколько локальных файлов Markdown в качестве смарт-документов; (2) Асинхронно экспортируйте содержимое смарт-документа в Markdown. Поддерживает поиск документов через docid или URL-адрес документа. Этот навык активируется, когда пользователь явно упоминает «умный документ» или «умную страницу» или предоставляет ссылку в форме «https://doc.weixin.qq.com/smartpage/xxx». Примечание. Для обычных документов (`/doc/*`) используйте `wecomcli-doc`; для онлайн-листов (`/sheet/*`) используйте `wecomcli-sheet`; для смарт-листов (`/smartsheet/*`) используйте `wecomcli-smartsheet`.
