Capacità di gestione Enterprise WeChat Smart Document (precedentemente nota come Smart Homepage, smartpage). Fornisce funzionalità per la creazione di documenti intelligenti (pubblicazione di file Markdown locali come documenti intelligenti) ed esportazione di contenuti (esportazione asincrona in Markdown). Scenari applicabili: (1) Creare uno o più file Markdown locali come documenti intelligenti; (2) Esporta in modo asincrono il contenuto dei documenti intelligenti in Markdown. Supporta l'individuazione dei documenti tramite docid o URL del documento. Questa abilità viene attivata quando l'utente menziona esplicitamente "smart document" o "smart homepage" o quando è presente un collegamento nel formato `https://doc.weixin.qq.com/smartpage/xxx`. Nota: per i documenti normali (`/doc/*`) utilizzare `wecomcli-doc`; per i fogli online (`/sheet/*`) utilizzare `wecomcli-sheet`; per i fogli intelligenti (`/smartsheet/*`) utilizzare `wecomcli-smartsheet`.
