Abilità di gestione di WeChat Work Smart Document (precedentemente nota come Smart Page, smartpage). Offre la possibilità di creare documenti intelligenti (pubblicare file Markdown locali come documenti intelligenti) ed esportare contenuto (esportazione asincrona in Markdown). Scenari applicabili: (1) Creare uno o più file Markdown locali come documenti intelligenti; (2) Esporta in modo asincrono il contenuto dei documenti intelligenti in Markdown. Supporta l'individuazione dei documenti tramite docid o URL del documento. La skill viene attivata quando l'utente menziona esplicitamente "smart document" o "smart page" o fornisce un collegamento nel formato `https://doc.weixin.qq.com/smartpage/xxx`. Nota: per i documenti normali (`/doc/*`) utilizzare `wecomcli-doc`; per i fogli online (`/sheet/*`) utilizzare `wecomcli-sheet`; per i fogli intelligenti (`/smartsheet/*`) utilizzare `wecomcli-smartsheet`.
