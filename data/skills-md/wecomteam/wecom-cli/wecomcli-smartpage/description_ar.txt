مهارة إدارة WeChat Work Smart Document (المعروفة سابقًا باسم Smart Page، Smartpage). يوفر القدرة على إنشاء مستندات ذكية (نشر ملفات Markdown المحلية كمستندات ذكية) وتصدير المحتوى (التصدير بشكل غير متزامن إلى Markdown). السيناريوهات القابلة للتطبيق: (1) إنشاء ملف Markdown محلي واحد أو عدة ملفات كمستندات ذكية؛ (2) تصدير محتوى المستند الذكي بشكل غير متزامن إلى Markdown. يدعم تحديد موقع المستندات عبر docid أو عنوان URL للمستند. يتم تشغيل المهارة عندما يذكر المستخدم صراحةً "المستند الذكي" أو "الصفحة الذكية"، أو يقدم رابطًا في النموذج "https://doc.weixin.qq.com/smartpage/xxx". ملحوظة: بالنسبة للمستندات العادية (`/doc/*`) استخدم `wecomcli-doc`؛ بالنسبة للأوراق الموجودة على الإنترنت (`/sheet/*`) استخدم `wecomcli-sheet`؛ بالنسبة للأوراق الذكية (`/smartsheet/*`) استخدم `wecomcli-smartsheet`.
