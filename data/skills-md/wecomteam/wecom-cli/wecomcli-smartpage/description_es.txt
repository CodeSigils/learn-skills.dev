Habilidad de gestión de documentos inteligentes de WeChat Work (anteriormente conocida como página inteligente, página inteligente). Proporciona la capacidad de crear documentos inteligentes (publicar archivos Markdown locales como documentos inteligentes) y exportar contenido (exportar asincrónicamente a Markdown). Escenarios aplicables: (1) Cree uno o varios archivos Markdown locales como documentos inteligentes; (2) Exportar de forma asincrónica el contenido del documento inteligente a Markdown. Admite la localización de documentos a través de docid o URL del documento. La habilidad se activa cuando el usuario menciona explícitamente "documento inteligente" o "página inteligente", o proporciona un enlace en el formato "https://doc.weixin.qq.com/smartpage/xxx". Nota: Para documentos normales (`/doc/*`), utilice `wecomcli-doc`; para hojas en línea (`/sheet/*`) use `wecomcli-sheet`; para hojas inteligentes (`/smartsheet/*`), utilice `wecomcli-smartsheet`.
