Habilidad de gestión de documentos inteligentes Enterprise WeChat (anteriormente Smart Page, página inteligente). Proporciona la capacidad de crear documentos inteligentes (publicando archivos Markdown locales como documentos inteligentes) y exportar contenido (exportando asincrónicamente a Markdown). Escenarios aplicables: (1) Crear uno o más archivos Markdown locales como documentos inteligentes (2) Exportar asincrónicamente el contenido del documento inteligente a Markdown. Admite la localización de documentos a través de docid o URL del documento. Esta habilidad se activa cuando el usuario menciona explícitamente "documento inteligente" o "página inteligente", o un enlace en el formato "https://doc.weixin.qq.com/smartpage/xxx". Nota: Para documentos normales (`/doc/*`), utilice `wecomcli-doc`; para hojas en línea (`/sheet/*`) use `wecomcli-sheet`; para hojas inteligentes (`/smartsheet/*`), utilice `wecomcli-smartsheet`.
