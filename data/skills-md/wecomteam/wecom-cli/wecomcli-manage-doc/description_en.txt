Enterprise WeChat Document Management Skills. Provides document creation, reading, and editing capabilities, supporting operations on Enterprise WeChat documents (doc_type=3) and smart tables (doc_type=10) via docid or document URL. Applicable scenarios: (1) Export document content in Markdown format via asynchronous polling (2) Create new documents or smart tables (3) Overwrite document content in Markdown format. This Skill is triggered when users need to view document content, create new documents, or edit document body.
