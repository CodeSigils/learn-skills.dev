Enterprise WeChat calendar management skill. Suitable for all user needs regarding managing calendars in Enterprise WeChat. Use this skill when the user needs to: (1) query the list of events within a specified time range or obtain detailed event information (title, time, location, participants, etc.), (2) create new events and set reminders and participants, (3) modify the title, time, location, or other information of existing events or cancel events, (4) add or remove event participants, (5) check the availability status of multiple members and analyze common free time slots to schedule meetings.
