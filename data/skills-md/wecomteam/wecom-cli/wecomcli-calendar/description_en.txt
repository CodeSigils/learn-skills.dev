Enterprise WeChat schedule management. It is triggered when the user needs to book a schedule, reserve a meeting room, view/update/cancel a schedule, or check availability. This skill handles “schedules”—arrangements that do not include online meeting links (also covering purely offline face‑to‑face meetups); if the user wants an “online meeting” (including meeting numbers/join links, remote or video participation), use the wecomcli‑meeting skill instead. When the user only says “have a meeting,” “schedule a meeting,” “some meeting,” etc., without clearly indicating whether to create a schedule or an online meeting, the system must first invoke this skill and follow its disambiguation process to ask the user for confirmation before proceeding, and must not assume and create directly.
