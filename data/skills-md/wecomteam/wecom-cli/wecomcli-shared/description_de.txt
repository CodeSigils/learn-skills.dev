Allgemeine Vorabprüfungen des Wecom-Cli-Business-Skills, die Anschaffung eines Roboters und die Autorisierung einer realen Personenidentität sowie allgemeine Ausgabebeschränkungen. Bevor ein wecomcli‑*-Skill einen wecom‑cli-Befehl ausführt, muss er auch diesen Skill laden, überprüfen, ob die CLI installiert ist, dass ihre Version mindestens 1.1.0 ist und dass die Enterprise WeChat-Anmeldeinformationen autorisiert wurden; Die Installation oder Initialisierung wird nur durchgeführt, wenn sie fehlt, die Version zu niedrig ist oder die Autorisierung fehlt. Dieser Skill definiert auch eine Einschränkung, dass ID-Typ-Felder, die von allen Skills gemeinsam genutzt werden, nicht offengelegt werden dürfen. Mit diesem Skill können keine spezifischen Geschäftsanfragen bearbeitet werden.
