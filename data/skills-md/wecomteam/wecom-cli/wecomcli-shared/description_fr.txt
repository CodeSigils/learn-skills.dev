Avant qu'une compétence wecomcli‑* exécute une commande wecom‑cli, elle doit également charger cette compétence, vérifier que la CLI est installée, que sa version est au moins 1.1.0 et que les informations d'identification Enterprise WeChat ont été autorisées ; l'installation ou l'initialisation n'est effectuée qu'en cas d'absence, de version trop basse ou d'autorisation absente. Cette compétence définit également une contrainte selon laquelle les champs de type ID partagés par toutes les compétences ne doivent pas être exposés. Cette compétence ne gère pas les demandes métiers spécifiques.
