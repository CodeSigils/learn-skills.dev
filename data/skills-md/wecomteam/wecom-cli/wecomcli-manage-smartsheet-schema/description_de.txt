Enterprise WeChat Smart Table Structure Management-Fähigkeiten. Bietet die Möglichkeit, Untertabellen (Blätter) und Felder (Felder/Spalten) hinzuzufügen, zu löschen, zu ändern und abzufragen. Anwendbare Szenarien: (1) Abfragen der Liste der Untertabellen in einer Smart Table (2) Hinzufügen, Aktualisieren oder Löschen von Untertabellen (3) Abfragen von Feld-/Spalteninformationen einer Untertabelle (4) Hinzufügen, Aktualisieren oder Löschen von Feldern/Spalten. Dieser Skill wird ausgelöst, wenn Benutzer die Tabellenstruktur, Spaltendefinitionen oder Untertabellenkonfigurationen einer Smart Table verwalten müssen. Unterstützt das Auffinden von Dokumenten über docid oder Dokument-URL.
