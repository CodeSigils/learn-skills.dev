Enterprise WeChat Smart Table Structure Management-Fähigkeit. Bietet Funktionen zum Erstellen, Lesen, Aktualisieren und Löschen für Blätter und Felder/Spalten. Anwendbare Szenarien: (1) Abfragen der Liste der Blätter in einer Smart Table (2) Hinzufügen, Aktualisieren oder Löschen von Blättern (3) Abfragen von Feld-/Spalteninformationen für ein Blatt (4) Hinzufügen, Aktualisieren oder Löschen von Feldern/Spalten. Diese Fähigkeit wird ausgelöst, wenn Benutzer die Struktur, Spaltendefinitionen oder Blattkonfigurationen einer Smart Table verwalten müssen. Unterstützt das Auffinden von Dokumenten über docid oder Dokument-URL.
