Enterprise WeChat Smart Table Structure Management Skills. Provides the ability to add, delete, modify, and query sub-tables (Sheets) and fields (Fields/columns). Applicable scenarios: (1) Query the list of sub-tables in a smart table (2) Add, update, or delete sub-tables (3) Query field/column information of a sub-table (4) Add, update, or delete fields/columns. This Skill is triggered when users need to manage the table structure, column definitions, or sub-table configurations of a smart table. Supports locating documents via docid or document URL.
