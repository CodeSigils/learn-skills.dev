Enterprise WeChat Smart Table Structure Management Skill. Offers create, read, update, and delete capabilities for sheets and fields/columns. Applicable scenarios: (1) Query the list of sheets in a smart table (2) Add, update, or delete sheets (3) Query field/column information for a sheet (4) Add, update, or delete fields/columns. This skill is triggered when users need to manage a smart table's structure, column definitions, or sheet configurations. Supports locating documents via docid or document URL.
