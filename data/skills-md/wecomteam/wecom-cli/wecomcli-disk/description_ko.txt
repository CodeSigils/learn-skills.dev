기업용 위챗 마이크로 디스크(디스크/클라우드 디스크) 파일 운용 스킬. "마이크로 디스크/클라우드 디스크"에 있는 파일에 대한 나열, 검색, 메타데이터 읽기, 업로드, 다운로드, 이름 변경 및 폴더 생성 작업을 처리합니다. 사용자가 "마이크로 디스크", "클라우드 디스크" 또는 "공유 공간"을 명시적으로 언급하는 경우 이 기술을 먼저 참조하여 전체 지침을 얻어야 하며 메모리에서 처리해서는 안 됩니다. 사용자가 "마이크로 디스크에 업로드", "마이크로 디스크에서 xxx 검색 도와줘", "마이크로 디스크에서 해당 PPT는 어디에 있습니까?", "마이크로 디스크에서 해당 파일 다운로드", "마이크로 디스크 파일 이름을 xxx로 변경"이라고 말하거나 `https://drive.weixin.qq.com/s?k=...` 형식의 마이크로 디스크 파일 링크를 제공할 때 이 기술을 사용하세요.  

`wecomcli-doc` / `wecomcli-sheet` / `wecomcli-smartsheet` / `wecomcli-smartpage`와의 차이점: 이 스킬은 검색, 목록, 기본 정보, 위치, 경로 및 이름 바꾸기와 같은 Micro Disk의 모든 파일 수준 작업(온라인 문서 포함)을 처리합니다. 온라인 문서(`doc/sheet/smartsheet/smartpage` 유형)의 콘텐츠 읽기/쓰기는 이 기술이 아닌 해당 문서 기술에 의해 처리됩니다. 사용자가 “이 문서가 마이크로 디스크에 어디에 있나요?”라고 묻거나 마이크로 디스크에 있는 파일의 위치를 ​​문의하면 공간 이름, 폴더 이름, 경로 등의 메타데이터를 GET 요청으로 반환하는 기술입니다.
