기업용 위챗 디스크(Disk/Netdisk) 파일 운용 능력. "디스크/넷디스크" 내에서 파일 나열, 검색, 메타데이터 읽기, 업로드, 다운로드, 이름 바꾸기 및 폴더 생성 작업을 처리합니다. 사용자가 "디스크"/"넷디스크"/"공유 공간"을 명시적으로 언급하는 경우 먼저 이 기술을 참조하여 완전한 지침을 얻어야 합니다. 기억에 의존해서는 안 됩니다. 사용자가 "디스크에 업로드", "디스크에서 xxx 검색 도움말", "디스크에서 해당 PPT는 어디에 있습니까?", "해당 디스크 파일 다운로드", "해당 디스크 파일 이름을 xxx로 변경"이라고 말하거나 `https://drive.weixin.qq.com/s?k=...` 스타일의 디스크 파일 링크를 제공하는 경우 이 기술을 사용해야 합니다.  

`wecomcli-doc` / `wecomcli-sheet` / `wecomcli-smartsheet` / `wecomcli-smartpage`와의 차이점: 이 기술은 온라인 문서를 포함하여 디스크의 모든 파일에 대한 모든 파일 수준 작업(검색/목록/기본 정보/위치/경로/이름 바꾸기 등)을 처리합니다. 온라인 문서('doc/sheet/smartsheet/smartpage' 유형)의 콘텐츠 읽기/쓰기는 이 기술이 아닌 해당 문서 기술에 의해 처리됩니다.  

사용자가 "이 문서가 디스크에 어디에 있습니까?"라고 물거나 디스크에 파일의 위치를 ​​문의할 때 이 스킬은 GET 요청을 통해 공간 이름, 폴더 이름, 경로 등의 메타데이터를 반환해야 합니다.
