Habilidades de operación de archivos Enterprise WeChat Disk (Disk / Netdisk). Maneja operaciones de listado de archivos, búsqueda, lectura de metadatos, carga, descarga, cambio de nombre y creación de carpetas dentro de "Disk/Netdisk". Cuando el usuario menciona explícitamente "Disco"/"Netdisk"/"Espacio compartido", primero debe consultar esta habilidad para obtener la guía completa; No debes confiar en la memoria. Cuando el usuario dice "cargar al disco", "ayúdame a buscar xxx en el disco", "dónde está ese PPT en el disco", "descargar ese archivo de disco", "cambiar el nombre de ese archivo de disco a xxx" o proporciona un enlace de archivo de disco estilo `https://drive.weixin.qq.com/s?k=...`, debes usar esta habilidad.  

Diferencia con `wecomcli-doc` / `wecomcli-sheet` / `wecomcli-smartsheet` / `wecomcli-smartpage`: esta habilidad maneja todas las operaciones a nivel de archivo (búsqueda/lista/información básica/ubicación/ruta/renombrar, etc.) para cada archivo en el disco, incluidos los documentos en línea. La lectura/escritura de contenido de documentos en línea (tipos `doc/sheet/smartsheet/smartpage`) se maneja mediante sus habilidades de documentos correspondientes, no por esta habilidad.  

Cuando el usuario pregunta "¿dónde está este documento en el disco" o pregunta sobre la ubicación de un archivo en el disco, esta habilidad debería devolver metadatos como el nombre del espacio, el nombre de la carpeta y la ruta a través de una solicitud GET.
