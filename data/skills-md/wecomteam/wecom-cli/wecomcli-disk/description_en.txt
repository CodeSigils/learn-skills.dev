Enterprise WeChat Micro Disk (Disk / Cloud Disk) file operation skill. It handles listing, searching, reading metadata, uploading, downloading, renaming, and creating folder operations for files in “Micro Disk/Cloud Disk”. When the user explicitly mentions “Micro Disk”, “Cloud Disk”, or “Shared Space”, this skill must first be consulted to obtain the full guidance and must not be handled from memory. Use this skill when the user says “upload to Micro Disk”, “help me search xxx in Micro Disk”, “where is that PPT in Micro Disk”, “download that file from Micro Disk”, “rename that Micro Disk file to xxx”, or provides a Micro Disk file link of the form `https://drive.weixin.qq.com/s?k=...`.  

Difference from `wecomcli-doc` / `wecomcli-sheet` / `wecomcli-smartsheet` / `wecomcli-smartpage`: this skill deals with all file‑level operations (including online documents) in Micro Disk such as search, list, basic info, location, path, and rename; content read/write of online documents (`doc/sheet/smartsheet/smartpage` types) is handled by the corresponding document skills and not by this skill. When the user asks “where is this document in Micro Disk” or inquires about the location of a file in Micro Disk, this skill returns metadata such as space name, folder name, and path via a GET request.
