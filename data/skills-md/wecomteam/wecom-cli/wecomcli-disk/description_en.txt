Enterprise WeChat Disk (Disk / Netdisk) file operation skills. Handles file listing, searching, reading metadata, uploading, downloading, renaming, and creating folder operations within "Disk / Netdisk". When the user explicitly mentions "Disk"/"Netdisk"/"Shared Space", you must first consult this skill to obtain the complete guidance; you must not rely on memory. When the user says "upload to Disk", "help me search xxx in Disk", "where is that PPT in Disk", "download that Disk file", "rename that Disk file to xxx", or provides a `https://drive.weixin.qq.com/s?k=...` style Disk file link, you must use this skill.  

Difference from `wecomcli-doc` / `wecomcli-sheet` / `wecomcli-smartsheet` / `wecomcli-smartpage`: this skill handles all file‑level operations (search/list/basic info/location/path/rename, etc.) for every file in Disk, including online documents. Content read/write of online documents (types `doc/sheet/smartsheet/smartpage`) is handled by their corresponding document skills, not by this skill.  

When the user asks "where is this document in Disk" or inquires about a file’s location in Disk, this skill should return metadata such as space name, folder name, and path via a GET request.
