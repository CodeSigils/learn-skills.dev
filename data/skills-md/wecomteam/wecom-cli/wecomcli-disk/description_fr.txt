Compétence en matière d'exploitation de fichiers Enterprise WeChat Micro Disk (Disque / Cloud Disk). Il gère la liste, la recherche, la lecture des métadonnées, le téléchargement, le renommage et la création d'opérations de dossier pour les fichiers dans « Micro Disk/Cloud Disk ». Lorsque l'utilisateur mentionne explicitement « Micro Disk », « Cloud Disk » ou « Shared Space », cette compétence doit d'abord être consultée pour obtenir un guidage complet et ne doit pas être manipulée de mémoire. Utilisez cette compétence lorsque l'utilisateur dit « télécharger sur Micro Disk », « aidez-moi à rechercher xxx dans Micro Disk », « où se trouve ce PPT dans Micro Disk », « téléchargez ce fichier à partir de Micro Disk », « renommez ce fichier Micro Disk en xxx », ou fournit un lien de fichier Micro Disk du formulaire « https://drive.weixin.qq.com/s?k=... ».  

Différence avec `wecomcli-doc` / `wecomcli-sheet` / `wecomcli-smartsheet` / `wecomcli-smartpage` : cette compétence traite toutes les opérations au niveau des fichiers (y compris les documents en ligne) dans Micro Disk telles que la recherche, la liste, les informations de base, l'emplacement, le chemin et le renommage ; le contenu lu/écrit des documents en ligne (types `doc/sheet/smartsheet/smartpage`) est géré par les compétences documentaires correspondantes et non par cette compétence. Lorsque l'utilisateur demande « où se trouve ce document dans Micro Disk » ou demande l'emplacement d'un fichier dans Micro Disk, cette compétence renvoie des métadonnées telles que le nom de l'espace, le nom du dossier et le chemin via une requête GET.
