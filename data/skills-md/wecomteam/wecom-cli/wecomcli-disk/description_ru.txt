Навыки работы с файлами Enterprise WeChat Disk (Disk / Net Disk). Управляет листингом, поиском, чтением метаданных, загрузкой, скачиванием, переименованием и созданием папок для файлов на «Диск/Сетевой диск». Когда пользователь явно упоминает «Диск»/«Сетевой диск»/«Общее пространство», вы должны сначала обратиться к этому навыку для получения полного руководства и не должны действовать по памяти. Используйте этот навык, когда пользователь говорит «загрузить на диск», «помогите мне найти xxx на диске», «где этот PPT на диске», «загрузите этот файл с диска», «переименуйте этот файл на диске в xxx» или напрямую предоставляет ссылку на файл на диске в форме `https://drive.weixin.qq.com/s?k=...`. Отличие от `wecomcli-doc`/`wecomcli-sheet`/`wecomcli-smartsheet`/`wecomcli-smartpage`: этот навык обрабатывает все операции на уровне файлов (поиск/список/основная информация/расположение/путь/переименование и т. д.) для файлов (включая онлайн-документы) на Диске; Чтение/запись содержимого онлайн-документов (типы «doc/sheet/smartsheet/smartpage») обрабатывается соответствующими навыками работы с документами, а не этим навыком. Когда пользователь спрашивает «где этот документ на Диске» или расположение файла на Диске, этот навык должен использовать get для возврата метаданных, таких как имя пространства/имя папки/путь и т. д.
