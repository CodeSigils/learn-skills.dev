Competenza di gestione dei file Enterprise WeChat Micro Disk (disco/cloud disk). Gestisce l'elenco, la ricerca, la lettura dei metadati, il caricamento, il download, la ridenominazione e la creazione di operazioni di cartelle per i file in “Micro Disk/Cloud Disk”. Quando l'utente menziona esplicitamente "Micro Disk", "Cloud Disk" o "Spazio condiviso", questa competenza deve essere prima consultata per ottenere la guida completa e non deve essere gestita dalla memoria. Utilizza questa abilità quando l'utente dice "carica su Micro Disk", "aiutami a cercare xxx in Micro Disk", "dov'è quel PPT in Micro Disk", "scarica quel file da Micro Disk", "rinomina quel file Micro Disk in xxx" o fornisce un collegamento al file Micro Disk nel formato `https://drive.weixin.qq.com/s?k=...`.  

Differenza da `wecomcli-doc` / `wecomcli-sheet` / `wecomcli-smartsheet` / `wecomcli-smartpage`: questa competenza si occupa di tutte le operazioni a livello di file (compresi i documenti online) in Micro Disk come ricerca, elenco, informazioni di base, posizione, percorso e ridenominazione; la lettura/scrittura del contenuto dei documenti online (tipi `doc/sheet/smartsheet/smartpage`) è gestita dalle competenze documento corrispondenti e non da questa competenza. Quando l'utente chiede "dov'è questo documento nel Micro Disk" o chiede informazioni sulla posizione di un file nel Micro Disk, questa abilità restituisce metadati come il nome dello spazio, il nome della cartella e il percorso tramite una richiesta GET.
