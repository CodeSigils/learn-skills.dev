Competenze di gestione dei file Enterprise WeChat Disk (Disco/Netdisk). Gestisce l'elenco dei file, la ricerca, la lettura dei metadati, il caricamento, il download, la ridenominazione e la creazione di operazioni di cartelle all'interno di "Disco/Netdisk". Quando l'utente menziona esplicitamente "Disco"/"Disco di rete"/"Spazio condiviso", è necessario prima consultare questa abilità per ottenere la guida completa; non devi fare affidamento sulla memoria. Quando l'utente dice "carica su disco", "aiutami a cercare xxx nel disco", "dov'è quel PPT nel disco", "scarica il file del disco", "rinomina il file del disco in xxx" o fornisce un collegamento al file del disco in stile `https://drive.weixin.qq.com/s?k=...`, devi utilizzare questa abilità.  

Differenza da `wecomcli-doc` / `wecomcli-sheet` / `wecomcli-smartsheet` / `wecomcli-smartpage`: questa skill gestisce tutte le operazioni a livello di file (ricerca/elenco/informazioni di base/posizione/percorso/rinomina, ecc.) per ogni file nel disco, inclusi i documenti online. La lettura/scrittura del contenuto dei documenti online (tipi `doc/sheet/smartsheet/smartpage`) è gestita dalle competenze documentali corrispondenti, non da questa competenza.  

Quando l'utente chiede "dov'è questo documento nel disco" o chiede informazioni sulla posizione di un file nel disco, questa abilità dovrebbe restituire metadati come nome dello spazio, nome della cartella e percorso tramite una richiesta GET.
