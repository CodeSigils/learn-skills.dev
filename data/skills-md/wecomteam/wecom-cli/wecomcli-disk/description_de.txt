Kenntnisse im Dateibetrieb von Enterprise WeChat Disk (Disk/Netdisk). Verwaltet das Auflisten, Suchen, Lesen von Metadaten, Hochladen, Herunterladen, Umbenennen und Erstellen von Ordnervorgängen innerhalb von „Disk/Netdisk“. Wenn der Benutzer explizit „Disk“/„Netdisk“/„Shared Space“ erwähnt, müssen Sie zuerst diesen Skill konsultieren, um die vollständige Anleitung zu erhalten; Sie dürfen sich nicht auf das Gedächtnis verlassen. Wenn der Benutzer „Auf Festplatte hochladen“, „Hilf mir bei der Suche nach xxx auf der Festplatte“, „Wo ist diese PPT auf der Festplatte“, „Diese Festplattendatei herunterladen“, „Diese Festplattendatei in xxx umbenennen“ sagt oder einen Festplattendateilink im Stil „https://drive.weixin.qq.com/s?k=...“ bereitstellt, müssen Sie diese Fähigkeit verwenden.  

Unterschied zu „wecomcli-doc“ / „wecomcli-sheet“ / „wecomcli-smartsheet“ / „wecomcli-smartpage“: Dieser Skill verarbeitet alle Vorgänge auf Dateiebene (Suche/Liste/grundlegende Informationen/Speicherort/Pfad/Umbenennen usw.) für jede Datei auf der Festplatte, einschließlich Online-Dokumenten. Das Lesen/Schreiben von Inhalten von Online-Dokumenten (Typen „doc/sheet/smartsheet/smartpage“) wird von den entsprechenden Dokumentfähigkeiten und nicht von dieser Fähigkeit verwaltet.  

Wenn der Benutzer fragt „Wo ist dieses Dokument auf der Festplatte?“ oder sich nach dem Speicherort einer Datei auf der Festplatte erkundigt, sollte dieser Skill Metadaten wie Space-Name, Ordnername und Pfad über eine GET-Anfrage zurückgeben.
