エンタープライズ WeChat マイクロ ディスク (ディスク / クラウド ディスク) ファイル操作スキル。 「Micro Disk/Cloud Disk」内のファイルのリスト、検索、メタデータの読み取り、アップロード、ダウンロード、名前変更、フォルダーの作成操作を処理します。ユーザーが「マイクロ ディスク」、「クラウド ディスク」、または「共有スペース」に明示的に言及した場合、完全なガイダンスを得るために最初にこのスキルを参照する必要があり、記憶に基づいて処理してはなりません。このスキルは、ユーザーが「Micro Disk にアップロードしてください」、「Micro Disk の xxx を検索してください」、「Micro Disk の PPT はどこにありますか」、「Micro Disk からそのファイルをダウンロードしてください」、「Micro Disk ファイルの名前を xxx に変更してください」と言う場合、または「https://drive.weixin.qq.com/s?k=...」形式の Micro Disk ファイル リンクを提供する場合に使用します。  

`wecomcli-doc` / `wecomcli-sheet` / `wecomcli-smartsheet` / `wecomcli-smartpage` との違い: このスキルは、検索、リスト、基本情報、場所、パス、名前変更など、Micro Disk 内のすべてのファイル レベルの操作 (オンライン ドキュメントを含む) を扱います。オンライン ドキュメント (`doc/sheet/smartsheet/smartpage` タイプ) のコンテンツの読み取り/書き込みは、このスキルではなく、対応するドキュメント スキルによって処理されます。ユーザーが「このドキュメントは Micro Disk のどこにありますか」と尋ねたり、Micro Disk 内のファイルの場所を問い合わせたりすると、このスキルは GET リクエストを介してスペース名、フォルダー名、パスなどのメタデータを返します。
