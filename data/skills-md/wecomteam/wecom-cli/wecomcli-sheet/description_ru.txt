Навыки управления онлайн-таблицами (листами) WeCom. Обеспечивает создание онлайн-таблиц, чтение содержимого, изменение содержимого, добавление данных строк и управление добавлением/удалением подлистов. Применимые сценарии: (1) Создание пустой онлайн-таблицы (2) Чтение полного содержимого электронной таблицы (Markdown) (3) Чтение основной информации и списка подлистов (4) Чтение данных подлистов электронной таблицы (5) Изменение содержимого в указанной области (6) Добавление строки данных в конец (7) Добавление/удаление подлистов. Этот навык срабатывает, когда пользователь упоминает «Электронную таблицу WeCom», «Онлайн-таблицу WeCom», «Электронную таблицу WeCom Excel» или ссылку в форме «https://doc.weixin.qq.com/sheet/xxx». Примечание. Для смарт-листов (`/smartsheet/*`) используйте `wecomcli-smartsheet`; для обычных документов (`/doc/*`) используйте `wecomcli-doc`; для смарт-документов/смарт-страниц (`/smartpage/*`) используйте `wecomcli-smartpage`.
