WeChat Work online spreadsheet (sheet) management skill. Provides online spreadsheet creation, content reading, content modification, row data appending, and sub‑worksheet addition/deletion management. Applicable scenarios: (1) Create a blank online spreadsheet (2) Read the entire spreadsheet content (Markdown) (3) Read basic information and sub‑sheet list (4) Read sub‑sheet data of the spreadsheet (5) Modify content in a specified region (6) Append a row of data at the end (7) Add/delete sub‑worksheets. This skill is triggered when the user mentions “WeChat Work spreadsheet”, “WeChat Work online spreadsheet”, “Qi Wei Excel spreadsheet”, or provides a link of the form `https://doc.weixin.qq.com/sheet/xxx`. Note: For smart sheets (`/smartsheet/*`) use `wecomcli-smartsheet`; for regular documents (`/doc/*`) use `wecomcli-doc`; for smart documents/smart pages (`/smartpage/*`) use `wecomcli-smartpage`.
