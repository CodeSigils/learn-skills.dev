WeCom-Fähigkeiten zur Online-Tabellenkalkulationsverwaltung. Bietet die Erstellung von Online-Tabellen, das Lesen von Inhalten, die Änderung von Inhalten, das Anhängen von Zeilen und die Verwaltung des Hinzufügens/Löschens von Unterblättern. Anwendbare Szenarien: (1) Erstellen Sie eine leere Online-Tabelle (2) Lesen Sie den vollständigen Inhalt der Tabelle (Markdown) (3) Lesen Sie grundlegende Informationen und die Liste der Unterblätter (4) Lesen Sie die Daten der Unterblätter (5) Ändern Sie den Inhalt in einem bestimmten Bereich (6) Hängen Sie am Ende eine Datenzeile an (7) Fügen Sie Unterblätter hinzu/löschen Sie sie. Der Skill wird ausgelöst, wenn der Benutzer „WeCom-Tabelle“, „WeCom-Online-Tabelle“, „WeCom-Excel-Tabelle“ oder einen Link wie „https://doc.weixin.qq.com/sheet/xxx“ erwähnt. Hinweis: Für Smart Sheets (`/smartsheet/*`) verwenden Sie „wecomcli-smartsheet“; für reguläre Dokumente (`/doc/*`) verwenden Sie `wecomcli-doc`; Für intelligente Dokumente/intelligente Seiten (`/smartpage/*`) verwenden Sie „wecomcli-smartpage“.
