Enterprise WeChat Smart Table Data (Record) Management Skill. Provides the ability to add, delete, update, and query smart table records. Applicable scenarios: (1) Query all records in a sub-table (2) Add one or more rows of records (3) Update existing records (4) Delete records. This Skill is triggered when the user needs to read table data, write new data, modify or delete table rows. Supports locating documents via docid or document URL.
