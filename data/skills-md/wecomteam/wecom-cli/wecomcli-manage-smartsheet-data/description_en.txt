Enterprise WeChat Smart Sheet data (record) management skill. Provides capabilities to add, delete, modify, and query smart sheet records. Applicable scenarios: (1) Query all records in a sub-table (2) Add one or more rows of records (3) Update existing records (4) Delete records. This Skill is triggered when the user needs to read sheet data, write new data, modify, or delete sheet rows. Supports locating documents via docid or document URL.
