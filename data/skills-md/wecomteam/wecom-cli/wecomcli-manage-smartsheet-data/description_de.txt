Fähigkeit zur Verwaltung von WeChat Smart Sheet-Daten (Datensätzen) für Unternehmen. Bietet Funktionen zum Hinzufügen, Löschen, Ändern und Abfragen von Smart Sheet-Datensätzen. Anwendbare Szenarien: (1) Alle Datensätze in einer Untertabelle abfragen (2) Eine oder mehrere Datensatzzeilen hinzufügen (3) Vorhandene Datensätze aktualisieren (4) Datensätze löschen. Dieser Skill wird ausgelöst, wenn der Benutzer Blattdaten lesen, neue Daten schreiben, Blattzeilen ändern oder löschen muss. Unterstützt das Auffinden von Dokumenten über docid oder Dokument-URL.
