Habilidad de consulta por lotes de Enterprise WeChat para detalles de tareas pendientes: recupera información completa (incluido el contenido de las tareas pendientes y la persona asignada) en función de una lista de ID de tareas pendientes. Úselo cuando el usuario diga "verifique los detalles de esta tarea pendiente", "cuál es el contenido de la tarea pendiente", "a quién está asignada esta tarea pendiente", "dígame la información específica de la tarea pendiente" o solicitudes similares para ver el contenido completo. Generalmente se usa junto con wecomcli-get-todo-list: primero obtenga la lista de ID de tareas pendientes y luego use esta habilidad para obtener los detalles.
