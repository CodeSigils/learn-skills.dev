Enterprise WeChat batch query skill for to-do details: retrieves full information (including to-do content and assignee) based on a list of to-do IDs. Use when the user says “check the details of this to-do,” “what is the to-do content,” “who is this to-do assigned to,” “tell me the specific info of the to-do,” or similar requests to view the complete content. Usually used together with wecomcli-get-todo-list—first obtain the to-do ID list, then use this skill to get the details.
