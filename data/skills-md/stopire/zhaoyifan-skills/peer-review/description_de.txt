Agentenübergreifender Peer-Review-Workflow für Code-Reviews. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Codex auffordert, Code, einen Diff, einen Commit, eine Pull-Anfrage, eine Zusammenführungsanforderung, einen Patch oder eine Verzweigung zu überprüfen, und möchte, dass ein anderer Code-Agent wie Claude Code, Codex oder ein konfigurierter CLI-Prüfer unabhängig Ergebnisse vorschlägt und die Ergebnisse von Codex kritisch prüft, bevor Ergebnisse zurückgegeben werden. Verwenden Sie dies auch, wenn der Benutzer Peer-Review, einen zweiten Gutachter, eine agentenübergreifende Überprüfung, eine gegenseitige Überprüfung, die Überprüfung von Ergebnissen durch einen anderen Agenten oder die Überprüfung von Ergebnissen durch Claude erwähnt oder möchte, dass die Review-Ergebnisse validiert und nicht für bare Münze akzeptiert werden.
