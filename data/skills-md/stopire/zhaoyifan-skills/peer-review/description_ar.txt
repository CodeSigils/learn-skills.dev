سير عمل مراجعة الأقران عبر الوكلاء لمراجعات التعليمات البرمجية. استخدم هذه المهارة عندما يطلب المستخدم من Codex مراجعة التعليمات البرمجية أو الفرق أو الالتزام أو طلب السحب أو طلب الدمج أو التصحيح أو الفرع ويريد وكيل تعليمات برمجية آخر مثل Claude Code أو Codex أو مراجع CLI الذي تم تكوينه لاقتراح النتائج بشكل مستقل وإجراء تدقيق نقدي لنتائج Codex قبل إرجاع النتائج. يُستخدم أيضًا عندما يذكر المستخدم مراجعة النظراء، أو مراجعًا ثانيًا، أو مراجعة مشتركة بين الوكلاء، أو مراجعة متبادلة، أو وكيل آخر يفحص النتائج، أو يقوم كلود بمراجعة النتائج، أو يريد التحقق من صحة نتائج المراجعة بدلاً من قبولها في ظاهرها.
