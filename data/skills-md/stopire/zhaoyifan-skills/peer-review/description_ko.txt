코드 검토를 위한 에이전트 간 동료 검토 워크플로입니다. 사용자가 Codex에게 코드 검토, diff, 커밋, 풀 요청, 병합 요청, 패치 또는 분기를 요청하고 Claude Code, Codex 또는 구성된 CLI 검토자와 같은 다른 코드 에이전트가 결과가 반환되기 전에 독립적으로 결과를 제안하고 Codex의 결과를 비판적으로 감사하기를 원할 때마다 이 기술을 사용합니다. 또한 사용자가 동료 검토, 두 번째 검토자, 에이전트 간 검토, 상호 검토, 다른 에이전트 확인 결과, Claude 검토 결과를 언급하거나 검토 결과를 액면 그대로 받아들이기보다는 검증하기를 원하는 경우에도 사용합니다.
