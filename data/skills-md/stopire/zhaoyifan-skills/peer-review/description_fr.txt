Workflow de révision par les pairs entre agents pour les révisions de code. Utilisez cette compétence chaque fois que l'utilisateur demande au Codex de réviser le code, une différence, une validation, une demande d'extraction, une demande de fusion, un correctif ou une branche et souhaite qu'un autre agent de code tel que Claude Code, Codex ou un réviseur CLI configuré propose de manière indépendante des résultats et audite de manière critique les résultats du Codex avant que les résultats ne soient renvoyés. À utiliser également lorsque l'utilisateur mentionne l'évaluation par les pairs, un deuxième évaluateur, l'évaluation multi-agents, l'évaluation mutuelle, un autre agent vérifiant les résultats, Claude révisant les résultats, ou souhaite que les résultats de l'examen soient validés plutôt qu'acceptés à leur valeur nominale.
