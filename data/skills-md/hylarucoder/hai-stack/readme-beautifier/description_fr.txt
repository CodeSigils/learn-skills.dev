Produit un README restructuré, formaté de manière cohérente et d'aspect professionnel (ou un document de projet de démarque similaire tel que CONTRIBUTING.md, docs/index.md, 项目说明.md) plus un bref résumé des modifications — contenu intact : rien d'ajouté, rien de supprimé, seule la structure et le formatage sont corrigés (hiérarchie des titres, listes, blocs de code, tableaux, espacement). À utiliser chaque fois que l'utilisateur demande d'embellir, de ranger, de réorganiser, de reformater, de formater ou de réparer un README — et d'être insistant : déclenchez même lorsque l'utilisateur se contente de vider un README désordonné et dit 太乱了 / 看下 / 帮我弄一下, sans jamais dire « embellir ». Déclencheurs : README 美化, README 美化, 整理 README, README 排版, README 格式化, README 太乱了, 看下我这个 README, embellir README, réparer/formater/nettoyer/ ranger/polisser/reformater README, réorganisez le fichier Lisez-moi, mon fichier Lisez-moi a l'air désordonné/moche, donnez à mon README un aspect professionnel.
