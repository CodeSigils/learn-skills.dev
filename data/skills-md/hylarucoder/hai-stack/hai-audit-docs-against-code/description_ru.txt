Проверяет документацию на соответствие реальному коду, конфигурации, схемам и контрактам API и создает
отчет по степени серьезности (P0-P3 + необходимые доказательства) по каждому устаревшему или несоответствующему заявлению, каждое с документом
местоположение, ссылка на код/контракт, влияние и минимальное предлагаемое исправление. Используйте каждый раз, когда пользователь
хочет проверить документы README/docs/API на соответствие реализации, проверить, не отстает ли документация или
подтвердите, что шаги настройки/переменные окружения/конечные точки/примеры по-прежнему соответствуют коду после переименования или рефакторинга —
даже на случайные вопросы, такие как «是不是过时了», «README 和代码对不上», «readme 还准吗», «我们改了接口文档忘了更新吧»,
«проверить наши документы» или «соответствуют ли документы». Запуск по 文档和代码一致性, 文档是否过时, 文档跟实现不一致,
API-интерфейс API, openapi-интерфейс, проверка документации на соответствие коду, документация и реализация. Для документа против документа
внутренние противоречия без сравнения кода, вместо этого используйте hai-audit-docs-internal.
