Verifica bloque por bloque un documento desviado y parcheado; en comparación con las conclusiones actuales, el
base de código y cualquier otra cosa que se pueda verificar; luego lo reescribe en torno a la evidencia: bloquea eso
sobreviven a la verificación mantienen su redacción original, los bloques que fallan se eliminan (nunca se reparan)
en una solución que parece plausible), y el resultado se envía como el documento reescrito más un
tabla de disposición (mantener/eliminar/indeciso, cada uno citando el cheque) y una lista de preguntas abiertas
lista. Usar siempre que se haya acumulado un documento
reclamaciones confusas y dudosas a través de rondas de discusión y el usuario quiere que se verifiquen y limpien,
No parcheado de nuevo. Activar en 重写这份文档, 这文档已经烂了, 文档已经不对了, 逐条核实这份文档,
把不对的内容删掉, 按最新结论重写, 文档跟讨论结论对不上, 别再缝缝补补了,推倒重写 e inglés
como "reescribir este documento", "verificar este documento y eliminar lo que está mal", "este documento se ha desviado". Para
un informe de resultados sin reescritura utiliza hai-audit-docs-internamente; si el documento es un uso PRD
hai-prd; si es un plan o un documento de objetivos, utilice hai-goal.
