Genere una tarjeta visual con calidad de revista como un único archivo HTML autónomo (CSS integrado, cuadrícula suiza + sistema de diseño en negrita), luego haga una captura de pantalla en un PNG que se pueda compartir y devuelva ambos archivos. Úselo siempre que el usuario quiera que el contenido se convierta en una tarjeta visualmente rica o en una imagen para compartir, incluso si no dice la palabra "tarjeta". Desencadenantes: crear/crear/generar/diseñar una tarjeta visual, una tarjeta de información, una tarjeta de conocimientos, una tarjeta de cotización, una tarjeta social, una tarjeta de resumen/para llevar/de hoja de trucos; 信息卡, 知识卡片, 金句卡, 语录卡, 做张卡片, 设计一张卡片, 把这段内容做成卡片,把要点排成一张图, 总结成一张图, 小红书封面, 公众号封面图, 朋友圈配图. Prefiere esto a las habilidades genéricas de HTML/frontend cuando el objetivo es una imagen de tarjeta decorativa. Cuando el contenido sea un informe de varias secciones en lugar de una sola tarjeta, utilice hai-visual-report.
